# 企画案: 半導体・IT につながる物理・化学・数学の基礎(2026-10-23)

運営者の依頼(物理・化学・数学の基礎分野を足す案を批判的に検討し、最初の実施案まで)への回答。今回は企画まで。

## 0. 結論

- **候補の分野を「教科」として足すのはやめる。** 物理・化学・数学の教科書の順番で分野を作ると、Khan Academy・LibreTexts・Wikipedia・大学の講義資料と正面からぶつかり、勝ち目が薄い。量も多く(候補は50近い)、保守できない
- 代わりに、**「1つの基礎の考え方が、どの技術で何に効いているか」を1テーマとする小さな橋渡しの単元**を作る。教科の網羅ではなく、サイトの既存の分野(81)から逆算して、理解のつまずきになっている基礎だけを選ぶ
- 候補の多くは、すでにサイトの分野が受け持っている(下の2章)。足すのは「足りない基礎」だけで、最初は **6テーマ** を英語・日本語・繁体字で同時に小さく出し、8週間で需要と効果を見てから広げる
- 1テーマ = **解説1本 + 計算ツールかシミュレーター1つ + 小さな問題集(15問)**。形式はテーマごとに変える(5章)

## 1. 現状(確認した事実)

- サイトは81分野・3,827問・用語約1,350語・比較162件・ツール63本。基礎に近い分野がすでにある: 半導体物性(50問)、PN接合、電気回路・電磁気の基礎(50問、ただし用語0語)、デジタル信号処理(フーリエ・サンプリング)、制御工学(ラプラス変換・伝達関数)、計算機算術(浮動小数点)、確率・統計と待ち行列、情報理論と符号、データ構造とアルゴリズム(グラフ)、論理回路(ブール代数)、量子コンピュータのハードウェア、シリコンフォトニクス(光学の一部)、エッチング(プラズマ)、酸化・拡散(Deal–Grove)、CMP・洗浄(表面の化学)、信頼性(ワイブル・アレニウス)
- 関連するツールもある: 真性キャリア密度、バンドギャップと波長、抵抗率と不純物濃度、PN接合の空乏層、Deal–Grove、RC時定数、配線のRC遅延、接合温度、ハミング符号、CRC、IEEE 754、ボード線図、PID、メモリ帯域、待ち行列
- Search Console(実質1週間)で、基礎に近い検索は約90語・表示911回(全体の約1割)。届いているのは**応用と結びついた語**: fermi level in semiconductor、mobility and conductivity in semiconductors、band gaps of semiconductors、本質載子濃度(繁体字 2.6位)、segregation coefficient、ベガード則、格子不整合、マシンイプシロン・mantisse、quantum efficiency、equivalent oxide thickness
- 純粋な数学の検索(フーリエ変換、行列、微分方程式など)は、ほぼ出ていない。ページがないので当然で、**需要がないという証拠ではない**(推測を含む)

## 2. 候補の評価(統合・除外・追加)

| 判断 | 候補 | 理由 |

| **作らない(当面)** | 力学・材料力学、流体、無機化学・有機化学・高分子化学の一般、光化学、電気化学の一般、量子化学、計算幾何、微分積分・線形代数・複素関数の一般論、実験計画法の単独分野 | 技術とのつながりが一部に限られる(例: 材料力学はパッケージの反りだけ、有機・高分子はレジストだけ)。その部分は応用側の分野に小さく入れる。一般論は競合が強すぎ、サイトの強みが出ない |

| **候補になかったが足したい** | 「浮動小数点の誤差と数値の精度」(マシンイプシロンの検索あり)、「指数関数と対数で見る技術」(dB・ムーアの法則・サブスレッショルド 60 mV/桁・アレニウス) | 検索の実績、または多くの分野で共通のつまずき |

## 6. 学習の導線(基礎 → 応用)

各テーマの解説の最後に「この考え方が出てくる技術」を3〜5個、既存のページ(用語・比較・図解・ツール・やさしい解説)へのリンクで並べる。逆向きに、応用の用語ページ・分野ページから「基礎から読む」で戻れるようにする(やさしい解説と同じ仕組み)。

- ボルツマン分布 → 熱電圧 kT/q → ダイオードの電流 → サブスレッショルド 60 mV/桁 → 待機電力とリーク
- アレニウス → 活性化エネルギー → 熱酸化の速度(Deal–Grove) → 加速試験(HTOL) → 故障率(バスタブ曲線)
- 拡散方程式 → √(Dt) → 不純物の分布 → PN接合の位置 / 熱の広がり → 接合温度 / 配線の RC → 長さの2乗の遅延
- 量子力学 → トンネル効果 → ゲート酸化膜の限界 → High-k → フラッシュの FN 書き込み → MTJ
- 有限体 GF(2) → 多項式の割り算 → CRC / LFSR → PRBS 試験 → 誤り訂正(SSD の ECC)
- 線形代数 → 行列の積の演算量 → 演算強度 → ルーフライン → GPU・HBM の選び方
- (第2段)微分方程式 → RC回路 → 2次系の減衰 → 電源のリンギング・PID 制御

## 7. サイトの構成

- やさしい解説(/learn/)の新しいシリーズ「Foundations for chips / 技術につながる基礎 / 技術背後的基礎」として解説を置く(仕組みはできている)
- 問題は新しい区分「基礎(物理・化学・数学)」に、テーマごとの小さな分野(12〜15問)として置く。分野一覧で1つの区分にまとまり、既存の81分野は散らからない
- ツールは既存の /tools/ に足す
- 解説の本文からクイズへは誘導しない(運営者の指示)。記事の後の1行だけ

## 8. 言語

- 運営者の方針どおり**英語を主軸**に書く(英語で書き起こし、題・説明も英語の検索語から決める)
- ただし最初の6テーマは**英語・日本語・繁体字で同時に**出す。英語はまだサイトの信頼が低く(平均50〜80位)、英語だけで出すと8週間では需要を判断できないおそれがある。日本語・繁体字は順位が出ているので、学習効果と回遊を測りやすい
- 韓国語・ドイツ語・オランダ語・フランス語は、成績のよいテーマだけ後で

| 週 | すること |
|---|---|
| 1 | アレニウス・AI の線形代数(ツールが主役で、負担が小さく、需要が見込める2つ)を英日繁で公開 |
| 2 | ボルツマン・フェルミ、GF(2)・多項式 |

- 量: 解説6本×3言語、新しいツール6つ、問題約85問×3言語。書く係と別の係による事実の確認(やさしい解説と同じ流れ)。数値・式は Python で検算
- **8週間後に見る数字**:
  - 集客: テーマのページ(解説・ツール)の検索表示とクリック。既存の用語ページの平均と比べる
  - 使われ方(GA4): ツールの利用回数、解説から応用のページへ進んだ割合、逆に応用から基礎へ戻った割合
  - 学習効果(近似): 基礎の問題集の正答率と、関連する応用分野の問題を続けて解いたか
- **続けるかの判断**: 6テーマのうち半分以上が、1ページあたりの表示で用語ページの平均を超えるか、ツールの利用が既存のツールの中央値を超えれば、7・8と第2段へ。どちらも届かなければ、新しいテーマは止め、既存の分野の中の「前提の説明」を厚くする方向に切り替える

## 10. 追加しない方がよいもの(まとめ)

- 物理・化学・数学の一般的な教科書の順番の分野(微分積分・線形代数・複素関数・力学の一般論など): 競合が強く、サイトの強み(半導体・IT との結びつき)が出ない。量が多く保守できない
- 材料力学・流体・高分子化学・有機化学・光化学・コロイドの独立した分野: 技術とのつながりが一部に限られる。必要な部分(パッケージの反り、レジストの化学、CMP のスラリー)は応用側の分野に小さく入れる
- 量子化学・計算幾何: 対象の読者が少なく、問題にしても技術の理解につながりにくい
- すでにある分野と同じ内容(半導体物理、確率統計、待ち行列、ブール代数、オートマトン、グラフ、情報理論): 新しく作らず、既存の分野を厚くする
