# 公開前の品質基準(チェックリスト)

## 状態の言葉

- **未確認**: まだ調べていない
- **確認済み**: 問題の有無を調べた(修正はしていない)
- **修正済み**: 変更したが、検証は終わっていない
- **検証済み**: 修正後に、書いた方法で正しさ・動作を確かめた(方法を必ず併記する)

実行していない検証を「検証済み」と書かない。確認した区画の結果を、ほかの区画に当てはめない。

## 優先度

学習者への影響で決める。迷ったら「誤った理解をさせるか」「学習・操作ができなくなるか」「何人・何ページに影響するか」の順に考える。

- **P0**: 誤った知識を教える(定義・数式・単位・数値の誤り、問題の正解の誤り・複数正解、計算ツールの計算誤り)。主要な機能が動かない(回答・採点・解説・ツールの計算・言語の切り替え)。多数のページに広がる共通の不具合
- **P1**: 読みにくい・操作しにくい、説明不足、導線不足、言語間の不一致、検索上の構成の問題
- **P2**: 学習への影響が小さいもの

区画内で数分で確実に直せるもの(誤字・表記ゆれ・リンク先の誤り)は、優先度によらずその場で直す。

## 毎回の機械的な点検(公開前に必ず実行)

```
node tools/build.js && npm test && npm run check:site && npm run audit
```

- `npm test`: 問題データの形式・翻訳の数値・正解の位置の偏り・記事の型・翻訳の古さ
- `npm run check:site`: 内部リンク切れ・JSON-LD・title/description
- `npm run audit`: サイトマップと noindex・canonical・hreflang・孤立ページ・alt・埋め込みの失敗・問題データの重複や訳の欠け

## 用語解説・比較・記事

- [ ] 定義・数式・単位・数値・適用条件・図を、実際に読めた資料(教科書・規格・公式資料・原論文)と照合した。読めなかった資料や記憶だけの主張は「未確認」と書き、推測で書き換えていない
- [ ] 一言の定義/仕組みと前提条件/式の記号と単位/具体的な数値の計算例/誤解しやすい点/関連する用語・ツール・問題へのリンク、のうち内容に必要なものがある
- [ ] 検索語(Search Console)と内容が合っている(検索した人の知りたいことに答えている)
- [ ] 冗長な前置き・一般論がない。文章を増やすこと自体を目的にしていない
- [ ] 日本語・英語・繁体字で意味が同じ。用語の訳がサイト内でそろっている(繁体字は台湾の用語)

## 計算ツール

- [ ] 計算結果を手計算・教科書の例題・既知の値と照合し、テストケース(境界値・単位換算・桁の大きい値を含む)をリポジトリに残した
- [ ] 画面に、使っている式・前提条件・単位・適用範囲・計算例がある
- [ ] 単位を取り違えやすい入力(kHz/Hz、nm/µm など)は、単位を明示するか選択式にしている
- [ ] 関連する用語解説・問題へのリンクがある
- [ ] PC(1280px)とスマホ(375px)で、入力・計算・グラフ・共有が動き、コンソールにエラーがない

## 問題

- [ ] 正解と解説を見ずに自分で解き、データの正解と照合した(不一致・迷いは要精査)
- [ ] 正解が成立し、1つに定まる。誤答の選択肢は明確に誤りで、学習上意味がある
- [ ] 解説が設問・正解と一致している。関連する用語・ツールへ進める
- [ ] 根拠が確定しない正解の変更はしていない(論点を記録して報告する)
- [ ] 全言語(日本語を直したら `npm run i18n:stale` で訳し直しが必要な言語を確認)に反映した

## 表示

- [ ] 問題文: スマホ 18px・PC 20px、太さ600、行間1.65。選択肢 17px・太さ400。解説・本文 16px・太さ400・行間1.8(2026-11-02 の基準)
- [ ] スマホ(375px)と PC(1280px)、日本語・英語・繁体字で見え方を確かめた。和文・漢字は同じ太さでも重く見えるので、700 以上の太字は重要語だけにする
- [ ] 広告が本文や操作と重ならない

## 画像

- [ ] 正確さが要る図(回路図・バンド図・グラフ・波形・ブロック図・数式を含む図)は SVG かコードで描いた
- [ ] 説明用のイラストやサムネイルは、画像生成 AI への依頼を `quality/images/requests.md` に書いた。届くまでは画像なしでもページが成り立つ
- [ ] 届いた画像の内容(誤った描写・不自然な文字)を確かめてから載せた。alt を各言語で付けた

## 検索の構成

- [ ] 意図しない noindex・重複 URL・canonical/hreflang の誤り・サイトマップ漏れがない(`npm run audit`)
- [ ] 順位は期間・検索語・ページ・国・端末をそろえ、表示回数・クリック数と合わせて比べた。平均順位だけで判断していない
- [ ] ページやURLの削除・変更、noindex の一括設定はしていない(必要なら根拠と影響範囲を示して提案にとどめる)
