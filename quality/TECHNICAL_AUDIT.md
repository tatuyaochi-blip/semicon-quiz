# 技術監査: 重点15項目の検証(2026-10-19)

ChatGPT による初期評価(「正しい/条件付き/誤り」)を仮説として扱い、項目ごとに独立に検証した結果です。

## 検証の方法と限界

- 3体の AI エージェントが Web 検索で一次資料を探しました。結果は保守担当(Claude)が読み、修正の採否を判断しました。
- **一次資料の本文は、どの項目でも開けていません。** この環境のネットワーク制限で、次のサイトへの接続がすべて拒否されました: aecouncil.com、iso.org、jedec.org、eur-lex、IEEE Xplore、arXiv など。
- そのため根拠は、検索結果に出た抜粋に限られます。メーカーの認定報告書・アプリケーションノート、論文、規格の目録ページ、二次資料などです。下の「根拠」欄はすべて「検索結果の抜粋で確認(本文未閲覧)」です。
- ISO・IEC・JEDEC・IEEE の規格本文(有料)は確認していません。
- 規格の箇条番号・表番号のうち確認できなかったものは、「未確認」と書いています。
- 出典の URL は、検索結果に実際に出たものだけを載せています。
- 以上から、この文書の判定は「人間の専門家による確認」の代わりにはなりません。重要な数値は、規格本文で確かめることを勧めます([UNVERIFIED_CLAIMS.md](UNVERIFIED_CLAIMS.md))。

## 項目ごとの結果

### 1. AEC-Q100 の HAST(130 ℃/85%RH/96 h)で THB(85 ℃/85%RH/1000 h)を置き換えられる — 正しい
- AEC-Q100 の Table 2、試験 A2 は「THB または HAST」の選択式です。
  - THB は JESD22-A101 で、85 ℃/85%RH・1000 h です。
  - バイアス付き HAST は JESD22-A110 で、130 ℃/85%RH・96 h です。
- バイアスなしの A3 にも、同じ 130 ℃/96 h の HAST があります。
- 現行の版は Rev J と見られます。供給者の 2026 年の通知が Rev. J を引用しています。版の発行年は未確認です。
- 根拠(検索結果の抜粋で確認): Qualcomm と Power Integrations(InnoSwitch3-AQ)の AEC-Q100 認定表、Nexperia TL431FDT-Q の信頼性資料、TI の PCN(Rev. J を引用)。AEC の公式文書は接続できず、未閲覧です。
- サイト: automotive-008、reliability-012/036/045 の記述は正確です。

### 2. AEC-Q100 のラッチアップ試験は最高動作温度で行う — 条件付きで正しい
- AEC-Q100-004 は JESD78 に基づき、Class II で試験します。Class II の温度は、グレードの**最高周囲温度(またはケース温度)**です。最高接合温度ではありません。
  - 例: Grade 0 は 150 ℃、Grade 1 は 125 ℃。
- JESD78 の Class I は室温での試験です。
- サイトの修正(automotive-009):
  - 問題文の「室温だけでなく」は、室温試験も必須と読めました。これを「室温より厳しい」に直しました。
  - 解説には、JESD78 Class II と、グレードの最高周囲温度(Grade 1 なら 125 ℃)を明記しました。
- 根拠(抜粋): JESD78F.02(TI E2E 上の写し)、Semitracks ニュースレター(2018-10)、NASA NEPP ETW 2020 の AEC 発表、Microchip MCP8024 データシート(「Latch-up AEC Q100-004, 150°C」)。

### 3. ISO 10605: 接触放電は数〜十数 kV、気中放電は 25 kV 程度まで — 条件付きで正しい
- 試験器(ESD ガン)の能力は、接触 2〜15 kV、気中 2〜25 kV です。放電回路は 150/330 pF と 330 Ω/2 kΩ の組み合わせです。
- 附属書の推奨レベルは、レベル4で接触 ±8 kV 程度、気中 ±15〜25 kV 程度です。この表は二次資料で見たもので、規格本文では未確認です。
- 実際の試験レベルは、放電回路、車内か車外か、OEM の仕様で変わります。
- 現行版は ISO 10605:2023(第3版)です。
- サイトの「数 kV から十数 kV(気中放電では 25 kV 程度まで)」は、目安として妥当です。
- 根拠(抜粋): TI SLVA954、Noiseken/SCA-Shinyei の規格解説、In Compliance Magazine、ISO の目録ページ。

### 4. ISO 16750-2 ロードダンプ(Test A)の td は 40〜400 ms — 条件付きで正しい
- 40〜400 ms は **12 V 系**の値で、Ri はおよそ 0.5〜4 Ω です。**24 V 系**は 100〜350 ms、Ri はおよそ 1〜8 Ω です。TI はこれを「典型値」として表にしています。
- Test B は、オルタネータ側で電圧を一括クランプした場合の試験です。12 V 系では 35 V という値が示されています(ADI)。
- 現行版は ISO 16750-2:2023(第5版)で、ロードダンプは 4.6.4 項に残っています。2023 年版でロードダンプがどう変わったかは確認できませんでした。
- サイトの修正(automotive-046): 解説に Test A の 12 V 系の継続時間 40〜400 ms を加えました。あわせて、Test B の 35 V 程度のクランプが、40 V 級の部品が多い理由になることも加えました。
- 根拠(抜粋): TI SNOAAA1、ADI LT Journal(LTC4380)、Diotec のアプリケーションノート、ISO 16750-2:2023 の目録。

### 5. ISO 26262 の SPFM・LFM・PMHF の目標 — 条件付きで正しい
- ISO 26262-5 は、これらの値を目標値の「導出のための情報源の一つ」として示しています。絶対の要求ではなく、ASIL B では推奨扱いです。

  | | SPFM | LFM | PMHF |
  |---|---|---|---|
  | ASIL B | ≥90% | ≥60% | <10⁻⁷/h(100 FIT) |
  | ASIL C | ≥97% | ≥80% | <10⁻⁷/h(100 FIT) |
  | ASIL D | ≥99% | ≥90% | <10⁻⁸/h(10 FIT) |

- 2018 年版での表番号は未確認です。
- サイトの automotive-018/019/021 はこれらの値と一致し、「目安」と書いているので、変更していません。
- 根拠(抜粋): Infineon AURIX の FMEDA(KBA236341)、Presencis の ISO 26262 Part 5 解説、In Compliance Magazine。

### 6. ASIL は S・E・C の数字の合計(10→D、9→C、8→B、7→A)と一致する — 条件付きで正しい(初期評価「誤り」を棄却)
- ISO 26262-3 は ASIL を**表**で定めています(2018 年版の Table 4)。
- S1〜S3・E1〜E4・C1〜C3 の 36 マスを1マスずつ照合したところ、合計の規則はすべてのマスで表と一致しました。
- ただし S0・E0・C0 のどれかがある場合は、ASIL を割り当てません。例えば S0+E4+C3 は合計 7 ですが、A にはなりません。この場合、合計の規則は使えません。
- サイトの automotive-015 は、この規則を S1〜3・E1〜4・C1〜3 に限ったうえで「覚え方の目安」と書いています。規格が表で定めることも明記しているため、正確です。修正していません。
- 根拠: ISO 26262-3:2018(有料、本文未閲覧。表の値は二次資料と照合)、Quality-One の ASIL 表、arXiv:1804.04349、Embitel の解説。

### 7. シリコンのストリップ導波路の損失はおおむね 1〜3 dB/cm — 条件付きで正しい
- この値が当てはまる条件:
  - 220 nm SOI の単一モードのストリップ導波路(幅 450〜500 nm)
  - TE モード、C バンド
  - 標準のドライエッチング
- 成熟したファウンドリでは 1〜2 dB/cm 程度です。リブ導波路や平滑化処理を使うと 0.1〜0.5 dB/cm 程度に下がります。
- サイトの photonics-004/047 は「条件によります」「代表的なストリップ導波路」と書いているので、正確です。
- 根拠(抜粋): CEA-LETI(HAL hal-03173743)、Grenoble の HAL 論文(hal-01942772)、Debnath ら(Frontiers in Materials 2016)、BU のファウンドリ低損失導波路の論文。

### 8. 空乏型シリコン MZM の VπL はおおむね 1〜3 V·cm — 条件付きで正しい
- この値が当てはまる条件:
  - 220〜250 nm SOI、1550 nm
  - 数 V の逆バイアス
- この条件で典型的な値は 1.5〜3 V·cm です。最適化した接合では 1 V·cm 程度まで下がり、初期の素子では 4〜5 V·cm でした。逆バイアスを大きくすると VπL は増えます。
- サイトの photonics-017 は「ドーピングや動作条件によりますが」と条件を書いているので、正確です。
- 根拠(抜粋): Watts ら(MIT/Sandia 2010)、Advances in Radio Science 15, 269 (2017)、ETRI の論文。

### 9. リング共振器の温度によるずれは約 0.07〜0.08 nm/℃ — 条件付きで正しい
- 理論式は dλ/dT ≈ λ·(dn/dT)/ng です。C バンドの 220×500 nm SOI では、ng が 4〜4.3、dn/dT が 1.8〜1.86×10⁻⁴/K です。
- これから 70〜80 pm/K となり、報告されている値 68〜80 pm/K とも合います。O バンドや別の断面形状では、値が変わります。
- サイトの photonics-019 は C バンドに限っているので、正確です。
- 根拠(抜粋): Photonics Research 2(2) 2014、US 特許 9513437、arXiv:1710.03605。

### 10. 100 Gb/s/レーンのマルチモード短距離の到達距離は 50〜100 m — 条件付きで正しい
- IEEE Std 802.3db-2022 の到達距離(OM4/OM5): VR 系(100GBASE-VR1 など)は 50 m、SR 系(100GBASE-SR1 など)は 100 m です。
- OM3 は短くなります。タスクフォースの目標値では VR が 30 m、SR が 60 m です。規格本文の表は未確認です。
- サイトの修正(photonics-044): 「OM4 ファイバで 50〜100 m 程度、OM3 ではさらに短い」と、ファイバの種類を明記しました。
- 根拠(抜粋): IEEE Xplore の目録、IEEE P802.3db の目標資料(murty_3db_adhoc_01b_121720)、Cabling Installation & Maintenance。

### 11. CDC のパルス同期で、送り側のパルス幅を受け側のクロック周期の1.5倍以上にする — 条件付きで正しい
- 出典は Cummings の「3エッジ」要件です(SNUG 2008。Litterick の提案として紹介)。受け側のクロックの3つの連続したエッジにわたって信号を保持すれば、少なくとも1回は余裕をもって取り込めます。
- この要件には前提と限界があります:
  - セットアップ・ホールド窓とジッタが、0.25 周期より十分小さいこと。
  - 保証されるのは「取り込める」ことだけです。受け側で1サイクル幅のパルスになることまでは保証しません。
- サイトの修正(sta-cdc-034): 解説に、この前提と「3エッジ」要件との対応を明記しました。
- 根拠(抜粋): Cummings の SNUG 2008 論文(大学のミラー。原典サイトは接続不可)と、その写し、fpgacpu.ca。

### 12. 同期化 FF を1段増やすと MTBF は約 e^(t/τ) 倍 — 条件付きで正しい
- 1段で増える解決時間は、1周期そのものではありません。1周期から、FF の clock-to-Q 遅延とセットアップ時間(と配線遅延)を引いた分です。
- 多段の場合の簡単な式は近似です(Ginosar のグループの指摘)。
- サイトの修正(sta-cdc-027): 解説に、増える解決時間の正確な定義を加えました。正解(約1周期分 → e^50 倍)は変わりません。
- 根拠(抜粋): Ginosar「Metastability and Synchronizers: A Tutorial」(IEEE D&T。書誌情報のみ)、Beer・Ginosar の 2014 年と 2015 年の論文(technion)。

### 13. MSL 3 は開封後 30 ℃/60%RH 以下で 168 時間以内にリフロー — 正しい
- 分類は IPC/JEDEC J-STD-020 が定め、取り扱い・ベーキングは J-STD-033 が定めます。
- 192 h は認定試験での吸湿時間で、フロアライフではありません。
- サイトの修正(datasheet-045): 「JEDEC の規格(J-STD-020)」を「IPC と JEDEC の共同規格(分類は J-STD-020、取り扱いは J-STD-033)」にしました。
- 根拠(抜粋): JEDEC の J-STD-033 のページ(接続不可)、Hilscher の Q&A、Broadcom AV02-1298EN。

### 14. RoHS は10物質、均質材料あたり 0.1 wt%(カドミウムは 0.01 wt%) — 条件付きで正しい
- 根拠は指令 2011/65/EU の Annex II と、それを改正した委任指令 (EU) 2015/863 です。
  - 4種類のフタル酸エステルは、2019年7月22日から適用されました。医療機器と監視・制御機器は2021年からです。
  - Annex III/IV の適用除外があります。例えば、高融点はんだ中の鉛です。
- サイトの修正(datasheet-046):
  - RoHS は EU の「指令(Directive)」で、日本語で「規則」と書くと Regulation(REACH 規則など)を指します。選択肢と解説の「規則」を「指令」に直しました。
  - 適用除外があることを一文加えました。
- 根拠(抜粋): legislation.gov.uk にある EU 指令 2011/65/EU と 2015/863 の写し、ChemSafetyPro。

### 15. EUV の NA を 0.33 から 0.55 にすると、同じ k2 で焦点深度は約 1/2.8 — 条件付きで正しい
- DOF = k2·λ/NA² から、λ と k2 が同じなら (0.33/0.55)² ≈ 0.36 となり、約 1/2.8 です。Hsu & Liu (2017) の「64% 減少」と一致します。
- 実際に使える焦点深度は、照明・パターン・マスクの 3D 効果・レジストで変わります。この値は1次の目安です。
- サイトでこの数値を使っているのは、計算ツール(露光の解像度)と用語集で、どちらも正確です。
- 根拠(抜粋): Hsu & Liu, Advanced Optical Technologies (2017)、imec の論文。
