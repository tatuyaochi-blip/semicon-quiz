# デザインの仕様(2026-11-11 の見直し)

検索データ(3か月): 入口の約8割は用語ページ(とくに繁体字)。クリックの約64%は PC。目的は広告収入なので、1回の訪問で見るページを増やす。

## 考え方

「調べに来た人が、その場で答えを得て、すぐ1問解ける」。飾りより、定義・図・問題を先に見せる。配色とロゴは変えない。

## 色(src/css/style.css の :root。ダークも同じ名前)

| 役割 | 変数 | 使いどころ |
|---|---|---|
| 背景 / 面 | --bg / --surface | ページ / カード |
| 文字 / 補助の文字 | --text / --muted | 本文 / 補足・件数 |
| 強調 | --accent(青)、--accent-2(緑)、--grad(青→緑) | リンク・主なボタン・例題の枠 |
| 境界 | --border | カードの線 |
| 状態 | --ok / --ng | 正解 / 不正解 |

## 文字

- 本文 17px・行間 1.75。解説の段落は .94rem・行間 1.8
- 見出し: トップの h1 は 1.65〜2.2rem(画面幅で変わる)、h2 1.25〜1.35rem、h3 1.05rem
- 日本語の見出しは文節で折り返す(word-break: auto-phrase、text-wrap: balance)

## 幅と余白

- 読むページ: 本文 760px
- トップと用語ページ(PC): 1040px(ヘッダー・フッターと同じ幅)。用語ページは本文 + 右の欄 264px(1100px 以上)
- トップの節の間は 44px

## 部品

- 主なボタン: .btn-primary(グラデーション)。1画面に1つ
- カード: 角丸 14px、線 1px。押せるカードはホバーで線が青になり 1px 浮く(0.12秒)
- アイコンのタイル: .ref-tile(資料のトップ・トップの「できること」で共通)
- チップ: .chip(分野・関連する用語・スマホの目次)
- 定義の枠: .term-def(左に青い線)

## 動き

- 使うのは、カードのホバー(0.12秒)、例題の正誤の表示、開閉の矢印だけ。スクロールに連動する演出や固定表示は使わない(読むサイトで、広告も入るため)
- 「動きを減らす」設定では、すべての動きを止める
- JavaScript が動かなくても、例題は「答えと解説を見る」で読める

## トップの構成(上から)

1. 何のサイトか・始めるボタン・その場で解ける例題(config.homeSample)
2. 分野から選ぶ(大分類6つ。PC は2列)
3. しくみを図で確かめる(config.homeFigures の図。スマホ4点、PC 6点)
4. できること(アイコンのタイル12個)
5. 学習コース、ほかの練習方法

## 用語ページの構成

1. 用語名・読み・定義の枠・分野
2. スマホ: 横に送れる目次。PC: 右の欄(目次・この分野を10問解くボタン・関連する用語)が画面に残る
3. 解説 → 練習問題 → よくある質問 → 出てくる問題 → 関連する用語

## 右の欄を使うページ(2026-11-11 に比較・問題・分野へ広げた)

PC(1100px 以上)で、本文の右に幅264pxの欄を置く。build.js の `rail()` が共通で作る。スマホでは目次だけを横に送れる行で出し、ほかは本文の下の一覧で見せる。

| ページ | 目次 | 問題を解くボタン | 一覧 |
|---|---|---|---|
| 用語 | 解説の見出し・練習問題・よくある質問など | その用語の分野を10問 | 関連する用語 |
| 比較 | どんなときに使うか・よくある質問・理解度チェックなど | その比較の分野を10問 | 関連する用語、関連する比較 |
| 問題 | なし | その分野を10問 | 同じ分野のほかの問題、この分野の比較 |
| 分野 | なし | なし(本文に主ボタンがある) | この分野の用語(8語)、同じ大分類のほかの分野 |
| やさしい解説 | 本文の見出し(PC だけ) | 記事の主な分野を10問 | 次に読む(同じシリーズの続き3本)、関連する用語 |

- 右の欄に出した一覧と同じものが本文の下にもあるとき(問題のほかの問題、分野のほかの分野)は、PC では下のほうを隠す(.rail-dup)

## 計算ツール(2026-11-11 の見直し)

運営者の指摘(使いづらく見にくい)を受けて、全ツール共通の入力・結果の作りを直した。ツールごとの HTML は変えず、build.js の後処理・共通の CSS・共通のスクリプト(src/js/tool-ui.js)で行う。

| 場所 | 前 | 後 |
|---|---|---|
| 入力のラベル | 薄い小さな字。「(nm)」などの単位がラベルに入り、2行に折れる | 濃い字。単位は入力欄の右端に出す(読み上げ用にラベルにも残す) |
| 入力の並び(PC) | 狭い列に2列で並び、ラベルが折れる | 「ラベル | 入力欄」の1行ずつ。選択欄はラベルの下に横いっぱい |
| リセット | なし | 入力の枠の右上に「リセット」(入力と結果が左右に分かれるツール) |
| 結果 | 同じ大きさの枠が並び、どれが答えか分からない | 主な結果を1つ、上に大きく出す(build.js の toolMain。なければ最初の結果) |
| 結果(スマホ) | 1列で縦に長い | 2列。表は余白を詰め、行の見出しを折り返して数値の列を画面に入れる |
| 入力中の結果(スマホ) | 結果が画面の外で、値を変えても見えない | 主な結果が見えない間、画面の上に結果のバーを出す(押すと結果へ移動)。キーボードが出ているときも見える範囲で判定する |
| 結果が変わったとき | 何も起きない | 主な結果の枠が短く光る(動きを減らす設定では光らない) |
| コピー・共有のボタン | ページの上(ツールの前) | 結果の枠の下 |
| 解説 | 幅760pxで中央。ツール(幅1008px)と幅がずれる | PC は左に本文、右に目次(スクロールしても残る) |

- 単位として扱うのは、短く、単位の記号だけでできているカッコ(丸カッコ・角カッコ)。「0でなし」「最大」などの注記はラベルに残す(build.js の isUnit)
- 図や表を直接操作するツール(カルノー図、状態機械、論理回路、問題セット)は1列のままで、リセットは付けない

## 数式と単位(2026-11-11)

運営者の指摘(数式や単位が見にくい)を受けて、本文の数式と単位を共通の処理で整える。原稿(data/ の文章)は変えず、ビルド時に HTML を、クイズ画面では表示のたびに DOM を整える(src/js/mathify.js。テスト tools/tests/mathify.test.mjs)。

| 項目 | 前 | 後 |
|---|---|---|
| 添字 | VGS、Vth、μnCox、gm が平文 | V_GS、V_th、μ_n C_ox、g_m のように下付き(`<sub>`) |
| 数値と単位 | 「0.5 V」「200 µA/V²」「0.05 /V」が行の途中で切れる | 間を行が切れないスペースにする |
| 値の代入 | 「VGS」と「= 1.5 V」が別の行になる | 「V_GS = 1.5 V」は1つのかたまり |
| 長い式 | どこででも折り返す | 「=」の前でだけ折り返す。演算子(−、+、×、·)の前後では切らない |
| ギリシャ文字・演算子 | 日本語の書体の全角幅で描かれ、間延びする | λ・μ・Ω・×・−・≈ などだけ、端末の欧文の書体で描く(CSS の @font-face と unicode-range。書体は読み込まない) |

- 添字にするのは、意味が1つに決まる記号(V_GS、V_th、g_m、C_ox、μ_n、φ_F、θ_JA など)。IC・ID・NA・R1 など、ほかの意味もある語は、式の中にあり、同じ段落にデバイスの記号があるときだけ変える(「このIC」「ユーザーID」「開口数 NA」は変えない)
- タグの属性、script、pre、code、入力欄、選択肢(option)の中は変えない
- ページの更新日は整形前の本文で判定する(整形の変更だけで更新日が変わらない)
- 同時に直した不具合: PN接合・MOSFET のページで、式の中の NA(アクセプタ濃度)が用語「開口数(NA)」にリンクされていた。用語の linkOnlyIn を露光・計測・光の分野に限った

## 教科書のような組み方の式(2026-11-11)

運営者の依頼(÷ や √ を教科書のように書き直す)。本文の1行書きの式(例: DPW ≈ πr²/S − πd/√(2S))を、分数を上下に重ね、根号を中身の上に伸ばした形で、1行を使って中央に出す。

- 表示はブラウザの標準の数式表示(MathML)。外部のライブラリや書体のファイルは使わない。書体は端末の数式用の書体(iPhone・Mac は STIX Two Math、Windows は Cambria Math)を指定
- 対象の式は data/math.json に挙げたものだけ(180本)。本文に同じ文字列があれば、どの言語でも置き換わる。原稿は変えない
- 1行書きから MathML への変換は tools/mathml.js。読み方の決まり: 並べて書いた積は割り算より強い(Eg/2kT = Eg/(2kT))、「·」でつないだ積は分子に入る、スペースで囲んだ「×」は分数どうしの積
- あいまいな記号は式ごとに指定する(開口数の NA は名前、fT・rπ・コレクタ抵抗の RC は添字)。微分の式、単位つきの値(0.05 /V)、数値の計算例は対象にしない
- 置き換えるのは、用語の解説・計算ツールの解説・よくある質問の答え。クイズ画面と問題の解説は1行書き(添字つき)のまま
- 式を足すときは、変換結果を画面で確かめてから data/math.json に足す(テスト tools/tests/mathml.test.mjs が、表の式がすべて変換でき本文にあることを確かめる)
