# 品質改善の進み具合(区画の一覧・着手順・状態)

運営者の指示(2026-11-02)による品質改善の台帳です。毎回ここと [next.md](next.md) から再開します。
状態の言葉は [standards.md](standards.md) の定義どおりに使います(未確認・確認済み・修正済み・検証済み)。

## 進め方の要点

- サイトを「区画」(分野 × ページの種類)に分け、1区画ずつ「確認 → 修正 → 検証 → 記録」まで終えてから次へ進む。1区画を終えたら報告して止まり、運営者の「次へ」を待つ
- 全ページ共通のテンプレート・CSS・生成処理の不具合は、区画をまたいで先に直してよい(種類ごとに表示を確かめる)
- 記録の置き場所: 指示では `docs/quality/` でしたが、このリポジトリの `docs/` はビルドの出力先で、ビルドのたびに消えて git にも入らないため、リポジトリ直下の `quality/` に置きます(画像の依頼は `quality/images/requests.md`)

## 区画の決め方(指示の目安からの調整)

- **用語解説**: 分野ごとの用語ページ(日本語で9〜25語)に、同じ分野の比較ページ(0〜5本)を加えて1区画にする。比較ページも用語ページと同じく検索から入る参照用のページなので、同じ分野の用語と一緒に確かめる。日本語・英語・繁体字が対象(ほかの言語は誤りの修正だけ反映)
- **問題**: 分野ごと(ほぼ50問)を1区画にする
- **計算ツール**: 64本をテーマで5本ずつ13区画にまとめる(下の表)
- **やさしい解説(記事)**: 111本(日本語)をシリーズで5区画にまとめる(下の表)
