### mosfet-001 [P2 / factual / 確度 medium] ja・explanation
> ゲートが浮いても電流が流れにくく(ノーマリーオフ)

- 問題: ノーマリーオフは VGS = 0 V でオフという意味です。ゲートが浮いた状態とは違います。浮いたゲートは誘導や静電気で帯電し、オンすることがあります。そのため、浮いても安全と誤解させるおそれがあります。
- 案: 「VGS = 0 V ではチャネルがなくオフ(ノーマリーオフ)なので、制御信号が0 Vのときに電流が流れず、論理回路やパワー用途の安全性に向きます。」とし、ゲートが浮いた場合の記述を削る(各言語も同様)。

### physics-037 [P2 / calculation / 確度 medium] all・explanation
> 抵抗率は約2〜3×10⁵ Ω·cm と大きくなります

### physics-050 [P2 / missing-condition / 確度 medium] all・explanation
> シリコンでは中央より約0.01 eV価電子帯側にずれます

- 問題: ずれの量は (kT/2)·ln(Nv/Nc) で決まるので、温度によって変わります。また Nc・Nv にどの値を使うかでも変わり、検算すると約0.001〜0.013 eV でした。解説には温度の条件が書かれていません。
- 案: 「室温(300 K)のシリコンでは、中央より約0.01 eV(Nc・Nvの採用値により0.01 eV程度以下)価電子帯側にずれます」のように、温度の条件と目安であることを書き添える。訳にも同じ修正を反映する。
