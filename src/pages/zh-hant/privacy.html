隱私權政策

{{siteName}}（以下稱「本站」）依下列方式處理使用者的資訊。

個人資訊

本站沒有會員註冊功能，瀏覽或作答時不會收集姓名、電子郵件地址等個人資訊。

儲存在瀏覽器中的資料

本站會將您的作答紀錄（答對或答錯、作答時間，以及作答歷程）與您選擇的顯示語言等設定，儲存在瀏覽器的 localStorage 中。這些資料只留在您的裝置上，不會傳送到本站的伺服器。您可以使用成績頁面上的重設按鈕，或清除瀏覽器的網站資料來刪除。

Cookie

Cookie 是網站儲存在瀏覽器中的小型資料。本站本身不使用 Cookie，但下述的廣告服務與流量分析工具會使用 Cookie。您可以在瀏覽器設定中停用或刪除 Cookie。停用後仍可作答本站的題目，但顯示的廣告等可能會有所不同。

傳送給第三方的資訊

當您開啟本站的頁面時，您的資訊可能會傳送給下列業者。

  • Google AdSense（Google LLC）：您瀏覽頁面的 URL、IP 位址、瀏覽器類型、Cookie 識別碼等，用於投放廣告及衡量廣告成效。（Google 隱私權政策）
  • Google Analytics（Google LLC）：您瀏覽頁面的 URL、來源網頁、瀏覽器與裝置類型、大致所在地區、Cookie 識別碼等，用於了解並改善本站的使用情形。

此外，當您開啟聯絡表單或外部網站的連結時，資訊會依該服務本身的條款傳送給該服務。

聯絡表單

詢問時使用外部服務（Google 表單）。您輸入的資訊僅用於回覆及改善本站，除法律要求外，不會提供給第三方。

主機代管

本站架設於 GitHub Pages。存取時的 IP 位址等資訊，由 GitHub 依其自身政策處理。

修訂

本政策可能在必要時修訂。修訂後的政策自刊登於本頁時起生效。若本繁體中文版與日文版內容有出入，以日文版為準。關於本政策的問題，請透過聯絡我們頁面提出。
