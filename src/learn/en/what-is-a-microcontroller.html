A microcontroller (MCU) is a small computer built on a single chip. It holds a circuit that runs instructions, memory that stores the program, and circuits that talk to other devices. It handles the "control" in rice cookers, remote controls and car brakes. It keeps repeating three steps: read a sensor, decide, and drive something such as a motor.

In everyday life

Press the button on a rice cooker. It adjusts the heat to the amount of rice, then switches to keep-warm when the rice is done. The part making these decisions inside the machine is a microcontroller.

Japan offers an early example. A Japanese government magazine (2020) says rice cookers that use a microcontroller to adjust heating to the amount of rice appeared in 1979. Today, microcontrollers are in many electric products, from water heaters to toys. Some cars carry more than 100 of them.

"Microcontroller" is often shortened to MCU, which stands for microcontroller unit.

A complete small computer on one chip

A computer needs a circuit that runs instructions, memory for programs and data, and ports to talk to the outside. In a PC, many of these are separate parts. A microcontroller puts all of them on one chip.

At the center is a circuit that fetches instructions one at a time and runs them. It does the same job as a PC's CPU. This part is called the "CPU core."

In most microcontrollers, the program is stored on the chip in memory that keeps its contents when the power is off. This type of memory is called flash memory. It belongs to the same family as a USB stick, though the details differ. When the power comes on, the CPU core starts reading instructions from it right away.

Measured temperatures and numbers in the middle of a calculation go into working memory. Microcontrollers usually use a type called SRAM. It is fast to read and write, and it loses its contents when the power is off. Depending on the model, it ranges from under 1 KB to a few MB. 1 KB holds about 1,000 letters or digits of plain text.

Peripherals: the link to the outside world

What makes a microcontroller special is its set of circuits for dealing with the outside world. Together they are called "peripherals." The main ones are:

  • Input/output pins: They read or set the voltage on the chip's legs (pins) as a 0 or a 1. Uses include reading a button or turning on an LED. These are called {{term:GPIO|GPIO}}.
  • A circuit that turns analog into numbers: A temperature sensor puts out a voltage that changes smoothly with temperature. This circuit turns that continuous value into a number. It is called an ADC (analog-to-digital converter).
  • Timers: They measure time by counting a steady stream of ticks (the clock).
  • A circuit that sets strength by switching on and off: It switches an output on and off very fast. The share of time it stays on sets the average strength. It is used to dim LEDs and set motor speed. It is called {{term:PWM(パルス幅変調)|PWM}}.
  • Communication circuits: They exchange data with other chips by fixed rules. Common methods are UART, I²C and SPI. A table of the differences is in "I2C vs SPI vs UART."

Some models also have radio circuits. Because peripherals come in so many combinations, there are a huge number of models.

How it differs from a PC or smartphone processor

The main chip in a PC or smartphone also has a CPU. But it is built to run many apps fast. Its working memory (DRAM) is a separate chip that can hold several GB. It also runs a large operating system (OS), such as Windows or Android, that manages the whole machine.

To tell them apart from microcontrollers, these chips are called microprocessors (MPUs). "What Chips Are Inside a Smartphone?" shows what is inside a phone's main chip (SoC). A microcontroller instead puts its priority on doing a fixed job cheaply, on little power, and reliably.

How it works: read, decide, act, repeat

Most microcontroller programs repeat the same loop of steps. Let's look at a rice cooker, kept very simple.

  1. Read: read the temperature sensor's voltage as a number, using the ADC
  2. Decide: compare that number with the target temperature
  3. Act: if it is too low, power the heater; if too high, switch it off

The chip repeats these three steps at short intervals, over and over. The measurement sets the next action, and the result is measured again. This keeps the temperature close to the target. Adjusting while watching the result like this is called {{term:フィードバック制御|feedback control}}. A real rice cooker changes its target by stage, such as soaking, boiling and steaming. Interrupts: answering urgent signals right away

One option is to check the button on every pass of the loop. But if the checks are far apart, the response is slow, or a short press is missed.

So a microcontroller has a way to pause its current work when a signal arrives. It first runs a task prepared in advance. When that is done, it goes back to where it stopped. This mechanism is called an {{term:割り込み|interrupt}}. Signals can come from a button pin, a timer or a communication circuit.

An interrupt can also wake a sleeping microcontroller. Checking every time instead is called polling. A table of the differences is in "Interrupt vs Polling."

An analogy

An interrupt is like the doorbell ringing while you cook. You turn off the stove and go to the door. After you take the package, you return to the kitchen and carry on. What is similar: when a signal comes, you pause your current work, and when you are done, you pick up where you left off.

Where the analogy breaks down: When the bell rings, a person decides on the spot whether to answer now or later. A microcontroller decides nothing. The program sets in advance which signals come first, and the chip simply follows it. Also, the circuit and program record the stopping point and resume in a fixed, exact way. The chip never wonders "where was I?"

Always meeting the deadline

In some microcontroller jobs, "always finishing by a set time" matters more than speed. A car's airbag is an example. It is useless unless it opens within a very short time after the sensor detects a crash.

A strict timing rule like this, where missing the deadline even once is a failure, is called {{term:ハードリアルタイム|hard real-time}}. A microcontroller suits it well. Its work is small and simple, so what happens inside is easy to predict. A PC's priority is running many apps fairly, so it is poor at guaranteeing exact timing.

Microcontrollers with and without an OS

On a PC, the OS switches between apps and manages memory ("What Is an Operating System?"). On a microcontroller, programs are often built with no OS, using only the loop and interrupts shown above. This is called "bare metal," meaning the program runs directly on the hardware.

When the work grows too large for one loop, a small OS is used. It is built mainly to meet deadlines. It is called an {{term:RTOS(リアルタイムOS)|RTOS}} (real-time operating system). It gives each task a priority and switches quickly when an urgent one arrives.

Years on a battery: asleep most of the time

An air conditioner remote can go a long time without new batteries. The microcontroller inside only has work when a button is pressed. The rest of the time, it sleeps and waits.

With no work to do, the microcontroller stops the clock signal and power to the CPU core and many other circuits. It then waits on a tiny amount of power. This state is called {{term:スリープモード|sleep mode}}. A button press triggers an interrupt that wakes it. It sends the signal, then goes back to sleep.

8-bit, 16-bit and 32-bit

Microcontroller descriptions often say "8-bit" or "32-bit." Roughly, this is how many binary digits (0s and 1s) the CPU core handles in one calculation. An 8-bit core handles numbers from 0 to 255 at once, and a 32-bit core up to about 4.3 billion. This is a simplified picture; the amount of memory it can address also plays a part. ("How Do Computers Use Binary?" explains how 0s and 1s stand for numbers.)

More bits make it easier to work with large numbers and lots of memory. On the other hand, 8-bit microcontrollers have small circuits and are still used for simple jobs. The Arduino Uno (R3), a popular hobby board, uses the 8-bit ATmega328P.

By sales, though, 32-bit leads. In 2021, the research firm IC Insights forecast that 32-bit chips would take about 77% of that year's automotive microcontroller sales. 16-bit would take about 18%, and 8-bit about 6%.

A common CPU core design in 32-bit microcontrollers is the "Cortex-M" series from Arm, a UK company. Arm licenses the design, and chipmakers build it into their own microcontrollers. Arm reported that 4.4 billion Cortex-M chips shipped in the three months from October to December 2020.

Microcontrollers in cars

In a car, small control units handle jobs such as the engine, brakes, power windows and airbags. Each one is called an {{term:ECU(電子制御ユニット)|ECU}} (electronic control unit). An ECU is a circuit board carrying a microcontroller and the circuits that connect it to sensors and motors.

A 2021 article in the tech magazine IEEE Spectrum says even low-end cars have close to 100 ECUs. Some luxury cars have 150 or more.

A car's microcontrollers face engine heat, winter cold and vibration for many years. So cars use parts proven to survive a set of standard tests. A leading test standard is {{term:AEC-Q100|AEC-Q100}}, set by the US Automotive Electronics Council (AEC).

Why aren't they made in the newest factories?

A smartphone SoC is made on a leading-edge process generation such as "3 nm." Most microcontrollers, in contrast, are made on proven generations several steps older. A 2022 analysis by McKinsey found that most automotive chips are made at 90 nm or older. "What Does 2nm or 3nm Mean?" explains these generation names.

One reason is the flash memory that holds the program. Flash uses high voltages to write and erase. The transistors that handle those voltages do not shrink at the same rate as each generation advances. Extra process steps also drive up the cost. According to the research firm Yole (2024), the industry broadly agrees that the limit is around 28 to 22 nm.

In 2018, Renesas began shipping samples of an automotive microcontroller with built-in flash at 28 nm, which it called an industry first. To go further, some companies are replacing flash with newer memory. In 2023, NXP and TSMC announced they would make {{term:MRAM|MRAM}}, a memory that uses magnetism, for cars at the 16 nm generation.

The other reason is cost. Microcontroller jobs rarely need leading-edge speed. What matters is making chips cheaply, at the same quality, for many years. Still, a shortage of factories for these generations was one reason car production stopped in 2020 to 2022 (see "What Caused the Global Chip Shortage?").

How do you write a program for one?

Microcontroller programs are usually written in a language people can read and write easily, such as C. A PC then converts it into the 0s and 1s the CPU core can run (machine code). The machine code is written into the microcontroller's flash, for example over a USB cable.

A program built into a device like this, and not normally changed, is called firmware.

Anyone can try microcontrollers at home. In January 2021, Raspberry Pi released the $4 "Raspberry Pi Pico" board. It carries the company's own RP2040 microcontroller, which has two Cortex-M CPU cores.

But the RP2040 has no built-in flash. The program sits in a separate flash chip on the board. "Built-in flash" is true of most models, but there are exceptions. Note that a plain "Raspberry Pi," without "Pico," is a small computer that runs Linux, not a microcontroller.

Common misconceptions

Myth: A microcontroller is just a slow, low-end CPU

In fact, it aims at different goals. A microcontroller's priorities are meeting deadlines, using little power, and talking directly to outside devices. A PC CPU in a rice cooker would cost far too much and use far too much power. The myth arises because, judged by clock speed alone, a microcontroller looks slow, like a "cheap CPU."

Myth: Only expensive products like PCs and phones contain computers

In fact, rice cookers, remote controls and toys have them too. One of the first microcontrollers, the TMS1000 (announced in 1974), cost about $2 each in large volumes (Computer History Museum, US). These devices have no screen or keyboard, so it is just hard to notice the computer inside.

Myth: Microcontrollers always run an OS too

In fact, as shown above, many microcontrollers run with no OS. Large operating systems like Windows or Linux need far too much memory to fit on a typical microcontroller. Because PCs and phones always have an OS, people assume microcontrollers do too.
