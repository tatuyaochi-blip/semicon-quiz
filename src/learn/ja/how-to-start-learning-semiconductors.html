半導体を一から学ぶなら、次の順がおすすめです。①半導体とトランジスタ(土台)→②チップの作り方→③製品の中での働き→④業界とニュース。前の段階で覚えた言葉を、次の段階の説明で使うからです。このページでは、サイトのやさしい解説を読む順に並べ、それぞれ何が説明できるようになるかを紹介します。

この記事でわかること

  • 半導体の学び方の全体の地図(4つの段階)
  • 段階ごとに読む記事と、その順番にした理由
  • 目的に合わせた近道(ニュース・仕事・試験)
  • 学び始めにつまずきやすい思い込み

前提知識: ありません。中学の理科で習う電流・電圧を、なんとなく覚えていれば十分です。

身近なところでは

ニュースでは「2nm」「ファウンドリ」「HBM」のような言葉が、説明なしに次々と出てきます。半導体の会社に入ると、会議で「前工程」「歩留まり」が当たり前のように使われます。一つ調べると、その説明に別の知らない言葉が出てきて、なかなか先へ進めません。

こうなるのは、半導体の言葉どうしに「先に知っておくべき順番」があるからです。例えば「2nm」を理解するには、トランジスタというスイッチと、回路を光で写す工程を先に知っている必要があります。順番どおりに読めば、一つひとつの説明が前の知識の上にすっと乗ります。このページは、その順番の案内です。

全体の地図: 4つの段階

このページでは、半導体の学び方を次の4つの段階に分けました。番号の順に読むと、前の段階で覚えた言葉を土台にして、次の段階が読みやすくなるように並べました。各段階の中も、上から順に読むのがおすすめです。

ここでは話を簡単にするため、一本の道として並べています。実際には、知りたいことから読み始めてもかまいません。各記事の冒頭には「前提知識」を一言で書いてあるので、足りないと感じたら、そこに挙がった記事へ戻ってください。

各段階の記事は、「まず読む」と「続けて読む」に分けました。「まず読む」だけで、その段階の要点はつかめます。「続けて読む」は、興味のあるものから選んで読む記事です。

ステップ1: 半導体と小さなスイッチ(土台)

最初の段階では、半導体という材料から、計算をするチップまでを一続きで見ます。ここが、ほかのすべての段階の土台です。読み終えると、「なぜシリコンの小さなかけらで計算ができるのか」を自分の言葉で説明できます。

まず読む

  1. 半導体とは? 電気の通しやすさを、混ぜ物や電圧で大きく変えられる材料の話です。シリコンが選ばれる理由もわかります。
  2. トランジスタとは? 電気の信号で電流をオン・オフする、小さなスイッチです。半導体の性質がどうスイッチになるのかがわかります。
  3. コンピュータは0と1でどう計算するの? 電圧の高い・低いを1と0に見立てて、数を表すしくみです。スイッチの組み合わせで足し算ができる理由がわかります。
  4. 論理ゲートとは? 0と1を入れると、決まった規則で0か1を返す小さな回路です。計算の回路の部品が、トランジスタでどう作られるかがわかります。
  5. 集積回路(IC)とは? たくさんの部品と配線を、1つのシリコンのかけらにまとめたものです。ニュースの「チップ」が何を指すのかを、ここで押さえます。

続けて読む

  • ダイオードとは? 電流を一方向にだけ流す部品です。LEDや太陽電池のしくみにもつながります。
  • CMOSとは? 正反対の動きをする2種類のトランジスタを組にする方式です。チップの電力を節約するしくみがわかります。

ステップ2: チップの作り方

次は、そのチップを工場でどう作るかです。作り方を知ると、ニュースの「工場」や「製造装置」が何の話かがわかります。読み終えると、「円い板の上で、膜をつけ・模様を写し・削る作業をくり返す」という流れを説明できます。

まず読む

  1. 半導体チップはどうやって作られる? 最初に全体の流れを見ます。円い板(ウエハ)の上で数百個のチップを同時に作り、切り分けて包むまでの地図です。
  2. 成膜とは? 板の表面に、ごく薄い膜をつける工程です。
  3. フォトリソグラフィとは? 光を使って、回路の模様を膜の上に写す工程です。
  4. エッチングとは? 写した模様のとおりに、膜のいらない部分を取り除く工程です。この3つの工程をくり返して、回路が何層にも積み上がります。

続けて読む

  • シリコンウエハとは? 土台になる円い板を、石から作るまでの話です。
  • クリーンルームとは? 工場がほこりをここまで嫌う理由です。
  • イオン注入とは? 混ぜ物を板に打ち込む工程です。「半導体とは?」で出てくるn型・p型の部分を、決まった場所に作ります。
  • CMPとは? 次の層を重ねる前に、表面を平らに磨く工程です。
  • 半導体の検査・テストとは? 不良のチップを見つけて、出荷の前に取り除く工程です。
  • 半導体パッケージとは? チップを包んで守り、機器の板とつなぐ入れ物と、その作り方です。
  • 半導体製造装置とは? 工程ごとの機械の種類と、それを作る会社の話です。

ステップ3: 製品の中での働き

3つ目は、作ったチップが製品の中で何をしているかです。チップには種類があり、計算する・覚える・電力の形を変える、などの仕事を分け合っています。読み終えると、スマホの仕様表や電気自動車の記事に出てくるチップの役割を説明できます。

まず読む

  1. CPUとは? プログラムの命令を1つずつ取り出し、計算や比較をくり返す部品です。仕様表の「コア数」の意味もわかります。
  2. メモリとストレージの違いは? 作業中のデータを置く場所と、写真やアプリをしまう場所の違いです。「8GB」と「256GB」が何の数字かがわかります。
  3. なぜAIにGPUが使われるの? 単純な計算を大量に同時に進めるチップが、AIに向く理由です。ニュースの「AI半導体」が読めるようになります。
  4. パワー半導体とは? 電気の形を変えたり、モーターの速さを調整したりする部品です。計算をするチップとは別の、もう一つの大きな分野です。
  5. スマホの中にはどんな半導体が入っている? ここまでのチップが、1台のスマホの中でどう分担しているかをまとめて見ます。

続けて読む

  • DRAMとは? と SSDとは? メモリとストレージの中身を、もう一段くわしく見ます。
  • イメージセンサとは? スマホのカメラが、光を電気に変えるしくみです。
  • 電気自動車(EV)にはどんな半導体が入っている? パワー半導体が主役になる製品の例です。
  • マイコンとは? 炊飯器や車を動かす、小さなコンピュータです。
  • アナログ半導体とは? 音や温度のように、なめらかに変わる信号を扱うチップです。

ステップ4: 業界とニュース

最後は、半導体のニュースを読むための段階です。ここまでの3段階を知っていると、会社の名前や数字の意味が読み取れます。読み終えると、「なぜ半導体の工場が国の政策の話題になるのか」を、工程と分業から説明できます。

まず読む

  1. ファウンドリとは? チップを設計する会社と、注文を受けて作る会社に分かれた理由です。台湾のTSMCのような会社が、なぜニュースに出るのかがわかります。
  2. 半導体不足はなぜ起きた? 2020〜2022年に品不足が起きた理由です。工場をすぐには増やせない話が、ステップ2とつながります。
  3. ムーアの法則とは? チップに載るトランジスタの数が、およそ2年ごとに2倍になってきたという観察の話です。部品を小さくして詰め込む「微細化」の背景がわかります。
  4. 「2nm」「3nm」は何の長さ? この数字は技術の世代の名前で、チップのどこかの長さそのものではありません。ステップ1のトランジスタと、ステップ2の光で写す工程を知っていると読みやすい記事です。

続けて読む

  • EUV露光とは? 最先端のチップで、回路の模様を写すための特別な光の話です。
  • HBMとは? AI用のチップのすぐ隣に置く、積み重ねたメモリです。
  • チップレットとは? 大きなチップを小さく分けて作り、組み合わせる方法です。
  • 半導体業界にはどんな仕事がある? 設計から製造・販売まで、業界の職種を紹介します。

目的に合わせた近道

時間が限られている人は、目的に合わせて次の順で読むのも一つの方法です。どの近道も、最初の「半導体とは?」と「トランジスタとは?」は共通です。この2本が、ほかの記事の説明の前提になっているためです。

  • ニュースを読み解きたい人: 半導体 → トランジスタ → 集積回路 → ファウンドリ → 「2nm」の意味。
  • 半導体の会社に入った人: 半導体 → トランジスタ → チップの作り方 → 業界の仕事。職種ごとのくわしい紹介は職種ガイドにもあります。
  • ITパスポート・基本情報の受験者: 半導体 → トランジスタ → 0と1の計算 → 論理ゲート → CPU → メモリとストレージ → キャッシュメモリ。試験の出題範囲は、試験を行うIPA(情報処理推進機構)が公開している最新の資料で確かめてください。

たとえで言うと

知らない町を歩くとき、駅前の案内図で町全体を見てから目当ての店へ向かうと、迷いにくくなります。このページの4つの段階は、その案内図にあたります。似ているのは、全体の位置関係を先に知っておくと、細かい道に入っても自分がどこにいるかを見失わない点です。

たとえが当てはまらない点: 案内図は町のすべての道を載せていますが、この4つの段階は、このサイトの記事を並べたものです。半導体の分野のすべてを描いた地図ではありません。また、案内図は一度見れば役目を終えますが、学習では後の段階を読むと前の段階の理解が深まります。一度読んだ記事も、あとで読み直すと新しいつながりが見えてきます。

よくある誤解

誤解: 物理や数学をしっかり学んでからでないと、半導体は理解できない。

実際は、しくみのイメージは中学の理科くらいの知識でつかめます。このページの4つの段階の記事も、式はほとんど使わず、言葉と図で説明しています。式や理論が役立つのは、イメージをつかんだ後で「なぜそうなるのか」を確かめたくなったときです。そのときは、物理・化学・数学の基礎を技術の側から説明したシリーズへ進んでください。

誤解: ニュースによく出る最新の言葉から覚えるのが近道だ。

実際は、最新の言葉ほど、たくさんの土台の言葉の上に成り立っています。例えば「2nm」は、チップのどこかが2nmという意味ではありません。土台を知らずに数字だけ覚えると、こうした思い違いをしやすくなります。ニュースが目的の人も、ステップ1の5本を先に読んでおくと、ニュースの数字の読み違いを防げます。

誤解: 営業や事務の仕事なら、作り方は知らなくてよい。

工程の細かいところまで覚える必要はありません。ただ、納期が長い理由や値段が動く理由は、工場のしくみと結びついています。例えば、板の上で回路を作る工程(前工程)だけで、平均約12週間かかります。米国半導体工業会(SIA)の2021年の解説の数字です。こうした数字を知っていると、お客さまや社内への説明がしやすくなります。

数字で見る: どのくらいの時間がかかる?

このページで紹介した記事は、どれも10〜15分ほどで読める長さです。各記事の題の下に、読む時間の目安が出ています。各段階の「まず読む」は4〜5本なので、1日1本ずつなら1つの段階を1週間以内で読み終えられます。

4つの段階の「まず読む」をすべて読むと、1日1本ずつで3週間ほどです。これは読む速さの平均から出した数字ではなく、あくまで一つの目安です。わからない所で立ち止まったり、2回読んだりする時間は含めていません。
