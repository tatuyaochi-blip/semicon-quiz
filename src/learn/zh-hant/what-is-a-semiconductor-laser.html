半導體雷射和LED一樣，是靠電子與電洞相遇而發光的元件。不同的是，它把晶片兩端做成鏡子，讓光來回反射，再由光引出更多相同的光。因此光的顏色整齊，容易聚成細光束，在光纖網路和資料中心裡負責傳送資訊。

生活中的例子

半導體雷射，是從一小片半導體射出顏色整齊的光的元件，也叫做雷射二極體（LD）。二極體是只讓電流往一個方向順利流動的元件，半導體雷射也是其中一種。

2000年諾貝爾物理學獎的新聞稿，舉了幾個用途的例子：光纖網際網路、CD播放器、條碼掃描器和雷射筆。CD在1982年上市，用雷射光讀取碟片上細微的凹凸。DVD和藍光光碟也是同樣的原理。

手機裡也有。從2017年的iPhone X開始使用的臉部辨識（Face ID），會在臉上投射數千個看不見的紅外線光點。再從光點的排列，測量臉部的凹凸。這個光源，就是後面會介紹的VCSEL半導體雷射（Apple）。2020年的iPad Pro，則搭載了以光返回的時間測量距離的光達掃描儀（LiDAR）。

在看不見的地方，資料中心裡也大量使用。伺服器和網路設備之間，用光的線路連接。2022〜2023年發表的元件，用1道光每秒就能傳送100〜200 Gb（Gb是十億位元）。

雷射光有什麼特別

和LED的光相比，雷射光有3個特徵。

  • 顏色只有一種：波長（光波的長度）的範圍非常窄
  • 波的步調一致：波峰和波谷的位置，一直保持整齊地前進
  • 容易聚成細光束：可以用透鏡聚成很小的點，或做成平行光送到遠處

LED的光，顏色有一定範圍，而且往四面八方擴散。適合照亮房間，卻不擅長送進細細的玻璃線、傳到遠方。另外，半導體雷射的出光口非常小，所以光剛射出時也會擴散。因此要先用透鏡整理過再使用。兩者的差異，也可以在「LED與半導體雷射的差異」的表格中比較。

原理1：光引出光的「受激輻射」

出發點和LED相同。對兩種性質不同的半導體交界處（PN接面）通入電流。電子和電洞（電子的空位）就會相遇，相遇的能量變成光的粒子放出來。在LED裡，這種相遇在各自隨意的時間、往隨意的方向發生。這稱為自發輻射。

如果有一個能量剛好相同的光粒子，從即將和電洞相遇的電子旁邊經過，電子就會被帶動而放出光。新的光和經過的光顏色相同、方向相同、波的步調也相同。這稱為受激輻射，是愛因斯坦在1917年從理論上預言的。

受激輻射會讓1個光粒子變成2個。這2個再讓別的電子放光，就變成4個，接連增加。雷射（LASER）這個名字，也是英文「受激輻射造成的光放大」的字首縮寫。

原理2：要讓光增加，需要「居量反轉」

光粒子不只會讓電子放光。它碰到低能量的電子時會被吸收，用來把那個電子往上推。一般狀態下，低能量的電子多得多，所以光還沒增加就先被吸收掉了。

要讓光增加，能放光的高能量電子必須比低能量的多。這和一般狀態的排列相反，所以稱為居量反轉。半導體雷射用大電流把電子和電洞接連送進發光層，做出這種狀態。這裡為了簡化，省略了電子能量的細部分布。

原理3：用兩端的鏡子讓光來回反射

即使形成了居量反轉，光只通過晶片1次，增加的量也很少。所以在發光層兩端放上鏡子，讓光來回很多次。每來回一次光就增加，方向也越來越一致。這一組鏡子稱為共振腔。

在許多半導體雷射裡，鏡子並不是另外加上的零件。把晶體沿著特定方向劈開，就會得到順著原子排列的平整表面。這個劈開的面（劈裂面）直接就是鏡子。半導體和空氣讓光前進的方式差很多，所以在交界處約有3成的光會反射回去。

其餘約7成的光會穿過鏡子射到外面。這就是我們使用的雷射光。也有產品在其中一面加上增強反射的膜，讓光多從另一面射出。

用比喻來說

雷射開始發光的樣子，很像麥克風和喇叭的「回授嘯叫」。麥克風收到喇叭的聲音，放大後再播出，聲音就會一圈圈循環。繞一圈增加的量超過減少的量時，聲音會突然變成刺耳的單一「嗶——」聲。雷射也一樣，來回增加的光超過損失的光時，就會突然變成強烈、顏色整齊的光。

比喻的限制：回授嘯叫是用電路把聲音訊號放大的現象。雷射則是光粒子讓電子放出相同的光而增加，增加的原理不同。另外，雷射的顏色主要由材料決定，嘯叫的音高卻取決於房間和麥克風的位置。這個比喻只表達「增加的量超過損失的量，就會突然變強」這一點。

原理4：開始發出雷射光的電流「臨界電流」

把通入半導體雷射的電流從0慢慢增加，一開始只會像LED一樣微弱地發光。因為來回途中損失的光，比增加的光還多。光會從鏡子射到外面，或在晶體裡被吸收而損失。

電流超過某個值後，增加的量就超過損失的量，整齊的光突然變強。這個分界的電流稱為臨界電流。超過之後，電流增加多少，光就跟著變強多少。

臨界電流會隨溫度改變，變熱就會升高。光的顏色也會稍微偏移。所以通訊用的雷射，有時會搭配讓溫度保持固定的元件。

兩種形式：邊射型與VCSEL

像前面的圖那樣，從橫向細長晶片的端面射出光的形式，稱為邊射型。發光層很長，容易發出強光，一直用在光纖的長距離通訊和光碟上。

另一種，是從製造晶片用的圓形薄板（晶圓）表面垂直射出光的{{term:VCSEL(垂直共振器面発光レーザー)|垂直共振腔面射型雷射（VCSEL）}}，也簡稱面射型雷射。它在發光層上下做出由數十層薄膜疊成的鏡子，讓光在垂直方向來回。

顏色由材料決定

雷射的顏色（波長）和LED一樣，由電子掉落時的能量高低差（能隙）決定。高低差由材料決定，越大，光的波長就越短。使用的是像砷化鎵這樣，由2種以上元素組合成的半導體。其中多半是週期表第13族與第15族元素的組合，稱為{{term:III-V族化合物半導体|III-V族化合物半導體}}。下表的材料名稱只列出主要的系列。

波長越短，越能把光聚成小點。從CD到DVD、再到藍光光碟，每次縮短波長，同樣大小的碟片就能存更多資料。

光纖使用1310 nm和1550 nm的原因

光纖是讓光通過像頭髮一樣細的玻璃線的纜線（「網際網路怎麼傳送資料？」）。玻璃並不是對每種顏色的光都一樣容易通過。光減弱的比例隨波長而變，在1550 nm附近最小。

在標準的光纖裡，1550 nm的光每1 km減弱約0.2分貝。大廠產品的上限值，約為每1 km 0.18〜0.22分貝（2024年時）。分貝是表示「變成幾分之一」的刻度，0.2分貝約減少5%。即使前進100 km，也還剩下約1%的光（「分貝（dB）是什麼？」）。

1310 nm附近，是光在光纖中前進的速度幾乎不隨波長改變的地方。雷射光的顏色也有一點點範圍，所以在其他波長，光閃爍的形狀會一點一點走樣。1310 nm不容易走樣，所以常用在資料中心內部，以及10 km左右以內的通訊。

這兩個波長範圍，稱為{{term:Oバンド|O波段}}（1310 nm附近）和{{term:Cバンド|C波段}}（1550 nm附近）。兩者的光，都能用做在InP基板上的半導體雷射有效率地發出。

讓光快速閃爍來傳送資訊

光通訊把光的強弱對應到0和1來傳送資訊。半導體雷射只要改變電流，光的強度馬上就會跟著變。所以VCSEL等雷射，會用直接以電流讓光閃爍的方法。

要傳得更快時，就讓雷射保持點亮，再用放在正前方的「光的快門」讓光閃爍。也會把光的強度分成4個等級，閃爍1次傳送2位元。2022年，Coherent公司發表了把雷射和快門整合在同一片晶片上的元件。1道光每秒可傳送200 Gb。這裡寫成「快門」是簡化的說法，實際上是用電壓改變光被吸收程度的部分。

為什麼很難用矽做雷射

電腦和手機的晶片是用矽做的。但矽是{{term:間接遷移型|間接能隙}}半導體，電子和電洞相遇幾乎不會變成光。大部分的能量都變成了熱。原因可以在「直接能隙與間接能隙的差異」中比較。

另一方面，矽幾乎不吸收1310 nm和1550 nm的光，能讓它順利通過。因此，在矽晶片上做出光學元件的{{term:シリコンフォトニクス|矽光子}}越來越普及。例如光的通道、快門，以及受光部（把光變成電的部分）。只有光源，要貼合InP等材料的雷射，或從別的元件把光送進來補足。

安全等級的分類

雷射光又細又強地前進，進入眼睛可能傷害視網膜。所以國際標準IEC 60825-1，依危險程度把雷射產品分成不同等級。以日本為例，對應的國家標準是JIS C 6802。

  • Class 1：正常使用下是安全的。例如iPhone 15 Pro就屬於這個等級（Apple）
  • Class 2：看得見的光，輸出在1 mW（毫瓦）以下。強光會讓人反射性閉眼，靠這個反應保護眼睛的程度
  • Class 3R、3B：直視可能傷害眼睛
  • Class 4：連散射的反射光都危險，也可能造成燙傷或火災

此外，還有只在用放大鏡或望遠鏡觀看時才危險的1M、2M。以日本為例，雷射筆是法律特別管理的產品，符合標準的產品會貼上PSC標章（日本國民生活中心）。紅外線雷射看不見，無法靠刺眼感察覺危險，這一點也要注意。

半導體雷射的發展

1962年秋，美國的4個團隊各自獨立做出了半導體雷射。分別是奇異公司的2個研究單位、IBM和MIT林肯實驗室。多數使用砷化鎵，奇異公司的何倫亞克等人做出了看得見的紅光。不過，當時必須用液態氮（約−196 °C）等冷卻，而且只能在極短的時間內通電。

要在室溫下持續發光，需要能用較少電流做出居量反轉的設計。答案是用能隙更大的其他半導體，從上下夾住發光層。電子、電洞和光都會集中在中間那一層。這稱為雙異質結構（「異質」是「不同」的意思）。

1970年，蘇聯的阿爾費羅夫（Zhores Alferov）等人，和美國貝爾實驗室的林嚴雄、帕尼許（Morton Panish），幾乎同時做出了在室溫下持續發光的雷射。阿爾費羅夫等人的報告稍早一些，林嚴雄等人也在同年6月確認成功。這種結構，是阿爾費羅夫等人與克勒默（Herbert Kroemer）在1963年分別提出的。兩人以這類「異質結構」的研究，獲得2000年諾貝爾物理學獎（另一半獎項頒給積體電路的基爾比）。

常見的誤解

誤解：雷射光是紅色或綠色等看得見的光

實際上，多數半導體雷射發出的是紅外線，肉眼看不見。臉部辨識的光點，以及光纖的1310 nm、1550 nm的光，都是紅外線。因為常見的雷射筆是紅色或綠色，人們很容易以為雷射是看得見的。

誤解：對LED通入大電流，就會變成雷射

實際上，如果沒有讓光來回反射的共振腔，光幾乎不會因受激輻射而整齊地增加。LED只會變亮，顏色範圍和擴散方式都不會改變。兩者都靠PN接面發光，所以很容易被看成只是亮度不同。

誤解：矽完全無法處理光

實際上，矽能讓通訊用的紅外線順利通過，可以在晶片上做出光的通道、光的快門和受光部。它不擅長的是「發光」。所以矽光子只把光源交給化合物半導體負責。
