生活中的例子

新聞裡常常一個接一個出現「2奈米」「晶圓代工廠」「HBM（高頻寬記憶體）」這類詞，卻沒有說明。進了半導體公司，開會時大家也理所當然地說「前段製程」「良率」。查了一個詞，說明裡又冒出另一個不認識的詞，很難往下讀。

會這樣，是因為半導體的詞語之間有「應該先知道哪個」的順序。例如要理解「2奈米」，得先知道兩件事。一是叫作電晶體的開關，二是用光把電路轉印上去的製程。照順序讀，每個說明都能順利接在先前的知識上。本頁就是這個順序的導覽。

整體地圖：4個階段

本頁把學習半導體分成下面4個階段。依編號順序閱讀時，前一階段學到的詞語會成為基礎，讓下一階段更容易讀懂。每個階段裡的文章，也建議從上往下依序閱讀。

為了讓說明簡單，這裡把它排成一條路。實際上，從想知道的地方開始讀也沒關係。每篇文章開頭都用一句話寫了「先備知識」。覺得不夠時，請回到那裡列出的文章。

各階段的文章分成「先讀」和「接著讀」。只讀「先讀」，就能掌握該階段的重點。「接著讀」則是依興趣挑選來讀的文章。

步驟1：半導體與小小的開關（基礎）

第一個階段，從半導體這種材料一路看到會計算的晶片。這裡是其他所有階段的基礎。讀完後，你能用自己的話說明：「為什麼一小片矽就能計算？」

先讀

  1. 半導體是什麼？ 介紹一種材料：它的導電性，可以靠摻入雜質或施加電壓大幅改變。也會了解為什麼選用矽。
  2. 電晶體是什麼？ 用電訊號讓電流導通或切斷的小開關。可以了解半導體的性質怎麼變成開關。
  3. 電腦怎麼用0和1計算？ 把電壓的高、低當成1和0來表示數字的原理。可以了解為什麼組合開關就能做加法。
  4. 邏輯閘是什麼？ 輸入0和1，就依固定規則輸出0或1的小電路。可以了解計算電路的零件怎麼用電晶體做出來。
  5. 積體電路（IC）是什麼？ 把大量零件和配線集中在一小片矽上的東西。新聞裡的「晶片」指的是什麼，要在這裡弄清楚。

接著讀

  • 二極體是什麼？ 只讓電流往一個方向流的零件。也和LED、太陽能電池的原理有關。
  • CMOS是什麼？ 把動作正好相反的2種電晶體配成一組的方式。可以了解晶片節省電力的原理。

步驟2：晶片的製造方法

接下來是晶片在工廠裡怎麼製造。了解製造方法後，就能明白新聞裡的「工廠」「製造設備」在說什麼。讀完後，你能說明這個流程：在圓形的板子上，反覆進行沉積薄膜、轉印圖案、削去多餘部分的作業。

先讀

  1. 半導體晶片是怎麼做出來的？ 先看整體流程。這是一張地圖：在圓形的板子（晶圓）上同時做出數百顆晶片，再切開、包裝。
  2. 薄膜沉積是什麼？ 在晶圓表面加上一層極薄薄膜的製程。
  3. 微影是什麼？ 用光把電路圖案轉印到薄膜上的製程。
  4. 蝕刻是什麼？ 依照轉印的圖案，去除薄膜不需要部分的製程。反覆進行這3個製程，電路就會一層層疊起來。

接著讀

  • 矽晶圓是什麼？ 作為基底的圓形板子，怎麼從石頭做出來。
  • 無塵室是什麼？ 工廠為什麼這麼怕灰塵。
  • 離子佈植是什麼？ 把雜質打進晶圓的製程。它會在指定的位置，做出「半導體是什麼？」裡介紹的n型、p型區域。
  • CMP（化學機械研磨）是什麼？ 疊上下一層之前，把表面磨平的製程。
  • 半導體測試是什麼？ 找出不良晶片，在出貨前剔除的製程。
  • 半導體封裝是什麼？ 包住晶片加以保護、並連接到機器電路板的外殼，以及它的製作方法。
  • 半導體設備是什麼？ 各製程使用的機台種類，以及製造這些機台的公司。

步驟3：晶片在產品中的作用

第三個階段，是做好的晶片在產品裡做什麼。晶片有很多種類，分擔計算、記憶、轉換電力形式等工作。讀完後，你能說明手機規格表或電動車報導中出現的晶片各有什麼作用。

先讀

  1. CPU是什麼？ 把程式的指令一個個取出來，反覆進行計算和比較的零件。也會了解規格表上「核心數」的意思。
  2. 記憶體和儲存空間有什麼不同？ 放置作業中資料的地方，和收存照片、App的地方有什麼不同。可以了解「8 GB」和「256 GB」是什麼數字。
  3. AI為什麼要用GPU？ 能同時進行大量簡單計算的晶片，為什麼適合AI。讀完就看得懂新聞裡的「AI晶片」。
  4. 功率半導體是什麼？ 轉換電的形式、調整馬達轉速的零件。這是和計算用晶片不同的另一個大領域。
  5. 手機裡有哪些半導體？ 整體看看前面介紹的晶片，在一支手機裡如何分工。

接著讀

  • DRAM是什麼？ 和 SSD（固態硬碟）是什麼？ 更深入一層，看看記憶體和儲存空間的內部。
  • 影像感測器是什麼？ 手機相機把光轉換成電的原理。
  • 電動車裡有哪些半導體？ 以功率半導體為主角的產品例子。
  • 微控制器（MCU）是什麼？ 讓電子鍋和汽車動起來的小電腦。
  • 類比IC是什麼？ 處理聲音、溫度這類平滑變化訊號的晶片。

步驟4：產業與新聞

最後一個階段，是為了讀懂半導體新聞。知道前面3個階段，就能讀出公司名稱和數字的意義。讀完後，你能從製程與分工說明：「為什麼半導體工廠會成為國家政策的話題？」

先讀

  1. 晶圓代工是什麼？ 產業為什麼分成設計晶片的公司，和接受訂單製造的公司。可以了解台灣的台積電（TSMC）這類公司為什麼常上新聞。
  2. 晶片短缺為什麼會發生？ 2020～2022年發生缺貨的原因。工廠無法馬上增加的內容，和步驟2連在一起。
  3. 摩爾定律是什麼？ 這是一項觀察：晶片上的電晶體數量，大約每2年增加為2倍。可以了解「微縮」的背景，也就是把零件做小、塞進更多的做法。
  4. 「2奈米」「3奈米」是什麼的長度？ 這個數字是技術世代的名稱，不是晶片某個部分的長度。如果知道步驟1的電晶體和步驟2用光轉印的製程，會比較容易讀懂。

接著讀

  • EUV微影是什麼？ 在最先進的晶片上，用來轉印電路圖案的特殊光線。
  • HBM是什麼？ 放在AI晶片旁邊、層層堆疊的記憶體。
  • 小晶片（Chiplet）是什麼？ 把大晶片拆成小塊來製造，再組合起來的方法。

依目的選擇的捷徑

時間有限的人，也可以依目的照下面的順序讀。每條捷徑的開頭都一樣，先讀「半導體是什麼？」和「電晶體是什麼？」。因為其他文章的說明，都以這2篇為前提。

  • 想看懂新聞的人：半導體→電晶體→積體電路→晶圓代工廠→「2奈米」的意思。
  • 剛進半導體公司的人：半導體→電晶體→晶片的製造方法。業界有哪些工作，職務指南依職務做了詳細介紹。
  • 準備日本資訊考試的人：半導體→電晶體→用0和1計算→邏輯閘→CPU→記憶體和儲存空間→CPU快取記憶體是什麼？。這是指日本的IT Passport考試和基本資訊技術人員考試。考試範圍請以主辦單位日本資訊處理推進機構（IPA）公布的最新資料為準。

常見的誤解

誤解：要先把物理和數學學好，才能理解半導體。

實際上，用國中理化程度的知識，就能掌握原理的概念。本頁4個階段的文章，也幾乎不用公式，而是用文字和圖說明。公式和理論派上用場，是在掌握概念之後，想確認「為什麼會這樣」的時候。到了那時，請前往從技術角度說明物理、化學、數學基礎的系列。

誤解：從新聞常出現的最新詞語開始記，是最快的捷徑。

實際上，愈新的詞語，是建立在愈多基礎詞語之上的。例如「2奈米」並不是說晶片某個部分是2 nm。不懂基礎只記數字，就容易產生這種誤會。即使目的是看新聞，先讀步驟1的5篇文章，也能避免看錯新聞裡的數字。

誤解：做業務或行政工作的人，不需要知道晶片怎麼製造。

實際上，不需要記住製程的細節。不過，交期長、價格變動的原因，都和工廠的運作方式有關。例如在晶圓上做出電路的製程（前段製程），平均就要約12週。這是美國半導體產業協會（SIA）2021年說明中的數字。知道這類數字，向客戶或公司內部說明時會更容易。

從數字來看：需要多少時間？

本頁介紹的文章，每篇大約10～15分鐘就能讀完。每篇文章的標題下方，都有閱讀時間的參考。各階段的「先讀」有4～5篇，每天讀1篇的話，1週內就能讀完一個階段。

把4個階段的「先讀」全部讀完，每天1篇大約需要3週。這不是從平均閱讀速度算出來的數字，只是一個參考。在不懂的地方停下來、或讀第二遍的時間，都沒有算進去。

進一步學習

  • 用表格看差異：導體、半導體、絕緣體的差異／半導體前段製程與後段製程的差異／IDM、無晶圓廠、晶圓代工的差異／CPU 與 GPU 的差異
  • 動手試試看：用邏輯電路模擬器，可以確認把邏輯閘接起來時，0和1會怎麼變化。
  • 未來的技術：「微縮之後」整理了步驟4之後的新技術方向。
  • 給想成為工程師的人：如果要進入使用公式的說明，可以先讀「電阻是什麼？」「電容器是什麼？」，再前往「費米分布和波茲曼分布是什麼？」，這是其中一條路。
  • 查詢詞語：在文章中遇到的詞語，可以到名詞解釋查詢正確的意思。
