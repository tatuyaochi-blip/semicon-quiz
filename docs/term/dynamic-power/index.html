動的消費電力とは

どうてきしょうひでんりょく

CMOS回路で、信号が切り替わるときに容量を充電・放電するために使われる電力。活動率α、容量C、電圧V、周波数fを使ってαCV²fで表す。

「動的消費電力」は、4分野の6問の練習問題に出てきます(電力管理(ソフトウェア制御), CPU・アーキテクチャ, MOSFETなど)。

この用語の分野: 電力管理(ソフトウェア制御)

エネルギーの行き先

CMOSゲートの出力は、配線と接続先のゲートからなる負荷容量を駆動します。出力が立ち上がるとき、電源は CV² のエネルギーを供給し、その半分はコンデンサに蓄えられ、半分はプルアップ側のトランジスタで消費されます。出力が立ち下がるとき、蓄えられていた半分がプルダウン側を通ってグラウンドに捨てられます。これにその頻度を掛けたものが動的消費電力 P = αCV²f です。α は活動率で、1クロックサイクルあたりにスイッチングする容量の割合です。½αCV²f と書き、立ち上がりと立ち下がりのそれぞれを遷移として数える教科書もあるので、α の値を比べる前にどちらの定義かを確認してください。

電圧、周波数とエネルギー

V² の項があるため、電圧が最も強力な手段です。電源電圧を10%下げると動的消費電力は約19%減り、半分にすると4分の1になります。周波数は事情が異なります。f を半分にすれば電力は半分になりますが、決まった仕事にかかる時間は2倍になるので、その仕事のエネルギーは変わりません。1回のスイッチングのエネルギーは CV² で決まるからです。f を下げることに価値があるのは、回路がより低い電圧で正しく動けるようになるからです。周波数に比例して電圧も下げられるなら、両方を半分にすると電力は8分の1、仕事のエネルギーは4分の1になります。これが動的電圧周波数制御(DVFS)の基礎です。

活動率と容量を減らす

切り替わらない論理は動的消費電力を使わないので、α を減らすことは重要な設計手段です。クロックネットワークは毎サイクル切り替わるため、値が変わらないレジスタやブロックへのクロックを止めるクロックゲーティングは、フリップフロップとクロック配線の両方のスイッチングをなくします。容量は、トランジスタの微細化、配線の短縮、low-k誘電体によって減ります。計算例として、α = 0.1、C = 1 nF、V = 1 V、f = 1 GHz なら0.1 Wになります。

動的消費電力と静的消費電力

動的消費電力は全体の一部にすぎません。入力の遷移中に両方のトランジスタが部分的にオンになっている間は、短絡電流(貫通電流)が流れます。エッジが急峻なら、これはおおむね動的消費電力の10分の1以下です。リーク電流による静的消費電力は回路に電源が入っている限り流れるので、クロックゲーティングでは減らせず、代わりにアイドル中のブロックへの電源を遮断するパワーゲーティングが必要です。リークは、電圧を下げても効果が頭打ちになる理由でもあります。しきい値付近やわずかに下回る電圧では回路が非常に遅くなり、演算1回あたりのリークエネルギーが増えるため、エネルギーが最小になる電圧が存在します。

動的消費電力の練習問題に挑戦

CMOS回路で、ほかの条件を変えずに電源電圧だけを半分にすると、動的消費電力はどうなるか。

  1. A変わらない
  2. B1/2になる
  3. C1/4になる
答えと解説を見る

正解：C. 1/4になる

CMOSの動的消費電力は P = αCV²f で電源電圧の2乗に比例するため、電圧を半分にすると1/4になります。ただし電圧を下げるとトランジスタの電流が減って遅くなり、同じ周波数では動けなくなります。それでも周波数を下げて電圧も下げれば電力は3乗近くで減るため、DVFSで処理が軽いときに電圧と周波数を下げるのが最も効果的な省電力手段です。

CMOS回路の動的消費電力の式 P = αCV²f で、αが表すものとして正しいものはどれか。

  1. Aトランジスタの数
  2. B1クロックあたりに信号が切り替わる割合(活動率)
  3. Cチップの温度
答えと解説を見る

正解：B. 1クロックあたりに信号が切り替わる割合(活動率)

動的消費電力は、配線やゲートの容量を充電したり放電したりするときに使われる電力です。Cは切り替わる部分の容量、Vは電源電圧、fはクロックの周波数で、αは1クロックの間にどれだけの割合の信号が切り替わるかを表す活動率です。データが変わらない部分や、クロックを止めた部分は切り替わらないので、αを小さくすることも省電力の大切な手段です。

よくある質問

CMOSの動的消費電力の式は?

P = αCV²f で、α は活動率、C はスイッチングする容量、V は電源電圧、f はクロック周波数です。負荷容量の充電と放電を繰り返すことで生じます。

周波数より電圧を下げるほうが省電力になるのはなぜですか?

電力は電圧の2乗に比例する一方、周波数には1乗でしか比例せず、周波数だけを下げても仕事を終えるのに必要なエネルギーは変わらないからです。電圧を下げると、スイッチング1回ごとのエネルギーが減るので、電力とエネルギーの両方を節約できます。

クロックゲーティングとパワーゲーティングの違いは?

クロックゲーティングはアイドル中の論理へのクロックを止めるもので、その動的消費電力はなくなりますがリークは残ります。パワーゲーティングはスイッチトランジスタでブロックを電源から切り離し、リークもほぼすべてなくしますが、状態が失われ、復帰に時間がかかります。
