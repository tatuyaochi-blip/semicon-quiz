ATPG(自動テストパターン生成)とは

えーてぃーぴーじー

回路のネットリストから、故障を検出するためのテストパターンを自動で生成すること。スキャン設計と組み合わせて使う。

「ATPG(自動テストパターン生成)」は、4分野の7問の練習問題に出てきます(テスト・検査, 計測・分析, 歩留まり・品質管理など)。

この用語の分野: テスト・検査

ATPG(自動テストパターン生成)の練習問題に挑戦

テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。

  1. Aチップの表面を光学顕微鏡で走査して欠陥を探す
  2. Bテスト時に電源電圧を徐々に上げて動作限界を調べる
  3. C回路内のフリップフロップをシフトレジスタ状につなぎ、内部状態の設定と観測を容易にする
答えと解説を見る

正解：C. 回路内のフリップフロップをシフトレジスタ状につなぎ、内部状態の設定と観測を容易にする

スキャン設計では、各フリップフロップの入力に切り替えのセレクタを付け、テストのときはそれらを数珠つなぎ(スキャンチェーン)にして、外部から任意の値をシフトで設定し、内部の値をシフトで読み出せるようにします。順序回路のテストが組み合わせ回路のテストに置き換わるため、ATPGで高い故障検出率のパターンを自動生成できます。顕微鏡での走査や電圧の掃引とは別物です。

論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。

  1. A信号が伝わるのが遅くなる故障
  2. B信号線の値が0または1に固定されてしまう故障
  3. Cチップの温度が上がる故障
答えと解説を見る

正解：B. 信号線の値が0または1に固定されてしまう故障

縮退故障モデルでは、回路内のある信号線が常に0(0縮退)または常に1(1縮退)に固定される故障を想定し、信号線がn本なら2n個の故障を考えます。単純ながら短絡や断線など多くの物理的な欠陥を代表でき、ATPGや故障検出率の評価の基本になっています。信号が遅くなる故障は遅延故障モデルで扱い、温度上昇は故障モデルではありません。

解説の中の「ATPG(自動テストパターン生成)」

  • 順序回路のテストが組み合わせ回路のテストに置き換わるため、ATPGで高い故障検出率のパターンを自動生成できます。

    テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。

  • 単純ながら短絡や断線など多くの物理的な欠陥を代表でき、ATPGや故障検出率の評価の基本になっています。

    論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。

  • ATPGは、縮退故障などの故障モデルにもとづいて、各故障を出力まで伝えて検出できる入力パターンを、ネットリストから自動で生成する技術です。

    回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。

  • 故障を効率よく検出できるパターンは、ATPGで自動生成したり、設計時の検証用のシミュレーションから変換したりしてつくります。

    テストで、チップの入力に順番に加える0と1の信号の並びと、それに対する期待値の組を何と呼ぶか。

  • ATPGはテストパターンの生成、APCは工程の自動制御です。

    検査で見つかった欠陥をSEMで撮影し、その画像から欠陥の種類を自動で分類する機能はどれか。

「ATPG(自動テストパターン生成)」が出てくる問題(7問)

  1. テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。
  2. 論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。
  3. 回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。
  4. テストで、チップの入力に順番に加える0と1の信号の並びと、それに対する期待値の組を何と呼ぶか。
  5. 検査で見つかった欠陥をSEMで撮影し、その画像から欠陥の種類を自動で分類する機能はどれか。
  6. テストでは規格内でも、同じロットの分布から大きく外れた値を示すチップを不良として除く手法はどれか。
  7. 配置配線後のレイアウトから、配線の抵抗や容量を取り出す工程を何と呼ぶか。
