ATPG(自動テストパターン生成)とは

えーてぃーぴーじー

回路のネットリストから、故障を検出するためのテストパターンを自動で生成すること。スキャン設計と組み合わせて使う。

「ATPG(自動テストパターン生成)」は、4分野の7問の練習問題に出てきます(テスト・検査, 計測・分析, 歩留まり・品質管理など)。

この用語の分野: テスト・検査

ATPGがテストを見つけるしくみ

ATPG(自動テストパターン生成)は、ゲートレベルのネットリストと故障モデルをもとに動作します。対象とする故障ごとに、故障線を縮退値と逆の値に駆動して故障を活性化し、その差を活性化した経路に沿って観測可能な出力まで伝搬させる必要があります。同時に、その両方を成り立たせる外部入力の値を見つけなければなりません。DアルゴリズムやPODEMといった古典的なアルゴリズムがこの探索を行います。新しいパターンは故障シミュレーションにかけ、偶然検出できる他の故障もすべてマークします。テスト時間とテスタのメモリはパターン数とともに増えるため、パターンは圧縮されます。

故障モデルと故障検出率

縮退故障モデルは、信号線が0または1に固定されたままになると仮定するもので、n本の信号線に対して2n個の故障があります。抽象的なモデルですが、縮退故障を検出するパターンは実際のショートやオープンの多くも検出でき、パターンセットが検出できるモデル化故障の割合である故障検出率を測る基準として今も使われています。信号を遅らせるだけの欠陥は静的なテストでは見えないため、遷移故障などの遅延故障モデルを用いて、遷移を発生させて1クロック後に結果を取り込む実速度パターンを追加します。故障検出率はあくまでモデルに対する値で、あらゆる物理欠陥に対するものではありません。

スキャン設計が欠かせない理由

深い順序回路のテスト生成は非常に困難です。内部状態に到達するには多くのクロックサイクルが必要だからです。テスト容易化設計(DFT)の手法であるスキャン設計では、各フリップフロップの入力にマルチプレクサを追加し、テストモードではフリップフロップがつながってシフトレジスタのチェーンになるようにします。テスタは状態をシフトインし、通常動作のキャプチャクロックを1回印加して、結果をシフトアウトします。これによりATPGはスキャンセル間の組み合わせ回路だけを解けばよくなり、数億ゲート規模のチップでも高い故障検出率を実用的に達成できます。

ATPGと機能検証の違い

機能検証は設計が正しいかどうかを問うものですが、ATPGは設計が正しいことを前提に、製造された個々のチップが設計どおりかどうかを問います。ATPGの出力はテストパターン(テストベクタ)で、時間ステップごとの入力値と期待される応答から成り、自動テスト装置がそれを印加して比較します。ほかの選別手法もこれを補います。PAT(パートアベレージテスト)は、合格していても測定値が統計的な外れ値となるチップを除外する手法で、車載部品で一般的です。なお自動欠陥分類(ADC)はウエハ検査に属するもので、電気テストではありません。

ATPG(自動テストパターン生成)の練習問題に挑戦

テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。

  1. Aチップの表面を光学顕微鏡で走査して欠陥を探す
  2. Bテスト時に電源電圧を徐々に上げて動作限界を調べる
  3. C回路内のフリップフロップをシフトレジスタ状につなぎ、内部状態の設定と観測を容易にする
答えと解説を見る

正解：C. 回路内のフリップフロップをシフトレジスタ状につなぎ、内部状態の設定と観測を容易にする

スキャン設計では、各フリップフロップの入力に切り替えのセレクタを付け、テストのときはそれらを数珠つなぎ(スキャンチェーン)にして、外部から任意の値をシフトで設定し、内部の値をシフトで読み出せるようにします。順序回路のテストが組み合わせ回路のテストに置き換わるため、ATPGで高い故障検出率のパターンを自動生成できます。顕微鏡での走査や電圧の掃引とは別物です。

論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。

  1. A信号が伝わるのが遅くなる故障
  2. B信号線の値が0または1に固定されてしまう故障
  3. Cチップの温度が上がる故障
答えと解説を見る

正解：B. 信号線の値が0または1に固定されてしまう故障

縮退故障モデルでは、回路内のある信号線が常に0(0縮退)または常に1(1縮退)に固定される故障を想定し、信号線がn本なら2n個の故障を考えます。単純ながら短絡や断線など多くの物理的な欠陥を代表でき、ATPGや故障検出率の評価の基本になっています。信号が遅くなる故障は遅延故障モデルで扱い、温度上昇は故障モデルではありません。

よくある質問

VLSIテストにおけるATPGとは何ですか?

回路のネットリストから、縮退故障などのモデル化された製造故障を検出する入力パターンと期待出力を自動的に生成するソフトウェアです。

ATPGにスキャンチェーンが必要なのはなぜですか?

スキャンチェーンによってテスタがすべてのフリップフロップを直接設定・読み出しできるようになり、難しい順序回路のテスト問題が組み合わせ回路の問題に変わるからです。これによりATPGは効率よく高い故障検出率を達成できます。

縮退故障モデルと遷移故障モデルの違いは何ですか?

縮退故障は信号線が0または1に固定された状態をモデル化したもので、静的なテストで検出します。遷移故障は信号線の変化が遅すぎる状態をモデル化したもので、実速度のローンチ・キャプチャパターンが必要です。

  1. テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。
  2. 論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。
  3. 回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。
  4. テストで、チップの入力に順番に加える0と1の信号の並びと、それに対する期待値の組を何と呼ぶか。
  5. 検査で見つかった欠陥をSEMで撮影し、その画像から欠陥の種類を自動で分類する機能はどれか。
  6. テストでは規格内でも、同じロットの分布から大きく外れた値を示すチップを不良として除く手法はどれか。
  7. 配置配線後のレイアウトから、配線の抵抗や容量を取り出す工程を何と呼ぶか。
