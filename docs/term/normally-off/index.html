ノーマリーオフとは

のーまりーおふ

ゲート電圧が0 Vのときに電流が流れない特性。駆動回路が故障したときでも電流が流れ続けないため、パワーデバイスで安全上求められる。

この用語の分野: パワー半導体

「ノーマリーオフ」が出てくる問題(5問)

  1. パワーデバイスで、ゲート電圧が0 Vのときに電流が流れない「ノーマリーオフ」特性が求められる主な理由はどれか。
  2. ノーマリーオン型のGaN HEMTを、ノーマリーオフの動作で安全に使うために、低耐圧のシリコンMOSFETと直列に組み合わせる構成はどれか。
  3. エンハンスメント型のnチャネルMOSFETがオン(導通)するための条件として正しいものはどれか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  4. デプレッション型MOSFETの特徴として正しいものはどれか。
  5. 不揮発性メモリをキャッシュやレジスタなどに使うことで期待される、システムの省電力化の仕組みとして正しいものはどれか。
