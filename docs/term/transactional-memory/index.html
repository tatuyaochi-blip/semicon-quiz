トランザクショナルメモリとは

とらんざくしょなるめもり

クリティカルセクションを投機的に実行し、衝突がなければまとめて確定し、衝突すれば取り消してやり直す仕組み。

「トランザクショナルメモリ」は、1分野の1問の練習問題に出てきます(マルチコアと同期など)。

この用語の分野: マルチコアと同期

トランザクショナルメモリの練習問題に挑戦

ハードウェアトランザクショナルメモリの考え方として正しいものはどれか。

  1. Aクリティカルセクションを投機的に実行し、ほかのスレッドとの衝突がなければまとめて確定し、衝突すれば取り消してやり直す
  2. Bすべてのメモリの読み書きを、銀行の取引のようにディスクへ記録する
  3. Cメモリの書き込みを禁止して、読み出しだけを許す
答えと解説を見る

正解：A. クリティカルセクションを投機的に実行し、ほかのスレッドとの衝突がなければまとめて確定し、衝突すれば取り消してやり直す

トランザクショナルメモリでは、クリティカルセクションをトランザクションとして実行し、その間の書き込みは仮のものとしてほかから見えないようにします。ほかのスレッドが同じデータに触れていなければ、最後にすべての書き込みを一度に確定し、衝突があれば全部取り消してやり直すか、普通のロックに切り替えます。衝突が少なければ、粗いロックのままでも細かいロックに近い並列性が得られます。

解説の中の「トランザクショナルメモリ」

  • トランザクショナルメモリでは、クリティカルセクションをトランザクションとして実行し、その間の書き込みは仮のものとしてほかから見えないようにします。

    ハードウェアトランザクショナルメモリの考え方として正しいものはどれか。

「トランザクショナルメモリ」が出てくる問題(1問)

  1. ハードウェアトランザクショナルメモリの考え方として正しいものはどれか。
