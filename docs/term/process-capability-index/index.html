工程能力指数(Cpk)とは

こうていのうりょくしすう

工程のばらつきと平均のずれが、規格の範囲に対してどれだけ余裕があるかを表す指標。1.33以上が一つの目安。

「工程能力指数(Cpk)」は、3分野の5問の練習問題に出てきます(歩留まり・品質管理, パッケージ・実装, 先端技術(3D実装・チップレット)など)。

この用語の分野: 歩留まり・品質管理

CpとCpkの計算式

工程能力指数Cpは、規格の幅と工程の自然なばらつきを比べる指標で、Cp = (USL − LSL)/6σで求めます。USLとLSLは規格の上限と下限、σは工程の標準偏差です。Cpは工程の平均が規格の中心にあることを前提としています。Cpkはこの前提をなくし、平均から近いほうの規格限界までの距離を3σ単位で表します。式はCpk = min(USL − μ, μ − LSL)/3σです。平均が中心にあればCpkはCpと等しくなり、少しでも中心からずれるとCpkは小さくなります。

計算例と代表的な目標値

規格が目標値±6で、σ = 1の場合を考えます。Cp = 12/6 = 2です。平均が中心から3ずれると、近いほうの規格限界までは3しかないので、Cpは変わらないままCpk = 3/3 = 1になります。Cpk = 1は、近いほうの規格限界が平均から3σの位置にあることを意味し、正規分布ではその外側に約0.135%が出ます。一般的な最低基準はCpk ≥ 1.33で、これは近いほうの規格限界が4σの位置にあり、外側に出るのは数十ppmだけということです。重要なパラメータでは1.67以上が求められることもあります。

管理限界と規格限界の違い

規格限界は顧客や設計の要求から決まり、製品として許容できる範囲を定めます。一方、管理図の管理限界は工程自身の平均とばらつきから決まり、何か異常が起きたことを知らせるものです。工程が統計的に管理状態にあっても、ばらつきが大きすぎれば規格外品を出しますし、急なシフトで管理外れになっていても規格は満たしていることがあります。CpとCpkはこの2つの世界を結ぶ指標ですが、意味をもつのは工程が安定しているときだけです。不安定なデータから計算したCpkは、将来の出来栄えについて何も予測しません。

実務上の注意点

ppmへの換算はおおむね正規分布であることを前提としていますが、パーティクル数やリーク電流などでは必ずしも成り立ちません。片側規格の場合は該当する側だけを使い、たとえば上限しかなければ(USL − μ)/3σとします。多くの品質管理体系では、短期的な群内変動から計算するCpkと、長期的な全体の標準偏差から計算するPpkを区別しており、通常はPpkのほうが低くなります。半導体工場では、寸法(CD)、膜厚、重ね合わせ(オーバーレイ)、電気的試験の結果などのパラメータについて、これらの指数を管理しています。

工程能力指数(Cpk)の練習問題に挑戦

工程の平均値が規格の中心からずれている場合に用いる工程能力指数はどれか。

  1. ACp
  2. BCpk
  3. CMTTR
答えと解説を見る

正解：B. Cpk

Cpは平均が規格の中心にあると仮定した指数ですが、Cpkは平均と近い方の規格限界までの距離を3σで割って求めるため、平均のずれも反映されます。例えば規格±6、σ=1でもCp=2ですが、平均が規格の中心から3ずれるとCpk=(6−3)/3=1に下がります。平均が中心にあればCpとCpkは等しくなります。MTTRは平均修復時間で、保全の指標です。

よくある質問

CpとCpkの違いは?

Cpは規格の幅を工程の6σのばらつきと比べる指標で、平均が中心にあることを前提としています。Cpkは実際の平均から近いほうの規格限界までの距離を使うため、工程の中心ずれも反映されます。

Cpkはいくつ以上あればよいですか?

近いほうの規格限界が平均から4σ以上離れていることを意味するCpk 1.33以上が、広く使われる最低基準です。重要な特性では1.67以上が求められることもよくあります。

CpkがCpより大きくなることはありますか?

ありません。平均がちょうど中心にあるときCpkはCpと等しく、平均がどちらかの規格限界側にずれていれば必ずCpより小さくなります。
