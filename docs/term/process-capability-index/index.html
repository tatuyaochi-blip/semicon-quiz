工程能力指数(Cpk)とは

こうていのうりょくしすう

工程のばらつきと平均のずれが、規格の範囲に対してどれだけ余裕があるかを表す指標。1.33以上が一つの目安。

「工程能力指数(Cpk)」は、3分野の5問の練習問題に出てきます(歩留まり・品質管理, パッケージ・実装, 先端技術(3D実装・チップレット)など)。

この用語の分野: 歩留まり・品質管理

工程能力指数(Cpk)の練習問題に挑戦

工程の平均値が規格の中心からずれている場合に用いる工程能力指数はどれか。

  1. ACp
  2. BCpk
  3. CMTTR
答えと解説を見る

正解：B. Cpk

Cpは平均が規格の中心にあると仮定した指数ですが、Cpkは平均と近い方の規格限界までの距離を3σで割って求めるため、平均のずれも反映されます。例えば規格±6、σ=1でもCp=2ですが、平均が規格の中心から3ずれるとCpk=(6−3)/3=1に下がります。平均が中心にあればCpとCpkは等しくなります。MTTRは平均修復時間で、保全の指標です。

解説の中の「工程能力指数(Cpk)」

「工程能力指数(Cpk)」が出てくる問題(5問)

  1. 工程の平均値が規格の中心からずれている場合に用いる工程能力指数はどれか。
  2. パッケージの放熱性能を表す、チップの接合部から周囲の空気までの熱抵抗を表す記号はどれか。
  3. 表面実装パッケージで、防湿梱包を開封してからリフローまでに放置してよい時間などを定めた、吸湿に関する等級はどれか。
  4. 管理図の管理限界と、製品の規格限界の違いとして正しいものはどれか。
  5. チップレット間接続の性能の指標として重視される、チップの辺の長さあたりに確保できるデータ転送量を何と呼ぶか。
