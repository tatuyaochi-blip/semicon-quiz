ボード線図とは

ぼーどせんず

系の周波数応答を、横軸に周波数の対数、縦軸にゲイン(dB)と位相(度)をとった2つのグラフで表したもの。伝達関数の積はゲイン(dB)と位相の和になるので、要素ごとの線を足し合わせて描ける。極が1つ増えるごとにゲインの傾きが −20 dB/dec 変わり、位相が最大90°遅れる。一巡伝達関数のボード線図から、ゲイン余裕と位相余裕を読み取って安定性を調べる。

「ボード線図」は、2分野の5問の練習問題に出てきます(制御工学の基礎, 回路解析(交流回路・線形回路・過渡現象)など)。

この用語の分野: 制御工学の基礎

折れ線近似の描き方

一次の要素 1/(1 + s/ωc) は、ωc より低い周波数では0 dBの水平線、高い周波数では −20 dB/dec の直線で近似します。実際のゲインは折れ点で約 −3 dBで、位相は折れ点で −45° になり、その10分の1から10倍の範囲で、およそ0°から −90° まで変わります。零点は逆に +20 dB/dec の傾きと位相の進みを加え、積分 1/s は全体に −20 dB/dec の傾きと −90° を加えます。

安定余裕を読み取る

一巡伝達関数のゲインが0 dBを横切る周波数(ゲイン交差周波数)で、位相が −180° まであと何度あるかが位相余裕です。位相が −180° になる周波数(位相交差周波数)で、ゲインが0 dBより何dB低いかがゲイン余裕です。ゲイン交差周波数はループの速さの目安にもなり、高いほど閉ループの応答は速くなります。

ナイキスト線図との違い

同じ周波数応答を、複素平面の上に1本の軌跡として描いたものがナイキスト線図(ベクトル軌跡)です。ボード線図は周波数の目盛りが読みやすく、要素を足し合わせて描けるので設計に向いています。ナイキスト線図は点 −1 との位置関係で安定性を直接判別でき、一巡伝達関数自体が不安定な場合にも使えます。

ボード線図の練習問題に挑戦

一次遅れ系 G(s) = 1/(1 + sT) のボード線図の特徴として正しいものはどれか。

  1. A折れ点の角周波数 ω = 1/T でゲインは約 −3 dB、位相は −45° で、それより十分高い周波数ではゲインが −20 dB/dec で下がる
  2. B折れ点の角周波数 ω = 1/T でゲインは −6 dB、位相は −90° で、それより十分高い周波数では、ゲインが −40 dB/dec の傾きで下がる
  3. Cゲインはどの周波数でも0 dBで、位相だけが周波数に比例して遅れていく
答えと解説を見る

正解：A. 折れ点の角周波数 ω = 1/T でゲインは約 −3 dB、位相は −45° で、それより十分高い周波数ではゲインが −20 dB/dec で下がる

G(jω) = 1/(1 + jωT) の大きさは 1/√(1 + (ωT)²) で、ω = 1/T では 1/√2(約 −3 dB)、位相は −45° です。ω が 1/T より十分大きいと大きさは 1/(ωT) に近づき、周波数が10倍になるごとにゲインが20 dB下がります(−20 dB/dec)。位相は、低い周波数の0°から高い周波数の −90° へ変わります。ボード線図の折れ線近似では、折れ点より下を0 dBの水平線、上を −20 dB/dec の直線で表します。

積分要素 G(s) = 1/s のボード線図として正しいものはどれか。

  1. Aゲインはどの周波数でも0 dBで、位相はどの周波数でも −90° になる
  2. Bゲインは ω = 1 rad/s で0 dBを通る +20 dB/dec の直線で、位相はどの周波数でも +90° になる
  3. Cゲインは ω = 1 rad/s で0 dBを通る −20 dB/dec の直線で、位相はどの周波数でも −90° になる
答えと解説を見る

正解：C. ゲインは ω = 1 rad/s で0 dBを通る −20 dB/dec の直線で、位相はどの周波数でも −90° になる

G(jω) = 1/(jω) の大きさは 1/ω なので、ω = 1 rad/s で0 dBになり、周波数が10倍になるごとに20 dB下がります。1/j = −j なので、位相はどの周波数でも −90° です。低い周波数ほどゲインが大きくなるので、積分を含む系は、ステップの目標値に対する定常偏差を0にできます。+20 dB/dec で位相 +90° の直線になるのは、微分要素 s です。

よくある質問

ボード線図の −20 dB/dec とは何ですか?

周波数が10倍(1ディケード)になるごとに、ゲインが20 dB、つまり振幅が10分の1になる傾きです。極が1つ増えるごとに、この傾きが −20 dB/dec ずつ急になります。周波数が2倍になるごとに約6 dB下がる −6 dB/oct と同じ傾きです。

ボード線図はどうやって測りますか?

正弦波の周波数を変えながら入力し、出力の振幅と位相を測ります。電源の制御ループでは、ループの途中に小さな抵抗を入れて信号を注入し、周波数応答アナライザで一巡伝達関数を測るのが一般的です。
