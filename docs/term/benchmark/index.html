ベンチマークとは

べんちまーく

コンピュータやプログラムの性能を比べるために、決まった条件で実行する代表的なプログラム。実際の用途に近いものを選ぶことが大切。

この用語の分野: 性能評価・プロファイリング

解説の中の「ベンチマーク」

  • そのため、実際の用途にできるだけ近いプログラムや、多くの代表的なプログラムを集めた標準のベンチマークで測り、条件をそろえて比べることが大切です。

    コンピュータの性能をベンチマークで評価するときの考え方として最も適切なものはどれか。

  • SPEC CPUは、コンパイラ、圧縮、物理のシミュレーションなど、実際のアプリケーションをもとにした多数のプログラムからなるベンチマークです。

    SPEC CPUのような標準のベンチマークの説明として正しいものはどれか。

  • 変更のたびに同じ条件でベンチマークを実行して結果を記録しておけば、性能が落ちたときにすぐ気づけ、どの変更が原因かもすぐ分かります。

    ソフトウェアの開発で、変更のたびにベンチマークを自動で実行して結果を記録しておく目的として正しいものはどれか。

「ベンチマーク」が出てくる問題(6問)

  1. コンピュータの性能をベンチマークで評価するときの考え方として最も適切なものはどれか。
  2. SPEC CPUのような標準のベンチマークの説明として正しいものはどれか。
  3. 複数のベンチマークの、基準の計算機に対する速さの比をまとめるときに、幾何平均がよく使われる理由として正しいものはどれか。
  4. ソフトウェアの開発で、変更のたびにベンチマークを自動で実行して結果を記録しておく目的として正しいものはどれか。
  5. ノートパソコンでベンチマークを測ったところ、同じプログラムでも結果が毎回大きくばらついた。CPUの側の原因として考えられるものと、その対策の組み合わせとして正しいものはどれか。
  6. STREAMベンチマークで主に測るものはどれか。
