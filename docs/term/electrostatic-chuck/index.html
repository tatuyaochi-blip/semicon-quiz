静電チャックとは

せいでんちゃっく

静電気力でウエハを台に吸着して固定する機構。真空中でも使え、ウエハの温度を制御するために裏面にガスを流すこともできる。成膜やエッチングの装置で広く使われる。

この用語の分野: 成膜(CVD・PVD)

解説の中の「静電チャック」

  • また温度によって損傷の回復の度合い(アモルファス化のしやすさ)が変わるため、ウエハを静電チャックで冷却して温度を管理します。

    大電流のイオン注入中にウエハを冷却する主な理由はどれか。

  • 静電チャックは、セラミックの台の内部の電極に数百V〜数kVの電圧をかけ、ウエハとの間にはたらく静電気力で吸着・固定します。

    成膜やエッチングの装置で、ウエハを静電気力で台に固定する機構はどれか。

  • 静電チャックやマスクとは別の部品です。

    スパッタリングで使うターゲットの説明として正しいものはどれか。
