マルチパターニングとは

まるちぱたーにんぐ

1回の露光では解像できない細かいピッチのパターンを、複数回の露光や加工に分けて形成する技術。2回に分けるものをダブルパターニングという。

「マルチパターニング」は、3分野の5問の練習問題に出てきます(リソグラフィ, 成膜(CVD・PVD), 半導体産業・市場など)。

この用語の分野: リソグラフィ

1回の露光では足りない理由

解像度は R = k1·λ/NA で表されます。ArF(フッ化アルゴン)液浸リソグラフィは波長 193 nm と NA 1.35 の組み合わせで、k1 を実用上の限界である約 0.27 まで下げても、最小ハーフピッチはおよそ 39 nm、ピッチにして約 80 nm です。先端ロジックやメモリの層には、それより狭いピッチが必要です。マルチパターニングは、最終パターンを複数回の露光から組み立てるか、緩いピッチのパターンを増やすプロセス工程を使うことで、どの露光も最終ピッチを解像しなくて済むようにします。

LELE:レイアウトの分割

LELE(リソ-エッチ-リソ-エッチ)では、レイアウトを2枚のマスクに分解します。これはしばしば「色分け」と呼ばれ、1回露光の限界より近いパターン同士が別々のマスクに載るようにします。それぞれのマスクを順に露光・エッチングします。マスクを3枚にする LELELE もあります。主な難点は2つです。露光間の重ね合わせ誤差がそのまま隣接パターンの間隔を変えるため、非常に厳しい位置合わせが必要になります。また、互いに近接する3つのパターンのように2色に分けられないレイアウトがあるため、デザインルールで禁止しなければなりません。

SADPとSAQP:スペーサがピッチを決める

SADP(自己整合ダブルパターニング)では、緩いピッチでマンドレル(芯材)のラインを形成し、通常 ALD(原子層堆積)でコンフォーマルな膜を被せ、エッチバックして両側壁にスペーサを残します。マンドレルを除去すると、元のピッチの半分のスペーサラインが残ります。線幅は膜厚で決まるので均一性に優れ、半分ずつの間の重ね合わせ誤差もありません。この工程を繰り返すのが SAQP(自己整合クアドルプルパターニング)です。得られるのは規則的な格子パターンなので、不要な部分はカットマスクやブロックマスクを追加して除去します。そのため設計は一方向のラインへと向かいます。

コストとEUVという選択肢

マスク、成膜、エッチングが1つ増えるごとに、コスト、サイクルタイム、欠陥の機会が増え、各工程がばらつきの原因にもなります。たとえばスペーサ方式では、マンドレルの線幅誤差によって交互のスペースが不均一になり、これはピッチウォーキングと呼ばれます。こうしたコストが、多くの層を1回露光に戻せる波長 13.5 nm の EUV(極端紫外線)リソグラフィの導入を後押ししました。ただし最も狭いピッチでは、EUV 自体を再びマルチパターニングと組み合わせることもあります。

マルチパターニングの練習問題に挑戦

ダブルパターニング(マルチパターニング)の説明として正しいものはどれか。

  1. A2枚のウエハを同時に露光する
  2. B1回の露光では解像できない細かいピッチのパターンを、複数回の露光や加工に分けて形成する
  3. Cレジストを2層重ねて塗るだけで解像度を2倍にする
答えと解説を見る

正解：B. 1回の露光では解像できない細かいピッチのパターンを、複数回の露光や加工に分けて形成する

ダブルパターニングは、1回では解像できない細かいピッチのパターンを、間引いた2つのパターンに分けて別々に露光・加工したり(LELE)、側壁に成膜したスペーサーで線を倍にしたり(SADP・SAQP)して形成する技術です。ArF液浸の限界(ピッチ約80 nm)を超えて20 nm台のピッチまで微細化を進めましたが、工程数・マスク数・コストが大きく増えるため、EUV露光の導入が進められてきました。

よくある質問

LELEとSADPの違いは何ですか?

LELE はレイアウトを2枚のマスクに分けて別々に露光・エッチングする方式で、両者の重ね合わせ精度が問題になります。SADP は1回形成したパターンの側壁スペーサを使って自己整合的にピッチを半分にする方式で、線幅は膜厚で決まります。

マルチパターニングはなぜコストが高いのですか?

層ごとにマスク、露光、成膜、エッチング、検査が追加で必要になり、コストとサイクルタイムが増え、ばらつきや欠陥の原因も増えるからです。

EUVを使えばマルチパターニングは不要になりますか?

EUV では多くの層を1回の露光で形成できるため、マルチパターニングの必要性は大きく減ります。ただし最も狭いピッチでは、EUV でもダブルパターニングと組み合わせることがあります。
