裏面電源供給とは

りめんでんげんきょうきゅう

電源配線をウエハの裏面側に配置し、表面の配線を信号用に使えるようにする技術。電圧降下や配線の混雑を減らせる。バックサイドパワーデリバリーとも呼ぶ。

この用語の分野: 配線プロセス

解説の中の「裏面電源供給」

  • 裏面電源供給では、ウエハを数百nm〜数µmまで薄くして裏側に太い電源配線を設け、トランジスタに下から電源を供給します。

    先端ロジックで導入が進む裏面電源供給(バックサイドパワーデリバリー)の説明として正しいものはどれか。

  • GAAでは、ナノシートの幅を変えられる柔軟性と、裏面電源供給などの新技術との組み合わせが性能向上の鍵になっています。

    GAA(ナノシート)型トランジスタを、世界で最初に量産に採用したと発表した企業と世代の組み合わせとして正しいものはどれ…

  • 裏面電源供給の導入で、層構成は今後さらに変わります。

    先端ロジックLSIの配線層の数として最も近いものはどれか。

「裏面電源供給」が出てくる問題(3問)

  2. GAA(ナノシート)型トランジスタを、世界で最初に量産に採用したと発表した企業と世代の組み合わせとして正しいものはどれか。
