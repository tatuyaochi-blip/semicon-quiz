I2Cとは

あいすけあしー

クロック(SCL)とデータ(SDA)の2本の線に複数の機器をつなぎ、アドレスで相手を選ぶ同期式のシリアル通信。線はオープンドレインでプルアップする。

この用語の分野: 組込み・ファームウェア

解説の中の「I2C」

  • I2Cは、SCLとSDAの2本だけで複数の機器をつなぐ同期式のシリアル通信です。

    I2C通信の特徴として正しいものはどれか。

  • I2Cでは、8ビットのデータに続く9番目のクロックで、受け取った側がSDAを0に引き下げて受け取ったことを知らせます(ACK)。

    I2Cで、データを1バイト受け取った側が、受け取ったことを知らせる方法として正しいものはどれか。

  • I2Cではアドレスで相手を選ぶので、同じアドレスの機器が2つあると、両方が同時に応答して通信が壊れます。

    同じ型番のI2Cの温度センサを2つ、同じI2Cの線につなぎたいが、どちらも同じアドレスを持っている。対策として正しいも…

「I2C」が出てくる問題(4問)

  1. I2C通信の特徴として正しいものはどれか。
  2. I2Cで、データを1バイト受け取った側が、受け取ったことを知らせる方法として正しいものはどれか。
  3. 同じ型番のI2Cの温度センサを2つ、同じI2Cの線につなぎたいが、どちらも同じアドレスを持っている。対策として正しいものはどれか。
  4. UART・SPI・I2Cを比べた説明として正しいものはどれか。
