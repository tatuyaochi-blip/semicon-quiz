ICMPとは

あいしーえむぴー

Internet Control Message Protocolの略。IPの通信で起きた誤りや状態を知らせるためのプロトコル。宛先に届けられない(Destination Unreachable)、TTLが0になった(Time Exceeded)といったことを送信元に通知する。pingはエコー要求とエコー応答で相手に届くかとRTTを調べ、tracerouteはTime Exceededの通知を使って経路を調べる。IPv6ではICMPv6が近隣探索なども担う。

「ICMP」は、3分野の6問の練習問題に出てきます(ネットワークの設計と運用, クラウドとコンテナの基礎, ネットワークの基礎など)。

ICMPの練習問題に挑戦

tracerouteで、送信元から数えて4台目のルータから、ICMPの時間超過(Time Exceeded)のメッセージを返させるために送るパケットの、IPヘッダのTTLの値はどれか。

  1. A3
  2. B4
  3. C5
答えと解説を見る

正解：B. 4

ルータはパケットを転送するたびにTTLを1減らし、0になったパケットは捨てて、送信元にICMPの時間超過のメッセージを返します。TTLを4にして送ると、1台目で3、2台目で2、3台目で1になり、4台目で0になるので、4台目のルータがメッセージを返します。tracerouteは、TTLを1、2、3…と1つずつ増やしながらパケットを送り、返ってきたメッセージの送信元のアドレスと時間から、経路上のルータと遅延を順に表示します。宛先まで届くと、宛先からの応答(ICMPのエコー応答や、宛先のポートに届かないことを示すメッセージ)で終わりを知ります。

拠点間のVPNのトンネルを通して、遠くのWebサーバと通信している。TCPのコネクションは確立でき、小さなページは表示されるが、大きなファイルのダウンロードだけが途中で止まってしまう。トンネルの中のMTUは1400バイトで、サーバは1500バイトのパケットを分割禁止(DFビットを1)にして送っている。また、サーバの手前のファイアウォールはICMPをすべて捨てる設定になっている。原因として最も適切なものはどれか。

  1. ADNSの名前解決が失敗しているため
  2. BTCPの受信ウィンドウが小さすぎて、一度に送れるデータの量が足りないため
  3. C大きすぎるパケットを捨てたルータが送る、分割が必要であることを知らせるICMPのメッセージがサーバに届かず、サーバがパケットを小さくできないため
答えと解説を見る

正解：C. 大きすぎるパケットを捨てたルータが送る、分割が必要であることを知らせるICMPのメッセージがサーバに届かず、サーバがパケットを小さくできないため

経路MTU探索では、送信元はDFビットを1にしてパケットを送り、途中のMTUより大きいパケットを捨てたルータが、ICMPのメッセージ(IPv4では分割が必要、IPv6ではPacket Too Big)で通れる大きさを知らせます。このメッセージがファイアウォールで捨てられると、サーバは大きなパケットを送り続け、それが毎回捨てられるので、大きなデータの転送だけが止まります(経路MTUのブラックホール)。コネクションの確立や小さな応答は、パケットが1400バイトより小さいので問題なく届きます。対策は、このICMPのメッセージを捨てないようにすることや、トンネルの入口のルータでTCPのMSSを小さく書き換えることです。IPv4とTCPのヘッダをそれぞれ20バイトとすると、MTUが1400バイトならMSSは 1400 − 20 − 20 = 1360 バイトにします。

「ICMP」が出てくる問題(6問)

  1. tracerouteで、送信元から数えて4台目のルータから、ICMPの時間超過(Time Exceeded)のメッセージを返させるために送るパケットの、IPヘッダのTTLの値はどれか。
  2. 拠点間のVPNのトンネルを通して、遠くのWebサーバと通信している。TCPのコネクションは確立でき、小さなページは表示されるが、大きなファイルのダウンロードだけが途中で止まってしまう。トンネルの中のMTUは1400バイトで、サーバは1500バイトのパケットを分割禁止(DFビットを1)にして送っている。また、サーバの手前のファイアウォールはICMPをすべて捨てる設定になっている。原因として最も適切なものはどれか。
  3. あるPCから、IPアドレスを指定したpingはインターネット上のサーバまで届くが、ブラウザでドメイン名を指定すると「サーバが見つからない」と表示されて、Webページを開けない。まず確認すべき設定として最も適切なものはどれか。
  4. 上のDockerfileから作ったイメージ pinger を、docker run pinger example.com として起動した。コンテナの中で実行されるコマンドとして、正しいものはどれか。
  5. IPv4ヘッダのTTL(Time To Live)の役割として正しいものはどれか。
  6. ある端末からWebサーバ 198.51.100.80 までtracerouteを実行したところ、1〜5番目の行に、192.168.1.1、10.0.0.1、「* * *」(応答なし)、203.0.113.1、198.51.100.80 の順で表示され、Webサーバも問題なく使えた。3番目の行の解釈として最も適切なものはどれか。
