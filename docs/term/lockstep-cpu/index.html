ロックステップとは

ろっくすてっぷ

同じ構成の2つのCPUコアで同じプログラムを実行し、出力を比較回路で照合して故障を検出する方式。共通原因故障で両方が同じように誤るのを防ぐため、実行を数クロックずらしたりコアを離して配置したりする。性能は1コア分になる。

「ロックステップ」は、1分野の2問の練習問題に出てきます(車載半導体と機能安全など)。

この用語の分野: 車載半導体と機能安全

ロックステップの練習問題に挑戦

車載マイコンの安全機構として使われるロックステップCPUの仕組みとして正しいものはどれか。

  1. A2つのCPUコアに別々の処理を分担させ、処理の速さをおよそ2倍にする
  2. B2つのCPUコアに同じ命令を同時に実行させ、出力をクロックごとに比較して、一致しなければ故障として知らせる
  3. C故障が見つかるとCPUの動作を一時的に止め(ロック)、予備の回路に切り替えて故障した部分を自動で修理してから再開する
答えと解説を見る

正解：B. 2つのCPUコアに同じ命令を同時に実行させ、出力をクロックごとに比較して、一致しなければ故障として知らせる

ロックステップは、同じ構成のCPUコアを2つ用意して同じプログラムを実行させ、比較回路で出力を照らし合わせる方式です。宇宙線によるビット反転や回路の故障で片方の結果が変わると、不一致として検出できるので、CPUの故障に対して高い診断カバレッジが得られます。2つのコアは同じ処理をしているので性能は1コア分です。2つのコアの比較だけでは、どちらが正しいかはわからないため、検出後はリセットや安全な状態への移行を行います。

ロックステップCPUで、2つのコアの実行を数クロックずらしたり、チップ上で2つのコアを離して配置したりする主な理由はどれか。

  1. A電源ノイズや放射線などの同じ原因で両方のコアに同時に同じ誤りが起きると比較で見つからないため、同じ誤りになりにくくする
  2. B片方のコアの計算結果を、もう片方のコアが先回りして使えるようにし、処理を速くするため
  3. C2つのコアがそれぞれ別のプログラムを実行できるようにし、使えるコアの数を増やすため
答えと解説を見る

正解：A. 電源ノイズや放射線などの同じ原因で両方のコアに同時に同じ誤りが起きると比較で見つからないため、同じ誤りになりにくくする

ロックステップは2つのコアの結果の違いで故障を見つけるので、同じ原因で両方に同じ誤りが起きると検出できません。このような故障を共通原因故障と呼びます。電源電圧の瞬間的な低下やクロックの乱れは両方のコアに同時に影響するため、片方の実行を例えば2クロック遅らせ、比較のときに合わせると、同じタイミングで同じ誤りになりにくくなります。コアを離して置くのも、局所的な原因が両方に及ばないようにするためです。

解説の中の「ロックステップ」

  • ロックステップは、同じ構成のCPUコアを2つ用意して同じプログラムを実行させ、比較回路で出力を照らし合わせる方式です。
