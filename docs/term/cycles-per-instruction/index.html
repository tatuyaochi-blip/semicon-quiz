CPIとは

しーぴーあい

Cycles Per Instructionの略。1命令あたりに平均何クロックサイクルかかるかを表す値。実行時間=命令数×CPI×サイクル時間の要素の1つ。IPCの逆数。

この用語の分野: 性能評価・プロファイリング

解説の中の「CPI」

  • CPIが1未満なのは、スーパースカラで1クロックに複数の命令を実行しているためです。

    クロック周波数2 GHz、平均CPI(1命令あたりの平均クロック数)0.5のプロセッサが、1秒間に実行できる命令数はお…

  • これを理想のCPIに足すと 1.0 + 2.6 = 3.6 になり、性能は理想の3.6分の1に落ちます。

    キャッシュが理想的なら平均CPIが1.0のプロセッサで、1命令あたり平均1.3回のメモリアクセスがあり、そのミス率が2…

  • 必要なサイクルの数は、命令数×CPI=10億×2=20億サイクルです。

    10億個の命令を実行するプログラムを、平均CPIが2、クロック周波数が2 GHzのCPUで実行した。実行時間はいくらか。

「CPI」が出てくる問題(9問)

  1. クロック周波数2 GHz、平均CPI(1命令あたりの平均クロック数)0.5のプロセッサが、1秒間に実行できる命令数はおよそいくらか。
  2. キャッシュが理想的なら平均CPIが1.0のプロセッサで、1命令あたり平均1.3回のメモリアクセスがあり、そのミス率が2%、ミスペナルティが100サイクルのとき、実際の平均CPIはいくらか。
  3. 10億個の命令を実行するプログラムを、平均CPIが2、クロック周波数が2 GHzのCPUで実行した。実行時間はいくらか。
  4. CPUの設計の変更で、クロックの周波数は1.5倍になったが、CPIも1.2倍に増えた(命令数は同じ)。実行の速さは元の何倍になるか。
  5. コンパイラの新しい最適化で、実行する命令の数は20%減ったが、平均CPIが10%増えた(周波数は同じ)。この最適化の効果として正しいものはどれか。
  6. あるプログラムの命令の割合が、整数の演算50%(CPI 1)、ロードとストア30%(CPI 2)、分岐20%(CPI 5)だった。平均CPIはいくらか。
  7. 1クロックあたりに実行できる命令数を表す指標はどれか。
  8. 機械的に弱いLow-k膜を使ったチップで、パッケージに実装するときの応力によって膜が割れたりはがれたりする問題を何と呼ぶか。
  9. プログラムのCPUでの実行時間を表す基本の式として正しいものはどれか。
