縮退故障とは

しゅくたいこしょう

信号線の値が0または1に固定されてしまうと仮定する、論理回路のテストの基本的な故障モデル。スタックアット故障とも呼ぶ。

この用語の分野: テスト・検査

解説の中の「縮退故障」

  • 縮退故障モデルでは、回路内のある信号線が常に0(0縮退)または常に1(1縮退)に固定される故障を想定します。

    論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。

  • ATPGは、縮退故障などの故障モデルにもとづいて、各故障を検出できる入力パターンを自動で生成する技術です。

    回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。

  • 単純な縮退故障だけでなく、隣接セルどうしの干渉(カップリング故障)やアドレスデコーダの不良なども効率よく検出できます。

    メモリのテストで、アドレスを順にたどりながら0と1の書き込みと読み出しを繰り返し、隣接するセル間の干渉などの不良も検出…

「縮退故障」が出てくる問題(5問)

  1. 論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。
  2. 論理回路のテストで、スキャンなどを使って回路の構造上の故障(縮退故障など)を網羅的に検出するテストと、実際の動作どおりに機能を確認するテストの呼び方の組み合わせとして正しいものはどれか。
  3. 回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。
  4. メモリのテストで、アドレスを順にたどりながら0と1の書き込みと読み出しを繰り返し、隣接するセル間の干渉などの不良も検出するテストパターンはどれか。
  5. スタンダードセルの内部のトランジスタの短絡や開放などの欠陥を、セルの回路をもとにモデル化してテストパターンを生成する手法はどれか。
