縮退故障とは

しゅくたいこしょう

信号線の値が0または1に固定されてしまうと仮定する、論理回路のテストの基本的な故障モデル。スタックアット故障とも呼ぶ。

「縮退故障」は、1分野の5問の練習問題に出てきます(テスト・検査など)。

この用語の分野: テスト・検査

縮退故障モデルの考え方

縮退故障モデルでは、回路の中のある信号線の値が、入力にかかわらず常に0に固定される(0縮退、stuck-at-0)か、常に1に固定される(1縮退、stuck-at-1)と仮定します。実際の欠陥は、配線の短絡や断線、トランジスタの不良などさまざまですが、それらを論理値の固定という単純な形に置き換えることで、テストの生成と評価を計算機で扱えるようにしています。信号線がn本あれば、故障の候補は2n個です。通常は、回路の中に故障が1つだけあると仮定する単一縮退故障モデルを使います。

故障を検出する条件

ある線の0縮退を検出するには、テストパターンでその線を、正常なら1になるように設定し(活性化)、その値の違いを出力やスキャンのフリップフロップまで伝える(伝搬)必要があります。例えば、ANDゲートの一方の入力の0縮退を出力に伝えるには、もう一方の入力を1にしておきます。こうした条件を満たすパターンを、ATPG(自動テストパターン生成)がネットリストから自動で求めます。順序回路では内部の値を直接設定しにくいため、フリップフロップをつないだスキャンチェーンで設定と観測を容易にし、組み合わせ回路の問題として解きます。

故障検出率と品質

想定した縮退故障のうち、テストで検出できる故障の割合が故障検出率(フォールトカバレッジ)です。見逃される不良の割合は、歩留まりYと故障検出率Tを使ってDL = 1 − Y^(1−T)と見積もられ、Y = 0.5、T = 99%でも約0.7%になります。そのため、車載向けなどでは99%を大きく超える値が求められます。縮退故障の検出率は、テストの質を数値で比べられる基本の指標として広く使われています。実際の計算では、検出の条件が同じになる等価な故障をまとめて(故障の縮約)、扱う故障の数を減らします。

縮退故障では捉えにくい欠陥

縮退故障モデルは単純で扱いやすい反面、すべての欠陥を表せるわけではありません。微細なプロセスでは、信号が遅れて届く欠陥が増えており、これは遷移故障やパス遅延故障などの遅延故障モデルを使い、実際の動作速度に近いat-speedテストで検出します。2本の配線の短絡はブリッジ故障モデルで、セルの内部のトランジスタの短絡や開放はセルアウェアテストで扱います。静止時の電源電流を測るIDDQテストも、縮退故障のテストで見逃されやすいブリッジなどを補う方法として使われてきました。

縮退故障の練習問題に挑戦

論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。

  1. A信号が伝わるのが遅くなる故障
  2. B信号線の値が0または1に固定されてしまう故障
  3. Cチップの温度が上がる故障
答えと解説を見る

正解：B. 信号線の値が0または1に固定されてしまう故障

縮退故障モデルでは、回路内のある信号線が常に0(0縮退)または常に1(1縮退)に固定される故障を想定し、信号線がn本なら2n個の故障を考えます。単純ながら短絡や断線など多くの物理的な欠陥を代表でき、ATPGや故障検出率の評価の基本になっています。信号が遅くなる故障は遅延故障モデルで扱い、温度上昇は故障モデルではありません。

論理回路のテストで、スキャンなどを使って回路の構造上の故障(縮退故障など)を網羅的に検出するテストと、実際の動作どおりに機能を確認するテストの呼び方の組み合わせとして正しいものはどれか。

  1. ADCテストとACテスト
  2. Bウエハテストとバーンイン
  3. Cストラクチャルテストとファンクショナルテスト
答えと解説を見る

正解：C. ストラクチャルテストとファンクショナルテスト

ストラクチャルテストは、回路の構造に対して故障モデルを考え、スキャンなどを使って各部分の故障を効率よく検出するテストで、故障検出率を数値で管理できます。ファンクショナルテストは、実際の使い方に近い入力を与えて、仕様どおりに機能するかを確認するテストです。前者は網羅性、後者は実使用に近い条件での確認に強く、両者を組み合わせて品質を確保します。

よくある質問

縮退故障とスタックアット故障は同じですか?

同じです。英語のstuck-at faultの訳が縮退故障で、信号線の値が0に固定される0縮退(stuck-at-0)と、1に固定される1縮退(stuck-at-1)の2種類があります。

縮退故障のテストだけで十分ですか?

十分とは限りません。信号が遅れる欠陥は縮退故障のテストでは見つけにくいため、遷移故障などの遅延故障のテストを実際の速度で行います。ブリッジ故障やセルの内部の欠陥を対象にしたテストも組み合わせ、品質の要求が高い製品ほど多くの故障モデルを使います。

信号線が100本の回路では、縮退故障はいくつ考えますか?

1本の線ごとに0縮退と1縮退の2つがあるので、2 × 100 = 200個です。実際には、検出の条件が同じになる等価な故障をまとめることで、テストの生成で扱う数を減らします。

  2. 論理回路のテストで、スキャンなどを使って回路の構造上の故障(縮退故障など)を網羅的に検出するテストと、実際の動作どおりに機能を確認するテストの呼び方の組み合わせとして正しいものはどれか。
