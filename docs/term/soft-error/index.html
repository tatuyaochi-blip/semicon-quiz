ソフトエラーとは

そふとえらー

宇宙線に由来する中性子やアルファ線などによって、メモリやフリップフロップの記憶データが一時的に反転する誤り。素子は壊れないため、書き直せば正常に戻る。

この用語の分野: 信頼性

解説の中の「ソフトエラー」

  • ソフトエラーは、パッケージ材料からのα線や宇宙線由来の中性子がシリコン中で電荷を発生させ、記憶データが反転する現象です。

    メモリのソフトエラーの説明として正しいものはどれか。

  • そのため、標高の高い場所や航空機の中ではソフトエラーの発生率が地上より高くなります。

    宇宙線に由来する中性子によるソフトエラーの発生率が高くなる環境として正しいものはどれか。

  • 地上の中性子の量は少ないため、実際の環境で十分な数のソフトエラーを観測するには長い時間がかかります。
