SPM(硫酸過水)とは

えすぴーえむ

硫酸と過酸化水素水の混合液。強い酸化力で、レジストなどの有機物を除去する。

「SPM(硫酸過水)」は、1分野の4問の練習問題に出てきます(CMP・洗浄など)。

この用語の分野: CMP・洗浄

SPM(硫酸過水)の練習問題に挑戦

硫酸と過酸化水素水の混合液(SPM)による洗浄の主な目的はどれか。

  1. Aレジストなどの有機物の除去
  2. B自然酸化膜の除去
  3. C銅の成膜
答えと解説を見る

正解：A. レジストなどの有機物の除去

SPM(H2SO4:H2O2、例えば4:1、120〜150 ℃程度)は、混合で生じるペルオキソ一硫酸(カロ酸)の強い酸化力で、レジストの残渣などの有機物を分解して除去します。アッシング後の洗浄や、イオン注入後のレジスト除去などに使われ、「ピラニア溶液」とも呼ばれるほど反応性が高く、取り扱いには注意が必要です。硫酸の使用量が多いため、オゾン水などへの置き換えも進められています。

SPM(硫酸と過酸化水素水)洗浄の後のすすぎが不十分なときに起こりやすい問題として知られているものはどれか。

  1. A表面に硫酸イオンなどが残り、後に曇り(ヘイズ)や欠陥の原因になる
  2. Bウエハが厚くなる
  3. C表面がn型になる
答えと解説を見る

正解：A. 表面に硫酸イオンなどが残り、後に曇り(ヘイズ)や欠陥の原因になる

硫酸は粘性が高く表面に吸着しやすいため、すすぎが不十分だと硫酸イオンが残留し、空気中のアンモニアなどと反応して硫酸アンモニウムの微結晶が析出し、曇り(ヘイズ)や欠陥を生じることがあります。露光のマスクで起こると、透過率を下げる成長性の欠陥(ヘイズ)の原因にもなりました。そのため、温水による十分なすすぎを行ったり、硫酸を使わない洗浄に置き換えたりします。

解説の中の「SPM(硫酸過水)」

  • SPM(H2SO4:H2O2、例えば4:1、120〜150 ℃程度)は、混合で生じるペルオキソ一硫酸(カロ酸)の強い酸化力で、レジストの残渣などの有機物を分解して除去します。

    硫酸と過酸化水素水の混合液(SPM)による洗浄の主な目的はどれか。

  • 使用後は酸素に分解するため廃液処理が容易で、硫酸と過酸化水素を大量に使うSPMなどに比べ、薬液の使用量やCO2排出を減らせる環境負荷の小さい洗浄として利用されています。

    オゾンを溶かした超純水(オゾン水)を洗浄に用いる主な目的はどれか。

  • それぞれに適した薬液(SC-1、SC-2、SPM、希フッ酸など)と物理的な力(ブラシ、メガソニック)を組み合わせて取り除き、材料を傷めないことも同時に求められます。

    洗浄で取り除く対象となるウエハ表面の汚染の種類の組み合わせとして正しいものはどれか。
