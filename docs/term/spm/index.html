SPM(硫酸過水)とは

えすぴーえむ

硫酸と過酸化水素水の混合液。強い酸化力で、レジストなどの有機物を除去する。

この用語の分野: CMP・洗浄

解説の中の「SPM(硫酸過水)」

  • SPM(H2SO4:H2O2、例えば4:1、120〜150 ℃程度)は、混合で生じるペルオキソ一硫酸(カロ酸)の強い酸化力で、レジストの残渣などの有機物を分解して除去します。

    硫酸と過酸化水素水の混合液(SPM)による洗浄の主な目的はどれか。

  • 使用後は酸素に分解するため廃液処理が容易で、硫酸と過酸化水素を大量に使うSPMなどに比べ、薬液の使用量やCO2排出を減らせる環境負荷の小さい洗浄として利用されています。

    オゾンを溶かした超純水(オゾン水)を洗浄に用いる主な目的はどれか。

  • それぞれに適した薬液(SC-1、SC-2、SPM、希フッ酸など)と物理的な力(ブラシ、メガソニック)を組み合わせて取り除き、材料を傷めないことも同時に求められます。

    洗浄で取り除く対象となるウエハ表面の汚染の種類の組み合わせとして正しいものはどれか。

「SPM(硫酸過水)」が出てくる問題(4問)

  1. 硫酸と過酸化水素水の混合液(SPM)による洗浄の主な目的はどれか。
  2. SPM(硫酸と過酸化水素水)洗浄の後のすすぎが不十分なときに起こりやすい問題として知られているものはどれか。
  3. オゾンを溶かした超純水(オゾン水)を洗浄に用いる主な目的はどれか。
  4. 洗浄で取り除く対象となるウエハ表面の汚染の種類の組み合わせとして正しいものはどれか。
