SPM(硫酸過水)とは

えすぴーえむ

硫酸と過酸化水素水の混合液。強い酸化力で、レジストなどの有機物を除去する。

「SPM(硫酸過水)」は、1分野の4問の練習問題に出てきます(CMP・洗浄など)。

この用語の分野: CMP・洗浄

SPMが有機物を分解するしくみ

濃硫酸(H2SO4)と過酸化水素水(H2O2)を混ぜると、きわめて強い酸化剤であるペルオキソ一硫酸(H2SO5、カロ酸)が生成します。硫酸には炭化水素を脱水する作用もあるため、フォトレジストなどの有機膜は分解され、二酸化炭素と水にまで酸化されます。混合比は硫酸:過酸化水素水が約2:1〜4:1、温度はおおむね120〜150 ℃が一般的で、混合時の強い発熱が加熱の一部を担います。使用中に過酸化水素が分解するため、剥離能力を保つよう新しいH2O2を補充します。

プロセスフローでの位置づけ

SPMは、プラズマアッシング後のレジスト残渣の除去や、イオン注入後のレジスト剥離で主力となる薬液です。高ドーズの注入ではレジスト表面が硬化して殻のようになるためです。炉前洗浄の最初の工程として使われることも多く、その後にパーティクル除去のSC-1(アンモニア過水)、金属除去のSC-2(塩酸過水)、酸化膜除去の希フッ酸が続きます。SPMはシリコン上に薄いケミカル酸化膜を残し、シリコンやSiO2はほとんどエッチングしませんが、多くの金属を溶かします。そのためシリサイド形成後の未反応ニッケルの除去に使える一方、銅やアルミニウムが露出した状態では使えません。

SPMとオゾン水の比較

オゾン水は、超純水に数〜数十 ppmのオゾンを溶かしたもので、室温で有機物を酸化できます。使用後は酸素に戻るため廃液処理が簡単です。これに対してSPMは大量の硫酸と過酸化水素水を消費し、加熱や排気、酸の回収設備も必要です。ただし厚いレジストや注入で硬化したレジストに対してはSPMのほうが強力なため、工場では残渣が軽い工程に限って、オゾン系などの硫酸を使わない洗浄に置き換えています。

リンスと安全上の注意

硫酸は粘度が高く表面に強く吸着するため、リンスが短かったり水温が低かったりすると表面に硫酸イオンが残ります。この硫酸イオンが後で大気中のアンモニアと結びつくと硫酸アンモニウムの結晶が成長し、ウエハ上のヘイズや、かつてはフォトマスク上で徐々に増えるヘイズ欠陥として現れました。対策には温超純水によるリンスが有効です。高温のSPMはピラニア溶液とも呼ばれ、有機溶剤と激しく反応し、過酸化水素の分解でガスを発生するため、密閉容器に保管してはいけません。

SPM(硫酸過水)の練習問題に挑戦

硫酸と過酸化水素水の混合液(SPM)による洗浄の主な目的はどれか。

  1. Aレジストなどの有機物の除去
  2. B自然酸化膜の除去
  3. C銅の成膜
答えと解説を見る

正解：A. レジストなどの有機物の除去

SPM(H2SO4:H2O2、例えば4:1、120〜150 ℃程度)は、混合で生じるペルオキソ一硫酸(カロ酸)の強い酸化力で、レジストの残渣などの有機物を分解して除去します。アッシング後の洗浄や、イオン注入後のレジスト除去などに使われ、「ピラニア溶液」とも呼ばれるほど反応性が高く、取り扱いには注意が必要です。硫酸の使用量が多いため、オゾン水などへの置き換えも進められています。

SPM(硫酸と過酸化水素水)洗浄の後のすすぎが不十分なときに起こりやすい問題として知られているものはどれか。

  1. A表面に硫酸イオンなどが残り、後に曇り(ヘイズ)や欠陥の原因になる
  2. Bウエハが厚くなる
  3. C表面がn型になる
答えと解説を見る

正解：A. 表面に硫酸イオンなどが残り、後に曇り(ヘイズ)や欠陥の原因になる

硫酸は粘性が高く表面に吸着しやすいため、すすぎが不十分だと硫酸イオンが残留し、空気中のアンモニアなどと反応して硫酸アンモニウムの微結晶が析出し、曇り(ヘイズ)や欠陥を生じることがあります。露光のマスクで起こると、透過率を下げる成長性の欠陥(ヘイズ)の原因にもなりました。そのため、温水による十分なすすぎを行ったり、硫酸を使わない洗浄に置き換えたりします。

よくある質問

SPMがピラニア溶液と呼ばれるのはなぜですか?

高温の硫酸と過酸化水素水が有機物を非常に激しく侵し、レジストなどの有機物が数分で食い尽くされるためです。この呼び名には、取り扱いが危険な薬液であることへの戒めも込められています。

SPM洗浄とSC-1洗浄の違いは何ですか?

SPMは酸性で酸化力の強い混合液で、レジストのような重度の有機汚染を対象とします。SC-1はアルカリ性のアンモニア過水で、主にパーティクルと軽度の有機物を対象とし、表面をわずかにエッチングしてパーティクルを浮かせて除去します。

SPM処理後に十分なリンスが必要なのはなぜですか?

残った硫酸イオンが後で大気中のアンモニアと反応し、ヘイズや欠陥となる硫酸アンモニウムの結晶を作るおそれがあるためです。通常は温超純水で十分にリンスして除去します。
