投機的実行とは

とうきてきじっこう

分岐の結果などが分かる前に、予測にもとづいて先の命令を実行しておくCPUの仕組み。予測が外れると結果を取り消すが、キャッシュなどの痕跡が残ることがある。

この用語の分野: ハードウェアセキュリティ

解説の中の「投機的実行」

  • Spectreへの対策には、条件分岐の後に投機的実行を止める命令(x86のlfenceなど)を入れる方法、添字をマスクして範囲の外を読めないようにする方法、間接分岐の予測を悪用されないようにする書き方(retpolineなど)、CPUのマイクロコードの更新による予測器の制御などがあります。

    Spectreのような投機的実行の脆弱性への対策として使われているものに当てはまらないものはどれか。

  • 投機的実行、分岐予測、共有のキャッシュは、現在のCPUの高い性能を支える仕組みです。

    投機的実行の脆弱性への対策について、一般的に正しいものはどれか。

  • ソフトウェアが正しく書かれていても、性能のための投機的実行やキャッシュ、処理によって変わる消費電力や時間、電圧や温度の異常による誤動作、製造の途中で仕込まれた回路などから、秘密が漏れたり守りが破られたりすることがあります。

    ハードウェアセキュリティで扱う問題の説明として最も適切なものはどれか。

「投機的実行」が出てくる問題(5問)

  1. 投機的実行の痕跡がキャッシュに残ることを悪用し、本来アクセスできないデータを推測する攻撃が明らかになった脆弱性の例はどれか。
  2. Spectreと呼ばれる投機的実行の脆弱性の原理として正しいものはどれか。
  3. Spectreのような投機的実行の脆弱性への対策として使われているものに当てはまらないものはどれか。
  4. 投機的実行の脆弱性への対策について、一般的に正しいものはどれか。
  5. ハードウェアセキュリティで扱う問題の説明として最も適切なものはどれか。
