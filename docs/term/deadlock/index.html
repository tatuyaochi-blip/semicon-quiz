デッドロックとは

でっどろっく

複数のスレッドがそれぞれ資源を持ったまま、ほかのスレッドが持つ資源を待ち合い、誰も先に進めなくなる状態。ロックを取る順番を全体で決めて防ぐ。

この用語の分野: マルチコアと同期

解説の中の「デッドロック」

  • デッドロックは、複数のスレッドがそれぞれ資源を持ったまま、ほかのスレッドが持つ資源を待ち合い、誰も先に進めなくなる状態です。

    デッドロックの例として正しいものはどれか。

  • デッドロックは、スレッドが互いに相手の持つロックを待つ「輪」ができると起こります。

    複数のロックを使うプログラムで、デッドロックを防ぐ方法として最も一般的なものはどれか。

  • デッドロックは互いの資源を待ち合って止まる状態です。
