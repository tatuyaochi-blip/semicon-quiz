CASレイテンシとは

きゃすれいてんし

DRAMで、列アドレスを指定した読み出しコマンドから、データが出力されるまでのクロック数。CLと略す。値が小さいほど応答が速い。

この用語の分野: DRAM

解説の中の「CASレイテンシ」

  • CASレイテンシは、列アドレスを指定する読み出しコマンドから最初のデータが出るまでのクロック数です。

    DRAMのCASレイテンシ(CL)の意味として正しいものはどれか。

  • 同じ行であれば活性化をやり直さず列アドレスを変えるだけ(CASレイテンシ分の時間)で読み出せるため、別の行に移る場合(プリチャージ+活性化+列アクセス)より速くなります。

    DRAMで、同じ行(ページ)に連続してアクセスするとアクセス時間が短くなる理由として正しいものはどれか。

「CASレイテンシ」が出てくる問題(2問)

  1. DRAMのCASレイテンシ(CL)の意味として正しいものはどれか。
  2. DRAMで、同じ行(ページ)に連続してアクセスするとアクセス時間が短くなる理由として正しいものはどれか。
