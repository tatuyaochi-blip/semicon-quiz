酸窒化膜(SiON)とは

さんちっかまく

ゲート酸化膜に窒素を導入した膜。ゲート電極からのボロンの突き抜けを抑え、誘電率もわずかに高くなるため、High-k膜の導入前のゲート絶縁膜に使われた。

この用語の分野: 酸化・拡散

解説の中の「酸窒化膜(SiON)」

  • 酸素より穏やかに反応するため気相で粒子ができにくく、条件によっては窒素を取り込んだ酸窒化膜(SiON)もつくれます。

    シランとともにCVDでシリコン酸化膜や酸窒化膜をつくるとき、酸化剤として使われることのあるガスはどれか。

  • 窒素を加えたSiONは5〜6程度、窒化膜(Si3N4)は約7、High-k材料の酸化ハフニウムは約20〜25です。

    熱酸化で形成したSiO2膜の比誘電率に最も近い値はどれか。

  • プラズマ窒化では、窒素のプラズマでつくった活性な窒素を、数百℃程度の比較的低い温度で酸化膜の表面付近に導入し、窒素を10〜20%程度含む酸窒化膜(SiON)にします。

    薄いゲート酸化膜の表面に、プラズマで生成した窒素を導入する処理を何と呼ぶか。

「酸窒化膜(SiON)」が出てくる問題(4問)

  1. ゲート酸化膜に窒素を導入して酸窒化膜(SiON)にする主な目的はどれか。
  2. シランとともにCVDでシリコン酸化膜や酸窒化膜をつくるとき、酸化剤として使われることのあるガスはどれか。
  3. 熱酸化で形成したSiO2膜の比誘電率に最も近い値はどれか。
  4. 薄いゲート酸化膜の表面に、プラズマで生成した窒素を導入する処理を何と呼ぶか。
