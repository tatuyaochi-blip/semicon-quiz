トライステートバッファとは

とらいすてーとばっふぁ

0と1に加えて、出力を切り離した高インピーダンスの状態をとれるバッファ。複数の回路が1本のバスを共有するときに、出力の衝突を防ぐ。

「トライステートバッファ」は、1分野の1問の練習問題に出てきます(論理回路など)。

この用語の分野: 論理回路

トライステートバッファの練習問題に挑戦

トライステートバッファの出力がとりうる3つ目の状態はどれか。

  1. A電源電圧の半分の電圧を出す状態
  2. B0と1を高速に繰り返す状態
  3. C出力を切り離して高インピーダンスにする状態
答えと解説を見る

正解：C. 出力を切り離して高インピーダンスにする状態

トライステートバッファは、0と1に加えて出力を切り離した高インピーダンス(Hi-Z)状態をとれます。複数の回路が1本のバスを共有するとき、使わない回路をHi-Zにして信号の衝突を防ぎ、双方向の入出力端子にも使われます。同時に2つが出力するとバスの衝突で大電流が流れるため、制御信号の管理が重要です。全員がHi-Zだと線の電位が定まらないので、プルアップなどで値を固定します。

解説の中の「トライステートバッファ」

  • トライステートバッファは、0と1に加えて出力を切り離した高インピーダンス(Hi-Z)状態をとれます。
