フルアソシアティブ方式とは

ふるあそしあてぃぶほうしき

どのデータもキャッシュ内のどの場所にでも置けるキャッシュの構成。競合ミスは起こらないが、すべてのタグと比べる必要があり、大きなキャッシュには向かない。TLBなどに使われる。

「フルアソシアティブ方式」は、2分野の6問の練習問題に出てきます(メモリ階層と性能, CPU・アーキテクチャなど)。

この用語の分野: メモリ階層と性能

フルアソシアティブ方式の練習問題に挑戦

フルアソシアティブ方式のキャッシュで、アドレスのうちインデックス(セットを選ぶ部分)に使うビット数はどれか。

  1. Aラインサイズで決まる6ビット
  2. Bライン数と同じだけのビット
  3. C0ビット
答えと解説を見る

正解：C. 0ビット

フルアソシアティブ方式では、どのデータもキャッシュ内のどの場所にでも置けるため、セットは全体で1つしかありません。セットを選ぶ必要がないのでインデックスは0ビットで、アドレスはオフセットとタグだけに分かれ、アクセスのたびにすべてのラインのタグと比べます。そのため比較器が多く必要で、大きなキャッシュには向かず、TLBなどの小さな構造に使われます。ラインサイズで決まるのはオフセットのビット数で、インデックスではありません。

キャッシュをフルアソシアティブ方式にしても減らないミスとして正しいものはどれか。

  1. A2つのデータが同じセットを取り合い、互いに追い出し合うことによるミス
  2. B使うデータの量がキャッシュの容量より大きいことによるミス
  3. Cダイレクトマップの配置の偏りによるミス
答えと解説を見る

正解：B. 使うデータの量がキャッシュの容量より大きいことによるミス

フルアソシアティブ方式ではどのデータもどこにでも置けるので、同じセットの取り合いによる競合ミスはなくなります。しかし、プログラムが繰り返し使うデータの量(ワーキングセット)がキャッシュ全体より大きければ、どこに置いても入りきらずに追い出しが起こります。これが容量ミスで、キャッシュを大きくするか、ループブロッキングなどで再利用の範囲を小さくする必要があります。配置の偏りやセットの取り合いは、どちらも競合ミスの原因です。

解説の中の「フルアソシアティブ方式」

  • フルアソシアティブ方式では、どのデータもキャッシュ内のどの場所にでも置けるため、セットは全体で1つしかありません。

    フルアソシアティブ方式のキャッシュで、アドレスのうちインデックス(セットを選ぶ部分)に使うビット数はどれか。

  • フルアソシアティブ方式ではどのデータもどこにでも置けるので、同じセットの取り合いによる競合ミスはなくなります。

    キャッシュをフルアソシアティブ方式にしても減らないミスとして正しいものはどれか。

  • どこにでも置けるのはフルアソシアティブ方式です。

    セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。

  • キャッシュ全体のライン数だけ比べるのはフルアソシアティブ方式、1個だけ比べるのはダイレクトマップ方式です。

    8ウェイ・セットアソシアティブ方式のキャッシュで、1回のアクセスのたびに並列に比べるタグの数はいくつか。

「フルアソシアティブ方式」が出てくる問題(6問)

  1. フルアソシアティブ方式のキャッシュで、アドレスのうちインデックス(セットを選ぶ部分)に使うビット数はどれか。
  2. キャッシュをフルアソシアティブ方式にしても減らないミスとして正しいものはどれか。
  3. 容量2ラインのフルアソシアティブ方式でLRU置き換えのキャッシュが最初は空のとき、ブロックをA、B、A、C、B、Aの順に参照すると、ミスは何回起こるか。
  4. 小容量のフルアソシアティブ方式のバッファに、L1キャッシュから追い出されたラインを一時的に保持するビクティムキャッシュの主な効果はどれか。
  5. セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。
  6. 8ウェイ・セットアソシアティブ方式のキャッシュで、1回のアクセスのたびに並列に比べるタグの数はいくつか。
