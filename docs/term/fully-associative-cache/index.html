フルアソシアティブ方式とは

ふるあそしあてぃぶほうしき

どのデータもキャッシュ内のどの場所にでも置けるキャッシュの構成。競合ミスは起こらないが、すべてのタグと比べる必要があり、大きなキャッシュには向かない。TLBなどに使われる。

この用語の分野: メモリ階層と性能

解説の中の「フルアソシアティブ方式」

  • フルアソシアティブ方式では、どのデータもキャッシュ内のどの場所にでも置けるため、セットは全体で1つしかありません。

    フルアソシアティブ方式のキャッシュで、アドレスのうちインデックス(セットを選ぶ部分)に使うビット数はどれか。

  • フルアソシアティブ方式ではどのデータもどこにでも置けるので、同じセットの取り合いによる競合ミスはなくなります。

    キャッシュをフルアソシアティブ方式にしても減らないミスとして正しいものはどれか。

  • どこにでも置けるのはフルアソシアティブ方式です。

    セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。

「フルアソシアティブ方式」が出てくる問題(6問)

  1. フルアソシアティブ方式のキャッシュで、アドレスのうちインデックス(セットを選ぶ部分)に使うビット数はどれか。
  2. キャッシュをフルアソシアティブ方式にしても減らないミスとして正しいものはどれか。
  3. 容量2ラインのフルアソシアティブ方式でLRU置き換えのキャッシュが最初は空のとき、ブロックをA、B、A、C、B、Aの順に参照すると、ミスは何回起こるか。
  4. 小容量のフルアソシアティブ方式のバッファに、L1キャッシュから追い出されたラインを一時的に保持するビクティムキャッシュの主な効果はどれか。
  5. セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。
  6. 8ウェイ・セットアソシアティブ方式のキャッシュで、1回のアクセスのたびに並列に比べるタグの数はいくつか。
