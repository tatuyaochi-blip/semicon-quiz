故障検出率(フォールトカバレッジ)とは

こしょうけんしゅつりつ

想定した故障のうち、そのテストパターンで検出できる故障の割合。高いほど不良品を見逃しにくい。

「故障検出率(フォールトカバレッジ)」は、2分野の6問の練習問題に出てきます(テスト・検査, 車載半導体と機能安全など)。

この用語の分野: テスト・検査

数値の前提となる故障モデル

故障検出率は常に故障モデルに対する値です。故障モデルとは、物理的な欠陥が論理にどう影響するかを抽象化したものです。古典的な縮退故障モデルは、回路の各ノードが0または1に固定されてしまう可能性を想定します。遷移遅延故障はスイッチングが遅すぎるノードを、ブリッジ故障は配線間の短絡を、セルアウェアモデルはスタンダードセル内部の欠陥をモデル化します。故障検出率は、検出された故障数をモデル化した故障数で割った値です。多くのツールはテストカバレッジも報告しますが、これはテスト不能と証明された故障を分母から除くため、故障検出率より高い値になります。

スキャンとATPGで高い検出率を得る

順序回路を直接テストするのは困難です。内部状態に到達するには長い入力系列が必要だからです。スキャン設計では各フリップフロップの入力にマルチプレクサを追加し、テストモードでフリップフロップをつないでシフトレジスタにします。これにより任意の状態をシフトインし、結果をシフトアウトできるようになり、問題を組み合わせ回路のテストに置き換えられます。そのうえで、自動テストパターン生成(ATPG)によって、モデル化した各故障を対象とするパターンを生成します。到達しにくい故障はテストポイントを挿入して検出可能にでき、量産では縮退故障の検出率の目標を99%を大きく超える値にするのが一般的です。

検出率から見逃し不良へ

ウィリアムズ・ブラウンの式は、出荷品の不良率をDL = 1 − Y^(1−T)と見積もります。ここでYは歩留まり、Tは故障検出率です。Y = 0.5、T = 0.99のときDLは約0.7%、つまりおよそ7,000 DPPM(100万個あたりの不良数)となり、最後のわずかな割合が重要である理由がわかります。この式は欠陥がモデル化した故障と同じように振る舞うことを前提としていますが、実際の欠陥は必ずしもそうではありません。そのためメーカーは、縮退故障のパターンでは見逃す欠陥を捕らえるために、実速度テスト、追加の故障モデル、その他のスクリーニングを加えています。

故障検出率と診断カバレッジ

製造テストの故障検出率は、出荷前のテストで不良チップをどれだけ見つけられるかを表します。一方、車載エレクトロニクスの機能安全規格で使われる診断カバレッジは、動作中にチップ上の安全機構が検出または制御できる故障の割合を表します。たとえば故障率200 FITのブロックを診断カバレッジ99%の安全機構で保護すると、検出されない残留故障率は200 × 0.01 = 2 FITになります。ここで1 FITは10億デバイス時間あたり1件の故障です。どちらも似た計算を使いますが、答えている問いは異なります。

故障検出率(フォールトカバレッジ)の練習問題に挑戦

テストパターンの故障検出率(フォールトカバレッジ)の定義として正しいものはどれか。

  1. A想定した故障のうち、そのテストで検出できる故障の割合
  2. B出荷した製品のうち不良品の割合
  3. Cウエハ上の良品チップの割合
答えと解説を見る

正解：A. 想定した故障のうち、そのテストで検出できる故障の割合

故障検出率は、モデル化した全故障のうち、テストパターンで検出できる故障の割合です。見逃される不良の割合は、歩留まりY・故障検出率Tを使ってDL=1−Y^(1−T)と見積もられ、Y=0.5・T=99%でも約0.7%(約7000 DPPM)になります。そのため車載用などでは99%を大きく超える値が求められます。出荷品の不良率や歩留まりそのものとは別の指標です。

よくある質問

故障検出率とテストカバレッジの違いは何ですか?

故障検出率は検出された故障数をモデル化したすべての故障数で割った値で、テストカバレッジはテスト不能と証明された故障を分母から除いた値です。そのためテストカバレッジは故障検出率以上の値になります。

故障検出率とDPPMはどう関係しますか?

ウィリアムズ・ブラウンのモデルでは、不良率は1 − Y^(1−T)で表されます。歩留まり50%、検出率99%では約0.7%、およそ7,000 DPPMとなるため、見逃し率を低くするには非常に高い検出率が必要です。

スキャンATPGでの故障検出率の目安はどのくらいですか?

量産では縮退故障の検出率を99%を大きく超える値にするのが一般的な目標です。車載製品ではさらに高い値を目指し、遷移遅延故障などの故障モデルも追加します。

「故障検出率(フォールトカバレッジ)」が出てくる問題(6問)

  1. テストパターンの故障検出率(フォールトカバレッジ)の定義として正しいものはどれか。
  2. 故障率200 FITの回路に、診断カバレッジ99%の安全機構を設けた。安全機構で検出されずに残る故障の故障率はいくらか。
  3. テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。
  4. 論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。
  5. 回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。
  6. 論理回路のテストで、スキャンなどを使って回路の構造上の故障(縮退故障など)を網羅的に検出するテストと、実際の動作どおりに機能を確認するテストの呼び方の組み合わせとして正しいものはどれか。
