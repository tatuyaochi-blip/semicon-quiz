故障検出率(フォールトカバレッジ)とは

こしょうけんしゅつりつ

想定した故障のうち、そのテストパターンで検出できる故障の割合。高いほど不良品を見逃しにくい。

「故障検出率(フォールトカバレッジ)」は、1分野の5問の練習問題に出てきます(テスト・検査など)。

この用語の分野: テスト・検査

故障検出率(フォールトカバレッジ)の練習問題に挑戦

テストパターンの故障検出率(フォールトカバレッジ)の定義として正しいものはどれか。

  1. A想定した故障のうち、そのテストで検出できる故障の割合
  2. B出荷した製品のうち不良品の割合
  3. Cウエハ上の良品チップの割合
答えと解説を見る

正解：A. 想定した故障のうち、そのテストで検出できる故障の割合

故障検出率は、モデル化した全故障のうち、テストパターンで検出できる故障の割合です。見逃される不良の割合は、歩留まりY・故障検出率Tを使ってDL=1−Y^(1−T)と見積もられ、Y=0.5・T=99%でも約0.7%(約7000 DPPM)になります。そのため車載用などでは99%を大きく超える値が求められます。出荷品の不良率や歩留まりそのものとは別の指標です。

「故障検出率(フォールトカバレッジ)」が出てくる問題(5問)

  1. テストパターンの故障検出率(フォールトカバレッジ)の定義として正しいものはどれか。
  2. テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。
  3. 論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。
  4. 回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。
  5. 論理回路のテストで、スキャンなどを使って回路の構造上の故障(縮退故障など)を網羅的に検出するテストと、実際の動作どおりに機能を確認するテストの呼び方の組み合わせとして正しいものはどれか。
