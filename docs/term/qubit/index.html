量子ビットとは

りょうしびっと

量子コンピュータで情報を表す単位。|0⟩と|1⟩の重ね合わせ α|0⟩ + β|1⟩ の状態をとることができ、測定すると確率 |α|² で0、|β|² で1が得られる。超伝導回路、イオン、中性原子、シリコン中の電子のスピン、光子などで実現される。

「量子ビット」は、1分野の34問の練習問題に出てきます(量子コンピュータのハードウェアなど)。

この用語の分野: 量子コンピュータのハードウェア

状態の表し方と測定

1つの量子ビットの状態は α|0⟩ + β|1⟩ と書け、α と β は |α|² + |β|² = 1 を満たす複素数(確率振幅)です。測定すると確率 |α|² で0、|β|² で1が得られ、状態は得られた結果の方に変わります。1回の測定では確率そのものは分からないので、同じ回路を何度も繰り返して(ショットと呼びます)結果の割合から推定します。確率が0.5のとき、1万回繰り返しても推定値の標準偏差は約0.5%残ります。状態はブロッホ球の上の点として表すことができ、量子ゲートの操作はその球の回転に当たります。

n 量子ビットと 2ⁿ 個の振幅

n 個の量子ビットの状態には 2ⁿ 個の確率振幅があり、50量子ビットでは約10¹⁵個になります。これを倍精度の複素数で古典コンピュータに保存すると約18 PB が必要で、量子ビットが1個増えるごとに2倍になります。ただし、測定で得られるのは n ビットだけで、振幅をすべて読み出すことはできません。量子アルゴリズムは、干渉によって正しい答えの振幅を大きくし、間違った答えの振幅を打ち消すように設計されます。

物理的な実現方法

超伝導回路(トランズモン)では、約5 GHz の2つのエネルギー準位を量子ビットにし、10 mK 程度まで冷やして動かします。イオントラップや中性原子では原子のエネルギー準位を、シリコンのスピン量子ビットでは量子ドットに閉じ込めた電子のスピンの向きを、光量子方式では光子の偏光や通る経路などを使います。どの方式でも、量子ビットの数だけでなく、ゲートの誤り率、コヒーレンス時間、量子ビットどうしのつながり方が性能を決めます。誤り訂正では、多数の物理量子ビットで1つの論理量子ビットを作ります。

量子ビットの練習問題に挑戦

量子ビットについての説明として正しいものはどれか。

  1. A0と1の中間の電圧を保持するアナログの記憶素子で、読み出すと中間の値がそのまま得られる
  2. B|0⟩と|1⟩の重ね合わせの状態をとることができ、測定すると確率的に0か1のどちらか一方が得られる
  3. C0と1を同時に保持しているので、1回の測定で0と1の両方の値を読み出せる
答えと解説を見る

正解：B. |0⟩と|1⟩の重ね合わせの状態をとることができ、測定すると確率的に0か1のどちらか一方が得られる

量子ビットの状態は α|0⟩ + β|1⟩ と書け、α と β は |α|² + |β|² = 1 を満たす複素数(確率振幅)です。測定すると、確率 |α|² で0、確率 |β|² で1が得られ、状態は得られた結果の方に変わります。重ね合わせは「0と1の中間の値」ではなく、測定で得られるのは常に0か1のどちらか一方です。1回の測定で得られる情報は1ビットだけで、α と β の値そのものを直接読み出すことはできません。

量子ビットが (√3/2)|0⟩ + (1/2)|1⟩ の状態にあるとき、測定して1が得られる確率はどれか。

  1. A25%
  2. B50%
  3. C75%
答えと解説を見る

正解：A. 25%

測定で1が得られる確率は、|1⟩の確率振幅の絶対値の2乗で、(1/2)² = 1/4 = 25%です。0が得られる確率は (√3/2)² = 3/4 = 75%で、両者の和は100%になります。振幅の1/2をそのまま確率と考えると、50%と誤ります。

よくある質問

n 個の量子ビットからは、何ビットの情報を取り出せますか?

測定で取り出せる古典的な情報は、最大で n ビットです。2ⁿ 個の振幅を保持していても、それを全部読み出すことはできません。量子コンピュータの速さは、多くの情報を読み出せることではなく、干渉を使って答えにたどり着く手順の数を減らせることから生まれます。

物理量子ビットと論理量子ビットの違いは何ですか?

物理量子ビットは、装置に実際に作り込まれた1個1個の量子ビットです。論理量子ビットは、量子誤り訂正によって多数の物理量子ビットをまとめ、誤りに強くした1つの量子ビットです。表面符号では、1つの論理量子ビットに数百個以上の物理量子ビットが必要になることがあります。

「量子ビット」が出てくる問題(34問)

  1. 量子ビットについての説明として正しいものはどれか。
  2. 量子ビットが (√3/2)|0⟩ + (1/2)|1⟩ の状態にあるとき、測定して1が得られる確率はどれか。
  3. 1つの量子ビットの状態をブロッホ球で表したとき、赤道上の点が表す状態はどれか。
  4. 10個の量子ビットからなる系の一般の状態を表すのに必要な、確率振幅(複素数)の数はどれか。
  5. 50量子ビットの状態ベクトル(すべての確率振幅)を、1個16バイトの倍精度複素数で古典コンピュータのメモリに保存するとき、必要な容量に最も近いものはどれか。
  6. 2つの量子ビットが (|00⟩ + |11⟩)/√2 の量子もつれ状態にあるときの説明として、正しいものはどれか。
  7. 1量子ビットの X ゲートの働きとして正しいものはどれか。
  8. |0⟩の状態の量子ビットにアダマール(H)ゲートを1回作用させてから測定したとき、1が得られる確率はどれか。
  9. 2量子ビットの|00⟩(左が1つ目の量子ビット)に対して、1つ目に H ゲートを作用させ、続いて1つ目を制御ビット、2つ目を標的ビットとする CNOT ゲートを作用させた。得られる状態はどれか。
  10. |0⟩の量子ビットに H、Z、H の順にゲートを作用させてから測定したとき、1が得られる確率はどれか。
  11. 量子ビットのエネルギー緩和時間 T1 の説明として正しいものはどれか。
  12. 量子ビットの位相緩和時間 T2 とエネルギー緩和時間 T1 の関係として、正しいものはどれか。
  13. 1回あたりの忠実度が99.5%(誤り率0.5%)の2量子ビットゲートを100回続けて使う回路で、誤りがそれぞれ独立に起こるとしたとき、途中で1回も誤りが起きない確率に最も近いものはどれか。
  14. 量子コンピュータの性能を、量子ビットの数だけで比べられない理由として最も適切なものはどれか。
  15. 超伝導量子ビット(トランズモン)が量子ビットとして働くために欠かせない素子はどれか。
