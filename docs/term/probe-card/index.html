プローブカードとは

ぷろーぶかーど

ウエハの状態でチップの電極に多数の針(プローブ)を当て、テスタと電気的につなぐための治具。

この用語の分野: テスト・検査

解説の中の「プローブカード」

  • プローブカードは、チップの電極パッドの配置に合わせて多数の針を並べた、品種ごとの専用治具です。

    プローブカードの説明として正しいものはどれか。

  • ウエハテストでは、プローブカードの多数の針を、各チップの周辺などに並んだ電極パッドに接触させ、テスタから電源や信号を加えて応答を測ります。

    ウエハテストで、プローブカードの針を接触させるチップ上の場所はどれか。

  • リードフレームは端子、プローブカードはテスト用の部品です。

    発熱の大きいプロセッサのパッケージで、チップの上に載せて熱を広げる金属の板を何と呼ぶか。

「プローブカード」が出てくる問題(5問)

  1. プローブカードの説明として正しいものはどれか。
  2. ウエハテストで、プローブカードの針を接触させるチップ上の場所はどれか。
  3. プローブカードの方式で、針をパッドに対して垂直に立てて並べる垂直型の主な利点はどれか。
  4. 発熱の大きいプロセッサのパッケージで、チップの上に載せて熱を広げる金属の板を何と呼ぶか。
  5. ウエハテスト(プローブテスト)の説明として正しいものはどれか。
