LPCVD(減圧CVD)とは

えるぴーしーぶいでぃー

減圧下で行う熱CVD。気体分子の拡散が速くなるため膜厚の均一性や段差被覆性がよく、多数のウエハを縦型炉で一度に処理できる。ポリシリコンや窒化膜の成膜に使われる。

この用語の分野: 成膜(CVD・PVD)

解説の中の「LPCVD(減圧CVD)」

  • LPCVDは、数十〜数百Pa程度に減圧して行う熱CVDです。

    減圧CVD(LPCVD)の特徴として正しいものはどれか。

  • LPCVDによるシリコン窒化膜は、ジクロロシラン(SiH2Cl2)とアンモニア(NH3)を700〜800 ℃程度で反応させてつくるのが一般的で(3SiH2Cl2 + 4NH3 → Si3N4 + 6HCl + 6H2)、化学量論に近い緻密な膜が得られます。

    熱CVDでシリコン窒化膜(Si3N4)を成膜するときに使われる原料ガスの組み合わせとして正しいものはどれか。

  • 例えばLPCVDの窒化膜の水素は数%以下ですが、プラズマCVDの窒化膜では20%前後含まれることもあります。

    同じ材料の膜で比べたとき、高温の熱CVD膜がプラズマCVD膜より一般に優れている点はどれか。

「LPCVD(減圧CVD)」が出てくる問題(6問)

  1. 減圧CVD(LPCVD)の特徴として正しいものはどれか。
  2. LPCVDでポリシリコン膜を成膜するときに一般的に使われる原料ガスはどれか。
  3. LPCVDでポリシリコン膜を成膜しながら、リンなどの不純物を含むガスを同時に流して導電性の膜をつくることを何と呼ぶか。
  4. 熱CVDでシリコン窒化膜(Si3N4)を成膜するときに使われる原料ガスの組み合わせとして正しいものはどれか。
  5. 同じ材料の膜で比べたとき、高温の熱CVD膜がプラズマCVD膜より一般に優れている点はどれか。
  6. CVD装置の方式で、ウエハを置く台だけを加熱し、反応炉の壁は低温に保つ方式はどれか。
