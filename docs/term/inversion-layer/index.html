反転層とは

はんてんそう

ゲート電圧によって半導体表面に、もとの型と逆のキャリアが集まってできる層。MOSFETのチャネルになる。

この用語の分野: MOSFET

解説の中の「反転層」

  • 反転層の電子は、界面の強い電界で狭い井戸に閉じ込められるため、量子力学的な効果で界面のすぐそばではなく約1 nm内側に分布のピークをもちます。

    ゲート絶縁膜が非常に薄いMOSFETで、反転層の電子の分布のピークが界面から少し離れた位置にくることによる影響として正…

  • エンハンスメント型のnMOSFETでは、ゲートにVthを超える正の電圧を加えると、p型基板の表面に電子が引き寄せられて反転層(チャネル)ができ、ソースとドレインの間に電流が流れます。

    エンハンスメント型のnチャネルMOSFETがオン(導通)するための条件として正しいものはどれか。(VGS:ゲート-ソー…

  • nMOSでは電子、pMOSでは正孔がチャネルを流れ、シリコンの反転層では電子の移動度が正孔の約2〜3倍あるため、同じ寸法ならnMOSのほうが大きな電流を流せます。

    同じ寸法のnMOSとpMOSでは、一般にnMOSの方が駆動電流が大きい。その主な理由はどれか。

「反転層」が出てくる問題(7問)

  1. ゲート絶縁膜が非常に薄いMOSFETで、反転層の電子の分布のピークが界面から少し離れた位置にくることによる影響として正しいものはどれか。
  2. エンハンスメント型のnチャネルMOSFETがオン(導通)するための条件として正しいものはどれか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  3. 同じ寸法のnMOSとpMOSでは、一般にnMOSの方が駆動電流が大きい。その主な理由はどれか。
  4. エンハンスメント型pチャネルMOSFETのしきい値電圧(ソース基準)の符号はどれか。
  5. nチャネルMOSFETのチャネルで電流を運ぶキャリアはどれか。
  6. p型基板のMOSキャパシタを高周波で測定したC-V特性で、ゲートに大きな正の電圧を加えて強反転させたときの容量はどうなるか。
  7. EOT(等価酸化膜厚)の説明として正しいものはどれか。
