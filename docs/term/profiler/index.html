プロファイラとは

ぷろふぁいら

プログラムのどの関数や部分が実行時間を多く使っているかを測る道具。サンプリング方式と計測(インストルメンテーション)方式がある。

「プロファイラ」は、2分野の9問の練習問題に出てきます(性能評価・プロファイリング, GPUプログラミングなど)。

この用語の分野: 性能評価・プロファイリング

サンプリング方式と計測方式

サンプリング方式のプロファイラは、タイマやハードウェア性能カウンタのオーバーフローを使って実行中のプログラムに一定間隔で割り込み、その時点の命令アドレスと、多くの場合コールスタックを記録します。その回数は毎秒数千回に及ぶこともあります。時間を多く使う関数ほど頻繁に捕まるので、サンプル数から時間の使われ方を統計的に推定でき、オーバーヘッドが小さく、プログラムを変更する必要もありません。一方、計測(インストルメンテーション)方式のプロファイラは、関数の入口と出口や基本ブロックにコードを挿入します。呼び出し回数を正確に数えられますが、オーバーヘッドが加わり、特に小さく頻繁に呼ばれる関数ではタイミングが歪むことがあります。

プロファイル結果の読み方

プロファイラは通常、関数自身のコードで使った自己時間(セルフタイム)と、呼び出した関数の時間も含めた包含時間(インクルーシブタイム)を報告します。フラットプロファイルは関数を自己時間の順に並べ、コールグラフやフレームグラフはどの呼び出し経路がコストにつながっているかを示します。よくある発見は、コードのわずか数パーセント、多くは内側のループが実行時間の大半を占めるホットスポットです。多くのプロファイラはキャッシュミスや分岐予測ミスなどのハードウェア性能カウンタも読み取れるので、ホットスポットの場所だけでなく、なぜ遅いのかを説明する手がかりになります。

プロファイリングとアムダールの法則

アムダールの法則によれば、実行時間のうち割合fの部分をs倍に高速化したときの全体の速度向上率は1 / ((1 − f) + f/s)です。実行時間の1 %を占めるコードを無限に速くしても約1 %しか改善せず、80 %を占めるコードを2倍速くすれば全体で約1.7倍になります。時間がどこで使われているかについての直感は外れることが多いため、確実な進め方は、測定し、最も大きな要因を最適化し、同じ条件で再び測定して、改善を確認するとともに他の部分が悪化していないかを確かめることです。

GPUのプロファイリングと名前の注意点

GPUプログラムでは、まずタイムライン表示で、全体の時間がカーネルの実行、CPUとGPUの間のデータ転送、CPU側の処理にどう配分されているか、転送が計算と重なっているかを確認します。カーネルの実行が大半を占める場合に限り、メモリアクセスパターンやオキュパンシを調べる価値があります。オキュパンシは高ければ自動的に速くなるわけではありません。なお、半導体の計測分野では「プロファイラ」がまったく別のものを指すことがあります。触針式プロファイラは細い触針をウエハ上でなぞり、ミリメートル単位の距離にわたって段差、エッチング深さ、平坦性を測定する装置で、分解能は原子間力顕微鏡(AFM)より粗くなります。

プロファイラの練習問題に挑戦

プログラムの性能を改善するときにプロファイラを使う目的として正しいものはどれか。

  1. Aプログラムの文法の誤りを見つける
  2. Bプログラムの利用者の数を数える
  3. Cプログラムのどの関数や部分が、実行時間の多くを使っているかを調べる
答えと解説を見る

正解：C. プログラムのどの関数や部分が、実行時間の多くを使っているかを調べる

多くのプログラムでは、実行時間の大部分がごく一部のコードで使われています。しかし、どこが遅いかを人が推測すると外れることがよくあります。プロファイラは、関数ごとの実行時間や呼ばれた回数、さらには行ごとや命令ごとの時間を測って示します。アムダールの法則のとおり、時間を多く使っている部分を改善するのが効果的なので、まず測ることが性能の改善の第一歩です。

サンプリング方式のプロファイラの特徴として正しいものはどれか。

  1. Aすべての関数の出入りを1回も漏らさず記録する
  2. B一定の間隔でプログラムを割り込み、そのとき実行していた場所を記録して、多く記録された場所を時間を使っている場所とみなす
  3. Cプログラムのソースコードを読むだけで、実行はしない
答えと解説を見る

正解：B. 一定の間隔でプログラムを割り込み、そのとき実行していた場所を記録して、多く記録された場所を時間を使っている場所とみなす

サンプリング方式では、タイマや性能カウンタの割り込みで、例えば1秒に数千回、実行中の命令の場所(と呼び出しの連なり)を記録します。時間を多く使う場所ほど記録される回数が多くなるので、統計的にどこが重いかが分かります。プログラムを書き換えないので測定による遅れが小さく、実際に近い状態で測れますが、ごく短い処理の正確な回数などは分かりません。

よくある質問

サンプリング方式と計測方式のプロファイラの違いは?

サンプリング方式はプログラムが実行している場所を定期的に記録し、小さなオーバーヘッドで時間を統計的に推定します。計測方式は関数やブロックに測定用のコードを追加するので正確な回数がわかりますが、プログラムが遅くなり、結果が歪むこともあります。

プロファイリングでいうホットスポットとは何ですか?

ループや少数の関数など、実行時間の大きな割合を占めるコードの小さな領域のことです。ホットスポットを最適化すると、手間に対して最も大きな効果が得られます。

プロファイラを使うとプログラムは遅くなりますか?

多少は遅くなります。サンプリング方式のオーバーヘッドは通常小さいものの、計測方式は特に短い関数を多数包む場合に大きなオーバーヘッドが生じることがあります。
