静的ライブラリとは

せいてきらいぶらり

多くのオブジェクトファイルを1つにまとめたアーカイブ(Linuxでは.a)。静的リンクのとき、リンカは必要なオブジェクトだけを取り出して実行ファイルに組み込む。

この用語の分野: リンカ・ローダと実行形式

解説の中の「静的ライブラリ」

  • 静的ライブラリは、たくさんのオブジェクトファイルを1つにまとめたアーカイブです。

    静的ライブラリ(.aファイル)と一緒にリンクするとき、リンカが実行ファイルに組み込むものとして正しいものはどれか。

  • GNUのリンカは、コマンドラインに書かれた順にファイルを処理し、静的ライブラリに出会った時点で「まだ定義が見つかっていない参照」を解決するオブジェクトだけを取り出します。

    GNUのリンカで「gcc -lmylib main.o」のように、静的ライブラリをそれを使うオブジェクトファイルより前…

  • 静的リンクでは、リンカが静的ライブラリ(Linuxでは.aファイル)から必要な関数を取り出して実行ファイルに組み込みます。

    静的リンクの説明として正しいものはどれか。

「静的ライブラリ」が出てくる問題(3問)

  1. 静的ライブラリ(.aファイル)と一緒にリンクするとき、リンカが実行ファイルに組み込むものとして正しいものはどれか。
  2. GNUのリンカで「gcc -lmylib main.o」のように、静的ライブラリをそれを使うオブジェクトファイルより前に書くと、未定義の参照のエラーになることがある。その理由として正しいものはどれか。
  3. 静的リンクの説明として正しいものはどれか。
