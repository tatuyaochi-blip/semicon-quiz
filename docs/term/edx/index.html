EDX(エネルギー分散型X線分光)とは

いーでぃーえっくす

電子線を当てたときに試料から出る特性X線のエネルギーを測り、含まれる元素の種類と量を調べる分析法。SEMやTEMと組み合わせて使う。

「EDX(エネルギー分散型X線分光)」は、1分野の5問の練習問題に出てきます(計測・分析など)。

この用語の分野: 計測・分析

EDX(エネルギー分散型X線分光)の練習問題に挑戦

SEMやTEMと組み合わせて使われるEDX(エネルギー分散型X線分光)で分かることはどれか。

  1. A表面の粗さ
  2. B試料に含まれる元素の種類と量
  3. C膜の内部応力
答えと解説を見る

正解：B. 試料に含まれる元素の種類と量

電子線を試料に当てると、内側の殻の電子がはじき出され、そこに外側の電子が落ちるときに元素ごとに固有のエネルギーの特性X線が出ます。EDXはそのエネルギーを分析して、元素の種類と量を調べます。電子顕微鏡で見た場所の組成がその場で分かるため、異物や不良箇所の分析に広く使われます。検出限界は0.1 wt%程度で、微量の不純物の分析にはSIMSなどを使います。

解説の中の「EDX(エネルギー分散型X線分光)」

  • EDXはそのエネルギーを分析して、元素の種類と量を調べます。

    SEMやTEMと組み合わせて使われるEDX(エネルギー分散型X線分光)で分かることはどれか。

  • 特性X線で元素を調べるのはEDX、反射率で膜厚を測るのは光学的な方法です。

    SIMS(二次イオン質量分析法)の説明として正しいものはどれか。

  • SIMSは質量分析、EDXは元素分析の方法です。

    ウエハの反り(ボウ・ワープ)や平坦度の測定に使われる方法として正しいものはどれか。

  • EDXは元素、AFMは形状を調べる方法です。

    SIMSが不純物の原子の濃度を測るのに対して、電気的に活性なキャリアの濃度の深さ方向分布を測る方法として正しいものはど…

  • 4探針法とEDXでは酸素濃度は測れません。

    シリコン中の格子間酸素の濃度の測定に使われる方法はどれか。

「EDX(エネルギー分散型X線分光)」が出てくる問題(5問)

  1. SEMやTEMと組み合わせて使われるEDX(エネルギー分散型X線分光)で分かることはどれか。
  2. SIMS(二次イオン質量分析法)の説明として正しいものはどれか。
  3. ウエハの反り(ボウ・ワープ)や平坦度の測定に使われる方法として正しいものはどれか。
  4. SIMSが不純物の原子の濃度を測るのに対して、電気的に活性なキャリアの濃度の深さ方向分布を測る方法として正しいものはどれか。
  5. シリコン中の格子間酸素の濃度の測定に使われる方法はどれか。
