EDX(エネルギー分散型X線分光)とは

いーでぃーえっくす

電子線を当てたときに試料から出る特性X線のエネルギーを測り、含まれる元素の種類と量を調べる分析法。SEMやTEMと組み合わせて使う。

「EDX(エネルギー分散型X線分光)」は、1分野の5問の練習問題に出てきます(計測・分析など)。

この用語の分野: 計測・分析

特性X線の発生と計数のしくみ

SEMでは一般に5〜30 keVの一次電子線を試料に当てます。電子線が原子の内殻電子をはじき出すと、外殻の電子がその空きに落ち込み、エネルギー差がX線光子として放出されます。このエネルギーは元素ごとに決まっており、たとえばシリコンのKα線は約1.74 keVです。固体検出器(現在は主にシリコンドリフト検出器、SDD)が光子1個ごとにエネルギーに比例した電荷パルスを出し、波高分析器がそれを仕分けてエネルギー対カウント数のスペクトルにします。ピーク位置から元素を同定し、補正したピーク面積から濃度を求めます。

空間分解能:SEMとTEMの違い

バルク試料では電子が散乱して洋梨形の相互作用体積に広がり、その大きさはしばしば1 µm以上になります。そのためSEMでの分析は、ビームスポットよりはるかに広い領域の平均組成を示すことになります。加速電圧を下げればこの体積は小さくなりますが、重い元素の高エネルギー側の線を励起できなくなることがあります。一方TEMや走査型TEM(STEM)では、試料は厚さ100 nmを大きく下回る薄片で、集束イオンビーム(FIB)で切り出すことが多いため、ビームがほとんど広がらず、nmスケールの分解能で元素マップが得られます。これは先端デバイス構造の解析に欠かせません。

知っておくべき限界

検出下限は約0.1 wt%で、主成分や異物粒子、膜の組成比は見えますが、デバイスレベルの濃度のドーパントは検出できません。ホウ素、炭素、窒素、酸素などの軽元素は低エネルギーのX線しか出さず吸収されやすいため定量性が悪く、特にホウ素は困難です。SDDのエネルギー分解能はおよそ130 eVなので、ピークが重なることがあります。チップ解析でよく知られた例が、1.77 keV付近のシリコンKα線とタングステンM線の重なりです。また絶縁性の試料はチャージアップしやすく、弱い膜は電子線で損傷することがあります。

SIMSなど他の分析法との比較

EDXは短時間で済み、ほぼ非破壊で、顕微鏡で見ているまさにその場所の組成がわかるため、異物や故障箇所の同定でまず使われる手法です。二次イオン質量分析(SIMS)は一次イオンで試料をスパッタし、飛び出したイオンを質量分析する方法で、ppm〜ppbの感度と深さ方向プロファイルが得られますが、試料を消耗します。WDS(分光結晶でX線を波長ごとに分けて測る方式)は重なったピークをよりよく分離できますが、測定に時間がかかります。電気的に活性なキャリアを測る拡がり抵抗測定(SRP)や、シリコン中の格子間酸素を測る赤外吸収(FTIR)は、EDXではできない測定です。

EDX(エネルギー分散型X線分光)の練習問題に挑戦

SEMやTEMと組み合わせて使われるEDX(エネルギー分散型X線分光)で分かることはどれか。

  1. A表面の粗さ
  2. B試料に含まれる元素の種類と量
  3. C膜の内部応力
答えと解説を見る

正解：B. 試料に含まれる元素の種類と量

電子線を試料に当てると、内側の殻の電子がはじき出され、そこに外側の電子が落ちるときに元素ごとに固有のエネルギーの特性X線が出ます。EDXはそのエネルギーを分析して、元素の種類と量を調べます。電子顕微鏡で見た場所の組成がその場で分かるため、異物や不良箇所の分析に広く使われます。検出限界は0.1 wt%程度で、微量の不純物の分析にはSIMSなどを使います。

よくある質問

EDXとEDSの違いは何ですか?

同じ手法です。EDX(energy-dispersive X-ray spectroscopy)とEDS(energy-dispersive spectroscopy)は区別なく使われ、XEDSと書く文献もあります。

EDXでシリコン中のドーパント濃度は測れますか?

測れません。一般的なドーパント濃度はEDXの検出下限(約0.1 wt%)よりはるかに低いためです。原子濃度のプロファイルにはSIMSを、活性キャリア濃度には拡がり抵抗測定などの電気的手法を使います。

EDX分析は破壊分析ですか?

測定自体はふつう試料を壊しませんが、電子線で絶縁物がチャージアップしたり、弱い膜が損傷したりすることはあります。ただしTEMでのEDXは薄片の切り出しが必要なので、その部分のデバイスは破壊されます。
