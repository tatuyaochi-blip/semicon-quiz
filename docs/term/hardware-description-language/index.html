ハードウェア記述言語とは

はーどうぇあきじゅつげんご

デジタル回路の構造や動作を文章で記述するための言語。HDL。VerilogやSystemVerilog、VHDLがあり、論理合成で回路に変換する。

「ハードウェア記述言語」は、1分野の2問の練習問題に出てきます(LSI設計フロー・EDAなど)。

この用語の分野: ハードウェア記述言語と検証

HDLが記述するもの

ハードウェア記述言語(HDL)が記述するのは、命令の並びではなく回路です。assign文、alwaysブロック、モジュールのインスタンスはどれも常に動作し続けるハードウェアを表すため、コードの順番は実行の順番を意味しません。設計は通常、レジスタ転送レベル(RTL)で記述します。クロックのエッジで更新されるレジスタと、その次の値を計算する組み合わせ回路で表現する方法です。主な言語は、Verilog、その拡張であるSystemVerilog、型の扱いがより厳密なVHDLです。どの言語でも、ゲートに変換できるのは論理合成可能なサブセットだけで、残りはシミュレーションと検証のために存在します。

論理合成できるRTLの書き方

always @(posedge clk)のようなクロック同期のブロックはフリップフロップになり、慣例としてノンブロッキング代入(<=)を使います。組み合わせ回路のブロックには@(*)やalways_combとブロッキング代入(=)を使い、default節を設けるなどして、すべての経路ですべての出力に値を代入する必要があります。そうしないと論理合成でラッチが推論されてしまいます。forループは並列のハードウェアに展開されるので、8ビット分のループは8個の加算器になります。ステートマシンは、状態レジスタ、次状態の論理、出力の論理の組み合わせで構成します。トライステート出力はチップ外の双方向ピンに限って使い、内部の選択にはマルチプレクサを使います。

HDLによる検証

検証環境も同じ言語で構築します。テストベンチは検証対象の設計をインスタンス化し、クロック、リセット、入力刺激を生成して出力を確認します。テストベンチは論理合成しないので、遅延、ファイル入出力、表示文を使えます。SystemVerilogはクラス、制約付きランダム刺激、機能カバレッジ、アサーションを追加しており、UVMは再利用可能なテストベンチのための標準クラスライブラリを提供します。リントツールは、ビット幅の不一致、推論されたラッチ、論理合成できない記述などをコードから静的に検出します。検証には設計そのものと同じか、それ以上の工数がかかることがよくあります。

設計フローにおけるHDLの位置づけ

HDLは仕様とゲートレベルのネットリストの中間に位置します。技術者は仕様からRTLを書いてシミュレーションし、その後、論理合成がPDK(プロセス設計キット)とタイミング制約に従って、ファウンドリのライブラリのセルにマッピングします。このように動作で記述できるからこそ、大規模な設計が可能になります。32ビット加算器でさえ、真理値表で書けば2⁶⁴行が必要になるからです。高位合成はCやC++からRTLを生成し、抽象度をさらに上げます。FPGAのツールは同じHDLを受け取り、スタンダードセルではなくルックアップテーブルにマッピングします。

ハードウェア記述言語の練習問題に挑戦

RTL設計で主に使われるハードウェア記述言語はどれか。

  1. AVerilog HDLやVHDL
  2. BHTML
  3. CSQL
答えと解説を見る

正解：A. Verilog HDLやVHDL

RTL設計では、Verilog HDL(およびその拡張のSystemVerilog)やVHDLといったハードウェア記述言語で、クロックごとにレジスタの間をデータがどう流れるかを記述します。ソフトウェアの言語と違い、記述した処理は回路として同時並行に動きます。HTMLはWebページの記述言語、SQLはデータベースの問い合わせ言語で、回路は記述できません。

よくある質問

VerilogとVHDLの違いは?

どちらもRTLでハードウェアを記述でき、論理合成ツールとシミュレータで扱えます。VerilogはC言語に似た簡潔な文法で、VHDLは記述が冗長な代わりに型の扱いが厳密です。SystemVerilogはVerilogに強力な検証機能を加えた言語です。

HDLはプログラミング言語ですか?

見た目は似ていますが、論理合成可能なHDLのコードが記述するのは、順番に実行される命令ではなく、並行して動くハードウェアです。1行1行が回路面積になるので、設計者は手順ではなくレジスタと論理で考えます。

Verilogのブロッキング代入とノンブロッキング代入はどう使い分けますか?

一般的な指針は、クロック同期のalwaysブロックではノンブロッキング代入(<=)、組み合わせ回路のブロックではブロッキング代入(=)を使うことです。1つのブロックで両者を混在させると、シミュレーションと論理合成の結果が食い違う原因になりがちです。
