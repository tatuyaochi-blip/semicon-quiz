ハードウェア記述言語とは

はーどうぇあきじゅつげんご

デジタル回路の構造や動作を文章で記述するための言語。HDL。VerilogやSystemVerilog、VHDLがあり、論理合成で回路に変換する。

「ハードウェア記述言語」は、1分野の2問の練習問題に出てきます(LSI設計フロー・EDAなど)。

この用語の分野: ハードウェア記述言語と検証

ハードウェア記述言語の練習問題に挑戦

RTL設計で主に使われるハードウェア記述言語はどれか。

  1. AVerilog HDLやVHDL
  2. BHTML
  3. CSQL
答えと解説を見る

正解：A. Verilog HDLやVHDL

RTL設計では、Verilog HDL(およびその拡張のSystemVerilog)やVHDLといったハードウェア記述言語で、クロックごとにレジスタの間をデータがどう流れるかを記述します。ソフトウェアの言語と違い、記述した処理は回路として同時並行に動きます。HTMLはWebページの記述言語、SQLはデータベースの問い合わせ言語で、回路は記述できません。

解説の中の「ハードウェア記述言語」

  • RTL設計では、Verilog HDL(およびその拡張のSystemVerilog)やVHDLといったハードウェア記述言語で、クロックごとにレジスタの間をデータがどう流れるかを記述します。

    RTL設計で主に使われるハードウェア記述言語はどれか。

  • まず仕様設計で機能や性能を決め、VerilogやVHDLなどのハードウェア記述言語でRTL設計を行います。

    一般的なデジタルLSIの設計フローの順序として正しいものはどれか。
