パターン倒壊とは

ぱたーんとうかい

高アスペクト比の微細なパターンを洗浄・乾燥するとき、パターンの間に残った液体の表面張力で、パターンが倒れたり貼り付いたりする不良。

「パターン倒壊」は、1分野の1問の練習問題に出てきます(CMP・洗浄など)。

この用語の分野: CMP・洗浄

倒壊の原因となる毛細管力

背の高い2本のラインの間からリンス液が乾燥していくとき、湾曲した液面によって圧力差(ラプラス圧)が生じます。この圧力差は、表面張力と接触角の余弦の積を隙間の幅で割った値に比例します。ラインの両側で液面の高さが異なると、ラインには横向きの正味の力がかかります。ラインを片持ち梁とみなすと、曲げ応力はおおむね高さと幅の比(アスペクト比)の2乗に比例し、間隔に反比例します。そのため、高さを保ったままピッチを縮めると、倒壊が格段に起こりやすくなります。

倒壊が起こる場面

典型例はレジストパターンです。現像とリンスの後、細く背の高いレジストラインが傾いて隣のラインに接触します。レジスト膜厚が線幅の数倍程度に抑えられている理由の一つがこれです。同じ不良は、シリコンフィン、DRAMのキャパシタピラー、深く積層された構造など、エッチング後の構造をウェット洗浄した後にも発生します。倒れたラインは乾燥後も付着力で貼り付いたままになることがあり、この関連現象はスティクションと呼ばれます。

倒壊への対策

毛細管力の各要素に対策を打つことができます。乾燥前に水(室温で約72 mN/m)をイソプロピルアルコール(IPA、約22 mN/m)に置換すれば表面張力が下がります。表面処理で接触角を90°に近づければ、余弦がゼロに近づきます。超臨界二酸化炭素乾燥は気液界面そのものをなくし、極低温エアロゾル洗浄のようなドライ方式は液体をまったく使いません。リソグラフィでは、金属酸化物レジストなどエッチング耐性の高い薄膜レジストを使ってアスペクト比を下げます。

パターン倒壊と他の乾燥起因欠陥

パターン倒壊は毛細管力によるパターンの機械的な破壊です。そのためアスペクト比と間隔に強く依存し、上面からの検査ではラインの傾きや融合として現れます。一方のウォーターマークは、液滴が乾いた場所に残る残渣で、主に疎水性の表面で発生し、パターンの変形は伴いません。IPA蒸気を使うマランゴニ乾燥は、水がその場で蒸発する前に表面から引き離すため、どちらの欠陥にも効果があります。

パターン倒壊の練習問題に挑戦

微細な構造の倒壊を防ぐため、液体を使わずに表面の自然酸化膜などを除去する方法はどれか。

  1. Aブラシスクラブ洗浄
  2. B気相のガスやラジカルを使ったドライ洗浄
  3. Cメガソニック洗浄
答えと解説を見る

正解：B. 気相のガスやラジカルを使ったドライ洗浄

高く細いパターンでは、洗浄液が乾くときの表面張力でパターンが引き寄せられて倒れることがあります。フッ化水素の蒸気、NF3とNH3のプラズマで生成したラジカル(SiCoNi処理)などを使う気相(ドライ)洗浄では液体を使わないため、パターン倒壊の心配がなく、成膜装置と真空でつないで処理直後に酸化させずに次の工程へ進めることもできます。コンタクトの底の酸化膜除去などに使われます。

よくある質問

IPA乾燥でパターン倒壊を防げるのはなぜですか?

IPAの表面張力は水の約3分の1しかないため、液体が蒸発するときに隣り合うパターンを引き寄せる毛細管力が大幅に小さくなるからです。また、水とよく混ざるので、リンス水を完全に置換できます。

レジストのパターン倒壊はアスペクト比がいくつで起こりますか?

倒壊のリスクは間隔、レジストの剛性、密着性、リンス液によって変わるため、単一のしきい値はありません。曲げ応力はアスペクト比のおおむね2乗に比例するため、プロセスではレジストの高さを幅の数倍程度に抑えています。

超臨界CO2乾燥でパターン倒壊を防げるのはなぜですか?

臨界点を超えた二酸化炭素には液相と気相の区別がないため、除去する際にメニスカス(湾曲した液面)ができません。メニスカスがなければ、パターンに毛細管力は働きません。
