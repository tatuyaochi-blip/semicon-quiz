ウェットエッチングとは

うぇっとえっちんぐ

薬液に浸して膜を溶かして削る方法。選択比が高く損傷も少ないが、一般に等方的に進むため微細な加工には向かない。

この用語の分野: エッチング

解説の中の「ウェットエッチング」

  • ウェットエッチングは薬液による化学反応で膜を溶かすため、一般にすべての方向へ同じように進み(等方性)、マスクの下にも回り込みます(サイドエッチ)。

    ウェットエッチングの一般的な特徴として正しいものはどれか。

  • ウェットエッチングは化学反応で進むため、一般に温度が上がると反応が速くなり、エッチング速度も上がります。

    ウェットエッチングで、薬液の温度を上げたときのエッチング速度の変化として一般的なものはどれか。

「ウェットエッチング」が出てくる問題(6問)

  1. ウェットエッチングの一般的な特徴として正しいものはどれか。
  2. シリコン窒化膜のウェットエッチングに一般的に使われる薬液はどれか。
  3. 水酸化カリウム(KOH)水溶液によるシリコンのウェットエッチングの特徴として正しいものはどれか。
  4. SiO2のウェットエッチングに使われる、フッ酸をフッ化アンモニウムで緩衝した液はどれか。
  5. ウェットエッチングで、薬液の温度を上げたときのエッチング速度の変化として一般的なものはどれか。
  6. 厚さ1 µmの膜を、完全に等方的なウェットエッチングでちょうど下地まで削ったとき、マスクの端から横方向に削れる量(アンダーカット)のおよその大きさはどれか。
