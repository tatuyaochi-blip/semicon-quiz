ウェットエッチングとは

うぇっとえっちんぐ

薬液に浸して膜を溶かして削る方法。選択比が高く損傷も少ないが、一般に等方的に進むため微細な加工には向かない。

「ウェットエッチング」は、1分野の7問の練習問題に出てきます(エッチングなど)。

この用語の分野: エッチング

ウェットエッチングの練習問題に挑戦

ウェットエッチングの一般的な特徴として正しいものはどれか。

  1. Aプラズマを用いるため異方性が高い
  2. B一般に等方的に進み、マスクの下にも回り込みやすい
  3. C真空装置が必須である
答えと解説を見る

正解：B. 一般に等方的に進み、マスクの下にも回り込みやすい

ウェットエッチングは薬液による化学反応で膜を溶かすため、一般にすべての方向へ同じように進み(等方性)、マスクの下にも膜厚と同程度回り込みます(サイドエッチ)。装置が簡単で多数枚を一度に処理でき、化学反応なので選択比を高くしやすい利点があります。微細パターンの形成にはドライエッチングが使われますが、膜の全面除去や洗浄では今も重要です。

シリコン窒化膜のウェットエッチングに一般的に使われる薬液はどれか。

  1. A純水
  2. B熱リン酸
  3. Cアンモニア水
答えと解説を見る

正解：B. 熱リン酸

シリコン窒化膜は、約160 ℃に加熱した濃いリン酸で、酸化膜に対して数十〜100以上の高い選択比でエッチングできます。LOCOSやSTIの形成後にマスクとして使った窒化膜を除去する工程や、3D NANDで酸化膜と窒化膜を交互に積んだ層から窒化膜だけを除いてワード線の金属に置き換える工程で使われます。液中のシリコン濃度で選択比が変わるため厳密な管理が必要です。
