IIRフィルタとは

あいあいあーるふぃるた

過去の出力を入力の側に戻す帰還をもち、インパルス応答が無限に続くデジタルフィルタ(無限インパルス応答フィルタ)。例えば y[n] = 0.2x[n] + 0.8y[n − 1](指数平滑化)のような差分方程式で計算し、伝達関数は分母をもつ。少ない係数と演算量で急峻な特性が得られ、遅延も小さいが、位相は直線にならない。すべての極が単位円の内側にないと不安定になり、高次のフィルタは係数の量子化に弱いので、2次のセクション(バイクワッド)の縦続接続で実装することが多い。アナログフィルタから双一次変換で設計する方法がよく使われる。

「IIRフィルタ」は、1分野の4問の練習問題に出てきます(デジタル信号処理の基礎など)。

この用語の分野: デジタル信号処理の基礎

IIRフィルタの練習問題に挑戦

指数平滑化 y[n] = 0.2x[n] + 0.8y[n − 1] で表される1次のIIRローパスフィルタの、直流とナイキスト周波数での利得の組み合わせとして正しいものはどれか。

  1. A直流で1、ナイキスト周波数で0
  2. B直流で5、ナイキスト周波数で約0.56
  3. C直流で1、ナイキスト周波数で約0.11
答えと解説を見る

正解：C. 直流で1、ナイキスト周波数で約0.11

伝達関数は H(z) = 0.2/(1 − 0.8z⁻¹) で、直流(z = 1)では 0.2/(1 − 0.8) = 1、ナイキスト周波数(z = −1)では 0.2/(1 + 0.8) = 1/9 ≈ 0.11(約 −19 dB)です。新しい入力に0.2、それまでの出力に0.8の重みを掛けて足すので、重みの和が1となり、一定の入力はそのまま通ります。1つ前の出力を覚えておくだけで、過去の入力に指数的に小さくなる重みを掛けた平均が得られます。極は z = 0.8 で単位円の内側にあるので安定ですが、帰還の係数が1に近いほど平滑化が強くなり、応答も遅くなります。

次数の高いIIRフィルタを、係数のビット数が限られた固定小数点で実装するときの注意として正しいものはどれか。

  1. AIIRフィルタの極は係数の量子化の影響を受けないので、係数のビット数は通過帯域の利得の精度だけで決めればよい
  2. B係数を量子化してもFIRフィルタと同じく必ず安定なので、次数が高くても1つの差分方程式のまま実装するのがよい
  3. C高次の分母を1つの式のまま実装すると係数の誤差で極が動いて不安定になりうるので、2次の部分の縦続接続に分ける
答えと解説を見る

正解：C. 高次の分母を1つの式のまま実装すると係数の誤差で極が動いて不安定になりうるので、2次の部分の縦続接続に分ける

高次の多項式の根(極)は係数のわずかな変化に敏感で、特に極が単位円の近くに集まる急峻なフィルタでは、係数を丸めただけで極が単位円の外に出ることがあります。そこで、極を2個ずつ受け持つ2次のセクション(バイクワッド)に分けて縦続に接続すると、各セクションの係数の誤差が他の極に影響せず、量子化に強くなります。FIRフィルタは係数を量子化しても安定ですが、周波数特性は変わります。

    FIRフィルタ(有限インパルス応答フィルタ)の特徴として正しいものはどれか。

「IIRフィルタ」が出てくる問題(4問)

  1. 指数平滑化 y[n] = 0.2x[n] + 0.8y[n − 1] で表される1次のIIRローパスフィルタの、直流とナイキスト周波数での利得の組み合わせとして正しいものはどれか。
  2. 次数の高いIIRフィルタを、係数のビット数が限られた固定小数点で実装するときの注意として正しいものはどれか。
  3. 差分方程式 y[n] = x[n] + 0.5y[n − 1] で表されるシステムに、n = 0 から単位ステップ(n ≥ 0 で x[n] = 1)を入力した。y[−1] = 0 のとき、y[2] として正しいものはどれか。
  4. FIRフィルタ(有限インパルス応答フィルタ)の特徴として正しいものはどれか。
