スピンコートとは

すぴんこーと

液状の材料をウエハの中心に滴下し、高速で回転させて遠心力で均一な薄い膜をつくる方法。フォトレジストや塗布型の絶縁膜の形成に使われる。

この用語の分野: 成膜(CVD・PVD)

解説の中の「スピンコート」

  • スピンコートでは、ウエハの外周に表面張力でレジストが厚く盛り上がります(エッジビード)。

    スピンコートでレジストを塗った後、ウエハの外周部に盛り上がったレジストを溶剤で取り除く処理を何と呼ぶか。

  • スピンコートでは、液をウエハの中心に滴下し、数千rpmで回転させて遠心力で広げ、余分な液を振り切って均一な膜をつくります。

    液状の材料をウエハの中心に滴下し、高速で回転させて均一な膜をつくる方法を何と呼ぶか。

「スピンコート」が出てくる問題(2問)

  2. 液状の材料をウエハの中心に滴下し、高速で回転させて均一な膜をつくる方法を何と呼ぶか。
