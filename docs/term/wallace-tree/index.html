ウォレスツリーとは

うぉれすつりー

乗算器で、多数の部分積を桁上げ保存加算器の木で並列に減らしていく構成。段数がビット数の対数程度で済み、高速な乗算器に使われる。最後に2つの数を通常の加算器で足す。

この用語の分野: 計算機算術

解説の中の「ウォレスツリー」

  • ウォレスツリーは、桁上げ保存加算器で3つを2つにまとめる処理を各段で並列に行い、部分積の数をおよそ3分の2ずつ減らしていきます。

    高速な乗算器で使われるウォレスツリーの特徴として正しいものはどれか。

  • 掛け算では部分積をすべて同時に作り、ウォレスツリーなどで並列に足せます。

  1. 高速な乗算器で使われるウォレスツリーの特徴として正しいものはどれか。
