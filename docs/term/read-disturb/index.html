リードディスターブとは

りーどでぃすたーぶ

NANDフラッシュで同じブロックを何度も読み出すうちに、読み出していないセルにも弱い電圧がかかり、しきい値電圧が少しずつ変化する現象。

「リードディスターブ」は、1分野の1問の練習問題に出てきます(SRAM・フラッシュメモリなど)。

この用語の分野: SRAM・フラッシュメモリ

1ページの読み出しが周囲にストレスを与える理由

NANDフラッシュのセルはストリング内で直列につながっています。1本のワード線を読み出すとき、選択セルのゲートには読み出し電圧がかかり、ブロック内の他のすべてのワード線には、記憶データにかかわらずセルを完全にオンにできる数ボルトのパス電圧がかかります。このパス電圧が非選択セルのトンネル酸化膜に弱い電界を生じさせ、読み出しのたびにごくわずかな電荷が記憶層に注入されます。読み出しを何度も重ねると、それらのセルのしきい値電圧が少しずつ上がっていきます。一般に、しきい値電圧が最も低い消去状態のセルが最も影響を受けやすくなります。

リードディスターブが問題になる場面

1回の読み出しによる変化は無視できるほど小さいものですが、同じブロックを数万〜数十万回読み出すと無視できなくなります。そのため、ブートコードや頻繁に参照されるルックアップテーブルなど、読み出し頻度が非常に高い一方でめったに書き換えられないデータを持つブロックで問題になります。1セルに複数ビットを記憶するセル(MLC、TLC、QLC)は、状態を区切るしきい値電圧のウィンドウが狭いため影響を受けやすく、書き込み・消去サイクルを多く重ねて劣化したセルはさらに影響を受けやすくなります。

SSDコントローラの対策

コントローラはブロックごとに読み出し回数のカウンタを持っています。回数が上限に近づいたり、誤り訂正(ECC)で訂正されるビット数が増え始めたりすると、データを新しいブロックへコピーし、後で古いブロックを消去します。この処理はリードリクレームやリフレッシュと呼ばれます。しきい値電圧の変化は永久的な損傷ではなく注入された電荷によるものなので、ブロックを消去して書き直せば元に戻ります。また、参照電圧をずらして読み直すリードリトライによって、分布が移動してしまったページのデータを回復できることもあります。

データ保持不良や他のメモリとの比較

リードディスターブはしきい値電圧を上げる現象で、ブロックが読み出される頻度に依存します。一方、データ保持(リテンション)による劣化は、蓄えた電荷が時間とともに漏れ出すことでしきい値電圧が下がる現象で、データにまったくアクセスしなくても起こります。この用語は他のメモリでも使われます。STT-MRAMでは読み出し電流が書き込みに使うのと同じ磁気トンネル接合を流れるため、スイッチング電流より十分小さくしないとビットが反転する恐れがありますが、小さすぎると信号が弱くなります。SRAMでは、セルへのアクセスによって記憶値が乱される関連したリスクを読み出し安定性と呼びます。

リードディスターブの練習問題に挑戦

NANDフラッシュで、同じブロックを何度も読み出すうちに、読み出していないセルのしきい値電圧が少しずつ変化してしまう現象を何と呼ぶか。

  2. Bリードディスターブ

答えと解説を見る

正解：B. リードディスターブ

NANDの読み出しでは、選択していないセルにも数Vの通過電圧をかけて導通させるため、繰り返し読み出すうちにわずかに電子が注入され、しきい値電圧が上がっていきます。これがリードディスターブで、数万〜数十万回の読み出しで問題になります。読み出し頻度の高いデータが集まるブロックで起きやすく、コントローラは読み出し回数を数えて、上限が近づくとデータを別のブロックに書き直します。

よくある質問

NANDフラッシュのリードディスターブとは何ですか?

NANDのブロック内で、読み出しのたびに非選択セルにかかるパス電圧によって、それらのセルのしきい値電圧が徐々に上昇する現象です。読み出し回数が十分に多くなると、記憶したビットが反転することがあります。

リードディスターブは永久的な損傷ですか?

いいえ。しきい値電圧の変化はセルに余分に注入された電荷によるものなので、ブロックを消去してデータを書き直せば正常なマージンに戻ります。この点で、書き込み・消去サイクルによる劣化とは異なります。

リードディスターブとデータ保持エラーの違いは?

リードディスターブは電荷が加わってしきい値電圧が上がる現象で、ブロックの読み出し回数に応じて進みます。データ保持エラーは時間とともに電荷が漏れ出すことで生じ、データにアクセスしなくてもしきい値電圧が下がります。
