バンドギャップ基準電圧回路とは

ばんどぎゃっぷきじゅんでんあつかいろ

温度で下がるダイオードの電圧と、温度で上がる電圧を足し合わせ、温度に依存しにくい約1.2 Vの基準電圧をつくる回路。ADCや電源ICの基準に広く使われる。

「バンドギャップ基準電圧回路」は、2分野の2問の練習問題に出てきます(PN接合・ダイオード, MEMS・センサなど)。

この用語の分野: アナログ・電子回路

バンドギャップ基準電圧回路の練習問題に挑戦

一定の電流を流したシリコンダイオードの順方向電圧は、温度が上がるとどうなるか。

  1. A約2 mV/℃の割合で下がる
  2. B約2 mV/℃の割合で上がる
  3. C変化しない
答えと解説を見る

正解：A. 約2 mV/℃の割合で下がる

一定電流で動かしたシリコンダイオードの順方向電圧は、温度が1 ℃上がるごとに約2 mV下がります。真性キャリア密度が増えて飽和電流Isが大きくなり、同じ電流を流すのに必要な電圧が小さくなるためです。この直線的な変化は温度センサに使われ、CPUの温度監視やバンドギャップ基準電圧回路(正の温度係数の電圧と足し合わせて温度依存を打ち消す)の基礎になっています。

一定電流を流したシリコンPN接合の順方向電圧の温度依存性として正しいものはどれか。

  1. A温度が上がると約2 mV/℃ずつ小さくなる
  2. B温度が上がると大きくなる
  3. C温度によらず一定である
答えと解説を見る

正解：A. 温度が上がると約2 mV/℃ずつ小さくなる

シリコンPN接合の順方向電圧は、一定電流のもとで温度が1 ℃上がるごとに約2 mV小さくなります。電流密度の異なる2つの接合の電圧差は絶対温度に比例するため(PTAT)、これを使うと±1 ℃程度の精度の温度センサをLSIに簡単に内蔵できます。CPUの過熱保護や電池の監視に使われ、電圧の温度変化を打ち消すように組み合わせたものがバンドギャップ基準電圧回路です。

解説の中の「バンドギャップ基準電圧回路」

  • この直線的な変化は温度センサに使われ、CPUの温度監視やバンドギャップ基準電圧回路(正の温度係数の電圧と足し合わせて温度依存を打ち消す)の基礎になっています。
