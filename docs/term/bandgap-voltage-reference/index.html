バンドギャップ基準電圧回路とは

ばんどぎゃっぷきじゅんでんあつかいろ

温度で下がるダイオードの電圧と、温度で上がる電圧を足し合わせ、温度に依存しにくい約1.2 Vの基準電圧をつくる回路。ADCや電源ICの基準に広く使われる。

この用語の分野: アナログ・電子回路

解説の中の「バンドギャップ基準電圧回路」

  • この直線的な変化は温度センサに使われ、CPUの温度監視やバンドギャップ基準電圧回路(正の温度係数の電圧と足し合わせて温度依存を打ち消す)の基礎になっています。

    一定の電流を流したシリコンダイオードの順方向電圧は、温度が上がるとどうなるか。

  • また、電圧の温度変化を打ち消すように組み合わせたものがバンドギャップ基準電圧回路です。

    一定電流を流したシリコンPN接合の順方向電圧の温度依存性として正しいものはどれか。

「バンドギャップ基準電圧回路」が出てくる問題(2問)

  1. 一定の電流を流したシリコンダイオードの順方向電圧は、温度が上がるとどうなるか。
  2. 一定電流を流したシリコンPN接合の順方向電圧の温度依存性として正しいものはどれか。
