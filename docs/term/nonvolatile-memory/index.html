不揮発性メモリとは

ふきはつせいめもり

電源を切っても記憶したデータが消えないメモリ。フラッシュメモリやMRAMなど。DRAMやSRAMは揮発性。

この用語の分野: SRAM・フラッシュメモリ

解説の中の「不揮発性メモリ」

  • 不揮発性メモリをキャッシュやレジスタに使えば、処理のない瞬間に電源を細かく切ってもデータが残るため、待機電力をほぼ0にでき、復帰も速くなります(ノーマリーオフ・コンピューティング)。

    不揮発性メモリをキャッシュやレジスタなどに使うことで期待される、システムの省電力化の仕組みとして正しいものはどれか。

  • MRAMは磁性体の磁化の向きで記憶するため、電源を切ってもデータが残る不揮発性メモリで、保持期間は一般に10年以上です。

    次のメモリのうち、電源を切ってもデータが残る不揮発性メモリはどれか。

  • フラッシュメモリは、絶縁膜で囲まれたフローティングゲートや電荷トラップ層に電子を閉じ込めて記憶するため、電源を切ってもデータが残る不揮発性メモリです。

    フラッシュメモリの性質として正しいものはどれか。

「不揮発性メモリ」が出てくる問題(6問)

  1. 不揮発性メモリをキャッシュやレジスタなどに使うことで期待される、システムの省電力化の仕組みとして正しいものはどれか。
  2. 次のメモリのうち、電源を切ってもデータが残る不揮発性メモリはどれか。
  3. フラッシュメモリの性質として正しいものはどれか。
  4. USBメモリやSDカードに主に使われているメモリはどれか。
  5. EEPROMとフラッシュメモリの違いとして正しいものはどれか。
  6. 「ストレージクラスメモリ」の位置づけとして正しいものはどれか。
