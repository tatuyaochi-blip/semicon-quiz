不揮発性メモリとは

ふきはつせいめもり

電源を切っても記憶したデータが消えないメモリ。フラッシュメモリやMRAMなど。DRAMやSRAMは揮発性。

「不揮発性メモリ」は、2分野の6問の練習問題に出てきます(次世代メモリ, SRAM・フラッシュメモリなど)。

この用語の分野: SRAM・フラッシュメモリ

不揮発性メモリの練習問題に挑戦

不揮発性メモリをキャッシュやレジスタなどに使うことで期待される、システムの省電力化の仕組みとして正しいものはどれか。

  1. A待機時に電源を切ってもデータが消えないため、待機時の電力を大幅に減らせる
  2. Bクロック周波数を上げられるため
  3. Cメモリの容量が増えるため
答えと解説を見る

正解：A. 待機時に電源を切ってもデータが消えないため、待機時の電力を大幅に減らせる

SRAMやDRAMは揮発性のため、データを保つには電源を入れ続ける必要があり、待機時にもリーク電流で電力を消費します。不揮発性メモリをキャッシュやレジスタに使えば、処理のない瞬間に電源を細かく切ってもデータが残るため、待機電力をほぼ0にでき、復帰も速くなります(ノーマリーオフ・コンピューティング)。センサーノードなど、ほとんどの時間を待機しているIoT機器で特に効果的です。

次のメモリのうち、電源を切ってもデータが残る不揮発性メモリはどれか。

  1. AMRAM
  2. BDRAM
  3. CSRAM
答えと解説を見る

正解：A. MRAM

MRAMは磁性体の磁化の向きで記憶するため、電源を切ってもデータが残る不揮発性メモリで、保持期間は一般に10年以上です。DRAMとSRAMはどちらも電源を切るとデータが消える揮発性メモリです。MRAMはSRAMに近い速さと不揮発性を兼ね備えるため、電源を頻繁に落とす省電力システムや、停電時もデータを守りたい産業機器で重宝されています。

解説の中の「不揮発性メモリ」

  • 不揮発性メモリをキャッシュやレジスタに使えば、処理のない瞬間に電源を細かく切ってもデータが残るため、待機電力をほぼ0にでき、復帰も速くなります(ノーマリーオフ・コンピューティング)。

    不揮発性メモリをキャッシュやレジスタなどに使うことで期待される、システムの省電力化の仕組みとして正しいものはどれか。

  • MRAMは磁性体の磁化の向きで記憶するため、電源を切ってもデータが残る不揮発性メモリで、保持期間は一般に10年以上です。

    次のメモリのうち、電源を切ってもデータが残る不揮発性メモリはどれか。

  • フラッシュメモリは、絶縁膜で囲まれたフローティングゲートや電荷トラップ層に電子を閉じ込めて記憶するため、電源を切ってもデータが残る不揮発性メモリです。

    フラッシュメモリの性質として正しいものはどれか。

  • USBメモリやSDカード、SSDには、大容量で安価な不揮発性メモリであるNANDフラッシュが使われ、内部にはNANDチップと、誤り訂正やウェアレベリングを担うコントローラが入っています。

    USBメモリやSDカードに主に使われているメモリはどれか。

  • EEPROMは1バイト単位で消去・書き換えができる不揮発性メモリで、各セルに選択トランジスタを付けるためセルが大きく、容量は数Kbit〜数Mbit程度です。

    EEPROMとフラッシュメモリの違いとして正しいものはどれか。

  2. 次のメモリのうち、電源を切ってもデータが残る不揮発性メモリはどれか。
  3. フラッシュメモリの性質として正しいものはどれか。
  4. USBメモリやSDカードに主に使われているメモリはどれか。
  5. EEPROMとフラッシュメモリの違いとして正しいものはどれか。
  6. 「ストレージクラスメモリ」の位置づけとして正しいものはどれか。
