アトミック命令とは

あとみっくめいれい

メモリの読み出しと書き込みを、途中でほかのコアに割り込まれない1つの操作として行う命令。CAS、フェッチ・アンド・アッド、LR/SCなど。

「アトミック命令」は、2分野の6問の練習問題に出てきます(マルチコアと同期, 命令セット・アセンブリなど)。

この用語の分野: マルチコアと同期

アトミック命令の練習問題に挑戦

アトミック命令(不可分命令)の説明として正しいものはどれか。

  1. Aメモリの読み出しと書き込みを、途中でほかのコアに割り込まれない1つの操作として行う命令
  2. B原子の数を数えるための、物理の計算用の命令
  3. C必ず1クロックで終わる、最も速い命令
答えと解説を見る

正解：A. メモリの読み出しと書き込みを、途中でほかのコアに割り込まれない1つの操作として行う命令

アトミック命令は、読んで、計算して、書き込むという一連の処理を、ほかのコアの読み書きが間に入らない形で行います。ほかのコアからは、操作の前か後の状態しか見えません。CAS(コンペア・アンド・スワップ)やフェッチ・アンド・アッド、RISC-VのLR/SCやAMO命令などがあり、ロックやロックフリーのデータ構造を作る土台になります。

スピンロックで、ロックの変数をいきなりアトミック命令で書き換えようとするのではなく、普段は通常の読み出しで空くのを待ち、空いたと見えたときだけアトミック命令を使う(test-and-test-and-set)理由として正しいものはどれか。

  1. A通常の読み出しの方がアトミック命令より正確だから
  2. Bアトミック命令は1つのプログラムで1回しか使えないから
  3. C読むだけなら自分のキャッシュの中で待てるので、キャッシュラインがコア間を行き来する通信を大きく減らせるから
答えと解説を見る

正解：C. 読むだけなら自分のキャッシュの中で待てるので、キャッシュラインがコア間を行き来する通信を大きく減らせるから

アトミック命令は書き込みをともなうので、待っているスレッドが繰り返し実行すると、そのたびにラインをM状態で奪い合い、ほかのコアのコピーを無効にし続けます。通常の読み出しなら、各コアはS状態のコピーを自分のキャッシュで読み続けるだけで、通信は起きません。ロックが解放されて値が変わったときだけ、アトミック命令で取りに行きます。

  • アトミック命令は、読んで、計算して、書き込むという一連の処理を、ほかのコアの読み書きが間に入らない形で行います。

  • M拡張はmul・div・remなどの乗算と除算、A拡張はアトミック命令、FとDは単精度と倍精度の浮動小数点、Cは16ビットの圧縮命令を加えます。

    RISC-VのM拡張が基本の整数命令セットに追加する命令はどれか。

  • スピンロックは、アトミック命令でロックを取ろうとし、取れなければすぐにもう一度試すことを繰り返します。

    スピンロックの説明として正しいものはどれか。

  • 要素ごとに共有の変数を更新すると、ロックやアトミック命令の待ちと、キャッシュラインの行き来で非常に遅くなります。

    配列の全要素の合計を複数のスレッドで求めるとき、性能のために適した方法はどれか。

「アトミック命令」が出てくる問題(6問)

  1. アトミック命令(不可分命令)の説明として正しいものはどれか。
  2. スピンロックで、ロックの変数をいきなりアトミック命令で書き換えようとするのではなく、普段は通常の読み出しで空くのを待ち、空いたと見えたときだけアトミック命令を使う(test-and-test-and-set)理由として正しいものはどれか。
  3. 64個のコアが、1つの共有カウンタを同時にアトミック命令で更新し続けると、コアを増やしても速くならない。主な理由はどれか。
  4. RISC-VのM拡張が基本の整数命令セットに追加する命令はどれか。
  5. スピンロックの説明として正しいものはどれか。
  6. 配列の全要素の合計を複数のスレッドで求めるとき、性能のために適した方法はどれか。
