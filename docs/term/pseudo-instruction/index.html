疑似命令とは

ぎじめいれい

アセンブリでは命令のように書けるが、アセンブラが1つ以上の本物の命令に置き換えるもの。RISC-Vのnop・mv・li・j・retなど。

「疑似命令」は、1分野の5問の練習問題に出てきます(命令セット・アセンブリなど)。

この用語の分野: 命令セット・アセンブリ

アセンブラによる展開

疑似命令は独自の機械語エンコーディングを持たないアセンブリ構文で、アセンブラが1つ以上の本物の命令に置き換えます。RISC-Vでは、nopはaddi x0, x0, 0に、mv rd, rsはaddi rd, rs, 0に、j labelはjal x0, labelに、retはjalr x0, 0(ra)に、bnez rs, labelはbne rs, x0, labelになります。多くは、読むと常に0で書き込みが捨てられるレジスタx0を利用しています。逆アセンブラは通常、疑似命令の形で表示し直すため、リストが読みやすくなります。

1行が複数の命令になる場合

疑似命令の中には、展開後の命令数が変わるものがあります。li(即値ロード)は、定数が12ビットの符号付き即値に収まる場合はaddi 1命令になりますが、それより大きな32ビットの値ではluiとaddiの組になり、64ビットの定数ではさらに長い命令列になります。la(アドレスロード)や遠くの関数へのcallは、auipcと2つ目の命令を使ってPC相対アドレスを作ります。コードサイズやオフセットを手計算する場合は、この点を考慮する必要があります。

ISAが疑似命令に頼る理由

nop、mv、単純なジャンプを個別のハードウェア命令として定義すると、オペコードとデコーダの論理が増えるだけで、機能は何も増えません。x0を使った既存の命令ですでに同じことができるからです。疑似命令を使えば、RISC-Vの中心的な設計目標であるハードウェア命令セットの小ささを保ちながら、関数からの復帰やゼロとの比較といったよく使う定型処理に、プログラマが読みやすい名前を付けられます。

疑似命令とディレクティブ、マクロの違い

.text、.globl、.wordのようなアセンブラディレクティブは、アセンブラ自体への指示です。セクションを選んだり、シンボルを公開したり、データを出力したりするもので、機械語命令には対応しません。疑似命令は、ツールチェーンが定めた固定の意味で必ず本物の命令に変換されます。マクロも同様の展開ですが、プログラマが定義します。ツールチェーンが後で展開を短くすることもあり、たとえば呼び出し先が十分に近ければ、auipcとjalrによるcallをリンク時に1つのjalに置き換えます。

疑似命令の練習問題に挑戦

RISC-Vの疑似命令「nop」(何もしない)は、アセンブラによって実際にはどの命令に置き換えられるか。

  1. Aaddi x0, x0, 0
  2. Bjal ra, 0
  3. Clw x0, 0(sp)
答えと解説を見る

正解：A. addi x0, x0, 0

RISC-Vには「何もしない」専用の命令はなく、nopは「addi x0, x0, 0」として表されます。x0への書き込みは捨てられるので、レジスタもメモリも何も変わりません。同様に「mv rd, rs」は「addi rd, rs, 0」、「j label」は「jal x0, label」、「ret」は「jalr x0, 0(ra)」です。x0を使って命令の種類を少なく保つのがRISC-Vの設計の考え方です。

RISC-Vの疑似命令「ret」は、実際にはどの命令として実行されるか。

  1. Ajal ra, 0
  2. Bjalr x0, 0(ra)
  3. Clw ra, 0(sp)
答えと解説を見る

正解：B. jalr x0, 0(ra)

jalr(jump and link register)は、レジスタの値にオフセットを足した番地へジャンプし、次の命令の番地を書き込み先に入れます。retは「jalr x0, 0(ra)」で、raの番地へ飛び、リンクはx0に捨てます。jalrは関数ポインタや仮想関数の呼び出しのように、行き先が実行時に決まるジャンプにも使われます。raを復元する「lw ra, …」はretの前に行う準備です。

よくある質問

疑似命令と本物の命令の違いは何ですか?

本物の命令は、CPUが実行する独自の機械語エンコーディングを持っています。疑似命令はアセンブラの構文にすぎず、実行前に1つ以上の本物の命令に変換されます。

RISC-Vのliは何に展開されますか?

符号付き12ビットに収まる小さな定数ならx0を使ったaddi 1命令に、それより大きな32ビットの値ならluiとaddiの組に展開され、64ビットの定数ではさらに長い命令列になります。

RISC-Vのnopは本物の命令ですか?

いいえ。nopはaddi x0, x0, 0としてエンコードされる疑似命令です。x0への書き込みは捨てられるため、何も変化しません。

解説の中の「疑似命令」

  • ただし「li」や「mv」のような疑似命令は、アセンブラが1つ以上の本物の命令に置き換えます。

    アセンブリ言語と機械語の関係として正しいものはどれか。

  • bnezは「bne t1, zero, loop」の疑似命令です。

    上のRISC-Vのコードを実行し終えたとき、t0の値はいくらか。

  • 呼び出し規約では戻り先をra(x1)に入れるので、関数の呼び出しは「jal ra, func」、疑似命令では「call func」と書きます。
