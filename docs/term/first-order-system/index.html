一次遅れ系とは

いちじおくれけい

伝達関数が G(s) = K/(1 + Ts) で表される系。K は定常ゲイン、T は時定数である。ステップ入力に対する出力は K(1 − e^(−t/T)) で、t = T で最終値の約63.2%、3T で約95%、5T で約99.3%に達し、行き過ぎ(オーバーシュート)はない。RC回路、熱の系、液面の系など、多くの身近な系がこの形で近似できる。周波数応答では、角周波数 1/T を折れ点として、ゲインが −20 dB/dec で下がる。

「一次遅れ系」は、1分野の5問の練習問題に出てきます(制御工学の基礎など)。

この用語の分野: 制御工学の基礎

一次遅れ系の練習問題に挑戦

伝達関数 G(s) = 2/(1 + 0.5s) の一次遅れ系に、時刻0で大きさ1のステップを入力した。t = 1 s での出力に最も近いものはどれか。

  1. A約1.26
  2. B約1.73
  3. C2
答えと解説を見る

正解：B. 約1.73

一次遅れ系 K/(1 + Ts) のステップ応答は y(t) = K(1 − e^(−t/T)) で、ここでは K = 2、T = 0.5 sです。t = 1 s は時定数の2倍なので、y = 2 × (1 − e^(−2)) ≈ 2 × 0.865 ≈ 1.73 になります。応答は、時定数 T で最終値の約63.2%、3T で約95%、5T で約99.3%に達します。

ある一次遅れ系に大きさ2のステップを入力したところ、出力は最終的に6に落ち着き、入力から0.4 sで最終値の約63%に達した。この系の伝達関数として正しいものはどれか。

  1. A3/(1 + 0.4s)
  2. B3/(1 + 2.5s)
  3. C6/(1 + 0.4s)
答えと解説を見る

正解：A. 3/(1 + 0.4s)

定常ゲインは、出力の最終値を入力の大きさで割った 6 ÷ 2 = 3 です。一次遅れ系のステップ応答が最終値の約63%(1 − e^(−1))に達するまでの時間が時定数なので、T = 0.4 sです。したがって G(s) = 3/(1 + 0.4s) となります。このように、ステップ応答の最終値と立ち上がりの時間から、一次遅れ系のモデルを簡単に作れます。
