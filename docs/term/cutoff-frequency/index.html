カットオフ周波数とは

かっとおふしゅうはすう

フィルタや増幅器の出力が通過域から3 dB(約0.707倍)下がる周波数。RC回路では1/(2πRC)。

「カットオフ周波数」は、2分野の4問の練習問題に出てきます(アナログ・電子回路, デジタル信号処理の基礎など)。

この用語の分野: アナログ・電子回路

RCローパスフィルタのfcの導出

RCローパスフィルタの伝達関数はH = 1/(1 + jωRC)です。その大きさはωRC = 1のとき1/√2になるので、カットオフ周波数はfc = 1/(2πRC)となり、この周波数で位相遅れはちょうど45°です。R = 1 kΩ、C = 1 µFならRC = 1 msで、fcは約159 Hzです。RとCの位置を入れ替えると同じfcのハイパスフィルタになり、RLフィルタではfc = R/(2πL)です。

なぜ−3 dBの点なのか

カットオフ周波数は、出力電圧が通過域の値の1/√2、つまり約0.707倍になる点として定義されます。デシベルでは20·log10(0.707)で約−3.01 dBになり、電力は電圧の2乗に比例するので、電力が半分になる半電力点でもあります。電圧が半分になる−6 dBと混同しないよう注意してください。なお、チェビシェフ型などのフィルタでは−3 dBではなく通過域リプルの端で仕様が規定されることが多いため、どの定義が使われているかを確認します。

カットオフより先の傾きとフィルタの次数

fcより十分高い周波数では、1次フィルタは20 dB/decade、つまり約6 dB/octaveで減衰します。これは緩やかな傾きで、fcの10倍の周波数でも信号は10分の1に下がるだけです。極が1つ増えるごとに20 dB/decadeずつ傾きが加わるので、n次フィルタは20n dB/decadeで減衰します。ADC前段のアンチエイリアシングのように急峻な遮断が必要な場合は、オペアンプを使った2次以上のアクティブフィルタで実現します。

増幅器の帯域幅としてのカットオフ周波数

増幅器では高域側の−3 dB周波数が帯域幅を決め、結合コンデンサがあると低域側にもカットオフが生じます。電圧帰還型オペアンプの閉ループ帯域幅はおおよそ利得帯域幅積をノイズゲインで割った値なので、利得を上げるほど帯域幅は狭くなります。また1極の系では帯域幅とステップ応答が結びついており、10〜90%の立ち上がり時間はおよそ0.35を−3 dB周波数で割った値になります。時間領域と周波数領域を行き来するのに便利な関係です。

カットオフ周波数の練習問題に挑戦

抵抗R = 1 kΩとコンデンサC = 1 µFで構成したRCローパスフィルタのカットオフ周波数に最も近いものはどれか。

  1. A約16 Hz
  2. B約160 Hz
  3. C約1.6 kHz
答えと解説を見る

正解：B. 約160 Hz

RCフィルタのカットオフ周波数は fc = 1/(2πRC) で、RC = 1×10³ × 1×10⁻⁶ = 1 ms なので fc ≈ 159 Hz(約160 Hz)です。この周波数で出力は −3 dB(約0.707倍)、位相は45°遅れ、それより上では周波数が10倍になるごとに −20 dB で減衰します。1次では減衰が緩やかなため、急峻に切りたいときはオペアンプを使った2次以上のアクティブフィルタを使います。

よくある質問

RCフィルタのカットオフ周波数の計算式は?

fc = 1/(2πRC)です。たとえば1 kΩと1 µFでは約159 Hzとなり、この周波数で出力は3 dB低下し、位相は45°ずれます。

カットオフ周波数はなぜ−3 dBで定義されるのですか?

−3 dBでは出力電圧が通過域の値の1/√2となり、供給される電力が半分になります。この半電力点はちょうどRCの項が1になる点でもあるため、簡単な式で表せます。

カットオフ周波数と帯域幅は同じものですか?

ローパスフィルタや増幅器では、通常−3 dBのカットオフ周波数を帯域幅として示します。バンドパスフィルタでは、高域側と低域側の−3 dB周波数の差が帯域幅です。
