カットオフ周波数とは

かっとおふしゅうはすう

フィルタや増幅器の出力が通過域から3 dB(約0.707倍)下がる周波数。RC回路では1/(2πRC)。

「カットオフ周波数」は、1分野の3問の練習問題に出てきます(アナログ・電子回路など)。

この用語の分野: アナログ・電子回路

カットオフ周波数の練習問題に挑戦

抵抗R = 1 kΩとコンデンサC = 1 µFで構成したRCローパスフィルタのカットオフ周波数に最も近いものはどれか。

  1. A約16 Hz
  2. B約160 Hz
  3. C約1.6 kHz
答えと解説を見る

正解：B. 約160 Hz

RCフィルタのカットオフ周波数は fc = 1/(2πRC) で、RC = 1×10³ × 1×10⁻⁶ = 1 ms なので fc ≈ 159 Hz(約160 Hz)です。この周波数で出力は −3 dB(約0.707倍)、位相は45°遅れ、それより上では周波数が10倍になるごとに −20 dB で減衰します。1次では減衰が緩やかなため、急峻に切りたいときはオペアンプを使った2次以上のアクティブフィルタを使います。

解説の中の「カットオフ周波数」

  • RCフィルタのカットオフ周波数は fc = 1/(2πRC) で、RC = 1×10³ × 1×10⁻⁶ = 1 ms なので fc ≈ 159 Hz(約160 Hz)です。

    抵抗R = 1 kΩとコンデンサC = 1 µFで構成したRCローパスフィルタのカットオフ周波数に最も近いものはどれか。

  • カットオフ周波数はローパスと同じ 1/(2πRC) で、それより下では周波数が1/10になるごとに −20 dB で減衰します。

    コンデンサを信号の経路に直列に入れ、抵抗を出力と接地の間に入れたRC回路の特性として正しいものはどれか。

  • −3 dBは電力で約1/2、電圧で 1/√2 ≈ 0.707倍に当たり、フィルタや増幅器ではこの点をカットオフ周波数(帯域の境目)とします。

    フィルタの周波数特性で「−3 dB」の点が表すものとして正しいものはどれか。

「カットオフ周波数」が出てくる問題(3問)

  1. 抵抗R = 1 kΩとコンデンサC = 1 µFで構成したRCローパスフィルタのカットオフ周波数に最も近いものはどれか。
  2. コンデンサを信号の経路に直列に入れ、抵抗を出力と接地の間に入れたRC回路の特性として正しいものはどれか。
  3. フィルタの周波数特性で「−3 dB」の点が表すものとして正しいものはどれか。
