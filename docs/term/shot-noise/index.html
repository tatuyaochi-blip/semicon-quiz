ショットノイズとは

しょっとのいず

光子や電子の数の統計的なゆらぎによる雑音。信号の電子数をNとすると大きさは√Nに比例するため、光が少ないほど信号に対して相対的に大きくなる。

「ショットノイズ」は、1分野の5問の練習問題に出てきます(イメージセンサ・光デバイスなど)。

この用語の分野: イメージセンサ・光デバイス

ショットノイズの発生源

光や電流は、ランダムな時刻に到着する離散的な粒子でできています。各事象が独立であれば、その個数はポアソン統計に従い、分散が平均に等しくなります。そのため、平均N個の光電子からなる信号は約√Nだけゆらぎます。電子回路でも、ダイオードの接合部やフォトダイオードのようにキャリアが独立に障壁を越える場合に同じ現象が現れ、雑音電流のスペクトル密度は2qI(ショットキーの式)になります。これは抵抗の熱雑音とは異なります。熱雑音はランダムな熱運動から生じ、電流が流れていなくても存在します。

画像のSN比を決めるもの

雑音はNの平方根に比例して増えるため、ショットノイズで制限されるSN比(信号対雑音比)はNを√Nで割った値、つまりやはり√Nになります。電子100個なら10、10,000個なら100です。暗いシーンでは集まる電子が少ないため、光子ノイズと読み出しノイズが信号に対して相対的に大きくなり、画像がざらついて見えます。ISO感度を上げても主に信号と雑音が一緒に増幅されるだけで、ショットノイズは減らせません。1画素1回の露光で得られるSN比の上限は、フルウェル容量(飽和電子数)で決まります。

フォトントランスファー法によるセンサー評価

光子ショットノイズは、電子数で表すと分散が平均に等しいため、センサーに内在する校正源として利用できます。フォトントランスファーカーブ(PTC)法では、複数の光量で均一光画像を撮影し、デジタル値(DN)で表した出力の分散を平均に対してプロットします。その傾きから電子数とデジタル値の間の変換ゲインが、低信号側の下限から読み出しノイズが求まり、分散が増えなくなる点がフルウェル容量を示します。これらからダイナミックレンジも求められます。

ビニング、スタッキング、EUVへの影響

ショットノイズは光そのものの性質なので、回路を改良しても除去できず、より多くの光子を集めることだけが有効です。大きな画素、明るいレンズ、ナイトモードでの複数フレームの合成、画素ビニングはいずれもそのための手段です。2×2画素をビニングすると信号は4倍になり、ショットノイズが支配的な場合、SN比はおよそ2倍になります。光子ショットノイズはEUV(極端紫外線)リソグラフィの制約にもなります。波長13.5 nmの光子1個のエネルギーは約92 eVで、193 nmの光子のおよそ14倍あるため、同じ露光量でも光子数がはるかに少なくなり、ランダムなラインエッジラフネスや確率的欠陥を引き起こします。

ショットノイズの練習問題に挑戦

光子の数の統計的なゆらぎによるショットノイズの大きさと、信号電子の数Nの関係として正しいものはどれか。

  1. ANに比例する
  2. B√Nに比例する
  3. CNによらず一定である
答えと解説を見る

正解：B. √Nに比例する

光子は確率的に到来するため、平均N個の信号電子には√N程度のゆらぎ(ポアソン分布)があります。これがショットノイズで、S/N = N/√N = √N となり、光が多いほどS/Nがよくなります。例えば100個なら10、1万個なら100です。光そのものの性質による限界なので、回路をどんなに改良してもなくせず、大きな画素やレンズで光を多く集めることが根本的な対策です。

よくある質問

ショットノイズが信号の平方根に比例するのはなぜですか?

ランダムに到着する光子や電子はポアソン統計に従い、分散が平均に等しくなります。そのため、雑音である標準偏差は平均個数の平方根になります。

ショットノイズと熱雑音の違いは何ですか?

ショットノイズは電荷や光子が離散的であることから生じ、電流や信号の大きさに応じて変化します。熱雑音は抵抗内のキャリアのランダムな熱運動から生じ、電流が流れていなくても存在します。

暗い場所でISO感度を上げるとノイズは減りますか?

ほとんど減りません。ISO感度を上げると信号とショットノイズが同じように増幅されるだけです。SN比を改善できるのは、長時間露光、大きな絞りや画素、フレームの平均化などで、より多くの光を集める方法だけです。
