LDOとは

えるでぃーおー

Low Drop-Out の略で、入力と出力の電圧差が小さくても動作するリニアレギュレータ。ノイズが少ないが、電圧差に電流を掛けた分が熱として失われる。

「LDO」は、2分野の5問の練習問題に出てきます(アナログ・電子回路, 電力管理(ソフトウェア制御)など)。

この用語の分野: アナログ・電子回路

LDOの練習問題に挑戦

リニアレギュレータ(LDOなど)と比べたときのスイッチングレギュレータの特徴として正しいものはどれか。

  1. A効率は低いが、ノイズが非常に少ない
  2. B交流を出力する
  3. C電力変換効率が高いが、スイッチングによるノイズが出やすい
答えと解説を見る

正解：C. 電力変換効率が高いが、スイッチングによるノイズが出やすい

スイッチングレギュレータはトランジスタを数百kHz〜数MHzでオン・オフし、コイルやコンデンサでエネルギーを受け渡すため、入出力の電圧差が大きくても80〜95%程度の高い効率が得られ、昇圧や反転もできます。リニアレギュレータは差分を熱として捨てるので、効率はおよそ出力電圧÷入力電圧です(12 V→3.3 Vなら約28%)。ノイズに敏感な回路ではスイッチングの後にLDOを置く構成がよく使われます。

LDO(低ドロップアウトのリニアレギュレータ)の「ドロップアウト電圧」の意味として正しいものはどれか。

  1. A出力電圧の最大値
  2. B負荷を外したときの出力電圧の変化
  3. C出力を規定の電圧に保つために必要な、入力と出力の最小の電圧差
答えと解説を見る

正解：C. 出力を規定の電圧に保つために必要な、入力と出力の最小の電圧差

ドロップアウト電圧は、レギュレータが出力を保てる入出力の電圧差の最小値です。LDOは出力のトランジスタにPMOSなどを使うことで0.1〜0.3 V程度まで小さくでき、例えばリチウムイオン電池(3.0〜4.2 V)から2.8 Vを作ることもできます。損失は(入力 − 出力)× 電流なので、電圧差が小さいほど効率がよくなります。リプル除去比が高く、ノイズに敏感な回路の電源によく使われます。

解説の中の「LDO」

  • ノイズに敏感な回路ではスイッチングの後にLDOを置く構成がよく使われます。

    リニアレギュレータ(LDOなど)と比べたときのスイッチングレギュレータの特徴として正しいものはどれか。

  • LDOは出力のトランジスタにPMOSなどを使うことで0.1〜0.3 V程度まで小さくでき、例えばリチウムイオン電池(3.0〜4.2 V)から2.8 Vを作ることもできます。

    LDO(低ドロップアウトのリニアレギュレータ)の「ドロップアウト電圧」の意味として正しいものはどれか。

  • スイッチング電源のリプル(数百kHz以上)はPSRRが低い帯域に入りやすいため、LCフィルタやLDO、パスコンで電源をきれいにしてからアナログ回路に供給します。

    回路の電源電圧の変動が出力にどれだけ伝わりにくいかを表す指標はどれか。

  • PMICは、スイッチングレギュレータやLDOを多数まとめた部品で、電池の電圧から必要な電圧を効率よく作り、SoCの指示に従ってDVFSのための電圧の変更や、ブロックごとの電源のオンとオフ、決められた順番での電源の投入を行います。

    スマートフォンなどで使われるPMIC(電源管理IC)の役割として正しいものはどれか。

「LDO」が出てくる問題(5問)

  1. リニアレギュレータ(LDOなど)と比べたときのスイッチングレギュレータの特徴として正しいものはどれか。
  2. LDO(低ドロップアウトのリニアレギュレータ)の「ドロップアウト電圧」の意味として正しいものはどれか。
  3. 入力1.8 Vから出力1.0 Vを作るリニアレギュレータ(LDO)の効率に最も近いものはどれか(レギュレータ自身の消費電流は無視する)。
  4. 回路の電源電圧の変動が出力にどれだけ伝わりにくいかを表す指標はどれか。
  5. スマートフォンなどで使われるPMIC(電源管理IC)の役割として正しいものはどれか。
