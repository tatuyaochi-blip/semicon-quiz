NOR型フラッシュメモリとは

のあがたふらっしゅめもり

セルを並列に接続したフラッシュメモリ。ランダムな読み出しが速く、マイコンのプログラムの格納などに使われる。

「NOR型フラッシュメモリ」は、1分野の1問の練習問題に出てきます(SRAM・フラッシュメモリなど)。

この用語の分野: SRAM・フラッシュメモリ

セルを並列につなぐ構造

NOR型フラッシュメモリは、各セルのトランジスタのドレインをビット線に、ソースを共通のソース線につなぎ、セルをビット線に対して並列に並べた構造です。どれか1つのセルがオンになるとビット線が引き下げられる形がNORゲートに似ていることが、名前の由来です。セルごとにビット線へのコンタクトが必要なため、NAND型よりセルの面積は大きくなりますが、どのセルも他のセルを経由せずに直接読み出せます。セルはNAND型と同じく、コントロールゲートの下に電荷蓄積層をもつトランジスタで、蓄えた電子の量で変わるしきい値電圧を0と1として読み取ります。

書き込みと消去

書き込みでは、ドレインに電圧をかけてチャネルで加速した電子の一部を電荷蓄積層に注入するチャネルホットエレクトロン(CHE)注入がよく使われます。速く書ける代わりにセルあたりの電流が大きいため、一度に書き込めるビット数は限られます。消去は、FN(ファウラー・ノルドハイム)トンネル電流で電子を引き抜く方式が一般的で、セクタやブロックと呼ぶまとまりの単位で行います。消去したビットは1になり、書き込みでは1を0にしか変えられないため、内容を書き換えるには先に消去が必要です。消去は読み出しや書き込みに比べて長い時間がかかる操作です。

XIPと主な用途

NOR型は任意のアドレスをバイトやワードの単位で速く読めるため、CPUがフラッシュから直接命令を取り出して実行するXIP(Execute In Place)ができます。プログラムをRAMにコピーしなくても起動できるので、マイコンのファームウェア、PCやサーバのBIOS/UEFI、FPGAの構成データ、車載機器や通信機器の起動用のコードなどの格納に使われます。容量は数Mbit〜数Gbitと小さく、ビットあたりの価格はNAND型より高いため、大容量のデータの保存にはNAND型が使われます。NAND型ほど強力な誤り訂正や不良ブロックの管理を必要としないことが多い点も、コードの格納に向く理由です。

パラレルNORとシリアルNOR

NOR型フラッシュには、アドレスとデータの端子を並べてもつパラレルNORと、SPIで接続するシリアルNORがあります。パラレルNORはアドレスを与えるとSRAMのように直接データを読み出せ、組込み機器のプログラムの格納に長く使われてきました。しかし多くの端子が必要なため、現在は数本の信号線で済むシリアルNORが主流です。シリアルNORも、データ線を4本や8本に増やすQuad SPIやOctal SPIで読み出しを速め、マイコンのメモリマップドモードを使えばXIPもできます。高い信頼性や長期の供給が求められる車載機器や産業機器では、パラレルNORも引き続き使われています。

NOR型は各セルがビット線に並列につながりランダムアクセスが速いため、CPUがメモリから直接プログラムを読み出して実行できます(XIP: Execute In Place)。そのため機器の起動用プログラムやマイコンのファームウェア、車載機器の制御コードに使われます。容量は数Mbit〜数Gbitと小さく、ビット単価はNANDより高いので、大容量のデータ保存にはNAND型が使われます。

よくある質問

NOR型とNAND型フラッシュの違いは?

NOR型は各セルをビット線に並列につなぐため、任意のアドレスを速く読め、プログラムの直接実行(XIP)に向きます。NAND型はセルを直列につないでコンタクトを減らすため、セルが小さく大容量で安価ですが、読み書きはページ単位です。NOR型は起動用のコードやファームウェア、NAND型はSSDやメモリカードのような大容量の保存に使われます。

NORフラッシュという名前の由来は?

セルがビット線に並列につながり、どれか1つのセルがオンになるとビット線が引き下げられる構造が、NORゲートのトランジスタの並び方に似ているためです。同様に、セルを直列につなぐNAND型は、NANDゲートに似ていることから名付けられています。

NORフラッシュは何に使われますか?

マイコンや組込み機器のファームウェア、PCのBIOS/UEFI、FPGAの構成データ、車載機器の起動用のコードなど、容量は小さくても速く確実に読み出したいコードの格納に使われます。CPUがフラッシュから直接命令を実行するXIPができることが大きな利点です。
