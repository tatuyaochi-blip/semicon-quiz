インパルス応答とは

いんぱるすおうとう

システムに単位インパルス δ[n](n = 0 だけ1で、ほかは0)を入力したときの出力 h[n]。線形時不変(LTI)なシステムでは、任意の入力に対する出力が、入力と h[n] の畳み込み y[n] = Σx[k]h[n − k] で求められるので、h[n] がシステムの性質をすべて表す。h[n] が有限の長さで終わるものをFIRフィルタ、無限に続くものをIIRフィルタと呼ぶ。Σ|h[n]| が有限であることがBIBO安定の条件で、h[n] のz変換が伝達関数 H(z) になる。

「インパルス応答」は、2分野の7問の練習問題に出てきます(デジタル信号処理の基礎, 制御工学の基礎など)。

インパルス応答の練習問題に挑戦

u[n] を単位ステップとする。インパルス応答が次のように表されるLTIシステムのうち、BIBO安定(有界な入力に対して出力が必ず有界)であるものはどれか。

  1. Ah[n] = (−0.9)ⁿu[n]
  2. Bh[n] = u[n]
  3. Ch[n] = (1.1)ⁿu[n]
答えと解説を見る

正解：A. h[n] = (−0.9)ⁿu[n]

LTIシステムがBIBO安定である必要十分条件は、インパルス応答の絶対値の総和 Σ|h[n]| が有限であることです。h[n] = (−0.9)ⁿu[n] では Σ|h[n]| = Σ0.9ⁿ = 1/(1 − 0.9) = 10 で有限なので安定です。h[n] = u[n] は入力をたし続ける累算器で、総和が無限大になり、一定の入力に対して出力が際限なく増えます。(1.1)ⁿ は時間とともに大きくなるので、不安定です。

x[n] = {1, 2, 3}(n = 0, 1, 2)を、インパルス応答 h[n] = {1, −1}(n = 0, 1)のLTIシステムに入力した。出力 y[0]〜y[3] として正しいものはどれか。

  1. A−1, −1, −1, 3
  2. B1, 3, 5, 3
  3. C1, 1, 1, −3
答えと解説を見る

正解：C. 1, 1, 1, −3

畳み込み y[n] = Σx[k]h[n − k] は、h[n] = {1, −1} の場合 y[n] = x[n] − x[n − 1](1つ前の入力との差)になります。y[0] = 1 − 0 = 1、y[1] = 2 − 1 = 1、y[2] = 3 − 2 = 1、y[3] = 0 − 3 = −3 です。出力の長さは、入力の長さ3とインパルス応答の長さ2から 3 + 2 − 1 = 4 になります。

「インパルス応答」が出てくる問題(7問)

  1. u[n] を単位ステップとする。インパルス応答が次のように表されるLTIシステムのうち、BIBO安定(有界な入力に対して出力が必ず有界)であるものはどれか。
  2. x[n] = {1, 2, 3}(n = 0, 1, 2)を、インパルス応答 h[n] = {1, −1}(n = 0, 1)のLTIシステムに入力した。出力 y[0]〜y[3] として正しいものはどれか。
  3. 連続時間の線形な系が安定である(インパルス応答が時間とともに0に近づく)ための条件として正しいものはどれか。
  4. 差分方程式 y[n] = x[n] + 0.5y[n − 1] で表されるシステムに、n = 0 から単位ステップ(n ≥ 0 で x[n] = 1)を入力した。y[−1] = 0 のとき、y[2] として正しいものはどれか。
  5. FIRフィルタ(有限インパルス応答フィルタ)の特徴として正しいものはどれか。
  6. アナログフィルタの伝達関数 H(s) からデジタルフィルタを設計するときに使う、双一次変換の説明として正しいものはどれか。
  7. 線形で時不変な系の伝達関数の説明として正しいものはどれか。
