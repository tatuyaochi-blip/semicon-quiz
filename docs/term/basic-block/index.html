基本ブロックとは

きほんぶろっく

途中に分岐の入口も出口もなく、先頭から末尾まで必ず続けて実行される命令の並び。制御フローグラフの節になり、ブロック内の最適化の単位にもなる。

「基本ブロック」は、1分野の2問の練習問題に出てきます(コンパイラなど)。

この用語の分野: コンパイラ

基本ブロックの練習問題に挑戦

基本ブロックの説明として正しいものはどれか。

  1. A途中に分岐の出入りがなく、必ず続けて実行される命令の並び
  2. B1つの関数の中に含まれる、すべての命令を1つにまとめたもの
  3. Cループの本体を何回分か並べて書き、繰り返しの回数を減らしたもの
答えと解説を見る

正解：A. 途中に分岐の出入りがなく、必ず続けて実行される命令の並び

基本ブロックは、入口が先頭だけ、出口が末尾だけの命令の並びで、一度実行が始まれば途中で抜けることも、途中から入ってくることもありません。分岐の飛び先になる命令や分岐命令の直後で区切って作ります。ブロックの中では実行の順番が決まっているので、局所的な最適化がしやすく、ブロックを節にした制御フローグラフで全体の流れを表します。関数全体は普通いくつもの基本ブロックからなり、ループ本体を並べるのはループ展開です。

解説の中の「基本ブロック」

  • 基本ブロックは、入口が先頭だけ、出口が末尾だけの命令の並びで、一度実行が始まれば途中で抜けることも、途中から入ってくることもありません。

    基本ブロックの説明として正しいものはどれか。

  • 制御フローグラフは、基本ブロックを節、あるブロックの実行のあとに続く可能性のあるブロックへの移り変わり(条件分岐の両方の行き先や、そのまま次のブロックへ進む流れ)を矢印として表したグラフです。

    制御フローグラフで、節と矢印が表しているものの組み合わせとして正しいものはどれか。

「基本ブロック」が出てくる問題(2問)

  1. 基本ブロックの説明として正しいものはどれか。
  2. 制御フローグラフで、節と矢印が表しているものの組み合わせとして正しいものはどれか。
