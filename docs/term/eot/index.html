EOT(等価酸化膜厚)とは

いーおーてぃー

High-k膜などのゲート絶縁膜を、同じゲート容量を与えるSiO2膜の厚さに換算した値。物理的には厚くてもEOTは薄くでき、トンネル電流を抑えながらゲート容量を確保できる。

「EOT(等価酸化膜厚)」は、4分野の7問の練習問題に出てきます(酸化・拡散, 先端トランジスタ(FinFET・GAA), 半導体物性など)。

この用語の分野: 先端トランジスタ(FinFET・GAA)

EOT(等価酸化膜厚)の練習問題に挑戦

EOT(等価酸化膜厚)の説明として正しいものはどれか。

  1. AHigh-k膜などのゲート絶縁膜を、同じゲート容量を与えるSiO2膜の厚さに換算した値
  2. Bゲート絶縁膜の実際の物理的な膜厚
  3. C配線層の厚さ
答えと解説を見る

正解：A. High-k膜などのゲート絶縁膜を、同じゲート容量を与えるSiO2膜の厚さに換算した値

EOTは、ゲート絶縁膜の容量を、SiO2(比誘電率3.9)で実現した場合の膜厚に換算した値で、EOT = 物理膜厚 × 3.9/εです。比誘電率20のHigh-k膜なら、物理膜厚約5 nmでEOT 1 nmとなります。先端品のEOTは界面層を含めて約0.8〜1 nmです。実際の電気的な厚さには、反転層の量子効果などによる分も加わるため、測定値(CET)はEOTより少し大きくなります。

解説の中の「EOT(等価酸化膜厚)」

  • EOTは、ゲート絶縁膜の容量を、SiO2(比誘電率3.9)で実現した場合の膜厚に換算した値で、EOT = 物理膜厚 × 3.9/εです。

    EOT(等価酸化膜厚)の説明として正しいものはどれか。

  • SiO2は約3.9で、ゲート絶縁膜の性能はこの値を基準にした等価酸化膜厚(EOT)で比べます。

    シリコンの比誘電率に最も近い値はどれか。

  • ポリシリコン空乏化とあわせて、物理膜厚より大きい「電気的膜厚(CET)」の原因で、EOTを薄くするほど比重が増します。

    ゲート絶縁膜が非常に薄いMOSFETで、反転層の電子の分布のピークが界面から少し離れた位置にくることによる影響として正…

  • ただし界面層は比誘電率が低くEOTの大部分を占めるため、EOTを下げるには界面層を極力薄くすることが鍵になります。

    High-k/メタルゲートのトランジスタで、シリコンとHigh-k膜(ハフニウム系酸化膜など)の間に、ごく薄いSiO2…

  • 窒素を導入するとホウ素の拡散が抑えられ、比誘電率も3.9から5〜6程度まで上がるため、同じEOTで物理的に厚くでき、リークも減ります。

「EOT(等価酸化膜厚)」が出てくる問題(7問)

  1. EOT(等価酸化膜厚)の説明として正しいものはどれか。
  2. シリコンの比誘電率に最も近い値はどれか。
  3. ゲート絶縁膜が非常に薄いMOSFETで、反転層の電子の分布のピークが界面から少し離れた位置にくることによる影響として正しいものはどれか。
  4. High-k/メタルゲートのトランジスタで、シリコンとHigh-k膜(ハフニウム系酸化膜など)の間に、ごく薄いSiO2などの層を設けることが多い理由はどれか。
  5. ゲート酸化膜に窒素を導入して酸窒化膜(SiON)にする主な目的はどれか。
  6. 熱酸化で形成したSiO2膜の比誘電率に最も近い値はどれか。
  7. 薄いゲート酸化膜の表面に、プラズマで生成した窒素を導入する処理を何と呼ぶか。
