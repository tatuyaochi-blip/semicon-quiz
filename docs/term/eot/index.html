EOT(等価酸化膜厚)とは

いーおーてぃー

High-k膜などのゲート絶縁膜を、同じゲート容量を与えるSiO2膜の厚さに換算した値。物理的には厚くてもEOTは薄くでき、トンネル電流を抑えながらゲート容量を確保できる。

やさしい解説で読む: トンネル効果とは? 薄い壁を電子がすり抜けるしくみ

「EOT(等価酸化膜厚)」は、4分野の7問の練習問題に出てきます(酸化・拡散, 先端トランジスタ(FinFET・GAA), 半導体物性など)。

この用語の分野: 先端トランジスタ(FinFET・GAA)

EOTの計算方法

単位面積あたりのゲート容量はε/tなので、どんな絶縁膜でも、同じ容量を与えるSiO₂(比誘電率3.9)の膜厚に換算できます。EOT = 物理膜厚×3.9/εです。ε = 20のhigh-k膜なら、物理膜厚約5 nmでEOTは1 nmになります。実際のゲートスタックは複数の層が直列になったものなので、各層のEOTを単純に足し合わせます。薄いSiO₂界面層はそのままの厚さで加わり、その上のhigh-k層は物理膜厚に3.9/εを掛けた分だけ寄与します。

ゲート絶縁膜がhigh-kに移行した理由

トランジスタを微細化するには、ゲートがチャネルを制御し続けられるようにゲート容量を増やす必要があります。純粋なSiO₂ではそれは膜を薄くすることを意味しますが、酸化膜を通る直接トンネル電流は膜が薄くなるにつれて指数関数的に増え、約2 nmを下回るとゲートリーク電流が電力と信頼性の深刻な問題になります。酸化ハフニウム(HfO₂、εは約20〜25)のようなhigh-k材料なら、物理的にはずっと厚い膜で同じ容量が得られるため、トンネル電流を抑えながらEOTを薄くし続けられます。その中間段階として使われたのが酸窒化シリコン(SiON、εは約5〜6)で、ボロンの突き抜けを防ぐ点でも重宝されました。

界面層が微細化の制約になる

high-k膜をシリコンの上に直接置くと、界面欠陥、固定電荷、リモートフォノン散乱によってチャネルの移動度が下がります。そのため、厚さ約0.5〜1 nmの薄いSiO₂またはSiONの界面層を下に残します。この層は誘電率が低いので全体のEOTの大きな部分を占め、EOTが約0.8〜1 nmの最近のゲートスタックでは、界面の質を落とさずに界面層をいかに薄くできるかが鍵になります。酸化膜表面のプラズマ窒化は、Si/SiO₂界面を乱さずに誘電率を上げる方法の一つです。

EOTとCETの違い

EOTは絶縁膜スタックだけの特性です。反転状態で測定した容量から求める容量換算膜厚(CET)はこれより大きくなります。量子閉じ込めにより反転層電荷のピークが界面から約1 nm内側にずれるため、SiO₂換算で約0.3〜0.4 nmが加わるからです。ポリシリコンゲートでは、ゲート電極内の空乏化がさらに加わります。メタルゲートではこの項がなくなり、これがhigh-kとメタルゲートを組み合わせる理由の一つです。EOTが薄くなるほど、こうした一定のペナルティが電気的膜厚に占める割合は大きくなっていきます。

EOT(等価酸化膜厚)の練習問題に挑戦

  2. Bゲート絶縁膜の実際の物理的な膜厚
  3. C配線層の厚さ
答えと解説を見る

正解：A. High-k膜などのゲート絶縁膜を、同じゲート容量を与えるSiO2膜の厚さに換算した値

EOTは、ゲート絶縁膜の容量を、SiO2(比誘電率3.9)で実現した場合の膜厚に換算した値で、EOT = 物理膜厚 × 3.9/εです。比誘電率20のHigh-k膜なら、物理膜厚約5 nmでEOT 1 nmとなります。先端品のEOTは界面層を含めて約0.8〜1 nmです。実際の電気的な厚さには、反転層の量子効果などによる分も加わるため、測定値(CET)はEOTより少し大きくなります。

よくある質問

半導体のEOTとは何の略ですか?

EOTはEquivalent Oxide Thickness(等価酸化膜厚)の略です。実際のゲート絶縁膜と同じゲート容量を与えるSiO₂の膜厚のことで、異なる材料でできたスタックを同じ尺度で比較できます。

high-k膜の膜厚をEOTに換算するには?

物理膜厚に、3.9をその膜の比誘電率で割った値を掛けます。たとえばε = 22の膜3 nmはEOT約0.53 nmに相当し、これに界面層自体のEOTを足します。

EOTとCETの違いは?

EOTは絶縁膜スタックだけを表し、CETは反転状態で測定した容量から求める電気的な膜厚です。反転層電荷が量子力学的効果で界面から内側にずれることと、ポリシリコンゲートの場合はゲートの空乏化のために、CETはEOTより大きくなります。
