命令セットアーキテクチャ(ISA)とは

めいれいせっとあーきてくちゃ

プロセッサが実行できる命令やレジスタなど、ソフトウェアから見たプロセッサの仕様。x86、Arm、RISC-Vなど。

この用語の分野: CPU・アーキテクチャ

解説の中の「命令セットアーキテクチャ(ISA)」

  • ARM、x86、RISC-Vは命令セットアーキテクチャ(ISA)の名前で、プロセッサが理解する命令の種類、レジスタ、メモリの扱い方など、ソフトウェアとハードウェアの約束ごとを定めます。

    ARM、x86、RISC-Vといった名前が主に表しているものはどれか。

  • RISC-Vは2010年にカリフォルニア大学バークレー校で開発が始まったオープンなISAで、仕様が公開され、ライセンス料なしで誰でも実装できます。

    RISC-Vの特徴として正しいものはどれか。

「命令セットアーキテクチャ(ISA)」が出てくる問題(2問)

  1. ARM、x86、RISC-Vといった名前が主に表しているものはどれか。
  2. RISC-Vの特徴として正しいものはどれか。
