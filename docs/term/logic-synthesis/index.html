論理合成とは

ろんりごうせい

RTLで記述された回路を、セルライブラリのゲートを使ったネットリストに変換する設計工程。

この用語の分野: LSI設計フロー・EDA

解説の中の「論理合成」

  • 論理合成は、RTLで書かれた回路の動作記述を、セルライブラリにある論理ゲートやフリップフロップの接続情報(ネットリスト)に変換する工程です。

    論理合成の説明として正しいものはどれか。

  • テストパターンを用意する必要がなく、すべての入力の組み合わせについて等価性を保証できるため、論理合成や配置配線、ECOの前後の確認に使われます。

    論理合成の前後で回路の論理が変わっていないことを、シミュレーションを使わずに数学的に確認する手法はどれか。

  • 「always @(posedge clk)」は、クロックの立ち上がりの瞬間にだけ中の代入を行うという意味で、論理合成はこれをエッジで動くフリップフロップにします。
