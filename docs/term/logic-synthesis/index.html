論理合成とは

ろんりごうせい

RTLで記述された回路を、セルライブラリのゲートを使ったネットリストに変換する設計工程。

「論理合成」は、3分野の23問の練習問題に出てきます(LSI設計フロー・EDA, ハードウェア記述言語と検証, 論理回路など)。

この用語の分野: LSI設計フロー・EDA

論理合成ツールが行うこと

論理合成には三つの入力があります。ハードウェア記述言語で書かれた RTL、各ゲートの機能・タイミング・面積・電力を記述したセルライブラリ、そしてクロック周期や入出力遅延などの制約で、制約は通常 SDC 形式で与えます。ツールはまず RTL を汎用ロジックに変換し、レジスタ、マルチプレクサ、算術演算器を推定します。次にテクノロジーに依存しない形でブール論理を最適化し、ライブラリのセルにマッピングしたうえで、制約を満たすようセルのサイジング、バッファ挿入、パスの再構成を行います。出力はゲートレベルのネットリストと、タイミング・面積・電力のレポートです。

RTL がハードウェアになるしくみ

論理合成はコードを命令ではなく回路に変換するので、すべてのブロックが並行して動作します。always @(posedge clk) ブロックはエッジトリガのフリップフロップになります。else のない if のように、組み合わせ回路のブロックがすべての分岐で出力に代入していないと、ツールは前の値を保持するためにラッチを推定せざるをえません。論理合成はセンシティビティリストを無視するため、リストが不完全だとシミュレーションとゲートの動作が食い違いますが、@(*) を使えば防げます。#10 のような遅延や $display のようなテストベンチ用タスクはシミュレーション専用で、合成では無視されます。

制約が結果を左右する

同じ RTL でも、まったく異なるネットリストになりえます。クロックが厳しいと、ツールは大きく高速なセル、低しきい値電圧セル、並列構造(リップルキャリー加算器の代わりにキャリールックアヘッド加算器など)を選び、面積とリーク電流が増えます。クロックに余裕があれば面積を最小化できます。フォールスパスやマルチサイクルパスは、ツールが労力をかけなくてよい箇所を示します。誤った制約は危険で、すべてのツールチェックに合格しても実際のシリコンで動かないことがあります。レイアウト前の配線遅延は推定値にすぎないため、物理情報を考慮した論理合成では配置情報を使って結果の一致度を高めます。

設計フローでの位置づけ

典型的なフローは、仕様策定、RTL 設計、論理合成、配置配線、寄生抽出、サインオフのタイミング解析を経てテープアウトに至ります。その上流に位置する高位合成(HLS)は、演算をクロックサイクルに割り当てて C や C++ から RTL を生成し、その RTL を論理合成がゲートに変換します。形式等価性検証は、シミュレーションを使わずにネットリストが RTL と同じ論理を実装していることを証明します。テスト用のスキャン挿入は、論理合成中またはその直後に行うのが一般的です。FPGA では、論理合成がロジックをスタンダードセルではなくルックアップテーブルとフリップフロップにマッピングします。

  2. BRTLの記述を、セルライブラリのゲートで構成したネットリストに変換する工程
  3. Cウエハ上に回路パターンを転写する工程

正解：B. RTLの記述を、セルライブラリのゲートで構成したネットリストに変換する工程

論理合成は、RTLで書かれた回路の動作記述を、セルライブラリにある論理ゲートやフリップフロップの接続情報(ネットリスト)に変換する工程です。タイミング・面積・消費電力の制約を与えると、ツールが論理式を簡単にし、適切な駆動力のセルを選んで制約を満たすように最適化します。セルを並べて配線するのは配置配線、ウエハに転写するのはリソグラフィです。

論理合成の前後で回路の論理が変わっていないことを、シミュレーションを使わずに数学的に確認する手法はどれか。

  1. A形式的等価性検証(フォーマル検証)
  2. BDRC
  3. Cダイシング
答えと解説を見る

正解：A. 形式的等価性検証(フォーマル検証)

形式的等価性検証は、2つの回路が同じ論理関数を実現しているかを、数学的な手法で網羅的に確かめる検証です。テストパターンを用意する必要がなく、すべての入力の組み合わせについて等価性を保証できるため、論理合成や配置配線、ECOの前後の確認に使われます。シミュレーションで全組み合わせを試すのは、入力が数十ビットあるだけで現実的に不可能です。DRCは図形の規則の検査です。

よくある質問

論理合成と高位合成の違いは何ですか?

高位合成は C や C++ によるアルゴリズム記述を RTL に変換し、各演算をどのクロックサイクルで実行するかを決めます。論理合成は RTL を受け取り、ライブラリセルからなるゲートレベルのネットリストに変換します。

論理合成で意図しないラッチができるのはなぜですか?

組み合わせ回路のブロックで、ある経路で出力に代入されないと、出力は前の値を記憶しなければならず、それを実現する手段がラッチしかないからです。デフォルト値を代入するか、すべての場合を網羅すれば解消できます。

論理合成の入力と出力は何ですか?

入力は RTL、セルライブラリ、タイミング制約(通常は SDC)です。出力はゲートレベルのネットリストと、タイミング・面積・電力のレポートです。
