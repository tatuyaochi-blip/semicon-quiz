TEM(透過電子顕微鏡)とは

てぃーいーえむ

薄くした試料に電子線を透過させて観察する顕微鏡。原子レベルの分解能で、断面の構造や結晶の欠陥を調べられる。

この用語の分野: 計測・分析

解説の中の「TEM(透過電子顕微鏡)」

  • TEMは試料を透過した電子で像をつくるため、試料を非常に薄くする必要があります。

    透過電子顕微鏡(TEM)で試料を観察するために必要な前処理として正しいものはどれか。

  • STEM(走査型透過電子顕微鏡)では、細い電子線を試料上で走査します。

    TEMで、細く絞った電子線を走査しながら、透過した電子のエネルギーの損失を測って元素や化学状態の分布を調べる手法はどれ…

  • TEM用の薄片試料の作製、不良箇所の断面観察、試作チップの配線の修正などに使われます。

    集束イオンビーム(FIB)装置の主な用途はどれか。

「TEM(透過電子顕微鏡)」が出てくる問題(6問)

  1. 透過電子顕微鏡(TEM)で試料を観察するために必要な前処理として正しいものはどれか。
  2. SEMやTEMと組み合わせて使われるEDX(エネルギー分散型X線分光)で分かることはどれか。
  3. TEMで、細く絞った電子線を走査しながら、透過した電子のエネルギーの損失を測って元素や化学状態の分布を調べる手法はどれか。
  4. 集束イオンビーム(FIB)装置の主な用途はどれか。
  5. 光学顕微鏡で、数十nmの微細なパターンを直接観察できない主な理由はどれか。
  6. 断面の形をくわしく調べるために、ウエハを割ったり削ったりしてから観察する方法の特徴として正しいものはどれか。
