ULPAフィルタとは

うるぱふぃるた

HEPAフィルタよりさらに微細な粒子まで捕集する高性能のエアフィルタ。高い清浄度のクリーンルームの天井に使われる。

「ULPAフィルタ」は、2分野の6問の練習問題に出てきます(クリーンルーム・製造装置, 環境安全など)。

この用語の分野: クリーンルーム・製造装置

ULPAフィルタの練習問題に挑戦

クリーンルームの空気から微粒子を取り除くために使われる高性能フィルタはどれか。

  1. Aローパスフィルタ
  2. Bカラーフィルタ
  3. CULPAフィルタ(HEPAフィルタ)
答えと解説を見る

正解：C. ULPAフィルタ(HEPAフィルタ)

HEPAフィルタやさらに高性能なULPAフィルタは、細かいガラス繊維などを折りたたんだろ材で空気中の微粒子をとらえるエアフィルタで、クリーンルームの天井などに設置されます。繊維の隙間より小さな粒子も、慣性や拡散で繊維に衝突してとらえられます。ローパスフィルタは電気回路で高い周波数を除く回路、カラーフィルタはイメージセンサなどで色を分ける部品です。

クリーンルームで、空気中にイオンを供給してウエハや装置の帯電を中和する装置はどれか。

  1. AULPAフィルタ
  2. Bイオナイザ(除電装置)
  3. Cスクラバー
答えと解説を見る

正解：B. イオナイザ(除電装置)

乾燥したクリーンルームでは静電気が発生しやすく、帯電したウエハやマスクはパーティクルを引き寄せたり、静電気放電でデバイスやマスクのパターンを損傷したりします。イオナイザは、コロナ放電などで正と負のイオンをつくって空気中に供給し、物体の帯電を中和します。接地できない絶縁物の除電に特に有効です。ULPAフィルタは粒子の除去、スクラバーは排ガスの洗浄に使います。

「ULPAフィルタ」が出てくる問題(6問)

  1. クリーンルームの空気から微粒子を取り除くために使われる高性能フィルタはどれか。
  2. クリーンルームで、空気中にイオンを供給してウエハや装置の帯電を中和する装置はどれか。
  3. 製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。
  4. 天井にフィルタとファンを一体化して並べ、清浄な空気を送り出す装置はどれか。
  5. HEPAフィルタの性能の一般的な定義として正しいものはどれか。
  6. 排ガス中の酸性ガスなどを、水や薬液と接触させて吸収・除去する装置はどれか。
