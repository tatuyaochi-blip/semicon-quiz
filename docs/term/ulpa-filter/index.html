ULPAフィルタとは

うるぱふぃるた

HEPAフィルタよりさらに微細な粒子まで捕集する高性能のエアフィルタ。高い清浄度のクリーンルームの天井に使われる。

この用語の分野: クリーンルーム・製造装置

解説の中の「ULPAフィルタ」

  • HEPAフィルタやさらに高性能なULPAフィルタは、細かいガラス繊維などを折りたたんだろ材で空気中の微粒子をとらえるエアフィルタで、クリーンルームの天井などに設置されます。

    クリーンルームの空気から微粒子を取り除くために使われる高性能フィルタはどれか。

  • ULPAフィルタは粒子の除去、スクラバーは排ガスの洗浄に使います。

    クリーンルームで、空気中にイオンを供給してウエハや装置の帯電を中和する装置はどれか。

  • OHTは装置間の搬送、ULPAフィルタは空気の清浄化を担います。

    製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。

「ULPAフィルタ」が出てくる問題(6問)

  1. クリーンルームの空気から微粒子を取り除くために使われる高性能フィルタはどれか。
  2. クリーンルームで、空気中にイオンを供給してウエハや装置の帯電を中和する装置はどれか。
  3. 製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。
  4. 天井にフィルタとファンを一体化して並べ、清浄な空気を送り出す装置はどれか。
  5. HEPAフィルタの性能の一般的な定義として正しいものはどれか。
  6. 排ガス中の酸性ガスなどを、水や薬液と接触させて吸収・除去する装置はどれか。
