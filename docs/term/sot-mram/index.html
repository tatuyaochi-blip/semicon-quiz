SOT-MRAMとは

えすおーてぃーえむらむ

重金属層に流す電流によるスピン軌道トルクで磁化を反転させるMRAM。書き込みと読み出しの電流経路を分けられ、高速で書き換えに強い。

この用語の分野: 次世代メモリ

解説の中の「SOT-MRAM」

  • SOT-MRAMは、MTJの下の重金属層などに電流を流したときに生じるスピン軌道トルクで記録層の磁化を反転させます。
