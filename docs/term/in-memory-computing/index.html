インメモリコンピューティングとは

いんめもりこんぴゅーてぃんぐ

メモリアレイの中で積和演算などの計算を行い、メモリとプロセッサの間のデータ移動を減らす考え方。抵抗変化素子などをAIの推論処理に使う研究が進んでいる。

「インメモリコンピューティング」は、1分野の1問の練習問題に出てきます(次世代メモリなど)。

この用語の分野: 次世代メモリ

インメモリコンピューティングの練習問題に挑戦

抵抗変化型メモリなどを使ったインメモリコンピューティングで期待される主な用途はどれか。

  1. Aディスプレイの発光素子として使う
  2. B電池の電極として使う
  3. Cメモリアレイの中で積和演算を行い、AI処理のデータ移動と消費電力を減らす
答えと解説を見る

正解：C. メモリアレイの中で積和演算を行い、AI処理のデータ移動と消費電力を減らす

AIの処理では膨大な積和演算が必要で、メモリと演算器の間のデータ移動が消費電力の大半を占めます。抵抗変化素子をアレイに並べ、重みをコンダクタンスとして記憶し、入力を電圧で与えると、オームの法則(I = GV)で掛け算、キルヒホッフの電流則で足し算が配線上で一度に行えます。ただしアナログ演算なので、素子のばらつきやADCの精度が課題です。

「インメモリコンピューティング」が出てくる問題(1問)

  1. 抵抗変化型メモリなどを使ったインメモリコンピューティングで期待される主な用途はどれか。
