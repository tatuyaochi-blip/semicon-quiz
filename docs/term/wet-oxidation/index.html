ウェット酸化とは

うぇっとさんか

水蒸気を含む雰囲気で行う熱酸化。ドライ酸化より成長が速く、厚い酸化膜をつくるのに使われる。

この用語の分野: 酸化・拡散

解説の中の「ウェット酸化」

  • 水蒸気を使うウェット酸化は、酸化剤のH2OのSiO2中への溶解度がO2より数百倍高いため、ドライ酸化より成長速度が数倍〜10倍程度速くなります。

    シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。

  • 例えばウェット酸化で1時間に得られる厚さは、900 ℃で約200 nm、1100 ℃で約700 nmと大きく違います。

    熱酸化の温度を上げると、同じ時間で得られる酸化膜の厚さはどうなるか。

  • ウェット酸化では水蒸気を使い、Si + 2H2O → SiO2 + 2H2 の反応が起こり、生じた水素が膜中に一部残るため、ウェットの膜はやや密度が低くなります。

    シリコンのドライ熱酸化で起こる化学反応として正しいものはどれか。

「ウェット酸化」が出てくる問題(3問)

  1. シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。
  2. 熱酸化の温度を上げると、同じ時間で得られる酸化膜の厚さはどうなるか。
  3. シリコンのドライ熱酸化で起こる化学反応として正しいものはどれか。
