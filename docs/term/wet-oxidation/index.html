ウェット酸化とは

うぇっとさんか

水蒸気を含む雰囲気で行う熱酸化。ドライ酸化より成長が速く、厚い酸化膜をつくるのに使われる。

この用語の分野: 酸化・拡散

解説の中の「ウェット酸化」

  • 水蒸気を使うウェット酸化は、酸化剤のSiO2中への溶解度が高いため、ドライ酸化より酸化膜の成長速度がかなり速くなります。

    シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。

  • 純水を沸騰させる方法に比べて汚染が少なく、水蒸気の量を制御しやすいため、ウェット酸化の方法として広く使われています。

    パイロジェニック酸化(水素燃焼酸化)の説明として正しいものはどれか。

  • 厚い膜を短時間でつくりたい場合は、高温のウェット酸化が使われます。

    熱酸化の温度を上げると、同じ時間で得られる酸化膜の厚さはどうなるか。

「ウェット酸化」が出てくる問題(4問)

  1. シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。
  2. パイロジェニック酸化(水素燃焼酸化)の説明として正しいものはどれか。
  3. 熱酸化の温度を上げると、同じ時間で得られる酸化膜の厚さはどうなるか。
  4. シリコンのドライ熱酸化で起こる化学反応として正しいものはどれか。
