リモートアテステーションとは

りもーとあてすてーしょん

機器が自分の中で動くソフトウェアの状態を、チップの中の鍵で署名して遠くのサーバに示し、信頼できるかを確かめてもらう仕組み。

「リモートアテステーション」は、1分野の2問の練習問題に出てきます(ハードウェアセキュリティなど)。

この用語の分野: ハードウェアセキュリティ

何を証明する仕組みか

リモートアテステーションは、ネットワークの向こうにある機器が、どのハードウェアの上でどのソフトウェアを起動したかを、相手のサーバに信頼できる形で示す仕組みです。機器の中のソフトウェアが自分で「正常です」と答えるだけでは、乗っ取られたソフトウェアも同じ答えを返せます。そこで、起動時に記録した測定値(ソフトウェアのハッシュ値)に、チップの中から取り出せない鍵で署名して送ります。証拠を出す機器、証拠を確かめる検証者、その結果を使ってデータやサービスを渡すかを決める側に役割を分けて考えるのが一般的です。

TPMを使った手順

PCなどでは、起動の各段階が次に実行するソフトウェアのハッシュ値をTPMのPCRに順に拡張していきます(メジャードブート)。検証するサーバは、使い回しを防ぐための新しい乱数(ノンス)を送り、TPMはPCRの値とノンスをまとめて、外に出せないアテステーション鍵で署名します(クォート)。機器はこれに起動の記録(イベントログ)を添えて返します。サーバは署名を確かめ、イベントログからPCRの値を計算し直して一致を確認し、各測定値を正しいとわかっている値と照合します。鍵が本物のTPMのものであることは、TPMのメーカーから続く証明書の連鎖で確かめます。

機密コンピューティングと組込み機器での利用

クラウドの機密コンピューティングでは、AMD SEV-SNPやIntel TDXなどの機能で暗号化した仮想マシンの初期状態をCPUが測定し、CPUの中の鍵で署名したレポートを出します。利用者は、レポートを検証して期待どおりの仮想マシンだと確かめてから、データを復号する鍵を渡します。スマートフォンでは、鍵が安全なハードウェアの中で作られたことや、機器の起動状態を示すために使われます。小さなマイコンでは、TCGが定めたDICEのように、層ごとにその層の測定値から鍵を導き出す軽量な方式も使われます。企業のネットワークに接続する機器の健全性の確認にも使われます。

証明できることの限界

アテステーションが示すのは、測定した時点で何が読み込まれたかです。起動後に実行中のソフトウェアがメモリ上で攻撃されても、起動時の測定値は変わらないことがあります。また、正しい値の一覧をソフトウェアの更新に合わせて管理しないと、正常な機器を拒否したり、古い脆弱な版を受け入れたりします。機器ごとの鍵は個体の追跡に使われうるため、プライバシーへの配慮も必要です。証明の信頼性は、鍵を守るハードウェアと、その製造者を信頼できることが前提になります。

答えと解説を見る

正解：C. 機器が、自分の中で動いているソフトウェアの状態を、チップの中の鍵で署名した形で遠くのサーバに示し、信頼できるかを確かめてもらう

リモートアテステーションでは、機器がTPMやTEEに記録されたソフトウェアの測定値を、チップの中から取り出せない鍵で署名してサーバに送ります。サーバは署名と測定値を確かめ、決められたソフトウェアで動いている機器にだけ、秘密のデータやサービスを渡します。クラウドで機密の計算を任せるときや、企業のネットワークにつなぐ機器を確かめるときなどに使われます。

よくある質問

リモートアテステーションとは何ですか?

機器が、自分の中で起動したソフトウェアの測定値を、チップの中の取り出せない鍵で署名して遠くのサーバに送り、信頼できる状態かを確かめてもらう仕組みです。サーバは検証に合格した機器にだけ、秘密のデータやサービス、ネットワークへのアクセスを渡します。

セキュアブートとの違いは何ですか?

セキュアブートは、署名の確認に失敗したソフトウェアをその機器の中で起動させない仕組みです。リモートアテステーションは、何が起動したかの記録を外部に示し、判断を相手のサーバに任せる仕組みです。両者は組み合わせて使われます。

ノンスは何のために使いますか?

検証者が毎回新しい乱数を送り、機器がそれを含めて署名することで、その報告が今作られたものだと確かめられます。ノンスがないと、正常だったときの古い報告を記録しておいて再送する攻撃(リプレイ)を防げません。
