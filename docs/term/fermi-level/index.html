フェルミ準位とは

ふぇるみじゅんい

電子がその準位を占める確率がちょうど1/2になるエネルギー。n型では伝導帯側に、p型では価電子帯側に寄る。

「フェルミ準位」は、3分野の9問の練習問題に出てきます(半導体物性, MOSFET, 酸化・拡散など)。

この用語の分野: 半導体物性

フェルミ準位の物理的な意味

フェルミ・ディラック分布関数 f(E) = 1/(1 + exp((E − EF)/kT)) は、エネルギーEの状態を電子が占める確率を表し、E = EFでちょうど1/2になります。EFより数kT上では(室温でkTは約0.026 eV)、占有確率はほぼ指数関数的に下がるため、電子密度は n = Nc·exp(−(Ec − EF)/kT)、正孔密度は p = Nv·exp(−(EF − Ev)/kT) と表せます。EFは電子の電気化学ポテンシャルなので、許容される状態が存在しないバンドギャップの中に位置することもできます。

ドーピングと温度による移動

真性シリコンのフェルミ準位は、ミッドギャップより約0.01 eV下にあります。伝導帯の有効状態密度が価電子帯より大きいためです。ドナーはEFを伝導帯側へ押し上げ、Ec − EF ≈ kT·ln(Nc/ND) に従って、NDが10倍になるごとに約60 mV動きます。アクセプタはEFを価電子帯側へ押し下げます。およそ10¹⁸〜10¹⁹ cm⁻³を超えるとEFはバンドの中に入り、縮退半導体になります。温度が上がると真性キャリア密度が増えてEFはミッドギャップ側に戻り、これがMOSFETのしきい値電圧が1 °Cあたり約1〜2 mV下がる理由の1つです。

接合やMOS構造でフェルミ準位がそろう

熱平衡状態では、どんな構造でもフェルミ準位は平ら(一定)です。そのためフェルミ準位の異なる2つの材料を接合すると、両者がそろうまで電荷が移動します。その結果生じるバンドの曲がりが、PN接合の内蔵電位や、MOS構造で金属と半導体の仕事関数差によって決まるフラットバンド電圧になります。仕事関数はEFから真空準位までのエネルギーで、ドーピングによって変わりますが、伝導帯の下端から測る電子親和力(シリコンで約4.05 eV)は変わりません。電圧Vを加えると、両側のフェルミ準位はqVだけずれます。

非平衡での擬フェルミ準位

光照射や電流注入がある状態では、電子と正孔を1つのフェルミ準位で表すことはできなくなります。そこで電子と正孔それぞれに擬フェルミ準位EFnとEFpを使い、n = ni·exp((EFn − Ei)/kT)、p = ni·exp((Ei − EFp)/kT) と表します。両者の差は np = ni²·exp((EFn − EFp)/kT) を決め、順バイアスのダイオードや光を当てた太陽電池では端子電圧に対応します。電流密度はそれぞれの擬フェルミ準位の勾配に比例するため、擬フェルミ準位が平らなら、そのキャリアの正味の電流は流れていません。

フェルミ準位の練習問題に挑戦

n型半導体のフェルミ準位の位置として正しいものはどれか。

  1. A真性フェルミ準位より価電子帯側にある
  2. B真性フェルミ準位より伝導帯側にある
  3. C常に価電子帯の中にある
答えと解説を見る

正解：B. 真性フェルミ準位より伝導帯側にある

n型では伝導帯の電子が多いため、フェルミ準位はギャップ中央付近の真性フェルミ準位より伝導帯側に移ります。位置は Ec − EF ≈ kT·ln(Nc/ND) で決まり、ドナー濃度が10倍になるごとに約60 mV(室温)ずつ伝導帯に近づきます。p型では逆に価電子帯側に移ります。フェルミ準位は常に禁制帯の中にあるとは限らず、非常に高濃度では帯の中に入ります(縮退半導体)。

フェルミ準位の意味として正しいものはどれか。

  1. A価電子帯の上端のエネルギー
  2. B伝導帯の下端のエネルギー
  3. C電子が占有する確率がちょうど1/2になるエネルギー
答えと解説を見る

正解：C. 電子が占有する確率がちょうど1/2になるエネルギー

フェルミ準位は、フェルミ-ディラック分布で電子の占有確率がちょうど1/2になるエネルギーで、電子の「水位」のようなものです。真性半導体ではギャップのほぼ中央、n型では伝導帯側、p型では価電子帯側にあります。熱平衡では接合した物質どうしでフェルミ準位が一直線にそろい、その結果PN接合の内蔵電位やMOSのフラットバンド電圧が生まれます。電圧をかけると両側のフェルミ準位は qV だけずれます。

よくある質問

状態のないバンドギャップ中にフェルミ準位があってよいのはなぜですか?

フェルミ準位は電子の電気化学ポテンシャルという統計的なパラメータで、電子が占める状態そのものではないからです。フェルミ準位が決めるのは、その上下のバンドに実際に存在する状態の占有確率だけです。

フェルミ準位と仕事関数の違いは?

フェルミ準位はエネルギーの位置で、仕事関数は電子をフェルミ準位から真空準位まで移すのに必要なエネルギーです。半導体ではドーピングでフェルミ準位が動くため、仕事関数も変わります。

縮退半導体とは何ですか?

シリコンではおよそ10¹⁸〜10¹⁹ cm⁻³を超えるほど高濃度にドープされ、フェルミ準位が伝導帯や価電子帯の中に入った半導体です。ほとんど金属のようにふるまい、np = ni²のような単純な関係は正確には成り立たなくなります。

「フェルミ準位」が出てくる問題(9問)

  1. n型半導体のフェルミ準位の位置として正しいものはどれか。
  2. フェルミ準位の意味として正しいものはどれか。
  3. 不純物濃度が非常に高く、フェルミ準位が伝導帯や価電子帯の中に入り込んだ半導体を何と呼ぶか。
  4. シリコンの真性フェルミ準位が、バンドギャップのちょうど中央からわずかにずれる理由として正しいものはどれか。
  5. 半導体の真空準位から伝導帯の下端までのエネルギー差を何と呼ぶか。
  6. 物質の仕事関数の定義として正しいものはどれか。
  7. 光の照射や電流の注入によって熱平衡から外れた半導体で、電子密度と正孔密度をそれぞれ表すために導入される準位を何と呼ぶか。
  8. MOSFETのしきい値電圧の絶対値は、温度が上がると一般にどうなるか。
  9. 不純物濃度が真性キャリア密度より十分高い領域で、ヒ素などの拡散係数が濃度によって変わる現象についての説明として正しいものはどれか。
