UDPとは

ゆーでぃーぴー

User Datagram Protocolの略。トランスポート層のコネクションレス型のプロトコル。ヘッダは8バイトで、ポート番号、長さ、チェックサムだけをもつ。接続の手順も、確認応答や再送も、順序の制御もしないので、遅れが小さい。DNSの問い合わせ、音声や映像の通話、オンラインゲーム、DHCP、QUICなどに使われる。

「UDP」は、2分野の4問の練習問題に出てきます(ネットワークの基礎, Web技術の基礎など)。

この用語の分野: ネットワークの基礎

ヘッダとデータグラム

UDPのヘッダは、送信元ポート番号、宛先ポート番号、長さ、チェックサムの4つ(各16ビット)で、合わせて8バイトです。アプリケーションが1回に送ったデータが1つのデータグラムになり、受信側でもその区切りのまま受け取れます(TCPのようなバイトの流れではありません)。チェックサムは、IPv4では省略できますが、IPv6では必須です。大きなデータグラムはIPのレベルで分割されて失われやすくなるので、MTUに収まる大きさにするのが普通です。

UDPが選ばれる場面

通話やライブ配信では、遅れて届いたデータは役に立たず、再送を待つと音や映像が途切れます。DNSの問い合わせのように1回の問いと答えで終わる通信では、接続の手順を省けば待ち時間が減ります。また、UDPは1対多のブロードキャストやマルチキャストにも使えるので、IPアドレスをまだ持たない端末が使うDHCPもUDPです。確実さが必要なアプリケーションは、QUICのように、再送や順序の制御を自分でUDPの上に作ります。

使うときの注意

UDPのデータグラムは、失われる、重なる、順序が入れ替わる、といったことが起こり得るので、アプリケーションの側で番号を付けるなどして対処します。UDP自体には輻輳制御がないので、大量に送るときは送る速さもアプリケーションが調整します。NATの対応づけは通信がしばらくないと消えるので、定期的に小さなパケットを送って保つこともあります。接続の手順がなく送信元を偽りやすいため、小さな問い合わせに大きな応答を返すDNSなどを悪用した、反射・増幅型のDDoS攻撃にも使われます。

UDPの練習問題に挑戦

TCP/IPの4階層のモデルで、TCPとUDPが属する層はどれか。

  1. Aアプリケーション層
  2. Bインターネット層
  3. Cトランスポート層
答えと解説を見る

正解：C. トランスポート層

TCP/IPのモデルは、下からリンク層(ネットワークインターフェース層)、インターネット層、トランスポート層、アプリケーション層の4つの層で表されます。TCPとUDPはトランスポート層のプロトコルで、ポート番号を使って、端末の中のどのアプリケーション宛ての通信かを区別します。インターネット層のIPは、端末から端末までパケットを届けることを担います。HTTPやDNSはアプリケーション層のプロトコルです。OSI参照モデルと対応させると、トランスポート層は第4層、インターネット層は第3層にあたります。

UDPの特徴として正しいものはどれか。

  1. Aコネクションを確立せず、再送や順序の制御をしないので、ヘッダが小さく、送るまでの待ちもない
  2. Bコネクションを確立し、届かなかったデータを再送して、受信側で順序もそろえる
  3. CIPアドレスを使わずに、MACアドレスだけで宛先の端末に届ける
答えと解説を見る

正解：A. コネクションを確立せず、再送や順序の制御をしないので、ヘッダが小さく、送るまでの待ちもない

UDPは、IPの上にポート番号と簡単な誤り検出(チェックサム)を加えただけの軽いプロトコルで、ヘッダは8バイトです(TCPはオプションなしで20バイト)。接続の手順がなく、届いたかの確認や再送もしないため、少し失われても遅れない方がよい音声通話やライブ映像、1回の問い合わせと応答で済むDNSなどに使われます。信頼性が必要なら、アプリケーションの側で補います。例えば、HTTP/3で使われるQUICは、UDPの上で再送や暗号化を実装しています。コネクションの確立、再送、順序の制御を行うのはTCPです。

よくある質問

信頼性がないUDPがなぜ使われるのですか?

接続の確立や再送を待たないので、遅れが小さく、ヘッダも小さいからです。少しのデータが欠けても、遅れない方がよい通話やゲーム、1往復で終わるDNSの問い合わせに向いています。確実さが必要なら、QUICのようにUDPの上で再送などを実装します。

UDPで送ったデータは順番どおりに届きますか?

保証されません。経路の違いなどで順序が入れ替わったり、失われたり、重なって届いたりすることがあります。順序が大事なら、アプリケーションがデータに番号を付けて並べ直します。
