コンパレータとは

こんぱれーた

2つの入力電圧の大小を比べ、その結果をHかLの2値で出力する回路。ADコンバータの基本的な構成要素でもある。

この用語の分野: アナログ・電子回路

解説の中の「コンパレータ」

  • コンパレータは2つの入力電圧のどちらが大きいかを判定し、HかLの2値を出力します。

    コンパレータ(比較器)の働きとして正しいものはどれか。

  • オペアンプ回路の解析の基本ですが、出力が飽和したときや正帰還の回路(コンパレータ)では成り立ちません。

    負帰還をかけた理想オペアンプ回路で、2つの入力端子の電圧がほぼ等しくなる性質を何と呼ぶか。

  • コンパレータに正帰還をかけて作り、74HC14のようなロジックICもあります。

    入力が上がるときと下がるときでしきい値が異なり、ノイズによる出力のばたつきを防ぐ回路はどれか。

「コンパレータ」が出てくる問題(4問)

  1. コンパレータ(比較器)の働きとして正しいものはどれか。
  2. 3ビットのフラッシュ型ADコンバータに必要なコンパレータの数はいくつか。
  3. 負帰還をかけた理想オペアンプ回路で、2つの入力端子の電圧がほぼ等しくなる性質を何と呼ぶか。
  4. 入力が上がるときと下がるときでしきい値が異なり、ノイズによる出力のばたつきを防ぐ回路はどれか。
