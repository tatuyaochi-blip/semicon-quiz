URLとは

ゆーあーるえる

Uniform Resource Locatorの略。Webページなどの資源の場所を表す文字列。https://www.example.com:8443/docs/page.html?q=1#top のように、スキーム(https)、ホスト名、ポート番号、パス、クエリ(?の後)、フラグメント(#の後)からなる。ポート番号は省略すると既定の値(HTTPSなら443)になり、ホスト名はDNSでIPアドレスに変換される。

URLの練習問題に挑戦

ブラウザで https://www.example.com:8443/docs/guide.html?lang=ja#install を開いた。このURLのうち、サーバへ送るリクエストには含まれず、ページを読み込んだ後にブラウザの中だけで使われる部分はどれか。

  1. A:8443
  2. B?lang=ja
  3. C#install
答えと解説を見る

正解：C. #install

このURLは、スキーム(https)、ホスト名(www.example.com)、ポート番号(8443、省略するとhttpsでは443)、パス(/docs/guide.html)、クエリ(lang=ja)、フラグメント(install)からできています。ブラウザはポート番号で接続先を決め、パスとクエリをリクエストに入れてサーバに送りますが、#の後のフラグメントは送りません。フラグメントは、ページの中で id="install" の要素の位置へ移動するなど、ブラウザの中だけで使われます。

URLのクエリに日本語の「あ」を入れるため、この文字をUTF-8で表したバイト列(E3 81 82)を、パーセントエンコーディングで表す。結果として正しいものはどれか。

  1. A%E3%81%82
  2. B%u3042
  3. C&#x3042;
答えと解説を見る

正解：A. %E3%81%82

パーセントエンコーディングでは、URLにそのまま書けない文字や、/ ? # & のように特別な意味をもつ文字をデータとして使うとき、文字をバイト列にして、1バイトずつ「%」と2桁の16進数で表します。「あ」はUTF-8で E3 81 82 の3バイトなので、%E3%81%82 になります。空白は %20 になります(フォームの送信の形式では + を使うこともあります)。JavaScriptでは encodeURIComponent 関数でこの変換ができます。
