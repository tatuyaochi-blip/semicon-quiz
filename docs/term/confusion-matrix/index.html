混同行列とは

こんどうぎょうれつ

分類のモデルの予測と実際の正解の組合せごとに、データの件数を数えた表。2クラス分類では、陽性を正しく陽性とした真陽性(TP)、陰性を誤って陽性とした偽陽性(FP)、陽性を誤って陰性とした偽陰性(FN)、陰性を正しく陰性とした真陰性(TN)の4つのマスになる。ここから正解率、適合率、再現率、F値などを計算できるほか、どのクラスをどのクラスと取り違えやすいかが分かる。

「混同行列」は、1分野の1問の練習問題に出てきます(機械学習の基礎など)。

この用語の分野: 機械学習の基礎

混同行列の練習問題に挑戦

2クラス分類のモデルを200件のテストデータで評価した混同行列で、真陽性(TP)が45件、偽陽性(FP)が5件、偽陰性(FN)が45件、真陰性(TN)が105件だった。適合率と再現率の組合せとして、正しいものはどれか。

  1. A適合率0.50、再現率0.90
  2. B適合率0.75、再現率0.50
  3. C適合率0.90、再現率0.50
答えと解説を見る

正解：C. 適合率0.90、再現率0.50

適合率(precision)は、陽性と予測したもののうち実際に陽性だった割合で、TP ÷ (TP + FP) = 45 ÷ 50 = 0.90です。再現率(recall)は、実際に陽性のもののうち陽性と予測できた割合で、TP ÷ (TP + FN) = 45 ÷ 90 = 0.50です。このモデルは、陽性と判定したものはほぼ正しいものの、陽性の半分を見逃しています。正解率は (45 + 105) ÷ 200 = 0.75です。
