GPUとは

じーぴーゆー

Graphics Processing Unit の略。単純な演算器を多数もち、大量のデータを並列に処理するプロセッサ。画像処理のほか、AIの学習や推論に広く使われている。

「GPU」は、14分野の89問の練習問題に出てきます(GPUプログラミング, AIハードウェアとソフトウェアスタック, 先端技術(3D実装・チップレット)など)。

この用語の分野: CPU・アーキテクチャ

GPUの構成

GPUは多数のストリーミングマルチプロセッサ(SM)を持ち、各SMは単純な実行ユニットの集まりで、専用のレジスタとオンチップの共有メモリを備えています。CPUコアのように大容量キャッシュや高度な分岐予測で1つのスレッドを速くするのではなく、GPUは数千のスレッドを同時に保持し、あるグループがメモリを待っている間は別のグループに切り替えます。こうして膨大な並列性でレイテンシを隠し、スループットを最大化します。スレッドは固定サイズのグループ単位でスケジュールされ、同じ命令をロックステップで一緒に発行します。NVIDIAのGPUではこの32スレッドの単位をワープと呼び、この実行モデルをSIMT(単一命令・複数スレッド)と呼びます。

SIMTとCPUのSIMDの違い

CPUのSIMD命令は、決まった数の要素を持つベクトルレジスタに1つの演算を適用し、プログラマやコンパイラはその幅に合わせてコードを書く必要があります。SIMTでは、プログラマは1スレッド分の普通のコードを書き、ハードウェアがスレッドをワープにまとめます。スレッドが異なる分岐に進むこともできますが、その場合ハードウェアは各パスを順番に実行するため、レーンが無駄になります。そのためGPUは、各要素を同じ演算で独立に処理できる場合に威力を発揮し、連結リストをたどるような逐次的でデータ依存の処理は苦手です。

ボトルネックはメモリ帯域幅

数千の実行ユニットにデータを供給するには、膨大な帯域幅が必要です。グラフィックスボードはGDDRメモリを使い、最近の世代ではピンあたり20 Gb/sを超える速度で、GPUの周囲に短い配線で配置します。AIアクセラレータでは、積層したHBMをシリコンインターポーザ上でGPUの隣に置きます(2.5Dパッケージ)。HBMは1個あたり1,024本のデータ線を持つので、複数個で数TB/sを実現します。ソフトウェアの協力も必要です。隣り合うスレッドが隣り合うアドレスを読むとアクセスが少数の幅広いトランザクションに結合されるため、通常は構造体の配列(AoS)より配列の構造体(SoA)のほうが有利です。

GPUプログラムの書き方

CUDAなどのフレームワークでは、CPUがカーネルを起動します。カーネルとは、多数のGPUスレッドが同時に実行する関数です。1回の起動でブロックからなるグリッドが作られ、各ブロックには、同じSM上で動作し共有メモリを通じて協調できる多数のスレッドが含まれます。各スレッドは自分のインデックスを計算して処理するデータ要素を選び、if (i < n) というガードで、最後のブロックの余ったスレッドが配列外のメモリにアクセスするのを防ぎます。ブロックは互いに独立して動くため、同じプログラムが小さなGPUでも大きなGPUでもスケールします。

GPUの練習問題に挑戦

GPUのグラフィックスメモリとして使われるGDDRの特徴として正しいものはどれか。

  1. Aデータ転送の帯域(速度)を重視した規格である
  2. B電源を切ってもデータが残る
  3. C低速だが非常に安価である
答えと解説を見る

正解：A. データ転送の帯域(速度)を重視した規格である

GDDRは、GPUが大量の画像データを高速に扱えるよう、1端子あたりの転送速度を重視したDRAMで、2025年時点の製品ではGDDR6Xで20 Gb/s以上、GDDR7で30 Gb/s前後に達します(DDR5の数倍)。基板上でGPUの周囲に並べて短い配線でつなぎます。容量あたりのコストや消費電力はDDRより高めです。さらに広い帯域が必要なAI向けアクセラレータでは、積層したHBMが使われます。

CPU、GPU、メモリコントローラ、通信機能など、システムに必要な機能を1つのチップに集積したLSIを何と呼ぶか。

  1. ASiP(システムインパッケージ)
  2. B汎用DRAM
  3. CSoC(システムオンチップ)
答えと解説を見る

正解：C. SoC(システムオンチップ)

SoCは、システムに必要な多くの機能を1つのチップに集積したLSIで、スマートフォン用のプロセッサが代表例です。チップ間の配線がなくなるため、部品点数が減り、小型・高速・低消費電力にできます。一方、チップが大きくなって歩留まりが下がり、異なるプロセスの回路を混ぜにくい欠点もあります。複数のチップを1つのパッケージに収めるSiPとは区別されます。汎用DRAMはメモリ単体の製品です。

よくある質問

CPUとGPUの違いは?

CPUは個々のタスクを低レイテンシで完了させるよう最適化された少数の複雑なコアを持ち、GPUは並列性の高い処理で全体のスループットを上げるよう最適化された多数の単純なコアを持ちます。GPUは大容量キャッシュに頼る代わりに、数千のスレッドを切り替えてメモリレイテンシを隠します。

GPUがAIに使われるのはなぜ?

ニューラルネットワークの学習と推論は、大部分が巨大な配列に同じ演算を施す大規模な行列積で、数千の並列スレッドに自然に割り当てられるためです。HBMのような広帯域メモリが、それらの演算器にデータを供給し続けます。

ワープダイバージェンスとは?

同じワープ内のスレッドが異なる分岐に進んだときに起こる現象です。ハードウェアは各パスを順に実行し、その間ほかのスレッドは待機するため効率が下がります。ワープ内で分岐条件をそろえれば避けられます。
