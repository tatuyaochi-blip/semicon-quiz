GPUとは

じーぴーゆー

Graphics Processing Unit の略。単純な演算器を多数もち、大量のデータを並列に処理するプロセッサ。画像処理のほか、AIの学習や推論に広く使われている。

「GPU」は、11分野の82問の練習問題に出てきます(GPUプログラミング, AIハードウェアとソフトウェアスタック, 先端技術(3D実装・チップレット)など)。

この用語の分野: CPU・アーキテクチャ

GPUの練習問題に挑戦

GPUのグラフィックスメモリとして使われるGDDRの特徴として正しいものはどれか。

  1. Aデータ転送の帯域(速度)を重視した規格である
  2. B電源を切ってもデータが残る
  3. C低速だが非常に安価である
答えと解説を見る

正解：A. データ転送の帯域(速度)を重視した規格である

GDDRは、GPUが大量の画像データを高速に扱えるよう、1端子あたりの転送速度を重視したDRAMで、GDDR6Xでは20 Gb/s以上、GDDR7では30 Gb/s前後に達します(DDR5の数倍)。基板上でGPUの周囲に並べて短い配線でつなぎます。容量あたりのコストや消費電力はDDRより高めです。さらに広い帯域が必要なAI向けアクセラレータでは、積層したHBMが使われます。

GPUが行列演算やAIの学習・推論に向いている主な理由はどれか。

  1. Aクロック周波数がCPUの100倍以上あるから
  2. B単純な演算器を多数もち、大量のデータを並列に処理できるから
  3. Cメモリを持たないから
答えと解説を見る

正解：B. 単純な演算器を多数もち、大量のデータを並列に処理できるから

GPUは、もともと画面の多数の画素を同時に処理するために、単純な演算器を数千〜1万個以上並べた構造をもっています。行列演算のように同じ計算を大量のデータに繰り返す処理では、この並列性で高い性能を発揮します。近年は行列演算専用のユニット(Tensor Coreなど)と広帯域のHBMを備え、AIの学習の主役になっています。分岐の多い逐次的な処理はCPUのほうが得意です。
