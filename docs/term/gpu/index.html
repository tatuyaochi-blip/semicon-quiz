GPUとは

じーぴーゆー

Graphics Processing Unit の略。単純な演算器を多数もち、大量のデータを並列に処理するプロセッサ。画像処理のほか、AIの学習や推論に広く使われている。

この用語の分野: CPU・アーキテクチャ

解説の中の「GPU」

  • GDDRは、GPUが大量の画像データを高速に扱えるよう、1端子あたりの転送速度を重視したDRAMで、GDDR6Xでは20 Gb/s以上、GDDR7では30 Gb/s前後に達します(DDR5の数倍)。

    GPUのグラフィックスメモリとして使われるGDDRの特徴として正しいものはどれか。

  • GPUは、もともと画面の多数の画素を同時に処理するために、単純な演算器を数千〜1万個以上並べた構造をもっています。

    GPUが行列演算やAIの学習・推論に向いている主な理由はどれか。

  • 微細な配線をつくれるシリコンインターポーザの上にGPUとHBMを並べると、多数の配線で数mmの短い距離で接続でき、AIの計算に必要な数TB/sのメモリ帯域を実現できます。

    AI向けのGPUで、GPUチップとHBMを1つのシリコンインターポーザの上に並べて実装する主な理由はどれか。

  6. CPUとGPUの設計の考え方の違いとして正しいものはどれか。
  7. GPUで速く処理できる仕事の特徴として最も適切なものはどれか。

  9. CUDAなどのGPUプログラミングでいう「カーネル」の説明として正しいものはどれか。

  13. 粒子の位置x、y、zを持つデータをGPUで処理するとき、メモリ合体アクセスの点で有利な並べ方はどれか。
