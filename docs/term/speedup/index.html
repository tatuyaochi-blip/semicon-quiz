速度向上率とは

そくどこうじょうりつ

改善前の実行時間を改善後の実行時間で割った値。スピードアップ。2なら2倍速くなったことを表す。

「速度向上率」は、1分野の5問の練習問題に出てきます(性能評価・プロファイリングなど)。

この用語の分野: 性能評価・プロファイリング

速度向上率の練習問題に挑戦

性能の改善を表す「速度向上率(スピードアップ)」の求め方として正しいものはどれか。

  1. A改善前の実行時間 ÷ 改善後の実行時間
  2. B改善後の実行時間 ÷ 改善前の実行時間
  3. C改善前の実行時間 − 改善後の実行時間
答えと解説を見る

正解：A. 改善前の実行時間 ÷ 改善後の実行時間

速度向上率は、改善前の時間を改善後の時間で割った値です。例えば10秒かかっていた処理が4秒になれば、10÷4=2.5倍の速度向上です。「60%短くなった」と「2.5倍速くなった」は同じことを表していますが、言い方を混同しやすいので注意が必要です。並列化の効果を示すときは、1つのコアのときの時間を基準にして、コアの数を増やしたときの速度向上率を示します。

処理全体の50%を占める部分を4倍速くした。全体の速度向上率はいくらか(アムダールの法則)。

  1. A2倍
  2. B1.6倍
  3. C4倍
答えと解説を見る

正解：B. 1.6倍

改善後の時間は、速くしない残りの50%(0.5)と、4倍速くした50%(0.5÷4=0.125)の合計で0.625になります。速度向上率は1÷0.625=1.6倍です。速くした部分をどれだけ速くしても、残りの50%はそのまま残るので、全体は最大でも2倍にしかなりません。全体を大きく速くするには、時間を多く占める部分を見つけて改善する必要があります。

解説の中の「速度向上率」

  • 速度向上率は、改善前の時間を改善後の時間で割った値です。

    性能の改善を表す「速度向上率(スピードアップ)」の求め方として正しいものはどれか。

  • 速度向上率は1÷0.625=1.6倍です。

    処理全体の50%を占める部分を4倍速くした。全体の速度向上率はいくらか(アムダールの法則)。

  • コアの数を変えながら速度向上率を測ると、理想的にはコアの数に比例して伸びますが、実際には並列にできない部分、同期や通信、メモリ帯域の不足などで、ある数から伸びが鈍くなります。

    並列プログラムのスケーラビリティを調べるときの方法として最も適切なものはどれか。

  • 並列効率は、速度向上率をコアの数で割った値で、コアがどれだけ有効に使われているかを表します。

    8コアで並列に実行したところ、1コアのときより6倍速くなった。並列効率はいくらか。

  • 速度向上率は、何と比べたかで大きく変わります。

    「新しい方法で100倍速くなった」という主張を評価するときに確かめるべき点として最も適切なものはどれか。

「速度向上率」が出てくる問題(5問)

  1. 性能の改善を表す「速度向上率(スピードアップ)」の求め方として正しいものはどれか。
  2. 処理全体の50%を占める部分を4倍速くした。全体の速度向上率はいくらか(アムダールの法則)。
  3. 並列プログラムのスケーラビリティを調べるときの方法として最も適切なものはどれか。
  4. 8コアで並列に実行したところ、1コアのときより6倍速くなった。並列効率はいくらか。
  5. 「新しい方法で100倍速くなった」という主張を評価するときに確かめるべき点として最も適切なものはどれか。
