X楽観主義とは

えっくすらっかんしゅぎ

HDLのシミュレーションで、不定値Xを含む条件がXのまま伝わらず確定した値として扱われ、不具合が隠れてしまう性質。Xオプティミズム。

「X楽観主義」は、1分野の2問の練習問題に出てきます(ハードウェア記述言語と検証など)。

正解：B. RTLのシミュレーションでは見えない、初期化やリセットの不具合、合成の結果の違い、遅延に関係する問題を確かめる

RTLのシミュレーションは速いものの、X楽観主義で不定値の問題が隠れたり、合成で記述と違う回路になったりした場合には気づけません。ゲートレベルのシミュレーションでは、実際に作られたゲートとフリップフロップで動きを確かめ、SDFの形式で各ゲートと配線の遅延を与えれば、遅延に関係する問題も見えます。ただし非常に遅いので、限られたテストだけで行うのが一般的です。
