ディレーティングとは

でぃれーてぃんぐ

信頼性を高めるため、電圧・電流・温度などを定格いっぱいではなく余裕をもたせて使うこと。例えば電圧は定格の70〜80%以下、接合温度は最大定格150 ℃に対して125 ℃以下で使う、といった基準を設ける。

「ディレーティング」は、4分野の6問の練習問題に出てきます(タイミング解析とCDC, データシートの読み方, パワー半導体など)。

この用語の分野: データシートの読み方

定格より低く使う理由

ほとんどの故障メカニズムはストレスによって加速します。化学的な劣化や拡散は温度とともに指数関数的に速くなり、絶縁膜は電界が高いほど早く劣化し、エレクトロマイグレーションは電流密度と温度が上がるほど悪化します。そのため余裕をもたせて使えば故障率が下がり、部品の公差、過渡現象、周囲温度の極値、経年劣化など、公称の動作点には表れない現実の影響も吸収できます。代表的な基準では、印加電圧は定格の70〜80%程度、接合温度は最大定格150 ℃に対して125 ℃程度に抑えます。正確な値は社内規定や業界の規格で決められます。

パワーデバイスの電圧マージン

パワーエレクトロニクスでは、浮遊インダクタンスを流れる電流をスイッチングすると、直流バス電圧の上にL·di/dtの電圧スパイクが乗ります。また、高電圧をかけ続けると、宇宙線中性子によるシングルイベントバーンアウトが起きやすくなり、このリスクは電圧と高度に応じて急激に高まります。そのため設計者は、400 Vのバスに650 V品を使うように、使用電圧の1.5倍程度の定格のデバイスを選びます。容量、リーク電流、寿命がいずれも印加電圧と温度に依存するため、セラミックコンデンサや電解コンデンサもディレーティングして使います。

熱的ディレーティングと電力の上限

データシートには、電力ディレーティングカーブがよく載っています。基準温度までは定格の損失を許容し、そこから最大接合温度で0になるまで直線的に減少するグラフです。これは Tj = Ta + P·θJA という関係から導かれ、θJAは接合部から周囲までの熱抵抗です。Tj(max) = 125 ℃、θJA = 50 ℃/W、Ta = 85 ℃なら、許容電力は (125 − 85)/50 = 0.8 Wになります。θJAは基板のレイアウトや風量によって大きく変わるため、設計ではこの計算値よりさらに余裕を見込みます。

タイミング解析でのディレーティング

チップ設計では、この言葉は関連した別の意味でも使われます。静的タイミング解析(STA)のOCV(オンチップばらつき)ディレーティングは、トランジスタ、配線、電圧、温度の局所的な違いをカバーするため、パスの遅延に係数を掛けます。セットアップのチェックでは送り側のクロックとデータパスを遅く、受け側のクロックを速くし、ホールドのチェックでは係数を逆にします。そのうえで、両方のパスが共有するクロックバッファに生じるあり得ない悲観性を、共通パス悲観性除去(CRPR)で差し戻します。発展型のAOCVなどでは、パスの段数や距離に応じて係数を変えます。

ディレーティングの練習問題に挑戦

パワーデバイスを選ぶとき、定格電圧に余裕をもたせて実際の使用電圧より高い耐圧の素子を使う(ディレーティングする)主な理由はどれか。

  1. Aスイッチング時のサージ電圧や、宇宙線による故障などに備えて信頼性を確保するため
  2. B部品の価格を下げるため
  3. Cオン抵抗を下げるため
答えと解説を見る

正解：A. スイッチング時のサージ電圧や、宇宙線による故障などに備えて信頼性を確保するため

実際の回路では、スイッチング時に寄生インダクタンスによるサージ電圧が加わるうえ、高電圧で使い続けると宇宙線由来の中性子がデバイス内で電荷を生み、突然の破壊(シングルイベントバーンアウト)が起こる確率が電圧とともに急に上がります。そのため、例えば400 V系の回路に650 V品を使うように、使用電圧の1.5倍程度の定格の素子を選ぶのが一般的です。高度の高い場所では余裕をさらに大きくします。

OCVディレーティングとして、セットアップ解析で送り側のクロック経路とデータ経路の遅延を1.1倍、受け側のクロック経路の遅延を0.9倍にする。送り側クロック経路 1.0 ns、データ経路(クロック→出力を含む)1.5 ns、受け側クロック経路 1.0 ns(共通部分はない)、周期 3.0 ns、セットアップ時間 0.1 ns のとき、セットアップのスラックはいくらか。

  1. A1.05 ns
  2. B1.40 ns
  3. C1.25 ns
答えと解説を見る

正解：A. 1.05 ns

OCVディレーティングは、同じチップ内でも場所によって遅延がばらつくことを見込み、セットアップには最も不利な組み合わせ(送り側は遅く、受け側のクロックは早く)を想定する方法です。到着時刻は 1.1 × (1.0 + 1.5) = 2.75 ns、要求時刻は 3.0 + 0.9 × 1.0 − 0.1 = 3.8 ns なので、スラックは 1.05 ns です。1.40 ns はディレーティングをしない値、1.25 ns はデータ経路だけに係数を掛けた値です。ホールド解析では係数の掛け方が逆になります。

よくある質問

電子部品のディレーティングとはどういう意味ですか?

電圧、電流、電力、温度を最大定格より低い条件で使い、信頼性を高めるとともに過渡現象や公差を吸収することです。定格電圧の70〜80%、接合温度は絶対最大定格よりかなり低く、というのが一般的な目安です。

電力ディレーティングカーブはどう読めばよいですか?

周囲温度またはケース温度に対する許容損失を示すグラフで、基準点までは一定、そこから最大接合温度で0になるまで直線的に下がります。その傾きは熱抵抗の逆数です。

静的タイミング解析のOCVディレーティングとは何ですか?

セルや配線の遅延に係数を掛け、送り側と受け側のパスをそれぞれ悲観的な異なる速度で評価する手法です。これにより、1つのチップ内の場所によるばらつきをカバーします。
