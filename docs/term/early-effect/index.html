アーリー効果とは

あーりーこうか

コレクタ電圧が上がるとベース-コレクタ間の空乏層が広がって実効的なベース幅が狭まり、コレクタ電流が少し増える現象。

「アーリー効果」は、1分野の4問の練習問題に出てきます(バイポーラトランジスタなど)。

この用語の分野: バイポーラトランジスタ

ベース幅変調

活性領域で動作するバイポーラトランジスタ(BJT)では、コレクタ・ベース接合が逆バイアスされ、その空乏層の一部がベース側に広がります。コレクタ電圧を上げるとこの空乏層が広がり、中性ベース幅が狭くなります。コレクタ電流はベースを拡散で横切る少数キャリアで決まり、ベースが一様にドープされていれば中性ベース幅に反比例します。そのためベースが狭くなるとキャリアの濃度勾配が急になり、電流がわずかに増えます。ベースが短くなると再結合するキャリアも減るので、電流増幅率もわずかに上がります。

アーリー電圧と出力抵抗

コレクタ電流対コレクタ・エミッタ間電圧の出力特性では、活性領域の線はほぼ水平ですが、わずかに右上がりに傾いています。これらの線を逆方向に延長すると、電圧軸上の −VA 付近の1点でほぼ交わります。このVAがアーリー電圧です。よく使われるモデルは IC = IS exp(VBE/VT)(1 + VCE/VA) で、出力抵抗は ro = VA/IC となります。トランジスタ1個の最大電圧利得 gm·ro は VA/VT に等しく、VAが100 Vなら室温で約4,000倍になります。小信号用npnトランジスタでは、アーリー電圧は数十〜100 V程度が一般的です。

アナログ回路への影響

出力抵抗が有限であることは、増幅器の利得を制限し、電流源を不完全にします。単純なカレントミラーでは、基準側のトランジスタはダイオード接続されて約0.7 Vにあるのに対し、出力側のトランジスタのコレクタ・エミッタ間電圧はずっと大きいことがあります。するとアーリー効果により、コピーされる電流がおよそ電圧差÷VAの割合だけ大きくなります。カスコードミラーやウィルソンミラーは、重要なトランジスタのコレクタ電圧をほぼ一定に保ち、出力抵抗をトランジスタの電流増幅率程度の倍率で高めます。SPICEでは、Gummel-Poonモデルが順方向アーリー電圧パラメータVAFでこの効果を表します。

アーリー効果とチャネル長変調

MOSFETにもよく似た効果があります。ドレイン電圧を上げると実効的なチャネルが短くなり、飽和領域でドレイン電流が増えるのです。これはチャネル長変調と呼ばれ、1/VAに相当するパラメータλ(ラムダ)でモデル化されます。どちらのデバイスでも、有限の出力抵抗が真性利得を制限します。デバイス設計者はベースのドーピングを高くしてアーリー電圧を上げます。こうすると空乏層がベースに入り込みにくくなりますが、電流増幅率は下がります。極端な場合はコレクタ側の空乏層がエミッタまで達してパンチスルーが起き、トランジスタとして動作しなくなります。

アーリー効果の練習問題に挑戦

バイポーラトランジスタのアーリー効果の説明として正しいものはどれか。

  1. A温度が上がると電流増幅率が下がる効果
  2. Bコレクタ-ベース間の逆バイアスが大きくなると実効的なベース幅が狭くなり、コレクタ電流が増える効果
  3. C光を当てるとベース電流が流れる効果
答えと解説を見る

正解：B. コレクタ-ベース間の逆バイアスが大きくなると実効的なベース幅が狭くなり、コレクタ電流が増える効果

コレクタ電圧を上げるとコレクタ-ベース接合の空乏層がベース側にも広がり、実効的なベース幅が狭くなります。すると少数キャリアの濃度勾配が急になってコレクタ電流が少し増えます。これがアーリー効果で、出力特性の線を左に延長すると電圧軸の一点(−VA、アーリー電圧)で交わります。VAが大きいほど出力抵抗 ro = VA/IC が大きく、増幅回路の最大利得 gm·ro = VA/VT が高くなります。

よくある質問

トランジスタのアーリー電圧とは何ですか?

BJTの活性領域の出力特性曲線を延長したときに、電圧軸と交わる点の電圧の大きさで、VAと書きます。アーリー電圧が大きいほど曲線が平らになり、出力抵抗 ro = VA/IC が高くなります。

アーリー効果は増幅器の利得をどう制限しますか?

トランジスタの出力抵抗が有限になるため、1段の最大利得が gm·ro = VA/VT に制限されます。VAが100 V程度なら数千倍で、負荷抵抗が並列に入るとさらに下がります。

アーリー効果とチャネル長変調は同じものですか?

同一ではなく、類似した現象です。アーリー効果はBJTの中性ベースを狭め、チャネル長変調はMOSFETのチャネルを短くしますが、どちらも出力電圧とともに出力電流を増やし、有限の出力抵抗を生みます。
