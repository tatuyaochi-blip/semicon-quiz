アーリー効果とは

あーりーこうか

コレクタ電圧が上がるとベース-コレクタ間の空乏層が広がって実効的なベース幅が狭まり、コレクタ電流が少し増える現象。

この用語の分野: バイポーラトランジスタ

解説の中の「アーリー効果」

  • これがアーリー効果で、出力特性の線を左に延長すると電圧軸の一点(−VA、アーリー電圧)で交わります。

    バイポーラトランジスタのアーリー効果の説明として正しいものはどれか。

  • ベース電流による誤差やアーリー効果による出力抵抗の不足は、ウィルソン型やカスコード型で改善します。

    特性のそろった2つのトランジスタを使い、一方に流した電流と同じ大きさの電流をもう一方に流す回路はどれか。

  • わずかな右上がりはアーリー効果によるもので、傾きの逆数が出力抵抗roです。

「アーリー効果」が出てくる問題(4問)

  1. バイポーラトランジスタのアーリー効果の説明として正しいものはどれか。
  2. 特性のそろった2つのトランジスタを使い、一方に流した電流と同じ大きさの電流をもう一方に流す回路はどれか。
  3. エミッタ接地のトランジスタの出力特性(IC-VCE特性)を、ベース電流IBをパラメータとして描いたときの能動領域の特徴として正しいものはどれか。
  4. バイポーラトランジスタの大信号動作を、2つのダイオードと電流源で表したモデルはどれか。
