スリープモードとは

すりーぷもーど

仕事のない間にCPUや周辺回路のクロックや電源を止めて消費電力を減らすマイコンの状態。割り込みなどで起きる。

「スリープモード」は、1分野の1問の練習問題に出てきます(組込み・ファームウェアなど)。

この用語の分野: 組込み・ファームウェア

スリープモードの練習問題に挑戦

電池で動く組込み機器で、マイコンのスリープモードを使う主な目的はどれか。

  1. A処理の速さを上げる
  2. B仕事のない間はCPUやクロックを止めて消費電力を減らし、割り込みなどで必要なときだけ起きる
  3. Cプログラムを消去する
答えと解説を見る

正解：B. 仕事のない間はCPUやクロックを止めて消費電力を減らし、割り込みなどで必要なときだけ起きる

センサを数秒に1回読むような機器では、ほとんどの時間は仕事がありません。スリープモードでは、CPUや使わない周辺回路のクロックや電源を止めて、消費電流をマイクロアンペア程度まで下げます。タイマや端子の変化の割り込みで起き、仕事を済ませたらすぐにまた眠ります。深いスリープほど電流は小さくなりますが、起きるまでの時間が長くなり、失われる状態も増えます。

解説の中の「スリープモード」

  • スリープモードでは、CPUや使わない周辺回路のクロックや電源を止めて、消費電流をマイクロアンペア程度まで下げます。
