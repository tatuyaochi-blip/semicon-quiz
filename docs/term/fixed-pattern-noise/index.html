固定パターンノイズとは

こていぱたーんのいず

画素や読み出し回路ごとの特性のばらつきによって、毎回同じ位置に同じように現れるノイズ。相関二重サンプリングや補正で取り除く。

「固定パターンノイズ」は、1分野の1問の練習問題に出てきます(イメージセンサ・光デバイスなど)。

この用語の分野: イメージセンサ・光デバイス

固定パターンノイズの練習問題に挑戦

画素ごとの特性のばらつきによって、毎回同じ位置に同じように現れるノイズを何と呼ぶか。

  1. Aショットノイズ
  2. B熱雑音
  3. C固定パターンノイズ
答えと解説を見る

正解：C. 固定パターンノイズ

固定パターンノイズは、画素ごとのアンプのオフセットや暗電流のばらつき、列ごとの読み出し回路やADCのばらつきなどで、撮影のたびに同じ位置に同じように現れるノイズです。特に列ごとのずれは縦縞として目立ちます。時間的に変化しないため、CDSや、遮光した画素の値を使った補正、工場での較正データで取り除けます。時間とともに変わるショットノイズや熱雑音とは区別されます。
