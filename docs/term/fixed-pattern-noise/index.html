固定パターンノイズとは

こていぱたーんのいず

画素や読み出し回路ごとの特性のばらつきによって、毎回同じ位置に同じように現れるノイズ。相関二重サンプリングや補正で取り除く。

「固定パターンノイズ」は、1分野の1問の練習問題に出てきます(イメージセンサ・光デバイスなど)。

この用語の分野: イメージセンサ・光デバイス

毎回同じ場所に出るノイズ

固定パターンノイズ(FPN)は、画素や読み出し回路ごとの特性のわずかな違いによって、撮影のたびに同じ位置に同じように現れるノイズです。同じ明るさの光を当てても、画素ごとに出力が少しずつ違うため、画像にざらつきや模様が重なります。時間とともに変化しないので、何枚撮影して平均しても消えず、撮影のたびに変わるショットノイズや熱雑音のような時間的なノイズとは区別されます。逆にいえば、パターンを事前に測っておけば、補正で取り除くことができます。

主な原因と現れ方

原因は大きく2つに分けられます。1つは、光がなくても出る出力のばらつきで、画素の増幅トランジスタのオフセットや、画素ごとの暗電流の違いによるものです(DSNU)。もう1つは光に対する感度のばらつきで、フォトダイオードやマイクロレンズ、カラーフィルタのわずかな違いによるものです(PRNU)。CMOSイメージセンサでは、列ごとにもつアンプやAD変換器のばらつきが縦の筋(列FPN)として現れやすく、人の目には点状のばらつきより目立ちます。暗電流は温度で大きく変わるため、暗いときのFPNは温度と露光時間によって変化します。

取り除き方

画素ごとのオフセットは、相関二重サンプリング(CDS)で取り除けます。リセットした直後と電荷を転送した後の出力をそれぞれ読み、その差を信号とすると、両方に共通するオフセットが打ち消されます。列ごとの回路のばらつきは、列の回路でも同じように差をとる処理や、遮光した画素(オプティカルブラック)の出力を基準にした補正で減らします。感度のばらつきは、均一な光を当てて測った画素ごとの係数で補正します(フラットフィールド補正)。天体撮影などでは、シャッタを閉じて撮ったダーク画像を差し引いて、暗電流によるパターンを取り除きます。

CCDとCMOSでの違い

CCDイメージセンサは、全画素の電荷を同じ出力アンプで電圧に変えるため、増幅のばらつきによるFPNが小さいのが特長でした。CMOSイメージセンサは、画素ごとの増幅トランジスタと列ごとの回路をもつため、初期にはFPNが大きいことが弱点でしたが、CDSや列の回路の工夫で大きく改善しました。それでも、ごく暗い場面や高感度の設定では、補正しきれない縦の筋やパターンが目立つことがあります。FPNの大きさは、出力の平均に対する標準偏差の割合や電子の数で表されることが多く、時間的なノイズと合わせてセンサの評価に使われます。

固定パターンノイズの練習問題に挑戦

画素ごとの特性のばらつきによって、毎回同じ位置に同じように現れるノイズを何と呼ぶか。

  1. Aショットノイズ
  2. B熱雑音
  3. C固定パターンノイズ
答えと解説を見る

正解：C. 固定パターンノイズ

固定パターンノイズは、画素ごとのアンプのオフセットや暗電流のばらつき、列ごとの読み出し回路やADCのばらつきなどで、撮影のたびに同じ位置に同じように現れるノイズです。特に列ごとのずれは縦縞として目立ちます。時間的に変化しないため、CDSや、遮光した画素の値を使った補正、工場での較正データで取り除けます。時間とともに変わるショットノイズや熱雑音とは区別されます。

よくある質問

固定パターンノイズとランダムノイズの違いは?

固定パターンノイズは、画素や回路の特性のばらつきが原因で、毎回同じ位置に同じように現れます。ショットノイズや熱雑音のようなランダムノイズは撮影のたびに変わります。固定パターンノイズは事前に測って補正でき、ランダムノイズは複数の画像を重ねて平均するなどして減らします。

CMOSセンサで縦の筋が出るのはなぜですか?

CMOSイメージセンサは列ごとにアンプやAD変換器をもつことが多く、その特性のばらつきが列全体に同じように乗るため、縦の筋として現れます。点状のばらつきより目に付きやすいため、遮光画素を使った補正や列の回路の工夫で抑えます。

相関二重サンプリングで固定パターンノイズは消えますか?

画素のアンプのオフセットのように、リセット時と信号の読み出し時の両方に共通するばらつきは、CDSで打ち消せます。ただし、暗電流のばらつきや感度のばらつきはCDSでは取り除けないため、ダーク画像の差し引きやフラットフィールド補正などを組み合わせます。
