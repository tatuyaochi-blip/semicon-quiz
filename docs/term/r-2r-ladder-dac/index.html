R-2Rラダー型DACとは

あーるつーあーるらだーがただっく

Rと2Rの2種類の抵抗だけをはしご状に並べたDAコンバータ。必要な抵抗の種類が少なく、ビット数を増やしても抵抗値の比が大きくならない。

「R-2Rラダー型DAC」は、1分野の2問の練習問題に出てきます(AD/DA変換など)。

この用語の分野: AD/DA変換

R-2Rラダー型DACの練習問題に挑戦

R-2Rラダー型DAコンバータの特徴として正しいものはどれか。

  1. A2種類の抵抗値(Rと2R)だけで構成でき、必要な抵抗値の種類が少ない
  2. Bコンデンサだけで構成される
  3. Cコイルを使って電流を切り替える
答えと解説を見る

正解：A. 2種類の抵抗値(Rと2R)だけで構成でき、必要な抵抗値の種類が少ない

R-2Rラダー型は、抵抗Rと2Rをはしご状に組み、各節点から見た抵抗がどこでも等しくなる性質を使って、ビットごとに電流を半分ずつに分けます。ビット数が増えても抵抗値は2種類だけでよく、同じ抵抗を2本直列にすれば2Rが作れるため、比の精度をそろえやすいのが利点です。精度は抵抗の整合で決まり、上位ビットほど高い精度が必要になります。

解説の中の「R-2Rラダー型DAC」

  • R-2Rラダー型は、抵抗Rと2Rをはしご状に組み、各節点から見た抵抗がどこでも等しくなる性質を使って、ビットごとに電流を半分ずつに分けます。

    R-2Rラダー型DAコンバータの特徴として正しいものはどれか。

  • R-2Rラダー型は2種類の抵抗値だけで済むため、この問題を避けられます。

    各ビットに重みの異なる抵抗(R、2R、4R…)を割り当てる重み付け抵抗型DACの欠点として正しいものはどれか。

  2. 各ビットに重みの異なる抵抗(R、2R、4R…)を割り当てる重み付け抵抗型DACの欠点として正しいものはどれか。
