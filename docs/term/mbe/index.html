MBE(分子線エピタキシー)とは

えむびーいー

超高真空中で、原料を分子線として基板に供給してエピタキシャル成長させる方法。膜厚や組成を原子層レベルで精密に制御でき、化合物半導体の研究や量子構造の作製に使われる。

この用語の分野: エピタキシャル成長

解説の中の「MBE(分子線エピタキシー)」

  • MBEは、超高真空の装置内で原料を加熱して分子(原子)の線として基板に当て、結晶を成長させる方法です。
