アムダールの法則とは

あむだーるのほうそく

プログラムの一部だけを並列化したとき、全体の高速化は並列化できない部分によって制限されるという法則。例えば90%を並列化しても、最大で10倍までしか速くならない。

「アムダールの法則」は、3分野の6問の練習問題に出てきます(性能評価・プロファイリング, CPU・アーキテクチャ, マルチコアと同期など)。

この用語の分野: CPU・アーキテクチャ

アムダールの法則の練習問題に挑戦

処理全体の50%を占める部分を4倍速くした。全体の速度向上率はいくらか(アムダールの法則)。

  1. A2倍
  2. B1.6倍
  3. C4倍
答えと解説を見る

正解：B. 1.6倍

改善後の時間は、速くしない残りの50%(0.5)と、4倍速くした50%(0.5÷4=0.125)の合計で0.625になります。速度向上率は1÷0.625=1.6倍です。速くした部分をどれだけ速くしても、残りの50%はそのまま残るので、全体は最大でも2倍にしかなりません。全体を大きく速くするには、時間を多く占める部分を見つけて改善する必要があります。

アムダールの法則から得られる、性能の改善の進め方についての教訓として最も適切なものはどれか。

  1. A時間を多く使っている部分(よくある場合)を速くすることを優先する
  2. Bめったに実行されない部分から先に速くする
  3. Cどの部分を速くしても、全体への効果は同じである
答えと解説を見る

正解：A. 時間を多く使っている部分(よくある場合)を速くすることを優先する

全体の1%しか使っていない部分を無限に速くしても、全体は約1%しか速くなりません。一方、80%を使っている部分を2倍速くすれば、全体は約1.7倍になります。そのため、まずプロファイラなどで時間を多く使っている部分を見つけ、そこから改善するのが基本です。「よくある場合を速くせよ」は、コンピュータの設計でも繰り返し使われる原則です。

解説の中の「アムダールの法則」

  • アムダールの法則では、並列化できる割合をp、プロセッサ数をNとすると、高速化率は 1/((1 − p) + p/N) です。

    処理全体の90%を並列化できるプログラムを、プロセッサの数を限りなく増やして実行したとき、理論上の最大の高速化率はどれ…

  • 並列化の効果を妨げる主な原因には、並列にできない部分(アムダールの法則)、ロックやバリアによる待ち、共有データや偽共有によるキャッシュラインの行き来、仕事の偏り、メモリ帯域の不足などがあります。

    並列プログラムで、コアの数を増やしても性能が思うように伸びない原因として当てはまらないものはどれか。

  • アムダールの法則は、問題の大きさを変えずにプロセッサを増やす場合を考えるので、並列にできない部分が速度向上の上限を決めます。

    グスタフソンの法則が示す考え方として正しいものはどれか。

  • アムダールの法則のとおり、時間を多く使っている部分を改善するのが効果的なので、まず測ることが性能の改善の第一歩です。

    プログラムの性能を改善するときにプロファイラを使う目的として正しいものはどれか。

「アムダールの法則」が出てくる問題(6問)

  1. 処理全体の50%を占める部分を4倍速くした。全体の速度向上率はいくらか(アムダールの法則)。
  2. アムダールの法則から得られる、性能の改善の進め方についての教訓として最も適切なものはどれか。
  3. 処理全体の90%を並列化できるプログラムを、プロセッサの数を限りなく増やして実行したとき、理論上の最大の高速化率はどれか。
  4. 並列プログラムで、コアの数を増やしても性能が思うように伸びない原因として当てはまらないものはどれか。
  5. グスタフソンの法則が示す考え方として正しいものはどれか。
  6. プログラムの性能を改善するときにプロファイラを使う目的として正しいものはどれか。
