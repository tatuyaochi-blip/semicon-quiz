プリフェッチとは

ぷりふぇっち

近いうちに必要になりそうなデータを、要求される前にキャッシュへ読み込んでおくこと。ハードウェアがアクセスの規則性を見つけて行う方式と、命令で指示するソフトウェアの方式がある。

「プリフェッチ」は、3分野の8問の練習問題に出てきます(メモリ階層と性能, DRAM, CPU・アーキテクチャなど)。

この用語の分野: メモリ階層と性能

プリフェッチの練習問題に挑戦

ハードウェアのプリフェッチが特に効果を発揮しやすいアクセスはどれか。

  1. A配列を一定の間隔(ストライド)で順に読んでいくアクセス
  2. B連結リストを先頭から1要素ずつたどっていくアクセス
  3. Cハッシュ表をランダムなキーで引いていくアクセス
答えと解説を見る

正解：A. 配列を一定の間隔(ストライド)で順に読んでいくアクセス

ハードウェアのプリフェッチャは、直前のアクセスのアドレスの規則性(連続や一定の間隔)を見つけ、次に来るアドレスを予測して先に読み込みます。配列を一定のストライドで読むアクセスは予測しやすく、効果が大きくなります。連結リストは次の要素のアドレスが今の要素を読むまで分からないため、規則性がなく予測できません。ランダムなキーでのハッシュ表の参照も、アドレスに規則性がないため効果は小さくなります。

ソフトウェアのプリフェッチ命令を入れるとき、どれだけ先のデータを読むか(プリフェッチの距離)についての説明として正しいものはどれか。

  1. A距離は短いほどよく、次の要素を読む直前に入れるのが最適である
  2. B距離は長いほどよく、ループで使う全データを最初にまとめて読んでおくのが最適である
  3. C短すぎても長すぎてもよくなく、ミスの時間とループ1回の時間から決める
答えと解説を見る

正解：C. 短すぎても長すぎてもよくなく、ミスの時間とループ1回の時間から決める

プリフェッチは、データが必要になるまでにメモリからの読み込みが終わっていなければ意味がありません。距離が短すぎると到着が間に合わず、長すぎるとキャッシュに入ったデータが使われる前に追い出されたり、キャッシュを汚したりします。目安は、ミスペナルティをループ1回の実行時間で割った回数だけ先を読むことです。直前に入れるだけでは待ち時間を隠せず、全データをまとめて読むとキャッシュに入りきりません。

「プリフェッチ」が出てくる問題(8問)

  1. ハードウェアのプリフェッチが特に効果を発揮しやすいアクセスはどれか。
  2. ソフトウェアのプリフェッチ命令を入れるとき、どれだけ先のデータを読むか(プリフェッチの距離)についての説明として正しいものはどれか。
  3. 上のループでintが4バイト、キャッシュラインが64バイト、配列はキャッシュに入っておらず先頭がラインの境界にそろっているとき、プリフェッチがなければ配列の読み込みのミス率はいくらか。
  4. プロセッサの性能向上に比べて、メモリの帯域や遅延の改善が追いつかないことによって生じる性能の制約を何と呼ぶか。
  5. キャッシュミスの分類「3つのC」に含まれるものの組み合わせとして正しいものはどれか。
  6. プログラムがあるデータに初めてアクセスしたときに起こるキャッシュミスを減らす方法として、効果があるものはどれか。
