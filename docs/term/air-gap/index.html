エアギャップとは

えあぎゃっぷ

配線の間の絶縁膜の一部を空洞にする技術。空気の比誘電率はほぼ1のため、配線間の容量を大きく下げられる。

「エアギャップ」は、3分野の4問の練習問題に出てきます(配線プロセス, 先端トランジスタ(FinFET・GAA), 酸化・拡散など)。

この用語の分野: 配線プロセス

エアギャップの練習問題に挑戦

配線間の絶縁膜の一部を空洞(エアギャップ)にする技術の主な目的はどれか。

  1. A配線の機械的強度を高める
  2. B配線間の容量を下げる(空気の比誘電率はほぼ1)
  3. C配線の抵抗を下げる
答えと解説を見る

正解：B. 配線間の容量を下げる(空気の比誘電率はほぼ1)

空気(真空)の比誘電率はほぼ1で、どの絶縁材料よりも低いため、配線の間を空洞にすると配線間の容量を20〜30%程度下げられます。配線を形成したあと間の絶縁膜を除いて上からふさぐ方法や、成膜でわざと空洞を残す方法があります。機械的強度、熱の逃げにくさ、上の層のビアが空洞に落ちる問題などがあるため、特に容量を下げたい密な層に限って使われています。

解説の中の「エアギャップ」

  • そのため、コンタクト材料の改良、エアギャップや低誘電率のスペーサー、裏面からの電源供給など、真性部分以外の改良が性能向上の中心になっています。

    微細化が進んだトランジスタで、性能を制限する要因として重要性が増しているものはどれか。

  • 逆に配線の間に使うLow-k材料は約3以下で、空気(約1)を含ませた多孔質膜やエアギャップも使われます。

    熱酸化で形成したSiO2膜の比誘電率に最も近い値はどれか。

  • 容量は誘電率εにも比例するため、Low-k材料やエアギャップで誘電率を下げることが対策になります。

    同じ層で隣り合う配線の間隔を半分にすると、その配線間の容量はおよそどうなるか。(平行平板として近似する)

「エアギャップ」が出てくる問題(4問)

  1. 配線間の絶縁膜の一部を空洞(エアギャップ)にする技術の主な目的はどれか。
  2. 微細化が進んだトランジスタで、性能を制限する要因として重要性が増しているものはどれか。
  3. 熱酸化で形成したSiO2膜の比誘電率に最も近い値はどれか。
  4. 同じ層で隣り合う配線の間隔を半分にすると、その配線間の容量はおよそどうなるか。(平行平板として近似する)
