抽象構文木(AST)とは

ちゅうしょうこうぶんぎ

プログラムの構造を、演算や文を節にした木で表したもの。括弧や区切り記号などの意味をもたない情報は省き、演算子の優先順位は木の形で表す。

この用語の分野: コンパイラ

解説の中の「抽象構文木(AST)」

  • 抽象構文木は、プログラムの意味に必要な演算や文だけを節にした木で、例えば (a + b) * c では、掛け算の節の下に足し算の節がくることで、括弧がなくても計算の順番が分かります。

    抽象構文木(AST)の特徴として正しいものはどれか。

  • 抽象構文木では先に計算する演算ほど下に置かれるので、根は + で、その左の子が2、右の子が3と4を子にもつ * の節になります。

    式 2 + 3 * 4 の抽象構文木の形として正しいものはどれか。

「抽象構文木(AST)」が出てくる問題(2問)

  1. 抽象構文木(AST)の特徴として正しいものはどれか。
  2. 式 2 + 3 * 4 の抽象構文木の形として正しいものはどれか。
