抽象構文木(AST)とは

ちゅうしょうこうぶんぎ

プログラムの構造を、演算や文を節にした木で表したもの。括弧や区切り記号などの意味をもたない情報は省き、演算子の優先順位は木の形で表す。

「抽象構文木(AST)」は、1分野の2問の練習問題に出てきます(コンパイラなど)。

この用語の分野: コンパイラ

構文解析木からASTへ

文法をそのままたどる構文解析器(パーサ)は、具象構文木(構文解析木)を作ります。そこには適用した文法規則ごとの節と、括弧、カンマ、セミコロンまで含むすべてのトークンの葉があります。式・項・因子を別々の規則にして優先順位を表す文法では、子が1つだけの節が長く連なることもあります。AST(抽象構文木)はこうしたものをすべて捨てます。各節は二項演算、関数呼び出し、if文、変数参照といった意味のある構文要素で、その要素に必要な子だけを持ちます。

木の形で表す優先順位と結合性

先に評価される演算ほど、木の深い位置に置かれます。2 + 3 * 4 では根が + で、その子は 2 と、3 と 4 を子に持つ * の節です。(2 + 3) * 4 では根が * になり、括弧は役目を終えて消えます。結合性も同じように表されます。a - b - c は (a - b) - c を意味するので、根の左の子がもう1つの減算になり、左に傾いた木になります。したがって、子を親より先に訪れる後行順(帰りがけ順)の走査を行えば、式を正しい順序で評価できます。

コンパイラはASTで何をするか

構文解析の後、意味解析がASTをたどり、各名前をその宣言に結び付け、型を検査・推論し、暗黙の型変換を挿入し、宣言されていない変数の使用などのエラーを報告します。各節には通常これらの情報が付加されます。情報を付加した木は次に、3番地コードやSSA形式などの中間表現(IR)に変換され、そこでは制御の流れが基本ブロック間の明示的な分岐になります。単純な木走査型インタプリタはASTを直接実行し、フォーマッタ、リンタ、リファクタリングエンジンといったツールもASTを対象に動作します。

ASTとIRの違い

ASTはソース言語をそのまま映したもので、入れ子のループや構造化されたif文、ソースレベルの式がまだ残っています。そのため、書かれたとおりのプログラムを対象にする検査や変換に最適です。IRはよりマシンに近く、単純な演算の平たい並びと明示的なジャンプで構成されるため、データフロー解析や最適化に向いています。両者は混同されがちですが、おおまかな境界は次のとおりです。ASTはプログラマが何を書いたかを表し、IRは何を計算しなければならないかを表します。

抽象構文木(AST)の練習問題に挑戦

抽象構文木(AST)の特徴として正しいものはどれか。

  1. Aソースコードの括弧や区切り記号まで、すべてを節として残している
  2. B意味に関係しない記号を省き、演算子の優先順位を木の形で表している
  3. CCPUの命令と1対1に対応しており、そのまま実行できる
答えと解説を見る

正解：B. 意味に関係しない記号を省き、演算子の優先順位を木の形で表している

構文解析では、文法の規則どおりに括弧や区切り記号まで含めた木(具象構文木)ができますが、その後の処理には不要な情報が多く含まれます。抽象構文木は、プログラムの意味に必要な演算や文だけを節にした木で、例えば (a + b) * c では、掛け算の節の下に足し算の節がくることで、括弧がなくても計算の順番が分かります。CPUの命令に対応しているのは、さらに後の段階で生成するコードです。

式 2 + 3 * 4 の抽象構文木の形として正しいものはどれか。

  1. A根は + の節で、その右の子が 3 * 4 を表す * の節になる
  2. B根は * の節で、その左の子が 2 + 3 を表す + の節になる
  3. C2、3、4、+、* の5つの節が、すべて根の直接の子として並ぶ
答えと解説を見る

正解：A. 根は + の節で、その右の子が 3 * 4 を表す * の節になる

掛け算は足し算より優先順位が高いので、この式は 2 + (3 * 4) と解釈されます。抽象構文木では先に計算する演算ほど下に置かれるので、根は + で、その左の子が2、右の子が3と4を子にもつ * の節になります。木を下から評価すると、3 * 4 = 12 を先に計算し、2 + 12 = 14 が得られます。根が * になるのは (2 + 3) * 4 と書いた場合で、すべてを根の子に並べると計算の順番が表せません。

よくある質問

構文解析木と抽象構文木の違いは何ですか?

構文解析木は区切り記号を含むすべての文法規則とトークンを記録しますが、ASTは意味をもつ構文要素だけを残します。構文解析木では規則の連なりで示される優先順位が、ASTではどの節が親になるかだけで表されます。

ASTでは括弧はどう表されますか?

括弧は節としては保存されません。その効果は木の構造に反映され、括弧で囲まれた部分式は、親の演算より先に評価される部分木になります。

インタプリタはASTを使いますか?

多くのインタプリタが使います。木走査型インタプリタはASTを直接評価し、より高速なインタプリタは通常、ASTをいったんバイトコードにコンパイルしてからそれを実行します。
