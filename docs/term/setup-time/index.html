セットアップ時間とは

せっとあっぷじかん

フリップフロップでクロックの有効なエッジより前に、データ入力を確定させておかなければならない最小の時間。守れない経路は、回路の最大動作周波数を制限する。

この用語の分野: 論理回路

解説の中の「セットアップ時間」

  • フリップフロップが正しく取り込むには、クロックのエッジより一定時間前からデータが安定している必要があり、これがセットアップ時間です。

    フリップフロップのセットアップ時間の説明として正しいものはどれか。

  • 正しく取り込むにはセットアップ時間とホールド時間を守る必要があります。

    D型フリップフロップの動作として正しいものはどれか。

  • クロック周期は「クロック→出力の遅延+経路の論理遅延+セットアップ時間+スキュー等の余裕」以上でなければならず、最も遅延の大きい経路(クリティカルパス)が最大周波数を決めます。

    同期式回路で、動作できる最大のクロック周波数を決めるものはどれか。

「セットアップ時間」が出てくる問題(6問)

  1. フリップフロップのセットアップ時間の説明として正しいものはどれか。
  2. 非同期の信号をフリップフロップで受けたときに、セットアップ時間やホールド時間を満たせず、出力が一時的に0とも1とも定まらなくなる状態を何と呼ぶか。
  3. D型フリップフロップの動作として正しいものはどれか。
  4. 同期式回路で、動作できる最大のクロック周波数を決めるものはどれか。
  5. ACテストで主に確認する項目はどれか。
  6. 静的タイミング解析(STA)の説明として正しいものはどれか。
