セットアップ時間とは

せっとあっぷじかん

フリップフロップでクロックの有効なエッジより前に、データ入力を確定させておかなければならない最小の時間。守れない経路は、回路の最大動作周波数を制限する。

「セットアップ時間」は、5分野の19問の練習問題に出てきます(タイミング解析とCDC, 論理回路, データシートの読み方など)。

この用語の分野: 論理回路

フリップフロップにセットアップ時間が必要な理由

エッジトリガ型のフリップフロップは、一般に2つのラッチで構成されます。クロックエッジまでに入力が1段目のラッチを通過し、内部ノードが落ち着いて、ラッチが閉じるときに値が確実に保持されなければなりません。データがエッジに近すぎるタイミングで変化すると、フリップフロップは古い値と新しい値のどちらを取り込むか分からず、メタステーブルになって確定までに予測できない時間がかかることもあります。エッジ前に必要な安定期間がセットアップ時間、エッジ後に必要な期間がホールド時間です。どちらもセルごとにキャラクタライズされ、入力のスルーや動作条件によって変わります。

セットアップチェックとスラック

あるエッジで送り出したデータは、次の取り込みエッジよりセットアップ時間以上前に到着しなければなりません。到着時間はクロック・出力間遅延とロジック遅延の和、要求時間はクロックスキューで補正したクロック周期からセットアップ時間とクロックの不確かさを引いた値です。スラックは要求時間から到着時間を引いた値で、負ならタイミング違反です。周期2.0 ns、クロック・出力間遅延0.2 ns、ロジック1.4 ns、セットアップ0.1 nsならスラックは0.3 nsです。最も遅いパス(クリティカルパス)が最大周波数を決め、合計2.5 nsなら400 MHzまで動作できます。

セットアップ時間とホールド時間の違い

セットアップは次のエッジに対する最大遅延のチェックなので、クロックを遅くすれば違反は消えます。パイプライン化、論理段数の削減、セルのサイズアップ、低しきい値電圧セルの使用でパスを短くしても解消できます。ホールドは同じエッジに対する最小遅延のチェックで、周波数に依存しないため、遅延を追加して修正します。両者は逆方向に働き、取り込み側クロックのスキューがセットアップに有利なら、ホールドには不利です。OCV(オンチップばらつき)のディレーティングでは、セットアップでは送り出し側を遅く、取り込みクロックを早く見積もり、ホールドではその逆にします。

チェックを変える制約

マルチサイクルパスを2に設定すると取り込みエッジが2周期先に移りますが、イネーブルなどのロジックで実際に1サイクルおきに取り込む場合にしか正しくありません。立ち上がりエッジで送り出し、立ち下がりエッジで取り込むハーフサイクルパスでは、半周期しか使えません。ラッチではタイムボローイングが可能で、ラッチが開いた後に届いたデータも閉じる前に到着すれば通過し、次段の時間を借りることになります。チップの境界では、set_input_delayとset_output_delayでチップ外部で費やされる時間を記述します。有用スキュー(useful skew)は、取り込みクロックを意図的に遅らせて隣接する段の時間配分を調整する手法です。

セットアップ時間の練習問題に挑戦

フリップフロップのセットアップ時間の説明として正しいものはどれか。

  1. Aクロックのエッジのあとに、データを保持し続けなければならない最小時間
  2. Bクロックのエッジより前に、データ入力が安定していなければならない最小時間
  3. C電源を入れてから動作するまでの時間
答えと解説を見る

正解：B. クロックのエッジより前に、データ入力が安定していなければならない最小時間

フリップフロップが正しく取り込むには、クロックのエッジより一定時間前からデータが安定している必要があり、これがセットアップ時間です。データ経路の遅延がクロック周期からセットアップ時間を引いた値を超えると違反になり、クロックを遅くすれば解消できます。エッジ後にデータを保持する必要がある時間はホールド時間で、どちらかを満たさないと誤った値の取り込みやメタステーブルの原因になります。

非同期の信号をフリップフロップで受けたときに、セットアップ時間やホールド時間を満たせず、出力が一時的に0とも1とも定まらなくなる状態を何と呼ぶか。

  1. Aメタステーブル
  2. Bグリッチ
  3. Cラッチアップ
答えと解説を見る

正解：A. メタステーブル

メタステーブル状態では、出力が中間電圧にとどまったり、定まるまでに長い時間がかかったりします。原理的に完全には防げず、解消までの時間に対して確率が指数関数的に減るだけです。そのため非同期信号はフリップフロップを2段以上つないだ同期化回路で受け、1段目で不定になっても2段目までに確定する確率を十分高めます(平均故障間隔を数千年以上に)。多ビットのデータはFIFOやハンドシェイクで受け渡します。

よくある質問

セットアップ時間とホールド時間の違いは?

セットアップ時間はクロックエッジの前にデータが安定していなければならない時間、ホールド時間はエッジの後も安定を保たなければならない時間です。セットアップは最大周波数を制限しますが、ホールド違反はクロック周波数に依存しません。

セットアップスラックの計算方法は?

スラック = 要求時間 − 到着時間 です。到着時間はクロック・出力間遅延とロジック遅延の和、要求時間は(スキューで補正した)クロック周期からセットアップ時間とクロックの不確かさを引いた値で、スラックが正ならタイミングを満たしています。

セットアップ違反はクロック周波数を下げれば直る?

直ります。周期が長くなればデータの到着に使える時間が増えるため、十分に低い周波数ではセットアップ違反は消えます。ホールド違反は周波数を下げても消えないため、チップ製造後に見つかるとより深刻です。

「セットアップ時間」が出てくる問題(19問)

  1. フリップフロップのセットアップ時間の説明として正しいものはどれか。
  2. 非同期の信号をフリップフロップで受けたときに、セットアップ時間やホールド時間を満たせず、出力が一時的に0とも1とも定まらなくなる状態を何と呼ぶか。
  3. クロック周期 2.0 ns の同期回路で、送り側フリップフロップのクロック→出力遅延が 0.2 ns、組み合わせ回路の遅延が 1.4 ns、受け側フリップフロップのセットアップ時間が 0.1 ns である。クロックスキューを0とすると、セットアップのスラックはいくらか。
  4. フリップフロップ間の経路で、クロック→出力遅延が 0.15 ns、組み合わせ回路の最大遅延が 2.2 ns、セットアップ時間が 0.15 ns である。スキューとクロックの不確かさを無視すると、この経路で動作できる最大のクロック周波数はいくらか。
  5. クロック周期 1.0 ns、クロック→出力遅延 0.1 ns、組み合わせ回路の遅延 0.85 ns、セットアップ時間 0.08 ns の経路がある。受け側フリップフロップのクロックが送り側より 0.05 ns 遅れて届くとき、セットアップのスラックはいくらか。
  6. クロック周期 1.25 ns(800 MHz)の経路で、クロック→出力遅延と組み合わせ回路の遅延の合計が 1.05 ns、セットアップ時間が 0.05 ns、セットアップ用のクロックの不確かさが 0.05 ns に設定されている。セットアップのスラックはいくらか。
  7. OCVディレーティングとして、セットアップ解析で送り側のクロック経路とデータ経路の遅延を1.1倍、受け側のクロック経路の遅延を0.9倍にする。送り側クロック経路 1.0 ns、データ経路(クロック→出力を含む)1.5 ns、受け側クロック経路 1.0 ns(共通部分はない)、周期 3.0 ns、セットアップ時間 0.1 ns のとき、セットアップのスラックはいくらか。
  8. 周期 2.0 ns のクロックで動く回路で、データの到着時刻(クロック→出力遅延と組み合わせ回路の遅延の合計)が 3.3 ns、セットアップ時間が 0.1 ns の経路がある。この経路は2サイクルに1回だけ取り込めばよいので、セットアップのマルチサイクルパスを2に設定した。セットアップのスラックはいくらか。
  9. 周期 2.0 ns、デューティ比50%のクロックで、立ち上がりエッジで送り出し、立ち下がりエッジで取り込む経路がある。セットアップ時間を 0.1 ns、スキューを0とすると、クロック→出力遅延と組み合わせ回路の遅延の合計に許される最大値はいくらか。
  10. 周期 2.0 ns のクロックで、入力端子に set_input_delay 0.6 ns が設定されている。内部のフリップフロップのセットアップ時間が 0.1 ns、クロックの遅延とスキューを無視すると、入力端子からフリップフロップまでのチップ内部の経路に許される最大遅延はいくらか。
  11. 周期 1.0 ns のクロックで、フリップフロップA→B→Cとつながる経路がある。A→Bはクロック→出力遅延とセットアップ時間を含めて 1.2 ns が必要で、B→Cは 0.8 ns で足りる。スキューを意図的に使って両方のセットアップを満たすには、Bのクロックをどうすればよいか(AとCのクロックは同時に届くものとする)。
  12. 送信側のICのクロック→出力の遅延が max 6 ns、基板配線の遅延が1 ns、受信側のICのセットアップ時間が3 nsのとき、クロックのずれを無視すると、使える最大のクロック周波数はいくらか。
  13. D型フリップフロップの動作として正しいものはどれか。
  14. 同期式回路で、動作できる最大のクロック周波数を決めるものはどれか。
  15. ACテストで主に確認する項目はどれか。
