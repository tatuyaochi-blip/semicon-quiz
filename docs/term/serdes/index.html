SerDesとは

さーです

シリアライザ/デシリアライザ。送る側でチップ内の並列のデータを1本の速いビット列に変え、受ける側で元の並列のデータに戻す回路。高速なシリアル伝送の物理層の中心。

この用語の分野: インターフェース・バス規格

解説の中の「SerDes」

  • SerDesの送信側はこれを1本の非常に速いビット列に並べ替えて送り出し、受信側はビット列からクロックを取り出してビットを判定し、元の幅のデータに戻します。

    高速なシリアル伝送で使われるSerDes(シリアライザ/デシリアライザ)の役割として正しいものはどれか。

  • 高速の通信インターフェース(SerDes)はこの変換を数十Gb/sで行い、配線の本数を減らしています。

    フリップフロップを直列につなぎ、クロックごとにデータを1ビットずつ隣へ移すシフトレジスタの代表的な用途はどれか。

  • 数十Gb/sに達する高速なSerDesなどを、テスタだけで直接測るのは難しく高価です。

「SerDes」が出てくる問題(7問)

  1. 高速なシリアル伝送で使われるSerDes(シリアライザ/デシリアライザ)の役割として正しいものはどれか。
  2. フリップフロップを直列につなぎ、クロックごとにデータを1ビットずつ隣へ移すシフトレジスタの代表的な用途はどれか。
  3. 高速なシリアル通信のインターフェースのテストで、チップの送信回路の出力を受信回路に折り返してつなぎ、チップ自身で通信を確認する方法はどれか。
  4. PCI Expressの通信のしくみとして正しいものはどれか。
  5. 100ギガビットのイーサネットのような高速な接続が、例えば25 Gb/sのレーンを4本束ねて作られることがある。この考え方として正しいものはどれか。
  6. AI向けのGPUを多数つなぐシステムで、PCI Expressとは別の、GPUどうしを結ぶ専用の高速な接続(NVIDIAのNVLinkなど)が使われる主な理由はどれか。
  7. PCI Expressのリンクの省電力の機能(ASPMによるL0sやL1の状態)について正しいものはどれか。
