直接遷移型とは

ちょくせつせんいがた

伝導帯の底と価電子帯の頂上が同じ波数にあるバンド構造。電子と正孔の再結合で効率よく発光する。GaAsなど。

この用語の分野: 化合物半導体

解説の中の「直接遷移型」

  • そのためLEDやレーザーにはGaAs、InP、GaNなどの直接遷移型が使われます。

    シリコンのバンド構造の種類として正しいものはどれか。

  • 光子は運動量をほとんど運べないため、遷移にはフォノンが同時に関わる必要があり、放射再結合の確率は直接遷移型より桁違いに低くなります。

    シリコンのような間接遷移型の半導体で、電子と正孔が再結合して光を出す確率が低い理由として正しいものはどれか。

  • 効率よく光らせるには直接遷移型の材料が必要で、シリコンでは実用的なLEDは作れません。

    LEDが光る仕組みとして正しいものはどれか。

「直接遷移型」が出てくる問題(4問)

  1. シリコンのバンド構造の種類として正しいものはどれか。
  2. シリコンのような間接遷移型の半導体で、電子と正孔が再結合して光を出す確率が低い理由として正しいものはどれか。
  3. LEDが光る仕組みとして正しいものはどれか。
  4. ガリウムヒ素(GaAs)のバンド構造として正しいものはどれか。
