ストレージクラスメモリとは

すとれーじくらすめもり

DRAMとNANDフラッシュの間の、速度・容量・コストの差を埋めることをめざした不揮発性メモリ。3D XPointを使った製品が代表例だった。

「ストレージクラスメモリ」は、1分野の2問の練習問題に出てきます(次世代メモリなど)。

この用語の分野: 次世代メモリ

埋めようとしている性能差

DRAMは数十 nsで応答しますが、揮発性でビットあたりのコストも比較的高く、NANDフラッシュは安価で不揮発ですが、読み出しに数十 µsと約1000倍の時間がかかります。SCM(ストレージクラスメモリ)はその中間を狙うもので、不揮発でありながらDRAMより高密度かつ安価で、NANDより桁違いに高速であることをめざします。候補となる技術はフラッシュのような書き込み前の消去が不要で、データをその場で書き換えられ、一般にNANDよりはるかに高い書き換え耐性をもちます。

2通りの接続方法

SCMはメモリバス上にモジュールとして置き、プロセッサが通常のロード・ストア命令でバイト単位に読み書きすることができます。この使い方では大容量の永続メモリとして働きますが、データが確実に不揮発の媒体に届くよう、ソフトウェアが明示的にCPUキャッシュからデータをフラッシュする必要があります。もう一つは、NVMeなどのストレージインターフェースの先に超高速のSSDとして置く方法です。この場合はブロック単位でアクセスし、遅延の多くは媒体ではなくインターフェースとソフトウェアスタックから生じます。

支える技術

最もよく知られた例である3D XPointは、IntelとMicronが開発し、Optaneとして販売されました。ワード線とビット線の交点に、相変化を利用するものと広く考えられている抵抗変化型の記憶素子と、OTS(オボニック閾値スイッチ)のセレクタを積み重ねた構造で、各セルにトランジスタはありません。ほかの候補には相変化メモリ、ReRAM(抵抗変化メモリ)、MRAM(磁気抵抗メモリ)がありますが、MRAMはセルが大きいため組み込みメモリに向いています。低遅延のSLC(シングルレベルセル)NANDは、同じ領域の一部をフラッシュで狙うアプローチです。

普及しなかった理由

SCMが成功するには、DRAMより明確に安く、同時にNANDより明確に速くなければなりませんが、既存の両技術は改良を続けています。NANDは3Dの積層数の増加でコストが下がり、DRAMも微細化を続けています。さらに、永続メモリを生かすにはアプリケーション側のソフトウェア変更も必要でした。Optane製品は大きな市場を得られず、2022年に製品終了が発表されました。現在この階層の多くは、低遅延のSLC NANDと、標準的なインターコネクトの先で容量を拡張するCXL(Compute Express Link)接続のメモリが担っています。

ストレージクラスメモリの練習問題に挑戦

「ストレージクラスメモリ」の位置づけとして正しいものはどれか。

  1. ADRAMとNANDフラッシュの間の速度・容量・コストの差を埋める不揮発性メモリ
  2. BCPU内部のレジスタ
  3. C光ディスクの一種
答えと解説を見る

正解：A. DRAMとNANDフラッシュの間の速度・容量・コストの差を埋める不揮発性メモリ

DRAMとNANDの間には、アクセス時間で約1000倍(数十ns対数十µs)、ビット単価で数十倍の差があります。その間を埋める、DRAMより安く大容量でNANDより桁違いに速い不揮発性メモリをストレージクラスメモリ(SCM)と呼びます。相変化メモリを使ったIntelのOptaneが代表例でしたが、2022年に終息が発表され、現在は高速なSLC型NANDやCXLで接続するメモリなどがこの領域を担っています。

かつてIntelとMicronが共同開発し、「Optane」の製品名で販売されたストレージクラスメモリの技術はどれか。

  1. A3D NAND
  2. B3D XPoint
  3. CHBM
答えと解説を見る

正解：B. 3D XPoint

3D XPointは、抵抗変化型(相変化系とされる)の記憶素子とOTSセレクタを縦横の配線の交点に置いて積み重ねたメモリで、2015年に発表され、Optaneとして製品化されました。NANDの約1000倍速く、DRAMより大容量・低価格をうたい、SSDやメインメモリ用のモジュールが作られました。しかし性能向上が進むNANDやDRAMとの価格競争で市場が広がらず、2022年に事業終息が発表されました。

よくある質問

Intel OptaneはDRAMですか、フラッシュですか?

どちらでもありません。Optaneは相変化を利用すると考えられている不揮発のクロスポイントメモリ、3D XPointを使っており、速度とコストの面でDRAMとNANDフラッシュの中間に位置づけられていました。

ストレージクラスメモリは揮発性ですか?

いいえ。定義上、電源がなくてもデータを保持する不揮発性メモリであり、それがDRAMとの最大の違いです。

Intel Optaneの後継は何ですか?

1つの技術がそのまま置き換えたわけではありません。高速ストレージの役割の多くは低遅延のSLC NAND SSDが担い、DRAMスロットを超える容量拡張はCXL接続のメモリが担っています。
