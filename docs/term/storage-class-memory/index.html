ストレージクラスメモリとは

すとれーじくらすめもり

DRAMとNANDフラッシュの間の、速度・容量・コストの差を埋めることをめざした不揮発性メモリ。3D XPointを使った製品が代表例だった。

「ストレージクラスメモリ」は、1分野の2問の練習問題に出てきます(次世代メモリなど)。

この用語の分野: 次世代メモリ

ストレージクラスメモリの練習問題に挑戦

「ストレージクラスメモリ」の位置づけとして正しいものはどれか。

  1. ADRAMとNANDフラッシュの間の速度・容量・コストの差を埋める不揮発性メモリ
  2. BCPU内部のレジスタ
  3. C光ディスクの一種
答えと解説を見る

正解：A. DRAMとNANDフラッシュの間の速度・容量・コストの差を埋める不揮発性メモリ

DRAMとNANDの間には、アクセス時間で約1000倍(数十ns対数十µs)、ビット単価で約10倍の差があります。その間を埋める、DRAMより安く大容量でNANDより桁違いに速い不揮発性メモリをストレージクラスメモリ(SCM)と呼びます。相変化メモリを使ったIntelのOptaneが代表例でしたが、2022年に終息が発表され、現在は高速なSLC型NANDやCXLで接続するメモリなどがこの領域を担っています。

かつてIntelとMicronが共同開発し、「Optane」の製品名で販売されたストレージクラスメモリの技術はどれか。

  1. A3D NAND
  2. B3D XPoint
  3. CHBM
答えと解説を見る

正解：B. 3D XPoint

3D XPointは、抵抗変化型(相変化系とされる)の記憶素子とOTSセレクタを縦横の配線の交点に置いて積み重ねたメモリで、2015年に発表され、Optaneとして製品化されました。NANDの約1000倍速く、DRAMより大容量・低価格をうたい、SSDやメインメモリ用のモジュールが作られました。しかし性能向上が進むNANDやDRAMとの価格競争で市場が広がらず、2022年に事業終息が発表されました。

解説の中の「ストレージクラスメモリ」

  • その間を埋める、DRAMより安く大容量でNANDより桁違いに速い不揮発性メモリをストレージクラスメモリ(SCM)と呼びます。
