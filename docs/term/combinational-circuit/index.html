組み合わせ回路とは

くみあわせかいろ

出力がそのときの入力だけで決まる論理回路。加算器やマルチプレクサ、デコーダなど。

「組み合わせ回路」は、4分野の30問の練習問題に出てきます(ハードウェア記述言語と検証, タイミング解析とCDC, 論理回路など)。

この用語の分野: 論理回路

組み合わせ回路とは

組み合わせ回路は、出力がそのときの入力だけで決まる論理回路です。AND、OR、NOTなどのゲートを、出力が入力に戻る帰還のない形でつないで作り、同じ入力に対しては、ゲートの遅延の後に必ず同じ出力になります。記憶の働きをもたないので、入力と出力の関係は真理値表や論理式で完全に表せます。代表例は加算器、マルチプレクサ、デコーダ、エンコーダ、比較器などで、CPUの演算器(ALU)も大部分が組み合わせ回路です。設計では、カルノー図や論理合成ツールを使って、論理式を少ないゲートで実現できる形に簡単化します。

順序回路との違い

順序回路は、フリップフロップなどの記憶素子をもち、出力が現在の入力だけでなく内部状態(過去の入力の履歴)にも依存します。カウンタ、レジスタ、ステートマシンが代表例です。実際のデジタル回路は2つを組み合わせた構成で、クロックで同期したレジスタの間に組み合わせ回路が置かれます。各クロックのサイクルで組み合わせ回路がレジスタの値から次の値を計算し、次のクロックのエッジでレジスタがそれを取り込みます。組み合わせ回路の出力をフリップフロップを通さずに自分の入力に戻すと組み合わせループになり、発振や値が定まらない原因になるため避けます。

遅延とグリッチ

組み合わせ回路の出力は、入力が変わってから、ゲートと配線の遅延を経て確定します。入力から出力までの経路のうち最も遅いもの(クリティカルパス)は、同期回路の最大のクロック周波数を決める要素の1つです。また、同じ入力の変化が遅延の異なる経路を通って出力に届くと、出力が一瞬だけ誤った値になるグリッチ(ハザード)が出ることがあります。同期回路ではクロックのエッジまでに落ち着けば機能上は問題ありませんが、余分な充放電で消費電力が増えます。クロックや非同期のリセットに使う信号では、グリッチが誤動作の原因になります。

HDLでの記述

VerilogやSystemVerilogでは、組み合わせ回路をassign文や、always @(*)、always_combのブロックで記述します。alwaysブロックで書く場合は、すべての条件で出力に値を代入する必要があります。代入しない場合があると前の値を保つ必要が生じ、論理合成で意図しないラッチができてしまいます。対策として、ブロックの先頭で既定値を代入したり、if文には必ずelseを、case文にはdefaultを書いたりします。また、組み合わせ回路のalwaysブロックではブロッキング代入(=)を使うのが一般的なガイドラインです。

組み合わせ回路の練習問題に挑戦

組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。

  1. Aメタステーブル
  2. Bグリッチ(ハザード)
  3. Cラッチアップ
答えと解説を見る

正解：B. グリッチ(ハザード)

同じ入力の変化が異なる経路で出力に届くとき、遅延の差によって出力が一瞬誤った値になることがあり、これをグリッチ(ハザード)といいます。同期式回路ではクロックのエッジまでに落ち着けば機能上は問題ありませんが、余分な充放電で消費電力が増えます。一方、クロックや非同期リセット、他チップへの制御信号にグリッチが乗ると誤動作するため、これらはフリップフロップの出力から直接出すのが鉄則です。

クロック周期 2.0 ns の同期回路で、送り側フリップフロップのクロック→出力遅延が 0.2 ns、組み合わせ回路の遅延が 1.4 ns、受け側フリップフロップのセットアップ時間が 0.1 ns である。クロックスキューを0とすると、セットアップのスラックはいくらか。

  1. A0.3 ns
  2. B0.4 ns
  3. C0.5 ns
答えと解説を見る

正解：A. 0.3 ns

セットアップのスラックは「要求時刻 − 到着時刻」で求めます。データの到着時刻は 0.2 + 1.4 = 1.6 ns、要求時刻は次のクロックエッジからセットアップ時間を引いた 2.0 − 0.1 = 1.9 ns なので、スラックは 1.9 − 1.6 = 0.3 ns です。正の値なので制約を満たしています。0.4 ns はセットアップ時間を引き忘れた値、0.5 ns はセットアップ時間を逆に足してしまった値です。スラックが負になると違反です。

よくある質問

組み合わせ回路とは何ですか?

出力がそのときの入力だけで決まり、記憶の働きをもたない論理回路です。加算器、マルチプレクサ、デコーダなどが代表例で、入力と出力の関係は真理値表で完全に表せます。

組み合わせ回路と順序回路の違いは?

組み合わせ回路の出力は現在の入力だけで決まります。順序回路はフリップフロップなどの記憶素子をもち、出力が現在の入力と内部状態(過去の入力の履歴)の両方で決まります。実際のデジタル回路は、レジスタの間に組み合わせ回路を置いた構成で、2つを組み合わせて使います。

ラッチやフリップフロップは組み合わせ回路ですか?

いいえ。ラッチやフリップフロップは値を記憶するので順序回路です。組み合わせ回路のつもりでHDLを書いても、出力に値を代入しない場合が残っていると、意図しないラッチができることがあります。

「組み合わせ回路」が出てくる問題(30問)

  1. 組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。
  2. クロック周期 2.0 ns の同期回路で、送り側フリップフロップのクロック→出力遅延が 0.2 ns、組み合わせ回路の遅延が 1.4 ns、受け側フリップフロップのセットアップ時間が 0.1 ns である。クロックスキューを0とすると、セットアップのスラックはいくらか。
  3. フリップフロップ間の経路で、クロック→出力遅延が 0.15 ns、組み合わせ回路の最大遅延が 2.2 ns、セットアップ時間が 0.15 ns である。スキューとクロックの不確かさを無視すると、この経路で動作できる最大のクロック周波数はいくらか。
  4. クロック周期 1.0 ns、クロック→出力遅延 0.1 ns、組み合わせ回路の遅延 0.85 ns、セットアップ時間 0.08 ns の経路がある。受け側フリップフロップのクロックが送り側より 0.05 ns 遅れて届くとき、セットアップのスラックはいくらか。
  5. 送り側のクロック→出力遅延が最小 0.08 ns、組み合わせ回路の最小遅延が 0.02 ns、受け側のホールド時間が 0.05 ns である。受け側のクロックが送り側より 0.1 ns 遅れて届くとき、ホールドのスラックはいくらか。
  6. クロック周期 1.25 ns(800 MHz)の経路で、クロック→出力遅延と組み合わせ回路の遅延の合計が 1.05 ns、セットアップ時間が 0.05 ns、セットアップ用のクロックの不確かさが 0.05 ns に設定されている。セットアップのスラックはいくらか。
  7. 周期 2.0 ns のクロックで動く回路で、データの到着時刻(クロック→出力遅延と組み合わせ回路の遅延の合計)が 3.3 ns、セットアップ時間が 0.1 ns の経路がある。この経路は2サイクルに1回だけ取り込めばよいので、セットアップのマルチサイクルパスを2に設定した。セットアップのスラックはいくらか。
  8. 周期 2.0 ns、デューティ比50%のクロックで、立ち上がりエッジで送り出し、立ち下がりエッジで取り込む経路がある。セットアップ時間を 0.1 ns、スキューを0とすると、クロック→出力遅延と組み合わせ回路の遅延の合計に許される最大値はいくらか。
  9. 周期 2.5 ns(400 MHz)のクロックで、出力端子に set_output_delay 0.8 ns が設定されている。出力端子を駆動するフリップフロップのクロック→出力遅延が 0.2 ns のとき、フリップフロップから出力端子までの組み合わせ回路と配線に許される最大遅延はいくらか(クロックの遅延は無視する)。
  10. 送り側のクロックドメインで、組み合わせ回路の出力を直接、受け側の同期化回路に入れてはいけない理由として正しいものはどれか。
  11. 組み合わせ回路のつもりで上のように書いた。起こりうる問題として正しいものはどれか。
  12. 組み合わせ回路のつもりで上のように書くと、論理合成で何ができるか。
  13. 組み合わせ回路のalwaysブロックで、意図しないラッチを防ぐためによく使われる書き方はどれか。
  14. 上の記述のように、フリップフロップを通らずに組み合わせ回路の出力が自分の入力に戻ってくる形を何と呼び、なぜ避けるべきか。
  15. 組み合わせ回路で、if・else ifを長くつないだ記述と、条件が互いに重ならないcase文の記述を比べたときの説明として正しいものはどれか。
