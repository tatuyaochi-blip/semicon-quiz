組み合わせ回路とは

くみあわせかいろ

出力がそのときの入力だけで決まる論理回路。加算器やマルチプレクサ、デコーダなど。

「組み合わせ回路」は、3分野の18問の練習問題に出てきます(ハードウェア記述言語と検証, 論理回路, テスト・検査など)。

この用語の分野: 論理回路

組み合わせ回路の練習問題に挑戦

組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。

  1. Aメタステーブル
  2. Bグリッチ(ハザード)
  3. Cラッチアップ
答えと解説を見る

正解：B. グリッチ(ハザード)

同じ入力の変化が異なる経路で出力に届くとき、遅延の差によって出力が一瞬誤った値になることがあり、これをグリッチ(ハザード)といいます。同期式回路ではクロックのエッジまでに落ち着けば機能上は問題ありませんが、余分な充放電で消費電力が増えます。一方、クロックや非同期リセット、他チップへの制御信号にグリッチが乗ると誤動作するため、これらはフリップフロップの出力から直接出すのが鉄則です。

組み合わせ回路のalwaysブロックで、意図しないラッチを防ぐためによく使われる書き方はどれか。

  1. A条件分岐をできるだけ多く書き、elseは省略する
  2. Bブロックの先頭で、出力のすべての信号にデフォルトの値を代入してから条件分岐を書く
  3. C出力の信号をすべてwireにして、alwaysの中で代入する
答えと解説を見る

正解：B. ブロックの先頭で、出力のすべての信号にデフォルトの値を代入してから条件分岐を書く

ブロックの先頭で「y = 0; valid = 0;」のように出力にデフォルトの値を入れておけば、後の条件分岐でどの経路を通っても、少なくともデフォルトの値が代入されているので、値を保つ必要がなくなりラッチはできません。条件の多い状態機械の出力の記述などで特に役に立ちます。SystemVerilogのalways_combを使うと、ラッチができたときにツールが警告を出してくれます。

解説の中の「組み合わせ回路」

  • 組み合わせ回路には記憶の働きがないので、論理合成は値を保つためのラッチを作ります。
