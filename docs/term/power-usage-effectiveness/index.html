PUEとは

ぴーゆーいー

Power Usage Effectivenessの略。データセンター全体の消費電力をIT機器の消費電力で割った値で、1に近いほど効率が良い。

「PUE」は、1分野の1問の練習問題に出てきます(電力管理(ソフトウェア制御)など)。

この用語の分野: 電力管理(ソフトウェア制御)

PUEの練習問題に挑戦

データセンターの電力の効率を表す指標PUEの説明として正しいものはどれか。

  1. ACPU1つあたりの性能を表す値で、大きいほど良い
  2. Bデータセンターの床の面積を表す値
  3. C施設全体の消費電力をIT機器の消費電力で割った値で、1に近いほど冷却などのむだが少ない
答えと解説を見る

正解：C. 施設全体の消費電力をIT機器の消費電力で割った値で、1に近いほど冷却などのむだが少ない

PUE(Power Usage Effectiveness)は、データセンター全体で使う電力を、サーバやストレージ、ネットワークの機器が使う電力で割った値です。冷却や電源の変換の損失、照明などに電力を使うほど大きくなります。例えばPUEが1.5なら、IT機器の電力の半分の量を冷却などに使っていることになります。外気や液冷を使った効率の高い冷却で、1.1程度を実現している施設もあります。
