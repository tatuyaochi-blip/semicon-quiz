自由空間伝搬損失とは

じゆうくうかんでんぱんそんしつ

障害物や反射のない自由空間で、等方性アンテナどうしの間で電波の電力が距離とともに球面状に広がって弱まる割合。L = (4πd/λ)² で表され、dBでは距離が2倍になるごとに約6 dB、10倍になるごとに20 dB増える。リンクバジェットの計算で、伝搬損失の基準として使われる。

「自由空間伝搬損失」は、1分野の1問の練習問題に出てきます(無線通信の基礎など)。

この用語の分野: 無線通信の基礎

自由空間伝搬損失の練習問題に挑戦

送受信のアンテナの利得を0 dBiとするとき、周波数2.4 GHz(波長0.125 m)の電波が自由空間を100 m伝わるときの自由空間伝搬損失に最も近いものはどれか。

  1. A40 dB
  2. B60 dB
  3. C80 dB
答えと解説を見る

正解：C. 80 dB

自由空間伝搬損失は、等方性アンテナどうしの間で、電力が距離とともに球面状に広がって弱まる割合で、L = (4πd/λ)² で表されます。d = 100 m、λ = 0.125 m では 4πd/λ ≈ 1.0×10⁴ なので、L = 20·log₁₀(1.0×10⁴) ≈ 80 dBです。dBで表すと、距離が2倍になるごとに約6 dB、10倍になるごとに20 dB損失が増えます。この式では、同じ距離なら周波数が高い(波長が短い)ほど損失が大きくなります。
