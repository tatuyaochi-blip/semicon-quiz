CVDとは

しーぶいでぃー

化学気相成長。原料ガスの化学反応によってウエハ上に薄膜を堆積する方法。

「CVD」は、7分野の31問の練習問題に出てきます(成膜(CVD・PVD), プロセス材料(ガス・薬液), エピタキシャル成長など)。

この用語の分野: 成膜(CVD・PVD)

CVD のしくみ

CVD(化学気相成長)では、原料ガスを加熱したウエハ上に流し、表面に吸着したガスが反応して固体の膜を残し、揮発性の副生成物は排気されます。たとえばタングステンは WF6 を水素で還元して堆積し、HF が放出されます。この点が、固体ターゲットから原子をはじき出し、化学変化なしに直進させるスパッタリングなどの PVD(物理気相成長)との違いです。CVD はガスが届く表面ならどこでも反応によって膜が成長するため、パターンの側壁や底面を PVD よりはるかによく被覆できます。

反応律速と供給律速

比較的低温では表面反応が遅い段階となるため、成長速度はアレニウスの式に従って温度に指数関数的に依存し、膜厚の均一性は温度の均一性で決まります。高温では反応が速く、ガスの供給が成長を律速するため、ガス流の均一性が重要になります。低温・低圧で得られる反応律速条件では、ガスが反応する前に溝の奥まで入り込むため、最も良好なコンフォーマリティが得られます。供給律速条件では開口部に膜が厚く付いて口がふさがり、内部にボイドが残ることがあります。

主な CVD の種類

数十〜数百 Pa で行う LPCVD(減圧 CVD)は、約 600〜800 ℃ で100枚以上のウエハを均一に成膜でき、ポリシリコン、ジクロロシランとアンモニアによる窒化シリコン、TEOS 酸化膜を堆積します。PECVD(プラズマ CVD)はプラズマ中の電子で原料を分解するため約 300〜400 ℃ で成膜でき、メタル配線形成後にも使えますが、膜に水素が含まれます。高密度プラズマ CVD は成膜と同時に角部をスパッタしてギャップを埋め、エピタキシャル CVD は単結晶層を成長させます(SiC では約 1,500〜1,650 ℃)。ALD(原子層堆積)は自己制限的な近縁手法で、ほぼ100%の段差被覆性が得られます。

使われている工程

CVD は、シャロートレンチ分離(STI)の埋め込み、層間絶縁膜、サイドウォールスペーサ、パッシベーション膜の堆積、タングステンのコンタクトプラグや 3D NAND のワード線の形成、デバイス用エピタキシャル層の成長に使われます。膜質は常に課題で、CVD 酸化膜は一般に熱酸化膜より密度が低く希フッ酸でのエッチングが速いため、熱酸化膜に対するウェットエッチングレート比(WERR)が膜質の指標になり、アニールで緻密化します。CVD の種類の選択は、主に温度の制約、コンフォーマリティ、スループット、膜の純度のバランスで決まります。

CVDの練習問題に挑戦

CVDによるエピタキシャル成長で、比較的低い温度の領域では成長速度が温度に強く依存する。その理由として正しいものはどれか。

  1. A原料ガスの供給量だけで成長速度が決まるため
  2. B表面での化学反応の速さが成長速度を決めている(表面反応律速)ため
  3. C成長速度が温度に依存しないため
答えと解説を見る

正解：B. 表面での化学反応の速さが成長速度を決めている(表面反応律速)ため

低温では表面での化学反応が遅く、反応の速さが成長速度を決めます(表面反応律速)。反応速度はアレニウスの式に従って温度に指数関数的に依存するため、成長速度も温度に強く依存し、ウエハ内の温度の均一性がそのまま膜厚の均一性になります。高温では反応が十分速くなり、原料ガスが表面に届く速さが成長速度を決める供給律速(拡散律速)になり、ガスの流れの均一性が重要になります。

SiCのエピタキシャル成長(CVD)の一般的な成長温度に最も近いものはどれか。

  1. A約600℃
  2. B約1,000℃
  3. C約1,500〜1,650℃
答えと解説を見る

正解：C. 約1,500〜1,650℃

SiCは結合が強く表面の原子が動きにくいため、良質なエピタキシャル層を得るには1,500〜1,650 ℃程度とシリコンより約500 ℃高い温度が必要です。原料にはシランやトリクロロシランと、プロパンなどの炭化水素を使い、CとSiの比で不純物の取り込みを制御します。この温度に耐えるため、反応炉の部材にはSiCやTaCで被覆した黒鉛が使われます。

よくある質問

CVD と PVD の違いは何ですか?

CVD はウエハ表面での原料ガスの化学反応で膜をつくり、スパッタリングなどの PVD は反応を伴わずに固体の原料から原子を物理的に移して膜をつくります。一般に CVD のほうが深いパターンでの段差被覆性がはるかに優れています。

PECVD が LPCVD より低温で成膜できるのはなぜですか?

PECVD ではプラズマ中の高エネルギー電子が原料の分解に必要なエネルギーを与えるため、熱 CVD である LPCVD の 600〜800 ℃ に対して、ウエハ温度は約 300〜400 ℃ で済むからです。そのため、アルミや銅の配線形成後にも使えます。

CVD と ALD の違いは何ですか?

CVD は原料を同時に供給して連続的に膜を成長させますが、ALD は原料を交互にパルス供給し、1サイクルごとに自己制限的に約1原子層ずつ膜を加えます。ALD は遅いものの、ほぼ完全なコンフォーマリティと原子レベルの膜厚制御が得られます。
