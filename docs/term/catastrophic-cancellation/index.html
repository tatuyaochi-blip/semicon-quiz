桁落ちとは

けたおち

ほぼ等しい2つの数を引き算したとき、上位の桁が打ち消し合って有効な桁が大きく減る現象。もとの数に含まれていた丸め誤差の割合が相対的に大きくなる。計算式を変形して避ける。

「桁落ち」は、1分野の2問の練習問題に出てきます(計算機算術など)。

この用語の分野: 計算機算術

原因は引き算そのものではない

意外なことに、近い値どうしの浮動小数点数の引き算は、通常は誤差なしで行えます。x と y の比が2倍以内なら x − y は正確に表現でき、ハードウェアは丸めずにその値を返します(ステルベンツの補題として知られる結果です)。害をもたらすのは、それ以前の丸め、測定、変換によってオペランドにすでに含まれている誤差です。上位の桁が打ち消し合うと、小さな絶対誤差はそのまま残る一方で結果自体はごく小さくなるので、相対誤差が拡大します。桁落ちは新しい誤差を生むのではなく、もとからあった誤差をあらわにするのです。

誤差はどれだけ拡大するか

a と b がそれぞれ約 e の相対誤差を持つとき、a − b の誤差はおよそ e に (|a| + |b|) / |a − b| を掛けた大きさになります。したがって上位6桁の有効数字が一致する数どうしを引くと、相対誤差は約100万倍に拡大し、doubleが持つ約16桁の10進有効数字のうち6桁を失います。オペランドがすべての桁で一致していれば、結果は単なるノイズか、ちょうど0になることもあります。この比は引き算の条件数であり、影響の大きさが形式だけでは決まらず、入力どうしがどれだけ近いかで決まることを示しています。

定番の式変形

対策は、近い値どうしの引き算を避けるように式を変形することです。有理化により、√(x + 1) − √x は 1 / (√(x + 1) + √x) になります。2次方程式の解の公式では、b² が 4ac よりはるかに大きいとき、一方の解で桁落ちが起きます。もう一方の解を先に求め、解の積 c / a を最初の解で割って問題の解を得れば、これを避けられます。x が小さいとき 1 − cos x は 2 sin²(x / 2) に変形でき、数学ライブラリには0付近で exp(x) − 1 と log(1 + x) を正確に計算する expm1(x) と log1p(x) が用意されています。

桁落ちと情報落ちの違い

桁落ちと情報落ちは、浮動小数点で情報が失われる代表的な2つの現象で、混同されがちです。桁落ちはほぼ等しい数どうしを引き算したときに起き、結果に意味のある桁がわずかしか残らなくなります。情報落ちは大きさが大きく異なる数を足したときに起き、小さいほうのオペランドの下位の桁が仮数の末尾からこぼれ落ちます。たとえば倍精度では 1.0e16 + 1 がちょうど 1.0e16 になります。より幅の広い形式に移れば、どちらの問題も先送りにはできますが、なくなりはしません。なくすには計算の仕方を組み立て直す必要があります。

桁落ちの練習問題に挑戦

x が非常に大きいとき、√(x + 1) − √x を浮動小数点で計算すると桁落ちが起こる。結果を精度よく求めるための書き換えとして正しいものはどれか。

  1. A1 ÷ (√(x + 1) + √x) として計算する
  2. B√(x + 1 − x) として計算する
  3. C√(x + 1) と √x をそれぞれ倍精度に変えてから、同じ式で引き算する
答えと解説を見る

正解：A. 1 ÷ (√(x + 1) + √x) として計算する

√(x + 1) と √x はほぼ等しいので、そのまま引くと上位の桁が打ち消し合います。分子と分母に √(x + 1) + √x を掛けると、(x + 1 − x) ÷ (√(x + 1) + √x) = 1 ÷ (√(x + 1) + √x) となり、近い数どうしの引き算がなくなって精度よく計算できます。√(x + 1 − x) は1となり、式として誤りです。倍精度にすると改善はしますが、xがさらに大きくなれば同じ問題が起こるので、根本の対策にはなりません。

よくある質問

ほぼ等しい浮動小数点数を引くと精度が落ちるのはなぜですか?

一致している上位の桁が打ち消し合い、主に下位の桁からなる小さな結果が残るからです。下位の桁はもともと丸め誤差で汚れているので、絶対誤差は変わらないまま値だけが小さくなり、相対誤差が急に大きくなります。

floatをdoubleに変えれば桁落ちは解決しますか?

失ってもよい桁が増えるので改善はしますが、オペランドがさらに近ければ同じ桁落ちが再び起きます。本当の解決策は、引き算を避けるように式を書き換えることです。

2次方程式の解の公式で桁落ちを避けるにはどうしますか?

−b と平方根の項が同じ符号になり、打ち消し合わずに足し合わされるほうの解を先に計算します。もう一方の解は、解の積が c / a になる関係から求めます。
