マスフローコントローラ(MFC)とは

ますふろーこんとろーら

成膜やエッチングの装置で、ガスの質量流量を精密に測りながら、設定した値に一定に制御する機器。

「マスフローコントローラ(MFC)」は、1分野の2問の練習問題に出てきます(プロセス材料(ガス・薬液)など)。

この用語の分野: プロセス材料(ガス・薬液)

熱式MFCの流量測定の仕組み

最も一般的な熱式では、流入したガスを分流します。一定のわずかな割合が加熱された細いセンサー管を通り、残りは分流比を一定に保つよう設計されたバイパス部を通ります。センサー管の上流側と下流側に置いた温度センサーが、流れるガスによって下流へ運ばれる熱の量を検出します。この温度差は、質量流量とガスの比熱の積に比例します。電子回路が測定した流量を設定値と比較し、ソレノイドやピエゾ素子による比例制御弁を動かしてフィードバック制御を行います。整定時間は一般に約1秒以内です。

質量流量を使う理由とsccmの意味

反応速度は、配管内がたまたまどんな圧力や温度であるかに左右される体積ではなく、1秒あたりに届く分子の数で決まります。質量流量を測れば、供給量がこうした変化の影響を受けません。流量は一般にsccm(standard cubic centimeters per minute)で表します。これはガスが基準の温度と圧力、一般には 0 ℃、1 atmで占める体積を1分あたりの cm³で表したもので、1 sccmは1分あたり一定の分子数に対応します。大きな流量には、標準状態換算の L/minであるslmを使います。

ガス補正とレンジの制約

熱式センサーは熱容量に応答するため、窒素で校正したMFCをほかのガスに使うと、ガス換算係数(コンバージョンファクター)をかけない限り正しい値を示しません。しかも反応性ガスや特殊なガス、混合ガスでは換算係数の精度が落ちるため、プロセス用のMFCは実際に使うガスで校正することがよくあります。また、フルスケールの下限付近では精度が低下します。ジボランやホスフィンのようなごく少量のドーパントガスを水素や窒素で%やppmのレベルまで希釈して使うのはこのためで、MFCを精度のよい範囲で動作させられるうえ、漏洩時の危険も減らせます。

主な使用場所

CVD、ALD、エッチング、エピタキシャル成長、拡散炉などの装置では、ガスラインごとに専用のMFCが付いています。成膜速度、膜組成、均一性、エッチング選択比が流量比に直接左右されるためです。応答の速さやガス種に影響されにくいことが求められる場面では、校正済みのオリフィス前後の圧力から流量を求める圧力式MFCも使われます。測定だけを行うマスフローメーターや、MFCがガス流量を決めるのに対してスロットルバルブでチャンバー圧力を決める圧力コントローラと混同しないよう注意が必要です。

マスフローコントローラ(MFC)の練習問題に挑戦

成膜やエッチングの装置で、ガスの流量を精密に測りながら一定に制御する機器はどれか。

  1. Aマスフローコントローラ(MFC)
  2. B圧力計だけ
  3. Cガスボンベのバルブ
答えと解説を見る

正解：A. マスフローコントローラ(MFC)

マスフローコントローラは、ガスの質量流量をセンサで測り、内蔵の弁を調整して設定値に保つ機器です。代表的な熱式では、細管を流れるガスが運ぶ熱量の差から流量を求めます。流量の単位にはsccm(標準状態での1分あたりのcm³)がよく使われます。成膜速度や膜の組成、エッチングの選択比は流量で大きく変わるため、各ガスラインにMFCが置かれます。

ジボランやホスフィンなどのドーパント用のガスが、多くの場合、水素や窒素などで低い濃度に薄めた状態で供給される主な理由はどれか。

  1. Aガスの色を変えるため
  2. B必要な添加量はごく少なく、流量を精密に制御しやすくするとともに、毒性や反応性のリスクを下げるため
  3. Cにおいを強くするため
答えと解説を見る

正解：B. 必要な添加量はごく少なく、流量を精密に制御しやすくするとともに、毒性や反応性のリスクを下げるため

ドーパントの添加量はごく微量なので、純ガスのままでは流量が小さすぎてマスフローコントローラで精密に制御できません。水素や窒素で数%〜ppmレベルに薄めておくと、扱いやすい流量で必要な量を正確に送れます。希釈すれば漏えい時の濃度も下がり、毒性や自然発火の危険を減らせます。ジボランは純ガスだと室温でも徐々に分解するため、希釈は安定性の面でも役立ちます。

よくある質問

熱式マスフローコントローラの仕組みは?

ガスのわずかな割合を加熱したセンサー管に流し、上流と下流の温度センサーの温度差から質量流量を求めます。そのうえで制御弁が流量を設定値に合わせて調整します。

sccmとはどういう意味?

standard cubic centimeters per minuteの略で、ガスの流量を基準状態(一般に 0 ℃、1 atm)で占める体積に換算して表したものです。そのため、1分あたりに供給される分子数の尺度になります。

MFCにガス補正係数が必要なのはなぜ?

熱式MFCはガスが運ぶ熱量に応答し、その量はガスの熱容量によって変わるためです。窒素で校正したMFCを別のガスに使うときは補正が必要です。
