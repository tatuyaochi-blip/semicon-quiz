IDDQテストとは

あいでぃーでぃーきゅーてすと

CMOS回路が静止しているときの電源電流を測り、異常に大きい場合にブリッジ故障などの欠陥があると判定するテスト。

「IDDQテスト」は、1分野の1問の練習問題に出てきます(テスト・検査など)。

この用語の分野: テスト・検査

IDDQテストの原理

IDDQは、CMOS回路の電源に流れる電流(IDD)を、入力が変化しない静止状態(Quiescent)で測った値です。正常なCMOSの論理ゲートでは、静止状態ではpMOSとnMOSのどちらか一方が必ずオフになっているため、電源からグラウンドへの直接の電流の経路がなく、流れるのはわずかなリーク電流だけです。ところが、配線どうしの短絡(ブリッジ)やゲート酸化膜の欠陥、トランジスタが常にオンになる不良があると、静止時でも電源からグラウンドへ電流が流れます。IDDQテストは、この異常な電流を測って欠陥を見つけます。

テストの進め方

テストでは、回路の内部をいくつかの異なる状態に設定するパターンを順に与え、それぞれで動作が落ち着いてから電源電流を測ります。欠陥による電流は、その欠陥の両側に逆の論理値が設定されたときにだけ流れるため、多くのノードの組み合わせを活性化できるパターンを選びます。測った値があらかじめ決めたしきい値を超えたチップを不良と判定します。電流が落ち着くのを待ってから高い精度で測るため時間がかかり、測定するパターンの数は論理のテストよりずっと少なく絞り込みます。

IDDQテストの利点

IDDQテストの大きな利点は、論理の出力には現れない欠陥を見つけられることです。例えば、ブリッジで電流が流れていても、回路の論理値がたまたま正しく保たれる場合、出力を比べるだけのテストでは良品に見えます。また、ゲート酸化膜の弱い部分のように、今は動作しても使用中に故障に至るおそれのある潜在的な欠陥も、電流の増加として捉えられることがあります。少ないパターンで多くの欠陥を検出できるため、縮退故障のテストを補う方法として、信頼性を重視する製品で使われてきました。

微細化による限界と工夫

微細化とともに、トランジスタ1個あたりのオフ時のリーク電流が増え、トランジスタの数も増えたため、正常なチップでも静止時の電流が大きくなりました。チップごとのばらつきも大きく、欠陥による電流の増加分が正常な電流の中に埋もれて、一定のしきい値では区別しにくくなっています。そこで、パターンごとの電流の差(ΔIDDQ)を見る、同じウエハの近くのチップの値と比べる、電源を回路ブロックごとに分けて測る、といった工夫がとられています。それでも適用は難しくなっており、遅延故障のテストなどと組み合わせて使われます。

IDDQテストの練習問題に挑戦

論理の出力を期待値と比べるテストに加えて、IDDQテストを行う利点として正しいものはどれか。

  1. A配線どうしの短絡(ブリッジ)のように、静止時の電流は増えるが論理の出力はたまたま正しい欠陥も見つけられる
  2. B実際の動作周波数で、信号の伝わる遅れが大きすぎる不良を見つけられる
  3. Cテストパターンを1つも用意せずに、すべての欠陥を見つけられる
答えと解説を見る

正解：A. 配線どうしの短絡(ブリッジ)のように、静止時の電流は増えるが論理の出力はたまたま正しい欠陥も見つけられる

正常なCMOS回路は、静止状態ではpMOSとnMOSのどちらかがオフなので、電源からグラウンドへはリーク電流しか流れません。ブリッジやゲート酸化膜の欠陥があると、その両側に逆の論理値が設定されたときに静止時の電流が増えますが、論理の値がたまたま正しく保たれると、出力を比べるテストでは良品に見えます。IDDQテストはこの電流を測って欠陥を見つけ、使ううちに故障しうる潜在的な欠陥を捉えられることもあります。ただし微細化で正常なチップのリーク電流が大きくなり、欠陥による増加分との区別が難しくなっています。

よくある質問

IDDQのQは何の意味ですか?

Quiescent(静止状態)の頭文字です。IDDはCMOS回路の電源電流を表し、IDDQは入力が変化しない静止状態で測った電源電流を意味します。

IDDQテストで見つけやすい欠陥は?

配線どうしの短絡(ブリッジ)、ゲート酸化膜の欠陥、トランジスタが常にオンになる不良など、静止時に電源からグラウンドへ電流の経路ができる欠陥です。論理の出力に現れないブリッジでも、電流の増加として検出できる場合があります。

IDDQテストが使いにくくなったのはなぜですか?

微細化でトランジスタのリーク電流が増え、正常なチップでも静止時の電流が大きく、ばらつくようになったためです。欠陥による電流の増加分が正常な電流に埋もれて、区別しにくくなりました。そのため、パターン間の電流の差を見るなどの工夫をし、ほかのテストと組み合わせて使います。
