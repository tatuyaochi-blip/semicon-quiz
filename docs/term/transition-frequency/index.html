トランジション周波数とは

とらんじしょんしゅうはすう

エミッタ接地の電流増幅率が1まで下がる周波数で、fTと書く。トランジスタの高周波性能の代表的な指標。

「トランジション周波数」は、2分野の3問の練習問題に出てきます(バイポーラトランジスタ, 化合物半導体など)。

この用語の分野: バイポーラトランジスタ

fTの定義と測り方

トランジション周波数fTは、出力を交流的に短絡したときのエミッタ接地の電流増幅率|hfe|が1(0 dB)になる周波数です。電流増幅率は低い周波数ではほぼ一定のβ0ですが、βカットオフ周波数fβを超えると周波数に反比例して(−20 dB/decで)下がります。この領域では|hfe|×fがほぼ一定になるため、fT ≈ β0·fβの関係があり、fTは電流利得の利得帯域幅積ともいえます。実際には、fTより低い周波数fで|hfe|を測り、fT = |hfe|×fとして求めるか、Sパラメータから求めた電流利得を−20 dB/decの傾きで外挿して求めるのが一般的です。

fTを決める遅延時間

fTの逆数は、信号がエミッタからコレクタまで伝わる時間の合計に対応し、おおまかに 1/(2πfT) ≈ (Cje + Cμ)/gm + τB + τC と表されます。第1項は接合容量を充電する時間、τBは少数キャリアがベースを横切る時間で、一様にドーピングしたベースでは幅WBと拡散係数Dnを使って約WB²/(2Dn)です。τCはコレクタの空乏層を走る時間です。小信号等価回路では fT ≈ gm/(2π(Cπ + Cμ)) と書け、Cπにはベースの拡散容量も含まれます。ベースを薄くしたり、SiGe HBTでGe濃度に傾斜をつけて電子を加速したりするのは、主にτBを短くするためです。

コレクタ電流とfTの関係

fTはバイアス条件で大きく変わります。gmはコレクタ電流ICに比例するので、電流が小さい領域では容量の充電時間(Cje + Cμ)/gmが支配的で、ICを増やすほどfTは上がります。しかし電流密度が高くなりすぎると、コレクタを流れる電子の電荷が空乏層の電界を打ち消し、実効的なベースがコレクタ側へ広がるカーク効果(ベースプッシュアウト)が起こってτBが急に長くなり、fTは下がります。そのためfTはあるICでピークをもちます。データシートのfTは決まったICとVCEで規定されているので、回路の動作点が違えば実際のfTも変わる点に注意が必要です。

fmaxとの違いとMOSFETのfT

fTは電流利得の指標で、ベース抵抗rbの影響をほとんど含みません。電力利得が1になる最大発振周波数fmaxはおおよそ √(fT/(8π·rb·Cμ)) で、rbやCμが大きいと低くなるため、増幅器や発振器の実力はfmaxも合わせて判断します。fTの定義はMOSFETやHEMTにも使われ、fT ≈ gm/(2π(Cgs + Cgd)) です。Cgdを無視した長チャネル近似ではfT ≈ 3μ(VGS − Vth)/(4πL²)とゲート長Lの2乗に反比例し、速度飽和が強い短チャネルではおよそvsat/(2πL)になるため、微細化とともに高くなります。

トランジション周波数の練習問題に挑戦

バイポーラトランジスタのトランジション周波数fTの意味として正しいものはどれか。

  1. A電源の周波数
  2. Bエミッタ接地の電流増幅率が1まで低下する周波数
  3. C回路が発振する周波数
答えと解説を見る

正解：B. エミッタ接地の電流増幅率が1まで低下する周波数

電流増幅率は周波数が高くなると、主にベースを通る時間と接合容量の充放電のために低下します。エミッタ接地の電流増幅率が1になる周波数がトランジション周波数fTで、おおよそ fT ≈ gm/(2π(Cπ + Cμ)) です。高周波性能の指標で、汎用の小信号トランジスタで数百MHz、SiGe HBTでは300 GHzを超えるものもあります。電力利得が1になる最大発振周波数fmaxも併せて使われます。

よくある質問

トランジション周波数とは簡単にいうと何ですか?

エミッタ接地の電流増幅率が1まで下がる周波数で、トランジスタが電流を増幅できる上限の目安です。fTと書き、電流利得の遮断周波数や単位利得周波数と呼ばれることもあります。値が大きいほど高い周波数まで増幅できます。

fTと利得帯域幅積は同じですか?

βカットオフ周波数fβより上では電流増幅率が周波数に反比例して下がるため、|hfe|×fがほぼ一定になり、その値がfTです。この意味でfTは電流利得の利得帯域幅積にあたり、fT ≈ β0·fβです。ただし、オペアンプなど回路全体の利得帯域幅積とは別の量です。

fTとfmaxはどう違いますか?

fTは電流利得が1になる周波数、fmaxは電力利得が1になる周波数です。fmaxはベース抵抗やコレクタ-ベース間の容量の影響を強く受け、素子の構造によってfTより高くも低くもなります。
