NATとは

なっと

Network Address Translation(ネットワークアドレス変換)の略。ルータを通るパケットのIPアドレスを書き換える技術。ポート番号も書き換えて1つのグローバルアドレスを多くの端末で共有するものをNAPT(IPマスカレード)と呼ぶ。

「NAT」は、1分野の2問の練習問題に出てきます(ネットワークの基礎など)。

この用語の分野: ネットワークの基礎

NATとNAPTのしくみ

基本のNATは、内側のプライベートアドレスと外側のグローバルアドレスを1対1で書き換えます。家庭や会社で広く使われるNAPTは、IPアドレスに加えて送信元のポート番号も書き換え、「内側のアドレスとポート」と「外側のポート」の対応を変換表に記録します。戻ってきたパケットは変換表を見て宛先を書き戻し、正しい端末に届けます。これにより、多くの端末が1つのグローバルアドレスを同時に使えます。

IPv4アドレスの不足とNAT

IPv4アドレスは32ビットで約43億個しかなく、インターネットの普及で新しく配れるアドレスが足りなくなりました。NAPTは、組織の中ではプライベートアドレスを使い、外に出るときだけ少数のグローバルアドレスを共有することで、この不足を和らげてきました。通信事業者の側でさらにNAPTを重ねるキャリアグレードNAT(CGN)も使われています。IPv6では十分なアドレスがあるため、アドレスの節約のためのNATは基本的に必要ありません。

NATの副作用

外から始まる通信は変換表に対応がないので、そのままでは内側の端末に届きません。これは結果的に外からの接続を防ぐ効果をもちますが、ファイアウォールの代わりにはなりません。内側でサーバを公開するにはポート転送の設定が必要で、端末どうしが直接つながるオンラインゲームや通話のアプリケーションでは、NATを越えるための工夫(NATトラバーサル)が必要になります。

NATの練習問題に挑戦

家庭のブロードバンドルータは、NAT(ネットワークアドレス変換)の一種であるNAPT(IPマスカレード)を行っている。NAPTによって可能になることとして正しいものはどれか。

  1. A家庭内の複数の端末が、ポート番号で区別されることで、1つのグローバルIPアドレスを同時に共有してインターネットと通信できる
  2. B家庭内の端末とインターネットの間の通信が暗号化され、途中で盗み見られなくなる
  3. C家庭内の端末それぞれに、別々のグローバルIPアドレスが自動的に割り当てられる
答えと解説を見る

正解：A. 家庭内の複数の端末が、ポート番号で区別されることで、1つのグローバルIPアドレスを同時に共有してインターネットと通信できる

NAT(ネットワークアドレス変換)は、ルータを通るパケットの送信元や宛先のIPアドレスを書き換える技術です。NAPTは、IPアドレスに加えてポート番号も書き換え、「内側のアドレスとポート」と「外側のポート」の対応を変換表に記録します。そのため、プライベートアドレスを使う複数の端末が、ルータのもつ1つのグローバルアドレスを同時に使えます。戻ってきたパケットは、変換表を見て正しい端末に届けられます。アドレスを書き換えるだけで暗号化はしません。また、外から始まる通信は変換表にないため、そのままでは内側の端末に届かず、内側でサーバを公開するにはポート転送などの設定が必要です。

よくある質問

NATとNAPTの違いは何ですか?

NATはIPアドレスだけを書き換え、基本的に内側と外側のアドレスを1対1で対応させます。NAPTはポート番号も書き換えるので、1つのグローバルアドレスを多くの端末で同時に共有できます。家庭用のルータが行っているのはNAPTです。

NATがあればファイアウォールは不要ですか?

不要にはなりません。NATは外から始まる接続を結果的に通さないことが多いものの、通信を選別する規則を設定する機能ではなく、ポート転送を設定した通信や内側から始めた通信は守れません。
