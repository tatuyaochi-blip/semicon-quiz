割り込みベクタテーブルとは

わりこみべくたてーぶる

割り込みや例外の種類ごとに、対応する割り込みハンドラの先頭アドレスを並べた表。CPUは原因の番号からこの表を引いて、処理の開始位置を決める。

この用語の分野: OSとハードウェア

解説の中の「割り込みベクタテーブル」

  • 割り込みや例外が起きると、CPUはその原因に対応する番号(ベクタ番号)を得て、割り込みベクタテーブルからハンドラの先頭アドレスを読み、そこへ処理を移します。

    割り込みベクタテーブルの役割として正しいものはどれか。

  • 割り込みを受け付けると、CPUは次に実行するはずだった命令のアドレスと動作モードなどの状態を保存し、割り込みベクタテーブルなどで決まる割り込みハンドラへ移ります。

    CPUが割り込みを受け付けたときの一般的な処理の流れとして正しいものはどれか。

「割り込みベクタテーブル」が出てくる問題(2問)

  1. 割り込みベクタテーブルの役割として正しいものはどれか。
  2. CPUが割り込みを受け付けたときの一般的な処理の流れとして正しいものはどれか。
