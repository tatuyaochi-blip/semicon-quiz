ラジカルとは

らじかる

不対電子をもち、化学的に非常に反応しやすい中性の原子や分子。プラズマ中にイオンよりはるかに多く存在し、化学的なエッチングや成膜を担う。

「ラジカル」は、7分野の21問の練習問題に出てきます(エッチング, 酸化・拡散, イオン注入など)。

この用語の分野: エッチング

プラズマがラジカルを生み出す仕組み

プロセス用のプラズマでは、高エネルギーの電子が原料ガスの分子に衝突します。一部の衝突は分子を電離させますが、それより多くの衝突は分子を中性の断片に分解するだけです。解離に必要なエネルギーが電離より小さいためで、たとえばCF4からはCF3とF、O2からは原子状のOが生じます。不対電子を持つこれらの断片がラジカルです。電荷を持たないためプラズマのシースによって壁へ引き寄せられることがなく、イオンより長く生き残るので、その密度は一般にイオン密度より2〜3桁以上高くなります。

エッチングにおけるラジカルとイオンの役割

ラジカルはあらゆる方向からウエハに到達し、相手となる表面と自発的に反応します。たとえばフッ素ラジカルはシリコンを揮発性のSiF4に変えます。この化学反応だけなら等方的で、選択性も非常に高くなります。イオンは数こそ少ないものの、シースで垂直方向に加速されて数十〜数百電子ボルトのエネルギーで水平面に衝突し、そこでの反応を促進し、トレンチ底の保護膜を除去します。異方性エッチングはこの役割分担に支えられています。ラジカルが化学反応の大部分を担い、イオンが反応の最も速く進む場所を決め、側壁保護膜が垂直な壁を守るのです。

ラジカルだけを使うプロセス

意図的にイオンを排除する工程もあります。ダウンストリームプラズマやリモートプラズマでは、ウエハから離れた場所でプラズマを発生させるので、イオンは到達する前に再結合し、寿命の長いラジカルだけが表面に届きます。これにより、ダメージのないレジストのアッシングや等方的な洗浄が可能になります。ラジカル酸化は酸素ラジカルを使い、約400〜600 °Cで良質な酸化膜を成長させる方法で、結晶方位への依存性も小さいため、FinFETのフィンや3D NANDの構造、熱履歴の制約が厳しい工程に適しています。

ラジカルの供給量の制御

ラジカル密度は、ガスの化学組成、圧力、RF電力、ラジカルが消費される速さによって決まります。誘導結合プラズマ(ICP)源を使えば、プラズマ密度、ひいてはラジカルとイオンの供給量を、イオンエネルギーとは独立に設定できます。パルスプラズマを使うと、ラジカル種の構成を変えられます。ラジカルの消費はローディング効果につながり、ウエハ上のエッチングされる面積が大きいとラジカルが枯渇してエッチングレートが下がります。深く狭いパターンではラジカルがホールの底まで拡散しなければならないため、アスペクト比が高くなるほどエッチングレートが下がることがよくあります。

ラジカルの練習問題に挑戦

酸素ラジカルを使うラジカル酸化の特徴として正しいものはどれか。

  1. A比較的低い温度でも良質な酸化膜をつくれ、面方位による酸化速度の差も小さい
  2. B必ず1200 ℃以上の高温が必要である
  3. C酸化膜の厚さが面方位によって大きく異なる
答えと解説を見る

正解：A. 比較的低い温度でも良質な酸化膜をつくれ、面方位による酸化速度の差も小さい

プラズマなどで生成した酸素ラジカルは反応性が高いため、400〜600 ℃程度の比較的低い温度でも、熱酸化に近い良質な酸化膜を形成できます。通常の熱酸化と比べて面方位による酸化速度の差や、角の部分の酸化の遅れが小さく、窒化膜も酸化できるため、FinFETのフィンや3D NANDのような立体的な構造や、熱予算の厳しい工程の酸化に使われています。

プラズマで生成したラジカルだけをウエハに供給するダウンフロー型エッチングの特徴として正しいものはどれか。

  1. Aイオン衝撃が強いため、異方性が非常に高い
  2. Bイオン衝撃がほとんどないため、ダメージが少なく等方的にエッチングできる
  3. C薬液を使ってエッチングする
答えと解説を見る

正解：B. イオン衝撃がほとんどないため、ダメージが少なく等方的にエッチングできる

ダウンフロー型(リモートプラズマ型)では、プラズマを発生させる場所とウエハを離し、途中でイオンや電子が再結合して失われるため、寿命の長い中性のラジカルだけがウエハに届きます。イオンが当たらずプラズマからの紫外線もさえぎられるためダメージが少なく、等方的にエッチングできます。レジストの除去、ダメージを嫌う工程での膜の除去、ナノシートの間のSiGeの除去などに使われます。

よくある質問

プラズマ中のラジカルとイオンの違いは?

ラジカルは不対電子を持つ電気的に中性の原子や分子で、化学的に反応しやすい一方、電界で向きを制御されることはありません。イオンは電荷を持ち、シースでウエハに向かって加速されるので、方向性のある衝撃を与えます。

エッチング用プラズマでラジカルがイオンより多いのはなぜですか?

分子を分解するのに必要な電子のエネルギーは電離より小さいため、解離のほうが頻繁に起こるからです。さらにラジカルは壁に引き寄せられないので寿命が長く、イオンよりはるかに高い密度まで蓄積します。

ラジカルによるエッチングは等方性ですか?

中性のラジカルはあらゆる方向から到達するため、ラジカルだけによるエッチングは等方性です。方向性は、イオン衝撃と側壁保護膜の組み合わせによって生まれます。
