DVFS(動的電圧・周波数制御)とは

でぃーぶいえふえす

処理の負荷に応じて、動作周波数と電源電圧を動的に変える技術。動的消費電力は電圧の2乗に比例するため、軽い処理のときに電圧を下げると大きく省電力になる。

「DVFS(動的電圧・周波数制御)」は、2分野の6問の練習問題に出てきます(電力管理(ソフトウェア制御), CPU・アーキテクチャなど)。

この用語の分野: CPU・アーキテクチャ

DVFS(動的電圧・周波数制御)の練習問題に挑戦

DVFSで、電源電圧を周波数に比例して下げられるとする。周波数を半分にしたとき、動的な電力と、決まった量の計算に使う動的なエネルギーはおよそどうなるか。

  1. A電力は8分の1、エネルギーは4分の1になる
  2. B電力もエネルギーも半分になる
  3. C電力は4分の1、エネルギーは変わらない
答えと解説を見る

正解：A. 電力は8分の1、エネルギーは4分の1になる

電力はV²fに比例するので、Vとfがともに半分なら(1/2)²×1/2=1/8になります。計算にかかる時間は2倍になるので、エネルギーは1/8×2=1/4です。1回の切り替えのエネルギーがCV²に比例するので、エネルギーは電圧の2乗で決まると考えても同じ結果になります。実際には電圧を下げられる範囲に限りがあり、静的な電力もあるので、ここまで理想的には減りません。

解説の中の「DVFS(動的電圧・周波数制御)」

  • それでも周波数を下げて電圧も下げれば電力は3乗近くで減るため、DVFSで処理が軽いときに電圧と周波数を下げるのが最も効果的な省電力手段です。

    CMOS回路で、ほかの条件を変えずに電源電圧だけを半分にすると、動的消費電力はどうなるか。

  • DVFSは、処理が軽いときは周波数と電源電圧を下げ、重いときは上げる技術です。

    CPUの消費電力を減らすため、負荷に応じて動作周波数と電源電圧を動的に変える技術はどれか。

  • OSやCPUの中の電源の管理の回路は、負荷に合わせてP-stateを切り替えます(DVFS)。

    CPUのP-state(Pステート)の説明として正しいものはどれか。

  • PMICは、スイッチングレギュレータやLDOを多数まとめた部品で、電池の電圧から必要な電圧を効率よく作り、SoCの指示に従ってDVFSのための電圧の変更や、ブロックごとの電源のオンとオフ、決められた順番での電源の投入を行います。

    スマートフォンなどで使われるPMIC(電源管理IC)の役割として正しいものはどれか。

  • ただし電圧を下げると回路は遅くなるので、必要な速さを保てる範囲で下げる必要があり、それを負荷に応じて行うのがDVFSです。

    電源電圧だけを10%下げたとき(ほかの条件は同じとする)、動的消費電力はおよそ何%減るか。

「DVFS(動的電圧・周波数制御)」が出てくる問題(6問)

  1. DVFSで、電源電圧を周波数に比例して下げられるとする。周波数を半分にしたとき、動的な電力と、決まった量の計算に使う動的なエネルギーはおよそどうなるか。
  2. CMOS回路で、ほかの条件を変えずに電源電圧だけを半分にすると、動的消費電力はどうなるか。
  3. CPUの消費電力を減らすため、負荷に応じて動作周波数と電源電圧を動的に変える技術はどれか。
  4. CPUのP-state(Pステート)の説明として正しいものはどれか。
  5. スマートフォンなどで使われるPMIC(電源管理IC)の役割として正しいものはどれか。
  6. 電源電圧だけを10%下げたとき(ほかの条件は同じとする)、動的消費電力はおよそ何%減るか。
