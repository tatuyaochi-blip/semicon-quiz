DNL(微分非直線性)とは

でぃーえぬえる

ADコンバータの隣り合うコードの間のステップ幅が、理想的な1 LSBからどれだけずれているかを表す誤差。−1 LSBに達するとミッシングコードになる。

この用語の分野: AD/DA変換

解説の中の「DNL(微分非直線性)」

  • DNLは、各コードに対応する入力の幅(ステップ幅)が理想の1 LSBからどれだけずれているかで、例えば幅が1.5 LSBならDNL = +0.5 LSB です。

    ADコンバータの微分非直線性(DNL)の説明として正しいものはどれか。

  • DNLが −1 LSB以下になったコードは、対応する入力の幅がなくなり出力に現れません。

    入力を変化させても、ある出力コードが一度も現れないADコンバータの不具合を何と呼ぶか。

  • 上位ビットを同じ重みの電流源の個数で表す温度計符号を使うとグリッチやDNLを抑えられ、通信機器や波形発生器の高速DACに使われています。

    高速なDAコンバータで多く使われる電流ステアリング型の特徴として正しいものはどれか。

「DNL(微分非直線性)」が出てくる問題(7問)

  1. ADコンバータの微分非直線性(DNL)の説明として正しいものはどれか。
  2. 入力を変化させても、ある出力コードが一度も現れないADコンバータの不具合を何と呼ぶか。
  3. 高速なDAコンバータで多く使われる電流ステアリング型の特徴として正しいものはどれか。
  4. ADコンバータの入出力特性で、入力が0のときに出力が0からずれている誤差を何と呼ぶか。
  5. ADコンバータの積分非直線性(INL)の説明として正しいものはどれか。
  6. DAコンバータが「単調性をもつ」とはどういう意味か。
  7. ADコンバータのテストで、ゆっくり変化する正弦波などを入力して、各出力コードが現れる回数(ヒストグラム)を数える主な目的はどれか。
