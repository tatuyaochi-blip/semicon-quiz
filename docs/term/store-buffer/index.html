ストアバッファとは

すとあばっふぁ

コアが書き込みを一時的にためておく小さなバッファ。書き込みの完了を待たずに次の命令へ進めるが、ほかのコアからは書き込みが遅れて見える。

この用語の分野: マルチコアと同期

解説の中の「ストアバッファ」

  • CPUは性能のために、書き込みをストアバッファにためたり、読み出しを先に行ったりして、メモリ操作の順番を入れ替えることがあります。

    メモリ一貫性モデル(メモリコンシステンシモデル)が定めているものはどれか。

  • プログラマにとって最も分かりやすいモデルですが、ハードウェアがストアバッファなどで順番を入れ替える最適化を大きく制限するので、実際の多くのCPUはもっと緩いモデルを採用しています。

    逐次一貫性(シーケンシャルコンシステンシ)の説明として正しいものはどれか。

「ストアバッファ」が出てくる問題(4問)

  1. メモリ一貫性モデル(メモリコンシステンシモデル)が定めているものはどれか。
  2. 逐次一貫性(シーケンシャルコンシステンシ)の説明として正しいものはどれか。
  3. 上の2つのスレッドを別々のコアで同時に実行する(コンパイラによる並べ替えはないとする)。逐次一貫性では起こらないが、x86などの実際のCPUでは起こりうる結果はどれか。
  4. x86のメモリ一貫性モデル(TSO、トータルストアオーダー)の特徴として正しいものはどれか。
