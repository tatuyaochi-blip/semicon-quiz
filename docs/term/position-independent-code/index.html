位置独立コードとは

いちどくりつこーど

メモリのどの番地に読み込んでも、コードを書き換えずに動く機械語。PICとも呼ぶ。PC相対の参照やGOTを使い、共有ライブラリやPIEで使われる。

この用語の分野: リンカ・ローダと実行形式

解説の中の「位置独立コード」

  • 位置独立コードでは、関数やデータを固定の番地ではなく、PCからの距離や、番地をまとめた表(GOT)を通して参照します。

    位置独立コード(PIC)の説明として正しいものはどれか。

  • これは共有ライブラリなどで使う位置独立コード(PIC)の土台になります。

    分岐やジャンプにPC相対アドレッシングを使うことの利点として正しいものはどれか。

  • これにより、プログラムをどこに読み込んでも動く位置独立コードで、遠くの関数を呼んだりグローバル変数を読んだりできます。

    RISC-Vのauipc命令(add upper immediate to PC)の動作として正しいものはどれか。

「位置独立コード」が出てくる問題(5問)

  1. 位置独立コード(PIC)の説明として正しいものはどれか。
  2. 分岐やジャンプにPC相対アドレッシングを使うことの利点として正しいものはどれか。
  3. RISC-Vのauipc命令(add upper immediate to PC)の動作として正しいものはどれか。
  4. 共有ライブラリで使われるGOT(グローバルオフセットテーブル)の役割として正しいものはどれか。
  5. 実行ファイルをPIE(位置独立実行ファイル)として作る主な理由はどれか。
