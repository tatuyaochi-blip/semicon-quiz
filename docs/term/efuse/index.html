eFuseとは

いーひゅーず

細い配線を電流で切って1ビットずつ書き込む、一度しか書けない記憶。機器ごとの鍵や設定、ロールバック防止の番号の記録などに使う。

「eFuse」は、1分野の6問の練習問題に出てきます(ハードウェアセキュリティなど)。

この用語の分野: ハードウェアセキュリティ

eFuseの練習問題に挑戦

セキュアブートの「ルートオブトラスト(信頼の起点)」として、チップの中に置かれるものとして最も適切なものはどれか。

  1. A書き換えられないROMの起動コードと、署名を確かめるための公開鍵(またはそのハッシュ値)
  2. B誰でも書き換えられるフラッシュメモリの起動コード
  3. Cインターネットからダウンロードした最新のOS
答えと解説を見る

正解：A. 書き換えられないROMの起動コードと、署名を確かめるための公開鍵(またはそのハッシュ値)

信頼の鎖は、最初の確認をする部分が正しいことを前提にしています。そのため、チップの製造時に書き込まれ、後から変えられないマスクROMの起動コードと、署名の検証に使う公開鍵(容量を節約するためハッシュ値をeFuseに書くことも多い)をルートオブトラストにします。ここが書き換えられると、その後のすべての確認が意味を失います。

セキュアブートを備えた機器で、ロールバック防止(アンチロールバック)の仕組みが必要になる理由として正しいものはどれか。

  1. A新しい版のソフトウェアには署名がないから
  2. B古い版のソフトウェアは、起動に時間がかかるから
  3. C脆弱性のある古い版のソフトウェアも正しい署名を持つので、それに戻されると攻撃に使われるから
答えと解説を見る

正解：C. 脆弱性のある古い版のソフトウェアも正しい署名を持つので、それに戻されると攻撃に使われるから

開発元は過去にも正しく署名したソフトウェアを出しているので、署名の確認だけでは、脆弱性が見つかった古い版を入れ直されても起動してしまいます。そこで、ソフトウェアに版の番号を持たせ、チップのeFuseなど一度書くと戻せない記憶に「これより古い版は起動しない」という番号を記録します。更新のたびにこの番号を進めれば、古い版に戻されるのを防げます。

「eFuse」が出てくる問題(6問)

  1. セキュアブートの「ルートオブトラスト(信頼の起点)」として、チップの中に置かれるものとして最も適切なものはどれか。
  2. セキュアブートを備えた機器で、ロールバック防止(アンチロールバック)の仕組みが必要になる理由として正しいものはどれか。
  3. 鍵の保管にPUFを使う利点として正しいものはどれか。
  4. 製品として出荷する機器で、JTAGなどのデバッグ用のポートを無効にしたり、認証が必要なようにしたりする理由として正しいものはどれか。
  5. チップの中に鍵を書き込んで保存する方法として、一般に使われているものはどれか。
  6. 多数の機器を製造するとき、すべての機器に同じ鍵を入れずに、機器ごとに違う鍵を持たせる理由として正しいものはどれか。
