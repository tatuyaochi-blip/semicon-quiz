ワンホット符号化とは

わんほっとふごうか

状態機械の状態ごとに1つのフリップフロップを割り当て、常に1つだけを1にする符号化。論理が簡単で速くなりやすく、FPGAでよく使われる。

「ワンホット符号化」は、1分野の2問の練習問題に出てきます(ハードウェア記述言語と検証など)。

ワンホットによる状態符号化の仕組み

有限状態機械(ステートマシン)のワンホット符号化では、状態ごとに専用のフリップフロップを割り当て、どの時点でもちょうど1個のフリップフロップだけが1を保持します。4つの状態は0001、0010、0100、1000になります。ある状態にいるかどうかは1ビットを見るだけでわかるので、状態に依存する出力は、フリップフロップ1個そのものか、数個の小さなORで済むことが多くなります。各フリップフロップの次状態入力は、その状態に入る遷移の条件それぞれを遷移元の状態ビットとANDし、それらをORしたものになるため、論理段数が浅く保たれ、状態機械を高速にできます。

ワンホットとバイナリ符号化の違い

バイナリ符号化は状態に番号を振るもので、必要なフリップフロップは log2 N の切り上げ個だけです。3状態ならバイナリでは2個に収まりますが、ワンホットでは3個必要で、16状態ならバイナリの4個に対してワンホットは16個です。バイナリ符号化の代償はデコード論理が広くなることで、状態を判別するにはすべての状態ビットを比較しなければなりません。3つ目の選択肢であるグレイコード符号化は、頻繁に起こる遷移で1ビットだけ変わるように符号を割り当て、スイッチングの活動を減らします。フリップフロップが少ない設計や状態数が多い設計にはバイナリが、フリップフロップに余裕があり速さと単純さを重視するときはワンホットが向いています。

FPGAで好まれる理由

FPGAの論理ブロックは、小さなルックアップテーブル(LUT)1つに1個以上のフリップフロップを組み合わせた構造なので、レジスタは豊富にある一方、入力の多い論理関数は複数段のLUTに分割しなければなりません。ワンホット符号化はこの構造によく合います。各状態ビットの次状態関数はたいてい少数の入力しか含まず、1個のLUTに収まるため、クリティカルパスが短くなります。論理合成ツールは一般にステートマシンを検出して符号化を自動的に選び、小・中規模の状態機械ではワンホットを選ぶことが多いですが、設計者が指定で上書きすることもできます。フリップフロップの面積コストが大きいASICでは、バイナリなどのコンパクトな符号化のほうが一般的です。

不正な状態と復帰

N個のフリップフロップで表せる2^N通りのパターンのうち、ワンホットが使うのはN通りだけなので、すべて0のパターンや複数ビットが1のパターンは不正な状態です。ノイズ、グリッチ、放射線によるビット反転で状態機械がそのどれかに入ると、止まったり予測できない動作をしたりすることがあります。バイナリ符号化にも、3状態の状態機械での11のように未使用の符号があり、同じ問題があります。そのため堅牢な設計では、想定外の状態を既知の状態に戻すデフォルトの分岐を定義します。論理合成ツールには、この復帰用の論理を最適化で削除せずに残すセーフステートマシンのオプションがあります。

ワンホット符号化の練習問題に挑戦

状態機械の状態の符号化で、ワンホット符号化の特徴として正しいものはどれか。

  1. A状態を2進数で表し、フリップフロップの数を最も少なくする
  2. Bすべてのフリップフロップが常に1になる
  3. C状態の数だけフリップフロップを使い、常に1つだけが1になるので、次の状態や出力の論理が簡単で速くなりやすい
答えと解説を見る

正解：C. 状態の数だけフリップフロップを使い、常に1つだけが1になるので、次の状態や出力の論理が簡単で速くなりやすい

ワンホット符号化では、例えば4つの状態を0001、0010、0100、1000のように表し、各状態に1つのフリップフロップを割り当てます。フリップフロップは増えますが、ある状態にいるかどうかは1ビットを見るだけで分かるので、次の状態や出力を決める論理が浅く速くなります。フリップフロップが豊富なFPGAでよく使われ、フリップフロップの数を減らしたいときはバイナリ符号化を使います。

3つの状態を持つ状態機械で、状態を覚えるのに必要なフリップフロップの数の組み合わせとして正しいものはどれか(バイナリ符号化/ワンホット符号化)。

  1. A3個/2個
  2. B2個/3個
  3. C1個/3個
答えと解説を見る

正解：B. 2個/3個

バイナリ符号化では、状態を2進数の番号で表すので、3つの状態には00、01、10の2ビット(フリップフロップ2個)で足ります。ワンホット符号化では、状態ごとに1つのフリップフロップを使うので3個です。バイナリでは使わない11の符号が残るので、雑音などでそこに入ったときに正しい状態に戻れるよう、defaultで行き先を決めておくと安全です。

よくある質問

ワンホット符号化にはフリップフロップがいくつ必要ですか?

状態1つにつき1個なので、N状態の状態機械にはN個のフリップフロップが必要です。同じ状態機械をバイナリ符号化すれば、log2 N の切り上げ個で済みます。

ワンホットとバイナリの状態符号化の違いは?

ワンホットは状態ごとに1個のフリップフロップを使い1ビットだけを1にするもので、レジスタは増えますがデコード論理が単純で高速です。バイナリ符号化は状態番号を最少のフリップフロップに保存しますが、各状態をデコードするのにより大きな論理が必要です。

デジタル回路設計のワンホットと機械学習のワンホットは同じものですか?

考え方は同じで、ちょうど1つの要素だけが1のベクトルで集合の中の1つを表します。ハードウェアでは状態機械の現在の状態や選択信号を符号化し、機械学習ではカテゴリ値を数値ベクトルとして表します。
