割り込みとは

わりこみ

外部機器からの要求などに応じて、実行中の処理を一時的に中断し、対応する処理を優先して行うCPUの仕組み。終わると元の処理に戻る。

この用語の分野: CPU・アーキテクチャ

解説の中の「割り込み」

  • 割り込みは、入出力装置の完了通知やタイマーなど、実行中の命令とは関係のない外部の要因で、いつ起こるか決まっていない(非同期の)ものです。

    割り込みと例外の違いとして一般的な説明はどれか。

  • 割り込みを受け付けると、CPUは次に実行するはずだった命令のアドレスと動作モードなどの状態を保存し、割り込みベクタテーブルなどで決まる割り込みハンドラへ移ります。

    CPUが割り込みを受け付けたときの一般的な処理の流れとして正しいものはどれか。

  • 割り込みを禁止すると、共有するデータの更新を途中で割り込まれずに済みますが、その間に届いた割り込みは待たされます。

    重要な処理の途中で一時的に割り込みを禁止(マスク)するときの注意点として正しいものはどれか。

「割り込み」が出てくる問題(23問)

  1. 割り込みと例外の違いとして一般的な説明はどれか。
  2. CPUが割り込みを受け付けたときの一般的な処理の流れとして正しいものはどれか。
  3. 重要な処理の途中で一時的に割り込みを禁止(マスク)するときの注意点として正しいものはどれか。
  4. 装置の状態を、割り込みを使わずにCPUが繰り返し調べる方式(ポーリング)が有利になる場合はどれか。
  5. 割り込みや例外の処理を終えて元のプログラムに戻るとき、通常の関数の戻り命令ではなく、専用の復帰命令(RISC-Vのsret・mretなど)を使う理由はどれか。
  6. リアルタイム性が求められるシステムで、割り込みが発生してからハンドラが動き出すまでの時間(割り込み遅延)を大きくしてしまう要因として最も適切なものはどれか。
  7. 2入力ORゲートの出力が0になるのはどのときか。
  8. 複数の入力が同時に1になったとき、最も優先度の高い入力の番号を2進数で出力する回路はどれか。
  9. オープンドレイン出力の回路を複数、プルアップ抵抗のある1本の信号線につないだときの動作として正しいものはどれか。
  10. 実行中の処理を一時的に中断し、外部機器からの要求などに応じた処理を優先して行うCPUの仕組みはどれか。
  11. CPUを介さずに、周辺装置とメモリの間で直接データを転送する仕組みはどれか。
  12. CPUのプログラムカウンタ(PC)が保持しているものはどれか。
  13. コンパイラの自動ベクトル化で使われる命令の種類として正しいものはどれか。
  14. 組込み向けの開発で使うリンカスクリプトの役割として正しいものはどれか。
  15. CPUに特権モード(カーネルモード)とユーザモードを設ける主な目的はどれか。
