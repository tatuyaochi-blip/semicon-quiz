割り込みとは

わりこみ

外部機器からの要求などに応じて、実行中の処理を一時的に中断し、対応する処理を優先して行うCPUの仕組み。終わると元の処理に戻る。

この用語の分野: CPU・アーキテクチャ

解説の中の「割り込み」

  • 例えば複数の割り込み要求をまとめる回路や、ビット演算で特定のビットを1にする操作(x OR 0x80で最上位ビットを1に)に使われます。

    2入力ORゲートの出力が0になるのはどのときか。

  • 割り込みコントローラでの要求の選択や、浮動小数点の正規化での先頭の1の位置検出(リーディングゼロ検出)に使われます。

    複数の入力が同時に1になったとき、最も優先度の高い入力の番号を2進数で出力する回路はどれか。

  • I²Cのバスや割り込み線、異なる電源電圧の回路間のレベル変換に使われます。

    オープンドレイン出力の回路を複数、プルアップ抵抗のある1本の信号線につないだときの動作として正しいものはどれか。

「割り込み」が出てくる問題(6問)

  1. 2入力ORゲートの出力が0になるのはどのときか。
  2. 複数の入力が同時に1になったとき、最も優先度の高い入力の番号を2進数で出力する回路はどれか。
  3. オープンドレイン出力の回路を複数、プルアップ抵抗のある1本の信号線につないだときの動作として正しいものはどれか。
  4. 実行中の処理を一時的に中断し、外部機器からの要求などに応じた処理を優先して行うCPUの仕組みはどれか。
  5. CPUを介さずに、周辺装置とメモリの間で直接データを転送する仕組みはどれか。
  6. CPUのプログラムカウンタ(PC)が保持しているものはどれか。
