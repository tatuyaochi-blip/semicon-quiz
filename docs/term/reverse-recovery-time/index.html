逆回復時間とは

ぎゃくかいふくじかん

導通していたダイオードに逆電圧をかけたとき、蓄積された少数キャリアが消えるまで逆方向に電流が流れ続ける時間。スイッチング損失やノイズの原因になる。

「逆回復時間」は、2分野の2問の練習問題に出てきます(PN接合・ダイオード, データシートの読み方など)。

この用語の分野: PN接合・ダイオード

逆回復のあいだに起こること

導通しているダイオードを逆バイアスに切り替えると、外部回路によって電流はdi/dtの傾きで減少し、やがて逆向きになります。しかし接合の両側に蓄積された少数キャリアが内部で順バイアス状態を保つため、接合はまだ電圧を阻止できず、逆方向電流が流れてピーク逆回復電流まで増加します。接合付近のキャリアがなくなるとダイオードは阻止を始め、電流はゼロに向かって減衰します。電流がゼロを横切ってから規定の割合まで減衰するまでの時間がtrrです。

蓄積電荷と測定条件

取り除くべき電荷Qrrはおおよそ順方向電流と少数キャリアの寿命の積なので、trrは順方向電流が大きいほど長くなり、ライフタイムを延ばす高温でも長くなります。di/dtが大きいとピーク逆電流が増え、波形も変わります。そのためデータシートでは、順方向電流、di/dt、温度などの条件とともにtrrが示されます。一般整流用ダイオードの回復時間はµsオーダーですが、ファストリカバリ型はライフタイムを短くする再結合中心を導入することで数十nsを実現しています。

ソフトリカバリとハードリカバリ

trrは、ピーク逆電流に達するまでの時間と、その後の減衰時間に分けて考えることが多く、減衰時間と立ち上がり時間の比をソフトネスと呼びます。電流が急激に途切れるハードリカバリ(スナッピー)なダイオードは、回路のインダクタンスに大きな電圧スパイクを生じさせ、リンギングや電磁妨害(EMI)の原因になります。ソフトリカバリのダイオードは電流がより緩やかに減衰します。そのため設計者は還流ダイオードを選ぶ際、trrだけでなくQrrと回復波形も確認します。

電力変換器への影響と代替手段

ハードスイッチングの変換器では、還流ダイオードの逆回復電流がターンオンするトランジスタを流れ、スイッチング周波数とともに増えるターンオン損失とストレスを加えます。MOSFETのボディダイオードは回復が遅いことが多く、ブリッジ回路でよく知られた問題です。炭化ケイ素(SiC)ショットキーダイオードを含むショットキーダイオードは多数キャリアで導通し、少数キャリアの電荷をほとんど蓄積しないため、本来の逆回復ではなく小さな容量性の電荷が流れるだけです。

逆回復時間の練習問題に挑戦

PN接合ダイオードを順方向から逆方向に切り替えたとき、短い時間だけ逆方向電流が流れる(逆回復時間がある)原因はどれか。

  1. A金属電極の抵抗が大きいため
  2. B順方向で導通していたときに蓄積された少数キャリアが、すぐには消えないため
  3. Cパッケージが熱をもつため
答えと解説を見る

正解：B. 順方向で導通していたときに蓄積された少数キャリアが、すぐには消えないため

順方向で導通している間、接合の両側には注入された少数キャリアが蓄積されています。逆方向に切り替えても、これらが引き抜かれるか再結合で消えるまでは逆方向に電流が流れ続けます。この時間が逆回復時間(trr)で、逆回復電流は損失やノイズの原因になります。対策として、ライフタイム制御をしたファストリカバリダイオード、少数キャリアを使わないショットキーやSiCダイオードが使われます。

ダイオードのデータシートにある逆回復時間 trr について正しいものはどれか。

  1. A素子に固有の定数なので、どのような回路条件で使っても同じ値になる
  2. B順電流 IF や電流の減少率 di/dt、温度などの条件で変わるので、測定条件とあわせて読む
  3. Cショットキーバリアダイオードは、一般のPN接合ダイオードと比べてtrrが長くなるのが一般的である
答えと解説を見る

正解：B. 順電流 IF や電流の減少率 di/dt、温度などの条件で変わるので、測定条件とあわせて読む

trrは、順方向に電流が流れている状態から逆バイアスに切り替えたとき、蓄積された少数キャリアが掃き出されるまで逆方向に電流が流れる時間です。蓄積される電荷の量は順電流や温度で変わり、電流を切り替える速さ(di/dt)によっても波形が変わるため、データシートでは「IF = 1 A、di/dt = 100 A/µs」のような条件付きで規定されます。一般整流用ではµsオーダー、ファストリカバリ品では数十ns程度です。ショットキーは多数キャリアで動くため、逆回復がほとんどありません。

よくある質問

ショットキーダイオードに逆回復時間はありますか?

実質的にありません。多数キャリアで導通し少数キャリアの電荷を蓄積しないため、オフ時には接合容量の小さな充電電荷が流れるだけです。

trrとQrrの違いは何ですか?

trrは逆回復電流が流れる時間で、Qrrはその電流が運ぶ電荷の総量です。回路で生じるスイッチング損失により直接関係するのはQrrです。

ダイオードの逆回復損失を減らすにはどうすればよいですか?

高速型やソフトリカバリ型のダイオード、ショットキーダイオードやSiCショットキーダイオードを使う方法があります。ほかにも、スナバやゲート制御でdi/dtを下げる方法や、逆電圧がかかる前にダイオード電流をゼロにできるソフトスイッチング方式を採用する方法があります。
