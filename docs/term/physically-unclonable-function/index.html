PUF(物理的複製困難関数)とは

ぱふ

チップごとの製造のばらつきを利用して、そのチップに固有で複製の難しい値を作る仕組み。鍵を保存せずに作り出せる。

「PUF(物理的複製困難関数)」は、2分野の7問の練習問題に出てきます(ハードウェアセキュリティ, ハードウェアセキュリティの最新動向など)。

この用語の分野: ハードウェアセキュリティ

チップ固有の値の源

工場から出てくるトランジスタに、まったく同じものは2つとありません。しきい値電圧、ゲート寸法、配線遅延は、チップごとにランダムにばらつきます。PUF(物理的複製困難関数)は、この違いを増幅してビットにします。SRAM PUFは、電源投入時に各セルがどちらに落ち着くかを読み取ります。これはたすき掛けにつながれた2つのインバータのどちらが強いかで決まります。リングオシレータPUFは、設計上は同一の発振器どうしの周波数を比べます。アービタPUFは、チャレンジで経路が決まる2本のパスに信号を競争させ、どちらが先に着くかを記録します。ばらつきはランダムで制御できないため、製造者でさえ狙った応答を持つチップは作れません。

雑音を含むビットから安定した鍵へ

PUFの応答は完全には再現しません。2つの選択肢がほぼ拮抗しているセルやパスは、温度、電源電圧、雑音、経年劣化で反転することがありますが、暗号鍵は毎回1ビットも違わず同じでなければなりません。そこで登録時に、チップは応答を記録し、誤り訂正符号のための公開情報であるヘルパーデータを計算します。使用時にはPUFを再び読み、ヘルパーデータを使って誤り訂正符号で反転したビットを直し、ハッシュや鍵導出の処理で最終的な鍵を作ります。ファジーエクストラクタと呼ばれるこの構成は、ヘルパーデータから鍵が漏れないように設計されています。

eFuseやOTPによる鍵の保存との比較

従来の方法では、デバイスごとの鍵を一度だけ書き込めるeFuseやOTPメモリに書き込み、理想的には暗号エンジンだけが読めるようにします。こうしたビットは常に存在するので、パッケージを開けて記憶部をプロービングしたり撮像したりする攻撃の標的になりえます。PUFでは鍵は必要なときだけ再生成され、電源が切れている間はどこにも存在しません。また侵襲的なプロービングは、鍵を決めているばらつきそのものを乱しやすくなります。よく使われる折衷案は、PUFから導出した鍵で暗号化した鍵をフラッシュに保存する方法です。どの方法でも、鍵の読み出し経路を制限することが不可欠です。

品質の指標と限界

PUFは主に3つの指標で評価されます。異なるチップの応答間のハミング距離で表す一意性(理想は50%)、同じチップを読んだときに変わるビットの少なさを示す信頼性、そして0と1の偏りのなさを示す均一性です。SRAM PUFのような弱いPUFは、チャレンジとレスポンスの組が少なく、鍵生成に向いています。アービタPUFのような強いPUFは非常に多くの組を持ち認証に使えますが、観測した組から機械学習でモデル化する攻撃によって、応答を学習されてしまうことがよくあります。サイドチャネルによる漏えいや、ヘルパーデータの改ざんも攻撃対象になります。

PUF(物理的複製困難関数)の練習問題に挑戦

PUF(物理的複製困難関数)の説明として正しいものはどれか。

  1. Aチップごとの製造のばらつきを利用して、そのチップに固有で複製の難しい値を作る仕組み
  2. Bすべてのチップに同じ値を書き込む仕組み
  3. Cチップの表面に印刷した製品の番号
答えと解説を見る

正解：A. チップごとの製造のばらつきを利用して、そのチップに固有で複製の難しい値を作る仕組み

同じ設計のチップでも、トランジスタのしきい値電圧や配線の遅延には、製造のばらつきによるわずかな違いがあります。PUFはこの違いを読み出して、チップごとに異なる値を作ります。ばらつきは製造する側にも制御できないので、同じ値を持つチップを作ることは困難です。機器の認証や、鍵を作る元として使われます。

鍵の保管にPUFを使う利点として正しいものはどれか。

  1. A鍵の値を、利用者が自由に選べる
  2. B鍵が電源を切っても必ずメモリに残る
  3. C鍵を不揮発メモリに書いておく必要がなく、使うときだけ作り出すので、チップを解析されても取り出されにくい
答えと解説を見る

正解：C. 鍵を不揮発メモリに書いておく必要がなく、使うときだけ作り出すので、チップを解析されても取り出されにくい

鍵をフラッシュやeFuseに書いておくと、チップを開けて記憶の内容を直接読み取る攻撃の対象になります。PUFを使えば、鍵はチップの物理的な性質から使うたびに作り出され、電源を切っている間はどこにも保存されていません。また、PUFの種類によっては、値を読もうとチップを加工するとばらつきの性質そのものが変わってしまうので、取り出しはさらに難しくなります。

よくある質問

PUFは何に使われますか?

デバイス認証や、不揮発性メモリに常時保存せずに暗号鍵を導出するための、チップ固有の値として使われます。ハードウェアの信頼の基点(ルート・オブ・トラスト)が必要なセキュアマイコンやFPGAなどのチップに搭載されています。

PUFは乱数生成器と同じものですか?

違います。真性乱数生成器は毎回新しい予測不能なビットを出す必要があるのに対し、PUFは読むたびに同じチップ固有の値を再現しなければなりません。ただし、不安定なSRAMセルを追加のエントロピー源として活用する設計もあります。

SRAM PUFに誤り訂正が必要なのはなぜですか?

SRAMセルの一部はほぼ拮抗しており、温度、電圧、雑音によって電源投入時の状態が変わるからです。ヘルパーデータを使った誤り訂正でこの反転するビットを直し、導出される鍵が毎回同じになるようにします。
