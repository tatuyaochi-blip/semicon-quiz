PUF(物理的複製困難関数)とは

ぱふ

チップごとの製造のばらつきを利用して、そのチップに固有で複製の難しい値を作る仕組み。鍵を保存せずに作り出せる。

この用語の分野: ハードウェアセキュリティ

解説の中の「PUF(物理的複製困難関数)」

  • PUFはこの違いを読み出して、チップごとに異なる値を作ります。

    PUF(物理的複製困難関数)の説明として正しいものはどれか。

  • PUFを使えば、鍵はチップの物理的な性質から使うたびに作り出され、電源を切っている間はどこにも保存されていません。

    鍵の保管にPUFを使う利点として正しいものはどれか。

  • PUFの値は製造のばらつきで決まりますが、2つの候補の差が小さいセルでは、温度や電圧、雑音によって読み出すたびに値が変わることがあります。

    PUFから鍵を作るときに、誤り訂正の仕組み(ヘルパーデータなど)を組み合わせる理由として正しいものはどれか。

「PUF(物理的複製困難関数)」が出てくる問題(6問)

  1. PUF(物理的複製困難関数)の説明として正しいものはどれか。
  2. 鍵の保管にPUFを使う利点として正しいものはどれか。
  3. SRAM PUFが利用している性質として正しいものはどれか。
  4. PUFから鍵を作るときに、誤り訂正の仕組み(ヘルパーデータなど)を組み合わせる理由として正しいものはどれか。
  5. チップの中に鍵を書き込んで保存する方法として、一般に使われているものはどれか。
  6. 多数の機器を製造するとき、すべての機器に同じ鍵を入れずに、機器ごとに違う鍵を持たせる理由として正しいものはどれか。
