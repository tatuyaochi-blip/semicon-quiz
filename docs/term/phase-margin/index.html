位相余裕(フェーズマージン)とは

いそうよゆう

負帰還ループの利得が1(0 dB)になる周波数で、位相の遅れが180°に達するまでの余裕。小さいと応答が振動的になり、0以下では発振する。一般に45〜60°以上を目安にする。

「位相余裕(フェーズマージン)」は、2分野の13問の練習問題に出てきます(制御工学の基礎, アナログ・電子回路など)。

この用語の分野: アナログ・電子回路

位相余裕の定義

信号が帰還ループを一巡するときに受ける利得、つまりループ利得 T = Aβ を考えます。T の大きさが 1(0 dB)まで下がる交差周波数で、位相遅れが 180 度まであとどれだけ残っているかが位相余裕です。位相遅れが 120 度なら位相余裕は 60 度です。対になる指標が利得余裕(ゲインマージン)で、位相遅れが 180 度に達する周波数でループ利得が 0 dB よりどれだけ低いかを表します。どちらも閉ループ応答ではなく、ループ利得のボード線図から読み取ります。

数値が実際に意味すること

位相余裕がゼロならループは持続発振し、負なら発振が成長します。正でも小さい場合は、閉ループ周波数応答にピーキングが、ステップ応答にオーバーシュートとリンギングが現れます。約 45 度ではオーバーシュートがはっきり見え、約 60 度ではわずかなオーバーシュートで速い応答が得られます。そのため 45〜60 度以上が一般的な目標になっています。非常に大きな位相余裕は安定ではありますが、多くの場合、帯域を犠牲にしていることを意味します。

位相遅れの原因

ループ内の各ポールは最大 90 度の位相遅れを生むため、交差周波数の近くにポールが2つあると合計は 180 度に近づきます。ドミナントポール補償では、1つのポールを非常に低い周波数(汎用オペアンプでは数 Hz〜数十 Hz)に置きます。ミラー効果を利用することが多く、そうすれば小さなオンチップ容量で済みます。すると利得は −20 dB/dec で下がり、次のポールが大きな遅れを加える前に 0 dB を横切ります。2つ目のポールが1つだけの場合、それを交差周波数の約 1.7 倍に置くと、およそ 60 度の位相余裕が得られます。代償は帯域とスルーレートの低下です。

ボルテージフォロワが最悪条件になる理由

帰還率 β = 1 では、ループ利得が開ループ利得そのものと等しくなり、交差周波数が最も高く、オペアンプ内部のポールに最も近くなります。閉ループ利得を高くすると β が小さくなって交差周波数が下がり、位相余裕が増えます。そのため非完全補償型(ディコンペンセイテッド)のオペアンプは、最小利得以上でのみ安定と規定されています。出力抵抗とともに余分なポールをつくる容量性負荷や、ループ内の遅延も位相余裕を削ります。同じ解析は電圧レギュレータや PLL(位相同期回路)にも当てはまります。

位相余裕(フェーズマージン)の練習問題に挑戦

一巡伝達関数のボード線図から読み取る、ゲイン余裕と位相余裕の説明として正しいものはどれか。

  1. Aゲイン余裕はゲインが0 dBになる周波数での位相の −180° までの差、位相余裕は位相が −180° になる周波数でのゲインの0 dBまでの差である
  2. Bゲイン余裕は位相が −180° になる周波数でのゲインの0 dBまでの差、位相余裕はゲインが0 dBになる周波数での位相の −180° までの差である
  3. Cゲイン余裕も位相余裕も、閉ループのボード線図で、ゲインが −3 dBになる周波数で読み取る
答えと解説を見る

正解：B. ゲイン余裕は位相が −180° になる周波数でのゲインの0 dBまでの差、位相余裕はゲインが0 dBになる周波数での位相の −180° までの差である

ゲイン余裕は、位相が −180° になる位相交差周波数で、ゲインが0 dBより何dB低いかを表します。位相余裕は、ゲインが0 dBになるゲイン交差周波数で、位相が −180° まであと何度あるかを表します。どちらも、一巡伝達関数が点 −1(ゲイン0 dB、位相 −180°)にどれだけ近いかを表す指標で、閉ループではなく一巡伝達関数から読み取ります。サーボ系では、ゲイン余裕10〜20 dB、位相余裕40〜60°程度がよく目安にされます。

一巡伝達関数のゲインを上げたところ、位相余裕が60°から30°に減った。閉ループのステップ応答の変化として正しいものはどれか。

  1. Aオーバーシュートが小さくなって振動がなくなり、そのかわりに応答の立ち上がりが遅くなる
  2. B位相余裕は周波数応答の指標なので、ステップ応答の形には影響しない
  3. C応答は速くなる傾向があるが、オーバーシュートが大きくなり、振動が収まりにくくなる
答えと解説を見る

正解：C. 応答は速くなる傾向があるが、オーバーシュートが大きくなり、振動が収まりにくくなる

ゲインを上げるとゲイン交差周波数が高くなって応答は速くなりますが、位相余裕が減ると、閉ループの減衰係数が小さくなります。目安として、減衰係数 ζ は位相余裕(度)の約100分の1と見積もられます。一巡伝達関数が ωn²/(s(s + 2ζωn)) の標準的な系では、位相余裕60°でオーバーシュートは約9%、30°では約42%になります。位相余裕が0に近づくと持続振動に近づき、負になると不安定になります。

よくある質問

増幅器の位相余裕はどのくらいあればよいですか?

一般的な目標は 45〜60 度以上です。約 60 度ではオーバーシュートの少ない速いステップ応答が得られ、45 度を大きく下回ると目立つリンギングが生じます。

位相余裕と利得余裕の違いは何ですか?

位相余裕は、ループ利得が 0 dB になる周波数で位相遅れが 180 度からどれだけ離れているかです。利得余裕は、位相遅れが 180 度に達する周波数でループ利得が 0 dB よりどれだけ低いかです。

オペアンプが利得1で不安定になりやすいのはなぜですか?

利得1では出力全体が帰還されるため、ループ利得が最も高い周波数で 0 dB を横切り、そこではオペアンプの高次のポールによる位相遅れが最も大きくなるからです。閉ループ利得を高くすると交差周波数が下がり、位相余裕が増えます。

  2. 一巡伝達関数のゲインを上げたところ、位相余裕が60°から30°に減った。閉ループのステップ応答の変化として正しいものはどれか。
  3. オペアンプを使ったボルテージフォロワの説明として正しいものはどれか。
  4. 増幅回路に負帰還をかけたときの効果として正しいものはどれか。
  5. 負帰還増幅回路が発振せずに安定に動作するかを判断する指標はどれか。
  6. オペアンプの位相補償で使われる「ドミナントポール補償」の考え方として正しいものはどれか。
  7. フィードフォワード制御を、フィードバック制御と組み合わせて使う理由として正しいものはどれか。
  8. ナイキストの安定判別法の説明として正しいものはどれか。
  9. むだ時間 L の要素 e^(−Ls) の周波数特性と、それを一巡伝達関数に含む制御系への影響として正しいものはどれか。
  10. 積分要素を含まない(0形の)制御対象を比例(P)制御する。比例ゲイン Kp を大きくしたときの一般的な変化として正しいものはどれか。
  11. PI制御で、積分(I)動作を加える主な目的と、その副作用の組み合わせとして正しいものはどれか。
  12. サンプリング周期 Ts = 1 ms のデジタル制御では、D/A変換の0次ホールドが、およそ Ts/2 のむだ時間として働く。ゲイン交差周波数が100 Hzのとき、この遅れによる位相の遅れに最も近いものはどれか。
  13. スイッチング周波数500 kHzの降圧DC-DCコンバータで、出力電圧のフィードバックループを設計する。ゲイン交差周波数の選び方の目安として正しいものはどれか。
