位相余裕(フェーズマージン)とは

いそうよゆう

負帰還ループの利得が1(0 dB)になる周波数で、位相の遅れが180°に達するまでの余裕。小さいと応答が振動的になり、0以下では発振する。一般に45〜60°以上を目安にする。

「位相余裕(フェーズマージン)」は、1分野の4問の練習問題に出てきます(アナログ・電子回路など)。

この用語の分野: アナログ・電子回路

位相余裕(フェーズマージン)の練習問題に挑戦

オペアンプを使ったボルテージフォロワの説明として正しいものはどれか。

  1. A電圧利得が1で、入力インピーダンスが高く出力インピーダンスが低いため、バッファとして使う
  2. B電圧利得が無限大の比較器として使う
  3. C入力電流を電圧に変換する回路として使う
答えと解説を見る

正解：A. 電圧利得が1で、入力インピーダンスが高く出力インピーダンスが低いため、バッファとして使う

ボルテージフォロワは出力を反転入力に直接つないだ非反転増幅回路(利得1)で、出力が入力と同じ電圧になります。入力インピーダンスが非常に高く出力インピーダンスが低いため、内部抵抗の大きいセンサーや分圧回路の信号を、値を変えずに後段や負荷へ渡すバッファに使われます。負帰還が最も深い構成なので、オペアンプによっては位相余裕が不足して発振しやすく、データシートで「ユニティゲイン安定」を確認します。

増幅回路に負帰還をかけたときの効果として正しいものはどれか。

  1. A利得は小さくなるが、利得の安定性の向上や周波数帯域の拡大、ひずみの低減が得られる
  2. B利得が無限大になる
  3. C必ず発振するようになる
答えと解説を見る

正解：A. 利得は小さくなるが、利得の安定性の向上や周波数帯域の拡大、ひずみの低減が得られる

負帰還をかけると、出力の一部を入力から差し引くため利得は小さくなります。その代わり、閉ループ利得が約 1/β(帰還率の逆数)となって素子のばらつきや温度に左右されにくくなり、帯域が広がり、ひずみや出力インピーダンスも(1 + ループ利得)分の1に減ります。オペアンプ回路はこの性質を前提にしています。ただし位相が大きく回る周波数で正帰還になると発振するため、位相余裕の確保が必要です。

「位相余裕(フェーズマージン)」が出てくる問題(4問)

  1. オペアンプを使ったボルテージフォロワの説明として正しいものはどれか。
  2. 増幅回路に負帰還をかけたときの効果として正しいものはどれか。
  3. 負帰還増幅回路が発振せずに安定に動作するかを判断する指標はどれか。
  4. オペアンプの位相補償で使われる「ドミナントポール補償」の考え方として正しいものはどれか。
