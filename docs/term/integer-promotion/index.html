整数拡張とは

せいすうかくちょう

C言語で、int より小さい整数型(char、short、ビットフィールドなど)の値を、演算の前に int(int で表せない場合は unsigned int)に変換する規則。そのため 8ビットの uint8_t どうしの足し算も int の幅で計算され、~ を付けた結果は上位のビットまで1になる。結果を小さい型の変数に代入するときに、その型の幅に戻される。符号付きと符号なしを混ぜた演算で型をそろえる「通常の算術変換」とあわせて、比較やビット演算の結果に影響する。

「整数拡張」は、1分野の2問の練習問題に出てきます(C言語の基礎など)。
