デジタルフォレンジックとは

でじたるふぉれんじっく

インシデントや犯罪の調査のために、コンピュータやネットワークの機器から証拠となるデータを集め、改ざんされていないことを保ちながら解析して、何が起きたかを明らかにする技術と手続き。失われやすいもの(メモリの内容やネットワークの接続の状態など)から順に集め、元の媒体は書き込みを防いで複製し、ハッシュ値で同一性を確かめ、証拠の受け渡しを記録する(チェーン・オブ・カストディ)ことが基本となる。

「デジタルフォレンジック」は、1分野の1問の練習問題に出てきます(サイバー攻撃と防御の実務など)。

この用語の分野: サイバー攻撃と防御の実務

デジタルフォレンジックの練習問題に挑戦

インシデントが起きたサーバから、調査のための証拠を集める。証拠を失われやすい順(揮発性の高い順)に集めるという考え方に沿った順序として、最も適切なものはどれか。

  1. Aメモリの内容と現在のネットワーク接続の状態 → ディスクの内容 → 外部に保管されたバックアップやアーカイブ
  2. B外部に保管されたバックアップやアーカイブ → ディスクの内容 → メモリの内容と現在のネットワーク接続の状態
  3. Cディスクの内容 → 電源を切ってから、メモリの内容と現在のネットワーク接続の状態 → 外部に保管されたバックアップ
答えと解説を見る

正解：A. メモリの内容と現在のネットワーク接続の状態 → ディスクの内容 → 外部に保管されたバックアップやアーカイブ

デジタルフォレンジックで証拠を集めるときの指針であるRFC 3227(2002年)は、失われやすいものから順に集めることを勧めています。CPUのレジスタやキャッシュ、メモリの内容、実行中のプロセスやネットワークの接続の状態は、時間がたったり電源を切ったりすると失われるので、最初に集めます。メモリには、ディスクに残らないマルウェアや、復号された状態の情報が残っていることがあります。ディスクの内容はその後に複製して調べ、外部に保管されたバックアップやアーカイブは、変わりにくいので最後でかまいません。
