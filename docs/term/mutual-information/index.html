相互情報量とは

そうごじょうほうりょう

2つの確率変数XとYが、互いについてどれだけの情報をもつかを表す量。I(X;Y) = H(X) − H(X|Y) = H(X) + H(Y) − H(X, Y) で、Yを知ることでXのあいまいさ(エントロピー)が平均してどれだけ減るかに当たる。値は0以上で、XとYが独立のときに0になる。XとYを入れ替えても同じ値になる。通信路の入力をX、出力をYとすると、1回の伝送で伝わる情報量を表し、入力の確率分布を変えたときの最大値が通信路容量である。

「相互情報量」は、1分野の3問の練習問題に出てきます(情報理論と符号の基礎など)。

相互情報量の練習問題に挑戦

2つの確率変数X、Yについて、条件付きエントロピー H(X|Y) と相互情報量 I(X;Y) の説明として、正しいものはどれか。

  1. AYの値を知ると、Xのあいまいさを表す H(X|Y) は、平均して H(X) より大きくなることがある
  2. B相互情報量 I(X;Y) は、XとYが互いに独立のときに最大になり、その値は H(X) + H(Y) である
  3. CI(X;Y) = H(X) − H(X|Y) は、Yを知ってXのあいまいさが減る量で、独立なら0になる
答えと解説を見る

正解：C. I(X;Y) = H(X) − H(X|Y) は、Yを知ってXのあいまいさが減る量で、独立なら0になる

H(X|Y) は、Yの値を知ったあとに残るXのあいまいさの平均で、Yを知って平均のあいまいさが増えることはなく、H(X|Y) ≤ H(X) が成り立ちます。その減った量が相互情報量 I(X;Y) = H(X) − H(X|Y) = H(X) + H(Y) − H(X, Y) で、XとYが独立なら、YからXについて何も分からないので0になります。通信では、Xを送った記号、Yを受け取った記号とすると、I(X;Y) は1回の伝送で実際に伝わる情報量に当たります。

2つの確率変数X(値は0か1)とY(値はa、b、cのどれか)の同時確率が、P(0, a) = P(0, b) = P(1, b) = P(1, c) = 1/4 で、ほかの組み合わせの確率は0である。相互情報量 I(X;Y) はどれか。

  1. A0.5ビット
  2. B1ビット
  3. C1.5ビット
答えと解説を見る

正解：A. 0.5ビット

Xは0と1が1/2ずつなので H(X) = 1 ビット、Yはaが1/4、bが1/2、cが1/4なので H(Y) = 1.5 ビットです。4つの組が1/4ずつなので H(X, Y) = 2 ビットとなり、I(X;Y) = H(X) + H(Y) − H(X, Y) = 1 + 1.5 − 2 = 0.5 ビットです。Yがaかcならば Xの値が分かり、bならば分からないので、YからXについて一部の情報が得られます。

「相互情報量」が出てくる問題(3問)

  1. 2つの確率変数X、Yについて、条件付きエントロピー H(X|Y) と相互情報量 I(X;Y) の説明として、正しいものはどれか。
  2. 2つの確率変数X(値は0か1)とY(値はa、b、cのどれか)の同時確率が、P(0, a) = P(0, b) = P(1, b) = P(1, c) = 1/4 で、ほかの組み合わせの確率は0である。相互情報量 I(X;Y) はどれか。
  3. 0と1を送り、各ビットが互いに独立に確率0.1で反転する二元対称通信路がある。2値のエントロピー関数を H(p) = −p log₂ p − (1 − p) log₂(1 − p) とすると、H(0.1) ≈ 0.469 である。この通信路の、1回の伝送あたりの通信路容量に最も近いものはどれか。
