MTTF(平均故障時間)とは

えむてぃーてぃーえふ

修理しない製品が故障するまでの時間の平均。製品の寿命の目安として使う。

「MTTF(平均故障時間)」は、3分野の6問の練習問題に出てきます(信頼性, 車載半導体と機能安全, 配線プロセスなど)。

この用語の分野: 信頼性

定義と指数分布モデル

平均故障時間(MTTF)は、修理しない部品が故障するまでの時間の期待値で、数学的には信頼度関数R(t)の積分です。偶発故障期には故障率λがほぼ一定で、故障までの時間は指数分布に従い、R(t) = exp(−λt)、MTTF = 1/λとなります。したがってλ = 1×10⁻⁵ /hの部品のMTTFは10⁵時間、約11年です。tがMTTFに等しい時点でまだ動作している部品はexp(−1)、つまり約37%にすぎず、平均値は保証寿命とは大きく異なります。

FITからMTTFへの換算

半導体の故障率は通常FITで表し、1 FITは10⁹デバイス時間あたり1件の故障です。換算すると、100 FITはMTTF 10⁷時間に相当し、部品1個としてはおよそ1140年になります。このような数値は母集団全体で考えて初めて意味を持ちます。100 FITの部品100万個を1万時間動かすと、10⁶ × 10⁴ × 100 / 10⁹ = 1000件の故障が見込まれます。λtが小さいときは、λtそのものが、ある部品が時間t以内に故障する確率のよい近似になります。

MTTFは摩耗寿命ではない

製品寿命にわたる故障率は、しばしばバスタブ曲線で描かれます。初期故障の期間、偶発故障が続く長く平らな期間、そして摩耗故障が増えていく期間です。平らな期間の故障率から計算したMTTFは、摩耗がいつ始まるかについては何も示さず、実際の耐用寿命を桁違いに上回ることもあります。摩耗故障のメカニズムについては、ストレス試験のデータに対数正規分布やワイブル分布などを当てはめ、所定の条件での故障時間の中央値やパーセンタイル値を示します。

エレクトロマイグレーションとブラックの式

エレクトロマイグレーションによる配線寿命は、ブラックの式MTTF = A·J⁻ⁿ·exp(Ea/kT)でモデル化されます。Jは電流密度、nは約2、Eaは活性化エネルギー、Tは絶対温度です。電流密度が高くても温度が高くても寿命は短くなり、温度の影響は指数関数的です。そのため試験は、たとえば約300 ℃といった高い電流と温度で加速して行い、結果を使用条件へ外挿します。設計ルールでは、配線1本あたりの電流密度をMA/cm²オーダーで制限します。ここでのMTTFは部品の寿命を表すもので、機能安全でいう故障許容時間間隔とは別物です。

MTTF(平均故障時間)の練習問題に挑戦

故障率が一定で1×10⁻⁵ /時間の部品の平均故障時間(MTTF)はいくらか。

  1. A1×10³時間
  2. B1×10⁵時間
  3. C1×10⁷時間
答えと解説を見る

正解：B. 1×10⁵時間

故障率が一定のとき、平均故障時間は故障率の逆数になります。1 ÷ (1×10⁻⁵) = 1×10⁵時間、つまり約11年です。1×10³時間や1×10⁷時間は指数の計算の誤りです。ただし、これは偶発故障期の故障率から求めた値で、摩耗故障が始まる時期を表すものではありません。MTTFが寿命より長く計算されることもあるため、両者を混同しないことが大切です。

よくある質問

故障率からMTTFはどう計算しますか?

故障率λが一定なら、MTTF = 1/λです。たとえば1×10⁻⁵ /hなら10⁵時間で、FITで与えられた故障率はMTTF = 10⁹ / FIT(時間)で換算します。

MTTFに達した時点で何%の部品が故障していますか?

故障率が一定なら約63%です。t = MTTFでの信頼度がexp(−1) ≈ 37%になるためです。MTTFは平均値であり、最低限の寿命ではありません。

MTTFとMTBFの違いは何ですか?

MTTFは故障したら廃棄する部品に使い、MTBFは修理可能なシステムで、故障と故障の間の時間を表します。復旧にかかる時間は平均修復時間(MTTR)で表します。

解説の中の「MTTF(平均故障時間)」

  • 故障率が一定のとき、平均故障時間は故障率の逆数になります。

    故障率が一定で1×10⁻⁵ /時間の部品の平均故障時間(MTTF)はいくらか。

  • 部品の寿命を表すMTTFや、修理にかかる時間とは別の考え方です。

    ISO 26262のフォールトトレラント時間間隔(FTTI)の説明として正しいものはどれか。

  • ブラックの式では、平均故障時間が MTTF = A·J⁻ⁿ·exp(Ea/kT) と表され、電流密度Jのn乗(nは約2)に反比例し、温度に対して指数関数的に短くなります。

    エレクトロマイグレーションによる配線の寿命を表すブラックの式で、寿命を短くする要因として正しいものはどれか。

  • 故障から修理完了までの平均時間はMTTR、修理しない部品の故障までの平均時間はMTTFと呼びます。

    MTBF(平均故障間隔)の説明として正しいものはどれか。

  • 1個の部品で見ると100 FITはMTTFが約1140年に相当するほど小さい値で、半導体のような故障率の低い部品を、大量に使ったときの故障数で評価するのに便利な単位です。

    故障率の単位FITの意味として正しいものはどれか。

「MTTF(平均故障時間)」が出てくる問題(6問)

  1. 故障率が一定で1×10⁻⁵ /時間の部品の平均故障時間(MTTF)はいくらか。
  2. ISO 26262のフォールトトレラント時間間隔(FTTI)の説明として正しいものはどれか。

  5. 故障率の単位FITの意味として正しいものはどれか。
