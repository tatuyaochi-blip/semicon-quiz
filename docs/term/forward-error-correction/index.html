前方誤り訂正(FEC)とは

ぜんぽうあやまりていせい

送信側で冗長なビットを加えた誤り訂正符号で送り、受信側だけで誤りを訂正する方式。Forward Error Correctionの略。受信側から送り直しを求めないので、戻りの通信路がない放送や、往復の遅れが大きい衛星・宇宙との通信、遅延の許されない高速の伝送路で使われる。代表的な符号に、ハミング符号、BCH符号、リード・ソロモン符号、LDPC符号などがある。誤りを検出して送り直してもらうARQ(自動再送要求)と比べると、常に冗長なビットの分だけ伝送の効率は下がるが、遅延が一定になる。PAM4を使うPCI Express 6.0などの高速なシリアル伝送でも使われる。

「前方誤り訂正(FEC)」は、2分野の2問の練習問題に出てきます(情報理論と符号の基礎, インターフェース・バス規格など)。

前方誤り訂正(FEC)の練習問題に挑戦

通信で誤りに対処する方式のARQ(自動再送要求)とFEC(前方誤り訂正)の説明として、正しいものはどれか。

  1. AARQは、受信側だけで誤りを訂正するので、送信側へ知らせを返す通信路が要らない
  2. BFECは、誤りを検出したら送り直しを求めるので、誤りが多いと遅延が大きくなりやすい
  3. CFECは、冗長なビットを使って受信側で誤りを訂正するので、片方向の放送にも使える
答えと解説を見る

正解：C. FECは、冗長なビットを使って受信側で誤りを訂正するので、片方向の放送にも使える

ARQは、CRCなどで誤りを検出し、受け取れなかったことを送信側に知らせて送り直してもらう方式で、戻りの通信路が必要で、送り直しの分だけ遅れます。FECは、冗長なビットを付けて送り、受信側だけで誤りを訂正するので、片方向の放送や、往復に時間のかかる宇宙との通信、遅れの許されない通信に向きます。実際の通信では、FECで大部分の誤りを直し、残った誤りをARQで送り直す組み合わせもよく使われます。

PAM4を使うと、NRZに比べて誤り訂正(FEC)がより重要になる理由として正しいものはどれか。

  1. APAM4ではクロックを取り出せないので、誤りが毎回起きるから
  2. B同じ振幅の中に4段階を入れるので段階の間隔が約1/3になり、雑音でビットを誤りやすくなるから
  3. CPAM4の信号は暗号化されているので、復号の誤りを直す必要があるから
答えと解説を見る

正解：B. 同じ振幅の中に4段階を入れるので段階の間隔が約1/3になり、雑音でビットを誤りやすくなるから

電圧の振れ幅が同じなら、2段階のNRZでは0と1の間に振れ幅いっぱいの間隔がありますが、4段階のPAM4では隣の段階との間隔が約1/3になります。雑音の余裕がおよそ9.5 dB小さくなるので、ビットの誤りが起こりやすくなります。そこでPCI Express 6.0では、軽い誤り訂正の符号を加え、受信側で小さな誤りを直してから使います。

解説の中の「前方誤り訂正(FEC)」

  • FECは、冗長なビットを付けて送り、受信側だけで誤りを訂正するので、片方向の放送や、往復に時間のかかる宇宙との通信、遅れの許されない通信に向きます。
