アーンドバリューマネジメント(EVM)とは

あーんどばりゅーまねじめんと

プロジェクトの進み具合とコストを、計画価値(PV)、出来高(EV)、実コスト(AC)という金額の物差しで比べて管理する手法。スケジュール効率指数 SPI = EV ÷ PV とコスト効率指数 CPI = EV ÷ AC から、遅れや予算の超過を判断し、完成時総コストを見積もる。

「アーンドバリューマネジメント(EVM)」は、1分野の1問の練習問題に出てきます(ソフトウェア開発とプロジェクト管理など)。

この用語の分野: ソフトウェア開発とプロジェクト管理

3つの値

計画価値(PV)は、その時点までに終える予定だった作業の予算です。出来高(EV、アーンドバリュー)は、その時点までに実際に終えた作業を、予算の金額で数えたものです。実コスト(AC)は、その時点までに実際にかかったコストです。進み具合だけを見ると「何%終わったか」、コストだけを見ると「いくら使ったか」しか分かりませんが、EVを基準にPVとACの両方と比べることで、遅れと超過を別々に判断できます。

差異と指数

スケジュール差異 SV = EV − PV とスケジュール効率指数 SPI = EV ÷ PV は進み具合を、コスト差異 CV = EV − AC とコスト効率指数 CPI = EV ÷ AC はコストを表します。SV が負(SPI が1未満)なら予定より遅れ、CV が負(CPI が1未満)なら予算を超過しています。例えば PV が500、EV が400、AC が450なら、SPI = 0.8で遅れ、CPI = 400 ÷ 450 ≈ 0.89で超過です。金額の差と比率を合わせて見ると、問題の大きさと効率の両方が分かります。

完成時の見積もり

今のコスト効率が最後まで続くとすると、完成時総コストの見積もりは EAC = BAC ÷ CPI です(BAC は完成時総予算)。上の例で BAC が1,000なら、EAC = 1,000 ÷ (400 ÷ 450) ≈ 1,125です。超過の原因が一時的で、残りの作業は予算どおりに進むと考える場合は、EAC = AC + (BAC − EV) を使います。どの式を使うかは超過の原因によるので、数値だけでなく原因の分析と合わせて判断します。

アーンドバリューマネジメント(EVM)の練習問題に挑戦

完成時総予算(BAC)が2,000万円のプロジェクトで、ある時点の計画価値(PV)が800万円、出来高(EV)が600万円、実コスト(AC)が750万円だった。この時点のプロジェクトの状況として、正しいものはどれか。

  1. Aスケジュールは遅れていて(SPI = 0.75)、コストも予算を超過している(CPI = 0.8)
  2. Bスケジュールは遅れているが(SPI = 0.75)、コストは予算内に収まっている(CPI = 1.25)
  3. Cスケジュールは進んでいるが(SPI = 1.33)、コストは予算を超過している(CPI = 0.8)
答えと解説を見る

正解：A. スケジュールは遅れていて(SPI = 0.75)、コストも予算を超過している(CPI = 0.8)

スケジュール効率指数は SPI = EV ÷ PV = 600 ÷ 800 = 0.75で、1より小さいので予定より遅れています(スケジュール差異 SV = EV − PV = −200万円)。コスト効率指数は CPI = EV ÷ AC = 600 ÷ 750 = 0.8で、1より小さいので、終わった作業の予算より多くのコストがかかっています(コスト差異 CV = EV − AC = −150万円)。EVMでは、出来高(EV)を計画価値(PV)と実コスト(AC)の両方と比べることで、進み具合とコストを同じ金額の物差しで評価します。

よくある質問

SPI と CPI はどちらが重要ですか?

両方を合わせて見ます。SPI が1未満でも CPI が1以上なら、遅れているがコストの効率は良い状態で、人を増やして取り戻せる余地があります。両方が1未満なら、遅れと超過が同時に起きていて、範囲や計画の見直しが必要になることが多くなります。

出来高(EV)はどうやって測りますか?

WBSのワークパッケージごとに予算を割り当て、終わった作業の予算を合計します。途中の作業は、着手で50%、完了で100%とする50/50ルールや、完了するまで0%とする0/100ルールなど、あらかじめ決めた規則で数えると、担当者の主観に左右されにくくなります。
