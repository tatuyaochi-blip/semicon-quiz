ACID特性とは

あしっどとくせい

トランザクションが満たすべき4つの性質の頭文字。原子性(Atomicity: すべて実行されるか、まったく実行されないか)、一貫性(Consistency: 整合性の制約を満たし続ける)、独立性(Isolation: 同時に実行しても互いに干渉しない)、耐久性(Durability: コミットした結果は障害でも失われない)。

「ACID特性」は、1分野の2問の練習問題に出てきます(データベースの基礎など)。

この用語の分野: データベースの基礎

ACID特性の練習問題に挑戦

トランザクションが持つべきACID特性のうち、「口座Aから引き落として口座Bに入金する振替の処理が、途中で障害が起きても、両方とも行われるか、まったく行われないかのどちらかになる」という性質はどれか。

  1. A一貫性(Consistency)
  2. B耐久性(Durability)
  3. C原子性(Atomicity)
答えと解説を見る

正解：C. 原子性(Atomicity)

ACID特性は、トランザクションが満たすべき4つの性質の頭文字をとったものです。原子性(Atomicity)は、トランザクションの中の処理がすべて実行されるか、まったく実行されないかのどちらかになる性質で、障害が起きたときは途中までの更新を取り消します。一貫性(Consistency)は、トランザクションの前後で、データが整合性の制約(残高が負にならない、外部キーの参照先があるなど)を満たし続ける性質です。独立性(Isolation、隔離性)は、同時に実行される複数のトランザクションが互いに干渉せず、1つずつ順に実行した場合と同じ結果になる性質です。耐久性(Durability、永続性)は、コミットしたトランザクションの結果が、その後に障害が起きても失われない性質です。設問の「全部か無か」の性質は原子性です。

「ACID特性」が出てくる問題(2問)

  1. トランザクションが持つべきACID特性のうち、「口座Aから引き落として口座Bに入金する振替の処理が、途中で障害が起きても、両方とも行われるか、まったく行われないかのどちらかになる」という性質はどれか。
  2. 多くのDBMSは、データを更新するとき、更新の内容をログ(ジャーナル)に記録し、そのログをデータベース本体より先に不揮発性の記憶装置に書き込む(WAL: ログ先行書き込み)。この方式をとる主な理由はどれか。
