犠牲層エッチングとは

ぎせいそうえっちんぐ

構造の下に一時的に置いた層(犠牲層)をエッチングで取り除き、動ける梁や膜を浮かせる、MEMSの代表的な加工法。

「犠牲層エッチング」は、1分野の1問の練習問題に出てきます(MEMS・センサなど)。

この用語の分野: MEMS・センサ

犠牲層エッチングの練習問題に挑戦

MEMSの製造で使われる犠牲層エッチングの目的として正しいものはどれか。

  1. Aウエハを薄くして軽くする
  2. B配線の抵抗を下げる
  3. C構造体の下にある層を取り除き、可動部を基板から浮かせる
答えと解説を見る

正解：C. 構造体の下にある層を取り除き、可動部を基板から浮かせる

犠牲層エッチングでは、あとで取り除く前提の層(犠牲層、例えばSiO2)の上に構造体の膜(ポリシリコンなど)をつくり、最後に犠牲層だけを選択的にエッチングで除去します。こうして基板から数µm浮いた梁や膜などの可動構造をつくれます。犠牲層の厚さがすき間の大きさになり、エッチング液が届くように構造に小さな穴を開けておくのが一般的です。
