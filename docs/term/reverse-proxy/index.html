リバースプロキシとは

りばーすぷろきし

Webサーバの手前に置かれ、利用者からのリクエストをサーバの代わりに受けて、後ろにある1台または複数のサーバへ中継するサーバ。HTTPSの暗号の処理をまとめて行う(TLSの終端)、よく使われる応答を保存して返す、複数のサーバに負荷を分ける、後ろのサーバの構成を隠す、といった役割を受け持つ。利用者の側に置かれ、利用者の代わりに外部のサイトへ接続するフォワードプロキシとは、置かれる場所と守る対象が違う。

「リバースプロキシ」は、2分野の2問の練習問題に出てきます(Web技術の基礎, クラウドとコンテナの基礎など)。

この用語の分野: Web技術の基礎

リバースプロキシの練習問題に挑戦

リバースプロキシの説明として、正しいものはどれか。

  1. A社内のPCがインターネット上のサイトを見るとき、PCの代わりに外部のサーバへ接続し、閲覧の記録や制限を行う
  2. Bドメイン名をIPアドレスに変換する問い合わせを、利用者の代わりにルートサーバから順に行い、結果をしばらく保存しておく
  3. CWebサーバの手前に置かれ、利用者からのリクエストを代わりに受けて後ろのサーバへ中継し、TLSの処理などを受け持つ
答えと解説を見る

正解：C. Webサーバの手前に置かれ、利用者からのリクエストを代わりに受けて後ろのサーバへ中継し、TLSの処理などを受け持つ

リバースプロキシは、サーバの側に置かれて利用者からのリクエストを受け、後ろにある1台または複数のサーバへ中継します。HTTPSの暗号の処理をまとめて行う(TLSの終端)、よく使われる応答を保存しておいて返す、複数のサーバへ振り分けるといった役割を受け持ち、後ろのサーバの構成を利用者から隠すこともできます。社内の利用者の代わりに外部へ接続するのはフォワードプロキシで、利用者の側に置かれる点が違います。
