ミラー効果とは

みらーこうか

反転増幅回路の入力と出力の間にある容量が、入力側から見ると(1 + 利得)倍に大きく見える効果。エミッタ接地やソース接地の回路の高周波特性を悪くする。

「ミラー効果」は、4分野の6問の練習問題に出てきます(バイポーラトランジスタ, MOSFET, アナログ・電子回路など)。

この用語の分野: バイポーラトランジスタ

容量が大きく見える理由

電圧利得が−Avの反転増幅器で、入力と出力の間に容量Cがつながっている場合を考えます。入力がvだけ上がると出力はAv·vだけ下がるので、容量の両端の電圧は(1 + Av)·v変化します。そのため入力側は、接地された容量の場合の(1 + Av)倍の電荷を供給しなければならず、この容量は入力から見るとC(1 + Av)に見えます。出力から見ると同じ容量はおよそC(1 + 1/Av)で、ほぼC自体と同じです。この等価的な入力容量はミラー容量と呼ばれます。

増幅器の帯域への影響

エミッタ接地段ではベース-コレクタ間容量Cμが、ソース接地段ではゲート-ドレイン間のオーバーラップ容量を含むゲート-ドレイン間容量Cgdが、このように何倍にもなります。Cμ = 2 pFで利得が100なら、入力からは約200 pFに見えます。これが信号源抵抗Rsと組み合わさって1/(2π·Rs·C_Miller)付近にローパスの極をつくり、多くの場合この極が段の上限帯域を決めます。つまり利得を上げるとそのまま帯域が犠牲になり、高インピーダンスの信号源で駆動する高利得の反転段が遅いのはこのためです。

ミラー効果を抑える方法

古典的な対策はカスコードです。入力トランジスタの上にベース接地(またはゲート接地)のトランジスタを重ね、入力トランジスタのコレクタやドレインをほぼ一定の電圧に保ちます。すると入力トランジスタの電圧利得は約1にとどまり、帰還容量はほとんど増倍されず、段全体としては高い利得を保てます。ベース接地段だけでも、ベースが交流的に接地されているためこの問題は起きません。駆動する信号源の抵抗を下げると極の周波数が上がり、帰還容量の小さいデバイスを選ぶことも効果があります。

ミラー効果が役立つ場面

同じ増倍作用は、オペアンプの位相補償で意図的に利用されます。高利得の反転段をまたぐように小さな容量を入れると大きな容量のようにふるまい、低い周波数に支配的な極(ドミナントポール)をつくります。これにより、ほかの極が大きな位相回転を加える前に利得が1を下回るので、物理的に大きな容量をチップ上に作らなくても、ユニティゲインのボルテージフォロワとして使っても安定に動作します。パワーMOSFETのスイッチングでは、ドレイン電圧が変化してCgdが充電されている間にゲート電圧が平坦になるミラープラトーも、ミラー効果で説明できます。

ミラー効果の練習問題に挑戦

エミッタ接地増幅回路の高周波特性を悪くするミラー効果の説明として正しいものはどれか。

  1. Aベース-コレクタ間の容量が、電圧利得に応じて入力側から見て大きな容量に見える
  2. Bエミッタの抵抗が温度によって変化する
  3. Cコレクタ電流が熱雑音で揺らぐ
答えと解説を見る

正解：A. ベース-コレクタ間の容量が、電圧利得に応じて入力側から見て大きな容量に見える

エミッタ接地回路ではコレクタ電圧がベースと逆位相で大きく振れるため、ベース-コレクタ間の容量Cμは入力側から見ると約(1 + |Av|)倍に見えます。例えばCμ = 2 pF、利得100なら約200 pFになり、信号源の抵抗とともにローパスフィルタを作って帯域を狭めます。対策には、ベース接地段を重ねて利得をコレクタ側で取るカスコード接続や、信号源の抵抗を下げることがあります。

よくある質問

ミラー容量とは何ですか?

反転増幅器の入力と出力をまたぐ容量が、信号源から見て約C(1 + |Av|)に大きく見える入力容量のことです。トランジスタでは、またぐ容量は通常Cμ(バイポーラ)またはCgd(MOSFET)です。

カスコード増幅器でミラー効果が小さくなるのはなぜですか?

カスコードでは入力トランジスタがベース接地またはゲート接地のデバイスの低いインピーダンスを駆動するため、入力トランジスタ自身の電圧利得が約1になるからです。そのため帰還容量は段全体の利得倍ではなく、約2倍にしかなりません。

非反転増幅器でもミラー効果は起こりますか?

大きな増倍には反転利得が必要です。利得が+1に近いフォロワでは、またぐ容量の両端の電圧がほとんど変化せず、実効的な入力容量はむしろ小さくなります。エミッタフォロワやソースフォロワの高周波特性がよいのはこのためです。

「ミラー効果」が出てくる問題(6問)

  1. エミッタ接地増幅回路の高周波特性を悪くするミラー効果の説明として正しいものはどれか。
  2. ベース接地増幅回路の特徴として正しいものはどれか。
  3. ゲート-ドレイン間の容量が、増幅回路の入力側から見ると(1 + 利得)倍に大きく見える効果を何と呼ぶか。
  4. MOSFETのゲート長(マスク上や加工後のゲート電極の長さ)と、実効チャネル長の関係として一般的に正しいものはどれか。
  5. オペアンプの位相補償で使われる「ドミナントポール補償」の考え方として正しいものはどれか。
