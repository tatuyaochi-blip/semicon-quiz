ミラー効果とは

みらーこうか

反転増幅回路の入力と出力の間にある容量が、入力側から見ると(1 + 利得)倍に大きく見える効果。エミッタ接地やソース接地の回路の高周波特性を悪くする。

この用語の分野: バイポーラトランジスタ

解説の中の「ミラー効果」

  • 入力インピーダンスは約1/gm(1 mAで約26 Ω)と低く、ベースが交流的に接地されているため入出力間の帰還容量の影響(ミラー効果)を受けにくく、高周波まで増幅できます。

    ベース接地増幅回路の特徴として正しいものはどれか。

  • これがミラー効果で、MOSFETではゲート-ドレイン間容量Cgdが対象です。

    ゲート-ドレイン間の容量が、増幅回路の入力側から見ると(1 + 利得)倍に大きく見える効果を何と呼ぶか。

  • 重なり部分はゲート-ソース・ドレイン間のオーバーラップ容量となり、ミラー効果で遅延を増やします。

    MOSFETのゲート長(マスク上や加工後のゲート電極の長さ)と、実効チャネル長の関係として一般的に正しいものはどれか。

「ミラー効果」が出てくる問題(5問)

  1. エミッタ接地増幅回路の高周波特性を悪くするミラー効果の説明として正しいものはどれか。
  2. ベース接地増幅回路の特徴として正しいものはどれか。
  3. ゲート-ドレイン間の容量が、増幅回路の入力側から見ると(1 + 利得)倍に大きく見える効果を何と呼ぶか。
  4. MOSFETのゲート長(マスク上や加工後のゲート電極の長さ)と、実効チャネル長の関係として一般的に正しいものはどれか。
  5. オペアンプの位相補償で使われる「ドミナントポール補償」の考え方として正しいものはどれか。
