IPCとは

あいぴーしー

Instructions Per Cycle の略で、1クロックあたりに実行できる命令の数。CPUの設計上の効率を表し、性能はおおよそIPCとクロック周波数の積になる。逆数はCPI。

「IPC」は、2分野の5問の練習問題に出てきます(CPU・アーキテクチャ, 性能評価・プロファイリングなど)。

この用語の分野: CPU・アーキテクチャ

IPCの練習問題に挑戦

性能カウンタで測ったところ、あるプログラムのIPC(1サイクルあたりの命令数)が0.3と非常に低く、最後の段のキャッシュのミスが多かった。最も考えられる状況と対策の組み合わせはどれか。

  1. Aメモリの待ちでCPUが止まっている時間が長い。データの並べ方を変えたりブロッキングを行ったりして、キャッシュを有効に使う
  2. B計算が速すぎる。周波数を上げる
  3. C分岐が少なすぎる。分岐を増やす
答えと解説を見る

正解：A. メモリの待ちでCPUが止まっている時間が長い。データの並べ方を変えたりブロッキングを行ったりして、キャッシュを有効に使う

現在のCPUは1サイクルに数命令を実行できるので、IPCが0.3というのは、ほとんどの時間何かを待っていることを示します。最後の段のキャッシュのミスが多ければ、主記憶からのデータを待っている時間が長いと考えられます。データを続いた番地に並べる、ループの順番を変える、ブロッキングで同じデータを何度も使う、などでキャッシュのミスを減らすのが効果的です。

解説の中の「IPC」

  • 現在のCPUは1サイクルに数命令を実行できるので、IPCが0.3というのは、ほとんどの時間何かを待っていることを示します。

    性能カウンタで測ったところ、あるプログラムのIPC(1サイクルあたりの命令数)が0.3と非常に低く、最後の段のキャッシ…

  • スーパースカラは、複数の演算器を備え、互いに依存しない命令を1クロックに複数発行して、IPCを1より大きくする方式です。

    1クロックサイクルに複数の命令を同時に発行・実行するプロセッサの方式を何と呼ぶか。

  • IPC(Instructions Per Clock)は1クロックあたりの平均実行命令数で、CPIの逆数です。

    1クロックあたりに実行できる命令数を表す指標はどれか。

  • ただし1クロックで実行できる命令数(IPC)は設計で大きく異なるため、周波数だけでは性能は比べられません。

    クロック周波数3 GHzのCPUの説明として正しいものはどれか。

  • サイクル数と命令数からIPCが求められ、各段のキャッシュのミス、TLBのミス、分岐の予測ミスなどの回数も分かります。

    CPUに内蔵された性能カウンタ(PMU)で数えられるものの例として正しいものはどれか。

「IPC」が出てくる問題(5問)

  1. 性能カウンタで測ったところ、あるプログラムのIPC(1サイクルあたりの命令数)が0.3と非常に低く、最後の段のキャッシュのミスが多かった。最も考えられる状況と対策の組み合わせはどれか。
  2. 1クロックサイクルに複数の命令を同時に発行・実行するプロセッサの方式を何と呼ぶか。
  3. 1クロックあたりに実行できる命令数を表す指標はどれか。
  4. クロック周波数3 GHzのCPUの説明として正しいものはどれか。
  5. CPUに内蔵された性能カウンタ(PMU)で数えられるものの例として正しいものはどれか。
