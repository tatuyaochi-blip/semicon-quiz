オーバーシュートとは

おーばーしゅーと

ステップ応答などで、出力が最終値を超えて行き過ぎること。また、その最大の行き過ぎ量。制御工学では最終値に対する割合(%)で表し、零点のない二次遅れ系では減衰係数 ζ だけで決まる exp(−πζ/√(1 − ζ²)) になる。フィードバック制御の系では、位相余裕が小さいほど大きくなる。電子回路では、配線のインダクタンスや反射によって、信号や電圧の波形が一時的に最終的なレベルを超える現象も同じように呼ぶ。

「オーバーシュート」は、3分野の9問の練習問題に出てきます(制御工学の基礎, アナログ・電子回路, 配線プロセスなど)。

この用語の分野: 制御工学の基礎

オーバーシュートの練習問題に挑戦

減衰係数 ζ = 0.5 の二次遅れ系(零点のない標準形)にステップを入力した。オーバーシュート(最大の行き過ぎ量の、最終値に対する割合)に最も近いものはどれか。

  1. A約16%
  2. B約21%
  3. C50%
答えと解説を見る

正解：A. 約16%

標準形の二次遅れ系のオーバーシュートは exp(−πζ/√(1 − ζ²)) で表され、固有角周波数 ωn にはよりません。ζ = 0.5 では exp(−π × 0.5/√0.75) ≈ exp(−1.81) ≈ 0.163 で、約16%です。ζ ≈ 0.707(1/√2)では約4.3%になり、行き過ぎの少ない応答の目安としてよく使われます。行き過ぎが最大になる時刻は π/ωd(ωd = ωn√(1 − ζ²))です。

「オーバーシュート」が出てくる問題(9問)

  1. 減衰係数 ζ = 0.5 の二次遅れ系(零点のない標準形)にステップを入力した。オーバーシュート(最大の行き過ぎ量の、最終値に対する割合)に最も近いものはどれか。
  2. 負帰還増幅回路が発振せずに安定に動作するかを判断する指標はどれか。
  3. 零点のない二次遅れ系で、極を s = −σ ± jωd とする。σ を変えずに ωd だけを大きくしたときの、ステップ応答の変化として正しいものはどれか。
  4. 一巡伝達関数のゲインを上げたところ、位相余裕が60°から30°に減った。閉ループのステップ応答の変化として正しいものはどれか。
  5. 積分要素を含まない(0形の)制御対象を比例(P)制御する。比例ゲイン Kp を大きくしたときの一般的な変化として正しいものはどれか。
  6. PI制御で、積分(I)動作を加える主な目的と、その副作用の組み合わせとして正しいものはどれか。
  7. ジーグラ・ニコルスの限界感度法では、比例制御だけでゲインを上げて持続振動が起きたときのゲイン Ku と振動の周期 Tu から、PID制御のパラメータを Kp = 0.6Ku、Ti = 0.5Tu、Td = 0.125Tu と決める。Ku = 8、Tu = 2 s のときの値として正しいものはどれか。
  8. 積分ワインドアップの説明として正しいものはどれか。
  9. 数GHzで動作するチップのクロック配線のように長く太い配線で、抵抗と容量に加えて考慮が必要になる配線の性質はどれか。
