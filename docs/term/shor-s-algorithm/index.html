ショアのアルゴリズムとは

しょあのあるごりずむ

大きな整数の素因数分解や離散対数問題を、量子フーリエ変換で周期を求めることによって多項式時間で解く量子アルゴリズム。1994年にピーター・ショアが発表した。RSA暗号や楕円曲線暗号を破れるが、実行には大規模な誤り耐性量子コンピュータが必要になる。

「ショアのアルゴリズム」は、1分野の4問の練習問題に出てきます(量子コンピュータのハードウェアなど)。

この用語の分野: 量子コンピュータのハードウェア

ショアのアルゴリズムの練習問題に挑戦

大規模な誤り耐性量子コンピュータが実現したとき、ショアのアルゴリズムによって安全性が大きく損なわれると考えられている暗号はどれか。

  1. ARSA暗号や楕円曲線暗号などの公開鍵暗号
  2. BAES などの共通鍵暗号だけ
  3. Cワンタイムパッド(使い捨ての乱数の鍵で暗号化する方式)
答えと解説を見る

正解：A. RSA暗号や楕円曲線暗号などの公開鍵暗号

RSA暗号の安全性は大きな数の素因数分解の難しさに、楕円曲線暗号は離散対数問題の難しさに基づいています。ショアのアルゴリズムは、量子フーリエ変換を使って周期を求めることで、これらの問題を多項式時間で解けます。古典のコンピュータでは現実的な時間で解けない長さの鍵でも、十分大きな誤り耐性量子コンピュータがあれば解読できるようになります。AES などの共通鍵暗号に対しては、グローバーのアルゴリズムによる2乗の高速化しかなく、鍵を長くすることで対応できます。

2020年代半ばの時点の量子コンピュータで、RSA-2048 をショアのアルゴリズムで解読できない主な理由として、最も適切なものはどれか。

  1. Aショアのアルゴリズムは、量子ビットの数が1,000個を超えると原理的に動作しなくなるから
  2. BRSA-2048 の解読には古典のコンピュータの方が速いことが、数学的に証明されているから
  3. C非常に多くのゲートを誤りなく実行する必要があり、誤り訂正で作った多数の論理量子ビットと、それを支える膨大な数の物理量子ビットが必要だから
答えと解説を見る

正解：C. 非常に多くのゲートを誤りなく実行する必要があり、誤り訂正で作った多数の論理量子ビットと、それを支える膨大な数の物理量子ビットが必要だから

RSA-2048 の解読には、千〜数千個程度の論理量子ビットで、数十億回規模のゲートを続けて実行する必要があります。そのため論理誤り率を極めて低くしなければならず、誤り訂正のために、1つの論理量子ビットあたり数百個以上の物理量子ビットが必要になります。2020年代の見積もりでは、誤り率0.1%程度の物理量子ビットが数十万〜数千万個程度必要とされており(前提によって大きく異なります)、現在の装置の規模とは桁違いの差があります。ただし、必要な規模の見積もりはアルゴリズムの改良で小さくなってきているので、暗号の移行の準備は早めに進める必要があります。
