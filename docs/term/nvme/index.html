NVMeとは

えぬぶいえむいー

PCI Expressで接続したSSDを高速に扱うためのインターフェースの規格。多数のコマンドを並列に処理でき、HDD向けに作られたSATAより遅延が小さい。

「NVMe」は、2分野の3問の練習問題に出てきます(SRAM・フラッシュメモリ, インターフェース・バス規格など)。

この用語の分野: SRAM・フラッシュメモリ

SSDに新しいインタフェースが必要だった理由

SATA接続のSSDは、ハードディスク向けに設計されたホストインタフェースであるAHCIを使います。コマンドキューは1本で最大32コマンドまでしか保持できず、リンク速度も約600 MB/sが上限です。フラッシュメモリは多数の要求を並列に処理できるため、これがボトルネックになりました。NVMe(NVM Express)は、PCI Expressに直接接続する不揮発性メモリ向けに設計されたプロトコルです。最大64K本のI/Oキューを持ち、各キューに最大64K個のコマンドを積めるほか、簡潔なコマンドセットを使い、CPUコアごとに専用のキューを持たせることで、ソフトウェアのオーバーヘッドやロックの競合を減らしています。

サブミッションキューとコンプリーションキュー

NVMeのキューは、ホストメモリ上のリングバッファです。読み書きを発行するとき、ドライバは64バイトのコマンドをサブミッションキューに置き、新しい末尾(テール)位置をデバイスのドアベルレジスタに書き込みます。コントローラはDMAでコマンドを取り出し、データをホストメモリとの間で直接転送し、対になるコンプリーションキューに16バイトのエントリを書き込みます。通常はMSI-X割り込みでホストに通知し、ホストはコンプリーションキューの先頭(ヘッド)ドアベルを更新します。ホストとデバイスは独立に処理を進めるので、多くの転送を同時に実行できます。

帯域幅とフォームファクタ

NVMeはPCIe上で動くため、帯域幅はリンクの世代とレーン数で決まり、PCIe 4.0 x4のドライブで約7 GB/s、PCIe 5.0 x4では10 GB/sを超えます。プロトコルのレイテンシは数マイクロ秒で、数十マイクロ秒かかるフラッシュの読み出し時間に比べて小さな値です。NVMeドライブには、小型のM.2カード、2.5インチのU.2ドライブ、拡張カードといった形態があります。注意したいのは、M.2はコネクタの規格にすぎないという点です。M.2スロットはSATAとPCIeのどちらにも対応しうるので、M.2のSSDが必ずNVMeとは限りません。NVMe over Fabrics(NVMe-oF)はこのプロトコルをネットワーク越しに拡張したものです。

管理用のコマンド

NVMeは読み書き以外に、キューの作成、コントローラの識別、ネームスペースの管理、ファームウェアの更新などを行う管理コマンドを定めています。Dataset Managementコマンドに含まれるDeallocate操作は、ATAのTRIMに相当するNVMeの機能です。どの論理ブロックがもう有用なデータを持っていないかをSSDに伝えることで、ガベージコレクションがそれらをコピーせずに消去できるようになります。これにより書き込み増幅(ライトアンプリフィケーション)が減り、持続的な書き込み性能が向上し、フラッシュの寿命も延びます。

NVMeの練習問題に挑戦

ネットワークカードやNVMeのSSDなどで広く使われる、メモリ上の記述子(ディスクリプタ)の輪(リング)を使ったDMAのしくみについて正しいものはどれか。

  1. ACPUがデータを1バイトずつ機器のレジスタに書き込んで転送する
  2. BCPUは転送の番地や長さを記述子に書いて機器に知らせるだけで、機器が記述子を読んで自分で転送を進める
  3. C記述子は機器の中にだけあり、CPUからは見えない
答えと解説を見る

正解：B. CPUは転送の番地や長さを記述子に書いて機器に知らせるだけで、機器が記述子を読んで自分で転送を進める

記述子のリングは、メインメモリ上に並べた「どの番地から何バイト送るか」を書いた表を輪のように使うしくみです。CPUは空いている記述子に転送の内容を書き、機器のレジスタに「ここまで書いた」と1回知らせます。機器はDMAで記述子を読み、データを転送し、終わった記述子に完了の印を付けます。CPUと機器が互いを待たずに多くの転送を進められます。

よくある質問

NVMeとは何の略ですか?

Non-Volatile Memory Expressの略で、NVM Expressとも書きます。PCI Express経由でSSDなどの不揮発性メモリにアクセスするための、ホストインタフェースとコマンドプロトコルの規格です。

NVMe SSDとSATA SSDの違いは?

SATA SSDは、32コマンドのキューが1本だけのAHCIプロトコルを使い、リンク速度は約600 MB/sが上限です。NVMe SSDはPCIeで接続し、数千の並列キューを持つため、数GB/sから10 GB/s超の速度と小さなソフトウェアレイテンシが得られます。

NVMeはTRIMに対応していますか?

はい。NVMeではDataset ManagementコマンドのDeallocate属性で同じ機能を提供しており、ファイルを削除したときにOSがこれを発行します。
