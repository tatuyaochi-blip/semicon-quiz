推論ランタイムとは

すいろんらんたいむ

学習済みのモデルを読み込み、グラフの最適化、量子化、ハードウェアに合ったカーネルの選択などを行って推論を速く実行するソフトウェア。

「推論ランタイム」は、1分野の2問の練習問題に出てきます(AIハードウェアとソフトウェアスタックなど)。

この用語の分野: AIハードウェアとソフトウェアスタック

推論ランタイムの練習問題に挑戦

TensorRTやONNX Runtimeのような推論ランタイムが、学習用のフレームワークでそのまま推論するより速くできる主な理由はどれか。

  1. A推論だけに必要な形にグラフを最適化し、演算の融合、量子化、ハードウェアに合ったカーネルの選択などを行うから
  2. B推論ランタイムは計算を省略して、だいたいの答えを出すから
  3. C推論ランタイムは、モデルの重みの数を増やすから
答えと解説を見る

正解：A. 推論だけに必要な形にグラフを最適化し、演算の融合、量子化、ハードウェアに合ったカーネルの選択などを行うから

学習用のフレームワークは、柔軟に書けることや逆伝播のための記録を重視しているので、推論だけに使うと無駄があります。推論ランタイムはモデルを読み込んだ後、推論に不要な部分を除き、演算を融合し、必要に応じて重みや活性化を低い精度に変え、対象のGPUやNPUで最も速いカーネルを選びます。こうして同じモデルでも遅延とメモリを大きく減らせます。

解説の中の「推論ランタイム」

  • 推論ランタイムはモデルを読み込んだ後、推論に不要な部分を除き、演算を融合し、必要に応じて重みや活性化を低い精度に変え、対象のGPUやNPUで最も速いカーネルを選びます。

    TensorRTやONNX Runtimeのような推論ランタイムが、学習用のフレームワークでそのまま推論するより速くで…

  • PyTorchなどで学習したモデルをONNXに書き出せば、別の会社の推論ランタイムや、さまざまなハードウェアの道具で読み込んで実行できます。

    ONNXの説明として正しいものはどれか。

「推論ランタイム」が出てくる問題(2問)

  1. TensorRTやONNX Runtimeのような推論ランタイムが、学習用のフレームワークでそのまま推論するより速くできる主な理由はどれか。
  2. ONNXの説明として正しいものはどれか。
