CCDイメージセンサとは

しーしーでぃーいめーじせんさ

画素の電荷をバケツリレーのように順に転送し、出力部で電圧に変換するイメージセンサ。低ノイズで画質が高かったが、消費電力が大きく、現在は多くの用途でCMOSに置き換わった。

この用語の分野: イメージセンサ・光デバイス

「CCDイメージセンサ」が出てくる問題(2問)

  1. CCDイメージセンサと比べたときの、CMOSイメージセンサの一般的な特長として正しいものはどれか。
  2. CCDイメージセンサの信号の読み出し方式として正しいものはどれか。

この用語が出てくる比較

  • CMOSイメージセンサーとCCDの違い：読み出し・速度・用途を比較CMOSイメージセンサーとCCDを、読み出し方式・消費電力・速度・ノイズ・シャッター方式・集積度・コスト・用途の観点で表にして比較します。
