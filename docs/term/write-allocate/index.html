ライトアロケートとは

らいとあろけーと

書き込みでキャッシュミスしたとき、そのラインをキャッシュに読み込んでから書き込む方式。ライトバック方式と組み合わせることが多い。読み込まずに下の階層へ直接書く方式はノーライトアロケートという。

「ライトアロケート」は、1分野の4問の練習問題に出てきます(メモリ階層と性能など)。

この用語の分野: メモリ階層と性能

書き込みミス時の動作

ライトアロケートでは、ミスしたストアはまず下位の階層からライン全体を読み込んでキャッシュに配置し、そこにストアするバイトを書き込みます。ライトバック方式のキャッシュでは、その後ラインがダーティとして記録され、後で追い出されるときに初めて主記憶に書き込まれます。マルチコアシステムでは、この読み込みと同時にラインの排他的な所有権も取得するため、書き込みの前に他のコアのコピーが無効化されます。この所有権付きの読み込み(RFO)があるため、ストアミスはメモリバス上では読み出しのように見えます。

ライトアロケートとノーライトアロケート

ノーライトアロケートでは、ミスしたストアを直接下位の階層に送り、キャッシュには手を付けません。ライトアロケートは、書いたデータをすぐにまた読み書きする場合に効果があります。後のアクセスがヒットするためで、ライトバック方式と組み合わせるのが一般的です。ノーライトアロケートは一度書いたら再利用しないデータに向いており、ライトスルー方式と組み合わせるのが一般的です。なお、ライトバックかライトスルーかはヒット時の書き込みの伝え方を決め、アロケートの有無はミス時の動作を決めるもので、両者は別々の選択です。

書き込むだけのデータでの隠れたコスト

メモリのクリアや出力の生成など、すぐには読まない大きなバッファを書き込む場合、ライトアロケートでは上書きするだけのために各ラインをまず主記憶から読み込み、後でまた書き戻すことになり、通信量がおよそ2倍になります。これらのラインは有用なデータを追い出してもしまいます。ノンテンポラル(ストリーミング)ストアは、書き込みをまとめて直接主記憶へ送ることでこれを回避します。命令セットアーキテクチャ(ISA)によっては、古い内容を読み込まずにキャッシュライン全体をゼロにする命令もあります。

関連するミス処理の技術

ライトアロケートはラインを取り込むかどうかを決めますが、ミスにかかる時間は別の技術が左右します。クリティカルワードファーストは、要求されたワードを64バイトのラインの残りより先に送り、CPUが早く処理を再開できるようにします。ライトスルー方式のキャッシュでは書き込みバッファがストアの遅延を隠し、ビクティムキャッシュは最近追い出されたラインを保持します。それぞれがミスのコストの異なる部分に対処しており、混同されやすい点です。

ライトアロケートの練習問題に挑戦

ライトスルー方式のキャッシュで、書き込みバッファを設ける主な目的はどれか。

  1. A主記憶への書き込みの完了を待たずに、CPUが次の処理に進めるようにするため
  2. Bキャッシュの中のデータを主記憶より新しい状態に保つため
  3. C書き込みでミスしたラインを、必ず先に主記憶からキャッシュへ読み込んでから書くため
答えと解説を見る

正解：A. 主記憶への書き込みの完了を待たずに、CPUが次の処理に進めるようにするため

ライトスルー方式では書き込みのたびに主記憶にも書くため、そのまま完了を待つとCPUが頻繁に止まります。書き込みバッファに書き込みを一時的にためておけば、CPUはすぐに次の命令へ進み、バッファが裏で主記憶へ書き出します。キャッシュを主記憶より新しく保つのはライトバック方式の性質で、ライトスルーではむしろ両者が一致します。ミスしたラインを読み込むかどうかはライトアロケートの選択で、書き込みバッファとは別の話です。

書き込みでキャッシュミスしたときに、そのラインを読み込まず、下の階層へ直接書き込む方式はどれか。

  1. Aライトアロケート
  2. Bライトバック
  3. Cノーライトアロケート
答えと解説を見る

正解：C. ノーライトアロケート

書き込みミスのときにラインを読み込まずに下の階層へ直接書く方式はノーライトアロケートで、ライトスルー方式と組み合わせることが多い方式です。一度書いたら読み返さないデータでは、無駄な読み込みを省けます。ライトアロケートは逆にラインを読み込んでから書き込む方式で、書いたデータをすぐまた使う場合に有利なため、ライトバック方式と組み合わせることが多くあります。ライトバックはヒットした書き込みの扱いを決める方式で、ミス時の読み込みの有無とは別の軸です。

よくある質問

ライトアロケートとノーライトアロケートの違いは何ですか?

書き込みミスのとき、ライトアロケートはラインをキャッシュに読み込んでからキャッシュに書き込みます。ノーライトアロケートはラインを読み込まずに、下位の階層へ直接書き込みます。

ライトアロケートがライトバック方式と組み合わされることが多いのはなぜですか?

ラインがライトバック方式のキャッシュに入れば、その後の書き込みはヒットしてメモリへの通信なしで吸収されるため、最初の読み込みのコストを回収できるからです。

ノンテンポラルストアは何に使われますか?

すぐには再利用しない大量のデータを、直接主記憶に書き込むために使います。ライトアロケートで発生する各ラインの読み込みを避けられ、キャッシュを有用なデータのために空けておけます。
