ライトアロケートとは

らいとあろけーと

書き込みでキャッシュミスしたとき、そのラインをキャッシュに読み込んでから書き込む方式。ライトバック方式と組み合わせることが多い。読み込まずに下の階層へ直接書く方式はノーライトアロケートという。

この用語の分野: メモリ階層と性能

解説の中の「ライトアロケート」

  • ミスしたラインを読み込むかどうかはライトアロケートの選択で、書き込みバッファとは別の話です。

    ライトスルー方式のキャッシュで、書き込みバッファを設ける主な目的はどれか。

  • ライトアロケートは逆にラインを読み込んでから書き込む方式で、書いたデータをすぐまた使う場合に有利なため、ライトバック方式と組み合わせることが多くあります。

    書き込みでキャッシュミスしたときに、そのラインを読み込まず、下の階層へ直接書き込む方式はどれか。

  • 通常の書き込みでは、ライトアロケートによりラインを主記憶から読み込んでから書くため、書くだけのデータでも読み込みの通信が発生し、再利用するほかのデータを追い出してしまいます。

「ライトアロケート」が出てくる問題(4問)

  1. ライトスルー方式のキャッシュで、書き込みバッファを設ける主な目的はどれか。
  2. 書き込みでキャッシュミスしたときに、そのラインを読み込まず、下の階層へ直接書き込む方式はどれか。
  3. 一度書いたあと当分読み返さない大きなデータを書き出すとき、キャッシュを通さないストア(ノンテンポラルストア)を使う主な利点はどれか。
  4. ミスしたラインを主記憶から読み込むとき、CPUが必要としている語(ワード)を先に送って、残りを後から送る手法はどれか。
