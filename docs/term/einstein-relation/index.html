アインシュタインの関係式とは

あいんしゅたいんのかんけいしき

キャリアの拡散係数Dと移動度μを結ぶ関係式 D = μkT/q。移動度が大きい材料ほど拡散もしやすいことを表す。

この用語の分野: 半導体物性

解説の中の「アインシュタインの関係式」

  • アインシュタインの関係式は D = μkT/q です。
