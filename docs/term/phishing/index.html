フィッシングとは

ふぃっしんぐ

実在の企業や組織を装ったメールやSMSなどで偽のWebサイトに誘導し、IDやパスワード、クレジットカードの番号などを入力させて盗む詐欺の手口。

「フィッシング」は、2分野の6問の練習問題に出てきます(情報セキュリティの基礎, サイバー攻撃と防御の実務など)。

この用語の分野: 情報セキュリティの基礎

フィッシングの練習問題に挑戦

フィッシングの手口と、利用者側の対策の組み合わせとして正しいものはどれか。

  1. A大量のパケットを送りつけてサーバを止める。サーバの回線を太くする
  2. Bパソコンのファイルを暗号化して身代金を要求する。オフラインのバックアップを取っておく
  3. C実在の企業などを装ったメールやSMSで偽のWebサイトに誘導し、IDやパスワード、カードの番号などを入力させて盗む。メールのリンクからではなく、ブックマークや公式のアプリからアクセスする
答えと解説を見る

正解：C. 実在の企業などを装ったメールやSMSで偽のWebサイトに誘導し、IDやパスワード、カードの番号などを入力させて盗む。メールのリンクからではなく、ブックマークや公式のアプリからアクセスする

フィッシングは、金融機関、通販サイト、配送業者、公的機関などを装ったメールやSMS(SMSを使うものはスミッシングとも呼ばれます)で、本物そっくりの偽のWebサイトに誘導し、IDとパスワード、クレジットカードの番号、ワンタイムパスワードなどを入力させて盗む手口です。偽のサイトのURLには、本物とよく似たドメイン名が使われることが多く、見た目だけで見分けるのは難しくなっています。利用者側では、メールやSMSのリンクから重要な情報を入力しない、ブックマークや公式のアプリから開く、多要素認証を有効にする、といった対策が有効です。サービスの側では、送信ドメイン認証(SPF、DKIM、DMARC)で、自社を装ったメールが届きにくくする対策もあります。

FIDO2(WebAuthn)のパスキーによる認証が、ワンタイムパスワード(OTP)と比べて、フィッシングに強いとされる理由として、正しいものはどれか。

  1. A秘密鍵による署名が接続先のドメインに結び付くので、偽のサイトでは本物のサイト用の署名が作られず、中継しても使えない
  2. Bパスキーは6桁の数字なので、OTPより桁数が少なく、利用者が偽のサイトに入力してしまうまでの時間も短くなるから
  3. Cパスキーでは、サーバに利用者のパスワードを保存しておくので、偽のサイトに入力されても、サーバでの照合で見破れるから
答えと解説を見る

正解：A. 秘密鍵による署名が接続先のドメインに結び付くので、偽のサイトでは本物のサイト用の署名が作られず、中継しても使えない

OTPは利用者が画面を見て入力する値なので、偽のサイトに入力させ、その値をすぐに本物のサイトへ中継する攻撃(中間者型のフィッシング)を防げません。FIDO2では、サイトごとに公開鍵と秘密鍵の組を作って公開鍵だけをサイトに登録し、ログインのときは、サイトから送られた値(チャレンジ)に秘密鍵で署名します。どのサイト用の鍵を使うかは、ブラウザが確かめた実際の接続先のドメインで決まり、署名される情報にもその接続先が含まれるので、偽のサイトでは本物のサイト用の署名を得られません。また、サーバには公開鍵しか保存されないので、サーバから漏えいしても、なりすましには使えません。

    ソーシャルエンジニアリングの例として当てはまるものはどれか。

「フィッシング」が出てくる問題(6問)

  1. フィッシングの手口と、利用者側の対策の組み合わせとして正しいものはどれか。
  2. FIDO2(WebAuthn)のパスキーによる認証が、ワンタイムパスワード(OTP)と比べて、フィッシングに強いとされる理由として、正しいものはどれか。
  3. 次の認証の方法のうち、多要素認証に当たるものはどれか。
  4. ソーシャルエンジニアリングの例として当てはまるものはどれか。
  5. 攻撃者が社員のパスワードを入手し、ログインを何十回も繰り返して、社員のスマートフォンに承認を求める通知を大量に送りつけた。社員はわずらわしくなり、つい「承認」を押してしまった。この攻撃への対策として、最も適切なものはどれか。
  6. 多要素認証を使っているクラウドのメールサービスで、社員が本物そっくりのログインの画面に誘導され、パスワードとワンタイムパスワードを入力した。攻撃者はその画面を本物のサービスとの中継に使い、ログインの後に発行されたセッションのCookieを盗んで、社員になりすました。この攻撃と対策の説明として、最も適切なものはどれか。
