中間表現とは

ちゅうかんひょうげん

コンパイラの内部で、ソース言語にもCPUにも依存しない形でプログラムを表したもの。最適化の多くはこの上で行い、言語ごとの前半とCPUごとの後半を分けられる。

「中間表現」は、1分野の6問の練習問題に出てきます(コンパイラなど)。

この用語の分野: コンパイラ

コンパイラが中間表現を使う理由

M種類のソース言語をN種類のプロセッサに対応させるのに個別のコンパイラを作ると、M × N個が必要になります。共通の中間表現(IR)があれば、言語ごとにIRへ変換するフロントエンドを、プロセッサごとにIRから変換するバックエンドを用意するだけでよく、合計M + N個で済みます。IR上に一度書いた最適化は、すべての言語とターゲットで役立ちます。最もよく知られた例がLLVMで、ClangなどのフロントエンドがLLVM IRを出力し、バックエンドがx86、Arm、RISC-Vなどのコードを生成します。

代表的な形式

コンパイラは複数のレベルのIRを使うことがよくあります。ソースに近い段階には抽象構文木があります。より低いレベルでは、3番地コードが式を t1 = a + b; x = t1 * c のような単純な手順に分解し、中間値には一時変数を使います。これらの命令は基本ブロックにまとめられ、制御フローグラフでつながれます。LLVM IRを含む現代の多くのIRは静的単一代入(SSA)形式を採用しています。各変数への代入はちょうど1回で、制御の経路が合流する場所ではφ(ファイ)関数と呼ばれる特別なノードが値を合流させます。

IR上で行われる処理

最適化パスの大部分はIR上で実行されます。定数伝播、不要コード除去、共通部分式の削除、ループ不変な計算のループ外への移動、関数のインライン展開などです。SSA形式では、変数のすべての使用箇所がちょうど1つの定義を指すため、これらの多くが簡単になります。リンク時最適化(LTO)では、オブジェクトファイルに機械語ではなくIRを格納しておき、プログラム全体をまとめて最適化することで、ソースファイルをまたいだインライン展開や未使用関数の削除を可能にします。

IRとバイトコード、機械語の違い

コンパイラ内部のIRは解析と変換のための作業用の形式で、CPUはそれを実行できません。バックエンドはさらに命令選択、レジスタ割り当て、命令スケジューリングを行う必要があります。JavaバイトコードやWebAssemblyのような移植可能なバイトコードも関連はありますが、目的が異なります。これらは仮想マシンがインタプリタで実行したりJITコンパイルしたりする安定した配布形式であるのに対し、内部のIRはコンパイラのバージョン間で変わることがあります。

中間表現の練習問題に挑戦

コンパイラの内部で、ソース言語にもCPUにも依存しない中間表現(IR)を使う主な利点はどれか。

  1. A中間表現を使うと、ソースコードを読まずにコンパイルできるようになるから
  2. B中間表現はCPUがそのまま実行できるので、機械語の生成が不要になるから
  3. C言語ごとの前半とCPUごとの後半を分けられ、最適化も共通に使えるから
答えと解説を見る

正解：C. 言語ごとの前半とCPUごとの後半を分けられ、最適化も共通に使えるから

M種類の言語とN種類のCPUに対応するとき、組み合わせごとにコンパイラを作るとM×N個必要ですが、共通の中間表現を介せば、言語から中間表現への前半(フロントエンド)M個と、中間表現からCPUへの後半(バックエンド)N個で済みます。最適化の多くも中間表現の上で一度作れば、すべての言語とCPUで使えます。中間表現はCPUがそのまま実行できるものではなく、最後に機械語へ変換する必要があります。

SSA形式の中間表現の特徴として正しいものはどれか。

  1. A各変数への代入がプログラム中でちょうど1回になる
  2. Bすべての変数が、レジスタではなくメモリ上に置かれる
  3. C条件分岐の命令を一切含まない形に書き直される
答えと解説を見る

正解：A. 各変数への代入がプログラム中でちょうど1回になる

SSA形式では、変数への代入が1回になるよう名前を付け替え、合流点ではφ関数で値を選びます。例えば x を2回代入するなら x1 と x2 に分け、どちらが使われているかを明確にします。定義と使用の関係がはっきりするため、定数伝播や不要コードの削除などの最適化がしやすくなります。分岐はφ関数で扱うので、分岐命令がなくなるわけではありません。変数がメモリに置かれる形でもなく、多くはレジスタの候補として扱われます。

よくある質問

コンパイラの中間表現とは何ですか?

コンパイラが機械語を生成する前にソースコードを変換する形式で、ソース言語にもターゲットのCPUにも依存しません。そのため最適化を共通化できます。

SSA形式とは何ですか?

静的単一代入(SSA)形式は、すべての変数への代入がちょうど1回になるIRの形式です。制御フローが合流する場所ではφ関数が値を選択します。多くの最適化が簡単になります。

LLVM IRは機械語ですか?

いいえ。LLVM IRはターゲットに依存しない中間表現で、特定のプロセッサ向けの機械語にするにはバックエンドで変換する必要があります。
