パレート図とは

ぱれーとず

不良の項目などを件数の多い順に棒グラフで並べ、累積の割合を折れ線で重ねた図。重点的に対策すべき項目を見つけるのに使う。

「パレート図」は、2分野の6問の練習問題に出てきます(歩留まり・品質管理, テスト・検査など)。

この用語の分野: 歩留まり・品質管理

パレート図の練習問題に挑戦

品質管理で使われるパレート図の目的として正しいものはどれか。

  1. A2つの変数の相関関係を調べる
  2. B時系列で工程の異常を監視する
  3. C不良の項目を件数の多い順に並べ、重点的に対策すべき項目を見つける
答えと解説を見る

正解：C. 不良の項目を件数の多い順に並べ、重点的に対策すべき項目を見つける

パレート図は、不良の項目や原因を件数(または損失金額)の多い順に棒グラフで並べ、累積比率の折れ線を重ねた図です。上位の2〜3項目で全体の7〜8割を占めることが多い(パレートの法則)ため、限られた人手でどこから手を付けるべきかがひと目でわかります。2つの変数の相関を見るのは散布図、時系列で工程の異常を監視するのは管理図です。

解説の中の「パレート図」

  • パレート図は、不良の項目や原因を件数(または損失金額)の多い順に棒グラフで並べ、累積比率の折れ線を重ねた図です。

    品質管理で使われるパレート図の目的として正しいものはどれか。

  • パレート図は不良の多い順の棒グラフ、ウエハマップはチップの位置ごとの結果です。

    電源電圧や動作周波数などの条件を変えながら合否を調べ、その結果を2次元の図にまとめたものを何と呼ぶか。

  • パレート図は件数の順位、ヒストグラムは分布を表します。

    問題(結果)と、それに影響を与える要因の関係を、魚の骨のような形に整理した図はどれか。

  • パレート図とヒストグラムは既に起きたデータの分析に使います。

    製品や工程で起こりうる故障モードを洗い出し、その影響と重要度を評価して、事前に対策を講じる手法はどれか。

  • パレート図は項目の順位、管理図は時間とともに工程が安定しているかを見るのに使います。

    2つの特性値の組をプロットし、それらの相関関係を調べるための図はどれか。

「パレート図」が出てくる問題(6問)

  1. 品質管理で使われるパレート図の目的として正しいものはどれか。
  2. 電源電圧や動作周波数などの条件を変えながら合否を調べ、その結果を2次元の図にまとめたものを何と呼ぶか。
  3. 問題(結果)と、それに影響を与える要因の関係を、魚の骨のような形に整理した図はどれか。
  4. 製品や工程で起こりうる故障モードを洗い出し、その影響と重要度を評価して、事前に対策を講じる手法はどれか。
  5. 2つの特性値の組をプロットし、それらの相関関係を調べるための図はどれか。
  6. QC七つ道具の一つで、確認すべき項目をあらかじめ表にしておき、点検の結果や不良の発生を記録・集計しやすくするものはどれか。
