AFM(原子間力顕微鏡)とは

えーえふえむ

鋭い探針で試料の表面をなぞり、探針と表面の間に働く力から表面の微細な凹凸を測る顕微鏡。表面の粗さの評価などに使われる。

「AFM(原子間力顕微鏡)」は、1分野の7問の練習問題に出てきます(計測・分析など)。

この用語の分野: 計測・分析

AFM(原子間力顕微鏡)の練習問題に挑戦

原子間力顕微鏡(AFM)で主に測定するものはどれか。

  1. Aシート抵抗
  2. B不純物濃度の深さ方向の分布
  3. C表面の微細な凹凸(形状や粗さ)
答えと解説を見る

正解：C. 表面の微細な凹凸(形状や粗さ)

AFMは、先端の鋭い探針を付けた板ばね(カンチレバー)で表面をなぞり、原子間力によるたわみをレーザーの反射で検出しながら走査して、表面の凹凸を測定します。高さ方向は0.1 nm程度の違いも測れるため、CMP後の表面粗さや薄膜の表面状態の評価に使われます。探針を振動させて軽く触れるタッピングモードなら試料を傷めにくくなります。シート抵抗やドーパントの分布は別の手法で測ります。

AFMで、非常に細い溝や急な側壁の形を測るときに誤差の原因になりやすいことはどれか。

  1. AAFMは真空中でしか使えない
  2. B探針の先端の太さや形が有限であるため、測った形に探針の形が重なって写ってしまう
  3. CAFMは表面の凹凸を測れない
答えと解説を見る

正解：B. 探針の先端の太さや形が有限であるため、測った形に探針の形が重なって写ってしまう

AFMは探針で表面をなぞって形を測るため、探針の先端より細い溝の底には届かず、急な側壁では探針の側面が先に当たります。その結果、測った形は実際の形と探針の形を重ね合わせたものになり、溝は浅く狭く、線は太く見えます。先の細い探針や、先端が横に広がった側壁測定用の探針を使い、探針の形を推定して補正する解析も行います。

「AFM(原子間力顕微鏡)」が出てくる問題(7問)

  1. 原子間力顕微鏡(AFM)で主に測定するものはどれか。
  2. AFMで、非常に細い溝や急な側壁の形を測るときに誤差の原因になりやすいことはどれか。
  3. 複数の異なる計測手法(光学式・CD-SEM・AFMなど)のデータを組み合わせて、一つの手法だけより正確に寸法や形状を求める考え方を何と呼ぶか。
  4. 4探針法で主に測定するものはどれか。
  5. X線を照射して放出される光電子のエネルギーから、表面の元素と化学結合状態を調べる分析法はどれか。
  6. SIMSが不純物の原子の濃度を測るのに対して、電気的に活性なキャリアの濃度の深さ方向分布を測る方法として正しいものはどれか。
  7. 細い針で試料の表面をなぞり、針の上下の動きから段差の高さや表面の形を測る装置はどれか。
