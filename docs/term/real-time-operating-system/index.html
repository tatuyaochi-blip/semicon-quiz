RTOS(リアルタイムOS)とは

あーるとす

複数のタスクを優先度に従って切り替え、決められた時間内に応答できるようにする組込み向けのOS。FreeRTOSやZephyrなど。

この用語の分野: 組込み・ファームウェア

解説の中の「RTOS(リアルタイムOS)」

  • RTOSは、処理をタスクに分け、優先度の高いタスクが実行できるようになったらすぐに切り替えて動かします。

    組込み機器でRTOS(リアルタイムOS)を使う主な目的はどれか。

  • プリエンプティブなRTOSでは、割り込みなどをきっかけに優先度の高いタスクが実行できる状態になると、カーネルが実行中の低いタスクの状態を保存して止め、高いタスクに切り替えます。

    プリエンプティブなRTOSで、優先度の低いタスクの実行中に、優先度の高いタスクが待っていたデータを受け取って実行できる…

  • RTOSのキューを使えば、送る側はデータを入れるだけ、受け取る側はデータが来るまで待ち状態でCPUを使わずに待てます。

    RTOSで、センサを読むタスクから表示するタスクへデータを渡すのに、キュー(メッセージキュー)を使う利点として正しいも…

「RTOS(リアルタイムOS)」が出てくる問題(7問)

  1. 組込み機器でRTOS(リアルタイムOS)を使う主な目的はどれか。
  2. プリエンプティブなRTOSで、優先度の低いタスクの実行中に、優先度の高いタスクが待っていたデータを受け取って実行できる状態になった。一般にどうなるか。
  3. RTOSで起こる優先度逆転の説明として正しいものはどれか。
  4. RTOSで、センサを読むタスクから表示するタスクへデータを渡すのに、キュー(メッセージキュー)を使う利点として正しいものはどれか。
  5. 16 MHzのクロックをプリスケーラで16分周したものでタイマを数え、1000カウントごとに割り込みを起こす設定にした。割り込みの間隔はいくらか。
  6. OSを使わないマイコンのプログラムでよく見られる「スーパーループ」の構成の説明として正しいものはどれか。
  7. 優先度逆転を防ぐために使われる「優先度継承」の考え方として正しいものはどれか。
