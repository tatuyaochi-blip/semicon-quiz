SiC(炭化ケイ素)とは

たんかけいそ

バンドギャップ約3.3 eVのワイドギャップ半導体。絶縁破壊電界が高く、高耐圧・低損失のパワーデバイスに使われる。

「SiC(炭化ケイ素)」は、10分野の49問の練習問題に出てきます(パワー半導体, 化合物半導体, エピタキシャル成長など)。

この用語の分野: パワー半導体

ワイドバンドギャップが効く理由

SiCのバンドギャップは約3.3 eVで、絶縁破壊電界は約3 MV/cmとシリコンのおよそ10倍です。同じ耐圧ならドリフト層を約10分の1の厚さ、約100倍のドーピング濃度にできるため、理論上は抵抗を数百分の1にできます。バリガ性能指数εμEc³では絶縁破壊電界が3乗で効くため、この差がよく表れます。ギャップが広いおかげで高温でも真性キャリア密度が低く保たれ、熱伝導率もシリコンの約3倍の約400 W/(m·K)あります。

電力変換器でのSiCデバイス

主力はSiC MOSFETとSiCショットキーバリアダイオード(SBD)です。ユニポーラ素子なので、シリコンIGBTのテール電流やシリコンpnダイオードの逆回復電流がなく、スイッチング損失が大きく減ります。SiC SBDは600〜1700 V品がつくられています。損失が減るとスイッチング周波数を上げてインダクタ、コンデンサ、冷却系を小さくできるため、SiCは電気自動車のインバータ、特に800 Vシステムに広がりました。高速化の代償は数十V/nsという急峻なdv/dtで、わずかな寄生インダクタンスがサージ電圧やEMIの原因になるため、レイアウトとゲート駆動が重要です。

ゲート駆動と堅牢性

SiC MOSFETは通常、オン時に約+15〜+18 Vで駆動し、オフ時にも−3〜−5 Vの負バイアスをかけることがよくあります。しきい値電圧が約2〜3 Vと低いため、負バイアスがないと、対向側スイッチのdv/dtによるミラー電流で誤点弧するおそれがあるからです。チップが小さく熱容量も小さいため、短絡耐量時間は通常数µsと、シリコンIGBTの約10 µsより短く、保護回路はより速く動作する必要があります。ケルビンソース端子付きのパッケージは、ゲート駆動の戻り経路を主電流経路から分離し、共通ソースインダクタンスによる問題を避けます。

SiCの製造が難しい理由

SiCは常圧では融解しないため、インゴットは2000〜2500 °Cでの昇華法(物理気相輸送法)で育成しますが、成長速度は毎時約0.1〜1 mmにすぎず、非常に硬い結晶は切断や研磨にも時間がかかります。パワーデバイスには4H-SiCポリタイプを使い、約4°のオフ角をつけた基板上に1500〜1650 °Cのステップフロー成長でエピ層を形成します。ドーパントはほとんど拡散しないため、接合はエピタキシャル成長と高温イオン注入、その後の1600〜1800 °Cのアニールでつくります。信頼性の課題には、炭素に関連した酸化膜界面の欠陥によるチャネル移動度の低さや、基底面転位が積層欠陥に成長するバイポーラ劣化があります。

  2. BバンドギャップがSiより小さいため
  3. CウエハがSiより安価で大口径化しやすいため
答えと解説を見る

正解：A. 絶縁破壊電界がSiの約10倍と高いため

SiCはバンドギャップが約3.3 eVと大きく、絶縁破壊電界がSiの約10倍(約3 MV/cm)あります。同じ耐圧ならドリフト層を約1/10の厚さにでき、不純物濃度を約100倍にできるため、ドリフト層の抵抗は理論上数百分の1になります。熱伝導率もSiの約3倍で高温に強く、EVのインバータなどで採用が広がっています。一方、ウエハはSiより高価で、大口径化(8インチ)は途上です。

SiCやGaNのように、シリコンよりバンドギャップが大きい半導体の総称はどれか。

  1. Aワイドバンドギャップ半導体
  2. Bナローギャップ半導体
  3. Cアモルファス半導体
答えと解説を見る

正解：A. ワイドバンドギャップ半導体

バンドギャップがおおむね2〜3 eV以上の半導体をワイドバンドギャップ半導体と呼び、SiC(約3.3 eV)やGaN(約3.4 eV)が代表です。絶縁破壊電界が高く、真性キャリアが少ないため高温でも動作しやすく、高耐圧・低損失のパワーデバイスや高周波デバイスに使われます。さらに大きいGa2O3(約4.8 eV)やダイヤモンド(約5.5 eV)は、ウルトラワイドバンドギャップ半導体と呼ばれます。

よくある質問

高耐圧のパワーデバイスでSiCがシリコンより優れているのはなぜですか?

SiCの絶縁破壊電界はシリコンの約10倍なので、より薄く高濃度のドリフト層で同じ電圧を阻止でき、抵抗を大幅に下げられます。高温にも強く熱伝導もよいため、損失と冷却の負担をともに減らせます。

SiCとGaNのパワーデバイスの違いは?

どちらもワイドバンドギャップ半導体で、ギャップはそれぞれ約3.3 eVと約3.4 eVです。SiCは同じ材料の基板上につくられ、主に高電圧・大電流向けの縦型MOSFETやダイオードに使われます。GaNパワートランジスタは通常、シリコンなどの異種基板上に成長させた横型HEMTで、中程度の電圧での非常に高速なスイッチングに優れています。

4H-SiCとは何ですか?

4層周期の六方晶の積層構造をもつ炭化ケイ素のポリタイプ(結晶多形)です。約3.26 eVのバンドギャップ、約1000 cm²/V·sの電子移動度、比較的小さい異方性を兼ね備えるため、パワーデバイスの標準になっています。
