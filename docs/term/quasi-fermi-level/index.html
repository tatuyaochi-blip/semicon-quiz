擬フェルミ準位とは

ぎふぇるみじゅんい

光の照射や電流の注入で熱平衡から外れた半導体で、電子密度と正孔密度を別々に表すために導入するフェルミ準位。両者の差が開くほど注入されたキャリアが多い。

「擬フェルミ準位」は、1分野の1問の練習問題に出てきます(半導体物性など)。

この用語の分野: 半導体物性

なぜ2つのフェルミ準位が必要か

熱平衡の半導体では、電子と正孔の密度はどちらも1つのフェルミ準位で決まり、積np = ni²が成り立ちます。光を当てたり、PN接合に順方向の電流を流したりすると、電子と正孔が平衡より多く存在してnp > ni²となり、1つのフェルミ準位では表せなくなります。ただし電子どうし、正孔どうしは、それぞれのバンドの中で再結合よりずっと速く熱平衡に近づきます。そこで電子と正孔に別々のフェルミ準位を当てはめて密度を表します。これが擬フェルミ準位で、Fermiを逆につづったイムレフ(Imref)とも呼ばれます。

定義と式

電子の擬フェルミ準位をEFn、正孔の擬フェルミ準位をEFpとすると、非縮退の半導体ではn = ni·exp((EFn − Ei)/kT)、p = ni·exp((Ei − EFp)/kT)と表せます。Eiは真性フェルミ準位です。2つを掛け合わせるとnp = ni²·exp((EFn − EFp)/kT)となり、両者の差が大きいほど過剰なキャリアが多いことがわかります。熱平衡に戻ると2つは一致し、ふつうのフェルミ準位になります。低注入の状態では、少数キャリアの擬フェルミ準位は大きく動き、多数キャリアの擬フェルミ準位はほとんど動きません。

PN接合と太陽電池の電圧

順方向バイアスのPN接合では、空乏層の中で擬フェルミ準位がほぼ平らに保たれ、その差はかけた電圧にほぼ等しくなります(EFn − EFp ≈ qV)。このため空乏層の端の少数キャリア密度は平衡の値のexp(qV/kT)倍になり、ダイオードの電流の式が導かれます。太陽電池では、光で生じたキャリアによって擬フェルミ準位が分かれ、端子を開いたときの差が開放電圧に対応します。半導体レーザーでは、擬フェルミ準位の差が光子のエネルギーより大きくなると誘導放出による利得が生じ、これが発振の前提になります。

電流と擬フェルミ準位の傾き

擬フェルミ準位を使うと、ドリフト電流と拡散電流をまとめて表せます。電子の電流密度はJn = n·µn·dEFn/dx、正孔の電流密度はJp = p·µp·dEFp/dxと書けます。つまり電流は擬フェルミ準位の傾きに比例して流れ、傾きがなければ電流は流れません。キャリア密度の高い領域では、大きな電流が流れていても擬フェルミ準位はほとんど傾きません。デバイスシミュレータでも、擬フェルミ準位やそれに対応する電位を変数として、電流の連続の式を解く方法がよく使われます。

擬フェルミ準位の練習問題に挑戦

光の照射や電流の注入によって熱平衡から外れた半導体で、電子密度と正孔密度をそれぞれ表すために導入される準位を何と呼ぶか。

  1. Aドナー準位
  2. B擬フェルミ準位
  3. C真性フェルミ準位
答えと解説を見る

正解：B. 擬フェルミ準位

光の照射や電流の注入で熱平衡から外れると、1つのフェルミ準位では電子と正孔の密度を同時に表せません。そこで電子用と正孔用の擬フェルミ準位(イムレフ)を別々に定め、n = ni·exp((EFn−Ei)/kT) のように扱います。両者の差は np = ni²·exp(ΔEF/kT) の関係を通じて、PN接合にかかる電圧や太陽電池の開放電圧に対応します。電流は擬フェルミ準位の傾きに比例して流れます。

よくある質問

擬フェルミ準位とは何ですか?

光の照射や電流の注入で熱平衡から外れた半導体で、電子と正孔の密度をそれぞれ表すために別々に定めるフェルミ準位です。電子用をEFn、正孔用をEFpと書き、熱平衡では両者が一致します。

擬フェルミ準位の差は何を表しますか?

過剰なキャリアの多さを表し、np = ni²·exp((EFn − EFp)/kT)の関係があります。PN接合では差がかけた電圧に、太陽電池では端子を開いたときの差が開放電圧に対応します。

フェルミ準位と擬フェルミ準位の違いは?

フェルミ準位は、熱平衡で電子と正孔の両方の分布を1つで表す準位です。擬フェルミ準位は非平衡の状態で、電子と正孔がそれぞれのバンドの中ではほぼ平衡にあると見なし、別々に定める準位です。
