仮想記憶とは

かそうきおく

プログラムが使うアドレス(仮想アドレス)を、OSとハードウェアが実際のメモリの番地(物理アドレス)に対応させる仕組み。各プログラムが広く独立したメモリ空間を使える。

「仮想記憶」は、2分野の2問の練習問題に出てきます(CPU・アーキテクチャ, OSとハードウェアなど)。

この用語の分野: CPU・アーキテクチャ

アドレス変換の仕組み

メモリは固定サイズのページ、一般には4 KBに分割されます。仮想アドレスは仮想ページ番号とページ内オフセットに分かれ、4 KBページならオフセットは12ビットです。MMU(メモリ管理ユニット)はページテーブルで仮想ページ番号を引き、物理フレーム番号と、存在・書き込み可・実行可・ユーザーアクセス可などの権限ビットを得ます。オフセットはそのままコピーされます。テーブルを小さく保つために木構造で構成され、48ビット仮想アドレスのx86-64では4段で、各段は9ビットのアドレスでインデックスされます。

TLBとヒュージページ

4段のテーブルをたどると、ロード1回につき4回のメモリアクセスがかかりかねません。そこでTLB(変換索引バッファ)が最近の変換結果をキャッシュし、大半のアクセスはそこでヒットします。TLBのエントリ数は数十から数千程度しかなく、カバーできる範囲はエントリ数×ページサイズです。4 KBのエントリ約1000個では4 MBしかカバーできません。ワーキングセットが大きいプログラムはミスが多くなるため、OSは2 MBなどのヒュージページを提供し、同じエントリ数でGB単位をカバーできるようにしています。アドレス空間識別子を使うと、TLBは複数のプロセスのエントリを同時に保持できます。

ページフォールトとデマンドページング

エントリが「存在しない」とされていると、アクセスはページフォールトを起こし、OSが処理を引き継ぎます。OSは、ゼロで初期化した新しいページを割り当てる、ファイルやスワップ領域からページを読み込む、あるいは不正なアクセスを検出してセグメンテーション違反としてプログラムを終了させる、のいずれかを行います。これにより、触れたときだけページを読み込むデマンドページング、メモリマップトファイル、どれかが書き込むまでプロセス間でページを共有するコピーオンライトが可能になります。ワーキングセットが物理メモリを大幅に超えると、スワップが絶え間なく起こるスラッシングが発生し、システムは極端に遅くなります。

仮想記憶とキャッシュの違い

キャッシュと仮想記憶はどちらもメモリ階層に関わるため混同されがちですが、役割は異なります。キャッシュは最近使ったデータのハードウェア管理のコピーで、純粋に速度のためにあり、ソフトウェアからは見えません。仮想記憶はOSが管理する対応付けで、各プロセスに独自のアドレス空間を与え、プロセス間やカーネルとの保護を強制し、共通ライブラリのように物理ページを共有できるようにします。日常的には仮想記憶がスワップファイルだけを指すこともありますが、それは仮想記憶が可能にする機能の一つにすぎません。

仮想記憶の練習問題に挑戦

仮想アドレスから物理アドレスへの変換結果を保持し、アドレス変換を高速化するキャッシュはどれか。

  1. AL3キャッシュ
  2. BTLB(変換索引バッファ)
  3. Cレジスタファイル
答えと解説を見る

正解：B. TLB(変換索引バッファ)

仮想記憶では、プログラムが使う仮想アドレスを物理アドレスに変換する必要があり、変換表(ページテーブル)はメモリ上にあるため、毎回参照すると何度もメモリにアクセスすることになります。そこで最近使った変換結果をTLBに保持します。TLBは数十〜数千項目と小さく、扱うメモリが広いとミスが増えるため、2 MBなどの大きなページ(ヒュージページ)でTLBの守備範囲を広げることもあります。

ページテーブルの役割として正しいものはどれか。

  1. A仮想アドレスのページ番号を、物理アドレスのページ番号に対応づける
  2. B物理メモリにあるデータの内容を、ページごとに複製して保存する
  3. C実行中のプロセスの優先度を、ページの順番に並べて管理する
答えと解説を見る

正解：A. 仮想アドレスのページ番号を、物理アドレスのページ番号に対応づける

仮想記憶では、プログラムが使う仮想アドレスを、実際の物理メモリのアドレスに変換して使います。ページテーブルは、仮想ページの番号ごとに、対応する物理ページの番号と、読み書きの許可などの保護の情報を記録した表で、OSがプロセスごとに作り、CPUのMMUが参照します。よく使う変換結果はTLBに保持されます。データの内容そのものを複製したり、プロセスの優先度を管理したりする表ではありません。

よくある質問

ページテーブルとTLBの違いは何ですか?

ページテーブルは仮想ページから物理ページへの完全な対応表で、メモリ上に置かれOSが管理します。TLBはCPU内の小さなハードウェアキャッシュで、最近使ったエントリを保持し、大半の変換でテーブルをたどらずに済むようにします。

ページフォールトが起きると何が行われますか?

CPUはフォールトを起こした命令を止めてOSに制御を渡します。OSは、ディスクから読み込むなどして有効なページを割り当てて命令を再実行させるか、不正なアクセスであればプロセスを終了させます。

ヒュージページを使うのはなぜですか?

TLBの1エントリがはるかに広いメモリをカバーするようになり、ワーキングセットの大きいプログラムでTLBミスやテーブルウォークが減るからです。データベースや仮想マシンでよく使われます。
