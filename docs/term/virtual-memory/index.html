仮想記憶とは

かそうきおく

プログラムが使うアドレス(仮想アドレス)を、OSとハードウェアが実際のメモリの番地(物理アドレス)に対応させる仕組み。各プログラムが広く独立したメモリ空間を使える。

この用語の分野: CPU・アーキテクチャ

解説の中の「仮想記憶」

  • 仮想記憶では、プログラムが使う仮想アドレスを物理アドレスに変換する必要があり、変換表(ページテーブル)はメモリ上にあるため、毎回参照すると何度もメモリにアクセスすることになります。

    仮想アドレスから物理アドレスへの変換結果を保持し、アドレス変換を高速化するキャッシュはどれか。

「仮想記憶」が出てくる問題(1問)

  1. 仮想アドレスから物理アドレスへの変換結果を保持し、アドレス変換を高速化するキャッシュはどれか。
