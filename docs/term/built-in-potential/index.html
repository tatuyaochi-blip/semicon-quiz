内蔵電位とは

ないぞうでんい

PN接合の空乏層に、外から電圧をかけなくても生じている電位差。シリコンでは0.6〜0.8 V程度で、キャリアの拡散を止める障壁になる。

この用語の分野: PN接合・ダイオード

解説の中の「内蔵電位」

  • 内蔵電位は Vbi = (kT/q)·ln(NA·ND/ni²) で、両側の不純物濃度が高いほど大きくなります。

    PN接合の内蔵電位(拡散電位)と、両側の不純物濃度の関係として正しいものはどれか。

  • その傾きから低濃度側の不純物濃度N、切片から内蔵電位が求まり、これがC-V測定の基本です。

    片側階段接合の空乏層の幅と逆バイアス電圧Vの関係として正しいものはどれか。(Vが内蔵電位より十分大きい場合)

  • 熱平衡では接合した物質どうしでフェルミ準位が一直線にそろい、その結果PN接合の内蔵電位やMOSのフラットバンド電圧が生まれます。

    フェルミ準位の意味として正しいものはどれか。

「内蔵電位」が出てくる問題(7問)

  1. PN接合の内蔵電位(拡散電位)と、両側の不純物濃度の関係として正しいものはどれか。
  2. 片側階段接合の空乏層の幅と逆バイアス電圧Vの関係として正しいものはどれか。(Vが内蔵電位より十分大きい場合)
  3. フェルミ準位の意味として正しいものはどれか。
  4. p型半導体の多数キャリアはどれか。
  5. PN接合ダイオードに順方向バイアスを加えるときの電圧のかけ方として正しいものはどれか。
  6. PN接合に加える逆方向バイアス電圧を大きくすると、空乏層の幅はどうなるか。
  7. 階段接合のPN接合に逆バイアスを加えたとき、電界が最も強くなる場所はどこか。
