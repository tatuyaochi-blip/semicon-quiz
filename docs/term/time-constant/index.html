時定数とは

じていすう

RC回路などのステップ応答の速さを表す量で、RC回路では τ = RC。τの時間で最終値の約63%に達し、約5τでほぼ落ち着く。

この用語の分野: アナログ・電子回路

解説の中の「時定数」

  • このRCが時定数τで、2τで約86%、3τで約95%、5τで99%以上になり、実用上は5τで充電完了とみなします。

    RC回路のステップ応答で、コンデンサの電圧が最終値の約63%に達するまでの時間はどれか。

  • Nビット精度まで落ち着くには時定数の約(N+1)·ln2倍の時間が必要です。

    逐次比較型ADコンバータの入力の前に、オペアンプなどのドライバ回路を置く主な理由はどれか。

  • RC回路の整定なので、1/2 LSBまで落ち着くには時定数の(N+1)·ln2倍、12ビットなら約9倍が必要です。

    サンプルホールド回路の「アクイジション時間」の説明として正しいものはどれか。

「時定数」が出てくる問題(3問)

  1. RC回路のステップ応答で、コンデンサの電圧が最終値の約63%に達するまでの時間はどれか。
  2. 逐次比較型ADコンバータの入力の前に、オペアンプなどのドライバ回路を置く主な理由はどれか。
  3. サンプルホールド回路の「アクイジション時間」の説明として正しいものはどれか。
