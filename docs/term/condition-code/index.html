条件コードとは

じょうけんこーど

比較や演算の結果、ゼロ・負・桁上がり・あふれなどを示すフラグ。x86やARMの条件分岐はこれを見て分岐する。RISC-Vは条件コードを持たない。

「条件コード」は、1分野の1問の練習問題に出てきます(命令セット・アセンブリなど)。

この用語の分野: 命令セット・アセンブリ

条件コードの練習問題に挑戦

条件分岐のしくみについて、RISC-Vとx86の違いとして正しいものはどれか。

  1. ARISC-Vはフラグを見て分岐し、x86は分岐命令が2つのレジスタを直接比べる
  2. Bどちらも条件分岐の命令を持たず、表引きでジャンプ先を決める
  3. CRISC-Vは分岐命令が2つのレジスタを直接比べ、x86は比較命令が設定したフラグを見て分岐する
答えと解説を見る

正解：C. RISC-Vは分岐命令が2つのレジスタを直接比べ、x86は比較命令が設定したフラグを見て分岐する

x86では「cmp eax, ebx」で比較してゼロや桁上がりなどのフラグ(条件コード)を設定し、次の「je」や「jl」がフラグを見て分岐します。RISC-Vはフラグを持たず、「beq a0, a1, L」「blt a0, a1, L」のように分岐命令自身が2つのレジスタを比べます。フラグのような暗黙の状態がないので、命令の並べ替えや同時実行のときに依存関係を追いやすくなります。

解説の中の「条件コード」

  • x86では「cmp eax, ebx」で比較してゼロや桁上がりなどのフラグ(条件コード)を設定し、次の「je」や「jl」がフラグを見て分岐します。
