SPICEとは

すぱいす

トランジスタレベルの回路の電圧や電流を、デバイスモデルを使って詳しく計算する回路シミュレータ。アナログ回路の設計やセルの特性評価に使う。

この用語の分野: LSI設計フロー・EDA

解説の中の「SPICE」

  • これにアーリー効果や高注入効果、電荷の蓄積を加えたのがガンメル・プーンモデルで、SPICEのバイポーラモデルの基礎になっています。

    バイポーラトランジスタの大信号動作を、2つのダイオードと電流源で表したモデルはどれか。

  • SPICEなどの回路シミュレータも、各節点にこの法則を当てはめる節点解析で計算しています。

    キルヒホッフの電流則(第1法則)の内容として正しいものはどれか。

  • PDKには、そのプロセスのデザインルール、トランジスタなどのSPICE用モデル、DRCやLVSのためのルールファイル、配線の寄生素子抽出のデータ、基本的なデバイスのレイアウトなどが含まれます。

    ファウンドリが設計者に提供する、デザインルール、デバイスモデル、セルライブラリなどの設計用データ一式を何と呼ぶか。

「SPICE」が出てくる問題(5問)

  1. バイポーラトランジスタの大信号動作を、2つのダイオードと電流源で表したモデルはどれか。
  2. キルヒホッフの電流則(第1法則)の内容として正しいものはどれか。
  3. ファウンドリが設計者に提供する、デザインルール、デバイスモデル、セルライブラリなどの設計用データ一式を何と呼ぶか。
  4. トランジスタレベルの回路の電圧や電流を、デバイスモデルを使って詳しく計算する回路シミュレータの代表はどれか。
  5. マスク製作のために製造側に渡すレイアウトデータの代表的な形式はどれか。
