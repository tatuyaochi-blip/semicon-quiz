伝達関数とは

でんたつかんすう

線形で時不変な系の入力と出力の関係を、初期値をすべて0としたときの出力と入力のラプラス変換の比 G(s) = Y(s)/X(s) で表したもの。系のインパルス応答のラプラス変換に等しい。分母を0にする s を極、分子を0にする s を零点と呼び、極の位置から安定性や応答の速さがわかる。s = jω とおくと周波数応答が得られる。離散時間の系では、z変換を使って H(z) で表す。

「伝達関数」は、2分野の23問の練習問題に出てきます(制御工学の基礎, デジタル信号処理の基礎など)。

この用語の分野: 制御工学の基礎

ブロック線図での計算

伝達関数を使うと、要素の直列の接続は掛け算、並列の接続は足し算で表せます。負帰還のループでは、前向きの伝達関数を G(s)、フィードバックの伝達関数を H(s) とすると、閉ループ伝達関数は G(s)/(1 + G(s)H(s)) になります。積 G(s)H(s) は一巡伝達関数(ループ伝達関数)と呼ばれ、安定性や安定の余裕を調べるときの出発点になります。

代表的な形

RC回路のローパスフィルタは 1/(1 + sRC) という一次遅れ系で、RLC回路やモータの位置の制御ループは、二次遅れ系で表されることが多くあります。積分は 1/s、微分は s、時間 L のむだ時間は e^(−Ls) です。分母の次数が分子の次数以上の伝達関数をプロパーと呼び、実際の物理的な系はふつうこの形になります。

極と零点が教えること

極 p は応答に e^(pt) の成分を生むので、すべての極の実部が負なら系は安定です。極が虚軸に近いほど応答はゆっくり減衰し、虚部が大きいほど速く振動します。零点は応答の形を変え、s平面の右半分に零点をもつ系では、ステップ応答が最初に逆向きに動く逆応答が現れることがあり、速い制御が難しくなります。

伝達関数の練習問題に挑戦

離散時間のLTIシステムの伝達関数 H(z) から周波数応答を求めるとき、z を動かす場所として正しいものはどれか。

  1. Az平面の単位円の上(z = e^(jω)、|z| = 1)
  2. Bz平面の正の実軸の上(z = r、r は0より大きい実数)
  3. Cz平面の虚軸の上(z = jω)
答えと解説を見る

正解：A. z平面の単位円の上(z = e^(jω)、|z| = 1)

周波数応答は、H(z) に z = e^(jω) を代入したもので、ω を −π から π まで動かすと、z は単位円を1周します。z = 1(ω = 0)が直流、z = −1(ω = π)がナイキスト周波数に当たります。連続時間のラプラス変換では虚軸 s = jω の上で周波数応答を求めますが、離散時間ではそれが単位円に対応します。

差分方程式 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1] で表されるシステムの伝達関数 H(z) = Y(z)/X(z) として正しいものはどれか。

  1. A(1 + 0.5z⁻¹)/(1 + 0.25z⁻¹)
  2. B(1 − 0.25z⁻¹)/(1 + 0.5z⁻¹)
  3. C(1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)
答えと解説を見る

正解：C. (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)

1サンプルの遅れは、z変換では z⁻¹ を掛けることに当たるので、両辺をz変換すると Y(z) = X(z) + 0.5z⁻¹X(z) + 0.25z⁻¹Y(z) です。Y(z) の項を左辺に集めると (1 − 0.25z⁻¹)Y(z) = (1 + 0.5z⁻¹)X(z) となり、H(z) = (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹) です。分子は入力の側、分母は出力の帰還の側の係数を表し、分母を0にする z = 0.25 が極、分子を0にする z = −0.5 が零点です。

よくある質問

伝達関数と周波数応答の違いは何ですか?

伝達関数 G(s) は複素数 s の関数で、s を虚軸の上の jω に限ったものが周波数応答 G(jω) です。周波数応答の大きさと位相を周波数に対して描いたものが、ボード線図です。

非線形な系にも伝達関数はありますか?

そのままでは定義できません。動作点の近くで線形化すれば、その近くでの小さな変化について伝達関数を使えます。飽和や不感帯のような強い非線形性は、別の方法で扱います。

  2. 差分方程式 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1] で表されるシステムの伝達関数 H(z) = Y(z)/X(z) として正しいものはどれか。

  6. 前向きの経路の伝達関数が G(s)、フィードバックの経路の伝達関数が H(s) の負帰還のブロック線図がある。目標値 R(s) から出力 Y(s) までの閉ループ伝達関数 Y(s)/R(s) として正しいものはどれか。
  7. 伝達関数 G(s) = 5/(s + 2) の系に、大きさ1のステップを入力した。出力の最終値(t → ∞ での値)として正しいものはどれか。
  8. 線形で時不変な系の伝達関数の説明として正しいものはどれか。

  10. ある一次遅れ系に大きさ2のステップを入力したところ、出力は最終的に6に落ち着き、入力から0.4 sで最終値の約63%に達した。この系の伝達関数として正しいものはどれか。
