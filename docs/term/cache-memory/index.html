キャッシュメモリとは

きゃっしゅめもり

CPUの近くに置く高速・小容量のメモリ。よく使うデータを保持して主記憶との速度差を緩和する。主にSRAMでつくられる。

「キャッシュメモリ」は、1分野の1問の練習問題に出てきます(CPU・アーキテクチャなど)。

この用語の分野: CPU・アーキテクチャ

キャッシュメモリの練習問題に挑戦

キャッシュメモリを設ける主な目的として正しいものはどれか。

  1. A電源を切ってもデータを保持するため
  2. Bよく使うデータをCPUの近くに置き、主記憶との速度差を緩和するため
  3. C演算結果の誤りを訂正するため
答えと解説を見る

正解：B. よく使うデータをCPUの近くに置き、主記憶との速度差を緩和するため

CPUが1クロック(0.2〜0.3 ns)で処理する間に、DRAMへのアクセスには数十〜100 ns、つまり数百クロックかかります。そこでよく使うデータや命令を高速なSRAMのキャッシュに置き、待ち時間を減らします。同じデータを近いうちにまた使う時間的局所性と、近くのアドレスを続けて使う空間的局所性を利用しており、L1で数クロック、L3でも数十クロックでアクセスできます。

「キャッシュメモリ」が出てくる問題(1問)

  1. キャッシュメモリを設ける主な目的として正しいものはどれか。

この用語が出てくる比較

  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • CPUとGPUの違い：構造・得意な処理・用途を比較CPUとGPUを、設計の目的・コア数・実行モデル・キャッシュ・メモリ帯域・分岐・データ転送・得意な処理の観点で表にして比較します。
  • ライトスルーとライトバックの違い：キャッシュの書き込み方式を比較ライトスルーとライトバックのキャッシュを、書き込みの方式・メモリのトラフィック・速度・整合性・複雑さ・追い出しのコスト・用途の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
