オーバーレイ(重ね合わせ精度)とは

おーばーれい

前の工程でつくったパターンに対して、新しいパターンをどれだけ正確な位置に重ねられるか。ずれるとコンタクトが外れるなどの不良になるため、ナノメートル単位で管理する。

この用語の分野: リソグラフィ

解説の中の「オーバーレイ(重ね合わせ精度)」

  • LSIは数十層のパターンを重ねてつくるため、各層を前の層に正確に位置合わせする必要があり、そのずれの小ささが重ね合わせ精度です。

    リソグラフィにおける重ね合わせ(オーバーレイ)精度とは何か。

  • 重ね合わせ精度を測るため、スクライブラインなどに、前の層と今の層のパターンを組み合わせた専用のマークをつくります。

    重ね合わせ(オーバーレイ)のずれを計測するために、ウエハ上に設けるものはどれか。

  • そのため非常に高い重ね合わせ精度が必要です。

    LELE(リソ・エッチ・リソ・エッチ)方式のダブルパターニングで、特に厳しく求められるものはどれか。

「オーバーレイ(重ね合わせ精度)」が出てくる問題(4問)

  1. リソグラフィにおける重ね合わせ(オーバーレイ)精度とは何か。
  2. 重ね合わせ(オーバーレイ)のずれを計測するために、ウエハ上に設けるものはどれか。
  3. LELE(リソ・エッチ・リソ・エッチ)方式のダブルパターニングで、特に厳しく求められるものはどれか。
  4. クリーンルーム、特に露光エリアで温度を非常に厳しく一定に保つ主な理由はどれか。
