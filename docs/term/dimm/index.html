DIMMとは

でぃむ

複数のDRAMチップを小さな基板に載せ、パソコンやサーバーのスロットに差し込めるようにしたメモリモジュール。

「DIMM」は、1分野の1問の練習問題に出てきます(DRAMなど)。

この用語の分野: DRAM

DIMMの構造と名前の由来

DIMM(Dual Inline Memory Module)は、複数のDRAMチップを細長いプリント基板に載せ、マザーボードのスロットに差し込めるようにしたメモリモジュールです。以前のSIMMは基板の表と裏の端子が同じ信号につながっていましたが、DIMMは表と裏の端子が別々の信号をもつため「デュアル」と呼ばれます。基板には、DRAMチップのほか、容量や速度、タイミングなどの情報を記録したSPDという小さな不揮発性メモリが載っていて、起動時にマザーボードがこれを読んでメモリを設定します。端子の途中にある切り欠きの位置は世代ごとに異なり、違う世代のモジュールを誤って差し込めないようになっています。

種類と用途

デスクトップPC向けの普通のDIMMは、信号をバッファしないためUDIMM(アンバッファードDIMM)とも呼ばれます。ノートPC向けには、長さを短くした小型のSO-DIMMがあります。サーバー向けには、コマンドとアドレスの信号をレジスタで受け直して多くのチップを駆動できるRDIMMや、データの信号もバッファするLRDIMMがあり、より大きな容量を搭載できます。誤り訂正(ECC)に対応したモジュールは、64ビットのデータにECC用の8ビットを加えた72ビットの幅で使います。DDR5では、1枚のモジュールを独立した2つの32ビットのサブチャネルに分け、電源回路(PMIC)もモジュール上に載せています。

容量と帯域の考え方

1枚のDIMMの容量は、載っているDRAMチップの容量と個数で決まります。例えば、データ幅8ビット(x8)の16 Gbのチップを8個載せたモジュールなら、16 Gb × 8 = 128 Gb = 16 GBです。64ビットのデータ幅をまとめて構成するチップの組をランクと呼び、ランクを増やすと容量が増えます。ピークの帯域はデータレートとデータ幅の積で、DDR4-3200のDIMMなら3200 MT/s × 8バイト = 25.6 GB/s、DDR5-4800なら38.4 GB/sです。CPUのメモリチャネルごとにDIMMを挿すと、チャネルの数だけ帯域が増えます。

選ぶときの注意

DDR4とDDR5のように世代が違うDIMMは、切り欠きの位置や電圧、信号が異なり、互換性がありません。同じ世代でも、RDIMMとUDIMMは混ぜて使えず、ECCが使えるかはCPUとマザーボードの対応によります。速度の異なるDIMMを混ぜると、一般に最も遅いものに合わせて動作します。また、1つのチャネルに挿すDIMMの枚数を増やすと、信号の負荷が増えるため、対応する最高速度が下がることがあります。ノートPC向けには、薄型で高速化しやすいCAMM2という新しい形のモジュールもJEDECで規格化されています。

DIMMの練習問題に挑戦

パソコンのメモリとして、複数のDRAMチップを小さな基板に載せて差し込めるようにした部品を何と呼ぶか。

  1. ASSD
  2. Bマザーボード
  3. CDIMM(メモリモジュール)
答えと解説を見る

正解：C. DIMM(メモリモジュール)

DIMM(Dual Inline Memory Module)は、複数のDRAMチップを1枚の基板に実装したモジュールで、表裏の端子が別々の信号をもつことから「デュアル」と呼ばれます。マザーボードのスロットに差し込んで交換・増設でき、ノートPC向けの小型品はSO-DIMMです。サーバー向けには信号をバッファするRDIMMがあり、DDR5ではモジュール上に電源回路(PMIC)も載っています。

よくある質問

DIMMとSO-DIMMの違いは?

どちらもDRAMチップを載せた差し込み式のメモリモジュールで、DIMMはデスクトップPCやサーバー向けの長いもの、SO-DIMM(Small Outline DIMM)はノートPCや小型PC向けの短いものです。端子の数や切り欠きの位置が異なり、互いのスロットには挿せません。

RDIMMとUDIMMの違いは?

RDIMMは、コマンドとアドレスの信号をモジュール上のレジスタで受け直してからDRAMチップに配るため、多くのチップを安定して駆動でき、大容量のサーバー向けに使われます。UDIMMはバッファをもたず、主にPC向けです。両者は電気的に異なるため、同じシステムで混ぜて使うことはできません。

DIMMの「デュアル」とは何を意味しますか?

基板の表と裏の端子が、それぞれ別々の信号をもつことを意味します。前の世代のSIMM(Single Inline Memory Module)では、表と裏の端子が同じ信号につながっていました。メモリチャネルを2つ使うという意味のデュアルチャネルとは別のものです。
