DIMMとは

でぃむ

複数のDRAMチップを小さな基板に載せ、パソコンやサーバーのスロットに差し込めるようにしたメモリモジュール。

この用語の分野: DRAM

解説の中の「DIMM」

  • DIMM(Dual Inline Memory Module)は、複数のDRAMチップを1枚の基板に実装したモジュールで、表裏の端子が別々の信号をもつことから「デュアル」と呼ばれます。

    パソコンのメモリとして、複数のDRAMチップを小さな基板に載せて差し込めるようにした部品を何と呼ぶか。

「DIMM」が出てくる問題(1問)
