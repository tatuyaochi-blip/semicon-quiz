空間的局所性とは

くうかんてききょくしょせい

あるアドレスにアクセスすると、その近くのアドレスにもまもなくアクセスしやすい性質。配列を順に読む処理が例で、キャッシュラインの単位でまとめて読み込む理由になる。

この用語の分野: メモリ階層と性能

解説の中の「空間的局所性」

  • 同じデータを近いうちにまた使う時間的局所性と、近くのアドレスを続けて使う空間的局所性を利用しており、L1で数クロック、L3でも数十クロックでアクセスできます。

    キャッシュメモリを設ける主な目的として正しいものはどれか。

  • 近くのアドレスのデータは続けて使われることが多い(空間的局所性)ため、まとめて取り込むと効率がよく、DRAMのバースト転送(DDR4で8回 × 8バイト = 64バイト)とも合っています。

    現在の多くのCPUで使われているキャッシュライン(キャッシュブロック)の大きさとして一般的なものはどれか。

  • 配列を先頭から順に読むのは、近くのアドレスを続けて使う空間的局所性の例で、時間的局所性とは別の性質です。

    時間的局所性の例として最も適切なものはどれか。

「空間的局所性」が出てくる問題(4問)

  1. キャッシュメモリを設ける主な目的として正しいものはどれか。
  2. 現在の多くのCPUで使われているキャッシュライン(キャッシュブロック)の大きさとして一般的なものはどれか。
  3. 時間的局所性の例として最も適切なものはどれか。
  4. キャッシュのラインサイズを大きくしたときの影響として正しいものはどれか。
