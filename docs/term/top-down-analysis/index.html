トップダウン分析とは

とっぷだうんぶんせき

性能カウンタを使い、CPUの命令の処理の枠の使われ方をフロントエンド・バックエンド・投機の無駄・リタイアに分け、ボトルネックを絞り込む方法。

この用語の分野: 性能評価・プロファイリング

解説の中の「トップダウン分析」

  • トップダウン分析では、毎サイクルの命令を処理する枠が、命令を取り出して解読する前段(フロントエンド)が間に合わずに空いたのか、演算器やメモリの待ちなど後段(バックエンド)で詰まったのか、予測を誤って捨てる命令に使われたのか、正しく完了した命令に使われたのかに分けます。
