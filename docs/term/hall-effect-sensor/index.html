ホール素子とは

ほーるそし

ホール効果を利用して磁界を検出するセンサ。電流を流した半導体に磁界をかけると、電流と磁界に垂直な方向に電圧が生じる。モーターの回転検出などに使われる。

この用語の分野: MEMS・センサ

解説の中の「ホール素子」

  • ホール素子の感度は移動度に比例するため、小さな磁界でも大きな出力が得られ、旭化成などが量産してモーターの回転位置の検出や電子コンパスに使われています。

    電子の移動度が非常に大きく、磁気センサ(ホール素子)などに使われる化合物半導体はどれか。

  • ホール素子はこの電圧から磁界を検出し、ブラシレスモーターの回転位置の検出、非接触の電流センサ、スマートフォンのカバーの開閉検知などに使われます。

    ホール効果を利用したセンサ(ホール素子)で主に検出するものはどれか。

  • 大電流では、損失のないホール素子などの磁気式の電流センサも使われます。

    電源回路などで、電流を測るために電流の経路に直列に入れる小さな抵抗を何と呼ぶか。

「ホール素子」が出てくる問題(4問)

  1. 電子の移動度が非常に大きく、磁気センサ(ホール素子)などに使われる化合物半導体はどれか。
  2. ホール効果を利用したセンサ(ホール素子)で主に検出するものはどれか。
  3. 電源回路などで、電流を測るために電流の経路に直列に入れる小さな抵抗を何と呼ぶか。
  4. スマートフォンの電子コンパスに使われるセンサが検出するものはどれか。
