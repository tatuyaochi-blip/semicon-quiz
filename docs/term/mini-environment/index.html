ミニエンバイロメントとは

みにえんばいろめんと

ウエハの周りの狭い空間だけを高い清浄度に保つ考え方。FOUPなどの密閉容器と装置前面のEFEMを組み合わせ、部屋全体の清浄度の要求を下げてコストを抑える。

この用語の分野: クリーンルーム・製造装置

解説の中の「ミニエンバイロメント」

  • 1980年代に考案され、ミニエンバイロメントの考え方を広めました。

    200 mmウエハの時代に普及した、カセットを密閉したポッドに入れて装置に受け渡すミニエンバイロメントの方式はどれか。

  • ウエハは密閉容器と装置のミニエンバイロメントで守られるため、部屋全体の清浄度をそこまで高くしなくて済み、装置の配置換えもしやすくなります。

    仕切りの少ない大きな部屋の中に製造装置を並べ、FOUPなどの密閉容器とミニエンバイロメントでウエハの清浄度を確保するク…

  • ミニエンバイロメント方式では、FOUPや装置内部など、ウエハが触れる空間だけを極めて清浄に保ち、人が作業する空間の清浄度は少し緩めます。

    ウエハの周りの狭い空間だけを高い清浄度に保つ考え方を何と呼ぶか。

「ミニエンバイロメント」が出てくる問題(5問)

  1. 200 mmウエハの時代に普及した、カセットを密閉したポッドに入れて装置に受け渡すミニエンバイロメントの方式はどれか。
  2. 仕切りの少ない大きな部屋の中に製造装置を並べ、FOUPなどの密閉容器とミニエンバイロメントでウエハの清浄度を確保するクリーンルームの方式はどれか。
  3. ウエハの周りの狭い空間だけを高い清浄度に保つ考え方を何と呼ぶか。
  4. 製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。
  5. 天井の一部から清浄な空気を吹き出し、室内の空気と混ぜて薄めながら清浄度を保つ方式のクリーンルームはどれか。清浄度は一方向流より低いが、設備費は安い。
