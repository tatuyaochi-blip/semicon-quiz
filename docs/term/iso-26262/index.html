ISO 26262とは

あいえすおー26262

電気・電子システムの故障による危険を、許容できる水準まで下げるための自動車の機能安全の国際規格。IEC 61508を自動車向けにしたもので、構想から開発、生産、廃棄までのライフサイクル全体を扱う。

「ISO 26262」は、2分野の14問の練習問題に出てきます(車載半導体と機能安全, 信頼性など)。

この用語の分野: 車載半導体と機能安全

機能安全とは

ISO 26262は機能安全を、電気・電子(E/E)システムの誤動作が引き起こすハザードによる、不合理なリスクが存在しないことと定義しています。目指すのは不可能な故障ゼロではなく、故障が危険な状況につながらないようにすることです。典型的なのは「検出して対処する」パターンで、たとえば電動パワーステアリングがモータ制御の異常を検出すると、アシストを停止して警告灯を点灯し、ドライバーが手動で操舵できる状態を保ちます。衝突安全や一般的な品質マネジメントは別の領域で、後者はIATF 16949が扱います。

ハザード分析から安全要求へ

作業はハザード分析・リスクアセスメント(HARA)から始まります。危険事象ごとに重大度(S1〜S3)、露出度(E1〜E4)、制御可能性(C1〜C3)を評価し、その組み合わせからASIL(自動車安全度水準)のA〜Dを決めます。通常の品質管理で十分な場合はQMとなります。便利な目安として、S・E・Cの数字の合計が10ならD、9ならC、8ならB、7ならAです。各ハザードは「意図しない急加速を起こさない」のような安全目標となり、そのASILを引き継いだうえで、機能安全要求、技術安全要求、ハードウェアとソフトウェアの安全要求へと詳細化されます。

ランダム故障とシステマティック故障

規格は2種類の故障を区別して扱います。摩耗や放射線によるビット反転などのランダムハードウェア故障は、FIT単位の故障率と、シングルポイント故障メトリック(SPFM)、潜在故障メトリック(LFM)、ランダムハードウェア故障確率メトリック(PMHF)などの指標で定量的に評価します。一方、仕様の誤り、設計ミス、ソフトウェアのバグによるシステマティック故障は、同じ条件がそろえば必ず再発するため、ASILに応じた厳格なプロセスで防ぎます。安全機構は故障許容時間間隔(FTTI)内に故障を検出して安全状態へ移行する必要があり、ECCの訂正回路の故障のような潜在故障は、2つ目の故障が起きる前に見つけなければなりません。

半導体サプライヤの位置づけ

汎用の車載マイコンは、最終的にどの車両でどう使われるかが決まる前に設計されるため、SEooC(Safety Element out of Context:特定の使用状況を前提としない安全要素)として開発されます。サプライヤは安全要求と使用条件を仮定してセーフティマニュアルにまとめ、システムインテグレータがその仮定を確認します。ASILデコンポジションを使うと、独立した冗長要素に要求を分割でき、たとえばASIL DをB(D)とB(D)に分けられますが、従属故障の分析が前提です。隣接する規格として、故障していないシステムの性能限界はISO 21448(SOTIF)が、サイバー攻撃はISO/SAE 21434が扱います。

ISO 26262の練習問題に挑戦

機能安全の規格ISO 26262の説明として正しいものはどれか。

  1. A量産される路上走行車両の電気・電子システムの故障による危険を減らすための規格で、IEC 61508をもとに自動車向けにしたもの
  2. B車体の衝突時の強度やエアバッグの展開性能など、衝突したときの乗員の保護について定めた規格
  3. C自動車部品を作る工場の品質マネジメントシステムについて、ISO 9001に自動車業界向けの追加の要求を加えて国際的に統一した規格
答えと解説を見る

正解：A. 量産される路上走行車両の電気・電子システムの故障による危険を減らすための規格で、IEC 61508をもとに自動車向けにしたもの

ISO 26262は、電気・電子システムの故障によって車が危険な振る舞いをするリスクを、許容できる水準まで下げるための機能安全の規格です。電気・電子・プログラマブル電子系の機能安全の基本規格IEC 61508を自動車向けにしたもので、構想から開発、生産、廃棄までのライフサイクル全体を扱います。衝突安全は車体やエアバッグの性能の話で、別の基準で扱います。品質マネジメントの自動車向け規格はIATF 16949です。

ISO 26262で、ハザード分析とリスクアセスメント(HARA)によりASILを決めるときに評価する3つの要素の組み合わせとして正しいものはどれか。

  1. A重大度(S)・露出度(E)・制御可能性(C)
  2. B故障率(λ)・診断カバレッジ(DC)・フォールトトレラント時間間隔(FTTI)
  3. C部品の価格・生産台数・開発期間
答えと解説を見る

正解：A. 重大度(S)・露出度(E)・制御可能性(C)

ASILは、危険な事象ごとに、けがの重さを表す重大度S、その危険が起こりうる運転状況にさらされる頻度や時間を表す露出度E、運転者などが危険を回避できる可能性を表す制御可能性Cの3つを評価して決めます。例えば高速走行中に急にブレーキが効かなくなる事象は、重大度が高く回避も難しいので高いASILになります。故障率や診断カバレッジ、FTTIは、ASILが決まった後に、その要求を満たす設計を評価するときに使う量です。

よくある質問

ISO 26262とIEC 61508の違いは何ですか?

IEC 61508は、電気・電子・プログラマブル電子システム全般を対象とした汎用の機能安全規格です。ISO 26262はこれを量産される道路車両向けに適合させたもので、ASILなど自動車固有の概念に置き換え、構想から廃棄までの車両ライフサイクルを扱います。

ISO 26262の認証を取得すれば事故は起きないのですか?

いいえ。目的はE/Eシステムの誤動作によるリスクを許容できる水準まで下げることで、一般には故障を検出して安全状態へ移行させることで実現します。センサの性能限界による危険はSOTIFが、攻撃による危険はISO/SAE 21434が扱います。

AEC-Q100に合格すればISO 26262に準拠したことになりますか?

いいえ。AEC-Q100はICの信頼性をストレス試験で確認する認定規格で、ISO 26262は安全ライフサイクル、安全機構、故障率の指標を規定するものです。車載チップには通常、両方を満たすことが求められます。

「ISO 26262」が出てくる問題(14問)

  1. 機能安全の規格ISO 26262の説明として正しいものはどれか。
  2. ISO 26262で、ハザード分析とリスクアセスメント(HARA)によりASILを決めるときに評価する3つの要素の組み合わせとして正しいものはどれか。
  3. ISO 26262のASILについての説明として正しいものはどれか。
  4. ISO 26262における「安全目標」の説明として正しいものはどれか。
  5. ISO 26262で区別されるランダムハードウェア故障とシステマティック故障の説明の組み合わせとして正しいものはどれか。
  6. ISO 26262でいう潜在故障(レイテントフォールト)の例として最も適切なものはどれか。
  7. ISO 26262のフォールトトレラント時間間隔(FTTI)の説明として正しいものはどれか。
  8. ISO 26262のASILデコンポジション(分解)で、ASIL Dの安全要求を、十分に独立した2つの冗長な要素に分けて割り当てる組み合わせとして認められているものはどれか。
  9. ISO 26262のSEooC(Safety Element out of Context)の説明として正しいものはどれか。
  10. 自動車の規格ISO 26262とISO/SAE 21434の違いとして正しいものはどれか。
  11. 次のうち、ISO 26262(機能安全)ではなく、主にSOTIF(ISO 21448、意図した機能の安全性)で扱う問題はどれか。
  12. 自動車の機能安全の考え方として正しいものはどれか。
  13. ある危険な事象を評価したところ、重大度S3・露出度E4・制御可能性C3で、ASIL Dとなった。同じ事象で、制御可能性だけがC2(通常は多くの運転者が回避できる)であったとすると、ASILはどうなるか。
  14. 同じ半導体でも、民生機器用と自動車用で求められる信頼性の水準についての説明として正しいものはどれか。
