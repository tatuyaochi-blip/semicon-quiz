デコヒーレンスとは

でこひーれんす

量子ビットが周囲の環境と相互作用することで、重ね合わせの位相やエネルギーの情報が失われ、量子的な性質が壊れていく現象。エネルギー緩和時間 T1 と位相緩和時間 T2 でその速さを表す。

「デコヒーレンス」は、1分野の1問の練習問題に出てきます(量子コンピュータのハードウェアなど)。

この用語の分野: 量子コンピュータのハードウェア

T1 と T2

T1(エネルギー緩和時間)は、|1⟩の量子ビットがエネルギーを失って|0⟩に戻るまでの時定数です。T2(位相緩和時間)は、重ね合わせ α|0⟩ + β|1⟩ の相対位相の情報が失われるまでの時間で、1/T2 = 1/(2T1) + 1/Tφ の関係があるので T2 ≤ 2T1 になります(Tφ は純粋な位相緩和の時間)。T1 はエネルギーの散逸、Tφ は量子ビットの周波数のゆらぎで決まり、どちらも周囲の環境とのわずかな相互作用が原因です。

主な原因

超伝導量子ビットでは、表面や界面のアモルファスの酸化膜にある二準位系(TLS)の欠陥による誘電損失、配線を通って入る熱雑音、磁束や電荷の雑音、超伝導が壊れてできる準粒子などが主な原因です。宇宙線などの放射線が、チップの広い範囲に同時に誤りを起こすことも報告されています。シリコンのスピン量子ビットでは ²⁹Si の核スピンや電荷の雑音が、イオンや中性原子ではレーザーの雑音や磁場のゆらぎが問題になります。そのため、材料、製造プロセス、遮蔽、配線のフィルタなど、ハードウェアのあらゆる部分の工夫が必要です。

デコヒーレンスと計算の深さ

重要なのは、コヒーレンス時間とゲートの時間の比です。T2 が100 µs、ゲートの時間が50 ns なら、その比は2,000で、誤り訂正なしに実行できる操作の数のおおよその上限の目安になります(実際にはゲートそのものの誤りも加わります)。量子誤り訂正は、デコヒーレンスによる誤りを検出して直しながら計算を続けるための技術で、物理的な誤り率がしきい値より十分低いことが前提になります。

デコヒーレンスの練習問題に挑戦

量子ビットのエネルギー緩和時間 T1 の説明として正しいものはどれか。

  1. A1回の量子ゲートの操作にかかる時間
  2. B励起状態|1⟩がエネルギーを周囲に失って、基底状態|0⟩に戻るまでの特性時間
  3. C冷凍機が室温から動作温度まで量子ビットを冷やすのにかかる時間
答えと解説を見る

正解：B. 励起状態|1⟩がエネルギーを周囲に失って、基底状態|0⟩に戻るまでの特性時間

T1 は、|1⟩に用意した量子ビットがエネルギーを失って|0⟩に戻る過程の時定数で、|1⟩にいる確率はおよそ exp(−t/T1) で減っていきます。超伝導量子ビットでは、配線や基板、表面の欠陥などにエネルギーが逃げることが主な原因です。重ね合わせの位相の情報が失われるまでの時間 T2 とともに、量子ビットが情報を保てる長さの指標になります。T1 や T2 が有限になるのは、量子ビットが周囲の環境と相互作用して量子的な性質を失うデコヒーレンスのためで、計算を正しく行うには、ゲートの時間が T1 や T2 よりずっと短いことが必要です。

よくある質問

デコヒーレンスを完全になくすことはできますか?

できません。量子ビットを操作し、測定するためには外部とつながる必要があり、そのつながりを通じて環境の影響も受けるからです。そのため、コヒーレンス時間を延ばす努力と、残った誤りを量子誤り訂正で直すことを組み合わせます。

コヒーレンス時間が長い方式ほど優れているのですか?

それだけでは決まりません。イオントラップ方式は秒単位以上のコヒーレンス時間をもつことがありますが、ゲートも遅いので、比べるべきはコヒーレンス時間とゲートの時間の比、そしてゲートの忠実度です。
