BSSセクションとは

びーえすえすせくしょん

初期値のない(または0の)グローバル変数や静的変数の領域。ファイルには大きさだけを記録し、読み込み時に0で埋めるので、実行ファイルを大きくしない。

「BSSセクション」は、1分野の2問の練習問題に出てきます(リンカ・ローダと実行形式など)。

この用語の分野: リンカ・ローダと実行形式

.bssに入るもの

C言語では、静的記憶域期間をもつオブジェクト、つまりグローバル変数と静的変数は、初期化子がなければ0から始まると決められています。コンパイラはこうした変数を、そして通常は明示的に0で初期化した変数も、.bssセクションに置きます。0以外の初期値をもつグローバル変数は.dataに、const修飾された定数は読み出し専用の.rodataに入ります。staticキーワードはセクションを決めるものではなく、見える範囲を1つのファイルに限るだけです。関数内の自動変数はスタック上に置かれ、初期値も決まっていないため、.bssに入ることはありません。

.bssがファイルの容量を使わない理由

長く続く0を実行ファイルに格納しても、ディスク容量と読み込み時間が無駄になるだけなので、.bssセクションには大きさとアラインメントだけが記録されます。ELFでは、ファイル内のバイトを占めないセクションとして印が付けられます。ローダは.dataと.bssを含む読み書き可能なセグメントをマップし、セグメントのメモリ上の大きさがファイル上の大きさを超える部分は、0で埋めたページとして用意します。そのため static char buf[1000000]; のような宣言は、メモリ使用量を約1 MB増やしますが、ファイルの大きさはほとんど増やしません。

組み込みシステムでのBSS

OSのないマイコンでは、ほかに誰もメモリを0で埋めてくれないため、スタートアップコードがこれを行います。リセットハンドラは通常、mainを呼ぶ前に、.dataの初期値をフラッシュからRAMへコピーし、RAM上の.bssの範囲をクリアします。このとき、リンカスクリプトがシンボルとして書き出した開始・終了アドレスを使います。どちらかを忘れると、グローバル変数がでたらめな値になります。sizeコマンドなどのツールはtext、data、bssを別々に表示するので、フラッシュとRAMの使用量の見積もりに役立ちます。

名前の由来

BSSは一般に、block started by symbolの略とされます。これは初期のIBMのメインフレームで、ラベルを付けて初期化されない記憶領域のブロックを確保していたアセンブラの疑似命令に由来する名前です。その疑似命令自体はとうに使われなくなりましたが、意味はUNIXのオブジェクト形式に、そして後のELFに受け継がれました。現在では、コードの.text、初期値付きデータの.data、定数の.rodataと並んで、ゼロ初期化データのセクションを指す名前として使われています。

BSSセクションの練習問題に挑戦

.bssセクションの特徴として正しいものはどれか。

  1. A関数の局所変数を、呼ばれるたびに置く領域である
  2. B初期値のない(または0の)変数の領域で、ファイルには大きさだけを記録し、読み込み時に0で埋める
  3. C定数の文字列を置く、書き込みのできない領域である
答えと解説を見る

正解：B. 初期値のない(または0の)変数の領域で、ファイルには大きさだけを記録し、読み込み時に0で埋める

初期値を書かないグローバル変数や静的変数は、C言語の決まりで0から始まります。中身がすべて0なら、ファイルに0を並べて保存するのはむだなので、.bssセクションには大きさだけを記録し、ローダがメモリを確保して0で埋めます。例えば「static char buf[1000000];」があっても、実行ファイルは1MB大きくなりません。

よくある質問

BSSとは何の略ですか?

古いアセンブラの疑似命令に由来して、一般にblock started by symbolの略とされます。現在のツールチェーンでは、単にゼロ初期化されるグローバル変数や静的変数のセクションの名前です。

初期化していない大きな配列は実行ファイルを大きくしますか?

大きくしません。初期化子のないグローバル配列や静的配列は.bssに置かれ、ファイルには大きさだけが記録されます。メモリはプログラムの読み込み時に確保され、0で埋められます。

.dataと.bssの違いは?

.dataセクションには0以外の初期値をもつグローバル変数や静的変数が入り、その値をファイルに格納しておく必要があります。.bssセクションには0から始まるものが入るので、実行時にはメモリを使いますが、ファイルには中身のための領域を取りません。
