ループブロッキングとは

るーぷぶろっきんぐ

大きな配列を、キャッシュに収まる小さなブロックに分けて処理し、読み込んだデータを追い出される前に何度も使うようにする最適化。行列の積などで効果が大きい。

この用語の分野: メモリ階層と性能

解説の中の「ループブロッキング」

  • ループブロッキングでは行列をキャッシュに収まる小さなブロックに分け、ブロックの中で計算をすませることで、読み込んだデータを何度も再利用し、容量ミスを大きく減らします。

    行列の積などで使われるループブロッキング(タイリング)の主な目的はどれか。

  • これが容量ミスで、キャッシュを大きくするか、ループブロッキングなどで再利用の範囲を小さくする必要があります。

    キャッシュをフルアソシアティブ方式にしても減らないミスとして正しいものはどれか。

「ループブロッキング」が出てくる問題(2問)

  1. 行列の積などで使われるループブロッキング(タイリング)の主な目的はどれか。
  2. キャッシュをフルアソシアティブ方式にしても減らないミスとして正しいものはどれか。
