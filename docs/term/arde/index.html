ARDE(アスペクト比依存エッチング)とは

えーあーるでぃーいー

パターンが細く深いほど、イオンやラジカルが底に届きにくくなり、エッチング速度が低下する現象。マイクロローディング効果とも呼ばれる。

「ARDE(アスペクト比依存エッチング)」は、1分野の1問の練習問題に出てきます(エッチングなど)。

この用語の分野: エッチング

ARDE(アスペクト比依存エッチング)の練習問題に挑戦

パターンが細く深くなるほどエッチング速度が低下する現象を何と呼ぶか。

  1. Aオートドーピング
  2. Bアスペクト比依存エッチング(ARDE、マイクロローディング効果)
  3. Cディッシング
答えと解説を見る

正解：B. アスペクト比依存エッチング(ARDE、マイクロローディング効果)

細く深い穴の底には、ラジカルが壁に衝突して失われたり、イオンが帯電で曲げられたりして届きにくく、反応生成物も排出されにくいため、アスペクト比が大きいほどエッチング速度が遅くなります。この現象がARDE(マイクロローディング効果)で、同じウエハでも細い穴は浅く、太い穴は深くなり、寸法によって深さがそろわない原因になります。エッチストップ層や条件の工夫で補います。

解説の中の「ARDE(アスペクト比依存エッチング)」

  • この現象がARDE(マイクロローディング効果)で、同じウエハでも細い穴は浅く、太い穴は深くなり、寸法によって深さがそろわない原因になります。
