グリッチとは

ぐりっち

信号の経路ごとの遅延の差などによって、出力に一瞬だけ現れる不要なパルス。組み合わせ回路ではハザードとも呼び、DAコンバータではコードの切り替わりで生じる。

「グリッチ」は、2分野の5問の練習問題に出てきます(論理回路, AD/DA変換など)。

この用語の分野: 論理回路

グリッチの練習問題に挑戦

出力が現在の状態だけで決まる順序回路(ステートマシン)の型はどれか。

  1. Aミーリ型
  2. Bムーア型
  3. Cハーバード型
答えと解説を見る

正解：B. ムーア型

ムーア型では出力が現在の状態だけで決まり、ミーリ型では状態と入力の両方で決まります。ムーア型は出力が状態レジスタから直接出るのでグリッチが少なく安定し、タイミングも予測しやすい反面、入力への反応が1クロック遅れ、状態数が増えがちです。ミーリ型は状態数を減らせて入力に即座に反応できますが、入力の変化が出力に直接伝わります。実際の設計では両者を組み合わせて使います。

組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。

  1. Aメタステーブル
  2. Bグリッチ(ハザード)
  3. Cラッチアップ
答えと解説を見る

正解：B. グリッチ(ハザード)

同じ入力の変化が異なる経路で出力に届くとき、遅延の差によって出力が一瞬誤った値になることがあり、これをグリッチ(ハザード)といいます。同期式回路ではクロックのエッジまでに落ち着けば機能上は問題ありませんが、余分な充放電で消費電力が増えます。一方、クロックや非同期リセット、他チップへの制御信号にグリッチが乗ると誤動作するため、これらはフリップフロップの出力から直接出すのが鉄則です。

解説の中の「グリッチ」

  • ムーア型は出力が状態レジスタから直接出るのでグリッチが少なく安定し、タイミングも予測しやすい反面、入力への反応が1クロック遅れ、状態数が増えがちです。

    出力が現在の状態だけで決まる順序回路(ステートマシン)の型はどれか。

  • 同じ入力の変化が異なる経路で出力に届くとき、遅延の差によって出力が一瞬誤った値になることがあり、これをグリッチ(ハザード)といいます。

    組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。

  • 隣り合う状態で1ビットしか変わらないため、2入力ゲートだけで各状態をデコードでき、グリッチも起きにくい特徴があります。

    n個のフリップフロップで構成したジョンソンカウンタ(ツイストリングカウンタ)がとる状態の数はいくつか。

  • 上位ビットを同じ重みの電流源の個数で表す温度計符号を使うとグリッチやDNLを抑えられ、通信機器や波形発生器の高速DACに使われています。

    高速なDAコンバータで多く使われる電流ステアリング型の特徴として正しいものはどれか。

  • グリッチは、複数のビットが同時に切り替わるとき、スイッチのタイミングのわずかなずれで中間の誤ったコードが一瞬現れることなどで生じる、とげ状の出力の乱れです。

    DAコンバータで、入力コードが切り替わる瞬間に出力に現れる一時的なとげ状の誤差を何と呼ぶか。

「グリッチ」が出てくる問題(5問)

  1. 出力が現在の状態だけで決まる順序回路(ステートマシン)の型はどれか。
  2. 組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。
  3. n個のフリップフロップで構成したジョンソンカウンタ(ツイストリングカウンタ)がとる状態の数はいくつか。
  4. 高速なDAコンバータで多く使われる電流ステアリング型の特徴として正しいものはどれか。
  5. DAコンバータで、入力コードが切り替わる瞬間に出力に現れる一時的なとげ状の誤差を何と呼ぶか。
