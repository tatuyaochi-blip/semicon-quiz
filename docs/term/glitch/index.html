グリッチとは

ぐりっち

信号の経路ごとの遅延の差などによって、出力に一瞬だけ現れる不要なパルス。組み合わせ回路ではハザードとも呼び、DAコンバータではコードの切り替わりで生じる。

この用語の分野: 論理回路

解説の中の「グリッチ」

  • ムーア型は出力が状態レジスタから直接出るのでグリッチが少なく安定し、タイミングも予測しやすい反面、入力への反応が1クロック遅れ、状態数が増えがちです。

    出力が現在の状態だけで決まる順序回路(ステートマシン)の型はどれか。

  • 同じ入力の変化が異なる経路で出力に届くとき、遅延の差によって出力が一瞬誤った値になることがあり、これをグリッチ(ハザード)といいます。

    組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。

  • 隣り合う状態で1ビットしか変わらないため、2入力ゲートだけで各状態をデコードでき、グリッチも起きにくい特徴があります。

    n個のフリップフロップで構成したジョンソンカウンタ(ツイストリングカウンタ)がとる状態の数はいくつか。

「グリッチ」が出てくる問題(5問)

  1. 出力が現在の状態だけで決まる順序回路(ステートマシン)の型はどれか。
  2. 組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。
  3. n個のフリップフロップで構成したジョンソンカウンタ(ツイストリングカウンタ)がとる状態の数はいくつか。
  4. 高速なDAコンバータで多く使われる電流ステアリング型の特徴として正しいものはどれか。
  5. DAコンバータで、入力コードが切り替わる瞬間に出力に現れる一時的なとげ状の誤差を何と呼ぶか。
