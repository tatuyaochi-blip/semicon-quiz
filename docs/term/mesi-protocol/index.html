MESIプロトコルとは

めしぷろとこる

キャッシュの各ラインをModified・Exclusive・Shared・Invalidの4つの状態で管理するコヒーレンシのプロトコル。書き込みのときにほかのコアのコピーを無効にする。

「MESIプロトコル」は、2分野の4問の練習問題に出てきます(マルチコアと同期, CPU・アーキテクチャなど)。

この用語の分野: マルチコアと同期

4つの状態

Modified(M)は、このキャッシュだけがコピーを持ち、しかも書き込み済みの状態です。メモリの内容は古いので、データは書き戻すか、ほかのキャッシュに供給しなければなりません。Exclusive(E)は唯一のコピーですが、メモリと同じ内容です。Shared(S)は変更されていないコピーで、ほかのキャッシュも持っている可能性があります。Invalid(I)は使えるデータがない状態です。このプロトコルは各ラインについて単一ライタ・複数リーダの規則を保証します。どの時点でも、1つのキャッシュだけが書き込める(MかE)か、任意の数のキャッシュが読める(S)かのどちらかで、両方が同時に成り立つことはありません。

主な状態遷移

読み出しミスでは、キャッシュはラインを要求します。ほかのどのキャッシュも持っていなければEで、持っていればSで読み込みます。ほかのキャッシュがMで持っている場合は、そのキャッシュがデータを供給するか書き戻して、Sに移ります。Sのラインに書き込むには、まずほかのすべてのコピーを無効化するアップグレード要求を出してからMに移ります。書き込みミスでは、ラインの取得とほかのコピーの無効化を1回で行う所有権付き読み出し(RFO)を発行します。ほかのコアの書き込み要求を観測すると手元のコピーはIになり、Mのコピーなら先にデータを引き渡します。

E状態が重要な理由

より単純なMSIプロトコルにはE状態がありません。そのため、コアが自分専用のデータを読んでから書き込むと、ほかのキャッシュがコピーを持っていなくても、バスに余分な無効化要求を出す必要があります。E状態はラインがクリーンで共有されていないことを記録しているので、後の書き込みでは何も通知せずにMへ移れます。多くのデータは1つのコアだけが使うため、これでコヒーレンシのトラフィックが大きく減ります。状態を増やした変種もあり、MOESIはOwned状態を加えて、ダーティなラインを先にメモリを更新せずに共有できるようにし、MESIFはForward状態を加えて、要求に応答する共有者を1つに決めます。

フォールスシェアリング

コヒーレンシは変数単位ではなく、通常64バイトのキャッシュライン単位で管理されます。2つのコアが、たまたま同じラインにある別々の変数に繰り返し書き込むと、書き込みのたびに相手のコアのコピーを無効化しなければなりません。そのため、スレッドどうしは同じデータに一切触れていないのに、ラインが一方のキャッシュではM、他方ではIという状態を行き来します。このフォールスシェアリング(偽共有)によって、並列化したコードが逐次実行より遅くなることさえあります。対策は、カウンタなどスレッドごとに頻繁に書き込むデータを、パディングやアラインメントで別々のラインに分けることです。

MESIプロトコルの練習問題に挑戦

MESIプロトコルでキャッシュのラインがModified(M)状態にあるときの意味として正しいものはどれか。

  1. Aこのコアだけがそのラインを持ち、内容は主記憶と違う(書き戻しが必要)
  2. B複数のコアが同じ内容を持ち、主記憶とも一致している
  3. Cこのラインの内容は使えず、読むにはもう一度取ってくる必要がある
答えと解説を見る

正解：A. このコアだけがそのラインを持ち、内容は主記憶と違う(書き戻しが必要)

M状態は、このコアが書き込みをして、最新の値を自分だけが持っている状態です。主記憶の値は古いので、このラインを追い出すときや、ほかのコアが読もうとしたときには、最新の値を書き戻すか直接渡す必要があります。M状態のラインには、ほかのコアに知らせずにそのまま何度でも書き込めるので、同じコアが続けて書き込むときは速く処理できます。

MESIプロトコルで、Exclusive(E)状態のラインにそのコアが書き込むときの動作として正しいものはどれか。

  1. Aほかのすべてのコアに無効化の要求を送ってから書き込む
  2. B書き込みはできないので、いったん主記憶に書いてから読み直す
  3. Cほかのコアに知らせる必要がなく、そのままM状態に変わる
答えと解説を見る

正解：C. ほかのコアに知らせる必要がなく、そのままM状態に変わる

E状態は、このコアだけがラインを持ち、内容が主記憶と同じ状態です。ほかのコアにコピーがないと分かっているので、書き込むときに無効化の通知をせずにM状態へ移れます。1つのコアだけが使うデータを読んでから書く、というよくある処理で通信を省けるのが、E状態を設ける利点です。S状態から書き込む場合は、ほかのコピーの無効化が必要です。

よくある質問

MESIとMSIの違いは何ですか?

MESIは、ほかのキャッシュが持っていないクリーンなライン用にExclusive状態を追加しています。これによりコアは、MSIでは必要になる無効化のブロードキャストをせずに、そのラインに書き込めます。

MESIのModified状態とはどういう意味ですか?

このキャッシュが唯一の有効なコピーを持っていて、それを変更済みのため、メインメモリの内容が古くなっている状態です。このラインは、追い出すときに書き戻すか、要求してきたほかのコアに供給しなければなりません。

フォールスシェアリングとは何ですか?

別々のコアで動くスレッドが同じキャッシュラインにある別々の変数に書き込むことで、コヒーレンシプロトコルがそのラインをキャッシュ間で行き来させ、性能が落ちる現象です。

解説の中の「MESIプロトコル」

  • コヒーレンシ制御は、各キャッシュラインに「変更済み・共有・無効」などの状態をもたせ(MESIプロトコルなど)、書き込み時に他のコアのコピーを無効にして一貫性を保ちます。

    マルチコアCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組みはどれか。

「MESIプロトコル」が出てくる問題(4問)

  1. MESIプロトコルでキャッシュのラインがModified(M)状態にあるときの意味として正しいものはどれか。
  2. MESIプロトコルで、Exclusive(E)状態のラインにそのコアが書き込むときの動作として正しいものはどれか。
  3. MESIプロトコルで、コア0がModified(M)状態で持っているラインを、コア1が読もうとしたときの一般的な動作はどれか。
  4. マルチコアCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組みはどれか。
