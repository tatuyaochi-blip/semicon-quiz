SIMDとは

しむど

Single Instruction, Multiple Data の略。1つの命令で複数のデータに同じ演算を同時に行う方式。画像処理やAIの計算を高速化する。

「SIMD」は、5分野の7問の練習問題に出てきます(コンパイラ, GPUプログラミング, CPU・アーキテクチャなど)。

この用語の分野: CPU・アーキテクチャ

SIMDの仕組み

SIMD(単一命令・複数データ)ユニットは、幅の広いレジスタを独立したレーンの集まりとして扱います。128ビットのレジスタには32ビットの値が4個、512ビットのレジスタには16個入り、1つの加算命令で全レーンを並列に加算します。x86のSSEやAVX、ArmのNEONやSVEといった命令セット拡張は、整数と浮動小数点のレーン演算のほか、ロード、シャッフル、比較の命令を備えています。フリンの分類では、SIMDは通常の逐次プロセッサであるSISDや、複数のコアが独立した命令列を実行するMIMDと並ぶ位置づけです。画像フィルタ、動画コーデック、行列演算は、一般に数倍以上高速化します。

ループをベクトル化できる条件

コンパイラは、配列の各要素に同じ演算を施すループを自動ベクトル化します。重要な条件は、ループ伝搬依存がないことです。a[i] = a[i-1] + b[i] では各要素が直前の結果を必要とするため、レーンを同時に実行できません。データは連続していることが望ましく、ポインタが重なる可能性(エイリアシング)があるとコンパイラはベクトル化をあきらめることがあります。反復回数がコンパイル時に分からないことは障害になりません。ベクトルループで完全なまとまりを処理し、残りを短い剰余ループで処理します。メディア処理では飽和演算も使われ、8ビット符号付きの127 + 1は −128 に折り返さず127にとどまります。

データ配置:AoSとSoA

構造体の配列(AoS)は、x、y、z、質量のように各レコードのフィールドをまとめて格納します。xだけを読むループでは各キャッシュラインの大部分が無駄になり、ベクトルレーンを埋めるのにギャザーやシャッフルの処理が必要になります。配列の構造体(SoA)はすべてのxを連続して並べるため、取り込んだラインが全部使われ、メモリトラフィックが大幅に減ることがあり、1回のベクトルロードで直接レーンを埋められます。同じ配置にすると、GPUでも隣り合うスレッドが隣り合うアドレスを読むため、メモリアクセスが結合(コアレス)されます。

SIMDとSIMT

CPUのSIMDでは、プログラマやコンパイラが固定幅のベクトル命令を明示的に使うため、ベクトル幅を意識してコードを書きます。GPUのSIMT(単一命令・複数スレッド)では、プログラマは1スレッド分の普通のコードを書き、ハードウェアがスレッドをグループ(一般に32スレッド)にまとめて、共通の命令発行でロックステップ実行します。グループ内のスレッドが異なる分岐に進むと、ハードウェアは非アクティブなスレッドをマスクしながら各パスを順に実行するので、コードは動作しますが効率は下がります。根底にあるのは、1つの命令のコストを多数のデータ要素で分け合うという同じ原理です。

SIMDの練習問題に挑戦

GPUのSIMT(単一命令・複数スレッド)の方式と、CPUのSIMD命令の違いとして正しいものはどれか。

  1. ASIMTは1つのデータに複数の命令を同時に行い、SIMDは1つの命令を1つのデータに行う
  2. BSIMTとSIMDはまったく同じもので、名前が違うだけである
  3. CSIMTでは各スレッドを独立したプログラムとして書け、分岐もハードウェアが処理するが、SIMDではプログラマやコンパイラが幅の決まったベクトルの命令を明示的に使う
答えと解説を見る

正解：C. SIMTでは各スレッドを独立したプログラムとして書け、分岐もハードウェアが処理するが、SIMDではプログラマやコンパイラが幅の決まったベクトルの命令を明示的に使う

CPUのSIMDでは、4個や8個のデータをまとめたベクトルのレジスタに1つの命令をかけるので、プログラムはベクトルの幅を意識して書きます。GPUのSIMTでは、プログラマは1本のスレッドの処理を普通に書き、ハードウェアが32本ずつ束ねて同じ命令で動かします。スレッドごとに分岐してもよく、ハードウェアが分岐した経路を順に実行しますが、そのときは効率が下がります。

よくある質問

SIMDとは何の略で、何をするもの?

Single Instruction, Multiple Dataの略で、幅の広いレジスタに詰め込んだ複数のデータ要素を1つの命令で処理します。たとえば128ビットのレジスタに入れた4個の32ビット数を一度に演算します。

ループが自動ベクトル化されないのはなぜ?

よくある原因は、反復が前の反復の結果を必要とするループ伝搬依存、連続していないメモリアクセス、コンパイラが否定できないポインタのエイリアシングの可能性です。

SIMDとSIMTの違いは?

SIMDはCPUで固定幅のベクトル命令を明示的に使う方式です。GPUで使われるSIMTは、スレッドごとのスカラーコードをスレッドのグループでロックステップ実行し、分岐の分かれ(ダイバージェンス)はハードウェアが処理します。
