SIMDとは

しむど

Single Instruction, Multiple Data の略。1つの命令で複数のデータに同じ演算を同時に行う方式。画像処理やAIの計算を高速化する。

この用語の分野: CPU・アーキテクチャ

解説の中の「SIMD」

  • ベクトル化では、例えば4つの要素の計算を1つのSIMD命令で同時に行います。

    上のループを、SIMD命令を使ってベクトル化しにくい主な理由はどれか。

  • CPUのSIMDでは、4個や8個のデータをまとめたベクトルのレジスタに1つの命令をかけるので、プログラムはベクトルの幅を意識して書きます。

    GPUのSIMT(単一命令・複数スレッド)の方式と、CPUのSIMD命令の違いとして正しいものはどれか。

  • SIMDは、1つの命令で複数のデータに同じ演算を並列に行う方式で、例えば512ビットのレジスタなら32ビットの数値16個を一度に計算できます。

    1つの命令で複数のデータに同じ演算を同時に行う方式はどれか。

「SIMD」が出てくる問題(7問)

  1. 上のループを、SIMD命令を使ってベクトル化しにくい主な理由はどれか。
  2. GPUのSIMT(単一命令・複数スレッド)の方式と、CPUのSIMD命令の違いとして正しいものはどれか。
  3. 1つの命令で複数のデータに同じ演算を同時に行う方式はどれか。
  4. 信号処理で使われる飽和演算の説明として正しいものはどれか。
  5. コンパイラの自動ベクトル化で使われる命令の種類として正しいものはどれか。
  6. 上のようにx座標だけを合計する処理を、配列の構造体(各成分を別々の配列にする形)に書き換えると速くなりやすい理由はどれか。
  7. 粒子の位置x、y、zを持つデータをGPUで処理するとき、メモリ合体アクセスの点で有利な並べ方はどれか。
