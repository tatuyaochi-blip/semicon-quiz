PLL(位相同期回路)とは

ぴーえるえる

基準クロックとの位相差を検出して発振器を制御し、基準に同期した、整数倍などの周波数のクロックをつくる回路。CPUのクロック生成や無線の周波数合成に使われる。

この用語の分野: アナログ・電子回路

解説の中の「PLL(位相同期回路)」

  • 共振周波数 f = 1/(2π√(LC)) を電圧で調整できるため、チューナーや電圧制御発振器(VCO)、PLLに使われます。

    可変容量ダイオード(バラクタダイオード)が利用している性質はどれか。

  • PLLの帰還回路でも分周器が使われ、例えば100 MHzの基準から分周比を変えて数GHzの周波数を合成します。

    クロックが入るたびに出力が反転するTフリップフロップ1個の出力の周波数は、クロック周波数の何倍になるか。

  • PLLは、位相比較器、ループフィルタ、電圧制御発振器(VCO)、分周器で構成され、VCOの出力を分周した信号と基準クロックの位相が一致するように制御します。

    基準クロックに位相を合わせながら、その整数倍などの周波数のクロックをつくる回路はどれか。

「PLL(位相同期回路)」が出てくる問題(8問)

  1. 可変容量ダイオード(バラクタダイオード)が利用している性質はどれか。
  2. クロックが入るたびに出力が反転するTフリップフロップ1個の出力の周波数は、クロック周波数の何倍になるか。
  3. 基準クロックに位相を合わせながら、その整数倍などの周波数のクロックをつくる回路はどれか。
  4. 水晶発振器が、時計やマイコンのクロック源として広く使われる主な理由はどれか。
  5. クロック源として、水晶振動子の代わりに使われることがあるMEMS発振器の利点として正しいものはどれか。
  6. 実際の動作周波数でテストを行い、信号の伝わる速さが遅すぎる不良を検出するテストを何と呼ぶか。
  7. テストベンチの上の記述で作られるクロックの周期はいくらか(時間の単位は1 nsとする)。
  8. 高速なシリアル伝送の受信側にあるクロック・データ・リカバリ(CDR)回路の役割として正しいものはどれか。
