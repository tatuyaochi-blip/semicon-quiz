エイリアシングとは

えいりあしんぐ

サンプリング周波数の半分を超える成分が、低い周波数の成分として誤って現れる現象。AD変換の前にローパスフィルタで防ぐ。

やさしい解説で読む: アナログ半導体とは? デジタルと何が違い、どこで使われる?

「エイリアシング」は、3分野の7問の練習問題に出てきます(AD/DA変換, デジタル信号処理の基礎, イメージセンサ・光デバイスなど)。

この用語の分野: AD/DA変換

エイリアシングが起こるしくみ

サンプリング周波数 fs でサンプリングすると、1/fs 秒ごとに一つの値しか記録されません。周波数 f の正弦波は、任意の整数 n について、位相を適切に合わせた周波数 |f − n·fs| の正弦波とまったく同じサンプル値になります。そのため、ナイキスト周波数 fs/2 を超える成分は折り返され、低い周波数の成分になりすまします。たとえば 10 kHz の信号を 12 kHz でサンプリングすると 2 kHz に現れます。一度サンプリングされると、この偽の信号は本物の 2 kHz の信号と区別できず、取り除くこともできません。映画で馬車の車輪が逆回転して見える現象も、時間方向の同じ効果です。

ナイキストレートとアンチエイリアシングフィルタ

サンプリング定理では、fs は信号に含まれる最高周波数の 2 倍を超える必要があり、20 kHz までの成分なら 40 kHz より高い周波数が必要です。実際のフィルタは急に遮断できないため、遷移帯域を設けます。音楽 CD は 44.1 kHz でサンプリングし、20〜22.05 kHz をフィルタの減衰に充てています。アンチエイリアシングフィルタは AD コンバータ(ADC)の前に置くローパスフィルタです。バターワース特性は通過域が最も平坦で、チェビシェフ特性はリップルと引き換えに急峻さを得て、ベッセル特性は波形の形を保ちます。オーバーサンプリングで間隔を広げれば簡単な RC フィルタで足り、急峻なフィルタリングとデシメーションは後段のデジタル処理で行えます。

アンダーサンプリング:エイリアシングの活用

エイリアシングを意図的に利用することもあります。高い周波数を中心とする帯域制限された信号は、最高周波数の 2 倍ではなく帯域幅の 2 倍を超える周波数でサンプリングすれば、低い周波数へ折り返させることができます。これをアンダーサンプリング(バンドパスサンプリング)と呼びます。たとえば帯域幅 10 MHz の 70 MHz の信号を 56 MS/s でサンプリングすると 14 MHz に現れ、アナログミキサーの代わりになります。ただし ADC のサンプル・ホールド回路は 70 MHz に対応する入力帯域を持つ必要があり、サンプリングクロックのジッタもその入力周波数に見合うほど小さくなければならず、要求は厳しくなります。

雑音の折り返しと別の意味のエイリアシング

エイリアシングは単一の周波数成分だけでなく雑音にも影響します。ナイキスト周波数を超える広帯域雑音はベースバンドに折り返されてノイズフロアを押し上げます。妨害信号が想定されない場合でもアンチエイリアシングフィルタが重要なのは、これが理由の一つです。画像では、細かな模様をサンプリング不足で取り込むとモアレが生じ、これは同じ効果の空間版です。ソフトウェアでは無関係な意味で使われます。二つのポインタが同じメモリを指しうるポインタエイリアシングがあると、コンパイラはストアをまたいで値をレジスタに保持できません。C 言語の restrict 修飾子は、そうした重なりがないことを保証するものです。

正解：C. 40 kHzより高い周波数

サンプリング定理により、最高周波数の2倍より高い周波数でサンプリングすれば元の信号を復元でき、20 kHzなら40 kHzより高い周波数が必要です。実際にはフィルタで急に切ることができないため余裕をとり、音楽CDは44.1 kHzでサンプリングしています(20〜22.05 kHzをフィルタの遷移帯域に使う)。サンプリング周波数の半分をナイキスト周波数と呼びます。

よくある質問

エイリアス周波数はどう計算しますか?

入力周波数に最も近いサンプリング周波数の整数倍を探し、その差の絶対値 |f − n·fs| をとります。たとえば 10 kHz を 12 kHz でサンプリングすると、|10 − 12| = 2 kHz に現れます。

ナイキスト周波数とは何ですか?

サンプリング周波数の半分の周波数で、エイリアシングを起こさずに表現できる最高の周波数です。これを超える成分は、それより下の帯域に折り返されます。

サンプリング後にデジタルフィルタでエイリアシングを除去できますか?

できません。いったん低い周波数に折り返された成分は正規の信号と同じ周波数を占めるため、サンプリング前にアナログ領域で除去する必要があります。
