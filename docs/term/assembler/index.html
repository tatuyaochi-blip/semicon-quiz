アセンブラとは

あせんぶら

アセンブリ言語で書いたプログラムを、機械語の命令のビット列に変換するソフトウェア。ラベルを番地に直し、疑似命令を本物の命令に置き換える。

「アセンブラ」は、2分野の6問の練習問題に出てきます(命令セット・アセンブリ, コンパイラなど)。

この用語の分野: 命令セット・アセンブリ

アセンブラの練習問題に挑戦

RISC-Vの疑似命令「nop」(何もしない)は、アセンブラによって実際にはどの命令に置き換えられるか。

  1. Aaddi x0, x0, 0
  2. Bjal ra, 0
  3. Clw x0, 0(sp)
答えと解説を見る

正解：A. addi x0, x0, 0

RISC-Vには「何もしない」専用の命令はなく、nopは「addi x0, x0, 0」として表されます。x0への書き込みは捨てられるので、レジスタもメモリも何も変わりません。同様に「mv rd, rs」は「addi rd, rs, 0」、「j label」は「jal x0, label」、「ret」は「jalr x0, 0(ra)」です。x0を使って命令の種類を少なく保つのがRISC-Vの設計の考え方です。

解説の中の「アセンブラ」

  • アセンブリ言語は、機械語の命令を「add a0, a0, a1」のような人が読める記号(ニーモニック)で書いたもので、アセンブラが命令のビット列に変換します。

    アセンブリ言語と機械語の関係として正しいものはどれか。

  • アセンブリで「li a0, 0x12345678」と書くと、アセンブラが必要に応じてこの2命令に展開します。

    RISC-Vで、12ビットの即値に収まらない32ビットの定数(例: 0x12345678)をレジスタに入れる一般的な方…

  • 下位12ビットのビット11が1のときは上位に1を足しておく、というこの補正は、アセンブラやリンカが自動で行います。

    RISC-Vで定数0x12345FFFをluiとaddiの2命令で作るとき、正しい組み合わせはどれか。

  • これより遠い分岐は、条件を逆にした短い分岐で、遠くへ届くjal(およそ±1MiB)を飛び越える形に、アセンブラが書き換えます。

    RISC-Vの条件分岐命令(B形式)は、分岐先までの距離を13ビットの符号付きのバイト数で表し、その最下位ビットは常に…

  • C言語のソースファイルは、まずコンパイラで機械語に近いアセンブリ言語(または直接オブジェクトファイル)に変換され、アセンブラで機械語のオブジェクトファイルになります。

    C言語のプログラムから実行ファイルができるまでの一般的な流れとして正しいものはどれか。

「アセンブラ」が出てくる問題(6問)

  1. RISC-Vの疑似命令「nop」(何もしない)は、アセンブラによって実際にはどの命令に置き換えられるか。
  2. アセンブリ言語と機械語の関係として正しいものはどれか。
  3. RISC-Vで、12ビットの即値に収まらない32ビットの定数(例: 0x12345678)をレジスタに入れる一般的な方法はどれか。
  4. RISC-Vで定数0x12345FFFをluiとaddiの2命令で作るとき、正しい組み合わせはどれか。
  5. RISC-Vの条件分岐命令(B形式)は、分岐先までの距離を13ビットの符号付きのバイト数で表し、その最下位ビットは常に0として命令に入れない。分岐命令が直接届く範囲としておよそ正しいものはどれか。
  6. C言語のプログラムから実行ファイルができるまでの一般的な流れとして正しいものはどれか。
