テストベンチとは

てすとべんち

検証する回路に入力を与え、出力が正しいかを確かめるためのシミュレーション用の記述。論理合成はしないので、遅延や表示の命令などを自由に使える。

「テストベンチ」は、2分野の8問の練習問題に出てきます(ハードウェア記述言語と検証, LSI設計フロー・EDAなど)。

この用語の分野: ハードウェア記述言語と検証

テストベンチの練習問題に挑戦

SystemVerilogを使った検証で、再利用しやすいテスト環境(テストベンチ)を組み立てるための標準的な方法論はどれか。

  1. AOPC
  2. BCMP
  3. CUVM(Universal Verification Methodology)
答えと解説を見る

正解：C. UVM(Universal Verification Methodology)

UVMは、SystemVerilogでテストベンチを部品(入力を与えるドライバ、出力を監視するモニタ、期待値と比べるスコアボードなど)の組み合わせとして構成するための標準的な方法論とクラスライブラリです。部品を他の設計の検証にも再利用でき、制約付きランダムな入力の生成やカバレッジの収集を組み込みやすくなります。IEEE 1800.2として標準化されています。OPCとCMPは製造の技術です。

HDLの検証で使うテストベンチの説明として正しいものはどれか。

  1. A回路を製造するための工場の設備
  2. B検証する回路に入力を与え、出力が正しいかを確かめるためのシミュレーション用の記述で、論理合成はしない
  3. C回路の消費電力を測るための測定器
答えと解説を見る

正解：B. 検証する回路に入力を与え、出力が正しいかを確かめるためのシミュレーション用の記述で、論理合成はしない

テストベンチは、検証する回路(DUT)をインスタンス化し、クロックやリセット、入力の信号を作って与え、出力を観察するためのHDLの記述です。回路にはしないので、遅延の指定やファイルの読み書き、表示の命令など、シミュレーション用の機能を自由に使えます。設計と同じくらい、あるいはそれ以上の手間をかけて作られることもあります。

「テストベンチ」が出てくる問題(8問)

  1. SystemVerilogを使った検証で、再利用しやすいテスト環境(テストベンチ)を組み立てるための標準的な方法論はどれか。
  2. HDLの検証で使うテストベンチの説明として正しいものはどれか。
  3. テストベンチの上の記述で作られるクロックの周期はいくらか(時間の単位は1 nsとする)。
  4. テストベンチで、回路への入力をクロックの立ち上がりと同じ時刻にブロッキング代入で変えると、問題が起きることがある。主な理由と対策の組み合わせとして正しいものはどれか。
  5. 自己チェック型のテストベンチの特徴として正しいものはどれか。
  6. 次のVerilogの記述のうち、論理合成で回路にならず無視されるもの(シミュレーション用の記述)はどれか。
  7. 回路の設計で行われる回帰テスト(リグレッションテスト)の説明として正しいものはどれか。
  8. Verilogの等号の演算子「==」と「===」の違いとして正しいものはどれか。
