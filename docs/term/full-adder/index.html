全加算器とは

ぜんかさんき

2つのビットと下位の桁からの桁上げの3入力を足し、和と上位への桁上げを出す回路。桁上げ入力のないものは半加算器。直列につなぐと多ビットの加算器になる。

「全加算器」は、2分野の5問の練習問題に出てきます(論理回路, 計算機算術など)。

この用語の分野: 論理回路

全加算器の練習問題に挑戦

全加算器の入力として正しい組み合わせはどれか。

  1. A加える2つのビットと、下位の桁からの桁上げ
  2. B加える2つのビットだけ
  3. Cクロック信号だけ
答えと解説を見る

正解：A. 加える2つのビットと、下位の桁からの桁上げ

全加算器は、加える2つのビットA、Bと下位からの桁上げCinの3入力から、和と上位への桁上げを出力します。nビットの加算には全加算器をn個つなぎます(リップルキャリー加算器)。最下位のCinを1にしてBを反転すれば A − B = A + (¬B + 1) となり、同じ回路で減算もできます。この性質によりCPUのALUは1つの加算器で加減算を兼ねています。

全加算器を直列につないだリプルキャリー加算器の欠点として正しいものはどれか。

  1. A負の数を扱えない
  2. B桁上げが下位から順に伝わるため、ビット数に比例して遅延が大きくなる
  3. Cビット数が増えても回路の規模が変わらない
答えと解説を見る

正解：B. 桁上げが下位から順に伝わるため、ビット数に比例して遅延が大きくなる

リプルキャリー加算器では、各全加算器が下位からの桁上げを待ってから計算するため、桁上げが最下位から最上位まで順に伝わり、遅延がビット数に比例して増えます。64ビットでは全加算器64段分の遅延になり、GHzで動くCPUには遅すぎます。回路が小さく単純なので、速度が問われない用途で使われます。高速化には桁上げ先見、桁上げ選択、並列プレフィックス(Kogge-Stone など)加算器が使われます。

解説の中の「全加算器」

  • 全加算器は、加える2つのビットA、Bと下位からの桁上げCinの3入力から、和と上位への桁上げを出力します。

    全加算器の入力として正しい組み合わせはどれか。

  • リプルキャリー加算器では、各全加算器が下位からの桁上げを待ってから計算するため、桁上げが最下位から最上位まで順に伝わり、遅延がビット数に比例して増えます。

    全加算器を直列につないだリプルキャリー加算器の欠点として正しいものはどれか。

  • 下位からの桁上げも加える全加算器は、半加算器2つとORゲートで構成でき、和は A⊕B⊕Cin、桁上げは AB + Cin(A⊕B) になります。

    1ビットの半加算器で、和(S)と桁上げ(C)を出力する論理として正しいものはどれか。

  • 論理式は AB + BC + CA で、全加算器の桁上げ出力と同じ論理になります。

    3入力の多数決回路の出力が1になる条件として正しいものはどれか。

  • 桁上げ保存加算器は、全加算器を桁ごとに独立に並べたもので、3つの数を「各桁の和」と「各桁の桁上げ」の2つの数にまとめるだけなので、桁上げの伝わりを待たず、遅延は全加算器1段分で一定です。

    乗算器で多数の部分積を足し合わせるのに、桁上げ保存加算器が使われる主な理由はどれか。

「全加算器」が出てくる問題(5問)

  1. 全加算器の入力として正しい組み合わせはどれか。
  2. 全加算器を直列につないだリプルキャリー加算器の欠点として正しいものはどれか。
  3. 1ビットの半加算器で、和(S)と桁上げ(C)を出力する論理として正しいものはどれか。
  4. 3入力の多数決回路の出力が1になる条件として正しいものはどれか。
  5. 乗算器で多数の部分積を足し合わせるのに、桁上げ保存加算器が使われる主な理由はどれか。
