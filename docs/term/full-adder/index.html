全加算器とは

ぜんかさんき

2つのビットと下位の桁からの桁上げの3入力を足し、和と上位への桁上げを出す回路。桁上げ入力のないものは半加算器。直列につなぐと多ビットの加算器になる。

「全加算器」は、2分野の5問の練習問題に出てきます(論理回路, 計算機算術など)。

この用語の分野: 論理回路

全加算器の論理

全加算器は、A、Bと桁上げ入力Cinの3つの1ビット入力を足し、和Sと桁上げ出力Coutを出す回路で、出力を合わせた値は1である入力の個数に等しくなります。和は入力のパリティで S = A ⊕ B ⊕ Cin、桁上げは入力の多数決で Cout = AB + BC + CA です。半加算器は2入力だけを扱い、和は A ⊕ B、桁上げは AB です。そのため全加算器は、2つの半加算器と、それぞれの桁上げをまとめるORゲート1つで構成できます。

リップルキャリー加算と減算

n個の全加算器を、各桁上げ出力が次の桁上げ入力につながるように直列につなぐと、nビットのリップルキャリー加算器になります。小さく規則的な構造ですが、桁上げがすべての段を伝わり終わるまで最上位ビットが確定しないため、遅延はビット幅に比例して増えます。64ビットの加算器では全加算器約64個分の遅延がかかり、GHz動作のプロセッサのデータパスには遅すぎます。同じ回路で減算もできます。Bを反転し、最下位の桁上げ入力を1にすると A + (¬B + 1) が計算され、これは2の補数表現での A − B なので、ALUは1つの加算器で加算と減算の両方をこなせます。

桁上げを高速化する方法

高速な加算器は、リップル伝搬を待たずに桁上げを求めます。各ビット位置は、G = AB のときに桁上げを生成し、P = A ⊕ B のときに入ってきた桁上げを伝搬させます。桁上げ先見加算器(キャリールックアヘッド加算器)は、複数ビットのグループについて桁上げの漸化式をGとPで展開して計算します。桁上げ選択加算器(キャリーセレクト加算器)は、上位の和を桁上げ入力が0と1の両方の場合について計算しておき、実際の桁上げが届いた時点で一方を選びます。Kogge-Stone加算器などの並列プレフィックス加算器は、GとPを木構造で組み合わせることで桁上げ遅延を log2 n に比例する程度に抑えますが、配線と面積は大幅に増えます。

加算器以外での全加算器の使われ方

乗算器では多数の部分積を一度に足すため、全加算器を3:2コンプレッサとして使います。同じ重みの3ビットを受け取り、和ビットと1つ上の重みの桁上げビットを出力するという使い方です。WallaceツリーやDaddaツリーのようなキャリーセーブ加算器の木によって多数の行を2行まで減らし、最後に1つの高速加算器で最終結果を求めます。トランジスタレベルでは、桁上げ回路を共有し、反転した桁上げから和を生成する28トランジスタのミラー加算器が、スタティックCMOSによる代表的な実装です。

全加算器の練習問題に挑戦

全加算器の入力として正しい組み合わせはどれか。

  1. A加える2つのビットと、下位の桁からの桁上げ
  2. B加える2つのビットだけ
  3. Cクロック信号だけ
答えと解説を見る

正解：A. 加える2つのビットと、下位の桁からの桁上げ

全加算器は、加える2つのビットA、Bと下位からの桁上げCinの3入力から、和と上位への桁上げを出力します。nビットの加算には全加算器をn個つなぎます(リップルキャリー加算器)。最下位のCinを1にしてBを反転すれば A − B = A + (¬B + 1) となり、同じ回路で減算もできます。この性質によりCPUのALUは1つの加算器で加減算を兼ねています。

全加算器を直列につないだリプルキャリー加算器の欠点として正しいものはどれか。

  1. A負の数を扱えない
  2. B桁上げが下位から順に伝わるため、ビット数に比例して遅延が大きくなる
  3. Cビット数が増えても回路の規模が変わらない
答えと解説を見る

正解：B. 桁上げが下位から順に伝わるため、ビット数に比例して遅延が大きくなる

リプルキャリー加算器では、各全加算器が下位からの桁上げを待ってから計算するため、桁上げが最下位から最上位まで順に伝わり、遅延がビット数に比例して増えます。64ビットでは全加算器64段分の遅延になり、GHzで動くCPUには遅すぎます。回路が小さく単純なので、速度が問われない用途で使われます。高速化には桁上げ先見、桁上げ選択、並列プレフィックス(Kogge-Stone など)加算器が使われます。

よくある質問

半加算器と全加算器の違いは?

半加算器は2つのビットを足して和と桁上げを出し、全加算器は2つのビットに下位からの桁上げ入力を加えて足します。多ビットの数を足すために直列につなげられるのは全加算器だけです。

全加算器の論理式は?

和は Sum = A ⊕ B ⊕ Cin、桁上げは Cout = AB + BC + CA で、これは AB + Cin(A ⊕ B) と同じです。桁上げ出力は3入力の多数決関数になっています。

全加算器は半加算器何個で作れますか?

2個です。1個目でAとBを足し、2個目でその和にCinを足し、2つの桁上げ出力をORゲートでまとめてCoutにします。
