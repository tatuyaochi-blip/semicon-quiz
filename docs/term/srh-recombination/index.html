SRH再結合(ショックレー・リード・ホール再結合)とは

えすあーるえいちさいけつごう

禁制帯の中にできた深い準位(トラップ)を介して電子と正孔が再結合する過程。シリコンの少数キャリアの寿命を主に決め、金属汚染や結晶欠陥で速くなる。

この用語の分野: 半導体物性

解説の中の「SRH再結合(ショックレー・リード・ホール再結合)」

  • 金や鉄などの重金属や結晶欠陥は、ギャップの中ほどに深い準位をつくり、電子と正孔の再結合を仲立ちする再結合中心になります(SRH再結合)。

    シリコン中の少数キャリアのライフタイム(寿命)を短くする要因として代表的なものはどれか。

  • 金属不純物や結晶欠陥がつくる深い準位(トラップ)が電子と正孔を順に捕まえて再結合させる過程がSRH再結合です。

    禁制帯の中にできた深い準位(トラップ)を介して電子と正孔が再結合する過程を何と呼ぶか。

  • その間にSRH再結合などで熱になってしまうため、シリコンは発光素子に向きません。

    シリコンのような間接遷移型の半導体で、電子と正孔が再結合して光を出す確率が低い理由として正しいものはどれか。
