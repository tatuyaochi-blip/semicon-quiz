SRH再結合(ショックレー・リード・ホール再結合)とは

えすあーるえいちさいけつごう

禁制帯の中にできた深い準位(トラップ)を介して電子と正孔が再結合する過程。シリコンの少数キャリアの寿命を主に決め、金属汚染や結晶欠陥で速くなる。

「SRH再結合(ショックレー・リード・ホール再結合)」は、1分野の3問の練習問題に出てきます(半導体物性など)。

この用語の分野: 半導体物性

トラップが再結合を仲介する仕組み

禁制帯の中にある深い準位は、伝導帯から電子を捕獲し、次に価電子帯から正孔を捕獲することで、2段階で電子・正孔対を消滅させます。捕獲したキャリアを元のバンドへ放出する過程がこれと競合します。正味の再結合速度はU = (np − ni²) / [τp(n + n1) + τn(p + p1)]で表され、n1とp1はトラップの準位の位置を表します。ミッドギャップ付近のトラップではn1とp1が最も小さくなるため、最も効果的な再結合中心になります。放出されたエネルギーは光ではなく、主に格子振動になります。

ライフタイムとそれを縮める要因

特性的な捕獲ライフタイムはτ = 1/(σ·vth·Nt)で表されます。σは捕獲断面積、vthは熱速度、Ntはトラップ密度で、ライフタイムはトラップ濃度に反比例して短くなります。鉄や金などの重金属や、転位などの結晶欠陥が典型的な原因です。シリコンは放射再結合の弱い間接遷移型半導体なので、中程度のキャリア密度ではSRH再結合が支配的となり、少数キャリアの寿命を決めます。少数キャリアの寿命は一般に光導電減衰法で測定します。

意図的なライフタイム制御

高速スイッチングデバイスでは、短いライフタイムが必要になることがあります。ファストリカバリダイオードやIGBTでは、白金や金の拡散、あるいは電子線やプロトンの照射によって意図的に再結合中心を導入し、ターンオフ時に蓄積された少数キャリアがすばやく消えるようにします。これにより逆回復時間とスイッチング損失は減りますが、順方向電圧降下とリーク電流は増えるため、ライフタイムは導通損失とスイッチング損失の妥協点として調整されます。

SRH生成とリーク電流

逆バイアスされた空乏層のようにnpがni²より小さい状態では、同じトラップが逆向きに働いて電子・正孔対を生成します。この生成電流は、室温のシリコンpn接合における逆方向リーク電流や、イメージセンサの暗電流の主な原因です。生成電流はexp(−Eg/2kT)に従うniに比例するため、活性化エネルギーはバンドギャップの約半分です。一方、ni²に比例する拡散電流の活性化エネルギーはほぼバンドギャップ全体に等しく、高温では拡散電流が支配的になります。

SRH再結合(ショックレー・リード・ホール再結合)の練習問題に挑戦

シリコン中の少数キャリアのライフタイム(寿命)を短くする要因として代表的なものはどれか。

  1. A金などの深い準位をつくる不純物や結晶欠陥
  2. B温度を極低温にすること
  3. C真空中にウエハを置くこと
答えと解説を見る

正解：A. 金などの深い準位をつくる不純物や結晶欠陥

金や鉄などの重金属や結晶欠陥は、ギャップの中ほどに深い準位をつくり、電子と正孔の再結合を仲立ちする再結合中心になります(SRH再結合)。中央に近い準位ほど再結合を強く促すため、ライフタイムが短くなります。逆に高速ダイオードやIGBTでは、蓄積された少数キャリアを早く消すため、白金拡散や電子線・プロトン照射でわざとライフタイムを短くします。極低温や真空はライフタイムを短くする代表的な要因ではありません。

禁制帯の中にできた深い準位(トラップ)を介して電子と正孔が再結合する過程を何と呼ぶか。

  1. ASRH(ショックレー・リード・ホール)再結合
  2. B放射再結合
  3. Cオージェ再結合
答えと解説を見る

正解：A. SRH(ショックレー・リード・ホール)再結合

金属不純物や結晶欠陥がつくる深い準位(トラップ)が電子と正孔を順に捕まえて再結合させる過程がSRH再結合です。トラップの準位がギャップ中央に近いほど効率よく働きます。シリコンのような間接遷移型では主要な再結合過程で、少数キャリアのライフタイムを決めます。空乏層内でのSRH過程による生成は、pn接合の逆方向漏れ電流やイメージセンサの暗電流の主な原因でもあります。

よくある質問

ミッドギャップのトラップが最も効果的な再結合中心になるのはなぜですか?

ミッドギャップの準位は電子と正孔の両方を同程度の速さで捕獲でき、熱的に再放出することもまれなため、捕獲されたキャリアはバンドに戻るよりも再結合しやすいからです。

SRH再結合、放射再結合、オージェ再結合の違いは何ですか?

SRH再結合はトラップ準位を介する過程で、中程度の密度のシリコンで支配的です。放射再結合は光子を放出する過程で、直接遷移型の材料で強く起こります。オージェ再結合はエネルギーを3つ目のキャリアに渡す過程で、キャリア密度が非常に高いときに支配的になります。

シリコンの少数キャリアの寿命を短くするものは何ですか?

鉄や金のような深い準位をつくる不純物や結晶欠陥で、これらがSRH再結合中心として働きます。ライフタイムはその密度にほぼ反比例して短くなります。
