デマンドページングとは

でまんどぺーじんぐ

プログラムのページを最初から全部読み込まず、初めてアクセスされてページフォルトが起きたときに物理メモリへ読み込む方式。起動が速く、使わない部分のメモリを節約できる。

「デマンドページング」は、1分野の4問の練習問題に出てきます(OSとハードウェアなど)。

この用語の分野: OSとハードウェア

デマンドページングの練習問題に挑戦

デマンドページングの説明として正しいものはどれか。

  1. Aプログラムを起動するときに、すべてのページを先に物理メモリへ読み込んでおく
  2. Bよく使うページを、ディスクではなくキャッシュに常に固定しておく
  3. Cページを初めて使うときにページフォルトを起こし、そのとき物理メモリへ読み込む
答えと解説を見る

正解：C. ページを初めて使うときにページフォルトを起こし、そのとき物理メモリへ読み込む

デマンドページングでは、プログラムの起動時にはページテーブルを用意するだけで、実際のページは読み込みません。初めてアクセスしたときにページフォルトが起き、OSがそのページだけをディスクから読み込みます。起動が速くなり、一度も使わないコードやデータのためにメモリを使わずに済みます。最初に全部読み込む方式とは逆の考え方で、キャッシュへの固定とも関係ありません。

解説の中の「デマンドページング」

  • デマンドページングでは、プログラムの起動時にはページテーブルを用意するだけで、実際のページは読み込みません。

    デマンドページングの説明として正しいものはどれか。

  • コンテキストスイッチは実行するプロセスを切り替えること、デマンドページングはページを必要になったときに読み込む方式です。

    アプリケーションがファイルの読み書きなどをOSに依頼するしくみを何と呼ぶか。

  • コピーオンライトとデマンドページングはメモリ管理の方式です。

    仮想マシンのOSが特権の必要な命令を実行したとき、ハイパーバイザに処理が移り、ハイパーバイザがその命令の効果を代わりに…

  • デマンドページングと同じしくみで、読み出しのたびにシステムコールを呼ぶ必要がなく、データの余分なコピーも減らせます。

    ファイルをメモリに対応づける(mmapのような)しくみで、ファイルの内容を読むときに起こることの説明として正しいものは…

「デマンドページング」が出てくる問題(4問)

  1. デマンドページングの説明として正しいものはどれか。
  2. アプリケーションがファイルの読み書きなどをOSに依頼するしくみを何と呼ぶか。
  3. 仮想マシンのOSが特権の必要な命令を実行したとき、ハイパーバイザに処理が移り、ハイパーバイザがその命令の効果を代わりに再現する方式を何と呼ぶか。
  4. ファイルをメモリに対応づける(mmapのような)しくみで、ファイルの内容を読むときに起こることの説明として正しいものはどれか。
