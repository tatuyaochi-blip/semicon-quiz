ディレクトリ方式とは

でぃれくとりほうしき

各ラインをどのコアが持っているかを表に記録し、関係するコアにだけ通知するコヒーレンシの方式。コアの数が多いシステムで使われる。

「ディレクトリ方式」は、2分野の3問の練習問題に出てきます(マルチコアと同期, CPU・アーキテクチャなど)。

この用語の分野: マルチコアと同期

ディレクトリ方式の練習問題に挑戦

コアの数が多いシステムで、スヌーピング方式の代わりにディレクトリ方式のコヒーレンシが使われる理由として正しいものはどれか。

  1. A各ラインをどのコアが持っているかを記録しておき、関係するコアにだけ通知することで通信を減らせるから
  2. Bディレクトリ方式ではキャッシュが不要になるから
  3. Cディレクトリ方式では書き込みのたびにすべてのコアへ通知できるから
答えと解説を見る

正解：A. 各ラインをどのコアが持っているかを記録しておき、関係するコアにだけ通知することで通信を減らせるから

ディレクトリ方式では、各ラインについて、どのコアがコピーを持ち、どの状態かを記録した表(ディレクトリ)を持ちます。書き込みがあると、ディレクトリを見てコピーを持つコアにだけ無効化の要求を送ります。すべてのキャッシュへ一斉に知らせるスヌーピングに比べて通信が少ないので、コアが数十以上あるサーバ向けのCPUなどで使われます。

解説の中の「ディレクトリ方式」

  • ディレクトリ方式では、各ラインについて、どのコアがコピーを持ち、どの状態かを記録した表(ディレクトリ)を持ちます。

    コアの数が多いシステムで、スヌーピング方式の代わりにディレクトリ方式のコヒーレンシが使われる理由として正しいものはどれ…

  • コア数が多いと通信量が増えるため、ディレクトリ方式などで効率化します。

    マルチコアCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組みはどれか。

  • しかしコアの数が増えると、すべての要求をすべてのキャッシュに届ける通信が多くなりすぎるため、大規模なシステムではディレクトリ方式が使われます。

    キャッシュコヒーレンシのスヌーピング方式の説明として正しいものはどれか。

「ディレクトリ方式」が出てくる問題(3問)

  1. コアの数が多いシステムで、スヌーピング方式の代わりにディレクトリ方式のコヒーレンシが使われる理由として正しいものはどれか。
  2. マルチコアCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組みはどれか。
  3. キャッシュコヒーレンシのスヌーピング方式の説明として正しいものはどれか。
