ドライ酸化とは

どらいさんか

乾燥した酸素で行う熱酸化。成長は遅いが、緻密で良質な酸化膜ができ、ゲート酸化膜などに使われる。

「ドライ酸化」は、1分野の5問の練習問題に出てきます(酸化・拡散など)。

この用語の分野: 酸化・拡散

ドライ酸化の練習問題に挑戦

シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。

  1. Aドライ酸化のほうが酸化膜の成長速度が速い
  2. Bウェット酸化のほうが酸化膜の成長速度が速い
  3. C両者の成長速度は同じである
答えと解説を見る

正解：B. ウェット酸化のほうが酸化膜の成長速度が速い

水蒸気を使うウェット酸化は、酸化剤のH2OのSiO2中への溶解度がO2より数百倍高いため、ドライ酸化より成長速度が数倍〜10倍程度速くなります。例えば1000 ℃・1時間で、ドライは約70 nm、ウェットは約400 nmです。厚い膜が必要な素子分離やマスクに向いています。ドライ酸化は遅いものの緻密で界面準位の少ない良質な膜ができ、膜厚も制御しやすいため、薄いゲート酸化膜に使われてきました。

ドライ酸化で厚さ数十nm以下の薄い酸化膜をつくるとき、Deal-Groveモデルからずれることとして知られているものはどれか。

  1. A初期の酸化がモデルの予測より速く進む
  2. B酸化がまったく進まない
  3. C酸化膜が導体になる
答えと解説を見る

正解：A. 初期の酸化がモデルの予測より速く進む

Deal-Groveモデルは厚い酸化膜の成長をよく表しますが、ドライ酸化で膜厚が数十nm以下の初期の領域では、実際の酸化がモデルの予測より速く進みます。原因として、薄い膜を通る酸化剤の別の経路や、界面付近の応力の影響などが考えられています。モデルではこの分を初期膜厚(τ、約20 nm相当)として補正しますが、数nmのゲート酸化膜の厚さを決めるには実測による条件出しが欠かせません。

解説の中の「ドライ酸化」

  • 水蒸気を使うウェット酸化は、酸化剤のH2OのSiO2中への溶解度がO2より数百倍高いため、ドライ酸化より成長速度が数倍〜10倍程度速くなります。

    シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。

  • Deal-Groveモデルは厚い酸化膜の成長をよく表しますが、ドライ酸化で膜厚が数十nm以下の初期の領域では、実際の酸化がモデルの予測より速く進みます。

    ドライ酸化で厚さ数十nm以下の薄い酸化膜をつくるとき、Deal-Groveモデルからずれることとして知られているものは…

  • 厚い膜を短時間でつくるには高温のウェット酸化が使われる一方、薄いゲート酸化膜は膜厚を精密に制御するため、低温やドライ酸化で時間をかけてつくります。

    熱酸化の温度を上げると、同じ時間で得られる酸化膜の厚さはどうなるか。

  • ドライ酸化では、高温でシリコンと酸素が反応して二酸化シリコンができます(Si + O2 → SiO2)。

    シリコンのドライ熱酸化で起こる化学反応として正しいものはどれか。

  • 切り替わりの目安は膜厚がA/2程度で、ドライ酸化では数十nm〜100 nm程度です。

    Deal-Groveモデルで、熱酸化の初期(酸化膜がまだ薄いとき)の酸化膜厚と時間の関係として正しいものはどれか。

「ドライ酸化」が出てくる問題(5問)

  1. シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。
  2. ドライ酸化で厚さ数十nm以下の薄い酸化膜をつくるとき、Deal-Groveモデルからずれることとして知られているものはどれか。
  3. 熱酸化の温度を上げると、同じ時間で得られる酸化膜の厚さはどうなるか。
  4. シリコンのドライ熱酸化で起こる化学反応として正しいものはどれか。
  5. Deal-Groveモデルで、熱酸化の初期(酸化膜がまだ薄いとき)の酸化膜厚と時間の関係として正しいものはどれか。
