ドライ酸化とは

どらいさんか

乾燥した酸素で行う熱酸化。成長は遅いが、緻密で良質な酸化膜ができ、ゲート酸化膜などに使われる。

「ドライ酸化」は、1分野の5問の練習問題に出てきます(酸化・拡散など)。

この用語の分野: 酸化・拡散

ドライ酸化で酸化膜が成長する仕組み

ドライ酸化では、シリコンウエハを炉の中で一般に800〜1200 °C程度に加熱し、純酸素の雰囲気でSi + O2 → SiO2の反応によって二酸化シリコンを形成します。反応は表面ではなく、シリコンと酸化膜の界面で起こります。酸素分子は、すでに成長した酸化膜の中を拡散してシリコンまで届かなければなりません。そのため酸化膜は上方向だけでなくウエハの内側へも成長し、最終的な酸化膜厚の約44%にあたるシリコンを消費します。元の表面が消費され、界面が新しく清浄なシリコンの中へ移動していくことが、熱酸化膜の界面品質が非常に高い理由の1つです。

Deal-Groveモデル

Deal-Groveモデルは、熱酸化を2つの速度定数で表します。酸化膜が薄いうちは酸素が容易に膜を通過し、界面での反応が成長を律速するため、膜厚は速度B/Aで時間に比例して増えます(直線則)。膜が厚くなると膜中の拡散が律速となり、膜厚は放物線速度定数Bのもとで時間の平方根に比例して増えます(放物線則)。切り替わりはおよそ膜厚A/2のあたりで、ドライ酸化では数十nm〜約100 nmです。数十nmより薄い領域では、ドライ酸化はモデルの予測より速く進むため、薄いゲート酸化膜の膜厚は経験的な校正で決めます。

ドライ酸化とウェット酸化の違い

ウェット酸化は酸素の代わりに水蒸気を使い、Si + 2H2O → SiO2 + 2H2の反応で酸化します。水はO2の数百倍もSiO2に溶け込みやすいため、ウェット酸化はドライ酸化の数倍〜10倍の速さで酸化膜が成長します。1000 °Cで1時間なら、ドライで約70 nm、ウェットで約400 nmです。ウェット酸化膜には水素の一部が残り、やや密度が低くなります。ドライ酸化膜は緻密で界面準位が少なく、膜厚を精密に制御できます。一方、完璧さより速さが重要な厚い素子分離膜やマスク層にはウェット酸化が選ばれます。

ドライ酸化膜の用途

成長が遅く制御しやすいことから、ドライ酸化は数十年にわたってMOSのゲート酸化膜の標準的な形成方法でした。現在も、窒化シリコンの下に敷くパッド酸化膜や、トンネル酸化膜・界面層など、薄く高品質な膜に広く使われています。ナトリウムなどの可動イオンを捕獲(ゲッタリング)し、膜質を高めるために、塩素を含むガスを少量加えることもあります。成長速度は結晶面方位にも依存し、(111)面のシリコンは(100)面より速く酸化します。先端ノードではゲート絶縁膜は純粋なSiO2からhigh-k絶縁膜に置き換わりましたが、その下には今も薄いシリコン酸化膜の界面層があります。

ドライ酸化の練習問題に挑戦

シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。

  1. Aドライ酸化のほうが酸化膜の成長速度が速い
  2. Bウェット酸化のほうが酸化膜の成長速度が速い
  3. C両者の成長速度は同じである
答えと解説を見る

正解：B. ウェット酸化のほうが酸化膜の成長速度が速い

水蒸気を使うウェット酸化は、酸化剤のH2OのSiO2中への溶解度がO2より数百倍高いため、ドライ酸化より成長速度が数倍〜10倍程度速くなります。例えば1000 ℃・1時間で、ドライは約70 nm、ウェットは約400 nmです。厚い膜が必要な素子分離やマスクに向いています。ドライ酸化は遅いものの緻密で界面準位の少ない良質な膜ができ、膜厚も制御しやすいため、薄いゲート酸化膜に使われてきました。

ドライ酸化で厚さ数十nm以下の薄い酸化膜をつくるとき、Deal-Groveモデルからずれることとして知られているものはどれか。

  1. A初期の酸化がモデルの予測より速く進む
  2. B酸化がまったく進まない
  3. C酸化膜が導体になる
答えと解説を見る

正解：A. 初期の酸化がモデルの予測より速く進む

Deal-Groveモデルは厚い酸化膜の成長をよく表しますが、ドライ酸化で膜厚が数十nm以下の初期の領域では、実際の酸化がモデルの予測より速く進みます。原因として、薄い膜を通る酸化剤の別の経路や、界面付近の応力の影響などが考えられています。モデルではこの分を初期膜厚(τ、約20 nm相当)として補正しますが、数nmのゲート酸化膜の厚さを決めるには実測による条件出しが欠かせません。

よくある質問

ドライ酸化とウェット酸化の違いは?

ドライ酸化は酸素ガスを使い、緻密で高品質な酸化膜をゆっくり成長させます。ウェット酸化は水蒸気を使い、数倍〜10倍の速さで成長しますが、膜の密度はやや低くなります。ドライ酸化膜は薄いゲート品質の膜に、ウェット酸化膜は厚い素子分離膜やマスク膜に向いています。

ドライ酸化の化学反応式は?

シリコンと酸素が反応して二酸化シリコンができます(Si + O2 → SiO2)。反応は、酸素が既存の酸化膜中を拡散したあと、シリコンと酸化膜の界面で起こります。

ゲート酸化膜にドライ酸化を使うのはなぜですか?

成長が遅いため非常に薄い膜でも膜厚を精密に制御でき、できた酸化膜は緻密で界面準位密度が低いからです。こうした性質により、しきい値電圧が安定し、信頼性の高いゲート絶縁膜が得られます。
