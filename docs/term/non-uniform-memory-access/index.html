NUMAとは

ぬま

Non-Uniform Memory Accessの略。コアから近いメモリと遠いメモリがあり、遠いメモリへのアクセスは時間がかかる構成。データとスレッドを同じ側に置くと速い。

「NUMA」は、3分野の4問の練習問題に出てきます(マルチコアと同期, 性能評価・プロファイリング, DRAMなど)。

この用語の分野: マルチコアと同期

メモリアクセスが不均一になる理由

現代のプロセッサはメモリコントローラを内蔵しているため、マルチソケットサーバでは各ソケットが直接接続されたDRAMを持ちます。自ソケットのメモリにはローカルのコントローラを通じて直接アクセスできますが、別ソケットのメモリにはソケット間リンクを渡り、リモート側のコントローラを経由する必要があります。コア群とそのローカルメモリをまとめてNUMAノードと呼びます。リモートアクセスは一般にレイテンシが目立って大きく、ローカルの約1.3〜2倍程度になることが多いうえ、帯域も低くなります。正確な比率はプラットフォームやリンクの負荷によって変わります。

UMAやクラスタとの違い

UMA(均一メモリアクセス)システムは、多くの場合1組のメモリコントローラを持つシングルソケットのマシンで、どのコアからどのアドレスにもほぼ同じコストでアクセスできます。ccNUMA(キャッシュコヒーレントNUMA)システムは単一の共有アドレス空間とハードウェアによるキャッシュコヒーレンスを維持するので、プログラムを修正しなくても正しく動作し、データの置き場所によって速度が変わるだけです。この点で、各ノードが独自のアドレス空間を持ち、メッセージパッシングで明示的にデータをやり取りする別々のコンピュータのクラスタとは異なります。大規模なチップレット構成のプロセッサでは、1ソケット内に複数のNUMAノードが見えることもあります。

ファーストタッチ配置とその落とし穴

mallocは仮想アドレスを予約するだけなので、Linuxは通常、ページを確保したスレッドではなく、最初にそのページへ書き込んだスレッドのノードに配置します。1つのスレッドで大きな配列をゼロ初期化すると、全ページがそのスレッドのノードに置かれます。その後、他ノードで実行される並列ループはほぼすべてリモートメモリから読むことになり、1つのメモリコントローラが飽和する一方で、他のコントローラは遊んでしまいます。対策は、計算と同じ作業分割でデータを並列に初期化し、各スレッドの担当部分がそのスレッドのローカルに置かれるようにすることです。

ツールと実践のポイント

Linuxではnumactl --hardwareで、ノードとそのメモリ量、および距離テーブルを表示できます。距離テーブルでは慣例としてローカルアクセスを10とし、リモートはそれより大きな値になります。同じツールで、プロセスを特定ノードのCPUとメモリに束縛したり、全スレッドが均等に読むデータ向けにページをノード間でインターリーブしたりできます。スレッドを固定(CPUアフィニティを設定)すると、スケジューラがスレッドをデータから離れたコアへ移すのを防げ、ベンチマークの再現性も高まります。カーネルにはページを使用中のスレッドの近くへ自動移動する機能もありますが、性能が重要なコードでは明示的に配置するほうが予測しやすくなります。

NUMAの練習問題に挑戦

NUMA(不均一メモリアクセス)のシステムの説明として正しいものはどれか。

  1. Aすべてのコアから、すべてのメモリに同じ時間でアクセスできる
  2. Bコアから近いメモリと遠いメモリがあり、遠いメモリへのアクセスは時間がかかる
  3. C各コアは自分のメモリしか読めず、ほかのコアのメモリは使えない
答えと解説を見る

正解：B. コアから近いメモリと遠いメモリがあり、遠いメモリへのアクセスは時間がかかる

複数のCPUのソケットを持つサーバなどでは、各ソケットに直接つながったメモリがあり、ほかのソケットのメモリにはソケット間の接続を通ってアクセスします。そのため、近いメモリより遠いメモリの方が遅く、帯域も小さくなります。すべてのメモリは1つのアドレス空間に見えるのでプログラムはそのまま動きますが、データとスレッドを同じ側に置くと性能が上がります。

LinuxのNUMAシステムでよく使われるファーストタッチの方針(初めてページに書き込んだスレッドが動いているノードのメモリにそのページを置く)で注意すべき点として正しいものはどれか。

  1. Aファーストタッチではページがランダムなノードに置かれる
  2. Bmallocを呼んだ時点で、すべてのページの置き場所が決まる
  3. C大きな配列を1つのスレッドだけで0に初期化すると、全部が1つのノードに置かれ、ほかのノードのスレッドが遠いメモリを使うことになる
答えと解説を見る

正解：C. 大きな配列を1つのスレッドだけで0に初期化すると、全部が1つのノードに置かれ、ほかのノードのスレッドが遠いメモリを使うことになる

mallocで確保しただけでは物理ページは割り当てられず、初めて書き込んだときのページフォルトで、そのスレッドがいるノードのメモリに置かれます。そのため、初期化を1つのスレッドで行うと配列全体がそのノードに集まり、並列の計算で各スレッドが担当する部分の多くが遠いメモリになります。初期化も計算と同じ分担で並列に行えば、各部分が担当のスレッドの近くに置かれます。

よくある質問

自分のマシンがNUMAかどうかはどう確認できますか?

Linuxではlscpuまたはnumactl --hardwareを実行します。NUMAノードが2つ以上表示されれば、メモリアクセスのコストが場所によって異なります。ほとんどのデュアルソケットサーバでは少なくとも2つのノードが表示されます。

NUMA向けにプログラムを書き直す必要はありますか?

いいえ。ccNUMAマシンは一貫した単一のアドレス空間を提供するので、プログラムはそのままで正しく動きます。書き直しが意味を持つのは性能面だけで、主に各スレッドのデータを自分のノードに置くことが目的です。

ファーストタッチポリシーとは何ですか?

物理ページを、そのページに最初に書き込んだスレッドのNUMAノードに確保するという一般的な規則です。NUMAシステムで配列を並列に初期化することが重要なのは、このためです。

  • 移った先のコアのキャッシュには必要なデータがなく、NUMAのシステムでは、データが置かれたメモリから遠いソケットに移ってしまうこともあります。

    マルチコアやNUMAのシステムで性能を測るとき、スレッドを特定のコアに固定する(アフィニティを設定する)ことがある理由…

  • 複数のCPUを持つサーバーでは、各CPUに直結されたメモリのほうが速いNUMA構成になります。

「NUMA」が出てくる問題(4問)

  1. NUMA(不均一メモリアクセス)のシステムの説明として正しいものはどれか。
  2. LinuxのNUMAシステムでよく使われるファーストタッチの方針(初めてページに書き込んだスレッドが動いているノードのメモリにそのページを置く)で注意すべき点として正しいものはどれか。
  3. マルチコアやNUMAのシステムで性能を測るとき、スレッドを特定のコアに固定する(アフィニティを設定する)ことがある理由として正しいものはどれか。
  4. 現在の多くのパソコン用プロセッサで、DRAMを制御するメモリコントローラが置かれている場所はどれか。
