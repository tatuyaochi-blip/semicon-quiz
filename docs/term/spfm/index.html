SPFM(単一点故障指標)とは

えすぴーえふえむ

ISO 26262のハードウェアの評価指標で、安全に関係する故障のうち、単独で安全目標の侵害につながる単一点故障と残余故障の割合が小さいことを表す。目標の目安はASIL Bで90%以上、Cで97%以上、Dで99%以上。

「SPFM(単一点故障指標)」は、1分野の4問の練習問題に出てきます(車載半導体と機能安全など)。

この用語の分野: 車載半導体と機能安全

SPFM(単一点故障指標)の練習問題に挑戦

単一点故障指標(SPFM)について、ASIL Dで求められる目標値の目安として正しいものはどれか。

  1. A90%以上
  2. B60%以上
  3. C99%以上
答えと解説を見る

正解：C. 99%以上

SPFMは、安全に関係する故障のうち、単独で安全目標の侵害につながる単一点故障と、安全機構で検出しきれずに残る残余故障が少ないことを表す指標で、1から両者の故障率の割合を引いて求めます。目標値の目安は、ASIL Bで90%以上、ASIL Cで97%以上、ASIL Dで99%以上です。潜在故障指標(LFM)の目安は、ASIL Bで60%以上、ASIL Cで80%以上、ASIL Dで90%以上なので、90%や60%はLFMやASIL Bの値と混同しやすい数字です。

安全に関係するハードウェアの故障率の合計が1000 FITで、そのうち単一点故障と残余故障(安全機構で検出されずに残る故障)の故障率の合計が5 FITのとき、単一点故障指標(SPFM)はいくらか。

  1. A99.5%
  2. B95%
  3. C99.95%
答えと解説を見る

正解：A. 99.5%

SPFMは、1から「単一点故障と残余故障の故障率の合計」を「安全に関係する故障率の合計」で割った値を引いて求めます。この例では1 − 5 / 1000 = 1 − 0.005 = 0.995なので99.5%です。ASIL Dの目安である99%以上を満たします。95%は割合を1桁大きく見積もった場合、99.95%は1桁小さく見積もった場合の値です。SPFMを高めるには、診断カバレッジの高い安全機構を加えて、検出されずに残る故障を減らします。
