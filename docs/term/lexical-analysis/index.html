字句解析とは

じくかいせき

ソースコードの文字の並びを、識別子・数値・演算子・予約語などのトークン(単語)に分けるコンパイラの最初の段階。空白やコメントもここで取り除く。

この用語の分野: コンパイラ

解説の中の「字句解析」

  • 字句解析はコンパイラの最初の段階で、例えば「count = count + 1;」を、識別子count、記号=、識別子count、記号+、数値1、記号; というトークンに分けます。

    コンパイラの字句解析の役割として正しいものはどれか。

  • そのため字句解析器は、正規表現から自動で生成する道具で作られることも多くあります。

    字句解析でトークンを見分ける規則を表すのによく使われるものはどれか。

  • 構文解析は、字句解析で得たトークンの並びが言語の文法に合っているかを調べ、if文の条件と本体、式の中の演算の組み合わせなどの構造を木の形(構文木)に組み立てます。

    コンパイラの構文解析で行うこととして正しいものはどれか。

「字句解析」が出てくる問題(4問)

  1. コンパイラの字句解析の役割として正しいものはどれか。
  2. 字句解析でトークンを見分ける規則を表すのによく使われるものはどれか。
  3. コンパイラの構文解析で行うこととして正しいものはどれか。
  4. 多くのプログラミング言語の文法を表すのに使われ、構文解析の基礎になる文法の種類はどれか。
