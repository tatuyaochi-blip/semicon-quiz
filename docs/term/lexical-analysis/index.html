字句解析とは

じくかいせき

ソースコードの文字の並びを、識別子・数値・演算子・予約語などのトークン(単語)に分けるコンパイラの最初の段階。空白やコメントもここで取り除く。

「字句解析」は、1分野の4問の練習問題に出てきます(コンパイラなど)。

この用語の分野: コンパイラ

字句解析の練習問題に挑戦

コンパイラの字句解析の役割として正しいものはどれか。

  1. Aプログラムの文が、言語の文法に合っているかどうかを木の形で確かめる
  2. Bソースコードの文字の並びを、識別子や演算子などのトークンに分ける
  3. C変数の型が合っているかや、未定義の名前を使っていないかを調べる
答えと解説を見る

正解：B. ソースコードの文字の並びを、識別子や演算子などのトークンに分ける

字句解析はコンパイラの最初の段階で、例えば「count = count + 1;」を、識別子count、記号=、識別子count、記号+、数値1、記号; というトークンに分けます。空白やコメントもここで取り除かれます。トークンの規則は正規表現で書けるので、有限オートマトンで高速に処理できます。文法に合っているかを木の形で確かめるのは次の構文解析、型や名前を調べるのは意味解析の仕事です。

字句解析でトークンを見分ける規則を表すのによく使われるものはどれか。

  1. A浮動小数点の丸めの規則
  2. B正規表現と、それを処理する有限オートマトン
  3. Cキャッシュの置き換えの規則
答えと解説を見る

正解：B. 正規表現と、それを処理する有限オートマトン

識別子は「英字で始まり英数字が続く」、数値は「数字が1つ以上続く」のように、トークンの種類は正規表現で簡潔に書けます。正規表現は有限オートマトン(状態の数が有限の機械)に変換でき、文字を1つ読むごとに状態を移していくだけで、入力の長さに比例する時間でトークンを切り出せます。そのため字句解析器は、正規表現から自動で生成する道具で作られることも多くあります。丸めやキャッシュの規則は字句解析とは関係ありません。

「字句解析」が出てくる問題(4問)

  1. コンパイラの字句解析の役割として正しいものはどれか。
  2. 字句解析でトークンを見分ける規則を表すのによく使われるものはどれか。
  3. コンパイラの構文解析で行うこととして正しいものはどれか。
