しきい値電圧とは

しきいちでんあつ

MOSFETでチャネル(反転層)が形成され、電流が流れ始めるゲート電圧。Vthと書く。

やさしい解説で読む: トランジスタとは? スマホに100億個以上ある小さなスイッチ

「しきい値電圧」は、20分野の68問の練習問題に出てきます(MOSFET, SRAM・フラッシュメモリ, 先端トランジスタ(FinFET・GAA)など)。

この用語の分野: MOSFET

しきい値電圧を決める要素

Vthは一般に、強反転が始まるゲート電圧と定義されます。このとき表面ポテンシャルはフェルミポテンシャルφFの2倍に達し、表面の少数キャリア密度がバルクの多数キャリア密度と等しくなります。nMOSFETでは Vth = VFB + 2φF + Qd/Cox です。フラットバンド電圧VFBはゲートとシリコンの仕事関数差や酸化膜中の電荷で決まり、Qdは空乏層電荷です。したがってチャネルのドーピングを高くしたり、ゲート酸化膜を厚くしたりするとVthは上がります。high-k/メタルゲートのFinFETやGAA(ゲートオールアラウンド)素子ではチャネルがほぼノンドープのため、Vthは主にゲート金属の仕事関数で決まります。

符号と代表的な値

エンハンスメント型nMOSFETは、VGSが正のVthを超えると導通します。エンハンスメント型pMOSFETのVthは負(−0.4 V前後)で、ゲートがソースより|Vth|以上低くなるとオンになるため、資料では絶対値で示されることがよくあります。先端ロジックでは約0.2〜0.4 V、パワー素子では約1〜4 Vが使われます。しきい値を超えると、長チャネル素子の飽和領域では ID = ½μCox(W/L)(VGS − Vth)² に従うため、オーバードライブ電圧VGS − Vthが駆動電流を決めます。短チャネル素子では速度飽和のため、この2乗則からずれます。

速度とリーク電流のトレードオフ

Vthを下げると、同じ電源電圧でもオーバードライブが増えてオン電流が増えます。しかし、しきい値以下の電流は指数関数的にしか減らないため、Vthを60〜80 mV下げるごとにオフリーク電流がおよそ10倍に増えます。そこでプロセスでは低Vth・標準Vth・高Vthのトランジスタを用意し、設計者は低Vthセルをクリティカルパスだけに使います。動作条件によってもVthは変わります。基板に逆バイアスをかけると上がり(基板バイアス効果)、ドレイン電圧が高いとドレイン誘起障壁低下(DIBL)によって下がり、温度が上がると絶対値が1 °Cあたり約1〜2 mV下がります。

ばらつきと経時変化

Vthが完全に同じ値になることはありません。小さなトランジスタでは、ドーパントのランダムなゆらぎやゲート金属の結晶粒の影響でVthが数十mVばらつき、そのばらつきはゲート面積の平方根にほぼ反比例します(ペルグロムの法則)。この影響を最も強く受けるのがSRAMセルです。厚さ数nmのフィンやナノシートでは、量子閉じ込めによって厚さのばらつきがそのままVthのばらつきになります。製品寿命の間にも、NBTI・PBTI(負・正バイアス温度不安定性)やホットキャリア注入によってVthが上方にシフトして回路が遅くなるため、タイミング設計には経年劣化のマージンが必要です。

しきい値電圧の練習問題に挑戦

エンハンスメント型のnチャネルMOSFETがオン(導通)するための条件として正しいものはどれか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)

  1. AVGSが0 Vであること
  2. BVGSがVthより大きいこと
  3. CVGSが負の電圧であること
答えと解説を見る

正解：B. VGSがVthより大きいこと

エンハンスメント型のnMOSFETでは、ゲートにVthを超える正の電圧を加えると、p型基板の表面に電子が引き寄せられて反転層(チャネル)ができ、ソースとドレインの間に電流が流れます。VGS = 0 Vではチャネルがなくオフなので、ゲートが浮いても電流が流れにくく(ノーマリーオフ)、論理回路やパワー用途の安全性に向きます。Vthは先端ロジックで0.2〜0.4 V、パワー用で1〜4 V程度が一般的です。

長チャネルのMOSFETが飽和領域で動作しているとき、ドレイン電流IDはおよそ何に比例するか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)

  1. A(VGS − Vth)の2乗
  2. BVGS − Vth
  3. CVGSの逆数
答えと解説を見る

正解：A. (VGS − Vth)の2乗

長チャネルMOSFETの飽和領域では ID = (1/2)μCox(W/L)(VGS − Vth)² で、ドレイン電流は(VGS − Vth)の2乗に比例します(2乗則)。VGS − Vth はオーバードライブ電圧と呼ばれ、アナログ設計の基本パラメータです。短チャネルでは速度飽和によって1乗に近づき、さらに移動度の劣化や寄生抵抗の影響でずれるため、実際の設計ではBSIMなどの精密なモデルを使います。

よくある質問

MOSFETのしきい値電圧の代表的な値は?

先端ロジックプロセスのトランジスタでは、しきい値電圧は絶対値で約0.2〜0.4 Vが一般的で、1つのプロセスで複数の選択肢が用意されています。パワーMOSFETは、ゲートにノイズが乗っても確実にオフを保てるよう、通常1〜4 V程度です。

pMOSのしきい値電圧はなぜ負になるのですか?

pMOSのチャネルは正孔でできており、ゲートをソースより低い電位にすると、正孔がn型ボディの表面に引き寄せられます。オンにするには負のゲート・ソース間電圧が必要なので、しきい値は負になります。

しきい値電圧はどうやって測定しますか?

通常は測定したID-VG特性から抽出します。ドレイン電流がW/Lで規格化した一定値に達するゲート電圧とする方法(定電流法)と、特性の直線部分を電流ゼロまで外挿する方法があり、両者は少し異なる値になるため、どの定義を使ったかを必ず明記します。

「しきい値電圧」が出てくる問題(68問)

  1. エンハンスメント型のnチャネルMOSFETがオン(導通)するための条件として正しいものはどれか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  2. 長チャネルのMOSFETが飽和領域で動作しているとき、ドレイン電流IDはおよそ何に比例するか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  3. nチャネルMOSFETで、ソースに対して基板(ボディ)に負の電圧をかける(基板バイアスをかける)と、しきい値電圧はどうなるか。
  4. CMOSインバータの論理しきい値電圧を電源電圧のほぼ半分にするための設計として正しいものはどれか。
  5. エンハンスメント型pチャネルMOSFETのしきい値電圧(ソース基準)の符号はどれか。
  6. MOSFETのしきい値電圧を下げたときの一般的な影響として正しいものはどれか。
  7. MOSFETのしきい値電圧の絶対値は、温度が上がると一般にどうなるか。
  8. nMOSFETのチャネル領域(p型基板)の不純物濃度を高くすると、しきい値電圧はどうなるか。
  9. 他の条件を変えずにゲート絶縁膜を厚くすると、nMOSFETのしきい値電圧の大きさは一般にどうなるか。
  10. MOSFETのしきい値電圧を定義するときに用いられる「強反転」の条件として一般的なものはどれか。(φF:フェルミ電位)
  11. NANDフラッシュで、同じブロックを何度も読み出すうちに、読み出していないセルのしきい値電圧が少しずつ変化してしまう現象を何と呼ぶか。
  12. QLC(1セル4ビット)のNANDフラッシュで、1つのセルが区別しなければならないしきい値電圧の状態の数はいくつか。
  13. フラッシュメモリの消去で、フローティングゲートなどから電子を引き抜くと、セルのしきい値電圧はどうなるか。
  14. NANDフラッシュで、少しずつ電圧を上げた書き込みパルスを繰り返し、そのたびにしきい値電圧を確認しながら書き込む方式はどれか。
  15. 多値(MLCやTLC)のNANDフラッシュで、隣り合うしきい値電圧の状態に割り当てるビットの並びを、1ビットだけ異なるようにする理由として正しいものはどれか。
