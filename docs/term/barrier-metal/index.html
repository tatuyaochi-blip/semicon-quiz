バリアメタルとは

ばりあめたる

銅配線の周りに設け、銅が絶縁膜やシリコンへ拡散するのを防ぐ薄い金属膜。TaやTaNなど。

この用語の分野: 配線プロセス

解説の中の「バリアメタル」

  • そのため、Cu配線の側面と底をTa/TaNなどのバリアメタル(数nm)で囲み、上面は誘電体のキャップ膜で覆って拡散を防いでいます。

    Cu配線で、TaやTaNなどのバリアメタルを設ける主な目的はどれか。

  • 金属配線、バリアメタル(Ta、TiNなど)、Cuのシード層、電極などの成膜に使われます。

    スパッタリングによる成膜は、次のどれに分類されるか。

  • Cu配線では、溝の外の厚いCu(数百nm〜1 µm)と、その下の数nmのバリアメタル(Ta/TaNなど)、さらに下の絶縁膜を順に研磨します。

    Cu配線のCMPで、一般的に研磨を段階に分けて行う理由として正しいものはどれか。

「バリアメタル」が出てくる問題(5問)

  1. Cu配線で、TaやTaNなどのバリアメタルを設ける主な目的はどれか。
  2. スパッタリングによる成膜は、次のどれに分類されるか。
  3. Cu配線のCMPで、一般的に研磨を段階に分けて行う理由として正しいものはどれか。
  4. 微細化が進んだ多層配線で、ビアの抵抗が問題になってきた主な理由として正しいものはどれか。
  5. Cuにマンガンなどを少量加えた合金を成膜し、熱処理で絶縁膜との界面に薄いバリア層を自然に形成させる技術はどれか。
