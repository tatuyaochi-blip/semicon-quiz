入力オフセット電圧とは

にゅうりょくおふせっとでんあつ

オペアンプの出力を0にするために入力の間に必要な小さな電圧で、内部の素子の不整合によって生じる。回路の利得倍されて出力の誤差になり、例えば2 mVで利得100倍なら出力は最大200 mVずれる。

「入力オフセット電圧」は、2分野の2問の練習問題に出てきます(アナログ・電子回路, データシートの読み方など)。

この用語の分野: データシートの読み方

入力オフセット電圧の練習問題に挑戦

オペアンプの入力オフセット電圧の説明として正しいものはどれか。

  1. A入力を0にしても出力が0にならないことを補正するために、入力端子間に加える必要のある小さな電圧
  2. B入力に加えられる最大の電圧
  3. Cオペアンプの電源電圧
答えと解説を見る

正解：A. 入力を0にしても出力が0にならないことを補正するために、入力端子間に加える必要のある小さな電圧

実際のオペアンプは、入力段のトランジスタのわずかな不一致によって、入力を同じ電圧にしても出力が0になりません。これを入力側に換算したのが入力オフセット電圧で、汎用品で数mV、精密品で数十µV以下です。出力には(1 + Rf/Ri)倍されて現れ、温度でも変化(ドリフト)します。熱電対など直流の微小信号を高い利得で扱うときは、低オフセット品やチョッパ安定化型を使います。

入力オフセット電圧が max 2 mV のオペアンプで、利得100倍の非反転増幅回路をつくった。入力を0 Vにしたとき、出力に現れうる誤差電圧の最大の目安はどれか。

  1. A2 mV
  2. B200 mV
  3. C20 mV
答えと解説を見る

正解：B. 200 mV

入力オフセット電圧は、入力に直列に入った小さな電圧源のように振る舞い、非反転増幅回路の利得(1 + Rf/Ri)倍されて出力に現れます。2 mV × 100 = 200 mV で、例えば5 Vのフルスケールに対して4%の誤差になります。typ値ではなくmax値で見積もり、さらに温度ドリフト(µV/℃)による変化も加えます。精密な測定には、オフセットが数µV程度のゼロドリフト(チョッパ)型を選ぶか、ソフトウェアで校正します。2 mVは利得を掛け忘れた値です。
