モニターウエハとは

もにたーうえは

装置の状態確認や膜厚・パーティクルの測定などのために、製品とは別に工程に流すウエハ。テストウエハとも呼ぶ。使用後は膜を除いて研磨し直し、再生ウエハとして再利用されることが多い。

この用語の分野: シリコンウエハ

解説の中の「モニターウエハ」

  • モニターウエハやダミーウエハは工場で大量に使われるため、使用後に表面の膜や汚染をエッチングや研磨で取り除き、再び鏡面に仕上げて再利用します。

    使用済みのモニターウエハの表面の膜などを除去し、研磨し直して再び使えるようにしたものを何と呼ぶか。

  • モニターウエハは、成膜の膜厚、パーティクルの数、エッチング速度、汚染などを確認するために製品とは別に流すウエハで、装置の立ち上げや定期点検で状態をチェックします。

    装置の状態確認や膜厚の測定などのために、製品とは別に工程に流すウエハを何と呼ぶか。

「モニターウエハ」が出てくる問題(2問)

  1. 使用済みのモニターウエハの表面の膜などを除去し、研磨し直して再び使えるようにしたものを何と呼ぶか。
  2. 装置の状態確認や膜厚の測定などのために、製品とは別に工程に流すウエハを何と呼ぶか。
