アニールとは

あにーる

熱処理のこと。イオン注入後の結晶欠陥の回復や不純物の活性化などに用いる。

この用語の分野: イオン注入

解説の中の「アニール」

  • アニールによって結晶の損傷を回復させ、不純物を結晶格子の位置に置き換えて活性化させます。

    イオン注入後にアニール(熱処理)を行う主な目的として正しいものはどれか。

  • イオン注入で生じた過剰な格子間シリコン原子は、ボロンなどの拡散を助けるため、アニールの初期に拡散が一時的に大きく増速します。

    イオン注入後のアニールの初期に、注入で生じた格子間シリコンの影響で、ボロンなどの拡散が一時的に速くなる現象を何と呼ぶか。

  • 短時間で高温にするアニールでは、一時的に固溶度を超える活性化が得られることもあります。

    アニールでドーパントを活性化させるとき、電気的に活性化できる濃度の上限を決める性質はどれか。

「アニール」が出てくる問題(22問)

  1. イオン注入後にアニール(熱処理)を行う主な目的として正しいものはどれか。
  2. イオン注入後のアニールの初期に、注入で生じた格子間シリコンの影響で、ボロンなどの拡散が一時的に速くなる現象を何と呼ぶか。
  3. 同じアニール条件で、イオン注入のドーズ量を増やすと注入層のシート抵抗は一般にどうなるか。
  4. アニールでドーパントを活性化させるとき、電気的に活性化できる濃度の上限を決める性質はどれか。
  5. エピタキシャル成長やアニールに使われる水素ガスの危険性として正しいものはどれか。
  6. MOSFETのゲート長(マスク上や加工後のゲート電極の長さ)と、実効チャネル長の関係として一般的に正しいものはどれか。
  7. MOCVD法でマグネシウムを添加したGaNが、成長直後には高抵抗でp型にならない主な理由と、その対策の組み合わせとして正しいものはどれか。
  8. ゲートラスト(リプレースメントメタルゲート)プロセスの説明として正しいものはどれか。
  9. 表面マイクロマシニングで構造層に使うポリシリコンなどの薄膜で、内部に大きな残留応力があるとどのような問題が起こるか。
  10. ウエハを熱処理して表面付近の酸素を外に拡散させ、デバイスをつくる表面に欠陥の少ない層をつくる。この層を何と呼ぶか。
  11. エピタキシャル成長中にドーピングガスを流し、成長と同時に不純物を添加することを何と呼ぶか。
  12. 多数のウエハを一度に熱酸化するときに一般的に使われる装置はどれか。
  13. ランプなどでウエハを1枚ずつ、数秒程度の短時間で高温に加熱する熱処理を何と呼ぶか。
  14. 微細なトランジスタのソース・ドレインに浅い接合をつくるための工夫として正しいものはどれか。
  15. 熱拡散と比べたときのイオン注入の主な利点はどれか。
