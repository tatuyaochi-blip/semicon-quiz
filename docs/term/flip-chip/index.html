フリップチップとは

ふりっぷちっぷ

チップの回路面を下に向け、バンプで基板と直接接続する実装方法。接続が短く多ピン化に向く。

この用語の分野: パッケージ・実装

解説の中の「フリップチップ」

  • フリップチップは、チップの回路面に形成したはんだや銅ピラーのバンプを介して、チップを裏返した状態で基板と接続する方式です。

    フリップチップ実装の説明として正しいものはどれか。

  • フリップチップではパッドの上にバンプを形成します。

    多くのLSIで、ワイヤボンディングを行う最上層の電極パッドに使われてきた金属はどれか。

  • チップを裏返してバンプでつなぐのはフリップチップ、樹脂で包むのはモールド(封止)です。

    ワイヤボンディングの説明として正しいものはどれか。

「フリップチップ」が出てくる問題(6問)

  1. フリップチップ実装の説明として正しいものはどれか。
  2. フリップチップ実装で、チップと基板の隙間にアンダーフィル樹脂を充填する主な目的はどれか。
  3. フリップチップのはんだバンプで、大きな電流によってエレクトロマイグレーションが問題になるとき、特に故障が起こりやすい場所として知られているのはどこか。
  4. フリップチップ接続で、はんだボールの代わりに銅の柱(Cuピラー)を使う主な利点はどれか。
  5. 多くのLSIで、ワイヤボンディングを行う最上層の電極パッドに使われてきた金属はどれか。
  6. ワイヤボンディングの説明として正しいものはどれか。

この用語が出てくる比較

  • ワイヤボンディングとフリップチップの違い：チップの接続方法を比較ワイヤボンディングとフリップチップを、接続のしかた・入出力の数・電気的な性能・コスト・大きさ・工程・用途の観点で表にして比較します。
