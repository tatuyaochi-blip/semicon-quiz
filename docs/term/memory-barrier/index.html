メモリバリアとは

めもりばりあ

バリアより前のメモリ操作が、後の操作より先にほかのコアから見えることを保証する命令。フェンスとも呼ぶ。RISC-Vのfenceなど。

「メモリバリア」は、1分野の2問の練習問題に出てきます(マルチコアと同期など)。

この用語の分野: マルチコアと同期

メモリバリアの練習問題に挑戦

メモリバリア(フェンス)命令の役割として正しいものはどれか。

  1. Aバリアより前のメモリ操作が、バリアより後の操作より先にほかのコアから見えることを保証する
  2. Bメモリを物理的に区切って、アクセスを禁止する
  3. Cプログラムの実行をすべてのスレッドが揃うまで止める
答えと解説を見る

正解：A. バリアより前のメモリ操作が、バリアより後の操作より先にほかのコアから見えることを保証する

CPUはメモリ操作の順番を入れ替えることがあるので、ほかのコアと決まった順番でデータを受け渡すには、それを止める指示が必要です。メモリバリアは、その前の読み書きをすべて終えてから(ほかのコアに見えるようにしてから)、後ろの読み書きを行わせます。ロックの取得や解放の中にもバリアの働きが含まれていて、ロックで守った変数が正しく受け渡されます。

  • メモリバリアは、その前の読み書きをすべて終えてから(ほかのコアに見えるようにしてから)、後ろの読み書きを行わせます。

「メモリバリア」が出てくる問題(2問)

  1. メモリバリア(フェンス)命令の役割として正しいものはどれか。
  2. 上の2つのスレッドを別々のコアで同時に実行する(コンパイラによる並べ替えはないとする)。逐次一貫性では起こらないが、x86などの実際のCPUでは起こりうる結果はどれか。
