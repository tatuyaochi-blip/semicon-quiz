電解めっきとは

でんかいめっき

めっき液の中でウエハ側を陰極にして電流を流し、金属を析出させる成膜方法。Cu配線の溝の埋め込みに使われ、添加剤で底から先に埋まるように制御する。

この用語の分野: 成膜(CVD・PVD)

解説の中の「電解めっき」

  • 電解めっきでは、表面に電流を流して金属を析出させるため、溝の内面まで導電性の層が必要です。

    Cuを電解めっきで埋め込む前に、スパッタリングで薄く形成するCu膜の役割として正しいものはどれか。

  • ダマシン法では、溝にバリア層とCuのシード層をスパッタリングで薄くつけたあと、電解めっきでCuを埋め込みます。

    Cu配線の溝を埋め込むために主に用いられる成膜方法はどれか。

「電解めっき」が出てくる問題(4問)

  1. Cuを電解めっきで埋め込む前に、スパッタリングで薄く形成するCu膜の役割として正しいものはどれか。
  2. 電解めっきで形成したCu膜が、室温で放置するだけでも時間とともに結晶粒が大きくなり、抵抗率が下がる現象を何と呼ぶか。
  3. Cu配線の電解めっきに使われるめっき液の主成分として正しいものはどれか。
  4. Cu配線の溝を埋め込むために主に用いられる成膜方法はどれか。
