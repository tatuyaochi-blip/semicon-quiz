IDM(垂直統合型デバイスメーカー)とは

あいでぃーえむ

設計から前工程・後工程の製造、販売までを自社で一貫して行う半導体企業。

この用語の分野: 半導体産業・市場

解説の中の「IDM(垂直統合型デバイスメーカー)」

  • 設計から製造までを自社で行う企業はIDM、後工程を受託する企業はOSATです。

    「ファブレス」企業の説明として正しいものはどれか。

  • IDM(Integrated Device Manufacturer)は、設計、製造、販売までを自社で行う企業です。

    設計から前工程・後工程の製造、販売までを自社で一貫して行う半導体企業の形態はどれか。

  • OSATとIDMは企業の形態です。

    ファウンドリが、複数の顧客の設計を1枚のウエハ(1組のマスク)に相乗りさせて試作する仕組みを何と呼ぶか。

「IDM(垂直統合型デバイスメーカー)」が出てくる問題(5問)

  1. 「ファブレス」企業の説明として正しいものはどれか。
  2. 設計から前工程・後工程の製造、販売までを自社で一貫して行う半導体企業の形態はどれか。
  3. ファウンドリが、複数の顧客の設計を1枚のウエハ(1組のマスク)に相乗りさせて試作する仕組みを何と呼ぶか。
  4. ファウンドリとファブレスの分業が広がった背景として適切なものはどれか。
  5. 自社の工場で一部の製品を製造しつつ、先端の製品などはファウンドリに製造を委託する、工場への投資を抑えた事業形態はどれか。
