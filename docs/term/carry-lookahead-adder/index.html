桁上げ先見加算器とは

けたあげせんけんかさんき

各桁の生成信号 g = a·b と伝搬信号 p = a ⊕ b から、桁上げを下位からの伝わりを待たずに並列に求める加算器。ビット数が多くても遅延が小さい。キャリールックアヘッド加算器ともいう。

「桁上げ先見加算器」は、2分野の3問の練習問題に出てきます(計算機算術, 論理回路など)。

この用語の分野: 計算機算術

生成信号と伝搬信号

入力がaとbの各ビットについて、生成信号 g = a·b は、下からの桁上げに関係なくそのビットが桁上げを生み出すときに1になり、伝搬信号 p = a ⊕ b は、入ってきた桁上げがそのまま通り抜けるときに1になります。桁上げ出力は c(i+1) = g(i) + p(i)·c(i)、和は s(i) = p(i) ⊕ c(i) です。この漸化式を展開すると c1 = g0 + p0·c0、c2 = g1 + p1·g0 + p1·p0·c0 となり、どの桁上げも、gとpの信号と入力桁上げc0だけを使った2段の論理で書けます。

リプルキャリー加算器が遅い理由

リプルキャリー加算器では、各全加算器が下位ビットからの桁上げを待たなければなりません。すべて1の語に1を足すような最悪の場合、桁上げはすべてのビットを順に通り抜けるため、遅延はビット幅に比例して増えます。64ビットのリプルキャリー加算器では、GHz級のクロックで動くプロセッサにはとても間に合いません。桁上げ先見加算器(CLA)は入力から直接すべての桁上げを並列に計算し、先見回路を階層化すれば、遅延はビット幅の対数に比例して増えるだけで済みます。

多ビットの加算器を階層的に作る

桁上げの式を完全に展開すると、すぐに入力数の多すぎるゲートが必要になるため、実際の設計では4ビット程度のブロックを使います。各ブロックはグループ生成信号 G = g3 + p3·g2 + p3·p2·g1 + p3·p2·p1·g0 とグループ伝搬信号 P = p3·p2·p1·p0 を出力します。2段目の先見回路はこれらを1ビットのgとpとまったく同じように扱って各ブロックへの桁上げを計算し、3段目で64ビットまで拡張します。Kogge-StoneやBrent-Kungなどの並列プレフィックス加算器は同じ考え方を一般化したもので、論理段数と配線量・面積のバランスがそれぞれ異なります。

使われる場面

高速な加算器は、ALU、アドレス生成器、浮動小数点ユニット、そして乗算器の最終段に使われています。乗算器はまず、多数の部分積をキャリーセーブ加算器で減らします。キャリーセーブ加算器は独立した全加算器の集まりで、桁上げを伝搬させず、全加算器1段分の遅延で3つの数を2つにまとめます。桁上げの伝搬が必要なのは最後に残った2つの数の加算だけで、これを桁上げ先見加算器やプレフィックス加算器で1回行います。キャリーセレクト加算器やキャリースキップ加算器などの折衷方式は、速度と面積の点でリプルキャリーと完全な先見方式の中間に位置します。

桁上げ先見加算器の練習問題に挑戦

桁上げ先見加算器で使う、各桁の生成信号 g と伝搬信号 p の定義(a、bはその桁の入力)と、上の桁への桁上げ c(i+1) の式の組み合わせとして正しいものはどれか。

  1. Ag = a + b、p = a・b、c(i+1) = p + g・c(i)
  2. Bg = a・b、p = a ⊕ b、c(i+1) = g + p・c(i)
  3. Cg = a ⊕ b、p = a・b、c(i+1) = g・p・c(i)
答えと解説を見る

正解：B. g = a・b、p = a ⊕ b、c(i+1) = g + p・c(i)

その桁で a と b がともに1なら、下からの桁上げに関係なく必ず桁上げが生じるので、生成信号は g = a・b です。a と b のどちらか一方だけが1なら、下からの桁上げをそのまま上へ伝えるので、伝搬信号は p = a ⊕ b(OR とすることもある)です。よって c(i+1) = g(i) + p(i)・c(i) となり、これを展開すると、各桁の桁上げを入力のg・pと最下位の桁上げだけから2段の論理で並列に求められます。生成と伝搬を取り違えた式では正しく計算できません。

よくある質問

桁上げ先見加算器がリプルキャリー加算器より速いのはなぜですか?

リプルキャリー加算器は桁上げが各ビットを順に通るのを待つため、遅延はビット幅に比例して増えます。桁上げ先見加算器は生成信号と伝搬信号からすべての桁上げを並列に計算するため、遅延はおおむねビット幅の対数で増えるだけです。

伝搬信号にはXORの代わりにORを使えますか?

桁上げの計算には使えます。両方の入力が1のときは生成信号がすでに桁上げを作るので、p = a + b でも同じ桁上げになります。ただし和のビットにはa ⊕ bが必要なため、多くの設計ではpをXORで求めて両方に使います。

グループ生成信号とグループ伝搬信号とは何ですか?

複数ビットのブロックをまとめて表す信号です。グループ生成信号はブロックが自分で桁上げを出すときに1、グループ伝搬信号はブロックに入った桁上げが最後まで通り抜けるときに1になり、上位の先見回路はこれらを使ってブロックごとの桁上げを素早く求めます。
