桁上げ先見加算器とは

けたあげせんけんかさんき

各桁の生成信号 g = a·b と伝搬信号 p = a ⊕ b から、桁上げを下位からの伝わりを待たずに並列に求める加算器。ビット数が多くても遅延が小さい。キャリールックアヘッド加算器ともいう。

「桁上げ先見加算器」は、2分野の3問の練習問題に出てきます(計算機算術, 論理回路など)。

この用語の分野: 計算機算術

桁上げ先見加算器の練習問題に挑戦

桁上げ先見加算器で使う、各桁の生成信号 g と伝搬信号 p の定義(a、bはその桁の入力)と、上の桁への桁上げ c(i+1) の式の組み合わせとして正しいものはどれか。

  1. Ag = a + b、p = a・b、c(i+1) = p + g・c(i)
  2. Bg = a・b、p = a ⊕ b、c(i+1) = g + p・c(i)
  3. Cg = a ⊕ b、p = a・b、c(i+1) = g・p・c(i)
答えと解説を見る

正解：B. g = a・b、p = a ⊕ b、c(i+1) = g + p・c(i)

その桁で a と b がともに1なら、下からの桁上げに関係なく必ず桁上げが生じるので、生成信号は g = a・b です。a と b のどちらか一方だけが1なら、下からの桁上げをそのまま上へ伝えるので、伝搬信号は p = a ⊕ b(OR とすることもある)です。よって c(i+1) = g(i) + p(i)・c(i) となり、これを展開すると、各桁の桁上げを入力のg・pと最下位の桁上げだけから2段の論理で並列に求められます。生成と伝搬を取り違えた式では正しく計算できません。

解説の中の「桁上げ先見加算器」

  • 桁上げ先見加算器は、各ビットの生成 G = A・B(必ず桁上げを出す)と伝搬 P = A⊕B(下位の桁上げを通す)を使い、C1 = G0 + P0・C0、C2 = G1 + P1・G0 + P1・P0・C0 … のように各桁の桁上げを入力から並列に計算します。

    桁上げ先見(キャリールックアヘッド)加算器が高速な理由として正しいものはどれか。

  • これを重ねて部分積を2つまで減らし、最後に1回だけ桁上げ先見加算器などで足します。

「桁上げ先見加算器」が出てくる問題(3問)

  1. 桁上げ先見加算器で使う、各桁の生成信号 g と伝搬信号 p の定義(a、bはその桁の入力)と、上の桁への桁上げ c(i+1) の式の組み合わせとして正しいものはどれか。
  2. 桁上げ先見(キャリールックアヘッド)加算器が高速な理由として正しいものはどれか。
  3. 乗算器で多数の部分積を足し合わせるのに、桁上げ保存加算器が使われる主な理由はどれか。
