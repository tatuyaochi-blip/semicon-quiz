システム監査とは

しすてむかんさ

監査の対象から独立した専門の監査人(システム監査人)が、情報システムに関わるリスクに対するコントロールが適切に整備・運用されているかを点検・評価し、その結果を保証や改善の助言として経営者などに報告する活動。監査計画、予備調査、本調査、評価と結論、監査報告、フォローアップの順に進める。日本では、経済産業省がシステム監査基準とシステム管理基準を示している。

「システム監査」は、1分野の8問の練習問題に出てきます(サービスマネジメントとシステム監査など)。

この用語の分野: サービスマネジメントとシステム監査

監査の進め方

システム監査は、監査計画で目的と対象、時期を決めることから始めます。予備調査で資料の閲覧や聞き取りを行って対象の実態とリスクを把握し、本調査で行う監査の手続を具体的に決めます。本調査では、記録の照合、観察、テストなどの手続で監査証拠を集め、監査調書に記録します。集めた証拠をもとに評価して結論を出し、監査報告書で指摘と改善提案を報告し、その後のフォローアップで改善の状況を確かめます。

独立性と専門性

システム監査人には、監査の対象から独立していることが求められます。監査の対象の開発や運用に関わっていると、自分や自部門の仕事を評価することになり、客観的な判断ができず、周りからも公正に見えないからです。監査人は、改善を自ら行うのではなく、改善の提案を行い、実施は被監査部門(とそれを指示する経営者)が責任をもちます。また、情報システムとリスク、コントロールについての専門的な知識も必要です。

監査の技法

監査人は、資料の閲覧、聞き取り、現場の観察、記録の突合などに加えて、コンピュータを使う技法も用います。監査人が用意したデータをプログラムで処理させて結果を確かめるテストデータ法、本番のシステムに監査用の架空の口座を設けるITF法、処理の途中のデータを書き出すスナップショット法、汎用の監査ソフトウェアで全件のデータを分析する方法などがあり、まとめてCAAT(コンピュータ支援監査技法)と呼ばれます。

システム監査の練習問題に挑戦

システム監査の目的の説明として、適切なものはどれか。

  1. A独立した専門的な立場から、情報システムに関わるリスクに対するコントロールが適切に整備・運用されているかを点検・評価し、その結果を保証や助言として関係者に伝える
  2. B情報システムの開発プロジェクトに加わり、自らプログラムを作成し、テストを行って、開発を早く進める
  3. C情報システムで障害が起きたときに、復旧の作業を指揮し、再発を防ぐための対策を自ら実施する
答えと解説を見る

正解：A. 独立した専門的な立場から、情報システムに関わるリスクに対するコントロールが適切に整備・運用されているかを点検・評価し、その結果を保証や助言として関係者に伝える

システム監査は、監査の対象から独立した専門の監査人が、情報システムのリスクに対するコントロール(管理の仕組み)が適切に整備され、運用されているかを点検・評価する活動です。結果は、問題がないことの保証や、改善の助言(改善提案)として、経営者などの関係者に報告します。監査人が自ら開発や運用の作業を行うと、自分の作業を評価することになり、独立性が損なわれます。

システム監査人の独立性の観点から、販売管理システムの監査を担当する者として、最も適切なものはどれか。

  1. A販売管理システムを開発し、現在もその保守を担当している情報システム部の社員
  2. B販売管理システムを毎日使い、業務を管理している営業部の課長
  3. C監査の対象の業務やシステムの開発・運用に関わっていない、内部監査部門の社員
答えと解説を見る

正解：C. 監査の対象の業務やシステムの開発・運用に関わっていない、内部監査部門の社員

システム監査人には、監査の対象から独立していることが求められます。監査の対象の開発や運用、利用に関わる者が監査すると、自分や自部門の仕事を評価することになり、客観的な判断ができないおそれがあり、周りからも公正に見えません。そのため、監査の対象の部門から独立した内部監査部門の社員や、外部の監査人が担当します。

よくある質問

システム監査と情報セキュリティ監査はどう違いますか?

システム監査は、情報システムに関わるリスク全般(有効性、効率性、信頼性、安全性など)を対象にします。情報セキュリティ監査は、そのうち情報セキュリティに焦点を当てた監査です。対象の範囲は重なるので、組織によってはまとめて行うこともあります。

内部監査部門の社員でもシステム監査人になれますか?

なれます。組織の中の内部監査部門の社員が行う内部監査も、監査の対象の業務やシステムから独立していれば、システム監査として行えます。外部の専門家に依頼する外部監査もあり、目的に応じて使い分けます。

「システム監査」が出てくる問題(8問)

  1. システム監査の目的の説明として、適切なものはどれか。
  2. システム監査人の独立性の観点から、販売管理システムの監査を担当する者として、最も適切なものはどれか。
  3. システム監査の手順のうち、予備調査で行うこととして、適切なものはどれか。
  4. システム監査人が監査報告書で改善提案を行った。その後のフォローアップとして、適切なものはどれか。
  5. システム監査人が、取引先への支払いの記録が正しいかについて監査証拠を集めている。一般に、証明力が最も高いと考えられる監査証拠はどれか。
  6. システム監査の技法のうち、テストデータ法の説明として、適切なものはどれか。
  7. システム監査人が、汎用の監査ソフトウェアを使って、販売システムの1年分の取引データ(数百万件)から、請求書の番号の重複や、承認の上限額を超える取引を抽出した。このようなコンピュータ支援監査技法(CAAT)の利点として、適切なものはどれか。
  8. システム監査で、システム監査人が、組織の情報システムの管理が適切かどうかを判断するための尺度として主に用いるものはどれか。
