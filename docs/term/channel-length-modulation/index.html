チャネル長変調とは

ちゃねるちょうへんちょう

飽和領域のMOSFETで、ドレイン電圧を上げるとピンチオフ点がソース側へ移り、実効的なチャネル長が短くなってドレイン電流がわずかに増える現象。出力抵抗を有限にする。

「チャネル長変調」は、1分野の2問の練習問題に出てきます(MOSFETなど)。

この用語の分野: MOSFET

飽和領域でもドレイン電流が増え続ける理由

VDSがVGS − Vthを超えると、チャネルのドレイン端で反転層が消えます。これをピンチオフと呼びます。それ以上にVDSを上げた分は、ピンチオフ点とドレインの間の短い空乏領域にかかり、この領域はVDSとともに広がります。そのためピンチオフ点はソース側へ移動し、導通しているチャネルの実効長はL − ΔLになります。ドレイン電流はチャネル長に反比例し、残ったチャネルにかかる電圧はほぼVGS − Vthのままなので、電流は完全に平坦にはならず、わずかに増加します。

λモデルと出力抵抗

チャネル長変調は通常、2乗則の式に係数を掛けてモデル化します。ID = (1/2)μCox(W/L)(VGS − Vth)²(1 + λVDS)で、λをチャネル長変調係数と呼びます。VDSに対するIDの傾きは約λIDなので、小信号の出力抵抗はro ≈ 1/(λID)です。短いチャネルほどΔLの占める割合が大きいため、λはおおよそLに反比例し、Lを2倍にするとroもほぼ2倍になります。短チャネルデバイスでは、ドレイン誘起障壁低下(DIBL)も出力コンダクタンスを増やす要因になります。

アナログ設計で重要な理由

トランジスタ1個の真性利得はgm·roで、gm = 2ID/(VGS − Vth)を使うと2/(λ(VGS − Vth))になります。微細化が進んだトランジスタではこれが約10〜20しかなく、多くの増幅器には不十分です。そこで設計者は、アナログブロックで最小寸法より長いチャネル長を使ったり、カスコードのデバイスを重ねて出力抵抗を増倍したり、複数の利得段を使ったりします。チャネル長変調はカレントミラーの精度も悪化させます。基準側と出力側のトランジスタのドレイン電圧が異なると、λに比例した電流誤差が生じます。

チャネル長変調とアーリー効果の違い

バイポーラトランジスタにも、アーリー効果(ベース幅変調)と呼ばれる似た現象があります。コレクタ-エミッタ間電圧を上げるとコレクタ-ベース間の空乏層が広がって中性ベース領域が狭くなり、コレクタ電流がわずかに増えます。その強さは、出力特性の曲線を外挿して電圧軸と交わる点であるアーリー電圧VAで表し、ro ≈ VA/ICとなります。MOSFETで同じ意味をもつ量は1/λで、これもアーリー電圧と呼ぶことがあります。どちらの効果も、本来平坦な出力特性を傾け、デバイス1個で得られる電圧利得を制限します。

チャネル長変調の練習問題に挑戦

飽和領域にあるMOSFETの小信号の出力抵抗roを、チャネル長変調係数λとドレイン電流IDで表した式として適切なものはどれか。

  1. Aro ≈ 1 / (λ × ID)
  2. Bro ≈ ID / λ
  3. Cro ≈ λ × ID
答えと解説を見る

正解：A. ro ≈ 1 / (λ × ID)

チャネル長変調を考えると、飽和領域のドレイン電流は ID(1 + λVDS) の形でVDSとともにわずかに増え、この傾きの逆数が出力抵抗 ro ≈ 1/(λID) です。λはチャネル長にほぼ反比例するため、Lを2倍にするとroも約2倍になります。トランジスタ単体の最大電圧利得は gm·ro で、微細なトランジスタでは10〜20倍程度しかないため、カスコードや多段構成で利得を確保します。

よくある質問

MOSFETのドレイン電流の式のλ(ラムダ)とは?

λはチャネル長変調係数で、係数(1 + λVDS)を通じて、VDSが1 V上がるごとに飽和ドレイン電流がどれだけ増えるかを表します。その逆数はアーリー電圧のようにふるまい、出力抵抗ro ≈ 1/(λID)を決めます。

アナログ回路で長いチャネル長を使うのはなぜですか?

長いチャネルではピンチオフ点の移動がLに占める割合が小さく、チャネル長変調が弱くなるからです。そのため長いデバイスほど出力抵抗と真性利得が高く、素子間の整合性(マッチング)もよくなります。

チャネル長変調とアーリー効果の違いは?

どちらも出力電圧とともに出力電流が増え、出力抵抗を有限にする現象です。チャネル長変調はMOSFETの実効チャネル長を短くし、アーリー効果はバイポーラトランジスタの中性ベース領域を狭くします。
