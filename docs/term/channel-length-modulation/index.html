チャネル長変調とは

ちゃねるちょうへんちょう

飽和領域のMOSFETで、ドレイン電圧を上げるとピンチオフ点がソース側へ移り、実効的なチャネル長が短くなってドレイン電流がわずかに増える現象。出力抵抗を有限にする。

この用語の分野: MOSFET

解説の中の「チャネル長変調」

  • チャネル長変調を考えると、飽和領域のドレイン電流は ID(1 + λVDS) の形でVDSとともにわずかに増え、この傾きの逆数が出力抵抗 ro ≈ 1/(λID) です。

    飽和領域にあるMOSFETの小信号の出力抵抗roを、チャネル長変調係数λとドレイン電流IDで表した式として適切なものは…

  • これがチャネル長変調で、ID = (1/2)μCox(W/L)(VGS − Vth)²(1 + λVDS) と表され、出力抵抗 ro ≈ 1/(λID) を決めます。
