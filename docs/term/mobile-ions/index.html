可動イオンとは

かどういおん

ゲート酸化膜の中を移動できるナトリウムやカリウムなどのイオン。電界や温度によって移動し、しきい値電圧を変動させる。人の汗などから混入するため厳しく管理される。

「可動イオン」は、3分野の5問の練習問題に出てきます(酸化・拡散, プロセス材料(ガス・薬液), クリーンルーム・製造装置など)。

この用語の分野: 酸化・拡散

可動イオンの練習問題に挑戦

ゲート酸化膜中にナトリウムイオンなどの可動イオンが含まれると起こる問題として正しいものはどれか。

  1. A酸化膜が発光する
  2. B電界や温度によってイオンが移動し、しきい値電圧が変動する
  3. C酸化膜の機械的強度が上がる
答えと解説を見る

正解：B. 電界や温度によってイオンが移動し、しきい値電圧が変動する

ナトリウムなどのアルカリ金属イオンは酸化膜中を動きやすく、電界や温度(例えば200 ℃程度)によって界面付近に移動すると、正の電荷としてしきい値電圧を変動させます。1960年代のMOSデバイスの不安定さの最大の原因で、人の汗や器具からも混入します。クリーンルームでの汚染管理、塩素酸化、リンガラス(PSG)による捕獲などで対策され、MOS技術が実用化しました。

解説の中の「可動イオン」

  • その結果、可動イオンによるしきい値の変動が減り、酸化膜の絶縁破壊耐圧などの信頼性も向上します。

    熱酸化の際に、塩化水素(HCl)などの塩素を含むガスを少量加える主な目的はどれか。

  • 酸化膜まわりの電荷は、界面のすぐ近くの酸化膜にある固定電荷(Qf、正)、ナトリウムなどの可動イオン電荷(Qm)、膜中の欠陥に捕らえられた酸化膜トラップ電荷(Qot)、界面の準位による界面トラップ電荷(Qit)の4つに分類されます。

    MOS構造の酸化膜とその界面にある電荷の種類の組み合わせとして、一般的に分類されるものはどれか。

  • ナトリウムやカリウムなどのアルカリ金属イオンは、酸化膜中を電界で動く可動イオンとなり、トランジスタのしきい値電圧を変動させます。

    半導体の現像液に、水酸化ナトリウムなどではなくTMAHのような有機アルカリが使われる主な理由はどれか。

  • ナトリウムは酸化膜の中を動く可動イオンとなってトランジスタのしきい値電圧を変動させ、有機物は成膜や接合の不良の原因になります。

    ウエハを素手で触ってはいけない主な理由はどれか。
