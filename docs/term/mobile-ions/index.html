可動イオンとは

かどういおん

ゲート酸化膜の中を移動できるナトリウムやカリウムなどのイオン。電界や温度によって移動し、しきい値電圧を変動させる。人の汗などから混入するため厳しく管理される。

「可動イオン」は、3分野の5問の練習問題に出てきます(酸化・拡散, プロセス材料(ガス・薬液), クリーンルーム・製造装置など)。

この用語の分野: 酸化・拡散

動くイオンとその理由

可動イオンとは、主にナトリウム(Na+)やカリウム(K+)などのアルカリ金属イオンのことで、小さく、酸化膜のネットワークに弱くしか結合していないため、二酸化シリコンの中を移動できます。室温では動きは遅いものの、200 °C程度のやや高い温度で電界がかかると、ゲート酸化膜を容易にドリフトして横切ります。主な混入源は人の汗や皮膚、プロセス薬品、装置、石英治具、炉の部品などで、半導体業界がアルカリ金属を重大な汚染物質として扱うのはこのためです。

可動イオンがしきい値電圧を変える仕組み

ゲート酸化膜中の電荷は、フラットバンド電圧、ひいてはしきい値電圧を、おおよそ電荷量を酸化膜容量で割った分だけシフトさせます。その影響は、電荷がシリコンにどれだけ近いかで重みづけされます。ゲート電極の近くにあるイオンはほとんど影響しませんが、正のゲートバイアスをかけると正イオンがSi/SiO2界面へドリフトし、そこで最大の影響を及ぼしてnMOSのしきい値電圧を下げます。バイアスを逆にするとイオンは引き戻されるので、このシフトは可逆的で、バイアスと温度の履歴に依存します。これが可動イオンを固定酸化膜電荷と見分ける特徴です。

可動イオン汚染の測定

標準的な検査は、MOSキャパシタを使ったバイアス温度ストレス(BT)試験です。正のゲートバイアスをかけたままキャパシタを一般に約200 °C以上に加熱し、バイアスをかけたまま冷却してから、容量-電圧(C–V)掃引で測定します。同じ手順を負のバイアスでも繰り返し、2つの状態のフラットバンド電圧の差から単位面積あたりの可動イオン電荷量を求めます。炉などの装置に通したモニタウエハをこの方法で検査し、汚染源を早期に見つけます。

業界が可動イオンを克服した方法

可動イオンは1960年代にMOSトランジスタが不安定だった主な原因で、いくつかの対策によってMOS技術が実用化されました。クリーンルームでの作業規律、手袋、高純度の薬品で混入源を抑え、フォトレジストの現像液には水酸化ナトリウムの代わりにTMAHのような金属を含まない薬品が使われます。熱酸化中にHClなどの塩素源を加えると、ナトリウムを揮発性の塩化物として除去したり、酸化膜中で動けなくしたりできます。リンケイ酸ガラス(PSG)層はナトリウムをゲッタリングし、窒化シリコン膜はパッシベーション層でバリアとして働きます。

可動イオンの練習問題に挑戦

ゲート酸化膜中にナトリウムイオンなどの可動イオンが含まれると起こる問題として正しいものはどれか。

  1. A酸化膜が発光する
  2. B電界や温度によってイオンが移動し、しきい値電圧が変動する
  3. C酸化膜の機械的強度が上がる
答えと解説を見る

正解：B. 電界や温度によってイオンが移動し、しきい値電圧が変動する

ナトリウムなどのアルカリ金属イオンは酸化膜中を動きやすく、電界や温度(例えば200 ℃程度)によって界面付近に移動すると、正の電荷としてしきい値電圧を変動させます。1960年代のMOSデバイスの不安定さの最大の原因で、人の汗や器具からも混入します。クリーンルームでの汚染管理、塩素酸化、リンガラス(PSG)による捕獲などで対策され、MOS技術が実用化しました。

よくある質問

ナトリウム汚染がMOSトランジスタに悪いのはなぜですか?

ナトリウムイオンは電界や熱によってゲート酸化膜中を移動し、シリコン界面付近にたまるとその正電荷がしきい値電圧をシフトさせ、デバイスの特性が不安定になるからです。

可動イオンと固定酸化膜電荷の違いは?

可動イオンは酸化膜中をドリフトできるため、それによるしきい値電圧のシフトはバイアスや温度で変化し、元に戻すこともできます。固定酸化膜電荷は界面付近にとどまり、一定のシフトを与えます。

ゲート酸化のときにHClを加えるのはなぜですか?

塩素がアルカリ金属や金属の汚染物質と結合し、揮発性の塩化物として除去したり酸化膜中で動けなくしたりするので、可動イオンの影響が減り、酸化膜の信頼性が向上するからです。
