可動イオンとは

かどういおん

ゲート酸化膜の中を移動できるナトリウムやカリウムなどのイオン。電界や温度によって移動し、しきい値電圧を変動させる。人の汗などから混入するため厳しく管理される。

この用語の分野: 酸化・拡散

解説の中の「可動イオン」

  • 塩素を含む雰囲気で酸化すると、ナトリウムなどの可動イオンや金属汚染が塩化物として取り除かれたり、酸化膜中で不活性化されたりします。

    熱酸化の際に、塩化水素(HCl)などの塩素を含むガスを少量加える主な目的はどれか。

  • 酸化膜まわりの電荷は、界面近くにある固定電荷、ナトリウムなどの可動イオン電荷、膜中の欠陥に捕らえられた酸化膜トラップ電荷、界面の準位による界面トラップ電荷の4つに分類されます。

    MOS構造の酸化膜とその界面にある電荷の種類の組み合わせとして、一般的に分類されるものはどれか。

  • シリコン窒化膜は酸素や水分を通しにくく、硬いため、選択酸化(LOCOS)のマスク、STI形成でのCMPストッパー、チップ表面を水分や可動イオンから守るパッシベーション膜などに使われます。

    シリコン窒化膜(Si3N4)の用途として正しいものはどれか。

「可動イオン」が出てくる問題(5問)

  1. ゲート酸化膜中にナトリウムイオンなどの可動イオンが含まれると起こる問題として正しいものはどれか。
  2. 熱酸化の際に、塩化水素(HCl)などの塩素を含むガスを少量加える主な目的はどれか。
  3. MOS構造の酸化膜とその界面にある電荷の種類の組み合わせとして、一般的に分類されるものはどれか。
  4. シリコン窒化膜(Si3N4)の用途として正しいものはどれか。
  5. ウエハを素手で触ってはいけない主な理由はどれか。
