ネットリストとは

ねっとりすと

回路を構成する素子(セル)と、それらの接続関係を記述したデータ。論理合成の出力であり、配置配線やタイミング解析の入力になる。

「ネットリスト」は、3分野の5問の練習問題に出てきます(LSI設計フロー・EDA, テスト・検査, ハードウェア記述言語と検証など)。

この用語の分野: LSI設計フロー・EDA

ネットリストの練習問題に挑戦

回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。

  1. ADRC
  2. BATPG(自動テストパターン生成)
  3. CCTS
答えと解説を見る

正解：B. ATPG(自動テストパターン生成)

ATPGは、縮退故障などの故障モデルにもとづいて、各故障を出力まで伝えて検出できる入力パターンを、ネットリストから自動で生成する技術です。スキャン設計と組み合わせることで、数億ゲートの回路でも高い故障検出率のパターンを効率よく作成できます。DRCはレイアウトの設計ルールの検査、CTSはクロックツリーの合成で、どちらも設計の工程です。

ネットリストの説明として正しいものはどれか。

  1. A回路を構成する素子(セル)とそれらの接続関係を記述したデータ
  2. Bマスクのパターンの図形データ
  3. Cテストの合否を記録したデータ
答えと解説を見る

正解：A. 回路を構成する素子(セル)とそれらの接続関係を記述したデータ

ネットリストは、回路にどの素子(トランジスタやセル)があり、それらの端子がどの配線(ネット)でつながっているかを記述したデータです。図形の情報はもたず、接続関係だけを表します。論理合成の出力や配置配線の入力として使われ、LVSではレイアウトから取り出したネットリストと回路図のネットリストを比べます。マスクの図形はGDSIIなどのレイアウトデータに含まれます。

解説の中の「ネットリスト」

  • ATPGは、縮退故障などの故障モデルにもとづいて、各故障を出力まで伝えて検出できる入力パターンを、ネットリストから自動で生成する技術です。

    回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。

  • ネットリストは、回路にどの素子(トランジスタやセル)があり、それらの端子がどの配線(ネット)でつながっているかを記述したデータです。

    ネットリストの説明として正しいものはどれか。

  • 次に論理合成でゲートレベルのネットリストに変換し、配置配線でチップ上のレイアウトをつくります。

    一般的なデジタルLSIの設計フローの順序として正しいものはどれか。

  • 論理合成は、RTLで書かれた回路の動作記述を、セルライブラリにある論理ゲートやフリップフロップの接続情報(ネットリスト)に変換する工程です。

    論理合成の説明として正しいものはどれか。

「ネットリスト」が出てくる問題(5問)

  1. 回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。
  2. ネットリストの説明として正しいものはどれか。
  3. 論理合成や配置配線の後の回路(ゲートレベルのネットリスト)で、遅延の情報を入れてシミュレーションを行う主な目的はどれか。
  4. 一般的なデジタルLSIの設計フローの順序として正しいものはどれか。
  5. 論理合成の説明として正しいものはどれか。
