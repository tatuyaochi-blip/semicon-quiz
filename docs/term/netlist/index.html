ネットリストとは

ねっとりすと

回路を構成する素子(セル)と、それらの接続関係を記述したデータ。論理合成の出力であり、配置配線やタイミング解析の入力になる。

この用語の分野: LSI設計フロー・EDA

解説の中の「ネットリスト」

  • ATPGは、縮退故障などの故障モデルにもとづいて、各故障を出力まで伝えて検出できる入力パターンを、ネットリストから自動で生成する技術です。

    回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。

  • ネットリストは、回路にどの素子(トランジスタやセル)があり、それらの端子がどの配線(ネット)でつながっているかを記述したデータです。

    ネットリストの説明として正しいものはどれか。

  • 次に論理合成でゲートレベルのネットリストに変換し、配置配線でチップ上のレイアウトをつくります。

    一般的なデジタルLSIの設計フローの順序として正しいものはどれか。

「ネットリスト」が出てくる問題(4問)

  1. 回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。
  2. ネットリストの説明として正しいものはどれか。
  3. 一般的なデジタルLSIの設計フローの順序として正しいものはどれか。
  4. 論理合成の説明として正しいものはどれか。
