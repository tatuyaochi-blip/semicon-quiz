なだれ降伏とは

なだれこうふく

逆方向の強い電界で加速されたキャリアが原子にぶつかって新たなキャリアをつくり、それが連鎖的に増えて大電流が流れる現象。

「なだれ降伏」は、1分野の6問の練習問題に出てきます(PN接合・ダイオードなど)。

この用語の分野: PN接合・ダイオード

なだれ降伏の練習問題に挑戦

なだれ降伏の仕組みとして正しいものはどれか。

  1. A高電界で加速されたキャリアが格子に衝突して新たな電子・正孔対をつくり、それが連鎖的に増える
  2. B電子が薄い障壁を量子力学的にすり抜ける
  3. C温度上昇で接合が溶ける
答えと解説を見る

正解：A. 高電界で加速されたキャリアが格子に衝突して新たな電子・正孔対をつくり、それが連鎖的に増える

なだれ降伏では、空乏層の強い電界で加速されたキャリアが原子に衝突して電子・正孔対をつくり(衝突電離)、それがまた加速されて衝突を繰り返すことで電流が急増します。シリコンの臨界電界は約3×10⁵ V/cmで、不純物濃度が低く空乏層が広い接合ほど高い電圧で起こります。SiCは臨界電界が約10倍高いため、同じ耐圧を薄いドリフト層で実現でき、低損失のパワー素子になります。

なだれ降伏の降伏電圧は、温度が上がると一般にどうなるか。

  1. A高くなる
  2. B低くなる
  3. C変化しない
答えと解説を見る

正解：A. 高くなる

温度が上がると格子振動による散乱が増え、キャリアが衝突電離に必要なエネルギーまで加速されにくくなるため、なだれ降伏の電圧は高くなります(正の温度係数)。この性質のおかげで、局所的に熱くなった部分では降伏しにくくなり電流が分散します。一方、ツェナー降伏はギャップが縮むため温度で降伏電圧が下がります。降伏の温度係数は、どちらの仕組みかを見分ける手がかりになります。

解説の中の「なだれ降伏」

  • なだれ降伏では、空乏層の強い電界で加速されたキャリアが原子に衝突して電子・正孔対をつくり(衝突電離)、それがまた加速されて衝突を繰り返すことで電流が急増します。

    なだれ降伏の仕組みとして正しいものはどれか。

  • 温度が上がると格子振動による散乱が増え、キャリアが衝突電離に必要なエネルギーまで加速されにくくなるため、なだれ降伏の電圧は高くなります(正の温度係数)。

    なだれ降伏の降伏電圧は、温度が上がると一般にどうなるか。

  • 約5 V以下は主にトンネル効果によるツェナー降伏、それ以上は主になだれ降伏です。

    定電圧ダイオード(ツェナーダイオード)が主に利用している現象はどれか。

  • 高い降伏電圧はなだれ降伏が主で、温度係数は逆に正になります。

    不純物濃度が非常に高いPN接合で、低い逆電圧で起こる降伏の主な仕組みはどれか。

  • 降伏電圧が約5 V以下のものは主にツェナー(トンネル)降伏で温度が上がると電圧が下がり、高いものは主になだれ降伏で温度が上がると電圧が上がります。

    定電圧ダイオードで、ツェナー電圧が約5〜6 Vのものは温度による電圧の変化が小さい。その理由として正しいものはどれか。

「なだれ降伏」が出てくる問題(6問)

  1. なだれ降伏の仕組みとして正しいものはどれか。
  2. なだれ降伏の降伏電圧は、温度が上がると一般にどうなるか。
  3. 定電圧ダイオード(ツェナーダイオード)が主に利用している現象はどれか。
  4. 不純物濃度が非常に高いPN接合で、低い逆電圧で起こる降伏の主な仕組みはどれか。
  5. 定電圧ダイオードで、ツェナー電圧が約5〜6 Vのものは温度による電圧の変化が小さい。その理由として正しいものはどれか。
  6. 階段接合のPN接合に逆バイアスを加えたとき、電界が最も強くなる場所はどこか。
