ランサムウェアとは

らんさむうぇあ

コンピュータの中のファイルを暗号化するなどして使えなくし、元に戻すことと引き換えに身代金を要求するマルウェア。盗んだデータを公開すると脅す手口もある。ネットワークから切り離したバックアップが重要な備えになる。

「ランサムウェア」は、2分野の4問の練習問題に出てきます(情報セキュリティの基礎, システム構成と信頼性設計など)。

この用語の分野: 情報セキュリティの基礎

ランサムウェアの練習問題に挑戦

ランサムウェアの説明として正しいものはどれか。

  1. A利用者の画面に広告を大量に表示して、広告の収入を得るソフトウェア
  2. Bコンピュータの中のファイルを勝手に暗号化するなどして使えなくし、元に戻すことと引き換えに金銭(身代金)を要求するマルウェア
  3. C大量のパケットを送りつけて、サーバを応答できなくする攻撃
答えと解説を見る

正解：B. コンピュータの中のファイルを勝手に暗号化するなどして使えなくし、元に戻すことと引き換えに金銭(身代金)を要求するマルウェア

ランサムウェアは、感染したコンピュータやネットワークの中のファイルを暗号化するなどして使えなくし、元に戻すための鍵と引き換えに身代金を要求するマルウェアです。2020年代半ばの時点では、組織のネットワークに侵入して多くのサーバを一斉に暗号化したり、暗号化の前に盗んだデータを「公開する」と脅したりする手口(二重恐喝)が多く報告されています。身代金を払っても元に戻る保証はなく、犯罪者の資金にもなるため、支払わないことが推奨されています。対策の中心は、侵入の入り口になる脆弱性への修正の適用、リモートアクセスの多要素認証、権限の最小化、そして、ネットワークから切り離した場所に保管するバックアップです。

ランサムウェアへの備えとしてのバックアップについて、「3-2-1ルール」に沿った方法として最も適切なものはどれか。

  1. A同じファイルサーバの中に3つのフォルダを作り、2時間ごとに1回コピーする
  2. B常にネットワークでつながったバックアップ用のディスクを3台用意し、2台を同じサーバに、1台を同じ部屋に置く
  3. C元のデータを含めて3つのコピーを持ち、2種類の異なる媒体に保存し、そのうち1つは別の場所(ネットワークから切り離した場所など)に置く
答えと解説を見る

正解：C. 元のデータを含めて3つのコピーを持ち、2種類の異なる媒体に保存し、そのうち1つは別の場所(ネットワークから切り離した場所など)に置く

3-2-1ルールは、データのコピーを元のデータを含めて3つ以上持ち、2種類以上の異なる媒体(ディスク、テープ、クラウドなど)に保存し、そのうち1つ以上を別の場所に置く、というバックアップの目安です。1台の機器の故障、媒体の種類に共通する不具合、火災や災害のような1か所での被害が、すべてのコピーに同時に及ばないようにするための考え方です。ランサムウェアは、ネットワークでつながっていて書き込めるバックアップも暗号化したり消したりすることがあるため、少なくとも1つはオフライン(ネットワークから切り離す)や、一定期間は書き換えられない設定(イミュータブル)にしておくことが重要です。また、いざというときに戻せることを、復元の試験で定期的に確かめておく必要があります。
