ミーリ型とは

みーりがた

出力が今の状態と入力の両方で決まる状態機械。入力の変化が同じサイクルで出力に表れるが、入力の雑音も出力に伝わりやすい。出力が状態だけで決まるのはムーア型。

この用語の分野: ハードウェア記述言語と検証

解説の中の「ミーリ型」

  • ミーリ型では、出力の論理が今の状態に加えて入力も見るので、入力が変わればクロックを待たずに出力が変わり、1サイクル早く反応できます。

    ミーリ型の状態機械の特徴として正しいものはどれか。

  • ムーア型では出力が現在の状態だけで決まり、ミーリ型では状態と入力の両方で決まります。

    出力が現在の状態だけで決まる順序回路(ステートマシン)の型はどれか。
