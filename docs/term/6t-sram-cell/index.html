6T SRAMセルとは

ろくてぃーえすらむせる

交差接続した2つのインバータ(4個)と、アクセス用の2個のトランジスタからなるSRAMのメモリセル。

「6T SRAMセル」は、1分野の2問の練習問題に出てきます(SRAM・フラッシュメモリなど)。

この用語の分野: SRAM・フラッシュメモリ

6個のトランジスタで1ビットを保持する仕組み

6T SRAMセルの中心は、交差接続した2つのCMOSインバータによるラッチです。各インバータはPMOSのプルアップとNMOSのプルダウンからなり、合計4個のトランジスタになります。それぞれのインバータの出力がもう一方の入力を駆動するため、この正帰還によって一方の記憶ノードがハイ、もう一方がローに保たれ、電源がある限りリフレッシュなしで保持されます。ワード線で制御される2個のNMOSアクセストランジスタが、2つの記憶ノードを相補のビット線対BLとBLバーにつなぎます。スタティックとはいえ電力がかからないわけではなく、トランジスタは常にリークしています。

読み出しと書き込みのためのサイズ設計

読み出しでは、両方のビット線をハイにプリチャージしてからワード線を上げます。0を記憶しているノードがビット線をわずかに引き下げ、センスアンプがその小さな差を検出します。このときアクセストランジスタから流れ込む電流が0のノードを持ち上げるため、プルダウンをアクセストランジスタより強くしておく必要があり(セル比約1.5〜2.5)、そうしないとセルが反転するおそれがあります。書き込みでは片方のビット線をローに駆動し、アクセストランジスタが、ノードをハイに保つプルアップPMOSに打ち勝たなければならないため、プルアップを3種類の中で最も弱くします。

6T SRAMとDRAMセルの比較

6T SRAMセルの面積は約120〜150 F²(Fは最小加工寸法)で、1トランジスタ1キャパシタのDRAMセルは約6 F²です。つまりSRAMの集積度は約20分の1で、ビットあたりのコストもはるかに高くなります。その代わり、キャパシタや特別なプロセスが不要でロジックトランジスタと一緒につくれ、DRAMの数十nsに対して約1 nsでアクセスできます。オンチップのキャッシュやレジスタファイルにSRAM、メインメモリにDRAMが使われるのはこのためです。

低電圧での限界と8Tセル

読み出しの安定性と書き込みやすさはトランジスタのサイズを逆方向に引っ張るため、しきい値電圧のランダムなばらつきがあると、電源電圧を下げたときに一部のセルが動作しなくなり、これが大規模アレイの最低動作電圧を決めます。8Tセルは2トランジスタの読み出しポートを追加し、そのビット線はトランジスタのゲートを介して記憶ノードを検出するだけなので、読み出しで記憶値が乱されません。読み出し経路と書き込み経路を別々に最適化でき、同時に動作させることもできるため、セルは大きくなるものの低電圧動作が改善されます。

6T SRAMセルの練習問題に挑戦

6T SRAMセルで、読み出し時にセルの内容が反転しない(読み出し破壊を防ぐ)ために必要な設計として正しいものはどれか。

  1. Aアクセストランジスタをプルダウントランジスタより強くする
  2. Bプルアップトランジスタを取り除く
  3. Cプルダウン(駆動)トランジスタをアクセストランジスタより強くする
答えと解説を見る

正解：C. プルダウン(駆動)トランジスタをアクセストランジスタより強くする

読み出し時、0を保持するノードにはプリチャージされたビット線からアクセストランジスタを通して電流が流れ込み、電圧が少し上がります。プルダウントランジスタがアクセストランジスタより十分強ければ(セル比 β = プルダウン/アクセス を1.5〜2.5程度)、この上昇が反対側のインバータのしきい値より小さく抑えられ、データが反転しません。8Tセルや読み出しアシストでも対策できます。

よくある質問

SRAMセルのトランジスタが6個なのはなぜですか?

4個のトランジスタで交差接続した2つのインバータをつくり、正帰還でビットを保持します。残りの2個はアクセストランジスタで、ワード線が選択されたときにセルをビット線につなぎます。これにより、ロジック用トランジスタだけで安定したリフレッシュ不要の記憶素子ができます。

SRAMにはDRAMのようなリフレッシュが必要ですか?

必要ありません。電源が供給されている限り、交差接続したインバータが記憶レベルを能動的に回復し続けるからです。ただし、電源を切るとデータは失われます。

6T SRAMのセル比(β比)とは何ですか?

アクセストランジスタに対するプルダウントランジスタの強さの比で、通常約1.5〜2.5です。十分な比があれば、読み出し中に0のノードがスイッチングしきい値を超えて上昇するのを防ぎ、読み出し時のデータ反転を防げます。
