シストリックアレイとは

しすとりっくあれい

多数の積和演算器を格子状に並べ、データを隣の演算器へ順に流しながら行列の積を計算する構成。AI向けのアクセラレータで使われる。

この用語の分野: CPU・アーキテクチャ

解説の中の「シストリックアレイ」

  • シストリックアレイでは、格子状に並べた積和の演算器の間をデータが拍動のように一定のリズムで流れます。

    AI向けのアクセラレータで使われるシストリックアレイが、行列の積を効率よく計算できる主な理由はどれか。

  • シストリックアレイは、積和演算器(MAC)を2次元に並べ、データを隣の演算器へ規則的に送りながら計算する構成で、血液を送り出す心臓の収縮(シストール)になぞらえた名前です。

    AI向けのアクセラレータなどで、多数の積和演算器を格子状に並べ、データを隣の演算器へ順に流しながら行列の積を計算する構…
