積層欠陥とは

せきそうけっかん

結晶の原子面の積み重なりの順序が乱れた面状の欠陥。スタッキングフォルトとも呼ぶ。エピ層や熱酸化(OSF)、SiCの結晶などで問題になる。

この用語の分野: エピタキシャル成長

解説の中の「積層欠陥」

  • SiCのボディダイオードに順方向電流を流すと、電子と正孔の再結合のエネルギーで、結晶中の基底面転位が積層欠陥に拡大し、オン電圧が上がることがあります(バイポーラ劣化)。

    SiC MOSFETのボディダイオードに電流を流し続けると、特性が劣化することがある原因として知られているものはどれか。

  • 表面に自然酸化膜(約1 nm)や炭素などの汚染が残っていると、その上には単結晶がうまく成長せず、積層欠陥などの原因になります。

    シリコンのエピタキシャル成長の直前に、高温の水素雰囲気でウエハを加熱する主な目的はどれか。

  • 積層欠陥は、結晶の原子面の積み重なりの順序(シリコンの{111}面ではABCABC…)が局所的に乱れた欠陥です。

    エピタキシャル層に生じる代表的な結晶欠陥の一つで、原子面の積み重なりの順序が乱れたものはどれか。

「積層欠陥」が出てくる問題(8問)

  1. シリコン結晶中の転位や積層欠陥などを光学顕微鏡で観察できるようにするため、欠陥の部分を選択的に浅くエッチングする方法はどれか。
  2. SiC MOSFETのボディダイオードに電流を流し続けると、特性が劣化することがある原因として知られているものはどれか。
  3. シリコンのエピタキシャル成長の直前に、高温の水素雰囲気でウエハを加熱する主な目的はどれか。
  4. エピタキシャル層に生じる代表的な結晶欠陥の一つで、原子面の積み重なりの順序が乱れたものはどれか。
  5. エピタキシャルウエハの品質として管理される主な項目はどれか。
  6. 熱酸化の際に、塩化水素(HCl)などの塩素を含むガスを少量加える主な目的はどれか。
  7. 熱酸化の際に、酸化によって生じた過剰な格子間シリコンがシリコン中に注入されて成長する欠陥はどれか。
  8. 高い圧力の酸化雰囲気で熱酸化を行う利点として正しいものはどれか。
