アテンションとは

あてんしょん

各トークンが、ほかのすべてのトークンとの関係の強さを計算して情報を集めるTransformerの仕組み。計算量は系列の長さの2乗に比例する。

アテンションの練習問題に挑戦

Transformerで使われるセルフアテンション(自己注意機構)の説明として、適切なものはどれか。

  1. A系列の要素を先頭から1つずつ順に読み込み、前の要素の隠れ状態を次の要素に渡しながら、系列全体の情報をまとめていく
  2. B各トークンのクエリと、すべてのトークンのキーとの類似度から重みを求めて、バリューの重み付きの和をとるので、系列の全位置の計算を並列に行える
  3. C各トークンについて、隣り合う決まった数のトークンだけを見る畳み込みを何層も重ねて、離れたトークンとの関係は扱わないようにする
答えと解説を見る

正解：B. 各トークンのクエリと、すべてのトークンのキーとの類似度から重みを求めて、バリューの重み付きの和をとるので、系列の全位置の計算を並列に行える

セルフアテンションでは、各トークンのベクトルからクエリ(Q)、キー(K)、バリュー(V)を作り、クエリとすべてのキーの内積をソフトマックス関数で重みに変えて、バリューの重み付きの和を求めます。どのトークンも離れたトークンの情報を直接取り込めるうえ、計算は行列の積にまとめられ、RNNのように前の時刻の結果を待つ必要がないので、学習のときに系列の全位置を並列に計算できます。この計算そのものには語順の情報が含まれないので、位置の情報を加える位置エンコーディングを組み合わせます。一方で、計算量は系列の長さの2乗に比例して増えます。

Transformerのセルフアテンションの計算量が、入力の系列の長さnに対してどのように増えるか。

  1. Anに比例して増える
  2. Bnの2乗に比例して増える
  3. Cnによらず一定
答えと解説を見る

正解：B. nの2乗に比例して増える

セルフアテンションでは、各トークンのQueryと、すべてのトークンのKeyとの内積を計算して、n×nの重みの表を作ります。そのため計算量と、素直に作ったときの中間の表のメモリは、系列の長さの2乗に比例します。長さが2倍になればアテンションの部分は4倍になるので、長い文章を扱うほどアテンションの効率が性能を左右します。

「アテンション」が出てくる問題(6問)

  1. Transformerで使われるセルフアテンション(自己注意機構)の説明として、適切なものはどれか。
  2. Transformerのセルフアテンションの計算量が、入力の系列の長さnに対してどのように増えるか。
  3. FlashAttentionなどの高速なアテンションの実装の主な考え方として正しいものはどれか。
  4. パラメータ数Nの大規模言語モデルで、1トークンを生成する推論に必要な演算の数の目安はどれか(アテンションの部分を除く)。
  5. 大規模言語モデルの推論で使われるKVキャッシュの役割として正しいものはどれか。
  6. ソフトマックス関数exp(xi)/Σexp(xj)を計算するとき、各xiから最大値を引いてから計算することが多い理由として正しいものはどれか。
