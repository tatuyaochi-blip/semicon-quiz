SIMS(二次イオン質量分析法)とは

にじいおんしつりょうぶんせきほう

一次イオンで試料を削りながら二次イオンを質量分析し、不純物の深さ方向の分布を高感度に測定する方法。

「SIMS(二次イオン質量分析法)」は、1分野の7問の練習問題に出てきます(計測・分析など)。

この用語の分野: 計測・分析

深さ方向分布の測定原理

二次イオン質量分析法(SIMS)では、セシウムや酸素などの一次イオンビームを絞って試料に照射し、スパッタリングで原子を一層ずつ削り取ります。飛び出した原子のごく一部はイオンとして放出され、この二次イオンを磁場型、四重極型、飛行時間型などの質量分析計で質量ごとに分離します。クレーターが深くなる間に特定の質量を記録すると、強度とスパッタ時間の関係が得られます。最終的なクレーター深さを触針式段差計などで測れば時間を深さに換算でき、注入量が既知の標準試料を使えば強度を濃度に換算できます。

感度、マトリックス効果、深さ分解能

SIMS は日常的に使われる分析法の中でも特に感度が高く、条件のよい元素では ppb 程度まで検出でき、約 0.1 wt% の EDX(エネルギー分散型 X 線分析)をはるかに上回ります。一次ビームの選択も重要で、酸素はホウ素のような陽性元素の正イオン収率を高め、セシウムは陰性元素の負イオン収率を高めます。イオン収率は周囲の材料に強く依存し、これをマトリックス効果と呼びます。そのため定量には同じマトリックスの標準試料が必要で、界面付近のプロファイルは慎重な解釈を要します。深さ分解能はイオンビームによるミキシングやクレーター底の荒れで制限されるため、極浅接合の評価には低エネルギーの一次ビームを使います。

拡がり抵抗法など他の手法との違い

SIMS は、格子位置に入ってキャリアを生み出しているかどうかに関係なく、その元素の原子をすべて数えます。一方、拡がり抵抗測定(SRP)は試料を浅い角度で斜め研磨し、その斜面に沿ってプローブを少しずつ移動させて抵抗を測り、電気的に活性なキャリア濃度の深さ分布を求めます。両者を比べると、注入した不純物のうちアニールでどれだけ活性化したかがわかります。SIMS は測定部分を削り取ってしまう破壊分析であり、膜厚を測る X 線反射率法や寸法を測るスキャトロメトリーのような非破壊の手法とは対照的です。

主な用途

SIMS はイオン注入のプロファイルやドーズ量、アニール後の不純物拡散、接合深さ、界面での不純物偏析を確認する標準的な手法です。膜中や界面の汚染物質に加え、水素、炭素、酸素、窒素といった軽元素も検出できます。これらの軽元素を低濃度で定量できる手法はほかにほとんどありません。ここで説明した深さ方向分析のモードはダイナミック SIMS と呼ばれます。これに対し、一次イオンの照射量を低く抑え、多くは飛行時間型の分析計を使う方式では、最表面の数原子層だけを調べて表面汚染や有機残渣を分析します。

SIMS(二次イオン質量分析法)の練習問題に挑戦

SIMS(二次イオン質量分析法)の説明として正しいものはどれか。

  1. A電子線を当てて発生する特性X線で元素を調べる
  2. B光の反射率から膜厚を測る
  3. C一次イオンで試料を削りながら、出てくる二次イオンを質量分析し、不純物の深さ方向の分布を調べる
答えと解説を見る

正解：C. 一次イオンで試料を削りながら、出てくる二次イオンを質量分析し、不純物の深さ方向の分布を調べる

SIMSは、セシウムや酸素の一次イオンを照射して試料表面を少しずつスパッタし、放出された二次イオンを質量分析します。削りながら測定を続けることで、不純物濃度の深さ方向の分布を、元素によってはppb程度の高い感度で測定できます。イオン注入や拡散の評価によく使われますが、試料を削るため破壊分析です。特性X線で元素を調べるのはEDX、反射率で膜厚を測るのは光学的な方法です。

SIMSが不純物の原子の濃度を測るのに対して、電気的に活性なキャリアの濃度の深さ方向分布を測る方法として正しいものはどれか。

  1. AEDX
  2. B原子間力顕微鏡(AFM)
  3. C拡がり抵抗測定(SRP)などの電気的な測定
答えと解説を見る

正解：C. 拡がり抵抗測定(SRP)などの電気的な測定

拡がり抵抗測定は、試料を浅い角度で斜めに研磨して深さ方向を引き伸ばし、2本の探針を少しずつずらしながら当てて抵抗を測ることで、キャリア濃度の深さ方向の分布を求める方法です。SIMSは活性化していない不純物も含めた原子の濃度を測るため、両者を比べると活性化の割合が分かります。EDXは元素、AFMは形状を調べる方法です。

よくある質問

SIMSは破壊分析ですか?

はい。一次イオンビームが分析対象の材料をスパッタで削り取ってクレーターを残すため、測定した部分は製品として使えなくなります。

SIMSとSRP(拡がり抵抗測定)の違いは何ですか?

SIMS は電気的に活性かどうかに関係なく、不純物の全原子濃度を測ります。SRP は活性なキャリアの濃度を測るので、両者を比べると活性化率がわかります。

SIMSの一次イオンにセシウムや酸素を使うのはなぜですか?

酸素は正の二次イオンの収率を、セシウムは負の二次イオンの収率を高めるためです。測りたい元素の感度が最大になるようにビームを選び、たとえばホウ素には酸素を使います。
