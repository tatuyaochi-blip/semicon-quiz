INL(積分非直線性)とは

あいえぬえる

ADコンバータやDAコンバータの実際の入出力特性が、理想的な直線からどれだけ離れているかの最大値。DNLを積み重ねたものに相当する。

「INL(積分非直線性)」は、2分野の4問の練習問題に出てきます(AD/DA変換, テスト・検査など)。

この用語の分野: AD/DA変換

INL(積分非直線性)の練習問題に挑戦

ADコンバータの積分非直線性(INL)の説明として正しいものはどれか。

  1. A入力が0のときの出力のずれ
  2. B隣り合うコードの間隔が1 LSBからどれだけずれているか
  3. C実際の入出力特性が、理想的な直線からどれだけ離れているかの最大値
答えと解説を見る

正解：C. 実際の入出力特性が、理想的な直線からどれだけ離れているかの最大値

INLは、実際の変換特性の各点が理想直線からどれだけ離れているかの最大値で、両端を結ぶ直線(エンドポイント法)か、最もよく合う直線(ベストフィット法)を基準にします。DNLを積み重ねたものがINLに相当します。INLは大きな信号のひずみ(高調波)の原因になり、オーディオや計測では重要です。校正で取り除けるオフセットやゲイン誤差と違い、補正が難しい誤差です。

解説の中の「INL(積分非直線性)」

  • INLは、実際の変換特性の各点が理想直線からどれだけ離れているかの最大値で、両端を結ぶ直線(エンドポイント法)か、最もよく合う直線(ベストフィット法)を基準にします。

    ADコンバータの積分非直線性(INL)の説明として正しいものはどれか。

  • 入出力特性全体の理想直線からのずれは積分非直線性(INL)、入力0での出力のずれはオフセット誤差です。

    ADコンバータの微分非直線性(DNL)の説明として正しいものはどれか。

  • 一方、INLやDNLのような非直線の誤差は単純な校正では取り除けません。

    ADコンバータの入出力特性で、入力が0のときに出力が0からずれている誤差を何と呼ぶか。

  • 実際の出現回数とのずれから各コードの幅、つまりDNLを求め、それを積み上げてINLを求めます。

    ADコンバータのテストで、ゆっくり変化する正弦波などを入力して、各出力コードが現れる回数(ヒストグラム)を数える主な目…

「INL(積分非直線性)」が出てくる問題(4問)

  1. ADコンバータの積分非直線性(INL)の説明として正しいものはどれか。
  2. ADコンバータの微分非直線性(DNL)の説明として正しいものはどれか。
  3. ADコンバータの入出力特性で、入力が0のときに出力が0からずれている誤差を何と呼ぶか。
  4. ADコンバータのテストで、ゆっくり変化する正弦波などを入力して、各出力コードが現れる回数(ヒストグラム)を数える主な目的はどれか。
