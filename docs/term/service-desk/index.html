サービスデスクとは

さーびすですく

利用者からの問い合わせ、障害の連絡、サービスの要求などを一括して受け付ける単一の窓口(SPOC: Single Point of Contact)。受け付けた内容を記録し、自ら解決できるものは解決し、できないものは専門の技術チームなどにエスカレーションして、進み具合を管理し、利用者に結果を伝える。拠点ごとに置くローカル型、一か所に集める中央型、各地の要員をネットワークで結ぶバーチャル型などの形態がある。

「サービスデスク」は、1分野の5問の練習問題に出てきます(サービスマネジメントとシステム監査など)。

この用語の分野: サービスマネジメントとシステム監査

サービスデスクの練習問題に挑戦

サービスデスクが、利用者から「経費精算システムで、領収書の画像を添付すると送信ボタンが反応しない」と連絡を受けた。同じ現象は既知のエラーとして登録されており、「画像を別の登録画面から先に登録すれば送信できる」という回避策が記録されている。インシデント管理の対応として、最も適切なものはどれか。

  1. A根本原因が分かって恒久的な対策が終わるまで、利用者には経費精算の操作を待ってもらうよう依頼する
  2. Bサービスデスクの担当者が原因を推測し、本番環境のプログラムをその場で修正して再発を防ぐ
  3. C記録されている回避策を利用者に案内して業務を続けられるようにし、インシデントを記録して既知のエラーと関連付ける
答えと解説を見る

正解：C. 記録されている回避策を利用者に案内して業務を続けられるようにし、インシデントを記録して既知のエラーと関連付ける

インシデント管理の目的は、サービスをできるだけ早く通常の状態に戻し、業務への影響を小さくすることです。既知のエラーに回避策が記録されていれば、それを案内して利用者が業務を続けられるようにします。インシデントを記録して既知のエラーと関連付けておくと、発生の件数が分かり、恒久的な対策の優先度を判断する材料になります。根本原因の解決は問題管理が、本番環境の修正は変更管理を通して行います。

サービスデスクを、利用者からの問い合わせや障害の連絡を一括して受け付ける単一の窓口(SPOC)として設ける主な利点はどれか。

  1. A利用者は連絡先に迷わずに済み、受付の記録が一か所に集まるので、対応の状況や傾向を把握しやすくなる
  2. Bサービスデスクがすべての障害の根本原因を自ら解決するので、専門の技術者が不要になる
  3. C問い合わせの件数そのものが減り、障害が起きなくなる
答えと解説を見る

正解：A. 利用者は連絡先に迷わずに済み、受付の記録が一か所に集まるので、対応の状況や傾向を把握しやすくなる

サービスデスクは、利用者とITサービスの提供者を結ぶ単一の窓口(SPOC: Single Point of Contact)です。利用者は内容によって連絡先を探す必要がなく、受け付けた内容がすべて記録されるので、対応の進み具合を管理でき、インシデントの傾向の分析にも使えます。サービスデスクで解決できないものは、専門の技術チームに引き継ぎます。

「サービスデスク」が出てくる問題(5問)

  1. サービスデスクが、利用者から「経費精算システムで、領収書の画像を添付すると送信ボタンが反応しない」と連絡を受けた。同じ現象は既知のエラーとして登録されており、「画像を別の登録画面から先に登録すれば送信できる」という回避策が記録されている。インシデント管理の対応として、最も適切なものはどれか。
  2. サービスデスクを、利用者からの問い合わせや障害の連絡を一括して受け付ける単一の窓口(SPOC)として設ける主な利点はどれか。
  3. サービスデスクの担当者が受け付けたインシデントが、SLAで定めた解決の目標時間を超えそうになった。担当者は、サービスデスクの責任者に状況を報告し、要員の追加や利用者への連絡について判断を求めた。この対応に当たるものはどれか。
  4. ITサービスの提供者が、利用者とのSLAで約束したサービスレベルを達成するために、同じ組織の中のネットワーク運用部門などとの間で、それぞれが受け持つ作業の内容や水準を取り決める合意はどれか。
  5. 問題管理でいう「既知のエラー」の説明として、適切なものはどれか。
