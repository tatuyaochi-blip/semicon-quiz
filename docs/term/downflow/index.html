ダウンフローとは

だうんふろー

天井全面から床へ一方向に清浄な空気を流す、クリーンルームの気流の方式。発生した粒子をすばやく床下へ排出する。

「ダウンフロー」は、2分野の6問の練習問題に出てきます(クリーンルーム・製造装置, エッチングなど)。

この用語の分野: クリーンルーム・製造装置

ダウンフローの仕組み

ダウンフロー(垂直一方向流)方式のクリーンルームでは、天井のほぼ全面に高性能なHEPAフィルターやULPAフィルターが、多くの場合ファンフィルターユニット(FFU)として敷き詰められます。ろ過された空気は作業空間をまっすぐ下へ流れ、多孔の床パネルを通って床下の空間へ入り、側面のリターン経路やリターンシャフトを通って天井裏へ戻り、再びろ過されます。人や装置から出たパーティクルは、横に漂ったりウエハの方へ舞い上がったりする前に、下向きに押し流されて室外へ排出されます。

一方向流と乱流方式の違い

従来型のクリーンルームは天井の一部からのみ清浄空気を供給し、混合による希釈でパーティクルを減らすため、汚染が滞留して広がりやすくなります。ダウンフローでは部屋全体の空気が平行な流線に沿って動くため、ある場所で発生したパーティクルは希釈されるのではなく運び去られます。このため、おおむねISOクラス5以上の高い清浄度には一般に一方向流が必要で、混合方式はそれほど厳しくないエリアに向いています。その代償は、膨大な風量とファンの消費電力です。

代表的な数値

吹き出し風速は通常0.3〜0.5 m/s程度です。これより速いと人や装置の周りで乱流が生じてパーティクルを巻き上げ、遅いと高温の装置から立ち上る熱上昇流に負けてしまいます。0.4 m/sでは空気は1時間に約1,440 m進むため、天井高3〜4 mの部屋では空気が1時間に数百回入れ替わります。一般的なオフィスの換気回数が1時間に数回であるのと比べると桁違いです。これだけの空気を動かすことが、工場の電力消費の大きな割合を占めています。

床、スラブ、ミニエンバイロメント

空気を通すため、床は多孔パネルやグレーチングで作られ、ワッフルスラブの上に敷かれます。ワッフルスラブは格子状に穴が開いた厚いコンクリート床で、露光装置の振動対策に必要な剛性も確保します。最新の工場では、ウエハを密閉ポッドに入れて搬送し、独自のフィルターユニットを備えた装置前面部からロードするため、最高の清浄度が必要なのはこうしたミニエンバイロメントの内部だけです。周囲のベイはフィルターの設置率を下げられるので、ウエハを守りながら省エネルギー化できます。

ダウンフローの練習問題に挑戦

プラズマで生成したラジカルだけをウエハに供給するダウンフロー型エッチングの特徴として正しいものはどれか。

  1. Aイオン衝撃が強いため、異方性が非常に高い
  2. Bイオン衝撃がほとんどないため、ダメージが少なく等方的にエッチングできる
  3. C薬液を使ってエッチングする
答えと解説を見る

正解：B. イオン衝撃がほとんどないため、ダメージが少なく等方的にエッチングできる

ダウンフロー型(リモートプラズマ型)では、プラズマを発生させる場所とウエハを離し、途中でイオンや電子が再結合して失われるため、寿命の長い中性のラジカルだけがウエハに届きます。イオンが当たらずプラズマからの紫外線もさえぎられるためダメージが少なく、等方的にエッチングできます。レジストの除去、ダメージを嫌う工程での膜の除去、ナノシートの間のSiGeの除去などに使われます。

クリーンルームで、天井から床へ一方向に空気を流す(ダウンフロー)方式の主な目的はどれか。

  1. A発生した粒子をすばやく床下へ排出し、ウエハの周りに滞留させない
  2. B室温を上げる
  3. C室内の騒音を下げる
答えと解説を見る

正解：A. 発生した粒子をすばやく床下へ排出し、ウエハの周りに滞留させない

天井の高性能フィルタを通した清浄な空気を床に向けて一方向に流すと、人や装置から発生した粒子が舞い上がらずに床下へ運ばれます。こうして粒子がウエハの周りに滞留しないようにしています。部屋の空気をかき混ぜて薄める方式より高い清浄度が得られる一方、大量の空気を動かすため、空調のエネルギーが大きくなります。室温や騒音の調整が目的ではありません。

よくある質問

ダウンフロー方式のクリーンルームの風速はどれくらいですか?

一般的には約0.3〜0.5 m/sです。熱上昇流に負けない程度に速く、かつ人や装置の周りで乱流にならず滑らかに流れる程度に遅い速度です。

クリーンルームの床に穴が開いているのはなぜですか?

穴を通して下向きの気流を床下へ流し、循環させて戻すためです。穴のない床だと気流が横向きに曲がり、パーティクルを室内に巻き上げてしまいます。

クリーンルームの消費電力が大きいのはなぜですか?

一方向のダウンフローでは室内の空気を1時間に数百回入れ替えるため、大型ファンが常時稼働しているからです。さらに、その空気の温度と湿度も厳密に管理しなければなりません。
