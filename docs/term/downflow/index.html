ダウンフローとは

だうんふろー

天井全面から床へ一方向に清浄な空気を流す、クリーンルームの気流の方式。発生した粒子をすばやく床下へ排出する。

「ダウンフロー」は、2分野の6問の練習問題に出てきます(クリーンルーム・製造装置, エッチングなど)。

この用語の分野: クリーンルーム・製造装置

ダウンフローの練習問題に挑戦

プラズマで生成したラジカルだけをウエハに供給するダウンフロー型エッチングの特徴として正しいものはどれか。

  1. Aイオン衝撃が強いため、異方性が非常に高い
  2. Bイオン衝撃がほとんどないため、ダメージが少なく等方的にエッチングできる
  3. C薬液を使ってエッチングする
答えと解説を見る

正解：B. イオン衝撃がほとんどないため、ダメージが少なく等方的にエッチングできる

ダウンフロー型(リモートプラズマ型)では、プラズマを発生させる場所とウエハを離し、途中でイオンや電子が再結合して失われるため、寿命の長い中性のラジカルだけがウエハに届きます。イオンが当たらずプラズマからの紫外線もさえぎられるためダメージが少なく、等方的にエッチングできます。レジストの除去、ダメージを嫌う工程での膜の除去、ナノシートの間のSiGeの除去などに使われます。

クリーンルームで、天井から床へ一方向に空気を流す(ダウンフロー)方式の主な目的はどれか。

  1. A発生した粒子をすばやく床下へ排出し、ウエハの周りに滞留させない
  2. B室温を上げる
  3. C室内の騒音を下げる
答えと解説を見る

正解：A. 発生した粒子をすばやく床下へ排出し、ウエハの周りに滞留させない

天井の高性能フィルタを通した清浄な空気を床に向けて一方向に流すと、人や装置から発生した粒子が舞い上がらずに床下へ運ばれます。こうして粒子がウエハの周りに滞留しないようにしています。部屋の空気をかき混ぜて薄める方式より高い清浄度が得られる一方、大量の空気を動かすため、空調のエネルギーが大きくなります。室温や騒音の調整が目的ではありません。

解説の中の「ダウンフロー」

  • ダウンフロー型(リモートプラズマ型)では、プラズマを発生させる場所とウエハを離し、途中でイオンや電子が再結合して失われるため、寿命の長い中性のラジカルだけがウエハに届きます。

    プラズマで生成したラジカルだけをウエハに供給するダウンフロー型エッチングの特徴として正しいものはどれか。

  • ダウンフロー方式では、天井のフィルタから吹き出した空気を、穴のあいた床から床下の空間へ吸い込み、側面の通路などを通って再び天井に戻して循環させます。

    ダウンフロー方式のクリーンルームで、床に穴のあいたパネル(グレーチング)を使う理由として正しいものはどれか。

  • ダウンフロー方式のクリーンルームでは、天井から約0.3〜0.5 m/s程度のゆっくりとした一方向の気流を流します。

    ダウンフロー方式のクリーンルームで一般的な、天井からの吹き出し風速の目安はどれか。

  • ダウンフロー方式では天井全面から約0.4 m/sで空気を吹き出すと、1時間に約1440 m進む計算になり、天井の高さが3〜4 mの部屋では1時間に数百回も空気が入れ替わります。

    高い清浄度のダウンフロー方式のクリーンルームで、1時間に部屋の空気が入れ替わる回数(換気回数)の目安として最も近いもの…

  • ワッフルスラブは、格子状の梁で補強された厚いコンクリートの床に多数の穴をあけたもので、ダウンフローの空気を床下へ通す通路になります。

    半導体工場のクリーンルームの床に使われる、格子状に穴のあいた厚いコンクリートの床(ワッフルスラブ)の役割として正しいも…

「ダウンフロー」が出てくる問題(6問)

  1. プラズマで生成したラジカルだけをウエハに供給するダウンフロー型エッチングの特徴として正しいものはどれか。
  2. クリーンルームで、天井から床へ一方向に空気を流す(ダウンフロー)方式の主な目的はどれか。
  3. ダウンフロー方式のクリーンルームで、床に穴のあいたパネル(グレーチング)を使う理由として正しいものはどれか。
  4. ダウンフロー方式のクリーンルームで一般的な、天井からの吹き出し風速の目安はどれか。
  5. 高い清浄度のダウンフロー方式のクリーンルームで、1時間に部屋の空気が入れ替わる回数(換気回数)の目安として最も近いものはどれか。
  6. 半導体工場のクリーンルームの床に使われる、格子状に穴のあいた厚いコンクリートの床(ワッフルスラブ)の役割として正しいものはどれか。
