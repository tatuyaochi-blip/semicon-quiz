初期参照ミスとは

しょきさんしょうみす

そのデータに初めてアクセスしたため、必ず起こるキャッシュミス。強制ミス(compulsory miss)ともいう。キャッシュを大きくしても減らないが、ラインを大きくしたりプリフェッチしたりすると減らせる。

「初期参照ミス」は、2分野の5問の練習問題に出てきます(メモリ階層と性能, CPU・アーキテクチャなど)。

この用語の分野: メモリ階層と性能

初期参照ミスの練習問題に挑戦

キャッシュミスの分類「3つのC」に含まれるものの組み合わせとして正しいものはどれか。

  1. A書き込みミス・読み出しミス・分岐ミス
  2. Bクロックミス・電圧ミス・温度ミス
  3. C初期参照ミス・容量ミス・競合ミス
答えと解説を見る

正解：C. 初期参照ミス・容量ミス・競合ミス

キャッシュミスは、初めてのアクセスで起こる初期参照ミス(Compulsory)、容量不足で追い出されたために起こる容量ミス(Capacity)、同じセットの取り合いで起こる競合ミス(Conflict)に分類されます。対策は、初期参照ミスにはラインを大きくしたりプリフェッチで先読みしたり、容量ミスにはキャッシュを大きくしたり、競合ミスには連想度を上げたりと、原因ごとに異なります。

ダイレクトマップ方式のキャッシュで、2つの配列の要素が同じキャッシュの位置に対応し、交互にアクセスするたびに互いを追い出し合っている。このミスの分類はどれか。

  1. A初期参照ミス
  2. B容量ミス
  3. C競合ミス
答えと解説を見る

正解：C. 競合ミス

キャッシュ全体には余裕があるのに、2つのデータが同じセットを取り合って追い出し合うミスは競合ミスです。連想度を上げて同じセットに2つ以上置けるようにしたり、配列の先頭をずらして別のセットに対応させたりすると減らせます。容量ミスはワーキングセットがキャッシュ全体より大きいことが原因で、フルアソシアティブにしても減りません。初期参照ミスは初めてのアクセスで起こるもので、繰り返しのアクセスでは当てはまりません。

解説の中の「初期参照ミス」

  • キャッシュミスは、初めてのアクセスで起こる初期参照ミス(Compulsory)、容量不足で追い出されたために起こる容量ミス(Capacity)、同じセットの取り合いで起こる競合ミス(Conflict)に分類されます。

    キャッシュミスの分類「3つのC」に含まれるものの組み合わせとして正しいものはどれか。

  • 初期参照ミスは初めてのアクセスで起こるもので、繰り返しのアクセスでは当てはまりません。

    ダイレクトマップ方式のキャッシュで、2つの配列の要素が同じキャッシュの位置に対応し、交互にアクセスするたびに互いを追い…

  • 初めてのアクセスで起こる初期参照ミスは、そのデータがまだ一度もキャッシュに入っていないために起こるので、容量や連想度を増やしても減りません。

    プログラムがあるデータに初めてアクセスしたときに起こるキャッシュミスを減らす方法として、効果があるものはどれか。

  • ラインを大きくすると、1回のミスで近くのデータをまとめて読み込めるので、空間的局所性のある処理では初期参照ミスが減ります。

    キャッシュのラインサイズを大きくしたときの影響として正しいものはどれか。

  • 小さいので容量ミスを大きく減らす効果はなく、一度も読み込んでいないデータの初期参照ミスにも効きません。

「初期参照ミス」が出てくる問題(5問)

  1. キャッシュミスの分類「3つのC」に含まれるものの組み合わせとして正しいものはどれか。
  2. ダイレクトマップ方式のキャッシュで、2つの配列の要素が同じキャッシュの位置に対応し、交互にアクセスするたびに互いを追い出し合っている。このミスの分類はどれか。
  3. プログラムがあるデータに初めてアクセスしたときに起こるキャッシュミスを減らす方法として、効果があるものはどれか。
  4. キャッシュのラインサイズを大きくしたときの影響として正しいものはどれか。
  5. 小容量のフルアソシアティブ方式のバッファに、L1キャッシュから追い出されたラインを一時的に保持するビクティムキャッシュの主な効果はどれか。
