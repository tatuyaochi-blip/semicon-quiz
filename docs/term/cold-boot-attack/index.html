コールドブート攻撃とは

こーるどぶーとこうげき

電源を切った後もしばらく残るDRAMの内容を読み出し、鍵などを取り出す攻撃。冷やすと長く残る。メモリの暗号化で防ぐ。

「コールドブート攻撃」は、2分野の2問の練習問題に出てきます(ハードウェアセキュリティ, DRAMなど)。

この用語の分野: ハードウェアセキュリティ

コールドブート攻撃の練習問題に挑戦

コールドブート攻撃が成り立つ理由と、代表的な対策の組み合わせとして正しいものはどれか。

  1. ADRAMは電源を切ると一瞬で完全に消える。電源を入れたままにする
  2. BDRAMは温めると内容が読みやすくなる。冷却装置を付ける
  3. CDRAMの内容は電源を切っても数秒〜数分残り、冷やすとさらに長く残る。メモリの内容を暗号化しておく
答えと解説を見る

正解：C. DRAMの内容は電源を切っても数秒〜数分残り、冷やすとさらに長く残る。メモリの内容を暗号化しておく

DRAMのセルの電荷は、リフレッシュがなくなってもすぐには消えず、数秒から数分は内容がかなり残り、低温ではさらに長く残ります。電源を切った直後のパソコンからメモリを取り出し、別の機器で読み出すと、ディスクの暗号の鍵などが見つかることがあります。メモリの内容を回路で暗号化する、電源を切るときに鍵を消す、鍵をCPUの中だけに置く、などの対策があります。

解説の中の「コールドブート攻撃」

  • ただし電源を切った直後に冷却すると数秒〜数分データが残ることがあり、それを悪用してメモリ内の暗号鍵を読み出す「コールドブート攻撃」が知られています。

    DRAMの性質として正しいものはどれか。
