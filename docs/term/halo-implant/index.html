ハロー注入(ポケット注入)とは

はろーちゅうにゅう

ソース・ドレインの端に、チャネルと同じ導電型の不純物を斜めに注入する方法。ドレインの空乏層の広がりを抑え、短チャネル効果を抑える。

「ハロー注入(ポケット注入)」は、2分野の4問の練習問題に出てきます(イオン注入, MOSFETなど)。

この用語の分野: イオン注入

ハロー注入(ポケット注入)の練習問題に挑戦

MOSFETのパンチスルーの説明として正しいものはどれか。

  1. Aチャネルの移動度が温度で下がること
  2. Bソースとドレインの空乏層がつながり、ゲートで制御できない電流が流れること
  3. Cゲート絶縁膜が絶縁破壊すること
答えと解説を見る

正解：B. ソースとドレインの空乏層がつながり、ゲートで制御できない電流が流れること

チャネルが短く基板の濃度が低いと、ドレイン電圧でドレイン側の空乏層がソース側の空乏層とつながり、ゲートと無関係に基板の深い所を電流が流れてオフにできなくなります。これがパンチスルーです。対策は、ソース・ドレインの下に高濃度の層(ハロー/ポケット注入)を入れる、接合を浅くする、さらにFinFETやGAAのようにゲートでチャネルを囲み、制御できない電流経路をなくすことです。

ソース・ドレインの端に、チャネルと同じ導電型の不純物を斜めに注入するハロー(ポケット)注入の主な目的はどれか。

  1. Aゲート電極の抵抗を下げる
  2. B短チャネル効果を抑える
  3. Cトランジスタを発光させる
答えと解説を見る

正解：B. 短チャネル効果を抑える

ハロー注入では、ウエハを20〜45°程度傾けて、ゲートの下に潜り込むようにソース・ドレイン端の近くにチャネルと同じ導電型の不純物を局所的に入れます。ドレインから広がる空乏層を抑えられるため、ゲート長が短くなってもしきい値電圧の低下やパンチスルーを抑えられます。チャネル全体を濃くするより移動度の低下が小さく、平面型の微細なトランジスタで標準的に使われました。

解説の中の「ハロー注入(ポケット注入)」

  • 対策は、ソース・ドレインの下に高濃度の層(ハロー/ポケット注入)を入れる、接合を浅くする、さらにFinFETやGAAのようにゲートでチャネルを囲み、制御できない電流経路をなくすことです。

  • ハロー注入では、ウエハを20〜45°程度傾けて、ゲートの下に潜り込むようにソース・ドレイン端の近くにチャネルと同じ導電型の不純物を局所的に入れます。

  • チャネリング対策やハロー注入でウエハを傾けて注入すると、背の高いレジストやゲートの陰になる部分にはイオンが届かなくなります(シャドウイング)。

    ウエハを傾けてイオン注入を行う際に、レジストなどの高いパターンの陰になって注入されない部分ができる現象を何と呼ぶか。

  • イオン注入装置は、ドーズ量とエネルギーの範囲によって、中電流(しきい値調整やハロー注入など、10¹¹〜10¹⁴ cm⁻²)、高電流(ソース・ドレインなどの高ドーズ)、高エネルギー(深いウェルなど)に分けられます。

    MOSFETのしきい値電圧の調整やウェルのような、中程度のドーズ量の注入に主に使われるイオン注入装置はどれか。
