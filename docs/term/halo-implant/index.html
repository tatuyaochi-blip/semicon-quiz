ハロー注入(ポケット注入)とは

はろーちゅうにゅう

ソース・ドレインの端に、チャネルと同じ導電型の不純物を斜めに注入する方法。ドレインの空乏層の広がりを抑え、短チャネル効果を抑える。

この用語の分野: イオン注入

解説の中の「ハロー注入(ポケット注入)」

  • 対策は、ソース・ドレインの下に高濃度の層(ハロー/ポケット注入)を入れる、接合を浅くする、さらにFinFETやGAAのようにゲートでチャネルを囲み、制御できない電流経路をなくすことです。

    MOSFETのパンチスルーの説明として正しいものはどれか。

  • ハロー注入では、ウエハを20〜45°程度傾けて、ゲートの下に潜り込むようにソース・ドレイン端の近くにチャネルと同じ導電型の不純物を局所的に入れます。

    ソース・ドレインの端に、チャネルと同じ導電型の不純物を斜めに注入するハロー(ポケット)注入の主な目的はどれか。

  • チャネリング対策やハロー注入でウエハを傾けて注入すると、背の高いレジストやゲートの陰になる部分にはイオンが届かなくなります(シャドウイング)。

    ウエハを傾けてイオン注入を行う際に、レジストなどの高いパターンの陰になって注入されない部分ができる現象を何と呼ぶか。

「ハロー注入(ポケット注入)」が出てくる問題(4問)

  1. MOSFETのパンチスルーの説明として正しいものはどれか。
  2. ソース・ドレインの端に、チャネルと同じ導電型の不純物を斜めに注入するハロー(ポケット)注入の主な目的はどれか。
  3. ウエハを傾けてイオン注入を行う際に、レジストなどの高いパターンの陰になって注入されない部分ができる現象を何と呼ぶか。
  4. MOSFETのしきい値電圧の調整やウェルのような、中程度のドーズ量の注入に主に使われるイオン注入装置はどれか。
