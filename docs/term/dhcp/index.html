DHCPとは

でぃーえいちしーぴー

Dynamic Host Configuration Protocolの略。ネットワークにつないだ端末に、IPアドレス、サブネットマスク、デフォルトゲートウェイ、DNSサーバなどの設定を期限付きで自動的に割り当てるプロトコル。

「DHCP」は、1分野の3問の練習問題に出てきます(ネットワークの基礎など)。

この用語の分野: ネットワークの基礎

DHCPの練習問題に挑戦

DHCPで端末がIPアドレスを得るときの、メッセージの順序として正しいものはどれか。

  1. ARequest → Offer → Discover → Ack
  2. BDiscover → Offer → Request → Ack
  3. COffer → Discover → Ack → Request
答えと解説を見る

正解：B. Discover → Offer → Request → Ack

アドレスをまだもたない端末は、DHCPサーバの場所も分からないため、まずDiscoverをブロードキャストで送ります。サーバは貸し出せるアドレスなどをOfferで提示し、端末はどのサーバの提示を受けるかをRequestで知らせ、サーバがAckで確定します。頭文字をとってDORAと呼ばれます。端末はIPアドレスのほか、サブネットマスク、デフォルトゲートウェイ、DNSサーバのアドレスなども受け取ります。アドレスは期限(リース期間)付きの貸し出しで、端末は期限が来る前に更新を求めます。ルータを越えた先のDHCPサーバを使うには、ルータでDHCPリレーを設定します。

解説の中の「DHCP」

  • アドレスをまだもたない端末は、DHCPサーバの場所も分からないため、まずDiscoverをブロードキャストで送ります。

    DHCPで端末がIPアドレスを得るときの、メッセージの順序として正しいものはどれか。

  • 32ビットでルータが経路を選ぶのに使うのはIPv4アドレスで、DHCPで割り当てられるのもIPアドレスです。

    MACアドレスについて正しいものはどれか。

  • ドメイン名からIPアドレスを調べるのはDNS、IPアドレスの自動割り当てはDHCPの役割です。

    ARPの役割として正しいものはどれか。

「DHCP」が出てくる問題(3問)

  1. DHCPで端末がIPアドレスを得るときの、メッセージの順序として正しいものはどれか。
  2. MACアドレスについて正しいものはどれか。
  3. ARPの役割として正しいものはどれか。
