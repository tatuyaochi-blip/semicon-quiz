ロックフリーとは

ろっくふりー

どれかのスレッドが途中で止まっても、ほかのスレッドのうち少なくとも1つは処理を進められるアルゴリズムの性質。CASなどのアトミック命令で作る。

この用語の分野: マルチコアと同期

解説の中の「ロックフリー」

  • ロックフリーのアルゴリズムはCASなどで共有データを直接更新し、あるスレッドが失敗してやり直すのは、ほかの誰かが成功したときだけ、という形にします。

    ロックフリー(lock-free)のアルゴリズムの性質として正しいものはどれか。

  • CAS(コンペア・アンド・スワップ)やフェッチ・アンド・アッド、RISC-VのLR/SCやAMO命令などがあり、ロックやロックフリーのデータ構造を作る土台になります。

    アトミック命令(不可分命令)の説明として正しいものはどれか。

「ロックフリー」が出てくる問題(3問)

  1. CASを使ったロックフリーのデータ構造で問題になるABA問題の説明として正しいものはどれか。
  2. ロックフリー(lock-free)のアルゴリズムの性質として正しいものはどれか。
  3. アトミック命令(不可分命令)の説明として正しいものはどれか。
