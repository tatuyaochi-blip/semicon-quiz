フリップフロップとは

ふりっぷふろっぷ

1ビットの情報を保持する順序回路の基本素子。D型はクロックのエッジで入力を取り込む。

「フリップフロップ」は、7分野の60問の練習問題に出てきます(ハードウェア記述言語と検証, タイミング解析とCDC, 論理回路など)。

この用語の分野: 論理回路

Dフリップフロップの動作

Dフリップフロップは、有効なクロックエッジでD入力を取り込み、その値を次のエッジまでQに保持します。エッジとエッジの間の入力変化は無視されます。内部は通常、逆位相のクロックで動く二つのラッチを組み合わせたマスタースレーブ構成です。これに対してラッチはレベルセンシティブで、イネーブルの間は透過状態となり、入力をそのまま出力に通します。エッジトリガのほうがタイミング解析がはるかに容易なため、同期設計では CPU のレジスタ、パイプラインの段の区切り、ステートマシン、カウンタにフリップフロップが使われます。

セットアップ時間、ホールド時間と最大周波数

データはクロックエッジ前のセットアップ時間と、エッジ後のホールド時間のあいだ安定している必要があります。レジスタ間パスでは、クロック周期がクロック・出力間遅延、論理遅延、セットアップ時間の合計以上でなければならず、0.15 + 2.2 + 0.15 ns なら最小周期は 2.5 ns、つまり 400 MHz です。セットアップ違反はクロックを遅くすれば解消できますが、ホールド違反は解消できません。ホールドチェックは同じエッジで送出・取り込みされるデータを比べるためで、代わりに遅延バッファを挿入します。取り込み側クロックを遅らせるクロックスキューは、セットアップには有利、ホールドには不利に働きます。

メタステーブルとシンクロナイザ

無関係なクロックから来る信号のように、セットアップ・ホールドの窓の中でデータが変化すると、フリップフロップはメタステーブル状態になり、出力が0と1の間にとどまることがあります。未確定のまま残る確率は時間とともに指数関数的に下がりますが、ゼロにはなりません。2段以上のフリップフロップを直列につないだシンクロナイザは初段に1クロック周期分の安定時間を与え、平均故障間隔を数千年以上にまで延ばします。複数ビットの値は非同期 FIFO やハンドシェイクでクロックドメインを渡し、CDC(クロックドメインクロッシング)検証ツールでこれらの構造があるかを確認します。

そのほかの種類と用途

JKフリップフロップは、J = 1 でセット、K = 1 でリセット、両方0で保持、両方1でトグルし、SRフリップフロップで禁止されていた入力にも意味をもたせています。入力を High に固定すると毎エッジ反転するTフリップフロップになり、クロックをデューティ比 50% で2分周します。これを連ねたものがリップルカウンタや分周器です。現代のロジックではほぼDフリップフロップだけが使われます。テスト用のスキャン設計では、各フリップフロップの入力にマルチプレクサを追加し、フリップフロップをシフトレジスタとして連結して内部状態の設定や観測を行います。

フリップフロップの練習問題に挑戦

D型フリップフロップの動作として正しいものはどれか。

  1. A入力の変化を常にそのまま出力に伝える
  2. B2つの入力の排他的論理和を出力する
  3. CクロックのエッジでD入力の値を取り込み、次のエッジまで保持する
答えと解説を見る

正解：C. クロックのエッジでD入力の値を取り込み、次のエッジまで保持する

D型フリップフロップは、クロックの立ち上がり(または立ち下がり)のエッジでD入力の値を取り込み、次のエッジまで保持します。エッジの瞬間だけを見るため、その間に入力が変化しても出力は変わりません。CPUのレジスタやパイプラインの段の区切り、カウンタなど順序回路の基本で、内部は2つのラッチを主従(マスター・スレーブ)につないだ構造です。正しく取り込むにはセットアップ時間とホールド時間を守る必要があります。

フリップフロップのセットアップ時間の説明として正しいものはどれか。

  1. Aクロックのエッジのあとに、データを保持し続けなければならない最小時間
  2. Bクロックのエッジより前に、データ入力が安定していなければならない最小時間
  3. C電源を入れてから動作するまでの時間
答えと解説を見る

正解：B. クロックのエッジより前に、データ入力が安定していなければならない最小時間

フリップフロップが正しく取り込むには、クロックのエッジより一定時間前からデータが安定している必要があり、これがセットアップ時間です。データ経路の遅延がクロック周期からセットアップ時間を引いた値を超えると違反になり、クロックを遅くすれば解消できます。エッジ後にデータを保持する必要がある時間はホールド時間で、どちらかを満たさないと誤った値の取り込みやメタステーブルの原因になります。

よくある質問

ラッチとフリップフロップの違いは何ですか?

ラッチはレベルセンシティブで、イネーブルの間は入力をそのまま出力に通します。フリップフロップはエッジトリガで、クロックエッジでのみ入力を取り込みます。一般的なDフリップフロップは、逆のクロック位相でイネーブルになる二つのラッチで構成されています。

ホールド違反はなぜクロック周波数を下げても直らないのですか?

ホールドチェックは同じクロックエッジで送出・取り込みされるデータを比べるため、クロック周期が関係しないからです。対策は短いパスに遅延を加えることで、通常はバッファを挿入します。

フリップフロップ間パスの最大クロック周波数はどう計算しますか?

クロック・出力間遅延、最悪ケースの組み合わせ回路遅延、セットアップ時間を足し、クロックスキューで補正したものが最小周期で、その逆数が最大周波数です。チップ上で最も遅いパス、つまりクリティカルパスがチップ全体の上限を決めます。

「フリップフロップ」が出てくる問題(60問)

  1. D型フリップフロップの動作として正しいものはどれか。
  2. フリップフロップのセットアップ時間の説明として正しいものはどれか。
  3. 非同期の信号をフリップフロップで受けたときに、セットアップ時間やホールド時間を満たせず、出力が一時的に0とも1とも定まらなくなる状態を何と呼ぶか。
  4. フリップフロップを直列につなぎ、クロックごとにデータを1ビットずつ隣へ移すシフトレジスタの代表的な用途はどれか。
  5. すべてのフリップフロップが共通のクロックで動作する同期式回路の利点として正しいものはどれか。
  6. JKフリップフロップで、J = 1、K = 1 のときにクロックが入ったときの動作はどれか。
  7. クロックが入るたびに出力が反転するTフリップフロップ1個の出力の周波数は、クロック周波数の何倍になるか。
  8. フリップフロップのホールド時間の説明として正しいものはどれか。
  9. n個のフリップフロップで構成したジョンソンカウンタ(ツイストリングカウンタ)がとる状態の数はいくつか。
  10. 静的タイミング解析で、信号がクロックのエッジ直後に早く変化しすぎて、フリップフロップが前のデータを正しく保持できなくなるタイミング違反はどれか。
  11. クロック周期 2.0 ns の同期回路で、送り側フリップフロップのクロック→出力遅延が 0.2 ns、組み合わせ回路の遅延が 1.4 ns、受け側フリップフロップのセットアップ時間が 0.1 ns である。クロックスキューを0とすると、セットアップのスラックはいくらか。
  12. フリップフロップ間の経路で、クロック→出力遅延が 0.15 ns、組み合わせ回路の最大遅延が 2.2 ns、セットアップ時間が 0.15 ns である。スキューとクロックの不確かさを無視すると、この経路で動作できる最大のクロック周波数はいくらか。
  13. クロック周期 1.0 ns、クロック→出力遅延 0.1 ns、組み合わせ回路の遅延 0.85 ns、セットアップ時間 0.08 ns の経路がある。受け側フリップフロップのクロックが送り側より 0.05 ns 遅れて届くとき、セットアップのスラックはいくらか。
  14. 受け側フリップフロップのクロックが送り側より遅れて届く(正のスキュー)ときの、セットアップとホールドへの影響として正しいものはどれか。
  15. 周期 2.0 ns のクロックで、時刻0の立ち上がりエッジでデータを出すフリップフロップから、時刻 1.0 ns に開いて(透過になって)時刻 2.0 ns に閉じるラッチへの経路がある。データがラッチに時刻 1.4 ns に着いたとき、このラッチで借りた時間(タイムボロー)はいくらか。
