DFT(テスト容易化設計)とは

てすとよういかせっけい

スキャンチェーンやBISTなど、テストしやすくする仕組みをあらかじめ回路に組み込む設計手法。

この用語の分野: テスト・検査

解説の中の「DFT(テスト容易化設計)」

  • スキャン設計やテストポイントの挿入などのDFTは、この2つを高めて少ないパターンで故障を検出できるようにします。

    テスト容易化設計で高めることを目指す2つの性質の組み合わせとして正しいものはどれか。

  • DFTはテストのしやすさ、CTSはクロックの分配のための手法です。

    製造上のばらつきや欠陥の影響を受けにくいように、レイアウトなどを工夫する設計の考え方はどれか。

  • SPCは品質管理、DFTはテスト容易化設計の手法です。

    作業を始める前に、その作業に潜む危険を話し合い、対策を確認する活動を何と呼ぶか。

「DFT(テスト容易化設計)」が出てくる問題(4問)

  1. テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。
  2. テスト容易化設計で高めることを目指す2つの性質の組み合わせとして正しいものはどれか。
  3. 製造上のばらつきや欠陥の影響を受けにくいように、レイアウトなどを工夫する設計の考え方はどれか。
  4. 作業を始める前に、その作業に潜む危険を話し合い、対策を確認する活動を何と呼ぶか。
