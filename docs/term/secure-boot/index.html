セキュアブートとは

せきゅあぶーと

起動の各段階で次に動かすソフトウェアの電子署名を確かめ、正しいものだけを起動する仕組み。信頼の鎖をつないでいく。

この用語の分野: ハードウェアセキュリティ

解説の中の「セキュアブート」

  • セキュアブートでは、書き換えられないROMのコードが最初のブートローダの署名を確かめ、そのブートローダが次の段階やOSのカーネルの署名を確かめる、というように、信頼の鎖をつないでいきます。

    セキュアブートの説明として正しいものはどれか。

  • 製品にそのまま残っていると、攻撃者が基板の端子に装置をつないで、ファームウェアを読み出したり、セキュアブートを飛ばしたり、鍵を取り出したりできてしまいます。

    製品として出荷する機器で、JTAGなどのデバッグ用のポートを無効にしたり、認証が必要なようにしたりする理由として正しい…

  • 多層防御では、セキュアブート、メモリの保護、TEE、暗号化、サイドチャネル対策、物理的な耐タンパ性など、性質の違う対策を重ねて、1つが破られても次の層で守れるようにします。

    ハードウェアとソフトウェアのセキュリティで重視される「多層防御」の考え方として正しいものはどれか。

「セキュアブート」が出てくる問題(7問)

  1. セキュアブートの説明として正しいものはどれか。
  2. セキュアブートの「ルートオブトラスト(信頼の起点)」として、チップの中に置かれるものとして最も適切なものはどれか。
  3. セキュアブートで、ソフトウェアの署名の確認に公開鍵暗号を使う利点として正しいものはどれか。
  4. セキュアブートを備えた機器で、ロールバック防止(アンチロールバック)の仕組みが必要になる理由として正しいものはどれか。
  5. セキュアブートと測定ブート(メジャードブート)の違いとして正しいものはどれか。
  6. 製品として出荷する機器で、JTAGなどのデバッグ用のポートを無効にしたり、認証が必要なようにしたりする理由として正しいものはどれか。
  7. ハードウェアとソフトウェアのセキュリティで重視される「多層防御」の考え方として正しいものはどれか。
