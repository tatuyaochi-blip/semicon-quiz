セキュアブートとは

せきゅあぶーと

起動の各段階で次に動かすソフトウェアの電子署名を確かめ、正しいものだけを起動する仕組み。信頼の鎖をつないでいく。

「セキュアブート」は、1分野の7問の練習問題に出てきます(ハードウェアセキュリティなど)。

この用語の分野: ハードウェアセキュリティ

セキュアブートの練習問題に挑戦

セキュアブートの説明として正しいものはどれか。

  1. Aパソコンを速く起動するための仕組み
  2. B起動の各段階で、次に動かすソフトウェアの電子署名を確かめ、正しいものだけを起動する
  3. C起動のたびに、ディスクの内容をすべて消去する仕組み
答えと解説を見る

正解：B. 起動の各段階で、次に動かすソフトウェアの電子署名を確かめ、正しいものだけを起動する

セキュアブートでは、書き換えられないROMのコードが最初のブートローダの署名を確かめ、そのブートローダが次の段階やOSのカーネルの署名を確かめる、というように、信頼の鎖をつないでいきます。どこかの段階で署名が合わなければ起動を止めるので、マルウェアがブートローダやOSの起動の部分を書き換えても動かせません。スマートフォンやパソコン、組込み機器で広く使われています。

セキュアブートの「ルートオブトラスト(信頼の起点)」として、チップの中に置かれるものとして最も適切なものはどれか。

  1. A書き換えられないROMの起動コードと、署名を確かめるための公開鍵(またはそのハッシュ値)
  2. B誰でも書き換えられるフラッシュメモリの起動コード
  3. Cインターネットからダウンロードした最新のOS
答えと解説を見る

正解：A. 書き換えられないROMの起動コードと、署名を確かめるための公開鍵(またはそのハッシュ値)

信頼の鎖は、最初の確認をする部分が正しいことを前提にしています。そのため、チップの製造時に書き込まれ、後から変えられないマスクROMの起動コードと、署名の検証に使う公開鍵(容量を節約するためハッシュ値をeFuseに書くことも多い)をルートオブトラストにします。ここが書き換えられると、その後のすべての確認が意味を失います。

「セキュアブート」が出てくる問題(7問)

  1. セキュアブートの説明として正しいものはどれか。
  2. セキュアブートの「ルートオブトラスト(信頼の起点)」として、チップの中に置かれるものとして最も適切なものはどれか。
  3. セキュアブートで、ソフトウェアの署名の確認に公開鍵暗号を使う利点として正しいものはどれか。
  4. セキュアブートを備えた機器で、ロールバック防止(アンチロールバック)の仕組みが必要になる理由として正しいものはどれか。
  5. セキュアブートと測定ブート(メジャードブート)の違いとして正しいものはどれか。
  6. 製品として出荷する機器で、JTAGなどのデバッグ用のポートを無効にしたり、認証が必要なようにしたりする理由として正しいものはどれか。
  7. ハードウェアとソフトウェアのセキュリティで重視される「多層防御」の考え方として正しいものはどれか。
