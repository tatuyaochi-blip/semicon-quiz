ロード・ストア・アーキテクチャとは

ろーど・すとあ・あーきてくちゃ

メモリを読み書きする命令をロードとストアに限り、加算などの演算はレジスタ同士で行うISAの方式。RISC-VやARMが採用し、命令の形がそろってパイプラインで処理しやすい。

「ロード・ストア・アーキテクチャ」は、1分野の1問の練習問題に出てきます(命令セット・アセンブリなど)。

この用語の分野: 命令セット・アセンブリ

メモリを扱う命令を分ける考え方

ロード・ストア・アーキテクチャでは、メモリを読み書きできるのはロード命令とストア命令だけで、加算や比較などの演算はレジスタ同士で行います。たとえばメモリ上の変数bとcを足してaに書く処理は、RISC-Vでは、bとcをlw命令でレジスタに読み込み、add命令で足し、sw命令でaに書き戻す4命令になります。これに対し、x86の「add eax, [mem]」のように演算命令がメモリを直接読める方式はレジスタ・メモリ型と呼ばれ、ロード・ストア型とは対照的です。

パイプラインと相性がよい理由

演算命令がメモリに触れないので、どの命令もメモリへのアクセスは多くても1回で、命令の形や処理の流れがそろいます。古典的な5段のパイプライン(命令フェッチ、デコード、実行、メモリアクセス、書き戻し)では、メモリアクセスの段を使うのはロードとストアだけで、ほかの命令はそこを素通りします。命令の取り出しを除けば、アドレス変換の失敗やページフォルトのようなメモリに関する例外もロードとストアでしか起きないため、例外の処理が単純になります。命令の長さを固定にしやすく、デコードも簡単になります。

レジスタの数とコードサイズ

値をいったんレジスタに置いてから演算するため、ロード・ストア型のISAは汎用レジスタを多くもつのが一般的です。RISC-Vの整数レジスタは32本、ARMの64ビット命令セット(AArch64)の汎用レジスタは31本です。コンパイラはよく使う値をレジスタに割り付けて、ロードとストアの回数を減らします。一方、命令の数が増えてコードが大きくなりやすいため、RISC-VのC拡張(圧縮命令)やARMのThumbのように、短い命令の形式を用意してコード密度を高める工夫があります。

CISCとの関係と例外的な命令

ロード・ストア型はRISCの代表的な特徴で、RISC-V、ARM、MIPS、Powerなどが採用しています。レジスタ・メモリ型のx86も、現在のCPUの内部では、メモリを読む演算命令をロードと演算のマイクロオペレーションに分けて実行しており、実行の段階ではロード・ストア型に近い形になっています。ただしロード・ストア型のISAにも、メモリ上の値を読んで演算して書き戻すアトミック命令(RISC-VのA拡張のAMO命令など)があり、マルチコアの同期のために例外的に用意されています。

ロード・ストア・アーキテクチャの練習問題に挑戦

RISC-Vのようなロード・ストア・アーキテクチャの特徴として正しいものはどれか。

  1. A加算などの演算命令が、メモリ上の値を直接読み出して計算し、結果をメモリに書き戻す
  2. Bメモリを読み書きできるのはロード命令とストア命令だけで、演算はレジスタ同士で行う
  3. Cレジスタを持たず、すべての値をスタックに積んで計算する
答えと解説を見る

正解：B. メモリを読み書きできるのはロード命令とストア命令だけで、演算はレジスタ同士で行う

ロード・ストア・アーキテクチャでは、メモリの値はまずロード命令でレジスタに読み込み、加算や比較などの演算はレジスタ同士で行い、結果が必要ならストア命令でメモリに書き戻します。演算命令がメモリを直接扱わないので、命令の形がそろい、パイプラインで処理しやすくなります。x86の「add eax, [mem]」のように演算命令がメモリを読める方式とは対照的です。

よくある質問

ロード・ストア・アーキテクチャとは何ですか?

メモリにアクセスする命令をロードとストアに限り、演算はすべてレジスタ同士で行う命令セットの方式です。RISC-VやARMが代表例で、命令の形がそろうためパイプラインで処理しやすくなります。

ロード・ストア・アーキテクチャとRISCは同じ意味ですか?

同じではありません。ロード・ストア型はメモリへのアクセスの仕方を表す言葉で、RISCは単純な命令や固定長の命令などを含む、より広い設計思想です。ただし、多くのRISCがロード・ストア型を採用しているため、両者はよく一緒に語られます。

x86はロード・ストア・アーキテクチャですか?

命令セットとしては違い、演算命令がメモリを直接読み書きできるレジスタ・メモリ型です。ただし現在のx86のCPUは、内部でこうした命令をロード、演算、ストアのマイクロオペレーションに分けて実行しています。
