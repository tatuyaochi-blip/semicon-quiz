ロード・ストア・アーキテクチャとは

ろーど・すとあ・あーきてくちゃ

メモリを読み書きする命令をロードとストアに限り、加算などの演算はレジスタ同士で行うISAの方式。RISC-VやARMが採用し、命令の形がそろってパイプラインで処理しやすい。

この用語の分野: 命令セット・アセンブリ

解説の中の「ロード・ストア・アーキテクチャ」

  • ロード・ストア・アーキテクチャでは、メモリの値はまずロード命令でレジスタに読み込み、加算や比較などの演算はレジスタ同士で行い、結果が必要ならストア命令でメモリに書き戻します。

    RISC-Vのようなロード・ストア・アーキテクチャの特徴として正しいものはどれか。
