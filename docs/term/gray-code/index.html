グレイコードとは

ぐれいこーど

隣り合う値の間で1ビットだけが変化する符号。ロータリーエンコーダや、異なるクロック間でのカウンタ値の受け渡しで、読み取りの誤りを防ぐのに使われる。

「グレイコード」は、3分野の11問の練習問題に出てきます(タイミング解析とCDC, 論理回路, SRAM・フラッシュメモリなど)。

この用語の分野: 論理回路

2進数とグレイコードの変換

一般的なグレイコードは反転2進符号(交番2進符号)と呼ばれるもので、nビットの並びを書き、その鏡像を後ろに付け加え、前半の先頭に0、後半の先頭に1を付けて作ります。2進数Bからの変換は G = B XOR (B >> 1) という1つの式で表せ、最上位以外のグレイビットは隣り合う2つの2進ビットのXORになります。逆変換は最上位から順にXORを累積していきます。最上位ビットはそのまま写し、下位の各2進ビットは1つ上の2進ビットと現在のグレイビットのXORです。3ビットの場合の並びは 000、001、011、010、110、111、101、100 です。

エンコーダで1ビット変化が重要な理由

通常の2進数では、0111から1000に進むとき4ビットが同時に反転します。ロータリー型やリニア型のアブソリュートエンコーダは各ビットを別々のトラックから読み取りますが、トラックごとの切り替わり位置は完全にはそろわないため、境界で読み取ると新旧のビットが混ざり、どちらの位置とも大きく異なる値を出してしまうことがあります。グレイコードなら1ステップごとに変化するトラックは1本だけなので、境界での読み取り値は旧い値か新しい値のどちらかになり、いずれも1ステップ以内の誤差で正しい値です。

非同期FIFOのグレイコードポインタ

非同期FIFOは2つのクロックドメインの間でデータを受け渡す回路で、フル・エンプティのフラグを求めるために、それぞれの側が相手側の読み出しポインタや書き込みポインタを参照する必要があります。2進数のポインタを同期化フリップフロップに通すと、複数のビットが同時に変化して別々のクロックエッジで取り込まれ、実際には存在しなかったポインタ値が生じる恐れがあるため危険です。グレイコードのポインタは1回の増加で1ビットしか変わらないので、そのビットが遷移の途中で取り込まれても、受け側には旧いポインタか新しいポインタのどちらかが届きます。ただし、これはポインタが1クロックに1ずつ進み、カウンタが2のべき乗で一巡する場合に限って成り立ちます。

フラッシュメモリとカルノー図での利用

MLC(マルチレベルセル)やTLC(トリプルレベルセル)のNANDフラッシュは、2ビットまたは3ビットを4つまたは8つのしきい値電圧状態のいずれかとして記憶します。劣化や干渉によって状態の分布が広がると、誤読はほとんどの場合、隣の状態との取り違えとして起こります。TLCで 111、110、100、101、001、000、010、011 のようにグレイコード順にビットパターンを割り当てておけば、こうした誤読は1ビットの誤りで済み、誤り訂正符号(ECC)で低コストに訂正できます。カルノー図も軸に同じ順序を使っており、隣り合うマスが1変数だけ異なるため、まとめてグループ化できます。

グレイコードの練習問題に挑戦

グレイコードの特徴として正しいものはどれか。

  1. A10進数の各桁を4ビットで表す符号
  2. Bパリティビットで誤りを検出する符号
  3. C隣り合う値の間で1ビットだけが変化する符号
答えと解説を見る

正解：C. 隣り合う値の間で1ビットだけが変化する符号

グレイコードは隣り合う値の間で必ず1ビットだけが変化する符号で、2進数Bから B XOR (B >> 1) で求められます。複数ビットが同時に変わらないため、ロータリーエンコーダの位置検出や、異なるクロックで動く回路の間でFIFOのポインタを受け渡すときに、途中の誤った値を読む危険がありません。カルノー図のマスの並びもグレイコード順です。10進の各桁を4ビットで表すのはBCDです。

非同期FIFOで、書き込みポインタと読み出しポインタをグレイコードに変換してから相手のドメインに同期化する理由として正しいものはどれか。

  1. Aグレイコードにするとビット数が半分になり、同期化回路が少なくて済むから
  2. B1つ進むごとに1ビットだけが変わるので、変化の途中で取り込んでも、進む前か後の正しい値になるから
  3. Cグレイコードの信号はメタステーブルにならないので、同期化が不要になるから
答えと解説を見る

正解：B. 1つ進むごとに1ビットだけが変わるので、変化の途中で取り込んでも、進む前か後の正しい値になるから

バイナリのポインタは、例えば 0111 から 1000 のように複数のビットが同時に変わるので、各ビットを別々に同期化すると、まったく関係のない値を受け取ることがあります。グレイコードなら1回の増加で変わるのは1ビットだけなので、そのビットがメタステーブルになって新旧どちらに決まっても、結果は進む前か進んだ後の値になります。少し古い値を見るだけなので、FIFOが壊れることはありません。ビット数は変わらず、メタステーブル自体も起こりうるので同期化回路は必要です。

よくある質問

2進数をグレイコードに変換する方法は?

2進数と、それを1ビット右にシフトした値とのXORをとります(G = B XOR (B >> 1))。最上位ビットはそのままで、それ以外の各グレイビットは隣り合う2つの2進ビットのXORになります。

クロックドメインをまたぐFIFOのポインタにグレイコードを使うのはなぜですか?

グレイコードのポインタは1回の増加で1ビットしか変わらないため、同期化回路が遷移の途中でサンプリングしても、得られるのは旧い値か新しい値のどちらかです。2進数のポインタは多くのビットが一度に変わることがあり、まったく誤った値として取り込まれる可能性があります。

グレイコードとBCDの違いは?

グレイコードは、連続する値どうしが1ビットだけ異なるように2進パターンを並べた符号です。BCD(2進化10進数)は10進数の各桁を4ビットで個別に表す符号で、1ビットだけ変化するという性質はありません。

「グレイコード」が出てくる問題(11問)

  1. グレイコードの特徴として正しいものはどれか。
  2. 非同期FIFOで、書き込みポインタと読み出しポインタをグレイコードに変換してから相手のドメインに同期化する理由として正しいものはどれか。
  3. 4ビットのバイナリ 0110(10進数の6)をグレイコードに変換したものはどれか。
  4. 5ビットのグレイコードのポインタを使う深さ16語の非同期FIFOで、書き込み側で満杯(full)を判定する条件として正しいものはどれか。
  5. 非同期FIFOのグレイコードのポインタを相手のドメインに渡す経路を、非同期だからといって制約なし(フォールスパス)にすると問題になりうる理由として正しいものはどれか。
  6. カルノー図の主な用途はどれか。
  7. 多値(MLCやTLC)のNANDフラッシュで、隣り合うしきい値電圧の状態に割り当てるビットの並びを、1ビットだけ異なるようにする理由として正しいものはどれか。
  8. 4ビットのデータの各ビットに、それぞれ2段の同期化回路を付けて別のクロックドメインに渡した。データが 0111 から 1000 に変わるときに起こりうる問題として正しいものはどれか。
  9. 深さ16語の非同期FIFOで、書き込みポインタと読み出しポインタをアドレスより1ビット多い5ビットにする理由として正しいものはどれか。
  10. 書き込み側 250 MHz、読み出し側 200 MHz で、どちらも毎サイクル1語ずつ転送する。64語のバーストを受けるFIFOに計算上必要な最小の深さはいくらか(同期化による遅れは無視し、端数は切り上げる)。
  11. 同じ送り側のドメインから来た2本の制御信号を、それぞれ別の2段同期化回路で受け、受け側でANDをとって使う設計の問題点として正しいものはどれか。
