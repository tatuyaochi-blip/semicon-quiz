グレイコードとは

ぐれいこーど

隣り合う値の間で1ビットだけが変化する符号。ロータリーエンコーダや、異なるクロック間でのカウンタ値の受け渡しで、読み取りの誤りを防ぐのに使われる。

「グレイコード」は、2分野の3問の練習問題に出てきます(論理回路, SRAM・フラッシュメモリなど)。

この用語の分野: 論理回路

グレイコードの練習問題に挑戦

グレイコードの特徴として正しいものはどれか。

  1. A10進数の各桁を4ビットで表す符号
  2. Bパリティビットで誤りを検出する符号
  3. C隣り合う値の間で1ビットだけが変化する符号
答えと解説を見る

正解：C. 隣り合う値の間で1ビットだけが変化する符号

グレイコードは隣り合う値の間で必ず1ビットだけが変化する符号で、2進数Bから B XOR (B >> 1) で求められます。複数ビットが同時に変わらないため、ロータリーエンコーダの位置検出や、異なるクロックで動く回路の間でFIFOのポインタを受け渡すときに、途中の誤った値を読む危険がありません。カルノー図のマスの並びもグレイコード順です。10進の各桁を4ビットで表すのはBCDです。

解説の中の「グレイコード」

  • グレイコードは隣り合う値の間で必ず1ビットだけが変化する符号で、2進数Bから B XOR (B >> 1) で求められます。

    グレイコードの特徴として正しいものはどれか。

  • カルノー図は、真理値表を隣り合うマスの入力が1ビットだけ異なる(グレイコード順)ように並べた図です。

    カルノー図の主な用途はどれか。

  • 誤読はほぼ必ず隣の状態との間で起こるため、隣り合う状態のビット列が1ビットだけ異なるグレイコードで割り当てておけば、誤読しても誤りは1ビットだけになり、ECCの負担を最小にできます。

    多値(MLCやTLC)のNANDフラッシュで、隣り合うしきい値電圧の状態に割り当てるビットの並びを、1ビットだけ異なる…

「グレイコード」が出てくる問題(3問)

  1. グレイコードの特徴として正しいものはどれか。
  2. カルノー図の主な用途はどれか。
  3. 多値(MLCやTLC)のNANDフラッシュで、隣り合うしきい値電圧の状態に割り当てるビットの並びを、1ビットだけ異なるようにする理由として正しいものはどれか。
