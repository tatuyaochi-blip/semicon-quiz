インゴットとは

いんごっと

CZ法などで育成した、ウエハに切り出す前の円柱状の単結晶の塊。両端を切り落とし、外周を研削して直径をそろえてから薄くスライスする。

「インゴット」は、1分野の11問の練習問題に出てきます(シリコンウエハなど)。

この用語の分野: シリコンウエハ

インゴットの育成方法

チョクラルスキー(CZ)法では、高純度の多結晶シリコンを石英るつぼに入れ、シリコンの融点である約1414 ℃をわずかに上回る温度で溶かします。種結晶を融液に浸し、種結晶とるつぼを互いに逆方向へ回転させながらゆっくり引き上げます。回転によって軸まわりの温度が均一になり、円柱状の結晶が得られます。まず細いネック部で転位を結晶外へ逃がし、続いてショルダー(クラウン)部で直径を広げ、直径一定の直胴部へ移ります。結晶と融液の境界に見える明るいメニスカスリングをカメラで追跡し、引き上げ速度とヒーター出力を調整して直径を一定に保ちます。

ドーピングとインゴット内の偏析

ドーパントは融液に添加し、p型にはボロン、n型にはリン、ヒ素、アンチモンを使います。多くのドーパントは偏析係数kが1未満で、成長する結晶には融液中より少ない不純物しか取り込まれません。取り込まれなかったドーパントは減っていく融液中に濃縮されるため、後から成長した部分ほど高濃度にドープされ、抵抗率が低くなります。偏析係数はリンが約0.35、ヒ素が約0.3、アンチモンが約0.023です。ボロンは約0.8と大きいため、p型インゴットは比較的均一になります。製品になるのは、抵抗率が仕様範囲内に収まる部分だけです。

クラウン・テールの処理と欠陥制御

使われるのは直径一定の直胴部だけで、クラウン部とテール部は切り落とされます。テール部は、結晶が融液から離れる前に意図的に円錐状に細くします。全直径のまま急に切り離すと熱衝撃でスリップ転位が発生し、直胴部へおよそ直径1つ分ほど伝播することがあるためです。引き上げ速度は結晶品質にも影響します。成長速度と温度勾配の比(V/G)によって空孔型と格子間型のどちらの点欠陥が支配的になるかが決まるため、直径制御のためにこの条件を損なってはいけません。また石英るつぼから溶け出した酸素も結晶に取り込まれ、インゴットの長さ方向に沿って測定されます。

インゴットからウエハへ

インゴットは両端を切断して外周を正確な直径に研削し、結晶方位を示すノッチ(古いサイズではオリエンテーションフラット)を付けます。次に、太さ約0.1 mmのワイヤを数百本平行に張ったマルチワイヤソーで、数時間かかる1回の加工により厚さ1 mm弱のウエハを数百枚切り出します。ウエハは面取り、平坦化のためのラッピングまたは研削、切断ダメージ層を除去するエッチング、鏡面研磨を経て、洗浄・検査されます。なお、るつぼを使わないFZ(フローティングゾーン)法では酸素が非常に少ないインゴットが得られ、高抵抗率の用途や一部のパワーデバイスに好まれます。

インゴットの練習問題に挑戦

単結晶インゴットからウエハをつくる工程の順序として最も適切なものはどれか。

  1. Aスライス → ラッピング(研削) → エッチング → 鏡面研磨
  2. B鏡面研磨 → スライス → エッチング → ラッピング
  3. Cエッチング → 鏡面研磨 → スライス → ラッピング
答えと解説を見る

正解：A. スライス → ラッピング(研削) → エッチング → 鏡面研磨

インゴットの外周を研削して直径をそろえ、ノッチを加工したあと、マルチワイヤーソーで1 mm弱の厚さに切り出します(スライス)。面取りののち、ラッピングや研削で厚さと平坦度を整え、加工で生じた数十µmのダメージ層をエッチングで除去し、最後に両面研磨と仕上げ研磨で原子レベルに近い鏡面に仕上げます。その後、洗浄と検査を経てクリーンな出荷用容器(FOSB)で出荷されます。

シリコンのインゴットを、一度に多数のウエハにスライスするために一般的に使われる装置はどれか。

  1. Aダイシングブレード
  2. Bマルチワイヤーソー
  3. CCMP装置
答えと解説を見る

正解：B. マルチワイヤーソー

マルチワイヤーソーは、直径0.1 mm前後の細いワイヤーを数百本平行に張って高速で走らせ、砥粒の入った液やダイヤモンドを固定したワイヤーで、インゴットを一度に数百枚のウエハに切断する装置です。切りしろが0.1 mm台と小さく、材料の無駄を減らせます。1本のインゴットを切るのに数時間かかります。ダイシングブレードは、完成したウエハをチップに切り分けるのに使います。

よくある質問

シリコンウエハが丸いのはなぜですか?

CZ法の結晶は回転させながら引き上げるため円柱状に成長し、それをスライスすると丸いウエハになるからです。また円形の基板は、スピンコートや研磨など回転を利用する工程にも適しています。

シリコンインゴットはどのようにウエハに切断されますか?

所定の直径に研削したあと、砥粒を含むスラリーや固定ダイヤモンド砥粒を用いた細いワイヤで数百枚を同時に切断するマルチワイヤソーでスライスします。その後、ラッピング、エッチング、研磨で切断ダメージを除去します。

インゴットの上部と下部で抵抗率が変わるのはなぜですか?

結晶成長に伴って多くのドーパントが融液側に偏析し、融液中のドーパント濃度が時間とともに高まるため、インゴットの下部ほど高濃度にドープされるからです。偏析係数が1に近いボロンでは、この効果が最も小さくなります。
