フォールトトレランスとは

ふぉーるととれらんす

部品や装置の故障は起こるものとして、多重化などによって、一部が故障してもシステム全体としては正しく動作を続けられるようにする考え方。故障そのものを起こりにくくするフォールトアボイダンスと対比される。

「フォールトトレランス」は、1分野の2問の練習問題に出てきます(システム構成と信頼性設計など)。

この用語の分野: システム構成と信頼性設計

フォールトトレランスの練習問題に挑戦

フールプルーフの考え方に基づく設計の例として、適切なものはどれか。

  1. A重要なデータを、2台のディスクに同時に書き込む
  2. B部品の点検や交換を定期的に行い、故障の発生を減らす
  3. Cコネクタの形を左右非対称にして、逆向きには差し込めないようにする
答えと解説を見る

正解：C. コネクタの形を左右非対称にして、逆向きには差し込めないようにする

フールプルーフは、人が誤った操作をしても危険な状態や誤動作にならないように、あるいはそもそも誤った操作ができないようにする設計の考え方です。逆向きに差し込めない形のコネクタは、誤った接続を物理的に防ぐ代表的な例です。データを2台のディスクに書き込むのは冗長化によるフォールトトレランス、定期的な点検や交換で故障を減らすのはフォールトアボイダンスの考え方です。

システムの信頼性を高める考え方のうち、フォールトアボイダンスに当たるものはどれか。

  1. A信頼性の高い部品を選び、出荷前のスクリーニング(バーンインなど)で初期故障を起こしやすいものを取り除いて、故障そのものが起きにくいようにする
  2. B装置を多重化し、一部が故障してもシステム全体としては機能を保てるようにする
  3. C故障が起きたときに、システムが安全な側の状態になるようにする
答えと解説を見る

正解：A. 信頼性の高い部品を選び、出荷前のスクリーニング(バーンインなど)で初期故障を起こしやすいものを取り除いて、故障そのものが起きにくいようにする

フォールトアボイダンスは、品質の高い部品の使用、十分な試験やスクリーニング、予防保守などで、故障そのものが起きにくいようにする考え方です。バーンインなどのスクリーニングは、バスタブ曲線の初期故障期間にあたる故障を出荷前に取り除くために行います。これに対し、故障は起きるものとして、多重化などで故障しても機能を保てるようにするのがフォールトトレランスです。故障時に安全な側の状態にするのは、フェールセーフの考え方です。

解説の中の「フォールトトレランス」

  • データを2台のディスクに書き込むのは冗長化によるフォールトトレランス、定期的な点検や交換で故障を減らすのはフォールトアボイダンスの考え方です。
