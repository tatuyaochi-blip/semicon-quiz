偽共有とは

にせきょうゆう

別々のスレッドが別々の変数を書き換えているのに、それらが同じキャッシュラインにあるため、ラインがコア間を行き来して遅くなる現象。フォールスシェアリング。

この用語の分野: マルチコアと同期

解説の中の「偽共有」

  • 結果は正しいのに、性能が大きく落ちるのが偽共有です。

    マルチスレッドのプログラムで起こる偽共有(フォールスシェアリング)の説明として正しいものはどれか。

  • マルチスレッドのプログラムでは、別々の変数が同じラインにあると取り合いが起きる「偽共有」に注意が必要です。

    現在の多くのCPUで使われているキャッシュライン(キャッシュブロック)の大きさとして一般的なものはどれか。

  • 並列化の効果を妨げる主な原因には、並列にできない部分(アムダールの法則)、ロックやバリアによる待ち、共有データや偽共有によるキャッシュラインの行き来、仕事の偏り、メモリ帯域の不足などがあります。

    並列プログラムで、コアの数を増やしても性能が思うように伸びない原因として当てはまらないものはどれか。

「偽共有」が出てくる問題(4問)

  1. マルチスレッドのプログラムで起こる偽共有(フォールスシェアリング)の説明として正しいものはどれか。
  2. スレッドごとのカウンタを「long cnt[8];」のように並べた配列で偽共有が起きている。対策として最も適切なものはどれか。
  3. 現在の多くのCPUで使われているキャッシュライン(キャッシュブロック)の大きさとして一般的なものはどれか。
  4. 並列プログラムで、コアの数を増やしても性能が思うように伸びない原因として当てはまらないものはどれか。
