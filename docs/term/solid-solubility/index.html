固溶度とは

こようど

ある温度で、結晶の中に溶け込める不純物の最大の濃度。電気的に活性化できるドーパントの濃度の上限を決める。

この用語の分野: イオン注入

解説の中の「固溶度」

  • ただし、不純物の固溶度を超えると活性化しきれない不純物が増えるため、ドーズ量を増やしてもシート抵抗が下がりにくくなります。

    同じアニール条件で、イオン注入のドーズ量を増やすと注入層のシート抵抗は一般にどうなるか。

  • 結晶中に溶け込める不純物の最大濃度を固溶度といいます。

    アニールでドーパントを活性化させるとき、電気的に活性化できる濃度の上限を決める性質はどれか。

「固溶度」が出てくる問題(2問)

  1. 同じアニール条件で、イオン注入のドーズ量を増やすと注入層のシート抵抗は一般にどうなるか。
  2. アニールでドーパントを活性化させるとき、電気的に活性化できる濃度の上限を決める性質はどれか。
