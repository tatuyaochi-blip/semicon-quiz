固溶度とは

こようど

ある温度で、結晶の中に溶け込める不純物の最大の濃度。電気的に活性化できるドーパントの濃度の上限を決める。

「固溶度」は、2分野の6問の練習問題に出てきます(イオン注入, 酸化・拡散など)。

この用語の分野: イオン注入

固溶度の練習問題に挑戦

シリコン中の熱処理での拡散が比較的遅く、浅い接合をつくりやすいn型不純物はどれか。

  1. Aホウ素(B)
  2. Bリン(P)
  3. Cヒ素(As)
答えと解説を見る

正解：C. ヒ素(As)

n型不純物のうちヒ素は、リンより原子が大きく拡散係数が小さく、質量も75とリン(31)の2倍以上あるためイオン注入でも浅く入ります。また固溶度が高く高濃度にできるため、浅く急峻で低抵抗な接合が求められるnMOSのソース・ドレインやエクステンションに使われてきました。リンは拡散が速いため、深いウェルや、最近はエピタキシャルのSiPとして使われます。ホウ素はp型です。

SiO2膜が、ボロンやリンの拡散のマスクには使えるが、ガリウムやアルミニウムに対してはマスクとして働きにくい理由として正しいものはどれか。

  1. ASiO2がガリウムやアルミニウムと反応して導体になるため
  2. BガリウムやアルミニウムはSiO2中の拡散が非常に速いため
  3. Cガリウムやアルミニウムはシリコン中で電気的に不活性なため
答えと解説を見る

正解：B. ガリウムやアルミニウムはSiO2中の拡散が非常に速いため

ボロンやリンはSiO2の中での拡散がシリコン中よりずっと遅いため、酸化膜でさえぎることができます。一方、ガリウムやアルミニウムはSiO2の中を速く拡散してしまうため、酸化膜をマスクにした選択的な拡散には向きません。アルミニウムは固溶度も低く深い位置まで拡散が速いため、パワーデバイスの深い接合に使われることがあります。シリコンのp型不純物として主にボロンが使われる理由の一つです。

解説の中の「固溶度」

  • また固溶度が高く高濃度にできるため、浅く急峻で低抵抗な接合が求められるnMOSのソース・ドレインやエクステンションに使われてきました。

    シリコン中の熱処理での拡散が比較的遅く、浅い接合をつくりやすいn型不純物はどれか。

  • アルミニウムは固溶度も低く深い位置まで拡散が速いため、パワーデバイスの深い接合に使われることがあります。

    SiO2膜が、ボロンやリンの拡散のマスクには使えるが、ガリウムやアルミニウムに対してはマスクとして働きにくい理由として…

  • ただし不純物の固溶度を超えると活性化しきれない不純物が増え、移動度も下がるため、ドーズ量を増やしてもシート抵抗は下がりにくくなります。

    同じアニール条件で、イオン注入のドーズ量を増やすと注入層のシート抵抗は一般にどうなるか。

  • 結晶中に熱平衡で溶け込める不純物の最大濃度を固溶度といい、シリコン中ではボロンが約2×10²⁰ cm⁻³(1000 ℃付近)、ヒ素やリンは10²¹ cm⁻³前後です。

    アニールでドーパントを活性化させるとき、電気的に活性化できる濃度の上限を決める性質はどれか。

  • ソース・ドレインのような高濃度の領域はこの程度の濃度で、固溶度に近いため、活性化をいかに高めるかが低抵抗化の鍵になります。

「固溶度」が出てくる問題(6問)

  1. シリコン中の熱処理での拡散が比較的遅く、浅い接合をつくりやすいn型不純物はどれか。
  2. SiO2膜が、ボロンやリンの拡散のマスクには使えるが、ガリウムやアルミニウムに対してはマスクとして働きにくい理由として正しいものはどれか。
  3. 同じアニール条件で、イオン注入のドーズ量を増やすと注入層のシート抵抗は一般にどうなるか。
  4. アニールでドーパントを活性化させるとき、電気的に活性化できる濃度の上限を決める性質はどれか。
  5. ドーズ量1×10¹⁵ cm⁻²の不純物が、深さ100 nmの範囲に均一に分布しているとすると、平均の濃度はおよそいくらか。
  6. nMOSのチャネルに急峻なレトログレード分布をつくるために、ボロンより重いp型不純物として検討・使用されてきた元素はどれか。
