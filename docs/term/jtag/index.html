JTAGとは

じぇいたぐ

チップのテストやデバッグのための標準のインターフェース。プログラムを止めて中の値を見たり、フラッシュを書き換えたりできる。Armではより線の少ないSWDも使われる。

「JTAG」は、3分野の3問の練習問題に出てきます(テスト・検査, 組込み・ファームウェア, ハードウェアセキュリティなど)。

この用語の分野: 組込み・ファームウェア

本来の目的はバウンダリスキャン

JTAGという名前はJoint Test Action Groupに由来し、規格はIEEE 1149.1です。もともとは組み立て済みのボードをテストするためのものでした。各I/O端子のすぐ内側にバウンダリスキャンセルを置き、それらをつないでシフトレジスタを構成します。テスト装置はTAP(テストアクセスポート)を通じてパターンをシフト入力し、あるチップの端子から出力して別のチップの端子で取り込みます。これにより、プローブが当てられないBGAパッケージの下でも、はんだのオープンやショートを見つけられます。

TAPの信号とステートマシン

TAPはTDI(テストデータ入力)、TDO(テストデータ出力)、TCK(テストクロック)、TMS(テストモード選択)の4本の信号に加え、オプションのリセット信号TRSTを使います。TCKのエッジで取り込まれるTMSが16状態のコントローラを遷移させ、TDIとTDOの間でシフトされるビットを命令レジスタに入れるか、選択したデータレジスタに入れるかを決めます。各チップのTDOを次のチップのTDIにつなぐデイジーチェーン接続により、1つのコネクタからボード上のすべてのデバイスにアクセスできます。

デバッグとフラッシュ書き込み、JTAGとSWDの違い

チップベンダは同じポートを、チップ内蔵のデバッグ回路へのアクセスにも使っています。PC上のデバッガからコアの停止、ブレークポイントの設定、ステップ実行、レジスタやメモリの読み書き、フラッシュの書き込みができ、printfが使えない状況でも内部の状態を確認できます。ArmのSWD(シリアルワイヤデバッグ)はSWDIOとSWCLKの2本だけで同様のデバッグアクセスを実現し、小型マイコンの端子を節約できますが、デバッグ用のプロトコルなのでバウンダリスキャンはできません。多くのArmデバイスは、共用の端子で両方に対応しています。

製品ではポートをロックする

開発者に役立つアクセス手段は、攻撃者にとっても役立ちます。デバッグポートが開いていると、プローブを持っている人なら誰でもファームウェアを読み出したり、鍵を抜き出したり、セキュアブートを回避したりできてしまいます。そのため出荷製品では、eFuseを切ってポートを恒久的に無効にする、読み出し保護をかける、あるいは暗号学的なチャレンジ・レスポンス認証の後にだけ開く、といった対策をとります。最後の方法なら、市場から返却された故障品を正規の技術者が解析することもできます。

JTAGの練習問題に挑戦

IEEE 1149.1(JTAG)で規定されたバウンダリスキャンの主な用途はどれか。

  1. Aウエハ上の膜厚の測定
  2. B配線のエレクトロマイグレーション評価
  3. Cプリント基板に実装したLSIの端子どうしの接続などを、プローブを当てずにテストする
答えと解説を見る

正解：C. プリント基板に実装したLSIの端子どうしの接続などを、プローブを当てずにテストする

バウンダリスキャンでは、LSIの各端子の内側にスキャン用のセルを設け、それらをシリアルにつないで、TDI・TDO・TCK・TMSの4本(とリセット)の信号で外部から値を設定・観測します。端子にプローブを当てられないBGAなどでも、基板上のはんだ接続の断線や短絡を検査できます。この端子はデバッグやフラッシュメモリの書き込みにも広く使われます。

JTAGやSWDといったデバッグ用のインターフェースでできることとして正しいものはどれか。

  1. A実際の基板の上でプログラムを止めたり1行ずつ進めたりして、レジスタや変数の値を見たり、フラッシュを書き換えたりする
  2. Bマイコンの製造工程を変更する
  3. Cプログラムを別の言語に自動で翻訳する
答えと解説を見る

正解：A. 実際の基板の上でプログラムを止めたり1行ずつ進めたりして、レジスタや変数の値を見たり、フラッシュを書き換えたりする

JTAGやArmのSWDは、マイコンの中のデバッグ回路とパソコンのデバッガを結ぶインターフェースです。ブレークポイントで止めて変数やレジスタを調べたり、1命令ずつ実行したり、フラッシュにプログラムを書き込んだりできます。printfを使えない場面でも中の様子が分かります。製品として出荷するときは、第三者に読み出されないように、デバッグの機能を無効にすることもあります。

よくある質問

JTAGの端子(ピン)にはどんなものがありますか?

TDI、TDO、TCK、TMSの4本と、オプションのリセット信号TRSTです。デバッグコネクタにはこれらに加えてグラウンドと、通常は基準電圧の端子もあります。

JTAGとSWDの違いは何ですか?

SWDはArmの2線式デバッグインターフェースで、少ない端子数で停止、ステップ実行、メモリアクセスといった同様の機能を提供します。JTAGは4本または5本の信号を使い、バウンダリスキャンによるボードテストや複数チップのデイジーチェーン接続にも対応します。

量産品でJTAGを無効にするのはなぜですか?

JTAGではメモリの読み書きやプロセッサの停止ができるため、ポートが開いていると攻撃者がファームウェアや鍵を抜き出したり、セキュアブートを回避したりできるからです。製品ではヒューズで無効にするか、ロック解除に認証を必要とします。

解説の中の「JTAG」
