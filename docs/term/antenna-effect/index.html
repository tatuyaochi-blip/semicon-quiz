アンテナ効果とは

あんてなこうか

プラズマ工程中に、長い配線などの導体がアンテナのように電荷を集め、つながっているゲート酸化膜を損傷させる現象。設計ルールで配線の面積比を制限して防ぐ。

この用語の分野: エッチング
