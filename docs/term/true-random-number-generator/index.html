真性乱数生成器とは

しんせいらんすうせいせいき

熱雑音や発振器のゆらぎなど、予測できない物理現象をもとに乱数を作る回路。TRNG。暗号の鍵の生成の元になる。

「真性乱数生成器」は、1分野の1問の練習問題に出てきます(ハードウェアセキュリティなど)。

この用語の分野: ハードウェアセキュリティ

擬似乱数との違い

コンピュータで普通に使う擬似乱数生成器は、種(シード)と呼ぶ初期値から決まった計算で数列を作るため、種が同じなら同じ数列が出てきます。暗号の鍵やノンスに使う乱数は、攻撃者に推測されないことが最も重要で、種そのものを予測できない値にする必要があります。真性乱数生成器(TRNG)は、熱雑音や発振器の周期のゆらぎなど、物理的に予測できない現象から乱数のビットを作る回路で、その予測できなさの源になります。チップに組み込んだものはハードウェアTRNGと呼ばれ、多くのマイコンやSoC、セキュリティチップが搭載しています。

エントロピー源の例

予測できなさの源をエントロピー源と呼びます。チップに組み込む方式でよく使われるのは、自走するリング発振器の出力を別のクロックでサンプリングし、周期のわずかなゆらぎ(ジッタ)の積み重なりからビットを取り出す方式です。ほかに、抵抗の熱雑音を増幅して比較器で0と1にする方式や、ラッチを不安定な状態から解放してどちらに落ち着くかを使う方式などがあります。単体の部品では、ダイオードの降伏による雑音や、光子の検出のような量子的な現象を使う乱数源もあります。どの方式でも、得られるビットの予測できなさの量を見積もることが設計の要になります。

後処理と健全性テスト

物理現象から取り出したままのビットは、0と1の割合が偏っていたり、前後のビットに相関があったりします。そこで、ハッシュ関数などで多くのビットを圧縮して、1ビットあたりの予測できなさを高める処理(コンディショニング)を行います。実際の製品では、こうして得た値を暗号用の決定的乱数生成器(DRBG)の種にして、速く大量の乱数を作るのが一般的です。さらに、同じ値が続きすぎないか、特定の値の割合が多すぎないかを常に調べる健全性テストを組み込み、雑音源が壊れたら出力を止めます。米国NISTのSP 800-90シリーズやドイツ連邦情報セキュリティ庁のAIS 31が、評価の考え方を定めています。

攻撃と設計上の注意

TRNGの出力の性質は、温度や電源電圧、製造のばらつき、経年劣化で変わります。攻撃者が電源に雑音を加えたり、外から電磁波を当ててリング発振器の周波数を引き込んだりすると、ゆらぎが減って出力が予測しやすくなるおそれがあります。後処理で見かけ上ランダムな出力になっていても、もとのエントロピーが足りなければ安全ではありません。そのため、最悪の条件でのエントロピーの見積もり、起動時と動作中の健全性テスト、異常時に出力を止める仕組みを組み合わせて設計します。統計的な乱数検定に合格することは必要ですが、それだけでは予測できないことの証明になりません。

真性乱数生成器の練習問題に挑戦

チップに内蔵される真性乱数生成器(TRNG)の説明として正しいものはどれか。

  1. A決まった計算式で、種(シード)から乱数の並びを作るプログラム
  2. B熱雑音や発振器のゆらぎなど、予測できない物理現象をもとに乱数を作る回路
  3. C時計の時刻をそのまま乱数として使う回路
答えと解説を見る

正解：B. 熱雑音や発振器のゆらぎなど、予測できない物理現象をもとに乱数を作る回路

擬似乱数は、種が分かれば同じ並びを作り直せるので、種を推測されると鍵も推測されてしまいます。真性乱数生成器は、抵抗の熱雑音やリング発振器の周期のゆらぎのような予測できない物理現象をもとにビットを作ります。実際には、TRNGの出力で暗号用の擬似乱数生成器の種を作り、速さと予測できなさを両立させることが多いです。

よくある質問

TRNGとは何の略ですか?

True Random Number Generatorの略で、真性乱数生成器と訳します。熱雑音や発振器のゆらぎなどの物理現象をもとに乱数を作る回路で、暗号の鍵や、擬似乱数生成器の種の生成に使われます。

TRNGの出力をそのまま鍵に使わないのはなぜですか?

生のビットには偏りや相関があり、1ビットあたりの予測できなさが1ビットに満たないことが多いからです。そのため後処理で圧縮し、さらに暗号用の決定的乱数生成器(DRBG)の種にして使うのが一般的です。DRBGを通すと、速く大量の乱数を作れます。

CPUにもTRNGは入っていますか?

多くのCPUやSoCに入っています。例えばx86のCPUには、ハードウェアの乱数を読み出すRDRAND命令と、種に使う値を読み出すRDSEED命令があり、Armv8.5-AではRNDR命令などが追加されました。OSはこうした乱数源をほかの情報源と合わせて、乱数の種に使います。
