真性乱数生成器とは

しんせいらんすうせいせいき

熱雑音や発振器のゆらぎなど、予測できない物理現象をもとに乱数を作る回路。TRNG。暗号の鍵の生成の元になる。

この用語の分野: ハードウェアセキュリティ

解説の中の「真性乱数生成器」

  • 真性乱数生成器は、抵抗の熱雑音やリング発振器の周期のゆらぎのような予測できない物理現象をもとにビットを作ります。
