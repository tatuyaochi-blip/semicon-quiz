移動平均フィルタとは

いどうへいきんふぃるた

直近 N 個のサンプルの平均を出力する、最も簡単なローパスフィルタ。y[n] = (x[n] + x[n − 1] + … + x[n − N + 1])/N で、係数がすべて 1/N のFIRフィルタである。直流の利得は1で、周波数 fs/N の整数倍で利得が0になるので、例えば電源の周期にちょうど合わせた区間で平均すると、電源の周波数とその高調波の雑音を取り除ける。係数が対称なので直線位相で、遅れは (N − 1)/2 サンプルである。新しいサンプルを足して最も古いサンプルを引くことで和を更新すれば、N によらず少ない演算で計算できる。

移動平均フィルタの練習問題に挑戦

サンプリング周波数8 kHzで、直近8サンプルの平均をとる移動平均フィルタ y[n] = (x[n] + x[n − 1] + … + x[n − 7])/8 を使う。出力が0になる最も低い周波数として正しいものはどれか。

  1. A500 Hz
  2. B1 kHz
  3. C4 kHz
答えと解説を見る

正解：B. 1 kHz

Nサンプルの移動平均の利得は、直流で (1 + 1 + … + 1)/N = 1 で、周波数 fs/N の整数倍(直流を除く)で0になります。fs/N = 8000 ÷ 8 = 1 kHz の正弦波は8サンプルでちょうど1周期なので、その平均は0になります。移動平均は計算が簡単なローパスフィルタですが、零点の間で利得が持ち上がるサイドローブがあり、遮断の特性はあまり急峻ではありません。
