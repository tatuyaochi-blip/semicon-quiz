EFEMとは

いーふぇむ

Equipment Front End Module の略。製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニット。ロードポートや搬送ロボットを含む。

「EFEM」は、1分野の4問の練習問題に出てきます(クリーンルーム・製造装置など)。

この用語の分野: クリーンルーム・製造装置

EFEMの構成

EFEM(Equipment Front End Module)は、プロセス装置や計測装置の前面にある密閉された部分です。FOUP(Front-Opening Unified Pod)をドッキングするロードポート、FOUPのふたのロックを外して取り外す機構、大気中でウエハを搬送するロボット、そして通常は処理前にウエハのノッチ位置を検出するアライナーを備えています。センサーでFOUPのどのスロットにウエハがあるかをマッピングします。上部のファンフィルターユニット(FFU)がHEPAまたはULPAフィルターでろ過した空気を下向きに吹き出し、内部をわずかな陽圧に保つことで、室内の空気が入り込まないようにしています。

ミニエンバイロメント方式での役割

最近の工場では、クリーンルーム全体を最高の清浄度に保つのではなく、ウエハを小さな清浄空間に隔離しています。搬送中と保管中は密閉されたFOUP、装置への移載中はEFEMがその空間です。ウエハは室内の空気に一度も触れずにFOUPから装置へ移るため、周囲のクリーンルームはより緩いクラスに抑えられ、コストを下げられます。200 mmの時代にはSMIFポッドがこの役割を担い、カセットを装置内に降ろしていました。300 mmのFOUPは前面が開き、EFEMのロードポートに直接ドッキングします。

プロセス装置とのインターフェース

EFEMは大気圧で動作します。エッチング装置やCVD装置などの真空装置では、EFEMのロボットがウエハをロードロックに置き、ロードロックを真空に引いてから真空ロボットがウエハを処理チャンバへ運びます。処理済みのウエハは同じ経路で戻ります。天井搬送(OHT)の搬送車がFOUPをロードポートへ自動で届けます。ロードポートの寸法と受け渡しの信号はSEMI規格に従っているため、異なるメーカーのFOUPや搬送システムを多くの装置で使えます。

ウエハを化学的に清浄に保つ

問題はパーティクルだけではありません。水分や酸素は露出したシリコンや金属に自然酸化膜を成長させることがあり、処理直後のウエハからの脱ガスは同じFOUP内のほかのウエハを汚染することがあります。そのため一部のEFEMでは、ろ過した空気ではなく窒素で満たした筐体を使い、ロードポートでFOUP内を窒素でパージできるようにして、工程間での酸化や相互汚染を抑えています。

EFEMの練習問題に挑戦

製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。

  1. AOHT
  2. BULPAフィルタ
  3. CEFEM(ロードポートや搬送ロボットを含む装置前面のモジュール)
答えと解説を見る

正解：C. EFEM(ロードポートや搬送ロボットを含む装置前面のモジュール)

EFEM(Equipment Front End Module)は、FOUPを置くロードポート、ふたを開ける機構、ウエハを取り出して装置内へ運ぶロボットなどを、FFUで清浄に保った空間に収めたモジュールです。ウエハを外気にさらさずに装置とFOUPの間でやり取りでき、ミニエンバイロメントの要になっています。OHTは装置間の搬送、ULPAフィルタは空気の清浄化を担います。

天井にフィルタとファンを一体化して並べ、清浄な空気を送り出す装置はどれか。

  1. AFFU(ファンフィルタユニット)
  2. BEFEM
  3. COHT
答えと解説を見る

正解：A. FFU(ファンフィルタユニット)

FFUは、送風ファンとHEPA/ULPAフィルタを一体化したユニットで、クリーンルームの天井に多数並べて、清浄な空気を下向きに吹き出します。ユニットごとに風量を調整でき、レイアウトの変更や部分的な清浄度の変更にも対応しやすいため、大きなダクトで空気を送る方式に代わって広く使われています。EFEMは装置前面のモジュール、OHTは天井の搬送車です。

よくある質問

EFEMとは何の略ですか?

EFEMはEquipment Front End Moduleの略です。半導体装置の前面にあり、FOUPを開けて清浄な環境のままウエハを装置内に移載する部分を指します。

EFEMとロードロックの違いは?

EFEMはロードポートとロボットを備えた、ろ過した空気で満たされた大気圧の筐体で、FOUPからウエハを取り出します。ロードロックは大気圧と真空を切り替える小さなチャンバで、ウエハをEFEMから真空のプロセス装置へ受け渡すために使います。

EFEMとFFUの違いは?

FFUは清浄な空気を供給するファンとフィルターのユニットで、クリーンルームの天井やEFEMの上部に使われます。EFEMはウエハ搬送のモジュール全体のことで、内部を清浄に保つためにFFUを備えています。
