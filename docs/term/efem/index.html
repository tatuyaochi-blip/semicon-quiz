EFEMとは

いーふぇむ

Equipment Front End Module の略。製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニット。ロードポートや搬送ロボットを含む。

この用語の分野: クリーンルーム・製造装置

解説の中の「EFEM」

  • EFEM(Equipment Front End Module)は、FOUPを置くロードポート、ふたを開ける機構、ウエハを取り出して装置内へ運ぶロボットなどを、FFUで清浄に保った空間に収めたモジュールです。

    製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。

  • EFEMは装置前面のモジュール、OHTは天井の搬送車です。

    天井にフィルタとファンを一体化して並べ、清浄な空気を送り出す装置はどれか。

  • EFEMはFOUPを受け渡す装置前面のモジュールです。

    200 mmウエハの時代に普及した、カセットを密閉したポッドに入れて装置に受け渡すミニエンバイロメントの方式はどれか。

「EFEM」が出てくる問題(4問)

  1. 製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。
  2. 天井にフィルタとファンを一体化して並べ、清浄な空気を送り出す装置はどれか。
  3. 200 mmウエハの時代に普及した、カセットを密閉したポッドに入れて装置に受け渡すミニエンバイロメントの方式はどれか。
  4. 真空を使うプロセス装置で、反応で生成した有害な物質を含む排ガスを、装置ごとに処理する装置はどれか。
