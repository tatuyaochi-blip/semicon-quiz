EFEMとは

いーふぇむ

Equipment Front End Module の略。製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニット。ロードポートや搬送ロボットを含む。

この用語の分野: クリーンルーム・製造装置

解説の中の「EFEM」

  • EFEM(Equipment Front End Module)は、FOUPを置くロードポート、ふたを開ける機構、ウエハを取り出して装置内へ運ぶロボットなどを、清浄な空間に収めたモジュールです。
