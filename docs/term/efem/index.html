EFEMとは

いーふぇむ

Equipment Front End Module の略。製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニット。ロードポートや搬送ロボットを含む。

「EFEM」は、1分野の4問の練習問題に出てきます(クリーンルーム・製造装置など)。

この用語の分野: クリーンルーム・製造装置

EFEMの練習問題に挑戦

製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。

  1. AOHT
  2. BULPAフィルタ
  3. CEFEM(ロードポートや搬送ロボットを含む装置前面のモジュール)
答えと解説を見る

正解：C. EFEM(ロードポートや搬送ロボットを含む装置前面のモジュール)

EFEM(Equipment Front End Module)は、FOUPを置くロードポート、ふたを開ける機構、ウエハを取り出して装置内へ運ぶロボットなどを、FFUで清浄に保った空間に収めたモジュールです。ウエハを外気にさらさずに装置とFOUPの間でやり取りでき、ミニエンバイロメントの要になっています。OHTは装置間の搬送、ULPAフィルタは空気の清浄化を担います。

天井にフィルタとファンを一体化して並べ、清浄な空気を送り出す装置はどれか。

  1. AFFU(ファンフィルタユニット)
  2. BEFEM
  3. COHT
答えと解説を見る

正解：A. FFU(ファンフィルタユニット)

FFUは、送風ファンとHEPA/ULPAフィルタを一体化したユニットで、クリーンルームの天井に多数並べて、清浄な空気を下向きに吹き出します。ユニットごとに風量を調整でき、レイアウトの変更や部分的な清浄度の変更にも対応しやすいため、大きなダクトで空気を送る方式に代わって広く使われています。EFEMは装置前面のモジュール、OHTは天井の搬送車です。
