拡散長とは

かくさんちょう

少数キャリアが再結合するまでに拡散で進む平均的な距離。拡散係数Dとライフタイムτから L = √(Dτ) で表される。太陽電池や受光素子の効率に大きく関わる。

「拡散長」は、2分野の3問の練習問題に出てきます(半導体物性, バイポーラトランジスタなど)。

この用語の分野: 半導体物性

拡散長の練習問題に挑戦

半導体のキャリアの拡散係数Dと移動度μの関係を表すアインシュタインの関係式はどれか。(k:ボルツマン定数、T:絶対温度、q:電気素量)

  1. AD = qμ
  2. BD = μ / (kT)
  3. CD = μkT / q
答えと解説を見る

正解：C. D = μkT / q

アインシュタインの関係式は D = μkT/q です。拡散もドリフトも、キャリアがどれだけ散乱されずに動けるかで決まるため、両者は比例します。室温では kT/q ≈ 26 mV なので、電子(μ ≈ 1400 cm²/V·s)なら D ≈ 36 cm²/s、正孔(約450)なら約12 cm²/s です。移動度の表があれば拡散係数をすぐに求められ、拡散長やデバイスの計算に使います。

少数キャリアの拡散係数をD、ライフタイムをτとしたとき、拡散長Lを表す式はどれか。

  1. AL = D / τ
  2. BL = √(D × τ)
  3. CL = D × τ
答えと解説を見る

正解：B. L = √(D × τ)

拡散長は、少数キャリアが再結合するまでに拡散で進むおよその距離で、L = √(Dτ) です。例えば D = 36 cm²/s、τ = 10 µs なら L = √(3.6×10⁻⁴) ≈ 190 µm になります。単位を確認すると √(cm²/s × s) = cm で、長さになる式はこれだけです。太陽電池では拡散長が厚さより長いほど光で生じたキャリアを集めやすく、バイポーラトランジスタではベース幅を拡散長より十分短くします。
