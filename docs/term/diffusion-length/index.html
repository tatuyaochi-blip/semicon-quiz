拡散長とは

かくさんちょう

少数キャリアが再結合するまでに拡散で進む平均的な距離。拡散係数Dとライフタイムτから L = √(Dτ) で表される。太陽電池や受光素子の効率に大きく関わる。

この用語の分野: 半導体物性

解説の中の「拡散長」

  • 移動度の表があれば拡散係数をすぐに求められ、拡散長やデバイスの計算に使います。

  • 拡散長は、少数キャリアが再結合するまでに拡散で進むおよその距離で、L = √(Dτ) です。

    少数キャリアの拡散係数をD、ライフタイムをτとしたとき、拡散長Lを表す式はどれか。

  • ベースを拡散長より十分薄くすると通過時間が短くなり、ほとんどのキャリアがコレクタに届くため電流増幅率が高くなり、高周波特性も良くなります。

    バイポーラトランジスタのベース幅を薄くする主な理由として最も適切なものはどれか。

「拡散長」が出てくる問題(3問)

  1. 半導体のキャリアの拡散係数Dと移動度μの関係を表すアインシュタインの関係式はどれか。(k:ボルツマン定数、T:絶対温度、q:電気素量)
  2. 少数キャリアの拡散係数をD、ライフタイムをτとしたとき、拡散長Lを表す式はどれか。
  3. バイポーラトランジスタのベース幅を薄くする主な理由として最も適切なものはどれか。
