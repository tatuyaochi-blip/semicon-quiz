セットアソシアティブ方式とは

せっとあそしあてぃぶほうしき

アドレスから決まる1つのセットの中の、複数の場所(ウェイ)のどれにでもデータを置けるキャッシュの構成。nウェイなら各アクセスでn個のタグを並列に比べる。

「セットアソシアティブ方式」は、2分野の4問の練習問題に出てきます(メモリ階層と性能, CPU・アーキテクチャなど)。

この用語の分野: メモリ階層と性能

セットアソシアティブ方式の練習問題に挑戦

セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。

  1. Aあるアドレスのデータを、決まったセットの中の複数の場所(ウェイ)のどれかに置ける
  2. Bあるアドレスのデータを置ける場所が、キャッシュ内の1か所に決まっている
  3. Cデータをキャッシュのどこにでも置ける
答えと解説を見る

正解：A. あるアドレスのデータを、決まったセットの中の複数の場所(ウェイ)のどれかに置ける

セットアソシアティブ方式では、アドレスの一部でセットが決まり、その中の複数のウェイのどれかにデータを置けます。例えば8ウェイなら8か所の候補があり、ダイレクトマップ方式より同じ場所の取り合い(競合ミス)を減らせます。ウェイを増やすと比較回路と電力が増えるため、L1で8〜12ウェイ程度、L3で16ウェイ前後が一般的です。どこにでも置けるのはフルアソシアティブ方式です。

アドレスが32ビット、容量32 KB、ラインサイズ64バイトの4ウェイ・セットアソシアティブ方式のキャッシュのセット数はいくつか。

  1. A128
  2. B512
  3. C32
答えと解説を見る

正解：A. 128

ライン数は 32 KB ÷ 64 B = 512 です。4ウェイでは1つのセットに4ラインが入るので、セット数は 512 ÷ 4 = 128 = 2⁷ となり、インデックスは7ビット、タグは 32 − 7 − 6 = 19ビットになります。512はライン数そのもので、ダイレクトマップのときのセット数です。連想度を上げるとセット数が減り、その分タグのビット数が増えて比較器も増えます。32はラインサイズの64を誤ってウェイ数で割った値です。

解説の中の「セットアソシアティブ方式」

  • セットアソシアティブ方式では、アドレスの一部でセットが決まり、その中の複数のウェイのどれかにデータを置けます。

    セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。

  • セットアソシアティブ方式では1つのセットに複数のウェイがあり、同じセットに対応するデータを複数置けるため、ダイレクトマップより競合ミスが減ります。

    ダイレクトマップ方式からセットアソシアティブ方式に変えたときに起こる変化として、正しいものはどれか。

  • セットアソシアティブ方式では、まずアドレスのインデックスで1つのセットを選び、そのセットにある全ウェイのタグを並列に比べます。

    8ウェイ・セットアソシアティブ方式のキャッシュで、1回のアクセスのたびに並列に比べるタグの数はいくつか。

「セットアソシアティブ方式」が出てくる問題(4問)

  1. セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。
  2. アドレスが32ビット、容量32 KB、ラインサイズ64バイトの4ウェイ・セットアソシアティブ方式のキャッシュのセット数はいくつか。
  3. ダイレクトマップ方式からセットアソシアティブ方式に変えたときに起こる変化として、正しいものはどれか。
  4. 8ウェイ・セットアソシアティブ方式のキャッシュで、1回のアクセスのたびに並列に比べるタグの数はいくつか。
