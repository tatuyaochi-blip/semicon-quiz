LOCOSとは

ろこす

窒化膜で覆っていない部分だけを厚く酸化して素子間を分離する方法。端に鳥のくちばし状の食い込み(バーズビーク)ができ、現在はSTIに置き換わった。

この用語の分野: 酸化・拡散

解説の中の「LOCOS」

  • LOCOSでは、窒化膜で覆った部分は酸化されませんが、酸化剤が窒化膜の下のパッド酸化膜を通って横から拡散し酸化が進むため、鳥のくちばしのような形に酸化膜が食い込みます(バーズビーク)。

    LOCOS(選択酸化)で、窒化膜マスクの端の下に酸化膜が鳥のくちばし状に食い込む現象を何と呼ぶか。

  • かつて主流だったLOCOSは、酸化膜が横方向に食い込むバーズビークで分離の幅を小さくできず、表面にも段差が残るため、0.25 µm世代ごろからSTIに置き換えられました。

    微細なLSIの素子分離に主に使われている方法はどれか。

  • 熱酸化でつくったSiO2は絶縁性が高く、シリコンとの界面の品質もよいため、MOSFETのゲート絶縁膜、素子と素子を電気的に分ける分離(LOCOS、STIのライナー)、イオン注入や拡散のマスク、注入のときの表面保護などに使われてきました。

    シリコンの熱酸化膜の代表的な使われ方として正しいものはどれか。

「LOCOS」が出てくる問題(7問)

  1. LOCOS(選択酸化)で、窒化膜マスクの端の下に酸化膜が鳥のくちばし状に食い込む現象を何と呼ぶか。
  2. LOCOSなどの素子分離に使われたフィールド酸化膜と、MOSFETのゲート酸化膜の厚さの関係として一般的に正しいものはどれか。
  3. LOCOSで、窒化膜マスクの下のシリコン表面に薄い窒化物ができ、後のゲート酸化膜が局所的に薄くなったり不良になったりする現象を何と呼ぶか。
  4. 微細なLSIの素子分離に主に使われている方法はどれか。
  5. シリコンの熱酸化膜の代表的な使われ方として正しいものはどれか。
  6. シリコン窒化膜(Si3N4)の用途として正しいものはどれか。
  7. シリコン窒化膜のウェットエッチングに一般的に使われる薬液はどれか。
