LOCOSとは

ろこす

窒化膜で覆っていない部分だけを厚く酸化して素子間を分離する方法。端に鳥のくちばし状の食い込み(バーズビーク)ができ、現在はSTIに置き換わった。

この用語の分野: 酸化・拡散

解説の中の「LOCOS」

  • LOCOSでは、窒化膜で覆った部分は酸化されませんが、酸化剤がマスクの端の下に横から拡散して酸化が進むため、鳥のくちばし(バーズビーク)のような形に酸化膜が食い込みます。

    LOCOS(選択酸化)で、窒化膜マスクの端の下に酸化膜が鳥のくちばし状に食い込む現象を何と呼ぶか。

  • かつて主流だったLOCOSは、酸化膜が横方向にも食い込む「バーズビーク」が生じて素子分離の幅を小さくしにくいため、微細化とともにSTIに置き換えられました。

    微細なLSIの素子分離に主に使われている方法はどれか。

  • シリコン窒化膜は酸素や水分を通しにくく、硬いため、選択酸化(LOCOS)のマスク、STI形成でのCMPストッパー、チップ表面を水分や可動イオンから守るパッシベーション膜などに使われます。

    シリコン窒化膜(Si3N4)の用途として正しいものはどれか。

「LOCOS」が出てくる問題(6問)

  1. LOCOS(選択酸化)で、窒化膜マスクの端の下に酸化膜が鳥のくちばし状に食い込む現象を何と呼ぶか。
  2. LOCOSなどの素子分離に使われたフィールド酸化膜と、MOSFETのゲート酸化膜の厚さの関係として一般的に正しいものはどれか。
  3. LOCOSで、窒化膜マスクの下のシリコン表面に薄い窒化物ができ、後のゲート酸化膜が局所的に薄くなったり不良になったりする現象を何と呼ぶか。
  4. 微細なLSIの素子分離に主に使われている方法はどれか。
  5. シリコン窒化膜(Si3N4)の用途として正しいものはどれか。
  6. シリコン窒化膜のウェットエッチングに一般的に使われる薬液はどれか。
