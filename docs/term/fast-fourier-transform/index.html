高速フーリエ変換(FFT)とは

こうそくふーりえへんかん

離散フーリエ変換(DFT)を、少ない演算で正確に計算するアルゴリズムの総称。N点のDFTを半分の大きさのDFTに次々に分けて共通の計算をまとめる方法(クーリー・テューキーのアルゴリズム)が代表的で、演算の回数は定義どおりの約 N² 回から約 N log₂N 回に減る。N = 1024 ならおよそ100分の1である。点数が2のべき乗のときに最も簡単な形になるが、ほかの点数に使える方法もある。スペクトルの解析のほか、OFDMの変調・復調や、長い畳み込みの高速な計算にも使われる。

「高速フーリエ変換(FFT)」は、3分野の5問の練習問題に出てきます(デジタル信号処理の基礎, 無線通信の基礎, ハードウェアセキュリティの最新動向など)。

この用語の分野: デジタル信号処理の基礎

なぜ速くなるのか

N点のDFTを、偶数番目と奇数番目のサンプルの2つの N/2 点のDFTに分けると、回転因子 e^(−j2πk/N) を掛けて足し引きするだけで元の結果を組み立てられます。これをくり返すと log₂N 段に分かれ、各段の演算はおよそ N 回なので、全体は N log₂N 程度になります。この足し引きの組は、その形から「バタフライ演算」と呼ばれます。

どのくらい速くなるか

比は N/log₂N で、N = 1024 なら 1024 ÷ 10 = 102.4、N = 65536 なら 65536 ÷ 16 = 4096 です。点数が大きいほど効果が大きく、実時間のスペクトル表示や、通信の受信機のように多くのDFTを続けて計算する用途には欠かせません。

FFTを使った畳み込み

2つの系列の畳み込みは、周波数の側では掛け算になります。そこで、両方をFFTで変換して掛け合わせ、逆FFTで戻すと、長いFIRフィルタの畳み込みを直接計算するより少ない演算で求められます。ただし、DFTどうしの掛け算は巡回畳み込みに当たるので、ゼロパディングで長さをそろえて、端の回り込みを防ぐ必要があります。

高速フーリエ変換(FFT)の練習問題に挑戦

N点のDFTを定義どおりに計算すると約 N² 回、FFT(高速フーリエ変換)では約 N log₂N 回の演算で済むとする。N = 1024 のとき、FFTによる演算回数の削減の度合いとして最も近いものはどれか。

  1. A約10分の1
  2. B約100分の1
  3. C約1000分の1
答えと解説を見る

正解：B. 約100分の1

N² = 1024² ≈ 105万、N log₂N = 1024 × 10 = 10240 で、比は N/log₂N = 1024 ÷ 10 = 102.4、つまり約100分の1です。N が大きいほど差は広がり、例えば N = 65536 では約4096分の1になります。FFTは、DFTを半分の大きさのDFTに次々に分けて、共通の計算をまとめることで演算を減らします。

よくある質問

FFTの点数は2のべき乗でなければいけませんか?

いいえ。2のべき乗のときが最も簡単で速いことが多いのですが、3や5などの因数に分ける混合基数のFFTや、素数の点数を扱う方法もあり、一般的なライブラリは任意の点数を計算できます。2のべき乗にそろえたい場合は、ゼロパディングで点数を増やすこともあります。

FFTの結果はDFTと同じですか?

同じ値を計算する方法なので、丸め誤差を除いて一致します。FFTは近似ではなく、計算の順序を工夫して、同じ結果を速く得るアルゴリズムです。

「高速フーリエ変換(FFT)」が出てくる問題(5問)

  1. N点のDFTを定義どおりに計算すると約 N² 回、FFT(高速フーリエ変換)では約 N log₂N 回の演算で済むとする。N = 1024 のとき、FFTによる演算回数の削減の度合いとして最も近いものはどれか。
  2. 256点の信号のあとに0を768個付け足して(ゼロパディング)、1024点のDFTを計算した。256点のままDFTを計算した場合と比べた説明として正しいものはどれか。
  3. OFDM(直交周波数分割多重)の説明として、適切なものはどれか。
  4. OFDMで、各シンボルの末尾の一部をコピーしてシンボルの先頭に付け加えるサイクリックプレフィックス(CP)の主な目的はどれか。
  5. 格子に基づく耐量子計算機暗号では、次数 n = 256 の多項式の掛け算を何度も行う。係数どうしをすべて掛け合わせる素朴な方法では約 n² 回、数論変換(NTT)を使う方法では約 n log₂ n 回の掛け算が必要とすると、NTTを使うことで掛け算の回数がおよそ何分の1になるかとして、最も近いものはどれか。
