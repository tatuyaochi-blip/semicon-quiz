オーバーサンプリングとは

おーばーさんぷりんぐ

信号に必要な周波数(ナイキスト周波数の2倍)より十分高い周波数でサンプリングすること。量子化雑音を広い帯域に散らし、信号帯域の雑音を減らせる。ΔΣ型ADCの基本となる。

この用語の分野: AD/DA変換

解説の中の「オーバーサンプリング」

  • つまり単純なオーバーサンプリングでは、1ビット増やすのに4倍、2ビットで16倍の速度が必要になり、効率が悪いのが難点です。

    ノイズシェーピングを行わない単純なオーバーサンプリングで、サンプリング周波数を4倍にしたときに得られる量子化雑音の改善…

  • ADCは、ナイキスト周波数の2倍程度でサンプリングするナイキスト型(フラッシュ型、逐次比較型、パイプライン型など)と、それよりはるかに高い周波数でサンプリングするオーバーサンプリング型に分けられます。

    ADコンバータの方式のうち、オーバーサンプリング型に分類されるものはどれか。

  • 積分を使うのは二重積分型、オーバーサンプリングを使うのはΔΣ型です。

    逐次比較型(SAR型)ADコンバータの動作として正しいものはどれか。

「オーバーサンプリング」が出てくる問題(6問)

  1. ノイズシェーピングを行わない単純なオーバーサンプリングで、サンプリング周波数を4倍にしたときに得られる量子化雑音の改善量はどれか。
  2. ADコンバータの方式のうち、オーバーサンプリング型に分類されるものはどれか。
  3. 逐次比較型(SAR型)ADコンバータの動作として正しいものはどれか。
  4. ΔΣ(デルタシグマ)型ADコンバータの特徴として正しいものはどれか。
  5. ADコンバータの前段に置くアンチエイリアシングフィルタとして使われるフィルタの種類はどれか。
  6. ΔΣ型ADコンバータの変調器の次数を上げる(例えば1次から2次にする)ことの効果として正しいものはどれか。
