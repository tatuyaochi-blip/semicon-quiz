カレントミラー回路とは

かれんとみらーかいろ

特性のそろった2つのトランジスタを使い、一方に流した電流と同じ(または一定比の)電流をもう一方に流す回路。アナログICのバイアス電流源や能動負荷に広く使われる。

この用語の分野: バイポーラトランジスタ
