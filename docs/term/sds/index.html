SDS(安全データシート)とは

あんぜんでーたしーと

化学物質の危険有害性、取り扱い方法、応急措置などを記載した文書。

この用語の分野: 環境安全

解説の中の「SDS(安全データシート)」

  • SDSは、化学物質やそれを含む製品を譲渡・提供するときに、提供者が相手に渡す文書です。

    SDS(安全データシート)の説明として正しいものはどれか。

  • GHSは、化学品の危険有害性を世界共通のルールで分類し、9種類の絵表示(ピクトグラム)、「危険」「警告」の注意喚起語、危険有害性情報などでラベルやSDSに表示する仕組みです。

    化学品の危険有害性を、ドクロや炎などの絵表示と注意書きによって国際的に統一して示す仕組みはどれか。

  • 薬液の種類で応急措置が異なる場合もあるため、事前にSDSで確認しておきます。

    目に薬液が入ったときの応急措置として適切なものはどれか。

「SDS(安全データシート)」が出てくる問題(4問)

  1. SDS(安全データシート)の説明として正しいものはどれか。
  2. 化学品の危険有害性を、ドクロや炎などの絵表示と注意書きによって国際的に統一して示す仕組みはどれか。
  3. 目に薬液が入ったときの応急措置として適切なものはどれか。
  4. 化学物質を使う作業について、危険性や有害性を特定し、そのリスクの大きさを見積もって対策を決める取り組みを何と呼ぶか。
