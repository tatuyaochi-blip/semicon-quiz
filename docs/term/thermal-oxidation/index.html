熱酸化とは

ねつさんか

シリコンを酸素や水蒸気の中で加熱し、表面にSiO2膜をつくる方法。ドライ酸化とウェット酸化がある。

「熱酸化」は、8分野の31問の練習問題に出てきます(酸化・拡散, 成膜(CVD・PVD), 半導体物性など)。

この用語の分野: 酸化・拡散

ドライ酸化とウェット酸化

ドライ酸化はシリコンを酸素ガスと反応させ(Si + O2 → SiO2)、ウェット酸化は水蒸気を使います(Si + 2H2O → SiO2 + 2H2)。水はO2の数百倍もSiO2に溶け込むため、ウェット酸化は数倍〜10倍速く、1000 °Cで1時間ならドライで約70 nm、ウェットで約400 nmの膜ができます。ウェット酸化膜は水素をいくらか含み、密度もやや低いため、厚い素子分離膜やマスク層に向いています。ドライ酸化膜は成長が遅いぶん膜厚を精密に制御でき、界面準位密度も低いため、古くからゲート酸化膜に使われてきました。

ディール・グローブモデル

ディール・グローブモデルでは、酸化を、酸化種が気相から酸化膜表面へ移動し、酸化膜中を拡散し、Si/SiO2界面でシリコンと反応する過程として扱います。これらの流束のつり合いから x² + Ax = B(t + τ) が得られます。酸化膜が薄いうちは界面反応が律速で、膜厚は速度B/Aで時間に比例して増えます。膜厚がおよそA/2を超えると拡散律速となり、膜厚は時間の平方根に比例するため、厚さを2倍にするには約4倍の時間がかかります。温度や酸化種の分圧を上げると、どちらの領域でも成長が速くなります。

シリコンの消費と応力

酸化膜は基板を消費して成長します。厚さxの膜をつくるのに約0.44xのシリコンを使うため、酸化膜の44%は元の表面より下、56%は上にあります。体積が約2.2倍に膨張するため、酸化膜には圧縮応力が残ります。約950 °C以上ではアモルファスのSiO2が粘性流動して応力を緩和できますが、それより低温では凸型の角で応力が酸化を遅らせ、角が鋭いまま残ります。新しい酸化膜は常に新たにできた界面で形成されるため、熱酸化膜は堆積した酸化膜より界面がきれいです。

実際のプロセス条件

酸化は約800〜1,200 °Cで行い、通常は約100枚のウエハを入れる縦型炉を使います。(111)面は(100)面より速く酸化され、薄い酸化膜では約1.5倍です。HClを数%加えると、ナトリウムや金属汚染をゲッタリングし、酸化誘起積層欠陥(OSF)を抑えられます。OSFは酸化中に注入される格子間シリコンから成長する欠陥です。高濃度にドープしたポリシリコンは速く酸化されますが、酸化膜の質は劣ります。熱酸化SiO2の比誘電率は約3.9で、等価酸化膜厚(EOT)の基準です。面方位に依存しない薄い膜が必要な場合は、ISSGによるラジカル酸化を使います。

熱酸化の練習問題に挑戦

シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。

  1. Aドライ酸化のほうが酸化膜の成長速度が速い
  2. Bウェット酸化のほうが酸化膜の成長速度が速い
  3. C両者の成長速度は同じである
答えと解説を見る

正解：B. ウェット酸化のほうが酸化膜の成長速度が速い

水蒸気を使うウェット酸化は、酸化剤のH2OのSiO2中への溶解度がO2より数百倍高いため、ドライ酸化より成長速度が数倍〜10倍程度速くなります。例えば1000 ℃・1時間で、ドライは約70 nm、ウェットは約400 nmです。厚い膜が必要な素子分離やマスクに向いています。ドライ酸化は遅いものの緻密で界面準位の少ない良質な膜ができ、膜厚も制御しやすいため、薄いゲート酸化膜に使われてきました。

シリコンを熱酸化して厚さxのSiO2膜をつくったとき、消費されるシリコンの厚さはおよそいくらか。

  1. A約0.44x
  2. B約1.0x
  3. C約2.2x
答えと解説を見る

正解：A. 約0.44x

熱酸化ではシリコン自身が酸素と反応してSiO2になります。シリコンの原子密度(約5.0×10²² cm⁻³)とSiO2の分子密度(約2.2×10²² cm⁻³)の比から、厚さxの酸化膜をつくるのに消費されるシリコンは約0.44xです。酸化膜の約44%は元の表面より下に、56%は上に成長し、体積は約2.2倍に膨らみます。このため酸化した部分は段差になり、界面は常に新しい清浄な面になります。

よくある質問

熱酸化でシリコンはどれくらい消費されますか?

最終的な酸化膜厚の約0.44倍です。100 nmのSiO2を成長させると約44 nmのシリコンが消費され、表面は約56 nm高くなります。

ウェット酸化がドライ酸化より速いのはなぜですか?

水分子はSiO2中に酸素の数百倍の濃度で溶け込むため、Si/SiO2界面に届く酸化種がはるかに多くなるからです。その結果、同じ温度でウェット酸化は数倍〜10倍速くなります。

熱酸化膜とCVD酸化膜の違いは?

熱酸化膜はシリコン基板そのものを酸化して成長させるため、緻密で界面の質が高い膜になります。CVD酸化膜はシリコンを消費せずに原料ガスから表面に堆積させるため、低温で成膜でき、シリコン以外の層の上にも厚くつけられますが、界面の質は劣ります。
