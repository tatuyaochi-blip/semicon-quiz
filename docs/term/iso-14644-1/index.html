ISO 14644-1とは

あいえすおー14644-1

クリーンルームの清浄度のクラスを、空気中の粒子の数で定めた国際規格。数字が小さいほど清浄度が高い。

「ISO 14644-1」は、1分野の3問の練習問題に出てきます(クリーンルーム・製造装置など)。

この用語の分野: クリーンルーム・製造装置

ISO 14644-1の練習問題に挑戦

旧米国連邦規格のクラス100(1立方フィートあたり0.5 µm以上の粒子が100個以下)に相当するISO 14644-1の清浄度クラスはどれか。

  1. AISOクラス5
  2. BISOクラス1
  3. CISOクラス9
答えと解説を見る

正解：A. ISOクラス5

旧米国連邦規格のクラス100は、1立方フィート(約28.3 L)あたり0.5 µm以上の粒子が100個以下で、1 m³に換算すると約3500個です。ISO 14644-1のクラス5の0.5 µm以上の上限は3520個/m³なので、ほぼ相当します。ISOクラスは数字が1つ小さくなるごとに許される粒子数が1/10になるため、クラス1は非常に厳しく、クラス9は普通の室内程度です。

ISO 14644-1の清浄度クラスについて正しい説明はどれか。

  1. A数字が大きいほど清浄度が高い
  2. B粒子の数ではなく、粒子の重さで決まる
  3. Cクラスの数字Nが1つ小さくなるごとに、許される粒子の数がおよそ10分の1になる
答えと解説を見る

正解：C. クラスの数字Nが1つ小さくなるごとに、許される粒子の数がおよそ10分の1になる

ISO 14644-1では、ISOクラスNのとき、1 m³あたりの0.1 µm以上の粒子の上限が10のN乗個と定められています(ほかの粒径の上限も式で決まります)。例えばクラス5は10万個、クラス4は1万個で、数字が小さいほど清浄度が高くなります。重さではなく個数濃度で決まります。先端の工場では、ウエハが触れる空間でクラス1〜3程度が求められます。
