LVSとは

えるぶいえす

Layout Versus Schematic の略。レイアウトから抽出した回路の接続が、回路図やネットリストと一致しているかを確認する検証。DRCとともにテープアウト前に必ず行う。

「LVS」は、1分野の5問の練習問題に出てきます(LSI設計フロー・EDAなど)。

この用語の分野: LSI設計フロー・EDA

LVSの仕組み

LVS(Layout Versus Schematic)は、描いたレイアウトが意図した回路をそのとおりに実現しているかを確認する検証です。ツールはまずレイアウトの図形から素子を抽出します。ポリシリコンと拡散層が重なった部分がトランジスタになり、特定のマーカー層で抵抗や容量を識別し、コンタクトやビアで金属の図形をつないでネットにします。こうしてレイアウトのネットリストができます。これを回路図や配置配線から得た基準のネットリストと比較します。本質的にはグラフの照合問題です。接続関係に加えて、トランジスタの幅と長さや抵抗値などの素子パラメータも基準と比較します。

LVSで見つかる典型的なエラー

最も多いLVSエラーは、分かれているべき2つのネットが接触しているショートと、ネットが途切れているオープンです。特に電源ネット間のショートは深刻です。ほかに、素子の不足や余分な素子、ピンの入れ違い、寸法の誤ったトランジスタ、ピンラベルの位置違いやつづり間違いも報告されます。ラベルの誤りがあると、図形は正しくてもネットが未接続に見えます。検証そのものよりデバッグのほうが難しいことが多くあります。1つのショートで2つの大きなネットがつながってしまうため、ツールの助けを借りて両者が接している図形を正確に突き止める必要があるからです。

LVS・DRC・ERCの違い

サインオフでは通常、3つの検証を一緒に行います。デザインルールチェック(DRC)は形状だけを見ます。最小幅、間隔、包含、密度などの製造ルールで、先端プロセスでは数千にもなります。LVSは接続関係と素子の同一性を見ます。電気的ルールチェック(ERC)は、フローティングの入力、複数の出力から駆動される出力、異なる電源間のショート、未接続のウェルなど、電気的に疑わしい接続を探します。DRCはクリーンでもLVSで不合格になるレイアウトもあれば、その逆もあるので、マスクデータを出す前にすべてに合格する必要があります。

サインオフの中でのLVSの位置づけ

LVSのルールデッキはファウンドリのプロセスデザインキット(PDK)から提供され、寄生成分抽出も同じ素子認識ルールに基づいています。そのためLVSがクリーンであることは、正確なレイアウト後シミュレーションとタイミング解析の前提条件でもあります。デジタル設計のフローでは、配線済みのレイアウトをゲートレベルのネットリストと比較し、スタンダードセルは検証済みの部品として扱います。サインオフにはさらに静的タイミング解析と、IRドロップやエレクトロマイグレーションなどの電源グリッドの検証も含まれます。これらすべてに合格して初めて、レイアウトはマスク製作用のGDSIIやOASISのデータとして出されます。この工程をテープアウトと呼びます。

LVSの練習問題に挑戦

レイアウト検証におけるDRC(デザインルールチェック)の説明として正しいものはどれか。

  1. A回路図とレイアウトの接続が一致するかを検証する
  2. Bレイアウトが、最小線幅や間隔などの製造上のルールを満たしているかを検証する
  3. CRTLの論理機能をシミュレーションで検証する
答えと解説を見る

正解：B. レイアウトが、最小線幅や間隔などの製造上のルールを満たしているかを検証する

DRCは、レイアウトの図形が、最小の線幅・間隔・重なり・密度など、製造工程から決まるデザインルールに違反していないかを調べる検証です。先端プロセスではルールが数千に及び、ツールで自動的に確認します。回路図とレイアウトの接続の一致を確認するのはLVS(Layout Versus Schematic)、論理機能の確認はシミュレーションです。DRCとLVSはマスクデータを出す前に必ず行います。

ファウンドリが設計者に提供する、デザインルール、デバイスモデル、セルライブラリなどの設計用データ一式を何と呼ぶか。

  1. APDK(プロセスデザインキット)
  2. BIPコア
  3. CHDL
答えと解説を見る

正解：A. PDK(プロセスデザインキット)

PDKには、そのプロセスのデザインルール、トランジスタなどのSPICE用モデル、DRCやLVSのためのルールファイル、配線の寄生素子抽出のデータ、基本的なデバイスのレイアウトなどが含まれます。設計者はPDKを使うことで、そのファウンドリで製造できる回路を設計できます。スタンダードセルのライブラリはPDKと別に提供されることもあります。IPコアは回路ブロック、HDLは記述言語です。

よくある質問

LVSとは何の略ですか?

LVSはLayout Versus Schematicの略です。チップのレイアウトから抽出した素子と接続が、意図した回路図やネットリストと一致していることを確認する検証工程です。

DRCとLVSの違いは?

DRCはレイアウトの図形がファウンドリの幾何学的な製造ルールを守っているかを確認し、LVSはレイアウトの素子と接続が回路のネットリストと一致しているかを確認します。テープアウト前には両方に合格する必要があります。

LVSのショートエラーの原因は何ですか?

LVSのショートは、分かれているべき2つのネットがレイアウト上で電気的につながっていることを意味します。金属の重なり、ビアやコンタクトの配置ミス、ネット名を統合してしまう誤ったラベルなどが典型的な原因です。
