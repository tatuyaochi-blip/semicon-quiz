LVSとは

えるぶいえす

Layout Versus Schematic の略。レイアウトから抽出した回路の接続が、回路図やネットリストと一致しているかを確認する検証。DRCとともにテープアウト前に必ず行う。

「LVS」は、1分野の5問の練習問題に出てきます(LSI設計フロー・EDAなど)。

この用語の分野: LSI設計フロー・EDA

LVSの練習問題に挑戦

レイアウト検証におけるDRC(デザインルールチェック)の説明として正しいものはどれか。

  1. A回路図とレイアウトの接続が一致するかを検証する
  2. Bレイアウトが、最小線幅や間隔などの製造上のルールを満たしているかを検証する
  3. CRTLの論理機能をシミュレーションで検証する
答えと解説を見る

正解：B. レイアウトが、最小線幅や間隔などの製造上のルールを満たしているかを検証する

DRCは、レイアウトの図形が、最小の線幅・間隔・重なり・密度など、製造工程から決まるデザインルールに違反していないかを調べる検証です。先端プロセスではルールが数千に及び、ツールで自動的に確認します。回路図とレイアウトの接続の一致を確認するのはLVS(Layout Versus Schematic)、論理機能の確認はシミュレーションです。DRCとLVSはマスクデータを出す前に必ず行います。

ファウンドリが設計者に提供する、デザインルール、デバイスモデル、セルライブラリなどの設計用データ一式を何と呼ぶか。

  1. APDK(プロセスデザインキット)
  2. BIPコア
  3. CHDL
答えと解説を見る

正解：A. PDK(プロセスデザインキット)

PDKには、そのプロセスのデザインルール、トランジスタなどのSPICE用モデル、DRCやLVSのためのルールファイル、配線の寄生素子抽出のデータ、基本的なデバイスのレイアウトなどが含まれます。設計者はPDKを使うことで、そのファウンドリで製造できる回路を設計できます。スタンダードセルのライブラリはPDKと別に提供されることもあります。IPコアは回路ブロック、HDLは記述言語です。

解説の中の「LVS」

  • 回路図とレイアウトの接続の一致を確認するのはLVS(Layout Versus Schematic)、論理機能の確認はシミュレーションです。

    レイアウト検証におけるDRC(デザインルールチェック)の説明として正しいものはどれか。

  • PDKには、そのプロセスのデザインルール、トランジスタなどのSPICE用モデル、DRCやLVSのためのルールファイル、配線の寄生素子抽出のデータ、基本的なデバイスのレイアウトなどが含まれます。

    ファウンドリが設計者に提供する、デザインルール、デバイスモデル、セルライブラリなどの設計用データ一式を何と呼ぶか。

  • サインオフでは、タイミング、DRC・LVSに加えて、電源配線の電圧降下(IRドロップ)や、配線の電流密度によるエレクトロマイグレーションの解析を行います。

    テープアウト前の最終確認(サインオフ)で、タイミングの検証と並んで行う電源配線の解析はどれか。

  • 論理合成の出力や配置配線の入力として使われ、LVSではレイアウトから取り出したネットリストと回路図のネットリストを比べます。

    ネットリストの説明として正しいものはどれか。

  • 図形の寸法の規則を調べるDRCや、回路図との一致を調べるLVSとともにサインオフで行います。

    レイアウト検証で、入力端子が浮いたまま(どこにもつながっていない)になっていないか、電源どうしが短絡していないかなど、…

「LVS」が出てくる問題(5問)

  1. レイアウト検証におけるDRC(デザインルールチェック)の説明として正しいものはどれか。
  2. ファウンドリが設計者に提供する、デザインルール、デバイスモデル、セルライブラリなどの設計用データ一式を何と呼ぶか。
  3. テープアウト前の最終確認(サインオフ)で、タイミングの検証と並んで行う電源配線の解析はどれか。
  4. ネットリストの説明として正しいものはどれか。
  5. レイアウト検証で、入力端子が浮いたまま(どこにもつながっていない)になっていないか、電源どうしが短絡していないかなど、電気的な接続の誤りを調べる検査はどれか。
