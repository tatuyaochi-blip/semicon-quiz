書き込み増幅(ライトアンプリフィケーション)とは

かきこみぞうふく

ホストが書き込んだデータ量より、ガベージコレクションなどのためにフラッシュメモリに実際に書き込まれるデータ量が多くなること。大きいほどSSDの寿命が縮む。

この用語の分野: SRAM・フラッシュメモリ

解説の中の「書き込み増幅(ライトアンプリフィケーション)」

  • この比が書き込み増幅係数(WAF)で、ランダムな小さい書き込みが多いと数倍になることもあります。

    SSDの「書き込み増幅(ライトアンプリフィケーション)」の説明として正しいものはどれか。

  • この余分なコピーが書き込み増幅の原因で、空き容量が少ないほど頻繁になり、書き込み性能が落ちます。

    SSDのガベージコレクションの説明として正しいものはどれか。

  • TRIMコマンドで不要な領域を通知すると、SSDはそのページを無効として扱い、コピーせずに消去できるため、書き込み増幅が減って性能と寿命が改善します。

    OSが削除したファイルの領域をSSDに通知し、ガベージコレクションを効率化するためのコマンドはどれか。

「書き込み増幅(ライトアンプリフィケーション)」が出てくる問題(3問)

  1. SSDの「書き込み増幅(ライトアンプリフィケーション)」の説明として正しいものはどれか。
  2. SSDのガベージコレクションの説明として正しいものはどれか。
  3. OSが削除したファイルの領域をSSDに通知し、ガベージコレクションを効率化するためのコマンドはどれか。
