NAND型フラッシュメモリとは

なんどがたふらっしゅめもり

メモリセルを直列に接続した構造の不揮発性メモリ。高集積で大容量化しやすく、SSDやメモリカードに使われる。

「NAND型フラッシュメモリ」は、2分野の6問の練習問題に出てきます(SRAM・フラッシュメモリ, 半導体産業・市場など)。

この用語の分野: SRAM・フラッシュメモリ

セルを直列につなぐ構造

NAND型フラッシュのセルは、コントロールゲートの下に電荷蓄積層(フローティングゲートまたはチャージトラップ膜)をもつトランジスタです。数十個のセルを2つの選択トランジスタの間に直列につないでストリングを構成するため、コンタクトはストリングの両端だけで済み、1ビットあたりの面積が非常に小さくなります。読み出しでは、選択セルのワード線に読み出し電圧をかけ、同じストリングの他のワード線にはセルを完全にオンにする高いパス電圧をかけます。ストリングが導通するかどうかで、選択セルのしきい値がわかります。

書き込みと消去

書き込みでは、コントロールゲートに約20 Vをかけ、チャネルの電子を薄いトンネル酸化膜越しにファウラー・ノルドハイム(FN)トンネリングで電荷蓄積層へ注入し、しきい値電圧を上げます。ISPP(インクリメンタル・ステップ・パルス・プログラミング)では、パルス電圧を数百mVずつ上げながら毎回ベリファイし、しきい値の分布を狭くそろえます。消去では、セルのウェルを高電圧にしてブロック内の全セルから電子を引き抜きます。消去状態(低しきい値)は1として読まれるため、消去済みのフラッシュは0xFFを返します。

ページ、ブロックとFTL

NANDは、1本のワード線上のセルからなる約16 KBのページ単位で読み出し・書き込みを行いますが、消去は数百ページからなる数MB〜数十MBのブロック単位でしかできません。書き込みではビットを1から0にしか変えられないため、データをその場で上書きできません。そこでコントローラ内のフラッシュ変換層(FTL)が新しいデータを空きページに書き、論理アドレスの対応を付け替え、古いページを無効にします。後でガベージコレクションが有効なページを別の場所にコピーしてから、そのブロックを消去します。ウェアレベリングで消去回数をブロック間に分散させ、強力な誤り訂正符号(ECC)でビットエラーに対処します。

セルあたりのビット数と書き換え耐性

1セルにNビットを記憶するには、ほぼ同じ電圧範囲に2のN乗個のしきい値電圧レベルが必要で、SLCは2、MLCは4、TLCは8、QLCは16レベルです。ビットを1つ増やすごとにギガバイトあたりのコストは下がりますが、レベル間の間隔が狭まるため書き込みが遅くなり、書き換え耐性も下がります。書き込み・消去のサイクルごとにトンネル酸化膜がわずかに劣化するためです。目安はSLCで約5万〜10万回、TLCで数千回、QLCで約1,000回です。現在の3D NANDは100層を超えるワード線を垂直に積み重ね、多くは垂直なチャネルホールの周りに形成したチャージトラップ型セルを使っています。

NAND型フラッシュメモリの練習問題に挑戦

NOR型と比べたときのNAND型フラッシュメモリの特徴として正しいものはどれか。

  1. Aランダムアクセスが速く、プログラムコードの直接実行に向く
  2. Bメモリセルを直列に接続するため高集積化しやすく、大容量ストレージに向く
  3. C電源を切るとデータが消える揮発性メモリである
答えと解説を見る

正解：B. メモリセルを直列に接続するため高集積化しやすく、大容量ストレージに向く

NAND型はメモリセルを数十個直列につなぎ、セルごとのコンタクトを省いているため、1ビットあたりの面積が小さく大容量化に向き、SSDやメモリカードに使われます。代わりに読み出しは直列のセルを通るため遅く、ページ単位のアクセスになります。NOR型は各セルがビット線に並列につながるためランダム読み出しが速く、コードの直接実行に向きます。どちらも不揮発性です。

NAND型フラッシュメモリでデータを消去する単位として正しいものはどれか。

  1. Aビット単位
  2. Bブロック単位
  3. Cバイト単位
答えと解説を見る

正解：B. ブロック単位

NANDでは読み出し・書き込みはページ(16 KB前後)単位ですが、消去は数百〜数千ページをまとめたブロック(数MB〜数十MB)単位でしか行えません。消去はウェル全体に高電圧をかけて一括で電子を抜くため、この単位になります。一部だけを書き換えるときも上書きはできず、新しいデータを空きページに書いて古いページを無効にし、後でガベージコレクションでまとめて消去します。

よくある質問

NAND型とNOR型フラッシュの違いは?

NAND型はセルを直列につなぐため、セルが最も小さく大容量にできますが、アクセスはページ単位で、SSDやメモリカードに使われます。NOR型は各セルをビット線に並列につなぐため、集積度は低いものの高速なランダム読み出しができ、プログラムコードの格納や直接実行に向いています。

NANDフラッシュがデータを上書きできないのはなぜですか?

書き込みでは電荷を加えてしきい値電圧を上げることしかできず、電荷を取り除くにはブロック全体を消去する必要があるからです。そのためコントローラは更新データを新しいページに書き、古いブロックは後でガベージコレクションによって回収します。

SLC、MLC、TLC、QLCとは何ですか?

1セルあたり1、2、3、4ビットを記憶する方式で、それぞれ2、4、8、16段階のしきい値電圧レベルを区別する必要があります。ビット数が多いほど容量あたりの価格は安くなりますが、書き込みは遅く、書き換え耐性は低くなります。
