NAND型フラッシュメモリとは

なんどがたふらっしゅめもり

メモリセルを直列に接続した構造の不揮発性メモリ。高集積で大容量化しやすく、SSDやメモリカードに使われる。

この用語の分野: SRAM・フラッシュメモリ

解説の中の「NAND型フラッシュメモリ」

  • メモリ半導体の売上の大部分は、コンピュータやスマートフォンの主記憶に使われるDRAMと、SSDやスマートフォンのストレージに使われるNAND型フラッシュメモリが占めています。

    メモリ半導体の市場で、売上の大部分を占める2つの製品の組み合わせとして正しいものはどれか。

「NAND型フラッシュメモリ」が出てくる問題(6問)

  1. NOR型と比べたときのNAND型フラッシュメモリの特徴として正しいものはどれか。
  2. NAND型フラッシュメモリでデータを消去する単位として正しいものはどれか。
  3. NAND型フラッシュメモリの書き込み(プログラム)で主に使われる電子の注入方式はどれか。
  4. NAND型フラッシュメモリで、すでにデータが書かれたページに新しいデータを書くときに必要なことはどれか。
  5. NAND型フラッシュメモリで、データの読み出しと書き込み(プログラム)を行う基本的な単位はどれか。
  6. メモリ半導体の市場で、売上の大部分を占める2つの製品の組み合わせとして正しいものはどれか。
