SPIとは

えすぴーあい

マスタが出すクロックに合わせて送受信を同時に行う同期式のシリアル通信。チップセレクトの線で相手を選び、高速な部品の接続に使う。

この用語の分野: 組込み・ファームウェア

解説の中の「SPI」

  • SPIは、マスタが出すクロックに合わせて、マスタからスレーブへの線とスレーブからマスタへの線で同時にデータを送り合う同期式の通信です。

    SPI通信の特徴として正しいものはどれか。

  • SPIでは、マスタがSCLKにクロックを出し、MOSI(Master Out Slave In)でデータを送り、同時にMISO(Master In Slave Out)でデータを受け取ります。

    SPIで一般に使われる4本の信号の組み合わせとして正しいものはどれか。

  • SPIには、クロックの待機時の値(CPOL)と、クロックのどちらの変化でデータを読むか(CPHA)の組み合わせで4つのモードがあります。

    SPIの部品をつないでも正しいデータが読めないとき、確かめるべき設定として最も適切なものはどれか。

「SPI」が出てくる問題(5問)

  1. SPI通信の特徴として正しいものはどれか。
  2. SPIで一般に使われる4本の信号の組み合わせとして正しいものはどれか。
  3. SPIの部品をつないでも正しいデータが読めないとき、確かめるべき設定として最も適切なものはどれか。
  4. UART・SPI・I2Cを比べた説明として正しいものはどれか。
  5. CPU、メモリ、タイマーやADCなどの周辺機能を1チップにまとめ、家電や機器の制御に使われるLSIはどれか。
