伝導度変調とは

でんどうどへんちょう

低濃度の層に多数の少数キャリアが注入され、その層の抵抗が大きく下がる現象。PINダイオードやIGBTで、高耐圧と低いオン電圧を両立させるために使われる。

この用語の分野: PN接合・ダイオード

解説の中の「伝導度変調」

  • 順方向では伝導度変調でi層の抵抗が下がり、逆方向では高抵抗になるため、高周波信号のスイッチや可変減衰器にも使われます。

    p層とn層の間に不純物の少ないi層を挟んだPINダイオードの特徴として正しいものはどれか。

  • これが伝導度変調で、厚いドリフト層で高耐圧を確保しながらオン電圧を低く保てます。

    PINダイオードに順方向電流を流したとき、i層に大量のキャリアが注入されて抵抗が大きく下がる現象を何と呼ぶか。

  • 電圧で駆動できるため駆動回路が簡単で、オン時にはコレクタ側から注入された少数キャリアがドリフト層の抵抗を下げる(伝導度変調)ため、高耐圧でもオン電圧を低くできます。

    IGBTの説明として正しいものはどれか。

「伝導度変調」が出てくる問題(4問)

  1. p層とn層の間に不純物の少ないi層を挟んだPINダイオードの特徴として正しいものはどれか。
  2. PINダイオードに順方向電流を流したとき、i層に大量のキャリアが注入されて抵抗が大きく下がる現象を何と呼ぶか。
  3. IGBTの説明として正しいものはどれか。
  4. シリコンのMOSFETとIGBTの一般的な使い分けとして正しいものはどれか。
