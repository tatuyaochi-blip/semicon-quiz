High-k/メタルゲートとは

はいけーめたるげーと

高誘電率のゲート絶縁膜と金属のゲート電極の組み合わせ。ゲートリークを抑えながらゲート容量を確保できる。

「High-k/メタルゲート」は、5分野の6問の練習問題に出てきます(先端トランジスタ(FinFET・GAA), 信頼性, MOSFETなど)。

この用語の分野: 先端トランジスタ(FinFET・GAA)

High-k/メタルゲートの練習問題に挑戦

High-k/メタルゲートのトランジスタで、しきい値電圧を調整する主な手段の一つはどれか。

  1. Aゲート電極に使う金属材料の仕事関数を選ぶ
  2. Bウエハの直径を変える
  3. Cパッケージの材料を変える
答えと解説を見る

正解：A. ゲート電極に使う金属材料の仕事関数を選ぶ

メタルゲートでは、ゲート電極の金属の仕事関数によってフラットバンド電圧が変わり、しきい値電圧が決まります。nMOSには伝導帯に近い仕事関数(約4.1 eV、TiAlなど)、pMOSには価電子帯に近い仕事関数(約5.1 eV、TiNなど)が適しています。数nm単位の薄い金属層の組み合わせや厚さを変えることで、高速用・低リーク用など複数のしきい値を作り分けています。

High-k/メタルゲートのトランジスタで、シリコンとHigh-k膜(ハフニウム系酸化膜など)の間に、ごく薄いSiO2などの層を設けることが多い理由はどれか。

  1. Aシリコンとの界面の品質を保ち、移動度の低下などを抑えるため
  2. Bゲート容量を大きくするため
  3. C金属ゲートの抵抗を下げるため
答えと解説を見る

正解：A. シリコンとの界面の品質を保ち、移動度の低下などを抑えるため

High-k膜をシリコンに直接つけると、界面の欠陥や、High-k膜中の電荷・格子振動(リモートフォノン)の影響でチャネルの移動度が下がりやすくなります。そこで厚さ0.5〜1 nm程度のSiO2などの界面層(IL)を挟み、良好な界面を保ちます。ただし界面層は比誘電率が低くEOTの大部分を占めるため、EOTを下げるには界面層を極力薄くすることが鍵になります。

解説の中の「High-k/メタルゲート」

  • 45 nm世代以降のHigh-k/メタルゲート(HKMG)では、金属の電極を使うためこの問題が解消されています。

    ポリシリコンゲートで、ゲート電極側のポリシリコンが空乏化することによる問題として正しいものはどれか。

  • ただしフローティングゲートの形成など工程が多く、28 nm前後より先の世代やHigh-k/メタルゲートとの混載が難しいため、より少ない工程で作れるMRAMやReRAMへの置き換えが進んでいます。

    マイコンのプログラムを格納するために、ロジック回路と同じチップに混載されてきた不揮発メモリはどれか。

  • 組み込みフラッシュはフローティングゲートの形成などで10枚以上のマスクを追加する必要があり、28 nm前後より先の世代やHigh-k/メタルゲートとの組み合わせでは実現が難しくなっています。

    MRAMが、マイコンなどの組み込み不揮発メモリとして注目されている理由の一つとして正しいものはどれか。

「High-k/メタルゲート」が出てくる問題(6問)

  1. High-k/メタルゲートのトランジスタで、しきい値電圧を調整する主な手段の一つはどれか。
  2. High-k/メタルゲートのトランジスタで、シリコンとHigh-k膜(ハフニウム系酸化膜など)の間に、ごく薄いSiO2などの層を設けることが多い理由はどれか。
  3. High-k/メタルゲートのnMOSトランジスタで、ゲートに正の電圧と高温が加わり続けるとしきい値電圧が変化していく劣化を何と呼ぶか。
  4. ポリシリコンゲートで、ゲート電極側のポリシリコンが空乏化することによる問題として正しいものはどれか。
  5. マイコンのプログラムを格納するために、ロジック回路と同じチップに混載されてきた不揮発メモリはどれか。
  6. MRAMが、マイコンなどの組み込み不揮発メモリとして注目されている理由の一つとして正しいものはどれか。
