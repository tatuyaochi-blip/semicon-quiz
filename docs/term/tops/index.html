TOPSとは

とっぷす

1秒あたりの演算の回数を兆(テラ)の単位で表したAIのアクセラレータの性能の指標。多くは低い精度で数えた理論上の最大値。

「TOPS」は、2分野の2問の練習問題に出てきます(AIハードウェアとソフトウェアスタック, CPU・アーキテクチャなど)。

この用語の分野: AIハードウェアとソフトウェアスタック

TOPSの値の計算方法

TOPSは、1秒あたりのテラ(1兆)回の演算を意味します。アクセラレータの場合、通常はピーク値で、積和演算(MAC)器の数×MACあたり2演算(乗算1回と加算1回)×クロック周波数で求めます。したがって、INT8のMAC器4,096個を1 GHzで動かすと約8.2 TOPSになります。この値は、すべての演算器が毎サイクル有効な仕事をすることを前提としていますが、実際のワークロードでそれが完全に達成されることはありません。TOPSはハードウェアの能力を示すもので、特定のモデルがどれだけ速く動くかを示すものではありません。

TOPSの数値に隠れていること

数値の前提条件は必ず確認しましょう。値はたいていINT8かそれ以下の精度で示されており、同じハードウェアでもINT4なら2倍のTOPSを、FP16ならずっと少ないTOPSを示すことがあります。構造化スパース性を前提とし、ゼロの重みを飛ばすことも演算を行ったものとして数えている値もあります。この数値からは、メモリ帯域、チップ上のバッファ容量、ハードウェアが対応する演算子、どれだけの処理がCPUに回るかはわかりません。エネルギー効率としてはTOPS/Wが示されますが、電圧、クロック、チップのどの部分を電力に含めるかに大きく左右されます。

ピーク性能と実効性能:ルーフラインの考え方

達成できる性能は、ピーク演算性能と、メモリ帯域×演算強度(転送1バイトあたりの演算数)のうち小さいほうになります。100 TOPSでメモリ帯域が100 GB/sのアクセラレータがピークに達するには、読み込む1バイトあたり約1,000回の演算が必要です。小バッチの全結合層や言語モデルのトークンごとの生成のように、データの再利用が少ない層ではピークに遠く及ばず、帯域律速になります。再利用の多い畳み込みはピークに近づきます。対象のモデルで実測したスループットだけが公平な比較になるのはこのためです。

TOPSとFLOPSの違い

FLOPSは1秒あたりの浮動小数点演算の回数を数えるのに対し、TOPSは主に整数演算や低精度の混合演算に使われます。ただし、ベンダーが低精度の浮動小数点演算についてTOPSで示すこともあります。数値が同じでも両者は置き換えられません。FP16の演算はINT8の演算より多くの仕事をし、面積も大きいからです。デバイスを比較するときは、両方を同じ精度に換算し、スパース性を前提としているかを確認し、同じモデル、バッチサイズ、精度目標など同一条件で測定したベンチマーク結果を探しましょう。

TOPSの練習問題に挑戦

AIのアクセラレータの性能として示される「○○ TOPS」という値について注意すべき点として正しいものはどれか。

  1. A多くはINT8などの低い精度で数えた理論上の最大値で、実際のモデルでの速さはメモリ帯域や演算器の利用率で大きく変わる
  2. BTOPSが2倍なら、どのモデルでも必ず2倍速く動く
  3. CTOPSはメモリの容量を表す値である
答えと解説を見る

正解：A. 多くはINT8などの低い精度で数えた理論上の最大値で、実際のモデルでの速さはメモリ帯域や演算器の利用率で大きく変わる

TOPS(1秒あたりの兆回の演算)は、全部の演算器が休みなく動いたときの理論上の値で、多くはINT8やそれより低い精度で数えられ、スパースを使った場合の値のこともあります。実際のモデルでは、メモリ帯域で律速されたり、演算器が遊んだり、対応していない演算をほかの回路で行ったりするので、実効の性能はずっと低くなることがあります。製品を比べるときは、同じ条件の実測の値を見ることが大切です。

よくある質問

TOPSは何の略ですか?

Tera Operations Per Secondの略で、1秒あたり何兆回演算できるかを表します。AIアクセラレータでは通常、INT8などの低い精度で、積和演算1回を2演算と数えた理論上のピーク値です。

TOPSが高ければAIの処理は速いのですか?

必ずしもそうではありません。実際の速度はメモリ帯域、演算器の利用率、対応する演算子、ソフトウェアにも左右されるため、モデルによってはTOPSの低いチップが高いチップを上回ることもあります。

TOPSとTFLOPSはどう違いますか?

TFLOPSは浮動小数点演算の回数を数え、TOPSは通常、整数や低精度の演算の回数を数えます。演算の種類が違うので、精度を明示しない限り数値を直接比較することはできません。
