部分分数分解とは

ぶぶんぶんすうぶんかい

分数の形の式を、分母の因数ごとの簡単な分数の和に分けること。ラプラス変換では F(s) = 6/((s + 1)(s + 3)) = 3/(s + 1) − 3/(s + 3) のように分けると、各項が e^(−t)、e^(−3t) に対応し、時間関数 3e^(−t) − 3e^(−3t) が表を使ってすぐに求まる。単純な極 s = p の係数は (s − p)F(s) に s = p を代入して求められる(留数)。

「部分分数分解」は、1分野の2問の練習問題に出てきます(回路解析(交流回路・線形回路・過渡現象)など)。

この用語の分野: 回路解析(交流回路・線形回路・過渡現象)

部分分数分解の練習問題に挑戦

図の直列RLC回路で、E = 6 V、R = 4 Ω、L = 1 H、C = 1/3 F とし、初期値はすべて0とする。t = 0 でスイッチを入れた後の電流 i(t) [A] はどれか。

  1. A3e^(−t) + 3e^(−3t)
  2. B3e^(−t) − 3e^(−3t)
  3. C6e^(−t) − 6e^(−3t)
答えと解説を見る

正解：B. 3e^(−t) − 3e^(−3t)

解き方1(ラプラス変換と部分分数分解): s領域では I(s) = (E/s)/(R + sL + 1/(sC)) = 6/(s² + 4s + 3) = 6/((s + 1)(s + 3)) です。部分分数に分けると I(s) = A/(s + 1) + B/(s + 3) で、A = 6/(−1 + 3) = 3、B = 6/(−3 + 1) = −3 なので、i(t) = 3e^(−t) − 3e^(−3t) A です。解き方2(微分方程式): 特性方程式 s² + 4s + 3 = 0 の根 −1、−3 から i = Ae^(−t) + Be^(−3t) とおき、i(0+) = 0(コイルの電流の連続性)と di/dt(0+) = E/L = 6 A/s から A + B = 0、−A − 3B = 6 を解いて、A = 3、B = −3 です。電流は t = (ln 3)/2 ≈ 0.55 s で最大の約1.15 Aになり、コンデンサが充電されると0に戻ります。

ある回路の電圧のラプラス変換が V(s) = 10(s + 3)/(s(s + 2)(s + 5)) であった。十分に時間がたった後の電圧 v(∞) はどれか。

  1. A0 V
  2. B3 V
  3. C10 V
答えと解説を見る

正解：B. 3 V

解き方1(最終値の定理): v(∞) = lim(s→0) sV(s) = 10 × 3/(2 × 5) = 3 V です。この定理は、sV(s) の極がすべて左半面にある(応答が収束する)ときに使えます。解き方2(部分分数分解で確かめる): V(s) = A/s + B/(s + 2) + C/(s + 5) とおくと A = 3、B = −5/3、C = −4/3 なので、v(t) = 3 − (5/3)e^(−2t) − (4/3)e^(−5t) です。t → ∞ で指数の項が消えて3 Vになり、t = 0 では 3 − 5/3 − 4/3 = 0 となって、初期値の定理 lim(s→∞) sV(s) = 0 とも一致します。

解説の中の「部分分数分解」

  • 解き方1(ラプラス変換と部分分数分解): s領域では I(s) = (E/s)/(R + sL + 1/(sC)) = 6/(s² + 4s + 3) = 6/((s + 1)(s + 3)) です。

    図の直列RLC回路で、E = 6 V、R = 4 Ω、L = 1 H、C = 1/3 F とし、初期値はすべて0とする…

  • 解き方2(部分分数分解で確かめる): V(s) = A/s + B/(s + 2) + C/(s + 5) とおくと A = 3、B = −5/3、C = −4/3 なので、v(t) = 3 − (5/3)e^(−2t) − (4/3)e^(−5t) です。
