テール電流とは

てーるでんりゅう

IGBTのターンオフ時に、蓄積された少数キャリアのために電流がすぐに0にならず、尾を引くように流れ続ける電流。ターンオフ損失の原因になる。

この用語の分野: パワー半導体

解説の中の「テール電流」

  • EV、鉄道、産業用インバータの主力ですが、テール電流のため高周波には不向きです。

    IGBTの説明として正しいものはどれか。

  • これがテール電流で、電圧が上がった状態で流れるためターンオフ損失の大きな原因になり、IGBTのスイッチング周波数を数十kHz以下に制限します。

    IGBTのターンオフ時に、蓄積された少数キャリアのために電流がすぐに0にならず、尾を引くように流れる現象を何と呼ぶか。

  • IGBTは伝導度変調で高耐圧でもオン電圧を低く保てるため、600 V以上の大電流用途(EV、産業用インバータ、鉄道)に向きますが、テール電流で遅めです。

    シリコンのMOSFETとIGBTの一般的な使い分けとして正しいものはどれか。

「テール電流」が出てくる問題(4問)

  1. IGBTの説明として正しいものはどれか。
  2. IGBTのターンオフ時に、蓄積された少数キャリアのために電流がすぐに0にならず、尾を引くように流れる現象を何と呼ぶか。
  3. シリコンのMOSFETとIGBTの一般的な使い分けとして正しいものはどれか。
  4. ウエハの剥離(スマートカット)や、パワーデバイスのライフタイム制御などに使われるイオン注入として正しいものはどれか。
