テープアウトとは

てーぷあうと

設計と検証を終え、マスク製作のためのレイアウトデータを製造側に引き渡すこと。昔は磁気テープでデータを渡したことに由来する。

「テープアウト」は、1分野の4問の練習問題に出てきます(LSI設計フロー・EDAなど)。

この用語の分野: LSI設計フロー・EDA

引き渡すもの

テープアウトでは、設計チームが最終レイアウトを、層ごとに多角形を並べたGDSIIやOASIS形式のファイルとして引き渡します。製造側はその後、マスクデータ処理を行います。光近接効果補正(OPC)などの解像度向上技術を適用し、図形をマスク描画装置が受け付ける形式に分割(フラクチャリング)して、マスクを描画・検査します。ウエハの投入はその後になります。VerilogやSPICEネットリストのような論理記述は、マスク製作には使われません。

テープアウト前のサインオフ検証

テープアウト後の誤りは非常に高くつくため、テープアウトはサインオフを通過しなければ行えません。静的タイミング解析(STA)は、プロセス・電圧・温度の各コーナーで合格する必要があります。デザインルールチェック(DRC)でレイアウトが製造ルールに従っていることを、LVS(レイアウト対回路図検証)で意図した回路が実装されていることを確認します。電源網の解析ではIRドロップとエレクトロマイグレーションを扱い、さらにアンテナ効果、電気的ルール、製造容易性の検証も行います。ファウンドリが受け取ったデータに独自の検証をかけることもあります。

リスピンとメタル修正

テープアウト後にバグが見つかると、新しいマスクが必要になります。先端プロセスのフルマスクセットは数千万ドルに達することもあり、修正によって製品の投入が数か月遅れるため、設計チームは被害を最小限に抑えようとします。レイアウト内に散りばめたスペアセルを使えば、多くの論理修正を金属層とビア層の変更だけで行えます。これはECO(設計変更指示)と呼ばれ、フルリスピンに比べて新規に必要なマスクがはるかに少なくて済みます。

開発スケジュールでの位置づけ

一般的なデジタル設計フローは、仕様策定からRTL設計、論理合成、配置配線、サインオフを経てテープアウトに至ります。最先端チップではこれに1〜2年かかることがあり、テープアウト後のウエハ処理にさらに数か月かかってから、ようやく最初のシリコンが評価に戻ってきます。試作では、小規模な設計は他のプロジェクトと1枚のレチクルを共有するマルチプロジェクトウエハ(MPW)に載せ、マスク費用を分担することがよくあります。

テープアウトの練習問題に挑戦

テープアウト前の最終確認(サインオフ)で、タイミングの検証と並んで行う電源配線の解析はどれか。

  1. Aパッケージの色の確認
  2. BIRドロップやエレクトロマイグレーションの解析
  3. Cチップの価格の見積もり
答えと解説を見る

正解：B. IRドロップやエレクトロマイグレーションの解析

サインオフでは、タイミング、DRC・LVSに加えて、電源配線の電圧降下(IRドロップ)や、配線の電流密度によるエレクトロマイグレーションの解析を行います。多くの回路が同時に切り替わると電流が急増し、局所的に電源電圧が下がって遅延が増えるため、IRドロップの結果をタイミング解析に反映することもあります。色や価格の確認はサインオフの項目ではありません。

よくある質問

なぜテープアウトと呼ぶのですか?

かつてレイアウトデータを磁気テープに入れてマスク製作会社に渡していたためです。現在はファイルを電子的に転送していますが、名前だけが残りました。

テープアウトの後には何が行われますか?

レイアウトはOPCを含むマスクデータ処理を経て、マスクが描画され、ウエハが処理されます。その後、パッケージング、テスト、シリコンの立ち上げ評価(ブリングアップ)が続きます。

チップ設計におけるリスピンとは何ですか?

リスピンは、シリコンで見つかった問題を修正するための2回目(またはそれ以降)のテープアウトです。少なくとも変更した層には新しいマスクが必要になり、製品の投入が遅れます。
