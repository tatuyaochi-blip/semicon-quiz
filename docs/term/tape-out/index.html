テープアウトとは

てーぷあうと

設計と検証を終え、マスク製作のためのレイアウトデータを製造側に引き渡すこと。昔は磁気テープでデータを渡したことに由来する。

この用語の分野: LSI設計フロー・EDA

解説の中の「テープアウト」

  • 先端品では仕様決定からテープアウトまで1〜2年かかることもあります。

    一般的なデジタルLSIの設計フローの順序として正しいものはどれか。

  • テープアウトは、設計の最終データ(マスクデータ)を製造側に引き渡すことで、設計工程の大きな節目です。

    設計と検証を終え、マスク製作のためのデータを製造側に引き渡すことを何と呼ぶか。

  • GDSIIやOASISは、レイアウトの図形(多角形)を層ごとに記述するデータ形式で、テープアウトで製造側に引き渡され、OPCなどの処理を経てマスクの製作に使われます。

    マスク製作のために製造側に渡すレイアウトデータの代表的な形式はどれか。

「テープアウト」が出てくる問題(4問)

  1. テープアウト前の最終確認(サインオフ)で、タイミングの検証と並んで行う電源配線の解析はどれか。
  2. 一般的なデジタルLSIの設計フローの順序として正しいものはどれか。
  3. 設計と検証を終え、マスク製作のためのデータを製造側に引き渡すことを何と呼ぶか。
  4. マスク製作のために製造側に渡すレイアウトデータの代表的な形式はどれか。
