表皮効果とは

ひょうひこうか

高い周波数の電流が導体の表面付近に集中して流れ、実効的な抵抗が上がる現象。周波数が高いほど電流が流れる表面の層は薄くなる。

「表皮効果」は、1分野の1問の練習問題に出てきます(インターフェース・バス規格など)。

この用語の分野: 配線プロセス

表皮効果の練習問題に挑戦

シリアル伝送の速度を上げるほど、同じ長さの基板の配線で信号を送るのが難しくなり、途中にリタイマなどを入れることがある。その主な理由はどれか。

  1. A配線の損失は周波数が高いほど大きくなるので、速い信号ほど届くまでに大きく弱まるから
  2. B速い信号は配線の中を光より速く進んでしまうから
  3. C速い信号ほど配線の抵抗が0に近づき、電流が流れすぎるから
答えと解説を見る

正解：A. 配線の損失は周波数が高いほど大きくなるので、速い信号ほど届くまでに大きく弱まるから

配線では、表皮効果による導体の損失と、基板の材料による誘電体の損失が、どちらも周波数とともに増えます。速度を2倍にすると、同じ長さでも信号は大きく弱まり、受信側のイコライザだけでは補いきれなくなります。そこで、損失の小さい基板の材料を使ったり、途中にリタイマを入れて信号をいったん受け取り、きれいな信号として送り直したりします。
