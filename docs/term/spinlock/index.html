スピンロックとは

すぴんろっく

ロックが空くまで、ループでロックの変数を調べ続けて待つ方式のロック。待ちが短いときに速いが、待つ間もCPUを使い続ける。

この用語の分野: マルチコアと同期

解説の中の「スピンロック」

  • スピンロックは、アトミック命令でロックを取ろうとし、取れなければすぐにもう一度試すことを繰り返します。

    スピンロックの説明として正しいものはどれか。

  • スピンロックで待つスレッドは、ロックが空くまでCPUを使い続けます。

    スピンロックが向かない場面として最も適切なものはどれか。

「スピンロック」が出てくる問題(4問)

  1. スピンロックの説明として正しいものはどれか。
  2. スピンロックが向かない場面として最も適切なものはどれか。
  3. スピンロックで、ロックの変数をいきなりアトミック命令で書き換えようとするのではなく、普段は通常の読み出しで空くのを待ち、空いたと見えたときだけアトミック命令を使う(test-and-test-and-set)理由として正しいものはどれか。
  4. ミューテックス(眠って待つロック)とスピンロックを比べた説明として正しいものはどれか。
