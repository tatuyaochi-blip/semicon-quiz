アッシングとは

あっしんぐ

酸素プラズマなどを使って、エッチングやイオン注入の後に不要になったフォトレジストを灰化して除去する工程。

この用語の分野: エッチング

解説の中の「アッシング」

  • そのため水素系などダメージの少ないアッシング条件や、シリル化剤で損傷を回復させる処理、加工後の脱水処理が必要です。

    Low-k膜をエッチングやアッシングで加工するときに注意すべき問題として正しいものはどれか。

  • 高ドーズの注入ではレジストの表面が炭化して硬化し、除去しにくくなるため、アッシングの条件にも注意が必要です。

    イオン注入のマスクとしてフォトレジストを使うときに注意すべき点はどれか。

  • そのまま高温でアッシングすると、殻の下の柔らかいレジストから出るガスで殻が破裂し(ポッピング)、残渣やパーティクルの原因になります。

    高ドーズのイオン注入を受けたフォトレジストを除去するときに問題になりやすいことはどれか。

「アッシング」が出てくる問題(7問)

  1. Low-k膜をエッチングやアッシングで加工するときに注意すべき問題として正しいものはどれか。
  2. イオン注入のマスクとしてフォトレジストを使うときに注意すべき点はどれか。
  3. 高ドーズのイオン注入を受けたフォトレジストを除去するときに問題になりやすいことはどれか。
  4. 酸素プラズマなどを使ってフォトレジストを灰化して除去する工程を何と呼ぶか。
  5. ドライエッチングのあとに、パターンの側壁などに残った反応生成物(ポリマー)を除去する理由として正しいものはどれか。
  6. 硫酸と過酸化水素水の混合液(SPM)による洗浄の主な目的はどれか。
  7. LSIの製造工程全体の中で、洗浄工程の回数についての説明として正しいものはどれか。
