フローティングゲートとは

ふろーてぃんぐげーと

フラッシュメモリのセルで、周囲を絶縁膜で囲まれた電極。ここに電子を蓄えるとトランジスタのしきい値電圧が変わり、電源を切ってもデータが保たれる。

「フローティングゲート」は、4分野の9問の練習問題に出てきます(SRAM・フラッシュメモリ, DRAM, 次世代メモリなど)。

この用語の分野: SRAM・フラッシュメモリ

セルの構造

フローティングゲート型のフラッシュセルは、2つのゲートを積み重ねたMOSFETです。下側のフローティングゲートは通常ポリシリコンで、完全に絶縁されています。チャネルとの間は薄いトンネル酸化膜で、上の制御ゲートとの間はポリ間絶縁膜で隔てられています。ポリ間絶縁膜には一般にONO(酸化膜・窒化膜・酸化膜)の積層が使われます。不純物を添加したポリシリコン上に熱酸化で成長させた酸化膜は表面が粗く、絶縁破壊耐性が低いためです。制御ゲートはフローティングゲートと容量で結合しているので、フローティングゲートの電圧は、カップリング比で決まる制御ゲート電圧の一部になります。

蓄えた電荷がしきい値電圧を変える仕組み

フローティングゲート上の電子は負の電荷で、制御ゲート電圧の一部を打ち消します。そのため、チャネルを反転させるにはより高い電圧が必要になり、しきい値電圧が上がります。書き込み(プログラム)では電子を加えてしきい値電圧を上げ、消去では電子を取り除いて下げます。読み出しでは、2つのしきい値レベルの間の一定電圧を加え、電流が流れるかどうかを調べます。NANDでは慣例として、しきい値電圧の低い消去状態を1と読むので、消去したフラッシュは0xFFと読めます。多値セルでは、しきい値電圧のウィンドウをより多くのレベルに分け、1セルに複数ビットを記憶します。

書き込みと消去

フローティングゲートには電気的な接点がないため、電荷は絶縁膜を通り抜けなければなりません。NANDでは、制御ゲートや基板に高電圧をかけてトンネル酸化膜に強い電界を生じさせ、ファウラー・ノルドハイム(FN)トンネリングで書き込みと消去の両方を行います。NORフラッシュは一般にチャネルホットエレクトロン注入で書き込み、ドレイン近くで加速された電子が酸化膜の障壁を越えるだけのエネルギーを得て注入されます。周囲の絶縁膜は通常の電圧ではリークを防げる厚さがあるので、電荷は電源なしで約10年保持されます。書き換えを繰り返すとトンネル酸化膜が徐々に損傷し、これが書き換え耐性を制限します。

フローティングゲートとチャージトラップの違い

導電性のフローティングゲートでは電荷が電極全体で共有されるため、トンネル酸化膜の欠陥を通るリーク経路が1つあるだけで、すべての電荷が抜けてしまう可能性があります。また、密集したフローティングゲートどうしは容量結合で互いに影響し合います。チャージトラップセルは、絶縁性の窒化シリコン層中のトラップに電子を蓄えるため、電荷が局在したままです。SiO2/SiN/SiO2の積層は縦型チャネルホールの側壁に連続して成膜できるので、3D NANDではチャージトラップ方式が広く使われ、平面型フラッシュではフローティングゲートが主流でした。

フローティングゲートの練習問題に挑戦

フラッシュメモリの消去で、フローティングゲートなどから電子を引き抜くと、セルのしきい値電圧はどうなるか。

  1. A高くなる
  2. B低くなる
  3. C変化しない
答えと解説を見る

正解：B. 低くなる

フローティングゲートに電子(負の電荷)があると、ゲート電圧の一部が打ち消されてチャネルを作るのにより大きな電圧が必要になるため、しきい値電圧は高くなります。消去で電子を引き抜くとしきい値電圧は低くなり、書き込みで電子を注入すると高くなります。NANDでは一般に消去状態(低いしきい値)を「1」、書き込み状態を「0」としており、消去したフラッシュの中身が0xFFになるのはこのためです。

よくある質問

フローティングゲートが電源なしでデータを保持できるのはなぜですか?

フローティングゲートは、通常の動作電圧では電子が通り抜けられない絶縁膜で完全に囲まれているため、注入された電荷が何年も閉じ込められるからです。書き込みや消去の高電圧をかけたときだけ、電子が酸化膜をトンネルします。

フラッシュセルに書き込むとしきい値電圧はどうなりますか?

書き込みによってフローティングゲートに電子が加わり、その負電荷でしきい値電圧が上がります。消去で電子を取り除くと、しきい値電圧は再び下がります。

フローティングゲートとチャージトラップの違いは?

フローティングゲートは電荷が全体に広がる導電性のポリシリコン電極で、チャージトラップセルは絶縁性の窒化シリコン層中の局在したトラップに電荷を蓄えます。チャージトラップは酸化膜の単一欠陥に強く、3D NANDで作りやすい方式です。
