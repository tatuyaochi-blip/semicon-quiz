フィードバック制御とは

ふぃーどばっくせいぎょ

制御量をセンサで測って目標値と比べ、その差(偏差)が小さくなるように操作量を変える制御。信号がループを一巡するので、閉ループ制御とも呼ぶ。原因によらず結果のずれを直すので外乱や制御対象の変化に強いが、偏差が出てから修正するので遅れがあり、ゲインが高すぎると振動や不安定を招く。PID制御が代表的で、温度、速度、電圧、位置などの制御に広く使われる。

「フィードバック制御」は、1分野の3問の練習問題に出てきます(制御工学の基礎など)。

この用語の分野: 制御工学の基礎

フィードバック制御の練習問題に挑戦

フィードバック制御(閉ループ制御)の説明として正しいものはどれか。

  1. A制御量を測らずに、あらかじめ決めた操作量や手順だけで動かすので、外乱で制御量がずれても自動では補正されない
  2. B制御量を測って目標値と比べ、その差(偏差)が小さくなるように操作量を変えるので、外乱や制御対象の特性の変化の影響を小さくできる
  3. C外乱を測り、それが制御量に現れる前に打ち消す操作量を加えるので、測っていない外乱やモデルの誤差まで含めて、必ず偏差を0にできる
答えと解説を見る

正解：B. 制御量を測って目標値と比べ、その差(偏差)が小さくなるように操作量を変えるので、外乱や制御対象の特性の変化の影響を小さくできる

フィードバック制御は、センサで測った制御量を目標値と比べ、偏差に応じて操作量を決める制御です。信号が出力から入力の側へ戻ってループをひと回りするので、閉ループ制御とも呼びます。原因が何であっても結果のずれを見て直すので、外乱や制御対象の特性の変化に強いのが長所です。一方で、偏差が生じてから修正するので遅れがあり、ゲインを上げすぎると振動したり不安定になったりします。

フィードフォワード制御を、フィードバック制御と組み合わせて使う理由として正しいものはどれか。

  1. Aフィードフォワードは、測れる外乱や目標値の変化に偏差が出る前に応じられるが、測っていない外乱やモデルの誤差は補正できないので、残りをフィードバックで補う
  2. Bフィードフォワードを加えると一巡伝達関数のゲインと位相が変わって位相余裕が増えるので、フィードバックのゲインを大きくしても安定に保てる
  3. Cフィードバックだけでは、積分動作を使っても定常偏差が必ず残ってしまうので、一定の目標値や外乱に対する定常偏差を0にするには、フィードフォワードが欠かせない
答えと解説を見る

正解：A. フィードフォワードは、測れる外乱や目標値の変化に偏差が出る前に応じられるが、測っていない外乱やモデルの誤差は補正できないので、残りをフィードバックで補う

フィードフォワード制御は、外乱や目標値の変化を測り、それが制御量に影響する前に、モデルから計算した操作量を加える制御です。偏差が出るのを待たないので速く応じられますが、モデルが正確で、外乱を測れることが前提になります。そこで、主な外乱や目標値への追従をフィードフォワードで受け持ち、残ったずれをフィードバックで直す組み合わせがよく使われます。フィードフォワードの経路はループの外にあるので、ループの安定性(位相余裕など)は変わりません。

解説の中の「フィードバック制御」

  • フィードバック制御は、センサで測った制御量を目標値と比べ、偏差に応じて操作量を決める制御です。

    フィードバック制御(閉ループ制御)の説明として正しいものはどれか。
