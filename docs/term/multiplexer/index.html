マルチプレクサとは

まるちぷれくさ

選択信号に応じて、複数の入力から1つを選んで出力する回路。セレクタとも呼ぶ。逆に1つの入力を複数の出力の1つに振り分ける回路をデマルチプレクサという。

「マルチプレクサ」は、4分野の5問の練習問題に出てきます(ハードウェア記述言語と検証, 論理回路, MOSFETなど)。

この用語の分野: 論理回路

マルチプレクサが入力を選ぶ仕組み

2入力1出力のマルチプレクサ(MUX)の出力は Y = S'·A + S·B で、選択信号Sが0のときは入力A、1のときは入力Bを出します。選択信号がnビットあれば2ⁿ個の入力から1つを選べるので、8入力のMUXには3本の選択線が必要です。CMOSでは、AND-ORやNAND-NANDの論理、トランスミッションゲート、あるいは入力数が多い場合は2入力MUXを木構造につないで作ります。MUXは万能な論理素子でもあり、データ入力を真理値表の定数につなげば、2ⁿ入力のMUXで任意のn入力論理関数を実現できます。

マルチプレクサが使われる場面

プロセッサのデータパスはMUXだらけです。レジスタと即値のどちらをALUのオペランドにするかを選んだり、パイプラインのストールを避けるためにバイパス経路で結果をフォワーディングしたり、次のプログラムカウンタを選んだり、共有バスを切り替えたりします。FPGAの論理ブロックはルックアップテーブル(LUT)で任意の関数を実現しますが、LUTはMUXの木で読み出す小さなメモリです。テスト容易化設計では、スキャンフリップフロップのデータ入力にMUXを追加し、テストモードでフリップフロップをシフトレジスタとして数珠つなぎにします。基板上では、アナログマルチプレクサで1つのADCを複数のセンサで共有したり、I2Cマルチプレクサで同じアドレスを持つデバイスを切り分けたりします。

HDLと論理合成でのマルチプレクサ

VerilogやVHDLでは、条件代入、if文、case文はたいていマルチプレクサに合成されます。長いif/else-ifの連鎖は優先順位を意味するため、2入力MUXが直列に並んだ遅延の大きい回路になりやすく、互いに排他的な値で分岐するcase文は1つの幅広い並列MUXになりやすい傾向があります。ただし、最近の合成ツールはどちらの書き方でも最適化することが多いです。よくある落とし穴は、組み合わせ回路で代入のない分岐を残してしまうことで、その場合は純粋なMUXではなく、古い値を保持するラッチが推論されてしまいます。

デマルチプレクサ・デコーダとの違い

デマルチプレクサはマルチプレクサの逆の動作をする回路で、1つの入力を選択ビットで指定された2ⁿ個の出力の1つへ振り分けます。デコーダはnビットのコードを2ⁿ本のワンホット信号に変換する回路で、実質的にはデータ入力を1に固定したデマルチプレクサです。デコーダは大規模なMUXの選択論理やメモリのワード線の駆動に使われます。通信の分野では、より広い意味で、時間・周波数・符号によって1つのチャネルを複数の信号で共有することを多重化(マルチプレクシング)と呼びます。

マルチプレクサの練習問題に挑戦

マルチプレクサの機能として正しいものはどれか。

  1. A入力の値を1クロック分記憶する
  2. B入力信号の論理を反転する
  3. C選択信号に応じて、複数の入力から1つを選んで出力する
答えと解説を見る

正解：C. 選択信号に応じて、複数の入力から1つを選んで出力する

マルチプレクサ(セレクタ)は、選択信号の値に応じて複数の入力から1つを選んで出力に伝える回路で、選択信号がnビットなら2ⁿ個の入力から選べます。CPUではレジスタの値の選択やバスの切り替えに使われ、FPGAの論理ブロック(LUT)もメモリとマルチプレクサで任意の論理を実現しています。1つの入力を複数の出力の1つに振り分ける回路はデマルチプレクサです。

よくある質問

8入力のマルチプレクサに必要な選択線は何本ですか?

2³ = 8 なので3本です。一般に、2ⁿ個のデータ入力を持つMUXにはn本の選択線が必要です。

マルチプレクサとデマルチプレクサの違いは?

マルチプレクサは複数の入力から1つを選んで1本の出力に渡す回路です。デマルチプレクサは1つの入力を受け取り、複数の出力のうち1つへ振り分ける回路です。

マルチプレクサで任意の論理関数を作れるのはなぜですか?

選択線を関数の入力変数につなぎ、各データ入力を真理値表に従って0か1に固定すれば、どの入力の組み合わせに対しても真理値表の正しい値が出力されるからです。FPGAのルックアップテーブルはこの仕組みで動いています。

「マルチプレクサ」が出てくる問題(5問)

  1. マルチプレクサの機能として正しいものはどれか。
  2. nMOSとpMOSを並列に接続したトランスミッションゲートの利点として正しいものはどれか。
  3. 同じ型番のI2Cの温度センサを2つ、同じI2Cの線につなぎたいが、どちらも同じアドレスを持っている。対策として正しいものはどれか。
  4. HDLでZ(ハイインピーダンス)を出力するトライステートの記述について、一般的に正しいものはどれか。
  5. 組み合わせ回路で、if・else ifを長くつないだ記述と、条件が互いに重ならないcase文の記述を比べたときの説明として正しいものはどれか。
