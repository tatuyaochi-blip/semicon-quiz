NaNとは

なん

Not a Numberの略で、0 ÷ 0 や負の数の平方根など、結果が数として定まらない演算で生じる浮動小数点の特殊値。指数部がすべて1で仮数が0でない値で表し、NaN どうしを比べても等しくならない。

「NaN」は、1分野の6問の練習問題に出てきます(計算機算術など)。

この用語の分野: 計算機算術

NaNの練習問題に挑戦

x がNaNのとき、多くのプログラミング言語で x == x を評価した結果はどれか。

  1. A真
  2. B偽
  3. C例外が起きてプログラムが必ず停止する
答えと解説を見る

正解：B. 偽

IEEE 754では、NaNは「数ではない」値なので、どんな値との比較でも等しくならず、NaN自身との比較でも x == x は偽になります(x != x は真)。この性質を使って、x != x でNaNかどうかを判定する書き方も使われますが、通常は専用の関数(isnanなど)を使います。NaNは 0 ÷ 0 や ∞ − ∞ などから生まれ、そのあとの計算にも広がっていきます。比較で例外が起きて止まるのは既定の動作ではありません。

解説の中の「NaN」

  • IEEE 754では、NaNは「数ではない」値なので、どんな値との比較でも等しくならず、NaN自身との比較でも x == x は偽になります(x != x は真)。

    x がNaNのとき、多くのプログラミング言語で x == x を評価した結果はどれか。

  • 指数部の0とすべて1(255)は、非正規化数や無限大・NaNのために予約されています。

    IEEE 754の単精度で、指数部に記録される値が130のとき、実際の指数(2の何乗か)はいくつか。

  • なお0 ÷ 0 は値が定まらないのでNaNになります。

    IEEE 754の浮動小数点数の演算で、正の数を0で割ったときの結果として規格で定められているものはどれか。

  • 仮数がすべて0なら、符号ビットに応じて正または負の無限大を表し、仮数が0でなければNaNを表します。

    IEEE 754の単精度で、指数部がすべて1(255)のビット列が表すものの説明として正しいものはどれか。

  • 1億は表せる数で、NaNにはなりません。

    単精度の浮動小数点数で、1億(10⁸)に1を足しても結果が1億のまま変わらない。この現象の説明として正しいものはどれか。

「NaN」が出てくる問題(6問)

  1. x がNaNのとき、多くのプログラミング言語で x == x を評価した結果はどれか。
  2. IEEE 754の単精度で、指数部に記録される値が130のとき、実際の指数(2の何乗か)はいくつか。
  3. IEEE 754の浮動小数点数の演算で、正の数を0で割ったときの結果として規格で定められているものはどれか。
  4. IEEE 754の単精度で、指数部がすべて1(255)のビット列が表すものの説明として正しいものはどれか。
  5. 単精度の浮動小数点数で、1億(10⁸)に1を足しても結果が1億のまま変わらない。この現象の説明として正しいものはどれか。
  6. FP16(符号1・指数部5ビット(バイアス15)・仮数10ビット)で表せる最大の有限の値はいくらか。
