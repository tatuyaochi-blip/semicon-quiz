ミューテックスとは

みゅーてっくす

同時に1つのスレッドだけが持てるロック。取れないときはスレッドを眠らせてCPUを譲り、解放されるとOSが起こす実装が一般的。

「ミューテックス」は、2分野の5問の練習問題に出てきます(組込み・ファームウェア, マルチコアと同期など)。

この用語の分野: マルチコアと同期

ミューテックスの練習問題に挑戦

ミューテックス(眠って待つロック)とスピンロックを比べた説明として正しいものはどれか。

  1. Aミューテックスは待つ間CPUを手放すので長い待ちに向くが、眠ったり起きたりにOSの手間がかかる
  2. Bミューテックスは待つ間もCPUを使い続けるので、短い待ちにしか使えない
  3. Cミューテックスとスピンロックは同じもので、名前が違うだけである
答えと解説を見る

正解：A. ミューテックスは待つ間CPUを手放すので長い待ちに向くが、眠ったり起きたりにOSの手間がかかる

ミューテックスは、ロックが取れないとスレッドを待ち状態にしてCPUをほかのスレッドに譲り、ロックが解放されるとOSが起こします。待つ間にCPUをむだにしないので長い待ちに向きますが、眠る・起きる処理とコンテキストスイッチに数マイクロ秒ほどかかります。実際のライブラリのミューテックスは、少しだけスピンしてから眠るなど、両方の長所を組み合わせています。

解説の中の「ミューテックス」

  • ミューテックスは、ロックが取れないとスレッドを待ち状態にしてCPUをほかのスレッドに譲り、ロックが解放されるとOSが起こします。

    ミューテックス(眠って待つロック)とスピンロックを比べた説明として正しいものはどれか。

  • 長い待ちには、眠って待つミューテックスを使い、短い間だけ回ってから眠る方式もあります。

    スピンロックが向かない場面として最も適切なものはどれか。

  • タスク間でデータを渡すキューや、資源を守るミューテックス、時間を待つ機能なども用意されています。

    組込み機器でRTOS(リアルタイムOS)を使う主な目的はどれか。

  • 低いタスクがミューテックスを持っている間に高いタスクがそれを待つと、高いタスクは低いタスクが手放すまで待ちます。

    RTOSで起こる優先度逆転の説明として正しいものはどれか。

  • 優先度継承では、高いタスクが低いタスクの持つミューテックスを待ち始めたとき、低いタスクの優先度を一時的に高いタスクと同じにします。

    優先度逆転を防ぐために使われる「優先度継承」の考え方として正しいものはどれか。

「ミューテックス」が出てくる問題(5問)

  1. ミューテックス(眠って待つロック)とスピンロックを比べた説明として正しいものはどれか。
  2. スピンロックが向かない場面として最も適切なものはどれか。
  3. 組込み機器でRTOS(リアルタイムOS)を使う主な目的はどれか。
  4. RTOSで起こる優先度逆転の説明として正しいものはどれか。
  5. 優先度逆転を防ぐために使われる「優先度継承」の考え方として正しいものはどれか。
