バスタブ曲線とは

ばすたぶきょくせん

故障率の時間変化を表す曲線。初期故障期・偶発故障期・摩耗故障期からなり、浴槽のような形になる。

「バスタブ曲線」は、3分野の4問の練習問題に出てきます(信頼性, テスト・検査, 歩留まり・品質管理など)。

この用語の分野: 信頼性

バスタブ曲線の練習問題に挑戦

故障率の時間変化を表すバスタブ曲線を構成する3つの期間の組み合わせとして正しいものはどれか。

  1. A初期故障期・偶発故障期・摩耗故障期
  2. B設計期・製造期・出荷期
  3. C試作期・量産期・保守期
答えと解説を見る

正解：A. 初期故障期・偶発故障期・摩耗故障期

バスタブ曲線は、使い始めに製造上の欠陥で故障率が高い初期故障期、故障率が低く一定に近い偶発故障期、劣化によって故障率が上がる摩耗故障期の3つからなり、形が浴槽の断面に似ています。初期故障はバーンインなどで出荷前に取り除き、摩耗故障は製品の想定寿命より後に起こるように設計します。設計・製造・出荷などは製品のライフサイクルの段階で、故障率の期間ではありません。

解説の中の「バスタブ曲線」

  • バスタブ曲線は、使い始めに製造上の欠陥で故障率が高い初期故障期、故障率が低く一定に近い偶発故障期、劣化によって故障率が上がる摩耗故障期の3つからなり、形が浴槽の断面に似ています。

    故障率の時間変化を表すバスタブ曲線を構成する3つの期間の組み合わせとして正しいものはどれか。

  • バスタブ曲線の初期故障期を出荷前に済ませておくことが目的で、車載やサーバー向けなど高い信頼性が必要な製品で行います。

    バーンインの目的として正しいものはどれか。

  • バスタブ曲線は製品の故障率の時間変化を表す信頼性の曲線です。

    新しいプロセスの立ち上げ以降、不良原因の解析と対策を重ねることで、歩留まりが時間とともに向上していく様子を表したものを…

  • バスタブ曲線の3つの期間を1つの分布で表せるのが特長です。

    信頼性データの解析によく使われ、形状パラメータの値によって初期故障型・偶発故障型・摩耗故障型を表せる分布はどれか。

「バスタブ曲線」が出てくる問題(4問)

  1. 故障率の時間変化を表すバスタブ曲線を構成する3つの期間の組み合わせとして正しいものはどれか。
  2. バーンインの目的として正しいものはどれか。
  3. 新しいプロセスの立ち上げ以降、不良原因の解析と対策を重ねることで、歩留まりが時間とともに向上していく様子を表したものを何と呼ぶか。
  4. 信頼性データの解析によく使われ、形状パラメータの値によって初期故障型・偶発故障型・摩耗故障型を表せる分布はどれか。
