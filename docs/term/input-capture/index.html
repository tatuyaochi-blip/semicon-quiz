インプットキャプチャとは

いんぷっときゃぷちゃ

入力の信号が変化した瞬間のタイマのカウンタの値をハードウェアが記録する機能。パルスの幅や周波数を正確に測れる。

「インプットキャプチャ」は、1分野の1問の練習問題に出てきます(組込み・ファームウェアなど)。

この用語の分野: 組込み・ファームウェア

インプットキャプチャの練習問題に挑戦

マイコンのタイマのインプットキャプチャ機能の用途として正しいものはどれか。

  1. A画面の画像を取り込んで保存する
  2. B入力の信号が変化した瞬間のカウンタの値を記録し、パルスの幅や周波数を正確に測る
  3. C出力端子からPWM信号を出す
答えと解説を見る

正解：B. 入力の信号が変化した瞬間のカウンタの値を記録し、パルスの幅や周波数を正確に測る

インプットキャプチャでは、入力の端子の信号が立ち上がったり立ち下がったりした瞬間に、タイマのカウンタの値をハードウェアがレジスタに写し取ります。2回の変化の値の差から、パルスの幅や周期が分かります。ソフトウェアで割り込みを受けてから時刻を読むと処理の遅れで誤差が出ますが、この方法なら遅れに関係なく正確に測れます。回転数のセンサや超音波の距離計などで使われます。
