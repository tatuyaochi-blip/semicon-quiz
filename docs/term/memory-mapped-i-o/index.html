メモリマップドI/Oとは

めもりまっぷどあいおー

周辺装置のレジスタを、メモリと同じアドレス空間の特定のアドレスに割り当て、通常の読み書き命令で操作する方式。その領域はキャッシュしない設定にする。

この用語の分野: OSとハードウェア

解説の中の「メモリマップドI/O」

  • メモリマップドI/Oでは、タイマーやUARTなどの周辺機器の制御レジスタに特定のアドレスを割り当て、通常のロード・ストア命令で操作します。

    マイコンなどで、周辺機器のレジスタをメモリと同じアドレス空間に割り当て、通常のメモリ読み書き命令で操作する方式はどれか。

「メモリマップドI/O」が出てくる問題(2問)

  1. 上のように装置の状態レジスタをメモリマップドI/Oで読むとき、volatileを付け、その領域をキャッシュしない設定にする理由として正しいものはどれか。
  2. マイコンなどで、周辺機器のレジスタをメモリと同じアドレス空間に割り当て、通常のメモリ読み書き命令で操作する方式はどれか。
