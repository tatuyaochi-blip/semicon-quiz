メモリマップドI/Oとは

めもりまっぷどあいおー

周辺装置のレジスタを、メモリと同じアドレス空間の特定のアドレスに割り当て、通常の読み書き命令で操作する方式。その領域はキャッシュしない設定にする。

「メモリマップドI/O」は、2分野の2問の練習問題に出てきます(OSとハードウェア, CPU・アーキテクチャなど)。

この用語の分野: OSとハードウェア

メモリマップドI/Oの練習問題に挑戦

マイコンなどで、周辺機器のレジスタをメモリと同じアドレス空間に割り当て、通常のメモリ読み書き命令で操作する方式はどれか。

  1. A仮想記憶
  2. BメモリマップドI/O
  3. Cキャッシュコヒーレンシ
答えと解説を見る

正解：B. メモリマップドI/O

メモリマップドI/Oでは、タイマーやUARTなどの周辺機器の制御レジスタに特定のアドレスを割り当て、通常のロード・ストア命令で操作します。入出力専用の命令を用意する方式(x86のIN/OUTなどのポートマップドI/O)と比べて命令セットを単純にでき、ARMやRISC-Vのマイコンで標準的です。周辺レジスタはキャッシュさせない、コンパイラに最適化させない(volatile)などの注意が必要です。

解説の中の「メモリマップドI/O」

  • メモリマップドI/Oでは、タイマーやUARTなどの周辺機器の制御レジスタに特定のアドレスを割り当て、通常のロード・ストア命令で操作します。
