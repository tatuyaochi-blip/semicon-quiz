スーパースカラとは

すーぱーすから

1クロックサイクルに複数の命令を同時に発行・実行するプロセッサの方式。複数の演算器を並べ、互いに依存しない命令を並列に処理する。

この用語の分野: CPU・アーキテクチャ

解説の中の「スーパースカラ」

  • スーパースカラは、複数の演算器を備え、互いに依存しない命令を1クロックに複数発行して、IPCを1より大きくする方式です。

    1クロックサイクルに複数の命令を同時に発行・実行するプロセッサの方式を何と呼ぶか。

  • CPIが1未満なのは、スーパースカラで1クロックに複数の命令を実行しているためです。

    クロック周波数2 GHz、平均CPI(1命令あたりの平均クロック数)0.5のプロセッサが、1秒間に実行できる命令数はお…

  • スーパースカラ、アウトオブオーダー実行、分岐予測、大きなキャッシュはすべてIPCを高める技術です。

    1クロックあたりに実行できる命令数を表す指標はどれか。

「スーパースカラ」が出てくる問題(4問)

  1. 1クロックサイクルに複数の命令を同時に発行・実行するプロセッサの方式を何と呼ぶか。
  2. クロック周波数2 GHz、平均CPI(1命令あたりの平均クロック数)0.5のプロセッサが、1秒間に実行できる命令数はおよそいくらか。
  3. 1クロックあたりに実行できる命令数を表す指標はどれか。
  4. 命令の長さを固定長にすることの利点として、最も適切なものはどれか。
