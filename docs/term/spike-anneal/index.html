スパイクアニールとは

すぱいくあにーる

ウエハを急速に高温まで上げ、その温度にほとんど保持せずにすぐ下げる熱処理。不純物の拡散を抑えながら活性化でき、浅い接合の形成に使われる。

「スパイクアニール」は、1分野の2問の練習問題に出てきます(イオン注入など)。

この用語の分野: イオン注入

スパイクアニールの練習問題に挑戦

微細なトランジスタのソース・ドレインに浅い接合をつくるための工夫として正しいものはどれか。

  1. A高エネルギーで注入し、長時間の炉アニールを行う
  2. Bイオン注入を使わず、熱酸化だけで形成する
  3. C低エネルギーで注入し、ごく短時間で加熱するアニール(スパイクアニールやレーザーアニールなど)を行う
答えと解説を見る

正解：C. 低エネルギーで注入し、ごく短時間で加熱するアニール(スパイクアニールやレーザーアニールなど)を行う

浅い接合をつくるには、まず1 keV以下などの低エネルギーで浅く注入します。さらにアニールで不純物が拡散して接合が深くならないよう、最高温度で保持せずにすぐ下げるスパイクアニール(約1050 ℃、秒以下)や、ミリ秒以下で表面だけを加熱するフラッシュランプアニール・レーザーアニールを使い、拡散を数nmに抑えながら活性化させます。共注入やプリアモルファス化も組み合わせます。

イオン注入後のアニールの初期に、注入で生じた格子間シリコンの影響で、ボロンなどの拡散が一時的に速くなる現象を何と呼ぶか。

  1. A過渡増速拡散(TED)
  2. Bゲッタリング
  3. C偏析
答えと解説を見る

正解：A. 過渡増速拡散(TED)

イオン注入で生じた過剰な格子間シリコン原子は、ボロンと組になってボロンの拡散を助けるため、アニールの初期に拡散が数十倍から千倍程度も一時的に増速します。格子間シリコンが表面などで消えると収まるため「過渡」増速拡散(TED)と呼ばれ、比較的低温で長く加熱するほど影響が大きくなります。浅い接合の妨げになるため、急速に高温にするスパイクアニールや炭素の共注入で抑えます。
