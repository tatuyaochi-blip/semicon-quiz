FMA(融合積和演算)とは

えふえむえー

a × b + c を1つの命令で計算し、途中の積を丸めずに最後に1回だけ丸める演算。掛け算と足し算を別々に行うより速く、誤差も小さい。行列の計算などで多用される。

この用語の分野: 計算機算術

解説の中の「FMA(融合積和演算)」

  • FMAは積を丸めずに内部で保持したまま c を足し、最後に1回だけ丸めるので、誤差が小さくなります。

    FMA(融合積和演算)命令で a × b + c を計算する利点として正しいものはどれか。

  • 同じ計算でもCPUによって使える命令は異なり、例えば a * b + c を、CPUに積和演算(FMA)の命令があれば1命令で、なければ掛け算と足し算の2命令で実現します。

    コード生成の段階の一つである命令選択(インストラクションセレクション)の説明として正しいものはどれか。
