RPO(目標復旧時点)とは

あーるぴーおー

障害や災害が起きたときに、どの時点の状態までデータを復旧できればよいかを表す目標(Recovery Point Objective)。RPOが1時間なら、失ってよいデータは直前の1時間分までで、少なくとも1時間ごとにバックアップやデータの複製を取る必要がある。

「RPO(目標復旧時点)」は、2分野の3問の練習問題に出てきます(システム構成と信頼性設計, サービスマネジメントとシステム監査など)。

この用語の分野: システム構成と信頼性設計

RPOとRTO

RPOは「どの時点まで戻せればよいか」、つまり失ってよいデータの量を時間で表した目標です。RTO(目標復旧時間)は「どれだけの時間で再開できればよいか」を表す目標です。例えば、RPOが4時間、RTOが2時間なら、障害が起きても4時間より前のデータは失わず、2時間以内に業務を再開する必要があります。2つは別の目標なので、両方を満たす方式を選ぶ必要があります。

RPOを満たす方法

定期的なバックアップだけで守る場合、障害が次のバックアップの直前に起きると、バックアップの間隔の分のデータが失われます。そのため、バックアップの間隔をRPO以下にします。RPOを数分や0に近づけたい場合は、データベースの更新のログをこまめに別の場所に送ったり、別のサーバにデータを複製するレプリケーションを使ったりします。

同期と非同期のレプリケーション

同期レプリケーションは、複製先でも書き込みが終わったことを確かめてから更新を完了させるので、障害時にデータを失いません(RPOが0)。その代わり、複製先までの往復の通信の時間が更新のたびに加わるので、遠く離れた場所の間では応答が遅くなります。非同期レプリケーションは複製を後から送るので応答は速いものの、障害時にまだ送っていない分のデータを失うことがあります。

RPO(目標復旧時点)の練習問題に挑戦

事業継続の計画でいうRPO(目標復旧時点)の説明として、適切なものはどれか。

  1. A障害が起きたとき、どの時点までのデータを復旧できればよいか(どれだけ前までのデータの損失を許すか)を表す目標
  2. B障害が起きてから、業務やシステムを再開するまでに許される時間の目標
  3. Cシステムが故障してから、次に故障するまでの平均の時間

正解：A. 障害が起きたとき、どの時点までのデータを復旧できればよいか(どれだけ前までのデータの損失を許すか)を表す目標

RPO(Recovery Point Objective、目標復旧時点)は、障害が起きたときに、どの時点の状態までデータを戻せればよいかを表す目標です。例えばRPOが1時間なら、障害の直前1時間以内の時点まで戻せる必要があり、少なくとも1時間ごとにバックアップやデータの複製を取る必要があります。業務を再開するまでに許される時間はRTO(Recovery Time Objective、目標復旧時間)で、RPOとRTOを短くするほど、必要な設備の費用は大きくなります。

あるシステムで、RPO(目標復旧時点)を4時間、RTO(目標復旧時間)を2時間と定めた。障害はいつでも起こりうるものとし、バックアップの取得にかかる時間は無視できるものとする。この目標を満たすデータの保護の方式として、適切なものはどれか。

  1. A1時間ごとにバックアップを取り、障害が起きたときは復旧に3時間かかる
  2. B3時間ごとにバックアップを取り、障害が起きたときは復旧に1.5時間かかる
  3. C6時間ごとにバックアップを取り、障害が起きたときは復旧に1時間かかる
答えと解説を見る

正解：B. 3時間ごとにバックアップを取り、障害が起きたときは復旧に1.5時間かかる

障害が次のバックアップの直前に起きると、直前のバックアップの間隔の分だけデータが失われるので、RPOを満たすにはバックアップの間隔をRPO以下にする必要があります。また、復旧にかかる時間はRTO以下でなければなりません。3時間ごとのバックアップで復旧に1.5時間なら、失われるのは最大3時間分(4時間以下)、復旧は1.5時間(2時間以下)で、両方を満たします。1時間ごとの方式はRTOを、6時間ごとの方式はRPOを満たしません。

よくある質問

RPOとRTOは短いほどよいのですか?

短いほど障害の影響は小さくなりますが、レプリケーションや待機系の設備、運用の手間などの費用が大きくなります。業務が止まったりデータを失ったりしたときの損失と、対策の費用を比べて、業務ごとに決めるのが一般的です。

RPOが0のシステムは作れますか?

同期レプリケーションを使えば、障害が起きた時点までのデータを失わない構成にできます。ただし、誤った操作やソフトウェアの不具合でデータが壊れた場合は、その壊れた状態もそのまま複製されるので、過去の時点に戻せるバックアップも別に必要です。
