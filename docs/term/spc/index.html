SPC(統計的工程管理)とは

えすぴーしー

工程のデータを管理図などで監視し、統計的に異常を見つけて品質を保つ方法。

「SPC(統計的工程管理)」は、2分野の4問の練習問題に出てきます(環境安全, 歩留まり・品質管理など)。

この用語の分野: 歩留まり・品質管理

SPC(統計的工程管理)の練習問題に挑戦

前の工程の計測結果などをもとに、次のロットやウエハの装置の加工条件を自動で補正する制御はどれか。

  1. AFMEA
  2. Bパレート分析
  3. CAPC(Run-to-Run制御など)
答えと解説を見る

正解：C. APC(Run-to-Run制御など)

APC(Advanced Process Control)は、計測データを使って装置の条件を自動で調整し、工程のばらつきを小さくする制御です。代表的なRun-to-Run制御では、例えば前の工程で測った膜厚が厚ければ、次のCMPの時間を延ばします。異常を監視して止めるSPCに対し、積極的に補正して中心に寄せる手法です。FMEAは事前のリスク評価、パレート分析は重点項目の発見に使います。

有害な化学物質を扱う作業場で、空気中の有害物質の濃度などを定期的に測って作業環境を評価することを何と呼ぶか。

  1. A製品検査
  2. B作業環境測定
  3. C統計的工程管理
答えと解説を見る

正解：B. 作業環境測定

作業環境測定は、作業場の空気中の有害物質の濃度などを測定し、作業者の健康を守るための環境が保たれているかを評価するものです。日本では労働安全衛生法で対象となる作業場や測定の頻度が定められ、資格をもつ作業環境測定士が行います。結果は管理区分で評価され、悪い場合は局所排気装置の改善などの対策を行います。製品検査やSPCは品質の管理の手法です。

「SPC(統計的工程管理)」が出てくる問題(4問)

  1. 前の工程の計測結果などをもとに、次のロットやウエハの装置の加工条件を自動で補正する制御はどれか。
  2. 有害な化学物質を扱う作業場で、空気中の有害物質の濃度などを定期的に測って作業環境を評価することを何と呼ぶか。
  3. 化学物質を使う作業について、危険性や有害性を特定し、そのリスクの大きさを見積もって対策を決める取り組みを何と呼ぶか。
  4. 作業を始める前に、その作業に潜む危険を話し合い、対策を確認する活動を何と呼ぶか。
