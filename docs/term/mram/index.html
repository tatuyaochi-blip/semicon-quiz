MRAMとは

えむらむ

磁気トンネル接合(MTJ)の磁化の向きによる抵抗の違いで情報を記憶する不揮発性メモリ。

「MRAM」は、2分野の19問の練習問題に出てきます(次世代メモリ, SRAM・フラッシュメモリなど)。

この用語の分野: 次世代メモリ

磁気トンネル接合がビットを記憶するしくみ

記憶素子は磁気トンネル接合(MTJ)です。磁化の向きが固定された参照層と、向きを反転できる自由層という二つの強磁性層が、厚さ約 1 nm の絶縁性トンネル障壁を挟んでいます。二つの磁化が平行なら電子はトンネルしやすく低抵抗、反平行なら高抵抗となり、このトンネル磁気抵抗(TMR)で0と1を区別します。結晶性の MgO 障壁では TMR 比が数百%に達し、アモルファス Al2O3 の数十%を大きく上回ります。読み出しは小さな電流を流して参照値と比較するだけで、磁化を乱さないため書き戻しは不要です。

スピン注入トルクによる書き込み

STT-MRAM(スピン注入磁化反転型 MRAM)では、書き込み電流を MTJ 自体に流します。参照層でスピン偏極した電子が自由層に角運動量を渡して磁化を反転させ、電流の向きで状態が決まります。近くの配線がつくる磁界で書き込んでいた初期の MRAM と違い、STT の書き込み電流はセル面積とともに小さくなるため、微細化が可能です。限界となるのは熱安定性です。エネルギー障壁は磁気異方性と自由層の体積の積で、これと kT の比 Δ が10年保持にはおよそ60以上必要です。Δ を上げると書き込み電流も増えるため、両者を両立させるのに垂直磁化材料が使われます。

ロジックチップへの混載

MTJ はトランジスタ形成後の配線工程(BEOL)で、配線層の間に数枚のマスク追加だけでつくり込めます。一方、混載フラッシュはフローティングゲートのために10枚以上のマスクを追加する必要があり、約 28 nm より先や high-k/メタルゲートとの組み合わせでは現実的でなくなります。そのため 22 nm 以下のマイコンや車載チップでは、MRAM が混載フラッシュの有力な後継とされています。集積上の課題は、約 400 ℃ の BEOL 熱工程に耐えることと、金属の再付着を起こさずに磁性膜を加工することで、加工には一般にイオンビームエッチングが使われます。

ほかのメモリとの比較

フラッシュと比べると、MRAM は消去なしに数〜数十 ns で書き込め、書き換え耐性は NAND の数千〜数万回に対し 10¹⁰ 回を超えます。DRAM や SRAM と違って不揮発です。弱点は密度と読み出しマージンです。セルが NAND より大きく3次元積層もできないためビット単価ははるかに高く、抵抗比が2〜3倍しかないため読み出しマージンも DRAM やフラッシュより小さくなります。なお FeRAM は強誘電体の分極で、相変化メモリは結晶とアモルファスの抵抗差でデータを記憶します。

MRAMの練習問題に挑戦

MRAMの記憶原理として正しいものはどれか。

  1. A磁気トンネル接合(MTJ)の磁化の向きによる抵抗の違い
  2. Bカルコゲナイド材料の結晶状態とアモルファス状態の抵抗の違い
  3. Cキャパシタに蓄えた電荷の有無
答えと解説を見る

正解：A. 磁気トンネル接合(MTJ)の磁化の向きによる抵抗の違い

MRAMは、2つの磁性層で厚さ1 nm程度の絶縁層をはさんだ磁気トンネル接合(MTJ)を使います。磁化の向きが平行なら抵抗が低く、反平行なら高くなるトンネル磁気抵抗効果で0と1を区別し、磁化は電源なしで保たれるため不揮発です。書き換え回数がほぼ無制限で高速な点が強みです。結晶とアモルファスの抵抗差を使うのは相変化メモリ、電荷を使うのはDRAMです。

フラッシュメモリと比べたときのMRAMの一般的な利点として正しいものはどれか。

  1. A1ビットあたりのコストがはるかに低い
  2. B電源を切るとデータが消える
  3. C書き換え可能回数が非常に多く、書き込みも高速である
答えと解説を見る

正解：C. 書き換え可能回数が非常に多く、書き込みも高速である

MRAMは磁化の向きで記憶するため、酸化膜の劣化を伴うフラッシュより書き換え回数がはるかに多く(10¹⁰回以上)、書き込みも数〜数十nsと高速で、消去の手順も不要です。そのためマイコンや車載機器の組み込みメモリ、データを頻繁に記録する用途に採用が進んでいます。一方、セルが大きく積層もできないため、大容量化やビット単価ではNANDフラッシュに遠く及びません。

よくある質問

MRAM は揮発性ですか、不揮発性ですか?

不揮発性です。データは自由層の磁化の向きとして保持され、電源がなくても通常10年以上保たれます。これに加えて高速な書き込みと非常に高い書き換え耐性を備えています。

STT-MRAM とトグル MRAM の違いは何ですか?

トグル MRAM(磁界書き込み型)は近くの配線に流す電流の磁界で自由層を反転させるため、セルが小さくなるほど多くの電流が必要になります。STT-MRAM はスピン偏極した電流を MTJ に直接流すので、書き込み電流がセルサイズとともに小さくなります。

MRAM が混載フラッシュに置き換わりつつあるのはなぜですか?

混載フラッシュは工程の追加が多く、約 28 nm より先や high-k/メタルゲートとの集積が難しいためです。MRAM は配線層に数枚のマスク追加でつくれ、書き込みも速く、書き換え耐性も高いという利点があります。
