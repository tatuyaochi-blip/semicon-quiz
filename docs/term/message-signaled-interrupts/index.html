MSI(メッセージシグナル割り込み)とは

えむえすあい

機器が決められた番地への書き込みを行うことで割り込みを知らせる方式。専用の割り込み線が不要で、1つの機器が多くの割り込みを持てる。

「MSI(メッセージシグナル割り込み)」は、1分野の1問の練習問題に出てきます(インターフェース・バス規格など)。

この用語の分野: インターフェース・バス規格

MSI(メッセージシグナル割り込み)の練習問題に挑戦

PCI Expressで使われるMSI(メッセージシグナル割り込み)の特徴として正しいものはどれか。

  1. A割り込みのたびに、機器が電話をかけてCPUに知らせる
  2. B割り込みを使わず、CPUが常に機器の状態を調べ続ける
  3. C機器が決められた番地へ書き込みを行うことで割り込みを知らせ、専用の割り込み線が不要になる
答えと解説を見る

正解：C. 機器が決められた番地へ書き込みを行うことで割り込みを知らせ、専用の割り込み線が不要になる

昔の機器は、割り込みを知らせるための専用の線を持ち、複数の機器で線を共有することもありました。MSIでは、機器がOSに指定された番地へ決められたデータを書き込むと、それが割り込みとしてCPUに届きます。線の数の制約がないので、1つの機器が多くの割り込みを持て、例えばネットワークカードが受信の待ち行列ごとに別の割り込みを別のコアへ送れます。

解説の中の「MSI(メッセージシグナル割り込み)」

  • MSIでは、機器がOSに指定された番地へ決められたデータを書き込むと、それが割り込みとしてCPUに届きます。
