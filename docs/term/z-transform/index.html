z変換とは

ぜっとへんかん

離散時間の信号 x[n] を、複素数 z の関数 X(z) = Σx[n]z^(−n) に変換する方法。1サンプルの遅れは z⁻¹ を掛けることに当たるので、差分方程式を z の分数式(伝達関数 H(z))として扱える。H(z) の分母を0にする z を極、分子を0にする z を零点と呼び、因果的なシステムはすべての極が単位円の内側にあるとき安定である。z = e^(jω) とおいて単位円の上で評価すると、周波数応答が得られる。連続時間のラプラス変換に当たる道具である。

「z変換」は、1分野の1問の練習問題に出てきます(デジタル信号処理の基礎など)。

差分方程式から伝達関数へ

例えば y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1] の両辺をz変換すると Y(z) = X(z) + 0.5z⁻¹X(z) + 0.25z⁻¹Y(z) となり、整理すると H(z) = (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹) です。分子が入力の側、分母が出力の帰還の側を表し、係数をそのまま読み替えるだけで、フィルタの構造と伝達関数を行き来できます。

極・零点と周波数特性

ある周波数での利得の大きさは、単位円の上の点 e^(jω) から各零点までの距離の積を、各極までの距離の積で割ったものに比例します。そのため、零点が単位円の上にあればその周波数の利得は0になり(ノッチ)、極が単位円の近くにあればその周波数の付近で利得が大きく持ち上がります。極と零点の配置を見るだけで、フィルタの特性のおおよその形がわかります。

安定性の判定

因果的なシステムのインパルス応答は、極 p ごとに pⁿ の形の成分を含むので、|p| < 1 なら時間とともに小さくなり、|p| > 1 なら大きくなり続けます。すべての極が単位円の内側にあることが安定の条件で、単位円の上にある極(例えば累算器の z = 1)をもつシステムは、有界な入力に対して出力が際限なく増えることがあるので、BIBO安定ではありません。

z変換の練習問題に挑戦

差分方程式 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1] で表されるシステムの伝達関数 H(z) = Y(z)/X(z) として正しいものはどれか。

  1. A(1 + 0.5z⁻¹)/(1 + 0.25z⁻¹)
  2. B(1 − 0.25z⁻¹)/(1 + 0.5z⁻¹)
  3. C(1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)
答えと解説を見る

正解：C. (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)

1サンプルの遅れは、z変換では z⁻¹ を掛けることに当たるので、両辺をz変換すると Y(z) = X(z) + 0.5z⁻¹X(z) + 0.25z⁻¹Y(z) です。Y(z) の項を左辺に集めると (1 − 0.25z⁻¹)Y(z) = (1 + 0.5z⁻¹)X(z) となり、H(z) = (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹) です。分子は入力の側、分母は出力の帰還の側の係数を表し、分母を0にする z = 0.25 が極、分子を0にする z = −0.5 が零点です。

よくある質問

z変換とフーリエ変換はどう関係していますか?

z変換で z = e^(jω)(単位円の上)とおいたものが、離散時間フーリエ変換(DTFT)です。z変換は、単位円の内側や外側も含めて z を広く考えることで、極や零点の位置からシステムの安定性や特性を議論できるようにしたものです。有限の長さの信号のDFTは、DTFTを単位円の上の N 個の等間隔の点で求めたものに当たります。

なぜ z⁻¹ が「1サンプルの遅れ」なのですか?

x[n − 1] のz変換は Σx[n − 1]z^(−n) で、m = n − 1 と置き換えると z⁻¹Σx[m]z^(−m) = z⁻¹X(z) になるからです。このため、ブロック図では遅延素子を「z⁻¹」と書き、デジタルフィルタを、掛け算・足し算・z⁻¹ の組み合わせで表します。
