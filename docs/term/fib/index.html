FIB(集束イオンビーム)とは

えふあいびー

細く絞ったイオンビームで試料を削ったり膜をつけたりする装置。微小な領域の断面加工、TEM用の薄い試料の作製、回路の修正などに使われる。

「FIB(集束イオンビーム)」は、1分野の4問の練習問題に出てきます(計測・分析など)。

この用語の分野: 計測・分析

FIB(集束イオンビーム)の練習問題に挑戦

集束イオンビーム(FIB)装置の主な用途はどれか。

  1. A微小な領域の加工、断面試料の作製、回路の修正
  2. Bウエハ全面の膜厚測定
  3. Cウエハの洗浄
答えと解説を見る

正解：A. 微小な領域の加工、断面試料の作製、回路の修正

FIBは、ガリウムなどのイオンを細く絞って試料に当て、狙った位置をナノメートル単位で削ったり、原料ガスと組み合わせて白金やタングステンの膜を堆積させたりできる装置です。TEM用の薄片の作製、不良箇所の断面観察、試作チップの配線を切ってつなぎ直す回路修正などに使われます。SEMと一体になった装置なら、削りながら観察できます。全面の膜厚測定や洗浄はしません。

解説の中の「FIB(集束イオンビーム)」

  • FIBは、ガリウムなどのイオンを細く絞って試料に当て、狙った位置をナノメートル単位で削ったり、原料ガスと組み合わせて白金やタングステンの膜を堆積させたりできる装置です。

    集束イオンビーム(FIB)装置の主な用途はどれか。

  • 半導体デバイスでは、FIBで観察したい場所の周りを削り、薄片を取り出して仕上げるリフトアウト法がよく使われます。

    透過電子顕微鏡(TEM)で試料を観察するために必要な前処理として正しいものはどれか。

  • 断面のSEMやTEMの観察では、ウエハを割ったりFIBで加工したりするため、観察した部分は製品として使えなくなります(破壊検査)。

    断面の形をくわしく調べるために、ウエハを割ったり削ったりしてから観察する方法の特徴として正しいものはどれか。

  • アトムプローブでは、FIBで先端を100 nm程度の針状に加工した試料に高い電圧とパルスをかけて、先端の原子を1個ずつイオンとして飛ばします。

「FIB(集束イオンビーム)」が出てくる問題(4問)

  1. 集束イオンビーム(FIB)装置の主な用途はどれか。
  2. 透過電子顕微鏡(TEM)で試料を観察するために必要な前処理として正しいものはどれか。
  3. 断面の形をくわしく調べるために、ウエハを割ったり削ったりしてから観察する方法の特徴として正しいものはどれか。
  4. 針状に加工した試料の先端から原子を1個ずつ電界で蒸発させ、その位置と種類を検出して、ドーパントなどの3次元の原子の分布を調べる分析法はどれか。
