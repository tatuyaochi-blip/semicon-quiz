仮想短絡(イマジナリーショート)とは

かそうたんらく

負帰還をかけた理想オペアンプで、2つの入力端子の電圧がほぼ等しくなる性質。電流は流れないのに短絡したように扱えるため、増幅回路の利得を簡単に求められる。

「仮想短絡(イマジナリーショート)」は、1分野の2問の練習問題に出てきます(アナログ・電子回路など)。

この用語の分野: アナログ・電子回路

2つの入力が等しくなる理由

オペアンプの出力はVout = A(V+ − V−)で表され、開ループ利得Aは非常に大きく、一般的な実際のデバイスでは低周波で約10⁵〜10⁶です。負帰還をかけると回路は出力が有限の値になるところで落ち着くので、入力の差はVout/Aでなければなりません。出力が10 VでA = 10⁵なら、入力の差はわずか100 µVです。理想的な解析ではAを無限大とするので差はゼロとなり、2つの入力は同じ電圧にあるものとして扱えます。

使い方:反転増幅回路

反転増幅回路では非反転入力がグラウンドに接続されているので、仮想短絡によって反転入力も0 Vになります。この特別な場合を仮想接地(バーチャルグラウンド)と呼びます。このとき入力電流はVin/R1です。理想オペアンプの入力には電流が流れ込まないので、この電流はすべて帰還抵抗Rfを流れ、Vout = −(Rf/R1)·Vinとなります。同じ2つのルールから、非反転増幅回路の利得1 + Rf/R1も求められ、加算回路、積分回路、差動増幅回路も解析できます。

仮想短絡と本当の短絡の違い

本当の短絡なら入力端子の間に電流が流れますが、仮想短絡では流れません。そのため解析では、理想オペアンプの2つの別々の仮定を組み合わせて使います。1つは、負帰還と高い利得によって入力同士が同じ電圧になること、もう1つは、入力インピーダンスが無限大なのでどちらの入力にも電流が流れ込まないことです。たとえば一方の入力から他方へ電流が流れるとするなど、この2つを混同すると誤った答えになります。電圧が等しく保たれるのは出力が能動的に働いているからであり、何かでつながっているからではありません。

仮定が成り立たない場合

仮想短絡が成り立つのは負帰還が働いている間だけです。出力が電源電圧に張り付いて飽和したとき、スルーレートで制限されているとき、あるいは信号周波数が高くループゲインが下がっているときには、入力同士の電圧がずれます。コンパレータやシュミットトリガは開ループや正帰還で動作するため、入力同士は意図的に異なる電圧になります。また実際のオペアンプには数µVから数mVの入力オフセット電圧があり、入力間の小さな一定の差として現れます。

仮想短絡(イマジナリーショート)の練習問題に挑戦

理想オペアンプの特性として正しい組み合わせはどれか。

  1. A入力インピーダンス:無限大、出力インピーダンス:0
  2. B入力インピーダンス:0、出力インピーダンス:無限大
  3. C入力インピーダンス:0、出力インピーダンス:0
答えと解説を見る

正解：A. 入力インピーダンス:無限大、出力インピーダンス:0

理想オペアンプは、入力インピーダンスが無限大(入力端子に電流が流れない)、出力インピーダンスが0(負荷によらず出力電圧が決まる)、開ループ利得が無限大として扱います。この仮定から、負帰還回路では2つの入力端子の電圧が等しくなる「仮想短絡」が成り立ち、回路の利得が抵抗の比だけで決まります。実物の開ループ利得は10⁵〜10⁶程度で、周波数とともに下がります。

負帰還をかけた理想オペアンプ回路で、2つの入力端子の電圧がほぼ等しくなる性質を何と呼ぶか。

  1. Aスルーレート
  2. Bオフセット
  3. C仮想短絡(イマジナリーショート)
答えと解説を見る

正解：C. 仮想短絡(イマジナリーショート)

開ループ利得Aが非常に大きいオペアンプに負帰還をかけると、出力が有限の値でつり合うために入力端子間の電圧差は Vout/A とほぼ0になります。実際につながっていないのに短絡したように見えるため仮想短絡と呼び、非反転入力が接地されていれば反転入力も0 V(仮想接地)とみなせます。オペアンプ回路の解析の基本ですが、出力が飽和したときや正帰還の回路(コンパレータ)では成り立ちません。

よくある質問

仮想短絡と仮想接地の違いは何ですか?

仮想短絡は、負帰還のもとで両方の入力が同じ電圧になるという一般的な性質です。仮想接地はその中で一方の入力がグラウンドに接続されている場合で、もう一方の入力が0 Vに保たれます。

仮想短絡では電流が流れますか?

流れません。入力同士は同じ電圧ですがつながってはおらず、理想オペアンプは入力電流を引き込みません。

コンパレータで仮想短絡が使えないのはなぜですか?

コンパレータには負帰還がないため、出力は電源電圧まで振り切れ、入力を同じ電圧にそろえる働きがないからです。
