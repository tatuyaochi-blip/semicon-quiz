DRAM(ダイナミックRAM)とは

でぃーらむ

1個のトランジスタと1個のキャパシタで1ビットを記憶し、電荷が漏れて消える前に定期的なリフレッシュが必要な揮発性メモリ。パソコンやサーバーの主記憶に使われる。

「DRAM(ダイナミックRAM)」は、16分野の91問の練習問題に出てきます(DRAM, 次世代メモリ, 半導体産業・市場など)。

この用語の分野: DRAM

DRAMの名前と基本構造

DRAMはDynamic Random Access Memoryの略で、日本語ではダイナミックRAMと呼びます。1個のトランジスタと1個のキャパシタからなる1T1Cセルで1ビットを記憶し、キャパシタに電荷があるかないかで0と1を表します。セルはワード線とビット線の交点に格子状に並び、ワード線でトランジスタをオンにするとキャパシタがビット線につながります。「ランダムアクセス」は、どの番地にも順番によらずアクセスできることを指し、「ダイナミック」は、記憶した電荷がリークで少しずつ失われるため、定期的に書き直す必要があることに由来します。

読み出しとリフレッシュ

読み出しでは、あらかじめ電源電圧の半分程度にプリチャージしたビット線にセルのキャパシタをつなぎ、電荷を分け合って生じる小さな電圧差をセンスアンプで増幅して0か1かを判定します。このときセルの電荷は崩れるため(破壊読み出し)、増幅した電圧でセルに書き戻します。電荷は接合リークやサブスレッショルドリークでも失われるので、一定時間ごとに全行を読み出して書き直すリフレッシュが必要です。目安として、DDR4までの規格では通常の温度範囲で64 ms以内、DDR5では32 ms以内に全行を一巡させ、高温ではさらに間隔を短くします。

SRAM・フラッシュメモリとの違い

SRAMは6個のトランジスタでラッチを組むためリフレッシュが不要で、1 ns前後でアクセスできますが、セル面積が大きくビットあたりのコストが高くなります。DRAMは1T1Cの小さなセルでSRAMより20倍前後高密度にでき、大容量の主記憶に向きます。その代わり、行の活性化などのためにアクセスに数十nsかかります。NAND型フラッシュメモリは電源を切ってもデータが残る不揮発性メモリで、さらに大容量・低コストですが、書き込みや消去が遅く、書き換え回数にも上限があります。そのため、キャッシュにSRAM、主記憶にDRAM、ストレージにSSDを使う記憶階層が組まれます。

製品の種類と微細化の課題

DRAMの製品は、パソコンやサーバー向けのDDR SDRAM、スマートフォンなど向けに消費電力を抑えたLPDDR、グラフィックス向けのGDDR、複数のダイをTSVで積み重ねて非常に広いバス幅をもたせたHBMなどに分かれます。微細化では、セルが小さくなってもデータを判定できるだけの電荷をキャパシタに蓄えることが課題で、細く深い円筒形のキャパシタ、高誘電率(high-k)の絶縁膜、リークを抑える埋め込みワード線のトランジスタなどが導入されてきました。隣の行を繰り返し活性化するとデータが反転するロウハンマーのように、高密度化に伴う信頼性の問題もあります。

DRAM(ダイナミックRAM)の練習問題に挑戦

一般的なDRAMの1ビットのメモリセルの構成として正しいものはどれか。

  1. Aトランジスタ1個とキャパシタ1個
  2. Bトランジスタ6個
  3. Cフローティングゲートをもつトランジスタ1個
答えと解説を見る

正解：A. トランジスタ1個とキャパシタ1個

DRAMのセルはトランジスタ1個とキャパシタ1個(1T1C)で、キャパシタの電荷の有無で1ビットを記憶します。キャパシタは約10 fF前後と非常に小さく、わずか数万個の電子の差で0と1を区別しています。素子数が少ないためセル面積は約6F²と小さく、大容量化に向きます。トランジスタ6個はSRAM、フローティングゲートのトランジスタはフラッシュメモリのセル構成です。

DRAMで定期的なリフレッシュ動作が必要になる理由として正しいものはどれか。

  1. A読み出し速度を上げるため
  2. B書き込み回数に上限があるため
  3. Cキャパシタに蓄えた電荷がリーク電流によって徐々に失われるため
答えと解説を見る

正解：C. キャパシタに蓄えた電荷がリーク電流によって徐々に失われるため

キャパシタの電荷は、セルトランジスタのサブスレッショルドリークや接合リークで少しずつ失われます。データが判定できなくなる前に読み出して書き直すのがリフレッシュで、DDR4までの規格では64 ms以内、DDR5では32 ms以内に全行を一巡します。リフレッシュ中はそのバンクにアクセスできず、電力も消費するため、容量が増えるほど負担が大きくなります。書き込み回数の上限はフラッシュメモリの特徴です。

よくある質問

DRAMは何の略ですか?

Dynamic Random Access Memoryの略です。記憶した電荷が時間とともに失われるため定期的なリフレッシュが必要なことから「ダイナミック」と呼ばれ、電源が入っている間はリフレッシュなしでデータを保つSRAM(Static RAM)と区別されます。

DRAMとSRAMの違いは何ですか?

DRAMは1T1Cの小さなセルで大容量・低コストにできる一方、リフレッシュが必要で、アクセスに数十nsかかります。SRAMは6トランジスタのセルでリフレッシュが不要で高速ですが、面積が大きくなります。そのため主記憶にはDRAM、CPUのキャッシュにはSRAMが使われます。

DRAMは電源を切るとデータが消えますか?

消えます。DRAMは揮発性メモリで、電源を切るとリフレッシュが止まり、電荷がリークで失われます。ただし冷却すると数秒〜数分程度データが残ることがあり、これを悪用してメモリ内の暗号鍵を読み出すコールドブート攻撃が知られています。
