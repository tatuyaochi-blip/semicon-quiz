メモリリークとは

めもりりーく

malloc などで確保したメモリを、使い終わっても free で解放せず、その領域を指すポインタも失ってしまうことで、使えるメモリが減っていく不具合。エラーで途中から戻る道で解放を忘れる場合が多い。短いプログラムでは終了時にOSが回収するので目立たないが、長い間動き続けるサーバや組込み機器では、少しずつ空きが減って最後に確保に失敗する。Valgrind や AddressSanitizer(LeakSanitizer)などで検出できる。

「メモリリーク」は、2分野の2問の練習問題に出てきます(C言語の基礎, リンカ・ローダと実行形式など)。

メモリリークの練習問題に挑戦

C言語のmallocで確保したメモリは、一般にプロセスのどの領域から取られるか。

  1. A.textセクション
  2. Bヒープ
  3. C.rodataセクション
答えと解説を見る

正解：B. ヒープ

ヒープは、プログラムの実行中に必要な大きさのメモリを確保し、不要になったらfreeで返す領域です。確保する大きさや寿命を実行時に決められるのが特徴です。mallocは自分で空き領域を管理し、足りなくなるとOSに頼んで領域を広げます(Linuxではbrkやmmapのシステムコール)。freeし忘れると、使わないメモリが残り続けるメモリリークになります。
