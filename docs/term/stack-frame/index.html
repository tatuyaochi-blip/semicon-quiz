スタックフレームとは

すたっくふれーむ

関数が呼ばれるたびにスタック上に確保する領域。戻り先、保存したレジスタ、局所変数などを置き、関数から戻るときに解放する。

「スタックフレーム」は、3分野の5問の練習問題に出てきます(命令セット・アセンブリ, コンパイラ, リンカ・ローダと実行形式など)。

この用語の分野: 命令セット・アセンブリ

スタックフレームの練習問題に挑戦

ほかの関数を呼ばない関数(葉関数、リーフ関数)では、raをスタックに保存しなくてよい場合が多い。その理由として正しいものはどれか。

  1. A葉関数ではret命令を使わないから
  2. B葉関数の戻り先は、CPUが自動でスタックに積むから
  3. Cほかの関数を呼ばないので、raが上書きされず、戻り先がそのまま残るから
答えと解説を見る

正解：C. ほかの関数を呼ばないので、raが上書きされず、戻り先がそのまま残るから

raは関数を呼ぶjalのたびに上書きされるので、ほかの関数を呼ぶ関数は自分の戻り先を最初にスタックへ保存しなければなりません。葉関数はjalを使わないのでraが壊れず、保存なしでretできます。さらに呼び出し先保存のレジスタも使わなければ、スタックフレームを作る必要すらありません。x86のcall命令は戻り先を必ずスタックに積むので、ここはRISC-Vとの違いです。

RISC-Vの関数の先頭で「addi sp, sp, -16」を実行する目的として正しいものはどれか。

  1. Aスタックを番地の小さい方へ伸ばして、16バイトの作業領域を確保する
  2. Bスタック上の16バイトを解放する
  3. Cspに入っている値から16を引いて、戻り値として返す
答えと解説を見る

正解：A. スタックを番地の小さい方へ伸ばして、16バイトの作業領域を確保する

RISC-Vを含む多くのISAの慣習では、スタックは番地の大きい方から小さい方へ伸びます。spを16減らすと、新しいspから元のspまでの16バイトが、この関数のスタックフレームになり、戻り先や保存したレジスタ、局所変数を置けます。関数の終わりに「addi sp, sp, 16」でspを戻すと領域が解放され、呼ぶ前と同じ状態になります。

解説の中の「スタックフレーム」

  • さらに呼び出し先保存のレジスタも使わなければ、スタックフレームを作る必要すらありません。

    ほかの関数を呼ばない関数(葉関数、リーフ関数)では、raをスタックに保存しなくてよい場合が多い。その理由として正しいも…

  • spを16減らすと、新しいspから元のspまでの16バイトが、この関数のスタックフレームになり、戻り先や保存したレジスタ、局所変数を置けます。

    RISC-Vの関数の先頭で「addi sp, sp, -16」を実行する目的として正しいものはどれか。

  • 1行目でspを16減らしてスタックフレームを確保し、2行目で戻り先のraを、3行目で呼び出し先保存のs0をフレームに書き込んでいます。

    上のコードは、ある関数の先頭(プロローグ)である。この部分が行っていることとして正しいものはどれか。

  • 呼び出しのあとに残る処理がないので、今の関数のスタックフレームを使い回し、引数を書き換えて関数の先頭へジャンプする形に変換できます。

    上の関数の最後の再帰呼び出しに末尾呼び出しの最適化を行うと、どのような効果があるか。

  • 局所変数は、関数が呼ばれたときにスタックフレームの中に作られ(最適化でレジスタだけに置かれることもあります)、関数から戻ると消えます。

    C言語の関数の中で宣言した、staticの付かない局所変数(自動変数)は、実行中どこに置かれるか。

「スタックフレーム」が出てくる問題(5問)

  1. ほかの関数を呼ばない関数(葉関数、リーフ関数)では、raをスタックに保存しなくてよい場合が多い。その理由として正しいものはどれか。
  2. RISC-Vの関数の先頭で「addi sp, sp, -16」を実行する目的として正しいものはどれか。
  3. 上のコードは、ある関数の先頭(プロローグ)である。この部分が行っていることとして正しいものはどれか。
  4. 上の関数の最後の再帰呼び出しに末尾呼び出しの最適化を行うと、どのような効果があるか。
  5. C言語の関数の中で宣言した、staticの付かない局所変数(自動変数)は、実行中どこに置かれるか。
