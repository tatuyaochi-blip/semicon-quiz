非同期リセットとは

ひどうきりせっと

クロックに関係なく、リセットの信号が有効になるとすぐにフリップフロップを初期化するリセット。解除はクロックに同期させるのが基本。

「非同期リセット」は、3分野の6問の練習問題に出てきます(ハードウェア記述言語と検証, タイミング解析とCDC, 論理回路など)。

この用語の分野: ハードウェア記述言語と検証

非同期リセットの書き方

Verilogでは、非同期リセットはクロックと一緒にセンシティビティリストに書きます。always @(posedge clk or negedge rst_n) の後に if (!rst_n) q <= 0; else q <= d; と続ける形です。rst_n の立ち下がりでもブロックが起動するので、リセットがアサートされた瞬間に、クロックエッジを待たずに q がクリアされます。末尾の _n は、ローアクティブの信号によく使われる命名規則です。論理合成はこの書き方を、専用のリセットピンやクリアピンを持つフリップフロップに割り当てるため、リセットはデータパスの論理を通りません。

非同期リセットと同期リセットの違い

同期リセットは、クロックエッジでサンプリングされる入力の1つにすぎません。フリップフロップのD入力の前にある論理を通り、クロックが動いているときにだけ効きます。そのためタイミング解析は簡単ですが、クロックが止まっているブロックは初期化できず、データパスに論理が追加されます。非同期リセットはフリップフロップのリセットピンを使い、クロックがなくてもすぐに効くので、電源投入時やクロックをゲーティングしているときに役立ちます。弱点は解除の瞬間で、そこには独自のタイミング要件があります。

リセット解除の問題

フリップフロップにはリカバリ時間とリムーバル時間が規定されており、これらは非同期リセットのデアサートに対するセットアップ時間とホールド時間の役割を果たします。クロックエッジに近すぎるタイミングでリセットを解除すると、フリップフロップがメタステーブルになったり、リセットネットワークの場所によってフリップフロップがリセットから抜けるクロックサイクルがずれたりします。状態ビットの開始が1サイクルずれたステートマシンは、不正な状態から動き始めることがあります。外部のリセット源はクロックと無関係なので、解除を同期化しない限り、この状況は排除できません。

非同期アサート・同期解除

一般的な対策はリセット同期化回路です。送り先のクロックで動く2個のフリップフロップを直列につなぎ、その非同期リセットピンを外部リセットで駆動し、1段目のデータ入力は非アクティブのレベルに固定します。リセットをアサートすると両段が同時にクリアされるので、リセットはこれまでどおりすぐに効きます。解除時には非アクティブのレベルが2個のフリップフロップを順に伝わる必要があるため、分配されるリセットはクロックにそろって解除され、2段目が1段目にメタステーブルを解消する時間を与えます。クロックドメインごとに個別の同期化回路が必要です。

非同期リセットの練習問題に挑戦

非同期リセット付きフリップフロップで、リセットの解除がクロックのエッジに近すぎないかをSTAで調べるチェックはどれか。

  1. Aクロックゲーティングチェック
  2. Bリカバリーチェックとリムーバルチェック
  3. C最大遷移時間(max transition)のチェック
答えと解説を見る

正解：B. リカバリーチェックとリムーバルチェック

非同期リセットの解除は、データ入力と同じように、クロックのエッジから一定の時間だけ離れていなければなりません。解除がエッジの直前すぎないかを見るのがリカバリーチェック(セットアップに相当)、エッジの直後すぎないかを見るのがリムーバルチェック(ホールドに相当)です。違反すると、そのサイクルでリセットが解除されるかどうかが定まらず、フリップフロップごとに動き出すサイクルがずれます。遷移時間のチェックは信号の波形のなまりを見るもので、目的が違います。

同期リセットと非同期リセットの違いとして正しいものはどれか。

  1. A同期リセットはクロックに関係なく効き、非同期リセットはクロックのエッジでだけ効く
  2. B同期リセットはクロックのエッジでだけ効き、非同期リセットはクロックに関係なくすぐに効く
  3. Cどちらもまったく同じ動作で、名前が違うだけである
答えと解説を見る

正解：B. 同期リセットはクロックのエッジでだけ効き、非同期リセットはクロックに関係なくすぐに効く

同期リセットは、リセットの信号をほかの入力と同じようにクロックのエッジで取り込むので、タイミングの解析がしやすい一方、クロックが動いていないとリセットできません。非同期リセットはフリップフロップのリセット端子を直接使うので、クロックがなくてもすぐにリセットできますが、解除の瞬間がクロックのエッジに近いと、フリップフロップごとに解除のタイミングがばらつく恐れがあります。

よくある質問

同期リセットと非同期リセットの違いは?

同期リセットはアクティブなクロックエッジでだけ効き、クロックが動いている必要があります。非同期リセットはクロックに関係なく、フリップフロップのリセットピンを通じてすぐに効きます。

非同期リセットの解除を同期化するのはなぜですか?

クロックエッジの近くでリセットを解除すると、フリップフロップがリカバリやリムーバルのタイミングに違反し、メタステーブルになったり、異なるサイクルでリセットから抜けたりするからです。2段のフリップフロップによる同期化回路で、解除をクロックにそろえます。

リカバリ時間とリムーバル時間とは何ですか?

アクティブなクロックエッジに対して、非同期リセットをその前までにデアサートしておくべき最小時間(リカバリ)と、その後もアサートを保持すべき最小時間(リムーバル)です。データのセットアップ時間とホールド時間に相当します。
