パッシベーション膜とは

ぱっしべーしょんまく

チップの最上層に形成し、内部の回路を水分や汚染、機械的な傷から守る膜。シリコン窒化膜やポリイミドなどが使われる。

この用語の分野: 配線プロセス

解説の中の「パッシベーション膜」

  • シリコン窒化膜は酸素や水分を通しにくく、硬いため、選択酸化(LOCOS)のマスク、STI形成でのCMPストッパー、チップ表面を水分や可動イオンから守るパッシベーション膜などに使われます。

    シリコン窒化膜(Si3N4)の用途として正しいものはどれか。

  • 保護膜(パッシベーション膜)などに使われます。

    プラズマCVDで成膜したシリコン窒化膜の特徴として正しいものはどれか。

  • パッシベーション膜は、チップの表面を覆う保護膜で、シリコン窒化膜や酸化膜、さらにポリイミドなどの樹脂膜が使われます。

    チップの最上層に形成し、内部の回路を水分や汚染、機械的な傷から守る膜を何と呼ぶか。

「パッシベーション膜」が出てくる問題(3問)

  1. シリコン窒化膜(Si3N4)の用途として正しいものはどれか。
  2. プラズマCVDで成膜したシリコン窒化膜の特徴として正しいものはどれか。
  3. チップの最上層に形成し、内部の回路を水分や汚染、機械的な傷から守る膜を何と呼ぶか。
