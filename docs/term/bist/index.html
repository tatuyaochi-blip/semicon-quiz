BIST(組み込み自己テスト)とは

びすと

テスト用の回路をチップ内に組み込み、チップ自身でテストパターンの生成と結果の判定を行う仕組み。メモリのテストなどで広く使われる。

「BIST(組み込み自己テスト)」は、3分野の4問の練習問題に出てきます(テスト・検査, 論理回路, 歩留まり・品質管理など)。

この用語の分野: テスト・検査

BIST(組み込み自己テスト)の練習問題に挑戦

BIST(組み込み自己テスト)の説明として正しいものはどれか。

  1. A外部のテスタだけですべてのテストを行う
  2. Bテスト用の回路をチップ内に組み込み、チップ自身でテストを行う
  3. C人の目で外観を検査する
答えと解説を見る

正解：B. テスト用の回路をチップ内に組み込み、チップ自身でテストを行う

BISTは、テストパターンの生成回路と結果の判定回路をチップに内蔵し、チップ自身でテストを実行する仕組みです。メモリ用のMBISTはマーチテストなどのパターンを高速に発生させ、論理回路用のLBISTは擬似乱数のパターンを使います。高価なテスタへの依存とテスト時間を減らせるほか、車載用では電源を入れるたびに出荷後も自己診断できる利点があります。

解説の中の「BIST(組み込み自己テスト)」

  • BISTは、テストパターンの生成回路と結果の判定回路をチップに内蔵し、チップ自身でテストを実行する仕組みです。

    BIST(組み込み自己テスト)の説明として正しいものはどれか。

  • XORとフリップフロップだけで作れるため、内蔵テスト(BIST)のパターン生成と結果の圧縮、イーサネットなどのCRC計算、信号を平均化して電磁ノイズを減らすスクランブラに使われます。

    シフトレジスタの一部の出力のXORを入力に戻す線形帰還シフトレジスタ(LFSR)の代表的な用途はどれか。

  • 同時に測るチップの数だけテスタのチャンネルが必要になるため、BISTやスキャン圧縮で必要なピンを減らす工夫と組み合わせます。

    テストのコストを下げるために、テスタで複数のチップを同時に測定する手法を何と呼ぶか。

  • BISTはテスト回路、EDAは設計ツールです。

「BIST(組み込み自己テスト)」が出てくる問題(4問)

  1. BIST(組み込み自己テスト)の説明として正しいものはどれか。
  2. シフトレジスタの一部の出力のXORを入力に戻す線形帰還シフトレジスタ(LFSR)の代表的な用途はどれか。
  3. テストのコストを下げるために、テスタで複数のチップを同時に測定する手法を何と呼ぶか。
  4. 工場の中で、どのロットがどの工程・装置にあり、どの条件で処理されたかなどを管理し、生産の流れを指示・記録するシステムはどれか。
