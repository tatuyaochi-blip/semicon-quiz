アレニウスモデルとは

あれにうすもでる

反応や劣化の速さが温度に対して exp(−Ea/kT) で変わるとするモデル。温度を上げた加速試験の結果から、実際の使用温度での寿命を推定するのに使う。

この用語の分野: 信頼性

解説の中の「アレニウスモデル」

  • この性質を利用し、高温で保存して短時間で長期保持を見積もる加速試験(アレニウスモデル)が行われます。

    フラッシュメモリのデータ保持(リテンション)特性が悪くなりやすい条件はどれか。

  • アレニウスモデルは、劣化の反応速度がexp(−Ea/kT)(Ea:活性化エネルギー、k:ボルツマン定数、T:絶対温度)に比例するという考え方で、温度を上げると寿命が指数関数的に短くなることを表します。

    温度を上げて寿命試験の時間を短縮する加速試験で、温度と寿命の関係を表すためによく使われるモデルはどれか。

  • 正確にはアレニウスモデルを使います。

    多くの化学反応や劣化の目安としてよく使われる「温度が10℃上がると反応の速さがおよそ2倍になる」という経験則から考える…

「アレニウスモデル」が出てくる問題(4問)

  1. 活性化エネルギー0.7 eVの故障メカニズムについて、アレニウスモデルで55 ℃に対する125 ℃の加速係数を求めるとおよそいくらか。(ボルツマン定数 8.6×10⁻⁵ eV/K)
  2. フラッシュメモリのデータ保持(リテンション)特性が悪くなりやすい条件はどれか。
  3. 温度を上げて寿命試験の時間を短縮する加速試験で、温度と寿命の関係を表すためによく使われるモデルはどれか。
  4. 多くの化学反応や劣化の目安としてよく使われる「温度が10℃上がると反応の速さがおよそ2倍になる」という経験則から考えると、使用温度を10℃下げたときの寿命はおよそどうなるか。
