ロウハンマーとは

ろうはんまー

DRAMで同じ行を短時間に何度も活性化すると、隣の行のセルの電荷が失われてデータが反転してしまう現象。セキュリティ上の攻撃にも悪用されうるため、DRAM側やメモリコントローラで対策が取られている。

この用語の分野: DRAM

解説の中の「ロウハンマー」

  • ロウハンマーは、ある行を短時間に何度も活性化すると、電気的な干渉で隣の行のセルの電荷が漏れてビットが反転する現象です。

    DRAMのロウハンマーへの対策として当てはまるものはどれか。

  • ロウハンマーは、同じ行を短時間に何万回も活性化すると、ワード線の電圧変動や電荷の移動によって隣接行のセルの電荷が失われ、データが反転する現象です。

    DRAMで、ある行を短時間に何度も活性化すると、隣接する行のデータが反転してしまうことがある現象を何と呼ぶか。

「ロウハンマー」が出てくる問題(2問)

  1. DRAMのロウハンマーへの対策として当てはまるものはどれか。
  2. DRAMで、ある行を短時間に何度も活性化すると、隣接する行のデータが反転してしまうことがある現象を何と呼ぶか。
