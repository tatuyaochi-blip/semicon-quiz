ロウハンマーとは

ろうはんまー

DRAMで同じ行を短時間に何度も活性化すると、隣の行のセルの電荷が失われてデータが反転してしまう現象。セキュリティ上の攻撃にも悪用されうるため、DRAM側やメモリコントローラで対策が取られている。

「ロウハンマー」は、2分野の2問の練習問題に出てきます(ハードウェアセキュリティ, DRAMなど)。

この用語の分野: DRAM

ロウハンマーの練習問題に挑戦

DRAMのロウハンマーへの対策として当てはまるものはどれか。

  1. ADRAMの容量を半分にする
  2. B何度も活性化された行の隣の行を早めにリフレッシュする(TRRなど)、リフレッシュの頻度を上げる
  3. CCPUのクロックを止める
答えと解説を見る

正解：B. 何度も活性化された行の隣の行を早めにリフレッシュする(TRRなど)、リフレッシュの頻度を上げる

ロウハンマーは、ある行を短時間に何度も活性化すると、電気的な干渉で隣の行のセルの電荷が漏れてビットが反転する現象です。権限のないプログラムがほかのプロセスやカーネルのデータを書き換える攻撃に使える恐れがあります。対策として、多く活性化された行の隣を追加でリフレッシュする仕組みや、リフレッシュの頻度を上げる方法、ECCで反転を見つけて直す方法などが組み合わされます。

解説の中の「ロウハンマー」

  • ロウハンマーは、ある行を短時間に何度も活性化すると、電気的な干渉で隣の行のセルの電荷が漏れてビットが反転する現象です。

    DRAMのロウハンマーへの対策として当てはまるものはどれか。

  • ロウハンマーは、同じ行を短時間に何万回も活性化すると、ワード線の電圧変動や電荷の移動によって隣接行のセルの電荷が失われ、データが反転する現象です。

    DRAMで、ある行を短時間に何度も活性化すると、隣接する行のデータが反転してしまうことがある現象を何と呼ぶか。

「ロウハンマー」が出てくる問題(2問)

  1. DRAMのロウハンマーへの対策として当てはまるものはどれか。
  2. DRAMで、ある行を短時間に何度も活性化すると、隣接する行のデータが反転してしまうことがある現象を何と呼ぶか。
