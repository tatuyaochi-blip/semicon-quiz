平均メモリアクセス時間(AMAT)とは

へいきんめもりあくせすじかん

1回のメモリアクセスにかかる時間の平均。ヒット時間 + ミス率 × ミスペナルティで求め、キャッシュの性能を比べる基本の指標になる。

この用語の分野: メモリ階層と性能

解説の中の「平均メモリアクセス時間(AMAT)」

  • よって平均メモリアクセス時間は 1 + 0.05 × 30 = 1 + 1.5 = 2.5 nsになります。

    L1キャッシュのヒット時間が1 ns、ミス率が5%、L2キャッシュのヒット時間が10 ns、L2のローカルミス率が20…

  • 平均メモリアクセス時間 = ヒット時間 + ミス率 × ミスペナルティ = 2 + 0.04 × 150 = 2 + 6 = 8サイクルです。

    キャッシュのヒット時間が2サイクル、ミス率が4%、ミスペナルティが150サイクルのとき、平均メモリアクセス時間は何サイ…

  • 平均メモリアクセス時間はヒット時間・ミス率・ミスペナルティの3つで決まります。

    キャッシュの性能を評価するとき、ミス率だけでなく平均メモリアクセス時間で比べる必要がある理由として正しいものはどれか。

「平均メモリアクセス時間(AMAT)」が出てくる問題(4問)

  1. L1キャッシュのヒット時間が1 ns、ミス率が5%、L2キャッシュのヒット時間が10 ns、L2のローカルミス率が20%、主記憶のアクセス時間が100 nsのとき、平均メモリアクセス時間はいくらか。
  2. キャッシュのヒット時間が2サイクル、ミス率が4%、ミスペナルティが150サイクルのとき、平均メモリアクセス時間は何サイクルか。
  3. キャッシュの性能を評価するとき、ミス率だけでなく平均メモリアクセス時間で比べる必要がある理由として正しいものはどれか。
  4. キャッシュのヒット率が95%のとき、ミス率はいくらか。
