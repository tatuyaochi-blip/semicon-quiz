VCSEL(垂直共振器面発光レーザー)とは

びくせる

基板に垂直な方向に光を出す半導体レーザー。ウエハのまま検査でき、2次元に並べるのも容易なため、データ通信や顔認証の光源などに使われる。

この用語の分野: 化合物半導体

解説の中の「VCSEL(垂直共振器面発光レーザー)」

  • VCSELは、上下を数十層の多層膜反射鏡(DBR)で挟んだ短い共振器をもち、ウエハ面に垂直な方向に円形のレーザー光を出します。

    VCSEL(垂直共振器面発光レーザー)の特徴として正しいものはどれか。

  • そのため赤外LEDや半導体レーザー(光ディスク、通信、顔認証のVCSEL)に使われます。

    ガリウムヒ素(GaAs)のバンド構造として正しいものはどれか。

  • GaAs系のLEDはテレビのリモコンや光電センサ、GaAs/AlGaAsのVCSELは850 nm付近でスマートフォンの顔認証や短距離の光通信に使われます。

    バンドギャップ約1.42 eVのGaAsから出る光のおよその波長はどれか。

「VCSEL(垂直共振器面発光レーザー)」が出てくる問題(3問)

  1. VCSEL(垂直共振器面発光レーザー)の特徴として正しいものはどれか。
  2. ガリウムヒ素(GaAs)のバンド構造として正しいものはどれか。
  3. バンドギャップ約1.42 eVのGaAsから出る光のおよその波長はどれか。
