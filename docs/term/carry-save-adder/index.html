桁上げ保存加算器とは

けたあげほぞんかさんき

3つの数を、桁上げを伝えずに「和」と「桁上げ」の2つの数にまとめる加算器。全加算器を桁ごとに並べただけで遅延が一定なので、乗算器で多数の部分積を足すのに使われる。

「桁上げ保存加算器」は、1分野の2問の練習問題に出てきます(計算機算術など)。

この用語の分野: 計算機算術

3つの数を2つにまとめるしくみ

桁上げ保存加算器(CSA)は、全加算器を各桁に1つずつ独立に並べた回路です。3つの数A、B、Cの同じ桁のビットを全加算器に入れ、各桁の和のビットを集めた数Sと、桁上げのビットを集めて1桁左にずらした数Cyをつくると、A + B + C = S + Cy が成り立ちます。たとえば4ビットの5(0101)、6(0110)、7(0111)では、S = 0100(4)、Cy = 1110(14)となり、4 + 14 = 18 = 5 + 6 + 7 です。桁上げを隣の桁へ伝えないので、遅延はビット数によらず全加算器1段分で一定です。

リプルキャリー加算器との違い

普通の加算器(リプルキャリー加算器)では、各桁の結果が下の桁からの桁上げを待つため、最悪の場合は最下位から最上位まで桁上げが伝わり、遅延がビット数に比例します。桁上げ先見加算器などで速くしても、遅延はビット数の対数程度に増えます。桁上げ保存加算器は、桁上げを「保存」して次の段に渡すだけなので、何個の数を足す場合でも、途中の加算で桁上げの伝わりを待つ必要がありません。その代わり結果が和と桁上げの2つの数に分かれた冗長な形になり、最後に1回だけ普通の加算器で足して1つの数にする必要があります。

乗算器での使い方

nビットの乗算ではn個の部分積ができ、これを順に足すと遅くなります。そこで桁上げ保存加算器を木の形に並べ、各段で3つの数を2つにまとめる処理を並列に行います。各段で数がおよそ3分の2に減るので、2つになるまでの段数はビット数の対数程度で済みます。これがウォレスツリーで、全加算器の使い方を工夫して回路を減らしたダッダツリーもあります。4つの数を2つにまとめる4:2コンプレッサもよく使われます。最後に残った2つの数を桁上げ先見加算器などの高速な加算器で足すと積が完成します。ブースのアルゴリズムで部分積の数を減らす方法と組み合わせることも一般的です。

その他の用途と注意点

桁上げ保存の形は、多くの数を足し続ける処理全般に使えます。積和演算器(MAC)では、累積値を和と桁上げの2つの形のまま保持して、毎サイクルの桁上げの伝わりを省くことがあります。暗号で使う大きな整数のモンゴメリ乗算や、除算・平方根の計算でも、途中の値を冗長な形で持つことで高速化します。ただし冗長な形のままでは値の大小や符号、あふれをすぐには判定できず、値を保持するレジスタもおよそ2倍のビット数が必要です。そのため、判定が必要になった時点で普通の加算器で1つの数に戻します。

桁上げ保存加算器の練習問題に挑戦

乗算器で多数の部分積を足し合わせるのに、桁上げ保存加算器が使われる主な理由はどれか。

  1. A桁上げ保存加算器は、部分積の数を最初から1つに減らせるから
  2. B桁上げ保存加算器は、掛け算を足し算なしで行えるから
  3. C桁上げを伝えずに3つを2つにまとめ、遅延が一定だから
答えと解説を見る

正解：C. 桁上げを伝えずに3つを2つにまとめ、遅延が一定だから

通常の加算器で部分積を1つずつ足していくと、そのたびに桁上げが下位から上位へ伝わるのを待つ必要があります。桁上げ保存加算器は、全加算器を桁ごとに独立に並べたもので、3つの数を「各桁の和」と「各桁の桁上げ」の2つの数にまとめるだけなので、桁上げの伝わりを待たず、遅延は全加算器1段分で一定です。これを重ねて部分積を2つまで減らし、最後に1回だけ桁上げ先見加算器などで足します。部分積をいきなり1つにはできません。

よくある質問

桁上げ保存加算器とは何ですか?

3つの数を、桁上げを伝えずに「和」と「桁上げ」の2つの数にまとめる加算器です。全加算器を桁ごとに並べただけなので遅延が一定で、乗算器で多数の部分積を足すのに使われます。

桁上げ保存加算器とリプルキャリー加算器の違いは何ですか?

リプルキャリー加算器は2つの数を足して1つの結果を出しますが、桁上げが下位から上位へ順に伝わるため、遅延がビット数に比例します。桁上げ保存加算器は3つの数を2つにまとめるだけで、桁上げを伝えないので、遅延はビット数によらず一定です。

桁上げ保存加算器だけで足し算を終えられないのはなぜですか?

出力が和と桁上げの2つの数に分かれているからです。1つの値として使うには、最後に桁上げを伝える普通の加算器で2つを足す必要があります。多くの数を足す場合でも、この最後の加算は1回で済みます。
