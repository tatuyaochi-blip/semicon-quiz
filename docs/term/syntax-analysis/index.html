構文解析とは

こうぶんかいせき

トークンの並びが言語の文法に合っているかを調べ、プログラムの構造を木の形に組み立てるコンパイラの段階。文法の誤りはここで見つかる。

「構文解析」は、1分野の6問の練習問題に出てきます(コンパイラなど)。

この用語の分野: コンパイラ

構文解析の練習問題に挑戦

コンパイラの構文解析で行うこととして正しいものはどれか。

  1. A文字の並びから空白やコメントを取り除き、単語に区切る
  2. Bよく実行される部分を見つけ、実行中に機械語に変換する
  3. Cトークンの並びを文法に照らし、プログラムの構造を木の形に組み立てる
答えと解説を見る

正解：C. トークンの並びを文法に照らし、プログラムの構造を木の形に組み立てる

構文解析は、字句解析で得たトークンの並びが言語の文法に合っているかを調べ、if文の条件と本体、式の中の演算の組み合わせなどの構造を木の形(構文木)に組み立てます。セミコロンの書き忘れや括弧の対応の誤りといった文法のエラーはこの段階で見つかります。空白を取り除いて単語に区切るのは字句解析、実行中に機械語に変換するのはJITコンパイルです。

多くのプログラミング言語の文法を表すのに使われ、構文解析の基礎になる文法の種類はどれか。

  1. A正規文法だけ
  2. B自然言語の文法
  3. C文脈自由文法
答えと解説を見る

正解：C. 文脈自由文法

括弧の入れ子や、if文の中にさらにif文がある構造は、正規表現では表せません。プログラミング言語の文法の多くは、「式 → 式 + 項」のような書き換えの規則の集まりである文脈自由文法で表され、構文解析はこの文法にもとづいて行われます。上から規則を当てはめていくLL法や、下から組み立てていくLR法などの解析方法があり、文法から解析器を自動で作る道具もあります。正規文法は字句解析向けで、入れ子の構造は扱えません。

  • 文法に合っているかを木の形で確かめるのは次の構文解析、型や名前を調べるのは意味解析の仕事です。

    コンパイラの字句解析の役割として正しいものはどれか。

  • セミコロンの書き忘れは文法の誤りなので構文解析で見つかります。

    コンパイラの意味解析で見つかる誤りの例として最も適切なものはどれか。

「構文解析」が出てくる問題(6問)

  1. コンパイラの構文解析で行うこととして正しいものはどれか。
  2. 多くのプログラミング言語の文法を表すのに使われ、構文解析の基礎になる文法の種類はどれか。
  3. コンパイラの字句解析の役割として正しいものはどれか。
  4. コンパイラの意味解析で見つかる誤りの例として最も適切なものはどれか。
  5. 抽象構文木(AST)の特徴として正しいものはどれか。
  6. プログラムの誤りのうち、コンパイルの時点で見つけることができるものはどれか。
