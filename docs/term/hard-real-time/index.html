ハードリアルタイムとは

はーどりあるたいむ

期限を1度でも守れないとシステムの失敗になる、厳しい時間の要求。自動車のブレーキやエアバッグの制御など。時々の遅れが許されるものはソフトリアルタイム。

この用語の分野: 組込み・ファームウェア

解説の中の「ハードリアルタイム」

  • ハードリアルタイムの例は、自動車のエアバッグやエンジン、ブレーキの制御で、期限に遅れると重大な事故につながります。

    ハードリアルタイムとソフトリアルタイムの違いとして正しいものはどれか。
