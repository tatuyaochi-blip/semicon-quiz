真理値表とは

しんりちひょう

入力のすべての組み合わせに対する出力を一覧にした表。論理回路の動作を表すのに使う。

「真理値表」は、2分野の3問の練習問題に出てきます(論理回路, LSI設計フロー・EDAなど)。

この用語の分野: 論理回路

真理値表の練習問題に挑戦

3入力の論理回路の真理値表は何行になるか。

  1. A6行
  2. B9行
  3. C8行
答えと解説を見る

正解：C. 8行

各入力は0か1の2通りなので、3入力の組み合わせは 2³ = 8 通りで、真理値表は8行になります。n入力では 2ⁿ 行と指数関数的に増えるため、32ビットの加算器(64入力)の真理値表は 2⁶⁴ 行となり、作ることは現実的ではありません。そのため大きな回路は、小さな部品を組み合わせて設計し、論理式やHDLで記述して検証します。

解説の中の「真理値表」

  • 各入力は0か1の2通りなので、3入力の組み合わせは 2³ = 8 通りで、真理値表は8行になります。

    3入力の論理回路の真理値表は何行になるか。

  • カルノー図は、真理値表を隣り合うマスの入力が1ビットだけ異なる(グレイコード順)ように並べた図です。

    カルノー図の主な用途はどれか。

  • FPGAは、小さな真理値表(LUT)をもつ論理ブロックと配線のつなぎ方を、製造後に設定データで書き換えられるデバイスです。

    FPGAの特徴として正しいものはどれか。

「真理値表」が出てくる問題(3問)

  1. 3入力の論理回路の真理値表は何行になるか。
  2. カルノー図の主な用途はどれか。
  3. FPGAの特徴として正しいものはどれか。
