CDN(コンテンツデリバリネットワーク)とは

しーでぃーえぬ

Content Delivery Networkの略。画像、動画、スクリプトなどのコンテンツの複製を、各地に置いたキャッシュサーバ(エッジサーバ)に置き、利用者に近いサーバから配信するしくみ。RTTが短くなって表示が速くなり、元のサーバ(オリジン)の負荷も減り、DDoS攻撃の通信を分散して受け止めるのにも役立つ。利用者を近いサーバに導くのに、DNSやエニーキャストを使う。

「CDN(コンテンツデリバリネットワーク)」は、4分野の6問の練習問題に出てきます(Web技術の基礎, システム構成と信頼性設計, クラウドとコンテナの基礎など)。

CDN(コンテンツデリバリネットワーク)の練習問題に挑戦

CDN(コンテンツデリバリネットワーク)の説明として、適切なものはどれか。

  1. Aすべての利用者の要求を1か所のサーバに集めて、配信するコンテンツの一貫性を保つ仕組み
  2. B通信の内容を暗号化して、離れた拠点の間に仮想的な専用の回線を作る仕組み
  3. C利用者に近い場所に置いた多数のサーバにコンテンツの複製(キャッシュ)を置き、利用者を近くのサーバに誘導して配信する仕組み
答えと解説を見る

正解：C. 利用者に近い場所に置いた多数のサーバにコンテンツの複製(キャッシュ)を置き、利用者を近くのサーバに誘導して配信する仕組み

CDNは、画像や動画、ソフトウェアの更新のファイルなどのコンテンツの複製を、各地に置いた配信用のサーバにもっておき、利用者を近くのサーバに誘導して配信する仕組みです。利用者までの距離が短くなるので応答が速くなり、元のサーバ(オリジンサーバ)の負荷や通信の量も減らせます。アクセスが一時的に集中したときにも、負荷を各地のサーバに分散できます。暗号化して拠点の間に仮想的な専用回線を作るのは、VPNです。

1秒あたり2,000件のリクエストを受けるCDNで、キャッシュヒット率が90%から98%に上がった。ヒットしたときの応答時間は20 ms、ヒットしなかったときはオリジンサーバから取得して返すので200 msかかり、ヒットしなかったリクエストだけがオリジンサーバに届くとする。98%になった後の、オリジンサーバに届くリクエストの数と平均の応答時間の組み合わせはどれか。

  1. A毎秒40件、約24 ms
  2. B毎秒40件、約110 ms
  3. C毎秒160件、約24 ms
答えと解説を見る

正解：A. 毎秒40件、約24 ms

ヒットしなかったリクエストは全体の 100 − 98 = 2% なので、オリジンサーバに届くのは 2,000 × 0.02 = 毎秒40件です。90%のときは毎秒200件だったので、ヒット率が8ポイント上がっただけで、オリジンサーバの負荷は5分の1になります。平均の応答時間は 0.98 × 20 + 0.02 × 200 = 19.6 + 4 = 23.6 ms で、約24 msです。90%のときの 0.9 × 20 + 0.1 × 200 = 38 ms と比べても、大きく短くなります。

    多くのパブリッククラウドのデータ転送の料金の考え方として、一般に当てはまるものはどれか。

  • ブラウザのキャッシュは1人の利用者だけが使うものですが、CDNやプロキシのキャッシュは多くの利用者で共有されます。
