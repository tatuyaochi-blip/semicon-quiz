故障注入攻撃とは

こしょうちゅうにゅうこうげき

電源の電圧やクロックの乱れ、レーザなどでチップをわざと誤動作させ、認証を飛ばしたり鍵を推測したりする攻撃。

「故障注入攻撃」は、1分野の2問の練習問題に出てきます(ハードウェアセキュリティなど)。

この用語の分野: ハードウェアセキュリティ

故障注入攻撃の練習問題に挑戦

故障注入攻撃の説明として正しいものはどれか。

  1. A電源の電圧やクロックに瞬間的な乱れを加えたり、レーザを当てたりしてチップを誤動作させ、認証を飛ばしたり鍵を推測したりする攻撃
  2. Bプログラムの中の誤り(バグ)を数える作業
  3. C製造の不良で壊れたチップを見つけるテスト
答えと解説を見る

正解：A. 電源の電圧やクロックに瞬間的な乱れを加えたり、レーザを当てたりしてチップを誤動作させ、認証を飛ばしたり鍵を推測したりする攻撃

チップは決められた電圧やクロックの範囲で正しく動くように作られています。故障注入攻撃は、電源の電圧を一瞬だけ下げる、クロックに短いパルスを入れる、レーザや電磁パルスを当てる、などでわざと誤動作を起こさせます。比較の命令を飛ばして署名の確認をすり抜けたり、誤った暗号の結果と正しい結果を比べて鍵を推測したりできることが知られています。

故障注入攻撃への対策として当てはまらないものはどれか。

  1. A電圧やクロックの異常を検出するセンサを置き、異常があれば処理を止める
  2. B処理を速くするため、重要な確認を1回だけにする
  3. C重要な計算を2回行ったり逆の計算で確かめたりして、結果が一致しなければ出力しない
答えと解説を見る

正解：B. 処理を速くするため、重要な確認を1回だけにする

故障注入は1回の誤動作で守りを破ろうとするので、確認を1回だけにしているとそこが弱点になります。対策としては、電圧やクロック、光を検出するセンサ、重要な計算や比較を繰り返して結果を突き合わせる冗長化、誤動作を見つけたら鍵を消すなどの反応があります。ソフトウェアでも、重要な分岐を二重に確かめる、成功と失敗の値をビットの差の大きい値にする、などの工夫をします。

解説の中の「故障注入攻撃」

  • 故障注入攻撃は、電源の電圧を一瞬だけ下げる、クロックに短いパルスを入れる、レーザや電磁パルスを当てる、などでわざと誤動作を起こさせます。
