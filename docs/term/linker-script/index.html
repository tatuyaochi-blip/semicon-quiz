リンカスクリプトとは

りんかすくりぷと

各セクションをメモリのどの番地に配置するかをリンカに指示するファイル。組込み開発で、フラッシュとRAMへの配置や割り込みベクタの番地を決めるのに使う。

「リンカスクリプト」は、1分野の2問の練習問題に出てきます(リンカ・ローダと実行形式など)。

この用語の分野: リンカ・ローダと実行形式

リンカスクリプトに書くこと

コンパイラが出力するオブジェクトファイルでは、コードとデータが.text(命令)、.rodata(定数)、.data(初期値付き変数)、.bss(ゼロ初期化変数)などのセクションにまとめられていますが、最終的なアドレスはまだ決まっていません。リンカスクリプトは、それらをどう結合するかをリンカに指示します。GNU ldの書式では、MEMORYブロックで開始アドレスと長さをもつ領域を宣言します。たとえばフラッシュをあるアドレスに、RAMを別のアドレスに置くといった具合です。SECTIONSブロックでは入力セクションを出力セクションに対応させ、それぞれを領域に割り当てます。領域があふれると、リンカはエラーを報告します。

組み込みシステムで必要な理由

PCでは、プログラムをメモリのどこに置くかはOSのローダが決めるので、ほとんどの場合、既定のリンカスクリプトで足ります。OSのないマイコンは電源投入時に決まったアドレスから実行を始めるため、プログラムはそのチップのメモリマップに正確に合わせてビルドしなければなりません。割り込みベクタテーブルはハードウェアが想定する位置に、コードと定数は不揮発性のフラッシュに、書き込み可能な変数、ヒープ、スタックはRAMに置く必要があります。同じファミリーの異なるチップでは、メモリの容量が違うだけなので、リンカスクリプトを変えるだけで済むこともよくあります。

ロードアドレスと実行アドレス

初期値付きの変数には特有の問題があります。初期値は電源を切っても残る必要があるのでフラッシュに格納しますが、プログラムが書き換えるので、実行時にはRAMに置かなければなりません。そのためリンカスクリプトは.dataに、フラッシュ上のロードアドレスとRAM上の実行アドレスの2つを与えます。また、.dataと.bssの開始・終了や、多くの場合スタックの最上位を示すシンボルも定義します。スタートアップコードはそれらのシンボルを使い、mainを呼ぶ前に.dataをフラッシュからRAMへコピーし、.bssを0で埋めます。これでC言語が約束する初期状態が整います。

よくある落とし穴

ベアメタルのプロジェクトで起きる問題の多くは、リンカスクリプトに原因があります。未使用セクションの削除を有効にすると、ベクタテーブルなど、ハードウェアからしか参照されないセクションが、保持の指定をしない限り捨てられてしまいます。スタック領域が小さすぎてもリンクエラーにはならず、実行時に知らないうちにほかのデータを上書きします。セクションを間違ったロードアドレスに置くと、変数の初期値がでたらめになります。結果を確かめる標準的な方法は、リンカが出力できるマップファイルを読むことです。マップファイルには、すべてのシンボルのアドレスと各領域の使用量が載っています。

リンカスクリプトの練習問題に挑戦

  1. A各セクションを、フラッシュやRAMなどのどの番地に配置するかをリンカに指示する
  2. Bプログラムのテストを自動で実行する手順を書く
  3. Cソースコードの書き方の規則を定めて、違反を知らせる
答えと解説を見る

正解：A. 各セクションを、フラッシュやRAMなどのどの番地に配置するかをリンカに指示する

パソコンのOSではローダが番地を決めますが、マイコンでは電源を入れた時点の番地がそのまま使われます。リンカスクリプトには、フラッシュとRAMの開始番地と大きさを書き、.textや定数はフラッシュに、.dataや.bss、スタックはRAMに置く、といった配置を指定します。割り込みベクタのように決まった番地に置く必要があるものも、ここで指定します。

よくある質問

リンカスクリプトは何に使うのですか?

どのようなメモリ領域があり、コードやデータの各セクションをどのアドレスに配置するかをリンカに指示するために使います。組み込み開発では、コードをフラッシュに、変数をRAMに、割り込みベクタテーブルを所定のアドレスに置くのに使います。

.dataと.bssの違いは?

.dataには0以外の初期値をもつ変数が入り、初期値はフラッシュに格納されて起動時にRAMへコピーされます。.bssには0から始まる変数が入るので、フラッシュの領域を使わず、mainの実行前にRAM上で0クリアされるだけです。

リンカスクリプトで.dataに2つのアドレスがあるのはなぜですか?

初期値は不揮発性のフラッシュに格納する必要がある一方、変数は実行時に書き換えられるのでRAMに置かなければならないからです。ロードアドレスはフラッシュ上のコピーを、実行アドレスはコードが実際に使うRAM上の位置を指します。
