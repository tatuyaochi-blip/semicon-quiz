非正規化数とは

ひせいきかすう

指数部がすべて0の浮動小数点数で、先頭の1を仮定せずに、正規化数より小さい0の近くの数を表す。0との間をなだらかにつなぎ(漸進アンダーフロー)、x − y = 0 なら x = y が成り立つようにする。

「非正規化数」は、1分野の7問の練習問題に出てきます(計算機算術など)。

この用語の分野: 計算機算術

非正規化数の練習問題に挑戦

IEEE 754の非正規化数(サブノーマル数)の役割として正しいものはどれか。

  1. A最も大きい正規化数より大きな値を表し、オーバーフローを防ぐ
  2. B計算の誤りを検出し、結果をNaNに置き換える
  3. C正規化数と0の間を埋め、アンダーフローをなだらかにする
答えと解説を見る

正解：C. 正規化数と0の間を埋め、アンダーフローをなだらかにする

正規化数だけでは、最も小さい正規化数(単精度で約1.18 × 10⁻³⁸)と0の間に大きなすき間ができ、それより小さい結果はいきなり0になってしまいます。非正規化数は、指数部をすべて0にして先頭の1を仮定しないことで、このすき間を等間隔の小さな数で埋めます(漸進アンダーフロー)。これにより x − y = 0 なら x = y という性質が保たれます。大きな値を表すのではなく、そちらは無限大で表します。誤りの検出とも関係ありません。

非正規化数を多く含む計算で、一部のプロセッサでは処理が大きく遅くなることがある。そのため性能を優先する場面で使われる設定はどれか。

  1. A非正規化数になる結果や入力を0とみなす設定(フラッシュ・トゥ・ゼロ)
  2. Bすべての計算を倍精度から単精度に自動で変換する設定
  3. C非正規化数を見つけたらプログラムを停止させる設定
答えと解説を見る

正解：A. 非正規化数になる結果や入力を0とみなす設定(フラッシュ・トゥ・ゼロ)

非正規化数は先頭の1を仮定しない特別な形なので、一部のプロセッサでは高速な回路で処理できず、マイクロコードなどで時間をかけて処理し、通常の何十倍も遅くなることがあります。音声処理やAIなど、0にごく近い値を正確に扱う必要がない場面では、非正規化数を0として扱うフラッシュ・トゥ・ゼロの設定にして速度を保ちます。その代わり、0の近くの精度と、漸進アンダーフローの性質は失われます。精度を一律に変えたり、停止させたりはしません。

「非正規化数」が出てくる問題(7問)

  1. IEEE 754の非正規化数(サブノーマル数)の役割として正しいものはどれか。
  2. 非正規化数を多く含む計算で、一部のプロセッサでは処理が大きく遅くなることがある。そのため性能を優先する場面で使われる設定はどれか。
  3. IEEE 754の単精度で、指数部に記録される値が130のとき、実際の指数(2の何乗か)はいくつか。
  4. IEEE 754の正規化数で、仮数の先頭の1を記録しない(隠れビット)ことの効果として正しいものはどれか。
  5. 10進数の1.0を、IEEE 754の単精度で表したビット列を16進数で書くとどれか。
  6. IEEE 754の単精度で、指数部がすべて1(255)のビット列が表すものの説明として正しいものはどれか。
  7. FP16(半精度:符号1・指数部5・仮数10ビット)でニューラルネットワークを学習させるときに問題になりやすく、損失の値を何倍かに拡大して計算する工夫(ロススケーリング)で対策するのはどれか。
