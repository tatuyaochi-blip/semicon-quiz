非正規化数とは

ひせいきかすう

指数部がすべて0の浮動小数点数で、先頭の1を仮定せずに、正規化数より小さい0の近くの数を表す。0との間をなだらかにつなぎ(漸進アンダーフロー)、x − y = 0 なら x = y が成り立つようにする。

この用語の分野: 計算機算術

解説の中の「非正規化数」

  • 非正規化数は、指数部をすべて0にして先頭の1を仮定しないことで、このすき間を等間隔の小さな数で埋めます(漸進アンダーフロー)。

    IEEE 754の非正規化数(サブノーマル数)の役割として正しいものはどれか。

  • 非正規化数は先頭の1を仮定しない特別な形なので、一部のプロセッサでは高速な回路で処理できず、マイクロコードなどで時間をかけて処理し、通常の何十倍も遅くなることがあります。

    非正規化数を多く含む計算で、一部のプロセッサでは処理が大きく遅くなることがある。そのため性能を優先する場面で使われる設…

  • 指数部の0とすべて1(255)は、非正規化数や無限大・NaNのために予約されています。

    IEEE 754の単精度で、指数部に記録される値が130のとき、実際の指数(2の何乗か)はいくつか。

「非正規化数」が出てくる問題(7問)

  1. IEEE 754の非正規化数(サブノーマル数)の役割として正しいものはどれか。
  2. 非正規化数を多く含む計算で、一部のプロセッサでは処理が大きく遅くなることがある。そのため性能を優先する場面で使われる設定はどれか。
  3. IEEE 754の単精度で、指数部に記録される値が130のとき、実際の指数(2の何乗か)はいくつか。
  4. IEEE 754の正規化数で、仮数の先頭の1を記録しない(隠れビット)ことの効果として正しいものはどれか。
  5. 10進数の1.0を、IEEE 754の単精度で表したビット列を16進数で書くとどれか。
  6. IEEE 754の単精度で、指数部がすべて1(255)のビット列が表すものの説明として正しいものはどれか。
  7. FP16(半精度:符号1・指数部5・仮数10ビット)でニューラルネットワークを学習させるときに問題になりやすく、損失の値を何倍かに拡大して計算する工夫(ロススケーリング)で対策するのはどれか。
