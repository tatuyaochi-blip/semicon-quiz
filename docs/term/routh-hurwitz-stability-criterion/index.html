ラウス・フルビッツの安定判別法とは

らうすふるびっつのあんていはんべつほう

特性方程式を解かずに、その係数だけから、根(閉ループの極)がすべて s平面の左半分にあるかを判定する方法。すべての係数が同じ符号で欠けた項がないことが必要条件で、さらにラウス表の第1列がすべて同じ符号なら安定であり、符号の変わる回数が右半分にある根の数に等しい。三次の方程式 s³ + a₂s² + a₁s + a₀ = 0 では、係数がすべて正で a₂a₁ > a₀ のとき安定になる。ゲインを変数として、安定になる範囲を求めるのに使われる。ラウスの方法とフルビッツの方法は同じ条件を与える。

「ラウス・フルビッツの安定判別法」は、1分野の2問の練習問題に出てきます(制御工学の基礎など)。

この用語の分野: 制御工学の基礎

ラウス・フルビッツの安定判別法の練習問題に挑戦

一巡伝達関数が K/(s(s + 1)(s + 2)) の単位フィードバックの系がある。閉ループの系が安定になる K の範囲として正しいものはどれか。

  1. A0 < K < 2
  2. B0 < K < 3
  3. C0 < K < 6
答えと解説を見る

正解：C. 0 < K < 6

特性方程式は s(s + 1)(s + 2) + K = s³ + 3s² + 2s + K = 0 です。ラウス・フルビッツの安定判別法によると、三次の方程式 s³ + a₂s² + a₁s + a₀ = 0 が安定である条件は、係数がすべて正で a₂a₁ > a₀ となることなので、3 × 2 > K、つまり 0 < K < 6 です。K = 6 では極が s = ±j√2 に来て、角周波数約1.41 rad/s(周期約4.4 s)の持続振動になります。K がこれより大きいと、振動が大きくなり続けます。

一巡伝達関数 L(s) = 2/(s(s + 1)(s + 2)) のゲイン余裕に最も近いものはどれか。

  1. A約4.8 dB
  2. B約9.5 dB
  3. C約15.6 dB
答えと解説を見る

正解：B. 約9.5 dB

位相は −90° − tan⁻¹ω − tan⁻¹(ω/2) で、2つの角の和が90°になる条件 ω × (ω/2) = 1 から、位相が −180° になるのは ω = √2 rad/s のときです。そこでのゲインは |L(j√2)| = 2/(√2 × √3 × √6) = 1/3 なので、ゲイン余裕は 20 log₁₀3 ≈ 9.5 dBです。ゲインを3倍(K = 6)にすると限界に達することになり、ラウス・フルビッツの安定判別法で求めた安定の範囲 0 < K < 6 と一致します。
