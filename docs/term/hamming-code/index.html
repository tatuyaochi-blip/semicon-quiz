ハミング符号とは

はみんぐふごう

1ビットの誤りを訂正できる誤り訂正符号の代表。r個の検査ビットを使い、長さ 2^r − 1 ビットの符号語のうち 2^r − 1 − r ビットをデータに使う。r = 3 のハミング符号(7, 4)では、4ビットのデータに3ビットの検査ビットを付ける。各検査ビットは、重なり合うビットの組のパリティで、受信側で検査をやり直した結果(シンドローム)が、誤ったビットの位置を2進数で示す。最小ハミング距離は3で、全体のパリティを1ビット加えたSECDEDでは、2ビットの誤りの検出もできる。サーバー用のメモリのECCなどに使われる。

「ハミング符号」は、2分野の5問の練習問題に出てきます(情報理論と符号の基礎, 論理回路など)。

この用語の分野: 情報理論と符号の基礎

(7, 4)符号のしくみ

ビットの位置を1〜7とし、2のべき乗の位置1、2、4を検査ビットにします。検査1は位置の番号を2進数で表したときに1の位が1になる位置(1、3、5、7)、検査2は2の位が1になる位置(2、3、6、7)、検査4は4の位が1になる位置(4、5、6、7)の1の個数を偶数にします。誤った位置の番号の、2進数で1になる桁に当たる検査だけが合わなくなるので、合わない検査の重みを足すと、誤った位置が分かります。

符号化率と長さ

検査ビットがr個なら符号語は 2^r − 1 ビットで、(7, 4)、(15, 11)、(31, 26) のように長くするほど、符号化率は 4/7 ≈ 0.57、11/15 ≈ 0.73、26/31 ≈ 0.84 と高くなります。その代わり、1つの符号語で訂正できるのは1ビットだけなので、長い符号語ほど、2ビット以上の誤りが入る確率が高くなります。

SECDEDとメモリ

ハミング符号に全体のパリティを1ビット加えると最小ハミング距離が4になり、1ビットの誤りの訂正(SEC)と2ビットの誤りの検出(DED)ができます。64ビットのデータには8ビットの検査ビットが必要で、サーバー用のメモリが72ビット幅になっているのはこのためです。より多くの誤りを扱うフラッシュメモリなどでは、BCH符号やLDPC符号が使われます。

ハミング符号の練習問題に挑戦

4ビットのデータに3ビットの検査ビットを付けて7ビットの符号語にする、ハミング符号(7, 4)の符号化率に最も近いものはどれか。

  1. A約0.43
  2. B約0.57
  3. C1.75
答えと解説を見る

正解：B. 約0.57

符号化率は、符号語の長さnのうち、データのビット数kが占める割合 k/n です。ハミング符号(7, 4)では 4/7 ≈ 0.57 で、送るビットの約57%がデータです。符号化率が低いほど、検査ビットが多く誤りに強くしやすい一方、データを送る効率は下がります。

ハミング符号(7, 4)で、7ビットを左から1〜7ビット目とし、1、2、4ビット目を検査ビットとする。検査1は1、3、5、7ビット目、検査2は2、3、6、7ビット目、検査4は4、5、6、7ビット目の1の個数が、それぞれ偶数になるように作る。受信した 0110001 に1ビットの誤りがあるとき、誤ったビットはどれか。

  1. A2ビット目
  2. B3ビット目
  3. C6ビット目
答えと解説を見る

正解：C. 6ビット目

受信した 0110001 で、1、3、5、7ビット目は0、1、0、1で1の個数は偶数(検査1の結果は0)、2、3、6、7ビット目は1、1、0、1で奇数(検査2の結果は1)、4、5、6、7ビット目は0、0、0、1で奇数(検査4の結果は1)です。検査4、検査2、検査1の結果を並べた 110 を2進数として読むと6なので、6ビット目が誤っています。6ビット目を反転した 0110011 は、3つの検査をすべて満たします。

よくある質問

2ビットの誤りが起きると、ハミング符号ではどうなりますか?

全体のパリティのないハミング符号では、2ビットの誤りでもシンドロームが0以外のどれかの位置を示すので、正しいビットを反転してしまい、誤りが3ビットに増えます。これを防ぐために、メモリなどでは全体のパリティを加えたSECDEDを使い、2ビットの誤りは訂正せずにエラーとして報告します。

ハミング符号は、今も使われていますか?

使われています。計算が簡単で速いので、メモリのECCやキャッシュ、レジスタの保護など、遅延を小さくしたい場面で広く使われています。通信のように、多くの誤りを効率よく訂正したい場面では、LDPC符号などのより強力な符号が使われます。

「ハミング符号」が出てくる問題(5問)

  1. 4ビットのデータに3ビットの検査ビットを付けて7ビットの符号語にする、ハミング符号(7, 4)の符号化率に最も近いものはどれか。
  2. ハミング符号(7, 4)で、7ビットを左から1〜7ビット目とし、1、2、4ビット目を検査ビットとする。検査1は1、3、5、7ビット目、検査2は2、3、6、7ビット目、検査4は4、5、6、7ビット目の1の個数が、それぞれ偶数になるように作る。受信した 0110001 に1ビットの誤りがあるとき、誤ったビットはどれか。
  3. 32ビットのデータに、1ビットの誤りを訂正し、2ビットの誤りを検出できるSECDED符号を付ける。ハミング符号の検査ビットの数rは、2^r ≥ データのビット数 + r + 1 を満たす最小の値で、SECDEDではこれに全体のパリティを1ビット加える。必要な検査ビットの数はどれか。
  4. ハミング符号(7, 4)の符号語を5つ並べ、各符号語の1ビット目を5つ、次に2ビット目を5つ、という順に送る(深さ5のインターリーブ)。受信側で元の順に並べ戻してから、符号語ごとに1ビットの誤りを訂正する。連続したビットに集中して起こるバースト誤りのうち、必ず訂正できる最大の長さはどれか。
  5. 7ビットのデータ 1011001 に偶数パリティのビットを付けるとき、パリティビットの値はどれか。
