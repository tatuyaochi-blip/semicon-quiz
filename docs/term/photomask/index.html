フォトマスク(レチクル)とは

ふぉとますく

回路のパターンを描いた露光用の原版。石英ガラスの基板に遮光膜のパターンを形成する(EUVでは反射型)。縮小投影の露光装置ではウエハ上の4倍の大きさでつくる。

この用語の分野: リソグラフィ

解説の中の「フォトマスク(レチクル)」

  • フォトマスクのパターンは、数nmに細く絞った電子線をマスク上のレジストに直接当てて描く電子線描画装置でつくります。

    フォトマスク(レチクル)のパターンを描くために主に使われる装置はどれか。

  • これに電子ビームでパターンを描き、エッチングしてフォトマスクをつくります。

    フォトマスクをつくるときに使う、石英ガラスの基板に遮光膜などをあらかじめ成膜した材料を何と呼ぶか。

  • 研究開発、少量の試作、フォトマスクの製作、ナノインプリントの型の製作などに使われます。

    マスクを使わず、電子ビームでウエハ上のレジストに直接パターンを描く方式の特徴として正しいものはどれか。

「フォトマスク(レチクル)」が出てくる問題(6問)

  1. フォトマスク(レチクル)のパターンを描くために主に使われる装置はどれか。
  2. フォトマスクの上に一定の間隔をあけて張る薄い膜(ペリクル)の役割はどれか。
  3. フォトマスクをつくるときに使う、石英ガラスの基板に遮光膜などをあらかじめ成膜した材料を何と呼ぶか。
  4. ArF露光用のフォトマスクの基板に使われる材料はどれか。
  5. マスクを使わず、電子ビームでウエハ上のレジストに直接パターンを描く方式の特徴として正しいものはどれか。
  6. ウエハテストの結果を、ウエハ上のチップの位置ごとに良否で表示したウエハマップを分析する主な目的はどれか。
