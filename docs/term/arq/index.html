ARQ(自動再送要求)とは

えーあーるきゅー

Automatic Repeat reQuestの略。受信側が誤りや欠けを見つけたら、送信側に送り直してもらって正しいデータを得る誤り制御の方式。受信側は確認応答(ACK)や否定応答(NAK)を返し、送信側は一定の時間内にACKが来なければ再送する。1つずつ確認するストップアンドウェイト、Go-Back-N、選択的再送などの方式があり、TCP、無線LAN、PCI Expressのデータリンク層などで使われる。前方誤り訂正(FEC)と組み合わせることも多い。

「ARQ(自動再送要求)」は、3分野の8問の練習問題に出てきます(ネットワークの基礎, インターフェース・バス規格, 情報理論と符号の基礎など)。

ARQ(自動再送要求)の練習問題に挑戦

通信で誤りに対処する方式のARQ(自動再送要求)とFEC(前方誤り訂正)の説明として、正しいものはどれか。

  1. AARQは、受信側だけで誤りを訂正するので、送信側へ知らせを返す通信路が要らない
  2. BFECは、誤りを検出したら送り直しを求めるので、誤りが多いと遅延が大きくなりやすい
  3. CFECは、冗長なビットを使って受信側で誤りを訂正するので、片方向の放送にも使える
答えと解説を見る

正解：C. FECは、冗長なビットを使って受信側で誤りを訂正するので、片方向の放送にも使える

ARQは、CRCなどで誤りを検出し、受け取れなかったことを送信側に知らせて送り直してもらう方式で、戻りの通信路が必要で、送り直しの分だけ遅れます。FECは、冗長なビットを付けて送り、受信側だけで誤りを訂正するので、片方向の放送や、往復に時間のかかる宇宙との通信、遅れの許されない通信に向きます。実際の通信では、FECで大部分の誤りを直し、残った誤りをARQで送り直す組み合わせもよく使われます。

TCPの送信側が、セグメントが失われたと判断して再送するきっかけとして正しいものはどれか。

  1. A受信側から、届かなかったセグメントの再送を求める否定応答(NAK)を受け取ったとき
  2. B途中のルータから、パケットを捨てたことを知らせるICMPのメッセージを受け取ったとき
  3. C決められた時間内にACKが返ってこないとき(再送タイムアウト)か、同じ確認番号のACK(重複ACK)を続けて受け取ったとき
答えと解説を見る

正解：C. 決められた時間内にACKが返ってこないとき(再送タイムアウト)か、同じ確認番号のACK(重複ACK)を続けて受け取ったとき

TCPの受信側は、届いたデータの続きの番号(次に受け取りたいシーケンス番号)をACKで返します。途中のセグメントが失われると、その後のセグメントが届いても同じ番号のACK(重複ACK)を返し続けます。送信側は重複ACKを3つ受け取ると、タイムアウトを待たずにそのセグメントを再送します(高速再送)。ACKがまったく返らない場合は、RTTの測定から決めた再送タイムアウトの時間が過ぎてから再送し、失敗が続くとタイムアウトの時間を倍々に延ばしていきます。TCPには否定応答(NAK)はなく、混雑で捨てたパケットについてルータが知らせることも一般にはないため、損失はACKの様子から推定します。

「ARQ(自動再送要求)」が出てくる問題(8問)

  1. 通信で誤りに対処する方式のARQ(自動再送要求)とFEC(前方誤り訂正)の説明として、正しいものはどれか。
  2. TCPの送信側が、セグメントが失われたと判断して再送するきっかけとして正しいものはどれか。
  3. USBの転送の種類のうち、アイソクロナス転送の特徴として正しいものはどれか。
  4. 高速なシリアル伝送の要求として「ビット誤り率(BER)が10のマイナス12乗以下」とされているときの意味として正しいものはどれか。
  5. PCI Expressで使われるクレジット方式のフロー制御の説明として正しいものはどれか。
  6. OSI参照モデルで、IPアドレスのような論理的なアドレスを使い、異なるネットワークの間でパケットを中継して宛先まで届ける役割をもつ層はどれか。
  7. UDPの特徴として正しいものはどれか。
  8. 無線LANが、有線のイーサネットで使われてきたCSMA/CDではなく、CSMA/CAを使う主な理由として正しいものはどれか。
