ヒープとは

ひーぷ

プログラムの実行中にmallocなどで必要な大きさのメモリを確保し、freeで返す領域。確保と解放を繰り返すと断片化が起きることがある。

この用語の分野: リンカ・ローダと実行形式

解説の中の「ヒープ」

  • ヒープは番地の大きい方へ、スタックは小さい方へ伸びるので、間の空きは、ヒープを多く使うプログラムにもスタックを多く使うプログラムにも使えます。

    プロセスのヒープとスタックを、間に広い空きをはさんで反対向きに伸ばす配置にする利点として正しいものはどれか。

  • ヒープは、プログラムの実行中に必要な大きさのメモリを確保し、不要になったらfreeで返す領域です。

    C言語のmallocで確保したメモリは、一般にプロセスのどの領域から取られるか。

  • 典型的な配置では、番地の小さい側から機械語のテキスト、初期値のあるデータ、0で始まるBSSが並び、その上にヒープが番地の大きい方へ伸びます。

    Linuxなどの一般的なプロセスのメモリ配置を、番地の小さい方から並べたものとして正しいものはどれか。

「ヒープ」が出てくる問題(6問)

  1. プロセスのヒープとスタックを、間に広い空きをはさんで反対向きに伸ばす配置にする利点として正しいものはどれか。
  2. C言語のmallocで確保したメモリは、一般にプロセスのどの領域から取られるか。
  3. Linuxなどの一般的なプロセスのメモリ配置を、番地の小さい方から並べたものとして正しいものはどれか。
  4. ASLR(アドレス空間配置のランダム化)の目的として正しいものはどれか。
  5. メモリのページに「書き込み可能」と「実行可能」を同時には許さない(W^X、書き込みと実行の分離)ことで防ぎやすくなる攻撃はどれか。
  6. 再帰が深くなりすぎてスタックの上限を超えたとき、Linuxなどで一般に起こることとして正しいものはどれか。
