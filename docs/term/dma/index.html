DMA(ダイレクトメモリアクセス)とは

でぃーえむえー

CPUを介さずに、周辺装置とメモリの間で直接データを転送する仕組み。大量のデータ転送の間もCPUが別の処理を進められる。

「DMA(ダイレクトメモリアクセス)」は、7分野の11問の練習問題に出てきます(OSとハードウェア, CPU・アーキテクチャ, インターフェース・バス規格など)。

この用語の分野: CPU・アーキテクチャ

DMA転送の仕組み

プログラムI/Oでは、CPU自身がロード命令とストア命令ですべてのワードを転送します。ダイレクトメモリアクセス(DMA)では、CPUはDMAコントローラ(またはデバイス自身のDMAエンジン)に転送元、転送先、長さ、起動条件(トリガ)を設定するだけで、ほかの処理に戻ります。コントローラはバスの制御権を得てデータを転送し、終わると完了割り込みを発生させます。たとえばマイコンでは、タイマで一定間隔ごとにADC変換を起動し、DMAで各変換結果を配列に格納していき、バッファがいっぱいになったときだけCPUを起こす、といった使い方ができます。

高速デバイスのディスクリプタリング

ネットワークカードやNVMe SSDはディスクリプタリングを使います。これはメインメモリ上の循環テーブルで、各エントリにバッファのアドレスと長さが入っています。CPUは空いているディスクリプタに情報を書き込み、どこまで書いたかをデバイスのレジスタ(ドアベルと呼ばれることが多い)に一度だけ書き込みます。デバイスはDMAでディスクリプタを読み込み、自ら転送を行い、終わったエントリに完了の印を付けます。こうしてCPUとデバイスはお互いを待つことなく多数の転送を進められ、分散した複数のバッファのリストも1回の操作で扱えます。これをスキャッタ・ギャザーと呼びます。

キャッシュとピン留めされたメモリ

DMAはCPUのキャッシュを経由しないため、CPUから見たメモリとデバイスから見たメモリの内容が食い違うことがあります。ハードウェアが一貫性(コヒーレンシ)を保たない場合、ドライバは、デバイスがバッファを読む前に変更済みのキャッシュラインをメモリに書き戻し、デバイスが書き込んだデータをCPUが読む前に該当範囲のキャッシュを無効化して、古い値が使われないようにします。また、OSは通常のページをいつでも移動したりスワップアウトしたりできるため、DMA用のバッファはその場に固定(ピン留め)します。ピン留めされたホストメモリを使うと、GPUは中間コピーなしでデータを転送でき、転送と計算を重ね合わせることもできます。

IOMMUによるメモリ保護

DMAはメモリに直接書き込むので、故障したデバイスや悪意のあるデバイスがカーネルのデータを書き換えたり暗号鍵を読み取ったりする恐れがあり、高速な外部ポートで接続するデバイスでは特に懸念されます。IOMMU(入出力メモリ管理ユニット)は、MMUがCPUに対して行うことをデバイスに対して行います。デバイスが使うアドレスを物理アドレスに変換し、OSが許可した領域以外へのアクセスを遮断します。また、ばらばらの物理ページをデバイスから連続して見せることもでき、デバイスを仮想マシンに直接割り当てても安全になります。

DMA(ダイレクトメモリアクセス)の練習問題に挑戦

ネットワークカードやNVMeのSSDなどで広く使われる、メモリ上の記述子(ディスクリプタ)の輪(リング)を使ったDMAのしくみについて正しいものはどれか。

  1. ACPUがデータを1バイトずつ機器のレジスタに書き込んで転送する
  2. BCPUは転送の番地や長さを記述子に書いて機器に知らせるだけで、機器が記述子を読んで自分で転送を進める
  3. C記述子は機器の中にだけあり、CPUからは見えない
答えと解説を見る

正解：B. CPUは転送の番地や長さを記述子に書いて機器に知らせるだけで、機器が記述子を読んで自分で転送を進める

記述子のリングは、メインメモリ上に並べた「どの番地から何バイト送るか」を書いた表を輪のように使うしくみです。CPUは空いている記述子に転送の内容を書き、機器のレジスタに「ここまで書いた」と1回知らせます。機器はDMAで記述子を読み、データを転送し、終わった記述子に完了の印を付けます。CPUと機器が互いを待たずに多くの転送を進められます。

マイコンでADコンバータの変換結果を一定の間隔で大量に取り込むとき、DMAを使う利点として正しいものはどれか。

  1. AADコンバータの分解能が自動で上がる
  2. B入力の電圧が自動で大きくなる
  3. C変換が終わるたびにCPUが割り込みで読む必要がなく、DMAがメモリに並べてくれるので、CPUの負担が減る
答えと解説を見る

正解：C. 変換が終わるたびにCPUが割り込みで読む必要がなく、DMAがメモリに並べてくれるので、CPUの負担が減る

変換のたびに割り込みでCPUが結果を読むと、1秒に数万回の取り込みでは割り込みの手間だけでCPUの多くの時間が使われます。DMAを使えば、変換が終わるたびにDMAが結果をメモリの配列に順に書き込み、配列がいっぱいになったときだけCPUに知らせます。タイマで変換を始める設定と組み合わせれば、正確な間隔での取り込みをCPUなしで続けられます。

よくある質問

DMAとは何の略ですか?

Direct Memory Access(ダイレクトメモリアクセス)の略です。CPUがワードを1つずつコピーしなくても周辺装置がメインメモリとの間でデータを転送できる仕組みで、転送中もCPUは別の処理を行えます。

DMAとプログラムI/Oの違いは?

プログラムI/Oでは、CPU自身がすべてのデータワードをデバイスとの間で読み書きします。DMAではCPUは転送を設定するだけで、終わったら通知を受けるので、大量または頻繁な転送でCPU時間を節約できます。

DMAでメモリに転送した後にキャッシュを無効化する必要があるのはなぜですか?

ハードウェアによるキャッシュコヒーレンシがないシステムでは、CPUのキャッシュにそのメモリ範囲の古いコピーが残っている可能性があるからです。無効化することで、CPUはデバイスが書き込んだ新しいデータを読むようになります。

「DMA(ダイレクトメモリアクセス)」が出てくる問題(11問)

  1. ネットワークカードやNVMeのSSDなどで広く使われる、メモリ上の記述子(ディスクリプタ)の輪(リング)を使ったDMAのしくみについて正しいものはどれか。
  2. マイコンでADコンバータの変換結果を一定の間隔で大量に取り込むとき、DMAを使う利点として正しいものはどれか。
  3. キャッシュの一貫性をハードウェアが保たない(非コヒーレントな)システムで、装置がDMAで主記憶に書き込んだデータをCPUが読む前に、ソフトウェアが行う必要のある処理はどれか。
  4. パソコンにつないだ外部の機器が、DMAを使ってメインメモリの内容を勝手に読み書きする攻撃への対策として正しいものはどれか。
  5. CPUを介さずに、周辺装置とメモリの間で直接データを転送する仕組みはどれか。
  6. キャッシュの書き込み方式で、ライトバック方式の説明として正しいものはどれか。
  7. CPUのメモリをピン留め(ページロック)してからGPUへ転送すると速くなる理由として正しいものはどれか。
  8. IOMMUの主な役割として正しいものはどれか。
  9. デバイスドライバの役割として正しいものはどれか。
  10. 一般的なOSで、アプリケーションが装置のレジスタを直接読み書きできないようにしている主な理由はどれか。
  11. 制御フロー完全性をハードウェアで支える機能について、関数からの戻りを守るものと、関数ポインタなどによる間接的な呼び出しやジャンプを守るものの組み合わせとして、正しいものはどれか。
