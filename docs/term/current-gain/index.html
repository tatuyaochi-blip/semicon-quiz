電流増幅率(hFE)とは

でんりゅうぞうふくりつ

バイポーラトランジスタのコレクタ電流とベース電流の比(IC/IB)。

「電流増幅率(hFE)」は、2分野の21問の練習問題に出てきます(バイポーラトランジスタ, 車載半導体と機能安全など)。

この用語の分野: バイポーラトランジスタ

αとβの関係

電流増幅率には2通りの表し方があります。ベース接地の電流増幅率 α = IC/IE は、エミッタ電流のごく一部がベースで失われるため、1よりわずかに小さくなります。エミッタ接地の電流増幅率はβまたはhFE = IC/IB と書き、β = α/(1 − α) で求められます。α = 0.99ならβ = 99、α = 0.995ならβ = 199となり、αのわずかな変化がhFEを大きく変えます。活性領域では IC ≈ hFE × IB で、hFE = 100のときベース電流10 µAでコレクタ電流は約1 mAになります(コレクタ側の回路がその電流を供給できる場合)。

hFEを決めるトランジスタ内部の要因

NPNトランジスタの場合、ベース電流は主に、ベースからエミッタへ逆注入される正孔と、ベースを横切る途中で再結合する電子から成ります。エミッタを高濃度にすると逆注入される正孔が抑えられて注入効率が高まり、ベースを少数キャリアの拡散長よりずっと薄くすると、ほぼすべての電子がコレクタに届きます。ただしエミッタを極端に高濃度にすると、バンドギャップ狭窄によって効果が頭打ちになります。ヘテロ接合バイポーラトランジスタ(HBT)は、エミッタにバンドギャップの広い材料を使ってこれを解決しています。なお、ベースを薄くするとベース抵抗が増え、パンチスルーの危険も高まります。

回路設計でhFEに頼らない理由

hFEは小信号用トランジスタで数十〜数百、パワー素子で数十が一般的ですが、同じ品番でも個体差が大きく、100〜400のような範囲でランク分けされることもよくあります。また温度が1 °C上がるごとにおよそ0.5〜1%上昇し、中程度のコレクタ電流で最大になります。低電流側では空乏層内の再結合、高電流側では高注入効果とカーク効果によって低下します。そのため安定したバイアス回路では、エミッタ抵抗と分圧抵抗によるベースバイアスを使い、動作点をhFEではなく抵抗値で決めます。

hFEとhfeの違い、スイッチング動作

大文字のhFEは直流の比IC/IBでバイアス計算に使い、小文字のhfeは動作点での小信号の比ΔIC/ΔIBで、交流利得や入力抵抗の計算に使います。両者は近い値になることが多いものの、同じではありません。スイッチング用途ではトランジスタを飽和させて使います。このときコレクタ電流は負荷で制限されるため、IC/IB(強制β)は意図的にhFEより小さくします。飽和を確実にするため、ベース電流はIC/hFE(min)の2〜10倍程度を流すのが一般的ですが、そのぶん蓄積電荷が増えてターンオフが遅くなります。

電流増幅率(hFE)の練習問題に挑戦

バイポーラトランジスタの直流電流増幅率hFEを表す式はどれか。(IC:コレクタ電流、IB:ベース電流、IE:エミッタ電流)

  1. AIB / IC
  2. BIC / IB
  3. CIE / IC
答えと解説を見る

正解：B. IC / IB

hFEはエミッタ接地での直流電流増幅率で、hFE = IC/IB です。小信号用トランジスタでは数十〜数百、パワートランジスタでは数十程度が一般的です。同じ型番でも個体差が大きく(例えば100〜400のようにランク分けされる)、温度や電流でも変わるため、回路はhFEの値に頼らず動作するように設計するのが基本です。ベース接地の電流増幅率αは IC/IE で、1よりわずかに小さい値です。

ベース接地電流増幅率α = 0.99のバイポーラトランジスタのエミッタ接地電流増幅率βはおよそいくらか。

  1. A0.99
  2. B9.9
  3. C99
答えと解説を見る

正解：C. 99

αとβには β = α/(1 − α) の関係があり、α = 0.99 なら β = 0.99 ÷ 0.01 = 99 です。逆に α = β/(1 + β) です。α = 0.995 なら β = 199 と、αがわずかに1に近づくだけでβは大きく変わります。エミッタ電流のうちベースで失われる割合(1 − α)が1%なら、ベース電流はコレクタ電流の約1/99になるという意味で、ベースでの損失をいかに減らすかが設計の要になります。

よくある質問

hFEとβ(ベータ)の違いは?

実用上は同じ量で、エミッタ接地の電流増幅率IC/IBを指します。hFEはデータシートで直流値に使われるhパラメータの名前で、βは教科書やデバイス物理でよく使われる記号です。

hFEとhfeの違いは何ですか?

hFEはある動作点での直流電流増幅率IC/IB、hfeはその動作点まわりの小信号電流増幅率ΔIC/ΔIBです。バイアス設計にはhFEを、交流解析にはhfeを使います。

hFEがトランジスタごとに大きくばらつくのはなぜですか?

hFEはベース幅、ドーピング、再結合に左右され、これらは素子ごとにばらつきます。さらに温度やコレクタ電流によっても変わるため、よい設計では正確なhFEに頼らず、帰還抵抗で動作点を決めます。
