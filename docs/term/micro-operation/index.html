マイクロオペレーションとは

まいくろおぺれーしょん

CPUが命令を内部で分解した単純な操作。μopとも書く。x86のCPUは複雑な命令をμopに分け、RISCと同じような高速な方法で実行する。

この用語の分野: 命令セット・アセンブリ

解説の中の「マイクロオペレーション」

  • そこで現在のx86のCPUは、内部でこうした命令をロードと加算のような単純な操作(マイクロオペレーション)に分けて実行しています。

    x86の命令「add eax, [rbx]」のように、演算命令がメモリ上の値を直接使える方式について正しいものはどれか。

  • x86のCPUは、可変長で複雑な命令を前段のデコーダでマイクロオペレーション(μop)と呼ぶ単純な操作に分け、後段ではそれらをアウトオブオーダーで実行します。

    現在の高性能なx86のCPUが、複雑な命令を内部でどのように実行しているかの説明として正しいものはどれか。

「マイクロオペレーション」が出てくる問題(2問)

  1. x86の命令「add eax, [rbx]」のように、演算命令がメモリ上の値を直接使える方式について正しいものはどれか。
  2. 現在の高性能なx86のCPUが、複雑な命令を内部でどのように実行しているかの説明として正しいものはどれか。
