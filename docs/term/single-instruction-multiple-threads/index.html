SIMTとは

しむてぃー

単一命令・複数スレッドの方式。プログラムはスレッドごとに書くが、ハードウェアはワープ(NVIDIAでは32本)ごとにスレッドを束ねて同じ命令で実行する。

「SIMT」は、1分野の2問の練習問題に出てきます(GPUプログラミングなど)。

この用語の分野: GPUプログラミング

SIMTのスレッド実行の仕組み

単一命令・複数スレッド(SIMT)のモデルでは、プログラマはカーネルを1つのスレッド用の普通のコードとして書き、それを数千のスレッドが別々のデータに対して実行します。ハードウェアはスレッドを固定数の束にまとめます。NVIDIAのGPUでは32スレッドのワープ、AMDのGPUでは64または32スレッドのウェーブフロントと呼びます。1つの命令を束全体のためにフェッチ・デコードし、束の全スレッドがそれぞれ自分のレジスタとデータを使って足並みをそろえて実行します。制御回路のコストを多数の演算レーンで分け合えるので、チップ面積の大部分を演算に回せます。

分岐ダイバージェンス

スレッドはそれぞれ独立に書かれているので、同じワープ内のスレッドが別々の分岐に進むことがあります。ハードウェアは、各経路を順番に実行し、その経路にいないスレッドをマスクして無効にし、その後で合流させることでこれに対処します。正しさは保たれますが、if-elseの両側に半分ずつスレッドが分かれると、ワープは両方に時間を使い、スループットはおよそ半分になります。性能を意識したコードでは、同じワープのスレッドが同じ経路をたどるようにデータを並べます。たとえば分岐条件を、各スレッドのデータではなくワープ番号に依存させます。

SIMTとCPUのSIMDの違い

CPUの単一命令・複数データ(SIMD)拡張は、4個や8個など決まった数の要素を持つベクトルレジスタに1つの命令を適用します。プログラムやコンパイラはその幅に合わせて書く必要があり、明示的なベクトル命令や、端の処理のためのマスクを使います。SIMTはこの幅を隠します。コードはスカラーの1スレッドを記述し、ハードウェアが多数のスレッドからベクトルを組み立て、ダイバージェンス時のマスク処理も管理します。内部の実行は似ているので、SIMTの性能もワープ内のスレッドの足並みをそろえられるかどうかに左右されます。

実践上の帰結

GPUプログラミングでよく言われるいくつかの決まりは、SIMTから導かれます。スレッドブロックの大きさは、一部が空のまま動くワープが出ないよう、通常32の倍数にします。メモリアクセスは、ワープ内の隣り合うスレッドが隣り合う番地にアクセスするときに最も速く、ハードウェアがそれらを少数の幅広いトランザクションにまとめられます。これをコアレッシングと呼びます。また、GPUは多くのワープを常駐させ、どれかが止まるたびに準備のできた別のワープに切り替えることで、長いメモリレイテンシを隠します。そのため、コアあたりのアクティブなワープ数が十分にある高いオキュパンシが、性能上重要になることが多いのです。

SIMTの練習問題に挑戦

GPUのSIMT(単一命令・複数スレッド)の方式と、CPUのSIMD命令の違いとして正しいものはどれか。

  1. ASIMTは1つのデータに複数の命令を同時に行い、SIMDは1つの命令を1つのデータに行う
  2. BSIMTとSIMDはまったく同じもので、名前が違うだけである
  3. CSIMTでは各スレッドを独立したプログラムとして書け、分岐もハードウェアが処理するが、SIMDではプログラマやコンパイラが幅の決まったベクトルの命令を明示的に使う
答えと解説を見る

正解：C. SIMTでは各スレッドを独立したプログラムとして書け、分岐もハードウェアが処理するが、SIMDではプログラマやコンパイラが幅の決まったベクトルの命令を明示的に使う

CPUのSIMDでは、4個や8個のデータをまとめたベクトルのレジスタに1つの命令をかけるので、プログラムはベクトルの幅を意識して書きます。GPUのSIMTでは、プログラマは1本のスレッドの処理を普通に書き、ハードウェアが32本ずつ束ねて同じ命令で動かします。スレッドごとに分岐してもよく、ハードウェアが分岐した経路を順に実行しますが、そのときは効率が下がります。

よくある質問

GPUのワープとは何ですか?

NVIDIAのGPUで、同じ命令を足並みをそろえて一緒に実行する32スレッドのまとまりです。SIMTモデルにおける命令発行の基本単位で、AMDではこれに相当するものをウェーブフロントと呼びます。

SIMTとSIMDの違いは?

SIMDは固定幅のベクトル命令を提供し、プログラマやコンパイラがそれを明示的に使う必要があります。SIMTでは各スレッドを独立したスカラーのコードとして書け、ハードウェアがスレッドをワープにまとめ、分岐のダイバージェンスも処理します。

ワープダイバージェンスとは何ですか?

同じワープのスレッドが異なる分岐経路に進むことです。ハードウェアは非アクティブなスレッドをマスクしながら各経路を順番に実行するため、経路が合流するまで効率が下がります。

解説の中の「SIMT」

  • GPUのSIMTでは、プログラマは1本のスレッドの処理を普通に書き、ハードウェアが32本ずつ束ねて同じ命令で動かします。
