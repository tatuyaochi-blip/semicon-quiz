STT-MRAMとは

えすてぃーてぃーえむらむ

スピン偏極した電流がもつスピントランスファートルクで、MTJの記録層の磁化を反転させて書き込むMRAM。組み込み用の不揮発メモリとして量産されている。

「STT-MRAM」は、1分野の4問の練習問題に出てきます(次世代メモリなど)。

この用語の分野: 次世代メモリ

STT-MRAMの練習問題に挑戦

STT-MRAMで情報を書き込む方法として正しいものはどれか。

  1. A外部のコイルが発生する磁界だけで書き込む
  2. B紫外線を照射して書き込む
  3. Cスピン偏極した電流によるスピントランスファートルクで磁化を反転させる
答えと解説を見る

正解：C. スピン偏極した電流によるスピントランスファートルクで磁化を反転させる

STT-MRAMでは、MTJに電流を流し、参照層でスピンの向きがそろった電子が記録層に角運動量を渡す(スピントランスファートルク)ことで磁化を反転させます。電流の向きで0と1を書き分けます。外部磁界で書き込む初期のMRAMは素子を小さくするほど大きな電流が必要でしたが、STTでは書き込み電流が素子の面積に比例して小さくなるため、微細化に向き、現在の主流です。

近年のSTT-MRAMで、磁化の向きが膜面に垂直なMTJ(垂直磁化MTJ)が主流になった理由として正しいものはどれか。

  1. A製造に磁性材料が不要になるため
  2. B微細化しても熱安定性を保ちやすく、書き込み電流も下げやすいため
  3. C読み出しに光が使えるため
答えと解説を見る

正解：B. 微細化しても熱安定性を保ちやすく、書き込み電流も下げやすいため

膜面内に磁化をもつMTJは、楕円形などの素子の形状で磁化の向きを安定させるため、小さくすると安定性が保てません。垂直磁化MTJは、CoFeBとMgOの界面などで生じる垂直磁気異方性で磁化を安定させるため、円形の小さな素子でも熱安定性を確保でき、書き込み電流も小さくできます。この材料技術が、STT-MRAMの量産化(2010年代後半)を可能にしました。

解説の中の「STT-MRAM」

  • STT-MRAMでは、MTJに電流を流し、参照層でスピンの向きがそろった電子が記録層に角運動量を渡す(スピントランスファートルク)ことで磁化を反転させます。

    STT-MRAMで情報を書き込む方法として正しいものはどれか。

  • この材料技術が、STT-MRAMの量産化(2010年代後半)を可能にしました。

    近年のSTT-MRAMで、磁化の向きが膜面に垂直なMTJ(垂直磁化MTJ)が主流になった理由として正しいものはどれか。

  • STT-MRAMの磁化反転は熱ゆらぎの影響を受ける確率的な現象で、同じ電流とパルス幅でも、まれに書き込みに失敗します(書き込みエラー率)。

    STT-MRAMの書き込みが確率的な性質をもつことによる設計上の課題として正しいものはどれか。

  • STT-MRAMは読み出しも書き込みもMTJに電流を流すため、読み出し電流が書き込みの反転電流に近いと、読み出しのたびに確率的に磁化が反転するおそれがあります(読み出しディスターブ)。

    STT-MRAMで、読み出し電流の大きさに制限が必要になる理由として正しいものはどれか。

「STT-MRAM」が出てくる問題(4問)

  1. STT-MRAMで情報を書き込む方法として正しいものはどれか。
  2. 近年のSTT-MRAMで、磁化の向きが膜面に垂直なMTJ(垂直磁化MTJ)が主流になった理由として正しいものはどれか。
  3. STT-MRAMの書き込みが確率的な性質をもつことによる設計上の課題として正しいものはどれか。
  4. STT-MRAMで、読み出し電流の大きさに制限が必要になる理由として正しいものはどれか。
