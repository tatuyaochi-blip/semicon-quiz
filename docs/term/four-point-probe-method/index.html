四探針法とは

よんたんしんほう

一直線に並べた4本の針の外側2本に電流を流し、内側2本の電圧を測って、ウエハや薄膜のシート抵抗を求める方法。

「四探針法」は、1分野の1問の練習問題に出てきます(計測・分析など)。

この用語の分野: 計測・分析

四探針法の練習問題に挑戦

電極をつくらずに、ウエハの表面にコロナ放電で電荷を載せ、表面電位の変化を測って酸化膜や界面の電気的な特性を評価する方法はどれか。

  1. A四探針法
  2. BX線回折
  3. Cコロナ帯電を使った非接触の電気的評価(COCOSなど)
答えと解説を見る

正解：C. コロナ帯電を使った非接触の電気的評価(COCOSなど)

コロナ放電でウエハ表面に決まった量の電荷を載せ、ケルビンプローブで表面電位を非接触で測ると、MOS構造をつくらなくても、酸化膜の厚さや膜中の電荷、界面準位、リーク特性などを評価できます。ゲート電極をつくる工程が不要で、測ったウエハもそのまま次の工程に進められるため、製造ラインでの監視に使われます。四探針法やX線回折では、これらの電気的特性は分かりません。
