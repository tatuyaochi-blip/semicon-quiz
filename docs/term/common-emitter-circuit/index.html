エミッタ接地回路とは

えみったせっちかいろ

エミッタを入力と出力の共通端子にした増幅回路。電流利得と電圧利得の両方が得られ、最もよく使われる。

「エミッタ接地回路」は、1分野の1問の練習問題に出てきます(バイポーラトランジスタなど)。

この用語の分野: バイポーラトランジスタ

エミッタ接地回路の練習問題に挑戦

エミッタ接地増幅回路の高周波特性を悪くするミラー効果の説明として正しいものはどれか。

  1. Aベース-コレクタ間の容量が、電圧利得に応じて入力側から見て大きな容量に見える
  2. Bエミッタの抵抗が温度によって変化する
  3. Cコレクタ電流が熱雑音で揺らぐ
答えと解説を見る

正解：A. ベース-コレクタ間の容量が、電圧利得に応じて入力側から見て大きな容量に見える

エミッタ接地回路ではコレクタ電圧がベースと逆位相で大きく振れるため、ベース-コレクタ間の容量Cμは入力側から見ると約(1 + |Av|)倍に見えます。例えばCμ = 2 pF、利得100なら約200 pFになり、信号源の抵抗とともにローパスフィルタを作って帯域を狭めます。対策には、ベース接地段を重ねて利得をコレクタ側で取るカスコード接続や、信号源の抵抗を下げることがあります。

解説の中の「エミッタ接地回路」

  • エミッタ接地回路ではコレクタ電圧がベースと逆位相で大きく振れるため、ベース-コレクタ間の容量Cμは入力側から見ると約(1 + |Av|)倍に見えます。
