インピーダンスとは

いんぴーだんす

交流回路で、電圧のフェーザを電流のフェーザで割った複素数 Z = V/I [Ω]。実部が抵抗R、虚部がリアクタンスXで、Z = R + jX と表す。コイルは jωL、コンデンサは 1/(jωC) = −j/(ωC) で、周波数によって大きさが変わる。大きさ |Z| は電圧と電流の振幅の比、偏角は電流に対する電圧の位相の進みを表す。

やさしい解説で読む: 交流と直流の違いとは? インピーダンスをやさしく

「インピーダンス」は、8分野の31問の練習問題に出てきます(回路解析(交流回路・線形回路・過渡現象), アナログ・電子回路, 電気回路・電磁気の基礎など)。

この用語の分野: 回路解析(交流回路・線形回路・過渡現象)

抵抗を交流に広げた量

直流のオームの法則 V = RI を、交流では V = ZI と複素数のまま書けるようにしたのがインピーダンスです。Z = 3 + j4 Ω なら、大きさは √(3² + 4²) = 5 Ω、偏角は約53.1°で、電流は電圧より53.1°遅れます。直列ではインピーダンスを足し、並列では逆数(アドミタンス)を足すという計算規則も、抵抗と同じです。

周波数で変わる部品の性質

コイルのリアクタンス ωL は周波数に比例して大きくなり、コンデンサのリアクタンス 1/(ωC) は周波数に反比例して小さくなります。このため、直流ではコイルは短絡、コンデンサは開放のように振る舞い、高い周波数ではその逆になります。フィルタ、共振回路、電源のデカップリングは、どれもこの周波数依存性を利用しています。

いろいろな「インピーダンス」

増幅回路の入力インピーダンスや出力インピーダンス、配線の特性インピーダンス、電源の経路のインピーダンスなど、電子回路では多くの場面でこの言葉が使われます。どれも「ある端子から見た電圧と電流の比」という同じ考え方です。高速信号では、配線の特性インピーダンスと終端のインピーダンスがそろっていないと反射が起こります。

インピーダンスの練習問題に挑戦

抵抗R = 30 Ωと、リアクタンスXL = 40 Ωのコイルを直列に接続した回路のインピーダンスの大きさはいくらか。(コイルの抵抗分は無視する)

  1. A70 Ω
  2. B10 Ω
  3. C50 Ω
答えと解説を見る

正解：C. 50 Ω

抵抗とコイルでは電圧の位相が90°ずれるため、そのまま足さずに複素数(ベクトル)として合成します。Z = R + jXL = 30 + j40 Ωで、大きさは √(30² + 40²) = √2500 = 50 Ωです。電流は電圧より φ = tan⁻¹(40/30) ≈ 53° 遅れ、力率は cos φ = 30/50 = 0.6です。

巻数比 N1:N2 = 10:1 の理想変圧器の二次側に8 Ωの抵抗負荷をつないだ。一次側から見たインピーダンスはいくらか。

  1. A800 Ω
  2. B80 Ω
  3. C0.8 Ω
答えと解説を見る

正解：A. 800 Ω

理想変圧器では、一次側の電圧は二次側の n = N1/N2 倍、電流は 1/n 倍になるため、一次側から見たインピーダンス V1/I1 は二次側の V2/I2 の n² 倍になります。10² × 8 Ω = 800 Ωです。このインピーダンス変換の性質から、変圧器はアンプとスピーカーの間などのインピーダンス整合にも使われます。

よくある質問

インピーダンスと抵抗はどう違うのですか?

抵抗は電圧と電流の比が周波数によらず位相もずれない場合で、インピーダンスの実部に当たります。インピーダンスは、コイルやコンデンサによる位相のずれと周波数による変化も含めて、複素数で表した量です。

インピーダンスの大きさだけで電力を計算できますか?

できません。有効電力を求めるには、電流の2乗に実部(抵抗分)を掛けるか、力率 cos φ = R/|Z| を使う必要があります。例えば 8 + j6 Ω に10 Aが流れると、消費される電力は 10² × 8 = 800 W で、|Z| = 10 Ω を使った1,000 VAは皮相電力です。
