変数とは

へんすう

プログラムの中で値を記憶しておくための、名前の付いた入れ物。整数型や実数型などの型を宣言して使い、代入によって値を書き換える。新しい値を代入すると、前の値は失われる。

「変数」は、12分野の78問の練習問題に出てきます(プログラミングの基礎(擬似言語のトレース), リンカ・ローダと実行形式, マルチコアと同期など)。

変数の練習問題に挑戦

組込みのプログラムで、32ビットの周辺レジスタの値を入れる変数を、unsigned int ではなく stdint.h の uint32_t で宣言することが多い。主な理由として正しいものはどれか。

  1. Auint32_t は、値が最大値を超えたときに0に戻らず、最大値で止まる(飽和する)から
  2. Buint32_t で宣言した変数は、コンパイラの最適化で読み書きが省かれなくなるから
  3. Cunsigned int の大きさは処理系によって違うが、uint32_t はちょうど32ビットの符号なし整数と決まっているから
答えと解説を見る

正解：C. unsigned int の大きさは処理系によって違うが、uint32_t はちょうど32ビットの符号なし整数と決まっているから

stdint.h の uint8_t、uint16_t、uint32_t、int32_t などは、ビット数が名前のとおりに決まった整数型(固定幅の整数型)です。unsigned int は16ビットのことも32ビットのこともあるので、レジスタの幅に合わせたい場面や、通信のデータの形を決める場面で固定幅の型を使うと、別のCPUに移しても意味が変わりません。uint32_t は、ほかの符号なしの整数型と同じく、あふれると 2³² で割った余りの値になります。読み書きを省かせないためには、型とは別に volatile を付けます。

C言語で、(1) 関数の中で static を付けずに宣言した局所変数、(2) malloc で確保した領域、(3) 関数の外で宣言した変数、のそれぞれが存在する期間(寿命)の組み合わせとして正しいものはどれか。

  1. A(1) プログラムの終了まで、(2) 確保した関数から戻るまで、(3) プログラムの終了まで
  2. B(1) 宣言したブロックから抜けるまで、(2) free で解放するまで、(3) プログラムの終了まで
  3. C(1) 宣言したブロックから抜けるまで、(2) プログラムの終了まで(途中では解放できない)、(3) その変数を最初に使った関数から戻るまで
答えと解説を見る

正解：B. (1) 宣言したブロックから抜けるまで、(2) free で解放するまで、(3) プログラムの終了まで

(1) の自動変数は、一般にスタックに置かれ、宣言したブロックに入ったときに作られて、抜けると無くなります。(2) の malloc で確保した領域はヒープに置かれ、関数から戻っても残り、free で解放するまで使えます。(3) の関数の外の変数(および static を付けた変数)は、プログラムの実行中ずっと存在し、.data や .bss のような静的な領域に置かれます。寿命の終わった領域を指すポインタを使うことや、free を忘れて領域が残り続けることが、よくある誤りの原因になります。
