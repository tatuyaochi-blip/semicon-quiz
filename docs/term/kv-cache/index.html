KVキャッシュとは

けーぶいきゃっしゅ

大規模言語モデルの推論で、すでに処理したトークンのアテンションのKeyとValueを保存しておくメモリ。再計算を避けるが、文章の長さとバッチに比例して大きくなる。

「KVキャッシュ」は、1分野の4問の練習問題に出てきます(AIハードウェアとソフトウェアスタックなど)。

この用語の分野: AIハードウェアとソフトウェアスタック

KVキャッシュの練習問題に挑戦

大規模言語モデルの推論で使われるKVキャッシュの役割として正しいものはどれか。

  1. Aよく使われる質問と答えを保存しておき、同じ質問にすぐ答える
  2. BCPUのキャッシュメモリにモデルの重みをすべて入れる
  3. Cすでに処理したトークンのアテンションのKeyとValueを保存しておき、新しいトークンのたびに計算し直すのを避ける
答えと解説を見る

正解：C. すでに処理したトークンのアテンションのKeyとValueを保存しておき、新しいトークンのたびに計算し直すのを避ける

アテンションの計算では、新しいトークンが、それまでのすべてのトークンのKeyとValueを参照します。前のトークンのKeyとValueは変わらないので、毎回計算し直さずに保存しておけば、新しいトークンの分だけ計算すれば済みます。これがKVキャッシュです。計算は大きく減りますが、保存するKeyとValueの量は文章の長さとバッチの大きさに比例して増えます。

解説の中の「KVキャッシュ」

  • これがKVキャッシュです。

    大規模言語モデルの推論で使われるKVキャッシュの役割として正しいものはどれか。

  • 推論ではこのほかに、途中の結果や大規模言語モデルのKVキャッシュのメモリも必要です。

    パラメータ数70億(7B)のモデルの重みをFP16(2バイト)で持つと、重みのメモリはおよそいくらか。

  • 途中の結果やKVキャッシュのメモリもバッチに比例して増えます。

    推論でバッチサイズを大きくしすぎたときの欠点として正しいものはどれか。

  • KVキャッシュの大きさは、層の数×KeyとValueの次元×トークンの数×バッチの大きさ×1要素のバイト数で決まります。
