網目解析とは

あみめかいせき

平面に描いた回路の各網目(内側に他の枝を含まない閉路)に仮想的な網目電流を流し、各網目にキルヒホッフの電圧則を当てはめて連立方程式を立てて解く方法。2つの網目に共通の素子には、両方の網目電流の差が流れる。電圧源が多い回路や直列の多い回路で式が少なくて済む。

「網目解析」は、1分野の1問の練習問題に出てきます(回路解析(交流回路・線形回路・過渡現象)など)。

この用語の分野: 回路解析(交流回路・線形回路・過渡現象)

網目解析の練習問題に挑戦

図の回路で、E1 = 14 V、E2 = 7 V、R1 = 2 Ω、R2 = 1 Ω、R3 = 4 Ω である。網目電流 I1、I2 を図の向きにとって網目解析で解いたとき、R3 に流れる電流の大きさはどれか。

  1. A1 A
  2. B2 A
  3. C3 A
答えと解説を見る

正解：B. 2 A

左の網目では E1 = (R1 + R3)I1 − R3 I2 から 6I1 − 4I2 = 14、右の網目では E2 が I2 と逆向きなので −E2 = (R2 + R3)I2 − R3 I1 から −4I1 + 5I2 = −7 です。この連立方程式を解くと、I1 = 3 A、I2 = 1 A になります。R3 には2つの網目電流が逆向きに流れるので、電流は I1 − I2 = 2 A(下向き)です。R3 の上の節点の電圧 4 × 2 = 8 V から、R1 の電流 (14 − 8)/2 = 3 A と R2 の電流 (8 − 7)/1 = 1 A も確かめられます。
