二次遅れ系とは

にじおくれけい

伝達関数が G(s) = Kωn²/(s² + 2ζωn s + ωn²) で表される系。ωn を固有角周波数、ζ を減衰係数(減衰比)と呼ぶ。0 < ζ < 1 ではステップ応答が振動しながら最終値に近づき、ζ = 1 では行き過ぎなく最も速く落ち着き、ζ > 1 ではゆっくり近づく。ばねと質量とダンパの機械系、RLC回路、位置の制御ループなどがこの形で表される。高次の系も、主要な2つの極で近似して扱うことが多い。

「二次遅れ系」は、2分野の9問の練習問題に出てきます(制御工学の基礎, 回路解析(交流回路・線形回路・過渡現象)など)。

この用語の分野: 制御工学の基礎

減衰係数と応答の形

オーバーシュートは exp(−πζ/√(1 − ζ²)) で、ζ だけで決まります。ζ = 0.5 で約16%、ζ ≈ 0.707(1/√2)で約4.3%です。行き過ぎが最大になる時刻は π/ωd で、ωd = ωn√(1 − ζ²) は減衰しながら振動する角周波数です。ζ が小さいほど応答は速く立ち上がりますが、行き過ぎと振動が大きくなります。

極の位置との対応

0 < ζ < 1 の極は s = −ζωn ± jωd で、原点からの距離が ωn、負の実軸となす角 θ が cos θ = ζ を満たします。実部 ζωn が減衰の速さを決め、±2%の整定時間はおよそ 4/(ζωn) と見積もられます。この式は振動の包絡線から求めた近似で、実際の値はこれより少し短いことが多くあります。

周波数応答で見ると

ボード線図では、ωn を折れ点として、高い周波数でゲインが −40 dB/dec で下がり、位相は0°から −180° まで変わります。ζ が約0.707より小さいと、ωn の近くでゲインが盛り上がる共振のピークが現れます。フィードバックをかけた系では、位相余裕が小さいほど閉ループの ζ が小さくなり、目安として ζ は位相余裕(度)の約100分の1です。

二次遅れ系の練習問題に挑戦

図の直列RLC回路で、L = 1 mH、C = 0.1 µF、R = 50 Ω である。減衰係数 ζ と、ステップ応答の種類の組み合わせとして正しいものはどれか。

  1. Aζ = 0.25 で、減衰振動
  2. Bζ = 0.50 で、減衰振動
  3. Cζ = 4.0 で、過減衰
答えと解説を見る

正解：A. ζ = 0.25 で、減衰振動

解き方1(標準形との比較): 特性方程式は s² + (R/L)s + 1/(LC) = 0 で、標準形 s² + 2ζωn s + ωn² と比べると ωn = 1/√(LC) = 1×10⁵ rad/s、2ζωn = R/L です。これから ζ = (R/2)√(C/L) = 25 × √(0.1×10⁻⁶/1×10⁻³) = 25 × 0.01 = 0.25 です。解き方2(臨界抵抗との比): 臨界減衰になる抵抗は 2√(L/C) = 200 Ω なので、ζ = R/(2√(L/C)) = 50/200 = 0.25 と求めることもできます。ζ < 1 なので、ステップ応答は最終値を行き過ぎ、振動しながら収まる減衰振動です。

二次遅れ系 G(s) = ωn²/(s² + 2ζωn s + ωn²) のステップ応答が、最終値を行き過ぎて振動しながら近づく、減衰係数 ζ の範囲として正しいものはどれか。

  1. Aζ > 1
  2. Bζ = 1
  3. C0 < ζ < 1
答えと解説を見る

正解：C. 0 < ζ < 1

0 < ζ < 1 では極が共役な複素数になり、応答は振動しながら最終値に近づきます(不足減衰)。ζ = 1 では極が負の実数の重根になり、行き過ぎのない応答のうちで最も速く落ち着きます(臨界減衰)。ζ > 1 では極が2つの負の実数になり、行き過ぎはないものの、ゆっくりと近づきます(過減衰)。ζ = 0 では振動が減衰せずに続き、ζ < 0 では不安定になります。

よくある質問

減衰係数はどのくらいに設計するのがよいですか?

行き過ぎを少しにして速く応答させたい場合は、ζ = 0.5〜0.8程度がよく選ばれます。ζ ≈ 0.707 はオーバーシュートが約4.3%で、周波数応答に共振のピークが出ない境目でもあります。行き過ぎが許されない用途では、ζ ≥ 1 に設計します。

三次以上の系でも二次遅れ系の式は使えますか?

虚軸に近い2つの極(代表極)がほかの極より十分遅い場合は、その2つの極で近似して見積もれます。ほかの極や零点が近いと誤差が大きくなるので、数値計算で確かめるのが確実です。

「二次遅れ系」が出てくる問題(9問)

  1. 図の直列RLC回路で、L = 1 mH、C = 0.1 µF、R = 50 Ω である。減衰係数 ζ と、ステップ応答の種類の組み合わせとして正しいものはどれか。
  2. 二次遅れ系 G(s) = ωn²/(s² + 2ζωn s + ωn²) のステップ応答が、最終値を行き過ぎて振動しながら近づく、減衰係数 ζ の範囲として正しいものはどれか。
  3. 伝達関数 G(s) = 25/(s² + 4s + 25) の二次遅れ系の、固有角周波数 ωn と減衰係数 ζ の組み合わせとして正しいものはどれか。
  4. 減衰係数 ζ = 0.5 の二次遅れ系(零点のない標準形)にステップを入力した。オーバーシュート(最大の行き過ぎ量の、最終値に対する割合)に最も近いものはどれか。
  5. 零点のない二次遅れ系で、極を s = −σ ± jωd とする。σ を変えずに ωd だけを大きくしたときの、ステップ応答の変化として正しいものはどれか。
  6. 図の直列RLC回路で、L = 1 mH、C = 0.1 µF である。ステップ応答が振動せずに最も速く最終値に近づく臨界減衰になる抵抗Rの値はどれか。
  7. 図の直列RLC回路で、L = 1 mH、C = 0.1 µF、R = 50 Ω である。ステップ応答に現れる減衰振動の周波数に最も近いものはどれか。
  8. 図の直列RLC回路で、R = 5 Ω、L = 1 H、C = 0.25 F である。回路の特性方程式の根と、ステップ応答の種類の組み合わせとして正しいものはどれか。
  9. 一巡伝達関数のゲインを上げたところ、位相余裕が60°から30°に減った。閉ループのステップ応答の変化として正しいものはどれか。
