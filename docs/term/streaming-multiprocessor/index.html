ストリーミングマルチプロセッサとは

すとりーみんぐまるちぷろせっさ

NVIDIAのGPUで、演算器、レジスタ、共有メモリ、ワープの切り替えの回路などをまとめた単位。SM。GPUは多数のSMを並べて作られる。

この用語の分野: GPUプログラミング

「ストリーミングマルチプロセッサ」が出てくる問題(1問)
