ストリーミングマルチプロセッサとは

すとりーみんぐまるちぷろせっさ

NVIDIAのGPUで、演算器、レジスタ、共有メモリ、ワープの切り替えの回路などをまとめた単位。SM。GPUは多数のSMを並べて作られる。

「ストリーミングマルチプロセッサ」は、1分野の1問の練習問題に出てきます(GPUプログラミングなど)。

この用語の分野: GPUプログラミング

ストリーミングマルチプロセッサの練習問題に挑戦

CUDAで、ブロックとSM(ストリーミングマルチプロセッサ)の関係として正しいものはどれか。

  1. A1つのブロックのスレッドは、すべてのSMに分散して実行される
  2. BSMの数とブロックの数は、必ず同じでなければならない
  3. C各ブロックは1つのSMに割り当てられて最後までそこで実行され、1つのSMには複数のブロックが同時に載ることがある
答えと解説を見る

正解：C. 各ブロックは1つのSMに割り当てられて最後までそこで実行され、1つのSMには複数のブロックが同時に載ることがある

GPUは多数のSMを持ち、カーネルのブロックを空いているSMに順に割り当てます。1つのブロックは1つのSMで実行されるので、ブロックの中のスレッドはそのSMの共有メモリを使い、同期も取れます。ブロックの数をSMの数より十分に多くしておくと、GPUの規模が違っても全部のSMに仕事が行き渡り、終わったSMには次のブロックが割り当てられます。
