過渡現象とは

かとげんしょう

スイッチの開閉や電源の急な変化のあと、コンデンサやコイルを含む回路が、ある定常状態から次の定常状態へ移る間に見られる電圧や電流の変化。コンデンサの電圧とコイルの電流は急に変わらないことを使って初期値を決め、RC回路やRL回路では時定数で指数関数的に、RLC回路では減衰係数に応じて振動しながら、または振動せずに落ち着く。微分方程式やラプラス変換で解く。

「過渡現象」は、1分野の1問の練習問題に出てきます(回路解析(交流回路・線形回路・過渡現象)など)。

この用語の分野: 回路解析(交流回路・線形回路・過渡現象)

一次の回路の過渡現象

RC回路やRL回路では、応答は x(t) = x(∞) + (x(0+) − x(∞))e^(−t/τ) の形になり、時定数はRC回路で τ = RC、RL回路で τ = L/R です。初期値 x(0+)、最終値 x(∞)、時定数の3つがわかれば、微分方程式を解かなくても波形が書けます。t = τ で変化の約63.2%、5τ で約99.3%が終わります。

初期値と最終値の決め方

コンデンサの電圧はエネルギー (1/2)CV² を急に変えられないので連続で、スイッチを入れた直後に充電されていなければ短絡と同じに扱えます。コイルの電流も連続で、直後に電流が0なら開放と同じに扱えます。十分に時間がたった直流の定常状態では、逆にコンデンサは開放、コイルは短絡と同じになります。

二次の回路と解き方

RLC回路の応答は特性方程式 Ls² + Rs + 1/C = 0 の根で決まり、異なる実根なら過減衰、重根なら臨界減衰、複素根なら減衰振動になります。ラプラス変換を使うと、初期値を電源として s領域の回路に組み込み、代数の計算と部分分数分解で時間波形を求められます。最終値だけなら、最終値の定理 lim(s→0) sF(s) ですぐにわかります。

過渡現象の練習問題に挑戦

図のRC回路で、充電されていないコンデンサに t = 0 でスイッチを入れて直流電圧Eを加えた。時定数を τ = RC とするとき、t = 5τ でのコンデンサの電圧 vC は最終値Eの約何%か、最も近いものはどれか。

  1. A約95%
  2. B約99.3%
  3. C100%
答えと解説を見る

正解：B. 約99.3%

解き方1(式に代入): コンデンサの電圧は vC(t) = E(1 − e^(−t/τ)) なので、t = 5τ では 1 − e^(−5) ≈ 1 − 0.0067 = 0.993、つまり約99.3%です。解き方2(時定数ごとの目安): τ ごとに最終値との差が e^(−1) ≈ 0.37倍になるので、到達率は 1τ で63%、2τ で86%、3τ で95%、4τ で98%、5τ で99.3%と進みます。理論上は100%に達しないので、実用上は5τ程度で過渡現象が終わったとみなします。

よくある質問

コイルを含む回路のスイッチを急に切ると、なぜ高い電圧が出るのですか?

コイルの電流は急に0にできないので、スイッチを切った瞬間も同じ電流が流れ続けようとし、電流の行き場がないと v = L di/dt で非常に大きな電圧が生じるからです。リレーのコイルにダイオードを並列に入れるのは、この電流の通り道をつくって電圧を抑えるためです。

過渡現象はどのくらいで終わったとみなせますか?

一次の回路では、時定数の5倍で最終値との差が1%未満(約0.7%)になるので、実用上は5τで終わったとみなすことが多いです。より高い精度が必要なら、許容誤差 ε に対して ln(1/ε) 倍の時定数を待ちます。
