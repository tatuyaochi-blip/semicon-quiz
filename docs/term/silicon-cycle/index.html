シリコンサイクルとは

しりこんさいくる

半導体市場で、需要と供給のバランスによって好況と不況が周期的に繰り返される現象。工場の建設に時間がかかり、供給の調整が需要の変化に遅れることが一因。

この用語の分野: 半導体産業・市場

解説の中の「シリコンサイクル」

  • シリコンサイクルは、需要の拡大に合わせた設備投資が数年後の供給過剰を招き、価格下落と投資の抑制を経て、再び供給不足になる、という好不況の周期的な変動を指します。

    半導体市場で、需要と供給のバランスによって好況と不況が周期的に繰り返される現象を何と呼ぶか。

  • デナードスケーリングとシリコンサイクルは別の概念です。

    微細化による集積度の向上だけでなく、センサーやパワー、アナログ、先端実装などの多様な機能の組み合わせで価値を高める方向…

  • セカンドソースは複数購買、シリコンサイクルは市況の周期です。

    大手のクラウド事業者などが、自社のデータセンター向けにAI処理などに特化した半導体を自ら設計し、ファウンドリで製造する…
