プルアップ抵抗とは

ぷるあっぷていこう

信号の線を抵抗で電源につなぎ、何も駆動していないときに1の電位に保つための抵抗。入力の端子が浮くのを防ぎ、I2Cの線などにも使う。

この用語の分野: 組込み・ファームウェア

解説の中の「プルアップ抵抗」

  • オープンドレイン出力は、トランジスタで線をグラウンドに引き下げるか切り離すかの2状態で、1はプルアップ抵抗が作ります。

    オープンドレイン出力の回路を複数、プルアップ抵抗のある1本の信号線につないだときの動作として正しいものはどれか。

  • プルアップ抵抗で電源につないでおけば、スイッチが開いているときは1、閉じて接地すると0と、確実に読めます。

    マイコンの入力端子にスイッチだけをつなぎ、プルアップやプルダウンの抵抗を付けなかった。スイッチが開いているときに起こり…

  • 線はオープンドレインで、プルアップ抵抗で1に引き上げ、どの機器も0に引き下げられるようにしています。

    I2C通信の特徴として正しいものはどれか。

「プルアップ抵抗」が出てくる問題(3問)

  1. オープンドレイン出力の回路を複数、プルアップ抵抗のある1本の信号線につないだときの動作として正しいものはどれか。
  2. マイコンの入力端子にスイッチだけをつなぎ、プルアップやプルダウンの抵抗を付けなかった。スイッチが開いているときに起こりうることはどれか。
  3. I2C通信の特徴として正しいものはどれか。
