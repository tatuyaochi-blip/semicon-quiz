回帰テストとは

かいきてすと

設計を変更するたびに、これまでのテストをまとめて実行し直し、以前は正しかった機能が壊れていないかを確かめること。リグレッションテスト。

この用語の分野: ハードウェア記述言語と検証

解説の中の「回帰テスト」

  • 回帰テストでは、これまでに作ったテストをすべてまとめて自動で実行し、以前通っていたテストが失敗していないかを確かめます。
