回帰テストとは

かいきてすと

設計を変更するたびに、これまでのテストをまとめて実行し直し、以前は正しかった機能が壊れていないかを確かめること。リグレッションテスト。

「回帰テスト」は、1分野の1問の練習問題に出てきます(ハードウェア記述言語と検証など)。

この用語の分野: ハードウェア記述言語と検証

回帰テストの練習問題に挑戦

回路の設計で行われる回帰テスト(リグレッションテスト)の説明として正しいものはどれか。

  1. A新しく作った機能だけを1回試す
  2. B回路の性能が年々下がっていく傾向を調べる
  3. C設計を変更するたびに、これまでのテストをまとめて実行し直し、以前は正しかった機能が壊れていないかを確かめる
答えと解説を見る

正解：C. 設計を変更するたびに、これまでのテストをまとめて実行し直し、以前は正しかった機能が壊れていないかを確かめる

ある不具合を直したり機能を加えたりすると、思わぬところで別の部分が壊れることがあります。回帰テストでは、これまでに作ったテストをすべてまとめて自動で実行し、以前通っていたテストが失敗していないかを確かめます。大規模な設計では何千ものテストを毎日のように実行し、結果を一覧で管理します。自己チェック型のテストベンチがあって初めて、こうした自動化ができます。
