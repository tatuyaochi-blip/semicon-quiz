侵入検知システム(IDS)とは

しんにゅうけんちしすてむ

Intrusion Detection Systemの略で、ネットワークの通信や端末の動きを監視し、攻撃の疑いを見つけて管理者に警告する仕組み。既知の攻撃の特徴と照らし合わせるシグネチャ型と、ふだんの状態からのずれを見つけるアノマリ型がある。通信の経路の途中(インライン)に置かれ、攻撃と判断した通信をその場で遮断できるものは、IPS(Intrusion Prevention System、侵入防止システム)と呼ばれる。IPSは誤検知で正常な通信まで止めるおそれがあるので、遮断の規則を慎重に調整する。

「侵入検知システム(IDS)」は、1分野の3問の練習問題に出てきます(サイバー攻撃と防御の実務など)。

この用語の分野: サイバー攻撃と防御の実務

侵入検知システム(IDS)の練習問題に挑戦

IDS(侵入検知システム)とIPS(侵入防止システム)の違いの説明として、正しいものはどれか。

  1. AIDSは不正な通信を見つけると自動でその通信を遮断し、IPSは通信を記録して後で調べるだけで、遮断はしない
  2. BIDSは不正の疑いを検知して管理者に知らせ、IPSは通信の経路の途中に置かれて、不正と判断した通信を遮断する
  3. CIDSもIPSも、ソフトウェアの脆弱性を修正するプログラムを、社内の各端末に自動で配って適用する仕組みである
答えと解説を見る

正解：B. IDSは不正の疑いを検知して管理者に知らせ、IPSは通信の経路の途中に置かれて、不正と判断した通信を遮断する

IDSは、ネットワークを流れる通信(または端末の動き)を監視し、攻撃の疑いを見つけると警告を出します。通信の写しを受け取って調べる形で置かれることが多く、正常な通信を誤って攻撃と判断しても業務は止まりませんが、遮断は人や別の仕組みに任せます。IPSは、通信の経路の途中(インライン)に置かれ、攻撃と判断した通信をその場で遮断できます。その代わり、誤検知があると正常な業務の通信まで止めてしまい、装置の故障や処理の遅れが通信全体に影響するので、どの規則で遮断するかを慎重に調整します。

IDSの検知の方式のうち、シグネチャ型(不正検出型)とアノマリ型(異常検出型)を比べた説明として、正しいものはどれか。

  1. Aシグネチャ型は既知の攻撃の特徴との一致で検知するので未知の攻撃を見逃しやすく、アノマリ型はふだんからのずれで検知するので未知の攻撃にも気づけるが誤検知が多い
  2. Bシグネチャ型は登録されていない未知の攻撃も確実に検知でき、アノマリ型は登録された既知の攻撃しか検知できない
  3. Cアノマリ型はふだんの状態を学ぶ必要がないので、導入した直後から誤検知なく使え、シグネチャの更新も要らない
答えと解説を見る

正解：A. シグネチャ型は既知の攻撃の特徴との一致で検知するので未知の攻撃を見逃しやすく、アノマリ型はふだんからのずれで検知するので未知の攻撃にも気づけるが誤検知が多い

シグネチャ型は、既知の攻撃の通信の特徴(シグネチャ)をあらかじめ登録し、一致するものを検知します。登録された攻撃は正確に見つけられますが、新しい攻撃や、特徴を少し変えた攻撃は見逃しやすく、シグネチャを常に更新する必要があります。アノマリ型は、通信の量や時間帯、接続先などのふだんの状態(ベースライン)を学び、そこから大きくずれたものを検知するので、未知の攻撃に気づける可能性があります。一方、正常でも珍しい通信を異常と判断しやすく、誤検知が増えるので、実際には両方を組み合わせて使います。

解説の中の「侵入検知システム(IDS)」

  • IDSは、ネットワークを流れる通信(または端末の動き)を監視し、攻撃の疑いを見つけると警告を出します。

    IDS(侵入検知システム)とIPS(侵入防止システム)の違いの説明として、正しいものはどれか。

「侵入検知システム(IDS)」が出てくる問題(3問)

  1. IDS(侵入検知システム)とIPS(侵入防止システム)の違いの説明として、正しいものはどれか。
  2. IDSの検知の方式のうち、シグネチャ型(不正検出型)とアノマリ型(異常検出型)を比べた説明として、正しいものはどれか。
  3. あるIDSは、1日に100万件の接続を調べる。そのうち実際の攻撃は100件である。このIDSは攻撃の99%を検知し、攻撃でない接続の0.1%を誤って攻撃と判定する。IDSが出した警告のうち、実際に攻撃であるものの割合に最も近いものはどれか。
