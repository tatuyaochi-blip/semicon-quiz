終点検出とは

しゅうてんけんしゅつ

エッチングなどで、目的の膜を削り終えた時点を検出すること。プラズマの発光スペクトルの変化を監視する方法がよく使われる。

「終点検出」は、1分野の2問の練習問題に出てきます(エッチングなど)。

この用語の分野: エッチング

終点検出が必要な理由

ドライエッチングでは、膜の厚さやエッチング速度がウエハの面内やウエハごとにばらつくため、決めた時間だけ削る方法では、削り残しや下地の削りすぎが起こります。終点検出は、目的の膜がなくなって下地が出てきた時点をエッチング中にリアルタイムで捉え、主エッチングを止めたり、条件を切り替えたりするための技術です。検出した時点では、一部の領域にまだ膜が残っていることが多いため、その後に一定時間のオーバーエッチングを加え、下地との選択比が高い条件で残りを取り除くのが一般的です。

発光分光法(OES)による検出

最もよく使われるのは、プラズマの発光を分光器で監視する発光分光法(OES)です。膜を削っている間はエッチング反応の生成物が発光し、下地が出てくると生成物の種類や量が変わるため、特定の波長の発光強度が増えたり減ったりします。例えば酸化膜のエッチングでは、COの483 nm付近の発光が下地の露出とともに減ります。装置の窓越しにプラズマの光を見るだけでよく、ウエハに触れずに測れます。複数の波長を組み合わせたり、強度の比をとったりして、雑音や装置の状態による変動の影響を抑えます。

干渉計などほかの方法

コンタクトホールのように、エッチングする面積がウエハ全体のごく一部しかない場合は、生成物の変化がわずかで、OESの信号が弱くなります。このようなときは、ウエハに光を当てて反射光の干渉を監視するレーザー干渉計や、広い波長の光を使う分光反射の方法で、残りの膜厚を直接追いかけます。膜厚の変化が干渉の強弱の周期として現れるため、途中の深さで止めるような制御にも使えます。プラズマの電気的なインピーダンスの変化を監視する方法もあります。CMPでも、モーターのトルクや光の反射率、金属膜では渦電流センサを使って研磨の終点を検出します。

時間による管理との違い

エッチングの量を管理する方法には、時間で決める方法と終点検出を使う方法があります。時間で決める場合は、膜厚÷エッチング速度で時間を求めます。例えば500 nmの膜を100 nm/minで削るなら5分で、20%のオーバーエッチングを含めると約6分です。ただし、装置の状態の変化や膜厚のばらつきが、そのまま削り残しや削りすぎになります。終点検出を使えば、そのばらつきをウエハごとに吸収できます。終点はあくまで「下地が見え始めた時点」であり、その後のオーバーエッチングの量と条件で、残渣の除去と下地の保護を両立させます。

終点検出の練習問題に挑戦

ドライエッチングの終点検出によく使われる方法はどれか。

  1. Aウエハの重さを量る
  2. Bプラズマの発光スペクトルの変化を監視する
  3. Cエッチング後に目視で確認する
答えと解説を見る

正解：B. プラズマの発光スペクトルの変化を監視する

エッチングしている膜がなくなって下地が出てくると、プラズマ中の反応生成物の種類や量が変わり、特定の波長の発光強度が変化します。例えば酸化膜のエッチングではCO(483 nm)の発光が減ります。この変化を発光分光法(OES)で監視することで、エッチングの終点をリアルタイムで検出できます。露出する面積が非常に小さい場合は信号が弱くなるため、干渉計による膜厚の測定なども使われます。

よくある質問

エッチングの終点はどうやって検出するのですか?

主にプラズマの発光を分光器で監視します(発光分光法、OES)。下地が出てくるとエッチングの生成物が変わり、特定の波長の発光強度が変化するため、その変化点を終点とします。露出する面積が小さく信号が弱い場合は、レーザー干渉計などで膜厚を直接測る方法も使われます。

終点を検出したら、すぐにエッチングを止めるのですか?

一般には止めずに、オーバーエッチングを続けます。終点は一部の領域で膜がなくなったことを示すだけで、膜厚やエッチング速度のばらつき、段差の側壁などのために膜が残っていることがあるためです。オーバーエッチングは、下地との選択比が高い条件に切り替えて行います。

終点検出が難しくなるのはどんなときですか?

コンタクトホールやビアのように、エッチングする面積がウエハのごく一部しかないときです。生成物の変化が小さく、発光の変化が雑音に埋もれやすくなります。複数の波長の比や統計的な処理で感度を上げたり、干渉計など別の方法と組み合わせたりします。
