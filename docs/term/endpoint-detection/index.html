終点検出とは

しゅうてんけんしゅつ

エッチングなどで、目的の膜を削り終えた時点を検出すること。プラズマの発光スペクトルの変化を監視する方法がよく使われる。

この用語の分野: エッチング

解説の中の「終点検出」

  • 装置ではこの時間と終点検出を組み合わせて管理します。

    エッチング速度が100 nm/minの条件で3分間エッチングしたとき、削れる膜の厚さはいくらか。

「終点検出」が出てくる問題(2問)

  1. ドライエッチングの終点検出によく使われる方法はどれか。
  2. エッチング速度が100 nm/minの条件で3分間エッチングしたとき、削れる膜の厚さはいくらか。
