チャネリングとは

ちゃねりんぐ

イオンが結晶の原子の並びのすき間を通り抜けて、予想より深くまで入り込む現象。ウエハを傾けて注入するなどして防ぐ。

「チャネリング」は、1分野の4問の練習問題に出てきます(イオン注入など)。

この用語の分野: イオン注入

チャネリングの練習問題に挑戦

イオン注入でチャネリング(イオンが結晶のすき間を通って深く入りすぎる現象)を抑える方法として一般的なものはどれか。

  1. A加速エネルギーを最大にする
  2. B注入後にウエハを洗浄する
  3. Cウエハを結晶軸から数度傾けて注入する
答えと解説を見る

正解：C. ウエハを結晶軸から数度傾けて注入する

結晶の原子の並びに沿ってイオンが入ると、原子の列の間のすき間(チャネル)を通って衝突しにくく、予定より深く入ってしまいます(チャネリング)。ウエハを結晶軸から約7°傾け、さらに回転方向もずらして注入したり、表面に薄い酸化膜(スクリーン酸化膜)を通して向きをばらつかせたり、先に表面をアモルファス化したりすることで抑えます。分布の深い側の裾が減り、浅い接合になります。

解説の中の「チャネリング」

  • 結晶の原子の並びに沿ってイオンが入ると、原子の列の間のすき間(チャネル)を通って衝突しにくく、予定より深く入ってしまいます(チャネリング)。

    イオン注入でチャネリング(イオンが結晶のすき間を通って深く入りすぎる現象)を抑える方法として一般的なものはどれか。

  • 実際には分布が左右非対称になったり、チャネリングで裾が深い側に伸びたりするため、より精密な分布関数やシミュレーションが使われます。

    イオン注入後の不純物の深さ方向の分布を近似的に表す分布と、そのピークの深さを表す量の組み合わせとして正しいものはどれか。

  • ゲルマニウムやシリコンなどの重いイオンを先に注入して表面を数十nmの深さまでアモルファスにしておくと、原子の並びがなくなるため、その後に注入するホウ素などのチャネリングが抑えられ、浅い接合をつくれます。

    プリアモルファス化注入(PAI)の目的として正しいものはどれか。

  • チャネリング対策やハロー注入でウエハを傾けて注入すると、背の高いレジストやゲートの陰になる部分にはイオンが届かなくなります(シャドウイング)。

    ウエハを傾けてイオン注入を行う際に、レジストなどの高いパターンの陰になって注入されない部分ができる現象を何と呼ぶか。

「チャネリング」が出てくる問題(4問)

  1. イオン注入でチャネリング(イオンが結晶のすき間を通って深く入りすぎる現象)を抑える方法として一般的なものはどれか。
  2. イオン注入後の不純物の深さ方向の分布を近似的に表す分布と、そのピークの深さを表す量の組み合わせとして正しいものはどれか。
  3. プリアモルファス化注入(PAI)の目的として正しいものはどれか。
  4. ウエハを傾けてイオン注入を行う際に、レジストなどの高いパターンの陰になって注入されない部分ができる現象を何と呼ぶか。
