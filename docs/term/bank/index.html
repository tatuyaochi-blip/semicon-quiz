バンクとは

ばんく

DRAMの内部を独立して動作できるいくつかの区画に分けたもの。異なるバンクの活性化や読み書きを重ねて行うことで、実効的なアクセス性能を高める。

「バンク」は、3分野の9問の練習問題に出てきます(DRAM, ハードウェアセキュリティの最新動向, GPUプログラミングなど)。

この用語の分野: DRAM

DRAMをバンクに分ける理由

DRAMへのアクセスには、時間のかかる手順がいくつかあります。アクティベートコマンドで行を開いてバンクのセンスアンプ(ロウバッファとも呼びます)にコピーし、読み書きではその行から列を選び、最後にプリチャージで行を閉じてビット線を準備します。アクティベートとプリチャージにはそれぞれ10 ns以上かかります。バンクは独自のロウバッファを持つ独立したアレイなので、あるバンクがアクティベートやプリチャージをしている間に、別のバンクがデータを転送できます。アクセスを複数のバンクにインターリーブすることで、こうしたレイテンシを隠し、データバスを常に働かせられます。

バンク数とバンクグループ

DDR4のデバイス(x4・x8品)は16バンクを4つのバンクグループに分けて持ち、DDR5(16 Gbit以上のx4・x8品)ではこれが倍の32バンクになります。x16品のバンク数はそれぞれその半分です。バンクグループにはタイミング上のルールがあり、異なるグループへの連続したカラムアクセスは、同じグループ内へのアクセスより短い間隔で発行できます。そのためコントローラはトラフィックをグループ間に分散させます。各バンクは別々の行を開いておけるので、要求がすでに開いている行に当たる(ページヒット)確率も上がり、アクティベートをやり直す必要が減ります。バンクはランクとは別物で、ランクはモジュール上でチップセレクトを共有するチップの集まりです。

リフレッシュとバンクの可用性

DRAMセルは電荷がリークするため、各行を通常64 ms以内にリフレッシュする必要があります。リフレッシュ中のバンクはアクセスに応じられず、容量が増えるにつれて1回のリフレッシュコマンドで扱う行が増え、tRFCと呼ばれるその時間も長くなります。16 Gbitクラスのデバイスでは、リフレッシュによる性能低下は数%から約10%に達し、消費電力も増えます。バンクごとのリフレッシュは、1つのバンクをリフレッシュする間も他のバンクを使えるようにして影響を減らします。また、データ保持時間の長い行のリフレッシュ頻度を下げる研究も行われています。

GPUの共有メモリのバンク

この言葉は、関連する意味でGPUプログラミングにも登場します。CUDAの共有メモリは32個のバンクに分かれ、4バイトごとに順番に割り当てられており、各バンクは1回のアクセスで1つのアドレスにしか応じられません。ワープの32スレッドがすべて異なるバンクにアクセスすれば一度に完了しますが、複数のスレッドが同じバンクの異なるアドレスにアクセスすると、アクセスが直列化されます。これがバンクコンフリクトです。32 × 32のfloatのタイルを列方向に読むと全要素が同じバンクに入りますが、タイルを32 × 33にパディングすると各行が1バンクずつずれ、コンフリクトがなくなります。

バンクの練習問題に挑戦

DRAMの内部を複数のバンクに分ける主な目的はどれか。

  1. A容量を減らすため
  2. B異なるバンクの動作を重ねて行い、実効的なアクセス性能を高めるため
  3. C発熱を増やすため
答えと解説を見る

正解：B. 異なるバンクの動作を重ねて行い、実効的なアクセス性能を高めるため

行の活性化やプリチャージには十数nsかかります。内部を複数のバンクに分けると、あるバンクがこれらの動作をしている間に別のバンクへアクセスでき、待ち時間を隠して転送効率を高められます。DDR4は16バンク(4つのバンクグループ)、DDR5は32バンク(8つのバンクグループ)です(DDR4はx4・x8品、DDR5は16 Gbit以上のx4・x8品の場合で、x16品はいずれもその半分)。複数のバンクで別々の行を開いておけるため、ページヒットの機会も増えます。

同じバンクで行を活性化できる最短の間隔を、簡単のためtRC = 50 nsとする。リフレッシュの周期が64 msのとき、ある行がリフレッシュされてから次にリフレッシュされるまでに、隣の1つの行を活性化できる回数は最大で 64 ms ÷ 50 ns となる。リフレッシュの頻度を2倍にしたときの、この最大の回数はどれか。

  1. A約64万回
  2. B約128万回
  3. C約256万回
答えと解説を見る

正解：A. 約64万回

リフレッシュの頻度を2倍にすると、周期は 64 ms ÷ 2 = 32 ms になります。その間に活性化できる回数は最大で 32 ms ÷ 50 ns = 640,000回(約64万回)で、もとの 64 ms ÷ 50 ns = 1,280,000回(約128万回)の半分です。研究では数千回程度の活性化で反転するDRAMも報告されているので、回数を半分にしても攻撃に十分な回数が残り、リフレッシュを増やすだけでは防げません。そのうえ、リフレッシュの間はバンクを使えず、電力も増えるので、性能と消費電力の負担が大きくなります。

よくある質問

DDR5のバンク数はいくつですか?

16 Gbit以上のx4・x8のDDR5デバイスは32バンクで、8つのバンクグループに分けて構成されています。DDR4のx4・x8品は16バンクを4つのバンクグループに分けていました。どちらもx16品のバンク数はその半分です。

DRAMのバンクとランクの違いは何ですか?

バンクは1つのDRAMチップ内で独立に動作するアレイです。ランクはモジュール上でチップセレクトを共有し、合わせて全データ幅を供給するチップの集まりで、その中の各チップがそれぞれバンクを持っています。

共有メモリのバンクコンフリクトとは何ですか?

GPUのワープ内のスレッドが、同じ共有メモリバンクに対応する異なるアドレスにアクセスし、ハードウェアがアクセスを直列化しなければならなくなる現象です。配列のパディングやアクセスパターンの変更で通常は回避でき、全スレッドが同じアドレスを読む場合はブロードキャストとなってコンフリクトにはなりません。
