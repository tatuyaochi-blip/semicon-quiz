ローダとは

ろーだ

実行ファイルをメモリに読み込み、各部分を権限付きで配置し、スタックに引数などを用意してプログラムを開始させるOSの機能。

「ローダ」は、1分野の5問の練習問題に出てきます(リンカ・ローダと実行形式など)。

この用語の分野: リンカ・ローダと実行形式

ローダの練習問題に挑戦

プログラムを起動するとき(Linuxのexecveなど)に、OSのローダが行うこととして正しいものはどれか。

  1. Aソースコードを読み込んで、その場でコンパイルしてから実行する
  2. B実行ファイルのプログラムヘッダにしたがって各部分をメモリに配置し、スタックに引数などを用意して、入口の番地から実行を始める
  3. C実行ファイルのすべてのシンボル名を画面に表示してから実行する
答えと解説を見る

正解：B. 実行ファイルのプログラムヘッダにしたがって各部分をメモリに配置し、スタックに引数などを用意して、入口の番地から実行を始める

ローダは実行ファイルのヘッダを読み、プログラムヘッダに書かれた各部分(セグメント)を、読み取り・書き込み・実行の権限を付けて仮想アドレス空間に対応づけます。BSSのための0の領域やスタックを用意し、コマンドライン引数や環境変数をスタックに積みます。動的リンクなら動的リンカを、そうでなければ実行ファイルの入口の番地から実行を始めます。

解説の中の「ローダ」

  • ローダは実行ファイルのヘッダを読み、プログラムヘッダに書かれた各部分(セグメント)を、読み取り・書き込み・実行の権限を付けて仮想アドレス空間に対応づけます。

    プログラムを起動するとき(Linuxのexecveなど)に、OSのローダが行うこととして正しいものはどれか。

  • 先頭のELFヘッダに、対象のCPUや64ビットかどうか、実行を始める番地などが書かれ、その後に.textや.dataなどのセクションと、ローダがメモリに読み込む単位を表すプログラムヘッダが続きます。

    Linuxなどでよく使われるELF形式のファイルについて正しいものはどれか。

  • 中身がすべて0なら、ファイルに0を並べて保存するのはむだなので、.bssセクションには大きさだけを記録し、ローダがメモリを確保して0で埋めます。

    .bssセクションの特徴として正しいものはどれか。

  • パソコンのOSではローダが番地を決めますが、マイコンでは電源を入れた時点の番地がそのまま使われます。

    組込み向けの開発で使うリンカスクリプトの役割として正しいものはどれか。

  • ローダはプログラムヘッダに書かれたセグメントを単位にメモリへ対応づけ、例えば読み取りと実行のセグメントに.textと.rodataを、読み書きのセグメントに.dataと.bssをまとめます。

    ELFのファイルにおける「セクション」と「セグメント」の違いとして正しいものはどれか。

「ローダ」が出てくる問題(5問)

  1. プログラムを起動するとき(Linuxのexecveなど)に、OSのローダが行うこととして正しいものはどれか。
  2. Linuxなどでよく使われるELF形式のファイルについて正しいものはどれか。
  3. .bssセクションの特徴として正しいものはどれか。
  4. 組込み向けの開発で使うリンカスクリプトの役割として正しいものはどれか。
  5. ELFのファイルにおける「セクション」と「セグメント」の違いとして正しいものはどれか。
