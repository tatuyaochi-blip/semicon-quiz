オブジェクトストレージとは

おぶじぇくとすとれーじ

データを、キー(名前)とメタデータの付いたオブジェクトとして保存し、HTTPのAPIで丸ごと読み書きするストレージ。容量を前もって決めずにほぼ際限なく増やせ、データは一般に複数の装置や場所に複製されて高い耐久性をもつ。画像や動画、バックアップ、ログ、静的なWebサイトのファイルの保存に向く。ファイルシステムのように一部だけを書き換える使い方や、データベースのデータファイルを置く用途には向かず、それらには仮想的なディスクを提供するブロックストレージや、共有のファイルシステムを提供するファイルストレージを使う。

「オブジェクトストレージ」は、2分野の2問の練習問題に出てきます(サイバー攻撃と防御の実務, クラウドとコンテナの基礎など)。

この用語の分野: クラウドとコンテナの基礎

オブジェクトストレージの練習問題に挑戦

クラウドのオブジェクトストレージに置いた顧客の情報のファイルが、インターネットの誰からでも読み出せる状態になっていたことが分かった。このような情報の漏えいの典型的な原因と、再発を防ぐ対策の組み合わせとして、適切なものはどれか。

  1. A利用者の設定の誤りで公開になっていた。アカウント全体で公開を禁止する設定にし、設定の誤りを自動で検査する
  2. Bクラウドの事業者の暗号の方式が弱く、ファイルが解読された。ファイルを圧縮してから保存するようにする
  3. Cクラウドの事業者のデータセンターの、物理的な警備が不十分だった。自社の社員をデータセンターに常駐させて見張る
答えと解説を見る

正解：A. 利用者の設定の誤りで公開になっていた。アカウント全体で公開を禁止する設定にし、設定の誤りを自動で検査する

クラウドの責任共有モデルでは、ストレージのアクセスの設定は利用者の責任で、公開の設定の誤りによる情報の漏えいは繰り返し起きています。テストのために一時的に公開した設定を戻し忘れる、許可の対象の意味を誤解して広く許可してしまう、といった誤りが典型的です。対策として、アカウントや組織の全体で公開を禁止する設定を既定にし、設定の状態を自動で検査する仕組み(CSPM: クラウドセキュリティ態勢管理)で、公開の設定や暗号化の設定漏れなどを継続的に見つけて直します。

「オブジェクトストレージ」が出てくる問題(2問)

  1. クラウドのオブジェクトストレージに置いた顧客の情報のファイルが、インターネットの誰からでも読み出せる状態になっていたことが分かった。このような情報の漏えいの典型的な原因と、再発を防ぐ対策の組み合わせとして、適切なものはどれか。
  2. クラウドのストレージを、①仮想マシンにディスクとして接続してファイルシステムを作り、データベースのデータファイルを置く、②複数のサーバから同時にマウントして共有のディレクトリとして使う、③HTTPのAPIでキー(名前)を指定して大量の画像を読み書きし、容量を前もって決めずに増やす、という3つの用途で使う。①〜③に適したストレージの種類の組み合わせとして、適切なものはどれか。
