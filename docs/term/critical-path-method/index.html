クリティカルパス法(CPM)とは

くりてぃかるぱすほう

プロジェクトの作業の所要日数と順番の関係から、各作業の最早・最遅の開始日と余裕日数(フロート)を求め、余裕が0の作業をつないだ最も長い経路(クリティカルパス)と全体の所要日数を求める日程管理の手法。クリティカルパス上の作業が遅れると、全体が遅れる。

「クリティカルパス法(CPM)」は、1分野の1問の練習問題に出てきます(ソフトウェア開発とプロジェクト管理など)。

この用語の分野: ソフトウェア開発とプロジェクト管理

最早開始日と最遅開始日

前から順に、先行作業がすべて終わる日のうち最も遅い日を最早開始日として求めると、最後の作業の最早終了日が全体の所要日数になります。次に後ろから順に、全体を延ばさないために遅くとも始めるべき日を最遅開始日として求めます。最遅開始日 − 最早開始日 がその作業の余裕日数(トータルフロート)で、これが0の作業をつないだ経路がクリティカルパスです。例えば A(6日)→ D(4日)→ F(3日)が13日で最も長ければ、A、D、F のどれかが1日遅れると全体も1日遅れます。

アローダイアグラムとダミー作業

日本の情報処理技術者試験では、作業を矢印、作業の区切りを結合点(丸)で表すアローダイアグラム(PERT図)がよく使われます。矢印だけでは表せない順番の関係は、所要日数0のダミー作業(点線の矢印)で表します。例えば、作業 D を始めるには B だけでなく A も終わっている必要があるとき、A の終点から D の始点へダミー作業を引きます。ダミー作業を見落とすと、実際より短い所要日数を求めてしまうので注意が必要です。

日程を短縮する方法

全体を短くするには、クリティカルパス上の作業を短くする必要があり、クリティカルパス上にない作業をいくら短くしても全体は変わりません。人や費用を追加して作業を縮めることをクラッシング、順番に行う予定の作業を一部重ねて並行に進めることをファストトラッキングといいます。クラッシングでは、1日短縮するための費用が最も少ないクリティカルパス上の作業から縮めます。短縮すると別の経路が新しいクリティカルパスになることがあるので、そのつど計算し直します。

クリティカルパス法(CPM)の練習問題に挑戦

作業と所要日数、先行作業が、A: 4日(先行作業なし)、B: 2日(なし)、C: 3日(A)、D: 2日(B)、E: 5日(C)、F: 4日(C と D)、G: 2日(F)のプロジェクトがある。ほかの作業はできるだけ早く始めるとき、作業Bの開始を遅らせても全体の所要日数が延びない最大の日数はどれか。

  1. A0日
  2. B1日
  3. C3日
答えと解説を見る

正解：C. 3日

最早開始日は C が4日、E と F が7日(F は C の終わる7日と D の終わる4日の遅い方)、G が11日で、全体は A→C→F→G の 4 + 3 + 4 + 2 = 13日です。後ろから最遅開始日を求めると、G が11日、F が7日、D が 7 − 2 = 5日、B が 5 − 2 = 3日なので、B のトータルフロート(余裕日数)は 3 − 0 = 3日です。B を遅らせると D の開始も遅れますが、D にも同じ余裕があるので、3日までなら全体は延びません。0日は B のフリーフロート(後続の D の最早開始を遅らせない余裕)、1日は E の余裕日数です。クリティカルパス法(CPM)では、このように余裕日数を求め、余裕が0の作業をつないだ経路をクリティカルパスとします。

よくある質問

クリティカルパスは1本だけですか?

複数あることもあります。所要日数が同じ最長の経路が2本あれば、どちらもクリティカルパスで、全体を短くするには両方の経路を短くする必要があります。

トータルフロートとフリーフロートの違いは何ですか?

トータルフロートは、全体の所要日数を延ばさずにその作業を遅らせられる日数です。フリーフロートは、後続の作業の最早開始日を遅らせずに遅らせられる日数で、トータルフロート以下になります。後続の作業と余裕を共有している場合、フリーフロートは0でもトータルフロートは正になることがあります。
