クリティカルパスとは

くりてぃかるぱす

回路の中で遅延が最も大きく、動作できる最大のクロック周波数を決める経路。STAではスラックが最小の経路にあたり、高速化はこの経路の遅延を減らすことから始める。

「クリティカルパス」は、2分野の2問の練習問題に出てきます(論理回路, タイミング解析とCDCなど)。

この用語の分野: タイミング解析とCDC

クリティカルパスの練習問題に挑戦

同期式回路で、動作できる最大のクロック周波数を決めるものはどれか。

  1. A最も遅延の小さい経路の遅延
  2. B電源電圧だけ
  3. Cフリップフロップ間で最も遅延の大きい経路(クリティカルパス)の遅延
答えと解説を見る

正解：C. フリップフロップ間で最も遅延の大きい経路(クリティカルパス)の遅延

クロック周期は「クロック→出力の遅延+経路の論理遅延+セットアップ時間+スキュー等の余裕」以上でなければならず、最も遅延の大きい経路(クリティカルパス)が最大周波数を決めます。例えば合計1 nsなら最大1 GHzです。高速化には、パイプラインで経路を分割する、論理段数を減らす、遅い経路に駆動力の高いセルや低Vthの素子を使う、といった方法があります。

フリップフロップ間の経路で、クロック→出力遅延が 0.15 ns、組み合わせ回路の最大遅延が 2.2 ns、セットアップ時間が 0.15 ns である。スキューとクロックの不確かさを無視すると、この経路で動作できる最大のクロック周波数はいくらか。

  1. A約 425 MHz
  2. B約 455 MHz
  3. C400 MHz
答えと解説を見る

正解：C. 400 MHz

最小のクロック周期は、クロック→出力遅延、組み合わせ回路の遅延、セットアップ時間の合計です。0.15 + 2.2 + 0.15 = 2.5 ns なので、最大周波数は 1 ÷ 2.5 ns = 400 MHz になります。約 425 MHz はセットアップ時間を入れ忘れた 2.35 ns から、約 455 MHz は組み合わせ回路の遅延 2.2 ns だけから計算した値です。チップ全体の最大周波数は、このような経路のうち最も厳しいクリティカルパスで決まります。
