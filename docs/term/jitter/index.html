ジッタとは

じった

クロックや信号のエッジのタイミングの、理想からの細かな時間的なゆらぎ。高い周波数の信号をサンプリングするとき、わずかなジッタでも大きな電圧誤差になる。

「ジッタ」は、4分野の6問の練習問題に出てきます(AD/DA変換, LSI設計フロー・EDA, 論理回路など)。

この用語の分野: AD/DA変換

ジッタの練習問題に挑戦

高い周波数の信号をAD変換するとき、サンプリングクロックの時間的なゆらぎ(ジッタ)が問題になる理由として正しいものはどれか。

  1. Aクロックが止まってしまうため
  2. B直流の信号でだけ誤差が出るため
  3. C信号の変化が速いほど、サンプリング時刻のわずかなずれが大きな電圧誤差になるため
答えと解説を見る

正解：C. 信号の変化が速いほど、サンプリング時刻のわずかなずれが大きな電圧誤差になるため

サンプリング時刻がΔtずれると、その間の信号の変化分が誤差になります。正弦波の傾きは周波数に比例するため、ジッタで決まるSNRの上限は SNR = −20 log₁₀(2πf·tj) です。例えば100 MHzの信号で70 dBを得るには、ジッタを約0.5 ps以下にする必要があります。そのため高速・高分解能のADCや無線の受信機では、位相雑音の小さいクロック源の設計が性能を左右します。

タイミングの制約(SDC)で、クロックのジッタやスキューの見込みなどとしてクロックの周期から差し引いておく余裕を指定するものはどれか。

  1. Aクロックの不確かさ(clock uncertainty)
  2. Bドーズ量
  3. Cアスペクト比
答えと解説を見る

正解：A. クロックの不確かさ(clock uncertainty)

クロックの不確かさは、クロックのジッタや、配置配線前に見込むスキューなどの影響を、タイミング解析で余裕として差し引くための設定です。例えば周期1 nsで不確かさを50 psとすると、データは0.95 nsで届く必要があります。設計の段階に応じて値を調整し、配置配線後は実際のクロックツリーから計算したスキューに置き換え、ジッタ分だけを残します。ドーズ量とアスペクト比は製造の用語です。

「ジッタ」が出てくる問題(6問)

  1. 高い周波数の信号をAD変換するとき、サンプリングクロックの時間的なゆらぎ(ジッタ)が問題になる理由として正しいものはどれか。
  2. タイミングの制約(SDC)で、クロックのジッタやスキューの見込みなどとしてクロックの周期から差し引いておく余裕を指定するものはどれか。
  3. 同期式回路の「クロックスキュー」の説明として正しいものはどれか。
  4. 実際のADコンバータの雑音やひずみを含めた性能を、理想的なADCのビット数に換算した指標はどれか。
  5. 中心周波数70 MHz、帯域幅10 MHzの信号を、それより低いサンプリング周波数で意図的にサンプリングして周波数変換も兼ねる手法はどれか。
  6. 高速なシリアル信号の品質を見るアイパターン(アイダイアグラム)について正しいものはどれか。
