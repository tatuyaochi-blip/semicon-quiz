二元対称通信路とは

にげんたいしょうつうしんろ

0か1を送り、各ビットが、送った値によらず同じ確率pで反転し、互いに独立に誤る通信路のモデル。BSCともいう。通信路容量は C = 1 − H(p) ビット/回(H(p) = −p log₂ p − (1 − p) log₂(1 − p))で、p = 0.1 なら約0.53ビット、p = 0.5 なら0になる。p = 1 では必ず反転するので、受け取った値を反転すれば誤りなく伝わり、容量は1に戻る。ビット誤りを扱う誤り訂正符号の性能を考えるときの、基本のモデルである。

「二元対称通信路」は、1分野の1問の練習問題に出てきます(情報理論と符号の基礎など)。

二元対称通信路の練習問題に挑戦

0と1を送り、各ビットが互いに独立に確率0.1で反転する二元対称通信路がある。2値のエントロピー関数を H(p) = −p log₂ p − (1 − p) log₂(1 − p) とすると、H(0.1) ≈ 0.469 である。この通信路の、1回の伝送あたりの通信路容量に最も近いものはどれか。

  1. A約0.47ビット
  2. B約0.53ビット
  3. C0.9ビット
答えと解説を見る

正解：B. 約0.53ビット

二元対称通信路の通信路容量は C = 1 − H(p) で、0と1を等しい確率で送るときの相互情報量の値です。p = 0.1 では C ≈ 1 − 0.469 = 0.531 で、1回の伝送あたり約0.53ビットです。適切な誤り訂正符号を使えば、この割合までのデータを、誤り率をいくらでも小さくして送れます。p = 0.5 では受け取った値が送った値と無関係になり、容量は0になります。
