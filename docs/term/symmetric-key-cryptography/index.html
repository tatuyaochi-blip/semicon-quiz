共通鍵暗号とは

きょうつうかぎあんごう

暗号化と復号に同じ鍵を使う暗号方式。対称鍵暗号や秘密鍵暗号とも呼ぶ。計算が軽く大量のデータを速く暗号化できるが、通信の相手と鍵を安全に共有する方法(鍵配送)が課題になる。AESが代表的。

「共通鍵暗号」は、2分野の5問の練習問題に出てきます(情報セキュリティの基礎, 量子コンピュータのハードウェアなど)。

共通鍵暗号の練習問題に挑戦

共通鍵暗号の特徴として正しいものはどれか。

  1. A暗号化と復号に別々の鍵を使い、暗号化の鍵は公開してよい
  2. B暗号化と復号に同じ鍵を使い、処理が速いが、通信の相手と安全に鍵を共有する方法が問題になる
  3. C鍵を使わずに、決まった手順だけでデータを変換するので、手順を知られなければ安全である
答えと解説を見る

正解：B. 暗号化と復号に同じ鍵を使い、処理が速いが、通信の相手と安全に鍵を共有する方法が問題になる

共通鍵暗号は、暗号化と復号に同じ鍵を使う方式で、AESが代表的です。計算が軽く、大量のデータを速く暗号化できるので、通信やディスクの暗号化の本体に使われています。一方で、送り手と受け手が同じ鍵を、第三者に知られないように前もって共有しておく必要があり、この鍵配送の問題が弱点です。暗号化と復号に別々の鍵を使い、暗号化の鍵を公開できるのは公開鍵暗号です。また、現代の暗号は、手順(アルゴリズム)が公開されていても、鍵が秘密である限り安全であるように設計されます(ケルクホフスの原理)。

50人のメンバーが、2人ずつの組のすべてで、ほかのメンバーに内容を知られずに暗号の通信をしたい。共通鍵暗号を使う場合に必要な鍵の数と、公開鍵暗号を使う場合に必要な鍵の数(公開鍵と秘密鍵の合計)の組み合わせとして正しいものはどれか。

  1. A共通鍵暗号は1225個、公開鍵暗号は100個
  2. B共通鍵暗号は2450個、公開鍵暗号は100個
  3. C共通鍵暗号は100個、公開鍵暗号は1225個
答えと解説を見る

正解：A. 共通鍵暗号は1225個、公開鍵暗号は100個

共通鍵暗号では、2人の組ごとに別々の鍵が必要です。同じ鍵を3人以上で使うと、ほかのメンバーにも内容が読めてしまうからです。n人から2人を選ぶ組の数は n(n−1)/2 なので、50人では 50 × 49 / 2 = 1225個です。公開鍵暗号では、各人が公開鍵と秘密鍵を1つずつ持てば、誰に送るときも相手の公開鍵で暗号化できるので、鍵は 2n = 2 × 50 = 100個で済みます。人数が増えると、共通鍵暗号の鍵の数は人数のおよそ2乗に比例して増えるのに対し、公開鍵暗号は人数に比例するだけです。これが公開鍵暗号で鍵の管理が楽になる理由の1つです。
