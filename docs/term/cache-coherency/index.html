キャッシュコヒーレンシとは

きゃっしゅこひーれんし

マルチコアのCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組み。あるコアが書き換えると、他のコアの古いコピーを無効にするなどして実現する。

この用語の分野: CPU・アーキテクチャ

解説の中の「キャッシュコヒーレンシ」

  • キャッシュコヒーレンシの仕組みは、書き込みのときに他のコアのコピーを無効にするなどして、どのコアから読んでも最新の値が見えるようにします。

    2つのコアがそれぞれ自分のキャッシュに変数xのコピーを持っている。コア0がxに書き込んだあと、コア1がxを読むときに、…

「キャッシュコヒーレンシ」が出てくる問題(4問)

  1. 2つのコアがそれぞれ自分のキャッシュに変数xのコピーを持っている。コア0がxに書き込んだあと、コア1がxを読むときに、キャッシュコヒーレンシの仕組みがなければ起こりうる問題はどれか。
  2. キャッシュコヒーレンシのプロトコルであるMESIの4つの状態の組み合わせとして正しいものはどれか。
  3. キャッシュコヒーレンシのスヌーピング方式の説明として正しいものはどれか。
  4. キャッシュコヒーレンシとメモリ一貫性モデルの違いとして正しいものはどれか。

この用語が出てくる比較

  • ライトスルーとライトバックの違い：キャッシュの書き込み方式を比較ライトスルーとライトバックのキャッシュを、書き込みの方式・メモリのトラフィック・速度・整合性・複雑さ・追い出しのコスト・用途の観点で表にして比較します。
