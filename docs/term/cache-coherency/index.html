キャッシュコヒーレンシとは

きゃっしゅこひーれんし

マルチコアのCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組み。あるコアが書き換えると、他のコアの古いコピーを無効にするなどして実現する。

「キャッシュコヒーレンシ」は、1分野の4問の練習問題に出てきます(マルチコアと同期など)。

この用語の分野: CPU・アーキテクチャ

キャッシュコヒーレンシの練習問題に挑戦

2つのコアがそれぞれ自分のキャッシュに変数xのコピーを持っている。コア0がxに書き込んだあと、コア1がxを読むときに、キャッシュコヒーレンシの仕組みがなければ起こりうる問題はどれか。

  1. Aコア1が自分のキャッシュに残っている古い値を読んでしまう
  2. Bコア1の読み出しが、コア0の書き込みより必ず速くなる
  3. Cxの値が2倍になって読める
答えと解説を見る

正解：A. コア1が自分のキャッシュに残っている古い値を読んでしまう

マルチコアのCPUでは、コアごとのキャッシュに同じ番地のデータのコピーができます。コア0が自分のキャッシュの中だけでxを書き換えると、コア1のキャッシュには古い値が残り、コア1はそれを読んでしまいます。キャッシュコヒーレンシの仕組みは、書き込みのときに他のコアのコピーを無効にするなどして、どのコアから読んでも最新の値が見えるようにします。

キャッシュコヒーレンシのプロトコルであるMESIの4つの状態の組み合わせとして正しいものはどれか。

  1. AMemory、Execute、Store、Index
  2. BModified、Exclusive、Shared、Invalid
  3. CMiss、Evict、Swap、Idle
答えと解説を見る

正解：B. Modified、Exclusive、Shared、Invalid

MESIでは、キャッシュの各ラインが、変更済みで自分だけが持つModified、変更はないが自分だけが持つExclusive、複数のコアが同じ内容を持つShared、無効なInvalidのどれかの状態をとります。コアが読み書きしたり、ほかのコアの読み書きを知ったりするたびに状態が移り変わり、同じ番地のデータの食い違いを防ぎます。

「キャッシュコヒーレンシ」が出てくる問題(4問)

  1. 2つのコアがそれぞれ自分のキャッシュに変数xのコピーを持っている。コア0がxに書き込んだあと、コア1がxを読むときに、キャッシュコヒーレンシの仕組みがなければ起こりうる問題はどれか。
  2. キャッシュコヒーレンシのプロトコルであるMESIの4つの状態の組み合わせとして正しいものはどれか。
  3. キャッシュコヒーレンシのスヌーピング方式の説明として正しいものはどれか。
  4. キャッシュコヒーレンシとメモリ一貫性モデルの違いとして正しいものはどれか。
