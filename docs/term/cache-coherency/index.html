キャッシュコヒーレンシとは

きゃっしゅこひーれんし

マルチコアのCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組み。あるコアが書き換えると、他のコアの古いコピーを無効にするなどして実現する。

この用語の分野: CPU・アーキテクチャ

解説の中の「キャッシュコヒーレンシ」

  • キャッシュコヒーレンシ制御は、書き換えを他のコアに知らせて古いデータを無効にするなどして、全コアから見たデータの一貫性を保ちます。
