AXIとは

えーえっくすあい

ArmのAMBA規格の1つで、SoCの中のブロックどうしをつなぐバス。5つの独立したチャネルとVALID・READYの受け渡しを持ち、AXI4-LiteやAXI4-Streamの種類もある。

この用語の分野: インターフェース・バス規格

解説の中の「AXI」

  • AXIは、読み出しのアドレス(AR)とデータ(R)、書き込みのアドレス(AW)とデータ(W)と応答(B)の5つのチャネルを持ちます。

    AXIバスの特徴として正しいものはどれか。

  • キャッシュラインの読み込みのように続いた番地のデータをまとめて扱うことが多いので、AXIは先頭の番地と長さだけを送り、データを続けて受け渡すバースト転送ができます。

    AXIのバースト転送の利点として正しいものはどれか。

  • AXIでは要求にIDを付けて複数を同時に出しておけるので、遅延の間にも次々とデータが返ってきて、帯域を有効に使えます。

    AXIで、前の読み出しの応答を待たずに次の読み出しの要求を出せる(複数の要求を同時に未完了のまま持てる)ことの利点とし…

「AXI」が出てくる問題(6問)

  1. AXIバスの特徴として正しいものはどれか。
  2. AXIの各チャネルで使われるVALIDとREADYによる受け渡し(ハンドシェイク)で、データが受け渡されるのはどのときか。
  3. AXIのバースト転送の利点として正しいものはどれか。
  4. AXIで、前の読み出しの応答を待たずに次の読み出しの要求を出せる(複数の要求を同時に未完了のまま持てる)ことの利点として正しいものはどれか。
  5. AXIの種類のうち、AXI4-Liteが主に使われる用途はどれか。
  6. SoCの内部で、CPUやメモリコントローラ、周辺回路などのブロックをつなぐのに広く使われている、ArmのAMBA規格のバスはどれか。
