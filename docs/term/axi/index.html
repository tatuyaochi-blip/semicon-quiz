AXIとは

えーえっくすあい

ArmのAMBA規格の1つで、SoCの中のブロックどうしをつなぐバス。5つの独立したチャネルとVALID・READYの受け渡しを持ち、AXI4-LiteやAXI4-Streamの種類もある。

「AXI」は、1分野の6問の練習問題に出てきます(インターフェース・バス規格など)。

この用語の分野: インターフェース・バス規格

AXIの練習問題に挑戦

AXIバスの特徴として正しいものはどれか。

  1. A読みのアドレス・読みのデータ・書きのアドレス・書きのデータ・書きの応答の5つのチャネルが独立していて、同時に動ける
  2. Bアドレスとデータを1本の線で交互に送る
  3. C読み出しと書き込みは、同時には決して行えない
答えと解説を見る

正解：A. 読みのアドレス・読みのデータ・書きのアドレス・書きのデータ・書きの応答の5つのチャネルが独立していて、同時に動ける

AXIは、読み出しのアドレス(AR)とデータ(R)、書き込みのアドレス(AW)とデータ(W)と応答(B)の5つのチャネルを持ちます。チャネルが独立しているので、読み出しと書き込みを同時に進めたり、アドレスを先に送ってデータを後から送ったりできます。それぞれのチャネルは同じVALIDとREADYの手順で受け渡しをするので、作りがそろっています。

AXIの各チャネルで使われるVALIDとREADYによる受け渡し(ハンドシェイク)で、データが受け渡されるのはどのときか。

  1. A送る側のVALIDと受ける側のREADYがどちらも1になっているクロックのエッジ
  2. B送る側がVALIDを1にした瞬間に、READYに関係なく
  3. C受ける側がREADYを1にした瞬間に、VALIDに関係なく
答えと解説を見る

正解：A. 送る側のVALIDと受ける側のREADYがどちらも1になっているクロックのエッジ

送る側は有効なデータがあるときVALIDを1にし、受ける側は受け取れるときREADYを1にします。クロックのエッジで両方が1なら受け渡しが成立します。受ける側が忙しいときはREADYを0にして送る側を待たせられるので(背圧)、速さの違うブロックどうしでもデータを失わずにつなげます。送る側はREADYを待たずにVALIDを出す決まりで、待ち合いによる停止を防いでいます。

「AXI」が出てくる問題(6問)

  1. AXIバスの特徴として正しいものはどれか。
  2. AXIの各チャネルで使われるVALIDとREADYによる受け渡し(ハンドシェイク)で、データが受け渡されるのはどのときか。
  3. AXIのバースト転送の利点として正しいものはどれか。
  4. AXIで、前の読み出しの応答を待たずに次の読み出しの要求を出せる(複数の要求を同時に未完了のまま持てる)ことの利点として正しいものはどれか。
  5. AXIの種類のうち、AXI4-Liteが主に使われる用途はどれか。
