割り込みハンドラとは

わりこみはんどら

割り込みや例外が起きたときにCPUが実行する処理。中断した処理の状態を保存し、原因に応じた処理をして、元の処理に戻る。処理はできるだけ短くするのが原則。

この用語の分野: OSとハードウェア

解説の中の「割り込みハンドラ」

  • 割り込みハンドラの実行中は、同じ種類やより低い優先度の割り込みが待たされることが多く、長い処理をするとシステム全体の応答が悪くなります。

    割り込みハンドラの処理を、すぐに行う短い部分と、あとで通常の文脈で行う残りの部分に分ける理由として正しいものはどれか。

  • 割り込みは、キーボード入力、タイマー、通信の受信などのイベントが起きたときに、CPUが実行中の処理を中断し、レジスタなどの状態を保存して対応する処理(割り込みハンドラ)を行い、終わったら元に戻る仕組みです。

    実行中の処理を一時的に中断し、外部機器からの要求などに応じた処理を優先して行うCPUの仕組みはどれか。

  • 組込みのソフトウェアでは、割り込みハンドラの既定の処理を弱いシンボルで用意しておき、利用者が同じ名前の関数を書けば、それに差し替わるようにする使い方がよく見られます。

    リンカでの弱いシンボル(weak symbol)の扱いとして正しいものはどれか。

「割り込みハンドラ」が出てくる問題(7問)

  1. 割り込みハンドラの処理を、すぐに行う短い部分と、あとで通常の文脈で行う残りの部分に分ける理由として正しいものはどれか。
  2. 実行中の処理を一時的に中断し、外部機器からの要求などに応じた処理を優先して行うCPUの仕組みはどれか。
  3. リンカでの弱いシンボル(weak symbol)の扱いとして正しいものはどれか。
  4. 割り込みと例外の違いとして一般的な説明はどれか。
  5. CPUが割り込みを受け付けたときの一般的な処理の流れとして正しいものはどれか。
  6. OSが、自分からCPUを手放さないプログラムからでも一定時間ごとにCPUを取り戻して、ほかのプロセスに切り替えられるのは、主にどのしくみによるか。
  7. スピンロックの説明として正しいものはどれか。
