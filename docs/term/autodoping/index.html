オートドーピングとは

おーとどーぴんぐ

エピタキシャル成長中に、基板などの不純物が気相を通じて成長層に取り込まれてしまう現象。高濃度の基板の上に低濃度の層を成長させるときに問題になる。

「オートドーピング」は、2分野の4問の練習問題に出てきます(エピタキシャル成長, シリコンウエハなど)。

この用語の分野: エピタキシャル成長

オートドーピングの練習問題に挑戦

ヒ素やアンチモンを高濃度に添加した低抵抗のn⁺シリコンウエハの主な用途として正しいものはどれか。

  1. Aイメージセンサの受光層そのもの
  2. B太陽電池の反射防止膜
  3. C低濃度のエピタキシャル層を成長させる基板や、縦型パワーデバイスのドレイン側の基板
答えと解説を見る

正解：C. 低濃度のエピタキシャル層を成長させる基板や、縦型パワーデバイスのドレイン側の基板

高濃度で低抵抗(0.001〜0.01 Ω·cm程度)のn⁺ウエハは、その上に低濃度のエピタキシャル層を成長させたエピウエハの基板として使われます。縦型のパワーMOSFETやダイオードでは電流が基板を縦に流れるため、基板の抵抗を低くするとオン抵抗を下げられます。偏析や蒸発の性質から、ヒ素やアンチモン、リンが使い分けられ、エピ層へのにじみ出し(オートドーピング)の抑制が課題です。

エピタキシャル成長中に、基板などの不純物が気相を通じて成長層に取り込まれてしまう現象を何と呼ぶか。

  1. Aオートドーピング
  2. Bゲッタリング
  3. Cエレクトロマイグレーション
答えと解説を見る

正解：A. オートドーピング

オートドーピングは、高濃度に不純物を含む基板やその裏面・側面から不純物が蒸発し、ガスを通じて成長中の層に取り込まれる現象です。特に成長の初期に多く、エピ層の不純物濃度が設計値からずれたり、界面の濃度変化がなだらかになったりします。基板の裏面を酸化膜やポリシリコンで覆う、減圧で成長させる、成長前に一度ガスで不純物を追い出すなどの対策がとられます。

解説の中の「オートドーピング」

  • 偏析や蒸発の性質から、ヒ素やアンチモン、リンが使い分けられ、エピ層へのにじみ出し(オートドーピング)の抑制が課題です。

    ヒ素やアンチモンを高濃度に添加した低抵抗のn⁺シリコンウエハの主な用途として正しいものはどれか。

  • オートドーピングは、高濃度に不純物を含む基板やその裏面・側面から不純物が蒸発し、ガスを通じて成長中の層に取り込まれる現象です。

    エピタキシャル成長中に、基板などの不純物が気相を通じて成長層に取り込まれてしまう現象を何と呼ぶか。

  • 減圧(数kPa〜数十kPa)でエピタキシャル成長を行うと、ガスの拡散が速くなり、基板から蒸発した不純物が成長面の近くの境界層に滞留しにくくなるため、オートドーピングを抑えられます。

「オートドーピング」が出てくる問題(4問)

  1. ヒ素やアンチモンを高濃度に添加した低抵抗のn⁺シリコンウエハの主な用途として正しいものはどれか。
  2. エピタキシャル成長中に、基板などの不純物が気相を通じて成長層に取り込まれてしまう現象を何と呼ぶか。
  3. シリコンのエピタキシャル成長を減圧で行う利点の一つとして正しいものはどれか。
  4. 高濃度の基板の上に低濃度のエピ層を高温で成長させるとき、固体の中の拡散によって基板の不純物がエピ層側にしみ出し、界面の濃度変化がなだらかになる現象を何と呼ぶか。
