ミッシングコードとは

みっしんぐこーど

入力を変化させても、ADコンバータのある出力コードが一度も現れない不具合。DNLが−1 LSBに達したときに起こる。

この用語の分野: AD/DA変換

解説の中の「ミッシングコード」

  • DNLが −1 LSBになるとそのコードが現れなくなり(ミッシングコード)、+1 LSBを超えると分解能が実質的に落ちます。

    ADコンバータの微分非直線性(DNL)の説明として正しいものはどれか。

  • これがミッシングコードで、例えばSAR型ADCの内部DACの上位ビットの重みが小さすぎると、コードが飛ぶことがあります。

    入力を変化させても、ある出力コードが一度も現れないADコンバータの不具合を何と呼ぶか。

「ミッシングコード」が出てくる問題(2問)

  1. ADコンバータの微分非直線性(DNL)の説明として正しいものはどれか。
  2. 入力を変化させても、ある出力コードが一度も現れないADコンバータの不具合を何と呼ぶか。
