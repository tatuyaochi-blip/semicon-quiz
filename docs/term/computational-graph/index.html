計算グラフとは

けいさんぐらふ

演算を節、テンソルの受け渡しを矢印として、モデルの計算を表した図。自動微分やAIコンパイラの最適化の土台になる。

「計算グラフ」は、1分野の4問の練習問題に出てきます(AIハードウェアとソフトウェアスタックなど)。

この用語の分野: AIハードウェアとソフトウェアスタック

計算グラフの練習問題に挑戦

AIのフレームワークやコンパイラで使われる「計算グラフ」の説明として正しいものはどれか。

  1. AAIの性能を年ごとに示した折れ線グラフ
  2. B学習の損失の値の変化を示したグラフ
  3. C演算を節、データ(テンソル)の受け渡しを矢印として、モデルの計算を表した図
答えと解説を見る

正解：C. 演算を節、データ(テンソル)の受け渡しを矢印として、モデルの計算を表した図

計算グラフは、行列の積、足し算、活性化関数などの演算を節に、それらの間を流れるテンソルを矢印にした、モデルの計算の設計図です。フレームワークはこのグラフを逆にたどって逆伝播の勾配を自動で計算し、コンパイラはグラフ全体を見て融合や並べ替えの最適化を行います。どの演算が独立に並列で行えるかも、グラフから分かります。

解説の中の「計算グラフ」

  • 計算グラフは、行列の積、足し算、活性化関数などの演算を節に、それらの間を流れるテンソルを矢印にした、モデルの計算の設計図です。

    AIのフレームワークやコンパイラで使われる「計算グラフ」の説明として正しいものはどれか。

  • AIコンパイラは、モデルを演算とデータの流れの計算グラフとして受け取り、まとめられる演算の融合、不要な計算の削除、メモリの並べ方の選択、タイルの大きさの調整などを行い、GPUやNPUなどの対象に合ったカーネルを作ります。

    XLAやTVM、PyTorchのコンパイル機能のようなAIコンパイラが行う主な処理として正しいものはどれか。

  • ONNX(Open Neural Network Exchange)は、モデルの計算グラフと重みを共通の形式で表すための規格です。

    ONNXの説明として正しいものはどれか。

  • フレームワークやAIコンパイラ・ランタイムが計算グラフを最適化し、行列の積や畳み込みなどは高度に最適化された演算のライブラリのカーネルを呼びます。

    AIのソフトウェアスタックを、利用者に近い上の層からハードウェアに近い下の層へ並べたものとして正しいものはどれか。

  3. ONNXの説明として正しいものはどれか。
