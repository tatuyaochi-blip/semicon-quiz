屈折率とは

くっせつりつ

真空中の光の速さを、物質中の光の速さで割った値。波長1.55 µmでシリコンは約3.48、酸化膜(SiO2)は約1.45で、この差が大きいほど光を小さな導波路に強く閉じ込められる。

「屈折率」は、5分野の18問の練習問題に出てきます(シリコンフォトニクス, エピタキシャル成長, リソグラフィなど)。

この用語の分野: シリコンフォトニクス

屈折率が表すもの

屈折率nは、真空中の光の速さと、物質中での位相速度の比です。光が物質に入っても周波数は変わらないため、物質中の波長はλ/nに縮みます。たとえば1.55 µmの光は、シリコン中では波長約0.45 µmになります。屈折率は波長(分散)や温度によって変わるので、値は条件とともに示す必要があります。代表的な値は、1.55 µmでシリコンが約3.48、SiO2が約1.45、窒化シリコンが約2.0、波長193 nmでの水が約1.44です。

スネルの法則と全反射

界面ではn1 sinθ1 = n2 sinθ2が成り立ちます。屈折率の高い側から低い側へ進むとき、臨界角(sinθc = n2/n1)を超える光線は外へ出られずに全反射します。シリコンから酸化膜へ向かう場合、1.45 / 3.48からθcは法線に対して約25°となり、ほとんどの光線が閉じ込められるため、導波路を非常に小さくし、急に曲げることができます。光ファイバでは屈折率差が1%未満でθcは80°を超え、界面すれすれの光線しか導かれません。逆に低い側から高い側へ向かうときは全反射は起きません。導波モードが感じる実効屈折率は、コアとクラッドの値の間になります。

屈折率を意図的に変える

シリコンの熱光学係数は約1.8×10⁻⁴ /Kと大きく、Cバンドのリング共振器の共振波長は1 ℃あたり約0.07〜0.08 nmずれます。ヒータによる波長チューニングはこの性質を利用しています。高速変調では、シリコンの結晶が中心対称でポッケルス効果を持たないため、キャリアプラズマ分散効果(自由キャリア分散)を利用します。電子と正孔を加えると屈折率が下がり、吸収が増えます。この変化は約10⁻³以下と小さいので、位相シフタの長さはmmオーダーになります。対照的に、ニオブ酸リチウムは強いポッケルス効果を持ちます。

製造プロセスで使われる屈折率

屈折率はいくつかのプロセス計測・装置で中心的な役割を果たします。エリプソメトリは、反射光の偏光変化をモデルにフィッティングし、膜厚と屈折率を同時に求めます。FTIR(フーリエ変換赤外分光)は干渉からエピタキシャル層の膜厚を測りますが、これは低濃度のエピ層と高濃度の基板の間で、自由キャリアが生むわずかな赤外域の屈折率差を利用しています。液浸露光ではレンズとウエハの間を水で満たし、NA(開口数) = n sinθを1より大きい約1.35まで高めます。シリコン酸窒化膜は屈折率を調整でき、反射防止膜として使われます。

屈折率の練習問題に挑戦

シリコン導波路(屈折率約3.5)を酸化膜(SiO2、屈折率約1.45)で囲む構造の特徴として正しいものはどれか。

  1. A屈折率差が大きいので光が外へ漏れやすく、光ファイバより大きな半径でしか導波路を曲げられず、集積に向かない
  2. B屈折率差が大きく光を強く閉じ込めるので、数 µmの小さな半径で曲げられ、素子を高密度に並べられる
  3. C屈折率差が大きいほど側壁の凹凸の影響を受けにくく、伝搬損失が光ファイバと同程度に小さくなる
答えと解説を見る

正解：B. 屈折率差が大きく光を強く閉じ込めるので、数 µmの小さな半径で曲げられ、素子を高密度に並べられる

光は屈折率の高い芯(コア)と低い周囲(クラッド)の境界で全反射して閉じ込められ、屈折率差が大きいほど強く閉じ込められます。シリコンと酸化膜の差は約2で、光ファイバのコアとクラッドの差(1%未満)よりけた違いに大きく、断面が約0.5 µm × 0.22 µmの細い導波路をつくれ、曲げ半径も数 µmまで小さくできます。一方、屈折率差が大きいほど側壁の凹凸で光が散乱されやすく、伝搬損失は条件によりますが代表的なストリップ導波路で1〜3 dB/cm程度(リブ導波路や低損失なプロセスではそれ以下)と、ファイバ(約0.2 dB/km)よりはるかに大きくなります。

屈折率3.48のシリコンから屈折率1.45の酸化膜へ光が進むとき、全反射が起こる臨界角(境界面の法線から測った角度)に最も近いものはどれか。

  1. A約65°
  2. B約25°
  3. C約45°
答えと解説を見る

正解：B. 約25°

臨界角θcは sinθc = n2 / n1 で求められ、1.45 ÷ 3.48 ≈ 0.417 から θc ≈ 24.6°、約25°となります。法線から測って25°より大きい角度で境界に当たる光は、酸化膜側へ出ていかずにすべて反射されます。全反射は屈折率の高い側から低い側へ進むときだけ起こり、逆向きでは起こりません。屈折率差が小さい光ファイバでは臨界角が80°以上と大きく、境界に浅い角度で当たる光しか閉じ込められません。約65°は、境界面から測った角度と取り違えた値です。

よくある質問

波長1550 nmでのシリコンの屈折率はいくつですか?

室温で約3.48で、温度が上がると約1.8×10⁻⁴ /Kの割合でわずかに大きくなります。同じ波長での二酸化シリコンは約1.45です。

屈折率差が大きいと光導波路を小さくできるのはなぜですか?

屈折率差が大きいほど臨界角が小さくなり、モードがコアに強く閉じ込められるため、コアをサブミクロンにしても、半径数 µmの曲げで光が放射されないからです。その代わり、側壁の荒れや寸法ばらつきの影響を受けやすくなります。

実効屈折率とは何ですか?

導波モード全体が感じる屈折率で、伝搬定数から定義され、常にクラッドとコアの屈折率の間の値になります。導波路を伝わる間に蓄積する位相や、リング共振器・グレーティングの共振条件を決めます。
