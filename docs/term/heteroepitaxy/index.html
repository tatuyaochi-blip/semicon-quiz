ヘテロエピタキシーとは

へてろえぴたきしー

基板と異なる材料の単結晶膜を成長させること。シリコン上のSiGeや、サファイア上のGaNなど。同じ材料の場合はホモエピタキシー。

「ヘテロエピタキシー」は、1分野の1問の練習問題に出てきます(エピタキシャル成長など)。

この用語の分野: エピタキシャル成長

格子不整合と臨界膜厚

膜と基板の格子定数が異なる場合、その差は格子不整合率f = (a_film − a_substrate)/a_substrateで表します。ゲルマニウムの格子定数はシリコンより約4%大きく、サファイア上のGaNでは面内の実効的な不整合が約16%になります。薄い層は面内で引き伸ばされたり圧縮されたりして基板に合わせ、弾性ひずみを蓄えたままシュードモルフィックに成長できます。しかし不整合が大きいほど小さくなる臨界膜厚を超えると、界面にミスフィット転位ができてひずみが緩和し、多くの場合、膜を貫いて上に伸びる貫通転位も伴います。

熱膨張係数の不整合

格子がよく整合した組み合わせでも、2つの材料の温度による膨張の仕方が違えば、割れや反りが起こることがあります。エピタキシャル成長は高温で行うため、冷却時に熱膨張係数の差によって応力がウエハ全体に蓄積します。たとえばシリコン上に成長したGaNは引張応力を受け、応力を補償する層を積層に入れないと割れてしまうことがあります。熱膨張の不整合によるウエハの反りは、後工程のリソグラフィやウエハ搬送も難しくします。

欠陥を抑えるバッファ層

不整合の大きい膜を直接成長させる代わりに、バッファ層を挟みます。Ge組成を1 µmあたり約10%ずつ上げる組成傾斜SiGeバッファでは、ミスフィット転位がバッファ内で長距離をすべり移動できるため、数µmのバッファが必要になる代わりに、最上層の貫通転位密度を約10⁵〜10⁶ cm⁻²まで下げられます。サファイア上のGaNでは、AlNやGaNの薄い低温核形成層を使いますが、それでも貫通転位密度はシリコンよりはるかに高いままです。

ヘテロエピタキシーとホモエピタキシー

ホモエピタキシーは、高濃度ドープのシリコンウエハ上に低濃度ドープのシリコン層を成長させる場合のように、基板と同じ材料を成長させるもので、格子不整合はありません。ヘテロエピタキシーはより難しいものの、SiGeソース/ドレインのようなひずみ技術や、ヘテロ接合バイポーラトランジスタ(HBT)、高電子移動度トランジスタ(HEMT)、量子井戸、LED、GaAs上のAlGaAsのようなレーザでのバンドギャップエンジニアリングを可能にします。なお熱酸化で形成したSiO2はエピタキシーではなく、シリコンを消費してできるアモルファス膜です。

  1. Aシリコン基板上へのシリコンの成長
  2. Bシリコン基板上へのSiGeの成長
  3. Cシリコン基板の熱酸化
答えと解説を見る

正解：B. シリコン基板上へのSiGeの成長

基板と同じ材料を成長させるのがホモエピタキシー、異なる材料を成長させるのがヘテロエピタキシーです。シリコン上のSiGe、サファイアやSiC上のGaN、GaAs上のAlGaAsなどがヘテロの例で、格子定数や熱膨張の違いによるひずみや欠陥の管理が課題になります。熱酸化でできるSiO2は、シリコンを消費してできるアモルファスの膜で、エピタキシャル成長ではありません。

よくある質問

ヘテロエピタキシーにおける臨界膜厚とは何ですか?

格子不整合のある層が、整合したひずみ状態を保ったまま成長できる最大の膜厚です。これを超えるとひずみを緩和するためにミスフィット転位が発生し、不整合が大きいほど臨界膜厚は薄くなります。

GaNはなぜGaN基板ではなくサファイアやシリコン上に成長させるのですか?

大口径で安価なGaN単結晶基板はこれまで作るのが難しかったため、格子や熱膨張の不整合があっても、サファイア、SiC、シリコン上にヘテロエピタキシャル成長させています。

シリコン上のSiGeはヘテロエピタキシーですか?

はい。SiGeはシリコンより格子定数が大きいため、薄いSiGe層は圧縮ひずみを受けた状態で成長し、この性質がトランジスタやHBTで利用されています。
