RCA洗浄とは

あーるしーえーせんじょう

SC-1(アンモニア・過酸化水素水)でパーティクルや有機物を、SC-2(塩酸・過酸化水素水)で金属汚染を除去する洗浄法。

この用語の分野: CMP・洗浄

解説の中の「RCA洗浄」

  • RCA洗浄では、まずアルカリ性のSC-1でパーティクルや有機物を除去し、次に酸性のSC-2で金属汚染を除去するのが基本的な順序です。

    標準的なRCA洗浄におけるSC-1とSC-2の順序と目的の組み合わせとして正しいものはどれか。

「RCA洗浄」が出てくる問題(2問)

  1. RCA洗浄で使われるSC-1(アンモニア・過酸化水素水の混合液)の主な目的はどれか。
  2. 標準的なRCA洗浄におけるSC-1とSC-2の順序と目的の組み合わせとして正しいものはどれか。
