ベイヤー配列とは

べいやーはいれつ

2×2の画素に赤・緑・緑・青のカラーフィルタを並べる配列。人の目の感度が高い緑を2つにしている。各画素の足りない色は周囲から補う(デモザイク)。

「ベイヤー配列」は、1分野の4問の練習問題に出てきます(イメージセンサ・光デバイスなど)。

この用語の分野: イメージセンサ・光デバイス

ベイヤー配列の並び方

シリコンのフォトダイオードは光の強さしかわからず、色を区別できません。そこでカラーのイメージセンサでは、画素ごとに赤(R)・緑(G)・青(B)のいずれかのカラーフィルタを置きます。ベイヤー配列は、2×2の画素を1つの単位として、緑を対角の位置に2つ、赤と青を1つずつ配置し、これを縦横に繰り返す並べ方です。緑は市松模様に並び、赤と青はそれぞれ1行おき・1列おきに並びます。1976年にコダックのブライス・ベイヤー(Bryce Bayer)が考案し、現在もほとんどのカラーのイメージセンサで使われています。

緑が2つある理由

人の目は緑の光に最も敏感で、明るさ(輝度)の感じ方の多くを緑の波長域が占めています。画像の細かさとして感じられるのは主に輝度の変化なので、緑の画素を多くすると、同じ画素数でも解像感を高められます。一方、色の変化に対する目の解像力は輝度ほど高くないため、赤と青が少なくても、見た目の画質への影響は比較的小さくなります。ただし、各画素は1色しか測らず、赤と青の画素はそれぞれ全体の4分の1しかないため、色の解像度は画素数から想像されるより低くなります。

デモザイクと偽色

センサからそのまま読み出したRAWデータでは、各画素に1色の値しかありません。カメラの画像処理(ISP)は、周囲の画素の値から足りない2色を推定して補い、すべての画素にRGBの3色をそろえます。これがデモザイク(色補間)です。単純な平均で補うと、輪郭に本来ない色(偽色)やギザギザが出るため、エッジの方向を調べて補間する方法や、AIを使う方法が用いられます。細かい縞模様では偽色やモアレが出やすいため、カメラによっては、センサの前に光学ローパスフィルタを置いて、細かすぎる模様をわずかにぼかします。

クアッドベイヤーなどの派生配列

スマートフォン向けの高画素センサでは、画素の大きさが1 µm前後かそれ以下になり、1画素あたりの感度が不足しやすくなります。そこで、同じ色の画素を2×2(または3×3、4×4)のまとまりにして、そのまとまりをベイヤーの並びに配置したクアッドベイヤー配列などが使われます。暗い場面では同じ色の画素をまとめて1画素として読み出す(ビニング)ことで感度を上げ、明るい場面では画素の並びを変換する処理で高い解像度の画像をつくります。このほか、フィルタで色を分けない白(W)の画素を加えて、感度を高める配列もあります。

  1. A赤
  2. B青
  3. C緑

正解：C. 緑

よくある質問

ベイヤー配列で緑が多いのはなぜですか?

人の目は緑の光に最も敏感で、明るさの情報の多くを緑から得ているためです。2×2の画素に緑を2つ、赤と青を1つずつ置くことで、同じ画素数でも解像感を高めています。

デモザイクとは何ですか?

ベイヤー配列の各画素は1色の値しか持たないため、周囲の画素から足りない2色の値を推定して補い、すべての画素にRGBの値をそろえる処理です。色補間とも呼ばれ、カメラの画像処理の重要な工程です。

ベイヤー配列とクアッドベイヤー配列の違いは?

ベイヤー配列は、2×2の画素に赤・緑・緑・青を1つずつ並べます。クアッドベイヤー配列は、同じ色の画素を2×2のまとまりにして、そのまとまりをベイヤーの並びに配置したものです。暗い場面では4画素をまとめて感度を上げ、明るい場面では高い解像度で使えます。
