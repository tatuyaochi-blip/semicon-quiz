ベイヤー配列とは

べいやーはいれつ

2×2の画素に赤・緑・緑・青のカラーフィルタを並べる配列。人の目の感度が高い緑を2つにしている。各画素の足りない色は周囲から補う(デモザイク)。

この用語の分野: イメージセンサ・光デバイス

解説の中の「ベイヤー配列」

  • ベイヤー配列では、2×2画素に赤1つ、青1つ、緑2つを配置します。

    ベイヤー配列のカラーフィルタで、2×2の画素の中に最も多く配置される色はどれか。

  • ベイヤー配列の各画素は1色の情報しかもたないため、足りない2色の値を周囲の画素から推定して補う必要があり、これがデモザイク(色補間)です。

    ベイヤー配列などのカラーフィルタを使ったセンサの出力から、各画素の赤・緑・青すべての値を周囲の画素から補って求める処理…

  • 小さな画素で感度を保つため、裏面照射型、DTI、積層型に加え、4つ(または9つ、16個)の同色画素を並べてまとめて使うクアッドベイヤー配列などが組み合わされています。

    スマートフォン向けの高画素イメージセンサの画素サイズとして最も近いものはどれか。

「ベイヤー配列」が出てくる問題(4問)

  1. ベイヤー配列のカラーフィルタで、2×2の画素の中に最も多く配置される色はどれか。
  2. ベイヤー配列などのカラーフィルタを使ったセンサの出力から、各画素の赤・緑・青すべての値を周囲の画素から補って求める処理を何と呼ぶか。
  3. スマートフォン向けの高画素イメージセンサの画素サイズとして最も近いものはどれか。
  4. 「1,200万画素」のイメージセンサの説明として正しいものはどれか。
