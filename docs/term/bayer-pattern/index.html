ベイヤー配列とは

べいやーはいれつ

2×2の画素に赤・緑・緑・青のカラーフィルタを並べる配列。人の目の感度が高い緑を2つにしている。各画素の足りない色は周囲から補う(デモザイク)。

「ベイヤー配列」は、1分野の4問の練習問題に出てきます(イメージセンサ・光デバイスなど)。

この用語の分野: イメージセンサ・光デバイス

ベイヤー配列の練習問題に挑戦

ベイヤー配列のカラーフィルタで、2×2の画素の中に最も多く配置される色はどれか。

  1. A赤
  2. B青
  3. C緑
答えと解説を見る

正解：C. 緑

ベイヤー配列では、2×2画素に赤1つ、青1つ、緑2つを配置します。人の目は緑の光に最も敏感で、明るさ(輝度)の情報の多くを緑から得ているため、緑を多くして解像感を高めています。各画素にない2色の情報は周囲の画素から補間します(デモザイク)。1976年にコダックのブライス・ベイヤーが考案し、現在もほとんどのカラーセンサで使われています。

ベイヤー配列などのカラーフィルタを使ったセンサの出力から、各画素の赤・緑・青すべての値を周囲の画素から補って求める処理を何と呼ぶか。

  1. A相関二重サンプリング
  2. Bデモザイク(色補間)
  3. Cホワイトバランス
答えと解説を見る

正解：B. デモザイク(色補間)

ベイヤー配列の各画素は1色の情報しかもたないため、足りない2色の値を周囲の画素から推定して補う必要があり、これがデモザイク(色補間)です。単純な平均では輪郭に偽色やギザギザが出るため、エッジの方向を調べて補間する方法や、AIを使う方法が用いられます。カメラの画像処理(ISP)の重要な工程で、RAW現像ソフトで処理方法を選べることもあります。
