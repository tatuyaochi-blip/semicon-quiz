ラインエッジラフネス(LER)とは

らいんえっじらふねす

微細なレジストのパターンの側面に生じる、ナノメートル単位の凹凸。線幅のばらつき(LWR)の原因となり、トランジスタの特性のばらつきにつながる。

この用語の分野: リソグラフィ

解説の中の「ラインエッジラフネス(LER)」

  • LERは、パターンの側面のでこぼこの大きさ(通常は3σで表す)を表す指標で、線幅のばらつきとして表したものはLWRと呼びます。

    微細なレジストパターンの側面に生じる、ナノメートル単位の凹凸を表す指標はどれか。

  • これがストカスティクスで、パターンの欠け・つながり、LER、小さな穴の開かない不良などの原因になります。

    EUV露光で問題になる確率的なゆらぎ(ストカスティクス)の主な原因として正しいものはどれか。

  • ただしピッチ(繰り返しの間隔)は細くならず、削る量のばらつきやLERがそのまま寸法のばらつきになるため、制御が重要です。

    露光でつくったレジストのパターンを、プラズマで少しずつ細らせて、露光の限界より細い線をつくる手法はどれか。

「ラインエッジラフネス(LER)」が出てくる問題(3問)

  1. 微細なレジストパターンの側面に生じる、ナノメートル単位の凹凸を表す指標はどれか。
  2. EUV露光で問題になる確率的なゆらぎ(ストカスティクス)の主な原因として正しいものはどれか。
  3. 露光でつくったレジストのパターンを、プラズマで少しずつ細らせて、露光の限界より細い線をつくる手法はどれか。
