ラプラス変換とは

らぷらすへんかん

時間の関数 f(t)(t ≥ 0)を、複素数 s の関数 F(s) = ∫₀^∞ f(t)e^(−st) dt に変換する方法。初期値が0なら、微分は s を掛けること、積分は s で割ることに対応するので、線形な微分方程式を s の代数の式として扱える。制御工学で伝達関数を求める基本の道具で、離散時間の系ではz変換が同じ役割をする。単位ステップは 1/s、e^(−at) は 1/(s + a) に変換される。

「ラプラス変換」は、2分野の3問の練習問題に出てきます(制御工学の基礎, デジタル信号処理の基礎など)。

この用語の分野: 制御工学の基礎

よく使う変換の対

単位インパルス δ(t) は1、単位ステップは 1/s、ランプ t は 1/s²、e^(−at) は 1/(s + a)、sin ωt は ω/(s² + ω²) になります。時間を L だけ遅らせると e^(−Ls) が掛かり、e^(−at) を掛けると s が s + a に置き換わります。これらの対と部分分数分解を組み合わせると、多くの応答を表を見ながら逆変換できます。

最終値の定理と初期値の定理

出力の最終値は、sF(s) の極がすべて s平面の左半分にある場合に限って、lim[t→∞] f(t) = lim[s→0] sF(s) で求められます。例えば伝達関数 G(s) の系のステップ応答の最終値は G(0) で、これを定常ゲインと呼びます。初期値は lim[t→+0] f(t) = lim[s→∞] sF(s) で求められます。

フーリエ変換、z変換との関係

ラプラス変換を s = jω の虚軸の上で評価したものが、フーリエ変換(周波数応答)に当たります。サンプリングした信号では、z = e^(sT) とおいたz変換が同じ役割をし、s平面の左半分が z平面の単位円の内側に対応します。そのため、連続時間の「極の実部が負なら安定」は、離散時間では「極が単位円の内側なら安定」になります。

ラプラス変換の練習問題に挑戦

初期値をすべて0とするとき、時間関数の微分と積分を、ラプラス変換した s の領域で表す計算の組み合わせとして正しいものはどれか。

  1. A微分は s を掛けること、積分は s で割ること
  2. B微分は s で割ること、積分は s を掛けること
  3. C微分は s を足すこと、積分は s を引くこと
答えと解説を見る

正解：A. 微分は s を掛けること、積分は s で割ること

ラプラス変換では、f(t) の微分は sF(s) − f(0) に、積分は F(s)/s に対応します。初期値が0なら、微分は s を掛けること、積分は s で割ることになり、微分方程式が s の多項式の計算に変わります。例えば、RC回路の式 RC·dv/dt + v = vin は (RCs + 1)V(s) = Vin(s) となり、伝達関数 1/(1 + RCs) が得られます。単位ステップ関数は 1/s に、e^(−at) は 1/(s + a) に変換されます。

よくある質問

なぜ制御工学でラプラス変換を使うのですか?

微分方程式を代数の式に変えられるので、要素をつないだ系の伝達関数を、掛け算や割り算で組み立てられるからです。極の位置から、安定性や応答の速さも読み取れます。

初期値が0でないときはどうなりますか?

微分の変換は sF(s) − f(0) となり、初期値の項が残ります。伝達関数は初期値を0として定義するので、初期値による応答は別に加えて考えます。
