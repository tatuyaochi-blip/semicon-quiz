引数とは

ひきすう

関数や手続を呼び出すときに渡す値。宣言の側で値を受け取る変数を仮引数、呼出しの側で渡す値を実引数という。値をコピーして渡す値渡しと、変数や配列そのものを参照させる参照渡しがある。

「引数」は、12分野の29問の練習問題に出てきます(プログラミングの基礎(擬似言語のトレース), リンカ・ローダと実行形式, コンパイラなど)。

引数の練習問題に挑戦

RISC-Vの標準の呼び出し規約で、整数の引数と戻り値の受け渡しに使うレジスタとして正しいものはどれか。

  1. A引数はs0〜s7、戻り値はra
  2. B引数はa0〜a7、戻り値はa0(とa1)
  3. C引数はすべてスタック、戻り値はsp
答えと解説を見る

正解：B. 引数はa0〜a7、戻り値はa0(とa1)

RISC-Vの標準の呼び出し規約では、整数の引数を最大8個までa0〜a7(x10〜x17)に入れて渡し、戻り値はa0に、RV32での64ビットの値などはa0とa1の2つに入れて返します。メモリより速いレジスタで受け渡すので、関数呼び出しの手間が小さくなります。8個を超える引数はスタックに置きます。浮動小数点の引数はfa0〜fa7を使います。

RISC-Vの標準の呼び出し規約で、整数の引数が10個ある関数を呼ぶとき、9個目と10個目の引数はどこで渡されるか。

  1. As0とs1
  2. Bt0とt1
  3. Cスタック上
答えと解説を見る

正解：C. スタック上

引数用のレジスタはa0〜a7の8本なので、9個目以降は呼び出す側がスタックに積み、呼ばれた側はスタックポインタからの決まった位置で読みます。メモリへのアクセスが増えるので、引数がとても多い関数は少し遅くなります。大きな構造体はまとめて構造体へのポインタで渡すなど、引数を少なくする工夫がよく使われます。
