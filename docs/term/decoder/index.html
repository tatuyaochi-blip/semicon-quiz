デコーダとは

でこーだ

nビットの入力に応じて、2ⁿ本の出力のうち1本だけを有効にする回路。メモリのアドレスから読み書きする行を選ぶのに使われる。逆の働きをする回路はエンコーダ。

「デコーダ」は、1分野の2問の練習問題に出てきます(論理回路など)。

この用語の分野: 論理回路

バイナリデコーダの動作

n 入力 2ⁿ 出力のデコーダには、とりうる入力コードごとに1本の出力があります。各出力は入力ビットをそのまま、または反転して取り込んだ AND で、ちょうど1つの組み合わせのときだけ有効になります。出力 k はコード k の最小項(ミンターム)にあたります。2-4 デコーダには 2 入力 AND ゲート4個とインバータ、3-8 デコーダには 3 入力ゲート8個が必要です。多くのデコーダはイネーブル入力を備え、出力をアクティブローにしています。イネーブルを使えば小さなデコーダを縦続接続して大きなデコーダをつくれます。すべての最小項が得られるので、デコーダの後に OR ゲートを置けば、入力の任意の組み合わせ論理関数を実現できます。

デコーダ、エンコーダ、デマルチプレクサの違い

エンコーダは逆の働きをし、2ⁿ 本のうち1本だけ有効な入力を n ビットのコードに変換します。単純なエンコーダは2つの入力が同時に有効になると誤った結果を出すため、プライオリティエンコーダは有効な入力のうち優先度の最も高いものを出力します。デマルチプレクサは、イネーブルにデータを載せたデコーダで、1つの入力信号を選択ビットで選んだ出力へ振り分けます。マルチプレクサは、デコーダの出力で各データ入力をゲートし、共通の OR にまとめたものと見なせます。BCD-7セグメントドライバのようなコード変換器も、出力がワンホットではないもののデコーダと呼ばれます。

メモリのアドレスデコーダ

メモリアレイには必ずデコーダが使われています。行デコーダは行アドレスを1本の有効なワード線に変換し、列デコーダはどのビット線をセンスアンプや I/O につなぐかを選びます。数千本のワード線をそれぞれ多入力の AND ゲート1個で駆動すると遅くなるため、大規模なデコーダではプリデコードを使います。アドレスを 2〜3 ビットずつのグループに分け、各グループを数本のワンホット線にデコードし、各行に置いた小さなゲートで各グループから1本ずつ線を組み合わせます。アドレスデコーダの故障は、マーチテストが検出対象とする故障の一つです。

デコーダと呼ばれるほかの回路

CPU の命令デコーダは、オペコードのフィールドを解釈して制御信号を生成します。高性能な x86 コアは可変長命令をより単純なマイクロオペレーションにデコードし、再デコードを避けるためにそれをキャッシュすることもあります。ビデオデコーダは動画ストリームを伸張する専用のハードウェアブロックで、汎用コア上のソフトウェアで同じアルゴリズムを動かすよりはるかにエネルギー効率よく処理します。これらはバイナリデコーダよりずっと大きな回路ですが、符号化された入力を、それに応じて動作する信号へ変換するという考え方は共通しています。

デコーダの練習問題に挑戦

順序回路の説明として正しいものはどれか。

  1. A出力が、現在の入力と、記憶している内部状態によって決まる
  2. B出力が現在の入力だけで決まる
  3. Cアナログ信号だけを扱う
答えと解説を見る

正解：A. 出力が、現在の入力と、記憶している内部状態によって決まる

順序回路は、フリップフロップなどの記憶素子をもち、出力が現在の入力だけでなく過去の入力の履歴(内部状態)にも依存する回路です。カウンタ、レジスタ、ステートマシンが代表例で、自動販売機の投入金額の管理などをモデル化できます。出力が現在の入力だけで決まる回路は組み合わせ回路(加算器、デコーダなど)で、実際のデジタル回路はこの2つをクロックで交互につないだ構造です。

3ビットの入力に応じて、8本の出力のうち1本だけを有効にする回路はどれか。

  1. Aエンコーダ
  2. Bデコーダ
  3. Cカウンタ
答えと解説を見る

正解：B. デコーダ

デコーダはnビットの入力をもとに、2ⁿ本の出力のうち対応する1本だけを有効にする回路で、3ビットなら8本です。メモリのアドレスからワード線や列を選ぶ回路、CPUの命令のデコード、7セグメント表示の駆動などに使われます。各出力は入力の組み合わせ(最小項)に対応するため、デコーダとORゲートで任意の論理関数を作ることもできます。逆の働きをするのがエンコーダです。

よくある質問

4ビットのデコーダの出力は何本ですか?

4-16 デコーダの出力は 2⁴ = 16 本で、4 ビットの入力コードごとにちょうど1本だけが有効になります。一般に n ビットのデコーダの出力は 2ⁿ 本です。

デコーダとエンコーダの違いは何ですか?

デコーダは n ビットのコードを 2ⁿ 本のうち1本だけ有効な線に変換し、エンコーダは 2ⁿ 本のうち1本だけ有効な線を n ビットのコードに戻します。複数の入力が同時に有効になる場合は、プライオリティエンコーダで対応します。

デマルチプレクサとデコーダは同じものですか?

密接に関係しています。イネーブル入力付きのデコーダは、イネーブルをデータ入力として使うとデマルチプレクサになり、選択ビットでどの出力にデータを送るかを選びます。
