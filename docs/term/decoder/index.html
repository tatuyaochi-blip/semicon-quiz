デコーダとは

でこーだ

nビットの入力に応じて、2ⁿ本の出力のうち1本だけを有効にする回路。メモリのアドレスから読み書きする行を選ぶのに使われる。逆の働きをする回路はエンコーダ。

「デコーダ」は、3分野の4問の練習問題に出てきます(論理回路, 電力管理(ソフトウェア制御), 命令セット・アセンブリなど)。

この用語の分野: 論理回路

デコーダの練習問題に挑戦

スマートフォンのSoCが、動画の再生を汎用のCPUではなく専用の動画デコーダの回路で行う主な理由はどれか。

  1. ACPUでは動画を再生できないから
  2. B専用の回路は、画質を自動で上げるから
  3. C特定の処理に特化した回路は、同じ処理をCPUで行うよりずっと少ないエネルギーで済み、電池が長くもつから
答えと解説を見る

正解：C. 特定の処理に特化した回路は、同じ処理をCPUで行うよりずっと少ないエネルギーで済み、電池が長くもつから

汎用のCPUは、どんな処理にも対応するため、命令の取り出しや解読、レジスタの読み書きなど、計算そのもの以外に多くのエネルギーを使います。動画のデコーダのような専用の回路は、決まった処理の流れを直接回路にしているので、同じ処理を何分の一から何十分の一のエネルギーで行えます。SoCには、動画、画像、音声、AIなどの専用の回路が多く載っています。

解説の中の「デコーダ」

  • 動画のデコーダのような専用の回路は、決まった処理の流れを直接回路にしているので、同じ処理を何分の一から何十分の一のエネルギーで行えます。

    スマートフォンのSoCが、動画の再生を汎用のCPUではなく専用の動画デコーダの回路で行う主な理由はどれか。

  • 出力が現在の入力だけで決まる回路は組み合わせ回路(加算器、デコーダなど)で、実際のデジタル回路はこの2つをクロックで交互につないだ構造です。

    順序回路の説明として正しいものはどれか。

  • デコーダはnビットの入力をもとに、2ⁿ本の出力のうち対応する1本だけを有効にする回路で、3ビットなら8本です。

    3ビットの入力に応じて、8本の出力のうち1本だけを有効にする回路はどれか。

  • x86のCPUは、可変長で複雑な命令を前段のデコーダでマイクロオペレーション(μop)と呼ぶ単純な操作に分け、後段ではそれらをアウトオブオーダーで実行します。

    現在の高性能なx86のCPUが、複雑な命令を内部でどのように実行しているかの説明として正しいものはどれか。

「デコーダ」が出てくる問題(4問)

  1. スマートフォンのSoCが、動画の再生を汎用のCPUではなく専用の動画デコーダの回路で行う主な理由はどれか。
  2. 順序回路の説明として正しいものはどれか。
  3. 3ビットの入力に応じて、8本の出力のうち1本だけを有効にする回路はどれか。
  4. 現在の高性能なx86のCPUが、複雑な命令を内部でどのように実行しているかの説明として正しいものはどれか。
