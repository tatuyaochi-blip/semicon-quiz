ASIL(自動車安全度水準)とは

えーしる

ISO 26262で、危険な事象ごとに重大度S・露出度E・制御可能性Cの3つから決める安全要求の水準。A〜Dの4段階でDが最も厳しく、リスクが低く割り当ての必要がないものはQMとされる。

「ASIL(自動車安全度水準)」は、1分野の10問の練習問題に出てきます(車載半導体と機能安全など)。

この用語の分野: 車載半導体と機能安全

ASILの決め方

ハザード分析・リスクアセスメント(HARA)では、危険事象ごとに、けがの重大度(S1〜S3)、その事象が起こりうる運転状況への露出度(E1〜E4)、ドライバーなどによる制御可能性(C1〜C3)を評価します。ISO 26262の表がその組み合わせをASIL A、B、C、Dのいずれか、またはASILが不要な場合のQM(品質管理)に対応づけます。便利な目安は、S・E・Cの数字の合計が10ならD、9ならC、8ならB、7ならAというものです。DになるのはS3/E4/C3の組み合わせだけで、どれか1つの要素が1段下がるとASILも1段下がります。

ASILによって変わること

ASILは安全目標に付けられ、そこから導かれる要求、さらにそれを実装するハードウェアとソフトウェアへ引き継がれます。ASILが高いほど、より厳格な開発・検証と、より厳しいハードウェアメトリックが求められます。シングルポイント故障メトリック(SPFM)の目標値の目安はBで90%、Cで97%、Dで99%、潜在故障メトリック(LFM)は同じく60%、80%、90%です。ランダムハードウェア故障確率メトリック(PMHF)の目標は、BとCで100 FIT未満、Dで10 FIT未満(10⁻⁸ /h)です。QMであっても通常の品質活動は必要です。

メトリックの計算例

SPFMは、安全に関わる故障率のうちシングルポイント故障と残余故障が占める割合を、1から引いた値です。これらは単独で安全目標を侵害する故障や、安全機構に検出されずにすり抜ける故障を指します。あるブロックの安全関連の故障率が1000 FITで、そのうち5 FITがシングルポイント故障または残余故障なら、SPFM = 1 − 5/1000 = 99.5%となり、ASIL Dの目標を満たします。SPFMを改善するには、メモリのECC、ロックステップコア、監視回路など、診断カバレッジの高い安全機構を追加し、検出されない故障を減らします。

デコンポジションと混在クリティカリティ設計

要求は十分に独立した冗長要素に分割でき、元のレベルを括弧書きで示します。ASIL DならB(D) + B(D)、C(D) + A(D)、D(D) + QM(D)などに分けられます。従属故障分析によって2つの要素が共通原因で同時に故障しないことを示す必要があり、ランダムハードウェアのメトリックは引き続き元のASILに従います。異なるASILのソフトウェアが1つのSoCを共有する場合は、メモリ保護ユニットやハイパーバイザによる空間的分離と、実行時間監視による時間的分離で、相互に干渉しないこと(freedom from interference)を示さなければなりません。示せなければ、すべてを最も高いASILで開発する必要があります。

ASIL(自動車安全度水準)の練習問題に挑戦

ISO 26262で、ハザード分析とリスクアセスメント(HARA)によりASILを決めるときに評価する3つの要素の組み合わせとして正しいものはどれか。

  1. A重大度(S)・露出度(E)・制御可能性(C)
  2. B故障率(λ)・診断カバレッジ(DC)・フォールトトレラント時間間隔(FTTI)
  3. C部品の価格・生産台数・開発期間
答えと解説を見る

正解：A. 重大度(S)・露出度(E)・制御可能性(C)

ASILは、危険な事象ごとに、けがの重さを表す重大度S、その危険が起こりうる運転状況にさらされる頻度や時間を表す露出度E、運転者などが危険を回避できる可能性を表す制御可能性Cの3つを評価して決めます。例えば高速走行中に急にブレーキが効かなくなる事象は、重大度が高く回避も難しいので高いASILになります。故障率や診断カバレッジ、FTTIは、ASILが決まった後に、その要求を満たす設計を評価するときに使う量です。

ISO 26262のASILについての説明として正しいものはどれか。

  1. AAからDまであり、ASIL Aが最も厳しい要求を表す。QMはASIL Dよりもさらに厳しい要求を表す
  2. BAからDまであり、ASIL Dが最も厳しい要求を表す。リスクが十分に低い場合はQMとされ、通常の品質管理で対応する
  3. CAからDまであり、ASIL Dは最も故障率の高い部品を表す。QMは品質に問題がないので、試験をすべて省略してよい部品を表す
答えと解説を見る

正解：B. AからDまであり、ASIL Dが最も厳しい要求を表す。リスクが十分に低い場合はQMとされ、通常の品質管理で対応する

ASIL(Automotive Safety Integrity Level)はA・B・C・Dの4段階で、Dが最も厳しく、開発の手順や安全機構、故障率の目標などに高い要求が課されます。例えばエアバッグやブレーキ、ステアリングの制御の一部は、ASIL Dが求められることが多い代表例です。リスクが低く、ASILを割り当てる必要がない場合はQM(Quality Management)とされ、通常の品質管理のもとで開発します。QMでも品質の確保は必要で、試験を省いてよいわけではありません。

よくある質問

ASILで最も厳しいのはどのレベルですか?

ASIL Dが最も高く、ASIL Aが最も低いレベルです。QMはリスクが十分に低く、通常の品質管理で足りることを意味します。ブレーキ、ステアリング、エアバッグの制御の一部がASIL Dの典型例です。

ASIL B(D)とはどういう意味ですか?

元はASIL Dだった要求を2つの独立した冗長要素に分割した結果、ASIL Bで開発する要求であることを示す表記です。ハードウェアメトリックの目標値など一部の義務は引き続きASIL Dに従うため、括弧で元のレベルを残しています。

ASILとSILは同じものですか?

いいえ。SIL 1〜4は汎用規格IEC 61508で定められたもので、ASIL A〜DはISO 26262が道路車両向けに、重大度・露出度・制御可能性を使って定義したものです。考え方は似ていますが、正式に置き換えられるものではありません。

「ASIL(自動車安全度水準)」が出てくる問題(10問)

  1. ISO 26262で、ハザード分析とリスクアセスメント(HARA)によりASILを決めるときに評価する3つの要素の組み合わせとして正しいものはどれか。
  2. ISO 26262のASILについての説明として正しいものはどれか。
  3. ある危険な事象を評価したところ、重大度S3・露出度E4・制御可能性C3で、ASIL Dとなった。同じ事象で、制御可能性だけがC2(通常は多くの運転者が回避できる)であったとすると、ASILはどうなるか。
  4. ランダムハードウェア故障によって安全目標が侵害される確率の指標PMHFについて、ASIL Dの目標値の目安は10 FIT未満とされる。これを1時間あたりの確率で表すとどれか。
  5. 単一点故障指標(SPFM)について、ASIL Dで求められる目標値の目安として正しいものはどれか。
  6. ISO 26262のASILデコンポジション(分解)で、ASIL Dの安全要求を、十分に独立した2つの冗長な要素に分けて割り当てる組み合わせとして認められているものはどれか。
  7. 複数のECUの機能を1つの高性能なSoCに統合し、異なるASILのソフトウェアを一緒に動かすときに求められることとして正しいものはどれか。
  8. ISO 26262における「安全目標」の説明として正しいものはどれか。
  9. ISO 26262で区別されるランダムハードウェア故障とシステマティック故障の説明の組み合わせとして正しいものはどれか。
  10. 安全に関係するハードウェアの故障率の合計が1000 FITで、そのうち単一点故障と残余故障(安全機構で検出されずに残る故障)の故障率の合計が5 FITのとき、単一点故障指標(SPFM)はいくらか。
