CUDAとは

くーだ

NVIDIAのGPUで汎用の計算を行うためのプログラミングの仕組み。C++を拡張した言語でカーネルを書き、グリッド・ブロック・スレッドの階層で並列性を表す。

「CUDA」は、1分野の18問の練習問題に出てきます(GPUプログラミングなど)。

この用語の分野: GPUプログラミング

CUDAの練習問題に挑戦

CUDAなどのGPUプログラミングでいう「カーネル」の説明として正しいものはどれか。

  1. AGPUのOSの中心となる部分
  2. BGPUの上で、多数のスレッドが同時に実行する関数
  3. CGPUのチップを冷やす部品
答えと解説を見る

正解：B. GPUの上で、多数のスレッドが同時に実行する関数

GPUプログラミングのカーネルは、CPU側のプログラムから起動され、GPUの上で多数のスレッドが同じコードを実行する関数です。各スレッドは自分の番号を使って、担当するデータの要素を選びます。例えば配列の足し算なら、1つのスレッドが1つの要素を足すようにカーネルを書き、要素の数だけスレッドを起動します。OSのカーネルとは同じ言葉ですが意味が違います。

CUDAのスレッドの階層の組み合わせとして正しいものはどれか(大きい順)。

  1. Aグリッド → ブロック → スレッド
  2. Bスレッド → ブロック → グリッド
  3. Cブロック → スレッド → グリッド
答えと解説を見る

正解：A. グリッド → ブロック → スレッド

カーネルを1回起動すると、全体がグリッドになり、グリッドは多数のブロックに、ブロックは多数のスレッドに分かれます。1つのブロックのスレッドは同じSM(演算器の集まり)で実行され、共有メモリで協力したり、同期を取ったりできます。異なるブロックは独立に実行されるので、GPUの規模に応じて同時に動くブロックの数が変わり、同じプログラムが大小のGPUで動きます。

解説の中の「CUDA」

  • CUDAには占有率を計算する道具も用意されています。

    GPUの占有率(オキュパンシー)の説明として正しいものはどれか。

  • 起動の並びをまとめて記録して一度に送る仕組み(CUDA Graphsなど)も使われます。

    非常に小さなカーネルを何千回も続けて起動するプログラムが遅いとき、改善の方法として最も適切なものはどれか。

  • CUDAはNVIDIAのGPU向けの仕組みですが、OpenCLは業界団体が定めた標準の規格で、複数の会社のGPUやCPU、FPGAなどで使えます。

    NVIDIA以外のGPUでも使える、GPUなどの並列計算のためのプログラミングの仕組みの例として正しいものはどれか。

「CUDA」が出てくる問題(18問)

  1. CUDAなどのGPUプログラミングでいう「カーネル」の説明として正しいものはどれか。
  2. CUDAのスレッドの階層の組み合わせとして正しいものはどれか(大きい順)。
  3. CUDAのカーネルで上の式により各スレッドの番号iを求める。blockIdx.x=2、blockDim.x=256、threadIdx.x=5のスレッドのiはいくらか。
  4. 上のCUDAのカーネルで「if (i < n)」を入れている理由として正しいものはどれか。
  5. CUDAの共有メモリ(シェアードメモリ)の特徴として正しいものはどれか。
  6. CUDAの__syncthreads()の働きとして正しいものはどれか。
  7. CUDAで、__syncthreads()を「if (threadIdx.x < 16)」の中に書き、一部のスレッドだけが通るようにした。起こりうることとして正しいものはどれか。
  8. CUDAの共有メモリのバンク競合の説明として正しいものはどれか。
  9. CUDAで、ブロックとSM(ストリーミングマルチプロセッサ)の関係として正しいものはどれか。
  10. CUDAで、カーネルの途中で、ほかのすべてのブロックの計算が終わるのを待ってから次の段階に進みたい。一般的な方法はどれか。
  11. CUDAのストリームを複数使う主な目的はどれか。
  12. CUDAのユニファイドメモリ(統合メモリ)の説明として正しいものはどれか。
  13. CUDAで1ブロックあたりのスレッドの数を決めるときの一般的な目安として正しいものはどれか。
  14. CUDAの定数メモリ(コンスタントメモリ)が特に速く働くのはどのようなアクセスのときか。
  15. CUDAで、CPU側のプログラムがカーネルを起動した直後の動作として一般に正しいものはどれか。
