CUDAとは

くーだ

NVIDIAのGPUで汎用の計算を行うためのプログラミングの仕組み。C++を拡張した言語でカーネルを書き、グリッド・ブロック・スレッドの階層で並列性を表す。

「CUDA」は、1分野の18問の練習問題に出てきます(GPUプログラミングなど)。

この用語の分野: GPUプログラミング

カーネルとスレッドの階層

CUDAでは、CPU(ホスト)がカーネルを起動します。カーネルは多数のGPUスレッドが同時に実行する関数です。1回の起動でブロックの集まりであるグリッドが作られ、各ブロックには多数のスレッドが含まれます。各スレッドは固有のグローバルインデックスを計算して担当するデータ要素を決めます。典型的にはi = blockIdx.x × blockDim.x + threadIdx.xで、1ブロック256スレッドのとき、ブロック2のスレッド5は要素517を担当します。スレッドはブロック単位でまとめて起動されるため、最後のブロックには通常余分なスレッドがあり、配列の範囲外に書き込まないよう、カーネルではif (i < n)でメモリアクセスを保護します。

ブロックとGPUハードウェアの対応

各ブロックは1つのストリーミングマルチプロセッサ(SM)に割り当てられ、そこで最後まで実行されます。1つのSMは複数のブロックを同時に保持できます。SMの内部では、スレッドは32本ずつのワープ単位で実行されます。SMが保持できる最大ワープ数に対する常駐ワープ数の比率をオキュパンシといい、スレッドあたりのレジスタ数、ブロックあたりの共有メモリ量、ブロックサイズで制限されます。オキュパンシが低いと、メモリの遅延を隠すのに十分なワープがありません。ブロックは独立に任意の順序で実行されるため、カーネル内で他の全ブロックを待つとデッドロックするおそれがあり、全体の同期は通常、処理を2回のカーネル起動に分けて実現します。

メモリ空間の種類

グローバルメモリはGPUのDRAMで、帯域は広いものの遅延が大きく、隣り合うスレッドが隣り合うアドレスにアクセスするときに最も速くなります。共有メモリはブロックごとの小さなオンチップメモリで、プログラムが明示的に管理します。共有メモリは32個のバンクに分かれており、1つのワープのスレッドが同じバンクの異なるアドレスにアクセスすると、アクセスが直列化されます。__syncthreads()はブロック内の全スレッドがそろうまで待たせる関数で、一部のスレッドが通らない分岐の中に置くと、ハングや未定義の結果を招きます。ユニファイドメモリを使うと、ホストとデバイスが1つのポインタを共有でき、ページは必要に応じて移動されます。

GPUを遊ばせない工夫

ホストからデバイスへのコピーはPCI Expressを通るため、しばしばボトルネックになります。転送とカーネルを順序付きで並べたキューであるストリームを使うと、異なるストリームの処理を重ねられるので、現在のデータを計算しながら次のデータをコピーできます。また、カーネルの起動には1回あたり数マイクロ秒かかるため、小さなカーネルを何千回も起動するプログラムでは、カーネルを融合すると効果があり、中間結果をメモリに書き出す手間も省けます。記録した一連の起動をCUDA Graphsでまとめて投入する方法もあります。CUDA自体はNVIDIAのGPUでしか動きませんが、OpenCLのようなベンダ共通の代替技術も、似たカーネルとワークグループのモデルを採用しています。

CUDAの練習問題に挑戦

CUDAなどのGPUプログラミングでいう「カーネル」の説明として正しいものはどれか。

  1. AGPUのOSの中心となる部分
  2. BGPUの上で、多数のスレッドが同時に実行する関数
  3. CGPUのチップを冷やす部品
答えと解説を見る

正解：B. GPUの上で、多数のスレッドが同時に実行する関数

GPUプログラミングのカーネルは、CPU側のプログラムから起動され、GPUの上で多数のスレッドが同じコードを実行する関数です。各スレッドは自分の番号を使って、担当するデータの要素を選びます。例えば配列の足し算なら、1つのスレッドが1つの要素を足すようにカーネルを書き、要素の数だけスレッドを起動します。OSのカーネルとは同じ言葉ですが意味が違います。

CUDAのスレッドの階層の組み合わせとして正しいものはどれか(大きい順)。

  1. Aグリッド → ブロック → スレッド
  2. Bスレッド → ブロック → グリッド
  3. Cブロック → スレッド → グリッド
答えと解説を見る

正解：A. グリッド → ブロック → スレッド

カーネルを1回起動すると、全体がグリッドになり、グリッドは多数のブロックに、ブロックは多数のスレッドに分かれます。1つのブロックのスレッドは同じSM(演算器の集まり)で実行され、共有メモリで協力したり、同期を取ったりできます。異なるブロックは独立に実行されるので、GPUの規模に応じて同時に動くブロックの数が変わり、同じプログラムが大小のGPUで動きます。

よくある質問

CUDAのブロックとワープの違いは?

ブロックはプログラマが決めるスレッドのまとまりで、1つのSM上で実行され、メモリを共有したり同期したりできます。ワープはブロック内でハードウェアがまとめる32スレッドの組で、命令をそろって一斉に実行します。

CUDAでグローバルなスレッドインデックスはどう計算しますか?

1次元の起動なら、i = blockIdx.x * blockDim.x + threadIdx.xで求めます。最後のブロックには残りの要素数より多くのスレッドが含まれることが多いので、配列にアクセスする前にi < nを確認します。

CUDAの共有メモリは何に使いますか?

1つのブロックのスレッドが共有する高速なオンチップメモリで、グローバルメモリのデータを置いて再利用したり、中間結果をやり取りしたりするのに使います。キャッシュと違って何を置くかはプログラムが決め、アクセスの順序は__syncthreads()で保証します。

  • CUDAには占有率を計算する道具も用意されています。

    GPUの占有率(オキュパンシー)の説明として正しいものはどれか。

    NVIDIA以外のGPUでも使える、GPUなどの並列計算のためのプログラミングの仕組みの例として正しいものはどれか。

  1. CUDAなどのGPUプログラミングでいう「カーネル」の説明として正しいものはどれか。
  2. CUDAのスレッドの階層の組み合わせとして正しいものはどれか(大きい順)。
  3. CUDAのカーネルで上の式により各スレッドの番号iを求める。blockIdx.x=2、blockDim.x=256、threadIdx.x=5のスレッドのiはいくらか。
  4. 上のCUDAのカーネルで「if (i < n)」を入れている理由として正しいものはどれか。
  5. CUDAの共有メモリ(シェアードメモリ)の特徴として正しいものはどれか。
  6. CUDAの__syncthreads()の働きとして正しいものはどれか。
  7. CUDAで、__syncthreads()を「if (threadIdx.x < 16)」の中に書き、一部のスレッドだけが通るようにした。起こりうることとして正しいものはどれか。
  8. CUDAの共有メモリのバンク競合の説明として正しいものはどれか。
  9. CUDAで、ブロックとSM(ストリーミングマルチプロセッサ)の関係として正しいものはどれか。
  10. CUDAで、カーネルの途中で、ほかのすべてのブロックの計算が終わるのを待ってから次の段階に進みたい。一般的な方法はどれか。
  11. CUDAのストリームを複数使う主な目的はどれか。
  12. CUDAのユニファイドメモリ(統合メモリ)の説明として正しいものはどれか。
  13. CUDAで1ブロックあたりのスレッドの数を決めるときの一般的な目安として正しいものはどれか。
  14. CUDAの定数メモリ(コンスタントメモリ)が特に速く働くのはどのようなアクセスのときか。
