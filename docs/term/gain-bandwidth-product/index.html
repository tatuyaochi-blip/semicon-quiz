利得帯域幅積(GBW)とは

りとくたいいきはばせき

オペアンプの利得と帯域幅の積で、ほぼ一定になる値。例えばGBWが1 MHzなら、利得10倍の回路の帯域は約100 kHzになる。

「利得帯域幅積(GBW)」は、1分野の2問の練習問題に出てきます(アナログ・電子回路など)。

この用語の分野: アナログ・電子回路

利得帯域幅積(GBW)の練習問題に挑戦

利得帯域幅積(GBW)が1 MHzのオペアンプで、利得10倍の非反転増幅回路をつくったときの帯域幅はおよそいくらか。

  1. A約10 MHz
  2. B約10 kHz
  3. C約100 kHz
答えと解説を見る

正解：C. 約100 kHz

内部で位相補償されたオペアンプは、開ループ利得が −20 dB/dec で下がるため、利得と帯域幅の積がほぼ一定です。GBWが1 MHzなら、利得10倍の帯域は 1 MHz ÷ 10 = 約100 kHz です。正確には非反転利得(ノイズゲイン)で割るため、反転増幅回路の−10倍は ÷11 で約91 kHz になります。高利得と広帯域を両立したいときは、GBWの大きいオペアンプを選ぶか、増幅を複数段に分けます。

解説の中の「利得帯域幅積(GBW)」

  • GBWが1 MHzなら、利得10倍の帯域は 1 MHz ÷ 10 = 約100 kHz です。

    利得帯域幅積(GBW)が1 MHzのオペアンプで、利得10倍の非反転増幅回路をつくったときの帯域幅はおよそいくらか。

  • 小信号の帯域(GBW)とは別に、大振幅の帯域を制限する要因です。

    オペアンプのスルーレートの意味として正しいものはどれか。

「利得帯域幅積(GBW)」が出てくる問題(2問)

  2. オペアンプのスルーレートの意味として正しいものはどれか。
