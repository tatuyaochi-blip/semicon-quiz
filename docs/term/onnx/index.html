ONNXとは

おにきす

異なるフレームワークや推論ランタイムの間でモデルをやり取りするための共通のモデルの形式。Open Neural Network Exchangeの略。

この用語の分野: AIハードウェアとソフトウェアスタック

解説の中の「ONNX」

  • ONNX(Open Neural Network Exchange)は、モデルの計算グラフと重みを共通の形式で表すための規格です。
