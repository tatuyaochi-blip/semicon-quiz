スピルとは

すぴる

レジスタ割り当てで、同時に使う値がレジスタの数より多いとき、一部の値をメモリ(スタック)に退避させること。退避と読み戻しの命令が増えて遅くなる。

「スピル」は、2分野の4問の練習問題に出てきます(コンパイラ, GPUプログラミングなど)。

この用語の分野: コンパイラ

スピルの練習問題に挑戦

レジスタ割り当てで「スピル」が起こると、生成されるコードはどうなるか。

  1. A値をスタックに退避・読み戻す命令が増え、遅くなりやすい
  2. Bレジスタの数が自動的に増え、すべての値をレジスタに置けるようになる
  3. C使われない値が削除されて、命令の数が少なくなる
答えと解説を見る

正解：A. 値をスタックに退避・読み戻す命令が増え、遅くなりやすい

スピルは、同時に生きている値がレジスタの数より多いときに、一部の値をメモリ(スタック)に置くことです。その値を使うたびに読み込み命令、書き換えるたびに書き込み命令が必要になり、命令が増えてメモリアクセスの分だけ遅くなりやすくなります。そのためコンパイラは、ループの中などよく使われる値をレジスタに残し、あまり使わない値を選んでスピルさせます。レジスタの数はCPUで決まっていて増えず、不要な値の削除とも別の話です。

ある関数の中で、同時に生きている値の数が最も多いところで5個だった。干渉グラフがこの5個以外の制約を生まない単純な場合、すべての値をスピルなしでレジスタに置くには、レジスタが少なくとも何個必要か。

  1. A5個
  2. B4個
  3. C10個
答えと解説を見る

正解：A. 5個

同時に生きている5個の値は、互いにすべて干渉するので、干渉グラフの中で5個の節がすべて辺でつながった形(完全グラフ)になり、塗り分けには少なくとも5色が必要です。直線的なコードのように生存区間が区間として表せる単純な場合は、同時に生きている値の最大数の色で塗り分けられるので、5個のレジスタで足ります。4個では、どこかで1つの値をメモリに退避するスピルが必要になります。10個は必要以上に多い数です。

解説の中の「スピル」

  • スピルは、同時に生きている値がレジスタの数より多いときに、一部の値をメモリ(スタック)に置くことです。

    レジスタ割り当てで「スピル」が起こると、生成されるコードはどうなるか。

  • 4個では、どこかで1つの値をメモリに退避するスピルが必要になります。

    ある関数の中で、同時に生きている値の数が最も多いところで5個だった。干渉グラフがこの5個以外の制約を生まない単純な場合…

  • 塗り分けられない場合は、一部の値をメモリに退避(スピル)します。

    コンパイラのレジスタ割り当てで、干渉グラフを塗り分ける(彩色する)方法を使うとき、グラフの節と辺が表すものの組み合わせ…

  • 足りない分はメモリに追い出され(スピル)、遅くなることもあります。

    GPUのカーネルで、1スレッドあたりのレジスタの使用量が多すぎると起こりうることとして正しいものはどれか。

「スピル」が出てくる問題(4問)

  1. レジスタ割り当てで「スピル」が起こると、生成されるコードはどうなるか。
  2. ある関数の中で、同時に生きている値の数が最も多いところで5個だった。干渉グラフがこの5個以外の制約を生まない単純な場合、すべての値をスピルなしでレジスタに置くには、レジスタが少なくとも何個必要か。
  3. コンパイラのレジスタ割り当てで、干渉グラフを塗り分ける(彩色する)方法を使うとき、グラフの節と辺が表すものの組み合わせとして正しいものはどれか。
  4. GPUのカーネルで、1スレッドあたりのレジスタの使用量が多すぎると起こりうることとして正しいものはどれか。
