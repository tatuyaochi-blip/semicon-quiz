ダマシン法とは

だましんほう

絶縁膜に溝を掘って金属を埋め込み、余分な金属をCMPで除去して配線を形成する方法。Cu配線に用いる。

この用語の分野: 配線プロセス

解説の中の「ダマシン法」

  • ダマシン法では、まず絶縁膜に配線の形の溝を掘り、バリア層とシード層を成膜したあと、めっきでCuを埋め込みます。

    Cu配線の形成に一般的に用いられるダマシン法の説明として正しいものはどれか。

  • ダマシン法では、溝にバリア層とCuのシード層をスパッタリングで薄くつけたあと、電解めっきでCuを埋め込みます。

    Cu配線の溝を埋め込むために主に用いられる成膜方法はどれか。

  • そのため、Cu配線はエッチングを使わずに、溝に埋め込んでCMPで削るダマシン法でつくられます。

    Cu配線をドライエッチングで直接加工するのが難しい理由として正しいものはどれか。

「ダマシン法」が出てくる問題(5問)

  1. Cu配線の形成に一般的に用いられるダマシン法の説明として正しいものはどれか。
  2. Cu配線の溝を埋め込むために主に用いられる成膜方法はどれか。
  3. Cu配線をドライエッチングで直接加工するのが難しい理由として正しいものはどれか。
  4. 先端LSIの配線材料が、アルミニウム(Al)から銅(Cu)に置き換えられた主な理由はどれか。
  5. 配線の溝とビアを同時にCuで埋め込み、1回のCMPで形成する方法を何と呼ぶか。
