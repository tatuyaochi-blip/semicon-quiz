エミッタフォロワとは

えみったふぉろわ

コレクタ接地の増幅回路。電圧利得はほぼ1だが、入力インピーダンスが高く出力インピーダンスが低いため、信号を弱らせずに次の段を駆動するバッファとして使われる。

この用語の分野: バイポーラトランジスタ

解説の中の「エミッタフォロワ」

  • エミッタフォロワでは、エミッタ電圧がベース電圧よりVBE(約0.7 V)だけ低い値で追従するため、電圧利得はほぼ1で同相です。

    コレクタ接地増幅回路(エミッタフォロワ)の特徴として正しいものはどれか。

  • さらに入力抵抗を上げたいときは、エミッタフォロワやダーリントン、エミッタ抵抗による帰還を使います。

    エミッタ接地増幅回路の小信号の入力抵抗(hie)を大きくする条件として正しいものはどれか。

  • エミッタフォロワに相当しますが、レベルのずれ(VGS)はVBEより大きく、ばらつきもあります。

    MOSFETのソースフォロワ(ドレイン接地)回路の特徴として正しいものはどれか。

「エミッタフォロワ」が出てくる問題(3問)

  1. コレクタ接地増幅回路(エミッタフォロワ)の特徴として正しいものはどれか。
  2. エミッタ接地増幅回路の小信号の入力抵抗(hie)を大きくする条件として正しいものはどれか。
  3. MOSFETのソースフォロワ(ドレイン接地)回路の特徴として正しいものはどれか。
