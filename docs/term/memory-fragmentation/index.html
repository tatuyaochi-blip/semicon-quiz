断片化とは

だんぺんか

確保と解放を繰り返すうちに空きメモリが細かく分かれ、合計は十分でも大きな領域をまとめて確保できなくなる現象。フラグメンテーションとも呼ぶ。

「断片化」は、2分野の2問の練習問題に出てきます(リンカ・ローダと実行形式, メモリ階層と性能など)。

この用語の分野: リンカ・ローダと実行形式

断片化の練習問題に挑戦

mallocとfreeを繰り返すうちに、空きメモリの合計は十分あるのに、大きな領域をまとめて確保できなくなることがある。この現象を何と呼ぶか。

  1. Aメモリリーク
  2. B断片化(フラグメンテーション)
  3. Cスタックオーバーフロー
答えと解説を見る

正解：B. 断片化(フラグメンテーション)

大きさの違う領域の確保と解放を繰り返すと、使用中の領域の間に小さな空きが散らばります。空きの合計は大きくても、つながった大きな空きがないと大きな確保に失敗します。これを断片化と呼びます。メモリの割り当て器は、大きさごとに分けて管理したり、隣り合う空きをまとめたりして断片化を減らします。長く動き続ける組込み機器では特に注意が必要です。

大きなページ(ヒュージページ)を使う主な利点と欠点の組み合わせとして正しいものはどれか。

  1. A利点はキャッシュのミス率が下がること、欠点はTLBミスが増えること
  2. B利点はページフォルトがなくなること、欠点はディスクの容量を多く使うこと
  3. C利点はTLBミスが減ること、欠点は内部断片化が増えやすいこと
答えと解説を見る

正解：C. 利点はTLBミスが減ること、欠点は内部断片化が増えやすいこと

ページを大きくすると、1つのTLBエントリで広い範囲を変換できるため、大きなデータを扱うプログラムでTLBミスが大きく減ります。一方、少しのデータでも大きなページ単位で割り当てるので、使わない領域(内部断片化)が増え、メモリの割り当ても柔軟でなくなります。TLBミスはむしろ減り、キャッシュのミス率はページの大きさに直接は左右されません。ページフォルトがなくなるわけでもありません。

解説の中の「断片化」

  • これを断片化と呼びます。

    mallocとfreeを繰り返すうちに、空きメモリの合計は十分あるのに、大きな領域をまとめて確保できなくなることがある…

  • 一方、少しのデータでも大きなページ単位で割り当てるので、使わない領域(内部断片化)が増え、メモリの割り当ても柔軟でなくなります。
