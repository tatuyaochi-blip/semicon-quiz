定数畳み込みとは

ていすうたたみこみ

コンパイルの時点で値が決まる式を、あらかじめ計算して結果の定数に置き換える最適化。例えば 3 * 4 を 12 にする。実行時の計算を減らせる。

やさしい解説で読む: コンパイラとは? プログラムが機械語になるまで

「定数畳み込み」は、1分野の6問の練習問題に出てきます(コンパイラなど)。

この用語の分野: コンパイラ

コンパイラが実際に行うこと

最適化の段階で、コンパイラは中間表現を調べて、オペランドがすべて定数である演算を探し、それを評価して結果のリテラルに置き換えます。算術演算、ビット演算、シフト、型変換、比較はどれも畳み込みの対象です。特に比較の畳み込みは効果が大きく、10 > 100 のような条件が偽と確定すれば、その条件で守られた分岐は決して実行されないことがわかります。コンパイラは通常、x * 1 や x + 0 を x に書き換える代数的簡約もあわせて行いますが、x 自体は定数ではないので、厳密には別の変換です。

定数伝播・インライン展開・デッドコード削除との連携

定数畳み込みが単独で働くことはまれです。定数伝播は、定数を持つとわかっている変数の使用箇所をその定数に置き換え、新たな畳み込みの機会を生みます。畳み込んだ結果はさらに伝播できます。たとえば n = 8; m = n * 2; return m + 1 は return 17 にまとまり、その後デッドコード削除で使われない代入が消えます。インライン展開もこの連鎖を後押しし、sq(6) の呼び出しを本体に置き換えれば 6 * 6 + 1 が 37 に畳み込まれます。SSA形式のコンパイラでは、伝播、畳み込み、到達不能な分岐の削除を、疎条件付き定数伝播(SCCP)という1つのアルゴリズムでまとめて行うことがよくあります。

プログラムの意味を保つ

畳み込んだ結果は、ターゲットマシンが実行時に計算したはずの値と完全に一致しなければなりません。そのためコンパイラはターゲットの整数幅やラップアラウンドを再現する必要があり、64ビットのホストから32ビットのターゲット向けにクロスコンパイルするときに問題になります。浮動小数点の畳み込みでは、ソースの順序どおりに各演算のIEEE 754の丸めを再現する必要があります。fast-mathのようなオプションで許可されない限り、コンパイラが浮動小数点式の結合順序を変えないのはこのためです。整数のゼロ除算のように例外を起こす演算は、そのコードが確実に実行される場合を除き、コンパイルエラーにしてはいけません。

言語仕様で求められる定数式との違い

コンパイル時の評価には、オプティマイザが選ぶものではなく、言語仕様で必須とされるものもあります。C言語では配列のサイズ、caseラベル、static変数の初期化子は定数式でなければならず、C++のconstexpr関数は要求すればコンパイル時に評価できます。最適化としての定数畳み込みはより広く、かつ任意です。伝播やインライン展開の後に初めて定数になった値も含めてプログラムのどこにでも適用でき、フロントエンドから中間表現、さらに命令選択まで、複数の段階で行われます。命令選択では、アドレスオフセットと定数を1つの即値にまとめることもあります。

定数畳み込みの練習問題に挑戦

コンパイラの定数畳み込みの例として正しいものはどれか。

  1. A同じ関数を何度も呼ぶ部分を、1回の呼び出しにまとめる
  2. Bx = 3 * 4 を、コンパイル時に計算して x = 12 にする
  3. Cループの本体を4回分並べ、繰り返しの回数を減らす
答えと解説を見る

正解：B. x = 3 * 4 を、コンパイル時に計算して x = 12 にする

定数畳み込みは、コンパイルの時点で値が決まる式を前もって計算し、結果の定数に置き換える最適化です。3 * 4 は実行するたびに同じ12になるので、実行時に掛け算をする必要はありません。定数伝播と組み合わせると、変数を通した計算もまとめて畳み込めます。浮動小数点では丸めの方法をそろえる必要があるなど注意点もあります。ループの本体を並べるのはループ展開で、関数呼び出しをまとめるのは別の最適化です。

よくある質問

定数畳み込みと定数伝播の違いは何ですか?

定数畳み込みは、3 * 4 を 12 にするように、オペランドがすべて定数の式を評価します。定数伝播は、変数の既知の定数値を使用箇所に代入するもので、その結果新たに畳み込める式が生まれることがよくあります。

最適化を無効にしても定数畳み込みは行われますか?

単純なリテラルの式は、フロントエンドが構文解析の際に評価するため、最適化なしでも畳み込まれることがよくあります。変数を通した畳み込みや、関数のインライン展開、分岐の削除には、一般に最適化を有効にする必要があります。

定数畳み込みで浮動小数点の計算結果が変わることはありますか?

規格に準拠したコンパイラは、ハードウェアと同じIEEE 754の丸めで浮動小数点演算を畳み込むので、結果は変わりません。fast-mathのように浮動小数点の規則を緩めるオプションでは、結合順序の変更が許され、結果の下位ビットが変わることがあります。
