IRドロップとは

あいあーるどろっぷ

電源配線の抵抗(R)に電流(I)が流れることで、回路に届く電源電圧が下がる現象。回路の遅延の増加や誤動作の原因になる。

この用語の分野: 配線プロセス

解説の中の「IRドロップ」

  • これがIRドロップで、例えば0.7 Vの電源で5%(35 mV)下がるだけでも回路の速度が数%落ち、タイミング違反や誤動作の原因になります。

    電源配線の抵抗に電流が流れることで、回路に届く電源電圧が下がる現象を何と呼ぶか。

  • 高性能なチップは100 Aを超える電流を消費することもあり、電流が急に変化すると、電源の経路の抵抗による電圧降下(IRドロップ)とインダクタンスによる電圧の揺れが起こります。

    多ピンのBGAパッケージで、ボールの多くを電源とグラウンドに割り当てる主な理由はどれか。

  • サインオフでは、タイミング、DRC・LVSに加えて、電源配線の電圧降下(IRドロップ)や、配線の電流密度によるエレクトロマイグレーションの解析を行います。

    テープアウト前の最終確認(サインオフ)で、タイミングの検証と並んで行う電源配線の解析はどれか。

「IRドロップ」が出てくる問題(4問)

  1. 電源配線の抵抗に電流が流れることで、回路に届く電源電圧が下がる現象を何と呼ぶか。
  2. 多ピンのBGAパッケージで、ボールの多くを電源とグラウンドに割り当てる主な理由はどれか。
  3. テープアウト前の最終確認(サインオフ)で、タイミングの検証と並んで行う電源配線の解析はどれか。
  4. チップの電源電圧に余裕(マージン)を持たせる必要がある理由として当てはまらないものはどれか。
