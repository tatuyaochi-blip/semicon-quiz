ツェナーダイオードとは

つぇなーだいおーど

逆方向の降伏電圧がほぼ一定になることを利用して、定電圧を得るダイオード。

この用語の分野: PN接合・ダイオード

解説の中の「ツェナーダイオード」

  • 代わりにリレーの切れが遅くなるため、速く切りたい場合はツェナーダイオードを直列に加えて電圧をある程度許します。

    リレーのコイルなどの誘導性負荷に並列に接続するダイオード(フライホイールダイオード)の目的として正しいものはどれか。

  • LEDは電気を光に変える素子、ツェナーダイオードは定電圧用です。

    CMOSイメージセンサの各画素で、光を電荷に変換する素子はどれか。

「ツェナーダイオード」が出てくる問題(4問)

  1. 定電圧ダイオード(ツェナーダイオード)が主に利用している現象はどれか。
  2. 定電圧ダイオード(ツェナーダイオード)を定電圧回路で使うときの一般的な向きはどれか。
  3. リレーのコイルなどの誘導性負荷に並列に接続するダイオード(フライホイールダイオード)の目的として正しいものはどれか。
  4. CMOSイメージセンサの各画素で、光を電荷に変換する素子はどれか。
