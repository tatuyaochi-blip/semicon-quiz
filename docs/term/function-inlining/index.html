インライン展開とは

いんらいんてんかい

関数の呼び出しを、呼び出し先の関数の本体で置き換える最適化。呼び出しの手間がなくなり、ほかの最適化も効きやすくなるが、コードが大きくなる。

「インライン展開」は、2分野の5問の練習問題に出てきます(コンパイラ, リンカ・ローダと実行形式など)。

この用語の分野: コンパイラ

インライン展開の練習問題に挑戦

関数のインライン展開の利点と欠点の組み合わせとして正しいものはどれか。

  1. A利点はコードが小さくなること、欠点は呼び出しの手間が増えること
  2. B利点はコンパイルが速く終わること、欠点は実行の結果が変わってしまうこと
  3. C利点は呼び出しの手間が消えること、欠点はコードが大きくなること
答えと解説を見る

正解：C. 利点は呼び出しの手間が消えること、欠点はコードが大きくなること

インライン展開では呼び出しの代わりに関数の本体を埋め込むので、引数の受け渡し、分岐、戻りの手間がなくなります。さらに、呼び出し元の定数などが本体に伝わり、定数畳み込みや不要コードの削除が効くようになるのが大きな利点です。一方、呼び出すたびに本体の写しができるのでコードが大きくなり、命令キャッシュのミスが増えることもあるため、小さな関数やよく呼ばれる関数を選んで行います。正しく行えば実行結果は変わりません。
