インライン展開とは

いんらいんてんかい

関数の呼び出しを、呼び出し先の関数の本体で置き換える最適化。呼び出しの手間がなくなり、ほかの最適化も効きやすくなるが、コードが大きくなる。

この用語の分野: コンパイラ

解説の中の「インライン展開」

  • インライン展開では呼び出しの代わりに関数の本体を埋め込むので、引数の受け渡し、分岐、戻りの手間がなくなります。

    関数のインライン展開の利点と欠点の組み合わせとして正しいものはどれか。

  • sqをインライン展開すると、g の中は return 6 * 6 + 1; となり、掛け算の材料がすべて定数になります。

    上のコードで、sqをインライン展開したあとに続けて効く最適化と、その結果として正しいものはどれか。

  • 次にその情報を使って再コンパイルし、よく通る道を一直線に並べたり、よく呼ばれる関数をインライン展開したりして、実際の使われ方に合った最適化を行います。

    プロファイルを使った最適化(PGO)の説明として正しいものはどれか。

「インライン展開」が出てくる問題(5問)

  1. 関数のインライン展開の利点と欠点の組み合わせとして正しいものはどれか。
  2. 上のコードで、sqをインライン展開したあとに続けて効く最適化と、その結果として正しいものはどれか。
  3. プロファイルを使った最適化(PGO)の説明として正しいものはどれか。
  4. リンク時最適化(LTO)によって可能になる最適化として最も適切なものはどれか。
  5. C言語で関数にstaticを付けて定義したとき(例: static int helper(void))の効果として正しいものはどれか。
