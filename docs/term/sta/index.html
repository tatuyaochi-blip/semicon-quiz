STA(静的タイミング解析)とは

せいてきたいみんぐかいせき

テストパターンを使わずに回路の各パスの遅延を計算し、タイミング制約を満たしているかを検証する手法。

「STA(静的タイミング解析)」は、4分野の21問の練習問題に出てきます(タイミング解析とCDC, LSI設計フロー・EDA, 論理回路など)。

この用語の分野: LSI設計フロー・EDA

STA のしくみ

静的タイミング解析(STA)は、同期回路を主にフリップフロップから次のフリップフロップまでのタイミングパスに分解します。各パスについて、入力遷移時間と出力負荷を引数とするライブラリの特性表から補間したセル遅延と、配線遅延を足し合わせ、データ到着時刻を求めます。これを、クロックエッジと取り込み側フリップフロップのセットアップまたはホールド要件で決まる要求時刻と比較します。スラックは要求時刻から到着時刻を引いた値で、負のスラックは違反です。テストベクタが不要なのですべてのパスを網羅できますが、論理的な正しさは別途シミュレーションで検証する必要があります。

制約で検査内容を指定する

STA ツールには、通常 SDC 形式のタイミング制約が必要です。クロックの周期と波形、入出力遅延、そして例外指定を与えます。フォールスパスは、互いに排他的なセレクト信号で遮断されるパスのように、実際には決して動作しない接続を解析から除外します。マルチサイクルパスはセットアップに N サイクルを与え、通常はホールドのマルチサイクルを N − 1 として、ホールドチェックを本来のエッジに戻します。誤った制約は危険で、すべてのツールチェックに合格してもシリコンで動かないことがあります。結果は、WNS(最悪負スラック)と TNS(負スラックの総和)にまとめて報告されます。

コーナーとオンチップばらつき

遅延はプロセス・電圧・温度(PVT)で変わるため、複数のコーナーで解析を繰り返します。セットアップは一般に、トランジスタが遅く電圧が低いスローコーナーで最も厳しく、ホールドはファストコーナーで最も厳しくなります。先端プロセスでは、低電圧の回路ほど低温で遅くなる温度逆転現象があるため、コーナーが増えます。同じダイ内のばらつきについては、OCV(オンチップばらつき)のディレーティングにより、セットアップチェックではデータパスと送り出し側クロックパスを遅く、取り込み側クロックパスを速く見積もります。さらに CRPR(共通パス悲観性除去)で、両パスが共有するクロックバッファを遅くも速くも扱うというありえない悲観分を差し戻します。

違反の修正方法

セットアップ違反はパスが遅すぎることを意味します。対策は論理段数の削減、セルのサイズアップや高速な低しきい値セルへの置き換え、セルを近くに配置して配線を短くすることなどで、最後の手段はクロック周波数を下げることです。ホールド違反はパスが速すぎることを意味し、チェックにクロック周期が関係しないため、遅延バッファの挿入で修正します。グラフベース解析は各ノードで最悪の遷移時間を採用するため悲観的になりがちで、パスベース解析(PBA)は違反パスを実際の遷移時間で再計算し、不要な修正を避けます。

STA(静的タイミング解析)の練習問題に挑戦

静的タイミング解析(STA)の説明として正しいものはどれか。

  1. A実際にチップを試作して動作速度を測定する
  2. B多数のテストパターンを入力してシミュレーションで動作を確認する
  3. Cテストパターンを使わずに回路の各パスの遅延を計算し、タイミング制約を満たすか検証する

正解：C. テストパターンを使わずに回路の各パスの遅延を計算し、タイミング制約を満たすか検証する

STAは、回路のすべての信号経路(パス)について、セルや配線の遅延を積み上げて計算し、セットアップ時間やホールド時間などのタイミング制約を満たしているかを網羅的に調べる手法です。テストパターンが不要で、パターンでは見落とす経路も漏れなく確認できるため、大規模LSIのタイミング検証の中心になっています。ただし論理の正しさは確かめないため、機能の検証はシミュレーションなどで別に行います。

静的タイミング解析で、信号がクロックのエッジ直後に早く変化しすぎて、フリップフロップが前のデータを正しく保持できなくなるタイミング違反はどれか。

  1. Aセットアップ違反
  2. Bホールド違反
  3. CDRC違反
答えと解説を見る

正解：B. ホールド違反

ホールド違反は、データの経路が短すぎて、クロックのエッジのあと必要な時間だけデータが保持されず、新しいデータが同じエッジで取り込まれてしまう違反です。ホールドの条件は同じエッジどうしの比較で周期が入らないため、クロック周波数を下げても解消せず、遅延用のバッファを挿入して修正します。経路が長すぎて間に合わないのはセットアップ違反、DRC違反はレイアウトの規則違反です。

よくある質問

静的タイミング解析とタイミングシミュレーションの違いは何ですか?

STA は入力ベクタを使わずに回路構造から全パスの最悪遅延を計算するため、網羅的かつ高速です。タイミングシミュレーションは特定のベクタを与えて動作を確認するため、そのベクタが通るパスしかカバーできませんが、機能も検証できます。

STA のスラックとは何ですか?

スラックは、パスの要求時刻から到着時刻を引いた値です。正のスラックは制約を余裕をもって満たしていることを、負のスラックは修正が必要な違反を意味します。

タイミングレポートの WNS と TNS とは何ですか?

WNS(最悪負スラック)は最も悪い1本のパスのスラック、TNS(負スラックの総和)は違反しているすべてのエンドポイントの負スラックの合計です。WNS が小さく TNS が大きい場合は、多数のパスがわずかずつ違反していることを意味します。
