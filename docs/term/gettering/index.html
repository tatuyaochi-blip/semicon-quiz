ゲッタリングとは

げったりんぐ

ウエハの中の金属不純物を、素子をつくる表面から離れた場所に集めて捕らえる技術。酸素析出物などを利用する。

この用語の分野: シリコンウエハ

解説の中の「ゲッタリング」

  • ゲッタリングは、デバイスの特性を悪くする金属不純物を、表面のデバイス領域から離れたウエハ内部や裏面の欠陥などに集めて捕らえる技術です。

    ゲッタリングの説明として正しいものはどれか。

  • 高温の熱処理で表面付近の酸素を外に逃がすと、表面には酸素析出物のない無欠陥層(DZ:Denuded Zone)ができ、内部には析出物によるゲッタリング層ができます。

    ウエハを熱処理して表面付近の酸素を外に拡散させ、デバイスをつくる表面に欠陥の少ない層をつくる。この層を何と呼ぶか。

  • この酸素は熱処理で析出してゲッタリングに役立つ一方、多すぎると欠陥の原因にもなるため、濃度が管理されます。

    CZ法で育成したシリコン結晶に含まれる格子間酸素の濃度の目安として最も近いものはどれか。

「ゲッタリング」が出てくる問題(5問)

  1. ゲッタリングの説明として正しいものはどれか。
  2. ウエハを熱処理して表面付近の酸素を外に拡散させ、デバイスをつくる表面に欠陥の少ない層をつくる。この層を何と呼ぶか。
  3. CZ法で育成したシリコン結晶に含まれる格子間酸素の濃度の目安として最も近いものはどれか。
  4. CZ結晶の育成中に窒素を微量に添加する(窒素ドープ)ことの効果として知られているものはどれか。
  5. p+基板の上に低濃度のp型エピタキシャル層を成長させたウエハ(p/p+エピウエハ)の利点として正しいものはどれか。
