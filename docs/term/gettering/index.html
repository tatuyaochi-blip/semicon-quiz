ゲッタリングとは

げったりんぐ

ウエハの中の金属不純物を、素子をつくる表面から離れた場所に集めて捕らえる技術。酸素析出物などを利用する。

「ゲッタリング」は、3分野の6問の練習問題に出てきます(シリコンウエハ, エピタキシャル成長, 計測・分析など)。

この用語の分野: シリコンウエハ

ゲッタリングの練習問題に挑戦

ゲッタリングの説明として正しいものはどれか。

  1. Aウエハを薄く削る加工
  2. B有害な金属不純物を、デバイスをつくる領域から離れた場所に捕獲する技術
  3. C複数のウエハを貼り合わせる技術
答えと解説を見る

正解：B. 有害な金属不純物を、デバイスをつくる領域から離れた場所に捕獲する技術

ゲッタリングは、デバイスの特性を悪くする鉄・銅・ニッケルなどの金属不純物を、表面のデバイス領域から離れたウエハ内部や裏面の欠陥などに集めて捕らえる技術です。金属はリーク電流の増加や酸化膜の劣化の原因になり、10¹⁰ atoms/cm²程度のわずかな汚染でも問題になります。ウエハ内部の酸素析出物を使うイントリンシックゲッタリングと、裏面に加工ひずみや多結晶膜を設けるエクストリンシックゲッタリングがあります。

「ゲッタリング」が出てくる問題(6問)

  1. ゲッタリングの説明として正しいものはどれか。
  2. ウエハを熱処理して表面付近の酸素を外に拡散させ、デバイスをつくる表面に欠陥の少ない層をつくる。この層を何と呼ぶか。
  3. CZ法で育成したシリコン結晶に含まれる格子間酸素の濃度の目安として最も近いものはどれか。
  4. CZ結晶の育成中に窒素を微量に添加する(窒素ドープ)ことの効果として知られているものはどれか。
