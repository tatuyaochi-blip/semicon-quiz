シフトレジスタとは

しふとれじすた

フリップフロップを直列につなぎ、クロックごとにデータを1ビットずつ隣へ移す回路。シリアルとパラレルのデータ変換や、スキャンテストのチェーンに使われる。

「シフトレジスタ」は、2分野の4問の練習問題に出てきます(論理回路, ハードウェア記述言語と検証など)。

この用語の分野: 論理回路

シフトレジスタの練習問題に挑戦

フリップフロップを直列につなぎ、クロックごとにデータを1ビットずつ隣へ移すシフトレジスタの代表的な用途はどれか。

  1. A交流の整流
  2. B発振
  3. Cシリアルデータとパラレルデータの変換
答えと解説を見る

正解：C. シリアルデータとパラレルデータの変換

シフトレジスタは、1本の線から順に入ってくるシリアルデータを蓄えてまとめてパラレルに取り出したり、その逆を行ったりできます。高速の通信インターフェース(SerDes)はこの変換を数十Gb/sで行い、配線の本数を減らしています。そのほか、LEDの多数個制御(74HC595)、遅延線、半導体のテストでフリップフロップを数珠つなぎにするスキャンチェーンにも使われます。

シフトレジスタの一部の出力のXORを入力に戻す線形帰還シフトレジスタ(LFSR)の代表的な用途はどれか。

  1. A疑似乱数パターンの生成や、テストでのパターン生成・CRC計算
  2. B正確な時刻を計る
  3. Cアナログ信号を増幅する
答えと解説を見る

正解：A. 疑似乱数パターンの生成や、テストでのパターン生成・CRC計算

LFSRは適切なタップを選ぶと、nビットで全0を除く 2ⁿ − 1 通りの状態を巡回する、一見ランダムな系列(M系列)を生成します。XORとフリップフロップだけで作れるため、内蔵テスト(BIST)のパターン生成と結果の圧縮、イーサネットなどのCRC計算、信号を平均化して電磁ノイズを減らすスクランブラに使われます。系列は予測可能なので、暗号用の乱数には使えません。

「シフトレジスタ」が出てくる問題(4問)

  1. フリップフロップを直列につなぎ、クロックごとにデータを1ビットずつ隣へ移すシフトレジスタの代表的な用途はどれか。
  2. シフトレジスタの一部の出力のXORを入力に戻す線形帰還シフトレジスタ(LFSR)の代表的な用途はどれか。
  3. 2段のシフトレジスタのつもりで、上のようにブロッキング代入(=)で書いた。起こる問題として正しいものはどれか。
  4. n個のフリップフロップで構成したジョンソンカウンタ(ツイストリングカウンタ)がとる状態の数はいくつか。
