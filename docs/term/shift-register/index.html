シフトレジスタとは

しふとれじすた

フリップフロップを直列につなぎ、クロックごとにデータを1ビットずつ隣へ移す回路。シリアルとパラレルのデータ変換や、スキャンテストのチェーンに使われる。

「シフトレジスタ」は、3分野の5問の練習問題に出てきます(論理回路, ハードウェア記述言語と検証, タイミング解析とCDCなど)。

この用語の分野: 論理回路

シフトレジスタの構成

シフトレジスタは、Dフリップフロップを各出力が次段の入力につながるように数珠つなぎにし、すべてに共通のクロックを与えた回路です。有効なクロックエッジごとに、各ビットが1段ずつ移動します。データの入れ方と出し方によって種類が分かれ、シリアル入力・シリアル出力は遅延線として働き、シリアル入力・パラレル出力は入ってくるビットを1ワードにまとめ、パラレル入力・シリアル出力はワードを読み込んで順に送り出します。双方向にシフトできるものもあります。HDLでは、q1 <= d; q2 <= q1; のように各段をノンブロッキング代入で記述する必要があります。

シリアル・パラレル変換とスキャンチェーン

代表的な用途はシリアル・パラレル変換です。高速シリアルリンクのSerDes(シリアライザ/デシリアライザ)は、幅の広いパラレルバスを少数の非常に高速なシリアルレーンに変換し、受信側で元に戻すことで、配線数やピン数を減らします。74HC595のような簡単なシリアル入力・パラレル出力のICを使えば、マイコンは3本のピンだけで多数のLEDを駆動できます。チップのテストでは、スキャン設計によってブロック内のフリップフロップをスキャンチェーンにつなぎます。テストモードではフリップフロップがシフトレジスタとなり、テストパターンをシフトインし、通常動作のクロックを1回与え、取り込んだ応答をシフトアウトします。

シフトレジスタで作るカウンタ

出力を入力に帰還すると、シフトレジスタはカウンタになります。リングカウンタは1つの「1」を循環させる回路で、n個のフリップフロップでn個の状態を持ちます。ジョンソンカウンタ(ツイストリングカウンタ)は最終段の出力を反転して帰還し、3段なら 000、100、110、111、011、001 のように2n個の状態を巡回します。隣り合う状態の間で変化するのは1ビットだけなので、各状態を2入力ゲートでグリッチの心配が少なくデコードでき、出力からは均等にずれたクロック位相が得られます。

線形帰還シフトレジスタ(LFSR)

線形帰還シフトレジスタ(LFSR)は、タップと呼ばれる特定の出力どうしのXORを入力に帰還する回路です。タップを適切に選ぶと、nビットのLFSRは0以外の2ⁿ − 1個の状態をすべて巡ってから繰り返す最大長系列を生成し、その出力はランダムに見えます。フリップフロップとXORゲートだけで作れるため、組み込み自己テスト(BIST)でのテストパターン生成と応答圧縮、巡回冗長検査(CRC)の計算、通信リンクでのデータのスクランブルに使われます。ただし、数ビットから出力を完全に予測できるため、暗号用の乱数には適していません。

シフトレジスタの練習問題に挑戦

フリップフロップを直列につなぎ、クロックごとにデータを1ビットずつ隣へ移すシフトレジスタの代表的な用途はどれか。

  1. A交流の整流
  2. B発振
  3. Cシリアルデータとパラレルデータの変換
答えと解説を見る

正解：C. シリアルデータとパラレルデータの変換

シフトレジスタは、1本の線から順に入ってくるシリアルデータを蓄えてまとめてパラレルに取り出したり、その逆を行ったりできます。高速の通信インターフェース(SerDes)はこの変換を数十Gb/sで行い、配線の本数を減らしています。そのほか、LEDの多数個制御(74HC595)、遅延線、半導体のテストでフリップフロップを数珠つなぎにするスキャンチェーンにも使われます。

シフトレジスタの一部の出力のXORを入力に戻す線形帰還シフトレジスタ(LFSR)の代表的な用途はどれか。

  1. A疑似乱数パターンの生成や、テストでのパターン生成・CRC計算
  2. B正確な時刻を計る
  3. Cアナログ信号を増幅する
答えと解説を見る

正解：A. 疑似乱数パターンの生成や、テストでのパターン生成・CRC計算

LFSRは適切なタップを選ぶと、nビットで全0を除く 2ⁿ − 1 通りの状態を巡回する、一見ランダムな系列(M系列)を生成します。XORとフリップフロップだけで作れるため、内蔵テスト(BIST)のパターン生成と結果の圧縮、イーサネットなどのCRC計算、信号を平均化して電磁ノイズを減らすスクランブラに使われます。系列は予測可能なので、暗号用の乱数には使えません。

よくある質問

シフトレジスタは何に使われますか?

シリアルとパラレルのデータ変換、遅延線やカウンタの構成、LFSRとしての擬似乱数列の生成、チップのテストに使うスキャンチェーンの構成などに使われます。

ジョンソンカウンタの状態数はいくつですか?

n個のフリップフロップで作ったジョンソンカウンタは2n個の状態を巡回します。同じ数のフリップフロップで作るリングカウンタの2倍です。

Verilogでシフトレジスタを書くときにノンブロッキング代入を使うのはなぜですか?

ブロッキング代入では各段がすぐに更新されるため、次段が同じクロックで新しい値を受け取ってしまい、チェーンが1段分に縮んでしまいます。ノンブロッキング代入なら、すべての段がクロックエッジ直前の値を受け取ります。

「シフトレジスタ」が出てくる問題(5問)

  1. フリップフロップを直列につなぎ、クロックごとにデータを1ビットずつ隣へ移すシフトレジスタの代表的な用途はどれか。
  2. シフトレジスタの一部の出力のXORを入力に戻す線形帰還シフトレジスタ(LFSR)の代表的な用途はどれか。
  3. 2段のシフトレジスタのつもりで、上のようにブロッキング代入(=)で書いた。起こる問題として正しいものはどれか。
  4. n個のフリップフロップで構成したジョンソンカウンタ(ツイストリングカウンタ)がとる状態の数はいくつか。
  5. 送り側のクロック→出力遅延が最小 0.08 ns、組み合わせ回路の最小遅延が 0.02 ns、受け側のホールド時間が 0.05 ns である。受け側のクロックが送り側より 0.1 ns 遅れて届くとき、ホールドのスラックはいくらか。
