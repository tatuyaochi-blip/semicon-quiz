焦点深度(DOF)とは

しょうてんしんど

パターンを許容できる品質で転写できる焦点の範囲。開口数を大きくすると解像度は上がるが焦点深度は浅くなるため、ウエハの平坦化が重要になる。

この用語の分野: リソグラフィ

解説の中の「焦点深度(DOF)」

  • 焦点深度は DOF = k2 × λ / NA² で表され、NAを大きくすると急に浅くなります。

    露光装置の開口数(NA)を大きくすると、焦点深度(DOF)は一般にどうなるか。

  • 微細なパターンを露光するほど焦点深度は浅くなり、先端の露光では100 nm前後しかありません。

    シリコンウエハに高い平坦度が求められる主な理由として正しいものはどれか。

  • 一方で焦点深度が浅くなり、露光できる領域の大きさが従来の半分になるなどの制約もあります。

    次世代のEUV露光装置として開発された「High-NA EUV」の特徴として正しいものはどれか。

「焦点深度(DOF)」が出てくる問題(4問)

  1. 露光装置の開口数(NA)を大きくすると、焦点深度(DOF)は一般にどうなるか。
  2. シリコンウエハに高い平坦度が求められる主な理由として正しいものはどれか。
  3. 次世代のEUV露光装置として開発された「High-NA EUV」の特徴として正しいものはどれか。
  4. 多層配線などの工程で、CMPによってウエハの表面を平坦にすることが必要になる主な理由はどれか。
