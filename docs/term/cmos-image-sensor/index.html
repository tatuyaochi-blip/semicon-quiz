CMOSイメージセンサーとは

しーもすいめーじせんさー

画素ごとに増幅回路をもち、CMOSプロセスで作るイメージセンサー。低消費電力で周辺回路を集積でき、スマートフォンのカメラなどの主流。

この用語の分野: イメージセンサ・光デバイス

4T画素で光が電圧になるまで

各画素のフォトダイオードは光を吸収し、露光量に比例した電子をためます。可視光に対する量子効率は通常約50〜80%です。一般的な4トランジスタ(4T)画素では、転送トランジスタがこの電荷をフローティングディフュージョン(FD)という小さなノードに移し、ソースフォロワ増幅器がFDの電圧を列信号線へ出力し、選択トランジスタが行を接続し、リセットトランジスタがFDをクリアします。変換ゲインはq/C_FDで、容量1 fFのノードなら電子1個あたり約160 µVです。面積を節約するため、隣接画素でFDや読み出しトランジスタを共有することがよくあります。

埋め込みフォトダイオードとCDS

シリコンと酸化膜の界面にある界面準位は暗電流を生みます。埋め込み(ピンド)フォトダイオードは、n型の電荷蓄積領域を高濃度のp+表面層の下に埋め込み、界面準位を正孔で満たして暗電流を抑えます。埋め込まれた領域は完全に空乏化するため電荷を残らず転送でき、残像も防げます。読み出しには相関二重サンプリング(CDS)を使い、リセット直後と電荷転送後にFDをサンプリングして差をとります。これでkTCリセットノイズと増幅器のオフセットが除かれ、読み出しノイズは電子数個以下になります。その後、列並列ADCで信号をチップ上でデジタル化します。

表面照射型と裏面照射型

表面照射型(FSI)センサーでは、光は金属配線層のすき間を通ってフォトダイオードに届くため、光量が減り、斜めの光にも弱くなります。裏面照射型(BSI)センサーはウエハを数µmまで薄くし、配線と反対側から光を受けるため、約1 µmの画素でも高い感度を保てます。このためスマートフォンのカメラで標準になりました。積層型センサーはさらに進んで、画素ウエハを、ADCや画像処理回路を載せた別のロジックウエハと貼り合わせます。画素領域には欠陥の少ないエピタキシャルシリコン基板が使われます。

CMOSセンサーとCCDセンサーの違い

電荷結合素子(CCD)は電荷のかたまりをチップ全体に転送して1つの出力増幅器に送るため、複数のクロック電圧が必要で消費電力も大きくなります。CMOSイメージセンサーは画素ごとに増幅し、列回路を通して行単位で読み出すので、消費電力が小さく読み出しも速く、タイミング回路やADC、画像処理を同じチップに集積できます。行ごとの読み出しは速い動きを歪ませるローリングシャッター歪みの原因になり、画素内に電荷の保持部をもつグローバルシャッター画素はこれを避けられます。デュアル変換ゲイン画素は、FDに容量を追加するかどうかを切り替えて、暗いシーンと明るいシーンの両方に対応します。

よくある質問

CMOSイメージセンサーとCCDの違いは?

CCDは電荷をチップ全体に転送して共通の出力増幅器1つで読み出しますが、CMOSイメージセンサーは各画素の中で電荷を電圧に変換し、行ごとに読み出します。CMOSセンサーは消費電力が小さくADCやロジックも集積できるため、スマートフォンをはじめほとんどのカメラで主流になっています。

イメージセンサーのBSIとは何の略ですか?

BSIはBack-Side Illumination(裏面照射)の略です。ウエハを薄くして裏側から光を入れることで、光が金属配線層を通らずにフォトダイオードに届き、小さな画素でも感度が上がります。

CMOSイメージセンサーの相関二重サンプリング(CDS)とは?

フローティングディフュージョンをリセット直後と電荷転送後の2回読み出し、その差をとる方法です。リセットノイズ(kTCノイズ)と増幅器のオフセットは両方のサンプルに含まれるので打ち消され、本来の信号だけが残ります。
