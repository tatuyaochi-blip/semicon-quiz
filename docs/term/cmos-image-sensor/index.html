CMOSイメージセンサーとは

しーもすいめーじせんさー

画素ごとに増幅回路をもち、CMOSプロセスで作るイメージセンサー。低消費電力で周辺回路を集積でき、スマートフォンのカメラなどの主流。

この用語の分野: イメージセンサ・光デバイス
