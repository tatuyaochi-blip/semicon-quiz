クロックスキューとは

くろっくすきゅー

同じクロック信号が、フリップフロップごとに到着する時刻のずれ。セットアップやホールドの余裕を変えるため、クロックツリー合成で小さく抑える。

「クロックスキュー」は、2分野の2問の練習問題に出てきます(論理回路, タイミング解析とCDCなど)。

この用語の分野: 論理回路

スキューが生じる原因

同期回路では、1 つのクロック源から配線とバッファのネットワークを通して数千から数百万個のフリップフロップにクロックを供給します。配線長、配線の抵抗と容量、バッファの負荷の違いや、プロセス・電圧・温度の局所的なばらつきによって、同じクロックエッジがフリップフロップごとにわずかに異なる時刻に到着します。この場所による到着時刻の差がクロックスキューです。1 か所でのクロックエッジのタイミングがサイクルごとに変動するジッタとは区別する必要があります。タイミング上で重要なのは、データを受け渡しするフリップフロップの組ごとのスキューです。

セットアップとホールドへの影響

スキューを、取り込み側と送り出し側のクロック到着時刻の差(取り込み側 − 送り出し側)と定義します。取り込み側のクロックが遅れるとデータに時間の余裕ができるため、セットアップには有利で、条件は 周期 + スキュー ≥ クロック・出力間遅延 + 論理遅延 + セットアップ時間 となります。周期 2.0 ns、クロック・出力間遅延 0.2 ns、論理遅延 1.4 ns、セットアップ時間 0.1 ns の場合、スラックはスキュー 0 で 0.3 ns、正のスキュー 0.1 ns で 0.4 ns です。一方、取り込みの遅れはホールドには不利です。取り込み側が古いデータをラッチする前に新しいデータで上書きされるおそれがあるので、最小のクロック・出力間遅延と最小の論理遅延の和が、ホールド時間とスキューの和を上回る必要があります。

クロックツリー合成によるスキューの制御

クロックツリー合成(CTS)は、チップ全体のクロック分配網を構築する工程で、バッファの配置を決め、配線長と負荷のバランスをとって、スキューを数十 ps 以内に収めます。代表的な構造には、対称な H ツリー、バッファ付きツリー、多くの枝を互いに短絡させた格子状のクロックメッシュがあります。その後、静的タイミング解析(STA)で、計算した実際のクロック到着時刻を使ってすべてのパスを検証し、チップ内ばらつきに対するディレーティングを加えます。設計者は、あえてスキューを入れる(有用スキュー)こともあります。クリティカルパスの取り込み側クロックを遅らせ、スラックに余裕のある隣のパスから時間を借りる方法です。

ホールド違反が危険な理由

セットアップ違反は、製造後でもクロック周波数を下げれば解消できます。周期が長くなればデータに時間の余裕ができるからです。しかしホールド違反はそうはいきません。ホールドの条件にはクロック周期がまったく含まれず、同じサイクル内での新しいデータとクロックエッジの競争だからです。そのため、スキューによるホールドの問題は、テープアウト前に短いパスへ遅延バッファを挿入して修正します。ボードレベルでも、チップ間インタフェースに同じ計算が当てはまり、タイミングバジェットからクロックスキューとジッタを差し引く必要があります。

クロックスキューの練習問題に挑戦

同期式回路の「クロックスキュー」の説明として正しいものはどれか。

  1. Aクロックの周波数が時間とともに変動すること
  2. Bクロック信号がフリップフロップごとに到着する時刻のずれ
  3. Cクロック信号の電圧が電源電圧より高くなること
答えと解説を見る

正解：B. クロック信号がフリップフロップごとに到着する時刻のずれ

クロックスキューは、同じクロックが配線の長さや負荷の違いでフリップフロップごとに異なる時刻に到着するずれです。受け側のクロックが遅れるとセットアップには有利でもホールドには不利になり、逆も同様です。チップ全体に届くクロックツリーをCTS(クロックツリー合成)で設計し、バッファの配置や配線長をそろえてスキューを数十ps以下に抑えます。周期の時間的な揺らぎはジッタです。

クロック周期 2.0 ns の同期回路で、送り側フリップフロップのクロック→出力遅延が 0.2 ns、組み合わせ回路の遅延が 1.4 ns、受け側フリップフロップのセットアップ時間が 0.1 ns である。クロックスキューを0とすると、セットアップのスラックはいくらか。

  1. A0.3 ns
  2. B0.4 ns
  3. C0.5 ns
答えと解説を見る

正解：A. 0.3 ns

セットアップのスラックは「要求時刻 − 到着時刻」で求めます。データの到着時刻は 0.2 + 1.4 = 1.6 ns、要求時刻は次のクロックエッジからセットアップ時間を引いた 2.0 − 0.1 = 1.9 ns なので、スラックは 1.9 − 1.6 = 0.3 ns です。正の値なので制約を満たしています。0.4 ns はセットアップ時間を引き忘れた値、0.5 ns はセットアップ時間を逆に足してしまった値です。スラックが負になると違反です。

よくある質問

クロックスキューとクロックジッタの違いは何ですか?

スキューは、同じサイクルでのクロック到着時刻の場所による差です。ジッタは、1 か所でのクロックエッジの時刻がサイクルごとに変動することです。

クロックスキューは常に悪いものですか?

いいえ。正のスキューはパスのセットアップ時間に余裕を与え、設計者がタイミングのバランスをとるために有用スキューを意図的に加えることもあります。ただし、セットアップに有利なスキューは、同じパスのホールドの余裕を減らします。

ホールド違反はクロックを遅くすれば直せますか?

直せません。ホールドのタイミングはクロック周期に依存しないため、短いデータパスに遅延を追加するか、スキューを減らして修正する必要があります。
