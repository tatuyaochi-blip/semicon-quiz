ファイアウォールとは

ふぁいあうぉーる

ネットワークの境界などに置き、あらかじめ決めた規則に従って、許可した通信だけを通し、それ以外を遮断するしくみ(機器やソフトウェア)。送信元と宛先のIPアドレス、ポート番号、プロトコル、通信の向きなどで判定する。社内のネットワークをインターネットからの不正な接続から守るのが主な役目。

「ファイアウォール」は、3分野の5問の練習問題に出てきます(サイバー攻撃と防御の実務, クラウドとコンテナの基礎, ネットワークの基礎など)。

この用語の分野: 情報セキュリティの基礎

パケットフィルタリングとステートフルインスペクション

最も基本的なパケットフィルタリングは、パケットのヘッダを、上から順に並べた規則と照らし合わせ、最初に当てはまった規則で通すか捨てるかを決めます。どれにも当てはまらない通信は捨てる(既定で拒否)のが原則です。ステートフルインスペクションは、通信の状態(どちらから始まった接続か)を覚えておき、内側から始めた接続への戻りの通信は自動的に通し、外から突然来た通信は捨てます。さらに、通信の中身からアプリケーションを見分けたり、侵入防止の機能をまとめたりした製品は、次世代ファイアウォールと呼ばれます。

置き場所とDMZ

ファイアウォールは、インターネットと社内のネットワークの境目に置くのが基本です。Webサーバやメールサーバのように外から接続される必要のあるサーバは、社内とは別のDMZ(非武装地帯)という区画に置き、インターネットからDMZへは必要なポートだけを許し、インターネットから社内へは許さず、DMZから社内への通信も制限します。こうすると、公開サーバが乗っ取られても社内に被害が広がりにくくなります。境界の装置とは別に、PCやサーバの1台ずつで動くホスト型のファイアウォールもあります。

ファイアウォールだけでは防げないもの

Webサイトのために443番ポートを開けていれば、その通信に紛れたSQLインジェクションやクロスサイトスクリプティングは通ってしまうので、通信の中身を調べるWAFが必要です。メールの添付ファイルやフィッシングで社内の端末が感染した場合や、正しい認証情報でVPNから入られた場合も、ファイアウォールは止められません。そのため、侵入検知システム(IDS/IPS)、端末を見張るEDR、通信のたびに確かめるゼロトラストの考え方などを組み合わせて守ります。

ファイアウォールの練習問題に挑戦

ファイアウォール(パケットフィルタリング型)の基本的な働きとして正しいものはどれか。

  1. A通信の内容を暗号化して、途中の経路での盗聴を防ぐ
  2. B送信元や宛先のIPアドレス、ポート番号などをもとにした規則に従って、許可した通信だけを通し、それ以外を遮断する
  3. C届いたパケットを複数のサーバに振り分けて、処理の負荷を分散する
答えと解説を見る

正解：B. 送信元や宛先のIPアドレス、ポート番号などをもとにした規則に従って、許可した通信だけを通し、それ以外を遮断する

ファイアウォールは、社内のネットワークとインターネットの境界などに置き、あらかじめ決めた規則で通信を許可または拒否します。例えば「外部からは公開Webサーバの443番ポートへの通信だけを許可し、それ以外の外部からの接続は拒否する」のように設定します。現在の多くのファイアウォールは、通信の状態を記録するステートフルインスペクションを行い、内側から始めた通信の戻りのパケットを自動的に通します。暗号化はしないので、通信を守るにはTLSやVPNと組み合わせます。また、許可したポートを通る攻撃(Webアプリケーションの脆弱性を突くものなど)は防げないため、WAFなど別の対策も使います。

よくある質問

ファイアウォールとWAFの違いは何ですか?

ファイアウォールは主にIPアドレスやポート番号などで、どの通信を通すかを決めます。WAF(Webアプリケーションファイアウォール)は、許可したWebの通信の中身(HTTPのリクエスト)を調べ、SQLインジェクションなどの攻撃を見つけて止めます。守る層が違うので、両方を組み合わせて使います。

ファイアウォールがあればウイルス対策は要りませんか?

要ります。ファイアウォールは許可した通信を通すので、Webの閲覧やメールで届いたマルウェアは防げません。端末のマルウェア対策やEDR、ソフトウェアの更新と組み合わせる必要があります。
