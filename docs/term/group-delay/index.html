群遅延とは

ぐんちえん

フィルタを通る信号の成分が、周波数ごとにどれだけ遅れるかを表す量で、位相特性 φ(ω) を周波数で微分して符号を反転したもの(−dφ/dω)。群遅延がすべての周波数で同じなら、波形の形を保ったまま全体が遅れるだけになる。係数が対称なNタップのFIRフィルタの群遅延は、(N − 1)/2 サンプルで一定である。IIRフィルタやアナログフィルタでは周波数によって群遅延が変わり、多くの場合カットオフ周波数の付近で大きくなるので、パルスの波形がひずむ。ベッセル特性のフィルタは、群遅延の平坦さを重視したものである。

「群遅延」は、2分野の2問の練習問題に出てきます(デジタル信号処理の基礎, アナログ・電子回路など)。

この用語の分野: デジタル信号処理の基礎

群遅延の練習問題に挑戦

101タップの直線位相FIRフィルタ(係数が左右対称)の群遅延として正しいものはどれか。

  1. A50サンプル
  2. B50.5サンプル
  3. C101サンプル
答えと解説を見る

正解：A. 50サンプル

係数が対称なNタップのFIRフィルタの群遅延は、周波数によらず (N − 1)/2 サンプルです。N = 101 なら (101 − 1)/2 = 50 サンプルで、係数の中心(51番目の係数 h[50])の位置に当たります。サンプリング周波数48 kHzなら 50 ÷ 48000 ≈ 1.04 ms の遅れになり、実時間の処理では、タップ数を増やすほど遅延が大きくなる点に注意が必要です。

解説の中の「群遅延」

  • 係数が対称なNタップのFIRフィルタの群遅延は、周波数によらず (N − 1)/2 サンプルです。
