固定小数点とは

こていしょうすうてん

小数点の位置を決めておき、整数と同じビット列で小数を表す方式。整数の演算回路で計算でき、回路が小さく消費電力も低いが、表せる範囲は狭い。Q15のように小数部のビット数で表すこともある。

この用語の分野: 計算機算術

解説の中の「固定小数点」

  • 固定小数点は、小数点の位置を決めておくだけで中身は整数なので、足し算や掛け算を整数の回路で行えます。

    小さなマイコンやDSPで、浮動小数点ではなく固定小数点の演算がよく使われる主な理由はどれか。

  • 整数部と小数部に分けるのは固定小数点の考え方で、パリティは誤りの検出のためのビットです。

    IEEE 754の浮動小数点数を構成する3つの部分の組み合わせとして正しいものはどれか。

  • どこでも同じ間隔になるのは固定小数点の性質です。

    浮動小数点数で、隣り合う表せる値どうしの間隔についての説明として正しいものはどれか。

「固定小数点」が出てくる問題(6問)

  1. 8ビットのうち下位4ビットを小数部とする固定小数点(符号なし)で、ビット列 0011 1000 が表す値はいくらか。
  2. 小さなマイコンやDSPで、浮動小数点ではなく固定小数点の演算がよく使われる主な理由はどれか。
  3. 16ビットの符号付き固定小数点のQ15形式(小数部15ビット)で表せる値の刻み(分解能)と範囲の組み合わせとして正しいものはどれか。
  4. 小数部8ビットの固定小数点数どうしを、整数の掛け算器で掛けたときの結果の扱いとして正しいものはどれか。
  5. IEEE 754の浮動小数点数を構成する3つの部分の組み合わせとして正しいものはどれか。
  6. 浮動小数点数で、隣り合う表せる値どうしの間隔についての説明として正しいものはどれか。
