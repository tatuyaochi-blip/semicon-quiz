遮断領域とは

しゃだんりょういき

バイポーラトランジスタの2つの接合がどちらも逆バイアスになり、コレクタ電流がほとんど流れない状態。スイッチのオフに相当する。

この用語の分野: バイポーラトランジスタ

解説の中の「遮断領域」

  • 遮断領域では、ベース-エミッタ接合とベース-コレクタ接合がどちらも逆バイアス(またはVBEが約0.5 V未満で電流がほぼ流れない状態)で、コレクタには漏れ電流(nA程度)しか流れません。

    バイポーラトランジスタが遮断領域(オフ)にあるときの接合の状態として正しいものはどれか。

  • 両方が順方向なら飽和領域(スイッチのオン)、両方が逆方向なら遮断領域(オフ)です。

    NPNトランジスタを増幅に使う(能動領域で動作させる)ときのバイアス条件として正しいものはどれか。

  • スイッチとして使う場合、オフは両方の接合が逆バイアスの遮断領域、オンは両方が順バイアスの飽和領域です。

    バイポーラトランジスタをスイッチとして使うとき、オンの状態に対応する動作領域はどれか。

「遮断領域」が出てくる問題(4問)

  1. バイポーラトランジスタが遮断領域(オフ)にあるときの接合の状態として正しいものはどれか。
  2. NPNトランジスタを増幅に使う(能動領域で動作させる)ときのバイアス条件として正しいものはどれか。
  3. バイポーラトランジスタをスイッチとして使うとき、オンの状態に対応する動作領域はどれか。
  4. エミッタ接地のトランジスタの出力特性(IC-VCE特性)を、ベース電流IBをパラメータとして描いたときの能動領域の特徴として正しいものはどれか。
