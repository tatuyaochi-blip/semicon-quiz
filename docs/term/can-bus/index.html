CANとは

きゃん

Controller Area Networkの略で、2本の線の差動信号でECUどうしをつなぐ車載ネットワーク。IDの値が小さいほど優先度が高く、同時に送信を始めても非破壊の調停で1つのフレームだけが残る。従来のCANは最大1 Mbit/sで、CAN FDではデータの部分を数 Mbit/sに高速化できる。

「CAN」は、2分野の7問の練習問題に出てきます(車載半導体と機能安全, CPU・アーキテクチャなど)。

この用語の分野: 車載半導体と機能安全

CANの練習問題に挑戦

CANで、2つのノードが同時にフレームを送り始めたときの動作として正しいものはどれか。

  1. A2つのフレームが衝突して両方とも壊れるので、両方のノードがランダムな時間だけ待ってから送り直す
  2. BIDの値が小さい(優先度が高い)フレームがそのまま送信を続け、負けたノードは送信をやめて後で送り直すので、勝ったフレームは壊れない
  3. CIDの値が大きいフレームが優先され、IDの値が小さいフレームは捨てられて送り直されない
答えと解説を見る

正解：B. IDの値が小さい(優先度が高い)フレームがそのまま送信を続け、負けたノードは送信をやめて後で送り直すので、勝ったフレームは壊れない

CANのバスでは、0(ドミナント)と1(リセシブ)が同時に出されると0が勝ちます。送信中のノードは自分が出したビットとバスの状態を1ビットずつ比べ、1を出したのに0が見えたら調停に負けたと判断して送信をやめます。IDは先頭から送られるので、値の小さいIDほど優先度が高くなり、勝ったフレームは壊れずにそのまま届きます。これを非破壊調停と呼びます。衝突後にランダムな時間待つのは、昔のイーサネットのCSMA/CDの方式です。

両端に120 Ωの終端抵抗を付けたCANのバスで、電源を切った状態でCAN_HとCAN_Lの間の抵抗を測った。正常な場合の値として最も近いものはどれか。

  1. A120 Ω
  2. B240 Ω
  3. C60 Ω
答えと解説を見る

正解：C. 60 Ω

CANのバスは、信号の反射を防ぐために、両端にそれぞれ120 Ωの終端抵抗を付けます。CAN_HとCAN_Lの間から見ると、2つの120 Ωが並列につながっているので、120 × 120 / (120 + 120) = 60 Ωになります。測定値が120 Ωなら片方の終端抵抗が付いていない、40 Ω程度なら終端抵抗が3つ付いているなどの配線の誤りが疑われます。240 Ωは2つを直列とみなした誤りです。
