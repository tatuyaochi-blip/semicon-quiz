高温放置試験(高温保存試験)とは

こうおんほうちしけん

電圧をかけずに製品を高温に置き続け、ワイヤボンディング接合部の劣化や不揮発性メモリのデータ保持などを評価する信頼性試験。HTSやHTSLとも呼ばれる。

「高温放置試験(高温保存試験)」は、1分野の1問の練習問題に出てきます(信頼性など)。

この用語の分野: 信頼性

温度だけを加える試験

高温放置試験は、電圧をかけずに製品を恒温槽に入れて高温に保ち、試験の前後や途中で電気的特性を比べる試験です。英語ではHigh Temperature Storage(HTS)やHigh Temperature Storage Life(HTSL)と呼ばれます。JEDECの規格(JESD22シリーズ)などでは、例えば150 ℃で1000時間が代表的な条件で、製品や規格によってはさらに高い温度で時間を短くすることもあります。電圧も信号も加えないため、装置が簡単で多くの試料を一度に試験でき、温度だけで進む劣化を切り分けて調べられます。

対象とする故障メカニズム

代表的な対象は、ワイヤボンディングの接合部です。金ワイヤとアルミニウムパッドの接合部では、高温で金とアルミニウムの金属間化合物が成長し、拡散の速さの違いによってボイド(カーケンダルボイド)ができると、接合部の抵抗が上がったり剥がれたりします。銅ワイヤの接合部でも、金属間化合物の成長や腐食の評価が重要です。このほか、封止樹脂やダイボンド材などの材料の熱による劣化や、不揮発性メモリのデータ保持も高温放置で評価します。

HTOL・THBとの違い

HTOL(高温動作寿命試験)は高温で電圧をかけて動作させるため、TDDBやエレクトロマイグレーションのように電界や電流で進む劣化も同時に加速します。高温放置試験は電圧をかけないので、こうした劣化は評価できない代わりに、温度だけによる劣化を見分けられます。高温高湿バイアス試験(THB)は湿度と電圧で腐食を加速し、温度サイクル試験は温度の変化によるひずみを加えます。それぞれ対象とする故障が異なるため、認定ではこれらを組み合わせて行います。データシートの保存温度範囲は保管してよい温度の規格で、試験条件とは別のものです。

不揮発性メモリのデータ保持

フラッシュメモリやEEPROMでは、フローティングゲートや電荷トラップ膜に蓄えた電荷が、温度が高いほど速く抜けていきます。そこで、データを書き込んだ製品を高温に放置し、所定の時間のあとでも正しく読み出せるかを確かめます。書き換えを繰り返すと絶縁膜が劣化して電荷が抜けやすくなるため、書き換え耐性の試験で劣化させてから放置する方法が一般的です。結果は、故障メカニズムに応じて仮定した活性化エネルギーを使い、アレニウスモデルで実使用の温度での保持期間に換算しますが、仮定によって結果が大きく変わる点に注意します。

  1. A高い温度
  2. B高い湿度
  3. C電源電圧などの電気的なバイアス
答えと解説を見る

正解：C. 電源電圧などの電気的なバイアス

高温放置試験(HTS)は、電圧をかけずに製品を例えば150 ℃程度の高温に長時間置き、前後で電気的特性を比べる試験です。HTOLは高温で電源電圧をかけて動作させるため、TDDBやエレクトロマイグレーションなど電界や電流で進む劣化も加速しますが、高温放置試験では温度だけで進む劣化を切り分けて評価できます。代表的な対象は、ワイヤボンディングの接合部での金属間化合物の成長とボイドによる抵抗の増加や剥がれ、不揮発性メモリのデータ保持、封止樹脂などの材料の劣化です。湿度と電圧を同時に加えるのは高温高湿バイアス試験(THB)です。

よくある質問

高温放置試験とHTOLの違いは何ですか?

高温放置試験は電圧をかけずに高温に置くだけで、温度だけで進む劣化を評価します。HTOLは高温で電圧をかけて動作させるため、電界や電流で進む劣化も加速して評価します。

高温放置試験の代表的な条件はどのくらいですか?

例えば150 ℃で1000時間が代表的な条件です。実際の温度と時間は、適用する規格、パッケージの材料、製品の温度グレードによって変わり、より高い温度で時間を短くすることもあります。

半導体の加速試験にはどのような種類がありますか?

温度と電圧をかけて動作させるHTOL、温度だけを加える高温放置試験、温度と湿度と電圧を加える高温高湿バイアス試験(THB)やHAST、温度の変化を繰り返す温度サイクル試験などがあります。いずれも故障を起こすストレスを強めて、短い時間で寿命や故障率を評価します。
