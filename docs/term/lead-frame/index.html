リードフレームとは

りーどふれーむ

チップを載せる台と外部端子(リード)を一体にした金属の薄板。QFPなどのパッケージで使われる。

この用語の分野: パッケージ・実装

解説の中の「リードフレーム」

  • リードフレームは、チップを載せ、外部端子にもなる金属の枠です。

    リードフレームの材料として一般的に使われるものはどれか。

  • ダイボンディングは、切り出したチップ(ダイ)を、銀ペーストやはんだ、ダイアタッチフィルムなどの接着材でリードフレームや基板に固定する工程です。

    チップをリードフレームや基板の所定の位置に接着・固定する工程を何と呼ぶか。

  • ワイヤボンディングは、金・銅・アルミニウムなどの細いワイヤで、チップの電極パッドとリードフレームやパッケージ基板の端子をつなぐ方法です。

    ワイヤボンディングの説明として正しいものはどれか。

「リードフレーム」が出てくる問題(6問)

  1. リードフレームの材料として一般的に使われるものはどれか。
  2. チップをリードフレームや基板の所定の位置に接着・固定する工程を何と呼ぶか。
  3. リードフレームを使うパッケージで、外に出たリードの表面にスズ(Sn)系のめっきをする主な目的はどれか。
  4. ワイヤボンディングの説明として正しいものはどれか。
  5. 封止樹脂の温度がガラス転移温度(Tg)を超えると起こる変化として正しいものはどれか。
  6. パッケージの内部の封止樹脂とチップなどの境界のはく離(デラミネーション)を、非破壊で見つけるのに広く使われる装置はどれか。
