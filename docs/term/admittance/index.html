アドミタンスとは

あどみたんす

インピーダンスの逆数 Y = 1/Z [S]。実部をコンダクタンスG、虚部をサセプタンスBとして Y = G + jB と表す。並列回路では各素子のアドミタンスを足せばよいので、並列RLC回路は Y = 1/R + j(ωC − 1/(ωL)) と簡単に書ける。Z = 3 + j4 Ω なら Y = 0.12 − j0.16 S で、誘導性ではサセプタンスが負になる。

「アドミタンス」は、1分野の5問の練習問題に出てきます(回路解析(交流回路・線形回路・過渡現象)など)。

アドミタンスの練習問題に挑戦

インピーダンスが Z = 3 + j4 [Ω] の負荷のアドミタンス Y はどれか。

  1. A0.12 − j0.16 S
  2. B0.12 + j0.16 S
  3. C約0.33 − j0.25 S
答えと解説を見る

正解：A. 0.12 − j0.16 S

解き方1(分母の有理化): Y = 1/(3 + j4) の分母と分子に共役複素数 3 − j4 を掛けると、Y = (3 − j4)/(3² + 4²) = (3 − j4)/25 = 0.12 − j0.16 S です。解き方2(極形式): |Z| = √(3² + 4²) = 5 Ω、偏角は約53.1° なので、Y = (1/5)∠−53.1° = 0.2∠−53.1° S で、直交形式に直すと同じ 0.12 − j0.16 S になります。インピーダンスが誘導性(虚部が正)なら、アドミタンスの虚部(サセプタンス)は負になります。

「アドミタンス」が出てくる問題(5問)

  1. インピーダンスが Z = 3 + j4 [Ω] の負荷のアドミタンス Y はどれか。
  2. 図の並列RLC回路で、電源の周波数を共振周波数 f0 = 1/(2π√(LC)) に合わせたときの性質として正しいものはどれか。
  3. 図(a)の回路で、R = 10 Ω、使う角周波数でのコンデンサのリアクタンスを 1/(ωC) = 10 Ω、入力電圧を vin = 10∠0° V(実効値)とする。出力端子から見たテブナンの等価回路の内部インピーダンス Zth はどれか。
