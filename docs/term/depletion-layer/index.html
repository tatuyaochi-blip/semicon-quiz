空乏層とは

くうぼうそう

PN接合の境界付近にできる、キャリアがほとんど存在しない領域。逆バイアスで広がる。

「空乏層」は、10分野の41問の練習問題に出てきます(PN接合・ダイオード, MOSFET, 半導体物性など)。

この用語の分野: PN接合・ダイオード

空乏層ができるしくみ

p型とn型の領域が接すると、n側から電子が、p側から正孔が拡散し、接合付近で再結合します。後には固定電荷が残ります。n側にはイオン化したドナーの正電荷、p側にはイオン化したアクセプタの負電荷です。これらの電荷がnからpに向かう内蔵電界をつくり、キャリアを押し戻して、それ以上の正味の拡散を止めます。その結果生じる内蔵電位(拡散電位)は、シリコンの接合ではドーピングによって0.6〜0.9 V程度が一般的です。この領域は、打ち消されない固定電荷を持つことが本質的な特徴なので、空間電荷領域とも呼ばれます。

空乏層の幅とドーピングによる配分

電荷中性の条件から NA·xp = ND·xn となるので、空乏層はドーピングの低い側へより深く広がります。階段接合では、全幅は W = √(2ε(Vbi + V)/q × (1/NA + 1/ND)) で表され、Vは逆バイアス電圧です。p+n接合ではこれが W ≈ √(2ε(Vbi + V)/(qND)) となり、空乏層のほぼすべてがn側にできます。典型的な幅は0.1〜1 µm程度で、たとえば ND = 10¹⁶ cm⁻³ でバイアスなしなら約0.3 µmです。Vbi + V を4倍にすると幅は2倍になります。

空乏層容量

空乏層には可動キャリアがほとんどないので、平行平板コンデンサの絶縁体のように振る舞い、容量は C = εA/W となります。逆バイアスでWが広がると容量は下がり、階段接合ではおよそ (Vbi + V)^-1/2 に比例します。バラクタダイオード(可変容量ダイオード)は、この電圧で制御できる容量を同調に利用しています。同じ関係はC-V測定によるプロファイリングにも使われ、1/C²を逆バイアスに対してプロットした傾きから、低ドープ側のドーピング濃度を求められます。接合容量はすべてのトランジスタのドレインやソースにも負荷としてつき、回路の遅延を増やします。

PNダイオード以外での空乏

空乏の概念はデバイス物理のいたるところに登場します。MOSのゲート下のシリコンは、反転が起きる前にゲート電圧によって空乏化します。ポリシリコンのゲート電極自体も空乏化して、等価酸化膜厚を約0.3〜0.5 nm増やすため、high-k/メタルゲート技術に置き換えられました。フォトダイオードは空乏層内で光が生成したキャリアを効率よく集めるので、PINダイオードでは幅の広い真性層を挟みます。パワーデバイスは低ドープのドリフト層を使い、広い空乏層で高電圧を保持します。なお、境界がくっきりした描像は空乏近似によるもので、実際の境界はデバイ長の数倍程度にわたってなだらかに変化します。

空乏層の練習問題に挑戦

PN接合に加える逆方向バイアス電圧を大きくすると、空乏層の幅はどうなるか。

  1. A狭くなる
  2. B変化しない
  3. C広くなる
答えと解説を見る

正解：C. 広くなる

逆方向バイアスでは外部電圧が内蔵電位と同じ向きに加わり、キャリアがさらに接合から引き離されるため、空乏層は広がります。幅はおよそ √(Vbi + V) に比例し、Vが内蔵電位より十分大きければ、例えば電圧を4倍にすると約2倍になります。空乏層が広がると接合容量(C = εA/W)は小さくなり、この性質が可変容量ダイオードに使われます。電界を受け持つ幅が広がることは、耐圧の確保にもつながります。

p側の不純物濃度がn側よりはるかに高いPN接合(p+n接合)で、空乏層はどのように広がるか。

  1. A不純物濃度の低いn側に大きく広がる
  2. B不純物濃度の高いp側に大きく広がる
  3. C必ずp側とn側に等しく広がる
答えと解説を見る

正解：A. 不純物濃度の低いn側に大きく広がる

空乏層の両側では、イオン化した不純物の電荷の量が等しくなります(NA·xp = ND·xn)。低濃度側は同じ電荷を得るために広い範囲が空乏化するので、p+n接合では空乏層のほとんどがn側に広がります。このため耐圧や容量は低濃度側の濃度でほぼ決まり、計算も片側だけで近似できます(片側階段接合)。パワーデバイスの低濃度ドリフト層は、この性質を利用して高い電圧を受け持ちます。

よくある質問

逆バイアスで空乏層が広がるのはなぜですか?

逆バイアスが内蔵電位に加わるので、大きくなった電圧を支えるためにより多くの固定電荷を露出させる必要があるからです。ドーパント密度は決まっているため、より広い領域を空乏化するしかなく、幅は全電圧のおよそ平方根に比例して広がります。

空乏層と空間電荷領域は同じものですか?

同じです。どちらも、接合付近で可動キャリアがほとんどなく、イオン化したドーパントが正味の固定電荷を残している領域を指します。

電圧をかけていないPN接合にも空乏層はありますか?

あります。熱平衡状態でキャリアの拡散と再結合によってでき、内蔵電位によって保たれています。順バイアスで狭まり、逆バイアスで広がります。
