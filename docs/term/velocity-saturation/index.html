速度飽和とは

そくどほうわ

強い電界の下で、キャリアのドリフト速度が電界に比例せず、約1×10⁷ cm/sで頭打ちになる現象。短チャネルのMOSFETでは、ドレイン電流が2乗則より小さくなる原因になる。

この用語の分野: MOSFET

解説の中の「速度飽和」

  • ただし比例するのは弱い電界の範囲だけで、シリコンの電子は約10⁴ V/cmを超えるあたりから伸びが鈍り、約1×10⁷ cm/sで頭打ちになります(速度飽和)。

    移動度1000 cm²/V·sの電子に、100 V/cmの電界をかけたときのドリフト速度はいくらか。

  • 電界が弱いうちはドリフト速度は電界に比例しますが、強くなるとキャリアが光学フォノンを放出してエネルギーを失う散乱が増え、シリコンの電子は約1×10⁷ cm/sで頭打ちになります(速度飽和)。

    シリコン中の電子に強い電界を加えたとき、ドリフト速度はどうなるか。

  • 短チャネルでは速度飽和によって1乗に近づき、さらに移動度の劣化や寄生抵抗の影響でずれるため、実際の設計ではBSIMなどの精密なモデルを使います。

「速度飽和」が出てくる問題(4問)

  1. 移動度1000 cm²/V·sの電子に、100 V/cmの電界をかけたときのドリフト速度はいくらか。
  2. シリコン中の電子に強い電界を加えたとき、ドリフト速度はどうなるか。
  3. 長チャネルのMOSFETが飽和領域で動作しているとき、ドレイン電流IDはおよそ何に比例するか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  4. 長チャネルのnMOSFETが飽和領域で動作する条件として正しいものはどれか。(VGS > Vth とする)
