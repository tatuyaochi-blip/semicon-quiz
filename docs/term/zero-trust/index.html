ゼロトラストとは

ぜろとらすと

ネットワークの場所(社内か社外か)によって暗黙に信頼せず、リソースへのアクセスの要求ごとに、利用者の認証、端末の状態、要求の内容などを確かめて、必要最小限のアクセスだけを許可するセキュリティの考え方。「決して信頼せず、常に確かめる(Never trust, always verify)」と表現される。米国のNISTは2020年に公開したSP 800-207で、その原則と、ポリシー決定点やポリシー実施点などの構成要素を示した。クラウドの利用やテレワークの広がりで、境界型の防御を補う考え方として採り入れられている。

「ゼロトラスト」は、2分野の3問の練習問題に出てきます(サイバー攻撃と防御の実務, 暗号技術の基礎と応用など)。

この用語の分野: サイバー攻撃と防御の実務

境界型の防御との違い

従来の境界型の防御は、社内のネットワークを信頼できる内側とみなし、ファイアウォールで外からの侵入を防ぎます。この方式では、フィッシングなどで一度内側に入られると、攻撃者が内部を自由に動けてしまいます。ゼロトラストでは、内側か外側かで信頼を決めず、社内からのアクセスにも同じ確認を行うので、侵入された後の被害の広がりを小さくできます。

構成要素

SP 800-207では、アクセスを許可するかを判断するポリシー決定点(PDP)と、利用者とリソースの間で判断を実行するポリシー実施点(PEP)を分けます。判断には、IDの管理と多要素認証、端末の管理の状態、脅威の情報、ログの分析などの情報が使われます。実装では、ZTNA(ゼロトラストネットワークアクセス)、マイクロセグメンテーション、IDを中心にしたアクセス制御などが組み合わされます。

導入の進め方

ゼロトラストは1つの製品を買えば実現するものではなく、守る対象(データ、アプリケーション、資産)を洗い出し、通信の流れを把握し、方針を少しずつ厳しくしていく取り組みです。多要素認証の徹底と端末の管理から始め、重要なアプリケーションからZTNAに移すなど、段階的に進めるのが一般的です。

ゼロトラストの練習問題に挑戦

ゼロトラストの考え方に基づくアクセス制御の説明として、正しいものはどれか。

  1. A社内のネットワークの中にいるだけでは信頼せず、要求ごとに利用者と端末の状態を確かめて、必要最小限のアクセスを許可する
  2. B社内のネットワークの中は安全とみなして自由に通信させ、境界のファイアウォールとVPNで、外部からの侵入だけを防ぐ
  3. C一度ログインに成功した利用者と端末は信頼できるので、その後はすべてのシステムに、確認なしで自由にアクセスできるようにする
答えと解説を見る

正解：A. 社内のネットワークの中にいるだけでは信頼せず、要求ごとに利用者と端末の状態を確かめて、必要最小限のアクセスを許可する

従来の境界型の防御は、社内のネットワークを信頼できる内側とみなし、境界で外部からの侵入を防ぐ考え方でした。クラウドの利用やテレワークで守る対象が社外に広がり、境界の内側に入った攻撃者が自由に動けてしまう問題もあるため、ネットワークの場所で信頼を与えないゼロトラストの考え方が広がりました。米国のNISTは2020年に公開したSP 800-207で、ネットワークの場所によって暗黙に信頼しないこと、リソースへのアクセスを要求ごとに許可すること、利用者や端末の状態などをもとにした動的な方針で判断することなどを原則として示しています。「決して信頼せず、常に確かめる(Never trust, always verify)」と表現されます。

NIST SP 800-207のゼロトラストアーキテクチャでは、アクセスを許可するかを判断する「ポリシー決定点(PDP)」と、判断を実行する「ポリシー実施点(PEP)」を分けて考える。社員が業務アプリケーションにアクセスするときの、両者の働きの説明として正しいものはどれか。

  1. APEPが利用者の認証や端末の状態をもとにアクセスを許可するかを判断し、PDPは利用者のPCの中で動いて、アプリケーションとの通信を暗号化する
  2. BPDPが認証の結果や端末の状態を方針に照らして判断し、利用者とアプリケーションの間のPEPが、その判断に従って接続を通したり切ったりする
  3. CPDPとPEPは同じ装置の別の呼び名で、一度接続を許可した後は、セッションが終わるまで許可の判断を見直さないことが原則である
答えと解説を見る

正解：B. PDPが認証の結果や端末の状態を方針に照らして判断し、利用者とアプリケーションの間のPEPが、その判断に従って接続を通したり切ったりする

SP 800-207では、ポリシーエンジンとポリシー管理者からなるPDPが、利用者の認証の結果、端末の状態、アクセスする対象の重要さ、脅威の情報などを方針に照らして、アクセスを許可するかを判断します。PEPは、利用者とリソースの間の通り道に置かれ、PDPの判断に従って接続を有効にしたり、監視したり、切ったりします。判断と実施を分けることで、方針を一か所で管理しながら、多くのアプリケーションの入口で同じように適用できます。また、端末の状態などが変われば、接続している途中でも判断を見直して、アクセスを止められるようにします。

よくある質問

ゼロトラストを採り入れると、ファイアウォールやVPNは要らなくなりますか?

すぐに不要になるわけではありません。ゼロトラストは、ネットワークの場所だけで信頼しないという考え方で、境界の防御は攻撃を減らす一層として引き続き役立ちます。ただし、リモートアクセスについては、VPNから、アプリケーションごとに許可するZTNAへ移す動きがあります。

「誰も信頼しない」なら、社員の仕事がしにくくなりませんか?

信頼しないのは「ネットワークの場所」で、確かめたうえで必要なアクセスは許可します。シングルサインオンやパスキーで確認の手間を利用者に意識させない工夫をし、新しい端末やふだんと違う場所からの利用のときだけ追加の確認を求めることで、使いやすさとの両立を図ります。

  • クラウドの利用やテレワークで守る対象が社外に広がり、境界の内側に入った攻撃者が自由に動けてしまう問題もあるため、ネットワークの場所で信頼を与えないゼロトラストの考え方が広がりました。
