定常偏差とは

ていじょうへんさ

制御系の応答が落ち着いた後に残る、目標値と制御量の差。オフセットとも呼ぶ。単位フィードバックの系では、ステップの目標値に対して 1/(1 + Kp)(Kp = G(0) は位置偏差定数)となり、前向きの経路に積分を含まない(0形の)系では0にならない。積分を1つ含む1形の系ではステップに対する定常偏差が0になり、ランプの目標値に対しては 1/Kv(Kv は速度偏差定数)の偏差が残る。PI制御の積分動作は、この偏差をなくすために使われる。

「定常偏差」は、1分野の5問の練習問題に出てきます(制御工学の基礎など)。

この用語の分野: 制御工学の基礎

定常偏差の練習問題に挑戦

単位フィードバックの系で、前向きの伝達関数が G(s) = 9/(1 + 2s) である。大きさ1のステップの目標値に対する定常偏差として正しいものはどれか。

  1. A0
  2. B0.1
  3. C約0.11
答えと解説を見る

正解：B. 0.1

単位フィードバックの系のステップに対する定常偏差は 1/(1 + Kp) で、Kp = G(0) を位置偏差定数と呼びます。ここでは Kp = 9 なので、定常偏差は 1/(1 + 9) = 0.1 です。前向きの経路に積分を含まない(0形の)系では、ゲインを上げると偏差は小さくなりますが、0にはなりません。偏差を0にするには、PI制御などで積分を加えます。

閉ループが安定な単位フィードバックの系で、前向きの伝達関数 G(s) が積分 1/s を1つ含む(1形の系である)とき、定常偏差の説明として正しいものはどれか。

  1. Aステップの目標値に対する定常偏差は0になり、一定の速さで増えるランプの目標値に対しては、一定の大きさの偏差が残る
  2. Bステップの目標値に対しても一定の大きさの定常偏差が残り、ランプの目標値に対しては、偏差が時間とともに大きくなり続ける
  3. Cステップ、ランプ、一定の加速度で増える目標値のどれに対しても、定常偏差は0になる
答えと解説を見る

正解：A. ステップの目標値に対する定常偏差は0になり、一定の速さで増えるランプの目標値に対しては、一定の大きさの偏差が残る

前向きの経路に含まれる積分の数を、系の形と呼びます。1形の系では、偏差が少しでも残ると積分が操作量を変え続けるので、ステップに対する定常偏差は0になります。ランプの目標値に対しては、追いかけ続けるために一定の偏差が必要で、その大きさは 1/Kv(Kv = lim[s→0] sG(s) は速度偏差定数)です。例えば G(s) = 2/(s(s + 1)) では Kv = 2 で、単位ランプに対する定常偏差は0.5になります。

解説の中の「定常偏差」

  • 単位フィードバックの系のステップに対する定常偏差は 1/(1 + Kp) で、Kp = G(0) を位置偏差定数と呼びます。

    単位フィードバックの系で、前向きの伝達関数が G(s) = 9/(1 + 2s) である。大きさ1のステップの目標値に…

  • 1形の系では、偏差が少しでも残ると積分が操作量を変え続けるので、ステップに対する定常偏差は0になります。

    閉ループが安定な単位フィードバックの系で、前向きの伝達関数 G(s) が積分 1/s を1つ含む(1形の系である)とき…

  • 低い周波数ほどゲインが大きくなるので、積分を含む系は、ステップの目標値に対する定常偏差を0にできます。

    積分要素 G(s) = 1/s のボード線図として正しいものはどれか。

  • Kp を大きくすると応答が速くなり、ステップに対する定常偏差 1/(1 + Kp·K)(K は制御対象の定常ゲイン)も小さくなりますが、偏差がなければ操作量も0になるので、偏差は0にはなりません(オフセット)。

    積分要素を含まない(0形の)制御対象を比例(P)制御する。比例ゲイン Kp を大きくしたときの一般的な変化として正しい…

  • 積分動作は偏差を時間で積み重ねて操作量にするので、偏差が少しでも残っている限り操作量を変え続け、最終的に定常偏差を0にします。

    PI制御で、積分(I)動作を加える主な目的と、その副作用の組み合わせとして正しいものはどれか。

「定常偏差」が出てくる問題(5問)

  1. 単位フィードバックの系で、前向きの伝達関数が G(s) = 9/(1 + 2s) である。大きさ1のステップの目標値に対する定常偏差として正しいものはどれか。
  2. 閉ループが安定な単位フィードバックの系で、前向きの伝達関数 G(s) が積分 1/s を1つ含む(1形の系である)とき、定常偏差の説明として正しいものはどれか。
  3. 積分要素 G(s) = 1/s のボード線図として正しいものはどれか。
  4. 積分要素を含まない(0形の)制御対象を比例(P)制御する。比例ゲイン Kp を大きくしたときの一般的な変化として正しいものはどれか。
  5. PI制御で、積分(I)動作を加える主な目的と、その副作用の組み合わせとして正しいものはどれか。
