FPGAとは

えふぴーじーえー

製造後に、ユーザーが論理回路の構成を書き換えられるLSI。試作や少量生産の製品、ASICの検証などに使われる。

この用語の分野: LSI設計フロー・EDA

解説の中の「FPGA」

  • FPGAは、論理ブロックと配線のつなぎ方を、製造後に設定データで書き換えられるデバイスです。

    FPGAの特徴として正しいものはどれか。

  • エミュレータやFPGAに回路を実装して動かすと、桁違いに速く検証でき、実際のOSやアプリケーションを動かしながら、チップができる前にソフトウェアの開発や検証を進められます。

    大規模なSoCの検証で、設計した回路を専用のハードウェアやFPGAの上で動かし、ソフトウェアと組み合わせて高速に検証す…

  • CPUではレジスタの値の選択やバスの切り替えに使われ、FPGAの論理ブロック(LUT)もメモリとマルチプレクサで任意の論理を実現しています。

    マルチプレクサの機能として正しいものはどれか。

「FPGA」が出てくる問題(4問)

  1. FPGAの特徴として正しいものはどれか。
  2. 大規模なSoCの検証で、設計した回路を専用のハードウェアやFPGAの上で動かし、ソフトウェアと組み合わせて高速に検証する手法はどれか。
  3. マルチプレクサの機能として正しいものはどれか。
  4. トランジスタを敷き詰めた共通の下地(マスター)をあらかじめつくっておき、配線層だけを品種ごとに設計して製造する方式はどれか。
