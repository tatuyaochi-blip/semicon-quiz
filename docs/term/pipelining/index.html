パイプライン処理とは

ぱいぷらいんしょり

命令の処理を取り出し・解読・実行などの段階に分け、複数の命令を少しずつずらして同時に処理する方式。

この用語の分野: CPU・アーキテクチャ

解説の中の「パイプライン処理」

  • それ以前の非同期DRAMは制御信号のタイミングで動いていましたが、同期させることでコマンドをパイプライン処理し、バースト転送で連続データを高速に送れるようになりました。

    SDRAMの「S(Synchronous)」が表す特徴として正しいものはどれか。

  • 命令ごとの処理時間がそろうため、パイプライン処理に適しています。

    RISC(縮小命令セットコンピュータ)の特徴として正しいものはどれか。

  • パイプライン処理は、この段階を重ねて並行に進めるものです。

    CPUが1つの命令を処理する基本的な流れとして正しい順序はどれか。

「パイプライン処理」が出てくる問題(4問)

  1. CPUのパイプライン処理の主な目的として正しいものはどれか。
  2. SDRAMの「S(Synchronous)」が表す特徴として正しいものはどれか。
  3. RISC(縮小命令セットコンピュータ)の特徴として正しいものはどれか。
  4. CPUが1つの命令を処理する基本的な流れとして正しい順序はどれか。
