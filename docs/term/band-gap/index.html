バンドギャップとは

ばんどぎゃっぷ

価電子帯の上端と伝導帯の下端とのエネルギー差。シリコンは室温で約1.12 eV。大きいほど高温・高電圧に強い。

「バンドギャップ」は、14分野の57問の練習問題に出てきます(化合物半導体, 半導体物性, シリコンフォトニクスなど)。

この用語の分野: 半導体物性

バンドギャップで決まること

バンドギャップEgは、半導体がどの波長の光を吸収・放出するかを決め、λ (nm) ≈ 1240 / Eg (eV) の関係があります。約1.12 eVのシリコンは約1.1 µmまで、約0.66 eVのゲルマニウムは約1.9 µmまでの光を吸収し、1.42 eVのGaAsは870 nm付近で発光します。真性キャリア密度niもEgで決まり(ni ∝ Tの3/2乗·exp(−Eg/2kT))、室温でシリコンは約1×10¹⁰ cm⁻³、ゲルマニウムは約2×10¹³、GaAsは約2×10⁶です。niが小さいほど接合のリークが小さく、わずかなドーピングで導電率を制御できます。なお、ギャップ自体も温度が上がるとわずかに狭まり、シリコンでは約0.3 meV/Kです。

直接遷移型と間接遷移型

GaAsやInGaNのような直接遷移型半導体では、伝導帯の底と価電子帯の頂上が同じ結晶運動量の位置にあるため、電子と正孔が光子を放出して効率よく再結合できます。シリコンは間接遷移型なので、発光再結合にはフォノンの関与も必要で、発光は弱くなります。代わりに、再結合は主に深い準位のトラップを介して進みます(ショックレー・リード・ホール(SRH)再結合)。LEDやレーザーに化合物半導体が使われるのはこのためで、青色にはInGaN、インジウムを増やすと緑色、赤色には1.9〜2.0 eV付近のAlGaInP、深紫外にはAlGaNが使われます。

パワー半導体向けのワイドバンドギャップ材料

おおむね3 eV以上のワイドバンドギャップ半導体は、熱的に励起されるキャリアが少ないため、高電界や高温に耐えます。4H-SiC(約3.26 eV)とGaN(約3.4 eV)の絶縁破壊電界はシリコンの約10倍あり、同じ耐圧ならSiCのドリフト層は厚さを約10分の1、ドーピング濃度を約100倍にでき、オン抵抗を大きく下げられます。さらにギャップの大きいウルトラワイドバンドギャップ材料として、Ga2O3(約4.5〜4.9 eV)やダイヤモンド(約5.5 eV)があります。絶縁体はさらに大きく、SiO2は約9 eV、HfO2は約5.8 eVです。

ギャップを設計する

混晶にするとEgを連続的に調整できます。AlGaAsはGaAsと格子整合したまま1.42 eVから大きくなり、InP上のIn0.53Ga0.47Asは約0.75 eVで1.55 µm帯の受光素子に、HgCdTeはほぼ0〜1.5 eVをカバーして赤外線検出器に使われます。HBTのナローギャップSiGeベースのようなヘテロ接合は、ギャップの差を利用しています。非常に高濃度のドーピングは見かけのギャップを狭め、厚さ数nmのフィンやナノシートでの量子閉じ込めはギャップを広げます。ギャップは単接合太陽電池の約33%というショックレー・クワイサー限界も決めます。バンドギャップリファレンス回路の出力約1.2 Vは、0 Kに外挿したシリコンのギャップに近い値です。

バンドギャップの練習問題に挑戦

室温におけるシリコン(Si)のバンドギャップに最も近い値はどれか。

  1. A約0.66 eV
  2. B約1.12 eV
  3. C約3.4 eV
答えと解説を見る

正解：B. 約1.12 eV

シリコンのバンドギャップは室温で約1.12 eVで、吸収できる光の波長の上限は約1.1 µm(1240÷1.12)です。約0.66 eVはゲルマニウムで、ギャップが小さいぶん高温で漏れ電流が増えやすく、約3.4 eVはGaNで、高耐圧・高温動作や青色LEDに向くワイドギャップ半導体です。シリコンはその中間で、良質な熱酸化膜(SiO2)を作れることと合わせてLSIの主役になりました。

シリコン中のリンがつくるドナー準位の、バンドギャップ内での位置として正しいものはどれか。

  1. A伝導帯の下端のすぐ近く(約0.045 eV下)
  2. B価電子帯の上端のすぐ近く
  3. Cバンドギャップのほぼ中央
答えと解説を見る

正解：A. 伝導帯の下端のすぐ近く(約0.045 eV下)

リンのドナー準位は伝導帯の下端から約0.045 eVと非常に浅く、室温の熱エネルギー(約0.026 eV)でもほぼ全てがイオン化して電子を供給します。ヒ素は約0.054 eV、ホウ素のアクセプタ準位は価電子帯から約0.045 eVです。浅い準位は母体の誘電率で束縛が弱められるため、水素原子のモデルで見積もれます。ギャップ中央付近の深い準位は金などの不純物によるもので、再結合中心になります。

よくある質問

バンドギャップとは簡単にいうと何ですか?

電子を結合から解き放ち、電気を運べる状態にするのに必要な最小のエネルギーで、価電子帯の上端と伝導帯の下端のエネルギー差に等しくなります。金属はフェルミ準位にギャップがなく、半導体は中程度、絶縁体は非常に大きなギャップをもちます。

バンドギャップから波長を求めるには?

λ (nm) ≈ 1240 / Eg (eV) を使います。シリコンの1.12 eVでは約1.1 µmとなり、これがシリコンが効率よく吸収できる最も長い波長です。

直接遷移型と間接遷移型のバンドギャップの違いは?

直接遷移型ではバンド端の結晶運動量がそろっているため、GaAsのように電子と正孔が効率よく光を出して再結合します。シリコンのような間接遷移型ではフォノンも必要になるため、発光は弱くなります。
