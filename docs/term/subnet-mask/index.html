サブネットマスクとは

さぶねっとますく

IPアドレスのうち、上位の何ビットがネットワークを表す部分(ネットワーク部)かを示す32ビットの値。255.255.255.0 のように書き、CIDR表記の /24 と同じ意味になる。

やさしい解説で読む: IPアドレスとは? ネットの住所のしくみとIPv4・IPv6

「サブネットマスク」は、2分野の8問の練習問題に出てきます(ネットワークの基礎, ネットワークの設計と運用など)。

この用語の分野: ネットワークの基礎

ネットワーク部とホスト部

IPv4アドレスの32ビットは、どのネットワークかを表すネットワーク部と、その中のどの機器かを表すホスト部に分かれます。サブネットマスクは、ネットワーク部を1、ホスト部を0にした値です。IPアドレスとサブネットマスクのビットごとのANDをとるとネットワークアドレスが求まり、端末はこれを使って、宛先が同じネットワークにあるか(直接送れるか)、デフォルトゲートウェイに渡すべきかを判断します。

収容できるホストの数の計算

ホスト部が h ビットのとき、アドレスは 2^h 個ありますが、ホスト部がすべて0のネットワークアドレスと、すべて1のブロードキャストアドレスは機器に割り当てられないため、使えるのは 2^h − 2 個です。例えば 255.255.255.192(/26)はホスト部6ビットで 64 − 2 = 62 個、255.255.254.0(/23)はホスト部9ビットで 512 − 2 = 510 個です。

CIDR表記との関係

サブネットマスクの1の数を「/」の後に書いたものがCIDR表記のプレフィックス長で、255.255.255.0 は /24、255.255.240.0 は /20 です。マスクの1は必ず上位から連続して並ぶので、プレフィックス長だけで同じ情報を表せます。IPv6ではサブネットマスクの書き方は使わず、2001:db8::/64 のようにプレフィックス長で表します。

サブネットマスクの練習問題に挑戦

IPアドレスが 192.168.1.10、サブネットマスクが 255.255.255.0 の端末が属するネットワークのネットワークアドレスはどれか。

  1. A192.168.0.0
  2. B192.168.1.0
  3. C192.168.1.255
答えと解説を見る

正解：B. 192.168.1.0

サブネットマスクは、IPアドレスの上位の何ビットがネットワークを表す部分(ネットワーク部)かを示す32ビットの値で、1が並ぶ部分がネットワーク部、0の部分がホスト部です。255.255.255.0 は上位24ビットが1なので、CIDR表記では 192.168.1.0/24 のように「/24」と書きます。IPアドレスとサブネットマスクのビットごとのANDをとるとホスト部が0になり、ネットワークアドレス 192.168.1.0 が得られます。ホスト部をすべて1にした 192.168.1.255 はブロードキャストアドレスで、端末には割り当てません。

CIDR表記の /20 をサブネットマスクで表したものはどれか。

  1. A255.255.240.0
  2. B255.255.255.240
  3. C255.255.248.0
答えと解説を見る

正解：A. 255.255.240.0

/20 は上位20ビットが1のマスクです。最初の16ビットで 255.255 となり、残りの4ビットは第3オクテットの上位4ビットに入ります。2進数の 11110000 は 128 + 64 + 32 + 16 = 240 なので、サブネットマスクは 255.255.240.0 です。ホスト部は12ビットで、2^12 − 2 = 4094 台を収容できます。255.255.255.240 は上位28ビットが1の /28、255.255.248.0 は上位21ビットが1の /21 です。

よくある質問

255.255.255.0 のサブネットマスクで使えるホストはいくつですか?

ホスト部が8ビットなので、2^8 − 2 = 254 個です。ネットワークアドレス(末尾0)とブロードキャストアドレス(末尾255)の2つは機器に割り当てられません。

サブネットマスクからネットワークアドレスを求めるには?

IPアドレスとサブネットマスクをビットごとにANDします。例えば 192.168.10.77 と 255.255.255.224 では、第4オクテットが 77 AND 224 = 64 となり、ネットワークアドレスは 192.168.10.64 です。

「サブネットマスク」が出てくる問題(8問)

  1. IPアドレスが 192.168.1.10、サブネットマスクが 255.255.255.0 の端末が属するネットワークのネットワークアドレスはどれか。
  2. CIDR表記の /20 をサブネットマスクで表したものはどれか。
  3. 192.168.5.0/26 のネットワークで、ホスト(端末やルータのインターフェース)に割り当てられるIPアドレスはいくつか。
  4. IPアドレス 192.168.10.77/27 の端末が属するサブネットのブロードキャストアドレスはどれか。
  5. 1つのサブネットに500台のホストを収容したい。これを満たすサブネットのうち、最も小さいもの(プレフィックス長が最も長いもの)はどれか。
  6. 端末(192.168.1.10/24、デフォルトゲートウェイ 192.168.1.1)が、別のネットワークにあるサーバ 203.0.113.80 にパケットを送る。ARPのキャッシュが空のとき、端末がARPでMACアドレスを調べる相手はどれか。
  7. DHCPで端末がIPアドレスを得るときの、メッセージの順序として正しいものはどれか。
  8. 192.168.10.0/24 を、拠点A(ホスト100台)、拠点B(50台)、拠点C(25台)のサブネットに分ける。必要なホストの数の多い拠点から順に、そのホストを収容できる最も小さいサブネットを、アドレスの小さい方から詰めて割り当てる。拠点Cに割り当てるサブネットはどれか。
