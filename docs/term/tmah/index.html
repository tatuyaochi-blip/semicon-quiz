TMAHとは

てぃーえむえーえいち

水酸化テトラメチルアンモニウム。金属イオンを含まない有機アルカリで、フォトレジストの現像液に使われる。皮膚からの吸収による中毒に注意が必要。

「TMAH」は、3分野の4問の練習問題に出てきます(プロセス材料(ガス・薬液), 環境安全, リソグラフィなど)。

この用語の分野: プロセス材料(ガス・薬液)

TMAHの練習問題に挑戦

半導体の現像液に、水酸化ナトリウムなどではなくTMAHのような有機アルカリが使われる主な理由はどれか。

  1. ATMAHの方が強い色をもつため
  2. BTMAHの方が必ず安価なため
  3. Cナトリウムなどの金属イオンによる汚染を避けるため
答えと解説を見る

正解：C. ナトリウムなどの金属イオンによる汚染を避けるため

ナトリウムやカリウムなどのアルカリ金属イオンは、酸化膜中を電界で動く可動イオンとなり、トランジスタのしきい値電圧を変動させます。初期のMOSデバイスが不安定だった主な原因がこのナトリウム汚染でした。TMAHは金属を含まない有機アルカリなので、こうした汚染の心配がありません。色や価格が選ばれる理由ではなく、TMAHが必ず安価なわけでもありません。

現像液に使われるTMAH(水酸化テトラメチルアンモニウム)の高濃度液が皮膚に付いた場合に特に危険とされる理由はどれか。

  1. A強い放射線を出すため
  2. B皮膚から吸収されて神経や筋肉の働きを妨げ、呼吸が止まるなどの全身の中毒を起こすおそれがあるため
  3. Cすぐに凍りついて凍傷を起こすため
答えと解説を見る

正解：B. 皮膚から吸収されて神経や筋肉の働きを妨げ、呼吸が止まるなどの全身の中毒を起こすおそれがあるため

TMAHは強いアルカリで皮膚を傷めるだけでなく、皮膚から吸収されたテトラメチルアンモニウムイオンが神経から筋肉への信号の伝達を妨げ、呼吸の停止などを起こすことがあります。現像に使う2.38%の液より、原液に近い25%程度の高濃度液が特に危険で、台湾などで接触による死亡事故が報告されています。保護具の着用と、付着したときのただちの洗浄と受診が重要です。

解説の中の「TMAH」

  • TMAHは金属を含まない有機アルカリなので、こうした汚染の心配がありません。

    半導体の現像液に、水酸化ナトリウムなどではなくTMAHのような有機アルカリが使われる主な理由はどれか。

  • TMAHは強いアルカリで皮膚を傷めるだけでなく、皮膚から吸収されたテトラメチルアンモニウムイオンが神経から筋肉への信号の伝達を妨げ、呼吸の停止などを起こすことがあります。

    現像液に使われるTMAH(水酸化テトラメチルアンモニウム)の高濃度液が皮膚に付いた場合に特に危険とされる理由はどれか。

  • i線用のノボラック樹脂系や、KrF・ArF用の化学増幅型が代表的で、アルカリ性の現像液(TMAH水溶液)で現像します。

    ポジ型フォトレジストの説明として正しいものはどれか。

  • ポジ型レジストの現像には、TMAHの2.38%水溶液(約0.26 N)が業界の標準として使われます。

    フォトレジストの現像に一般的に使われる水溶液はどれか。
