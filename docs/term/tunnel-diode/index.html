トンネルダイオード(エサキダイオード)とは

とんねるだいおーど

両側を非常に高濃度にしたPN接合で、トンネル効果によって順方向に負性抵抗の領域が現れるダイオード。1957年に江崎玲於奈が発見した。

「トンネルダイオード(エサキダイオード)」は、2分野の2問の練習問題に出てきます(半導体物性, PN接合・ダイオードなど)。

この用語の分野: PN接合・ダイオード

トンネルダイオード(エサキダイオード)の練習問題に挑戦

不純物濃度が非常に高く、フェルミ準位が伝導帯や価電子帯の中に入り込んだ半導体を何と呼ぶか。

  1. A真性半導体
  2. B絶縁体
  3. C縮退半導体
答えと解説を見る

正解：C. 縮退半導体

不純物濃度が非常に高く(シリコンではおよそ10¹⁸〜10¹⁹ cm⁻³以上)なると、フェルミ準位が伝導帯や価電子帯の中に入り、金属に近い性質を示します。これが縮退半導体で、n × p = ni² の簡単な式が成り立たなくなり、バンドギャップも見かけ上小さくなります(バンドギャップ狭窄)。MOSFETのソース・ドレインや、電極との低抵抗接触、トンネルダイオードの高濃度領域がその例です。

両側を非常に高濃度にしたPN接合で、順方向電圧を上げると電流が減る負性抵抗の領域が現れるダイオードはどれか。

  1. Aショットキーバリアダイオード
  2. BPINダイオード
  3. Cトンネルダイオード(エサキダイオード)
答えと解説を見る

正解：C. トンネルダイオード(エサキダイオード)

トンネルダイオードは、両側を縮退するほど高濃度にしたPN接合で、空乏層が非常に薄いため順方向の低い電圧でトンネル電流が流れます。電圧を上げると、n側の電子とp側の空いた準位のエネルギーがずれてトンネル電流が減り、負性抵抗領域が現れます。1957年に江崎玲於奈氏が発見し、1973年にノーベル物理学賞を受けました。トンネル効果を電子素子で初めて示した例です。

解説の中の「トンネルダイオード(エサキダイオード)」

  • MOSFETのソース・ドレインや、電極との低抵抗接触、トンネルダイオードの高濃度領域がその例です。
