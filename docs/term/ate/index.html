ATE(自動試験装置)とは

えーてぃーいー

チップに試験パターンを与えて出力を測り、良否を自動で判定する装置。テスタとも呼ばれる。

「ATE(自動試験装置)」は、1分野の1問の練習問題に出てきます(テスト・検査など)。

この用語の分野: テスト・検査

テスタの役割

自動試験装置(ATE)は、被試験デバイス(DUT)に電源と信号を与えて応答を測定し、期待値と比較して、良品・不良品や性能ごとのビンに仕分けます。各ステップの順序はテストプログラムで決めます。テスタには数百〜数千のチャネルがあり、各ピンの回路は、設定したタイミングで論理レベルを入力したり、ストローブのタイミングで出力を期待値と比較したりできます。さらにピンごとのパラメトリック測定ユニット(PMU)で、電圧を印加して電流を測る、あるいは電流を流して電圧を測ることもできます。デバイス電源は電源レールへの供給と監視を行います。

ウエハテストとファイナルテスト

ATEは主に2つの段階で使われます。ウエハテスト(ウエハソート)では、プローバがウエハを順に送り、プローブカードの針を各チップの数十µm角のパッドに接触させます。プローブ痕が後のワイヤボンディングやバンプ形成に支障をきたさないよう検査も行います。不良チップにはマークを付け、パッケージに組み立てないようにします。ファイナルテストでは、ハンドラがパッケージ品をロードボード上のソケットに入れ、多くの場合は高温や低温の条件で試験し、結果に応じて仕分けます。

何を試験するのか

一般的なテストフローは、オープン・ショートを調べる導通チェックから始まり、リーク電流や電源電流などのDCパラメトリック試験、そして機能試験と構造試験へと進みます。デジタルロジックでは、自動テストパターン生成(ATPG)で作ったスキャンパターンで製造欠陥を検出し、実動作速度で試験することもよくあります。メモリはアルゴリズミックパターンや組み込み自己テスト(BIST)で試験します。アナログ、ミックスドシグナル、RFのデバイスには直線性、雑音、周波数特性を測る計測器が必要なため、テスタはロジック・SoC用、メモリ用、ミックスドシグナル用、RF用などに分かれています。

テストコスト

テスタは高価なため、テストコストはおおよそテスト時間とテスタの秒あたりコストの積になります。メーカーは、複数のデバイスを並列に試験するマルチサイトテスト、冗長な試験の削減、テスト容易化設計(DFT)機能の追加によってコストを下げています。スキャンチェーン、テスト圧縮、BISTを使えば、比較的少ないテスタピンと小さなパターンメモリで大規模なチップを試験でき、少ピン数テストにより安価なテスタでも一度に多くのサイトを扱えます。

ATE(自動試験装置)の練習問題に挑戦

ATE(自動試験装置)の説明として正しいものはどれか。

  1. Aテストパターンを入力し、出力を期待値と比較して良否を判定する装置
  2. Bウエハに回路パターンを露光する装置
  3. Cウエハを洗浄する装置
答えと解説を見る

正解：A. テストパターンを入力し、出力を期待値と比較して良否を判定する装置

ATE(Automatic Test Equipment)は、テスト対象のチップに電源や信号を与え、出力を測定して期待値と比べ、良否を判定する装置です。ピンごとに信号の発生、電圧・電流の測定、タイミングの判定ができる回路を数百〜数千チャンネル備えています。ウエハテストではプローバ、最終テストではハンドラと組み合わせて使います。露光や洗浄は前工程の装置の仕事です。

よくある質問

半導体のATEとは何の略ですか?

ATEはAutomatic Test Equipment(自動試験装置)の略です。チップに試験パターンを与えて出力を測定し、良否を自動で判定するテスタを指します。

プローバとハンドラの違いは?

どちらもATEにデバイスを供給する装置です。プローバはウエハレベルのテストのためにウエハをプローブカードの下に位置決めし、ハンドラはファイナルテストでパッケージ品をテストソケットに置き、試験後に仕分けます。

テスト容易化設計(DFT)でATEのコストが下がるのはなぜですか?

スキャンチェーン、テスト圧縮、組み込み自己テストなどの構造により、チップが自分自身を試験したり、少ないピンで試験できたりするようになるからです。テスト時間が短くなり、安価な装置でより多くのデバイスを並列に試験できます。
