スティクションとは

すてぃくしょん

MEMSの微小な可動部が、表面張力や表面の吸着力によって基板に張り付き、動かなくなる現象。犠牲層を除去した後の乾燥などで起こりやすい。

この用語の分野: MEMS・センサ

解説の中の「スティクション」

  • これがスティクションで、製造時の乾燥で起こるものと、使用中の接触で起こるものがあります。

    MEMSの製造中や使用中に、微小な可動部が表面張力などによって基板に張り付き、動かなくなる現象を何と呼ぶか。

  • 酸化膜や窒化膜、レジスト、多くの金属に対する選択比が1000以上と非常に高く、液体を使わないためスティクションが起きにくいことから、MEMSの構造をシリコンの犠牲層から解放するのに使われます。

    MEMSの犠牲層除去などで、プラズマを使わずにシリコンを等方的にエッチングできる気体はどれか。

  • ウィスカはスズめっきから伸びる針状の結晶、スティクションはMEMSの張り付きです。

    吸湿した樹脂パッケージをはんだリフローで加熱したとき、内部の水分が急に気化して膨張し、パッケージが割れる現象を何と呼ぶ…

「スティクション」が出てくる問題(4問)

  1. SiO2の犠牲層を除去してMEMS構造を浮かせるとき、スティクションを防ぐために使われる方法として適切なものはどれか。
  2. MEMSの製造中や使用中に、微小な可動部が表面張力などによって基板に張り付き、動かなくなる現象を何と呼ぶか。
  3. MEMSの犠牲層除去などで、プラズマを使わずにシリコンを等方的にエッチングできる気体はどれか。
  4. 吸湿した樹脂パッケージをはんだリフローで加熱したとき、内部の水分が急に気化して膨張し、パッケージが割れる現象を何と呼ぶか。
