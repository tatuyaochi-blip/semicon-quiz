スティクションとは

すてぃくしょん

MEMSの微小な可動部が、表面張力や表面の吸着力によって基板に張り付き、動かなくなる現象。犠牲層を除去した後の乾燥などで起こりやすい。

「スティクション」は、3分野の4問の練習問題に出てきます(MEMS・センサ, エッチング, パッケージ・実装など)。

この用語の分野: MEMS・センサ

微小な構造が張り付く理由

スティクションは微細化に伴って生じる現象です。液膜による毛管力、ファンデルワールス力、トラップされた電荷による静電引力、親水性表面どうしの水素結合といった付着力は、接触面積とともに大きくなります。一方、薄く柔らかい梁やメンブレンの復元力は比較的弱く、リリースされたMEMS構造の下の隙間は1 µm程度しかないことも珍しくありません。このような狭い隙間を隔てた大きく平坦で滑らかな面は接触しやすく、いったん触れると、付着力が引き離そうとするばね力を上回ることがあります。

製造中のリリーススティクション

典型的なのはリリース時です。多くの場合SiO2でできた犠牲層を液体のHFでエッチング除去し、リンスします。狭い隙間からリンス液が蒸発するとき、メニスカスが構造を基板側へ引き寄せ、乾燥後も面が張り付いたままになります。対策は液体と気体の界面を作らないことです。超臨界CO2乾燥ではメニスカスを生じずに液体から気体へ移行でき、気相HFは液体を使わずに酸化膜を除去します。XeF2ガスはプラズマなしでシリコン犠牲層を等方的にエッチングし、酸化膜、窒化膜、多くの金属に対して1000以上の選択比をもちます。

使用中のスティクションと対策

スティクションは出荷後に起こることもあります。衝撃で加速度センサのプルーフマスがストッパに当たったり、RF MEMSスイッチの接点が何百万回も開閉したりするうえ、湿気やトラップ電荷のために、それまで離れていた接点が張り付いたままになることがあります。対策として、可動部に小さな突起(ディンプル)を設けて接触面積を減らす、表面エネルギーを下げる疎水性の自己組織化単分子膜をコーティングする、十分な復元力をもつストッパを設計する、乾燥した気密パッケージに封止して毛管架橋の原因となる水分がたまらないようにする、といった方法がとられます。

スティクションとプルインの違い

スティクションは、静電的な不安定現象であるプルインとよく混同されます。平行平板型の静電アクチュエータでは、可動電極が隙間の約3分の1まで動くと静電力がばね力より速く増え、電極が一気に引き込まれます。これは完全に清浄で付着性のない表面でも起こります。プルインは電圧を取り除けば元に戻りますが、その後も面が付着したままなら、デバイスはスティクションで故障したことになります。プルインは電圧、ギャップ、剛性で決まり、スティクションは表面力で決まります。

スティクションの練習問題に挑戦

SiO2の犠牲層を除去してMEMS構造を浮かせるとき、スティクションを防ぐために使われる方法として適切なものはどれか。

  1. A大量の水で洗い流し、自然乾燥させる
  2. B研磨して除去する
  3. Cフッ化水素(HF)の蒸気による気相エッチング
答えと解説を見る

正解：C. フッ化水素(HF)の蒸気による気相エッチング

液体のフッ酸で犠牲層を除去すると、乾燥時に可動部と基板の間に残った液体の表面張力で構造が引き寄せられ、張り付くことがあります。HFの蒸気を使った気相エッチングでは、液体を使わないためこの力が生じません。少量の水分やアルコールを加えて反応を制御し、反応で生じる水が凝縮しないよう温度を管理します。超臨界二酸化炭素による乾燥も、液体と気体の境界をなくして同じ問題を防ぎます。

よくある質問

スティクションという言葉の由来は?

static friction(静止摩擦)を組み合わせた造語です。MEMSでは、より広く、可動部を面に押し付けて自由に動けなくするあらゆる付着を指します。

MEMSのスティクションはどう防ぎますか?

リリース時には、気相HF、XeF2エッチング、超臨界CO2乾燥など、液体やメニスカスを使わない方法を用います。動作中は、ディンプル、疎水性のスティクション防止コーティング、乾燥した気密パッケージによって面の張り付きを防ぎます。

スティクションが大きな機械よりMEMSで問題になるのはなぜですか?

表面力は面積に比例し、慣性力や復元力は体積や剛性に比例するため、マイクロメートルスケールでは表面力が支配的になります。大きな機械では、同じ力は重さやばね力に比べて無視できるほど小さくなります。
