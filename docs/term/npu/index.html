NPU(ニューラルプロセッシングユニット)とは

えぬぴーゆー

AIのニューラルネットワークの推論処理を、高速かつ低い消費電力で行うための専用回路。スマートフォンやパソコンのSoCに搭載されている。

「NPU(ニューラルプロセッシングユニット)」は、2分野の6問の練習問題に出てきます(AIハードウェアとソフトウェアスタック, CPU・アーキテクチャなど)。

この用語の分野: CPU・アーキテクチャ

NPU(ニューラルプロセッシングユニット)の練習問題に挑戦

スマートフォンのSoCに載るNPUが、AIの推論でCPUより電力の効率が高い主な理由はどれか。

  1. ANPUは電気を使わずに光で計算するから
  2. BINT8などの低い精度の積和の演算器を多数並べ、AIの計算に必要のない汎用の回路を省いているから
  3. CNPUはCPUより必ず高いクロックで動くから
答えと解説を見る

正解：B. INT8などの低い精度の積和の演算器を多数並べ、AIの計算に必要のない汎用の回路を省いているから

CPUは何でも実行できるよう、分岐予測や命令の並べ替えなど、命令ごとに多くの回路を動かします。NPUは行列の積和に特化し、低い精度の演算器を多数並べて、データをチップの中で使い回すように作られているので、1回の演算にかかるエネルギーが桁違いに小さくなります。その分、AI以外の処理や、対応していない演算には向きません。

解説の中の「NPU(ニューラルプロセッシングユニット)」

  • NPUは行列の積和に特化し、低い精度の演算器を多数並べて、データをチップの中で使い回すように作られているので、1回の演算にかかるエネルギーが桁違いに小さくなります。

    スマートフォンのSoCに載るNPUが、AIの推論でCPUより電力の効率が高い主な理由はどれか。

  • NPUは、ニューラルネットワークの計算の大部分を占める積和演算を、8ビット以下の整数など低い精度で大量に並列処理する専用回路です。

    AIの推論処理を高速かつ低い消費電力で行うために、スマートフォン用のSoCなどに搭載される専用回路はどれか。

  • AIコンパイラは、モデルを演算とデータの流れの計算グラフとして受け取り、まとめられる演算の融合、不要な計算の削除、メモリの並べ方の選択、タイルの大きさの調整などを行い、GPUやNPUなどの対象に合ったカーネルを作ります。

    XLAやTVM、PyTorchのコンパイル機能のようなAIコンパイラが行う主な処理として正しいものはどれか。

  • 推論ランタイムはモデルを読み込んだ後、推論に不要な部分を除き、演算を融合し、必要に応じて重みや活性化を低い精度に変え、対象のGPUやNPUで最も速いカーネルを選びます。

    TensorRTやONNX Runtimeのような推論ランタイムが、学習用のフレームワークでそのまま推論するより速くで…

  • 量子化や小さなモデルへの蒸留、NPUのような電力の効率の高い専用回路を使って、制約の中で動かします。

    AIの推論をクラウドのサーバではなく、スマートフォンなどの端末の中(エッジ)で行う利点として当てはまらないものはどれか。

「NPU(ニューラルプロセッシングユニット)」が出てくる問題(6問)

  1. スマートフォンのSoCに載るNPUが、AIの推論でCPUより電力の効率が高い主な理由はどれか。
  2. AIの推論処理を高速かつ低い消費電力で行うために、スマートフォン用のSoCなどに搭載される専用回路はどれか。
  3. XLAやTVM、PyTorchのコンパイル機能のようなAIコンパイラが行う主な処理として正しいものはどれか。
  4. TensorRTやONNX Runtimeのような推論ランタイムが、学習用のフレームワークでそのまま推論するより速くできる主な理由はどれか。
  5. AIの推論をクラウドのサーバではなく、スマートフォンなどの端末の中(エッジ)で行う利点として当てはまらないものはどれか。
  6. AIのソフトウェアスタックを、利用者に近い上の層からハードウェアに近い下の層へ並べたものとして正しいものはどれか。
