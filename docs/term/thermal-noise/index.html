熱雑音(ジョンソン雑音)とは

ねつざつおん

抵抗の中の電子の熱運動によって生じる雑音。電圧の2乗平均は 4kTRΔf で、温度、抵抗値、帯域幅に比例する。

この用語の分野: アナログ・電子回路

解説の中の「熱雑音(ジョンソン雑音)」

  • 熱雑音の電圧は √(4kTRB) で、抵抗が大きく、温度が高く、帯域が広いほど大きくなります。

    抵抗で発生する熱雑音(ジョンソン雑音)の電圧を大きくする要因として正しいものはどれか。

  • スイッチの抵抗が大きいほど熱雑音の密度は大きくなりますが、同時にRC回路の帯域が狭くなって打ち消し合い、コンデンサに残る雑音の実効値は √(kT/C) になります(kT/C雑音)。

    スイッチとコンデンサCで電圧をサンプリングしたときに、コンデンサに残る熱雑音の電圧(実効値)として正しいものはどれか。…

  • 熱雑音と同じ大きさになる周波数(コーナー周波数)は数kHz〜数MHzに及ぶことがあります。

    MOSFETで特に目立つ、周波数が低いほど大きくなる雑音はどれか。

「熱雑音(ジョンソン雑音)」が出てくる問題(4問)

  1. 抵抗で発生する熱雑音(ジョンソン雑音)の電圧を大きくする要因として正しいものはどれか。
  2. スイッチとコンデンサCで電圧をサンプリングしたときに、コンデンサに残る熱雑音の電圧(実効値)として正しいものはどれか。(k:ボルツマン定数、T:絶対温度)
  3. MOSFETで特に目立つ、周波数が低いほど大きくなる雑音はどれか。
  4. 理想的なNビットADコンバータの、量子化雑音によって決まる信号対雑音比(SNR)の近似式はどれか。(フルスケールの正弦波入力の場合)
