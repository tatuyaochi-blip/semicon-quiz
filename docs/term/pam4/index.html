PAM4とは

ぱむふぉー

4段階の電圧で1つの記号あたり2ビットを送る変調方式。同じ記号の速さでビットの速さを2倍にできるが、雑音の余裕が小さくなる。

「PAM4」は、2分野の5問の練習問題に出てきます(インターフェース・バス規格, シリコンフォトニクスなど)。

この用語の分野: インターフェース・バス規格

PAM4の練習問題に挑戦

データセンター内の光接続で広く使われる強度変調・直接検波(IM-DD)方式でPAM4を使う場合、4つの値として変えているものはどれか。

  1. A光の位相
  2. B光の偏光の向き
  3. C光の強さ(パワー)
答えと解説を見る

正解：C. 光の強さ(パワー)

IM-DD(Intensity Modulation / Direct Detection)では、送信側で光の強さを変調し、受信側ではフォトダイオードで光の強さを直接電流に変えて判定します。PAM4では光の強さを4段階に変え、1つの記号で2ビットを送ります。受光器は光の強さしか検出できませんが、そのぶん構成が簡単で、低コスト・低消費電力です。光の位相や偏光にも情報を乗せるには、受信側で別のレーザーの光と干渉させて検出するコヒーレント方式が必要で、回路が複雑になります。

PAM4で、1波長あたり約106 Gb/s(誤り訂正の符号などを含む)の信号を送るときのシンボルレート(1秒あたりの記号の数)に最も近いものはどれか。

  1. A約53 GBd
  2. B約106 GBd
  3. C約27 GBd
答えと解説を見る

正解：A. 約53 GBd

PAM4は4つの値で1記号あたり2ビットを運ぶため、シンボルレートはビットレートの半分の約53 GBd(ギガボー)です。同じビットレートをNRZ(2値)で送ると約106 GBdが必要で、それだけ広い帯域の変調器や受光器、電気回路が求められます。一方、PAM4では記号を4段階に分けるため、隣り合う値の間隔がNRZの約3分の1になり、雑音の影響を受けやすくなります。約27 GBdは、1記号で4ビットを送る16値の変調の場合の値です。

「PAM4」が出てくる問題(5問)

  1. データセンター内の光接続で広く使われる強度変調・直接検波(IM-DD)方式でPAM4を使う場合、4つの値として変えているものはどれか。
  2. PAM4で、1波長あたり約106 Gb/s(誤り訂正の符号などを含む)の信号を送るときのシンボルレート(1秒あたりの記号の数)に最も近いものはどれか。
  3. PCI Express 6.0で採用されたPAM4(4値パルス振幅変調)の特徴として正しいものはどれか。
  4. PAM4を使うと、NRZに比べて誤り訂正(FEC)がより重要になる理由として正しいものはどれか。
  5. 100ギガビットのイーサネットのような高速な接続が、例えば25 Gb/sのレーンを4本束ねて作られることがある。この考え方として正しいものはどれか。
