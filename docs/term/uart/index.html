UARTとは

ゆーあーと

クロックの線を使わず、送る側と受ける側が同じボーレートに合わせて通信する非同期式のシリアル通信の回路。スタートビットとストップビットで文字を区切る。

「UART」は、3分野の8問の練習問題に出てきます(組込み・ファームウェア, CPU・アーキテクチャ, 電力管理(ソフトウェア制御)など)。

この用語の分野: 組込み・ファームウェア

UARTの練習問題に挑戦

UARTによるシリアル通信の特徴として正しいものはどれか。

  1. A送る側がクロックの線を出し、受ける側はそのクロックでデータを読む
  2. Bクロックの線を使わず、送る側と受ける側が同じ通信速度(ボーレート)に合わせ、スタートビットで区切りを知らせる
  3. C1本の線に多数の機器をつなぎ、アドレスで相手を選ぶ
答えと解説を見る

正解：B. クロックの線を使わず、送る側と受ける側が同じ通信速度(ボーレート)に合わせ、スタートビットで区切りを知らせる

UARTは、送信と受信の2本の線(とグラウンド)で通信する非同期式のシリアル通信です。何も送らないときは1の状態で、0のスタートビットで文字の始まりを知らせ、データのビットに続いて1のストップビットで終わります。クロックを送らないので、両方が115200 bpsなどの同じ速度に設定しておく必要があります。デバッグ用の出力やGPS、無線のモジュールとの接続によく使われます。

115200 bpsのUARTで、データ8ビット・パリティなし・ストップビット1(8N1)の形式で送るとき、1秒間に送れるバイト数に最も近いものはどれか。

  1. A約14400バイト
  2. B約11500バイト
  3. C約115200バイト
答えと解説を見る

正解：B. 約11500バイト

8N1の形式では、1バイトのデータを送るのにスタートビット1、データ8、ストップビット1の合計10ビットが必要です。115200÷10=11520なので、1秒間に約11500バイト、1バイトあたり約87 µsかかります。ログを大量に出すと思ったより時間がかかり、処理の遅れの原因になることがあるので、出力の量やバッファの使い方に注意が必要です。

「UART」が出てくる問題(8問)

  1. UARTによるシリアル通信の特徴として正しいものはどれか。
  2. 115200 bpsのUARTで、データ8ビット・パリティなし・ストップビット1(8N1)の形式で送るとき、1秒間に送れるバイト数に最も近いものはどれか。
  3. UARTの送信側と受信側のボーレートが少しずれていると、文字化けが起こることがある。ずれの許容範囲がおよそ数%程度に限られる理由として正しいものはどれか。
  4. UART・SPI・I2Cを比べた説明として正しいものはどれか。
  5. マイコンで消費電力を減らすために、使っていない周辺回路(タイマやUARTなど)について行うこととして正しいものはどれか。
  6. CPU、メモリ、タイマーやADCなどの周辺機能を1チップにまとめ、家電や機器の制御に使われるLSIはどれか。
  7. マイコンなどで、周辺機器のレジスタをメモリと同じアドレス空間に割り当て、通常のメモリ読み書き命令で操作する方式はどれか。
  8. 組込み機器のブートローダの役割として正しいものはどれか。
