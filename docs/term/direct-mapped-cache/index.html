ダイレクトマップ方式とは

だいれくとまっぷほうしき

各アドレスのデータを置けるキャッシュ上の場所が1か所に決まっているキャッシュの構成。回路が単純でヒット時間が短いが、同じ場所を取り合う競合ミスが起こりやすい。

この用語の分野: メモリ階層と性能

解説の中の「ダイレクトマップ方式」

  • 例えば8ウェイなら8か所の候補があり、ダイレクトマップ方式より同じ場所の取り合い(競合ミス)を減らせます。

    セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。

  • ダイレクトマップ方式などでは、同じセットを取り合うデータが追い出し合い、追い出したばかりのラインをすぐにまた使うことがよくあります。

    小容量のフルアソシアティブ方式のバッファに、L1キャッシュから追い出されたラインを一時的に保持するビクティムキャッシュ…

  • キャッシュ全体のライン数だけ比べるのはフルアソシアティブ方式、1個だけ比べるのはダイレクトマップ方式です。

    8ウェイ・セットアソシアティブ方式のキャッシュで、1回のアクセスのたびに並列に比べるタグの数はいくつか。

「ダイレクトマップ方式」が出てくる問題(6問)

  1. アドレスが32ビット、容量32 KB、ラインサイズ64バイトのダイレクトマップ方式のキャッシュで、タグは何ビットになるか。
  2. ダイレクトマップ方式のキャッシュで、2つの配列の要素が同じキャッシュの位置に対応し、交互にアクセスするたびに互いを追い出し合っている。このミスの分類はどれか。
  3. ダイレクトマップ方式からセットアソシアティブ方式に変えたときに起こる変化として、正しいものはどれか。
  4. セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。
  5. 小容量のフルアソシアティブ方式のバッファに、L1キャッシュから追い出されたラインを一時的に保持するビクティムキャッシュの主な効果はどれか。
  6. 8ウェイ・セットアソシアティブ方式のキャッシュで、1回のアクセスのたびに並列に比べるタグの数はいくつか。
