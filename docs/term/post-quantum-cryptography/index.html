耐量子計算機暗号とは

たいりょうしけいさんきあんごう

量子コンピュータでも効率よく解けないと考えられている数学の問題(格子の問題、ハッシュ関数など)に安全性の根拠を置く暗号。従来のコンピュータで動作し、ショアのアルゴリズムで破られる RSA暗号や楕円曲線暗号を置き換えるために使われる。

「耐量子計算機暗号」は、3分野の8問の練習問題に出てきます(暗号技術の基礎と応用, 量子コンピュータのハードウェア, ハードウェアセキュリティの最新動向など)。

この用語の分野: 量子コンピュータのハードウェア

なぜ必要か

現在広く使われている RSA暗号や楕円曲線暗号は、大規模な誤り耐性量子コンピュータがあれば、ショアのアルゴリズムで破られてしまいます。そうした量子コンピュータはまだありませんが、今記録された暗号文が将来解読される「ハーベスト・ナウ、ディクリプト・レイター」の危険があり、暗号の入れ替えにも長い年月がかかります。そのため、量子コンピュータが実現する前から移行を始める必要があります。

主な方式と標準

米国の NIST は2024年に、格子に基づく鍵カプセル化方式 ML-KEM(FIPS 203)、格子に基づく署名方式 ML-DSA(FIPS 204)、ハッシュ関数に基づく署名方式 SLH-DSA(FIPS 205)を標準として公表しました。これらは鍵や署名が従来より大きく、例えば ML-KEM-768 の公開鍵は1,184バイトで、楕円曲線の鍵交換 X25519 の32バイトよりずっと大きくなります。ML-DSA-65 の署名も3,309バイトあります。

ハードウェアと移行

鍵や署名が大きく、計算の性質も違うので、メモリの少ない組込み機器や IC カード、通信プロトコルのパケットの大きさなどへの影響を確かめながら移行します。格子暗号では多項式の掛け算を数論変換(NTT)で速くするので、専用の回路による高速化も研究されています。実装では、消費電力や処理時間から秘密の情報が漏れるサイドチャネル攻撃への対策も必要です。当面は、従来の暗号と組み合わせたハイブリッド方式で段階的に移行し、暗号を後から入れ替えやすい設計(クリプトアジリティ)が重視されています。

耐量子計算機暗号の練習問題に挑戦

耐量子計算機暗号(ポスト量子暗号、PQC)の説明として正しいものはどれか。

  1. A従来のコンピュータで動作し、量子コンピュータでも効率よく解けないと考えられている数学の問題(格子の問題など)に安全性の根拠を置く暗号
  2. B量子コンピュータを使わないと、暗号化も復号もできない暗号
  3. CRSA暗号の鍵の長さを2倍にしただけの暗号
答えと解説を見る

正解：A. 従来のコンピュータで動作し、量子コンピュータでも効率よく解けないと考えられている数学の問題(格子の問題など)に安全性の根拠を置く暗号

耐量子計算機暗号は、ショアのアルゴリズムで解けてしまう素因数分解や離散対数問題の代わりに、格子の問題やハッシュ関数などに基づく暗号で、現在のコンピュータやネットワーク機器でそのまま動きます。米国の NIST は2024年に、格子に基づく鍵カプセル化方式 ML-KEM(FIPS 203)や署名方式 ML-DSA(FIPS 204)などを標準として公表しました。鍵や署名のサイズが RSA暗号や楕円曲線暗号より大きくなるものが多いので、通信プロトコルや組込み機器、ハードウェアでの実装への影響を考えながら移行を進めます。量子の性質そのものを使って鍵を共有する量子鍵配送(QKD)とは、別の技術です。

大規模な量子コンピュータがまだ実現していない段階から、耐量子計算機暗号への移行を急ぐ理由として、最も適切なものはどれか。

  1. A2020年代半ばの量子コンピュータで、すでに RSA-2048 が日常的に解読されているから
  2. B耐量子計算機暗号に切り替えると、通信の速度が必ず速くなるから
  3. C今盗聴して保存した暗号文を将来の量子コンピュータで解読されるおそれがあり(ハーベスト・ナウ、ディクリプト・レイター)、暗号の移行には長い年月がかかるから
答えと解説を見る

正解：C. 今盗聴して保存した暗号文を将来の量子コンピュータで解読されるおそれがあり(ハーベスト・ナウ、ディクリプト・レイター)、暗号の移行には長い年月がかかるから

攻撃者は、今のうちに暗号化された通信を記録しておき、将来量子コンピュータが実用になったときに鍵交換を解いて、中身を読むことができます。そのため、長い期間秘密にすべき情報は、量子コンピュータが実現する前から耐量子計算機暗号で守る必要があります。また、暗号は OS、ブラウザ、ネットワーク機器、ICカード、組込み機器のファームウェアやハードウェアに組み込まれており、すべてを入れ替えるには長い年月がかかります。従来の暗号と耐量子計算機暗号を組み合わせたハイブリッド方式で、段階的に移行する方法がとられています。

よくある質問

量子鍵配送(QKD)とはどう違いますか?

耐量子計算機暗号は、数学の問題の難しさに基づく暗号で、ふつうのコンピュータとネットワークで動きます。量子鍵配送は、光子などの量子の性質を使って鍵を共有する技術で、専用の光通信の装置が必要です。両者は別の技術で、置き換えの中心になっているのは耐量子計算機暗号です。

AES などの共通鍵暗号も置き換える必要がありますか?

共通鍵暗号に対しては、グローバーのアルゴリズムによる2乗の高速化しかないので、方式を変える必要はなく、鍵を十分長くすれば対応できると考えられています。例えば AES-256 を使えば、量子コンピュータに対しても十分な安全性が保てるとされています。

「耐量子計算機暗号」が出てくる問題(8問)

  1. 耐量子計算機暗号(ポスト量子暗号、PQC)の説明として正しいものはどれか。
  2. 大規模な量子コンピュータがまだ実現していない段階から、耐量子計算機暗号への移行を急ぐ理由として、最も適切なものはどれか。
  3. 米国のNISTが2024年8月に公表した耐量子計算機暗号の標準と、その種類の組み合わせとして正しいものはどれか。
  4. 耐量子計算機暗号への移行の途中で使われる、X25519(楕円曲線を使うディフィー・ヘルマン鍵交換)とML-KEMを組み合わせたハイブリッド鍵交換の考え方として、正しいものはどれか。
  5. 格子に基づく耐量子計算機暗号では、次数 n = 256 の多項式の掛け算を何度も行う。係数どうしをすべて掛け合わせる素朴な方法では約 n² 回、数論変換(NTT)を使う方法では約 n log₂ n 回の掛け算が必要とすると、NTTを使うことで掛け算の回数がおよそ何分の1になるかとして、最も近いものはどれか。
  6. 10年以上使われる組込み機器のSoCを設計する。将来の暗号の移行(耐量子計算機暗号への移行など)に備えるハードウェアとファームウェアの設計として、適切なものはどれか。
  7. 鍵長がnビットの共通鍵暗号の鍵を、量子コンピュータのグローバーのアルゴリズムで探すと、必要な計算の回数は約 2^(n/2) 回になるとされる。この単純な目安で考えたときの、量子コンピュータに対するAES-128の安全性として、最も近いものはどれか。
  8. システムの設計で、クリプトアジリティ(暗号の方式を入れ替えやすくしておく性質)を高める取り組みとして、適切なものはどれか。
