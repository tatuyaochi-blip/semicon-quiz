クロスポイント型メモリとは

くろすぽいんとがためもり

縦横の配線の交点に記憶素子を置く構造のメモリ。高密度にできるが、選択していないセルへの電流の回り込みを防ぐため、記憶素子と直列にセレクタ(選択素子)を入れる。

「クロスポイント型メモリ」は、1分野の1問の練習問題に出てきます(次世代メモリなど)。

この用語の分野: 次世代メモリ

クロスポイント型メモリの練習問題に挑戦

抵抗変化素子を縦横の配線の交点に配置するクロスポイント型メモリで、選択していないセルに電流が回り込むのを防ぐために、記憶素子と直列に入れる素子はどれか。

  1. Aキャパシタ
  2. Bインダクタ
  3. Cセレクタ(選択素子)
答えと解説を見る

正解：C. セレクタ(選択素子)

クロスポイント型は、各交点にトランジスタを置かず、記憶素子を縦横の配線の交点に直接置くため、セル面積を最小の4F²にでき、層を積み重ねることもできます。しかし選択していないセルを通るスニーク電流が読み出しを妨げるため、一定の電圧以下ではほとんど電流を流さないセレクタを直列に入れます。セレクタには、オン電流が大きくオフ電流が小さい、極めて非線形な特性が求められます。
