デフォルトゲートウェイとは

でふぉるとげーとうぇい

端末が、自分と別のネットワークにある宛先へのパケットを渡すルータ。端末はサブネットマスクで宛先が同じネットワークかを判断し、外ならこのルータに送る。

「デフォルトゲートウェイ」は、2分野の9問の練習問題に出てきます(ネットワークの設計と運用, ネットワークの基礎など)。

この用語の分野: ネットワークの基礎

デフォルトゲートウェイの練習問題に挑戦

端末(192.168.1.10/24、デフォルトゲートウェイ 192.168.1.1)が、別のネットワークにあるサーバ 203.0.113.80 にパケットを送る。ARPのキャッシュが空のとき、端末がARPでMACアドレスを調べる相手はどれか。

  1. Aデフォルトゲートウェイ 192.168.1.1
  2. Bサーバ 203.0.113.80
  3. Cサーバまでの経路上にあるすべてのルータ
答えと解説を見る

正解：A. デフォルトゲートウェイ 192.168.1.1

端末はまず、自分のIPアドレスとサブネットマスクから、宛先が同じネットワークにあるかを判断します。203.0.113.80 は 192.168.1.0/24 の外なので、パケットはデフォルトゲートウェイ(ルータ)に渡します。このとき、IPヘッダの宛先はサーバの 203.0.113.80 のままで、フレームの宛先MACアドレスだけをゲートウェイのものにします。そのため、ARPで調べるのは 192.168.1.1 のMACアドレスです。ARPのブロードキャストはルータを越えないので、別のネットワークにあるサーバのMACアドレスは調べられず、知る必要もありません。経路上の各ルータが、次の機器へ送るたびに、それぞれ相手のMACアドレスを調べます。

2台のルータR1(192.168.1.2)とR2(192.168.1.3)でVRRPを構成し、仮想IPアドレスを 192.168.1.254 とした。ふだんはR1がマスタとして転送している。LANの端末のデフォルトゲートウェイに設定するアドレスとして適切なものはどれか。

  1. A192.168.1.2(R1のアドレス)
  2. B192.168.1.3(R2のアドレス)
  3. C192.168.1.254(仮想IPアドレス)
答えと解説を見る

正解：C. 192.168.1.254(仮想IPアドレス)

VRRPは、複数のルータで1つの仮想ルータを作り、仮想IPアドレスと仮想MACアドレスを共有させるプロトコルです。ふだんはマスタのルータが仮想アドレス宛てのパケットを転送し、マスタが止まるとバックアップのルータがマスタになって転送を引き継ぎます。端末は仮想IPアドレスをデフォルトゲートウェイにしておけば、どちらのルータが動いていても設定を変える必要がありません。このようにデフォルトゲートウェイを冗長化するしくみをFHRPと総称し、VRRPのほかにHSRPなどがあります。

「デフォルトゲートウェイ」が出てくる問題(9問)

  1. 端末(192.168.1.10/24、デフォルトゲートウェイ 192.168.1.1)が、別のネットワークにあるサーバ 203.0.113.80 にパケットを送る。ARPのキャッシュが空のとき、端末がARPでMACアドレスを調べる相手はどれか。
  2. 2台のルータR1(192.168.1.2)とR2(192.168.1.3)でVRRPを構成し、仮想IPアドレスを 192.168.1.254 とした。ふだんはR1がマスタとして転送している。LANの端末のデフォルトゲートウェイに設定するアドレスとして適切なものはどれか。
  3. VLAN 20(192.168.20.0/24)の端末に、別のネットワークにあるDHCPサーバ 10.0.0.5 からアドレスを割り当てる。そのため、VLAN 20のデフォルトゲートウェイであるL3スイッチのインターフェース(192.168.20.1)に、DHCPリレーエージェントを設定した。リレーエージェントの動作として正しいものはどれか。
  4. DHCPで端末がIPアドレスを得るときの、メッセージの順序として正しいものはどれか。
  5. VLAN 10(192.168.10.0/24)とVLAN 20(192.168.20.0/24)をもつL2スイッチにルータを1本のリンクでつなぎ、2つのVLANの間で通信できるようにしたい。この構成の設定として適切なものはどれか。
  6. NAPTを行うルータ(外側のアドレスは 198.51.100.7)に、「外側のTCP 8080番ポートに届いた通信を、内側のWebサーバ 192.168.1.20 の80番ポートへ転送する」というポート転送(宛先だけを変換する静的な設定)を行った。インターネット上の端末 203.0.113.9 が、送信元ポート51000で 198.51.100.7 の8080番ポートに接続したとき、Webサーバが受け取るパケットの宛先と送信元の組み合わせはどれか。
  7. IPv6で、同じリンクの中だけで使われ、IPv6を使うインターフェースには必ず自動的に設定されるリンクローカルアドレスの範囲はどれか。
  8. IPv6のSLAAC(ステートレスアドレス自動設定)で、端末がグローバルユニキャストアドレスを作る方法として正しいものはどれか。
  9. あるPCから、IPアドレスを指定したpingはインターネット上のサーバまで届くが、ブラウザでドメイン名を指定すると「サーバが見つからない」と表示されて、Webページを開けない。まず確認すべき設定として最も適切なものはどれか。
