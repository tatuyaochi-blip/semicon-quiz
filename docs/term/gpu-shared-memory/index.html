シェアードメモリとは

しぇあーどめもり

GPUの各SMの中にある、同じブロックのスレッドで共有できる小さく高速なメモリ。共有メモリとも呼ぶ。何を置くかをプログラムが決める。

「シェアードメモリ」は、1分野の1問の練習問題に出てきます(GPUプログラミングなど)。

この用語の分野: GPUプログラミング

シェアードメモリの練習問題に挑戦

CUDAの共有メモリ(シェアードメモリ)の特徴として正しいものはどれか。

  1. AすべてのGPUとCPUで共有する、大容量の主記憶
  2. BGPUのメモリをハードディスクと共有する領域
  3. C同じブロックのスレッドで共有できる、チップ上の小さく高速なメモリで、プログラムが明示的に使う
答えと解説を見る

正解：C. 同じブロックのスレッドで共有できる、チップ上の小さく高速なメモリで、プログラムが明示的に使う

共有メモリは、各SMの中にある1ブロックあたり数十KB程度の高速なメモリで、グローバルメモリ(GPUのDRAM)より何十倍も速く読み書きできます。同じブロックのスレッドがデータを置いて共有できるので、グローバルメモリから一度だけ読み込んで何度も使う、スレッドどうしで途中の結果を受け渡す、といった用途に使います。キャッシュと違い、何を置くかをプログラムが決めます。
