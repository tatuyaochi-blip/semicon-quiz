エレクトロマイグレーションとは

えれくとろまいぐれーしょん

電流によって配線の金属原子が移動する現象。ボイドやヒロックが生じ、断線や短絡の原因になる。

「エレクトロマイグレーション」は、8分野の26問の練習問題に出てきます(配線プロセス, 信頼性, 先端トランジスタ(FinFET・GAA)など)。

この用語の分野: 信頼性

電子風とダメージの発生場所

伝導電子は金属イオンに散乱されて運動量を渡し、原子を電子の流れる方向、つまり電流とは逆の方向へ押し流します。原子は主に速い拡散経路に沿って移動し、アルミニウムでは結晶粒界、銅では銅と絶縁性キャップ膜の上部界面がその経路です。ダメージは、バリアメタルでふさがれたビアの底のように、この原子の流れが途切れる場所に現れます。上流側では原子が補充されないまま出ていくためボイドができ、抵抗が上がったり断線したりします。下流側では原子が積み上がってヒロックとなり、絶縁膜を割って隣の配線と短絡することがあります。

ブラックの式と寿命試験

ブラックの式 MTTF = A·J⁻ⁿ·exp(Ea/kT) は、メジアン寿命が電流密度Jとともに低下し(nは通常約2)、温度が上がると指数関数的に低下することを示します。そのため信頼性試験では、高い電流密度と300 °C前後の温度で配線にストレスを加え、使用条件に外挿します。故障時間は対数正規分布に従い、チップには数億本の配線があるため、設計目標は0.1 ppmのようなごくわずかな割合が故障するまでの時間に置かれます。これにより、配線1本あたりの電流密度の上限はMA/cm²のオーダーになります。

耐性を高める材料と構造

アルミニウムに約0.5%の銅を加えると、銅が結晶粒界に入り、アルミニウムの移動を1桁以上遅くします。抵抗率が約1.7 µΩ·cm(アルミニウムは約2.7 µΩ·cm)で融点も高い銅配線により、耐性はさらに向上しました。銅は主に上面に沿って移動するため、寿命は絶縁性キャップ膜(SiCNやSiN)やコバルトなどの選択的なメタルキャップで決まります。バンブー構造の結晶粒はアルミニウムには大きな効果がありますが、銅には十分ではありません。短い配線ではブレッヒ効果が働き、電流密度と配線長の積が臨界値を下回ると、バックストレス(逆向きの応力)によって正味の原子移動が止まります。

設計でのチェックと関連する故障

設計者は冗長ビアを追加し、ビア周辺の金属を広げ、サインオフ時にはIRドロップ解析とあわせてエレクトロマイグレーション解析を行います。FinFETやSOIデバイスの自己発熱は近くの配線温度を上げ、故障を早めます。フリップチップのはんだバンプでは、配線からバンプへの角部に電流が集中してボイドの起点となり、これが銅ピラーが好まれる理由の1つです。エレクトロマイグレーションは、電流がなくても熱応力でボイドができるストレスマイグレーションや、湿気によって基板上のバイアスがかかった電極間で金属イオンがデンドライト状に成長するイオンマイグレーションとは区別されます。

エレクトロマイグレーションの練習問題に挑戦

エレクトロマイグレーションによる配線の寿命を表すブラックの式で、寿命を短くする要因として正しいものはどれか。

  1. A配線を太くすること
  2. B電流密度が高いことと、温度が高いこと
  3. C温度を下げること
答えと解説を見る

正解：B. 電流密度が高いことと、温度が高いこと

ブラックの式では、平均故障時間が MTTF = A·J⁻ⁿ·exp(Ea/kT) と表され、電流密度Jのn乗(nは約2)に反比例し、温度に対して指数関数的に短くなります。そのため試験では、使用条件より高い電流密度と温度(例えば300 ℃前後)で加速して故障時間を測り、式で使用条件の寿命に換算します。設計では、配線ごとに流してよい電流密度の上限(例えばMA/cm²級)が決められています。

エレクトロマイグレーションによるボイドが発生しやすい場所として正しいものはどれか。

  1. Aビアと配線の境界など、金属原子の流れが不連続になる場所
  2. B電流が流れていない配線の中央
  3. Cチップの外のパッケージ基板
答えと解説を見る

正解：A. ビアと配線の境界など、金属原子の流れが不連続になる場所

エレクトロマイグレーションでは、原子が電子の流れに押されて移動します(電子風力)。ビアと配線の境界、ビアの下のバリアのように原子の流れが途切れる場所では、上流側から原子が出ていく一方で補充されないためボイドができ、下流側では原子がたまってヒロック(盛り上がり)ができます。設計では冗長ビアを置く、ビアの周りの配線を広げる、電流の向きを考えるなどの対策をとります。

よくある質問

エレクトロマイグレーションとストレスマイグレーションの違いは?

エレクトロマイグレーションは電流によって起こり、電子が金属原子を配線に沿って押し流します。ストレスマイグレーションは電流がなくても起こり、熱膨張の差で残った引張応力を緩和するように原子が移動してボイドができる現象で、150〜250 °C付近で最も顕著です。

銅がアルミニウムよりエレクトロマイグレーションに強いのはなぜですか?

銅は融点が高いため動作温度で原子が動きにくく、寿命が1桁以上改善するからです。抵抗率も低いため、同じ電流での発熱も少なくなります。

ブレッヒ効果とは何ですか?

短い配線では、一端に押し寄せた原子が応力勾配をつくり、逆向きの原子の流れを生みます。電流密度と配線長の積が臨界値を下回ると、この逆流が電子風と打ち消し合い、配線は劣化しません。

解説の中の「エレクトロマイグレーション」

  • エレクトロマイグレーションでは、原子が電子の流れに押されて移動します(電子風力)。

  • 原子が速く移動しやすい配線方向に沿った粒界の経路がなくなるため、粒界拡散によるエレクトロマイグレーションが抑えられ、アルミ配線では寿命が大きく延びました。

    配線の幅が結晶粒より細くなり、結晶粒界が配線を横切るように並んだ構造を何と呼び、エレクトロマイグレーションにどう影響す…

  • エレクトロマイグレーションは、配線を流れる電子が金属原子に衝突して運動量を与え、原子を少しずつ電子の流れの向きに移動させる現象です。

    エレクトロマイグレーションの説明として正しいものはどれか。

  • エレクトロマイグレーションでは、電子の流れの上流側で原子が抜けてボイドができて断線の原因になり、下流側では原子がたまってヒロックができ、絶縁膜を押し破って隣の配線や上下の配線と接触して短絡を起こすことがあります。
