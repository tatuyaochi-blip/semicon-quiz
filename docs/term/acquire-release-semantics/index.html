アクワイア・リリースとは

あくわいあ・りりーす

取得(acquire)の後の操作は取得より前に動かず、解放(release)の前の操作は解放より後に動かないという順番の保証。ロックの取得と解放に使われ、完全なバリアより軽い。

この用語の分野: マルチコアと同期
