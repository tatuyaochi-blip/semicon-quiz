PECVD(プラズマCVD)とは

ぴーいーしーぶいでぃー

プラズマで原料ガスを分解して膜を堆積するCVD。熱CVDより低い温度で成膜でき、配線工程の絶縁膜などに使われる。

この用語の分野: 成膜(CVD・PVD)

解説の中の「PECVD(プラズマCVD)」

  • プラズマCVDは、プラズマ中の電子のエネルギーで原料ガスを分解・活性化するため、熱だけで反応させる熱CVD(600〜800 ℃程度)より低い300〜400 ℃程度で成膜できます。

    プラズマCVD(PECVD)の主な利点として正しいものはどれか。

  • 例えばLPCVDの窒化膜の水素は数%以下ですが、プラズマCVDの窒化膜では20%前後含まれることもあります。

    同じ材料の膜で比べたとき、高温の熱CVD膜がプラズマCVD膜より一般に優れている点はどれか。

  • プラズマCVDのシリコン窒化膜は、シランとアンモニアなどを300〜400 ℃の低温で反応させるため、Si-HやN-Hの形で水素を10〜30%程度含み、組成もSiNxとずれます。

    プラズマCVDで成膜したシリコン窒化膜の特徴として正しいものはどれか。

「PECVD(プラズマCVD)」が出てくる問題(8問)

  1. プラズマCVD(PECVD)の主な利点として正しいものはどれか。
  2. 同じ材料の膜で比べたとき、高温の熱CVD膜がプラズマCVD膜より一般に優れている点はどれか。
  3. プラズマCVDで成膜したシリコン窒化膜の特徴として正しいものはどれか。
  4. プラズマCVDのシリコン窒化膜の応力を、圧縮から引っ張りまで調整する方法として使われるものはどれか。
  5. シリコン酸化膜のCVDで原料として広く使われる、液体の有機シリコン化合物はどれか。
  6. 熱CVDでシリコン窒化膜(Si3N4)を成膜するときに使われる原料ガスの組み合わせとして正しいものはどれか。
  7. CVD装置で、原料ガスをウエハの上から多数の小さな穴を通して均一に供給する部品はどれか。
  8. シランとともにCVDでシリコン酸化膜や酸窒化膜をつくるとき、酸化剤として使われることのあるガスはどれか。
