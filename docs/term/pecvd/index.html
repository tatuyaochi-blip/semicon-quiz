PECVD(プラズマCVD)とは

ぴーいーしーぶいでぃー

プラズマで原料ガスを分解して膜を堆積するCVD。熱CVDより低い温度で成膜でき、配線工程の絶縁膜などに使われる。

「PECVD(プラズマCVD)」は、2分野の9問の練習問題に出てきます(成膜(CVD・PVD), プロセス材料(ガス・薬液)など)。

この用語の分野: 成膜(CVD・PVD)

熱の代わりにプラズマを使う

プラズマ CVD(PECVD)では、RF 電力によってシャワーヘッド電極と加熱したウエハステージの間にグロー放電を起こします。プラズマ中の高エネルギーの電子が原料分子を反応性の高いラジカルやイオンに分解する一方、ガスとウエハは比較的低温に保たれます。そのため、熱 CVD で一般的な 600〜800 ℃ ではなく、約 300〜400 ℃ で成膜できます。これにより、高温が許されないアルミニウムや銅の配線を形成した後の工程でも PECVD を使えます。多数の小さな穴からガスをウエハ全面に均一に供給するシャワーヘッドは、ほとんどの枚葉式 PECVD チャンバーで上部電極を兼ねています。

代表的な膜と原料

シリコン酸化膜は、シランと穏やかな酸化剤である亜酸化窒素(N2O)、または TEOS と酸素から堆積するのが一般的です。シリコン窒化膜はシランとアンモニアからつくり、ガスの混合比を変えると酸窒化膜(SiON)になります。SiON は屈折率を調整できるため、リソグラフィ用の反射防止膜に適しています。比誘電率が SiO2 の約 3.9 に対して約 2.7〜3.0 の炭素添加酸化膜(SiOC)の low-k 絶縁膜も、ほとんどが PECVD でつくられます。PECVD 窒化膜は、チップ最終のパッシベーション膜や、銅配線上のキャップ膜・拡散バリアとしても使われます。

熱CVDとの膜質の違い

低温で成膜できることには代償があります。原料の反応が不完全なため、PECVD の膜には Si-H や N-H 結合として水素が残ります。減圧 CVD(LPCVD)の窒化膜の水素含有量が数 % なのに対し、PECVD 窒化膜は約 10〜30% の水素を含むことがあり、化学量論組成からずれているため SiNx と表記されることがよくあります。こうした膜は密度が低く、ウェットエッチングの速度も速くなります。狭い隙間でのコンフォーマル性も一般に LPCVD より劣ります。そのため技術者は、熱履歴が許す場合は熱 CVD を使い、膜の完全さより温度が制約となる工程に PECVD を充てます。

二周波RFによる応力の調整

多くの PECVD 装置は、高周波(13.56 MHz)と低周波(数百 kHz)の二つの周波数を印加します。重いイオンは遅い電界には追従できるため、成長中の膜に衝突して膜を緻密にし、応力を圧縮側に変えます。高周波と低周波の電力比、ガス組成、温度を変えることで、窒化膜の応力をおよそ −3 GPa(圧縮)から +1.5 GPa(引張)まで調整できます。この制御は、チャネルにひずみを加えてトランジスタの移動度を高めるストレスライナー膜や、厚い積層膜でウエハの反りを許容範囲に抑えるために使われます。

PECVD(プラズマCVD)の練習問題に挑戦

プラズマCVD(PECVD)の主な利点として正しいものはどれか。

  1. A熱CVDより高い温度が必要になる
  2. B膜中に水素がまったく含まれない
  3. C熱CVDより低い温度で成膜できる
答えと解説を見る

正解：C. 熱CVDより低い温度で成膜できる

プラズマCVDは、プラズマ中の電子のエネルギーで原料ガスを分解・活性化するため、熱だけで反応させる熱CVD(600〜800 ℃程度)より低い300〜400 ℃程度で成膜できます。アルミや銅の配線形成後など高温にできない工程で、層間絶縁膜や保護膜の成膜に使われます。一方、原料ガスに由来する水素が膜に含まれやすく、膜質は熱CVDに劣る傾向があります。

同じ材料の膜で比べたとき、高温の熱CVD膜がプラズマCVD膜より一般に優れている点はどれか。

  1. A成膜温度が低い
  2. B成膜速度が必ず速い
  3. C膜が緻密で、水素などの不純物が少ない
答えと解説を見る

正解：C. 膜が緻密で、水素などの不純物が少ない

高温の熱CVDでは、原料が十分に反応して緻密な膜ができ、原料に由来する水素などの不純物も少なく、組成も化学量論に近くなります。例えばLPCVDの窒化膜の水素は数%以下ですが、プラズマCVDの窒化膜では20%前後含まれることもあります。プラズマCVDは低温で成膜できる一方、膜が粗く、エッチング速度が速い傾向があるため、工程の温度の制約と必要な膜質に応じて使い分けます。

よくある質問

PECVDが熱CVDより低温で成膜できるのはなぜですか?

原料の結合を切るエネルギーを、ウエハの熱ではなくプラズマ中の高エネルギー電子が供給するためです。ウエハは約 300〜400 ℃ に保てるので、形成済みの金属配線にも影響を与えません。

PECVDとLPCVDのシリコン窒化膜の違いは何ですか?

LPCVD 窒化膜は高温で堆積し、緻密でほぼ化学量論組成、水素も少ない膜です。PECVD 窒化膜は低温で堆積し、約 10〜30% の水素を含み、エッチング速度が速く、パッシベーションのように熱履歴が限られる工程で使われます。

PECVDで膜応力はどう制御しますか?

主に低周波と高周波の RF 電力比で制御します。この比によってイオンが膜に衝突する強さが決まり、ガス組成や温度もあわせて調整します。一般に、イオン衝撃が強いほど膜は圧縮応力側になります。
