C-stateとは

しーすてーと

仕事のないときのCPUの休みの深さを表す状態。C0が動作中で、数字が大きいほど電力は小さいが、元に戻るのに時間がかかる。

「C-state」は、1分野の3問の練習問題に出てきます(電力管理(ソフトウェア制御)など)。

この用語の分野: 電力管理(ソフトウェア制御)

C-stateの練習問題に挑戦

CPUのC-state(Cステート)の説明として正しいものはどれか。

  1. ACPUが動いているときの周波数と電圧の組み合わせ
  2. B仕事のないときのCPUの休みの深さを表す状態で、深い状態ほど電力は小さいが、元に戻るのに時間がかかる
  3. CCPUの製造の工程の名前
答えと解説を見る

正解：B. 仕事のないときのCPUの休みの深さを表す状態で、深い状態ほど電力は小さいが、元に戻るのに時間がかかる

C-stateでは、C0が命令を実行している状態で、C1はクロックを止めるだけの浅い休み、さらに深い状態ではキャッシュの内容を書き出してコアの電源を切る、などのように、番号が大きくなるほど多くの回路を止めます。深いほど電力は小さくなりますが、戻るまでの時間と手間が増えるので、OSは次の仕事までの時間を予想して、適切な深さを選びます。
