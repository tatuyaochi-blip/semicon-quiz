情報量とは

じょうほうりょう

確率pで起こる事象が起こったと知らされたときに得られる情報の大きさ。I = −log₂ p で表し、単位はビットである。起こりにくい事象ほど大きく、必ず起こる事象(p = 1)では0になる。確率1/2の事象は1ビット、確率1/1024の事象は10ビットである。独立な2つの事象が両方起こったときの情報量は、それぞれの情報量の和になる。情報源の1記号あたりの情報量を確率で平均したものが、エントロピーである。自己情報量ともいう。

「情報量」は、1分野の5問の練習問題に出てきます(情報理論と符号の基礎など)。

情報量の練習問題に挑戦

事象の確率をpとするとき、その事象が起こったと知らされて得られる情報量を −log₂ p ビットとする。確率1/8で起こる事象が起こったと知らされたときの情報量はどれか。

  1. A0.125ビット
  2. B0.375ビット
  3. C3ビット
答えと解説を見る

正解：C. 3ビット

情報量は −log₂(1/8) = log₂ 8 = 3 ビットです。1/8 = 1/2³ なので、確率1/2の「2つに1つ」を知らされることを、3回重ねたのと同じ量の情報になります。起こりにくい事象ほど、起こったと知らされたときの情報量は大きくなります。

情報量(確率pの事象が起こったと知らされたときの −log₂ p)の性質として、正しいものはどれか。

  1. A確率1で必ず起こる事象が起こったと知らされたときの情報量は、1ビットである
  2. B独立な2つの事象が両方起こったと知らされたときの情報量は、それぞれの情報量の和になる
  3. C起こる確率が高い事象ほど、起こったと知らされたときの情報量は大きい
答えと解説を見る

正解：B. 独立な2つの事象が両方起こったと知らされたときの情報量は、それぞれの情報量の和になる

独立な2つの事象が両方起こる確率は p₁ × p₂ なので、情報量は −log₂(p₁ × p₂) = (−log₂ p₁) + (−log₂ p₂) となり、それぞれの情報量の和になります。情報量を対数で定義するのは、この足し算の性質をもたせるためです。必ず起こる事象は、知らされても新しく分かることがないので、情報量は −log₂ 1 = 0 です。

「情報量」が出てくる問題(5問)

  1. 事象の確率をpとするとき、その事象が起こったと知らされて得られる情報量を −log₂ p ビットとする。確率1/8で起こる事象が起こったと知らされたときの情報量はどれか。
  2. 情報量(確率pの事象が起こったと知らされたときの −log₂ p)の性質として、正しいものはどれか。
  3. 記号A、B、C、Dをそれぞれ確率1/2、1/4、1/8、1/8で、互いに独立に出す情報源がある。この情報源のエントロピー(1記号あたりの平均情報量)はどれか。
  4. 8種類の記号を出す情報源のエントロピーが2.4ビットであった。冗長度を 1 − (エントロピー ÷ 最大エントロピー) と定義するとき、この情報源の冗長度はどれか。
  5. 2つの確率変数X、Yについて、条件付きエントロピー H(X|Y) と相互情報量 I(X;Y) の説明として、正しいものはどれか。
