量子化誤差とは

りょうしかごさ

連続したアナログ値を有限のビット数のデジタル値に丸めるときに生じる誤差。最大で1 LSBの半分。

「量子化誤差」は、1分野の3問の練習問題に出てきます(AD/DA変換など)。

この用語の分野: AD/DA変換

誤差が生じる理由

NビットのA/D変換器(ADC)は、フルスケール範囲を2^N個のステップに分け、各ステップの幅を1 LSB(最下位ビット)とします。範囲1 Vの10ビット変換器では、LSBは約0.98 mVです。1つのステップ内の入力はすべて同じコードになるため、入力を掃引すると、真の入力値とコードが表す値との差はのこぎり波状に増減します。丸めを行う理想的な変換器では、この誤差が±1/2 LSBを超えることはありません。ビットを1つ増やすごとにLSBは半分になり、したがって最大誤差も半分になります。

量子化雑音と理想SNR

入力が多くのコードにまたがって変化し、サンプリングクロックに同期していない場合、誤差は−1/2〜+1/2 LSBに一様に分布するランダムな雑音のようにふるまいます。このとき実効値(rms)はLSB/√12、約0.29 LSBです。フルスケールの正弦波では、ここから理想的な信号対雑音比(SNR)が6.02N + 1.76 dBとなり、12ビットで約74 dB、16ビットで約98 dBです。実際の変換器は熱雑音、ジッタ、非直線性のためにこれに届かないので、測定性能から求めた有効ビット数(ENOB)が示されます。

ひずみとしてふるまう場合:ディザ

入力が小さい場合や、ゆっくり変化する場合、あるいはサンプリングクロックに同期した周期信号の場合、誤差はもはやランダムではなく信号に追従し、高調波ひずみやスプリアスとして現れます。変換前にディザと呼ばれる1〜数 LSB程度の小さなランダム信号を加えると、誤差と信号の相関がなくなり、ひずみが無害なノイズフロアに変わります。さらにディザをかけた多数のサンプルを平均すれば、1 LSBより細かい値まで分解できます。同じ原理は、オーディオのビット深度の削減や、画像の誤差拡散にも使われています。

ビットを増やす以外の低減方法

オーバーサンプリングは、一定の量子化雑音電力をより広い周波数範囲に広げます。その後で信号帯域にフィルタリングすれば雑音の一部が除去され、サンプリングレートを2倍にするごとに約3 dB、つまり0.5ビット分改善します。デルタシグマ変換器で使われるノイズシェーピングはさらに進んで、雑音の大部分をフィルタで除去する前に信号帯域の外へ押し出します。量子化誤差は、オフセット、ゲイン誤差、微分・積分非直線性(DNL、INL)といった他のADC誤差とは区別すべきです。これらは有限の分解能ではなく、回路の不完全さから生じます。

量子化誤差の練習問題に挑戦

理想的なADコンバータにおける量子化誤差の最大値はどれか。(LSB:最下位ビット1つ分に相当する電圧)

  1. A±2 LSB
  2. B±1 LSB
  3. C±1/2 LSB
答えと解説を見る

正解：C. ±1/2 LSB

連続した値を1 LSB幅の段階に丸めるため、変換には必ず誤差が生じ、理想的なADCでは最大±1/2 LSBです。入力が十分に変化する場合、この誤差は ±1/2 LSB の範囲に一様に分布する雑音とみなせ、実効値は LSB/√12 になります。これが理想ADCのSNR(6.02N + 1.76 dB)の根拠です。ビット数を増やすと1 LSBが小さくなり、量子化誤差も小さくなります。

よくある質問

ADCの量子化誤差の最大値はいくつですか?

丸めを行う理想的なADCでは±1/2 LSBです。1 LSBはフルスケール範囲を2^Nで割った値です。

量子化雑音がLSB/√12になるのはなぜですか?

誤差が−1/2〜+1/2 LSBに一様分布するとすれば、分散はLSB²/12になるため、実効値はLSB/√12、約0.29 LSBになります。

12ビットADCの理想SNRはいくつですか?

フルスケール正弦波に対する6.02N + 1.76 dBの式を使うと、12ビットADCの理想SNRは約74 dBです。
