量子化誤差とは

りょうしかごさ

連続したアナログ値を有限のビット数のデジタル値に丸めるときに生じる誤差。最大で1 LSBの半分。

「量子化誤差」は、1分野の3問の練習問題に出てきます(AD/DA変換など)。

この用語の分野: AD/DA変換

量子化誤差の練習問題に挑戦

理想的なADコンバータにおける量子化誤差の最大値はどれか。(LSB:最下位ビット1つ分に相当する電圧)

  1. A±2 LSB
  2. B±1 LSB
  3. C±1/2 LSB
答えと解説を見る

正解：C. ±1/2 LSB

連続した値を1 LSB幅の段階に丸めるため、変換には必ず誤差が生じ、理想的なADCでは最大±1/2 LSBです。入力が十分に変化する場合、この誤差は ±1/2 LSB の範囲に一様に分布する雑音とみなせ、実効値は LSB/√12 になります。これが理想ADCのSNR(6.02N + 1.76 dB)の根拠です。ビット数を増やすと1 LSBが小さくなり、量子化誤差も小さくなります。

解説の中の「量子化誤差」

  • ビット数を増やすと1 LSBが小さくなり、量子化誤差も小さくなります。

    理想的なADコンバータにおける量子化誤差の最大値はどれか。(LSB:最下位ビット1つ分に相当する電圧)

  • 量子化は、サンプリングした値を有限個の段階のどれかに丸める処理で、元の値との差が量子化誤差です。

    AD変換における「量子化」によって生じる誤差を何と呼ぶか。

  • 入力が小さいときや変化がゆっくりなとき、量子化誤差は信号と相関をもち、高調波のひずみとして現れます。

    AD変換の前に、小さな雑音(ディザ)をわざと加える主な目的はどれか。

「量子化誤差」が出てくる問題(3問)

  1. 理想的なADコンバータにおける量子化誤差の最大値はどれか。(LSB:最下位ビット1つ分に相当する電圧)
  2. AD変換における「量子化」によって生じる誤差を何と呼ぶか。
  3. AD変換の前に、小さな雑音(ディザ)をわざと加える主な目的はどれか。
