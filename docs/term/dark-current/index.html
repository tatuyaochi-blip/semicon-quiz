暗電流とは

あんでんりゅう

光が当たっていないのにフォトダイオードに流れる電流。熱によるキャリアの発生などが原因で、温度が上がると増え、暗い画像のノイズになる。

「暗電流」は、3分野の6問の練習問題に出てきます(イメージセンサ・光デバイス, 半導体物性, PN接合・ダイオードなど)。

この用語の分野: イメージセンサ・光デバイス

暗電流の練習問題に挑戦

イメージセンサの暗電流の説明として正しいものはどれか。

  1. A光の強さに比例して増える信号電流
  2. B光が当たっていなくても流れる電流で、温度が上がると増える
  3. C画素を読み出すためのクロック電流
答えと解説を見る

正解：B. 光が当たっていなくても流れる電流で、温度が上がると増える

暗電流は、光が当たっていなくてもフォトダイオードで熱的に発生する電荷による電流で、主に表面の界面準位や結晶欠陥、金属汚染による準位から発生します。暗い場所での撮影や長時間露光でノイズや白い点(白傷)の原因になり、温度が上がるとおよそ6〜8 ℃ごとに2倍に増えます。天体撮影用のカメラがセンサを冷却するのはこのためです。

「暗電流」が出てくる問題(6問)

  1. イメージセンサの暗電流の説明として正しいものはどれか。
  2. 禁制帯の中にできた深い準位(トラップ)を介して電子と正孔が再結合する過程を何と呼ぶか。
  3. フォトダイオードを光の検出に使うときの一般的な使い方として正しいものはどれか。
  4. CMOSイメージセンサの埋め込みフォトダイオード(ピンドフォトダイオード)で、表面に高濃度のp+層を設ける主な目的はどれか。
  5. 画素ごとの特性のばらつきによって、毎回同じ位置に同じように現れるノイズを何と呼ぶか。
  6. 微細な画素の間に深い溝を掘り、絶縁物などを埋め込む構造(DTI)の主な目的はどれか。
