P-stateとは

ぴーすてーと

動いているCPUの周波数と電圧の組み合わせで表した性能の段階。DVFSで負荷に合わせて切り替える。

この用語の分野: 電力管理(ソフトウェア制御)

解説の中の「P-state」

  • P-stateは、動作中のCPUの周波数と電圧の組み合わせを段階に分けたもので、高い段階ほど速く、電力も大きくなります。

    CPUのP-state(Pステート)の説明として正しいものはどれか。

  • ファームウェアが機器の構成や電源の操作の方法を表の形でOSに伝え、OSはそれを使って、スリープ(S3)や休止状態(S4)への移行、CPUのC-stateやP-stateの制御、温度に応じたファンの制御などを行います。

    パソコンなどで使われるACPIの説明として正しいものはどれか。

「P-state」が出てくる問題(2問)

  1. CPUのP-state(Pステート)の説明として正しいものはどれか。
  2. パソコンなどで使われるACPIの説明として正しいものはどれか。
