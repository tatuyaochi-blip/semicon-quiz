MOCVD(有機金属気相成長)とは

えむおーしーぶいでぃー

有機金属化合物とアンモニアなどの原料ガスを使って結晶を成長させる方法。GaNやGaAsなどの化合物半導体の成長に広く使われる。

この用語の分野: エピタキシャル成長

解説の中の「MOCVD(有機金属気相成長)」

  • MOCVDの原料のアンモニアなどに由来する水素がMgと結合してMg-H複合体をつくり、アクセプタとして働かなくします。

    MOCVD法でマグネシウムを添加したGaNが、成長直後には高抵抗でp型にならない主な理由と、その対策の組み合わせとして…

  • MOCVDは、トリメチルガリウムなどの有機金属とアンモニアなどの原料ガスを反応させて、化合物半導体の結晶を成長させる方法です。

  2. MOCVD(有機金属気相成長法)が主に使われる用途はどれか。
  3. MOCVDによるGaNの成長で、条件として管理される「V/III比」の意味はどれか。
  4. MOCVDの原料であるトリメチルガリウム(TMGa)などの有機金属化合物の取り扱い上の注意点として正しいものはどれか。
