前方秘匿性とは

ぜんぽうひとくせい

長期間使う秘密鍵が後で漏えいしても、それ以前に記録された通信の内容は復号されないという性質。PFS(Perfect Forward Secrecy)ともいう。接続ごとに使い捨ての値で鍵交換を行うDHEやECDHEで実現し、使い終わった値は捨てるので、後から過去のセッションの鍵を計算し直せない。サーバのRSA公開鍵で鍵の材料を暗号化して送る方式にはこの性質がなく、TLS 1.3ではその方式が廃止された。

「前方秘匿性」は、2分野の4問の練習問題に出てきます(暗号技術の基礎と応用, 無線通信の基礎など)。

前方秘匿性の練習問題に挑戦

TLSで、サーバの証明書の秘密鍵が後で漏えいしても、それ以前に記録された通信は復号されないという性質(前方秘匿性)が得られる鍵交換の方法はどれか。

  1. A接続ごとに使い捨ての値を作って行う、ECDHEなどの鍵交換
  2. Bクライアントが作った鍵の材料を、サーバの証明書のRSA公開鍵で暗号化して送る方式
  3. Cサーバとクライアントが、あらかじめ決めた同じ共通鍵を、すべての接続で使い続ける方式
答えと解説を見る

正解：A. 接続ごとに使い捨ての値を作って行う、ECDHEなどの鍵交換

ECDHEの最後のEはエフェメラル(使い捨て)の意味で、接続ごとに新しい秘密の値で鍵交換をし、終わったら捨てます。証明書の秘密鍵は署名に使うだけなので、後で漏れても、過去の接続の共有の秘密は計算できません。一方、鍵の材料をサーバのRSA公開鍵で暗号化して送る方式では、記録しておいた通信と、後で漏れた秘密鍵があれば、過去の通信をすべて復号できてしまいます。TLS 1.3ではこの方式が廃止され、鍵交換は前方秘匿性のある (EC)DHE が基本になりました(事前共有鍵だけで接続を再開する場合を除きます)。

「前方秘匿性」が出てくる問題(4問)

  1. TLSで、サーバの証明書の秘密鍵が後で漏えいしても、それ以前に記録された通信は復号されないという性質(前方秘匿性)が得られる鍵交換の方法はどれか。
  2. 無線LANのセキュリティ規格WPA3のパーソナルモードで、WPA2の事前共有鍵(PSK)による方式に代えて採用され、通信を傍受されてもオフラインの辞書攻撃でパスワードを推測されにくくした認証・鍵交換の方式はどれか。
  3. TLS 1.3(RFC 8446)で、TLS 1.2から変わった点として正しいものはどれか。
  4. TLS 1.3の0-RTT(以前の接続で得た事前共有鍵を使い、最初のメッセージと一緒に「アーリーデータ」を送る方法)の注意点として、正しいものはどれか。
