相関二重サンプリング(CDS)とは

そうかんにじゅうさんぷりんぐ

画素をリセットしたときの電圧と、信号を読み出したときの電圧の差をとる処理。リセットノイズや画素ごとのオフセットを取り除ける。

この用語の分野: イメージセンサ・光デバイス

解説の中の「相関二重サンプリング(CDS)」

  • CDSでは、画素をリセットした直後の出力と、光の信号を読み出したときの出力をそれぞれサンプリングし、その差を信号とします。

    CMOSイメージセンサの読み出しで使われる相関二重サンプリング(CDS)の目的として正しいものはどれか。

  • センサでは相関二重サンプリングで除去します。

    スイッチとコンデンサCで電圧をサンプリングしたときに、コンデンサに残る熱雑音の電圧(実効値)として正しいものはどれか。…

  • 時間的に変化しないため、相関二重サンプリングや補正処理によって取り除くことができます。

    画素ごとの特性のばらつきによって、毎回同じ位置に同じように現れるノイズを何と呼ぶか。

「相関二重サンプリング(CDS)」が出てくる問題(3問)

  1. CMOSイメージセンサの読み出しで使われる相関二重サンプリング(CDS)の目的として正しいものはどれか。
  2. スイッチとコンデンサCで電圧をサンプリングしたときに、コンデンサに残る熱雑音の電圧(実効値)として正しいものはどれか。(k:ボルツマン定数、T:絶対温度)
  3. 画素ごとの特性のばらつきによって、毎回同じ位置に同じように現れるノイズを何と呼ぶか。
