接合容量(空乏層容量)とは

せつごうようりょう

PN接合の空乏層が、平行平板のコンデンサのように働くことで生じる容量。逆バイアスを大きくすると空乏層が広がって小さくなる。可変容量ダイオードはこの性質を使う。

「接合容量(空乏層容量)」は、5分野の11問の練習問題に出てきます(PN接合・ダイオード, 半導体物性, バイポーラトランジスタなど)。

この用語の分野: PN接合・ダイオード

接合容量(空乏層容量)の練習問題に挑戦

逆バイアスのPN接合の空乏層容量(接合容量)Cを、接合の面積A、空乏層の幅W、半導体の誘電率εで表した式はどれか。

  1. AC = εA / W
  2. BC = εW / A
  3. CC = ε / (A × W)
答えと解説を見る

正解：A. C = εA / W

空乏層は両側に電荷がたまった絶縁層のように振る舞うため、平行平板コンデンサと同じく C = εA/W で表せます。逆バイアスでWが広がると容量は小さくなります。例えばシリコンで面積100 µm角、W = 1 µm なら、C ≈ 11.7 × 8.85×10⁻¹² × 10⁻⁸ ÷ 10⁻⁶ ≈ 1 pF です。高速回路ではこの容量が遅延の原因になるため、接合面積を小さくしたり低濃度にしたりして減らします。

解説の中の「接合容量(空乏層容量)」

  • シリコンの比誘電率は約11.7で、空乏層の幅(W = √(2εV/qN))や接合容量の計算に使います。

    シリコンの比誘電率に最も近い値はどれか。

  • 空乏層が広がると接合容量(C = εA/W)は小さくなり、この性質が可変容量ダイオードに使われます。

    PN接合に加える逆方向バイアス電圧を大きくすると、空乏層の幅はどうなるか。

  • 逆バイアスを強くすると空乏層が広がり、接合容量が小さくなります。

    可変容量ダイオード(バラクタダイオード)が利用している性質はどれか。

  • 逆バイアスは接合容量を小さくするので応答も速くなります。

    フォトダイオードを光の検出に使うときの一般的な使い方として正しいものはどれか。

  • 広い空乏層で高い電圧を受け持てるため高耐圧の整流ダイオードに、光の吸収領域が広く接合容量も小さいため高速・高感度の光検出器に向きます。

    p層とn層の間に不純物の少ないi層を挟んだPINダイオードの特徴として正しいものはどれか。

「接合容量(空乏層容量)」が出てくる問題(11問)

  1. 逆バイアスのPN接合の空乏層容量(接合容量)Cを、接合の面積A、空乏層の幅W、半導体の誘電率εで表した式はどれか。
  2. シリコンの比誘電率に最も近い値はどれか。
  3. PN接合に加える逆方向バイアス電圧を大きくすると、空乏層の幅はどうなるか。
  4. 可変容量ダイオード(バラクタダイオード)が利用している性質はどれか。
  5. フォトダイオードを光の検出に使うときの一般的な使い方として正しいものはどれか。
  6. p層とn層の間に不純物の少ないi層を挟んだPINダイオードの特徴として正しいものはどれか。
  7. 順方向バイアスのPN接合で、注入された少数キャリアの蓄積によって生じる容量はどれか。
  8. 片側階段接合の空乏層の幅と逆バイアス電圧Vの関係として正しいものはどれか。(Vが内蔵電位より十分大きい場合)
  9. バイポーラトランジスタのトランジション周波数fTの意味として正しいものはどれか。
  10. p型基板のMOSキャパシタを高周波で測定したC-V特性で、ゲートに大きな正の電圧を加えて強反転させたときの容量はどうなるか。
  11. SOI(Silicon On Insulator)構造の説明として正しいものはどれか。
