ナイキスト周波数とは

ないきすとしゅうはすう

サンプリング周波数の半分の周波数。これを超える成分をサンプリングすると、低い周波数の信号として現れる(エイリアシング)。

「ナイキスト周波数」は、2分野の12問の練習問題に出てきます(デジタル信号処理の基礎, AD/DA変換など)。

この用語の分野: AD/DA変換

周波数の折り返し

信号をサンプリング周波数 fs でサンプリングすると、そのサンプルからは周波数 f と、f に fs の整数倍を足し引きした周波数とを区別できません。そのため、すべての入力成分は 0 からナイキスト周波数 fs/2 までのどこかに現れ、fs/2 の整数倍ごとに紙を折るように折り返されます。たとえば 10 kHz の正弦波を 12 kHz でサンプリングすると、6 kHz のナイキスト周波数を超えているため、|12 − 10| = 2 kHz に現れます。このときのサンプルは本物の 2 kHz の信号のサンプルとまったく同じになり、後でどう処理しても区別できません。

ナイキスト周波数とナイキストレートの違い

この 2 つの用語は混同しやすいものです。ナイキスト周波数はサンプリングする側の性質で、サンプリング周波数の半分 fs/2 です。ナイキストレートは信号側の性質で、信号に含まれる最高周波数成分の 2 倍、つまりサンプリング定理が求める最低のサンプリング周波数です。したがって 20 kHz までのオーディオをサンプリングするには、40 kHz を超える周波数が必要です。ちょうど fs/2 にある成分は、サンプル値の振幅が位相によって変わり、ゼロになることさえあるため、あいまいになります。サンプリング定理が最高周波数の 2 倍より厳密に速いサンプリングを求めるのはこのためです。

アンチエイリアシングとオーバーサンプリング

エイリアシングは元に戻せないため、ADC の前にローパスのアンチエイリアシングフィルタを置き、ナイキスト周波数を超える成分を取り除きます。実際のフィルタには通過域と阻止域の間に遷移帯域が必要なので、サンプリング周波数には余裕を持たせます。オーディオ CD は 20 kHz の帯域に対して 44.1 kHz でサンプリングしており、20〜22.05 kHz の範囲をフィルタの減衰に充てています。必要よりはるかに速くサンプリングするオーバーサンプリングでは、ナイキスト周波数が信号帯域よりずっと上に移るため、簡単な 1 次や 2 次の RC フィルタで足り、急峻な遮断は後段のデジタルフィルタが担います。

意図的なエイリアシングと DAC 側の対策

エイリアシングは常に誤りというわけではありません。アンダーサンプリング(バンドパスサンプリング)では、無線受信機の中間周波数の搬送波のように、高いナイキストゾーンにある狭帯域の信号を、あえてその周波数の 2 倍未満でサンプリングし、扱いやすい低い周波数に折り返します。これが成り立つのは、前段にバンドパスフィルタがあり、ADC のアナログ帯域とクロックジッタが高い入力周波数に十分対応できる場合だけです。出力側では、DAC が fs ± f にイメージ成分を生じるため、再構成用のローパスフィルタで取り除きます。

ナイキスト周波数の練習問題に挑戦

8点の実数の信号 x[n] = {3, 1, 3, 1, 3, 1, 3, 1} の DFT を X[k] = Σx[n]e^(−j2πkn/8) とする。ナイキスト周波数に当たるビン X[4] の値として正しいものはどれか。

  1. A1
  2. B2
  3. C8
答えと解説を見る

正解：C. 8

k = N/2 = 4 では e^(−jπn) = (−1)ⁿ なので、X[4] = Σ(−1)ⁿx[n] = 3 − 1 + 3 − 1 + 3 − 1 + 3 − 1 = 8 です。この信号は、平均2の直流に、±1で交互に変わる成分 (−1)ⁿ が重なったもので、交互の成分がナイキストのビンに、直流が X[0] = 16 に現れます。X[0] と X[N/2] は、実数の信号では常に実数になります。

y[n] = x[n] − x[n − 1](1つ前の入力との差)で表されるフィルタの、直流とナイキスト周波数での利得の大きさの組み合わせとして正しいものはどれか。

  1. A直流で0、ナイキスト周波数で2
  2. B直流で2、ナイキスト周波数で0
  3. C直流で1、ナイキスト周波数で1
答えと解説を見る

正解：A. 直流で0、ナイキスト周波数で2

伝達関数は H(z) = 1 − z⁻¹ で、直流は z = 1、ナイキスト周波数は z = −1 に当たります。直流では 1 − 1 = 0 なので一定の値は完全に取り除かれ、ナイキスト周波数では 1 − (−1) = 2 になります。低い周波数を通さず高い周波数を通すハイパスの特性で、z = 1 に零点があります。y[n] = x[n] + x[n − 1] にすると逆に、直流で2、ナイキスト周波数で0のローパスの特性になります。

よくある質問

ナイキスト周波数とナイキストレートの違いは何ですか?

ナイキスト周波数はサンプリング周波数の半分で、そのサンプリング系が表現できる最高の周波数です。ナイキストレートは信号の最高周波数の 2 倍で、その信号をとらえるのに必要な最低のサンプリング周波数です。

エイリアスの周波数はどう計算しますか?

入力周波数に最も近いサンプリング周波数の整数倍を求め、その差の絶対値をとります。たとえば 10 kHz を 12 kHz でサンプリングすると、|12 − 10| = 2 kHz に現れます。

CD のサンプリング周波数が 40 kHz ではなく 44.1 kHz なのはなぜですか?

人間の可聴域は約 20 kHz までで、40 kHz に上乗せした余裕によって、アンチエイリアシングフィルタに 20〜22.05 kHz の遷移帯域を確保できるからです。実際のフィルタは瞬時に遮断できません。
