OSI参照モデルとは

おーえすあいさんしょうもでる

通信の機能を、物理層・データリンク層・ネットワーク層・トランスポート層・セッション層・プレゼンテーション層・アプリケーション層の7つの層に分けて整理したモデル。各層の役割を分けて考えるための共通の言葉として使われる。

「OSI参照モデル」は、1分野の2問の練習問題に出てきます(ネットワークの基礎など)。

この用語の分野: ネットワークの基礎

7つの層の役割

下の第1層(物理層)は、ケーブルや電波でビットを信号として送ることを扱います。第2層(データリンク層)は、MACアドレスを使って同じネットワークの中の隣の機器にフレームを届けます。第3層(ネットワーク層)は、IPアドレスを使ってネットワークをまたいだ経路を選び、パケットを中継します。第4層(トランスポート層)は、端末のアプリケーションどうしの通信を扱い、TCPなら再送や順序の制御を行います。第5〜7層(セッション層・プレゼンテーション層・アプリケーション層)は、通信の開始と終了の管理、データの表現の変換、アプリケーションの機能を扱います。

TCP/IPの4階層との対応

実際のインターネットで使われているのはTCP/IPのプロトコル群で、そのモデルはリンク層・インターネット層・トランスポート層・アプリケーション層の4つの層で表されます。おおまかには、リンク層がOSIの第1〜2層、インターネット層が第3層、トランスポート層が第4層、アプリケーション層が第5〜7層に対応します。OSI参照モデルのプロトコルそのものは広まりませんでしたが、「L2スイッチ」「L3スイッチ」「L7の負荷分散」のように、機器や機能がどの層で動くかを表す言葉として今も使われています。

層に分ける利点

各層は、すぐ下の層が提供する機能だけを使い、すぐ上の層に機能を提供します。送信側では各層がヘッダを付けてデータを包み(カプセル化)、受信側では下の層から順に取り外します。層の間の約束さえ守れば、ある層の技術を入れ替えても、ほかの層はそのまま使えます。例えば、有線LANを無線LANに替えても、IPやTCP、Webブラウザは変更なしで動きます。

OSI参照モデルの練習問題に挑戦

OSI参照モデルで、IPアドレスのような論理的なアドレスを使い、異なるネットワークの間でパケットを中継して宛先まで届ける役割をもつ層はどれか。

  1. Aデータリンク層(第2層)
  2. Bネットワーク層(第3層)
  3. Cトランスポート層(第4層)
答えと解説を見る

正解：B. ネットワーク層(第3層)

OSI参照モデルは、通信の機能を物理層からアプリケーション層までの7つの層に分けて整理したモデルです。ネットワーク層(第3層)は、IPアドレスのような論理的なアドレスを使い、複数のネットワークをまたいで宛先までの経路を選び、パケットを中継します。その下のデータリンク層は、同じネットワークの中で、MACアドレスを使って隣の機器にフレームを届けるところまでを担います。トランスポート層は、端末のアプリケーションどうしの通信を扱い、TCPなら再送や順序の管理を行います。機器でいえば、ルータは第3層、L2スイッチは第2層で動きます。

よくある質問

OSI参照モデルの7つの層を下から順に言うと?

物理層、データリンク層、ネットワーク層、トランスポート層、セッション層、プレゼンテーション層、アプリケーション層です。ルータは主に第3層、L2スイッチは第2層、ハブは第1層で動く機器です。

OSI参照モデルとTCP/IPモデルはどちらを覚えればよいですか?

両方の対応を押さえるのがよいです。実際に使われるのはTCP/IPのプロトコルですが、機器や機能の位置づけは「第3層」「L7」のようにOSI参照モデルの番号で表すことが多いためです。

  • OSI参照モデルは、通信の機能を物理層からアプリケーション層までの7つの層に分けて整理したモデルです。
