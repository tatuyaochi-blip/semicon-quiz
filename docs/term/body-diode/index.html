ボディダイオードとは

ぼでぃだいおーど

パワーMOSFETの構造上、ソースとドレインの間に寄生的にできるダイオード。インバータで還流ダイオードとして使えるが、逆回復の特性に注意が必要。

「ボディダイオード」は、2分野の3問の練習問題に出てきます(パワー半導体, MOSFETなど)。

この用語の分野: パワー半導体

ボディダイオードの練習問題に挑戦

SiC MOSFETのボディダイオードに電流を流し続けると、特性が劣化することがある原因として知られているものはどれか。

  1. A結晶中の基底面転位が、積層欠陥に拡大すること
  2. Bゲート電極が溶けること
  3. Cパッケージが発光すること
答えと解説を見る

正解：A. 結晶中の基底面転位が、積層欠陥に拡大すること

SiCのボディダイオードに順方向電流を流すと、電子と正孔の再結合のエネルギーで、結晶中の基底面転位が積層欠陥に拡大し、オン電圧が上がることがあります(バイポーラ劣化)。積層欠陥は導通を妨げる面状の欠陥です。基底面転位をエピ成長の途中で別の種類の転位に変換するバッファ層の工夫や、ボディダイオードに頼らずショットキーダイオードを内蔵するなどの対策がとられています。

解説の中の「ボディダイオード」

  • SiCのボディダイオードに順方向電流を流すと、電子と正孔の再結合のエネルギーで、結晶中の基底面転位が積層欠陥に拡大し、オン電圧が上がることがあります(バイポーラ劣化)。

    SiC MOSFETのボディダイオードに電流を流し続けると、特性が劣化することがある原因として知られているものはどれか。

  • ディスクリート部品ではボディがソースに内部接続されて3端子に見え、その結果ソース-ドレイン間に寄生のボディダイオードができます。

    MOSFETの端子として、ゲート・ソース・ドレインのほかにもう1つあるものはどれか。

  • これがボディダイオードで、インバータで電流を還流させる経路に使えます。

    パワーMOSFETの内部に構造上できる寄生ダイオードを何と呼ぶか。

「ボディダイオード」が出てくる問題(3問)

  1. SiC MOSFETのボディダイオードに電流を流し続けると、特性が劣化することがある原因として知られているものはどれか。
  2. MOSFETの端子として、ゲート・ソース・ドレインのほかにもう1つあるものはどれか。
  3. パワーMOSFETの内部に構造上できる寄生ダイオードを何と呼ぶか。
