ゲートドライバとは

げーとどらいば

制御回路の信号を受けて、パワーデバイスのゲートを適切な電圧と十分な電流で駆動する回路。高電圧側のスイッチを駆動するための絶縁やレベル変換の機能をもつものも多い。

この用語の分野: パワー半導体

解説の中の「ゲートドライバ」

  • ゲートドライバは、マイコンなどの数mAの信号を受けてこの駆動を行い、適切なゲート電圧(SiCなら+15〜18 V/負電圧など)を与えます。
