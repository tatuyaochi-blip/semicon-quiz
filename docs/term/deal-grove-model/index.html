Deal-Groveモデルとは

でぃーるぐろーぶもでる

シリコンの熱酸化を、酸化剤が酸化膜中を拡散してSi/SiO2界面でシリコンと反応する過程として表したモデル。薄いときは膜厚が時間に比例し、厚くなると時間の平方根に比例する。

「Deal-Groveモデル」は、1分野の4問の練習問題に出てきます(酸化・拡散など)。

この用語の分野: 酸化・拡散

Deal-Groveモデルの練習問題に挑戦

Deal-Groveモデルによると、熱酸化はどこで進むか。

  1. A酸化膜の最表面で、シリコン原子と酸化剤が反応する
  2. Bシリコン原子が酸化膜の表面まで拡散して反応する
  3. C酸化剤が酸化膜中を拡散し、Si/SiO2界面でシリコンと反応する
答えと解説を見る

正解：C. 酸化剤が酸化膜中を拡散し、Si/SiO2界面でシリコンと反応する

Deal-Groveモデル(1965年)では、酸化剤が気相から酸化膜の表面に取り込まれ、膜中を拡散してシリコンとの界面で反応し、新しい酸化膜ができると考えます。そのため酸化膜は界面側で成長し、界面は常に新しい面になります。酸化膜が厚くなるほど拡散距離が長くなり成長が遅くなります。この3段階の流束を等しいとおいて、直線則と放物線則を1つの式で表しました。

Deal-Groveモデルで、熱酸化の初期(酸化膜がまだ薄いとき)の酸化膜厚と時間の関係として正しいものはどれか。

  1. A膜厚は時間の平方根に比例する
  2. B膜厚は時間にほぼ比例する(直線的に増える)
  3. C膜厚は時間によらず一定である
答えと解説を見る

正解：B. 膜厚は時間にほぼ比例する(直線的に増える)

酸化膜が薄いうちは、酸化剤が膜を通り抜けるのは容易で、界面での反応の速さが律速になるため、膜厚は時間にほぼ比例して増えます(直線則、速度定数B/A)。膜が厚くなると酸化剤の膜中の拡散が律速になり、膜厚は時間の平方根に比例するようになります(放物線則、速度定数B)。切り替わりの目安は膜厚がA/2程度で、ドライ酸化では数十nm〜100 nm程度です。

解説の中の「Deal-Groveモデル」

  • Deal-Groveモデル(1965年)では、酸化剤が気相から酸化膜の表面に取り込まれ、膜中を拡散してシリコンとの界面で反応し、新しい酸化膜ができると考えます。

    Deal-Groveモデルによると、熱酸化はどこで進むか。

  • Deal-Groveモデルは厚い酸化膜の成長をよく表しますが、ドライ酸化で膜厚が数十nm以下の初期の領域では、実際の酸化がモデルの予測より速く進みます。

    ドライ酸化で厚さ数十nm以下の薄い酸化膜をつくるとき、Deal-Groveモデルからずれることとして知られているものは…

  • Deal-Groveモデルでは x² + Ax = B(t + τ) となり、膜が薄いうちは界面の反応が律速で膜厚は時間にほぼ比例し(直線則、x ≈ (B/A)t)、厚くなると酸化剤の膜中拡散が律速で時間の平方根に比例します(放物線則、x ≈ √(Bt))。

    熱酸化で酸化膜が十分厚くなったときの、酸化膜厚と酸化時間の関係として正しいものはどれか。

「Deal-Groveモデル」が出てくる問題(4問)

  1. Deal-Groveモデルによると、熱酸化はどこで進むか。
  2. Deal-Groveモデルで、熱酸化の初期(酸化膜がまだ薄いとき)の酸化膜厚と時間の関係として正しいものはどれか。
  3. ドライ酸化で厚さ数十nm以下の薄い酸化膜をつくるとき、Deal-Groveモデルからずれることとして知られているものはどれか。
  4. 熱酸化で酸化膜が十分厚くなったときの、酸化膜厚と酸化時間の関係として正しいものはどれか。
