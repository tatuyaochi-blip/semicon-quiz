ガベージコレクションとは

がべーじこれくしょん

SSDで、無効になったデータを含むブロックから有効なデータだけを別の場所に移し、ブロックを消去して空き領域をつくる処理。

この用語の分野: SRAM・フラッシュメモリ

解説の中の「ガベージコレクション」

  • ファイルを削除しても、OSは管理情報を書き換えるだけなので、SSDはそのデータが不要になったことを知らず、ガベージコレクションで無駄にコピーし続けます。

    OSが削除したファイルの領域をSSDに通知し、ガベージコレクションを効率化するためのコマンドはどれか。

  • 一部だけを書き換えるときも上書きはできず、新しいデータを空きページに書いて古いページを無効にし、後でガベージコレクションでまとめて消去します。

    NAND型フラッシュメモリでデータを消去する単位として正しいものはどれか。

  • オーバープロビジョニングは、ユーザーが使える容量より多くのフラッシュを搭載し、余剰領域を空きブロックの確保、ガベージコレクション、不良ブロックの代替に使うことです。

    SSDの「オーバープロビジョニング」の説明として正しいものはどれか。

「ガベージコレクション」が出てくる問題(6問)

  1. SSDのガベージコレクションの説明として正しいものはどれか。
  2. OSが削除したファイルの領域をSSDに通知し、ガベージコレクションを効率化するためのコマンドはどれか。
  3. NAND型フラッシュメモリでデータを消去する単位として正しいものはどれか。
  4. SSDの「オーバープロビジョニング」の説明として正しいものはどれか。
  5. SSDの「書き込み増幅(ライトアンプリフィケーション)」の説明として正しいものはどれか。
  6. NAND型フラッシュメモリで、データの読み出しと書き込み(プログラム)を行う基本的な単位はどれか。
