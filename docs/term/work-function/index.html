仕事関数とは

しごとかんすう

真空準位からフェルミ準位までのエネルギー差で、物質から電子を取り出すのに必要な最小のエネルギー。メタルゲートのしきい値電圧やショットキー障壁の高さを左右する。

この用語の分野: 半導体物性

解説の中の「仕事関数」

  • 仕事関数は、フェルミ準位にある電子を真空中に取り出すのに必要なエネルギーで、真空準位とフェルミ準位の差です。

    物質の仕事関数の定義として正しいものはどれか。

  • 一方、仕事関数はフェルミ準位から真空準位までの差で、不純物濃度で変わります。

    半導体の真空準位から伝導帯の下端までのエネルギー差を何と呼ぶか。

  • ただし高濃度にすると移動度が下がり、ばらつき(ドーパント数の揺らぎ)も増えるため、FinFETやGAAではチャネルをほぼ無ドープにして仕事関数でVthを決めています。

    nMOSFETのチャネル領域(p型基板)の不純物濃度を高くすると、しきい値電圧はどうなるか。

「仕事関数」が出てくる問題(7問)

  1. 物質の仕事関数の定義として正しいものはどれか。
  2. 半導体の真空準位から伝導帯の下端までのエネルギー差を何と呼ぶか。
  3. nMOSFETのチャネル領域(p型基板)の不純物濃度を高くすると、しきい値電圧はどうなるか。
  4. MOS構造のフラットバンド電圧の説明として正しいものはどれか。
  5. High-k/メタルゲートのトランジスタで、しきい値電圧を調整する主な手段の一つはどれか。
  6. ゲートラスト(リプレースメントメタルゲート)プロセスの説明として正しいものはどれか。
  7. チタンのターゲットを窒素を含むガス中でスパッタし、窒化チタン(TiN)膜を形成する方法を何と呼ぶか。
