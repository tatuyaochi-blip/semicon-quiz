仕事関数とは

しごとかんすう

真空準位からフェルミ準位までのエネルギー差で、物質から電子を取り出すのに必要な最小のエネルギー。メタルゲートのしきい値電圧やショットキー障壁の高さを左右する。

「仕事関数」は、4分野の7問の練習問題に出てきます(半導体物性, MOSFET, 先端トランジスタ(FinFET・GAA)など)。

この用語の分野: 半導体物性

仕事関数と電子親和力

仕事関数はフェルミ準位から真空準位までのエネルギーであるのに対し、電子親和力は伝導帯の底から真空準位までのエネルギーです。金属ではフェルミ準位がバンドの中にあるため、仕事関数は物質固有の値となり、一般に約4〜6 eVで、結晶面や表面の清浄度によって多少変わります。半導体の仕事関数は、電子親和力に伝導帯とフェルミ準位の差を加えた値です。シリコンの電子親和力は約4.05 eVなので、仕事関数は高濃度n型の約4.05 eVから高濃度p型の約5.17 eVまで変化します。

ショットキー障壁とコンタクト

金属がn型半導体に接すると、電子に対する理想的な(ショットキー・モット則による)障壁高さは、金属の仕事関数から半導体の電子親和力を引いた値になります。したがって、仕事関数の大きい金属をn型シリコンに接触させると、整流性のショットキー接触になるはずです。しかし実際には界面準位によってフェルミ準位がピン止めされるため、シリコン上の障壁高さは単純な法則が予測するほど金属の種類に左右されません。そこでオーミック接触は主に、コンタクト直下を高濃度にドーピングして障壁を薄くし、キャリアがトンネルで通り抜けられるようにして形成します。

しきい値電圧を決める役割

MOS構造では、ゲートとチャネルの仕事関数差がフラットバンド電圧を決め、これがそのまましきい値電圧に加わります。ポリシリコンゲートでは、nMOSには伝導帯に近いn+ポリ、pMOSには価電子帯に近いp+ポリを使うことで、自然に適切な値が得られました。high-k絶縁膜の導入でポリシリコンがメタルゲートに置き換わると、金属側で実効仕事関数を、nMOSでは約4.1 eV(TiAlなどアルミニウムを含む積層)、pMOSでは約5.1 eV(TiN系の積層)に近づける必要が生じました。FinFETやGAAデバイスではチャネルを低濃度にするため、薄膜を積み重ねて実効仕事関数を調整することが、複数のしきい値電圧を用意する主な手段になっています。

ゲートラストが有利な理由

メタルゲートの実効仕事関数はhigh-k膜との界面反応に左右され、ソース・ドレインの活性化に使う約1000 ℃のアニールによって予測できない変動を起こすことがあります。そこでゲートラスト(リプレースメントメタルゲート)プロセスでは、犠牲ポリシリコンゲートを使ってトランジスタを作り込み、高温工程の後にそれを除去してから、high-k膜と仕事関数メタルを堆積します。なお仕事関数は熱電子放出や光電子放出も支配しており、光電子分光法やケルビンプローブ法で測定されます。

仕事関数の練習問題に挑戦

物質の仕事関数の定義として正しいものはどれか。

  1. A真空準位から伝導帯の下端までのエネルギー差
  2. B伝導帯の下端から価電子帯の上端までのエネルギー差
  3. C真空準位からフェルミ準位までのエネルギー差
答えと解説を見る

正解：C. 真空準位からフェルミ準位までのエネルギー差

仕事関数は、フェルミ準位にある電子を真空中に取り出すのに必要なエネルギーで、真空準位とフェルミ準位の差です。半導体ではフェルミ準位が不純物濃度で動くため、仕事関数も変わります(シリコンで約4.05〜5.17 eV)。金属と半導体の仕事関数の差はショットキー障壁やMOSのしきい値電圧を左右し、メタルゲートの材料(TiN、TiAlなど)は狙ったしきい値になる仕事関数で選ばれます。

よくある質問

仕事関数と電子親和力の違いは何ですか?

仕事関数はフェルミ準位から真空準位までのエネルギー、電子親和力は伝導帯の底から真空準位までのエネルギーです。半導体では電子親和力は材料で決まりますが、仕事関数はドーピングによって変わります。

ドーピングでシリコンの仕事関数は変わりますか?

変わります。ドーピングによってフェルミ準位が移動するため、シリコンの仕事関数は高濃度n型の約4.05 eVから高濃度p型の約5.17 eVまで変化します。

ゲート金属の仕事関数がしきい値電圧に影響するのはなぜですか?

ゲートとチャネルの仕事関数差がフラットバンド電圧を決め、それがしきい値電圧を同じ量だけシフトさせるためです。そのため、ゲート金属を選んだり調整したりすることで、チャネルを高濃度にドーピングしなくてもしきい値電圧を設定できます。
