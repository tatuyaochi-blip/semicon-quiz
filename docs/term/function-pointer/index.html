関数ポインタとは

かんすうぽいんた

関数の番地を値として持つポインタ。int (*fp)(int, int) = add; のように、引数と戻り値の型を含めて宣言し、fp(1, 2) または (*fp)(1, 2) で指す先の関数を呼び出す。関数ポインタの配列を使えば、番号に応じて処理を切り替える表を作れる。ソートの比較関数を渡す qsort のようなコールバック、割り込みのベクタの表、状態機械の各状態の処理などに使われる。機械語では、番地をレジスタに入れて飛ぶ間接呼び出しになる。

「関数ポインタ」は、3分野の4問の練習問題に出てきます(命令セット・アセンブリ, C言語の基礎, ハードウェアセキュリティの最新動向など)。

関数ポインタの練習問題に挑戦

C言語の関数ポインタを使った呼び出し「(*fp)(x)」は、RISC-Vでは一般にどの命令で行われるか。

  1. A関数の番地をレジスタに入れて、jalrでそのレジスタの番地へ飛ぶ
  2. Bjalに関数の番地を即値で書いて飛ぶ
  3. Cbeqで関数の番地と比べて、等しければ飛ぶ
答えと解説を見る

正解：A. 関数の番地をレジスタに入れて、jalrでそのレジスタの番地へ飛ぶ

関数ポインタの指す先は実行時まで分からないので、命令の中に行き先を書くjalは使えません。そこで、ポインタの値をレジスタに読み込み、「jalr ra, 0(t0)」のようにレジスタの番地へ飛び、戻り先はraに残します。C++の仮想関数や共有ライブラリの関数の呼び出しも、同じような間接呼び出しです。行き先が変わるので、CPUは間接分岐の予測器で行き先を予想します。

制御フロー完全性をハードウェアで支える機能について、関数からの戻りを守るものと、関数ポインタなどによる間接的な呼び出しやジャンプを守るものの組み合わせとして、正しいものはどれか。

  1. A戻りはシャドウスタックやポインタ認証、間接的な呼び出しやジャンプは、飛び先の先頭に決められた印の命令があることを求める仕組みで守る
  2. B戻りは飛び先の先頭に決められた印の命令があることを求める仕組み、間接的な呼び出しやジャンプはシャドウスタックで守る
  3. C戻りはKPTI(カーネルページテーブル分離)、間接的な呼び出しやジャンプはIOMMUによるアドレスの変換で守る
答えと解説を見る

正解：A. 戻りはシャドウスタックやポインタ認証、間接的な呼び出しやジャンプは、飛び先の先頭に決められた印の命令があることを求める仕組みで守る

シャドウスタックは戻りアドレスを複製と比べ、ポインタ認証は戻りアドレスに付けた認証コードを確かめるので、どちらも関数からの戻りを守ります。間接的な呼び出しやジャンプについては、IntelのIBTやArmの分岐先識別(Branch Target Identification)が、飛び先の先頭に印の命令(x86ではENDBR64)があることを求め、関数の途中などへの分岐を例外にします。ただし、印のある場所ならどの関数にも飛べてしまうので、型の合う関数だけに飛び先を絞るコンパイラによる細かい確認と組み合わせることもあります。KPTIはMeltdownへの対策、IOMMUは機器のDMAを制限する仕組みで、制御の流れは守りません。

解説の中の「関数ポインタ」

  • 関数ポインタは、処理の切り替えの表や、割り込みのベクタ、コールバックなどに使われます。

    関数ポインタの配列を使った上のプログラムを実行したときの出力として、正しいものはどれか。

  • 関数ポインタの指す先は実行時まで分からないので、命令の中に行き先を書くjalは使えません。

    C言語の関数ポインタを使った呼び出し「(*fp)(x)」は、RISC-Vでは一般にどの命令で行われるか。

  • jalrは関数ポインタや仮想関数の呼び出しのように、行き先が実行時に決まるジャンプにも使われます。

    RISC-Vの疑似命令「ret」は、実際にはどの命令として実行されるか。

「関数ポインタ」が出てくる問題(4問)

  1. 関数ポインタの配列を使った上のプログラムを実行したときの出力として、正しいものはどれか。
  2. C言語の関数ポインタを使った呼び出し「(*fp)(x)」は、RISC-Vでは一般にどの命令で行われるか。
  3. 制御フロー完全性をハードウェアで支える機能について、関数からの戻りを守るものと、関数ポインタなどによる間接的な呼び出しやジャンプを守るものの組み合わせとして、正しいものはどれか。
