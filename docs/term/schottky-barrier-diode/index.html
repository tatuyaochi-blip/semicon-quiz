ショットキーバリアダイオードとは

しょっときーばりあだいおーど

金属と半導体の接合(ショットキー接合)を使ったダイオード。順方向電圧が低く、少数キャリアの蓄積がないため高速にスイッチングできる。

この用語の分野: PN接合・ダイオード

解説の中の「ショットキーバリアダイオード」

  • ショットキーバリアダイオードは金属と半導体の接合(ショットキー接合)を使い、多数キャリアだけで動作します。

    ショットキーバリアダイオードの特徴として正しいものはどれか。

  • ショットキーバリアダイオードは約0.2〜0.4 V、SiCダイオードは約1〜1.5 V、GaN系の青色LEDは約3 Vです。

    一般的なシリコンPN接合ダイオードの順方向電圧(電流が流れ始めるおよその電圧)はどれか。

  • ショットキーバリアダイオードは多数キャリアだけで動作するため、PN接合ダイオードのような少数キャリアの蓄積による逆回復電流がほとんどありません。

    SiCショットキーバリアダイオードが、インバータなどの還流ダイオードとして使われる主な利点はどれか。

「ショットキーバリアダイオード」が出てくる問題(4問)

  1. ショットキーバリアダイオードの特徴として正しいものはどれか。
  2. ベース-コレクタ間にショットキーバリアダイオードを並列に入れたトランジスタ(ショットキークランプ)の狙いとして正しいものはどれか。
  3. 一般的なシリコンPN接合ダイオードの順方向電圧(電流が流れ始めるおよその電圧)はどれか。
  4. SiCショットキーバリアダイオードが、インバータなどの還流ダイオードとして使われる主な利点はどれか。
