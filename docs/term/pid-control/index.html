PID制御とは

ぴーあいでぃーせいぎょ

偏差 e に比例する項(P)、偏差の積分に比例する項(I)、偏差の微分に比例する項(D)を足し合わせて操作量を決めるフィードバック制御。u = Kp(e + (1/Ti)∫e dt + Td·de/dt) と書き、Kp を比例ゲイン、Ti を積分時間、Td を微分時間と呼ぶ。比例は速さ、積分は定常偏差の除去、微分は振動の抑制を受け持つ。構造が簡単で、温度、モータ、電源、化学プロセスなど、産業の制御ループの大半で使われている。

「PID制御」は、2分野の9問の練習問題に出てきます(制御工学の基礎, アナログ・電子回路など)。

この用語の分野: 制御工学の基礎

3つの動作の役割

比例動作はゲインを上げるほど速くなりますが、それだけでは定常偏差(オフセット)が残り、上げすぎると振動します。積分動作は残った偏差を積み重ねて定常偏差を0にしますが、位相を遅らせて振動しやすくします。微分動作は偏差の変化を先読みして振動を抑えますが、雑音を増幅するので、ローパスフィルタを組み合わせた不完全微分にして使います。

ゲインの決め方

制御対象のモデルがあれば、ボード線図で位相余裕を確かめながら決められます。モデルがない場合には、ジーグラ・ニコルスの限界感度法やステップ応答法のような経験則で初期値を決め、オーバーシュートや整定時間を見ながら調整します。ジーグラ・ニコルスの値はかなり振動的な応答を与えるので、多くの場合はそこからゲインを下げます。

デジタルで実装するときの注意

マイコンでは、一定のサンプリング周期 Ts ごとに、積分を Σe·Ts、微分を (e[k] − e[k − 1])/Ts のような差分で計算します。操作量の飽和による積分ワインドアップには条件付き積分などで備え、目標値の急な変化による微分キックは、微分を測定値だけにかけて防ぎます。サンプリングと計算の遅れは位相を遅らせるので、サンプリング周波数はゲイン交差周波数より十分高く選びます。

PID制御の練習問題に挑戦

PI制御で、積分(I)動作を加える主な目的と、その副作用の組み合わせとして正しいものはどれか。

  1. A目的は高い周波数の雑音を取り除くことで、副作用は定常偏差が大きくなること
  2. B目的は一定の目標値や外乱に対する定常偏差をなくすことで、副作用は位相が遅れて振動しやすくなること
  3. C目的は偏差の変化を先読みして応答を速くし、行き過ぎを抑えることで、副作用は高い周波数の雑音を大きく増幅すること
答えと解説を見る

正解：B. 目的は一定の目標値や外乱に対する定常偏差をなくすことで、副作用は位相が遅れて振動しやすくなること

積分動作は偏差を時間で積み重ねて操作量にするので、偏差が少しでも残っている限り操作量を変え続け、最終的に定常偏差を0にします。一方、積分要素は位相を90°遅らせるので、位相余裕が減り、オーバーシュートや振動が起こりやすくなります。そこで、積分時間 Ti を短くしすぎないように調整します。応答を速くして行き過ぎを抑え、雑音を増幅しやすいのは、微分動作の特徴です。

PID制御の微分(D)動作の性質と、実装での対策の組み合わせとして正しいものはどれか。

  1. A偏差を時間で積み重ねて定常偏差をなくす働きがあり、積分ワインドアップを防ぐために、操作量の上限と下限の制限を取り払う
  2. B高い周波数ほどゲインが小さくなるので雑音に強く、ローパスフィルタを入れると位相が遅れて不安定になるので、フィルタは入れずにそのまま使うようにする
  3. C偏差の変化の速さに応じた操作量で振動を抑えるが、高い周波数の雑音を大きく増幅するので、ローパスフィルタと組み合わせた不完全微分にする
答えと解説を見る

正解：C. 偏差の変化の速さに応じた操作量で振動を抑えるが、高い周波数の雑音を大きく増幅するので、ローパスフィルタと組み合わせた不完全微分にする

微分動作は、偏差の変化の速さに比例した操作量を出し、偏差が大きくなる前に先回りして応じるので、振動を抑えて減衰を増やす働きがあります。微分要素 s のゲインは周波数に比例して大きくなるため、センサの雑音のような高い周波数の成分を大きく増幅してしまいます。そこで、Td·s/(1 + Td·s/N) のように一次のローパスフィルタを組み合わせ(不完全微分)、高い周波数でのゲインを N 倍程度に制限します。N は8〜20程度に選ぶことが多くあります。

よくある質問

PI制御とPID制御はどう使い分けますか?

流量、圧力、温度などの多くの制御ではPI制御で十分で、微分は雑音に弱いので使わないことも多くあります。慣性が大きく振動しやすい対象や、速い応答が必要なモータの位置の制御などでは、微分を加えて減衰を増やします。

並列形と標準形の違いは何ですか?

並列形は u = Kp·e + Ki∫e dt + Kd·de/dt と、3つのゲインを独立に書きます。標準形は Kp(e + (1/Ti)∫e dt + Td·de/dt) と書き、Ki = Kp/Ti、Kd = Kp·Td の関係があります。製品やライブラリによって形が違うので、パラメータを移すときは換算が必要です。

「PID制御」が出てくる問題(9問)

  1. PI制御で、積分(I)動作を加える主な目的と、その副作用の組み合わせとして正しいものはどれか。
  2. PID制御の微分(D)動作の性質と、実装での対策の組み合わせとして正しいものはどれか。
  3. PID制御で、目標値をステップ状に変えた瞬間に操作量が大きく跳ね上がる(微分キック)のを防ぐ方法として正しいものはどれか。
  4. ジーグラ・ニコルスの限界感度法では、比例制御だけでゲインを上げて持続振動が起きたときのゲイン Ku と振動の周期 Tu から、PID制御のパラメータを Kp = 0.6Ku、Ti = 0.5Tu、Td = 0.125Tu と決める。Ku = 8、Tu = 2 s のときの値として正しいものはどれか。
  5. マイコンで位置形のPI制御を実装し、PWMのデューティ比(0〜100%)を操作量とする。積分ワインドアップの対策として正しいものはどれか。
  6. サンプリング周期 Ts = 1 ms で、積分を長方形近似 Σe·Ts で計算するデジタルのPI制御がある。積分ゲイン Ki = 10 s⁻¹ で、偏差 e = 0.2 が50サンプルの間続いたとき、積分項の増加分として正しいものはどれか。
  7. オペアンプの反転増幅回路で、帰還抵抗をコンデンサに置き換えた回路は何と呼ばれるか。
  8. オペアンプの反転増幅回路で、入力抵抗をコンデンサに置き換えた回路は何と呼ばれるか。
