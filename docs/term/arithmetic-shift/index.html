算術シフトとは

さんじゅつしふと

符号付き整数の右シフトで、空いた上位のビットに符号ビットをコピーする方式。負の数を右に1ビットずらすと、2で割って小さい方に切り捨てた値になる。0を入れるのは論理シフト。

「算術シフト」は、2分野の2問の練習問題に出てきます(論理回路, 計算機算術など)。

この用語の分野: 計算機算術

算術シフトの練習問題に挑戦

2進数を1ビット左にシフトすると、値はどうなるか。(桁あふれがない場合)

  1. A2倍になる
  2. B半分になる
  3. C1だけ増える
答えと解説を見る

正解：A. 2倍になる

2進数では各桁が2倍ずつの重みをもつため、1ビット左にシフトして最下位に0を入れると値は2倍、右にシフトすると半分(切り捨て)になります。nビットのシフトは 2ⁿ 倍・1/2ⁿ です。乗除算器よりはるかに小さく速いため、コンパイラは x × 8 を x << 3 に置き換えます。符号付き数の右シフトでは、符号ビットを複製する算術シフトを使わないと負の数が正しく割れません。

8ビットの符号付き整数で −8(1111 1000)を算術右シフトで1ビット右にずらした結果はどれか。

  1. A124(0111 1100)
  2. B−16(1111 0000)
  3. C−4(1111 1100)
答えと解説を見る

正解：C. −4(1111 1100)

算術シフト(算術右シフト)では、空いた最上位のビットに符号ビットをコピーするので、1111 1000 は 1111 1100 になり、これは2の補数で −4 です。負の数でも、右に1ビットずらすと2で割った値になります。最上位に0を入れる論理右シフトでは 0111 1100 = 124 となり、符号が変わってしまいます。−16は左に1ビットずらした結果です。C言語で符号付き整数を右シフトしたときにどちらになるかは、処理系に任されていた点にも注意が必要です。

解説の中の「算術シフト」

  • 符号付き数の右シフトでは、符号ビットを複製する算術シフトを使わないと負の数が正しく割れません。
