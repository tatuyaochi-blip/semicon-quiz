算術シフトとは

さんじゅつしふと

符号付き整数の右シフトで、空いた上位のビットに符号ビットをコピーする方式。負の数を右に1ビットずらすと、2で割って小さい方に切り捨てた値になる。0を入れるのは論理シフト。

「算術シフト」は、3分野の3問の練習問題に出てきます(論理回路, 計算機算術, C言語の基礎など)。

この用語の分野: 計算機算術

算術右シフトのしくみ

算術右シフトは、2の補数で表した符号付き整数のビットを右へずらし、空いた上位のビットに元の最上位ビット(符号ビット)をコピーする操作です。正の数なら0、負の数なら1が入るので、符号が保たれます。たとえば8ビットの−8(1111 1000)を1ビット右にずらすと1111 1100で−4になります。nビットの算術右シフトの結果は、元の値を2のn乗で割って小さい方(負の無限大の方向)に丸めた値と一致します。上位に0を入れる論理右シフトは符号なし整数向けで、負の数に使うと大きな正の数になってしまいます。

割り算との違いと丸めの方向

算術右シフトは負の無限大の方向に丸めるため、0の方向に切り捨てる割り算とは、負の数で結果が変わることがあります。C言語(C99以降)では −7 / 2 は −3 ですが、−7(1111 1001)を算術右シフトで1ビットずらすと1111 1100で −4 です。そのためコンパイラは、符号付き整数を2のn乗で割る処理をシフトに置き換えるとき、値が負なら先に2のn乗−1を足してからシフトする、といった補正の命令を加えます。符号なし整数や、0以上とわかっている値なら、補正なしでシフトに置き換えられます。

算術左シフトとあふれ

左シフトでは、算術シフトでも論理シフトでも下位に0を入れるので、ビットの動きは同じです。x86のSAL命令とSHL命令が同じ動作をするのはこのためです。値は2のn乗倍になりますが、符号付き整数では、押し出されたビットや新しい最上位ビットが元の符号と違うと、あふれ(オーバーフロー)が起きて符号が変わります。たとえば8ビットの64(0100 0000)を1ビット左にずらすと1000 0000で−128になります。C言語では、負の値の左シフトや、結果が型に収まらない符号付き整数の左シフトは未定義動作とされているので注意が必要です。

命令セットと回路での実装

多くの命令セットは、算術右シフトと論理右シフトを別の命令として用意しています。RISC-VではSRA/SRAIとSRL/SRLI、ArmではASRとLSR、x86ではSARとSHRです。プログラミング言語では、Javaが >> を算術右シフト、>>> を論理右シフトとして区別しています。回路では、バレルシフタの上位側に入れる値を、符号ビットにするか0にするかを切り替えるだけで両方を実現できます。固定小数点のDSP処理では算術右シフトで値のスケールを下げますが、丸めが負の方向に偏るため、先に2の(n−1)乗を足して四捨五入に近づけることがあります。

算術シフトの練習問題に挑戦

2進数を1ビット左にシフトすると、値はどうなるか。(桁あふれがない場合)

  1. A2倍になる
  2. B半分になる
  3. C1だけ増える
答えと解説を見る

正解：A. 2倍になる

2進数では各桁が2倍ずつの重みをもつため、1ビット左にシフトして最下位に0を入れると値は2倍、右にシフトすると半分(切り捨て)になります。nビットのシフトは 2ⁿ 倍・1/2ⁿ です。乗除算器よりはるかに小さく速いため、コンパイラは x × 8 を x << 3 に置き換えます。符号付き数の右シフトでは、符号ビットを複製する算術シフトを使わないと負の数が正しく割れません。

8ビットの符号付き整数で −8(1111 1000)を算術右シフトで1ビット右にずらした結果はどれか。

  1. A124(0111 1100)
  2. B−16(1111 0000)
  3. C−4(1111 1100)
答えと解説を見る

正解：C. −4(1111 1100)

算術シフト(算術右シフト)では、空いた最上位のビットに符号ビットをコピーするので、1111 1000 は 1111 1100 になり、これは2の補数で −4 です。負の数でも、右に1ビットずらすと2で割った値になります。最上位に0を入れる論理右シフトでは 0111 1100 = 124 となり、符号が変わってしまいます。−16は左に1ビットずらした結果です。C言語で負の符号付き整数を右シフトしたときにどちらになるかは、処理系定義(処理系に任されている)である点にも注意が必要です。

よくある質問

算術シフトと論理シフトの違いは何ですか?

右シフトで空いた上位のビットに、算術シフトは符号ビットをコピーし、論理シフトは0を入れます。算術シフトは符号付き整数、論理シフトは符号なし整数やビット列の操作に使います。左シフトではどちらも下位に0を入れるので、ビットの動きは同じです。

算術右シフトは2で割るのと同じですか?

正の数では同じですが、負の数では違うことがあります。算術右シフトは負の無限大の方向に丸めるので −7 は −4 になり、0の方向に切り捨てるC言語の割り算では −3 になります。

C言語の >> は算術シフトですか?

符号なし整数と0以上の符号付き整数では、結果は2のべき乗での割り算と同じと決まっています。負の符号付き整数の右シフトは処理系定義で、多くのコンパイラは算術シフトを使いますが、移植性が必要なコードではこれに頼らない書き方が安全です。
