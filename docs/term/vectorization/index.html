ベクトル化とは

べくとるか

ループの中で要素ごとに行う同じ計算を、SIMD命令を使って複数の要素にまとめて行う形に変える最適化。繰り返しの間にデータの依存がないことが条件になる。

この用語の分野: コンパイラ

解説の中の「ベクトル化」

  • ベクトル化では、例えば4つの要素の計算を1つのSIMD命令で同時に行います。

    上のループを、SIMD命令を使ってベクトル化しにくい主な理由はどれか。

  • 自動ベクトル化は、配列の要素ごとに同じ計算をするループを見つけ、複数の要素をまとめて処理するSIMD命令に置き換える最適化です。

    コンパイラの自動ベクトル化で使われる命令の種類として正しいものはどれか。

  • 結果の違いを許す設定(高速な数学の設定など)を選ぶと、ベクトル化のために並べ替えることもあります。

    コンパイラが、浮動小数点数の足し算 (a + b) + c を、厳密な設定のもとでは a + (b + c) に勝手に…

「ベクトル化」が出てくる問題(4問)

  1. 上のループを、SIMD命令を使ってベクトル化しにくい主な理由はどれか。
  2. コンパイラの自動ベクトル化で使われる命令の種類として正しいものはどれか。
  3. コンパイラが、浮動小数点数の足し算 (a + b) + c を、厳密な設定のもとでは a + (b + c) に勝手に並べ替えない理由として正しいものはどれか。
  4. 上のようにx座標だけを合計する処理を、配列の構造体(各成分を別々の配列にする形)に書き換えると速くなりやすい理由はどれか。
