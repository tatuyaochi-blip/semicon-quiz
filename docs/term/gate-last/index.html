ゲートラスト(リプレースメントメタルゲート)とは

げーとらすと

先にダミーのゲートでトランジスタを形成し、ソース・ドレインの活性化などの高温工程の後でダミーを取り除いて、High-k膜と金属ゲートに置き換える製法。

「ゲートラスト(リプレースメントメタルゲート)」は、2分野の2問の練習問題に出てきます(先端トランジスタ(FinFET・GAA), CMP・洗浄など)。

この用語の分野: 先端トランジスタ(FinFET・GAA)

なぜゲートを最後に作るのか

ゲートリーク電流を減らし、ポリシリコンゲートの空乏化をなくすため、SiO2とポリシリコンに代わって酸化ハフニウム(HfO2)などのHigh-k絶縁膜と金属ゲートの組み合わせが使われるようになりました。ところが、ソース・ドレインの活性化アニールは1000 °C前後に達し、金属ゲートスタックの仕事関数を変化させたりHigh-k膜を劣化させたりして、しきい値電圧が狙いの値からずれてしまいます。ゲートラスト、すなわちリプレースメントメタルゲート(RMG)方式は、最も高温の工程が終わってから敏感なゲートスタックを入れることで、この問題を避けます。

リプレースメントメタルゲートの工程

まずポリシリコンのダミーゲートをパターニングし、これを基準にスペーサとソース・ドレイン領域の位置を合わせます。ソース・ドレインはイオン注入またはエピタキシャル成長で作り、高温で活性化します。次に全面に層間絶縁膜を堆積し、化学機械研磨(CMP)でダミーゲートの頂部が露出するまで平坦化します。ダミーのポリシリコンを選択的にエッチングで除去すると、スペーサの間に細い溝が残ります。この溝にHigh-k絶縁膜、nMOSとpMOSで別々に選んだ仕事関数メタル、低抵抗の埋め込みメタルを堆積し、2回目のCMPで余分な膜を取り除きます。

ゲートファーストとゲートラストの違い

ゲートファーストでは、従来のポリシリコンゲートと同じように、High-k膜と金属を工程の最初に堆積・パターニングします。工程数は少なくて済みますが、ゲートスタックが活性化アニールに耐えなければならず、特にpMOSで狙いどおりのしきい値電圧を保つのが難しくなります。ゲートラストはダミーゲート、追加のCMP、難しい溝の埋め込みが必要になる代わりに、仕事関数メタルを自由に選べます。Intelが45 nm世代でゲートラストを採用し、以降はこちらが主流になりました。High-k膜を最初に堆積するか、ダミー除去後に堆積するかによって派生方式が分かれます。

FinFETとGAAでのゲートラスト

リプレースメントゲートはFinFETにも自然に引き継がれました。ダミーを除去するとフィンの周りに空間が開くので、High-k膜と金属でフィンの側面を包み込めます。ゲートオールアラウンド(GAA)のナノシート構造では、同じ開口を使ってシリコンシート間の犠牲SiGe層をエッチングで除去し、その後、各シートの周囲の隙間をHigh-k膜と金属で埋めます。難しいのは、ゲート高さをそろえるためにダミー頂部を露出させるCMPを均一に止めることと、ゲート長で幅が決まる細い溝をボイドなく埋め込むことです。

ゲートラスト(リプレースメントメタルゲート)の練習問題に挑戦

ゲートラスト(リプレースメントメタルゲート)プロセスの説明として正しいものはどれか。

  1. A最初に金属ゲートをつくり、そのあとすべての高温工程を行う
  2. B先にダミーのゲートでトランジスタを形成し、高温工程のあとでダミーを取り除いて金属ゲートに置き換える
  3. Cゲートを使わないトランジスタをつくる
答えと解説を見る

正解：B. 先にダミーのゲートでトランジスタを形成し、高温工程のあとでダミーを取り除いて金属ゲートに置き換える

ソース・ドレインの活性化アニール(1000 ℃前後)などの高温工程は、High-k膜やメタルゲートの仕事関数を変化させるおそれがあります。ゲートラストでは、ポリシリコンのダミーゲートで先に高温工程を済ませ、層間膜を平らに削ってダミーを露出させてから取り除き、できた溝にHigh-k膜とメタルゲートを埋め込みます。Intelが45 nm世代で採用し、現在の主流です。

よくある質問

リプレースメントメタルゲートとは何ですか?

一時的なポリシリコンのダミーゲートに置き換えて作るゲートです。ダミーが高温工程の間トランジスタの形を決め、その後取り除かれて、High-k絶縁膜と金属で埋め直されます。

ゲートファーストとゲートラストの違いは?

ゲートファーストは最終的なHigh-k・メタルゲートを最初に形成するため、ソース・ドレインのアニールに耐える必要があります。ゲートラストは最後に形成するので、工程が増える代わりに仕事関数を高温から守れます。

ダミーゲートはなぜポリシリコンで作るのですか?

ポリシリコンは堆積と精密なパターニングが容易で、高温アニールにも耐えます。さらに、置き換えの段階では周囲の酸化膜や窒化膜のスペーサに対して選択的にエッチング除去できるからです。
