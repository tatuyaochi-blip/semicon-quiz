ゲートラスト(リプレースメントメタルゲート)とは

げーとらすと

先にダミーのゲートでトランジスタを形成し、ソース・ドレインの活性化などの高温工程の後でダミーを取り除いて、High-k膜と金属ゲートに置き換える製法。

この用語の分野: 先端トランジスタ(FinFET・GAA)

解説の中の「ゲートラスト(リプレースメントメタルゲート)」

  • ゲートラストでは、ポリシリコンのダミーゲートで先に高温工程を済ませ、層間膜を平らに削ってダミーを露出させてから取り除き、できた溝にHigh-k膜とメタルゲートを埋め込みます。

    ゲートラスト(リプレースメントメタルゲート)プロセスの説明として正しいものはどれか。

  • CMPは、STIの埋め込み酸化膜の平坦化、層間絶縁膜の平坦化、タングステンプラグやCu配線の余分な金属の除去、さらにゲートラストのダミーゲートの露出や、ウエハの貼り合わせ前の表面の仕上げなど、多くの工程で使われ、先端ロジックでは数十回にもなります。

    CMPが使われる工程の組み合わせとして正しいものはどれか。
