ゲートラスト(リプレースメントメタルゲート)とは

げーとらすと

先にダミーのゲートでトランジスタを形成し、ソース・ドレインの活性化などの高温工程の後でダミーを取り除いて、High-k膜と金属ゲートに置き換える製法。

「ゲートラスト(リプレースメントメタルゲート)」は、2分野の2問の練習問題に出てきます(先端トランジスタ(FinFET・GAA), CMP・洗浄など)。

この用語の分野: 先端トランジスタ(FinFET・GAA)

ゲートラスト(リプレースメントメタルゲート)の練習問題に挑戦

ゲートラスト(リプレースメントメタルゲート)プロセスの説明として正しいものはどれか。

  1. A最初に金属ゲートをつくり、そのあとすべての高温工程を行う
  2. B先にダミーのゲートでトランジスタを形成し、高温工程のあとでダミーを取り除いて金属ゲートに置き換える
  3. Cゲートを使わないトランジスタをつくる
答えと解説を見る

正解：B. 先にダミーのゲートでトランジスタを形成し、高温工程のあとでダミーを取り除いて金属ゲートに置き換える

ソース・ドレインの活性化アニール(1000 ℃前後)などの高温工程は、High-k膜やメタルゲートの仕事関数を変化させるおそれがあります。ゲートラストでは、ポリシリコンのダミーゲートで先に高温工程を済ませ、層間膜を平らに削ってダミーを露出させてから取り除き、できた溝にHigh-k膜とメタルゲートを埋め込みます。Intelが45 nm世代で採用し、現在の主流です。
