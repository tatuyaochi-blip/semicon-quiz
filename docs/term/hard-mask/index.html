ハードマスクとは

はーどますく

深い穴の加工などで、フォトレジストだけではマスクとして持たない場合に使う、窒化膜や炭素膜、金属などの硬いマスク。

この用語の分野: エッチング

解説の中の「ハードマスク」

  • エッチングのストッパーやハードマスクとしても使われます。

    シリコン窒化膜(Si3N4)の用途として正しいものはどれか。

  • TiNはバリア層やハードマスク、メタルゲートなどに使われます。

    チタンのターゲットを窒素を含むガス中でスパッタし、窒化チタン(TiN)膜を形成する方法を何と呼ぶか。

  • こうした無機膜などのマスクをハードマスクといいます。

    深い穴の加工などで、フォトレジストだけではマスクとして持たない場合に使われる、窒化膜や炭素膜などのマスクを何と呼ぶか。

「ハードマスク」が出てくる問題(4問)

  1. シリコン窒化膜(Si3N4)の用途として正しいものはどれか。
  2. チタンのターゲットを窒素を含むガス中でスパッタし、窒化チタン(TiN)膜を形成する方法を何と呼ぶか。
  3. 深い穴の加工などで、フォトレジストだけではマスクとして持たない場合に使われる、窒化膜や炭素膜などのマスクを何と呼ぶか。
  4. 上下の配線層の位置合わせのずれに強くするため、ビアを配線の溝に合わせて自己整合的に形成する技術はどれか。
