ハードマスクとは

はーどますく

深い穴の加工などで、フォトレジストだけではマスクとして持たない場合に使う、窒化膜や炭素膜、金属などの硬いマスク。

「ハードマスク」は、4分野の6問の練習問題に出てきます(成膜(CVD・PVD), エッチング, 配線プロセスなど)。

この用語の分野: エッチング

ハードマスクの練習問題に挑戦

シリコン窒化膜(Si3N4)の用途として正しいものはどれか。

  1. Aゲート電極や配線の主材料
  2. BLOCOSの酸化マスク、CMPのストッパー、表面の保護膜(パッシベーション)
  3. Cフォトレジストの代わり
答えと解説を見る

正解：B. LOCOSの酸化マスク、CMPのストッパー、表面の保護膜(パッシベーション)

シリコン窒化膜は酸素や水分、ナトリウムなどのイオンを通しにくく、硬く、酸化膜とエッチングの選択比をとりやすいため、選択酸化(LOCOS)のマスク、STI形成でのCMPストッパー、チップ表面を守るパッシベーション膜、エッチングのストッパーやハードマスク、ゲートのサイドウォール、自己整合コンタクトの保護などに使われます。比誘電率は約7で、配線間にはあまり使われません。

チタンのターゲットを窒素を含むガス中でスパッタし、窒化チタン(TiN)膜を形成する方法を何と呼ぶか。

  1. A真空蒸着
  2. B反応性スパッタリング
  3. Cイオン注入
答えと解説を見る

正解：B. 反応性スパッタリング

反応性スパッタリングは、アルゴンに窒素や酸素などの反応性ガスを加えてスパッタし、金属とガスを反応させて窒化物や酸化物の膜をつくる方法です。化合物のターゲットは割れやすく電気を通しにくいものもあるため、扱いやすい金属ターゲットから化合物の膜を得られる利点があり、ガスの流量で組成を調整できます。TiNはバリア層、ハードマスク、メタルゲートの仕事関数調整などに使われます。

「ハードマスク」が出てくる問題(6問)

  1. シリコン窒化膜(Si3N4)の用途として正しいものはどれか。
  2. チタンのターゲットを窒素を含むガス中でスパッタし、窒化チタン(TiN)膜を形成する方法を何と呼ぶか。
  3. 深い穴の加工などで、フォトレジストだけではマスクとして持たない場合に使われる、窒化膜や炭素膜などのマスクを何と呼ぶか。
  4. 酸化膜のエッチング速度が100 nm/min、マスクの削れる速度が20 nm/minのとき、マスクに対する選択比はいくらか。
  5. 上下の配線層の位置合わせのずれに強くするため、ビアを配線の溝に合わせて自己整合的に形成する技術はどれか。
  6. Low-k層間絶縁膜として使われる代表的な材料はどれか。
