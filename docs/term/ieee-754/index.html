IEEE 754とは

あいとりぷるいーななごーよん

浮動小数点数の表し方と演算の規則を定めた国際規格。単精度(32ビット)・倍精度(64ビット)などの形式、丸めの方法、無限大やNaNなどの特殊値を定め、計算結果がコンピュータによらずそろうようにしている。

「IEEE 754」は、1分野の14問の練習問題に出てきます(計算機算術など)。

この用語の分野: 計算機算術

ビット列で値を表す仕組み

IEEE 754の2進浮動小数点数は、符号ビット、バイアス付きの指数部、仮数部を格納し、正規化数では (−1)^符号 × 1.仮数部 × 2^(指数 − バイアス) を表します。単精度(FP32)はそれぞれ1、8、23ビットでバイアスは127、倍精度(FP64)は1、11、52ビットでバイアスは1023です。先頭の1は省略される(隠れビット)ため、精度は24ビットと53ビットとなり、10進数でおよそ7桁と15〜16桁に相当します。たとえば1.0は格納される指数が127、仮数部がすべて0で、FP32では0x3F800000になります。

特殊な値と例外

指数部の両端の値は予約されています。指数部がすべて0のときは±0と非正規化数を表します。非正規化数は隠れビットの1をなくし、最小の正規化数より下の隙間を等間隔の微小な値で埋めます(漸進的アンダーフロー)。指数部がすべて1のときは、仮数部が0なら±無限大、それ以外ならNaN(非数)です。0でない数を0で割ると無限大、0 ÷ 0や∞ − ∞はNaNになり、NaNは自分自身とも等しくないと判定されます。+0と−0は等しいと判定されますが、除数にすると符号が逆の無限大になります。既定では、これらの事象はプログラムを止めずにステータスフラグを立てます。

丸めと精度の限界

加算、乗算、除算、平方根などの基本演算は正しく丸めることが求められ、結果は厳密な値を表現可能な値に丸めたものと一致します。既定の丸めモードは最近接偶数丸め(最も近い値に丸め、ちょうど中間なら偶数側を選ぶ)で、値が系統的に大きい側へずれるのを防ぎます。1.0とその次の値との差であるマシンイプシロンは、FP32で2⁻²³(約1.19 × 10⁻⁷)、FP64で2⁻⁵²です。整数を正確に表せるのはそれぞれ2²⁴と2⁵³までです。0.1のような10進小数は正確に表現できず、浮動小数点の加算は結合法則を満たさないため、結果は許容誤差を設けて比較します。

浮動小数点と固定小数点の違い

固定小数点数は値が等間隔に並ぶため、絶対誤差が一定で、表せる範囲は狭くなります。浮動小数点は、FP64でおよそ10⁻³⁰⁸から10³⁰⁸という非常に広い範囲で相対誤差をほぼ一定に保てますが、その代わり桁合わせ、正規化、丸めのためのハードウェアが複雑になります。規格には指数部5ビットの半精度や、丸めを1回だけ行う積和演算(FMA)も定められています。機械学習向けハードウェアでは、FP32と同じ8ビットの指数部に7ビットの仮数部を組み合わせたbfloat16がよく使われます。符号化の考え方は同じですが、規格に定められた形式ではありません。

IEEE 754の練習問題に挑戦

IEEE 754の浮動小数点数を構成する3つの部分の組み合わせとして正しいものはどれか。

  1. A符号、指数部、仮数
  2. B整数部、小数部、桁上げ
  3. C上位バイト、下位バイト、パリティ
答えと解説を見る

正解：A. 符号、指数部、仮数

浮動小数点数は、値を「(−1)^符号 × 1.仮数 × 2^指数」の形で表し、正か負かを表す符号ビット、2の何乗かを表す指数部、有効数字を表す仮数の3つの部分で記録します。指数で小数点の位置を動かせるので、非常に小さな数から大きな数までを同じビット数で表せます。整数部と小数部に分けるのは固定小数点の考え方で、パリティは誤りの検出のためのビットです。

IEEE 754の単精度(32ビット)の浮動小数点数で、符号・指数部・仮数に割り当てられるビット数の組み合わせはどれか。

  1. A1・11・20
  2. B1・8・23
  3. C1・5・26
答えと解説を見る

正解：B. 1・8・23

単精度(FP32)は、符号1ビット、指数部8ビット、仮数23ビットの合計32ビットです。正規化された数では仮数の先頭の1を省略しているので、精度は24ビット分あり、10進数でおよそ7桁です。倍精度(FP64)は符号1・指数部11・仮数52ビットで、指数部が広く精度も高くなります。1・11・20は倍精度の指数部の幅と混同した組み合わせで、1・5・26は半精度の指数部の幅と混同しています。

よくある質問

浮動小数点で0.1 + 0.2が0.3にならないのはなぜですか?

これらの10進数はどれも2進数で正確に表せないため丸めた値で格納され、その丸め誤差が打ち消し合わないからです。倍精度では和が0.30000000000000004になるので、等しいかどうかは許容誤差を使って判定します。

IEEE 754単精度の指数バイアスはいくつですか?

バイアスは127で、実際の指数は格納された8ビットの値から127を引いたものです。格納値0と255はゼロ、非正規化数、無限大、NaNのために予約されており、正規化数には1〜254が使われます。

NaNが自分自身と等しくならないのはなぜですか?

IEEE 754ではNaNを含む比較はすべて「順序なし」と定められているため、xがNaNのときx == xは偽になります。この性質に頼らず、isnanのような専用の関数で判定するのが確実です。

解説の中の「IEEE 754」

  • IEEE 754では、0でない数を0で割ると、符号に応じて正または負の無限大を返すと定めています。

    IEEE 754の浮動小数点数の演算で、正の数を0で割ったときの結果として規格で定められているものはどれか。

  • IEEE 754の既定の丸めは、表せる値のうち最も近いものに丸め、ちょうど中間のときは最下位のビットが0(偶数)になる方を選ぶ最近接偶数丸めです。

    IEEE 754で既定の丸めの方法として定められているものはどれか。

  • IEEE 754では、NaNは「数ではない」値なので、どんな値との比較でも等しくならず、NaN自身との比較でも x == x は偽になります(x != x は真)。

    x がNaNのとき、多くのプログラミング言語で x == x を評価した結果はどれか。
