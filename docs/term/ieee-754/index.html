IEEE 754とは

あいとりぷるいーななごーよん

浮動小数点数の表し方と演算の規則を定めた国際規格。単精度(32ビット)・倍精度(64ビット)などの形式、丸めの方法、無限大やNaNなどの特殊値を定め、計算結果がコンピュータによらずそろうようにしている。

「IEEE 754」は、1分野の14問の練習問題に出てきます(計算機算術など)。

この用語の分野: 計算機算術

IEEE 754の練習問題に挑戦

IEEE 754の浮動小数点数を構成する3つの部分の組み合わせとして正しいものはどれか。

  1. A符号、指数部、仮数
  2. B整数部、小数部、桁上げ
  3. C上位バイト、下位バイト、パリティ
答えと解説を見る

正解：A. 符号、指数部、仮数

浮動小数点数は、値を「(−1)^符号 × 1.仮数 × 2^指数」の形で表し、正か負かを表す符号ビット、2の何乗かを表す指数部、有効数字を表す仮数の3つの部分で記録します。指数で小数点の位置を動かせるので、非常に小さな数から大きな数までを同じビット数で表せます。整数部と小数部に分けるのは固定小数点の考え方で、パリティは誤りの検出のためのビットです。

IEEE 754の単精度(32ビット)の浮動小数点数で、符号・指数部・仮数に割り当てられるビット数の組み合わせはどれか。

  1. A1・11・20
  2. B1・8・23
  3. C1・5・26
答えと解説を見る

正解：B. 1・8・23

単精度(FP32)は、符号1ビット、指数部8ビット、仮数23ビットの合計32ビットです。正規化された数では仮数の先頭の1を省略しているので、精度は24ビット分あり、10進数でおよそ7桁です。倍精度(FP64)は符号1・指数部11・仮数52ビットで、指数部が広く精度も高くなります。1・11・20は倍精度の指数部の幅と混同した組み合わせで、1・5・26は半精度の指数部の幅と混同しています。

解説の中の「IEEE 754」

  • IEEE 754では、0でない数を0で割ると、符号に応じて正または負の無限大を返すと定めています。

    IEEE 754の浮動小数点数の演算で、正の数を0で割ったときの結果として規格で定められているものはどれか。

  • IEEE 754の既定の丸めは、表せる値のうち最も近いものに丸め、ちょうど中間のときは最下位のビットが0(偶数)になる方を選ぶ最近接偶数丸めです。

    IEEE 754で既定の丸めの方法として定められているものはどれか。

  • IEEE 754では、NaNは「数ではない」値なので、どんな値との比較でも等しくならず、NaN自身との比較でも x == x は偽になります(x != x は真)。

    x がNaNのとき、多くのプログラミング言語で x == x を評価した結果はどれか。

「IEEE 754」が出てくる問題(14問)

  1. IEEE 754の浮動小数点数を構成する3つの部分の組み合わせとして正しいものはどれか。
  2. IEEE 754の単精度(32ビット)の浮動小数点数で、符号・指数部・仮数に割り当てられるビット数の組み合わせはどれか。
  3. IEEE 754の倍精度(64ビット)の浮動小数点数で、指数部と仮数のビット数の組み合わせとして正しいものはどれか。
  4. IEEE 754の単精度で、指数部に記録される値が130のとき、実際の指数(2の何乗か)はいくつか。
  5. IEEE 754の正規化数で、仮数の先頭の1を記録しない(隠れビット)ことの効果として正しいものはどれか。
  6. 10進数の1.0を、IEEE 754の単精度で表したビット列を16進数で書くとどれか。
  7. IEEE 754の単精度のマシンイプシロン(1と、1の次に大きい表せる数との差)はいくらか。
  8. IEEE 754の非正規化数(サブノーマル数)の役割として正しいものはどれか。
  9. IEEE 754の浮動小数点数の演算で、正の数を0で割ったときの結果として規格で定められているものはどれか。
  10. IEEE 754の単精度で、指数部がすべて1(255)のビット列が表すものの説明として正しいものはどれか。
  11. IEEE 754の浮動小数点数で、+0と−0についての説明として正しいものはどれか。
  12. IEEE 754で既定の丸めの方法として定められているものはどれか。
  13. IEEE 754の単精度の浮動小数点数で、0から始めてすべての整数を正確に表せる上限はどれか。
  14. x がNaNのとき、多くのプログラミング言語で x == x を評価した結果はどれか。
