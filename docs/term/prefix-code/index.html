接頭符号とは

せっとうふごう

どの符号語も、ほかの符号語の先頭部分になっていない符号。例えば {0, 10, 110, 111} は接頭符号で、受信したビット列を先頭から読み、符号語に一致した時点で区切れば、後ろのビットを待たずに1通りに復号できる。この性質から瞬時符号ともいう。符号長の組がクラフトの不等式を満たせば、その長さの接頭符号を作れる。ハフマン符号は接頭符号である。{0, 01, 11} のように、接頭符号でなくても1通りに復号できる符号もあるが、復号するときに後ろのビットまで見る必要がある。

「接頭符号」は、1分野の5問の練習問題に出てきます(情報理論と符号の基礎など)。

接頭符号の練習問題に挑戦

4つの記号に割り当てた次の符号語の組のうち、接頭符号(どの符号語も、ほかの符号語の先頭部分になっていない符号)になっているものはどれか。

  1. A{0, 01, 011, 111}
  2. B{0, 10, 110, 111}
  3. C{00, 01, 1, 10}
答えと解説を見る

正解：B. {0, 10, 110, 111}

接頭符号では、ある符号語を読み終えた時点で1つの記号だと確定できるので、後ろのビットを待たずにすぐ復号できます(瞬時符号)。{0, 10, 110, 111} では、どの符号語も、ほかの符号語の先頭部分になっていません。{0, 01, 011, 111} では0が01や011の、{00, 01, 1, 10} では1が10の先頭部分になっています。

記号A、B、C、Dに、符号語 A = 0、B = 10、C = 110、D = 111 を割り当てた接頭符号がある。ビット列 110100111 を先頭から復号した結果はどれか。

  1. ACABD
  2. BCBDA
  3. CCBAD
答えと解説を見る

正解：C. CBAD

先頭から読み、符号語に一致した時点で区切ります。110 で C、続く 10 で B、0 で A、残りの 111 で D となり、CBAD です。接頭符号なので、このように区切り方が1通りに決まり、区切りの記号を入れなくても復号できます。

  1. 4つの記号に割り当てた次の符号語の組のうち、接頭符号(どの符号語も、ほかの符号語の先頭部分になっていない符号)になっているものはどれか。

  3. 4つの記号A〜Dに、次の長さ(ビット数)の符号語を割り当てて、0と1からなる接頭符号を作りたい。作ることができる符号長の組み合わせはどれか。
  4. 0と1からなる接頭符号を作っている。長さ2の符号語 00 と 01 をすでに使っているとき、接頭符号の条件を保ったまま追加できる、長さ3の符号語の最大の個数はどれか。
  5. 固定長符号と比べたときの、可変長符号の説明として、正しいものはどれか。
