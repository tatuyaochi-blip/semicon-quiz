クロックの不確かさとは

くろっくのふたしかさ

ジッタや、まだ確定していないクロックスキューの見込みとして、タイミング解析で使える時間から差し引く余裕。SDCではset_clock_uncertaintyで指定し、クロックツリーができる前の段階ではスキューの分も含めて大きめに設定する。

「クロックの不確かさ」は、2分野の4問の練習問題に出てきます(タイミング解析とCDC, LSI設計フロー・EDAなど)。

この用語の分野: タイミング解析とCDC

クロックの不確かさの練習問題に挑戦

フリップフロップ間の経路で、クロック→出力遅延が 0.15 ns、組み合わせ回路の最大遅延が 2.2 ns、セットアップ時間が 0.15 ns である。スキューとクロックの不確かさを無視すると、この経路で動作できる最大のクロック周波数はいくらか。

  1. A約 425 MHz
  2. B約 455 MHz
  3. C400 MHz
答えと解説を見る

正解：C. 400 MHz

最小のクロック周期は、クロック→出力遅延、組み合わせ回路の遅延、セットアップ時間の合計です。0.15 + 2.2 + 0.15 = 2.5 ns なので、最大周波数は 1 ÷ 2.5 ns = 400 MHz になります。約 425 MHz はセットアップ時間を入れ忘れた 2.35 ns から、約 455 MHz は組み合わせ回路の遅延 2.2 ns だけから計算した値です。チップ全体の最大周波数は、このような経路のうち最も厳しいクリティカルパスで決まります。

クロック周期 1.25 ns(800 MHz)の経路で、クロック→出力遅延と組み合わせ回路の遅延の合計が 1.05 ns、セットアップ時間が 0.05 ns、セットアップ用のクロックの不確かさが 0.05 ns に設定されている。セットアップのスラックはいくらか。

  1. A0.15 ns
  2. B0.20 ns
  3. C0.10 ns
答えと解説を見る

正解：C. 0.10 ns

クロックの不確かさは、ジッタやまだ確定していないスキューの見込みとして、使える時間から差し引く余裕です。要求時刻は 1.25 − 0.05(不確かさ)− 0.05(セットアップ時間)= 1.15 ns、到着時刻は 1.05 ns なので、スラックは 0.10 ns です。0.15 ns は不確かさを引き忘れた値、0.20 ns はセットアップ時間も不確かさも引かなかった値です。配置配線の前はクロックツリーがないので、スキューの分も不確かさに含めて大きめに設定するのが一般的です。

「クロックの不確かさ」が出てくる問題(4問)

  1. フリップフロップ間の経路で、クロック→出力遅延が 0.15 ns、組み合わせ回路の最大遅延が 2.2 ns、セットアップ時間が 0.15 ns である。スキューとクロックの不確かさを無視すると、この経路で動作できる最大のクロック周波数はいくらか。
  2. クロック周期 1.25 ns(800 MHz)の経路で、クロック→出力遅延と組み合わせ回路の遅延の合計が 1.05 ns、セットアップ時間が 0.05 ns、セットアップ用のクロックの不確かさが 0.05 ns に設定されている。セットアップのスラックはいくらか。
  3. クロックの不確かさの設定で、セットアップ用には周期ジッタを含めるが、ホールド用には含めないことが多い。その理由として正しいものはどれか。
  4. タイミングの制約(SDC)で、クロックのジッタやスキューの見込みなどとしてクロックの周期から差し引いておく余裕を指定するものはどれか。
