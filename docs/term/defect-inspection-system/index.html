欠陥検査装置とは

けっかんけんさそうち

ウエハ上の異物やパターンの欠陥を見つける装置。光を当てたときの散乱光を検出する方式や、隣り合うダイの画像を比較する方式などがある。

この用語の分野: 計測・分析

解説の中の「欠陥検査装置」

  • 欠陥検査装置は1枚のウエハから数千個の欠陥を検出することもあり、それぞれの原因を調べるには種類の分類が必要です。

    検査で見つかった欠陥をSEMで撮影し、その画像から欠陥の種類を自動で分類する機能はどれか。

「欠陥検査装置」が出てくる問題(3問)

  1. ウエハ上の異物やパターン欠陥を検出する欠陥検査装置で使われる代表的な原理はどれか。
  2. ウエハの欠陥検査装置で、パターンの像を直接見る明視野方式と比べた、散乱光だけを捉える暗視野方式の特徴として正しいものはどれか。
  3. 検査で見つかった欠陥をSEMで撮影し、その画像から欠陥の種類を自動で分類する機能はどれか。
