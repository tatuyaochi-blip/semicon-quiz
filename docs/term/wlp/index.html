WLP(ウエハレベルパッケージ)とは

だぶりゅーえるぴー

ウエハの状態のまま再配線や外部端子の形成までを行い、その後で個片化するパッケージ。チップとほぼ同じ大きさの小型のパッケージになる。

この用語の分野: パッケージ・実装

解説の中の「WLP(ウエハレベルパッケージ)」

  • WLPでは、ダイシングする前のウエハの状態で、再配線層やはんだボールなどの外部端子を一括して形成し、最後に個々のチップに切り分けます。

    ウエハレベルパッケージ(WLP)の特徴として正しいものはどれか。

  • ウエハレベルパッケージやファンアウトパッケージ、インターポーザなどで使われ、配線の微細化が進んでいます。

    チップやウエハの表面に形成し、電極の位置を外部端子の位置まで引き回すための配線層を何と呼ぶか。

「WLP(ウエハレベルパッケージ)」が出てくる問題(6問)

  1. ウエハレベルパッケージ(WLP)の特徴として正しいものはどれか。
  2. ファンアウト型ウエハレベルパッケージ(FOWLP)の特徴として正しいものはどれか。
  3. TSMCが開発したファンアウト型ウエハレベルパッケージの技術で、2016年にスマートフォンのプロセッサで採用されて広く知られるようになったものはどれか。
  4. ファンアウト型ウエハレベルパッケージで、切り出したチップを支持体の上に間隔をあけて並べ、樹脂で埋めて作り直したウエハ状のものを何と呼ぶか。
  5. ファンアウト型ウエハレベルパッケージの製造で、チップを樹脂で封止する際に、樹脂の流動や硬化時の収縮によってチップの位置がずれる問題を何と呼ぶか。
  6. チップやウエハの表面に形成し、電極の位置を外部端子の位置まで引き回すための配線層を何と呼ぶか。
