PWM(パルス幅変調)とは

ぴーだぶりゅーえむ

周期を一定にしたまま、出力がHighになっている時間の長さを変えて、平均の電圧や電力を調整する方式。LEDの明るさやモーターの速さの調整に使う。

「PWM(パルス幅変調)」は、4分野の6問の練習問題に出てきます(組込み・ファームウェア, パワー半導体, AD/DA変換など)。

この用語の分野: 組込み・ファームウェア

デューティ比と平均値

パルス幅変調(PWM)では、スイッチングの周期 T を一定にしたまま、Highの時間 t_on を変えます。デューティ比 D = t_on/T が平均出力を決め、平均出力はパルス振幅の D 倍になります。たとえば5 Vの信号をデューティ比40%で出すと平均は2 Vです。情報はすべてタイミングで表されるため、出力段は2つのレベルのどちらかにしかなりません。モーター、ヒーター、LEDを見る人の目、RCやLCのフィルタなど、周期に比べて反応の遅い負荷には、主にこの平均値が効きます。

マイコンのタイマによるPWM生成

ハードウェアタイマはクロックパルスを0から周期の値まで数え、そこで最初に戻ります。出力は各周期の始めにHighになり、カウンタがコンペアレジスタの値と一致したところでLowになります。周期が1000カウントでコンペア値が250なら、出力がHighの時間は25%です。分解能は1周期あたりのカウント数で決まるので、タイマのクロックが一定なら、PWMの周波数を上げるほどデューティ比の刻みは粗くなります。いったん設定すれば、タイマはCPUの手を借りずに動き続けます。アナログのPWM回路は、制御電圧を三角波やのこぎり波と比較することで同じ働きをします。

スイッチングが高効率な理由

スイッチングトランジスタは、両端の電圧がほとんどかからない完全オンか、電流がほとんど流れない完全オフのどちらかの状態にあります。そのため、リニア回路で中間の電圧に保たれるトランジスタに比べ、消費する電力ははるかに小さくなります。損失は主にオン抵抗と、状態が切り替わる短い遷移の間に生じます。周波数は負荷に合わせて選びます。LEDのちらつきが見えず、モーター電流が巻線のインダクタンスで平滑化される程度には高く、モーターのうなり音を避けるために可聴域より上にすることも多い一方、スイッチング損失が支配的になるほど高くはしません。

DACとしての利用とパワーエレクトロニクス

PWMをローパスフィルタに通すと、専用のDACハードウェアなしで簡易的なD/A変換器になります。PWM周波数をフィルタのカットオフより十分高くするとリップルは減りますが、応答は遅くなります。同じ原理はスイッチング電源でも使われており、理想的な降圧(バック)コンバータは入力電圧の D 倍を出力します。インバータもパワーデバイスを数kHzから数十kHzでスイッチングし、パルス幅を変えながら交流を合成します。三相モーター用のインバータでは、1つのレグに2個ずつ、計6個のスイッチを使います。

PWM(パルス幅変調)の練習問題に挑戦

マイコンでPWM信号をローパスフィルタに通してアナログ電圧をつくる方法で、出力電圧を決めるものはどれか。

  1. Aパルスのデューティ比(1周期のうちオンの時間の割合)
  2. Bパルスの色
  3. Cマイコンのメモリ容量
答えと解説を見る

正解：A. パルスのデューティ比(1周期のうちオンの時間の割合)

PWM信号をローパスフィルタで平均化すると、出力電圧は「振幅 × デューティ比」になり、5 Vで40%なら約2 Vです。分解能はタイマのカウント数で決まり、PWM周波数をフィルタのカットオフより十分高くするとリプルが減ります。専用のDACなしでアナログ電圧を作れるため、LEDの調光、モーター速度の制御、簡易的な音声出力に使われますが、応答の速さと精度はリプルとのトレードオフになります。

周期が1000カウントのPWM信号で、1周期のうち250カウントの間だけ出力を1(High)にしている。デューティ比はいくらか。

  1. A75%
  2. B25%
  3. C250%
答えと解説を見る

正解：B. 25%

デューティ比は、1周期のうち出力がHighになっている時間の割合で、250÷1000=25%です。PWM(パルス幅変調)は、周期を一定にしたままHighの時間の長さを変えることで、平均の電圧や電力を調整します。マイコンのタイマは、カウンタの値と比較の値を比べて出力を切り替えることで、CPUの手を借りずにPWM信号を出し続けられます。

よくある質問

PWMのデューティ比はどう計算しますか?

Highの時間を周期で割ります。デューティ比 = t_on / T です。たとえば1000カウントの周期のうち250カウントがHighなら25%で、平均出力はパルス振幅の25%になります。

PWMは周波数と電圧のどちらを変えるのですか?

基本的な形ではどちらも変えません。周波数とパルスの振幅は一定のまま、パルスの幅だけを変えます。オンの時間の割合が変わるので、負荷に届く平均の電圧や電力が変わります。

モーター駆動でPWMがリニアレギュレータより効率が良いのはなぜですか?

リニアレギュレータは、全電流が流れるトランジスタに余分な電圧をかけて落とすため、それが熱として無駄になります。PWMではトランジスタが完全オンか完全オフのどちらかなので、電圧と電流の積、つまり損失が小さく抑えられます。
