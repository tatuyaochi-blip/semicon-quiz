特権モードとは

とっけんもーど

OSのカーネルだけが使える、CPUの動作モード。ページテーブルの設定や入出力の操作など危険な命令を実行でき、アプリケーションが動くユーザモードと区別される。

「特権モード」は、1分野の4問の練習問題に出てきます(OSとハードウェアなど)。

この用語の分野: OSとハードウェア

特権モードの練習問題に挑戦

CPUに特権モード(カーネルモード)とユーザモードを設ける主な目的はどれか。

  1. Aアプリケーションの命令を、カーネルの命令より速く優先して実行できるようにするため
  2. Bアプリケーションがページテーブルや装置を勝手に操作できないよう保護するため
  3. C1つのCPUで同時に2つの命令を実行できるようにするため
答えと解説を見る

正解：B. アプリケーションがページテーブルや装置を勝手に操作できないよう保護するため

ページテーブルの書き換えや入出力装置の操作、割り込みの禁止などをアプリケーションが自由にできると、ほかのプログラムのメモリを壊したりシステム全体を止めたりできてしまいます。そこでCPUは、これらの命令を特権モードでしか実行できないようにし、OSのカーネルだけが使えるようにしています。ユーザモードで実行しようとすると例外になります。速さや同時実行のためのしくみではありません。

「特権モード」が出てくる問題(4問)

  1. CPUに特権モード(カーネルモード)とユーザモードを設ける主な目的はどれか。
  2. アプリケーションがファイルの読み書きなどをOSに依頼するしくみを何と呼ぶか。
  3. 割り込みや例外の処理を終えて元のプログラムに戻るとき、通常の関数の戻り命令ではなく、専用の復帰命令(RISC-Vのsret・mretなど)を使う理由はどれか。
  4. 小さなデータを1バイトずつ書き出すときに、毎回システムコールを呼ぶより、ユーザ空間のバッファにためてからまとめて書き出す方が速くなる主な理由はどれか。
