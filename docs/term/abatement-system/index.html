除害装置とは

じょがいそうち

製造装置から出る排ガスに含まれる有害な物質を、燃焼・吸着・水洗などで取り除く装置。

この用語の分野: 環境安全

解説の中の「除害装置」

  • これらのガスは地球温暖化係数がCO2の数千倍以上と大きいため、使用後は除害装置で分解してから排出します。

    シリコン酸化膜(SiO2)のドライエッチングに主に使われるガスはどれか。

  • シリンダーキャビネット、漏えい検知器、緊急遮断弁、除害装置を組み合わせて厳重に管理します。

    n型不純物の導入に使われるホスフィン(PH3)やアルシン(AsH3)の特徴として正しいものはどれか。

  • NF3の地球温暖化係数はCO2の約1万6000倍と大きいため、除害装置で分解して排出します。

    三フッ化窒素(NF3)の主な用途はどれか。

「除害装置」が出てくる問題(7問)

  1. シリコン酸化膜(SiO2)のドライエッチングに主に使われるガスはどれか。
  2. n型不純物の導入に使われるホスフィン(PH3)やアルシン(AsH3)の特徴として正しいものはどれか。
  3. 三フッ化窒素(NF3)の主な用途はどれか。
  4. 真空を使うプロセス装置で、反応で生成した有害な物質を含む排ガスを、装置ごとに処理する装置はどれか。
  5. エッチングや装置のクリーニングに使われるPFC(パーフルオロカーボン)類の排出が環境上問題とされる主な理由はどれか。
  6. 排ガス中の酸性ガスなどを、水や薬液と接触させて吸収・除去する装置はどれか。
  7. 企業の温室効果ガス排出量の算定で、自社の工場での燃料の燃焼や、プロセスガスの排出などの直接排出が分類される区分はどれか。
