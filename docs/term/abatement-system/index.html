除害装置とは

じょがいそうち

製造装置から出る排ガスに含まれる有害な物質を、燃焼・吸着・水洗などで取り除く装置。

「除害装置」は、3分野の7問の練習問題に出てきます(プロセス材料(ガス・薬液), 環境安全, クリーンルーム・製造装置など)。

この用語の分野: 環境安全

除害装置の練習問題に挑戦

シリコン酸化膜(SiO2)のドライエッチングに主に使われるガスはどれか。

  1. A窒素ガスのみ
  2. Bヘリウムガスのみ
  3. CCF4やC4F8などのフルオロカーボン系ガス
答えと解説を見る

正解：C. CF4やC4F8などのフルオロカーボン系ガス

SiO2のドライエッチングでは、CF4やC4F8などのフルオロカーボンガスのプラズマを使います。フッ素がSiと結びついて揮発性のSiF4になり、炭素は膜中の酸素とCOやCO2になって排気されます。窒素やヘリウムだけでは化学反応が起こらず、膜を削れません。これらのガスは地球温暖化係数がCO2の数千倍以上と大きいため、使用後は除害装置で分解してから排出します。

n型不純物の導入に使われるホスフィン(PH3)やアルシン(AsH3)の特徴として正しいものはどれか。

  1. A無害で特別な管理は不要である
  2. B毒性が非常に強く、厳重な漏えい管理が必要である
  3. C不燃・無臭で、空気中に放出しても安全である
答えと解説を見る

正解：B. 毒性が非常に強く、厳重な漏えい管理が必要である

ホスフィンやアルシンは、許容濃度が0.05 ppm以下とされるほど毒性の強いガスです。シリンダーキャビネット、漏えい検知器、緊急遮断弁、除害装置を組み合わせて厳重に管理します。漏れても外に出にくいよう、多孔質の吸着材にガスを吸着させて大気圧より低い圧力で供給する容器も広く使われています。不燃・無害なガスではなく、ホスフィンには可燃性もあります。

    三フッ化窒素(NF3)の主な用途はどれか。

  • 除害装置は、装置のすぐ近くでこれらを燃焼、熱分解、プラズマ分解、吸着、水洗などで無害化してから、工場全体の排気系に送ります。

    エッチングや装置のクリーニングに使われるPFC(パーフルオロカーボン)類の排出が環境上問題とされる主な理由はどれか。

「除害装置」が出てくる問題(7問)

  1. シリコン酸化膜(SiO2)のドライエッチングに主に使われるガスはどれか。
  2. n型不純物の導入に使われるホスフィン(PH3)やアルシン(AsH3)の特徴として正しいものはどれか。
  3. 三フッ化窒素(NF3)の主な用途はどれか。
  4. 真空を使うプロセス装置で、反応で生成した有害な物質を含む排ガスを、装置ごとに処理する装置はどれか。
  5. エッチングや装置のクリーニングに使われるPFC(パーフルオロカーボン)類の排出が環境上問題とされる主な理由はどれか。
  6. 排ガス中の酸性ガスなどを、水や薬液と接触させて吸収・除去する装置はどれか。
  7. 企業の温室効果ガス排出量の算定で、自社の工場での燃料の燃焼や、プロセスガスの排出などの直接排出が分類される区分はどれか。
