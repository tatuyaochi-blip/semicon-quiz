CD-SEMとは

しーでぃーせむ

パターンの線幅(CD)を測定するための走査電子顕微鏡。リソグラフィやエッチング後の寸法管理に使われる。

この用語の分野: 計測・分析

解説の中の「CD-SEM」

  • 半導体工場では、パターンの線幅を測るCD-SEM(測長SEM)が工程管理に使われています。

    走査電子顕微鏡(SEM)の原理として正しいものはどれか。

「CD-SEM」が出てくる問題(3問)

  1. CD-SEMでArFレジストのパターンを測定するとき、電子線の照射によってパターンが縮んでしまう現象を何と呼ぶか。
  2. 複数の異なる計測手法(光学式・CD-SEM・AFMなど)のデータを組み合わせて、一つの手法だけより正確に寸法や形状を求める考え方を何と呼ぶか。
  3. 走査電子顕微鏡(SEM)の原理として正しいものはどれか。
