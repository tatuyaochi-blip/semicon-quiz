再配置とは

さいはいち

コードとデータの最終的な番地が決まった後、命令やデータの中の仮の番地を正しい値に書き換える処理。リンカが行い、動的リンクでは一部を実行時に動的リンカが行う。

この用語の分野: リンカ・ローダと実行形式

解説の中の「再配置」

  • コンパイラは各ファイルを番地0から始まるものとして作り、ほかのファイルの関数や自分の変数の番地を使う場所を再配置情報として記録します。

    リンカが行う再配置(リロケーション)の説明として正しいものはどれか。

  • オブジェクトファイルには、そのファイルの関数を翻訳した機械語、変数の初期値、定義や参照している名前の一覧(シンボルテーブル)、後から番地を埋める場所の一覧(再配置情報)が入っています。

    コンパイラが1つのソースファイルから出力するオブジェクトファイル(.o)について正しいものはどれか。

  • リンカは、各オブジェクトファイルで参照されている名前(シンボル)を、どこかで定義されている実体と対応づけ(シンボル解決)、各ファイルのコードとデータを並べて最終的な番地を決め、命令の中の仮の番地を正しい値に書き換え(再配置)ます。

    リンカの主な役割として正しいものはどれか。

「再配置」が出てくる問題(8問)

  1. リンカが行う再配置(リロケーション)の説明として正しいものはどれか。
  2. コンパイラが1つのソースファイルから出力するオブジェクトファイル(.o)について正しいものはどれか。
  3. リンカの主な役割として正しいものはどれか。
  4. C言語で「extern int count;」と書いたときの意味として正しいものはどれか。
  5. Linuxで動的リンクのプログラムを起動するときに働く動的リンカ(ld.soなど)の役割として正しいものはどれか。
  6. オブジェクトファイルを逆アセンブルすると、外部の関数printfを呼ぶ命令の飛び先が0のように仮の値になっていた。この値はいつ正しく埋められるか。
  7. ELFのファイルにおける「セクション」と「セグメント」の違いとして正しいものはどれか。
  8. 主なOSで使われる実行ファイルの形式の組み合わせとして正しいものはどれか。
