Compilateurs : points clés

Un compilateur traduit les programmes écrits par des humains en code machine exécutable par un CPU. Il passe par l'analyse lexicale, qui découpe le code source en tokens, l'analyse syntaxique, qui construit un arbre selon la grammaire, et l'analyse sémantique, qui vérifie types et noms, avant de convertir le programme en représentation intermédiaire (IR).

Sur l'IR, il applique des optimisations comme la propagation de constantes (constant folding), l'élimination des sous-expressions communes, l'inlining, le déroulage de boucles et la vectorisation, puis génère un code adapté au CPU par allocation de registres et ordonnancement des instructions. Comprendre ces optimisations aide à écrire du code rapide et à tirer le meilleur parti du matériel.
