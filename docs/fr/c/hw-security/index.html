Sécurité matérielle : points clés

Même lorsque le logiciel est exempt de bogues, des informations peuvent fuir par les propriétés du matériel. Les vulnérabilités connues sous les noms de Spectre et Meltdown exploitent le fait que l'exécution spéculative et les caches, conçus pour améliorer les performances, laissent des traces de données qui devraient rester invisibles. Les attaques par canal auxiliaire peuvent aussi déduire des clés cryptographiques à partir d'infimes différences de consommation ou de temps d'exécution.

Les technologies de défense comprennent le secure boot, qui ne démarre que des logiciels de confiance, les environnements d'exécution de confiance (TEE), isolés même de l'OS, les PUF, qui utilisent les variations de fabrication de chaque puce comme une empreinte, et les contre-mesures contre les circuits malveillants insérés lors de la conception ou de la fabrication (chevaux de Troie matériels). L'objectif est de comprendre les principes et les défenses, et non les procédures d'attaque.
