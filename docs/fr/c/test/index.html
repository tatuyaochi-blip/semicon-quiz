Test et inspection : points clés

Les produits semi-conducteurs passent par plusieurs étapes de test pendant et après la fabrication. Le test sur plaquette, avant la découpe, détecte les puces défectueuses, et le test final, après mise en boîtier, garantit les caractéristiques des produits livrés.

Le déverminage (burn-in), qui élimine les défaillances précoces, et la conception pour la testabilité (DFT), qui intègre des fonctions de test dans les circuits, maintiennent une qualité élevée tout en limitant les coûts de test.
