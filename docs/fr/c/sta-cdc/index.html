タイミング解析とCDC : points clés

同期回路が正しく動くには、フリップフロップ間のすべての経路で、データがセットアップ時間とホールド時間を満たして届く必要があります。静的タイミング解析(STA)は、SDCで与えたクロックや入出力遅延の制約をもとに各経路のスラックを計算し、スキューやジッタ、製造ばらつきも見込んで違反を見つけます。

一方、非同期のクロックどうしの間ではタイミングを保証できず、メタステーブルを避けられません。2段フリップフロップの同期化回路、ハンドシェイク、グレイコードのポインタを使う非同期FIFOなどで信号を安全に渡すクロックドメインクロッシング(CDC)の設計と検証も、論理設計の基本です。
