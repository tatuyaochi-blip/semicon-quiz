ISA et assembleur : points clés

Une architecture de jeu d'instructions (ISA) est le contrat entre le logiciel et le matériel. Elle définit les instructions existantes, leur codage en bits et la manière de désigner registres et mémoire. Tout CPU qui respecte la même ISA peut exécuter les mêmes programmes, aussi différente que soit son organisation interne.

Le langage assembleur écrit les instructions machine sous une forme lisible par l'humain. Connaître les instructions RISC-V de base, l'usage des registres, le passage des arguments et des valeurs de retour entre fonctions (convention d'appel) et la construction des cadres de pile montre ce que génèrent les compilateurs et comment les programmes s'exécutent réellement sur un CPU.
