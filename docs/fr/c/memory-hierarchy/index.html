Hiérarchie mémoire : points clés

Une opération du CPU prend moins d'une nanoseconde, alors que la lecture de données dans la mémoire principale DRAM prend de quelques dizaines à 100 nanosecondes. Pour combler cet écart, les ordinateurs empilent une hiérarchie allant de petits caches rapides jusqu'à une grande mémoire principale lente et au stockage, en conservant les données fréquemment utilisées dans les niveaux rapides.

Les caches fonctionnent parce que les programmes présentent une localité temporelle et spatiale. Comprendre les organisations à correspondance directe et associatives par ensembles, le découpage d'une adresse en tag, index et offset, les trois types de défauts de cache et le calcul du temps d'accès mémoire moyen explique pourquoi la disposition des données et l'ordre des boucles peuvent multiplier ou diviser les performances.
