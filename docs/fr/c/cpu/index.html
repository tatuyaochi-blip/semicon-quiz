CPU et architecture : points clés

Un CPU exécute un programme en répétant la recherche, le décodage et l'exécution des instructions. La plupart des ordinateurs utilisent l'architecture de von Neumann, dans laquelle programmes et données sont stockés dans la même mémoire principale.

Parmi les techniques d'amélioration des performances figurent le pipeline, qui chevauche les étapes de traitement des instructions, les caches, qui comblent l'écart de vitesse avec la mémoire principale, et le traitement parallèle sur plusieurs cœurs. La miniaturisation des semi-conducteurs a soutenu toutes ces avancées.
