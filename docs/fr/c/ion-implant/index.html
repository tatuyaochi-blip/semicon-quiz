Implantation ionique : points clés

L'implantation ionique ionise des impuretés, les accélère par un champ électrique et les projette dans la plaquette. Comme la dose et la profondeur peuvent être contrôlées avec précision, c'est aujourd'hui la principale méthode d'introduction des dopants.

Les ions implantés endommagent le cristal : après implantation, la plaquette subit donc un recuit qui restaure le cristal et active électriquement les dopants. Retenez aussi ce qui détermine la profondeur d'implantation et comment éviter la canalisation (channeling).
