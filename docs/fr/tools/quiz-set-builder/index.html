Créer une série de questions

Créez un quiz pour une classe, un groupe de TP ou la formation de nouveaux collaborateurs : choisissez les thèmes et le nombre de questions, puis partagez le lien. Toutes les personnes qui l’ouvrent reçoivent les mêmes questions, avec des explications complètes. Aucune inscription requise.

Ouvrir pour vérifier

Toute personne qui ouvre ce lien reçoit les mêmes questions (l’ordre des choix est mélangé à chaque fois). Les résultats restent dans le navigateur de chacun et ne sont jamais envoyés ni à vous ni à nous.

Comment ça marche

Cochez les thèmes, choisissez le nombre de questions et cliquez sur « Créer le lien ». Les questions sont réparties de façon équilibrée entre les thèmes sélectionnés. Si vous saisissez un nom de série, il s’affiche comme titre sur l’écran du quiz. Partagez le lien via votre plateforme d’apprentissage (ENT, LMS), par e-mail ou par messagerie ; le même lien donne toujours les mêmes questions.

Notes et confidentialité

Le site n’utilise ni comptes ni base de données. Les résultats sont enregistrés uniquement dans le navigateur de la personne qui répond au quiz. Si vous devez recueillir les scores, demandez aux élèves de remettre une capture d’écran de la page de résultats ou leur score, selon ce qui convient le mieux à votre cours.

Questions fréquentes

Le créateur de quiz est-il gratuit ?

Oui. Il est gratuit, ne nécessite aucune inscription, et les liens que vous créez n’expirent pas.

Tous les élèves reçoivent-ils les mêmes questions ?

Oui, toutes les personnes qui ouvrent le même lien reçoivent les mêmes questions. L’ordre des choix de réponse est mélangé à chaque fois, pour que les réponses ne puissent pas simplement circuler.
