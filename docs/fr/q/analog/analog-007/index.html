Circuits analogiques et électroniques

Que signifie un CMRR (taux de réjection du mode commun) élevé pour un amplificateur différentiel ?

  1. ALa consommation est élevée
  2. BLa capacité à rejeter le bruit appliqué de la même façon aux deux entrées (signal de mode commun) est élevée
  3. CLe gain est inférieur à 1
Afficher la réponse et l'explication

Réponse : B. La capacité à rejeter le bruit appliqué de la même façon aux deux entrées (signal de mode commun) est élevée

L'amplificateur différentiel amplifie idéalement la différence entre ses deux entrées sans amplifier la composante appliquée identiquement aux deux (signal de mode commun). Le CMRR est le rapport entre gain différentiel et gain de mode commun, de l'ordre de 80 à 120 dB pour un amplificateur opérationnel courant. Plus il est élevé, mieux le montage résiste au bruit de mode commun, comme le bruit induit sur de longs câbles ou les fluctuations d'alimentation. Le CMRR baisse toutefois avec la fréquence et se dégrade avec le désappariement des résistances externes ; on utilise donc un amplificateur d'instrumentation lorsque la précision est requise.
