Circuits analogiques et électroniques

Quelle combinaison de caractéristiques d'un amplificateur opérationnel idéal est correcte ?

  1. AImpédance d'entrée : infinie ; impédance de sortie : 0
  2. BImpédance d'entrée : 0 ; impédance de sortie : infinie
  3. CImpédance d'entrée : 0 ; impédance de sortie : 0
Afficher la réponse et l'explication

Réponse : A. Impédance d'entrée : infinie ; impédance de sortie : 0

L'amplificateur opérationnel idéal est modélisé avec une impédance d'entrée infinie (aucun courant n'entre dans les bornes d'entrée), une impédance de sortie nulle (la tension de sortie est fixée quelle que soit la charge) et un gain en boucle ouverte infini. Ces hypothèses établissent, dans un montage à contre-réaction, le « court-circuit virtuel » où les tensions des deux entrées sont égales, et le gain du montage ne dépend que du rapport des résistances. Le gain en boucle ouverte réel est de l'ordre de 10⁵ à 10⁶ et diminue avec la fréquence.
