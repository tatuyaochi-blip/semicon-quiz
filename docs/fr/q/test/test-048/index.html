Test et inspection

Lors du test d'un convertisseur AD, quel est l'objectif principal d'appliquer en entrée une sinusoïde lente ou un signal similaire et de compter le nombre d'occurrences de chaque code de sortie (histogramme) ?

  1. APeser la puce
  2. BDéterminer la linéarité, comme la DNL et l'INL
  3. CMesurer la consommation
Afficher la réponse et l'explication

Réponse : B. Déterminer la linéarité, comme la DNL et l'INL

Lorsqu'un signal de distribution connue est appliqué à un ADC idéal, le nombre d'occurrences de chaque code suit une distribution calculable. L'écart avec le nombre réel d'occurrences donne la largeur de chaque code, c'est-à-dire la DNL, dont le cumul donne l'INL. C'est la méthode de l'histogramme. Une sinusoïde se concentrant près de ses crêtes, une correction par la distribution théorique est appliquée, tandis qu'un signal triangulaire ou une rampe donne une distribution quasi uniforme. La consommation se déduit du courant d'alimentation.
