Test et inspection

Lors du test sur wafer, comment appelle-t-on le fait d'enfoncer légèrement la pointe après qu'elle a touché le plot d'électrode pour assurer un contact fiable ?

  1. AUnderfill
  2. BBande de garde
  3. COverdrive
Afficher la réponse et l'explication

Réponse : C. Overdrive

L'enfoncement supplémentaire de quelques dizaines de µm environ à partir de la position où la pointe touche le plot est appelé overdrive. L'extrémité de la pointe glisse légèrement sur le plot et perce l'oxyde superficiel de l'aluminium, ce qui assure un contact stable. Une trace de pointe trop grande peut provoquer des défauts de liaison lors du wire bonding ultérieur, et un enfoncement excessif endommage les structures situées sous le plot.
