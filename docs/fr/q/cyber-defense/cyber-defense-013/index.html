Cyberattaques et défense en pratique

Quelle description de la différence entre un IDS (système de détection d'intrusion) et un IPS (système de prévention d'intrusion) est correcte ?

  1. AUn IDS bloque automatiquement le trafic malveillant dès qu'il le détecte, alors qu'un IPS se contente d'enregistrer le trafic pour une analyse ultérieure sans le bloquer
  2. BUn IDS détecte les attaques présumées et prévient les administrateurs, alors qu'un IPS est placé sur le chemin du trafic et bloque le trafic qu'il juge malveillant
  3. CL'IDS comme l'IPS sont des mécanismes qui distribuent et appliquent automatiquement à chaque appareil interne les programmes corrigeant les vulnérabilités logicielles
Afficher la réponse et l'explication

Réponse : B. Un IDS détecte les attaques présumées et prévient les administrateurs, alors qu'un IPS est placé sur le chemin du trafic et bloque le trafic qu'il juge malveillant

Un IDS surveille le trafic réseau (ou l'activité sur les terminaux) et émet une alerte lorsqu'il trouve une attaque présumée. Il est souvent déployé pour recevoir et examiner une copie du trafic ; prendre à tort un trafic normal pour une attaque n'arrête donc pas l'activité, mais le blocage est laissé aux personnes ou à d'autres mécanismes. Un IPS est placé sur le chemin du trafic (en ligne) et peut bloquer sur-le-champ le trafic qu'il juge être une attaque. En contrepartie, les faux positifs arrêtent du trafic métier légitime, et les pannes ou les retards de traitement de l'équipement touchent tout le trafic ; les règles de blocage sont donc ajustées avec soin.
