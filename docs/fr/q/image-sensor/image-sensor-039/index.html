Capteurs d'images et composants optiques

Comment appelle-t-on le phénomène par lequel les charges débordent d'un pixel recevant une lumière très intense et s'étalent en blanc sur les pixels voisins ?

  1. ADiaphonie nulle
  2. BÉblouissement (blooming)
  3. CDéformation d'obturateur déroulant
Afficher la réponse et l'explication

Réponse : B. Éblouissement (blooming)

Lorsqu'une lumière intense dépassant la charge de saturation du pixel le frappe, les charges débordantes s'écoulent dans les pixels voisins et les zones claires s'étalent alentour. C'est le blooming ; dans les CCD, des traînées verticales (smear) peuvent aussi apparaître dans le sens du transfert. En CMOS, on le limite par un drain anti-débordement évacuant les charges vers l'alimentation ou par un chemin d'évacuation via le transistor de réinitialisation. À l'inverse, certains schémas HDR accumulent les charges débordantes dans une capacité séparée pour les exploiter.
