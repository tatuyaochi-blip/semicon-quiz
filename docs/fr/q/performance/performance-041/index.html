Analyse des performances

Quelle est la démarche la plus appropriée pour améliorer les performances d'un programme ?

  1. AMesurer d'abord pour trouver les parties consommatrices de temps, les améliorer, puis mesurer de nouveau pour vérifier l'effet
  2. BDeviner les parties qui semblent lentes et les réécrire sans mesurer
  3. COptimiser toutes les fonctions de manière égale
Afficher la réponse et l'explication

Réponse : A. Mesurer d'abord pour trouver les parties consommatrices de temps, les améliorer, puis mesurer de nouveau pour vérifier l'effet

Les suppositions sur les parties lentes sont souvent erronées, même chez les personnes expérimentées. On mesure d'abord avec un profileur ou des compteurs de performance pour identifier les parties consommatrices et leur cause (calcul, mémoire, branchements, entrées-sorties, etc.). Après amélioration, on mesure de nouveau dans les mêmes conditions pour vérifier que l'exécution est réellement plus rapide et qu'aucune autre partie n'a ralenti. Cette itération est le moyen sûr d'améliorer les performances.
