Bases des technologies web

On encode en Base64 une image de 3000 octets pour l'intégrer dans du HTML. Sans retours à la ligne, combien de caractères compte le résultat de l'encodage ?

  1. A2250 caractères
  2. B4000 caractères
  3. C6000 caractères
Afficher la réponse et l'explication

Réponse : B. 4000 caractères

Le Base64 découpe chaque groupe de 3 octets (24 bits) en quatre morceaux de 6 bits, et représente chacun par l'un de 64 caractères. La taille est donc multipliée par 4/3 : 3000 ÷ 3 × 4 = 4000 caractères. Lorsque le nombre d'octets d'origine n'est pas un multiple de 3, on complète à la fin par des « = » pour obtenir des groupes de 4 caractères. Intégrer des images dans le HTML ou le CSS réduit le nombre de requêtes, mais grossit les données d'environ 33 %, et le navigateur ne peut plus les conserver comme des fichiers séparés pour les réutiliser.
