Bases des technologies web

En HTTP, quelle association entre un code d'état et sa signification est correcte ?

  1. A301 : la ressource demandée se trouve temporairement à une autre URL
  2. B404 : la ressource demandée est introuvable sur le serveur
  3. C503 : la requête est mal formée et le serveur n'a pas pu la comprendre
Afficher la réponse et l'explication

Réponse : B. 404 : la ressource demandée est introuvable sur le serveur

Un code d'état est un nombre à trois chiffres dont le chiffre des centaines indique la classe. 2xx signifie un succès (200 OK, 201 Created, 204 No Content), 3xx une redirection (301 Moved Permanently, 302 Found, 304 Not Modified), 4xx une erreur du client (400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found) et 5xx une erreur du serveur (500 Internal Server Error, 503 Service Unavailable). 404 indique que la ressource désignée par l'URL est introuvable sur le serveur.
