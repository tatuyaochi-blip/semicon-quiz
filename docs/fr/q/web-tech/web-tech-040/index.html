Bases des technologies web

Parmi les méthodes de construction des pages d'un site web, laquelle génère à l'avance, lors de la compilation du site (build), les fichiers HTML de toutes les pages et renvoie ces fichiers tels quels aux requêtes ?

  1. ACSR (rendu côté client)
  2. BSSR (rendu côté serveur)
  3. CSSG (génération de site statique)
Afficher la réponse et l'explication

Réponse : C. SSG (génération de site statique)

Un site produit par SSG est un site statique : aucun programme ne s'exécute sur le serveur à chaque requête, si bien qu'il peut être distribué rapidement tel quel par un hébergement de fichiers statiques ou un CDN, et que sa surface d'attaque est réduite. C'est le cas, par exemple, d'un site qui génère au build ses pages de questions et de glossaire à partir des données de contenu et les distribue ; quand le contenu change, on régénère les pages. Le SSR est une méthode dynamique qui produit le HTML sur le serveur à chaque requête, et le CSR une méthode qui envoie un HTML minimal et du JavaScript et assemble la page dans le navigateur.
