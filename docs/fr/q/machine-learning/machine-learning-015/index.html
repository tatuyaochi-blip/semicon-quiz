Bases de l'apprentissage automatique

Sur des données qui ne comptent que 10 positifs sur 1000, quelle est l'exactitude d'un modèle qui prédit tout comme négatif ?

  1. A0 %
  2. B1 %
  3. C99 %
Afficher la réponse et l'explication

Réponse : C. 99 %

Si l'on prédit tout comme négatif, les 990 négatifs sont tous corrects et les 10 positifs tous faux : l'exactitude vaut 990 ÷ 1000 = 99 %. En revanche, aucun positif n'est trouvé et le rappel vaut 0 % ; si le but est de détecter les positifs, comme pour une maladie ou une fraude, le modèle est inutile. Pour des données où les proportions des classes sont très déséquilibrées (données déséquilibrées), on n'évalue donc pas avec la seule exactitude, mais aussi avec la précision, le rappel, le score F1, etc. Il existe aussi des parades comme la pondération, qui pénalise davantage les erreurs sur la classe minoritaire, ou l'échantillonnage, qui équilibre le nombre de données par classe.
