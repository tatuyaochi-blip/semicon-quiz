Bases de l'apprentissage automatique

Quelle affirmation est correcte lorsque l'on décompose l'erreur d'un modèle en biais et en variance (dispersion) ?

  1. AUn modèle à fort biais voit ses prédictions changer beaucoup selon les données d'apprentissage choisies, et il est sujet au surapprentissage
  2. BPlus le modèle est complexe, plus le biais et la variance diminuent tous les deux ; il vaut donc mieux utiliser le modèle le plus complexe possible
  3. CComplexifier le modèle tend à réduire le biais mais à augmenter la variance ; on choisit donc une complexité qui équilibre les deux
Afficher la réponse et l'explication

Réponse : C. Complexifier le modèle tend à réduire le biais mais à augmenter la variance ; on choisit donc une complexité qui équilibre les deux

Pour l'erreur quadratique, l'espérance de l'erreur sur de nouvelles données se décompose en la somme de trois termes : le carré du biais, la variance et le bruit propre aux données. Le biais est l'erreur due à un modèle trop simple pour capturer la vraie relation ; s'il est élevé, il y a sous-apprentissage. La variance est l'erreur due à la dispersion des prédictions selon les données d'apprentissage choisies ; si elle est élevée, il y a surapprentissage. En général, complexifier le modèle diminue le biais et augmente la variance ; on choisit donc, à l'aide des données de validation ou de la validation croisée, une complexité qui équilibre les deux.
