Compilateurs

Dans un langage à typage statique, quel est le principal avantage de la vérification des types par le compilateur ?

  1. ALes opérations et affectations de types incompatibles sont détectées avant l'exécution
  2. BLes déclarations de type disparaissent et le programme est toujours plus court
  3. CToutes les erreurs d'exécution sont éliminées dès la compilation
Afficher la réponse et l'explication

Réponse : A. Les opérations et affectations de types incompatibles sont détectées avant l'exécution

La vérification des types détecte avant l'exécution des erreurs comme l'addition d'un entier et d'une chaîne ou le passage d'un argument de mauvais type à une fonction. Outre la détection précoce, les informations de type aident le compilateur à choisir un code machine efficace. Elle n'élimine toutefois pas toutes les erreurs dépendant des valeurs, comme la division par 0 ou l'accès hors des bornes d'un tableau. Et comme il faut déclarer les types, le programme n'est pas forcément plus court.
