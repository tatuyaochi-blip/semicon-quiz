Interfaces d'E/S et bus

Quelle est la méthode la plus efficace pour accélérer un programme qui échange des milliers de fois de petites données une à une avec un périphérique ?

  1. ASe contenter de passer à une génération de liaison offrant deux fois plus de bande passante
  2. BRegrouper les données en blocs plus gros pour réduire le nombre d'échanges
  3. CDécouper encore davantage les données de chaque échange
Afficher la réponse et l'explication

Réponse : B. Regrouper les données en blocs plus gros pour réduire le nombre d'échanges

Pour de petits échanges, chaque échange subit la latence et le coût du traitement logiciel, et la bande passante est à peine utilisée. Transmettre les données regroupées en une fois réduit le nombre de latences subies et utilise efficacement la bande passante. Dans le stockage et les réseaux, des techniques fondées sur la même idée sont largement utilisées : accumuler plusieurs requêtes dans une file pour les transmettre d'un coup, regrouper les interruptions, etc.
