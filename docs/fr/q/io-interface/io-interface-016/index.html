Interfaces d'E/S et bus

Que fait la couche liaison de données de PCI Express face aux erreurs binaires survenant en transmission ?

  1. ARien ; les données erronées sont utilisées telles quelles jusqu'à ce que le logiciel s'en aperçoive
  2. BSi une erreur est détectée, elle met le périphérique hors tension
  3. CElle ajoute un CRC aux paquets pour détecter les erreurs et, en cas d'erreur, signale la non-réception afin de provoquer une retransmission
Afficher la réponse et l'explication

Réponse : C. Elle ajoute un CRC aux paquets pour détecter les erreurs et, en cas d'erreur, signale la non-réception afin de provoquer une retransmission

La couche liaison de données ajoute à chaque paquet un numéro de séquence et un code CRC (contrôle de redondance cyclique). Le récepteur vérifie le CRC et renvoie un ACK si le paquet est correct, un NAK s'il est erroné ; l'émetteur conserve le paquet jusqu'à confirmation et le retransmet en cas de NAK. Grâce à ce mécanisme, même si de rares erreurs binaires surviennent dans la couche physique, les couches supérieures et le logiciel reçoivent des données correctes.
