Systèmes embarqués et firmware

Dans un RTOS, quel est l'avantage d'utiliser une file (file de messages) pour transmettre des données de la tâche de lecture des capteurs à la tâche d'affichage ?

  1. ALes données traversant la file sont automatiquement chiffrées
  2. BLe récepteur peut dormir jusqu'à l'arrivée des données, et la file absorbe les différences de rythme entre émetteur et récepteur
  3. CAvec une file, les priorités des tâches deviennent inutiles
Afficher la réponse et l'explication

Réponse : B. Le récepteur peut dormir jusqu'à l'arrivée des données, et la file absorbe les différences de rythme entre émetteur et récepteur

Transmettre les données par une variable partagée et un drapeau exige des précautions contre les accès concurrents et oblige le récepteur à vérifier de façon répétée. Avec une file RTOS, l'émetteur se contente d'y déposer les données et le récepteur attend, en état d'attente, sans utiliser le processeur, jusqu'à leur arrivée. La file pouvant accumuler plusieurs données, aucune n'est perdue même si l'émetteur est temporairement plus rapide.
