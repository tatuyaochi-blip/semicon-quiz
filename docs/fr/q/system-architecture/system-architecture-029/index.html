Architecture des systèmes et fiabilité

Dans un service cloud IaaS, qu'est-ce que l'utilisateur gère généralement lui-même ?

  1. ALes bâtiments du centre de données et les installations électriques et de climatisation
  2. BLes équipements physiques, comme les serveurs et le stockage, et la plateforme de virtualisation
  3. CLe système d'exploitation, les intergiciels et les applications qui s'exécutent sur les machines virtuelles
Afficher la réponse et l'explication

Réponse : C. Le système d'exploitation, les intergiciels et les applications qui s'exécutent sur les machines virtuelles

Avec l'IaaS (Infrastructure as a Service), le fournisseur gère les bâtiments, les installations, les équipements physiques et la plateforme de virtualisation, et l'utilisateur gère lui-même tout ce qui se trouve au-dessus, à partir du système d'exploitation des machines virtuelles. Avec le PaaS, le fournisseur gère aussi le système d'exploitation et les intergiciels, et l'utilisateur gère les applications et les données ; avec le SaaS, le fournisseur gère tout jusqu'à l'application, et l'utilisateur gère les données et les paramètres d'utilisation. Le partage des responsabilités entre le fournisseur et l'utilisateur varie ainsi selon le modèle de service.
