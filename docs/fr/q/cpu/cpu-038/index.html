CPU et architecture

Quelle description d'un cache associatif par ensembles est correcte ?

  1. ALa donnée d'une adresse peut être placée dans l'un quelconque de plusieurs emplacements (voies) d'un ensemble déterminé
  2. BLa donnée d'une adresse ne peut être placée qu'en un seul emplacement du cache
  3. CLes données peuvent être placées n'importe où dans le cache
Afficher la réponse et l'explication

Réponse : A. La donnée d'une adresse peut être placée dans l'un quelconque de plusieurs emplacements (voies) d'un ensemble déterminé

Dans un cache associatif par ensembles, une partie de l'adresse détermine l'ensemble, et la donnée peut être placée dans l'une des voies de cet ensemble. Par exemple, avec 8 voies, il y a 8 emplacements candidats, ce qui réduit les conflits pour un même emplacement (défauts de conflit) par rapport au cache à correspondance directe. Augmenter le nombre de voies accroît les comparateurs et la consommation ; on utilise généralement environ 8 à 12 voies en L1 et autour de 16 en L3. Le placement n'importe où correspond au cache totalement associatif.
