CPU et architecture

Dans un pipeline, lorsqu'une instruction utilise immédiatement le résultat de la précédente (aléa de données), quelle technique transmet directement le résultat du calcul à l'instruction suivante sans attendre l'écriture dans le registre ?

  1. AForwarding (bypass)
  2. BMémoire virtuelle
  3. CPrédiction de branchement
Afficher la réponse et l'explication

Réponse : A. Forwarding (bypass)

Le forwarding (bypass) achemine directement la sortie de l'unité de calcul vers l'entrée de l'instruction suivante, sans attendre son écriture dans le registre. Par exemple, même si « r4 = r1 × 2 » suit immédiatement « r1 = r2 + r3 », l'exécution se fait sans arrêt (stall) de plusieurs cycles. En revanche, dans un pipeline classique à 5 étages, lorsque le résultat d'un chargement depuis la mémoire est utilisé immédiatement, la donnée n'étant pas encore arrivée, un arrêt d'un cycle subsiste (aléa load-use) ; dans les pipelines plus profonds, cet arrêt est plus long.
