CPU et architecture

Que désignent principalement les noms ARM, x86 et RISC-V ?

  2. BDes architectures de jeu d'instructions (ISA)
  3. CDes types de boîtiers

Réponse : B. Des architectures de jeu d'instructions (ISA)

ARM, x86 et RISC-V sont des noms d'architectures de jeu d'instructions (ISA), qui définissent le contrat entre logiciel et matériel : types d'instructions compris par le processeur, registres, gestion de la mémoire, etc. Pour une même ISA, un même programme s'exécute quelle que soit l'entreprise qui a conçu le processeur. x86 est utilisé par Intel et AMD dans les PC et serveurs, ARM dans les smartphones et les Mac d'Apple, et RISC-V se répand principalement dans l'embarqué.
