Bases de la théorie de l'information et du codage

Cinq mots de code du code de Hamming (7, 4) sont alignés et envoyés dans l'ordre suivant : le bit 1 de chacun des cinq mots de code, puis le bit 2 de chacun, et ainsi de suite (entrelacement de profondeur 5). Le récepteur rétablit l'ordre d'origine puis corrige une erreur sur 1 bit dans chaque mot de code. Quelle est la longueur maximale d'une erreur en rafale, concentrée sur des bits consécutifs, qui peut toujours être corrigée ?

  1. A5 bits
  2. B7 bits
  3. C35 bits
Afficher la réponse et l'explication

Réponse : A. 5 bits

Dans la suite de bits transmise, les bits d'un même mot de code apparaissent tous les 5 bits. Une erreur en rafale de 5 bits consécutifs ou moins se répartit donc, après rétablissement de l'ordre, à raison d'au plus un bit dans chacun des cinq mots de code, et chacun d'eux peut être corrigé par le code de Hamming. Avec 6 bits, l'un des mots de code reçoit une erreur sur 2 bits et ne peut plus être corrigé. Sans entrelacement, même une erreur en rafale de 2 bits tomberait dans un seul mot de code.
