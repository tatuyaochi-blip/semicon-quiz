Bases de la théorie de l'information et du codage

Quelle association entre l'entropie maximale d'une source qui émet 8 sortes de symboles et la condition dans laquelle ce maximum est atteint est correcte ?

  1. A3 bits ; lorsque l'un des symboles a la probabilité 1
  2. B3 bits ; lorsque les 8 symboles ont tous la probabilité 1/8
  3. C8 bits ; lorsque les 8 symboles ont tous la probabilité 1/8
Afficher la réponse et l'explication

Réponse : B. 3 bits ; lorsque les 8 symboles ont tous la probabilité 1/8

L'entropie d'une source qui émet n sortes de symboles est maximale lorsque tous les symboles apparaissent avec la même probabilité 1/n, et elle vaut alors log₂ n. Pour n = 8, cela donne log₂ 8 = 3 bits. La quantité d'information moyenne par symbole est maximale lorsque le symbole suivant est le plus difficile à prévoir. À l'inverse, lorsqu'un symbole apparaît avec la probabilité 1, on sait ce qui va venir, et l'entropie vaut 0.
