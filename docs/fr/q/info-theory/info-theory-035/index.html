Bases de la théorie de l'information et du codage

On ajoute à 32 bits de données un code SECDED, qui corrige les erreurs sur 1 bit et détecte les erreurs sur 2 bits. Le nombre r de bits de contrôle d'un code de Hamming est la plus petite valeur qui satisfait 2^r ≥ nombre de bits de données + r + 1, et le SECDED y ajoute 1 bit de parité globale. Combien de bits de contrôle faut-il ?

  1. A6 bits
  2. B7 bits
  3. C8 bits
Afficher la réponse et l'explication

Réponse : B. 7 bits

Avec r = 5, 2⁵ = 32 < 32 + 5 + 1 = 38, ce qui ne suffit pas, et avec r = 6, 2⁶ = 64 ≥ 32 + 6 + 1 = 39 : le code de Hamming demande donc 6 bits de contrôle. Le SECDED ajoute 1 bit de parité globale pour distinguer les erreurs sur 1 bit des erreurs sur 2 bits, ce qui donne 7 bits et un mot de code de 39 bits. Pour 64 bits de données, le même calcul donne 8 bits, d'où la largeur de 72 bits utilisée pour l'ECC des mémoires de serveurs.
