Hiérarchie mémoire

Quel est l’effet principal d’un cache de victimes, petit tampon totalement associatif qui conserve temporairement les lignes évincées du cache L1 ?

  1. AIl permet de récupérer rapidement une ligne réutilisée juste après son éviction et réduit la pénalité des défauts de conflit
  2. BIl réduit les défauts de capacité autant qu’une augmentation de la capacité du L1
  3. CIl élimine les défauts obligatoires et rend le préchargement inutile
Afficher la réponse et l'explication

Réponse : A. Il permet de récupérer rapidement une ligne réutilisée juste après son éviction et réduit la pénalité des défauts de conflit

Dans un cache à correspondance directe notamment, des données qui se disputent le même ensemble s’évincent mutuellement, et une ligne tout juste évincée est souvent réutilisée aussitôt. Le cache de victimes conserve de quelques-unes à une quinzaine de lignes évincées ; en cas de défaut L1, une ligne qui s’y trouve est récupérée plus vite qu’au niveau inférieur. Sa petite taille ne lui permet pas de réduire sensiblement les défauts de capacité, et il est sans effet sur les défauts obligatoires de données jamais chargées.
