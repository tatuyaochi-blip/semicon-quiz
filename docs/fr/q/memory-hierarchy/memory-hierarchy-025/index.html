Hiérarchie mémoire

Quel est le principal avantage d’un cache non bloquant (cache qui accepte d’autres accès pendant le traitement d’un défaut) ?

  1. AIl réduit le nombre de défauts de cache lui-même par rapport à un cache bloquant
  2. BIl permet de lire plus rapidement depuis la mémoire principale les données en défaut
  3. CIl recouvre les temps d’attente de plusieurs défauts et traite les succès pendant ce temps
Afficher la réponse et l'explication

Réponse : C. Il recouvre les temps d’attente de plusieurs défauts et traite les succès pendant ce temps

Dans un cache bloquant, tous les accès suivants attendent la fin du traitement d’un défaut. Un cache non bloquant dispose de registres dédiés (MSHR) qui enregistrent les défauts en cours ; il peut ainsi servir les accès en succès et envoyer simultanément d’autres défauts vers la mémoire principale. Les temps d’attente se recouvrent et sont masqués, mais le nombre de défauts ne diminue pas et le temps de lecture en mémoire principale par défaut reste inchangé. Le gain se manifeste en combinaison avec l’exécution dans le désordre.
