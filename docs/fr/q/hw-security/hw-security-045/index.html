Sécurité matérielle

Quel est le principe du partitionnement du cache partagé, utilisé comme contre-mesure aux canaux auxiliaires de cache ?

  1. ACouper physiquement le cache en deux et jeter une moitié
  2. BDoubler la capacité du cache
  3. CSéparer les plages de cache utilisables par processus ou par machine virtuelle, de sorte qu'ils ne puissent pas évincer mutuellement leurs données, rendant les traces inobservables
Afficher la réponse et l'explication

Réponse : C. Séparer les plages de cache utilisables par processus ou par machine virtuelle, de sorte qu'ils ne puissent pas évincer mutuellement leurs données, rendant les traces inobservables

Les canaux auxiliaires de cache reposent sur la concurrence entre attaquant et victime pour les mêmes emplacements de cache. En attribuant certaines voies ou certains ensembles du cache à chaque processus ou machine virtuelle, l'éviction mutuelle des données devient impossible et les traces d'accès de l'autre partie ne peuvent plus être observées. Certains CPU disposent de fonctions de contrôle de l'allocation du cache. La capacité disponible pour chacun diminuant, il faut toutefois arbitrer avec les performances.
