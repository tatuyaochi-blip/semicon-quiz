Sécurité matérielle

Parmi les analyses de consommation exploitant les courbes de consommation d'une puce effectuant des traitements cryptographiques, quelle est la caractéristique de l'analyse différentielle de consommation (DPA) ?

  1. AElle recueille les courbes de consommation de nombreux traitements et les traite statistiquement pour extraire les petites différences liées à la clé, invisibles sur une seule courbe
  2. BLa seule observation visuelle d'une courbe de consommation révèle toute la clé
  3. CElle extrait la clé en coupant l'alimentation de la puce
Afficher la réponse et l'explication

Réponse : A. Elle recueille les courbes de consommation de nombreux traitements et les traite statistiquement pour extraire les petites différences liées à la clé, invisibles sur une seule courbe

Les circuits CMOS consommant de l'énergie lors des commutations de signaux, la consommation varie légèrement selon les données manipulées. L'analyse simple de consommation lit le déroulement du traitement d'après la forme d'une seule courbe, tandis que l'analyse différentielle recueille les courbes de milliers de traitements cryptographiques et calcule, pour chaque clé candidate, la corrélation entre une valeur intermédiaire prédite et les courbes, afin de trouver la bonne clé. Sa caractéristique est d'extraire statistiquement des différences infimes noyées dans le bruit.
