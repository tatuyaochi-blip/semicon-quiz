Bases des bases de données

Une table Produit contient 5 lignes (Nom, Prix) : (Stylo, 120), (Cahier, 250), (Gomme, 80), (Classeur, 300), (Règle, 150). Quelle proposition donne, dans l'ordre, les lignes renvoyées par SELECT Nom FROM Produit WHERE Prix >= 150 ORDER BY Prix DESC ?

  1. ARègle, Cahier, Classeur
  2. BClasseur, Cahier
  3. CClasseur, Cahier, Règle
Afficher la réponse et l'explication

Réponse : C. Classeur, Cahier, Règle

WHERE Prix >= 150 ne sélectionne que les lignes dont le prix est supérieur ou égal à 150. La règle, à exactement 150, est incluse ; 3 lignes sont donc sélectionnées : Cahier (250), Classeur (300) et Règle (150). ORDER BY Prix DESC les trie ensuite du prix le plus élevé au plus bas (ordre décroissant), ce qui donne Classeur (300), Cahier (250), Règle (150). Spécifier ASC, ou rien, avec ORDER BY trie du plus bas au plus élevé (ordre croissant). Sans ORDER BY, l'ordre des lignes du résultat n'est pas garanti. Après SELECT, on écrit les colonnes à extraire (ici Nom), après FROM la table, et après WHERE la condition qui sélectionne les lignes.
