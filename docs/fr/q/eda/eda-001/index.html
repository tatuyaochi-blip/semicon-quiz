Flot de conception de circuits intégrés et EDA

Quel est l'ordre correct du flot de conception d'un LSI numérique courant ?

  1. ASpécification → conception RTL → synthèse logique → placement-routage
  2. BSynthèse logique → spécification → placement-routage → conception RTL
  3. CPlacement-routage → conception RTL → synthèse logique → spécification
Afficher la réponse et l'explication

Réponse : A. Spécification → conception RTL → synthèse logique → placement-routage

La spécification fixe d'abord les fonctions et les performances, puis la conception RTL est réalisée dans un langage de description matérielle comme Verilog ou VHDL. La synthèse logique convertit ensuite le RTL en netlist au niveau portes, et le placement-routage produit le dessin des masques sur la puce. Une vérification a lieu à chaque étape, et les données de masque sont finalement produites. Le flot descend d'une description abstraite vers une forme concrète ; aucun autre ordre n'est possible. Pour les produits avancés, il peut s'écouler 1 à 2 ans entre la spécification et le tape-out.
