Circuits logiques

Pour une bascule JK avec J = 1 et K = 1, quel est le comportement lors d'un front d'horloge ?

  1. ALa sortie s'inverse (toggle)
  2. BLa sortie est remise à 0
  3. CLa sortie est maintenue
Afficher la réponse et l'explication

Réponse : A. La sortie s'inverse (toggle)

La bascule JK effectue une mise à 1 pour J = 1, K = 0, une remise à 0 pour J = 0, K = 1, un maintien pour J = K = 0, et une inversion (toggle) pour J = K = 1. Elle donne le sens « inverser » à la combinaison S = R = 1 interdite dans la bascule SR ; l'état suivant s'écrit Q⁺ = J·¬Q + ¬K·Q. Avec J et K à 1, elle devient une bascule T, utilisée dans les compteurs. Dans les conceptions actuelles, la bascule D domine.
