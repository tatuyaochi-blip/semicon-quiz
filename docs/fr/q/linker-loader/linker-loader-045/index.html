Éditeurs de liens, chargeurs et exécutables

Quelle combinaison des formats d'exécutables utilisés par les principaux OS est correcte ?

  1. ALinux : PE, Windows : Mach-O, macOS : ELF
  2. BLinux : ELF, Windows : PE, macOS : Mach-O
  3. CTous les OS utilisent ELF
Afficher la réponse et l'explication

Réponse : B. Linux : ELF, Windows : PE, macOS : Mach-O

Le format d'exécutable est propre à chaque OS. Linux, BSD et de nombreux systèmes embarqués utilisent ELF, Windows le format PE (Portable Executable) des .exe et .dll, et macOS et iOS Mach-O. Les principes du contenu (zones de code et de données, symboles, relocalisation, informations d'édition de liens dynamique) sont similaires, mais les formats différant, un exécutable ne fonctionne pas tel quel sur un autre OS, même pour le même CPU.
