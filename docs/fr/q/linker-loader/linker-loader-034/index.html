Éditeurs de liens, chargeurs et exécutables

Quel est le traitement correct d'un symbole faible (weak symbol) par l'éditeur de liens ?

  1. AUn symbole faible est toujours prioritaire sur les autres définitions
  2. BS'il existe une définition ordinaire (forte) de même nom, elle est utilisée ; sinon, la définition faible est utilisée
  3. CUn fichier contenant un symbole faible ne peut pas être lié
Afficher la réponse et l'explication

Réponse : B. S'il existe une définition ordinaire (forte) de même nom, elle est utilisée ; sinon, la définition faible est utilisée

Un symbole faible est une définition de secours : « à utiliser s'il n'y a pas d'autre définition ». Dans le logiciel embarqué, il est courant de fournir le traitement par défaut des gestionnaires d'interruption sous forme de symboles faibles, que l'utilisateur remplace en écrivant une fonction de même nom. Le chevauchement de deux définitions fortes provoque une erreur de définition multiple, mais pas le chevauchement avec une définition faible.
