Bases des réseaux informatiques

Un résolveur récursif (serveur DNS cache) dont le cache est vide recherche l'adresse IP de www.example.com. Dans quel ordre interroge-t-il les serveurs ?

  1. AServeur racine → serveur DNS de .com → serveur DNS faisant autorité pour example.com
  2. BServeur DNS faisant autorité pour example.com → serveur DNS de .com → serveur racine
  3. CServeur DNS de .com → serveur racine → serveur web de www.example.com
Afficher la réponse et l'explication

Réponse : A. Serveur racine → serveur DNS de .com → serveur DNS faisant autorité pour example.com

Le terminal interroge un résolveur géré par son fournisseur d'accès ou son organisation, et ce résolveur parcourt la hiérarchie des noms de domaine depuis le sommet pour le compte du terminal. Il interroge d'abord un serveur racine, qui l'oriente vers le serveur qui gère .com (serveur de TLD) ; celui-ci l'oriente vers le serveur DNS faisant autorité pour example.com, qui renvoie enfin l'adresse de www.example.com. La réponse est mise en cache pendant la durée de validité attachée à l'enregistrement (son TTL, distinct du TTL de l'en-tête IP), si bien que les requêtes suivantes obtiennent une réponse immédiate. C'est pourquoi, après la modification d'un paramètre DNS, l'ancienne adresse peut encore être utilisée jusqu'à l'expiration des réponses en cache.
