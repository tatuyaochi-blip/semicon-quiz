Bases des réseaux informatiques

Quel est le rôle principal de DNS ?

  1. ATrouver, à partir de son adresse IP, l'adresse MAC d'un équipement situé sur le même réseau
  2. BTraduire des noms de domaine comme www.example.com en adresses IP utilisées pour la communication (résolution de noms)
  3. CChiffrer la communication et vérifier que le site web auquel on se connecte est authentique
Afficher la réponse et l'explication

Réponse : B. Traduire des noms de domaine comme www.example.com en adresses IP utilisées pour la communication (résolution de noms)

DNS (Domain Name System) est le système qui associe des noms de domaine faciles à retenir pour les humains aux adresses IP utilisées pour la communication. Lorsqu'on ouvre une URL dans un navigateur, le terminal interroge d'abord DNS pour obtenir l'adresse IP du serveur, puis se connecte à cette adresse. Les données DNS ne sont pas regroupées sur un seul serveur : elles sont réparties selon les niveaux de la hiérarchie des noms de domaine et gérées de façon distribuée par des serveurs du monde entier. Les requêtes utilisent principalement le port 53 d'UDP, et TCP sert aussi, par exemple lorsque les réponses sont volumineuses.
