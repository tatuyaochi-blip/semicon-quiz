Physique des semi-conducteurs

Quelle relation d'Einstein lie le coefficient de diffusion D et la mobilité μ des porteurs dans un semi-conducteur ? (k : constante de Boltzmann, T : température absolue, q : charge élémentaire)

  1. AD = qμ
  2. BD = μ / (kT)
  3. CD = μkT / q
Afficher la réponse et l'explication

Réponse : C. D = μkT / q

La relation d'Einstein s'écrit D = μkT/q. Diffusion et dérive dépendant toutes deux de la capacité des porteurs à se déplacer sans être diffusés, elles sont proportionnelles. À température ambiante, kT/q ≈ 26 mV : pour les électrons (μ ≈ 1400 cm²/V·s), D ≈ 36 cm²/s ; pour les trous (environ 450), environ 12 cm²/s. Une table de mobilités donne donc immédiatement le coefficient de diffusion, utilisé pour la longueur de diffusion et les calculs de composants.
