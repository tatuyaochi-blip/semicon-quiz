Physique des semi-conducteurs

Quelle description est correcte lorsqu'on ajoute du phosphore (P) comme impureté dans le silicium ?

  1. AIl devient un semi-conducteur de type p dont les porteurs majoritaires sont les trous
  2. BIl devient un semi-conducteur de type n dont les porteurs majoritaires sont les électrons
  3. CLes porteurs n'augmentent pas et il reste un semi-conducteur intrinsèque
Afficher la réponse et l'explication

Réponse : B. Il devient un semi-conducteur de type n dont les porteurs majoritaires sont les électrons

Le phosphore, élément du groupe V, possède 5 électrons de valence : un électron reste inutilisé dans les liaisons covalentes du silicium (groupe IV). Cet électron n'est que faiblement lié à un niveau peu profond d'environ 0,045 eV, si bien qu'à température ambiante presque tous passent dans la bande de conduction et deviennent électrons de conduction. Une telle impureté est appelée donneur et produit un semi-conducteur de type n. L'arsenic (As) et l'antimoine (Sb) sont aussi des donneurs. Pour obtenir un type p, on ajoute un élément du groupe III (accepteur) tel que le bore (B).
