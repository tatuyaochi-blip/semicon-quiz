ISA et assembleur

Quel est l'avantage le plus pertinent d'une longueur d'instruction fixe ?

  1. ALes limites des instructions sont immédiatement connues, ce qui facilite le décodage simultané de plusieurs instructions
  2. BToutes les instructions étant plus courtes qu'en longueur variable, le programme est toujours plus petit
  3. CLe nombre de types d'instructions peut être augmenté sans limite
Afficher la réponse et l'explication

Réponse : A. Les limites des instructions sont immédiatement connues, ce qui facilite le décodage simultané de plusieurs instructions

En longueur fixe, la n-ième instruction commence nécessairement à l'octet 4n ; on peut donc extraire plusieurs instructions à la fois et les décoder en parallèle. C'est particulièrement avantageux pour les CPU superscalaires qui émettent plusieurs instructions par cycle. En revanche, les instructions fréquentes ne pouvant être représentées de façon courte, la taille du code tend à dépasser celle d'un jeu à longueur variable. L'extension C de RISC-V compense cette faiblesse en ajoutant des instructions de 16 bits.
