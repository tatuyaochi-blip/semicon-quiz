Bases de la programmation (trace de pseudo-code)

Les deux affectations du programme suivant devaient échanger les valeurs de x et y. Quelles sont les valeurs de x et y après son exécution ?

integer: x ← 3, y ← 7
x ← y
y ← x
  1. Ax = 3, y = 3
  2. Bx = 7, y = 3
  3. Cx = 7, y = 7
Afficher la réponse et l'explication

Réponse : C. x = 7, y = 7

En pseudo-code, les affectations s'exécutent une par une, de haut en bas. x ← y donne 7 à x, et la valeur d'origine 3 est perdue à ce moment-là. L'affectation suivante y ← x copie alors dans y la nouvelle valeur de x, 7 : on obtient x = 7 et y = 7. Pour échanger deux valeurs, on sauvegarde d'abord la valeur d'origine dans une variable temporaire, par exemple t ← x, x ← y, y ← t.
