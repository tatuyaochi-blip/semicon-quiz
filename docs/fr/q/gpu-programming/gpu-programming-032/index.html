Programmation GPU

Envoyer des données au GPU pour un traitement léger, comme une seule addition par élément d'un tableau, peut être plus lent qu'un calcul sur CPU. Quelle en est la raison principale ?

  1. AParce que le GPU ne sait pas additionner
  2. BParce que le temps de copie des données par PCI Express dépasse le temps de calcul gagné sur le GPU
  3. CParce que l'envoi au GPU modifie les valeurs des données
Afficher la réponse et l'explication

Réponse : B. Parce que le temps de copie des données par PCI Express dépasse le temps de calcul gagné sur le GPU

La bande passante PCI Express est inférieure d'au moins un ordre de grandeur à celle de la mémoire GPU, si bien que le seul envoi des données prend du temps. Avec une seule addition par élément, le temps de calcul est négligeable devant le temps d'envoi et la vitesse du GPU n'est pas exploitée. Le GPU est avantageux lorsque de nombreux calculs portent sur les données envoyées, ou lorsque les données restent en mémoire GPU pour des traitements répétés.
