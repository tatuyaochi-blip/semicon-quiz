Programmation GPU

Quelle est la caractéristique la plus adaptée d'une tâche que le GPU traite rapidement ?

  1. AUn calcul séquentiel en chaîne, où chaque étape utilise le résultat précédent
  2. BUn même calcul, indépendant pour chaque élément, appliqué à de grandes quantités de données
  3. CUn calcul sur peu de données comportant de très nombreux branchements conditionnels
Afficher la réponse et l'explication

Réponse : B. Un même calcul, indépendant pour chaque élément, appliqué à de grandes quantités de données

Le GPU répartit un même traitement sur des milliers de threads exécutés en parallèle ; il excelle donc dans les tâches où de nombreux éléments peuvent être calculés indépendamment (parallélisme de données), comme le traitement de chaque pixel d'une image, la multiplication de matrices ou les opérations vectorielles. Les calculs séquentiels dépendant du résultat précédent, ou les calculs sur peu de données avec beaucoup de branchements, offrent peu de parallélisme, et le CPU y est souvent plus rapide.
