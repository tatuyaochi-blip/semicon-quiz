Programmation GPU

Quelle est la définition de la mémoire unifiée (unified memory) de CUDA ?

  1. AUne mémoire utilisable depuis le CPU et le GPU avec le même pointeur, les données se déplaçant automatiquement selon les besoins
  2. BLa réunion physique des puces CPU et GPU en une seule
  3. CLe passage de toute la mémoire GPU en lecture seule
Afficher la réponse et l'explication

Réponse : A. Une mémoire utilisable depuis le CPU et le GPU avec le même pointeur, les données se déplaçant automatiquement selon les besoins

Avec la mémoire unifiée, la zone allouée est accessible depuis le CPU comme depuis le GPU avec le même pointeur, et les données migrent par pages vers le côté qui y accède. Le programme est simplifié et des données plus grandes que la mémoire GPU sont plus faciles à manipuler. Chaque migration provoquant toutefois un défaut de page et un transfert, on recourt, lorsque les performances comptent, à des directives de migration anticipée.
