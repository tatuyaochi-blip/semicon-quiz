Semi-conducteurs automobiles et sécurité fonctionnelle

La mémoire d'un microcontrôleur automobile utilise un ECC (SEC-DED) capable de corriger les erreurs sur 1 bit et de détecter les erreurs sur 2 bits. Que se passe-t-il généralement si une erreur sur 2 bits est présente dans les données lues ?

  1. ALes erreurs jusqu'à 2 bits sont corrigées automatiquement à l'aide des bits de contrôle ; aucune erreur n'est donc signalée et le traitement se poursuit tel quel
  2. BL'erreur ne pouvant être ni détectée ni corrigée, les données erronées sont utilisées telles quelles et le traitement se poursuit
  3. CL'erreur ne peut pas être corrigée mais elle peut être détectée ; elle est donc signalée comme une erreur et l'on prend des mesures, comme le passage du système dans un état sûr
Afficher la réponse et l'explication

Réponse : C. L'erreur ne peut pas être corrigée mais elle peut être détectée ; elle est donc signalée comme une erreur et l'on prend des mesures, comme le passage du système dans un état sûr

Le SEC-DED (Single Error Correction, Double Error Detection) ajoute par exemple 8 bits de contrôle à 64 bits de données ; il corrige les erreurs sur 1 bit et, sans pouvoir corriger les erreurs sur 2 bits, les détecte de façon certaine. Lorsqu'une erreur sur 2 bits est détectée, le microcontrôleur la signale, et le logiciel n'utilise pas les données et procède à une réinitialisation ou au passage dans un état sûr. Si l'on enregistre aussi les erreurs sur 1 bit après les avoir corrigées, on peut repérer des signes d'anomalie avant que les erreurs ne s'accumulent.
