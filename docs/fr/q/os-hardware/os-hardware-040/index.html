Système d'exploitation et matériel

Beaucoup d’OS placent la zone du noyau dans une partie de l’espace d’adressage de chaque processus (par exemple la plage haute) et en interdisent l’accès depuis le mode utilisateur par les bits de protection de la table des pages. Quel est l’avantage principal de cette disposition ?

  1. AIl n’est pas nécessaire de changer d’espace d’adressage lors de l’entrée dans le noyau
  2. BLes applications peuvent appeler directement les fonctions du noyau sans appel système
  3. CChaque processus peut modifier librement et partager la mémoire du noyau
Afficher la réponse et l'explication

Réponse : A. Il n’est pas nécessaire de changer d’espace d’adressage lors de l’entrée dans le noyau

En plaçant le noyau de la même façon dans l’espace d’adressage de chaque processus, l’entrée dans le noyau par appel système ou interruption permet d’accéder directement au code et aux données du noyau sans changer de table des pages ni vider le TLB. L’accès depuis le mode utilisateur étant interdit par les bits de protection de la table des pages, les applications ne peuvent ni appeler directement les fonctions du noyau ni modifier sa mémoire. Le contournement de cette protection constituerait une vulnérabilité grave.
