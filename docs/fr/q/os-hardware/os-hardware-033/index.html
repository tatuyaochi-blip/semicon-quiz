Système d'exploitation et matériel

Comment s’appelle le logiciel qui permet d’exécuter simultanément sur un même ordinateur plusieurs OS, chacun dans une machine virtuelle indépendante ?

  1. ACompilateur
  2. BPilote de périphérique
  3. CHyperviseur
Afficher la réponse et l'explication

Réponse : C. Hyperviseur

L’hyperviseur (moniteur de machines virtuelles) répartit CPU, mémoire et périphériques entre plusieurs machines virtuelles et donne à chaque OS l’impression de disposer de son propre ordinateur. Les machines virtuelles étant isolées, la défaillance de l’une affecte peu les autres ; cette technologie est très utilisée dans les serveurs cloud. Les fonctions d’assistance à la virtualisation du CPU et la pagination imbriquée en soutiennent les performances. Le compilateur traduit les programmes, le pilote de périphérique gère les périphériques.
