Multicœur et synchronisation

Quelle est la différence entre cohérence de cache et modèle de cohérence mémoire ?

  1. ALes deux ont le même sens sous des noms différents
  2. BLa cohérence de cache est le contrat qui supprime les divergences de valeur d’une même adresse, et le modèle de cohérence mémoire le contrat sur l’ordre dans lequel les opérations sur des adresses différentes sont vues
  3. CLa cohérence de cache est réalisée uniquement par logiciel, le modèle de cohérence mémoire uniquement par matériel
Afficher la réponse et l'explication

Réponse : B. La cohérence de cache est le contrat qui supprime les divergences de valeur d’une même adresse, et le modèle de cohérence mémoire le contrat sur l’ordre dans lequel les opérations sur des adresses différentes sont vues

La cohérence de cache garantit, pour une adresse donnée, que tous les cœurs voient les écritures dans le même ordre et finissent par lire la valeur la plus récente. Le modèle de cohérence mémoire définit, lorsque le cœur 0 écrit x puis y, dans quel ordre les écritures de x et y peuvent être vues des autres cœurs. Même avec la cohérence de cache, l’ordre entre adresses différentes peut paraître inversé, d’où la nécessité de barrières.
