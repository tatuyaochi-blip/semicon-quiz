Qu'est-ce que Temps d'accès mémoire moyen (AMAT) ?

Durée moyenne d'un accès mémoire, calculée par temps de succès + taux de défauts × pénalité de défaut. Indicateur de base pour comparer les performances des caches.

Nom japonais: 平均メモリアクセス時間(AMAT)

Domaine: Hiérarchie mémoire

Termes associés

Allocation en écriture (write allocate) Blocage de boucle (loop blocking) Cache associatif par ensembles Cache entièrement associatif Cache non bloquant Correspondance directe (direct-mapped) Défaut de capacité (capacity miss) Défaut de conflit Défaut obligatoire (compulsory miss) Écriture immédiate (write-through)
