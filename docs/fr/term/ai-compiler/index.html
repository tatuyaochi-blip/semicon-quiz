Qu'est-ce que Compilateur d'IA ?

Logiciel qui analyse le graphe de calcul d'un modèle, optimise la fusion d'opérations, la disposition des données, le tuilage, etc., et génère du code pour le matériel cible. Exemples : XLA, TVM.

Nom japonais: AIコンパイラ

S'entraîner : questions sur Compilateur d'IA

Quel est le principal traitement effectué par les compilateurs d'IA comme XLA, TVM ou la fonction de compilation de PyTorch ?

  1. ATraduire les réponses d'un modèle d'IA en langage humain
  2. BCollecter automatiquement les données d'entraînement
  3. CAnalyser le graphe de calcul du modèle, optimiser la fusion d'opérations, l'agencement des données, le tuilage, etc., et générer du code pour le matériel cible
Afficher la réponse et l'explication

Réponse : C. Analyser le graphe de calcul du modèle, optimiser la fusion d'opérations, l'agencement des données, le tuilage, etc., et générer du code pour le matériel cible

Le compilateur d'IA reçoit le modèle sous forme de graphe de calcul (opérations et flux de données), fusionne les opérations regroupables, supprime les calculs inutiles, choisit l'agencement mémoire, ajuste la taille des tuiles, etc., et génère des noyaux adaptés à la cible, GPU, NPU ou autre. Il produit automatiquement le code optimal pour chaque matériel à partir du même modèle, ce qui réduit fortement l'effort d'optimisation manuelle.
