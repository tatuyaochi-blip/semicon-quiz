Qu'est-ce que JSON (JavaScript Object Notation) ?

Format texte de représentation des données fondé sur la syntaxe des objets JavaScript. Il combine des objets, qui regroupent des paires nom-valeur entre { }, et des tableaux, qui alignent des valeurs entre [ ] ; les valeurs peuvent être des chaînes, des nombres, true ou false, ou null. Les noms et les chaînes doivent toujours être entourés de guillemets doubles. Plus concis que XML et lisible et inscriptible dans de nombreux langages de programmation, il est très utilisé comme format de données des API web. Son type de média est application/json.

Nom japonais: JSON

Une API web renvoie des données au format JSON comme corps de sa réponse. Quel en-tête ajoute-t-on généralement à la réponse pour indiquer le format du corps ?

  1. AAccept: application/json
  2. BContent-Type: text/html
  3. CContent-Type: application/json
Afficher la réponse et l'explication

Réponse : C. Content-Type: application/json

Le type des données du corps est indiqué par l'en-tête Content-Type, dont la valeur est un type de média (type MIME) de la forme « type/sous-type », comme text/html ou image/png. Le type de média de JSON est application/json. JSON est un format texte qui représente les données par des paires nom-valeur et des tableaux, comme {"id": 42, "tags": ["a", "b"]} ; plus concis que XML et facile à manipuler depuis JavaScript, il est très utilisé dans les API web. L'en-tête Accept sert, dans une requête, à indiquer au serveur les formats que le client souhaite recevoir.
