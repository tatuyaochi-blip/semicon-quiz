Qu'est-ce que Analyse top-down ?

Méthode qui, à l'aide des compteurs de performance, répartit l'utilisation des créneaux de traitement d'instructions du CPU entre front-end, back-end, spéculation perdue et instructions retirées, afin de cerner le goulot d'étranglement.

Nom japonais: トップダウン分析

Domaine: Analyse des performances

Termes associés

Benchmark (banc d'essai) Benchmark STREAM Compteur de performance CPI Débit (throughput) Effet de sonde (probe effect) Efficacité parallèle Facteur d'accélération (speedup) Flame graph Latence de queue (tail latency)
