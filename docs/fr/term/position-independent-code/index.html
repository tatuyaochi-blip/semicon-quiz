Qu'est-ce que Code indépendant de la position ?

Code machine qui fonctionne sans modification quelle que soit l'adresse de chargement en mémoire. Aussi appelé PIC. Il utilise des références relatives au PC et la GOT ; employé pour les bibliothèques partagées et les PIE.

Nom japonais: 位置独立コード

« Code indépendant de la position » apparaît dans 5 questions d'entraînement réparties sur 2 thèmes, dont Éditeurs de liens, chargeurs et exécutables, ISA et assembleur.

Quelle description du code indépendant de la position (PIC) est correcte ?

  1. ADu langage machine fonctionnant de la même manière sur tous les CPU
  2. BDu langage machine qui déplace continuellement son propre emplacement pendant l'exécution
  3. CDu langage machine conçu pour fonctionner correctement quelle que soit l'adresse mémoire où il est chargé, sans modification du code
Afficher la réponse et l'explication

Réponse : C. Du langage machine conçu pour fonctionner correctement quelle que soit l'adresse mémoire où il est chargé, sans modification du code

Une bibliothèque partagée peut être chargée à une adresse différente dans chaque processus. Le code indépendant de la position référence fonctions et données non par des adresses fixes, mais par leur distance au PC ou via une table regroupant les adresses (GOT). Ainsi, même si l'adresse de chargement change, les pages de code n'ont pas à être modifiées, et une seule copie en mémoire physique peut être partagée par de nombreux processus.
