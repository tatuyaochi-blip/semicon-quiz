Qu'est-ce que ECC (code correcteur d'erreurs) ?

Mécanisme qui ajoute des bits redondants aux données pour détecter et corriger les bits erronés à la lecture. Utilisé dans la mémoire serveur, la mémoire flash et à l'intérieur des puces DDR5.

Nom japonais: ECC(誤り訂正符号)

Quelle fonction du code correcteur d'erreurs (ECC) utilisé dans les mémoires est correcte ?

  1. ACompresser les données pour augmenter la capacité
  2. BAjouter des bits redondants aux données pour détecter et corriger les erreurs de bits
  3. CChiffrer les données
Afficher la réponse et l'explication

Réponse : B. Ajouter des bits redondants aux données pour détecter et corriger les erreurs de bits

L'ECC ajoute aux données des bits de contrôle et détecte et corrige les erreurs à la lecture. Pour la mémoire de serveur, le schéma de base ajoute 8 bits à 64 bits, corrige les erreurs d'un bit et détecte les erreurs de deux bits (SECDED). Les serveurs à haute fiabilité disposent en outre de Chipkill, capable de récupérer la défaillance complète d'une puce. La DDR5 intègre également un ECC à l'intérieur de la puce.

Combien de puces DRAM de largeur 8 bits (x8) faut-il par rang pour former un bus de données de 64 bits (sans ECC) ?

  1. A4 puces
  2. B64 puces
  3. C8 puces
Afficher la réponse et l'explication

Réponse : C. 8 puces

64 bits ÷ 8 bits = 8 : huit puces x8 accédées simultanément donnent une largeur de 64 bits. Avec des puces x4, il en faut 16, avec des x16, 4. Les modules avec ECC ajoutent les puces nécessaires aux 8 bits de contrôle, soit 9 puces x8 (72 bits de large). Les modules DDR5 sont divisés en deux sous-canaux de 32 bits ; avec ECC, chaque sous-canal fait 40 bits de large.
