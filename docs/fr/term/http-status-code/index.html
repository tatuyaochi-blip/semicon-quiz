Qu'est-ce que Code d'état HTTP ?

Nombre à trois chiffres placé sur la première ligne d'une réponse HTTP, qui indique le résultat de la requête. Le chiffre des centaines donne la classe : 1xx information, 2xx succès (200 OK, 201 Created, 204 No Content), 3xx redirection (301 Moved Permanently, 302 Found, 304 Not Modified), 4xx erreur du client (400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found) et 5xx erreur du serveur (500 Internal Server Error, 503 Service Unavailable). 401 s'utilise lorsque les informations d'authentification sont absentes ou incorrectes, et 403 lorsque l'utilisateur est authentifié mais n'a pas le droit d'accès.

Nom japonais: HTTPステータスコード

S'entraîner : questions sur Code d'état HTTP

En HTTP, quelle association entre un code d'état et sa signification est correcte ?

  1. A301 : la ressource demandée se trouve temporairement à une autre URL
  2. B404 : la ressource demandée est introuvable sur le serveur
  3. C503 : la requête est mal formée et le serveur n'a pas pu la comprendre
Afficher la réponse et l'explication

Réponse : B. 404 : la ressource demandée est introuvable sur le serveur

Un code d'état est un nombre à trois chiffres dont le chiffre des centaines indique la classe. 2xx signifie un succès (200 OK, 201 Created, 204 No Content), 3xx une redirection (301 Moved Permanently, 302 Found, 304 Not Modified), 4xx une erreur du client (400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found) et 5xx une erreur du serveur (500 Internal Server Error, 503 Service Unavailable). 404 indique que la ressource désignée par l'URL est introuvable sur le serveur.

Sur un site réservé aux membres, un membre ordinaire connecté demande une page à laquelle seuls les administrateurs ont accès. Le serveur sait qui est l'utilisateur, mais n'autorise pas l'accès à cette page. Quel code d'état est le plus approprié pour la réponse ?

  1. A401 Unauthorized
  2. B403 Forbidden
  3. C404 Not Found
Afficher la réponse et l'explication

Réponse : B. 403 Forbidden

403 Forbidden indique que le serveur a compris la requête mais refuse d'en autoriser l'accès. Malgré son nom, 401 Unauthorized est le code qui signale des informations d'authentification absentes ou incorrectes, et l'en-tête WWW-Authenticate indique au client la méthode d'authentification. Ici, le serveur sait qui est l'utilisateur et ce qui manque, c'est le droit d'accès (l'autorisation) : 403 s'applique donc. Certaines conceptions renvoient délibérément 404 pour ne pas révéler l'existence d'une page d'administration, mais le code qui décrit la situation telle qu'elle est, c'est 403.
