Qu'est-ce que inode ?

Dans les systèmes de fichiers de Linux et des systèmes semblables, enregistrement de gestion d'un fichier qui contient notamment sa taille, son propriétaire, ses permissions, son heure de modification et l'emplacement de son contenu sur le disque. À l'intérieur d'un système de fichiers, il est identifié par un numéro (le numéro d'inode), que l'on peut vérifier avec ls -i ou stat. Le nom du fichier ne fait pas partie de l'inode : c'est le répertoire qui contient la correspondance « nom → numéro d'inode », si bien qu'un même inode peut porter plusieurs noms (liens physiques). Dans les systèmes de fichiers où le nombre d'inodes est fixé à la création, un très grand nombre de petits fichiers peut épuiser les inodes, de sorte qu'aucun nouveau fichier ne peut être créé alors qu'il reste de l'espace ; df -i montre leur utilisation.
