Qu'est-ce que API REST ?

API web conçue selon les principes de REST. Les objets manipulés sont représentés comme des ressources identifiées par des URL, et les opérations s'expriment par les méthodes HTTP : GET pour la lecture, POST pour la création, PUT ou PATCH pour la mise à jour, DELETE pour la suppression. Chaque requête est sans état et contient toutes les informations nécessaires à son traitement, et les données sont souvent représentées en JSON. Le résultat est renvoyé par un code d'état HTTP : par exemple, une création réussie renvoie 201 Created.

Nom japonais: REST API

Quelle conception d'API web est conforme aux principes de REST ?

  1. AMettre le nom de l'opération dans l'URL, comme /getUser?id=42 ou /deleteUser?id=42, et tout envoyer en GET
  2. BReprésenter la ressource utilisateur par une URL comme /users/42 et exprimer les opérations par les méthodes HTTP, par exemple GET pour la lecture et DELETE pour la suppression
  3. CLe serveur mémorise pour chaque client le contenu de la requête précédente, et la requête suivante n'envoie qu'une courte commande qui en dépend
Afficher la réponse et l'explication

Réponse : B. Représenter la ressource utilisateur par une URL comme /users/42 et exprimer les opérations par les méthodes HTTP, par exemple GET pour la lecture et DELETE pour la suppression

En REST, les objets manipulés sont représentés comme des ressources identifiées par des URL, et les opérations sur ces ressources sont exprimées par des méthodes HTTP comme GET (lecture), POST (création), PUT ou PATCH (mise à jour) et DELETE (suppression). Par exemple, GET /users/42 lit une ressource, et lorsque POST /users crée un nouvel utilisateur, le serveur renvoie 201 Created avec l'URL de la nouvelle ressource. Chaque requête est sans état et contient toutes les informations nécessaires à son traitement. Si une opération comme une suppression se fait par GET, des données risquent de disparaître du seul fait que le navigateur récupère des liens par anticipation ou qu'un robot d'indexation visite la page.
