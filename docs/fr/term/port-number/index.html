Qu'est-ce que Numéro de port ?

Nombre de 0 à 65535 utilisé par TCP et UDP pour indiquer à quelle application d'un terminal une communication est destinée. Les ports 0 à 1023, comme 80 pour HTTP, 443 pour HTTPS et 53 pour DNS, sont appelés ports bien connus (well-known ports).

Nom japonais: ポート番号

S'entraîner : questions sur Numéro de port

Quelle combinaison associe correctement des protocoles aux numéros de port standard utilisés par leurs serveurs ?

  1. AHTTP 80, HTTPS 443, DNS 53
  2. BHTTP 8080, HTTPS 443, DNS 25
  3. CHTTP 80, HTTPS 22, DNS 53
Afficher la réponse et l'explication

Réponse : A. HTTP 80, HTTPS 443, DNS 53

Un numéro de port est un nombre de 16 bits, de 0 à 65535, qui indique à quelle application d'un terminal, atteint grâce à son adresse IP, une communication est destinée. Les ports 0 à 1023 sont appelés ports bien connus (well-known ports) et sont attribués aux principaux services. Les plus courants sont HTTP 80, HTTPS 443, DNS 53, SSH 22 et SMTP (transfert du courrier) 25. Côté client, le port source est un numéro choisi à chaque fois par l'OS (port éphémère). Un service peut fonctionner sur un numéro non standard ; 8080 sert souvent au développement web ou aux serveurs proxy, mais le client doit alors préciser le numéro.
