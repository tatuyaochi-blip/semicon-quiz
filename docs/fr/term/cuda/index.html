Qu'est-ce que CUDA ?

Environnement de programmation permettant d'effectuer des calculs généraux sur les GPU NVIDIA. Les noyaux s'écrivent dans une extension du C++, et le parallélisme s'exprime par la hiérarchie grille-bloc-thread.

Nom japonais: CUDA

S'entraîner : questions sur CUDA

Quelle est la définition du « noyau » (kernel) en programmation GPU, par exemple en CUDA ?

  1. ALa partie centrale du système d'exploitation du GPU
  2. BUne fonction exécutée simultanément par de nombreux threads sur le GPU
  3. CUn composant refroidissant la puce GPU
Afficher la réponse et l'explication

Réponse : B. Une fonction exécutée simultanément par de nombreux threads sur le GPU

En programmation GPU, un noyau est une fonction lancée depuis le programme côté CPU et dont le même code est exécuté par de nombreux threads sur le GPU. Chaque thread utilise son propre indice pour choisir l'élément de données dont il est chargé. Pour une addition de tableaux par exemple, on écrit le noyau pour qu'un thread additionne un élément, et l'on lance autant de threads que d'éléments. Le mot est le même que pour le noyau d'un système d'exploitation, mais le sens diffère.

Quelle est la hiérarchie correcte des threads en CUDA (du plus grand au plus petit) ?

  1. AGrille → bloc → thread
  2. BThread → bloc → grille
  3. CBloc → thread → grille
Afficher la réponse et l'explication

Réponse : A. Grille → bloc → thread

Un lancement de noyau forme une grille, divisée en de nombreux blocs, eux-mêmes divisés en de nombreux threads. Les threads d'un même bloc sont exécutés sur le même SM (ensemble d'unités de calcul) et peuvent coopérer via la mémoire partagée et se synchroniser. Les blocs différents s'exécutant indépendamment, le nombre de blocs actifs simultanément varie selon la taille du GPU, et un même programme fonctionne sur des GPU petits ou grands.
