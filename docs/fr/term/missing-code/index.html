Qu'est-ce que Code manquant ?

Défaut d'un CAN dont un code de sortie n'apparaît jamais, quelle que soit la variation de l'entrée. Il survient lorsque la DNL atteint −1 LSB.

Nom japonais: ミッシングコード

« Code manquant » apparaît dans 3 questions d'entraînement réparties sur 2 thèmes, dont Conversion A/N et N/A, Lire une fiche technique.

Domaine: Conversion A/N et N/A

Comment un code disparaît

Un CAN divise sa plage d'entrée en intervalles de code séparés par des tensions de transition. Idéalement, chaque intervalle a une largeur d'exactement 1 LSB. La non-linéarité différentielle (DNL) est la largeur réelle de chaque intervalle moins 1 LSB : un intervalle de 1,5 LSB a une DNL de +0,5 LSB. Lorsque la DNL atteint −1 LSB, l'intervalle a une largeur nulle ; ses deux transitions coïncident et aucune tension d'entrée ne le produit. C'est un code manquant. Comme la somme des largeurs d'intervalle doit couvrir toute la plage, un code manquant s'accompagne souvent d'un code voisin trop large.

Pourquoi cela se produit

Les codes manquants apparaissent généralement aux transitions de retenue majeures, où de nombreux bits changent à la fois, par exemple de 0111…1 à 1000…0. Dans un CAN SAR (registre à approximations successives), le CNA (convertisseur numérique-analogique) capacitif interne fixe les niveaux de décision ; si le poids d'un bit de rang supérieur est légèrement trop faible par rapport à la somme des bits inférieurs, le code situé juste sous cette transition peut disparaître, tandis qu'un poids trop grand crée au contraire un code anormalement large. Les CAN pipeline et à sous-gammes sont sensibles aux offsets des comparateurs entre étages ; c'est pourquoi ils intègrent de la redondance et une correction numérique d'erreur pour garantir l'absence de codes manquants.

Test et spécifications des fiches techniques

Les codes manquants se détectent par un test d'histogramme : on applique une rampe lente ou une sinusoïde, on recueille de nombreux échantillons et on compte le nombre d'occurrences de chaque code. Avec une rampe, le compte de chaque code est proportionnel à sa largeur ; avec une sinusoïde, les comptes sont corrigés selon la distribution d'amplitude de la sinusoïde. Un code sans aucune occurrence est manquant. Les fiches techniques indiquent une résolution garantie sans code manquant, par exemple une sortie 16 bits sans code manquant à 16 bits ou peut-être à 15 bits, ce qui équivaut à garantir une DNL supérieure à −1 LSB à cette résolution.

Codes manquants, INL et monotonie des CNA

La non-linéarité intégrale (INL) est l'écart cumulé de la courbe de transfert par rapport à une droite idéale ; un CAN peut présenter plusieurs LSB d'INL tout en produisant tous les codes, si bien que l'INL ne détermine pas directement les codes manquants. Dans un CNA, la préoccupation analogue est la monotonie : si la DNL reste supérieure à −1 LSB, la sortie ne diminue jamais quand le code augmente. Les codes manquants importent surtout dans les boucles de régulation, où un code sauté agit comme un saut brutal du gain de boucle pouvant provoquer des cycles limites, et dans les systèmes de mesure qui construisent des histogrammes de codes.

  3. CLe décalage de la sortie lorsque l'entrée est nulle

Réponse : B. L'écart de la largeur entre codes adjacents (largeur de pas) par rapport au 1 LSB idéal

La DNL est l'écart entre la largeur d'entrée correspondant à chaque code (largeur de pas) et le 1 LSB idéal ; une largeur de 1,5 LSB donne par exemple DNL = +0,5 LSB. Une DNL de −1 LSB fait disparaître le code (code manquant), et au-delà de +1 LSB la résolution est réduite en pratique. L'écart de l'ensemble de la caractéristique par rapport à la droite idéale est la non-linéarité intégrale (INL), et le décalage de sortie pour une entrée nulle est l'erreur d'offset.

  3. CGlitch

Réponse : A. Code manquant

Un code dont la DNL est inférieure ou égale à −1 LSB n'a plus de largeur d'entrée et n'apparaît pas en sortie : c'est un code manquant. Par exemple, si le poids d'un bit de poids fort du CNA interne d'un CAN SAR est trop faible, des codes peuvent être sautés. Ce défaut étant rédhibitoire pour les systèmes de régulation ou l'analyse de distributions par histogramme, les fiches techniques indiquent le nombre de bits garantis « sans code manquant » (No Missing Codes).

Questions fréquentes

Que signifie « no missing codes » dans une fiche technique de CAN ?

Cela garantit que chaque code de sortie apparaît pour une certaine tension d'entrée à la résolution indiquée, ce qui équivaut à une DNL restant supérieure à −1 LSB.

L'INL peut-elle provoquer des codes manquants ?

Pas directement. L'INL est un écart cumulé par rapport à une droite, tandis que les codes manquants proviennent d'un intervalle de code unique dont la largeur tombe à zéro, ce qui relève de la DNL.

Comment tester les codes manquants d'un CAN ?

Appliquez une rampe lente ou une sinusoïde, recueillez un grand nombre d'échantillons et construisez un histogramme des codes de sortie ; tout code sans aucune occurrence est manquant.
