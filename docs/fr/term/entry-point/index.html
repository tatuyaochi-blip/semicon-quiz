Qu'est-ce que Point d'entrée ?

Adresse à laquelle commence l'exécution d'un programme, enregistrée dans l'en-tête ELF. En C, il ne s'agit généralement pas de main mais d'un code de démarrage comme _start, qui initialise puis appelle main.

Nom japonais: エントリポイント

« Point d'entrée » apparaît dans 4 questions d'entraînement réparties sur 2 thèmes, dont Éditeurs de liens, chargeurs et exécutables, Conversion A/N et N/A.

Afficher la réponse et l'explication

Réponse : C. Ce n'est généralement pas main mais un code de démarrage comme _start, qui effectue l'initialisation puis appelle main

L'éditeur de liens intègre au programme les objets de démarrage fournis par le runtime C (crt1.o, etc.) et prend comme point d'entrée le _start qu'ils contiennent. _start récupère les arguments de ligne de commande sur la pile, initialise la bibliothèque standard et les objets globaux, puis appelle main. Au retour de main, il appelle exit avec la valeur de retour pour effectuer le traitement de fin.
