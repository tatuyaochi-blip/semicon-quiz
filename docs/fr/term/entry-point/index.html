Qu'est-ce que Point d'entrée ?

Adresse à laquelle commence l'exécution d'un programme, enregistrée dans l'en-tête ELF. En C, il ne s'agit généralement pas de main mais d'un code de démarrage comme _start, qui initialise puis appelle main.

Nom japonais: エントリポイント

« Point d'entrée » apparaît dans 3 questions d'entraînement réparties sur 1 thèmes, dont Éditeurs de liens, chargeurs et exécutables.

Domaine: Éditeurs de liens, chargeurs et exécutables

Point d'entrée et main

Le point d'entrée est l'adresse de la première instruction à laquelle le chargeur transfère le contrôle ; elle est stockée dans l'en-tête de l'exécutable, par exemple dans le champ e_entry d'un fichier ELF. Pour un programme C, ce n'est normalement pas main. L'éditeur de liens ajoute des objets de démarrage de l'environnement d'exécution C, comme crt1.o, et fait du symbole _start qu'ils contiennent le point d'entrée. Pour le code C, main semble être le début, mais ce n'est qu'une fonction ordinaire appelée par ce code de démarrage. Les éditeurs de liens permettent de choisir un autre symbole d'entrée si nécessaire.

Ce que fait le code de démarrage

Sous Linux, le noyau démarre un nouveau processus en disposant sur la pile argc, les pointeurs argv, les pointeurs vers les variables d'environnement et un vecteur auxiliaire. La routine _start les rassemble, aligne la pile et appelle l'initialisation de la bibliothèque C, qui met en place la bibliothèque standard, exécute les constructeurs et les initialiseurs des objets globaux, puis appelle main. Lorsque main retourne, sa valeur de retour est transmise à exit, qui exécute les gestionnaires enregistrés avec atexit, vide les sorties mises en tampon et demande enfin au noyau de terminer le processus.

Programmes liés dynamiquement

Un exécutable lié dynamiquement indique dans un en-tête de programme le nom de son éditeur de liens dynamique, comme ld.so sous Linux. Le noyau mappe à la fois le programme et l'éditeur de liens dynamique, et démarre l'exécution au point d'entrée propre de l'éditeur de liens dynamique, et non à celui du programme. L'éditeur de liens dynamique charge les bibliothèques partagées nécessaires, applique les relocations, lie les symboles et exécute les fonctions d'initialisation des bibliothèques, puis saute au point d'entrée du programme, _start. Dans un processus lié dynamiquement, une quantité substantielle de code s'exécute donc avant la première instruction du programme lui-même.

Points d'entrée dans les noyaux et les microcontrôleurs

Le terme couvre aussi d'autres endroits où l'exécution commence. Un système d'exploitation enregistre auprès du CPU des points d'entrée d'exceptions et d'interruptions ; sur RISC-V, par exemple, une instruction ecall déclenche une exception qui fait passer dans un mode de privilège supérieur et saute au vecteur de trap configuré par l'OS. Sur un microcontrôleur bare-metal, le vecteur de reset pointe vers un code de démarrage qui prépare la pile, copie les données initialisées de la flash vers la RAM, met à zéro la section non initialisée .bss et seulement ensuite appelle main.

  1. AC'est toujours le début de la fonction main
  2. BC'est par convention le premier octet de l'exécutable
  3. CCe n'est généralement pas main mais un code de démarrage comme _start, qui effectue l'initialisation puis appelle main
Afficher la réponse et l'explication

Réponse : C. Ce n'est généralement pas main mais un code de démarrage comme _start, qui effectue l'initialisation puis appelle main

L'éditeur de liens intègre au programme les objets de démarrage fournis par l'environnement d'exécution C (crt1.o, etc.) et prend comme point d'entrée le _start qu'ils contiennent. _start récupère les arguments de ligne de commande sur la pile, initialise la bibliothèque standard et les objets globaux, puis appelle main. Au retour de main, il appelle exit avec la valeur de retour pour effectuer le traitement de fin.

Questions fréquentes

main est-il le point d'entrée d'un programme C ?

Généralement non. Le point d'entrée de l'exécutable est un code de démarrage comme _start, qui prépare les arguments et le runtime, appelle main puis transmet la valeur de retour de main à exit.

Où est stocké le point d'entrée dans un fichier ELF ?

Dans le champ e_entry de l'en-tête ELF, qui contient l'adresse virtuelle à laquelle l'exécution commence après le chargement du programme.

Qu'est-ce qui s'exécute avant main dans un programme C ?

Le code de démarrage du runtime C, l'initialisation de la bibliothèque et les constructeurs des objets globaux ; dans un programme lié dynamiquement, l'éditeur de liens dynamique charge et reloge aussi d'abord les bibliothèques partagées.
