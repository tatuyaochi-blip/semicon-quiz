Qu'est-ce que Lint ?

Outil qui examine des descriptions HDL, etc., selon des règles et sans simulation, pour détecter les écritures à risque comme les incohérences de largeur de bits ou les latchs involontaires.

Nom japonais: Lint

« Lint » apparaît dans 2 questions d'entraînement réparties sur 1 thèmes, dont HDL et vérification.

Domaine: HDL et vérification

S'entraîner : questions sur Lint

Quel est le rôle des outils de lint utilisés en vérification HDL ?

  1. AUn appareil retirant les déchets (peluches) de la puce
  2. BUn outil affichant joliment les chronogrammes de simulation
  3. CExaminer la description sans simulation pour détecter des problèmes comme les incohérences de largeur, les verrous non voulus ou les écritures non synthétisables
Afficher la réponse et l'explication

Réponse : C. Examiner la description sans simulation pour détecter des problèmes comme les incohérences de largeur, les verrous non voulus ou les écritures non synthétisables

Les outils de lint examinent statiquement la description HDL au regard de règles et signalent les écritures syntaxiquement correctes mais susceptibles de poser problème : affectation entre signaux de largeurs différentes, oubli dans la liste de sensibilité, inférence de verrous, mélange d'affectations bloquantes et non bloquantes, mauvaise gestion des horloges, etc. Exécutables sans écrire de tests, ils réduisent l'effort de vérification ultérieur lorsqu'ils sont utilisés dès les premières phases de conception.
