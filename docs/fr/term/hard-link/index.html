Qu'est-ce que Lien physique (hard link) ?

Nom supplémentaire attaché à l'inode qui gère le contenu et les attributs d'un fichier. On le crée avec ln nom_existant nouveau_nom ; les deux noms sont équivalents, et ls -i affiche le même numéro d'inode. L'inode compte les noms qui le désignent (le nombre de liens), et le contenu n'est libéré que lorsque tous les noms ont disparu : même après la suppression du nom d'origine avec rm, le fichier reste lisible par le nom restant. Il ne peut être créé qu'à l'intérieur d'un même système de fichiers, et normalement pas pour un répertoire.
