Qu'est-ce que DIMM ?

Module mémoire regroupant plusieurs puces DRAM sur une petite carte, à insérer dans un emplacement d'ordinateur ou de serveur.

Nom japonais: DIMM

Domaine: DRAM

Comment appelle-t-on le composant de mémoire de PC qui regroupe plusieurs puces DRAM sur une petite carte enfichable ?

  1. ASSD
  2. BCarte mère
  3. CDIMM (module mémoire)
Afficher la réponse et l'explication

Réponse : C. DIMM (module mémoire)

Le DIMM (Dual Inline Memory Module) est un module portant plusieurs puces DRAM sur une carte ; il est dit « dual » parce que les contacts des deux faces portent des signaux distincts. Il s'enfiche dans un connecteur de la carte mère et peut être remplacé ou ajouté ; la version compacte pour ordinateurs portables est le SO-DIMM. Pour les serveurs, il existe le RDIMM, qui tamponne les signaux, et en DDR5 le module porte aussi un circuit d'alimentation (PMIC).
