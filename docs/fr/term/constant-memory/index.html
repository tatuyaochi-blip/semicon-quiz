Qu'est-ce que Mémoire constante ?

Petite zone du GPU contenant des valeurs non modifiées pendant l'exécution du noyau. Si tous les threads d'un warp lisent la même adresse, une seule lecture est diffusée à tous, ce qui est rapide.

Nom japonais: 定数メモリ

Pour quel type d'accès la mémoire constante de CUDA est-elle particulièrement rapide ?

  1. ALorsque tous les threads d'un warp lisent la même adresse (une seule lecture diffusée à tous)
  2. BLorsque chaque thread d'un warp écrit à une adresse différente
  3. CLorsque chaque thread d'un warp lit aléatoirement une adresse différente
Afficher la réponse et l'explication

Réponse : A. Lorsque tous les threads d'un warp lisent la même adresse (une seule lecture diffusée à tous)

La mémoire constante est une petite zone non modifiée pendant l'exécution du noyau, dotée d'un cache dédié. Lorsque tous les threads d'un warp lisent la même adresse, le résultat d'une seule lecture est diffusé à tous, ce qui est très rapide. Elle convient aux valeurs utilisées par tous les threads, comme les coefficients d'un filtre d'image ou les paramètres d'une simulation physique. Si les adresses sont dispersées, les lectures se scindent et deviennent au contraire plus lentes.
