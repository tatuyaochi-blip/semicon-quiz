Qu'est-ce que Storage Class Memory ?

Mémoire non volatile visant à combler l'écart de vitesse, de capacité et de coût entre la DRAM et la flash NAND. Les produits basés sur 3D XPoint en étaient l'exemple type.

Nom japonais: ストレージクラスメモリ

Domaine: Mémoires émergentes

Termes associés

3D XPoint Calcul en mémoire (in-memory computing) Chalcogénure FeFET (transistor ferroélectrique) FeRAM (mémoire ferroélectrique) Formage (forming) Jonction tunnel magnétique (MTJ) Mémoire crosspoint MRAM PCM (mémoire à changement de phase)
