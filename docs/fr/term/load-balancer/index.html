Qu'est-ce que Répartiteur de charge (load balancer) ?

Équipement ou logiciel qui distribue les demandes des utilisateurs entre plusieurs serveurs pour répartir la charge. Il vérifie régulièrement l'état de chaque serveur (contrôles de santé) et retire de la distribution les serveurs en panne : il joue donc aussi un rôle de redondance. S'il n'est pas lui-même rendu redondant, le répartiteur de charge devient un point de défaillance unique.

Nom japonais: ロードバランサ

Un système comporte deux répartiteurs de charge (load balancers) redondants, trois serveurs web placés derrière eux et un seul serveur de base de données utilisé par tous les serveurs web. Parmi les équipements cités, lequel constitue un point de défaillance unique (un point dont l'arrêt arrête tout le système) ?

  1. ALes répartiteurs de charge
  2. BLes serveurs web
  3. CLe serveur de base de données
Afficher la réponse et l'explication

Réponse : C. Le serveur de base de données

Un point de défaillance unique (SPOF) est un point dont l'arrêt, à lui seul, arrête tout le système. Les répartiteurs de charge sont rendus redondants par deux unités, et il y a trois serveurs web, les répartiteurs pouvant retirer de la distribution un serveur en panne : le traitement se poursuit donc si l'un d'eux s'arrête. Il n'y a qu'un seul serveur de base de données et tous les serveurs web l'utilisent : s'il s'arrête, tout le système s'arrête. Rendre aussi le serveur de base de données redondant, par exemple au moyen d'une configuration en cluster, supprime ce point de défaillance unique.
