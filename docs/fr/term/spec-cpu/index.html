Qu'est-ce que SPEC CPU ?

Benchmark CPU standard composé de nombreux programmes issus d'applications réelles. Les résultats sont exprimés par la moyenne géométrique des rapports à une machine de référence.

Afficher la réponse et l'explication

Réponse : A. De nombreux programmes issus d'applications réelles sont exécutés selon des règles définies, et les performances sont exprimées par une synthèse des rapports à une machine de référence

SPEC CPU est un benchmark composé de nombreux programmes issus d'applications réelles : compilateurs, compression, simulations physiques, etc. Pour chaque programme, on calcule le rapport de son temps d'exécution à celui d'une machine de référence, puis on agrège ces rapports par moyenne géométrique en une valeur unique. Les options de compilation et les modalités d'exécution sont réglementées, et les résultats sont publiés avec des conditions détaillées.
