Qu'est-ce que URL (Uniform Resource Locator) ?

Chaîne qui indique l'emplacement d'une ressource comme une page web. Comme dans https://www.example.com:8443/docs/page.html?q=1#top, elle se compose d'un schéma (https), d'un nom d'hôte, d'un numéro de port, d'un chemin, d'une requête (après ?) et d'un fragment (après #). Si le port est omis, la valeur par défaut s'applique (443 pour HTTPS), et le nom d'hôte est converti en adresse IP par le DNS.

Nom japonais: URL

S'entraîner : questions sur URL (Uniform Resource Locator)

Un navigateur ouvre https://www.example.com:8443/docs/guide.html?lang=ja#install. Quelle partie de cette URL n'est pas incluse dans la requête envoyée au serveur et n'est utilisée que dans le navigateur après le chargement de la page ?

  1. A:8443
  2. B?lang=ja
  3. C#install
Afficher la réponse et l'explication

Réponse : C. #install

Cette URL se compose du schéma (https), du nom d'hôte (www.example.com), du numéro de port (8443 ; s'il est omis, 443 pour https), du chemin (/docs/guide.html), de la requête (query, lang=ja) et du fragment (install). Le navigateur utilise le numéro de port pour choisir où se connecter et envoie le chemin et la requête au serveur, mais il n'envoie pas le fragment qui suit #. Le fragment n'est utilisé que dans le navigateur, par exemple pour se placer sur l'élément id="install" de la page.

Pour mettre le caractère japonais « あ » dans la requête (query) d'une URL, on encode en pourcentage la suite d'octets qui le représente en UTF-8 (E3 81 82). Quel est le résultat correct ?

  1. A%E3%81%82
  2. B%u3042
  3. C&#x3042;
Afficher la réponse et l'explication

Réponse : A. %E3%81%82

Dans l'encodage-pourcent, lorsque des caractères qu'on ne peut pas écrire tels quels dans une URL, ou des caractères ayant un sens particulier comme / ? # &, sont utilisés comme données, on convertit les caractères en octets et l'on écrit chaque octet sous la forme « % » suivi de deux chiffres hexadécimaux (base 16). « あ » est formé des trois octets E3 81 82 en UTF-8 ; il devient donc %E3%81%82. Une espace devient %20 (dans le format d'envoi des formulaires, + est aussi utilisé). En JavaScript, la fonction encodeURIComponent effectue cette conversion.
