Qu'est-ce que Compression sans perte ?

Méthode de compression qui permet de restaurer les données d'origine sans le moindre bit de différence. On l'appelle aussi compression lossless. Elle comprend le codage de Huffman et le codage arithmétique, qui exploitent la dissymétrie des probabilités des symboles, les méthodes LZ comme LZ77, qui exploitent les répétitions, et le codage par plages ; elle est utilisée dans ZIP, gzip, PNG, FLAC et ailleurs. On l'emploie pour les données où pas un seul bit ne doit différer, comme les programmes, les documents et les données de tableaux. Le taux de réduction dépend de la redondance des données, et aucune compression sans perte ne peut réduire toutes les données.

Nom japonais: 可逆圧縮

Quelle description de la relation entre la compression sans perte et l'entropie d'une source est correcte ?

  1. AAvec un algorithme de compression sans perte suffisamment performant, n'importe quel fichier, quel que soit son contenu, peut toujours être rendu plus petit que l'original
  2. BMême pour une source qui émet des symboles indépendamment, un code sans perte habilement conçu peut rendre la longueur moyenne de code inférieure à l'entropie
  3. CLa longueur moyenne de code d'un code sans perte ne peut pas être rendue inférieure à l'entropie, mais coder les symboles par groupes l'en rapproche
Afficher la réponse et l'explication

Réponse : C. La longueur moyenne de code d'un code sans perte ne peut pas être rendue inférieure à l'entropie, mais coder les symboles par groupes l'en rapproche

Pour une source qui émet des symboles indépendamment, la longueur moyenne de code par symbole d'un code sans perte est au moins égale à l'entropie, et coder les symboles par groupes l'en rapproche autant qu'on veut (théorème du codage de source). De plus, il existe 2ⁿ fichiers de n bits, mais seulement 2ⁿ − 1 suites de bits plus courtes au total : aucune compression sans perte ne peut donc raccourcir tous les fichiers. La compression sans perte raccourcit les données qui présentent un déséquilibre ou des répétitions, au prix d'un léger allongement des autres données.

Lors de la compression de données, dans lequel des cas suivants faut-il utiliser une compression sans perte plutôt qu'une compression avec perte ?

  1. ACompresser le fichier exécutable d'un programme pour le distribuer
  2. BDans un service de diffusion vidéo en continu, réduire la vidéo pour l'adapter au débit de la connexion
  3. CRéduire la taille de fichiers musicaux pour les écouter sur un baladeur
Afficher la réponse et l'explication

Réponse : A. Compresser le fichier exécutable d'un programme pour le distribuer

La compression sans perte restitue les données d'origine sans le moindre bit de différence, tandis que la compression avec perte élimine des parties que l'on remarque à peine, en échange d'une réduction bien plus forte. Un programme ne fonctionne pas correctement si un seul bit diffère : on utilise donc une compression sans perte comme ZIP. Les petites différences d'image et de son sont difficiles à voir ou à entendre : pour la vidéo et la musique, on utilise donc couramment des compressions avec perte comme JPEG, MP3 et les formats de codage vidéo.
