Qu'est-ce que Critère de Routh–Hurwitz ?

Méthode qui détermine, à partir des seuls coefficients de l'équation caractéristique et sans la résoudre, si toutes ses racines (les pôles de la boucle fermée) se trouvent dans le demi-plan gauche du plan s. Une condition nécessaire est que tous les coefficients aient le même signe, sans terme manquant ; de plus, le système est stable si la première colonne du tableau de Routh est entièrement de même signe, et le nombre de changements de signe est égal au nombre de racines situées dans le demi-plan droit. Une équation du troisième degré s³ + a₂s² + a₁s + a₀ = 0 est stable si tous les coefficients sont positifs et si a₂a₁ > a₀. On l'utilise pour trouver la plage d'un gain pour laquelle un système est stable. La méthode de Routh et celle de Hurwitz donnent les mêmes conditions.

Nom japonais: ラウス・フルビッツの安定判別法

S'entraîner : questions sur Critère de Routh–Hurwitz

Un système à retour unitaire a pour fonction de transfert en boucle ouverte K/(s(s + 1)(s + 2)). Pour quelle plage de K le système en boucle fermée est-il stable ?

  1. A0 < K < 2
  2. B0 < K < 3
  3. C0 < K < 6
Afficher la réponse et l'explication

Réponse : C. 0 < K < 6

L'équation caractéristique est s(s + 1)(s + 2) + K = s³ + 3s² + 2s + K = 0. D'après le critère de Routh–Hurwitz, une équation du troisième degré s³ + a₂s² + a₁s + a₀ = 0 est stable si tous les coefficients sont positifs et si a₂a₁ > a₀, d'où 3 × 2 > K, c'est-à-dire 0 < K < 6. Pour K = 6, les pôles se placent en s = ±j√2, ce qui donne une oscillation entretenue de pulsation environ 1,41 rad/s (période d'environ 4,4 s). Pour un K plus grand, l'oscillation ne cesse de croître.

Quelle valeur est la plus proche de la marge de gain de la fonction de transfert en boucle ouverte L(s) = 2/(s(s + 1)(s + 2)) ?

  1. AEnviron 4,8 dB
  2. BEnviron 9,5 dB
  3. CEnviron 15,6 dB
Afficher la réponse et l'explication

Réponse : B. Environ 9,5 dB

La phase vaut −90° − tan⁻¹ω − tan⁻¹(ω/2) ; les deux angles totalisent 90° lorsque ω × (ω/2) = 1, si bien que la phase atteint −180° pour ω = √2 rad/s. Le gain y vaut |L(j√2)| = 2/(√2 × √3 × √6) = 1/3, donc la marge de gain vaut 20 log₁₀3 ≈ 9,5 dB. Multiplier le gain par 3 (K = 6) amènerait à la limite, ce qui concorde avec la plage de stabilité 0 < K < 6 obtenue avec le critère de Routh–Hurwitz.
