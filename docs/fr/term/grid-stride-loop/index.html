Qu'est-ce que Boucle grid-stride ?

Façon d'écrire un noyau (kernel) où chaque thread traite les éléments par pas égal au nombre total de threads. Elle découple le nombre de threads lancés du nombre d'éléments.

Nom japonais: グリッドストライドループ

Domaine: Programmation GPU

Termes associés

Bloc de threads Coalescence mémoire Conflit de banc CUDA Divergence de warp Masquage de latence Mémoire constante Mémoire épinglée (pinned memory) Mémoire partagée (shared memory) Mémoire unifiée
