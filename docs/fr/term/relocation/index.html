Qu'est-ce que Relocalisation ?

Opération qui, une fois les adresses définitives du code et des données fixées, remplace les adresses provisoires contenues dans les instructions et les données par les bonnes valeurs. Effectuée par l'éditeur de liens, et en partie à l'exécution par l'éditeur de liens dynamique.

Nom japonais: 再配置

Réponse : A. Une fois les adresses définitives du code et des données fixées, réécrire les adresses dans les instructions et les données avec les valeurs correctes

Le compilateur produit chaque fichier comme s'il commençait à l'adresse 0, et enregistre comme informations de relocalisation les emplacements utilisant l'adresse de fonctions d'autres fichiers ou de ses propres variables. Après avoir disposé tous les fichiers et fixé les adresses réelles, l'éditeur de liens calcule pour chaque emplacement enregistré l'adresse correcte (ou la distance au PC) et l'inscrit dans l'instruction. En édition de liens dynamique, une partie de ces réécritures est effectuée à l'exécution par l'éditeur de liens dynamique.
