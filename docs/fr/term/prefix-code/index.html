Qu'est-ce que Code préfixe ?

Code dans lequel aucun mot de code n'est le début d'un autre mot de code. Par exemple, {0, 10, 110, 111} est un code préfixe : en lisant la suite de bits reçue depuis le début et en coupant dès qu'un mot de code correspond, on la décode d'une seule manière sans attendre les bits suivants. C'est pourquoi on l'appelle aussi code instantané. Si un ensemble de longueurs de code satisfait l'inégalité de Kraft, on peut construire un code préfixe ayant ces longueurs. Les codes de Huffman sont des codes préfixes. Certains codes qui ne sont pas des codes préfixes, comme {0, 01, 11}, peuvent tout de même se décoder d'une seule manière, mais leur décodage exige de regarder les bits suivants.

Nom japonais: 接頭符号

S'entraîner : questions sur Code préfixe

Parmi les ensembles de mots de code suivants, attribués à quatre symboles, lequel est un code préfixe (code dans lequel aucun mot de code n'est le début d'un autre mot de code) ?

  1. A{0, 01, 011, 111}
  2. B{0, 10, 110, 111}
  3. C{00, 01, 1, 10}
Afficher la réponse et l'explication

Réponse : B. {0, 10, 110, 111}

Dans un code préfixe, un symbole est déterminé dès que son mot de code a été lu : on peut donc le décoder immédiatement sans attendre les bits suivants (code instantané). Dans {0, 10, 110, 111}, aucun mot de code n'est le début d'un autre. Dans {0, 01, 011, 111}, 0 est le début de 01 et de 011, et dans {00, 01, 1, 10}, 1 est le début de 10.

Un code préfixe attribue les mots de code A = 0, B = 10, C = 110 et D = 111 aux symboles A, B, C et D. Quel est le résultat du décodage de la suite de bits 110100111 depuis le début ?

  1. ACABD
  2. BCBDA
  3. CCBAD
Afficher la réponse et l'explication

Réponse : C. CBAD

On lit depuis le début et on coupe dès qu'un mot de code correspond. 110 donne C, le 10 suivant donne B, 0 donne A et le 111 restant donne D : le résultat est donc CBAD. Comme il s'agit d'un code préfixe, la suite ne peut se découper ainsi que d'une seule manière et se décode sans aucun symbole de séparation.
