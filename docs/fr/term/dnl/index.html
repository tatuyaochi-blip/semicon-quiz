Qu'est-ce que DNL (non-linéarité différentielle) ?

Erreur indiquant l'écart entre la largeur de pas entre codes adjacents d'un convertisseur et le 1 LSB idéal. À −1 LSB, un code manquant apparaît.

Nom japonais: DNL(微分非直線性)

« DNL (non-linéarité différentielle) » apparaît dans 8 questions d'entraînement réparties sur 3 thèmes, dont Conversion A/N et N/A, Test et inspection, Lire une fiche technique.

Domaine: Conversion A/N et N/A

Définition de la DNL

Un convertisseur idéal de N bits divise sa pleine échelle en 2ᴺ pas égaux de 1 LSB (bit de poids faible). Pour un convertisseur analogique-numérique (CAN), chaque code de sortie doit donc correspondre à un intervalle d'entrée d'exactement 1 LSB de large. La non-linéarité différentielle (DNL) est l'erreur de largeur réelle de chaque code, exprimée en LSB : DNL = (largeur réelle − 1 LSB) / 1 LSB. Un code de 1,5 LSB de large a une DNL de +0,5 LSB, et un code de 0,7 LSB de large une DNL de −0,3 LSB. Pour un convertisseur numérique-analogique (CNA), le même principe s'applique à la taille de chaque pas de sortie.

Codes manquants et monotonie

Quand la DNL d'un code atteint −1 LSB, sa largeur devient nulle : ce code n'apparaît jamais, quelle que soit la façon dont on balaie l'entrée. C'est un code manquant. Garantir « aucun code manquant » à une résolution donnée équivaut donc à garantir une DNL supérieure à −1 LSB. Une forte DNL positive, au-delà d'environ +1 LSB, gaspille de la résolution, car un code large couvre ce qui devrait en être plusieurs. Pour un CNA, une DNL supérieure à −1 LSB garantit la monotonie, c'est-à-dire que la sortie ne baisse jamais quand le code augmente. Les erreurs se concentrent aux transitions de retenue majeures, comme de 0111…1 à 1000…0, où des éléments pondérés binairement et mal appariés permutent.

DNL, INL, erreur d'offset et erreur de gain

L'erreur d'offset décale toute la courbe de transfert et l'erreur de gain modifie sa pente ; toutes deux sont linéaires et peuvent être éliminées par un étalonnage en deux points. La non-linéarité intégrale (INL) est l'écart maximal de la courbe réelle par rapport à une droite, tracée soit par les extrémités, soit par meilleur ajustement, et pour tout code elle est égale à la somme cumulée de la DNL jusqu'à ce code. Un convertisseur peut donc avoir une faible DNL partout et pourtant une forte INL si de petites erreurs s'accumulent dans le même sens. L'INL se manifeste par de la distorsion harmonique sur les grands signaux, tandis que la DNL détermine la précision des petits pas et les codes manquants ; aucune des deux n'est corrigée par un simple étalonnage.

Mesurer la DNL et la réduire à la conception

La méthode de l'histogramme, ou de densité de codes, applique au CAN un signal dont la distribution d'amplitude est connue et compte la fréquence d'apparition de chaque code. Avec une rampe lente ou un signal triangulaire, chaque code devrait recevoir le même nombre d'occurrences ; le compte de chaque code divisé par la moyenne, moins un, donne donc sa DNL. Une sinusoïde est plus facile à produire pure, mais exige une correction de sa distribution concentrée aux crêtes. Sommer la DNL donne l'INL. Côté conception, les CNA à aiguillage de courant en code thermomètre et les CNA à chaîne de résistances sont monotones par construction, et segmenter les bits de poids fort en éléments de poids égal réduit la DNL aux transitions majeures.

Afficher la réponse et l'explication

Réponse : B. L'écart de la largeur entre codes adjacents (largeur de pas) par rapport au 1 LSB idéal

La DNL est l'écart entre la largeur d'entrée correspondant à chaque code (largeur de pas) et le 1 LSB idéal ; une largeur de 1,5 LSB donne par exemple DNL = +0,5 LSB. Une DNL de −1 LSB fait disparaître le code (code manquant), et au-delà de +1 LSB la résolution est réduite en pratique. L'écart de l'ensemble de la caractéristique par rapport à la droite idéale est la non-linéarité intégrale (INL), et le décalage de sortie pour une entrée nulle est l'erreur d'offset.

Questions fréquentes

Que signifie une DNL de ±0,5 LSB ?

Chaque largeur de code est comprise entre 0,5 et 1,5 LSB : aucun code ne manque et aucun n'est plus large qu'un pas idéal et demi. C'est une spécification courante pour les convertisseurs de bonne qualité.

Différence entre DNL et INL

La DNL est l'erreur sur la largeur de chaque pas individuel, tandis que l'INL mesure l'écart de toute la courbe de transfert par rapport à une droite. L'INL à un code donné est essentiellement la DNL cumulée jusqu'à ce point.

Une DNL supérieure à −1 LSB garantit-elle l'absence de codes manquants ?

Oui. Un code manquant est précisément un code dont la largeur est devenue nulle, ce qui correspond à une DNL de −1 LSB ; maintenir chaque DNL au-dessus de −1 LSB l'exclut donc.
