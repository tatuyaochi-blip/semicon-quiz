Qu'est-ce que Table de vérité ?

Tableau donnant la sortie pour toutes les combinaisons d'entrées. Elle sert à décrire le fonctionnement d'un circuit logique.

Nom japonais: 真理値表

« Table de vérité » apparaît dans 2 questions d'entraînement réparties sur 1 thèmes, dont Circuits logiques.

Domaine: Circuits logiques

S'entraîner : questions sur Table de vérité

Combien de lignes compte la table de vérité d'un circuit logique à 3 entrées ?

  1. A6 lignes
  2. B9 lignes
  3. C8 lignes
Afficher la réponse et l'explication

Réponse : C. 8 lignes

Chaque entrée pouvant valoir 0 ou 1, il y a 2³ = 8 combinaisons pour 3 entrées, et la table de vérité compte 8 lignes. Pour n entrées, elle compte 2ⁿ lignes, croissance exponentielle ; la table de vérité d'un additionneur 32 bits (64 entrées) aurait 2⁶⁴ lignes, ce qui n'est pas réaliste. Les grands circuits sont donc conçus par assemblage de petits composants, décrits par des expressions logiques ou en HDL, et vérifiés ainsi.
