Qu'est-ce que Architecture du jeu d'instructions (ISA) ?

Spécification du processeur vue par le logiciel : instructions exécutables, registres, etc. Exemples : x86, Arm, RISC-V.

Nom japonais: 命令セットアーキテクチャ(ISA)

  3. CIls doivent être fabriqués dans la même usine de semi-conducteurs avec le même procédé
Afficher la réponse et l'explication

Réponse : B. Même si leur organisation interne diffère, ils peuvent exécuter le même programme en langage machine

L'ISA est le contrat entre logiciel et matériel qui définit les types d'instructions, l'agencement de leurs bits, le nombre de registres, etc. L'organisation interne, comme le nombre d'étages du pipeline, la taille des caches ou la méthode de prédiction de branchement, s'appelle la microarchitecture et se définit indépendamment de l'ISA. Ainsi, pour une même ISA, il existe de petits cœurs basse consommation et de grands cœurs hautes performances, aux performances et consommations différentes, mais qui exécutent le même programme en langage machine. L'usine et le procédé de fabrication sont également sans rapport avec l'ISA.
