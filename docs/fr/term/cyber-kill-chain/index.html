Qu'est-ce que Cyber Kill Chain ?

Modèle présenté en 2011 par l'entreprise américaine Lockheed Martin, qui divise le déroulement d'une attaque ciblée en sept étapes. Il considère que l'attaque passe par la reconnaissance, l'armement, la livraison, l'exploitation, l'installation, la commande et le contrôle (C2) et les actions sur les objectifs, et la défense aligne des mesures pour rompre la chaîne à chaque étape. Il exprime l'idée que plus la chaîne est rompue tôt, plus les dommages sont faibles, mais comme il représente mal les activités détaillées après l'intrusion et les malveillances internes, il est utilisé avec MITRE ATT&CK et des cadres similaires.

Nom japonais: サイバーキルチェーン

S'entraîner : questions sur Cyber Kill Chain

La Cyber Kill Chain présentée par Lockheed Martin en 2011 divise le déroulement d'une attaque ciblée en sept étapes. Quel ordre des étapes est correct ?

  1. ALivraison → reconnaissance → armement → exploitation → installation → C2 (commande à distance) → actions sur les objectifs
  2. BReconnaissance → armement → livraison → exploitation → installation → C2 (commande à distance) → actions sur les objectifs
  3. CReconnaissance → livraison → armement → installation → exploitation → actions sur les objectifs → C2 (commande à distance)
Afficher la réponse et l'explication

Réponse : B. Reconnaissance → armement → livraison → exploitation → installation → C2 (commande à distance) → actions sur les objectifs

La Cyber Kill Chain décrit une attaque en sept étapes : la reconnaissance (étudier la cible), l'armement (préparer par exemple un fichier contenant le code d'attaque), la livraison (le faire parvenir à la cible par une pièce jointe d'e-mail ou un site web), l'exploitation (exploiter une vulnérabilité pour exécuter du code), l'installation (faire persister le logiciel malveillant), le C2 (établir un canal avec un serveur de commande externe) et les actions sur les objectifs (vol ou destruction d'informations). La défense aligne ses mesures selon l'étape à laquelle elles peuvent rompre la chaîne, et plus la chaîne est rompue tôt, plus les dommages sont faibles. Par exemple, bloquer une pièce jointe suspecte au niveau de l'e-mail met fin à l'attaque à l'étape de la livraison. Le modèle représente toutefois mal les malveillances internes et les longues activités après l'intrusion ; il est donc utilisé avec MITRE ATT&CK, plus détaillé.
