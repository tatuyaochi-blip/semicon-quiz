イオン注入

イオン注入の加速エネルギーとドーズ量、注入後のアニール、チャネリング対策を3択問題で確認できます。

イオン注入の要点

イオン注入は、不純物をイオン化して電界で加速し、ウエハに打ち込む技術です。注入量(ドーズ量)と深さを精度よく制御できるため、現在の不純物導入の主流になっています。

打ち込まれたイオンは結晶に損傷を与えるため、注入後には熱処理(アニール)で結晶を回復させ、不純物を電気的に活性化させます。注入の深さを決める要因や、チャネリングを防ぐ工夫も押さえておきましょう。

イオン注入の問題一覧（50問）

  1. イオン注入で、不純物が打ち込まれる深さ(飛程)を主に決めるパラメータはどれか。
  2. イオン注入後にアニール(熱処理)を行う主な目的として正しいものはどれか。
  3. イオン注入でチャネリング(イオンが結晶のすき間を通って深く入りすぎる現象)を抑える方法として一般的なものはどれか。
  4. イオン注入のドーズ量を表す単位として正しいものはどれか。
  5. 微細なトランジスタのソース・ドレインに浅い接合をつくるための工夫として正しいものはどれか。
  6. イオン注入後の不純物の深さ方向の分布を近似的に表す分布と、そのピークの深さを表す量の組み合わせとして正しいものはどれか。
  7. イオン注入装置で、磁場を使って目的のイオン種だけを選び出す部分はどれか。
  8. 熱拡散と比べたときのイオン注入の主な利点はどれか。
  9. プリアモルファス化注入(PAI)の目的として正しいものはどれか。
  10. イオン注入中のウエハの帯電(チャージアップ)を抑えるために用いられるものはどれか。
  11. 1価のイオンを、面積100 cm²のウエハにドーズ量1×10¹⁵ ions/cm²で注入する。ビーム電流が1 mAのとき、必要な注入時間はおよそいくらか。(電気素量 1.6×10⁻¹⁹ C)
  12. CMOSのウェル形成で、高エネルギーのイオン注入を使って、表面より深い位置の不純物濃度を高くしたウェルを何と呼ぶか。
  13. ソース・ドレインの端に、チャネルと同じ導電型の不純物を斜めに注入するハロー(ポケット)注入の主な目的はどれか。
  14. 浅いp型層をつくるために、ボロン単体ではなくBF2⁺イオンを注入することがある理由はどれか。
  15. イオン注入後のアニールの初期に、注入で生じた格子間シリコンの影響で、ボロンなどの拡散が一時的に速くなる現象を何と呼ぶか。
  16. ソース・ドレインの形成のように、大きなドーズ量を短い時間で注入するために使われるイオン注入装置はどれか。
  17. 同じアニール条件で、イオン注入のドーズ量を増やすと注入層のシート抵抗は一般にどうなるか。
  18. イオン注入のマスクとしてフォトレジストを使うときに注意すべき点はどれか。
  19. ウエハをドーパントを含むプラズマに直接さらし、低エネルギーのイオンを注入するプラズマドーピングの利点として正しいものはどれか。
  20. ウエハを傾けてイオン注入を行う際に、レジストなどの高いパターンの陰になって注入されない部分ができる現象を何と呼ぶか。
  21. アニールでドーパントを活性化させるとき、電気的に活性化できる濃度の上限を決める性質はどれか。
  22. レーザーアニールの特徴として正しいものはどれか。
  23. イオン注入で、ウエハ面内のドーズを均一にするための方法として正しいものはどれか。
  24. イオン注入装置で、注入したイオンの量(ドーズ)を求めるために、ビーム電流を測定する部品はどれか。
  25. 浅いp型接合をつくる際に、ボロンと一緒に炭素などを注入する(共注入する)主な目的はどれか。
  26. イオン注入装置のイオン源で、ボロンのイオンをつくるために使われる代表的なガスはどれか。
  27. 数MeVに及ぶ高エネルギーのイオン注入が使われる用途の例として正しいものはどれか。
  28. ドーズ量1×10¹⁵ cm⁻²の不純物が、深さ100 nmの範囲に均一に分布しているとすると、平均の濃度はおよそいくらか。
  29. ウエハの剥離(スマートカット)や、パワーデバイスのライフタイム制御などに使われるイオン注入として正しいものはどれか。
  30. アモルファス化した層を再結晶させたとき、元のアモルファス層と結晶の境界より少し深い位置に残る欠陥を何と呼ぶか。
  31. イオン注入の原理として正しいものはどれか。
  32. イオン注入の加速エネルギーを表すときに一般的に使われる単位はどれか。
  33. シリコンに注入する不純物と導電型の組み合わせとして正しいものはどれか。
  34. LSIの製造で使われるイオン注入のドーズ量の範囲として最も近いものはどれか。
  35. イオン注入装置のビームの通り道を高い真空にする主な理由はどれか。
  36. 一般的なイオン注入装置で、イオンが通る順序として正しいものはどれか。
  37. 同じ加速エネルギーでシリコンに注入したとき、ヒ素(質量数75)とリン(質量数31)の飛程の関係として正しいものはどれか。
  38. イオン注入装置で、加速電圧50 kVで2価のイオン(電荷が2倍)を加速したときのエネルギーはいくらか。
  39. MOSFETのしきい値電圧の調整やウェルのような、中程度のドーズ量の注入に主に使われるイオン注入装置はどれか。
  40. 注入されたイオンがシリコンの原子をはじき飛ばしたときに結晶中にできる、空孔と格子間原子の組を何と呼ぶか。
  41. 大電流のイオン注入中にウエハを冷却する主な理由はどれか。
  42. イオン注入でできる結晶の損傷の分布として一般的に正しいものはどれか。
  43. MOSFETのポリシリコンゲート電極を低抵抗にするために、ゲートに不純物を導入する方法として一般的に使われてきたものはどれか。
  44. すでにp型の領域にn型の不純物を注入して、正味の不純物濃度を下げたり導電型を反転させたりする手法を何と呼ぶか。
  45. 減速モード(高いエネルギーで運んでからウエハの手前で減速する方式)の低エネルギー注入で注意が必要な「エネルギーコンタミネーション」の原因はどれか。
  46. マスクの端の付近にイオン注入したとき、不純物がマスクの下まで横方向に広がって入り込む原因として正しいものはどれか。
  47. 注入されたイオンが物質中でエネルギーを失う2つの仕組みの組み合わせとして正しいものはどれか。
  48. SiCにアルミニウムなどをイオン注入するとき、ウエハを数百℃に加熱しながら注入する(高温注入)ことが多い理由はどれか。
  49. nMOSのチャネルに急峻なレトログレード分布をつくるために、ボロンより重いp型不純物として検討・使用されてきた元素はどれか。
  50. 高ドーズのイオン注入を受けたフォトレジストを除去するときに問題になりやすいことはどれか。
