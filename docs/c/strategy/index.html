経営戦略と会計の基礎(ストラテジ系)の要点

半導体の会社は、技術だけでなく、どの事業にいくら投資し、どの価格で売り、どれだけ作れば利益が出るかという経営の判断で、業績が大きく変わります。巨額の設備投資が必要な工場をもつか、設計に特化してファブレスになるかといった事業の形も、固定費や減価償却の大きさを通じて、損益分岐点や景気の波への強さを左右します。

損益計算書・貸借対照表・キャッシュフロー計算書の読み方、損益分岐点や目標利益の売上高、減価償却、ROEや自己資本比率、在庫の評価などの会計の計算と、SWOT分析、PPM、ファイブフォース分析、バリューチェーン、ポーターの基本戦略、経験曲線などの経営戦略、4P・STP・プロダクトライフサイクル・価格戦略などのマーケティングを学びます。さらに、ABC分析、回帰分析、デシジョンツリー、マクシミン原理、線形計画法、NPVによる投資の評価、BPRやクラウドサービス、著作権と特許、秘密保持契約、個人情報の考え方を、計算問題を中心に扱います。ITパスポート試験・基本情報技術者試験・応用情報技術者試験のストラテジ系の学習にも役立ちます。

経営戦略と会計の基礎(ストラテジ系)の問題一覧（40問）
  1. 企業の財務諸表のうち、貸借対照表の説明として、適切なものはどれか。
  2. ある期の損益計算書の項目が、売上高8,000万円、売上原価5,000万円、販売費及び一般管理費1,800万円、営業外収益100万円、営業外費用300万円、特別利益200万円、特別損失400万円だった。この期の経常利益はどれか。
  3. 半導体メーカーが新しい製造装置を購入し、代金を現金で支払った。キャッシュフロー計算書で、この支出が記載される区分はどれか。
  4. 半導体工場の費用のうち、一般に変動費に分類されるものはどれか。
  5. 売上高が5,000万円、変動費が2,000万円、固定費が2,400万円の企業がある。この企業の損益分岐点売上高はどれか。
  6. 売上高が2億円、変動費率が70%、固定費が4,500万円の企業の安全余裕率はどれか。
  7. 固定費が3,000万円、変動費率が60%の事業で、1,000万円の利益を出すために必要な売上高はどれか。
  8. ある半導体メーカーが専用のチップを開発する。チップの販売単価は4,000円、1個あたりの変動費(ウエハ・パッケージ・テストの費用など)は2,400円で、マスクの製作費や設計費などの固定費は8億円である。損益分岐点となる販売数量はどれか。
  9. 固定費が2,700万円、変動費率が40%で、費用は変動費と固定費だけの事業がある。売上高営業利益率(営業利益 ÷ 売上高)を15%にするために必要な売上高はどれか。
  10. ある製品の作り方として、案A(固定費1,000万円、変動費率60%)と、製造ラインを自動化する案B(固定費1,600万円、変動費率45%)がある。売上高がある値を超えると、案Bの利益のほうが案Aの利益より大きくなる。その値はどれか。
  11. 取得原価1,200万円の検査装置を、耐用年数5年、残存価額0円として定額法で減価償却する。3年目の期末の帳簿価額(未償却残高)はどれか。
  12. 取得原価1,000万円の製造装置を、償却率0.4の定率法で減価償却する(償却保証額による償却方法の切替えは考えない)。2年目の期末の帳簿価額はどれか。
  13. ある企業の当期純利益が120億円、自己資本が800億円、総資産が2,000億円だった。この企業のROE(自己資本利益率)はどれか。
  14. ある企業の貸借対照表は、流動資産600億円、固定資産900億円、流動負債400億円、固定負債500億円、純資産600億円(すべて自己資本)だった。この企業の流動比率と自己資本比率の組合せとして、正しいものはどれか。
  15. ある部品の1か月の受け払いは、月初の在庫が100個(単価1,000円)、10日に200個を単価1,300円で仕入れ、15日に150個を払い出し、20日に100個を単価1,400円で仕入れ、25日に150個を払い出した。移動平均法で評価した月末の在庫の金額はどれか。
  16. 車載向けのパワー半導体を手がける企業がSWOT分析を行った。「機会(Opportunities)」に分類されるものはどれか。
  17. プロダクトポートフォリオマネジメント(PPM)で、市場成長率が高く、相対的市場シェアも高い事業の分類はどれか。
  18. PPMにおける「金のなる木」の事業についての説明として、適切なものはどれか。
  19. 半導体メーカーにとって、必要な製造装置を供給できるメーカーが少数に限られているため、価格や納期の交渉で装置メーカーの立場が強い。ファイブフォース分析の競争要因のうち、この状況に当たるものはどれか。
  20. アナログ半導体メーカーのA社は、産業機器向けの高精度なセンサ用ICという限られた市場に絞り込み、その顧客の細かな要求に合わせた製品を提供して競争している。ポーターの3つの基本戦略のうち、A社の戦略に当たるものはどれか。
  21. ポーターのバリューチェーン(価値連鎖)で、主活動に分類されるものはどれか。
  22. 顧客に価値をもたらし、競合他社がまねしにくい、企業の中核となる技術や能力を表す用語はどれか。
  23. 半導体メーカーが、自社で使うウエハを製造している材料メーカーを買収し、材料の調達から製品の製造までを自社のグループで行うようにした。このような統合の形態はどれか。
  24. 自社の工場で製造まで行うIDM(垂直統合型デバイスメーカー)と比べたときの、ファブレス企業の一般的な特徴として、適切なものはどれか。
  25. ある製品の製造コストは、累積生産量が2倍になるたびに1個あたりのコストが80%になる経験曲線(習熟率80%)に従う。累積生産量が10万個に達した時点の1個あたりのコストが1,000円のとき、累積生産量が80万個に達した時点の1個あたりのコストはどれか。
  26. マーケティングミックスの4Pを顧客の視点から捉え直した4Cで、4Pの「Price(価格)」に対応するものはどれか。
  27. プロダクトライフサイクルで、売上の伸びが鈍って市場が飽和に近づき、競合が多くなって価格競争が激しくなる段階はどれか。
  28. マイコンメーカーが、市場を用途によって車載・産業機器・家電などに分け、その中から車載市場を狙うことに決めた。そのうえで、「長期にわたる安定供給と高い信頼性」を打ち出して、競合製品とは違う位置付けを顧客に認識してもらう取組みを進めている。この最後の取組みに当たるSTPの段階はどれか。
  29. ある企業が新しい計測装置を発売するときに、新しい技術を高く評価して早く導入したい一部の顧客向けに高い価格を付けて開発費を早く回収し、その後、需要に合わせて段階的に価格を下げていく方針をとった。この価格戦略はどれか。
  30. 8種類の製品の年間売上高(万円)は、製品1が380、製品2が55、製品3が260、製品4が30、製品5が130、製品6が85、製品7が40、製品8が20である。売上高の大きい順に並べ、累積構成比が70%以下の製品をA、70%を超え90%以下の製品をB、それ以外をCとするABC分析を行ったとき、Bに分類される製品はどれか。
  31. ある工場の月ごとのウエハの投入枚数x(千枚)と電力費y(百万円)は、(x, y) = (2, 5)、(4, 9)、(6, 11)、(8, 15)だった。最小二乗法で回帰直線 y = ax + b を求め、傾きaを1千枚あたりの変動費、切片bを固定費とみなすとき、その組合せとして正しいものはどれか。
  32. 新しい製造ラインへの投資を検討している。大規模投資(投資額10億円)では、需要が大きい場合(確率0.6)に25億円、小さい場合(確率0.4)に8億円の収入が見込まれる。小規模投資(投資額4億円)では、需要が小さい場合の収入は7億円で、需要が大きい場合は、そのままなら12億円の収入だが、その時点で5億円を追加投資すると収入が22億円になる。収入から投資額を引いた利益の期待値が最大になる方針をとるとき、その期待値はどれか。
  33. ある企業が3つの戦略S1〜S3を検討している。景気が好況・普通・不況のときの利益(億円)は、S1が50、30、−10、S2が40、25、5、S3が30、20、10と見込まれ、どの景気になるかの確率は分からない。マクシミン原理(最悪の場合の利益が最大になる戦略を選ぶ)に従うとき、選ぶ戦略はどれか。
  34. ある工場で2種類の製品X、Yを作る。1個あたりの利益はXが4万円、Yが3万円で、1個作るのに必要な機械の時間はXが2時間、Yが1時間、作業者の時間はXもYも1時間である。1週間に使える時間が、機械は100時間、作業者は80時間までのとき、1週間の利益の最大値はどれか。
  35. 1,000万円を投資して業務システムを導入すると、今後3年間、毎年末に400万円の費用の削減効果が見込まれる。割引率を年5%とし、1年後・2年後・3年後の現価係数(1 ÷ 1.05ⁿ)をそれぞれ0.952、0.907、0.864とするとき、この投資の正味現在価値(NPV)に最も近いものはどれか。
  36. 企業の目標を達成するために、今の業務の手順や組織を前提とせず、業務の流れ(ビジネスプロセス)を根本から見直して再設計する取組みはどれか。
  37. クラウドサービスのうち、事業者が仮想マシン・ストレージ・ネットワークなどの基盤を提供し、OSやミドルウェア、アプリケーションは利用者が導入して管理するものはどれか。
  38. ソフトウェアや技術の知的財産の保護についての説明として、適切なものはどれか。
  39. 共同開発を検討している相手企業に自社の未公開の技術情報を見せる前に結ぶ契約で、開示した情報を検討の目的以外に使わないことや、第三者に漏らさないことを約束するものはどれか。
  40. 日本の個人情報保護法の基本的な考え方として、適切なものはどれか。
