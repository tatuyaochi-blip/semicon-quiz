AD/DA変換

ADコンバータの分解能、サンプリング定理、フラッシュ型・逐次比較型の違い、量子化誤差を3択問題で学べます。

AD/DA変換の要点

ADコンバータ(ADC)はアナログ信号をデジタル値に、DAコンバータ(DAC)はデジタル値をアナログ信号に変換する回路です。センサーや通信、オーディオなど、現実の信号とデジタル処理をつなぐ場所で必ず使われます。

性能を表す基本は分解能(ビット数)と変換速度です。サンプリング定理、量子化誤差、そしてフラッシュ型・逐次比較型・ΔΣ型といった方式ごとの特徴を押さえておきましょう。

AD/DA変換の問題一覧（30問）

  1. 8ビットのADコンバータが表現できる出力の段階数はいくつか。
  2. 最高20 kHzの成分を含むアナログ信号を、折り返し雑音(エイリアシング)なくサンプリングするために必要なサンプリング周波数はどれか。
  3. フラッシュ型ADコンバータの特徴として正しいものはどれか。
  4. 逐次比較型(SAR型)ADコンバータの動作として正しいものはどれか。
  5. 理想的なADコンバータにおける量子化誤差の最大値はどれか。(LSB:最下位ビット1つ分に相当する電圧)
  6. ΔΣ(デルタシグマ)型ADコンバータの特徴として正しいものはどれか。
  7. 分解能10ビット、フルスケール入力1.024 VのADコンバータの1 LSBに相当する電圧はいくらか。
  8. ADコンバータの前段に置くアンチエイリアシングフィルタとして使われるフィルタの種類はどれか。
  9. R-2Rラダー型DAコンバータの特徴として正しいものはどれか。
  10. ADコンバータの前段に置くサンプルホールド回路の役割はどれか。
  11. 理想的なNビットADコンバータの、量子化雑音によって決まる信号対雑音比(SNR)の近似式はどれか。(フルスケールの正弦波入力の場合)
  12. デジタルマルチメータなどによく使われる二重積分型ADコンバータの特徴として正しいものはどれか。
  13. ADコンバータの微分非直線性(DNL)の説明として正しいものはどれか。
  14. 入力を変化させても、ある出力コードが一度も現れないADコンバータの不具合を何と呼ぶか。
  15. 高速なDAコンバータで多く使われる電流ステアリング型の特徴として正しいものはどれか。
  16. 実際のADコンバータの雑音やひずみを含めた性能を、理想的なADCのビット数に換算した指標はどれか。
  17. 変換を複数の段に分けて流れ作業のように処理し、高速と中〜高分解能を両立するADコンバータはどれか。
  18. ノイズシェーピングを行わない単純なオーバーサンプリングで、サンプリング周波数を4倍にしたときに得られる量子化雑音の改善量はどれか。
  19. 高い周波数の信号をAD変換するとき、サンプリングクロックの時間的なゆらぎ(ジッタ)が問題になる理由として正しいものはどれか。
  20. マイコンでPWM信号をローパスフィルタに通してアナログ電圧をつくる方法で、出力電圧を決めるものはどれか。
  21. ADコンバータの変換速度を表す「MS/s(MSPS)」の意味として正しいものはどれか。
  22. ADコンバータの入出力特性で、入力が0のときに出力が0からずれている誤差を何と呼ぶか。
  23. ADコンバータに差動入力を使う利点として正しいものはどれか。
  24. ΔΣ型ADコンバータで、高速で粗い量子化出力を、低いサンプリング周波数の高分解能なデータに変換するデジタル回路はどれか。
  25. DAコンバータで、入力コードが切り替わる瞬間に出力に現れる一時的なとげ状の誤差を何と呼ぶか。
  26. 複数のADコンバータを少しずつずらしたタイミングで交互に動作させ、全体として高いサンプリング速度を得る方式はどれか。
  27. 逐次比較型ADコンバータの入力の前に、オペアンプなどのドライバ回路を置く主な理由はどれか。
  28. 多くの逐次比較型ADコンバータで、内部のDACとして使われている方式はどれか。
  29. 抵抗を直列に多数つないだ抵抗ストリング型DACの特徴として正しいものはどれか。
  30. ADコンバータの方式のうち、オーバーサンプリング型に分類されるものはどれか。
