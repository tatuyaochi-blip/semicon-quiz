シリコンフォトニクスの要点

シリコンフォトニクスは、CMOSと同じシリコンの製造技術を使って、光を通す導波路や変調器、受光器などを1つのチップに集積する技術です。シリコンは通信に使う1.31〜1.55 µm帯の光をほとんど吸収せず、周囲の酸化膜との屈折率差が大きいため、光を小さな回路に強く閉じ込められます。

AIの学習などでデータセンターの通信量が急増し、電気配線では高速化に伴って損失や消費電力が増え続けています。光トランシーバや、スイッチICのすぐ近くに光部品を実装するCPOなどの光インターコネクトは、こうした課題を解決する中心技術として注目されています。

シリコンフォトニクスの問題一覧（52問）
  1. 長距離の光ファイバ通信で、波長1.55 µm付近(Cバンド)が広く使われる主な理由はどれか。
  2. データセンター内の比較的短い距離の光接続で、波長1.31 µm付近(Oバンド)がよく使われる理由として正しいものはどれか。
  3. 波長1.55 µmの光の光子エネルギーと、シリコン導波路の中でのふるまいの組み合わせとして正しいものはどれか(E [eV] ≈ 1.24 / λ [µm])。
  4. シリコン導波路(屈折率約3.5)を酸化膜(SiO2、屈折率約1.45)で囲む構造の特徴として正しいものはどれか。
  5. 屈折率3.48のシリコンから屈折率1.45の酸化膜へ光が進むとき、全反射が起こる臨界角(境界面の法線から測った角度)に最も近いものはどれか。
  6. 伝搬損失が2 dB/cmのシリコン導波路を光が5 mm進んだとき、出口に残る光のパワーの割合に最も近いものはどれか。
  7. 出力+3 dBmのレーザー光が、合計10 dBの損失(ファイバとの結合、導波路、変調器など)を経て受光器に届いた。受光パワーに最も近いものはどれか。
  8. シリコンフォトニクスで使われるSOIウエハの埋め込み酸化膜(BOX層)の主な役割はどれか。
  9. 両側に薄いシリコンの板(スラブ)を残して浅くエッチングしたリブ導波路が、シリコンの光変調器によく使われる主な理由はどれか。
  10. 光ファイバとシリコンの光回路をつなぐグレーティングカプラの利点として正しいものはどれか。
  11. チップの端面で光ファイバと結合するエッジカプラの、グレーティングカプラと比べた特徴として正しいものはどれか。
  12. エッジカプラで、チップの端に向かってシリコン導波路の幅を細くしていく逆テーパ構造が使われる理由はどれか。
  13. 標準的なシングルモードファイバから届く光をシリコンの光回路で受けるとき、偏光が問題になる理由として正しいものはどれか。
  14. マッハツェンダー変調器が、光の位相の変化を光の強さの変化に変える仕組みとして正しいものはどれか。
  15. シリコンの光変調器で、電気信号によって屈折率を変える方法としてキャリア分散効果(プラズマ分散効果)が使われる理由はどれか。
  16. 高速なシリコン変調器で、位相シフタのpn接合に逆バイアスをかけて空乏層の幅を変える方式(空乏型)が多く使われる理由はどれか。
  17. マッハツェンダー変調器の性能を表すVπL(ブイパイエル)の説明として正しいものはどれか。
  18. シリコンのリング共振器が、特定の波長の光にだけ強く反応する理由として正しいものはどれか。
  19. リング共振器を使った光回路で、リングの近くにヒーターを設けて温度を制御することが多い理由はどれか。
  20. リング共振器の周長を短くしたときの変化として正しいものはどれか。
  21. シリコンフォトニクスで、シリコン導波路とともに窒化シリコン(SiN)の導波路を組み合わせることがある。SiN導波路の特徴として正しいものはどれか。
  22. シリコンの光回路で、通信波長の受光器にゲルマニウム(Ge)が広く使われる理由として正しいものはどれか。
  23. シリコンの上に成長させたゲルマニウムの受光器で、暗電流が大きくなりやすい主な原因はどれか。
  24. 波長1.55 µmで量子効率80%のフォトダイオードの受光感度(1 Wの光あたりに流れる電流)に最も近いものはどれか(R [A/W] ≈ 量子効率 × λ [µm] / 1.24)。
  25. 光受信器で、フォトダイオードのすぐ後ろに置かれるトランスインピーダンスアンプ(TIA)の役割はどれか。
  26. シリコンの光回路にレーザーを組み込む方法のうち、異種集積(ヘテロジニアス集積)の説明として正しいものはどれか。
  27. シリコンの光回路に、レーザーと一緒に光アイソレータを集積することが難しい理由として正しいものはどれか。
  28. 波長多重(WDM)の説明として正しいものはどれか。
  29. データセンター向けの光トランシーバのCWDM(粗い波長多重)では、例えば1271、1291、1311、1331 nmのように20 nm間隔で波長を並べる。間隔を広くとる主な理由はどれか。
  30. Cバンド(波長1.55 µm付近)の波長多重で、周波数の間隔100 GHzは、波長の間隔にするとおよそいくらか(Δλ ≈ λ² × Δf / c、c = 3×10⁸ m/s)。
  31. 光トランシーバで、4本のファイバに1波長ずつ信号を送る並列方式と、4つの波長を1本のファイバにまとめるCWDM方式の比較として正しいものはどれか。
  32. 光の送信信号の品質を表す消光比の説明として正しいものはどれか。
  33. ラックをまたぐような数 m以上の高速な接続で、銅のケーブルや基板の配線より光ファイバが有利になる主な理由はどれか。
  34. スイッチの前面パネルに差し込んで使うプラガブル光トランシーバの利点として正しいものはどれか。
  35. 光の送受信部品をスイッチICと同じパッケージに実装するCPO(Co-Packaged Optics)の課題として正しいものはどれか。
  36. CPOでは、レーザー光源をスイッチICのパッケージの外に置き、ファイバで光だけを供給する外部レーザー光源がよく検討される。その主な理由はどれか。
  37. 光トランシーバの「リニアドライブ」(リニアプラガブル光学、LPOなどと呼ばれる)の考え方として正しいものはどれか。
  38. DSPを省いたリニアドライブの光トランシーバの課題として正しいものはどれか。
  39. データセンター内の光接続で広く使われる強度変調・直接検波(IM-DD)方式でPAM4を使う場合、4つの値として変えているものはどれか。
  40. PAM4で、1波長あたり約106 Gb/s(誤り訂正の符号などを含む)の信号を送るときのシンボルレート(1秒あたりの記号の数)に最も近いものはどれか。
  41. データセンター間を結ぶ数十 km以上の接続などで使われるコヒーレント方式の、IM-DD方式と比べた特徴として正しいものはどれか。
  42. 800 Gb/sの光トランシーバの消費電力が16 Wのとき、1ビットあたりのエネルギーはいくらか。
  43. 合計51.2 Tb/sの帯域をもつスイッチで、すべての光接続を1ビットあたり5 pJで行うとき、光接続の消費電力に最も近いものはどれか。
  44. 波長850 nm付近のVCSELとマルチモードファイバを組み合わせた光接続の特徴として正しいものはどれか。
  45. シングルモードファイバをシリコンの光チップに固定するとき、レーザー光を実際に通して出力を測りながら位置を合わせるアクティブアライメントが行われることが多い理由はどれか。
  46. シリコンフォトニクスが、半導体の工場での量産に向いているといわれる主な理由はどれか。
  47. シリコン導波路の伝搬損失(dB/cm)の主な原因の一つとされるものはどれか。
  48. シリコン導波路の伝搬損失を測るカットバック法の説明として正しいものはどれか。
  49. 光の部品とスイッチICなどを1つのパッケージに組み込むCPOで、組み立て前にウエハの状態で光学特性を検査することが特に重要になる理由はどれか。
  50. 光の素子をつくったチップ(PIC)と、ドライバやTIAなどの電子回路のチップ(EIC)を別々につくり、積層して接続する構成が使われる理由として正しいものはどれか。
  51. 光電融合で、光の送受信部品を電子回路のすぐ近くに置こうとする主な狙いとして正しいものはどれか。
  52. 光電融合が進んでも、チップの中のごく短い配線などでは電気配線が使われ続けると考えられている主な理由として正しいものはどれか。
