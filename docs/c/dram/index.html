DRAMの要点

DRAMは、1個のトランジスタと1個のキャパシタで1ビットを記憶するメモリです。セル構造が単純なため高集積化しやすく、コンピュータの主記憶として広く使われています。

キャパシタの電荷はリーク電流で徐々に失われるため、一定時間ごとに書き直すリフレッシュが必要です。また読み出しでセルの電荷が変化するため、センスアンプで増幅したあとに再書き込みを行います。

DRAMの問題一覧（50問）

  1. 一般的なDRAMの1ビットのメモリセルの構成として正しいものはどれか。
  2. DRAMで定期的なリフレッシュ動作が必要になる理由として正しいものはどれか。
  3. DRAMの読み出し動作の特徴として正しいものはどれか。
  4. DRAMのセルで、キャパシタの容量を確保するために使われてきた立体構造の組み合わせとして正しいものはどれか。
  5. DRAMの性質として正しいものはどれか。
  6. DDR SDRAMの「DDR(ダブルデータレート)」の意味として正しいものはどれか。
  7. DRAMのセルアレイで、セルトランジスタのゲートにつながり、読み書きする行を選択する配線はどれか。
  8. 温度が上がると、DRAMのセルがデータを保持できる時間は一般にどうなるか。
  9. メモリのソフトエラーの説明として正しいものはどれか。
  10. SRAMと比べたときのDRAMの特徴として正しいものはどれか。
  11. DRAMの歩留まりを上げるために使われる冗長救済の説明として正しいものはどれか。
  12. メモリで使われる誤り訂正符号(ECC)の働きとして正しいものはどれか。
  13. DRAMで、同じ行(ページ)に連続してアクセスするとアクセス時間が短くなる理由として正しいものはどれか。
  14. DRAMのキャパシタの誘電体膜に、酸化ジルコニウムなどのHigh-k材料が使われる理由として正しいものはどれか。
  15. DRAMのセルフリフレッシュモードの説明として正しいものはどれか。
  16. 容量8 GbitのDRAMチップは、バイトに換算するといくらか。
  17. DRAMのCASレイテンシ(CL)の意味として正しいものはどれか。
  18. LPDDRと呼ばれるDRAM規格の主な用途はどれか。
  19. GPUのグラフィックスメモリとして使われるGDDRの特徴として正しいものはどれか。
  20. 最近のDRAMのセルトランジスタで、ゲート電極をシリコン基板の溝の中に埋め込む構造(埋め込みワード線)を使う主な目的はどれか。
  21. DRAMで、アドレスを行アドレスと列アドレスに分けて、同じ端子から順番に与える主な理由はどれか。
  22. DRAMの内部を複数のバンクに分ける主な目的はどれか。
  23. DRAMの読み出しで、ビット線に現れる電圧の変化が非常に小さい理由として正しいものはどれか。
  24. 将来のDRAMの大容量化の手段として研究開発が進められている3D DRAMの考え方として正しいものはどれか。
  25. DRAMで、ある行を短時間に何度も活性化すると、隣接する行のデータが反転してしまうことがある現象を何と呼ぶか。
  26. DRAMのセルのデータ保持時間を決める主なリークの経路として正しいものはどれか。
  27. DRAMのセル面積を表すときに使われる「6F²」のFの意味として正しいものはどれか。
  28. DRAMのアクセスで、開いていた行を閉じ、ビット線を中間電位に戻して次の行の活性化に備える動作を何と呼ぶか。
  29. DDR5で採用された、DRAMチップの内部で誤りを訂正する機能はどれか。
  30. プロセッサの性能向上に比べて、メモリの帯域や遅延の改善が追いつかないことによって生じる性能の制約を何と呼ぶか。
  31. DRAMの「RAM(Random Access Memory)」の意味として正しいものはどれか。
  32. パソコンやサーバーで、DRAMが主に使われる用途はどれか。
  33. パソコンのメモリとして、複数のDRAMチップを小さな基板に載せて差し込めるようにした部品を何と呼ぶか。
  34. SDRAMの「S(Synchronous)」が表す特徴として正しいものはどれか。
  35. DRAMの世界市場で大きなシェアをもつ主要メーカー3社の組み合わせとして正しいものはどれか。
  36. 一般的なDRAMの規格で、すべてのセルを一通りリフレッシュする周期として定められている時間に最も近いものはどれか。(通常の温度範囲)
  37. DRAMのタイミング規格「tRCD」が表すものはどれか。
  38. DRAMのバースト転送の説明として正しいものはどれか。
  39. データ転送速度3,200 MT/s、データバス幅64ビットのDDR4メモリ1チャネルのピーク帯域に最も近いものはどれか。
  40. パソコンでメモリを「デュアルチャネル」で動作させる主な効果はどれか。
  41. DRAMモジュールの「ランク」の説明として正しいものはどれか。
  42. データ幅8ビット(x8)のDRAMチップを使って、64ビット幅のデータバスを構成するには、1ランクあたり何個のチップが必要か(ECCなし)。
  43. 現在の多くのパソコン用プロセッサで、DRAMを制御するメモリコントローラが置かれている場所はどれか。
  44. DRAMの規格で、チップの温度が高い範囲(例えば85℃を超える範囲)で求められる対応として一般的なものはどれか。
  45. DRAMの容量が大きくなるにつれて、リフレッシュに関して問題になりやすいことはどれか。
  46. DRAMのセルアレイのビット線の構成で、対になるビット線を同じセルアレイ内に並べて配置する方式はどれか。
  47. DDR4 SDRAMなどで使われている「8nプリフェッチ」の考え方として正しいものはどれか。
  48. DDR系のDRAMで、信号の反射を抑えるための終端抵抗をDRAMチップの内部に持たせ、オン・オフを制御できるようにした機能はどれか。
  49. DRAMのセルの中には、データ保持時間が時間とともに長くなったり短くなったりを不規則に繰り返すものがある。この現象を何と呼ぶか。
  50. DRAMのワード線を駆動する電圧に、電源電圧より高い昇圧電圧(VPP)が使われる主な理由はどれか。
