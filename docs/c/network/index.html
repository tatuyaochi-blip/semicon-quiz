ネットワークの基礎の要点

Webページを開くだけでも、名前からアドレスを調べ、経路を選び、データを確実に届け、暗号で守るといった多くのしくみが順番に働いています。コンピュータネットワークは、これらの機能を層に分けて整理し、各層が自分の役割だけを受け持つことで成り立っています。

OSI参照モデルとTCP/IPの階層、MACアドレスとスイッチ、IPアドレスとサブネットマスクの計算、ARPとルーティング、TCPの3ウェイハンドシェイクやフロー制御・輻輳制御、DNS・DHCP・TLSを学びます。帯域と遅延から転送時間を求める計算や、無線LAN、ファイアウォールとVPNの基本も扱い、基本情報技術者試験のネットワーク分野の学習にも役立ちます。

ネットワークの基礎の問題一覧（40問）
  1. OSI参照モデルで、IPアドレスのような論理的なアドレスを使い、異なるネットワークの間でパケットを中継して宛先まで届ける役割をもつ層はどれか。
  2. TCP/IPの4階層のモデルで、TCPとUDPが属する層はどれか。
  3. Webページのデータを送るとき、送信側でデータが上の層から下の層へ渡されるたびに起こることとして正しいものはどれか。
  4. MACアドレスについて正しいものはどれか。
  5. ハブ(リピータハブ)と比べたときの、L2スイッチの動作として正しいものはどれか。
  6. 1台のL2スイッチでVLANを設定し、ポート1〜4をVLAN 10、ポート5〜8をVLAN 20にした。このときの動作として正しいものはどれか。
  7. IPv6アドレス 2001:0db8:0000:0000:0000:0000:0000:0001 を、省略の規則に従って正しく短く書いたものはどれか。
  8. IPアドレスが 192.168.1.10、サブネットマスクが 255.255.255.0 の端末が属するネットワークのネットワークアドレスはどれか。
  9. 192.168.5.0/26 のネットワークで、ホスト(端末やルータのインターフェース)に割り当てられるIPアドレスはいくつか。
  10. IPアドレス 192.168.10.77/27 の端末が属するサブネットのブロードキャストアドレスはどれか。
  11. 1つのサブネットに500台のホストを収容したい。これを満たすサブネットのうち、最も小さいもの(プレフィックス長が最も長いもの)はどれか。
  12. CIDR表記の /20 をサブネットマスクで表したものはどれか。
  13. 次のIPv4アドレスのうち、プライベートアドレスの範囲に含まれるものはどれか。
  14. 家庭のブロードバンドルータは、NAT(ネットワークアドレス変換)の一種であるNAPT(IPマスカレード)を行っている。NAPTによって可能になることとして正しいものはどれか。
  15. NAPTを行うルータ(外側のグローバルアドレスは 198.51.100.7)の内側にある端末A(192.168.1.10)が、送信元ポート50000でWebサーバ 203.0.113.5 の443番ポートへ接続した。ルータは送信元を 198.51.100.7 のポート61000に変換した。Webサーバが返す応答パケットの宛先はどれか。
  16. ARPの役割として正しいものはどれか。
  17. 端末(192.168.1.10/24、デフォルトゲートウェイ 192.168.1.1)が、別のネットワークにあるサーバ 203.0.113.80 にパケットを送る。ARPのキャッシュが空のとき、端末がARPでMACアドレスを調べる相手はどれか。
  18. ルータの経路表に、0.0.0.0/0(次の転送先はルータA)、10.0.0.0/8(ルータB)、10.1.0.0/16(ルータC)、10.1.2.0/24(ルータD)の4つの経路がある。宛先が 10.1.5.9 のパケットは、どのルータに送られるか。
  19. IPv4ヘッダのTTL(Time To Live)の役割として正しいものはどれか。
  20. 動的ルーティングの説明として正しいものはどれか。
  21. UDPの特徴として正しいものはどれか。
  22. TCPでコネクションを確立する3ウェイハンドシェイクで、やり取りされるパケットの順序として正しいものはどれか。
  23. RTT(往復の時間)が100 msのWebサーバに、HTTPS(TCPの上のTLS 1.3)で新しく接続し、最初のリクエストを送って応答を受け取り始めるまでにかかる時間に最も近いものはどれか。DNSの名前解決は済んでおり、サーバの処理時間とデータの転送時間は無視する。
  24. プロトコルと、そのサーバが標準で使うポート番号の組み合わせとして正しいものはどれか。
  25. TCPのフロー制御で、受信側がウィンドウサイズ(受信ウィンドウ)を送信側に通知する目的として正しいものはどれか。
  26. TCPの受信ウィンドウが65536バイトで一定、RTTが10 msの接続で、回線の帯域は十分に大きく、損失もないとする。この接続で得られるスループットの上限に最も近いものはどれか。
  27. TCPの輻輳制御の基本的な考え方として正しいものはどれか。
  28. TCPの送信側が、セグメントが失われたと判断して再送するきっかけとして正しいものはどれか。
  29. DNSの主な役割として正しいものはどれか。
  30. キャッシュに何も入っていないフルサービスリゾルバ(キャッシュDNSサーバ)が、www.example.com のIPアドレスを調べるときに問い合わせる順序として正しいものはどれか。
  31. DHCPで端末がIPアドレスを得るときの、メッセージの順序として正しいものはどれか。
  32. HTTPS(HTTPをTLSで保護した通信)で守られることとして正しいものはどれか。
  33. TLSで、ブラウザが接続先のサーバを「なりすましではない」と判断できる理由として正しいものはどれか。
  34. 100 MBのファイルを100 Mbpsの回線で送るのにかかる時間に最も近いものはどれか。ヘッダなどのオーバーヘッドや遅延は無視し、1 MB = 10^6 バイトとする。
  35. 1 Gbpsのイーサネットで、IPパケットの大きさがMTUいっぱいの1500バイトになるようにしてTCPのデータを送り続ける。IPv4ヘッダを20バイト、TCPヘッダを20バイト、イーサネットのヘッダとFCSを合わせて18バイト、プリアンブルとフレームの間の空き(フレーム間ギャップ)を合わせて20バイトとすると、アプリケーションのデータのスループットの上限に最も近いものはどれか。
  36. RTTが50 ms、帯域が100 Mbpsの回線で、10 KBの応答を受け取る要求を、前の応答を受け取り終えてから次を送る形で100回繰り返す。かかる時間に最も近いものはどれか。1回あたりの時間はRTTに応答の転送時間(データ量÷帯域)を足したものとし、1 KB = 1000バイト、サーバの処理時間は無視する。
  37. 無線LANが、有線のイーサネットで使われてきたCSMA/CDではなく、CSMA/CAを使う主な理由として正しいものはどれか。
  38. 無線LANの2.4 GHz帯と5 GHz帯の一般的な違いとして正しいものはどれか。
  39. ファイアウォール(パケットフィルタリング型)の基本的な働きとして正しいものはどれか。
  40. インターネットVPNの説明として正しいものはどれか。
