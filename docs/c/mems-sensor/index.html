MEMS・センサの要点

MEMS(微小電気機械システム)は、半導体の微細加工技術を使って、微小な機械構造と電子回路をつくり込んだデバイスです。スマートフォンの加速度センサやジャイロ、マイク、圧力センサなどに広く使われています。

可動構造を浮かせる犠牲層エッチングや、変位・応力・磁界などを電気信号に変える原理(静電容量、ピエゾ抵抗効果、ホール効果)を押さえておきましょう。

MEMS・センサの問題一覧（30問）

  1. MEMSの説明として正しいものはどれか。
  2. 静電容量式のMEMS加速度センサが加速度を検出する原理として正しいものはどれか。
  3. MEMSの製造で使われる犠牲層エッチングの目的として正しいものはどれか。
  4. 半導体圧力センサなどに利用されるピエゾ抵抗効果の説明として正しいものはどれか。
  5. ホール効果を利用したセンサ(ホール素子)で主に検出するものはどれか。
  6. 振動型のMEMSジャイロスコープが角速度を検出するために利用している力はどれか。
  7. MEMSの製造で使われるDeep RIE(ボッシュプロセス)の説明として正しいものはどれか。
  8. MEMSマイクロフォンで音を電気信号に変える代表的な方式はどれか。
  9. 一定電流を流したシリコンPN接合の順方向電圧の温度依存性として正しいものはどれか。
  10. プロジェクターに使われるDMD(デジタルミラーデバイス)の動作原理として正しいものはどれか。
  11. MEMS技術でつくられるインクジェットプリンタのヘッドの一般的なインク吐出方式はどれか。
  12. スマートフォンなどの高周波フィルタに使われるBAWフィルタが利用している現象はどれか。
  13. MEMSジャイロなどで可動部を真空中に封止する主な理由として正しいものはどれか。
  14. MEMSの製造中や使用中に、微小な可動部が表面張力などによって基板に張り付き、動かなくなる現象を何と呼ぶか。
  15. 酸化スズなどを使った半導体式ガスセンサの検出原理として正しいものはどれか。
  16. スマートフォンの電子コンパスに使われるセンサが検出するものはどれか。
  17. スマートフォンのMEMS気圧センサで、気圧の変化から推定できる情報として正しいものはどれか。
  18. MEMSの製造でSOIウエハがよく使われる理由として正しいものはどれか。
  19. MEMSの封止などで、シリコンとガラスを加熱しながら電圧をかけて接合する方法を何と呼ぶか。
  20. 自動車のLiDARなどで、レーザー光を走査するために使われるMEMSデバイスはどれか。
  21. ばねとおもりからなるMEMS構造の共振周波数を高くする方法として正しいものはどれか。
  22. 自動車のエアバッグの作動判定に使われてきたMEMSセンサはどれか。
  23. SiO2の犠牲層を除去してMEMS構造を浮かせるとき、スティクションを防ぐために使われる方法として適切なものはどれか。
  24. 基板の上に積層した薄膜を加工して可動構造をつくるMEMSの加工法はどれか。
  25. MEMSセンサとその信号処理回路を組み合わせる方法について正しいものはどれか。
  26. MEMS加速度センサが、静止した状態でも約1 Gの加速度を検出する理由として正しいものはどれか。
  27. 加速度センサ、ジャイロ、地磁気センサなどの情報を組み合わせて、より正確な姿勢や動きを求める処理を何と呼ぶか。
  28. クロック源として、水晶振動子の代わりに使われることがあるMEMS発振器の利点として正しいものはどれか。
  29. ガスの流れによってヒーターの熱が運ばれることを利用して、流量を測るMEMSセンサはどれか。
  30. 機械的な接点の開閉で高周波信号を切り替えるRF MEMSスイッチの利点として正しいものはどれか。
