制御工学の基礎の要点

エアコンの温度、モータの回転数、電源の出力電圧、ハードディスクのヘッドの位置など、身の回りの多くの量は、センサで測った結果を目標値と比べて操作量を変えるフィードバック制御で一定に保たれています。ここでは、その設計と解析の基礎になる古典制御を学びます。

まず、開ループ制御とフィードバック制御、フィードフォワード制御の違い、ブロック線図と閉ループ伝達関数、負帰還による変動の抑制を確かめ、ラプラス変換と伝達関数、最終値の定理を扱います。続いて、一次遅れ系の時定数とステップ応答、二次遅れ系の減衰係数と固有角周波数、オーバーシュートと整定時間、極の位置と応答の関係、定常偏差と系の形を計算で確かめます。安定性では、極による安定の条件、ラウス・フルビッツの安定判別法、ナイキストの安定判別法を学び、周波数応答では、ボード線図と折れ線近似、積分要素、むだ時間、ゲイン余裕と位相余裕の読み取り方と、位相余裕とオーバーシュートの関係を扱います。後半では、P・PI・PID制御のそれぞれの動作の働き、ジーグラ・ニコルスの限界感度法、積分ワインドアップと対策、微分キック、マイコンでの離散時間のPI制御の計算、0次ホールドによる位相の遅れ、s平面とz平面の対応を確かめ、モータのカスケード制御、DC-DCコンバータの制御ループ、シーケンス制御の入口に触れます。第三種電気主任技術者試験(電験三種)の「機械」の自動制御や、韓国の電気技士(전기기사)の「回路理論及び制御工学」の学習の入口としても使えます。計算問題の値は、誤りの選択肢の値も含めて、Python(NumPy)で計算して確かめています。負帰還の利得、オペアンプの位相余裕と位相補償は「アナログ・電子回路」、RC回路の時定数は「電気回路・電磁気の基礎」、z変換と差分方程式、双一次変換は「デジタル信号処理の基礎」、PWMとタイマ割り込みは「組込み・ファームウェア」、固定小数点と飽和演算は「計算機算術」、半導体の工場のプロセス制御(APC)は「歩留まり・品質管理」の分野で扱います。

制御工学の基礎の問題一覧（40問）
  1. フィードバック制御(閉ループ制御)の説明として正しいものはどれか。
  2. フィードフォワード制御を、フィードバック制御と組み合わせて使う理由として正しいものはどれか。
  3. 前向きの経路の伝達関数が G(s)、フィードバックの経路の伝達関数が H(s) の負帰還のブロック線図がある。目標値 R(s) から出力 Y(s) までの閉ループ伝達関数 Y(s)/R(s) として正しいものはどれか。
  4. 前向きの利得 G = 100、フィードバックの利得 H = 0.1 の負帰還の系がある。部品の劣化で G が50に半減したとき、閉ループの利得の減少の割合に最も近いものはどれか。
  5. 初期値をすべて0とするとき、時間関数の微分と積分を、ラプラス変換した s の領域で表す計算の組み合わせとして正しいものはどれか。
  6. 伝達関数 G(s) = 5/(s + 2) の系に、大きさ1のステップを入力した。出力の最終値(t → ∞ での値)として正しいものはどれか。
  7. 線形で時不変な系の伝達関数の説明として正しいものはどれか。
  8. 伝達関数 G(s) = 2/(1 + 0.5s) の一次遅れ系に、時刻0で大きさ1のステップを入力した。t = 1 s での出力に最も近いものはどれか。
  9. ある一次遅れ系に大きさ2のステップを入力したところ、出力は最終的に6に落ち着き、入力から0.4 sで最終値の約63%に達した。この系の伝達関数として正しいものはどれか。
  10. 二次遅れ系 G(s) = ωn²/(s² + 2ζωn s + ωn²) のステップ応答が、最終値を行き過ぎて振動しながら近づく、減衰係数 ζ の範囲として正しいものはどれか。
  11. 伝達関数 G(s) = 25/(s² + 4s + 25) の二次遅れ系の、固有角周波数 ωn と減衰係数 ζ の組み合わせとして正しいものはどれか。
  12. 減衰係数 ζ = 0.5 の二次遅れ系(零点のない標準形)にステップを入力した。オーバーシュート(最大の行き過ぎ量の、最終値に対する割合)に最も近いものはどれか。
  13. 伝達関数 G(s) = 25/(s² + 4s + 25) の系のステップ応答が、最終値の±2%以内に収まるまでの整定時間を、近似式 ts ≈ 4/(ζωn) で見積もった値として正しいものはどれか。
  14. 零点のない二次遅れ系で、極を s = −σ ± jωd とする。σ を変えずに ωd だけを大きくしたときの、ステップ応答の変化として正しいものはどれか。
  15. 単位フィードバックの系で、前向きの伝達関数が G(s) = 9/(1 + 2s) である。大きさ1のステップの目標値に対する定常偏差として正しいものはどれか。
  16. 閉ループが安定な単位フィードバックの系で、前向きの伝達関数 G(s) が積分 1/s を1つ含む(1形の系である)とき、定常偏差の説明として正しいものはどれか。
  17. 連続時間の線形な系が安定である(インパルス応答が時間とともに0に近づく)ための条件として正しいものはどれか。
  18. 閉ループの系の特性方程式が次のようになるとき、安定な系はどれか。
  19. 一巡伝達関数が K/(s(s + 1)(s + 2)) の単位フィードバックの系がある。閉ループの系が安定になる K の範囲として正しいものはどれか。
  20. ナイキストの安定判別法の説明として正しいものはどれか。
  21. 一次遅れ系 G(s) = 1/(1 + sT) のボード線図の特徴として正しいものはどれか。
  22. 積分要素 G(s) = 1/s のボード線図として正しいものはどれか。
  23. G(s) = 10/((1 + s/100)(1 + s/1000)) の、角周波数 ω = 10⁴ rad/s でのゲインを、ボード線図の折れ線近似で求めた値として正しいものはどれか。
  24. むだ時間 L の要素 e^(−Ls) の周波数特性と、それを一巡伝達関数に含む制御系への影響として正しいものはどれか。
  25. 一巡伝達関数のボード線図から読み取る、ゲイン余裕と位相余裕の説明として正しいものはどれか。
  26. 一巡伝達関数 L(s) = 2/(s(s + 1)(s + 2)) のゲイン余裕に最も近いものはどれか。
  27. 一巡伝達関数のゲインを上げたところ、位相余裕が60°から30°に減った。閉ループのステップ応答の変化として正しいものはどれか。
  28. 積分要素を含まない(0形の)制御対象を比例(P)制御する。比例ゲイン Kp を大きくしたときの一般的な変化として正しいものはどれか。
  29. PI制御で、積分(I)動作を加える主な目的と、その副作用の組み合わせとして正しいものはどれか。
  30. PID制御の微分(D)動作の性質と、実装での対策の組み合わせとして正しいものはどれか。
  31. PID制御で、目標値をステップ状に変えた瞬間に操作量が大きく跳ね上がる(微分キック)のを防ぐ方法として正しいものはどれか。
  32. ジーグラ・ニコルスの限界感度法では、比例制御だけでゲインを上げて持続振動が起きたときのゲイン Ku と振動の周期 Tu から、PID制御のパラメータを Kp = 0.6Ku、Ti = 0.5Tu、Td = 0.125Tu と決める。Ku = 8、Tu = 2 s のときの値として正しいものはどれか。
  33. 積分ワインドアップの説明として正しいものはどれか。
  34. マイコンで位置形のPI制御を実装し、PWMのデューティ比(0〜100%)を操作量とする。積分ワインドアップの対策として正しいものはどれか。
  35. サンプリング周期 Ts = 1 ms で、積分を長方形近似 Σe·Ts で計算するデジタルのPI制御がある。積分ゲイン Ki = 10 s⁻¹ で、偏差 e = 0.2 が50サンプルの間続いたとき、積分項の増加分として正しいものはどれか。
  36. サンプリング周期 Ts = 1 ms のデジタル制御では、D/A変換の0次ホールドが、およそ Ts/2 のむだ時間として働く。ゲイン交差周波数が100 Hzのとき、この遅れによる位相の遅れに最も近いものはどれか。
  37. 極が s = −100 s⁻¹ にある連続時間の一次遅れ系を、サンプリング周期 Ts = 1 ms で離散化した。z = e^(sTs) の関係から求まる離散時間の極として最も近いものはどれか。
  38. モータの制御で、内側に電流(トルク)のループ、外側に速度のループを置くカスケード制御にする。設計の考え方として正しいものはどれか。
  39. スイッチング周波数500 kHzの降圧DC-DCコンバータで、出力電圧のフィードバックループを設計する。ゲイン交差周波数の選び方の目安として正しいものはどれか。
  40. シーケンス制御の説明として正しいものはどれか。

この分野の比較

  • 開ループ制御と閉ループ制御の違い：仕組み・外乱への強さ・安定性・センサ・用途を比較開ループ制御と閉ループ制御(フィードバック制御)を、信号の流れ・センサの要否・外乱への対応・制御対象の変化への強さ・応答の速さ・安定性・定常偏差・構成とコスト・例の観点で表にして比較します。
  • P制御・PI制御・PID制御の違い：定常偏差・応答の速さ・オーバーシュート・調整を比較P制御(比例制御)・PI制御・PID制御を、操作量の式・定常偏差・応答の速さ・オーバーシュートと振動・シミュレーターでの例・雑音への強さ・操作量の飽和・調整するパラメータとジーグラ・ニコルスの目安・用途の観点で表にして…
