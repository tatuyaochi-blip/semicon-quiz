インターフェース・バス規格の要点

コンピュータの中では、CPUとメモリ、GPU、ストレージ、ネットワークなどの部品が、さまざまなインターフェースでつながっています。高速な接続では、多数の線を並べる並列伝送より、少ない線に非常に速い信号を流すシリアル伝送が主流になり、送受信回路のSerDesがそれを支えています。

PCI Expressのレーン数と1レーンあたりの速度から帯域を求める計算や、符号化による効率、USBの基本、チップ内でブロックをつなぐAXIなどのバス、メモリを共有するCXLを学びます。帯域と遅延が別の量であることを理解すると、何が性能を決めているかが見えてきます。

インターフェース・バス規格の問題一覧（50問）
  1. チップやボードの間の高速な接続が、多数の線を並べる並列伝送から、少ない線に速い信号を流すシリアル伝送に移ってきた主な理由はどれか。
  2. 高速なシリアル伝送で使われるSerDes(シリアライザ/デシリアライザ)の役割として正しいものはどれか。
  3. 高速なシリアル伝送で、2本の線に逆向きの信号を流す差動信号が使われる主な理由はどれか。
  4. 高速なシリアル伝送の受信側にあるクロック・データ・リカバリ(CDR)回路の役割として正しいものはどれか。
  5. シリアル伝送で8b/10b符号化(8ビットのデータを10ビットの符号にして送る方式)が使われてきた目的として正しいものはどれか。
  6. 8b/10b符号化を使う伝送路の信号の速度が5 Gb/sのとき、データとして送れる実効的な速度はいくらか。
  7. PCI Express 3.0以降で採用された128b/130b符号化の効率に最も近いものはどれか。
  8. PCI Expressの「レーン」の説明として正しいものはどれか。
  9. PCI Express 3.0(1レーンあたり8 GT/s、128b/130b符号化)のx16接続の、片方向の実効的な帯域に最も近いものはどれか。
  10. PCI Expressの世代が1つ進むごとの、1レーンあたりの信号の速度の変化として、第3世代から第6世代について正しいものはどれか。
  11. PCI Express 6.0で採用されたPAM4(4値パルス振幅変調)の特徴として正しいものはどれか。
  12. PAM4を使うと、NRZに比べて誤り訂正(FEC)がより重要になる理由として正しいものはどれか。
  13. x4のPCI ExpressのSSDを、マザーボードのx16の長さのスロットに差し込むとどうなるか(スロットがx4以上の配線を持つとする)。
  14. PCI Expressの構成について正しいものはどれか。
  15. PCI Expressの通信のしくみとして正しいものはどれか。
  16. PCI Expressのデータリンク層が、伝送中のビットの誤りに対して行うこととして正しいものはどれか。
  17. PCI Expressの機器のレジスタやメモリを、CPUから読み書きできるようにするしくみとして正しいものはどれか。
  18. PCI Expressで使われるMSI(メッセージシグナル割り込み)の特徴として正しいものはどれか。
  19. インターフェースの性能を表す「帯域」と「遅延(レイテンシ)」の違いとして正しいものはどれか。
  20. 帯域10 GB/s、遅延1 µsの接続で、64バイトのデータを1回送るのにかかる時間に最も近いものはどれか(時間=遅延+データ量÷帯域とする)。
  21. 機器との間で小さなデータを1つずつ何千回もやり取りするプログラムを速くする方法として、最も効果的なものはどれか。
  22. USBの通信のしくみについて正しいものはどれか(USB4を除く従来のUSBについて)。
  23. USB Type-Cについて正しいものはどれか。
  24. USB Power Delivery(USB PD)の説明として正しいものはどれか。
  25. USBの転送の種類のうち、アイソクロナス転送の特徴として正しいものはどれか。
  26. USBやPCI Expressの一部で使える「ホットプラグ」の説明として正しいものはどれか。
  27. SoCの内部で、CPUやメモリコントローラ、周辺回路などのブロックをつなぐのに広く使われている、ArmのAMBA規格のバスはどれか。
  28. AXIバスの特徴として正しいものはどれか。
  29. AXIの各チャネルで使われるVALIDとREADYによる受け渡し(ハンドシェイク)で、データが受け渡されるのはどのときか。
  30. AXIのバースト転送の利点として正しいものはどれか。
  31. AXIで、前の読み出しの応答を待たずに次の読み出しの要求を出せる(複数の要求を同時に未完了のまま持てる)ことの利点として正しいものはどれか。
  32. AXIの種類のうち、AXI4-Liteが主に使われる用途はどれか。
  33. AXI4-Streamの特徴として正しいものはどれか。
  34. 大きなSoCで、1本の共有のバスの代わりにネットワークオンチップ(NoC)が使われるようになった理由として正しいものはどれか。
  35. CXL(Compute Express Link)の説明として正しいものはどれか。
  36. CXLを使ったメモリの拡張(CXLメモリ)の利点として正しいものはどれか。
  37. CXLを構成する3つのプロトコルの組み合わせとして正しいものはどれか。
  38. 高速なシリアル伝送の受信回路で使われるイコライザ(CTLEやDFEなど)の役割として正しいものはどれか。
  39. 高速なシリアル信号の品質を見るアイパターン(アイダイアグラム)について正しいものはどれか。
  40. シリアル伝送の速度を上げるほど、同じ長さの基板の配線で信号を送るのが難しくなり、途中にリタイマなどを入れることがある。その主な理由はどれか。
  41. 高速なシリアル伝送の要求として「ビット誤り率(BER)が10のマイナス12乗以下」とされているときの意味として正しいものはどれか。
  42. 高速な信号の配線で、配線の特性インピーダンスを送受信の回路と合わせる(整合をとる)目的として正しいものはどれか。
  43. 100ギガビットのイーサネットのような高速な接続が、例えば25 Gb/sのレーンを4本束ねて作られることがある。この考え方として正しいものはどれか。
  44. PCI Expressなどで使われるスペクトラム拡散クロック(SSC)の目的として正しいものはどれか。
  45. PCI Expressの1レーンが「全二重」であることの意味として正しいものはどれか。
  46. PCI Expressで使われるクレジット方式のフロー制御の説明として正しいものはどれか。
  47. AI向けのGPUを多数つなぐシステムで、PCI Expressとは別の、GPUどうしを結ぶ専用の高速な接続(NVIDIAのNVLinkなど)が使われる主な理由はどれか。
  48. PCI Expressで、64バイトの小さなデータを書き込むパケットを多数送ると、実効的な帯域が理論値よりかなり小さくなる。その主な理由はどれか。
  49. ネットワークカードやNVMeのSSDなどで広く使われる、メモリ上の記述子(ディスクリプタ)の輪(リング)を使ったDMAのしくみについて正しいものはどれか。
  50. PCI Expressのリンクの省電力の機能(ASPMによるL0sやL1の状態)について正しいものはどれか。

この分野の比較

  • NVMeとSATAのSSDの違い：速度・インターフェース・選び方NVMeとSATAのSSDを、インターフェース・速度・遅延・コマンドキュー・形状・消費電力・互換性・価格・向いている人の観点で表にして比較します。
  • DMAとプログラムI/Oの違い：データ転送の方法を比較DMAとプログラムI/O(PIO)を、データを動かす主体・CPUの負荷・スループット・準備のコスト・複雑さ・バスの使用・用途の観点で表にして比較します。
  • PCIe 3.0・4.0・5.0・6.0の違い：速度と世代ごとの特徴を比較PCIe 3.0、4.0、5.0、6.0を、転送レート・レーンあたりと×4、×16のリンクの帯域・エンコード・信号方式・使われる機器の観点で表にして比較します。
  • NRZとPAM4の違い：ビット数・ボーレート・アイの開き・FEC・規格の世代を比較NRZとPAM4を、1シンボルのビット数・同じビットレートでのボーレート・アイの開きとSNR・FECの必要性・回路・使われる規格の世代の観点で表にして比較します。
  • シングルエンドと差動信号の違い：配線・ノイズ耐性・放射・速度・規格を比較シングルエンド信号と差動信号を、配線の数・基準の電圧・ノイズへの強さ・放射ノイズ・振幅と速度・配線の設計・代表的な規格(LVDS、USB、PCIeなど)の観点で表にして比較します。
