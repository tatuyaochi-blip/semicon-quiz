GPUプログラミングの要点

GPUは、数千から数万のスレッドを同時に動かして、同じ処理を大量のデータにまとめて行うのが得意なプロセッサです。プログラムはグリッド・ブロック・スレッドの階層で並列性を表し、ハードウェアは32本程度のスレッドをワープという単位で同じ命令で動かします。

性能を引き出すには、隣のスレッドが隣のアドレスを読むメモリ合体アクセス、ブロック内で共有するオンチップの共有メモリ、ワープ内の分岐を避ける工夫、メモリの待ち時間を隠すための占有率の確保などが重要です。製品の世代に左右されない原理を中心に学びます。
