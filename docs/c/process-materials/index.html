プロセス材料(ガス・薬液)の要点

半導体の製造には、高純度のシリコンをはじめ、成膜やエッチングに使う特殊材料ガス、洗浄に使う薬液や超純水、スパッタリングターゲット、フォトレジスト、CMPスラリーなど、多くの材料が使われます。

わずかな不純物が不良の原因になるため、材料には極めて高い純度が求められます。また、自然発火性や毒性をもつガスも多く、安全な取り扱いが欠かせません。
