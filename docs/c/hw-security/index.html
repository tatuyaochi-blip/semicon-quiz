ハードウェアセキュリティの要点

ソフトウェアに誤りがなくても、ハードウェアの性質から情報が漏れることがあります。性能を上げるための投機実行やキャッシュが、本来見えないはずのデータの痕跡を残すことを利用したのが、SpectreやMeltdownと呼ばれる脆弱性です。消費電力や処理時間のわずかな違いから暗号の鍵を推定するサイドチャネル攻撃もあります。

守る側の技術として、正しいソフトウェアだけを起動するセキュアブート、OSからも隔離された安全な実行環境(TEE)、チップごとの製造ばらつきを指紋のように使うPUF、設計や製造の途中で仕込まれる不正な回路(ハードウェアトロイ)への対策などがあります。攻撃の手順ではなく、原理と対策を理解することを目的とします。

ハードウェアセキュリティの問題一覧（50問）
  1. ハードウェアセキュリティで扱う問題の説明として最も適切なものはどれか。
  2. サイドチャネル攻撃の説明として正しいものはどれか。
  3. タイミング攻撃が成り立つ原理と、代表的な対策の組み合わせとして正しいものはどれか。
  4. 上のパスワードの比較の関数に潜む問題と、対策の組み合わせとして正しいものはどれか。
  5. キャッシュを使ったサイドチャネル攻撃が成り立つ主な理由はどれか。
  6. Spectreと呼ばれる投機的実行の脆弱性の原理として正しいものはどれか。
  7. 投機的に実行された命令の結果が取り消されても、Spectreのような攻撃で情報が漏れる理由として正しいものはどれか。
  8. 一部のCPUで問題になったMeltdownと呼ばれる脆弱性の原理として正しいものはどれか。
  9. Meltdownへのソフトウェアの対策として導入されたKPTI(カーネルページテーブル分離)の考え方として正しいものはどれか。
  10. Spectreのような投機的実行の脆弱性への対策として使われているものに当てはまらないものはどれか。
  11. 投機的実行の脆弱性への対策について、一般的に正しいものはどれか。
  12. 暗号の処理を行うチップの消費電力の波形を使う電力解析のうち、差分電力解析(DPA)の特徴として正しいものはどれか。
  13. 電力解析への対策として使われるマスキングの考え方として正しいものはどれか。
  14. 電磁波を使ったサイドチャネル解析の特徴として正しいものはどれか。
  15. 故障注入攻撃の説明として正しいものはどれか。
  16. 故障注入攻撃への対策として当てはまらないものはどれか。
  17. DRAMのロウハンマーへの対策として当てはまるものはどれか。
  18. コールドブート攻撃が成り立つ理由と、代表的な対策の組み合わせとして正しいものはどれか。
  19. セキュアブートの説明として正しいものはどれか。
  20. セキュアブートの「ルートオブトラスト(信頼の起点)」として、チップの中に置かれるものとして最も適切なものはどれか。
  21. セキュアブートで、ソフトウェアの署名の確認に公開鍵暗号を使う利点として正しいものはどれか。
  22. セキュアブートを備えた機器で、ロールバック防止(アンチロールバック)の仕組みが必要になる理由として正しいものはどれか。
  23. パソコンなどに搭載されるTPM(トラステッドプラットフォームモジュール)の主な役割として正しいものはどれか。
  24. セキュアブートと測定ブート(メジャードブート)の違いとして正しいものはどれか。
  25. リモートアテステーション(遠隔証明)の説明として正しいものはどれか。
  26. TEE(信頼できる実行環境)の説明として正しいものはどれか。
  27. ArmのTrustZoneの基本的なしくみとして正しいものはどれか。
  28. IntelのSGXのような「エンクレーブ」型のTEEの特徴として正しいものはどれか。
  29. クラウドで使われる「機密コンピューティング」で、仮想マシンのメモリをCPUが暗号化する機能(AMD SEVやIntel TDXなど)の目的として正しいものはどれか。
  30. PUF(物理的複製困難関数)の説明として正しいものはどれか。
  31. 鍵の保管にPUFを使う利点として正しいものはどれか。
  32. SRAM PUFが利用している性質として正しいものはどれか。
  33. PUFから鍵を作るときに、誤り訂正の仕組み(ヘルパーデータなど)を組み合わせる理由として正しいものはどれか。
  34. チップに内蔵される真性乱数生成器(TRNG)の説明として正しいものはどれか。
  35. 暗号の鍵を作るときに、予測されやすい質の悪い乱数を使うと起こりうることとして正しいものはどれか。
  36. ハードウェアトロイ(ハードウェアトロイの木馬)の説明として正しいものはどれか。
  37. ハードウェアトロイが通常のテストで見つかりにくい主な理由はどれか。
  38. ハードウェアトロイへの対策として当てはまらないものはどれか。
  39. 半導体の流通で問題になる偽造チップ(リマーク品など)の危険として正しいものはどれか。
  40. 製品として出荷する機器で、JTAGなどのデバッグ用のポートを無効にしたり、認証が必要なようにしたりする理由として正しいものはどれか。
  41. ICカードなどのセキュリティ用のチップに求められる耐タンパ性の説明として正しいものはどれか。
  42. チップの中に鍵を書き込んで保存する方法として、一般に使われているものはどれか。
  43. CPUにAESの暗号の専用の命令(AES-NIなど)を持たせる利点として、速さのほかに挙げられるものはどれか。
  44. 暗号の処理を「定数時間」で実装するときに守るべきこととして正しいものはどれか。
  45. キャッシュのサイドチャネルへの対策として、共有のキャッシュを分割(パーティショニング)する考え方として正しいものはどれか。
  46. 機密の処理を行うシステムで、CPUの同時マルチスレッディング(SMT)を無効にすることがある理由として正しいものはどれか。
  47. パソコンにつないだ外部の機器が、DMAを使ってメインメモリの内容を勝手に読み書きする攻撃への対策として正しいものはどれか。
  48. ハードウェアとソフトウェアのセキュリティで重視される「多層防御」の考え方として正しいものはどれか。
  49. 多数の機器を製造するとき、すべての機器に同じ鍵を入れずに、機器ごとに違う鍵を持たせる理由として正しいものはどれか。
  50. CPUのハードウェアの脆弱性が見つかったとき、出荷済みのCPUで行われる対策の1つとして正しいものはどれか。
