パワー半導体の要点

パワー半導体は、電力の変換や制御を担うデバイスで、インバータや電源、電気自動車などに使われます。高い耐圧、低いオン抵抗、高速なスイッチングが求められます。

シリコンのMOSFETやIGBTに加え、バンドギャップが大きく絶縁破壊電界の高いSiCやGaNを使ったデバイスが普及しつつあります。材料の物性とデバイス構造の関係を理解することが大切です。

パワー半導体の問題一覧（50問）

  1. SiC(炭化ケイ素)がSiに比べて高耐圧パワーデバイスに有利な主な理由はどれか。
  2. IGBTの説明として正しいものはどれか。
  3. GaN HEMTで電流が流れるチャネルとして正しいものはどれか。
  4. シリコンのパワーMOSFETにおける耐圧とオン抵抗の関係として正しいものはどれか。
  5. パワーエレクトロニクスにおけるインバータの主な役割はどれか。
  6. パワーデバイスで、スイッチング周波数を高くすると主に増える損失はどれか。
  7. スーパージャンクション(SJ)MOSFETの特徴として正しいものはどれか。
  8. 熱抵抗が2 ℃/Wのパワーデバイスで10 Wの損失が生じたとき、温度上昇はいくらか。
  9. パワーMOSFETの内部に構造上できる寄生ダイオードを何と呼ぶか。
  10. SiCやGaNのように、シリコンよりバンドギャップが大きい半導体の総称はどれか。
  11. パワー半導体のゲートドライバの主な役割として正しいものはどれか。
  12. パワーデバイスで、ゲート電圧が0 Vのときに電流が流れない「ノーマリーオフ」特性が求められる主な理由はどれか。
  13. SiCショットキーバリアダイオードが、インバータなどの還流ダイオードとして使われる主な利点はどれか。
  14. サイリスタの特徴として正しいものはどれか。
  15. 大電力用のパワーモジュールで、パワーチップの下に絶縁基板(セラミック基板など)を使う主な目的はどれか。
  16. SiCやGaNのパワーデバイスで高速にスイッチングするときに、特に対策が重要になる問題はどれか。
  17. 寄生インダクタンス10 nHの配線で、電流が10 nsの間に10 A変化したとき、配線に生じる電圧はおよそいくらか。
  18. 電源回路に使われる力率改善(PFC)回路の目的として正しいものはどれか。
  19. 電気自動車のインバータにSiCパワーデバイスを使う主な利点はどれか。
  20. 理想的な降圧チョッパ(バックコンバータ)で、入力電圧12 V、スイッチのデューティ比0.25のときの出力電圧はいくらか。
  21. 入力より高い直流電圧を出力するDC-DCコンバータはどれか。
  22. IGBTのターンオフ時に、蓄積された少数キャリアのために電流がすぐに0にならず、尾を引くように流れる現象を何と呼ぶか。
  23. SiC MOSFETの課題の一つとして知られているものはどれか。
  24. 高温で動作するSiCパワーモジュールで、チップの接合材として、はんだに代わって使われることがある材料はどれか。
  25. 電力変換器のスイッチング周波数を高くすることの主な利点はどれか。
  26. パワーデバイスのゲート駆動回路で、ゲート抵抗の値を大きくしたときの影響として正しいものはどれか。
  27. インバータで、上下のスイッチが同時にオンするなどの短絡が起きたとき、パワーデバイスが破壊されずに耐えられる時間を表す指標はどれか。
  28. インバータの上下のスイッチを切り替えるときに、両方をオフにしておく短い時間(デッドタイム)を設ける目的はどれか。
  29. SiC MOSFETのボディダイオードに電流を流し続けると、特性が劣化することがある原因として知られているものはどれか。
  30. GaNパワーデバイスの採用が進んでいる身近な製品の例として正しいものはどれか。
  31. パワー半導体の主な役割として正しいものはどれか。
  32. オン抵抗10 mΩのパワーMOSFETに10 Aの電流が流れているときの導通損失はいくらか。
  33. パワーデバイスにヒートシンク(放熱器)を取り付ける主な目的はどれか。
  34. 三相モーターを駆動する一般的な三相インバータで使われるスイッチング素子の数はいくつか。
  35. 電源回路などで、電流を測るために電流の経路に直列に入れる小さな抵抗を何と呼ぶか。
  36. トランジスタを線形に動作させるリニア電源と比べて、スイッチング電源の効率が高い主な理由はどれか。
  37. パワーMOSFETで、ゲートをシリコンに掘った溝の中に埋め込むトレンチゲート構造の主な利点はどれか。
  38. シリコンのMOSFETとIGBTの一般的な使い分けとして正しいものはどれか。
  39. パワーデバイスのスイッチング回路に入れるスナバ回路の主な目的はどれか。
  40. インバータの一方のスイッチがオンになるとき、反対側のアームのダイオードの逆回復によって増える損失として正しいものはどれか。
  41. 電力変換器のソフトスイッチングのうち、ZVS(ゼロ電圧スイッチング)の説明として正しいものはどれか。
  42. パワーMOSFETのゲートを一定電流で充電したとき、ゲート電圧がしばらく平らになる「ミラープラトー」が生じる理由として正しいものはどれか。
  43. SiC MOSFETやIGBTの駆動で、オフ時にゲートに負の電圧(例えば −3〜−5 V)を加えることがある主な理由はどれか。
  44. 一般的なシリコンのパワーデバイスの最大接合温度(Tj max)の定格として多いものはどれか。
  45. パワーデバイスを選ぶとき、定格電圧に余裕をもたせて実際の使用電圧より高い耐圧の素子を使う(ディレーティングする)主な理由はどれか。
  46. パワーMOSFETの「アバランシェ耐量」が重要になるのはどのような場合か。
  47. パワーモジュールに温度の上昇と下降を繰り返し与える「パワーサイクル試験」で見られる代表的な故障はどれか。
  48. 高速スイッチング用のパワーデバイスのパッケージで、ゲート駆動の戻り線専用のソース端子(ケルビンソース)を設ける目的はどれか。
  49. ハーフブリッジの上側(ハイサイド)のnチャネルMOSFETを駆動するために、ダイオードとコンデンサで電源電圧より高いゲート電圧をつくる回路はどれか。
  50. ユニポーラ型のパワーデバイス材料の性能を比べる「バリガ性能指数」で、特に大きく効く材料の物性値はどれか。
