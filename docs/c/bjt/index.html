バイポーラトランジスタの要点

バイポーラトランジスタは、エミッタ・ベース・コレクタの3層構造をもち、電子と正孔の両方が動作に関わる素子です。ベース電流でコレクタ電流を制御し、電流を増幅します。

増幅動作(能動領域)では、ベース-エミッタ間を順方向、ベース-コレクタ間を逆方向にバイアスします。電流増幅率hFE、ベース幅と再結合の関係、飽和・遮断領域の意味を押さえておきましょう。

バイポーラトランジスタの問題一覧（50問）

  1. NPNトランジスタを増幅に使う(能動領域で動作させる)ときのバイアス条件として正しいものはどれか。
  2. バイポーラトランジスタの直流電流増幅率hFEを表す式はどれか。(IC:コレクタ電流、IB:ベース電流、IE:エミッタ電流)
  3. バイポーラトランジスタのベース幅を薄くする主な理由として最も適切なものはどれか。
  4. バイポーラトランジスタをスイッチとして使うとき、オンの状態に対応する動作領域はどれか。
  5. エミッタ接地増幅回路の出力電圧の位相は、入力電圧に対してどうなるか。
  6. NPNトランジスタで、エミッタの不純物濃度をベースより高くする主な理由はどれか。
  7. ベース接地電流増幅率α = 0.99のバイポーラトランジスタのエミッタ接地電流増幅率βはおよそいくらか。
  8. バイポーラトランジスタのアーリー効果の説明として正しいものはどれか。
  9. 2つのトランジスタを組み合わせたダーリントン接続の特徴として正しいものはどれか。
  10. PNPトランジスタで、エミッタからベースへ注入されて主に電流を運ぶキャリアはどれか。
  11. コレクタ接地増幅回路(エミッタフォロワ)の特徴として正しいものはどれか。
  12. ベース接地増幅回路の特徴として正しいものはどれか。
  13. バイポーラトランジスタのトランジション周波数fTの意味として正しいものはどれか。
  14. バイポーラトランジスタの熱暴走の説明として正しいものはどれか。
  15. SiGe HBT(ヘテロ接合バイポーラトランジスタ)の特徴として正しいものはどれか。
  16. シリコンのバイポーラトランジスタが飽和領域にあるときの、コレクタ-エミッタ間電圧の目安として正しいものはどれか。
  17. 特性のそろった2つのトランジスタを使い、一方に流した電流と同じ大きさの電流をもう一方に流す回路はどれか。
  18. 2つのトランジスタのエミッタを共通の電流源につないだ差動対の働きとして正しいものはどれか。
  19. コレクタ電流1 mAで動作しているバイポーラトランジスタの相互コンダクタンスgmはおよそいくらか。(室温、熱電圧VT ≈ 26 mVとする)
  20. LEDとフォトトランジスタを1つのパッケージに組み合わせたフォトカプラの主な用途はどれか。
  21. トランジスタ増幅回路で、エミッタ抵抗を入れた電流帰還バイアス回路を使う主な理由はどれか。
  22. 増幅回路で、入力信号がないときのトランジスタの直流の電圧・電流の状態を何と呼ぶか。
  23. NPNとPNPのトランジスタで正と負の半周期を分担するB級プッシュプル増幅回路で生じやすいひずみはどれか。
  24. 増幅回路の段と段の間に入れる結合コンデンサの役割として正しいものはどれか。
  25. シリコンのバイポーラトランジスタの電流増幅率hFEは、一般に温度が上がるとどうなるか。
  26. エミッタ接地増幅回路の小信号の入力抵抗(hie)を大きくする条件として正しいものはどれか。
  27. 増幅回路の負荷抵抗の代わりに、電流源として働くトランジスタを使う能動負荷の利点として正しいものはどれか。
  28. スイッチ用のトランジスタを深い飽和状態からオフにするとき、オフになるまでに時間がかかる主な理由はどれか。
  29. バイポーラトランジスタで構成された代表的な論理ICの系列はどれか。
  30. バイポーラトランジスタとCMOSを同じチップに集積する技術とその狙いの組み合わせとして正しいものはどれか。
  31. バイポーラトランジスタの3つの端子の組み合わせとして正しいものはどれか。
  32. NPNトランジスタの回路記号で、エミッタに付いている矢印の向きとして正しいものはどれか。
  33. バイポーラトランジスタのエミッタ電流IE、ベース電流IB、コレクタ電流ICの関係として正しいものはどれか。
  34. 直流電流増幅率hFE = 100のトランジスタにベース電流10 μAを流したとき、能動領域でのコレクタ電流はおよそいくらか。
  35. バイポーラトランジスタが遮断領域(オフ)にあるときの接合の状態として正しいものはどれか。
  36. 能動領域で動作しているシリコンのバイポーラトランジスタのベース-エミッタ間電圧VBEの目安として正しいものはどれか。
  37. コレクタ-エミッタ間電圧5 V、コレクタ電流100 mAで動作しているトランジスタのコレクタ損失はいくらか。
  38. バイポーラトランジスタとMOSFETの制御の違いとして正しいものはどれか。
  39. エミッタ接地増幅回路で、相互コンダクタンスgm = 40 mS、コレクタ抵抗RC = 5 kΩのとき、電圧利得の大きさはおよそいくらか。(負荷は無視する)
  40. バイポーラトランジスタが飽和領域にあるときの接合の状態として正しいものはどれか。
  41. エミッタ接地のトランジスタの出力特性(IC-VCE特性)を、ベース電流IBをパラメータとして描いたときの能動領域の特徴として正しいものはどれか。
  42. トランジスタ増幅回路の出力特性の図に引く「負荷線」が表すものとして正しいものはどれか。
  43. 理想的なB級プッシュプル増幅回路の最大の電力効率に最も近い値はどれか。
  44. トランジスタをスイッチとして使う回路で、ベースに直列に抵抗を入れる主な目的はどれか。
  45. 直流電流増幅率hFEと、小信号の電流増幅率hfeの違いとして正しいものはどれか。
  46. バイポーラトランジスタの大信号動作を、2つのダイオードと電流源で表したモデルはどれか。
  47. バイポーラトランジスタの電流増幅率hFEのコレクタ電流依存性として正しいものはどれか。
  48. ベースを開放したときのコレクタ-エミッタ間の降伏電圧BVCEOと、エミッタを開放したときのコレクタ-ベース間の降伏電圧BVCBOの関係として正しいものはどれか。
  49. エミッタ接地増幅回路の高周波特性を悪くするミラー効果の説明として正しいものはどれか。
  50. ベース-コレクタ間にショットキーバリアダイオードを並列に入れたトランジスタ(ショットキークランプ)の狙いとして正しいものはどれか。
