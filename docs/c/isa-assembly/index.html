命令セット・アセンブリの要点

命令セットアーキテクチャ(ISA)は、ソフトウェアとハードウェアの間の約束ごとです。どんな命令があり、命令がどのようなビットの並びで表され、レジスタやメモリをどう指定するかが決められています。同じISAを守っていれば、内部の作りが違うCPUでも同じプログラムが動きます。

アセンブリ言語は、機械語の命令を人が読める形で書いたものです。RISC-Vの基本命令、レジスタの使い分け、関数を呼ぶときの引数や戻り値の受け渡し(呼び出し規約)、スタックフレームの作り方を知ると、コンパイラが出力するコードや、プログラムがCPUの上でどう動くかが見えてきます。
