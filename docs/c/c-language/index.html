C言語の基礎の要点

C言語は、OSやデバイスドライバ、マイコンのファームウェアなど、ハードウェアに近いソフトウェアで今も広く使われています。メモリの番地を直接扱えて速いコードを書ける一方で、int の大きさが処理系によって違ったり、計算の途中で型が変わったり、配列の範囲を超えても止まらなかったりと、知らないと誤りに気づきにくい決まりが多くあります。

ここでは、短いコードを実際に実行したときの出力をたどる問題を中心に、整数型の大きさと stdint.h の固定幅の整数型、整数の除算、整数拡張と符号付き・符号なしの比較、演算子の優先順位、ビット演算、短絡評価、switch 文のフォールスルー、値渡しとポインタ渡し、static 変数と寿命、ポインタの演算と配列、2次元配列の並び、文字列と strlen・sizeof、const の付け方、関数ポインタを学びます。続いて、malloc と free、メモリリーク、ダングリングポインタ、バッファオーバーフロー、NULL ポインタ、構造体のパディング、共用体とエンディアン、ビットフィールド、マクロとインクルードガード、条件付きコンパイル、組込みでの volatile、未定義動作とコンパイラの最適化を扱います。プログラムの出力は、x86-64 の Linux の gcc で実際にコンパイルして確かめています。擬似言語のトレースは「プログラミングの基礎(擬似言語のトレース)」、volatile を使った割り込みやレジスタの操作は「組込み・ファームウェア」、コンパイラの最適化の詳細は「コンパイラ」、メモリの配置やリンクは「リンカ・ローダと実行形式」の分野で扱います。
