LSI設計フロー・EDAの要点

LSIの設計は、仕様を決め、ハードウェア記述言語でRTL(レジスタ転送レベル)の回路を記述し、論理合成でゲートの接続(ネットリスト)に変換し、配置配線でレイアウトをつくる流れで進みます。

各段階では、EDAツールによるシミュレーション、静的タイミング解析(STA)、検証が欠かせません。設計規模が大きくなるほど、検証にかかる手間が大きくなります。

LSI設計フロー・EDAの問題一覧（30問）

  1. 一般的なデジタルLSIの設計フローの順序として正しいものはどれか。
  2. 論理合成の説明として正しいものはどれか。
  3. 静的タイミング解析(STA)の説明として正しいものはどれか。
  4. RTL設計で主に使われるハードウェア記述言語はどれか。
  5. レイアウト検証におけるDRC(デザインルールチェック)の説明として正しいものはどれか。
  6. 論理合成の前後で回路の論理が変わっていないことを、シミュレーションを使わずに数学的に確認する手法はどれか。
  7. スタンダードセル方式の設計の説明として正しいものはどれか。
  8. FPGAの特徴として正しいものはどれか。
  9. 配置配線工程でのクロックツリー合成(CTS)の主な目的はどれか。
  10. LSI設計で使われる「IP(IPコア)」の意味として正しいものはどれか。
  11. 静的タイミング解析で、信号がクロックのエッジ直後に早く変化しすぎて、フリップフロップが前のデータを正しく保持できなくなるタイミング違反はどれか。
  12. ファウンドリが設計者に提供する、デザインルール、デバイスモデル、セルライブラリなどの設計用データ一式を何と呼ぶか。
  13. トランジスタレベルの回路の電圧や電流を、デバイスモデルを使って詳しく計算する回路シミュレータの代表はどれか。
  14. C言語やC++などで書いたアルゴリズムの記述から、RTLを自動で生成する技術を何と呼ぶか。
  15. 使っていない回路ブロックへのクロックの供給を止めて、無駄な消費電力を減らす低消費電力設計の手法はどれか。
  16. 静的タイミング解析でセットアップ違反が見つかったときの対策として適切なものはどれか。
  17. 静的タイミング解析を、プロセスのばらつき・電源電圧・温度の組み合わせを変えた複数の条件で行う理由として正しいものはどれか。
  18. 配置配線後のレイアウトから、配線の抵抗や容量を取り出す工程を何と呼ぶか。
  19. 大規模なSoCの検証で、設計した回路を専用のハードウェアやFPGAの上で動かし、ソフトウェアと組み合わせて高速に検証する手法はどれか。
  20. 設計と検証を終え、マスク製作のためのデータを製造側に引き渡すことを何と呼ぶか。
  21. テープアウト前の最終確認(サインオフ)で、タイミングの検証と並んで行う電源配線の解析はどれか。
  22. 製造上のばらつきや欠陥の影響を受けにくいように、レイアウトなどを工夫する設計の考え方はどれか。
  23. アナログ回路のレイアウトで、ペアにするトランジスタを、互いの重心が一致するように分割して配置する手法はどれか。
  24. レイアウトの空いた場所に、回路として機能しないダミーパターンを配置する主な目的はどれか。
  25. ダブルパターニングを前提としたレイアウトで、設計ツールが行うパターンの割り振りとして正しいものはどれか。
  26. ネットリストの説明として正しいものはどれか。
  27. 論理合成や静的タイミング解析で、クロック周期や入出力の遅延などのタイミングの条件を記述したものを何と呼ぶか。
  28. マスク製作のために製造側に渡すレイアウトデータの代表的な形式はどれか。
  29. 配置配線の最初に、大きな回路ブロックや入出力端子、電源配線などのおおまかな配置を決める工程はどれか。
  30. RTLの検証で、検証がどれだけ十分に行われたかを評価するために使われる指標はどれか。
