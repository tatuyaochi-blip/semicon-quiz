次世代メモリ

MRAM・PCM(相変化メモリ)・ReRAM・FeRAMなど次世代メモリの記憶原理を3択問題で学べます。

—あなたの正答率
0 / 50解いた問題
10問練習するこの分野からランダムに10問・約5分 この分野を解くこの分野の問題をすべて、ランダムな順で出題します 苦手問題直近で間違えた問題だけを解き直します

次世代メモリの要点

DRAMやフラッシュメモリの限界を補うため、さまざまな新しい原理のメモリが開発されています。多くは電荷ではなく、抵抗値の違いや分極の向きで情報を記憶する不揮発性メモリです。

MRAMは磁気トンネル接合の磁化の向き、PCMは結晶とアモルファスの抵抗差、ReRAMは酸化物中の導電パス、FeRAMは強誘電体の分極を利用します。それぞれの原理と特徴を区別して覚えましょう。

次世代メモリの問題一覧（50問）
  1. MRAMの記憶原理として正しいものはどれか。
  2. 相変化メモリ(PCM)の記憶原理として正しいものはどれか。
  3. FeRAM(強誘電体メモリ)が情報の記憶に利用している性質はどれか。
  4. ReRAM(抵抗変化メモリ)の記憶原理として正しいものはどれか。
  5. STT-MRAMで情報を書き込む方法として正しいものはどれか。
  6. 「ストレージクラスメモリ」の位置づけとして正しいものはどれか。
  7. フラッシュメモリと比べたときのMRAMの一般的な利点として正しいものはどれか。
  8. 近年、FeRAMや強誘電体トランジスタ(FeFET)の材料として注目されている、CMOSプロセスと相性のよい強誘電体材料はどれか。
  9. 相変化メモリ(PCM)で、セルを高抵抗のアモルファス状態にする(リセットする)方法として正しいものはどれか。
  10. 抵抗変化型メモリなどを使ったインメモリコンピューティングで期待される主な用途はどれか。
  11. キャパシタ型FeRAMの読み出しの特徴として正しいものはどれか。
  12. MRAMの磁気トンネル接合(MTJ)で、トンネル障壁層として広く使われ、大きなトンネル磁気抵抗比が得られる材料はどれか。
  13. ReRAMで、最初に比較的高い電圧を加えて導電性フィラメントをつくる初期化工程を何と呼ぶか。
  14. SOT-MRAMの特徴として正しいものはどれか。
  15. MRAMが、マイコンなどの組み込み不揮発メモリとして注目されている理由の一つとして正しいものはどれか。
  16. MRAMで、記憶素子(MTJ)を小さくしすぎると問題になりやすいことはどれか。
  17. 近年のSTT-MRAMで、磁化の向きが膜面に垂直なMTJ(垂直磁化MTJ)が主流になった理由として正しいものはどれか。
  18. 抵抗変化素子を縦横の配線の交点に配置するクロスポイント型メモリで、選択していないセルに電流が回り込むのを防ぐために、記憶素子と直列に入れる素子はどれか。
  19. ゲート絶縁膜に強誘電体を使ったFeFETの特徴として正しいものはどれか。
  20. 相変化メモリ(PCM)で、アモルファス状態の抵抗値が時間とともに少しずつ増加していく現象を何と呼ぶか。
  21. MRAMのデータの読み出し方法として正しいものはどれか。
  22. 相変化メモリの記録材料として代表的なGSTとはどのような材料か。
  23. ReRAMの抵抗変化層として研究・実用化されている材料の例として正しいものはどれか。
  24. 不揮発性メモリをキャッシュやレジスタなどに使うことで期待される、システムの省電力化の仕組みとして正しいものはどれか。
  25. FeRAMが使われてきた代表的な用途として正しいものはどれか。
  26. MRAMの記憶素子(MTJ)は、ロジックLSIのどの工程でつくり込むのが一般的か。
  27. 相変化メモリを微細化するときに問題になる、書き込み時の熱が隣のセルに伝わって状態を変えてしまう現象はどれか。
  28. STT-MRAMの書き込みが確率的な性質をもつことによる設計上の課題として正しいものはどれか。
  29. ReRAMのセルの抵抗値のばらつきが大きいことによる課題として正しいものはどれか。
  30. 一般に、書き換え可能回数が最も少ないメモリはどれか。
  31. 次のメモリのうち、電源を切ってもデータが残る不揮発性メモリはどれか。
  32. MRAMの「M」が表すものとして正しいものはどれか。
  33. 多くの次世代メモリの研究開発で目標とされてきた「ユニバーサルメモリ」の考え方として正しいものはどれか。
  34. FeRAMの「Fe」が表すものとして正しいものはどれか。
  35. MRAMで1ビットの情報を記憶する素子として使われる、2つの磁性層で薄い絶縁層を挟んだ構造を何と呼ぶか。
  36. MTJのトンネル磁気抵抗比(TMR比)の説明として正しいものはどれか。
  37. MTJで、2つの磁性層の磁化の向きが平行のときと反平行のときの抵抗の関係として正しいものはどれか。
  38. MTJを構成する2つの磁性層の役割として正しいものはどれか。
  39. 相変化メモリ(PCM)で、セルを低抵抗の結晶状態にする(セットする)ときの加熱のしかたとして正しいものはどれか。
  40. 強誘電体のヒステリシス曲線(分極-電界特性)で、電界をゼロに戻しても残る分極を何と呼ぶか。
  41. MRAMを使うときに注意が必要な外部環境として正しいものはどれか。
  42. MRAMやFeRAMが宇宙機器など放射線の多い環境で使われることがある理由として正しいものはどれか。
  43. かつてIntelとMicronが共同開発し、「Optane」の製品名で販売されたストレージクラスメモリの技術はどれか。
  44. 相変化メモリ(PCM)で、1つのセルに複数ビットを記憶する(多値化する)方法として正しいものはどれか。
  45. 銀や銅などの金属イオンが固体電解質の中を移動して導電パスをつくったり切ったりすることで抵抗を変えるメモリはどれか。
  46. ReRAMの動作方式で「バイポーラ型」と「ユニポーラ型」の違いとして正しいものはどれか。
  47. クロスポイント型のPCMなどで、記憶素子と直列に置くセレクタとして使われる、ある電圧を超えると急に導通するカルコゲナイド材料の素子はどれか。
  48. STT-MRAMで、読み出し電流の大きさに制限が必要になる理由として正しいものはどれか。
  49. 強誘電体の分極の向きによって、薄い強誘電体層を通るトンネル電流の大きさが変わることを利用する素子はどれか。
  50. MRAMの書き込みエネルギーを下げる方法として研究されている、電圧で磁性層の磁気異方性を変える効果はどれか。
