組込み・ファームウェアの要点

家電や自動車、産業機器の中では、マイコンの上で動くファームウェアが機器を制御しています。ファームウェアは周辺回路のレジスタを直接読み書きし、ビット演算で特定のビットだけを操作して、端子の入出力(GPIO)やタイマー、通信回路を動かします。

割り込みハンドラでは処理を短くし、共有する変数にvolatileを付けるといった、組込み特有の注意点があります。UART・SPI・I2Cの通信、複数の処理を優先度で切り替えるRTOS、電源を入れたときに最初に動くブートローダ、暴走から立ち直るためのウォッチドッグまで、ハードウェアに最も近いソフトウェアのしくみを学びます。
