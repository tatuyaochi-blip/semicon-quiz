配線プロセスの要点

LSIでは、トランジスタどうしを多層の金属配線で接続します。微細化が進むと配線の抵抗と容量による遅延(RC遅延)が性能を左右するようになり、配線材料の改良が進められてきました。

アルミニウムより抵抗が低いCu配線は、ドライエッチングが難しいため、溝に埋め込んでCMPで削るダマシン法でつくられます。層間絶縁膜には、誘電率の低いLow-k材料が使われます。

配線プロセスの問題一覧（50問）

  1. 先端LSIの配線材料が、アルミニウム(Al)から銅(Cu)に置き換えられた主な理由はどれか。
  2. Cu配線の形成に一般的に用いられるダマシン法の説明として正しいものはどれか。
  3. 層間絶縁膜にLow-k(低誘電率)材料を用いる主な目的はどれか。
  4. Cu配線で、TaやTaNなどのバリアメタルを設ける主な目的はどれか。
  5. 多層配線におけるビアの説明として正しいものはどれか。
  6. 配線の断面形状や配線間隔を変えずに、配線の長さを2倍にすると、配線のRC遅延はおよそ何倍になるか。
  7. トランジスタのソース・ドレインやゲートの表面に、NiSiなどのシリサイドを形成する目的はどれか。
  8. トランジスタと最下層の配線をつなぐコンタクトホールの埋め込みに広く使われてきた金属はどれか。
  9. Cu配線の幅が非常に細くなると、配線の実効的な抵抗率が上昇する主な理由はどれか。
  10. 多層配線で、上層の配線ほど太く厚くする主な理由はどれか。
  11. 配線間の絶縁膜の一部を空洞(エアギャップ)にする技術の主な目的はどれか。
  12. 先端ロジックで導入が進む裏面電源供給(バックサイドパワーデリバリー)の説明として正しいものはどれか。
  13. 電源配線の抵抗に電流が流れることで、回路に届く電源電圧が下がる現象を何と呼ぶか。
  14. 隣り合う配線の間の容量結合によって、一方の信号の変化がもう一方の信号に雑音として現れる現象を何と呼ぶか。
  15. Cu配線の上面にコバルトなどのキャップ層を設ける主な目的はどれか。
  16. エレクトロマイグレーションによる配線の寿命を表すブラックの式で、寿命を短くする要因として正しいものはどれか。
  17. 先端ロジックLSIの配線層の数として最も近いものはどれか。
  18. Cuに代わる微細配線の材料として検討されているルテニウム(Ru)などの金属の利点として正しいものはどれか。
  19. チップの最上層に形成し、内部の回路を水分や汚染、機械的な傷から守る膜を何と呼ぶか。
  20. 多くのLSIで、ワイヤボンディングを行う最上層の電極パッドに使われてきた金属はどれか。
  21. 配線の溝とビアを同時にCuで埋め込み、1回のCMPで形成する方法を何と呼ぶか。
  22. Cuを電解めっきで埋め込む前に、スパッタリングで薄く形成するCu膜の役割として正しいものはどれか。
  23. Cuの埋め込みが不十分で、ビアの中に空洞(ボイド)が残ると起こる問題として正しいものはどれか。
  24. 同じ層で隣り合う配線の間隔を半分にすると、その配線間の容量はおよそどうなるか。(平行平板として近似する)
  25. 上下の配線層の位置合わせのずれに強くするため、ビアを配線の溝に合わせて自己整合的に形成する技術はどれか。
  26. 抵抗率2 µΩ·cmの配線で、長さ1 mm、幅と厚さがそれぞれ100 nmのときの抵抗はおよそいくらか。
  27. エレクトロマイグレーションによるボイドが発生しやすい場所として正しいものはどれか。
  28. 微細化が進んだLSIで、ゲートの遅延と比べた配線の遅延の傾向として正しいものはどれか。
  29. Low-k膜をエッチングやアッシングで加工するときに注意すべき問題として正しいものはどれか。
  30. 配線どうしの間隔が狭くなることで重要性が増している、配線間の絶縁膜の経時的な絶縁破壊を何と呼ぶか。
  31. LSIの中の配線の主な役割はどれか。
  32. LSIの「多層配線」の説明として正しいものはどれか。
  33. 室温での銅(Cu)の抵抗率に最も近い値はどれか。(バルクの値)
  34. LSIの配線材料に求められる主な性質の組み合わせとして正しいものはどれか。
  35. 配線と配線の間を埋める層間絶縁膜の基本的な役割はどれか。
  36. アルミニウム配線に、銅を0.5%程度添加したAl-Cu合金が使われてきた主な理由はどれか。
  37. 電解めっきで形成したCu膜が、室温で放置するだけでも時間とともに結晶粒が大きくなり、抵抗率が下がる現象を何と呼ぶか。
  38. 配線の上下をつなぐビアを、可能な場所では1個でなく2個以上並べて配置する設計上の工夫の主な目的はどれか。
  39. トランジスタ(FEOL側)と多層配線をつなぐ、コンタクトや局所的な配線の部分を指して使われる言葉はどれか。
  40. 微細化が進んだ多層配線で、ビアの抵抗が問題になってきた主な理由として正しいものはどれか。
  41. ある配線の容量について、正しい説明はどれか。
  42. 配線の幅を変えずに厚さ(高さ)を大きくしたときの影響として正しいものはどれか。
  43. 機械的に弱いLow-k膜を使ったチップで、パッケージに実装するときの応力によって膜が割れたりはがれたりする問題を何と呼ぶか。
  44. Cu配線の上面に、絶縁膜側の拡散防止とエッチングストップを兼ねてつける膜として一般的なものはどれか。
  45. エレクトロマイグレーションの試験で、ある長さより短い配線では寿命が大きく延びる(劣化がほとんど進まない)現象が知られている。この現象の名前はどれか。
  46. 配線の幅が結晶粒より細くなり、結晶粒界が配線を横切るように並んだ構造を何と呼び、エレクトロマイグレーションにどう影響するか。
  47. 高い周波数の信号が配線を流れるとき、電流が導体の表面付近に集中し、実効的な抵抗が上がる現象を何と呼ぶか。
  48. ワイヤボンディングなどを行う電極パッドの真下に、能動素子や配線を配置する設計を何と呼ぶか。
  49. Cuにマンガンなどを少量加えた合金を成膜し、熱処理で絶縁膜との界面に薄いバリア層を自然に形成させる技術はどれか。
  50. 数GHzで動作するチップのクロック配線のように長く太い配線で、抵抗と容量に加えて考慮が必要になる配線の性質はどれか。
