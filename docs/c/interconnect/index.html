配線プロセスの要点

LSIでは、トランジスタどうしを多層の金属配線で接続します。微細化が進むと配線の抵抗と容量による遅延(RC遅延)が性能を左右するようになり、配線材料の改良が進められてきました。

アルミニウムより抵抗が低いCu配線は、ドライエッチングが難しいため、溝に埋め込んでCMPで削るダマシン法でつくられます。層間絶縁膜には、誘電率の低いLow-k材料が使われます。
