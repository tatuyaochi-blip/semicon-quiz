機械学習の基礎の要点

機械学習は、データから規則を自動で学び取って、予測や分類を行う技術です。正解のラベルを使う教師あり学習、ラベルのないデータからまとまりを見つける教師なし学習、報酬を手がかりに行動を学ぶ強化学習があり、どの方法でも、学習に使っていないデータでどれだけ正しく予測できるか(汎化性能)が大切です。

ここでは、学習用・検証用・テスト用のデータの分け方と交差検証、過学習とバイアス・バリアンス、正則化やドロップアウト、混同行列から求める適合率・再現率・F値、ROC曲線、平均二乗誤差を、計算問題を中心に学びます。線形回帰、ロジスティック回帰、決定木、ランダムフォレスト、k近傍法、SVM、ナイーブベイズといった代表的なモデルに続いて、ニューラルネットワークの順伝播、活性化関数、損失関数、勾配降下法と誤差逆伝播法、ミニバッチとエポック、CNNの出力の大きさ、RNNとTransformer、転移学習、生成モデル、LLMのトークンまでを扱います。基本情報技術者試験・応用情報技術者試験やG検定のAI分野の学習にも役立ちます。

機械学習の基礎の問題一覧（40問）
  1. 教師あり学習の課題のうち、回帰に当たるものはどれか。
  2. 教師なし学習に当たるものはどれか。
  3. 強化学習の説明として、適切なものはどれか。
  4. k平均法(k-means法)によるクラスタリングの手順として、適切なものはどれか。
  5. 主成分分析(PCA)の説明として、適切なものはどれか。
  6. データを学習用・検証用・テスト用の3つに分けるとき、検証用データの主な使い方として、適切なものはどれか。
  7. 1000件のデータで5分割交差検証(k = 5 のk分割交差検証)を行うとき、1回ごとの学習に使うデータの件数はどれか。
  8. 過学習(過剰適合)が起きているときに見られる様子として、適切なものはどれか。
  9. モデルの誤差を、バイアス(偏り)とバリアンス(ばらつき)に分けて考えるとき、適切なものはどれか。
  10. 過学習を抑える正則化などの手法の説明として、適切なものはどれか。
  11. 機械学習のモデルを作る手順のうち、データリーク(評価に使うデータの情報が学習に紛れ込むこと)を起こしているものはどれか。
  12. 2クラス分類のモデルを200件のテストデータで評価した混同行列で、真陽性(TP)が45件、偽陽性(FP)が5件、偽陰性(FN)が45件、真陰性(TN)が105件だった。適合率と再現率の組合せとして、正しいものはどれか。
  13. 2クラス分類のモデルを200件のテストデータで評価したところ、TPが20件、FPが5件、FNが30件、TNが145件だった。F値(F1スコア)に最も近いものはどれか。
  14. 2クラス分類のモデルの評価に使うROC曲線とAUCの説明として、適切なものはどれか。
  15. 1000件のうち陽性が10件しかないデータに対して、すべてを陰性と予測するモデルの正解率はどれか。
  16. 4件のデータの実際の値が3、5、2、6で、モデルの予測値がそれぞれ2、5、4、4のとき、平均二乗誤差(MSE)はどれか。
  17. 3つのデータ (x, y) = (1, 3)、(2, 4)、(3, 8) に、最小二乗法で直線 y = ax + b を当てはめた。x = 4 のときの予測値はどれか。
  18. ロジスティック回帰で、z = 2x − 4 をシグモイド関数 σ(z) = 1 ÷ (1 + e^(−z)) に通した値を、陽性である確率として出力する。x = 2 のときの出力はどれか。
  19. 決定木のあるノードに、クラスAのデータが6件、クラスBのデータが4件ある。このノードのジニ不純度はどれか。
  20. アンサンブル学習のバギング(ランダムフォレストなど)とブースティングの違いとして、適切なものはどれか。
  21. 2次元の点 (0, 0) のクラスをk近傍法で予測する。学習用データは、赤の点 (1, 0)、(3, 0)、(0, −3) と、青の点 (0, 2)、(−2, 1) である。距離をユークリッド距離とするとき、k = 3 と k = 5 の予測の組合せとして、正しいものはどれか。
  22. サポートベクターマシン(SVM)の説明として、適切なものはどれか。
  23. メール全体の20%がスパムである。ある単語は、スパムの50%と、スパムでないメールの5%に含まれる。この単語を含むメールがスパムである確率に最も近いものはどれか。
  24. 入力層と出力層だけからなる単純パーセプトロン(しきい値で0か1を出力する1つのニューロン)で表せない論理関数はどれか。
  25. 3クラスの分類で、ソフトマックス関数に入力する値(ロジット)が3、1、0だった。1番目のクラスの出力(確率)は、2番目のクラスの出力の約何倍か。最も近いものはどれか。
  26. 入力が x₁ = 1、x₂ = 2 の小さなニューラルネットワークで、隠れ層の2つのニューロンが h₁ = ReLU(x₁ + x₂ − 1)、h₂ = ReLU(x₁ − 2x₂ + 1)、出力が y = 2h₁ + 3h₂ + 1 である。yの値はどれか。
  27. 正解のクラスに対してモデルが出力した確率をpとするとき、分類の学習で使う交差エントロピー損失 −log p の性質として、適切なものはどれか。
  28. 勾配降下法で、重み w = 2.0 における損失の勾配 ∂L/∂w が0.5、学習率が0.1のとき、1回の更新後の重みはどれか。
  29. y = (2x + 1)² の x = 1 における微分係数 dy/dx を、u = 2x + 1、y = u² として連鎖律で求めるとき、正しい値はどれか。
  30. 多くの層を重ねたニューラルネットワークで、活性化関数にシグモイド関数を使うと、入力に近い層の学習が進みにくくなる理由として、適切なものはどれか。
  31. 1万件の学習用データを、ミニバッチの大きさ(バッチサイズ)50で学習する。1エポックでの重みの更新の回数はどれか。
  32. 入力が64個、出力が32個の全結合層(各出力にバイアスが1つずつある)の、学習するパラメータの数はどれか。
  33. 28×28の1チャネルの画像に、5×5のフィルタで畳み込み(ストライド1、パディングなし)を行い、続けて2×2の最大値プーリング(ストライド2)を行う。出力の縦と横の大きさはどれか。
  34. 再帰型ニューラルネットワーク(RNN)とLSTMの説明として、適切なものはどれか。
  35. Transformerで使われるセルフアテンション(自己注意機構)の説明として、適切なものはどれか。
  36. 大量のデータで学習済みのモデルを、別の課題に少ないデータで利用する転移学習の説明として、適切なものはどれか。
  37. 画像などを生成するモデルの説明として、適切なものはどれか。
  38. 大規模言語モデル(LLM)が文章を処理するしくみの説明として、適切なものはどれか。
  39. 過去の採用の結果を正解として、応募書類から採用の可否を予測するモデルを作るときに注意すべき点として、適切なものはどれか。
  40. 説明可能なAI(XAI)の説明として、適切なものはどれか。
