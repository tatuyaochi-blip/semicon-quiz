論理回路

基本論理ゲート、ド・モルガンの定理、フリップフロップなど論理回路の基礎を3択問題で確認できます。

—あなたの正答率
0 / 50解いた問題
この分野を解くこの分野の問題をすべて、ランダムな順で出題します 苦手問題直近で間違えた問題だけを解き直します

論理回路の要点

デジタル回路は、AND・OR・NOTといった基本ゲートと、その組み合わせであるNAND・NOR・XORなどで構成されます。真理値表やブール代数、ド・モルガンの定理を使うと、論理式を簡単にしたり別のゲートで置き換えたりできます。

出力が入力だけで決まる組み合わせ回路と、フリップフロップなどで状態を保持する順序回路の違いも押さえておきましょう。

論理回路の問題一覧（50問）

  1. 2入力NANDゲートの出力が0になるのはどのときか。
  2. ド・モルガンの定理によれば、NOT(A AND B) と等しい論理式はどれか。
  3. D型フリップフロップの動作として正しいものはどれか。
  4. 2入力XOR(排他的論理和)ゲートの出力が1になるのはどのときか。
  5. 2進数の1011を10進数で表すといくつか。
  6. 順序回路の説明として正しいものはどれか。
  7. 1ビットの半加算器で、和(S)と桁上げ(C)を出力する論理として正しいものはどれか。
  8. 16進数のFFを10進数で表すといくつか。
  9. 4ビットの2の補数表現で −1 を表すビット列はどれか。
  10. マルチプレクサの機能として正しいものはどれか。
  11. 2入力NANDゲートの2つの入力をつないで1入力にしたときの働きはどれか。
  12. カルノー図の主な用途はどれか。
  13. フリップフロップのセットアップ時間の説明として正しいものはどれか。
  14. 4ビットのバイナリカウンタが表すことのできる状態の数はいくつか。
  15. グレイコードの特徴として正しいものはどれか。
  16. Dラッチの動作の説明として正しいものはどれか。
  17. 非同期の信号をフリップフロップで受けたときに、セットアップ時間やホールド時間を満たせず、出力が一時的に0とも1とも定まらなくなる状態を何と呼ぶか。
  18. 出力が現在の状態だけで決まる順序回路(ステートマシン)の型はどれか。
  19. 10進数の59をBCD(2進化10進数)で表したものはどれか。
  20. 3入力の多数決回路の出力が1になる条件として正しいものはどれか。
  21. 全加算器の入力として正しい組み合わせはどれか。
  22. 3ビットの入力に応じて、8本の出力のうち1本だけを有効にする回路はどれか。
  23. フリップフロップを直列につなぎ、クロックごとにデータを1ビットずつ隣へ移すシフトレジスタの代表的な用途はどれか。
  24. 2進数を1ビット左にシフトすると、値はどうなるか。(桁あふれがない場合)
  25. 7ビットのデータ 1011001 に偶数パリティのビットを付けるとき、パリティビットの値はどれか。
  26. 2入力NORゲートの出力が1になるのはどのときか。
  27. 論理式 A + A・B を簡単化した結果はどれか。
  28. すべてのフリップフロップが共通のクロックで動作する同期式回路の利点として正しいものはどれか。
  29. 同期式回路で、動作できる最大のクロック周波数を決めるものはどれか。
  30. 組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。
  31. 2入力ANDゲートの出力が1になるのはどのときか。
  32. 2入力ORゲートの出力が0になるのはどのときか。
  33. NOTゲート(インバータ)の働きとして正しいものはどれか。
  34. 10進数の13を2進数で表したものはどれか。
  35. 3入力の論理回路の真理値表は何行になるか。
  36. 1バイトは何ビットか。
  37. 16進数の1Aを10進数で表すといくつか。
  38. JKフリップフロップで、J = 1、K = 1 のときにクロックが入ったときの動作はどれか。
  39. クロックが入るたびに出力が反転するTフリップフロップ1個の出力の周波数は、クロック周波数の何倍になるか。
  40. 複数の入力が同時に1になったとき、最も優先度の高い入力の番号を2進数で出力する回路はどれか。
  41. 全加算器を直列につないだリプルキャリー加算器の欠点として正しいものはどれか。
  42. フリップフロップのホールド時間の説明として正しいものはどれか。
  43. 同期式回路の「クロックスキュー」の説明として正しいものはどれか。
  44. トライステートバッファの出力がとりうる3つ目の状態はどれか。
  45. 8ビットの2の補数表現で表せる整数の範囲はどれか。
  46. 桁上げ先見(キャリールックアヘッド)加算器が高速な理由として正しいものはどれか。
  47. 2の補数表現の数どうしの加算で、オーバーフロー(桁あふれ)が起きたことを判定する条件として正しいものはどれか。
  48. n個のフリップフロップで構成したジョンソンカウンタ(ツイストリングカウンタ)がとる状態の数はいくつか。
  49. シフトレジスタの一部の出力のXORを入力に戻す線形帰還シフトレジスタ(LFSR)の代表的な用途はどれか。
  50. オープンドレイン出力の回路を複数、プルアップ抵抗のある1本の信号線につないだときの動作として正しいものはどれか。
