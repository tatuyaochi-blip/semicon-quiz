歩留まり・品質管理の要点

歩留まりは、投入した製品のうち良品として得られた割合で、半導体工場の収益を大きく左右する指標です。欠陥密度が同じなら、チップ面積が大きいほど欠陥を含む確率が高くなり、歩留まりは下がります。

工程を安定させるため、管理図などの統計的な手法(SPC)でデータを監視し、異常を早く見つけて対策します。
