酸化・拡散

ドライ酸化とウェット酸化の違い、熱酸化で消費されるシリコン厚、拡散係数の温度依存性を3択で学べます。

酸化・拡散の要点

シリコンを高温の酸素や水蒸気の雰囲気で加熱すると、表面に良質なSiO2膜ができます。これを熱酸化といい、ゲート絶縁膜や素子分離、マスクなどに使われてきました。

熱拡散は、高温で不純物を原子の拡散によってシリコン中に導入する方法です。拡散の進み方は温度に強く依存するため、温度と時間の管理が重要になります。

酸化・拡散の問題一覧（50問）

  1. シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。
  2. シリコンを熱酸化して厚さxのSiO2膜をつくったとき、消費されるシリコンの厚さはおよそいくらか。
  3. シリコン中の不純物の拡散係数と温度の関係として正しいものはどれか。
  4. 微細なLSIの素子分離に主に使われている方法はどれか。
  5. 熱酸化で酸化膜が十分厚くなったときの、酸化膜厚と酸化時間の関係として正しいものはどれか。
  6. シリコン上の酸化膜が、膜厚に応じてさまざまな色に見える理由として正しいものはどれか。
  7. 多数のウエハを一度に熱酸化するときに一般的に使われる装置はどれか。
  8. 熱拡散で、表面に一定量の不純物を導入する工程のあとに、不純物をより深く押し込む工程を何と呼ぶか。
  9. シリコンの熱酸化における酸化速度の面方位依存性として正しいものはどれか。
  10. ゲート酸化膜に窒素を導入して酸窒化膜(SiON)にする主な目的はどれか。
  11. 熱酸化膜が、拡散の際の不純物のマスクとして使える理由として正しいものはどれか。
  12. Si/SiO2界面の界面準位を減らすために行われる、水素を含む雰囲気での熱処理を何と呼ぶか。
  13. 熱酸化の際に、塩化水素(HCl)などの塩素を含むガスを少量加える主な目的はどれか。
  14. ボロンを含むシリコンを熱酸化するとき、界面付近のシリコン側のボロン濃度はどうなる傾向があるか。
  15. ランプなどでウエハを1枚ずつ、数秒程度の短時間で高温に加熱する熱処理を何と呼ぶか。
  16. 熱酸化で形成したSiO2膜の比誘電率に最も近い値はどれか。
  17. シリコンがMOSデバイスの材料として広く使われてきた大きな理由の一つとして正しいものはどれか。
  18. ゲート酸化膜中にナトリウムイオンなどの可動イオンが含まれると起こる問題として正しいものはどれか。
  19. シリコン中の熱処理での拡散が比較的遅く、浅い接合をつくりやすいn型不純物はどれか。
  20. パイロジェニック酸化(水素燃焼酸化)の説明として正しいものはどれか。
  21. 良質な熱酸化膜(SiO2)の絶縁破壊電界の目安として正しいものはどれか。
  22. ウエハ表面の近くで水素と酸素を反応させ、短時間で良質な薄い酸化膜をつくる方法はどれか。
  23. 薄いゲート酸化膜の表面に、プラズマで生成した窒素を導入する処理を何と呼ぶか。
  24. 同じ希フッ酸でエッチングしたとき、熱酸化膜とCVDで成膜した酸化膜のエッチング速度の一般的な関係として正しいものはどれか。
  25. 熱酸化の際に、酸化によって生じた過剰な格子間シリコンがシリコン中に注入されて成長する欠陥はどれか。
  26. 熱酸化の温度を上げると、同じ時間で得られる酸化膜の厚さはどうなるか。
  27. LOCOS(選択酸化)で、窒化膜マスクの端の下に酸化膜が鳥のくちばし状に食い込む現象を何と呼ぶか。
  28. 高い圧力の酸化雰囲気で熱酸化を行う利点として正しいものはどれか。
  29. 酸素ラジカルを使うラジカル酸化の特徴として正しいものはどれか。
  30. Deal-Groveモデルによると、熱酸化はどこで進むか。
  31. シリコンのドライ熱酸化で起こる化学反応として正しいものはどれか。
  32. シリコンの熱酸化が一般的に行われる温度の範囲として最も近いものはどれか。
  33. 半導体製造でいう不純物の「拡散」の説明として正しいものはどれか。
  34. シリコンの熱酸化膜の代表的な使われ方として正しいものはどれか。
  35. 拡散係数Dの単位として正しいものはどれか。
  36. フィックの第1法則の内容として正しいものはどれか。(J:拡散の流束、D:拡散係数、C:濃度、x:位置)
  37. 同じ温度で不純物を拡散させるとき、拡散時間を4倍にすると、不純物が広がるおよその距離は何倍になるか。
  38. 熱拡散で、表面の不純物濃度を一定に保ちながら拡散させた場合(定表面濃度拡散)と、決まった量の不純物を拡散させた場合(有限量の拡散)の分布の形の組み合わせとして正しいものはどれか。
  39. 熱拡散でシリコンにリンを導入するときに、液体の拡散源として使われてきた化合物はどれか。
  40. MOS構造の酸化膜とその界面にある電荷の種類の組み合わせとして、一般的に分類されるものはどれか。
  41. Deal-Groveモデルで、熱酸化の初期(酸化膜がまだ薄いとき)の酸化膜厚と時間の関係として正しいものはどれか。
  42. LOCOSなどの素子分離に使われたフィールド酸化膜と、MOSFETのゲート酸化膜の厚さの関係として一般的に正しいものはどれか。
  43. PN接合の「接合深さ」の定義として一般的に正しいものはどれか。
  44. シリコンを酸化している間に、ボロンやリンの拡散が酸化していないときより速くなる現象を何と呼ぶか。
  45. ドライ酸化で厚さ数十nm以下の薄い酸化膜をつくるとき、Deal-Groveモデルからずれることとして知られているものはどれか。
  46. LOCOSで、窒化膜マスクの下のシリコン表面に薄い窒化物ができ、後のゲート酸化膜が局所的に薄くなったり不良になったりする現象を何と呼ぶか。
  47. 熱酸化で生じた酸化膜の圧縮応力が、およそ950℃以上の高温の酸化では小さくなる主な理由はどれか。
  48. SiO2膜が、ボロンやリンの拡散のマスクには使えるが、ガリウムやアルミニウムに対してはマスクとして働きにくい理由として正しいものはどれか。
  49. 不純物濃度が真性キャリア密度より十分高い領域で、ヒ素などの拡散係数が濃度によって変わる現象についての説明として正しいものはどれか。
  50. 不純物を多く含む多結晶シリコン(ポリシリコン)を熱酸化したときの特徴として正しいものはどれか。
