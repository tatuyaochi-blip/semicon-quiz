先端技術(3D実装・チップレット)の要点

微細化だけで性能を伸ばすことが難しくなり、複数のチップを1つのパッケージにまとめて性能を高める技術が注目されています。機能ごとに分けた小さなチップ(チップレット)を組み合わせる方式は、歩留まりやコストの面でも利点があります。

TSVでチップを縦に積み重ねる3D実装や、インターポーザ上にプロセッサとHBMを並べる2.5D実装が、AI向けの高性能半導体で使われています。
