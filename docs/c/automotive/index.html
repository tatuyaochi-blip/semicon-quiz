車載半導体と機能安全の要点

自動車の半導体は、−40 ℃から150 ℃にもなる温度の中で15年程度使われ、故障が人命に関わるため、民生用より厳しい品質と信頼性が求められます。AEC-Q100などの認定試験、ゼロ不良を目指す品質管理、変更の通知やトレーサビリティがその土台です。

さらにISO 26262の機能安全では、危険の大きさからASILを決め、ロックステップCPUやECC、電圧・クロック監視などの安全機構で故障を検出して、安全な状態に移します。CANや車載イーサネットのネットワーク、48 V・800 V系の電源、ADASのセンサとSOTIFまで、車載の電子設計の基本を学びます。

車載半導体と機能安全の問題一覧（50問）
  1. 車載用ICの信頼性試験の基準AEC-Q100で、動作温度のグレード1に定められている周囲温度の範囲はどれか。
  2. 車載用電子部品の認定試験の基準であるAEC-Q100・AEC-Q101・AEC-Q200が主に対象とする部品の組み合わせとして正しいものはどれか。
  3. ある車載部品が、15年間、1日24時間ずっと動作し続けると仮定する。合計の動作時間はおよそ何時間か。
  4. 車載用の半導体で求められる「ゼロディフェクト(ゼロ不良)」の考え方として最も適切なものはどれか。
  5. 自動車業界で使われるPPAP(量産部品承認プロセス)の説明として正しいものはどれか。
  6. 車載用の半導体で、製造する工場や使う材料を変更したいときの進め方として正しいものはどれか。
  7. 車載用のICで、ウエハテストのときにロット番号・ウエハ番号・ウエハ上の座標などを、チップ内部の電気的に書き込める不揮発の記憶(ヒューズなど)に記録しておく主な目的はどれか。
  8. 車載用ICの認定試験で、85 ℃・85%RHで1000時間行う高温高湿バイアス試験(THB)の代わりに、HAST(130 ℃・85%RH程度の加圧した水蒸気中でバイアスをかける試験)が使われることがある主な理由はどれか。
  9. 車載用ICのラッチアップ試験を、室温より厳しい、製品の最高動作温度で行うことが求められる理由として正しいものはどれか。
  10. ICの部品単体のESD試験(HBMやCDM)と、完成した車載機器に対して行うシステムレベルのESD試験の違いとして正しいものはどれか。
  11. 機能安全の規格ISO 26262の説明として正しいものはどれか。
  12. 自動車の機能安全の考え方として正しいものはどれか。
  13. ISO 26262で、ハザード分析とリスクアセスメント(HARA)によりASILを決めるときに評価する3つの要素の組み合わせとして正しいものはどれか。
  14. ISO 26262のASILについての説明として正しいものはどれか。
  15. ある危険な事象を評価したところ、重大度S3・露出度E4・制御可能性C3で、ASIL Dとなった。同じ事象で、制御可能性だけがC2(通常は多くの運転者が回避できる)であったとすると、ASILはどうなるか。
  16. ISO 26262における「安全目標」の説明として正しいものはどれか。
  17. ISO 26262で区別されるランダムハードウェア故障とシステマティック故障の説明の組み合わせとして正しいものはどれか。
  18. ランダムハードウェア故障によって安全目標が侵害される確率の指標PMHFについて、ASIL Dの目標値の目安は10 FIT未満とされる。これを1時間あたりの確率で表すとどれか。
  19. 単一点故障指標(SPFM)について、ASIL Dで求められる目標値の目安として正しいものはどれか。
  20. ISO 26262でいう潜在故障(レイテントフォールト)の例として最も適切なものはどれか。
  21. 安全に関係するハードウェアの故障率の合計が1000 FITで、そのうち単一点故障と残余故障(安全機構で検出されずに残る故障)の故障率の合計が5 FITのとき、単一点故障指標(SPFM)はいくらか。
  22. 故障率200 FITの回路に、診断カバレッジ99%の安全機構を設けた。安全機構で検出されずに残る故障の故障率はいくらか。
  23. ISO 26262のフォールトトレラント時間間隔(FTTI)の説明として正しいものはどれか。
  24. 車載マイコンの安全機構として使われるロックステップCPUの仕組みとして正しいものはどれか。
  25. ロックステップCPUで、2つのコアの実行を数クロックずらしたり、チップ上で2つのコアを離して配置したりする主な理由はどれか。
  26. 車載マイコンのメモリで、1ビットの誤りを訂正し2ビットの誤りを検出できるECC(SEC-DED)を使っている。読み出したデータに2ビットの誤りが起きていたとき、一般にどうなるか。
  27. ウィンドウ型のウォッチドッグタイマの特徴として正しいものはどれか。
  28. 車載マイコンで、電源を入れたときや走行の前などに、ロジックBISTやメモリBISTを実行する機能安全上の主な目的はどれか。
  29. 車載マイコンのクロック監視の安全機構として適切なものはどれか。
  30. 機能安全に対応した車載用の電源ICなどに設けられる電圧監視の安全機構として適切なものはどれか。
  31. ISO 26262のASILデコンポジション(分解)で、ASIL Dの安全要求を、十分に独立した2つの冗長な要素に分けて割り当てる組み合わせとして認められているものはどれか。
  32. ISO 26262のSEooC(Safety Element out of Context)の説明として正しいものはどれか。
  33. 機能安全の評価で行うFMEDA(故障モード・影響・診断解析)の説明として正しいものはどれか。
  34. 複数のECUの機能を1つの高性能なSoCに統合し、異なるASILのソフトウェアを一緒に動かすときに求められることとして正しいものはどれか。
  35. CANで、2つのノードが同時にフレームを送り始めたときの動作として正しいものはどれか。
  36. 両端に120 Ωの終端抵抗を付けたCANのバスで、電源を切った状態でCAN_HとCAN_Lの間の抵抗を測った。正常な場合の値として最も近いものはどれか。
  37. CAN FDの特徴として正しいものはどれか。
  38. 車載ネットワークのLINの特徴として正しいものはどれか。
  39. 車載ネットワークのFlexRayの特徴として正しいものはどれか。
  40. 車載イーサネット(100BASE-T1や1000BASE-T1など)の特徴として正しいものはどれか。
  41. 自動車の電子システムで進んでいる「ゾーンアーキテクチャ」への移行の説明として正しいものはどれか。
  42. 車のソフトウェアを無線で書き換えるOTA(Over-the-Air)アップデートを行うときの考え方として適切なものはどれか。
  43. 自動車の規格ISO 26262とISO/SAE 21434の違いとして正しいものはどれか。
  44. 同じ電力を同じ抵抗の配線で送るとき、電源の電圧を12 Vから48 Vにすると、配線で生じるジュール損失はおよそ何倍になるか。
  45. 800 V系のバッテリーを使う電気自動車の主機インバータに使われるパワー素子の耐圧クラスとして一般的なものはどれか。
  46. 車載電源で問題になる「ロードダンプ」の説明として正しいものはどれか。
  47. 電動車の電力変換で、IGBT・SiC MOSFET・GaN HEMTの使い分けの考え方として最も適切なものはどれか。
  48. ADAS(先進運転支援システム)で使われるミリ波レーダーの特徴として正しいものはどれか。
  49. LiDARがレーザーのパルスを出してから、対象物からの反射光が戻ってくるまでに400 nsかかった。対象物までの距離はおよそいくらか(光速 3×10⁸ m/s)。
  50. 次のうち、ISO 26262(機能安全)ではなく、主にSOTIF(ISO 21448、意図した機能の安全性)で扱う問題はどれか。
