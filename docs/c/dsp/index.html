デジタル信号処理の基礎の要点

ADコンバータで数値の列になった信号は、プロセッサやFPGAの上で、フィルタをかけたり、周波数の成分を調べたり、サンプリング周波数を変えたりして処理されます。オーディオ、通信、センサ、モータの制御、計測器など、デジタル信号処理はほとんどの電子機器の中で動いています。

ここでは、離散時間の信号の正規化周波数と周期、単位インパルスとステップ、エネルギーと電力から始め、線形時不変システムの性質(線形性・時不変性・因果性・BIBO安定)、インパルス応答と畳み込み、差分方程式の計算を扱います。続いて、DFTのビンの間隔と番号、実数の信号のスペクトルの対称性、FFTの演算量、ゼロパディング、スペクトル漏れと窓関数、パーセバルの定理、z変換による伝達関数と極・零点、FIRフィルタとIIRフィルタ、直線位相と群遅延、移動平均と指数平滑化、双一次変換、係数の量子化、デシメーションと補間、積和演算の回数と実時間処理の時間の見積もりを確かめます。計算問題の値は、選択肢の誤りの値も含めて、Python(NumPy)で計算して確かめています。サンプリング定理、エイリアシング、量子化雑音、オーバーサンプリング、ΔΣ型のADCは「AD/DA変換」、アナログのフィルタやオペアンプは「アナログ・電子回路」、OFDMは「無線通信の基礎」、CNNの畳み込みは「機械学習の基礎」、固定小数点の表し方は「計算機算術」の分野で扱います。

デジタル信号処理の基礎の問題一覧（40問）
  1. サンプリング周波数48 kHzで、周波数6 kHzの正弦波をサンプリングした。この離散時間信号の正規化角周波数ω(1サンプルあたりに進む位相)として正しいものはどれか。
  2. 離散時間信号 x[n] = cos(0.3πn) の基本周期(すべての整数 n で x[n + N] = x[n] となる最小の正の整数 N)として正しいものはどれか。
  3. 離散時間信号 x[n] = cos(1.75πn) と、すべての整数 n で同じ値をとる信号はどれか。
  4. 単位インパルス δ[n](n = 0 で1、それ以外で0)と単位ステップ u[n](n ≥ 0 で1、n < 0 で0)の関係として正しいものはどれか。
  5. x[n] = (0.5)ⁿu[n](n ≥ 0 で0.5のn乗、n < 0 で0)のエネルギー E = Σ|x[n]|² として正しいものはどれか。
  6. x[n] = 2cos(πn/4) の平均電力(1周期にわたる |x[n]|² の平均)として正しいものはどれか。
  7. 入力 x[n]、出力 y[n] のシステムのうち、線形かつ時不変(LTI)であるものはどれか。
  8. y[n] = n·x[n] で表されるシステムの性質として正しいものはどれか。
  9. 入力 x[n]、出力 y[n] のシステムのうち、因果的(出力がその時刻までの入力だけで決まる)であるものはどれか。
  10. u[n] を単位ステップとする。インパルス応答が次のように表されるLTIシステムのうち、BIBO安定(有界な入力に対して出力が必ず有界)であるものはどれか。
  11. x[n] = {1, 2, 3}(n = 0, 1, 2)を、インパルス応答 h[n] = {1, −1}(n = 0, 1)のLTIシステムに入力した。出力 y[0]〜y[3] として正しいものはどれか。
  12. 差分方程式 y[n] = x[n] + 0.5y[n − 1] で表されるシステムに、n = 0 から単位ステップ(n ≥ 0 で x[n] = 1)を入力した。y[−1] = 0 のとき、y[2] として正しいものはどれか。
  13. サンプリング周波数48 kHzの信号を、1024点の離散フーリエ変換(DFT)で解析する。周波数ビンの間隔として正しいものはどれか。
  14. k = 0 を直流のビンとする。サンプリング周波数8 kHzでサンプリングした1 kHzの正弦波を256点のDFTで解析したとき、正の周波数の側でピークが現れるビンの番号 k として正しいものはどれか。
  15. 実数の信号 x[n] の64点のDFTを計算したところ、X[10] = 3 + 4j であった。X[54] として正しいものはどれか。
  16. 8点の実数の信号 x[n] = {3, 1, 3, 1, 3, 1, 3, 1} の DFT を X[k] = Σx[n]e^(−j2πkn/8) とする。ナイキスト周波数に当たるビン X[4] の値として正しいものはどれか。
  17. N点のDFTを定義どおりに計算すると約 N² 回、FFT(高速フーリエ変換)では約 N log₂N 回の演算で済むとする。N = 1024 のとき、FFTによる演算回数の削減の度合いとして最も近いものはどれか。
  18. 256点の信号のあとに0を768個付け足して(ゼロパディング)、1024点のDFTを計算した。256点のままDFTを計算した場合と比べた説明として正しいものはどれか。
  19. DFTでスペクトル漏れが生じる主な原因として正しいものはどれか。
  20. DFTの前に掛ける窓関数について、方形窓(何も掛けない場合)とハン窓(ハニング窓)を比べた説明として正しいものはどれか。
  21. 点数 N は十分大きいものとする。方形窓のDFTで、正弦波の周波数が隣り合う2つのビンのちょうど中間にあるとき、最も近いビンで読み取れる振幅の、周波数がビンの中心に一致する場合からの低下として最も近いものはどれか。
  22. 4点の信号 x[n] = {1, −1, 2, 0} の DFT を X[k] = Σx[n]e^(−j2πkn/4) とする。Σ|X[k]|²(k = 0〜3)として正しいものはどれか。
  23. 離散時間のLTIシステムの伝達関数 H(z) から周波数応答を求めるとき、z を動かす場所として正しいものはどれか。
  24. 差分方程式 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1] で表されるシステムの伝達関数 H(z) = Y(z)/X(z) として正しいものはどれか。
  25. 伝達関数 H(z) = 1/(1 − 1.3z⁻¹ + 0.4z⁻²) で表される因果的なシステムの、極と安定性の組み合わせとして正しいものはどれか。
  26. サンプリング周波数8 kHzで動作する、伝達関数 H(z) = 1 + z⁻²(y[n] = x[n] + x[n − 2])のFIRフィルタがある。出力が0になる正弦波の入力の周波数として正しいものはどれか。
  27. y[n] = x[n] − x[n − 1](1つ前の入力との差)で表されるフィルタの、直流とナイキスト周波数での利得の大きさの組み合わせとして正しいものはどれか。
  28. FIRフィルタ(有限インパルス応答フィルタ)の特徴として正しいものはどれか。
  29. 次の係数をもつ5タップのFIRフィルタのうち、直線位相(線形位相)の特性をもつものはどれか。
  30. 101タップの直線位相FIRフィルタ(係数が左右対称)の群遅延として正しいものはどれか。
  31. サンプリング周波数8 kHzで、直近8サンプルの平均をとる移動平均フィルタ y[n] = (x[n] + x[n − 1] + … + x[n − 7])/8 を使う。出力が0になる最も低い周波数として正しいものはどれか。
  32. 指数平滑化 y[n] = 0.2x[n] + 0.8y[n − 1] で表される1次のIIRローパスフィルタの、直流とナイキスト周波数での利得の組み合わせとして正しいものはどれか。
  33. アナログフィルタの伝達関数 H(s) からデジタルフィルタを設計するときに使う、双一次変換の説明として正しいものはどれか。
  34. 次数の高いIIRフィルタを、係数のビット数が限られた固定小数点で実装するときの注意として正しいものはどれか。
  35. サンプリング周波数48 kHzの信号を、4サンプルごとに1つ取り出して12 kHzに下げる(1/4のデシメーション)。間引く前に置くローパスフィルタで取り除いておくべき周波数の成分として正しいものはどれか。
  36. サンプリング周波数を L 倍にするため、各サンプルの間に L − 1 個の0を挿入した(ゼロ挿入)。このあとに必要な処理の説明として正しいものはどれか。
  37. サンプリング周波数を44.1 kHzから48 kHzに変換するため、L 倍のアップサンプリングと 1/M のダウンサンプリングを組み合わせる。最小の整数の組 (L, M) として正しいものはどれか。
  38. 256タップのFIRフィルタを、サンプリング周波数44.1 kHzで実時間に動かす。1秒あたりに必要な積和演算(MAC)の回数として正しいものはどれか。
  39. サンプリング周波数48 kHzで、1サンプルごとにFIRフィルタの出力を計算する。クロック200 MHzで1サイクルに1回の積和ができるプロセッサを使い、ほかの処理の時間を無視するとき、実時間で処理できるタップ数の上限に最も近いものはどれか。
  40. 16ビットの固定小数点のデータと係数の積を32ビットで表し、その積を256個たし合わせるFIRフィルタの計算がある。途中で桁あふれが起こらないことを保証するのに必要な、アキュムレータのビット数の最小値として正しいものはどれか。
