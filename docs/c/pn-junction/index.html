PN接合・ダイオード

PN接合の空乏層、順方向・逆方向バイアス、降伏現象とダイオードの用途を3択問題で学べます。

PN接合・ダイオードの要点

p型とn型の半導体を接合すると、境界付近でキャリアが拡散して再結合し、キャリアがほとんどない空乏層ができます。空乏層には内蔵電位が生じ、これが電流を一方向に流す整流作用のもとになります。

順方向バイアスでは障壁が下がって電流が流れ、逆方向バイアスでは空乏層が広がってほとんど電流が流れません。逆電圧をさらに大きくすると降伏が起こり、この現象は定電圧ダイオードに利用されます。

PN接合・ダイオードの問題一覧（30問）

  1. PN接合ダイオードに順方向バイアスを加えるときの電圧のかけ方として正しいものはどれか。
  2. PN接合に加える逆方向バイアス電圧を大きくすると、空乏層の幅はどうなるか。
  3. 定電圧ダイオード(ツェナーダイオード)が主に利用している現象はどれか。
  4. PN接合ダイオードの順方向電流と順方向電圧の関係として正しいものはどれか。
  5. 一般的なシリコンPN接合ダイオードの順方向電圧(電流が流れ始めるおよその電圧)はどれか。
  6. PN接合ダイオードの逆方向飽和電流と温度の関係として正しいものはどれか。
  7. ショットキーバリアダイオードの特徴として正しいものはどれか。
  8. 可変容量ダイオード(バラクタダイオード)が利用している性質はどれか。
  9. p側の不純物濃度がn側よりはるかに高いPN接合(p+n接合)で、空乏層はどのように広がるか。
  10. PN接合ダイオードを順方向から逆方向に切り替えたとき、短い時間だけ逆方向電流が流れる(逆回復時間がある)原因はどれか。
  11. PN接合の内蔵電位(拡散電位)と、両側の不純物濃度の関係として正しいものはどれか。
  12. なだれ降伏の仕組みとして正しいものはどれか。
  13. 不純物濃度が非常に高いPN接合で、低い逆電圧で起こる降伏の主な仕組みはどれか。
  14. ダイオード4個で構成するブリッジ整流回路の働きとして正しいものはどれか。
  15. フォトダイオードを光の検出に使うときの一般的な使い方として正しいものはどれか。
  16. LEDが光る仕組みとして正しいものはどれか。
  17. p層とn層の間に不純物の少ないi層を挟んだPINダイオードの特徴として正しいものはどれか。
  18. アバランシェフォトダイオード(APD)の特徴として正しいものはどれか。
  19. ダイオードの電流の式 I = Is {exp(qV / nkT) − 1} で、降伏しない範囲で逆方向に大きな電圧を加えたときに流れる電流はどうなるか。
  20. リレーのコイルなどの誘導性負荷に並列に接続するダイオード(フライホイールダイオード)の目的として正しいものはどれか。
  21. 順方向バイアスのPN接合で、注入された少数キャリアの蓄積によって生じる容量はどれか。
  22. 片側階段接合の空乏層の幅と逆バイアス電圧Vの関係として正しいものはどれか。(Vが内蔵電位より十分大きい場合)
  23. 高耐圧のPN接合で、接合の端(周辺部)にガードリングなどの終端構造を設ける目的として正しいものはどれか。
  24. 定電圧ダイオードを使った簡単な定電圧回路で、ダイオードと直列に入れる抵抗の役割として正しいものはどれか。
  25. 両側を非常に高濃度にしたPN接合で、順方向電圧を上げると電流が減る負性抵抗の領域が現れるダイオードはどれか。
  26. 結晶シリコン太陽電池のセル1枚の開放電圧の目安として正しいものはどれか。
  27. 単接合の太陽電池の理論的な変換効率の上限(ショックレー・クワイサー限界)に最も近い値はどれか。
  28. なだれ降伏の降伏電圧は、温度が上がると一般にどうなるか。
  29. PINダイオードに順方向電流を流したとき、i層に大量のキャリアが注入されて抵抗が大きく下がる現象を何と呼ぶか。
  30. PN接合の逆バイアス時の容量を、電圧を変えながら測る(C-V測定)ことで評価できるものとして正しいものはどれか。
