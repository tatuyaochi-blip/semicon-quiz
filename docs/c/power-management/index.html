電力管理(ソフトウェア制御)の要点

はじめて学ぶ人へ: スマホの中にはどんな半導体が入っている? 主なチップと役割 / ムーアの法則とは? 半導体が速く安くなってきた理由と今

スマートフォンの電池の持ちも、データセンターの電気代も、チップの電力の使い方で大きく変わります。CMOS回路の電力には、信号が切り替わるたびに消費する動的電力と、何もしなくても漏れ電流で消費する静的電力があり、それぞれに効く対策が違います。

電圧と周波数を負荷に応じて下げるDVFS、使わない回路のクロックを止めるクロックゲーティング、電源ごと切るパワーゲーティングといったハードウェアのしくみを、OSやファームウェアがどう使い分けているかを学びます。CPUのスリープ状態や性能の状態、温度が上がりすぎたときのサーマルスロットリングの考え方も扱います。

電力管理(ソフトウェア制御)の問題一覧（51問）
  1. CMOS回路の動的消費電力の式 P = αCV²f で、αが表すものとして正しいものはどれか。
  2. 活動率α=0.1、切り替わる容量C=1 nF、電源電圧V=1 V、周波数f=1 GHzの回路の動的消費電力はいくらか。
  3. 電源電圧はそのままで、クロックの周波数だけを半分にした。決まった量の計算を終えるまでに使う動的なエネルギーはどうなるか。
  4. DVFSで、電源電圧を周波数に比例して下げられるとする。周波数を半分にしたとき、動的な電力と、決まった量の計算に使う動的なエネルギーはおよそどうなるか。
  5. CMOS回路の静的消費電力(リーク電力)の説明として正しいものはどれか。
  6. チップの温度が上がると、リーク電力はどのように変わるか。また、それによって起こりうる問題はどれか。
  7. パワーゲーティングの説明として正しいものはどれか。
  8. パワーゲーティングで電源を切ったブロックについて注意すべきことと、その対策の組み合わせとして正しいものはどれか。
  9. クロックゲーティングとパワーゲーティングを比べた説明として正しいものはどれか。
  10. パワーゲーティングで、ブロックの電源のスイッチを一度に全部オンにせず、少しずつ順にオンにすることが多い理由として正しいものはどれか。
  11. パワーゲーティングで電源を切ったブロックと、動いているブロックの境目に置くアイソレーションセルの役割として正しいものはどれか。
  12. 異なる電源電圧で動く2つのブロックの間で信号を受け渡すときに入れるレベルシフタの役割として正しいものはどれか。
  13. 1つのSoCの中を複数の電源ドメインに分ける主な目的はどれか。
  14. 回路のブロックを休ませるとき、電源を切って得をするかどうかを判断する「損益分岐時間」の説明として正しいものはどれか。
  15. CPUのC-state(Cステート)の説明として正しいものはどれか。
  16. CPUのP-state(Pステート)の説明として正しいものはどれか。
  17. 「レーストゥアイドル」(速く処理を終えて早く深く休む)の考え方が省エネルギーに有利になりやすいのはどのような場合か。
  18. LinuxなどのOSでCPUの周波数を決めるガバナ(cpufreqのガバナなど)の役割として正しいものはどれか。
  19. CPUのターボ動作(ターボブーストなど)の説明として正しいものはどれか。
  20. サーマルスロットリングの説明として正しいものはどれか。
  21. CPUの電力の制限で、短い時間なら長い時間の平均の制限(TDPに近い値)を超える電力で動くことを許す設定がある。これが成り立つ理由として正しいものはどれか。
  22. IntelのRAPLのような、CPUやメモリの電力をソフトウェアから測ったり上限を設定したりする機能の用途として最も適切なものはどれか。
  23. パソコンなどで使われるACPIの説明として正しいものはどれか。
  24. スマートフォンのSoCで、高性能なコアと省電力なコアを組み合わせるとき、軽い仕事を省電力なコアで行うと消費エネルギーが少なくなる理由として正しいものはどれか。
  25. 適応電圧スケーリング(AVS)の考え方として正しいものはどれか。
  26. チップの電源電圧に余裕(マージン)を持たせる必要がある理由として当てはまらないものはどれか。
  27. CPUの電源電圧を作るレギュレータを、マザーボードの上ではなくチップやパッケージの中に置く(内蔵レギュレータ)利点として正しいものはどれか。
  28. 省電力の設計の評価で使われる「エネルギー遅延積(EDP)」が、エネルギーだけの指標より好まれることがある理由として正しいものはどれか。
  29. 入力1.8 Vから出力1.0 Vを作るリニアレギュレータ(LDO)の効率に最も近いものはどれか(レギュレータ自身の消費電流は無視する)。
  30. 容量3000 mAhの電池で、平均300 mAの電流を使う機器を動かすと、およそ何時間動くか(電池の電圧の低下などは無視する)。
  31. 電力とエネルギーの違いとして正しいものはどれか。
  32. プロセッサのエネルギーの効率を比べる指標として最も適切なものはどれか。
  33. 現在のチップで、データの移動と計算のエネルギーを比べた説明として一般的に正しいものはどれか。
  34. DRAMの省電力のための状態のうち、セルフリフレッシュの説明として正しいものはどれか。
  35. DRAMを高い温度で使うときに、リフレッシュの間隔を短くする必要があることがある。その理由と、電力への影響の組み合わせとして正しいものはどれか。
  36. マイコンで消費電力を減らすために、使っていない周辺回路(タイマやUARTなど)について行うこととして正しいものはどれか。
  37. スマートフォンなどで使われるPMIC(電源管理IC)の役割として正しいものはどれか。
  38. 複数の電源電圧を使うチップで、電源を入れる順番(パワーシーケンス)を守る必要がある理由として正しいものはどれか。
  39. 電源電圧をトランジスタのしきい値電圧に近いところまで下げて動かす「ニアスレッショルド動作」の特徴として正しいものはどれか。
  40. 電源電圧を下げていくと、1回の演算に使う全体のエネルギーがある電圧で最小になり、それより下げると逆に増える。その理由として正しいものはどれか。
  41. 消費電力50 WのCPUに、熱抵抗0.5 K/Wの冷却器を付けた。周りの空気よりチップがおよそ何℃高くなるか(ほかの熱の通り道は無視する)。
  42. 大きなチップの中に温度センサを何か所も置くことが多い理由として正しいものはどれか。
  43. AI向けの高性能なGPUを多数並べたデータセンターで、空気で冷やす方式に加えて液体で冷やす方式(液冷)が広がっている主な理由はどれか。
  44. データセンターの電力の効率を表す指標PUEの説明として正しいものはどれか。
  45. スマートフォンのSoCが、動画の再生を汎用のCPUではなく専用の動画デコーダの回路で行う主な理由はどれか。
  46. OSが、多くのプログラムのタイマの起き上がる時刻を少しずつずらしてそろえる(タイマのまとめ)理由として正しいものはどれか。
  47. LinuxなどのOSで使われるティックレス(tickless)カーネルの考え方として正しいものはどれか。
  48. ArmのプロセッサのWFI(Wait For Interrupt)命令の使い道として正しいものはどれか。
  49. 電池で動く機器を、スリープの状態から決まった時刻に起こすのによく使われるものはどれか。
  50. 電源電圧だけを10%下げたとき(ほかの条件は同じとする)、動的消費電力はおよそ何%減るか。
  51. 電力の上限が8 kWのラックに、最大で500 Wを使うサーバを並べる。各サーバにパワーキャップで400 Wの上限を設けると、ラックに置けるサーバの台数はどうなるか(ほかの機器の電力は無視する)。

この分野の比較

  • 静的消費電力と動的消費電力の違い：原因・式・温度依存・削減方法を比較CMOS回路の静的消費電力(リーク電力)と動的消費電力を、原因・式・電源電圧と周波数への依存・温度依存・削減方法・微細化(スケーリング)での変化の観点で表にして比較し、待機中と動作中で効く対策の違いも説明します。
  • クロックゲーティングとパワーゲーティングの違い：減らす電力・復帰時間・状態の保持・回路を比較クロックゲーティングとパワーゲーティングを、減らす電力(動的か静的か)・止めるもの・復帰の時間・状態の保持・必要な回路(ICG、電源スイッチ、アイソレーションセル)・細かさの観点で比較します。
