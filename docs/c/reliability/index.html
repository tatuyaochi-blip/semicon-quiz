信頼性の要点

信頼性は、製品が決められた条件で決められた期間、機能を保ち続ける能力です。故障率の時間変化は、初期故障期・偶発故障期・摩耗故障期からなるバスタブ曲線で表されます。

半導体特有の故障メカニズムには、配線のエレクトロマイグレーション、ゲート絶縁膜の経時破壊(TDDB)、トランジスタ特性の劣化などがあります。加速試験によって短期間で寿命を見積もります。

信頼性の問題一覧（30問）

  1. 故障率の時間変化を表すバスタブ曲線を構成する3つの期間の組み合わせとして正しいものはどれか。
  2. エレクトロマイグレーションの説明として正しいものはどれか。
  3. MTBF(平均故障間隔)の説明として正しいものはどれか。
  4. 温度を上げて寿命試験の時間を短縮する加速試験で、温度と寿命の関係を表すためによく使われるモデルはどれか。
  5. TDDB(経時絶縁破壊)の説明として正しいものはどれか。
  6. 故障率の単位FITの意味として正しいものはどれか。
  7. 温度サイクル試験で主に評価する故障はどれか。
  8. ESD(静電気放電)対策としてLSIの入出力端子に設けるものはどれか。
  9. pMOSトランジスタに負のゲート電圧と高温が加わり続けると、しきい値電圧の絶対値が徐々に増加していく劣化現象はどれか。
  10. CMOS回路のラッチアップの説明として正しいものはどれか。
  11. ドレイン近くの高電界で加速されたキャリアがゲート絶縁膜に注入され、トランジスタの特性が劣化する現象はどれか。
  12. 高温高湿バイアス試験(THBやHAST)で主に評価する故障はどれか。
  13. 信頼性データの解析によく使われ、形状パラメータの値によって初期故障型・偶発故障型・摩耗故障型を表せる分布はどれか。
  14. 電流が流れていなくても、配線内部の応力によって金属原子が移動し、ボイドが発生する現象はどれか。
  15. スズめっきの表面から針状の金属結晶が成長し、隣の端子と短絡する現象を何と呼ぶか。
  16. 製品を高温で長時間動作させ、寿命や故障率を評価する代表的な信頼性試験はどれか。
  17. 活性化エネルギー0.7 eVの故障メカニズムについて、アレニウスモデルで55 ℃に対する125 ℃の加速係数を求めるとおよそいくらか。(ボルツマン定数 8.6×10⁻⁵ eV/K)
  18. 故障解析を行うときの一般的な進め方として正しいものはどれか。
  19. 金ワイヤとアルミパッドの接合部で、高温で長時間保存すると金属間化合物やボイドが成長して接合強度が低下する現象の通称はどれか。
  20. 宇宙線に由来する中性子によるソフトエラーの発生率が高くなる環境として正しいものはどれか。
  21. 車載用の集積回路の信頼性試験の基準として広く使われている規格はどれか。
  22. 故障率λが一定のとき、時間tまで故障しない確率(信頼度)R(t)を表す式はどれか。
  23. 故障率が一定で1×10⁻⁵ /時間の部品の平均故障時間(MTTF)はいくらか。
  24. 信頼度0.9の部品を2つ並列に接続し、どちらか一方が動作すれば機能するシステムの信頼度はいくらか。
  25. 信頼度0.9の部品を2つ直列に接続し、両方が動作しないと機能しないシステムの信頼度はいくらか。
  26. TDDBの寿命評価で、実際の使用電圧より高い電圧をかけて試験する理由として正しいものはどれか。
  27. スマートフォンなどの携帯機器で、はんだ接合部の信頼性の評価として特に重視される試験はどれか。
  28. エレクトロマイグレーションで配線にヒロック(突起)が生じたときに起こりうる故障はどれか。
  29. 非常に低い故障率を統計的に保証するための信頼性試験の条件として適切なものはどれか。
  30. 薄いゲート酸化膜で、完全に絶縁が失われる前に、リーク電流が段階的に増える軽い破壊を何と呼ぶか。
