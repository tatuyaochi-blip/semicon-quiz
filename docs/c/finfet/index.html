先端トランジスタ(FinFET・GAA)の要点

トランジスタを微細化すると、ゲートがチャネルを制御しにくくなる短チャネル効果が問題になります。そこで、チャネルを立体的なフィン形状にしてゲートで3方向から囲むFinFETが登場し、さらにチャネルの全周を囲むGAA(ゲートオールアラウンド)へと進化しています。

ゲートリークを抑えるHigh-k/メタルゲートや、移動度を高めるひずみ技術も、先端トランジスタを支える重要な技術です。
