システム構成と信頼性設計の要点

情報システムは、1台のコンピュータの性能だけでなく、機器をどう組み合わせ、故障したときにどう処理を続けるかで、使いやすさと止まりにくさが大きく変わります。半導体工場の製造実行システム(MES)や装置のデータを集めるサーバのように、止まると生産に直接影響するシステムでは、この設計が特に重要です。

クライアントサーバ、3層クライアントサーバ、ピアツーピア、バッチ処理とオンライン処理などのシステムの構成、デュアルシステムとデュプレックスシステム、ホットスタンバイやクラスタ、単一障害点といった冗長化の考え方を学びます。さらに、RAIDの容量と耐えられる故障の台数、バックアップの復元の手順、RPOとRTO、フェールセーフなどの信頼性の設計、IaaS・PaaS・SaaSやライブマイグレーション、SAN・NAS、PUEやUPS、必要なサーバの台数の見積もりを、計算問題を交えて扱います。基本情報技術者試験・応用情報技術者試験のシステム構成要素の分野の学習にも役立ちます。

システム構成と信頼性設計の問題一覧（40問）
  1. クライアントサーバシステムの説明として、適切なものはどれか。
  2. 3層クライアントサーバシステムで、業務の処理(ビジネスロジック)を担当する層はどれか。
  3. シンクライアントの説明として、適切なものはどれか。
  4. ピアツーピア(P2P)型のシステムの特徴として、適切なものはどれか。
  5. 集中処理と比べた分散処理の特徴として、適切なものはどれか。
  6. バッチ処理で行うのが適している処理はどれか。
  7. オンライン処理のシステムの性能を評価する指標のうち、レスポンスタイム(応答時間)の説明として、適切なものはどれか。
  8. 利用者の要求を、Webサーバ層、アプリケーションサーバ層、データベースサーバ層の順に処理するシステムがある。各要求は3つの層をそれぞれ1回ずつ通り、各層が処理できる最大の件数は、Webサーバ層が毎秒1,200件、アプリケーションサーバ層が毎秒1,000件、データベースサーバ層が毎秒900件である。データベースサーバ層を増強して毎秒1,500件を処理できるようにしたとき、システム全体で処理できる最大の件数として、正しいものはどれか。
  9. デュアルシステムの説明として、適切なものはどれか。
  10. 半導体工場の製造実行システム(MES)のサーバを、主系(現用系)と待機系からなるデュプレックスシステムにする。待機系をホットスタンバイにしたときの特徴として、適切なものはどれか。
  11. 2台のロードバランサ(負荷分散装置)を冗長化し、その配下にWebサーバを3台置き、すべてのWebサーバが1台のデータベースサーバを使うシステムがある。ここに挙げた機器のうち、単一障害点(そこが止まるとシステム全体が止まる箇所)となっているものはどれか。
  12. 5台のサーバで処理を均等に分け合うアクティブ/アクティブ構成のクラスタがある。使用率は処理の量に比例するものとする。1台が故障したときに残りの4台で処理を均等に引き継いでも、各サーバの使用率を80%以下に保ちたい。平常時(5台とも動作中)の各サーバの使用率の上限として、正しいものはどれか。
  13. 稼働率0.95のサーバを3台用意し、そのうち2台以上が動いていれば必要な処理能力を確保できるシステムがある。サーバは互いに独立に故障し、サーバ以外の機器の故障は考えないものとする。このシステムの稼働率として、正しいものはどれか。
  14. フェールソフトの考え方に基づく設計の例として、適切なものはどれか。
  15. 半導体製造装置で、空気圧で開く常時閉(ノーマリクローズ)形のガス供給バルブを使い、停電や圧縮空気の喪失が起きたときには、バルブが閉じて危険なガスの供給が止まるようにしている。この設計の考え方はどれか。
  16. フールプルーフの考え方に基づく設計の例として、適切なものはどれか。
  17. システムの信頼性を高める考え方のうち、フォールトアボイダンスに当たるものはどれか。
  18. RAID1の説明として、適切なものはどれか。
  19. 容量4 TBのディスク4台でRAID5を構成した。データを記録できる容量として、正しいものはどれか。
  20. 容量8 TBのディスク6台でRAID6を構成した。データを記録できる容量と、データを失わずに耐えられる同時に故障するディスクの台数の組合せとして、正しいものはどれか。
  21. 4台のディスクで構成したRAID10(2台ずつのミラーを2組作り、その2組にストライピングする)で、4台のうち2台が同時に故障した。どの2台が故障するかは等しい確率で起こるとき、データが失われる確率として、正しいものはどれか。
  22. 1台あたり毎秒200回のランダムな入出力(IOPS)ができるディスク4台でRAID5を構成した。小さなデータのランダムな書き込みを1回行うたびに、旧データと旧パリティの読み出し、新データと新パリティの書き込みの合わせて4回の入出力が必要になるとし、キャッシュの効果は考えない。書き込みだけを行うとき、RAID5全体で処理できる書き込みの回数として、正しいものはどれか。
  23. 差分バックアップの説明として、適切なものはどれか。
  24. 毎週日曜日の夜にフルバックアップを取り、月曜日から土曜日までは毎晩、増分バックアップを取っている。木曜日の昼に障害が起き、水曜日の夜のバックアップの時点までデータを戻すことにした。復元に使うバックアップの数として、正しいものはどれか。
  25. データ全体が500 GBのシステムで、毎週日曜日にフルバックアップを取り、月曜日から土曜日までは毎晩、差分バックアップを取る。毎日、それまで変更されていなかった別のデータが20 GBずつ変更されるものとする。月曜日から土曜日までの6回の差分バックアップの容量の合計として、正しいものはどれか。
  26. 事業継続の計画でいうRPO(目標復旧時点)の説明として、適切なものはどれか。
  27. あるシステムで、RPO(目標復旧時点)を4時間、RTO(目標復旧時間)を2時間と定めた。障害はいつでも起こりうるものとし、バックアップの取得にかかる時間は無視できるものとする。この目標を満たすデータの保護の方式として、適切なものはどれか。
  28. 1,000 km離れた2か所のデータセンターの間で、データベースの更新を同期レプリケーションする。更新のたびに、もう一方への転送と書き込み完了の通知の1往復の通信を待つとする。光ファイバの中の光の速さを約20万 km/sとし、ファイバの経路の長さは直線の距離と同じとみなすとき、通信の伝搬だけで1回の更新の応答時間が増える量として、最も近いものはどれか。
  29. クラウドサービスのIaaSで、一般に利用者が自分で管理するものはどれか。
  30. システムの処理能力を高める方法のうち、スケールアウトに当たるものはどれか。
  31. 負荷に応じてサーバの台数を自動で増減するオートスケールを使うシステムの設計として、一般に望ましいものはどれか。
  32. 仮想化の環境でのライブマイグレーションの説明として、適切なものはどれか。
  33. CDN(コンテンツデリバリネットワーク)の説明として、適切なものはどれか。
  34. 半導体工場で、多数の製造装置から高い頻度で集まるセンサのデータを使って、異常をすぐに検知したい。データをすべて遠くのクラウドに送って処理するのではなく、装置の近くに置いたコンピュータで処理するエッジコンピューティングを用いる主な利点として、適切なものはどれか。
  35. ストレージの接続の方式のうち、SAN(ストレージエリアネットワーク)の説明として、適切なものはどれか。
  36. 物理容量が100 TBのストレージプールから、シンプロビジョニングで論理容量5 TBのボリュームを30個作った。いま、各ボリュームには平均して論理容量の40%のデータが書き込まれており、データは毎週合計2 TBずつ増えている。データの削除や圧縮は考えないとき、プールの使用率が80%に達する時期として、正しいものはどれか。
  37. IT機器の消費電力が800 kW、冷却の設備の消費電力が280 kW、電源の設備の損失と照明などが120 kWのデータセンターがある。冷却の方式を改善して、冷却の設備の消費電力だけを半分にしたとき、PUEとして、正しいものはどれか。
  38. データセンターで、UPS(無停電電源装置)と自家発電設備を組み合わせて使う理由として、適切なものはどれか。
  39. データセンターのサーバラックの配置で使われる、ホットアイル/コールドアイルの考え方として、適切なものはどれか。
  40. ピーク時に毎秒1,800件の要求を処理する必要があるWebシステムを設計する。サーバ1台が処理できるのは最大で毎秒250件で、各サーバの使用率は70%以下に抑えたい。さらに、サーバが1台故障しても、残りのサーバでこの条件を満たすようにする(N+1構成)。負荷は均等に分散されるとき、必要なサーバの最少の台数として、正しいものはどれか。
