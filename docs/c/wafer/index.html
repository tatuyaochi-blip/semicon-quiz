シリコンウエハの要点

半導体デバイスの多くは、高純度の単結晶シリコンを薄く切り出したウエハの上につくられます。単結晶の製法には、るつぼで溶かしたシリコンから結晶を引き上げるCZ法と、るつぼを使わないFZ法があります。

引き上げた結晶はスライス・研磨・洗浄を経てウエハになります。口径は大きくなり続け、先端の量産ラインでは300 mmウエハが主流です。

シリコンウエハの問題一覧（50問）
  1. LSI用の単結晶シリコンの製造で最も広く使われている方法はどれか。
  2. 現在、最先端のロジックやメモリの量産ラインで主流となっているウエハの直径はどれか。
  3. FZ法(フローティングゾーン法)で作製したシリコン単結晶の特徴として正しいものはどれか。
  4. シリコンウエハの外周に設けるノッチ(小さな切り欠き)の主な役割はどれか。
  5. ゲッタリングの説明として正しいものはどれか。
  6. CZ法で育成したシリコン結晶に、るつぼから比較的多く取り込まれる不純物はどれか。
  7. 単結晶インゴットからウエハをつくる工程の順序として最も適切なものはどれか。
  8. SOIウエハの代表的な製造方法として正しいものはどれか。
  9. CMOS LSI用のシリコンウエハで一般的に使われる面方位はどれか。
  10. シリコンウエハの抵抗率と、添加した不純物濃度の関係として正しいものはどれか。
  11. 300 mmシリコンウエハの標準的な厚さに最も近いものはどれか。
  12. CZ法で、結晶の引き上げ速度と結晶中の温度勾配の比(V/G)を制御する主な目的はどれか。
  13. 高純度の多結晶シリコンの代表的な製造方法はどれか。
  14. 装置の状態確認や膜厚の測定などのために、製品とは別に工程に流すウエハを何と呼ぶか。
  15. シリコンウエハに高い平坦度が求められる主な理由として正しいものはどれか。
  16. シリコンのインゴットを、一度に多数のウエハにスライスするために一般的に使われる装置はどれか。
  17. ウエハの外周を面取り(ベベル加工)する主な目的はどれか。
  18. CZ法でp型のシリコン結晶をつくるとき、融液に添加する代表的な不純物はどれか。
  19. CZ法で不純物を添加した結晶を引き上げると、結晶の下部(引き上げの後半)ほど不純物濃度が高くなる傾向がある。その理由として正しいものはどれか。
  20. 300 mmの次の口径として開発が進められた450 mmウエハについての説明として適切なものはどれか。
  21. CZウエハの内部で、酸素が析出してできる微小な欠陥(BMD)を利用する目的として正しいものはどれか。
  22. ウエハを熱処理して表面付近の酸素を外に拡散させ、デバイスをつくる表面に欠陥の少ない層をつくる。この層を何と呼ぶか。
  23. ウエハの表面や裏面に刻むレーザーマーク(IDマーク)の目的はどれか。
  24. 300 mmウエハで一般的な研磨の方法として正しいものはどれか。
  25. 使用済みのモニターウエハの表面の膜などを除去し、研磨し直して再び使えるようにしたものを何と呼ぶか。
  26. ウエハの抵抗率を非接触で測定する方法として使われるものはどれか。
  27. FZシリコンに中性子を照射し、シリコンの一部をリンに変換して均一なn型にする方法はどれか。
  28. CZ法で、るつぼに磁場をかけて融液の対流を抑え、酸素濃度などを制御する方法はどれか。
  29. シリコン単結晶インゴットの直径を一定に保つため、引き上げ中に主に調整する条件はどれか。
  30. SiCウエハの製造が難しく、高価である理由の一つとして正しいものはどれか。
  31. 直径300 mmのシリコンウエハは、インチで表すとおよそ何インチと呼ばれるか。
  32. CZ法などで育成した、ウエハに切り出す前の円柱状の単結晶シリコンの塊を何と呼ぶか。
  33. シリコンウエハが円形をしている主な理由として正しいものはどれか。
  34. シリコンウエハの世界市場で大きなシェアをもつ日本の企業の組み合わせとして正しいものはどれか。
  35. CZ法の引き上げの初めに、種結晶の直後を細く絞って成長させる(ネッキング)目的はどれか。
  36. 大口径のウエハを高温で熱処理するときに問題となる「スリップ」の原因として正しいものはどれか。
  37. 直径300 mm、厚さ775 µmのシリコンウエハ1枚の質量に最も近いものはどれか。(シリコンの密度は約2.33 g/cm³)
  38. 太陽電池用の多結晶シリコンのインゴットを、低コストで大量につくるのに使われてきた方法はどれか。
  39. CZ法で単結晶を引き上げ終えるとき、インゴットの直径を少しずつ細くして(テールを絞って)融液から切り離す主な理由はどれか。
  40. CZ法で育成したシリコン結晶に含まれる格子間酸素の濃度の目安として最も近いものはどれか。
  41. シリコンウエハの鏡面研磨(CMPによる仕上げ研磨)で、研磨液の砥粒として一般的に使われるものはどれか。
  42. ヒ素やアンチモンを高濃度に添加した低抵抗のn⁺シリコンウエハの主な用途として正しいものはどれか。
  43. CZシリコンを450℃付近で熱処理すると、酸素原子が集まってドナーとして働き、ウエハの抵抗率が変わることがある。これを何と呼ぶか。
  44. ウエハ表面の金属汚染を高感度に分析するため、フッ酸の蒸気で表面の酸化膜を溶かし、液滴で回収して分析装置にかける前処理の方法はどれか。
  45. ウエハの表面にある、波長が数mm程度の非常にゆるやかで高さ数十nm程度の凹凸を何と呼ぶか。
  46. CZシリコンに含まれる格子間酸素が、FZシリコンに比べてウエハの機械的強度に与える影響として正しいものはどれか。
  47. CZ結晶の育成中に窒素を微量に添加する(窒素ドープ)ことの効果として知られているものはどれか。
  48. シリコン結晶中の転位や積層欠陥などを光学顕微鏡で観察できるようにするため、欠陥の部分を選択的に浅くエッチングする方法はどれか。
  49. CZ結晶で、結晶の成長界面の温度のゆらぎなどによって生じる、ドーパントや酸素の濃度の周期的な縞状の変化を何と呼ぶか。
  50. シリコン単結晶が最も割れやすい(へき開しやすい)結晶面はどれか。
