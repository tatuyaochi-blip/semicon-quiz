半導体物性の要点

半導体の性質は、価電子帯と伝導帯のあいだのエネルギー差であるバンドギャップで大きく決まります。シリコンのバンドギャップは室温で約1.12 eVで、絶縁体ほど大きくなく、金属のようにゼロでもありません。

不純物を添加すると、電子が多いn型や正孔が多いp型の半導体になります。キャリア密度の温度依存性、移動度、ドリフト電流と拡散電流の違いは、あとに学ぶデバイスの動作を理解する土台になります。

半導体物性の問題一覧（50問）
  1. 室温におけるシリコン(Si)のバンドギャップに最も近い値はどれか。
  2. シリコンにリン(P)を不純物として添加したときの説明として正しいものはどれか。
  3. 真性半導体の温度を上げたとき、真性キャリア密度はどうなるか。
  4. シリコンにおける電子と正孔の移動度の比較として正しいものはどれか。
  5. n型半導体のフェルミ準位の位置として正しいものはどれか。
  6. 真性半導体の抵抗率の温度依存性として正しいものはどれか。
  7. 熱平衡状態の半導体における電子密度nと正孔密度pの積(n×p)として正しいものはどれか。(ni:真性キャリア密度)
  8. 半導体中で拡散電流が流れる原因として正しいものはどれか。
  9. シリコン中の少数キャリアのライフタイム(寿命)を短くする要因として代表的なものはどれか。
  10. シリコン単結晶の結晶構造はどれか。
  11. 移動度1000 cm²/V·sの電子に、100 V/cmの電界をかけたときのドリフト速度はいくらか。
  12. 結晶中の電子の運動を、外力に対する応答から自由電子と同じように扱うために導入される質量を何と呼ぶか。
  13. フェルミ準位の意味として正しいものはどれか。
  14. ドナー濃度1×10¹⁶ cm⁻³のn型シリコン(ドナーはすべてイオン化、真性キャリア密度ni = 1×10¹⁰ cm⁻³)の正孔密度はおよそいくらか。
  15. シリコンが吸収できる光として正しいものはどれか。
  16. シリコンのバンド構造の種類として正しいものはどれか。
  17. ホール効果の測定から分かることとして正しいものはどれか。
  18. 不純物濃度が非常に高く、フェルミ準位が伝導帯や価電子帯の中に入り込んだ半導体を何と呼ぶか。
  19. 半導体のキャリアの拡散係数Dと移動度μの関係を表すアインシュタインの関係式はどれか。(k:ボルツマン定数、T:絶対温度、q:電気素量)
  20. 室温(300 K)における熱電圧 kT/q の値に最も近いものはどれか。
  21. シリコン中のリンがつくるドナー準位の、バンドギャップ内での位置として正しいものはどれか。
  22. ドナー濃度5×10¹⁶ cm⁻³とアクセプタ濃度2×10¹⁶ cm⁻³の両方を含むシリコン(室温、すべてイオン化)の性質として正しいものはどれか。
  23. n型シリコンを極低温まで冷やしたとき、キャリア密度が大きく減少する理由として正しいものはどれか。
  24. キャリア濃度が高いときに顕著になる再結合で、再結合で放出されたエネルギーが光ではなく別のキャリアに与えられる過程はどれか。
  25. 電子密度1×10¹⁶ cm⁻³、電子の移動度1000 cm²/V·sのn型シリコンの抵抗率はおよそいくらか。(正孔の寄与は無視、電気素量1.6×10⁻¹⁹ C)
  26. 半導体の真空準位から伝導帯の下端までのエネルギー差を何と呼ぶか。
  27. 不純物濃度の低いシリコンで、温度が上がると移動度が下がる主な理由はどれか。
  28. 室温におけるシリコンの真性キャリア密度に最も近い値はどれか。
  29. シリコン結晶の原子密度に最も近い値はどれか。
  30. 正孔(ホール)の説明として正しいものはどれか。
  31. 室温におけるゲルマニウム(Ge)のバンドギャップに最も近い値はどれか。
  32. シリコン原子1個がもつ価電子(最外殻電子)の数はいくつか。
  33. シリコンにホウ素(B)を不純物として添加したときの説明として正しいものはどれか。
  34. p型半導体の多数キャリアはどれか。
  35. 次の材料のうち、バンドギャップが最も大きいものはどれか。
  36. キャリアの移動度の単位として正しいものはどれか。
  37. 電子密度n、正孔密度p、電子の移動度μn、正孔の移動度μp、電荷素量qのとき、半導体の導電率σを表す式はどれか。
  38. 禁制帯の中にできた深い準位(トラップ)を介して電子と正孔が再結合する過程を何と呼ぶか。
  39. 少数キャリアの拡散係数をD、ライフタイムをτとしたとき、拡散長Lを表す式はどれか。
  40. シリコンのバンドギャップは、温度が上がるとどうなるか。
  41. シリコン中の電子に強い電界を加えたとき、ドリフト速度はどうなるか。
  42. 波長620 nmの光の光子1個がもつエネルギーに最も近い値はどれか。(E [eV] ≈ 1240 / λ [nm])
  43. シリコンの不純物濃度を高くすると、キャリアの移動度は一般にどうなるか。
  44. 物質の仕事関数の定義として正しいものはどれか。
  45. シリコンの比誘電率に最も近い値はどれか。
  46. 不純物の少ないシリコンの室温における電子の移動度に最も近い値はどれか。
  47. シリコンのような間接遷移型の半導体で、電子と正孔が再結合して光を出す確率が低い理由として正しいものはどれか。
  48. 光の照射や電流の注入によって熱平衡から外れた半導体で、電子密度と正孔密度をそれぞれ表すために導入される準位を何と呼ぶか。
  49. シリコン結晶の格子定数に最も近い値はどれか。
  50. シリコンの真性フェルミ準位が、バンドギャップのちょうど中央からわずかにずれる理由として正しいものはどれか。

この分野の比較

  • 直接遷移型と間接遷移型の半導体の違い：バンド構造・発光効率・光吸収・材料を比較直接遷移型と間接遷移型の半導体を、バンド構造・フォノンの関与・発光効率・キャリアの寿命・光の吸収の深さ・代表的な材料・用途の観点で表にして比較します。
  • n型半導体とp型半導体の違い：ドーパント・多数キャリア・フェルミ準位・移動度を比較n型とp型の半導体を、添加する不純物(ドナーとアクセプタ)・多数キャリア・不純物準位・フェルミ準位の位置・移動度と抵抗率・デバイスで使われる場所の観点で表にして比較します。
  • 導体・半導体・絶縁体の違い：バンドギャップ・抵抗率・温度特性を比較導体(金属)・半導体・絶縁体を、バンド構造・バンドギャップ・抵抗率・キャリアの数・温度や光による変化・代表的な材料・デバイスでの役割の観点で表にして比較します。
  • 真性半導体と不純物半導体の違い：キャリア・フェルミ準位・温度特性を比較不純物を含まない真性半導体と、ドナーやアクセプタを加えた不純物半導体(外因性半導体、n型・p型)を、キャリアの起源と密度・フェルミ準位・抵抗率・温度による変化・用途の観点で表にして比較します。
