リソグラフィの要点

リソグラフィは、マスク(レチクル)の回路パターンを光でウエハ上のフォトレジストに転写する工程です。微細化の限界を決める重要な工程で、露光装置は半導体製造装置のなかでも特に高度な装置です。

解像度は、露光波長λを短くし、レンズの開口数NAを大きくするほど向上します。ArFエキシマレーザー(193 nm)の液浸露光や、波長13.5 nmのEUV露光が先端品の製造に使われています。
