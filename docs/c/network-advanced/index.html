ネットワークの設計と運用の要点

はじめて学ぶ人へ: インターネットはどうやってデータを届けるの? パケットとルータ / IPアドレスとは? ネットの住所のしくみとIPv4・IPv6

会社やデータセンターのネットワークでは、スイッチとルータを冗長につなぎ、VLANで区切り、複数の経路から最適なものを選び、障害が起きても通信が止まらないように設計します。そのうえで、DHCPやDNS、NATやACLといったサービスを組み合わせ、通信量や障害を監視しながら運用します。

この分野は「ネットワークの基礎」の次の段階として、L2スイッチのMACアドレスの学習、IEEE 802.1QのタグとトランクポートとVLAN間ルーティング、STP・RSTPによるループの防止、リンクアグリゲーション、VLSMと経路集約の計算、ロンゲストマッチ、静的経路とアドミニストレーティブディスタンス、距離ベクトル型とリンクステート型、OSPFのコストの計算、BGPとAS、VRRPを扱います。さらに、DHCPリレー、DNSの再帰的な問い合わせとTTL、ポート転送、ACLの評価の順序、IPv6のSLAACとEUI-64、トンネル、traceroute、IPv4のフラグメント、経路MTU探索、QoSとキューイング、SNMP・syslog・NetFlow、層ごとの障害の切り分けを、計算やトレースの問題で学びます。応用情報技術者試験やネットワークスペシャリスト試験の入門の学習にも役立ちます。

ネットワークの設計と運用の問題一覧（40問）
  1. L2スイッチがフレームを受け取ったときに、MACアドレステーブルに登録する情報として正しいものはどれか。
  2. MACアドレステーブルが空のL2スイッチのポート1〜4に機器がつながっており、すべて同じVLANに属する。ポート1につながるPC-Aが、ポート2につながるPC-B宛てのフレームを送り、続いてPC-BがPC-A宛てに返信のフレームを送った。2つのフレームの転送のされ方として正しいものはどれか。
  3. ルータの一方のインターフェースにL2スイッチをつなぎ、そのスイッチに4台のPCをつないだ。ルータのもう一方のインターフェースにはリピータハブをつなぎ、そのハブに3台のPCをつないだ。VLANは使っていない。コリジョンドメインを、半二重のイーサネットでフレームの衝突が起こりうる範囲として数えるとき、ブロードキャストドメインとコリジョンドメインの数の組み合わせとして正しいものはどれか。
  4. IEEE 802.1Qのタグに入るVLAN IDは12ビットで、そのうち0と4095は特別な用途のために予約されている。VLANの識別に使えるVLAN IDの数はどれか。
  5. 2台のスイッチSW1とSW2の両方に、VLAN 10とVLAN 20のポートがある。2台を1本のケーブルでつなぎ、同じVLANどうしならスイッチをまたいで通信できるようにしたい。つなぐポートの設定として適切なものはどれか。
  6. スイッチを冗長な経路でつないだネットワークで、スパニングツリープロトコル(STP)が果たす役割として正しいものはどれか。
  7. STPで、3台のスイッチのブリッジIDが次のように分かっている。SW1は優先度32768、MACアドレス 00-00-5E-00-53-01、SW2は優先度61440、MACアドレス 00-00-5E-00-53-05、SW3は優先度4096、MACアドレス 00-00-5E-00-53-0A である。ルートブリッジに選ばれるスイッチはどれか。
  8. 3台のスイッチSW1、SW2、SW3を、互いに1本ずつのリンクで三角形につないだ。STPのルートブリッジはSW1で、ブリッジIDはSW2の方がSW3より小さい。どのリンクもパスコストは同じとする。ブロックされる(フレームを転送しない)ポートはどれか。
  9. 従来のSTP(IEEE 802.1D)は、既定のタイマーのままでは、障害の後にブロックされていたポートが転送を始めるまでに30〜50秒ほどかかる。RSTPが切り替えを速くしたしくみとして正しいものはどれか。
  10. 2台のスイッチの間の1 Gbpsのリンク4本を、リンクアグリゲーションで1本の論理的なリンクに束ねた。フレームは、送信元と宛先のアドレスやポート番号の組み合わせ(フロー)ごとに、どのリンクで送るかを決める一般的な方式で振り分ける。1つのTCPコネクションで得られるスループットの上限に最も近いものはどれか。
  11. VLAN 10(192.168.10.0/24)とVLAN 20(192.168.20.0/24)をもつL2スイッチにルータを1本のリンクでつなぎ、2つのVLANの間で通信できるようにしたい。この構成の設定として適切なものはどれか。
  12. 2台のルータR1(192.168.1.2)とR2(192.168.1.3)でVRRPを構成し、仮想IPアドレスを 192.168.1.254 とした。ふだんはR1がマスタとして転送している。LANの端末のデフォルトゲートウェイに設定するアドレスとして適切なものはどれか。
  13. 192.168.10.0/24 を、拠点A(ホスト100台)、拠点B(50台)、拠点C(25台)のサブネットに分ける。必要なホストの数の多い拠点から順に、そのホストを収容できる最も小さいサブネットを、アドレスの小さい方から詰めて割り当てる。拠点Cに割り当てるサブネットはどれか。
  14. 次の3組は、いずれも連続する4つの /24 のネットワークである。4つの経路を、含まないアドレスを含めずに、ちょうど1つの /22 の経路にまとめられる組はどれか。
  15. ルータの経路表に、172.16.0.0/12(次の転送先はルータB)、172.16.32.0/19(ルータA)、172.16.48.0/20(ルータC)、0.0.0.0/0(ルータD)の4つの経路がある。宛先が 172.16.45.10 のパケットが送られるルータはどれか。
  16. 支社のルータR2は、本社のルータR1と 10.255.0.0/30 のリンクでつながっており、R1側のアドレスは 10.255.0.1、R2側は 10.255.0.2 である。R2に、本社のネットワーク 192.168.1.0/24 への静的経路を設定するとき、次の転送先(ネクストホップ)に指定するアドレスとして適切なものはどれか。
  17. あるルータは、同じ宛先 192.168.50.0/24 への経路を、OSPFとRIPの両方から学んだ。このルータでは、経路の情報源ごとの優先度を表すアドミニストレーティブディスタンス(値が小さいほど優先)が、OSPFは110、RIPは120である。経路表に入る経路として正しいものはどれか。
  18. ルータの経路表に、静的経路の 10.0.0.0/8(次の転送先はルータA、アドミニストレーティブディスタンス1)、OSPFで学んだ 10.1.0.0/16(ルータB、110)、RIPで学んだ 10.1.1.0/24(ルータC、120)の3つが入っている。宛先が 10.1.1.5 のパケットが送られるルータはどれか。
  19. リンクステート型のルーティングプロトコルの説明として正しいものはどれか。
  20. OSPFで、ルータR1からR4の先にあるネットワークへの経路が3つある。経路Aは R1–R5 が10 Gbps、R5–R4 が1 Gbpsのリンク、経路Bは R1–R4 を直接つなぐ100 Mbpsのリンク、経路Cは R1–R2、R2–R3、R3–R4 がすべて1 Gbpsのリンクである。各リンクのコストを「参照帯域幅10 Gbps ÷ リンクの帯域幅」とし、R4から先のコストはどの経路でも同じとする。R1が選ぶ経路はどれか。
  21. インターネットで、プロバイダなどの組織が管理するネットワークの単位(AS、自律システム)の間で経路の情報をやり取りし、通ってきたASの並び(AS_PATH)などの属性と、組織ごとの方針(ポリシー)に基づいて経路を選ぶプロトコルはどれか。
  22. VLAN 20(192.168.20.0/24)の端末に、別のネットワークにあるDHCPサーバ 10.0.0.5 からアドレスを割り当てる。そのため、VLAN 20のデフォルトゲートウェイであるL3スイッチのインターフェース(192.168.20.1)に、DHCPリレーエージェントを設定した。リレーエージェントの動作として正しいものはどれか。
  23. あるドメイン宛ての電子メールを受け取るメールサーバを指定する、DNSのリソースレコードはどれか。
  24. DNSの名前解決での、再帰的な問い合わせと非再帰的な(反復的な)問い合わせの使われ方として正しいものはどれか。
  25. Webサーバの引っ越しで、www.example.com のAレコードのIPアドレスを変更する。このレコードのTTLは現在86400秒で、変更の後に古いアドレスが使われる時間を最大でも5分程度にしたいので、事前にTTLを300秒に下げておく。リゾルバはTTLのとおりにキャッシュするものとする。TTLを下げる設定を行う期限として正しいものはどれか。
  26. NAPTを行うルータ(外側のアドレスは 198.51.100.7)に、「外側のTCP 8080番ポートに届いた通信を、内側のWebサーバ 192.168.1.20 の80番ポートへ転送する」というポート転送(宛先だけを変換する静的な設定)を行った。インターネット上の端末 203.0.113.9 が、送信元ポート51000で 198.51.100.7 の8080番ポートに接続したとき、Webサーバが受け取るパケットの宛先と送信元の組み合わせはどれか。
  27. ルータのインターフェースに、入ってくるパケットを上から順に調べるACLを設定した。規則1は「宛先 10.0.0.10 のTCP 443番ポートへの通信を許可」、規則2は「送信元が 192.168.1.0/24 の通信をすべて拒否」、規則3は「送信元が 192.168.0.0/16 で、宛先がTCP 80番ポートの通信を許可」で、ほかに規則はない。ア「192.168.1.5 から 10.0.0.10 のTCP 443番ポートへ」、イ「192.168.1.5 から 10.0.0.20 のTCP 80番ポートへ」、ウ「192.168.2.5 から 10.0.0.20 のTCP 80番ポートへ」、エ「192.168.2.5 から 10.0.0.20 のTCP 22番ポートへ」の4つのパケットのうち、通過できるものをすべて挙げたものはどれか。
  28. IPv6で、同じリンクの中だけで使われ、IPv6を使うインターフェースには必ず自動的に設定されるリンクローカルアドレスの範囲はどれか。
  29. IPv6のSLAAC(ステートレスアドレス自動設定)で、端末がグローバルユニキャストアドレスを作る方法として正しいものはどれか。
  30. MACアドレスが 00-1A-2B-3C-4D-5E のインターフェースが、プレフィックス 2001:db8:1:1::/64 と、EUI-64形式のインターフェースIDから、SLAACでアドレスを作る。できるアドレスはどれか。
  31. IPv6だけで動く2つの拠点を、IPv4だけで動くネットワークを通してつなぎ、拠点の間をIPv6のパケットのまま通信させたい。用いる方法として適切なものはどれか。
  32. tracerouteで、送信元から数えて4台目のルータから、ICMPの時間超過(Time Exceeded)のメッセージを返させるために送るパケットの、IPヘッダのTTLの値はどれか。
  33. ある端末からWebサーバ 198.51.100.80 までtracerouteを実行したところ、1〜5番目の行に、192.168.1.1、10.0.0.1、「* * *」(応答なし)、203.0.113.1、198.51.100.80 の順で表示され、Webサーバも問題なく使えた。3番目の行の解釈として最も適切なものはどれか。
  34. IPv4で、全長4000バイト(ヘッダ20バイト、データ3980バイト)のパケットが、MTUが1500バイトのリンクで分割(フラグメント化)される。分割されたパケットのヘッダも20バイトで、分割してよい設定とする。最後のフラグメントのフラグメントオフセットの欄の値はどれか。
  35. 拠点間のVPNのトンネルを通して、遠くのWebサーバと通信している。TCPのコネクションは確立でき、小さなページは表示されるが、大きなファイルのダウンロードだけが途中で止まってしまう。トンネルの中のMTUは1400バイトで、サーバは1500バイトのパケットを分割禁止(DFビットを1)にして送っている。また、サーバの手前のファイアウォールはICMPをすべて捨てる設定になっている。原因として最も適切なものはどれか。
  36. QoSの制御で使われる、IPヘッダのDSCPの説明として正しいものはどれか。
  37. ルータの出口の70 Mbpsのリンクで、3つのキューを重み4:2:1の重み付きラウンドロビンで送り出す。3つのキューには常に送るパケットがたまっており、パケットの大きさはすべて同じとする。重み2のキューが使える帯域に最も近いものはどれか。
  38. SNMPで、ルータのインターフェースの受信バイト数を数える64ビットのカウンタを5分(300秒)ごとに読み出したところ、前回が 1,200,000,000、今回が 4,950,000,000 だった。この5分間の平均の受信速度に最も近いものはどれか。
  39. ルータを通る通信について、どの送信元と宛先の組み合わせ(アドレス、ポート番号、プロトコル)の通信が、どれだけのバイト数を占めているかを、通信のまとまりごとに集計して調べたい。用いるしくみとして最も適切なものはどれか。
  40. あるPCから、IPアドレスを指定したpingはインターネット上のサーバまで届くが、ブラウザでドメイン名を指定すると「サーバが見つからない」と表示されて、Webページを開けない。まず確認すべき設定として最も適切なものはどれか。
