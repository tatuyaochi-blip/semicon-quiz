イメージセンサ・光デバイスの要点

イメージセンサは、画素ごとのフォトダイオードで光を電荷に変え、電気信号として読み出す素子です。現在はCMOSイメージセンサが主流で、スマートフォンや車載カメラに広く使われています。

配線層の反対側から光を入れる裏面照射型や、画素と回路を別のチップに作って重ねる積層型が性能向上に貢献しています。LEDやレーザーなど、電気を光に変える光デバイスもこの分野に含まれます。

イメージセンサ・光デバイスの問題一覧（50問）
  1. CMOSイメージセンサの各画素で、光を電荷に変換する素子はどれか。
  2. 裏面照射型(BSI)CMOSイメージセンサの主な利点として正しいものはどれか。
  3. LEDの発光色(発光波長)を決める主な要因はどれか。
  4. CCDイメージセンサと比べたときの、CMOSイメージセンサの一般的な特長として正しいものはどれか。
  5. ベイヤー配列のカラーフィルタで、2×2の画素の中に最も多く配置される色はどれか。
  6. CMOSイメージセンサのローリングシャッター方式で、速く動く被写体がゆがんで写る理由として正しいものはどれか。
  7. イメージセンサの各画素の上に設けるマイクロレンズの役割はどれか。
  8. イメージセンサの暗電流の説明として正しいものはどれか。
  9. 太陽電池が発電に利用している現象はどれか。
  10. 半導体レーザーとLEDの違いとして正しいものはどれか。
  11. 積層型CMOSイメージセンサの説明として正しいものはどれか。
  12. イメージセンサの画素サイズを小さくしたときに起こりやすい問題はどれか。
  13. ToF(Time of Flight)センサの測定原理として正しいものはどれか。
  14. CMOSイメージセンサの埋め込みフォトダイオード(ピンドフォトダイオード)で、表面に高濃度のp+層を設ける主な目的はどれか。
  15. 非冷却型の赤外線イメージセンサに使われるマイクロボロメータの原理として正しいものはどれか。
  16. 明るい部分と暗い部分が混在する場面を撮影するための、イメージセンサのHDR(ハイダイナミックレンジ)化の手法として正しいものはどれか。
  17. イメージセンサの量子効率の定義として正しいものはどれか。
  18. シリコンのイメージセンサで、近赤外光の感度を高めるのが難しい理由として正しいものはどれか。
  19. CMOSイメージセンサの読み出しで使われる相関二重サンプリング(CDS)の目的として正しいものはどれか。
  20. 有機EL(OLED)ディスプレイの特徴として正しいものはどれか。
  21. CMOSイメージセンサの代表的な4トランジスタ画素で、フォトダイオードの電荷を浮遊拡散層(フローティングディフュージョン)に移す役割をもつトランジスタはどれか。
  22. 画素ごとの特性のばらつきによって、毎回同じ位置に同じように現れるノイズを何と呼ぶか。
  23. 光子の数の統計的なゆらぎによるショットノイズの大きさと、信号電子の数Nの関係として正しいものはどれか。
  24. 微細な画素の間に深い溝を掘り、絶縁物などを埋め込む構造(DTI)の主な目的はどれか。
  25. 光ファイバ通信の1.55 µm帯の光を受けるフォトダイオードに使われる材料として適切なものはどれか。
  26. CCDイメージセンサの信号の読み出し方式として正しいものはどれか。
  27. スマートフォン向けの高画素イメージセンサの画素サイズとして最も近いものはどれか。
  28. イメージセンサの一部の画素で、レンズの左右から入る光を分けて受けることによって実現するオートフォーカスの方式はどれか。
  29. イメージセンサの1画素に蓄えられる電子の最大数を何と呼ぶか。
  30. 光通信で、単一の波長で安定に発振させるために、回折格子を内蔵した半導体レーザーはどれか。
  31. 「1,200万画素」のイメージセンサの説明として正しいものはどれか。
  32. カラー画像を撮るイメージセンサで、画素の上にカラーフィルタを置く必要がある理由として正しいものはどれか。
  33. 現在のスマートフォンのカメラに主に使われているイメージセンサはどれか。
  34. 逆バイアスをかけたフォトダイオードに当たる光を強くすると、流れる電流(光電流)はどうなるか。
  35. 暗い場所で撮影した画像がざらついて(ノイズが目立って)見える主な理由はどれか。
  36. CMOSイメージセンサの「変換ゲイン」の説明として正しいものはどれか。
  37. 多くのCMOSイメージセンサで採用されている、画素の列ごとにAD変換器を設けて並列に変換する方式の主な利点はどれか。
  38. イメージセンサの「画素ビニング」の説明として正しいものはどれか。
  39. 非常に明るい光を受けた画素から電荷があふれ、周囲の画素まで白く広がって写る現象を何と呼ぶか。
  40. 細かい縞模様の被写体を撮影したときに、画素の配列との干渉で本来ない模様(モアレ)が現れるのを抑えるために、センサの前に置かれることがある部品はどれか。
  41. 人や物の温度を画像にするサーモグラフィで、主に検出に使われる赤外線の波長帯はどれか。
  42. イメージセンサの画素の「開口率(フィルファクタ)」の意味として正しいものはどれか。
  43. ベイヤー配列などのカラーフィルタを使ったセンサの出力から、各画素の赤・緑・青すべての値を周囲の画素から補って求める処理を何と呼ぶか。
  44. 放送用カメラなどで使われる「3板式」の撮像方式の説明として正しいものはどれか。
  45. 降伏電圧を超える逆バイアスで動作させ、光子1個でもなだれ増倍によるパルスを発生させる受光素子はどれか。
  46. 画素ごとに明るさの変化だけを検出し、変化があった画素の情報だけを非同期に出力するイメージセンサはどれか。
  47. CMOSイメージセンサで、フォトダイオードから浮遊拡散層への電荷の転送が不完全なときに起こる問題はどれか。
  48. イメージセンサの変換ゲインなどを、明るさを変えて撮った画像の信号の平均値とばらつき(分散)の関係から求める評価方法はどれか。
  49. シリコンでは検出できない短波長赤外(SWIR、約1〜2 µm)を、安価なイメージセンサで検出するために研究・実用化が進んでいる受光材料の例はどれか。
  50. 医療用のX線撮影に使われる間接変換型のフラットパネル検出器で、X線を検出する方法として正しいものはどれか。

この分野の比較

  • CMOSイメージセンサーとCCDの違い：読み出し・速度・用途を比較CMOSイメージセンサーとCCDを、読み出し方式・消費電力・速度・ノイズ・シャッター方式・集積度・コスト・用途の観点で表にして比較します。
  • 表面照射型・裏面照射型・積層型イメージセンサの違い：構造・感度・速度を比較表面照射型(FSI)、裏面照射型(BSI)、積層型のCMOSイメージセンサを、光の入る側・構造・開口率と感度・配線と周辺回路・チップ面積・速度・製造の難しさ・課題・用途の観点で表にして比較し、使い分けも解説します。
  • ローリングシャッターとグローバルシャッターの違い：露光・ゆがみ・ノイズ・用途を比較ローリングシャッターとグローバルシャッターを、露光のタイミング・読み出し・動く被写体のゆがみ・点滅する光・画素の回路・画素サイズと感度・ノイズ・コスト・用途の観点で表にして比較し、どちらをどんなときに使うかも解説します。
  • LEDと半導体レーザーの違い：発光の仕組み・光の性質・用途を比較LED(発光ダイオード)と半導体レーザー(レーザーダイオード)を、発光の仕組み・共振器の有無・スペクトル幅・光の広がり・電流と光出力の関係・変調の速さ・用途の観点で表にして比較します。
