CPU・アーキテクチャの要点

はじめて学ぶ人へ: CPUとは? パソコンやスマホの中で何をしているのか / なぜAIにGPUが使われるの? 大量の掛け算を同時にこなすしくみ

CPUは、命令の取り出し・解読・実行を繰り返してプログラムを処理します。多くのコンピュータは、プログラムとデータを同じ主記憶に置くノイマン型の構成をとっています。

性能を高める工夫として、命令処理を段階に分けて重ねるパイプライン、主記憶との速度差を埋めるキャッシュ、複数のコアによる並列処理などがあります。半導体の微細化がこれらの進化を支えてきました。

CPU・アーキテクチャの問題一覧（50問）
  1. CPUのパイプライン処理の主な目的として正しいものはどれか。
  2. キャッシュメモリを設ける主な目的として正しいものはどれか。
  3. ノイマン型コンピュータの特徴として正しいものはどれか。
  4. 1つのチップに複数のプロセッサコアを搭載する(マルチコア化する)主な目的はどれか。
  5. RISC(縮小命令セットコンピュータ)の特徴として正しいものはどれか。
  6. クロック周波数1 GHzのクロックの周期はいくらか。
  7. CPUの分岐予測の目的として正しいものはどれか。
  8. GPUが行列演算やAIの学習・推論に向いている主な理由はどれか。
  9. キャッシュのアクセス時間が10 ns、主記憶のアクセス時間が100 ns、キャッシュのヒット率が90%のとき、平均アクセス時間はいくらか。
  10. CMOS回路で、ほかの条件を変えずに電源電圧だけを半分にすると、動的消費電力はどうなるか。
  11. ARM、x86、RISC-Vといった名前が主に表しているものはどれか。
  12. RISC-Vの特徴として正しいものはどれか。
  13. 1クロックサイクルに複数の命令を同時に発行・実行するプロセッサの方式を何と呼ぶか。
  14. 仮想アドレスから物理アドレスへの変換結果を保持し、アドレス変換を高速化するキャッシュはどれか。
  15. AIの推論処理を高速かつ低い消費電力で行うために、スマートフォン用のSoCなどに搭載される専用回路はどれか。
  16. 一般的なコンピュータで、アクセスが速い順に並べた記憶階層として正しいものはどれか。
  17. クロック周波数2 GHz、平均CPI(1命令あたりの平均クロック数)0.5のプロセッサが、1秒間に実行できる命令数はおよそいくらか。
  18. 処理全体の90%を並列化できるプログラムを、プロセッサの数を限りなく増やして実行したとき、理論上の最大の高速化率はどれか。
  19. 1つの命令で複数のデータに同じ演算を同時に行う方式はどれか。
  20. 高性能なコアと省電力なコアを組み合わせ、処理の重さに応じて使い分けるCPUの構成はどれか。
  21. 命令の依存関係を調べ、実行できる命令からプログラムの順序と異なる順で実行して性能を高める方式はどれか。
  22. 実行中の処理を一時的に中断し、外部機器からの要求などに応じた処理を優先して行うCPUの仕組みはどれか。
  23. CPUを介さずに、周辺装置とメモリの間で直接データを転送する仕組みはどれか。
  24. CPU、メモリ、タイマーやADCなどの周辺機能を1チップにまとめ、家電や機器の制御に使われるLSIはどれか。
  25. マルチコアCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組みはどれか。
  26. CPUの消費電力を減らすため、負荷に応じて動作周波数と電源電圧を動的に変える技術はどれか。
  27. 投機的実行の痕跡がキャッシュに残ることを悪用し、本来アクセスできないデータを推測する攻撃が明らかになった脆弱性の例はどれか。
  28. CPUの冷却設計の目安となる、標準的な高負荷時に発生する熱量を表す指標はどれか。
  29. 1クロックあたりに実行できる命令数を表す指標はどれか。
  30. 消費電力と発熱の制約によって、チップ上のすべての回路を同時に最大性能で動かせなくなる問題を何と呼ぶか。
  31. CPUの日本語での一般的な呼び方として正しいものはどれか。
  32. クロック周波数3 GHzのCPUの説明として正しいものはどれか。
  33. 「64ビットCPU」の64ビットが主に表しているものはどれか。
  34. CPUが1つの命令を処理する基本的な流れとして正しい順序はどれか。
  35. CPUの中のALU(算術論理演算装置)の役割として正しいものはどれか。
  36. CPUのプログラムカウンタ(PC)が保持しているものはどれか。
  37. キャッシュの書き込み方式で、ライトバック方式の説明として正しいものはどれか。
  38. セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。
  39. 現在の多くのCPUで使われているキャッシュライン(キャッシュブロック)の大きさとして一般的なものはどれか。
  40. パイプラインで、前の命令の結果を次の命令がすぐ使う(データハザード)とき、レジスタへの書き込みを待たずに演算結果を直接次の命令に渡す手法はどれか。
  41. リトルエンディアンの説明として正しいものはどれか。
  42. 1つのCPUコアで複数のスレッドの命令を同時に処理し、コア内の演算器などを有効に使う技術はどれか。
  43. マイコンなどで、周辺機器のレジスタをメモリと同じアドレス空間に割り当て、通常のメモリ読み書き命令で操作する方式はどれか。
  44. マイコンに搭載されるウォッチドッグタイマの役割として正しいものはどれか。
  45. プログラムでサブルーチン(関数)を呼び出すとき、戻り先のアドレスなどを一時的に保存するために一般的に使われる領域はどれか。
  46. キャッシュミスの分類「3つのC」に含まれるものの組み合わせとして正しいものはどれか。
  47. アウトオブオーダー実行のCPUで、順序を入れ替えて実行した命令の結果を、プログラムの本来の順序で確定(リタイア)させるための仕組みはどれか。
  48. アウトオブオーダー実行のCPUで使われるレジスタリネーミングの主な目的はどれか。
  49. AI向けのアクセラレータなどで、多数の積和演算器を格子状に並べ、データを隣の演算器へ順に流しながら行列の積を計算する構成はどれか。
  50. プログラムの性能が、演算性能とメモリ帯域のどちらで制限されるかを、演算強度(1バイトあたりの演算数)を横軸にして図示するモデルはどれか。

この分野の比較

  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
  • ARM・RISC-V・x86の違い：命令セットアーキテクチャを比較ARM、RISC-V、x86を、設計の考え方・命令長・ライセンス・レジスタ・ソフトウェアの環境・強み・用途の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
  • インオーダー実行とアウトオブオーダー実行の違い：発行順・ハザード・回路規模・IPCを比較インオーダー実行とアウトオブオーダー実行を、命令の発行順・待ちが生じたときの動き・ハザードへの対応・レジスタリネーミングとROB・回路規模と電力・IPC・使われる場所の観点で比較します。
