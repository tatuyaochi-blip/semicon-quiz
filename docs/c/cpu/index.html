CPU・アーキテクチャの要点

CPUは、命令の取り出し・解読・実行を繰り返してプログラムを処理します。多くのコンピュータは、プログラムとデータを同じ主記憶に置くノイマン型の構成をとっています。

性能を高める工夫として、命令処理を段階に分けて重ねるパイプライン、主記憶との速度差を埋めるキャッシュ、複数のコアによる並列処理などがあります。半導体の微細化がこれらの進化を支えてきました。

CPU・アーキテクチャの問題一覧（30問）

  1. CPUのパイプライン処理の主な目的として正しいものはどれか。
  2. キャッシュメモリを設ける主な目的として正しいものはどれか。
  3. ノイマン型コンピュータの特徴として正しいものはどれか。
  4. 1つのチップに複数のプロセッサコアを搭載する(マルチコア化する)主な目的はどれか。
  5. RISC(縮小命令セットコンピュータ)の特徴として正しいものはどれか。
  6. クロック周波数1 GHzのクロックの周期はいくらか。
  7. CPUの分岐予測の目的として正しいものはどれか。
  8. GPUが行列演算やAIの学習・推論に向いている主な理由はどれか。
  9. キャッシュのアクセス時間が10 ns、主記憶のアクセス時間が100 ns、キャッシュのヒット率が90%のとき、平均アクセス時間はいくらか。
  10. CMOS回路で、ほかの条件を変えずに電源電圧だけを半分にすると、動的消費電力はどうなるか。
  11. ARM、x86、RISC-Vといった名前が主に表しているものはどれか。
  12. RISC-Vの特徴として正しいものはどれか。
  13. 1クロックサイクルに複数の命令を同時に発行・実行するプロセッサの方式を何と呼ぶか。
  14. 仮想アドレスから物理アドレスへの変換結果を保持し、アドレス変換を高速化するキャッシュはどれか。
  15. AIの推論処理を高速かつ低い消費電力で行うために、スマートフォン用のSoCなどに搭載される専用回路はどれか。
  16. 一般的なコンピュータで、アクセスが速い順に並べた記憶階層として正しいものはどれか。
  17. クロック周波数2 GHz、平均CPI(1命令あたりの平均クロック数)0.5のプロセッサが、1秒間に実行できる命令数はおよそいくらか。
  18. 処理全体の90%を並列化できるプログラムを、プロセッサの数を限りなく増やして実行したとき、理論上の最大の高速化率はどれか。
  19. 1つの命令で複数のデータに同じ演算を同時に行う方式はどれか。
  20. 高性能なコアと省電力なコアを組み合わせ、処理の重さに応じて使い分けるCPUの構成はどれか。
  21. 命令の依存関係を調べ、実行できる命令からプログラムの順序と異なる順で実行して性能を高める方式はどれか。
  22. 実行中の処理を一時的に中断し、外部機器からの要求などに応じた処理を優先して行うCPUの仕組みはどれか。
  23. CPUを介さずに、周辺装置とメモリの間で直接データを転送する仕組みはどれか。
  24. CPU、メモリ、タイマーやADCなどの周辺機能を1チップにまとめ、家電や機器の制御に使われるLSIはどれか。
  25. マルチコアCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組みはどれか。
  26. CPUの消費電力を減らすため、負荷に応じて動作周波数と電源電圧を動的に変える技術はどれか。
  27. 投機的実行の痕跡がキャッシュに残ることを悪用し、本来アクセスできないデータを推測する攻撃が明らかになった脆弱性の例はどれか。
  28. CPUの冷却設計の目安となる、標準的な高負荷時に発生する熱量を表す指標はどれか。
  29. 1クロックあたりに実行できる命令数を表す指標はどれか。
  30. 消費電力と発熱の制約によって、チップ上のすべての回路を同時に最大性能で動かせなくなる問題を何と呼ぶか。
