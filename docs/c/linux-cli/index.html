Linuxとコマンドラインの基礎の要点

サーバやクラウドの多くはLinuxで動いていて、論理合成や回路シミュレーションなどのEDAツールも、ふつうはLinuxのサーバの上で使います。そこでは画面のボタンではなく、シェルにコマンドを打ち込み、ファイルを調べ、ログを絞り込み、長い処理を走らせたまま接続を切る、といった作業が毎日の仕事になります。

ここでは、ディレクトリの構成と絶対パス・相対パス、隠しファイル、ハードリンクとシンボリックリンク、ワイルドカード、パーミッションの rwx と8進数の表記、umask、ディレクトリの実行の権限、sudo と setuid を学びます。続いて、リダイレクトとパイプ、grep と正規表現、sort と uniq を組み合わせた集計、tail -f、cut、sed、awk、find、kill とシグナル、Ctrl+Z と bg・fg、nohup、終了ステータスと && ・ ||、引用符と変数の展開、スクリプトの引数と条件と繰り返し、PATH と export を扱い、最後にパッケージ管理、systemctl、cron、df と du、SSH の鍵、tar、Gitの add・commit・push と .gitignore を確かめます。コマンドの動きは bash と GNU のコマンド(coreutils、grep、sed、findutils、tar)を基準にしていて、問題の出力は、Linuxの上で実際に実行して確かめています。プロセスや仮想記憶のしくみは「OSとハードウェア」、ポート番号やDNSは「ネットワークの基礎」、アクセス制御の考え方は「情報セキュリティの基礎」、Gitのマージや開発の進め方は「ソフトウェア開発とプロジェクト管理」の分野で扱います。
