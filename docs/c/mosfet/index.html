MOSFETの要点

MOSFETは、ゲート電圧によって半導体表面に反転層(チャネル)をつくり、ソース-ドレイン間の電流を制御するトランジスタです。ゲートは薄い絶縁膜で隔てられているため、定常的なゲート電流はほとんど流れません。

しきい値電圧、線形領域と飽和領域、短チャネル効果、そしてnMOSとpMOSを組み合わせたCMOS回路は、LSIを理解するための重要なテーマです。

MOSFETの問題一覧（30問）

  1. エンハンスメント型のnチャネルMOSFETがオン(導通)するための条件として正しいものはどれか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  2. ゲート絶縁膜の材料と面積を変えずに膜厚だけを薄くすると、単位面積あたりのゲート容量はどうなるか。
  3. CMOSインバータの静的(定常状態の)消費電力が小さい理由として正しいものはどれか。
  4. 長チャネルのMOSFETが飽和領域で動作しているとき、ドレイン電流IDはおよそ何に比例するか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  5. 同じ寸法のnMOSとpMOSでは、一般にnMOSの方が駆動電流が大きい。その主な理由はどれか。
  6. nチャネルMOSFETで、ソースに対して基板(ボディ)に負の電圧をかける(基板バイアスをかける)と、しきい値電圧はどうなるか。
  7. デプレッション型MOSFETの特徴として正しいものはどれか。
  8. 室温におけるMOSFETのサブスレッショルド係数(しきい値以下でドレイン電流を1桁変えるのに必要なゲート電圧)の理論的な下限値に最も近いものはどれか。
  9. ドレイン-ソース間電圧VDSが十分小さい線形領域でのMOSFETの振る舞いとして正しいものはどれか。
  10. MOSFETのLDD(Lightly Doped Drain)構造の目的として正しいものはどれか。
  11. 飽和領域にあるMOSFETで、ドレイン電圧を上げると実効的なチャネル長が短くなり、ドレイン電流がわずかに増える現象を何と呼ぶか。
  12. MOSFETの相互コンダクタンスgmの定義として正しいものはどれか。
  13. p型基板のMOS構造で、ゲートに負の電圧を加えたときの半導体表面の状態として正しいものはどれか。
  14. CMOSインバータの論理しきい値電圧を電源電圧のほぼ半分にするための設計として正しいものはどれか。
  15. nMOSとpMOSを並列に接続したトランスミッションゲートの利点として正しいものはどれか。
  16. MOSFETのゲート-ソース間に、定格を大きく超える電圧を加えたときに起こりうる破壊はどれか。
  17. MOSFETのチャネルの移動度が、シリコン結晶内部の移動度より小さくなる主な理由として正しいものはどれか。
  18. 短チャネルのMOSFETで、ドレイン電流が(VGS − Vth)の2乗則より小さくなり、1乗に近い依存性を示すようになる主な原因はどれか。
  19. CMOS論理ゲートの遅延時間をおおまかに表す式として適切なものはどれか。(C:負荷容量、V:電源電圧、I:駆動電流)
  20. エンハンスメント型pチャネルMOSFETのしきい値電圧(ソース基準)の符号はどれか。
  21. ゲート-ドレイン間の容量が、増幅回路の入力側から見ると(1 + 利得)倍に大きく見える効果を何と呼ぶか。
  22. ポリシリコンゲートで、ゲート電極側のポリシリコンが空乏化することによる問題として正しいものはどれか。
  23. MOSFETのしきい値電圧を下げたときの一般的な影響として正しいものはどれか。
  24. CMOSの2入力NANDゲートのトランジスタの接続として正しいものはどれか。
  25. ゲートとドレインが重なる部分の強い電界によってバンド間トンネル電流が流れ、オフ時のリーク電流が増える現象はどれか。
  26. MOSFETのゲートにほとんど電流が流れないことによる回路上の利点として正しいものはどれか。
  27. MOSFETのソースフォロワ(ドレイン接地)回路の特徴として正しいものはどれか。
  28. MOSFETのしきい値電圧の絶対値は、温度が上がると一般にどうなるか。
  29. MOSFETのドレイン電流を大きくするための寸法の変え方として正しいものはどれか。
  30. MOSFETがオフの状態で流れるリーク電流の主な成分の組み合わせとして正しいものはどれか。
