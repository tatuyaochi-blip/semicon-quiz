情報セキュリティの基礎の要点

情報を守るとは、許可された人だけが見られ(機密性)、正しい内容が保たれ(完全性)、必要なときに使える(可用性)状態を保つことです。そのために、暗号やハッシュ関数、デジタル署名といった技術と、認証やアクセス制御、バックアップ、組織としての管理の仕組みを組み合わせます。

脅威・脆弱性・リスクの考え方とリスクへの対応、共通鍵暗号と公開鍵暗号の使い分けと鍵の数の計算、ハッシュ関数とパスワードの保存、デジタル署名と証明書、多要素認証と生体認証の誤り率、最小権限の原則を学びます。マルウェアやフィッシング、SQLインジェクションやクロスサイトスクリプティングなどのWebの攻撃を、しくみと対策の観点から扱い、基本情報技術者試験・応用情報技術者試験のセキュリティ分野の学習にも役立ちます。ハードウェアに関わるセキュリティは「ハードウェアセキュリティ」の分野で扱います。

情報セキュリティの基礎の問題一覧（40問）
  1. 社内の業務システムが大量のアクセスを受けて応答しなくなり、利用者が必要なときに使えなくなった。情報セキュリティの3要素(機密性・完全性・可用性)のうち、主に損なわれたものはどれか。
  2. 情報セキュリティのリスクを考えるときの「脅威」と「脆弱性」について、脆弱性に当たるものはどれか。
  3. 情報漏えいが起きたときの損害賠償に備えて、サイバー保険に加入した。このリスクへの対応はどれに当たるか。
  4. ある情報システムで、1回起きると2000万円の損失が出る事故が、年に0.1回の頻度で起きると見積もられている。年間50万円の費用がかかる対策を行うと、発生の頻度が年に0.02回に下がる。この対策による1年あたりの正味の効果(損失の期待値の減少額から対策の費用を引いたもの)はいくらか。
  5. ISMS(情報セキュリティマネジメントシステム)をPDCAサイクルで運用するとき、Check(評価)の段階で行うこととして適切なものはどれか。
  6. 共通鍵暗号の特徴として正しいものはどれか。
  7. 公開鍵暗号を使って、AさんがBさんだけに読めるようにメッセージを暗号化して送りたい。暗号化に使う鍵はどれか。
  8. 50人のメンバーが、2人ずつの組のすべてで、ほかのメンバーに内容を知られずに暗号の通信をしたい。共通鍵暗号を使う場合に必要な鍵の数と、公開鍵暗号を使う場合に必要な鍵の数(公開鍵と秘密鍵の合計)の組み合わせとして正しいものはどれか。
  9. 大きなファイルを相手に暗号化して送るとき、よく使われるハイブリッド暗号方式の手順として正しいものはどれか。
  10. 暗号で使われるハッシュ関数(暗号学的ハッシュ関数)の性質として正しいものはどれか。
  11. 出力が256ビットの理想的なハッシュ関数に対して、総当たりで攻撃するときに必要な計算の回数の目安として、「与えられたハッシュ値になる入力を見つける(原像攻撃)」場合と、「同じハッシュ値になる異なる2つの入力を、どれでもよいので見つける(衝突攻撃)」場合の組み合わせとして正しいものはどれか。
  12. Webサービスで利用者のパスワードを保存するとき、パスワードに利用者ごとに異なるランダムな値(ソルト)を加えてからハッシュ値を計算して保存する。ソルトを使う主な目的はどれか。
  13. パスワードの保存に、SHA-256のような高速なハッシュ関数をそのまま使うのではなく、bcryptやArgon2のような、わざと計算に時間がかかるように設計された方式を使うことが推奨される理由として正しいものはどれか。
  14. 8文字のパスワードを、すべての候補を試す総当たりで探す。1秒あたり1×10^10個の候補を試せるとき、英小文字(26種類)だけで作ったパスワードと、英大文字・英小文字・数字(62種類)で作ったパスワードについて、すべての候補を試し終えるまでの時間の組み合わせとして最も近いものはどれか。
  15. AさんがBさんに送る文書にデジタル署名を付ける。署名の作成と検証に使う鍵と、デジタル署名によって確かめられることの組み合わせとして正しいものはどれか。
  16. メッセージ認証コード(MAC)とデジタル署名を比べたときの説明として正しいものはどれか。
  17. Webサーバのサーバ証明書に対応する秘密鍵が漏えいしたおそれがあることが分かった。証明書の有効期限はまだ残っている。運営者がとるべき対応として最も適切なものはどれか。
  18. 利用者を確かめる認証の3つの要素(知識・所持・生体)のうち、社員証のICカードを使う認証が当てはまるものはどれか。
  19. 次の認証の方法のうち、多要素認証に当たるものはどれか。
  20. 指紋による生体認証で、本人と判定するための一致の度合いのしきい値を厳しく(高く)した。一般に起こる変化として正しいものはどれか。
  21. ある顔認証の装置では、しきい値をA・B・Cの3通りに設定でき、それぞれの他人受入率(FAR)と本人拒否率(FRR)は、Aが1%と0.5%、Bが0.1%と2%、Cが0.01%と8%である。研究室の入室の管理で「FARを0.1%以下にする」ことを条件とし、そのうえで正規の利用者ができるだけ拒否されないようにしたい。選ぶべきしきい値はどれか。
  22. シングルサインオン(SSO)の説明として正しいものはどれか。
  23. 最小権限の原則に沿った運用として正しいものはどれか。
  24. 社員が数千人いる会社で、ロールベースアクセス制御(RBAC)を使って権限を管理する。RBACの考え方として正しいものはどれか。
  25. マルウェアの種類のうち、ワームの特徴として正しいものはどれか。
  26. ランサムウェアの説明として正しいものはどれか。
  27. ランサムウェアへの備えとしてのバックアップについて、「3-2-1ルール」に沿った方法として最も適切なものはどれか。
  28. フィッシングの手口と、利用者側の対策の組み合わせとして正しいものはどれか。
  29. ソーシャルエンジニアリングの例として当てはまるものはどれか。
  30. 取引先の担当者を名乗るメールで「振込先の口座が変わったので、今回の請求からはこちらに支払ってほしい」と依頼された。ビジネスメール詐欺(BEC)を疑うときの対応として最も適切なものはどれか。
  31. ログインの画面で、パスワードの欄に ' OR '1'='1 のような文字列を入力されると、パスワードを知らなくてもログインできてしまうWebアプリケーションがある。この攻撃の名前はどれか。
  32. SQLインジェクションへの対策として、プレースホルダを使うプリペアドステートメント(パラメータ化クエリ)が、入力の中の危険な文字を取り除く方法より根本的な対策とされる理由として正しいものはどれか。
  33. 掲示板のWebアプリケーションで、利用者が投稿した文章の中のスクリプトが、ほかの閲覧者のブラウザで実行されてしまう脆弱性があった。この脆弱性の名前と、根本的な対策の組み合わせとして正しいものはどれか。
  34. Webアプリケーションで、ログインしたままの利用者が攻撃者の用意した罠のページを開くと、利用者のブラウザから正規のサイトへ、利用者の意図しない送金や設定の変更のリクエストが送られてしまう脆弱性がある。この脆弱性への対策として適切なものはどれか。
  35. Webアプリケーションが、URLのパラメータで指定されたファイル名を、公開用のフォルダの名前とつなげて読み出して表示している。ファイル名に ../ を含む値を指定されると、公開用のフォルダの外にある設定ファイルなどを読み出されてしまう。この攻撃の名前と対策の組み合わせとして正しいものはどれか。
  36. Webアプリケーションで、ログインの前と後で同じセッションIDを使い続けていると、攻撃者があらかじめ用意したセッションIDを利用者に使わせ、利用者がログインした後にそのIDで利用者になりすますおそれがある。この攻撃への対策として最も適切なものはどれか。
  37. DDoS攻撃の説明として正しいものはどれか。
  38. ゼロデイ攻撃の説明として正しいものはどれか。
  39. 脆弱性の管理で使われるCVEとCVSSの説明の組み合わせとして正しいものはどれか。
  40. 社員のPCで、ファイルの拡張子が次々に変わり、身代金を要求する画面が表示された。この社員がまず行う対応として最も適切なものはどれか。
