パッケージ・実装

ワイヤボンディング、フリップチップ、BGAなど半導体パッケージと実装の基本を3択問題で確認できます。

パッケージ・実装の要点

パッケージは、チップを外部環境から保護し、基板と電気的に接続し、熱を逃がす役割をもっています。ウエハから切り出したチップは、ダイボンディング、接続、封止などの工程を経て製品になります。

チップと外部の接続方法にはワイヤボンディングやフリップチップがあり、パッケージの形状もリードを出すタイプから、裏面にはんだボールを並べるBGAなどへと多ピン化に合わせて進化してきました。

パッケージ・実装の問題一覧（50問）

  1. ワイヤボンディングの説明として正しいものはどれか。
  2. フリップチップ実装の説明として正しいものはどれか。
  3. BGA(ボールグリッドアレイ)パッケージの特徴として正しいものはどれか。
  4. ダイシングの説明として正しいものはどれか。
  5. 一般的な樹脂封止パッケージの封止材として主に使われる材料はどれか。
  6. リードフレームの材料として一般的に使われるものはどれか。
  7. CSP(チップサイズパッケージ)の説明として正しいものはどれか。
  8. ウエハレベルパッケージ(WLP)の特徴として正しいものはどれか。
  9. フリップチップ実装で、チップと基板の隙間にアンダーフィル樹脂を充填する主な目的はどれか。
  10. 環境規制に対応した鉛フリーはんだとして広く使われている組成はどれか。
  11. QFN(Quad Flat No-lead)パッケージの特徴として正しいものはどれか。
  12. チップをリードフレームや基板の所定の位置に接着・固定する工程を何と呼ぶか。
  13. パッケージを薄くするため、ダイシングの前にウエハの裏面を研削して薄くする工程を何と呼ぶか。
  14. 吸湿した樹脂パッケージをはんだリフローで加熱したとき、内部の水分が急に気化して膨張し、パッケージが割れる現象を何と呼ぶか。
  15. ワイヤボンディングで、金(Au)ワイヤから銅(Cu)ワイヤへの置き換えが進んだ主な理由はどれか。
  16. パッケージの放熱性能を表す、チップの接合部から周囲の空気までの熱抵抗を表す記号はどれか。
  17. プリント基板にはんだペーストを印刷し、部品を載せてから炉で加熱してはんだ付けする方法はどれか。
  18. プロセッサのパッケージの上に、メモリのパッケージを重ねて実装する方式を何と呼ぶか。
  19. パッケージの両側2列にピンを並べ、基板の穴に差し込んで実装する、古くからあるパッケージはどれか。
  20. 大型のパッケージで、リフロー時の加熱による反り(ワーページ)が問題になる理由として正しいものはどれか。
  21. 表面実装パッケージで、防湿梱包を開封してからリフローまでに放置してよい時間などを定めた、吸湿に関する等級はどれか。
  22. 発熱の大きいプロセッサのパッケージで、チップの上に載せて熱を広げる金属の板を何と呼ぶか。
  23. フリップチップBGAなどで使われる、絶縁層と微細な配線層を積み重ねてつくる有機パッケージ基板はどれか。
  24. 金ワイヤの先端を放電で溶かしてボールをつくり、熱と超音波を加えて電極に接合するワイヤボンディングの方式はどれか。
  25. 宇宙用など高い信頼性が求められる用途で使われる、セラミックや金属で内部を密閉したパッケージはどれか。
  26. パッケージの2辺から、ガルウィング状のリードを出した表面実装パッケージはどれか。
  27. 多ピンのQFPで、リードの間隔を狭くしすぎると起こりやすい問題はどれか。
  28. チップと基板を加熱・加圧しながら1個ずつ接合し、反りの大きい薄いチップや狭いピッチのバンプの接続に使われる方法はどれか。
  29. 封止樹脂に大量のシリカのフィラーを加える主な目的はどれか。
  30. パッケージやプリント基板に、デカップリングコンデンサ(バイパスコンデンサ)を配置する主な目的はどれか。
  31. 半導体パッケージの主な役割の組み合わせとして正しいものはどれか。
  32. 完成したICのパッケージの表面に、品名やロット番号などを表示する工程として一般的なものはどれか。
  33. ワイヤボンディングで使われるワイヤの太さとして一般的なものはどれか。
  34. 表面実装用のICを、くぼみのあるテープに1個ずつ入れて巻き取り、実装機に供給する梱包形態を何と呼ぶか。
  35. 端子をプリント基板の穴に差し込む実装と比べた、表面実装の主な利点はどれか。
  36. リードフレームを使うパッケージで、外に出たリードの表面にスズ(Sn)系のめっきをする主な目的はどれか。
  37. 鉛フリーはんだ(Sn-Ag-Cu系)を使うリフローで、部品が受けるピーク温度の目安として最も近いものはどれか。
  38. レーザーをウエハの内部に集光して改質層をつくり、テープを引き伸ばしてチップに分割する、切りしろの少ないダイシングの方法はどれか。
  39. パッケージの底面に、はんだボールではなく平らな電極(ランド)を格子状に並べたパッケージはどれか。
  40. 電子機器のプリント基板の基材として最も広く使われている材料はどれか。
  41. 多くの樹脂封止パッケージの封止樹脂が黒い色をしている主な理由はどれか。
  42. 多ピンのBGAパッケージで、ボールの多くを電源とグラウンドに割り当てる主な理由はどれか。
  43. ボール形成を使うワイヤボンディングで、一般的に最初の接合(ボールボンド)をする場所はどれか。
  44. 樹脂でモールドした後のパッケージを、オーブンでしばらく加熱する(ポストモールドキュア)主な目的はどれか。
  45. 樹脂を流し込んでモールドするとき、樹脂の流れによってボンディングワイヤが押し流されて変形する不良を何と呼ぶか。
  46. 封止樹脂の温度がガラス転移温度(Tg)を超えると起こる変化として正しいものはどれか。
  47. 非常に薄いチップをつくるため、ウエハの表面から途中の深さまで溝を切っておき、その後に裏面を研削してチップに分割する方法はどれか。
  48. スマートフォンなどの高密度な実装で、パッケージの表面に金属膜をスパッタなどで形成する目的として正しいものはどれか。
  49. リフローで、チップ抵抗などの小さな部品の片側だけが浮き上がって立ってしまう不良を何と呼ぶか。
  50. ワイヤボンディングの際の力や超音波によって、電極パッドの下の絶縁膜やシリコンが割れる不良を何と呼ぶか。

この分野の比較

  • ワイヤボンディングとフリップチップの違い：チップの接続方法を比較ワイヤボンディングとフリップチップを、接続のしかた・入出力の数・電気的な性能・コスト・大きさ・工程・用途の観点で表にして比較します。
  • BGA・QFP・QFNの違い：ICパッケージの種類を比較BGA、QFP、QFNのパッケージを、端子・ピン数・ピッチ・大きさ・電気的な性能と放熱・検査・用途の観点で表にして比較します。
