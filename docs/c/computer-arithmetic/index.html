計算機算術の要点

コンピュータは数を有限のビットで表すため、表せる範囲と精度に限りがあります。小数点の位置を固定する固定小数点に対し、IEEE 754の浮動小数点は数を符号・指数・仮数に分けて、非常に小さい数から大きい数までを表します。正規化、非正規化数、丸めモード、無限大やNaNといった特殊値の扱いを知ることが大切です。

浮動小数点の計算では丸め誤差が生じ、近い数どうしの引き算で有効な桁が減る桁落ちも起こります。AIではbfloat16・FP16・FP8・INT8のような短い形式が使われます。数の表し方とともに、乗算器や除算器、桁上げ先見加算器など、算術をハードウェアで実現する回路の構成も学びます。
