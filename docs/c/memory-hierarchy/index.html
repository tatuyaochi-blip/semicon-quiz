メモリ階層と性能の要点

CPUの演算は1ナノ秒もかからないのに、主記憶のDRAMからデータを読むには数十〜100ナノ秒かかります。この差を埋めるため、コンピュータは小さく速いキャッシュから大きく遅い主記憶やストレージまでを階層に重ね、よく使うデータを速い場所に置いています。

キャッシュがうまく働くのは、プログラムに時間的局所性と空間的局所性があるからです。ダイレクトマップやセットアソシアティブの構成、アドレスをタグ・インデックス・オフセットに分ける計算、ミスの3分類、平均メモリアクセス時間の求め方を知ると、データの並べ方やループの順番で性能が何倍も変わる理由が分かります。
