クリーンルーム・製造装置の要点

半導体の製造では、微小なパーティクルでも不良の原因になるため、空気中の粒子を極めて少なく保ったクリーンルームで作業します。清浄度は、一定体積の空気に含まれる粒子の数で表します。

300 mmウエハの工場では、ウエハをFOUPという密閉容器に入れて自動搬送し、装置の中だけを高い清浄度に保つ方式が一般的です。

クリーンルーム・製造装置の問題一覧（50問）
  1. クリーンルームの清浄度は、一般に何によって表されるか。
  2. リソグラフィ工程のエリアで黄色い照明が使われている主な理由はどれか。
  3. FOUPの説明として正しいものはどれか。
  4. クリーンルームで、天井から床へ一方向に空気を流す(ダウンフロー)方式の主な目的はどれか。
  5. クリーンルームの空気から微粒子を取り除くために使われる高性能フィルタはどれか。
  6. ウエハの周りの狭い空間だけを高い清浄度に保つ考え方を何と呼ぶか。
  7. クリーンルーム内の気圧を周囲より高く(陽圧に)保つ主な理由はどれか。
  8. クリーンルームでの主要な発塵源の一つで、クリーンスーツの着用で対策するものはどれか。
  9. クリーンルームで、粒子ではなくガス状の汚染物質(酸、アルカリ、有機物など)を指す用語はどれか。
  10. 300 mmウエハの工場で、FOUPを天井のレールに沿って装置間で自動搬送するシステムはどれか。
  11. クリーンルームの入口で、作業者に強い清浄空気を吹き付けて衣服の表面のほこりを落とす設備はどれか。
  12. クリーンルーム、特に露光エリアで温度を非常に厳しく一定に保つ主な理由はどれか。
  13. 露光装置などの精密装置で、床から伝わる振動の影響を抑えるために用いられるものはどれか。
  14. クリーンルームで、空気中にイオンを供給してウエハや装置の帯電を中和する装置はどれか。
  15. 製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。
  16. クリーンスーツに求められる性質として正しいものはどれか。
  17. 天井にフィルタとファンを一体化して並べ、清浄な空気を送り出す装置はどれか。
  18. クリーンルームの湿度を極端に低くしすぎないように管理する理由の一つとして正しいものはどれか。
  19. クリーンルーム内への持ち込みが厳しく制限されるものはどれか。
  20. 半導体工場で一般的な、装置のレイアウトの考え方として正しいものはどれか。
  21. FOUPの内部を窒素で置換(パージ)する主な目的はどれか。
  22. 200 mmウエハの時代に普及した、カセットを密閉したポッドに入れて装置に受け渡すミニエンバイロメントの方式はどれか。
  23. ダウンフロー方式のクリーンルームで、床に穴のあいたパネル(グレーチング)を使う理由として正しいものはどれか。
  24. 真空を使うプロセス装置で、反応で生成した有害な物質を含む排ガスを、装置ごとに処理する装置はどれか。
  25. 瞬時電圧低下(瞬低)や停電による、製造中のウエハの損失を防ぐために半導体工場で導入される設備はどれか。
  26. 旧米国連邦規格のクラス100(1立方フィートあたり0.5 µm以上の粒子が100個以下)に相当するISO 14644-1の清浄度クラスはどれか。
  27. ダウンフロー方式のクリーンルームで一般的な、天井からの吹き出し風速の目安はどれか。
  28. ベイ・チェイス方式のクリーンルームで、装置の裏側の保守用の空間(チェイス)の清浄度の扱いとして一般的なものはどれか。
  29. ガラス繊維のフィルタなどから放出され、ウエハの意図しないドーピング(汚染)の原因になることがある元素はどれか。
  30. クリーンルームの一般的な温度の設定値に最も近いものはどれか。
  31. クリーンルームの空気中に含まれる微粒子の数と大きさを測るために使われる装置はどれか。
  32. クリーンルームの入口などの床に置かれ、靴底に付いたほこりを取り除くためのものはどれか。
  33. クリーンルームの作業者から出る粒子の量について正しいものはどれか。
  34. 回路の微細化が進むにつれて、クリーンルームで管理すべき粒子の大きさはどう変わるか。
  35. ウエハを素手で触ってはいけない主な理由はどれか。
  36. ISO 14644-1の清浄度クラスについて正しい説明はどれか。
  37. 天井の一部から清浄な空気を吹き出し、室内の空気と混ぜて薄めながら清浄度を保つ方式のクリーンルームはどれか。清浄度は一方向流より低いが、設備費は安い。
  38. クリーンルームの空気から、アンモニアや有機物などの分子状汚染(AMC)を取り除くために使われるフィルタはどれか。
  39. クリーンルームの空調で、取り入れた外気を除じんし、温度と湿度を調整してから室内の循環空気に供給する装置はどれか。
  40. 半導体工場の自動搬送システムで、次の工程に進むまでのFOUPを一時的に保管する自動倉庫はどれか。
  41. ベイ方式の工場の自動搬送で、ベイとベイの間の搬送と、ベイの中で装置間を結ぶ搬送の呼び方の組み合わせとして正しいものはどれか。
  42. 仕切りの少ない大きな部屋の中に製造装置を並べ、FOUPなどの密閉容器とミニエンバイロメントでウエハの清浄度を確保するクリーンルームの方式はどれか。
  43. 高い清浄度のダウンフロー方式のクリーンルームで、1時間に部屋の空気が入れ替わる回数(換気回数)の目安として最も近いものはどれか。
  44. クリーンルームの床材や作業台に、導電性(静電気を逃がす性質)をもつ材料が使われる主な理由はどれか。
  45. HEPAフィルタの性能の一般的な定義として正しいものはどれか。
  46. 化学増幅型レジストを使う露光エリアで、アンモニアやアミンなどの塩基性の分子状汚染を特に厳しく管理する理由はどれか。
  47. 半導体工場で、高純度のガスを供給するステンレス配管の内面に電解研磨(EP)が施される主な理由はどれか。
  48. 半導体工場のクリーンルームの床に使われる、格子状に穴のあいた厚いコンクリートの床(ワッフルスラブ)の役割として正しいものはどれか。
  49. 半導体工場などの精密施設で、床の振動の許容レベルを周波数ごとの振動速度で段階的に示した指標はどれか。
  50. 電子ビーム描画装置や電子顕微鏡などを設置するとき、振動のほかに特に配慮が必要な環境の要因はどれか。
