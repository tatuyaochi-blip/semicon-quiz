ダイオードとは? 電流を一方向にだけ流すしくみと使い道

約14分 · 更新: 2026年10月23日

ダイオードは、電流を一方向にだけよく流し、逆向きにはほとんど流さない半導体の部品です。中身は、性質の違う2種類の半導体をつないだ境目(PN接合)です。コンセントの交流を直流に変える充電器や、回路を守る部品に使われ、LEDや太陽電池もその仲間です。

この記事でわかること

  • ダイオードが電流の「一方通行」になるしくみ
  • シリコンのダイオードで「約0.6〜0.7ボルト」という数字が出てくる理由
  • 逆向きの電圧をかけすぎると起きる「降伏」とは何か
  • 交流を直流に変える「整流」と、回路を守る使い方
  • ツェナーダイオード、ショットキーダイオード、LED・太陽電池との関係

前提知識: n型とp型(電子が多い半導体と、電子の空席である正孔が多い半導体)を知っていると読みやすくなります(「半導体とは?」)。式は使いません。

身近なところでは

スマホの充電器やノートパソコンのACアダプタの中には、コンセントの電気を機器が使える形に変えるため、ダイオードが入っています。LED電球の光る部分や、テレビのリモコンの先で赤外線を出す部分も、ダイオードの一種です。

車や家電の基板にも、たくさんのダイオードが載っています。CPUのようなチップの中にも、静電気から回路を守るダイオードが作り込まれています。

回路図では、ダイオードを三角形と縦の棒を組み合わせた記号で表します。三角形が指す向きが、電流がよく流れる向きです。2本の端子には名前があり、電流が入る側をアノード、出ていく側をカソードと呼びます。

しくみ① 電流の一方通行

電池とダイオードをつないで、電流を流してみます。記号の三角形の向きに電流が流れるようにつなぐと、電流はよく流れます。この向きを順方向と呼びます。反対につなぐと、電流はほとんど流れません。こちらは逆方向です。

電圧の向きで電流の流れやすさが大きく変わるこの性質を、「整流作用」と呼びます。ダイオードには、オン・オフを指示するための端子がありません。かかっている電圧の向きと大きさだけで、通すか止めるかが決まります。ここが、電圧でオン・オフを操作するトランジスタとの違いです。

たとえで言うと

ダイオードは、水道管の「逆止弁」に似ています。逆止弁は、水が決まった向きに流れると弁が押し開けられ、逆向きに流れようとすると弁が閉じる部品です。人が操作しなくても、流れの向きだけで開け閉めが決まる点が、ダイオードと同じです。

たとえが当てはまらない点: 逆止弁には動く弁がありますが、ダイオードには動く部品がありません。中で変わるのは、電子と正孔の集まり方です。また、ダイオードは逆向きにもごくわずかに電流が流れ、逆向きの電圧が大きすぎると急に流れ出します(後で説明します)。水の流れのたとえは、電子が動く速さの説明には使えません。

しくみ② 中身はPN接合

ふつうのダイオードは、p型とn型の半導体をくっつけて作ります。n型は電気の運び手として電子が多い半導体、p型は電子の空席である「正孔」が多い半導体です。2つが接する境目を、PN接合と呼びます。

境目のすぐ近くでは、n型の電子とp型の正孔の一部が相手側へ移り、出会って消えます。その結果、境目には、動ける電子も正孔もほとんどない薄い層ができます。この層を空乏層と呼びます。

空乏層の中では、電子が去ったn型の側がプラスに、正孔が去ったp型の側がマイナスに帯びます。この電気の偏りが、電子や正孔がそれ以上境目を越えないように押し戻します。境目に、電子や正孔にとっての「坂」ができた状態です。

PN接合は、1940年に米国ベル研究所のラッセル・オールが、シリコンの試料の中で見つけました(米国コンピュータ歴史博物館)。この発見は、のちの太陽電池やトランジスタにつながりました。

p型の側を電池のプラスに、n型の側をマイナスにつなぐのが順方向です。外からの電圧が境目の坂を低くするので、電子と正孔が次々に境目を越え、相手側で出会って消えます。消えた分は電池から補われるため、電流が流れ続けます。

反対につなぐと、電子と正孔はそれぞれ電極の側へ引き寄せられ、境目から離れます。空乏層は広がり、坂は高くなります。越えられる電子や正孔がほとんどいないので、電流はほとんど流れません。

しくみ③ 「0.6〜0.7ボルト」の意味

順方向につないでも、電圧がごく小さいうちは、坂を越えられる電子や正孔が少なく、電流はわずかしか流れません。シリコンのダイオードでは、電圧が0.6〜0.7ボルトほどになると、電流がはっきり流れ始めます。この、電流を流すときにダイオードの両端にかかる電圧を「順方向電圧」と呼びます。

この数字は、境目の坂の高さと関係しています。外から電圧をかけないときの坂の高さを電圧で表したものを内蔵電位と呼び、シリコンでは0.6〜0.9ボルト程度です。外からの電圧でこの坂を十分に低くすると、電子と正孔がまとまって越えられるようになります。

大事なのは、0.6〜0.7ボルトが「ここで突然流れ出す」境目ではないことです。電流は電圧に対してなめらかに、しかしとても急に増えます。小さな電流用(小信号用)のダイオード1SS181の、東芝のデータシートにある標準的な値を見ます。1ミリアンペア(1000分の1アンペア)では0.61ボルトです。10ミリアンペアでは0.74ボルト、100ミリアンペアでは0.92ボルトになります。電流が10倍になっても、電圧は0.1〜0.2ボルトほどしか増えません。

そのため回路の見積もりでは、「約0.6〜0.7ボルト」と覚えておくと便利です。ただし大きな電流では、部品の中の抵抗の分も加わり、1ボルト前後になります。

たとえで言うと

順方向電圧は、坂を越えるたくさんのボールにたとえられます。ボールの勢いはばらばらで、坂が高いうちは、たまたま勢いの強い少数だけが越えます。外から坂を低くしていくと、越えられるボールの数が急に増えます。電流がなめらかに、しかし急に増える理由が、このたとえでわかります。

たとえが当てはまらない点: 本物の坂は場所の高さではなく、電子のエネルギーの差を表しています。ボールの勢いのばらつきは、温度による電子の動きのばらつきにあたります。また、越えた電子が相手側で正孔と出会って消えることや、電子が回路を進む速さは、このたとえでは表せません。

順方向電圧は温度でも変わります。シリコンのダイオードに同じ電流を流したまま温度を1℃上げると、約2ミリボルト(0.002ボルト)下がります。チップの中には、この性質を使って温度を測るダイオードを持つものもあります(東芝)。

材料が変わると、順方向電圧も変わります。LEDの材料は、シリコンより電子のエネルギーの「段差」(バンドギャップ)が大きく、境目の坂も高くなります。そのため順方向電圧も高く、ロームの製品で20ミリアンペアを流すときの代表値は、赤いLEDで1.9ボルト、青いLEDで3.2ボルトです。

しくみ④ 逆向きの限界: 降伏

逆方向につないだときも、電流は完全にゼロではありません。熱によってわずかに生まれる電子と正孔が、境目を通るからです。例えば小信号用ダイオード1N4148の規格では、20ボルトをかけたときの逆方向の電流は、25℃で最大25ナノアンペアです。1ナノアンペアは10億分の1アンペアです。ただし150℃では、上限がその2000倍に増えます。

逆向きの電圧をさらに大きくしていくと、ある電圧で急に大きな電流が流れ出します。これを「降伏」(ブレークダウン)と呼びます。降伏が起きる電圧は、製品ごとに設計で決めます。例えば整流用の1N4007は、逆方向に1000ボルトまでならくり返しかけてよい規格です。

降伏の起こり方は、主に2つあります。1つは、空乏層の強い電気の力で加速された電子が原子にぶつかり、新しい電子と正孔を作る現象です。作られた電子もまた加速されてぶつかり、雪崩のように数が増えます。これをなだれ降伏と呼びます。

もう1つは、不純物を多く入れて空乏層をとても薄くしたときに起きます。電子が、越えられないはずの薄い壁を、量子力学の性質ですり抜けるのです(「トンネル効果とは?」)。このすり抜けによる降伏を、ツェナー降伏と呼びます。

降伏は、それだけでダイオードを壊すものではありません。壊れる原因は、大きな電圧と電流が同時にかかったときに出る熱です。熱を許せる範囲に抑えれば、降伏した状態で使い続けることもできます。これを利用したのが、後で紹介するツェナーダイオードです。

使い道① 交流を直流に変える(整流)

家のコンセントの電気は、流れる向きの行き来を、1秒間に50回(東日本)または60回(西日本)くり返します。このように向きが入れ替わる電気を、交流と呼びます。一方、スマホの電池や電子回路は、向きが一定の電気で動きます。こちらを直流と呼びます。

交流の通り道にダイオードを1個入れると、一方の向きの半分だけが通り、逆向きの半分は止められます。これを半波整流と呼びます。電流の向きはそろいますが、半分の時間は電気が届きません。

ダイオードを4個、ひし形に組み合わせると、逆向きの半分も向きを折り返して通せます。どちらの向きの電流も、出口では同じ向きに流れるようにつないであるのです。これを全波整流と呼びます。

整流しただけの電気は、向きはそろっても、大きさが波打っています。そこで、電気を一時的にためて放す部品(コンデンサ)をつなぎ、波をならします。これで、向きも大きさもほぼ一定の直流に近づきます。

今の充電器の多くは、まずコンセントの交流を、4個のダイオードの組(ダイオードブリッジ)で整流し、コンデンサでならします。それを1秒間に数万回以上の速さで細かく切り替え、小さな変圧器に通して電圧を下げます。最後にもう一度整流してならし、スマホに送る直流にします(ローム)。速く切り替えるほど変圧器を小さくできるので、充電器が小さく軽くなります。

使い道② 回路を守る

ダイオードは、回路を守る役目もします。例えば電池を逆向きに入れても電流が流れないように、電池の通り道にダイオードを入れておく方法があります。順方向電圧の分だけ電気は少し失われますが、入れまちがいで中の回路を傷めずにすみます。

モーターや、電磁石で動くスイッチ(リレー)のように、コイル(電線を巻いたもの)を使う部品にも欠かせません。コイルには、流れている電流を流し続けようとする性質があります。そのためスイッチを切った瞬間に高い電圧が生まれ、ほかの部品を壊すことがあります。コイルと並べてダイオードをつないでおくと、電流の逃げ道になり、この高い電圧を抑えられます。

人の体にたまった静電気が、指先から端子へ一瞬で流れることがあります。これをESD(静電気放電)と呼び、チップの中の薄い膜などを壊すことがあります。そこでチップの端子には、余分な電流を回路の外へ逃がすダイオードが作り込まれています。基板の上に、保護専用のダイオードを置くこともあります(東芝)。

ダイオードの仲間

ダイオードには、目的に合わせて作り方を変えた仲間がいくつもあります。

種類使う状態主な使い道
整流用(ふつうのPN接合)順方向で通し、逆方向で止める充電器・電源
ツェナーダイオード逆方向の降伏一定の電圧を作る、保護
ショットキーダイオード順方向(低い電圧で流れる)電源の効率を上げる
LED(発光ダイオード)順方向光を出す

ツェナーダイオード: 降伏を使って電圧をそろえる

ツェナーダイオードは、降伏が狙った電圧で起きるように作ったダイオードです。逆方向に電流を流しておくと、両端の電圧がほぼその値に保たれます。この性質で、一定の電圧を作ったり、電圧が上がりすぎないように抑えたりします。

名前は、物理学者クラレンス・ツェナーにちなみます。絶縁体の中で電子が壁をすり抜けて起きる降伏を、1934年に理論で説明した人です。ただし、ツェナー降伏が主に働くのは、降伏の電圧がおよそ5ボルトより低い品種です。それより高い品種では、主になだれ降伏が起きています(東芝、Nexperia)。しくみが違っても、まとめてツェナーダイオードと呼ぶのが習慣です。

ショットキーダイオード: 低い電圧で速く切り替わる

ショットキーダイオードは、PN接合の代わりに、金属と半導体の接合を使います。順方向電圧は、東芝の解説では決められた電流を流したときに0.4〜0.7ボルト程度で(使う金属で変わります)、同じ条件のPN接合より低い値です。電圧で失われる電気が減るので、電源の効率を上げられます。

PN接合のダイオードは、逆向きに切り替えた直後、中に残った電子と正孔が消えるまで、少しの間だけ逆に電流が流れます。ショットキーダイオードにはこの遅れがほとんどなく、速く切り替える電源に向いています。弱点は、逆方向の漏れ電流が大きく、シリコン製では高い電圧に弱いことです。高い電圧向けには、炭化ケイ素(SiC)で作ったものが使われます(「パワー半導体とは?」)。

LED・フォトダイオード・太陽電池: 光とやりとりする仲間

LEDは、順方向に流した電子と正孔が境目で出会うときのエネルギーを、光として出すダイオードです。色が材料で決まるしくみは「LEDはなぜ光る?」で説明しています。

フォトダイオードと太陽電池は、その逆向きの働きをします。光が境目の近くで電子と正孔の組を作り、空乏層の電気の力がそれを引き離して電流にします。カメラの画素では光の量を測るために(「イメージセンサとは?」)、太陽電池では電力を得るために使います(「太陽電池はなぜ発電できる?」)。

よくある誤解

誤解: 0.7ボルトまでは電流がまったく流れず、超えたとたんに一気に流れる

実際は、電流は電圧とともになめらかに、とても急に増えます。0.6〜0.7ボルトは、ふつうの回路で使う大きさの電流が流れる電圧の目安です。回路の計算で「0.7ボルトでオン」と単純化して教えることが多いため、本当に境目があると思われがちです。

誤解: 降伏したダイオードは壊れている

実際は、降伏そのものは元に戻る現象です。壊れるのは、大きな電流が流れて熱が出すぎたときです。ツェナーダイオードや保護用のダイオードは、降伏した状態で働くように作られています。「ブレークダウン(破壊)」という名前から、この誤解が生まれます。

誤解: ダイオードを通せば、きれいな直流になる

実際は、ダイオードがするのは向きをそろえることだけで、整流した直後の電気は大きさが波打っています。コンデンサで波をならし、電圧を整える回路を通して、ようやく電子機器が使える直流になります。「交流を直流に変える部品」と短く説明されることが多いため、こう思われがちです。
