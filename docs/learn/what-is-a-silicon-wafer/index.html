シリコンウエハとは? 石から鏡のような円板ができるまで

約14分 · 更新: 2026年10月23日

シリコンウエハは、原子の並びが全体でそろったシリコンの結晶でできた、厚さ1 mm足らずの円い板です。表面は鏡のように磨いてあります。この板の上で、チップを数百〜数千個まとめて作ります。円いのは、溶かしたシリコンから回しながら引き上げて育てた円柱の結晶を、輪切りにするからです。

この記事でわかること

  • ウエハとは何か、なぜ円い板の上でチップを作るのか
  • 石から、とても純度の高いシリコンを作るまで
  • 単結晶を育てる方法と、鏡のように磨くまでの工程
  • 平らさと、ごみのなさが大事な理由
  • ウエハが大きくなってきた理由と、作っている会社

前提知識: とくになし。「チップは1枚の板の上でまとめて作る」と知っていると読みやすくなります。全体の流れは「半導体チップはどうやって作られる?」で説明しています。

身近なところでは

半導体の工場のニュースでは、「月に◯万枚」のように、作る量を枚数で表すことがよくあります。この「枚」が数えているのがウエハです。ウエハは、チップを作るための土台になる円い薄い板です。工場に届いたときは、まだ回路のない、鏡のようにぴかぴかの板です。

日本は、このウエハを作る会社が強い国としても知られています。世界の主なウエハメーカーのうち、2社が日本の会社です(後半で紹介します)。半導体の会社に入ると、「12インチ」「ノッチ」「エピ」など、ウエハにまつわる言葉をよく耳にします。この記事では、そうした言葉の意味も順に説明します。

ウエハとは: 1つの結晶でできた円い板

量産で使う最も大きなウエハは、直径300 mmです。大きめのお皿ほどの広さがあります。厚さは約0.775 mmで、クレジットカード(約0.76 mm)とほぼ同じです。重さは計算すると約130 gです。

大事なのは、板全体が1つの結晶になっていることです。結晶とは、原子が決まった規則で並んだ固体のことです。ウエハでは、原子の並びが端から端まで同じ向きにそろっています。このような結晶を「単結晶」と呼びます。

並びの向きが違う小さな粒の集まりだと、粒の境目で電気の流れ方が変わってしまいます。チップには何十億個ものトランジスタ(電気のスイッチ)が入っていて、それらを同じ性質にそろえる必要があります。そのため、どこをとっても同じ並びの単結晶が必要なのです。

回路を作るのは、ウエハの表面のごく浅い部分だけです。残りの厚みは、作る途中で割れたり反ったりしないための支えです。回路ができたあとは、多くの場合、ウエハの裏側を削って薄くしてから、チップに切り分けます。

なぜ円い板の上でまとめて作るのか

チップはとても小さいので、1個ずつ作ると手間がかかり、品質もそろいません。そこで、1枚の板に同じチップを碁盤の目のように並べ、まとめて加工します。直径300 mmのウエハなら、10 mm角のチップがおよそ600個並びます。

ウエハが円いのは、材料の結晶を育てるときに、回しながら引き上げるからです。結晶は円柱の形に育ち、それを輪切りにするので円い板になります。四角いチップを円い板に並べると、縁では欠けてしまうチップが出ます。それでも、大きく質のよい単結晶を作るには、この育て方が向いているのです。

石から、純度の高いシリコンへ

シリコンは、砂や岩に含まれる二酸化ケイ素(シリコンと酸素が結びついたもの)の形で、身近にたくさんあります。原料には、二酸化ケイ素をとても多く含むけい石(石英の岩)を使います。浜辺の砂をそのまま使うわけではありません。

まず、けい石を炭素と一緒に電気炉に入れ、高温に熱します。すると炭素が酸素を奪い、シリコンが残ります。こうしてできるものを「金属シリコン」と呼びます。純度は98〜99%ほどで、半導体に使うにはまだ足りません。

次に、金属シリコンを塩化水素と反応させて、常温で液体になる化合物に変えます。液体なら、蒸留をくり返して不純物を取り除けます。きれいにした化合物を水素と一緒に反応炉へ送ると、熱した細いシリコンの棒の表面に、シリコンが少しずつ積もります。この作り方をシーメンス法と呼びます。

積もってできたシリコンは、小さな結晶の粒がたくさん集まったものです。粒ごとに原子の並びの向きが違うので、「多結晶シリコン」と呼びます。純度はとても高いのですが、このままではチップには使えません。

純度は「99.9999999%」のように、9が並ぶ数で表します。半導体用では、9が9〜11個並ぶ水準とする資料が多くあります。国内の大手メーカーは、9が11個の「イレブンナイン」を当然の水準としています(2026年の報道)。これは、原子1000億個あたり不純物が1個以下ということです。

ここまで純度を上げるのは、ごく少量の不純物をわざと加えて、電気の通しやすさを決めるためです。くわしくは「半導体とは?」で説明しています。

単結晶を育てる: CZ法

多結晶シリコンを、石英でできた耐熱の器(るつぼ)に入れ、1,400 ℃あまりで溶かします。このとき、ホウ素やリンなどを、ごくわずか加えておきます。育つ結晶に、狙った電気の通しやすさを持たせるためです。

溶けたシリコンの表面に、小さな単結晶のかけらを浸します。このかけらを「種結晶」と呼びます。種結晶を回しながら、ゆっくり引き上げていきます。

種結晶にふれた溶けたシリコンは、少し冷えて固まります。固まるとき、原子は種結晶と同じ向きに並びます。これが次々に続くので、種と同じ並びのまま、太く長い単結晶が下へ育ちます。引き上げる速さと温度を調整して、太さを一定にそろえます。

この育て方をCZ法と呼びます。ポーランド出身の化学者チョクラルスキーが、1916年に見つけた方法がもとになっています。もとは金属の結晶を調べるための方法で、のちにシリコンに使われるようになりました。

たとえで言うと

種結晶の役目は、タイル貼りの最初の1枚に似ています。最初の1枚の向きに合わせて次々に貼っていけば、壁全体の目地がまっすぐそろいます。CZ法でも、種結晶の原子の並びが手本になり、育った結晶全体の向きが種と同じにそろいます。似ているのは「最初の1つが、全体の向きを決める」という一点です。

たとえが当てはまらない点: タイルは人が1枚ずつ置きますが、結晶では、液体から固まる原子が自分で手本の並びに収まります。また、タイルは平面に並べますが、結晶は立体的に育ちます。並びがまったく乱れないわけではなく、温度などの条件がくずれると結晶に欠陥ができます。

育った円柱の塊をインゴットと呼びます。両端の太さがそろわない部分を切り落とし、外周を削って直径をそろえます。

CZ法では、石英のるつぼが、溶けたシリコンの中へ少しずつ溶け出します。そのため、結晶にはわずかに酸素が入ります。るつぼを使わないFZ法なら、器にふれないので、酸素などが混じりにくい結晶ができます。ただ、大きな直径の結晶を作りにくく、高い電圧を扱うパワー半導体など、一部の用途で使われます。量産のウエハの大部分はCZ法で作られています。2つの違いは「CZ法とFZ法の違い」で比べられます。

切って、削って、鏡のように磨く

インゴットからウエハにするまでには、いくつもの加工があります。順番に見ていきます。

  1. 目印をつける: 外周に小さなV字の切り欠きを入れます。結晶の並びの向きを示す目印で、ノッチと呼びます。工場の装置は、これを見てウエハの向きをそろえます。
  2. 薄く切る: 細いワイヤーを何百列も平行に張って走らせる切断機で、インゴットを一度にたくさんの円い板に切ります。厚さは1 mm足らずです。
  3. 縁を丸める: 板の縁が角ばっていると、ぶつかったときに欠けて、割れやごみのもとになります。そこで縁を丸く削ります。
  4. 厚さと平らさを整える: 両面を削って、板の厚さをそろえ、平らにします。
  5. 傷んだ層を溶かす: 機械で切ったり削ったりすると、表面近くに細かい傷やひずみが残ります。これを薬液で溶かして取り除きます。
  6. 鏡のように磨く: ごく細かい粒を含んだ薬液と、やわらかいパッドで表面を磨きます。薬液が表面のシリコンと反応して削れやすくし、そこを粒が少しずつ削り取ります。
  7. 洗って検査する: 表面の小さなごみや汚れを洗い落とし、平らさや厚さを測ります。

検査では、表面にレーザーの光を当てます。小さなごみの粒があると、そこで光が散らばるので、粒の数と場所がわかります。合格したウエハは、ごみが入らない専用の容器に入れて出荷します。

用途によっては、磨いたウエハの上に、さらに薄い単結晶の層を育てることがあります。下の結晶の並びを引き継いで層が育つので、この方法をエピタキシャル成長と呼びます。こうして作ったウエハが、現場で「エピ」と呼ばれる「エピタキシャルウエハ」です。表面の層だけ欠陥を減らしたり、電気の通しやすさを変えたりできます。

このほか、表面の薄いシリコンの下に、電気を通さない膜をはさんだウエハもあります。「SOIとバルクシリコンの違い」で、ふつうのウエハと比べられます。

なぜ平らで、ごみがあってはいけないのか

チップの工場では、光を使って回路の模様をウエハに写します。この作業を露光と呼びます。露光装置は、レンズや鏡で模様を縮めてウエハに映します。このとき、模様がくっきり写る高さの範囲は、とても狭いのです。

この範囲を焦点深度と呼びます。細かい模様を写すために、広い角度から光を集めるレンズを使うほど、焦点深度は浅くなります。ウエハの表面にわずかな凹凸があると、そこだけピントが外れ、模様がぼやけます。

露光装置は、場所ごとに高さを測ってピントを合わせ直しています。それでも、一度に写す範囲(数cm角)の中の細かい凹凸までは、直しきれません。そのため、ウエハそのものを、とても平らにしておく必要があります。細かい模様を写す露光のしくみは「EUV露光とは?」で説明しています。

ごみの粒も大敵です。粒が乗った場所では、模様が正しく写らなかったり、配線がつながったり切れたりします。そのチップは不良になり、良品の割合(歩留まり)が下がります。そのため、ウエハは出荷の前から、ごみの数まで厳しく調べられています。

なぜウエハは大きくなってきたのか

初期のウエハは、直径が数cmほどでした。その後、主に100 mm、150 mm、200 mm、300 mmと、段階を追って大きくなりました。300 mmのウエハでの量産は、2001年ごろに始まりました。300 mmは、現場では「12インチ」とも呼ばれます(正確には、12インチは約305 mmです)。

大きくする理由は、1枚から取れるチップを増やすためです。面積は直径の2乗に比例するので、300 mmのウエハの面積は、200 mmの2.25倍です。多くの工程は1枚ずつ、またはまとめて処理するので、1枚が大きいほど、1回の処理で作れるチップが増えます。

取れるチップの数は、面積の比以上に増えます。当サイトの計算ツールで10 mm角のチップを数えてみます。200 mmでは約260個、300 mmでは約610個で、約2.4倍です。縁で欠けるむだの割合が、大きいウエハほど小さくなるからです。欠けるのは縁に沿った細い帯で、その長さ(円周)は直径に比例してしか増えません。ダイ数・歩留まり計算ツールで、ウエハの直径やチップの大きさを変えて試せます。

一方で、直径を変えると、工場の装置をほとんど作り直さなければなりません。次の450 mmに向けては、2011年に米国で共同開発の団体(G450C)ができました。インテル、TSMC、サムスン電子などが参加しました。しかし参加した会社は、次の段階へ進む時期ではないと判断しました。団体は2016年の終わりに活動を終えています(EE Times、2017年1月の報道)。2026年の時点でも、量産で使う最大のウエハは300 mmです。

小さいウエハがなくなったわけでもありません。パワー半導体やセンサー、アナログの部品などは、今も200 mmのウエハの工場で作られています(業界団体SEMIの説明)。最先端の細かさが要らない部品では、使い慣れた設備で作るほうが合っているからです。

だれがウエハを作っている?

ウエハは、半導体のメーカーが自分で作るのではなく、専門のウエハメーカーから買うのがふつうです。ウエハメーカーは、結晶を育て、磨き、検査して出荷するまでを受け持ちます。回路を作り込むのは、それを買った半導体メーカーや、製造を請け負う会社(ファウンドリ)です。

シリコンウエハの主なメーカーとして、次の5社がよく挙げられます。

  • 信越化学工業(日本。グループの信越半導体がウエハを作っています)
  • SUMCO(日本)
  • GlobalWafers(台湾)
  • Siltronic(ドイツ)
  • SK siltron(韓国)

市場での割合(シェア)の数字は、調べた機関や年によって違いがあります。そのため、この記事では載せていません。原料の多結晶シリコンを作る会社や、結晶を育てる装置を作る会社は、またそれぞれ別にあります。

よくある誤解

誤解: 浜辺の砂を溶かして、ウエハを作っている

実際は、二酸化ケイ素をとても多く含むけい石を原料にします。砂と同じ成分ですが、そのまま溶かすのではありません。いったん金属シリコンにし、液体の化合物に変えて精製し、さらに単結晶に育てます。「砂からチップができる」という言い方は、成分が同じことを表した、短い言い方です。

誤解: ウエハの厚み全体に、回路が詰まっている

実際は、回路を作るのは表面のごく浅い部分だけです。残りの厚みは、工程の途中で割れたり反ったりしないための支えです。完成したあとは、多くの場合、裏側を削って薄くします。断面の図では回路の部分を拡大して描くことが多いので、こう思われがちです。

誤解: 大きなウエハほど、性能のよいチップができる

実際は、ウエハの直径が変えるのは、主に1枚から取れるチップの数と費用です。チップの速さや省電力は、回路の細かさや設計で決まります。200 mmのウエハで作るパワー半導体やセンサーも、それぞれの用途で大事な部品です。最先端のチップが300 mmで作られるので、大きさと性能が結びつけられやすいのです。
