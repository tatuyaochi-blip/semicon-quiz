DRAMとは? データを電気でためるメモリのしくみ

約14分 · 更新: 2026年10月23日

DRAM(ディーラム)は、パソコンやスマホ、サーバーの「メモリ」に使われている半導体のチップです。1ビットを、小さなスイッチと、電気をためる小さな入れ物の1組で覚えます。入れ物の電気は少しずつ漏れるので、数十ミリ秒ごとに全部を書き直しながら、データを保っています。

この記事でわかること

  • DRAMがどこで、何のために使われているか
  • 1ビットを覚えるしくみと、書き直し(リフレッシュ)が必要な理由
  • 読むと中身が減ってしまう問題と、それを補う回路
  • 「ランダムアクセス」の意味、「DDR5」「LPDDR」などの名前の読み方、主なメーカー

前提知識: メモリが「作業中のデータを置く場所で、電源を切ると消える」と知っていると読みやすくなります。「メモリとストレージの違い」で説明しています。

身近なところでは: 「メモリ16GB」の中身

パソコンの仕様表には「メモリ 16GB DDR5」、スマホには「RAM 8GB」などと書かれています。この「メモリ」や「RAM」の正体が、DRAMのチップです。CPUが作業する間、プログラムやデータを置いておく場所になります。

デスクトップのパソコンでは、DRAMのチップを何枚か細長い基板に載せ、差し込み口に挿して使います。この板の代表的な形をDIMM(ディム)と呼びます。挿す枚数を変えれば、後から容量を増やせます。

スマホや薄いノートパソコンでは、DRAMのチップを基板に直接はんだ付けします。場所を節約できる代わりに、後からは増やせません。データセンターのサーバーは、パソコンよりずっと多くのDRAMを積みます。AIの計算に使うチップ(GPU)のそばにも、DRAMを積み重ねた部品が置かれています。

形や置き場所は違っても、データを覚えるしくみはどれも同じです。この記事では、そのしくみを順に見ていきます。

しくみ① 1ビットは「スイッチ」と「入れ物」の1組

DRAMは、0か1かの1つ分(1ビット)を、部品2つで覚えます。1つは、電気の通り道をつないだり切ったりするスイッチです。これはトランジスタです(「トランジスタとは?」)。

もう1つは、電気をためる小さな入れ物で、コンデンサ(キャパシタ)と呼ばれる部品です(「コンデンサとは?」)。入れ物に電気がたまっていれば1、空なら0のように決めておきます。スイッチを切っている間、入れ物は外から切り離され、電気を閉じ込めます。

1ビットを覚えるこの1組を「セル」と呼びます。部品が2つだけなので、とても小さく作れます。1枚のチップには、このセルが数十億個も並んでいます。

スイッチを入れる合図の線は、横一列に並んだセルにまとめてつながっています。この線をワード線と呼びます。1本のワード線に合図を送ると、その列のスイッチが一斉に入ります。

スイッチの反対側は、縦に通る別の線につながっています。データは、この線を通ってセルに出入りします。この線をビット線と呼びます。

このしくみは、1966年にIBMのロバート・デナードが考え出しました。今のDRAMも、基本の形は同じです。1970年には、Intelが製品「1103」を発売しました。1103は1ビットにトランジスタを3個使う、少し違う形のセルでした。それでも、当時の主流だった小さな磁石の輪で覚えるメモリ(磁気コアメモリ)と、値段で競える最初の半導体メモリになりました。

しくみ② 電気は漏れる: だから書き直し続ける

入れ物の電気は、スイッチを切っていても少しずつ漏れていきます。スイッチも入れ物も、電気を完全には止められないからです。放っておくと、1を覚えたセルが、0と見分けられなくなります。

そこでDRAMは、中身が消える前に読み出して、同じ値を書き直します。これをリフレッシュと呼びます。DRAMの「D」は「ダイナミック(動的)」の略で、休みなく手入れが要ることを表しています。

書き直す間隔は、半導体の規格を作る業界団体JEDECが決めています。DDR4という世代では、85℃までなら64ミリ秒(0.064秒)以内に、全部のセルを1回ずつ書き直します。温度が高いと漏れが速くなるので、85℃を超えると32ミリ秒に縮めます。新しいDDR5では、85℃まででも32ミリ秒です。

全部のセルを一度に書き直すと、その間はメモリが使えません。そこでDDR4では、CPU側の回路が64ミリ秒の間に8,192回、書き直しの命令を出します。チップは命令のたびに、一部のセルだけを書き直します。命令は約7.8マイクロ秒(1マイクロ秒は100万分の1秒)に1回です。リフレッシュは、ふだんの読み書きの合間に差し込まれます。

電源を切ると、リフレッシュも止まります。漏れた電気は戻らないので、中身はやがて消えます。これが、DRAMが電源を切ると中身を失う理由です。

しくみ③ 読むと中身が減る: センスアンプが書き戻す

セルの入れ物はとても小さく、ためられる電気はごくわずかです。一方、ビット線はたくさんのセルにつながる長い線です。スイッチを入れると、入れ物の電気はビット線に広がって薄まります。線の電圧は、ほんの少ししか動きません。

そこで読む前に、ビット線を0と1のちょうど中間の電圧にそろえておきます。この準備をプリチャージと呼びます。セルが1なら電圧はわずかに上がり、0ならわずかに下がります。

この小さな上がり下がりを見分けて、はっきりした0か1の電圧に広げる回路があります。これをセンスアンプと呼びます。「感じ取って(sense)大きくする(amplify)」という意味の名前です。

ビット線に広がった電気は、自然には入れ物に戻りません。つまりDRAMは、読むと中身が壊れてしまうメモリです。ただ、センスアンプがはっきりさせた値は、そのままビット線を通って入れ物に書き戻されます。読み出しが、書き直しを兼ねているのです。リフレッシュも、このしくみを使っています。

ここでは話を簡単にするため、センスアンプの中身の回路は省きました。大事なのは、「わずかな差を見分けて広げ、ついでに書き戻す」という役目です。

しくみ④ 行と列で場所を決める: 「ランダムアクセス」の意味

チップの中のセルは、碁盤の目のように縦横に並んでいます。横の並びを行、縦の並びを列と呼びます。読みたい場所は、「何行目の何列目」という番号で指定します。

読むときは、まずワード線で1つの行を選びます。これを「行を開く」と言います。すると、その行のセルが全部、それぞれのビット線を通ってセンスアンプに読み出されます。次に、列の番号で、その中から必要な分だけを外へ出します。MicronのDDR4のチップの例では、1つの行は8,192ビット(1KB)あります。

開いている行の中なら、列を変えるだけで、続けて速く読めます。別の行に移るときは、今の行を閉じ、ビット線をプリチャージし直してから新しい行を開きます。その分、待ち時間が長くなります。

RAMは「ランダム・アクセス・メモリ」の略です。ここでの「ランダム」は、でたらめという意味ではありません。どの番号の場所でも、順番をたどらずに直接読み書きできる、という意味です。先頭から順に送らないと目的の場所に着かない磁気テープなどと比べた呼び名です。

ただし、上で見たとおり、同じ行が続けば速く、行をまたぐと遅くなります。「どこでもまったく同じ速さ」という意味ではない点に注意しましょう。

1枚のチップには、このような碁盤の目が何組も入っています。別々に動かせる1組をバンクと呼びます。あるバンクが行を開いている間に、別のバンクで次の準備を進められるので、待ち時間を隠せます。

たとえで言うと

DRAMの読み出しは、書庫から本を出してもらう手順に似ています。係の人は、まず棚を1段まるごと受付の台に運びます(行を開く)。そこから頼まれた本を選んで渡します(列を選ぶ)。同じ段の本なら、続けてすぐに渡せます。似ているのは「まず1段をまとめて出し、その中から選ぶ。同じ段なら速い」という点です。

たとえが当てはまらない点: 本物の書庫なら、本を運び出しても中身は変わりません。DRAMでは、行を開くとセルの電気が薄まり、書き戻さないと中身が失われます。また、受付の台にあたるセンスアンプには、1つのバンクで一度に1行分しか置けません。

DRAM・SRAM・フラッシュメモリの違い

半導体のメモリには、DRAMのほかにも代表的な種類があります。CPUの中には、よく使うデータの写しを置くキャッシュがあり、SRAMが使われます(「キャッシュのしくみ」)。スマホのストレージやSSDには、フラッシュメモリが使われます。

SRAMは、1ビットをふつう6個のトランジスタの回路で覚えます。電源が入っている限り値を保つので、リフレッシュは要りません。速い代わりに1ビットあたりの場所が大きく、大容量には向きません。

フラッシュメモリは、電気を通さない膜で囲んだ部屋に、電子を閉じ込めて覚えます。電源を切っても消えませんが、読み書きはDRAMよりずっと遅く、書き換えの回数にも限りがあります(「SSDとフラッシュメモリのしくみ」)。

待つ時間は、CPUから見たおおよその目安です(1ナノ秒は10億分の1秒)。SRAMはCPUの中のキャッシュ、フラッシュはSSDなどで一般的なチップの例で、製品によって変わります。3つは得意なことが違うので、コンピュータは組み合わせて使います。表でくわしく比べるなら「DRAMとSRAMの違い」と「DRAMとNANDフラッシュの違い」があります。

DDRとLPDDR: 世代の名前の読み方

パソコンやサーバーのDRAMは、CPUとデータをやりとりする方式の決まりで、世代が分かれます。いまの標準の方式はDDR SDRAMです。仕様表の「DDR5」は、その5番目の世代という意味です。

DRAMとCPUは、一定のリズムで刻まれる合図に合わせてデータを送ります。この合図を「クロック」と呼びます。DDRは「ダブル・データ・レート」の略です。合図の波が上がるときと下がるときの両方でデータを送るので、1回の合図で2回送れます。

下の表は、JEDECが各世代の規格を発表した時期と、データの線1本の速さです。MT/sは「1秒に100万回送る」という単位で、3,200MT/sなら1秒に32億回です。

世代規格の発表線1本の速さ電源の電圧
DDR32007年6月800〜1,600MT/s1.5V
DDR42012年9月1,600〜3,200MT/s1.2V
DDR52020年7月4,800MT/sから(2024年の改訂で8,800MT/sまで)1.1V

速さは、それぞれの規格が最初に決めた範囲です(DDR5は後の改訂を含めました)。DDR3の前にも、DDRとDDR2の世代がありました。世代が変わると、差し込み口の形も電気の決まりも変わるので、DDR4の差し込み口にDDR5は挿せません。

スマホや薄いノートパソコンには、電気をあまり使わないように作り変えたLPDDRが使われます。LPは「Low Power(低電力)」の略です。電圧を下げたり、使っていない部分を細かく休ませたりします。2025年7月には、JEDECが新しい世代のLPDDR6を発表しました。

グラフィックス用のGDDRや、チップを積み重ねたHBMも、中身はDRAMです。違うのは、チップの並べ方と、CPUやGPUとのつなぎ方です。HBMは「HBMとは?」で詳しく説明しています。

だれが作っている? DRAMのメーカー

DRAMを大量に作れる会社は、世界でもごく少数です。調査会社TrendForceによると、2026年4〜6月期の売上高のシェアの1位は、韓国のSamsungで39.4%でした。2位は韓国のSK hynixで24.9%、3位はアメリカのMicronで23.3%です。3社を合わせると、約9割になります。

順位は、値段の動きや、AI向けのHBMの売れ行きで入れ替わります。同じTrendForceの調べでは、2025年1〜3月期はSK hynixがSamsungを抜いて首位でした。ニュースでシェアを見かけたら、いつの、だれの調べかを確かめましょう。

日本とのつながりもあります。日本のDRAMメーカーだったエルピーダメモリは、2013年にMicronに買収されました。このとき、広島にあるDRAMの工場もMicronのものになりました。

よくある誤解

誤解: パソコンのメモリ(DRAM)は、電源を切ってもデータを覚えている

実際は、電源を切るとリフレッシュが止まり、中身は失われます。保存していない文書が消えるのはこのためです。誤解のもとは、パソコンの「スリープ」です。スリープ中は電源の一部が入ったままで、DRAMが自分でリフレッシュを続けています(セルフリフレッシュ)。なお、中身は一瞬で全部消えるわけではありません。2008年のプリンストン大学などの研究では、ふつうの温度でも数秒は中身が残り、冷やすともっと長く残りました。

誤解: メモリの容量(GB)が多いほど、パソコンは速くなる

実際は、容量は「一度にどれだけ置けるか」の数字で、速さそのものではありません。足りないと、ストレージとのやりとりが増えて遅くなります。足りていれば、増やしても速さはほとんど変わりません。速さに効くのは、世代や線1本の速さ(MT/s)、同時に使える通り道(チャネル)の数です。例えば多くのパソコンでは、同じ16GBでも、8GBを2枚挿すと通り道が2組になり、1枚のときより多くのデータを運べます。

このチップは、1つの列の番号で8ビットずつ出し入れします。8Gb(ギガビット)のチップの数字を掛け合わせると、8,589,934,592ビットです。これは2を33回掛けた数で、メモリの「8Gb」はこの数え方を使います。8ビットで1バイトなので、このチップ8枚を並べると8GBのメモリになります。

DDR5の1枚の通り道は、合わせて64本(8バイト分)です。DDR5-6400は、1本が1秒に64億回(6,400MT/s)送る製品です。8バイトの64億倍で、1秒に51.2GBになります。これは理論上の最大で、実際に使える量はもう少し少なくなります。
