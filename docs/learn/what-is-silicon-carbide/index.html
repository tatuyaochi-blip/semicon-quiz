SiC(炭化ケイ素)とは? EVの電力変換を変える半導体

約14分 · 更新: 2026年10月23日

SiC(炭化ケイ素)は、ケイ素(シリコン)と炭素が1対1で結びついた結晶の半導体です。シリコンの約10倍の強さの電気の力に耐えるので、高い電圧を薄い層で受け止められます。そのため、電気自動車のモーターを回す装置などで、損失と熱を減らせます。弱点は、結晶を育てるのが難しく、値段が高いことです。

この記事でわかること

  • SiCが使われている場所(電気自動車、充電器、太陽光発電、鉄道)
  • SiCの何が特別で、それで何が得られるのか(薄い層で高い電圧に耐える)
  • SiCのMOSFETとシリコンのIGBTの使い分け
  • 結晶づくりが難しく、値段が高い理由と、業界の動き

前提知識: パワー半導体を「電気を速くオン・オフして、電気の形を変える部品」と知っていると読みやすくなります(「パワー半導体とは?」)。

身近なところでは: 研磨材から電気自動車まで

SiCは、実は新しい物質ではありません。1891年、米国のアチソンが、電気炉の実験の中で偶然見つけました。とても硬いので「カーボランダム」の名で、物を削ったり磨いたりする研磨材として広まりました(米国電気化学会の解説)。

半導体として広く知られるきっかけは、電気自動車です。2018年に報じられた分解調査では、テスラの「Model 3」のモーター用の装置に、SiCの部品が24個ありました。作ったのはSTマイクロエレクトロニクスです。この装置は、電池の直流をモーター用の交流に変えるインバータです。

2026年の時点で、SiCは主に次の場所で使われています。

  • 電気自動車のインバータ: 電圧の高い電池を積む車で、特に利点が大きくなります。インフィニオンは2021年、こうした車向けのSiCの部品を出しました。採用した韓国のヒョンデは、走れる距離がシリコンより5%以上延びたと述べています
  • 車載充電器と急速充電器: 家のコンセントの交流を電池用の直流に変える、車の中の充電器や、充電スタンドの中の変換に使われます(ロームの資料)
  • 太陽光発電: パネルの直流を、家や送電網で使う交流に変える装置です。2011年にCreeが出したSiCのMOSFETも、主な用途に挙げていました
  • 鉄道: 三菱電機は2014年、小田急電鉄の車両向けに、SiCだけで作ったインバータを受注したと発表しました。新幹線N700Sの例は「パワー半導体とは?」で紹介しています

SiCはどんな材料?

SiCは、ケイ素(Si)の原子と炭素(C)の原子が同じ数ずつ、交互に結びついた結晶です。ケイ素と炭素の結びつきはとても強く、結晶は非常に硬くなります。硬さの目安のモース硬度では9.5ほどで、最も硬いダイヤモンドの10に近い値です。

SiCには、原子の組み合わせは同じなのに、並び方が違う結晶がたくさんあります。原子の層を積み重ねるときの、ずらし方の順番が違うのです。こうした兄弟のような結晶を「結晶多形」と呼び、SiCでは200種類以上が知られています。

パワー半導体に使われるのは、4層ごとに同じ積み方をくり返す4H-SiCです。「4」は4層、「H」は六角形の形(英語のhexagonal)を表します。並び方が違うと、電子の動きやすさも変わります。4H-SiCは、電子が比較的動きやすく、向きによる差も小さいので選ばれています。

しくみ① シリコンと比べた3つの数字

材料の性格は、3つの数字でつかめます。それぞれの意味は「パワー半導体とは?」で説明したので、ここでは数字を並べます(東芝デバイス&ストレージの資料による)。

しくみ② 薄い層で高い電圧を受け止める

パワー半導体の中には、電気を通しにくくした厚い層があります。オフのときはこの層で高い電圧を受け止め、オンのときは電流がこの層を縦に通り抜けます。この層を「ドリフト層」と呼びます。

受け止められる電圧は、「耐えられる電気の力」と「層の厚さ」の掛け算にほぼ比例します(ここでは単純化しています)。耐えられる力が約10倍なら、同じ電圧を約10分の1の厚さで受け止められます。1,200ボルトで単純に計算すると、シリコンは約80マイクロメートル、SiCは約9マイクロメートルです。1マイクロメートルは、1ミリの1000分の1です。

層が薄くなるだけではありません。層には、電気を運ぶ電子を増やすための混ぜ物を少し入れます。混ぜ物を増やすと層は電気の力に弱くなりますが、SiCはもともと強いので、ずっと多く入れられます。層が薄く、電子も多いので、オンのときの抵抗(オン抵抗)が大きく下がります。同じ電圧に耐える層どうしでは、理論上シリコンの数百分の1です(ロームの解説)。

抵抗が小さいと、同じ電流を流したときに出る熱が減ります。熱が減れば、冷やす装置を小さくでき、機器全体が小さく軽くなります。ただし、実際に使える温度の上限は、チップを包むパッケージなどの材料でも決まります。

しくみ③ SiCのMOSFETとシリコンのIGBTの使い分け

シリコンで、モーターを回すような高い電圧と大きな電流を扱うときは、主にIGBTが使われてきました。シリコンのMOSFET(電圧でオン・オフするトランジスタ)では、厚いドリフト層の抵抗が大きくなりすぎるからです。IGBTは、電子と正孔(電子が抜けた穴)の2種類の粒を層にあふれさせて、抵抗を下げます。

その代わり、IGBTはオフにするとき、層に残った粒が抜けるまで、電流が少し尾を引きます。これをテール電流と呼び、切り替えのたびに損失になります。そのためIGBTは、1秒に数万回(数十キロヘルツ)ほどまでの切り替えで使うのが一般的です。

SiCなら、ドリフト層が薄いので、1,200ボルト級でもMOSFETの抵抗を小さくできます。MOSFETは電子だけで電流を運ぶので、テール電流がありません。米国のCree(今のWolfspeed)は2011年1月、1,200ボルトのSiCのMOSFETを発表しました。同社は「初の市販品」としています。

なぜSiCは作るのが難しく、高いのか

結晶を気体から育てる

シリコンの結晶は、溶かした液から引き上げて育てます(「シリコンウエハとは?」)。SiCは、ふつうの圧力では液体にならず、固体から直接気体になってしまいます。固体が液体を経ずに気体になることを、「昇華」と呼びます。

そこでSiCは、昇華を利用して育てます。黒鉛の容器の底に原料のSiCの粉を入れ、ふたの裏に種になる結晶を貼ります。容器を2,100〜2,500℃に熱すると、粉が気体になります。気体は、少しだけ温度の低い種の上で固体に戻り、種と同じ並びで積もっていきます。この育て方を「昇華法」と呼びます(2024年の論文による)。

この方法のもとは、ソ連のタイロフとツベトコフが1978年に示した、種を使う昇華法です。結晶が育つ速さは、1時間に0.3〜0.8ミリほどです。速くしようとすると、結晶に傷や、別の並び方の結晶が混じりやすくなります(2024年の論文)。この速さだと、数センチ育てるだけで数日かかります(当サイトの計算)。

たとえで言うと

昇華法は、冷凍庫の壁につく霜に少し似ています。霜は、空気中の水蒸気が、液体の水を経ずに、冷たい壁の上で直接氷になったものです。昇華法でも、気体になったSiCが、少し温度の低い種の上で直接固体に戻ります。似ているのは「気体が、冷たいところで直接固体になる」という一点です。

たとえが当てはまらない点: 霜は、小さな氷の粒がばらばらの向きに集まったものです。昇華法では、種と同じ原子の並びを引き継ぐ、1つの大きな結晶を育てます。温度も、霜は0℃以下、SiCは2,000℃を超える世界です。

結晶の中の傷

気体から育てる結晶には、原子の並びのずれが入りやすくなります。昔から大きな問題だったのが、結晶を縦に貫く、細い管のような穴です。これを「マイクロパイプ」と呼び、その上に作った部品は壊れやすくなります。改良が進み、高品質の結晶では1平方センチメートルあたり1個未満まで減りました。

今も気をつけているのが、原子の層に沿って横に入った並びのずれです。これを「基底面転位」と呼びます。SiCのMOSFETの中の、ダイオードとして働く部分に電流が流れると、電子と正孔が出会って消えます。そのとき出るエネルギーで、このずれが広がることがあります。

広がったずれは、層の積み重ねの順番が狂った面になります。これを積層欠陥と呼びます。積層欠陥は電流を通しにくいので、使ううちに、オンのときの電圧が上がってしまいます。対策として、ずれの害を抑える層を、土台の結晶と部品の層の間にはさむなどの工夫がされています。

硬くて、切るのも磨くのも大変

育てた結晶は、薄く切って鏡のように磨き、ウエハにします。SiCはダイヤモンドに近い硬さなので、ダイヤモンドの粒をつけたワイヤーや砥石を使っても時間がかかり、道具もすり減ります。かたい一方でもろいので、縁が欠けたり、表面の下に見えない傷が入ったりもしやすいのです。

磨いたウエハの上には、ドリフト層などの部品用の層を、1,500℃を超える温度で気体の原料から育てます。土台の結晶の並びを引き継いで、薄い結晶の層を育てる技術です。これをエピタキシャル成長と呼び、ここでも結晶の傷を減らす工夫が要ります。

ウエハを大きくしにくい

SiCのウエハは、長く直径150ミリが主流でした。シリコンの最大の300ミリと比べると、面積は4分の1です。STマイクロエレクトロニクスは2021年7月、試作用の直径200ミリのウエハを作ったと発表しました。200ミリでは使える面積が150ミリのほぼ2倍になり、良品のチップは1.8〜1.9倍取れるとしています。

工場も200ミリへ移りつつあります。Wolfspeedは2022年4月、米ニューヨーク州で200ミリの工場を開きました。インフィニオンも2024年8月、マレーシアで200ミリの工場の第1期を開いています。STも2024年5月、イタリアに200ミリの工場を建てる計画を発表しています(2026年に生産開始の予定)。2026年1月には、Wolfspeedが直径300ミリの単結晶のウエハを作ったと発表しましたが、量産はこれからです。

ゲートの膜との境目

MOSFETでは、ゲートという電極と電子の通り道の間に、ガラスのような薄い膜をはさみます(「トランジスタとは?」)。SiCも、表面を酸化させて、シリコンと同じ酸化膜を作れます。ところが、SiCと膜の境目には、電子を捕まえる「わな」(界面準位)が多く残りやすいのです。

わなが多いと、通り道の電子が動きにくくなります。動きやすさは、結晶の中に比べて10分の1以下になりやすいのです。わなが電子を捕まえたり放したりすると、スイッチが入り始める電圧(しきい値電圧)も少しずつずれます(2021年の論文)。メーカーは膜の作り方を工夫し、長く使えるかを確かめる試験を重ねています。

業界の動き: 結晶から部品まで自社で

SiCでは、ウエハの品質と量が、部品の性能と値段を左右します。そこで大手は、結晶づくりから部品までを自社グループで手がけようとしてきました。ロームは2009年にドイツのSiCrystalを、STは2019年にスウェーデンのNorstelを買いました。onsemiも2021年11月、結晶を育てる米国のGT Advanced Technologiesを買っています。

SiCのウエハと部品の大手が、米国のWolfspeedです。LEDなども手がけていたCreeがSiCに事業を絞り、2021年10月に社名を変えました。2025年6月30日には、負債を減らすため、米国の連邦破産法第11章の手続きを申し立てました。会社を続けながら借金を整理する制度です。同年9月に手続きを終え、負債を約7割減らしたと発表しています(同社の発表)。

ほかにも、インフィニオン、三菱電機、東芝、デンソーなどがSiCの部品を作っています。ロームと東芝のグループ会社の増産計画は、「パワー半導体とは?」で紹介しています。

よくある誤解

誤解: 電気自動車には、もうどれもSiCが使われている

実際は、シリコンのIGBTを使う車も多くあります。400ボルト級の車で使う650ボルト級の部品では、電気を流しているときの損失はIGBTも小さく、値段も安いからです。テスラも2023年3月、新しい安い車向けの駆動装置でSiCの使用量を75%減らすと説明しました。同社は、性能は落とさないとしています。SiCの話題が目立つので、置き換えが終わったように見えやすいのです。

誤解: SiCとGaNは、ほとんど同じ材料

実際は、段差の大きさが近いだけで、作り方も得意な場面も違います。SiCは同じSiCのウエハの上に、電流が縦に流れる部品を作ります。GaNの多くは、シリコンのウエハの上に薄い膜を育て、電流が表面を横に流れる部品を作ります。SiCは600ボルト級以上の大きな電力、GaNは数百ボルトまでのとても速い切り替えが得意です(「GaN(窒化ガリウム)とは?」)。「次世代のパワー半導体」とひとまとめに紹介されることが多いので、混同されやすいのです。

誤解: SiCは最近見つかった新しい材料

実際は、1891年から研磨材として作られてきた物質です。インフィニオンは2001年にSiCのダイオードを、Creeは2011年にSiCのMOSFETを売り出しました。時間がかかったのは、部品に使えるほど傷の少ない大きな結晶を作る技術です。新しいのは物質ではなく、作り方のほうなのです。
