パワー半導体とは? 電気自動車や家電で電力を変換するしくみ

約14分 · 更新: 2026年10月23日

パワー半導体は、電気の形を変えたり、モーターに送る電気の量を調整したりする半導体の部品です。交流と直流の変換、電圧の上げ下げ、モーターの速さの制御などを受け持ちます。大きな電流をとても速くオン・オフして電気を整えるので、むだな熱を少なくできます。

この記事でわかること

  • 「電力を変換する」とは何をすることか(交流と直流、電圧、モーターの速さ)
  • 電気を熱で捨てずに、速いオン・オフで整えるしくみ
  • 主な部品(ダイオード・パワーMOSFET・IGBT)の役割の違い
  • 計算用のチップとの違いと、SiC・GaNが注目される理由

前提知識: 特にありません。トランジスタを「電気で切り替えるスイッチ」と知っていると読みやすくなります(「トランジスタとは?」)。

身近なところでは: 充電器から新幹線まで

スマホの充電器は、コンセントの電気を、スマホが受け取れる形に変えています。日本の家のコンセントに来ているのは、100ボルトの交流です。一方、スマホが受け取るのは、ずっと低い電圧の直流です。この変換の中心で働く部品が、パワー半導体です。

直流は、いつも同じ向きに流れる電気で、電池から出てくるのはこちらです。交流は、流れる向きが1秒間に50回または60回、行ったり来たりする電気です。電圧を変えやすく、遠くまで送るのに都合がよいので、送電やコンセントには交流が使われています。

同じような変換は、身の回りのあちこちにあります。

  • エアコン・冷蔵庫・洗濯機: 多くの機種で、コンセントの交流をいったん直流にし、好きな速さの交流に作り直して、モーターの回る速さを変えています
  • 電気自動車: 電池の直流を交流に変えて、モーターを回します
  • 電車: 架線から受け取った電気を、モーターを回すための交流に作り直します
  • 太陽光発電: パネルが作る直流を、家で使える交流に変えます

このうち、直流を交流に変える装置をインバータと呼びます。「インバータエアコン」のインバータです。

「電力を変換する」とは

電圧は電気を押し出す強さ、電流は流れる電気の量です。電気が1秒あたりに運ぶエネルギーを電力と呼び、電圧と電流の掛け算で表します。同じ電力でも、「高い電圧・少ない電流」と「低い電圧・多い電流」という、違う形で運べるわけです。

パワー半導体がする「電力の変換」は、この形を、使う機器に合わせて変えることです。おおまかには、次の4種類に分けられます。

変換呼び名例
交流 → 直流整流充電器、家電の電源
直流 → 交流インバータモーターの駆動、太陽光発電
直流 → 電圧の違う直流DC-DCコンバータパソコンの中、電気自動車
交流 → 周波数の違う交流(直流を経由することが多い)エアコン、電車

周波数は、交流が1秒間に行ったり来たりする回数です。表の最後の行のように、一度直流にしてから作り直すことがよくあります。

下の図は、電気自動車の中の変換を大まかに描いたものです。

電気自動車の電池は、数百ボルトの直流です。2019年のポルシェ「タイカン」など、800ボルト級の車もあります。インバータは、この直流を交流に変えてモーターを回します。ライトやナビのような機器は12ボルトの直流で動くので、電圧を下げる変換も必要です。

ブレーキをかけるときは、モーターが発電機として働きます。インバータが逆向きに働いて、できた交流を直流に変え、電池に戻します。これを「回生」と呼びます。

しくみ① 余った電気を熱で捨てない

たとえば、12ボルトの直流を5ボルトに下げたいとします。いちばん簡単なのは、途中に電気を通しにくい部品を入れ、余った7ボルト分を熱にして捨てる方法です。このとき電流は入口と出口で同じなので、使えるのは最大でも12分の5、約42%です。残りは熱になります(当サイトの計算)。

パワー半導体を使う多くの電源は、別のやり方をとります。12ボルトをスイッチで「流す・止める」と、とても速くくり返すのです。オンの時間を全体の12分の5にすると、ならした平均は5ボルトになります。

細かく切った電気は、ぎざぎざのままでは使えません。電気を一時的にためて少しずつ出す部品(コイルとコンデンサ)で、なめらかにします。オンの時間の割合を変えて出力を調整するこの方法を、PWM(パルス幅変調)と呼びます。

この方法で熱が少なくてすむのは、スイッチで失われる電力が「スイッチにかかる電圧」と「流れる電流」の掛け算だからです。オンのときは電流が流れますが、スイッチにはほとんど電圧がかかりません。オフのときは電圧がかかりますが、電流は流れません。どちらの状態でも、掛け算の答えは小さくなります。

ただし、失われる電力はゼロではありません。オンのときにも、スイッチにはわずかな抵抗が残ります。これをオン抵抗と呼び、小さいほど損失が減ります。

もう一つの損失は、オンとオフが切り替わる途中で生まれます。切り替えの一瞬だけ、電圧と電流が両方ある状態になるからです。これをスイッチング損失と呼びます。切り替えの回数が多いほど増えるので、速く切り替えられる部品が求められます。失われた分は熱になるため、大きな電力を扱う部品には放熱の工夫が欠かせません。

たとえで言うと

熱で捨てる方法とスイッチで整える方法の差は、自転車のブレーキと変速ギアの差に似ています。坂道で速さを抑えるとき、ブレーキは余分な勢いを熱にして捨てます。変速ギアは、こぐ速さと力の組み合わせを変えるだけで、勢いをほとんど捨てません。パワー半導体を使った変換は、ギアのように「形を変えるが、捨てない」ことを目指しています。

たとえが当てはまらない点: 自転車のギアは歯車がなめらかに回り続けますが、パワー半導体は電気を細かく切ってはつなぐことをくり返します。また、実際の変換では、オン抵抗や切り替えで少しずつ熱が出ます。このたとえは「捨てる」か「形を変える」かの違いだけを表しています。

しくみ② 主な部品: ダイオード・パワーMOSFET・IGBT

パワー半導体の代表的な3つの種類を、かなり単純化して紹介します。

ダイオード: 一方通行の弁

ダイオードは、電流を一つの向きにだけ通す部品です。操作するための端子はなく、かかる電圧の向きだけで、通すか止めるかが決まります。4個を組み合わせると、行ったり来たりする交流を、一つの向きの流れにそろえられます。この働きを整流と呼びます。インバータの中では、スイッチが切れた瞬間に、モーターの電流の逃げ道をつくる役目もします。

パワーMOSFET: 速く切り替えられるスイッチ

「トランジスタとは?」の記事で紹介したMOSFETは、ゲートという電極に電圧をかけるだけでオン・オフできるスイッチです。これを、大きな電流と高い電圧に耐えられるように作ったものがパワーMOSFETです。切り替えがとても速いのが長所です。シリコン製のものは、主に数百ボルトまでの充電器やパソコンの電源などで使われます。

IGBT: 高い電圧で大きな電流を流すスイッチ

IGBTも、MOSFETと同じようにゲートの電圧で操作します。違うのは、中で電気を運ぶ粒として、電子と正孔(電子が抜けた穴)の2種類を使う点です。オンのときは2種類の粒が中にたくさん入りこみ、電流が通りやすくなります。そのため、高い電圧に耐える部品でも、オンのときの損失を小さくできます。

代わりに、オフにするとき電流が少し尾を引き、MOSFETより切り替えが遅くなります。シリコンのIGBTには、6,500ボルト級の製品まであります。電気自動車のインバータ、電車、工場のモーター、エアコンなどで広く使われています。2つの使い分けは「IGBTとパワーMOSFETの違い」で表にしています。

しくみ③ インバータでモーターの速さを変える

エアコンや電気自動車のモーターの多くは、交流の周波数に合わせて回ります。周波数を変えられれば、回る速さを自由に変えられます。よく使われる形のインバータは、6個のスイッチを決まった順にオン・オフして、好きな周波数と大きさの交流を作ります。

インバータのないエアコンは、冷やす装置(圧縮機)を一定の速さで回し、止めたり動かしたりして温度を保っていました。インバータで回る速さを変えられれば、部屋が冷えたあとは、ゆっくり回し続けられます。東芝は1980年に業務用、1981年に家庭用で、この方式のエアコンを世界で初めて量産しました。室内機と室外機に分かれた形のものです。この業績は2020年、電気・電子の学会IEEEの「マイルストーン」に認定されました。

電気自動車では、アクセルの踏み方に合わせて、インバータが周波数と電圧の大きさを変えます。これで、モーターの速さと力を細かく調整しています。

計算用のチップとの違い: 小さくするより「耐える」

CPUのような計算用のチップは、1ボルト前後の低い電圧で動く小さなトランジスタを、何十億個も並べたものです。トランジスタを小さくするほど、たくさん載せられて性能が上がります(「「2nm」は何の長さ?」)。

パワー半導体の目標は違います。数十ボルトから数千ボルトの高い電圧に耐え、大きな電流を少ない損失で流すことです。そのため、小さくする競争ではなく、材料や構造、熱の逃がし方の工夫が性能を決めます。

高い電圧に耐えるには、電気を通しにくくした厚い層で電圧を受け止めます。電圧が高いほど、この層を厚くする必要があります。多くのパワー半導体では、電流がチップの表面から裏面へ、この層を縦に通り抜けます。チップの面積全体を電流の通り道に使えるので、大きな電流を流せます。

たとえで言うと

厚い層は、川の堤防に少し似ています。水位が高い川ほど、水を受け止める堤防を厚く、がっしり作る必要があります。パワー半導体も、受け止める電圧が高いほど、厚い層が必要です。似ているのは「押す力が強いほど、受け止める部分を厚くする」という一点です。

たとえが当てはまらない点: 堤防は水を通しませんが、パワー半導体の厚い層は、オンのときには電流の通り道になります。層が厚いほど電流が通りにくくなり、損失が増えるという悩みがあります。この悩みを軽くするのが、次の節の材料です。

SiCとGaN: なぜ新しい材料が注目されるのか

パワー半導体の多くはシリコン製です。ここ数年ニュースでよく見かけるのが、SiC(炭化ケイ素)とGaN(窒化ガリウム)という材料です。

違いのもとは、材料の中で電子が自由に動けるようになるために越える「段差」の大きさです。これをバンドギャップと呼びます(くわしくは「半導体とは?」)。SiCとGaNの段差は、シリコンの約3倍あります。このような材料をワイドバンドギャップ半導体と呼びます。

段差が大きい材料は、強い電気の力をかけても壊れにくくなります。東芝の資料の表では、SiCとGaNが壊れずに耐えられる電気の力の強さは、シリコンの約10倍です。そのため、同じ電圧を、ずっと薄い層で受け止められます。層が薄いと電流が通りやすいので、オンのときの損失を小さくできます。

段差が大きいと、熱くなっても電子が勝手に段差を越えにくいので、高い温度でも電気をきちんと止められます。SiCは、熱を伝える力もシリコンの約3倍あり、熱を逃がしやすい材料です(GaNはシリコンと同じくらいです)。ただし、製品として使える温度の上限は、パッケージなどにも左右されます。

SiC: 高い電圧と大きな電力に

SiCは、主に600ボルト級以上のMOSFETやダイオードとして使われます。シリコンのIGBTのように電流が尾を引かないので、切り替えの損失も減らせます。電気自動車のインバータ、急速充電器、太陽光発電の変換装置などで、シリコンのIGBTの代わりに使われ始めています。

デンソーは2023年、自社で初めてSiCを使ったインバータを開発し、レクサスの電気自動車「RZ」に搭載しました。同社によると、特定の条件での試験で、シリコンの場合より損失を半分以下にできました。2020年に営業運転を始めた新幹線のN700Sも、駆動装置にSiCを使い、床下の機器を小さく軽くしています。

弱点は値段です。SiCはふつうの圧力では液体にならないので、シリコンのように溶かした液から結晶を引き上げられません。主な方法では、2,000℃を超える高温で原料を気体にし、種になる結晶の上に少しずつ積もらせて育てます。そのため、手間と時間がかかります(三菱電機の解説資料による)。

GaN: とても速い切り替えで小さく

GaNのパワー半導体の多くは、シリコンの板の上にGaNの薄い膜を育てて作ります。数百ボルトまでの用途が中心で、切り替えがとても速いのが特徴です。

切り替えの回数を増やすと、ぎざぎざをならすコイルや、電圧を変える変圧器を小さくできます。電気をためて出す1回分の量が少なくてすむからです。手のひらに収まる小型の充電器にGaNが使われるのは、このためです。データセンターのサーバーの電源にも使われています。

GaNは、青色LEDの材料でもあります。効率のよい青色LEDを発明した赤﨑勇・天野浩・中村修二の3氏は、2014年のノーベル物理学賞を受けました。

シリコンも、安く大量に作れるので、今も広く使われています。3つの材料は、電圧・速さ・値段で使い分けられています。違いは「SiCとGaNの違い」「SiとSiCの違い」で表にしています。

日本とパワー半導体

日本には、パワー半導体を開発・製造する会社が多くあります。2023年12月、経済産業省は、ロームと東芝のグループ会社が共同で進める増産計画を認定しました。ロームがSiC、東芝側がシリコンのパワー半導体に重点的に投資し、作る力を互いに使い合う計画です。国の助成は最大1,294億円です。

よくある誤解

誤解: パワー半導体も、CPUと同じように「何nm」と小さくするほど高性能になる

実際は、高い電圧に耐えるために、厚い層や広い面積が必要です。性能を決めるのは、材料、構造、熱の逃がし方です。ニュースではどちらも「半導体」と呼ばれるので、同じ物差しで考えられがちです。

誤解: SiCやGaNが、いずれシリコンのパワー半導体をすべて置き換える

実際は、用途ごとに使い分けられています。SiCは損失が小さい代わりに値段が高く、GaNは数百ボルトまでの用途が中心です。シリコンのMOSFETやIGBTは安く作れるので、今も多くの機器で使われています。新しい材料の話題が目立つので、置き換えが一気に進むように見えやすいのです。

誤解: インバータエアコンの「インバータ」は、0と1をひっくり返す回路と同じもの

実際は、名前が同じだけの別物です。0と1を反転する論理回路(NOTゲート)も、英語でインバータと呼びます。電力の世界では、交流を直流にする変換を「順変換」、その逆を「逆変換」と呼びます。逆変換の装置がインバータです。どちらも「ひっくり返す」という意味の英語から来ているので、混同されやすいのです。
