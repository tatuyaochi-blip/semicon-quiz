IPアドレスとは? ネットの住所のしくみとIPv4・IPv6

約14分 · 更新: 2026年10月23日

IPアドレスは、インターネットでデータを届けるときの宛先と送り主を表す番号です。広く使われるIPv4は約43億通りしかなく、世界の大もとの在庫は2011年に尽きました。そこで家のルータが1つの番号を複数の機器で分け合い、番号がずっと多いIPv6への移行も進んでいます。

この記事でわかること

  • IPアドレスの形(IPv4・IPv6)と、数字の読み方
  • IPv4が足りなくなった理由と、家のルータが番号を分け合うしくみ(NAPT)
  • 番号を自動で配るしくみ(DHCP)と、番号の「前半」と「後半」の役割
  • IPアドレスから分かること・分からないこと

前提知識: 特にありません。「インターネットでデータが届くしくみ」(パケットとルータ)を知っていると、より読みやすくなります。

身近なところでは

スマホのWi-Fiの詳しい設定を開くと、「192.168.1.10」のような数字が見つかります。一方、「あなたのIPアドレス」を表示するサイトでは、まったく別の数字が出ます。同じスマホなのに、番号が2つあるのはなぜでしょうか。

ニュースでは「IPアドレスから投稿者を特定」という言葉も耳にします。光回線の広告には「IPv6対応」と書かれています。この記事では、こうした場面の裏にある番号のしくみを、順に見ていきます。

IPアドレスは「パケットの宛先の番号」

インターネットでは、データを小さなかたまりに分けて送ります。このかたまりをパケットと呼びます。パケットには、宛先と送り主を表す番号が書かれます。この番号がIPアドレスです。

途中のルータ(ネットワークの間でパケットを中継する機器)は、宛先の番号を見て次の行き先を選びます。中継のしくみは「インターネットはどうやってデータを届けるの?」で説明しています。この記事では、番号そのものに注目します。

IPアドレスは、人ではなく、ネットワークへのつながり口ごとにつきます。スマホなら、Wi-Fiのときとモバイル回線のときで、別の番号を使います。同じ機器でも、つなぐ場所が変われば番号も変わります。

IPv4の形: 0〜255の数が4つ

いま広く使われている形式をIPv4と呼びます。IPv4のアドレスは、「203.0.113.25」のように、4つの数を点で区切って書きます。それぞれの数は0から255までです。

なぜ255までなのでしょうか。コンピュータの中では、数を0と1の並びで表します。この0か1の1けたを「ビット」と呼びます。8ビットで表せるのは、2を8回かけた256通りで、0〜255になります(0と1の話は「コンピュータは0と1でどうやって計算するの?」で)。

IPv4のアドレスは、8ビットの数が4つで、合わせて32ビットです。作れる番号は2を32回かけた数で、約43億通りです。一部は特別な用途に取ってあるので、機器に配れる番号はさらに少なくなります。

なぜIPv4は足りなくなったのか

IPv4の決まりごとが文書にまとめられたのは、1981年です。当時つながっていたのは研究機関などのコンピュータで、43億は十分に大きな数でした。しかし今では、世界の人口(国連によると2022年に80億人)のほうが、番号の数よりずっと多いのです。1人がスマホとパソコンを持てば、なおさら足りません。

インターネットへの接続を提供する会社を、プロバイダと呼びます。番号は、管理団体を順に経てプロバイダへ配られます。日本では、世界全体を受け持つIANA、アジア太平洋のAPNIC、日本のJPNICの順がふつうです。

2011年2月、IANAは最後に残っていた分を各地域の団体に配り終え、手元の在庫がなくなりました。続いて2011年4月15日、APNICとJPNICも通常の配布を終えました。残りが最後のまとまり(約1,677万個)になったためで、その後はごく少しずつしか配られていません。

それ以降は、使われなくなった番号を回収したり、組織の間で譲り渡したりして、やりくりしています。根本的な解決策はIPv6ですが、その前に、今の家庭を支えている工夫を見ておきましょう。

家の中だけの番号: プライベートアドレス

番号を節約する1つ目の工夫は、家や会社の中だけで使う番号を決めたことです。これを「プライベートアドレス」と呼びます。1996年の決まりごと(RFC 1918)で、次の3つの範囲が定められました。

  • 10.0.0.0 〜 10.255.255.255
  • 172.16.0.0 〜 172.31.255.255
  • 192.168.0.0 〜 192.168.255.255

プライベートアドレスは、どの家でも会社でも、自由に使えます。あなたの家のスマホと隣の家のスマホが、同じ「192.168.1.10」でもかまいません。その代わり、インターネットの宛先には使えません。

これに対し、インターネットの中で重ならないように1つずつ配られる番号を「グローバルアドレス」と呼びます。家庭では多くの場合、プロバイダが家のルータに1つ割り当てます(ほかの契約者と分け合う方式もあります)。冒頭の「あなたのIPアドレス」のサイトに出るのは、この外向きの番号です。後で説明するIPv6の番号が出ることもあります。

1つの番号をみんなで使う: NAPT

家の中の機器は、プライベートアドレスのままではインターネットと話せません。そこで家のルータが、外へ出るパケットの送り主の番号を、グローバルアドレスに書き換えます。この書き換えをNATと呼びます。

ただ、番号を書き換えるだけでは、返ってきたパケットをどの機器に戻せばよいか分かりません。そこでルータは、もう1つの番号も使います。機器の中で「どの通信か」を区別する番号で、ポート番号と呼びます。

ルータは、外へ出る通信ごとに別のポート番号をつけ、その対応を表に控えます。返事が届いたら、表を見て元の機器と番号に戻します。IPアドレスとポート番号を組にして書き換えるこの方式を、NAPTと呼びます。家庭用ルータの「NAT」は、ふつうこのNAPTのことです。

たとえで言うと

NAPTは、会社の代表電話と内線に似ています。外の人から見えるのは代表番号だけで、社内の一人ひとりは内線番号を持っています。似ているのは「外には1つの番号だけを見せ、中の誰宛てかは内側で振り分ける」という点です。

たとえが当てはまらない点: 代表電話なら、外から「内線123番へ」と頼んでつないでもらえます。NAPTでは、外から始まる通信は対応表にないので、ふつうは中の機器に届きません(ポート開放の設定をした場合は別)。ただし、これは安全のための専用の機能(ファイアウォール)の代わりにはなりません。また内線と違い、ポート番号は機器ごとに決まった番号ではなく、通信のたびに割り当てられます。

携帯電話の回線などでは、通信会社の側でも同じ書き換えをすることがあります。これをキャリアグレードNATと呼びます。この場合は、1つのグローバルアドレスを、たくさんの契約者が同時に使っています。

番号は誰が配るのか: DHCP

友人のスマホを家のWi-Fiにつなぐと、すぐにインターネットが使えます。番号を手で設定しなくてよいのは、家のルータが自動で番号を配っているからです。このしくみをDHCPと呼びます。

スマホは、つないだ直後に「番号をください」と呼びかけます。ルータは空いている番号を選び、使ってよい期間をつけて貸し出します。いっしょに、ネットワークの出口になるルータの番号や、名前を番号に変えるサーバの番号も伝えます。

貸し出しには期限があるので、しばらく使わなかった番号は、ほかの機器に回されることがあります。同じスマホでも、家の中の番号が変わることがあるのはこのためです。家のルータが受け取るグローバルアドレスも、プロバイダから自動で割り当てられることが多い番号です。つなぎ直すと変わる場合があります(固定の番号を貸すサービスもあります)。

番号の前半と後半: ネットワーク部とホスト部

IPアドレスは、前半と後半で役割が分かれています。前半は「どのネットワークか」、後半は「その中のどの機器か」を表します。前半をネットワーク部、後半をホスト部と呼びます(ホストは、ネットワークにつながる機器のことです)。

境目の位置は、「/24」のように、前から何ビットがネットワーク部かで示します。この書き方をCIDR表記と呼びます。家庭でよく使われる /24 なら、前の24ビット、つまり最初の3つの数がネットワーク部です。

例えば「192.168.1.0/24」では、192.168.1.1〜192.168.1.254 を機器に配れます。末尾が0と255の番号は、ネットワークそのものと「全員宛て」を表すので、機器には使いません。配れる番号は、ルータ自身の分も含めて254個です。

スマホは、宛先のネットワーク部が自分と同じなら、相手に直接送ります。違えば、ネットワークの出口のルータに渡します。この出口をデフォルトゲートウェイと呼びます。

同じ境目を「255.255.255.0」という形で表したものがサブネットマスクです。Wi-Fiの詳しい設定でよく見かけます。境目を変えたときの計算は「IPアドレス・サブネット計算」で試せます。

IPv6: 番号を128ビットに広げる

IPv4の不足を根本から解決するために作られたのがIPv6です。アドレスの長さを、32ビットから128ビットに広げました。作れる番号は約3.4×1038通りで、「1兆の1兆倍の1兆倍」のさらに約340倍です。

けたが多いので、書き方も変わりました。IPv6では16進数を使います。16進数とは、0〜9とa〜fの16種類の記号で数を書く方法です(aが10、fが15を表します)。

128ビットを16ビットずつ8つに区切り、それぞれを4けたの16進数にして、コロン(:)でつなぎます。そのままでは長いので、省略の決まりがあります。各区切りの頭に並ぶ0は省けます(0db8 → db8)。また、0だけの区切りが続く部分は「::」とまとめられます。

  • 省略なし: 2001:0db8:0000:0000:0000:0000:0000:0001
  • 先頭の0を省く: 2001:db8:0:0:0:0:0:1
  • 「::」でまとめる: 2001:db8::1

「::」が使えるのは1つのアドレスで1か所だけです。2か所あると、それぞれが0の区切りいくつ分か、分からなくなるからです。

IPv6とIPv4はパケットの形が違い、そのままでは互いに通信できません。そのため今は、1台の機器が両方の番号を持ち、相手に合わせて使い分けるのが一般的です。違いは「IPv4とIPv6の違い」で表にまとめています。

Googleの統計では、GoogleにIPv6でつなぐ利用者の割合が、2026年3月28日に50.1%となりました。2008年に記録を始めてから、初めて半分を超えた日です。ただしこれは1日の値で、ほかの測り方では4割ほどという結果もあります。国による差も大きく、IPv4しか使えない機器やサイトも多く残っています。

DNS: 名前から番号を調べる

ふだん私たちは、IPアドレスを直接入力しません。「www.example.com」のような名前を、DNSというしくみで番号に変えてから通信しています。1つの名前にIPv4とIPv6の両方の番号が登録されていることも多く、その場合は機器が使える方を選びます。

IPアドレスから分かること・分からないこと

分かること: どの組織の番号か、おおよその地域

番号の範囲ごとに、どの組織に配られたかは公開されています。そのため、番号から、どのプロバイダや会社の番号かは、たいてい分かります。番号から位置を推定するサービスもあり、国や大まかな地域なら当たることが多いです。

分からないこと: 名前や住所

番号から、使っている人の名前や住所は分かりません。米国のMaxMind社は、位置を推定するデータを売っている会社です。その同社も、データは世帯や番地、個人を特定できるほど正確ではないと説明しています。通信を別の場所のサーバ経由で送るVPNを使えば、相手に見えるのは経由先の番号です。

記録をたどれる場合

一方でプロバイダは、いつ、どの契約者にどの番号を割り当てたかを記録しています(残す期間には限りがあります)。法律に基づく手続きがあれば、その記録から契約者を調べられる場合があります。日本では、ネット上で権利を侵害された人が、条件を満たせば、投稿に使われた回線の契約者の情報などの開示を求められます。根拠は情報流通プラットフォーム対処法です(2025年4月に、プロバイダ責任制限法から名前が変わりました)。

1つの番号を大勢で使っている場合は、時刻だけでなく、ポート番号の記録も必要になります。そのため、インターネットの技術標準を作る団体IETFは、2011年に記録のしかたの文書を出しました。サーバに、相手のポート番号と正確な時刻も残すよう勧めています。また、たどれるのは回線の契約者で、実際に操作した人とは限りません。

よくある誤解

誤解: IPアドレスは、人や機器にずっとついている番号

実際は、ネットワークにつないだときに、つながり口に割り当てられる番号です。つなぐ場所が変われば変わり、DHCPの貸し出しの期限やプロバイダへのつなぎ直しでも変わることがあります。キャリアグレードNATでは、1つの番号を大勢が同時に使います。

IPv6でも、多くのスマホやパソコンは、追跡されにくいように番号の後半を定期的に変えます。これを一時アドレスと呼びます。「ネットの住所」という呼び方から、家の住所のように変わらないものと思われがちですが、実際はよく変わる番号です。

誤解: IPv6は、IPv4の速い版

実際は、主な違いは番号の数と形式です。IPv4とはそのままではつながらない、別の決まりごとです。IPv6にしたからといって、通信が速くなるとは決まっていません。

NTTのフレッツ光などで「IPv6にしたら速くなった」と感じるのは、多くの場合、接続のしかたの違いによるものです。従来のPPPoE方式は、夜など利用者が多い時間に混みやすい設備を通ります。新しいIPoE方式は、その設備を通らずに済みます。IPv4のサイトへの通信も、IPoEの通り道に乗せて運ぶ方式があり、それで速くなることもあります。速くなったのは、番号の形式ではなく、通り道が変わったためです。

誤解: 192.168.x.x のような番号は、世界に1つだけ

実際は、プライベートアドレスは、世界中の数えきれない家や会社で同じ番号が使われています。あなたの家の「192.168.1.10」と、隣の家の「192.168.1.10」は別の機器です。そのため、インターネットの向こうから、この番号宛てにパケットを送ることはできません。
