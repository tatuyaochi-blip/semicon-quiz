ノイズキャンセリングとは? 音で音を消すしくみ

約13分 · 更新: 2026年10月23日

ノイズキャンセリングは、マイクで拾った騒音と山と谷が逆の音をチップで作り、耳の中で重ねて打ち消すしくみです。電車や飛行機の「ゴー」という低くて続く音はよく消えます。一方、人の声や食器の音のような高い音・急な音は、タイミングを合わせにくく、あまり消えません。

この記事でわかること

  • 耳をふさぐ「パッシブ」と、音で消す「アクティブ」の違い
  • マイク → チップ → スピーカーで、逆の音を作る流れ
  • 低い音はよく消え、声や高い音が残る理由(音の速さと遅れ)
  • 外の音を聞くモード、風の音、耳が詰まった感じ、聴力との関係

前提知識: 特になし。dB(デシベル)の数字が出てきますが、その都度説明します。

身近なところでは

ワイヤレスイヤホンやヘッドホンには、「ノイズキャンセリング」のボタンがついたものがあります。電車でこれを入れると、走る音の「ゴー」という響きが急に小さくなります。音楽を流していなくても、耳の周りが静かになります。

ところが、隣の人の話し声や、駅のアナウンスはまだ聞こえます。消える音と、消えにくい音があるのです。この記事では、その違いがどこから来るのかを、音の正体から順に見ていきます。

音は、空気の圧力の小さな揺れ

音は、空気がわずかに押し縮められたり、薄くなったりする揺れです。この揺れが、空気の中を波として伝わります。耳の奥の鼓膜は、届いた揺れに合わせて動き、それを私たちは音として感じます。

揺れが1秒間に何回くり返されるかを、周波数と呼び、単位はHz(ヘルツ)です。回数が少ないほど低い音、多いほど高い音に聞こえます。電車や飛行機のエンジンの響きは主に低い音です。人の声の聞き取りに大切な成分や、食器が当たる音は、より高い音です。

音の大きさは、dB(デシベル)という目盛りで表します。聞こえる限界の音に比べて、音の強さが10倍になるごとに10 dBずつ増える数え方です。くわしくは「デシベル(dB)とは?」で説明しています。

揺れはとても小さなものです。かなりうるさい80 dBの音でも、圧力の揺れは約0.2 Pa(パスカル、圧力の単位)です。まわりの気圧(約10万1300 Pa)の、約50万分の1しかありません。

2つの防ぎ方: ふさぐか、音で消すか

騒音を減らす方法は、大きく2つあります。1つめは、耳栓や、耳をすっぽり覆うイヤーカップのように、音の通り道を物でふさぐ方法です。これをパッシブ(受け身の)ノイズキャンセリング、または遮音と呼びます。電気は使いません。

ふさぐ方法は、高い音によく効きます。一方、低い音は、薄い壁や耳栓を揺らして通り抜けやすいため、減らしにくい音です。低い音までふさごうとすると、重く厚い覆いが必要になります。

2つめが、この記事の主役のアクティブ(能動的な)ノイズキャンセリングで、英語の頭文字からANCとも呼びます。騒音そのものに、それを打ち消す音をぶつけます。ふさぐのが苦手な低い音を、こちらで受け持ちます。実際の製品は、2つを組み合わせて使っています。

しくみ1: 山と谷が逆の波を重ねる

2つの音の波が同じ場所に来ると、圧力の揺れは足し算になります。山と山が重なれば揺れは大きくなり、山と谷が重なれば打ち消し合います。湖で、2つの波紋がぶつかる所を思い浮かべてください。

波が今、1回の揺れのどの段階にいるか(山か、谷か、その途中か)を、位相と呼びます。騒音とちょうど山と谷が入れ替わった波は「逆位相の波」です。騒音と同じ大きさの逆位相の波を耳の中で重ねれば、合計の揺れはほぼ0になります。

大切なのは、打ち消すには「大きさ」と「タイミング」の両方が合っている必要があることです。逆の波が少し遅れたり、大きすぎたりすると、消え残りが出ます。逆の波が揺れ半回分ずれると、今度は山と山が重なり、騒音を大きくしてしまいます。

たとえで言うと

揺れているブランコを止めたいとき、ブランコが来る向きと反対に、ちょうどよい時に押し返せば揺れは小さくなります。押す時刻を半回分まちがえると、揺れを強めてしまいます。似ているのは「逆向きの力を、正しいタイミングで重ねると打ち消せる」という点です。ゆっくりしたブランコほど、タイミングを合わせやすいのも同じです。

たとえが当てはまらない点: ブランコは1つの物ですが、音は空間に広がる波です。耳の位置で打ち消せても、少し離れた場所では打ち消せません。そのためANCは、周りの人にとっての騒音は減らせず、耳の中という狭い場所だけを静かにします。

しくみ2: マイク → チップ → スピーカー

逆の波は、イヤホンの中の部品が流れ作業で作ります。まず、外側の小さなマイクが騒音を拾い、圧力の揺れを電圧の揺れに変えます。小さなマイクのしくみは「MEMSとは?」でも紹介しています。

次に、電圧を数字に直します。この働きをする回路をADコンバータ(ADC)と呼びます。数字にしておけば、決まった手順の計算で、波の形を自由に作り直せます。

数字になった騒音を受け取り、逆の波を計算するのが、DSP(デジタル信号処理用のプロセッサ)です。DSPは、決まった形の掛け算と足し算を、とても速くくり返すのが得意なチップです。

計算した数字は、DAコンバータ(DAC)で電圧の波に戻し、スピーカーを鳴らします。スピーカーは、音楽と一緒に逆の音も出します。こうして、外から漏れてきた騒音と逆の音が耳の中で重なります。電圧と数字を行き来する回路のしくみは、「アナログ半導体とは?」で詳しく説明しています。

逆の波を作る計算でよく使われるのは、マイクから届いた直近のいくつかの数字に、それぞれ重みを掛けて足し合わせる方法です。この計算方法をFIRフィルタと呼びます。耳への付け方や騒音の種類は刻々と変わるので、重みを少しずつ直し続ける方式もあります。ここでは計算の中身は簡単にし、詳しい式は省きます。

しくみ3: 外のマイクと、中のマイク

マイクを置く場所には、2つの考え方があります。1つは、イヤホンの外側にマイクを置き、騒音が耳に届く前に聞いて、逆の音を前もって作る方法です。これをフィードフォワード方式と呼びます。結果を確かめずに、予測で先回りする方法です。

もう1つは、スピーカーのすぐ近く、耳の中にマイクを置く方法です。このマイクは、打ち消した後に残った音を聞きます。残りが小さくなるように、逆の音を直し続けます。結果を測って直すこのやり方をフィードバック制御と呼び、ANCではフィードバック方式と呼びます。

2つには得意・不得意があります。外のマイクは先回りできますが、耳の中で本当に消えたかはわかりません。中のマイクは結果を確かめられますが、直す力を強くしすぎると、音が「ピー」と鳴り続けるように不安定になります。そのため、両方を組み合わせる製品があります。例えばAppleは、外向きと内向きのマイクの両方で逆の音を作ると説明しています。2つの制御の違いは「開ループ制御と閉ループ制御の違い」で比べています。

しくみ4: 音より先に計算を終える

ANCで最も厳しいのは、時間です。空気中の音の速さは、20 °Cで秒速約343 mです。1ミリ秒(1000分の1秒)では約34 cm、1マイクロ秒(100万分の1秒)では約0.3 mm進みます。

外のマイクから鼓膜までは、イヤホンでは数cmほどです。仮に3 cmとし、音がまっすぐ進むとすると、そこを約90マイクロ秒で通り抜けます。フィードフォワード方式では、この短い間に、ADC → DSP → DAC → スピーカーの全部を終える必要があります。間に合わなければ、逆の波は「遅れた逆の波」になり、うまく打ち消せません。

そのため、ANC用のチップは、入ってから出るまでの遅れを特に短くしています。例えば、Analog Devicesのチップ(ADAU1787)は、ANC向けの近道を備えています。計算を省いた設定では、入口から出口までの遅れは5マイクロ秒です。音が約1.7 mm進む時間です。チップの説明書では、この種の遅れを群遅延と書くことがあります。

なお、Bluetoothでスマホから音楽が届くまでの遅れは、これとは別の話です。ANCはイヤホンの中だけで計算が完結するので、電波の遅れの影響を受けません。Bluetoothの遅れは「Bluetoothのしくみとは?」で説明しています。

低い音は消え、声や高い音が残る理由

同じ遅れでも、低い音と高い音では影響がまったく違います。1回の揺れにかかる時間は、100 Hzの低い音なら10ミリ秒、5 kHz(5000 Hz)の高い音なら0.2ミリ秒です。逆の波が0.1ミリ秒遅れたとき、100 Hzでは揺れ1回の1%のずれで済みます。5 kHzでは半回分のずれになり、山と山が重なって、かえって大きくなります。

計算で確かめると、0.1ミリ秒の遅れで、100 Hzの揺れの幅は約16分の1になります。音の強さでは約250分の1(約−24 dB)です。1 kHzでは揺れの幅が約0.6倍(約−4 dB)にしかなりません。ここでは、逆の波の大きさはぴったりで、遅れだけがあるとして計算しました。

場所の問題もあります。音が1回揺れる間に進む長さを、波長と呼びます。100 Hzの波長は約3.4 m、5 kHzでは約7 cmです。波長の長い低い音は、耳の周りのどこでもほぼ同じ揺れ方をするので、まとめて打ち消せます。波長が短い高い音は、数mmずれただけで揺れ方が変わり、耳の中の全体で消すのが難しくなります。

急な音も苦手です。食器の「カチャン」やドアの「バタン」は、いきなり始まり、高い音を多く含みます。一方、エンジンや走行音のように同じ調子で続く音は、少し先の揺れまで見込みやすく、重みの調整も追いつきます。こうした理由から、高い音はANCに頼らず、イヤーピースやイヤーカップでふさぐ力に任せています。

外の音を聞く「外音取り込み」モード

ANCのついた製品には、反対に外の音を聞きやすくするモードを備えたものもあります。メーカーにより、外音取り込み、アンビエント、トランスペアレンシーなどと呼びます。外のマイクで拾った音を、打ち消すのではなく、そのままスピーカーから流します。

イヤホンで耳をふさいだままでも、駅のアナウンスや人の呼びかけが聞こえます。Appleの説明では、このモードは外の音を取り込み、周りで何が起きているかを聞けるようにするものです。ただし、道を歩くときや自転車に乗るときは、外の音を聞き逃さないよう、使い方に注意が必要です。

風の音と、耳が詰まったような感じ

ANCをつけて外を歩くと、風の「ボボボ」という音が目立つことがあります。風がマイクに直接当たると、空気の乱れがマイクを揺らし、大きな低い音として拾われます。これは耳に届く騒音とは別の揺れなので、それに合わせて逆の音を作ると、かえって雑音を足してしまうことがあります。Sonyも、ANCを使うときの風の音を減らす設定や対策を案内しています。

ANCを入れたとき、耳が詰まったような、気圧が変わったような感じがする人もいます。ただ、ANCが打ち消すのは音の小さな揺れで、先に見たとおり気圧の50万分の1ほどです。鼓膜を押し続けるような圧力を作るわけではありません。この感じ方には個人差があり、研究も少なく、原因はまだ確かめられていません。気になるときは、ANCを弱めるか、休憩を挟みましょう。

ノイズキャンセリングの歩み

逆の音で音を消す考え方は、イヤホンよりずっと古いものです。ドイツのポール・ルーグ(Paul Lueg)は、管の中などの音を逆の波で消すしくみを考えました。1936年に、米国で特許を得ています。ただ、当時の部品では製品にできませんでした。

1950年代には、米国のローレンス・フォーゲル(Lawrence J. Fogel)が研究を進めました。航空機やヘリコプターの騒音の中で、通信を聞き取りやすくするためです。その特許(米国特許第2,966,549号)は1950年代に出願され、1960年に登録されています。題は「騒音の大きい場所で、聞き取りを良くする装置」です。

製品に結びつけたのが、米国の音響メーカーBoseです。同社の年表によると、創業者のアマー・ボーズは1978年、機内の騒音に悩み、研究を思い立ちました。1986年には、無給油の世界一周飛行に挑んだ飛行機「ボイジャー」の操縦士に試作品を提供しました。1989年に航空用のヘッドセットを発売し、2000年に一般向けのヘッドホンを出しています。その後、チップが小さく省電力になり、今ではイヤホンにも入るようになりました。

よくある誤解

誤解: ノイズキャンセリングは、周りの音をすべて消す

実際は、よく消えるのは低くて続く音で、声や高い音、急な音は残ります。Sonyの説明書も、飛行機や電車、空調のような低い音に効き、人の声のような高い音にはあまり効かないとしています。「全部消える」と思うと、高い音が残ったときに故障と勘違いしがちです。

誤解: 逆の音を出すので、耳に悪い

実際は、逆の音は打ち消す騒音と同じくらいの大きさで、耳に届く音の合計は小さくなります。2022年の研究では、ANCを入れると鼓膜の近くの低い音が下がり、耳の穴に入れるイヤホンでは、人が選ぶ音量も下がりました。WHOも、騒がしい場所では、ノイズキャンセリングで音量を上げずに済ませることを勧めています。

誤解: うるさい電車では、音量を上げて騒音をかき消せばよい

実際は、耳への負担は「音の大きさ × 聞いた時間」で積み重なります。WHO(世界保健機関)は、平均して約80 dBの音量なら、1週間に40時間まで安全に聞けるという目安を示しています。同じ考え方で、音の強さが2倍(+3 dB)なら、時間は半分の20時間になります。騒音をかき消すほど音量を上げるより、ANCで騒音を減らして音量を控えるほうが、耳を守れます。

ANCで減る量は、製品や耳への合い方で大きく変わります。表の1992年の評価では、ANCの働きだけで最大15〜22 dB減りましたが、高い音はほとんど変わりませんでした。20 dBは、音の強さが100分の1になることです。音の強さが10分の1(−10 dB)になると、大きさの感じ方は約半分になるという目安があります。dBの数字の読み方は、先に挙げた「デシベル(dB)とは?」を参照してください。
