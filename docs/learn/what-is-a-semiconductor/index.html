半導体とは? 電気の通しやすさを変えられる材料

約13分 · 更新: 2026年10月23日

半導体は、電気の通しやすさが金属(導体)とガラスやゴム(絶縁体)の中間にある材料です。大事なのは「中間」であることより、ごく少量の不純物や電圧・光・温度で、その通しやすさを大きく変えられる点です。この性質で電流をオン・オフするスイッチが作れるので、スマホやパソコン、車の電子部品の土台になっています。

この記事でわかること

  • 「半導体」という名前の意味と、導体・絶縁体との違い
  • 電気の通しやすさを変える4つの方法
  • シリコンが使われる理由
  • n型・p型とは何か(不純物で電気の運び手を作るしくみ)
  • ニュースの「半導体」が、材料・部品・チップのどれを指しているか

前提知識: 中学の理科(電流・電圧、原子と電子)くらい。式は使いません。

身近なところでは

スマホの中には、計算をする部品、写真や連絡先を覚えておく部品、電波をやりとりする部品が入っています。これらの部品の中心は、どれも半導体でできています。カメラで光を電気の信号に変える部品も半導体で、イメージセンサと呼ばれます。

家の中では、LED電球の光る部分や、屋根の太陽電池が半導体です。LEDは電気を光に、太陽電池は光を電気に変えます。エアコンや電気自動車では、大きな電流を素早くオン・オフする部品が、モーターに送る電気を調整しています。この種類の部品をパワー半導体と呼びます。

ニュースで「半導体不足」「半導体工場」と言うときの「半導体」は、多くの場合、材料そのものではありません。半導体で作った部品、とくに小さな板に回路を詰め込んだ「チップ」を指しています。この言葉の使い分けは、後半の「『半導体』という言葉の3つの意味」で整理します。

「半導体」という名前の意味

物質は、電気の通しやすさで大まかに3つに分けられます。銅やアルミニウムのような金属は電気をよく通し、「導体」と呼びます。ガラスやゴム、プラスチックは電気をほとんど通さず、「絶縁体」と呼びます。半導体は、その中間に入る材料です。英語の semiconductor も「半分(semi)の導体(conductor)」という意味です。

材料どうしを比べるときは、同じ形・同じ大きさにしたときの電気の流れにくさを使います。この値を「抵抗率」と呼び、単位はΩ·cm(オーム・センチメートル)です。値が小さいほど、電気を通しやすい材料です。銅と、ガラスの主な成分である二酸化シリコン(SiO₂)では、抵抗率がおよそ10の20乗倍(1のあとに0が20個)も違います。

ただし、「半分だけ電気を通す」と覚えると、半導体のいちばん大事な点を見落とします。図のとおり、純粋なシリコンは、じつはかなり電気を通しにくい材料です。半導体の本当の特徴は、次に見るように、通しやすさを外から大きく変えられることです。

いちばん大事な点: 通しやすさを変えられる

電気が流れるのは、電気をもった小さな粒が動くからです。金属には、自由に動ける電子がもともとたくさんあります。半導体では、この「電気の運び手」の数を、あとから増やしたり減らしたりできます。

半導体の通しやすさは、次の4つの方法で変えられます。金属では、どれをしても通しやすさはあまり変わりません。

  • 不純物を加える: ほかの元素をほんの少し混ぜます。部品の性質を決める、半導体作りの中心の方法です。混ぜる量はとても少なく、例えばシリコンの原子500万個に1個でも、通しやすさは数十万倍になります。
  • 電圧をかける: 薄い絶縁の膜をはさんで金属の板(電極)を置き、電圧をかけます。すると電気の運び手が引き寄せられ、膜のすぐ下だけ電気が通るようになります。トランジスタというスイッチは、このしくみを使っています。
  • 光を当てる: 光のエネルギーで電気の運び手が生まれ、電気が流れやすくなります。カメラのイメージセンサや太陽電池は、この性質を使っています。
  • 温度を変える: 純粋な半導体は、温度が上がるほど電気を通しやすくなります。金属とは逆の向きです。この性質は、温度を測る部品にも使われます。

電子機器にとって特に大事なのは、最初の2つです。不純物で電気の運び手の種類と量を作り分け、電圧でその場の流れをオン・オフする。この組み合わせが、半導体の部品の基本です。

なぜシリコンが使われるのか

半導体になる物質はいくつもあります。それでも、コンピュータやスマホで計算や記憶をするチップの大部分は、シリコン(ケイ素)で作られています。理由は大きく3つあります。

1. 材料がたくさんある

シリコンは、地球の表面をおおう岩石の層(地殻)の重さの4分の1以上を占めます。酸素に次いで2番目に多い元素です。砂や水晶の主な成分も、シリコンと酸素が結びついたものです。ただし砂をそのまま使えるわけではなく、何段階もの精製が必要です。

2. 電気を仕切るよい膜を作りやすい

シリコンを酸素の中で高温に熱すると、表面に二酸化シリコン(SiO₂)のきれいな膜ができます。この方法を熱酸化と呼びます。SiO₂は電気をほとんど通さないうえ、シリコンとの境目に傷が少ない膜になります。そのため、トランジスタの電極の下の薄い膜など、電気を仕切る膜に使えます。

じつは、最初のトランジスタ(1947年、米国ベル研究所)はゲルマニウムという別の半導体で作られました。その後シリコンが主役になったのは、このよい膜を作れることが大きな理由です。シリコンのほうが、温度が上がっても電気が漏れにくいという利点もあります。

3. とても純粋な、大きな結晶を作れる

半導体の部品には、原子が規則正しく並んだ結晶を使います。全体が一つの結晶としてそろったものを「単結晶」と呼びます。シリコンでは、直径30 cmもの単結晶を作る技術が確立しています。これを薄く切った円い板(ウエハ)の上に、部品を作り込みます。

原料のシリコンの純度は、99.999999999%(9が11個並ぶので「イレブンナイン」)という水準です。不純物は、原子1000億個あたり1個以下ということです。ここまで純度を上げるのは、狙った不純物をごく少量だけ加えて性質を決めるためです。余計なものが最初から混じっていると、狙いどおりの性質になりません。

n型とp型: 不純物で「電気の運び手」を作る

シリコンの原子は、いちばん外側に4個の電子をもっています。結晶の中では、となりの4個の原子と電子を出し合い、手をつなぐように結びついています。すべての電子が結びつきに使われるので、純粋なシリコンには自由に動ける電子がほとんどありません。これが、純粋なシリコンが電気を通しにくい理由です。

ここに、外側の電子を5個もつリン(P)を少し混ぜます。リンはシリコンの位置に入り、4個の電子で結びつきを作ります。残った1個はゆるく引き止められているだけで、室温ではほぼすべてが離れて動き回れるようになります。このように電子を与える不純物をドナー(与えるもの)と呼びます。

ドナーを加えて、マイナスの電気をもつ電子が電気を運ぶようにしたものを「n型半導体」と呼びます。n は negative(マイナス)の頭文字です。電子が増えても、リンの側に同じ量のプラスの電気が残ります。そのため、全体としてはマイナスに帯電しません。

反対に、外側の電子が3個のホウ素(B)を混ぜると、結びつきに電子が1個足りなくなります。この電子の空席に、となりの結びつきから電子が移ると、空席は反対の向きへ移ります。空席はプラスの電気をもつ粒のようにふるまうので、「正孔(せいこう)」と呼びます。

ホウ素のように電子を受け取る不純物をアクセプタ(受け取るもの)と呼びます。アクセプタを加えて、正孔が電気を運ぶようにしたものが「p型半導体」です。p は positive(プラス)の頭文字です。

電子や正孔のように電気を運ぶ粒を、まとめて「キャリア」(運ぶもの)と呼びます。n型では電子が、p型では正孔が、数の多いほうのキャリアです。これを多数キャリアと呼びます。どちらの型でも、加える不純物はシリコンの原子に比べてごくわずかです。

たとえで言うと

正孔の動き方は、満席に近い映画館の座席の列に似ています。列に空席が1つあり、となりの人が1つずつ席をずれていくと、空席は人の動きとは逆の向きに進みます。動いているのは人ですが、空席を1つのものとして追いかけたほうが、話が簡単になります。正孔も同じで、実際に動くのは電子ですが、空席を「プラスの粒」として扱います。

たとえが当てはまらない点: 座席の人は自分の意思で動きますが、結晶の中の電子は電圧に押されて動きます。また本物の正孔は、電子とは動きやすさの違う、独自の粒としてふるまいます(シリコンでは電子のほうが約3倍動きやすい)。座席のたとえでは、この違いは表せません。

もう一歩: バンドギャップという「段差」

ここまでは、原子のつながりの絵で考えました。物理の教科書では、同じことを電子のエネルギーの「段」で説明します。この見方を使うと、導体・半導体・絶縁体の違いを1枚の図で比べられます。

結晶の中の電子がとれるエネルギーは、いくつかの決まった範囲(帯)に限られます。半導体や絶縁体では、下の帯は電子で満員で、そのままでは電子が動けません。上の帯に上がった電子と、そのとき下の帯にできた空席(正孔)が、電気を運べます。2つの帯のあいだの、電子がとれないすき間の大きさをバンドギャップと呼びます。

すき間の大きさは、eV(電子ボルト)という単位で表します。1 eVは、電子1個が1ボルトの電圧に押されて得るエネルギーです。シリコンのすき間は約1.1 eV、絶縁体の二酸化シリコンは約9 eVです。金属では、電子の入った帯のすぐ上に空きがあり、すき間がありません。

シリコンのすき間は、室温の熱でごくわずかな電子が越えられる程度の大きさです。温度が上がると越える電子が増えるので、純粋な半導体は温度が高いほど電気を通しやすくなります。光を当てたときに流れやすくなるのも、光のエネルギーで電子がすき間を越えるからです。一方、ドナーの電子は、すき間よりずっと小さなエネルギーで上の帯に移れます。

たとえで言うと

バンドギャップは、2階建ての駐車場の「階の高さ」に似ています。1階は車でぎっしり満車で、どの車も動けません。2階はがらがらですが、車が2階に上がるには坂を上る力が要ります。上がった車は自由に走れます。この坂の高さにあたるのがバンドギャップで、坂が高いほど2階に上がれる車が減り、電気が流れにくくなります。

たとえが当てはまらない点: 駐車場の1階と2階は場所が違いますが、電子の「段」は場所の違いではありません。同じ結晶の同じ場所で、電子のエネルギーの値が違うだけです。また電子は、車のように1台ずつ見分けて動きを追えるものではありません。このたとえは「上がるのにエネルギーが要る」という一点だけを表しています。

だからスイッチが作れる

p型とn型をくっつけると、境目で電気の通り方に向きができます。p型の側をプラスにすると電流がよく流れ、逆向きにすると、ほとんど流れません。この、一方向にだけ電流をよく流す性質を「整流作用」と呼びます。

整流作用をもつ部品が、ダイオードです。コンセントの交流(向きが行ったり来たりする電気)を、電子機器が使う直流(向きが一定の電気)に変える回路などで使われます。LEDも、電気を光に変えるダイオードの一種です。p型とn型の境目で何が起きているかは、PN接合の図解で動かしながら確かめられます。

さらに、n型とp型を組み合わせて電極をつけると、電極にかける電圧で電気の通り道ができたり消えたりする部品が作れます。これがトランジスタです。電圧という小さな信号で電流のオン・オフを切り替える、電気で動くスイッチです。くわしいしくみは、次の記事「トランジスタとは?」で説明します。

スイッチのオンとオフは、0と1という2つの状態を表せます。たくさんのトランジスタを組み合わせると、0と1で計算したり、覚えたりする回路になります。スマホのCPUのような計算の部品も、もとをたどれば、この小さなスイッチの集まりです(「CPUとは?」)。

「半導体」という言葉の3つの意味

「半導体」という言葉は、場面によって3つのものを指します。ニュースを読むときは、どれの話かを意識すると、内容がつかみやすくなります。

指しているもの例よく出る場面
材料シリコン、炭化ケイ素(SiC)、窒化ガリウム(GaN)物理や材料の話
部品(1個で働くもの)ダイオード、パワー半導体電源やモーターの話
チップ(集積回路)CPU、メモリ「半導体不足」「半導体工場」

3つ目のチップは、シリコンの小さなかけらの上に、たくさんのトランジスタと配線を作り込んだものです。正式には集積回路、英語の頭文字でICと呼びます。ニュースの「半導体」の多くは、このICのことです。

2つ目のように、1つの働きを1個で受け持つ部品は、ICと区別してディスクリート半導体と呼ばれます。半導体は、家電から自動車まであらゆる製品に欠かせないため、日本では「産業のコメ」とも呼ばれてきました。

よくある誤解

誤解: 半導体は「電気を半分だけ通す」材料

実際は、通しやすさを大きく変えられることが特徴です。純粋なシリコンは、むしろ電気を通しにくい材料です。不純物の量によって、電気をかなり通しにくい状態から金属に近い状態まで、何桁も変えられます。「半分の導体」という名前と、抵抗率が中間にあるという説明だけが広まったことから生まれる誤解です。

誤解: 「半導体」とはチップ(IC)のこと

実際は、材料・部品・チップの3つを指します。LED電球の光る部分や太陽電池も半導体ですが、多くのトランジスタを集めたICではありません。ニュースが「半導体チップ」を短く「半導体」と呼ぶことが多いため、この誤解が生まれます。

誤解: 半導体はすべてシリコンでできている

実際は、用途によって別の材料も使います。青や白のLEDは、窒化ガリウム(GaN)の仲間で作ります。シリコンは光を出すのが苦手だからです。電気自動車などのパワー半導体では、高い電圧に強い炭化ケイ素(SiC)も広く使われています。計算や記憶のチップの多くがシリコン製なので、このように思われがちです。

理解度チェック

記事の内容で答えられる3問です。答えを開いて確かめてください。

シリコンにホウ素(B)を不純物として添加したときの説明として正しいものはどれか。

  1. A電気的に不活性で、導電型は変わらない
  2. Bドナーとして働き、n型半導体になる
  3. Cアクセプタとして働き、p型半導体になる
答えと解説を見る

正解：C. アクセプタとして働き、p型半導体になる

ホウ素はIII族で価電子が3個のため、共有結合に電子が1個足りず、周囲から電子を受け取ります。すると価電子帯に正孔ができ、シリコンはp型になります。ホウ素はシリコン中の代表的なアクセプタで、準位は価電子帯から約0.045 eVと浅く、室温でほぼ全てイオン化します。原子が軽く拡散が速いため、浅い接合を作るときは低エネルギー注入やBF2の注入が使われます。

p型半導体の多数キャリアはどれか。

  1. Aイオン化したアクセプタ
  2. B正孔
  3. C電子
答えと解説を見る

正解：B. 正孔

p型ではアクセプタが価電子帯から電子を受け取るため正孔が増え、多数キャリアは正孔、少数キャリアは電子になります。イオン化したアクセプタは格子に固定された負の電荷で、自分は動けません。ただし空乏層では、この固定電荷が電界と内蔵電位を生み出す主役になります。MOSFETでは、p型基板の表面に少数キャリアの電子を集めて(反転)nチャネルを作ります。

ダイオードが一方向にだけ電流をよく流し、逆方向にはほとんど流さない性質を何と呼ぶか。

  1. A光電効果
  2. B整流作用
  3. C増幅作用
答えと解説を見る

正解：B. 整流作用

順方向には電流がよく流れ、逆方向にはほとんど流れない性質を整流作用といいます。シリコンダイオードでは順方向と逆方向の電流の比が10⁸倍以上にもなります。この性質で交流を直流に変える整流回路がつくられ、電源のほか、ラジオの検波や信号のクランプ、論理回路の保護にも使われます。最初期の整流素子は鉱石検波器や真空管で、PN接合はそれを小型・高信頼にしました。
