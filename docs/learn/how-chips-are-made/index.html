半導体チップはどうやって作られる? 前工程・後工程の全体像

約13分 · 更新: 2026年10月23日

半導体チップは、石から取り出したシリコンの円い薄い板(ウエハ)の上で作ります。「膜をつける・光で模様を写す・削る」を数十回くり返し、数百個のチップを同時に作ります(前工程)。最後に1個ずつ切り分け、包んで外とつなぎ、検査して完成です(後工程)。

この記事でわかること

  • 石からウエハができるまでの流れ
  • 前工程の基本: 膜をつけ、光で模様を写し、削る
  • 同じような工程を数十回もくり返す理由
  • クリーンルームで、ほこりを嫌う理由
  • 後工程(検査・切り分け・パッケージ)と、かかる時間、だれが作っているか

前提知識: とくになし。チップの中身が「トランジスタというスイッチと、それをつなぐ配線」だと知っていると読みやすくなります。

身近なところでは

スマホやパソコンの中には、計算や記憶をする黒い小さな部品がいくつも載っています。その中身が、シリコンの小さなかけらに回路を作り込んだ「チップ」です。スマホの計算を受け持つチップには、トランジスタという小さなスイッチが何十億個も入っています。くわしくは「トランジスタとは?」で説明しています。

これほど小さなものを、1個ずつ組み立てることはできません。そこで、たくさんのチップを1枚の板の上でまとめて作り、最後に切り分けます。

全体の流れ: 3つの段階

チップができるまでは、大きく3つの段階に分けられます。まず、材料のシリコンから、ウエハという円い板を作ります。次に、ウエハの上にトランジスタと配線を作り込みます。この段階を「前工程(まえこうてい)」と呼びます。

最後に、ウエハを1個ずつのチップに切り分け、部品の形に仕上げて検査します。この段階を「後工程(あとこうてい)」と呼びます。2つの違いは、比較ページ「前工程と後工程の違い」の表でも確かめられます。

石からウエハへ

シリコンは、砂や岩に多く含まれる二酸化ケイ素(シリコンと酸素が結びついたもの)から取り出します。ただし、浜辺の砂をそのまま使うわけではありません。純度の高いけい石(石英の岩)を、炭素と一緒に電気炉で高温に熱して、酸素を取り除きます。こうしてできるシリコンの純度は、まだ98%ほどです。

これを、いったん液体の化合物に変えて不純物を除き、ふたたび固体のシリコンに戻します(シーメンス法)。できるのは、小さな結晶の粒がたくさん集まった「多結晶シリコン」です。純度は、9が11個並ぶ99.999999999%ほどまで上がります。この純度が必要な理由は「半導体とは?」で説明しています。

チップには、全体の原子の並びが1つにそろった「単結晶」が必要です。そこで、多結晶シリコンを石英の耐熱の器に入れ、1,400 ℃あまりで溶かします。そこへ小さな単結晶のかけら(種)を浸し、回しながらゆっくり引き上げます。種と同じ並びのまま、結晶が太く長く育ちます。この育て方をCZ法と呼びます。

回しながら引き上げるので、できる結晶の塊は円柱の形になります。この塊をインゴットと呼びます。ウエハが円い形をしているのは、この円柱を輪切りにするからです。

インゴットは、細いワイヤーを使った切断機で、厚さ1 mm足らずの円い板に切り分けます。表面を研磨して鏡のように平らにすれば、ウエハの完成です。量産で使われる最も大きなウエハは、直径300 mmです。

前工程: 模様を写して、削る

前工程では、1枚のウエハの上に、同じチップを碁盤の目のように数百個並べて作ります。ほとんどの作業は、ウエハ1枚分をまとめて行います。チップを1個ずつ加工するのではないので、たくさんのチップを同じ品質で作れます。

基本になるのは、膜に回路の模様を刻む一連の作業です。図の①〜⑥の順に進みます。

  1. 膜をつける(成膜): ウエハの表面全体に、ごく薄い膜をつけます。電気を通さない膜や、配線になる金属の膜などです。
  2. レジストを塗る: 光が当たると性質が変わる薬剤を、膜の上に薄く塗ります。
  3. 光を当てる(露光): 回路の模様を描いた原版を通して光を当て、模様の形にレジストを変化させます。
  4. 現像する: 薬液で、光が当たった部分のレジストを溶かします(光が当たらなかった部分が溶ける種類もあります)。
  5. エッチング: レジストで覆われていない部分の膜を、ガスや薬液で削り取ります。
  6. レジストを除く: 役目を終えたレジストを取り除くと、膜に回路の模様が残ります。

②で塗る、光で性質が変わる薬剤をフォトレジストと呼びます。現場では短く「レジスト」と言います。光が当たった部分が溶けるものと、残るものの2種類があります。

③で使う原版をマスクと呼びます。ガラスの板に、光をさえぎる膜で回路の模様が描かれています。露光装置は、この模様をレンズや鏡で縮めてウエハに写します。一度に写すのはウエハの一部なので、ウエハを少しずつずらしながら、全面に同じ模様を写していきます。

②〜④のように、光を使って模様をレジストに写す作業全体を、リソグラフィと呼びます。もとは、石版を使った印刷の技術の名前です。リソグラフィで写せる模様の細かさが、チップをどこまで細かく作れるかを大きく左右します。

たとえで言うと

リソグラフィは、型紙(ステンシル)を使った吹き付け塗装に少し似ています。型紙の穴の形どおりに、同じ模様を何度でも写せます。マスクも同じで、1枚のマスクから、ウエハ上の数百個のチップに同じ模様を写せます。似ているのは「1つの原版から、同じ模様をくり返し写す」という一点です。

たとえが当てはまらない点: 塗装では、型紙を通った塗料そのものが模様になります。リソグラフィの光は、レジストの性質を変えるだけです。回路の形ができるのは、そのあとの現像やエッチングによります。また、マスクはウエハにふれず、離れた場所からレンズや鏡で縮めて写します。

前工程のほかの作業

模様を写して削る作業のほかにも、前工程にはいくつかの大事な作業があります。ここでは代表的な3つを挙げます。

  • 不純物を打ち込む: 半導体の性質を決める元素(不純物)を、電気の力で加速してウエハに打ち込みます。この作業をイオン注入と呼びます。レジストで覆った部分には入らないので、決めた場所だけ電気の通りやすさを変えられます。
  • 平らに磨く: 層を重ねると、表面に凹凸ができます。凹凸が残ると、次の露光でピントが合わない場所が出ます。そこで、薬液と研磨用のパッドで表面を平らに磨きます。この作業をCMPと呼びます。
  • 洗う: 小さなごみや、わずかな金属の汚れでも、回路の不良の原因になります。そのため、多くの作業の前後でウエハを洗います。洗浄は、前工程の中でも特に回数の多い作業です。

このほか、途中で膜の厚さや模様の寸法を測り、きずやごみがないかを検査します。問題を早く見つけるほど、むだになるウエハを減らせるからです。

なぜ何十回もくり返すのか

チップは、1枚の模様でできているわけではありません。下から順に、たくさんの層を積み重ねた立体の構造です。層ごとに形が違うので、層ごとに別のマスクを使い、ここまでの作業をくり返します。

まず、シリコンの表面にトランジスタを作ります。不純物を入れる場所、電圧をかける電極、それらを仕切る膜など、トランジスタだけでも何枚ものマスクが必要です。そのあと、トランジスタどうしをつなぐ配線を、電気を通さない膜をはさんで何層も重ねます。こうして何層にも重ねた配線を、多層配線と呼びます。

何十億個ものトランジスタを、平らな1層の配線だけでつなぐことはできません。下の層では細い配線で近くのトランジスタどうしを結びます。上の層ほど太い配線にして、チップの遠い場所どうしや、電源をつなぎます。上下の層は、縦の細い柱のような配線でつながっています。

新しい層の模様は、下の層の模様とぴったり重ならなければなりません。露光装置は、ウエハにつけた目印を読み取って位置を合わせてから光を当てます。くり返す回数はチップの種類で違い、露光装置メーカーのASMLは、模様を写す作業が100回以上になると説明しています。

クリーンルーム: なぜほこりを嫌うのか

前工程は、空気中の小さな粒を極端に減らした部屋で行います。この部屋をクリーンルームと呼びます。天井から、ごく細かい粒までこし取るフィルターを通した空気を送り、粒を床へ押し流し続けています。

ほこりを嫌うのは、チップの模様がとても細かいからです。nm(ナノメートル)は、100万分の1 mmです。IEEE Spectrumの記事(2020年)によると、当時の最先端のチップの細い配線は、約36 nmの間隔で並びます。髪の毛1本(太さ約0.09 mm)の幅に、この配線が2,000本以上並ぶ細かさです。

この細かさでは、100 nmの粒が1つ乗るだけで、となり合う数本の配線にまたがります。配線どうしがつながったり、途中で切れたりして、そのチップは不良になります。目に見えない粒でも、チップにとっては大きな岩のようなものです。

空気のきれいさには、国際規格(ISO 14644-1)で決めたクラスがあります。都市の外気は、いちばんゆるいクラス9に当たります。最もきれいなクラス1では、100 nm以上の粒が空気1 m³あたり10個までです。工場では、ウエハが通る場所ほど厳しく管理し、ウエハは密閉した容器に入れて運びます。

作業する人は、全身を覆う専用の服を着ます。人の体や服からは、皮膚のかけらや繊維などの粒が絶えず出ているからです。この服は、人を守るためというより、人から出る粒からウエハを守るためのものです。

後工程: 切り分けて、包んで、検査する

前工程を終えたウエハには、完成したチップが並んでいます。ただし、すべてが良品とは限りません。そこで、まずウエハのまま、チップ1個ずつの電極に細い針を当てて、電気的に正しく動くかを調べます。この検査をウエハテストと呼び、不良のチップの位置を記録しておきます。

次に、ウエハの裏を削って薄くしたあと、回転する刃などで1個ずつのチップに切り分けます。この作業をダイシングと呼びます。切り分けたチップは、外とつなぐための土台(基板や金属の枠)に固定します。

チップの電極と土台は、主に2つの方法でつなぎます。1つは、髪の毛より細い金や銅の線で1本ずつ結ぶワイヤボンディングです。もう1つは、チップを裏返し、電極に付けた小さな金属の粒で直接つなぐ方法で、フリップチップと呼びます。違いは「ワイヤボンディングとフリップチップの違い」で比べられます。

つないだチップを樹脂などで包んで守り、外につなぐ端子をそろえると、部品の形になります。この入れ物を含めた全体をパッケージと呼びます。パッケージには、チップを湿気や衝撃から守り、熱を逃がす役目もあります。

最後に、完成した部品をもう一度検査します。これを最終テスト(ファイナルテスト)と呼びます。包む作業で壊れていないか、決められた温度や電圧で性能が出るかを確かめ、合格したものだけを出荷します。2つの検査の違いは「ウエハテストとファイナルテストの違い」にまとめています。

どれくらい時間がかかる?

米国半導体工業会(SIA)の2021年の解説によると、前工程にかかる時間は平均で約12週間です。先端のチップでは14〜20週間かかることもあります。後工程の組み立てと検査には、さらに6週間ほどかかります。

前工程に時間がかかるのは、ここまで見たように、同じような作業を層の数だけくり返すからです。1台の装置で済むわけではなく、ウエハは多くの装置の間を何度も行き来します。そのため、注文が急に増えても、すぐには出荷を増やせません。

歩留まり: 全部は良品にならない

どれほど管理しても、ウエハの上には一定の割合で不良のチップができます。作ったチップのうち良品の割合を歩留まりと呼び、チップ1個の値段を大きく左右します。小さな欠陥がランダムに散らばると考えると、チップが大きいほど欠陥に当たりやすく、歩留まりは下がります。

例えば直径300 mmのウエハからは、10 mm角のチップが約600個取れます。欠陥が1 cm²あたり0.1個なら、良品は約9割です。20 mm角にすると、取れる数は約150個、良品は約3分の2に減ります(当サイトの計算ツールによる概算)。ダイ数・歩留まり計算ツールで、チップの大きさを変えて試せます。

だれが作っている?

ここまでの流れを、1つの会社ですべて行うことはまれです。段階ごとに得意な会社が受け持つ、分業で成り立っています。下の表は、左から順に「何をする会社か」「業界での呼び名」「会社の例」です。

何をする会社か呼び名例
ウエハを作るウエハメーカー信越化学工業、SUMCO
工場で使う装置や材料を作る装置メーカー、材料メーカーASML、東京エレクトロン
チップの設計だけをして、製造は他社に任せるファブレスNVIDIA、クアルコム
他社が設計したチップの前工程を引き受けるファウンドリTSMC
後工程(組み立てと検査)を引き受けるOSATASE、Amkor
設計から製造まで自社で行うIDMインテル

呼び名を全部覚える必要はありません。ニュースで特によく出るのは、製造を引き受けるファウンドリです。それぞれの違いは「IDM・ファブレス・ファウンドリの違い」で比べられます。

よくある誤解

誤解: 機械がシリコンを1個ずつ削って、チップを作っている

実際は、1枚のウエハの上で数百個のチップを同時に作ります。模様は光で写し、膜をつける・削る・不純物を入れるといった作業を、ウエハ全体にまとめて行います。削るだけでなく、膜を積み上げる作業も同じくらい大事です。金属部品を削り出すイメージから生まれやすい誤解です。

誤解: クリーンルームは、人のために衛生的にしている部屋

実際は、ウエハを粒や汚れから守るための部屋です。人は粒を出す大きな発生源なので、全身を覆う服で、人から出る粒を閉じ込めます。病院の手術室のような「清潔」のイメージから生まれる誤解です。危険な薬品やガスから人を守る対策は、これとは別に行われています。

誤解: 回路を1回「印刷」すれば、チップができあがる

実際は、層ごとに別のマスクで模様を写し、膜をつけて削る作業を数十回くり返します。新しい層は、下の層とぴったり位置を合わせて重ねる必要があります。リソグラフィの語源が「印刷」であることや、「回路を焼き付ける」という表現から生まれやすい誤解です。

数字何の数字か

数字を並べると、前工程の難しさが見えてきます。髪の毛の2,000分の1ほどの間隔の模様を、層ごとに位置を合わせて何十回も重ねます。そのあいだ、数百個のチップのどこにも、粒1つ落とさないようにしなければなりません。
