電気自動車(EV)にはどんな半導体が入っている? 主なチップと役割

約13分 · 更新: 2026年10月23日

電気自動車(EV)の中心で働く半導体は、電池の直流を交流に変えてモーターを回す、インバータの中のパワー半導体です。そのまわりで、電池のセルを1つずつ見張るIC、全体を制御するマイコン、電流や回転を測るセンサが働きます。充電器や12ボルトを作る装置にもチップが要ります。ある分析(2022年)では、EVの半導体の数はエンジン車の約2倍です。

この記事でわかること

  • EVの主な電気の部品と、それぞれのチップ(電池を見張るICなど)
  • 回生ブレーキで、減速しながら電気を戻すしくみ
  • 400ボルトと800ボルトの違いが、チップに何を求めるか
  • EVで半導体が増える理由と、車のチップに求められる丈夫さ

前提知識: 特にありません。「パワー半導体とは?」を読んでいると、インバータの話がわかりやすくなります。

身近なところでは: 静かに走り出す車

EVは、エンジンの音がなく、静かに走り出します。アクセルを戻すと、ブレーキを踏まなくても、すっと速度が落ちます。家で充電できるのも、エンジン車との違いです。

こうした動きを、半導体のチップが受け持っています。エンジン車にも、制御のためのマイコンはたくさん入っています(「マイコンとは?」)。EV(ここでは電池だけで走る車)では、走る力を電気で作ります。そのため、大きな電気を扱うチップが加わります。

電池パック: たくさんのセルと、見張るチップ

EVの電池パックには、リチウムイオン電池の小さな単位がたくさん並んでいます。この1つ1つをセルと呼びます。1セルの電圧は約3.7ボルトです(「リチウムイオン電池とは?」)。

数百ボルトを作るには、多くのセルを1列につなぎます。これを直列と呼び、電圧は足し算になります。たとえば96個を直列にすると、約355ボルトです(当サイトの計算)。

セルには、使ってよい電圧の範囲があります。上限を超えて充電したり、使いすぎたりすると、傷んだり危険になったりします。ところが、直列のセルの残りの量は、少しずつずれていきます。1つでも上限に達したら、全体の充電を止めなければなりません。

そこで、セルの電圧と温度を細かく測るチップ、電池監視ICを使います。たとえばTexas Instrumentsの車載用の品種BQ79616-Q1は、1個で最大16個のセルを測れます。96個のセルなら、6個のチップで見張る計算です(当サイトの計算)。

残りの量のずれをそろえるのも、このチップの仕事です。多く残っているセルから少しだけ電気を逃がして、ほかのセルにそろえます。これをセルバランスと呼びます。

測った値は、チップからチップへ、数珠つなぎで送ります。ただし、端と端のセルでは、電圧が数百ボルトも違います。そこで、電気を直接つながずに、信号だけを伝えます。これを絶縁と呼び、この品種では間にコンデンサか変圧器をはさみます。

集まった値から、残りの量や出してよい電力を計算するのはマイコンです。この管理の仕組み全体を、BMS(バッテリー管理システム)と呼びます。

インバータとモーター: 走る力を作る

インバータは、電池の直流を、モーターを回すための交流に作り直します。しくみは「インバーターとは?」で説明したので、ここでは中のチップを見ます。

中心は、大きな電流を速くオン・オフするスイッチです。EVでは主に、シリコンのIGBTか、SiC(炭化ケイ素)のMOSFETが使われます。どちらもパワー半導体の一種で、違いは「IGBTとパワーMOSFETの違い」にまとめています。

3本の線で電気を受け取るモーターには、6つのスイッチが基本です。ふつうは1つのチップでは大きな電流を流しきれないので、同じ役目のチップを何個も並べて使います。2018年の分解調査では、テスラ「Model 3」のインバータに、SiCの部品が24個ありました(「SiCとは?」)。

パワー半導体は、マイコンの信号では直接動かせません。スイッチを入り切りする電極(ゲート)を、大きめの電流で素早く操作する必要があるからです。この役目のチップをゲートドライバと呼びます。EV用のものは、マイコンの側とスイッチの高い電圧の側を絶縁しています(TIの解説)。

いつ、どのスイッチを入れるかを計算するのは、マイコンです。もとになるのは、モーターに流れる電流と回転の角度で、それぞれを測るセンサがあります(Allegroの解説)。電流のセンサには、電流が作る磁石の力を測るホール素子などが使われます。

回生ブレーキ: 減速しながら発電する

EVでアクセルを戻すと、速度が落ちながら電池に電気が戻ります。これを回生ブレーキと呼びます。

モーターは、電気を流すと回ります。逆に、外から軸を回すと、電気を生みます。発電機と同じ働きです。走っている車には勢いがあるので、アクセルを戻しても、車輪がモーターの軸を回し続けます。

このとき、インバータはスイッチの入れ方を変えて、モーターに発電させます。発電すると、モーターの軸は回しにくくなります。この「回しにくさ」が、車を減速させる力になります。生まれた交流は、インバータで直流に戻し、電池にためます。同じパワー半導体が、行きと帰りの両方の向きに働くのです。

たとえで言うと

回生ブレーキは、自転車のライトの発電機(ダイナモ)に少し似ています。ダイナモをタイヤに当ててライトをつけると、ペダルが少し重くなります。発電すると、回す側に「重さ」がかかるのです。似ているのは「発電すると、回しにくくなる」という一点です。

たとえが当てはまらない点: ダイナモの電気はその場でライトに使われ、ためられません。EVは電気を電池にため、次の加速に使います。また、減速の勢いのうち、電池に戻せるのは一部で、残りは熱になります。

いつでも同じだけ回生できるわけではありません。日産リーフの取扱説明書では、電池が満充電のときは、回生を自動で弱めるとしています。電池の温度が高すぎるとき、低すぎるときも同じです。どちらも電池を傷めないためで、そのぶんはふつうのブレーキ(摩擦ブレーキ)が受け持ちます。

充電の道: 車載充電器と急速充電

家や普通充電のスタンドから車に届くのは、交流です。電池にためられるのは直流なので、車の中で交流を直流に変えます。この装置を車載充電器(オンボードチャージャー)と呼びます(Boschの用語解説)。

車載充電器の中でも、パワー半導体が働きます。交流を一つの向きの流れにそろえ、電池に合った電圧と電流に整えます。流れはスマホの充電器と似ていて、扱う電力がずっと大きい装置です(「ACアダプターのしくみ」)。ロームの資料によると、ここにもSiCのダイオードやMOSFETが使われています。

急速充電では、交流から直流への変換を、充電スタンドの中の大きな装置が受け持ちます。車には直流が届き、車載充電器を通らずに電池へ入ります。

12ボルトの世界とDC-DCコンバータ

EVにも、エンジン車と同じ12ボルトで動く部品がたくさんあります。ライト、カメラ、多くの制御装置です(パナソニックの解説)。

そこで、電池の数百ボルトを12ボルトに下げる装置を積んでいます。直流の電圧を、別の大きさの直流に変える回路をDC-DCコンバータと呼びます。中では、パワー半導体を速くオン・オフして、電圧を下げます。

多くのEVは12ボルトの小さな電池(鉛電池など)も積み、DC-DCコンバータがこれを充電します。安全のため、高い電圧の側と12ボルトの側は絶縁されています(Boschの製品情報)。

運転を助けるチップ: カメラ・レーダー・SoC

車線のはみ出しを知らせたり、前の車との距離を保ったりする機能を、ADAS(先進運転支援システム)と呼びます。エンジン車にも広く載っています。

周りを見るのは、カメラのイメージセンサ(「イメージセンサとは?」)と、電波で距離を測るレーダーです。見えたものから人や車を見分ける計算は、CPUやAI向けの回路をまとめた大きなチップ(SoC)が受け持ちます。

400ボルトと800ボルト: チップにとって何が違う?

多くのEVの電池は、400ボルト級です(Boschの用語解説)。2019年に出たポルシェ「タイカン」は、800ボルトを使う初めての量産車でした(ポルシェの発表)。ヒョンデも2020年12月、800ボルトの急速充電に対応したEV専用の車台を発表しました。

電圧を上げるのは、電流を減らせるからです。電気が1秒間に運ぶエネルギーを電力と呼び、電圧と電流の掛け算で決まります。同じ200キロワットなら、400ボルトでは500アンペア、800ボルトでは半分の250アンペアです(当サイトの計算)。

電流が半分になると、電線で熱になる分は、同じ電線なら約4分の1です。熱になる分は、電流を2回掛けた値に比例するからです(当サイトの計算。単純化しています)。そのため電線を細くしやすく、急速充電で大きな電力を受け取りやすくなります(Boschの用語解説)。

たとえで言うと

電圧を上げて電流を減らすのは、水車を回す水に少し似ています。水車を回す力は、水の落ちる高さと、流れる水の量で決まります。高いところから落とせば、少ない水でも同じ力が出せます。水が少なければ、細い水路ですみます。似ているのは「押す強さを上げれば、流す量を減らせる」という点です。

たとえが当てはまらない点: 電線の中の電子は、水のように速く流れているわけではありません。電子そのものはゆっくり動き、電気のエネルギーはそれとは別の速さで伝わります。また、電線が熱を出すしくみは、水路の水の流れにはうまく対応しません。

チップにとっての違いは、耐えなければならない電圧です。部品が壊れずに耐えられる電圧を、耐圧と呼びます。電池の電圧は充電の状態で上下し、スイッチを切る瞬間には一時的に跳ね上がります。そのため一般に、電池の電圧よりかなり高い耐圧の部品を選びます。400ボルト級の車では650〜750ボルト級、800ボルト級の車では1,200ボルト級が目安です(部品メーカーの資料)。

1,200ボルト級では、シリコンのIGBTより、SiCのMOSFETの利点が大きくなります。たとえばInfineonは2021年、800ボルトの車向けに1,200ボルトのSiCの部品を出しました。

なぜEVには半導体が多いのか

エンジン車では、走る力はガソリンを燃やして作り、電気は主にライトや制御装置に使います。EVでは、走る力そのものが電気です。車を動かすほどの大きな電力が、インバータのスイッチを毎秒数千〜数万回切り替えながら通ります。

そのうえ、電気の形を変える場所が、インバータ、車載充電器、DC-DCコンバータと何か所もあります。どれにも、パワー半導体とゲートドライバ、制御するマイコンが要ります。

コンサルティング会社P3の分析(2022年の記事)では、EV1台の半導体は約1,300個、エンジン車は約600個でした。差の多くは走るための部分(駆動系)で、EVが約600個、エンジン車が約300個です。

金額では、ドイツの半導体メーカーInfineonの推定があります。2025年の1台あたりで、エンジン車は約750ドル、EVは約1,400ドルです(同社の投資家向け資料)。数と金額では、調べた会社も年も違います。それでも、どちらもEVはエンジン車の2倍前後です。

暑さ・寒さ・振動に耐える: 車のチップの丈夫さ

車のチップは、冬の寒さ、夏の炎天下、モーターのそばの熱、走るときの振動にさらされながら、何年も働きます。冷やし方は「チップの冷却とは?」で説明しています。

そこで車のチップは、決められた試験に通ったことを確かめてから使います。代表的な試験の基準が、米国の自動車用電子部品評議会(AEC)のAEC-Q100です。一言でいえば、「車の中の暑さ寒さや湿気に、長い間耐えられるか」を確かめる決まりです。マイコンなどのICが対象で、パワー半導体のような単体の部品には別の基準(AEC-Q101)があります。

試験では、温度の上げ下げを繰り返したり、高い温度で長く動かしたりして、弱いところがないかを確かめます。使える周りの温度には「等級」があり、たとえば等級1は−40〜125℃です。

数の多さも、品質への要求をきびしくします。仮に、100万個に1個だけ不良のチップがあるとします。1台に1,300個使うEVを100万台作ると、約1,300台に不良のチップが入る計算です(当サイトの仮の計算)。

そこで車の業界は、不良ゼロを目標に、設計の余裕、製造の管理、怪しいチップをはじく検査を組み合わせます。この考え方をゼロディフェクトと呼びます。

壊れても危なくならない工夫も要ります。異常を見つけたら、車を安全な状態に移す仕組みなどです。この考え方を機能安全と呼び、自動車向けの国際規格がISO 26262です。

よくある誤解

誤解: EVは部品が少なくシンプルだから、半導体も少ない

実際は、数でも金額でも、エンジン車の2倍前後という推定があります(P3、Infineon)。「部品が少ない」のはエンジンなどの機械の部品の話で、電気の形を変える装置とそのチップは増えます。

誤解: 回生ブレーキがあれば、ふつうのブレーキはほとんど要らない

実際は、ふつうのブレーキも欠かせません。満充電のときや、電池が冷えすぎ・熱すぎのときは、回生が弱まります(日産リーフの取扱説明書)。強く止まるときも、ふつうのブレーキが働きます。アクセルを戻すだけで止まれる場面が多いので、誤解されやすいのです。

誤解: EVのチップは、どれも最先端の「◯nm」で作られている

実際は、パワー半導体の性能は、細かさより材料や構造で決まります。マイコンなど車のチップの多くも、古い世代で作られます。McKinseyの2022年の予測では、2030年でも、車向けのウエハの需要の約3分の2が90nm以上の古い世代です。ニュースでは「半導体」とひとまとめに呼ばれるので、誤解されやすいのです(「「2nm」「3nm」は何の長さ?」)。
