Wi-Fiのしくみとは? 電波でデータを送る方法と速さが変わる理由

約13分 · 更新: 2026年10月23日

Wi-Fiは、スマホやパソコンと家のルータの間を、電波で結ぶしくみです。0と1のデータを電波の波の形の違いに置き換え、決まった順番のルールで電波を分け合って送ります。速さは、電波の幅・波の形の細かさ・アンテナの数・周りの混み具合で決まります。

この記事でわかること

  • Wi-Fiが受け持つ範囲と、その先のインターネットとの関係
  • 電波にデータを乗せるしくみと、2.4・5・6 GHz帯の違い
  • 電波をみんなで分け合うしくみと、世代(Wi-Fi 4〜7)の違い
  • 箱に書かれた速度が出ない理由と、安全に速く使うためのコツ

前提知識: 特にありません。「インターネットはどうやってデータを届けるの?」を先に読むと、つながりがわかります。

身近なところでは

スマホのWi-Fiの設定を開くと、近くのネットワークの名前が並びます。この名前をSSIDと呼びます。自分の家の名前が、末尾だけ違って2つ並ぶこともあります。多くは2.4 GHz帯用と5 GHz帯用です。

ルータの箱には「最大2,402 Mbps」のような速さの数字が書かれています。ところが速度を測るアプリでは、ずっと小さい数字が出ます。その理由を順に見ていきます。

Wi-Fiは「無線LAN」の規格の呼び名

家や会社の中のように、狭い範囲の機器どうしをつなぐネットワークを、LANと呼びます。ケーブルの代わりに電波でつなぐLANが、無線LANです。

無線LANの決まりごとは、技術者の国際的な団体IEEEが「802.11」という番号の規格として定めています。最初の規格は1997年に出て、速さは1秒に最大200万ビット(2 Mbps)でした。ビットは、0か1かの1けたのことです。

Wi-Fiは、この802.11の機器につけられる呼び名です。業界団体のWi-Fi Allianceが機器を試験し、合格した製品に「Wi-Fi」の名前を認めています。ふだんは「無線LAN」と「Wi-Fi」を、ほぼ同じ意味で使います。

Wi-Fiが受け持つのは、家のルータまで

家のWi-Fiでは、スマホやパソコンが、電波で1台の親機とやり取りします。電波を出し入れする親機をアクセスポイントと呼びます。家庭用の「Wi-Fiルータ」の多くは、アクセスポイントとルータを1台にまとめた機器です。

ルータは、ネットワークの境目でデータを中継する機器です。ルータの反対側は、ケーブルで光回線などにつながっています。その先は、インターネットへの接続を提供する会社(プロバイダ)の設備です。

つまり、Wi-Fiが受け持つのは最初の区間だけです。その先のしくみは「インターネットはどうやってデータを届けるの?」で説明しています。

電波は、1秒に何十億回も振れる波

電波は、電気と磁気の振動が空間を伝わっていく波です。光の仲間で、空気中を光とほぼ同じ速さで進みます。波が1秒間に何回振れるかを「周波数」と呼び、単位はHz(ヘルツ)です。

2.4 GHz帯の電波は、1秒に約24億回振れます(Gは10億を表します)。波の山から次の山までの長さを「波長」と呼びます。2.4 GHzの波長は約12.5 cm、5 GHzなら約6 cm、6 GHzなら約5 cmです。

同じ周波数で勝手に電波を出すと、互いの邪魔になります。そこで日本では総務省が、周波数ごとに使いみちを決めています。Wi-Fiには、2.4・5・6 GHz付近の範囲が、免許なしで使えるよう用意されています。この範囲を「帯」や「帯域」と呼びます。

2.4・5・6 GHz帯の違い

一般に、周波数が低い電波ほど、物の陰に回り込みやすく、壁も通り抜けやすい性質があります。そのため2.4 GHz帯は遠くまで届きやすく、別の部屋や別の階でもつながりやすい電波です。5 GHz帯と6 GHz帯は、壁や床で弱まりやすくなります。

その代わり、2.4 GHz帯は、Wi-Fiに使ってよい周波数の幅が約80 MHz(Mは100万)しかありません。電子レンジは食べ物を温めるのに、この帯域の電波を使います。Bluetoothの機器も同じ帯域です。電子レンジを動かすとWi-Fiが遅くなることがあるのは、このためです。

5 GHz帯と6 GHz帯は使える幅が広いので、速くしやすい帯域です。日本では2022年9月に、6 GHz帯のうち500 MHz幅がWi-Fiに開放されました。6 GHz帯は対応する新しい機器しか使えないので、古い機器の電波とは混み合いません。

0と1を電波に乗せる: 波の形を変える

電波そのものは、同じ形で振れ続けるだけの波です。データを送るには、0と1に合わせて波の形を変えます。この操作を「変調」と呼びます。受け取った側は、波の形を読み取って0と1に戻します。

いちばん簡単なのは、波の強さを2段階に変えるやり方です。強い波なら1、弱い波なら0と決めれば、1回の区切りで1ビットを送れます。強さに加えて、波の山が来るタイミングもずらせば、もっと多くの形を作れます。このタイミングを「位相」と呼びます。

Wi-Fiでは、強さと位相の組み合わせで、16通りや1024通りといった数の形を使い分けます。この方式をQAMと呼びます。16通りなら1回で4ビット、1024通りなら1回で10ビットを送れます(2を10回かけると1024です)。

形の種類を増やすほど、隣どうしの形の違いはわずかになります。電波は途中で弱まり、ほかの電波や雑音も混ざります。違いがわずかだと、受け取った側が読み間違えます。細かい形を使えるのは、強くてきれいな電波が届くときだけです。

そこでWi-Fiの機器は、電波の状態に合わせて、形の数を自動で切り替えます。親機の近くでは細かい形で速く、離れると粗い形で確実に送ります。設定画面の「リンク速度」が場所で変わるのは、主にこのためです。

たとえで言うと

夜に、遠くの人へ懐中電灯で合図を送る場面に似ています。「点く・消える」の2段階なら、遠くからでも見分けられます。明るさを16段階に分ければ1回で多く伝えられますが、霧が出ると見分けられません。似ているのは「1回の合図の種類を増やすほど多く送れるが、条件が悪いと間違えやすい」という点です。

たとえが当てはまらない点: 懐中電灯は明るさだけで合図しますが、Wi-Fiは波の強さと位相の2つを組み合わせます。また、電波の雑音は霧と違い、ほかの機器の電波が重なるなど、時と場所で入り方が変わります。

チャネル: 電波の幅を区切って使う

Wi-Fiは、帯域の全体を一度に使うわけではありません。帯域を決まった幅に区切り、その1区切りを使って通信します。この区切りを「チャネル」と呼びます。

チャネルの幅は20 MHzが基本で、40・80・160 MHzと広げられます。Wi-Fi 7では、6 GHz帯で320 MHzまで広げられます。幅を2倍にすると、同じ時間に送れる量もおよそ2倍になります。ただし、広いチャネルほど、近所のWi-Fiとも重なりやすくなります。

2.4 GHz帯は全体で約80 MHzしかないので、20 MHz幅のチャネルを重ならずに置けるのは3〜4つです。近所のWi-Fiが多い場所では、同じチャネルを何台もの親機が使うことになります。

1つのチャネルの中も、さらに細かく分けて使います。チャネルを数十〜数千本の細い波に分け、それぞれに少しずつデータを乗せて同時に送ります。この方式をOFDMと呼びます。1本1本の波はゆっくり変わるので、壁で反射して遅れて届いた電波が混ざっても乱れにくくなります。

電波は順番に使う: 同時に話せるのは1台

同じチャネルの電波は、近くの機器みんなで分け合う1本の通り道です。2台が同時に電波を出すと、波が重なって、どちらも読み取れなくなります。そのため、1つのチャネルで一度に送るのは、基本的に1台だけです(後で触れる工夫を省いた単純化です)。

そこでWi-Fiの機器は、送る前に、誰かが電波を出していないかを確かめます。出していれば、終わるまで待ちます。空いたら、さらに機器ごとにばらばらな短い時間だけ待ってから送ります。みんなが同時に送り始めて、ぶつかるのを避けるためです。この手順をCSMA/CAと呼びます。

受け取った側は、届いたら短い確認の返事を返します。返事が来なければ、送った側は失われたとみなして送り直します。下りも上りも、この同じ通り道を交代で使います。

壁のせいで、機器どうしが互いの電波を聞けないこともあります。すると両方が「空いている」と思って送り、親機でぶつかります。これを隠れ端末問題と呼びます。

たとえで言うと

司会のいない会議で発言する場面に似ています。誰かが話している間は待ち、終わったら少し間をおいて話し始めます。2人が同時に話し始めたら、言い直します。似ているのは「1つの場所で話せるのは1人ずつで、空いたのを確かめてから話す」という点です。

たとえが当てはまらない点: 会議では全員の声が聞こえますが、Wi-Fiでは隠れ端末のように、互いの電波が届かない機器があります。また、Wi-Fiの機器は目配せで譲り合えず、それぞれがくじ引きのように待つ時間を決めます。

Wi-Fi 6のOFDMA: 1回の送信を何台かで分ける

1台ずつ順番に送るやり方では、小さなデータを送る機器が多いと、むだが出ます。送る前の確認や待ち時間は、毎回かかるからです。

そこでWi-Fi 6では、OFDMの細い波をいくつかの組に分けました。1回の送信の中で、組ごとに別々の機器に割り当てられます。これをOFDMAと呼びます。何台かへの小さなデータを、まとめて一度に送れます。

OFDMAが効くのは、チャットやゲームのように小さなデータを送る機器が多いときです。大きなファイルを受け取る1台が速くなるわけではありません。

MIMO: アンテナを増やして、同時に何本も送る

もう1つの工夫は、送る側と受ける側の両方に、アンテナを複数つけることです。部屋の電波は壁や家具で反射し、アンテナごとに少し違う道筋で届きます。受ける側はその違いを手がかりに、同時に送られた別々のデータを分けられます。この技術をMIMOと呼びます。

同時に送るデータの流れを、ストリームと呼びます。流れを2本にすれば、速さの上限はおよそ2倍です。ただし、流れの数は送る側と受ける側の少ない方で決まります。親機が4本でも、スマホが2本までなら2本です。

世代の違い: Wi-Fi 4からWi-Fi 7まで

「802.11ax」のような名前はわかりにくいので、2018年にWi-Fi Allianceが世代の番号をつけました。主な世代は次のとおりです。

呼び名規格の名前主な変化規格上の最大
Wi-Fi 4802.11n(2009年)MIMO、40 MHz幅600 Mbps
Wi-Fi 5802.11ac(2013年)5 GHz帯で160 MHz幅、256通り約6.9 Gbps
Wi-Fi 6802.11ax(2021年)OFDMA、1024通り約9.6 Gbps
Wi-Fi 6E802.11ax6 GHz帯を追加約9.6 Gbps
Wi-Fi 7802.11be(2024年)320 MHz幅、4096通り、複数の帯域を同時に約23 Gbps

表の「何通り」は、1回の区切りで使う波の形の数です。「規格上の最大」は、いちばん広いチャネル・細かい形・流れ8本(Wi-Fi 4は4本)をそろえた計算上の値です。Wi-Fi 7なら、流れ1本で約2.9 Gbps、8本で約23 Gbpsです。

Wi-Fi 7を「最大46 Gbps」とする記事や広告もあります。これは、開発の途中で検討された「流れ16本」を前提にした値です。最終的な規格では、流れは8本までになりました。

「複数の帯域を同時に」は、5 GHzと6 GHzなどに同時につながり、空いた方や両方を使うしくみです。日本では2023年12月に国の基準が改められ、320 MHz幅が使えるようになりました。

安全に使う: 暗号化とWPA3

電波は壁の外にも届くので、近くにいる人は、その気になればWi-Fiの電波を受け取れます。そこでWi-Fiでは、鍵がないと読めない形にデータを変えて送ります。これを暗号化と呼びます。

現在の主な方式は、WPA2と、2018年に始まったWPA3です。家庭用のWPA2では、つなぎ始めのやり取りを録られると、持ち帰ってパスワードを次々に試されるおそれがあります。WPA3では、1つ試すたびに親機とのやり取りが要るので、この攻撃を防げます。それでも、推測しやすいパスワードが危ないことは変わりません。

もっと古いWEPは短時間で解読する方法が知られており、総務省も使わないよう呼びかけています。家のルータの設定が古い方式なら、WPA2かWPA3に変えましょう。

駅やカフェの公衆Wi-Fiには、暗号化されていないものや、パスワードが貼り出されているものがあります。本物に似た名前の偽のWi-Fiも報告されています。総務省の利用者向けの手引きは、接続先と、HTTPSの通信かをよく確かめるよう勧めています。HTTPSなら、Wi-Fiとは別に、ブラウザとサーバの間で中身が守られます(「HTTPSとは?」)。

しくみから考える、家のWi-Fiのコツ

  • 置き場所: 電波は壁や床で弱まるので、親機は家の中心に近い、棚の上などに置きます。家の隅や床の上、金属の棚の中は不利です。
  • 帯域: 親機の近くなら5 GHz帯や6 GHz帯、壁を何枚も隔てた部屋なら2.4 GHz帯が向くことがあります。電子レンジの使用中に遅くなるなら、2.4 GHz帯をやめるのも手です。
  • 動かない機器は有線に: テレビなどをケーブルでつなぐと、電波の順番待ちが減り、ほかの機器も速くなることがあります。
  • 中継とメッシュ: 受けた電波を同じチャネルで送り直す中継機は、通り道を2回使うので、速さが半分ほどに落ちることがあります。

複数の親機が連携して家全体を覆うしくみを、メッシュWi-Fiと呼びます。親機どうしを専用の帯域やケーブルでつなぐ製品なら、この落ち込みを減らせます。2台目は、1台目の電波がまだ十分に強い中間あたりに置くのが目安です。

よくある誤解

誤解: 箱に書かれた速度が、そのまま出る

実際は、箱の数字は、電波で0と1を送る速さの上限です。送る間には確認の返事や待ち時間があり、データには宛先などの付け足しもつきます。そのため、運べる中身の量(スループット)は、かなり小さくなります。

また、箱の数字は最良の条件の値です。例えばWi-Fi 6の「2,402 Mbps」は、160 MHz幅で流れ2本の値です。80 MHz幅でつなげば、上限は半分の約1,200 Mbpsです。離れれば形は粗くなり、近くの機器とは時間を分け合います。その先の光回線より速くもなりません。

誤解: 5 GHz帯は、2.4 GHz帯よりいつも速い

実際は、親機の近くでは5 GHz帯が速いことが多いものの、壁を何枚も隔てると弱まって、粗い形しか使えなくなります。その場合は、2.4 GHz帯のほうが速いこともあります。どちらが良いかは、距離・障害物・混み具合で決まります。

誤解: Wi-Fiの表示が満タンなら、ネットも速いはず

実際は、扇形の表示は、親機から届く電波の強さを表すだけです。同じチャネルが混んでいれば待たされますし、その先の回線や相手のサーバが混んでいても遅くなります。Wi-Fiはインターネットそのものではなく、ルータまでの区間です。
