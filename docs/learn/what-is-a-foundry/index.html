ファウンドリとは? 半導体の受託製造と分業のしくみ

約12分 · 更新: 2026年10月23日

ファウンドリは、ほかの会社が設計した半導体チップを、注文を受けて製造する会社です。最先端の工場はとても高価で、多くの会社にとって、自社の製品だけで費用を回収するのは難しくなりました。そこで「設計する会社」と「作る会社」の分業が広がりました。代表は台湾のTSMCで、日本のラピダスもこの形をめざしています。

この記事でわかること

  • 半導体の会社の4つの形(ファブレス・ファウンドリ・IDM・OSAT)
  • チップの設計と製造が、別々の会社に分かれた理由
  • ファウンドリが実際に売っているもの
  • 主なファウンドリの会社と、それぞれの立ち位置
  • ニュースに出るシェアや「◯nm」の数字の読み方

前提知識: チップ(集積回路)が「小さな部品と配線を、1つのシリコンのかけらにまとめた電子回路」だと知っていると読みやすくなります。くわしくは「集積回路(IC)とは?」で説明しています。

身近なところでは: ニュースのTSMCとラピダス

「TSMCの熊本の工場が量産を始めた」「ラピダスが北海道で2nmの試作をした」。こうしたニュースで、ファウンドリという言葉を見かけます。どちらも、ほかの会社のチップを作る会社です。

身近な例はスマホです。iPhoneのチップは、Appleが自分で設計しています。でも、Appleはチップを作る工場を持っていません。Appleは2025年8月の発表で、自社がTSMCのアリゾナ州の工場の「最大の顧客」だと述べています。

つまり、チップの設計図を描く会社と、実際に作る会社が別々なのです。この記事では、なぜそうなったのか、作る側の会社は何を売っているのかを順に見ていきます。

チップができるまでの3つの仕事

チップができるまでの仕事は、大きく3つに分けられます。1つ目は設計です。どんな働きの回路にするかを決め、コンピュータの上で設計図を作ります。

2つ目は前工程です。シリコンの円い板(ウエハ)の上に、設計図どおりの回路を作り込みます。光で模様を写し、膜をつけ、削る作業を何十回もくり返します。いちばん大がかりな設備が要る段階です。

3つ目は後工程です。ウエハを1個ずつのチップに切り分け、外とつなぐ端子のついた包み(パッケージ)に入れ、検査します。工場の中の流れは「半導体チップはどうやって作られる?」でくわしく説明しています。

半導体の会社の4つの形

半導体の工場のことを、業界では「ファブ」と呼びます。英語で製造を意味するfabricationを縮めた言葉です。これを知っておくと、会社の形の名前がわかりやすくなります。

設計と販売だけを行い、工場を持たない会社をファブレスと呼びます。「ファブがない」という意味です。NVIDIAやクアルコムが代表例で、自社の名前でチップを売ります。

反対に、他社の設計図を受け取って、前工程の製造を引き受ける会社がファウンドリです。英語のfoundryは、もとは金属を溶かして型に流す「鋳物工場」のことです。ファウンドリは、自分の製品を売るのではなく「作る」という仕事を売ります。

設計から製造、販売までを1社で行う会社はIDMと呼びます。日本語では「垂直統合型」と言い、設計から製造・販売までの流れを1社でまとめるという意味です。インテルや、メモリを作るサムスン電子などが代表です。

後工程の組み立てと検査を引き受ける会社はOSATと呼びます。ファウンドリが作ったウエハを、OSATがチップに仕上げる、という分担がよくあります。

ただし、1社が1つの形だけとは限りません。サムスン電子は、自社のメモリを作るIDMであると同時に、他社のチップを作るファウンドリの事業も行っています。

なぜ設計と製造が分かれたのか

昔は、チップを作る会社の多くが、自分で設計して自分の工場で作っていました。つまり、IDMがふつうでした。分業が広がった大きな理由は、工場がとても高くなったことです。

工場は、建てたあと休ませずに動かすほど得をします。工場の能力のうち、実際に使っている割合を「稼働率」と呼びます。1社の製品だけで工場を使うと、売れ行きが落ちたときに稼働率が下がり、高い設備が遊んでしまいます。

ファウンドリは、多くの会社から注文を集めて工場を埋めます。ある会社の注文が減っても、ほかの会社の注文で穴を埋めやすくなります。こうして、巨額の設備の費用を、多くの顧客で分け合う形になります。

この形の先がけが、1987年に台湾で生まれたTSMCです。同社は「顧客の製品の製造だけに専念する事業の形を切り開いた」と説明しています。自社ブランドのチップを設計・販売しないので、顧客と競争しません。顧客は安心して設計図を預けられます。

製造を任せられる相手ができたことで、工場を持たない会社でも、最先端のチップを作れるようになりました。こうして、設計の力で勝負するファブレスが大きく育ちました。

ファウンドリは何を売っているのか

ファウンドリが顧客に売っているものは、大きく3つにまとめられます。ここでは話を簡単にするため、前工程の製造を中心に説明します。

1. 製造技術(プロセス)

どんな材料と手順で、どのくらい細かい回路を作るか。この作り方の一式を「プロセス」と呼びます。最先端の世代だけでなく、電力を抑えたもの、高い電圧に強いもの、センサー向けのものなど、用途ごとに種類があります。TSMCは2025年に、305種類の製造技術を使い、534社の顧客の12,682種類の製品を作ったと公表しています。

2. 生産能力

決まった時期に、決まった量を作れること。これも大事な商品です。生産能力は、1か月や1年にウエハを何枚処理できるかで表します。人気のある世代では工場の枠が埋まるので、顧客は早めに枠を押さえようとします。

3. 設計のための道具と支援

設計する会社は、そのファウンドリの作り方に合わせて設計図を描く必要があります。線の細さやすき間の最小値などの決まりと、トランジスタの性質をコンピュータでまねするためのデータが必要です。ファウンドリは、これらを一式にまとめて渡します。これをPDK(プロセス・デザイン・キット)と呼びます。

PDKの決まりを守った設計図なら、その工場で作れて、予測どおりに動くことが期待できます。さらにファウンドリは、設計ソフトの会社や、よく使う回路の設計データを売る会社とも組みます。TSMCは2008年から、こうした協力の枠組みを「OIP」という名前で運営しています。

逆に言うと、設計図は特定のファウンドリの作り方に結びつきます。別のファウンドリに移るには、多くの場合、設計の手直しが必要です。顧客が簡単に乗り換えられない理由の1つです。

たとえで言うと

ファウンドリは、本の印刷所に少し似ています。出版社は本の中身を作り、高価な印刷機を持つ印刷所に刷ってもらいます。印刷所は多くの出版社の仕事を受けるので、機械を休ませずに使えます。似ているのは「中身を作る会社と、高い設備で作る会社が分かれ、設備を多くの客で分け合う」という一点です。

たとえが当てはまらない点: 印刷所は、原稿をほぼそのまま紙に写します。ファウンドリでは、作り方そのものがチップの性能を大きく左右し、設計図もその作り方に合わせて描かれます。また、チップの製造は一度刷れば終わりではありません。前工程だけでも、作業を何十回もくり返し、数週間から数か月かかります。

なぜ最先端の工場は高いのか

最先端の工場が高い理由の1つは、いちばん細かい模様を描く装置がとても高価で、何台も必要なことです。代表が、波長13.5nmの光を使うEUV露光の装置です。ほかにも、ほこりを極端に減らした部屋や、膜をつける・削る・測るための多くの装置が要ります。

金額の例を見てみましょう。TSMCが2025年に工場や装置に使ったお金(設備投資)は409億ドルでした。2024年の298億ドルから、さらに増えています(同社の決算説明会による)。1ドル=150円で計算すると、2025年の分は約6兆円です。

TSMCは2025年3月、アメリカへの投資を合計1,650億ドルに広げる計画を発表しました。工場6つと、先端のパッケージの工場2つ、研究開発の拠点を含む計画です。これは計画の金額で、すでに使い終わった金額ではない点に注意しましょう。

これほどの費用を回収できる会社は、限られています。アメリカのGlobalFoundriesは2018年、最先端だった7nm世代の開発を無期限で止めると発表しました。最先端を必要とする顧客が少なく、投資に見合わないと判断したためです(IEEE Spectrum、2018年)。その後は、通信用などの特色のある製造技術に力を入れています。

主なファウンドリの会社

主な会社を、立ち位置とともにまとめます。シェアのような数字はすぐ変わるので、表には変わりにくい特徴だけを書きました。

日本では、TSMCが熊本県に子会社JASMをつくりました。第1工場は2024年末に量産を始めています(TSMCの年次報告による)。ソニーグループの半導体の会社、デンソー、トヨタ自動車も出資しています。

第1工場が作るのは、最先端より前の世代(12〜28nm)のチップです。車や産業機器、家電などに使うチップの多くは、実績があり安く作れる前の世代で作られます。最先端の競争だけが、ファウンドリの仕事ではないのです。なお、建設中の第2工場では、より新しい3nm世代を作る計画が2026年に示されました。

ファウンドリのニュースの読み方

シェアの数字: だれが、いつ、何を数えたか

「TSMCのシェアが7割を超えた」といったニュースでよく引用されるのが、台湾の調査会社TrendForceの集計です。TrendForceによると、2026年4〜6月期のファウンドリの売上のシェアは次のとおりです。TSMCが72.5%、サムスン電子が5.9%、SMICが5.4%でした。

この数字は、3か月ごとの売上から計算しています。調査会社によって、どの会社のどの売上を数えるかが違います。そのため、別の調査会社の数字とはそのまま比べられません。見出しの数字を見たら、出どころと期間を確かめましょう。

「◯nm」は世代の名前

「2nmの量産」などの数字は、製造技術の世代につけた名前です。チップのどこかが2nmという意味ではありません。会社が違うと、同じ数字でも中身はそろっていません。くわしくは「「2nm」「3nm」は何の長さ?」で説明しています。

計画・試作・量産の違い

工場のニュースでは、どの段階の話かに注目しましょう。「計画」や「投資の表明」は、まだお金を使い終わっていない段階です。「試作」は少しだけ作って確かめる段階、「量産」は製品として大量に作る段階です。同じ工場の話でも、段階によって意味が大きく変わります。

よくある誤解

誤解: ファウンドリは、言われたとおりに作るだけの下請け

実際は、作り方(プロセス)そのものを開発して提供する会社です。どこまで細かく、どれだけ少ない電力で動くチップを作れるかは、ファウンドリの技術に大きく左右されます。設計する会社は、その技術を前提に設計します。「受託製造」という言葉から、技術を持つのは注文する側だけだと思われやすいのが、誤解の理由です。

誤解: 工場を持たないファブレスは、本当の半導体メーカーではない

実際は、チップの働きや性能を決める設計を行い、自社の名前で製品を売る半導体の会社です。たとえばNVIDIAは工場を持ちませんが、AI向けのチップで世界の主要な会社です。「メーカー=自分の工場で作る会社」というイメージから生まれる誤解です。

誤解: 「TSMCのシェア7割」は、世界の半導体の7割をTSMCが作っているという意味

実際は、ファウンドリという市場の中での、売上の割合です。メモリのように、IDMが自社の工場で作って売る半導体は、この数字に入りません。また、個数ではなく売上で数えるので、高価な最先端のチップを多く作る会社ほど大きく出ます。

もっと詳しく学ぶ

  • 会社の形を表で比べる: 「IDM・ファブレス・ファウンドリの違い」で、強みと弱み、代表的な会社を整理しています。
  • 前工程と後工程の違い: 「半導体の前工程と後工程の違い」と、「半導体チップはどうやって作られる?」で読めます。
  • 設計図ができるまで: 「集積回路(IC)とは?」で、設計の流れと、設計データを製造側に渡すテープアウトを説明しています。
  • 試作の費用を分け合うしくみ: 複数の会社の設計を1枚のウエハに相乗りさせるMPW。
  • ニュースに出る会社と言葉: ファウンドリ、ラピダス、好況と不況をくり返すシリコンサイクルの意味は用語集で。
  • 小さくする以外の進め方: 「微細化の先へ」で、チップを重ねる技術などをまとめて読めます。
