拡散とは? 不純物が広がるしくみと√(Dt)の意味

約13分 · 更新: 2026年10月23日

拡散は、原子や分子がでたらめに動いた結果、物が濃いところから薄いところへ広がる現象です。広がる距離の目安は√(Dt)(Dは広がりやすさ、tは時間)で、時間を2倍にしても約1.4倍にしか伸びません。シリコンに入れた不純物も高温の工程のたびに広がるので、チップ作りでは、どの温度に何秒さらすかを細かく管理しています。

この記事でわかること

  • 不純物の広がりが、チップ作りで問題になる理由
  • でたらめな動きから「濃い → 薄い」の流れが生まれるしくみ
  • 広がる距離が時間の平方根で伸びる理由と、計算例
  • 拡散の速さが温度で桁違いに変わる理由
  • 先端のチップで、ごく短い時間だけ加熱する理由
  • 熱や電子、配線の遅れにも、同じ考え方が出てくること

前提知識: 「半導体とは?」で説明している、n型・p型のおおまかな意味。

身近なところでは

固めた寒天に色水を1滴たらし、そっと置いておくと、色は何日もかけて少しずつ周りへにじみます。かき混ぜなくても、色の粒が自分で広がっていくのです。このように、粒のでたらめな動きで物が広がる現象を、拡散と呼びます。

水の中では、流れ(対流)でずっと速く混ざってしまいます。寒天の中なら、拡散だけを見られます。

チップの中でも、同じことが起きています。シリコンには、電気の性質を決めるために、ホウ素やリンといった不純物をごく少量入れます。入れた不純物は、1000 ℃前後の高温の工程を通るたびに、少しずつ周りへ広がります。

トランジスタは、n型とp型の部分を、ナノメートル(nm、10億分の1メートル)の単位で並べて作ります。不純物が広がりすぎると、境目の位置がずれて、設計どおりに動きません。そのため工場では、不純物がどれだけ広がるかを見積もって、温度と時間を決めています。

技術の側から: 不純物の入れ方と「熱」

シリコンに不純物を入れることを、ドーピングと呼びます。1950年代に広まったのは、拡散そのものを使う方法でした。不純物を含むガスの中でシリコンを高温に熱すると、不純物が表面から中へしみ込みます。この方法を熱拡散と呼びます。

熱拡散は、1950年代の前半に米国のベル研究所で開発されました。温度と時間で入る深さを調節でき、1954年にはトランジスタや、ホウ素を拡散させたシリコンの太陽電池に使われています。

その後、多くの工程はイオン注入に置き換わりました。不純物の原子を電気の力で加速し、弾丸のようにシリコンへ打ち込む方法です。入れる量を電流で数えられ、深さも加速の強さで決まるので、熱拡散よりずっと正確です。置き換えは1970年代から進みました。

ただし、打ち込んだだけでは使えません。打ち込まれた原子の多くは結晶の決まった位置に収まっておらず、電気の運び手を生み出せません。結晶も傷つきます。

そこで、もう一度熱を加えて傷を直し、不純物を結晶の位置に収めます。この熱処理をアニール、運び手を生み出せる状態にすることを「活性化」と呼びます。

困るのは、アニールの高温でも不純物が拡散することです。その後も、膜をつける、酸化するなど、高温の工程が続きます。入れ方が変わっても、拡散は「避けられない副作用」として残ったのです。なお熱拡散も、深い領域を作る工程や太陽電池などで、いまも使われています(熱拡散とイオン注入の違い)。

しくみ1: でたらめな動きから「流れ」が生まれる

高温のシリコンの中で、不純物の原子は、結晶の中の隣の場所へときどき跳び移ります。どちらへ跳ぶかはまったくの偶然で、右へも左へも同じ確率です。原子が「薄いほうへ行こう」としているわけではありません。

それでも全体としては、濃いところから薄いところへ流れが生まれます。隣り合う2つの区画を考えます。左に8個、右に2個の原子があり、どの原子も半分の確率で隣の区画へ跳ぶとします。

左から右へ跳ぶのは平均4個、右から左へ跳ぶのは平均1個です。差し引き3個が、左から右へ移ります。1個1個はでたらめでも、数の多い側から出ていく原子のほうが多いので、差し引きの流れは濃い側から薄い側へ向きます。

この差し引きの流れは、濃さの差が急なほど大きくなります。「流れの大きさは、濃さの傾きに比例する」という関係を、フィックの第1法則と呼びます。1855年に、ドイツ生まれの生理学者フィックが発表しました。

このときの比例の係数を、拡散係数(D)と呼びます。原子の跳びやすさを表す数で、大きいほど速く広がります。単位はcm²/s(面積を秒で割ったもの)で、その理由は次の節でわかります。

濃さがどこでも同じになると、左右へ跳ぶ数がつり合い、差し引きの流れは0になります。このときも、原子1個1個は跳び続けています。止まったのは、差し引きの流れだけです。

たとえで言うと

箱を仕切り板で2つに分け、板の一部にすき間をあけます。左側にだけビーズをたくさん入れて、箱を小刻みに揺すり続けます。ビーズはどちらへ転がるかでたらめですが、やがて右側にも広がり、左右がほぼ同じ数になります。1個1個は行き先を選んでいないのに、全体では「多いほうから少ないほうへ」移る点が、拡散と似ています。

たとえが当てはまらない点: ビーズは、揺すり方の向きや重さの影響を受けますが、原子はどの向きにも同じ確率で跳びます。また原子が跳ぶ回数は、温度で桁違いに変わります(しくみ3)。このたとえが表すのは、でたらめな動きから差し引きの流れが生まれる、という点だけです。

しくみ2: 広がる距離は√(Dt)

では、不純物はどれくらいの距離を広がるのでしょうか。1個の原子に注目すると、右へ左へとでたらめに跳ぶので、行っては戻るを繰り返します。そのため、跳んだ回数のわりに、元の場所からはあまり離れません。

確率の計算によると、元の場所からの離れ方の目安は、跳んだ回数の平方根に比例します。平方根は、2回掛けるとその数になる数で、√と書きます(√100 = 10)。100回跳んでも、離れるのはおよそ10回分です。跳ぶ回数は時間に比例するので、広がる距離は時間の平方根に比例します。

これを式で書くと、広がる距離の目安は√(D × t)です(tは時間)。Dの単位はcm²/sなので、秒を掛けるとcm²、平方根をとるとcmという長さになります。

平方根の性質から、時間を2倍にしても、距離は√2倍、約1.4倍にしかなりません。4倍の時間でようやく2倍、100倍で10倍です。最初のうちに大きく広がり、その後の伸びはゆっくりになります。

この記事では、係数をつけない√(Dt)を「広がりの目安」とし、数字はすべてこれで計算します。実際の分布はなだらかに裾を引くので、どこまでを「広がった」とみなすかで係数が変わります。教科書では2√(Dt)を使うことも多くあります。

数字で見る: 1000 ℃で1時間熱すると

1000 ℃のシリコンの中の拡散係数は、ホウ素が約1.5×10⁻¹⁴ cm²/s、リンが約1.3×10⁻¹⁴ cm²/sです。教科書でよく使われる値から計算したもので、測定によって数割の違いがあります。

ホウ素を1000 ℃で1時間(3600秒)熱した場合を計算します。

  1. D × t = 1.5×10⁻¹⁴ × 3600 ≈ 5.4×10⁻¹¹ cm²
  2. 平方根をとると、約7.4×10⁻⁶ cm
  3. ナノメートルに直すと、約74 nm
1000 ℃で熱した時間広がりの目安 √(Dt)
30分約50 nm
1時間約74 nm
2時間約105 nm(1時間の約1.4倍)
4時間約150 nm(1時間の2倍)

74 nmは、髪の毛の太さ(約0.08 mm)の1000分の1ほどですが、先端のトランジスタには大きな距離です。IBMが2021年に発表した「2nm」の試作では、ゲートの長さは12 nmでした。炉で1時間熱するだけで、その数倍の距離を広がってしまいます。

しくみ3: 拡散係数は温度で桁違いに変わる

原子が隣の場所へ跳ぶには、近くに結晶の欠陥(原子が抜けた穴や、すき間に入り込んだ原子)があり、しかもエネルギーの「山」を越える必要があります。欠陥の数も、山を越えられる原子の割合も、温度が上がると急に増えます。そのため拡散係数は、温度に対して指数関数的に、つまり桁で変わります。

この関係を表すのが、アレニウスの式です(「アレニウスの式とは?」)。山の高さに当たる活性化エネルギーは、ホウ素で約3.5 eV、リンで約3.7 eVです(eVはエネルギーの単位)。

この高さだと、1000 ℃を1100 ℃に上げるだけで、拡散係数は約10倍になります。900 ℃から1000 ℃では、15〜17倍です。同じ時間なら、広がる距離は√10倍、約3倍になります。温度の100 ℃の差が、時間の約10倍の差と同じ効き目をもつわけです。

逆に室温では、ホウ素やリンは事実上まったく動きません。式をそのまま25 ℃に当てはめると、ホウ素の拡散係数は10⁻⁵⁹ cm²/sほどです。10年たっても、跳び移る原子はまず出てきません。使っているうちに不純物が広がってチップが壊れる、という心配はないのです。

しくみ4: 不純物の分布の2つの形

熱拡散で不純物を入れるとき、教科書では2つの典型的な場合を考えます。どちらも、分布の広がりは√(Dt)を物差しにして決まります。

1つ目は、表面の濃さを一定に保ったまま熱する場合です。表面にいつも不純物が補給されるので、入る量は時間とともに増え続けます。分布は表面がいちばん濃く、奥へ行くほどなめらかに薄くなります。この形を、数学の関数の名前から補誤差関数(erfc)の形と呼びます。

2つ目は、決まった量を入れてから、補給なしで熱する場合です。総量は変わらないので、時間とともに山が低く、幅が広くなります。形は「つりがね型」(ガウス分布)の半分です。

昔の熱拡散では、この2つを順に使いました。まず表面を一定の濃さに保って短く熱し、決まった量を浅く入れます。次に補給を止めて熱し、奥へ押し込みます。この工程をドライブインと呼びます。量と深さを別々に決められるのが利点です。

接合の深さ

n型のシリコンにホウ素を入れてp型の層を作るとき、ホウ素がもとからあるリンより濃いところはp型、薄いところはn型のままです。2つの濃さが等しくなる位置がp型とn型の境目(PN接合)で、表面からそこまでの距離を接合の深さと呼びます。

熱を加えるほど分布が奥へ伸び、接合も深くなります。表面の濃さを一定に保つ場合、接合の深さは√(Dt)に比例します。決まった量の場合は、山が低くなる分、それよりややゆっくり深くなります。

効くところ: サーマルバジェットと短時間のアニール

拡散は、高温の工程のたびに積み重なります。拡散係数が一定とみなせる範囲では、工程ごとの「拡散係数 × 時間」の合計が、全体の広がりを決めます。ウエハが受ける熱の合計を、サーマルバジェット(熱の予算)と呼びます。

拡散係数は温度に敏感なので、合計の大部分はいちばん高温の工程が占めます。1100 ℃での1分は、1000 ℃での約10分にあたります。高温にいる時間をいかに短くするかが勝負です。

ここで板挟みになるのが、アニールです。活性化と傷の修復には高い温度が要りますが、高温に長くいると不純物が広がります。これを解いたのが、高温にいる時間をうんと短くする方法です。

昔は多くのウエハを炉に入れ、数十分かけて熱しました。これを、ランプの光で1枚ずつ数秒で熱するようにしたのが、急速熱処理です(炉・RTA・レーザーアニールの違い)。

さらに、最高温度に着いたらすぐ冷やすのがスパイクアニールで、最高温度の近くにいるのは1秒前後です。その先に、強い光を一瞬当てるフラッシュランプアニールやレーザーアニールがあり、表面を1ミリ秒前後、方式によってはもっと短く熱します。

1050 ℃にいる時間ホウ素の広がりの目安
30分(炉)約95 nm
1秒約2 nm
1ミリ秒約0.07 nm

表は温度をそろえ、時間だけを比べた計算です。実際の短時間のアニールは、もっと高い温度まで上げて活性化を高めますが、高温の時間が短いので、広がりは炉よりずっと小さく抑えられます。

ただし実際には、注入で傷ついた結晶のせいで、アニールの初めに拡散が一時的に速くなります(過渡増速拡散(TED))。この記事の計算は、こうした効果を省いた基本の形です。

同じ考え方が出てくる場所

熱の広がり

熱も、温度の高いところから低いところへ、拡散と同じ形の式で広がります。濃さの代わりに温度が、拡散係数の代わりに「熱拡散率」が出てきます。シリコンの熱拡散率は室温で約0.8 cm²/sで、1000 ℃のホウ素の拡散係数の約50兆倍です。

√(Dt)で計算すると、熱が1ミリ秒で広がるのは約0.3 mmで、高温ではさらに浅くなります。ミリ秒のアニールで、厚さ約0.78 mmのウエハの表側だけが熱くなるのは、このためです(接合温度の計算ツール)。

PN接合の電子と正孔

p型とn型の境目では、電子はn型からp型の側へ、正孔(電子が抜けた穴)はp型からn型の側へ拡散し、拡散電流が流れます。すると境目に、動ける運び手のいない層が残り、そこにできる電気の力が、それ以上の拡散を押しとどめます(PN接合の空乏層の図解)。

シリコンの中の電子の拡散係数は、室温で最大約36 cm²/sで、1ナノ秒で約2 µm広がる速さです。電子が消えるまでの平均の時間をtにした√(Dt)を、拡散長と呼びます。太陽電池やカメラのセンサの感度を左右する長さです。

長い配線の遅れ

チップの長い配線は、抵抗と、電気をためる部分(容量)が、全長にわたって細かく並んだものと見なせます。このような配線では、電圧の伝わり方が拡散と同じ形の式になります。

距離が時間の平方根で伸びることを裏返すと、かかる時間は距離の2乗で増えます。そのため、配線そのものの抵抗と容量で決まる遅れは、長さを2倍にすると約4倍になります。実際のチップでは、長い配線の途中に中継の回路を入れて、この増え方を抑えます(配線のRC遅延の計算ツール)。

よくある誤解

誤解: 広がる距離は、時間に比例する

実際は、時間の平方根に比例します。時間を2倍にしても約1.4倍、100倍にしても10倍です。一定の速さで進む車のような動きを思い浮かべると、比例すると考えがちです。拡散する原子は行っては戻るを繰り返すので、時間のわりに進みません。

誤解: 原子は、濃いところから薄いところへ向かって動く

実際は、1個1個の原子はでたらめな向きに跳んでいて、薄い側から濃い側へ戻る原子もいます。濃い側から薄い側へ向かうのは、差し引きの流れだけです。なお実際のシリコンでは、電気の力や結晶のひずみなども、流れの向きや速さを変えます。

誤解: ドーピングは、温度が高いほどうまくいく

実際は、温度を100 ℃上げると拡散係数が約10倍になり、接合が深くなりすぎたり、横へ広がりすぎたりします。先に入れた不純物まで一緒に広がります。結晶に溶け込める量(固溶度)も、温度とともにいつまでも増えるわけではありません。必要なのは、高い温度と、ごく短い時間の組み合わせです。
