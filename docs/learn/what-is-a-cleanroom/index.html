クリーンルームとは? 半導体工場がほこりを嫌う理由

約13分 · 更新: 2026年10月23日

クリーンルームは、空気中の目に見えない粒(ほこり)を極端に減らした部屋です。チップの回路はとても細かく、小さな粒が1つ乗るだけで不良になることがあります。そのため、ウエハに回路を作る工程はこの部屋で行います。フィルターでこした空気を天井から床へ流し続け、人や薬品から出る汚れも管理しています。

この記事でわかること

  • 小さな粒1つが、なぜ大きな損になるのか
  • 「ISOクラス5」「クラス100」など、きれいさの段階の読み方
  • フィルター・空気の流れ・気圧で、部屋をきれいに保つしくみ
  • いちばんの汚れの元が人である理由と、全身を覆う服
  • ウエハを密閉した容器に入れ、部屋全体の負担を減らす工夫
  • 粒以外の汚れ(金属・ガス・静電気)と、温度・揺れ・電気の使用量

前提知識: とくになし。チップは「ウエハという円い板の上で、膜をつけ、模様を写し、削る作業をくり返して作る」と知っていると読みやすくなります。全体の流れは「半導体チップはどうやって作られる?」で説明しています。

身近なところでは

半導体の工場の建設のニュースでは、白い服で全身を覆った人の写真がよく使われます。頭から足まで覆い、マスクと手袋をつけ、目の周りだけが見えています。背景の部屋が、黄色い光に照らされていることもあります。この部屋がクリーンルームです。

黄色い光の部屋は、回路の模様を光で写す工程の場所です。模様を写すときに塗る薬剤は、青い光や紫外線に反応します。そこで照明から青い光と紫外線を除いているので、部屋が黄色く見えます。

この記事では、クリーンルームがどれくらいきれいか、どうやってきれいに保つか、なぜそこまでするのかを順に見ていきます。

なぜ小さな粒1つが問題になるのか

今のチップの細い配線は、髪の毛の太さ(約0.09 mm)の1,000分の1よりも細くなっています。ここに粒が1つ乗ると、となりの配線どうしがつながったり、配線が途中で切れたりします。チップを不良にしてしまう、こうした欠陥をキラー欠陥と呼びます。

粒は、どのチップの上に落ちるかを選びません。1枚のウエハには数百〜数千個のチップが並ぶので、落ちる粒が多いほど、不良のチップも増えます。しかもチップは、模様を写す作業を100回以上くり返して作ります。1回ごとに粒が落ちる機会があるので、小さな確率でも積み重なります。

作ったチップのうち良品の割合を歩留まりと呼びます。ウエハ1枚を加工する費用は、良品が何個取れても大きくは変わりません。例えば良品が9割から8割に減ると、良品1個あたりの費用は約1.1倍になります(0.9÷0.8の計算)。チップの大きさや粒の多さで良品がどう変わるかは、ダイ数・歩留まり計算ツールで試せます。

どれくらいきれい? クリーンルームの「クラス」

きれいさは、空気中の粒を数えて表します。国際規格のISO 14644-1は、空気のきれいさを1〜9の「クラス」に分けています。決まった量の空気に、決まった大きさ以上の粒がいくつまであってよいかで決めます。数字が小さいほどきれいです。

粒の大きさには、µm(マイクロメートル)という単位を使います。1 µmは1,000分の1 mmで、1,000 nmです。空気の量は1 m³、つまり1辺が1 mの立方体の分です。

決め方の基本は単純です。0.1 µm以上の粒の上限は、クラス1で10個、クラス2で100個です。クラスの数字が1つ大きくなるごとに、許される数が10倍になります。大きな粒ほど少なくしか許されず、クラス5では0.1 µm以上が10万個まで、0.5 µm以上は3,520個までです。

ケンタッキー大学の説明では、都市の外気は、多いとクラス9に当たる数の粒を含みます。0.5 µm以上の粒の上限で比べると、クラス9とクラス5の差は1万倍です。1リットルあたりに直すと、クラス9は約3万5,000個、クラス5は約3.5個になります。

現場やニュースでは、「クラス100」のような古い呼び方も残っています。これは2001年に廃止された米国の規格(連邦規格209E)の呼び方です。1立方フィート(約28リットル)の空気にある0.5 µm以上の粒の数を表します。クラス100は、ISOのクラス5にほぼ当たります。

しくみ1: フィルターで粒をこし取る

空気から粒を取り除くのは、天井に並べたフィルターです。ガラスなどのごく細い繊維を薄い紙のように重ね、ひだ状に折りたたんでいます。網の目より大きな粒をふるい分けるだけではありません。空気の流れに乗った粒が繊維にぶつかったり触れたりして、くっついて離れなくなります。

よく使われるHEPAフィルタは、0.3 µmの粒を99.97%以上とらえます(日本のJISや米国エネルギー省の基準)。1万個の粒のうち、通り抜けるのは3個以下という意味です。0.3 µmは、繊維で最もとらえにくい大きさに近い値です。それより大きな粒や、ずっと小さな粒は、もっとよくとらえられます。

さらに性能の高いものがULPAフィルタです。日本のJISの定義では、0.15 µmの粒を99.9995%以上とらえます。米国などの規格では、試す粒の大きさや割合が少し違います。通り抜けるのは、100万個に5個以下です。2つの違いは「HEPAフィルタとULPAフィルタの違い」で詳しく比べられます。

ただし、どちらのフィルターもとらえるのは粒だけです。においのもとのような、ガスの分子は通り抜けてしまいます。ガスへの対策は、あとの「粒だけではない汚れ」で説明します。

しくみ2: 空気を上から下へ流し続ける

フィルターを通したきれいな空気は、天井に並べたフィルターから、まっすぐ下へ向けて流します。この流し方をダウンフローと呼びます。人や装置から出た粒は、横へ広がる前に、床の方へ押し流されます。

床には穴のあいた板を並べ、その下に空間を作ってあります。空気は床の穴から床下へ抜け、壁ぎわの通路を通って天井裏へ戻ります。そして、またフィルターを通って部屋に入ります。外の空気を取り込むのは一部で、大部分は同じ空気をくり返しこして使います。

風の速さの目安は、秒速0.3〜0.5 mほどです。人がゆっくり歩くより遅い、そよ風です。それでも天井の高さを3 mとすると、空気は6〜10秒で天井から床まで流れます(計算による目安)。

もう1つの工夫は、部屋の気圧を周りより少しだけ高くしておくことです。こうすると、扉を開けたときやすき間では、空気が中から外へ流れます。外の汚れた空気が、部屋に入り込みにくくなります。

いちばんの汚れの元は「人」

クリーンルームの中で粒を出し続けるのは、人です。皮膚の表面は少しずつはがれ落ち、服からは繊維のくずが出ます。人が動くたびに、それが空気中に舞い上がります。

英国のWhyteらの研究(2007年)は、55人が出す粒を測りました。普段の服では、0.5 µm以上の粒が1分あたり平均で約210万個出ていました。この研究のクリーンルーム用の服を着ても、約100万個でした。数字は服や測り方で大きく変わりますが、服を着ても人から出る粒をゼロにはできないことがわかります。

そこで作業する人は、頭から足まで全身を覆う専用の服を着ます。帽子、マスク、手袋、専用の靴も身につけます。粒を出しにくい布で作った服で、人から出る粒を服の内側に閉じ込めるのが目的です。英語では「バニースーツ」とも呼ばれます。

服を着たあとは、強い風を全身に吹き付ける小部屋を通ってから入ります。これをエアシャワーと呼びます。服の表面についた粒を吹き飛ばし、部屋に持ち込む粒を減らすためです。部屋の中で急に動かないことも、粒を減らす大切な決まりです。

部屋全体より、ウエハの周りだけを守る

昔の工場は、部屋全体をとびきりきれいにして、ウエハを守っていました。しかし広い部屋全体の空気をこし続けるには、多くの費用と電気がかかります。人と同じ空気の中にウエハがある限り、人から出る粒も避けにくくなります。

そこで今の工場では、ウエハを密閉した容器に入れて運びます。直径300 mmのウエハを最大25枚入れられる容器で、FOUP(フープ)と呼びます。満載すると重いので、天井のレールを走る搬送車が、装置から装置へ自動で運びます。

装置の前面には、FOUPのふたを開けてウエハを取り出す小さな部屋があります。ここにもフィルターがあり、中の空気はとてもきれいに保たれています。このように、ウエハの周りの小さな空間だけを特にきれいに保つ考え方を、ミニエンバイロメントと呼びます。

ウエハは、人が働く部屋の空気に直接ふれません。そのため、部屋全体の基準はゆるめられるようになりました。日立評論(2007年)の解説も、同じ方向を示しています。きれいさはミニエンバイロメントの中を中心に高め、部屋全体は装置の保守に必要な程度にとどめます。そうして、費用と電気を減らします。

たとえで言うと

ミニエンバイロメントは、ほこりっぽい家で大切な宝石を守る方法に少し似ています。家じゅうを掃除し続けるより、宝石を密閉したケースに入れ、ケースを開けるのはきれいな小箱の中だけにします。似ているのは「守る範囲を小さくすれば、手間と費用を大きく減らせる」という一点です。

たとえが当てはまらない点: 宝石は一度しまえば終わりですが、ウエハは何度も装置に出し入れされます。そのたびにケースを開けるので、受け渡しの小部屋もきれいに保ち続けなければなりません。また、ケースの材料や処理を終えたウエハからガスが出て、中の空気を汚すことがあります。部屋も汚くてよいわけではなく、外の空気よりずっときれいに保たれています。

粒だけではない汚れ

クリーンルームが防ぐ汚れは、目に見えない粒だけではありません。代表的なものを3つ挙げます。

  • 金属: 人の汗や皮膚には、ナトリウムが含まれます。ナトリウムがトランジスタの絶縁の膜に入ると、膜の中を動き回り、トランジスタが電気を通し始める電圧を狂わせます。こうした動くイオンを可動イオンと呼び、厳しく管理します。
  • 空気中のガス: 模様を写す薬剤の一部は、光で生まれたわずかな酸を使って反応します。空気中のアンモニアがこの酸を打ち消すと、模様の形がくずれます。ガスによる、こうした汚れを分子状汚染と呼び、活性炭などを使う専用のフィルターで取り除きます。
  • 静電気: ものが静電気を帯びると、空気中の粒を引き寄せます。静電気が一気に流れると、チップの回路そのものを壊すこともあります(静電気放電)。そこで、床や作業台に電気が逃げる素材を使い、電気を打ち消す装置も置きます。

ウエハを洗う水も、普通の水ではいけません。金属やイオン、粒、有機物を極限まで取り除いた超純水を使います。純度は、電気の通しにくさ(比抵抗)で確かめます。水は自分自身がわずかにイオンに分かれるので、どれほど純粋でも通しにくさには上限があります。25 ℃では18.2 MΩ·cmです。超純水は、この上限にきわめて近い水です。ウエハの洗い方は、比較ページ「SC-1・SC-2・希フッ酸の違い」で見られます。

温度・湿度・揺れも管理する

物は温まると、わずかに伸びます。シリコンは1 ℃上がると、長さが100万分の2.6ほど伸びます。直径300 mmのウエハなら、約0.78 µm(780 nm)伸びる計算です。数十nmの模様をぴったり重ねる工程では、無視できない大きさです。そのため、特に模様を写す装置の周りでは、温度を一定に保ちます。

湿度も一定に保ちます。空気が乾きすぎると、静電気が起きやすくなるからです。湿気は、模様を写す薬剤の働き方にも影響します。

揺れも大敵です。模様を写す装置は、ナノメートルの精度で位置を合わせます。近くの機械や人の動きによるわずかな揺れでも、位置がずれるおそれがあります。工場は、揺れを伝えにくい丈夫な床や基礎の上に、装置を据えるように作られます。

きれいさを保つには、電気がいる

クリーンルームでは、大きなファンが昼も夜も空気を回し続けます。空気の温度と湿度も、一年中同じに保ちます。米国のローレンス・バークレー国立研究所の研究者は、2000年の報告で見積もりを示しています。クリーンルームや実験施設は、同じ広さの一般の商業ビルのおよそ4〜100倍のエネルギーを使います。

ミニエンバイロメントで部屋の基準をゆるめるのは、この電気と費用を減らすためでもあります。新しい工場のニュースで電気や水の確保が話題になるのは、こうした設備を休みなく動かし続けるからでもあります。

よくある誤解

誤解: 工場の中は、どこも同じようにとびきりきれい

実際は、場所によって求めるクラスが違います。今の工場では、最もきれいなのはFOUPや装置の中など、ウエハの周りの小さな空間です。人が働く部屋は、それよりゆるい基準で管理されます。ただし、ゆるいといっても外の空気よりはずっときれいです。工場の写真で、どこも同じ白い服と部屋に見えることから生まれやすい誤解です。

誤解: クリーンルームは、病院の手術室のような「無菌の部屋」

実際は、目的が違います。ISO 14644-1のクラスは粒の数だけで決まり、その粒が生きた菌かどうかは区別しません。手術室や薬の工場では、菌を減らすことが大きな目的です。半導体の工場が特に気にするのは、粒の数と、金属やガスなどの化学的な汚れです。「クリーン」を「清潔」と訳したときのイメージから生まれる誤解です。

誤解: 真っ白な服を着た人は、部屋の中でいちばんきれいなもの

実際は、人は部屋の中で最大の汚れの元です。専用の服は人を守るためというより、人から出る粒を閉じ込めるために着ます。服を着ていても、大きく動くほど粒は外へ漏れ出します。白くて清潔そうな見た目から生まれやすい誤解です。
