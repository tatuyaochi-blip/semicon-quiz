半導体の検査・テストとは? 不良チップを見つける工程と装置

約12分 · 更新: 2026年10月23日

半導体の検査・テストは、作ったチップから不良品を見つけ、出荷の前に取り除く作業です。作っている途中のウエハを「見て・測る」検査と、チップに電気を流して動きを確かめるテストがあります。不良は早く見つけるほど、むだになる費用が小さくて済みます。

この記事でわかること

  • 工程のどこで、何を調べているのか
  • ウエハテスト・最終テスト・バーンインの違いと、使う装置
  • 電気のテストで確かめる中身(機能・速さ・電力・漏れる電流)
  • 同じ設計のチップが、速さで別の型番に分かれることがある理由
  • テストしやすくする設計の考え方と、歩留まりの計算

前提知識: チップがウエハの上でまとめて作られ、切り分けて包まれることを知っていると読みやすくなります。くわしくは「半導体チップはどうやって作られる?」で説明しています。

身近なところでは

スマホやパソコンに入っているチップは、どれも出荷の前に何度もテストに合格したものです。スマホのプロセッサには何十億個もの小さなスイッチがあり、目で見ても良し悪しはわかりません。そこで、電気の信号を入れて、正しい答えが返ってくるかを機械で確かめます。

半導体の会社に入ると、「テスト工程」「歩留まり」「ビン」といった言葉をよく耳にします。工場の人だけでなく、営業や調達の人も、値段や納期の話で使う言葉です。この記事では、こうした言葉の意味を工程の順に見ていきます。

全体の流れ: 「見る検査」と「電気のテスト」

不良を見つける作業は、大きく2種類に分けられます。1つは、作っている途中のウエハを光や電子の顕微鏡で見て、ごみや形のずれを探したり、寸法を測ったりする作業です。もう1つは、できたチップに電気を流して、正しく動くかを確かめる作業です。

この記事では、前者を「検査」、後者を「テスト」と呼び分けます。ただし、現場では両方をまとめて検査と呼ぶことも多く、厳密な決まりではありません。ウエハの上に回路を作る段階を前工程、チップを切り分けて包む段階を後工程と呼びます。下の図は、チップが工程を進むあいだに、どこで調べるかを示しています。

なぜ検査がそんなに大事なのか

どれほど丁寧に作っても、ウエハの上には一定の割合で不良のチップができます。作ったチップのうち、良品の割合を歩留まりと呼びます。歩留まりが低いと売れるチップが減り、1個あたりの費用が上がります。

不良は、見つけるのが遅いほど高くつきます。不良のチップを包めば、包む材料と手間がむだになります。機器の中の配線板(基板)にはんだ付けしたあとなら、基板ごと直すか捨てることになります。製品が人の手に渡ったあとなら、回収や交換の費用がかかり、会社の信用にも響きます。

そのため、検査やテストを工程のあちこちに置き、不良をできるだけ早い段階で止めます。ただし、調べるほど時間と装置の費用もかかります。どこで、何を、どこまで調べるかを決めることも、大事な仕事の1つです。

作っている途中の検査: 見る・測る

前工程では、膜をつけ、模様を写し、削る作業を何十回もくり返します。その途中で、ウエハを専用の装置に入れて状態を調べます。決めたとおりにできているかを確かめ、ずれていれば早めに工程を直すためです。

1つ目は、ごみや模様の欠けを探す検査です。ウエハに光を当てると、ごみの粒がある場所では光が散らばります。となり合うチップの画像を比べて、違う所を探す方法もあります。こうした装置を欠陥検査装置と呼びます。

見つかった欠陥が、すべて不良につながるわけではありません。たとえば、配線を途中で切ったり、配線どうしをつないだりしてしまう欠陥が、チップを不良にします。こうした欠陥をキラー欠陥と呼び、その数を減らすことが歩留まりを上げる近道です。

2つ目は、決めた場所の寸法を測る計測です。写した模様の線の幅は、電子の細いビームで上から見る専用の顕微鏡で測ります。この顕微鏡をCD-SEMと呼びます。

膜の厚さは、光を当てて、はね返った光の性質の変わり方から求めます。この測り方の1つをエリプソメトリと呼びます。膜にふれずに測れるので、製品のウエハをそのまま調べられます。こうした検査・計測の装置の主なメーカーには、アメリカのKLAなどがあります。

ウエハテスト: 針を当てて1個ずつ調べる

前工程を終えたウエハには、チップが碁盤の目のように並んでいます。まだ切り分ける前のこの状態で、チップを1個ずつ電気で調べます。これをウエハテストと呼びます。

チップの表面には、外とつなぐための小さな電極が並んでいます。そこへ、細い針をたくさん並べた部品を押し当てます。この部品をプローブカードと呼びます。針は、チップの電極の位置に合わせて並べてあります。

ウエハを運んで、針と電極の位置をぴったり合わせる装置は、プローバと呼びます。主なメーカーは、東京エレクトロンと東京精密です。調べ終えるごとにウエハを動かし、次のチップへ針を移します。何個かまとめて調べる場合もあります。

信号を作って送り、返ってきた答えを正しい答えと比べ、良品かどうかを自動で判定する装置がテスタです。正式にはATEと呼びます。主なメーカーは、日本のアドバンテストとアメリカのテラダインです。装置の全体像は「半導体製造装置とは?」で紹介しています。

結果は、チップの位置ごとに記録します。この記録をウエハマップと呼び、不良と判定したチップは、このあと包みません。不良が特定の場所に固まっていれば、前工程のどこかに原因があると考える手がかりにもなります。

最終テスト: 包んだあとにもう一度

良品のチップを切り分けて包むと、部品の形になります(「半導体パッケージとは?」)。包む作業の途中で、つなぐ線が外れたり、チップが割れたりすることもあります。そこで、完成した部品をもう一度テストします。これを最終テスト(ファイナルテスト)と呼びます。

最終テストでは、部品を運ぶ機械が、部品をテスト用の差し込み口(ソケット)に入れます。この機械をハンドラと呼びます。ハンドラは部品を温めたり冷やしたりして、決めた温度で測れるようにします。テストが終わると、結果に応じて部品を別々の入れ物に仕分けます。

温度を変えて測るのは、チップの性能が温度で変わるからです。たとえば車の部品の規格AEC-Q100には、使う温度の区分があります。最も厳しいグレード0は、周りの温度が−40〜150 ℃の範囲です。2つのテストの違いは「ウエハテストとファイナルテストの違い」で表にしています。

バーンイン: 早く壊れるものを先に見つける

チップの故障は、使い始めてすぐの時期に起こりやすい傾向があります。作るときに入った小さな弱点が、早いうちに表に出るからです。その後は故障の少ない時期が長く続き、寿命が近づくとまた増えます。この形を、浴槽の断面に見立ててバスタブ曲線と呼びます。

そこで出荷の前に、高い温度と高めの電圧をかけてチップを動かし、弱いものを先に壊してしまう方法があります。これをバーンインと呼びます。条件は製品によって違います。よく挙げられる例は、125 ℃で168時間(1週間)です(米国FDAの電子部品の検査の手引きなど)。

バーンインには、専用の装置と時間がかかります。そのため、すべての製品に行うわけではありません。車や産業機器、データセンターのサーバ向けのチップのように、故障すると損失の大きい製品で多く使われます。温度を上げると劣化が速まる理由は「アレニウスの式とは?」、やり方の種類は「バーンインの種類の違い」で説明しています。

電気のテストで何を調べるのか

テストで調べる中身は、製品によって違います。ここでは、多くのチップに共通する代表的なものを、おおまかな順に挙げます。実際の項目は、もっと細かく分かれています。

  • つながっているか: 針や端子が、チップの電極にきちんと触れているかを最初に確かめます。ここで失敗すると、ほかの結果も信用できないからです。
  • 漏れる電流: スイッチを切っているのに流れてしまう、わずかな電流を測ります。多すぎると電池の減りが早くなります。つながってはいけない所がつながる不良の手がかりにもなります。この電流をリーク電流と呼びます。
  • 正しく動くか(機能): 決めた0と1の並びを入れ、返ってくる答えが正しい答えと一致するかを比べます。
  • 速さ: 回路が動く拍子(クロック)を決めた速さにしても、答えを間違えないかを確かめます。
  • 電力: 動かしたときと止めたときに、電源から流れる電流を測ります。止まっているときの電流で欠陥を探す方法を、IDDQテストと呼びます。

速さで仕分ける: 同じ設計が別の型番になることも

同じ設計、同じ工場で作ったチップでも、仕上がりはわずかにばらつきます。模様の幅や膜の厚さが、ほんの少しずつ違うからです。その結果、間違えずに動ける最高の速さも、チップごとに少しずつ違います。

そこでテストで速さを測り、結果ごとにグループに分けることがあります。この仕分けをビニング、それぞれのグループをビン(入れ物の意味)と呼びます。速いグループは上位の型番として高く、遅いグループは下位の型番として安く売ります。2007年の大学の研究論文でも、ばらつきへの一般的な対処法として説明されています。

ただし、型番が違うチップが、すべて同じ設計というわけではありません。どの型番を同じ設計から仕分けているかは、メーカーが公表しないことも多い情報です。ここで言えるのは「同じ設計でも、テストの結果で売り方が分かれることがある」という点までです。

たとえで言うと

速さで分けるビニングは、収穫した果物を大きさで等級に分ける作業に少し似ています。同じ畑・同じ育て方でも、実の大きさはばらつきます。そこで、とれたあとに測って、等級ごとに値段を変えて売ります。似ているのは「同じ作り方でできたものを、できあがってから測って分ける」という一点です。

たとえが当てはまらない点: 果物の大きさは見ればわかりますが、チップの速さは見た目ではわかりません。電気で動かして、どの速さまで間違えないかを測る必要があります。また、チップの速さは全体の平均ではなく、回路の中でいちばん遅い通り道で決まります。

テストしやすく設計する: スキャンチェーンとBIST

何十億個ものスイッチがあるチップを、外の端子だけで調べ尽くすのは大変です。中の回路の状態は、外から直接は見えないからです。そこで、テストのための仕組みを、設計の段階からチップに入れておきます。この考え方をDFTと呼びます。

チップの中には、0か1を1つ覚えておく小さな回路がたくさんあります。これをフリップフロップと呼びます。ふだんは、計算の途中の結果を、次の拍子まで覚えておく役目です。

テストのときだけ、このフリップフロップを1列の鎖のようにつなぎます。入口から0と1を順に送り込むと、中の回路に好きな値を置けます。回路を1回だけ動かし、結果を出口から順に取り出して、正しい答えと比べます。この鎖をスキャンチェーン、これを使う方法をスキャンテストと呼びます。

もう1つは、テストをする回路そのものを、チップの中に入れておく方法です。チップ自身が試しの値を作り、答えが正しいかを判定して、結果だけを外に知らせます。これをBISTと呼び、チップの中のメモリを調べるときなどによく使われます。2つの違いは「スキャンテストとBISTの違い」で比べられます。

歩留まりを仮の数字で計算する

歩留まりを、仮の数字で計算してみます。実在の製品の数字ではなく、考え方を示すための例です。1枚のウエハに500個のチップが並び、ウエハテストで450個が合格したとします。ウエハテストの歩留まりは、450÷500で90%です。

合格した450個を包んで最終テストをしたら、441個が合格したとします。最終テストの歩留まりは、441÷450で98%です。全体では、最初の500個のうち441個を出荷できるので、約88%になります。

このように、全体の歩留まりは、各段階の合格の割合をかけ合わせた値になります(0.9×0.98≒0.88)。どの段階で多く落ちているかを見れば、直すべき工程の見当がつきます。チップの大きさと歩留まりの関係は「ダイ数・歩留まり計算ツール」で試せます。

よくある誤解

誤解: テストに合格したチップは、ずっと壊れない

実際は、テストで確かめるのは、出荷する時点で正しく動くかどうかです。長く使えば、熱や電気で少しずつ劣化します。どれくらい長持ちするかは、一部のチップを抜き出し、温度を上げて長い時間動かす別の試験で見積もります。「合格」を「永久の保証」と受け取りやすいことが、誤解の理由です。

誤解: 検査は、完成したあとに1回だけ行う

実際は、前工程の途中、ウエハテスト、最終テストと、何度も調べます。後になるほど不良の後始末が高くつくので、早い段階で止めるためです。完成品を最後に検査して出荷する、というほかの製品のイメージから生まれやすい誤解です。

誤解: 安い型番のチップは、必ず別の安い作り方をしている

実際は、同じ設計・同じ工場のチップを、テストで測った速さで仕分け、型番を分けることがあります。もちろん、最初から別に設計した製品もあります。型番が違えば中身もまったく違う、と考えやすいことが誤解の理由です。
