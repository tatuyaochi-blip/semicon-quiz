インバーターとは? エアコンやEVで電気を自在に変えるしくみ

約14分 · 更新: 2026年10月23日

インバーターは、直流の電気を、周波数と電圧を選んだ交流に作り直す装置です。中では半導体のスイッチが1秒に千回から数万回ほどオン・オフをくり返し、オンの時間の長さを変えて波の形を作ります。エアコンや電気自動車では、この働きでモーターの回る速さを自由に変えています。

この記事でわかること

  • インバーターが「何を何に変える」装置なのか
  • エアコン、電気自動車、太陽光発電、停電に備える電源での役目
  • 4つのスイッチで向きを入れ替え、PWMで波の形を作るしくみ
  • 速さを変えると省エネになる理由と、ならない場合
  • コンバーターや整流との違いと、音・熱・安全の注意

前提知識: 直流と交流の大まかな違い(「交流と直流の違いとは?」)。パワー半導体を「大きな電流を速くオン・オフするスイッチ」と知っていると読みやすくなります(「パワー半導体とは?」)。

身近なところでは: エアコンから停電の備えまで

家電の売り場では、「インバーターエアコン」「インバーター冷蔵庫」という言葉を見かけます。ダイキンの広報担当者によると、住宅用エアコンのうちインバーター付きの割合は、日本・EU・オーストラリアで100%です。一方、米国などでは、まだ一部にとどまります(2024年8月、ウェザーニュースの取材)。日本では、意識して選ばなくても、ほぼすべてのエアコンがインバーター付きなのです。

インバーターは、家電の外でも働いています。

  • 電気自動車・ハイブリッド車: 電池の直流を交流に変えて、走るためのモーターを回します
  • 太陽光発電: パネルが作る直流を、家で使える交流に変えます。この装置は「パワーコンディショナ」と呼ばれます
  • 無停電電源装置(UPS): 停電したとき、電池の直流を交流に変えて、パソコンやサーバーに電気を送り続けます
  • 電車: 架線から受け取った電気から、モーターに合った交流を作ります

UPSには、いつも電気を一度直流にし、インバーターで交流に戻して送る方式があります。この方式なら、停電しても途切れません。停電してから電池に切り替える方式では、100分の1秒ほど途切れます(ITmediaとASCII.jpの解説)。

どの例も、「直流しかない所で交流がほしい」か「交流の速さを変えたい」場面です。

インバーターがすること: 直流から「注文どおりの交流」へ

直流は、電池や太陽光パネルから出てくる、向きがいつも同じ電気です。交流は、向きが規則正しく行ったり来たりする電気です。1秒間の往復の回数を周波数と呼び、日本のコンセントでは50回か60回です。

インバーターは、直流を受け取って交流を作ります。このとき、周波数と電圧の大きさを、使う側の注文に合わせて選べるのが特徴です。周波数が決まっているコンセントと違い、1秒に10回の往復でも、100回を超える往復でも作れます。

交流を直流にする「順変換」に対して、直流を交流にすることを「逆変換」と呼びます。インバーターは、逆変換をする装置の呼び名です(パナソニックの用語解説)。技術の資料や当サイトの用語集では「インバータ」と書くことが多く、同じものです。

しくみ① 4つのスイッチで電流の向きを入れ替える

直流を交流にする基本のアイデアは、とても単純です。電池とモーターの間で、つなぐ向きを速く入れ替えればよいのです。手で電池の向きを入れ替えるかわりに、電気の信号で操作できるスイッチを4つ使います。

下の図のように、4つのスイッチをアルファベットのHの形に並べ、真ん中の横棒の位置にモーターを置きます。この並べ方を「Hブリッジ」または「フルブリッジ」と呼びます。

左上のS1と右下のS4をオンにすると、電流はモーターを右向きに流れます。次に、左下のS2と右上のS3をオンにすると、左向きに流れます。これを交互にくり返せば、向きが行ったり来たりする電気、つまり交流ができます。入れ替えるペースを変えれば、周波数も変えられます。

スイッチには、大きな電流と高い電圧に耐えるパワー半導体を使います。IGBTやパワーMOSFET、SiC(炭化ケイ素)のMOSFETなどです。それぞれの性格は「パワー半導体とは?」と「IGBTとパワーMOSFETの違い」で説明しています。ここでは「電気の信号で、とても速くオン・オフできるスイッチ」と考えてください。

一つだけ、絶対に避けなければならない状態があります。同じ縦の列の上と下(S1とS2など)が、同時にオンになることです。電源のプラスとマイナスがスイッチだけでつながり、大きな電流が流れて部品が壊れます。スイッチは、切れるまでにわずかな時間がかかります。そこで切り替えのときは、上下の両方をオフにする、ごく短い待ち時間をはさみます。これをデッドタイムと呼びます。

モーターは、流れている電流を急には止められません。そこで各スイッチには、電流を一方向にだけ通す部品(ダイオード)を並べ、切った瞬間の電流の逃げ道にします(「ダイオードとは?」)。

しくみ② 刻み方を変えて、なめらかな波に近づける

向きを入れ替えるだけでは、電圧は「プラスいっぱい」と「マイナスいっぱい」を行き来する、四角い波になります。コンセントの交流は、なめらかに上がり下がりする正弦波です。モーターを静かに、むだなく回すには、正弦波に近い形のほうが向いています。

そこで、スイッチをもっと細かく刻みます。交流の1回の往復の間に、オン・オフを何十回から何百回もくり返すのです。波の山のあたりではオンの時間を長く、0に近いあたりでは短くします。すると、ならした平均の電圧が、正弦波の形をなぞるように上がり下がりします。

オンの時間の長さ(パルスの幅)で、平均の電圧を決める方法を、PWM(パルス幅変調)と呼びます。インバーターでは、この幅を、時間とともに波の形に合わせて変えていきます。

幅の決め方にはいくつかありますが、代表的なのは、作りたい正弦波と、それよりずっと速い三角の波を比べる方法です。正弦波のほうが高い間はプラス側のスイッチをオンにし、低い間はマイナス側をオンにします。このやり方を正弦波PWMと呼びます(ここでは名前だけ紹介します)。

実際の電圧は、オンかオフかのパルスのままです。それでも、モーターに流れる電流はなめらかになります。モーターの電線を巻いた部分(コイル)は、速い変化ほど電流を通しにくいからです(「交流と直流の違いとは?」)。細かいぎざぎざはならされ、ゆっくりした正弦波の変化が電流に残ります。

周波数と電圧の選び方も、ここで決まります。幅を広げたり狭めたりするリズムを速くすれば、周波数が上がります。全体の幅を広めにすれば電圧が上がり、狭めにすれば下がります。どのスイッチをいつ切り替えるかは、マイコンなどの制御用のチップが計算して決めています(「マイコンとは?」)。

たとえで言うと

PWMは、印刷した写真の「網点」に少し似ています。新聞の白黒写真をルーペで見ると、灰色の部分も、黒い点と白い紙だけでできています。点が大きいところは濃く、小さいところは薄く見えます。インバーターも「オン」と「オフ」の2つしかないのに、オンの割合を変えることで、中間の電圧を表しています。似ているのは、この一点です。

たとえが当てはまらない点: 網点をならすのは人の目で、紙の上の場所で平均しています。インバーターでは、モーターのコイルが、時間の流れの中で電流をならします。また、ならしきれない小さな揺れが電流に残り、音や熱のもとになります。

しくみ③ 6つのスイッチで三相交流を作る

エアコンの圧縮機(冷やすためのガスを押し縮める機械)や電気自動車のモーターの多くは、3本の線で電気を受け取ります。3本には、同じ形の交流が、往復の3分の1ずつタイミングをずらして流れます。この送り方を三相交流と呼びます。3つの波が順番に強くなるので、モーターの中に、ぐるぐる回る磁石の力が生まれます。

三相のインバーターは、上下2つのスイッチの組を3列並べた、合計6つのスイッチで作ります。各列が、PWMで1本ずつの線の電圧を作ります。3列の波のタイミングを3分の1ずつずらせば、三相交流になります。

回る磁石の力の速さは、交流の周波数で決まります。周波数を半分にすれば、モーターの回る速さもおよそ半分になります。工場のポンプやファンでよく使われるモーターの一種、誘導電動機も、この性質を持っています。ただし、周波数だけを下げると、モーターに電流が流れすぎてしまいます。そのため、周波数に合わせて電圧も下げるのが基本です(ここでは単純化しています)。

電気自動車では、アクセルの踏み方に合わせて、インバーターが周波数と電圧を刻々と変えます。ブレーキのときに電気を電池へ戻す流れは、「パワー半導体とは?」の図で紹介しています。

なぜ速さを変えると省エネになるのか

インバーターのないエアコンは、圧縮機をいつも同じ速さで回していました。部屋が冷えすぎたら止め、暑くなったらまた全力で動かす、のくり返しです。インバーター付きなら、最初は速く回して早く冷やし、そのあとはゆっくり回し続けられます。この方式のエアコンは、東芝が1980年に業務用、1981年に家庭用で、世界で初めて量産しました。電気の国際的な学会IEEEが、歴史に残る業績として認めています。

止めては動かす運転には、むだがあります。ダイキンによると、エアコンは、室温と設定温度の差が大きい運転開始の直後に、電力を多く使います(2016年の発表)。速さを細かく変えられれば、全力で動かす回数が減り、温度の上がり下がりも小さくなります。ダイキンは2023年、国連の気候変動の会議(COP28)で高効率の機種を紹介しました。インバーターのない機種より、消費電力を50%以上減らせる、というのが同社の説明です。

ファンやポンプでは、速さを落としたときの効果がさらに大きくなります。これらでは、必要な電力が、回る速さの3乗(同じ数を3回掛けた値)におよそ比例するからです。米国エネルギー省の資料は、速さを2割落とすと、必要な電力はおよそ半分になるとしています。0.8を3回掛けると約0.51なので、計算とも合います(当サイトの計算)。

3乗になる理由を、かなり単純化して説明します。ファンを遅く回すと、1秒に送る風の量は、速さに比例して減ります。同時に、風を押し出す圧力は、速さの2乗で弱まります。必要な電力は「風の量 × 圧力」で決まるので、合わせて速さの3乗で減るのです。

ただし、エアコンの圧縮機は、ファンほど大きくは減りません。同じ資料は、空気を押し縮める圧縮機などでは、電力が速さにほぼ比例するとしています。エアコンでの省エネの大きな理由の一つは、前に見た「止めては全力で動かす」むだを減らせることです。

熱と損失: スイッチも少し熱くなる

インバーターも、受け取った電力をすべて送り出せるわけではありません。失う分は熱になります。日立が2017年に発表した太陽光発電用のパワーコンディショナでは、変換効率が96.5%でした。受け取った電力のうち、96.5%を送り出せるという意味です。この効率のまま定格の5.5キロワットを送り出すとすると、熱になるのは約0.2キロワットです(当サイトの計算)。

損失の一つ目は、オンのスイッチにわずかに残る抵抗によるものです。電流が流れている間は、ずっと熱が出ます。この抵抗をオン抵抗と呼び、これによる損失を導通損失と呼びます。

二つ目は、オンとオフが切り替わる途中の一瞬に生まれるスイッチング損失です。切り替えの途中では、スイッチに電圧と電流が両方かかるからです。

ここに、設計の悩みがあります。刻む回数を増やすほど、電流はなめらかになり、モーターの音も小さくなります。けれども、切り替えのたびに損失が出るので、回数を増やすほど熱が増えます。切り替えの損失が小さいSiCやGaNの部品は、この悩みを軽くできるので注目されています(「GaN(窒化ガリウム)とは?」)。

言葉の整理: コンバーター・整流との違い

変換よく使う呼び名例
交流 → 直流整流、コンバーター(順変換)充電器、エアコンの入口
直流 → 交流インバーター(逆変換)モーターの駆動、太陽光発電
直流 → 電圧の違う直流DC-DCコンバーターパソコンの中、電気自動車

「コンバーター」は、広く「電気の形を変える装置」を指す言葉です。交流を一方向の流れにそろえる働きは、特に整流と呼びます。

インバーターエアコンの中には、実はこの両方が入っています。コンセントの交流を、まずコンバーターで直流にします。それをインバーターで好きな周波数の交流に作り直して、圧縮機のモーターを回します。エアコンや冷蔵庫で「インバーター〇〇」と言うときは、このしくみで「モーターの速さを変えられる」製品という意味です。照明の「インバーター式」は、明かりに送る電気の周波数を高くするもので、目的が違います。

違いは「コンバータとインバータの違い」の表にまとめています。なお、0と1をひっくり返す論理回路も英語でインバータと呼びますが、名前が同じだけの別物です(「論理ゲートとは?」)。

音・ノイズ・安全

インバーターで動くモーターからは、「キーン」という高い音が聞こえることがあります。スイッチを刻むリズムに合わせて、モーターの鉄の部分がわずかに震えるためです。京急電鉄の一部の電車では、この音が発車のときに音階のように聞こえ、「歌う電車」と呼ばれました。1998年登場の2100形などに載ったシーメンス製の装置の音で、2021年夏に聞けなくなりました。

刻む回数を、人の耳に聞こえる範囲(1秒に約2万回まで)より多くすると、音は小さくなります。ただし、周りの機器に影響する電気のノイズが増えます(ジョンソンコントロールズの説明書)。切り替えの回数が増える分、損失も増えます。ラジオの雑音などを防ぐため、インバーターにはノイズを抑える部品(フィルタ)が組み込まれています。

安全面では、電源を切ったあとにも注意が要ります。インバーターの中には、直流をためておく大きなコンデンサがあります(「コンデンサとは?」)。電源を切っても、しばらくは高い電圧が残ることがあります。ドイツのメーカーSEW-EURODRIVEの説明書では、電源を切ってから少なくとも10分待つよう求めています。待つ時間は製品ごとに説明書に書かれています。家電の中を開けて触るのは避け、修理は専門の人に任せてください。

よくある誤解

誤解: インバーター付きなら、どんな使い方でも必ず省エネになる

実際は、省エネになるのは、速さを落として運転できる時間が長い場合です。ずっと全力で回し続ける機械では、速さを変える利点がありません。むしろ、インバーター自身の損失(数%)の分だけ、電力がわずかに増えることもあります。エアコンでも使い方で差が出ます。ダイキンの2016年の検証では、日中30分ほどの外出なら、切るよりつけたままのほうが得でした。ただし、いつでもつけたままにするのは逆効果だとしています。広告で「インバーター=省エネ」と強調されるので、どんな場合も得だと思われやすいのです。

誤解: インバーターが作る交流は、コンセントの交流より「きれい」

実際は、インバーターが作るのは、オンとオフのパルスを並べた電圧です。モーター用の場合、なめらかなのは、コイルでならされた電流のほうです。パルスをならす部品をきちんと付けた「正弦波出力」の装置もあります。一方、安い装置の中には、四角い波や階段状の波を出すものもあります。シュナイダーエレクトリックは、四角い波を出すUPSには対応できない機器がある、と注意しています。「電子の力で作った電気」という響きから、もとの電気より上等だと思われやすいのです。
