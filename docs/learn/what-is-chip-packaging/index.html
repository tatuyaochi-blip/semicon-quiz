半導体パッケージとは? チップを守り、外とつなぐしくみ

約13分 · 更新: 2026年10月23日

半導体パッケージは、シリコンのチップを包んで守り、機器の基板とつなぐための入れ物です。チップのとても細かい電極を、はんだ付けできる間隔の端子に広げ、熱を逃がす通り道にもなります。最近は、複数のチップを1つに包む「先端パッケージ」が性能を左右するため、ニュースでも注目されています。

この記事でわかること

  • パッケージの4つの役目: 守る・電気をつなぐ・熱を逃がす・間隔を広げる
  • 後工程で、ウエハが部品になるまでの順番
  • ワイヤボンディングとフリップチップの違い
  • DIP・QFP・QFN・BGA・WLCSPなど、形の違い
  • 壊れにくさを確かめる試験と、先端パッケージへのつながり

前提知識: チップがウエハという円い板の上でまとめて作られ、最後に切り分けられることを知っていると読みやすくなります。「半導体チップはどうやって作られる?」で説明しています。

身近なところでは

パソコンやゲーム機の基板を見ると、黒くて四角い部品がいくつも並んでいます。多くの場合、見えているのはチップそのものではなく、チップを包んだ樹脂の外側です。この包みを含めた部品全体を、パッケージと呼びます。チップ・ダイ・パッケージという言葉の整理は「集積回路(IC)とは?」にあります。

ニュースでも、パッケージの話題が増えました。データセンター向けのAI用GPUの多くは、計算用のチップとメモリを1つのパッケージに並べます。台湾のTSMCは2024年7月、この組み立ての生産能力を前の年の2倍以上に増やしたと説明しました。それでも需要に追いつかない状態でした。包む工程は、もう脇役ではありません。

パッケージの4つの役目

チップは、ウエハから切り出したシリコンの薄いかけらです。むき出しのままでは、機器の基板に取り付けて使えません。パッケージには、大きく4つの役目があります。

  • 守る: チップは薄くて割れやすく、表面の配線は湿気や汚れで傷みます。樹脂などで包み、衝撃や湿気から守ります。
  • 電気をつなぐ: チップの電極(電気の出入り口)と基板の配線を結び、信号と電源を通します。通り道が長いと、速い信号ほど形がくずれやすく、電源の電圧も揺れやすくなります。
  • 熱を逃がす: 動いているチップは、使った電力のほとんどを熱に変えます。その熱を、パッケージを通して基板や放熱器へ逃がします。
  • 間隔を広げる: チップの電極は、とても細かい間隔で並んでいます。これを、機器の基板にはんだ付けできる間隔まで広げます。

4つ目の例です。裏にはんだの球を並べたパッケージでは、端子の間隔はおよそ0.4〜1.27 mmです(当サイトの比較表)。チップの電極はそれよりずっと細かく並ぶので、パッケージの中の配線で間隔を広げてつなぎます。

たとえで言うと

パッケージの「間隔を広げる」役目は、海外旅行で使うコンセントの変換アダプタに少し似ています。形の合わないプラグを、壁の差し込み口に合う形に変えてつなぎます。パッケージも、チップの細かい電極を、基板に合う間隔の端子に変えます。似ているのは「合わない2つの間に入って、形と間隔を合わせる」という一点です。

たとえが当てはまらない点: 変換アダプタは抜き差しでき、電気の性質をほとんど変えません。パッケージははんだ付けして固定し、中の通り道の長さは信号の乱れにも影響します。チップを守る役目や、熱を逃がす役目も、このたとえには含まれていません。

後工程の流れ: ウエハから部品へ

パッケージに包む作業は、後工程と呼ばれる段階で行います。ここでは、細い線でつなぐ代表的なパッケージを例に、順番に見ていきます。前工程との違いは「前工程と後工程の違い」の表にまとめています。

  1. ウエハテスト: ウエハのまま、チップ1個ずつの電極に細い針を当てて、正しく動くかを調べます。不良のチップの位置を記録し、そのチップは包みません。手間のかかる包む作業を、むだにしないためです。
  2. 裏を削る: ウエハを裏から削って薄くします。300 mmのウエハの厚さは約0.775 mmですが、その数分の1に、薄いものでは0.05 mm以下まで削ります。この作業をバックグラインドと呼びます。
  3. 切り分ける: 回転する薄い刃やレーザーで、碁盤の目のように並んだチップを1個ずつに切ります。この作業をダイシングと呼びます。切り出したシリコンのかけらは、ダイとも呼ばれます。とても薄いチップでは、先に途中まで切れ目を入れてから裏を削り、切り離す順番もあります。
  4. 土台に固定する: ダイを、接着剤やはんだで土台に貼り付けます。土台は、金属の薄い枠か、配線の入った小さな板です。この作業をダイボンディングと呼びます。
  5. 電極をつなぐ: ダイの電極と土台の端子を、細い金属の線や小さな金属の粒でつなぎます。2つの方法は、次の節でくわしく見ます。
  6. 樹脂で包む: 型の中に溶かした樹脂を流し込み、ダイと線を丸ごと固めます。この作業をモールド、または封止と呼びます。
  7. 印をつける: 包みの表面に、レーザーなどで会社のマークや型番、製造した時期を表す番号を刻みます。あとで不具合が出たとき、いつ作ったものかをたどれます。
  8. 最終テスト: 完成した部品を、決められた温度や電圧で動かして検査します。これをファイナルテストと呼び、合格したものだけを出荷します。2つの検査の違いは「ウエハテストとファイナルテストの違い」で比べられます。

つなぎ方: ワイヤボンディングとフリップチップ

1つ目は、チップを上向きに置き、縁に並んだ電極と土台の端子を、細い金属の線で1本ずつ結ぶ方法です。これをワイヤボンディングと呼びます。線の太さは、およそ15〜50 µmです(線のメーカーの製品紹介による)。µm(マイクロメートル)は1000分の1 mmで、髪の毛(約0.09 mm)の数分の1の細さです。

線の材料には、さびにくく扱いやすい金が長く使われてきました。ただ、金の値段が上がったため、2010年代には安い銅の線への切り替えが進みました。ワイヤボンディングは安く、配置の融通もききます。マイコンやメモリ、アナログのチップなど、今も多くの製品で使われています。

2つ目の方法では、まずチップの電極の上に、はんだや銅でできた小さな金属の粒を作ります。この粒をバンプと呼びます。バンプは、線のように縁だけでなく、チップの面全体に並べられます。

そのうえでチップを裏返し、バンプを基板の電極に直接くっつけます。裏返す(フリップする)ので、この方法をフリップチップと呼びます。1960年代にIBMが実用化した方法がもとになっています。電極の数を大きく増やせて、通り道も短いので、速い信号を通しやすくなります。

チップと基板のすき間には、樹脂を流し込んで固めます。この樹脂をアンダーフィルと呼びます。温度が変わると、チップと基板は違う割合で伸び縮みします。その差でバンプにかかる力を、樹脂が分け持って和らげます。

フリップチップは、CPUやGPUのように、電極が数千もある速いチップに向きます。そのかわり、バンプを作る工程や細かい配線の基板が要るので、費用は高めです。違いの一覧は「ワイヤボンディングとフリップチップの違い」で見られます。

パッケージの形: 足のある形から、はんだの球へ

パッケージには多くの形があり、外の基板とつなぐ端子の形で見分けられます。代表的なものを、古くからある順に見てみます。

  • DIP: 本体の両側から、くしの歯のように足が下へ伸びた形です。足を基板の穴に挿して、はんだ付けします。1971年のインテルの4004も、16本足のDIPでした。
  • QFP: 本体の4辺から、外へ曲げた足が出た形です。基板の表面に載せてはんだ付けします。足が見えるので、検査や手作業の修理がしやすい形です(QFP)。
  • QFN: 足を外に出さず、本体の底の縁に平らな電極を並べた形です。小さく薄く、多くは底の中央に金属の面があり、そこから熱を逃がせます(QFN)。
  • BGA: 本体の底一面に、はんだの小さな球を碁盤の目のように並べた形です。面全体を使うので、端子を数百から数千も並べられます。CPUやGPU、メモリで広く使われます(BGA)。
  • WLCSP: 切り分ける前のウエハの上で、配線とはんだの球まで作ってしまう形です。包みがチップとほぼ同じ大きさになり、スマホの小さなチップに多く使われます(ウエハレベルパッケージの一種)。

DIP・QFP・QFNのように足や電極のある形では、チップを金属の薄い枠に載せます。この枠をリードフレームと呼び、枠の一部がそのまま端子になります。3つの形の比べ方は「BGA・QFP・QFNの違い」にまとめています。

ウエハレベルの形には、チップの外側まで配線を広げる「ファンアウト型」もあります。チップより広い面に端子を並べられ、薄く作れます。調査会社のYoleによると、2016年のiPhone 7のプロセッサ(A10)は、TSMCのこの方式で包まれました。違いは「ファンイン型とファンアウト型WLPの違い」で比べられます。

パッケージ基板: 包みの中の小さな配線板

BGAの多くでは、チップを小さな配線の板に載せます。これをパッケージ基板と呼びます。樹脂の薄い層と銅の配線の層を何層も重ねた板で、チップ側の細かい電極を、裏のはんだの球までつなぎます。役目の4つ目「間隔を広げる」を受け持つ部品です。

高性能なチップ向けの基板は、機器の基板よりずっと細い配線を何層も重ねます。配線の層の間には、電気を通さない樹脂のフィルムをはさみます。このフィルムで広く使われているのが、味の素が開発したABFです。

熱を逃がす: 包みは放熱の通り道

チップが熱くなりすぎると、動作が不安定になり、寿命も縮みます。チップの熱は、パッケージを通って基板や放熱器へ逃げていきます。熱の伝わりにくさを熱抵抗と呼び、パッケージの形と材料で大きく変わります。

たとえばQFNは、底の金属の面を基板にはんだ付けして、熱を基板へ直接逃がします。電力の大きいCPUでは、フリップチップで裏返したチップの背中に金属のふたを密着させ、熱を広げてから放熱器へ渡します。消費電力と熱抵抗からチップの温度を見積もるには「接合温度の計算ツール」が使えます。

材料: 樹脂も基板も性能を左右する

包む樹脂は、熱で固まるエポキシ樹脂に、ガラスと同じ成分の細かい粉(シリカ)をたくさん混ぜたものです。粉は、重さの多くを占めます。粉を増やすと、温度による伸び縮みがシリコンに近づき、湿気も吸いにくくなります。

材料と装置で日本の会社が持つ世界シェアは「半導体業界にはどんな仕事がある?」で、ウエハを削る装置や切る装置のメーカーは「半導体製造装置とは?」で紹介しています。

長く壊れないことを確かめる

パッケージに入ったチップは、車の中や屋外で、10年以上使われることもあります。そこで、厳しい条件を短い期間に詰め込んだ試験で、壊れにくさを確かめます。こうした試験を、信頼性試験と呼びます。

1つは、低温と高温を何百回もくり返す試験です。チップ、樹脂、基板は、温まったときの伸び方が違います。くり返すうちに、はんだの継ぎ目にひびが入ったり、樹脂がはがれたりしないかを見ます。たとえば−55 ℃と125 ℃の間を行き来させるこの試験を、温度サイクル試験と呼びます。

もう1つは湿気です。包む樹脂は、わずかずつ水分を吸います。業界団体JEDECの規格には、85 ℃・湿度85%の中で電圧をかけたまま、約1000時間置く試験があります。中の金属がさびたり、電気が漏れたりしないかを確かめます。

水分は、機器の基板にはんだ付けするときにも問題になります。部品は、炉で一度に温めてはんだを溶かします。このとき250 ℃前後まで温まり、吸った水分が一気に水蒸気になって、包みを内側から割ることがあります。はじける様子から、ポップコーン現象とも呼ばれます。湿気への弱さはMSLという段階で表し、弱い部品は乾燥剤と一緒に袋に密封して出荷します。

温度を上げた試験の結果を、ふだんの温度での寿命に読み替える考え方は「アレニウスの式とは?」で説明しています。試験の種類の違いは「HTOL・THB・HAST・温度サイクル・高温放置試験の違い」で比べられます。

先端パッケージ: チップレットとHBMへ

最近は、1つのパッケージに複数のチップを入れ、1つの部品のように働かせる技術が広がっています。これをまとめて、先端パッケージと呼びます。大きな回路を小さなチップに分けて並べるチップレットや、メモリを積み重ねてGPUの隣に置くHBMが代表例です。くわしくは「チップレットとは?」「HBMとは?」で、並べ方と積み方の違いは「2.5Dと3D実装の違い」で説明しています。

よくある誤解

誤解: パッケージは、チップを入れておくただのプラスチックの箱

実際は、包みの中に配線の板や金属の枠があり、何百〜何千本もの電気の通り道を受け持ちます。熱を逃がす通り道でもあり、パッケージの作りで、チップの速さや使える電力が変わります。外からは黒い樹脂しか見えないので、生まれやすい誤解です。

誤解: 中のチップは、包みと同じくらいの大きさ

実際は、多くの形で、チップは包みよりずっと小さくなります。インテルの4004のチップは約3 mm×4 mmで、16本足のDIPに入っていました。足は2.54 mm間隔で片側に8本ずつ並びます。2.54 mm×7に両端の余白を足すと、包みの長さは2 cm近くになる計算です。一方、WLCSPのように、包みがチップとほぼ同じ大きさの形もあります。

誤解: 包む工程は、技術的にやさしい

実際は、0.05 mmほどの薄いチップを割らずに扱い、数千の電極を一度にずれなくつなぐ、精密な技術の集まりです。先端パッケージでは、チップどうしをつなぐ粒の間隔が数十µmまで細かくなります。前工程の微細化に比べて目立たないことから生まれやすい誤解です。
