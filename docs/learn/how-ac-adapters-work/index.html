ACアダプターのしくみ: 充電器はどう100Vを5Vにする?

約14分 · 更新: 2026年10月23日

ACアダプター(充電器)は、コンセントの交流100ボルトを、スマホなどが使う5ボルト前後の直流に変える装置です。今の多くは「スイッチング電源」です。交流をいったん直流にし、1秒に数万回以上オン・オフしてから、小さな変圧器で電圧を下げます。速く切り替えるほど変圧器を小さくできるので、昔の重い箱より小さく軽くなりました。

この記事でわかること

  • スマホやパソコンが「低い電圧の直流」を必要とする理由
  • 昔の重いアダプターと、今の小さな充電器の違い
  • 中で起きている5つの段階(整流、速いオン・オフ、小さな変圧器、もう一度の整流、見張りと調整)
  • 速く切り替えるほど部品が小さくなる理由と、その代わりに増える熱
  • コンセント側と出力側を電線でつながない「絶縁」の意味

前提知識: 直流と交流の大まかな違い(「交流と直流の違いとは?」)。変圧器を「2つのコイルで交流の電圧を上げ下げする部品」と知っていると読みやすくなります。

身近なところでは: 重い箱から手のひらサイズへ

スマホの充電器、ノートパソコンの電源、Wi-Fiのルーターやゲーム機の電源。家の中には、コンセントに挿す小さな箱がたくさんあります。どれも、コンセントの電気を機器に合う形に変える役目をしています。

少し前まで、家電に付いてくるアダプターは、ずっしり重い四角い箱でした。今のスマホ用の充電器は、同じくらいの電力を、ずっと小さく軽い箱で送り出せます。中身のしくみが、根本から変わったからです。

この記事では、今の充電器の中で何が起きているかを、5つの段階に分けて見ていきます。

なぜ「低い電圧の直流」が必要なのか

コンセントの電気は、1秒に50回か60回、向きが行ったり来たりする交流です。電圧は、山のところで約141ボルトに達します(くわしくは「交流と直流の違いとは?」)。一方、スマホやパソコンの中の回路は、向きが一定の直流で動きます。

必要な電圧も、ずっと低いのが特徴です。スマホのリチウムイオン電池は、1つ(1セル)あたり3.6ボルトほどです(Battery University)。パソコンのメモリの規格DDR5では、電源の電圧は1.1ボルトです(JEDEC、2020年)。チップの中のとても小さなトランジスタは、高い電圧に耐えられないのです。

そこで、まずACアダプターが、100ボルトの交流を、多くは5〜20ボルトほどの直流にします。機器の中では、さらに小さな電源の回路が、チップごとに合った電圧へ細かく分けます(「スマホの中にはどんな半導体が入っている?」)。ACアダプターは、この長い道のりの最初の、いちばん大きな一段を受け持っています。

昔のアダプター: 大きな変圧器で直接下げる

昔のアダプターの中身は、とても単純でした。コンセントの交流を、そのまま変圧器に通して電圧を下げます。次に、電流を一方向にだけ通すダイオードで向きをそろえ、コンデンサでならして直流にしていました(「ダイオードとは?」)。

重さのもとは、この変圧器です。1秒に50回か60回というゆっくりした変化を扱うには、太い鉄の芯と、たくさん巻いた銅の線が要ります。芯は、薄い鉄の板を何枚も重ねて作ります(OpenStaxの物理の教科書)。

この方式には、ほかにも弱点がありました。電圧は巻き数の比で決まるので、入力が2倍の国で使うと、出力もほぼ2倍になります。そのまま使えば、機器を壊すおそれがあります。つなぐ機器が電気をあまり使わないと、表示より高い電圧が出ることもありました。例えば、交流9ボルトと表示された変圧器式の製品があります。何もつながないときは、11.6ボルト近くまで上がりえます(Triad Magnetics)。

むだも多めでした。米国のENERGY STARの資料では、変圧器式の電源の効率を測ると、20〜75%でした。効率は、受け取った電力のうち、送り出せた割合です。残りは熱になり、箱を温めていました。

しくみ① 今の充電器の全体の流れ

今の充電器の多くは、スイッチング電源と呼ばれる方式です。電気を細かく「切り替える(スイッチする)」ことから、この名前があります。電気が通る順番は、下の図のようになります。

一見すると、遠回りに見えます。交流をわざわざ直流にして、また細かく刻んで変圧器に通すからです。けれども、この遠回りのおかげで、変圧器を手のひらに収まる大きさにできます。順に見ていきましょう。

しくみ② まず直流にして、高い電圧のまま蓄える

最初の段階では、コンセントの交流を、4個のダイオードを組にした回路で一方向にそろえます。これを整流と呼びます。そのあと、大きなコンデンサが電気をためては少しずつ出し、波打ちをならします。

ここでは、電圧はまだ下げていません。100ボルトのコンセントなら、山の高さに近い約140ボルトの直流になります(ローム)。240ボルトの国なら、約340ボルトです(当サイトの計算)。

このコンデンサには、高い電圧に耐えるものが必要です(ローム)。役目は、1秒に100回か120回来るコンセントの波の谷間をしのぐことです。大きさは、この谷間の長さと、コンセントの電圧が低めのときを基準に決まります(米国のTI社の資料)。切り替えの速さとは関係がないので、あとで見る「速く切り替える工夫」では小さくなりません。

しくみ③ パワートランジスタで、速くオン・オフする

次に、その直流を、電気の信号で操作できるスイッチで細かく刻みます。使うのは、大きな電流と高い電圧に耐えるトランジスタです。電気を通す・止めるを、1秒に何万回も切り替えられます(「パワー半導体とは?」)。

切り替える速さは製品によって違い、例えば1秒に5万回(50キロヘルツ)ほどです(ローム)。50ヘルツのコンセントの交流が1回往復する間に、千回もオン・オフをくり返す速さです。

刻むのは、変圧器が「変化している電流」でしか働かないからです。一定の直流を通しても、反対側には電圧が生まれません。オン・オフをくり返すと、変圧器にとっては、とても速い交流と同じように働きます。

しくみ④ 小さな変圧器で電圧を下げ、もう一度直流にする

刻んだ電気を、小さな変圧器に通して電圧を下げます。小さな充電器では、オンの間に変圧器の中に磁石の力としてエネルギーをため、オフの間に出力側へ渡す方式がよく使われます。この方式をフライバック方式と呼び、100ワットくらいまでの電源で広く使われています(ローム)。

出力側に出てくるのは、まだオン・オフに合わせて脈打つ電気です。そこで、ここでも整流して、コンデンサでならします。こうして、やっと5ボルトなどの落ち着いた直流ができます。

この整流の部品には、工夫があります。ダイオードは、電流を通すたびに電圧を少し使ってしまいます。使う電圧が低いショットキーダイオードでも、0.4〜0.7ボルトほどです(東芝)。5ボルトを作るときに0.5ボルトを失えば、それだけで1割です。

そこで今の充電器では、ダイオードの代わりにトランジスタを置く方法が広く使われています(Monolithic Power Systems)。電流を通すべき瞬間にだけ、オンにするのです。これを同期整流と呼びます。

しくみ⑤ 出力を見張って、オンの長さを直す

スマホが電気を急にたくさん使うと、出力の電圧は少し下がります。コンセントの電圧も、いつも同じではありません。それでも5ボルトを保てるのは、出力をいつも見張り、ずれを直しているからです。

出力側には、決まった基準の電圧と、今の出力の電圧を比べる部品があります(TI)。ずれがあると、その大きさを、コンセント側の制御用のチップへ知らせます。チップは、スイッチをオンにしておく時間の割合を変えて、送る電力を増やしたり減らしたりします。この割合をデューティ比と呼びます。

結果を見て操作を直すこのしくみは、フィードバック(帰還)と呼ばれます。入力が100ボルトでも240ボルトでも同じ出力が出るのも、この調整のおかげです。

急速充電の決まりUSB PDで9ボルトや20ボルトを頼まれたときは、出力側のチップが目標の電圧を切り替えます。その指示を、図と同じフォトカプラでコンセント側へ伝える製品もあります(ルネサスの製品資料。「USBとは?」)。

たとえで言うと

フィードバックは、シャワーの湯の温度を手で確かめながら、ハンドルを少しずつ回すのに似ています。熱すぎれば戻し、ぬるければ足します。似ているのは「結果を測り、目標とのずれに合わせて操作を直す」という一点です。

たとえが当てはまらない点: 人は数秒ごとにしか確かめませんが、充電器は電子の回路で、ずっと見張り続けています。また、ハンドルは湯の量をなめらかに変えます。充電器はスイッチを「オン」と「オフ」だけで操作し、オンの時間の割合で量を決めます。

速く切り替えると、なぜ部品が小さくなるのか

変圧器は、片方のコイルで芯の中に磁石の力(磁束)を作り、その変化でもう片方に電圧を生みます。芯が抱えられる磁束には上限があり、芯の材料と太さで決まります。上限を超えると、変圧器はうまく働かなくなります。

同じ電圧なら、かける時間が短いほど、芯に積み上がる磁束は少なくてすみます。50ヘルツの交流では、向きが変わるまでの半周期が100分の1秒あります。5万回の切り替えなら、1回のオンは長くても5万分の1秒ほどです。積み上がる量が少なければ、芯を細くし、巻き数を減らせます(電力変換の教科書、エリクソンほか)。

ただし、千倍速くしても、変圧器が千分の1になるわけではありません。速い変化では、芯や線の中で失われる熱が増えます。そのため芯の材料も、鉄の板から、高い周波数でも損失の少ないフェライト(鉄の酸化物を主な材料に焼き固めたもの)に変わります。別のたとえを使った説明は「GaN(窒化ガリウム)とは?」にもあります。

効率と熱: 速さとのかけひき

今の充電器の効率は、昔よりずっと高くなりました。例えば、効率90%の充電器で20ワットを送り出すとします。受け取る電力は約22.2ワットで、約2.2ワットが熱になります(当サイトの計算)。

熱の出どころは、主に4つです。トランジスタがオンのときの小さな抵抗、出力側の整流、変圧器の芯と線、そして切り替えの途中に生まれる損失です。最後のものは、オンとオフが入れ替わるほんの一瞬に、電圧と電流が両方かかることで生まれます。これをスイッチング損失と呼びます。

ここに、かけひきがあります。切り替えを速くすると部品は小さくなりますが、切り替えのたびにスイッチング損失が出るので、熱が増えます。しかも小さな箱は表面が狭く、熱を逃がしにくいのです。小型化は「速く切り替えても熱が増えにくい」部品があって初めて進みます。

何もつないでいないときの電力にも、決まりがあります(2026年時点)。EUでは2020年4月から、交流を直流にする49ワット以下の外付け電源で、0.10ワット以下です(EU規則2019/1782)。米国でも2016年から、同じような範囲で0.100ワットが上限です(米国エネルギー省)。EUでは2028年12月から、より厳しい新しい規則に替わります(EU規則2025/2052)。

GaNの充電器が小さくなった理由

最近の小さな充電器では、スイッチにGaN(窒化ガリウム)という材料のトランジスタを使うものが増えました。GaNのトランジスタは、1回の切り替えで失う電気がシリコンより少なくてすみます。そのため、熱をあまり増やさずに切り替えを速くでき、変圧器や出力側のコンデンサを小さくできます。

ただし、小さくなるのは、切り替えの速さで大きさが決まる部品です。しくみ②で見た入口の大きなコンデンサは、コンセントの波に合わせた部品なので、ほとんど小さくなりません。制御用のチップの改良や、部品を詰めて並べる工夫も合わさって、今の大きさになっています。

安全のための「絶縁」: 電線でつながない

しくみ①の図で、点線の上と下を見てください。コンセント側には、100ボルト以上の電気が流れています。一方、出力側のUSBの端子には、人の指が直接ふれます。そこで、この2つの間は、電線でつながないように作ります。電気を通さない材料や、すき間で隔てることを、絶縁と呼びます。

では、電気をどうやって渡しているのでしょうか。電力は、変圧器の芯の中の磁束で渡ります。2つのコイルは、電気的にはつながっていません。見張り役の情報は、光で渡す方式がよく使われます(図2)。変圧器に別のコイルを巻き、出力の電圧を推し量る方式もあります(ローム)。

光で信号を送る部品を、フォトカプラと呼びます。入口のLEDが光り、出口の部品がその光を受けて電気の信号に戻します。入口と出口が電気的に切り離されているので、両側の電圧が大きく違っても信号を送れます(東芝)。

こうした絶縁の決まりは、国際的な安全規格で定められています。パソコンやAV機器とその電源には、IEC 62368-1という規格が使われます(コーセル)。

充電器のラベルには、正方形を二重にした「回」の形のマークがよくあります。二重の絶縁などで守る「クラスII」の機器を表す記号です(IEC 60417-5172)。

日本では、ACアダプターは、国の決まりで特に安全の確認が厳しい「特定電気用品」に入ります。ひし形のPSEマークの表示が必要です(経済産業省)。マークのない製品は避けてください。また、充電器は分解しないでください。中の大きなコンデンサには、プラグを抜いたあとも、しばらく高い電圧が残ることがあります。

よくある誤解

誤解: コンセントに挿したままの充電器は、電気をまったく使わない

実際は、何もつないでいなくても、見張りの回路などがわずかに電気を使います。ただし量は小さく、EUや米国の上限は0.1ワットです(2026年時点、49ワット以下の場合)。0.1ワットを1年間使い続けると、約0.9キロワット時です(当サイトの計算)。昔の変圧器式には、何もつながなくても温かくなるものがありました。変圧器の芯に、いつも電流を流しているからです。

誤解: ワット数の大きい充電器は、いつも電気をたくさん使う

実際は、充電器のワット数は「出せる上限」です。フィードバックで、機器が使う分だけを送り出すので、小さな機器をつなげば使う電力も小さくなります。ワット数の大きさと電気代は直接は結びつきません。箱に大きく書かれた数字なので、いつもその分を使うと思われやすいのです。

誤解: 充電器が温かくなるのは、故障している証拠

実際は、効率が90%を超えても、残りは熱になります。20ワットを送り出すときに2ワットほどの熱が出るのは、設計どおりです。ただし、触れないほど熱い、焦げたにおいがする、変形している、といったときは、コンセントから抜いて使うのをやめてください。
