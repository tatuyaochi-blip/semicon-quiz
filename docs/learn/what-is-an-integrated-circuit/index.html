集積回路(IC)とは? チップ・ダイ・LSI・SoCの違いも整理

約12分 · 更新: 2026年10月23日

集積回路(IC)は、たくさんのトランジスタと配線などを、1つの小さなシリコンのかけらにまとめて作り込んだ電子回路です。部品を1個ずつつなぐより、小さく、安く、速く、壊れにくくできます。「チップ」や「LSI」もほぼ同じものを指し、SoCは機器の主な働きを1つのチップにまとめたICです。

この記事でわかること

  • 「集積」とは、何をまとめることなのか
  • ICが画期的だった理由
  • IC・チップ・ダイ・LSI・SoC・パッケージの違い
  • ICの種類と、設計の流れ
  • ICが機器の基板とつながる形

前提知識: とくになし。トランジスタを「電気で切り替える小さなスイッチ」と知っていると読みやすくなります(「トランジスタとは?」)。

身近なところでは: スマホの中の黒い部品

スマホの中には、部品を載せて配線でつなぐ板が入っています。これを基板と呼びます。基板の上には、黒や銀色の四角い部品がいくつも並んでいます。その多くがIC、つまり集積回路です。

修理の情報サイトiFixitは、iPhone 15 Pro Max(2023年)の基板の部品を調べて公開しています。そこには、仕事の違うICがいくつも並んでいます。

  • 計算の中心になるチップ(AppleのA17 Pro)
  • 作業中のデータを一時的に覚えるメモリ
  • 写真やアプリをしまっておく、記憶用のメモリ
  • 電池の電気を、各部品に合う電圧に整えるIC(いくつもある)

テレビや冷蔵庫、車にも、ICはたくさん入っています。

「集積」とは: 部品と配線を一緒に作ること

電子回路は、いくつもの部品を電線でつないで作ります。代表的な部品が、電気で切り替える小さなスイッチのトランジスタです。昔は、部品を1個ずつ別々に作り、基板に並べて、はんだ(低い温度で溶ける金属)でつないでいました。

部品には、ほかに抵抗やコンデンサもあります。抵抗は電流を流れにくくする部品、コンデンサは電気を少しためておく部品です。どちらも、1個ずつの部品として今も売られています。

集積回路は、これらの部品と配線を、1つのシリコンのかけらの中にまとめて作ります。トランジスタも抵抗もコンデンサも、シリコンの上に同じ工程で層を重ねて形づくります。部品どうしをつなぐ金属の配線も、同じ流れの中で作り込みます。「集積」とは、部品と配線を1か所に集めて、一体として作ることです。

何十億個のトランジスタも、1個ずつ作るのではありません。光で模様を写す方法で、まとめて一度に作ります。作り方は「半導体チップはどうやって作られる?」で説明しています。

なお、図は話を簡単にしています。実際のICでは、部品のほとんどがトランジスタです。大きな値の抵抗やコンデンサは場所を取るので、ICの外に別の部品として置くこともよくあります。

たとえで言うと

集積は、プラモデルの作り方の違いに少し似ています。小さな部品を1つずつ接着剤でつなぐ代わりに、最初から全体がつながった形で、型から一度に作るようなものです。似ているのは「つながった状態で作るので、つなぎ目が外れる心配がない」という一点です。

たとえが当てはまらない点: 型で作る部品は、1つの材料を流し込んで一度に形を作ります。ICは、性質の違う材料の薄い層を、光で写した模様に合わせて何十回も重ねて作ります。電気の通しやすさまで、場所ごとに作り分ける点も違います。

なぜ画期的だったのか

ICが生まれる前の大きな悩みは、部品の数でした。計算機を高性能にしようとすると、部品とつなぎ目がどんどん増えます。つなぎ目が1か所でも外れれば、装置は正しく動きません。

極端な例が、1946年に公開されたアメリカの計算機ENIACです。トランジスタが広まる前の機械で、スイッチの役目をする真空管を1万7千本以上使っていました。ミシガン大学の解説によると、はんだ付けのつなぎ目は約500万か所ありました。

この悩みを解いたのが集積回路です。1958年にジャック・キルビーが、1959年にロバート・ノイスが、その基本の形を示しました。その歴史は「トランジスタとは?」の年表にあります。まとめて作ることで、主に4つのよい点が生まれました。

  • 壊れにくい: はんだで部品をつなぐ点が減り、外れる場所が少なくなります。
  • 安い: 組み立てる代わりに、まとめて作れます。1枚のウエハ(シリコンの円い板)から、何百個ものICが同時にできます。
  • 速い: 部品どうしの距離が短くなります。配線が短いと、配線にためる電気の量が減り、信号を速く切り替えられます。
  • 小さく、電力が少ない: 同じ回路が指先に乗るほどの大きさに収まり、使う電力も減ります。

のちにインテルを共同で創業するゴードン・ムーアも、1965年に論文を書きました。ICは壊れにくく、機器全体の費用も下げている、という内容です。部品の数が毎年約2倍に増えているという、のちのムーアの法則も、同じ論文の指摘です。

IC・チップ・ダイ・LSI・SoCの違い

ICのまわりには、似た言葉がたくさんあります。同じものを場面によって呼び分けているだけのこともあります。図と表で整理します。

チップとダイ: 本体のシリコンのかけら

ICの本体は、ウエハから切り分けたシリコンのかけらで、多くは1辺が数mmから2 cmほどです。これをチップと呼びます。製造や設計の現場では、同じものをダイとも呼びます。

ただし、ふだんの会話では、「チップ」がパッケージに入った部品全体を指すことも多いです。「AIチップ」のようなニュースの言葉も、この広い意味です。

パッケージ: 外から見える部分

ダイはとても薄く、割れやすく、湿気にも弱いものです。そこで、土台に載せて外とつなぐ端子をつけ、樹脂などで包みます。この入れ物を含めた部品全体を、パッケージと呼びます。基板の上で見える黒い四角は、多くの場合、このパッケージの樹脂です。

LSI・VLSI: 規模による呼び名

ICは、入っている部品の数で呼び分けられてきました。部品の多い大きなICをLSI(大規模集積回路)、さらに多いものをVLSI(超大規模集積回路)と呼びます。

境目の数に、決まった定義はありません。例えば、部品1,000個以上をLSIとする大学の講義資料があります。今は大規模なのが当たり前なので、ICとLSIはほぼ同じ意味で使われます。

SoC: 機器の主な働きを1つのチップに

スマホの計算の中心にあるチップには、CPUのほか、画面の絵を描く回路(GPU)や、AIの計算に向いた回路も入っています。このように機器の主な働きを1つにまとめたICを、SoCと呼びます。日本では「システムLSI」とも呼びます。CPUの働きは「CPUとは?」で説明しています。

ICの種類: 仕事で分けると

ICは、受け持つ仕事で大きく分けられます。ここでは身近な例と一緒に、4つに分けて見ていきます。

  • 計算する(ロジック): 0と1の信号を組み合わせて、計算や判断をするIC。CPU、GPU、スマホのSoCなどがここに入ります。
  • 覚える(メモリ): データを0と1で記憶するIC。作業中のデータを置くDRAMは、速い代わりに電源を切ると中身が消えます。写真などを保存するNANDフラッシュは、電源を切っても消えません。
  • なめらかな信号を扱う(アナログ): 音や電波、温度のように、連続して変わる信号を扱うIC。小さな信号を大きくしたり、0と1のデータに変えたりします。
  • 電源を整える(電源管理): 電池などの電気から、各部品に合う電圧を作って配るIC。PMIC(電源管理IC)と呼ばれ、スマホにはいくつも入っています。

ここでは話を簡単にしています。世界の半導体の出荷を集計する団体WSTSの統計では、ICを「アナログ」「マイクロ」「ロジック」「メモリ」に分けます。CPUやマイコン(小さなコンピュータを1つにまとめたIC)は「マイクロ」に、電源管理のICは主に「アナログ」に入ります。カメラのイメージセンサのようなセンサや、光を扱う部品は、ICとは別に数えます。

2025年の世界の半導体の売上は7,917億ドルでした。米国半導体工業会(SIA)が2026年2月に発表した、WSTSのデータによる数字です。分類別では「ロジック」が3,019億ドル、「メモリ」が2,231億ドルで、2つで全体の約3分の2です。

もう一つの分け方として、多くの会社が買って使う汎用のICと、特定の製品のためだけに設計するICがあります。後者をASIC(特定用途向けIC)と呼びます。たくさん売れる製品ほど、専用に作る意味が大きくなります。

ICができるまで: まず設計する

ICは、作る前に、まずコンピュータの上で設計図を作ります。何十億個ものトランジスタを、人が1個ずつ描くことはできません。そこで、EDA(電子設計の自動化)と呼ぶ専用のソフトの助けを借ります。大まかな流れは次のとおりです。

  1. 仕様を決める: 何をするICか、速さや電力の目標を決めます。
  2. 働きを書く: 回路の動きを、プログラムに似た専用の言葉(ハードウェア記述言語)で書きます。
  3. 回路に直す: 書いた動きを、ソフトが、0と1を処理する小さな回路(論理ゲート)のつながりに変えます。この作業を論理合成と呼びます。
  4. 並べてつなぐ: 部品をチップの上に並べ、配線の道筋を決めます。これを配置配線と呼びます。
  5. 確かめる: 各段階で、回路をコンピュータの上で動かしてみて(シミュレーション)、正しく、決めた速さで動くかを確かめます。
  6. 製造側に渡す: 完成した設計データを、製造側に渡します。これをテープアウトと呼びます。

製造側は、設計データから、層ごとの模様を描いた原版(マスク)を作ります。そして工場で回路を作り込み、検査し、切り分けて、パッケージに入れます。この工場の中の流れは、前に紹介した「半導体チップはどうやって作られる?」で説明しています。

設計する会社と製造する会社が分かれていることも多く、その違いは「IDM・ファブレス・ファウンドリの違い」で比べられます。

ICと外の世界をつなぐ

ダイの表面には、外と信号や電気をやりとりする小さな電極が並んでいます。ダイとパッケージの土台は、細い金属の線で結ぶか、ダイを裏返して小さな金属の粒で直接つなぎます。この2つの方法は「ワイヤボンディングとフリップチップの違い」で比べられます。

パッケージから機器の基板へは、外側の端子でつなぎます。昔からある形は、パッケージの横から金属の足を出すものです。四辺から足を出したQFPは、今もよく使われる形です。例えば、家電の制御に使うマイコンに使われます。

端子の数が多いICでは、パッケージの裏一面に、はんだの小さな玉を碁盤の目のように並べます。この形をBGAと呼びます。辺だけでなく面全体を使えるので、たくさんの端子を並べられます。基板に載せて熱を加えると、玉が溶けて基板とつながります。

端子の数は、ICによって大きく違います。1971年のインテル4004の端子は16本でした。インテルのデスクトップ用CPU(第12〜14世代)は、裏に1,700個の平らな接点が並びます(LGA1700と呼ぶ形)。形の比べ方は「BGA・QFP・QFNの違い」にまとめています。

よくある誤解

誤解: ICといえばCPUのこと

実際は、CPUはICの一種にすぎません。スマホの中にも、メモリ、電源管理、音や電波を扱うICなど、仕事の違うICがいくつも入っています。売上の統計でも、CPUなどの「マイクロ」は、ICの4つの分類の一つです。ニュースでCPUやAI向けのチップが特に目立つため、この誤解が生まれます。

誤解: 基板の上の黒い四角が、チップそのもの

実際は、黒く見えるのは、多くの場合ダイを包むパッケージの樹脂です。本体のダイは中に入っていて、パッケージより小さいのがふつうです。例えば4004のダイは約3 mm×4 mmで、16本の端子のある細長いパッケージに収められていました。「チップ」という言葉が部品全体にも使われるため、この誤解が生まれます。

誤解: トランジスタが多いほど、必ず性能のよいICになる

実際は、性能は、トランジスタを何に使い、どう組み合わせたかで決まります。同じ作り方で数を増やすとダイが大きくなり、1枚のウエハから取れる数が減ります。良品の割合(歩留まり)も下がりやすく、値段や電力も上がりがちです。炊飯器のマイコンのように、小さく安いことが一番大事な用途もあります。新しいチップがトランジスタの数で紹介されることが多いため、この誤解が生まれます。
