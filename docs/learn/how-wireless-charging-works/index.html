ワイヤレス充電とは? 置くだけで充電できるしくみ

約13分 · 更新: 2026年10月23日

ワイヤレス充電は、充電台のコイルが作る「変化する磁界」で、スマホの中のコイルに電流を生ませるしくみです。この現象を電磁誘導と呼びます。金属の接点はいりませんが、2つのコイルを近づけて位置をそろえる必要があります。ケーブルより電気を多く使い、温かくなりやすいのが弱点です。

この記事でわかること

  • 置くだけで充電できる理由(電磁誘導)と、変圧器と似ている点・違う点
  • 充電台からスマホの電池まで、電気がどんな部品を通るか
  • 置く位置と距離が大事な理由と、磁石で位置を合わせるQi2
  • 硬貨を見つけて止める異物検出、ケーブルより遅く温かくなる理由
  • 電磁波の安全性や、電池が傷むかについての誤解

前提知識: 電圧と電流の大まかな意味。交流と直流の違いを知っていると読みやすくなります(「交流と直流の違いとは?」)。式は使いません。

身近なところでは

スマホを充電台に置くと、ケーブルを差さなくても充電が始まります。ワイヤレスイヤホンのケースや、スマートウォッチも同じです。台に置いたり、裏にくっつけたりするだけで電池がたまります。

もう一つの身近な例が、電動歯ブラシです。たとえばフィリップスの「ソニッケアー」は、充電台と持ち手の中に、それぞれコイルが入っています(分解記事、EE World)。持ち手に金属の差し込み口がないので、水にぬれる洗面所でも使いやすいのです。

埼玉大学の2016年の資料も、電動ひげそりや電動歯ブラシ、電話の子機などの充電に、この技術が欠かせないと説明しています。この記事では、スマホを中心に、置くだけで充電できるしくみを順に見ていきます。

しくみ1: 変化する磁界が、離れたコイルに電流を生む

電線をぐるぐると巻いた部品を、コイルと呼びます。コイルに電流を流すと、まわりに、磁石と同じように鉄を引きつけたり方位磁針を動かしたりする力の場ができます。この場を磁界と呼びます。

1831年、イギリスのマイケル・ファラデーは、鉄の輪に2つのコイルを巻いて実験しました。片方のコイルに電池をつないだり外したりすると、その瞬間だけ、もう片方のコイルに電流が流れました。つないだままにしておくと、何も起きませんでした(英国王立研究所)。

つまり、磁界が「変わる」ときに、近くのコイルに電圧が生まれるのです。この現象を電磁誘導と呼びます。大事なのは、変化が必要なことです。そこで充電台は、向きが1秒に約9万〜20万回入れ替わる電流をコイルに流して、磁界を変わり続けさせます(Qiの基本の方式。WPC)。

同じ原理で電圧を変える道具が、変圧器です。なぜ変化が必要なのか、交流とどう関係するのかは、「交流と直流の違いとは?」で説明しています。

たとえで言うと

ワイヤレス充電は、変圧器の鉄の芯を取り去り、2つのコイルを充電台とスマホに分けて入れたもの、と考えられます。似ているのは、電線でつながっていない2つのコイルの間を、変化する磁界がエネルギーを運ぶという一点です。

たとえが当てはまらない点: 変圧器では鉄の芯が磁界の通り道になり、片方の磁界のほとんどが、もう片方のコイルを通ります。ワイヤレス充電では、コイルの間にすき間やケースがあり、磁界の一部は相手に届かずに散らばります。どれだけ相手を通るかの目安(結合係数)は、変圧器でほぼ1、Qiでは0.5以下です(規格を作る団体WPCの資料。ここでは大まかに言い換えています)。そのため、変圧器にはない、位置合わせや強さの調整、相手との「会話」が必要になります。

しくみ2: コンセントから電池まで、電気の通り道

コンセントから電池まで、電気は何度も形を変えます。まず、ACアダプタがコンセントの交流を直流にします。充電台の中の送電用の半導体チップ(送電IC)は、その直流を細かくオン・オフして、速く向きが変わる電流に変え、コイルに流します。直流を交流に変えるこの働きを、インバーターと呼びます(「インバーターとは?」)。

スマホの側では、受電用のコイルに、向きの変わる電流が生まれます。受電用のチップ(受電IC)は、まずそれを一方向の流れにそろえます。この働きを整流と呼び、くわしくは「ダイオードとは?」で説明しています。受電チップには、ダイオードの代わりにトランジスタのスイッチで向きをそろえ、熱になる損失を減らすものもあります。これを同期整流と呼びます。

直流に戻った電気は、充電用のチップに渡されます。ここから先は、ケーブルで充電するときと同じです。電池に合った電流と電圧に整えて、決まった手順で充電します(「リチウムイオン電池とは?」)。

送る側と受ける側の「会話」

充電台とスマホは、充電の間ずっと合図をやり取りしています。受電チップは「もっと強く」「弱く」「満タンなので止めて」といった合図を送ります。自分の側で電気の受け取り方を細かく変え、その変化が充電台のコイルの電流の揺れとして伝わるしくみです。

この合図があるので、充電台は必要なぶんだけ送り、スマホのない台は送電を止めて待てます。Qiの初めのころの版では、合図は受ける側から送る側への一方通行でした。版1.2から、双方向でやり取りできるようになりました(WPC)。

しくみ3: なぜ置く位置と距離が大事なのか

充電台のコイルが作る磁界は、コイルの真上でいちばん強く、離れたり横にずれたりすると、急に弱まります。スマホのコイルを通る磁界が減れば、生まれる電圧も小さくなります。

足りないぶんを補うため、充電台は送る電流を増やします。すると、コイルや回路で熱になる電気も増えます。TDKは2016年の展示で、従来の方式の弱点を説明しています。2つのコイルの中心が10 mm以上ずれると、効率(送った電気のうち届く割合)が大きく落ちるというものです(MONOist)。

厚いケースや、背面に付けたリングなどをはさむと、距離が開いて同じことが起きます。置く場所を少しずらすだけで充電が遅くなったり、止まったりするのは、このためです。

しくみ4: 共振で、ゆるい結びつきを補う

コイルに、電気を一時的にためる部品(コンデンサ)を組み合わせます。すると、ある周波数(1秒に向きが入れ替わる回数)でだけ強く応える回路ができます。この現象を共振と呼びます。ラジオで一つの局だけを選べるのと同じ原理です(共振回路)。

ワイヤレス充電の充電台とスマホのコイルにも、コンデンサが組み合わされています。送る周波数の近くで共振させると、コイルどうしの結びつきがゆるくても、電気を送りやすくなります(STマイクロエレクトロニクス)。充電台は、周波数や電圧を少しずつ変えて、送る強さを調整します。

共振をもっと強く使えば、離れた所にも送れます。2007年、アメリカのMITの研究グループは、2 mを超える距離で60ワットを送りました。効率は約40 %でした(Science誌)。ただし、離れるほど効率は下がります。スマホで広く使われているのは、コイルを近づけて使う方式です。

しくみ5: 規格Qiと、磁石で合わせるQi2

違う会社の充電台とスマホでも充電できるのは、共通の決まりがあるからです。その決まりを作るのが、2008年に設立された業界団体、WPC(ワイヤレスパワーコンソーシアム)です。アップルやサムスンなど、多くの会社が加わっています。

WPCの規格の名前がQi(チー)です。最初の版は2010年7月に出て、送れる電力は5ワットでした。2015年の版1.2で、15ワットまで送れる段階が加わりました(WPC)。

2020年10月、アップルはiPhone 12で、MagSafe(マグセーフ)を始めました。充電コイルのまわりに磁石を輪のように並べ、充電器をぴたりと正しい位置に付けるしくみです(アップル)。発売当時のMagSafeの充電器は、最大15ワットでした。

2023年1月、WPCは、このMagSafeをもとにした新しい規格、Qi2を発表しました。アップルが技術を提供し、磁石で位置を合わせることが規格の中心です。規格に合うかを試験して合格の印を出す「認証」は2023年11月に始まり、当初の上限は15ワットでした。2025年7月には、上限を25ワットにした「Qi2 25W」が始まっています(WPC)。

ただし、実際の速さは、充電台とスマホの組み合わせで決まります。たとえばアップルの案内では、MagSafeやQi2でない、Qi認証の充電台の多くでは、iPhoneは最大7.5ワットです。

しくみ6: 硬貨やカードを見張る「異物検出」

電磁誘導は、コイルでなくても、近くの金属の中に電流を生みます。硬貨や鍵などの金属が、充電台とスマホの間にはさまると、金属の中を電流が渦のように回り、金属が熱くなります。IH調理器が鍋を温めるのとほぼ同じ原理です(埼玉大学)。

そこでQiの規格では、充電台が金属に気づいて、危ないときは送るのを止めるよう決めています。この働きを異物検出と呼びます。基本の考え方は、送った電力と、スマホが「受け取った」と知らせてくる電力を比べることです。差が大きければ、どこかで電気が熱になっていると判断します(WPC)。

WPCの資料には、認証のない充電器を独立した試験所で調べた例があります。金属をはさむと、200 °F(約93 °C)近くまで熱くなりました。やけどをするほどの温度です。Qiの認証マークのある充電器を選ぶのは、このためです。

カードにも注意が必要です。アップルは、スマホと充電器の間に物を置かないよう案内しています。クレジットカードの磁気の帯や、社員証のICチップを傷めるおそれがあるからです。カードを入れる手帳型のケースは、充電の前に中身を確かめましょう。

しくみ7: ケーブルより遅く、温かくなる理由

ワイヤレス充電では、電気が電池に届くまでに、ケーブルの充電にはない段階が加わります。送電ICでの切り替え、コイルからコイルへの受け渡し、受電ICでの整流です。そのどこでも、一部が熱になって失われます。

研究の総説で紹介された試作品の例では、5ワットを5 mmの距離で送って、効率は約70 %でした(Lu ほか、2016年)。修理情報サイトのiFixitが2024年に測った例でも、同じ充電にワイヤレスはケーブルより多くの電気を使いました。位置がずれると、むだはさらに増えます(しくみ3)。

失われた電気の多くは熱になります。しかも、その熱が出るのは、スマホの電池のすぐ近くです。電池は熱に弱いので、この熱は気になるところです。

アップルによると、iPhoneは充電中に少し温かくなります。温かくなりすぎると、80 %より先の充電を抑えることがあります。電池の寿命を守るためで、温度が下がると充電は再開します。「ワイヤレスは遅い」と感じる理由の一つは、ここにあります。

ほかのワイヤレス給電

交通系ICカードとNFC

改札にかざすICカードには、電池が入っていません。読み取り機は、向きが1秒に1356万回変わる磁界(13.56メガヘルツ)を出します。その磁界がカードの中のコイルに電流を生ませ、その電気でチップが動きます。返事は、カードが電気の受け取り方を変えて、磁界の揺れとして返します(STマイクロエレクトロニクス)。

この数センチの距離の通信を、NFCと呼びます。スマホのタッチ決済も、同じ方式です。送る電力はチップを動かすぶんだけで、スマホの充電とは大きさがまったく違います。

電気自動車のワイヤレス給電

電気自動車でも、駐車場の床に置いたコイルから、車の底のコイルへ送る方式が開発されています。アメリカの自動車技術の団体SAEは、乗用車向けの技術標準J2954を2020年に出しました。送る電力の大きさには3つの段階があり、いちばん上は約11キロワットです(SAE)。2024年の改訂版も、最大を11 kVA(キロボルトアンペア。交流の電力の大きさを表す単位)としています。

走りながら充電する実験もあります。2023年10月、東京大学などは千葉県柏市で、道路に埋めたコイルから走る車へ給電する、日本で初めての公道での実験を始めました。どちらも、スマホの充電ほど広くは使われていません。

よくある誤解

誤解: ワイヤレス充電なら、ケーブルはまったくいらない

実際は、充電台そのものはケーブルでコンセントにつながっています。ワイヤレスなのは、充電台とスマホの間だけです。しかも、スマホは台の上に正しく置いておく必要があり、手に持って使いながら充電できるケーブルほど自由ではありません。「線がない」より「接点がない」充電と考えると正確です。

誤解: 充電台の電磁波は、体に危ない

実際は、充電に使う磁界は、レントゲンのX線などとは違い、物質の原子から電子をはじき出すほどのエネルギーを持ちません。強い磁界による体への影響として知られているのは、神経への刺激と、体の温度の上昇です。国際的な委員会ICNIRPは、この2つを防ぐ上限を、余裕をもって指針に定めています。1秒に10万回の変化(100キロヘルツ)までは2010年、それより速い変化は2020年の指針です。また、磁界はコイルのすぐ近くでしか強くありません。

ただし、ペースメーカーなどの医療機器は別です。アップルは、ワイヤレスで充電している間は医療機器から30 cm以上離すよう案内しています。医療機器を使っている人は、医師やメーカーに確かめてください。

誤解: ワイヤレス充電は、それだけで電池をだめにする

実際は、電池の劣化を速める主な原因は、方式そのものより、熱と、満充電のまま長く置くことです(「リチウムイオン電池とは?」)。ワイヤレスは熱が出やすいので、その点では不利になりえます。位置を合わせて置く、熱のこもる布団の上などで充電しない、認証のある充電台を使う、といった工夫で、熱を減らせます。
