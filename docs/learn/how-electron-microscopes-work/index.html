電子顕微鏡(SEM・TEM)とは? 光では見えないものを見るしくみ

約14分 · 更新: 2026年10月23日

電子顕微鏡は、光の代わりに電子の流れを当てて、ものを大きく見る装置です。電子は、光よりずっと波長の短い「波」としてふるまいます。そのため、ふつうの光の顕微鏡では見分けられない数nmの形や、原子の並びまで見えます。表面の形を見るのがSEM、薄く切った試料の中を見るのがTEMです。

この記事でわかること

  • 光の顕微鏡では、約200nmより細かい形を見分けられない理由
  • 電子を使うと、なぜずっと細かく見えるのか
  • SEM(表面の形を見る)とTEM(中の構造を見る)のしくみと違い
  • 試料を真空に入れ、薄く切る準備が必要な理由
  • チップ工場での使われ方(線の幅の測定、欠陥の確認、故障の解析)

前提知識: 特にありません。チップが膜をつけて模様を写し、削る作業をくり返して作られることを知っていると、後半が読みやすくなります。くわしくは「半導体チップはどうやって作られる?」で説明しています。

身近なところでは: 白黒の、立体的な写真

理科の資料集で、花粉や虫の目を写した、白黒で立体的な写真を見たことはないでしょうか。毛の1本1本や、表面のでこぼこまでくっきり写っています。多くは電子顕微鏡で撮った写真です。

半導体のニュースでも、電子顕微鏡の写真はよく登場します。新しいスマホのチップを分解した調査記事には、チップを縦に切った断面の写真が載ります。細い配線や、小さなスイッチ(トランジスタ)が何層にも重なる様子は、電子顕微鏡でなければ写せません。

髪の毛の太さは、約8万〜10万nmです(アメリカ政府のナノテクノロジーの案内による)。nm(ナノメートル)は、1mmの100万分の1の長さです。チップの中の模様は、その数千分の1ほどの細かさです。この記事では、そんな世界をどうやって「見て」いるのかを説明します。

光の顕微鏡の限界: 波より細かいものはぼやける

光は波の性質を持っています。波の山から次の山までの長さを、波長と呼びます。目に見える光の波長は、およそ400〜700nmです。

波には、小さなすき間や物のふちで、回り込んで広がる性質があります。そのため、光で作った像は、どんなによいレンズを使っても少しぼやけます。ぼやけの大きさは、使う光の波長と同じくらいの大きさです。2つの点が近すぎると、ぼやけが重なって1つの点に見えてしまいます。

この限界は、ドイツのアッベが1873年に示しました。見分けられる2点の間隔は、よい条件でも光の波長のおよそ半分です。目に見える光を使う顕微鏡では、約200nmが限界の目安になります。この「見分けられる細かさ」を、分解能と呼びます。

なお、光る目印(蛍光)を使ってこの限界をこえる方法もあり、2014年のノーベル化学賞を受けました。細胞の中を見るための特別な方法なので、この記事では扱いません。

では、もっと波長の短い光を使えばよいのでしょうか。紫外線を使うと少しは細かく見えます。しかし、さらに波長の短い光は、ガラスのレンズに吸収されて通りません。この性質は「EUV露光とは?」でも説明しています。

たとえで言うと

海の大きな波が、細い棒のくいに当たる場面を考えてみましょう。波はくいを回り込んで進み、くいの後ろにもほとんど影ができません。波の側から見ると、くいの太さや形は「わからない」のです。似ているのは「波は、自分の波長よりずっと小さいものの形を写せない」という一点です。

たとえが当てはまらない点: 海の波は水そのものが動きますが、光は水のような何かが揺れているわけではありません。また、顕微鏡はレンズで光を集めて像を作るので、波が「影を作るかどうか」だけで見え方が決まるわけでもありません。たとえで伝えたいのは、波長が細かさの限界を決める、という点だけです。

電子も「波」としてふるまう

電子は、すべての原子の中にある、とても小さな粒です。マイナスの電気を帯びていて、電線を流れる電流の正体でもあります。ところが電子は、粒でありながら、光と同じように波の性質も持っています。

この考えは、フランスのド・ブロイが1924年に唱えました。その後、原子が規則正しく並んだ結晶に電子を当てると、光と同じように波どうしが強め合う模様ができることが確かめられました。この2つの成果には、1929年と1937年のノーベル物理学賞が贈られています。電子が波としてふるまう話は「トンネル効果とは?」でも扱っています。

電子の波長は、電子が速いほど短くなります。電子を速くするには、高い電圧で引っぱります。この電圧を加速電圧と呼び、kV(キロボルト、1kVは1,000ボルト)で表します。100kVで加速した電子の波長は、約0.0037nmです。目に見える緑の光(約550nm)のおよそ15万分の1です。

電子はマイナスの電気を帯びているので、磁石の力で進む向きを曲げられます。電線を巻いたコイルに電流を流すと、レンズのように電子を集められます。ドイツのルスカは1931年、クノールとともに、このしくみで最初の電子顕微鏡を組み立てました。1933年には光の顕微鏡をはっきり上回る性能に達し、ルスカは1986年にノーベル物理学賞を受けています。

ただし、電子のレンズは、ガラスのレンズほど理想どおりには電子を集められません。この像のゆがみを収差(しゅうさ)と呼びます。そのため、実際に見分けられる細かさは、電子の波長よりずっと粗くなります。それでも、最高性能のものは、光の顕微鏡より千倍以上細かく見えます。

電子顕微鏡の中は、空気を抜いた真空にします。空気の分子にぶつかると、電子は向きを変えたり止まったりしてしまうからです。電子を出す部品(電子銃)も、空気があると傷んでしまいます。

SEM: 電子の点で表面をなぞり、形を見る

電子顕微鏡には、大きく分けて2つの種類があります。1つめは、電子の細い流れ(ビーム)をさらに絞り、試料の表面をなぞって像を作る顕微鏡です。これをSEM(走査電子顕微鏡)と呼びます。「走査」は、なぞるように順に動かすという意味です。市販の最初のSEMは、1965年にイギリスで発売されました。

SEMは、電子のビームを、幅数nmの小さな点に絞ります。この点を、本の文字を読むように左から右へ、上から下へと少しずつずらしていきます。ビームが当たった点からは、試料の中にあった電子がたたき出されて飛び出します。この電子を二次電子と呼びます。

装置は、飛び出した二次電子を受け止める部品(検出器)で、その数を点ごとに数えます。多ければ明るく、少なければ暗くして、画像の1つの点(画素)にします。全部の点を並べると、1枚の白黒の画像になります。つまりSEMの画像は、レンズで像を結んだものではなく、点ごとの測定値を並べたものです。

二次電子は勢いが弱く、表面のごく浅い所で生まれたものだけが外に出られます。斜面や角では、表面に近い所が多いので、たくさん飛び出します。そのため、ふちや斜面が明るく光り、影のついた立体的な写真に見えるのです。高性能な装置では、1nm以下の細かさまで見分けられます。

たとえで言うと

真っ暗な部屋で、細い懐中電灯の光を壁に当てる場面を考えます。光の点を少しずつずらし、点ごとに「明るく見えたか」をメモします。メモを並べると、壁の模様が1枚の絵になります。似ているのは「1点ずつ順に調べて、あとで並べて画像にする」という一点です。

たとえが当てはまらない点: 懐中電灯では、当てた光がそのまま跳ね返って目に入ります。SEMで主に数えるのは、当てた電子ではなく、試料の中からたたき出された別の電子(二次電子)です。また、SEMの明るさは色の違いではなく、主に表面の傾きや角で決まります。

電気を通さない試料には、注意が必要です。当たった電子の逃げ場がなく、表面に電気がたまって、像がゆがむからです。そこで、表面に金属や炭素のごく薄い膜をつけたり、加速電圧を下げたりして防ぎます。

TEM: 薄い試料に電子を通し、中を見る

2つめは、電子を試料に通り抜けさせ、反対側に出てきた電子で像を作る顕微鏡です。これをTEM(透過電子顕微鏡)と呼びます。「透過」は、通り抜けるという意味です。ルスカが最初に作った電子顕微鏡も、この種類でした。

TEMでは、ふつう80〜300kVの高い電圧で電子を加速します。それでも電子が通り抜けられるのは、とても薄い試料だけです。そのため、試料を厚さ100nmほど以下まで薄く削ります。髪の毛の太さの、1,000分の1ほどの薄さです。

試料の中で、重い原子が多い所や厚い所は、電子を大きく散らします。散らされた電子は像に届きにくいので、そこが暗く写ります。通り抜けた電子をレンズで何段も拡大し、カメラで写します。ここでは、いちばん基本の見え方だけを説明しています。

TEMの強みは、中の構造を原子のレベルで見られることです。シリコンの結晶では、となり合う原子の中心の間隔は約0.235nmです。収差を補正した最高性能のTEMでは、0.05nmの細かさが確かめられています。アメリカのローレンス・バークレー国立研究所が2008年に発表しました。原子が並んだ列が、点の並びとして写ります。

電子が当たった試料からは、元素ごとに決まったエネルギーのX線も出ます。このX線を調べると、その場所に何の元素があるかがわかります。この分析をEDXと呼び、SEMやTEMに取りつけて使います。

2つの違いは「SEMとTEMの違い」で、分解能・準備の手間・速さ・費用などを表にしています。ざっくり言えば、SEMは速くて手軽、TEMは手間がかかるぶん、中まで細かく見えます。

試料の準備: 真空に入れ、薄く切り出す

電子顕微鏡で見る試料は、真空の中に入れます。そのため、水を含んだ生き物などは、そのままでは見られません。乾かしたり固めたりする準備が必要です。シリコンのチップは乾いた固体なので、この点では扱いやすい試料です。

TEMの準備は、さらに大変です。チップの、たった1か所の不良を見たいとき、その場所を狙って薄い板を切り出す必要があります。ここで使うのが、電気を帯びた原子(イオン)のビームで、試料を削る装置です。これをFIB(集束イオンビーム)と呼びます。

FIBは、ガリウムという金属のイオンを細く絞って当て、原子を少しずつはじき飛ばして削ります。まず、見たい場所の上に、保護のための金属の膜をつけます。その両側を深く掘り、間に残った薄い壁を切り離して取り出します。最後に厚さ100nmほど以下まで薄くして、TEMに入れます。

多くのFIBにはSEMも組み込まれていて、削る様子を見ながら作業できます。準備には、数時間かかることも珍しくありません。切り出したチップは元に戻せないので、製品の一部を抜き取って調べます。

チップ工場での使われ方

線の幅を測る: CD-SEM

チップは、シリコンの円い薄い板(ウエハ)の上に作ります。工場では、光で模様を写したあとや削ったあとに、模様の線の幅が設計どおりかを確かめます。この測定に使う専用のSEMを、CD-SEMと呼びます。CDは、測りたい大事な寸法(クリティカル・ディメンジョン)の略です。日立(今の日立ハイテク)は、1984年に最初のCD-SEMを製品にしたと説明しています。

CD-SEMは、ウエハの上から模様をなぞり、二次電子が多く出る線のふちの位置から幅を計算します。模様を写すために塗る薬剤(フォトレジスト)は、電子が当たると傷みやすい材料です。そのため、1kVほどか、それより低い加速電圧で、そっと測ります。測った結果は、模様を写す工程(露光)の条件の調整に生かされます。

欠陥を確かめる: レビューSEM

ウエハ全体からごみや模様の欠けを探すのは、光を使う欠陥検査装置の役目です。光は速く広い範囲を調べられますが、見つけた欠陥の形まではよくわかりません。そこで、見つけた場所にSEMで近づいて撮影し、欠陥の種類を確かめます。こうした使い方をするSEMを、レビューSEMと呼びます。

最近の装置は、撮った画像から欠陥の種類を自動で分類します。どんな欠陥が、どの工程で増えたかがわかれば、原因の装置や条件を早く突き止められます。良品の割合(歩留まり)を上げるための、大事な仕事です。

故障の原因を探る: FIBとTEMで断面を見る

できあがったチップが動かないとき、どこが壊れているのかを調べる作業を故障解析と呼びます。電気の測定で怪しい場所を絞り込み、FIBでその場所の断面を出して、SEMやTEMで見ます。配線のすき間や、膜のはがれ、異物などが見つかります。

トランジスタの中には、厚さが数nmしかない膜もあります。たとえば、電気の流れを開け閉めする部分を区切る、電気を通さないごく薄い膜です。こうした膜の厚さや、層と層の境目の様子を確かめるには、TEMが欠かせません。EDXを組み合わせれば、どの層にどの元素があるかも調べられます。

よくある誤解

誤解: 倍率を上げれば、いくらでも細かく見える

実際は、細かく見えるかどうかを決めるのは、倍率ではなく分解能です。ぼやけた像をいくら大きく引き伸ばしても、ぼやけが大きくなるだけです。SEMの倍率も、画面の大きさと、なぞった範囲の大きさの比にすぎません。光の顕微鏡で倍率だけを上げても、約200nmより細かいものは見分けられません。顕微鏡の宣伝で倍率の数字が目立つため、生まれやすい誤解です。

誤解: 光の検査では、200nmより小さい欠陥は見つけられない

実際は、「形を見分ける」ことと「あることに気づく」ことは別です。とても小さなごみでも、光を当てると、わずかに光を散らします。その散った光をとらえれば、形はわからなくても、そこに何かあることはわかります。ウエハの検査装置は、このしくみで、200nmよりずっと小さな欠陥も見つけています。形を確かめるのは、そのあとのレビューSEMの仕事です。

誤解: 電子顕微鏡なら、チップを壊さずに中まで見られる

実際は、SEMで上から見るだけなら、ウエハを壊さずに済みます。CD-SEMはそのための装置です。しかし、中の構造をTEMで見るには、FIBで薄い板を切り出す必要があり、そのチップは使えなくなります。断面の写真が手軽に見られるため、どれも同じように非破壊で見られると思われがちです。
