データセンターとは? クラウドとAIを支える建物の中身

約14分 · 更新: 2026年10月23日

データセンターは、たくさんのコンピュータ(サーバ)を、電気・冷房・通信の設備と一緒に置いた建物です。「クラウド」もAIのサービスも、実際にはこうした建物の中で動いています。建物には、止まらずに電気を送り、出てくる熱を捨てるための大きな設備も欠かせません。

この記事でわかること

  • データセンターの中に並んでいるもの(ラック・サーバ・ストレージ・スイッチ)
  • 電気が届く道すじと、停電に備えるUPSのしくみ
  • 熱の捨て方と、AIのために広がる液冷
  • 効率を表すPUEの読み方と、世界の電気に占める割合
  • 止めないための「予備」の考え方と、中で働くチップ

前提知識: 特にありません。「クラウドはよその会社のコンピュータを借りること」だと知っていると読みやすくなります(「クラウドとは?」)。

身近なところでは

チャットのAIに質問すると、数秒で答えが返ってきます。その答えを作っているのは、手元のスマホではありません。遠くの建物に置かれた、たくさんのコンピュータです。動画の配信や、写真の保存、ネットの検索も同じです。

スマホからの問い合わせは、インターネットを通ってその建物に届きます(しくみは「インターネットはどうやってデータを届けるの?」)。この記事では、届いた先の建物の中を見ていきます。

データセンターは「コンピュータのための建物」

求めに応じてデータを返したり、計算したりするコンピュータを「サーバ」と呼びます。データセンターは、サーバを何千台、何万台とまとめて置くための建物です。人が働くためのビルではなく、機械が働きやすいように作られています。

機械のために必要なものは、主に3つです。途切れない電気、熱を捨てる冷房、外とつながる太い通信の回線です。これらを一か所にまとめて用意すると、1台ずつ別々に置くより安く、確実に面倒を見られます。

中に並ぶもの: ラック・サーバ・ストレージ・スイッチ

中に入ると、背の高い金属の棚が、何列にも並んでいます。この棚を「ラック」と呼びます。幅などの規格がそろっているので、多くの会社の機械を同じ棚に収められます。

ラックには、薄い箱の形をしたサーバが、引き出しのように何台も重ねて入っています。1台のサーバの中身は、パソコンとよく似ています。計算をするCPU、作業中のデータを置くメモリ、データをしまっておく装置があります。

データをためることを専門にした機械もあります。これを「ストレージ」と呼びます。中には、電気でデータを覚えるSSDや、回る円盤に磁気で記録するハードディスクが、たくさん入っています。

サーバどうしや外の回線をつなぎ、届いたデータを宛先のサーバへ振り分ける機械もあります。この機械を「スイッチ」と呼び、ラックごとに置くことがよくあります。家のルータとの違いは「ハブ・スイッチ・ルータの違い」で表にしています。

サーバの部屋の外には、電気を受けて配る設備、停電に備える電池や発電機、冷房の機械の部屋があります。こうした「サーバを止めないための設備」も、建物の大きな場所を占めます。

電気の道すじ: 送電網からチップまで

データセンターは、電力会社の送電網から電気を受け取ります。遠くまで送るために、送電網の電気は電圧がとても高くなっています。そこで、まず電圧を下げる装置を通します。この装置を変圧器と呼びます。

次に通るのが、停電に備える装置です。電池をつないでおき、停電した瞬間から電池の電気を送り続けます。この装置を「UPS」(無停電電源装置)と呼びます。サーバは、電気がわずかな時間途切れるだけでも止まることがあるので、UPSが欠かせません。

電池では長い停電をしのげないので、燃料で動く非常用の発電機も用意します。発電機は、動き出して安定した電気を送れるまでに少し時間がかかります。その間をUPSの電池がつなぎ、その後は発電機が電気を送ります。

UPSの中では、電気の形を変える部品が働いています。コンセントの電気は、向きが行き来する「交流」です。これを一度、向きが一定の「直流」に変えて電池とつなぎ、また交流に戻して送り出す方式がよく使われます。この変換をするのが、パワー半導体です。しくみは「パワー半導体とは?」で説明しています。

UPSを出た電気は、ラックごとに分けて配られます。この配電の装置を「PDU」と呼びます。最後に、サーバの中の電源が、交流を直流に変えて電圧を下げます(くわしくは「交流と直流の違いとは?」)。

CPUなどのチップは、1ボルト前後の低い電圧で動きます。そこで基板の上でも、直流の電圧をもう一段下げます。この変換をする回路をDC-DCコンバータと呼びます。チップのすぐ近くに置き、大きな電流を送り込みます。

変換のたびに、電気の一部は熱になって失われます。損失を減らす工夫として、Googleは2016年、ラックの中を48ボルトの直流で配る設計を公表しました。2010年から使い、12ボルトで配るより損失が減ったと説明しています。

熱の捨て方: 空気で冷やす

サーバが使った電気は、計算をしたあと、最後はほとんどすべて熱になります。熱を捨て続けないと、チップの温度が上がりすぎて止まったり、壊れたりします。

多くのデータセンターは、空気で冷やします。サーバは、前から冷たい空気を吸い込み、温まった空気を後ろへ吐き出します。冷たい空気と熱い空気が混ざると、冷房のむだが増えます。

そこで、ラックの列の向きをそろえます。前どうしを向かい合わせると、間の通路には冷たい空気だけが流れます。後ろどうしの間の通路には、熱い空気が集まります。この並べ方を「ホットアイル・コールドアイル」と呼びます(アイルは通路のことです)。米国エネルギー省の設計の手引きでも、空気の管理の基本として紹介されています。

集めた熱い空気は、冷房の機械で冷やしてから、また冷たい通路へ送ります。外の空気が冷たい季節や地域では、外気を使って冷房の電気を減らす方法もあります。

AIで変わったこと: 1台のラックの電気が桁違いに

チップが標準的な重い仕事をしたときに出す熱の目安を、TDPと呼びます。冷やす装置は、この値を目安に設計します。AI用のGPUであるNVIDIAのH100は、高性能な版で最大700ワットです。

NVIDIAの資料では、このGPUを8個積んだサーバ「DGX H100」は、1台で最大10.2キロワットを使います。1キロワットは1,000ワットです。一方、Uptime Instituteの2024年の調査では、回答した施設のラックの平均は8キロワット未満でした。AI用のサーバ1台が、平均的なラック1台分より多くの電気を使いうる計算です。

さらに、ラック1台を丸ごと1つの大きな計算機として作る製品も出てきました。NVIDIAのGB200 NVL72は、GPU72個とCPU36個を1台のラックにまとめたものです。HPEの製品の資料では、このラック1台で132キロワットを使います。平均(8キロワット未満)の16倍を超えます。

ただし、これはまだ一部の最先端の例です。Uptime Instituteの2025年の調査では、全体では10〜30キロワットのラックが増えつつある段階でした。30キロワットを超える施設は、まだ少数です。

電気や冷房の上限を超えないように、サーバの電力に上限を決めて抑えることもあります。これをパワーキャップと呼びます。それでも足りないほど熱が集まるときに使われるのが、次の液冷です。

液冷: 水などの液体で熱を運ぶ

空気は、熱を運ぶ力があまり強くありません。同じ体積で比べると、水は空気よりずっと多くの熱を運べます。そこで、チップのすぐ上に、液体が中を流れる金属の板を当てて冷やす方法が広がっています。この方法を「液冷」と呼びます。

板で受け取った熱は、液体と一緒に配管でラックの外へ運ばれます。そこで別の水と熱を受け渡し、最後は建物の外へ捨てます。HPEの資料では、GB200 NVL72の132キロワットのうち115キロワットを液冷で、残りを空気で冷やします。

サーバを、電気を通さない特別な液体にまるごと沈めて冷やす方法もあります。どの方式でも、配管や液の管理という新しい手間が増えます。

PUE: 電気のうち、どれだけがコンピュータに届くか

データセンターの電気は、サーバだけでなく、冷房や電源の変換のむだにも使われます。建物全体の電気を、コンピュータなどのIT機器が使う電気で割った値をPUEと呼びます。IT機器が使う分を1としたとき、全体でどれだけ使っているかを表す数字です。

例えば、PUEが1.5なら、IT機器が1使うごとに、冷房などで0.5を余分に使っています。PUEが1.0なら余分がゼロで、電気をすべてIT機器に届けている理想の状態です。現実には、冷房も変換の損失もゼロにはできないので、1.0より大きくなります。

Uptime Instituteの世界の調査では、回答した施設の平均は2024年が1.56、2025年が1.54でした。世界のすべての施設の平均ではありませんが、ここ数年ほぼ横ばいです。古い建物が多く、気候によっては冷房を減らしにくいためと、同社は説明しています。大手はもっと低く、例えばGoogleは2024年の自社の大規模なデータセンター全体で1.09と公表しています。

たとえで言うと

PUEは、通販で払う「総額」を「品物の値段」で割った値に似ています。品物が1,000円で、送料と手数料が500円なら、1,500÷1,000で1.5です。似ているのは「本当に欲しいもの以外に、どれだけ余分に払っているか」を表す点です。

たとえが当てはまらない点: 通販の割り算からは、品物そのものが値段に見合うかはわかりません。PUEも同じで、サーバが電気をむだなく計算に使っているかは表しません。また、送料は季節で変わりませんが、PUEは外が暑い夏に上がりやすくなります。

世界の電気の、どれくらいを使っているのか

電気の量は、TWh(テラワット時)という単位で表します。1TWhは10億キロワット時です。国際エネルギー機関(IEA)の2025年の報告では、2024年の世界のデータセンターの電気は約415TWhでした。世界の電気の約1.5%に当たります。

IEAは2026年4月の報告で、2025年は約485TWhに増えたと推計しています。2030年には約950TWhと、2025年のおよそ2倍になる見込みです。そのころには、世界の電気の約3%を占めることになります。増える分の大きな理由が、AI用のサーバです。

ただし、これは見込みです。半導体や発電所、送電線の準備が間に合うかで変わり、IEAもこうした供給の制約が当面の伸びを抑えると述べています。

止めないための工夫: 予備を用意する

データセンターは、どの機械もいつか壊れる、と考えて設計します。そこで大切になるのが、1か所が止まるだけで全体が止まる場所をなくすことです。そうした弱い場所を単一障害点と呼びます。

よく使われるのが「N+1」という考え方です。必要な台数をNとして、1台多く用意しておきます。例えば、冷房が4台で足りるなら5台置きます。1台が壊れても、点検で止めても、残りの4台で冷やし続けられます。

たとえで言うと

N+1は、車に積む予備のタイヤに似ています。4本で走る車に、もう1本を用意しておく考え方です。似ているのは「必要な数より1つ多く持ち、1つ壊れても続けられる」という点です。

たとえが当てはまらない点: 予備のタイヤは、車を止めて付け替えないと使えません。データセンターのN+1では、予備も一緒に動いているか、自動で動き出すので、止まらずに引き継ぎます。なお、2つが同時に壊れると足りなくなる点は、どちらも同じです。

さらに手厚くするなら、必要な一式をまるごと2組そろえます。これを「2N」と呼びます。片方の組がすべて止まっても、もう片方で動き続けられます。そのぶん費用は高くなります。

建物の備えの度合いを表す格付けもあります。代表的なのが、Uptime Instituteの「Tier」(ティア)という4段階です。ティアは「段」のことです。Tier Iは予備のない基本の作りで、点検のときは全体を止めます。Tier IIは、UPSや冷房などの機械に予備を持ちます。Tier IIIは、電気や冷房の道も2本にして、どの設備もサービスを止めずに点検できる作りです。Tier IVは、さらに機械1台の故障や道の1か所の切断が起きても止まらない作りです。

クラウドの事業者は、こうした建物を同じ地域に複数用意します。電源や冷房が互いに独立した建物のまとまりを、アベイラビリティゾーンと呼びます。建物ごと止まっても、別のまとまりで続けられるようにするためです。

データセンターの中で働くチップ

データセンターは、半導体のチップのかたまりでもあります。計算だけでなく、記憶や通信、電気の変換にもチップが働いています。

サーバをネットワークにつなぐ部品を、NICと呼びます。ケーブルを差す口と、送り受けを受け持つチップが一体になっています。AIの計算では、何千ものGPUが互いにデータをやり取りします。そのため、通信の速さが計算の速さを左右するようになっています。

スイッチの中心には、データの振り分けだけに絞った専用のチップが入っています。このように、1つの用途のために作ったチップをASICと呼びます。何でもこなすCPUより、決まった仕事をずっと速く、少ない電気でこなせます。主なチップを表にまとめます。

よくある誤解

誤解: クラウドのデータは「空の上」のどこかにある

実際は、データはどこかの国のデータセンターの、ラックの中の装置に保存されています。通信も、多くは地面の下や海の底の光ファイバを通ります。「クラウド(雲)」という呼び名から生まれやすい誤解です。

誤解: データセンターは、もう世界の電気の大きな部分を使っている

実際は、IEAの推計では2024年で世界の約1.5%、2030年の見込みでも約3%です。ただ、データセンターが集まる地域では割合がずっと大きく、送電網の負担になります。AIの電気のニュースが多いので、世界全体の割合も大きく見えやすいのです。

誤解: PUEが低いデータセンターほど、使う電気が少ない

実際は、PUEは「全体の電気÷IT機器の電気」という割合です。冷房などの余分が少ないことはわかりますが、使う電気の量そのものはわかりません。PUEが低くても、サーバがたくさんあれば、電気はたくさん使います。「効率」と「量」を混ぜてしまう誤解です。

もっと詳しく学ぶ

  • 計算で試す: 稼働率の計算ツール(機械を2台にすると、止まる時間がどれだけ減るか)
  • 計算で試す: チップの温度の計算ツール(消費電力と冷やしやすさから、チップの温度を求める)
  • 違いを表で見る: SSDとHDDの違い、CPU・GPU・NPUの違い
  • 次の一歩の用語: RAID(複数のディスクでデータを守る)、ロードバランサ(仕事をサーバに振り分ける)、熱抵抗(熱の逃げにくさ)
