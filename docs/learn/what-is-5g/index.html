5Gとは? 4Gと何が違うのか、速さと遅延のしくみ

約13分 · 更新: 2026年10月23日

5Gは、携帯電話の通信の第5世代の規格です。4Gより広い幅の電波と、電波を相手の向きに絞るアンテナなどで、速さ・遅れの小ささ・つなげる数を高めました。ただし「最大20 Gbit/s」「1ミリ秒」は国際機関の目標の値で、実際の速さは場所や電波の種類で大きく変わります。

この記事でわかること

  • 携帯電話の「世代」とは何で、誰が決めているか
  • 5Gの3つの目標と、実際の速さが目標よりずっと低い理由
  • サブ6とミリ波の違いと、ミリ波に小さな基地局がたくさん要る理由
  • 「5G」表示の中身(NSAとSA)と、電波の安全の基準

前提知識: 特にありません。「Wi-Fiのしくみとは?」を先に読むと、電波の幅やアンテナの話がわかりやすくなります。

身近なところでは

スマホの画面の上には、「5G」や「4G」の表示が出ます。携帯電話会社の広告では、5Gは「高速・大容量」「低遅延」とうたわれます。ところが5Gの表示が出ていても、4Gのときと速さが変わらないと感じることがあります。

この記事では、5Gが何を目指して作られたかを見ていきます。そのうえで、目標と実際の差がどこから来るのかを順に説明します。

「世代」は、約10年ごとの作り直し

携帯電話の通信は、約10年ごとに大きく作り直されてきました。日本では1979年に、自動車電話として第1世代が始まりました。1993年の第2世代で、音声をデジタルの0と1で送るようになりました。その後、2001年に第3世代が始まりました。5Gは、2020年3月にNTTドコモ・au・ソフトバンクが、9月に楽天モバイルが始めました。

世代が変わると、電波にデータを乗せる方法や、電波の使い方の決まりが変わります。新しい世代の電波を使うには、対応したスマホと基地局が要ります。基地局は、ビルの屋上や鉄塔にある、携帯電話の電波を出し入れする設備です。

世代の目標を決めるのは、国連の専門機関の国際電気通信連合(ITU)です。どんな性能を目指すかを、数字で示します。目標を満たす具体的な技術の決まりは、別の団体が作ります。

その中心が、世界の通信会社やメーカーが集まる3GPPです。3GPPは仕様を「リリース」という版にまとめて出します。5Gの最初の版はRelease 15です。4Gの設備と組み合わせる形が2017年12月に、5Gだけで動く形が2018年6月に承認されました。

実は、2010年に始まったLTEは、日本では当初「3.9世代」とも呼ばれました。ITUが決めた4Gの条件を満たすのは、その発展版のLTE-Advancedだったからです。今はLTEも含めて「4G」と呼ぶのが普通です。世代の名前には、宣伝の言葉としての面もあります。

5Gの3つの目標

ITUは2015年に、5Gで目指す使いみちを3つにまとめました。1つ目は、動画などの大きなデータを速く送ることです。これを「高速・大容量」と呼び、英語の頭文字でeMBBと書きます。

2つ目は、遅れがごく小さく、途切れにくい通信です。工場の機械を離れた場所から動かすような使い方を想定しています。これを「超高信頼・低遅延」と呼び、URLLCと書きます。

3つ目は、とても多くの機器を同時につなぐことです。電気やガスのメーターやセンサのように、少しのデータを時々送る機器を想定しています。これを「多数同時接続」と呼び、mMTCと書きます。

2017年にITUは、5Gと認めるための性能の最低ラインを数字で示しました。速さの単位のGbit/sは、1秒に10億ビットです。ビットは、0か1かの1けたです。msはミリ秒、つまり1000分の1秒です。

これらは、決められた条件で計算や試験をして確かめるための目標です。利用者が実際に得られる速さを約束する数字ではありません。なお、Mbit/sは1秒に100万ビットで、下りはスマホが受け取る向きです。

実際の速さが、目標よりずっと低い理由

20 Gbit/sは、1台のスマホが基地局の電波をすべて使えたときの値です。実際には、近くにいる人どうしで1つの基地局の電波を分け合います。基地局から離れたり建物の陰に入ったりして電波が弱まると、1回に乗せるデータを減らして確実に送るので、さらに遅くなります。

携帯電話会社が使える電波の幅にも限りがあります。2020年3月にNTTドコモが5Gを始めたときの最大は、受信で3.4 Gbit/sでした。これも最良の条件の値で、速度を測るアプリの数字はふつう、さらに小さくなります。

遅れの「1ミリ秒」も、スマホと基地局の間の無線区間だけの、片道の目標です。その先には、通信会社の設備やインターネットの長い道のりがあります。光ファイバの中を光が進む速さは、1秒に約20万kmです。片道500 kmの相手なら、往復するだけで約5ミリ秒かかります。

データを送ってから返事が戻るまでの時間を、RTTと呼びます。体感の遅さは、無線区間よりも、このRTT全体で決まります。遅れを本当に小さくしたい用途では、処理をするコンピュータ(サーバ)を、利用者の近くに置く工夫も組み合わせます。

電波の帯域: サブ6とミリ波

携帯電話の電波は、1秒に何億〜何百億回も振動します。その回数を周波数と呼びます。速くするいちばんの近道は、使う周波数の範囲、つまり電波の幅を広げることです。幅を2倍にすると、同じ時間に送れる量もおよそ2倍になります。これはWi-Fiのチャネルの幅と同じ考え方です(「Wi-Fiのしくみとは?」)。ところが、4Gまでに使ってきた低い周波数には、空きがほとんどありません。

そこで5Gでは、より高い周波数の、広い幅が使えるようにしました。日本では2019年4月に、5G用の電波が携帯電話会社4社に割り当てられました。GHzは1秒に10億回、MHzは100万回です。3.7 GHz帯と4.5 GHz帯は1枠100 MHz幅、28 GHz帯は1枠400 MHz幅です。このうち6 GHzより低い帯域を、「サブ6」と呼びます。

28 GHz帯のような高い帯域は、「ミリ波」と呼ばれます。波の山から山までの長さ(波長)が、約1 cmと短いからです。厳密にはミリ波は30 GHz以上を指し、28 GHzは少し手前ですが、業界ではまとめてミリ波と呼んでいます。

一般に、周波数が高い電波ほど、物の陰に回り込みにくく、遠くで弱まりやすい性質があります。ミリ波は、壁や窓ガラス、人の体や手でも弱まります。サブ6は広い範囲を覆いやすく、ミリ波は狭い範囲で大量に送るのに向きます。Wi-Fiの2.4 GHz帯と5 GHz帯の関係と同じ傾向です。

ミリ波を生かす: 小さな基地局と、電波を絞るアンテナ

1つの基地局が受け持つ範囲を、セルと呼びます。ミリ波はセルが小さいので、広い範囲を覆うには基地局がたくさん要ります。そこで駅前や競技場のように人が集まる場所に、小さな基地局を集中して置きます。このような小さなセルを、スモールセルと呼びます。

もう1つの工夫は、電波を必要な向きに絞って送ることです。基地局に小さなアンテナを数十〜数百個並べ、それぞれが波を出すタイミングを少しずつずらします。すると、ある向きでは波の山がそろって強め合い、ほかの向きでは弱め合います。これをビームフォーミングと呼びます。

アンテナの数を大幅に増やし、何台かのスマホに別々のビームを同時に向けるしくみを、Massive MIMOと呼びます。同時に別々のデータを送るMIMOの考え方を、大きく広げたものです。サブ6の基地局でも使われ、たとえば3.5 GHz付近で64組のアンテナを並べた装置があります。

ミリ波は波長が短いので、1つ1つのアンテナを小さくできます。そのため、手のひらほどの板にも多くのアンテナを並べられます。ミリ波が届きにくい弱点を、電波を絞って補うわけです。

たとえで言うと

部屋全体を照らす裸電球と、一方向を照らす懐中電灯の違いに似ています。同じ明るさの光でも、一方向に集めれば遠くまで届きます。似ているのは「電波を広くまき散らさず、相手の向きに集めると遠くまで届く」という点です。

たとえが当てはまらない点: 懐中電灯は反射板で光を集めますが、ビームフォーミングは多くのアンテナの波が強め合う向きを作ります。向きは手で動かさずに一瞬で変えられ、別々の相手に同時に何本も向けられます。また、絞った向きの外にも弱い電波は出ています。

「5G」表示の中身: NSAとSA

携帯電話会社の中には、利用者の確認や、データの行き先を管理する中心の設備があります。これをコアネットワークと呼びます。基地局は、スマホとコアネットワークの間をつなぐ入り口の役です。

5Gを早く始めるため、初めのころの5Gの多くは、4Gの設備と組み合わせて作られました。スマホは4Gと5Gの両方の基地局につながり、つながりの管理は4Gが受け持ちます。データの多くは5Gの電波で運び、コアネットワークは4G用のものを使います。この方式をNSA(ノンスタンドアロン)と呼びます。

NSAなら、すでにある4Gの設備を生かせるので、早く安く始められます。5Gの基地局とコアネットワークだけで動く方式は、SA(スタンドアロン)と呼びます。5Gの新しい機能の多くは、5G用のコアを使うSAで生かせます。日本では2021年10月にソフトバンクが国内で初めてSAの商用サービスを始め、各社が順に広げています。

もう1つ、4G用の周波数を5Gの方式で使う「転用」もあります。広い範囲を早く5Gにできますが、電波の幅は4Gと同じなので、速さは4Gと同じくらいです。NTTドコモも、4Gの周波数を使った5Gの速さは「4Gと同等」と案内しています。

ネットワークスライシング: 1つの設備を用途ごとに切り分ける

5Gの3つの目標は、求めるものがばらばらです。動画は速さ、機械の遠隔操作は遅れの小ささ、メーターは数の多さを求めます。そこで5G用のコアを使うSAでは、同じ設備の上に、性質の違うネットワークを、見かけ上いくつも作れます。これをネットワークスライシングと呼びます。

例えば、ある工場向けに、遅れの小ささを優先した切り分けを用意できます。切り分けは、ソフトウェアの設定で作ったり、広さを変えたりできます。ここでは話を簡単にしています。実際に何を選べるかは、通信会社のサービスや契約によって違います。

たとえで言うと

道路にバス専用レーンを設けることに似ています。同じ道路でも、専用レーンがあれば、バスは渋滞に巻き込まれにくくなります。似ているのは「同じ設備を、目的ごとに優先の決まりをつけて分けて使う」という点です。

たとえが当てはまらない点: 道路のレーンはペンキで引いた固定の線ですが、スライスは設定で作り直せ、広さも変えられます。また、基地局の電波からコアの設備まで、通り道の全体にまたがって切り分けます。

これからの5Gと6G

3GPPは、5Gの仕様の改良を続けています。2024年にまとまったRelease 18からは、「5G-Advanced」という名前がつきました。基地局の電力を減らす工夫が加わり、AIを電波の制御に使う検討も始まりました。

次の6Gについては、ITUが2023年に、目指す使いみちと性能の枠組みをまとめました。3GPPは、Release 21で6Gの最初の仕様を作る計画です。2030年ごろの実用化を目標とする計画が多いものの、時期や中身はまだ決まっていない部分があります。

よくある誤解

誤解: 5Gなら、4GやWi-Fiよりいつも速い

実際は、5Gの速さは、使っている帯域と混み具合で大きく変わります。4Gから転用した周波数の5Gは、4Gと同じくらいの速さです。ミリ波はとても速くなることがありますが、建物に入ったり向きを変えたりすると、すぐ弱まります。

家の中では、光回線につないだWi-Fiのほうが速く安定していることも多くあります。どちらが速いかは、場所と時間で決まります。

誤解: 「5G」の表示が出ていれば、5Gの機能がすべて使える

実際は、表示は、スマホが5Gの電波につながっていることを示すだけです。NSAなら中心の設備は4G用で、電波も4Gからの転用かもしれません。遅れの小ささを生かす機能やスライシングは、SAで、対応したサービスでないと使えません。表示のしかたも、機種や通信会社によって違います。

誤解: 5Gの電波は体に危ない

見えない電波が新しく増えると、不安を感じるのは自然なことです。電波について確かめられている体への影響は、強い電波が体を温めることです。電波のエネルギーが熱に変わる現象で、電子レンジで食べ物が温まるのと同じしくみです。そこで国際的な専門家の委員会ICNIRPは、体温が上がる影響が出る強さより十分に低い上限を、ガイドラインで示しています。2020年の改訂では、5Gで使う6 GHzを超える電波の扱いが見直されました。

日本では総務省が、これを参考に「電波防護指針」を定めています。一般の人の全身については、体温が上がる影響が出る強さの50分の1が基準です。基地局は人が立ち入る場所で、スマホは体に近づけて使っても、基準を超えないよう法令で決められています。6 GHzを超える電波は主に体の表面で吸収されるので、表面での吸収を基にした基準も加えられました。

WHOは2020年に、多くの研究の結果、無線の技術による健康への悪影響はこれまで確認されていないと説明しています。一方、WHOの専門機関IARCは2011年、無線の電波を「発がん性があるかもしれない」(2B)に分類しました。主に携帯電話の使用と脳腫瘍の関係を調べた研究をもとにした分類です。人での証拠が限られている段階を示すもので、研究と見直しは今も続いています。
