接合温度(Tj)と熱抵抗の計算

消費電力、周囲温度、データシートの熱抵抗を入れると、チップ内部の接合温度Tjを見積もります。ヒートシンクなし(θJA)とヒートシンクあり(θJC + θCS + θSA)の2通りについて、最大接合温度までの余裕と、その条件で使える最大の消費電力を比べられます。

熱抵抗は電気回路と同じ考え方

チップで消費された電力は熱となり、接合(チップ内部)からパッケージ、基板やヒートシンクを通って周囲の空気へ逃げていきます。熱抵抗θは、1 Wの熱が流れたときに生じる温度差を表す値で、単位は ℃/W です。温度差を電圧、熱の流れを電流とみなすと、オームの法則と同じく ΔT = P × θ が成り立ち、直列につながった熱抵抗は足し算できます。そのため接合温度は Tj = Ta + P × θJA で求められます。既定値の P = 1 W、Ta = 25 ℃、θJA = 50 ℃/W では Tj = 75 ℃ で、Tj(max) = 125 ℃ までの余裕は50 ℃です。

θJAが基板で変わる理由とψJT

θJAはパッケージだけで決まる値ではなく、実装する基板の大きさや銅の層数、配線の面積、風の有無で大きく変わります。データシートの値の多くは、JEDECの規格で決められた試験基板と静止した空気の条件で測ったもので、パッケージどうしを比べるための目安です。実際の機器では、熱が基板の銅箔を通って広がるため、θJAは表の値より大きくも小さくもなります。実機で接合温度を確かめるには、パッケージ上面の温度Ttを測り、Tj = Tt + P × ψJT で推定する方法がよく使われます。熱のすべてが上面を通るわけではないので、ψJTは熱抵抗ではなく熱特性パラメータと呼ばれます。

ヒートシンクと熱の通り道

ヒートシンクを付けると、熱の主な通り道は接合→ケース→ヒートシンク→周囲となり、全体の熱抵抗は θJC + θCS + θSA の和になります。θJCはパッケージ内部の値で、データシートに載っています。θCSはケースとヒートシンクの接触部分の値で、表面の細かい凹凸にできる空気の層が熱を妨げるため、サーマルグリースや熱伝導シートなどのTIM(熱界面材料)で隙間を埋めて小さくします。θSAはヒートシンクの大きさやフィンの形、風量で決まります。既定値では合計 4.5 ℃/W となり、1 Wで Tj = 29.5 ℃、使える最大電力は約22.2 Wです。

ディレーティングと設計の余裕

最大接合温度 Tj(max) は、シリコンのICやパワーデバイスでは125 ℃や150 ℃が多く、許される消費電力は Pmax = (Tj(max) − Ta) ÷ θ で決まります。周囲温度が上がるほど余裕が減るため、データシートには周囲温度に応じて許容損失を直線的に下げるディレーティング曲線が載っています。例えば θJA = 50 ℃/W、Tj(max) = 125 ℃ なら、Ta = 25 ℃ で2.0 W、Ta = 85 ℃ では0.8 Wです。また、接合温度が高いほど故障率が上がり寿命が短くなるため、実際の設計では Tj(max) ぎりぎりではなく、さらに余裕を見込むのが普通です。

データシートの問題を解く

データシートに記載された θJA(接合〜周囲の熱抵抗)を、実際の機器の熱設計に使うときの注意として正しいものはどれか。

  1. Aパッケージの構造だけで決まる値なので、どのような基板に実装しても値は変わらない
  2. B基板の銅箔の面積を広げるほど熱がこもりやすくなり、θJAは大きくなる
  3. C試験用基板で測った値なので、実際の基板の銅箔の面積や層数、風の有無で大きく変わる
答えと解説を見る

正解：C. 試験用基板で測った値なので、実際の基板の銅箔の面積や層数、風の有無で大きく変わる

θJAは、JEDECなどの規格で定めた試験用基板にICを実装し、無風の容器の中で測った値です。熱の多くはパッケージから端子や裏面のパッドを通って基板へ流れるので、θJAは基板に強く依存します。同じパッケージでも、1層の小さな基板と多層でベタ層の多い基板とでは2倍近く違うこともあります。銅箔の面積を広げたり風を当てたりすると、θJAは小さく(放熱しやすく)なります。データシートの値は比較の目安と考え、実機では温度を測って確認します。

最大接合温度 Tj(max) = 125 ℃、θJA = 50 ℃/W のICを、周囲温度 Ta = 85 ℃ で使うとき、許される消費電力の上限はいくらか。

  1. A0.8 W
  2. B2.5 W
  3. C1.7 W
答えと解説を見る

正解：A. 0.8 W

接合温度は Tj = Ta + P × θJA で求められます。これをPについて解くと、P = (Tj(max) − Ta)/θJA = (125 − 85)/50 = 0.8 W です。周囲温度が高いほど許される温度上昇の幅が小さくなるので、許容される電力も小さくなります。2.5 Wは周囲温度を引き忘れて125/50とした誤り、1.7 Wは85/50とした誤りです。実際には、θJAが基板によって変わることやディレーティングの余裕を考え、計算値より少ない電力に抑えて設計します。

ヒートシンクを取り付けて使うパワーデバイスの接合温度を見積もるとき、接合から周囲までの熱抵抗として使う組み合わせはどれか。

  1. AデータシートのθJA(接合〜周囲)に、ヒートシンク〜周囲の熱抵抗を足したもの
  2. BθJC、ケース〜ヒートシンク間の接触熱抵抗、ヒートシンク〜周囲の熱抵抗の和
  3. CデータシートのθJA(接合〜周囲)だけで、ヒートシンクを付けても値は変わらない
答えと解説を見る

正解：B. θJC、ケース〜ヒートシンク間の接触熱抵抗、ヒートシンク〜周囲の熱抵抗の和

θJCは、接合からパッケージの放熱面(ケース)までの熱抵抗で、ケースを一定温度に保った状態で測ります。ヒートシンクを付けると熱の大半はケースからヒートシンクへ流れるので、θJC、シリコングリスなどの接触熱抵抗θCS、ヒートシンクの熱抵抗θSAを直列に足して考えます。例えば 1.0 + 0.5 + 3.0 = 4.5 ℃/W で、10 Wの損失なら温度上昇は45 ℃です。θJAはヒートシンクなしで試験用基板に実装して測った値なので、この場合には使えません。

一般的なシリコンのパワーデバイスの最大接合温度(Tj max)の定格として多いものはどれか。

  1. A約500℃
  2. B約50℃
  3. C約150〜175℃
答えと解説を見る

正解：C. 約150〜175℃

シリコンのパワーデバイスでは、最大接合温度が150 ℃や175 ℃に定められているものが一般的です。これを超えると漏れ電流が急増して熱暴走しやすくなり、寿命も大きく縮みます。設計では最大値に対して余裕(例えば125 ℃程度で運用)をとります。SiCは材料としては300 ℃以上にも耐えますが、はんだやワイヤ、樹脂などパッケージ材料の耐熱が実用上の制約になります。

よくある質問

θJAとθJCはどう使い分けますか?

θJAはヒートシンクを付けず、基板と周囲の空気で冷やすときの接合〜周囲の熱抵抗です。θJCは接合からケース表面までの熱抵抗で、ヒートシンクを付けるときに θCS、θSA と足し合わせて使います。ヒートシンクありの計算で θJA に θSA を足すのは誤りです。

Tj(max) = 125 ℃、θJA = 50 ℃/W、Ta = 85 ℃ のとき、使える消費電力はいくらですか?

Pmax = (125 − 85) ÷ 50 = 0.8 W です。周囲温度が25 ℃なら (125 − 25) ÷ 50 = 2.0 W まで使えます。周囲温度が高い機器ほど、使える電力は小さくなります。

データシートのθJAが実機と合わないのはなぜですか?

θJAは、JEDECの規格で決められた試験基板など決まった条件で測った値で、基板の大きさや銅の層数、風の条件が違うと大きく変わるためです。実機では、パッケージ上面の温度を測って ψJT から接合温度を推定する方法がよく使われます。
