真性キャリア密度の温度依存

温度が上がると、価電子帯から伝導帯へ熱で上がる電子が指数関数的に増えます。材料と温度を入れると真性キャリア密度niを計算し、ドーピングした半導体がどの温度まで不純物で決まる性質を保てるかを確かめられます。

真性キャリア密度の式

不純物を含まない半導体では、熱で伝導帯に上がった電子と、価電子帯に残った正孔が同じ数だけでき、その密度が真性キャリア密度 ni = √(Nc·Nv)·exp(−Eg/2kT) です。Nc と Nv は伝導帯と価電子帯の有効状態密度で、T^1.5 に比例します。指数の中にバンドギャップがあるため、niは温度に対して非常に急に増え、同じ温度でもバンドギャップが大きい材料ほど桁違いに小さくなります。このツールでは300 Kの代表値を基準にして、ni(T) = ni(300 K) × (T/300)^1.5 × exp[−(Eg(T)/kT − Eg(300 K)/(k·300 K))/2] で計算しています。

前提条件

有効質量は温度によらず一定とみなし、Nc・Nv の温度依存は T^1.5 だけにしています。バンドギャップの温度変化は Varshni の式で入れています。多数キャリアと少数キャリアは、ドナーがすべてイオン化したn型について、電荷中性 n = p + ND と質量作用の法則 n·p = ni² から、n = ND/2 + √((ND/2)² + ni²)、p = ni²/n と求めます。ドナーのイオン化が不完全になる低温(Siではおおむね100 K以下)や、縮退するほどの高濃度では使えません。

計算例

既定値のSi、300 Kでは ni = 1.0×10¹⁰ cm⁻³ です。100 ℃(373 K)では約1.3×10¹² cm⁻³ と約130倍、400 Kでは約5.3×10¹² cm⁻³ と約530倍に増えます。ND = 10¹⁵ cm⁻³ のn型では、300 Kの電子密度はほぼ10¹⁵ cm⁻³、正孔密度は ni²/ND = 10⁵ cm⁻³ です。温度を上げて ni が ND に追いつくのは約547 K(約274 ℃)で、これより高温では熱でできたキャリアが不純物によるキャリアを上回り、n型としての性質が薄れていきます。同じ条件で Ge は約391 K(約118 ℃)、GaAs は約771 K(約498 ℃)となり、バンドギャップの大きい材料ほど高温まで使える理由がわかります。

使っている値と出典の種類

300 Kの ni と Varshni の式の係数は、半導体デバイスの教科書や物性値の便覧に載っている代表的な物性値です。Siの ni は文献によって 9.65×10⁹〜1.5×10¹⁰ cm⁻³ と幅があり、近年は約1.0×10¹⁰ cm⁻³ がよく使われます。Ge は 2.0〜2.4×10¹³ cm⁻³、GaAs は 1.8〜2.1×10⁶ cm⁻³ 程度の幅があります。ボルツマン定数は k = 8.617×10⁻⁵ eV/K です。結果は、桁と温度による変化の傾向をつかむための値として使ってください。

半導体物性の問題を解く

真性半導体の温度を上げたとき、真性キャリア密度はどうなるか。

  1. A増加する
  2. B減少する
  3. C変化しない
答えと解説を見る

正解：A. 増加する

温度が上がると、価電子帯の電子が熱エネルギーでバンドギャップを越えやすくなり、電子と正孔の対が増えます。真性キャリア密度は ni ∝ T^(3/2)·exp(−Eg/2kT) で、シリコンでは室温付近で約10 ℃上がるごとにおよそ2倍になります。この急な増加が、pn接合の逆方向の漏れ電流が高温で増える原因であり、バンドギャップの大きいSiCやGaNが高温動作に強い理由でもあります。

室温におけるシリコンの真性キャリア密度に最も近い値はどれか。

  1. A約1×10⁴ cm⁻³
  2. B約1×10¹⁰ cm⁻³
  3. C約1×10²² cm⁻³
答えと解説を見る

正解：B. 約1×10¹⁰ cm⁻³

シリコンの真性キャリア密度は室温で約1×10¹⁰ cm⁻³(文献により1.0〜1.5×10¹⁰)です。原子密度約5×10²² cm⁻³と比べると、原子約10¹²個に1個しか自由なキャリアがありません。ゲルマニウムは約2×10¹³、GaAsは約2×10⁶ cm⁻³と、バンドギャップが大きいほど桁違いに小さくなります。この ni の小ささが、わずかなドーピングで導電性を自在に制御できる理由です。

熱平衡状態の半導体における電子密度nと正孔密度pの積(n×p)として正しいものはどれか。(ni:真性キャリア密度)

  1. A常に0になる
  2. Bni の2乗に等しい
  3. C不純物濃度の2乗に等しい
答えと解説を見る

正解：B. ni の2乗に等しい

熱平衡状態では、不純物を添加しても、縮退していなければ n × p = ni² が成り立ちます(質量作用の法則)。電子を増やすと再結合の相手が増えるため、正孔は電子密度に反比例して減るという関係です。例えばシリコン(ni ≈ 1×10¹⁰ cm⁻³)に1×10¹⁶ cm⁻³のドナーを入れると、正孔は1×10⁴ cm⁻³になります。光の照射や電流の注入がある非平衡状態では成り立たず、np > ni² になります。

ドナー濃度1×10¹⁶ cm⁻³のn型シリコン(ドナーはすべてイオン化、真性キャリア密度ni = 1×10¹⁰ cm⁻³)の正孔密度はおよそいくらか。

  1. A1×10⁴ cm⁻³
  2. B1×10⁶ cm⁻³
  3. C1×10¹⁰ cm⁻³
答えと解説を見る

正解：A. 1×10⁴ cm⁻³

ドナーがすべてイオン化しているので電子密度は n ≈ 1×10¹⁶ cm⁻³ です。質量作用の法則 n × p = ni² より、p = (1×10¹⁰)² ÷ 1×10¹⁶ = 1×10⁴ cm⁻³ になります。多数キャリアの1兆分の1しかない少数キャリアですが、PN接合の逆方向電流やバイポーラトランジスタの動作はこの少数キャリアが担っています。ni は温度で急に増えるため、少数キャリア密度も高温で大きく増えます。

よくある質問

温度が10 K上がると、Siの ni は何倍になりますか?

室温付近では約2.2倍です(300 K → 310 K)。逆方向飽和電流のように ni² に比例する量は約5倍になるため、PN接合のリーク電流は温度に非常に敏感です。

ni がわかると、何に使えますか?

少数キャリア密度 p = ni²/ND、PN接合の内蔵電位 (kT/q)ln(NA·ND/ni²)、ダイオードの逆方向飽和電流(ni²に比例)、高温でのリーク電流の見積もりなどに使います。どれも ni の温度依存を通して、デバイスの温度特性を決めています。

SiCやGaNのパワー半導体が高温に強いのはなぜですか?

バンドギャップが約3 eV以上と大きく、ni がシリコンより何十桁も小さいからです。数百℃でも熱でできるキャリアが不純物によるキャリアに追いつかず、真性化しにくいため、高温でもリーク電流が小さく、デバイスとして動作できます。
