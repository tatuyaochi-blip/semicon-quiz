画像・音声・動画のデータ量の計算ツール

デジタルの画像・音声・動画が、圧縮しないとどれくらいのデータ量になるかを計算します。解像度や色の深さ、サンプリング周波数や量子化ビット数を変えると、データ量がどう変わるかが分かります。圧縮率を入れれば、圧縮後の大きさやビットレートの目安も確かめられます。

データ量の単位は1000倍ずつ(kB・MB・GB)で表し、かっこの中に1024倍ずつ(KiB・MiB・GiB)の値も示します。実際の画像・動画ファイルには、ヘッダなどの付加情報も含まれます。

画像のデータ量

デジタル画像は、画素(ピクセル)の並びとして記録されます。データ量は「横の画素数 × 縦の画素数 × 1画素のビット数」です。1画素のビット数(色の深さ)は、赤・緑・青をそれぞれ8ビットで表すフルカラーなら24ビットで、約1677万色を表せます。フルHD(1920 × 1080)のフルカラー画像は、圧縮しないと約6.2 MB になります。イメージセンサの画素数が増えると、1枚あたりのデータ量も比例して増えます。

音声のデータ量: 標本化と量子化

音声をデジタルにするには、一定の間隔で波形の値を取り出し(標本化、サンプリング)、その値を決まった段階の数値に丸めます(量子化)。データ量は「標本化周波数 × 量子化ビット数 × チャネル数 × 時間」です。CDは44.1 kHz・16ビット・ステレオなので、1秒あたり1411.2 kビットで、1分では約10.6 MBです。標本化の定理により、元の音に含まれる最も高い周波数の2倍より高い周波数で標本化すれば、元の波形を再現できます。人が聞こえる約20 kHzまでを記録するため、CDは44.1 kHzを使います。

動画のデータ量と圧縮

動画は、画像を1秒間に何枚も切り替えて表示するので、データ量は「1枚の画像のデータ量 × フレームレート × 時間」になります。フルHD・30フレーム/秒の動画を圧縮しないと、約1.5 Gbpsものビットレートになり、1分で約11 GB です。そのため、動画はH.264やH.265などの方式で、前後のフレームとの差分や人の目に目立たない情報を省いて、数十分の1から数百分の1に圧縮して保存・配信します。

ADコンバータとの関係

音声の標本化と量子化は、ADコンバータ(AD変換器)がアナログ信号をデジタルに変える仕組みそのものです。量子化ビット数が1ビット増えると、表せる段階の数は2倍になり、理想的な量子化雑音に対するSN比は約6 dB良くなります。イメージセンサでも、各画素の明るさをADコンバータで数値にしており、1画素あたりのビット数はその分解能で決まります。

AD・DA変換の問題を解く

音楽CDのサンプリング周波数として正しいものはどれか。

  1. A44.1 kHz
  2. B8 kHz
  3. C1 MHz
答えと解説を見る

正解：A. 44.1 kHz

音楽CDは44.1 kHz・16ビット・2チャンネルで記録され、データ量は約1.4 Mb/sです。可聴域の上限約20 kHzの2倍を少し上回る値で、当時の業務用ビデオ機器に記録しやすい数値から決まったといわれています。16ビットのダイナミックレンジは約96 dBです。放送や映像では48 kHz、ハイレゾ音源では96 kHzや192 kHz・24ビット、電話音声では8 kHzが使われます。

最高20 kHzの成分を含むアナログ信号を、折り返し雑音(エイリアシング)なくサンプリングするために必要なサンプリング周波数はどれか。

  1. A10 kHz以上
  2. B20 kHzちょうど
  3. C40 kHzより高い周波数
答えと解説を見る

正解：C. 40 kHzより高い周波数

サンプリング定理により、最高周波数の2倍より高い周波数でサンプリングすれば元の信号を復元でき、20 kHzなら40 kHzより高い周波数が必要です。実際にはフィルタで急に切ることができないため余裕をとり、音楽CDは44.1 kHzでサンプリングしています(20〜22.05 kHzをフィルタの遷移帯域に使う)。サンプリング周波数の半分をナイキスト周波数と呼びます。

よくある質問

量子化ビット数を増やすと何が良くなりますか?

1つの標本値を細かい段階で表せるので、元の波形との誤差(量子化雑音)が小さくなります。量子化ビット数が1ビット増えるごとに、段階の数は2倍、データ量は(ビット数に比例して)増えます。

256色の画像は1画素何ビットですか?

256 = 2⁸ なので8ビットです。2色なら1ビット、65536色なら16ビット、約1677万色(フルカラー)なら24ビットです。

圧縮率1/100とはどういう意味ですか?

圧縮後のデータ量が元の100分の1になるという意味です。このツールの「圧縮率」には、何分の1にするかの数(この場合は100)を入れます。

試験ではどのように問われますか?

基本情報技術者試験などでは、画像の解像度と色数から必要な記憶容量を求める問題、標本化周波数と量子化ビット数から音声のデータ量を求める問題、動画を回線で送るのに必要なビットレートを求める問題がよく出ます。
