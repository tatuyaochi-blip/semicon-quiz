クリティカルパスの計算ツール

プロジェクトの作業の順番と所要日数から、全体を最短で終えるのに何日かかるか、どの作業が遅れると全体が遅れるか(クリティカルパス)を、クリティカルパス法(CPM)で計算します。アローダイアグラム(PERT図)の問題で使う、最早開始日・最遅開始日・余裕日数を表で確かめられます。

お気に入りと最近使ったツールは、このブラウザ内（localStorage）にのみ保存されます。

作業の一覧

作業名は英数字・かな漢字8文字まで、所要日数は0以上の数、先行作業は空白かカンマで区切って並べます。先行作業がなければ省きます。作業は26個まで。

日数は、プロジェクトの開始を0日目として数えます。全余裕(トータルフロート)は、全体の所要日数を延ばさずに遅らせられる日数、自由余裕(フリーフロート)は、後の作業の最早開始日を遅らせずに遅らせられる日数です。

クリティカルパスとは

プロジェクトの作業には、前の作業が終わらないと始められない順序の関係があります。開始から終了までの作業のつながりのうち、所要日数の合計が最も長いものがクリティカルパスで、その長さがプロジェクト全体の最短の所要日数になります。クリティカルパス上の作業は、1日でも遅れると全体が遅れます。例「6つの作業」では、B(5日)→ D(4日)→ E(3日)の12日がクリティカルパスで、A や C、F には余裕があります。

最早開始日と最遅開始日の求め方

最早開始日は、先行作業がすべて終わる日のうち最も遅い日で、開始から順に「先行作業の最早終了日の最大」として求めます(前進計算)。最遅開始日は、全体の所要日数を延ばさないために遅くとも始めなければならない日で、終了から逆に「後続作業の最遅開始日の最小 − 自分の所要日数」として求めます(後退計算)。最遅開始日と最早開始日の差が余裕日数(全余裕)で、余裕が0の作業をつないだものがクリティカルパスです。

アローダイアグラムとPERT

作業の順序関係を矢印で表した図をアローダイアグラムといい、PERT(Program Evaluation and Review Technique)と呼ばれる手法で使われます。アローダイアグラムでは作業を矢印、作業の区切りを丸(結合点)で表し、順序の関係だけを表す点線の矢印(ダミー作業、所要日数0)を使うこともあります。このツールでは、作業ごとに先行作業を並べる書き方(プレシデンスダイアグラムと同じ考え方)で入力するので、ダミー作業は必要ありません。

日程の短縮

プロジェクトを早く終わらせるには、クリティカルパス上の作業を短縮しなければ効果がありません。余裕のある作業を短縮しても、全体の日数は変わりません。人を増やして作業を短縮するクラッシング、順番に行う作業を一部重ねて並行に進めるファストトラッキングなどの方法があります。クリティカルパス上の作業を短縮すると、別の経路が新しいクリティカルパスになることがあるので、表を見ながら確かめてください。

関連する問題を解く

結合点を①〜⑥とし、作業を「名前: 始点→終点、所要日数」で示すと、A: ①→②、6日、B: ①→③、4日、C: ②→④、4日、D: ③→⑤、4日、E: ④→⑥、2日、F: ⑤→⑥、3日、ダミー作業: ②→③(所要日数0)となるアローダイアグラムがある。プロジェクト全体の最短の所要日数はどれか。

  1. A11日
  2. B12日
  3. C13日
答えと解説を見る

正解：C. 13日

ダミー作業②→③は、作業Dを始めるには、Bだけでなく A も終わっている必要があることを表します。各結合点の最早結合点時刻は、②が6日、③が max(4, 6 + 0) = 6日、④が 6 + 4 = 10日、⑤が 6 + 4 = 10日、⑥が max(10 + 2, 10 + 3) = 13日なので、全体の所要日数は13日で、クリティカルパスは A→ダミー→D→F です。ダミー作業を見落とすと D が4日目から始められることになり、A→C→E の12日が最長になってしまいます。11日は B→D→F の経路だけの日数です。

作業と所要日数、先行作業が、A: 4日(先行作業なし)、B: 2日(なし)、C: 3日(A)、D: 2日(B)、E: 5日(C)、F: 4日(C と D)、G: 2日(F)のプロジェクトがある。ほかの作業はできるだけ早く始めるとき、作業Bの開始を遅らせても全体の所要日数が延びない最大の日数はどれか。

  1. A0日
  2. B1日
  3. C3日
答えと解説を見る

正解：C. 3日

最早開始日は C が4日、E と F が7日(F は C の終わる7日と D の終わる4日の遅い方)、G が11日で、全体は A→C→F→G の 4 + 3 + 4 + 2 = 13日です。後ろから最遅開始日を求めると、G が11日、F が7日、D が 7 − 2 = 5日、B が 5 − 2 = 3日なので、B のトータルフロート(余裕日数)は 3 − 0 = 3日です。B を遅らせると D の開始も遅れますが、D にも同じ余裕があるので、3日までなら全体は延びません。0日は B のフリーフロート(後続の D の最早開始を遅らせない余裕)、1日は E の余裕日数です。クリティカルパス法(CPM)では、このように余裕日数を求め、余裕が0の作業をつないだ経路をクリティカルパスとします。

作業と所要日数、先行作業が、A: 6日(なし)、B: 4日(なし)、C: 4日(A)、D: 4日(A と B)、E: 2日(C)、F: 3日(D)で、全体の所要日数が13日のプロジェクトがある。各作業を1日短縮するのにかかる追加の費用は、A が30万円、B が5万円、C が10万円、D が20万円、E が8万円、F が25万円である。全体の所要日数を1日短縮するのに、追加の費用が最も少ない方法はどれか。

  1. A作業Bを1日短縮する(5万円)
  2. B作業Dを1日短縮する(20万円)
  3. C作業Aを1日短縮する(30万円)
答えと解説を見る

正解：B. 作業Dを1日短縮する(20万円)

クリティカルパスは A→D→F(6 + 4 + 3 = 13日)で、ほかの経路は A→C→E が12日、B→D→F が11日です。全体を短くするにはクリティカルパス上の作業を短縮する必要があり、その中で費用が最も少ないのは D の20万円で、短縮後は A→D→F と A→C→E がともに12日になります。B はいちばん安いのですが、クリティカルパス上にないので、短縮しても全体は13日のままです。A を短縮しても全体は12日になりますが、費用は30万円かかります。このように費用をかけて作業の期間を縮めることを、クラッシングといいます。

よくある質問

全余裕と自由余裕の違いは何ですか?

全余裕(トータルフロート)は、プロジェクト全体を遅らせない範囲で遅らせられる日数です。自由余裕(フリーフロート)は、すぐ後の作業の最早開始日も遅らせない範囲で遅らせられる日数で、全余裕以下になります。全余裕を使い切ると、後の作業の余裕も減ります。

クリティカルパスが2本以上あることはありますか?

あります。所要日数の合計が最長の経路が複数あれば、どれもクリティカルパスです。その場合、全体を短縮するには、すべてのクリティカルパスを短縮する必要があります。

所要日数が不確かなときはどうしますか?

PERTでは、楽観値 a、最可能値 m、悲観値 b の3つを見積もり、期待値を (a + 4m + b) ÷ 6 として使う方法があります。このツールに入力する前に、作業ごとの期待値を計算してください。

試験ではどのように問われますか?

基本情報技術者試験や応用情報技術者試験では、アローダイアグラムからプロジェクト全体の所要日数やクリティカルパス、ある作業の最早開始日・最遅開始日・余裕日数を求める問題、作業を短縮したときに全体が何日短くなるかを問う問題がよく出ます。
