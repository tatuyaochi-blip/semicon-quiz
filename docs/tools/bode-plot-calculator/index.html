ボード線図の計算

伝達関数 G(s) の分子と分母を、10 や s^2 + 3s + 2、(s+1)(s+2) のように s の式で入れると、角周波数 ω に対するゲインと位相のグラフ(ボード線図)を描きます。開ループの伝達関数として、位相余裕とゲイン余裕も求めます。

お気に入りと最近使ったツールは、このブラウザ内（localStorage）にのみ保存されます。

伝達関数 G(s) = 分子 / 分母 · e^(−Ls)

掛け算は 2s、s(s+1)、(s+1)(s+2) のように省略できます。べき乗は s^2 です。係数を次数の高い順に空白で並べた「1 3 2」も使えます。

グラフで見る

ほかの入力は今の値のまま、選んだ入力だけを今の値の1/4〜4倍の範囲で変えたときの結果です。赤い点が今の値です。

ボード線図の読み方

ボード線図は、正弦波を入れたときの出力の大きさ(ゲイン)と位相のずれを、角周波数 ω に対して描いた2枚のグラフです。横軸は対数目盛りで、ゲインは 20·log10|G(jω)| のデシベルで表します。対数にすると、掛け算した伝達関数のゲインと位相が足し算になるので、要素ごとの線図を重ねて全体を考えられます。一次遅れ 1/(Ts+1) のゲインは、折れ点の角周波数 1/T までほぼ平らで、それより上では 10 倍ごとに 20 dB 下がり、位相は 0° から −90° へ変わります。折れ点ではゲインが −3 dB、位相が −45° です。

位相余裕とゲイン余裕

フィードバック制御の安定の余裕は、開ループの伝達関数のボード線図から読み取れます。ゲインが 0 dB になる角周波数(ゲイン交差周波数)で、位相が −180° からどれだけ離れているかが位相余裕です。位相が −180° になる角周波数(位相交差周波数)で、ゲインが 0 dB よりどれだけ下にあるかがゲイン余裕です。例の 1/(s(s+1)) では、ωgc ≈ 0.786 rad/s で位相余裕は約52°です。10/((s+1)(s+2)(s+3)) では、ωpc = √11 ≈ 3.32 rad/s でゲイン余裕は約15.6 dB なので、ゲインを約6倍の60にすると安定限界になります。目安として、位相余裕は 40〜60°、ゲイン余裕は 10 dB 前後以上がよく使われます。

極・零点と線図の形

分母が 0 になる s が極、分子が 0 になる s が零点です。左半平面の実数の極は、その大きさの角周波数でゲインを 20 dB/dec 下げ、位相を 90° 遅らせます。零点は逆に、ゲインを上げて位相を進めます。原点の極(積分)は、すべての周波数で −20 dB/dec と −90° を加えます。複素共役の極の組は、減衰係数 ζ が小さいほど、固有角周波数の近くにゲインの山(共振)を作ります。例の二次遅れ(ζ = 0.2)では、ω ≈ 1 rad/s 付近にゲインの山が見えます。

むだ時間の影響

むだ時間 e^(−Ls) は、ゲインを変えずに位相だけを ωL [rad] 遅らせます。周波数が高いほど遅れが大きくなるので、位相余裕を減らし、ゲインを上げられる限界を下げます。例の 2e^(−0.5s)/(s+1) では、ゲイン交差周波数 √3 ≈ 1.73 rad/s で、むだ時間による遅れは約50°です。位相余裕は約70°で、むだ時間がなければ約120°でした。むだ時間がある系の閉ループの根は多項式では求められないので、このツールでは、閉ループの安定は余裕から判断するように表示します。

制御工学の問題を解く

一次遅れ系 G(s) = 1/(1 + sT) のボード線図の特徴として正しいものはどれか。

  1. A折れ点の角周波数 ω = 1/T でゲインは約 −3 dB、位相は −45° で、それより十分高い周波数ではゲインが −20 dB/dec で下がる
  2. B折れ点の角周波数 ω = 1/T でゲインは −6 dB、位相は −90° で、それより十分高い周波数では、ゲインが −40 dB/dec の傾きで下がる
  3. Cゲインはどの周波数でも0 dBで、位相だけが周波数に比例して遅れていく
答えと解説を見る

正解：A. 折れ点の角周波数 ω = 1/T でゲインは約 −3 dB、位相は −45° で、それより十分高い周波数ではゲインが −20 dB/dec で下がる

G(jω) = 1/(1 + jωT) の大きさは 1/√(1 + (ωT)²) で、ω = 1/T では 1/√2(約 −3 dB)、位相は −45° です。ω が 1/T より十分大きいと大きさは 1/(ωT) に近づき、周波数が10倍になるごとにゲインが20 dB下がります(−20 dB/dec)。位相は、低い周波数の0°から高い周波数の −90° へ変わります。ボード線図の折れ線近似では、折れ点より下を0 dBの水平線、上を −20 dB/dec の直線で表します。

積分要素 G(s) = 1/s のボード線図として正しいものはどれか。

  1. Aゲインはどの周波数でも0 dBで、位相はどの周波数でも −90° になる
  2. Bゲインは ω = 1 rad/s で0 dBを通る +20 dB/dec の直線で、位相はどの周波数でも +90° になる
  3. Cゲインは ω = 1 rad/s で0 dBを通る −20 dB/dec の直線で、位相はどの周波数でも −90° になる
答えと解説を見る

正解：C. ゲインは ω = 1 rad/s で0 dBを通る −20 dB/dec の直線で、位相はどの周波数でも −90° になる

G(jω) = 1/(jω) の大きさは 1/ω なので、ω = 1 rad/s で0 dBになり、周波数が10倍になるごとに20 dB下がります。1/j = −j なので、位相はどの周波数でも −90° です。低い周波数ほどゲインが大きくなるので、積分を含む系は、ステップの目標値に対する定常偏差を0にできます。+20 dB/dec で位相 +90° の直線になるのは、微分要素 s です。

G(s) = 10/((1 + s/100)(1 + s/1000)) の、角周波数 ω = 10⁴ rad/s でのゲインを、ボード線図の折れ線近似で求めた値として正しいものはどれか。

  1. A−40 dB
  2. B−20 dB
  3. C0 dB
答えと解説を見る

正解：A. −40 dB

低い周波数でのゲインは 20 log₁₀10 = 20 dBです。100 rad/sから1000 rad/sまでは −20 dB/dec で下がって1000 rad/sで0 dBになり、そこから先は2つ目の極が加わって −40 dB/dec で下がります。1000 rad/sから10⁴ rad/sまでは1ディケードなので、ゲインは 0 − 40 = −40 dBです。実際の値も約 −40.04 dBで、折れ点から十分離れた周波数では、折れ線近似がよく合います。

一巡伝達関数のボード線図から読み取る、ゲイン余裕と位相余裕の説明として正しいものはどれか。

  1. Aゲイン余裕はゲインが0 dBになる周波数での位相の −180° までの差、位相余裕は位相が −180° になる周波数でのゲインの0 dBまでの差である
  2. Bゲイン余裕は位相が −180° になる周波数でのゲインの0 dBまでの差、位相余裕はゲインが0 dBになる周波数での位相の −180° までの差である
  3. Cゲイン余裕も位相余裕も、閉ループのボード線図で、ゲインが −3 dBになる周波数で読み取る
答えと解説を見る

正解：B. ゲイン余裕は位相が −180° になる周波数でのゲインの0 dBまでの差、位相余裕はゲインが0 dBになる周波数での位相の −180° までの差である

ゲイン余裕は、位相が −180° になる位相交差周波数で、ゲインが0 dBより何dB低いかを表します。位相余裕は、ゲインが0 dBになるゲイン交差周波数で、位相が −180° まであと何度あるかを表します。どちらも、一巡伝達関数が点 −1(ゲイン0 dB、位相 −180°)にどれだけ近いかを表す指標で、閉ループではなく一巡伝達関数から読み取ります。サーボ系では、ゲイン余裕10〜20 dB、位相余裕40〜60°程度がよく目安にされます。

一巡伝達関数 L(s) = 2/(s(s + 1)(s + 2)) のゲイン余裕に最も近いものはどれか。

  1. A約4.8 dB
  2. B約9.5 dB
  3. C約15.6 dB
答えと解説を見る

正解：B. 約9.5 dB

位相は −90° − tan⁻¹ω − tan⁻¹(ω/2) で、2つの角の和が90°になる条件 ω × (ω/2) = 1 から、位相が −180° になるのは ω = √2 rad/s のときです。そこでのゲインは |L(j√2)| = 2/(√2 × √3 × √6) = 1/3 なので、ゲイン余裕は 20 log₁₀3 ≈ 9.5 dBです。ゲインを3倍(K = 6)にすると限界に達することになり、ラウス・フルビッツの安定判別法で求めた安定の範囲 0 < K < 6 と一致します。

一巡伝達関数のゲインを上げたところ、位相余裕が60°から30°に減った。閉ループのステップ応答の変化として正しいものはどれか。

  1. Aオーバーシュートが小さくなって振動がなくなり、そのかわりに応答の立ち上がりが遅くなる
  2. B位相余裕は周波数応答の指標なので、ステップ応答の形には影響しない
  3. C応答は速くなる傾向があるが、オーバーシュートが大きくなり、振動が収まりにくくなる
答えと解説を見る

正解：C. 応答は速くなる傾向があるが、オーバーシュートが大きくなり、振動が収まりにくくなる

ゲインを上げるとゲイン交差周波数が高くなって応答は速くなりますが、位相余裕が減ると、閉ループの減衰係数が小さくなります。目安として、減衰係数 ζ は位相余裕(度)の約100分の1と見積もられます。一巡伝達関数が ωn²/(s(s + 2ζωn)) の標準的な系では、位相余裕60°でオーバーシュートは約9%、30°では約42%になります。位相余裕が0に近づくと持続振動に近づき、負になると不安定になります。

よくある質問

位相余裕はどれくらいあればよいですか?

一般に 40〜60° がよく使われる目安です。位相余裕が小さいと、閉ループのステップ応答のオーバーシュートが大きくなり、振動しやすくなります。2次系の近似では、位相余裕が約45°で減衰係数が約0.4、約60°で約0.6に相当します。部品のばらつきや温度による変化も考えて、余裕を持たせます。

dB と倍率はどう換算しますか?

ゲインの dB は 20·log10(倍率) です。2倍は約 6 dB、10倍は 20 dB、1/√2 ≈ 0.707倍は約 −3 dB、0.1倍は −20 dB です。ゲイン余裕 15.6 dB は、ゲインを約6倍にすると安定限界になることを意味します。

開ループのボード線図で、閉ループの安定が分かるのはなぜですか?

単位フィードバックの閉ループ G/(1 + G) が不安定になるのは、1 + G(jω) = 0、つまり G(jω) がゲイン 1・位相 −180° の点を通ったり囲んだりするときだからです(ナイキストの安定判別)。開ループが安定な一般的な系では、位相交差周波数でゲインが 1 より小さければ安定です。開ループ自体に不安定な極がある場合は、ナイキスト線図で回る回数を数える必要があります。
