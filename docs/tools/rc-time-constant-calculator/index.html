RC 時定数の計算

抵抗 R とコンデンサ C の値を入れると、時定数 τ = RC と、1次の RC フィルタのカットオフ周波数を計算します。指定した時刻にコンデンサがどこまで充電・放電しているかも、グラフで確かめられます。

時定数τ = RCの意味

抵抗Rを通してコンデンサCを充電すると、電圧はv(t) = V(1 − e^(−t/τ))のように電源電圧Vに近づいていきます。このτ = RCが時定数で、Ωとファラドの積は秒になります。t = τのとき、電圧は最終値の1 − e^(−1) ≈ 63.2%です。既定値のR = 10 kΩ、C = 100 nFではτ = 10 kΩ × 100 nF = 1 msで、t = 1 msでの充電は63.21%、放電では36.79%の電圧が残ります。放電はv(t) = V0·e^(−t/τ)で表され、同じτで減っていきます。

充電しきるまでの時間

式の上では、電圧は最終値に近づき続けるだけで、ちょうど100%にはなりません。そこで、どこまで近づけば十分かで考えます。2τで約86.5%、3τで約95.0%、4τで約98.2%、5τで約99.3%に達するので、一般に5τを「ほぼ充電しきる時間」の目安にします。既定値では5τ = 5 msです。50%に達する時間はln2·τ ≈ 0.69τ、10%から90%までの立ち上がり時間はln9·τ ≈ 2.2τです。ADCの入力のように高い精度で落ち着かせたい場合は、5τより長い時間が必要になります。

カットオフ周波数とRCフィルタ

RとCで作る1次のローパスフィルタでは、カットオフ周波数はfc = 1/(2πRC)です。この周波数で出力の振幅は入力の1/√2 ≈ 0.707倍、つまり−3 dBになり、位相は45°遅れます。fcより十分高い周波数では、周波数が10倍になるごとに振幅が約20 dBずつ下がります。既定値ではfc = 1/(2π × 1 ms) ≈ 159 Hzです。RとCの位置を入れ替えたハイパスフィルタでも、カットオフ周波数は同じ式で決まります。いずれも、信号源の抵抗が0で、出力に負荷をつながない場合の値です。

使いどころと配線のRC遅延

RC回路は、スイッチのチャタリング(接点がはねてオン・オフを短時間に繰り返す現象)の除去、ノイズを減らすフィルタ、リセットやタイマの遅延などに使われます。チャタリング除去では、はねが続く時間より十分長いτにして、シュミットトリガ入力で受けるのが一般的です。半導体チップの中では、配線の抵抗と容量によるRC遅延が信号を遅らせます。配線ではRもCも長さに比例するため遅延は長さの2乗で増え、分布定数として扱うと50%遅延は約0.38RCです。なお、コンデンサの容量には許容差があり、セラミックコンデンサの種類によっては電圧や温度で容量が大きく変わります。

アナログ・電子回路の問題を解く

よくある質問

時定数とは何ですか?

RC回路では抵抗と容量の積τ = RCで、ステップ入力に対する応答の速さを表します。充電では時間τで最終値の約63.2%に達し、放電では約36.8%まで下がります。10 kΩと100 nFならτ = 1 msです。

コンデンサが完全に充電されるまでどれくらいかかりますか?

理論上は100%には達しませんが、5τで約99.3%に達するため、一般に5τをほぼ充電しきった目安とします。10 kΩと100 nFなら5 msです。さらに高い精度が必要な場合は、7τで約99.9%のように、必要な精度から時間を決めます。

RCフィルタのカットオフ周波数の式は?

1次のRCフィルタではfc = 1/(2πRC)で、ローパスでもハイパスでも同じです。時定数を使ってfc = 1/(2πτ)とも書けます。10 kΩと100 nFでは約159 Hzで、この周波数で振幅は約0.707倍(−3 dB)になります。
