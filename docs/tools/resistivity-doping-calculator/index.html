シリコンの抵抗率と不純物濃度の換算

ウエハの仕様にある抵抗率から不純物濃度を、または濃度から抵抗率を求めます。不純物が多いほど移動度が下がる効果も入れて、n型(リン・ヒ素)とp型(ホウ素)を計算します。

抵抗率と不純物濃度の式

半導体の導電率は、キャリアの数と動きやすさの積で σ = q(nμn + pμp) と表されます。n型で不純物がすべてイオン化していれば n ≈ ND で、少数キャリアの寄与は無視できるので、抵抗率は ρ = 1/(q·ND·μn) です。p型も同じく ρ = 1/(q·NA·μp) です。ただし移動度μ自体が濃度で変わるため、濃度と抵抗率は単純な反比例になりません。このツールでは μ(N) = μmin + (μmax − μmin)/(1 + (N/Nref)^α) という Caughey–Thomas 型の式で移動度を求め、抵抗率から濃度を求めるときは、この式を濃度について数値的に解いています。

前提条件と使える範囲

温度300 Kのシリコンで、不純物は1種類だけ、そのすべてがイオン化しているとし、少数キャリアの寄与は無視します。使う範囲の目安は10¹³〜10¹⁹ cm⁻³ です。ドナーとアクセプタを両方含む補償された結晶では、キャリアの数は正味の濃度で決まる一方、移動度は両方を合わせた濃度で散乱を受けるので、このツールの値より抵抗率が高くなります。10¹⁹ cm⁻³ を超えると、不完全イオン化やバンドギャップの縮小の影響が出て、実測にもとづく換算表とのずれが大きくなります。

計算例

既定値のp型、NA = 10¹⁵ cm⁻³ では、正孔の移動度は約462 cm²/V·sで、ρ = 1/(1.602×10⁻¹⁹ × 10¹⁵ × 462) ≈ 13.5 Ω·cm です。同じ濃度のn型では電子の移動度が約1362 cm²/V·sと約3倍大きいため、ρ ≈ 4.58 Ω·cm になります。逆に、仕様が「p型 10 Ω·cm」のウエハは約1.36×10¹⁵ cm⁻³、「n型 1 Ω·cm」は約4.9×10¹⁵ cm⁻³ と求まります。濃度を100倍の10¹⁷ cm⁻³ にすると、p型の抵抗率は約0.197 Ω·cmで、100分の1の0.135 Ω·cmまでは下がりません。不純物によるクーロン散乱で、移動度が約317 cm²/V·sに下がるためです。

使っている値と出典の種類

移動度の式の係数は、シリコンの移動度の実測値に合わせた代表的なフィット値で、半導体デバイスの教科書や解説で広く使われているものです。電気素量は q = 1.602×10⁻¹⁹ C です。実際のウエハでは、四探針法などで抵抗率を測り、SEMI MF723(旧ASTM F723)などの換算規格で濃度に直すのが一般的です。このツールの結果は目安として使い、正確な値が必要なときは換算規格や実測で確かめてください。

半導体物性の問題を解く

電子密度1×10¹⁶ cm⁻³、電子の移動度1000 cm²/V·sのn型シリコンの抵抗率はおよそいくらか。(正孔の寄与は無視、電気素量1.6×10⁻¹⁹ C)

  1. A約0.06 Ω·cm
  2. B約0.6 Ω·cm
  3. C約60 Ω·cm
答えと解説を見る

正解：B. 約0.6 Ω·cm

導電率は σ = qnμ = 1.6×10⁻¹⁹ × 1×10¹⁶ × 1000 = 1.6 S/cm で、抵抗率はその逆数の ρ ≈ 0.63 Ω·cm です。「ρ ≈ 1/(qnμ)」は、ウエハの抵抗率からドーパント濃度を見積もる基本式です。実務では、移動度の濃度依存を含めた換算表(ASTM規格など)を使い、例えば1〜10 Ω·cm のp型ウエハはホウ素約10¹⁵〜10¹⁶ cm⁻³ に相当します。

シリコンウエハの抵抗率と、添加した不純物濃度の関係として正しいものはどれか。

  1. A不純物濃度が高いほど抵抗率は高くなる
  2. B不純物濃度と抵抗率は無関係である
  3. C不純物濃度が高いほど抵抗率は低くなる
答えと解説を見る

正解：C. 不純物濃度が高いほど抵抗率は低くなる

不純物を多く添加するとキャリアが増えるため抵抗率は低くなり、その関係からウエハの抵抗率は不純物濃度の目安として仕様に指定されます。例えばp型で1〜10 Ω·cmならホウ素は約10¹⁵〜10¹⁶ cm⁻³、0.01 Ω·cmなら約10¹⁹ cm⁻³です。濃度が高くなるとイオン化不純物散乱で移動度が下がるため単純な反比例にはならず、ASTMなどの換算表を使って変換します。

真性半導体の抵抗率の温度依存性として正しいものはどれか。

  1. A温度が上がると抵抗率が下がる
  2. B温度が上がると抵抗率が上がる
  3. C温度によらず抵抗率は一定である
答えと解説を見る

正解：A. 温度が上がると抵抗率が下がる

真性半導体では、温度が上がるとバンドギャップを越えて励起されるキャリアが指数関数的に増えるため、抵抗率は下がります(負の温度係数)。金属はキャリア数がほぼ一定で、格子振動による散乱が増えるため抵抗率が上がります。この性質を利用したのがサーミスタ(NTC)です。ただし不純物を添加したシリコンでは、常温付近ではキャリア数がほぼ一定のため、移動度の低下で抵抗がむしろ上がる範囲もあります。

ウエハの抵抗率を非接触で測定する方法として使われるものはどれか。

  1. ASIMS
  2. BTEM観察
  3. C渦電流を利用した測定
答えと解説を見る

正解：C. 渦電流を利用した測定

交流磁界をかけるとウエハ内に渦電流が流れ、その大きさは導電率(シート抵抗)によって変わります。これをコイルで検出して、ウエハに触れずに抵抗率を測定できます。針を当てる4探針法と異なり表面を傷つけず汚染もないため、ウエハの受け入れ検査や、金属膜の厚さの測定(シート抵抗から換算)などに使われます。マッピングしてウエハ内の分布も評価できます。

よくある質問

同じ濃度なのに、n型とp型で抵抗率が違うのはなぜですか?

シリコンでは電子の移動度が正孔の約3倍あるからです。低濃度では電子が約1400 cm²/V·s、正孔が約470 cm²/V·sなので、同じ濃度ならn型の抵抗率はp型の約3分の1になります。

抵抗率を10倍にするには、濃度を10分の1にすればよいですか?

10¹⁵ cm⁻³ 以下の低濃度では移動度がほぼ一定なので、ほぼ10分の1で済みます。高濃度では、濃度を下げると移動度が上がって抵抗率の上がり方が鈍るため、10分の1より大きく下げる必要があります。グラフで傾きの変化を確かめてください。

実際のウエハの抵抗率から濃度を求めるのに使えますか?

目安には使えます。ただし、ドナーとアクセプタが両方入った補償や、CZシリコンを450 ℃付近で熱処理したときにできるサーマルドナーがあると、抵抗率と濃度の関係が変わります。正確な値は換算規格や、SIMSなどによる濃度の測定で確かめてください。
