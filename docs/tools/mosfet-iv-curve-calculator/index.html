MOSFETの電流-電圧特性(ID–VDS)

nチャネルMOSFETのドレイン電流を、長チャネルの2乗則にチャネル長変調を加えたモデルで計算し、ID–VDS特性の曲線群として描きます。VGSとVDSで決まる動作点が、遮断・線形・飽和のどの領域にあるか、そのときのドレイン電流や小信号パラメータもすぐに分かります。

太い線が入力したVGSの曲線、細い線はそれより低いVGSの曲線です。破線は線形領域と飽和領域の境界(VDS = VGS − Vth)です。しきい値以下の小さな電流(サブスレッショルド電流)や、短チャネル効果による速度飽和は含めていません。

2乗則モデル

長チャネルのnMOSFETでは、VGSがしきい値電圧Vthを超えるとチャネルができて電流が流れます。VDSが小さい線形(三極管)領域では ID = µnCox(W/L)[(VGS − Vth)VDS − VDS²/2] で、VDSに比例する抵抗のように振る舞います。VDSがオーバードライブ電圧 VGS − Vth を超えるとドレイン端でチャネルがピンチオフし、飽和領域では ID = (1/2)µnCox(W/L)(VGS − Vth)² と、VDSにほとんどよらない電流になります。

チャネル長変調と出力抵抗

実際には、飽和領域でもVDSを上げるとピンチオフ点がソース側へ動き、実効的なチャネル長が短くなるため、電流がわずかに増えます。これをチャネル長変調と呼び、ID に (1 + λVDS) を掛けて表します。この傾きから小信号の出力抵抗は ro ≈ 1/(λID) となり、増幅回路の利得 gm·ro を決めます。チャネル長が短いほどλは大きく、roは小さくなるので、アナログ回路では長めのチャネルを使うことがよくあります。

相互コンダクタンスの求め方

飽和領域でのゲート電圧に対する電流の変化率 gm は、gm = µnCox(W/L)(VGS − Vth) = 2ID/(VGS − Vth) です。同じ電流でもオーバードライブ電圧を小さくするとgmは大きくなりますが、そのぶん素子を大きく(W/Lを大きく)する必要があり、動作できる電圧の余裕も変わります。例えば既定値の Vth = 0.5 V、µnCox = 200 µA/V²、W/L = 10、λ = 0.05 /V、VGS = 1.5 V、VDS = 1.2 V では、ID ≈ 1.06 mA、gm ≈ 2.1 mS、ro ≈ 19 kΩ で、gm·ro は約40です。

モデルの限界

2乗則は長チャネルの素子を前提にした近似です。最先端の短チャネルの素子では、強い電界でキャリアの速度が飽和するため、電流は (VGS − Vth) の2乗より1乗に近い依存になります。また、しきい値以下でも電流はゼロではなく、ゲート電圧に対して指数関数的に変化するサブスレッショルド電流が流れ、室温では電流を1桁変えるのに少なくとも約60 mVが必要です。回路設計では、こうした効果を含むBSIMなどの詳しいモデルでシミュレーションします。

MOSFETの問題を解く

長チャネルのMOSFETが飽和領域で動作しているとき、ドレイン電流IDはおよそ何に比例するか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)

  1. A(VGS − Vth)の2乗
  2. BVGS − Vth
  3. CVGSの逆数
答えと解説を見る

正解：A. (VGS − Vth)の2乗

長チャネルMOSFETの飽和領域では ID = (1/2)μCox(W/L)(VGS − Vth)² で、ドレイン電流は(VGS − Vth)の2乗に比例します(2乗則)。VGS − Vth はオーバードライブ電圧と呼ばれ、アナログ設計の基本パラメータです。短チャネルでは速度飽和によって1乗に近づき、さらに移動度の劣化や寄生抵抗の影響でずれるため、実際の設計ではBSIMなどの精密なモデルを使います。

ドレイン-ソース間電圧VDSが十分小さい線形領域でのMOSFETの振る舞いとして正しいものはどれか。

  1. Aゲート電圧によって抵抗値が変わる可変抵抗のように振る舞う
  2. BVDSによらず一定の電流を流す定電流源のように振る舞う
  3. C一方向にしか電流を流さないダイオードのように振る舞う
答えと解説を見る

正解：A. ゲート電圧によって抵抗値が変わる可変抵抗のように振る舞う

線形領域ではドレイン電流がVDSにほぼ比例し、その傾き(コンダクタンス)μCox(W/L)(VGS − Vth)がゲート電圧で変わるため、ゲート電圧で制御できる可変抵抗のように振る舞います。スイッチのオン状態はこの領域で、オン抵抗はゲート電圧を高くするほど小さくなります。この性質はアナログスイッチや可変利得回路にも使われます。VDSが VGS − Vth を超えると飽和領域になります。

長チャネルのnMOSFETが飽和領域で動作する条件として正しいものはどれか。(VGS > Vth とする)

  1. AVDS = 0
  2. BVDS < VGS − Vth
  3. CVDS ≥ VGS − Vth
答えと解説を見る

正解：C. VDS ≥ VGS − Vth

VGS > Vth でチャネルがあるとき、VDS ≥ VGS − Vth になると、ドレイン端のゲート-チャネル間電圧がVthを下回ってチャネルがピンチオフし、ドレイン電流はVDSにほとんど依存しなくなります。これが飽和領域です。増幅回路はこの領域で使い、最低限必要なVDS(= VGS − Vth)が出力の振れ幅の下限になります。短チャネルでは速度飽和のため、より低いVDSで電流が飽和します。

飽和領域にあるMOSFETの小信号の出力抵抗roを、チャネル長変調係数λとドレイン電流IDで表した式として適切なものはどれか。

  1. Aro ≈ 1 / (λ × ID)
  2. Bro ≈ ID / λ
  3. Cro ≈ λ × ID
答えと解説を見る

正解：A. ro ≈ 1 / (λ × ID)

チャネル長変調を考えると、飽和領域のドレイン電流は ID(1 + λVDS) の形でVDSとともにわずかに増え、この傾きの逆数が出力抵抗 ro ≈ 1/(λID) です。λはチャネル長にほぼ反比例するため、Lを2倍にするとroも約2倍になります。トランジスタ単体の最大電圧利得は gm·ro で、微細なトランジスタでは10〜20倍程度しかないため、カスコードや多段構成で利得を確保します。

よくある質問

MOSFETが飽和領域で動作する条件は?

nMOSFETでは、VGS > Vth でチャネルができ、さらに VDS ≥ VGS − Vth であれば飽和領域です。VDSがそれより小さいと線形(三極管)領域になります。

MOSFETの飽和領域とバイポーラトランジスタの飽和領域は同じ意味ですか?

違います。MOSFETの飽和領域は電流がVDSにほとんどよらない領域で、増幅に使います。バイポーラトランジスタの飽和はスイッチとして完全にオンした状態で、MOSFETではむしろ線形領域に近い状態です。

出力抵抗roはどう計算しますか?

飽和領域では、チャネル長変調係数λとドレイン電流IDを使って ro ≈ 1/(λID) で見積もります。例えば λ = 0.05 /V、ID = 1 mA なら ro は約20 kΩです。
