4本帯・5本帯の読み方

4本帯の抵抗では、1本目と2本目が数字、3本目が乗数(10のべき乗)、4本目が許容差です。色と数字の対応は、黒0・茶1・赤2・橙3・黄4・緑5・青6・紫7・灰8・白9です。既定値の茶・黒・赤・金は10 × 10² = 1000 Ω、つまり1 kΩ ±5%で、実際の値は950 Ω〜1.05 kΩの範囲に入ります。5本帯では数字の帯が3本になり、茶・黒・黒・茶・茶なら100 × 10 = 1 kΩ ±1%です。桁が一つ多いぶん細かい値を表せるため、許容差の小さい抵抗によく使われます。

どちらの端から読むか

向きを見分ける手がかりはいくつかあります。一般に、許容差の帯はほかの帯から少し離して塗られていて、1本目の帯は胴体の端に寄っています。また、金と銀は数字を表さないので、1本目には来ません。4本帯で端に金か銀があれば、そちらが最後の帯です。5本帯の精密な抵抗では許容差が茶(±1%)のことが多く、両端が茶になって迷うことがあります。その場合は、両方向に読んでE系列にある値になる向きを選ぶか、テスターで実際に抵抗値を測って確かめます。

乗数の金・銀と許容差の色

乗数の帯が数字の色なら、10のその数乗(黒は×1、茶は×10、赤は×100、橙は×1000など)を表し、金は×0.1、銀は×0.01です。たとえば黄・紫・金・金は47 × 0.1 = 4.7 Ω ±5%で、10 Ω未満の値に使われます。許容差の色は、茶±1%、赤±2%、緑±0.5%、青±0.25%、紫±0.1%、金±5%、銀±10%です。帯が3本しかない(許容差の帯がない)抵抗は、一般に±20%を表します。逆引きでは、既定値の4700 Ωは4本帯で黄・紫・赤、5本帯で黄・紫・黒・茶となり、そのあとに許容差の帯が続きます。

E系列と4.7 kΩのような値

市販の抵抗値は、E系列と呼ばれる標準数(IEC 60063)から選ばれています。E6・E12・E24は1桁の範囲をそれぞれ6・12・24に分けた数列で、隣り合う値の比がほぼ一定(E6で約1.47倍、E12で約1.21倍)になるように並んでいます。E12は1.0、1.2、1.5、1.8、2.2、2.7、3.3、3.9、4.7、5.6、6.8、8.2です。等比で並べると10^(4/6) ≈ 4.64となり、これを丸めた値が4.7です。一般にE12は±10%、E24は±5%の許容差と組み合わせて使われ、隣の値と許容差の範囲がおおむね接するように作られています。

よくある質問

抵抗のカラーコードはどちらの端から読みますか?

一般に、胴体の端に寄っている帯が1本目で、少し離れて塗られた帯が許容差です。金と銀は数字を表さないため1本目にはならず、4本帯で端に金か銀があれば、そちらが最後の帯です。それでも判断できないときは、両方向に読んでE系列にある値になるほうを選ぶか、テスターで測って確かめます。

6本目の帯は何を表しますか?

6本帯の抵抗では、5本帯と同じ数字3本・乗数・許容差のあとに、温度係数を表す6本目の帯が加わるのが一般的です。温度係数は、温度が1 K変わったときに抵抗値がどれだけ変わるかをppm/Kで表したもので、精密な回路で重要になります。色と温度係数の対応は規格の表で定められているので、データシートや規格で確かめてください。このツールは4本帯と5本帯に対応しています。

5 kΩではなく4.7 kΩのような半端な値があるのはなぜですか?

抵抗値は、1桁の範囲をほぼ等しい比で分けたE系列から選ばれているためです。E6では1.0 → 1.5 → 2.2 → 3.3 → 4.7 → 6.8のように約1.5倍ずつ増え、10^(4/6) ≈ 4.64を丸めた値が4.7です。等比で並べると、許容差を含めた隣り合う値の範囲がほぼすき間なく並びます。5.0はE24にもありませんが、E24には5.1があります。
