オペアンプ増幅回路の計算

回路の種類を選んで抵抗と入力電圧を入れると、オペアンプ増幅回路のゲイン(増幅率)と出力電圧を計算します。出力が電源電圧を超えて飽和しないかや、目標のゲインに近いE24系列の抵抗の組み合わせも確かめられます。

理想オペアンプとして、直流の値を計算します。周波数特性(利得帯域幅積)、スルーレート、入力オフセット電圧などは考えていません。出力電圧は電源電圧で頭打ちにして表示しますが、実際のオペアンプは電源電圧より手前で飽和します。差動増幅回路は、2組の抵抗の比がそろっている(V2側もR1とRfで分圧する)ものとして計算します。組み合わせの探索では、Rin(非反転増幅ではRg、差動増幅ではR1)を1 kΩ〜100 kΩのE24系列から選びます。

理想オペアンプの前提:仮想短絡と入力電流ゼロ

増幅回路の式は、理想オペアンプの前提から導きます。開ループ利得が非常に大きいこと、入力端子に電流が流れない(入力インピーダンスが無限大)こと、出力インピーダンスがゼロであることです。負帰還をかけると、出力は2つの入力端子の電圧がほぼ等しくなるところで落ち着きます。開ループ利得が10万倍(100 dB)なら、出力が10 Vのときの入力端子間の電圧は0.1 mVしかありません。このように、つながっていないのに短絡したように見える性質を仮想短絡(イマジナリーショート)と呼びます。仮想短絡は、負帰還がかかっていて、出力が飽和していないときだけ成り立ちます。

反転増幅回路の導き方と仮想接地

反転増幅回路では、非反転入力をグラウンドにつなぎ、入力電圧VinをRinを通して反転入力に加え、出力をRfを通して反転入力に戻します。仮想短絡により反転入力は0 Vになり(仮想接地)、Rinを流れる電流Vin/Rinは、オペアンプに入らずにすべてRfを流れます。出力はVout = 0 − Rf·Vin/Rinなので、ゲインはG = −Rf/Rinです。Rf = 100 kΩ、Rin = 10 kΩならG = −10(20 dB)で、Vin = 0.5 Vのときの出力は−5 Vです。マイナスは位相の反転(180°)を表します。信号源から見た入力インピーダンスは、仮想接地までの抵抗Rinそのものです。RfをRinより小さくすれば、ゲインの大きさを1倍より小さくすることもできます。

非反転増幅回路とボルテージフォロワ

非反転増幅回路では、入力電圧Vinを非反転入力に直接加え、出力をRfとRgで分圧して反転入力に戻します。仮想短絡により反転入力もVinになるので、Vin = Vout·Rg/(Rf + Rg)、つまりG = 1 + Rf/Rgです。Rf = 100 kΩ、Rg = 10 kΩならG = 11(約20.8 dB)で、出力は入力と同じ位相です。入力はオペアンプの入力端子に直接つながるため、入力インピーダンスは非常に高く、信号源からほとんど電流を取りません。Rfを0(短絡)にしてRgを外したものがボルテージフォロワで、G = 1です。電圧を変えずに、出力側の抵抗が大きいセンサや分圧回路の信号を後段に渡すバッファとして使います。

差動増幅回路と抵抗の比をそろえる理由

差動増幅回路は、V1をR1を通して反転入力に加え、V2をR1とRfで分圧して非反転入力に加えます。2組の抵抗の比がそろっていれば、Vout = (Rf/R1)(V2 − V1)となり、2つの入力の差だけを増幅します。Rf/R1 = 10、V1 = 1.0 V、V2 = 1.2 Vなら、出力は2.0 Vです。両方の入力に同じだけ乗る雑音(同相信号)は打ち消されますが、それは抵抗の比が正確にそろっているときだけです。比がずれると同相信号が出力に現れ、CMRR(同相信号除去比)が下がります。目安の式(1 + G)/(4 × 許容差)で見積もると、ゲイン1倍で許容差1%の抵抗では最悪でCMRRが約34 dB、0.1%でも約54 dBにとどまります。高いCMRRが必要なら、比をそろえた抵抗ネットワークや計装アンプを使います。浮いた(グラウンドにつながない)信号源から見た差動入力インピーダンスは2·R1です。

実際のオペアンプの限界(このツールは理想の直流値)

このツールが示すのは理想オペアンプの直流の値で、実際の回路には次のような限界があります。まず出力の振れ幅で、出力は電源電圧までは振れず、一般的なオペアンプでは電源から1〜2 V程度、レール・ツー・レール出力の品種でも負荷に応じて数十mV程度手前で飽和します。次に帯域で、帯域幅はおよそGBW ÷ ノイズゲインになり、ノイズゲインは反転・非反転のどちらでも1 + Rf/Rinです。GBWが1 MHzなら、ゲイン−10の反転増幅もゲイン11の非反転増幅も、帯域は約91 kHzです。さらにスルーレートにより出力の変化の速さに上限があり、0.5 V/µsの品種で振幅10 Vの正弦波を出せるのは約8 kHzまでです。入力オフセット電圧もノイズゲイン倍されて出力に現れ、2 mVなら11倍で22 mVになります。

アナログ・電子回路の問題を解く

理想オペアンプを使った反転増幅回路で、入力抵抗Ri = 10 kΩ、帰還抵抗Rf = 100 kΩのとき、電圧利得はいくらか。

  1. A+11倍
  2. B-0.1倍
  3. C-10倍
答えと解説を見る

正解：C. -10倍

反転増幅回路の利得は −Rf/Ri で、−100 kΩ/10 kΩ = −10倍です。反転入力が仮想接地になるため、入力電流 Vin/Ri がすべてRfに流れ、出力は −Rf × Vin/Ri になるという理屈です。入力インピーダンスはRiそのもの(10 kΩ)なので、信号源の負担になる点に注意します。+11倍は同じ抵抗で非反転増幅回路を組んだときの利得(1 + Rf/Ri)です。

理想オペアンプを使った非反転増幅回路で、入力側の抵抗R1 = 10 kΩ、帰還抵抗R2 = 90 kΩのとき、電圧利得はいくらか。

  1. A−9倍
  2. B+9倍
  3. C+10倍
答えと解説を見る

正解：C. +10倍

非反転増幅回路の利得は 1 + R2/R1 で、1 + 90/10 = 10倍、出力は入力と同相です。入力が非反転入力に直接入るため入力インピーダンスが非常に高く、信号源に負担をかけないのが利点です。利得は1倍未満にはできません(R2 = 0でボルテージフォロワ)。反転増幅回路の −R2/R1(ここでは−9倍)と混同しないようにしましょう。

利得帯域幅積(GBW)が1 MHzのオペアンプで、利得10倍の非反転増幅回路をつくったときの帯域幅はおよそいくらか。

  1. A約10 MHz
  2. B約10 kHz
  3. C約100 kHz
答えと解説を見る

正解：C. 約100 kHz

内部で位相補償されたオペアンプは、開ループ利得が −20 dB/dec で下がるため、利得と帯域幅の積がほぼ一定です。GBWが1 MHzなら、利得10倍の帯域は 1 MHz ÷ 10 = 約100 kHz です。正確には非反転利得(ノイズゲイン)で割るため、反転増幅回路の−10倍は ÷11 で約91 kHz になります。高利得と広帯域を両立したいときは、GBWの大きいオペアンプを選ぶか、増幅を複数段に分けます。

よくある質問

反転増幅回路のゲインはどう計算しますか?

G = −Rf/Rinです。Rf = 100 kΩ、Rin = 10 kΩならG = −10で、dBでは20·log10(10) = 20 dBです。マイナスは出力の位相が入力と反転することを表します。入力インピーダンスはRinと同じなので、信号源の出力側の抵抗に比べてRinを十分大きくします。

非反転増幅回路のゲインはどう計算しますか?

G = 1 + Rf/Rgです。Rf = 100 kΩ、Rg = 10 kΩならG = 11で、dBでは約20.8 dBです。反転増幅回路と同じ抵抗でも、ゲインの大きさは1だけ大きくなります。ゲインを1倍より小さくすることはできず、Rf = 0にするとゲイン1のボルテージフォロワになります。

反転増幅と非反転増幅はどう使い分けますか?

信号源に負担をかけたくない(入力インピーダンスを高くしたい)ときは非反転増幅を使うのが基本です。位相を反転したいとき、1倍より小さいゲインが必要なとき、複数の入力を足し合わせたいときは反転増幅を使います。反転増幅は入力端子が仮想接地で一定の電圧に保たれるため、オペアンプの同相入力電圧範囲の制約を受けにくいという利点もあります。

出力電圧が計算どおりにならないのはなぜですか?

計算した出力が電源電圧を超えると、出力は頭打ちになって飽和します。±15 V電源でゲイン−10の反転増幅に2 Vを入れると、計算では−20 Vですが、実際には電源より手前の−13 V前後で止まります(値は品種と負荷によります)。ほかにも、周波数が高いと利得帯域幅積やスルーレートの制限で、直流では入力オフセット電圧で、計算とずれます。

抵抗値の大きさはどう選べばよいですか?

ゲインは抵抗の比で決まるので、同じ比でも大きさは選べます。一般に1 kΩ〜100 kΩ程度がよく使われます。小さすぎると帰還抵抗や負荷に流れる電流が増え、オペアンプの出力電流の上限や消費電力が問題になります。大きすぎると、抵抗の熱雑音、入力バイアス電流による誤差、寄生容量による帯域の低下が大きくなります。このツールの組み合わせの探索も、Rinを1 kΩ〜100 kΩから選びます。
