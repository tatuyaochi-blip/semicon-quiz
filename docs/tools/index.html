半導体・電子回路・情報の計算ツール

ダイの数や露光の解像度といった半導体の数字から、合成抵抗やオペアンプなどの電子回路、論理回路のシミュレーターやカルノー図、2進数・浮動小数点数・CRC、サブネット・待ち行列・稼働率まで、ブラウザ上で使える無料のツールです。

お気に入り

最近使ったツール

お気に入りと最近使ったツールは、このブラウザ内（localStorage）にのみ保存されます。別の端末やブラウザとは共有されません。

基礎

セットアップ・ホールドのタイミング計算クロック周期と遅延から、セットアップ・ホールドの余裕(スラック)と最大周波数を計算MOSFETの電流-電圧特性(ID–VDS)しきい値電圧やW/Lを変えて、ID–VDS特性と動作点(領域・ID・gm・ro)を確かめるADコンバータのSN比と有効ビット数(ENOB)分解能、クロックジッタ、オーバーサンプリングから、ADコンバータのSN比と有効ビット数を計算PN接合の内蔵電位と空乏層幅不純物濃度と逆バイアス電圧から、PN接合の内蔵電位、空乏層幅、最大電界、接合容量を計算位相雑音からRMSジッタへの換算位相雑音のプロファイル(dBc/Hz)を積分して、クロックのRMS位相誤差とRMSジッタを計算シリコンの抵抗率と不純物濃度の換算シリコンの抵抗率と不純物濃度(n型・p型)を相互に換算し、移動度も表示真性キャリア密度の温度依存Si・Ge・GaAsの真性キャリア密度niを温度から計算。不純物濃度を入れると真性化する温度もわかるMOSFETのしきい値電圧酸化膜厚・基板濃度・ゲート材料・固定電荷・基板バイアスから、MOSFETのしきい値電圧を計算dB・dBm 換算ツールdBm と mW・W、負荷抵抗での電圧、dB と電力比・電圧比を相互に換算抵抗のカラーコード色の帯から抵抗値と許容差を読み、抵抗値から色の並びを調べる分圧回路の計算2本の抵抗で分けた電圧と、負荷をつないだときの電圧・電流・消費電力LED の電流制限抵抗の計算電源電圧・LED の順方向電圧・電流から、直列抵抗の値と消費電力を計算RC 時定数の計算抵抗とコンデンサから時定数・カットオフ周波数・充放電の割合を計算論理回路シミュレーターゲートやフリップフロップを並べて配線し、スイッチで動かしながら真理値表を自動で作る論理回路エディタカルノー図・論理式の簡単化ツール真理値表かカルノー図のマスをクリックして0・1・Xを入れると、最小の積和形と和積形を求め、グループを色分けして描きます合成抵抗・合成容量の計算抵抗・コンデンサ・コイルを直列・並列にしたときの合成値と、目標値に近いE24の2本の組み合わせオペアンプ増幅回路の計算反転・非反転・差動増幅回路のゲイン、dB、出力電圧と飽和、目標ゲインに近いE24の抵抗の組み合わせ画像・音声・動画のデータ量の計算ツール画素数と色の深さから画像の、標本化周波数と量子化ビット数から音声の、フレームレートから動画のデータ量とビットレートを計算。圧縮率と転送時間も状態遷移図ツール状態遷移表から状態遷移図を描き、入力の列で状態と出力の変化を1つずつたどる。ムーア型・ミーリ型と状態の最小化に対応

デバイス

メモリ帯域幅の計算転送レートとバス幅から、DDR・LPDDR・GDDR・HBMのピーク帯域と実効帯域の目安を計算バンドギャップと発光波長の換算バンドギャップ(eV)と発光波長(nm)を相互に換算。Si・GaAs・GaNなど代表的な材料のプリセットつき

前工程

露光の解像度・焦点深度の計算波長・NA・k1から、解像できる線幅と焦点深度、必要なパターン分割の回数を計算熱酸化の膜厚(Deal-Groveモデル)温度・時間・ドライ/ウェット・面方位から、Deal-Groveモデルでシリコン酸化膜の厚さと消費されるシリコンを計算LSIの配線のRC遅延配線の金属・幅・厚さ・間隔・比誘電率・長さから、配線の抵抗と容量、分布RC線路の遅延とドライバを含めた遅延を計算

後工程・評価

ダイ数・歩留まり計算ツールウエハ径・チップサイズ・欠陥密度から、ダイ数・歩留まり・良品1個のコストを計算PDNの目標インピーダンスとデカップリングコンデンサ電源電圧・許容リップル・電流の変化から目標インピーダンスを求め、デカップリングコンデンサの自己共振周波数と効く周波数範囲を計算稼働率の計算ツールMTBF・MTTRから稼働率を求め、直列・並列・n台中k台の装置を組み合わせたシステムの稼働率と年間停止時間を計算

設計・産業

接合温度(Tj)と熱抵抗の計算消費電力と熱抵抗から、チップの接合温度、最大接合温度までの余裕、使える最大電力を計算

コンピュータシステム

アムダールの法則と並列化の速度向上並列化できる割合とプロセッサ数から、アムダールの法則とグスタフソンの法則で速度向上率と並列効率を計算キャッシュのアドレス分割と平均メモリアクセス時間容量・ラインサイズ・連想度から、タグ・インデックス・オフセットのビット数と平均メモリアクセス時間を計算CMOS回路の消費電力(動的電力と静的電力)活動率・容量・電圧・周波数とリーク電流から、動的電力と静的電力、DVFSで電圧と周波数を下げたときの電力を計算基数変換・2の補数ツール2進数・8進数・10進数・16進数を相互に変換し、8〜64ビットの2の補数と符号なし・符号つきの値を表示浮動小数点数(IEEE 754)変換ツール10進数を半精度・単精度・倍精度のビット列に変換し、実際に記憶される値と誤差を表示CRC計算ツールCRC-8・CRC-16・CRC-32などを、文字列か16進数のバイト列から計算。多項式の割り算の途中も表示ハミング符号の計算ツールデータをハミング符号に符号化し、ビットを押して誤りを入れると、シンドロームで位置を求めて訂正する様子を確かめられますIPアドレス・サブネット計算ツールIPアドレスとCIDR・サブネットマスクから、ネットワークアドレス、ブロードキャストアドレス、ホスト数を計算。2進数の表示とサブネットの分割にも対応待ち行列の計算ツール(M/M/1・M/M/c)到着率・平均サービス時間・窓口の数から、M/M/1とM/M/cの利用率、平均待ち時間、応答時間、待っている数を計算データ転送時間の計算ツールデータ量と回線速度、伝送効率から転送にかかる時間を計算。バイトとビットの換算の途中と、決まった時間で送るのに必要な回線速度も表示パスワードの総当たり時間の計算ツール文字の種類と長さから組み合わせの数とエントロピーを求め、総当たりにかかる時間を試算SQL練習ツールブラウザの中でSQLを実行して結果を確かめ、10問の練習問題で答え合わせもできる練習ツールソートの動きを見るツールバブル・選択・挿入・シェル・マージ・クイック・ヒープの7種類のソートを棒グラフで1手ずつ再生。比較と書き込みの回数も比べられるダイクストラ法の計算ツール辺の重みの一覧から最短経路と最短距離を計算。頂点を確定していく手順を表と図で1回ずつたどれる二分探索木・ヒープの可視化ツール値を順に挿入した二分探索木やヒープを図にし、先行順・中間順・後行順のなぞり順、探索の経路、ヒープの配列を表示ハッシュ表の計算ツールキーをハッシュ表に入れたときの衝突と格納位置を、チェイン法・線形探査・二次探査・ダブルハッシュで表示。負荷率と平均の探査回数も計算計算量(オーダー)の比較ツールO(log n)・O(n)・O(n log n)・O(n²)・O(2ⁿ) などで、データ数に応じた処理の回数と時間を比較。データ数を変えたときの処理時間も見積もれる逆ポーランド記法の変換ツール中置記法の式を逆ポーランド記法(後置記法)とポーランド記法(前置記法)に変換。スタックの動き・構文木・計算の途中も表示ページ置換アルゴリズムの計算ツール参照列とページ枠の数から、FIFO・LRU・OPT・Clockのページフォルトの回数と枠の中身の移り変わりを表で表示CPUスケジューリングの計算ツール到着時刻と実行時間から、FCFS・SJF・SRT・ラウンドロビン・優先度順のガントチャートと平均待ち時間・ターンアラウンド時間を計算クリティカルパスの計算ツール作業の所要日数と先行作業から、最早・最遅の開始日、余裕日数、クリティカルパスと全体の日数を計算し、ガントチャートで表示EVM(アーンドバリュー)の計算ツールPV・EV・AC と完成時総予算から、SV・CV・SPI・CPI と完成時総コストの見積もり(EAC)を計算し、遅れ・超過を判定
