問題セットを作る

授業の小テストや社内研修のために、分野と問題数を選んでクイズの問題セットを作れます。発行したURLを配れば、全員が同じ問題を、解説付きで解けます。登録は不要です。

お気に入りと最近使ったツールは、このブラウザ内（localStorage）にのみ保存されます。

セットの内容

分野

問題セットのURL

開いて確かめる

このURLを開いた人は、同じ問題を解けます(選択肢の順番は毎回入れ替わります)。結果はそれぞれのブラウザに保存され、こちらには送られません。

サイトや授業資料に埋め込む

このコードをブログや学習管理システムのHTMLに貼ると、ページの中でそのままクイズを解けます。

グラフで見る

ほかの入力は今の値のまま、選んだ入力だけを今の値の1/4〜4倍の範囲で変えたときの結果です。赤い点が今の値です。

使い方

分野にチェックを入れ、問題数を選んで「URLを発行する」を押すと、選んだ分野から偏りなく問題を選んだURLができます。セットの名前を入れると、クイズの画面にその名前が表示されます。発行したURLは、学習管理システム、メール、チャットなどでそのまま配れます。同じURLを開けば、何度でも同じ問題を出題できます。

成績や個人情報の扱い

このサイトはアカウント登録もデータベースも使っていません。解いた結果は、解いた人のブラウザの中にだけ保存されます。成績を集めたいときは、結果画面のスクリーンショットや点数を提出してもらうなど、授業や研修の方法に合わせて工夫してください。

よくある質問

問題セットは無料で作れますか?

はい、登録不要・無料で作れます。発行したURLにも有効期限はありません。

生徒ごとに問題は同じですか?

同じURLなら全員が同じ問題を解きます。選択肢の並び順は、答えを覚えて回せないように毎回入れ替わります。
