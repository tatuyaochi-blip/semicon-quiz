PN接合の内蔵電位と空乏層幅

p側とn側の不純物濃度と逆バイアス電圧を入れると、階段接合の空乏近似で、内蔵電位、空乏層の幅とその広がり方、接合の最大電界、接合容量を計算します。濃度の差や電圧によって空乏層がどう変わるかを、数字で確かめられます。

内蔵電位と空乏層幅の式

p型とn型を接合すると、境界付近の電子と正孔が拡散して再結合し、イオン化した不純物だけが残る空乏層ができます。その電荷がつくる電位差が内蔵電位で、Vbi = (kT/q)ln(NA·ND/ni²) です。空乏層の中の電荷密度を一定とみなす空乏近似でポアソン方程式を解くと、空乏層幅は W = √(2εs(Vbi + VR)/q × (1/NA + 1/ND)) となります。既定値のSi、NA = 10¹⁷ cm⁻³、ND = 10¹⁶ cm⁻³、VR = 0 V では、Vbi ≈ 0.774 V、W ≈ 0.332 µm です。

空乏層は低濃度側に広がる

空乏層の両側では、イオン化した不純物の電荷の量が等しく、NA·xp = ND·xn が成り立ちます。そのため、濃度の低い側ほど広く空乏化します。既定値では、n側に0.302 µm広がるのに対し、p側は0.030 µmだけで、ほぼ片側階段接合とみなせます。電界は接合面で最大になり、Emax = qND·xn/εs = 2(Vbi + VR)/W で、既定値では約46.6 kV/cmです。逆バイアスを5 Vにすると、Wは (Vbi + VR) の平方根に比例して約0.906 µmに広がり、Emaxは約127 kV/cmに上がります。

接合容量とC-V測定

逆バイアスの空乏層は、両側に電荷を持つ平行平板のコンデンサとみなせるので、単位面積あたりの接合容量は Cj = εs/W です。既定値では約31.2 nF/cm²で、逆バイアス5 Vでは約11.4 nF/cm²に減ります。電圧で容量が変わるこの性質を利用したのが、可変容量ダイオード(バラクタ)です。また、片側階段接合では 1/Cj² が電圧に比例し、その傾きから低濃度側の不純物濃度が求められるため、C-V測定は濃度分布の評価にも使われます。

材料の違いと設計での使い方

内蔵電位は、バンドギャップが大きくniが小さい材料ほど大きくなり、同じ濃度でもGeでは約0.38 V、GaAsでは約1.21 Vです。niは温度にも強く依存するので、温度が上がるとVbiは下がります。逆バイアスを上げてEmaxが臨界電界(Siでは濃度によりますが約3×10⁵ V/cm)に近づくと、なだれ降伏が起こります。パワーデバイスでは、低濃度で厚いドリフト層に空乏層を広げて電界を下げ、高い耐圧を得ます。逆に両側を高濃度にするとWが薄くなり、低い電圧でトンネル効果によるツェナー降伏が起こります。

PN接合の問題を解く

PN接合に加える逆方向バイアス電圧を大きくすると、空乏層の幅はどうなるか。

  1. A狭くなる
  2. B変化しない
  3. C広くなる
答えと解説を見る

正解：C. 広くなる

逆方向バイアスでは外部電圧が内蔵電位と同じ向きに加わり、キャリアがさらに接合から引き離されるため、空乏層は広がります。幅はおよそ √(Vbi + V) に比例し、Vが内蔵電位より十分大きければ、例えば電圧を4倍にすると約2倍になります。空乏層が広がると接合容量(C = εA/W)は小さくなり、この性質が可変容量ダイオードに使われます。電界を受け持つ幅が広がることは、耐圧の確保にもつながります。

p側の不純物濃度がn側よりはるかに高いPN接合(p+n接合)で、空乏層はどのように広がるか。

  1. A不純物濃度の低いn側に大きく広がる
  2. B不純物濃度の高いp側に大きく広がる
  3. C必ずp側とn側に等しく広がる
答えと解説を見る

正解：A. 不純物濃度の低いn側に大きく広がる

空乏層の両側では、イオン化した不純物の電荷の量が等しくなります(NA·xp = ND·xn)。低濃度側は同じ電荷を得るために広い範囲が空乏化するので、p+n接合では空乏層のほとんどがn側に広がります。このため耐圧や容量は低濃度側の濃度でほぼ決まり、計算も片側だけで近似できます(片側階段接合)。パワーデバイスの低濃度ドリフト層は、この性質を利用して高い電圧を受け持ちます。

PN接合の内蔵電位(拡散電位)と、両側の不純物濃度の関係として正しいものはどれか。

  1. A不純物濃度とは無関係に一定である
  2. B不純物濃度が高いほど小さくなる
  3. C不純物濃度が高いほど大きくなる
答えと解説を見る

正解：C. 不純物濃度が高いほど大きくなる

内蔵電位は Vbi = (kT/q)·ln(NA·ND/ni²) で、両側の不純物濃度が高いほど大きくなります。対数で効くため、濃度を10倍にしても約60 mV増えるだけで、シリコンでは一般に0.6〜0.9 V程度です。外部から電圧計で測ることはできず(電極の接触電位で打ち消される)、順方向電圧の目安や空乏層幅の計算に使われます。ギャップの大きい材料ほど ni が小さく、Vbi は大きくなります。

逆バイアスのPN接合の空乏層容量(接合容量)Cを、接合の面積A、空乏層の幅W、半導体の誘電率εで表した式はどれか。

  1. AC = εA / W
  2. BC = εW / A
  3. CC = ε / (A × W)
答えと解説を見る

正解：A. C = εA / W

空乏層は両側に電荷がたまった絶縁層のように振る舞うため、平行平板コンデンサと同じく C = εA/W で表せます。逆バイアスでWが広がると容量は小さくなります。例えばシリコンで面積100 µm角、W = 1 µm なら、C ≈ 11.7 × 8.85×10⁻¹² × 10⁻⁸ ÷ 10⁻⁶ ≈ 1 pF です。高速回路ではこの容量が遅延の原因になるため、接合面積を小さくしたり低濃度にしたりして減らします。

よくある質問

p+n接合では、空乏層はどちらに広がりますか?

濃度の低いn側にほとんどが広がります。NA·xp = ND·xn の関係から、例えば NA = 10¹⁹ cm⁻³、ND = 10¹⁶ cm⁻³ では、空乏層の99.9%がn側にあります。このため耐圧や接合容量は、ほぼ低濃度側の濃度で決まります。

逆バイアス電圧を4倍にすると、空乏層幅はどうなりますか?

Wは (Vbi + VR) の平方根に比例するので、VRが内蔵電位より十分大きければ約2倍になります。接合容量はWに反比例するので約半分になります。内蔵電位が無視できない低い電圧では、Vbiを足してから比べてください。

順方向バイアスでも計算できますか?

VRに負の値を入れると、電位差が Vbi − VF に減って空乏層が縮む様子を計算できます。ただし、電流が大きく流れる状態では空乏近似の精度が落ち、VFがVbiに達すると空乏層の幅がゼロになるため、この式は使えません。
