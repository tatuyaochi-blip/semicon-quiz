λ [nm] = hc/(q·Eg[eV]) ≈ 1239.84/Eg で計算しています。プリセットのバンドギャップは温度300 Kでの代表的な物性値です。実際の発光波長は、発光スペクトルの幅、温度、混晶の組成、量子井戸の閉じ込めなどで数nm〜数十nmずれます。間接遷移の材料は発光が弱く、ふつうはLEDに使われません。

換算式 λ ≈ 1240/Eg

光子1個のエネルギーは E = hν = hc/λ です。プランク定数 h = 6.626×10⁻³⁴ J·s、光速 c = 2.998×10⁸ m/s、電気素量 q = 1.602×10⁻¹⁹ C を入れて単位を eV と nm にそろえると、E[eV] × λ[nm] ≈ 1239.84 となり、λ ≈ 1240/Eg と覚えられます。半導体で伝導帯の底の電子が価電子帯の頂上の正孔と再結合して光を出すとき、光子のエネルギーはほぼバンドギャップに等しいので、この式で発光波長の目安がわかります。受光素子では逆に、1240/Eg より長い波長の光は吸収されず、これが感度の限界(カットオフ波長)になります。

前提条件

光子のエネルギーがバンドギャップに等しい、つまり伝導帯の底と価電子帯の頂上の間の遷移だけを考えています。実際のLEDの発光ピークは、キャリアの熱エネルギー(kT程度)の分だけ少し高いエネルギー側に出て、幅を持ちます。温度が上がるとバンドギャップは小さくなり、波長は長い方へずれます。InGaNやAlGaAsのような混晶では組成でバンドギャップが変わり、量子井戸では閉じ込めのエネルギーが加わるため、同じ材料名でも発光波長は製品ごとに違います。

計算例

既定値のGaAs(Eg = 1.42 eV)では λ ≈ 1239.84/1.42 ≈ 873 nm で、近赤外のLEDなどに使われる波長です。Si(1.12 eV)は約1107 nmで、シリコンの受光素子が約1.1 µmより長い波長をほとんど感じない理由がわかります。GaN(3.4 eV)は約365 nmの紫外で、青色LEDではInを混ぜたInGaNでバンドギャップを約2.7 eVまで下げ、約460 nmの青を出します。逆に、光通信の1550 nmに対応するバンドギャップは約0.80 eVで、InPの上に作るInGaAsPなどの混晶が使われます。

使っている値と出典の種類

プリセットのバンドギャップは、半導体の教科書や物性値の便覧に載っている、温度300 Kでの代表的な物性値です(Si 1.12、Ge 0.66、GaAs 1.42、InP 1.34、In₀.₅₃Ga₀.₄₇As 0.75、GaP 2.26、4H-SiC 3.26、GaN 3.4、ZnO 3.37、ダイヤモンド 5.47、AlN 6.2 eV)。文献によって小数第2位程度の違いがあります。直接遷移と間接遷移の区別も代表的な分類です。換算の定数 1239.84 eV·nm は、物理定数 h、c、q の値から求めたものです。

化合物半導体の問題を解く

波長620 nmの光の光子1個がもつエネルギーに最も近い値はどれか。(E [eV] ≈ 1240 / λ [nm])

  1. A約1.0 eV
  2. B約3.0 eV
  3. C約2.0 eV
答えと解説を見る

正解：C. 約2.0 eV

光子のエネルギーは E = hc/λ で、eVとnmで表すと E ≈ 1240/λ です。λ = 620 nm(赤色)なら E ≈ 2.0 eV になります。この換算式を使うと、Si(1.12 eV)の吸収端は約1.1 µm、GaN(3.4 eV)は約365 nmの紫外とすぐに求まります。LEDの発光色はおおむねバンドギャップで決まるため、赤色LEDには約1.9〜2.0 eVのAlGaInPなどが使われます。

バンドギャップ約1.42 eVのGaAsから出る光のおよその波長はどれか。

  1. A約450 nm(青色)
  2. B約870 nm(近赤外)
  3. C約10 µm(遠赤外)
答えと解説を見る

正解：B. 約870 nm(近赤外)

波長は λ(nm) ≈ 1240/Eg(eV) で、1240/1.42 ≈ 873 nm となり、目に見えない近赤外の光です。GaAs系のLEDはテレビのリモコンや光電センサ、GaAs/AlGaAsのVCSELは850 nm付近でスマートフォンの顔認証や短距離の光通信に使われます。可視光(約400〜700 nm)を出すには、GaAsPやAlGaInPのようにバンドギャップを大きくした材料が必要です。

LEDの発光色(発光波長)を決める主な要因はどれか。

  1. Aパッケージの形状
  2. B駆動電流の向き
  3. C発光層に使う半導体のバンドギャップ
答えと解説を見る

正解：C. 発光層に使う半導体のバンドギャップ

LEDでは電子と正孔が再結合するとき、バンドギャップに相当するエネルギーの光が出ます。波長は λ(nm) ≈ 1240/Eg(eV) で、例えばGaN系(InGaN)は約2.7 eVで青色の約460 nm、AlGaInPは約1.9 eVで赤色の約650 nmです。発光層の組成を変えるとバンドギャップを調整でき、同じInGaNでもInを増やすと緑色になります。白色LEDは青色LEDと黄色の蛍光体の組み合わせです。

よくある質問

1240という数はどこから来るのですか?

プランク定数と光速の積を電気素量で割った hc/q = 1.23984×10⁻⁶ eV·m を、nm の単位に直した値です。光子のエネルギー(eV)と波長(nm)の積が常に約1240になる、という関係を表しています。

シリコンが光らないのはなぜですか?

シリコンは間接遷移型で、伝導帯の底と価電子帯の頂上で電子の運動量が違うため、光を出すにはフォノン(格子振動)の助けが必要です。その確率が低く、熱になる再結合の方が先に起こるので、発光はとても弱くなります。光を吸収する方はフォノンを介して起こるので、受光素子やイメージセンサーには使えます。

白色LEDの波長も計算できますか?

多くの白色LEDは、青色LED(約450〜460 nm)の光で黄色の蛍光体を光らせ、混ぜて白に見せています。この式で計算できるのは青色LEDの部分で、蛍光体の発光は別の仕組みです。
