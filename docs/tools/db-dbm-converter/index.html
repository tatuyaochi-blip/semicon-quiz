dBm・dBW・dBµVとは

dBmは、1 mWを基準にした電力の大きさを、P[dBm] = 10·log10(P/1 mW)で表した単位です。逆に、P[mW] = 10^(dBm/10)、P[W] = 10^(dBm/10)/1000で電力に戻せます。dBWは1 Wを基準にした値で、dBm − 30に等しくなります。dBµVは1 µVを基準にした電圧の単位で、20·log10(V/1 µV)です。既定値の0 dBmは1 mW、つまり−30 dBWです。比をとって対数にすることで、何桁にもわたる電力の大きさを、足し算と引き算で扱えるようになります。

50 Ωの負荷での電圧

電力が分かれば、負荷抵抗Rにかかる正弦波の実効電圧はVrms = √(P·R)で求められます。既定値の0 dBm(1 mW)とR = 50 Ωでは、Vrms = √(0.001 × 50) ≈ 223.6 mV、ピーク間電圧はその2√2倍で約632.5 mV、dBµVでは約106.99 dBµVです。50 Ωの系では「dBµV ≈ dBm + 107」と覚えておくと便利です。50 Ωは、多くの高周波機器や同軸ケーブルで標準として使われている特性インピーダンスです。映像機器などでは75 Ωも使われ、同じ0 dBmでも電圧は約273.9 mVになります。

dBは電力比なら10·log、電圧比なら20·log

dBそのものは単位ではなく、比を表します。電力の比はdB = 10·log10(P2/P1)です。電力は電圧の2乗に比例する(P = V²/R)ため、同じ抵抗の上で電圧の比を表すときはdB = 20·log10(V2/V1)になります。既定値の3 dBは、電力比で約1.995倍、電圧比で約1.413倍です。3 dBがほぼ電力2倍、6 dBがほぼ電圧2倍(電力4倍)、10 dBがちょうど電力10倍、20 dBが電圧10倍(電力100倍)と覚えておくと、暗算でおおよその値が分かります。

よく使う値と計算の注意

目安として、−30 dBmは1 µW、0 dBmは1 mW、10 dBmは10 mW、20 dBmは100 mW、30 dBmは1 W、40 dBmは10 Wです。dBmにdBの利得や損失を足すと、そこを通ったあとの電力がdBmで得られます。一方、dBm同士を足しても意味はなく、二つの信号の電力を合わせるときは、いったんmWに戻してから足します。たとえば相関のない0 dBmの信号を二つ合わせると約3 dBmです。電圧への換算は、正弦波で負荷抵抗が分かっている場合に限ります。オーディオで使われてきた600 Ωでは、0 dBmが約0.775 Vにあたります。

アナログ・電子回路の問題を解く

よくある質問

dBmをワット(W)に換算するには?

P[W] = 10^(dBm/10)/1000で計算します。10 dBmは0.01 W、20 dBmは0.1 W、30 dBmは1 W、40 dBmは10 Wで、10 dB増えるごとに電力は10倍になります。逆にワットからdBmへは、dBm = 10·log10(P[W]) + 30で換算します。

dBとdBmの違いは何ですか?

dBは二つの量の比を表すもので、それだけでは絶対的な大きさを持ちません。dBmは1 mWに対する比なので、電力の絶対値を表します。増幅器の利得やケーブルの損失はdB、送信出力や受信レベルはdBmで表し、たとえば10 dBmの信号が20 dBの増幅器を通ると、飽和しない範囲で30 dBm(1 W)になります。

電圧のdBはなぜ20·logなのですか?

dBはもともと、電力の比を10·log10で表すものです。電力は電圧の2乗に比例するので、同じ抵抗の上では10·log10(V2²/V1²) = 20·log10(V2/V1)となります。そのため電圧が2倍なら約6 dB、10倍なら20 dBです。抵抗(インピーダンス)の違う2点の電圧を比べるときは、20·logの値が電力比のdBと一致しないことに注意してください。
