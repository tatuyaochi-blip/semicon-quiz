直列と並列の合成の式

直列につなぐと、すべての部品に同じ電流が流れ、それぞれの電圧が足し合わされます。抵抗ではV = I·R1 + I·R2 + …なので、合成抵抗は和のR = R1 + R2 + …になります。並列につなぐと、すべての部品に同じ電圧がかかり、それぞれの電流が足し合わされます。I = V/R1 + V/R2 + …なので、1/R = 1/R1 + 1/R2 + …です。並列は電流の通り道が増えることにあたり、合成抵抗はいちばん小さい抵抗よりさらに小さくなります。たとえば100 Ω、200 Ω、300 Ωは、直列で600 Ω、並列で約54.5 Ωです。コイルも、同じ電流で電圧V = L·dI/dtが足し合わされるため、抵抗と同じ式になります。

コンデンサだけ式が逆になる理由

コンデンサは、並列で和、直列で逆数の和の逆数になり、抵抗とは逆です。平行平板コンデンサの容量はC = εS/d(S:極板の面積、d:極板の間隔)で、並列につなぐのは極板の面積を広げること、同じコンデンサを直列につなぐのは極板の間隔を広げることにあたるためです。式で見ると、直列では各コンデンサに同じ電荷Qがたまり、電圧V = Q/C1 + Q/C2 + …が足し合わされるので、1/C = 1/C1 + 1/C2 + …になります。たとえば10 µFと22 µFは、並列で32 µF、直列で約6.88 µFです。直列では、容量の小さいコンデンサほど大きな電圧がかかる点にも注意します。

2本の並列は「積÷和」、同じ値のn本はR/n

2本の抵抗の並列は、1/R = 1/R1 + 1/R2を変形したR = R1R2/(R1 + R2)(積÷和)で求められます。6 Ωと3 Ωなら18 ÷ 9 = 2 Ωです。同じ値Rの抵抗をn本並列にするとR/nになり、10 kΩを2本で5 kΩ、4本で2.5 kΩです。値が大きく違う2本を並列にすると、ほぼ小さいほうの値になります。100 Ωと10 kΩの並列は約99.0 Ωで、大きい抵抗は小さい抵抗の値をわずかに下げる微調整に使えます。コンデンサの直列も同じ形のC1C2/(C1 + C2)になり、100 nFを2個直列にすると50 nFです。

E系列と、2本の組み合わせで目標値に近づける方法

市販の抵抗やコンデンサの値は、E系列という等比に近い数列から選ばれています。E24系列は1桁(10倍)の間を24の値に分けたもので、隣の値との比は平均で約1.1倍(10の1/24乗)です。ただし間隔は一定ではなく、1.3と1.5の間は約15%離れているため、1.4 kΩに最も近い1本は1.3 kΩか1.5 kΩで、誤差は約7%になります。2本を組み合わせれば、1.2 kΩ + 200 Ωの直列でちょうど1.4 kΩが作れます。このツールは、範囲内のE24の値から選んだすべての2本の組を直列と並列で調べ、誤差の小さい順に示します。100 Ω〜100 kΩの目標値で試すと、目安として9割ほどの値で誤差は0.1%以下、悪い場合でも約0.33%に収まります。

組み合わせるときの許容差と定格電力

目標値ぴったりの組を見つけても、実際の値は部品の許容差の分だけずれます。許容差±5%の抵抗2本を直列や並列にした合成値の許容差は、最悪の場合で±5%のままで、組み合わせても精度は上がりません。精度が必要なら、E96系列などの許容差±1%以下の抵抗を使います。電力にも注意します。直列では同じ電流が流れるので大きい抵抗ほど、並列では同じ電圧がかかるので小さい抵抗ほど大きな電力を消費します。5 Vに100 Ωと1 kΩを並列につなぐと、100 Ωは250 mW、1 kΩは25 mWを消費します。同じ値の2本を並列にすれば電力は半分ずつになり、1/4 W品2本で1/2 W分を扱えますが、定格には余裕(ディレーティング)を持たせます。コンデンサを直列にして耐圧を上げる場合は、もれ電流の差で電圧が偏らないよう、各コンデンサに並列にバランス用の抵抗を入れるのが一般的です。

電気回路・電磁気の基礎の問題を解く

100 Ω、200 Ω、300 Ωの3本の抵抗を直列に接続したときの合成抵抗はいくらか。

  1. A約55 Ω
  2. B600 Ω
  3. C200 Ω
答えと解説を見る

正解：B. 600 Ω

直列接続の合成抵抗は各抵抗の和で、100 + 200 + 300 = 600 Ωです。直列では3本に同じ電流が流れ、電圧は抵抗値に比例して分かれます。例えば12 Vを加えると、電流は 12 V/600 Ω = 20 mA で、各抵抗の電圧は2 V、4 V、6 Vになります。同じ3本を並列にすると、合成抵抗は最も小さい100 Ωより小さい約55 Ωになります。

6 Ωと3 Ωの抵抗を並列に接続したときの合成抵抗はいくらか。

  1. A2 Ω
  2. B9 Ω
  3. C4.5 Ω
答えと解説を見る

正解：A. 2 Ω

2本の並列の合成抵抗は R1R2/(R1 + R2)(和分の積)で、6 × 3/(6 + 3) = 18/9 = 2 Ωです。逆数の和 1/6 + 1/3 = 1/2 の逆数としても求まります。並列の合成抵抗は、最も小さい抵抗(3 Ω)より小さくなります。並列では両方に同じ電圧がかかり、電流は抵抗に反比例して分かれるため、3 Ωには6 Ωの2倍の電流が流れます。

平行平板コンデンサで、極板の面積を2倍にし、極板の間隔を半分にすると、静電容量は何倍になるか。(極板の間の誘電体は変えない)

  1. A1倍(変わらない)
  2. B4倍
  3. C2倍
答えと解説を見る

正解：B. 4倍

平行平板コンデンサの容量は C = εS/d(ε:誘電率、S:極板の面積、d:間隔)で、面積に比例し間隔に反比例します。面積を2倍にすると2倍、間隔を半分にするとさらに2倍で、合わせて 2 × 2 = 4倍です。極板の間を比誘電率εrの誘電体で満たすと、容量はεr倍になります。積層セラミックコンデンサは、薄い誘電体を何層も重ねて大きな容量を得ています。

よくある質問

並列の合成抵抗はどう計算しますか?

各抵抗の逆数を足し、その合計の逆数をとります(1/R = 1/R1 + 1/R2 + …)。2本なら積÷和のR1R2/(R1 + R2)で、6 Ωと3 Ωの並列は2 Ωです。同じ値の抵抗n本ならR/nで、10 kΩ 2本の並列は5 kΩになります。

並列にすると合成抵抗が小さくなるのはなぜですか?

並列につなぐと、同じ電圧に対して電流の通り道が増え、全体に流れる電流が増えるためです。オームの法則R = V/Iから、電流が増えれば合成抵抗は小さくなります。どんな値の抵抗を並列に足しても、合成抵抗はいちばん小さい抵抗より小さくなります。

コンデンサを直列にすると容量が小さくなるのはなぜですか?

直列にすると、各コンデンサに同じ電荷Qがたまり、それぞれの電圧が足し合わされるため、同じ電圧でためられる電荷が少なくなるからです。極板の間隔を広げたのと同じ効果で、1/C = 1/C1 + 1/C2 + …になります。100 nFを2個直列にすると50 nFです。反対に並列にすると極板の面積を広げたのと同じで、容量は足し算になります。

手持ちにない抵抗値を作るにはどうすればよいですか?

E24系列などの2本を直列か並列にして、近い値を作ります。たとえば7.07 kΩはE24にはなく、最も近い6.8 kΩでは約3.8%低くなりますが、6.8 kΩ + 270 Ωの直列ならちょうど7.07 kΩになります。このツールの後半に目標値を入れると、誤差の小さい組み合わせを5つ示します。部品の許容差は残るので、精度が必要なら許容差の小さい抵抗を選びます。

コイルを直列・並列にするときの注意点は何ですか?

抵抗と同じ式で計算できるのは、コイルどうしが磁気的に結合していない場合です。近くに置いたコイルは互いの磁束を受けて相互インダクタンスMが生じ、直列の合成値はL1 + L2 ± 2M(磁束が強め合うか弱め合うかで符号が変わる)になります。結合を避けるには、離して置く、軸の向きを直交させる、シールド付きのコイルを使う、といった方法をとります。巻線の抵抗や定格電流も確かめます。
