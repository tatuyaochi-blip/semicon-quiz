投資評価(NPV・IRR・回収期間)の計算ツール

システムの導入や設備投資が、かけた費用に見合うかどうかを評価する指標を計算します。将来のお金は、今のお金より価値が低いと考えて割り引き(現在価値)、投資額と比べます。正味現在価値(NPV)、内部収益率(IRR)、何年で元が取れるか(回収期間)を同時に確かめられます。

お気に入りと最近使ったツールは、このブラウザ内（localStorage）にのみ保存されます。

投資とキャッシュフロー

初期投資は0より大きく、割引率は −100% より大きく、キャッシュフローは数を1〜30個入れてください。

キャッシュフローは各年の終わりに得られるものとして割り引きます。回収期間の年の途中は、その年のキャッシュフローが一様に得られるとして直線で補っています。IRR は、キャッシュフローがすべて0以上のときに求めます。

グラフで見る

ほかの入力は今の値のまま、選んだ入力だけを今の値の1/4〜4倍の範囲で変えたときの結果です。赤い点が今の値です。

お金の時間価値と現在価値

今の100万円と1年後の100万円では、今の100万円のほうが価値があります。今すぐ受け取れば、運用して利息を得たり、ほかの投資に回したりできるからです。そこで、将来のキャッシュフローを「割引率」で割り引いて、今の価値(現在価値)に直して比べます。割引率 r のとき、t 年後の C 円の現在価値は C ÷ (1 + r)ᵗ です。割引率5%なら、1年後の105円は今の100円と同じ価値です。

正味現在価値(NPV)

正味現在価値(NPV)は、将来のキャッシュフローの現在価値の合計から初期投資を引いたものです。NPV がプラスなら、その投資は割引率で求められる収益を上回るので実行する価値があり、マイナスなら見合いません。例「初期投資1,000、3年間 300・400・500、割引率5%」では、現在価値の合計は約1,080.4で、NPV は約80.4のプラスです。単純に足すと1,200になりますが、割り引くと価値が小さくなることが分かります。

内部収益率(IRR)と回収期間

内部収益率(IRR)は、NPV がちょうど0になる割引率で、その投資が年あたり何%の収益を生むかを表します。IRR が、資金を調達するときの費用(資本コスト)や会社が求める収益率を上回れば、投資する価値があると判断します。回収期間は、キャッシュフローの累計が初期投資に達するまでの年数で、計算が簡単で分かりやすい一方、回収した後のキャッシュフローや時間価値を考えないという欠点があります。割引回収期間は、現在価値で累計した回収期間です。

IT投資の評価

情報システムの導入では、人手の削減や売上の増加などの効果をキャッシュフローとして見積もり、導入費用や運用費用と比べて評価します。効果には、作業時間の短縮のように金額に直しやすいものと、顧客満足度の向上のように直しにくいものがあるので、金額の指標に加えて、定性的な効果も合わせて判断します。複数の案を比べるときは、規模が違っても比べやすい IRR や収益性指数も使います。

関連する問題を解く

1,000万円を投資して業務システムを導入すると、今後3年間、毎年末に400万円の費用の削減効果が見込まれる。割引率を年5%とし、1年後・2年後・3年後の現価係数(1 ÷ 1.05ⁿ)をそれぞれ0.952、0.907、0.864とするとき、この投資の正味現在価値(NPV)に最も近いものはどれか。

  1. A約89万円
  2. B約143万円
  3. C200万円
答えと解説を見る

正解：A. 約89万円

将来の効果を現在の価値に直すと、400 × (0.952 + 0.907 + 0.864) = 400 × 2.723 = 1,089.2万円です。ここから投資額1,000万円を引いた正味現在価値は約89万円で、0より大きいので、割引率5%のもとでは投資する価値があると判断できます。割り引かずに効果の合計1,200万円から投資額を引くと200万円(投資額に対する割合で20%)になりますが、お金の時間的な価値を考えると、将来の400万円は今の400万円より価値が小さくなります。

よくある質問

割引率はどう決めますか?

資金を借りたり出資を受けたりするときの費用(資本コスト)や、会社がその投資に求める最低限の収益率(ハードルレート)を使うのが一般的です。リスクの大きい投資ほど、高い割引率を使います。

NPV と IRR で判断が分かれることはありますか?

規模やキャッシュフローの時期が違う案を比べるとき、NPV が大きい案と IRR が高い案が異なることがあります。会社の価値をどれだけ増やすかを重視するなら、NPV で判断するのが基本です。

回収期間だけで判断してもよいですか?

回収期間は分かりやすく、早く資金を回収したいときの目安になりますが、回収した後に得られるキャッシュフローやお金の時間価値を考えません。NPV や IRR と合わせて使うのがよいとされています。

試験ではどのように問われますか?

基本情報技術者試験や応用情報技術者試験のストラテジ系では、割引率と年ごとのキャッシュフローから正味現在価値を求めて投資案を比べる問題や、回収期間を求める問題が出ます。
