EVM(アーンドバリュー)の計算ツール

プロジェクトの進み具合とコストを、金額という同じ物差しで管理するアーンドバリューマネジメント(EVM)の指標を計算します。計画した作業の価値、実際に終わった作業の価値、実際にかかったコストを入れると、予定より遅れているか、予算を超えているか、最終的にいくらかかりそうかが分かります。

お気に入りと最近使ったツールは、このブラウザ内（localStorage）にのみ保存されます。

現時点の値

BAC は0より大きく、PV・EV・AC は0以上、経過した期間は0〜100%にしてください。

現時点の状況

スケジュール差異 SV = EV − PV
–
コスト差異 CV = EV − AC
–
スケジュール効率指数 SPI = EV ÷ PV
–
コスト効率指数 CPI = EV ÷ AC
–
完了した割合 EV ÷ BAC
–

完成時の見積もり

EAC(今のコスト効率が続く: BAC ÷ CPI)
–
EAC(残りは予算どおり: AC + (BAC − EV))
–
EAC(CPI と SPI の両方が影響: AC + (BAC − EV) ÷ (CPI × SPI))
–
残作業の見積もり ETC = EAC − AC
–
完成時差異 VAC = BAC − EAC
–
予算内で終えるのに必要な効率 TCPI
–

ETC と VAC は、今のコスト効率が続く場合の EAC(BAC ÷ CPI)をもとに計算しています。TCPI = (BAC − EV) ÷ (BAC − AC) は、残りの作業をこの効率でこなせば予算内で終わる、という値です。グラフは、計画を「今」の PV を通る折れ線で、見積もりを直線で簡単に描いたものです。

グラフで見る

ほかの入力は今の値のまま、選んだ入力だけを今の値の1/4〜4倍の範囲で変えたときの結果です。赤い点が今の値です。

アーンドバリューマネジメントとは

アーンドバリューマネジメント(EVM)は、プロジェクトの作業の進み具合を金額に換算して、スケジュールとコストを同じ物差しで管理する手法です。今の時点で終えている予定だった作業の予算を計画価値(PV)、実際に終えた作業の予算を出来高(EV、アーンドバリュー)、実際にかかったコストを実コスト(AC)と呼びます。進捗率だけ、支出額だけを見ても、遅れているのか効率が悪いのかは分かりませんが、この3つを比べるとどちらも分かります。

差異と効率指数

スケジュール差異 SV = EV − PV が負なら、予定より作業が遅れています。コスト差異 CV = EV − AC が負なら、終えた作業に対して予算以上のコストがかかっています。比で表したのがスケジュール効率指数 SPI = EV ÷ PV とコスト効率指数 CPI = EV ÷ AC で、1より小さいと遅れ・超過です。例「遅れていて、予算も超過」では、PV 500、EV 400、AC 450 なので、SV = −100、CV = −50、SPI = 0.8、CPI ≒ 0.89 になります。

完成時総コストの見積もり

完成時総コストの見積もり(EAC)は、これからの作業がどんな効率で進むと考えるかで式が変わります。今のコスト効率が続くと考えるなら EAC = BAC ÷ CPI、これまでの超過は一時的で残りは予算どおりと考えるなら EAC = AC + (BAC − EV) です。スケジュールの遅れを取り戻すためにコストもかかると考えるなら、CPI と SPI の両方を使います。例では BAC 1000 に対して、EAC は1125(今の効率が続く場合)となり、125の超過が見込まれます。

使うときの注意

EVM の値の確かさは、作業の分け方(WBS)と出来高の測り方に左右されます。作業の途中で「半分終わった」と判断するのは難しいので、着手したら50%、完了したら100%とみなす(50/50ルール)などの決まりを使います。また、SPI はプロジェクトの終わりには必ず1に近づくので、終盤のスケジュールの判断にはクリティカルパスとあわせて使います。

関連する問題を解く

完成時総予算(BAC)が2,000万円のプロジェクトで、ある時点の計画価値(PV)が800万円、出来高(EV)が600万円、実コスト(AC)が750万円だった。この時点のプロジェクトの状況として、正しいものはどれか。

  1. Aスケジュールは遅れていて(SPI = 0.75)、コストも予算を超過している(CPI = 0.8)
  2. Bスケジュールは遅れているが(SPI = 0.75)、コストは予算内に収まっている(CPI = 1.25)
  3. Cスケジュールは進んでいるが(SPI = 1.33)、コストは予算を超過している(CPI = 0.8)
答えと解説を見る

正解：A. スケジュールは遅れていて(SPI = 0.75)、コストも予算を超過している(CPI = 0.8)

スケジュール効率指数は SPI = EV ÷ PV = 600 ÷ 800 = 0.75で、1より小さいので予定より遅れています(スケジュール差異 SV = EV − PV = −200万円)。コスト効率指数は CPI = EV ÷ AC = 600 ÷ 750 = 0.8で、1より小さいので、終わった作業の予算より多くのコストがかかっています(コスト差異 CV = EV − AC = −150万円)。EVMでは、出来高(EV)を計画価値(PV)と実コスト(AC)の両方と比べることで、進み具合とコストを同じ金額の物差しで評価します。

完成時総予算(BAC)が1,200万円のプロジェクトで、現時点の計画価値(PV)が600万円、出来高(EV)が480万円、実コスト(AC)が600万円である。今後も現在のコスト効率が続くとしたとき、完成時総コストの見積もり(EAC)はどれか。

  1. A1,320万円
  2. B1,500万円
  3. C1,725万円
答えと解説を見る

正解：B. 1,500万円

コスト効率指数は CPI = EV ÷ AC = 480 ÷ 600 = 0.8で、予算1円分の作業に1.25円かかっています。この効率が続くとすると、EAC = BAC ÷ CPI = 1,200 ÷ 0.8 = 1,500万円で、予算を300万円超える見込みです。1,320万円は、残りの作業(BAC − EV = 720万円)が予算どおりに進むとした AC + (BAC − EV) の値です。1,725万円は、コストとスケジュールの両方の効率が残りの作業に影響するとした AC + (BAC − EV) ÷ (CPI × SPI) = 600 + 720 ÷ 0.64 の値です。

よくある質問

SPI と CPI はどちらを重視すればよいですか?

どちらも重要ですが、CPI は一度悪くなると回復しにくいことが知られていて、完成時の予算超過を早めに見積もるのに役立ちます。SPI は期間全体の遅れを示しますが、遅れている作業がクリティカルパス上にあるかどうかは、日程の計画と合わせて確かめる必要があります。

PV・EV・AC の単位は何ですか?

通常は金額ですが、工数(人日など)で管理することもあります。3つと BAC の単位がそろっていれば、計算の仕方は同じです。

EV が PV より大きいのに、予算を超えることはありますか?

あります。予定より多くの作業を終えていても(SPI > 1)、それ以上にコストを使っていれば(AC > EV、CPI < 1)予算は超過しています。スケジュールとコストは別々に判断します。

試験ではどのように問われますか?

応用情報技術者試験やプロジェクトマネージャ試験では、PV・EV・AC の値やグラフから、スケジュールの遅れやコストの超過を判断する問題、完成時総コストの見積もりを計算する問題がよく出ます。
