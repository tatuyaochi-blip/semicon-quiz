セットアップの条件

送信側のフリップフロップがクロックのエッジでデータを出してから、組み合わせ回路を通って受信側に届くまでの最も遅い時間は、クロック→出力遅延の最大値と組み合わせ回路の遅延の最大値の和です。これが、次のクロックのエッジ(周期+スキュー)からセットアップ時間とクロックの不確かさを引いた時刻より前でなければなりません。セットアップのスラックは「期限 − 到着時刻」で、負になると周期が足りず、周波数を下げるか遅延を減らす必要があります。

ホールドの条件

ホールドは、同じクロックのエッジで送信側が次のデータを出したとき、それが速く届きすぎて受信側がまだ取り込んでいる前のデータを壊さないかという条件です。最も早いデータの到着(クロック→出力遅延の最小値と組み合わせ回路の遅延の最小値の和)が、スキューとホールド時間の和より後でなければなりません。ホールドの条件にはクロック周期が入らないため、周波数を下げても直りません。違反はバッファを挿入して経路の遅延を増やして直します。

スキューの影響

受信側のクロックが送信側より遅れて届く(スキューが正の)場合、セットアップには期限が延びて有利になる一方、ホールドには不利になります。スキューが負なら逆です。そのため、スキューをわざと付けてセットアップの厳しい経路を救う手法(有用スキュー)もありますが、ホールドの余裕を同時に確認する必要があります。実際のSTAでは、最悪の条件(遅いコーナーでのセットアップ、速いコーナーでのホールド)で全経路を調べます。

最大動作周波数の考え方

セットアップのスラックがちょうど0になる周期が、この経路での最小周期で、その逆数が最大動作周波数です。式では fmax = 1 / (クロック→出力遅延 + 組み合わせ回路の遅延 + セットアップ時間 + 不確かさ − スキュー) です。チップ全体の最大周波数は、最も遅い経路(クリティカルパス)で決まります。パイプラインの段数を増やして1段あたりの組み合わせ回路を短くすると、周波数を上げられます。

論理回路の問題を解く

フリップフロップのセットアップ時間の説明として正しいものはどれか。

  1. Aクロックのエッジのあとに、データを保持し続けなければならない最小時間
  2. Bクロックのエッジより前に、データ入力が安定していなければならない最小時間
  3. C電源を入れてから動作するまでの時間
答えと解説を見る

正解：B. クロックのエッジより前に、データ入力が安定していなければならない最小時間

フリップフロップが正しく取り込むには、クロックのエッジより一定時間前からデータが安定している必要があり、これがセットアップ時間です。データ経路の遅延がクロック周期からセットアップ時間を引いた値を超えると違反になり、クロックを遅くすれば解消できます。エッジ後にデータを保持する必要がある時間はホールド時間で、どちらかを満たさないと誤った値の取り込みやメタステーブルの原因になります。

フリップフロップのホールド時間の説明として正しいものはどれか。

  1. Aクロックの有効なエッジの前に、データ入力を確定させておかなければならない時間
  2. Bクロックが入ってから出力が変わるまでの時間
  3. Cクロックの有効なエッジの後も、データ入力を変えずに保たなければならない時間
答えと解説を見る

正解：C. クロックの有効なエッジの後も、データ入力を変えずに保たなければならない時間

ホールド時間は、クロックのエッジ後もデータを安定させておく必要がある最小時間です。前段のフリップフロップから次段までの経路が短すぎると、同じエッジで更新された新しいデータが次段に早く届きすぎて違反します。周期と無関係なのでクロックを遅くしても直らず、データ経路にバッファを挿入して遅延を加えるのが対策です。製造後に見つかるとチップが使えなくなるため、設計時の検証が重要です。

よくある質問

セットアップ違反とホールド違反の直し方の違いは?

セットアップ違反は、クロック周波数を下げる、組み合わせ回路の遅延を減らす、パイプラインを分けるなどで直します。ホールド違反は周波数に依存しないので、バッファを挿入して最短経路の遅延を増やして直します。

クロックスキューはセットアップとホールドのどちらに効きますか?

両方に効き、向きが逆です。受信側のクロックが遅れる正のスキューはセットアップに有利でホールドに不利、負のスキューはその逆になります。

スラックとは何ですか?

タイミングの期限に対する余裕の時間です。期限から実際の到着時刻を引いた値で、正なら条件を満たし、負なら違反です。
