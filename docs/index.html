学習コース

何から学べばいいか迷ったら、目的に合ったコースを選んで順に進めましょう。

はじめての半導体 半導体のしくみから、トランジスタ、チップのつくり方、業界の全体像までを一通り見ます。最初の一歩におすすめです。 9分野 デバイスを深く知る 物性の基礎からトランジスタ、先端トランジスタ、パワーや化合物、センサーまで、デバイスの原理を順に学びます。 9分野 製造プロセスを一通り ウエハからクリーンルーム、酸化、リソグラフィ、エッチング、成膜、配線、計測、歩留まりまで、前工程を流れの順に学びます。 13分野 回路・設計とメモリ 論理回路とアナログ回路から、AD/DA変換、CPU、各種メモリ、設計フローまで、チップの中身と設計を学びます。 8分野 後工程・品質・安全 パッケージと先端実装、テスト、信頼性、環境安全、産業の動きまで、チップを製品として届けるための知識を学びます。 6分野 トランジスタからソフトまで トランジスタと論理回路から、計算機の数の表し方、コンパイラ、OS、メモリ階層まで、ハードウェアの上でソフトウェアが動くしくみを下から順にたどります。 8分野 ハードウェア技術面接対策 半導体・ハードウェア企業の技術面接でよく問われる、論理回路、タイミング解析とCDC、HDL、数値表現、CPU、キャッシュ、並行処理、性能、高速インタフェースを順に練習します。 10分野

ほかの練習方法

今日の1問毎日1問、その日の問題を出します。続けて解くと連続学習日数が伸びます 苦手問題直近で間違えた問題だけを解き直します 模擬試験（30問）全分野から30問。解説は最後にまとめて表示します 今日の復習解いた問題を、忘れかけたころにもう一度出題します 弱点診断全分野から1問ずつ出題し、苦手な分野と次に学ぶ分野を案内します
