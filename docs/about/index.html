サイトについて

「半導体教室」は、半導体技術者検定の学習を3択問題で手軽に進めるための非公式の学習サイトです。

非公式サイトであることについて

当サイトは個人が運営しており、半導体技術者検定の主催団体・関係団体とは一切関係ありません。試験の申し込みや出題範囲などの公式情報は、主催団体の案内をご確認ください。

問題について

掲載している問題と解説はすべて当サイトのオリジナルです。公式の過去問題は使用していません。問題は半導体の基礎からデバイス、製造プロセス、実装・評価、設計・産業まで36分野に分けています。

内容には十分注意していますが、誤りが含まれる可能性があります。お気づきの点があればお問い合わせからお知らせください。

使い方

  • 分野別：トップページから分野を選び、その分野の問題を解きます。
  • ランダム出題：全分野から10問をランダムに出題します。
  • 苦手問題：直近で間違えた問題だけを解き直します。
  • 模擬試験：全分野から30問。解説は最後にまとめて表示します。

解答の記録はお使いのブラウザ内にのみ保存され、成績ページで確認できます。会員登録は不要です。
