Was ist Multiplexer?

Schaltung, die abhängig von einem Auswahlsignal einen von mehreren Eingängen auf den Ausgang schaltet. Auch Selektor genannt. Das Gegenstück, das einen Eingang auf einen von mehreren Ausgängen verteilt, heißt Demultiplexer.

Japanische Bezeichnung: マルチプレクサ

„Multiplexer“ kommt in 3 Übungsfragen aus 3 Themen vor, z. B. Logikschaltungen, Embedded Systems und Firmware, Hardwarebeschreibungssprachen und Verifikation.

Fachgebiet: Logikschaltungen

Wie ein Multiplexer auswählt

Ein 2:1-Multiplexer (Mux) gibt Y = S'·A + S·B aus: Eingang A, wenn das Auswahlsignal S 0 ist, und Eingang B, wenn S 1 ist. Mit n Auswahlbits wählt ein Mux unter 2ⁿ Eingängen, ein 8:1-Mux braucht also drei Auswahlleitungen. In CMOS werden Muxe aus AND-OR- oder NAND-NAND-Logik, aus Transmission-Gates oder bei breiten Eingängen als Bäume von 2:1-Muxen aufgebaut. Ein Mux ist zudem ein universelles Logikelement: Legt man seine Dateneingänge auf die Konstanten einer Wahrheitstabelle, realisiert ein 2ⁿ:1-Mux jede beliebige boolesche Funktion mit n Eingängen.

Wo Multiplexer vorkommen

Datenpfade von Prozessoren sind voller Muxe: Sie wählen ALU-Operanden aus Registern oder Direktwerten, leiten Ergebnisse über Bypass-Pfade weiter, um Pipeline-Stalls zu vermeiden, wählen den nächsten Programmzähler und schalten gemeinsam genutzte Busse um. FPGA-Logikblöcke realisieren beliebige Funktionen mit Lookup-Tabellen (LUTs), kleinen Speichern, die über einen Mux-Baum ausgelesen werden. Beim testgerechten Entwurf (Design for Testability) erhalten Scan-Flipflops einen Mux am Dateneingang, damit die Flipflops im Testmodus zu Schieberegistern verkettet werden können. Auf Platinen teilen sich über analoge Multiplexer mehrere Sensoren einen ADC, und I2C-Multiplexer trennen Bausteine mit identischen Adressen.

Multiplexer in HDL und Synthese

In Verilog oder VHDL wird eine bedingte Zuweisung, eine if-Anweisung oder eine case-Anweisung meist zu einem Multiplexer synthetisiert. Eine lange if/else-if-Kette impliziert eine Priorität und ergibt eine Reihe von 2:1-Muxen mit langer Verzögerung, während eine case-Anweisung über sich gegenseitig ausschließende Werte eher zu einem einzigen breiten parallelen Mux wird; moderne Synthesewerkzeuge optimieren allerdings oft beide Formen. Ein häufiger Fehler ist, in kombinatorischer Logik einen Zweig ohne Zuweisung zu lassen; dann wird statt eines reinen Mux ein Latch inferiert, das den alten Wert hält.

Multiplexer vs. Demultiplexer und Decoder

Ein Demultiplexer macht das Umgekehrte eines Multiplexers: Er leitet einen Eingang auf einen von 2ⁿ Ausgängen, der durch die Auswahlbits bestimmt wird. Ein Decoder wandelt einen n-Bit-Code in 2ⁿ One-hot-Leitungen um und ist im Grunde ein Demultiplexer, dessen Dateneingang fest auf 1 liegt; Decoder steuern die Auswahllogik großer Muxe und die Wortleitungen von Speichern. In der Nachrichtentechnik bedeutet Multiplexen allgemeiner, einen Kanal über Zeit, Frequenz oder Code auf mehrere Signale aufzuteilen.

Ein Multiplexer (Selektor) ist eine Schaltung, die abhängig vom Wert des Auswahlsignals einen von mehreren Eingängen an den Ausgang weitergibt; bei einem n-Bit-Auswahlsignal kann aus 2ⁿ Eingängen gewählt werden. In der CPU dient er zur Auswahl von Registerwerten und zum Umschalten von Bussen, und auch der Logikblock (LUT) eines FPGA realisiert beliebige Logik mit Speicher und Multiplexern. Eine Schaltung, die einen Eingang auf einen von mehreren Ausgängen verteilt, ist ein Demultiplexer.

Antwort: C. Über den Adress-Einstellpin die Adresse eines der Sensoren ändern oder sie auf getrennte I2C-Leitungen legen

Bei I2C wird das Gegenüber per Adresse gewählt; bei zwei Geräten mit derselben Adresse antworten beide gleichzeitig, und die Kommunikation wird gestört. Bei vielen Bauteilen lässt sich ein Teil der Adresse ändern, indem ein Pin mit Versorgung oder Masse verbunden wird. Ist das nicht möglich, wird eine weitere I2C-Peripherie des Mikrocontrollers verwendet oder die Leitungen werden mit einem Baustein zum Umschalten der I2C-Leitung (Multiplexer) getrennt.

Häufige Fragen

Wie viele Auswahlleitungen braucht ein 8:1-Multiplexer?

Drei, denn 2³ = 8. Allgemein braucht ein Mux mit 2ⁿ Dateneingängen n Auswahlleitungen.

Was ist der Unterschied zwischen Multiplexer und Demultiplexer?

Ein Multiplexer wählt einen von mehreren Eingängen aus und gibt ihn an einen einzigen Ausgang weiter. Ein Demultiplexer nimmt einen einzigen Eingang und leitet ihn auf einen von mehreren Ausgängen.

Wie kann ein Multiplexer jede beliebige Logikfunktion realisieren?

Man verbindet die Auswahlleitungen mit den Eingangsvariablen der Funktion und legt jeden Dateneingang gemäß der Wahrheitstabelle auf 0 oder 1. Der Mux gibt dann für jede Eingangskombination den richtigen Tabelleneintrag aus; genau so funktionieren FPGA-Lookup-Tabellen.
