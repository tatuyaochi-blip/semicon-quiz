Was ist Multiplexer?

Schaltung, die abhängig von einem Auswahlsignal einen von mehreren Eingängen auf den Ausgang schaltet. Auch Selektor genannt. Das Gegenstück, das einen Eingang auf einen von mehreren Ausgängen verteilt, heißt Demultiplexer.

Japanische Bezeichnung: マルチプレクサ

Antwort: C. Er wählt abhängig vom Auswahlsignal einen von mehreren Eingängen aus und gibt ihn aus

Ein Multiplexer (Selektor) ist eine Schaltung, die abhängig vom Wert des Auswahlsignals einen von mehreren Eingängen an den Ausgang weitergibt; bei einem n-Bit-Auswahlsignal kann aus 2ⁿ Eingängen gewählt werden. In der CPU dient er zur Auswahl von Registerwerten und zum Umschalten von Bussen, und auch der Logikblock (LUT) eines FPGA realisiert beliebige Logik mit Speicher und Multiplexern. Eine Schaltung, die einen Eingang auf einen von mehreren Ausgängen verteilt, ist ein Demultiplexer.

Antwort: C. Über den Adress-Einstellpin die Adresse eines der Sensoren ändern oder sie auf getrennte I2C-Leitungen legen

Bei I2C wird das Gegenüber per Adresse gewählt; bei zwei Geräten mit derselben Adresse antworten beide gleichzeitig, und die Kommunikation wird gestört. Bei vielen Bauteilen lässt sich ein Teil der Adresse ändern, indem ein Pin mit Versorgung oder Masse verbunden wird. Ist das nicht möglich, wird eine weitere I2C-Peripherie des Mikrocontrollers verwendet oder die Leitungen werden mit einem Baustein zum Umschalten der I2C-Leitung (Multiplexer) getrennt.
