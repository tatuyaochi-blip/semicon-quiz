Was ist DOM (Document Object Model)?

Schnittstelle, die ein HTML- oder XML-Dokument als Baum darstellt, dessen Knoten Elemente, Text und Ähnliches sind, sodass Programme es lesen und schreiben können. Der Browser parst das HTML und baut daraus das DOM auf; JavaScript sucht Elemente etwa mit document.querySelector und ändert deren Text, Attribute und Stile oder fügt Elemente hinzu. Ändert sich das DOM, berechnet der Browser bei Bedarf das Layout neu und zeichnet erneut; zu viele Änderungen verlangsamen daher die Anzeige.

Antwort: B. Eine Darstellung eines HTML-Dokuments als Baum, dessen Knoten Elemente und Ähnliches sind; JavaScript kann sie lesen und schreiben

Der Browser parst das HTML und baut eine Baumstruktur (den DOM-Baum) auf, deren Wurzel das html-Element ist und deren Knoten unter anderem head, body und die darin enthaltenen Absätze sind. JavaScript verändert die Seite über das DOM, indem es Elemente mit document.querySelector sucht, Texte und Attribute ändert oder Elemente hinzufügt. Ändert sich das DOM, berechnet der Browser bei Bedarf das Layout neu und zeichnet erneut. Das DOM ist als Schnittstelle zum Bearbeiten von Dokumenten standardisiert, die von keiner bestimmten Programmiersprache abhängt.
