Was ist Bank?

Unterteilung des DRAM in mehrere Bereiche, die unabhängig arbeiten können. Durch überlappende Aktivierung und Lese-/Schreibzugriffe auf verschiedene Banks steigt die effektive Zugriffsleistung.

Japanische Bezeichnung: バンク

„Bank“ kommt in 7 Übungsfragen aus 3 Themen vor, z. B. GPU-Programmierung, DRAM, Embedded Systems und Firmware.

Fachgebiet: DRAM

Warum DRAM in Bänke aufgeteilt ist

Ein DRAM-Zugriff umfasst mehrere langsame Schritte. Ein Activate-Befehl öffnet eine Zeile und kopiert sie in die Leseverstärker der Bank, oft Row Buffer genannt; Lese- und Schreibzugriffe wählen dann Spalten aus dieser Zeile; schließlich schließt ein Precharge die Zeile und bereitet die Bitleitungen vor. Activate und Precharge dauern jeweils über zehn Nanosekunden. Eine Bank ist ein unabhängiges Array mit eigenem Row Buffer, sodass eine Bank Daten übertragen kann, während eine andere gerade aktiviert oder vorgeladen wird. Das Verschränken (Interleaving) von Zugriffen über Bänke verbirgt diese Latenzen und hält den Datenbus ausgelastet.

Bankanzahl und Bankgruppen

DDR4-Bausteine in x4- und x8-Organisation haben 16 Bänke in vier Bankgruppen, DDR5-Bausteine in x4- und x8-Organisation ab 16 Gbit verdoppeln dies auf 32; x16-Bausteine haben jeweils halb so viele Bänke. Bankgruppen bringen eine zusätzliche Timingregel: Aufeinanderfolgende Spaltenzugriffe auf verschiedene Gruppen können in kürzerem Abstand ausgegeben werden als Zugriffe innerhalb derselben Gruppe, daher verteilen Controller den Verkehr über die Gruppen. Jede Bank kann eine andere offene Zeile halten, was auch die Chance erhöht, dass eine Anfrage eine bereits offene Zeile trifft (Page Hit), statt die Kosten eines weiteren Activate zu tragen. Eine Bank ist von einem Rank zu unterscheiden, einer Gruppe von Chips auf einem Modul, die sich ein Chip-Select teilen.

Refresh und Bankverfügbarkeit

DRAM-Zellen verlieren Ladung, daher muss jede Zeile typischerweise innerhalb von 64 ms aufgefrischt werden. Eine Bank im Refresh kann keine Zugriffe bedienen, und mit wachsender Kapazität deckt jeder Refresh-Befehl mehr Zeilen ab und dauert länger; diese Zeit heißt tRFC. Bei Bausteinen der 16-Gbit-Klasse kann der Refresh mehrere Prozent bis etwa 10 % der Leistung kosten, dazu zusätzliche Energie. Per-Bank-Refresh verringert die Auswirkung, indem jeweils eine Bank aufgefrischt wird, während die anderen verfügbar bleiben, und die Forschung hat untersucht, Zeilen mit langer Retentionszeit seltener aufzufrischen.

Bänke im Shared Memory von GPUs

Der Begriff taucht auch in der GPU-Programmierung mit einer verwandten Idee auf. CUDA-Shared-Memory ist in 32 Bänke aufgeteilt, die reihum alle 4 Byte zugewiesen werden, und jede Bank bedient eine Adresse pro Zugriff. Treffen die 32 Threads eines Warps verschiedene Bänke, ist der Zugriff sofort abgeschlossen; greifen mehrere Threads auf verschiedene Adressen in derselben Bank zu, werden die Zugriffe serialisiert, ein Bankkonflikt. Das Lesen einer Spalte einer 32 × 32-Float-Kachel legt jedes Element in dieselbe Bank; ein Auffüllen (Padding) der Kachel auf 32 × 33 verschiebt jede Zeile um eine Bank und beseitigt den Konflikt.

Eine 32×32-float-Tabelle liegt im Shared Memory, und die 32 Threads eines Warps lesen in Spaltenrichtung (vertikal), wodurch Bank Conflicts entstehen. Welche Gegenmaßnahme ist üblich?

  1. ADie Tabelle bleibt 32×32, die Lesereihenfolge wird zufällig gewählt
  2. BAuf den Shared Memory wird verzichtet, und alles wird aus dem Global Memory gelesen
  3. CDie Tabelle wird mit einer zusätzlichen Spalte reserviert, z. B. 32×33, sodass die Bankposition von Zeile zu Zeile verschoben ist

Antwort: C. Die Tabelle wird mit einer zusätzlichen Spalte reserviert, z. B. 32×33, sodass die Bankposition von Zeile zu Zeile verschoben ist

Hat eine Zeile 32 float-Werte (128 Byte), beginnt jede Zeile in derselben Bank, sodass alle Elemente derselben Spalte in derselben Bank liegen und beim vertikalen Lesen alle 32 Threads auf eine Bank treffen. Bei 33 Werten pro Zeile verschiebt sich die Bank mit jeder Zeile um eins, sodass sich die 32 Werte derselben Spalte auf alle Bänke verteilen und in einem Zugriff gelesen werden. Es ist ein einfacher Kniff, der nur eine ungenutzte Spalte zusätzlichen Speicher kostet.

Häufige Fragen

Wie viele Bänke hat DDR5?

DDR5-Bausteine in x4- und x8-Organisation ab 16 Gbit haben 32 Bänke, organisiert in acht Bankgruppen, gegenüber 16 Bänken in vier Bankgruppen bei DDR4 (x4/x8); x16-Bausteine haben jeweils halb so viele.

Unterschied zwischen DRAM-Bank und Rank?

Eine Bank ist ein unabhängig arbeitendes Array innerhalb eines einzelnen DRAM-Chips. Ein Rank ist eine Gruppe von Chips auf einem Modul, die sich ein Chip-Select teilen und zusammen die volle Datenbreite liefern, und jeder Chip darin enthält seine eigenen Bänke.

Was ist ein Shared-Memory-Bankkonflikt?

Er tritt auf, wenn Threads eines GPU-Warps auf verschiedene Adressen zugreifen, die auf dieselbe Shared-Memory-Bank abgebildet werden, sodass die Hardware die Zugriffe serialisieren muss. Padding von Arrays oder ein geändertes Zugriffsmuster vermeidet ihn meist; lesen alle Threads dieselbe Adresse, ist das ein Broadcast und kein Konflikt.
