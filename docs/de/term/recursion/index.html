Was ist Rekursion?

Aufruf einer Funktion durch sich selbst als Teil ihrer eigenen Verarbeitung. Das Problem wird in kleinere Probleme derselben Form zerlegt, und die Aufrufe enden bei einem Fall, der nicht weiter zerlegt wird (dem Basisfall). Jeder Aufruf belegt Stack-Speicher, daher läuft der Stack bei zu tiefer Rekursion über. Endrekursion, bei der der rekursive Aufruf das Letzte ist, was die Funktion tut, lässt sich in eine Schleife umwandeln.

Japanische Bezeichnung: 再帰

Antwort und Erläuterung anzeigen

Antwort: A. Das Programm berührt die hinter dem Stack liegende, für Zugriffe gesperrte Guard Page und wird abnormal beendet

Der Stack hat eine Obergrenze, hinter der eine für Zugriffe gesperrte Guard Page liegt. Erreicht der Stack bei zu tiefer Rekursion diese, tritt ein Seitenfehler auf, und das Betriebssystem beendet das Programm (Segmentation Fault). Der Vorteil der Guard Page ist, dass das Programm gestoppt werden kann, bevor andere Daten zerstört werden. Dasselbe passiert bei großen Arrays als lokalen Variablen; große Daten legt man daher sicherer auf dem Heap ab.
