Was ist Immutable Infrastructure (unveränderliche Infrastruktur)?

Betriebsansatz, bei dem einmal erzeugte Server (virtuelle Maschinen oder Container) nie verändert werden; ist ein Update nötig, werden aus einem Image mit der Änderung neue erzeugt und eingewechselt, und die alten werden verworfen. Da jeder Server aus demselben Image entsteht, driften die Konfigurationen nicht durch angehäufte manuelle Unterschiede auseinander, und die Rückkehr zum vorherigen Image stellt den alten Zustand einfach wieder her. Was erhalten bleiben soll, etwa Logs und Daten, wird in Speicher oder Datenbanken außerhalb der Server abgelegt.

Japanische Bezeichnung: イミュータブルインフラストラクチャ

Antwort: B. Aus einem neuen Image, das das Update enthält, neue Server erzeugen, auf diese umschalten und die alten Server unverändert verwerfen

Bei Immutable Infrastructure werden einmal erzeugte Server (virtuelle Maschinen oder Container) nie verändert; ist eine Änderung nötig, werden aus einem Image mit der Änderung neue erzeugt und eingewechselt. Da jeder Server aus demselben Image entsteht, driften die Konfigurationen nicht durch angehäufte manuelle Unterschiede von Server zu Server auseinander. Tritt ein Problem auf, stellt die Neuerzeugung aus dem vorherigen Image den alten Zustand wieder her. Was erhalten bleiben muss, etwa Logs und Daten, wird in Speicher oder Datenbanken außerhalb der Server abgelegt.
