Was ist Flipflop?

Das Grundelement sequenzieller Schaltungen, das ein Bit speichert. Ein D-Flipflop übernimmt seinen Eingang bei einer Taktflanke.

Japanische Bezeichnung: フリップフロップ

Fachgebiet: Logikschaltungen
