Was ist Loop Blocking (Schleifenkachelung)?

Optimierung, die große Arrays in kleinen Blöcken verarbeitet, die in den Cache passen, sodass geladene Daten vor der Verdrängung oft wiederverwendet werden. Sehr wirksam bei der Matrixmultiplikation.

Japanische Bezeichnung: ループブロッキング

Fachgebiet: Speicherhierarchie

Verwandte Begriffe

Cache-Zeile (Cache Line) Direkt abgebildeter Cache (Direct-Mapped) Erstzugriffs-Fehlzugriff (Compulsory Miss) Fehlzugriffsstrafe (Miss Penalty) Kapazitäts-Fehlzugriff (Capacity Miss) Konflikt-Fehlzugriff (Conflict Miss) LRU-Ersetzung (Least Recently Used) Mengenassoziativer Cache (Set-Associative) Mittlere Speicherzugriffszeit (AMAT) Nichtblockierender Cache
