Was ist Bitfeld?

Mechanismus in C, mit dem ein Member einer Struktur als Feld mit einer angegebenen Bitzahl deklariert wird, etwa unsigned int x : 3;. Da sich kleine Werte dicht gepackt halten lassen, fasst man damit Flags und Einstellwerte zusammen. Ein Wert, der nicht in ein vorzeichenloses Feld passt, wird zum Rest der Division durch 2 hoch Bitzahl. Ob die Felder vom oberen oder unteren Ende eines Worts an angeordnet werden und ob ein Feld eine Grenze überschreiten darf, kann je nach Implementierung verschieden sein; für Peripherieregister und Kommunikationsformate schreibt man daher oft Masken und Shifts.

Japanische Bezeichnung: ビットフィールド

Antwort und Erläuterung anzeigen

Antwort: B. Die Bitreihenfolge von Bitfeldern darf je nach Compiler verschieden sein, sodass mit einem anderen Compiler unbeabsichtigt andere Bits bearbeitet werden können

Bitfelder sind gut lesbar, doch im C-Standard bleibt der Implementierung überlassen, ob Bits in einer Struktur von oben oder von unten angeordnet werden, wie Felder über Grenzen hinweg behandelt werden und wie breit der Zugriff ist. Daher kann Code, der mit einem Compiler korrekt läuft, mit einem anderen Compiler oder einer anderen CPU andere Bits lesen oder schreiben. Von Mikrocontroller-Herstellern bereitgestellte Header sind häufig mit Masken und Shifts geschrieben.
