Was ist Standardgateway (Default Gateway)?

Router, dem ein Endgerät Pakete an Ziele in anderen Netzwerken übergibt. Das Endgerät entscheidet anhand seiner Subnetzmaske, ob ein Ziel im selben Netzwerk liegt, und sendet andernfalls an diesen Router.

Japanische Bezeichnung: デフォルトゲートウェイ

Jetzt üben: Fragen zu Standardgateway (Default Gateway)

Ein Endgerät (192.168.1.10/24, Standardgateway 192.168.1.1) sendet ein Paket an den Server 203.0.113.80 in einem anderen Netzwerk. Wessen MAC-Adresse ermittelt das Endgerät per ARP, wenn der ARP-Cache leer ist?

  1. ADie des Standardgateways 192.168.1.1
  2. BDie des Servers 203.0.113.80
  3. CDie aller Router auf dem Weg zum Server
Antwort und Erläuterung anzeigen

Antwort: A. Die des Standardgateways 192.168.1.1

Das Endgerät prüft zunächst anhand seiner eigenen IP-Adresse und Subnetzmaske, ob das Ziel im selben Netzwerk liegt. 203.0.113.80 liegt außerhalb von 192.168.1.0/24, also wird das Paket dem Standardgateway (einem Router) übergeben. Das Ziel im IP-Header bleibt dabei 203.0.113.80, die Adresse des Servers; nur die Ziel-MAC-Adresse des Frames wird auf die des Gateways gesetzt. Per ARP wird daher die MAC-Adresse von 192.168.1.1 ermittelt. ARP-Broadcasts gelangen nicht über Router hinaus, sodass die MAC-Adresse eines Servers in einem anderen Netzwerk weder ermittelt werden kann noch benötigt wird. Jeder Router auf dem Weg ermittelt bei jeder Weiterleitung selbst die MAC-Adresse des nächsten Geräts.

Zwei Router, R1 (192.168.1.2) und R2 (192.168.1.3), sind für VRRP mit der virtuellen IP-Adresse 192.168.1.254 konfiguriert. Im Normalbetrieb leitet R1 als Master weiter. Welche Adresse sollte auf den Endgeräten im LAN als Standardgateway eingetragen werden?

  1. A192.168.1.2 (Adresse von R1)
  2. B192.168.1.3 (Adresse von R2)
  3. C192.168.1.254 (die virtuelle IP-Adresse)
Antwort und Erläuterung anzeigen

Antwort: C. 192.168.1.254 (die virtuelle IP-Adresse)

Mit VRRP bilden mehrere Router einen virtuellen Router, der eine virtuelle IP-Adresse und eine virtuelle MAC-Adresse gemeinsam nutzt. Im Normalbetrieb leitet der Master-Router die an die virtuelle Adresse gerichteten Pakete weiter; fällt der Master aus, wird ein Backup-Router zum Master und übernimmt die Weiterleitung. Verwenden die Endgeräte die virtuelle IP-Adresse als Standardgateway, müssen sie nicht umkonfiguriert werden, gleich welcher Router gerade arbeitet. Mechanismen dieser Art, die das Standardgateway redundant machen, werden unter dem Begriff FHRP zusammengefasst; neben VRRP gehört etwa HSRP dazu.
