Was ist Überwachtes Lernen (Supervised Learning)?

Ein Ansatz des maschinellen Lernens, der anhand von Daten aus Paaren von Eingaben und richtigen Antworten (Labels) ein Modell trainiert, das aus einer Eingabe die richtige Antwort vorhersagt. Ist die vorhergesagte Ausgabe ein kontinuierlicher Zahlenwert, spricht man von Regression, ist sie eine von mehreren festgelegten Klassen, von Klassifikation. Verwendet werden Modelle wie lineare Regression, logistische Regression, Entscheidungsbäume, Support Vector Machines und neuronale Netze. Das Erstellen der Labels ist oft aufwendig.

Antwort: C. Den Preis eines Hauses aus Wohnfläche, Entfernung zum Bahnhof usw. vorhersagen

Überwachtes Lernen trainiert ein Modell, das aus einer Eingabe eine Ausgabe vorhersagt, anhand von Paaren aus Eingaben und richtigen Antworten (Labels). Ist die vorhergesagte Ausgabe ein kontinuierlicher Zahlenwert, spricht man von Regression; ist sie eine von mehreren festgelegten Klassen, von Klassifikation. Ein Hauspreis ist ein kontinuierlicher Zahlenwert, also handelt es sich um eine Regression. Die Spamerkennung ist eine Klassifikation mit 2 Klassen, die Erkennung handgeschriebener Ziffern eine Klassifikation mit 10 Klassen.
