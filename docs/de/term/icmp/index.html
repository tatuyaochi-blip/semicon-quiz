Was ist ICMP (Internet Control Message Protocol)?

Protokoll zum Melden von Fehlern und Zuständen in der IP-Kommunikation. Es teilt dem Absender zum Beispiel mit, dass ein Ziel nicht erreichbar ist (Destination Unreachable) oder dass die TTL eines Pakets 0 erreicht hat (Time Exceeded). ping prüft mit Echo Request und Echo Reply die Erreichbarkeit und misst die RTT, und traceroute verfolgt mit Time-Exceeded-Meldungen einen Pfad. Bei IPv6 übernimmt ICMPv6 auch die Nachbarerkennung und weitere Aufgaben.

Welche Beschreibung der Aufgabe von TTL (Time To Live) im IPv4-Header ist richtig?

  1. ASie hält die Zeit vom Senden eines Pakets bis zum Eintreffen der Antwort fest und bestimmt den Zeitpunkt der TCP-Sendewiederholung
  2. BSie wird bei jedem Router um 1 verringert, und Pakete, bei denen sie 0 erreicht, werden verworfen; so wird verhindert, dass Pakete in einer Routing-Schleife endlos kreisen
  3. CPakete mit größerem Wert werden von Routern bevorzugt weitergeleitet
Antwort und Erläuterung anzeigen

Antwort: B. Sie wird bei jedem Router um 1 verringert, und Pakete, bei denen sie 0 erreicht, werden verworfen; so wird verhindert, dass Pakete in einer Routing-Schleife endlos kreisen

Trotz „Time“ im Namen dient die TTL in der Praxis als Obergrenze für die Zahl der Router (Hops), die ein Paket passieren darf, und wird bei jedem Router um 1 verringert. Erreicht sie 0, verwirft der Router das Paket und sendet der Quelle eine ICMP-Meldung „Time Exceeded“. Selbst wenn eine Fehlkonfiguration eine Routing-Schleife erzeugt, kreisen Pakete deshalb nicht endlos. Ein mit TTL 64 gesendetes Paket kommt zum Beispiel nach drei Routern mit 61 an. traceroute sendet Pakete mit TTL 1, 2, 3 usw. und ermittelt den Weg aus den „Time Exceeded“-Meldungen, die jeder Router zurückschickt. In IPv6 heißt das Feld mit derselben Aufgabe Hop Limit.
