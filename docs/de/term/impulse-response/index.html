Was ist Impulsantwort?

Ausgang h[n] eines Systems, wenn der Einheitsimpuls δ[n] (1 nur bei n = 0, sonst 0) angelegt wird. Bei einem linearen zeitinvarianten (LTI) System ist der Ausgang für jeden Eingang die Faltung des Eingangs mit h[n], y[n] = Σx[k]h[n − k]; h[n] beschreibt das System daher vollständig. Ein Filter, dessen h[n] nach endlicher Länge endet, ist ein FIR-Filter, eines, dessen h[n] unendlich lange andauert, ein IIR-Filter. BIBO-Stabilität erfordert, dass Σ|h[n]| endlich ist, und die z-Transformation von h[n] ist die Übertragungsfunktion H(z).

Jetzt üben: Fragen zu Impulsantwort

u[n] sei der Einheitssprung. Welches der folgenden LTI-Systeme, gegeben durch seine Impulsantwort, ist BIBO-stabil (jeder beschränkte Eingang ergibt einen beschränkten Ausgang)?

  1. Ah[n] = (−0,9)ⁿu[n]
  2. Bh[n] = u[n]
  3. Ch[n] = (1,1)ⁿu[n]
Antwort und Erläuterung anzeigen

Antwort: A. h[n] = (−0,9)ⁿu[n]

Ein LTI-System ist genau dann BIBO-stabil, wenn die Summe der Beträge seiner Impulsantwort Σ|h[n]| endlich ist. Für h[n] = (−0,9)ⁿu[n] gilt Σ|h[n]| = Σ0,9ⁿ = 1/(1 − 0,9) = 10; das ist endlich, also ist das System stabil. h[n] = u[n] ist ein Akkumulator, der seinen Eingang fortlaufend aufsummiert; die Summe ist unendlich, und ein konstanter Eingang lässt den Ausgang unbegrenzt wachsen. (1,1)ⁿ wächst mit der Zeit, dieses System ist also instabil.

Die Folge x[n] = {1, 2, 3} (n = 0, 1, 2) wird auf ein LTI-System mit der Impulsantwort h[n] = {1, −1} (n = 0, 1) gegeben. Welche Ausgangswerte y[0] bis y[3] ergeben sich?

  1. A−1, −1, −1, 3
  2. B1, 3, 5, 3
  3. C1, 1, 1, −3
Antwort und Erläuterung anzeigen

Antwort: C. 1, 1, 1, −3

Für h[n] = {1, −1} wird die Faltung y[n] = Σx[k]h[n − k] zu y[n] = x[n] − x[n − 1], der Differenz zum vorherigen Eingang. Es ergeben sich y[0] = 1 − 0 = 1, y[1] = 2 − 1 = 1, y[2] = 3 − 2 = 1 und y[3] = 0 − 3 = −3. Die Länge des Ausgangs ist 3 + 2 − 1 = 4, aus der Eingangslänge 3 und der Länge 2 der Impulsantwort.
