Was ist Cache-Speicher?

Schneller, kleiner Speicher in der Nähe der CPU. Er hält häufig benötigte Daten und überbrückt den Geschwindigkeitsunterschied zum Hauptspeicher. Er besteht überwiegend aus SRAM.

Japanische Bezeichnung: キャッシュメモリ
