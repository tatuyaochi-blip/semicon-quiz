Was ist Shadow Stack?

Mechanismus, der bei jedem Funktionsaufruf eine Kopie der Rücksprungadresse auch auf einem separaten Stack ablegt, den normale Schreibzugriffe nicht verändern können, und sie beim Rücksprung mit dem Wert auf dem normalen Stack vergleicht, um Manipulationen der Rücksprungadresse zu erkennen. Bei Abweichung wird eine Ausnahme ausgelöst und die Ausführung gestoppt. Hardwareseitig unterstützt ihn unter anderem Intel CET (Control-flow Enforcement Technology); er erschwert Angriffe wie ROP, die Pufferüberläufe auf dem Stack ausnutzen.

Japanische Bezeichnung: シャドウスタック

Antwort und Erläuterung anzeigen

Antwort: C. Beim Aufruf einer Funktion wird eine Kopie der Rücksprungadresse auch auf einem separaten Stack abgelegt, den normale Schreibzugriffe nicht ändern können, und beim Rücksprung werden beide verglichen

Wird eine Rücksprungadresse etwa durch einen Pufferüberlauf auf dem Stack überschrieben, springt die Ausführung beim Rücksprung aus der Funktion an eine vom Angreifer gewählte Stelle. Beim Shadow Stack legt der call-Befehl die Rücksprungadresse sowohl auf den normalen Stack als auch auf den Shadow Stack, und der ret-Befehl vergleicht beide. Shadow-Stack-Seiten sind ein besonderer Seitentyp, den gewöhnliche Store-Befehle nicht beschreiben können; ein Angreifer, der den normalen Stack überschrieben hat, kann die Kopie daher nicht ändern, und bei Abweichung wird eine Ausnahme ausgelöst und die Ausführung gestoppt.
