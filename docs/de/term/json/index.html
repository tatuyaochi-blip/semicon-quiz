Was ist JSON (JavaScript Object Notation)?

Textformat zur Darstellung von Daten, das auf der Schreibweise von Objekten in JavaScript beruht. Es kombiniert Objekte, die Name-Wert-Paare in { } einschließen, und Arrays, die Werte in [ ] auflisten; Werte können Zeichenketten, Zahlen, true/false oder null sein. Namen und Zeichenketten müssen immer in doppelte Anführungszeichen gesetzt werden. JSON ist knapper als XML und lässt sich in vielen Programmiersprachen lesen und schreiben, deshalb ist es als Datenformat von Web-APIs weit verbreitet. Sein Medientyp ist application/json.

Antwort und Erläuterung anzeigen

Antwort: C. Content-Type: application/json

Die Art der Daten im Body gibt der Header Content-Type an; als Wert steht ein Medientyp (MIME-Typ) in der Form „Typ/Untertyp“, etwa text/html oder image/png. Der Medientyp von JSON ist application/json. JSON ist ein Textformat, das Daten mit Name-Wert-Paaren und Arrays darstellt, etwa {"id": 42, "tags": ["a", "b"]}; es ist knapper als XML und lässt sich gut aus JavaScript verarbeiten, deshalb wird es bei Web-APIs häufig verwendet. Mit dem Header Accept teilt der Client in einer Anfrage mit, welche Formate er empfangen möchte.
