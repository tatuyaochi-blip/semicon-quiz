Was ist Statisches Linken?

Verfahren, bei dem der Code der verwendeten Bibliotheken in die ausführbare Datei kopiert und eingebunden wird. Sie läuft auch ohne Bibliotheken in der Laufzeitumgebung, die Datei wird aber größer, und Korrekturen an Bibliotheken wirken erst nach Neuerstellung.

Japanische Bezeichnung: 静的リンク

Fachgebiet: Linker, Loader und ausführbare Formate

Was der Linker tut

Beim statischen Linken liest der Linker die Objektdateien des Programms und die in der Befehlszeile genannten statischen Bibliotheken, holt die Archivmitglieder heraus, die zum Auflösen undefinierter Symbole nötig sind, und führt gleichartige Sektionen zusammen: allen Code in eine Textsektion, alle initialisierten Daten in eine Datensektion und so weiter. Anschließend vergibt er die endgültigen Adressen, passt jede Referenz anhand der Relokationseinträge an und schreibt eine einzige ausführbare Datei. Bei GCC fordert die Option -static dies für alle Bibliotheken an, einschließlich der C-Standardbibliothek, sofern statische Versionen davon installiert sind.

Statisches und dynamisches Linken im Vergleich

Eine statisch gelinkte ausführbare Datei ist in sich geschlossen: Beim Start muss nichts gesucht werden, es gibt keine Symbolbindung durch einen dynamischen Linker, und Aufrufe in Bibliothekscode erfolgen direkt. Die Kosten sind Größe und Wartung. Jedes Programm trägt seine eigene Kopie jeder verwendeten Bibliotheksroutine, sodass die Kopien im Speicher nicht wie die Seiten gemeinsam genutzter Bibliotheken zwischen Prozessen geteilt werden, und eine Sicherheitskorrektur in einer Bibliothek erreicht das Programm erst, wenn es neu gelinkt wird. Dynamisches Linken kehrt diese Abwägungen um, um den Preis, auf jeder Maschine, auf der das Programm läuft, von kompatiblen Bibliotheksversionen abzuhängen.

Grenzen der Eigenständigkeit

Eine statische ausführbare Datei hängt weiterhin von der CPU-Architektur und von der Systemaufrufschnittstelle des Betriebssystems ab und kann daher nicht einfach auf einem anderen Betriebssystem laufen. Manche Bibliotheksfunktionen setzen zudem im Hintergrund dynamisches Laden voraus. GNU libc warnt beispielsweise, dass Funktionen wie getaddrinfo, wenn sie in statisch gelinkten Programmen verwendet werden, für Namensdienst-Abfragen zur Laufzeit dennoch gemeinsam genutzte Bibliotheken benötigen. Statisches Linken bedeutet auch, dass das Programm Plug-ins im Stil von dlopen nicht so leicht nutzen kann, da es sich dabei um Shared Objects handelt, die einen dynamischen Linker erwarten.

Wo man ihm begegnet

Firmware für Mikrocontroller wird fast immer statisch zu einem einzigen Image gelinkt, da es zur Laufzeit keinen Lader und kein Dateisystem gibt, das Bibliotheken bereitstellen könnte. Auf Servern und in minimalen Container-Images werden statische ausführbare Dateien geschätzt, weil eine einzige Datei überallhin mit einem kompatiblen Kernel kopiert werden kann. Entwickler nutzen statisches Linken auch für Kommandozeilenwerkzeuge, die auf vielen Distributionen laufen müssen, ohne sich um Bibliotheksversionen zu kümmern, und nehmen eine größere Datei in Kauf, um Probleme wie eine fehlende oder inkompatible gemeinsam genutzte Bibliothek zu vermeiden.

Häufige Fragen

C-Programm mit gcc statisch linken

Man fügt dem Link-Befehl -static hinzu, zum Beispiel gcc -static main.c -o main. Damit das gelingt, müssen statische (.a-)Versionen aller beteiligten Bibliotheken, einschließlich der C-Bibliothek, installiert sein.

Warum ist meine statisch gelinkte ausführbare Datei so viel größer?

Sie enthält Kopien des gesamten verwendeten Bibliothekscodes, einschließlich Teilen der C-Laufzeitumgebung, statt auf bereits im System vorhandene gemeinsam genutzte Bibliotheken zu verweisen. Das Entfernen von Symbolen und das Linken mit Garbage Collection für Sektionen können die Größe verringern.

Ist ein statisch gelinktes Programm schneller?

Der Start ist meist schneller, weil keine gemeinsam genutzten Bibliotheken geladen und gebunden werden müssen und Aufrufe eine Indirektion vermeiden. Bei den meisten lang laufenden Programmen ist der Unterschied in der Geschwindigkeit im eingeschwungenen Zustand gering.
