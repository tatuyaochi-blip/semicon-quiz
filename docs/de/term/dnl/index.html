Was ist DNL (differenzielle Nichtlinearität)?

Fehler, der angibt, wie stark die Schrittweite zwischen benachbarten Codes eines AD-Wandlers vom idealen Wert 1 LSB abweicht. Bei −1 LSB entsteht ein fehlender Code (Missing Code).

Japanische Bezeichnung: DNL(微分非直線性)

„DNL (differenzielle Nichtlinearität)“ kommt in 8 Übungsfragen aus 3 Themen vor, z. B. A/D- und D/A-Wandlung, Test und Prüfung, Datenblätter lesen.

Fachgebiet: A/D- und D/A-Wandlung

Wie DNL definiert ist

Ein idealer N-Bit-Wandler teilt seinen Messbereich in 2ᴺ gleiche Stufen von 1 LSB (niederwertigstes Bit). Bei einem Analog-Digital-Wandler (ADC) sollte daher jeder Ausgangscode einem Eingangsintervall von genau 1 LSB Breite entsprechen. Die differenzielle Nichtlinearität (DNL) ist der Fehler jeder tatsächlichen Codebreite, ausgedrückt in LSB: DNL = (tatsächliche Breite − 1 LSB) / 1 LSB. Ein Code mit 1,5 LSB Breite hat DNL = +0,5 LSB, einer mit 0,7 LSB Breite −0,3 LSB. Bei einem Digital-Analog-Wandler (DAC) gilt dasselbe Prinzip für die Größe jeder Ausgangsstufe.

Fehlende Codes und Monotonie

Erreicht die DNL eines Codes −1 LSB, schrumpft seine Breite auf null, sodass dieser Code nie erscheint, egal wie das Eingangssignal durchgefahren wird: ein fehlender Code (Missing Code). Die Zusicherung „keine fehlenden Codes“ bei einer bestimmten Auflösung ist daher gleichbedeutend damit, dass die DNL über −1 LSB bleibt. Große positive DNL, über etwa +1 LSB, verschwendet Auflösung, weil ein breiter Code abdeckt, was eigentlich mehrere Codes sein sollten. Bei einem DAC garantiert eine DNL über −1 LSB Monotonie, das heißt, der Ausgang sinkt nie, wenn der Code steigt. Fehler häufen sich an wichtigen Übertragsübergängen wie von 0111…1 nach 1000…0, an denen fehlangepasste binär gewichtete Elemente umgeschaltet werden.

DNL im Vergleich zu INL, Offset- und Verstärkungsfehler

Der Offsetfehler verschiebt die gesamte Übertragungskennlinie und der Verstärkungsfehler ändert ihre Steigung; beide sind linear und lassen sich mit einer Zweipunktkalibrierung beseitigen. Die integrale Nichtlinearität (INL) ist die maximale Abweichung der tatsächlichen Kennlinie von einer Geraden, die entweder durch die Endpunkte oder als Ausgleichsgerade gelegt wird, und entspricht bei jedem Code der laufenden Summe der DNL bis zu diesem Code. Ein Wandler kann daher überall eine kleine DNL, aber eine große INL haben, wenn sich kleine Fehler in eine Richtung aufsummieren. INL zeigt sich als harmonische Verzerrung bei großen Signalen, während DNL die Genauigkeit kleiner Schritte und fehlende Codes bestimmt; keine von beiden lässt sich durch einfache Kalibrierung beheben.

DNL messen und im Entwurf verringern

Bei der Histogramm- bzw. Codedichtemethode wird dem ADC ein Signal mit bekannter Amplitudenverteilung zugeführt, und es wird gezählt, wie oft jeder Code auftritt. Bei einer langsamen Rampe oder einem Dreiecksignal sollte jeder Code gleich oft vorkommen, sodass die Anzahl jedes Codes geteilt durch den Mittelwert minus eins seine DNL ergibt; ein Sinussignal lässt sich leichter rein erzeugen, erfordert aber eine Korrektur seiner zu den Spitzen hin gewichteten Verteilung. Die Summation der DNL ergibt die INL. Auf der Entwurfsseite sind thermometercodierte Current-Steering-DACs und Widerstandsketten-DACs konstruktionsbedingt monoton, und die Segmentierung der oberen Bits in gleich gewichtete Elemente verringert die DNL an den wichtigen Übergängen.

Antwort und Erläuterung anzeigen

Antwort: B. Die Abweichung der Breite zwischen benachbarten Codes (Stufenbreite) von den idealen 1 LSB

Die DNL gibt an, wie stark die zu jedem Code gehörende Eingangsbreite (Stufenbreite) von den idealen 1 LSB abweicht; bei einer Breite von 1,5 LSB beträgt die DNL beispielsweise +0,5 LSB. Bei einer DNL von −1 LSB tritt der betreffende Code nicht mehr auf (Missing Code), und oberhalb von +1 LSB sinkt die effektive Auflösung. Die Abweichung der gesamten Kennlinie von der idealen Geraden ist die integrale Nichtlinearität (INL), die Abweichung des Ausgangs bei Eingang 0 der Offsetfehler.

Häufige Fragen

Was bedeutet eine DNL von ±0,5 LSB?

Jede Codebreite liegt zwischen 0,5 und 1,5 LSB, sodass kein Code fehlt und keiner breiter als anderthalb ideale Stufen ist. Das ist eine übliche Spezifikation für hochwertige Wandler.

Unterschied zwischen DNL und INL

DNL ist der Fehler jeder einzelnen Stufenbreite, während INL angibt, wie weit die gesamte Übertragungskennlinie von einer Geraden abweicht. Die INL bei einem Code ist im Wesentlichen die bis dahin aufsummierte DNL.

Garantiert eine DNL größer als −1 LSB keine fehlenden Codes?

Ja. Ein fehlender Code ist genau ein Code, dessen Breite auf null geschrumpft ist, was einer DNL = −1 LSB entspricht; hält man jede DNL über −1 LSB, ist dies daher ausgeschlossen.
