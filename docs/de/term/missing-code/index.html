Was ist Missing Code?

Fehler, bei dem ein bestimmter Ausgangscode eines AD-Wandlers bei Änderung des Eingangs nie auftritt. Entsteht, wenn die DNL −1 LSB erreicht.

Japanische Bezeichnung: ミッシングコード

„Missing Code“ kommt in 2 Übungsfragen aus 1 Themen vor, z. B. A/D- und D/A-Wandlung.

Fachgebiet: A/D- und D/A-Wandlung

Welche Aussage zur differentiellen Nichtlinearität (DNL) eines A/D-Wandlers ist richtig?

  1. ADer Fehler der Steigung (Verstärkung) der gesamten Übertragungskennlinie
  2. BDie Abweichung der Breite zwischen benachbarten Codes (Stufenbreite) von den idealen 1 LSB
  3. CDie Abweichung des Ausgangs bei Eingang 0
Antwort und Erläuterung anzeigen

Antwort: B. Die Abweichung der Breite zwischen benachbarten Codes (Stufenbreite) von den idealen 1 LSB

Die DNL gibt an, wie stark die zu jedem Code gehörende Eingangsbreite (Stufenbreite) von den idealen 1 LSB abweicht; bei einer Breite von 1,5 LSB beträgt die DNL beispielsweise +0,5 LSB. Bei einer DNL von −1 LSB tritt der betreffende Code nicht mehr auf (Missing Code), und oberhalb von +1 LSB sinkt die effektive Auflösung. Die Abweichung der gesamten Kennlinie von der idealen Geraden ist die integrale Nichtlinearität (INL), die Abweichung des Ausgangs bei Eingang 0 der Offsetfehler.

Wie heißt der Fehler eines A/D-Wandlers, bei dem ein bestimmter Ausgangscode auch bei Variation des Eingangs nie auftritt?

  1. AMissing Code
  2. BAliasing
  3. CGlitch
Antwort und Erläuterung anzeigen

Antwort: A. Missing Code

Bei einem Code mit einer DNL von −1 LSB oder weniger verschwindet die zugehörige Eingangsbreite, sodass er am Ausgang nicht erscheint. Dies ist der Missing Code; ist etwa das Gewicht höherwertiger Bits im internen D/A-Wandler eines SAR-Wandlers zu klein, können Codes übersprungen werden. Bei Regelsystemen oder Anwendungen, die die Verteilung per Histogramm auswerten, ist das fatal; deshalb geben Datenblätter die Bitzahl an, für die „No Missing Codes“ garantiert wird.
