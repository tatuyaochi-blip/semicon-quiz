Was ist Streaming Multiprocessor (SM)?

Einheit in NVIDIA-GPUs, die Rechenwerke, Register, Shared Memory und die Schaltung zum Warp-Wechsel zusammenfasst. Eine GPU besteht aus vielen nebeneinander angeordneten SMs.

Japanische Bezeichnung: ストリーミングマルチプロセッサ

Antwort und Erläuterung anzeigen

Antwort: C. Jeder Block wird einem SM zugewiesen und dort bis zum Ende ausgeführt; auf einem SM können mehrere Blöcke gleichzeitig platziert sein

Die GPU besitzt viele SMs und weist die Blöcke des Kernels der Reihe nach freien SMs zu. Ein Block wird auf einem SM ausgeführt, sodass die Threads des Blocks den Shared Memory dieses SM nutzen und sich synchronisieren können. Ist die Zahl der Blöcke deutlich größer als die Zahl der SMs, erhalten bei unterschiedlich großen GPUs alle SMs Arbeit, und einem fertigen SM wird der nächste Block zugewiesen.
