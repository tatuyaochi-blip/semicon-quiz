Was ist Same-Origin-Policy?

Regel im Browser, die Skripte einer Seite, die von einem Ursprung (Origin) geladen wurde, daran hindert, den Inhalt von Ressourcen eines anderen Ursprungs zu lesen. Ein Ursprung ist die Kombination aus Schema, Hostname und Portnummer; zwei URLs haben nur dann denselben Ursprung, wenn alle drei übereinstimmen. Die Regel verhindert, dass das Skript einer bösartigen Seite Informationen von anderen Websites ausliest, bei denen der Nutzer angemeldet ist. Einbettungen wie das Laden von Bildern oder Skripten sind erlaubt; muss eine Seite Antworten eines anderen Ursprungs lesen, verwendet man CORS, das auf der Erlaubnis des Servers beruht.

Japanische Bezeichnung: 同一オリジンポリシー

Antwort und Erläuterung anzeigen

Antwort: A. https://www.example.com/data/list.json

Ein Ursprung (Origin) wird durch die Kombination aus Schema, Hostname und Portnummer bestimmt; zwei URLs haben nur dann denselben Ursprung, wenn alle drei übereinstimmen. Der Pfad spielt keine Rolle, daher hat /data/list.json denselben Ursprung. Nach der Same-Origin-Policy kann das JavaScript einer Seite den Inhalt von Antworten aus anderen Ursprüngen grundsätzlich nicht lesen. So wird verhindert, dass das Skript einer bösartigen Seite Informationen von anderen Websites ausliest, bei denen der Nutzer angemeldet ist.
