Was ist Occupancy (Auslastung)?

Verhältnis der tatsächlich auf einem GPU-SM befindlichen Warps zur maximal gleichzeitig möglichen Warp-Zahl. Bestimmt durch Register- und Shared-Memory-Verbrauch.

Japanische Bezeichnung: 占有率

„Occupancy (Auslastung)“ kommt in 9 Übungsfragen aus 4 Themen vor, z. B. GPU-Programmierung, Leistungsbewertung und Profiling, Halbleiterindustrie und Markt.

Fachgebiet: GPU-Programmierung

  2. BDas Verhältnis der tatsächlich auf einem SM befindlichen Warps zur maximalen Zahl gleichzeitig platzierbarer Warps
  3. CDer Anteil des GPU-Speichers, der mit Daten belegt ist
Antwort und Erläuterung anzeigen

Antwort: B. Das Verhältnis der tatsächlich auf einem SM befindlichen Warps zur maximalen Zahl gleichzeitig platzierbarer Warps

Die Zahl der Warps, die jeder SM gleichzeitig aufnehmen kann, hat eine Obergrenze, und die tatsächliche Zahl wird durch Register pro Thread, Shared Memory pro Block, Blockgröße usw. bestimmt. Dieses Verhältnis ist die Occupancy. Bei niedriger Occupancy stehen anstelle von Warps, die auf Speicher warten, nur wenige ausführbare Warps bereit, und die Recheneinheiten liegen leicht brach. Für CUDA gibt es auch Werkzeuge zur Berechnung der Occupancy.

Welche Aussage zur Occupancy der GPU ist richtig?

  1. ABei 100 % Occupancy wird stets die höchste Leistung erzielt
  2. BAuch bei niedriger Occupancy kann hohe Leistung erreicht werden, wenn jeder Thread viele unabhängige Berechnungen ausführt und so die Befehlsparallelität steigt
  3. CDie Occupancy hat überhaupt keinen Einfluss auf die Leistung
Antwort und Erläuterung anzeigen

Antwort: B. Auch bei niedriger Occupancy kann hohe Leistung erreicht werden, wenn jeder Thread viele unabhängige Berechnungen ausführt und so die Befehlsparallelität steigt

Occupancy ist ein Mittel, Latenzen zu verbergen, kein Ziel. Kann ein Thread mehrere voneinander unabhängige Berechnungen oder Speicherlesezugriffe hintereinander ausgeben, lässt sich die Wartezeit auch mit wenigen Warps füllen. Umgekehrt kann es langsamer werden, wenn zur Steigerung der Occupancy die Register verringert werden und dadurch mehr in den Speicher ausgelagert wird. Verlässlich ist es, die Leistung durch tatsächliche Messung mit einem Profiler zu beurteilen.
