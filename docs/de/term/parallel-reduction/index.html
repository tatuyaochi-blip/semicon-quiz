Was ist Parallele Reduktion?

Verfahren, Summen vieler Werte u. Ä. parallel in einer Baumstruktur zu berechnen, indem benachbarte Werte wiederholt zusammengefasst werden. n Werte lassen sich in log2 n Stufen verarbeiten.

Japanische Bezeichnung: 並列リダクション

Fachgebiet: GPU-Programmierung

Verwandte Begriffe

Bank-Konflikt Constant Memory CUDA Gemischte Genauigkeit (Mixed Precision) GPU-Kernel Grid-Stride-Loop Latenzverdeckung (Latency Hiding) Memory Coalescing Occupancy (Auslastung) OpenCL
