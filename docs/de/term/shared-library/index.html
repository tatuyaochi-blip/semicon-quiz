Was ist Gemeinsame Bibliothek (Shared Library)?

Eine Bibliothek, die durch dynamisches Linken zur Laufzeit geladen wird: .so unter Linux, .dll unter Windows. Sie wird als positionsunabhängiger Code gebaut, so dass ihre Codeseiten von vielen Prozessen geteilt werden können.

Japanische Bezeichnung: 共有ライブラリ
