Was ist Array?

Eine Datenstruktur, die Werte desselben Typs nacheinander speichert und jedes Element über einen Index anspricht. Weil die Elemente zusammenhängend im Speicher liegen, lässt sich die Position jedes Elements aus seinem Index berechnen, sodass jedes Element in konstanter Zeit gelesen oder geschrieben werden kann. Manche Sprachen beginnen die Indizes bei 0, manche Schreibweisen bei 1.

Japanische Bezeichnung: 配列

Jetzt üben: Fragen zu Array

Welche Zeitkomplexität hat bei einem Array mit n Elementen ein Verfahren, das jedes Paar zweier verschiedener Elemente genau einmal vergleicht (eine doppelte Schleife, die das i-te Element mit allen dahinterliegenden Elementen vergleicht und i schrittweise erhöht)?

  1. AO(n)
  2. BO(n log n)
  3. CO(n²)
Antwort und Erläuterung anzeigen

Antwort: C. O(n²)

Die Zahl der verglichenen Paare beträgt (n−1) + (n−2) + … + 1 = n(n−1)/2, also 45 bei n = 10 und 499.500 bei n = 1000. Die O-Notation beschreibt nur, wie der Aufwand bei großem n wächst; daher entfallen der Faktor 1/2 und der Term niedrigerer Ordnung, und es ergibt sich O(n²). Verdoppelt sich n, vervierfacht sich die Zahl der Vergleiche ungefähr. O(n) ist die Komplexität eines Verfahrens, das jedes Element einmal betrachtet, und O(n log n) die von Verfahren wie Mergesort, die die Daten wiederholt halbieren.

Eine lineare Suche vergleicht die Elemente eines Arrays mit 100 verschiedenen Werten der Reihe nach von vorn, um einen Zielwert zu finden. Der Zielwert ist immer im Array enthalten und steht mit gleicher Wahrscheinlichkeit an jeder Position. Wie viele Vergleiche sind im Mittel nötig?

  1. AEtwa 7
  2. B50,5
  3. C100
Antwort und Erläuterung anzeigen

Antwort: B. 50,5

Steht der Zielwert an Position k, sind k Vergleiche nötig; im Mittel also (1 + 2 + … + 100) / 100 = 50,5, allgemein (n + 1)/2. Im besten Fall (Zielwert ganz vorn) genügt 1 Vergleich, im schlechtesten Fall (Zielwert am Ende) sind es 100. Sowohl der mittlere als auch der schlechteste Fall sind proportional zu n, die Komplexität ist also O(n). Etwa 7 entspricht log₂ 100 ≈ 6,6, der Schrittzahl einer binären Suche, die sich nur auf sortierte Daten anwenden lässt.

Fragen mit „Array“ (59)

  1. Welche Zeitkomplexität hat bei einem Array mit n Elementen ein Verfahren, das jedes Paar zweier verschiedener Elemente genau einmal vergleicht (eine doppelte Schleife, die das i-te Element mit allen dahinterliegenden Elementen vergleicht und i schrittweise erhöht)?

  3. Welche Aussage beschreibt eine verkettete Liste (eine Liste, in der jedes Element einen Zeiger auf das nächste Element enthält) im Vergleich zu einem Array richtig?
  4. Eine binäre Suche sucht 38 im aufsteigend sortierten Array a[0] bis a[9] = 3, 8, 12, 17, 23, 31, 38, 45, 52, 60. Der Suchbereich beginnt mit lo = 0 und hi = 9, und die mittlere Position ist (lo + hi) ÷ 2 abgerundet. Welche Folge gibt die Elemente, die mit 38 verglichen werden, in der richtigen Reihenfolge an?
  5. Das Array 5, 3, 8, 1, 4 wird mit Bubblesort aufsteigend sortiert. Wie sieht das Array nach einem Durchlauf aus, bei dem benachbarte Elemente von vorn bis zum Ende verglichen und vertauscht werden, wenn das linke größer ist?
  6. Das Array 29, 10, 14, 37, 13 wird mit Selectionsort aufsteigend sortiert: Das Minimum des unsortierten Teils wird gesucht und mit dem ersten Element des unsortierten Teils vertauscht. Wie sieht das Array aus, nachdem dieser Schritt zweimal ausgeführt wurde?
  7. Ein Array mit 10 Elementen wird mit Insertionsort aufsteigend sortiert. Jedes Element ab dem zweiten wird herausgenommen und mit den Elementen links davon verglichen, beginnend beim linken Nachbarn, bis ein Element gefunden wird, das kleiner oder gleich ist, oder der Anfang erreicht ist. Wie viele Vergleiche sind nötig, wenn das Array bereits aufsteigend sortiert ist, und wie viele, wenn es absteigend sortiert ist?
  8. Ein binärer Heap wird mit der Wurzel in a[0] in einem Array a[0], a[1], a[2], … gespeichert, wobei jede Ebene von oben beginnend von links nach rechts aufgefüllt wird. Welches sind die Kinder und der Elternknoten von a[4]?
  9. Ein Max-Heap, in dem der Wert jedes Elternknotens mindestens so groß ist wie die Werte seiner Kinder, wird in einem Array mit der Wurzel in a[0] gespeichert. Zum Heap 50, 30, 40, 10, 20, 35 wird 45 hinzugefügt, indem es ans Ende gesetzt und dann mit seinem Elternknoten vertauscht wird, solange es größer als dieser ist. Wie sieht das resultierende Array aus?
  10. Ein dynamisches Array legt, wenn ein Element hinzugefügt wird, während es voll ist, einen neuen Bereich mit doppelter Kapazität an und kopiert alle Elemente dorthin. Wie viele Elementkopien entstehen insgesamt, wenn einem leeren Array mit der Kapazität 1 nacheinander 1000 Elemente hinzugefügt werden?
  11. Das folgende Programm sollte die Summe aller Elemente des Arrays a berechnen. Die Array-Indizes beginnen bei 1. Welchen Wert hat s nach der Ausführung?
  12. Die Array-Indizes beginnen bei 1. Das folgende Programm sucht das größte Element. Welchen Wert hat m nach der Ausführung?
  13. Das folgende Programm sollte die Reihenfolge der Elemente des Arrays a umkehren. Die Array-Indizes beginnen bei 1. Was enthält a nach der Ausführung?
  14. Die Array-Indizes beginnen bei 1. Was enthält das Array a, nachdem das folgende Programm ausgeführt wurde?
