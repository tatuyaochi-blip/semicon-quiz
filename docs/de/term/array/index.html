Was ist Array?

Eine Datenstruktur, die Werte desselben Typs nacheinander speichert und jedes Element über einen Index anspricht. Weil die Elemente zusammenhängend im Speicher liegen, lässt sich die Position jedes Elements aus seinem Index berechnen, sodass jedes Element in konstanter Zeit gelesen oder geschrieben werden kann. Manche Sprachen beginnen die Indizes bei 0, manche Schreibweisen bei 1.

Japanische Bezeichnung: 配列

Jetzt üben: Fragen zu Array

In einem Array von Zählern je Thread wie „long cnt[8];“ tritt False Sharing auf. Welche Gegenmaßnahme ist am besten geeignet?

  1. ADen Zählertyp von long auf int ändern und das Array verkleinern
  2. BZwischen den Zählern Füllbytes einfügen oder sie ausrichten, sodass sie in verschiedenen Cache-Zeilen liegen
  3. CDie Zahl der Threads erhöhen, um die Wartezeiten zu verteilen
Antwort und Erläuterung anzeigen

Antwort: B. Zwischen den Zählern Füllbytes einfügen oder sie ausrichten, sodass sie in verschiedenen Cache-Zeilen liegen

Bei 8 Byte großem long passen die 8 Zähler in eine Zeile von 64 Byte, und alle Threads streiten um dieselbe Zeile. Fügt man Füllbytes ein, sodass jeder Zähler auf einer 64-Byte-Grenze liegt, oder richtet man die Struktur an der Größe der Cache-Zeile aus, kann jeder Thread eine eigene Zeile nutzen. Wirksam ist auch, dass jeder Thread in einer lokalen Variablen zählt und erst am Ende einmal auf den gemeinsamen Speicherplatz addiert.

Ein Array mit 1000 Elementen soll mit 256 Threads pro Block verarbeitet werden, wobei jeder Thread ein Element bearbeitet. Wie viele Blöcke müssen gestartet werden?

  1. A3
  2. B4
  3. C1000
Antwort und Erläuterung anzeigen

Antwort: B. 4

1000÷256≈3,9; bei Abrunden auf 3 Blöcke würden nur 256×3=768 Elemente verarbeitet, und der Rest bliebe unbearbeitet. Es werden daher aufgerundet 4 Blöcke (1024 Threads) gestartet, und die 24 überzähligen Threads tun nichts. Allgemein wird mit „(n + 256 - 1) / 256“ aufgerundet. Damit die überzähligen Threads nicht außerhalb des Arrays lesen oder schreiben, muss im Kernel die Nummer geprüft werden.

  13. Das Array 5, 3, 8, 1, 4 wird mit Bubblesort aufsteigend sortiert. Wie sieht das Array nach einem Durchlauf aus, bei dem benachbarte Elemente von vorn bis zum Ende verglichen und vertauscht werden, wenn das linke größer ist?
  14. Das Array 29, 10, 14, 37, 13 wird mit Selectionsort aufsteigend sortiert: Das Minimum des unsortierten Teils wird gesucht und mit dem ersten Element des unsortierten Teils vertauscht. Wie sieht das Array aus, nachdem dieser Schritt zweimal ausgeführt wurde?
  15. Ein Array mit 10 Elementen wird mit Insertionsort aufsteigend sortiert. Jedes Element ab dem zweiten wird herausgenommen und mit den Elementen links davon verglichen, beginnend beim linken Nachbarn, bis ein Element gefunden wird, das kleiner oder gleich ist, oder der Anfang erreicht ist. Wie viele Vergleiche sind nötig, wenn das Array bereits aufsteigend sortiert ist, und wie viele, wenn es absteigend sortiert ist?
