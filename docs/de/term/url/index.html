Was ist URL (Uniform Resource Locator)?

Zeichenkette, die den Ort einer Ressource wie einer Webseite angibt. Wie in https://www.example.com:8443/docs/page.html?q=1#top besteht sie aus Schema (https), Hostname, Portnummer, Pfad, Query (nach ?) und Fragment (nach #). Fehlt die Portnummer, gilt der Standardwert (bei HTTPS 443), und der Hostname wird per DNS in eine IP-Adresse aufgelöst.

Japanische Bezeichnung: URL

Jetzt üben: Fragen zu URL (Uniform Resource Locator)

Ein Browser öffnet https://www.example.com:8443/docs/guide.html?lang=ja#install. Welcher Teil dieser URL ist nicht in der an den Server gesendeten Anfrage enthalten und wird erst nach dem Laden der Seite nur im Browser verwendet?

  1. A:8443
  2. B?lang=ja
  3. C#install
Antwort und Erläuterung anzeigen

Antwort: C. #install

Diese URL besteht aus dem Schema (https), dem Hostnamen (www.example.com), der Portnummer (8443; ohne Angabe bei https 443), dem Pfad (/docs/guide.html), der Query (lang=ja) und dem Fragment (install). Der Browser bestimmt anhand der Portnummer, wohin er sich verbindet, und sendet Pfad und Query in der Anfrage an den Server, das Fragment nach dem # aber nicht. Das Fragment wird nur im Browser verwendet, etwa um in der Seite zur Position des Elements mit id="install" zu springen.

Um das japanische Zeichen „あ“ in die Query einer URL zu schreiben, wird die Bytefolge, die es in UTF-8 darstellt (E3 81 82), prozentkodiert. Welches Ergebnis ist richtig?

  1. A%E3%81%82
  2. B%u3042
  3. C&#x3042;
Antwort und Erläuterung anzeigen

Antwort: A. %E3%81%82

Bei der Prozentkodierung (Percent-Encoding) werden Zeichen, die nicht unverändert in einer URL stehen können, oder Zeichen mit besonderer Bedeutung wie / ? # &, wenn sie als Daten verwendet werden, in Bytes umgewandelt, und jedes Byte wird als „%“ mit zwei Hexadezimalziffern (Basis 16) geschrieben. „あ“ besteht in UTF-8 aus den drei Bytes E3 81 82 und wird daher zu %E3%81%82. Ein Leerzeichen wird zu %20 (im Format für Formularübermittlungen wird auch + verwendet). In JavaScript erledigt die Funktion encodeURIComponent diese Umwandlung.
