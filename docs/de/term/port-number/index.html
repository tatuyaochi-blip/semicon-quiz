Was ist Portnummer?

Zahl von 0 bis 65535, mit der TCP und UDP unterscheiden, für welche Anwendung auf einem Endgerät die Daten bestimmt sind. Die Ports 0–1023, etwa 80 für HTTP, 443 für HTTPS und 53 für DNS, heißen Well-known Ports.

Japanische Bezeichnung: ポート番号

  1. AHTTP 80, HTTPS 443, DNS 53
  2. BHTTP 8080, HTTPS 443, DNS 25
  3. CHTTP 80, HTTPS 22, DNS 53
Antwort und Erläuterung anzeigen

Antwort: A. HTTP 80, HTTPS 443, DNS 53

Eine Portnummer ist eine 16-Bit-Zahl von 0 bis 65535, die angibt, für welche Anwendung auf einem per IP-Adresse erreichten Endgerät die Daten bestimmt sind. Die Ports 0–1023 heißen Well-known Ports und sind wichtigen Diensten zugeordnet. Typisch sind HTTP 80, HTTPS 443, DNS 53, SSH 22 und SMTP (Mailübertragung) 25. Die Clientseite verwendet als Quellport eine Nummer, die das Betriebssystem jeweils wählt (ephemerer Port). Dienste können auch auf nicht standardmäßigen Nummern laufen; 8080 wird häufig für Webentwicklung oder Proxyserver verwendet, dann muss die verbindende Seite die Nummer jedoch angeben.

Ein Browser öffnet https://www.example.com:8443/docs/guide.html?lang=ja#install. Welcher Teil dieser URL ist nicht in der an den Server gesendeten Anfrage enthalten und wird erst nach dem Laden der Seite nur im Browser verwendet?

  1. A:8443
  2. B?lang=ja
  3. C#install
Antwort und Erläuterung anzeigen

Antwort: C. #install

Diese URL besteht aus dem Schema (https), dem Hostnamen (www.example.com), der Portnummer (8443; ohne Angabe bei https 443), dem Pfad (/docs/guide.html), der Query (lang=ja) und dem Fragment (install). Der Browser bestimmt anhand der Portnummer, wohin er sich verbindet, und sendet Pfad und Query in der Anfrage an den Server, das Fragment nach dem # aber nicht. Das Fragment wird nur im Browser verwendet, etwa um in der Seite zur Position des Elements mit id="install" zu springen.
