Was ist GPU-Kernel?

Funktion, die auf der GPU von vielen Threads gleichzeitig ausgeführt wird. Sie wird vom CPU-Programm gestartet, und jeder Thread wählt anhand seiner Nummer die ihm zugeordneten Daten. Nicht zu verwechseln mit dem Betriebssystemkern.

Japanische Bezeichnung: GPUカーネル

Antwort und Erläuterung anzeigen

Antwort: C. Da die Gesamtzahl der Register des SM fest ist, sinkt die Zahl gleichzeitig platzierbarer Threads, und Speicherlatenzen lassen sich schwerer verbergen

Die GPU hält die Register aller laufenden Threads auf dem Chip und wechselt so in einem Augenblick zwischen Warps. Verwendet ein Thread viele Register, sinkt daher die Zahl der gleichzeitig auf dem SM platzierbaren Threads. Reichen die Register nicht aus, werden sie in den Speicher ausgelagert (Spill), was ebenfalls verlangsamen kann. Mitunter wird über die Compiler-Einstellung eine Obergrenze für Register angegeben, um einen Ausgleich mit der Thread-Zahl herzustellen.

  3. CDas CPU-seitige Programm liest die Werte, die jeder Thread mit printf ausgegeben hat, als Variablen ein
Antwort und Erläuterung anzeigen

Antwort: B. Der Kernel schreibt seine Ergebnisse in ein Array im GPU-Speicher, und die CPU-Seite kopiert dieses Array nach Ende des Kernels in den CPU-Speicher (oder liest Unified Memory)

Ein GPU-Kernel wird von vielen Threads gleichzeitig ausgeführt und kann seine Ergebnisse daher nicht als einzelnen Rückgabewert liefern; bei CUDA muss eine __global__-Funktion den Rückgabetyp void haben. Die CPU-Seite reserviert ein Array im GPU-Speicher und übergibt dessen Zeiger als Argument, und jeder Thread schreibt sein Ergebnis in das Element, für das er zuständig ist. Da Kernel-Starts asynchron sind, kopiert die CPU-Seite das Array nach Ende des Kernels mit cudaMemcpy o. Ä. zurück (im selben Stream wartet die Kopie auf das Ende des vorherigen Kernels). printf im Kernel ist ein Debugging-Hilfsmittel zur Anzeige; das Programm kann diese Werte nicht einlesen.
