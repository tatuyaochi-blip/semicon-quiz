Was ist Ausrichtung und Auffüllung (Alignment und Padding)?

Das Ablegen von Daten an Adressen, die ein Vielfaches einer typabhängigen Zahl sind (Alignment), und die dafür zwischen oder hinter den Daten eingefügten ungenutzten Bytes (Padding, Füllbytes). In einer Umgebung, in der int an 4-Byte-Grenzen ausgerichtet wird, folgen in struct { char c; int i; char d; } auf c 3 Byte und auf d 3 Byte, sodass die Größe 12 Byte beträgt. Zugriffe auf nicht ausgerichtete Adressen sind je nach CPU langsamer oder lösen eine Ausnahme aus. Ordnet man die Member vom größten Typ abwärts an, lässt sich das Padding verringern.

Japanische Bezeichnung: アライメントとパディング

Antwort: B. Je nach CPU-Implementierung tritt eine Ausnahme auf, oder der Zugriff wird in Hardware oder Software behandelt und ist sehr langsam

4-Byte-Daten an einer Adresse, die ein Vielfaches von 4 ist, lassen sich mit einem Speicherzugriff lesen. Überschreiten sie eine Grenze, sind zwei Zugriffe nötig; RISC-V überlässt es der Implementierung, nicht ausgerichtete Zugriffe in der Schaltung zu behandeln oder eine Ausnahme auszulösen und der Software zu überlassen. Im zweiten Fall ist der Zugriff um Größenordnungen langsamer. Deshalb fügen Compiler zwischen Strukturelementen Füllbytes (Padding) zur Ausrichtung ein.
