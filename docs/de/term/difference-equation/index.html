Was ist Differenzengleichung?

Gleichung, die den Ausgang eines zeitdiskreten Systems als gewichtete Summe aktueller und vergangener Eingänge sowie vergangener Ausgänge ausdrückt. y[n] = x[n] + 0,5y[n − 1] addiert zum Beispiel die Hälfte des vorherigen Ausgangs zum aktuellen Eingang. Eine Gleichung ohne vergangene Ausgänge auf der rechten Seite beschreibt ein FIR-Filter, eine mit vergangenen Ausgängen (mit Rückkopplung) meist ein IIR-Filter, dessen Impulsantwort unendlich lange andauert. Mit Anfangswerten lässt sie sich schrittweise berechnen und direkt in Software oder Hardware umsetzen. Die z-Transformation beider Seiten liefert die Übertragungsfunktion H(z).

Japanische Bezeichnung: 差分方程式

Jetzt üben: Fragen zu Differenzengleichung

Auf das durch die Differenzengleichung y[n] = x[n] + 0,5y[n − 1] beschriebene System wird ab n = 0 ein Einheitssprung (x[n] = 1 für n ≥ 0) gegeben. Welchen Wert hat y[2], wenn y[−1] = 0 ist?

  1. A1,75
  2. B1,875
  3. C2
Antwort und Erläuterung anzeigen

Antwort: A. 1,75

Schrittweise gerechnet: y[0] = 1 + 0,5 × 0 = 1; y[1] = 1 + 0,5 × 1 = 1,5; y[2] = 1 + 0,5 × 1,5 = 1,75. Rechnet man weiter, ergibt sich y[n] = 2 − 0,5ⁿ, das sich dem Endwert 1/(1 − 0,5) = 2 nähert. Da vergangene Ausgänge verwendet werden (es gibt eine Rückkopplung), handelt es sich um ein IIR-Filter, dessen Impulsantwort 0,5ⁿ unendlich lange andauert.

Welche Übertragungsfunktion H(z) = Y(z)/X(z) hat das durch die Differenzengleichung y[n] = x[n] + 0,5x[n − 1] + 0,25y[n − 1] beschriebene System?

  1. A(1 + 0,5z⁻¹)/(1 + 0,25z⁻¹)
  2. B(1 − 0,25z⁻¹)/(1 + 0,5z⁻¹)
  3. C(1 + 0,5z⁻¹)/(1 − 0,25z⁻¹)
Antwort und Erläuterung anzeigen

Antwort: C. (1 + 0,5z⁻¹)/(1 − 0,25z⁻¹)

Eine Verzögerung um einen Abtastwert entspricht in der z-Transformation der Multiplikation mit z⁻¹; die Transformation beider Seiten ergibt daher Y(z) = X(z) + 0,5z⁻¹X(z) + 0,25z⁻¹Y(z). Fasst man die Y(z)-Terme links zusammen, erhält man (1 − 0,25z⁻¹)Y(z) = (1 + 0,5z⁻¹)X(z), also H(z) = (1 + 0,5z⁻¹)/(1 − 0,25z⁻¹). Der Zähler enthält die Koeffizienten der Eingangsseite, der Nenner die der Rückkopplung des Ausgangs; z = 0,25, das den Nenner zu 0 macht, ist ein Pol, und z = −0,5, das den Zähler zu 0 macht, ist eine Nullstelle.
