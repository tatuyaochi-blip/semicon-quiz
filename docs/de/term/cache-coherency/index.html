Was ist Cache-Kohärenz?

Mechanismus in Mehrkern-CPUs, der die Konsistenz sicherstellt, wenn mehrere Kerne Daten derselben Adresse in ihren Caches halten. Schreibt ein Kern, werden z. B. die veralteten Kopien in anderen Kernen für ungültig erklärt.

Japanische Bezeichnung: キャッシュコヒーレンシ

Jetzt üben: Fragen zu Cache-Kohärenz

Was muss bei einem System, in dem die Hardware die Cache-Kohärenz nicht gewährleistet (nicht kohärent), vor dem Lesen von per DMA vom Gerät in den Hauptspeicher geschriebenen Daten durch die CPU von der Software erledigt werden?

  1. ADie Taktfrequenz der CPU vorübergehend senken
  2. BDen Cache-Inhalt des betreffenden Bereichs ungültig machen, sodass aus dem Hauptspeicher neu gelesen wird
  3. CDen gesamten Cache-Inhalt in den Hauptspeicher zurückschreiben und anschließend das per DMA gelieferte Ergebnis verwerfen
Antwort und Erläuterung anzeigen

Antwort: B. Den Cache-Inhalt des betreffenden Bereichs ungültig machen, sodass aus dem Hauptspeicher neu gelesen wird

DMA überträgt Daten ohne Umweg über die CPU zwischen Gerät und Hauptspeicher; in Systemen, in denen die Hardware keine Kohärenz gewährleistet, können im CPU-Cache daher noch veraltete Daten dieses Bereichs liegen. Würde man direkt lesen, bekäme man den alten Wert statt der per DMA gelieferten neuen Daten. Deshalb macht der Treiber vor dem Lesen den Cache dieses Bereichs ungültig, damit der neue Wert aus dem Hauptspeicher gelesen wird. Umgekehrt werden an das Gerät zu sendende Daten vor dem DMA-Start aus dem Cache zurückgeschrieben.

Zwei Kerne besitzen jeweils in ihrem eigenen Cache eine Kopie der Variablen x. Welches Problem kann auftreten, wenn Kern 1 x liest, nachdem Kern 0 x geschrieben hat, und es keinen Cache-Kohärenz-Mechanismus gibt?

  1. AKern 1 liest den veralteten Wert, der noch in seinem eigenen Cache steht
  2. BDas Lesen von Kern 1 ist stets schneller als das Schreiben von Kern 0
  3. CDer Wert von x ist beim Lesen verdoppelt
Antwort und Erläuterung anzeigen

Antwort: A. Kern 1 liest den veralteten Wert, der noch in seinem eigenen Cache steht

In Multicore-CPUs entstehen in den Caches der einzelnen Kerne Kopien von Daten derselben Adresse. Schreibt Kern 0 x nur in seinem eigenen Cache, bleibt im Cache von Kern 1 der alte Wert stehen, und Kern 1 liest diesen. Ein Cache-Kohärenz-Mechanismus sorgt dafür, dass von jedem Kern aus der aktuelle Wert sichtbar ist, etwa indem beim Schreiben die Kopien anderer Kerne ungültig gemacht werden.
