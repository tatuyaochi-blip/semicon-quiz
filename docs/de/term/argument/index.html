Was ist Argument?

Ein Wert, der beim Aufruf einer Funktion oder Prozedur übergeben wird. Die Variable, die den Wert in der Deklaration empfängt, heißt formaler Parameter, der beim Aufruf übergebene Wert aktuelles Argument. Argumente können als Wert übergeben werden (Call by Value), wobei der Wert kopiert wird, oder als Referenz (Call by Reference), wobei die aufgerufene Funktion auf die Variable oder das Array selbst zugreift.

Japanische Bezeichnung: 引数
