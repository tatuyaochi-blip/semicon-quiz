Was ist DIMM?

Speichermodul, bei dem mehrere DRAM-Chips auf einer kleinen Platine sitzen und in Steckplätze von PCs oder Servern gesteckt werden können.

Japanische Bezeichnung: DIMM

„DIMM“ kommt in 1 Übungsfragen aus 1 Themen vor, z. B. DRAM.

Antwort: C. DIMM (Speichermodul)

Ein DIMM (Dual Inline Memory Module) ist ein Modul, bei dem mehrere DRAM-Chips auf einer Platine montiert sind; es heißt „Dual“, weil die Kontakte auf Vorder- und Rückseite unterschiedliche Signale führen. Es wird in den Steckplatz des Mainboards gesteckt und kann ausgetauscht oder erweitert werden; die kompakte Ausführung für Notebooks ist das SO-DIMM. Für Server gibt es RDIMM mit Signalpufferung, und bei DDR5 sitzt auch eine Spannungsversorgungsschaltung (PMIC) auf dem Modul.
