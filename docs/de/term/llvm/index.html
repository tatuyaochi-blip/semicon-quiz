Was ist LLVM?

Compiler-Infrastruktur, in der um eine gemeinsame Zwischendarstellung (LLVM IR) sprachspezifische Frontends, Optimierungsstufen und CPU-spezifische Backends kombiniert werden können. Wird für viele Sprachen und CPUs verwendet.

Japanische Bezeichnung: LLVM

  1. AEin ausschließlich für C gedachter Compiler, der mit anderen Sprachen nicht verwendbar ist
  2. BEine Kombination aus Assembler und Linker nur für eine bestimmte CPU
  3. CEine gemeinsame Zwischendarstellung im Zentrum, an die Frontends und Backends angeschlossen werden
Antwort und Erläuterung anzeigen

Antwort: C. Eine gemeinsame Zwischendarstellung im Zentrum, an die Frontends und Backends angeschlossen werden

LLVM ist eine Compiler-Infrastruktur rund um die gemeinsame Zwischendarstellung LLVM IR. Frontends verschiedener Sprachen, allen voran Clang für C/C++, übersetzen den Quellcode in LLVM IR, die gemeinsamen Optimierungsphasen durchlaufen ihn, und Backends für viele CPUs wie x86, Arm, RISC-V und GPUs erzeugen den Maschinencode. Ihre Stärke ist, dass für eine neue Sprache oder CPU nur eine Seite entwickelt werden muss. Es ist weder auf C noch auf eine bestimmte CPU beschränkt.
