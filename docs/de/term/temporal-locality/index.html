Was ist Zeitliche Lokalität?

Eigenschaft, dass auf einmal zugegriffene Daten oder Befehle bald wieder zugegriffen wird. Beispiel sind in Schleifen wiederholt genutzte Variablen; einer der Gründe, warum Caches wirken.

Japanische Bezeichnung: 時間的局所性

„Zeitliche Lokalität“ kommt in 2 Übungsfragen aus 2 Themen vor, z. B. Speicherhierarchie und Leistung, CPU und Architektur.

Fachgebiet: Speicherhierarchie und Leistung

Was zeitliche Lokalität bedeutet

Ein Programm zeigt zeitliche Lokalität, wenn ein Element, das es verwendet, wahrscheinlich bald wieder verwendet wird. Schleifenzähler, Akkumulatoren, häufig aufgerufene Funktionen und die Befehle eines Schleifenrumpfs sind klassische Beispiele: Einmal geladen, werden sie immer wieder angesprochen. Caches nutzen das, indem sie kürzlich verwendete Daten nahe am Prozessor halten, und Ersetzungsstrategien wie LRU (Least Recently Used) verdrängen das am längsten unbenutzte Element in der Annahme, dass kürzliche Nutzung die künftige Nutzung vorhersagt. Register nutzen sie im feinsten Maßstab, wenn der Compiler eine viel genutzte Variable ganz aus dem Speicher heraushält.

Zeitliche und räumliche Lokalität im Vergleich

Räumliche Lokalität ist die Tendenz, Adressen nahe einer gerade verwendeten Adresse zu nutzen, etwa wenn ein Array vom Anfang bis zum Ende gelesen wird. Caches nutzen sie, indem sie bei jedem Miss eine ganze Cache-Line holen, typischerweise 64 Byte. Bei der zeitlichen Lokalität geht es um die Wiederverwendung desselben Elements über die Zeit; sie wird durch die Cache-Kapazität und die Ersetzungsstrategie genutzt. Ein einzelner Durchlauf durch ein riesiges Array hat gute räumliche, aber keine zeitliche Lokalität; das wiederholte Aktualisieren einer einzigen Summenvariable hat starke zeitliche Lokalität; das einmalige Lesen zufälliger Adressen hat keine von beiden.

Wiederverwendungsdistanz und warum sie zählt

Ein nützliches Maß für zeitliche Lokalität ist die Wiederverwendungsdistanz (Reuse Distance): die Anzahl verschiedener Cache-Lines, auf die zwischen zwei Nutzungen derselben Line zugegriffen wird. In einem vollassoziativen LRU-Cache ist ein Zugriff ein Treffer, wenn seine Wiederverwendungsdistanz kleiner ist als die Anzahl der Lines, die der Cache fasst. Da L1 in wenigen Takten, L3 in einigen zehn Takten erreichbar ist und DRAM einige zehn bis etwa 100 ns, also Hunderte von Takten, benötigt, ist es für die Leistung oft wichtiger, die Wiederverwendungsdistanzen kurz zu halten, als die reine Zahl der Operationen zu verringern.

Verbesserung im Code

Programmierer und Compiler verkürzen die Wiederverwendungsdistanz, indem sie die Arbeit umordnen. Loop Blocking (Tiling) erledigt alle Arbeit an einem cachegroßen Block, bevor es weitergeht, und Loop Fusion verschmilzt zwei Schleifen, die dasselbe Array ansprechen, sodass Daten wiederverwendet werden, solange sie noch im Cache liegen. Werden viel genutzte Werte in lokalen Variablen gehalten, kann der Compiler sie in Registern halten. Umgekehrt können Daten, die einmal geschrieben und nicht bald wiederverwendet werden, mit nicht-temporalen Stores geschrieben werden, die den Cache umgehen, um keine nützlichen Lines zu verdrängen.

Antwort: B. Innerhalb einer Schleife wird dieselbe Summenvariable wiederholt aktualisiert

Zeitliche Lokalität ist die Eigenschaft, dass einmal verwendete Daten bald wieder verwendet werden; typisches Beispiel sind Variablen, die in einer Schleife wiederholt gelesen und geschrieben werden. Solche Daten werden wiederverwendet, solange sie noch im Cache oder in Registern liegen, sodass der Zugriff schnell ist. Das Lesen eines Arrays vom Anfang an ist ein Beispiel für räumliche Lokalität, bei der nahe beieinanderliegende Adressen nacheinander verwendet werden, und eine andere Eigenschaft als zeitliche Lokalität. Zufällige Einmalzugriffe weisen kaum eine der beiden Lokalitäten auf.

Häufige Fragen

Beispiel für zeitliche Lokalität

Das Aktualisieren derselben Summenvariable in jeder Iteration einer Schleife oder das wiederholte Ausführen derselben Schleifenbefehle; dasselbe Element wird kurz nach seiner letzten Nutzung wiederverwendet.

Unterschied zwischen zeitlicher und räumlicher Lokalität

Zeitliche Lokalität ist die baldige Wiederverwendung derselben Daten; räumliche Lokalität ist die Nutzung von Daten an benachbarten Adressen als Nächstes, etwa beim Durchlaufen eines Arrays.

Wie nutzen Caches die zeitliche Lokalität?

Sie halten kürzlich genutzte Daten in schnellem Speicher und verdrängen zuerst die am längsten nicht genutzten Elemente, sodass bald wiederverwendete Daten wahrscheinlich noch vorhanden sind.
