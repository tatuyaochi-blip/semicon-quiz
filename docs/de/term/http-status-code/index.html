Was ist HTTP-Statuscode?

Dreistellige Zahl in der ersten Zeile einer HTTP-Antwort, die das Ergebnis der Anfrage angibt. Die Hunderterstelle gibt die Klasse an: 1xx steht für Information, 2xx für Erfolg (200 OK, 201 Created, 204 No Content), 3xx für Umleitung (301 Moved Permanently, 302 Found, 304 Not Modified), 4xx für einen Fehler auf der Clientseite (400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found) und 5xx für einen Fehler auf der Serverseite (500 Internal Server Error, 503 Service Unavailable). 401 wird verwendet, wenn Authentifizierungsdaten fehlen oder ungültig sind, 403, wenn der Client zwar authentifiziert ist, ihm aber die Berechtigung fehlt.

Japanische Bezeichnung: HTTPステータスコード

Jetzt üben: Fragen zu HTTP-Statuscode

Welche Zuordnung eines Statuscodes zu seiner Bedeutung ist bei HTTP richtig?

  1. A301: Die angeforderte Ressource befindet sich vorübergehend unter einer anderen URL
  2. B404: Die angeforderte Ressource wurde auf dem Server nicht gefunden
  3. C503: Die Anfrage war fehlerhaft formuliert, und der Server konnte sie nicht verstehen

Antwort: B. 404: Die angeforderte Ressource wurde auf dem Server nicht gefunden

Ein Statuscode ist eine dreistellige Zahl, deren Hunderterstelle die Klasse angibt. 2xx bedeutet Erfolg (200 OK, 201 Created, 204 No Content), 3xx Umleitung (301 Moved Permanently, 302 Found, 304 Not Modified), 4xx einen Fehler auf der Clientseite (400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found) und 5xx einen Fehler auf der Serverseite (500 Internal Server Error, 503 Service Unavailable). 404 zeigt an, dass die durch die URL bezeichnete Ressource auf dem Server nicht gefunden wurde.

Auf einer Website nur für Mitglieder fordert ein angemeldetes gewöhnliches Mitglied eine Seite an, die nur Administratoren erlaubt ist. Der Server weiß, wer der Nutzer ist, erlaubt den Zugriff auf diese Seite aber nicht. Welcher Statuscode ist hier als Antwort am besten geeignet?

  1. A401 Unauthorized
  2. B403 Forbidden
  3. C404 Not Found
Antwort und Erläuterung anzeigen

Antwort: B. 403 Forbidden

403 Forbidden zeigt an, dass der Server die Anfrage verstanden hat, den Zugriff aber nicht erlaubt. 401 Unauthorized ist entgegen seinem Namen der Code für fehlende oder ungültige Authentifizierungsdaten; mit dem Header WWW-Authenticate wird mitgeteilt, wie man sich authentifiziert. Hier ist bekannt, wer der Nutzer ist, und es fehlt die Berechtigung (Autorisierung), daher trifft 403 zu. Manche Systeme geben bewusst 404 zurück, damit nicht einmal bekannt wird, dass es eine Administrationsseite gibt; der Code, der die Situation zutreffend beschreibt, ist aber 403.
