Was ist Booth-Algorithmus?

Ein Multiplikationsverfahren, das die Bits des Multiplikators, etwa paarweise, in vorzeichenbehaftete Ziffern umkodiert, um die Zahl der Teilprodukte zu verringern. Die Radix-4-Booth-Kodierung halbiert sie etwa.

Japanische Bezeichnung: ブースのアルゴリズム

Fachgebiet: Computerarithmetik
