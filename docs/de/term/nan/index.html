Was ist NaN?

Kurz für Not a Number, ein Gleitkomma-Sonderwert für Operationen ohne numerisches Ergebnis, etwa 0 ÷ 0 oder die Wurzel aus einer negativen Zahl. Er hat einen Exponenten aus lauter Einsen und eine Mantisse ungleich null und ist nicht einmal mit sich selbst gleich.

Japanische Bezeichnung: NaN

Fachgebiet: Computerarithmetik

Verwandte Begriffe

Absorption (Gleitkomma) Arithmetische Verschiebung Auslöschung (Catastrophic Cancellation) bfloat16 Booth-Algorithmus Carry-Lookahead-Addierer Carry-Save-Addierer Denormalisierte Zahl (Subnormal) Exponentenfeld Festkommadarstellung (Fixed Point)
