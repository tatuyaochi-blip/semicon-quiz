Was ist NaN?

Abkürzung für Not a Number; spezieller Gleitkommawert für Operationen ohne definiertes Zahlenergebnis, etwa 0 ÷ 0 oder die Wurzel aus einer negativen Zahl. Dargestellt mit Exponent aus lauter Einsen und Mantisse ungleich 0; NaN ist auch mit sich selbst nicht gleich.

Japanische Bezeichnung: NaN

Fachgebiet: Computerarithmetik

Wie NaN codiert wird

In den binären Formaten von IEEE 754 ist ein Exponentenfeld aus lauter Einsen für Sonderwerte reserviert: Eine Mantisse von null bedeutet Unendlich, jede von null verschiedene Mantisse bedeutet NaN. Das Vorzeichenbit hat bei NaN keine Bedeutung. Es gibt zwei Arten. Ein Quiet NaN läuft stillschweigend durch Rechenoperationen, während ein Signaling NaN bei Verwendung die Invalid-Operation-Ausnahme auslöst. In der von der Revision 2008 empfohlenen und von gängigen Prozessoren verwendeten Codierung kennzeichnet eine 1 im höchstwertigen Mantissenbit ein Quiet NaN, und die übrigen Bits bilden eine Nutzlast (Payload), die Diagnoseinformationen tragen kann.

Operationen, die NaN erzeugen

NaN ist das Standardergebnis einer ungültigen Operation, also einer ohne sinnvolles numerisches Ergebnis: 0 ÷ 0, ∞ − ∞, 0 × ∞, ∞ ÷ ∞, die Quadratwurzel einer negativen Zahl und ähnliche Fälle. Diese setzen außerdem das Statusflag für ungültige Operationen. Die Division einer von null verschiedenen Zahl durch null ist etwas anderes: Sie liefert ein vorzeichenbehaftetes Unendlich und setzt das Division-durch-null-Flag. Einmal entstanden, pflanzt sich ein NaN fort, sodass fast jede Rechnung mit ihm NaN ergibt; dadurch kann eine Berechnung zu Ende laufen und das Problem am Ende erkannt werden.

Vergleiche und ihre Tücken

NaN ist gegenüber jedem Wert ungeordnet, sich selbst eingeschlossen. Jeder Ordnungsvergleich wie <, <= oder == mit einem NaN-Operanden ist falsch, und != ist wahr, weshalb x != x ein klassischer NaN-Test ist. Deshalb kann ein einziges NaN Sortierroutinen oder Suchen, die eine konsistente Ordnung voraussetzen, aus dem Tritt bringen. Bibliotheksfunktionen wie isnan sind der sicherere Test, da aggressive Compiler-Optimierungsoptionen annehmen können, dass NaNs nie auftreten, und Prüfungen der Form x != x entfernen. Auch Minimum- und Maximumfunktionen unterscheiden sich darin, ob sie das NaN oder den anderen Operanden zurückgeben.

Wo man ihm begegnet

Beim maschinellen Lernen mit 16-Bit-Gleitkommazahlen, deren größter endlicher Wert 65504 ist, erzeugt ein Überlauf zunächst Unendlich, und eine spätere Operation wie ∞ − ∞ oder 0 × ∞ macht daraus ein NaN, das sich über Loss und Gewichte ausbreitet; Loss Scaling und Überlaufprüfungen schützen davor. In numerischem Code hält das Aktivieren von Traps für die Invalid-Operation-Ausnahme die Ausführung beim ersten NaN an, um die Ursache zu finden. Ganzzahlen haben überhaupt kein NaN: Eine ganzzahlige Division durch null wird typischerweise abgefangen oder ist undefiniert, statt einen Sonderwert zu liefern.

Antwort: B. Falsch

In IEEE 754 ist NaN ein „Nicht-eine-Zahl“-Wert, der mit keinem Wert gleich ist, auch nicht mit sich selbst; daher ist x == x falsch (und x != x wahr). Diese Eigenschaft wird mit x != x auch zur NaN-Prüfung genutzt, üblicherweise verwendet man aber eigene Funktionen (isnan o. Ä.). NaN entsteht z. B. aus 0 ÷ 0 oder ∞ − ∞ und setzt sich in nachfolgenden Berechnungen fort. Eine Ausnahme mit Abbruch beim Vergleich ist nicht das Standardverhalten.

Häufige Fragen

Warum ist NaN nicht gleich sich selbst?

IEEE 754 definiert NaN als ungeordnet, das heißt, es steht für keine bestimmte Zahl, daher ist jeder Gleichheits- und Ordnungsvergleich damit falsch. Folglich ist x == x falsch und x != x wahr, wenn x NaN ist.

Unterschied zwischen NaN und Unendlich?

Unendlich ist ein legitimes Ergebnis eines Überlaufs oder der Division einer von null verschiedenen Zahl durch null und hat weiterhin ein Vorzeichen und eine Ordnung. NaN entsteht bei Operationen ohne definierten Wert, etwa 0 ÷ 0, und lässt sich nicht ordnen.

Unterschied zwischen Quiet NaN und Signaling NaN?

Ein Quiet NaN pflanzt sich durch Berechnungen fort, ohne eine Ausnahme auszulösen. Ein Signaling NaN löst bei Verwendung die Invalid-Operation-Ausnahme aus, was nützlich ist, um nicht initialisierte Daten aufzuspüren.
