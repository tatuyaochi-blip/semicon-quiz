Was ist Message Authentication Code (Nachrichtenauthentifizierungscode)?

Kurzer Wert (MAC), der aus einer Nachricht und einem von Sender und Empfänger geteilten symmetrischen Schlüssel berechnet wird. Indem der Empfänger ihn mit demselben Schlüssel neu berechnet und vergleicht, kann er bestätigen, dass die Nachricht von jemandem stammt, der den Schlüssel kennt, und nicht verändert wurde. Da auch der Empfänger denselben Wert erzeugen kann, bietet er keine Nichtabstreitbarkeit. Ein typisches Beispiel ist HMAC.

Antwort: B. Ein MAC wird mit einem symmetrischen Schlüssel erstellt, den Sender und Empfänger teilen; er erkennt Manipulationen, kann aber keine Nichtabstreitbarkeit bieten, also Dritten nicht beweisen, dass der Sender die Nachricht erstellt hat, weil auch der Empfänger denselben MAC erzeugen kann

Ein Message Authentication Code (MAC) ist ein kurzer Wert, der aus einer Nachricht und einem symmetrischen Schlüssel berechnet wird; verbreitet ist HMAC, das eine Hashfunktion verwendet. Der Empfänger berechnet ihn mit demselben Schlüssel neu und vergleicht; stimmen die Werte überein, stammt die Nachricht von jemandem, der den Schlüssel kennt, und wurde unterwegs nicht verändert. Ein Angreifer ohne Kenntnis des Schlüssels kann für eine veränderte Nachricht keinen korrekten MAC erzeugen. Der Empfänger besitzt jedoch denselben Schlüssel und kann ebenfalls MACs erzeugen. Er kann Dritten daher nicht beweisen, dass der Sender die Nachricht erstellt hat; ein MAC bietet also keine Nichtabstreitbarkeit. Eine digitale Signatur lässt sich nur mit dem privaten Schlüssel des Senders erstellen und von jedem mit dem öffentlichen Schlüssel prüfen, sie kann also Nichtabstreitbarkeit bieten. MACs sind dagegen leicht zu berechnen und werden verbreitet für Prüfungen zwischen den beiden Beteiligten eingesetzt, etwa um Manipulationen an jedem einzelnen Paket einer Verbindung zu erkennen. Einen einfachen Hashwert ohne Schlüssel kann ein Angreifer zusammen mit der veränderten Nachricht neu berechnen, er eignet sich daher nicht zur Erkennung absichtlicher Manipulationen.
