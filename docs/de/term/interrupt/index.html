Was ist Interrupt (Unterbrechung)?

CPU-Mechanismus, der die laufende Aufgabe kurz anhält, um eine Anforderung, etwa von einem externen Gerät, zu bearbeiten, und danach zur ursprünglichen Aufgabe zurückkehrt.

Japanische Bezeichnung: 割り込み
