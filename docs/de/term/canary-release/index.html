Was ist Canary-Release?

Release-Verfahren, das eine neue Version zunächst nur einem Teil der Nutzer oder Anfragen (zum Beispiel 5 %) zugänglich macht und den Anteil schrittweise erhöht, wenn kein Problem auftritt, während Kennzahlen wie Fehlerrate und Antwortzeit beobachtet werden. Bei einem Fehler ist nur ein Teil der Anfragen betroffen, und die alte Version lässt sich schnell wiederherstellen. Der Name geht auf Kanarienvögel zurück, die in Kohlebergwerke mitgenommen wurden, um früh vor giftigen Gasen zu warnen. Der Vergleich von alter und neuer Version erfordert genügend Anfragen, und die Überwachung der Kennzahlen wird oft mit einem automatischen Rollback kombiniert.

Japanische Bezeichnung: カナリアリリース

Jetzt üben: Fragen zu Canary-Release

Ein Dienst, der 12.000 Anfragen pro Stunde erhält, führt ein Canary-Release einer neuen Version durch und leitet nur 5 % der Anfragen an sie. Die neue Version hat einen Fehler, durch den 3 % der erhaltenen Anfragen fehlschlagen; er wird nach einer Stunde bemerkt, und alle Anfragen werden auf die alte Version zurückgeleitet. Wie viele Anfragen sind in dieser Stunde wegen des Fehlers fehlgeschlagen?

  1. A18
  2. B360
  3. C600
Antwort und Erläuterung anzeigen

Antwort: A. 18

Die neue Version erhielt 12.000 × 5 % = 600 Anfragen, von denen 3 % fehlschlugen, also 600 × 3 % = 18 Anfragen. Wären alle Anfragen auf einen Schlag auf die neue Version umgeschaltet worden, wären 12.000 × 3 % = 360 fehlgeschlagen. Ein Canary-Release begrenzt die von einem Fehler betroffenen Anfragen auf diese Weise auf einen kleinen Anteil und erhöht den Anteil, wenn kein Problem auftritt, während Kennzahlen wie Fehlerrate und Antwortzeit beobachtet werden. Für den Vergleich der Kennzahlen von neuer und alter Version sind genügend Anfragen nötig, daher werden Anteil und Beobachtungsdauer gemeinsam festgelegt.

  2. Es werden zwei Umgebungen mit derselben Konfiguration wie die Produktion bereitgestellt; in der einen läuft weiter die aktuelle Version, in der anderen wird die neue Version installiert und geprüft, und dann wird der Load Balancer auf einen Schlag auf sie umgeschaltet.
