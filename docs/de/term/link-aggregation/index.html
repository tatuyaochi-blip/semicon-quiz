Was ist Link Aggregation?

Technik (IEEE 802.1AX), die mehrere physische Verbindungen bündelt, sodass sie als eine logische Verbindung behandelt werden. Sie erhöht die Bandbreite, und fällt eine Verbindung aus, tragen die übrigen den Verkehr weiter. Frames werden je Flow (etwa je Kombination aus Quelle und Ziel) einer Verbindung zugeordnet, sodass ein einzelner Flow auf die Geschwindigkeit einer Verbindung begrenzt ist. LACP ist das Protokoll, das die Bündelungseinstellungen an beiden Enden automatisch abgleicht.

Japanische Bezeichnung: リンクアグリゲーション

Antwort: A. 1 Gbit/s

Bei Link Aggregation werden die Frames desselben Flows üblicherweise über ein und dieselbe Verbindung gesendet. Würden die Frames eines Flows auf mehrere Verbindungen aufgeteilt, könnte sich ihre Reihenfolge ändern und die Leistung von TCP sinken. Eine einzelne TCP-Verbindung erreicht daher höchstens die 1 Gbit/s einer Verbindung. Bei vielen Flows verteilen sich diese auf die vier Verbindungen, sodass insgesamt bis zu 4 Gbit/s nutzbar sind. Fällt eine Verbindung aus, läuft der Verkehr über die übrigen weiter, und STP sieht das Bündel als eine einzige Verbindung, sodass keine der gebündelten Verbindungen blockiert wird.
