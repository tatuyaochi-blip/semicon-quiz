Was ist CDN (Content Delivery Network)?

System, das Kopien von Inhalten wie Bildern, Videos und Skripten auf Cache-Servern (Edge-Servern) an vielen Standorten vorhält und sie von einem Server nahe beim Nutzer ausliefert. Die kürzere RTT beschleunigt das Laden von Seiten, die Last auf dem ursprünglichen Server (Origin) sinkt, und die Verteilung des Verkehrs auf viele Server hilft auch, DDoS-Angriffe abzufangen. Nutzer werden per DNS oder Anycast zu einem nahen Server geleitet.

Japanische Bezeichnung: CDN(コンテンツデリバリネットワーク)

Welche Beschreibung trifft auf ein CDN (Content Delivery Network) zu?

  1. AEin Mechanismus, der alle Nutzeranfragen auf einen einzigen Server bündelt, um die ausgelieferten Inhalte konsistent zu halten
  2. BEin Mechanismus, der die Kommunikation verschlüsselt, um eine virtuelle Standleitung zwischen entfernten Standorten zu schaffen
  3. CEin Mechanismus, der Kopien (Caches) von Inhalten auf vielen Servern in der Nähe der Nutzer ablegt und die Nutzer zur Auslieferung an einen nahen Server leitet
Antwort und Erläuterung anzeigen

Antwort: C. Ein Mechanismus, der Kopien (Caches) von Inhalten auf vielen Servern in der Nähe der Nutzer ablegt und die Nutzer zur Auslieferung an einen nahen Server leitet

Ein CDN hält Kopien von Inhalten wie Bildern, Videos und Software-Updates auf Auslieferungsservern an vielen Standorten vor und leitet die Nutzer zur Auslieferung an einen nahen Server. Weil der Weg zu den Nutzern kürzer ist, sind die Antworten schneller, und Last und Datenverkehr auf dem ursprünglichen Server (Origin-Server) sinken. Bei vorübergehend gehäuften Zugriffen lässt sich die Last außerdem auf die Server an vielen Standorten verteilen. Kommunikation zu verschlüsseln, um eine virtuelle Standleitung zwischen Standorten zu schaffen, ist ein VPN.

Ein CDN erhält 2000 Anfragen pro Sekunde, und seine Cache-Trefferquote steigt von 90 % auf 98 %. Bei einem Treffer beträgt die Antwortzeit 20 ms, ohne Treffer 200 ms, weil der Inhalt vom Origin-Server geholt und dann zurückgegeben wird; nur Anfragen ohne Treffer erreichen den Origin-Server. Welche Kombination aus der Zahl der Anfragen, die den Origin-Server erreichen, und der mittleren Antwortzeit gilt nach dem Anstieg auf 98 %?

  1. A40 pro Sekunde, etwa 24 ms
  2. B40 pro Sekunde, etwa 110 ms
  3. C160 pro Sekunde, etwa 24 ms
Antwort und Erläuterung anzeigen

Antwort: A. 40 pro Sekunde, etwa 24 ms

Die Anfragen ohne Treffer machen 100 − 98 = 2 % aller Anfragen aus, also erreichen 2000 × 0,02 = 40 pro Sekunde den Origin-Server. Bei 90 % waren es 200 pro Sekunde; ein Anstieg der Trefferquote um nur 8 Prozentpunkte senkt die Last des Origin-Servers also auf ein Fünftel. Die mittlere Antwortzeit beträgt 0,98 × 20 + 0,02 × 200 = 19,6 + 4 = 23,6 ms, also etwa 24 ms. Auch im Vergleich zu 0,9 × 20 + 0,1 × 200 = 38 ms bei 90 % ist das deutlich kürzer.
