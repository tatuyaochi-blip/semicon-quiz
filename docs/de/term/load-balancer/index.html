Was ist Load Balancer (Lastverteiler)?

Ein Gerät oder eine Software, die Anfragen von Nutzern auf mehrere Server verteilt, um die Last zu verteilen. Er prüft regelmäßig den Zustand jedes Servers (Health Checks) und nimmt ausgefallene Server aus der Verteilung, erfüllt also auch eine Redundanzfunktion. Wird der Load Balancer nicht selbst redundant ausgelegt, wird er zum Single Point of Failure.

Japanische Bezeichnung: ロードバランサ

Jetzt üben: Fragen zu Load Balancer (Lastverteiler)

Hinter einem Load Balancer stehen drei Anwendungsserver, auf die die Anfragen der Reihe nach verteilt werden (Round Robin). Die Sitzungsinformationen eines angemeldeten Nutzers werden nur im Arbeitsspeicher des Servers abgelegt, der die Anmeldung bearbeitet hat. Welche Kombination aus wahrscheinlichem Problem und Gegenmaßnahme ist angemessen?

  1. AWird eine Anfrage an einen anderen Server verteilt, wird die Sitzung nicht gefunden, und der Nutzer scheint abgemeldet zu sein. Die Sitzungen werden an einem gemeinsamen Ort abgelegt, den alle Server nutzen können
  2. BDie drei Server geben unabhängig voneinander dieselbe Sitzungs-ID aus, und die IDs kollidieren. Sitzungs-IDs werden zu kurzen fortlaufenden Nummern, damit sich Nutzer ihre ID leicht merken können
  3. CDer Load Balancer kann keine Cookies lesen, sodass HTTPS nicht mehr funktioniert. Die Kommunikation zwischen Load Balancer und Servern wird nicht mehr verschlüsselt

Antwort: A. Wird eine Anfrage an einen anderen Server verteilt, wird die Sitzung nicht gefunden, und der Nutzer scheint abgemeldet zu sein. Die Sitzungen werden an einem gemeinsamen Ort abgelegt, den alle Server nutzen können

Liegen die Sitzungsinformationen nur im Arbeitsspeicher eines Servers, kann ein anderer Server, an den die nächste Anfrage verteilt wird, den Nutzer nicht erkennen. Eine Gegenmaßnahme ist, die Sitzungen an einem gemeinsamen Speicherort abzulegen, den jeder Server lesen und beschreiben kann (einem In-Memory-Datenspeicher oder einer Datenbank). Eine andere ist die Sitzungspersistenz (Sticky Sessions), bei der die Anfragen desselben Nutzers immer an denselben Server verteilt werden; fällt dieser Server jedoch aus, gehen die Sitzungen verloren, und die Last verteilt sich leicht ungleichmäßig. Halten die Server keinen Zustand, lassen sich leicht Server hinzufügen oder entfernen.

Ein System hat zwei redundante Load Balancer (Lastverteiler), dahinter drei Webserver und einen einzigen Datenbankserver, den alle Webserver nutzen. Welches der genannten Geräte ist ein Single Point of Failure (eine Stelle, deren Ausfall das gesamte System stoppt)?

  1. ADie Load Balancer
  2. BDie Webserver
  3. CDer Datenbankserver
Antwort und Erläuterung anzeigen

Antwort: C. Der Datenbankserver

Ein Single Point of Failure (SPOF) ist eine Stelle, deren Ausfall allein das gesamte System stoppt. Die Load Balancer sind mit zwei Geräten redundant ausgelegt, und es gibt drei Webserver, von denen die Load Balancer einen ausgefallenen Server aus der Verteilung nehmen können; die Verarbeitung läuft also weiter, wenn eines dieser Geräte ausfällt. Es gibt nur einen Datenbankserver, und alle Webserver nutzen ihn; fällt er aus, steht das gesamte System. Wird auch der Datenbankserver redundant ausgelegt, etwa als Cluster, entfällt dieser Single Point of Failure.
