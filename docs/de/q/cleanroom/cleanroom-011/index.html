Antwort: C. Luftdusche

Die Luftdusche ist eine kleine Kabine, die Mitarbeitende beim Betreten des Reinraums durchlaufen; aus Düsen an allen Seiten wird saubere Luft mit mehr als 20 m/s auf den Reinraumanzug geblasen, um anhaftenden Staub zu entfernen. Die Türen auf beiden Seiten lassen sich nicht gleichzeitig öffnen, sodass auch das Eindringen von Außenluft verhindert wird. Eine kleine kastenförmige Einrichtung für die Übergabe von Gegenständen ist die Pass-Box; die Abzugskammer ist ein Arbeitsplatz zur Absaugung von Chemikaliendämpfen.
