Grundlagen der Informationssicherheit

Welches der folgenden Authentifizierungsverfahren ist eine Multi-Faktor-Authentifizierung?

  1. ANach dem Passwort ein Einmalpasswort eingeben, das in einer App auf dem eigenen Smartphone angezeigt wird
  2. BNach dem Passwort zusätzlich die Antwort auf eine Sicherheitsfrage eingeben
  3. CEin doppelt so langes, komplexeres Passwort eingeben
Antwort und Erläuterung anzeigen

Antwort: A. Nach dem Passwort ein Einmalpasswort eingeben, das in einer App auf dem eigenen Smartphone angezeigt wird

Eine Multi-Faktor-Authentifizierung kombiniert zwei oder mehr verschiedene Faktoren aus Wissen, Besitz und Inhärenz. Ein Passwort (Wissen) kombiniert mit einem auf dem eigenen Smartphone erzeugten Einmalpasswort (Besitz) verwendet zwei verschiedene Faktoren und ist daher eine Multi-Faktor-Authentifizierung. Selbst wenn das Passwort abfließt, kann sich ein Angreifer ohne das Smartphone der Person nicht anmelden. Passwort und Sicherheitsfrage sind beide Faktoren der Art Wissen; obwohl in zwei Schritten geprüft wird, ist das keine Multi-Faktor-Authentifizierung (es wird manchmal zweistufige Verifizierung genannt). Gleichartige Faktoren übereinanderzulegen bedeutet, dass sie mit derselben Methode zusammen gestohlen werden können, etwa indem Nutzer per Phishing getäuscht werden. Auch Einmalpasswörter können durch Angriffe missbraucht werden, bei denen Nutzer sie in Echtzeit auf einer gefälschten Website eingeben; daher verbreiten sich Mitte der 2020er-Jahre Verfahren, bei denen die Authentifizierung auf einer gefälschten Website nicht funktioniert (etwa Passkeys nach FIDO2).
