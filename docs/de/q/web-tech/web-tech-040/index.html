Grundlagen der Webtechnologien

Welches Verfahren zum Erzeugen der Seiten einer Website erzeugt die HTML-Dateien aller Seiten bereits beim Build und gibt auf Anfragen diese Dateien unverändert zurück?

  1. ACSR (clientseitiges Rendering)
  2. BSSR (serverseitiges Rendering)
  3. CSSG (statische Seitengenerierung)
Antwort und Erläuterung anzeigen

Antwort: C. SSG (statische Seitengenerierung)

Eine mit SSG erstellte Website ist eine statische Website, bei der für Anfragen kein Programm auf dem Server läuft; sie lässt sich daher schnell und unverändert von Hosting-Diensten für statische Dateien oder einem CDN ausliefern und bietet auch weniger Angriffsfläche. Ein Beispiel ist eine Website, die ihre Fragen- und Glossarseiten beim Build aus den Inhaltsdaten erzeugt und ausliefert; ändert sich der Inhalt, werden die Seiten neu erzeugt. SSR ist ein dynamisches Verfahren, bei dem der Server für jede Anfrage HTML erzeugt, und CSR sendet minimales HTML und JavaScript und baut die Seite im Browser zusammen.
