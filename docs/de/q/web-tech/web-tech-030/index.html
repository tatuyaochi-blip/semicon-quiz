Grundlagen der Webtechnologien

Die Antwort für eine „Meine Seite“, deren Inhalt für jeden Nutzer anders ist, erhält Cache-Control: private, max-age=60. Welche Aussage über die Wirkung dieser Angabe ist richtig?

  1. ANur gemeinsam genutzte Caches wie ein CDN verwenden sie 60 Sekunden lang wieder, und der Browser-Cache des Nutzers speichert sie nicht
  2. BDer Browser-Cache darf sie 60 Sekunden lang unverändert wiederverwenden, gemeinsam genutzte Caches wie ein CDN oder ein Proxy speichern sie aber nicht
  3. CSie wird in keinem Cache gespeichert, sodass auch der Browser sie jedes Mal neu vom Server abruft
Antwort und Erläuterung anzeigen

Antwort: B. Der Browser-Cache darf sie 60 Sekunden lang unverändert wiederverwenden, gemeinsam genutzte Caches wie ein CDN oder ein Proxy speichern sie aber nicht

Ein Browser-Cache wird nur von einem einzigen Nutzer verwendet, die Caches eines CDN oder eines Proxys dagegen werden von vielen Nutzern gemeinsam genutzt. private gibt an, dass die Antwort nicht in gemeinsam genutzten Caches gespeichert werden darf, und max-age=60, dass sie nach dem Speichern 60 Sekunden lang ohne Rückfrage beim Server verwendet werden darf. Würden nutzerspezifische Seiten in einem CDN gespeichert, könnte das zu Pannen führen, bei denen anderen Nutzern die Informationen einer fremden Person angezeigt werden. Soll eine Antwort nirgends gespeichert werden, verwendet man no-store; darf sie gespeichert werden, muss aber vor jeder Verwendung beim Server geprüft werden, verwendet man no-cache.

Weitere Fragen zu Grundlagen der Webtechnologien

  1. Ein Webserver komprimiert Antworten vor dem Senden mit gzip oder Brotli. Bei welchem Inhalt verringert die Komprimierung die übertragene Datenmenge im Allgemeinen am wenigsten?
  2. 1,5 MB Textdaten werden mit gzip auf ein Drittel der Größe komprimiert und gesendet. Die Bandbreite beträgt 10 Mbit/s und die RTT 100 ms; bevor das Senden der Daten beginnt, brauchen TCP-Verbindungsaufbau, TLS-Handshake und HTTP-Anfrage zusammen drei Umläufe. Es gilt 1 MB = 10^6 Byte; die Zeit für Komprimierung und Dekomprimierung, Header sowie Wartezeiten durch die Überlastkontrolle von TCP werden vernachlässigt. Welcher Wert liegt der Zeit bis zum vollständigen Empfang der Daten am nächsten?
  3. Ein CDN erhält 2000 Anfragen pro Sekunde, und seine Cache-Trefferquote steigt von 90 % auf 98 %. Bei einem Treffer beträgt die Antwortzeit 20 ms, ohne Treffer 200 ms, weil der Inhalt vom Origin-Server geholt und dann zurückgegeben wird; nur Anfragen ohne Treffer erreichen den Origin-Server. Welche Kombination aus der Zahl der Anfragen, die den Origin-Server erreichen, und der mittleren Antwortzeit gilt nach dem Anstieg auf 98 %?
  4. Was gibt bei den Core Web Vitals, den Kennzahlen für das Nutzungserlebnis einer Webseite, der Wert CLS (Cumulative Layout Shift) an?
  5. Welche Zuordnung eines Bildformats für Webseiten zu seiner typischen Verwendung ist angemessen?
