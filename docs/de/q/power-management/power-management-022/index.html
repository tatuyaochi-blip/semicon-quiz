Energieverwaltung (softwaregesteuert)

Wofür werden Funktionen wie Intels RAPL, mit denen sich die Leistung von CPU und Speicher per Software messen und begrenzen lässt, am besten verwendet?

  1. AZum Auffinden von Fertigungsfehlern bei CPUs
  2. BZur Verwaltung der Leistung einzelner Server durch Begrenzung, damit in Rechenzentren die Leistungsobergrenze von Racks oder Gebäuden nicht überschritten wird
  3. CZum Auffinden von Grammatikfehlern in Programmen
Antwort und Erläuterung anzeigen

Antwort: B. Zur Verwaltung der Leistung einzelner Server durch Begrenzung, damit in Rechenzentren die Leistungsobergrenze von Racks oder Gebäuden nicht überschritten wird

In Rechenzentren ist die nutzbare Leistung durch die Stromversorgungsanlagen und die Kühlleistung nach oben begrenzt. Kann die Leistung von CPU und Speicher per Software gemessen und eine Obergrenze gesetzt werden, lassen sich unter Einhaltung der Obergrenze viele Server aufstellen, ohne die Anlagen auf den ungünstigsten Fall auszulegen, in dem alle Server maximale Leistung verbrauchen. Auch lässt sich messen, wie viel Energie ein Programm verbraucht hat, und für Energiesparmaßnahmen nutzen.
