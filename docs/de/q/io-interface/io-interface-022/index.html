Schnittstellen und Busstandards

Welche Aussage zur Kommunikation bei USB ist richtig (für herkömmliches USB ohne USB4)?

  1. ADer Host legt den Kommunikationsplan fest und fragt die Geräte ab; die Geräte senden Daten auf Anweisung des Hosts
  2. BAlle Geräte sind gleichberechtigt und können jederzeit von sich aus Daten senden
  3. CGrundsätzlich kommunizieren Geräte direkt miteinander, ohne den Host zu durchlaufen
Antwort und Erläuterung anzeigen

Antwort: A. Der Host legt den Kommunikationsplan fest und fragt die Geräte ab; die Geräte senden Daten auf Anweisung des Hosts

Bei USB verwaltet der Host, z. B. ein PC, die angeschlossenen Geräte und legt fest, wann mit welchem Gerät kommuniziert wird. Auch Geräte wie eine Maus geben ihre Eingabedaten zurück, wenn der Host sie regelmäßig abfragt. Vorteil ist, dass die Geräteseite einfach gehalten werden kann und viele Geräte günstig hergestellt werden können. Beim Anschließen meldet ein Gerät dem Host seinen Typ, und der Host lädt den passenden Treiber.
