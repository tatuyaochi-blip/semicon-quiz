Schnittstellen und Busstandards

Welchen Vorteil bietet der Burst-Transfer von AXI?

  1. ADie Daten werden komprimiert gesendet, sodass die Sendemenge sinkt
  2. BDie Adresse wird bei jedem Transfer neu geprüft, sodass es keine Fehler mehr gibt
  3. CMit einer Adresse lassen sich mehrere Daten aufeinanderfolgender Adressen senden, sodass der Aufwand für das Senden von Adressen sinkt und die Bandbreite sinnvoll genutzt wird
Antwort und Erläuterung anzeigen

Antwort: C. Mit einer Adresse lassen sich mehrere Daten aufeinanderfolgender Adressen senden, sodass der Aufwand für das Senden von Adressen sinkt und die Bandbreite sinnvoll genutzt wird

Da häufig Daten aufeinanderfolgender Adressen gebündelt behandelt werden, etwa beim Laden einer Cache-Zeile, sendet AXI nur Startadresse und Länge und kann die Daten im Burst-Transfer aufeinanderfolgend übergeben. Da nicht für jedes Datum eine Adresse gesendet werden muss, bleibt der Adresskanal frei, und der Datenkanal kann ohne Pause genutzt werden. Da auch DRAM im Burst gut liest und schreibt, ist es ein gut passendes Verfahren.
