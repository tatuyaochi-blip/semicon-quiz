Schnittstellen und Busstandards

Welche Aussage zum „Lane“ bei PCI Express ist richtig?

  1. AEine Verbindungseinheit mit je einem differenziellen Paar zum Senden und zum Empfangen, wobei durch Bündeln von Lanes die Bandbreite erhöht werden kann
  2. BEine Einheit, bei der über eine einzige Leitung abwechselnd gesendet und empfangen wird
  3. CDie physische Länge des Steckplatzes, in den PCI-Express-Geräte gesteckt werden
Antwort und Erläuterung anzeigen

Antwort: A. Eine Verbindungseinheit mit je einem differenziellen Paar zum Senden und zum Empfangen, wobei durch Bündeln von Lanes die Bandbreite erhöht werden kann

Ein Lane von PCI Express besteht aus einem differenziellen Paar zum Senden und einem zum Empfangen, insgesamt vier Leitungen, und kann Daten in beide Richtungen gleichzeitig senden. Werden Lanes wie x4 oder x16 gebündelt, werden die Daten auf die Lanes verteilt, sodass die Bandbreite proportional zur Lane-Zahl steigt. Grafikkarten verwenden häufig x16, SSDs x4 und Netzwerkkarten x1 bis x8.
