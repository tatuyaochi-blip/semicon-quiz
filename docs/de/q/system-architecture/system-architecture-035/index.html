Systemarchitektur und Zuverlässigkeit

Welche der Arten, Speicher anzubinden, beschreibt ein SAN (Storage Area Network)?

  1. AEin Speichergerät mit Fileserver-Funktionen wird an das LAN angeschlossen, und mehrere Clients nutzen es gemeinsam auf Dateiebene
  2. BServer und Speicher sind über ein eigenes Netzwerk verbunden, und ein Server nutzt den Speicher auf Blockebene, als wäre er eine an ihn selbst angeschlossene Festplatte
  3. CFestplatten im Server oder direkt per Kabel an einen Server angeschlossene Festplatten werden nur von diesem Server genutzt
Antwort und Erläuterung anzeigen

Antwort: B. Server und Speicher sind über ein eigenes Netzwerk verbunden, und ein Server nutzt den Speicher auf Blockebene, als wäre er eine an ihn selbst angeschlossene Festplatte

Ein SAN verbindet Server und Speicher über ein eigenes Netzwerk (etwa Fibre Channel oder iSCSI, das ein IP-Netzwerk nutzt), und ein Server nutzt Bereiche des Speichers auf Blockebene wie eigene Festplatten. Es wird häufig für Datenbanken und Virtualisierungsplattformen eingesetzt, die Leistung erfordern. Ein an das LAN angeschlossenes Speichergerät auf Dateiebene gemeinsam zu nutzen, ist NAS, und Speicher direkt an einen Server anzuschließen, ist DAS (Direct Attached Storage).

Weitere Fragen zu Systemarchitektur und Zuverlässigkeit

  1. Aus einem Speicherpool mit 100 TB physischer Kapazität wurden per Thin Provisioning 30 Volumes mit je 5 TB logischer Kapazität angelegt. Derzeit sind im Durchschnitt 40 % der logischen Kapazität jedes Volumes beschrieben, und die Daten wachsen pro Woche um insgesamt 2 TB. Wann erreicht die Auslastung des Pools 80 %, wenn Löschen und Komprimieren von Daten nicht berücksichtigt werden?
  2. In einem Rechenzentrum verbrauchen die IT-Geräte 800 kW und die Kühlanlagen 280 kW, und Verluste der Stromversorgung, Beleuchtung usw. betragen 120 kW. Wie hoch ist die PUE, wenn das Kühlverfahren so verbessert wird, dass sich nur der Stromverbrauch der Kühlanlagen halbiert?
  3. Aus welchem Grund werden in einem Rechenzentrum eine USV (unterbrechungsfreie Stromversorgung) und eigene Notstromaggregate kombiniert?
  4. Welche Beschreibung trifft auf das Konzept von Warm- und Kaltgängen (Hot Aisle/Cold Aisle) bei der Anordnung von Serverracks in einem Rechenzentrum zu?
  5. Ein Websystem, das zur Spitzenzeit 1800 Anfragen pro Sekunde verarbeiten muss, wird entworfen. Ein Server kann höchstens 250 Anfragen pro Sekunde verarbeiten, und die Auslastung jedes Servers soll höchstens 70 % betragen. Außerdem sollen die übrigen Server diese Bedingung auch dann erfüllen, wenn ein Server ausfällt (N+1-Konfiguration). Wie viele Server werden bei gleichmäßig verteilter Last mindestens benötigt?
