Systemarchitektur und Zuverlässigkeit

Welches Merkmal trifft im Vergleich zur zentralen Verarbeitung auf die verteilte Verarbeitung zu?

  1. ABetriebsführung und Sicherheitsmanagement lassen sich insgesamt an einer Stelle erledigen, was die Verwaltung vereinfacht
  2. BKommunikation zwischen Computern wird überflüssig, daher ist das System nicht von Netzwerkstörungen betroffen
  3. CDie Verarbeitung wird auf mehrere Computer aufgeteilt; die Auswirkungen eines Ausfalls lassen sich daher leichter begrenzen, und die Kapazität lässt sich durch zusätzliche Computer leichter erhöhen, aber Betriebsführung und Datenkonsistenz werden aufwendiger
Antwort und Erläuterung anzeigen

Antwort: C. Die Verarbeitung wird auf mehrere Computer aufgeteilt; die Auswirkungen eines Ausfalls lassen sich daher leichter begrenzen, und die Kapazität lässt sich durch zusätzliche Computer leichter erhöhen, aber Betriebsführung und Datenkonsistenz werden aufwendiger

Die verteilte Verarbeitung teilt die Arbeit auf mehrere Computer auf. Sie hat den Vorteil, dass sich die Auswirkungen eines Computerausfalls leichter auf einen Teil begrenzen lassen und dass sich bei wachsender Last leicht Computer hinzufügen lassen. Andererseits wird Kommunikation zwischen den Computern nötig, und die Verwaltung der Geräte, die Umsetzung von Sicherheitsmaßnahmen und die Wahrung der Datenkonsistenz werden aufwendiger. Eine einfache Verwaltung an einer Stelle ist ein Vorteil der zentralen Verarbeitung, bei der ein einzelner Computer die Arbeit erledigt.
