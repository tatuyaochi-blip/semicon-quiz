Siliziumphotonik

Wie wandelt ein Mach-Zehnder-Modulator eine Änderung der Lichtphase in eine Änderung der Lichtintensität um?

  1. ADas Licht wird auf zwei Arme aufgeteilt, zwischen den Armen wird eine Phasendifferenz erzeugt, und anschließend wird es wieder zusammengeführt und zur Interferenz gebracht
  2. BDas Licht läuft in einem ringförmigen Resonator viele Male um, und nur eine bestimmte Wellenlänge wird absorbiert
  3. CTrifft das phasenveränderte Licht direkt auf einen Photodetektor, wird der Phasenunterschied zu einem Unterschied in der Stromstärke
Antwort und Erläuterung anzeigen

Antwort: A. Das Licht wird auf zwei Arme aufgeteilt, zwischen den Armen wird eine Phasendifferenz erzeugt, und anschließend wird es wieder zusammengeführt und zur Interferenz gebracht

Im Mach-Zehnder-Modulator wird das einfallende Licht zu gleichen Teilen auf zwei Arme aufgeteilt, der Brechungsindex der Arme wird durch ein elektrisches Signal verändert, um eine Phasendifferenz zu erzeugen, und danach wird das Licht wieder zu einem Strahl zusammengeführt. Ist die Phasendifferenz der beiden Lichtwellen 0, verstärken sie sich (hell); bei π (einer halben Wellenlänge) löschen sie sich aus (dunkel); dazwischen ergibt sich eine Intensität entsprechend der Phasendifferenz. So lässt sich das Signal als Intensitätsänderung aufprägen, die ein Photodetektor erfassen kann. Ein Photodetektor liefert lediglich einen Strom entsprechend der Lichtintensität und kann Phasenunterschiede nicht direkt erfassen. Ein Resonator wird beim Ringmodulator verwendet.
