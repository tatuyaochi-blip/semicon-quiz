Softwareentwicklung und Projektmanagement

Welches GoF-Entwurfsmuster sorgt dafür, dass die von einem Objekt abhängigen Objekte automatisch benachrichtigt werden, wenn sich der Zustand dieses Objekts ändert?

  1. AObserver
  2. BSingleton
  3. CAdapter
Antwort und Erläuterung anzeigen

Antwort: A. Observer

Beim Observer-Muster führt das benachrichtigende Objekt (das Subjekt) eine Liste registrierter Objekte, die benachrichtigt werden wollen (Beobachter), und informiert sie alle, wenn sich sein Zustand ändert. Das Subjekt muss die konkreten Klassen der Beobachter nicht kennen, wodurch die Kopplung schwach bleibt. Es eignet sich zum Beispiel für einen Entwurf, der Anzeige, Protokollierung und Alarmverarbeitung informiert, wenn sich ein Sensorwert ändert. Singleton ist ein Muster, das sicherstellt, dass eine Klasse nur eine einzige Instanz hat, und Adapter ein Muster, das eine nicht passende Schnittstelle umsetzt, damit Klassen zusammenarbeiten können.
