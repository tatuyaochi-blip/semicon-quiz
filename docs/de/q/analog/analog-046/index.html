Analog- und Elektronikschaltungen

Welche Aussage zum Konzept der „Dominant-Pol-Kompensation“ bei der Phasenkompensation von Operationsverstärkern ist korrekt?

  1. AAlle Pole werden auf dieselbe Frequenz gelegt
  2. BDie Verstärkung wird bei allen Frequenzen auf 0 dB gesetzt
  3. CEin Pol wird auf eine ausreichend niedrige Frequenz gelegt und die Verstärkung fällt unter 1, bevor die anderen Pole erreicht werden, was Stabilität bewirkt
Antwort und Erläuterung anzeigen

Antwort: C. Ein Pol wird auf eine ausreichend niedrige Frequenz gelegt und die Verstärkung fällt unter 1, bevor die anderen Pole erreicht werden, was Stabilität bewirkt

Bei der Dominant-Pol-Kompensation wird durch einen zusätzlichen Kondensator ein Pol auf eine ausreichend niedrige Frequenz (einige Hz bis einige zehn Hz) verschoben. Von dort fällt die Verstärkung mit −20 dB/Dekade und unterschreitet 0 dB, bevor die Phase an den anderen Polen stark dreht, sodass selbst bei Verstärkung 1 (Folger) genügend Phasenreserve besteht. Bei Operationsverstärkern wird der Miller-Effekt genutzt, um mit kleiner Kapazität einen Pol bei niedriger Frequenz zu erzeugen. Der Preis sind begrenzte Bandbreite und Slew Rate.
