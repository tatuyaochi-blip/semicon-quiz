Analog- und Elektronikschaltungen

Welche Aussage zum Satz von Thévenin ist korrekt?

  1. AEine lineare Schaltung aus Quellen und Widerständen kann, von zwei Anschlüssen aus betrachtet, durch eine Spannungsquelle mit einem Reihenwiderstand ersetzt werden
  2. BDer Strom einer Schaltung ist an jeder Stelle gleich
  3. CAuch wenn alle Widerstände durch Parallelschaltungen ersetzt werden, ändert sich der Strom nicht
Antwort und Erläuterung anzeigen

Antwort: A. Eine lineare Schaltung aus Quellen und Widerständen kann, von zwei Anschlüssen aus betrachtet, durch eine Spannungsquelle mit einem Reihenwiderstand ersetzt werden

Nach dem Satz von Thévenin kann eine lineare Schaltung, von zwei betrachteten Anschlüssen aus gesehen, durch eine Reihenschaltung aus einer Spannungsquelle mit der Leerlaufspannung Vth und einem Innenwiderstand Rth (Widerstand bei entfernten Quellen) ersetzt werden. Der Strom durch die Last RL ergibt sich einfach als Vth/(Rth + RL), und auch dass die Leistung an der Last bei RL = Rth maximal wird (Satz der maximalen Leistungsübertragung), lässt sich daraus ableiten. Der Ersatz durch eine Stromquelle mit Parallelwiderstand ist der Satz von Norton.
