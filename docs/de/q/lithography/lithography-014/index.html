Lithografie

Welche allgemeine Prozessreihenfolge der Lithografie ist richtig?

  1. ABelichtung → Resistbeschichtung → Entwicklung → Pre-Bake
  2. BResistbeschichtung → Pre-Bake → Belichtung → Post-Exposure-Bake → Entwicklung
  3. CEntwicklung → Belichtung → Resistbeschichtung → Ätzen
Antwort und Erläuterung anzeigen

Antwort: B. Resistbeschichtung → Pre-Bake → Belichtung → Post-Exposure-Bake → Entwicklung

Zunächst wird die Haftung durch HMDS-Behandlung erhöht, Antireflexschicht und Resist werden aufgetragen, und im Pre-Bake (etwa 100 ℃) wird das Lösungsmittel ausgetrieben. Dann wird belichtet, und bei chemisch verstärkten Resists schreitet die Reaktion im Post-Exposure-Bake (PEB) voran. Zuletzt wird mit alkalischem Entwickler entwickelt, das Muster gebildet und bei Bedarf im Post-Bake gehärtet. Vom Beschichten bis zur Entwicklung läuft alles in einem mit der Belichtungsanlage verbundenen Coater/Developer, wobei die Temperatur auf etwa ±0,1 ℃ kontrolliert wird.
