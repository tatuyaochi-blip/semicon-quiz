Test und Prüfung

Antwort: B. Testmuster (Testvektor)

Ein Testmuster (Testvektor) fasst die zu jedem Zeitpunkt an die Chipeingänge angelegten Signalwerte und die dann zu erwartenden Ausgabewerte zusammen. Muster, die Fehler effizient erkennen, werden mit ATPG automatisch erzeugt oder aus Simulationen zur Verifikation beim Entwurf umgewandelt. Je länger die Muster, desto länger die Testzeit, daher werden sie so optimiert, dass mit wenigen Mustern viele Fehler erkannt werden.
