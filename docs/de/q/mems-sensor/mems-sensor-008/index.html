  2. BErfassung der Lichtmenge eines durch Schall leuchtenden Elements
  3. CErfassung der Kapazitätsänderung zwischen einer durch Schalldruck schwingenden Membran und einer festen Elektrode
Antwort und Erläuterung anzeigen

Antwort: C. Erfassung der Kapazitätsänderung zwischen einer durch Schalldruck schwingenden Membran und einer festen Elektrode

Ein übliches MEMS-Mikrofon bildet aus einer durch Schalldruck schwingenden dünnen Membran (Diaphragma) von etwa 1 µm Dicke und einer gelochten festen Elektrode (Backplate) einen Kondensator; die Kapazitätsänderung durch die Membranschwingung wird von einem ASIC im selben Gehäuse in ein elektrisches Signal umgewandelt. Es ist kleiner als herkömmliche Elektret-Kondensatormikrofone, hitzebeständig gegenüber dem Löten und weist gleichmäßigere Eigenschaften auf, sodass Smartphones mehrere davon etwa zur Rauschunterdrückung nutzen.
