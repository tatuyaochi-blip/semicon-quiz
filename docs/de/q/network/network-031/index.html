Grundlagen der Computernetzwerke

In welcher Reihenfolge laufen die Nachrichten ab, wenn ein Gerät per DHCP eine IP-Adresse bezieht?

  1. ARequest → Offer → Discover → Ack
  2. BDiscover → Offer → Request → Ack
  3. COffer → Discover → Ack → Request
Antwort und Erläuterung anzeigen

Antwort: B. Discover → Offer → Request → Ack

Ein Gerät ohne Adresse weiß auch nicht, wo sich der DHCP-Server befindet, und sendet daher zuerst per Broadcast ein Discover. Ein Server bietet in einem Offer eine Adresse und weitere Einstellungen an, das Gerät teilt in einem Request mit, welches Angebot es annimmt, und der Server bestätigt mit einem Ack. Nach den Anfangsbuchstaben heißt das DORA. Neben der IP-Adresse erhält das Gerät auch Subnetzmaske, Standardgateway, die Adressen der DNS-Server und weiteres. Adressen werden befristet verliehen (Lease), und das Gerät beantragt vor Ablauf eine Verlängerung. Um einen DHCP-Server jenseits eines Routers zu nutzen, wird auf dem Router ein DHCP-Relay eingerichtet.

Weitere Fragen zu Grundlagen der Computernetzwerke

  1. Was wird durch HTTPS (durch TLS geschütztes HTTP) geschützt?
  2. Warum kann ein Browser bei TLS davon ausgehen, dass der verbundene Server kein Betrüger ist, der sich als jemand anderes ausgibt?
  3. Wie lange dauert es ungefähr, eine Datei von 100 MB über eine Leitung mit 100 Mbit/s zu senden? Overhead wie Header sowie Latenz werden vernachlässigt; 1 MB = 10^6 Byte.
  4. Über 1-Gbit/s-Ethernet werden fortlaufend TCP-Daten gesendet, wobei die IP-Pakete die MTU von 1500 Byte voll ausschöpfen. Der IPv4-Header hat 20 Byte, der TCP-Header 20 Byte, Ethernet-Header und FCS zusammen 18 Byte, Präambel und Lücke zwischen den Frames (Interframe Gap) zusammen 20 Byte. Welcher Wert liegt der Obergrenze des Durchsatzes an Anwendungsdaten am nächsten?
  5. Über eine Leitung mit einer RTT von 50 ms und einer Bandbreite von 100 Mbit/s wird eine Anfrage, die eine Antwort von 10 KB liefert, 100-mal wiederholt, wobei die nächste Anfrage jeweils erst nach vollständigem Empfang der vorherigen Antwort gesendet wird. Welcher Wert liegt der Gesamtdauer am nächsten? Die Zeit pro Anfrage ist die RTT plus die Übertragungszeit der Antwort (Datenmenge ÷ Bandbreite), 1 KB = 1000 Byte, die Verarbeitungszeit des Servers wird vernachlässigt.
