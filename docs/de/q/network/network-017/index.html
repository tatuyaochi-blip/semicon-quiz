Grundlagen der Computernetzwerke

Ein Endgerät (192.168.1.10/24, Standardgateway 192.168.1.1) sendet ein Paket an den Server 203.0.113.80 in einem anderen Netzwerk. Wessen MAC-Adresse ermittelt das Endgerät per ARP, wenn der ARP-Cache leer ist?

  1. ADie des Standardgateways 192.168.1.1
  2. BDie des Servers 203.0.113.80
  3. CDie aller Router auf dem Weg zum Server
Antwort und Erläuterung anzeigen

Antwort: A. Die des Standardgateways 192.168.1.1

Das Endgerät prüft zunächst anhand seiner eigenen IP-Adresse und Subnetzmaske, ob das Ziel im selben Netzwerk liegt. 203.0.113.80 liegt außerhalb von 192.168.1.0/24, also wird das Paket dem Standardgateway (einem Router) übergeben. Das Ziel im IP-Header bleibt dabei 203.0.113.80, die Adresse des Servers; nur die Ziel-MAC-Adresse des Frames wird auf die des Gateways gesetzt. Per ARP wird daher die MAC-Adresse von 192.168.1.1 ermittelt. ARP-Broadcasts gelangen nicht über Router hinaus, sodass die MAC-Adresse eines Servers in einem anderen Netzwerk weder ermittelt werden kann noch benötigt wird. Jeder Router auf dem Weg ermittelt bei jeder Weiterleitung selbst die MAC-Adresse des nächsten Geräts.
