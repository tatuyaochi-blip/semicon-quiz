Computerarithmetik

Wie lautet die hexadezimale Schreibweise der Bitfolge, die die Dezimalzahl 1.0 in einfacher Genauigkeit nach IEEE 754 darstellt?

  1. A0x00000001
  2. B0x3F000000
  3. C0x3F800000
Antwort und Erläuterung anzeigen

Antwort: C. 0x3F800000

1.0 = 1.0 × 2⁰, also Vorzeichen 0, tatsächlicher Exponent 0 und Exponentenfeld 0 + 127 = 127 = 0111 1111; die Mantisse (ohne führende 1) besteht nur aus Nullen. Zusammengesetzt ergibt sich 0 01111111 000…0, in Vierergruppen 0011 1111 1000 0000 …, also 0x3F800000. 0x00000001 ist die Bitfolge der Ganzzahl 1; als Gleitkommazahl stellt sie eine winzige denormalisierte Zahl dar. 0x3F000000 hat das Exponentenfeld 126 und stellt 0.5 dar.
