Computerarithmetik

Wie lässt sich bei der Addition vorzeichenloser Ganzzahlen feststellen, dass das Ergebnis den darstellbaren Bereich überschritten hat (Überlauf)?

  1. AMan prüft, ob das höchste Bit des Ergebnisses 1 ist
  2. BMan prüft, ob die höchsten Bits der beiden Eingänge gleich sind
  3. CMan prüft, ob aus dem höchsten Bit ein Übertrag herausgeht
Antwort und Erläuterung anzeigen

Antwort: C. Man prüft, ob aus dem höchsten Bit ein Übertrag herausgeht

Bei der Addition vorzeichenloser Zahlen hat das Ergebnis den mit der Bitzahl darstellbaren Höchstwert überschritten, wenn aus dem höchsten Bit ein Übertrag nach oben herausgeht. In der CPU bleibt dieser Übertrag als Carry-Flag erhalten und kann zur Prüfung herangezogen werden. Dass das höchste Bit des Ergebnisses 1 ist, bedeutet nur eine große Zahl und keinen Überlauf. Der Vergleich zwischen Übertrag in das höchste Bit und Übertrag aus dem höchsten Bit ist die Methode zur Überlauferkennung bei vorzeichenbehafteten Zahlen.
