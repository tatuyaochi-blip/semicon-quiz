Welches Ergebnis legt die Norm bei Gleitkommaoperationen nach IEEE 754 für die Division einer positiven Zahl durch 0 fest?

  3. CPositiv unendlich

Antwort: C. Positiv unendlich

IEEE 754 legt fest, dass die Division einer Zahl ungleich 0 durch 0 je nach Vorzeichen positiv oder negativ unendlich ergibt. Unendlich wird durch eine Bitfolge mit Exponent aus lauter Einsen und Mantisse 0 dargestellt und auch als Ergebnis bei Überlauf verwendet. Die Berechnung kann ohne Programmabbruch fortgesetzt und das Ergebnis später auf Auffälligkeiten geprüft werden. 0 ÷ 0 ist unbestimmt und ergibt NaN. Anders als bei ganzzahliger Division bricht Gleitkomma standardmäßig nicht mit einer Ausnahme ab.
