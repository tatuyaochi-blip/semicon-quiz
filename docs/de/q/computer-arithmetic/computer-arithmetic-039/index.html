Computerarithmetik

Was ist die Hauptwirkung der Booth-Kodierung (Booth-Algorithmus zur Basis 4) in Multiplizierern?

  1. ADas Multiplikationsergebnis wird stets ohne Rundung exakt bestimmt
  2. BDer Multiplikator wird durch vorzeichenbehaftete Ziffern ersetzt, und die Teilprodukte werden etwa halbiert
  3. CDie Multiplikation vorzeichenbehafteter Zahlen wird unmöglich, dafür wird die Schaltung kleiner
Antwort und Erläuterung anzeigen

Antwort: B. Der Multiplikator wird durch vorzeichenbehaftete Ziffern ersetzt, und die Teilprodukte werden etwa halbiert

Bei normaler Multiplikation entsteht pro Bit des Multiplikators ein Teilprodukt, bei n Bit müssen also n Teilprodukte addiert werden. Bei der Booth-Kodierung zur Basis 4 wird der Multiplikator je 2 Bit (mit Blick auf überlappende 3 Bit) durch Ziffern −2, −1, 0, +1, +2 ersetzt, sodass sich die Teilprodukte auf etwa n/2 verringern. Das ±2-Fache ist eine Verschiebung um 1 Bit, negative Werte lassen sich im Zweierkomplement bilden, die Schaltung bleibt also einfach. Mit weniger Teilprodukten wird die Summationsschaltung kleiner und schneller. Auch vorzeichenbehaftete Multiplikation wird natürlich unterstützt.
