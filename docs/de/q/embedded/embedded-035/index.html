Embedded Systems und Firmware

Welche Aussage zum Unterschied zwischen Hard Real-Time und Soft Real-Time ist korrekt?

  1. AHard wird nur aus Hardware, Soft nur aus Software gebaut
  2. BHard ist in der Verarbeitung langsam, Soft schnell
  3. CBei Hard bedeutet schon ein einziges verpasstes Zeitlimit ein Systemversagen, bei Soft führen gelegentliche Verzögerungen nur zu geringerer Leistung
Antwort und Erläuterung anzeigen

Antwort: C. Bei Hard bedeutet schon ein einziges verpasstes Zeitlimit ein Systemversagen, bei Soft führen gelegentliche Verzögerungen nur zu geringerer Leistung

Beispiele für Hard Real-Time sind Airbag, Motor und Bremssteuerung von Fahrzeugen, bei denen eine verpasste Frist zu schweren Unfällen führt. Dass die Frist auch im ungünstigsten Fall eingehalten wird, muss bereits beim Entwurf nachgewiesen werden. Beispiele für Soft Real-Time sind Video- und Audiowiedergabe, wo gelegentliche Verzögerungen höchstens zu leichten Bildstörungen führen. Je nachdem, welcher Fall vorliegt, ändert sich die Strenge der nötigen Verifikation erheblich.
