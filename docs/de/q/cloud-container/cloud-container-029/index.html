Grundlagen von Cloud und Containern

Bei serverlosen Funktionen (FaaS) antwortet manchmal nur der erste Aufruf einer Funktion, die eine Weile nicht aufgerufen wurde, um einige hundert Millisekunden bis einige Sekunden langsamer. Welche Erklärung dieses Phänomens ist richtig?

  1. ADas Ergebnis des ersten Aufrufs wird zwischengespeichert, und ab dem zweiten Aufruf wird der Code der Funktion nicht ausgeführt, sondern nur das gespeicherte Ergebnis zurückgegeben
  2. BEs kostet Zeit, eine neue Umgebung zur Ausführung der Funktion bereitzustellen, die Laufzeitumgebung der Sprache zu starten und die Initialisierung durchzuführen (Kaltstart)
  3. CBeim ersten Aufruf wird der Code der Funktion an das Gerät des Nutzers geschickt, dort kompiliert und dann ausgeführt
Antwort und Erläuterung anzeigen

Antwort: B. Es kostet Zeit, eine neue Umgebung zur Ausführung der Funktion bereitzustellen, die Laufzeitumgebung der Sprache zu starten und die Initialisierung durchzuführen (Kaltstart)

Bei serverlosen Funktionen stellt der Anbieter Ausführungsumgebungen (etwa Container oder leichtgewichtige virtuelle Maschinen) nach Bedarf bereit und räumt sie wieder ab, wenn sie eine Weile nicht genutzt werden. Der erste Aufruf nach dem Abräumen erfordert die Bereitstellung der Umgebung, den Start der Laufzeitumgebung der Sprache und die Initialisierung der Funktion, und die Antwort verzögert sich entsprechend. Folgeaufrufe verwenden die bereitgestellte Umgebung wieder und sind schneller (Warmstart). Gegenmaßnahmen sind etwa, die Initialisierung und die geladenen Bibliotheken schlank zu halten oder Einstellungen zu nutzen, die vorab eine bestimmte Zahl von Umgebungen bereithalten.

Weitere Fragen zu Grundlagen von Cloud und Containern

  1. Cloud-Speicher wird für drei Zwecke eingesetzt: (1) als Festplatte an eine virtuelle Maschine angebunden, mit einem Dateisystem versehen und für die Datendateien einer Datenbank genutzt; (2) von mehreren Servern gleichzeitig eingebunden und als gemeinsames Verzeichnis genutzt; (3) zum Lesen und Schreiben einer großen Zahl von Bildern per Schlüssel (Name) über eine API per HTTP, wobei die Kapazität wächst, ohne vorab festgelegt zu werden. Welche Kombination von Speicherarten ist für (1) bis (3) geeignet?
  2. Es werden virtuelle Maschinen genutzt, die nur nach genutzter Zeit abgerechnet werden, zu 40 Yen pro Stunde (ein erfundener Preis). Normalerweise laufen 2 Maschinen den ganzen Monat (30 Tage) durch, und an 20 Werktagen kommen je 6 Stunden am Tag 4 weitere hinzu, um die Last abzufangen. Wie hoch sind die Kosten für den Monat?
  3. Eine virtuelle Maschine kostet On-Demand, also mit Bezahlung nur der genutzten Stunden, 50 Yen pro Stunde, mit einer Reservierung, die ein Jahr Nutzung im Voraus zusagt, unabhängig von den genutzten Stunden 262.800 Yen pro Jahr (beides erfundene Preise). Ein Jahr wird mit 8760 Stunden angesetzt; ab einer bestimmten Zahl genutzter Stunden pro Jahr wird die Reservierung günstiger. Welche Stundenzahl ist das?
  4. Was gilt im Allgemeinen für die Art, wie viele Public Clouds die Datenübertragung abrechnen?
  5. Mit einem deklarativen IaC-Werkzeug (Infrastructure as Code) wurde eine Umgebung erstellt, indem eine Datei angewendet wurde, die ein Netzwerk und zwei virtuelle Maschinen definiert. Unmittelbar danach wird dieselbe Datei ohne jede Änderung noch einmal angewendet. Was geschieht?
