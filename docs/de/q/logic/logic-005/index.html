Welchen Dezimalwert hat die Binärzahl 1011?

  1. A11
  2. B9
  3. C13
Antwort und Erläuterung anzeigen

Antwort: A. 11

Die Stellen einer Binärzahl haben von rechts die Wertigkeiten 1, 2, 4, 8, und 1011 ist 8×1 + 4×0 + 2×1 + 1×1 = 11. Umgekehrt wandelt man eine Dezimalzahl in eine Binärzahl um, indem man die Reste der Division durch 2 von der niedrigsten Stelle an aufschreibt oder von der größten Wertigkeit an subtrahiert. In Gruppen zu je 4 Bit entspricht jede Gruppe einer Hexadezimalstelle (1011 = B), was zum Kurzschreiben langer Bitfolgen praktisch ist. Ein Merkmal von Binärzahlen ist auch, dass man am niederwertigsten Bit 1 sofort eine ungerade Zahl erkennt.
