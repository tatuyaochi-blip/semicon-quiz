Grundlagen der digitalen Signalverarbeitung

Welche Übertragungsfunktion H(z) = Y(z)/X(z) hat das durch die Differenzengleichung y[n] = x[n] + 0,5x[n − 1] + 0,25y[n − 1] beschriebene System?

  1. A(1 + 0,5z⁻¹)/(1 + 0,25z⁻¹)
  2. B(1 − 0,25z⁻¹)/(1 + 0,5z⁻¹)
  3. C(1 + 0,5z⁻¹)/(1 − 0,25z⁻¹)
Antwort und Erläuterung anzeigen

Antwort: C. (1 + 0,5z⁻¹)/(1 − 0,25z⁻¹)

Eine Verzögerung um einen Abtastwert entspricht in der z-Transformation der Multiplikation mit z⁻¹; die Transformation beider Seiten ergibt daher Y(z) = X(z) + 0,5z⁻¹X(z) + 0,25z⁻¹Y(z). Fasst man die Y(z)-Terme links zusammen, erhält man (1 − 0,25z⁻¹)Y(z) = (1 + 0,5z⁻¹)X(z), also H(z) = (1 + 0,5z⁻¹)/(1 − 0,25z⁻¹). Der Zähler enthält die Koeffizienten der Eingangsseite, der Nenner die der Rückkopplung des Ausgangs; z = 0,25, das den Nenner zu 0 macht, ist ein Pol, und z = −0,5, das den Zähler zu 0 macht, ist eine Nullstelle.
