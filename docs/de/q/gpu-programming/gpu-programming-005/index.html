GPU-Programmierung

Welche Kombination der Thread-Hierarchie in CUDA ist richtig (von groß nach klein)?

  1. AGrid → Block → Thread
  2. BThread → Block → Grid
  3. CBlock → Thread → Grid
Antwort und Erläuterung anzeigen

Antwort: A. Grid → Block → Thread

Beim einmaligen Start eines Kernels bildet das Ganze ein Grid, das Grid gliedert sich in viele Blöcke und der Block in viele Threads. Die Threads eines Blocks werden auf demselben SM (einer Gruppe von Recheneinheiten) ausgeführt und können über den Shared Memory zusammenarbeiten und sich synchronisieren. Verschiedene Blöcke werden unabhängig ausgeführt, sodass sich die Zahl der gleichzeitig laufenden Blöcke an die Größe der GPU anpasst und dasselbe Programm auf kleinen wie großen GPUs läuft.
