GPU-Programmierung

Welche Aussage zu Unified Memory von CUDA ist richtig?

  1. AEin Speicher, der von CPU und GPU über denselben Zeiger genutzt werden kann und dessen Daten bei Bedarf automatisch verschoben werden
  2. BCPU- und GPU-Chip physisch zu einem vereint
  3. CDer gesamte GPU-Speicher ist schreibgeschützt
Antwort und Erläuterung anzeigen

Antwort: A. Ein Speicher, der von CPU und GPU über denselben Zeiger genutzt werden kann und dessen Daten bei Bedarf automatisch verschoben werden

Bei Unified Memory kann auf den reservierten Bereich sowohl von der CPU als auch von der GPU über denselben Zeiger zugegriffen werden, und bei einem Zugriff werden die Daten seitenweise zu der Seite verschoben, die sie braucht. Das Programm wird einfacher, und auch Daten, die größer sind als der GPU-Speicher, lassen sich leichter handhaben. Bei jeder Verschiebung treten jedoch Page Faults und Übertragungen auf; ist Leistung gefragt, wird z. B. durch Anweisungen zum vorherigen Verschieben nachgeholfen.
