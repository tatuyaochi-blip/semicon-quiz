Betriebssystem und Hardware

Was ist der Hauptzweck der Einrichtung von privilegiertem Modus (Kernel-Modus) und Benutzermodus in der CPU?

  1. ADamit Befehle von Anwendungen schneller und vorrangig vor Kernel-Befehlen ausgeführt werden können
  2. BUm Anwendungen daran zu hindern, eigenmächtig Seitentabellen oder Geräte zu manipulieren
  3. CDamit eine CPU zwei Befehle gleichzeitig ausführen kann
Antwort und Erläuterung anzeigen

Antwort: B. Um Anwendungen daran zu hindern, eigenmächtig Seitentabellen oder Geräte zu manipulieren

Könnten Anwendungen beliebig Seitentabellen umschreiben, Ein-/Ausgabegeräte bedienen oder Interrupts sperren, ließe sich der Speicher anderer Programme zerstören oder das ganze System anhalten. Daher erlaubt die CPU diese Befehle nur im privilegierten Modus, sodass nur der Kernel des Betriebssystems sie nutzen kann. Der Versuch, sie im Benutzermodus auszuführen, löst eine Ausnahme aus. Es handelt sich nicht um einen Mechanismus für Geschwindigkeit oder Gleichzeitigkeit.
