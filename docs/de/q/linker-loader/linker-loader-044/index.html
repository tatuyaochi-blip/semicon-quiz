Linker, Loader und ausführbare Formate

Was lässt sich unter Linux erkennen, wenn der Befehl ldd auf eine ausführbare Datei angewendet wird?

  1. ADie Shared Libraries, die diese ausführbare Datei benötigt, und die Orte, an denen sie jeweils gefunden werden
  2. BDer Quellcode dieser ausführbaren Datei
  3. CDie von dieser ausführbaren Datei verbrauchte CPU-Zeit
Antwort und Erläuterung anzeigen

Antwort: A. Die Shared Libraries, die diese ausführbare Datei benötigt, und die Orte, an denen sie jeweils gefunden werden

ldd zeigt die Liste der Shared Libraries, die dynamisch gelinkte ausführbare Dateien oder Shared Libraries verwenden, und zu welchen Dateien sie jeweils aufgelöst werden. Nicht gefundene werden als „not found“ angezeigt, was bei der Suche nach der Ursache eines nicht startenden Programms hilft. Bei nicht vertrauenswürdigen ausführbaren Dateien ist Vorsicht geboten, da dabei unter Umständen der enthaltene Code ausgeführt wird.
