Netzwerkdesign und Netzwerkbetrieb

Bei IPv4 wird ein Paket mit einer Gesamtlänge von 4000 Byte (20 Byte Header und 3980 Byte Daten) auf einer Verbindung mit einer MTU von 1500 Byte aufgeteilt (fragmentiert). Auch die Fragmente haben 20-Byte-Header, und die Fragmentierung ist erlaubt. Welchen Wert hat das Feld Fragment Offset im letzten Fragment?

  1. A185
  2. B370
  3. C2960
Antwort und Erläuterung anzeigen

Antwort: B. 370

Jedes Fragment kann MTU − Header = 1500 − 20 = 1480 Byte Daten aufnehmen; das ist ein Vielfaches von 8 und kann unverändert verwendet werden. Die 3980 Byte Daten werden in drei Teile zu 1480, 1480 und 1020 Byte aufgeteilt. Der Fragment Offset gibt die Position in den ursprünglichen Daten in Einheiten von 8 Byte an, also 1480 ÷ 8 = 185 für das zweite und 2960 ÷ 8 = 370 für das dritte Fragment. Das letzte Fragment hat eine Gesamtlänge von 1040 Byte, und sein MF-Flag ist 0, um anzuzeigen, dass keine weiteren Fragmente folgen. Das Ziel ordnet Fragmente mit derselben Identifikation nach ihrem Offset und setzt daraus das ursprüngliche Paket wieder zusammen.

Weitere Fragen zu Netzwerkdesign und Netzwerkbetrieb

  1. Ein Endgerät kommuniziert über einen Site-to-Site-VPN-Tunnel mit einem entfernten Webserver. TCP-Verbindungen lassen sich aufbauen und kleine Seiten werden angezeigt, doch Downloads großer Dateien bleiben mittendrin stehen. Die MTU im Tunnel beträgt 1400 Byte, und der Server sendet 1500-Byte-Pakete mit verbotener Fragmentierung (DF-Bit auf 1). Außerdem ist die Firewall vor dem Server so eingestellt, dass sie jegliches ICMP verwirft. Was ist die wahrscheinlichste Ursache?
  2. Welche Beschreibung von DSCP im IP-Header, das bei der QoS-Steuerung verwendet wird, ist richtig?
  3. Auf einer ausgehenden 70-Mbit/s-Verbindung eines Routers werden drei Warteschlangen per Weighted Round Robin mit den Gewichten 4:2:1 bedient. Alle drei Warteschlangen enthalten stets wartende Pakete, und alle Pakete sind gleich groß. Welcher Wert liegt der Bandbreite, die der Warteschlange mit dem Gewicht 2 zur Verfügung steht, am nächsten?
  4. Per SNMP wird alle 5 Minuten (300 Sekunden) ein 64-Bit-Zähler der empfangenen Bytes einer Router-Schnittstelle ausgelesen. Der vorige Wert war 1 200 000 000, der aktuelle ist 4 950 000 000. Welcher Wert liegt der mittleren Empfangsrate in diesen 5 Minuten am nächsten?
  5. Für den Verkehr durch einen Router soll ermittelt werden, wie viele Bytes auf jede Kombination aus Quelle und Ziel (Adressen, Portnummern und Protokoll) entfallen, zusammengefasst je Verkehrsstrom. Welcher Mechanismus ist dafür am besten geeignet?
