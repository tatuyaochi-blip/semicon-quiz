Grundlagen der Programmierung (Pseudocode nachverfolgen)

Die Array-Indizes beginnen bei 1. Was enthält das Array a, nachdem das folgende Programm ausgeführt wurde?

integer array: a ← {5, 1, 4, 2, 3}
integer: t ← a[1]
for (i from 1 to 4 step 1)
  a[i] ← a[i + 1]
endfor
a[5] ← t
  1. A{1, 4, 2, 3, 5}
  2. B{1, 4, 2, 3, 3}
  3. C{3, 5, 1, 4, 2}
Antwort und Erläuterung anzeigen

Antwort: A. {1, 4, 2, 3, 5}

Nachdem der erste Wert 5 in t gespeichert wurde, rückt a[i] ← a[i + 1] jedes Element um eine Stelle nach vorn. Weil i aufwärts läuft, wird jeder Wert verschoben, bevor er überschrieben wird, und es ergibt sich {1, 4, 2, 3, 3}. Zum Schluss schreibt a[5] ← t die 5 ans Ende: {1, 4, 2, 3, 5}. Das Programm rotiert das ganze Array um eine Stelle nach links.

Weitere Fragen zu Grundlagen der Programmierung (Pseudocode nachverfolgen)
