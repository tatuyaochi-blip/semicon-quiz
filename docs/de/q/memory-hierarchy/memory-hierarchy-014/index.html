Speicherhierarchie und Leistung

Ein voll assoziativer Cache mit 2 Zeilen Kapazität und LRU-Ersetzung ist anfangs leer. Wie viele Misses treten auf, wenn die Blöcke in der Reihenfolge A, B, A, C, B, A referenziert werden?

  1. A4
  2. B5
  3. C6
Antwort und Erläuterung anzeigen

Antwort: B. 5

Der Reihe nach: A (Miss, [A]), B (Miss, [A,B]), A (Treffer, A ist jetzt am jüngsten), C (Miss, das älteste B wird verdrängt, [A,C]), B (Miss, das älteste A wird verdrängt, [C,B]), A (Miss, das älteste C wird verdrängt, [B,A]); es sind 5 Misses. 4 ergibt sich bei einer Zählung, bei der man fälschlich annimmt, dass beim Einlegen von C das A verdrängt wird; wichtig ist, dass bei LRU das getroffene A aktualisiert wird. 6 ist die Zahl, bei der der Treffer des dritten Zugriffs auf A übersehen wurde.
