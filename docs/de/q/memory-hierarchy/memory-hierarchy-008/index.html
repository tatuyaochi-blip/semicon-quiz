Speicherhierarchie und Leistung

Welche Methode ist wirksam, um Cache-Misses zu verringern, die beim ersten Zugriff eines Programms auf ein Datum auftreten?

  1. AMit Prefetch vorab laden
  2. BDie Assoziativität (Wegezahl) des Caches verdoppeln
  3. CNur die Kapazität des Caches verdoppeln
Antwort und Erläuterung anzeigen

Antwort: A. Mit Prefetch vorab laden

Compulsory Misses beim ersten Zugriff entstehen, weil das Datum noch nie im Cache war, und werden durch mehr Kapazität oder Assoziativität nicht weniger. Sie lassen sich verringern, indem per Prefetch vor dem Bedarf geladen wird oder durch größere Zeilen nahe Daten gebündelt mitgebracht werden. Durch höhere Assoziativität sinken Konflikt-Misses um denselben Satz, durch mehr Kapazität Kapazitäts-Misses, bei denen das Working Set überläuft.
