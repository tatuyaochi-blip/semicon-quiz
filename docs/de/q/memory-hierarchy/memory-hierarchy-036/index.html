Speicherhierarchie und Leistung

Wie viele Tags werden bei einem 8-fach satzassoziativen Cache bei jedem Zugriff parallel verglichen?

  1. ASo viele wie die gesamte Zeilenzahl des Caches
  2. B8
  3. C1
Antwort und Erläuterung anzeigen

Antwort: B. 8

Bei der satzassoziativen Methode wird zunächst mit dem Index der Adresse ein Satz ausgewählt, und die Tags aller Wege dieses Satzes werden parallel verglichen. Bei 8 Wegen hat ein Satz 8 Zeilen, es werden also 8 Tags verglichen, und es sind dafür 8 Komparatoren nötig. So viele Tags wie die gesamte Zeilenzahl werden bei voller Assoziativität verglichen, nur ein Tag bei Direct-Mapped. Mit mehr Wegen steigen Komparatoren und Stromverbrauch, weshalb die Assoziativität von L1 häufig zurückhaltend gewählt wird.
