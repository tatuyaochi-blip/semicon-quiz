Speicherhierarchie und Leistung

Welches Verfahren sendet beim Laden einer Miss-Zeile aus dem Hauptspeicher zuerst das von der CPU benötigte Wort und den Rest später?

  1. ACritical Word First
  2. BWrite-Allocate
  3. CVictim Cache
Antwort und Erläuterung anzeigen

Antwort: A. Critical Word First

Wird erst die gesamte 64-Byte-Zeile abgewartet, bevor Daten übergeben werden, verlängert sich die Wartezeit der CPU entsprechend. Bei Critical Word First wird das angeforderte Wort zuerst übertragen und sofort an die CPU übergeben, der Rest der Zeile wird später aufgefüllt; die effektive Miss-Penalty verkürzt sich. Write-Allocate ist ein Verfahren dafür, ob bei einem Schreib-Miss die Zeile geladen wird, und der Victim Cache ein kleiner Puffer, der verdrängte Zeilen vorübergehend hält. Beide haben mit der Übertragungsreihenfolge nichts zu tun.
