Speicherhierarchie und Leistung

Welche Auswirkung hat es, die Zeilengröße des Caches zu vergrößern?

  1. ACompulsory Misses nehmen zu, und die Miss-Penalty wird kleiner
  2. BBei jedem Programm sinkt die Miss-Rate stetig weiter
  3. CRäumliche Lokalität wird besser genutzt, doch die Miss-Penalty wird größer
Antwort und Erläuterung anzeigen

Antwort: C. Räumliche Lokalität wird besser genutzt, doch die Miss-Penalty wird größer

Bei größeren Zeilen werden mit einem Miss nahe Daten gebündelt geladen, sodass bei Verarbeitungen mit räumlicher Lokalität die Compulsory Misses abnehmen. Andererseits wächst die Miss-Penalty, weil pro Miss mehr übertragen wird, und bei gleicher Kapazität sinkt die Zeilenzahl, sodass Konflikt-Misses und das Laden nicht verwendeter Daten zunehmen. Werden die Zeilen zu groß, steigt die Miss-Rate daher sogar, und sie sinkt nicht stetig weiter. Dass Compulsory Misses zunehmen, ist ebenfalls umgekehrt.
