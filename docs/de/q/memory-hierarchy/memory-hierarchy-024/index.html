Speicherhierarchie und Leistung

Ein Prozessor hat bei idealem Cache eine mittlere CPI von 1,0, im Mittel 1,3 Speicherzugriffe pro Befehl, eine Miss-Rate von 2 % und eine Miss-Penalty von 100 Zyklen. Wie hoch ist die tatsächliche mittlere CPI?

  1. A3,0
  2. B3,6
  3. C1,3
Antwort und Erläuterung anzeigen

Antwort: B. 3,6

Die Speicher-Stall-Zyklen pro Befehl betragen 1,3 Zugriffe × 0,02 × 100 Zyklen = 2,6 Zyklen. Addiert zur idealen CPI ergibt das 1,0 + 2,6 = 3,6, und die Leistung fällt auf 1/3,6 des Idealwerts. 3,0 ist der Wert bei irrtümlich einem Zugriff pro Befehl (1,0 + 1 × 0,02 × 100). 1,3 ist die Zahl der Zugriffe pro Befehl und keine CPI. Man sieht, dass selbst eine kleine Miss-Rate die Leistung bei großer Miss-Penalty stark senkt.
