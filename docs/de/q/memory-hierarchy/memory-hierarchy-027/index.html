Speicherhierarchie und Leistung

Ein TLB hat 64 Einträge, die Seitengröße beträgt 4 KB. Welchen Speicherbereich kann man ohne TLB-Miss ansprechen (TLB-Reichweite)?

  1. A64 KB
  2. B256 KB
  3. C4 MB
Antwort und Erläuterung anzeigen

Antwort: B. 256 KB

Ein TLB-Eintrag hält die Umsetzung für eine Seite; die TLB-Reichweite ist also Eintragszahl × Seitengröße = 64 × 4 KB = 256 KB. Verwendet ein Programm häufig einen größeren Bereich, nehmen TLB-Misses zu. Mit großen 2-MB-Seiten (Huge Pages) lässt sich dieselbe Eintragszahl von 64 auf 64 × 2 MB = 128 MB erweitern. 64 KB ist der Wert bei irrtümlich 1 KB Seitengröße, 4 MB ein Wert, bei dem Seitenzahl und Größe verwechselt wurden.
