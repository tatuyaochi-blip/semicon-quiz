GPU-Programmierung: Kernpunkte

Eine GPU ist ein Prozessor, der Tausende bis Zehntausende Threads gleichzeitig ausführt und dieselbe Verarbeitung auf große Datenmengen anwendet. Programme drücken Parallelität in der Hierarchie aus Grid, Block und Thread aus, während die Hardware etwa 32 Threads als Warp mit demselben Befehl ausführt.

Für hohe Leistung sind entscheidend: Coalesced Memory Access, bei dem benachbarte Threads benachbarte Adressen lesen, der On-Chip Shared Memory, den sich die Threads eines Blocks teilen, die Vermeidung von Verzweigungen innerhalb eines Warps und eine ausreichende Occupancy, um Speicherlatenzen zu verbergen. Im Mittelpunkt stehen Prinzipien, die unabhängig von der Produktgeneration gelten.
