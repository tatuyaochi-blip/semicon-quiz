Compiler: Kernpunkte

Ein Compiler ist Software, die ein von Menschen geschriebenes Programm in Maschinencode übersetzt, den die CPU ausführen kann. Der Quellcode durchläuft die lexikalische Analyse, die ihn in Token zerlegt, die Syntaxanalyse, die gemäß der Grammatik einen Baum aufbaut, und die semantische Analyse, die Typen und Namen prüft, und wird dann in eine Zwischendarstellung (IR) überführt.

Auf der Zwischendarstellung erfolgen Optimierungen wie Constant Folding, Entfernung gemeinsamer Teilausdrücke, Inlining, Loop Unrolling und Vektorisierung; zuletzt erzeugen Registerzuteilung und Befehlsplanung den zur CPU passenden Code. Wer die Optimierungen kennt, versteht, wie man schnelle Programme schreibt und die Hardwareleistung ausschöpft.
