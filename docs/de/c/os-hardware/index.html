Betriebssystem und Hardware: Kernpunkte

Ein Betriebssystem (OS) ist Software, mit der sich viele Programme Hardware wie CPU, Speicher und Ein-/Ausgabegeräte sicher teilen. Dazu verfügt die CPU über einen privilegierten Modus, der nur dem OS zur Verfügung steht, über Interrupt- und Exception-Mechanismen und über Schaltungen für den Zugriff auf Seitentabellen der virtuellen Speicherverwaltung.

Anwendungen fordern Dienste des OS per Systemaufruf an, das OS wechselt per Timer-Interrupt zwischen Programmen (Kontextwechsel) und stellt bei einem Page Fault die benötigte Seite im Speicher bereit. Behandelt wird das Zusammenspiel von Hardware und Software bis hin zu Gerätetreibern, Memory-Mapped I/O und Virtualisierung durch Hypervisoren.
