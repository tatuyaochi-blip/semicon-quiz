Hardwaresicherheit: Kernpunkte

Auch wenn die Software fehlerfrei ist, können aufgrund von Hardwareeigenschaften Informationen abfließen. Die Schwachstellen Spectre und Meltdown nutzen aus, dass spekulative Ausführung und Caches, die der Leistungssteigerung dienen, Spuren eigentlich unsichtbarer Daten hinterlassen. Auch Seitenkanalangriffe, die aus geringen Unterschieden in Leistungsaufnahme oder Verarbeitungszeit kryptografische Schlüssel ableiten, gehören dazu.

Als Schutztechniken dienen Secure Boot, das nur korrekte Software startet, eine auch vom OS isolierte sichere Ausführungsumgebung (TEE), PUF, die chipindividuelle Fertigungsstreuungen wie einen Fingerabdruck nutzen, sowie Gegenmaßnahmen gegen Hardware-Trojaner, also während Entwurf oder Fertigung eingeschleuste bösartige Schaltungen. Ziel ist das Verständnis von Prinzipien und Gegenmaßnahmen, nicht von Angriffsabläufen.
