DRAM: Das Wichtigste

Ein DRAM speichert ein Bit mit einem Transistor und einem Kondensator. Der einfache Zellaufbau ermöglicht leicht eine hohe Integrationsdichte, weshalb DRAM weithin als Hauptspeicher von Computern verwendet wird.

Die Ladung im Kondensator geht durch Leckströme allmählich verloren, sodass die Daten regelmäßig neu geschrieben werden müssen (Refresh). Auch beim Lesen wird die Ladung der Zelle gestört, daher werden die Daten von einem Leseverstärker (Sense Amplifier) verstärkt und anschließend zurückgeschrieben.
