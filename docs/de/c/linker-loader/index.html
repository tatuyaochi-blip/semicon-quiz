Linker, Loader und ausführbare Formate: Kernpunkte

Die Ausgabe des Compilers ist eine Objektdatei, die so noch nicht ausführbar ist. Der Linker sammelt mehrere Objektdateien und Bibliotheken, bindet die Namen von Funktionen und Variablen (Symbole) an tatsächliche Adressen (Symbolauflösung), trägt diese Adressen in die Befehle ein (Relokation) und erzeugt so die ausführbare Datei.

Der Loader lädt die ausführbare Datei in den Speicher, richtet die Bereiche Text, Data, BSS, Heap und Stack ein und startet das Programm. Dynamisches Linken, bei dem Bibliotheken zur Laufzeit gebunden werden, und positionsunabhängiger Code (PIC), der an beliebigen Adressen lauffähig ist, helfen sowohl beim Speichersparen als auch bei der Sicherheit.
