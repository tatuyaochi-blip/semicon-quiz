Befehlssatz und Assembler: Kernpunkte

Die Befehlssatzarchitektur (ISA) ist die Schnittstellenvereinbarung zwischen Software und Hardware. Sie legt fest, welche Befehle es gibt, mit welchen Bitmustern sie kodiert werden und wie Register und Speicher angesprochen werden. Wird dieselbe ISA eingehalten, läuft dasselbe Programm auch auf CPUs mit unterschiedlichem internem Aufbau.

Assemblersprache ist die für Menschen lesbare Schreibweise der Maschinenbefehle. Wer die RISC-V-Basisbefehle, die Verwendung der Register, die Übergabe von Argumenten und Rückgabewerten beim Funktionsaufruf (Aufrufkonvention) und den Aufbau von Stack-Frames kennt, versteht den vom Compiler erzeugten Code und die Ausführung von Programmen auf der CPU.
