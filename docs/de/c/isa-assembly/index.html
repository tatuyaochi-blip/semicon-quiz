ISA und Assembler: Das Wichtigste

Eine Befehlssatzarchitektur (ISA) ist der Vertrag zwischen Software und Hardware. Sie legt fest, welche Befehle es gibt, wie sie als Bits kodiert werden und wie Register und Speicher angegeben werden. Jede CPU, die dieselbe ISA einhält, kann dieselben Programme ausführen, egal wie unterschiedlich ihr Innenleben ist.

Assemblersprache schreibt Maschinenbefehle in menschenlesbarer Form. Wer die zentralen RISC-V-Befehle, die Registernutzung, die Übergabe von Argumenten und Rückgabewerten zwischen Funktionen (Aufrufkonvention) und den Aufbau von Stack-Frames kennt, sieht, was Compiler erzeugen und wie Programme tatsächlich auf einer CPU laufen.
