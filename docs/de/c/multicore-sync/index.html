Multicore und Synchronisation: Kernpunkte

Bei Multicore-CPUs mit mehreren Kernen auf einem Chip hat jeder Kern seinen eigenen Cache, teilt sich aber denselben Speicher. Damit ein Kern nicht mit veralteten Daten arbeitet, die ein anderer Kern geändert hat, verwalten Kohärenzprotokolle wie MESI die Zustände der Caches.

Hinzu kommen Speicherkonsistenzmodelle, die festlegen, in welcher Reihenfolge Schreibzugriffe für andere Kerne sichtbar werden, atomare Befehle für sichere Aktualisierungen durch mehrere Kerne sowie Sperren und Memory Barriers. Behandelt werden auch Fallstricke wie False Sharing und Data Races, durch die scheinbar korrekte Programme langsam werden oder fehlerhaft arbeiten.
