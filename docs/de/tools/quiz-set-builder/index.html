Fragenset erstellen

Erstellen Sie ein Quiz für eine Klasse, eine Laborgruppe oder die Einarbeitung neuer Mitarbeitender: Themen und Fragenanzahl wählen, Link teilen – fertig. Alle, die den Link öffnen, erhalten dieselben Fragen mit ausführlichen Erklärungen. Keine Anmeldung nötig.

Link zu Ihrem Fragenset

Zum Prüfen öffnen

Alle, die diesen Link öffnen, erhalten dieselben Fragen (die Reihenfolge der Antwortmöglichkeiten wird jedes Mal gemischt). Die Ergebnisse bleiben im Browser der jeweiligen Person und werden weder an Sie noch an uns gesendet.

So funktioniert es

Haken Sie die gewünschten Themen an, wählen Sie die Anzahl der Fragen und klicken Sie auf „Link erstellen“. Die Fragen werden gleichmäßig aus den gewählten Themen gezogen. Wenn Sie einen Namen für das Fragenset eingeben, erscheint er als Titel auf der Quiz-Seite. Teilen Sie den Link über Ihre Lernplattform, per E-Mail oder im Chat; derselbe Link liefert immer dieselben Fragen.

Noten und Datenschutz

Die Website verwendet keine Konten und keine Datenbank. Die Ergebnisse werden nur im Browser der Person gespeichert, die das Quiz bearbeitet. Wenn Sie Punktzahlen einsammeln möchten, bitten Sie Ihre Lernenden, einen Screenshot der Ergebnisseite oder ihre Punktzahl abzugeben – je nachdem, was zu Ihrem Kurs passt.

Häufige Fragen

Ist das Erstellen von Quizzen kostenlos?

Ja. Es ist kostenlos, erfordert keine Anmeldung, und die erstellten Links laufen nicht ab.

Bekommen alle Lernenden dieselben Fragen?

Ja, alle, die denselben Link öffnen, erhalten dieselben Fragen. Die Reihenfolge der Antwortmöglichkeiten wird jedes Mal gemischt, sodass Antworten nicht einfach weitergegeben werden können.
