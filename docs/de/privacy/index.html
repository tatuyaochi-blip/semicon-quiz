Datenschutzerklärung

Halbleiter-Raum („diese Website“) behandelt Informationen über ihre Nutzerinnen und Nutzer wie folgt.

Personenbezogene Daten

Diese Website hat keine Benutzerregistrierung und erhebt zum Ansehen oder Beantworten von Fragen keine personenbezogenen Daten wie Namen oder E-Mail-Adressen.

Im Browser gespeicherte Daten

Diese Website speichert Ihre Antwortdaten (richtig oder falsch, Zeitpunkt der Antwort und Sitzungsverlauf) sowie Einstellungen wie die gewählte Sprache im localStorage Ihres Browsers. Diese Daten bleiben auf Ihrem Gerät und werden nie an unsere Server übertragen. Sie können sie mit der Zurücksetzen-Schaltfläche auf der Fortschrittsseite oder durch Löschen der Websitedaten im Browser entfernen.

Cookies

Cookies sind kleine Datenmengen, die eine Website in Ihrem Browser speichert. Diese Website selbst verwendet keine Cookies, der unten beschriebene Werbedienst und das Analysewerkzeug jedoch schon. Sie können Cookies in den Browsereinstellungen deaktivieren oder löschen. Auch ohne Cookies können Sie die Fragen beantworten, allerdings kann sich die angezeigte Werbung ändern.

Werbung und Analyse

Diese Website nutzt den Werbedienst eines Drittanbieters, Google AdSense. Drittanbieter wie Google verwenden Cookies, um Anzeigen auf Grundlage früherer Besuche dieser und anderer Websites auszuspielen. Personalisierte Werbung können Sie in den Google-Anzeigeneinstellungen deaktivieren. Weitere Informationen finden Sie unter Wie Google Cookies in der Werbung verwendet. Auf der Quizseite werden keine Anzeigen angezeigt.

Bei der Vorstellung von Büchern oder Diensten kann diese Website Affiliate-Programme (erfolgsabhängige Werbung) nutzen. Wenn über einen solchen Link ein Produkt gekauft oder ein Dienst abgeschlossen wird, kann diese Website vom Anbieter eine Vermittlungsprovision erhalten. Die Provision hat keinen Einfluss auf Fragen und Erläuterungen. Links und Bereiche mit Werbung sind mit „PR“ oder „Anzeige“ gekennzeichnet.

Diese Website verwendet Google Analytics, um die Nutzung zu analysieren. Google Analytics setzt Cookies ein und erfasst Informationen in einer Form, die keine Rückschlüsse auf einzelne Personen zulässt. Die erfassten Daten werden gemäß der Datenschutzerklärung von Google verarbeitet. Die Datenerfassung können Sie mit dem Browser-Add-on zur Deaktivierung von Google Analytics unterbinden. Weitere Informationen finden Sie unter Wie Google Daten von Websites oder Apps verwendet, die Google-Dienste nutzen.

An Dritte übermittelte Informationen

Wenn Sie eine Seite dieser Website öffnen, können Informationen über Sie an die folgenden Unternehmen übermittelt werden.

  • Google AdSense (Google LLC): URL der aufgerufenen Seite, IP-Adresse, Browsertyp, Cookie-Kennungen und ähnliche Daten, die zur Auslieferung von Werbung und zur Messung ihrer Wirkung verwendet werden (Datenschutzerklärung von Google).
  • Google Analytics (Google LLC): URL der aufgerufenen Seite, verweisende Seite, Browser- und Gerätetyp, ungefähre Region, Cookie-Kennungen und ähnliche Daten, die verwendet werden, um die Nutzung dieser Website zu verstehen und zu verbessern.

Darüber hinaus werden beim Öffnen des Kontaktformulars oder von Links zu externen Websites Informationen gemäß den Bedingungen des jeweiligen Dienstes an diesen übermittelt.

Kontaktformular

Für Anfragen nutzen wir einen externen Dienst (Google Formulare). Ihre Eingaben werden nur zur Beantwortung und zur Verbesserung dieser Website verwendet und nicht an Dritte weitergegeben, außer wenn dies gesetzlich vorgeschrieben ist.

Hosting

Diese Website wird über GitHub Pages bereitgestellt. Informationen wie IP-Adressen beim Zugriff werden von GitHub nach dessen eigenen Richtlinien verarbeitet.

Änderungen
