半導体用語集

試験勉強でよく出てくる基本用語をまとめました。キーワードで絞り込めます。

RCA洗浄あーるしーえーせんじょう
SC-1(アンモニア・過酸化水素水)でパーティクルや有機物を、SC-2(塩酸・過酸化水素水)で金属汚染を除去する洗浄法。 関連：CMP・洗浄 →
IGBTあいじーびーてぃー
絶縁ゲートバイポーラトランジスタ。MOSゲートで駆動し、伝導度変調によって高耐圧でも低いオン電圧を得られる。 関連：パワー半導体 →
アクセプタあくせぷた
半導体から電子を受け取り、正孔を生じさせる不純物。シリコンに対してはホウ素(B)などのIII族元素で、p型半導体をつくる。 関連：半導体物性 →
アニールあにーる
熱処理のこと。イオン注入後の結晶欠陥の回復や不純物の活性化などに用いる。 関連：イオン注入 →
SDS(安全データシート)あんぜんでーたしーと
化学物質の危険有害性、取り扱い方法、応急措置などを記載した文書。 関連：環境安全 →
EUV露光いーゆーぶいろこう
波長13.5 nmの極端紫外光を使う露光技術。反射光学系と真空環境を用いる。 関連：リソグラフィ →
イオン注入いおんちゅうにゅう
不純物をイオン化し、加速してウエハに打ち込む技術。注入量と深さを精密に制御できる。 関連：イオン注入 →
移動度いどうど
電界をかけたときのキャリアの動きやすさ。シリコンでは電子の移動度が正孔より大きい。 関連：半導体物性 →
異方性エッチングいほうせいえっちんぐ
特定の方向(主に垂直方向)にだけエッチングが進む性質。微細パターンの加工に必要。 関連：エッチング →
HBMえいちびーえむ
複数のDRAMダイをTSVで積層し、非常に広いバス幅で高い帯域を実現するメモリ。 関連：先端技術(3D実装・チップレット) →
ALDえーえるでぃー
原子層堆積。前駆体ガスの自己制限的な表面反応を繰り返し、原子層単位で膜厚を制御する成膜法。 関連：成膜(CVD・PVD) →
エピタキシャル成長えぴたきしゃるせいちょう
単結晶基板の上に、基板の結晶方位をそろえて単結晶の薄膜を成長させる技術。 関連：エピタキシャル成長 →
MRAMえむらむ
磁気トンネル接合(MTJ)の磁化の向きによる抵抗の違いで情報を記憶する不揮発性メモリ。 関連：次世代メモリ →
エレクトロマイグレーションえれくとろまいぐれーしょん
電流によって配線の金属原子が移動する現象。ボイドやヒロックが生じ、断線や短絡の原因になる。 関連：信頼性 →
オペアンプおぺあんぷ
差動入力と高い増幅率をもつ増幅器。負帰還をかけて増幅回路やフィルタなどに使う。 関連：アナログ・電子回路 →
開口数(NA)かいこうすう
レンズが集められる光の角度の広がりを表す値。大きいほど解像度が高くなる。 関連：リソグラフィ →
キャッシュメモリきゃっしゅめもり
CPUの近くに置く高速・小容量のメモリ。よく使うデータを保持して主記憶との速度差を緩和する。主にSRAMでつくられる。 関連：CPU・アーキテクチャ →
空乏層くうぼうそう
PN接合の境界付近にできる、キャリアがほとんど存在しない領域。逆バイアスで広がる。 関連：PN接合・ダイオード →
サンプリング定理さんぷりんぐていり
信号に含まれる最高周波数の2倍より高い周波数で標本化すれば、元の信号を復元できるという定理。標本化定理ともいう。 関連：AD/DA変換 →
CMPしーえむぴー
化学機械研磨。スラリーの化学作用とパッドの機械的研磨を組み合わせてウエハ表面を平坦化する。 関連：CMP・洗浄 →
CD-SEMしーでぃーせむ
パターンの線幅(CD)を測定するための走査電子顕微鏡。リソグラフィやエッチング後の寸法管理に使われる。 関連：計測・分析 →
CVDしーぶいでぃー
化学気相成長。原料ガスの化学反応によってウエハ上に薄膜を堆積する方法。 関連：成膜(CVD・PVD) →
CMOSしーもす
nMOSとpMOSを相補的に組み合わせた回路方式。定常状態で貫通電流がほとんど流れず、消費電力が小さい。 関連：MOSFET →
しきい値電圧しきいちでんあつ
MOSFETでチャネル(反転層)が形成され、電流が流れ始めるゲート電圧。Vthと書く。 関連：MOSFET →
TSV(シリコン貫通電極)しりこんかんつうでんきょく
シリコン基板を貫通する電極。積層したチップどうしを上下に短い距離で接続する。 関連：先端技術(3D実装・チップレット) →
スパッタリングすぱったりんぐ
プラズマ中のイオンをターゲットに衝突させ、はじき出された原子をウエハに堆積させるPVDの一種。 関連：成膜(CVD・PVD) →
STA(静的タイミング解析)せいてきたいみんぐかいせき
テストパターンを使わずに回路の各パスの遅延を計算し、タイミング制約を満たしているかを検証する手法。 関連：LSI設計フロー・EDA →
センスアンプせんすあんぷ
メモリセルから読み出したわずかな電圧差を増幅し、0か1かを判定する回路。 関連：DRAM →
選択比せんたくひ
エッチングで、削りたい膜とマスクや下地膜とのエッチング速度の比。大きいほど下地を傷めにくい。 関連：エッチング →
ダマシン法だましんほう
絶縁膜に溝を掘って金属を埋め込み、余分な金属をCMPで除去して配線を形成する方法。Cu配線に用いる。 関連：配線プロセス →
SiC(炭化ケイ素)たんかけいそ
バンドギャップ約3.3 eVのワイドギャップ半導体。絶縁破壊電界が高く、高耐圧・低損失のパワーデバイスに使われる。 関連：パワー半導体 →
GaN(窒化ガリウム)ちっかがりうむ
バンドギャップ約3.4 eVのIII-V族化合物半導体。青色LEDや高周波・パワーデバイスに使われる。 関連：化合物半導体 →
チップレットちっぷれっと
機能ごとに分けてつくった小さなチップ。複数を1つのパッケージ内で接続して大きなシステムを構成する。 関連：先端技術(3D実装・チップレット) →
超純水ちょうじゅんすい
イオン・微粒子・有機物などを極限まで取り除いた水。ウエハの洗浄に大量に使われ、比抵抗などで純度を管理する。 関連：プロセス材料(ガス・薬液) →
直接遷移型ちょくせつせんいがた
伝導帯の底と価電子帯の頂上が同じ波数にあるバンド構造。電子と正孔の再結合で効率よく発光する。GaAsなど。 関連：化合物半導体 →
CZ法(チョクラルスキー法)ちょくらるすきーほう
るつぼで溶かしたシリコンに種結晶を浸し、回転させながら引き上げて単結晶をつくる方法。 関連：シリコンウエハ →
ツェナーダイオードつぇなーだいおーど
逆方向の降伏電圧がほぼ一定になることを利用して、定電圧を得るダイオード。 関連：PN接合・ダイオード →
DFT(テスト容易化設計)てすとよういかせっけい
スキャンチェーンやBISTなど、テストしやすくする仕組みをあらかじめ回路に組み込む設計手法。 関連：テスト・検査 →
電流増幅率(hFE)でんりゅうぞうふくりつ
バイポーラトランジスタのコレクタ電流とベース電流の比(IC/IB)。 関連：バイポーラトランジスタ →
ドナーどなー
半導体に電子を供給する不純物。シリコンに対してはリン(P)やヒ素(As)などのV族元素で、n型半導体をつくる。 関連：半導体物性 →
NAND型フラッシュメモリなんどがたふらっしゅめもり
メモリセルを直列に接続した構造の不揮発性メモリ。高集積で大容量化しやすく、SSDやメモリカードに使われる。 関連：SRAM・フラッシュメモリ →
SIMS(二次イオン質量分析法)にじいおんしつりょうぶんせきほう
一次イオンで試料を削りながら二次イオンを質量分析し、不純物の深さ方向の分布を高感度に測定する方法。 関連：計測・分析 →
熱酸化ねつさんか
シリコンを酸素や水蒸気の中で加熱し、表面にSiO2膜をつくる方法。ドライ酸化とウェット酸化がある。 関連：酸化・拡散 →
バーンインばーんいん
高温・高電圧などのストレスを加えて動作させ、初期故障を起こしやすい製品を出荷前に取り除く試験。 関連：テスト・検査 →
High-k/メタルゲートはいけーめたるげーと
高誘電率のゲート絶縁膜と金属のゲート電極の組み合わせ。ゲートリークを抑えながらゲート容量を確保できる。 関連：先端トランジスタ(FinFET・GAA) →
バスタブ曲線ばすたぶきょくせん
故障率の時間変化を表す曲線。初期故障期・偶発故障期・摩耗故障期からなり、浴槽のような形になる。 関連：信頼性 →
バンドギャップばんどぎゃっぷ
価電子帯の上端と伝導帯の下端とのエネルギー差。シリコンは室温で約1.12 eV。大きいほど高温・高電圧に強い。 関連：半導体物性 →
BGAびーじーえー
ボールグリッドアレイ。パッケージ裏面にはんだボールを格子状に並べた多ピン向けのパッケージ。 関連：パッケージ・実装 →
ファウンドリふぁうんどり
他社が設計した半導体の製造を専門に受託する企業や事業形態。 関連：半導体産業・市場 →
ファブレスふぁぶれす
自社で製造工場を持たず、半導体の設計と販売に特化する企業の形態。 関連：半導体産業・市場 →
FinFETふぃんふぇっと
ひれ(フィン)状に立てたチャネルをゲートが3方向から囲む立体構造のトランジスタ。短チャネル効果を抑えやすい。 関連：先端トランジスタ(FinFET・GAA) →
FOUPふーぷ
300 mmウエハを密閉した状態で搬送・保管するための容器。 関連：クリーンルーム・製造装置 →
フォトダイオードふぉとだいおーど
光を受けて電荷(電流)を発生させるダイオード。イメージセンサの画素の受光素子として使われる。 関連：イメージセンサ・光デバイス →
フォトレジストふぉとれじすと
光に反応して現像液への溶けやすさが変わる感光性材料。ポジ型は露光部が溶け、ネガ型は露光部が残る。 関連：リソグラフィ →
歩留まりぶどまり
投入した数に対する良品の割合。半導体の製造コストに大きく影響する指標。 関連：歩留まり・品質管理 →
フリップチップふりっぷちっぷ
チップの回路面を下に向け、バンプで基板と直接接続する実装方法。接続が短く多ピン化に向く。 関連：パッケージ・実装 →
フリップフロップふりっぷふろっぷ
1ビットの情報を保持する順序回路の基本素子。D型はクロックのエッジで入力を取り込む。 関連：論理回路 →
MEMSめむす
微小電気機械システム。半導体の微細加工技術で微小な機械構造と電子回路をつくり込んだデバイス。 関連：MEMS・センサ →
リフレッシュりふれっしゅ
DRAMのキャパシタの電荷がリークで失われる前に、定期的にデータを読み出して書き直す動作。 関連：DRAM →
Low-k材料ろーけーざいりょう
比誘電率の低い層間絶縁膜材料。配線間容量を下げ、信号遅延や消費電力を減らす。 関連：配線プロセス →
論理合成ろんりごうせい
RTLで記述された回路を、セルライブラリのゲートを使ったネットリストに変換する設計工程。 関連：LSI設計フロー・EDA →
ワイヤボンディングわいやぼんでぃんぐ
チップの電極パッドとリードフレームや基板を、金や銅などの細い金属線でつなぐ接続方法。 関連：パッケージ・実装 →
