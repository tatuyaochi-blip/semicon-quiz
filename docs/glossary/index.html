基礎

半導体物性この分野の問題 →

アクセプタあくせぷた
半導体から電子を受け取り、正孔を生じさせる不純物。シリコンに対してはホウ素(B)などのIII族元素で、p型半導体をつくる。
移動度いどうど
電界をかけたときのキャリアの動きやすさ。シリコンでは電子の移動度が正孔より大きい。
ドナーどなー
半導体に電子を供給する不純物。シリコンに対してはリン(P)やヒ素(As)などのV族元素で、n型半導体をつくる。
バンドギャップばんどぎゃっぷ
価電子帯の上端と伝導帯の下端とのエネルギー差。シリコンは室温で約1.12 eV。大きいほど高温・高電圧に強い。
フェルミ準位ふぇるみじゅんい
電子がその準位を占める確率がちょうど1/2になるエネルギー。n型では伝導帯側に、p型では価電子帯側に寄る。

PN接合・ダイオードこの分野の問題 →

空乏層くうぼうそう
PN接合の境界付近にできる、キャリアがほとんど存在しない領域。逆バイアスで広がる。
順方向バイアスじゅんほうこうばいあす
p側に正、n側に負の電圧をかけること。障壁が下がって電流がよく流れる。逆にかけると逆方向バイアスで、電流はほとんど流れない。
ツェナーダイオードつぇなーだいおーど
逆方向の降伏電圧がほぼ一定になることを利用して、定電圧を得るダイオード。
内蔵電位ないぞうでんい
PN接合の空乏層に、外から電圧をかけなくても生じている電位差。シリコンでは0.6〜0.8 V程度で、キャリアの拡散を止める障壁になる。
なだれ降伏なだれこうふく
逆方向の強い電界で加速されたキャリアが原子にぶつかって新たなキャリアをつくり、それが連鎖的に増えて大電流が流れる現象。

バイポーラトランジスタこの分野の問題 →

アーリー効果あーりーこうか
コレクタ電圧が上がるとベース-コレクタ間の空乏層が広がって実効的なベース幅が狭まり、コレクタ電流が少し増える現象。
HBT(ヘテロ接合バイポーラトランジスタ)えいちびーてぃー
エミッタとベースにバンドギャップの異なる材料を使ったバイポーラトランジスタ。SiGeやGaAs系などがあり、高周波の増幅器に使われる。
エミッタ接地回路えみったせっちかいろ
エミッタを入力と出力の共通端子にした増幅回路。電流利得と電圧利得の両方が得られ、最もよく使われる。
電流増幅率(hFE)でんりゅうぞうふくりつ
バイポーラトランジスタのコレクタ電流とベース電流の比(IC/IB)。
能動領域のうどうりょういき
ベース-エミッタ間を順方向、ベース-コレクタ間を逆方向にバイアスした状態。ベース電流に比例したコレクタ電流が流れ、増幅に使う。

MOSFETこの分野の問題 →

サブスレッショルドスイングさぶすれっしょるどすいんぐ
しきい値電圧以下で、ドレイン電流を10倍変えるのに必要なゲート電圧。室温での理論的な下限は約60 mV/桁で、小さいほどオンとオフの切り替えが鋭い。
CMOSしーもす
nMOSとpMOSを相補的に組み合わせた回路方式。定常状態で貫通電流がほとんど流れず、消費電力が小さい。
しきい値電圧しきいちでんあつ
MOSFETでチャネル(反転層)が形成され、電流が流れ始めるゲート電圧。Vthと書く。
短チャネル効果たんちゃねるこうか
ゲート長が短くなると、ドレインの電界の影響でしきい値電圧が下がったり、オフ時のリーク電流が増えたりする現象。
反転層はんてんそう
ゲート電圧によって半導体表面に、もとの型と逆のキャリアが集まってできる層。MOSFETのチャネルになる。

論理回路この分野の問題 →

組み合わせ回路くみあわせかいろ
出力がそのときの入力だけで決まる論理回路。加算器やマルチプレクサ、デコーダなど。
順序回路じゅんじょかいろ
フリップフロップなどで状態を記憶し、出力が入力と過去の状態の両方で決まる論理回路。カウンタやレジスタなど。
真理値表しんりちひょう
入力のすべての組み合わせに対する出力を一覧にした表。論理回路の動作を表すのに使う。
ド・モルガンの定理どもるがんのていり
「AかつBの否定は、Aの否定またはBの否定」「AまたはBの否定は、Aの否定かつBの否定」という論理式の変換規則。
フリップフロップふりっぷふろっぷ
1ビットの情報を保持する順序回路の基本素子。D型はクロックのエッジで入力を取り込む。

アナログ・電子回路この分野の問題 →

オペアンプおぺあんぷ
差動入力と高い増幅率をもつ増幅器。負帰還をかけて増幅回路やフィルタなどに使う。
カットオフ周波数かっとおふしゅうはすう
フィルタや増幅器の出力が通過域から3 dB(約0.707倍)下がる周波数。RC回路では1/(2πRC)。
差動増幅回路さどうぞうふくかいろ
2つの入力の差を増幅し、両方に共通な成分(雑音など)は打ち消す回路。オペアンプの入力段に使われる。
負帰還ふきかん
出力の一部を入力に逆の極性で戻すこと。増幅率は下がるが、利得が安定し、ひずみや帯域が改善する。
ボルテージフォロワぼるてーじふぉろわ
出力を反転入力に直接つないだ、利得1のオペアンプ回路。入力インピーダンスが高く出力インピーダンスが低いので、バッファに使う。

AD/DA変換この分野の問題 →

エイリアシングえいりあしんぐ
サンプリング周波数の半分を超える成分が、低い周波数の成分として誤って現れる現象。AD変換の前にローパスフィルタで防ぐ。
サンプリング定理さんぷりんぐていり
信号に含まれる最高周波数の2倍より高い周波数で標本化すれば、元の信号を復元できるという定理。標本化定理ともいう。
逐次比較型ADCちくじひかくがたえーでぃーしー
内部のDACと比較器を使い、上位ビットから1ビットずつ決めていくADC。速度と精度、消費電力のバランスがよい。
ΔΣ型ADCでるたしぐまがたえーでぃーしー
高い周波数でオーバーサンプリングし、量子化雑音を高い周波数へ追いやってから取り除くADC。音声や計測などの高分解能の用途に使う。
量子化誤差りょうしかごさ
連続したアナログ値を有限のビット数のデジタル値に丸めるときに生じる誤差。最大で1 LSBの半分。

デバイス

DRAMこの分野の問題 →

センスアンプせんすあんぷ
メモリセルから読み出したわずかな電圧差を増幅し、0か1かを判定する回路。
ビット線びっとせん
メモリセルのデータを読み書きするための配線。DRAMでは、セルの電荷によるビット線の小さな電位の変化をセンスアンプで増幅する。
リフレッシュりふれっしゅ
DRAMのキャパシタの電荷がリークで失われる前に、定期的にデータを読み出して書き直す動作。
ワード線わーどせん
メモリセルのトランジスタのゲートにつながり、読み書きする行を選ぶ配線。
1T1Cセルわんてぃーわんしーせる
1個のトランジスタと1個のキャパシタで1ビットを記憶するDRAMのメモリセル。キャパシタの電荷の有無で0と1を表す。

SRAM・フラッシュメモリこの分野の問題 →

ウェアレベリングうぇあれべりんぐ
フラッシュメモリの書き換えが特定のブロックに集中しないよう、書き込み先を分散させて寿命を延ばす技術。
NAND型フラッシュメモリなんどがたふらっしゅめもり
メモリセルを直列に接続した構造の不揮発性メモリ。高集積で大容量化しやすく、SSDやメモリカードに使われる。
NOR型フラッシュメモリのあがたふらっしゅめもり
セルを並列に接続したフラッシュメモリ。ランダムな読み出しが速く、マイコンのプログラムの格納などに使われる。
不揮発性メモリふきはつせいめもり
電源を切っても記憶したデータが消えないメモリ。フラッシュメモリやMRAMなど。DRAMやSRAMは揮発性。
6T SRAMセルろくてぃーえすらむせる
交差接続した2つのインバータ(4個)と、アクセス用の2個のトランジスタからなるSRAMのメモリセル。

次世代メモリこの分野の問題 →

FeRAM(強誘電体メモリ)えふいーらむ
強誘電体の分極の向きで情報を記憶する不揮発性メモリ。書き込みが速く低電力で、ICカードなどに使われる。
MRAMえむらむ
磁気トンネル接合(MTJ)の磁化の向きによる抵抗の違いで情報を記憶する不揮発性メモリ。
磁気トンネル接合(MTJ)じきとんねるせつごう
薄い絶縁膜を2つの磁性層で挟んだ構造。2層の磁化の向きがそろうと抵抗が低く、逆向きだと高くなる。MRAMの記憶素子。
PCM(相変化メモリ)ぴーしーえむ
カルコゲナイド材料の結晶状態(低抵抗)とアモルファス状態(高抵抗)の違いで情報を記憶する不揮発性メモリ。
ReRAM(抵抗変化メモリ)りらむ
電圧をかけて酸化物などの中に導電パスをつくったり切ったりし、抵抗の違いで情報を記憶する不揮発性メモリ。

CPU・アーキテクチャこの分野の問題 →

キャッシュメモリきゃっしゅめもり
CPUの近くに置く高速・小容量のメモリ。よく使うデータを保持して主記憶との速度差を緩和する。主にSRAMでつくられる。
ノイマン型アーキテクチャのいまんがたあーきてくちゃ
プログラムとデータを同じ主記憶に置き、命令を順に読み出して実行するコンピュータの構成。
パイプライン処理ぱいぷらいんしょり
命令の処理を取り出し・解読・実行などの段階に分け、複数の命令を少しずつずらして同時に処理する方式。
分岐予測ぶんきよそく
条件分岐の結果を実行前に予測し、パイプラインを止めずに先の命令を処理する技術。予測が外れると処理をやり直す。
命令セットアーキテクチャ(ISA)めいれいせっとあーきてくちゃ
プロセッサが実行できる命令やレジスタなど、ソフトウェアから見たプロセッサの仕様。x86、Arm、RISC-Vなど。

パワー半導体この分野の問題 →

IGBTあいじーびーてぃー
絶縁ゲートバイポーラトランジスタ。MOSゲートで駆動し、伝導度変調によって高耐圧でも低いオン電圧を得られる。
オン抵抗おんていこう
パワー半導体がオンのときの、電流が流れる経路の抵抗。小さいほど導通時の損失が少ない。
スイッチング損失すいっちんぐそんしつ
パワー半導体がオンとオフを切り替える途中で、電圧と電流が同時にかかることで生じる損失。周波数が高いほど大きくなる。
SiC(炭化ケイ素)たんかけいそ
バンドギャップ約3.3 eVのワイドギャップ半導体。絶縁破壊電界が高く、高耐圧・低損失のパワーデバイスに使われる。
パワーMOSFETぱわーもすえふいーてぃー
大きな電流や電圧を扱えるようにしたMOSFET。スイッチングが速く、電源回路などで広く使われる。

イメージセンサ・光デバイスこの分野の問題 →

グローバルシャッターぐろーばるしゃったー
すべての画素を同時に露光する電子シャッター方式。行ごとに順に読み出すローリングシャッターと違い、動く物の像がゆがまない。
CMOSイメージセンサーしーもすいめーじせんさー
画素ごとに増幅回路をもち、CMOSプロセスで作るイメージセンサー。低消費電力で周辺回路を集積でき、スマートフォンのカメラなどの主流。
フォトダイオードふぉとだいおーど
光を受けて電荷(電流)を発生させるダイオード。イメージセンサの画素の受光素子として使われる。
裏面照射型(BSI)りめんしょうしゃがた
配線層のない基板の裏側から光を入れる構造のイメージセンサー。配線に光がさえぎられず、小さな画素でも感度が高い。
量子効率りょうしこうりつ
入射した光子のうち、信号となる電子に変換される割合。高いほど感度がよい。

化合物半導体この分野の問題 →

III-V族化合物半導体さんごぞくかごうぶつはんどうたい
III族元素(Ga、In、Alなど)とV族元素(As、P、Nなど)からなる半導体。GaAs、InP、GaNなど。
GaN(窒化ガリウム)ちっかがりうむ
バンドギャップ約3.4 eVのIII-V族化合物半導体。青色LEDや高周波・パワーデバイスに使われる。
直接遷移型ちょくせつせんいがた
伝導帯の底と価電子帯の頂上が同じ波数にあるバンド構造。電子と正孔の再結合で効率よく発光する。GaAsなど。
HEMT(高電子移動度トランジスタ)へむと
ヘテロ接合の界面にできる高移動度の2次元電子ガスをチャネルに使うトランジスタ。高周波・高出力の用途に使われる。
ワイドバンドギャップ半導体わいどばんどぎゃっぷはんどうたい
シリコンよりバンドギャップが大きい半導体。SiCやGaNなど。絶縁破壊電界が高く、高電圧・高温での動作に強い。

先端トランジスタ(FinFET・GAA)この分野の問題 →

GAA(ゲートオールアラウンド)じーえーえー
チャネルの周囲を全方向からゲートで囲むトランジスタ構造。FinFETより電流の制御性が高く、FinFETの次の世代で使われる。
CFET(相補型FET)しーふぇっと
nMOSとpMOSのトランジスタを縦に積み重ねる構造。CMOSの回路の面積を大きく縮小できるとして開発が進められている。
ナノシートなのしーと
薄い板状のシリコンのチャネルを縦に何枚も積み重ね、それぞれをゲートで囲むGAAトランジスタの構造。シートの幅で電流を調整できる。
High-k/メタルゲートはいけーめたるげーと
高誘電率のゲート絶縁膜と金属のゲート電極の組み合わせ。ゲートリークを抑えながらゲート容量を確保できる。
FinFETふぃんふぇっと
ひれ(フィン)状に立てたチャネルをゲートが3方向から囲む立体構造のトランジスタ。短チャネル効果を抑えやすい。

MEMS・センサこの分野の問題 →

加速度センサーかそくどせんさー
ばねで支えた小さなおもりの動きから加速度を検出するセンサー。スマートフォンの向きの検出やエアバッグなどに使われる。
犠牲層エッチングぎせいそうえっちんぐ
構造の下に一時的に置いた層(犠牲層)をエッチングで取り除き、動ける梁や膜を浮かせる、MEMSの代表的な加工法。
ジャイロスコープじゃいろすこーぷ
回転の速さ(角速度)を検出するセンサー。MEMSのものは振動する構造に働くコリオリ力を利用する。
静電容量検出せいでんようりょうけんしゅつ
可動電極と固定電極の間の静電容量の変化から、変位や圧力などを検出する方式。MEMSセンサーで広く使われる。
MEMSめむす
微小電気機械システム。半導体の微細加工技術で微小な機械構造と電子回路をつくり込んだデバイス。

前工程

シリコンウエハこの分野の問題 →

ウエハのノッチうえはののっち
ウエハの結晶方位を示すために外周に設けた小さな切り欠き。200 mm以上のウエハで使われ、それ以前はオリエンテーションフラット(直線部)が使われた。
FZ法(フローティングゾーン法)えふぜっとほう
多結晶シリコンの棒の一部を加熱して溶かし、その溶けた帯を移動させて単結晶にする方法。るつぼを使わないため酸素が少なく、高抵抗のウエハに向く。
結晶方位けっしょうほうい
結晶の面や方向の向きを表すもの。(100)のようにミラー指数で表し、MOSFET用のシリコンウエハでは(100)面が一般的。
ゲッタリングげったりんぐ
ウエハの中の金属不純物を、素子をつくる表面から離れた場所に集めて捕らえる技術。酸素析出物などを利用する。
CZ法(チョクラルスキー法)ちょくらるすきーほう
るつぼで溶かしたシリコンに種結晶を浸し、回転させながら引き上げて単結晶をつくる方法。

エピタキシャル成長この分野の問題 →

エピタキシャル成長えぴたきしゃるせいちょう
単結晶基板の上に、基板の結晶方位をそろえて単結晶の薄膜を成長させる技術。
MOCVD(有機金属気相成長)えむおーしーぶいでぃー
有機金属化合物とアンモニアなどの原料ガスを使って結晶を成長させる方法。GaNやGaAsなどの化合物半導体の成長に広く使われる。
格子不整合こうしふせいごう
成長させる膜と基板の結晶の原子の間隔(格子定数)が異なること。大きいとひずみや転位などの欠陥が生じる。
選択エピタキシャル成長せんたくえぴたきしゃるせいちょう
絶縁膜で覆われていない、シリコンが露出した部分だけに結晶を成長させる方法。トランジスタのソース・ドレインのSiGeなどに使われる。
ヘテロエピタキシーへてろえぴたきしー
基板と異なる材料の単結晶膜を成長させること。シリコン上のSiGeや、サファイア上のGaNなど。同じ材料の場合はホモエピタキシー。

酸化・拡散この分野の問題 →

ウェット酸化うぇっとさんか
水蒸気を含む雰囲気で行う熱酸化。ドライ酸化より成長が速く、厚い酸化膜をつくるのに使われる。
ドライ酸化どらいさんか
乾燥した酸素で行う熱酸化。成長は遅いが、緻密で良質な酸化膜ができ、ゲート酸化膜などに使われる。
熱拡散ねつかくさん
高温で不純物原子を半導体の中へ拡散させてドーピングする方法。濃度の高いところから低いところへ広がる。
熱酸化ねつさんか
シリコンを酸素や水蒸気の中で加熱し、表面にSiO2膜をつくる方法。ドライ酸化とウェット酸化がある。
LOCOSろこす
窒化膜で覆っていない部分だけを厚く酸化して素子間を分離する方法。端に鳥のくちばし状の食い込み(バーズビーク)ができ、現在はSTIに置き換わった。

イオン注入この分野の問題 →

アニールあにーる
熱処理のこと。イオン注入後の結晶欠陥の回復や不純物の活性化などに用いる。
イオン注入いおんちゅうにゅう
不純物をイオン化し、加速してウエハに打ち込む技術。注入量と深さを精密に制御できる。
チャネリングちゃねりんぐ
イオンが結晶の原子の並びのすき間を通り抜けて、予想より深くまで入り込む現象。ウエハを傾けて注入するなどして防ぐ。
投影飛程とうえいひてい
注入したイオンが止まる深さの平均。加速エネルギーが大きいほど深く、イオンが軽いほど深くなる。
ドーズ量どーずりょう
イオン注入で、単位面積あたりに打ち込むイオンの数。cm⁻²の単位で表し、ビーム電流と注入時間で決まる。

成膜(CVD・PVD)この分野の問題 →

ALDえーえるでぃー
原子層堆積。前駆体ガスの自己制限的な表面反応を繰り返し、原子層単位で膜厚を制御する成膜法。
CVDしーぶいでぃー
化学気相成長。原料ガスの化学反応によってウエハ上に薄膜を堆積する方法。
ステップカバレッジすてっぷかばれっじ
段差や穴の側面・底面に、平らな部分と比べてどれだけ均一な厚さで膜がつくかを表す指標。ALDは非常によい。
スパッタリングすぱったりんぐ
プラズマ中のイオンをターゲットに衝突させ、はじき出された原子をウエハに堆積させるPVDの一種。
PECVD(プラズマCVD)ぴーいーしーぶいでぃー
プラズマで原料ガスを分解して膜を堆積するCVD。熱CVDより低い温度で成膜でき、配線工程の絶縁膜などに使われる。

リソグラフィこの分野の問題 →

EUV露光いーゆーぶいろこう
波長13.5 nmの極端紫外光を使う露光技術。反射光学系と真空環境を用いる。
液浸露光えきしんろこう
レンズとウエハの間を水で満たして露光する方法。開口数を1以上にでき、ArFエキシマレーザーでより細かいパターンを形成できる。
OPC(光学近接効果補正)おーぴーしー
光の回折などでパターンがゆがむのを見越して、マスクのパターンをあらかじめ補正しておく技術。
開口数(NA)かいこうすう
レンズが集められる光の角度の広がりを表す値。大きいほど解像度が高くなる。
フォトレジストふぉとれじすと
光に反応して現像液への溶けやすさが変わる感光性材料。ポジ型は露光部が溶け、ネガ型は露光部が残る。

エッチングこの分野の問題 →

RIE(反応性イオンエッチング)あーるあいいー
プラズマ中の反応性の粒子と、電界で加速したイオンを組み合わせて削るドライエッチング。垂直な異方性の加工ができる。
異方性エッチングいほうせいえっちんぐ
特定の方向(主に垂直方向)にだけエッチングが進む性質。微細パターンの加工に必要。
ウェットエッチングうぇっとえっちんぐ
薬液に浸して膜を溶かして削る方法。選択比が高く損傷も少ないが、一般に等方的に進むため微細な加工には向かない。
選択比せんたくひ
エッチングで、削りたい膜とマスクや下地膜とのエッチング速度の比。大きいほど下地を傷めにくい。
等方性エッチングとうほうせいえっちんぐ
縦にも横にも同じ速さで削れるエッチング。マスクの下に回り込んで削れる(アンダーカット)。

CMP・洗浄この分野の問題 →

RCA洗浄あーるしーえーせんじょう
SC-1(アンモニア・過酸化水素水)でパーティクルや有機物を、SC-2(塩酸・過酸化水素水)で金属汚染を除去する洗浄法。
CMPしーえむぴー
化学機械研磨。スラリーの化学作用とパッドの機械的研磨を組み合わせてウエハ表面を平坦化する。
スラリーすらりー
CMPで使う、微細な研磨粒子を薬液に分散させた液体。化学的な作用と機械的な研磨を組み合わせて表面を平らにする。
ディッシングでぃっしんぐ
CMPで、幅の広い金属配線の中央部が皿のようにくぼんで削れすぎる現象。
メガソニック洗浄めがそにっくせんじょう
約1 MHzの超音波を洗浄液に加えて、ウエハ表面の微粒子を取り除く洗浄方法。

配線プロセスこの分野の問題 →

RC遅延あーるしーちえん
配線の抵抗(R)と容量(C)の積で決まる信号の遅れ。微細化で配線が細くなるほど大きくなり、性能を制限する。
多層配線たそうはいせん
絶縁膜を挟んで配線の層を何層も重ね、ビアで上下をつなぐ構造。先端のLSIでは10層以上になる。
ダマシン法だましんほう
絶縁膜に溝を掘って金属を埋め込み、余分な金属をCMPで除去して配線を形成する方法。Cu配線に用いる。
バリアメタルばりあめたる
銅配線の周りに設け、銅が絶縁膜やシリコンへ拡散するのを防ぐ薄い金属膜。TaやTaNなど。
Low-k材料ろーけーざいりょう
比誘電率の低い層間絶縁膜材料。配線間容量を下げ、信号遅延や消費電力を減らす。

プロセス材料(ガス・薬液)この分野の問題 →

NF3(三フッ化窒素)えぬえふすりー
CVD装置のチャンバーのクリーニングなどに使われるガス。地球温暖化係数が大きく、排出の削減が求められる。
超純水ちょうじゅんすい
イオン・微粒子・有機物などを極限まで取り除いた水。ウエハの洗浄に大量に使われ、比抵抗などで純度を管理する。
TMAHてぃーえむえーえいち
水酸化テトラメチルアンモニウム。金属イオンを含まない有機アルカリで、フォトレジストの現像液に使われる。皮膚からの吸収による中毒に注意が必要。
特殊材料ガスとくしゅざいりょうがす
シラン、アルシン、ホスフィンなど、半導体の製造に使う毒性や可燃性をもつ高純度のガス。厳重な管理のもとで供給される。
プリカーサ(前駆体)ぷりかーさ
CVDやALDで、反応して目的の膜になる原料の化合物。TEOSや有機金属化合物など。

後工程・評価

パッケージ・実装この分野の問題 →

アンダーフィルあんだーふぃる
フリップチップで、チップと基板の隙間に充填する樹脂。熱膨張の差による応力を分散し、バンプの接続を守る。
BGAびーじーえー
ボールグリッドアレイ。パッケージ裏面にはんだボールを格子状に並べた多ピン向けのパッケージ。
フリップチップふりっぷちっぷ
チップの回路面を下に向け、バンプで基板と直接接続する実装方法。接続が短く多ピン化に向く。
リードフレームりーどふれーむ
チップを載せる台と外部端子(リード)を一体にした金属の薄板。QFPなどのパッケージで使われる。
ワイヤボンディングわいやぼんでぃんぐ
チップの電極パッドとリードフレームや基板を、金や銅などの細い金属線でつなぐ接続方法。

テスト・検査この分野の問題 →

ATE(自動試験装置)えーてぃーいー
チップに試験パターンを与えて出力を測り、良否を自動で判定する装置。テスタとも呼ばれる。
スキャンテストすきゃんてすと
回路の中のフリップフロップを鎖状につないだスキャンチェーンを使い、内部の状態を設定・観測してテストする方法。
DFT(テスト容易化設計)てすとよういかせっけい
スキャンチェーンやBISTなど、テストしやすくする仕組みをあらかじめ回路に組み込む設計手法。
バーンインばーんいん
高温・高電圧などのストレスを加えて動作させ、初期故障を起こしやすい製品を出荷前に取り除く試験。
プローブカードぷろーぶかーど
ウエハの状態でチップの電極に多数の針(プローブ)を当て、テスタと電気的につなぐための治具。

計測・分析この分野の問題 →

エリプソメトリえりぷそめとり
偏光した光を当てて、反射による偏光状態の変化から薄膜の厚さや屈折率を求める測定法。非破壊で測れる。
CD-SEMしーでぃーせむ
パターンの線幅(CD)を測定するための走査電子顕微鏡。リソグラフィやエッチング後の寸法管理に使われる。
TEM(透過電子顕微鏡)てぃーいーえむ
薄くした試料に電子線を透過させて観察する顕微鏡。原子レベルの分解能で、断面の構造や結晶の欠陥を調べられる。
SIMS(二次イオン質量分析法)にじいおんしつりょうぶんせきほう
一次イオンで試料を削りながら二次イオンを質量分析し、不純物の深さ方向の分布を高感度に測定する方法。
四探針法よんたんしんほう
一直線に並べた4本の針の外側2本に電流を流し、内側2本の電圧を測って、ウエハや薄膜のシート抵抗を求める方法。

歩留まり・品質管理この分野の問題 →

SPC(統計的工程管理)えすぴーしー
工程のデータを管理図などで監視し、統計的に異常を見つけて品質を保つ方法。
キラー欠陥きらーけっかん
チップを不良にしてしまう欠陥。配線のショートや断線を起こす大きさ・位置の粒子やパターン異常など。
工程能力指数(Cpk)こうていのうりょくしすう
工程のばらつきと平均のずれが、規格の範囲に対してどれだけ余裕があるかを表す指標。1.33以上が一つの目安。
歩留まりぶどまり
投入した数に対する良品の割合。半導体の製造コストに大きく影響する指標。
ポアソン歩留まりモデルぽあそんぶどまりもでる
欠陥がランダムに分布すると仮定し、歩留まりを Y = exp(−D×A)(Dは欠陥密度、Aはチップ面積)で表すモデル。

信頼性この分野の問題 →

NBTIえぬびーてぃーあい
pMOSのゲートに負の電圧をかけた状態で温度が高いと、しきい値電圧の絶対値が徐々に大きくなる劣化現象。
MTTF(平均故障時間)えむてぃーてぃーえふ
修理しない製品が故障するまでの時間の平均。製品の寿命の目安として使う。
エレクトロマイグレーションえれくとろまいぐれーしょん
電流によって配線の金属原子が移動する現象。ボイドやヒロックが生じ、断線や短絡の原因になる。
TDDB(経時絶縁破壊)てぃーでぃーでぃーびー
絶縁膜に電圧をかけ続けると、破壊電圧より低い電圧でもいずれ絶縁破壊に至る現象。ゲート酸化膜などの寿命の評価に使う。
バスタブ曲線ばすたぶきょくせん
故障率の時間変化を表す曲線。初期故障期・偶発故障期・摩耗故障期からなり、浴槽のような形になる。

設計・産業

LSI設計フロー・EDAこの分野の問題 →

RTL(レジスタ転送レベル)あーるてぃーえる
レジスタの間でデータがどのように転送・処理されるかで回路を記述する設計の抽象度。VerilogやVHDLで書き、論理合成の入力になる。
STA(静的タイミング解析)せいてきたいみんぐかいせき
テストパターンを使わずに回路の各パスの遅延を計算し、タイミング制約を満たしているかを検証する手法。
DRC(デザインルールチェック)でぃーあーるしー
レイアウトが、線幅や間隔など製造のための幾何学的な規則を守っているかを調べる検証。
配置配線はいちはいせん
論理合成で得たネットリストをもとに、セルをチップ上に並べ(配置)、セルの間をつなぐ配線を決める(配線)設計の工程。
論理合成ろんりごうせい
RTLで記述された回路を、セルライブラリのゲートを使ったネットリストに変換する設計工程。

クリーンルーム・製造装置この分野の問題 →

ISO 14644-1あいえすおー14644-1
クリーンルームの清浄度のクラスを、空気中の粒子の数で定めた国際規格。数字が小さいほど清浄度が高い。
ULPAフィルタうるぱふぃるた
HEPAフィルタよりさらに微細な粒子まで捕集する高性能のエアフィルタ。高い清浄度のクリーンルームの天井に使われる。
ダウンフローだうんふろー
天井全面から床へ一方向に清浄な空気を流す、クリーンルームの気流の方式。発生した粒子をすばやく床下へ排出する。
FOUPふーぷ
300 mmウエハを密閉した状態で搬送・保管するための容器。
分子状汚染(AMC)ぶんしじょうおせん
空気中の酸、アルカリ、有機物などのガス状の汚染物質。粒子用のフィルタでは除けず、ケミカルフィルタで取り除く。

環境安全この分野の問題 →

SDS(安全データシート)あんぜんでーたしーと
化学物質の危険有害性、取り扱い方法、応急措置などを記載した文書。
GHSじーえいちえす
化学品の危険有害性を、絵表示と注意書きで国際的に統一して示す仕組み。
除害装置じょがいそうち
製造装置から出る排ガスに含まれる有害な物質を、燃焼・吸着・水洗などで取り除く装置。
パーフルオロカーボンぱーふるおろかーぼん
PFCとも。CF4やC2F6など、エッチングやチャンバーのクリーニングに使われるフッ素化合物のガス。温室効果が非常に大きい。
RoHS指令ろーずしれい
電気電子機器に含まれる鉛や水銀などの特定有害物質の使用を制限するEUの規制。

半導体産業・市場この分野の問題 →

IDM(垂直統合型デバイスメーカー)あいでぃーえむ
設計から前工程・後工程の製造、販売までを自社で一貫して行う半導体企業。
OSATおーさっと
半導体の組立やテストなどの後工程を受託する企業。
ファウンドリふぁうんどり
他社が設計した半導体の製造を専門に受託する企業や事業形態。
ファブレスふぁぶれす
自社で製造工場を持たず、半導体の設計と販売に特化する企業の形態。
ムーアの法則むーあのほうそく
集積回路に載るトランジスタの数が約2年ごとに倍増するという経験則。半導体の微細化の目標とされてきた。

先端技術(3D実装・チップレット)この分野の問題 →

HBMえいちびーえむ
複数のDRAMダイをTSVで積層し、非常に広いバス幅で高い帯域を実現するメモリ。
シリコンインターポーザしりこんいんたーぽーざ
複数のチップを並べて載せ、微細な配線で高密度に接続するシリコンの中継基板。GPUとHBMの接続などに使われる。
TSV(シリコン貫通電極)しりこんかんつうでんきょく
シリコン基板を貫通する電極。積層したチップどうしを上下に短い距離で接続する。
チップレットちっぷれっと
機能ごとに分けてつくった小さなチップ。複数を1つのパッケージ内で接続して大きなシステムを構成する。
ハイブリッドボンディングはいぶりっどぼんでぃんぐ
バンプを使わず、銅の電極と絶縁膜の面どうしを直接接合する技術。極めて狭いピッチで多数の接続ができる。
