ARM・RISC-V・x86の違い：命令セットアーキテクチャを比較

ARM、RISC-V、x86は、3つの命令セットアーキテクチャ(ISA)で、ソフトウェアとプロセッサの間の約束事です。ARMとRISC-Vは、RISC方式の設計で、x86は、何十年もかけて育ってきたCISC方式の設計です。最も大きな違いは、誰が作れるかと、ソフトウェアの環境の大きさです。x86はパソコンとサーバーで、ARMはスマートフォンで優位にあり、ノートパソコンとサーバーでも広がっています。RISC-Vはオープンな標準で、組み込みの分野で急速に広がっています。

項目ARMRISC-Vx86
設計の考え方RISC。ロード/ストア方式RISC。ロード/ストア方式で、モジュール化されているCISC。複雑な命令が多く、メモリのオペランドも使える
命令の長さ64ビットモード(AArch64)では32ビット固定32ビットに、任意の16ビットの圧縮命令可変で、1〜15バイト
汎用レジスタ31個(AArch64)32個(x0は常に0として読める)16個(x86-64)
ライセンス独占的。企業はArm社からライセンスを受け、料金とロイヤルティを払うオープンな標準。誰でも、ライセンス料なしでチップを作れる独占的。実際には、IntelとAMDだけがx86のプロセッサを作る
モジュール性アプリケーション用(A)、リアルタイム用(R)、マイコン用(M)のプロファイル小さな基本部分に、任意の拡張(乗算、浮動小数点、ベクトルなど)を加える何十年もかけて拡張を追加(SSE、AVXなど)。古いソフトウェアも動き続ける
ソフトウェアの環境成熟している。モバイル、Linux、AppleシリコンのMac、Windows on Arm急速に成長中。組み込みとLinuxで特に強い最大。特にWindowsや、従来のデスクトップ・サーバーのソフトウェア
主な強み電力効率と、マイコンからサーバーまでの幅広さカスタマイズのしやすさと、ライセンス料がないこと高いシングルスレッド性能と、ソフトウェアの互換性
主な用途スマートフォン、タブレット、AppleのMac、クラウドのサーバー、組み込み組み込みとIoT、アクセラレータ、教育、新しいサーバーパソコン、サーバー、ワークステーション

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

ARM
電力効率が重要で、実績のある環境が欲しいとき。スマートフォンからクラウドのサーバーまで。
RISC-V
自分でプロセッサを設計したいとき、ライセンス料を避けたいとき、独自の命令を加えたいとき。
x86
既存のパソコンやサーバーのソフトウェアとの互換性が最優先のとき。

理解度チェック

  1. ARM、x86、RISC-Vといった名前が主に表しているものはどれか。
  2. RISC-Vの特徴として正しいものはどれか。
  3. RISC(縮小命令セットコンピュータ)の特徴として正しいものはどれか。
  4. 同じ命令セットアーキテクチャ(ISA)を採用した2つのCPUについて正しいものはどれか。
  5. RISC-Vのようなロード・ストア・アーキテクチャの特徴として正しいものはどれか。

関連する比較

  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • NAND型とNOR型フラッシュメモリの違い：速度・容量・用途を比較NAND型とNOR型のフラッシュメモリを、セルの接続・読み出し速度・消去単位・容量・コスト・信頼性・用途の観点で表にして比較します。
  • FinFETとGAAトランジスタの違い：構造・制御性・製造を比較FinFETとゲートオールアラウンド(GAA)ナノシートのトランジスタを、ゲート構造・チャネル・静電制御・幅の調整・製造・採用状況の観点で表にして比較します。
  • SiCとGaNのパワー半導体の違い：耐圧・周波数・用途を比較SiCとGaNのパワー半導体を、バンドギャップ・熱伝導率・素子の種類・耐圧・スイッチング周波数・ウェハ・コスト・用途の観点で表にして比較します。
