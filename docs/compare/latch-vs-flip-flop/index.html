ラッチとフリップフロップの違い：動作と使い分けを比較

どちらも1ビットを記憶しますが、動き出すきっかけが違います。ラッチはレベル感応で、イネーブルが有効な間は透明になって入力をそのまま出力へ通し、イネーブルが無効になると、その値を保持します。フリップフロップはエッジトリガで、クロックのエッジの瞬間だけ入力を取り込み、それ以外の変化は無視します。フリップフロップは、逆の位相で動く2つのラッチでできています。

項目ラッチフリップフロップ
トリガーレベル感応。イネーブルが有効な間、動作するエッジトリガ。クロックの立ち上がりまたは立ち下がりの瞬間だけ動作する
出力の動き透明な間は入力に追従し、そのあと保持するクロックのエッジでだけ変わり、それ以外は安定している
構成記憶の段が1つ逆の位相で動く2つのラッチを直列につなぐ(マスタースレーブ)
大きさと消費電力小さく、消費電力も小さい大きい。トランジスタ数はおよそ2倍
タイミング解析複雑。透明な期間をまたぐタイムボローイングがある簡単。クロックのエッジの前後のセットアップ時間とホールド時間
グリッチへの影響透明な間は、グリッチやレースが通り抜けるクロックのエッジの間の入力の変化には影響されない
主な用途タイムボローイングを使う専用の高速設計、クロックゲーティングのセル同期設計のレジスタ、カウンタ、ステートマシン

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

ラッチ
面積、電力、速度の利点が、難しくなるタイミング解析に見合うとき。多くは専用設計や高性能な回路です。
フリップフロップ
同期設計の標準的な部品です。タイミングが簡単で、頑健だからです。
HDLのヒント
VerilogやVHDLでは、組み合わせ回路のifやcaseが不完全だと、意図しないラッチができます。すべての分岐で値を代入すれば避けられます。

理解度チェック

  1. Dラッチの動作の説明として正しいものはどれか。
  2. D型フリップフロップの動作として正しいものはどれか。
  3. フリップフロップのセットアップ時間の説明として正しいものはどれか。
  4. 非同期の信号をフリップフロップで受けたときに、セットアップ時間やホールド時間を満たせず、出力が一時的に0とも1とも定まらなくなる状態を何と呼ぶか。
  5. すべてのフリップフロップが共通のクロックで動作する同期式回路の利点として正しいものはどれか。
  6. 上の記述でラッチができてしまう理由と、対策の組み合わせとして正しいものはどれか。
