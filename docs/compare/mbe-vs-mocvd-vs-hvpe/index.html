MBE・MOCVD・HVPEの違い：エピタキシャル成長法の真空度・成長速度・原料・材料・用途を比較

MBE・MOCVD・HVPEは、どれも基板の結晶にならって化合物半導体の結晶を成長させるエピタキシャル成長の方法ですが、原料の運び方と成長の速さが大きく違います。MBEは超高真空の中で、加熱して蒸発させた原料を分子線として基板に当てます。成長は一般に毎時約1 µmと遅いものの、原子層の単位で膜厚を制御できます。MOCVDは、有機金属と水素化物のガスを、減圧から大気圧の流れる雰囲気で加熱した基板に送り、毎時1〜数µm程度で成長させます。多数のウエハを同時に処理でき、LEDやレーザーの量産の主力です。HVPEは、ガリウムと塩化水素からつくる塩化ガリウムとアンモニアを使い、毎時数十〜数百µmの速さで厚いGaNを成長させ、自立基板づくりに使われます。

どんなときに使うか

MBE
原子層の単位で膜厚や組成を決めたいとき、急峻な界面が性能を決めるHEMTや量子構造、新しい材料の研究に向きます。
MOCVD
薄い多層構造のデバイス層を、多数のウエハで量産したいとき。GaN系のLEDやレーザー、HEMTの製造の主力です。
HVPE
厚いGaNを速く成長させたいとき。異種基板の上に厚く成長させて基板を外し、GaNの自立基板をつくります。デバイス層は、その上にMOCVDなどで成長させます。

よくある質問

MBEはなぜ超高真空で行うのですか？

原料の原子や分子を、ほかの気体分子と衝突させずにビームとして基板まで届けるためです。不純物の混入も少なくなり、電子線を使うRHEEDで成長中の表面をその場で観察することもできます。

HVPEはなぜMOCVDより成長が速いのですか？

III族の原料を塩化ガリウムの形で大量に供給でき、高温の基板の上で速く反応させられるからです。成長速度は一般に毎時数十〜数百µmで、MOCVDの数十倍になります。その代わり、数nmの薄い層を正確につくるのは苦手です。

LEDの製造にはなぜMOCVDが使われるのですか？

量子井戸のような数nmの薄い層を、組成を切り替えながら成長させられ、しかも1回に多数のウエハを処理できるからです。MBEは制御性に優れますが成長が遅く、HVPEは速いものの薄い層の制御が苦手です。

GaNの自立基板はどのようにつくりますか？

サファイアなどの異種基板の上に、HVPEで数百µm〜mmの厚いGaNを成長させ、元の基板を取り除きます。膜が厚くなるにつれて貫通転位どうしが出会って消えるため、表面に近いほど転位が少なくなります。

理解度チェック

MOCVD(有機金属気相成長法)が主に使われる用途はどれか。

  1. Aシリコンの熱酸化
  2. BCu配線のめっき
  3. CGaNなど化合物半導体のエピタキシャル成長
答えと解説を見る

正解：C. GaNなど化合物半導体のエピタキシャル成長

MOCVDは、トリメチルガリウムなどの有機金属とアンモニアなどの水素化物ガスを加熱した基板上で反応させ、化合物半導体の結晶を成長させる方法です。ガスの切り替えで組成を数nm単位で変えられ、1回に数十枚のウエハを処理できる量産性があります。GaN系の青色・白色LED、半導体レーザー、高周波・パワーデバイスのほか、太陽電池の製造にも広く使われています。

MBE(分子線エピタキシー)の特徴として正しいものはどれか。

  1. A大気圧で厚い膜を高速に成長させる
  2. B超高真空中で原料を分子線として基板に供給し、膜厚や組成を原子層レベルで精密に制御できる
  3. C液体の原料にウエハを浸して成長させる
答えと解説を見る

正解：B. 超高真空中で原料を分子線として基板に供給し、膜厚や組成を原子層レベルで精密に制御できる

MBEは、10⁻⁸ Pa程度の超高真空の装置内で原料を加熱して分子(原子)の線として基板に当て、結晶を成長させる方法です。シャッターの開閉で原料を瞬時に切り替えられ、RHEEDで成長の様子をその場で観察しながら原子層単位で膜厚や組成を制御できます。成長速度は1時間に1 µm程度と遅く量産性はMOCVDに劣りますが、研究開発や高性能なHEMT、量子デバイスに使われます。

MBEで、成長中の表面に電子線を浅い角度で当て、その回折像から成長の様子をその場で観察する手法はどれか。

  1. ASIMS
  2. BRHEED(反射高速電子回折)
  3. CXPS
答えと解説を見る

正解：B. RHEED(反射高速電子回折)

RHEEDは、成長中の表面に10〜30 keVの電子線を1〜3°ほどのすれすれの角度で当て、回折パターンを蛍光スクリーンで観察する手法です。表面の平坦さや再構成構造がわかり、1原子層ずつ成長するたびに表面の凹凸が周期的に変わって強度が振動するため、成長した層の数をその場で数えられます。電子線が気体分子で散乱されない超高真空のMBEならではの観察方法です。

  2. MOCVDによるGaNの成長で、条件として管理される「V/III比」の意味はどれか。

エピタキシャル成長の練習問題へ

関連する用語の解説

MBE(分子線エピタキシー)
超高真空中で、原料を分子線として基板に供給してエピタキシャル成長させる方法。膜厚や組成を原子層レベルで精密に制御でき、化合物半導体の研究や量子構造の作製に使われる。
MOCVD(有機金属気相成長)
有機金属化合物とアンモニアなどの原料ガスを使って結晶を成長させる方法。GaNやGaAsなどの化合物半導体の成長に広く使われる。
HVPE(ハイドライド気相成長)
塩化水素とガリウムの反応で生じた塩化ガリウムとアンモニアを使う気相成長法。成長速度が非常に速く、GaNの自立基板をつくる厚い結晶の成長に使われる。
エピタキシャル成長
単結晶基板の上に、基板の結晶方位をそろえて単結晶の薄膜を成長させる技術。
GaN(窒化ガリウム)
バンドギャップ約3.4 eVのIII-V族化合物半導体。青色LEDや高周波・パワーデバイスに使われる。
量子井戸
バンドギャップの小さい数nmの薄い層を、バンドギャップの大きい層で挟んだ構造。キャリアを閉じ込めて再結合を起こしやすくするため、LEDやレーザーの発光層に使われる。
HEMT(高電子移動度トランジスタ)
ヘテロ接合の界面にできる高移動度の2次元電子ガスをチャネルに使うトランジスタ。高周波・高出力の用途に使われる。
貫通転位
成長層の中を表面まで突き抜けて伸びる転位。サファイアやシリコンの上のGaNでは密度が高く(10⁸〜10⁹ cm⁻²程度)、デバイスの特性や信頼性を下げる。
