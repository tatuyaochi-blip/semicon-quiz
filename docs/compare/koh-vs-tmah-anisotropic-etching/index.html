KOHとTMAHの違い：シリコンの異方性エッチングの速さ・マスク・CMOSとの相性を比較

KOHとTMAHは、どちらもシリコンを結晶面によって大きく異なる速さで溶かすアルカリの水溶液です。(111)面がほかの面より非常に遅くエッチングされるため、(100)面のウエハでは(111)面が約54.7°の斜面として現れ、V字形の溝やピラミッド形の穴、薄いダイヤフラムをつくれます。KOHは安価で、結晶面による速さの差が大きく、MEMSのバルクマイクロマシニングで古くから使われてきました。ただし、カリウムイオンがトランジスタの特性を乱すため、CMOSの工程には持ち込めません。TMAHは金属イオンを含まないのでCMOSと両立しやすく、酸化膜をマスクに使いやすい一方、結晶面による速さの差は小さめです。また、皮膚から吸収されると重い中毒を起こすため、取り扱いには特に注意が必要です。

どんなときに使うか

KOH
回路を含まないMEMSの部品を、安く速く深くエッチングしたいときに向きます。結晶面による速さの差が大きいので形の精度を出しやすく、シリコン窒化膜をマスクにして使います。
TMAH
CMOSの回路と同じウエハを加工するときや、金属イオンの汚染を避けたいときに選びます。熱酸化膜をマスクにできるのも利点ですが、取り扱いには厳重な保護具と手順が必要です。

よくある質問

なぜ(111)面はエッチングが遅いのですか？

(111)面の表面の原子は、結晶の内側と3本の結合でつながっていて、表面に出ている結合が1本しかないため、溶液に引き離されにくいと説明されます。この差によって、(100)面のウエハでは(111)面がほとんどエッチングされずに残り、約54.7°の斜面ができます。

KOHはなぜCMOSの工程で使えないのですか？

カリウムはナトリウムと同じアルカリ金属で、ゲート酸化膜の中を動く可動イオンになり、しきい値電圧を変動させるからです。ごく微量でも問題になるため、KOHを使った装置やウエハをCMOSの工程に持ち込まないように管理します。

エッチングを決まった深さで止めるには？

ボロンを非常に高い濃度で入れた層は、アルカリの溶液ではほとんどエッチングされないので、その層で止められます(ボロンによるエッチストップ)。KOHでもTMAHでも使えます。pn接合に電圧をかけて止める電気化学的な方法や、SOIウエハの埋め込み酸化膜で止める方法もあります。時間だけで管理すると、ウエハの厚さのばらつきがそのまま残る膜の厚さのばらつきになります。

TMAHはフォトレジストの現像液と同じものですか？

同じ物質ですが、濃度と温度が違います。現像液は2.38%程度の薄い液を室温付近で使い、シリコンのエッチングには5〜25%程度の液を70〜90 ℃程度に加熱して使います。どちらでも皮膚に付けないことが重要で、特に高濃度の液は危険です。

理解度チェック

水酸化カリウム(KOH)水溶液によるシリコンのウェットエッチングの特徴として正しいものはどれか。

  1. A結晶面によってエッチング速度が大きく異なり、(111)面が非常に遅いため、斜面をもつV字形の溝などができる
  2. Bすべての結晶面で同じ速さで進む等方性エッチングである
  3. C酸化膜を高速に溶かす
答えと解説を見る

正解：A. 結晶面によってエッチング速度が大きく異なり、(111)面が非常に遅いため、斜面をもつV字形の溝などができる

KOHなどのアルカリ溶液は、シリコンの(111)面を(100)面の100分の1程度の速さでしかエッチングしないため、(100)ウエハでは(111)面が現れて約54.7°の斜面をもつV字形の溝やピラミッド形の穴ができます。この結晶方位による異方性を利用して、MEMSの圧力センサのダイヤフラム、インクジェットのノズル、太陽電池表面の光を閉じ込める凹凸(テクスチャ)などをつくります。

半導体の現像液に、水酸化ナトリウムなどではなくTMAHのような有機アルカリが使われる主な理由はどれか。

  1. ATMAHの方が強い色をもつため
  2. BTMAHの方が必ず安価なため
  3. Cナトリウムなどの金属イオンによる汚染を避けるため
答えと解説を見る

正解：C. ナトリウムなどの金属イオンによる汚染を避けるため

ナトリウムやカリウムなどのアルカリ金属イオンは、酸化膜中を電界で動く可動イオンとなり、トランジスタのしきい値電圧を変動させます。初期のMOSデバイスが不安定だった主な原因がこのナトリウム汚染でした。TMAHは金属を含まない有機アルカリなので、こうした汚染の心配がありません。色や価格が選ばれる理由ではなく、TMAHが必ず安価なわけでもありません。

現像液に使われるTMAH(水酸化テトラメチルアンモニウム)の高濃度液が皮膚に付いた場合に特に危険とされる理由はどれか。

  1. A強い放射線を出すため
  2. B皮膚から吸収されて神経や筋肉の働きを妨げ、呼吸が止まるなどの全身の中毒を起こすおそれがあるため
  3. Cすぐに凍りついて凍傷を起こすため
答えと解説を見る

正解：B. 皮膚から吸収されて神経や筋肉の働きを妨げ、呼吸が止まるなどの全身の中毒を起こすおそれがあるため

TMAHは強いアルカリで皮膚を傷めるだけでなく、皮膚から吸収されたテトラメチルアンモニウムイオンが神経から筋肉への信号の伝達を妨げ、呼吸の停止などを起こすことがあります。現像に使う2.38%の液より、原液に近い25%程度の高濃度液が特に危険で、台湾などで接触による死亡事故が報告されています。保護具の着用と、付着したときのただちの洗浄と受診が重要です。

エッチングの練習問題へ

関連する用語の解説

異方性エッチング
特定の方向(主に垂直方向)にだけエッチングが進む性質。微細パターンの加工に必要。
ウェットエッチング
薬液に浸して膜を溶かして削る方法。選択比が高く損傷も少ないが、一般に等方的に進むため微細な加工には向かない。
TMAH
水酸化テトラメチルアンモニウム。金属イオンを含まない有機アルカリで、フォトレジストの現像液に使われる。皮膚からの吸収による中毒に注意が必要。
結晶方位
結晶の面や方向の向きを表すもの。(100)のようにミラー指数で表し、MOSFET用のシリコンウエハでは(100)面が一般的。
可動イオン
ゲート酸化膜の中を移動できるナトリウムやカリウムなどのイオン。電界や温度によって移動し、しきい値電圧を変動させる。人の汗などから混入するため厳しく管理される。
MEMS
微小電気機械システム。半導体の微細加工技術で微小な機械構造と電子回路をつくり込んだデバイス。
選択比
エッチングで、削りたい膜とマスクや下地膜とのエッチング速度の比。大きいほど下地を傷めにくい。
