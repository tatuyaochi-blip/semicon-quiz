DDR4とDDR5の違い：速度・構造・買い替えの目安

DDR5はDDR4の後継で、出発点のデータレートがおよそ2倍になり、電圧が下がり、メモリモジュールの構成も変わりました。1枚のモジュールが、独立した32ビットのサブチャネルを2つ持ち、電源の調整回路がモジュールの上へ移ります。チップの内部での誤り訂正も加わりました。ただし、DDR5とDDR4には互換性がありません。クロック数で見た遅延は大きくなるので、実際の効果は処理の内容によって変わります。

項目DDR4DDR5
登場2014年ごろ2020〜2021年ごろ
電源電圧1.2 V1.1 V
データレート1,600〜3,200 MT/s(標準の速度)4,800 MT/sから始まり、標準の速度は6,400 MT/s以上
64ビットのチャネルの帯域3,200 MT/sで約25.6 GB/s6,400 MT/sで約51.2 GB/s
モジュールあたりのチャネル64ビットのチャネルが1つ独立した32ビットのサブチャネルが2つ
プリフェッチとバースト長8nプリフェッチ、バースト長816nプリフェッチ、バースト長16
バンク4つのバンクグループに16バンク(一般的なx8のチップ)8つのバンクグループに32バンク
チップの容量1ダイで最大16 Gbit規格上は1ダイで最大64 Gbit
誤り訂正内蔵の訂正はない(ECCのモジュールはチップを追加する)すべてのチップにオンダイECCを内蔵
電源管理マザーボード側モジュール側(PMIC)
遅延クロック数では小さいクロック数では大きい。ナノ秒で見た遅延は、最初のうちは同程度
互換性専用のスロット別のスロット。DDR4とは互換性がない

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

DDR4
今ある環境や、メモリ帯域が制約にならない用途には、今も安くて堅実な選択です。
DDR5
新しいシステム、コア数が多いもの、内蔵グラフィックス、メモリ帯域が必要な用途の選択です。サーバー、コンテンツ制作、新しいゲーム向けのプラットフォームなど。
注意
混在はできません。使える種類は、プラットフォーム(CPUとマザーボード)で決まります。

理解度チェック

  1. DDR5で採用された、DRAMチップの内部で誤りを訂正する機能はどれか。
  2. データ転送速度3,200 MT/s、データバス幅64ビットのDDR4メモリ1チャネルのピーク帯域に最も近いものはどれか。
  3. DDR4 SDRAMなどで使われている「8nプリフェッチ」の考え方として正しいものはどれか。
  4. DDR SDRAMの「DDR(ダブルデータレート)」の意味として正しいものはどれか。
  5. パソコンでメモリを「デュアルチャネル」で動作させる主な効果はどれか。
  6. DDR系のDRAMで、信号の反射を抑えるための終端抵抗をDRAMチップの内部に持たせ、オン・オフを制御できるようにした機能はどれか。

関連する比較

  • DDR・LPDDR・GDDR・HBMの違い：DRAMの種類を比較DDR、LPDDR、GDDR、HBMを、使われる機器・バス幅・速度・帯域・消費電力・実装・容量・コストの観点で表にして比較します。
  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • NAND型とNOR型フラッシュメモリの違い：速度・容量・用途を比較NAND型とNOR型のフラッシュメモリを、セルの接続・読み出し速度・消去単位・容量・コスト・信頼性・用途の観点で表にして比較します。
  • FinFETとGAAトランジスタの違い：構造・制御性・製造を比較FinFETとゲートオールアラウンド(GAA)ナノシートのトランジスタを、ゲート構造・チャネル・静電制御・幅の調整・製造・採用状況の観点で表にして比較します。
  • SiCとGaNのパワー半導体の違い：耐圧・周波数・用途を比較SiCとGaNのパワー半導体を、バンドギャップ・熱伝導率・素子の種類・耐圧・スイッチング周波数・ウェハ・コスト・用途の観点で表にして比較します。
  • CMOSイメージセンサーとCCDの違い：読み出し・速度・用途を比較CMOSイメージセンサーとCCDを、読み出し方式・消費電力・速度・ノイズ・シャッター方式・集積度・コスト・用途の観点で表にして比較します。
