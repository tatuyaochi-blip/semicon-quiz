SOIとバルクシリコンの違い：チップメーカーから見た比較

ほとんどのチップは、ふつうのシリコンウェハ(バルクシリコン)の中に直接作られます。シリコン・オン・インシュレータ(SOI)のウェハは、トランジスタを作る薄いシリコン層の下に、酸化膜の層を埋め込んだものです。この絶縁層が、トランジスタを基板から分離するので、寄生容量が減り、ラッチアップがなくなり、回路を速く、または低消費電力にできます。代わりに、ウェハは高価で、熱も逃げにくくなります。

項目バルクシリコンSOI
構造トランジスタをシリコンウェハの中に直接作る薄いシリコン層が、シリコン基板の上の埋め込み酸化膜(BOX)の上にある
分離ウェルとシャロートレンチ分離BOXで基板から完全に分離し、横方向はトレンチ分離
寄生容量接合容量が大きい小さい。接合が酸化膜の上にあるため
ラッチアップ起こりうる。寄生のサイリスタ構造のためなくなる
ソフトエラー放射線による電荷に敏感敏感さが小さい。電荷を集める体積が小さいため
しきい値の調整ボディバイアスは使えるが、限られる完全空乏型SOI(FD-SOI)では、BOX越しに強いバックゲートバイアスをかけられる
自己発熱熱は基板に逃げる悪化する。酸化膜は熱を伝えにくい
ウェハのコスト安いかなり高い
主な用途ほとんどのCMOSチップ。メモリ、プロセッサ、汎用のロジックスマートフォンのRFスイッチ、IoTや車載向けの低消費電力のFD-SOIチップ、MEMS、高耐圧や耐放射線のIC

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

バルク
主流のチップの標準です。ウェハが安く、周りの環境も成熟しています。
SOI
低消費電力、RF性能、耐放射線性、ボディバイアスが、ウェハのコスト増に見合うとき。

理解度チェック

  1. SOI(Silicon On Insulator)構造の説明として正しいものはどれか。
  2. 完全空乏型SOI(FD-SOI)トランジスタの利点として正しいものはどれか。
  3. FinFETやSOIトランジスタで問題になりやすい自己発熱の原因として正しいものはどれか。
  4. バルク基板上につくるFinFETで、フィンの根元(ゲートで制御しにくい部分)に高濃度の不純物層を設ける目的はどれか。
  5. MEMSの製造でSOIウエハがよく使われる理由として正しいものはどれか。
