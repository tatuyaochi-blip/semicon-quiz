JFETとMOSFETの違い：ゲート構造と使い分けを比較

どちらも電界効果トランジスタで、ゲートの電圧が、ソースとドレインの間の電流を制御します。MOSFETでは、ゲートが酸化膜で絶縁されています。JFETでは、ゲートが逆バイアスのPN接合で、チャネルを絞ります。そのため、JFETはノーマリオンで、雑音が非常に小さく、MOSFETは、絶縁されたゲートにほとんど電流が流れず、数十億個を集積するのがはるかに容易です。

どんなときに使うか

JFET
マイクやセンサーのプリアンプなど、アナログのフロントエンドで、低雑音と高い入力インピーダンスが重要なとき。
MOSFET
それ以外のほぼすべて。デジタル回路、電力スイッチング、大規模に集積する必要があるもの全般。

理解度チェック

  1. エンハンスメント型のnチャネルMOSFETがオン(導通)するための条件として正しいものはどれか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  2. デプレッション型MOSFETの特徴として正しいものはどれか。
  3. MOSFETのゲートにほとんど電流が流れないことによる回路上の利点として正しいものはどれか。
  4. MOSFETのゲート-ソース間に、定格を大きく超える電圧を加えたときに起こりうる破壊はどれか。
  5. ドレイン-ソース間電圧VDSが十分小さい線形領域でのMOSFETの振る舞いとして正しいものはどれか。
  6. nチャネルMOSFETのチャネルで電流を運ぶキャリアはどれか。

関連する比較

  • BJTとMOSFETの違い：制御方式・速度・用途を比較バイポーラトランジスタ(BJT)とMOSFETを、制御方式・入力電流・キャリア・速度・オン状態・温度特性・集積度・用途の観点で表にして比較します。
  • SAR・ΔΣ・パイプライン・フラッシュADCの違い：方式を比較フラッシュ型、SAR型、パイプライン型、ΔΣ型のADCを、仕組み・分解能・速度・遅延・消費電力・面積・用途の観点で表にして比較します。
  • ラッチとフリップフロップの違い：動作と使い分けを比較ラッチとフリップフロップを、トリガー・出力の動き・構成・大きさ・タイミング解析・グリッチ・デジタル設計での使い分けの観点で表にして比較します。
  • 組み合わせ回路と順序回路の違い：出力の決まり方を比較組み合わせ回路と順序回路を、出力が何で決まるか・記憶素子・クロック・フィードバック・例・タイミング・HDLでの書き方の観点で表にして比較します。
  • CMOSとTTLの違い：論理ICのファミリーを比較CMOSとTTLの論理ICを、トランジスタ・静的消費電力・電源電圧・論理レベル・ノイズマージン・速度・入力・使われる場所の観点で表にして比較します。
  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
