JFETとMOSFETの違い：ゲート構造と使い分けを比較

どちらも電界効果トランジスタで、ゲートの電圧が、ソースとドレインの間の電流を制御します。MOSFETでは、ゲートが酸化膜で絶縁されています。JFETでは、ゲートが逆バイアスのPN接合で、チャネルを絞ります。そのため、JFETはノーマリオンで、雑音が非常に小さく、MOSFETは、絶縁されたゲートにほとんど電流が流れず、数十億個を集積するのがはるかに容易です。

どんなときに使うか

JFET
マイクやセンサーのプリアンプなど、アナログのフロントエンドで、低雑音と高い入力インピーダンスが重要なとき。
MOSFET
それ以外のほぼすべて。デジタル回路、電力スイッチング、大規模に集積する必要があるもの全般。

よくある質問

なぜJFETはノーマリオンなのですか？

ゲート電圧がなくてもチャネルがあり、逆バイアスのゲート接合が、それを絞って閉じるからです。ディプリーション型の動作です。

JFETとMOSFETでは、どちらが低雑音ですか？

JFETです。特に低い周波数で低雑音なので、低雑音のプリアンプの入力段に使われます。

なぜMOSFETは静電気に弱いのですか？

薄いゲート酸化膜が、静電気放電で壊れることがあるからです。JFETには、壊れるゲート酸化膜がありません。

なぜICにはJFETでなくMOSFETが使われるのですか？

絶縁されたゲートに電流がほとんど流れず、微細化もしやすく、相補型(CMOS)の組み合わせも作りやすいので、1チップに数十億個を載せられるからです。

理解度チェック

エンハンスメント型のnチャネルMOSFETがオン(導通)するための条件として正しいものはどれか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)

  1. AVGSが0 Vであること
  2. BVGSがVthより大きいこと
  3. CVGSが負の電圧であること
答えと解説を見る

正解：B. VGSがVthより大きいこと

エンハンスメント型のnMOSFETでは、ゲートにVthを超える正の電圧を加えると、p型基板の表面に電子が引き寄せられて反転層(チャネル)ができ、ソースとドレインの間に電流が流れます。VGS = 0 Vではチャネルがなくオフなので、ゲートが浮いても電流が流れにくく(ノーマリーオフ)、論理回路やパワー用途の安全性に向きます。Vthは先端ロジックで0.2〜0.4 V、パワー用で1〜4 V程度が一般的です。

デプレッション型MOSFETの特徴として正しいものはどれか。

  1. Aゲートを持たない
  2. Bゲート電圧が0 Vでもチャネルが存在し、電流が流れる
  3. Cしきい値電圧より高いゲート電圧でも電流が流れない
答えと解説を見る

正解：B. ゲート電圧が0 Vでもチャネルが存在し、電流が流れる

デプレッション型はチャネルがあらかじめできており、ゲート電圧が0 Vでも電流が流れる(ノーマリーオン)MOSFETです。nチャネルなら負のゲート電圧でチャネルを消して電流を止めます。初期のNMOS論理では負荷素子として使われました。電源が落ちても導通するため安全面で注意が必要で、GaNのHEMTも本来はノーマリーオンのため、ノーマリーオフ化する構造の工夫が行われています。

MOSFETのゲートにほとんど電流が流れないことによる回路上の利点として正しいものはどれか。

  1. Aゲートを駆動するのに大きな直流電流が必要になる
  2. Bスイッチングの速さがゲート容量に関係しなくなる
  3. C入力電流がほぼ0で、状態を保つための直流電力がほとんど不要になる
答えと解説を見る

正解：C. 入力電流がほぼ0で、状態を保つための直流電力がほとんど不要になる

MOSFETのゲートは絶縁膜で隔てられているため、状態を保つための直流の入力電流はほぼ0です。そのため1つの出力で多数のゲートを駆動でき、CMOS回路は静止時の消費電力が非常に小さくなります。DRAMやフラッシュが電荷を保持できるのも、この絶縁ゲートのおかげです。ただしスイッチングのたびにゲート容量を充放電する電流は流れるため、周波数が高いほど駆動電力は大きくなります。
