ハブ・スイッチ・ルータの違い：動作する層・使うアドレス・転送のしかた・ドメインの分け方を比較

どれも機器をつないでデータを中継する装置ですが、どの層の情報を見て転送するかが違います。ハブ(リピータハブ)は第1層(物理層)の機器で、届いた信号をそのまま全ポートに流します。スイッチ(L2スイッチ)は第2層(データリンク層)の機器で、フレームの宛先MACアドレスを見て、宛先がつながるポートだけに転送します。ルータは第3層(ネットワーク層)の機器で、パケットの宛先IPアドレスと経路表(ルーティングテーブル)をもとに、異なるネットワークの間でパケットを中継します。同じネットワークの中をつなぐのがハブとスイッチ、ネットワークどうしをつなぐのがルータです。

どんなときに使うか

ハブ
現在はスイッチに置き換わっていて、新しく選ぶことはほとんどありません。スイッチの動作を理解するときの比較の基準として押さえておくと役立ちます。
スイッチ(L2スイッチ)
同じネットワークの中で、多くの機器をつなぐとき。VLANに対応した製品なら、1台でネットワークを論理的に分けることもできます。
ルータ
異なるネットワークどうしをつなぐとき。LANとインターネットの境界やサブネットの間に置き、経路の選択、NAT、パケットフィルタリングなどを受け持ちます。

よくある質問

L3スイッチとルータは、どう違いますか？

L3スイッチは、スイッチにルータの機能(第3層での転送)を加えた機器で、VLANどうしの間の通信をハードウェアで高速に中継できます。主に、社内のLANの中で、サブネットやVLANの間をつなぐのに使います。ルータは、インターネットや拠点の間をつなぐ回線への接続、NAT、VPNなど、ネットワークの境界で必要な機能を幅広くもつのが一般的です。ただし、製品によって機能の範囲は重なっています。

家庭のブロードバンドルータは、どれに当たりますか？

ルータ、スイッチ、無線LANのアクセスポイントなどを1台にまとめた機器です。LAN側の複数のポートどうしはスイッチとしてつながり、LANとインターネットの間はルータとして中継して、NAPTで1つのグローバルアドレスを共有します。DHCPサーバの機能をもつものも多くあります。

スイッチを使えば、ブロードキャストは減りますか？

減りません。スイッチは、ブロードキャストのフレームを、受け取ったポート以外の全ポートに送るので、つながった機器すべてに届きます。スイッチが分けるのはコリジョンドメインです。ブロードキャストが届く範囲を分けるには、VLANで分けるか、ルータでネットワークを分けます。

なぜハブは使われなくなったのですか？

ハブでは全ポートが1つの通信路を共有するので、つながる機器が増えるほど衝突が増え、帯域も分け合うことになります。また、すべての通信がすべてのポートに流れるので、ほかの機器あての通信も受け取れてしまいます。スイッチは宛先のポートだけに転送し、ポートごとに全二重で通信できるので、別のポートどうしの通信を同時に行えます。

理解度チェック

OSI参照モデルで、IPアドレスのような論理的なアドレスを使い、異なるネットワークの間でパケットを中継して宛先まで届ける役割をもつ層はどれか。

  1. Aデータリンク層(第2層)
  2. Bネットワーク層(第3層)
  3. Cトランスポート層(第4層)
答えと解説を見る

正解：B. ネットワーク層(第3層)

OSI参照モデルは、通信の機能を物理層からアプリケーション層までの7つの層に分けて整理したモデルです。ネットワーク層(第3層)は、IPアドレスのような論理的なアドレスを使い、複数のネットワークをまたいで宛先までの経路を選び、パケットを中継します。その下のデータリンク層は、同じネットワークの中で、MACアドレスを使って隣の機器にフレームを届けるところまでを担います。トランスポート層は、端末のアプリケーションどうしの通信を扱い、TCPなら再送や順序の管理を行います。機器でいえば、ルータは第3層、L2スイッチは第2層で動きます。

ハブ(リピータハブ)と比べたときの、L2スイッチの動作として正しいものはどれか。

  1. AIPアドレスを見て、異なるネットワークの間でパケットを中継する
  2. Bフレームの宛先MACアドレスを見て、宛先の機器がつながっているポートだけに転送する
  3. C届いたフレームを常にすべてのポートに送り、宛先の機器だけがそれを受け取る
答えと解説を見る

正解：B. フレームの宛先MACアドレスを見て、宛先の機器がつながっているポートだけに転送する

ハブは第1層の機器で、あるポートに届いた信号をそのまま全ポートに流します。そのため、つながったすべての機器が1つの通信路を共有し、同時に送ると衝突が起きます。L2スイッチは第2層の機器で、届いたフレームの送信元MACアドレスとポートの対応を表(MACアドレステーブル)に覚え、宛先MACアドレスがつながるポートだけに転送します。表にまだない宛先やブロードキャストのフレームは、受け取ったポート以外の全ポートに送ります(フラッディング)。ポートごとに通信が分かれるので、別のポートどうしの通信は同時に行えます。IPアドレスを見て異なるネットワークの間を中継するのは、第3層のルータの役割です。

1台のL2スイッチでVLANを設定し、ポート1〜4をVLAN 10、ポート5〜8をVLAN 20にした。このときの動作として正しいものはどれか。

  1. AVLAN 10とVLAN 20は同じスイッチにつながっているので、ルータを使わずに直接通信できる
  2. BVLANを2つに分けると、各ポートの通信速度がそれぞれ半分になる
  3. CVLAN 10の機器が送ったブロードキャストはVLAN 20のポートには届かず、VLAN 10とVLAN 20の間の通信にはルータ(またはL3スイッチ)が必要になる
答えと解説を見る

正解：C. VLAN 10の機器が送ったブロードキャストはVLAN 20のポートには届かず、VLAN 10とVLAN 20の間の通信にはルータ(またはL3スイッチ)が必要になる

VLAN(仮想LAN)は、スイッチのポートなどを単位にして、物理的には同じ機器の上に論理的に別々のネットワークを作る機能です。VLANごとにブロードキャストが届く範囲(ブロードキャストドメイン)が分かれ、スイッチは同じVLANのポートの間でだけフレームを転送します。そのため、この例のVLAN 10とVLAN 20のように異なるVLANの間の通信は、第3層で中継するルータやL3スイッチを通す必要があります。複数のスイッチをまたいでVLANを使うときは、IEEE 802.1Qで定められたタグ(VLAN ID)をフレームに入れて、どのVLANのフレームかを区別します。部署ごとにネットワークを分けたり、来客用の無線LANを社内のネットワークから切り離したりするのに使われます。

  1. 端末(192.168.1.10/24、デフォルトゲートウェイ 192.168.1.1)が、別のネットワークにあるサーバ 203.0.113.80 にパケットを送る。ARPのキャッシュが空のとき、端末がARPでMACアドレスを調べる相手はどれか。
  2. ルータの経路表に、0.0.0.0/0(次の転送先はルータA)、10.0.0.0/8(ルータB)、10.1.0.0/16(ルータC)、10.1.2.0/24(ルータD)の4つの経路がある。宛先が 10.1.5.9 のパケットは、どのルータに送られるか。
  3. 動的ルーティングの説明として正しいものはどれか。

関連する用語の解説

OSI参照モデル
通信の機能を、物理層・データリンク層・ネットワーク層・トランスポート層・セッション層・プレゼンテーション層・アプリケーション層の7つの層に分けて整理したモデル。各層の役割を分けて考えるための共通の言葉として使われる。
MACアドレス
イーサネットや無線LANで、同じネットワークの中の機器を指定するのに使う48ビットのアドレス。上位24ビットが製造者を表し、製造時にインターフェースごとに割り当てられる。
VLAN
仮想LAN。スイッチのポートなどを単位に、物理的に同じ機器の上に論理的に別々のネットワーク(ブロードキャストドメイン)を作る機能。スイッチの間ではIEEE 802.1Qのタグで区別する。
ARP
Address Resolution Protocolの略。IPアドレスから、同じネットワークにある機器のMACアドレスを調べるプロトコル。要求をブロードキャストで送り、該当する機器が答える。
デフォルトゲートウェイ
端末が、自分と別のネットワークにある宛先へのパケットを渡すルータ。端末はサブネットマスクで宛先が同じネットワークかを判断し、外ならこのルータに送る。
NAT
Network Address Translation(ネットワークアドレス変換)の略。ルータを通るパケットのIPアドレスを書き換える技術。ポート番号も書き換えて1つのグローバルアドレスを多くの端末で共有するものをNAPT(IPマスカレード)と呼ぶ。
サブネットマスク
IPアドレスのうち、上位の何ビットがネットワークを表す部分(ネットワーク部)かを示す32ビットの値。255.255.255.0 のように書き、CIDR表記の /24 と同じ意味になる。
