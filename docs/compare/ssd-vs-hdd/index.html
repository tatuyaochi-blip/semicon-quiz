SSDとHDDの違い：速度・耐久性・コストを比較

ハードディスクドライブ(HDD)は、回転する円盤に磁気でデータを記録し、動くヘッドで読み書きします。ソリッドステートドライブ(SSD)は、NAND型フラッシュのチップにデータを記録し、可動部分がありません。SSDは、何倍も速く、静かで、衝撃にも強い反面、HDDは、1TBあたりのコストがはるかに安く、大きな容量にできます。そのため、両方を組み合わせて、システムや作業中のファイルにはSSD、大量の保存にはHDDを使うことが多くあります。

どんなときに使うか

SSD
速度と反応のよさが重要なすべての用途。システムのドライブ、アプリケーション、ノートパソコン、モバイル機器。
HDD
めったにアクセスしない大量のデータを、1TBあたり最も安く保存するとき。バックアップ、メディアのライブラリ、アーカイブなど。
組み合わせ
システムと作業用に速いSSD、保存用に大容量のHDD、という構成がよく使われます。

よくある質問

SSDは、いつもHDDより速いですか？

ほとんどの作業でそうです。SSDのアクセス時間は数十マイクロ秒で、HDDはミリ秒です。シーケンシャルの速度も、SSDは約500 MB/sから14 GB/s、HDDは約100〜250 MB/sです。

SSDは劣化しますか？

フラッシュのセルが耐えられる書き込みと消去の回数には限りがあります。ウェアレベリングと予備の領域で摩耗を分散し、ドライブはTBWで評価されますが、その値は、ほとんどの使い方で書き込む量よりはるかに大きいです。

なぜHDDは今も使われるのですか？

1TBあたりがはるかに安く、より大きな容量にできるので、大量の保存、バックアップ、アーカイブの選択肢であり続けています。

TRIMとは何ですか？

OSがもう使わないブロックを、SSDに知らせるコマンドです。ガベージコレクションが先にそれを消去でき、書き込み性能を保てます。

理解度チェック

HDD(ハードディスク)と比べたときのSSDの特徴として正しいものはどれか。

  1. A円盤を回転させて磁気で記録する
  2. B機械的に動く部品がなく、ランダムアクセスが高速で衝撃に強い
  3. C同じ容量なら必ずHDDより安い
答えと解説を見る

正解：B. 機械的に動く部品がなく、ランダムアクセスが高速で衝撃に強い

SSDはNANDフラッシュで記録するため、ディスクやヘッドのような可動部品がありません。HDDはヘッドの移動とディスクの回転待ちで1回のアクセスに数msかかりますが、SSDは数十〜100 µs程度で、特にランダムアクセスが数百倍速くなります。衝撃や振動に強く静かです。一方、容量あたりの価格はHDDの方が安く、大容量の保存ではHDDも引き続き使われています。

SSDなどで使われるウェアレベリングの目的として正しいものはどれか。

  1. Aデータを圧縮して容量を増やす
  2. Bデータを暗号化して保護する
  3. C書き込みを特定のブロックに集中させず、全体に分散させて寿命を延ばす
答えと解説を見る

正解：C. 書き込みを特定のブロックに集中させず、全体に分散させて寿命を延ばす

ブロックには書き換え回数の上限があるため、同じ論理アドレスばかりに書くとそこだけが早く寿命を迎えます。ウェアレベリングでは、コントローラが論理アドレスと物理ブロックの対応表(FTL)を管理し、書き込みを消去回数の少ないブロックへ振り分けます。書き換えの少ない静的データも時々移動させて、全ブロックの消耗をそろえることで、製品全体の寿命を延ばします。

SSDのガベージコレクションの説明として正しいものはどれか。

  1. A無効になったデータを含むブロックから有効なデータを別の場所に移し、ブロックを消去して空き領域をつくる処理
  2. Bコンピュータウイルスを除去する処理
  3. Cデータを圧縮する処理
答えと解説を見る

正解：A. 無効になったデータを含むブロックから有効なデータを別の場所に移し、ブロックを消去して空き領域をつくる処理

NANDは上書きができず、消去はブロック単位でしか行えないため、書き換えのたびに古い版が無効なページとして残ります。コントローラは無効ページが多いブロックを選び、有効なデータを別のブロックに移してから元のブロックを消去し、空き領域をつくります。この余分なコピーが書き込み増幅の原因で、空き容量が少ないほど頻繁になり、書き込み性能が落ちます。

  2. SSDの「書き込み増幅(ライトアンプリフィケーション)」の説明として正しいものはどれか。
  3. SSDの「オーバープロビジョニング」の説明として正しいものはどれか。

SRAM・フラッシュメモリの練習問題へ

関連する用語の解説

NAND型フラッシュメモリ
メモリセルを直列に接続した構造の不揮発性メモリ。高集積で大容量化しやすく、SSDやメモリカードに使われる。
3D NAND
NANDフラッシュのメモリセルを垂直方向に多数積み重ねて大容量化したもの。平面の微細化の限界を超えるために導入され、積層数は200層以上に達している。
