順方向バイアスと逆方向バイアスの違い：空乏層・障壁・電流・容量・用途を比較

PN接合ダイオードは、電圧をかける向きによって性質が大きく変わります。順方向バイアスは、p側に正、n側に負の電圧をかけることです。接合の電位障壁が下がり、多数キャリアが接合を越えて相手側へ注入されるので、電流は電圧とともに指数関数的に増えます。逆方向バイアスは、p側に負、n側に正の電圧をかけることです。障壁が高くなって空乏層が広がり、ごくわずかな逆方向電流しか流れません。順方向は整流やLEDの発光に、逆方向は光の検出、電圧で変わる容量、降伏を使った定電圧などに使われます。

どんなときに使うか

順方向バイアス
電流を流したいときの使い方です。整流回路でダイオードが導通する半周期、LEDを光らせるとき、バイポーラトランジスタのベース-エミッタ接合がこの状態です。順方向電圧は温度が上がると一般に約2 mV/℃下がるので、温度センサーにも使われます。高速にスイッチするときは、蓄積された少数キャリアによる拡散容量や逆回復時間に注意します。
逆方向バイアス
電流を止めたいとき、または空乏層そのものを使いたいときの使い方です。フォトダイオードは空乏層で光が生んだキャリアを電界で集め、可変容量ダイオードは電圧で空乏層の幅を変えて容量を変えます。ツェナーダイオードは降伏電圧の付近で使って一定の電圧を得ます。集積回路では、ウェルや拡散層の接合を逆バイアスに保って、素子どうしを電気的に分けています。

よくある質問

逆方向バイアスでも電流が少し流れるのはなぜですか？

空乏層やその近くで熱的に生じた電子と正孔が、空乏層の電界で反対側へ流されるからです。この電流は熱的に生じる少数キャリアの量で決まるので、電圧を上げてもほとんど増えず、温度が上がると大きく増えます。シリコンではごく小さな値ですが、フォトダイオードでは暗電流として、DRAMではデータを保持できる時間を決めるリークとして問題になります。

順方向バイアスで空乏層は完全になくなりますか？

なくなりません。空乏層の幅は√(Vbi − V)に比例して狭くなりますが、電圧が内蔵電位に近づく前に電流が大きくなり、直列抵抗での電圧降下が増えるので、接合そのものにかかる電圧は内蔵電位より小さいままです。たとえばn側1×10¹⁶ cm⁻³の片側階段接合では、0 Vで約0.34 µmの幅が、0.5 Vの順方向バイアスで約0.23 µmになります(空乏近似による目安)。

順方向と逆方向で、容量の種類が違うのはなぜですか？

容量のもとになる電荷が違うからです。逆方向では、空乏層の両側にあるイオン化した不純物の電荷が電圧で増減し、平行平板のコンデンサのように働く接合容量が主になります。順方向では、接合を越えて注入され中性領域にたまる少数キャリアの電荷が電流とともに増え、拡散容量が主になります。拡散容量は大電流で大きくなり、ダイオードやバイポーラトランジスタを高速にスイッチするときの遅れの原因になります。

フォトダイオードはなぜ逆方向バイアスで使うのですか？

逆バイアスで空乏層が広がると、光で生じた電子と正孔を集められる範囲が広がり、それらが強い電界で素早く分けられて電流になるからです。接合容量も小さくなるので、応答も速くなります。これに対して太陽電池はバイアスをかけずに光で生じた電力を取り出し、LEDは順方向バイアスで注入したキャリアが再結合するときに光を出します。

理解度チェック

PN接合ダイオードに順方向バイアスを加えるときの電圧のかけ方として正しいものはどれか。

  1. Ap側を正、n側を負にする
  2. Bp側を負、n側を正にする
  3. Cp側とn側を同じ電位にする
答えと解説を見る

正解：A. p側を正、n側を負にする

p側(アノード)を正、n側(カソード)を負にすると、外部電圧が内蔵電位を打ち消す向きに働いて電位障壁が下がり、多数キャリアが接合を越えて相手側に注入されます。これが順方向バイアスで、電流は電圧に対して指数関数的に増えます。逆につなぐと障壁が高くなり、熱で生じた少数キャリアによるごく小さな電流しか流れません。同電位では拡散とドリフトがつり合い、電流は0です。

PN接合に加える逆方向バイアス電圧を大きくすると、空乏層の幅はどうなるか。

  1. A狭くなる
  2. B変化しない
  3. C広くなる
答えと解説を見る

正解：C. 広くなる

逆方向バイアスでは外部電圧が内蔵電位と同じ向きに加わり、キャリアがさらに接合から引き離されるため、空乏層は広がります。幅はおよそ √(Vbi + V) に比例し、Vが内蔵電位より十分大きければ、例えば電圧を4倍にすると約2倍になります。空乏層が広がると接合容量(C = εA/W)は小さくなり、この性質が可変容量ダイオードに使われます。電界を受け持つ幅が広がることは、耐圧の確保にもつながります。

可変容量ダイオード(バラクタダイオード)が利用している性質はどれか。

  1. A順方向電流で発光する性質
  2. B温度によって抵抗が変わる性質
  3. C逆バイアス電圧によって接合容量が変わる性質
答えと解説を見る

正解：C. 逆バイアス電圧によって接合容量が変わる性質

逆バイアスを強くすると空乏層が広がり、接合容量が小さくなります。この性質を利用して、電圧で容量を変えられるようにしたのが可変容量ダイオード(バラクタ)です。急峻な不純物分布にした超階段接合では容量が電圧で大きく変わり、可変範囲が広がります。共振周波数 f = 1/(2π√(LC)) を電圧で調整できるため、チューナーや電圧制御発振器(VCO)、PLLに使われます。

  1. フォトダイオードを光の検出に使うときの一般的な使い方として正しいものはどれか。
  2. 順方向バイアスのPN接合で、注入された少数キャリアの蓄積によって生じる容量はどれか。
  3. LEDが光る仕組みとして正しいものはどれか。

関連する用語の解説

順方向バイアス
p側に正、n側に負の電圧をかけること。障壁が下がって電流がよく流れる。逆にかけると逆方向バイアスで、電流はほとんど流れない。
空乏層
PN接合の境界付近にできる、キャリアがほとんど存在しない領域。逆バイアスで広がる。
内蔵電位
PN接合の空乏層に、外から電圧をかけなくても生じている電位差。シリコンでは0.6〜0.9 V程度で、キャリアの拡散を止める障壁になる。
接合容量(空乏層容量)
PN接合の空乏層が、平行平板のコンデンサのように働くことで生じる容量。逆バイアスを大きくすると空乏層が広がって小さくなる。可変容量ダイオードはこの性質を使う。
拡散容量
順方向バイアスのPN接合で、注入された少数キャリアが中性領域に蓄積されることで生じる容量。順方向電流に比例して大きくなり、高速動作を制限する。
ツェナーダイオード
逆方向の降伏電圧がほぼ一定になることを利用して、定電圧を得るダイオード。
フォトダイオード
光を受けて電荷(電流)を発生させるダイオード。イメージセンサの画素の受光素子として使われる。
なだれ降伏
逆方向の強い電界で加速されたキャリアが原子にぶつかって新たなキャリアをつくり、それが連鎖的に増えて大電流が流れる現象。
