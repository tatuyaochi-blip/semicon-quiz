CMOSとTTLの違い：論理ICのファミリーを比較

TTL(トランジスタ・トランジスタ・ロジック)は、バイポーラトランジスタでゲートを作り、1960年代から標準的なデジタルのファミリーでした。CMOSは、相補型のMOSトランジスタでゲートを作り、その後、ほぼすべての場面でTTLに置き換わりました。大きな違いは電力です。CMOSのゲートは、切り替わっていないときはほとんど電流を流しませんが、TTLのゲートは常に電流を流します。CMOSは、電源電圧の範囲も広く、ノイズマージンも大きく、チップに数十億個も集積できます。

項目TTLCMOS
トランジスタバイポーラトランジスタ。入力にマルチエミッタのトランジスタを使う相補型のnMOSとpMOSのトランジスタ
静的消費電力大きい。待機中も電流が流れる非常に小さい。リーク電流だけ
電源電圧5 V固定(約±5%)広い範囲。ファミリーによって約1 Vから15 Vまで
論理レベルLowは約0.8 Vまで、Highは約2.0 Vから電源電圧の約30%と70%
ノイズマージン小さい(約0.4 V)大きい(電源電圧の約30%)
出力の振幅電源のレールまでは完全には届かないグランドから電源まで、完全に振れる
入力電流が流れる。何もつながない入力はHighになる電流はほとんど流れないが、使わない入力は、ある電位にしておく必要がある
速度当時は速かった(74S、74Fなど)現代のファミリーでは同等以上
集積密度低い。電力が大きいため非常に高い。VLSIの基本
主な用途古いシステム、教育、昔の機器プロセッサやメモリを含む、現代のほぼすべてのデジタルチップ

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

TTL
主に、古い設計や、昔の機器の修理で見かけます。
CMOS
新しいデジタル設計のほぼすべてで、選ばれる方式です。
混在
74HCTなど、TTLの入力レベルを受け付けるCMOSのファミリーもあり、古いTTLの部品とつなげられます。

よくある質問

なぜCMOSはTTLより消費電力が小さいのですか？

CMOSのゲートは、切り替わっていないときは、相補的な2つのトランジスタのどちらかが常にオフなので、ほとんど電流を流しません。TTLのゲートは、常に電流を流します。

74HCTとは何ですか？

TTLの入力レベルに対応した、CMOSのファミリーです。古いTTLの部品とつなげられます。

使わないCMOSの入力は、つなぐ必要がありますか？

はい。CMOSの入力はほとんど電流を流さないので、何もつながないと入力が浮いて、不安定な動作や余分な電力の原因になります。グランドか電源につないでください。

TTLは今も使われていますか？

ほとんど使われません。古い設計や昔の機器に見られますが、現代のデジタルチップのほぼすべては、CMOSを使っています。

理解度チェック

バイポーラトランジスタで構成された代表的な論理ICの系列はどれか。

  1. ATTL
  2. BCMOS 4000シリーズ
  3. CNMOSロジック
答えと解説を見る

正解：A. TTL

TTL(Transistor-Transistor Logic)は、マルチエミッタのバイポーラトランジスタを入力に使った論理ICで、1960年代から7400シリーズとしてデジタル回路の標準になりました。電源は5 Vで、入力は約0.8 V以下をL、約2 V以上をHと判定します。静止時にも電流が流れて消費電力が大きいため、現在はCMOSが主流ですが、TTLレベルの入力をもつ74HCTなどのCMOSロジックにその名残があります。

CMOSインバータの静的(定常状態の)消費電力が小さい理由として正しいものはどれか。

  1. A電源電圧が高いため
  2. Bゲートに常に電流が流れているため
  3. C入力が0でも1でも、pMOSとnMOSのどちらか一方がオフになり、電源から接地への電流がほとんど流れないため
答えと解説を見る

正解：C. 入力が0でも1でも、pMOSとnMOSのどちらか一方がオフになり、電源から接地への電流がほとんど流れないため

CMOSインバータでは、入力が0のときpMOSがオン・nMOSがオフ、1のときはその逆になり、定常状態では電源と接地の間に必ずオフのトランジスタが入るため貫通電流がほとんど流れません。電力を主に消費するのはスイッチング時の負荷容量の充放電で、P = α·C·V²·f と表されます。ただし微細化でオフ時のリーク電流が増え、先端チップでは静的電力も無視できない割合になっています。

CMOSの「C(Complementary:相補型)」が表す意味として正しいものはどれか。

  1. AnMOSだけを直列につないで回路をつくる
  2. BnMOSとpMOSを組み合わせ、互いに補い合うように動作させる
  3. CバイポーラトランジスタとMOSFETを組み合わせる
答えと解説を見る

正解：B. nMOSとpMOSを組み合わせ、互いに補い合うように動作させる

CMOSはnMOSとpMOSを対にして使う回路方式です。入力が変わると一方がオン、もう一方がオフになるため、定常状態では電源からグラウンドへの電流経路がなく、消費電力を小さくできます。出力は電源とグラウンドの電位まで完全に振れるため、ノイズマージンも大きくとれます。1963年に提案され、1980年代に消費電力の大きいNMOSやバイポーラに代わってLSIの標準になりました。

  1. CMOSインバータで、入力が切り替わる途中に電源からグラウンドへ流れる電流を何と呼ぶか。
  2. CMOS回路で、ほかの条件を変えずに電源電圧だけを半分にすると、動的消費電力はどうなるか。
