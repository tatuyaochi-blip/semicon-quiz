表面照射型・裏面照射型・積層型イメージセンサの違い：構造・感度・速度を比較

CMOSイメージセンサは、光をどちらの面から入れるか、回路をどこに置くかで3つの構造に分けられます。表面照射型(FSI)は、配線層のある表面から光を入れるため、光の一部が配線にさえぎられます。裏面照射型(BSI)は、ウエハを裏返して数 µmまで薄くし、配線のない裏面から光を入れるので、小さな画素でも感度を確保できます。積層型は、BSIの画素のチップを、読み出しや画像処理の回路を持つロジックのチップと貼り合わせた構造で、チップを小さくし、読み出しを速くできます。

どんなときに使うか

表面照射型(FSI)
画素が大きく、配線による光の損失が小さいとき、またはコストを最も抑えたいとき。
裏面照射型(BSI)
画素が約1 µm前後まで小さくても感度を確保したいとき。スマートフォンのカメラの標準的な構造です。
積層型
チップを小さくしたいとき、または高速読み出しや画像処理の機能をセンサに載せたいとき。
3つの関係
3つは順に発展してきた構造です。BSIは貼り合わせのために支持ウエハが必要なので、その支持ウエハを回路の入ったロジックのチップに置き換えたものが積層型です。

よくある質問

裏面照射型はなぜ感度が高いのですか？

表面照射型では、光がフォトダイオードに届くまでに何層もの配線の間を通るため、一部がさえぎられたり反射したりします。裏面照射型は、配線のない裏面から光を入れるので、画素面積のほぼ全体で光を受けられ、斜めの光も失われにくくなります。

積層型も裏面照射型ですか？

はい。積層型の画素のチップは裏面照射型の構造で、その下に、読み出しや画像処理の回路を持つロジックのチップを貼り合わせています。「裏面照射型」は光の入れ方、「積層型」は回路の置き方を表す言葉です。

表面照射型はもう使われていないのですか？

使われています。画素が大きければ配線による光の損失は小さく、工程も簡単で安いので、画素の大きいセンサや低コストのセンサでは今も表面照射型が選ばれることがあります。

理解度チェック

裏面照射型(BSI)CMOSイメージセンサの主な利点として正しいものはどれか。

  1. A画素数を減らせる
  2. B配線層を通らずに光がフォトダイオードへ届くため、感度を高めやすい
  3. Cカラーフィルタが不要になる
答えと解説を見る

正解：B. 配線層を通らずに光がフォトダイオードへ届くため、感度を高めやすい

表面照射型では、光がフォトダイオードの上にある何層もの配線のすき間を通るため、配線で遮られたり反射したりしていました。裏面照射型はウエハを数µmまで薄く削り、配線層の反対側から光を入れるため、光を効率よく取り込め、斜めの光にも強くなります。2009年にソニーが製品化し、1 µm前後の微細な画素でも感度を確保できるため、スマートフォンのカメラで標準になりました。

積層型CMOSイメージセンサの説明として正しいものはどれか。

  1. Aレンズを何枚も重ねた構造
  2. Bフォトダイオードを使わない構造
  3. C画素部と信号処理回路を別々のチップでつくり、重ね合わせて接合した構造
答えと解説を見る

正解：C. 画素部と信号処理回路を別々のチップでつくり、重ね合わせて接合した構造

積層型では、画素部のチップと、AD変換や画像処理を行うロジック回路のチップを別々に最適なプロセスでつくり、銅どうしの直接接合(Cu-Cu接合)などで重ねて接合します。2012年にソニーが製品化し、チップ面積を小さくしながら、高速読み出し、HDR、動画の高フレームレート化などを実現できます。メモリを挟んだ3層構造の製品もあります。

イメージセンサの画素の「開口率(フィルファクタ)」の意味として正しいものはどれか。

  1. Aレンズの絞りの大きさ
  2. B画素数に対する有効画素数の割合
  3. C画素の面積のうち、光を受けて電荷に変える部分が占める割合
答えと解説を見る

正解：C. 画素の面積のうち、光を受けて電荷に変える部分が占める割合

開口率は、1つの画素の面積のうちフォトダイオードとして光を受けられる部分の割合です。トランジスタや配線が多いと開口率が下がり、感度が落ちます。初期のCMOSセンサは開口率が30%程度しかなく、CCDに比べて不利でした。マイクロレンズで光を集めて実効的な開口率を高め、さらに裏面照射型では配線が光路から外れるため、実質的にほぼ100%近い受光が可能になりました。

関連する用語の解説

裏面照射型(BSI)
配線層のない基板の裏側から光を入れる構造のイメージセンサー。配線に光がさえぎられず、小さな画素でも感度が高い。
積層型CMOSイメージセンサ
画素部と信号処理回路を別々のチップでつくり、重ね合わせて接合したイメージセンサ。それぞれに適したプロセスを使え、チップを小さく、処理を速くできる。
マイクロレンズ
イメージセンサの各画素の上に置かれる小さなレンズ。光を集めてフォトダイオードへ効率よく導き、感度を高める。
CMOSイメージセンサー
画素ごとに増幅回路をもち、CMOSプロセスで作るイメージセンサー。低消費電力で周辺回路を集積でき、スマートフォンのカメラなどの主流。
ハイブリッドボンディング
バンプを使わず、銅の電極と絶縁膜の面どうしを直接接合する技術。極めて狭いピッチで多数の接続ができる。
