CPUとGPUの違い：構造・得意な処理・用途を比較

CPUは、1つの仕事をできるだけ速く終わらせるために作られていて、強力なコアを少数と、大きなキャッシュ、賢い制御回路を持ちます。GPUは、似た仕事を大量に同時にこなすために作られていて、単純な演算器を数千個そろえ、膨大な数のスレッドを切り替えることでメモリの待ち時間を隠します。CPUは複雑で分岐の多い逐次的な処理に、GPUは画像処理やディープラーニングのような大規模な並列計算に向いています。

項目CPUGPU
設計の目的低遅延。1つのスレッドをできるだけ速く終わらせる高スループット。全体でできるだけ多くの仕事をこなす
コア数複雑なコアが数個から数百個単純な演算器が数千個。いくつかの塊にまとめられている
実行モデル各コアに投機実行(アウトオブオーダー)と分岐予測があり、SIMD命令も使うSIMT。スレッドのグループ(たとえば32個)が、同じ命令をそろって実行する
制御回路とキャッシュ大きなキャッシュと高度な制御回路が、チップ面積の多くを占める面積の多くを演算器に使う。スレッドあたりのキャッシュは小さい
メモリ遅延の隠し方主にキャッシュとプリフェッチ主に、待っているスレッドから別の実行可能なスレッドへ切り替える
メモリDDRやLPDDR。帯域は一般に数十〜数百GB/sGDDRやHBM。帯域は一般に数百GB/s〜数TB/s
分岐分岐や不規則なコードに強いグループ内のスレッドが別々の分岐に進むと遅くなる(ダイバージェンス)
データの置き場所メインメモリを直接扱う外付けのGPUは専用メモリを持つので、PCIeなどでデータをコピーする必要がある
プログラミングほとんどの言語やツールが使えるCUDA、HIP、OpenCL、シェーダー言語などの専用のモデル
得意な処理OS、データベース、制御ロジック、一般的なアプリケーショングラフィックス、行列・ベクトル計算、ディープラーニング、シミュレーション

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

CPU
処理が逐次的で分岐が多いとき、または1つのスレッドに素早い応答が必要なとき。OSの実行、アプリケーションのロジック、データベースなど。
GPU
同じ演算を大量のデータに当てはめるとき。画像のレンダリング、ニューラルネットワークの学習と推論、科学技術シミュレーションなど。
組み合わせ
ほとんどのシステムは両方を使います。CPUがプログラムを動かしてデータを用意し、GPUが重い並列計算をします。GPUに渡す仕事が少なすぎると、データのコピーに時間がかかり、CPUだけで済ませるより遅くなることもあります。

理解度チェック

  1. GPUのSIMT(単一命令・複数スレッド)の方式と、CPUのSIMD命令の違いとして正しいものはどれか。
  2. GPUが行列演算やAIの学習・推論に向いている主な理由はどれか。
  3. GPUのキャッシュについて、CPUと比べた一般的な特徴として正しいものはどれか。
  4. 単体のGPUを使うプログラムで、CPU側のメモリとGPU側のメモリについて一般的に正しいものはどれか。
  5. 配列の要素を1回だけ足し算するような軽い処理のためにデータをGPUへ送ると、CPUで計算するより遅くなることがある。主な理由はどれか。
  6. CPUのメモリをピン留め(ページロック)してからGPUへ転送すると速くなる理由として正しいものはどれか。

ほかの比較

  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • NAND型とNOR型フラッシュメモリの違い：速度・容量・用途を比較NAND型とNOR型のフラッシュメモリを、セルの接続・読み出し速度・消去単位・容量・コスト・信頼性・用途の観点で表にして比較します。
  • BJTとMOSFETの違い：制御方式・速度・用途を比較バイポーラトランジスタ(BJT)とMOSFETを、制御方式・入力電流・キャリア・速度・オン状態・温度特性・集積度・用途の観点で表にして比較します。
  • FinFETとGAAトランジスタの違い：構造・制御性・製造を比較FinFETとゲートオールアラウンド(GAA)ナノシートのトランジスタを、ゲート構造・チャネル・静電制御・幅の調整・製造・採用状況の観点で表にして比較します。
  • ASIC・FPGA・SoCの違い：柔軟性・コスト・用途を比較ASIC、FPGA、SoCを、それぞれが何か、柔軟性・性能・初期費用と単価・開発期間・用途の観点で表にして比較します。
  • SiCとGaNのパワー半導体の違い：耐圧・周波数・用途を比較SiCとGaNのパワー半導体を、バンドギャップ・熱伝導率・素子の種類・耐圧・スイッチング周波数・ウェハ・コスト・用途の観点で表にして比較します。
  • EUVとDUV露光の違い：波長・光学系・コストを比較EUV露光とDUV(ArF液浸)露光を、波長・光源・光学系・マスク・解像度・コスト・欠陥・使われる場所の観点で表にして比較します。
  • CMOSイメージセンサーとCCDの違い：読み出し・速度・用途を比較CMOSイメージセンサーとCCDを、読み出し方式・消費電力・速度・ノイズ・シャッター方式・集積度・コスト・用途の観点で表にして比較します。
  • ウェットエッチングとドライエッチングの違い：方向性・選択比・用途を比較ウェットエッチングとドライエッチングを、媒体・方向性・選択比・微細化・スループット・ダメージ・コスト・使われる工程の観点で表にして比較します。
  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
