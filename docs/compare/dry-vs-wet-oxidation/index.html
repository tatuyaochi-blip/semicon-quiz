ドライ酸化とウェット酸化の違い：成長速度・膜質・温度・用途を比較

どちらもシリコンを高温で酸化してSiO2をつくる熱酸化ですが、使う酸化剤が違います。ドライ酸化は乾燥した酸素(O2)を使い、成長は遅いものの、緻密で界面準位の少ない良質な膜ができるので、薄いゲート酸化膜に使われてきました。ウェット酸化は水蒸気(H2O)を使い、H2OがSiO2の中に溶ける量がO2よりずっと多いため、数倍〜10倍程度速く成長します。そのため、LOCOSのフィールド酸化膜やマスクのような厚い膜に使われます。

どんなときに使うか

ドライ酸化
膜は薄くてよいが、界面の品質と膜厚の精度を最優先したいとき。MOSFETのゲート酸化膜や、窒化膜の下に敷く薄いパッド酸化膜など。
ウェット酸化
厚い酸化膜を短い時間でつくりたいとき。LOCOSのフィールド酸化膜、拡散や注入のマスク、素子の周りの厚い絶縁膜など。
組み合わせ
ドライ酸化で界面をつくり、ウェット酸化で厚さを稼ぎ、最後にもう一度ドライ酸化で仕上げる、という順に組み合わせることもあります。

よくある質問

ウェット酸化がドライ酸化より速いのはなぜですか？

酸化はSiO2とシリコンの界面で進むので、酸化剤が膜の中を拡散して界面まで届く必要があります。H2OはO2よりSiO2の中に数百倍多く溶けるため、膜の中の酸化剤の濃度が高くなり、界面に届く量が増えます。Deal-Groveモデルでは、速度定数BとB/Aが大きくなる形で表れます。

ゲート酸化膜にドライ酸化が使われてきたのはなぜですか？

ドライ酸化の膜は緻密で、シリコンとの界面の準位が少なく、絶縁破壊にも強いからです。成長が遅いので、数nmの膜厚を精密に制御しやすいことも理由です。先端のゲートはHigh-k膜に置き換わりましたが、その下のごく薄いSiO2の界面層は今も重要です。

Deal-Groveモデルで、ドライ酸化だけ補正が必要なのはなぜですか？

ドライ酸化では、膜が数十nmより薄いうちは、モデルの予測より速く酸化が進むことが知られているからです。そこで、初期の速い成長で約25 nmの膜ができたとみなし、その分を時間τとして式に加えて補正します。ウェット酸化はモデルとよく合うので、τ ≈ 0 とおくことが多いです。

熱酸化では、シリコンはどれくらい消費されますか？

ドライ酸化でもウェット酸化でも同じで、できた酸化膜の厚さの約44%にあたるシリコンが消費されます。酸化膜は元の表面より上に約56%、下に約44%の割合で成長します。

理解度チェック

シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。

  1. Aドライ酸化のほうが酸化膜の成長速度が速い
  2. Bウェット酸化のほうが酸化膜の成長速度が速い
  3. C両者の成長速度は同じである
答えと解説を見る

正解：B. ウェット酸化のほうが酸化膜の成長速度が速い

水蒸気を使うウェット酸化は、酸化剤のH2OのSiO2中への溶解度がO2より数百倍高いため、ドライ酸化より成長速度が数倍〜10倍程度速くなります。例えば1000 ℃・1時間で、ドライは約70 nm、ウェットは約400 nmです。厚い膜が必要な素子分離やマスクに向いています。ドライ酸化は遅いものの緻密で界面準位の少ない良質な膜ができ、膜厚も制御しやすいため、薄いゲート酸化膜に使われてきました。

Deal-Groveモデルによると、熱酸化はどこで進むか。

  1. A酸化膜の最表面で、シリコン原子と酸化剤が反応する
  2. Bシリコン原子が酸化膜の表面まで拡散して反応する
  3. C酸化剤が酸化膜中を拡散し、Si/SiO2界面でシリコンと反応する
答えと解説を見る

正解：C. 酸化剤が酸化膜中を拡散し、Si/SiO2界面でシリコンと反応する

Deal-Groveモデル(1965年)では、酸化剤が気相から酸化膜の表面に取り込まれ、膜中を拡散してシリコンとの界面で反応し、新しい酸化膜ができると考えます。そのため酸化膜は界面側で成長し、界面は常に新しい面になります。酸化膜が厚くなるほど拡散距離が長くなり成長が遅くなります。この3段階の流束を等しいとおいて、直線則と放物線則を1つの式で表しました。

Deal-Groveモデルで、熱酸化の初期(酸化膜がまだ薄いとき)の酸化膜厚と時間の関係として正しいものはどれか。

  1. A膜厚は時間の平方根に比例する
  2. B膜厚は時間にほぼ比例する(直線的に増える)
  3. C膜厚は時間によらず一定である
答えと解説を見る

正解：B. 膜厚は時間にほぼ比例する(直線的に増える)

酸化膜が薄いうちは、酸化剤が膜を通り抜けるのは容易で、界面での反応の速さが律速になるため、膜厚は時間にほぼ比例して増えます(直線則、速度定数B/A)。膜が厚くなると酸化剤の膜中の拡散が律速になり、膜厚は時間の平方根に比例するようになります(放物線則、速度定数B)。切り替わりの目安は膜厚がA/2程度で、ドライ酸化では数十nm〜100 nm程度です。

  1. 熱酸化で酸化膜が十分厚くなったときの、酸化膜厚と酸化時間の関係として正しいものはどれか。
  2. シリコンのドライ熱酸化で起こる化学反応として正しいものはどれか。
  3. LOCOSなどの素子分離に使われたフィールド酸化膜と、MOSFETのゲート酸化膜の厚さの関係として一般的に正しいものはどれか。

関連する用語の解説

ドライ酸化
乾燥した酸素で行う熱酸化。成長は遅いが、緻密で良質な酸化膜ができ、ゲート酸化膜などに使われる。
ウェット酸化
水蒸気を含む雰囲気で行う熱酸化。ドライ酸化より成長が速く、厚い酸化膜をつくるのに使われる。
Deal-Groveモデル
シリコンの熱酸化を、酸化剤が酸化膜中を拡散してSi/SiO2界面でシリコンと反応する過程として表したモデル。薄いときは膜厚が時間に比例し、厚くなると時間の平方根に比例する。
熱酸化
シリコンを酸素や水蒸気の中で加熱し、表面にSiO2膜をつくる方法。ドライ酸化とウェット酸化がある。
LOCOS
窒化膜で覆っていない部分だけを厚く酸化して素子間を分離する方法。端に鳥のくちばし状の食い込み(バーズビーク)ができ、現在はSTIに置き換わった。

  • EUVとDUV露光の違い：波長・光学系・コストを比較EUV露光とDUV(ArF液浸)露光を、波長・光源・光学系・マスク・解像度・コスト・欠陥・使われる場所の観点で表にして比較します。
  • ウェットエッチングとドライエッチングの違い：方向性・選択比・用途を比較ウェットエッチングとドライエッチングを、媒体・方向性・選択比・微細化・スループット・ダメージ・コスト・使われる工程の観点で表にして比較します。
  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
