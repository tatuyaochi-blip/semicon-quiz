A級・AB級・D級アンプの違い：動作原理・効率・ひずみ・発熱・用途を比較

アンプの級(クラス)は、出力のトランジスタをどう動かすかの違いです。A級は信号の全周期でトランジスタに電流を流し続けるので、ひずみは最も小さいものの、信号がなくても電力を使い、効率は理論上でも25%または50%です。AB級は、正と負の半周期を2つのトランジスタで分担するB級に、少しのアイドリング電流を加えてクロスオーバーひずみを抑えたもので、効率はB級の理論上の最大約78.5%に近づきます。D級はトランジスタをスイッチとしてオン・オフし、PWMなどのパルスをフィルタで元の信号に戻すので、大きな出力で90%前後の高い効率が得られます。

どんなときに使うか

A級
出力が小さく、ひずみの少なさを最優先するとき。小さな信号の増幅や、プリアンプ、後ろの段を駆動するドライバの段。
AB級
ひずみの少なさと効率を両立したいとき。オーディオのパワーアンプやヘッドホンアンプ、オペアンプやバッファの出力段。
D級
電池で長く動かしたいとき、発熱や放熱器を小さくしたいとき、大きな出力が必要なとき。スマートフォンやテレビのスピーカ、カーオーディオ。

よくある質問

A級の最大効率に、25%と50%の2つがあるのはなぜですか？

負荷のつなぎ方が違うからです。負荷の抵抗をトランジスタに直列につなぐと、負荷にも直流の電流が流れて電力を捨てるので、理論上の最大は25%です。トランスやチョークコイルで負荷につなぐと、直流の電力を負荷で捨てずに済み、出力の電圧も電源の電圧の2倍まで振れるので、最大50%になります。

クロスオーバーひずみとは何ですか？

B級のプッシュプルで、信号が0の付近を通るとき、どちらのトランジスタもオンにならない区間ができて、出力の波形がゆがむことです。バイポーラトランジスタでは、ベースとエミッタの間に約0.6〜0.7 Vかけないと電流が流れないために起きます。AB級では、少しのアイドリング電流を流してこの区間をなくします。

D級のDは、デジタルのことですか？

違います。A級、B級、C級に続いて名付けられたもので、デジタルという意味ではありません。アナログの入力の信号を、三角波と比較器で比べてPWMのパルスに変えて動くD級アンプも多くあります。

D級の効率が高いのはなぜですか？

出力のトランジスタを、完全なオンかオフで使うからです。オンでは電圧がほぼゼロ、オフでは電流がほぼゼロなので、トランジスタで熱になる電力が小さくなります。残る損失は、オン抵抗による損失、切り替えの途中の損失、ゲートを駆動する電力などです。

理解度チェック

A級増幅回路と比べたときのB級プッシュプル増幅回路の特徴として正しいものはどれか。

  1. A効率は低いが、ひずみが非常に小さい
  2. Bバイアス電流を常に大きく流す
  3. C電力効率が高い(理論上最大約78.5%)が、クロスオーバーひずみが生じやすい
答えと解説を見る

正解：C. 電力効率が高い(理論上最大約78.5%)が、クロスオーバーひずみが生じやすい

A級は常に大きなバイアス電流を流すため、ひずみは小さいものの、理論上の最大効率は抵抗負荷で25%、トランス結合で50%と低く、信号がなくても発熱します。B級は信号がないときにほとんど電流を流さないため効率が高く、最大約78.5%(π/4)ですが、出力の切り替わりでクロスオーバーひずみが生じます。実用ではわずかにバイアスを流すAB級、さらに高効率なD級が使われます。

NPNとPNPのトランジスタで正と負の半周期を分担するB級プッシュプル増幅回路で生じやすいひずみはどれか。

  1. A量子化誤差
  2. Bエイリアシング
  3. Cクロスオーバーひずみ
答えと解説を見る

正解：C. クロスオーバーひずみ

B級プッシュプルでは、入力が0付近のとき、どちらのトランジスタもVBEが約0.6 Vに届かず導通しない区間ができ、波形の切り替わり部分がひずみます。これがクロスオーバーひずみで、小さい音量ほど目立ちます。ダイオードやVBEマルチプライヤで約1.2 Vのバイアスをかけ、わずかに電流を流すAB級にすることで低減します。オーディオアンプの出力段の多くがAB級です。

理想的なB級プッシュプル増幅回路の最大の電力効率に最も近い値はどれか。

  1. A約100%
  2. B約78.5%
  3. C約25%
答えと解説を見る

正解：B. 約78.5%

B級増幅では2つのトランジスタがそれぞれ半周期ずつ動作し、信号がないときにはほとんど電流が流れません。正弦波を最大振幅で出したときの効率は π/4 ≈ 78.5% が理論上の上限で、常にバイアス電流を流すA級(抵抗負荷で25%、トランス結合で50%)より高効率です。さらに効率を上げたい用途では、トランジスタをスイッチとして使うD級(90%以上)が使われ、スマートフォンや薄型テレビのアンプの主流になっています。

関連する用語の解説

クロスオーバーひずみ
B級プッシュプル増幅回路で、正と負の半周期を受け持つトランジスタが切り替わる0 V付近で、どちらも導通しないために生じるひずみ。わずかにバイアスを流すAB級で軽減する。
PWM(パルス幅変調)
周期を一定にしたまま、出力がHighになっている時間の長さを変えて、平均の電圧や電力を調整する方式。LEDの明るさやモーターの速さの調整に使う。
負帰還
出力の一部を入力に逆の極性で戻すこと。増幅率は下がるが、利得が安定し、ひずみや帯域が改善する。
