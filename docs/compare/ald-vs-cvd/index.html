ALDとCVDの違い：原子層堆積を比較

ALD(原子層堆積)は、CVDの特別な形で、原料のガスを1種類ずつ順番に流し、それぞれの反応が、表面が覆われたところで止まるようにしたものです。そのため、1サイクルで原子1層ずつ膜が成長し、膜厚を正確に制御でき、非常に深い構造もむらなく覆えます。代わりに速度は遅く、普通のCVDよりずっと時間がかかるので、最も薄く最も重要な膜に使われます。

項目ALDCVD
仕組み原料を順番に流し、間をパージで分ける。反応は自己停止的で、1サイクルでおよそ原子1層が付く原料を同時に流し、表面で連続的に反応させる
膜厚の制御原子レベル。サイクル数で決まる成膜の時間と速度で決まるので、精度は低め
被覆性優れている。非常に深く狭い穴や溝でも均一良好。ただし深い構造は、埋まる前に口がふさがることがある
成膜の速度遅い。1サイクルで1 nm未満速い。1分あたり数nm以上
均一性と膜質非常に均一で、緻密で、ピンホールが少ない均一性は良好
温度低いことが多い(約100〜350 ℃)幅が広く、高めのことが多い(プラズマCVDは低い)
スループットウェハあたりでは低い(バッチ式の装置で改善)高い
一般的な膜厚約1〜50 nm数十nmからマイクロメートル
主な用途high-kのゲート絶縁膜(HfO2など)、薄いバリア、スペーサー、3D構造のライナー厚い絶縁膜、ポリシリコン、窒化シリコン、タングステンのプラグ

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

ALD
膜が極端に薄く、完全に均一で、複雑な3D構造を覆う必要があるとき。FinFETやGAAのゲートスタック、DRAMのキャパシタなど。
CVD
より厚い膜を、速く、安く作りたく、構造がそれほど厳しくないとき。
使い分け
両方を組み合わせることも多くあります。最初の薄い被覆層をALDで作り、そのあと速いCVDで埋めたり厚くしたりします。

理解度チェック

  1. ALD(原子層堆積)の特徴として正しいものはどれか。
  2. ALDで成膜される代表的な材料の例として正しいものはどれか。
  3. 成膜におけるステップカバレッジ(段差被覆性)の説明として正しいものはどれか。
  4. CVDで段差被覆性(コンフォーマル性)がよくなる条件として正しいものはどれか。
  5. 減圧CVD(LPCVD)の特徴として正しいものはどれか。
  6. プラズマCVD(PECVD)の主な利点として正しいものはどれか。

関連する比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • EUVとDUV露光の違い：波長・光学系・コストを比較EUV露光とDUV(ArF液浸)露光を、波長・光源・光学系・マスク・解像度・コスト・欠陥・使われる場所の観点で表にして比較します。
  • ウェットエッチングとドライエッチングの違い：方向性・選択比・用途を比較ウェットエッチングとドライエッチングを、媒体・方向性・選択比・微細化・スループット・ダメージ・コスト・使われる工程の観点で表にして比較します。
  • 熱拡散とイオン注入の違い：ドーピング方法を比較熱拡散とイオン注入を、原理・ドーズ量の制御・深さ方向の分布・温度・結晶のダメージ・コスト・用途の観点で表にして比較します。
  • CZ法とFZ法の違い：シリコン単結晶の育て方を比較CZ法とFZ法のシリコンを、結晶の育て方・酸素濃度・純度・抵抗率・ウェハの大きさ・コスト・強度・用途の観点で表にして比較します。
  • ポジ型とネガ型フォトレジストの違い：反応・解像度・用途を比較ポジ型とネガ型のフォトレジストを、光に対する反応・パターンの極性・解像度・現像液・断面形状・材料・用途の観点で表にして比較します。
