プレーナ型MOSFETとFinFETの違い：業界が切り替えた理由

プレーナ型のMOSFETは、平らなチャネルの上にゲートがあり、ゲートは片側からだけチャネルを制御します。ゲート長が約20 nmより短くなると、ドレインがチャネルへ及ぼす影響が大きくなりすぎ、リーク電流や短チャネル効果が増えました。FinFETは、チャネルを細い縦のフィンに立ち上げ、ゲートが3方向から包むので、制御がはるかに強くなります。そのため、ロジックでは、22 nmや16/14 nmの世代から、プレーナ型からFinFETへ移りました。

項目プレーナ型MOSFETFinFET
構造ゲートが平らなチャネルの上にあるゲートが、細い縦のシリコンのフィンの3面を包む
ゲートの制御片側だけ。ゲート長が短いと弱い3方向から。はるかに強い
短チャネル効果(DIBLなど)寸法が小さいと深刻強く抑えられる
リーク電流微細化したデバイスでは大きい小さい
サブスレッショルドスイング微細化とともに悪化する理想の約60 mV/decadeに近い
占有面積あたりの駆動電流小さい大きい。チャネル幅がフィンの両側面と上面を含む
チャネルのドーピング濃い。ランダムなドーパントのばらつきが起こる薄い、またはドーピングなし。ばらつきが小さい
幅の調整連続的。どんな幅でも描ける段階的。フィンの本数で決まる
製造簡単で安い複雑。フィンのパターニングと、立体的なゲートの形成
現在の使われ方成熟したノード(28 nm以上)。アナログ、マイコン、RF、IoT16/14 nmから約3 nmまでの先端ロジック

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

プレーナ型
最後のひと伸びの速度よりもコストが重要で、最も小さいノードが不要なとき。アナログ、アナログ・デジタル混載、多くのマイコンなど。
FinFET
微細な寸法での性能と低リークが不可欠なとき。スマートフォン、パソコン、データセンターのプロセッサなど。

  1. MOSFETの短チャネル効果として当てはまるものはどれか。
  2. DIBL(Drain Induced Barrier Lowering)の説明として正しいものはどれか。
  3. FinFETで短チャネル効果を十分に抑えるために、フィンの幅について一般に求められることはどれか。
  4. 平面型トランジスタからFinFETに移行したことで、サブスレッショルド係数(SS)は一般にどう変わったか。
  5. FinFETの構造上の特徴として正しいものはどれか。
  6. 短チャネル効果の強さを見積もるのに使われる「スケール長(ナチュラル長)λ」の説明として正しいものはどれか。
