NVMeとSATAのSSDの違い：速度・インターフェース・選び方

どちらも中身はフラッシュメモリのSSDですが、コンピュータとのつなぎ方が違います。SATAのSSDは、ハードディスク用に作られたSATAインターフェースを使い、速度は約550 MB/sが上限です。NVMeのSSDは、PCI Expressを使い、フラッシュ用に作られたプロトコルで通信するので、3〜14 GB/s以上の速度が出て、遅延も小さいです。普段の使い方では違いは小さいですが、大きなファイルの転送や重い作業では、NVMeがはるかに速くなります。

項目SATAのSSDNVMeのSSD
インターフェースSATA III、6 Gb/sPCI Express。多くはx4レーン
シーケンシャルの速度最大でも約550 MB/sPCIe 3.0 x4で約3.5 GB/s、PCIe 4.0 x4で約7 GB/s、PCIe 5.0 x4で約14 GB/s
プロトコルAHCI。ハードディスク向けに設計されたNVMe。フラッシュメモリ向けに設計された
コマンドキュー1つのキューに32コマンド最大65,535のキューに、それぞれ最大65,536コマンド
遅延大きめ(約100マイクロ秒)小さい(数十マイクロ秒)
形状2.5インチのドライブと、M.2のSATAM.2、U.2またはU.3、アドインカード
消費電力と発熱小さい(数W)最高速では大きい。速いドライブは、速度の低下を防ぐためにヒートシンクが必要なことが多い
互換性古いパソコンでも、2.5インチのベイでも使えるM.2またはPCIeのスロットと、NVMeから起動できるファームウェアが必要
価格安い。エントリー向けのNVMeと同程度最速のものはやや高い。エントリー向けのNVMeは、SATAに近い価格になっている
向いている用途古いパソコンやノートパソコンの増強、大容量の保存用新しいパソコン、ゲーム、動画編集、ワークステーション、サーバー

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

SATAのSSD
パソコンにNVMeのスロットがないとき、またはハードディスクからの手軽で安い置き換えをしたいとき。
NVMeのSSD
M.2スロットがあり、大きなファイルを頻繁に動かすとき、または遅延を小さくしたいとき。新しいシステムの標準的な選択です。
先に確認すること
M.2スロットは、SATA用、NVMe用、またはその両方があります。M.2のSATAとM.2のNVMeのドライブは見た目が似ているので、購入前にマニュアルで確認してください。

  5. ネットワークカードやNVMeのSSDなどで広く使われる、メモリ上の記述子(ディスクリプタ)の輪(リング)を使ったDMAのしくみについて正しいものはどれか。
  6. HDD(ハードディスク)と比べたときのSSDの特徴として正しいものはどれか。
