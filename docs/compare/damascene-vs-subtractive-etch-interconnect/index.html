ダマシン法とエッチングで形づくる配線の違い：工程の順番・金属・CMP・微細配線を比較

エッチングで形づくる配線(サブトラクティブ法)は、金属の膜を全面に成膜し、レジストのパターンを使ってドライエッチングで不要な部分を除き、残った配線の間を絶縁膜で埋める方法で、アルミニウムの配線で長く使われてきました。ダマシン法は順番が逆で、先に絶縁膜に溝を掘り、金属を埋め込んでから、余分な金属をCMPで削り取ります。銅は揮発しやすい化合物を作りにくく、ドライエッチングが難しいため、銅の配線ではダマシン法が標準になりました。最も細い配線では、ルテニウムなどをエッチングで形づくる方法も検討されています。

項目ダマシン法エッチングで形づくる配線(サブトラクティブ法)
工程の順番絶縁膜を成膜 → 溝やビアの穴をエッチング → バリアメタルとシード層 → 銅のめっき → CMPで余分を除く金属膜を成膜 → リソグラフィ → 金属をドライエッチング → 配線の間を絶縁膜で埋めて平坦化
エッチングするもの絶縁膜金属膜
主な金属銅(Cu)アルミニウム(Al-Cu合金)。最も細い配線向けにルテニウムなども検討されている
金属の埋め込み電解めっきで溝を埋める。細い溝ではすき間(ボイド)を作らない埋め込みが課題スパッタなどで平らな膜を作るだけでよい
絶縁膜の埋め込み絶縁膜は先に平らに成膜するので問題になりにくい狭い配線の間を絶縁膜ですき間なく埋める必要がある(HDP-CVDなどを使ってきた)
CMP必須。溝の外の銅とバリアメタルを削り、配線を1本ずつ分離する金属の加工には使わない。絶縁膜の平坦化に使う
バリア層銅の拡散を防ぐため、溝の底と側壁をTaN/Taなどで覆う。細い配線では断面に占める割合が大きくなるアルミでは拡散が問題になりにくく、上下にTi/TiNなどの膜を重ねる
ビアの作り方デュアルダマシン法では、配線の溝とビアを同時に埋め、1回のCMPで仕上げるビアは別の工程で穴を開け、タングステンなどで埋めてCMPで平坦化してから、次の配線層を作る
微細配線での課題細くなると銅の抵抗率が上がり(サイズ効果)、バリア層の割合も増える細い金属の線をエッチングで加工する精度や、配線の間を絶縁膜で埋めることが課題

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

ダマシン法
銅の配線を作るとき。抵抗が低く、エレクトロマイグレーションに強い配線が必要な、先端のLSIの多層配線。
エッチングで形づくる配線
アルミニウムの配線を作るとき。配線の層が少ない製品や、比較的太い配線。最も細い配線で、ルテニウムなどを使う方法として検討されています。
傾向
現在の先端のLSIは、配線の大部分を銅のデュアルダマシン法で作ります。最も細い層では、抵抗の上がり方が小さくバリア層を薄くできる金属を、エッチングで形づくる方法が見直されています。

よくある質問

銅はなぜドライエッチングしにくいのですか？

塩素などのエッチングガスと反応してできる銅の化合物は揮発しにくく、室温付近では表面に残ってしまうからです。高い温度にすれば揮発させられますが、レジストなどが耐えられず、実用的な加工が難しくなります。そのため、銅は溝に埋め込んでCMPで形を作ります。

デュアルダマシン法とは何ですか？

絶縁膜に配線の溝と、下の層とつなぐビアの穴の両方を作っておき、1回の銅のめっきで同時に埋めて、1回のCMPで仕上げる方法です。溝とビアを別々に作るシングルダマシン法より工程を減らせます。

ダマシンという名前の由来は何ですか？

金属の表面に溝を彫って別の金属を埋め込む、象嵌(ぞうがん)の装飾技法に由来します。絶縁膜の溝に金属を埋め込む工程が、この技法に似ていることから名付けられました。

これからは、エッチングで形づくる配線に戻るのですか？

全部が戻るわけではありません。太い配線の層は、引き続き銅のダマシン法で作ります。線幅が非常に小さい層では、銅の抵抗率の上昇やバリア層の厚みが問題になるため、ルテニウムなどの金属をエッチングで加工する方法が検討されています。

理解度チェック

Cu配線の形成に一般的に用いられるダマシン法の説明として正しいものはどれか。

  1. ACu膜をドライエッチングで直接パターニングする
  2. B絶縁膜に溝を形成してCuを埋め込み、余分なCuをCMPで除去する
  3. CCuを熱酸化して配線の形状をつくる
答えと解説を見る

正解：B. 絶縁膜に溝を形成してCuを埋め込み、余分なCuをCMPで除去する

ダマシン法では、まず絶縁膜に配線の形の溝を掘り、バリア層とCuのシード層をスパッタで成膜したあと、電解めっきでCuを埋め込みます。最後にCMPで表面の余分なCuとバリアを削り取ると、溝の中にだけ配線が残ります。名前は、金属に溝を彫って金や銀をはめ込む古代ダマスカスの象嵌細工に由来します。溝とビアを一度に埋め込む方法はデュアルダマシン法と呼ばれます。

配線の溝とビアを同時にCuで埋め込み、1回のCMPで形成する方法を何と呼ぶか。

  1. Aシングルダマシン法
  2. Bエッチバック法
  3. Cデュアルダマシン法
答えと解説を見る

正解：C. デュアルダマシン法

デュアルダマシン法では、絶縁膜にビアの穴と配線の溝の両方をリソグラフィとエッチングで形成してから、バリア層、シード層、Cuめっきでまとめて埋め込み、1回のCMPで仕上げます。ビアと配線を別々につくるシングルダマシン法より、成膜・めっき・CMPがそれぞれ1回ずつ減り、ビアと配線の間にバリアの界面もできないため抵抗と信頼性の面でも有利です。穴と溝のどちらを先に開けるかで方式が分かれます。

先端LSIの配線材料が、アルミニウム(Al)から銅(Cu)に置き換えられた主な理由はどれか。

  1. A抵抗率が低く、エレクトロマイグレーション耐性も高いため
  2. Bドライエッチングで加工しやすいため
  3. C酸化膜との密着性が非常に高く、バリア層が不要なため
答えと解説を見る

正解：A. 抵抗率が低く、エレクトロマイグレーション耐性も高いため

Cuは抵抗率が約1.7 µΩ·cmとAl(約2.7 µΩ·cm)の約6割で配線遅延と電力を減らせ、融点が高く原子が動きにくいためエレクトロマイグレーションへの耐性も1桁以上高くなります。1997年にIBMが量産を発表し、0.13 µm世代ごろから主流になりました。一方、Cuは揮発性の化合物をつくりにくくドライエッチングが難しく、絶縁膜中に拡散しやすいため、ダマシン法で形成し、TaやTaNなどのバリア層で囲んで使います。

  1. Cu配線で、TaやTaNなどのバリアメタルを設ける主な目的はどれか。
  2. Cuに代わる微細配線の材料として検討されているルテニウム(Ru)などの金属の利点として正しいものはどれか。
  3. Cu配線のCMPで、一般的に研磨を段階に分けて行う理由として正しいものはどれか。

関連する用語の解説

ダマシン法
絶縁膜に溝を掘って金属を埋め込み、余分な金属をCMPで除去して配線を形成する方法。Cu配線に用いる。
デュアルダマシン法
配線の溝とビアの穴を絶縁膜につくってから、両方を同時にCuで埋め込み、1回のCMPで形成する方法。工程数を減らせる。
CMP
化学機械研磨。スラリーの化学作用とパッドの機械的研磨を組み合わせてウエハ表面を平坦化する。
バリアメタル
銅配線の周りに設け、銅が絶縁膜やシリコンへ拡散するのを防ぐ薄い金属膜。TaやTaNなど。
エレクトロマイグレーション
電流によって配線の金属原子が移動する現象。ボイドやヒロックが生じ、断線や短絡の原因になる。
