ライトスルーとライトバックの違い：キャッシュの書き込み方式を比較

書き込みの方式は、CPUがキャッシュにあるデータへ書き込んだときに、何をするかを決めます。ライトスルーのキャッシュは、キャッシュとメインメモリを同時に更新するので、メモリはいつも最新ですが、書き込みのたびにメモリへの通信が発生します。ライトバックのキャッシュは、キャッシュだけを更新してラインにダーティの印を付け、そのラインが追い出されるときに、あとからメモリへ書き込みます。ライトバックは、速く、帯域も少なくて済みますが、整合性を保つのが複雑になります。

項目ライトスルーライトバック
書き込みの方式書き込みのたびに、キャッシュと次のメモリの階層の両方へ書く書き込みはキャッシュだけを更新してダーティビットを立て、メモリの更新は追い出し時
メモリのトラフィック多い。書き込みのたびに外へ出る少ない。同じラインへの繰り返しの書き込みが、1回のライトバックにまとまる
書き込みの速度何もしないと遅い。ライトバッファが遅れの多くを隠す速い。書き込みはキャッシュの速度で終わる
メモリとの整合性メモリがいつも最新なので、DMAやほかのコアとの共有が簡単ラインが書き戻されるまでメモリが古いことがあるので、コヒーレンシにより注意が必要
複雑さ単純複雑。ダーティビット、追い出し時のライトバック、コヒーレンシのプロトコル
追い出しのコスト安い。書き込むものがないダーティなラインの追い出しには、メモリへの書き込みが1回余分にかかる
書き込みミスの方針通常はノーライトアロケート通常はライトアロケート
主な用途一部のL1キャッシュ、単純なシステムや信頼性を重視するシステム現代のほとんどのCPUのキャッシュ、特にL2とL3

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

ライトスルー
書き込みの帯域よりも、単純さと、いつも最新のメモリが重要なとき。
ライトバック
性能が重要なとき。特に、同じラインに何度も書き込むコードで効果が大きいです。

理解度チェック

  1. キャッシュの書き込み方式で、ライトバック方式の説明として正しいものはどれか。
  2. ライトスルー方式のキャッシュで、書き込みバッファを設ける主な目的はどれか。
  3. ライトバック方式のキャッシュで、各ラインに付けるダーティビットの役割として正しいものはどれか。
  4. 同じラインに何度も書き込む処理で、ライトスルー方式よりライトバック方式の方が有利になる主な理由はどれか。
