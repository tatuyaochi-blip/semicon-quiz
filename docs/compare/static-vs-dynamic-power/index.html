静的消費電力と動的消費電力の違い：原因・式・温度依存・削減方法を比較

CMOS回路の消費電力は、信号が切り替わるときに使う動的消費電力と、切り替わらなくても使い続ける静的消費電力に分けられます。動的消費電力は、配線やゲートの容量の充電と放電によるもので、P = αCV²fで表されます。静的消費電力は、オフのトランジスタなどを流れるリーク電流によるもので、温度が上がると急に増えます。微細化で電源電圧としきい値電圧が下がるにつれて、静的消費電力の割合が大きくなりました。

項目静的消費電力動的消費電力
別名リーク電力スイッチング電力
原因オフのトランジスタのサブスレッショルドリーク、ゲートリーク、接合リークなど負荷の容量の充電と放電。切り替えの途中でpMOSとnMOSが同時にオンになる貫通電流を含めることもある
式の目安P = V × Ileak(Ileak:リーク電流)P = αCV²f(α:活動率、C:容量、V:電源電圧、f:周波数)
回路が止まっているとき電源が入っている限り使われる信号が切り替わらなければ、ほぼゼロ
電源電圧への依存電圧に比例する以上に増える。DIBLなどでリーク電流自体も増えるため電圧の2乗に比例する
周波数への依存ほぼ依存しない周波数に比例する
温度への依存強い。温度とともに指数関数的に増え、熱暴走の原因にもなる弱い
しきい値電圧への依存強い。しきい値を下げるとサブスレッショルドリークが指数関数的に増える(室温で約60〜100 mV下げるごとにおよそ10倍)直接は依存しない。ただし、しきい値が高いと回路が遅くなる
削減方法パワーゲーティング、しきい値の高いトランジスタ(マルチVt)、待機中の電圧の低下、High-k/メタルゲートによるゲートリークの抑制クロックゲーティング、DVFS、電源電圧を下げる、容量を減らす、活動率を下げる
スケーリングでの変化電源電圧とともにしきい値電圧を下げたため急に増え、無視できない割合になった。FinFETなどゲートの制御性の高い構造で抑えているデナードスケーリングでは、寸法と電圧を同じ比率で縮めて電力密度を一定に保てた。電圧を下げにくくなり、電力密度の上昇が問題になった
効いてくる場面待機の時間が長い機器、高温で動くチップ高い周波数で活発に動いているとき

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

静的消費電力を減らす
待機の時間が長い機器や、高温で動くチップ。パワーゲーティングで使っていないブロックの電源を切り、速さの要らない経路にはしきい値の高いトランジスタを使います。
動的消費電力を減らす
高い周波数で活発に動くプロセッサ。クロックゲーティングで無駄な切り替えを止め、DVFSで負荷に応じて電圧と周波数を下げます。
組み合わせ
電圧を下げると動的消費電力は2乗で減りますが、回路が遅くなって処理の時間が延び、その間のリークのエネルギーが増えます。そのため、1回の演算のエネルギーが最小になる電圧があります。

よくある質問

電源電圧を半分にすると、動的消費電力はどうなりますか？

ほかの条件が同じなら、電圧の2乗に比例するので1/4になります。ただし、電圧を下げると回路が遅くなるので、同じ周波数で動かせるとは限りません。

温度が上がると、静的消費電力が増えるのはなぜですか？

しきい値以下で流れるサブスレッショルドリークは、温度が上がるとキャリアのエネルギーの分布が広がり、しきい値電圧も下がるので、急激に増えるからです。発熱が増えてさらに温度が上がる悪循環に注意が必要です。

クロックゲーティングで、静的消費電力は減りますか？

ほとんど減りません。クロックを止めると切り替えがなくなって動的消費電力は減りますが、電源はつながったままなので、リーク電流は流れ続けます。リークも減らすには、電源を切るパワーゲーティングを使います。

理解度チェック

CMOS回路の動的消費電力の式 P = αCV²f で、αが表すものとして正しいものはどれか。

  1. Aトランジスタの数
  2. B1クロックあたりに信号が切り替わる割合(活動率)
  3. Cチップの温度
答えと解説を見る

正解：B. 1クロックあたりに信号が切り替わる割合(活動率)

動的消費電力は、配線やゲートの容量を充電したり放電したりするときに使われる電力です。Cは切り替わる部分の容量、Vは電源電圧、fはクロックの周波数で、αは1クロックの間にどれだけの割合の信号が切り替わるかを表す活動率です。データが変わらない部分や、クロックを止めた部分は切り替わらないので、αを小さくすることも省電力の大切な手段です。

CMOS回路の静的消費電力(リーク電力)の説明として正しいものはどれか。

  1. Aクロックが速いほど、比例して大きくなる電力
  2. B信号が切り替わらなくても、オフのトランジスタなどを流れるリーク電流によって使われ続ける電力
  3. Cチップを製造するときにだけ使われる電力
答えと解説を見る

正解：B. 信号が切り替わらなくても、オフのトランジスタなどを流れるリーク電流によって使われ続ける電力

トランジスタは完全なスイッチではなく、オフのときもしきい値以下のリーク電流やゲートのリーク電流などがわずかに流れます。1つは小さくても、数十億個のトランジスタでは大きな電力になり、微細化でしきい値電圧が下がるにつれて目立つようになりました。静的な電力はクロックを止めても減らないので、電源そのものを切るパワーゲーティングなどで対策します。

チップの温度が上がると、リーク電力はどのように変わるか。また、それによって起こりうる問題はどれか。

  1. A温度とともに急激に(指数関数的に)増え、発熱が増えてさらに温度が上がる悪循環(熱暴走)につながることがある
  2. B温度が上がると減るので、熱いほど省電力になる
  3. C温度とは関係なく一定である
答えと解説を見る

正解：A. 温度とともに急激に(指数関数的に)増え、発熱が増えてさらに温度が上がる悪循環(熱暴走)につながることがある

しきい値以下のリーク電流は、温度が上がるとキャリアのエネルギーの分布が広がって急激に増え、目安として10℃ほどで大きく増えることがあります。リークが増えると発熱が増え、さらに温度が上がってリークが増える、という正の帰還が起こるので、冷却が不十分だと熱暴走に至る恐れがあります。そのため、温度センサで監視して周波数を下げるなどの制御が行われます。

  2. CMOS回路で、ほかの条件を変えずに電源電圧だけを半分にすると、動的消費電力はどうなるか。
  3. MOSFETがオフの状態で流れるリーク電流の主な成分の組み合わせとして正しいものはどれか。

関連する用語の解説

静的消費電力
信号が切り替わらなくても、オフのトランジスタなどを流れるリーク電流によって使われ続ける電力。リーク電力とも呼ぶ。温度とともに急に増える。
動的消費電力
CMOS回路で、信号が切り替わるときに容量を充電・放電するために使われる電力。活動率α、容量C、電圧V、周波数fを使ってαCV²fで表す。
活動率
回路の信号が1クロックあたりに切り替わる割合。動的消費電力の式αCV²fのα。クロックゲーティングなどで小さくできる。
パワーゲーティング
使っていない回路のブロックへの電源の供給をスイッチで切り、リーク電力もほぼなくす低消費電力の手法。状態の保存と復帰の時間に注意が必要。
クロックゲーティング
使っていない回路ブロックへのクロックの供給を止めて、無駄なスイッチングによる消費電力を減らす低消費電力設計の手法。
