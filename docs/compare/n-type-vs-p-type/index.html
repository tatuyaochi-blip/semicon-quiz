n型半導体とp型半導体の違い：ドーパント・多数キャリア・フェルミ準位・移動度を比較

n型半導体は、シリコンにリンやヒ素などのV族の不純物(ドナー)を加え、余った電子を多数キャリアにしたものです。p型半導体は、ホウ素などのIII族の不純物(アクセプタ)を加え、電子が足りずにできた正孔を多数キャリアにしたものです。フェルミ準位は、n型では伝導帯側、p型では価電子帯側に寄ります。シリコンでは電子の移動度が正孔の約2〜3倍あるので、同じ不純物濃度ならn型の方が抵抗率が低くなります。

どんなときに使うか

n型
電子を流したいとき。nMOSのソース・ドレインやnpnトランジスタのエミッタ・コレクタ、pMOSを作るnウェルなどに使います。
p型
正孔を流したいとき。pMOSのソース・ドレインやnpnトランジスタのベース、nMOSを作るpウェルなどに使います。
組み合わせ
n型とp型を接するとPN接合ができ、ダイオード、トランジスタ、太陽電池、LEDなどの基本になります。製造では、すでにある層に逆の型の不純物を多く加えて、型を反転させること(カウンタードープ)も使われます。

よくある質問

n型半導体は電子が多いので、全体として負に帯電しているのですか？

いいえ、全体としては電気的に中性です。ドナーが電子を1個出すと、ドナー自身は正のイオンになって格子に残るので、電子の負の電荷と打ち消し合います。p型でも同じで、正孔の正の電荷とイオン化したアクセプタの負の電荷がつり合っています。

n型の中にも正孔はあるのですか？

あります。熱平衡では電子密度と正孔密度の積が真性キャリア密度の2乗(n × p = ni²)になるので、ドナー濃度が1×10¹⁶ cm⁻³なら、室温の正孔密度は約1×10⁴ cm⁻³です。数はわずかですが、この少数キャリアがPN接合やバイポーラトランジスタの動作で重要な役割をします。

ドナーとアクセプタを両方加えるとどうなりますか？

互いに打ち消し合い(補償)、多い方の型になります。キャリア密度はおよそ濃度の差で決まりますが、移動度は両方のイオン化不純物による散乱で下がります。ウェルの中に逆の型のソース・ドレインを作るときは、この性質を使って型を反転させています。

n型とp型で、フェルミ準位の位置が違うのはなぜですか？

フェルミ準位は、電子が占める確率が1/2になるエネルギーで、キャリアの分布を表しているからです。伝導帯の電子が多いn型では伝導帯側に、価電子帯の電子が抜けて正孔が多いp型では価電子帯側に寄ります。室温のシリコンでは、不純物濃度が10倍になるごとに約60 mVずつ帯の端に近づきます。

理解度チェック

シリコンにリン(P)を不純物として添加したときの説明として正しいものはどれか。

  1. A正孔が多数キャリアのp型半導体になる
  2. B電子が多数キャリアのn型半導体になる
  3. Cキャリアは増えず、真性半導体のままである
答えと解説を見る

正解：B. 電子が多数キャリアのn型半導体になる

リンはV族で価電子が5個あり、シリコン(IV族)の共有結合に使われない電子が1個余ります。この電子は約0.045 eVの浅い準位にゆるく束縛されているだけなので、室温でほぼすべて伝導帯に出て伝導電子になります。こうした不純物をドナーといい、n型半導体ができます。ほかにヒ素(As)やアンチモン(Sb)もドナーです。p型にするにはホウ素(B)などのIII族元素(アクセプタ)を添加します。

シリコンにホウ素(B)を不純物として添加したときの説明として正しいものはどれか。

  1. A電気的に不活性で、導電型は変わらない
  2. Bドナーとして働き、n型半導体になる
  3. Cアクセプタとして働き、p型半導体になる
答えと解説を見る

正解：C. アクセプタとして働き、p型半導体になる

ホウ素はIII族で価電子が3個のため、共有結合に電子が1個足りず、周囲から電子を受け取ります。すると価電子帯に正孔ができ、シリコンはp型になります。ホウ素はシリコン中の代表的なアクセプタで、準位は価電子帯から約0.045 eVと浅く、室温でほぼ全てイオン化します。原子が軽く拡散が速いため、浅い接合を作るときは低エネルギー注入やBF2の注入が使われます。

p型半導体の多数キャリアはどれか。

  1. Aイオン化したアクセプタ
  2. B正孔
  3. C電子
答えと解説を見る

正解：B. 正孔

p型ではアクセプタが価電子帯から電子を受け取るため正孔が増え、多数キャリアは正孔、少数キャリアは電子になります。イオン化したアクセプタは格子に固定された負の電荷で、自分は動けません。ただし空乏層では、この固定電荷が電界と内蔵電位を生み出す主役になります。MOSFETでは、p型基板の表面に少数キャリアの電子を集めて(反転)nチャネルを作ります。

  1. n型半導体のフェルミ準位の位置として正しいものはどれか。
  2. シリコン中のリンがつくるドナー準位の、バンドギャップ内での位置として正しいものはどれか。
  3. シリコンに注入する不純物と導電型の組み合わせとして正しいものはどれか。

関連する用語の解説

ドナー
半導体に電子を供給する不純物。シリコンに対してはリン(P)やヒ素(As)などのV族元素で、n型半導体をつくる。
アクセプタ
半導体から電子を受け取り、正孔を生じさせる不純物。シリコンに対してはホウ素(B)などのIII族元素で、p型半導体をつくる。
フェルミ準位
電子がその準位を占める確率がちょうど1/2になるエネルギー。n型では伝導帯側に、p型では価電子帯側に寄る。
移動度
電界をかけたときのキャリアの動きやすさ。シリコンでは電子の移動度が正孔より大きい。
真性キャリア密度
不純物を含まない半導体で、熱によって生じる電子と正孔の密度(niと書く)。シリコンでは室温で約1×10¹⁰ cm⁻³で、温度が上がると急激に増える。熱平衡では n × p = ni² が成り立つ。
