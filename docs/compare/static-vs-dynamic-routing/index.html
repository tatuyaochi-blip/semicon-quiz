静的ルーティングと動的ルーティングの違い：設定・障害時の切り替え・負荷・規模・使い分けを比較

ルータは、経路表を見てパケットの次の転送先を決めます。この経路表に経路を入れる方法には、管理者が手で設定する静的ルーティング(スタティックルーティング)と、ルータどうしがルーティングプロトコルで情報を交換して自動で作る動的ルーティング(ダイナミックルーティング)があります。静的ルーティングは単純で、ルータに余計な負荷をかけず、動きを予測しやすい一方、障害が起きても自動では切り替わらず、ネットワークが大きくなると設定と管理の手間が増えます。動的ルーティングは、OSPFやBGPなどで経路を自動で求め、障害のときには別の経路に切り替えます。実際のネットワークでは、出口が1つしかない拠点には静的なデフォルトルートを、冗長な経路をもつ部分には動的ルーティングを使うように、両方を組み合わせるのが一般的です。

項目静的ルーティング動的ルーティング
経路の決め方管理者が、宛先のネットワークと次の転送先(ネクストホップ)を各ルータに設定するルータどうしがルーティングプロトコル(OSPF、BGP、RIPなど)で情報を交換し、経路を自動で求める
障害のときの動き自動では切り替わらない。隣のルータより先の障害には気づかず、届かない経路を使い続けることがある障害を検知すると、別の経路を求め直して切り替える
ルータの負荷と帯域経路の情報を交換しないので、そのためのCPU・メモリ・回線の帯域を使わない経路の情報のやり取りと経路の計算に、CPU・メモリ・帯域を使う
設定の手間と規模ネットワークや経路が増えるほど、設定の量と誤りの危険が増える。変更のたびに、関係するルータをすべて直す経路の追加や変更が自動で伝わるので、大きなネットワークでも管理しやすい。ただし、プロトコルの設計と設定の知識が要る
動きの予測のしやすさ設定したとおりに動くので、予測しやすいプロトコルの計算の結果しだいで、使う経路が変わる
セキュリティ経路の情報を受け取らないので、偽の経路を送り込まれる心配がない偽の経路を受け入れないよう、隣のルータの認証や、受け入れる経路の制限(フィルタ)が要る
アドミニストレーティブディスタンス一般に小さい値で、動的な経路より優先される(値は機器によって違う。例えば1)プロトコルごとに決まる(例えばOSPFを110、RIPを120とする機器がある)
向いている場所小さなネットワーク、出口が1つの拠点のデフォルトルート、プロバイダへの出口冗長な経路をもつネットワーク、拠点の多い企業のネットワーク、インターネットのAS間(BGP)

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

静的ルーティング
ルータが少なく構成がほとんど変わらないネットワークや、支社のように出口が1つしかない拠点。0.0.0.0/0 のデフォルトルートを1つ設定するだけで済む場合に向きます。
動的ルーティング
ルータが多いネットワークや、冗長な経路をもち、障害のときに自動で切り替えたいネットワーク。経路の追加や変更が多い場合にも向きます。

よくある質問

静的ルーティングでも、障害のときに予備の経路に切り替えられますか？

ある程度はできます。アドミニストレーティブディスタンスを、ふだん使う経路より大きくした静的経路(フローティングスタティックルート)を予備として設定しておくと、ふだんの経路が経路表から消えたときにだけ、予備の経路が使われます。ただし、ふだんの経路が消えるのは、ルータが自分のリンクの切断に気づいたときなどに限られ、その先の障害には気づけません。そのため、相手に届くかを定期的に確かめて経路を消す機能と組み合わせることもあります。

デフォルトルートとは何ですか？

0.0.0.0/0(IPv6では ::/0)のように、すべての宛先に一致する経路です。ルータは、宛先に一致する経路のうちプレフィックスが最も長いものを選ぶ(ロンゲストマッチ)ので、デフォルトルートはほかに一致する経路がないときだけ使われます。出口が1つしかない拠点では、宛先ごとに経路を設定する代わりに、デフォルトルートを1つ静的に設定するのが一般的です。

静的経路と動的な経路が同じ宛先にあるとき、どちらが使われますか？

プレフィックス長の違う経路は別の経路として扱われ、転送のときはロンゲストマッチで最も長いものが選ばれます。同じ宛先・同じプレフィックス長の経路が両方にあるときは、アドミニストレーティブディスタンスの小さい方が経路表に入ります。静的経路は一般に動的な経路より小さい値なので、静的経路が優先されます。具体的な値は機器のメーカーによって違います。

静的ルーティングと動的ルーティングは、一緒に使えますか？

使えます。多くのネットワークで両方を組み合わせます。例えば、本社と支社の間はOSPFで経路を交換し、インターネットへの出口には静的なデフォルトルートを設定して、そのデフォルトルートをOSPFでほかのルータに広める、といった使い方です。

理解度チェック

動的ルーティングの説明として正しいものはどれか。

  1. A管理者が各ルータに経路を手で設定し、障害が起きても設定を変えるまで同じ経路を使い続ける
  2. Bルータどうしがルーティングプロトコルで経路の情報を交換し、障害で経路が使えなくなると自動的に別の経路に切り替える
  3. Cパケットごとに経路をランダムに選び、複数の経路に負荷を均等に分散する
答えと解説を見る

正解：B. ルータどうしがルーティングプロトコルで経路の情報を交換し、障害で経路が使えなくなると自動的に別の経路に切り替える

静的ルーティングは、管理者が経路を手で設定する方法です。設定が単純で動きを予測しやすく、小さなネットワークや、出口が1つしかない拠点のデフォルトルートに向きますが、障害が起きても自動では切り替わりません。動的ルーティングでは、ルータがOSPFやBGPなどのルーティングプロトコルで情報を交換して経路表を自動で作り、リンクが切れると別の経路を計算し直します。インターネットでは、組織のネットワーク(自律システム)の間の経路をBGPで交換しています。実際のネットワークでは、両方を組み合わせて使うのが一般的です。

支社のルータR2は、本社のルータR1と 10.255.0.0/30 のリンクでつながっており、R1側のアドレスは 10.255.0.1、R2側は 10.255.0.2 である。R2に、本社のネットワーク 192.168.1.0/24 への静的経路を設定するとき、次の転送先(ネクストホップ)に指定するアドレスとして適切なものはどれか。

  1. A10.255.0.1
  2. B10.255.0.2
  3. C192.168.1.1(R1の本社のLAN側のアドレス)
答えと解説を見る

正解：A. 10.255.0.1

静的経路では、宛先のネットワークと、そこへ送るために次に渡すルータのアドレス(ネクストホップ)を設定します。ネクストホップは、自分が直接つながっているネットワークの上にある、隣のルータのアドレスにするのが基本です。ここではリンクの向こう側にあるR1の 10.255.0.1 で、R2はARPでこのアドレスのMACアドレスを調べてフレームを送ります。支社に出口が1つしかない場合は、宛先ごとに経路を書く代わりに、0.0.0.0/0 のデフォルトルートを1つだけ設定する方法もよく使われます。

あるルータは、同じ宛先 192.168.50.0/24 への経路を、OSPFとRIPの両方から学んだ。このルータでは、経路の情報源ごとの優先度を表すアドミニストレーティブディスタンス(値が小さいほど優先)が、OSPFは110、RIPは120である。経路表に入る経路として正しいものはどれか。

  1. A両方の経路を経路表に入れ、パケットごとに交互に使う
  2. BRIPの経路だけを入れる
  3. COSPFの経路だけを入れる
答えと解説を見る

正解：C. OSPFの経路だけを入れる

OSPFのコストとRIPのホップ数のように、ルーティングプロトコルによって経路の良さを表す値(メトリック)の意味が違うので、そのままでは比べられません。そこで、同じ宛先・同じプレフィックス長の経路が複数の情報源から得られたときは、情報源ごとの信頼の度合いであるアドミニストレーティブディスタンスの小さい方を採用します。ここではOSPFの110がRIPの120より小さいので、OSPFの経路が経路表に入ります。直接つながっているネットワークは0、静的経路は1のように、人が設定したものほど小さい値にするのが一般的ですが、呼び方や既定値は機器のメーカーによって違います。

  1. ルータの経路表に、静的経路の 10.0.0.0/8(次の転送先はルータA、アドミニストレーティブディスタンス1)、OSPFで学んだ 10.1.0.0/16(ルータB、110)、RIPで学んだ 10.1.1.0/24(ルータC、120)の3つが入っている。宛先が 10.1.1.5 のパケットが送られるルータはどれか。
  2. ルータの経路表に、0.0.0.0/0(次の転送先はルータA)、10.0.0.0/8(ルータB)、10.1.0.0/16(ルータC)、10.1.2.0/24(ルータD)の4つの経路がある。宛先が 10.1.5.9 のパケットは、どのルータに送られるか。

関連する用語の解説

ルーティング(経路制御)
IPのネットワークで、パケットを宛先まで届けるために、どの経路で送るかを決めること。各ルータは経路表(ルーティングテーブル)をもち、宛先IPアドレスに最も長く一致する経路(最長一致)を選んで次のルータに渡す。経路表は、人が設定する静的ルーティングか、OSPF、RIP、BGPなどのルーティングプロトコルで自動的に作る動的ルーティングで作る。
ルータ
異なるネットワークの間でパケットを中継する、ネットワーク層(第3層)の機器。受け取ったパケットの宛先IPアドレスを経路表(ルーティングテーブル)と照らし合わせ、次に渡すルータ(ネクストホップ)と出口のインターフェースを決めて送り出す。家庭用のルータは、NAPTやDHCPサーバ、ファイアウォールの機能もまとめてもつ。
アドミニストレーティブディスタンス
同じ宛先・同じプレフィックス長の経路を、静的経路やOSPF、RIPなど複数の情報源から得たときに、どれを経路表に入れるかを決めるための、情報源ごとの優先度の値。値が小さいほど優先される。プレフィックス長が違う経路どうしの選択には使われず、そちらはロンゲストマッチで決まる。呼び方や既定値は、機器のメーカーによって異なる。
ロンゲストマッチ(最長一致)
ルータが、宛先IPアドレスに一致する経路が経路表に複数あるとき、プレフィックスが最も長い(最も具体的な)経路を選ぶ規則。例えば 10.0.0.0/8 と 10.1.0.0/16 の両方に一致する宛先には /16 の経路を使う。どこにも一致しないときに使うデフォルトルート(0.0.0.0/0)は、長さ0の最も短い経路にあたる。
OSPF
Open Shortest Path Firstの略。組織の中で使うリンクステート型のルーティングプロトコル。各ルータが自分のリンクの状態を広めてネットワークの構成を共有し、ダイクストラ法で、コストの合計が最も小さい経路を計算する。コストは一般にリンクの帯域から決め、ネットワークを複数のエリアに分けて、規模の大きなネットワークにも対応できる。
BGP
Border Gateway Protocolの略。インターネットで、AS(自律システム。プロバイダなどの組織が管理するネットワークの単位)の間で経路の情報を交換するルーティングプロトコル。経路に付いた、通ってきたASの並び(AS_PATH)などの属性と、組織ごとの方針(ポリシー)に基づいて経路を選ぶ。ルータどうしはTCPの179番ポートで接続して情報をやり取りする。
