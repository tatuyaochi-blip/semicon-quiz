RISCとCISCの違い：命令セットの考え方と代表例を比較

RISC(縮小命令セットコンピュータ)とCISC(複合命令セットコンピュータ)は、命令セットの設計に関する2つの考え方です。RISCは、単純で長さが一定の少数の命令を使い、パイプライン処理がしやすいです。CISCは、複雑で長さが可変の多数の命令を使い、1つの命令でより多くの仕事ができます。今では境界はあいまいで、現代のx86プロセッサは、CISCの命令を内部で単純な演算に変換して実行します。そのため、違いが重要なのは、主に命令セットとソフトウェアの環境の面です。

項目RISCCISC
考え方少数の単純な命令を使う。1つの命令の仕事は小さく、速く実行できるように作る多数の強力な命令を使う。1つの命令で複数のステップを実行するものもある
命令の長さ固定(RISC-VやAArch64の基本の命令セットでは32ビットなど)可変(x86の命令は1〜15バイト)
メモリアクセスロード/ストア方式。メモリに触るのはロードとストアの命令だけで、演算はレジスタ同士で行う多くの命令で、メモリのデータを直接オペランドにできる
レジスタ汎用レジスタが多い(RISC-VやAArch64では32個)少なめ(x86-64の汎用レジスタは16個)
デコード単純で、パイプライン処理に向き、ハードウェアも小さくできる複雑。現代のx86のコアは、命令を内部のマイクロ命令に変換する
コードサイズ大きめ。ただし圧縮命令の拡張(ThumbやRISC-VのC拡張)で小さくできる1つの命令の仕事が多いので、密になりやすい
代表例ARM、RISC-V、MIPS、PowerPCx86とx86-64(Intel、AMD)、IBM z/Architecture
主な用途スマートフォン、組み込み機器、最近はノートPCやサーバーにもパソコンとサーバー。ソフトウェアの互換性が重要な分野

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

RISC
電力効率が重要で、単純で拡張しやすい設計が欲しいときに向きます。スマートフォン、組み込み機器、独自のプロセッサなど。RISC-Vはオープンな標準なので、誰でもライセンス料なしでコアを作れます。
CISC
今、CISCを選ぶ理由はソフトウェアの互換性です。膨大なx86のソフトウェア資産が、パソコンとサーバーでの優位を支えています。
実際には
性能を左右するのは、RISCかCISCかよりも、マイクロアーキテクチャ、キャッシュ、製造プロセスです。

理解度チェック

  1. RISC(縮小命令セットコンピュータ)の特徴として正しいものはどれか。
  2. ARM、x86、RISC-Vといった名前が主に表しているものはどれか。
  3. RISC-Vの特徴として正しいものはどれか。
  4. RISC-Vのようなロード・ストア・アーキテクチャの特徴として正しいものはどれか。
  5. CPUが1つの命令を処理する基本的な流れとして正しい順序はどれか。

ほかの比較

  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • NAND型とNOR型フラッシュメモリの違い：速度・容量・用途を比較NAND型とNOR型のフラッシュメモリを、セルの接続・読み出し速度・消去単位・容量・コスト・信頼性・用途の観点で表にして比較します。
  • BJTとMOSFETの違い：制御方式・速度・用途を比較バイポーラトランジスタ(BJT)とMOSFETを、制御方式・入力電流・キャリア・速度・オン状態・温度特性・集積度・用途の観点で表にして比較します。
  • FinFETとGAAトランジスタの違い：構造・制御性・製造を比較FinFETとゲートオールアラウンド(GAA)ナノシートのトランジスタを、ゲート構造・チャネル・静電制御・幅の調整・製造・採用状況の観点で表にして比較します。
  • CPUとGPUの違い：構造・得意な処理・用途を比較CPUとGPUを、設計の目的・コア数・実行モデル・キャッシュ・メモリ帯域・分岐・データ転送・得意な処理の観点で表にして比較します。
  • ASIC・FPGA・SoCの違い：柔軟性・コスト・用途を比較ASIC、FPGA、SoCを、それぞれが何か、柔軟性・性能・初期費用と単価・開発期間・用途の観点で表にして比較します。
  • SiCとGaNのパワー半導体の違い：耐圧・周波数・用途を比較SiCとGaNのパワー半導体を、バンドギャップ・熱伝導率・素子の種類・耐圧・スイッチング周波数・ウェハ・コスト・用途の観点で表にして比較します。
  • EUVとDUV露光の違い：波長・光学系・コストを比較EUV露光とDUV(ArF液浸)露光を、波長・光源・光学系・マスク・解像度・コスト・欠陥・使われる場所の観点で表にして比較します。
  • CMOSイメージセンサーとCCDの違い：読み出し・速度・用途を比較CMOSイメージセンサーとCCDを、読み出し方式・消費電力・速度・ノイズ・シャッター方式・集積度・コスト・用途の観点で表にして比較します。
  • ウェットエッチングとドライエッチングの違い：方向性・選択比・用途を比較ウェットエッチングとドライエッチングを、媒体・方向性・選択比・微細化・スループット・ダメージ・コスト・使われる工程の観点で表にして比較します。
