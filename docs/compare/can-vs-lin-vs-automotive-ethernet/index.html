CAN・LIN・車載イーサネットの違い：速度・配線・ノードの構成・コスト・用途を比較

自動車の中では、必要な速度とコストに合わせて、複数のネットワークを使い分けています。LINは1本の信号線で最大20 kbit/s程度の安いネットワークで、スイッチやモータなどボディ系の部品をつなぎます。CANは2本の線の差動信号で、ECUどうしが優先度つきで通信でき、最大1 Mbit/s(CAN FDではデータの部分を数 Mbit/s)の信頼性の高いネットワークとして、エンジンやブレーキなどの制御に使われます。車載イーサネットは1対のより対線で100 Mbit/s以上を送り、カメラなどの大量のデータやECUどうしを結ぶバックボーンを担います。

どんなときに使うか

LIN
速度がいらず、安さが最優先のスイッチやモータ、センサを、近くのECUにつなぐとき。CANのサブネットとして使います。
CAN
制御のデータを、優先度に従って確実にやり取りしたいとき。多くのECUを1本のバスでつなぎ、ノイズに強い通信が必要なとき。データ量が増えたらCAN FDを使います。
車載イーサネット
カメラやセンサの大量のデータ、ソフトウェアの更新、ゾーンアーキテクチャで中央のコンピュータとゾーンECUを結ぶバックボーンなど、100 Mbit/s以上の帯域が必要なとき。

よくある質問

CANで、2つのノードが同時に送り始めるとどうなりますか？

IDのビットを送りながらバスの状態を監視し、優先度の高い(IDの値が小さい)フレームを送っているノードだけが送信を続けます。負けたノードは送信をやめて後で送り直すので、勝ったフレームは壊れずに届きます。これを非破壊の調停と呼びます。

LINはなぜ安いのですか？

信号線が1本で済み、通信のタイミングはマスタが決めるので、スレーブの回路が簡単だからです。マスタが送る同期の信号でスレーブがクロックを合わせるため、スレーブは水晶振動子なしの発振器でも動けます。

車載イーサネットは、オフィスなどの一般のイーサネットと何が違うのですか？

1対のより対線だけで全二重の通信を行い、配線を軽く安くしています。また、車の中の強いノイズや広い温度範囲に耐えるように作られ、決まった時間内に届ける必要がある通信にはTSNの規格で時刻と帯域を管理します。

車載イーサネットが増えると、CANやLINはなくなりますか？

すぐにはなくなりません。高速なバックボーンやカメラなどにはイーサネットが使われますが、スイッチやモータ、制御のデータのように少量で確実さが大事な通信には、安くて実績のあるCANやLINが引き続き使われます。

理解度チェック

車載ネットワークのLINの特徴として正しいものはどれか。

  1. A2本の差動信号線で最大10 Mbit/sの通信を行う高速な方式で、ブレーキやステアリングなど安全上重要な制御に使われる
  2. B1対のより対線で1 Gbit/sの通信を行う方式で、カメラの映像やディスプレイの表示データの伝送に使われる
  3. C1本の信号線に1台のマスタと複数のスレーブをつなぐ低速(最大20 kbit/s程度)で安価な方式で、パワーウィンドウやミラーの制御などに使われる
答えと解説を見る

正解：C. 1本の信号線に1台のマスタと複数のスレーブをつなぐ低速(最大20 kbit/s程度)で安価な方式で、パワーウィンドウやミラーの制御などに使われる

LIN(Local Interconnect Network)は、1本の信号線を使い、マスタが決めた順番でスレーブに送信させる方式で、最大20 kbit/s程度と低速です。UARTに近い簡単な通信回路で作れ、スレーブは高精度の発振器がなくても同期できるので安価です。パワーウィンドウ、ミラー、シート、スイッチ類など、速さが必要ない部分をCANのサブネットワークとしてつなぎます。10 Mbit/sの方式はFlexRay、1 Gbit/sの方式は車載イーサネットの説明です。

CANで、2つのノードが同時にフレームを送り始めたときの動作として正しいものはどれか。

  1. A2つのフレームが衝突して両方とも壊れるので、両方のノードがランダムな時間だけ待ってから送り直す
  2. BIDの値が小さい(優先度が高い)フレームがそのまま送信を続け、負けたノードは送信をやめて後で送り直すので、勝ったフレームは壊れない
  3. CIDの値が大きいフレームが優先され、IDの値が小さいフレームは捨てられて送り直されない
答えと解説を見る

正解：B. IDの値が小さい(優先度が高い)フレームがそのまま送信を続け、負けたノードは送信をやめて後で送り直すので、勝ったフレームは壊れない

CANのバスでは、0(ドミナント)と1(リセシブ)が同時に出されると0が勝ちます。送信中のノードは自分が出したビットとバスの状態を1ビットずつ比べ、1を出したのに0が見えたら調停に負けたと判断して送信をやめます。IDは先頭から送られるので、値の小さいIDほど優先度が高くなり、勝ったフレームは壊れずにそのまま届きます。これを非破壊調停と呼びます。衝突後にランダムな時間待つのは、昔のイーサネットのCSMA/CDの方式です。

両端に120 Ωの終端抵抗を付けたCANのバスで、電源を切った状態でCAN_HとCAN_Lの間の抵抗を測った。正常な場合の値として最も近いものはどれか。

  1. A120 Ω
  2. B240 Ω
  3. C60 Ω
答えと解説を見る

正解：C. 60 Ω

CANのバスは、信号の反射を防ぐために、両端にそれぞれ120 Ωの終端抵抗を付けます。CAN_HとCAN_Lの間から見ると、2つの120 Ωが並列につながっているので、120 × 120 / (120 + 120) = 60 Ωになります。測定値が120 Ωなら片方の終端抵抗が付いていない、40 Ω程度なら終端抵抗が3つ付いているなどの配線の誤りが疑われます。240 Ωは2つを直列とみなした誤りです。

  1. CAN FDの特徴として正しいものはどれか。
  2. 車載イーサネット(100BASE-T1や1000BASE-T1など)の特徴として正しいものはどれか。
  3. 自動車の電子システムで進んでいる「ゾーンアーキテクチャ」への移行の説明として正しいものはどれか。

関連する用語の解説

CAN
Controller Area Networkの略で、2本の線の差動信号でECUどうしをつなぐ車載ネットワーク。IDの値が小さいほど優先度が高く、同時に送信を始めても非破壊の調停で1つのフレームだけが残る。従来のCANは最大1 Mbit/sで、CAN FDではデータの部分を数 Mbit/sに高速化できる。
ECU(電子制御ユニット)
エンジン、ブレーキ、ドアなどを制御する、マイコンを中心とした車載の制御装置。機能ごとに増えて1台に100個を超えることもあり、ゾーンアーキテクチャなどによる統合が進んでいる。
ゾーンアーキテクチャ
車両の場所ごとに置いたゾーンECUが近くのセンサやアクチュエータをつなぎ、制御の処理は中央の高性能なコンピュータにまとめる電子システムの構成。機能ごとにECUを置く従来の方式より、ワイヤーハーネスを短く軽くできる。
差動信号
2本の線に逆向きの信号を流し、電圧の差で0と1を表す方式。2本に同じように乗った雑音が打ち消されるので、小さな振幅で速く送れる。
