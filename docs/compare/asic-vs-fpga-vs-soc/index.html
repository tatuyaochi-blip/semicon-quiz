ASIC・FPGA・SoCの違い：柔軟性・コスト・用途を比較

この3つの言葉は、それぞれ別のことを表しています。ASICは、特定の用途のために専用に設計したチップです。FPGAは、製造後に論理を書き換えられるチップです。SoC(システムオンチップ)は、CPUコア、GPU、メモリコントローラ、入出力など、システム全体を1つのチップにまとめたものです。言葉は重なる部分もあり、スマートフォンのSoCは多くの場合ASICとして作られ、プロセッサを内蔵したFPGAはSoCでもあります。

項目ASICFPGASoC
何か特定の用途のために設計・製造されたチップ製造後に設定できる、プログラマブルな論理ブロックと配線を持つチッププロセッサコア、メモリコントローラ、入出力、アクセラレータなど、システムの主な部分を1つにまとめたチップ
柔軟性製造後は変えられない現場でも書き換えられるハードウェアは固定だが、プロセッサで動くソフトウェアは更新できる
性能と電力効率最も高い。論理が用途に合わせて作られている中間。書き換えのための回路が、面積・速度・電力の負担になる高い。よく使う処理の専用アクセラレータがある
初期費用非常に高い。先端ノードでは、設計・検証・マスクで数百万〜数億ドルかかる低い。出来合いのデバイスを買う高い。専用チップなのでASICと同程度
量産時の単価最も安い1個あたりは高い安い
開発期間長い。設計・検証・製造に数か月〜数年かかる短い。数日〜数週間で動かせることもある長い
設計のバグの修正高くつく。多くの場合、マスクを作り直す(リスピン)簡単。書き換えるだけ高くつく。ただし一部はソフトウェアで回避できる
主な用途暗号資産のマイニング機、ネットワーク・ストレージのコントローラ、専用のコーデック試作、少量生産の製品、通信機器や計測機器、ハードウェアによる高速化スマートフォン、タブレット、ゲーム機、多くの組み込み機器

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

ASIC
生産数が多く、機能が固まっていて、コストあたりの性能と電力効率を最大にしたいとき。
FPGA
生産数が少ないとき、仕様が変わるかもしれないとき、すぐに始めたいとき。試作、立ち上げ期の製品、専門的な機器など。
SoC
スマートフォンのように、完成した製品を1つのチップで実現したいとき。実際にはSoCはASICとして設計され、製造の前にFPGAで試作することもよくあります。

理解度チェック

  1. FPGAの特徴として正しいものはどれか。
  2. CPU、GPU、メモリコントローラ、通信機能など、システムに必要な機能を1つのチップに集積したLSIを何と呼ぶか。
  3. 特定の用途や顧客向けに専用に設計されたLSIを何と呼ぶか。
  4. 大規模なSoCの検証で、設計した回路を専用のハードウェアやFPGAの上で動かし、ソフトウェアと組み合わせて高速に検証する手法はどれか。
  5. AIの推論処理を高速かつ低い消費電力で行うために、スマートフォン用のSoCなどに搭載される専用回路はどれか。
