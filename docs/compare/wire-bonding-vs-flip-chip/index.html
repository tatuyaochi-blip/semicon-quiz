ワイヤボンディングとフリップチップの違い：チップの接続方法を比較

チップをパッケージにつなぐ、主な2つの方法です。ワイヤボンディングでは、チップを上向きに置き、細い金属線でチップの端のパッドとパッケージをつなぎます。フリップチップでは、チップを裏返して下向きにし、表面のはんだや銅のバンプを、基板に直接つなぎます。ワイヤボンディングは安くて柔軟で、フリップチップは、はるかに多くの接続、短い経路、よい電気的な性能が得られます。

項目ワイヤボンディングフリップチップ
接続細い線(金、銅、アルミニウム。およそ15〜50 µm)を、チップのパッドからパッケージへ溶接するチップ表面のはんだや銅のバンプを、基板に直接接合する
チップの向き上向き下向き(裏返す)
入出力の位置と数チップの端のパッドだけ。数百から約1,000の接続表面全体にバンプを並べる(エリアアレイ)。数千の接続
電気的な性能長い線がインダクタンスと抵抗を増やし、速度と電力供給を制限する経路が短く、インダクタンスが小さい。信号と電源の品質がよい
放熱の経路熱は主にチップの裏からダイアタッチへ逃げるチップの裏を、ヒートスプレッダやヒートシンクに直接つなげられる
工程1本ずつ順にボンディングするので遅めリフローですべてのバンプを一度に接合し、応力を和らげるアンダーフィルの樹脂を入れる
パッケージの大きさ大きい。チップの周りに、ワイヤのための空間が要る小さい
コスト安い。成熟していて柔軟で、チップにバンプを付ける必要がない高い。バンプの形成、より細かい基板、アンダーフィルが必要
主な用途メモリ、マイコン、アナログIC、LED、低コストの製品CPU、GPU、SoCなど、高速でピン数の多いチップ

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

ワイヤボンディング
ピン数が多くなく、コストが最優先のとき。ほとんどのマイコン、メモリ、アナログ部品など。
フリップチップ
数千の接続、高速、大電力が必要なとき。プロセッサや高性能なチップ。
補足
フリップチップのバンプは、先端パッケージの出発点でもあり、積層したチップを、はるかに小さなマイクロバンプでつなぎます。

理解度チェック

  1. ワイヤボンディングの説明として正しいものはどれか。
  2. フリップチップ実装の説明として正しいものはどれか。
  3. フリップチップ実装で、チップと基板の隙間にアンダーフィル樹脂を充填する主な目的はどれか。
  4. BGA(ボールグリッドアレイ)パッケージの特徴として正しいものはどれか。
  5. フリップチップ接続で、はんだボールの代わりに銅の柱(Cuピラー)を使う主な利点はどれか。
  6. TSVで積層したチップどうしや、チップとインターポーザの接続に使われる、通常のはんだボールよりはるかに小さいバンプを何と呼ぶか。
