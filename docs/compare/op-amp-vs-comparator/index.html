オペアンプとコンパレータの違い：使い方・出力段・速さ・位相補償を比較

記号はどちらも同じ三角形で、2つの入力の電圧の差を大きく増幅しますが、作られた目的が違います。オペアンプは負帰還をかけて使うことを前提に、発振しないよう位相補償を入れ、出力をアナログの電圧として滑らかに動かします。コンパレータは開ループで使い、2つの電圧の大小をHかLの2値ですばやく出すように作られていて、位相補償を持たず、出力もロジックにつなぎやすい形です。そのため、オペアンプをコンパレータの代わりにすると遅く、コンパレータに負帰還をかけると発振しやすくなります。

どんなときに使うか

オペアンプ
信号をアナログのまま増幅したり、フィルタやバッファを作ったりするとき。負帰還をかけて、出力を連続に動かす用途。
コンパレータ
電圧がしきい値を超えたかを、速く確実に判定してロジックに伝えたいとき。電池の電圧の監視、ゼロクロスの検出、ADCの中の比較など。
オペアンプで代用
応答が遅くてよく、出力の電圧のレベルが後ろの回路に合うとき。データシートで、入力の差動の電圧の範囲や飽和したときの動作を確かめてから使います。

よくある質問

オペアンプを、コンパレータの代わりに使ってもよいですか？

遅くてよい用途なら使えることがあります。ただし、位相補償のために切り替わりが遅く、飽和からの回復にも時間がかかり、出力のHとLの電圧がロジックに合わないこともあります。入力の間に保護のダイオードを持つ品種では、大きな差動の電圧をかけると電流が流れるので注意が必要です。

コンパレータに負帰還をかけると、どうなりますか？

多くの場合、発振します。コンパレータは速く切り替わるように位相補償を持たないので、負帰還のループの位相余裕が足りなくなるからです。増幅などの用途には、オペアンプを使います。

コンパレータにヒステリシスを付けるのはなぜですか？

入力がしきい値の近くでゆっくり変わると、わずかなノイズで出力がHとLを何度も行き来してしまうからです。正帰還で、入力が上がるときと下がるときのしきい値をずらす(シュミットトリガ)と、出力は1回だけ切り替わります。

コンパレータの出力に、オープンドレインが多いのはなぜですか？

プルアップ先の電圧を変えれば、コンパレータの電源と違う電圧のロジックにもそのままつなげるからです。また、複数のコンパレータの出力を1本の線にまとめ、どれか1つが反応したらLにする(ワイヤードAND)、といった使い方もできます。

理解度チェック

コンパレータ(比較器)の働きとして正しいものはどれか。

  1. A入力電圧を時間で積分する
  2. B2つの入力電圧の大小を比較し、その結果を2値(HかL)で出力する
  3. C入力電圧に比例した電圧を出力する
答えと解説を見る

正解：B. 2つの入力電圧の大小を比較し、その結果を2値(HかL)で出力する

コンパレータは2つの入力電圧のどちらが大きいかを判定し、HかLの2値を出力します。オペアンプと違い、負帰還をかけずに飽和状態から素早く復帰するよう設計され、オープンドレイン出力などでロジックに直接つなげます。ADコンバータの判定、過電圧・低電圧の監視、ゼロクロス検出に使われます。ノイズで出力がばたつくのを防ぐため、ヒステリシスをもたせることもあります。

負帰還をかけた理想オペアンプ回路で、2つの入力端子の電圧がほぼ等しくなる性質を何と呼ぶか。

  1. Aスルーレート
  2. Bオフセット
  3. C仮想短絡(イマジナリーショート)
答えと解説を見る

正解：C. 仮想短絡(イマジナリーショート)

開ループ利得Aが非常に大きいオペアンプに負帰還をかけると、出力が有限の値でつり合うために入力端子間の電圧差は Vout/A とほぼ0になります。実際につながっていないのに短絡したように見えるため仮想短絡と呼び、非反転入力が接地されていれば反転入力も0 V(仮想接地)とみなせます。オペアンプ回路の解析の基本ですが、出力が飽和したときや正帰還の回路(コンパレータ)では成り立ちません。

入力が上がるときと下がるときでしきい値が異なり、ノイズによる出力のばたつきを防ぐ回路はどれか。

  1. APLL
  2. Bサンプルホールド回路
  3. Cシュミットトリガ
答えと解説を見る

正解：C. シュミットトリガ

シュミットトリガは、入力が上がるときのしきい値を高く、下がるときを低くして、その差(ヒステリシス)をもたせた回路です。ゆっくり変化する信号やノイズを含む信号を受けても、しきい値付近で出力が何度も切り替わる(チャタリング)のを防げます。コンパレータに正帰還をかけて作り、74HC14のようなロジックICもあります。スイッチ入力の整形やRC発振器(弛張発振)にも使われます。

  2. オペアンプのスルーレートの意味として正しいものはどれか。

関連する用語の解説

オペアンプ
差動入力と高い増幅率をもつ増幅器。負帰還をかけて増幅回路やフィルタなどに使う。
コンパレータ
2つの入力電圧の大小を比べ、その結果をHかLの2値で出力する回路。ADコンバータの基本的な構成要素でもある。
負帰還
出力の一部を入力に逆の極性で戻すこと。増幅率は下がるが、利得が安定し、ひずみや帯域が改善する。
シュミットトリガ
入力が上がるときと下がるときでしきい値が異なる(ヒステリシスをもつ)回路。ゆっくり変化する信号やノイズの乗った信号でも、出力がばたつかない。
位相余裕(フェーズマージン)
負帰還ループの利得が1(0 dB)になる周波数で、位相の遅れが180°に達するまでの余裕。小さいと応答が振動的になり、0以下では発振する。一般に45〜60°以上を目安にする。
