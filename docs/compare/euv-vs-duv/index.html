EUVとDUV露光の違い：波長・光学系・コストを比較

リソグラフィ(露光)は、光で回路のパターンをウェハに焼き付ける工程です。DUV(深紫外線)露光は、ArFレーザーの193 nmの光を使い、レンズと、レンズとウェハの間の水(液浸)で焼き付けます。EUV(極端紫外線)露光は13.5 nmの光を使うので、1回の露光ではるかに細いパターンを焼き付けられます。ただし、この光はほとんどの物質に吸収されるため、装置全体を真空中の鏡だけで作る必要があります。EUVは、はるかに高価で複雑です。

項目DUV(ArF液浸)EUV
波長193 nm13.5 nm
光源ArFエキシマレーザーレーザー生成プラズマ。溶けたスズの小さな滴にレーザーを当てる
光学系レンズ(屈折)。液浸では最後のレンズとウェハの間に水を入れる鏡(多層膜による反射)だけ。ほとんどの材料がEUV光を吸収するため
フォトマスク石英で作る透過型のマスク多層膜をつけた反射型のマスク
環境空気または窒素と、液浸の水真空
解像度1回の露光で、ピッチ約80 nmまで。それより細かいパターンには多重露光が必要1回の露光で、ピッチ30 nm前後以下も焼き付けられる。High-NA EUVはさらに細かい
工程の複雑さ多重露光(SADP、SAQPなど)で工程数が増える最も細かい層は工程が減るが、レジストやマスクに新しい課題がある
主な欠陥重ね合わせの誤差や、多重露光による欠陥光子の数が少ないことによる確率的な欠陥や、マスクの欠陥
装置の価格1台あたり数千万ドル1台あたり1億ドルをはるかに超える
供給元ASML、ニコンなど事実上ASMLだけ
主な使われ方先端チップを含め、ほとんどのチップのほとんどの層7 nm世代以降の、最も重要で最も細かい層

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

DUV
先端チップでも、層の大半は今もDUVで焼き付けます。成熟していて速く、1層あたりのコストがはるかに安いです。
EUV
DUVでは何回かの露光に分けなければならない、最も細かい層に使います。工程は簡単になりますが、装置も運用のコストも非常に高いです。
次の世代
High-NA EUVは、開口数を大きくして、次の世代でさらに小さいパターンを解像します。

理解度チェック

  1. EUV露光で使われる光の波長はどれか。
  2. ArF液浸露光の説明として正しいものはどれか。
  3. 次世代のEUV露光装置として開発された「High-NA EUV」の特徴として正しいものはどれか。
  4. EUV露光で問題になる確率的なゆらぎ(ストカスティクス)の主な原因として正しいものはどれか。
  5. EUV露光装置を事実上1社で供給している企業はどれか。
  6. EUV露光で使われるマスクの特徴として正しいものはどれか。
