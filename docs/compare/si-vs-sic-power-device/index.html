Si(シリコン)とSiC(炭化ケイ素)のパワー半導体の違い：物性・耐圧・損失・用途を比較

SiCは、シリコンの約3倍のバンドギャップと約10倍の絶縁破壊電界をもつワイドバンドギャップ半導体です。同じ耐圧ならドリフト層を薄く、不純物の濃度を高くできるので、オン抵抗を大きく下げられ、高い耐圧でもMOSFETやショットキーバリアダイオードのような速い素子を使えます。一方、シリコンはウエハが安く大口径で、製造技術も成熟しているため、多くの用途で今も主力です。

どんなときに使うか

Si(シリコン)
コストを優先したいとき。数百V以下の電源や、スイッチング周波数がそれほど高くない大電流のインバータなどに使います。実績と供給量の多さも強みです。
SiC(炭化ケイ素)
高い電圧で損失を減らしたいとき、装置を小さく軽くしたいとき。電気自動車では、インバータの効率が上がることで、同じ電池でも走れる距離を延ばせます。
使い分け
SiCの素子は高価なので、損失の低減や、冷却装置・受動部品の小型化によるシステム全体の利点が、素子のコストの増加を上回る用途から採用が広がっています。数百Vまでの電圧で特に速く動かしたい用途では、GaNも候補になります。

よくある質問

SiCはなぜシリコンより高い耐圧に向いているのですか？

絶縁破壊電界がシリコンの約10倍あるからです。同じ耐圧に必要なドリフト層の厚さを約10分の1にでき、不純物の濃度も約100倍にできるので、オン抵抗を大きく下げられます。

SiC MOSFETはシリコンのIGBTを置き換えますか？

電気自動車のインバータなど、効率が重視される用途で置き換えが進んでいます。ただしSiCの素子は高価なので、コストを重視する用途や大電流の産業用途では、シリコンのIGBTも広く使われ続けています。

SiCのデメリットは何ですか？

ウエハとチップが高価なこと、結晶欠陥が多く歩留まりを上げにくいこと、ゲート酸化膜との界面の品質が低くチャネルの移動度が小さいことなどです。速くスイッチングできる反面、電圧の急な変化によるノイズやサージへの対策も必要になります。

SiCとGaNはどう使い分けますか？

SiCは縦型の素子で、高い耐圧と大電流に強く、電気自動車のインバータや産業用途に向きます。GaNは横型のHEMTが中心で、650 V程度までの電圧で非常に速くスイッチングでき、小型の充電器やデータセンターの電源に使われます。

理解度チェック

SiC(炭化ケイ素)がSiに比べて高耐圧パワーデバイスに有利な主な理由はどれか。

  1. A絶縁破壊電界がSiの約10倍と高いため
  2. BバンドギャップがSiより小さいため
  3. CウエハがSiより安価で大口径化しやすいため
答えと解説を見る

正解：A. 絶縁破壊電界がSiの約10倍と高いため

SiCはバンドギャップが約3.3 eVと大きく、絶縁破壊電界がSiの約10倍(約3 MV/cm)あります。同じ耐圧ならドリフト層を約1/10の厚さにでき、不純物濃度を約100倍にできるため、ドリフト層の抵抗は理論上数百分の1になります。熱伝導率もSiの約3倍で高温に強く、EVのインバータなどで採用が広がっています。一方、ウエハはSiより高価で、大口径化(8インチ)は2020年代半ばの時点でまだ移行の途上です。

SiCやGaNのように、シリコンよりバンドギャップが大きい半導体の総称はどれか。

  1. Aワイドバンドギャップ半導体
  2. Bナローギャップ半導体
  3. Cアモルファス半導体
答えと解説を見る

正解：A. ワイドバンドギャップ半導体

バンドギャップがおおむね2〜3 eV以上の半導体をワイドバンドギャップ半導体と呼び、SiC(約3.3 eV)やGaN(約3.4 eV)が代表です。絶縁破壊電界が高く、真性キャリアが少ないため高温でも動作しやすく、高耐圧・低損失のパワーデバイスや高周波デバイスに使われます。さらに大きいGa2O3(約4.8 eV)やダイヤモンド(約5.5 eV)は、ウルトラワイドバンドギャップ半導体と呼ばれます。

電気自動車のインバータにSiCパワーデバイスを使う主な利点はどれか。

  1. Aシリコンより必ず安価になる
  2. B損失が小さく、航続距離の延長や冷却装置の小型化につながる
  3. Cモーターが不要になる
答えと解説を見る

正解：B. 損失が小さく、航続距離の延長や冷却装置の小型化につながる

SiCデバイスはオン抵抗とスイッチング損失が小さく高温に強いため、EVのインバータ損失を減らせます。損失が減れば同じ電池で走れる距離が数%〜1割程度延び、冷却装置やインバータも小型・軽量にできます。2018年のTesla Model 3で本格採用されて以降、普及が進み、800 V系の高電圧バッテリーで特に効果が大きくなります。課題はSi IGBTより高いコストです。

関連する用語の解説

SiC(炭化ケイ素)
バンドギャップ約3.3 eVのワイドギャップ半導体。絶縁破壊電界が高く、高耐圧・低損失のパワーデバイスに使われる。
4H-SiC
SiCの結晶多形の一つで、パワーデバイスに主に使われるもの。バンドギャップが約3.3 eVと大きく、電子の移動度も比較的高い。
IGBT
絶縁ゲートバイポーラトランジスタ。MOSゲートで駆動し、伝導度変調によって高耐圧でも低いオン電圧を得られる。
オン抵抗
パワー半導体がオンのときの、電流が流れる経路の抵抗。小さいほど導通時の損失が少ない。
テール電流
IGBTのターンオフ時に、蓄積された少数キャリアのために電流がすぐに0にならず、尾を引くように流れ続ける電流。ターンオフ損失の原因になる。
ワイドバンドギャップ半導体
シリコンよりバンドギャップが大きい半導体。SiCやGaNなど。絶縁破壊電界が高く、高電圧・高温での動作に強い。
