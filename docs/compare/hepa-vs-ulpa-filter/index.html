HEPAフィルタとULPAフィルタの違い：捕集効率の定義・規格の等級・MPPS・使うクリーンルームを比較

HEPAフィルタとULPAフィルタは、どちらも細いガラス繊維などのろ材をひだ状に折りたたんだ高性能のエアフィルタで、クリーンルームの天井やFFUに取り付けて、空気中の粒子を取り除きます。違いは捕集効率です。日本のJISの用語の定義(JIS Z 8122)では、定格風量でHEPAは粒径0.3 µmの粒子を99.97%以上、ULPAは0.15 µmの粒子を99.9995%以上捕集するものとしています。欧州のEN 1822-1では、最も透過しやすい粒径(MPPS)での効率で等級を分け、H13・H14をHEPA、U15〜U17をULPAとしています。ULPAは粒子をより多く取れる一方、同じ風量では圧力損失と価格が大きくなるため、求める清浄度に合わせて使い分けます。

どんなときに使うか

HEPAフィルタ
ISOクラス5程度より緩い清浄度で十分なエリアに向きます。圧力損失が小さいので、広い面積に多数並べても、ファンの電力を抑えられます。
ULPAフィルタ
微細なパターンを扱う半導体の工程など、ごく小さな粒子も減らしたい、特に清浄度の高い場所に使います。効率の高さと引き換えに、圧力損失とコストが増えます。
清浄度はフィルタだけで決まらない
部屋の清浄度は、フィルタの等級に加えて、天井をフィルタで覆う割合、ダウンフローの気流、人や装置からの発塵、フィルタの枠からの漏れで決まります。高い等級のフィルタを付けても、気流が乱れていれば清浄度は上がりません。

よくある質問

HEPAフィルタの「0.3 µmで99.97%」とはどういう意味ですか？

粒径0.3 µmの粒子を含む空気を定格の風量で通したとき、粒子の99.97%以上をとらえ、通り抜けるのは1万個に3個以下という意味です。0.3 µmは、繊維にとらえにくい粒径(MPPS)に近いため、性能を表す粒径として使われてきました。それより大きい粒子や小さい粒子は、一般にもっと高い効率でとらえられます。

H13やU15とは何ですか？

欧州の規格EN 1822-1の等級です。最も透過しやすい粒径(MPPS)の粒子でフィルタ全体の効率を測り、H13は99.95%以上、H14は99.995%以上、U15は99.9995%以上と、数字が1つ上がるごとに通り抜ける割合が10分の1になります。国際規格のISO 29463もほぼ同じ考え方で等級を定めています。JISの定義とは試験の粒径が違うので、数値をそのまま比べないようにします。

ULPAフィルタを付ければ、どの部屋でも高い清浄度になりますか？

なりません。清浄度は、天井のどれだけをフィルタで覆うか、ダウンフローの気流がそろっているか、人や装置がどれだけ発塵するか、フィルタの枠から漏れがないかで大きく変わります。設置後は粒子計数器でフィルタの面と枠を走査して漏れを確かめ、ISO 14644-1にもとづいて部屋の粒子の数を測ります。

HEPAやULPAでガスも取り除けますか？

取り除けません。どちらも粒子をとらえるフィルタで、アンモニアや有機物などの分子はろ材を通り抜けます。半導体工場では、活性炭などを使ったケミカルフィルタを組み合わせて、分子状汚染(AMC)を減らします。

理解度チェック

クリーンルームの空気から微粒子を取り除くために使われる高性能フィルタはどれか。

  1. Aローパスフィルタ
  2. Bカラーフィルタ
  3. CULPAフィルタ(HEPAフィルタ)
答えと解説を見る

正解：C. ULPAフィルタ(HEPAフィルタ)

HEPAフィルタやさらに高性能なULPAフィルタは、細かいガラス繊維などを折りたたんだろ材で空気中の微粒子をとらえるエアフィルタで、クリーンルームの天井などに設置されます。繊維の隙間より小さな粒子も、慣性や拡散で繊維に衝突してとらえられます。ローパスフィルタは電気回路で高い周波数を除く回路、カラーフィルタはイメージセンサなどで色を分ける部品です。

HEPAフィルタの性能の一般的な定義として正しいものはどれか。

  1. A粒径0.3 µmの粒子を99.97%以上捕集する
  2. B粒径10 µmの粒子を50%以上捕集する
  3. Cガス状の分子を99.99%以上除去する
答えと解説を見る

正解：A. 粒径0.3 µmの粒子を99.97%以上捕集する

HEPAフィルタは、ろ過が最も難しい粒径に近い0.3 µm程度の粒子に対して、99.97%以上の捕集効率をもつフィルタとして定義されます(JISなど)。それより大きな粒子は慣性で、小さな粒子はブラウン運動による拡散で繊維に捕らえやすいため、中間の大きさが最も抜けやすいのです。さらに高性能なULPAフィルタは0.15 µmで99.9995%以上とされます。どちらもガスは除去できません。

天井にフィルタとファンを一体化して並べ、清浄な空気を送り出す装置はどれか。

  1. AFFU(ファンフィルタユニット)
  2. BEFEM
  3. COHT
答えと解説を見る

正解：A. FFU(ファンフィルタユニット)

FFUは、送風ファンとHEPA/ULPAフィルタを一体化したユニットで、クリーンルームの天井に多数並べて、清浄な空気を下向きに吹き出します。ユニットごとに風量を調整でき、レイアウトの変更や部分的な清浄度の変更にも対応しやすいため、大きなダクトで空気を送る方式に代わって広く使われています。EFEMは装置前面のモジュール、OHTは天井の搬送車です。

  2. クリーンルームの空気から、アンモニアや有機物などの分子状汚染(AMC)を取り除くために使われるフィルタはどれか。
  3. ISO 14644-1の清浄度クラスについて正しい説明はどれか。

関連する用語の解説

HEPAフィルタ
粒径0.3 µmの粒子を99.97%以上捕集する高性能の空気フィルタ。さらに細かい粒子まで捕集するものがULPAフィルタ。
ULPAフィルタ
HEPAフィルタよりさらに微細な粒子まで捕集する高性能のエアフィルタ。高い清浄度のクリーンルームの天井に使われる。
ISO 14644-1
クリーンルームの清浄度のクラスを、空気中の粒子の数で定めた国際規格。数字が小さいほど清浄度が高い。
FFU(ファンフィルタユニット)
ファンと高性能フィルタを一体化した装置。クリーンルームの天井に並べて、清浄な空気を下向きに送り出す。
ダウンフロー
天井全面から床へ一方向に清浄な空気を流す、クリーンルームの気流の方式。発生した粒子をすばやく床下へ排出する。
クリーンルーム
空気中の微粒子(パーティクル)の数を決められた水準以下に保ち、温度・湿度・気圧なども管理した部屋。半導体の製造は、ウエハを汚さないようにクリーンルームの中で行う。
分子状汚染(AMC)
空気中の酸、アルカリ、有機物などのガス状の汚染物質。粒子用のフィルタでは除けず、ケミカルフィルタで取り除く。
ミニエンバイロメント
ウエハの周りの狭い空間だけを高い清浄度に保つ考え方。FOUPなどの密閉容器と装置前面のEFEMを組み合わせ、部屋全体の清浄度の要求を下げてコストを抑える。
