CVDとPVDの違い：薄膜の成膜方法を比較

どちらもウェハ上に薄膜を作る方法です。化学気相成長(CVD)では、ガスがウェハの表面で反応して膜になります。物理気相成長(PVD)の代表であるスパッタリングでは、固体のターゲットから原子をたたき出し、化学反応なしにウェハに付着させます。絶縁膜や、深い構造をむらなく覆う場合はCVDが、金属の膜ではPVDが、一般的に選ばれます。

項目CVDPVD(スパッタリング)
原理原料のガスが、加熱された、またはプラズマで活性化されたウェハ表面で化学反応する固体のターゲットから原子を物理的に飛ばし(たとえばアルゴンイオンで)、ウェハの上に凝縮させる
主な材料酸化シリコン、窒化シリコン、ポリシリコン、タングステン、low-k絶縁膜アルミニウム、チタン、窒化チタン、タンタルなどの金属、銅のシード層
ステップカバレッジ良好。特にLPCVDで良い。ALDはさらに良い直進する粒子で成膜するので、深い溝や穴は覆いにくい(イオン化PVDで改善)
温度高め。LPCVDは約600〜800 ℃、プラズマCVDは約200〜400 ℃低め。室温から数百度まで
膜の純度原料に由来する水素、炭素、塩素が残ることがある高い。ターゲットの純度で決まる
環境常圧から低圧。反応性のガスを使う高真空で、不活性ガスのプラズマを使う
危険性毒性、可燃性、腐食性のあるガス(シラン、WF6など)を慎重に扱い、除害する必要がある危険な薬品は少ないが、高真空とプラズマの装置を使う
主な用途層間絶縁膜、スペーサー、ポリシリコンのゲート、タングステンのプラグ銅配線のバリア層とシード層、アルミニウムのパッド、コンタクトの金属

どんなときに使うか

CVD
絶縁膜が必要なとき、または急な段差のある形状をむらなく覆いたいとき。
PVD
低い温度で純粋な金属膜が必要なとき。たとえば銅めっきのシード層。
組み合わせ
チップには両方を使います。CVDで絶縁層を作り、穴や溝を埋める前に、PVDで薄い金属のライナーを付けます。

よくある質問

CVDとPVDの主な違いは何ですか？

CVDは、ウェハ上でガスが化学反応して膜を作ります。PVDは、スパッタリングのように、固体のターゲットから原子を物理的に飛ばして、ウェハに付着させます。

なぜCVDは急な段差を覆うのが得意なのですか？

ガスの分子が、溝や穴の奥まで届き、表面のあらゆる場所で反応できるからです。PVDは直進して成膜するので、深く狭い形状は覆いにくくなります。

金属の配線にはどちらを使いますか？

両方です。PVDはバリア層、シード層、アルミニウムのパッドに使い、CVDはタングステンのプラグを作ります。銅は、PVDのシード層の上に、電解めっきで埋めます。

PECVDとは何ですか？

プラズマCVDのことで、プラズマでガスを活性化するので、より低い温度(約200〜400 ℃)で成膜できます。

理解度チェック

スパッタリングによる成膜は、次のどれに分類されるか。

  1. APVD(物理気相成長)
  2. BCVD(化学気相成長)
  3. C熱酸化
答えと解説を見る

正解：A. PVD(物理気相成長)

スパッタリングは、アルゴンなどのプラズマ中のイオンを数百Vで加速してターゲットに衝突させ、運動量を受け取ってはじき出された原子をウエハに堆積させる方法で、化学反応を使わない物理的な現象なのでPVD(物理気相成長)に分類されます。金属配線、バリアメタル(Ta、TiNなど)、Cuのシード層、電極などの成膜に使われます。CVDは原料ガスの化学反応、熱酸化はシリコン自体の酸化です。

プラズマCVD(PECVD)の主な利点として正しいものはどれか。

  1. A熱CVDより高い温度が必要になる
  2. B膜中に水素がまったく含まれない
  3. C熱CVDより低い温度で成膜できる
答えと解説を見る

正解：C. 熱CVDより低い温度で成膜できる

プラズマCVDは、プラズマ中の電子のエネルギーで原料ガスを分解・活性化するため、熱だけで反応させる熱CVD(600〜800 ℃程度)より低い300〜400 ℃程度で成膜できます。アルミや銅の配線形成後など高温にできない工程で、層間絶縁膜や保護膜の成膜に使われます。一方、原料ガスに由来する水素が膜に含まれやすく、膜質は熱CVDに劣る傾向があります。

減圧CVD(LPCVD)の特徴として正しいものはどれか。

  1. A減圧下で行うため膜厚の均一性がよく、多数のウエハを一度に処理できる
  2. B大気圧で行うため装置が最も簡単である
  3. Cプラズマを使うため室温で成膜できる
答えと解説を見る

正解：A. 減圧下で行うため膜厚の均一性がよく、多数のウエハを一度に処理できる

LPCVDは、数十〜数百Pa程度に減圧して行う熱CVDです。減圧するとガス分子の拡散が速くなり、成膜速度が表面反応で決まる(表面反応律速)ため、ウエハを数mm間隔で立てて100枚以上並べても均一な膜が得られます。段差被覆性もよく、ポリシリコン、シリコン窒化膜、TEOS酸化膜などの成膜に使われます。温度は600〜800 ℃程度と高く、配線形成後には使えません。

  2. 成膜におけるステップカバレッジ(段差被覆性)の説明として正しいものはどれか。

成膜(CVD・PVD)の練習問題へ

関連する用語の解説

CVD
化学気相成長。原料ガスの化学反応によってウエハ上に薄膜を堆積する方法。
スパッタリング
プラズマ中のイオンをターゲットに衝突させ、はじき出された原子をウエハに堆積させるPVDの一種。
PECVD(プラズマCVD)
プラズマで原料ガスを分解して膜を堆積するCVD。熱CVDより低い温度で成膜でき、配線工程の絶縁膜などに使われる。
LPCVD(減圧CVD)
減圧下で行う熱CVD。気体分子の拡散が速くなるため膜厚の均一性や段差被覆性がよく、多数のウエハを縦型炉で一度に処理できる。ポリシリコンや窒化膜の成膜に使われる。
ALD
原子層堆積。前駆体ガスの自己制限的な表面反応を繰り返し、原子層単位で膜厚を制御する成膜法。
