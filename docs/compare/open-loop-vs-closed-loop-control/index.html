開ループ制御と閉ループ制御の違い：仕組み・外乱への強さ・安定性・センサ・用途を比較

開ループ制御は、目標値から操作量を決めて制御対象に加えるだけで、結果の制御量を測って確かめません。閉ループ制御は、センサで制御量を測って目標値と比べ、その差(偏差)が小さくなるように操作量を直し続けます。信号が出力から入力の側へ戻ってループを一巡するので、フィードバック制御とも呼びます。開ループ制御は簡単で安く、安定な制御対象なら制御のせいで振動することもありませんが、外乱や制御対象の変化によるずれを直せません。閉ループ制御はずれを自動で直せる代わりにセンサが必要で、ゲインを上げすぎると振動したり不安定になったりします。

項目開ループ制御閉ループ制御(フィードバック制御)
信号の流れ目標値 → 制御器 → 制御対象 → 制御量。出力は入力の側へ戻らない制御量をセンサで測り、目標値との差(偏差)を制御器に戻す。信号がループを一巡する
センサ(制御量の測定)不要必要。センサの精度と雑音が、制御の精度を左右する
外乱への対応直せない。負荷や周囲の温度が変わると、ずれたままになる偏差として現れたずれを、原因によらず直す
制御対象の特性の変化変化がそのまま結果に出る。対象のゲインが50%下がれば、出力も50%下がる影響が小さくなる。G = 100、H = 0.1の負帰還では、Gが半分になっても閉ループの利得の低下は約8.3%
応答の速さ制御対象そのものの遅れだけ。偏差が出るのを待たずに操作できる偏差が出てから修正するので遅れがある。ただしゲインを上げれば、制御対象だけのときより速く応答させることもできる
安定性安定な制御対象なら、制御が原因で振動や発散は起きないゲインが高すぎたり、むだ時間などの遅れが大きかったりすると振動し、発散する。ゲイン余裕や位相余裕で確かめる
定常偏差モデルが正確なら0にできるが、モデルの誤差や外乱の分はそのまま残る比例動作だけでは偏差が残る(0形の系のステップに対して1/(1 + G(0)))。積分動作を加えると0にできる
構成とコスト簡単で安い。精度はモデルと部品の正確さしだいセンサと、比べて直す回路やソフトウェアが要る。ループの安定性を考えた設計と調整が必要
例時間だけで焼き加減を決めるトースター、パルスの数で角度を決めるステッピングモータの位置決め、決まった時間で切り替わる信号機エアコンの室温、車のクルーズコントロール、DC-DCコンバータの出力電圧、モータの速度と位置

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

開ループ制御
外乱が小さく、制御対象の特性がよくわかっていて変わりにくいとき。センサを付けられないときや、付けると高くつくときにも使います。安定な対象なら振動の心配がなく、調整も簡単です。
閉ループ制御(フィードバック制御)
外乱や負荷の変化、部品のばらつきや劣化があっても、結果を目標値に正確に合わせたいとき。温度、速度、位置、電圧など多くの制御はこちらで、PID制御が代表的です。

よくある質問

フィードフォワード制御は、開ループ制御ですか？

フィードフォワードの経路だけを見ると、制御量を測らずにモデルから操作量を決めるので、開ループの構造です。外乱や目標値の変化を測って、偏差が出る前に打ち消す操作量を加えるので速く応じられますが、測っていない外乱やモデルの誤差は直せません。そこで、フィードバック制御と組み合わせ、残ったずれをフィードバックで直すのが一般的です。フィードフォワードの経路はループの外にあるので、ループの安定性は変わりません。

閉ループ制御は、なぜ制御対象の特性の変化に強いのですか？

前向きの利得G、フィードバックの利得Hの負帰還では、閉ループの利得はG/(1 + GH)で、GHが1より十分大きければ約1/Hになり、Gにほとんどよらなくなるからです。G = 100、H = 0.1では閉ループの利得は約9.09で、Gが50に半減しても約8.33と、約8.3%しか下がりません。開ループでは、Gが半分になれば結果も半分になります。

閉ループ制御が不安定になるのはなぜですか？

制御対象やセンサの遅れのために、修正の操作が遅れて効くからです。ゲインが高いと、ずれを強く直そうとして逆向きに行き過ぎ、これを繰り返して振動します。一巡伝達関数の位相が−180°になる周波数でゲインが1(0 dB)以上だと、振動が大きくなり続けて発散します。設計では、ゲイン余裕と位相余裕で安定までの余裕を確かめます。

理解度チェック

フィードバック制御(閉ループ制御)の説明として正しいものはどれか。

  1. A制御量を測らずに、あらかじめ決めた操作量や手順だけで動かすので、外乱で制御量がずれても自動では補正されない
  2. B制御量を測って目標値と比べ、その差(偏差)が小さくなるように操作量を変えるので、外乱や制御対象の特性の変化の影響を小さくできる
  3. C外乱を測り、それが制御量に現れる前に打ち消す操作量を加えるので、測っていない外乱やモデルの誤差まで含めて、必ず偏差を0にできる
答えと解説を見る

正解：B. 制御量を測って目標値と比べ、その差(偏差)が小さくなるように操作量を変えるので、外乱や制御対象の特性の変化の影響を小さくできる

フィードバック制御は、センサで測った制御量を目標値と比べ、偏差に応じて操作量を決める制御です。信号が出力から入力の側へ戻ってループをひと回りするので、閉ループ制御とも呼びます。原因が何であっても結果のずれを見て直すので、外乱や制御対象の特性の変化に強いのが長所です。一方で、偏差が生じてから修正するので遅れがあり、ゲインを上げすぎると振動したり不安定になったりします。

フィードフォワード制御を、フィードバック制御と組み合わせて使う理由として正しいものはどれか。

  1. Aフィードフォワードは、測れる外乱や目標値の変化に偏差が出る前に応じられるが、測っていない外乱やモデルの誤差は補正できないので、残りをフィードバックで補う
  2. Bフィードフォワードを加えると一巡伝達関数のゲインと位相が変わって位相余裕が増えるので、フィードバックのゲインを大きくしても安定に保てる
  3. Cフィードバックだけでは、積分動作を使っても定常偏差が必ず残ってしまうので、一定の目標値や外乱に対する定常偏差を0にするには、フィードフォワードが欠かせない
答えと解説を見る

正解：A. フィードフォワードは、測れる外乱や目標値の変化に偏差が出る前に応じられるが、測っていない外乱やモデルの誤差は補正できないので、残りをフィードバックで補う

フィードフォワード制御は、外乱や目標値の変化を測り、それが制御量に影響する前に、モデルから計算した操作量を加える制御です。偏差が出るのを待たないので速く応じられますが、モデルが正確で、外乱を測れることが前提になります。そこで、主な外乱や目標値への追従をフィードフォワードで受け持ち、残ったずれをフィードバックで直す組み合わせがよく使われます。フィードフォワードの経路はループの外にあるので、ループの安定性(位相余裕など)は変わりません。

前向きの経路の伝達関数が G(s)、フィードバックの経路の伝達関数が H(s) の負帰還のブロック線図がある。目標値 R(s) から出力 Y(s) までの閉ループ伝達関数 Y(s)/R(s) として正しいものはどれか。

  1. AG(s)/(1 − G(s)H(s))
  2. BG(s)H(s)/(1 + G(s)H(s))
  3. CG(s)/(1 + G(s)H(s))
答えと解説を見る

正解：C. G(s)/(1 + G(s)H(s))

偏差は E(s) = R(s) − H(s)Y(s)、出力は Y(s) = G(s)E(s) です。2つの式から E(s) を消すと Y(s) = G(s)R(s) − G(s)H(s)Y(s) となり、Y(s)/R(s) = G(s)/(1 + G(s)H(s)) が得られます。分母の G(s)H(s) は、信号がループをひと回りするときの伝達関数で、一巡伝達関数(ループ伝達関数)と呼びます。H(s) = 1 の単位フィードバックでは、G(s)/(1 + G(s)) になります。

  1. 前向きの利得 G = 100、フィードバックの利得 H = 0.1 の負帰還の系がある。部品の劣化で G が50に半減したとき、閉ループの利得の減少の割合に最も近いものはどれか。
  2. 単位フィードバックの系で、前向きの伝達関数が G(s) = 9/(1 + 2s) である。大きさ1のステップの目標値に対する定常偏差として正しいものはどれか。
  3. 一巡伝達関数のボード線図から読み取る、ゲイン余裕と位相余裕の説明として正しいものはどれか。

関連する用語の解説

フィードバック制御
制御量をセンサで測って目標値と比べ、その差(偏差)が小さくなるように操作量を変える制御。信号がループを一巡するので、閉ループ制御とも呼ぶ。原因によらず結果のずれを直すので外乱や制御対象の変化に強いが、偏差が出てから修正するので遅れがあり、ゲインが高すぎると振動や不安定を招く。PID制御が代表的で、温度、速度、電圧、位置などの制御に広く使われる。
フィードフォワード制御
外乱や目標値の変化を測り、それが制御量に影響する前に、制御対象のモデルから求めた操作量を加える制御。偏差が出るのを待たないので速く応じられるが、モデルの誤差や測っていない外乱は補正できないため、フィードバック制御と組み合わせて使うことが多い。ループの外にある経路なので、フィードバックのループの安定性は変えない。半導体の工場では、前の工程の計測結果をもとに、次の工程の条件を補正する制御もフィードフォワード制御と呼ぶ。
ブロック線図
制御系の要素を、伝達関数を書いた箱(ブロック)で表し、信号の流れを矢印、信号の足し引きを加え合わせ点、信号の分かれを引き出し点で示した図。直列のブロックは伝達関数の積、並列のブロックは和にまとめられ、負帰還のループは G/(1 + GH) の1つのブロックに置き換えられる。こうした等価変換を繰り返して、目標値や外乱から出力までの伝達関数を求める。
伝達関数
線形で時不変な系の入力と出力の関係を、初期値をすべて0としたときの出力と入力のラプラス変換の比 G(s) = Y(s)/X(s) で表したもの。系のインパルス応答のラプラス変換に等しい。分母を0にする s を極、分子を0にする s を零点と呼び、極の位置から安定性や応答の速さがわかる。s = jω とおくと周波数応答が得られる。離散時間の系では、z変換を使って H(z) で表す。
定常偏差
制御系の応答が落ち着いた後に残る、目標値と制御量の差。オフセットとも呼ぶ。単位フィードバックの系では、ステップの目標値に対して 1/(1 + Kp)(Kp = G(0) は位置偏差定数)となり、前向きの経路に積分を含まない(0形の)系では0にならない。積分を1つ含む1形の系ではステップに対する定常偏差が0になり、ランプの目標値に対しては 1/Kv(Kv は速度偏差定数)の偏差が残る。PI制御の積分動作は、この偏差をなくすために使われる。
ゲイン余裕(利得余裕)
一巡伝達関数の位相が −180° になる周波数(位相交差周波数)で、ゲインが0 dBより何dB低いかを表す量。ループのゲインをあと何倍にすると不安定になるかを示し、例えばゲイン余裕が約9.5 dBなら、ゲインを3倍にすると安定限界に達する。位相余裕と組み合わせて安定の余裕を表し、サーボ系では10〜20 dB程度が目安とされる。
PID制御
偏差 e に比例する項(P)、偏差の積分に比例する項(I)、偏差の微分に比例する項(D)を足し合わせて操作量を決めるフィードバック制御。u = Kp(e + (1/Ti)∫e dt + Td·de/dt) と書き、Kp を比例ゲイン、Ti を積分時間、Td を微分時間と呼ぶ。比例は速さ、積分は定常偏差の除去、微分は振動の抑制を受け持つ。構造が簡単で、温度、モータ、電源、化学プロセスなど、産業の制御ループの大半で使われている。
