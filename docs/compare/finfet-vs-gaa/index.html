FinFETとGAAトランジスタの違い：構造・制御性・製造を比較

FinFETでは、ゲートが立ち上がったシリコンのフィンを3方向から包みます。ゲートオールアラウンド(GAA)では、ゲートがチャネルの全周を囲み、多くは水平のナノシートを何枚も重ねた形になります。チャネルをより完全に包むと、ゲートが短くてもリーク電流を抑えやすくなります。そのため、先端の半導体メーカーは3 nm・2 nm世代で、FinFETからGAAへ移っています。

項目FinFETGAA(ナノシート)
ゲートの構造ゲートが立ったフィンの3面を覆うゲートがチャネルの4面すべてを囲む
チャネルの形細く立ったシリコンのフィン水平のナノシート(またはナノワイヤ)を縦に積み重ねる
静電制御良好。プレーナ型よりはるかに優れるさらに優れる。リークを減らし、短いゲートや低い電源電圧に向く
チャネル幅の調整段階的。フィンの高さが一定なので、幅はフィンの本数で決まる柔軟。シートの幅と枚数を、トランジスタごとに選べる
主な製造工程フィンのパターニング(SADPやSAQPを使うことが多い)、フィン間の分離、ゲート形成SiとSiGeを交互にエピ成長し、SiGeだけを選択的に除去してシートを浮かせ、インナースペーサーを作る
工程の複雑さ成熟していて、よく分かっている新しい工程が増え、制御もより厳しい
自己発熱問題になる。細いチャネルから熱が逃げにくいこちらも問題になる。シートが絶縁膜で囲まれているため
量産の開始Intelの22 nm(Tri-Gate)、2012年に出荷開始3 nm世代で2022年ごろに量産開始。他の大手も続いた
各社の呼び名Tri-Gate(Intel)、FinFET(TSMC、Samsungなど)RibbonFET(Intel)、MBCFET(Samsung)、ナノシート(TSMC)

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

FinFET
22 nmから5 nm世代あたりまでのロジックを支えてきた主力で、3 nmでも広く使われています。成熟していて、設計ルールがよく分かっており、歩留まりも高いです。
GAA
最先端のノードで、FinFETではリークを抑えにくくなった領域に向きます。トランジスタごとに幅を調整したいときにも有利です。
その先
nMOSとpMOSを縦に重ねる、積層型の相補型FET(CFET)の研究が続いています。

理解度チェック

  1. FinFETの構造上の特徴として正しいものはどれか。
  2. GAA(ゲートオールアラウンド)型トランジスタの説明として正しいものはどれか。
  3. FinFETでトランジスタの実効的なチャネル幅を調整する方法として正しいものはどれか。
  4. FinFETと比べたときの、ナノシート型GAAトランジスタの設計上の利点として正しいものはどれか。
  5. ナノシート型GAAトランジスタの製造で、SiとSiGeを交互に積み重ねた層からSiGe層だけを選択的に除去する理由として正しいものはどれか。
  6. FinFET(IntelはTri-Gateと呼んだ)を初めて量産のロジック製品に採用した企業と世代の組み合わせとして正しいものはどれか。
