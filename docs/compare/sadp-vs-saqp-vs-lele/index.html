SADP・SAQP・LELEの違い：マルチパターニングのピッチの分割・重ね合わせ精度・マスクと工程の数を比較

マルチパターニングは、1回の露光では解像できない細かいピッチのパターンを、複数の露光や加工に分けてつくる技術です。LELEは、レイアウトを2枚のマスクに分け、露光とエッチングを2回繰り返して、線を互い違いに並べます。SADPは、芯材(マンドレル)の側壁にスペーサーをつくって芯材を除き、1本の芯材から2本の線をつくってピッチを半分にします。SAQPはスペーサーの工程を2回重ねて、ピッチを4分の1にします。LELEはレイアウトの自由度が高い代わりに2回の露光の重ね合わせ精度に厳しく、SADPとSAQPは線の位置が自己整合で決まる代わりに、規則的な線の並びと、不要な部分を切るカットマスクが必要になります。

どんなときに使うか

SADP
一方向の規則的な線を、ピッチを半分にしてそろった線幅でつくりたいとき。重ね合わせのずれを気にせずに密な線がつくれます。
SAQP
SADPでも足りない、最も細かいピッチの線が必要なとき。工程とコストは最も多くなりますが、ArF液浸でも20 nm台のピッチに届きます。
LELE
コンタクトやビアのように、規則的な線ではない2次元のパターンを分けて露光したいとき。重ね合わせ精度を非常に厳しく管理する必要があります。
EUVとの関係
EUV露光は、多くの層を1回の露光に戻し、マルチパターニングの工程を減らしました。ただし最も細かいピッチでは、EUVとスペーサーの技術を組み合わせることもあります。

よくある質問

なぜSADPは重ね合わせのずれに強いのですか？

対になる2本の線が、同じ芯材の両側の側壁にできるスペーサーからつくられるからです。2本の線の位置は、芯材の位置とスペーサーの膜厚で決まり、2回目の露光で位置を合わせる必要がありません。LELEでは、2回目の露光のずれがそのまま隣の線との間隔の変化になります。

ピッチウォーキングとは何ですか？

スペーサーを使うパターニングで、交互に並ぶ間隔がそろわなくなる現象です。芯材を除いた跡の間隔は芯材の幅で、隣の芯材とのあいだの間隔は芯材のピッチと幅とスペーサーの膜厚で決まるため、芯材の幅が目標からずれると2種類の間隔が等しくなくなります。SAQPでは原因となる寸法が増えるので、管理がさらに難しくなります。

カットマスクはなぜ必要なのですか？

SADPやSAQPでは、スペーサーが芯材の端を回り込んでループ状になり、規則的な線が並ぶだけだからです。回路に必要な形にするには、線の端や不要な部分を、別のマスクで切ったりふさいだりします。このマスクは線に合わせて位置を決めるので、重ね合わせ精度が必要です。

LELEで2色に塗り分けられない配置とは何ですか？

1回の露光では近すぎる3つのパターンが互いに隣り合うような、奇数の輪になる配置です。2枚のマスクに振り分けると、どこかで近すぎるパターンどうしが同じマスクに入ってしまいます。設計ツールは、このような配置をエラーとして修正を求めます。

理解度チェック

ダブルパターニング(マルチパターニング)の説明として正しいものはどれか。

  1. A2枚のウエハを同時に露光する
  2. B1回の露光では解像できない細かいピッチのパターンを、複数回の露光や加工に分けて形成する
  3. Cレジストを2層重ねて塗るだけで解像度を2倍にする
答えと解説を見る

正解：B. 1回の露光では解像できない細かいピッチのパターンを、複数回の露光や加工に分けて形成する

ダブルパターニングは、1回では解像できない細かいピッチのパターンを、間引いた2つのパターンに分けて別々に露光・加工したり(LELE)、側壁に成膜したスペーサーで線を倍にしたり(SADP・SAQP)して形成する技術です。ArF液浸の限界(ピッチ約80 nm)を超えて20 nm台のピッチまで微細化を進めましたが、工程数・マスク数・コストが大きく増えるため、EUV露光の導入が進められてきました。

LELE(リソ・エッチ・リソ・エッチ)方式のダブルパターニングで、特に厳しく求められるものはどれか。

  1. Aレジストの色
  2. B露光装置の台数
  3. C1回目と2回目のパターンの重ね合わせ精度
答えと解説を見る

正解：C. 1回目と2回目のパターンの重ね合わせ精度

LELEでは、細かいパターンを2つに分けて別々に露光・エッチングするため、2回目のパターンが1回目に対してずれると、隣り合う線の間隔がそのずれの分だけ変わってしまい、配線の容量や短絡に直結します。例えば間隔20 nmで2 nmずれると10%の変化です。そのため非常に高い重ね合わせ精度が必要です。スペーサーを使うSADPは線の位置が自己整合的に決まるため、この問題が小さくなります。

FinFETの細いフィンをつくるのに使われる、側壁スペーサーを利用してリソグラフィの限界より細かいパターンをつくる技術はどれか。

  1. ASADP/SAQP(自己整合ダブル/クアドルプルパターニング)
  2. BOPC
  3. CCMP
答えと解説を見る

正解：A. SADP/SAQP(自己整合ダブル/クアドルプルパターニング)

SADPでは、芯となるパターンの側壁にALDなどで均一な膜をつけてスペーサーを形成し、芯を取り除くことで、元の2倍の密度の線をつくります。SAQPはこれを2回繰り返して4倍にします。線の幅は露光ではなく膜厚で決まるため、ばらつきが小さく、ArF液浸露光の限界(ピッチ約80 nm)より細かいフィンや配線を形成できます。EUV露光でも、最も細かいピッチでは組み合わせて使われます。

  2. 解像度の式 R = k1 × λ / NA にもとづき、解像度を向上させる(Rを小さくする)方法として正しいものはどれか。

関連する用語の解説

マルチパターニング
1回の露光では解像できない細かいピッチのパターンを、複数回の露光や加工に分けて形成する技術。2回に分けるものをダブルパターニングという。
SADP(自己整合ダブルパターニング)
芯になるパターンの側壁に膜(スペーサー)をつくり、芯を除いてスペーサーをマスクにすることで、リソグラフィの限界の半分のピッチをつくる技術。2回繰り返すものはSAQP。
オーバーレイ(重ね合わせ精度)
前の工程でつくったパターンに対して、新しいパターンをどれだけ正確な位置に重ねられるか。ずれるとコンタクトが外れるなどの不良になるため、ナノメートル単位で管理する。
ALD
原子層堆積。前駆体ガスの自己制限的な表面反応を繰り返し、原子層単位で膜厚を制御する成膜法。
ハードマスク
深い穴の加工などで、フォトレジストだけではマスクとして持たない場合に使う、窒化膜や炭素膜、金属などの硬いマスク。
液浸露光
レンズとウエハの間を水で満たして露光する方法。開口数を1以上にでき、ArFエキシマレーザーでより細かいパターンを形成できる。
EUV露光
波長13.5 nmの極端紫外光を使う露光技術。反射光学系と真空環境を用いる。
