境界型防御とゼロトラストの違い：信頼の前提・認証の頻度・リモートアクセスを比較

境界型防御は、社内のネットワークの内側を信頼し、インターネットとの境界にファイアウォールやVPNの装置を置いて外からの攻撃を防ぐ考え方です。ゼロトラストは、ネットワークの場所では信頼を与えず、利用者・端末・アクセス先の1つ1つの組み合わせについて、アクセスのたびに確かめてから必要な分だけを許可する考え方です。米国のNISTはSP 800-207(2020年)でゼロトラストのアーキテクチャを定義しています。クラウドのサービスや社外からの利用が増え、守るものが境界の外に出たことが、ゼロトラストが広まった背景にあります。

項目境界型防御ゼロトラスト
信頼の前提社内のネットワークの内側は信頼し、外側を信頼しないネットワークの場所では信頼しない。社内からのアクセスも、外からと同じように毎回確かめる
防御を置く場所インターネットとの境界(ファイアウォール、VPNの装置、プロキシなど)利用者・端末とアクセス先(アプリケーションやデータ)のあいだの、1つ1つのアクセスの経路。許可するかを判断する場所(ポリシー決定点)と、判断に従って通す場所(ポリシー実施点)を置く
認証・認可のタイミング社内のネットワークに入るとき(VPNに接続するときなど)に1回アクセス先ごと・セッションごと。利用者の認証(多要素認証など)、端末の状態、場所や時間などから判断し、状況が変われば見直す
社外からのアクセスVPNで社内のネットワークにつなぎ、社内にいるのと同じように扱うZTNA(ゼロトラストネットワークアクセス)などで、許可したアプリケーションにだけつなぐ。ネットワーク全体には入れない
侵入された後の横への広がり内側に入られると、内側の機器どうしの通信は制限が少ないため、ほかの機器へ広がりやすいアクセスを細かく区切り、必要な権限だけを与える(最小権限)ので、広がりにくい
端末の扱い社内のネットワークにつながっている端末を信頼しやすい端末が管理されているか、OSの更新やマルウェア対策の状態が正しいかを、アクセスのたびに判断の材料にする
可視化・記録境界を通る通信は記録されるが、内側どうしの通信は見えにくいすべてのアクセスの要求と判断を記録し、継続的な監視と、判断の方針の改善に使う
クラウドとの相性クラウドのサービスや自宅からの利用が増えると、守るものが境界の外に出る。すべての通信をVPN経由で社内に集めると、回線や装置が混雑しやすい場所によらず同じ方針で判断するので、クラウドのサービスやリモートワークに向く
移行の難しさ仕組みが分かりやすく、多くの組織がすでに持っているIDの管理、端末の管理、守る資産の一覧、アクセスの方針の設計が必要で、段階的に移行する。1つの製品を入れれば実現するものではない

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

境界型防御
利用者と守るシステムがおもに社内のネットワークにあり、出入口を絞れば守れる環境。ゼロトラストに移行した後も、境界のファイアウォールは多層防御の1つの層として残ります。
ゼロトラスト
クラウドのサービスやリモートワークが中心で、社内と社外の区別があいまいな環境。侵入されることを前提に、被害が広がる範囲を小さくしたいときにも向きます。
段階的な移行
多くの組織では、多要素認証の徹底、端末の管理、重要なアプリケーションから順にZTNAへ移す、というように、境界型の仕組みと併用しながら少しずつ移行します。

よくある質問

ゼロトラストでは、VPNは要らなくなりますか？

社外から社内のアプリケーションを使うためのVPNは、ZTNAで置き換えることがよくあります。VPNは接続するとネットワーク全体に入れるのに対し、ZTNAは許可したアプリケーションにだけ、アクセスのたびに確かめてつなぐからです。ただし、拠点どうしを結ぶVPNのように、ほかの目的で使い続けるものもあります。

ゼロトラストは、製品の名前ですか？

製品ではなく、セキュリティの設計の考え方です。NISTのSP 800-207(2020年)は、ネットワークの場所や資産の持ち主だけで信頼を与えず、リソースへのアクセスごとに認証と認可を行う考え方として、ゼロトラストとそのアーキテクチャを説明しています。実現には、IDの管理、多要素認証、端末の管理、ZTNA、記録と監視などを組み合わせます。

ゼロトラストにすると、ファイアウォールは不要になりますか？

不要にはなりません。ゼロトラストは、境界の内側だからという理由だけで信頼しないという考え方で、境界の防御をなくすことではありません。ファイアウォールは、不要な通信を入口で減らす層として引き続き使われ、ネットワークを細かく区切る手段としても使われます。

理解度チェック

次の認証の方法のうち、多要素認証に当たるものはどれか。

  1. Aパスワードを入力した後に、本人のスマートフォンのアプリに表示されたワンタイムパスワードを入力する
  2. Bパスワードを入力した後に、さらに秘密の質問の答えを入力する
  3. C長さが2倍の、より複雑なパスワードを入力する
答えと解説を見る

正解：A. パスワードを入力した後に、本人のスマートフォンのアプリに表示されたワンタイムパスワードを入力する

多要素認証は、知識・所持・生体のうち、異なる2つ以上の要素を組み合わせる認証です。パスワード(知識)と、本人のスマートフォンで作られるワンタイムパスワード(所持)の組み合わせは、異なる2つの要素を使うので多要素認証です。パスワードが漏れても、攻撃者は本人のスマートフォンを持っていなければログインできません。パスワードと秘密の質問は、どちらも知識の要素なので、2段階で確かめていても多要素認証ではありません(二段階認証と呼ばれることはあります)。同じ種類の要素を重ねても、同じ方法(例えば、フィッシングでだまして聞き出す)でまとめて盗まれるおそれがあります。なお、ワンタイムパスワードも、偽のサイトにその場で入力させて使われる攻撃があるため、2020年代半ばの時点で、偽のサイトでは認証が成り立たない方式(FIDO2のパスキーなど)の利用が広がっています。

シングルサインオン(SSO)の説明として正しいものはどれか。

  1. A1回の認証で、連携している複数のサービスを改めてログインせずに使えるようにする仕組みで、利便性が上がる一方、その認証が破られると多くのサービスに影響するので、多要素認証と組み合わせることが望ましい
  2. Bすべてのサービスで同じパスワードを使い回すことをいい、安全性を高めるために推奨されている
  3. C1つのサービスには同時に1人しかログインできないようにする仕組みである
答えと解説を見る

正解：A. 1回の認証で、連携している複数のサービスを改めてログインせずに使えるようにする仕組みで、利便性が上がる一方、その認証が破られると多くのサービスに影響するので、多要素認証と組み合わせることが望ましい

シングルサインオン(SSO)では、利用者が認証を行う仕組み(IdP、IDプロバイダ)に一度ログインすると、その結果が連携する各サービスに安全な形で伝えられ、サービスごとにログインし直さずに使えます。代表的な方式に、SAMLやOpenID Connectがあります。各サービスにパスワードを渡さないので、管理するパスワードが減り、退職者のアカウントを1か所で止められるなど管理の面でも利点があります。ただし、IdPのアカウントが乗っ取られると連携するすべてのサービスに入られてしまうため、IdPでの多要素認証が特に重要です。パスワードの使い回しは、1つのサービスから漏れたパスワードでほかのサービスにも入られる(パスワードリスト攻撃)原因になるもので、SSOとは別のものです。

最小権限の原則に沿った運用として正しいものはどれか。

  1. A作業の手間を減らすため、全員に管理者の権限を与えておく
  2. B権限の設定を簡単にするため、すべてのファイルを全員が読み書きできるようにする
  3. C利用者やプログラムには、業務に必要な最小限の権限だけを与え、普段の作業は管理者ではないアカウントで行う
答えと解説を見る

正解：C. 利用者やプログラムには、業務に必要な最小限の権限だけを与え、普段の作業は管理者ではないアカウントで行う

最小権限の原則は、利用者、プログラム、サービスのアカウントに、役割を果たすのに必要な最小限の権限だけを与えるという考え方です。権限を絞っておけば、アカウントが乗っ取られたり、マルウェアが動いたり、操作を誤ったりしたときでも、被害が及ぶ範囲を小さくできます。例えば、普段のメールやWebの閲覧は一般の権限のアカウントで行い、管理者の権限は必要な作業のときだけ使います。情報についても、業務で知る必要がある人だけがアクセスできるようにする「必要な人だけに知らせる(ニードトゥノウ)」の考え方があります。異動や退職のときに不要になった権限をすぐに取り消すことも大切です。

関連する用語の解説

多要素認証
知識(パスワードなど)、所持(スマートフォンやICカードなど)、生体(指紋や顔など)のうち、異なる2つ以上の要素を組み合わせて本人を確かめる認証。パスワードが漏れても、ほかの要素がなければログインできない。MFAとも呼ぶ。
最小権限の原則
利用者、プログラム、サービスに、役割を果たすのに必要な最小限の権限だけを与えるという考え方。アカウントの乗っ取りやマルウェア、操作の誤りが起きても、被害の範囲を小さくできる。
TLS
Transport Layer Securityの略。通信の暗号化、改ざんの検出、証明書によるサーバの認証を行うプロトコル。HTTPSはHTTPをTLSで保護したもの。
VLAN
仮想LAN。スイッチのポートなどを単位に、物理的に同じ機器の上に論理的に別々のネットワーク(ブロードキャストドメイン)を作る機能。スイッチの間ではIEEE 802.1Qのタグで区別する。
ランサムウェア
コンピュータの中のファイルを暗号化するなどして使えなくし、元に戻すことと引き換えに身代金を要求するマルウェア。盗んだデータを公開すると脅す手口もある。ネットワークから切り離したバックアップが重要な備えになる。
