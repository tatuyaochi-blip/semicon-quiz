スタティック・ダイナミック・ウエハレベルのバーンインの違い：ストレス・網羅性・コストを比較

バーンインは、高温と定格より高い電圧のもとで製品に電源を入れ、初期故障を起こしやすい製品を出荷前に取り除くスクリーニングです。スタティックバーンインは、電源と固定のバイアスをかけるだけで回路を動かさないので、装置は簡単ですが、ストレスがかかる部分が限られます。ダイナミックバーンインは、クロックやテストパターンを入れて内部の回路を動かしながら行うので、より広い範囲にストレスを加えられます。ウエハレベルバーンインは、行う段階の違いで、ダイシング前のウエハの状態でまとめてストレスを加え、パッケージに入れる前に不良のチップを見つけます。

どんなときに使うか

スタティックバーンイン
回路を動かさなくても、電圧のストレスで主な欠陥を加速できる製品で、装置とコストを抑えたいとき。
ダイナミックバーンイン
内部の回路が複雑で、動かさないとストレスがかからない部分が多い製品を、より確実にスクリーニングしたいとき。
ウエハレベルバーンイン
パッケージに入れる前に良品と確認したダイ(KGD)が必要なとき。1つの不良で全体が不良になる、複数のチップを積むパッケージなど。
テスト工程での位置
一般的な流れは、ウエハテスト、組立、最終テスト、出荷で、パッケージのバーンインは最終テストの前後に入れます。ウエハレベルバーンインは、ウエハテストの段階でストレスを加える方法です。

よくある質問

スタティックとダイナミックのバーンインの違いは何ですか？

スタティックバーンインは、電源と固定のバイアスをかけるだけで回路を動かしません。ダイナミックバーンインは、クロックやテストパターンで内部のノードを切り替えながら動かすので、より多くのトランジスタや配線にストレスを加えられ、初期故障を見つけやすくなります。

なぜウエハの状態でバーンインをするのですか？

複数のチップを1つのパッケージに入れる場合、1つでも不良が混ざると全体が不良になるからです。ウエハの状態でバーンインを行い、初期故障を起こすチップを先に取り除けば、良品と確認したダイ(KGD)だけを組み立てられます。

バーンインで良品の寿命は短くなりませんか？

わずかに使いますが、条件は、良品が摩耗寿命のごく一部しか失わないように選びます。バーンインの目的は、バスタブ曲線の初期故障期を出荷前に済ませ、故障率の低い偶発故障期の状態で出荷することです。

理解度チェック

バーンインの目的として正しいものはどれか。

  1. Aチップの外観を検査する
  2. B高温・高電圧などのストレスを加えて、初期故障を起こす製品を出荷前に取り除く
  3. Cウエハの膜厚を測定する
答えと解説を見る

正解：B. 高温・高電圧などのストレスを加えて、初期故障を起こす製品を出荷前に取り除く

バーンインは、125 ℃前後の高温と定格より高い電圧のもとで製品を数時間〜数十時間動作させ、潜在的な欠陥をもつ製品を早く故障させて取り除くスクリーニングです。バスタブ曲線の初期故障期を出荷前に済ませておくことが目的で、車載やサーバー向けなど高い信頼性が必要な製品で行います。外観検査や膜厚の測定とは目的が違います。

故障率の時間変化を表すバスタブ曲線を構成する3つの期間の組み合わせとして正しいものはどれか。

  1. A初期故障期・偶発故障期・摩耗故障期
  2. B設計期・製造期・出荷期
  3. C試作期・量産期・保守期
答えと解説を見る

正解：A. 初期故障期・偶発故障期・摩耗故障期

バスタブ曲線は、使い始めに製造上の欠陥で故障率が高い初期故障期、故障率が低く一定に近い偶発故障期、劣化によって故障率が上がる摩耗故障期の3つからなり、形が浴槽の断面に似ています。初期故障はバーンインなどで出荷前に取り除き、摩耗故障は製品の想定寿命より後に起こるように設計します。設計・製造・出荷などは製品のライフサイクルの段階で、故障率の期間ではありません。

複数のチップを1つのパッケージに実装する際に重要となるKGD(Known Good Die)とは何か。

  1. A大型のチップ
  2. B故障したチップ
  3. C実装前に良品であることが確認されたチップ(ダイ)
答えと解説を見る

正解：C. 実装前に良品であることが確認されたチップ(ダイ)

複数のチップを1つのパッケージに組み込む場合、1つでも不良チップが含まれると、ほかの良品チップも含めてパッケージ全体が不良になります。例えば良品率99%のチップを8個積むと、全部が良品である確率は0.99⁸≒92%まで下がります。そのため、実装前のダイの段階で十分にテストした良品(KGD)を使うことが重要で、HBMやチップレットで特に重視されます。

  1. 一般的な半導体製品のテストの流れとして正しいものはどれか。
  2. 温度を上げて寿命試験の時間を短縮する加速試験で、温度と寿命の関係を表すためによく使われるモデルはどれか。
  3. 製品を高温で長時間動作させ、寿命や故障率を評価する代表的な信頼性試験はどれか。

関連する用語の解説

バーンイン
高温・高電圧などのストレスを加えて動作させ、初期故障を起こしやすい製品を出荷前に取り除く試験。
バスタブ曲線
故障率の時間変化を表す曲線。初期故障期・偶発故障期・摩耗故障期からなり、浴槽のような形になる。
KGD(ノウングッドダイ)
実装する前に良品であることが確認されたチップ。複数のチップを1つのパッケージに積む場合、1つでも不良が混ざると全体が不良になるため重要になる。
アレニウスモデル
反応や劣化の速さが温度に対して exp(−Ea/kT) で変わるとするモデル。温度を上げた加速試験の結果から、実際の使用温度での寿命を推定するのに使う。
ウエハテスト(プローブテスト)
ダイシングの前に、ウエハ上の各チップの電極にプローブを当てて電気的特性を検査する工程。不良チップを組み立て前に見つけ、無駄な組み立てを避ける。
