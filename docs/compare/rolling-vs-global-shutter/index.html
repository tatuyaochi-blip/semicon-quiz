ローリングシャッターとグローバルシャッターの違い：露光・ゆがみ・ノイズ・用途を比較

どちらもイメージセンサの電子シャッターの方式です。ローリングシャッターは、画素の行ごとに少しずつ時刻をずらして露光し、順に読み出します。画素の回路が簡単でノイズも小さくできますが、上の行と下の行で撮影の時刻が違うため、速く動く被写体は斜めにゆがみます。グローバルシャッターは、すべての画素を同時に露光し、電荷を画素の中に一時的に保持してから読み出すので、ゆがみが生じません。その代わり、画素の回路が増え、画素が大きくなりやすくなります。

どんなときに使うか

ローリングシャッター
被写体の動きが速すぎず、画素の小ささ、感度、低ノイズ、コストを優先したいとき。多くのカメラの標準です。
グローバルシャッター
速く動く物を正確な形で撮りたいとき、またはパルス光やフラッシュと露光を正確に合わせたいとき。検査や計測、機械が画像を判断する用途です。
ゆがみを小さくするには
ローリングシャッターでも、1画面を読み出す時間を短くすれば、ゆがみは小さくなります。積層型センサで読み出しを速くしたり、メカニカルシャッターと組み合わせたりする方法があります。

よくある質問

ローリングシャッターで、動く物がゆがむのはなぜですか？

画素を1行ずつ順に露光して読み出すため、画面の上の行と下の行で撮影の時刻が数 ms〜数十 msずれるからです。その間に被写体が動くと、行ごとに違う位置が写り、全体が斜めにゆがみます。

グローバルシャッターのほうが常に優れていますか？

そうとは限りません。グローバルシャッターは画素に保持部が必要なので、画素が大きくなりやすく、感度やノイズ、コストの面では不利になりがちです。動きのゆがみが問題にならない用途では、ローリングシャッターが選ばれます。

照明のちらつきが縞になるのはなぜですか？

ローリングシャッターでは行ごとに露光の時刻が違うため、点滅する照明の明るさが変わる途中で露光した行と、そうでない行の明るさに差が出て、横縞として写ります。グローバルシャッターでは全画素が同時に露光するので縞になりません。

理解度チェック

CMOSイメージセンサのローリングシャッター方式で、速く動く被写体がゆがんで写る理由として正しいものはどれか。

  1. A行ごとに露光と読み出しのタイミングがずれるため
  2. Bすべての画素を同時に露光するため
  3. Cカラーフィルタの配列のため
答えと解説を見る

正解：A. 行ごとに露光と読み出しのタイミングがずれるため

ローリングシャッター方式では、画素を1行ずつ順に露光・読み出すため、上の行と下の行で撮影時刻が数ms〜数十msずれます。そのため速く動く被写体が斜めにゆがんだり、蛍光灯のちらつきが縞になったりします。全画素を同時に露光するグローバルシャッター方式ではゆがみが生じず、工業用の検査カメラや車載で使われますが、画素内に電荷を一時保持する回路が必要で画素が大きくなります。

CMOSイメージセンサの代表的な4トランジスタ画素で、フォトダイオードの電荷を浮遊拡散層(フローティングディフュージョン)に移す役割をもつトランジスタはどれか。

  1. A転送トランジスタ
  2. Bリセットトランジスタ
  3. C選択トランジスタ
答えと解説を見る

正解：A. 転送トランジスタ

4トランジスタ画素は、転送、リセット、増幅(ソースフォロワ)、選択の4つのトランジスタで構成されます。転送トランジスタが埋め込みフォトダイオードの電荷を浮遊拡散層(FD)に移し、その電圧を増幅トランジスタで出力します。リセットはFDの初期化、選択は読み出す行の選択です。転送前後の値の差をとるCDSが可能になるのがこの構造の利点で、隣の画素とFDなどを共有して面積を減らす工夫もあります。

CMOSイメージセンサの読み出しで使われる相関二重サンプリング(CDS)の目的として正しいものはどれか。

  1. A信号を2倍に増幅するため
  2. B色の情報を補間するため
  3. Cリセット時と信号読み出し時の差をとり、リセットノイズや画素ごとのオフセットを除去するため
答えと解説を見る

正解：C. リセット時と信号読み出し時の差をとり、リセットノイズや画素ごとのオフセットを除去するため

CDSでは、浮遊拡散層をリセットした直後の出力と、フォトダイオードの電荷を転送した後の出力をそれぞれサンプリングし、その差を信号とします。リセットのたびにばらつくkTC雑音と画素ごとのアンプのオフセットは両方の値に共通なので、差をとると打ち消されます。埋め込みフォトダイオードの完全転送と組み合わせることで、読み出しノイズを電子数個分以下まで減らせます。

関連する用語の解説

ローリングシャッター
画素の行ごとに順番に露光と読み出しを行う方式。回路が簡単だが、速く動く被写体はゆがんで写る。すべての画素を同時に露光する方式はグローバルシャッター。
グローバルシャッター
すべての画素を同時に露光する電子シャッター方式。行ごとに順に読み出すローリングシャッターと違い、動く物の像がゆがまない。
相関二重サンプリング(CDS)
画素をリセットしたときの電圧と、信号を読み出したときの電圧の差をとる処理。リセットノイズや画素ごとのオフセットを取り除ける。
CMOSイメージセンサー
画素ごとに増幅回路をもち、CMOSプロセスで作るイメージセンサー。低消費電力で周辺回路を集積でき、スマートフォンのカメラなどの主流。
