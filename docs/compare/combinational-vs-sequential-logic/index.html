組み合わせ回路と順序回路の違い：出力の決まり方を比較

組み合わせ回路では、出力が現在の入力だけで決まるので、同じ入力にはいつも同じ出力が返ります。順序回路では、出力が、記憶している状態、つまり過去の入力の履歴にも依存します。順序回路は、フリップフロップなどの記憶素子を持ち、多くはクロックで制御されます。実際のデジタルシステムは両方を交互に使い、状態を保持するレジスタの間で、組み合わせ回路が計算します。

項目組み合わせ回路順序回路
出力が依存するもの現在の入力だけ現在の入力と、記憶している状態(履歴)
記憶素子なしフリップフロップやラッチ
クロック不要多くはクロックで動く(同期設計)
フィードバックなし。フィードバックのループがあれば、設計の誤り状態の素子を通したフィードバックがある
例加算器、マルチプレクサ、デコーダ、エンコーダ、比較器レジスタ、カウンタ、シフトレジスタ、ステートマシン

どんなときに使うか

組み合わせ回路
算術や選択のように、現在の値だけに依存すべき計算やデコードのとき。
順序回路
何かを覚えておくもの全般。カウンタ、レジスタ、制御回路、一連の手順に従う回路。
HDLのヒント
組み合わせ回路のalwaysブロックでは、すべての分岐ですべての出力に代入します。そうしないと、論理合成で意図しないラッチが推論されます。

理解度チェック

  1. 順序回路の説明として正しいものはどれか。
  2. 組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。
  3. 出力が現在の状態だけで決まる順序回路(ステートマシン)の型はどれか。
  4. すべてのフリップフロップが共通のクロックで動作する同期式回路の利点として正しいものはどれか。
  5. 組み合わせ回路のつもりで上のように書いた。起こりうる問題として正しいものはどれか。
  6. 組み合わせ回路のalwaysブロックで、意図しないラッチを防ぐためによく使われる書き方はどれか。

関連する比較

  • ラッチとフリップフロップの違い：動作と使い分けを比較ラッチとフリップフロップを、トリガー・出力の動き・構成・大きさ・タイミング解析・グリッチ・デジタル設計での使い分けの観点で表にして比較します。
  • CMOSとTTLの違い：論理ICのファミリーを比較CMOSとTTLの論理ICを、トランジスタ・静的消費電力・電源電圧・論理レベル・ノイズマージン・速度・入力・使われる場所の観点で表にして比較します。
  • BJTとMOSFETの違い：制御方式・速度・用途を比較バイポーラトランジスタ(BJT)とMOSFETを、制御方式・入力電流・キャリア・速度・オン状態・温度特性・集積度・用途の観点で表にして比較します。
  • SAR・ΔΣ・パイプライン・フラッシュADCの違い：方式を比較フラッシュ型、SAR型、パイプライン型、ΔΣ型のADCを、仕組み・分解能・速度・遅延・消費電力・面積・用途の観点で表にして比較します。
  • JFETとMOSFETの違い：ゲート構造と使い分けを比較JFETとMOSFETを、ゲートの構造・ノーマリオンかオフか・ゲート電流・雑音・静電気への強さ・集積度・用途の観点で表にして比較します。
  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
