CZ法とFZ法の違い：シリコン単結晶の育て方を比較

ほとんどのシリコンウェハは、2つの方法のどちらかで育てた単結晶から作ります。チョクラルスキー(CZ)法では、石英のるつぼの中で溶かしたシリコンに種結晶をつけ、ゆっくり引き上げます。フローティングゾーン(FZ)法では、ポリシリコンの棒をコイルで狭い範囲だけ溶かし、その溶けた部分を棒に沿って動かすので、シリコンがるつぼに触れません。CZ法は安く、大きなウェハを作れます。FZ法は、より純度の高いシリコンが得られます。

項目CZ法FZ法
結晶の育て方石英のるつぼで溶かしたシリコンに種結晶をつけ、回しながら引き上げる高周波のコイルでポリシリコンの棒の狭い範囲を溶かし、その部分を棒に沿って動かす
るつぼとの接触あり。石英から酸素が融液に溶け込むなし。酸素はごくわずか
酸素濃度高い非常に低い
純度と抵抗率純度は低め。抵抗率に限りがある(磁場を使うMCZ法で改善)非常に高純度で、抵抗率も非常に高い
ドーピング融液にドーパントを入れる。インゴットの中で濃度が変わるガスによるドーピング、または中性子照射(NTD)による均一なリンのドーピング
ウェハの直径量産で最大300 mm一般に約200 mmまで。それより大きいものは難しい
コスト安い。大きなインゴットで生産性がよい高い
機械的な強度とゲッタリング酸素の析出物が強度を高め、金属不純物を捕らえる(イントリンシックゲッタリング)これらの利点がなく、ウェハは割れやすいことがある
主な用途ウェハの大部分。ロジック、メモリ、太陽電池高耐圧のパワーデバイス(IGBTなど)、検出器、高抵抗率のRFデバイス

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

CZ法
主流のチップの標準です。最大のウェハサイズまで対応でき、最も経済的です。
FZ法
コストやウェハサイズよりも、高純度と非常に高い抵抗率が重要なとき。主にパワーデバイスやセンサー向けです。

理解度チェック

  1. FZ法(フローティングゾーン法)で作製したシリコン単結晶の特徴として正しいものはどれか。
  2. CZ法で育成したシリコン結晶に、るつぼから比較的多く取り込まれる不純物はどれか。
  3. CZ法で、結晶の引き上げ速度と結晶中の温度勾配の比(V/G)を制御する主な目的はどれか。
  4. CZ法でp型のシリコン結晶をつくるとき、融液に添加する代表的な不純物はどれか。
  5. FZシリコンに中性子を照射し、シリコンの一部をリンに変換して均一なn型にする方法はどれか。
  6. CZ法で、るつぼに磁場をかけて融液の対流を抑え、酸素濃度などを制御する方法はどれか。
