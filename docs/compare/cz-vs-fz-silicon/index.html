CZ法とFZ法の違い：シリコン単結晶の育て方を比較

ほとんどのシリコンウェハは、2つの方法のどちらかで育てた単結晶から作ります。チョクラルスキー(CZ)法では、石英のるつぼの中で溶かしたシリコンに種結晶をつけ、ゆっくり引き上げます。フローティングゾーン(FZ)法では、ポリシリコンの棒をコイルで狭い範囲だけ溶かし、その溶けた部分を棒に沿って動かすので、シリコンがるつぼに触れません。CZ法は安く、大きなウェハを作れます。FZ法は、より純度の高いシリコンが得られます。

項目CZ法FZ法

どんなときに使うか

CZ法
主流のチップの標準です。最大のウェハサイズまで対応でき、最も経済的です。
FZ法
コストやウェハサイズよりも、高純度と非常に高い抵抗率が重要なとき。主にパワーデバイスやセンサー向けです。

よくある質問

なぜCZ法が最も一般的なのですか？

安く、大きなインゴット(量産で最大300 mmのウェハ)が作れ、酸素の析出物が強度を高め、不純物を捕らえるウェハになるからです。

なぜFZ法のシリコンは抵抗率が高いのですか？

るつぼがシリコンに触れないので、酸素やほかの不純物がほとんど入らず、非常に高い純度と抵抗率が得られます。

中性子転換ドーピングとは何ですか？

FZ法のシリコンに中性子を照射して、一部のシリコン原子をリンに変え、非常に均一なn型のドーピングを実現する方法です。

FZ法のウェハは何に使われますか？

IGBTなどの高耐圧のパワーデバイス、検出器、高抵抗率のRFデバイスなどです。

理解度チェック

FZ法(フローティングゾーン法)で作製したシリコン単結晶の特徴として正しいものはどれか。

  1. A大口径化が最も容易で、300 mmウエハの主流の製法である
  2. B石英るつぼを使わないため酸素などの不純物が少なく、高抵抗の結晶を得やすい
  3. C多結晶シリコンを溶かさずに単結晶化する
答えと解説を見る

正解：B. 石英るつぼを使わないため酸素などの不純物が少なく、高抵抗の結晶を得やすい

FZ法は、多結晶シリコンの棒の一部を高周波誘導加熱で帯状に溶かし、その溶融帯を移動させて単結晶化する方法です。るつぼを使わないため酸素の混入が少なく、不純物も溶融帯に集まって除かれるため、高純度で抵抗率1000 Ω·cm以上の結晶も得られます。耐圧の高いパワーデバイス(IGBTなど)や検出器に使われますが、大口径化はCZ法の方が容易で、200 mm程度が上限です。

CZ法で育成したシリコン結晶に、るつぼから比較的多く取り込まれる不純物はどれか。

  1. A金
  2. B酸素
  3. Cヘリウム
答えと解説を見る

正解：B. 酸素

CZ法では石英(SiO2)のるつぼでシリコンを溶かすため、るつぼから溶け出した酸素が結晶に約10¹⁸ cm⁻³取り込まれます。酸素は転位を固着して結晶の機械的強度を高め、熱処理でできる析出物がゲッタリングサイトとして働く利点がある一方、多すぎると欠陥やサーマルドナーの原因になります。そのため磁場をかけて対流を抑えるMCZ法などで濃度を制御し、用途ごとに仕様を決めています。

CZ法で、結晶の引き上げ速度と結晶中の温度勾配の比(V/G)を制御する主な目的はどれか。

  1. A結晶に取り込まれる点欠陥(空孔や格子間シリコン)の種類と量を制御し、結晶欠陥を減らす
  2. B結晶の色を変える
  3. Cるつぼの寿命を延ばす
答えと解説を見る

正解：A. 結晶に取り込まれる点欠陥(空孔や格子間シリコン)の種類と量を制御し、結晶欠陥を減らす

引き上げ速度Vと界面付近の温度勾配Gの比で、結晶に過剰に取り込まれる点欠陥が空孔になるか格子間シリコンになるかが決まります。V/Gが大きいと空孔が余って集まり微小な空洞(COP)に、小さいと格子間シリコンが余って転位ループになります。両者がちょうどつり合う狭い条件で引き上げると、どちらの欠陥もほとんどない結晶(完全結晶、パーフェクトシリコン)が得られます。

  1. CZ法でp型のシリコン結晶をつくるとき、融液に添加する代表的な不純物はどれか。
  2. FZシリコンに中性子を照射し、シリコンの一部をリンに変換して均一なn型にする方法はどれか。
  3. CZ法で、るつぼに磁場をかけて融液の対流を抑え、酸素濃度などを制御する方法はどれか。

関連する用語の解説

CZ法(チョクラルスキー法)
るつぼで溶かしたシリコンに種結晶を浸し、回転させながら引き上げて単結晶をつくる方法。
FZ法(フローティングゾーン法)
多結晶シリコンの棒の一部を加熱して溶かし、その溶けた帯を移動させて単結晶にする方法。るつぼを使わないため酸素が少なく、高抵抗のウエハに向く。
MCZ法(磁場印加CZ法)
CZ法で、るつぼに磁場をかけて融液の対流を抑える方法。結晶に取り込まれる酸素の濃度を制御しやすく、大口径の結晶で使われる。
