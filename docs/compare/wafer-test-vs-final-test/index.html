ウエハテストとファイナルテストの違い：時期・接触のしかた・温度・項目・目的を比較

ウエハテストは、前工程を終えてダイシングする前のウエハで、各チップの電極パッドにプローブカードの針を当てて良否を調べるテストです。不良のチップを組立の前に除くことで、パッケージや組立の費用をむだにしません。ファイナルテスト(最終テスト)は、パッケージに組み立てたあとのICをハンドラでソケットに入れて測るテストで、組立で生じた不良も含めて、仕様どおりに動くことを確かめてから出荷します。

項目ウエハテスト(プローブテスト)ファイナルテスト(最終テスト)
時期前工程を終え、ダイシングする前組立(パッケージへの封止)を終えたあと、出荷の前
対象ウエハ上のすべてのチップパッケージに封止したIC(ウエハテストで良品だったチップを組み立てたもの)
接触のしかたプローバがウエハを動かし、プローブカードの針をチップの電極パッドに当てるハンドラがICをソケットに入れ、ポゴピンなどでパッケージの端子(リードやボール)に接触させる
使う装置テスター、プローバ、プローブカードテスター、ハンドラ、ソケットを載せたロードボード
温度ウエハを載せるチャックの温度を変えて測る。室温のほか高温や低温で測ることもあるハンドラでICを加熱・冷却し、製品が保証する温度範囲の高温・低温で測ることが多い
主なテスト項目直流特性(リーク電流など)、機能テスト、スキャンテスト。メモリでは不良ビットを予備に置き換える救済のための測定機能、直流特性、タイミングなどの交流特性、実際の速度での動作。速度などによる等級分け
高速の信号の測定針の電気的な特性の制約があり、高速の信号や大電流の測定が難しいことがあるソケットのほうが電気的に有利で、高速の信号を測りやすい
不良を見つける目的組立の前に不良チップを除き、パッケージや組立の費用を節約する。ウエハマップから工程の問題を早く見つける組立で生じた不良(接続の不良など)も含めて取り除き、品質を保証して出荷する
不良の扱い不良チップをウエハマップの電子データに記録し、組立で使わない(かつてはインクで印をつけた)不良品を除き、良品は性能などで分類して出荷する
KGDとの関係複数のチップを1つのパッケージに載せる場合、この段階で良品と確かめたチップ(KGD)が求められる組み立てたあとで不良と分かっても、不良のチップだけを取り替えるのは難しい

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

ウエハテスト
組立の前に不良チップを除いて、パッケージや組立の費用を節約したいとき。複数のチップを1つのパッケージに載せる製品で、良品と確かめたチップ(KGD)だけを使いたいとき。
ファイナルテスト
組立のあとに、パッケージの状態で仕様どおりに動くことを保証してから出荷するとき。保証する温度範囲や実際の速度での動作を確かめたいとき。
組み合わせ
一般的な製品は、ウエハテスト → 組立 → ファイナルテスト → 出荷の順に、両方のテストを行います。2つのテストで項目を分担し、重複を減らしてテストのコストを下げます。

よくある質問

ファイナルテストがあるのに、ウエハテストも行うのはなぜですか？

不良のチップを組み立ててしまうと、パッケージの材料や組立の費用がむだになるからです。ウエハの段階で不良を除けば、良品だけを組み立てられます。また、ウエハマップで不良の分布を見ると、原因となった工程を早く見つけられます。

ウエハテストとWAT(パラメトリックテスト)は何が違いますか？

WATは、ウエハ上のTEG(評価用のパターン)でしきい値電圧やシート抵抗などを測り、工程が規格どおりにできたかを確かめる検査です。ウエハテストは、製品の各チップが正しく動くかを調べて良否を判定するテストです。

KGDとは何ですか？

実装する前に良品であることが確かめられたチップ(Known Good Die)のことです。複数のチップを1つのパッケージに載せる場合、1つでも不良のチップが混ざるとパッケージ全体が不良になるので、ウエハテストの段階で十分に確かめておく必要があります。

バーンインはどの段階で行いますか？

高い温度と電圧をかけて初期故障を起こしやすいチップを取り除く試験で、パッケージに組み立てたあとに行うことが多いです。KGDが必要な場合などには、ウエハの状態で行うウエハレベルのバーンインもあります。

理解度チェック

ウエハテスト(プローブテスト)の説明として正しいものはどれか。

  1. Aダイシング前に、ウエハ上の各チップにプローブを当てて電気的特性を検査する
  2. Bパッケージ封止後に、外観だけを検査する
  3. C製品を長期間使用して故障率を調べる
答えと解説を見る

正解：A. ダイシング前に、ウエハ上の各チップにプローブを当てて電気的特性を検査する

ウエハテストでは、プローバがウエハを動かしてプローブカードの針をチップの電極パッドに当て、テスタで電気的な特性や機能を検査します。不良チップをこの段階で見つければ、パッケージの材料費や組立の手間をむだにせずに済みます。不良は後の工程で見つかるほど損失が大きくなるためです。封止後の検査は最終テスト、長期間使って故障率を調べるのは信頼性試験です。

一般的な半導体製品のテストの流れとして正しいものはどれか。

  1. A最終テスト → ウエハテスト → 組立 → 出荷
  2. B組立 → ウエハテスト → 出荷 → 最終テスト
  3. Cウエハテスト → 組立 → 最終テスト → 出荷
答えと解説を見る

正解：C. ウエハテスト → 組立 → 最終テスト → 出荷

まず前工程を終えたウエハの状態でウエハテストを行い、不良チップを判別します。良品チップだけを組立工程でパッケージに入れ、最終テストで特性を確認してから出荷します。製品によっては最終テストの前後にバーンインやシステムレベルテストを行います。最終テストは組立のあとで、出荷のあとに行うテストはないため、ほかの順序は成り立ちません。

プローブカードの説明として正しいものはどれか。

  1. Aチップを封止するための金型
  2. Bウエハを搬送するための容器
  3. Cウエハ上のチップの電極に針を接触させ、テスタと電気的に接続する治具
答えと解説を見る

正解：C. ウエハ上のチップの電極に針を接触させ、テスタと電気的に接続する治具

プローブカードは、チップの電極パッドの配置に合わせて多数の針を並べた、品種ごとの専用治具です。プローバがカメラでウエハの位置を合わせ、チャックを上げて針とパッドを接触させ、テスタとチップを電気的につなぎます。針の方式には、斜めの針の片持ち梁型、垂直型、MEMS技術でつくる型があります。封止用の金型や搬送容器とは別物です。

  2. 複数のチップを1つのパッケージに実装する際に重要となるKGD(Known Good Die)とは何か。

テスト・検査の練習問題へ

関連する用語の解説

ウエハテスト(プローブテスト)
ダイシングの前に、ウエハ上の各チップの電極にプローブを当てて電気的特性を検査する工程。不良チップを組み立て前に見つけ、無駄な組み立てを避ける。
プローブカード
ウエハの状態でチップの電極に多数の針(プローブ)を当て、テスタと電気的につなぐための治具。
KGD(ノウングッドダイ)
実装する前に良品であることが確認されたチップ。複数のチップを1つのパッケージに積む場合、1つでも不良が混ざると全体が不良になるため重要になる。
バーンイン
高温・高電圧などのストレスを加えて動作させ、初期故障を起こしやすい製品を出荷前に取り除く試験。
ダイシング
ウエハを個々のチップ(ダイ)に切り分ける工程。回転するブレードで切る方法のほか、レーザーで内部に改質層をつくるステルスダイシングなどがある。
