ウェットエッチングとドライエッチングの違い：方向性・選択比・用途を比較

エッチングは、ウェハから材料を取り除いてパターンを作る工程です。ウェットエッチングは、材料を薬液に溶かして取り除きます。簡単で速く、選択比も高いのですが、深さ方向だけでなく横方向にも削れやすく(等方性)、微細な加工には向きません。ドライエッチングは、真空チャンバー内で反応性ガスのプラズマを使います。イオンの働きで強い方向性(異方性)を持たせることができ、現代のチップに必要な、細くて垂直な形を彫るのに欠かせません。

項目ウェットエッチングドライエッチング
媒体薬液。酸化膜にはHF、窒化膜には熱リン酸、シリコンにはKOHなど真空チャンバー内の反応性ガスのプラズマ(RIEなど)
方向性多くは等方性。横方向にも削れ、マスクの下まで入り込む(KOHによるシリコンのエッチングは、結晶面に沿う例外)強い異方性にできる。イオンの衝突と側壁の保護で、ほぼ垂直な側壁が得られる
選択比多くは非常に高い。薬液の化学反応が特定の材料に限られるためウェットより低く、ガスの種類やプラズマの条件で調整する
最小の寸法サイドエッチで制限される。大きなパターンや膜の除去に使うナノメートル級のパターンに必須
スループット高い。槽で多数のウェハをまとめて処理できる低め。多くは1枚ずつ処理する
プロセスの制御槽の温度、濃度、時間に左右される精密。プラズマの発光で終点を検出できる
ダメージプラズマによるダメージはないプラズマによるダメージや帯電(アンテナ効果)の可能性がある
装置と廃棄物装置は簡単だが、廃液が出る複雑な真空装置と排ガスの処理が必要で、コストが高い
主な用途ウェハの洗浄、膜(酸化膜・窒化膜)の除去、MEMSのバルクのシリコンエッチング先端ICのゲート、コンタクト、トレンチ、ビアのパターニング

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

ウェットエッチング
形よりも選択比が大切なとき、または膜全体の除去や洗浄をするとき。酸化膜の除去、窒化膜の除去、MEMSのバルクエッチングなど。
ドライエッチング
パターンが細かく、垂直な壁が必要なとき。トランジスタのゲート、コンタクト、トレンチ、ビアなど。
組み合わせ
チップの製造工程では両方を使います。ドライエッチングで細かいパターンを作り、そのあとの洗浄や膜の除去にウェットの工程を使います。

理解度チェック

  1. 異方性エッチングの説明として正しいものはどれか。
  2. ウェットエッチングの一般的な特徴として正しいものはどれか。
  3. 反応性イオンエッチング(RIE)の説明として正しいものはどれか。
  4. ドライエッチングで異方性が得られる仕組みの一つとして正しいものはどれか。
  5. プラズマエッチング中に、長い配線などのアンテナとなる導体が電荷を集め、つながっているゲート酸化膜を損傷させる現象を何と呼ぶか。
  6. 水酸化カリウム(KOH)水溶液によるシリコンのウェットエッチングの特徴として正しいものはどれか。
