シングルモードとマルチモードの光ファイバの違い：コア径・波長・距離・モード分散・コストを比較

シングルモードファイバは、コアの直径が約9 µmと細く、光が1つのモードだけで進むので、モードによる速さの違い(モード分散)がなく、数十 km以上の長距離や高速な通信に使われます。マルチモードファイバは、コアの直径が50 µmや62.5 µmと太く、多数のモードが同時に進むため、モード分散で届く距離が数十〜数百 m程度に限られます。そのかわり、850 nmのVCSELのような安価な光源を使え、位置合わせも楽なので、データセンターや建物の中の短い接続に向いています。

どんなときに使うか

シングルモードファイバ
数百 mを超える距離や、将来の高速化を見込む配線。長距離の通信、加入者線、データセンターの建物間やスイッチ間の接続。波長多重(WDM)で1本に多くの信号を載せたいとき。
マルチモードファイバ
同じ部屋や同じ建物の中など、およそ100 m以下の短い接続を安く作りたいとき。850 nmのVCSELを使う光トランシーバと組み合わせます。
傾向
1レーンあたりの速度が上がるほどマルチモードで届く距離が短くなるため、データセンターの中でもシングルモードを使う範囲が広がっています。

よくある質問

なぜマルチモードファイバは遠くまで届かないのですか？

コアが太く、多数のモード(光の通り道)が同時に進むからです。モードごとに進む距離と速さがわずかに違うので、出発したときは同じだったパルスが、到着するときには時間的に広がってしまいます(モード分散)。速い信号ほどパルスの間隔が短いので、届く距離が短くなります。

シングルモードファイバの方が高いのですか？

ファイバそのものは、シングルモードの方が安いくらいです。高くなりやすいのは光トランシーバの側で、約9 µmの細いコアに光を入れるために、出力の安定したレーザとサブµmの精度の位置合わせが必要になります。短い距離では、VCSELを使えるマルチモードの方がリンク全体で安くなることが多いです。

マルチモードファイバでは、なぜ850 nmの光がよく使われるのですか？

850 nm付近のVCSELは、安く大量に作れ、ウエハのまま検査でき、マルチモードファイバとの結合も容易だからです。マルチモードファイバも、この波長で帯域が広くなるように作られています。

シングルモードファイバでは、モード分散以外に何が距離を制限しますか？

損失と波長分散です。損失は1550 nm付近で最小(約0.2 dB/km)になり、標準的なシングルモードファイバの波長分散は1310 nm付近でほぼゼロになります。長距離では光増幅器で損失を補い、分散は補償や信号処理で対処します。

理解度チェック

波長850 nm付近のVCSELとマルチモードファイバを組み合わせた光接続の特徴として正しいものはどれか。

  1. A部品が安価で位置合わせも容易だが、届く距離は数十〜数百 m程度の短距離に限られる
  2. Bファイバの損失が最小になる波長帯を使うため、数百 kmを超える長距離通信の主流になっている
  3. Cシリコンが850 nmの光をよく通すため、シリコン導波路と直接つないで使うのに最適である
答えと解説を見る

正解：A. 部品が安価で位置合わせも容易だが、届く距離は数十〜数百 m程度の短距離に限られる

VCSELはウエハのまま検査でき、安価に量産できて消費電力も小さい面発光レーザーです。マルチモードファイバはコアの直径が50 µmなどと太いため、位置合わせが容易です。そのため、サーバとスイッチを結ぶラック内やラック間の短い接続に広く使われてきました。一方、マルチモードファイバでは複数の伝わり方(モード)で到着時間がずれるモード分散が起こるため、高速になるほど距離が短くなり(1レーン100 Gb/s級では、OM4ファイバで50〜100 m程度、OM3ではさらに短い)、850 nmではファイバの損失も約3 dB/km前後と大きめです。シリコンは850 nmの光を吸収するため、導波路には使えません。

データセンター内の比較的短い距離の光接続で、波長1.31 µm付近(Oバンド)がよく使われる理由として正しいものはどれか。

  1. Aファイバの損失が全波長の中で最も小さく、増幅器なしで数千 kmまで届くから
  2. B標準的なシングルモードファイバの波長分散がほぼゼロで、高速な信号の波形が崩れにくいから
  3. Cシリコンのバンドギャップと同じエネルギーの光なので、受光器にシリコンをそのまま使えるから
答えと解説を見る

正解：B. 標準的なシングルモードファイバの波長分散がほぼゼロで、高速な信号の波形が崩れにくいから

波長分散は、波長によってファイバ中を進む速さがわずかに異なるために、光のパルスが広がる現象です。標準的なシングルモードファイバでは1.31 µm付近で分散がほぼゼロになるため、分散を補償する処理なしで高速な信号を数 km〜10 km程度まで送りやすく、データセンター向けの多くの光トランシーバで使われています。損失が最小なのは1.55 µm付近(約0.2 dB/km)で、1.31 µmでは約0.3〜0.35 dB/kmとやや大きめです。1.31 µmの光子エネルギーは約0.95 eVで、シリコンでは吸収されません。

長距離の光ファイバ通信で、波長1.55 µm付近(Cバンド)が広く使われる主な理由はどれか。

  1. A石英の光ファイバの損失が最も小さくなる波長帯だから
  2. Bシリコンが最も強く光を吸収し、受光器をつくりやすい波長帯だから
  3. C波長分散がゼロになり、パルスがまったく広がらない波長帯だから
答えと解説を見る

正解：A. 石英の光ファイバの損失が最も小さくなる波長帯だから

石英(SiO2)の光ファイバの損失は、短い波長ではレイリー散乱、長い波長では赤外吸収で増えるため、その間の1.55 µm付近で最小(約0.2 dB/km)になります。100 km進んでも損失は約20 dBで済み、エルビウム添加ファイバ増幅器(EDFA)で光のまま増幅できることも、長距離通信でCバンドが使われる理由です。標準的なシングルモードファイバで波長分散がほぼゼロになるのは1.31 µm付近(Oバンド)で、1.55 µmでは分散が残ります。シリコンはこの波長をほとんど吸収しません。

  1. VCSEL(垂直共振器面発光レーザー)の特徴として正しいものはどれか。
  2. シングルモードファイバをシリコンの光チップに固定するとき、レーザー光を実際に通して出力を測りながら位置を合わせるアクティブアライメントが行われることが多い理由はどれか。

関連する用語の解説

シングルモードファイバ
1つの伝搬モードだけを通す光ファイバで、コアの直径は約9 µm。モードによって伝わる速さが違うことによるパルスの広がり(モード分散)がないため、長距離や高速な通信に使われる。
VCSEL(垂直共振器面発光レーザー)
基板に垂直な方向に光を出す半導体レーザー。ウエハのまま検査でき、2次元に並べるのも容易なため、データ通信や顔認証の光源などに使われる。
波長分散
光の進む速さが波長によってわずかに異なるため、光ファイバの中で光のパルスが広がる現象。標準的なシングルモードファイバでは1.31 µm付近でほぼゼロ、1.55 µmでは約17 ps/(nm·km)になる。
Oバンド
光ファイバ通信で使う波長1260〜1360 nm付近の帯域。標準的なシングルモードファイバの波長分散がほぼゼロになる1.31 µm付近を含み、データセンター内などの短距離の接続でよく使われる。
Cバンド
光ファイバ通信で使う波長1530〜1565 nm付近の帯域。石英ファイバの損失が最小(約0.2 dB/km)になり、エルビウム添加ファイバ増幅器(EDFA)で増幅できるため、長距離通信や高密度な波長多重(DWDM)に使われる。
