MCUとMPUの違い：マイコンとマイクロプロセッサを比較

マイコン(MCU)は、プロセッサ、フラッシュメモリ、RAM、タイマーやADC、通信インターフェースなどの周辺機能を1つのチップにまとめていて、小さなシステムを1チップだけで動かせます。マイクロプロセッサ(MPU)は、主に高速なプロセッサで、外付けのDRAMやストレージが必要で、多くはLinuxのような本格的なOSを動かします。MCUは単純で低消費電力のリアルタイム制御に、MPUは複雑でソフトウェアが豊富な機器に向いています。

項目MCUMPU
集積度CPU、フラッシュ、RAM、周辺機能(GPIO、タイマー、ADC、UART、SPI、I2C)を1チップに集積キャッシュとMMUを持つCPUコアが中心。DRAMとストレージは外付けのチップ
クロック約1 MHzから数百MHz数百MHzから数GHz
メモリチップ内のフラッシュが数KB〜数MB、SRAMが数KB〜数MB外付けのDRAM(数百MB〜数GB)と、eMMCやSDなどのストレージ
ソフトウェアOSなしのコード、または小さなリアルタイムOS(FreeRTOS、Zephyrなど)LinuxやAndroidなどの本格的なOS
リアルタイム性予測しやすい。割り込みの遅延はマイクロ秒単位Linuxでは、リアルタイム向けの拡張なしに保証するのは難しい
消費電力非常に小さい。スリープ時はマイクロアンペア。コイン電池で数年動くこともある大きい。数百ミリワットから数ワット
起動時間一瞬(ミリ秒)数秒。ブートローダーとOSの起動が必要
コストと基板チップは安く、基板も簡単で、外付け部品が少ないチップは高く、DRAMや電源用のチップも必要。基板は多層で複雑
主な用途家電、モーター制御、センサー、ウェアラブル、車載ECUスマートフォン、タブレット、セットトップボックス、ルーター、産業用のタッチパネル、車載のインフォテインメント
例STM32、ESP32、RP2040、Arduinoの基板NXP i.MX、TI Sitaraなどのアプリケーションプロセッサ、Raspberry Piのチップ

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

MCU
仕事が制御とセンシングで、消費電力が非常に小さいこと、すぐ起動することが必要で、プログラムがチップ内のメモリに収まるとき。
MPU
豊富なユーザーインターフェース、ネットワーク、ファイルシステム、OSに依存する大きなソフトウェアが必要なとき。
両方
両方を組み合わせた製品も多くあります。MPUがユーザーインターフェースとアプリケーションを動かし、MCUが時間に厳しい制御と電源管理を担当します。

理解度チェック

  1. マイコンのGPIO(汎用入出力)の端子を使うときに、最初に設定する必要があることとして正しいものはどれか。
  2. マイコンでLEDの明るさやモーターの回転の速さを調整するのによく使われる方法はどれか。
  3. UARTによるシリアル通信の特徴として正しいものはどれか。
  4. 周辺回路の状態を知る方法のうち、ポーリングと割り込みの違いとして正しいものはどれか。
  5. マイコンでADコンバータの変換結果を一定の間隔で大量に取り込むとき、DMAを使う利点として正しいものはどれか。
