SiCとGaNのパワー半導体の違い：耐圧・周波数・用途を比較

炭化ケイ素(SiC)と窒化ガリウム(GaN)は、どちらもシリコンよりバンドギャップが広く、電力変換でシリコンを上回ります。高い電界に耐え、速くスイッチングでき、損失も小さいです。使い分けの目安は電圧です。SiCは電気自動車のインバータなど、高電圧・大電力の用途に向きます。GaNは、比較的低い電圧で、スイッチング周波数がとても高い用途に強く、小型の急速充電器などに使われます。

バンドギャップ約3.3 eV(4H-SiC)。シリコンは1.12 eV約3.4 eV
絶縁破壊電界シリコンの約10倍シリコンの約10倍
熱伝導率高い。シリコンの約3倍で、冷却しやすいシリコンと同程度で、SiCより低い

どんなときに使うか

SiC
電圧も電力も大きく、効率と発熱が重要なとき。車載インバータ、太陽光発電や産業用の電源システムなど。
GaN
電圧が中程度で、高いスイッチング周波数で、小さく軽く効率の高い変換器を作りたいとき。充電器、アダプタ、サーバー電源など。
どちらも
高速にスイッチングするときは、波形の乱れ(リンギング)やノイズに注意が必要です。素子と同じくらい、配線のレイアウトとゲート駆動が重要です。

よくある質問

SiCとGaNはどちらが優れていますか？

全体としてどちらが優れているとは言えません。SiCは、電気自動車のインバータなど、高電圧・大電力に向き、GaNは、小型の充電器など、比較的低い電圧で、スイッチング周波数がとても高い用途に向きます。

なぜパワーデバイスではSiCやGaNがシリコンより優れているのですか？

どちらもバンドギャップが広く、絶縁破壊電界がシリコンの約10倍あるので、高い電圧に耐え、速くスイッチングでき、損失も小さくなります。

なぜシリコン上のGaNはSiCより安いのですか？

GaNのパワーデバイスは、多くがシリコンウェハ上に作られ、シリコンウェハは安く、既存のシリコンの工場でも作れます。SiCのウェハは、高価で、結晶成長も難しいです。

熱に強いのはSiCとGaNのどちらですか？

SiCです。熱伝導率がシリコンの約3倍あり、GaNはシリコンと同程度です。

理解度チェック

SiC(炭化ケイ素)がSiに比べて高耐圧パワーデバイスに有利な主な理由はどれか。

  1. A絶縁破壊電界がSiの約10倍と高いため
  2. BバンドギャップがSiより小さいため
  3. CウエハがSiより安価で大口径化しやすいため
答えと解説を見る

正解：A. 絶縁破壊電界がSiの約10倍と高いため

SiCはバンドギャップが約3.3 eVと大きく、絶縁破壊電界がSiの約10倍(約3 MV/cm)あります。同じ耐圧ならドリフト層を約1/10の厚さにでき、不純物濃度を約100倍にできるため、ドリフト層の抵抗は理論上数百分の1になります。熱伝導率もSiの約3倍で高温に強く、EVのインバータなどで採用が広がっています。一方、ウエハはSiより高価で、大口径化(8インチ)は途上です。

SiCやGaNのように、シリコンよりバンドギャップが大きい半導体の総称はどれか。

  1. Aワイドバンドギャップ半導体
  2. Bナローギャップ半導体
  3. Cアモルファス半導体
答えと解説を見る

正解：A. ワイドバンドギャップ半導体

バンドギャップがおおむね3 eV前後以上の半導体をワイドバンドギャップ半導体と呼び、SiC(約3.3 eV)やGaN(約3.4 eV)が代表です。絶縁破壊電界が高く、真性キャリアが少ないため高温でも動作しやすく、高耐圧・低損失のパワーデバイスや高周波デバイスに使われます。さらに大きいGa2O3(約4.8 eV)やダイヤモンド(約5.5 eV)は、ウルトラワイドバンドギャップ半導体と呼ばれます。

電気自動車のインバータにSiCパワーデバイスを使う主な利点はどれか。

  1. Aシリコンより必ず安価になる
  2. B損失が小さく、航続距離の延長や冷却装置の小型化につながる
  3. Cモーターが不要になる
答えと解説を見る

正解：B. 損失が小さく、航続距離の延長や冷却装置の小型化につながる

SiCデバイスはオン抵抗とスイッチング損失が小さく高温に強いため、EVのインバータ損失を減らせます。損失が減れば同じ電池で走れる距離が数%〜1割程度延び、冷却装置やインバータも小型・軽量にできます。2018年のTesla Model 3で本格採用されて以降、普及が進み、800 V系の高電圧バッテリーで特に効果が大きくなります。課題はSi IGBTより高いコストです。

関連する用語の解説

SiC(炭化ケイ素)
バンドギャップ約3.3 eVのワイドギャップ半導体。絶縁破壊電界が高く、高耐圧・低損失のパワーデバイスに使われる。
GaN(窒化ガリウム)
バンドギャップ約3.4 eVのIII-V族化合物半導体。青色LEDや高周波・パワーデバイスに使われる。
ワイドバンドギャップ半導体
シリコンよりバンドギャップが大きい半導体。SiCやGaNなど。絶縁破壊電界が高く、高電圧・高温での動作に強い。
パワーMOSFET
大きな電流や電圧を扱えるようにしたMOSFET。スイッチングが速く、電源回路などで広く使われる。
