SiCとGaNのパワー半導体の違い：耐圧・周波数・用途を比較

炭化ケイ素(SiC)と窒化ガリウム(GaN)は、どちらもシリコンよりバンドギャップが広く、電力変換でシリコンを上回ります。高い電界に耐え、速くスイッチングでき、損失も小さいです。使い分けの目安は電圧です。SiCは電気自動車のインバータなど、高電圧・大電力の用途に向きます。GaNは、比較的低い電圧で、スイッチング周波数がとても高い用途に強く、小型の急速充電器などに使われます。

項目SiCGaN
バンドギャップ約3.3 eV(4H-SiC)。シリコンは1.12 eV約3.4 eV
絶縁破壊電界シリコンの約10倍シリコンの約10倍
熱伝導率高い。シリコンの約3倍で、冷却しやすいシリコンと同程度で、SiCより低い
代表的な素子縦型のMOSFETとショットキーバリアダイオード2次元電子ガスをチャネルに使う、横型のHEMT
代表的な耐圧650 Vから3.3 kV程度、さらに高いものも650 V程度までが中心
スイッチング周波数高い(数十〜数百kHz)とても高い(数百kHz〜MHz)
基板とウェハSiCウェハは高価で、結晶成長も難しい多くはシリコンウェハ上に成長させる(GaN-on-Si)。安く、シリコンの工場で作れる。RF用にはGaN-on-SiCも使う
設計上の課題ゲート酸化膜の信頼性と、高めのゲート駆動電圧ノーマリオンを避ける必要があり、ゲートが耐えられる電圧の幅が小さい
主な用途電気自動車の駆動用インバータ、車載充電器、太陽光発電のインバータ、産業用モータ駆動、鉄道小型の急速充電器やアダプタ、データセンターの電源、5G基地局のRF増幅器

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

SiC
電圧も電力も大きく、効率と発熱が重要なとき。車載インバータ、太陽光発電や産業用の電源システムなど。
GaN
電圧が中程度で、高いスイッチング周波数で、小さく軽く効率の高い変換器を作りたいとき。充電器、アダプタ、サーバー電源など。
どちらも
高速にスイッチングするときは、波形の乱れ(リンギング)やノイズに注意が必要です。素子と同じくらい、配線のレイアウトとゲート駆動が重要です。

  1. SiC(炭化ケイ素)がSiに比べて高耐圧パワーデバイスに有利な主な理由はどれか。

  3. 電気自動車のインバータにSiCパワーデバイスを使う主な利点はどれか。
  4. SiCやGaNのパワーデバイスで高速にスイッチングするときに、特に対策が重要になる問題はどれか。
  5. GaNが高周波・高出力のトランジスタに適している理由として正しいものはどれか。
  6. 現在普及しているGaNパワーデバイスの多くが採用している構造はどれか。
