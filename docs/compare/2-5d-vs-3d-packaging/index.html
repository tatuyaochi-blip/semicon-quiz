2.5Dと3D実装の違い：チップの集積方法を比較

どちらも、複数のチップを1つのパッケージに入れて、プリント基板では得られない帯域を実現する方法です。2.5D実装では、チップをシリコンインターポーザの上に並べ、インターポーザが細かいピッチで配線します。3D実装では、チップを縦に積み重ね、シリコン貫通電極(TSV)やハイブリッド接合でつなぎます。3Dは接続が最も短くなりますが、冷却も製造も難しくなります。

項目2.5D3D
構造チップをシリコンインターポーザ(またはシリコンブリッジ)の上に並べるチップを縦に積み重ねる
接続マイクロバンプでインターポーザにつなぎ、中の非常に細かい配線層で結ぶチップを貫くTSVを、マイクロバンプやハイブリッド接合でつなぐ
帯域密度高い最も高い。接続が最も短いため
熱冷やしやすい。各チップを上から冷やせる冷やしにくい。下のチップの熱が、上のチップを通らなければならない
占有面積大きい。インターポーザにすべてのチップを載せる小さい
製造の難しさ大きなインターポーザが必要で、コストが増えるウェハを数十マイクロメートルまで薄くし、TSVを作り、各チップを慎重にテストする必要がある
代表例同じパッケージにHBMを載せたAI向けGPU(TSMCのCoWoSなど)HBMそのもの(積層したDRAMのチップ)、プロセッサに積んだキャッシュ
主な用途プロセッサ、メモリ、チップレットの接続メモリの積層、または最短の経路が欲しいロジックとキャッシュの積層

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

2.5D
大きなプロセッサと、複数のメモリスタックやチップレットを組み合わせつつ、冷却も容易にしたいとき。
3D
接続の長さ、電力、占有面積が最も重要なとき。積層メモリなど。
組み合わせ
高性能なAIアクセラレータは両方を使います。HBMは、DRAMのチップを積み重ねた3Dのスタックで、それを2.5Dのインターポーザの上のプロセッサの隣に置きます。

理解度チェック

  1. 2.5D実装と3D実装の違いとして正しいものはどれか。
  2. 2.5D実装で使われるシリコンインターポーザの役割として正しいものはどれか。
  3. TSV(シリコン貫通電極)の説明として正しいものはどれか。
  4. チップを縦に積み重ねる3D実装で特に課題になりやすいものはどれか。
  5. TSVを形成したチップを積層するため、ウエハを裏面から研削して薄くする厚さの目安として正しいものはどれか。
  6. AI向けのGPUで、GPUチップとHBMを1つのシリコンインターポーザの上に並べて実装する主な理由はどれか。

関連する比較

  • DDR・LPDDR・GDDR・HBMの違い：DRAMの種類を比較DDR、LPDDR、GDDR、HBMを、使われる機器・バス幅・速度・帯域・消費電力・実装・容量・コストの観点で表にして比較します。
  • ASIC・FPGA・SoCの違い：柔軟性・コスト・用途を比較ASIC、FPGA、SoCを、それぞれが何か、柔軟性・性能・初期費用と単価・開発期間・用途の観点で表にして比較します。
  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • NAND型とNOR型フラッシュメモリの違い：速度・容量・用途を比較NAND型とNOR型のフラッシュメモリを、セルの接続・読み出し速度・消去単位・容量・コスト・信頼性・用途の観点で表にして比較します。
  • BJTとMOSFETの違い：制御方式・速度・用途を比較バイポーラトランジスタ(BJT)とMOSFETを、制御方式・入力電流・キャリア・速度・オン状態・温度特性・集積度・用途の観点で表にして比較します。
  • FinFETとGAAトランジスタの違い：構造・制御性・製造を比較FinFETとゲートオールアラウンド(GAA)ナノシートのトランジスタを、ゲート構造・チャネル・静電制御・幅の調整・製造・採用状況の観点で表にして比較します。
