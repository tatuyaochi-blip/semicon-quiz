STIとLOCOSの違い：素子分離のしかた・バーズビーク・微細化・工程・世代を比較

どちらも、隣り合うトランジスタを厚い酸化膜で電気的に分ける素子分離の方法です。LOCOSは、窒化膜で覆っていない部分のシリコンを熱酸化して厚い酸化膜を育てる方法で、工程が簡単ですが、窒化膜の端の下に酸化膜が食い込むバーズビークが生じ、分離の幅を狭くできません。STIは、シリコンに浅い溝を掘って酸化膜を埋め込み、CMPで平らにする方法で、バーズビークがなく表面も平坦なので、0.25 µm前後の世代から微細なLSIの標準になりました。

項目STI(シャロートレンチ分離)LOCOS(選択酸化)
分離のしかたシリコンに浅い溝を掘り、酸化膜を埋め込む窒化膜で覆っていない部分のシリコンを熱酸化して、厚いフィールド酸化膜を育てる
主な工程パッド酸化膜と窒化膜の形成 → リソグラフィ → シリコンのドライエッチング → ライナー酸化 → 酸化膜の埋め込み(HDP-CVDなど) → CMP → 窒化膜の除去パッド酸化膜と窒化膜の形成 → リソグラフィ → 窒化膜のエッチング → 熱酸化(約1,000 ℃のウェット酸化など) → 窒化膜の除去

バーズビークないある。窒化膜の端の下に酸化膜が食い込み、素子の有効な幅が減る
表面の平坦さCMPで平坦になる。リソグラフィの焦点深度の点で有利酸化膜の一部がシリコン面より上に盛り上がり、段差が残る

主な課題溝の埋め込み不良(ボイド)、CMPのディッシング、溝の角の形状(ディボット)、埋め込んだ酸化膜の応力バーズビーク、窒化膜の下にできる窒化物によるゲート酸化膜の不良(クーイ効果)、長い高温の工程

数値は代表的な目安で、世代や製品によって異なります。

どんなときに使うか

STI
微細なロジックやメモリなど、素子を高い密度で並べたいとき。分離の幅を最小加工寸法まで狭くし、平坦な表面で後のリソグラフィを行いたいとき。
LOCOS
寸法に余裕のある古い世代のプロセスで、工程を簡単にし、コストをおさえたいとき。
移り変わり
LOCOSのバーズビークを小さくする改良も行われましたが限界があり、微細化とCMPの実用化に合わせてSTIに置き換わりました。

よくある質問

バーズビークとは何ですか？

LOCOSで熱酸化するとき、酸素が窒化膜の端の下にも横から入り込み、酸化膜が鳥のくちばしのような形で素子の側に食い込む現象です。トランジスタを作れる幅が設計より狭くなるので、微細化の大きな妨げになりました。

STIではなぜCMPが必要なのですか？

溝に酸化膜を埋め込むと、溝の外の窒化膜の上にも酸化膜が厚く積もるからです。CMPでこれを削り取り、窒化膜を研磨の止まる層として使って、溝の中の酸化膜だけを残し、表面を平らにします。

STIの溝はどれくらいの深さですか？

世代によって違いますが、数百 nm程度が代表的です。隣の素子との間でリーク電流が流れたり、寄生的なトランジスタが働いたりしないよう、十分な深さの絶縁膜を置きます。

LOCOSはもう使われていないのですか？

微細なロジックやメモリではSTIに置き換わっていますが、寸法に余裕のある古い世代のプロセスでは、工程が少なく安いことから使われることがあります。

理解度チェック

微細なLSIの素子分離に主に使われている方法はどれか。

  1. Aワイヤボンディング
  2. BLOCOS(選択酸化)
  3. CSTI(シャロートレンチ分離)
答えと解説を見る

正解：C. STI(シャロートレンチ分離)

現在の微細なLSIでは、シリコンに深さ200〜300 nm程度の浅い溝を掘り、CVDの酸化膜を埋め込んでCMPで平坦化するSTIが主に使われます。かつて主流だったLOCOSは、酸化膜が横方向に食い込むバーズビークで分離の幅を小さくできず、表面にも段差が残るため、0.25 µm世代ごろからSTIに置き換えられました。STIは平坦で幅を狭くでき、FinFETのフィンの間の分離にも使われます。

LOCOS(選択酸化)で、窒化膜マスクの端の下に酸化膜が鳥のくちばし状に食い込む現象を何と呼ぶか。

  1. Aディッシング
  2. Bノッチング
  3. Cバーズビーク
答えと解説を見る

正解：C. バーズビーク

LOCOSでは、窒化膜で覆った部分は酸化されませんが、酸化剤が窒化膜の下のパッド酸化膜を通って横から拡散し酸化が進むため、鳥のくちばしのような形に酸化膜が食い込みます(バーズビーク)。食い込みは片側で酸化膜厚の半分程度にも達し、素子の有効な面積が減るため、0.25 µm世代ごろから溝を使うSTIに置き換えられました。パッド酸化膜は窒化膜の応力からシリコンを守るために必要です。

LOCOSなどの素子分離に使われたフィールド酸化膜と、MOSFETのゲート酸化膜の厚さの関係として一般的に正しいものはどれか。

  1. Aゲート酸化膜の方がずっと厚い
  2. B両者は同じ厚さである
  3. Cフィールド酸化膜の方がずっと厚い
答えと解説を見る

正解：C. フィールド酸化膜の方がずっと厚い

フィールド酸化膜は、その上を通る配線とシリコンの間で寄生トランジスタがオンしないように、数百nm程度と厚くつくります。厚いほど寄生トランジスタのしきい値電圧が高くなるためです。一方、ゲート酸化膜はゲートの電界をチャネルに強く伝えるため数nm程度と非常に薄く、100倍以上の差があります。同じチップに、入出力用の厚めのゲート酸化膜を使い分けることもあります。

  1. LOCOSで、窒化膜マスクの下のシリコン表面に薄い窒化物ができ、後のゲート酸化膜が局所的に薄くなったり不良になったりする現象を何と呼ぶか。
  2. STI形成のCMPで、シリコン窒化膜に対する酸化膜の研磨選択比を高くするためによく使われる研磨粒子はどれか。
  3. CMPが使われる工程の組み合わせとして正しいものはどれか。

関連する用語の解説

STI(シャロートレンチ分離)
シリコンに浅い溝を掘って絶縁膜を埋め込み、CMPで平坦化して素子どうしを分離する方法。LOCOSのバーズビークがなく、微細なLSIの素子分離の標準になっている。
LOCOS
窒化膜で覆っていない部分だけを厚く酸化して素子間を分離する方法。端に鳥のくちばし状の食い込み(バーズビーク)ができ、現在はSTIに置き換わった。
バーズビーク
LOCOSで、窒化膜マスクの端の下に酸化膜が鳥のくちばし状に食い込む現象。素子の有効な面積を減らすため、微細化ではSTIに置き換えられた。
CMP
化学機械研磨。スラリーの化学作用とパッドの機械的研磨を組み合わせてウエハ表面を平坦化する。
熱酸化
シリコンを酸素や水蒸気の中で加熱し、表面にSiO2膜をつくる方法。ドライ酸化とウェット酸化がある。
