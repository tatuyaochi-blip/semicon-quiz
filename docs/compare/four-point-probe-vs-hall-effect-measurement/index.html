四探針法とホール効果測定の違い：わかる量・試料の準備・破壊の有無・用途を比較

どちらも半導体の層の電気的な性質を測る方法ですが、わかることが違います。四探針法は、一直線に並べた4本の針をウエハに当て、外側の2本に電流を流して内側の2本で電圧を測り、シート抵抗を求めます。ホール効果測定は、小さく切り出した試料に電極をつけ、抵抗に加えて、磁界をかけたときに生じるホール電圧を測ります。これで、キャリアが電子か正孔か、その濃度と移動度まで分けてわかります。四探針法は速く手軽な工程の監視に、ホール効果測定は材料そのものの評価に使われます。

どんなときに使うか

四探針法
イオン注入やアニール、成膜の結果を、毎日の工程管理として速く確かめたいときに使います。基準のウエハと比べたシート抵抗の変化から、ドーズ量や活性化、金属膜の厚さの異常に気づけます。
ホール効果測定
エピ層や新しい材料について、キャリアの種類と濃度、移動度を分けて知りたいときに使います。抵抗だけでは、キャリアが多いのか、動きやすいのかを区別できないからです。

よくある質問

四探針法では、なぜ接触抵抗の影響を受けないのですか？

電流を流す針と、電圧を測る針を分けているからです。電圧を測る内側の針にはほとんど電流が流れないので、針と試料の間の接触抵抗で電圧が落ちず、層そのものの電圧だけを測れます。

ホール効果測定で移動度がわかるのはなぜですか？

ホール電圧からキャリアの濃度がわかり、抵抗の測定から導電率がわかります。導電率は、電荷×キャリア濃度×移動度で表せるので、2つの結果を組み合わせると移動度が求まります。こうして求めた値はホール移動度と呼ばれ、散乱の仕方によってドリフト移動度と少し異なることがあります。

ファン・デル・パウ法とは何ですか？

厚さが均一で穴のない試料であれば、形にかかわらず、周囲の4つの小さな電極だけで抵抗率とホール係数を測れる方法です。電流を流す電極と電圧を測る電極の組み合わせを入れ替えて測り、平均をとります。

四探針法でドーズ量はわかりますか？

直接はわかりません。シート抵抗は、活性化した不純物の量と移動度で決まるので、同じアニール条件なら、ドーズ量が多いほど下がります。そこで、基準のウエハとの比較や、あらかじめ作った換算の関係から、ドーズ量や活性化の異常を監視します。

理解度チェック

4探針法で主に測定するものはどれか。

  1. Aシート抵抗
  2. B膜の応力
  3. C表面の粗さ
答えと解説を見る

正解：A. シート抵抗

4探針法は、一直線に並べた4本の針を試料に当て、外側の2本に電流を流し、内側の2本で電圧を測る方法です。電圧を測る針にはほとんど電流が流れないため、接触抵抗の影響を受けずにシート抵抗を測定できます。十分広い薄膜では、Rs=(π/ln2)×V/I≒4.53×V/Iで求められます。拡散層や金属膜の評価に使われます。応力はウエハの反り、粗さはAFMなどで測ります。

ホール効果の測定から分かることとして正しいものはどれか。

  1. Aキャリアの種類(電子か正孔か)とキャリア密度
  2. Bバンドギャップの大きさ
  3. C結晶の融点
答えと解説を見る

正解：A. キャリアの種類(電子か正孔か)とキャリア密度

電流を流した試料に垂直に磁界をかけると、ローレンツ力でキャリアが片側に寄り、横方向にホール電圧が生じます。電圧の符号でキャリアが電子か正孔か、大きさ(V_H = IB/qnt)でキャリア密度がわかります。抵抗率と組み合わせると移動度(μ = 1/qnρ)も求まり、ファン・デル・パウ法と組み合わせて薄膜の評価に広く使われます。バンドギャップは光吸収などで、融点は熱分析で調べます。

電子密度n、正孔密度p、電子の移動度μn、正孔の移動度μp、電荷素量qのとき、半導体の導電率σを表す式はどれか。

  1. Aσ = q(nμn − pμp)
  2. Bσ = (nμn + pμp) / q
  3. Cσ = q(nμn + pμp)
答えと解説を見る

正解：C. σ = q(nμn + pμp)

電子と正孔は動く向きが逆ですが電荷の符号も逆なので、電流は同じ向きに流れ、導電率は和の σ = q(nμn + pμp) になります。抵抗率はその逆数です。ドープした半導体では多数キャリアの項だけで十分近似でき、例えばn型なら σ ≈ qnμn です。真性シリコンでは n = p = ni なので σ = q·ni(μn + μp) となり、抵抗率は約2〜3×10⁵ Ω·cm と大きくなります。

関連する用語の解説

四探針法
一直線に並べた4本の針の外側2本に電流を流し、内側2本の電圧を測って、ウエハや薄膜のシート抵抗を求める方法。
移動度
電界をかけたときのキャリアの動きやすさ。シリコンでは電子の移動度が正孔より大きい。
イオン注入
不純物をイオン化し、加速してウエハに打ち込む技術。注入量と深さを精密に制御できる。
ドーズ量
イオン注入で、単位面積あたりに打ち込むイオンの数。cm⁻²の単位で表し、ビーム電流と注入時間で決まる。
アニール
熱処理のこと。イオン注入後の結晶欠陥の回復や不純物の活性化などに用いる。
オーミック接触
電流の向きによらず抵抗が小さく、電流と電圧が比例する金属と半導体の接触。半導体の表面を高濃度にドープして障壁をトンネルで通り抜けやすくしてつくる。
モニターウエハ
装置の状態確認や膜厚・パーティクルの測定などのために、製品とは別に工程に流すウエハ。テストウエハとも呼ぶ。使用後は膜を除いて研磨し直し、再生ウエハとして再利用されることが多い。
