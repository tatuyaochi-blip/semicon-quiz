IGBTとパワーMOSFETの違い：使い分けを比較

どちらも、絶縁されたゲートを持つ、電圧制御のパワースイッチですが、電流の流れ方が違います。パワーMOSFETは、1種類のキャリアで電流を流し、抵抗のように働くので、低〜中程度の電圧で速く効率的です。IGBTは、バイポーラの出力段を加えてキャリアをあふれさせるので、高い電圧と電流でも導通損失が小さいですが、ターンオフは遅くなります。使い分けの目安は、数百ボルトまでの電圧や高い周波数ではMOSFET、高電圧・大電力ではIGBTです。

項目パワーMOSFETIGBT
構造ユニポーラ。多数キャリアだけで、MOSゲートで制御するMOSゲートでバイポーラの出力段を駆動する。電子と正孔の両方が関わる
一般的な耐圧の範囲数Vから約900 V(シリコン)。SiCのMOSFETは数kVまで約600 Vから数kV
オン状態の損失抵抗性(RDS(on))。耐圧が上がると急に大きくなるほぼ一定の飽和電圧(約1.5〜3 V)。高電圧・大電流では損失が小さい
スイッチング速度速い。数十〜数百kHz、それ以上も遅め。通常は数十kHzまで
ターンオフのテール電流なしあり。蓄積した少数キャリアのため、電流が少しの間流れ続ける

どんなときに使うか

パワーMOSFET
スイッチング周波数が高く、電圧がそれほど高くないとき。電源、コンバータ、バッテリー駆動のモーター駆動など。
IGBT
電圧と電流が大きく、周波数は中程度のとき。駆動用のインバータ、産業用のドライブ、重機など。
傾向
SiCのMOSFETが、IGBTの範囲の一部に入り込んでいます。高電圧、高速スイッチング、低損失を両立できるためです。

理解度チェック

  1. IGBTの説明として正しいものはどれか。
  2. シリコンのMOSFETとIGBTの一般的な使い分けとして正しいものはどれか。
  3. IGBTのターンオフ時に、蓄積された少数キャリアのために電流がすぐに0にならず、尾を引くように流れる現象を何と呼ぶか。
  4. バイポーラトランジスタとMOSFETの制御の違いとして正しいものはどれか。
  5. パワーMOSFETを複数並列に接続して使いやすい理由として、オン抵抗の温度依存性に関する説明で正しいものはどれか。
  6. SiC MOSFETやIGBTの駆動で、オフ時にゲートに負の電圧(例えば −3〜−5 V)を加えることがある主な理由はどれか。
