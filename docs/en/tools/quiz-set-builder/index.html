How it works

Tick the topics, choose how many questions you want and press Create link. Questions are drawn evenly across the selected topics. If you enter a set name, it appears as the title on the quiz screen. Share the link through your learning management system, email or chat; opening the same link always gives the same questions.

Grades and privacy

The site uses no accounts and no database. Results are stored only in the browser of the person taking the quiz. If you need to collect scores, ask students to submit a screenshot of the results screen or their score, whichever suits your course.

FAQ

Is the quiz builder free?

Yes. It is free, needs no sign-up, and the links you create do not expire.

Do all students get the same questions?

Yes, everyone who opens the same link gets the same questions. The order of the answer choices is shuffled each time so answers cannot simply be passed around.
