Silicon wafers

Which crystal orientation is commonly used for silicon wafers for CMOS ICs?

  1. A(111)
  2. B(100)
  3. C(211)
Show answer and explanation

Answer: B. (100)

CMOS ICs generally use (100) wafers. The (100) surface has fewer bonds per surface atom, giving an interface-state density at the SiO2 interface about one tenth that of (111), which stabilizes threshold voltage and improves MOS characteristics; electron mobility is also higher on (100). (111) wafers, which oxidize faster, were formerly used for bipolar devices.
