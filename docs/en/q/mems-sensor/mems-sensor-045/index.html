MEMS and sensors

When choosing the measurement range of a MEMS accelerometer (for example, ±2 g versus ±16 g), which reasoning is correct?

  1. AA wider range can measure larger shocks, but with the same number of bits the resolution becomes coarser
  2. BA wider range always gives finer resolution
  3. CThe range determines only the sensor's power consumption
Show answer and explanation

Answer: A. A wider range can measure larger shocks, but with the same number of bits the resolution becomes coarser

With the same output bit count, a wider range means more acceleration per LSB, making small changes harder to distinguish. A narrow range with high resolution suits step counting and tilt detection, while a wide range suits collision and drop detection, so the range is chosen for the application. Many sensors allow the range to be switched.

  • A. Correct. Range and resolution trade off.
  • B. A wider range makes resolution coarser at the same bit count.
  • C. The range relates to resolution and the maximum measurable acceleration.
