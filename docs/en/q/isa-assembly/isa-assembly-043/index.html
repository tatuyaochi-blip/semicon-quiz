ISA & Assembly

How do today's high-performance x86 CPUs execute complex instructions internally?

  1. AThey execute every instruction one at a time in a software emulator
  2. BThey decode instructions into simple, RISC-like micro-operations and execute those in a pipeline
  3. CThey cannot run complex instructions, so the OS stops them with an error
Show answer and explanation

Answer: B. They decode instructions into simple, RISC-like micro-operations and execute those in a pipeline

x86 CPUs break variable-length, complex instructions into simple operations called micro-operations (μops) in the front-end decoder, and the back end executes them out of order. Some CPUs keep a μop cache so decoded μops can be reused without decoding again. This lets them keep compatibility with old software while using the same fast execution techniques as RISC designs.

  • A. They are not emulated in software.
  • B. Correct. CISC outside, close to RISC inside.
  • C. Complex instructions do run.
