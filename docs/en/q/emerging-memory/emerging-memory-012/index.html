Emerging memories

Which material is widely used as the tunnel barrier in MRAM magnetic tunnel junctions (MTJs) and gives a large tunnel magnetoresistance ratio?

  1. AMagnesium oxide (MgO)
  2. BCopper
  3. CPolycrystalline silicon
Show answer and explanation

Answer: A. Magnesium oxide (MgO)

Using crystalline MgO as the tunnel barrier lets only electrons with a particular symmetry tunnel selectively, giving TMR ratios of several hundred percent at room temperature (versus tens of percent for amorphous Al2O3). Reported independently by Japan's AIST and IBM in 2004, this widened the 0/1 resistance gap, enabling higher-capacity HDD read heads and practical MRAM.
