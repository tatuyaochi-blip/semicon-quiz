Emerging memories

Which external environmental factor requires care when using MRAM?

  1. AStrong light
  2. BStrong external magnetic fields
  3. CLow humidity
Show answer and explanation

Answer: B. Strong external magnetic fields

Because MRAM stores information as magnetization direction, exposure to a strong external magnetic field may disturb the storage layer's magnetization and lose data. For some applications, packages with magnetic shielding are used.

  • A. MRAM does not store information with light.
  • B. Correct. Strong magnetic fields may disturb the data.
  • C. Humidity is not directly related to MRAM's storage principle.
