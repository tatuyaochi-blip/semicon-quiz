Emerging memories

Which external environmental factor requires care when using MRAM?

  1. AStrong light
  2. BStrong external magnetic fields
  3. CLow humidity
Show answer and explanation

Answer: B. Strong external magnetic fields

Because MRAM stores data as magnetization, strong external fields can disturb the free layer and corrupt data; fields above roughly tens of mT are a concern, such as from magnets near phones, motors or MRI scanners. Some applications use magnetically shielded packages, and designs must respect the datasheet's magnetic immunity rating.

  • A. MRAM does not store information with light.
  • B. Correct. Strong magnetic fields may disturb the data.
  • C. Humidity is not directly related to MRAM's storage principle.
