What is the difference between "bipolar" and "unipolar" operation of ReRAM?

  1. ABipolar uses bipolar transistors and unipolar uses MOSFETs
  2. BBipolar stores 2 bits and unipolar stores 1 bit
  3. CBipolar switches set and reset by reversing the voltage polarity, while unipolar switches with the same polarity by changing the magnitude of voltage or current
Show answer and explanation

Answer: C. Bipolar switches set and reset by reversing the voltage polarity, while unipolar switches with the same polarity by changing the magnitude of voltage or current

Bipolar ReRAM applies voltages of opposite polarity for set (to low resistance) and reset (to high resistance). Unipolar ReRAM keeps the same polarity and switches by changing the magnitude or duration of the voltage or current. Which mode a device shows depends on its materials and electrode combination.

  • A. The terms do not refer to transistor types.
  • B. It is not a difference in the number of bits stored.
  • C. Correct. The difference is whether voltage polarity is used to switch.
