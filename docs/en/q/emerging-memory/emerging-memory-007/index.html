Emerging memories

Compared with flash memory, which is a general advantage of MRAM?

  1. AIts cost per bit is far lower
  2. BIt loses data when the power is turned off
  3. CIt can be rewritten far more times, and writes are fast
Show answer and explanation

Answer: C. It can be rewritten far more times, and writes are fast

MRAM stores information in magnetization direction, so it can be rewritten far more times than flash memory, which involves oxide degradation, and writes faster. It is being adopted as embedded memory in microcontrollers and similar devices. However, it falls short of NAND flash in capacity and cost per bit.
