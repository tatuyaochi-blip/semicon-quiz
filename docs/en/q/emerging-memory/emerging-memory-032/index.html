What does the "M" in MRAM stand for?

  1. AMicro
  2. BMagnetoresistive
  3. CMulti-level
Show answer and explanation

Answer: B. Magnetoresistive

MRAM stands for magnetoresistive random access memory; it reads information using the magnetoresistive effect, in which resistance changes with magnetization direction.

  • A. It does not refer to size.
  • B. Correct. It is memory that uses the magnetoresistive effect.
  • C. It does not stand for multi-level storage.
