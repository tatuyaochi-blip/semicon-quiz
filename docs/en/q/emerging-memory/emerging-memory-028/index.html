Emerging memories

What design challenge arises from the probabilistic nature of writing in STT-MRAM?

  1. AWriting requires light
  2. BMargins in write current and pulse width, or combination with error correction, are needed
  3. CWrites always fail
Show answer and explanation

Answer: B. Margins in write current and pulse width, or combination with error correction, are needed

STT-MRAM switching is stochastic because of thermal fluctuations, so even with identical current and pulse width a write occasionally fails (the write error rate). More current reduces failures but pushes the MgO barrier toward breakdown, shortening life. Reliability is secured with margins in current and pulse width, verify-and-rewrite schemes, and ECC.
