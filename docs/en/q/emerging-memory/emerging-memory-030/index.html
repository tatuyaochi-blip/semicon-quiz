Emerging memories

In general, which memory has the fewest possible rewrite cycles?

  1. ADRAM
  2. BSRAM
  3. CNAND flash memory
Show answer and explanation

Answer: C. NAND flash memory

DRAM and SRAM hardly degrade from rewriting and can be rewritten practically without limit. NAND flash is limited to thousands to tens of thousands of rewrites (fewer for more bits per cell) because of tunnel oxide degradation. MRAM is said to withstand a very large number of rewrites.
