Emerging memories

In general, which memory has the fewest possible rewrite cycles?

  1. ADRAM
  2. BSRAM
  3. CNAND flash memory
Show answer and explanation

Answer: C. NAND flash memory

DRAM and SRAM barely wear with writes and are effectively unlimited. NAND flash degrades each time electrons cross the tunnel oxide at high field, limiting it to thousands to tens of thousands of cycles (fewer for multilevel). Emerging memories fall in between: PCM and ReRAM at about 10⁶–10⁹ cycles, FeRAM at 10¹² or more and MRAM at over 10¹⁰ (nearly unlimited)—a key criterion in choosing among them.
