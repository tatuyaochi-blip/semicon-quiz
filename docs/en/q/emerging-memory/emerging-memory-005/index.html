Emerging memories

How is information written in STT-MRAM?

  1. AOnly with a magnetic field generated by an external coil
  2. BBy irradiating it with ultraviolet light
  3. CBy reversing the magnetization with spin-transfer torque from a spin-polarized current
Show answer and explanation

Answer: C. By reversing the magnetization with spin-transfer torque from a spin-polarized current

In STT-MRAM, current flows through the MTJ, and electrons spin-polarized by the reference layer transfer angular momentum to the free layer (spin-transfer torque), flipping its magnetization; the current direction determines 0 or 1. Early field-written MRAM needed more current as cells shrank, but STT write current scales down with cell area, so it suits scaling and is now mainstream.
