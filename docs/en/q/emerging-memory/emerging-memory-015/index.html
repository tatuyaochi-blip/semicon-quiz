Emerging memories

Which is one reason MRAM is attracting attention as embedded non-volatile memory for microcontrollers and similar chips?

  1. AIn advanced logic processes embedded flash has become hard to manufacture, and MRAM, which can be built in the interconnect process, is a candidate replacement
  2. BIt has larger capacity and lower cost than DRAM
  3. CIt loses data when the power is turned off
Show answer and explanation

Answer: A. In advanced logic processes embedded flash has become hard to manufacture, and MRAM, which can be built in the interconnect process, is a candidate replacement

Embedding flash memory in logic LSIs requires many dedicated process steps and has become difficult in advanced processes. MRAM can be built into the interconnect process by forming MTJs between wiring layers, making it easy to integrate with logic, so it is being adopted as a replacement for embedded flash.
