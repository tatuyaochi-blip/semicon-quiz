Emerging memories

Which correctly describes the position of 'storage-class memory'?

  1. AA non-volatile memory that bridges the gap in speed, capacity and cost between DRAM and NAND flash
  2. BRegisters inside a CPU
  3. CA type of optical disc
Show answer and explanation

Answer: A. A non-volatile memory that bridges the gap in speed, capacity and cost between DRAM and NAND flash

DRAM and NAND differ by about 1000× in access time (tens of ns versus tens of µs) and about 10× in cost per bit. Storage-class memory (SCM) fills that gap: non-volatile, cheaper and denser than DRAM, and orders of magnitude faster than NAND. Intel's phase-change-based Optane was the flagship until its discontinuation was announced in 2022; today low-latency SLC NAND and CXL-attached memory occupy much of this space.
