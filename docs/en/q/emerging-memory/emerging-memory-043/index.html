Emerging memories

Which storage-class memory technology, jointly developed by Intel and Micron, was sold under the product name "Optane"?

  1. A3D NAND
  2. B3D XPoint
  3. CHBM
Show answer and explanation

Answer: B. 3D XPoint

3D XPoint is a memory technology that stacks resistive storage elements and selectors at the intersections of crossing wires. It was commercialized as Optane, a storage-class memory filling the gap between DRAM and NAND flash. The market did not grow as hoped, and the end of the products was announced in 2022.

  • A. 3D NAND is flash memory with cells stacked vertically.
  • B. Correct. Optane was a product based on 3D XPoint technology.
  • C. HBM is high-bandwidth memory made of stacked DRAM.
