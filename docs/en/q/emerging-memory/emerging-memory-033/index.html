Emerging memories

Which correctly describes the idea of "universal memory" that many emerging memory efforts have aimed for?

  1. AA memory card that fits any device
  2. BMemory that always uses magnetism
  3. CA single memory combining DRAM-like speed and endurance with flash-like non-volatility and high capacity
Show answer and explanation

Answer: C. A single memory combining DRAM-like speed and endurance with flash-like non-volatility and high capacity

Universal memory is the idea of achieving in one memory the strengths of DRAM and SRAM (speed and nearly unlimited rewrites) and those of flash (retaining data without power). In practice, each emerging memory has strengths and weaknesses and is chosen according to the application.

  • A. It is not about memory card standards.
  • B. The storage principle is not limited to magnetism.
  • C. Correct. It aims to combine speed, non-volatility and other strengths in one memory.
