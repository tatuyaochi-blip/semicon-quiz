Emerging memories

Which device uses the fact that the tunneling current through a thin ferroelectric layer depends on the direction of its polarization?

  1. AFTJ (ferroelectric tunnel junction)
  2. BMTJ (magnetic tunnel junction)
  3. CMIM capacitor
Show answer and explanation

Answer: A. FTJ (ferroelectric tunnel junction)

An FTJ (ferroelectric tunnel junction) sandwiches a ferroelectric layer only a few nm thick between electrodes; the polarization direction changes the barrier's height and shape and hence the tunneling resistance. Unlike capacitor-type FeRAM, it reads non-destructively as a resistance without flipping the polarization, with low current and power. HfO2-based ferroelectrics have accelerated research, and FTJs are also promising as analog compute elements for AI.

  • A. Correct. Its tunneling resistance changes with ferroelectric polarization.
  • B. An MTJ's tunneling resistance changes with magnetization direction.
  • C. A MIM capacitor is a metal-insulator-metal capacitor and does not use resistance change.
