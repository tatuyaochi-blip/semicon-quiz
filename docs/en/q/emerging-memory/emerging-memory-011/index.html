Emerging memories

Which correctly describes reading in capacitor-type FeRAM?

  1. AIt is a non-destructive read that does not change the data
  2. BReading requires ultraviolet light
  3. CData is read according to whether the polarization switches, so the read is destructive and data must be rewritten afterward
Show answer and explanation

Answer: C. Data is read according to whether the polarization switches, so the read is destructive and data must be rewritten afterward

In capacitor-type FeRAM, a voltage is applied and the stored content is determined by whether the polarization switches. If it switches, the original data is lost, so it is rewritten after the read. Like DRAM, the read is destructive, but the data is retained in a non-volatile way.
