Emerging memories

In phase-change memory (PCM), how can multiple bits be stored in one cell (multi-level storage)?

  1. ABy changing the color of the cell
  2. BBy using multiple magnetization directions in the cell
  3. CBy controlling, for example, the size of the amorphous region in the cell to create intermediate resistance values
Show answer and explanation

Answer: C. By controlling, for example, the size of the amorphous region in the cell to create intermediate resistance values

In PCM, controlling the proportion of amorphous and crystalline regions in a cell produces intermediate resistances between high and low. Distinguishing several resistance levels allows multiple bits per cell. However, effects such as resistance drift make stable discrimination between levels a challenge.

  • A. PCM stores data as electrical resistance, not color.
  • B. Storing data as magnetization direction is MRAM.
  • C. Correct. Intermediate resistance values are created.
