Emerging memories

In phase-change memory (PCM), how is a cell put into the high-resistance amorphous state (reset)?

  1. ABy applying a magnetic field to reverse the magnetization
  2. BBy heating it above the melting point with a large current pulse and then quenching it
  3. CBy holding it near the crystallization temperature for a long time
Show answer and explanation

Answer: B. By heating it above the melting point with a large current pulse and then quenching it

Reset melts the material above its melting point (about 600 °C for GST) with a large current pulse of around tens of ns, then quenches it within nanoseconds so atoms have no time to order, leaving it amorphous. Set holds the material between its crystallization temperature and melting point long enough to crystallize. The large reset current is PCM's power challenge, reduced by structures that shrink the heated volume.
