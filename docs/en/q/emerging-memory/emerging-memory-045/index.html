Emerging memories

Which memory changes resistance by having metal ions such as silver or copper move through a solid electrolyte to form or break a conductive path?

  1. ACBRAM (conductive-bridge memory)
  2. BFeRAM
  3. CSTT-MRAM
Show answer and explanation

Answer: A. CBRAM (conductive-bridge memory)

In CBRAM, metal ions dissolve from an active metal electrode such as silver or copper into an electrolyte layer, and a voltage forms or breaks a metal conductive bridge (filament), switching between low and high resistance. It is sometimes classified as a type of resistive memory (ReRAM).

  • A. Correct. It uses a conductive bridge formed by metal ions.
  • B. FeRAM stores data as ferroelectric polarization.
  • C. STT-MRAM stores data as magnetization direction.
