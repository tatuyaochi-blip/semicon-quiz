Emerging memories

Which phenomenon becomes a problem when phase-change memory is scaled, in which heat from writing reaches a neighboring cell and changes its state?

  1. ARow hammer
  2. BElectrostatic discharge
  3. CThermal disturb (thermal crosstalk)
Show answer and explanation

Answer: C. Thermal disturb (thermal crosstalk)

Writing PCM heats the material to several hundred degrees Celsius or more. As the spacing between cells narrows, that heat can reach a neighboring cell and unintentionally crystallize it from the amorphous state. Thermal insulation structures and smaller heated regions are used to counter this.
