Emerging memories

Which of the following is non-volatile memory that retains data after power is removed?

  1. ADRAM
  2. BSRAM
  3. CMRAM
Show answer and explanation

Answer: C. MRAM

MRAM stores information as the magnetization direction of a magnetic material, so it is non-volatile and retains data after power-off. DRAM and SRAM are both volatile and lose data when power is removed.

  • A. DRAM is volatile and loses data at power-off.
  • B. SRAM is also volatile and loses data at power-off.
  • C. Correct. MRAM is non-volatile, storing data as magnetization direction.
