Emerging memories

Which is a typical application in which FeRAM has been used?

  1. AHigh-capacity SSDs
  2. BPC main memory
  3. CIC cards and similar devices that take advantage of fast, low-power writes
Show answer and explanation

Answer: C. IC cards and similar devices that take advantage of fast, low-power writes

FeRAM writes quickly, needs little power to write, and can be rewritten many times. It has therefore been used in contactless transit IC cards that run on the small amount of power they receive wirelessly, and in measuring instruments that record data frequently. Because high capacity is difficult, it is not suited to SSDs or main memory.
