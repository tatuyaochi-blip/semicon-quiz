Emerging memories

What is the main application expected for in-memory computing using resistive memories and similar devices?

  1. AAs light-emitting elements for displays
  2. BAs battery electrodes
  3. CPerforming multiply-accumulate operations inside the memory array to reduce data movement and power in AI processing
Show answer and explanation

Answer: C. Performing multiply-accumulate operations inside the memory array to reduce data movement and power in AI processing

AI workloads need enormous numbers of multiply-accumulate operations, and moving data between memory and compute dominates power. Storing weights as conductances in a resistive array and applying inputs as voltages performs multiplication by Ohm's law (I = GV) and summation by Kirchhoff's current law, all at once on the wires. Because it is analog computation, device variability and ADC precision are the challenges.
