PN junctions and diodes

When a sinusoidal AC signal is applied to a half-wave rectifier made of one diode and a resistor, what is the output?

  1. AThe AC signal passes through unchanged
  2. BThe negative half-cycles are also flipped and output as positive
  3. COnly one half-cycle, either positive or negative, is output
Show answer and explanation

Answer: C. Only one half-cycle, either positive or negative, is output

In a half-wave rectifier, current flows only during the half-cycle when the diode is forward-biased; the other half is blocked, so only one half-cycle appears at the output. The output peak is lower than the input peak by the diode drop (about 0.7 V). It needs just one diode, but it uses only half the input and its ripple has the same frequency as the input, making it hard to smooth, so power supplies mainly use full-wave rectification.

  • A. The diode blocks reverse current, so the AC does not pass unchanged.
  • B. Flipping the negative half-cycles is what a full-wave rectifier does.
  • C. Correct. Only one half-cycle is output.
