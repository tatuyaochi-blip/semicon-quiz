Reliability

What is the reliability of a system with two parts of reliability 0.9 connected in parallel, which functions if either one works?

  1. A0.81
  2. B0.9
  3. C0.99
Show answer and explanation

Answer: C. 0.99

A parallel system fails only when both parts fail, with probability (1 − 0.9) × (1 − 0.9) = 0.01, so its reliability is 1 − 0.01 = 0.99. 0.81 is the series value and 0.9 that of a single part. Redundancy is effective because failure probabilities multiply, but it helps less when a common cause, such as a power failure, takes out both at once.
