Reliability

Which degradation phenomenon causes the absolute value of a pMOS transistor's threshold voltage to gradually increase under sustained negative gate voltage and high temperature?

  1. ANBTI
  2. BElectromigration
  3. CESD
Show answer and explanation

Answer: A. NBTI

NBTI (Negative Bias Temperature Instability) is degradation in which negative gate bias and high temperature applied to a pMOS increase interface states and charge in the dielectric, raising the absolute value of the threshold voltage. Because circuits gradually slow down, margin for this degradation is built in at design time.
