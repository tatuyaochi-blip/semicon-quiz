Reliability

Which correctly describes MTBF (mean time between failures)?

  1. AThe average time from a failure until repair is completed
  2. BThe shortest time until the first failure occurs
  3. CFor a repairable system, the average operating time from one failure to the next
Show answer and explanation

Answer: C. For a repairable system, the average operating time from one failure to the next

MTBF (Mean Time Between Failures) is the average operating time between failures of a system used with repairs. The larger it is, the more reliable the system. The average time from failure to completed repair is called MTTR, and the average time to failure for non-repaired items such as components is called MTTF.
