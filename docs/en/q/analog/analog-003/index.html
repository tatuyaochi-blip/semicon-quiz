Which is closest to the cutoff frequency of an RC low-pass filter with R = 1 kΩ and C = 1 µF?

  1. AAbout 16 Hz
  2. BAbout 160 Hz
  3. CAbout 1.6 kHz
Show answer and explanation

Answer: B. About 160 Hz

The cutoff frequency of an RC filter is fc = 1 / (2πRC). RC = 1×10³ × 1×10⁻⁶ = 1×10⁻³ s, so fc = 1 / (2π × 10⁻³) ≈ 159 Hz, or about 160 Hz.
