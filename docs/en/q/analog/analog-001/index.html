Analog and electronic circuits

Which combination correctly describes an ideal op-amp?

  1. AInput impedance: infinite; output impedance: 0
  2. BInput impedance: 0; output impedance: infinite
  3. CInput impedance: 0; output impedance: 0
Show answer and explanation

Answer: A. Input impedance: infinite; output impedance: 0

An ideal op-amp is treated as having infinite input impedance (no current flows into its inputs), zero output impedance (the output voltage does not depend on the load) and infinite open-loop gain. From these assumptions, a negative-feedback circuit has a 'virtual short' in which the two input voltages are equal.
