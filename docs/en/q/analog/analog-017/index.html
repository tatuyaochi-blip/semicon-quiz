Analog and electronic circuits

Which correctly describes the input offset voltage of an op-amp?

  1. AThe small voltage that must be applied between the inputs to correct for the output not being 0 when the inputs are equal
  2. BThe maximum voltage that can be applied to the input
  3. CThe supply voltage of the op-amp
Show answer and explanation

Answer: A. The small voltage that must be applied between the inputs to correct for the output not being 0 when the inputs are equal

Tiny mismatches in a real op-amp's input transistors mean the output is not zero even with both inputs at the same voltage. Referred to the input, this is the input offset voltage: a few mV in general-purpose parts and tens of µV or less in precision parts. It appears at the output multiplied by (1 + Rf/Ri) and drifts with temperature. For high-gain DC work with tiny signals such as thermocouples, low-offset or chopper-stabilized op-amps are used.
