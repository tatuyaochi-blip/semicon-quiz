Analog and electronic circuits

In an inverting amplifier using a bipolar-input op-amp, why is a resistor equal to the parallel value of the input and feedback resistors placed between the non-inverting input and ground?

  1. ATo double the gain
  2. BTo cancel the output offset error caused by input bias currents
  3. CTo cause oscillation
Show answer and explanation

Answer: B. To cancel the output offset error caused by input bias currents

Input bias current flows into an op-amp's inputs, and the resistance seen from the inverting input (Ri∥Rf) turns it into a voltage drop that appears as output error. Adding an equal resistance at the non-inverting input creates a matching drop that cancels it, leaving only the error from the difference between the two bias currents (the input offset current). Op-amps with CMOS or JFET inputs, whose bias currents are in the pA range, usually do not need this resistor.

  • A. This resistor does not change the gain.
  • B. Correct. It equalizes the bias-current voltage drops at both inputs so they cancel.
  • C. It is not meant to cause oscillation.
