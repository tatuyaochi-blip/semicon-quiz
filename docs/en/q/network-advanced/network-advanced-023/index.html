Which DNS resource record specifies the mail server that receives email addressed to a domain?

  1. ACNAME
  2. BNS
  3. CMX
Show answer and explanation

Answer: C. MX

An MX record gives the server that mail for a domain is delivered to, as in "mail for example.com is received by mail.example.com." Several servers can be registered with preference values, and delivery is tried starting with the server with the lowest value. A CNAME record defines an alias, used for example to make www.example.com an alias of web.example.net. NS gives the domain's authoritative DNS servers, and A and AAAA give IPv4 and IPv6 addresses, respectively.

  • A. A CNAME record registers one name as an alias of another name.
  • B. An NS record gives the authoritative DNS servers that hold the domain's information.
  • C. Correct. An MX record gives the server that mail is delivered to.
