Network Design and Operations

From a PC, ping with an IP address reaches a server on the internet, but when a domain name is entered in the browser it shows "server not found" and the web page does not open. Which setting is the most appropriate to check first?

  1. AThe DNS server address configured on the PC
  2. BThe default gateway address configured on the PC
  3. CThe LAN cable connection and the link status
Show answer and explanation

Answer: A. The DNS server address configured on the PC

When isolating a problem, you check how far things are working, starting from the lower layers. Since ping with an IP address reaches an outside server, everything from the physical layer, such as the cable, up to IP communication through the default gateway (the network layer) is working. Because only access by name fails, a problem with DNS, which translates domain names into IP addresses, is suspected. Check with a command such as nslookup that the DNS server address configured on the PC is correct and that the server responds.

  • A. Correct. IP communication works and only access by name fails, so name resolution is suspected.
  • B. If the default gateway were wrong, ping to a server on the internet would not get through either.
  • C. If there were a problem with the cable or link, ping would not get through at all.
