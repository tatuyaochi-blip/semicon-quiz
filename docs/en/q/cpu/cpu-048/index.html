CPUs and architecture

What is the main purpose of register renaming in out-of-order CPUs?

  1. ATo reduce the number of registers and make the circuit smaller
  2. BTo reassign physical registers without changing the register names used by the program, removing false dependences (WAR and WAW)
  3. CTo encrypt register values
Show answer and explanation

Answer: B. To reassign physical registers without changing the register names used by the program, removing false dependences (WAR and WAW)

ISAs have only about 16–32 architectural registers, so names are reused and create false dependences unrelated to actual data flow—write-after-read (WAR) and write-after-write (WAW). Register renaming dynamically maps them onto hundreds of physical registers, assigning a fresh one on each write to remove these false dependences and expose more parallelism. True dependences (read-after-write, RAW) cannot be removed.

  • A. In fact, more physical registers are provided than the instruction set defines.
  • B. Correct. It removes false dependences.
  • C. It has nothing to do with encryption.
