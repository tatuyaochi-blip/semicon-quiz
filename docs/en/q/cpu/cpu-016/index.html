CPUs and architecture

In a typical computer, which lists the memory hierarchy from fastest to slowest access?

  1. ASSD → main memory → L2 cache → L1 cache → registers
  2. BMain memory → registers → SSD → L1 cache
  3. CRegisters → L1 cache → L2 cache → main memory (DRAM) → SSD
Show answer and explanation

Answer: C. Registers → L1 cache → L2 cache → main memory (DRAM) → SSD

Memory closer to the CPU is faster and smaller; memory farther away is slower, larger and cheaper. A hierarchy of registers, L1/L2/L3 caches (SRAM), main memory (DRAM) and storage (SSD, etc.) keeps frequently used data in the faster levels, achieving memory that is fast and large overall.
