CPUs and architecture

What does CPU stand for?

  1. ACentral processing unit
  2. BMain memory unit
  3. CAuxiliary storage unit
Show answer and explanation

Answer: A. Central processing unit

CPU stands for central processing unit—the heart of a computer that fetches and interprets instructions and performs arithmetic and control. The Intel 4004 of 1971 was the first commercial single-chip microprocessor, with about 2,300 transistors; today's CPUs integrate tens of billions. Main memory refers to RAM, and auxiliary storage to SSDs and HDDs.

  • A. Correct. CPU is the central processing unit.
  • B. Main memory refers to DRAM and similar memory.
  • C. Auxiliary storage refers to SSDs, HDDs and similar.
