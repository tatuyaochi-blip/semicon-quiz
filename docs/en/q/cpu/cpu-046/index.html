Which correctly lists the "three Cs" classification of cache misses?

  1. AWrite, read and branch misses
  2. BClock, voltage and temperature misses
  3. CCompulsory, capacity and conflict misses
Show answer and explanation

Answer: C. Compulsory, capacity and conflict misses

Cache misses are classified as compulsory (first access), capacity (evicted because the cache is too small) and conflict (competition for the same set). Remedies differ by cause: larger lines or prefetching for compulsory misses, a bigger cache for capacity misses, and higher associativity for conflict misses.

  • A. It is not a classification by type of access.
  • B. It is not a classification by operating conditions.
  • C. Correct. Compulsory, capacity and conflict.
