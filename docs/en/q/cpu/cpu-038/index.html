CPUs and architecture

Which correctly describes a set-associative cache?

  1. AData for a given address can be placed in only one location in the cache
  2. BData can be placed anywhere in the cache
  3. CData for a given address can be placed in any of several locations (ways) within a fixed set
Show answer and explanation

Answer: C. Data for a given address can be placed in any of several locations (ways) within a fixed set

In a set-associative cache, the address selects a set, and the data can be placed in any of several ways within that set. This reduces misses caused by competition for the same location (conflict misses) compared with a direct-mapped cache, which has only one possible location. Being able to place data anywhere is a fully associative cache.

  • A. Only one possible location is a direct-mapped cache.
  • B. Being able to place data anywhere is a fully associative cache.
  • C. Correct. It can be placed in several ways within a fixed set.
