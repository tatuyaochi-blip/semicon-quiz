CPUs and architecture

What does "64-bit" in "64-bit CPU" mainly refer to?

  1. AThe number of CPU cores
  2. BThe capacity of the cache memory
  3. CThe width of integer data handled at once, such as general-purpose registers and addresses
Show answer and explanation

Answer: C. The width of integer data handled at once, such as general-purpose registers and addresses

A 64-bit CPU has 64-bit general-purpose registers and addresses, handling 64-bit integers at once. A 32-bit CPU's address space is limited to 2³² = 4 GB, while 64 bits allow a theoretical 16 EB (exabytes)—vastly more memory (implementations use about 48–57 bits). x86-64 spread in PCs during the 2000s, and 64-bit ARM in smartphones from around 2013.

  • A. The number of cores is a separate metric from bit width.
  • B. Cache capacity is not expressed by bit width.
  • C. Correct. It is the width of data and addresses handled at once.
