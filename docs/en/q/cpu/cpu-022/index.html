CPUs and architecture

Which CPU mechanism temporarily suspends the current task to give priority to handling requests such as those from external devices?

  1. AInterrupt
  2. BPipeline
  3. CCache
Show answer and explanation

Answer: A. Interrupt

When an event such as keyboard input, a timer or received data occurs, an interrupt makes the CPU suspend its current task, run the corresponding handler, and then return to the original task. The CPU no longer needs to keep checking the status of peripherals.
