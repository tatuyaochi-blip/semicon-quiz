CPUs and architecture

Which CPU configuration combines high-performance cores and power-efficient cores and uses them according to the workload?

  1. ASingle-core configuration
  2. BConfiguration with only identical cores
  3. CHeterogeneous configuration combining cores of different performance (such as big.LITTLE)
Show answer and explanation

Answer: C. Heterogeneous configuration combining cores of different performance (such as big.LITTLE)

Heavy tasks run fast on high-performance cores, while light and background tasks run on small, efficient cores, balancing performance and battery life. Popularized in smartphones as ARM's big.LITTLE, the approach is now used in PCs, such as Intel's P-cores and E-cores. Assigning tasks to the right cores requires cooperation between the OS scheduler and hardware.
