Which correctly describes little-endian byte order?

  1. AData is compressed before being stored
  2. BMulti-byte data is stored starting with the least significant byte at the lowest address
  3. CMulti-byte data is stored starting with the most significant byte at the lowest address
Show answer and explanation

Answer: B. Multi-byte data is stored starting with the least significant byte at the lowest address

In little-endian order, the 4-byte value 0x12345678 is stored as 78, 56, 34, 12 from the lowest address upward. It is used by x86 and ARM (in its usual configuration), among others. Storing the most significant byte first is big-endian, used in network protocols and elsewhere.

  • A. Endianness concerns storage order, not compression.
  • B. Correct. The least significant byte goes at the lowest address.
  • C. Storing the most significant byte first is big-endian.
