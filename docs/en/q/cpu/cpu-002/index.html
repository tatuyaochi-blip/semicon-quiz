CPUs and architecture

What is the main purpose of cache memory?

  1. ATo retain data when the power is turned off
  2. BTo keep frequently used data close to the CPU and bridge the speed gap with main memory
  3. CTo correct errors in computation results
Show answer and explanation

Answer: B. To keep frequently used data close to the CPU and bridge the speed gap with main memory

Accessing main memory (DRAM) is slow compared with the CPU's processing speed, so frequently used data and instructions are kept in fast caches (mainly SRAM) to reduce waiting time. Caches exploit the tendency of programs to reuse data from nearby times and addresses (locality).
