CPUs and architecture

Which is a characteristic of a von Neumann computer?

  1. AInstructions and data are always kept in separate memories
  2. BPrograms are changed by rewiring
  3. CPrograms (instructions) and data are stored in the same main memory, and instructions are read and executed in order
Show answer and explanation

Answer: C. Programs (instructions) and data are stored in the same main memory, and instructions are read and executed in order

In the von Neumann (stored-program) architecture, instructions and data are kept in the same main memory, and the CPU reads and executes instructions in sequence. An architecture with separate memories and paths for instructions and data is the Harvard architecture, used in microcontrollers and DSPs, and also in the cache organization inside CPUs.
