CPUs and architecture

Which correctly describes a CPU with a clock frequency of 3 GHz?

  1. AIt receives 3,000 clock cycles per second
  2. BIt receives 3 billion clock cycles per second
  3. CIt executes 3 instructions per second
Show answer and explanation

Answer: B. It receives 3 billion clock cycles per second

1 GHz is 10⁹ Hz, so 3 GHz means 3 billion clock cycles per second, a period of about 0.33 ns. Because instructions per clock (IPC) vary greatly between designs, frequency alone cannot compare performance. Also, most CPUs constantly vary their frequency with load and temperature, and the advertised figure is usually the base or maximum boost frequency.

  • A. 3,000 cycles per second corresponds to 3 kHz.
  • B. Correct. 3 GHz = 3 billion cycles per second.
  • C. Clock frequency is not the number of instructions.
