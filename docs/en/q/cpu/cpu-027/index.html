CPUs and architecture

Which is an example of vulnerabilities revealing attacks that exploit traces of speculative execution left in the cache to infer data that should not be accessible?

  1. ARow hammer
  2. BSpectre and Meltdown
  3. CLatch-up
Show answer and explanation

Answer: B. Spectre and Meltdown

Spectre and Meltdown, disclosed in 2018, exploit the fact that although speculatively executed results are discarded, data they loaded remains in the cache; timing differences (a side channel) then reveal secrets that should be inaccessible. Nearly all high-performance CPUs were affected, prompting OS patches and processor design changes. They showed how performance features can become security weaknesses.
