CPUs and architecture

What is the typical size of a cache line (cache block) in many current CPUs?

  1. A1 byte
  2. B64 bytes
  3. C64 MB
Show answer and explanation

Answer: B. 64 bytes

Many CPUs transfer data between cache and main memory in lines of about 64 bytes. Because data at nearby addresses is often used soon after (spatial locality), fetching it together is efficient.

  • A. Transferring one byte at a time would be inefficient.
  • B. Correct. 64 bytes is typical.
  • C. 64 MB is on the order of an entire cache's capacity, not a line size.
