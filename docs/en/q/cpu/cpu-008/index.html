CPUs and architecture

What is the main reason GPUs are well suited to matrix operations and AI training and inference?

  1. ATheir clock frequency is over 100 times that of CPUs
  2. BThey have many simple arithmetic units and can process large amounts of data in parallel
  3. CThey have no memory
Show answer and explanation

Answer: B. They have many simple arithmetic units and can process large amounts of data in parallel

GPUs were built to process many screen pixels at once, packing thousands to over ten thousand simple arithmetic units. Workloads like matrix math that repeat the same computation over huge data sets exploit this parallelism for high performance. Modern GPUs add dedicated matrix units (such as Tensor Cores) and high-bandwidth HBM, making them the workhorse of AI training. CPUs remain better at branch-heavy sequential code.
