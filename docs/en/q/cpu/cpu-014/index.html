CPUs and architecture

Which cache holds the results of translating virtual addresses into physical addresses to speed up address translation?

  1. AL3 cache
  2. BTLB (translation lookaside buffer)
  3. CRegister file
Show answer and explanation

Answer: B. TLB (translation lookaside buffer)

Virtual memory must translate the virtual addresses programs use into physical addresses, and since page tables live in memory, walking them each time would cost several memory accesses. The TLB caches recent translations. With only tens to thousands of entries, it misses more as working sets grow, so large pages (huge pages, such as 2 MB) are used to extend its reach.
