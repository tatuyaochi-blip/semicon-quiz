CPUs and architecture

Which mechanism transfers data directly between peripherals and memory without going through the CPU?

  1. ATLB
  2. BSIMD
  3. CDMA (direct memory access)
Show answer and explanation

Answer: C. DMA (direct memory access)

With DMA, a dedicated controller moves data between memory and peripherals, so the CPU only starts the transfer and receives a completion interrupt, remaining free in between. It is used for storage, networking, audio and ADC data capture—anywhere large volumes move. Coherence between CPU caches and transferred data must be managed, by hardware or the OS.
