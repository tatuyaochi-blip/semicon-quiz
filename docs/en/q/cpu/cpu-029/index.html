CPUs and architecture

Which metric indicates the number of instructions executed per clock?

  1. AIPC
  2. BCPI
  3. CTDP
Show answer and explanation

Answer: A. IPC

IPC (instructions per clock) is the average number of instructions executed per cycle, the inverse of CPI. For the same program on the same instruction set, performance is proportional to IPC × frequency, so at equal clock speed a higher IPC is faster. Superscalar issue, out-of-order execution, branch prediction and large caches all raise IPC. With clock growth slowing, generational gains now depend heavily on IPC improvements.
