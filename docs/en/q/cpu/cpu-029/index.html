CPUs and architecture

Which metric indicates the number of instructions executed per clock?

  1. AIPC
  2. BCPI
  3. CTDP
Show answer and explanation

Answer: A. IPC

IPC (instructions per clock) is the average number of instructions executed per clock and is the reciprocal of CPI (clocks per instruction). At the same clock frequency, higher IPC means higher performance. Superscalar and out-of-order execution are techniques for raising IPC.
