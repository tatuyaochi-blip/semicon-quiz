CPUs and architecture

Which technique lets one CPU core process instructions from multiple threads at the same time to make better use of the core's execution units?

  1. ADVFS
  2. BDMA
  3. CSMT (simultaneous multithreading)
Show answer and explanation

Answer: C. SMT (simultaneous multithreading)

SMT lets one core issue instructions from multiple threads at once, using execution resources a single thread cannot saturate; while one thread waits on a cache miss, the other proceeds. Intel's Hyper-Threading is the best-known example, presenting each core to the OS as two logical processors. Gains range from about 0 to 30% depending on the workload—not the same as doubling the cores.

  • A. DVFS is a power-saving technique that dynamically changes voltage and frequency.
  • B. DMA transfers data without involving the CPU.
  • C. Correct. One core processes several threads at once.
