CPUs and architecture

In a multicore CPU, which mechanism keeps data consistent when the caches of several cores hold data for the same address?

  1. ABranch prediction
  2. BTLB
  3. CCache coherence control
Show answer and explanation

Answer: C. Cache coherence control

If one core modifies cached data while another core's cache still holds the old copy, the other core may use a stale value. Coherence protocols such as MESI tag each cache line with states like Modified, Shared or Invalid and invalidate other copies on writes to keep data consistent. With many cores the traffic grows, so directory-based schemes are used to scale.
