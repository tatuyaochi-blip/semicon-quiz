CPUs and architecture

Which IC integrates a CPU, memory and peripherals such as timers and ADCs on one chip and is used to control appliances and equipment?

  1. AGPU
  2. BMicrocontroller (MCU)
  3. CHBM
Show answer and explanation

Answer: B. Microcontroller (MCU)

A microcontroller integrates a CPU with flash for program storage, working RAM, timers, ADCs and communication interfaces (UART, SPI, I²C, CAN, etc.) on one chip. It controls home appliances, cars (dozens to over 100 per vehicle) and industrial equipment, with tens of billions shipped each year. It is small, cheap, low-power and ready to run immediately at power-on.
