CPUs and architecture

Approximately how many instructions per second can a processor with a 2 GHz clock and an average CPI (clocks per instruction) of 0.5 execute?

  1. A1 billion instructions
  2. B4 billion instructions
  3. C100 million instructions
Show answer and explanation

Answer: B. 4 billion instructions

There are 2×10⁹ clocks per second and each instruction averages 0.5 clocks, so 2×10⁹ ÷ 0.5 = 4×10⁹—4 billion instructions. CPI below 1 reflects superscalar execution of multiple instructions per clock. Performance is execution time = instruction count × CPI ÷ frequency, so no single one of the three factors suffices for comparison.
