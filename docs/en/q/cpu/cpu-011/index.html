CPUs and architecture

What do names like ARM, x86 and RISC-V mainly refer to?

  1. AGenerations of manufacturing processes
  2. BInstruction set architectures (ISAs)
  3. CTypes of packages
Show answer and explanation

Answer: B. Instruction set architectures (ISAs)

These are names of instruction set architectures (ISAs), which define the contract between software and hardware, such as the types and formats of instructions a processor understands. With the same ISA, processors designed by different companies can run the same programs.
