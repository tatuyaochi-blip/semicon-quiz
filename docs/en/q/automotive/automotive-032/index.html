Automotive Semiconductors and Functional Safety

Which correctly describes SEooC (Safety Element out of Context) in ISO 26262?

  1. AA component used only in non-safety-related applications, to which ISO 26262 need not be applied; an IC for car audio is an example
  2. BA device installed outside the vehicle, on roads or traffic signals, that communicates with vehicles to support safety; a roadside communication unit is an example
  3. CAn element developed before the target system is determined by assuming its usage and higher-level safety requirements, with the user verifying those assumptions; a general-purpose automotive microcontroller is an example
Show answer and explanation

Answer: C. An element developed before the target system is determined by assuming its usage and higher-level safety requirements, with the user verifying those assumptions; a general-purpose automotive microcontroller is an example

General-purpose automotive microcontrollers and power ICs are developed before it is known which system of which vehicle they will be used in. So the semiconductor manufacturer develops them by assuming safety requirements and usage (for example, "used together with an external watchdog"), and provides those assumptions and how to use the safety mechanisms in a safety manual. This is SEooC. The developer of the system using the component confirms that those assumptions hold in their design. It does not mean a component exempt from ISO 26262.
