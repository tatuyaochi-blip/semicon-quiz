Bipolar transistors

What is the main reason for making the base of a bipolar transistor thin?

  1. ATo raise the collector breakdown voltage
  2. BTo lower the base resistance
  3. CTo reduce recombination in the base and increase the current gain
Show answer and explanation

Answer: C. To reduce recombination in the base and increase the current gain

Some of the carriers injected from the emitter into the base recombine and are lost while crossing the base. A thinner base shortens the transit time and reduces recombination, so more carriers reach the collector and the current gain increases. A thinner base, however, raises the base resistance and makes punch-through more likely, which is a disadvantage for breakdown voltage.
