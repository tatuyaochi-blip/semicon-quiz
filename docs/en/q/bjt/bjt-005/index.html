Bipolar transistors

How does the phase of the output voltage of a common-emitter amplifier compare with the input voltage?

  1. AIn phase
  2. BInverted by 180°
  3. CLeading by 90°
Show answer and explanation

Answer: B. Inverted by 180°

In a common-emitter amplifier, when the input (base) voltage rises, the collector current increases and the voltage drop across the collector resistor grows, so the output (collector) voltage falls. The output is therefore 180° out of phase with the input.
