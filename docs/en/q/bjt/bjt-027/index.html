Bipolar transistors

What is the advantage of an active load, which uses a transistor acting as a current source instead of a load resistor in an amplifier?

  1. AThe gain always decreases
  2. BIt gives the same effect as a very large resistor in a small area, allowing high gain
  3. CThe circuit starts to emit light
Show answer and explanation

Answer: B. It gives the same effect as a very large resistor in a small area, allowing high gain

A current source acts as a very large resistance for small signals, so an active load gives high voltage gain without actually placing a large resistor. Large resistors take up a lot of area on an IC, so active loads are widely used in analog ICs.
