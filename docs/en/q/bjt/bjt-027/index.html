Bipolar transistors

What is the advantage of an active load, which uses a transistor acting as a current source instead of a load resistor in an amplifier?

  1. AThe gain always decreases
  2. BIt gives the same effect as a very large resistor in a small area, allowing high gain
  3. CThe circuit starts to emit light
Show answer and explanation

Answer: B. It gives the same effect as a very large resistor in a small area, allowing high gain

A current source looks like a very large resistance to small signals (its output resistance ro, tens of kΩ to MΩ), so an active load raises voltage gain to about gm × ro. Achieving that with a resistor would need a large voltage drop and area, whereas an active load needs little of either. In an op-amp's differential input stage, a current-mirror active load converts the differential signal to single-ended while doubling the gain.
