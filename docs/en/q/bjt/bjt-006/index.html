Bipolar transistors

What is the main reason for making the emitter of an NPN transistor more heavily doped than the base?

  1. ATo increase emitter injection efficiency and the current gain
  2. BTo raise the collector breakdown voltage
  3. CTo increase the base resistance
Show answer and explanation

Answer: A. To increase emitter injection efficiency and the current gain

With a heavily doped emitter, nearly all the current across the base-emitter junction consists of electrons injected into the base (high injection efficiency). Holes flowing back from base to emitter never reach the collector and only add to base current, so suppressing them raises current gain. Over-doping the emitter loses effectiveness due to bandgap narrowing, which HBTs solve by using a wider-bandgap emitter material.
