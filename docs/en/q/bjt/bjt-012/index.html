Bipolar transistors

Which is a characteristic of a common-base amplifier?

  1. AIts current gain is about 1, but it amplifies well up to high frequencies
  2. BIt has the highest current gain of the three configurations
  3. CIt has the highest input impedance of the three configurations
Show answer and explanation

Answer: A. Its current gain is about 1, but it amplifies well up to high frequencies

In common base, input emitter current and output collector current are nearly equal, so current gain is α (about 1), but voltage gain can be as large as common emitter. Input impedance is low, about 1/gm (about 26 Ω at 1 mA), and because the base is AC-grounded the stage avoids feedback capacitance between input and output (the Miller effect), so it amplifies to high frequencies. The cascode, combining it with a common-emitter stage, is the classic example.
