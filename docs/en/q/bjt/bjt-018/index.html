Bipolar transistors

What does a differential pair, with the emitters of two transistors connected to a common current source, do?

  1. AAmplifies the sum of the two input voltages
  2. BAmplifies the difference between the two input voltages
  3. CRectifies the input voltage
Show answer and explanation

Answer: B. Amplifies the difference between the two input voltages

In a differential pair, the current from the common current source is divided between the two transistors according to the difference between the two input voltages. If both inputs change by the same amount, the division does not change, so only the difference is amplified. It is used as the input stage of op-amps and similar circuits.
