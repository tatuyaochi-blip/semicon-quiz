Bipolar transistors

What does a differential pair, with the emitters of two transistors connected to a common current source, do?

  1. AAmplifies the sum of the two input voltages
  2. BAmplifies the difference between the two input voltages
  3. CRectifies the input voltage
Show answer and explanation

Answer: B. Amplifies the difference between the two input voltages

In a differential pair, the tail current source's current is split between the two transistors according to the difference between the input voltages. If both inputs move together (common mode) the split does not change, so only the difference is amplified while noise or drift common to both cancels. The ratio of differential to common-mode gain is the CMRR (common-mode rejection ratio). Differential pairs form op-amp input stages and receivers for high-speed differential links such as LVDS.
