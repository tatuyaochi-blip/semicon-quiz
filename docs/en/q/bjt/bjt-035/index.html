Bipolar transistors

What is the state of the junctions when a bipolar transistor is in the cutoff region (off)?

  1. AThe base-emitter junction is forward biased and the base-collector junction is reverse biased
  2. BBoth junctions are forward biased
  3. CBoth the base-emitter and base-collector junctions are reverse biased
Show answer and explanation

Answer: C. Both the base-emitter and base-collector junctions are reverse biased

In cutoff, both the base-emitter and base-collector junctions are reverse-biased (or VBE is below about 0.5 V, so almost no current flows), and only leakage current (around nA) reaches the collector—the switch is off. If the base is left floating, leakage can be amplified so the device is not fully off, so a resistor between base and emitter is standard practice to ensure turn-off.

  • A. This combination is the active region, used for amplification.
  • B. Both junctions forward biased is the saturation region.
  • C. Correct. Cutoff is when both junctions are reverse biased.
