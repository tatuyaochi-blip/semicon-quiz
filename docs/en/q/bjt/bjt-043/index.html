Bipolar transistors

Which value is closest to the maximum power efficiency of an ideal class B push-pull amplifier?

  1. AAbout 100%
  2. BAbout 78.5%
  3. CAbout 25%
Show answer and explanation

Answer: B. About 78.5%

In class B, each transistor conducts for half a cycle and almost no current flows without a signal. At full sine-wave output the theoretical maximum efficiency is π/4 ≈ 78.5%, higher than class A, which always draws bias current (25% with a resistive load, 50% transformer-coupled). Where still higher efficiency is needed, class D uses the transistors as switches (over 90%) and is now standard in smartphones and flat-panel TVs.

  • A. Voltage drops across the transistors mean linear amplification cannot reach 100%.
  • B. Correct. The theoretical maximum efficiency is π/4 ≈ 78.5%.
  • C. About 25% is the maximum efficiency of a class A amplifier with a resistive load.
