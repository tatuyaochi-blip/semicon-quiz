Bipolar transistors

When the output characteristics (IC-VCE) of a common-emitter transistor are plotted with base current IB as a parameter, what is characteristic of the active region?

  1. AEvery curve is a straight line through the origin
  2. BFor each IB, there is a nearly horizontal line that depends little on VCE
  3. CIncreasing IB decreases IC
Show answer and explanation

Answer: B. For each IB, there is a nearly horizontal line that depends little on VCE

In the active region collector current is set mainly by base current and depends little on VCE, so the output characteristics are nearly horizontal lines, one per IB, spaced according to hFE. Their slight upward slope is the Early effect, and the inverse of the slope is the output resistance ro. The steep rise near the origin is saturation, and below the IB = 0 line is cutoff. A load line overlaid on this plot shows the operating point and signal swing.

  • A. The steep part near the origin is the saturation region; in the active region the lines are nearly horizontal.
  • B. Correct. Lines of nearly constant IC, set by IB, are lined up.
  • C. Increasing IB increases IC.
