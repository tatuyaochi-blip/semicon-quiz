Bipolar transistors

What is the main use of a photocoupler, which combines an LED and a phototransistor in one package?

  1. ATo amplify current greatly
  2. BTo generate power from sunlight
  3. CTo transmit a signal while keeping the input and output electrically isolated
Show answer and explanation

Answer: C. To transmit a signal while keeping the input and output electrically isolated

An optocoupler drives an LED with the input signal and receives its light with a phototransistor on the output side. Because input and output are linked only by light, it can pass signals safely between circuits at different potentials with isolation ratings of several kV, and it blocks noise coupling through shared grounds. It is used for output-voltage feedback in switching power supplies and in PLC input circuits. Capacitive and magnetic digital isolators are increasingly used as alternatives.
