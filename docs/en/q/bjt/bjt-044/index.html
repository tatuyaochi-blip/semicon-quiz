Bipolar transistors

In a circuit using a transistor as a switch, what is the main purpose of a resistor in series with the base?

  1. ATo raise the current gain of the transistor
  2. BTo increase the collector current
  3. CTo limit the base current to a suitable value and protect the base-emitter junction and the driving circuit
Show answer and explanation

Answer: C. To limit the base current to a suitable value and protect the base-emitter junction and the driving circuit

The base-emitter junction is a forward-biased PN junction, so applying a voltage without a resistor would cause excessive current. The base resistor limits the current while being chosen to supply enough base current to drive the transistor firmly into saturation.

  • A. The current gain is a property of the transistor itself and is not raised by the base resistor.
  • B. The base resistor limits current; it is not meant to increase the collector current.
  • C. Correct. It limits base current and protects the junction and the driver.
