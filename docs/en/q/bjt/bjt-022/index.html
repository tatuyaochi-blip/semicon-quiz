Bipolar transistors

In an amplifier, what is the DC voltage and current state of the transistor with no input signal called?

  1. AOperating point (bias point)
  2. BCutoff point
  3. CPinch-off point
Show answer and explanation

Answer: A. Operating point (bias point)

The operating point is the DC voltage and current set by the bias network when no signal is present. Since the signal swings around it, placing it near the middle of the load line—for example, VCE at about half the supply—allows the largest undistorted swing; if it is off-center, one side hits saturation or cutoff and the waveform clips. It also sets small-signal parameters such as gm and input resistance, so it is one of the first design values chosen.
