Bipolar transistors

In an amplifier, what is the DC voltage and current state of the transistor with no input signal called?

  1. AOperating point (bias point)
  2. BCutoff point
  3. CPinch-off point
Show answer and explanation

Answer: A. Operating point (bias point)

The operating point is the DC voltage and current state set by the bias circuit when there is no signal. The signal varies around this point, so to handle large signals without distortion, it is important to place the operating point near the middle of the linear part of the characteristics.
