Bipolar transistors

Which bias condition is correct when an NPN transistor is used for amplification (operated in the active region)?

  1. ABase-emitter forward-biased, base-collector reverse-biased
  2. BBase-emitter reverse-biased, base-collector forward-biased
  3. CBoth base-emitter and base-collector forward-biased
Show answer and explanation

Answer: A. Base-emitter forward-biased, base-collector reverse-biased

In the active region the base-emitter junction is forward-biased to inject electrons from emitter into base, and the base-collector junction is reverse-biased so its strong field sweeps electrons that cross the base into the collector. Collector current is then set by base current (or VBE) and barely depends on collector voltage, which enables amplification. Both junctions forward is saturation (switch on); both reverse is cutoff (switch off).
