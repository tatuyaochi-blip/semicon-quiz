Deposition (CVD and PVD)

Which type of CVD reactor heats only the stage holding the wafer while keeping the reactor walls cool?

  1. ACold-wall type
  2. BOpen-atmosphere type
  3. CHot-wall type
Show answer and explanation

Answer: A. Cold-wall type

A cold-wall reactor heats only the wafer (or susceptor) and keeps the walls cool, reducing film deposition on the walls and particles from them. It is used in single-wafer epi tools and similar. A hot-wall reactor, which heats the whole furnace, makes it easy to process many wafers at a uniform temperature and is used in LPCVD batch furnaces and the like.

  • A. Correct. Only the wafer side is heated.
  • B. CVD is normally done in a reactor with a controlled atmosphere.
  • C. A hot-wall reactor heats the whole furnace.
