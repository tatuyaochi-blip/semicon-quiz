Memory Hierarchy

Which pair correctly states the main advantage and drawback of using large pages (huge pages)?

  1. AAdvantage: lower cache miss rate. Drawback: more TLB misses
  2. BAdvantage: page faults disappear. Drawback: more disk space is used
  3. CAdvantage: fewer TLB misses. Drawback: more internal fragmentation
Show answer and explanation

Answer: C. Advantage: fewer TLB misses. Drawback: more internal fragmentation

Larger pages let one TLB entry translate a wide range, sharply reducing TLB misses for programs with large data. On the other hand, even small amounts of data are allocated in large page units, increasing unused space (internal fragmentation) and making allocation less flexible. TLB misses decrease rather than increase, and the cache miss rate does not depend directly on page size. Page faults do not disappear either.

  • A. TLB misses actually decrease, and the cache miss rate is not directly affected.
  • B. Page faults do not disappear.
  • C. Correct. TLB misses fall, but internal fragmentation grows.
