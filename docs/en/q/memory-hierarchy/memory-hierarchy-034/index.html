Memory Hierarchy

Which describes an inclusive cache, where a lower level (such as L2) contains everything in the upper level (L1)?

  1. AUpper and lower levels never hold the same data, so total capacity is used most efficiently
  2. BThe lower cache must always be smaller than the upper one
  3. CCoherence is easier to manage, but data is duplicated
Show answer and explanation

Answer: C. Coherence is easier to manage, but data is duplicated

In an inclusive design, anything in L1 is guaranteed to be in L2, so snoops from other cores can be answered by checking L2 alone, without probing L1. The cost is duplicated data, leaving effective capacity at roughly the L2 size. Not duplicating data is the exclusive design, which uses total capacity efficiently. Lower-level caches are normally larger than upper ones.

  • A. Avoiding duplication describes an exclusive cache.
  • B. Lower-level caches are normally larger than upper ones.
  • C. Correct. Coherence is easier, but data is duplicated.
