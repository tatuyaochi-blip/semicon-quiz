Logic circuits

Which circuit activates exactly one of eight outputs according to a 3-bit input?

  1. AEncoder
  2. BDecoder
  3. CCounter
Show answer and explanation

Answer: B. Decoder

A decoder activates exactly one of 2ⁿ outputs based on an n-bit input—eight outputs for three bits. It selects word lines or columns from memory addresses, decodes CPU instructions and drives seven-segment displays. Since each output corresponds to one input combination (a minterm), a decoder plus OR gates can implement any logic function. An encoder performs the reverse.
