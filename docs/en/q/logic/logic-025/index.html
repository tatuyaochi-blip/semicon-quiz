Logic circuits

When an even parity bit is added to the 7-bit data 1011001, what is the parity bit?

  1. A1
  2. B0
  3. CAlways 1 regardless of the data
Show answer and explanation

Answer: B. 0

With even parity, the parity bit is chosen so that the total number of 1s, including the parity bit, is even. 1011001 already contains four 1s, which is even, so the parity bit is 0. If the receiver counts an odd number of 1s, it can detect a single-bit error.
