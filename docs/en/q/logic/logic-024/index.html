Logic circuits

What happens to the value of a binary number when it is shifted left by one bit (assuming no overflow)?

  1. AIt doubles
  2. BIt halves
  3. CIt increases by 1
Show answer and explanation

Answer: A. It doubles

Each binary digit has twice the weight of the one to its right, so shifting everything left by one bit and inserting 0 at the lowest bit doubles the value. Shifting right by one bit halves it (rounding down). This is why multiplication and division by powers of two can be done quickly with shifts.
