How many states can a 4-bit binary counter represent?

  1. A4
  2. B8
  3. C16
Show answer and explanation

Answer: C. 16

Four bits can represent 2⁴ = 16 states. A binary counter counts from 0 (0000) to 15 (1111) and returns to 0 on the next clock. An N-bit counter has 2ᴺ states.
