Logic circuits

What does a two-input NAND gate do when its two inputs are tied together to form a single input?

  1. AAND
  2. BNOT (inverter)
  3. CXOR
Show answer and explanation

Answer: B. NOT (inverter)

If the same value A is applied to both inputs, the output is NOT(A AND A) = NOT A, so it works as an inverter. Because NOT, AND and OR can all be built from NAND gates, any logic circuit can be built from NAND gates alone (the same is true of NOR).
