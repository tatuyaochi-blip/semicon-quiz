Logic circuits

When several open-drain outputs are connected to one signal line with a pull-up resistor, how does the line behave?

  1. AThe outputs conflict and are always damaged
  2. BIf any one outputs 0, the line becomes 0, acting as a wired AND
  3. CIf any one outputs 1, the line becomes 1
Show answer and explanation

Answer: B. If any one outputs 0, the line becomes 0, acting as a wired AND

An open-drain output either pulls the line to ground or releases it; a pull-up resistor provides the 1. If any device outputs 0 the line goes low, and it is high only when all release it—a wired-AND that tolerates simultaneous drivers without damage. It is used for I²C buses, interrupt lines and level shifting between different supply voltages. Rise time, set by the pull-up resistor and line capacitance, is relatively slow.

  • A. The outputs only pull down, so connecting them together does not damage them.
  • B. Correct. Any single 0 makes the line 0, a wired AND.
  • C. Open-drain outputs never actively drive 1, so a 1 cannot take precedence.
