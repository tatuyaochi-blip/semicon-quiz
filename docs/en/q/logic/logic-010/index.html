Logic circuits

Which correctly describes the function of a multiplexer?

  1. AIt stores the input value for one clock cycle
  2. BIt inverts the logic of the input signal
  3. CIt selects one of several inputs according to select signals and outputs it
Show answer and explanation

Answer: C. It selects one of several inputs according to select signals and outputs it

A multiplexer (selector) chooses one of several inputs according to the value of its select signals and passes it to the output. For example, with 2-bit select signals it can choose one of four inputs. A circuit that routes one input to one of several outputs is a demultiplexer.
