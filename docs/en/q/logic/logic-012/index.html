Logic circuits

What is the main use of a Karnaugh map?

  1. AMeasuring circuit delay
  2. BDesigning analog filters
  3. CSimplifying logic expressions
Show answer and explanation

Answer: C. Simplifying logic expressions

A Karnaugh map arranges a truth table so that adjacent cells differ in only one input bit (Gray-code order). Grouping adjacent 1s in rectangles of 1, 2, 4 or 8 cells eliminates the variables that change within each group, simplifying the expression; note that the edges wrap around and count as adjacent. Manual use tops out at about four or five variables; beyond that, the Quine-McCluskey method or synthesis-tool algorithms are used.
