What does a JK flip-flop do when a clock edge arrives with J = 1 and K = 1?

  1. AThe output inverts (toggles)
  2. BThe output is reset to 0
  3. CThe output is held
Show answer and explanation

Answer: A. The output inverts (toggles)

A JK flip-flop sets with J = 1, K = 0, resets with J = 0, K = 1, holds with J = K = 0, and toggles with J = K = 1. It gives meaning ("toggle") to the S = R = 1 input forbidden in an SR flip-flop, with next state Q⁺ = J·¬Q + ¬K·Q. Tying J and K to 1 makes a T flip-flop used in counters. Modern designs mainly use D flip-flops.

  • A. Correct. With J = K = 1 the output toggles.
  • B. Reset occurs with J = 0, K = 1.
  • C. Hold occurs with J = K = 0.
