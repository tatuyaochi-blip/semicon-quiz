What does a JK flip-flop do when a clock edge arrives with J = 1 and K = 1?

  1. AThe output is reset to 0
  2. BThe output is held
  3. CThe output inverts (toggles)
Show answer and explanation

Answer: C. The output inverts (toggles)

A JK flip-flop sets with J = 1, K = 0; resets with J = 0, K = 1; holds with J = K = 0; and toggles its output with J = K = 1. It gives meaning (toggling) to the input combination that is forbidden in an SR flip-flop.

  • A. Reset occurs with J = 0, K = 1.
  • B. Hold occurs with J = K = 0.
  • C. Correct. With J = K = 1 the output toggles.
