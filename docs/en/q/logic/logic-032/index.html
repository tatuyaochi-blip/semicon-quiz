Logic circuits

When is the output of a 2-input OR gate 0?

  1. AWhen both inputs are 0
  2. BWhen both inputs are 1
  3. CWhen the two inputs differ
Show answer and explanation

Answer: A. When both inputs are 0

An OR gate (logical sum) outputs 1 if at least one input is 1. Its output is therefore 0 only when all inputs are 0.

  • A. Correct. OR outputs 0 only when all inputs are 0.
  • B. When both inputs are 1, the OR output is 1.
  • C. When the inputs differ, the OR output is 1.
