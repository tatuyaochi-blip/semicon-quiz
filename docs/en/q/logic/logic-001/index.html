Logic circuits

When is the output of a two-input NAND gate 0?

  1. AWhen both inputs are 1
  2. BWhen at least one input is 0
  3. CWhen both inputs are 0
Show answer and explanation

Answer: A. When both inputs are 1

NAND is the negation of AND. AND outputs 1 only when all inputs are 1, so NAND outputs 0 only when all inputs are 1. For every other combination, the output is 1.
