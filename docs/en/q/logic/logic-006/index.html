Logic circuits

Which correctly describes a sequential circuit?

  1. AIts output depends on the current inputs and a stored internal state
  2. BIts output depends only on the current inputs
  3. CIt handles only analog signals
Show answer and explanation

Answer: A. Its output depends on the current inputs and a stored internal state

A sequential circuit has storage elements such as flip-flops, and its output depends not only on the current inputs but also on the history of past inputs (its internal state). Counters, registers and state machines are typical examples. A circuit whose output depends only on the current inputs is a combinational circuit.
