Logic circuits

What is a typical use of a linear feedback shift register (LFSR), which feeds the XOR of some outputs of a shift register back to its input?

  1. AGenerating pseudo-random patterns, such as test patterns, and computing CRCs
  2. BMeasuring precise time
  3. CAmplifying analog signals
Show answer and explanation

Answer: A. Generating pseudo-random patterns, such as test patterns, and computing CRCs

With properly chosen taps, an n-bit LFSR cycles through all 2ⁿ − 1 nonzero states, producing a seemingly random maximal-length sequence (m-sequence). Built only from XORs and flip-flops, it is used for built-in self-test (BIST) pattern generation and response compaction, CRC calculation in protocols such as Ethernet, and scramblers that randomize data to reduce electromagnetic noise. Its output is predictable, so it is unsuitable for cryptographic randomness.

  • A. Correct. It is used for pseudo-random and test patterns and CRCs.
  • B. It is not used for measuring precise time.
  • C. An LFSR is a digital circuit and does not amplify analog signals.
