Logic circuits

Which correctly describes the operation of a D flip-flop?

  1. AIt always passes input changes directly to the output
  2. BIt outputs the exclusive OR of two inputs
  3. CIt captures the value of the D input at a clock edge and holds it until the next edge
Show answer and explanation

Answer: C. It captures the value of the D input at a clock edge and holds it until the next edge

A D flip-flop captures its D input on the rising (or falling) clock edge and holds it until the next edge; changes between edges do not affect the output. It is the building block of sequential circuits—CPU registers, pipeline stage boundaries and counters—and is internally two latches in a master-slave arrangement. Correct capture requires meeting setup and hold times.
