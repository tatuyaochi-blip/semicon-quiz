How many bits are in one byte?

  1. A8 bits
  2. B4 bits
  3. C16 bits
Show answer and explanation

Answer: A. 8 bits

A byte is 8 bits and can represent 256 values (0–255)—one ASCII character or one color channel of a pixel (0–255 intensity). Four bits form a nibble (half a byte), matching one hex digit. Some early computers used 6- or 9-bit bytes, so "octet" is used, for example in networking standards, when exactly 8 bits is meant.

  • A. Correct. 1 byte = 8 bits.
  • B. Four bits are called a nibble, half a byte.
  • C. 16 bits are two bytes.
