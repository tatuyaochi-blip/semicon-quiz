How many bits are in one byte?

  1. A8 bits
  2. B4 bits
  3. C16 bits
Show answer and explanation

Answer: A. 8 bits

One byte is 8 bits and can represent 256 values (0 to 255). Four bits are called a nibble (half a byte) and correspond to one hexadecimal digit.

  • A. Correct. 1 byte = 8 bits.
  • B. Four bits are called a nibble, half a byte.
  • C. 16 bits are two bytes.
