Which correctly describes the operation of a D latch?

  1. AIt captures the input only at the instant of the rising clock edge
  2. BIt always outputs the inverted input
  3. CWhile the enable signal is active, the input passes straight to the output; when it becomes inactive, the value is held
Show answer and explanation

Answer: C. While the enable signal is active, the input passes straight to the output; when it becomes inactive, the value is held

A D latch is level-sensitive: while enabled it is transparent, passing input straight to output, and when disabled it holds the value at that moment. It uses fewer transistors than a flip-flop and is sometimes used for speed via latch-based timing (time borrowing), but signals racing through during transparency make timing analysis harder. An edge-triggered D flip-flop is built from two latches clocked in opposite phases.
