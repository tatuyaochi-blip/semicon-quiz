Power Management

What is the role of the isolation cells placed between a powered-off block and running blocks?

  1. ATo pass a fixed value (0 or 1) to the running side even when the powered-off block's outputs become undefined
  2. BTo convert supply voltages between the two blocks
  3. CTo cool the powered-off block
Show answer and explanation

Answer: A. To pass a fixed value (0 or 1) to the running side even when the powered-off block's outputs become undefined

Outputs of a powered-off block float at undefined intermediate voltages, which could make receiving circuits malfunction or draw shoot-through current in their input stages. Isolation cells clamp those outputs to fixed values while the block is off. Which signals are clamped to which values is conveyed to design tools in a file describing the power intent.

  • A. Correct. It keeps undefined values from spreading.
  • B. Voltage conversion is the level shifter's job.
  • C. It has nothing to do with temperature.
