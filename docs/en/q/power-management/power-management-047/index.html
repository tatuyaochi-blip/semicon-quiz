Power Management

What is the idea behind the tickless kernel used in Linux and other OSes?

  1. AHiding the clock display to reduce screen power
  2. BWhen idle, the periodic timer tick interrupt is stopped so the CPU can sleep until the next work
  3. CRaising the timer tick interrupt to tens of thousands per second
Show answer and explanation

Answer: B. When idle, the periodic timer tick interrupt is stopped so the CPU can sleep until the next work

Traditional OSes used a timer tick interrupt, say 100 to 1000 times per second, for task switching and timekeeping, waking the CPU each time even with nothing to do. A tickless kernel stops the tick on idle CPUs and programs a timer only for the next time it actually needs to wake. The CPU can then sleep longer and deeper, reducing standby power.

  • A. It has nothing to do with the display.
  • B. Correct. It reduces standby power.
  • C. It reduces interrupts instead.
