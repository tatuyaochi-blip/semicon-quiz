Power Management

Which describes ACPI, used in PCs and similar systems?

  1. AThe name of a CPU instruction set
  2. BA standard interface between hardware and OS that lets the OS manage device power states, power saving and thermals
  3. CA wireless LAN standard
Show answer and explanation

Answer: B. A standard interface between hardware and OS that lets the OS manage device power states, power saving and thermals

ACPI (Advanced Configuration and Power Interface) is the standard mechanism by which an OS manages system and device power states. Firmware describes the hardware configuration and how to control power to the OS in tables, which the OS uses to enter sleep (S3) or hibernation (S4), control CPU C-states and P-states, drive fans according to temperature and so on. It also hides hardware-specific differences from the OS.

  • A. It is not an instruction set.
  • B. Correct. It also controls sleep and hibernation.
  • C. It is not a wireless LAN standard.
