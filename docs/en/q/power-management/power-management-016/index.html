Power Management

Which describes CPU P-states?

  1. APerformance levels while the CPU runs, defined by combinations of frequency and voltage
  2. BHow deeply the CPU sleeps when idle
  3. CTypes of CPU package
Show answer and explanation

Answer: A. Performance levels while the CPU runs, defined by combinations of frequency and voltage

P-states divide a running CPU's frequency and voltage combinations into levels; higher levels are faster and use more power. The OS or the CPU's internal power-management circuitry switches P-states to match load (DVFS). Combined with C-states, which describe sleep depth, this lets the CPU run at a suitable speed when there is work and sleep deeply when there is none.

  • A. Correct. They correspond to DVFS levels.
  • B. That is a C-state.
  • C. It is not a package type.
