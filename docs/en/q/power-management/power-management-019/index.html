Power Management

Which describes CPU turbo operation (such as Turbo Boost)?

  1. AAutomatically raising frequency above the rated value to boost performance when power and temperature allow
  2. BAlways running at minimum frequency to save power
  3. CAttaching a tiny jet engine to the CPU
Show answer and explanation

Answer: A. Automatically raising frequency above the rated value to boost performance when power and temperature allow

A CPU's rated frequency is set so that power and thermal limits hold even with every core heavily loaded. In practice there is headroom when only some cores are busy or the chip is cool. Turbo operation monitors power, temperature and current and raises frequency and voltage to use that headroom for more performance, automatically backing off when it runs out.

  • A. Correct. It converts headroom into performance.
  • B. That is power-saving operation.
  • C. Of course no engine is attached.
