How to read datasheets

A voltage of 1.4 V is applied to an input of an IC whose input thresholds are specified as VIH(min) = 2.0 V and VIL(max) = 0.8 V. How is it interpreted?

  1. AIt is below VIH(min) of 2.0 V, so it is always interpreted as L
  2. BIt is above VIL(max) of 0.8 V, so it is always interpreted as H
  3. CWhether it is interpreted as H or L is not guaranteed
Show answer and explanation

Answer: C. Whether it is interpreted as H or L is not guaranteed

VIH(min) is the lowest voltage guaranteed to be recognized as H, and VIL(max) is the highest voltage guaranteed to be recognized as L. The range between them, 0.8–2.0 V, is an undefined region where the input may be recognized either way depending on the unit and temperature. If an input stays in this region for long, the output may oscillate, or the pMOS and nMOS of the input stage may turn on simultaneously and shoot-through current may flow. For slowly changing signals, use a Schmitt-trigger input with hysteresis.
