Power semiconductors

In packages for fast-switching power devices, what is the purpose of a dedicated source terminal for the gate-drive return (Kelvin source)?

  1. ATo double the source current
  2. BTo keep the voltage across the inductance of the main-current source path from affecting the gate drive
  3. CTo make the package smaller
Show answer and explanation

Answer: B. To keep the voltage across the inductance of the main-current source path from affecting the gate drive

The source lead carrying main current has inductance Ls, so rapid current changes induce Ls·di/dt. If the gate-drive return shares this path, that voltage opposes the gate drive, slowing switching or causing oscillation (the common-source inductance problem). A Kelvin source is a dedicated source terminal for the driver that eliminates this effect, and four-pin packages are increasingly used to exploit the speed of SiC and GaN.

  • A. It is not a terminal for increasing current.
  • B. Correct. It removes the effect of common source inductance.
  • C. It is not intended to shrink the package.
