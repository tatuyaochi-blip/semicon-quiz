System Architecture and Reliability

Among the measures used to evaluate the performance of an online processing system, which describes response time?

  1. AThe time from when the user finishes entering a processing request until the system starts outputting the result
  2. BThe time from when a processing request starts being entered until the output of the result is completely finished
  3. CThe amount of work the system can process per unit time
Show answer and explanation

Answer: A. The time from when the user finishes entering a processing request until the system starts outputting the result

Response time is the time from when the user finishes entering a processing request at a terminal until the system starts outputting the result. It is especially important in online processing, where users wait in front of the screen. The time from submitting a job until all of its results have been output is called turnaround time and is used mainly to evaluate batch processing. The amount of work per unit time is throughput.

  • A. Correct. It is the time from the end of input to the start of output.
  • B. This is close to turnaround time and includes the time until the output is finished.
  • C. This describes throughput.
