System Architecture and Reliability

Which describes a differential backup?

  1. ABacking up only the data changed since the previous backup (whether full or incremental)
  2. BBacking up all data, regardless of whether it has changed
  3. CBacking up all data changed since the previous full backup
Show answer and explanation

Answer: C. Backing up all data changed since the previous full backup

A differential backup backs up all data changed since the previous full backup. Each backup grows as the days since the full backup increase, but a restore needs only two: the full backup and the latest differential backup. Backing up only the changes since the previous backup is an incremental backup; each one is small, but a restore needs the full backup and every incremental backup after it.

  • A. This describes an incremental backup.
  • B. This describes a full backup.
  • C. Correct. It includes all changes since the full backup.
