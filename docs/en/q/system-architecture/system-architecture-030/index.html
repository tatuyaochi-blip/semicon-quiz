System Architecture and Reliability

Among the ways to increase a system's processing capacity, which corresponds to scale-out?

  1. AIncreasing the number of servers with the same configuration and distributing the processing with a load balancer
  2. BReplacing a server's CPU with a faster one and adding memory
  3. CReducing the number of servers to raise the utilization of each
Show answer and explanation

Answer: A. Increasing the number of servers with the same configuration and distributing the processing with a load balancer

Scale-out increases the processing capacity of the whole system by adding servers and sharing the processing among them. Capacity can be added simply by adding servers, and processing continues on the rest if one fails, but the system must be designed so that the processing can be divided. Making the parts of one server faster is scale-up, which is simple to configure but limited by the performance one server can achieve. Reducing the number of servers is called scale-in.

  • A. Correct. The processing is shared by adding servers.
  • B. This is scale-up, raising the performance of one server.
  • C. This is scale-in, reducing the number of servers, which lowers the processing capacity.
