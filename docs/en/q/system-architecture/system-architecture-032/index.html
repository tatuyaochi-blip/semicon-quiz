System Architecture and Reliability

Which describes live migration in a virtualized environment?

  1. AMoving a running virtual machine to another physical server with only a very short interruption as seen by users
  2. BStopping a virtual machine, copying its disk image and restarting it on another physical server
  3. CRebuilding the OS and applications running on a physical server as a virtual machine and moving them
Show answer and explanation

Answer: A. Moving a running virtual machine to another physical server with only a very short interruption as seen by users

Live migration moves a virtual machine to another physical server by repeatedly copying the memory contents of the running virtual machine to the destination while it keeps running, and finally stopping it for only a very short time to transfer the remaining contents and the CPU state. It allows physical server maintenance and rebalancing of uneven load with almost no service interruption. Generally, the source and destination must share the same storage or the storage contents must be moved as well, and compatible CPU features are also required.

  • A. Correct. The virtual machine is moved while running, with almost no stop.
  • B. This describes cold migration, which moves a stopped virtual machine.
  • C. This describes P2V (physical to virtual), which moves a physical server into a virtual machine.
