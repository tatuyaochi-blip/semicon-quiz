Advanced transistors (FinFET and GAA)

What is the purpose of using several types of transistors with different threshold voltages on the same chip?

  1. ATo decorate the chip
  2. BTo use low-threshold transistors where speed is needed and high-threshold ones where leakage should be low, balancing performance and power
  3. CTo make the threshold voltage unmeasurable
Show answer and explanation

Answer: B. To use low-threshold transistors where speed is needed and high-threshold ones where leakage should be low, balancing performance and power

Low-threshold transistors are fast but leaky, and high-threshold ones are slower but leak less. Using low-threshold transistors only on timing-critical paths and high-threshold ones elsewhere keeps performance while reducing standby power.
