Advanced transistors (FinFET and GAA)

Compared with FinFETs, what is a design advantage of nanosheet GAA transistors?

  1. AChannel width can only be changed by the number of fins
  2. BDrive current can be adjusted more flexibly by changing the nanosheet width
  3. CGate length does not affect transistor characteristics
Show answer and explanation

Answer: B. Drive current can be adjusted more flexibly by changing the nanosheet width

A FinFET's channel width can change only by fin count, but in nanosheet GAA the stacked sheets' width (e.g., 15–50 nm) can be varied continuously in layout. Wide sheets suit high-performance cells and narrow ones suit low-power logic and SRAM, giving flexible control of drive current and capacitance. The all-around gate also resists short-channel effects, delivering more current than a FinFET in the same footprint.
