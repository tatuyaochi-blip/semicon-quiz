Compound semiconductors

Which configuration combines a normally-on GaN HEMT in series with a low-voltage silicon MOSFET so it can be used safely with normally-off behavior?

  1. ABridge rectifier
  2. BDarlington connection
  3. CCascode configuration
Show answer and explanation

Answer: C. Cascode configuration

In the cascode configuration, a low-voltage silicon MOSFET is placed in series on the source side of the GaN HEMT, and the HEMT's gate is tied to the MOSFET's source. Turning off the MOSFET automatically turns off the HEMT, so the combination behaves as a normally-off device. Another advantage is that gate drivers for silicon MOSFETs can be used as is.

  • A. A bridge rectifier converts AC to DC.
  • B. A Darlington connection uses two bipolar transistors to increase current gain.
  • C. Correct. Placing it in series with a Si MOSFET gives normally-off operation.
