Advanced packaging (3D and chiplets)

Which correctly describes the role of the base die (logic die) at the bottom of an HBM stack?

  1. AIt handles the interface between the stacked DRAM and the processor, as well as functions such as test
  2. BIt is placed as decoration
  3. CIt emits light
Show answer and explanation

Answer: A. It handles the interface between the stacked DRAM and the processor, as well as functions such as test

The HBM base die handles signaling between the stacked DRAM dies and the processor and includes circuitry for testing and repairing defective cells. It has traditionally been made in a DRAM process, but in the HBM4 generation there is a move to make it in a logic process and add customer-specific functions. It is neither decorative nor light-emitting.
