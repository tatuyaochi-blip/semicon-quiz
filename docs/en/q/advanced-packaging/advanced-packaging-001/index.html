Advanced packaging (3D and chiplets)

Which correctly describes chiplets?

  1. AA technology that connects several small chips, divided by function, inside one package so they operate as one system
  2. BA technology that uses an entire wafer as a single chip
  3. CA technology that solders chips directly to the board without a package
Show answer and explanation

Answer: A. A technology that connects several small chips, divided by function, inside one package so they operate as one system

Chiplets replace one large die carrying every function with separate small dies for compute, I/O and so on, densely interconnected inside one package. Small dies are less likely to contain defects, so they yield better, and each function can use the most suitable process. Chiplets are widely used in server CPUs and AI GPUs. Using a whole wafer as one chip is wafer-scale integration, and soldering a bare die directly to a board is chip-on-board mounting.
