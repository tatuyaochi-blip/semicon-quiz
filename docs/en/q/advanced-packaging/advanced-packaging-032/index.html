Advanced packaging (3D and chiplets)

What is the problem called in which the speed of supplying data from memory cannot keep up with improvements in processor compute performance, limiting overall performance?

  1. AThe thermal wall
  2. BThe memory wall
  3. CMoore's law
Show answer and explanation

Answer: B. The memory wall

Processor compute performance has grown rapidly, but bandwidth to memory has grown more slowly, so compute units spend more time waiting for data. This is the memory wall. It is especially severe for large AI models, which read huge numbers of weights for every computation, and advanced packaging that places HBM next to the processor, along with stacked large caches, are countermeasures.

  • A. Limits from heat are a different problem, called the power wall and the like.
  • B. Correct. It is the problem of memory bandwidth limiting performance.
  • C. Moore's law is an empirical rule about the growth in transistor count.
