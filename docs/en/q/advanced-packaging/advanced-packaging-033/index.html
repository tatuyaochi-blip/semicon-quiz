Advanced packaging (3D and chiplets)

Which stacking method, long used in smartphone memory and elsewhere, stacks multiple chips slightly offset from one another and connects each to the substrate with wire bonding?

  1. AStacking with TSVs
  2. BStacking with hybrid bonding
  3. CWire-bonded chip stacking (stacked MCP)
Show answer and explanation

Answer: C. Wire-bonded chip stacking (stacked MCP)

In a stacked MCP, thinned dies are stacked in a staircase offset or with spacers, and fine wires connect pads along each die's edge to the substrate. Requiring no special processing like TSVs, it is inexpensive and widely used in memory products stacking NAND flash or DRAM, with NAND stacks sometimes exceeding 16 dies. Wires are long and limited in number, however, so ultra-high-bandwidth applications use TSVs or hybrid bonding.

  • A. TSV stacking connects chips through electrodes that pass through the silicon.
  • B. Hybrid bonding joins electrodes directly to each other.
  • C. Correct. Each chip is connected by wire bonding.
