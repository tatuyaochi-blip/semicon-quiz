Advanced packaging (3D and chiplets)

Which correctly describes HBM (High Bandwidth Memory)?

  1. AA slow memory using a single layer of flash memory
  2. BAn SRAM cache built into the CPU chip
  3. CA memory that stacks several DRAM dies with TSVs and achieves high bandwidth with a very wide bus
Show answer and explanation

Answer: C. A memory that stacks several DRAM dies with TSVs and achieves high bandwidth with a very wide bus

HBM stacks several DRAM dies with TSVs and connects them to the processor through a very wide data bus of more than 1,000 lines, achieving high data transfer bandwidth. It is used in 2.5D packaging, placed beside the processor on a silicon interposer or similar, and is mounted on AI GPUs and other devices.
