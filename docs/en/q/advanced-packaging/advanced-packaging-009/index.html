Advanced packaging (3D and chiplets)

Which correctly describes SiP (system in package)?

  1. ASeveral chips and passive components are housed in one package to function as a system
  2. BAll functions are integrated on one chip
  3. CA system is built with software alone
Show answer and explanation

Answer: A. Several chips and passive components are housed in one package to function as a system

SiP integrates processors, memory, power ICs, passive components and more in one package so that they function as a single system. Compared with an SoC, which integrates everything on one chip, it readily combines parts made in different processes and can reuse existing chips, shortening development. It is widely used in products that demand miniaturization, such as smartwatches and communication modules.
