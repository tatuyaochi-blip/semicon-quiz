Advanced packaging (3D and chiplets)

Through the HBM3 generation, which is the data bus width per HBM stack?

  1. A1024 bits
  2. B8 bits
  3. C64 bits
Show answer and explanation

Answer: A. 1024 bits

Whereas a typical DDR DRAM module has a 64-bit data bus, HBM has a very wide 1024-bit bus per stack, achieving high bandwidth even though each line is not especially fast. That many wires cannot be routed on ordinary substrates, so high-density wiring such as a silicon interposer is required. The next generation, HBM4, widens it to 2048 bits.

  • A. Correct. A very wide bus yields high bandwidth.
  • B. 8 bits is a very narrow bus, the opposite of HBM's character.
  • C. 64 bits is the bus width of a typical DDR module.
