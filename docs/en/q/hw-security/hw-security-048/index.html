Hardware Security

What is the idea of "defense in depth," emphasized in hardware and software security?

  1. AChoosing only the single strongest countermeasure and omitting the rest
  2. BLayering several different countermeasures so the whole is not breached even if one fails
  3. CDoing nothing and thinking only after an attack
Show answer and explanation

Answer: B. Layering several different countermeasures so the whole is not breached even if one fails

Every countermeasure may have weaknesses not yet discovered. Defense in depth layers different kinds of protection, such as secure boot, memory protection, TEEs, encryption, side-channel countermeasures and physical tamper resistance, so that when one is breached the next layer still holds. The cost and effort for an attacker to defeat every layer at once is what makes the whole secure.

  • A. If that one fails, everything fails.
  • B. Correct. It assumes no single measure is perfect.
  • C. Advance countermeasures are needed.
