Hardware Security

When a CPU hardware vulnerability is discovered, which is one countermeasure applied to CPUs already shipped?

  1. ARecalling all CPUs and replacing transistors one by one
  2. BUpdating the CPU microcode to change problematic internal behavior or add new controls the OS can use
  3. CChanging the marking on the CPU surface
Show answer and explanation

Answer: B. Updating the CPU microcode to change problematic internal behavior or add new controls the OS can use

Many CPUs implement complex instructions and some internal control in updatable microcode. When a vulnerability is found, the vendor distributes a microcode update loaded at every boot through the BIOS or OS. This can suppress problematic behavior or add new controls, such as instructions to flush branch predictors. Problems rooted in the circuitry itself are fixed fundamentally in the next CPU generation.

  • A. Transistors cannot be replaced.
  • B. Correct. It is combined with OS and compiler countermeasures.
  • C. Changing the marking does not change behavior.
