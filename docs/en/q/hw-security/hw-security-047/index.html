Hardware Security

What countermeasure protects against external devices connected to a PC using DMA to read or write main memory without permission?

  1. ARaise the supply voltage of the external device
  2. BMake DMA transfers faster
  3. CUse an IOMMU to limit each device's DMA to memory regions the OS has permitted
Show answer and explanation

Answer: C. Use an IOMMU to limit each device's DMA to memory regions the OS has permitted

DMA lets devices read and write memory directly without the CPU, so a malicious or compromised device can read or modify OS memory and keys. This became a particular concern for devices attached through fast external ports. With an IOMMU, the OS restricts each device to the addresses it has allowed, and DMA to other locations is rejected.

  • A. Voltage is irrelevant.
  • B. Faster transfers do not prevent it.
  • C. Correct. It applies address translation and protection per device.
