Hardware Security

Which method is commonly used to store keys written into a chip?

  1. AOne-time-programmable eFuses or OTP memory, or storing them encrypted in non-volatile memory
  2. BPrinting the key value on the chip surface
  3. CPlacing the key value as is in memory anyone can read externally
Show answer and explanation

Answer: A. One-time-programmable eFuses or OTP memory, or storing them encrypted in non-volatile memory

An eFuse is one-time-programmable storage written bit by bit by blowing a thin wire with a large current. Per-device keys and settings are written after manufacturing, sometimes made unreadable by software so that only the cryptographic engine can use them. Another approach stores keys in flash encrypted with a key derived from a PUF. In every approach, restricting read paths is essential.

  • A. Correct. Read restrictions and combination with PUFs are also used.
  • B. Anyone looking would see it.
  • C. The key would be stolen immediately.
