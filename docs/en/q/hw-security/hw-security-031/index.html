Hardware Security

What is the advantage of using a PUF for key storage?

  1. AUsers can freely choose the key value
  2. BThe key always remains in memory at power-off
  3. CThe key need not be written in non-volatile memory and is regenerated only when used, so it is hard to extract even if the chip is analyzed
Show answer and explanation

Answer: C. The key need not be written in non-volatile memory and is regenerated only when used, so it is hard to extract even if the chip is analyzed

Keys written in flash or eFuses are targets for attacks that open the chip and read storage directly. With a PUF, the key is regenerated from the chip's physical properties each time it is used and is stored nowhere while power is off. For some PUF types, physically tampering with the chip to read the PUF also alters the very variation it depends on, making extraction even harder.

  • A. The value is set by variation and cannot be chosen.
  • B. Not storing it is precisely the advantage.
  • C. Correct. With power off, the key is stored nowhere.
