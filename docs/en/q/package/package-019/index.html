Packaging and assembly

Which long-established package has two rows of pins along both sides and is mounted by inserting them into holes in the board?

  1. ADIP (dual in-line package)
  2. BBGA
  3. CCSP
Show answer and explanation

Answer: A. DIP (dual in-line package)

A DIP is a through-hole package with two rows of pins coming out of both sides, which are inserted into holes in the board and soldered. It is easy to handle and is still used for prototypes and education, but it is unsuited to high pin counts and miniaturization, so surface-mount packages have become mainstream.
