Packaging and assembly

What is the method called that mounts a memory package stacked on top of a processor package?

  1. AQFP
  2. BDIP
  3. CPoP (package on package)
Show answer and explanation

Answer: C. PoP (package on package)

PoP stacks a separate package, such as DRAM, on top of a lower package such as a processor, and solders them together. It saves board area and shortens processor–memory wiring, so it is widely used in smartphones. Because memory and processor are tested separately before stacking, only known-good parts are combined. QFP and DIP are single-package formats.
