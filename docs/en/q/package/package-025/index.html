Packaging and assembly

Which package, used in applications needing high reliability such as space, seals its interior with ceramic or metal?

  1. AResin-molded package
  2. BHermetically sealed package
  3. CTape carrier package
Show answer and explanation

Answer: B. Hermetically sealed package

A hermetic package encloses the chip in a ceramic or metal body sealed with a metal lid by welding or brazing so that no moisture can enter. The cavity is filled with dry nitrogen or similar gas, and tightness is verified by helium leak testing. Because plastic slowly lets moisture through, hermetic sealing is chosen for space, defense and medical uses that require long life in harsh environments.
