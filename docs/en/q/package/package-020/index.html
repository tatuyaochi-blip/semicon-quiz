Packaging and assembly

Why does warpage from heating during reflow become a problem for large packages?

  1. ABecause the package changes color
  2. BBecause some solder balls fail to join the board, causing connection failures
  3. CBecause the package becomes lighter
Show answer and explanation

Answer: B. Because some solder balls fail to join the board, causing connection failures

Packages are made of materials with different coefficients of thermal expansion, such as the chip, substrate and mold resin, so they warp when heated. Large warpage can keep some solder balls from reaching the board or cause neighboring balls to merge, leading to connection failures. It is an important issue as packages grow larger.
