What is a drawback of making the inference batch size too large?

  1. AWaiting to gather inputs and the longer processing per batch delay each request's response, and memory use increases
  2. BWeight values change and answers become inaccurate
  3. CArithmetic intensity drops and efficiency worsens
Show answer and explanation

Answer: A. Waiting to gather inputs and the longer processing per batch delay each request's response, and memory use increases

A larger batch raises total throughput, but waiting for other inputs to arrive and the longer computation per batch increase the time until each request returns (latency). Memory for intermediate results and the KV cache also grows with batch size. Interactive applications increase the batch only as far as their response-time targets allow.

  • A. Correct. Throughput must be balanced against response time.
  • B. Weights do not change.
  • C. Arithmetic intensity actually rises.
