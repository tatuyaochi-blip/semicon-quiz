Digital Signal Processing Basics

Let k = 0 be the DC bin. When a 1 kHz sine wave sampled at 8 kHz is analyzed with a 256-point DFT, which of the following is the index k of the bin where the peak appears on the positive-frequency side?

  1. A32
  2. B64
  3. C128
Show answer and explanation

Answer: A. 32

The bin spacing is Δf = fs/N = 8000 ÷ 256 = 31.25 Hz, so 1 kHz falls in bin k = 1000 ÷ 31.25 = 32. 1 kHz is an exact multiple of the bin spacing (exactly 32 cycles in 256 samples), so the peak is concentrated in the single bin k = 32 and there is no spectral leakage. For a real signal, a peak of the same size also appears at k = N − 32 = 224, which corresponds to the negative frequency.

  • A. Correct. k = f × N/fs = 1000 × 256/8000 = 32.
  • B. This divides by the Nyquist frequency of 4 kHz instead of 8 kHz (1000 × 256/4000).
  • C. k = N/2 = 128 is the bin of the Nyquist frequency (4 kHz).
