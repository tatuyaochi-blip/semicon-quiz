Digital Signal Processing Basics

The DFT of the 8-point real signal x[n] = {3, 1, 3, 1, 3, 1, 3, 1} is defined as X[k] = Σx[n]e^(−j2πkn/8). Which of the following is the value of X[4], the bin at the Nyquist frequency?

  1. A1
  2. B2
  3. C8
Show answer and explanation

Answer: C. 8

At k = N/2 = 4, e^(−jπn) = (−1)ⁿ, so X[4] = Σ(−1)ⁿx[n] = 3 − 1 + 3 − 1 + 3 − 1 + 3 − 1 = 8. The signal is a DC level of 2 plus a component (−1)ⁿ that alternates by ±1; the alternating component appears in the Nyquist bin and the DC level in X[0] = 16. For a real signal, X[0] and X[N/2] are always real.

  • A. This is the amplitude of the alternating component (X[4]/N = 8/8). With this DFT definition, the value is N times larger.
  • B. This is the mean of the signal (the DC component, X[0]/N = 16/8).
  • C. Correct. Multiplying by (−1)ⁿ and summing gives 8.
