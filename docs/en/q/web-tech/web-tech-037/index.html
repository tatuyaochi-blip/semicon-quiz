Web Technology Basics

A web system is built in three tiers: a web server, an application server and a database server. Which of the following is the processing that the application server mainly handles?

  1. AIt receives user input, performs business processing such as checking logins and registering orders, and produces results using the database
  2. BIt accepts HTTP requests from browsers and returns unchanging files such as images and CSS as they are
  3. CIt stores data in the form of tables and searches or updates it in response to SQL queries from applications
Show answer and explanation

Answer: A. It receives user input, performs business processing such as checking logins and registering orders, and produces results using the database

In a three-tier setup, the web server accepts HTTP requests from users, returns static files and passes requests that need processing to the application server. The application server performs business processing in programs and leaves reading and writing of data to the database server. Separating the roles makes it possible to scale up each tier separately and to place the database where it cannot be reached directly from outside. In small systems, one computer may handle several tiers.

  • A. Correct. It performs the business processing and produces results using data obtained from the database.
  • B. This is the main role of the web server.
  • C. This is the role of the database server.
