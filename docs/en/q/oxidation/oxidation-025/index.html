Oxidation and diffusion

Which defect grows when excess interstitial silicon generated by oxidation is injected into the silicon during thermal oxidation?

  1. ACOP
  2. BOxidation-induced stacking fault (OSF)
  3. CHillock
Show answer and explanation

Answer: B. Oxidation-induced stacking fault (OSF)

When silicon oxidizes, not all silicon atoms are incorporated into the oxide; some are released into the substrate as interstitials. These cluster and grow into stacking faults called oxidation-induced stacking faults (OSFs), which cause leakage current.
