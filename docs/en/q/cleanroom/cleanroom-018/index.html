Cleanrooms and equipment

Which is one correct reason for not letting cleanroom humidity become extremely low?

  1. ABecause mold grows more easily
  2. BBecause static electricity is generated more easily when humidity is too low
  3. CBecause lighting becomes dimmer
Show answer and explanation

Answer: B. Because static electricity is generated more easily when humidity is too low

If the air is too dry, static electricity is generated more easily, causing particles to stick to wafers and devices to be damaged by electrostatic discharge. On the other hand, too much humidity affects resist properties and corrosion, so cleanroom humidity is kept within a set range.
