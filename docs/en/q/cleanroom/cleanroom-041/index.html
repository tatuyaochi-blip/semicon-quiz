Cleanrooms and equipment

In automated transport in a bay-type fab, which pair correctly names transport between bays and transport linking tools within a bay?

  1. AFront-end transport and back-end transport
  2. BInterbay transport and intrabay transport
  3. CWet transport and dry transport
Show answer and explanation

Answer: B. Interbay transport and intrabay transport

Bay-based fabs have combined interbay transport, linking distant bays via stockers, with intrabay transport, linking tools to each other and to stockers within a bay. Because each handoff adds waiting time, recent 300 mm fabs widely use OHTs that handle both and carry FOUPs directly from tool to tool. This is unrelated to the front-end/back-end distinction.

  • A. That is a different matter from front-end and back-end processes.
  • B. Correct. Between bays is interbay; within a bay is intrabay.
  • C. These are not common names for transport categories.
