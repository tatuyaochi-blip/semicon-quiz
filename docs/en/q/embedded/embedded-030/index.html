Embedded Systems & Firmware

What is the main purpose of using an RTOS (real-time operating system) in embedded devices?

  1. ATo display attractive windows on a screen
  2. BTo make average processing speed always faster than a PC OS
  3. CTo switch among multiple tasks by priority so the system can respond within set time limits
Show answer and explanation

Answer: C. To switch among multiple tasks by priority so the system can respond within set time limits

An RTOS divides work into tasks and switches to a higher-priority task as soon as it becomes ready to run. Its purpose is to make sure time-critical work, such as motor control or communication responses, happens reliably within set time limits. It also provides queues for passing data between tasks, mutexes for protecting resources and timed waits. Examples include FreeRTOS, Zephyr and μITRON.

  • A. Displaying graphics is not the main purpose.
  • B. Guaranteeing worst-case time matters more than average speed.
  • C. Correct. Predictable response times are what matter.
