SRAM and flash memory

Which memory is mainly used in USB flash drives and SD cards?

  1. ASRAM
  2. BNAND flash memory
  3. CDRAM
Show answer and explanation

Answer: B. NAND flash memory

USB drives, SD cards and SSDs use NAND flash, an inexpensive high-capacity non-volatile memory, together with a controller that handles error correction and wear leveling. Cheap products may have simple controllers and weaker long-term reliability. DRAM and SRAM are volatile and lose data without power, so they are not used for portable storage.

  • A. SRAM is volatile and mainly used for caches and similar.
  • B. Correct. High-capacity, non-volatile NAND flash is used.
  • C. DRAM is volatile and mainly used as main memory.
