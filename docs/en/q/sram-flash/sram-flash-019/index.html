SRAM and flash memory

In QLC (4 bits per cell) NAND flash, how many threshold voltage states must one cell distinguish?

  1. A4
  2. B8
  3. C16
Show answer and explanation

Answer: C. 16

Storing N bits per cell requires distinguishing 2ᴺ threshold voltage states. For QLC that is 2⁴ = 16 states; SLC has 2, MLC 4 and TLC 8. The more states, the narrower the spacing between them, and the more precise reading and writing must be.
