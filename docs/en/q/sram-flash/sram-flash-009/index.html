SRAM and flash memory

Which correctly describes a property of SRAM?

  1. AIt retains data without refresh while powered, but loses data when the power is turned off
  2. BIt retains data when the power is turned off
  3. CIt needs periodic refresh
Show answer and explanation

Answer: A. It retains data without refresh while powered, but loses data when the power is turned off

SRAM holds data through the positive feedback of a latch, so it needs no refresh while powered, but it is volatile and loses data when power is removed. Access takes around 1 ns, making it the choice for CPU caches and register files. Transistor leakage flows even in standby, so large arrays face standby-power problems and use low-voltage retention modes.
