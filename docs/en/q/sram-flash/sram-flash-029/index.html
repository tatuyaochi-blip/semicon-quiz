SRAM and flash memory

Which non-volatile memory has been integrated on the same chip as logic circuits to store microcontroller programs?

  1. AEmbedded flash memory
  2. BHBM
  3. CGDDR
Show answer and explanation

Answer: A. Embedded flash memory

Microcontrollers have integrated embedded flash memory on the same chip as their logic circuits to store programs and data. Its contents remain when power is off and can be rewritten. In advanced processes, integration has become difficult, and replacement with MRAM and other memories is progressing.
