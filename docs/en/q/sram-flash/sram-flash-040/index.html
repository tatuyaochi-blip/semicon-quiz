SRAM and flash memory

Which correctly describes "bad block management" in NAND flash?

  1. ABad blocks found at manufacturing or during use are recorded, excluded from use and replaced with spare blocks
  2. BChips with even one bad block are not shipped
  3. CBad blocks are repaired with a high voltage
Show answer and explanation

Answer: A. Bad blocks found at manufacturing or during use are recorded, excluded from use and replaced with spare blocks

NAND flash is assumed to contain a certain number of bad blocks from manufacturing, and more appear during use due to wear. The controller records them, excludes them from use and replaces them with spare blocks so the device as a whole works correctly.

  • A. Correct. Bad blocks are avoided and replaced with spares.
  • B. NAND flash is shipped on the assumption that it contains some bad blocks.
  • C. Worn-out blocks cannot be repaired with a voltage.
