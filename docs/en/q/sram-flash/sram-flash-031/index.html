SRAM and flash memory

Which correctly describes flash memory?

  1. AIt is non-volatile memory that retains data after power is removed
  2. BIt is volatile memory that loses data when power is removed
  3. CIt requires periodic refresh
Show answer and explanation

Answer: A. It is non-volatile memory that retains data after power is removed

Flash memory stores information by trapping electrons in a floating gate or charge-trap layer surrounded by insulators, so it is non-volatile and retains data after power-off. DRAM and SRAM are volatile and lose data when power is removed.

  • A. Correct. Flash memory is non-volatile.
  • B. DRAM and SRAM are the memories that lose data at power-off.
  • C. DRAM is the memory that needs periodic refresh.
