SRAM and flash memory

In flash memory erase, what happens to a cell's threshold voltage when electrons are removed from the floating gate or similar layer?

  1. AIt rises
  2. BIt falls
  3. CIt does not change
Show answer and explanation

Answer: B. It falls

When the floating gate holds electrons (negative charge), a larger gate voltage is needed to form a channel, so the threshold voltage is high. Removing electrons during erase lowers the threshold voltage, and injecting electrons during programming raises it.
