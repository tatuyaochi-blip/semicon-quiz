SRAM and flash memory

In TLC and QLC SSDs, what is the main purpose of using part of the space as SLC to absorb writes temporarily?

  1. ATo increase capacity
  2. BTo encrypt data
  3. CTo make writes faster
Show answer and explanation

Answer: C. To make writes faster

TLC and QLC write many bits into each cell, so writing takes time. Part of the free space is therefore used in fast SLC mode: data is written there first and later moved to the TLC or QLC area (SLC cache). If a large amount of data is written continuously and the cache overflows, speed drops.
