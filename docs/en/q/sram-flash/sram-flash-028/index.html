SRAM and flash memory

Which command notifies an SSD of space freed by files deleted by the OS, making garbage collection more efficient?

  1. AECC
  2. BISPP
  3. CTRIM
Show answer and explanation

Answer: C. TRIM

When a file is deleted, the OS only updates its management information, so the SSD does not know the data is no longer needed. Notifying the SSD of the freed space with the TRIM command lets it avoid copying that data during garbage collection, improving write performance and lifespan.
