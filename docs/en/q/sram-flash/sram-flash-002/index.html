SRAM and flash memory

Compared with NOR flash, which is a characteristic of NAND flash memory?

  1. AFast random access, suitable for executing program code directly
  2. BCells are connected in series, so it is easy to make dense and suits high-capacity storage
  3. CIt is volatile memory that loses data when the power is off
Show answer and explanation

Answer: B. Cells are connected in series, so it is easy to make dense and suits high-capacity storage

NAND flash connects memory cells in series and reduces the number of contacts per cell, so the area per bit is small and it suits high capacities. It is used in SSDs and memory cards. NOR flash is the one with fast random reads suited to executing code directly. Both are non-volatile.
