SRAM and flash memory

In multi-level (MLC or TLC) NAND flash, why are the bit patterns assigned to adjacent threshold-voltage states chosen to differ by only one bit?

  1. ATo double the write speed
  2. BTo make erasing unnecessary
  3. CSo that misreading a state as its neighbor causes only a single-bit error
Show answer and explanation

Answer: C. So that misreading a state as its neighbor causes only a single-bit error

In multi-level cells, the threshold voltage distributions can overlap with neighboring states, causing misreads. Assigning bit patterns with a Gray code, in which adjacent states differ by only one bit, means a misread produces only a single-bit error that ECC can easily correct.

  • A. The bit assignment does not double the write speed.
  • B. Erasing is still necessary regardless of the assignment.
  • C. Correct. A Gray code limits the error to a single bit.
