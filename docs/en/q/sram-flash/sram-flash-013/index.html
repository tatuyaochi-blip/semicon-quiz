SRAM and flash memory

Which technique do NAND flash controllers use to cope with the increase in read errors that comes with storing more bits per cell?

  1. AData encryption
  2. BPowerful error-correcting codes (such as LDPC codes)
  3. CFaster clocks
Show answer and explanation

Answer: B. Powerful error-correcting codes (such as LDPC codes)

The more bits stored per cell, the narrower the gaps between threshold-voltage distributions and the more read errors occur. NAND controllers therefore use powerful error correction such as LDPC codes, adding hundreds of bytes of parity per few KB of data. LDPC can use soft-decision information about how likely each bit is, so controllers re-read at shifted read voltages to boost correction capability further.
