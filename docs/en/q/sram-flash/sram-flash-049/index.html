SRAM and flash memory

In 3D NAND, what is the structure called in which the edge of the stack is shaped into steps so that each layer's word line can be connected?

  1. AStaircase structure
  2. BDamascene structure
  3. CTrench structure
Show answer and explanation

Answer: A. Staircase structure

In 3D NAND, hundreds of conductive word-line layers are stacked, so the array edge is etched into a staircase that exposes each layer's top surface for contacts. The steps are formed by repeatedly etching while trimming back the resist, so more layers mean longer processing and more staircase area. Designs split the staircase into multiple rows or add steps in another direction to save area.

  • A. Correct. It is a stepped structure for connecting to each layer.
  • B. Damascene is a process of filling trenches with metal to form wiring.
  • C. A trench is a groove in the substrate, not a structure for connecting to each layer.
