SRAM and flash memory

Which correctly describes "overprovisioning" in an SSD?

  1. AWriting data in two places for redundancy
  2. BInstalling more flash memory than the capacity shown to the user and using the extra area for garbage collection and longer life
  3. CInstalling less flash memory than the displayed capacity
Show answer and explanation

Answer: B. Installing more flash memory than the capacity shown to the user and using the extra area for garbage collection and longer life

Over-provisioning installs more flash than the user-visible capacity and uses the surplus for free blocks, garbage collection and bad-block replacement. Fitting 512 GiB of NAND into a drive sold as 480 GB, for example, leaves about 14% spare. More spare area eases garbage collection, stabilizing write performance and extending life, so enterprise SSDs reserve more.

  • A. Duplicating data is mirroring, a different mechanism.
  • B. Correct. The extra area is used for internal management.
  • C. With less than the displayed capacity, the stated capacity could not be used.
