SRAM and flash memory

In NAND flash memory, what is needed to write new data to a page that already contains data?

  1. AIt can simply be overwritten
  2. BOverwrite it with a lower write voltage
  3. CErase the block containing the page first, then write
Show answer and explanation

Answer: C. Erase the block containing the page first, then write

In NAND flash, programming can only raise a cell's threshold voltage, and erasing is needed to bring it back. Erasing can only be done in blocks larger than a page, so overwriting is impossible. SSD controllers write new data to another free page, mark the old page invalid, and erase blocks later in bulk.

  • A. NAND flash cannot be overwritten.
  • B. Lowering the voltage does not make overwriting possible.
  • C. Correct. Data can only be written after erasing.
