SRAM and flash memory

In NAND flash memory, what is needed to write new data to a page that already contains data?

  1. AErase the block containing the page first, then write
  2. BIt can simply be overwritten
  3. COverwrite it with a lower write voltage
Show answer and explanation

Answer: A. Erase the block containing the page first, then write

Programming NAND can only raise threshold voltages (1→0); returning requires an erase, and erases happen only in blocks larger than a page, so in-place overwriting is impossible. The SSD controller writes new data to a free page, updates the logical-to-physical map (FTL) to invalidate the old page, and erases blocks in bulk later. This mechanism underlies SSD performance and lifetime management.

  • A. Correct. Data can only be written after erasing.
  • B. NAND flash cannot be overwritten.
  • C. Lowering the voltage does not make overwriting possible.
