SRAM and flash memory

What is the main reason flash memory has a limited number of rewrite cycles?

  1. ARepeated rewriting degrades the tunnel oxide that electrons pass through
  2. BThe capacitor's capacitance increases
  3. CThe wiring stretches
Show answer and explanation

Answer: A. Repeated rewriting degrades the tunnel oxide that electrons pass through

Each program or erase drives electrons through the tunnel oxide at fields around 10 MV/cm, and some become trapped or create defects. Repeated cycling narrows the threshold-voltage window and makes stored electrons leak more easily (stress-induced leakage current, SILC). Endurance is therefore limited, and multilevel cells with narrow state gaps suffer most: about 100,000 cycles for SLC versus a few thousand for TLC.
