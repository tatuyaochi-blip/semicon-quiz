SRAM and flash memory

What is the unit in which data is erased in NAND flash memory?

  1. ABit
  2. BBlock
  3. CByte
Show answer and explanation

Answer: B. Block

In NAND flash, writing and reading are done in pages, but erasing is done in blocks made up of multiple pages. Even to rewrite part of a block, the whole block must be copied elsewhere and erased, so management by the controller is important.
