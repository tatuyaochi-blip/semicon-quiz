SRAM and flash memory

What is a typical use of NOR flash memory?

  1. AStoring large videos and photos
  2. BMain memory of a PC
  3. CStoring program code for devices (such as boot programs)
Show answer and explanation

Answer: C. Storing program code for devices (such as boot programs)

NOR flash offers fast random access, and a CPU can read and execute programs directly from it, so it is used to store device boot programs and microcontroller firmware. NAND flash is used for storing large amounts of data.
