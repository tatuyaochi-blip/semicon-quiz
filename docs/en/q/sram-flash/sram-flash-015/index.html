SRAM and flash memory

Which correctly describes garbage collection in an SSD?

  1. AMoving valid data out of blocks that contain invalid data, then erasing those blocks to create free space
  2. BRemoving computer viruses
  3. CCompressing data
Show answer and explanation

Answer: A. Moving valid data out of blocks that contain invalid data, then erasing those blocks to create free space

NAND flash cannot be overwritten, and erasing can only be done in blocks. Old versions of rewritten data remain as invalid pages, so the controller gathers the valid data into another block and then erases the original block to create free space for new writes.
