SRAM and flash memory

In NAND flash, which programming method applies repeated program pulses with gradually increasing voltage, checking the threshold voltage after each one?

  1. AECC
  2. BISPP (incremental step pulse programming)
  3. CTRIM
Show answer and explanation

Answer: B. ISPP (incremental step pulse programming)

ISPP starts with a low-voltage pulse and increases the voltage slightly with each pulse, verifying the threshold voltage after each one. Cells that reach their target are not programmed further, so the threshold voltage distributions are kept narrow. It is essential for multi-level cells.
