SRAM and flash memory

Which correctly describes "write amplification" in an SSD?

  1. AThe write speed doubling
  2. BThe write voltage becoming higher than normal
  3. CThe amount of data actually written to flash exceeding the amount written by the host
Show answer and explanation

Answer: C. The amount of data actually written to flash exceeding the amount written by the host

Because flash cannot be overwritten and is erased in blocks, extra writes occur, such as copying valid data to another block during garbage collection. As a result, the amount actually written exceeds what the host wrote. The larger this ratio, the shorter the life and the lower the performance.

  • A. Write amplification degrades rather than improves performance.
  • B. It has nothing to do with voltage.
  • C. Correct. More data is actually written than the host wrote.
