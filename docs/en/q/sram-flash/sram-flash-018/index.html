SRAM and flash memory

In NAND flash, what is the phenomenon in which repeatedly reading the same block gradually shifts the threshold voltages of cells that are not being read?

  1. AWear leveling
  2. BRead disturb
  3. CGarbage collection
Show answer and explanation

Answer: B. Read disturb

During a NAND read, a voltage is applied to unselected cells to make them conduct, so repeated reads cause weak programming and their threshold voltages rise. This is called read disturb. The controller tracks the number of reads and rewrites data when necessary.
