SRAM and flash memory

What is the most appropriate main use of SRAM?

  1. ARecording media for digital cameras
  2. BLong-term storage of large amounts of data
  3. CCPU cache memory
Show answer and explanation

Answer: C. CPU cache memory

SRAM needs no refresh, is built in the same process as logic and can be accessed in about 1 ns, so it is used for CPU caches (L1–L3) and register files. Some recent CPUs carry tens to hundreds of MB of L3 cache, and products that stack extra SRAM dies vertically have appeared. Its large area per bit and high cost make it unsuitable for bulk main memory.

  • A. Recording media use non-volatile NAND flash.
  • B. SRAM is volatile and cannot be used for long-term storage.
  • C. Correct. Fast SRAM is used for caches.
