SRAM and flash memory

Which interface standard, built on PCI Express, is widely used to connect high-speed SSDs to the host?

  1. AIDE
  2. BUSB 1.1
  3. CNVMe
Show answer and explanation

Answer: C. NVMe

NVMe (NVM Express) is an interface standard designed to handle flash memory efficiently over PCI Express. It can process many command queues in parallel, achieving lower latency and higher bandwidth than SATA (AHCI), which was designed for HDDs.

  • A. IDE is an old parallel interface for HDDs.
  • B. USB 1.1 is a slow general-purpose interface.
  • C. Correct. It is the standard for high-speed PCIe SSDs.
