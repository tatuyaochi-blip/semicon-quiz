Wireless Communication Basics

In 64QAM, which is the number of bits that can be sent per symbol?

  1. A6 bits
  2. B8 bits
  3. C64 bits
Show answer and explanation

Answer: A. 6 bits

In M-ary modulation, each symbol sends one of M possible signal points, so the number of bits it carries is log₂ M. 64QAM has 64 signal points, so it carries log₂ 64 = 6 bits. The 64 points form a grid with 8 levels on each of the in-phase (I) and quadrature (Q) axes. Similarly, 16QAM carries 4 bits and 256QAM carries 8 bits.

  • A. Correct. 2⁶ = 64, so it is 6 bits.
  • B. This is the number of levels (8) on one of the I or Q axes. 256QAM is the scheme that sends 8 bits per symbol.
  • C. This is the number of signal points itself. The number of bits is the base-2 logarithm of the number of points.
