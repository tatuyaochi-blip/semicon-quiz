DRAM

Which correctly describes the structure of a typical 1-bit DRAM memory cell?

  1. AOne transistor and one capacitor
  2. BSix transistors
  3. COne transistor with a floating gate
Show answer and explanation

Answer: A. One transistor and one capacitor

A DRAM cell consists of one transistor and one capacitor (1T1C) and stores one bit according to whether the capacitor is charged. Six transistors is the SRAM cell, and a floating-gate transistor is the flash memory cell.
