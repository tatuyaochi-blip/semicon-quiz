DRAM

What does "RAM (random access memory)" in DRAM mean?

  1. AMemory in which any address can be read or written directly in roughly the same time
  2. BMemory that can only be read sequentially from the beginning
  3. CRead-only memory that cannot be rewritten
Show answer and explanation

Answer: A. Memory in which any address can be read or written directly in roughly the same time

Random access means any location can be reached directly by its address, regardless of order—as opposed to sequential access, as with magnetic tape. Real DRAM is not perfectly uniform, though: consecutive accesses to the same row are fast, while switching rows is slower. Read-only memory is called ROM, although flash memory and similar ROM-family devices can be rewritten.

  • A. Correct. Any address can be accessed directly.
  • B. Memory that can only be read in order is sequential-access memory.
  • C. Read-only memory is ROM.
