DRAM

Which correctly describes the read operation of DRAM?

  1. AReading does not change the cell's charge at all
  2. BReading changes the cell's charge, so the data is amplified by a sense amplifier and written back to the cell
  3. CReading uses tunneling current at high voltage
Show answer and explanation

Answer: B. Reading changes the cell's charge, so the data is amplified by a sense amplifier and written back to the cell

In DRAM, connecting the cell capacitor to the bit line shares its charge with the bit line, destroying the original state (destructive read). The sense amplifier therefore amplifies the tiny voltage difference to determine the data and at the same time writes the amplified value back to the cell.
