DRAM

In DRAM cell arrays, which bit-line arrangement places the paired bit lines side by side within the same array?

  1. ADivided word-line architecture
  2. BOpen bit-line architecture
  3. CFolded bit-line architecture
Show answer and explanation

Answer: C. Folded bit-line architecture

In the folded bit-line scheme, the pair of bit lines feeding a sense amplifier runs side by side in the same array, so noise couples equally onto both and cancels differentially. But each word line contacts cells on only one bit line of the pair, so the cell area is 8F². The open bit-line scheme, with the pair in separate arrays, is more noise-sensitive but allows 6F² cells and is the current mainstream.

  • A. A divided word line is not a bit-line pairing arrangement.
  • B. The open bit-line architecture places the paired lines in separate arrays on either side of the sense amplifier.
  • C. Correct. The paired bit lines run side by side in the same array.
