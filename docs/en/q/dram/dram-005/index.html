DRAM

Which correctly describes a property of DRAM?

  1. AIt is volatile memory that loses data when the power is turned off
  2. BIt is non-volatile memory that retains data when the power is turned off
  3. CIt is read-only memory that cannot be rewritten
Show answer and explanation

Answer: A. It is volatile memory that loses data when the power is turned off

DRAM stores information as charge on a capacitor and is volatile: when power is turned off, the charge is not maintained and the data is lost. Even with power on, the charge gradually leaks away, so refresh is needed. Non-volatile memories such as flash retain data without power.
