DRAM

Which correctly describes the idea of "8n prefetch" used in memories such as DDR4 SDRAM?

  1. AData eight times the I/O width is fetched from the internal array at once and output in sequence at high speed through the external pins
  2. BEight refresh operations are performed together
  3. CThe same data is written to eight chips
Show answer and explanation

Answer: A. Data eight times the I/O width is fetched from the internal array at once and output in sequence at high speed through the external pins

Because the DRAM cell array itself cannot run much faster, the device internally reads eight times the I/O width (8n) in a single access and sends it out in sequence over the fast external interface. This raises the external transfer rate without speeding up the internal array.

  • A. Correct. Wide data is read internally and output quickly externally.
  • B. It is not a mechanism for grouping refreshes.
  • C. It is not a mechanism for writing the same data to several chips.
