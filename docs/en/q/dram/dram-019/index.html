DRAM

Which is a characteristic of GDDR, used as graphics memory for GPUs?

  1. AIt is a standard that emphasizes data transfer bandwidth (speed)
  2. BIt retains data when the power is turned off
  3. CIt is slow but very cheap
Show answer and explanation

Answer: A. It is a standard that emphasizes data transfer bandwidth (speed)

GDDR is a DRAM standard that emphasizes data transfer speed so that GPUs can handle large amounts of image data quickly. Its per-pin data rate is higher than ordinary DDR, and it is used in graphics cards and game consoles. When even more bandwidth is needed, HBM is used.
