DRAM

What does an error-correcting code (ECC) used in memory do?

  1. ACompresses data to increase capacity
  2. BAdds redundant bits to data to detect and correct bit errors
  3. CEncrypts data
Show answer and explanation

Answer: B. Adds redundant bits to data to detect and correct bit errors

ECC adds check bits to data so that errors can be detected and corrected when the data is read. To reduce the impact of soft errors and defects due to scaling, ECC is used in server memory, and DDR5 also builds ECC into the chip itself.
