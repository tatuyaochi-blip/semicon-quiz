DRAM

What does the "S" (synchronous) in SDRAM indicate?

  1. AIt retains data after power-off
  2. BIt operates in sync with an external clock signal
  3. CIt has the same cell structure as SRAM
Show answer and explanation

Answer: B. It operates in sync with an external clock signal

SDRAM is DRAM that accepts commands and transfers data in sync with a clock signal. Synchronization enabled pipelining and burst transfers, making it faster. DDR SDRAM developed this idea further.

  • A. SDRAM is also volatile and loses data at power-off.
  • B. Correct. It is DRAM that operates in sync with a clock.
  • C. SDRAM cells use the same 1T1C structure as ordinary DRAM.
