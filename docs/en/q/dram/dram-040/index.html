DRAM

What is the main effect of running PC memory in dual-channel mode?

  1. ATwo memory channels are used simultaneously, roughly doubling peak bandwidth
  2. BThe memory latency is halved
  3. CThe memory capacity doubles
Show answer and explanation

Answer: A. Two memory channels are used simultaneously, roughly doubling peak bandwidth

In dual-channel mode the memory controller uses two independent channels at once, roughly doubling peak bandwidth (51.2 GB/s for DDR4-3200). To benefit, modules of equal capacity are installed in matched pairs, one per channel. The gain is largest for bandwidth-hungry work such as integrated graphics, and server processors offer 8–12 channels. Capacity and latency are unchanged.

  • A. Correct. Two channels in parallel roughly double the bandwidth.
  • B. The latency of a single access hardly changes.
  • C. Capacity is the total of the installed modules and is not doubled by channels.
