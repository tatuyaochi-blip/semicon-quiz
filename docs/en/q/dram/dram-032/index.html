DRAM

In PCs and servers, what is DRAM mainly used for?

  1. ARegisters inside the CPU
  2. BMain memory that holds running programs and their data
  3. CLong-term storage that retains data after power-off
Show answer and explanation

Answer: B. Main memory that holds running programs and their data

DRAM is large and fairly fast, so it serves as main memory holding the programs and data a CPU is running—8–64 GB in PCs and up to several TB in a single server. Being volatile, it relies on SSDs or HDDs for long-term storage, while CPU registers and caches use SRAM and flip-flops. It sits in the middle of the memory hierarchy, which combines memories of different speed, capacity and cost.

  • A. CPU registers are built from flip-flops and similar circuits.
  • B. Correct. DRAM is used as main memory.
  • C. DRAM is volatile and loses data at power-off, so it is unsuited to long-term storage.
