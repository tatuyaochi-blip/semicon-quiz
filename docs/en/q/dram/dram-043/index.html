DRAM

In most current PC processors, where is the memory controller that controls DRAM located?

  1. AInside the DRAM chips
  2. BInside the processor chip (package)
  3. CInside the SSD
Show answer and explanation

Answer: B. Inside the processor chip (package)

The memory controller, once located in the chipset (northbridge) on the motherboard, is now generally integrated into the processor. This shortens the path between CPU and memory and reduces latency.

  • A. DRAM chips follow commands sent by an external memory controller.
  • B. Correct. It is now generally integrated into the processor.
  • C. An SSD controller manages flash memory and does not control DRAM main memory.
