What does the DRAM timing parameter tRCD represent?

  1. AThe refresh period
  2. BThe time from closing a row until the next row can be opened
  3. CThe time from activating a row until it can be read or written using a column address
Show answer and explanation

Answer: C. The time from activating a row until it can be read or written using a column address

tRCD (RAS to CAS delay) is the time required after an activate command opens a row before read or write commands can be issued to that row. The time from closing a row to opening the next is tRP (precharge time).

  • A. The refresh period is specified by parameters such as tREFI.
  • B. The time from closing a row to opening the next is tRP.
  • C. Correct. It is the time from row activation to column access.
