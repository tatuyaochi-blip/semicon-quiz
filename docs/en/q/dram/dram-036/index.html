DRAM

In typical DRAM standards, which is closest to the period within which every cell must be refreshed once? (Normal temperature range)

  1. AAbout 64 ms
  2. BAbout 64 µs
  3. CAbout 64 s
Show answer and explanation

Answer: A. About 64 ms

DDR DRAMs must refresh every row within about 64 ms in the normal temperature range. In practice the controller issues 8192 refresh commands within that window (about every 7.8 µs in DDR4, tREFI), each refreshing several rows. The time per refresh command (tRFC) grows with density, reaching several hundred nanoseconds at 16 Gbit.

  • A. Correct. All cells are normally refreshed within 64 ms.
  • B. 64 µs is too short; refresh would take up too much time.
  • C. 64 s is too long for cells to retain their data.
