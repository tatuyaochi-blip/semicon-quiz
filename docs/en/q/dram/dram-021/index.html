DRAM

In DRAM, what is the main reason for splitting the address into row and column addresses and supplying them in turn through the same pins?

  1. ATo reduce the number of address pins
  2. BTo eliminate the need for refresh
  3. CTo encrypt the data
Show answer and explanation

Answer: A. To reduce the number of address pins

DRAM has a large capacity, so supplying the whole address at once would require many pins. Supplying the row and column addresses through the same pins at different times (address multiplexing) reduces the number of pins. It also matches DRAM's internal operation of activating a row and then selecting a column.
