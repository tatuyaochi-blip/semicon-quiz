DRAM

How many 8-bit-wide (x8) DRAM chips are needed per rank to form a 64-bit data bus (without ECC)?

  1. A4
  2. B64
  3. C8
Show answer and explanation

Answer: C. 8

64 bits ÷ 8 bits = 8, so eight x8 chips accessed together form a 64-bit bus; it would take 16 x4 chips or four x16 chips. ECC modules add chips for the 8 check bits—nine x8 chips (72 bits wide). DDR5 modules are split into two 32-bit subchannels, each 40 bits wide with ECC.

  • A. Four chips would give only a 32-bit width.
  • B. 64 chips would be needed with 1-bit-wide (x1) chips.
  • C. Correct. 64 ÷ 8 = 8 chips.
