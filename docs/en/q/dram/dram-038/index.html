DRAM

Which correctly describes a DRAM burst transfer?

  1. AA single read command transfers several consecutive data words, one after another on successive clocks
  2. BData is compressed before transfer
  3. CRefresh and data transfer are performed at the same time
Show answer and explanation

Answer: A. A single read command transfers several consecutive data words, one after another on successive clocks

In a burst transfer, one read or write command transfers several data words at consecutive addresses (for example, 8) on successive clocks. Because a command is not needed for each word, blocks of data such as cache lines can be transferred efficiently.

  • A. Correct. One command transfers consecutive data together.
  • B. DRAM burst transfer does not compress data.
  • C. Normal reads and writes cannot be performed during refresh.
