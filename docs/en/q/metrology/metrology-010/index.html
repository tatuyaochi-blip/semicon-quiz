Metrology and analysis

Which can be evaluated from C-V (capacitance-voltage) measurements of a MOS capacitor?

  1. APattern linewidth
  2. BOxide thickness, interface states, substrate doping concentration and more
  3. CThe number of particles on the wafer surface
Show answer and explanation

Answer: B. Oxide thickness, interface states, substrate doping concentration and more

Measuring capacitance while varying the voltage applied to a MOS capacitor shows capacitance changing with the accumulation, depletion and inversion states. From the curve, oxide thickness, flat-band voltage, interface state density, substrate doping concentration and more can be evaluated. It is a basic technique for evaluating gate dielectric quality.
