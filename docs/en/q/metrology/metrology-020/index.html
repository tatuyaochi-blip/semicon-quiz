Metrology and analysis

Which technique evaluates whether a measuring instrument's repeatability and reproducibility are small enough compared with the process variation to be controlled?

  1. APareto analysis
  2. BGage R&R (measurement system analysis)
  3. CFMEA
Show answer and explanation

Answer: B. Gage R&R (measurement system analysis)

Measured variation includes not only process variation but also measurement-system variation. Gauge R&R evaluates repeatability (variation when the same sample is measured repeatedly) and reproducibility (variation across operators or tools). As a guideline, measurement variation below 10% of the tolerance is good, while above 30% the gauge is unfit for process control. Pareto analysis and FMEA serve other purposes.
