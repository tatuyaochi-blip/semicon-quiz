Metrology and analysis

Which function captures SEM images of defects found in inspection and automatically classifies their types from the images?

  1. AATPG
  2. BAutomatic defect classification (ADC)
  3. CAPC
Show answer and explanation

Answer: B. Automatic defect classification (ADC)

Defect inspection can flag thousands of defects on a single wafer, and tracing their causes requires classification by type. Automatic defect classification (ADC) sorts review-SEM images into categories such as particles, pattern defects and scratches, speeding identification of the responsible process or tool. Machine learning is increasingly used. ATPG generates test patterns and APC is advanced process control.
