Information Security Basics

Which combination correctly describes CVE and CVSS, used in vulnerability management?

  1. ACVE is a common identifier assigned to each vulnerability, and CVSS is a common method that rates the severity of a vulnerability with a number from 0.0 to 10.0
  2. BCVE is a number that rates the severity of a vulnerability, and CVSS is a vulnerability identifier
  3. CBoth CVE and CVSS are names of definition files that antivirus software uses to recognize malware
Show answer and explanation

Answer: A. CVE is a common identifier assigned to each vulnerability, and CVSS is a common method that rates the severity of a vulnerability with a number from 0.0 to 10.0

CVE (Common Vulnerabilities and Exposures) is an identifier of the form "CVE-year-number" assigned to each publicly disclosed vulnerability, so that the same vulnerability can be referred to by the same number across products and organizations. CVSS (Common Vulnerability Scoring System) is a common method that rates the severity of a vulnerability with a number from 0.0 to 10.0, based on factors such as the conditions needed for an attack and the impact on confidentiality, integrity and availability. The CVSS base score reflects the nature of the vulnerability itself, so the order in which fixes are applied is decided by also considering how dangerous it actually is in one's own environment (for example, whether the device is reachable from the internet, or whether attacks have actually been observed). Vulnerability management repeats a cycle: keeping an inventory of the software and versions in use (an asset register), gathering information on new vulnerabilities, assessing their impact, applying patches and confirming that they were applied.

  • A. Correct. CVE is a vulnerability identifier, and CVSS is a method for rating severity as a number.
  • B. The two descriptions are swapped.
  • C. Neither is a definition file. CVE is an identifier and CVSS is a method for rating severity.
