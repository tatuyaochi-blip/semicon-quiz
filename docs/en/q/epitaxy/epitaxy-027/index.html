Epitaxial growth

Compared with thermal diffusion, what is an advantage of adding dopants during epitaxial growth?

  1. AIt is always cheaper
  2. BIt is easier to create abrupt changes in concentration with depth
  3. CUniform concentration cannot be achieved
Show answer and explanation

Answer: B. It is easier to create abrupt changes in concentration with depth

In thermal diffusion, dopants spread from the surface inward, so concentration changes gradually. In epitaxial growth, switching the amount of dopant gas during growth changes the concentration layer by layer, creating abrupt concentration changes and structures with heavily doped layers buried inside.
