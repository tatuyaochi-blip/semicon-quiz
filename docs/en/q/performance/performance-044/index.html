Performance Analysis

Benchmarks on a laptop vary widely between runs of the same program. Which pairs a CPU-side cause with a countermeasure correctly?

  1. AThe CPU instruction set changes each run; fix the instruction set
  2. BThe number of CPU cores changes each run; add cores
  3. CFrequency changes from turbo operation and temperature; fix the frequency or measure under thermally settled conditions
Show answer and explanation

Answer: C. Frequency changes from turbo operation and temperature; fix the frequency or measure under thermally settled conditions

Modern CPUs automatically raise and lower frequency according to thermal and power headroom. Starting cool, turbo makes runs fast; as the chip heats up during repeated runs, frequency drops, so the same program yields different results each time. To see the effect of a change correctly, fix the frequency, match power settings, wait for temperatures to settle and take many measurements for statistics.

  • A. The instruction set does not change between runs.
  • B. The core count does not change.
  • C. Correct. Power settings also affect results.
