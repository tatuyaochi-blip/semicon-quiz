Performance Analysis

What does the STREAM benchmark mainly measure?

  1. AThe CPU's peak floating-point rate
  2. BThe memory bandwidth actually achieved when copying or adding large arrays
  3. CStorage capacity
Show answer and explanation

Answer: B. The memory bandwidth actually achieved when copying or adding large arrays

STREAM performs four simple operations, copy, scale, add and a combination, on large arrays that do not fit in cache and measures bytes read and written per second. With almost no computation, results are determined by memory bandwidth. It shows how much bandwidth is actually usable compared with the theoretical figure and supplies the slope of the slanted line in the Roofline model.

  • A. It does not measure arithmetic speed.
  • B. Correct. It indicates usable bandwidth.
  • C. It measures bandwidth, not capacity.
