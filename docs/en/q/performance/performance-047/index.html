Performance Analysis

When choosing servers for a data center, which is NOT a consideration beyond peak performance?

  1. APerformance per watt and electricity costs including cooling
  2. BPreference for the server chassis color
  3. CTotal cost of ownership from purchase to disposal
Show answer and explanation

Answer: B. Preference for the server chassis color

Data centers run servers for years, so total cost of ownership, including electricity, cooling, floor space and maintenance as well as purchase price, is what matters. Comparisons therefore often focus on performance per watt or per dollar on real workloads rather than peak performance. Performance evaluation must begin by deciding what matters most.

  • A. This is an important consideration.
  • B. Correct. It is irrelevant to performance or cost evaluation.
  • C. This is an important consideration.
