Performance Analysis

When comparing CPU performance by instructions executed per second (millions of instructions per second), what should be kept in mind?

  1. ADifferent instruction sets do different amounts of work per instruction, so more instructions per second does not guarantee a program finishes sooner
  2. BA CPU with a larger value is always faster on any program
  3. CThe value represents memory capacity
Show answer and explanation

Answer: A. Different instruction sets do different amounts of work per instruction, so more instructions per second does not guarantee a program finishes sooner

Instructions per second is an intuitive metric, but different instruction sets need different numbers of instructions for the same work. A CPU using many simple instructions tends to score higher without necessarily processing faster. Even within one instruction set, the value changes with each program's instruction mix. The most reliable comparison is to run the same program and measure the time.

  • A. Correct. What matters is time to complete the same work.
  • B. Results vary with instruction content and program.
  • C. It has nothing to do with memory capacity.
