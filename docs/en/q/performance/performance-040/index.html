Performance Analysis

What is the phenomenon called in which adding a mechanism to measure performance changes the behavior of the program being measured?

  1. ACache coherence
  2. BThe probe effect (observer effect)
  3. CPipelining
Show answer and explanation

Answer: B. The probe effect (observer effect)

Measurement actions such as printing logs, inserting timing code or stopping in a debugger consume time and cache themselves and change timing. So measured behavior may differ from unmeasured behavior, and timing-dependent bugs such as data races may vanish only while being measured. It is important to choose low-impact methods such as sampling or performance counters and to check how large the measurement's influence is.

  • A. That is a cache consistency mechanism.
  • B. Correct. Measurement impact must be minimized.
  • C. That is overlapping instruction execution.
