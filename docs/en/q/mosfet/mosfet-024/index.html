MOSFET

How are the transistors connected in a CMOS two-input NAND gate?

  1. ATwo pMOS in series and two nMOS in parallel
  2. BTwo pMOS in parallel and two nMOS in series
  3. CAll four in parallel
Show answer and explanation

Answer: B. Two pMOS in parallel and two nMOS in series

A NAND outputs 0 only when both inputs are 1, so nMOS transistors are placed in series between the output and ground so the output connects to 0 only when both are on. pMOS transistors are placed in parallel between the output and supply so the output connects to 1 if either input is 0. A NOR uses the opposite connection.
