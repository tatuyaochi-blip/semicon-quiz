MOSFET

How does a MOSFET behave in the linear region, where the drain-source voltage VDS is sufficiently small?

  1. ALike a variable resistor whose resistance changes with gate voltage
  2. BLike a constant-current source independent of VDS
  3. CLike a diode that conducts in only one direction
Show answer and explanation

Answer: A. Like a variable resistor whose resistance changes with gate voltage

In the linear region drain current is nearly proportional to VDS, and the slope—conductance μCox(W/L)(VGS − Vth)—changes with gate voltage, so the device acts as a gate-controlled variable resistor. A switch's on state lies in this region, and on-resistance falls as gate voltage rises. The property is also used in analog switches and variable-gain circuits. When VDS exceeds VGS − Vth, the device enters saturation.
