MOSFET

What is the advantage of a transmission gate, which connects an nMOS and a pMOS in parallel?

  1. AIt can pass both 0 and 1 without voltage loss
  2. BIt can amplify the signal current
  3. CIt can store data
Show answer and explanation

Answer: A. It can pass both 0 and 1 without voltage loss

An nMOS alone loses a threshold voltage when passing a 1 (high voltage), and a pMOS alone suffers a similar loss when passing a 0 (low voltage). Connecting both in parallel lets each compensate for the other, so both 0 and 1 are passed at full voltage. Transmission gates are used in multiplexers, latches and similar circuits.
