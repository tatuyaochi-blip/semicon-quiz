MOSFET

What is the effect in which the gate-drain capacitance appears (1 + gain) times larger when seen from the input of an amplifier?

  1. AEarly effect
  2. BMiller effect
  3. CHall effect
Show answer and explanation

Answer: B. Miller effect

In an inverting amplifier, a voltage change of (1 + gain) times the input voltage appears across a capacitance between input and output, so the capacitance looks larger from the input side. This is the Miller effect, which reduces the gain of amplifiers at high frequencies.
