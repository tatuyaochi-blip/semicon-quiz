MOSFET

How should the dimensions be changed to increase a MOSFET's drain current?

  1. AMake the gate width W narrower and the gate length L longer
  2. BDimensions do not affect drain current
  3. CMake the gate width W wider and the gate length L shorter
Show answer and explanation

Answer: C. Make the gate width W wider and the gate length L shorter

Drain current is roughly proportional to W/L (gate width ÷ gate length). A wider gate widens the current path, and a shorter gate shortens the distance carriers travel, both increasing current. Widening W also increases gate capacitance and area proportionally. L is usually the minimum for the technology, but analog circuits use longer L to improve output resistance and matching. In FinFETs, effective width is set by the number of fins.
