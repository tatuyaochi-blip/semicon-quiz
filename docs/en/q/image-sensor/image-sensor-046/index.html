Image sensors and optical devices

Which image sensor detects only changes in brightness at each pixel and asynchronously outputs information only from pixels that changed?

  1. ALine sensor
  2. BCCD image sensor
  3. CEvent-based vision sensor
Show answer and explanation

Answer: C. Event-based vision sensor

An event-based vision sensor (dynamic vision sensor) does not read out every pixel in fixed frames; only pixels whose brightness changes output their position and time as an event. This keeps data volume low and provides very high time resolution, so it is used for detecting fast motion and similar tasks.

  • A. A line sensor has pixels in a single row and is used in scanners and the like.
  • B. A CCD reads out all pixel charges in sequence, frame by frame.
  • C. Correct. Only pixels that change output data, asynchronously.
