Image sensors and optical devices

From the output of a sensor with color filters such as a Bayer array, what is the process called that estimates all of the red, green and blue values for each pixel from surrounding pixels?

  1. ACorrelated double sampling
  2. BDemosaicing (color interpolation)
  3. CWhite balance
Show answer and explanation

Answer: B. Demosaicing (color interpolation)

In a Bayer array, each pixel has information for only one color, so the missing two colors must be estimated from surrounding pixels. This process is called demosaicing (color interpolation). The method used affects false color in fine detail and perceived sharpness.

  • A. Correlated double sampling is a readout process that removes pixel reset noise and the like.
  • B. Correct. It fills in the missing colors from surrounding pixels.
  • C. White balance corrects color tones to match the light source.
