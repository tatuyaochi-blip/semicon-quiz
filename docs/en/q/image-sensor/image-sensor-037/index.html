Image sensors and optical devices

What is the main advantage of the scheme used in many CMOS image sensors in which each pixel column has its own ADC for parallel conversion?

  1. AColor filters become unnecessary
  2. BPixel size can be doubled
  3. CCompared with converting every pixel in turn with one ADC, a high frame rate is achieved with slower ADCs
Show answer and explanation

Answer: C. Compared with converting every pixel in turn with one ADC, a high frame rate is achieved with slower ADCs

Column-parallel ADC architectures place an ADC at each column and convert an entire row at once. With thousands of columns working in parallel, each ADC has a full row time (a few µs) per conversion, so slow, low-power, low-noise circuits achieve high overall frame rates. Single-slope designs with a comparator and counter are common, and calibrating column-to-column variation is important.

  • A. Color filters are still needed to obtain color information.
  • B. It is unrelated to pixel size.
  • C. Correct. Parallel conversion speeds things up.
