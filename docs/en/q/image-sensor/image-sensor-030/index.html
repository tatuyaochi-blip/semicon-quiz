Image sensors and optical devices

Which semiconductor laser has a built-in diffraction grating so that it oscillates stably at a single wavelength for optical communication?

  1. ALED
  2. BDFB laser (distributed feedback laser)
  3. COrganic EL
Show answer and explanation

Answer: B. DFB laser (distributed feedback laser)

A DFB laser incorporates a grating with a period of a few hundred nm near the active layer, strongly feeding back only the wavelength set by the grating period so it lases in a single mode. Ordinary Fabry-Pérot lasers, which resonate between facets, emit multiple wavelengths, but DFB lasers have narrow spectra that resist mode hopping with temperature or current, so they serve long-haul fiber links and wavelength-division multiplexing (WDM).
