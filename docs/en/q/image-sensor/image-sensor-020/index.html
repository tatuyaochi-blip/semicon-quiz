Image sensors and optical devices

Which is a characteristic of an OLED (organic EL) display?

  1. AIt displays images by blocking backlight with liquid crystals
  2. BEach pixel emits its own light, so no backlight is needed
  3. CIt displays images only by reflecting ambient light
Show answer and explanation

Answer: B. Each pixel emits its own light, so no backlight is needed

An OLED display passes current through layers of organic material to make each pixel emit light. Without a backlight, it can be thin, and black is shown by turning pixels completely off, giving high contrast. The transistor circuits that drive each pixel are built on a glass or similar substrate.
