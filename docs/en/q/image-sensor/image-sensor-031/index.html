Image sensors and optical devices

Which correctly describes a "12-megapixel" image sensor?

  1. AAbout 12 million light-receiving pixels are arranged on it
  2. BIt can capture 12 million images per second
  3. CIt can distinguish 12 million colors
Show answer and explanation

Answer: A. About 12 million light-receiving pixels are arranged on it

Pixel count is the number of photosites on the sensor; 12 megapixels is, for example, 4,000 × 3,000. With a Bayer filter, each pixel measures only one color, so color resolution is lower. Image quality depends not only on pixel count but on sensor size, pixel size and the lens. Capture speed is the frame rate, and the number of colors depends on bit depth—separate specifications.

  • A. Correct. About 12 million pixels are arranged on it.
  • B. Images per second is expressed by the frame rate.
  • C. The number of distinguishable colors depends on gradation, not pixel count.
