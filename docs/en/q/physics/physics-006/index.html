Semiconductor physics

Which correctly describes how the resistivity of an intrinsic semiconductor depends on temperature?

  1. AResistivity decreases as temperature rises
  2. BResistivity increases as temperature rises
  3. CResistivity is constant regardless of temperature
Show answer and explanation

Answer: A. Resistivity decreases as temperature rises

In an intrinsic semiconductor, the number of carriers excited from the valence band to the conduction band rises sharply with temperature, so resistivity decreases. In metals the number of carriers is nearly constant and scattering by lattice vibrations increases with temperature, so resistivity increases instead. This difference is a key feature of semiconductors.
