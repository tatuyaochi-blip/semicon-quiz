Ion implantation

In a typical ion implanter, in what order do ions pass through the system?

  1. AIon source → mass analysis → accelerator → scanning → wafer
  2. BAccelerator → ion source → mass analysis → wafer
  3. CMass analysis → ion source → wafer → accelerator
Show answer and explanation

Answer: A. Ion source → mass analysis → accelerator → scanning → wafer

The ion source turns gas into plasma and extracts ions, the analyzer magnet selects only the desired ions, and the accelerator brings them to the required energy. The beam is then scanned to implant uniformly over the whole wafer (some tools differ in the order of acceleration and analysis).

  • A. Correct. It starts at the source, then selection, acceleration and scanning before reaching the wafer.
  • B. Ions cannot be accelerated before they are created.
  • C. Mass analysis cannot come before the ion source.
