OS & Hardware

Which correctly describes the types of hypervisors?

  1. ASome run directly on the hardware, and others run as applications on an ordinary OS
  2. BThey always run as applications on an ordinary OS and never directly on hardware
  3. CThere are no types; all run purely in software without using hardware features
Show answer and explanation

Answer: A. Some run directly on the hardware, and others run as applications on an ordinary OS

Hypervisors come in two types: Type 1 (bare-metal), which runs directly on the hardware and manages guest OSes, and Type 2 (hosted), which runs as an application on an ordinary OS such as Windows or Linux. Type 1 has no extra layer and offers better performance and isolation, so it is used in servers and clouds; Type 2 is convenient for development and testing on PCs. Both use hardware features such as CPU virtualization support.

  • A. Correct. Type 1 runs directly on hardware, and Type 2 runs on an OS.
  • B. Some hypervisors run directly on hardware.
  • C. Both types use hardware such as CPU virtualization support.
