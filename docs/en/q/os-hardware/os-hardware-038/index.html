Which describes paravirtualization?

  1. AThe guest OS is left completely unmodified, and real hardware devices are reproduced exactly
  2. BThe guest OS knows it is virtualized and uses efficient procedures designed for the hypervisor
  3. CMultiple applications run inside one OS without any hypervisor
Show answer and explanation

Answer: B. The guest OS knows it is virtualized and uses efficient procedures designed for the hypervisor

Emulating a real device in full detail triggers a switch to the hypervisor on every device register access, which is slow. With paravirtualization, the guest OS installs virtualization-aware drivers and uses efficient, virtualization-aware procedures, such as exchanging batched requests through queues in shared memory. It is widely used for virtual disks and network devices. Reproducing devices exactly without modifying the OS is the idea of full virtualization.

  • A. Reproducing real devices without changing the OS is full virtualization.
  • B. Correct. It uses efficient procedures that assume virtualization.
  • C. Running multiple applications in one OS is what ordinary OSes do.
