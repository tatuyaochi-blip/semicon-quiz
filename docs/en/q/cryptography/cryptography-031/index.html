Applied Cryptography

Which of the following correctly describes mutual TLS (mTLS)?

  1. AA scheme that applies TLS encryption twice over to double the strength of the encryption
  2. BA scheme that uses both of the protocols TLS 1.2 and TLS 1.3 at the same time within one connection
  3. CA scheme in which not only the server but also the client presents a certificate, so each side authenticates the other
Show answer and explanation

Answer: C. A scheme in which not only the server but also the client presents a certificate, so each side authenticates the other

In ordinary TLS the client only checks the server's certificate, and the client is authenticated by mechanisms on top of TLS such as passwords or tokens. In mutual TLS the server also asks the client for a certificate, and the client sends its certificate and a signature made with the corresponding private key. It is often used for authentication between machines with no human operating them, such as communication between microservices, connections between IoT devices and servers, and networks based on the zero-trust approach.

  • A. It is not a scheme that layers encryption. "Mutual" means that authentication goes in both directions.
  • B. One connection uses one version of TLS, decided in the handshake.
  • C. Correct. The client is also authenticated with a certificate and a private key.
