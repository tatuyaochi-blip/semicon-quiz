Applied Cryptography

Which of the following correctly describes how a key encapsulation mechanism (KEM) such as ML-KEM is used?

  1. AThe sender signs the shared secret with its own private key and sends it, and the receiver verifies the signature with the sender's public key and receives the secret
  2. BThe sender creates a shared secret and a ciphertext wrapping it from the receiver's public key, and the receiver extracts the same secret with its private key
  3. CThe sender and receiver hold the same symmetric key in advance and encrypt messages directly with it
Show answer and explanation

Answer: B. The sender creates a shared secret and a ciphertext wrapping it from the receiver's public key, and the receiver extracts the same secret with its private key

A KEM consists of three operations: key generation, encapsulation and decapsulation. The sender encapsulates with the receiver's public key, obtaining a random shared secret together with a ciphertext that wraps it, and sends only the ciphertext. The receiver decapsulates with its private key to obtain the same shared secret, after which they use symmetric-key encryption with keys based on it. A KEM is a mechanism for sharing keys, so a separate signature such as ML-DSA is used to authenticate the other party.

  • A. This is how digital signatures are used. A KEM is a mechanism for sharing keys and has no signature function.
  • B. Correct. The receiver opens the ciphertext made by encapsulation with its private key.
  • C. This describes sharing a symmetric key in advance. A KEM creates a shared secret using a public key with a party with whom no secret has been shared beforehand.
