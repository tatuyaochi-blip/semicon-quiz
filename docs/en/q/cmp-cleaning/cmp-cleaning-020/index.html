CMP and cleaning

To prevent fine structures from collapsing, which method removes native oxide and the like without using liquids?

  1. ABrush scrub cleaning
  2. BDry cleaning using vapor-phase gases or radicals
  3. CMegasonic cleaning
Show answer and explanation

Answer: B. Dry cleaning using vapor-phase gases or radicals

Tall, narrow patterns can collapse due to surface tension as cleaning liquid dries. Vapor-phase (dry) cleaning, using hydrogen fluoride vapor or plasma-generated radicals, uses no liquid, so there is no risk of pattern collapse, and it is used for surface treatment of fine structures.
