What is the role of a lint tool in HDL verification?

  1. AA device that removes lint from chips
  2. BA tool for displaying simulation waveforms attractively
  3. CExamining code without simulation to find problems such as width mismatches, unintended latches and unsynthesizable constructs
Show answer and explanation

Answer: C. Examining code without simulation to find problems such as width mismatches, unintended latches and unsynthesizable constructs

A lint tool statically checks HDL code against rules and flags constructs that are legal but prone to problems, such as assignments between different widths, incomplete sensitivity lists, inferred latches, mixed blocking and nonblocking assignments and clocking mistakes. It runs without any tests, so using it from early in design reduces later verification effort.

  • A. It is not a physical cleaning device.
  • B. It is not a waveform viewer.
  • C. Correct. It finds mistakes early and cheaply.
