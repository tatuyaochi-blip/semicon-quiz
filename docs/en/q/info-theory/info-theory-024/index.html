Information Theory and Coding Basics

When compressing data, which of the following must use lossless compression rather than lossy compression?

  1. ACompressing a program's executable file for distribution
  2. BShrinking video to match the speed of the connection in a video streaming service
  3. CMaking music files smaller to listen to on a portable player
Show answer and explanation

Answer: A. Compressing a program's executable file for distribution

Lossless compression restores the original data without a single bit of difference, while lossy compression discards parts that people hardly notice in return for much greater shrinkage. A program does not run correctly if even one bit differs, so lossless compression such as ZIP is used. Small differences in images and sound are hard to see or hear, so lossy compression such as JPEG, MP3 and video coding formats is widely used for them.

  • A. Correct. An executable file does not run correctly unless it is exactly the same as the original.
  • B. Some degradation of video is acceptable, so lossy compression is used. On a slow connection, the picture quality is lowered to shrink it further.
  • C. Lossy compression such as MP3 and AAC is widely used. It shrinks files by discarding components the ear hardly notices.
