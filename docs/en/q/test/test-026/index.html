Testing and inspection

Which correctly describes ATE (automatic test equipment)?

  1. AEquipment that applies test patterns and compares outputs with expected values to judge pass or fail
  2. BEquipment that exposes circuit patterns onto wafers
  3. CEquipment that cleans wafers
Show answer and explanation

Answer: A. Equipment that applies test patterns and compares outputs with expected values to judge pass or fail

ATE (Automatic Test Equipment) is used to test semiconductors: it supplies power and signals to the chip under test, measures the outputs, compares them with expected values and judges pass or fail. It is used with a prober in wafer test and with a handler in final test.
