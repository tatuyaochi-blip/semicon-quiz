Testing and inspection

Which quality metric expresses the number of defects per million shipped products?

  1. AFIT
  2. BCp
  3. CDPPM
Show answer and explanation

Answer: C. DPPM

DPPM (Defective Parts Per Million) expresses the number of defective parts per million shipped. Automotive semiconductors and similar products require very low DPPM, making it important to reduce defects missed in test. FIT is a failure rate over time, and Cp is a process capability index.
