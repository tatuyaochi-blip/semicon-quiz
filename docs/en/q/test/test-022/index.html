Testing and inspection

In developing test programs, which is emphasized to lower test cost?

  1. AOptimizing test items and their order to shorten test time while still detecting defects adequately
  2. BMeasuring every item the maximum number of times
  3. CSkipping tests for items with many failures
Show answer and explanation

Answer: A. Optimizing test items and their order to shorten test time while still detecting defects adequately

Test cost is roughly proportional to test time, so test items are narrowed down as far as quality allows, and the order and conditions of measurements are refined to shorten test time. Items that past data show almost never fail may be reconsidered, and multi-site testing is also combined.
