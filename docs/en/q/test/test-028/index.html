Testing and inspection

Which pair correctly names the two properties that design for testability aims to improve?

  1. ASpeed and area
  2. BControllability and observability
  3. CColor and shape
Show answer and explanation

Answer: B. Controllability and observability

Controllability is how easily internal signals can be set to desired values from outside, and observability is how easily the values of internal signals can be observed from outside. DFT techniques such as scan design raise both so that internal faults can be detected with fewer test patterns.
