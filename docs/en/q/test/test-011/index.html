Testing and inspection

What is it called to automatically generate test patterns that detect faults from a circuit's netlist?

  1. ADRC
  2. BATPG (automatic test pattern generation)
  3. CCTS
Show answer and explanation

Answer: B. ATPG (automatic test pattern generation)

ATPG is a technology that automatically generates input patterns that can detect each fault, based on fault models such as stuck-at faults. Combined with scan design, it efficiently creates test patterns with high fault coverage even for large circuits.
