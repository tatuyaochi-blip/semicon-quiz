Testing and inspection

Which correctly describes BIST (built-in self-test)?

  1. AAll tests are performed by an external tester alone
  2. BTest circuitry is built into the chip so that the chip tests itself
  3. CAppearance is inspected by eye
Show answer and explanation

Answer: B. Test circuitry is built into the chip so that the chip tests itself

BIST builds pattern-generation and result-checking circuits into the chip so that the chip runs tests itself. It is widely used especially for testing large memories, reducing dependence on expensive external testers and cutting test time.
