Testing and inspection

Which method is now common for passing information on chips judged defective in wafer test to the later assembly process?

  1. ADefective chips are left unmarked and all chips are retested in assembly
  2. BIt is passed to assembly as an electronic wafer map
  3. COperators memorize it visually
Show answer and explanation

Answer: B. It is passed to assembly as an electronic wafer map

Defective chips used to be marked with ink, but now wafer test results are typically saved as electronic wafer map data, and the die bonder in assembly reads that data to pick only good chips.
