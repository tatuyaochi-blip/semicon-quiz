Testing and inspection

What is the test called that judges chips by running an OS and applications in an environment close to actual use?

  1. ASystem-level test (SLT)
  2. BDC test
  3. CIDDQ test
Show answer and explanation

Answer: A. System-level test (SLT)

In system-level test, the chip is mounted on a board close to the actual product, and operation is checked by booting an OS or running applications. It can detect defects that are hard to find with structural tests alone, so it is used for high-performance processors and similar devices.
