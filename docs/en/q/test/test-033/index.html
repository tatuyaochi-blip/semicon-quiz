Testing and inspection

What is the basic method for judging whether a chip is good in logic circuit testing?

  1. AJust looking at the chip under a microscope
  2. BMeasuring only the chip temperature
  3. CApplying test patterns to the inputs and comparing the outputs with the expected values from a correct circuit
Show answer and explanation

Answer: C. Applying test patterns to the inputs and comparing the outputs with the expected values from a correct circuit

In logic testing, the tester applies test patterns (sequences of input signals) to the chip and compares the outputs with the expected values a correct circuit would produce. Any single mismatch marks the chip as defective.

  • A. Visual inspection cannot reveal internal electrical defects.
  • B. Temperature alone cannot judge functional correctness.
  • C. Correct. Outputs are compared with expected values.
