Testing and inspection

Which correctly describes the stuck-at fault model used in testing logic circuits?

  1. AA fault in which signals propagate more slowly
  2. BA fault in which a signal line's value is fixed at 0 or 1
  3. CA fault in which the chip's temperature rises
Show answer and explanation

Answer: B. A fault in which a signal line's value is fixed at 0 or 1

The stuck-at model assumes a signal line is permanently fixed at 0 (stuck-at-0) or 1 (stuck-at-1), giving 2n faults for n lines. Simple as it is, it represents many physical defects such as shorts and opens, and it underpins ATPG and fault-coverage evaluation. Slow signals are handled by delay fault models, and temperature rise is not a fault model.
