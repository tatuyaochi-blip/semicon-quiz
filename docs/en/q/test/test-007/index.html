Testing and inspection

Which correctly describes the stuck-at fault model used in testing logic circuits?

  1. AA fault in which signals propagate more slowly
  2. BA fault in which a signal line's value is fixed at 0 or 1
  3. CA fault in which the chip's temperature rises
Show answer and explanation

Answer: B. A fault in which a signal line's value is fixed at 0 or 1

The stuck-at fault model assumes faults in which a signal line in the circuit is always 0 (stuck-at-0) or always 1 (stuck-at-1). Though simple, it represents many physical defects, so it is widely used for automatic test pattern generation and evaluating fault coverage. Delay is targeted by delay fault models.
