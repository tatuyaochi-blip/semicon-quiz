Testing and inspection

In logic testing, which pair correctly names the test that exhaustively detects structural faults (such as stuck-at faults) using scan and similar, and the test that checks function as in actual operation?

  1. ADC test and AC test
  2. BWafer test and burn-in
  3. CStructural test and functional test
Show answer and explanation

Answer: C. Structural test and functional test

A structural test applies fault models to the circuit's structure and efficiently detects faults in each part, using scan and the like. A functional test applies inputs close to real usage and checks that the chip functions to specification. The two are combined to ensure quality.

  • A. DC and AC tests examine DC characteristics and AC characteristics such as timing.
  • B. Wafer test and burn-in are distinguished by test stage and type.
  • C. Correct. They are structure-based and function-based tests.
