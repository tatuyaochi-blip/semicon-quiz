Testing and inspection

What is the technique called that dynamically changes test items or limits per chip or per lot based on intermediate results and statistics, such as from wafer test?

  1. AAdaptive test
  2. BDummy test
  3. CBlack-box test
Show answer and explanation

Answer: A. Adaptive test

Adaptive test adds or skips tests or changes limits based on results from earlier steps or other chips on the same wafer, statistical outlier detection and the like. It can cut test time while maintaining quality and make latent defects easier to find.

  • A. Correct. Tests are changed dynamically based on results.
  • B. This is not a common technique by that name.
  • C. Black-box testing is a software testing concept of checking inputs and outputs without seeing the internals.
