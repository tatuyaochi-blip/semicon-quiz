Testing and inspection

What is the printed circuit board called that attaches to the tester's test head, carries the IC socket and peripheral components and routes signals to the IC for each product?

  1. ALoad board (DUT board)
  2. BMotherboard
  3. CPackage substrate
Show answer and explanation

Answer: A. Load board (DUT board)

A load board (DUT board) is a product-specific board connecting the tester to the device under test (DUT). It carries the socket, supply capacitors, relays, load circuits and so on, wiring tester signals correctly to the IC's terminals. One must be designed and built for each product.

  • A. Correct. It is a product-specific board connecting tester and IC.
  • B. A motherboard is the main board of a PC or similar.
  • C. A package substrate is part of the package that holds the chip.
