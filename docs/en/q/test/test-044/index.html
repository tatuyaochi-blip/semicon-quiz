Testing and inspection

In memory testing, what is the main purpose of making a map recording which bits at which addresses failed?

  1. ATo increase memory capacity
  2. BTo decide the chip's color
  3. CTo perform repair by replacing failing locations with redundant rows and columns, and to analyze failure causes
Show answer and explanation

Answer: C. To perform repair by replacing failing locations with redundant rows and columns, and to analyze failure causes

A fail bit map plots failing bits by address. It is used to calculate redundancy repair, replacing failing rows or columns with spares by blowing fuses with a laser or electrically. The failure pattern, whether single bits, whole rows or columns, or clusters, also helps infer the type of process defect, such as particles or wiring shorts.

  • A. Recording failures does not increase capacity.
  • B. It has nothing to do with color.
  • C. Correct. It is used for repair and failure analysis.
