Testing and inspection

What is the test called that runs at the actual operating frequency to detect defects where signals propagate too slowly?

  1. ADC test
  2. BVisual inspection
  3. CAt-speed test
Show answer and explanation

Answer: C. At-speed test

In fine-geometry LSIs, delay defects are a problem: the circuit works logically, but a slight defect lengthens signal propagation time. At-speed testing at the actual operating frequency detects such defects using patterns based on delay fault models and similar approaches.
