Testing and inspection

In AD converter testing, what is the main purpose of inputting a slowly varying sine wave or similar and counting how often each output code appears (a histogram)?

  1. ATo weigh the chip
  2. BTo determine linearity such as DNL and INL
  3. CTo measure power consumption
Show answer and explanation

Answer: B. To determine linearity such as DNL and INL

Feeding an ideal ADC a signal with a known distribution yields a calculable distribution of code counts. Deviations of the actual counts reveal each code's width, giving DNL and, by accumulation, INL. This is called the histogram method and is widely used to test ADC static performance.

  • A. It has nothing to do with weight.
  • B. Correct. Linearity is obtained from code counts.
  • C. Power consumption is found by measuring supply current.
