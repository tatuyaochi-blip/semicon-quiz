Testing and inspection

What is the technology called that expands test patterns inside the chip and compresses the responses to reduce scan test data volume and test time?

  1. ATest compression (scan compression)
  2. BBurn-in
  3. CIDDQ test
Show answer and explanation

Answer: A. Test compression (scan compression)

In large LSIs, the volume of scan test patterns becomes enormous, straining tester memory and test time. Test compression uses on-chip circuits to expand a small amount of input data into many scan chains and compresses the outputs for comparison, greatly reducing data volume and test time.
