Testing and inspection

In testing high-speed serial interfaces, which method loops the chip's transmitter output back to its receiver so the chip itself verifies communication?

  1. AIDDQ test
  2. BBurn-in
  3. CLoopback test
Show answer and explanation

Answer: C. Loopback test

Directly measuring SerDes running at tens of Gb/s with a tester alone is difficult and expensive. In loopback testing, the transmitter sends pseudo-random data back to the receiver, and on-chip circuits count bit errors. The loop can be closed inside the chip or externally through traces on the load board, letting general-purpose testers test high-speed interfaces efficiently.

  • A. An IDDQ test detects defects from quiescent supply current.
  • B. Burn-in is a stress test to remove early failures.
  • C. Correct. Transmission is looped back to reception for checking.
