Testing and inspection

Which technique models defects such as transistor shorts and opens inside standard cells based on each cell's circuit and generates test patterns for them?

  1. AVisual inspection
  2. BCell-aware test
  3. CIDDQ test only
Show answer and explanation

Answer: B. Cell-aware test

Conventional models such as stuck-at consider only a cell's input and output pins. Cell-aware testing extracts possible transistor shorts and opens from each cell's layout, simulates them at transistor level, and feeds the detecting input combinations into pattern generation. It helps reduce field failures from intra-cell defects, which have increased in advanced processes.

  • A. Visual inspection cannot find internal electrical defects.
  • B. Correct. It models defects inside cells.
  • C. IDDQ detects defects through supply current but is separate from modeling intra-cell defects.
