Testing and inspection

Which correctly describes the typical test flow of semiconductor products?

  1. AFinal test → wafer test → assembly → shipment
  2. BAssembly → wafer test → shipment → final test
  3. CWafer test → assembly → final test → shipment
Show answer and explanation

Answer: C. Wafer test → assembly → final test → shipment

Wafer test is performed first on the finished wafer to identify bad chips. Only good chips are packaged in assembly, and final test verifies their characteristics before shipment. Some products add burn-in or system-level test around final test. Final test must follow assembly and no testing occurs after shipment, so the other orders do not work.
