Testing and inspection

Which correctly describes the typical test flow of semiconductor products?

  1. AFinal test → wafer test → assembly → shipment
  2. BAssembly → wafer test → shipment → final test
  3. CWafer test → assembly → final test → shipment
Show answer and explanation

Answer: C. Wafer test → assembly → final test → shipment

First, wafer test is performed on wafers that have completed front-end processing, identifying defective chips. Only good chips are packaged in assembly, and their characteristics are checked in final test before shipment. For some products, burn-in is performed before or after final test.
