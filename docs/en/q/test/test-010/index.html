Testing and inspection

What is the technique called in which a tester measures several chips simultaneously to lower test cost?

  1. ABurn-in
  2. BMulti-site test (parallel test)
  3. CWire bonding
Show answer and explanation

Answer: B. Multi-site test (parallel test)

Test cost scales roughly with time on an expensive tester. Multi-site testing measures several chips in parallel on one tester, lowering per-chip test time and cost; memory testing may measure hundreds at once. Since each site needs tester channels, it is combined with BIST and scan compression to reduce the pins required per chip.
