Testing and inspection

In testing, what is the set of sequences of 0 and 1 signals applied to a chip's inputs, together with the expected responses, called?

  1. ARecipe
  2. BTest patterns (test vectors)
  3. CPhotomask
Show answer and explanation

Answer: B. Test patterns (test vectors)

Test patterns (test vectors) specify the signal values applied to the chip inputs at each time step and the output values expected in response. Patterns that detect faults efficiently are created by methods such as automatic test pattern generation (ATPG).

  • A. A recipe is the set of process conditions for manufacturing equipment.
  • B. Correct. They pair input sequences with expected values.
  • C. A photomask is the master for transferring patterns by exposure.
