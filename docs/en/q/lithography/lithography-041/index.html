Lithography

Which correctly describes writing patterns directly into resist on the wafer with an electron beam, without a mask?

  1. AIt is the fastest method for volume production
  2. BIt needs no mask and can write very fine patterns, but writing takes so long that it is unsuited to mass production
  3. CIt cannot write patterns
Show answer and explanation

Answer: B. It needs no mask and can write very fine patterns, but writing takes so long that it is unsuited to mass production

Direct-write electron-beam lithography uses electrons with sub-nanometer wavelengths, free of optical diffraction limits, to pattern features below 10 nm without a mask. Because it writes patterns serially, a single 300 mm wafer can take days, making it unsuitable for volume production. It serves research, small-volume prototyping, photomask making and nanoimprint template fabrication.

  • A. Because it draws patterns serially, it is slow for volume production.
  • B. Correct. No mask is needed, but writing takes time.
  • C. It can write patterns.
