Lithography

Which is the correct general order of lithography steps?

  1. AExposure → resist coating → development → pre-bake
  2. BResist coating → pre-bake → exposure → post-exposure bake → development
  3. CDevelopment → exposure → resist coating → etching
Show answer and explanation

Answer: B. Resist coating → pre-bake → exposure → post-exposure bake → development

First, resist is coated and solvent is driven off in a pre-bake. Next comes exposure, and for chemically amplified resists a post-exposure bake (PEB) drives the reaction. Finally, development forms the pattern, followed by a post-bake to harden it if needed. Coating through development is done in a coater/developer connected to the exposure tool.
