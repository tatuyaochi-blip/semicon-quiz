Computer Networking Basics

What is the main role of DNS (Domain Name System)?

  1. AIt finds the MAC address of a device on the same network from its IP address
  2. BIt translates domain names such as www.example.com into the IP addresses used for communication (name resolution)
  3. CIt encrypts communication and verifies whether a connected website is genuine
Show answer and explanation

Answer: B. It translates domain names such as www.example.com into the IP addresses used for communication (name resolution)

DNS (Domain Name System) is the system that maps human-friendly domain names to the IP addresses used for communication. When you open a URL in a browser, the device first asks DNS for the server's IP address and then connects to that address. DNS data is not held on one server; it is divided by levels of the domain name hierarchy and managed in a distributed way by servers around the world. Queries mainly use UDP port 53, and TCP is also used, for example when responses are large.

  • A. That is the role of ARP.
  • B. Correct. It maps domain names to IP addresses.
  • C. That is the role of TLS (HTTPS).
