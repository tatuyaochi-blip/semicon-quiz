Computer Networking Basics

Which correctly describes an internet VPN?

  1. AIt switches the communication path to a dedicated physical line so that traffic does not cross the internet
  2. BWith a VPN you can communicate safely even if the server or device you connect to is infected with malware
  3. CIt creates a virtual private channel (tunnel) with encryption and authentication over the internet, so that remote sites or home devices are treated as if connected to the internal network
Show answer and explanation

Answer: C. It creates a virtual private channel (tunnel) with encryption and authentication over the internet, so that remote sites or home devices are treated as if connected to the internal network

In a VPN (virtual private network), original packets are encrypted and placed inside other packets (encapsulated), then extracted by the VPN device on the other side. The contents and internal addresses cannot be seen along the path, and tampering can be detected. Protocols used include IPsec, TLS-based ones and WireGuard. Physically, it differs from a leased line in that it travels over the shared internet. Only the tunnel section is protected, so the security of the destination itself and of traffic beyond the VPN exit must be considered separately.

  • A. That describes a leased line; an internet VPN goes over the internet.
  • B. Only traffic in the tunnel section is protected; the safety of the destination device is a separate issue.
  • C. Correct. An encrypted tunnel connects remote devices to the internal network.
