A/D and D/A conversion

Which is a characteristic of the current-steering architecture often used in high-speed DACs?

  1. AIt is slow because it integrates the input for a long time
  2. BIt produces the output by slowly discharging a capacitor
  3. CIt produces the output by switching where the currents of many current sources go, so it suits high-speed operation
Show answer and explanation

Answer: C. It produces the output by switching where the currents of many current sources go, so it suits high-speed operation

A current-steering DAC uses many current sources and, according to the digital input, steers each current either to the output or to a dummy node, forming the output from the sum. Because the sources never turn off—only their destination switches—it can run at several GS/s. Coding the upper bits as thermometer code with equal-weight sources reduces glitches and DNL. These DACs serve communications equipment and waveform generators.
