AD/DA conversion

Which is a characteristic of an R-2R ladder DA converter?

  1. AIt can be built with only two resistor values (R and 2R), so few resistor values are needed
  2. BIt is built only from capacitors
  3. CIt switches current using inductors
Show answer and explanation

Answer: A. It can be built with only two resistor values (R and 2R), so few resistor values are needed

An R-2R ladder arranges resistors R and 2R so that the resistance seen from every node is identical, halving the current at each successive bit. Only two resistor values are needed regardless of resolution, and 2R can be made from two R's in series, which makes ratios easy to match. Accuracy is set by resistor matching, with the most significant bits demanding the tightest precision.
