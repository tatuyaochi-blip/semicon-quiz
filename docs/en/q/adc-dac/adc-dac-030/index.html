AD/DA conversion

Which ADC architecture is classified as oversampling?

  1. AFlash
  2. BDelta-sigma
  3. CSuccessive approximation
Show answer and explanation

Answer: B. Delta-sigma

ADCs are classed as Nyquist-rate converters, which sample at about twice the signal bandwidth (flash, SAR, pipelined, etc.), and oversampling converters, which sample far faster. The ΔΣ ADC is the classic oversampling type, with oversampling ratios (OSR) typically in the tens to hundreds. Nyquist-rate converters convert each sample independently, which also suits multiplexing many channels.
