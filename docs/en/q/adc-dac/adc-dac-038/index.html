A/D and D/A conversion

Which correctly describes the gain error of an ADC?

  1. AThe slope of the transfer characteristic deviates from ideal, so the error grows toward full scale
  2. BThe output deviates from 0 when the input is 0
  3. CA particular code is never output
Show answer and explanation

Answer: A. The slope of the transfer characteristic deviates from ideal, so the error grows toward full scale

Gain error is a deviation of the transfer slope from ideal after offset is corrected; it grows with input and peaks at full scale. The main cause is reference-voltage error: a 0.1% reference error gives a 0.1% error at full scale (about 4 LSB at 12 bits). For precision, use an accurate, low-temperature-coefficient voltage reference or calibrate with a known voltage.

  • A. Correct. It is the error due to a slope deviation.
  • B. Output deviation at zero input is the offset error.
  • C. A code that never appears is a missing code.
