AD/DA conversion

How many output levels can an 8-bit AD converter represent?

  1. A8 levels
  2. B256 levels
  3. C1024 levels
Show answer and explanation

Answer: B. 256 levels

An N-bit converter can represent 2 to the power N levels. For 8 bits, that is 2⁸ = 256 levels. 1024 levels corresponds to 10 bits. Each additional bit doubles the number of levels, allowing finer voltage differences to be distinguished.
