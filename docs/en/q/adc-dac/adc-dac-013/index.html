AD/DA conversion

Which correctly describes the differential nonlinearity (DNL) of an AD converter?

  1. AError in the slope (gain) of the overall transfer characteristic
  2. BDeviation of the width (step size) between adjacent codes from the ideal 1 LSB
  3. CDeviation of the output when the input is 0
Show answer and explanation

Answer: B. Deviation of the width (step size) between adjacent codes from the ideal 1 LSB

DNL indicates how much the input voltage width corresponding to each output code deviates from the ideal 1 LSB. Deviation of the overall transfer characteristic from the ideal straight line is integral nonlinearity (INL), and the output deviation at zero input is offset error.
