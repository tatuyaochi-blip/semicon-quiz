AD/DA conversion

Which architecture is used as the internal DAC in many successive-approximation AD converters?

  1. AOnly the R-2R resistor ladder
  2. BOnly current steering
  3. CA capacitor array using capacitance ratios (charge redistribution)
Show answer and explanation

Answer: C. A capacitor array using capacitance ratios (charge redistribution)

Most SAR ADCs use a capacitor array with binary weights (C, 2C, 4C…), switching the bottom plates to redistribute charge and generate comparison voltages. The array doubles as the sampling capacitor and draws no static current, keeping power low. In CMOS, capacitor ratios can also be matched more precisely than resistors, so the approach is used from microcontrollers to sensor interfaces.
