A/D and D/A conversion

How many comparators does a 3-bit flash ADC need?

  1. A8
  2. B7
  3. C3
Show answer and explanation

Answer: B. 7

A flash ADC compares the input with every threshold simultaneously, so N bits need 2ᴺ − 1 comparators—seven for 3 bits. The comparator outputs form a thermometer code (all 1s up to a point, all 0s above), which an encoder converts to binary. At 8 bits there are 255 comparators, with large input capacitance and power, so the approach does not suit high resolution.

  • A. 8 is the number of output levels; there is one fewer boundary between them.
  • B. Correct. 2³ − 1 = 7.
  • C. 3 matches the number of bits, the idea behind deciding one bit at a time as in successive approximation.
