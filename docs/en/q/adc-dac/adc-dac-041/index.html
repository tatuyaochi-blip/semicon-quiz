AD/DA conversion

How many comparators does a 3-bit flash AD converter need?

  1. A3
  2. B8
  3. C7
Show answer and explanation

Answer: C. 7

A flash ADC compares the input with every threshold at once, so N bits require 2ᴺ − 1 comparators. For 3 bits that is 2³ − 1 = 7. Because the number of comparators grows exponentially with the number of bits, flash ADCs are not suited to high resolution.

  • A. 3 matches the number of bits, the idea behind deciding one bit at a time as in successive approximation.
  • B. 8 is the number of output levels; there is one fewer boundary between them.
  • C. Correct. 2³ − 1 = 7.
