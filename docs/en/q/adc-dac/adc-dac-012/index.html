AD/DA conversion

Which is a characteristic of the dual-slope AD converter often used in digital multimeters?

  1. AIt is the fastest because it uses many comparators
  2. BConversion finishes in one comparison
  3. CIt is slow but accurate, and integration makes it resistant to noise
Show answer and explanation

Answer: C. It is slow but accurate, and integration makes it resistant to noise

A dual-slope converter integrates the input voltage for a fixed time, then integrates the reference voltage in the opposite direction and counts the time until it returns to zero. Component value errors cancel out and noise is averaged by integration, so it is highly accurate. Because conversion takes time, it is used in slow applications such as measuring instruments.
