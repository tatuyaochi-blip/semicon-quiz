AD/DA conversion

For AD converters with the same input range, what happens when the resolution (number of bits) is increased?

  1. AThe voltage per LSB becomes larger, so small changes can no longer be distinguished
  2. BThe sampling frequency automatically increases
  3. CThe voltage per LSB becomes smaller, so finer voltage differences can be distinguished
Show answer and explanation

Answer: C. The voltage per LSB becomes smaller, so finer voltage differences can be distinguished

An N-bit converter divides the input range into 2ᴺ steps. Each additional bit doubles the number of steps and halves the voltage corresponding to 1 LSB, so finer voltage differences can be represented.

  • A. More bits make 1 LSB smaller.
  • B. Resolution and sampling frequency are separate specifications.
  • C. Correct. 1 LSB becomes smaller, allowing finer distinctions.
