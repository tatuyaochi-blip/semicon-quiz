AD/DA conversion

How many comparisons does an N-bit successive-approximation AD converter basically perform per conversion?

  1. A1
  2. B2ᴺ
  3. CN
Show answer and explanation

Answer: C. N

A successive-approximation ADC starts from the most significant bit and compares whether the input exceeds the internal DAC voltage, deciding one bit per comparison (a binary search). An N-bit conversion therefore basically needs N comparisons.

  • A. Deciding all bits in a single comparison is the idea of the flash type, which uses many comparators.
  • B. 2ᴺ is the count for a method that compares against every level in turn.
  • C. Correct. One comparison per bit, N in total.
