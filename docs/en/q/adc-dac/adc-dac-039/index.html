AD/DA conversion

What does it mean for a DAC to be monotonic?

  1. AIncreasing the input code always decreases the output
  2. BThe output never decreases when the input code is increased
  3. CIts output is always constant
Show answer and explanation

Answer: B. The output never decreases when the input code is increased

Monotonicity means the output never decreases when the input code increases by one, guaranteed if DNL is always greater than −1 LSB. In a control loop, a non-monotonic DAC creates points where raising the command lowers the output, producing local positive feedback that can cause oscillation or malfunction. Resistor-string and thermometer-coded current-steering DACs are monotonic by construction.

  • A. An output that drops as the input rises is a loss of monotonicity.
  • B. Correct. The output does not decrease as the code increases.
  • C. A constant output would not function as a converter.
