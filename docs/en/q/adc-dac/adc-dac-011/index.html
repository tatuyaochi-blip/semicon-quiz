AD/DA conversion

Which is the approximate formula for the signal-to-noise ratio (SNR) of an ideal N-bit AD converter, set by quantization noise? (For a full-scale sine-wave input)

  1. A6.02N + 1.76 dB
  2. B3N dB
  3. C20N dB
Show answer and explanation

Answer: A. 6.02N + 1.76 dB

For an ideal ADC, SNR ≈ 6.02N + 1.76 dB, improving by about 6 dB for each additional bit. For example, 12 bits give about 74 dB. Real ADCs fall short of this because of thermal noise, distortion and other factors.
