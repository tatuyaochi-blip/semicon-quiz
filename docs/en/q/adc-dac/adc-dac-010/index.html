A/D and D/A conversion

What is the role of a sample-and-hold circuit placed before an ADC?

  1. ATo amplify the input signal
  2. BTo hold the input voltage constant while AD conversion is performed
  3. CTo generate a clock signal
Show answer and explanation

Answer: B. To hold the input voltage constant while AD conversion is performed

Conversion takes time, and if the input changes meanwhile, the result is wrong. A sample-and-hold closes a switch to capture the input on a capacitor (track) and, when the switch opens, holds that value until conversion ends (hold). Without it, converting a 10 kHz sine wave to 12-bit accuracy would allow only a few nanoseconds. In modern SAR ADCs, the internal capacitive DAC performs this function.
