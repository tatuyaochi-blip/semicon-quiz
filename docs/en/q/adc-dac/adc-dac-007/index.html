A/D and D/A conversion

For a 10-bit ADC with a full-scale input of 1.024 V, what voltage corresponds to 1 LSB?

  1. A0.1 mV
  2. B1 mV
  3. C10 mV
Show answer and explanation

Answer: B. 1 mV

10 bits give 2¹⁰ = 1024 levels, so 1 LSB = 1.024 V ÷ 1024 = 1 mV. Using power-of-two references (1.024 V, 2.048 V, 4.096 V, etc.) makes the LSB a round number that simplifies calculations, which is why such reference ICs are sold. With the same full scale, 12 bits give 0.25 mV. Actual accuracy also depends on reference error and noise.
