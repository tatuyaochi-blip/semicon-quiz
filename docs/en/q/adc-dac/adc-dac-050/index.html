A/D and D/A conversion

Which correctly describes the "offset binary" code used in ADCs that handle both positive and negative voltages?

  1. AThe MSB alone represents the sign and the remaining bits the magnitude
  2. BNegative full scale is all 0s, positive full scale is all 1s, and 0 V is represented by the middle code
  3. CAll negative values are collapsed into the all-0 code
Show answer and explanation

Answer: B. Negative full scale is all 0s, positive full scale is all 1s, and 0 V is represented by the middle code

Offset binary assigns 000…0 to negative full scale and 111…1 to positive full scale, with 0 V near the middle code (100…0). It differs from two's complement only in the inverted most significant bit, so conversion is trivial. Since counting up from the bottom is natural inside an ADC, offset binary is often used at the output and converted to two's complement for digital processing.

  • A. An MSB sign with the remaining bits as magnitude is sign-magnitude representation.
  • B. Correct. The whole range is assigned from 0 upward, with 0 V in the middle.
  • C. Collapsing negative values into a single code would lose information.
