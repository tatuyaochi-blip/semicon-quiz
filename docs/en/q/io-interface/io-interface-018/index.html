I/O Interfaces & Buses

What is a characteristic of MSI (message-signaled interrupts) used in PCI Express?

  1. AThe device phones the CPU on every interrupt
  2. BNo interrupts are used; the CPU continuously polls the device
  3. CThe device signals an interrupt by writing to a designated address, so no dedicated interrupt wire is needed
Show answer and explanation

Answer: C. The device signals an interrupt by writing to a designated address, so no dedicated interrupt wire is needed

Older devices had dedicated interrupt wires, sometimes shared among several devices. With MSI, the device writes a designated value to an address set by the OS, and that write arrives at the CPU as an interrupt. Without the limit on wires, a device can have many interrupts; a network card, for example, can send a separate interrupt for each receive queue to a different core.

  • A. Of course no telephone is involved.
  • B. That is polling.
  • C. Correct. Interrupts are sent as packets too.
