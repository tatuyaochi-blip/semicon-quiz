I/O Interfaces & Buses

What is AXI4-Lite mainly used for?

  1. ASimple, low-volume exchanges such as reading and writing peripheral configuration registers
  2. BMoving huge volumes of data between a GPU and HBM
  3. CConnecting to external equipment by cable
Show answer and explanation

Answer: A. Simple, low-volume exchanges such as reading and writing peripheral configuration registers

AXI4-Lite drops features such as bursts and multiple outstanding requests and simply reads or writes one data item at a time. Its small, easy-to-build circuits make it the usual way to connect the configuration registers of timers, communication blocks and the like to the CPU. Fast, high-volume transfers instead use full AXI or AXI4-Stream, which has no addresses.

  • A. Correct. It is a simplified version without bursts.
  • B. Bulk transfers use full AXI with bursts or similar.
  • C. It is an on-chip bus.
