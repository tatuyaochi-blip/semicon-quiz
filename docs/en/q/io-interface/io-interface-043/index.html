I/O Interfaces & Buses

High-speed links such as 100-gigabit Ethernet are sometimes built by bundling, for example, four 25 Gb/s lanes. Which describes this approach?

  1. AThree of the four are spares; data actually travels on just one
  2. BThe same data is sent on all four and errors are fixed by majority vote
  3. CBecause per-lane speed is limited, data is spread across several SerDes lanes to reach the total bandwidth
Show answer and explanation

Answer: C. Because per-lane speed is limited, data is spread across several SerDes lanes to reach the total bandwidth

The speed of one SerDes lane is limited by circuit and channel technology. Spreading data across several lanes and realigning it in order at the receiver yields large total bandwidth. As per-lane speeds rise, the same bandwidth needs fewer lanes; for example, a single 100 Gb/s PAM4 lane can carry 100-gigabit traffic.

  • A. All lanes carry data.
  • B. The data is divided, not duplicated.
  • C. Correct. It is the same idea as PCI Express lanes.
