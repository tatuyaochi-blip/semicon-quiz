I/O Interfaces & Buses

How does communication in PCI Express work?

  1. AAddresses and data are driven simultaneously on many separate wires
  2. BRead and write requests are sent as packets and handled in three layers: transaction, data link and physical
  3. CThe CPU directly controls every bit of every transfer
Show answer and explanation

Answer: B. Read and write requests are sent as packets and handled in three layers: transaction, data link and physical

PCI Express sends memory reads and writes and configuration requests as packets (TLPs) with headers and data. The transaction layer forms packets, the data link layer adds error-detecting codes and confirms delivery, and the physical layer encodes them and sends them through the SerDes. To software it still looks like reading and writing memory addresses, as with old PCI, which preserves compatibility.

  • A. That is how a parallel bus works.
  • B. Correct. It has a layered structure like a network.
  • C. The CPU does not handle individual bits.
