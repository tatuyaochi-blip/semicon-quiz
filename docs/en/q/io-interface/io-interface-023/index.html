Which statement about USB Type-C is correct?

  1. AAny USB Type-C cable always communicates at the maximum speed
  2. BUSB Type-C cannot be used to supply power
  3. CIt is a connector-shape standard that plugs in either way up; the data rate is set by separate specifications
Show answer and explanation

Answer: C. It is a connector-shape standard that plugs in either way up; the data rate is set by separate specifications

USB Type-C is a standard for a small connector that plugs in either way up. Behind the same connector, the data link ranges from USB 2.0's 480 Mb/s to tens of Gb/s with USB 3.x or USB4, depending on what the cable and both devices support. It is also used for power delivery and video output, so cables and ports that look the same may differ in what they can do.

  • A. Speed depends on the specifications the cable and devices support.
  • B. It can deliver substantial power via USB PD and similar.
  • C. Correct. Shape and speed are separate matters.
