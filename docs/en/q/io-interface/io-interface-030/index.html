What is the advantage of burst transfers in AXI?

  1. AData is compressed, reducing the amount sent
  2. BEach transfer rechecks the address, eliminating errors
  3. COne address covers several consecutive data items, reducing address overhead and using bandwidth effectively
Show answer and explanation

Answer: C. One address covers several consecutive data items, reducing address overhead and using bandwidth effectively

Data at consecutive addresses, such as a cache-line fill, is often handled together, so AXI can send just the starting address and a length and then stream the data as a burst. Not sending an address per item frees the address channel and keeps the data channel busy without gaps. DRAM is also good at burst reads and writes, so the two match well.

  • A. It does not compress.
  • B. The benefit is omitting addresses, not rechecking them.
  • C. Correct. It suits reading and writing cache lines and similar.
