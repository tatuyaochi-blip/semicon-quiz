LSI design flow and EDA

What is the verification called that uses dedicated tools to check whether synchronizers are correctly inserted where signals pass between circuits running on different clocks?

  1. AIR drop analysis
  2. BCDC (clock domain crossing) verification
  3. CDRC
Show answer and explanation

Answer: B. CDC (clock domain crossing) verification

Passing signals directly between asynchronous clocks causes metastability and lost data. CDC verification automatically finds such crossings in the design and checks that synchronizers such as two-stage flip-flops are correctly inserted. It detects bugs that are hard to find with ordinary simulation.

  • A. IR drop analysis examines supply voltage drop.
  • B. Correct. It checks signals crossing between clock domains.
  • C. DRC checks geometric rules in the layout.
