LSI design flow and EDA

Which is the correct order of a typical digital LSI design flow?

  1. ASpecification → RTL design → logic synthesis → place and route
  2. BLogic synthesis → specification → place and route → RTL design
  3. CPlace and route → RTL design → logic synthesis → specification
Show answer and explanation

Answer: A. Specification → RTL design → logic synthesis → place and route

First, the specification defines functions and performance, and RTL design is done in a hardware description language such as Verilog or VHDL. Logic synthesis then converts it into a gate-level netlist, and place and route creates the layout on the chip. Verification is done at each stage, and the result is finally output as mask data.
