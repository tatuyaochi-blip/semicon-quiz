LSI design flow and EDA

What is the set of design data, including design rules, device models and cell libraries, that a foundry provides to designers called?

  1. APDK (process design kit)
  2. BIP core
  3. CHDL
Show answer and explanation

Answer: A. PDK (process design kit)

A PDK contains the process's design rules, simulation models for transistors and other devices, rule files for DRC and LVS, basic cells and more. Using the PDK, designers can design circuits that can be manufactured at that foundry.
