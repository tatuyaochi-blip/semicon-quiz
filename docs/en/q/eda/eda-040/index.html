IC design flow and EDA

In low-power design, which standard format describes the "power intent", such as power domains, power shutoff and level shifters, separately from the circuit description?

  1. AUPF (Unified Power Format)
  2. BGDSII
  3. CSPICE netlist
Show answer and explanation

Answer: A. UPF (Unified Power Format)

UPF is a standard format, IEEE 1801, for describing power intent: which supply each block uses, when supplies are shut off, and which isolation cells and level shifters sit between domains. Because it is kept in files separate from the RTL, the power architecture can change without touching the RTL, and synthesis, verification and place-and-route tools handle the power structure consistently.

  • A. Correct. It is the standard format for describing power intent.
  • B. GDSII is a layout data format.
  • C. A SPICE netlist describes circuits at the transistor level.
