IC design flow and EDA

In static timing analysis, what is the technique called that recalculates violating paths in detail based on how signals actually propagate, removing excess pessimism from ordinary analysis?

  1. ADRC
  2. BPath-based analysis (PBA)
  3. CGraph-based analysis (GBA) only
Show answer and explanation

Answer: B. Path-based analysis (PBA)

Ordinary graph-based analysis (GBA) uses the worst transition time among signals converging at each node, which can produce pessimistic results from combinations that never actually occur. Path-based analysis recomputes using the real transition times along a specific path, giving more accurate delays and avoiding unnecessary fixes. Because it is computationally expensive, it is usually applied only to paths that fail GBA.

  • A. DRC checks geometric rules in the layout.
  • B. Correct. It recalculates each path in detail.
  • C. GBA is fast but tends to be pessimistic.
