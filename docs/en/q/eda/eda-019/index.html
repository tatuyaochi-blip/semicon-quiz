IC design flow and EDA

In verifying large SoCs, which technique runs the designed circuit on dedicated hardware or FPGAs and verifies it quickly together with software?

  1. AEmulation and FPGA prototyping
  2. BDRC
  3. CCMP
Show answer and explanation

Answer: A. Emulation and FPGA prototyping

Software logic simulation of a large design is so slow that one second of operation can take days. Mapping the design onto an emulator or FPGAs runs it orders of magnitude faster, allowing real OSes and applications to run and software development to start before silicon exists. Emulators offer better visibility into internal signals, while FPGA prototypes run faster.
