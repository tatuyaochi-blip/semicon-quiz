LSI design flow and EDA

Which analysis method, rather than combining worst-case values at corners, treats delay variation as probability distributions and computes the probability of meeting timing?

  1. ADRC
  2. BLogic simulation
  3. CStatistical static timing analysis (SSTA)
Show answer and explanation

Answer: C. Statistical static timing analysis (SSTA)

Corner-based analysis assumes all variations are simultaneously at their worst, which can be overly pessimistic. SSTA treats each element's delay as a probability distribution and, accounting for correlations, computes the distribution of path delay to evaluate the probability of meeting timing more realistically.

  • A. DRC checks geometric rules in the layout.
  • B. Logic simulation checks circuit behavior for given inputs.
  • C. Correct. It is timing analysis treating variation as distributions.
