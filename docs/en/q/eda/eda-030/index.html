IC design flow and EDA

In RTL verification, which metric is used to evaluate how thoroughly verification has been done?

  1. AFIT
  2. BCoverage (code coverage and functional coverage)
  3. CCp
Show answer and explanation

Answer: B. Coverage (code coverage and functional coverage)

Coverage measures how thoroughly verification exercised the design: which RTL lines and branches executed (code coverage) and how many specified functions and scenarios were checked (functional coverage). 100% code coverage does not guarantee that combinations in the specification were tested, so both are tracked. Tests are added where coverage is low. FIT is a failure rate and Cp a process capability index.
