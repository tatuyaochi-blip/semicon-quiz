IC design flow and EDA

Which design philosophy refines layouts and the like to make them less susceptible to manufacturing variation and defects?

  1. ADFT (design for testability)
  2. BCTS (clock tree synthesis)
  3. CDFM (design for manufacturability)
Show answer and explanation

Answer: C. DFM (design for manufacturability)

DFM (design for manufacturability) creates layouts that are easy to build with high yield, for example by avoiding patterns hard to resolve in lithography, doubling vias so a connection survives if one fails, and widening wire spacing where possible. Tools that flag risky patterns using fab data are also used. DFT addresses testability and CTS distributes the clock.
