LSI design flow and EDA

Which correctly describes a feature of FPGAs?

  1. AThe circuit is fixed at manufacture and cannot be changed
  2. BThey are devices dedicated to analog circuits
  3. CUsers can rewrite the configuration of the logic circuit after manufacturing
Show answer and explanation

Answer: C. Users can rewrite the configuration of the logic circuit after manufacturing

An FPGA is a device whose logic blocks and wiring connections can be rewritten with configuration data after manufacturing. Unlike custom LSIs (ASICs), it requires no manufacturing time or mask costs, so it is used for prototypes, low-volume production and equipment that needs function updates. For the same circuit, however, an ASIC is faster and uses less power.
