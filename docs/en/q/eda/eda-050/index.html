IC design flow and EDA

Which logic simulation method computes only the parts affected when a signal value changes (an event)?

  1. AElectromagnetic simulation
  2. BEvent-driven simulation
  3. CMonte Carlo simulation
Show answer and explanation

Answer: B. Event-driven simulation

Event-driven simulation evaluates gates only when one of their input signals changes value, skipping parts with no activity. Since only a small fraction of signals change in any cycle in digital circuits, it is efficient and can model timing including delays. It is the basic method of Verilog and VHDL simulators. Cycle-based simulation, which evaluates everything each clock, is faster but does not model delays.

  • A. Electromagnetic simulation computes the behavior of electromagnetic waves.
  • B. Correct. It computes only in response to value changes.
  • C. Monte Carlo repeats simulations with random variations.
