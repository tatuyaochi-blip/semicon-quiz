What does 'IP (IP core)' mean in IC design?

  1. AAn Internet address
  2. BA reusable, pre-designed circuit block such as a CPU or interface
  3. CThe name of a manufacturing tool
Show answer and explanation

Answer: B. A reusable, pre-designed circuit block such as a CPU or interface

An IP core is a pre-designed circuit block, such as a CPU core, memory or USB or PCIe interface, prepared for reuse in other designs. Companies develop their own or license them from specialist vendors for fees and royalties. Combining verified blocks reduces the development time and risk of large SoCs. IP stands for intellectual property, unrelated to internet IP addresses.
