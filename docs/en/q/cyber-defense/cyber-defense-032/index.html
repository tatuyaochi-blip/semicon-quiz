Cyber Attacks and Defense in Practice

Which of the following is the correct reason why authentication with FIDO2 (WebAuthn) passkeys is considered more resistant to phishing than one-time passwords (OTPs)?

  1. AThe private-key signature is bound to the domain being connected to, so a fake site cannot obtain a signature for the real site, and relaying it is useless
  2. BA passkey is a six-digit number, which has fewer digits than an OTP, so the time until a user enters it on a fake site is also shorter
  3. CWith passkeys, the user's password is stored on the server, so even if it is entered on a fake site, the check on the server reveals the fraud
Show answer and explanation

Answer: A. The private-key signature is bound to the domain being connected to, so a fake site cannot obtain a signature for the real site, and relaying it is useless

An OTP is a value the user reads and types, so it cannot prevent attacks that get it entered on a fake site and immediately relay it to the real site (adversary-in-the-middle phishing). In FIDO2, a pair of public and private keys is created for each site and only the public key is registered with the site; at login, the authenticator signs a value sent by the site (the challenge) with the private key. Which site's key is used is decided by the actual domain being connected to as verified by the browser, and the signed information also includes that origin, so a fake site cannot obtain a signature for the real site. And since the server stores only the public key, a leak from the server cannot be used for impersonation.

  • A. Correct. The signature is bound to the domain being connected to, so a fake site cannot obtain a usable signature.
  • B. A passkey is not entered as a number; it is a method of signing with a private key inside the device.
  • C. With passkeys, a public key, not a password, is registered on the server.
