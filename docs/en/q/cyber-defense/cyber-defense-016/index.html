Cyber Attacks and Defense in Practice

An organization places "decoy" files that nobody uses for work, and a decoy administrator account that no system uses, on an internal file server, and monitors access to them. Which of the following is the main advantage of this measure?

  1. AWith decoys in place, attackers will always target only the decoys, so the real files and accounts will no longer be attacked
  2. BThe decoy account can also be used for everyday work, so there is no need to reduce the number of administrator accounts
  3. CLegitimate users have no reason to touch them, so any access is a strong clue of intrusion with few false positives
Show answer and explanation

Answer: C. Legitimate users have no reason to touch them, so any access is a strong clue of intrusion with few false positives

Decoys that are not used for work (called honeypots, honeytokens, decoys and so on) give legitimate users no reason to touch them, so the very fact that they were accessed is a strong sign of something abnormal. Unlike anomaly-based detection, there is no need to judge from differences from the normal state, and the advantage is that there are few false positives. Intruders explore the inside looking for administrator accounts and important-looking files, so mixing decoys among them may reveal lateral movement at an early stage. However, decoys do not stop the real assets from being attacked, so they are a supplementary measure combined with other controls.

  • A. Attackers do not necessarily target only the decoys. Other controls that protect the real assets are still needed.
  • B. Decoys are premised on not being used for work. If they are used for work, legitimate use will trigger alerts.
  • C. Correct. Access to something nobody has a reason to touch is a clue with few false positives.
