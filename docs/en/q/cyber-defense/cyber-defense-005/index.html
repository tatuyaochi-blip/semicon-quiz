Cyber Attacks and Defense in Practice

An attacker who exploited a vulnerability in a web application can now run commands with the same ordinary user privileges as the web server program. Which of the following is an example of the "privilege escalation" the attacker carries out next?

  1. ATrying to connect by SSH to another internal server with a stolen password, still with the same ordinary user privileges
  2. BGaining root privileges by exploiting an unpatched vulnerability in the OS kernel or similar
  3. CConnecting to an external server at regular intervals to receive the next instruction
Show answer and explanation

Answer: B. Gaining root privileges by exploiting an unpatched vulnerability in the OS kernel or similar

Privilege escalation means gaining higher privileges than those currently held by exploiting vulnerabilities or configuration flaws. On Linux, unpatched kernel vulnerabilities, programs that unnecessarily have the SUID bit set and sudo configured to allow running anything without a password are abused. With administrator privileges, the attacker can erase logs, stop security software and steal credentials, so the damage spreads widely. Applying fixes, the principle of least privilege and reducing the programs that run with administrator privileges are the basic controls.

  • A. Extending connections to another server with the same privileges is lateral movement.
  • B. Correct. Obtaining higher privileges by using vulnerabilities or configuration flaws is privilege escalation.
  • C. Regular communication with a command server is C2 (command and control).
