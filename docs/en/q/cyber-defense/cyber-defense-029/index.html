Cyber Attacks and Defense in Practice

It was found that files containing customer information in cloud object storage could be read by anyone on the internet. Which of the following is an appropriate combination of a typical cause of this kind of leak and a measure to prevent recurrence?

  1. AIt was made public through a configuration mistake by the user. Enable a setting that forbids public access across the account and check for configuration mistakes automatically
  2. BThe cloud provider's encryption scheme was weak, and the files were decrypted. Compress the files before storing them
  3. CPhysical security at the cloud provider's data center was insufficient. Station the company's own employees in the data center to keep watch
Show answer and explanation

Answer: A. It was made public through a configuration mistake by the user. Enable a setting that forbids public access across the account and check for configuration mistakes automatically

Under the cloud shared responsibility model, storage access settings are the user's responsibility, and leaks caused by mistakes in public-access settings have happened again and again. Typical mistakes include forgetting to revert a setting made public temporarily for testing, or misunderstanding what a grant applies to and granting access too broadly. As countermeasures, forbidding public access across the account or organization is made the default, and a mechanism that checks the configuration state automatically (CSPM: cloud security posture management) continuously finds and fixes public settings, missing encryption and the like.

  • A. Correct. Configuration mistakes are the typical cause, so forbid public access by default and check the configuration continuously.
  • B. The cause is not weak encryption but a setting that lets anyone read the data. Compression does not protect the contents.
  • C. This is not a case of physical intrusion; the data were read over the internet.
