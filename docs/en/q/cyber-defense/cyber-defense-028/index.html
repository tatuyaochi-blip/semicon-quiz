Cyber Attacks and Defense in Practice

In the SolarWinds incident discovered in December 2020, attackers got into the build environment of IT management software and malicious code was mixed into legitimate updates. The updates were distributed carrying the developer's legitimate code signature. Which of the following is the most appropriate lesson from this incident?

  1. AUpdates with a valid code signature never contain malicious code, so it is enough for users to check the signature
  2. BUpdates are dangerous, so software should never be updated at all, including security fixes
  3. CA code signature shows only who signed and whether the code was altered after signing, so developers must protect the build environment and users must also monitor the behavior of trusted software
Show answer and explanation

Answer: C. A code signature shows only who signed and whether the code was altered after signing, so developers must protect the build environment and users must also monitor the behavior of trusted software

Code signing confirms who signed and that the contents were not changed after signing; it cannot recognize malicious code mixed in before signing. In the SolarWinds incident, a prime example of a software supply chain attack, malicious code was added during the build, so it reached many organizations as legitimate signed updates. In the xz-utils backdoor discovered in March 2024 as well, a person who had spent a long time gaining trust as a developer slipped malicious code into the distributed files. It is important that developers isolate and protect the build environment and record and verify provenance from source to build, and that users monitor even trusted software for suspicious traffic and behavior with EDR and similar tools.

  • A. A signature cannot recognize malicious code mixed in before signing. The updates in this incident also carried legitimate signatures.
  • B. Stopping updates leaves known vulnerabilities in place and actually increases the risk.
  • C. Correct. Understand the limits of what a signature confirms, and combine protection of the build environment with monitoring of behavior.
