Yield and quality control

Which type of control automatically adjusts equipment processing conditions for the next lot or wafer based on, for example, measurement results from earlier steps?

  1. AFMEA
  2. BPareto analysis
  3. CAPC (run-to-run control, etc.)
Show answer and explanation

Answer: C. APC (run-to-run control, etc.)

APC (advanced process control) uses metrology data to adjust tool settings automatically and reduce process variation. In run-to-run control, for example, if the incoming film measured thick, the next CMP time is extended. Whereas SPC monitors and stops on abnormalities, APC actively corrects toward target. FMEA is proactive risk assessment and Pareto analysis finds priorities.
