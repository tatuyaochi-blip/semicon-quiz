Yield and quality control

Which correctly states Little's law, relating work in progress (WIP), throughput and cycle time in a factory?

  1. AWIP = throughput × cycle time
  2. BWIP = throughput ÷ cycle time
  3. CWIP is unrelated to cycle time
Show answer and explanation

Answer: A. WIP = throughput × cycle time

Little's law states that average WIP equals throughput (output per unit time) times cycle time. A fab completing 50,000 wafers a month with a three-month cycle time always holds about 150,000 wafers in process. Shortening cycle time at the same throughput requires less WIP, and piling on too much WIP lengthens cycle time.

  • A. Correct. WIP = throughput × cycle time.
  • B. The relationship is multiplication, not division.
  • C. WIP is closely related to cycle time.
