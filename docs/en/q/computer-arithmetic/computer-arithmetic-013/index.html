Computer Arithmetic

What is the role of IEEE 754 subnormal numbers?

  1. ARepresenting values above the largest normal number to prevent overflow
  2. BDetecting calculation errors and replacing the results with NaN
  3. CFilling the gap between normal numbers and zero for gradual underflow
Show answer and explanation

Answer: C. Filling the gap between normal numbers and zero for gradual underflow

With only normal numbers, there would be a large gap between the smallest normal number (about 1.18 × 10⁻³⁸ in single precision) and zero, and anything smaller would jump straight to 0. Subnormals, with an all-zero exponent and no implied leading 1, fill this gap with evenly spaced tiny values (gradual underflow), preserving the property that x − y = 0 implies x = y. Large values are represented by infinity, not subnormals, and error detection is unrelated.

  • A. Values too large are represented by infinity.
  • B. It has nothing to do with error detection.
  • C. Correct. It fills the gap near zero, making underflow gradual.
