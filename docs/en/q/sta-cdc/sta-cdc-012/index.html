Timing analysis and CDC

For OCV derating in setup analysis, the launch clock path and data path delays are multiplied by 1.1 and the capture clock path delay by 0.9. With a launch clock path of 1.0 ns, a data path (including clock-to-output) of 1.5 ns, a capture clock path of 1.0 ns (no common portion), a period of 3.0 ns and a setup time of 0.1 ns, what is the setup slack?

  1. A1.05 ns
  2. B1.40 ns
  3. C1.25 ns
Show answer and explanation

Answer: A. 1.05 ns

OCV derating accounts for delay varying with location even within the same chip, and for setup assumes the most pessimistic combination (slow launch side, early capture clock). The arrival time is 1.1 × (1.0 + 1.5) = 2.75 ns and the required time is 3.0 + 0.9 × 1.0 − 0.1 = 3.8 ns, so the slack is 1.05 ns. 1.40 ns is the value without derating, and 1.25 ns applies the factor to the data path only. In hold analysis the factors are applied the other way around.
