Timing analysis and CDC

What does the value specified with set_output_delay represent?

  1. AThe upper limit on the delay from an internal flip-flop to the output port
  2. BThe time needed outside the chip from when data leaves the output port until it is captured by the receiving device
  3. CThe amount of current the output port can drive
Show answer and explanation

Answer: B. The time needed outside the chip from when data leaves the output port until it is captured by the receiving device

set_output_delay specifies the time consumed outside the chip, referenced to the clock edge. For example, if the board trace delay is 0.3 ns and the receiving device's setup time is 0.7 ns, the output delay is set to 1.0 ns, and STA checks the path from the internal flip-flop to the output port against the time left after subtracting this value from the period. The upper limit on internal delay results from this constraint; it is not a value specified directly. Drive current is a separate matter from timing constraints.
