Timing analysis and CDC

For which path is it appropriate to set a false path (set_false_path)?

  1. AA path that is structurally connected but along which no signal can actually propagate, for example because the select conditions are mutually exclusive
  2. BA path with a large timing violation that is hard to fix
  3. CA path that only needs to capture data once every two cycles
Show answer and explanation

Answer: A. A path that is structurally connected but along which no signal can actually propagate, for example because the select conditions are mutually exclusive

STA examines every connected path without considering what the logic means. As a result, violations can be reported even on paths that are never actually exercised, such as in a circuit where two multiplexers driven by the same select signal choose opposite inputs. Such paths are designated false paths and excluded from analysis. Excluding a path just because it is hard to fix hides real bugs. A path that captures once every two cycles should stay in the analysis as a multicycle path with extended time.
