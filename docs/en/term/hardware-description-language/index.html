What is Hardware description language (HDL)?

A language for describing the structure and behavior of digital circuits, such as Verilog, SystemVerilog and VHDL, converted into circuits by logic synthesis.

Japanese name: ハードウェア記述言語

What is a major difference between a description written in an HDL such as Verilog and a software program in a language such as C?

  1. AAn HDL description represents circuits that operate concurrently
  2. BAn HDL description is a sequence of instructions executed one line at a time from the top
  3. CHDLs cannot use variables or conditional branches
Show answer and explanation

Answer: A. An HDL description represents circuits that operate concurrently

An HDL looks like a program, but logic synthesis turns what is written into gates and flip-flops. Every part of a circuit operates at all times, so multiple assign statements and always blocks work in parallel regardless of their order in the text. Thinking "do this, then that" as in software leads to unintended circuits, so it is important to picture the circuit being created while writing.

What is the basic structure of a state machine written in an HDL?

  1. AOnly memory to remember the state, with no logic
  2. BOnly output logic, with no memory of state
  3. CA register holding the current state, combinational logic choosing the next state, and combinational logic producing outputs
Show answer and explanation

Answer: C. A register holding the current state, combinational logic choosing the next state, and combinational logic producing outputs

A state machine keeps the current state in a flip-flop register, determines the next state from the current state and inputs with combinational logic, and updates the state at the clock edge. Outputs are produced from the current state (and inputs) by combinational logic. Many circuits that follow a procedure, such as protocol controllers, vending machines and traffic lights, are written as state machines.
