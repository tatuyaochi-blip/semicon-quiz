What is Hardware description language (HDL)?

A language for describing the structure and behavior of digital circuits, such as Verilog, SystemVerilog and VHDL, converted into circuits by logic synthesis.

Japanese name: ハードウェア記述言語

Field: HDL & Verification

What an HDL describes

A hardware description language describes circuits rather than a sequence of instructions. Every assign statement, always block and module instance represents hardware that operates all the time, so code order does not imply execution order. Designs are usually written at register-transfer level (RTL): registers updated on clock edges, with combinational logic computing their next values. The main languages are Verilog, its extension SystemVerilog, and VHDL, which is more strongly typed. Only a synthesizable subset of each language maps to gates; the rest exists for simulation and verification.

Writing synthesizable RTL

Clocked blocks such as always @(posedge clk) become flip-flops and conventionally use nonblocking assignments (<=). Combinational blocks should use @(*) or always_comb with blocking assignments (=) and must assign every output on every path, for example with a default case, or synthesis infers a latch. A for loop is unrolled into parallel hardware, so a loop over eight bits becomes eight adders. State machines combine a state register, next-state logic and output logic. Tri-state outputs are kept for off-chip bidirectional pins; internal selection uses multiplexers.

Verification with HDLs

The same languages build the verification environment. A testbench instantiates the design under test, generates clocks, resets and stimulus, and checks outputs; since it is never synthesized, it can use delays, file I/O and display statements. SystemVerilog adds classes, constrained-random stimulus, functional coverage and assertions, and UVM provides a standard class library for reusable testbenches. Lint tools check code statically for width mismatches, inferred latches and unsynthesizable constructs. Verification often takes as much effort as the design itself, or more.

HDL in the design flow

HDL sits between the specification and the gate-level netlist. Engineers write RTL from the specification, simulate it, then logic synthesis maps it onto cells from the foundry's library, guided by the process design kit (PDK) and timing constraints. Describing behavior this way is what makes large designs possible: even a 32-bit adder would need a truth table of 2⁶⁴ rows. High-level synthesis raises abstraction further by generating RTL from C or C++, while FPGA tools take the same HDL and map it to lookup tables instead of standard cells.

Answer: A. An HDL description represents circuits that operate concurrently

An HDL looks like a program, but logic synthesis turns what is written into gates and flip-flops. Every part of a circuit operates at all times, so multiple assign statements and always blocks work in parallel regardless of their order in the text. Thinking "do this, then that" as in software leads to unintended circuits, so it is important to picture the circuit being created while writing.

What is the basic structure of a state machine written in an HDL?

  3. CA register holding the current state, combinational logic choosing the next state, and combinational logic producing outputs

Answer: C. A register holding the current state, combinational logic choosing the next state, and combinational logic producing outputs

A state machine keeps the current state in a flip-flop register, determines the next state from the current state and inputs with combinational logic, and updates the state at the clock edge. Outputs are produced from the current state (and inputs) by combinational logic. Many circuits that follow a procedure, such as protocol controllers, vending machines and traffic lights, are written as state machines.

FAQ

What is the difference between Verilog and VHDL?

Both describe hardware at RTL and are supported by synthesis and simulation tools. Verilog has a terse, C-like syntax, while VHDL is more verbose and strongly typed; SystemVerilog extends Verilog with major verification features.

Is an HDL a programming language?

It looks like one, but synthesizable HDL code describes hardware that runs concurrently, not instructions executed in order. Each line costs circuit area, so designers think in terms of registers and logic rather than steps.

When should blocking and nonblocking assignments be used in Verilog?

The common guideline is nonblocking (<=) in clocked always blocks and blocking (=) in combinational blocks. Mixing them in one block is a frequent source of simulation-synthesis mismatches.
