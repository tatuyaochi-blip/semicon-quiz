What is ATPG (automatic test pattern generation)?

Automatically generating test patterns that detect faults from a circuit's netlist. It is used together with scan design.

Field: Testing and inspection

ATPG (automatic test pattern generation) in the explanations

  • This turns sequential-circuit testing into combinational-circuit testing, letting ATPG automatically generate patterns with high fault coverage.
