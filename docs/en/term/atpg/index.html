What is ATPG (automatic test pattern generation)?

Automatically generating test patterns that detect faults from a circuit's netlist. It is used together with scan design.

Japanese name: ATPG(自動テストパターン生成)

Which correctly describes scan design, a form of design for testability (DFT)?

  1. AScanning the chip surface with an optical microscope to find defects
  2. BGradually raising the supply voltage during test to find the operating limit
  3. CConnecting the flip-flops in a circuit like a shift register to make it easy to set and observe internal states
Show answer and explanation

Answer: C. Connecting the flip-flops in a circuit like a shift register to make it easy to set and observe internal states

Scan design adds a multiplexer at each flip-flop input; in test mode the flip-flops are chained into scan chains so arbitrary values can be shifted in and internal values shifted out. This turns sequential-circuit testing into combinational-circuit testing, letting ATPG automatically generate patterns with high fault coverage. It has nothing to do with microscope scanning or voltage sweeps.

Which correctly describes the stuck-at fault model used in testing logic circuits?

  1. AA fault in which signals propagate more slowly
  2. BA fault in which a signal line's value is fixed at 0 or 1
  3. CA fault in which the chip's temperature rises
Show answer and explanation

Answer: B. A fault in which a signal line's value is fixed at 0 or 1

The stuck-at model assumes a signal line is permanently fixed at 0 (stuck-at-0) or 1 (stuck-at-1), giving 2n faults for n lines. Simple as it is, it represents many physical defects such as shorts and opens, and it underpins ATPG and fault-coverage evaluation. Slow signals are handled by delay fault models, and temperature rise is not a fault model.
