What is JTAG?

A standard interface for chip testing and debugging that lets developers halt programs, inspect internal values and program flash. Arm also uses SWD, which needs fewer wires.

Japanese name: JTAG

What is the main use of boundary scan, specified in IEEE 1149.1 (JTAG)?

  1. AMeasuring film thickness on wafers
  2. BEvaluating electromigration in wiring
  3. CTesting connections between the pins of ICs mounted on a printed circuit board, without applying probes
Show answer and explanation

Answer: C. Testing connections between the pins of ICs mounted on a printed circuit board, without applying probes

Boundary scan places scan cells just inside each I/O pin and chains them serially, so values can be set and observed externally through four signals, TDI, TDO, TCK and TMS (plus an optional reset). Solder opens and shorts on the board can be tested even for BGAs whose pins cannot be probed. The same port is widely used for debugging and programming flash memory.

What can be done through debug interfaces such as JTAG and SWD?

  1. AHalt or single-step the program on the real board, inspect registers and variables, and program flash
  2. BChange the microcontroller's manufacturing process
  3. CAutomatically translate the program into another language
Show answer and explanation

Answer: A. Halt or single-step the program on the real board, inspect registers and variables, and program flash

JTAG and Arm's SWD connect the on-chip debug circuitry to a debugger on a PC. You can stop at breakpoints to examine variables and registers, step one instruction at a time and program the flash. They reveal internal state even where printf cannot be used. When shipping a product, the debug function may be disabled so that third parties cannot read out the firmware.
