What is Booth's algorithm?

A multiplication method that recodes the multiplier's bits, for example in pairs, into signed digits to reduce the number of partial products. Radix-4 Booth encoding roughly halves them.

Japanese name: ブースのアルゴリズム

Answer: B. Signed-digit recoding roughly halves the partial products

Ordinary multiplication produces one partial product per multiplier bit, so n bits require summing n partial products. Radix-4 Booth encoding recodes the multiplier two bits at a time (examining overlapping 3-bit groups) into digits −2, −1, 0, +1 and +2, reducing the partial products to about n/2. Doubling is a one-bit shift and negatives are formed with two's complement, so the circuitry is simple. Fewer partial products make the summing logic smaller and faster, and signed multiplication is handled naturally.
