What is Real-time operating system (RTOS)?

An embedded OS that switches tasks by priority so the system responds within set time limits, such as FreeRTOS and Zephyr.

Japanese name: RTOS(リアルタイムOS)

Try it: questions about Real-time operating system (RTOS)

What is the main purpose of using an RTOS (real-time operating system) in embedded devices?

  1. ATo display attractive windows on a screen
  2. BTo make average processing speed always faster than a PC OS
  3. CTo switch among multiple tasks by priority so the system can respond within set time limits
Show answer and explanation

Answer: C. To switch among multiple tasks by priority so the system can respond within set time limits

An RTOS divides work into tasks and switches to a higher-priority task as soon as it becomes ready to run. Its purpose is to make sure time-critical work, such as motor control or communication responses, happens reliably within set time limits. It also provides queues for passing data between tasks, mutexes for protecting resources and timed waits. Examples include FreeRTOS, Zephyr and μITRON.

In a preemptive RTOS, while a low-priority task is running, a high-priority task receives the data it was waiting for and becomes ready. What generally happens?

  1. AThe high-priority task waits until the low-priority task finishes on its own
  2. BBoth tasks stop and the microcontroller reboots
  3. CThe low-priority task is suspended midway and the high-priority task runs immediately
Show answer and explanation

Answer: C. The low-priority task is suspended midway and the high-priority task runs immediately

In a preemptive RTOS, when an interrupt or similar event makes a higher-priority task ready, the kernel saves and suspends the running low-priority task and switches to the high-priority one. When the high-priority task finishes or blocks, the low-priority task resumes where it left off. This keeps response times for high-priority work short and predictable.
