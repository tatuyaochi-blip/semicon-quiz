What is Cross-point memory?

Memory with a storage element at each intersection of row and column lines. It is very dense, but a selector is placed in series with each element to stop current sneaking through unselected cells.

Japanese name: クロスポイント型メモリ

Try it: questions about Cross-point memory

In a cross-point memory with resistive elements placed at the intersections of row and column lines, which element is placed in series with the storage element to prevent current from sneaking through unselected cells?

  1. ACapacitor
  2. BInductor
  3. CSelector
Show answer and explanation

Answer: C. Selector

Crosspoint arrays place storage elements directly at word-line/bit-line intersections without per-cell transistors, achieving the minimum 4F² cell and allowing layers to be stacked. Sneak currents through unselected cells disrupt reads, however, so a selector that conducts almost nothing below a threshold voltage is placed in series. Selectors need extremely nonlinear behavior: high on-current and very low off-current.
