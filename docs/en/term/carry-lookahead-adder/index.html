What is Carry-lookahead adder?

An adder that computes carries in parallel from each bit's generate signal g = a·b and propagate signal p = a ⊕ b, without waiting for carries to ripple. Delay stays small even for wide operands.

Field: Computer Arithmetic

Carry-lookahead adder in the explanations

  • A carry-lookahead adder uses per-bit generate G = A·B (always produces a carry) and propagate P = A⊕B (passes a lower carry) to compute each carry directly from the inputs in parallel: C1 = G0 + P0·C0, C2 = G1 + P1·G0 + P1·P0·C0, and so on.
