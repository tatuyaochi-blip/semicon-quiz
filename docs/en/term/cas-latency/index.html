What is CAS latency?

The number of clock cycles in DRAM from a read command (specifying the column address) until data appears at the output, abbreviated CL. Smaller values mean a faster response.

Field: DRAM

What CAS latency measures

CAS stands for column address strobe. A DRAM read first activates a row, copying it into the sense amplifiers, and then issues a read command carrying the column address. The CAS latency (CL) is the number of clock cycles from that read command until the first data appears at the output. After that, the rest of the burst follows on successive clock edges. Because CL is counted in cycles, the actual delay in nanoseconds is CL multiplied by the clock period, and a smaller CL is faster only when the clock speed is the same.

Converting CL to nanoseconds

For DDR memory the data rate is twice the clock frequency, so DDR4-3200 transfers 3200 million times per second on a 1600 MHz clock with a period of 0.625 ns. CL22 then corresponds to 22 × 0.625 ns ≈ 13.75 ns. DDR3-1600 runs an 800 MHz clock with a 1.25 ns period, so CL11 is also about 13.75 ns. The larger CL number of the newer generation hides an essentially unchanged delay, because the speed of the memory cell array improves little between generations while the interface clock keeps rising.

Where CL fits among DRAM timings

CL is only one part of an access. If the needed row is not open, the controller must first precharge the bank to close the old row (tRP), then activate the new one and wait the RAS-to-CAS delay (tRCD) before issuing the read, and only then wait CL. Timings are often quoted together, such as CL-tRCD-tRP. A page hit, where the row is already open in the sense amplifiers, needs only CL, so memory controllers reorder requests to group accesses to the same row and increase the fraction of hits.

Latency vs. bandwidth

CAS latency describes how long the first word takes, while bandwidth describes how fast data streams once it starts. Faster memory generations mainly raise bandwidth by increasing the data rate and burst length; first-word latency in nanoseconds has stayed in a similar range. Workloads that stream large blocks benefit from bandwidth, while pointer chasing and random accesses that miss in the processor's caches are more sensitive to latency. Comparing modules therefore requires converting CL to nanoseconds and also considering the other timings, not just the CL number.

FAQ

What does CAS latency mean for RAM?

CAS latency is the number of memory clock cycles between a read command with a column address and the first data output. Multiplying it by the clock period gives the actual delay in nanoseconds.

Is lower CAS latency always faster?

Only at the same clock speed. A higher-frequency module with a larger CL can have the same or lower latency in nanoseconds, so CL must be converted using the clock period before comparing.

Why are CAS latency numbers larger for newer DDR generations?

The DRAM cell array's response time in nanoseconds has changed little, while the clock period keeps shrinking. More clock cycles are therefore needed to cover about the same delay.
