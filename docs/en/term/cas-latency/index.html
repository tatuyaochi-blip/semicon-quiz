What is CAS latency?

The number of clock cycles in DRAM from a read command (specifying the column address) until data appears at the output, abbreviated CL. Smaller values mean a faster response.

Answer: B. The number of clock cycles from a read command (specifying the column address) until data is output

CAS latency is the number of clock cycles from a read command (column address) to the first data. Actual time is CL × clock period: DDR4-3200 CL22 is 22 × 0.625 ns ≈ 13.75 ns, and DDR3-1600 CL11 is 11 × 1.25 ns ≈ 13.75 ns—a bigger number, but about the same time. Because the cell array's speed barely changes between generations, CL values grow with each generation.
