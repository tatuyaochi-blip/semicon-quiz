What is Slack?

A value expressing timing margin. For setup it is required time minus arrival time, and for hold it is arrival time minus required time; a negative value means a violation.

Japanese name: スラック

Try it: questions about Slack

In a synchronous circuit with a clock period of 2.0 ns, the launching flip-flop's clock-to-output delay is 0.2 ns, the combinational logic delay is 1.4 ns and the capturing flip-flop's setup time is 0.1 ns. With zero clock skew, what is the setup slack?

  1. A0.3 ns
  2. B0.4 ns
  3. C0.5 ns
Show answer and explanation

Answer: A. 0.3 ns

Setup slack is calculated as "required time − arrival time." The data arrival time is 0.2 + 1.4 = 1.6 ns and the required time is the next clock edge minus the setup time, 2.0 − 0.1 = 1.9 ns, so the slack is 1.9 − 1.6 = 0.3 ns. Being positive, it meets the constraint. 0.4 ns is the value obtained by forgetting to subtract the setup time, and 0.5 ns by adding the setup time instead. A negative slack means a violation.

A path has a clock period of 1.0 ns, a clock-to-output delay of 0.1 ns, a combinational logic delay of 0.85 ns and a setup time of 0.08 ns. If the clock arrives at the capturing flip-flop 0.05 ns later than at the launching flip-flop, what is the setup slack?

  1. A−0.03 ns
  2. B+0.02 ns
  3. C−0.08 ns
Show answer and explanation

Answer: B. +0.02 ns

When the capture clock arrives late (positive skew), the capturing edge shifts later, giving more time for setup. The required time is 1.0 + 0.05 − 0.08 = 0.97 ns and the arrival time is 0.1 + 0.85 = 0.95 ns, so the slack is +0.02 ns. −0.03 ns ignores the skew, and −0.08 ns treats the skew in the opposite direction (as if the capture clock arrived early). Note that the same skew works against hold.
