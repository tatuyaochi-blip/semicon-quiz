What is Condition code?

Flags such as zero, negative, carry and overflow that record the outcome of a compare or arithmetic operation. Conditional branches in x86 and Arm test them; RISC-V has none.

Japanese name: 条件コード

Answer: C. In RISC-V the branch compares two registers directly; in x86 the branch tests flags set by a compare instruction

In x86, "cmp eax, ebx" compares and sets flags (condition codes) such as zero and carry, and the following "je" or "jl" branches on those flags. RISC-V has no flags; the branch itself compares two registers, as in "beq a0, a1, L" or "blt a0, a1, L". With no implicit state like flags, dependences are easier to track when instructions are reordered or executed in parallel.
