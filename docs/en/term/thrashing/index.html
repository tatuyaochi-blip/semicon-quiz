What is Thrashing?

A state in which physical memory is so short that pages are constantly evicted and reloaded, and little useful work gets done. It is relieved by running fewer processes or adding memory.

Japanese name: スラッシング

Try it: questions about Thrashing

With FIFO page replacement, adding physical pages can sometimes increase page faults. What is this phenomenon called?

  1. AThrashing
  2. BBélády's anomaly
  3. CCopy-on-write
Show answer and explanation

Answer: B. Bélády's anomaly

Intuitively, more physical pages should mean fewer page faults, but with FIFO certain access sequences are known to fault more when the page count grows from three to four. This is Bélády's anomaly. It cannot occur with stack algorithms such as LRU, where the set of pages held with more frames always contains the set held with fewer. Thrashing is constant replacement from memory shortage, and copy-on-write copies pages on write.

What is the state called in which physical memory is so short that pages are constantly evicted and reloaded and little work gets done?

  1. ADeadlock
  2. BCache coherence
  3. CThrashing
Show answer and explanation

Answer: C. Thrashing

When the combined working sets of running processes exceed physical memory, loading a needed page evicts a page another process needs, which is then needed again almost immediately. Time is spent waiting on disk I/O and CPU utilization falls. This is thrashing, relieved by running fewer processes or adding memory. Deadlock is when tasks stop because each waits for resources held by the other.
