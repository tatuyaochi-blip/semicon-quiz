What is Position-independent code?

Machine code that runs without modification at any load address, also called PIC. It uses PC-relative references and the GOT and is used for shared libraries and PIEs.

Field: Linkers, Loaders & Executables

Position-independent code in the explanations

  • Position-independent code refers to functions and data not by fixed addresses but by distances from the PC or through a table of addresses (the GOT).
