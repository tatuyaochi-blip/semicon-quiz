Field: Logic circuits

What a combinational circuit is

A combinational circuit is a logic circuit whose output depends only on its current inputs. It is built from gates such as AND, OR and NOT connected without feedback from outputs to inputs, and for a given input it always produces the same output after the gate delays. Having no memory, its input-output relationship can be fully described by a truth table or a Boolean expression. Typical examples are adders, multiplexers, decoders, encoders and comparators, and most of a CPU's arithmetic logic unit (ALU) is combinational. In design, Karnaugh maps or logic synthesis tools simplify the logic expressions into forms that need fewer gates.

Versus sequential circuits

A sequential circuit contains memory elements such as flip-flops, and its output depends not only on the current inputs but also on its internal state, the history of past inputs. Counters, registers and state machines are typical examples. Real digital circuits combine the two, placing combinational logic between registers synchronized by a clock. In each clock cycle the combinational logic computes the next values from the register contents, and the registers capture them at the next clock edge. Feeding a combinational circuit's output back to its own input without passing through a flip-flop creates a combinational loop, which can oscillate or leave values undefined, so it is avoided.

Delay and glitches

A combinational circuit's output settles only after the gate and wire delays following an input change. The slowest path from input to output, the critical path, is one of the factors that sets the maximum clock frequency of a synchronous circuit. When a single input change reaches the output through paths with different delays, the output can briefly take a wrong value, a glitch (hazard). In a synchronous circuit this is functionally harmless as long as the output settles before the clock edge, but the extra charging and discharging increases power consumption. On signals used as clocks or asynchronous resets, glitches can cause malfunctions.

Describing it in HDL

In Verilog and SystemVerilog, combinational circuits are written with assign statements or with always @(*) and always_comb blocks. In an always block, the output must be assigned a value under every condition. If some case leaves it unassigned, the previous value must be held, and logic synthesis infers an unintended latch. To prevent this, assign a default value at the top of the block, always give if statements an else, and give case statements a default. A common guideline is also to use blocking assignments (=) in combinational always blocks.

Answer: B. Glitch (hazard)

When one input change reaches the output along paths with different delays, the output can briefly show a wrong value—a glitch (hazard). In synchronous circuits it is functionally harmless if it settles before the clock edge, but the extra switching wastes power. Glitches on clocks, asynchronous resets or control signals to other chips cause malfunctions, so such signals should come directly from flip-flop outputs.

FAQ

What is a combinational circuit?

It is a logic circuit with no memory whose output depends only on its current inputs. Adders, multiplexers and decoders are typical examples, and the input-output relationship can be fully described by a truth table.

What is the difference between combinational and sequential circuits?

A combinational circuit's output depends only on the current inputs. A sequential circuit contains memory elements such as flip-flops, and its output depends on both the current inputs and its internal state, the history of past inputs. Real digital circuits use both together, with combinational logic placed between registers.

Are latches and flip-flops combinational circuits?

No. Latches and flip-flops store values, so they are sequential circuits. Even when HDL code is meant to describe combinational logic, an unintended latch can be created if some case leaves the output unassigned.
