What is Packet?

A unit of data for transmission: data split into pieces no larger than a set size, each with a header carrying control information such as the destination. Packets let many conversations share one line (packet switching) and let only the damaged part be resent after an error. Depending on the layer, the units are often called packets in IP, segments in TCP and frames in Ethernet. PCI Express and networks-on-chip also send data as packets.

Japanese name: パケット

Try it: questions about Packet

In PCI Express, sending many packets that each write 64 bytes yields effective bandwidth well below the theoretical figure. What is the main reason?

  1. A64-byte payloads cannot be sent over PCI Express
  2. BEach packet carries headers, error-detection codes and other overhead, which are large relative to the data
  3. CSmall packets are always corrupted and resent every time
Show answer and explanation

Answer: B. Each packet carries headers, error-detection codes and other overhead, which are large relative to the data

Besides data, a PCI Express packet carries a header with address and type, a data-link sequence number and CRC, physical-layer framing and so on, about 20 to 30 bytes in total. With 64 bytes of data, roughly 30% of the bits sent are not data. Transfers of 256 bytes or more shrink this share. This is another reason to watch packet size, not just raw bandwidth.

In the OSI reference model, which layer uses logical addresses such as IP addresses to relay packets between different networks until they reach their destination?

  1. AData link layer (layer 2)
  2. BNetwork layer (layer 3)
  3. CTransport layer (layer 4)
Show answer and explanation

Answer: B. Network layer (layer 3)

The OSI reference model organizes communication functions into seven layers, from the physical layer up to the application layer. The network layer (layer 3) uses logical addresses such as IP addresses to choose a route across multiple networks and relay packets to the destination. The data link layer below it only delivers frames to a neighboring device within the same network, using MAC addresses. The transport layer handles communication between applications on the end hosts; TCP, for example, manages retransmission and ordering. In terms of equipment, routers operate at layer 3 and L2 switches at layer 2.
