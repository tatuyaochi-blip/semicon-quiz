What is Precharge?

Charging the bit lines to a set potential (half the supply voltage in DRAM, for example) before a read. In DRAM it also means closing the open row to prepare for activating the next one.

Japanese name: プリチャージ

Precharge appears in 2 practice questions across 1 topic, including DRAM.

Field: DRAM

Precharge in the DRAM read path

Each DRAM sense amplifier sits on a pair of bit lines that are equalized to half the array supply, VDD/2, before a row is opened. When a word line turns on, the cell capacitor shares its charge with the much larger bit-line capacitance and nudges that line slightly up for a stored 1 or down for a 0. Starting from the midpoint makes the two cases symmetric, and the sense amplifier compares the disturbed line with its untouched partner, then drives both to full logic levels, restoring the cell in the process.

Precharge as a DRAM command

At the command level, precharge (PRE) closes the open row of a bank, letting the word line turn off and the bit lines return to VDD/2 so a different row can be activated. A typical access sequence is activate (ACT), wait tRCD, read or write, then precharge, and wait tRP before the next activate. The row cycle time tRC is tRAS plus tRP. Read and write commands can also carry auto-precharge, closing the row automatically, and a precharge-all command closes every bank, which is required before an all-bank refresh.

Open-page vs. closed-page policies

While a row stays open its data sits in the sense amplifiers, so another access to that row needs only a column command and the CAS latency. Accessing a different row in the same bank instead costs precharge, activation and column access, roughly tRP + tRCD + CL. Memory controllers therefore choose policies: leave pages open when accesses show locality, or precharge early when access is random. They also reorder queued requests to favor row hits. In DDR4 and DDR5 parts, tRP is usually a figure close to the CAS latency.

Precharge elsewhere in circuits

The word appears in other contexts too. SRAM bit lines are typically precharged high, usually to VDD, and a read is detected as one line discharging slightly. Dynamic (domino) logic precharges an internal node high during one clock phase and conditionally discharges it during the evaluate phase. In power electronics, precharging means charging a large DC-link capacitor bank slowly through a resistor to limit inrush current before closing the main contactor. The common idea is preparing a node at a known voltage before the real operation begins.

In DRAM, why is access time shorter when the same row (page) is accessed repeatedly?

  1. ABecause refresh is no longer needed
  2. BBecause the supply voltage rises
  3. CBecause the data of an activated row is held in the sense amplifiers and can be read by just switching columns
Show answer and explanation

Answer: C. Because the data of an activated row is held in the sense amplifiers and can be read by just switching columns

Activating a row reads all its cells into the sense amplifiers, where it stays open as a page. Accesses to the same row need only a new column address (the CAS latency), avoiding the precharge, activation and column access required to move to another row. Memory controllers reorder requests—grouping those to the same row, for example—to increase these page hits.

In DRAM access, what is the operation called that closes the open row and returns the bit lines to an intermediate voltage to prepare for activating the next row?

  1. ARefresh
  2. BPrecharge
  3. CErase
Show answer and explanation

Answer: B. Precharge

Precharge closes the current row and returns the bit lines to a midpoint voltage (VDD/2) before another row is accessed. Starting from the midpoint lets the bit line swing equally up or down for a 1 or a 0, making the sense amplifier's decision easier. The time, specified as tRP, adds to row-switch latency. Memory controllers choose between leaving pages open or closing them based on access patterns.

FAQ

What is tRP in RAM timings?

tRP is the row precharge time, the minimum delay between a precharge command and the next activate to the same bank. It is usually the third number in timings written like CL-tRCD-tRP.

Why are DRAM bit lines precharged to VDD/2?

A cell can then pull the bit line either up or down by a similar small amount, so the sense amplifier sees symmetric signals for 1 and 0 against the midpoint reference.

What is the difference between precharge and refresh in DRAM?

Precharge closes an open row and resets the bit lines; refresh periodically reads and rewrites rows so their leaking charge is restored. A refresh internally involves activation and precharge of the rows it touches.
