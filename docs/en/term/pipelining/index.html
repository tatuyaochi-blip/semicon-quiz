What is Pipelining?

A method that splits instruction processing into stages such as fetch, decode and execute, and processes several instructions at once, each offset by a stage.

Field: CPUs and architecture

Pipelining in the explanations

  • Pipelining overlaps stages such as fetch, decode, execute, memory access and write-back like an assembly line, completing one instruction per clock to raise throughput—ideally about 5× for five stages.

    What is the main purpose of pipelining in a CPU?

  • Software pipelining divides one loop iteration into stages such as load, compute and store, then arranges instructions so that, for example, the store for iteration i, the computation for i+1 and the load for i+2 happen within the same loop body.
