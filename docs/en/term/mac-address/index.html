What is MAC address?

The 48-bit address used in Ethernet and wireless LAN to identify devices within the same network. The upper 24 bits identify the manufacturer, and it is assigned to each interface at manufacture.

Japanese name: MACアドレス

Try it: questions about MAC address

A host (192.168.1.10/24, default gateway 192.168.1.1) sends a packet to server 203.0.113.80 on a different network. With an empty ARP cache, whose MAC address does the host look up with ARP?

  1. AThe default gateway, 192.168.1.1
  2. BThe server, 203.0.113.80
  3. CEvery router on the path to the server
Show answer and explanation

Answer: A. The default gateway, 192.168.1.1

The host first uses its own IP address and subnet mask to decide whether the destination is on the same network. 203.0.113.80 is outside 192.168.1.0/24, so the packet is handed to the default gateway (a router). The destination in the IP header stays the server's 203.0.113.80; only the frame's destination MAC address is set to the gateway's. So ARP looks up the MAC address of 192.168.1.1. ARP broadcasts do not cross routers, so the host cannot look up, and does not need, the MAC address of a server on another network. Each router along the path looks up the MAC address of the next device whenever it forwards.

When an L2 switch receives a frame, which information does it record in its MAC address table?

  1. AThe frame's source MAC address and the port on which the frame arrived
  2. BThe frame's destination MAC address and the port out of which the frame was sent
  3. CA pair made of an IP address in the frame and the MAC address that corresponds to it
Show answer and explanation

Answer: A. The frame's source MAC address and the port on which the frame arrived

An L2 switch looks at the source MAC address of each frame it receives and records in its MAC address table that "this device is behind this port" (learning). To forward a frame, it looks up the destination MAC address in the table; if there is an entry it sends the frame only out of that port, and if not it sends it out of every port except the one it arrived on (flooding). The destination MAC address says nothing about where that device is, so it cannot be used for learning. An entry is removed if no frame arrives from that device for a set time (for example 300 seconds), so the table can follow devices that move.
