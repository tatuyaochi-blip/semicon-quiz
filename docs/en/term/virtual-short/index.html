What is Virtual short?

The property of an ideal op-amp with negative feedback that its two input voltages become nearly equal. Although no current flows between them, they can be treated as shorted, which makes gain calculations simple.

Japanese name: 仮想短絡(イマジナリーショート)

Field: Analog and electronic circuits

Why the inputs end up equal

An op-amp's output is Vout = A(V+ − V−), where the open-loop gain A is very large, about 10⁵ to 10⁶ for typical real devices at low frequency. With negative feedback the circuit settles where the output is finite, so the input difference must be Vout/A. For an output of 10 V and A = 10⁵, the inputs differ by only 100 µV. In ideal analysis A is infinite, the difference becomes zero, and the two inputs can be treated as being at the same voltage.

Using it: the inverting amplifier

In an inverting amplifier the non-inverting input is grounded, so the virtual short puts the inverting input at 0 V; this special case is called a virtual ground. The input current is then Vin/R1. Because an ideal op-amp input draws no current, all of it flows through the feedback resistor Rf, giving Vout = −(Rf/R1)·Vin. The same two rules give the non-inverting gain of 1 + Rf/R1 and analyze summing amplifiers, integrators and differential amplifiers.

Virtual short vs. a real short

A real short would let current flow between the inputs; a virtual short does not. Analysis therefore uses two separate ideal-op-amp assumptions together: the inputs are at equal voltage because of feedback and high gain, and no current enters either input because of the infinite input impedance. Confusing the two, for example by letting current flow from one input to the other, gives wrong answers. The equality is maintained actively by the output, not by any connection.

When the assumption fails

The virtual short holds only while negative feedback is working. If the output saturates at a supply rail, is slew-rate limited or the signal frequency is so high that the loop gain has fallen, the inputs separate. Comparators and Schmitt triggers run open loop or with positive feedback, so their inputs are deliberately unequal. Real op-amps also have an input offset voltage, from microvolts to a few millivolts, that appears as a small, constant difference between the inputs.

Which combination correctly describes an ideal op-amp?

  1. AInput impedance: infinite; output impedance: 0
  2. BInput impedance: 0; output impedance: infinite
  3. CInput impedance: 0; output impedance: 0
Show answer and explanation

Answer: A. Input impedance: infinite; output impedance: 0

An ideal op-amp is assumed to have infinite input impedance (no current into the inputs), zero output impedance (output voltage independent of load) and infinite open-loop gain. From these assumptions, a negative-feedback circuit keeps both inputs at the same voltage—the "virtual short"—so circuit gain depends only on resistor ratios. Real op-amps have open-loop gains of about 10⁵–10⁶, which fall with frequency.

In an ideal op-amp circuit with negative feedback, what is the property called by which the two input terminals have almost the same voltage?

  1. ASlew rate
  2. BOffset
  3. CVirtual short
Show answer and explanation

Answer: C. Virtual short

When an op-amp with huge open-loop gain A has negative feedback, the output settles at a finite value, so the voltage between its inputs is Vout/A—essentially zero. The inputs look shorted without being connected, hence "virtual short"; with the non-inverting input grounded, the inverting input sits at 0 V (virtual ground). This is the foundation of op-amp analysis, but it fails when the output saturates or in positive-feedback circuits such as comparators.

FAQ

What is the difference between virtual short and virtual ground?

Virtual short is the general property that both inputs sit at the same voltage under negative feedback; virtual ground is the case where one input is grounded, so the other is held at 0 V.

Does current flow through a virtual short?

No. The inputs are at the same voltage but not connected, and an ideal op-amp draws no input current.

Why can't the virtual short be used for a comparator?

A comparator has no negative feedback, so its output swings to a rail and nothing forces the inputs to the same voltage.
