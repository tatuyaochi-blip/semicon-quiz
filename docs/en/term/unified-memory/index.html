What is Unified memory?

Memory accessible from CPU and GPU through the same pointer, with data migrating automatically on access. It simplifies programs, but migration costs need attention.

Field: GPU Programming

Unified memory in the explanations

  • With unified memory, an allocation can be accessed from both CPU and GPU through the same pointer, and data migrates page by page to whichever side accesses it.
