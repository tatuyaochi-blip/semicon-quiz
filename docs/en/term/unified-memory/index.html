What is Unified memory?

Memory accessible from CPU and GPU through the same pointer, with data migrating automatically on access. It simplifies programs, but migration costs need attention.

Japanese name: ユニファイドメモリ

Which describes CUDA unified memory?

  1. AMemory usable from both CPU and GPU through the same pointer, with data migrating automatically as needed
  2. BThe CPU and GPU physically merged into one chip
  3. CGPU memory made entirely read-only
Show answer and explanation

Answer: A. Memory usable from both CPU and GPU through the same pointer, with data migrating automatically as needed

With unified memory, an allocation can be accessed from both CPU and GPU through the same pointer, and data migrates page by page to whichever side accesses it. Programs become simpler, and data larger than GPU memory is easier to handle. Each migration involves page faults and transfers, though, so for performance, programs issue hints to prefetch data in advance.
