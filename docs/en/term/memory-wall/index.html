What is Memory wall?

The problem that memory bandwidth and latency improve more slowly than processor performance, limiting overall performance. HBM, larger caches and advanced packaging are used to address it.

Japanese name: メモリウォール

Memory wall appears in 2 practice questions across 2 topics, including DRAM, Advanced packaging (3D and chiplets).

Field: DRAM

Try it: questions about Memory wall

What is the performance limitation called that arises because improvements in memory bandwidth and latency have not kept up with improvements in processor performance?

  1. AMoore's law
  2. BSilicon cycle
  3. CMemory wall
Show answer and explanation

Answer: C. Memory wall

Processor performance at times grew more than 50% per year, but DRAM access latency has stayed at tens of nanoseconds, leaving CPUs waiting hundreds of cycles for data—the memory wall. Responses include multilevel caches, parallel memory access, prefetching, high-bandwidth memory such as HBM, and processing-in-memory, which computes near the data.

What is the problem called in which the speed of supplying data from memory cannot keep up with improvements in processor compute performance, limiting overall performance?

  1. AThe thermal wall
  2. BThe memory wall
  3. CMoore's law
Show answer and explanation

Answer: B. The memory wall

Processor compute performance has grown rapidly, but bandwidth to memory has grown more slowly, so compute units spend more time waiting for data. This is the memory wall. It is especially severe for large AI models, which read huge numbers of weights for every computation, and advanced packaging that places HBM next to the processor, along with stacked large caches, are countermeasures.
