What is Garbage collection?

In an SSD, moving the still-valid data out of blocks that contain invalid data and then erasing those blocks to create free space.

Japanese name: ガベージコレクション

Which correctly describes garbage collection in an SSD?

  1. AMoving valid data out of blocks that contain invalid data, then erasing those blocks to create free space
  2. BRemoving computer viruses
  3. CCompressing data
Show answer and explanation

Answer: A. Moving valid data out of blocks that contain invalid data, then erasing those blocks to create free space

NAND cannot overwrite in place and erases only by block, so each rewrite leaves the old version behind as an invalid page. The controller picks blocks with many invalid pages, moves their valid data to another block, and erases them to create free space. These extra copies cause write amplification, and the fuller the drive, the more often garbage collection runs and the more write performance suffers.

Which command notifies an SSD of space freed by files deleted by the OS, making garbage collection more efficient?

  1. AECC
  2. BISPP
  3. CTRIM
Show answer and explanation

Answer: C. TRIM

Deleting a file only updates the OS's bookkeeping, so the SSD does not know the data is obsolete and keeps copying it during garbage collection. The TRIM command tells the SSD which ranges are no longer needed; it marks those pages invalid and can erase them without copying, reducing write amplification and improving performance and lifespan. NVMe provides the same function through the Deallocate command.
