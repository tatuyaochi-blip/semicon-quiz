What is Spinlock?

A lock that waits by repeatedly checking the lock variable in a loop. Fast for short waits, but it keeps using the CPU while waiting.

Field: Multicore & Synchronization

Spinlock in the explanations

  • A spinlock tries to acquire the lock with an atomic instruction and, if that fails, immediately tries again, over and over.

  • A thread waiting on a spinlock keeps using the CPU until the lock is free.
