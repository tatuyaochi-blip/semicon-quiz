What is RSA cryptosystem?

A public-key cryptosystem devised in 1977 by Rivest, Shamir and Adleman. The public key is the product n of two large primes p and q together with a public exponent e, and the private key is the d that satisfies e × d ≡ 1 (mod (p − 1)(q − 1)). Encryption is c = m^e mod n and decryption m = c^d mod n. Its security rests on the difficulty of factoring n, and it can be used for both encryption and signatures. In practice it is combined with randomized padding such as OAEP or PSS.

A small-number example

With p = 5 and q = 11, n = 55 and (p − 1)(q − 1) = 40. Taking e = 3, 3 × 27 = 81 ≡ 1 (mod 40), so d = 27. The plaintext m = 7 is encrypted as 7³ = 343 ≡ 13 (mod 55), and computing 13^27 mod 55 gives back 7.

Key length and security

In the table of NIST SP 800-57, a 2048-bit n is a guideline for 112-bit security and 3072 bits for 128-bit security. For the same security, RSA needs much longer keys and signatures than elliptic-curve cryptography, and key generation and signing are heavier. The public exponent is usually 65537 (2^16 + 1), which keeps the computation fast.

How its use has changed

Older versions of TLS widely used a key exchange in which the client encrypted key material with the server's RSA public key, but it was removed in TLS 1.3 because it lacks forward secrecy. Today RSA is mainly used for signatures on certificates and software. A large quantum computer could break it with Shor's algorithm, so migration to post-quantum cryptography is under way.

Try it: questions about RSA cryptosystem

The mechanism of RSA is checked with small numbers. From the primes p = 5 and q = 11, n = pq is formed, and the public exponent is e = 3. With φ(n) = (p − 1)(q − 1), which of the following is the private exponent d (0 < d < φ(n)) that satisfies e × d ≡ 1 (mod φ(n))?

  1. A5
  2. B27
  3. C37
Show answer and explanation

Answer: B. 27

n = 5 × 11 = 55 and φ(n) = 4 × 10 = 40. Looking for d such that 3 × d leaves a remainder of 1 when divided by 40, 3 × 27 = 81 = 2 × 40 + 1, so d = 27. The public key is (n, e) = (55, 3) and the private key is d = 27; the security rests on the fact that without knowing p and q one cannot find φ(n), and so cannot find d. In real RSA, p and q are each large primes of more than 1000 bits, and e is commonly 65537.

In RSA, let the public key be n = 55 and e = 3. Which of the following is the ciphertext c when the plaintext m = 7 is encrypted as c = m^e mod n?

  1. A13
  2. B21
  3. C23
Show answer and explanation

Answer: A. 13

7³ = 343, and 343 = 6 × 55 + 13, so c = 13. The private exponent for this public key is d = 27 (with p = 5, q = 11 and φ(n) = 40, 3 × 27 ≡ 1), and computing 13^27 mod 55 gives back the original plaintext 7. Encryption needs only the public key, but decryption requires d.

FAQ

Why must p and q be kept secret?

Because anyone who knows p and q can compute (p − 1)(q − 1) and then derive d from the public e. Since n is public, the security relies on the difficulty of factoring n.

Why is RSA not used to encrypt files directly?

RSA can only encrypt numbers smaller than n at a time, and it is far slower than symmetric-key encryption. In practice the file is encrypted with a symmetric cipher such as AES, and only that symmetric key is protected with the public key, which is called hybrid encryption.
