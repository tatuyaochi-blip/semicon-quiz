What is Sequential circuit?

A logic circuit that stores state in flip-flops and the like, so its output depends on both inputs and past state. Examples include counters and registers.

Japanese name: 順序回路

Field: Logic circuits

State, next-state logic and the clock

A synchronous sequential circuit has two parts: a state register built from flip-flops and combinational logic that computes the next state and the outputs from the current state and inputs. On each active clock edge the register loads the next state. This feedback loop through memory is what lets the circuit count, remember a sequence or track how many coins a vending machine has received. Asynchronous sequential circuits use latches or feedback without a common clock, which makes them harder to design reliably.

Moore vs. Mealy machines

In a Moore machine the outputs depend only on the current state, so they change only after a clock edge and come cleanly from the state register without glitches. In a Mealy machine the outputs depend on the state and the current inputs, so they can react within the same clock cycle and often need fewer states, but input changes and glitches propagate straight to the outputs. Practical controllers frequently mix both styles, registering outputs where clean timing matters.

Sequential vs. combinational circuits

A combinational circuit such as an adder, decoder or multiplexer has no memory: the same inputs always give the same outputs after the propagation delay. A sequential circuit can give different outputs for identical inputs because its history differs. Real digital systems alternate the two, with banks of registers separated by clouds of combinational logic, all synchronized by the clock. Latches, flip-flops, counters, shift registers and finite state machines are the standard sequential building blocks.

Timing constraints

For a synchronous design to work, data must arrive at each flip-flop at least a setup time before the clock edge and stay stable for a hold time after it. The minimum clock period is roughly the clock-to-output delay plus the longest combinational path plus the setup time, which sets the maximum frequency. Inputs from another clock domain can violate these windows and drive a flip-flop into metastability, so they pass through synchronizers, typically two flip-flops in series.

  2. BIts output depends only on the current inputs
  3. CIt handles only analog signals

Answer: A. Its output depends on the current inputs and a stored internal state

A sequential circuit contains memory elements such as flip-flops, so its output depends not only on current inputs but also on past history (its internal state). Counters, registers and state machines are typical examples, able to model things like a vending machine tracking inserted coins. Circuits whose output depends only on current inputs are combinational (adders, decoders, etc.), and real digital systems alternate the two, synchronized by a clock.

Which type of sequential circuit (state machine) has outputs determined only by the current state?

  1. AMealy machine
  2. BMoore machine
  3. CHarvard machine

Answer: B. Moore machine

In a Moore machine, outputs depend only on the current state; in a Mealy machine, they depend on both state and inputs. Moore outputs come straight from the state register, so they are glitch-free, stable and predictable, but respond a clock later and often need more states. Mealy machines need fewer states and react immediately, but input changes pass directly to the outputs. Real designs mix both styles.

FAQ

Is a latch a sequential circuit?

Yes. A latch stores a bit and its output depends on past inputs, so it is sequential; it is level-sensitive, whereas an edge-triggered flip-flop samples only at clock edges.

What are examples of sequential circuits?

Counters, shift registers, register files, memories and finite state machines such as protocol or traffic-light controllers are all sequential circuits.

What limits the clock frequency of a sequential circuit?

The longest register-to-register path: clock-to-output delay plus combinational logic delay plus setup time must fit within one clock period, with some margin for clock skew.
