What is Soft error?

A temporary flip of data stored in memory or flip-flops caused by neutrons from cosmic rays, alpha particles and the like. The device is not damaged, so rewriting restores correct operation.

Japanese name: ソフトエラー

Show answer and explanation

Answer: A. An error in which stored data is temporarily flipped by radiation or the like, without damaging the device

A soft error occurs when alpha particles from package materials or cosmic-ray-induced neutrons generate charge in silicon and flip stored data. The device is not damaged, so rewriting restores correct operation. Neutron flux rises with altitude—hundreds of times higher at airliner cruising altitude than on the ground. ECC is the main countermeasure, along with reducing radioactive impurities in materials. Permanent failures from defects or wear-out are hard errors.
