What is URL (Uniform Resource Locator)?

A string that gives the location of a resource such as a web page. As in https://www.example.com:8443/docs/page.html?q=1#top, it consists of a scheme (https), a host name, a port number, a path, a query (after ?) and a fragment (after #). If the port is omitted, the default is used (443 for HTTPS), and the host name is converted to an IP address by DNS.

Try it: questions about URL (Uniform Resource Locator)

A browser opens https://www.example.com:8443/docs/guide.html?lang=ja#install. Which part of this URL is not included in the request sent to the server and is used only inside the browser after the page loads?

  1. A:8443
  2. B?lang=ja
  3. C#install
Show answer and explanation

Answer: C. #install

This URL consists of the scheme (https), the host name (www.example.com), the port number (8443; if omitted, 443 for https), the path (/docs/guide.html), the query (lang=ja) and the fragment (install). The browser uses the port number to decide where to connect and sends the path and query to the server in the request, but it does not send the fragment after #. The fragment is used only inside the browser, for example to move to the position of the element with id="install" in the page.

To put the Japanese character "あ" into a URL query, the byte sequence representing it in UTF-8 (E3 81 82) is percent-encoded. Which of the following is the correct result?

  1. A%E3%81%82
  2. B%u3042
  3. C&#x3042;
Show answer and explanation

Answer: A. %E3%81%82

In percent-encoding, when characters that cannot be written in a URL as they are, or characters with special meanings such as / ? # &, are used as data, the characters are turned into bytes and each byte is written as "%" followed by two hexadecimal digits. "あ" is the three bytes E3 81 82 in UTF-8, so it becomes %E3%81%82. A space becomes %20 (in the form submission format, + is also used). In JavaScript, the encodeURIComponent function performs this conversion.
