What is Glitch?

An unwanted momentary pulse on an output, caused for example by differing delays along signal paths. In combinational logic it is also called a hazard; in DACs it appears when the code changes.

Japanese name: グリッチ

Field: Logic circuits

How a hazard creates a glitch

A glitch appears when one input change reaches an output through paths of different delay. Consider F = A·B + (not A)·C with B and C both 1: F should stay 1 as A switches, but if the inverted path is slower, both product terms can be 0 for an instant and F dips briefly. This is a static-1 hazard. Adding the redundant consensus term B·C removes it. A dynamic hazard is an output that should change once but bounces several times before settling.

When glitches matter

In synchronous logic, a glitch on a data path is functionally harmless if it settles before the capturing clock edge, which static timing analysis guarantees. It still wastes dynamic power, because every spurious transition charges and discharges capacitance, and deep arithmetic logic can produce many of them. Glitches become real failures on clocks, asynchronous resets or sets, and signals leaving the chip, where a brief pulse can be taken as a real event. Such signals should therefore come directly from flip-flop outputs, which is one reason Moore-machine outputs are preferred for critical controls.

Glitches in clock gating

Gating a clock with a plain AND gate is risky: if the enable changes while the clock is high, the output can produce a truncated or extra pulse. Static timing analysis applies clock gating checks to ensure the enable is stable before the clock rises and held until it falls. Standard designs avoid the problem with integrated clock gating cells, which latch the enable while the clock is low so it can only change during the low phase.

DAC glitches and glitch attacks

In a digital-to-analog converter (DAC), bits switching at slightly different times create brief wrong codes at the output. The worst case is the midscale major carry, from 0111... to 1000..., where every bit changes. Glitch energy is specified as glitch impulse area, and it is reduced by thermometer-coding the upper bits, matching switch drivers and adding a deglitching sample-and-hold. Glitches can also be weaponized: fault injection attacks insert deliberate glitches into a chip's clock or supply to make it skip instructions such as a signature check.

Answer: C. Glitch

A glitch is a spike-like disturbance in a DAC's output that occurs when several bits switch at once and slight timing differences make wrong intermediate codes appear briefly. It is worst at the midscale major carry, where every bit changes (0111… to 1000…). It is reduced by thermometer-coding the upper bits, deglitching the output with a sample-and-hold, and matching the switch drivers.

FAQ

What is the difference between a glitch and a hazard?

A hazard is the property of a logic circuit that allows a momentary wrong output when inputs change; the glitch is the actual spurious pulse that appears. The terms are often used interchangeably.

Are glitches a problem in synchronous designs?

On ordinary data paths they are harmless as long as they settle before the clock edge, though they add power consumption. On clocks, asynchronous resets and off-chip control signals they can cause real malfunctions.

Why is DAC glitch worst at midscale?

At the midscale transition every bit changes at once, so small timing mismatches between the most significant bit and the rest briefly produce codes far from either the old or new value.
