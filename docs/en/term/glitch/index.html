What is Glitch?

An unwanted momentary pulse on an output, caused for example by differing delays along signal paths. In combinational logic it is also called a hazard; in DACs it appears when the code changes.

Japanese name: グリッチ

Which type of sequential circuit (state machine) has outputs determined only by the current state?

  1. AMealy machine
  2. BMoore machine
  3. CHarvard machine
Show answer and explanation

Answer: B. Moore machine

In a Moore machine, outputs depend only on the current state; in a Mealy machine, they depend on both state and inputs. Moore outputs come straight from the state register, so they are glitch-free, stable and predictable, but respond a clock later and often need more states. Mealy machines need fewer states and react immediately, but input changes pass directly to the outputs. Real designs mix both styles.

In a combinational circuit, what is the unwanted pulse that appears briefly at the output when an input changes, due to different delays along different paths?

  1. AMetastability
  2. BGlitch (hazard)
  3. CLatch-up
Show answer and explanation

Answer: B. Glitch (hazard)

When one input change reaches the output along paths with different delays, the output can briefly show a wrong value—a glitch (hazard). In synchronous circuits it is functionally harmless if it settles before the clock edge, but the extra switching wastes power. Glitches on clocks, asynchronous resets or control signals to other chips cause malfunctions, so such signals should come directly from flip-flop outputs.
