What is Lateral movement?

The spreading of a compromise by an attacker who has got into an organization's network, using the first hijacked endpoint as a foothold and moving to other endpoints and servers one after another with stolen credentials and legitimate administration tools. It is done to get closer to the target data or to systems with administrator privileges. It is prevented and detected with a different administrator password on each endpoint, blocking unnecessary traffic between endpoints (micro-segmentation), management of privileged accounts and monitoring of authentication logs.

Japanese name: ラテラルムーブメント

Try it: questions about Lateral movement

Which of the following is the most appropriate control for making "lateral movement" difficult, that is, the spread of a compromise from one hijacked employee PC to other PCs and servers inside the company?

  1. AGiving each PC a different local administrator password and blocking unnecessary traffic between PCs (such as file sharing)
  2. BTo reduce administrative effort, setting the local administrator password of all PCs to the same long, complex value
  3. CTightening the rules of the firewall at the internet perimeter and restricting only the traffic coming into the company from outside in even finer detail
Show answer and explanation

Answer: A. Giving each PC a different local administrator password and blocking unnecessary traffic between PCs (such as file sharing)

An intruder steals credentials from the hijacked PC and connects one after another to other PCs and servers where those credentials work, getting closer to important systems. If all PCs use the same local administrator password, information stolen from one PC is enough to get into all of them, so mechanisms that automatically set a different value on each PC (such as Windows LAPS) are used. In addition, PCs normally have no need for file-sharing or remote-administration traffic between each other, so blocking that traffic with network or host firewalls and limiting traffic between servers to what is needed (micro-segmentation) reduces the spread of a compromise. Perimeter defenses cannot stop an attacker who is already inside from moving around internally (east-west traffic).
