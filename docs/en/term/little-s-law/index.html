What is Little's law?

The relationship that the average number in a system equals the arrival rate times the average time each spends there: L = λW.

Japanese name: リトルの法則

Little's law appears in 3 practice questions across 3 topics, including Yield and quality control, Performance Analysis, Memory Hierarchy.

Try it: questions about Little's law

Which correctly states Little's law, relating work in progress (WIP), throughput and cycle time in a factory?

  1. AWIP = throughput × cycle time
  2. BWIP = throughput ÷ cycle time
  3. CWIP is unrelated to cycle time
Show answer and explanation

Answer: A. WIP = throughput × cycle time

Little's law states that average WIP equals throughput (output per unit time) times cycle time. A fab completing 50,000 wafers a month with a three-month cycle time always holds about 150,000 wafers in process. Shortening cycle time at the same throughput requires less WIP, and piling on too much WIP lengthens cycle time.

A server receives 100 requests per second, each taking 0.2 seconds on average (steady state). How many requests are in progress at once on average (Little's law)?

  1. A500
  2. B20
  3. C0.002
Show answer and explanation

Answer: B. 20

Little's law states that the average number in a system L equals the arrival rate λ times the average time each item spends in the system W. With 100 arrivals per second each staying 0.2 seconds, 20 requests are in progress on average. The law helps size thread pools and buffers, and the same reasoning gives how many outstanding requests are needed to saturate memory bandwidth.
