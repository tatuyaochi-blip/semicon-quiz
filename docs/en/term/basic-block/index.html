What is Basic block?

A sequence of instructions with no branch entering or leaving in the middle, always executed from start to end. Basic blocks are the nodes of a control-flow graph and units of local optimization.

Japanese name: 基本ブロック

Which describes a basic block?

  1. AA run of instructions with no branches in or out midway
  2. BAll the instructions contained in a single function, gathered together
  3. CA loop body replicated several times to reduce the number of iterations
Show answer and explanation

Answer: A. A run of instructions with no branches in or out midway

A basic block is an instruction sequence entered only at its first instruction and exited only at its last; once started, execution neither leaves nor enters partway through. Blocks are delimited at branch targets and right after branch instructions. Since execution order within a block is fixed, local optimization is easy, and a control-flow graph with blocks as nodes represents overall flow. A function usually consists of many basic blocks, and replicating a loop body is loop unrolling.
