What is Global offset table?

A table of the actual addresses of external variables and functions, filled in by the dynamic linker at run time. Position-independent code refers to them through it, so code pages need no patching.

Japanese name: GOT(グローバルオフセットテーブル)

Answer: C. A table of the actual addresses of external variables and functions, filled by the dynamic linker at run time, through which the code refers to them

Position-independent code cannot write the address of a variable in another library directly into an instruction. So each module has a table of addresses (the GOT); the code reads a GOT entry at a PC-relative distance and uses the address stored there. The dynamic linker writes the real addresses into the GOT when the module is loaded. Only the writable data of the GOT is patched, so the code pages remain shared.
