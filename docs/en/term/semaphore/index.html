What is Semaphore?

A synchronization mechanism holding a counter of remaining units: decrement before use (waiting at 0) and increment when done. Used to manage resources with a fixed number of units.

Japanese name: セマフォ

Answer: C. Letting up to four threads at a time use a resource with a fixed number of units, such as four connections

A semaphore holds a counter of remaining units: a thread decrements it before use (waiting if it is 0) and increments it when done. With an initial value of 4, up to four threads can use the resource at once. With 1, it works like a lock for mutual exclusion. Waiting threads are usually put to sleep and woken by the OS.
