What is Setup time?

The minimum time before the active clock edge during which a flip-flop's data input must be stable. Paths that cannot meet it limit the maximum operating frequency.

Japanese name: セットアップ時間

Setup time appears in 15 practice questions across 3 topics, including Timing analysis and CDC, Logic circuits, How to read datasheets.

Field: Logic circuits

Why flip-flops need setup time

An edge-triggered flip-flop is typically built from two latches. Before the clock edge, the input must pass through the first latch and its internal nodes must settle so the value is firmly held when that latch closes. If data changes too close to the edge, the flip-flop may capture the old value, the new one, or go metastable, taking unpredictable time to resolve. Setup time is the required stable interval before the edge and hold time the interval after it. Both are characterized per cell and vary with slew and operating conditions.

The setup check and slack

Data launched at one edge must arrive at least the setup time before the next capture edge. Arrival time is clock-to-output plus logic delay; required time is the period, adjusted for clock skew, minus setup time and clock uncertainty. Slack is required minus arrival, and negative slack is a violation. With a 2.0 ns period, 0.2 ns clock-to-output, 1.4 ns of logic and 0.1 ns setup, slack is 0.3 ns. The slowest path, the critical path, sets the maximum frequency: a 2.5 ns total allows 400 MHz.

Setup time vs. hold time

Setup is a maximum-delay check against the next edge, so a violation disappears if the clock is slowed, or the path is shortened by pipelining, reducing logic depth, upsizing cells or using low-threshold-voltage cells. Hold is a minimum-delay check against the same edge and does not depend on frequency, so it is repaired by adding delay. The two pull in opposite directions: capture-clock skew that helps setup hurts hold. Under on-chip variation (OCV) derating, setup assumes a slow launch side and an early capture clock; hold reverses this.

Constraints that reshape the check

A multicycle path of 2 moves the capture edge two periods away, valid only if logic such as an enable really captures every other cycle. A half-cycle path, launched on the rising edge and captured on the falling edge, gets only half a period. Latches allow time borrowing: data arriving after the latch opens still passes if it arrives before closing, taking time from the next stage. At chip boundaries, set_input_delay and set_output_delay describe time spent outside the chip. Useful skew deliberately delays a capture clock to rebalance adjacent stages.

Which correctly describes the setup time of a flip-flop?

  1. AThe minimum time data must be held after the clock edge
  2. BThe minimum time the data input must be stable before the clock edge
  3. CThe time from power-on until it starts operating
Show answer and explanation

Answer: B. The minimum time the data input must be stable before the clock edge

For a flip-flop to capture correctly, data must be stable for a certain time before the clock edge—the setup time. A violation occurs if the data-path delay exceeds the clock period minus the setup time, and it can be fixed by slowing the clock. The time data must remain stable after the edge is the hold time. Violating either can capture wrong values or cause metastability.

In a synchronous circuit with a clock period of 2.0 ns, the launching flip-flop's clock-to-output delay is 0.2 ns, the combinational logic delay is 1.4 ns and the capturing flip-flop's setup time is 0.1 ns. With zero clock skew, what is the setup slack?

  1. A0.3 ns
  2. B0.4 ns
  3. C0.5 ns
Show answer and explanation

Answer: A. 0.3 ns

Setup slack is calculated as "required time − arrival time." The data arrival time is 0.2 + 1.4 = 1.6 ns and the required time is the next clock edge minus the setup time, 2.0 − 0.1 = 1.9 ns, so the slack is 1.9 − 1.6 = 0.3 ns. Being positive, it meets the constraint. 0.4 ns is the value obtained by forgetting to subtract the setup time, and 0.5 ns by adding the setup time instead. A negative slack means a violation.

FAQ

What is the difference between setup time and hold time?

Setup time is how long data must be stable before the clock edge, and hold time is how long it must stay stable after the edge. Setup limits maximum frequency, while hold violations are independent of clock frequency.

How do you calculate setup slack?

Slack = required time − arrival time, where arrival time is clock-to-output plus logic delay and required time is the clock period (adjusted for skew) minus setup time and clock uncertainty. Positive slack means the path meets timing.

Can a setup violation be fixed by lowering the clock frequency?

Yes, a longer period gives the data more time to arrive, so setup violations disappear at a low enough frequency. Hold violations do not, which makes them more dangerous once silicon is built.
