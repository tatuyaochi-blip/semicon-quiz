What is Server-side rendering (SSR)?

A method in which the server generates a page's HTML and returns it each time a request arrives. The browser can display the HTML as soon as it arrives, so the first display is fast and the content is easily understood by search engines. Sending minimal HTML and JavaScript and building the page inside the browser is client-side rendering (CSR), and generating the HTML of every page in advance at build time is static site generation (SSG). Many setups also make the server-generated HTML interactive with JavaScript after it is displayed.

Japanese name: サーバサイドレンダリング(SSR)

Answer: C. SSG (static site generation)

A site made with SSG is a static site that does not run a program on the server for each request, so it can be delivered quickly as is from hosting services for static files or from a CDN, and it also has fewer parts that can be attacked. For example, a site that generates its question and glossary pages from content data at build time and delivers them is of this kind, and when the content changes, the pages are generated again. SSR is a dynamic method in which the server builds HTML for each request, and CSR sends minimal HTML and JavaScript and assembles the page inside the browser.
