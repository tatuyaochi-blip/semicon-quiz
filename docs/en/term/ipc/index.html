What is IPC?

Short for instructions per cycle: the number of instructions executed per clock. It expresses design efficiency; performance is roughly IPC times clock frequency. Its reciprocal is CPI.

Japanese name: IPC

Try it: questions about IPC

Performance counters show a program's IPC is very low at 0.3, with many last-level cache misses. Which pairs the likely situation with a remedy?

  1. AThe CPU spends much time stalled on memory; change data layout or apply blocking to use caches effectively
  2. BComputation is too fast; raise the frequency
  3. CThere are too few branches; add more
Show answer and explanation

Answer: A. The CPU spends much time stalled on memory; change data layout or apply blocking to use caches effectively

Modern CPUs can execute several instructions per cycle, so an IPC of 0.3 means they are waiting most of the time. Many last-level cache misses suggest long waits for data from main memory. Effective remedies reduce cache misses: laying data out at consecutive addresses, reordering loops, or blocking so data is reused many times.
