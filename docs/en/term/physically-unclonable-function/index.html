What is Physically unclonable function (PUF)?

A mechanism using per-chip manufacturing variation to produce values unique to each chip and hard to clone, allowing keys to be regenerated without storing them.

Japanese name: PUF(物理的複製困難関数)

Field: Hardware Security

Where the chip-unique value comes from

No two transistors come out of a fab identical: threshold voltages, gate dimensions and wire delays vary randomly from chip to chip. A physically unclonable function (PUF) amplifies these differences into bits. An SRAM PUF reads which way each cell settles at power-up, decided by the stronger of its two cross-coupled inverters. A ring-oscillator PUF compares the frequencies of nominally identical oscillators. An arbiter PUF races a signal down two paths whose routing is set by a challenge and records which arrives first. Because the variation is random and uncontrollable, even the manufacturer cannot build a chip with a chosen response.

From noisy bits to a stable key

A PUF response is not perfectly repeatable. Cells or paths whose two options are nearly balanced can flip with temperature, supply voltage, noise and aging, yet a cryptographic key must be bit-for-bit identical every time. At enrollment the chip therefore records the response and computes helper data, public information for an error-correcting code. At each use the PUF is read again, the code corrects the flipped bits with the help of the helper data, and a hash or key-derivation step produces the final key. This construction, often called a fuzzy extractor, is designed so the helper data does not reveal the key.

PUF versus eFuse and OTP key storage

The conventional approach writes a per-device key into one-time-programmable eFuses or OTP memory, ideally readable only by the crypto engine. Such bits exist permanently and can be targeted by opening the package and probing or imaging the storage. With a PUF the key is regenerated only when needed and exists nowhere while power is off, and invasive probing tends to disturb the very variation that defines it. A common hybrid stores keys in flash encrypted with a PUF-derived key. Whatever the approach, restricting the read paths to the key is essential.

Quality measures and limitations

PUFs are judged by uniqueness, the Hamming distance between responses of different chips, ideally 50 percent; reliability, how few bits change between readings of the same chip; and uniformity, an even balance of zeros and ones. Weak PUFs, such as SRAM PUFs, offer few challenge-response pairs and suit key generation. Strong PUFs, such as arbiter PUFs, offer very many pairs for authentication, but their responses can often be learned with machine-learning modeling attacks from observed pairs. Side-channel leakage and helper-data manipulation are further attack surfaces.

Answer: A. A mechanism that uses per-chip manufacturing variation to produce values unique to each chip and hard to clone

Even chips of the same design differ slightly in transistor threshold voltages and wire delays due to manufacturing variation. A PUF reads out these differences to produce a value unique to each chip. Not even the manufacturer can control the variation, so producing a chip with the same value is very difficult. PUFs are used for device authentication and as a source for generating keys.

  1. AUsers can freely choose the key value
  2. BThe key always remains in memory at power-off
  3. CThe key need not be written in non-volatile memory and is regenerated only when used, so it is hard to extract even if the chip is analyzed

Answer: C. The key need not be written in non-volatile memory and is regenerated only when used, so it is hard to extract even if the chip is analyzed

Keys written in flash or eFuses are targets for attacks that open the chip and read storage directly. With a PUF, the key is regenerated from the chip's physical properties each time it is used and is stored nowhere while power is off. For some PUF types, physically tampering with the chip to read the PUF also alters the very variation it depends on, making extraction even harder.

FAQ

What is a PUF used for?

PUFs provide chip-unique values for device authentication and for deriving cryptographic keys without storing them permanently in non-volatile memory. They are used in secure microcontrollers, FPGAs and other chips that need a hardware root of trust.

Is a PUF the same as a random number generator?

No. A true random number generator must produce fresh, unpredictable bits every time, whereas a PUF must reproduce the same chip-specific value on every reading. Some designs do harvest the unstable SRAM cells as an additional entropy source.

Why does an SRAM PUF need error correction?

A fraction of SRAM cells are nearly balanced and power up differently depending on temperature, voltage and noise. Error correction with helper data fixes these flipping bits so the derived key is identical every time.
