What is Physically unclonable function (PUF)?

A mechanism using per-chip manufacturing variation to produce values unique to each chip and hard to clone, allowing keys to be regenerated without storing them.

Japanese name: PUF(物理的複製困難関数)

Which describes a PUF (physically unclonable function)?

  1. AA mechanism that uses per-chip manufacturing variation to produce values unique to each chip and hard to clone
  2. BA mechanism writing the same value into every chip
  3. CA product number printed on the chip surface
Show answer and explanation

Answer: A. A mechanism that uses per-chip manufacturing variation to produce values unique to each chip and hard to clone

Even chips of the same design differ slightly in transistor threshold voltages and wire delays due to manufacturing variation. A PUF reads out these differences to produce a value unique to each chip. Not even the manufacturer can control the variation, so producing a chip with the same value is very difficult. PUFs are used for device authentication and as a source for generating keys.

What is the advantage of using a PUF for key storage?

  1. AUsers can freely choose the key value
  2. BThe key always remains in memory at power-off
  3. CThe key need not be written in non-volatile memory and is regenerated only when used, so it is hard to extract even if the chip is analyzed
Show answer and explanation

Answer: C. The key need not be written in non-volatile memory and is regenerated only when used, so it is hard to extract even if the chip is analyzed

Keys written in flash or eFuses are targets for attacks that open the chip and read storage directly. With a PUF, the key is regenerated from the chip's physical properties each time it is used and is stored nowhere while power is off. Physically tampering with the chip to read the PUF also alters the very variation it depends on, making extraction even harder.
