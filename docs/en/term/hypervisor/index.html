What is Hypervisor?

Software that runs multiple virtual machines on one computer, allocating CPU, memory and devices to each guest OS and isolating them from one another. Also called a virtual machine monitor.

Japanese name: ハイパーバイザ

What is it called when a guest OS executes a privileged instruction, control passes to the hypervisor, and the hypervisor reproduces the instruction's effect on its behalf?

  1. ATrap-and-emulate
  2. BCopy-on-write
  3. CDemand paging
Show answer and explanation

Answer: A. Trap-and-emulate

A guest OS executes privileged instructions believing it controls the hardware, but it actually runs in a lower-privilege mode, so an exception (trap) occurs. The hypervisor catches it, reproduces (emulates) the instruction's effect so the result is correct for that virtual machine, and returns to the guest. CPU virtualization support makes these transitions fast and reliable. Copy-on-write and demand paging are memory-management techniques.
