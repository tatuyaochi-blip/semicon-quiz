What is 128b/130b encoding?

Line coding that sends 128 data bits with a 2-bit header, about 98.5% efficient, relying on scrambling for transitions. Used from PCI Express 3.0 onward.

How a 128b/130b block is built

128b/130b encoding groups data into blocks of 130 bits: a 2-bit sync header followed by a 128-bit payload. Only the header values 01 and 10 are legal, so every block is guaranteed at least one transition at its start, which lets the receiver find block boundaries. The header also tells the receiver whether the payload carries data or an ordered set, the special symbols used for link training and clock compensation. The payload itself is passed through a scrambler, which XORs it with a pseudo-random sequence from a linear feedback shift register, and the receiver descrambles it with the same sequence.

Scrambling instead of guaranteed balance

A serial receiver recovers its clock from data transitions and AC-coupled links need roughly equal numbers of ones and zeros. 8b/10b encoding guarantees both by construction: no run longer than five identical bits and a running disparity that keeps the line DC-balanced, at the cost of two extra bits per byte. 128b/130b instead relies on scrambling to make long runs and imbalance statistically very unlikely. The guarantee is weaker, so equalization and clock recovery must tolerate occasional longer runs, but the overhead drops from 20% to about 1.5%.

What the efficiency means for PCI Express

Efficiency is 128/130, about 98.5%, versus 80% for 8b/10b. That is why PCI Express 3.0 nearly doubled usable bandwidth while raising the signaling rate only from 5 to 8 GT/s: a PCIe 2.0 lane carries 5 × 0.8 = 4 Gb/s of data, while a PCIe 3.0 lane carries 8 × 128/130 ≈ 7.88 Gb/s, or about 0.985 GB/s. A x16 link therefore gives about 15.8 GB/s in each direction before packet headers and protocol overhead, which reduce the delivered figure somewhat.

Related codes

128b/130b is used by PCI Express 3.0, 4.0 and 5.0, which kept the encoding while doubling the transfer rate each generation. It belongs to the same family as 64b/66b, used in 10 Gigabit Ethernet, which also pairs a 2-bit sync header with a scrambled payload. PCI Express 6.0 moved to PAM4 signaling with fixed-size flits and forward error correction, so it no longer uses 128b/130b blocks. When comparing link speeds, always check which encoding applies, because the raw rate in GT/s is not the data rate.

Sixteen lanes give about 15.8 GB/s, roughly 16 GB/s in one direction, or about 32 GB/s for both directions together. FAQ

Why is 128b/130b more efficient than 8b/10b?

8b/10b spends 2 extra bits on every 8 data bits, a 20% overhead, while 128b/130b spends 2 header bits on every 128 data bits, about 1.5%. It can do this because scrambling, rather than the code itself, provides the transitions and balance the receiver needs.

What is the sync header in 128b/130b encoding?

It is the 2-bit prefix of each 130-bit block, either 01 or 10, which marks the block boundary with a guaranteed transition and indicates whether the block carries data or an ordered set.

How much bandwidth does a PCIe 3.0 x16 link have?

About 15.8 GB/s in each direction, from 8 GT/s × 128/130 ÷ 8 bits per byte × 16 lanes. Packet overhead makes the usable throughput slightly lower.
