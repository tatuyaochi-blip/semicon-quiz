What is 128b/130b encoding?

Line coding that sends 128 data bits with a 2-bit header, about 98.5% efficient, relying on scrambling for transitions. Used from PCI Express 3.0 onward.

Field: I/O Interfaces & Buses

128b/130b encoding in the explanations

  • 128b/130b encoding sends 128 data bits with a 2-bit header as 130 bits, so efficiency is 128/130 ≈ 98.5%, a big reduction in waste compared with 8b/10b's 80%.
