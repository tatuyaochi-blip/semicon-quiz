What is TLB shootdown?

On a multiprocessor, the procedure for making other cores discard stale translations from their TLBs after a page table is modified. It uses inter-processor interrupts or instructions that broadcast the invalidation to all cores, and is costly.

Japanese name: TLBシュートダウン

On a multicore system, when the OS modifies a page-table entry to revoke a mapping, what must be done?

  1. AFlushing only its own core's TLB is enough; other cores automatically use the correct translation
  2. BMaking sure the stale translation is removed from other cores' TLBs too
  3. CNothing; every TLB is updated at the same moment the page table is written
Show answer and explanation

Answer: B. Making sure the stale translation is removed from other cores' TLBs too

On many CPUs, unlike caches, TLBs are not kept coherent by hardware, so other cores' TLBs may still hold the translation from before the page table was changed. Left alone, other cores could still access the revoked page. The OS therefore removes the stale entry from other cores, either by sending inter-processor interrupts or by using instructions that broadcast the invalidation, and waits for completion. This is a TLB shootdown, and it gets more expensive as core counts rise.
