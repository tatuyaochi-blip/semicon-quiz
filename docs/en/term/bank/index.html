What is Bank?

One of several independently operating sections inside a DRAM. Overlapping activation and access across different banks raises effective performance.

Japanese name: バンク

Field: DRAM

Why DRAM is split into banks

Accessing DRAM involves several slow steps. An activate command opens a row, copying it into the bank's sense amplifiers, often called the row buffer; reads and writes then select columns from that row; finally a precharge closes the row and readies the bit lines. Activation and precharge each take over ten nanoseconds. A bank is an independent array with its own row buffer, so while one bank is activating or precharging, another can be transferring data. Interleaving accesses across banks hides these latencies and keeps the data bus busy.

Bank counts and bank groups

DDR4 x4/x8 devices have 16 banks arranged in four bank groups, and DDR5 x4/x8 devices of 16 Gbit and larger double this to 32; x16 devices have half as many banks. Bank groups add a timing rule: consecutive column accesses to different groups can be issued closer together than accesses within the same group, so controllers spread traffic across groups. Each bank can hold a different open row, which also raises the chance that a request hits an already-open row (a page hit) instead of paying for another activate. A bank is distinct from a rank, which is a set of chips sharing a chip select on a module.

Refresh and bank availability

DRAM cells leak, so every row must typically be refreshed within 64 ms. A bank under refresh cannot serve accesses, and as capacity grows each refresh command covers more rows and lasts longer, a time known as tRFC. For 16 Gbit-class devices, refresh can cost from several percent to about 10% of performance, along with extra power. Per-bank refresh reduces the impact by refreshing one bank while the others remain available, and research has explored refreshing rows with long retention less often.

Banks in GPU shared memory

The word also appears in GPU programming with a related idea. CUDA shared memory is divided into 32 banks assigned in rotation every 4 bytes, and each bank serves one address per access. If the 32 threads of a warp hit distinct banks, the access completes at once; if several threads hit different addresses in one bank, the accesses are serialized, a bank conflict. Reading down a column of a 32 × 32 float tile puts every element in one bank; padding the tile to 32 × 33 shifts each row by one bank and removes the conflict.

Answer: A. about 640,000

Doubling the refresh rate makes the period 64 ms ÷ 2 = 32 ms. The maximum number of activations in that time is 32 ms ÷ 50 ns = 640,000, half of the original 64 ms ÷ 50 ns = 1,280,000. Research has reported DRAM that flips after only a few thousand activations, so even halving the number leaves plenty for an attack, and adding refreshes alone cannot prevent it. Moreover, banks cannot be used during refresh and power rises, so the burden on performance and power consumption becomes large.

FAQ

How many banks does DDR5 have?

DDR5 x4/x8 devices of 16 Gbit and larger have 32 banks, organized into eight bank groups, compared with 16 banks in four bank groups for DDR4 x4/x8 devices; x16 devices have half as many in both cases.

What is the difference between a DRAM bank and a rank?

A bank is an independently operating array inside a single DRAM chip. A rank is a set of chips on a module that share a chip select and together supply the full data width, and each chip in it contains its own banks.

What is a shared memory bank conflict?

It occurs when threads in a GPU warp access different addresses that map to the same shared-memory bank, forcing the hardware to serialize the accesses. Padding arrays or changing the access pattern usually avoids it; all threads reading the same address is a broadcast and not a conflict.
