What is Channel-length modulation?

In a saturated MOSFET, raising the drain voltage moves the pinch-off point toward the source, shortening the effective channel and slightly increasing drain current. It makes the output resistance finite.

Japanese name: チャネル長変調

Which expression appropriately gives the small-signal output resistance ro of a MOSFET in saturation, using the channel-length modulation coefficient λ and drain current ID?

  1. Aro ≈ 1 / (λ × ID)
  2. Bro ≈ ID / λ
  3. Cro ≈ λ × ID
Show answer and explanation

Answer: A. ro ≈ 1 / (λ × ID)

Including channel-length modulation, saturation drain current rises slightly with VDS as ID(1 + λVDS), and the inverse of this slope is the output resistance ro ≈ 1/(λID). λ is roughly inversely proportional to channel length, so doubling L about doubles ro. The intrinsic gain gm·ro is only about 10–20 in highly scaled transistors, so cascodes and multistage designs are used to obtain enough gain.
