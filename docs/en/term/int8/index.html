What is INT8?

An 8-bit signed integer (−128 to 127). In AI inference, quantizing weights and activations to INT8 with a scale factor greatly cuts computation and memory and allows fast processing on small integer circuits.

Japanese name: INT8

Field: Computer Arithmetic

How real values are mapped to 8-bit integers

INT8 is an 8-bit two's-complement integer from -128 to 127. To use it for a neural network, each tensor gets a scale factor so that real value is approximately scale times the integer, sometimes after subtracting a zero point. Symmetric quantization fixes the zero point at 0 and usually uses -127 to 127 so the range is balanced; the scale is the maximum absolute value divided by 127. For data spanning -6.35 to 6.35 the scale is 0.05, so 1.0 maps to 20. Asymmetric quantization adds a zero point, which suits activations that are always non-negative after ReLU.

Why integer hardware is cheaper

Compared with FP32, INT8 cuts weight storage and memory traffic to one quarter, which matters most when inference is limited by memory bandwidth. The arithmetic is also cheaper: multiplier area grows roughly with the square of operand width, and an 8-bit integer multiplier has no exponent handling or normalization, so it is far smaller and more energy-efficient than an FP32 unit. A product of two INT8 values fits in 16 bits, and long dot products are accumulated in 32-bit integers to avoid overflow. The 32-bit result is then rescaled, or requantized, back to INT8 for the next layer.

Calibration and keeping accuracy

Only 256 levels are available, so rounding and clipping errors are unavoidable. Weights are fixed after training, so their scales can be chosen directly, often per output channel to fit each channel's range. Activations depend on the input, so post-training quantization runs a few hundred representative samples through the model to observe each layer's range, a step called calibration. Matching the absolute maximum lets rare outliers waste resolution, so the range is often clipped to cover most of the distribution. If accuracy still drops too much, quantization-aware training simulates rounding during training so the network learns to tolerate it.

INT8 versus other low-precision formats

INT8 has uniformly spaced levels, so its precision is the same everywhere in its range, which works well for weights and activations with modest dynamic range. Floating-point formats such as FP16, BF16 and FP8 spend bits on an exponent, giving wider dynamic range with spacing that grows with magnitude. Many accelerators support several of these formats, and performance figures quoted in TOPS are usually given at INT8 or lower. Even narrower integers, such as INT4, are used mainly for weights when memory capacity is the main constraint, at the price of more quantization error.

In AI inference, what is the main benefit of converting (quantizing) weights from FP32 to INT8?

  1. APrecision always becomes higher than FP32
  2. BData shrinks to a quarter and computation gets faster and leaner
  3. CModel accuracy always improves, even without any retraining at all
Show answer and explanation

Answer: B. Data shrinks to a quarter and computation gets faster and leaner

Going from 32-bit to 8-bit weights cuts memory usage and data read to a quarter, a big win for inference limited by memory bandwidth. In addition, 8-bit integer multipliers are far smaller and more power-efficient than floating-point ones, allowing more operations for the same area and power. In exchange, only 256 values are representable, so errors arise and accuracy may drop slightly. Precision does not increase, nor does accuracy always improve.

Data ranging from −6.35 to 6.35 is quantized to symmetric INT8 (−127 to 127) centered at zero, with scale = maximum absolute value ÷ 127. Which integer represents 1.0?

  1. A1
  2. B127
  3. C20
Show answer and explanation

Answer: C. 20

The scale is 6.35 ÷ 127 = 0.05, so integer 1 corresponds to the real value 0.05. A real value is quantized by dividing by the scale and rounding to the nearest integer: 1.0 ÷ 0.05 = 20. Dequantizing gives 20 × 0.05 = 1.0. 1 wrongly takes the real value as the integer, and 127 corresponds to the maximum, 6.35. Large outliers make the scale coarse and hurt accuracy, so choosing the range (calibration) matters.

FAQ

What is the range of INT8?

A signed 8-bit integer covers -128 to 127. Symmetric quantization schemes often restrict themselves to -127 to 127 so that positive and negative ranges are equal and zero maps exactly to 0.

Why are INT8 products accumulated in 32-bit integers?

Each INT8 by INT8 product needs up to 16 bits, and a dot product adds hundreds or thousands of them, which would overflow a narrow accumulator. A 32-bit accumulator keeps the sum exact before it is rescaled back to INT8.

How much accuracy is lost by quantizing a model to INT8?

It depends on the model and how carefully scales are chosen. With good calibration and per-channel weight scales the loss is often small, and quantization-aware training can recover more when post-training quantization is not good enough.
