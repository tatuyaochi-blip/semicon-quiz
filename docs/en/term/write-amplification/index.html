What is Write amplification?

The amount of data actually written to flash exceeding what the host wrote, because of garbage collection and similar operations. The larger it is, the shorter the SSD's life.

Japanese name: 書き込み増幅(ライトアンプリフィケーション)

Show answer and explanation

Answer: C. The amount of data actually written to flash exceeding the amount written by the host

Because flash cannot overwrite and erases by block, garbage collection adds extra writes such as copying valid data to new blocks, so the flash receives more data than the host wrote. The ratio is the write amplification factor (WAF), which can reach several times under small random writes. TRIM, spare area and data compression reduce it, protecting lifespan and performance.
