What is Read disturb?

In NAND flash, the gradual shift in threshold voltage of unread cells caused by the weak voltage applied to them when the same block is read many times.

Japanese name: リードディスターブ

Read disturb appears in 2 practice questions across 2 topics, including SRAM and flash memory, Emerging memories.

Field: SRAM and flash memory

Try it: questions about Read disturb

In NAND flash, what is the phenomenon in which repeatedly reading the same block gradually shifts the threshold voltages of cells that are not being read?

  1. AWear leveling
  2. BRead disturb
  3. CGarbage collection
Show answer and explanation

Answer: B. Read disturb

Reading NAND applies a pass voltage of several volts to unselected cells so they conduct, and repeated reads slowly inject electrons that raise their threshold voltages—read disturb, which becomes significant after tens to hundreds of thousands of reads. It affects blocks holding frequently read data, so controllers count reads and rewrite the data to another block as the limit approaches.

Why must the read current be limited in STT-MRAM?

  1. ABecause a large read current permanently changes the MTJ's resistance
  2. BBecause spin torque also acts during reads, so too large a current can accidentally reverse the storage layer's magnetization
  3. CBecause a large read current melts the magnetic layers
Show answer and explanation

Answer: B. Because spin torque also acts during reads, so too large a current can accidentally reverse the storage layer's magnetization

STT-MRAM passes current through the MTJ for both reading and writing, so a read current close to the switching current may flip the magnetization stochastically on each read (read disturb). Read current is therefore designed well below write current, but too small a current weakens the signal, slowing reads and increasing errors. As scaling lowers write current, balancing the two gets harder.
