What is Read disturb?

In NAND flash, the gradual shift in threshold voltage of unread cells caused by the weak voltage applied to them when the same block is read many times.

Japanese name: リードディスターブ

Read disturb appears in 2 practice questions across 2 topics, including SRAM and flash memory, Emerging memories.

Field: SRAM and flash memory

Why reading one page stresses its neighbors

NAND flash cells are connected in series in strings. To read one word line, the selected cell's gate receives a read voltage while every other word line in the block receives a pass voltage of several volts, high enough to turn those cells fully on regardless of their stored data. That pass voltage creates a weak field across the tunnel oxide of the unselected cells, and each read injects a tiny amount of charge into their storage layer. Over many reads, their threshold voltages creep upward. Erased cells, with the lowest threshold voltage, are typically the most vulnerable.

When read disturb becomes a problem

A single read causes a negligible shift, but read disturb becomes significant after tens to hundreds of thousands of reads of the same block. It therefore hits blocks holding data that is read very often but rarely rewritten, such as boot code or hot lookup tables. Cells that store multiple bits (MLC, TLC, QLC) are more sensitive because the threshold voltage windows separating their states are narrow, and cells worn by many program/erase cycles are more susceptible still.

How SSD controllers handle it

Controllers keep a read counter per block. As the count approaches a limit, or when error correction (ECC) starts reporting more corrected bits, the controller copies the data to a fresh block and later erases the old one, a process often called read reclaim or refresh. The shift is caused by added charge, not by permanent damage, so erasing and rewriting the block resets it. Read-retry, which re-reads with shifted reference voltages, can also recover pages whose distributions have moved.

Read disturb vs. retention and other memories

Read disturb raises threshold voltages and depends on how often a block is read; retention loss lowers them as stored charge leaks away over time, even if the data is never touched. The term also appears in other memories. In STT-MRAM the read current flows through the same magnetic tunnel junction used for writing, so it must stay well below the switching current or it may flip the bit, yet too small a current weakens the signal. In SRAM, read stability describes the related risk that accessing a cell upsets its stored value.

Answer: B. Read disturb

Reading NAND applies a pass voltage of several volts to unselected cells so they conduct, and repeated reads slowly inject electrons that raise their threshold voltages—read disturb, which becomes significant after tens to hundreds of thousands of reads. It affects blocks holding frequently read data, so controllers count reads and rewrite the data to another block as the limit approaches.

Why must the read current be limited in STT-MRAM?

  1. ABecause a large read current permanently changes the MTJ's resistance
  2. BBecause spin torque also acts during reads, so too large a current can accidentally reverse the storage layer's magnetization
  3. CBecause a large read current melts the magnetic layers
Show answer and explanation

Answer: B. Because spin torque also acts during reads, so too large a current can accidentally reverse the storage layer's magnetization

STT-MRAM passes current through the MTJ for both reading and writing, so a read current close to the switching current may flip the magnetization stochastically on each read (read disturb). Read current is therefore designed well below write current, but too small a current weakens the signal, slowing reads and increasing errors. As scaling lowers write current, balancing the two gets harder.

FAQ

What is read disturb in NAND flash?

Read disturb is the gradual upward shift in the threshold voltage of unselected cells in a NAND block caused by the pass voltage applied to them on every read. After enough reads, it can flip stored bits.

Is read disturb permanent damage?

No. The shift comes from extra charge injected into the cells, so erasing the block and rewriting the data restores normal margins, unlike wear from program/erase cycling.

What is the difference between read disturb and data retention errors?

Read disturb adds charge and raises threshold voltages in proportion to how many reads a block sees. Retention errors come from charge leaking out over time, which lowers threshold voltages even when the data is not accessed.
