What is GPU?

Short for graphics processing unit: a processor with many simple execution units that processes large amounts of data in parallel. Besides graphics, it is widely used for AI training and inference.

Japanese name: GPU

What is an IC called that integrates functions a system needs, such as a CPU, GPU, memory controller and communications, on a single chip?

  1. ASiP (system in package)
  2. BCommodity DRAM
  3. CSoC (system on chip)
Show answer and explanation

Answer: C. SoC (system on chip)

An SoC integrates most of a system's functions on a single chip; smartphone processors are the classic example. Eliminating chip-to-chip wiring reduces part count and makes systems smaller, faster and lower-power. On the other hand, larger dies yield worse, and circuits requiring different processes are hard to combine. It is distinguished from an SiP, which houses multiple chips in one package. Commodity DRAM is a standalone memory product.

In AI GPUs, what is the main reason the GPU chip and HBM are placed side by side on one silicon interposer?

  1. ATo increase part count
  2. BTo connect the chips over short distances with an extremely large number of wires, achieving very high memory bandwidth
  3. CTo reduce memory capacity
Show answer and explanation

Answer: B. To connect the chips over short distances with an extremely large number of wires, achieving very high memory bandwidth

Each HBM stack has 1,024 data lines, and several stacks add up to thousands, more than an ordinary package substrate can route. Placing the GPU and HBM side by side on a silicon interposer with fine wiring connects them through many short wires only millimeters long, achieving memory bandwidth of several TB/s needed for AI computation. The purpose is neither to add parts nor to reduce capacity.
