What is Relocation?

Rewriting placeholder addresses in instructions and data with correct values once final addresses are decided. The linker does it, and with dynamic linking part of it is done at run time by the dynamic linker.

Japanese name: 再配置

Show answer and explanation

Answer: A. After final addresses of code and data are decided, rewriting the addresses inside instructions and data with the correct values

The compiler builds each file as if it started at address 0 and records, as relocation entries, every place that uses the address of another file's function or of its own variables. After laying out all files and deciding real addresses, the linker computes the correct address (or PC-relative distance) for each recorded place and writes it into the instruction. With dynamic linking, part of this patching is done at run time by the dynamic linker.
