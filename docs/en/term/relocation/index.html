What is Relocation?

Rewriting placeholder addresses in instructions and data with correct values once final addresses are decided. The linker does it, and with dynamic linking part of it is done at run time by the dynamic linker.

Field: Linkers, Loaders & Executables

Relocation in the explanations

  • The compiler builds each file as if it started at address 0 and records, as relocation entries, every place that uses the address of another file's function or of its own variables.

  • An object file holds the machine code translated from that file's functions, initial values of variables, a list of names it defines and references (the symbol table) and a list of places whose addresses must be filled in later (relocation entries).
