What is Systolic array?

An arrangement of many multiply-accumulate units in a grid that computes matrix products by passing data to neighboring units step by step. It is used in AI accelerators.

Japanese name: シストリックアレイ

In AI accelerators and similar, which architecture arranges many multiply-accumulate units in a grid and computes matrix products by passing data from one unit to the next?

  1. ASystolic array
  2. BCrossbar switch
  3. CRing buffer
Show answer and explanation

Answer: A. Systolic array

A systolic array arranges multiply-accumulate units (MACs) in a 2D grid and pumps data rhythmically from neighbor to neighbor—named after the heart's systolic contractions. Each loaded value is reused by many units, cutting memory accesses and making matrix operations efficient. Google's TPU, for example, uses large arrays such as 128×128.

What is the main reason systolic arrays in AI accelerators compute matrix products efficiently?

  1. AEach unit reads data directly from main memory every time
  2. BThere is only one unit, so the circuit is simple
  3. CData is passed from unit to neighboring unit and reused, so memory reads are few and many units work simultaneously
Show answer and explanation

Answer: C. Data is passed from unit to neighboring unit and reused, so memory reads are few and many units work simultaneously

In a systolic array, data flows in a regular, pulse-like rhythm between multiply-accumulate units arranged in a grid. A value read once is passed from neighbor to neighbor and used in dozens of operations, so a great deal of computation is done relative to the data read from memory. Only short wires between neighbors are needed, so many units can be packed densely.
