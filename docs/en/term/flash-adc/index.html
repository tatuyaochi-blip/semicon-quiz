What is Flash ADC?

The fastest type of ADC, which compares the input against many comparators at once. N bits need 2ᴺ − 1 comparators, so the circuit grows rapidly with resolution.

Japanese name: フラッシュ型ADC

Which is a characteristic of a flash ADC?

  1. AIt converts in one step using many comparators in parallel, so it is fast, but circuit size grows rapidly with resolution
  2. BIt compares one bit at a time, so it is slow but small
  3. CIt integrates the input voltage for a long time, so it is accurate but slow
Show answer and explanation

Answer: A. It converts in one step using many comparators in parallel, so it is fast, but circuit size grows rapidly with resolution

A flash ADC compares the input against every threshold at once using 2ᴺ−1 comparators, so conversion finishes in a single comparison—the fastest architecture (several GS/s). But N bits need 2ᴺ−1 comparators: 255 at 8 bits and 1023 at 10, so area, power and input capacitance grow rapidly. Flash converters are therefore used for ultra-high-speed applications at about 6–8 bits and as building blocks in pipelined and subranging ADCs.

How many comparators does a 3-bit flash ADC need?

  1. A8
  2. B7
  3. C3
Show answer and explanation

Answer: B. 7

A flash ADC compares the input with every threshold simultaneously, so N bits need 2ᴺ − 1 comparators—seven for 3 bits. The comparator outputs form a thermometer code (all 1s up to a point, all 0s above), which an encoder converts to binary. At 8 bits there are 255 comparators, with large input capacitance and power, so the approach does not suit high resolution.
