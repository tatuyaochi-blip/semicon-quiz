What is Flash ADC?

The fastest type of ADC, which compares the input against many comparators at once. N bits need 2ᴺ − 1 comparators, so the circuit grows rapidly with resolution.

Field: AD/DA conversion

Flash ADC in the explanations

  • A flash ADC compares the input against every threshold at once using 2ᴺ−1 comparators, so conversion finishes in a single comparison—the fastest architecture (several GS/s).
