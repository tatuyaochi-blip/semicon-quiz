What is Current mirror?

A circuit that uses two matched transistors to copy the current flowing in one into the other (or at a fixed ratio). It is widely used for bias current sources and active loads in analog ICs.

Japanese name: カレントミラー回路

Show answer and explanation

Answer: C. Current mirror

A current mirror passes a reference current through a diode-connected transistor (base shorted to collector) to set VBE, then applies the same VBE to a second transistor to copy the current. Scaling emitter areas makes the copy an integer multiple. Errors from base current and limited output resistance from the Early effect are improved by Wilson or cascode mirrors. Current mirrors are indispensable for biasing and active loads in analog ICs.
