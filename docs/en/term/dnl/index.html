What is DNL (differential nonlinearity)?

The error in each code step width of an ADC relative to the ideal 1 LSB. When it reaches −1 LSB, a missing code occurs.

Japanese name: DNL(微分非直線性)

DNL (differential nonlinearity) appears in 8 practice questions across 3 topics, including A/D and D/A conversion, Testing and inspection, How to read datasheets.

Field: A/D and D/A conversion

How DNL is defined

An ideal N-bit converter divides its full-scale range into 2ᴺ equal steps of 1 LSB (least significant bit). For an analog-to-digital converter (ADC), each output code should therefore correspond to an input interval exactly 1 LSB wide. Differential nonlinearity (DNL) is the error of each actual code width, expressed in LSB: DNL = (actual width − 1 LSB) / 1 LSB. A code 1.5 LSB wide has DNL = +0.5 LSB, and one 0.7 LSB wide has −0.3 LSB. For a digital-to-analog converter (DAC), the same idea applies to the size of each output step.

Missing codes and monotonicity

When a code's DNL reaches −1 LSB its width shrinks to zero, so that code never appears no matter how the input is swept: a missing code. A guarantee of "no missing codes" at a given resolution is therefore equivalent to DNL staying above −1 LSB. Large positive DNL, beyond about +1 LSB, wastes resolution because one wide code covers what should be several. For a DAC, DNL above −1 LSB guarantees monotonicity, meaning the output never falls when the code rises. Errors cluster at major carry transitions, such as 0111…1 to 1000…0, where mismatched binary-weighted elements swap.

DNL vs. INL, offset and gain error

Offset error shifts the whole transfer curve and gain error changes its slope; both are linear and can be removed with a two-point calibration. Integral nonlinearity (INL) is the maximum deviation of the actual curve from a straight line, drawn either through the endpoints or as a best fit, and at any code it equals the running sum of DNL up to that code. A converter can thus have small DNL everywhere yet large INL if small errors accumulate in one direction. INL shows up as harmonic distortion on large signals, while DNL governs small-step accuracy and missing codes; neither is fixed by simple calibration.

Measuring DNL and designing it down

The histogram, or code-density, method feeds the ADC a signal with known amplitude distribution and counts how often each code occurs. With a slow ramp or triangle every code should receive the same count, so each code's count divided by the average, minus one, gives its DNL; a sine wave is easier to make pure but needs correction for its peak-weighted distribution. Summing DNL gives INL. On the design side, thermometer-coded current-steering DACs and resistor-string DACs are monotonic by construction, and segmenting upper bits into equal-weight elements reduces DNL at major transitions.

Answer: B. Deviation of the width (step size) between adjacent codes from the ideal 1 LSB

DNL measures how far each code's input width (step width) deviates from the ideal 1 LSB; a width of 1.5 LSB means DNL = +0.5 LSB. At −1 LSB a code disappears (a missing code), and beyond +1 LSB the effective resolution degrades. Deviation of the whole transfer curve from the ideal line is integral nonlinearity (INL), and the output deviation at zero input is offset error.

FAQ

What does a DNL of ±0.5 LSB mean?

Every code width lies between 0.5 and 1.5 LSB, so no code is missing and none is wider than one and a half ideal steps. It is a common specification for good-quality converters.

What is the difference between DNL and INL?

DNL is the error of each individual step width, while INL is how far the whole transfer curve wanders from a straight line. INL at a code is essentially the accumulated DNL up to that point.

Does DNL greater than −1 LSB guarantee no missing codes?

Yes. A missing code is precisely a code whose width has shrunk to zero, which corresponds to DNL = −1 LSB, so keeping every DNL above −1 LSB rules it out.
