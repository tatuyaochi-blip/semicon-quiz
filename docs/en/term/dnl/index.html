What is DNL (differential nonlinearity)?

The error in each code step width of an ADC relative to the ideal 1 LSB. When it reaches −1 LSB, a missing code occurs.

Field: AD/DA conversion

DNL (differential nonlinearity) in the explanations

  • DNL measures how far each code's input width (step width) deviates from the ideal 1 LSB; a width of 1.5 LSB means DNL = +0.5 LSB.
