What is Hamming distance?

The number of positions at which two bit strings (or character strings) of the same length differ. It equals the number of 1s in the exclusive OR of the two bit strings. For example, the Hamming distance between 1011010 and 0110011 is 4. The smallest distance between any two codewords of a code is its minimum Hamming distance; a code with minimum Hamming distance d can detect errors of up to d − 1 bits and correct errors of up to (d − 1) ÷ 2 bits, rounded down.

Japanese name: ハミング距離

Error detection and correction capability

The farther apart the codewords, the less likely an error is to turn one into another. In a code with minimum Hamming distance d, an error of d − 1 bits or fewer cannot produce another codeword, so it can be detected, and if the error is at most (d − 1) ÷ 2 bits, the codeword nearest to the received word is the original, so it can be corrected. For example, the repetition code that sends each bit three times has d = 3 and corrects a 1-bit error by majority vote.

Finding it for a linear code

In a linear code, where the exclusive OR of any two codewords is also a codeword, the distance between two codewords equals the number of 1s in the codeword that is their exclusive OR. The minimum Hamming distance can therefore be found as the smallest number of 1s (weight) in a nonzero codeword, without comparing every pair.

Uses in other fields

Hamming distance is used as a general measure that counts the differences between two pieces of data. In evaluating PUFs (physically unclonable functions), the closer the Hamming distance between the responses of different chips is to 50% of all bits, the easier the individual chips are considered to tell apart. In encoding state machines, making the Hamming distance between neighboring states 1 reduces the number of bits that change on a transition.

Answer: C. 4

The Hamming distance is the number of positions at which the bits differ. The exclusive OR of the two words is 1101001, which has four 1s, so the Hamming distance is 4. Comparing bit by bit, bits 1, 2, 4 and 7 differ.

Answer: A. Detection up to 4 bits, correction up to 2 bits

In a code with minimum Hamming distance d, an error of up to d − 1 bits never turns a codeword into another codeword, so it can be detected. Correction changes the received bit string to the nearest codeword, so if the number of errors is at most (d − 1) ÷ 2 rounded down, the original codeword remains the nearest. For d = 5, detection works up to 4 bits and correction up to 2 bits.

FAQ

Are Hamming distance and Hamming code the same thing?

No. Hamming distance is a measure that counts the differences between two bit strings, while a Hamming code is a code built to have a minimum Hamming distance of 3, which can correct a 1-bit error. Both are named after Hamming.

Can the Hamming distance between bit strings of different lengths be found?

Hamming distance is defined only between strings of the same length. To count differences including inserted and deleted characters, the edit distance (Levenshtein distance) is used.
