What is Argument?

A value passed when calling a function or procedure. The variable that receives the value in the declaration is called a formal parameter, and the value passed at the call is called an actual argument. Arguments can be passed by value, which copies the value, or by reference, which lets the callee refer to the variable or array itself.

In the standard RISC-V calling convention, which registers pass integer arguments and return values?

  1. AArguments in s0-s7; return value in ra
  2. BArguments in a0-a7; return value in a0 (and a1)
  3. CAll arguments on the stack; return value in sp
Show answer and explanation

Answer: B. Arguments in a0-a7; return value in a0 (and a1)

In the standard RISC-V calling convention, up to eight integer arguments are passed in a0-a7 (x10-x17), and the return value comes back in a0, or in a0 and a1 for values such as 64-bit integers on RV32. Passing through registers, which are faster than memory, keeps call overhead low. Arguments beyond eight go on the stack. Floating-point arguments use fa0-fa7.

In the standard RISC-V calling convention, when calling a function with ten integer arguments, where are the ninth and tenth passed?

  1. AIn s0 and s1
  2. BIn t0 and t1
  3. COn the stack
Show answer and explanation

Answer: C. On the stack

There are only eight argument registers, a0-a7, so from the ninth argument on the caller places them on the stack and the callee reads them at fixed positions relative to the stack pointer. The extra memory accesses make functions with very many arguments a little slower. Passing a pointer to a struct instead of many separate values is a common way to keep the argument count down.
