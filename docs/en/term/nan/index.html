What is NaN?

Short for Not a Number, a floating-point special value produced by operations with no numeric result, such as 0 ÷ 0 or the square root of a negative number. It has an all-ones exponent and a nonzero significand, and compares unequal even to itself.

When x is NaN, what does evaluating x == x give in most programming languages?

  1. ATrue
  2. BFalse
  3. CAn exception that always stops the program
Show answer and explanation

Answer: B. False

Under IEEE 754, NaN is "not a number," so it compares unequal to everything, including itself: x == x is false (and x != x is true). This property is sometimes used to test for NaN with x != x, though dedicated functions such as isnan are preferred. NaN arises from operations such as 0 ÷ 0 or ∞ − ∞ and propagates through later computations. Stopping on the comparison is not the default behavior.
