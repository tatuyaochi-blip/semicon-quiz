What is Arithmetic intensity?

Operations performed divided by bytes moved to and from memory. High values tend toward compute-bound, low values toward memory-bound.

Japanese name: 演算強度

Try it: questions about Arithmetic intensity

Which model plots whether a program's performance is limited by compute throughput or memory bandwidth, using arithmetic intensity (operations per byte) on the horizontal axis?

  1. AAmdahl's law
  2. BThe roofline model
  3. CThe Poisson model
Show answer and explanation

Answer: B. The roofline model

The roofline model plots performance against arithmetic intensity (operations per byte read from memory). Low-intensity workloads hit a slanted ceiling set by memory bandwidth; high-intensity workloads hit a flat ceiling at peak compute. With 1 TB/s of bandwidth and 100 TFLOPS of compute, for example, anything below 100 FLOP/byte is memory-bound. The model guides whether to improve data reuse or compute efficiency.

For the product of two N × N FP16 (2-byte) matrices, assuming each input is read once and the result written once, roughly what is the arithmetic intensity (operations per byte)?

  1. A1/3
  2. BN/3
  3. C3N
Show answer and explanation

Answer: B. N/3

The operation count is 2N³, and memory traffic is 3N² elements for the three matrices, or 6N² bytes in FP16. Arithmetic intensity is 2N³ ÷ 6N² = N/3, about 340 for N = 1024. The larger a matrix product, the more computation per byte, so it easily exploits arithmetic performance. By contrast, element-wise addition has intensity below 1 and is limited by memory bandwidth.
