What is AI compiler?

Software that analyzes a model's computational graph, optimizes fusion, data layout and tiling, and generates code for the target hardware, such as XLA and TVM.

Japanese name: AIコンパイラ

What do AI compilers such as XLA, TVM or PyTorch's compile feature mainly do?

  1. ATranslate an AI model's answers into human language
  2. BAutomatically collect training data
  3. CAnalyze the model's computational graph, optimize fusion, data layout and tiling, and generate code for the target hardware
Show answer and explanation

Answer: C. Analyze the model's computational graph, optimize fusion, data layout and tiling, and generate code for the target hardware

An AI compiler takes the model as a computational graph of operations and data flows, fuses operations where possible, removes unnecessary computation, chooses memory layouts and tunes tile sizes, then generates kernels suited to the target, such as a GPU or NPU. It automatically produces optimized code for each hardware target from the same model, greatly reducing manual optimization work.

Which orders the AI software stack from the layer closest to users down to the layer closest to hardware?

  1. AFramework (such as PyTorch) → compiler or runtime → operation libraries (such as cuBLAS) → driver → hardware
  2. BHardware → framework → driver → libraries
  3. CDriver → framework → hardware → compiler
Show answer and explanation

Answer: A. Framework (such as PyTorch) → compiler or runtime → operation libraries (such as cuBLAS) → driver → hardware

Users write models in a framework such as PyTorch. The framework or an AI compiler or runtime optimizes the computational graph, and operations such as matrix products and convolutions call kernels from highly optimized libraries. The libraries send commands to the GPU or NPU through the driver. For new hardware to be widely adopted, this whole software stack must be mature, not just the raw arithmetic performance.
