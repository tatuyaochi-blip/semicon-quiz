What is SoC (system on chip)?

An IC that integrates the functions a system needs, such as CPU, GPU, memory controller and communications, on one chip. The heart of a smartphone is a typical example.

Japanese name: SoC(システムオンチップ)

What goes on an SoC

A typical smartphone system on chip (SoC) contains several CPU cores, a GPU, often a neural processing unit and image signal processor, on-chip SRAM caches, a memory controller with its DRAM interface, display and camera interfaces, high-speed I/O, security blocks and power management logic, and in some designs a cellular modem. Main DRAM normally stays on separate chips, often stacked on top of the SoC package. Blocks inside communicate over an on-chip interconnect; Arm's AMBA AXI family, including AXI4-Lite for register access and AXI4-Stream for data flows, is a widely used standard that lets IP from different vendors connect.

Why integrate on one chip

Signals that stay on one die avoid package pins, board traces and the large drivers needed to switch them, so an SoC is smaller, faster and uses less power than the same functions spread over several chips, and the board needs fewer parts. The costs are real, however. Large dies have lower yield because each defect kills more area, the die cannot exceed the lithography field of about 26 mm by 33 mm, and functions that need different processes, such as DRAM, analog or RF, are hard to build optimally on the same logic process.

Power and security inside an SoC

Because blocks differ in speed requirements and activity, an SoC is split into power domains. Each can run at its own voltage and frequency through dynamic voltage and frequency scaling (DVFS) or be switched off entirely, while a small always-on domain handles wake-up. Signals crossing domains need level shifters and isolation cells. An external power management IC (PMIC) generates the many supply rails from the battery under SoC control. For security, mechanisms such as Arm TrustZone tag every bus access as secure or normal, creating a protected environment within the same chip.

SoC versus SiP and chiplets

An SoC puts the system on one die. A system in package (SiP) instead places several dies and passive components in one package, which makes it easy to combine chips made in different processes and to reuse existing parts, at some cost in interconnect density and power. Chiplet designs split what would be a very large SoC into several dies connected at high density in an advanced package, improving yield and allowing systems larger than one reticle field. Many companies that design SoCs are fabless and have them manufactured by foundries.

  3. CGive the lower-ASIL software higher priority and run the higher-ASIL software only in idle time
Show answer and explanation

Answer: B. Isolate them with memory protection, timing monitoring and similar measures so that malfunctions of lower-ASIL software do not encroach on the memory or execution time of higher-ASIL software

Consolidating multiple functions in one SoC reduces the number of components and ECUs, but bugs in lower-ASIL software may interfere with higher-ASIL functions by corrupting memory or using up CPU time. Therefore, freedom from interference is demonstrated through spatial partitioning with memory protection units or a hypervisor, and temporal partitioning by allocating and monitoring execution time. Without partitioning, everything must be developed to the highest ASIL, which requires much more effort.

What is the main purpose of dividing an SoC into multiple power domains?

  1. ATo cut total power by setting each block's voltage to its performance needs and powering off only idle blocks
  2. BTo ensure all blocks always run at the same voltage
  3. CTo shrink the chip area
Show answer and explanation

Answer: A. To cut total power by setting each block's voltage to its performance needs and powering off only idle blocks

CPU cores, the GPU, memory controllers and small always-on management circuits differ in the performance they need and in when they run. Separate power domains let only the blocks that need speed run at high voltage, idle blocks be powered off and only essential circuits stay powered during standby. Boundaries need level shifters and isolation cells, making design and verification more complex.

FAQ

What is the difference between an SoC and a SiP?

An SoC integrates the system's functions on a single silicon die, while a SiP houses multiple separate dies and components in one package. SoCs give the lowest power and latency; SiPs make it easier to mix chips from different processes.

Is a microcontroller an SoC?

In a broad sense yes, since a microcontroller integrates a CPU, flash, SRAM and peripherals on one chip. The term SoC is usually reserved for larger application processors that run a full operating system with external DRAM.

Why is DRAM usually not on the same die as the SoC?

Commodity DRAM uses a specialized process optimized for dense capacitor cells, which is incompatible with a high-performance logic process. Smartphones therefore stack separate DRAM chips on or next to the SoC package instead.
