What is Cutoff frequency?

The frequency at which the output of a filter or amplifier falls 3 dB (to about 0.707 times) below the passband. For an RC circuit it is 1/(2πRC).

Japanese name: カットオフ周波数

  1. AAbout 16 Hz
  2. BAbout 160 Hz
  3. CAbout 1.6 kHz
Show answer and explanation

Answer: B. About 160 Hz

An RC filter's cutoff is fc = 1/(2πRC); with RC = 1×10³ × 1×10⁻⁶ = 1 ms, fc ≈ 159 Hz, about 160 Hz. At this frequency the output is −3 dB (about 0.707×) with a 45° phase lag, and above it the response falls 20 dB per decade. Because first-order roll-off is gentle, second- or higher-order active filters using op-amps are used for sharper cutoff.
