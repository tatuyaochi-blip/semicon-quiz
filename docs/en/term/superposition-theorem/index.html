What is Superposition theorem?

The property that a voltage or current in a linear circuit with several sources equals the sum of the results obtained with one source acting at a time and the other independent sources set to 0 (voltage sources shorted, current sources opened). It follows from the linearity of the circuit, so it cannot be applied directly to power, which is proportional to the square of the current. Dependent sources are not set to 0 but kept as part of the circuit.

Japanese name: 重ね合わせの理

  1. AThe power consumed in a resistor
  2. BThe current in a resistor
  3. CThe voltage of a node
Show answer and explanation

Answer: A. The power consumed in a resistor

The superposition theorem holds because voltages and currents are proportional to the sources (the circuit is linear). Power is proportional to the square of the current, so adding the powers due to each source is wrong. For example, if one source drives 1 A and the other 2 A in the same direction through a 1 Ω resistor, the correct power is (1 + 2)² × 1 = 9 W, but adding the separate powers gives 1 + 4 = 5 W. To find a power, first find the current by superposition and then square it.
