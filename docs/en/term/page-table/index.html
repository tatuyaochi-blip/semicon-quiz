What is Page table?

A table recording the mapping from virtual page numbers to physical page numbers. The OS builds one per process, and the CPU's MMU walks it to translate addresses. Each entry also holds protection bits.

Japanese name: ページテーブル

What is the role of a page table?

  1. AMapping virtual page numbers to physical page numbers
  2. BStoring a copy of the data in physical memory, page by page
  3. CManaging the priorities of running processes in page order
Show answer and explanation

Answer: A. Mapping virtual page numbers to physical page numbers

With virtual memory, the virtual addresses programs use are translated into actual physical memory addresses. A page table records, for each virtual page number, the corresponding physical page number and protection information such as read/write permissions; the OS builds one per process and the CPU's MMU walks it. Frequently used translations are cached in the TLB. It neither copies data contents nor manages process priorities.

With 32-bit virtual addresses, 4 KB pages and 4-byte page-table entries, how large is a single-level page table?

  1. A4 KB
  2. B4 MB
  3. C16 MB
Show answer and explanation

Answer: B. 4 MB

A 4 KB = 2¹² page gives a 12-bit offset, so the page number has 32 − 12 = 20 bits and there are 2²⁰ ≈ one million pages. At 4 bytes per entry the table is 2²⁰ × 4 B = 4 MB. Needing 4 MB per process is why multilevel page tables that omit unused parts are standard. 4 KB is the size of one page, and 16 MB would assume 16-byte entries.
