What is Page table?

A table recording the mapping from virtual page numbers to physical page numbers. The OS builds one per process, and the CPU's MMU walks it to translate addresses. Each entry also holds protection bits.

Field: OS & Hardware

Page table in the explanations

  • A page table records, for each virtual page number, the corresponding physical page number and protection information such as read/write permissions; the OS builds one per process and the CPU's MMU walks it.
