What is Baud rate?

The number of symbols sent per second in serial communication; for a UART it equals bits per second and must match on both sides.

Japanese name: ボーレート

Baud rate appears in 2 practice questions across 2 topics, including Embedded Systems & Firmware, Wireless Communication Basics.

Try it: questions about Baud rate

A small baud-rate mismatch between UART transmitter and receiver can garble characters. Why is the tolerance limited to roughly a few percent?

  1. AThe receiver aligns on the start bit and then samples each bit's center with its own clock, so the error accumulates over a character and fails once it exceeds half a bit by the last bit
  2. BA baud-rate mismatch lowers the transmitter's voltage
  3. CUARTs correct mismatches automatically, so there is effectively no limit
Show answer and explanation

Answer: A. The receiver aligns on the start bit and then samples each bit's center with its own clock, so the error accumulates over a character and fails once it exceeds half a bit by the last bit

The receiver aligns its timing at the start of the start bit and then counts at its own baud rate, sampling each bit at its center. A speed mismatch makes the sampling error accumulate bit by bit, and if it exceeds half a bit by the stop bit about 10 bits later, the receiver reads the wrong bit. So the combined error of both sides must stay within a few percent, which requires care with less accurate internal oscillators.

With 16QAM at a symbol rate of 5 M symbols per second (5 Mbaud), which is the bit rate?

  1. A1.25 Mbit/s
  2. B5 Mbit/s
  3. C20 Mbit/s
Show answer and explanation

Answer: C. 20 Mbit/s

16QAM sends log₂ 16 = 4 bits per symbol. The bit rate is "symbol rate × bits per symbol", so it is 5 M × 4 = 20 Mbit/s. The symbol rate (baud rate) is the number of symbols sent per second, and with multilevel modulation it does not equal the bit rate. Because the occupied bandwidth is set mainly by the symbol rate, using more levels raises the bit rate without widening the bandwidth.
