What is I/O redirection?

In the shell, switching where a command's standard input, standard output and standard error go, to a file or elsewhere instead of the screen or keyboard. > overwrites a file, >> appends to its end, < makes a file the standard input, and 2> sends standard error (number 2) to a file. 2>&1 points standard error to where standard output goes "at that moment", so > file 2>&1 and 2>&1 > file give different results.

Japanese name: 入出力のリダイレクト
