What is Memory leak?

A defect in which memory obtained with malloc or similar is not released with free after use, and the pointer to it is lost, so the usable memory keeps shrinking. It often happens when an error path returns early and skips the release. In a short program the OS reclaims the memory at exit, so it goes unnoticed, but in servers and embedded devices that run for a long time free memory decreases little by little until an allocation finally fails. Tools such as Valgrind and AddressSanitizer (LeakSanitizer) can detect it.

Answer: B. The heap

The heap is the area from which a running program obtains memory of the size it needs and returns it with free when done. Its key feature is that sizes and lifetimes are decided at run time. malloc manages free space itself and asks the OS to enlarge the area when it runs short (through the brk or mmap system calls on Linux). Forgetting to call free leaves unused memory behind, which is a memory leak.
