What is Redundancy repair?

Replacing rows or columns that contain defective memory cells with spare rows or columns prepared in advance. The defect locations are found by testing and the switch is made with fuses or similar. It greatly improves yield.

Japanese name: 冗長救済

Field: DRAM

Why memory chips carry spares

A DRAM die contains billions of cells, and the chance that every one of them is defect-free is small. Without repair, a single bad cell or a shorted word line would scrap the whole chip, and yields of high-capacity memory would be untenable. Designers therefore add spare rows and spare columns to each memory array. Redundancy repair replaces rows or columns that contain defective cells with these spares, so a die with a limited number of faults can still be shipped as a fully working part.

From test to repair

At wafer test, memory testers write and read patterns across all addresses and build a fail bit map showing which bits failed. A redundancy analysis program then decides how to cover every failing bit with the available spare rows and columns; a single failing bit can be fixed by either, while a failing line needs a matching spare line. The chosen addresses are stored in fuses, either laser-cut metal fuses or electrically programmed fuses and antifuses. On each access, comparators check the incoming address against the stored ones and redirect matches to a spare.

Repair after packaging

Laser fuses can only be cut at wafer level, but electrically programmable elements allow fixes later. Post-package repair (PPR) lets a failing row discovered after assembly be remapped to a spare, and some memory standards let a system perform this in the field. This catches defects introduced by packaging stress or found in burn-in. The design must balance spare count against cost: each spare row or column takes area, and the address comparison adds a small delay to the access path.

Fail bit maps as a diagnostic

The fail bit map is useful beyond repair. The shape of the failures hints at their physical cause: isolated single bits suggest weak cells or point defects, complete rows or columns suggest broken or shorted word lines or bit lines, and clusters suggest particles or local process problems. Failure analysis engineers correlate these signatures with inline inspection data to find the responsible process step. The same redundancy approach is used in large SRAM caches on processors, where spare rows or columns recover yield on dies with large memory area.

Answer: A. Rows or columns containing defective cells are replaced with spare rows or columns prepared in advance

Building billions of cells with no defects is rare, so DRAMs include spare rows and columns. Addresses of faulty locations found at wafer test are recorded in laser-cut fuses or electrically programmed antifuses, and accesses are redirected to spares; post-package repair (PPR) allows fixes even after packaging. Without this redundancy repair, high-capacity DRAM yields would be untenable.

FAQ

How does DRAM redundancy repair work?

Testing identifies the addresses of failing rows or columns, those addresses are stored in fuses or antifuses, and on-chip comparators redirect any access to them to built-in spare rows or columns.

What is post-package repair (PPR)?

Post-package repair is a feature that lets a failing DRAM row be remapped to a spare row after the chip is packaged, using electrically programmable elements instead of wafer-level laser fuses.

What is a fail bit map?

A fail bit map is a map of which memory bits failed at which addresses; it is used to plan redundancy repair and to infer the physical cause of defects from the failure pattern.
