What is Superscalar?

A processor design that issues and executes several instructions per clock cycle. It has multiple execution units and processes independent instructions in parallel.

Japanese name: スーパースカラ

Superscalar appears in 4 practice questions across 2 topics, including CPUs and architecture, ISA & Assembly.

Try it: questions about Superscalar

What is the processor design called that issues and executes multiple instructions simultaneously in one clock cycle?

  1. ASuperscalar
  2. BSingle-cycle
  3. CHarvard architecture
Show answer and explanation

Answer: A. Superscalar

A superscalar processor has multiple execution units and issues several independent instructions per clock, pushing IPC above 1. Recent high-performance cores are about 6–10 instructions wide. Combined with out-of-order execution it boosts performance, but dependency-checking logic grows roughly with the square of the width, so width cannot be increased indefinitely.

Approximately how many instructions per second can a processor with a 2 GHz clock and an average CPI (clocks per instruction) of 0.5 execute?

  1. A1 billion instructions
  2. B4 billion instructions
  3. C100 million instructions
Show answer and explanation

Answer: B. 4 billion instructions

There are 2×10⁹ clocks per second and each instruction averages 0.5 clocks, so 2×10⁹ ÷ 0.5 = 4×10⁹—4 billion instructions. CPI below 1 reflects superscalar execution of multiple instructions per clock. Performance is execution time = instruction count × CPI ÷ frequency, so no single one of the three factors suffices for comparison.
