What is Quantization error?

The error that arises when rounding a continuous analog value to a digital value with a finite number of bits. At most half of one LSB.

Field: A/D and D/A conversion

Where the error comes from

An N-bit analog-to-digital converter (ADC) divides its full-scale range into 2^N steps, each one least significant bit (LSB) wide. A 10-bit converter with a 1 V range has an LSB of about 0.98 mV. Every input inside a step maps to the same code, so the difference between the true input and the value the code represents rises and falls in a sawtooth pattern as the input sweeps. In an ideal converter with rounding it never exceeds ±1/2 LSB. Each extra bit halves the LSB and therefore halves the maximum error.

Quantization noise and ideal SNR

When the input is busy, spanning many codes and not locked to the sampling clock, the error behaves like random noise spread uniformly between −1/2 and +1/2 LSB. Its root-mean-square (rms) value is then LSB/√12, about 0.29 LSB. For a full-scale sine wave, this gives the ideal signal-to-noise ratio (SNR) of 6.02N + 1.76 dB, about 74 dB for 12 bits and 98 dB for 16 bits. Real converters fall short because of thermal noise, jitter and nonlinearity, which is why effective number of bits (ENOB) is quoted from measured performance.

When it behaves as distortion: dither

For small, slowly varying or periodic inputs synchronized with the sampling clock, the error is no longer random; it follows the signal and shows up as harmonic distortion and spurious tones. Adding a small random signal, called dither, of roughly one to a few LSB before conversion decorrelates the error from the signal, turning distortion into a benign noise floor. Averaging many dithered samples can then resolve values finer than one LSB. The same principle appears in audio bit-depth reduction and in error diffusion for images.

Reducing it beyond adding bits

Oversampling spreads the fixed quantization noise power over a wider frequency range; filtering back to the signal band then removes part of it, gaining about 3 dB, or half a bit, per doubling of the sampling rate. Noise shaping, used in delta-sigma converters, goes further by pushing most of the noise out of the signal band before it is filtered away. Quantization error should be distinguished from other ADC errors, such as offset, gain error and differential or integral nonlinearity (DNL, INL), which come from imperfect circuits rather than finite resolution.

Answer: C. ±1/2 LSB

Rounding a continuous value to steps 1 LSB wide always introduces error, at most ±1/2 LSB in an ideal ADC. When the input varies enough, the error behaves like noise uniformly distributed over ±1/2 LSB with an rms value of LSB/√12—the basis of the ideal SNR of 6.02N + 1.76 dB. More bits mean a smaller LSB and smaller quantization error.

FAQ

What is the maximum quantization error of an ADC?

For an ideal rounding ADC it is ±1/2 LSB, where one LSB is the full-scale range divided by 2^N.

Why is quantization noise LSB divided by root 12?

If the error is uniformly distributed between −1/2 and +1/2 LSB, its variance is LSB²/12, so the rms value is LSB/√12, about 0.29 LSB.

What is the ideal SNR of a 12-bit ADC?

Using 6.02N + 1.76 dB for a full-scale sine wave, a 12-bit ADC has an ideal SNR of about 74 dB.
