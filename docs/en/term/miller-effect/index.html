What is Miller effect?

The effect by which a capacitance between the input and output of an inverting amplifier appears (1 + gain) times larger from the input. It degrades the high-frequency response of common-emitter and common-source stages.

Field: Bipolar transistors

  • Input impedance is low, about 1/gm (about 26 Ω at 1 mA), and because the base is AC-grounded the stage avoids feedback capacitance between input and output (the Miller effect), so it amplifies to high frequencies.
