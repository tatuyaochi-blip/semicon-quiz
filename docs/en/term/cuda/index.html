What is CUDA?

NVIDIA's platform for general-purpose computing on its GPUs. Kernels are written in an extended C++, with parallelism expressed as a grid, blocks and threads.

Japanese name: CUDA

In GPU programming such as CUDA, what is a "kernel"?

  1. AThe core of the GPU's operating system
  2. BA function that many threads execute simultaneously on the GPU
  3. CA component that cools the GPU chip
Show answer and explanation

Answer: B. A function that many threads execute simultaneously on the GPU

In GPU programming a kernel is a function launched from the CPU-side program in which many GPU threads execute the same code. Each thread uses its own index to choose which data element to handle. For array addition, for example, the kernel is written so that each thread adds one element, and as many threads are launched as there are elements. The word is the same as for an OS kernel, but the meaning differs.

Which correctly orders the CUDA thread hierarchy from largest to smallest?

  1. AGrid → block → thread
  2. BThread → block → grid
  3. CBlock → thread → grid
Show answer and explanation

Answer: A. Grid → block → thread

One kernel launch forms a grid, which is divided into many blocks, each containing many threads. A block's threads run on the same SM (a cluster of execution units) and can cooperate through shared memory and synchronize. Different blocks run independently, so the number running at once adapts to the GPU's size, and the same program runs on small and large GPUs.
