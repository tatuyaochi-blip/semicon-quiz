What is Top-down analysis?

A method using performance counters to divide CPU issue slots into frontend bound, backend bound, bad speculation and retiring, narrowing down bottlenecks.

Japanese name: トップダウン分析

In top-down microarchitecture analysis using performance counters, which are the major categories into which CPU issue slots are divided?

  1. AFast, slow and normal
  2. BFrontend bound, backend bound, bad speculation and retiring
  3. CDisk, network, display and keyboard
Show answer and explanation

Answer: B. Frontend bound, backend bound, bad speculation and retiring

Top-down analysis classifies each cycle's issue slots by whether they went empty because the front end (fetch and decode) could not keep up, stalled in the back end (waiting on execution units or memory), were spent on instructions discarded after misprediction, or were used by instructions that completed (retired). Drilling from the largest category into finer causes identifies bottlenecks efficiently.
