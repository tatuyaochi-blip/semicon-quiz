What is Self-refresh?

A low-power DRAM state in which the DRAM refreshes itself to retain contents without commands from the memory controller, used during system sleep.

Japanese name: セルフリフレッシュ

Which correctly describes the self-refresh mode of DRAM?

  1. AA mode that erases all data
  2. BA mode in which the DRAM refreshes itself internally without external commands, retaining data at low power, for example during standby
  3. CA mode that doubles access speed
Show answer and explanation

Answer: B. A mode in which the DRAM refreshes itself internally without external commands, retaining data at low power, for example during standby

In self-refresh mode the DRAM refreshes itself using an internal timer, so the external clock and controller can be stopped, preserving data at low power while a phone or PC sleeps. Some devices adjust refresh rate automatically with temperature, and partial-array self-refresh retains only selected banks to cut power further.

Among DRAM power-saving states, which describes self-refresh?

  1. AA low-power state in which the DRAM keeps refreshing itself to retain its contents even with no commands from the memory controller
  2. BA state that erases all DRAM contents
  3. CA state that doubles DRAM frequency
Show answer and explanation

Answer: A. A low-power state in which the DRAM keeps refreshing itself to retain its contents even with no commands from the memory controller

DRAM loses its contents without periodic refresh, normally commanded by the memory controller. In self-refresh, the DRAM keeps refreshing itself with an internal oscillator, so contents survive even with the memory controller and interface circuits shut down. It is used while PCs and smartphones sleep, allowing work to resume immediately on wake.
