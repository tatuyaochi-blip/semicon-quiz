What is Interrupt?

A CPU mechanism that temporarily suspends the current task to handle a request, for example from an external device, and then returns to the original task.

Field: CPUs and architecture

Interrupt in the explanations

  • On accepting an interrupt, the CPU saves the address of the instruction it would have executed next plus state such as the operating mode, and jumps to the interrupt handler, located for example via an interrupt vector table.
