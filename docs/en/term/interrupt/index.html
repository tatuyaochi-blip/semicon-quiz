What is Interrupt?

A CPU mechanism that temporarily suspends the current task to handle a request, for example from an external device, and then returns to the original task.

Japanese name: 割り込み

Try it: questions about Interrupt

What is the usual sequence when a CPU accepts an interrupt?

  1. AIt discards the running program and restarts it from the beginning
  2. BAfter running the interrupt handler, it starts the next program rather than returning
  3. CIt saves the current location and state, runs the interrupt handler, then returns to the saved location
Show answer and explanation

Answer: C. It saves the current location and state, runs the interrupt handler, then returns to the saved location

On accepting an interrupt, the CPU saves the address of the instruction it would have executed next plus state such as the operating mode, and jumps to the interrupt handler, located for example via an interrupt vector table. The handler saves the registers it uses, does its work, restores state and resumes the original program where it stopped. Programs are not discarded or restarted. The OS may switch to another process after the handler, but that is a scheduling decision.

Why is interrupt handling split into a short part done immediately and the remainder done later in a normal context?

  1. ARunning the handler in two parts halves the total amount of work
  2. BThe second half is done automatically by hardware, so no software is needed
  3. CTo minimize time with interrupts held off and defer heavy work
Show answer and explanation

Answer: C. To minimize time with interrupts held off and defer heavy work

While a handler runs, interrupts of the same or lower priority are often held off, so long handlers degrade the whole system's responsiveness. Only urgent work, such as reading device status and acknowledging the interrupt, is done first; slow work, such as processing data and notifying upper layers, is deferred to a normal context with interrupts enabled. The total work does not shrink, and software still does the second part.
