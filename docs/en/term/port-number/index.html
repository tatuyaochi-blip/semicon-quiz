What is Port number?

A number from 0 to 65535 used by TCP and UDP to identify which application on a host the traffic is for. Ports 0–1023, such as 80 for HTTP, 443 for HTTPS and 53 for DNS, are called well-known ports.

Answer: A. HTTP 80, HTTPS 443, DNS 53

A port number is a 16-bit number from 0 to 65535 that identifies which application on a host, reached by IP address, the traffic is for. Ports 0–1023 are called well-known ports and are assigned to major services. Typical ones are HTTP 80, HTTPS 443, DNS 53, SSH 22 and SMTP (mail transfer) 25. The client side uses a number chosen by the OS each time (an ephemeral port) as its source port. Services can run on non-standard numbers; 8080 is often used for web development or proxy servers, but then the connecting side has to specify the number.
