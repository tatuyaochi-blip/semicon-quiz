What is Lossy compression?

A compression method that makes data far smaller than lossless compression can by discarding components that human eyes or ears hardly notice. The restored data do not match the original exactly. Examples include JPEG for images, MP3 and AAC for audio, and H.264 and H.265 for video, which commonly split the data into frequency components and quantize the fine components coarsely. The stronger the compression, the more visible the degradation, such as blocky distortion. Repeated compression and restoration compounds the degradation.

Japanese name: 非可逆圧縮

Answer: A. Compressing a program's executable file for distribution

Lossless compression restores the original data without a single bit of difference, while lossy compression discards parts that people hardly notice in return for much greater shrinkage. A program does not run correctly if even one bit differs, so lossless compression such as ZIP is used. Small differences in images and sound are hard to see or hear, so lossy compression such as JPEG, MP3 and video coding formats is widely used for them.
