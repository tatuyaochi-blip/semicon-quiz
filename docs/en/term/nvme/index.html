What is NVMe?

An interface standard for fast access to SSDs connected over PCI Express. It processes many commands in parallel and has lower latency than SATA, which was designed for HDDs.

Japanese name: NVMe

NVMe appears in 3 practice questions across 2 topics, including SRAM and flash memory, I/O Interfaces & Buses.

Field: SRAM and flash memory

Why SSDs needed a new interface

SATA SSDs use AHCI, a host interface designed for hard disks: one command queue holding up to 32 commands, behind a link that tops out around 600 MB/s. Flash memory can service many requests in parallel, so this became the bottleneck. NVMe (NVM Express) is a protocol designed for non-volatile memory attached directly to PCI Express. It supports up to 64K I/O queues, each up to 64K commands deep, uses a compact command set, and lets each CPU core own its own queues, cutting software overhead and lock contention.

Submission and completion queues

NVMe queues are rings in host memory. To issue a read or write, the driver places a 64-byte command in a submission queue and writes the new tail position to a doorbell register on the device. The controller fetches commands by DMA, moves the data directly to or from host memory, and writes a 16-byte entry to the paired completion queue, typically signaling the host with an MSI-X interrupt. The host then updates the completion queue's head doorbell. Host and device advance independently, so many transfers are in flight at once.

Bandwidth and form factors

Because NVMe rides on PCIe, its bandwidth follows the link generation and lane count: about 7 GB/s for PCIe 4.0 x4 drives and over 10 GB/s with PCIe 5.0 x4. Protocol latency is a few microseconds, small compared with flash read times of tens of microseconds. NVMe drives come as compact M.2 cards, 2.5-inch U.2 drives and add-in cards. Note that M.2 is only a connector: an M.2 slot may carry SATA or PCIe, so an M.2 SSD is not necessarily NVMe. NVMe over Fabrics extends the protocol across networks.

Housekeeping commands

Besides reads and writes, NVMe defines administrative commands for creating queues, identifying the controller, managing namespaces and updating firmware. The Deallocate operation, part of the Dataset Management command, is the NVMe equivalent of ATA TRIM: it tells the SSD which logical blocks no longer hold useful data, so garbage collection can erase them without copying. This reduces write amplification, which improves sustained write performance and extends flash endurance.

  1. AThe CPU transfers data by writing it byte by byte into device registers
  2. BThe CPU only writes addresses and lengths into descriptors and notifies the device, which reads them and carries out the transfers itself
  3. CDescriptors exist only inside the device and are invisible to the CPU
Show answer and explanation

Answer: B. The CPU only writes addresses and lengths into descriptors and notifies the device, which reads them and carries out the transfers itself

A descriptor ring is a table in main memory, used in a circular way, where each entry says which address to transfer and how many bytes. The CPU fills free descriptors and tells the device once, through a register, how far it has written. The device reads the descriptors by DMA, transfers the data and marks finished descriptors as complete. CPU and device can advance many transfers without waiting for each other.

FAQ

What does NVMe stand for?

NVMe stands for Non-Volatile Memory Express, also written NVM Express. It is a host interface and command protocol for accessing SSDs and other non-volatile memory over PCI Express.

What is the difference between an NVMe SSD and a SATA SSD?

A SATA SSD uses the AHCI protocol with a single 32-command queue and a link limited to about 600 MB/s. An NVMe SSD connects over PCIe with thousands of parallel queues, giving several to more than ten gigabytes per second and lower software latency.

Does NVMe support TRIM?

Yes. NVMe provides the same function through the Deallocate attribute of the Dataset Management command, which operating systems issue when files are deleted.
