What is Interrupt handler?

The routine a CPU runs when an interrupt or exception occurs. It saves the interrupted state, handles the cause and returns. Handlers should be kept as short as possible.

Japanese name: 割り込みハンドラ

Try it: questions about Interrupt handler

While the main code updates a register bit with "reg |= mask;" (read-modify-write), an interrupt handler changes a different bit of the same register. Which pairs the possible problem with a fix correctly?

  1. AThe handler's change is lost when main writes back; disable interrupts during the update or use dedicated per-bit set/clear registers
  2. BThe register is permanently damaged; replace the microcontroller
  3. CNothing happens; no fix is needed
Show answer and explanation

Answer: A. The handler's change is lost when main writes back; disable interrupts during the update or use dedicated per-bit set/clear registers

"reg |= mask" is three operations: read the register, OR, and write back. If an interrupt arrives right after the read and the handler changes another bit, main writes back a value based on the stale read, wiping out the handler's change. Disabling interrupts during the operation, or using set and clear registers where only the bits written as 1 change, makes it a single write and avoids the problem.

What should be avoided inside an interrupt handler?

  1. AWriting 1 to a flag variable to notify the main code
  2. BClearing the bit that indicates the interrupt source
  3. CTime-consuming work such as printing long strings with printf or loops that wait for something to happen
Show answer and explanation

Answer: C. Time-consuming work such as printing long strings with printf or loops that wait for something to happen

While an interrupt handler runs long, other interrupts cannot be serviced and the main code stalls. printf takes time to finish and may itself rely on interrupts, so it is especially risky. A handler should do only the minimum, such as moving received data into a buffer or setting a flag, and leave heavy work to the main loop or a task. It must also remember to clear the interrupt source bit.
