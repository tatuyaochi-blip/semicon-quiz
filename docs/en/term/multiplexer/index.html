What is Multiplexer?

A circuit that selects one of several inputs according to select signals and passes it to the output. The reverse, routing one input to one of several outputs, is a demultiplexer.

Japanese name: マルチプレクサ

Which correctly describes the function of a multiplexer?

  1. AIt stores the input value for one clock cycle
  2. BIt inverts the logic of the input signal
  3. CIt selects one of several inputs according to select signals and outputs it
Show answer and explanation

Answer: C. It selects one of several inputs according to select signals and outputs it

A multiplexer (selector) routes one of several inputs to its output according to a select signal; n select bits choose among 2ⁿ inputs. CPUs use them to pick register values and switch buses, and FPGA logic blocks (LUTs) implement arbitrary logic with memory plus multiplexers. A circuit that routes one input to one of several outputs is a demultiplexer.
