What is Loop unrolling?

Replicating a loop body several times to reduce the number of iterations. It cuts branch and counter overhead and gives more freedom to reorder instructions, at the cost of larger code.

Japanese name: ループ展開

Show answer and explanation

Answer: A. Fewer counter checks and branches, and easier reordering

Loop unrolling writes, say, four copies of the loop body and runs a quarter as many iterations. Counter checks and branches shrink, and instructions from the copies can be interleaved, making it easier to hide operation latencies. Code grows in exchange and can strain the instruction cache. A single copy with smaller code is the reverse, and extracting a loop into a function is a different transformation.
