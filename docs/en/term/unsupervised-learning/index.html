What is Unsupervised learning?

A machine learning approach that finds groupings or structure in data that has no correct-answer labels. It is used for clustering, which divides similar data into groups (k-means and others), dimensionality reduction, which represents data with fewer variables (principal component analysis and others), and anomaly detection, which finds data that differs greatly from the rest. No labels need to be prepared, but the quality of the result is harder to evaluate.
