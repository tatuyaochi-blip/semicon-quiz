What is Leaf function?

A function that calls no other functions. Its return address is never overwritten, so it need not be saved, and it often needs no stack frame at all.

Field: ISA & Assembly

Leaf function in the explanations

  • A leaf function never executes jal, so ra stays intact and it can ret without saving it.
