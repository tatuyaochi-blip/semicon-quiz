What is ISO 14644-1?

The international standard that defines cleanroom cleanliness classes by the number of airborne particles. The smaller the number, the cleaner.

Japanese name: ISO 14644-1

Try it: questions about ISO 14644-1

Which ISO 14644-1 cleanliness class corresponds to Class 100 of the former US federal standard (no more than 100 particles of 0.5 µm or larger per cubic foot)?

  1. AISO Class 5
  2. BISO Class 1
  3. CISO Class 9
Show answer and explanation

Answer: A. ISO Class 5

Former US Federal Standard Class 100 allows no more than 100 particles of 0.5 µm or larger per cubic foot (about 28.3 L), or roughly 3,500 per m³. ISO 14644-1 Class 5 allows 3,520 per m³ at 0.5 µm, making them nearly equivalent. Each step down in ISO class divides the allowed count by 10, so Class 1 is extremely strict and Class 9 is like ordinary room air.

Which statement about ISO 14644-1 cleanliness classes is correct?

  1. AThe larger the number, the cleaner
  2. BThey are defined by particle weight rather than particle count
  3. CEach step down in the class number N cuts the allowed particle count by about a factor of 10
Show answer and explanation

Answer: C. Each step down in the class number N cuts the allowed particle count by about a factor of 10

Under ISO 14644-1, ISO Class N allows at most 10^N particles of 0.1 µm or larger per m³, with limits for other sizes given by a formula. Class 5 thus allows 100,000 and Class 4 10,000; lower numbers are cleaner. Classes are based on particle count concentration, not mass. Advanced fabs require about Class 1–3 in the spaces wafers touch.
