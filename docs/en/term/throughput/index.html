What is Throughput?

The amount of work, requests or data processed per unit time, a different metric from latency, which describes how fast one task completes.

Japanese name: スループット

Throughput appears in 15 practice questions across 12 topics, including CPUs and architecture, DRAM, CMP and cleaning.

Field: Performance Analysis

Try it: questions about Throughput

Which model plots whether a program's performance is limited by compute throughput or memory bandwidth, using arithmetic intensity (operations per byte) on the horizontal axis?

  1. AAmdahl's law
  2. BThe roofline model
  3. CThe Poisson model
Show answer and explanation

Answer: B. The roofline model

The roofline model plots performance against arithmetic intensity (operations per byte read from memory). Low-intensity workloads hit a slanted ceiling set by memory bandwidth; high-intensity workloads hit a flat ceiling at peak compute. With 1 TB/s of bandwidth and 100 TFLOPS of compute, for example, anything below 100 FLOP/byte is memory-bound. The model guides whether to improve data reuse or compute efficiency.

Which correctly states Little's law, relating work in progress (WIP), throughput and cycle time in a factory?

  1. AWIP = throughput × cycle time
  2. BWIP = throughput ÷ cycle time
  3. CWIP is unrelated to cycle time
Show answer and explanation

Answer: A. WIP = throughput × cycle time

Little's law states that average WIP equals throughput (output per unit time) times cycle time. A fab completing 50,000 wafers a month with a three-month cycle time always holds about 150,000 wafers in process. Shortening cycle time at the same throughput requires less WIP, and piling on too much WIP lengthens cycle time.
