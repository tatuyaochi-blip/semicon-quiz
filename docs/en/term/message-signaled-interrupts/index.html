What is Message-signaled interrupts (MSI)?

A scheme in which a device signals an interrupt by writing to a designated address. It needs no dedicated interrupt wire and lets one device have many interrupts.

Field: I/O Interfaces & Buses

Message-signaled interrupts (MSI) in the explanations

  • With MSI, the device writes a designated value to an address set by the OS, and that write arrives at the CPU as an interrupt.
