What is Cold boot attack?

An attack reading DRAM contents that persist briefly after power-off to extract keys and other secrets; cooling extends persistence. Prevented by memory encryption.

Japanese name: コールドブート攻撃

Which correctly describes a property of DRAM?

  1. AIt is volatile memory that loses data when the power is turned off
  2. BIt is non-volatile memory that retains data when the power is turned off
  3. CIt is read-only memory that cannot be rewritten
Show answer and explanation

Answer: A. It is volatile memory that loses data when the power is turned off

DRAM stores data as charge and is volatile: when power is removed, the charge is not maintained and the data is lost. Unlike SRAM, also volatile, it needs refresh even while powered. Chilled right after power-off, however, DRAM can retain data for seconds to minutes—exploited by the "cold boot attack" to read encryption keys from memory. Flash memory and similar devices are non-volatile.
