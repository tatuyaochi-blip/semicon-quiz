What is Sleep mode?

A microcontroller state that stops clocks or power to the CPU and peripherals while idle to save power, waking on an interrupt or similar.

Japanese name: スリープモード

  1. ATo increase processing speed

  3. CTo erase the program
Show answer and explanation

Answer: B. To stop the CPU and clocks when idle to cut power, waking only when needed, for example on an interrupt

A device that reads a sensor once every few seconds has nothing to do most of the time. Sleep mode stops the clocks or power to the CPU and unused peripherals, cutting current to the microampere range. A timer or pin-change interrupt wakes it, and it goes back to sleep as soon as the work is done. Deeper sleep draws less current but takes longer to wake and loses more state.
