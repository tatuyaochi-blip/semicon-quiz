What is Compute Express Link (CXL)?

A standard on the PCI Express physical layer that enables coherent memory sharing between CPUs and accelerators or memory devices.

Japanese name: CXL

Compute Express Link (CXL) appears in 4 practice questions across 2 topics, including I/O Interfaces & Buses, Emerging memories.

Field: I/O Interfaces & Buses

Why CXL was created

PCI Express (PCIe) moves data efficiently, but it does not keep device memory coherent with CPU caches, so software has to copy buffers and flush or invalidate caches to share data with an accelerator. Compute Express Link (CXL) reuses the PCIe physical layer, connectors and electrical signaling and adds protocols that keep caches coherent and let the CPU access device memory with ordinary loads and stores. CXL 1.x and 2.0 run at the PCIe 5.0 rate of 32 GT/s per lane, and CXL 3.x moves to the PCIe 6.0 rate of 64 GT/s.

The three CXL protocols

CXL.io is essentially PCIe and handles device discovery, configuration, interrupts and DMA. CXL.cache lets a device cache CPU memory in its own cache while hardware keeps it coherent. CXL.mem lets the CPU read and write memory attached to the device as if it were part of system memory. Devices are commonly grouped into three types: Type 1 devices such as smart network cards use CXL.io and CXL.cache; Type 2 accelerators with their own memory use all three; Type 3 memory expanders use CXL.io and CXL.mem.

Memory expansion and pooling

The DRAM a CPU can attach directly is limited by its number of memory channels and DIMM slots. A CXL memory expander adds capacity, and bandwidth, through PCIe-style links, and with CXL switches a pool of memory can be shared among several servers and assigned where it is needed. Access latency is higher than for directly attached DRAM, often compared with reaching memory on another CPU socket, so operating systems usually present CXL memory as a separate NUMA node and use it as a tier, keeping frequently accessed data in local DRAM.

CXL in the memory hierarchy

DRAM and NAND flash differ by about 1000 times in access time, tens of nanoseconds versus tens of microseconds, and storage-class memory was proposed to fill that gap. After Intel announced in 2022 that it would discontinue its phase-change-based Optane products, much of this space has been taken by low-latency SLC NAND on the storage side and CXL-attached DRAM on the memory side. CXL also allows memory controllers on the device to use different memory types than the CPU supports natively.

Answer: B. A standard that uses the PCI Express physical layer to allow coherent memory sharing between CPUs and accelerators or memory devices

With PCI Express, coherence between device memory and CPU caches is not maintained by hardware, so software had to take care of it. CXL runs on the same physical layer as PCI Express and adds protocols that maintain cache coherence and let the CPU read and write device memory like ordinary memory. It is used for sharing data with accelerators and for expanding memory.

Answer: C. Capacity can grow beyond the limit of the CPU's memory channels, and memory can be pooled among servers

The memory attachable directly to a CPU is capped by its number of memory channels and slots. CXL memory adds capacity by attaching memory devices to PCI Express slots or similar, and with switches several servers can share pooled capacity. Its latency is higher than directly attached DRAM, though, so it is used as a tier, with frequently used data kept in direct memory.

FAQ

What does CXL stand for?

CXL stands for Compute Express Link, an open interconnect standard built on the PCI Express physical layer that adds cache-coherent memory access between CPUs, accelerators and memory devices.

What is the difference between CXL and PCIe?

They share the same physical layer and slots, but plain PCIe transfers are not cache coherent. CXL adds the CXL.cache and CXL.mem protocols so devices and CPUs can share memory coherently with load/store semantics.

What is a CXL Type 3 device?

A Type 3 device is a memory expander that uses CXL.io and CXL.mem to give the host additional memory capacity, without caching host memory itself.
