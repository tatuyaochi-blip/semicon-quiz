What is Name mangling?

A C++ compiler's encoding of argument types and namespaces into a function's symbol name, so the linker can tell overloaded functions apart.

Japanese name: 名前修飾

Try it: questions about Name mangling

What is the main purpose of name mangling, in which a C++ compiler encodes argument types and other information into symbol names?

  1. ATo make function names unreadable so the program cannot be stolen
  2. BTo shorten function names and make the executable smaller
  3. CTo let the linker distinguish overloaded functions with the same name but different argument types, and namespaces
Show answer and explanation

Answer: C. To let the linker distinguish overloaded functions with the same name but different argument types, and namespaces

The linker matches symbols purely by their name strings. C++ allows functions with the same name, such as print(int) and print(double), which would otherwise be indistinguishable. So the compiler embeds the argument types and more into the name, as in "_Z5printi". C functions are not mangled, so when C++ calls a C function, it is declared extern "C" to turn mangling off.
