What is Verilog?

A hardware description language widely used for digital design and verification, describing circuits as modules with behavior expressed through assign and always.

Japanese name: Verilog

What is a major difference between a description written in an HDL such as Verilog and a software program in a language such as C?

  1. AAn HDL description represents circuits that operate concurrently
  2. BAn HDL description is a sequence of instructions executed one line at a time from the top
  3. CHDLs cannot use variables or conditional branches
Show answer and explanation

Answer: A. An HDL description represents circuits that operate concurrently

An HDL looks like a program, but logic synthesis turns what is written into gates and flip-flops. Every part of a circuit operates at all times, so multiple assign statements and always blocks work in parallel regardless of their order in the text. Thinking "do this, then that" as in software leads to unintended circuits, so it is important to picture the circuit being created while writing.

What is the purpose of a module in Verilog?

  1. ATo define a circuit component with input and output ports so it can be used inside other modules
  2. BTo pause program execution temporarily
  3. CTo print simulation results on the screen
Show answer and explanation

Answer: A. To define a circuit component with input and output ports so it can be used inside other modules

A module defines a block of circuitry with input and output ports, representing anything from an adder or counter to an entire CPU. A defined module can be used as a component any number of times inside other modules (instantiation), with its ports wired together to build larger circuits. Circuits are built hierarchically, much like placing and wiring parts on a board.
