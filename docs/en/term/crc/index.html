What is CRC (cyclic redundancy check)?

An error-detection method that treats the data bits as a polynomial, appends the remainder of dividing it by a generator polynomial, and lets the receiver repeat the calculation to detect errors. It is widely used in Ethernet, PCI Express, USB and file formats.

Japanese name: CRC(巡回冗長検査)

Field: I/O Interfaces & Buses

How it works

A CRC treats the data bits as the coefficients of a polynomial in modulo-2 arithmetic and computes the remainder after dividing by a generator polynomial. In modulo-2 arithmetic both addition and subtraction are XOR, so the division is repeated "if the leading bit is 1, XOR the generator and shift by one". For a w-bit CRC, the w-bit remainder after appending w zeros is sent with the data, and the receiver repeats the calculation to check that it matches. Real standards add conventions such as an initial value, bit reflection of each byte and a final XOR.

Errors it detects and where it is used

A w-bit CRC detects every burst error of length w or less, and the chance of missing other random errors is roughly 2⁻ʷ. It only detects errors, however; it cannot correct them, so systems recover by retransmission. CRCs are used in the Ethernet FCS (CRC-32), PCI Express packets, USB, CAN, storage commands and file formats such as ZIP and PNG, and in hardware they can be computed with a linear feedback shift register of flip-flops and XOR gates.

Try it: questions about CRC (cyclic redundancy check)

Three CRC check bits for the generator polynomial x³ + x + 1 (bit string 1011) are to be appended to the data 1101. The check bits are the remainder of dividing 1101000, the data followed by three 0s, by 1011, using exclusive OR instead of subtraction in the division. Which of the following are the check bits?

  1. A001
  2. B101
  3. C110
Show answer and explanation

Answer: A. 001

Divide 1101000 by 1011. The exclusive OR of the leading 1101 and 1011 is 0110; bringing down the next bit gives 1100, whose exclusive OR with 1011 is 0111; 1110 with 1011 gives 0101; and finally 1010 with 1011 gives 0001, so the remainder is 001. The word sent is 1101001, and the receiver judges that there is no error if the remainder after dividing by 1011 is 0.

Which of the following correctly describes a CRC whose generator polynomial has degree r (r check bits) and a constant term of 1?

  1. AFor a 1-bit error, its main use is to identify which bit is wrong and correct it
  2. BIt detects every burst error (an error confined to a contiguous range) of length r bits or less
  3. CWith a well-chosen generator polynomial, it detects every possible error pattern
Show answer and explanation

Answer: B. It detects every burst error (an error confined to a contiguous range) of length r bits or less

Representing the error pattern as a polynomial E(x), a CRC fails to detect an error only when E(x) is divisible by the generator polynomial G(x). A burst error of length r or less can be written as x^i × B(x) (B(x) of degree r − 1 or less with a constant term of 1), which is not divisible by a degree-r G(x) with a constant term of 1, so it is always detected. On the other hand, patterns that are divisible, such as an error with the same form as G(x) itself, are not detected. CRCs are used mainly to detect errors, and when one is found the data are sent again.

FAQ

How does a CRC differ from a checksum?

A checksum uses a simple operation such as adding bytes and easily misses reordered data or errors that cancel out, whereas a CRC is based on polynomial division, distinguishes bit positions and reliably catches burst errors.

Can a CRC correct errors?

In general, no. A CRC detects whether an error occurred but not which bit is wrong, so memories that need correction use an ECC such as a Hamming code.
