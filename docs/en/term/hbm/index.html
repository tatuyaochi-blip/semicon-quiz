What is HBM?

High Bandwidth Memory. Multiple DRAM dies stacked with TSVs, achieving very high bandwidth through an extremely wide bus.

Japanese name: HBM

In a nutshell

HBM is memory made by stacking several DRAM dies and connecting them to the processor through a very large number of wires. It is used in AI GPUs and similar chips to read and write large amounts of data at high speed.

Why it is in the news

  • April 2025 JEDEC released the next-generation standard HBM4 (JESD270-4). It doubles the interface width to 2,048 bits and specifies up to 2 TB/s of bandwidth per stack.
  • September 12, 2025 SK hynix announced that it had completed HBM4 development and was ready for volume production.
  • February 12, 2026 Samsung announced that it had begun shipping volume-production HBM4 running at 11.7 Gb/s per pin.

In AI training and inference, performance is often set less by the computation itself than by how fast data can be moved from memory, so HBM is indispensable for AI accelerator chips. New generations of the standard and the start of volume production at each memory maker make the news.

Bandwidth from width, not speed

High Bandwidth Memory (HBM) gets its performance from an extremely wide interface rather than very fast pins. Through the HBM3 generation each stack has a 1,024-bit data bus, compared with 64 bits for a typical DDR module; HBM4 widens this to 2,048 bits. At 6.4 Gb/s per pin, an HBM3 stack delivers about 819 GB/s, and a processor with several stacks reaches several TB/s. Running many pins at a moderate rate also keeps energy per bit lower than pushing fewer pins to the high per-pin speeds of graphics memory.

Inside an HBM stack

A stack consists of 8, 12 or 16 DRAM dies on a base, or logic, die, all connected vertically by through-silicon vias (TSVs) and microbumps. The base die handles signaling to the processor and contains test and repair circuitry. Because the standard fixes the stack height, adding dies means thinning each to around 30 µm and shrinking the bond layers; dies are typically joined by thermocompression bonding, with hybrid bonding emerging. Every die must be a known good die, since eight dies that are each 99% good give only about 92% good stacks.

Why HBM sits on an interposer

Several stacks of 1,024 lines each add up to thousands of signals, far more than an organic package substrate with wiring tens of micrometers wide can route. HBM is therefore placed beside the processor on a silicon interposer whose wiring is 1 µm or finer, giving connections only millimeters long. This side-by-side arrangement is called 2.5D packaging, while the DRAM stack itself is 3D. AI packages need interposers larger than one lithography field of about 26 × 33 mm, so the interposer wiring is stitched across adjacent exposure fields.

HBM versus GDDR and DDR

GDDR, the other memory used with GPUs, takes the opposite approach: individual chips on the circuit board around the processor, each with a narrow interface running above 20 Gb/s per pin. It is cheaper and simpler to assemble but delivers less bandwidth per watt. DDR serves CPU main memory with the largest capacity and lowest cost per bit. HBM costs more and needs advanced packaging, but it is the main answer to the memory wall in AI accelerators, whose large models must stream weights from memory for every computation.

How it differs from existing technology

DDR and GDDR memory run components laid out on the board at high speed over relatively few wires. HBM places DRAM stacked with TSVs right next to the processor and transfers data in parallel over many wires: 1,024 up to HBM3, and 2,048 in HBM4. The key difference is that it raises total bandwidth and power efficiency while keeping the per-pin speed modest.

  2. BTo connect the chips over short distances with an extremely large number of wires, achieving very high memory bandwidth
  3. CTo reduce memory capacity
Show answer and explanation

Answer: B. To connect the chips over short distances with an extremely large number of wires, achieving very high memory bandwidth

Each HBM stack has 1,024 data lines, and several stacks add up to thousands, more than an ordinary package substrate can route. Placing the GPU and HBM side by side on a silicon interposer with fine wiring connects them through many short wires only millimeters long, achieving memory bandwidth of several TB/s needed for AI computation. The purpose is neither to add parts nor to reduce capacity.

FAQ

What does HBM stand for?

In memory, HBM stands for High Bandwidth Memory, a JEDEC-standard stacked DRAM. In ESD testing the same letters mean the human body model, an unrelated test that simulates discharge from a charged person through 100 pF and 1.5 kΩ.

What is the difference between HBM and GDDR?

HBM stacks DRAM dies and connects them to the processor through a very wide bus on a silicon interposer, while GDDR uses separate chips on the board with narrow but very fast interfaces. HBM gives higher bandwidth and better energy per bit at higher cost.

Why is HBM placed so close to the GPU?

Each HBM stack needs over a thousand data connections, which can only be routed with the fine wiring of a silicon interposer over a few millimeters. Short, dense connections are what allow the very high bandwidth at moderate per-pin speed.
