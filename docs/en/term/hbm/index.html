What is HBM?

High Bandwidth Memory. Multiple DRAM dies stacked with TSVs, achieving very high bandwidth through an extremely wide bus.

Japanese name: HBM

HBM appears in 29 practice questions across 10 topics, including Advanced packaging (3D and chiplets), Semiconductor industry and market, DRAM.

Try it: questions about HBM

Which correctly describes HBM (High Bandwidth Memory)?

  1. AA slow memory using a single layer of flash memory
  2. BAn SRAM cache built into the CPU chip
  3. CA memory that stacks several DRAM dies with TSVs and achieves high bandwidth with a very wide bus
Show answer and explanation

Answer: C. A memory that stacks several DRAM dies with TSVs and achieves high bandwidth with a very wide bus

HBM stacks multiple DRAM dies with TSVs and connects to the processor over an extremely wide 1,024-bit data bus to achieve high bandwidth. HBM3, for example, runs 6.4 Gb/s per pin for about 819 GB/s per stack. It is used in 2.5D packages placed beside the processor on a silicon interposer and is found in AI GPUs and similar chips. It is neither flash memory nor on-chip SRAM cache.

In AI GPUs, what is the main reason the GPU chip and HBM are placed side by side on one silicon interposer?

  1. ATo increase part count
  2. BTo connect the chips over short distances with an extremely large number of wires, achieving very high memory bandwidth
  3. CTo reduce memory capacity
Show answer and explanation

Answer: B. To connect the chips over short distances with an extremely large number of wires, achieving very high memory bandwidth

Each HBM stack has 1,024 data lines, and several stacks add up to thousands, more than an ordinary package substrate can route. Placing the GPU and HBM side by side on a silicon interposer with fine wiring connects them through many short wires only millimeters long, achieving memory bandwidth of several TB/s needed for AI computation. The purpose is neither to add parts nor to reduce capacity.
