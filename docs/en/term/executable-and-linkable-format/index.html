What is Executable and Linkable Format (ELF)?

The file format used for object files, executables and shared libraries on Linux and other UNIX-like systems and in embedded devices.

Japanese name: ELF

Which statement is correct about files in the ELF format commonly used on Linux and similar systems?

  1. AIt is only for executables and cannot be used for object files
  2. BIt is used for object files, executables and shared libraries alike, and consists of a header, sections and so on
  3. CIt is a format for storing images
Show answer and explanation

Answer: B. It is used for object files, executables and shared libraries alike, and consists of a header, sections and so on

ELF (Executable and Linkable Format) is the program file format used by Linux, many other UNIX-like systems and embedded devices. The ELF header at the start records the target CPU, whether it is 64-bit, the address where execution starts and more, followed by sections such as .text and .data and program headers describing what the loader maps into memory. Windows uses the PE format and macOS uses Mach-O.

What is the difference between "sections" and "segments" in an ELF file?

  1. ASection is the Windows term and segment the Linux term for the same thing
  2. BSections are fine-grained units handled by the linker; segments group sections with the same permissions as units the loader maps into memory
  3. CSegments exist only on disk and are never loaded into memory
Show answer and explanation

Answer: B. Sections are fine-grained units handled by the linker; segments group sections with the same permissions as units the loader maps into memory

ELF has two views. The linker combines and relocates in units of fine-grained sections such as .text, .rodata, .data and .bss. The loader maps memory in units of segments described by the program headers, grouping, for example, .text and .rodata into a read-execute segment and .data and .bss into a read-write segment. Grouping by permission makes page-level protection easy to set up.
