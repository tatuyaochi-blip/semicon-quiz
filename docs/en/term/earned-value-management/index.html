What is Earned value management (EVM)?

A technique for managing a project's progress and cost by comparing them on a monetary scale using the planned value (PV), earned value (EV) and actual cost (AC). The schedule performance index SPI = EV ÷ PV and the cost performance index CPI = EV ÷ AC are used to judge delays and budget overruns and to estimate the total cost at completion.

Japanese name: アーンドバリューマネジメント(EVM)

The three values

The planned value (PV) is the budget for the work that was planned to be finished by a given point. The earned value (EV) is the work actually finished by that point, counted at its budgeted amount. The actual cost (AC) is the cost actually incurred by that point. Looking only at progress tells you what percentage is finished, and looking only at cost tells you how much has been spent, but comparing EV with both PV and AC lets you judge delays and overruns separately.

Variances and indices

The schedule variance SV = EV − PV and the schedule performance index SPI = EV ÷ PV describe progress, and the cost variance CV = EV − AC and the cost performance index CPI = EV ÷ AC describe cost. A negative SV (SPI below 1) means the project is behind schedule, and a negative CV (CPI below 1) means it is over budget. For example, with PV 500, EV 400 and AC 450, SPI = 0.8 (behind schedule) and CPI = 400 ÷ 450 ≈ 0.89 (over budget). Looking at both the differences and the ratios shows both the size of the problem and the efficiency.

Estimates at completion

If the current cost efficiency continues to the end, the estimate at completion is EAC = BAC ÷ CPI, where BAC is the budget at completion. In the example above, with a BAC of 1,000, EAC = 1,000 ÷ (400 ÷ 450) ≈ 1,125. If the overrun is considered temporary and the remaining work is expected to proceed on budget, EAC = AC + (BAC − EV) is used. Which formula to use depends on the cause of the overrun, so the decision is made together with an analysis of the cause, not from the numbers alone.

Try it: questions about Earned value management (EVM)

In a project with a budget at completion (BAC) of ¥20 million, at a certain point the planned value (PV) was ¥8 million, the earned value (EV) ¥6 million and the actual cost (AC) ¥7.5 million. Which correctly describes the project's status at that point?

  1. AIt is behind schedule (SPI = 0.75) and over budget (CPI = 0.8)
  2. BIt is behind schedule (SPI = 0.75) but within budget (CPI = 1.25)
  3. CIt is ahead of schedule (SPI = 1.33) but over budget (CPI = 0.8)
Show answer and explanation

Answer: A. It is behind schedule (SPI = 0.75) and over budget (CPI = 0.8)

The schedule performance index is SPI = EV ÷ PV = 6 ÷ 8 = 0.75, which is less than 1, so the project is behind schedule (schedule variance SV = EV − PV = −¥2 million). The cost performance index is CPI = EV ÷ AC = 6 ÷ 7.5 = 0.8, which is less than 1, so more has been spent than the budget for the completed work (cost variance CV = EV − AC = −¥1.5 million). In EVM, comparing the earned value (EV) with both the planned value (PV) and the actual cost (AC) evaluates progress and cost on the same monetary scale.

In a project with a budget at completion (BAC) of ¥12 million, the current planned value (PV) is ¥6 million, the earned value (EV) ¥4.8 million and the actual cost (AC) ¥6 million. Assuming the current cost efficiency continues, what is the estimate at completion (EAC)?

  1. A¥13.2 million
  2. B¥15 million
  3. C¥17.25 million
Show answer and explanation

Answer: B. ¥15 million

The cost performance index is CPI = EV ÷ AC = 4.8 ÷ 6 = 0.8, meaning that each yen's worth of budgeted work costs 1.25 yen. If this efficiency continues, EAC = BAC ÷ CPI = 12 ÷ 0.8 = ¥15 million, which is expected to exceed the budget by ¥3 million. ¥13.2 million is AC + (BAC − EV), assuming the remaining work (BAC − EV = ¥7.2 million) proceeds on budget. ¥17.25 million is AC + (BAC − EV) ÷ (CPI × SPI) = 6 + 7.2 ÷ 0.64 (in millions of yen), assuming both the cost and schedule efficiencies affect the remaining work.

FAQ

Which is more important, SPI or CPI?

They are looked at together. If SPI is below 1 but CPI is 1 or above, the project is behind but cost-efficient, so there is room to catch up by adding people. If both are below 1, delay and overrun are happening at the same time, and the scope or plan often has to be revised.

How is earned value (EV) measured?

A budget is assigned to each work package in the WBS, and the budgets of the finished work are added up. Work in progress is counted by rules set in advance, such as the 50/50 rule (50% when started, 100% when finished) or the 0/100 rule (0% until finished), which makes the figures less dependent on individual judgment.
