What is FeFET (ferroelectric FET)?

A transistor with a ferroelectric gate insulator. Its threshold voltage depends on the polarization direction, so a single transistor can store data non-volatilely and be read non-destructively.

Japanese name: FeFET(強誘電体トランジスタ)

Answer: A. The polarization direction changes the threshold voltage, so one transistor can store data non-volatilely and be read non-destructively

In a FeFET, the polarization direction of the ferroelectric gate dielectric changes the charge induced in the channel, shifting the threshold voltage. One transistor stores a bit (1T), and reading by whether current flows is non-destructive. Writing needs only gate voltage, keeping power low. The discovery of HfO2-based ferroelectrics revived interest, and improving endurance is the main challenge.
