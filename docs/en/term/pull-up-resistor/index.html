What is Pull-up resistor?

A resistor connecting a signal line to the supply so it rests at logic 1 when nothing drives it. It keeps input pins from floating and is used on I2C lines and elsewhere.

Japanese name: プルアップ抵抗

Field: Embedded Systems & Firmware

Why inputs need a defined level

A CMOS input draws almost no current, so if nothing drives it, its voltage is undefined. Coupled noise or even a nearby hand can make it read 0 and 1 at random, and an input resting at an intermediate voltage can turn on both transistors of the input stage, wasting shoot-through current. A pull-up resistor connects the line to the supply so it reads 1 by default. A switch wired from the pin to ground then reads 1 when open and 0 when pressed. A pull-down resistor does the mirror-image job.

Open-drain lines and wired-AND

An open-drain (or open-collector) output can only pull a line to ground or release it; it never drives high. The pull-up resistor supplies the high level. When several such outputs share one line, the line is high only if all of them release it and goes low if any one pulls down, forming a wired-AND. Multiple devices can therefore drive the line simultaneously without damaging each other, which is why I²C, shared interrupt lines and reset lines use this arrangement. Pulling up to a different supply also provides simple level shifting.

Choosing the resistor value

The rising edge is an RC charge of the line capacitance through the pull-up, so the time constant is R × C: 10 kΩ and 100 pF give 1 µs, with the 10–90% rise taking about 2.2 time constants. A smaller resistor speeds this up, but whenever an output holds the line low, current V/R flows, for example 3.3 mA from 3.3 V through 1 kΩ. That current must stay within the sink current at which the datasheet guarantees the low output voltage VOL, and it wastes power. Buses like I²C specify both maximum rise time and sink current.

Weak pulls vs. strong drivers

A pull-up is deliberately weak, so any active driver can override it; it only sets the default state. A push-pull output, by contrast, actively drives both high and low with low impedance and must never be tied to another push-pull output. Most microcontrollers offer internal pull-ups, typically in the tens of kilohms, which are fine for buttons but often too weak for fast buses that need external resistors. Pull-ups and pull-downs also hold enable, reset and configuration pins in a known state during power-up.

  1. AThe outputs conflict and are always damaged
  2. BIf any one outputs 0, the line becomes 0, acting as a wired AND
  3. CIf any one outputs 1, the line becomes 1

Answer: B. If any one outputs 0, the line becomes 0, acting as a wired AND

An open-drain output either pulls the line to ground or releases it; a pull-up resistor provides the 1. If any device outputs 0 the line goes low, and it is high only when all release it—a wired-AND that tolerates simultaneous drivers without damage. It is used for I²C buses, interrupt lines and level shifting between different supply voltages. Rise time, set by the pull-up resistor and line capacitance, is relatively slow.

Which correctly describes the change when the value of the pull-up resistor on an open-drain output is reduced?

  1. AThe rise becomes slower, but the current flowing while the output is low decreases, reducing power consumption
  2. BThe rise becomes faster, but the current flowing while the output is low increases, and VOL also tends to rise
  3. CThe high-level voltage rises above the pull-up supply voltage, making it easier to exceed the receiver's input rating
Show answer and explanation

Answer: B. The rise becomes faster, but the current flowing while the output is low increases, and VOL also tends to rise

The high level of an open-drain output is produced by the pull-up resistor pulling the signal line up while the output transistor is off. The rise speed is set by the time constant of the resistor and the line capacitance—for example, 1 µs for 10 kΩ and 100 pF. A smaller resistor makes it faster, but when the output is low, current flows from the supply through the resistor: 3.3 mA for 3.3 V and 1 kΩ. If this current exceeds the IOL condition in the datasheet, VOL will not stay within its specified value, so choose a value that satisfies both.

FAQ

Why do I2C lines need pull-up resistors?

I²C devices have open-drain outputs that can only pull SDA and SCL low, so external pull-ups are needed to create the high level and allow several devices to share the lines safely.

What happens if a pull-up resistor value is too small?

Edges get faster, but more current flows whenever a device holds the line low, which wastes power and can push the low voltage above its specified VOL if the driver's sink rating is exceeded.

What happens if a microcontroller input is left floating?

The pin's level is undefined, so noise makes it read 0 and 1 unpredictably and an intermediate voltage can cause extra current in the input buffer; a pull-up or pull-down resistor fixes it.
