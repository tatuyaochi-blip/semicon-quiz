What is Set-associative cache?

A cache organization in which data can go in any of several locations (ways) within the one set selected by the address. An n-way cache compares n tags in parallel on each access.

Field: Memory Hierarchy

Set-associative cache in the explanations

  • In a set-associative cache, part of the address selects a set, and data may occupy any of that set's ways—eight candidate slots in an 8-way cache—reducing conflict misses compared with direct mapping.

  • A set-associative cache first selects one set with the index bits, then compares the tags of every way in that set in parallel.
