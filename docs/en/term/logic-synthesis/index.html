What is Logic synthesis?

The design step that converts a circuit described in RTL into a netlist made of gates from a cell library.

Japanese name: 論理合成

Logic synthesis appears in 12 practice questions across 3 topics, including IC design flow and EDA, HDL & Verification, Logic circuits.

Field: IC design flow and EDA

What a synthesis tool does

Synthesis takes three inputs: RTL in a hardware description language, a cell library describing each gate's function, timing, area and power, and constraints such as clock periods and I/O delays, usually in SDC format. The tool first translates the RTL into generic logic, inferring registers, multiplexers and arithmetic operators. It then optimizes the Boolean logic independently of technology, maps it onto library cells, and finally sizes, buffers and restructures paths to meet the constraints. The output is a gate-level netlist plus timing, area and power reports.

How RTL becomes hardware

Synthesis turns code into circuits, not instructions, so every block runs concurrently. An always @(posedge clk) block becomes edge-triggered flip-flops. A combinational block that does not assign an output on every branch, such as an if without else, forces the tool to infer a latch to hold the old value. Synthesis ignores sensitivity lists, so an incomplete list makes simulation disagree with the gates; @(*) avoids this. Delays such as #10 and testbench tasks such as $display are simulation-only and are ignored.

Constraints shape the result

The same RTL can yield very different netlists. A tight clock pushes the tool toward larger, faster cells, low-threshold-voltage cells and parallel structures, such as a carry-lookahead adder in place of a ripple-carry one, increasing area and leakage; a relaxed clock lets it minimize area. False paths and multicycle paths tell the tool where not to spend effort. Wrong constraints are dangerous: a design can pass every tool check yet fail in silicon. Because wire delays are only estimated before layout, physically aware synthesis uses placement information to improve correlation.

Synthesis in the design flow

A typical flow runs specification, RTL design, logic synthesis, place and route, parasitic extraction, and signoff timing analysis before tape-out. High-level synthesis (HLS) sits above it, generating RTL from C or C++ by scheduling operations into clock cycles; logic synthesis then turns that RTL into gates. Formal equivalence checking proves the netlist implements the same logic as the RTL without simulation. Scan insertion for testing is commonly done during or right after synthesis. For FPGAs, synthesis maps logic onto lookup tables and flip-flops rather than standard cells.

Answer: B. The step of converting an RTL description into a netlist made of gates from a cell library

Logic synthesis converts RTL behavioral descriptions into a netlist of logic gates and flip-flops from the cell library. Given timing, area and power constraints, the tool simplifies logic and selects cells of suitable drive strength to meet them. Placing cells and routing wires is place-and-route, and transferring patterns to wafers is lithography.

Which technique confirms mathematically, without simulation, that a circuit's logic has not changed before and after logic synthesis?

  1. AFormal equivalence checking (formal verification)
  2. BDRC
  3. CDicing
Show answer and explanation

Answer: A. Formal equivalence checking (formal verification)

Formal equivalence checking mathematically and exhaustively verifies that two circuits implement the same logic function. It needs no test patterns and guarantees equivalence for all input combinations, so it is used before and after synthesis, place-and-route and ECOs. Exhaustive simulation is impractical once inputs reach just a few dozen bits. DRC checks layout geometry rules.

FAQ

What is the difference between logic synthesis and high-level synthesis?

High-level synthesis converts C or C++ algorithm descriptions into RTL, deciding which clock cycle each operation runs in. Logic synthesis takes RTL and converts it into a gate-level netlist of library cells.

Why does synthesis create an unintended latch?

If a combinational block leaves an output unassigned on some path, the output must remember its previous value, and a latch is the only way to do that. Assigning a default value or covering every case removes it.

What are the inputs and outputs of logic synthesis?

Inputs are the RTL, a cell library and timing constraints (typically SDC). The output is a gate-level netlist with reports on timing, area and power.
