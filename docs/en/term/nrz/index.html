What is NRZ?

Non-return-to-zero: the most basic signaling scheme, sending 1 bit per symbol with two voltage levels.

Japanese name: NRZ

NRZ appears in 3 practice questions across 2 topics, including I/O Interfaces & Buses, Silicon photonics.

Field: I/O Interfaces & Buses

What non-return-to-zero means

In NRZ signaling, each bit is sent as one of two levels, for example high for 1 and low for 0, and the level is held for the entire bit period. The name contrasts it with return-to-zero (RZ) coding, in which each pulse returns to a rest level partway through the bit, roughly doubling the required bandwidth. Because NRZ sends 1 bit per symbol, the symbol rate in baud equals the bit rate. In the context of multilevel signaling it is also called PAM2, and in optics it corresponds to on-off keying.

Bandwidth and spectrum

The fastest-changing NRZ pattern, alternating 1010, is a square wave whose fundamental is half the bit rate. This Nyquist frequency is where channel loss is usually quoted: a 32 Gb/s NRZ link has a Nyquist frequency of 16 GHz. NRZ also has strong low-frequency content, since long runs of identical bits contain no transitions and shift the average level. That is why links add line coding or scrambling, to give the receiver's clock recovery enough edges and keep AC-coupled signals balanced.

NRZ vs. PAM4

Four-level pulse amplitude modulation (PAM4) carries 2 bits per symbol, so the same bit rate needs only half the symbol rate and half the Nyquist frequency. About 106 Gb/s, for example, needs about 53 GBd in PAM4 but about 106 GBd in NRZ. The price is noise margin: with the same voltage swing, PAM4's three eyes each get about one third of the height, a penalty of roughly 9.5 dB, which raises the bit error rate and makes forward error correction (FEC) necessary. PCI Express 6.0 doubled Gen 5's bit rate this way.

Variants and where it fits

Related schemes appear in many interfaces. NRZI (non-return-to-zero inverted) encodes a 1 or a 0 as the presence or absence of a transition rather than as a level; USB 2.0 uses it, with bit stuffing to limit run length. Plain NRZ remains the simplest, most noise-tolerant choice whenever the channel can support the required Nyquist frequency, and it served PCI Express through generation 5. PAM4 takes over when channel loss at the NRZ Nyquist frequency becomes too high to equalize.

Answer: B. Fitting four levels into the same swing shrinks the spacing to about one third, so noise causes more bit errors

With the same voltage swing, two-level NRZ has the full swing between 0 and 1, but four-level PAM4 leaves only about one third of it between adjacent levels. The noise margin drops by roughly 9.5 dB, so bit errors become more likely. PCI Express 6.0 therefore adds a lightweight error-correcting code so the receiver can fix small errors before use.

FAQ

What is the difference between NRZ and PAM4?

NRZ uses two levels and sends 1 bit per symbol, while PAM4 uses four levels and sends 2 bits per symbol; PAM4 halves the required symbol rate but has about one third the eye height, so it needs error correction.

Is the baud rate equal to the bit rate in NRZ?

Yes. NRZ carries exactly one bit per symbol, so for example a 10 Gb/s NRZ signal runs at 10 GBd.

What is the difference between NRZ and NRZI?

NRZ represents bits by the signal level itself, while NRZI represents them by whether the level changes at the start of a bit period, which makes it independent of signal polarity.
