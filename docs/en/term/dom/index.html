What is DOM (Document Object Model)?

An interface that represents an HTML or XML document as a tree whose nodes are elements, text and so on, so that programs can read and write it. The browser parses HTML to build the DOM, and JavaScript finds elements with methods such as document.querySelector and changes their text, attributes and styles or adds elements. When the DOM changes, the browser redoes the layout calculation and painting as needed, so too many changes slow down the display.

Answer: B. A representation of an HTML document as a tree whose nodes are elements and so on, which JavaScript can read and write

The browser parses HTML and builds a tree structure (the DOM tree) whose root is the html element and whose nodes include head, body and the paragraphs inside them. JavaScript changes the page through the DOM, finding elements with document.querySelector, rewriting text and attributes, and adding elements. When the DOM changes, the browser redoes the layout calculation and painting as needed. The DOM is standardized as an interface for manipulating documents that does not depend on any particular programming language.
