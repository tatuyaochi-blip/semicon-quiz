What is Asynchronous reset?

A reset that initializes flip-flops as soon as the reset signal is asserted, regardless of the clock. Release should be synchronized to the clock.

Field: HDL & Verification

Asynchronous reset in the explanations

  • If an asynchronous reset is released just before or after a clock edge, the timing requirements for release are violated, and one flip-flop may start in this cycle while another starts in the next.
