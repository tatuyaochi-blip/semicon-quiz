What is AXI?

An on-chip bus from Arm's AMBA specifications that connects blocks in an SoC, with five independent channels and a VALID/READY handshake. Variants include AXI4-Lite and AXI4-Stream.

Field: I/O Interfaces & Buses

AXI in the explanations

  • AXI has five channels: read address (AR), read data (R), write address (AW), write data (W) and write response (B).

    What is a characteristic of the AXI bus?

  • Data at consecutive addresses, such as a cache-line fill, is often handled together, so AXI can send just the starting address and a length and then stream the data as a burst.

    What is the advantage of burst transfers in AXI?

  • AXI tags requests with IDs and allows several to be outstanding, so data keeps returning during the latency and bandwidth is used well.
