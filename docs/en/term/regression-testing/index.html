What is Regression testing?

Re-running existing tests after each design change to confirm that previously working features still work.

Japanese name: 回帰テスト

Which describes regression testing in circuit design?

  1. ATesting only the newly added feature once
  2. BStudying how circuit performance declines year by year
  3. CRe-running the existing tests after every design change to confirm that previously working features have not broken
Show answer and explanation

Answer: C. Re-running the existing tests after every design change to confirm that previously working features have not broken

Fixing a bug or adding a feature can break something elsewhere unexpectedly. Regression testing automatically re-runs every test built so far to check that previously passing tests still pass. Large designs run thousands of tests almost daily and track the results in a summary. This automation is possible only with self-checking testbenches.
