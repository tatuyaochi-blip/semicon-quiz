What is Calling convention?

The agreement on how arguments and return values are passed in registers or on the stack, and who saves which registers, when calling a function. It is a key part of the ABI.

Japanese name: 呼び出し規約

What is the main purpose of defining a calling convention?

  1. ATo standardize function names and make programs readable
  2. BSo that separately compiled functions and libraries can pass arguments and return values correctly
  3. CTo require OS permission each time a function is called
Show answer and explanation

Answer: B. So that separately compiled functions and libraries can pass arguments and return values correctly

A calling convention specifies which registers hold arguments, where return values go, which registers the callee may clobber and how the stack is used. Because of this agreement, libraries built by different compilers, or assembly functions combined with C functions, work together correctly. The calling convention is a key part of the ABI (application binary interface).

In the standard RISC-V calling convention, which registers pass integer arguments and return values?

  1. AArguments in s0-s7; return value in ra
  2. BArguments in a0-a7; return value in a0 (and a1)
  3. CAll arguments on the stack; return value in sp
Show answer and explanation

Answer: B. Arguments in a0-a7; return value in a0 (and a1)

In the standard RISC-V calling convention, up to eight integer arguments are passed in a0-a7 (x10-x17), and the return value comes back in a0, or in a0 and a1 for values such as 64-bit integers on RV32. Passing through registers, which are faster than memory, keeps call overhead low. Arguments beyond eight go on the stack. Floating-point arguments use fa0-fa7.
