What is Calling convention?

The agreement on how arguments and return values are passed in registers or on the stack, and who saves which registers, when calling a function. It is a key part of the ABI.

Field: ISA & Assembly

Calling convention in the explanations

  • A calling convention specifies which registers hold arguments, where return values go, which registers the callee may clobber and how the stack is used.

    What is the main purpose of defining a calling convention?

  • In the standard RISC-V calling convention, up to eight integer arguments are passed in a0-a7 (x10-x17), and the return value comes back in a0, or in a0 and a1 for values such as 64-bit integers on RV32.
