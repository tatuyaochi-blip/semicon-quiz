What is Quiescent current?

The current consumed by an IC's own internal circuitry, such as a regulator's, separate from the current delivered to the load; written IQ. It dominates standby consumption in battery-powered equipment and ranges from under 1 µA to several mA depending on the product.

Japanese name: 静止電流

Try it: questions about Quiescent current

Which correctly describes the "quiescent current (IQ)" of a linear regulator?

  1. ALeakage current that flows backward from the output pin toward the input pin when the output is turned off
  2. BThe maximum output current, guaranteed in the datasheet, that the regulator can supply to the load
  3. CCurrent that flows to ground for the regulator's own operation, separate from the current flowing to the load
Show answer and explanation

Answer: C. Current that flows to ground for the regulator's own operation, separate from the current flowing to the load

Quiescent current is the current consumed by the regulator's internal circuits, such as the voltage reference and error amplifier, so that input current = load current + quiescent current. It ranges from under 1 µA to several mA depending on the product. For example, using a regulator with 50 µA quiescent current in equipment whose standby load current is 10 µA means most of the battery drain goes to the regulator itself. In some products the quiescent current increases with load current, so check the values and graphs at no load and under load.

What is the closest efficiency of a linear regulator (LDO) producing 1.0 V from a 1.8 V input (ignoring the regulator's own quiescent current)?

  1. AAbout 80%
  2. BAbout 95%
  3. CAbout 56%
Show answer and explanation

Answer: C. About 56%

A linear regulator passes the same current at input and output and maintains the output voltage by dissipating the voltage difference as heat in a transistor. Efficiency is therefore roughly output voltage ÷ input voltage: 1.0 ÷ 1.8 ≈ 56%, with the remaining 44% turned into heat. It suits small input-output differences or noise-sensitive loads; for large differences, a switching regulator usually steps the voltage down first.
