What is NPU (neural processing unit)?

A dedicated circuit for running neural-network inference quickly and at low power. It is built into the SoCs of smartphones and PCs.

Japanese name: NPU(ニューラルプロセッシングユニット)

  1. APLL (phase-locked loop)
  2. BADC
  3. CNPU (neural processing unit)
Show answer and explanation

Answer: C. NPU (neural processing unit)

An NPU is a dedicated circuit that executes, in massive parallel, the multiply-accumulate operations dominating neural networks, often at low precision such as 8-bit integers or less. Its performance per watt exceeds a general-purpose CPU's by an order of magnitude or more, letting phones handle photo enhancement, speech recognition and translation on-device. Performance is quoted in TOPS (trillions of operations per second), and NPUs are spreading into PC SoCs.

Show answer and explanation

Answer: C. Analyze the model's computational graph, optimize fusion, data layout and tiling, and generate code for the target hardware

An AI compiler takes the model as a computational graph of operations and data flows, fuses operations where possible, removes unnecessary computation, chooses memory layouts and tunes tile sizes, then generates kernels suited to the target, such as a GPU or NPU. It automatically produces optimized code for each hardware target from the same model, greatly reducing manual optimization work.
