What is bfloat16?

A 16-bit floating-point format with 1 sign, 8 exponent and 7 significand bits. Sharing FP32's exponent width gives it a wide range, so despite low precision it is used for AI training. FP16, with 5 exponent and 10 significand bits, is more precise but has a narrow range.

What is the main reason bfloat16 is used for AI training?

  1. AIts exponent is 8 bits like FP32, so its range is wide
  2. BIts significand is longer than FP32's, so it is more precise
  3. CIt can be computed with integer arithmetic
Show answer and explanation

Answer: A. Its exponent is 8 bits like FP32, so its range is wide

bfloat16 is a 16-bit format with 1 sign, 8 exponent and 7 significand bits. Sharing FP32's exponent width gives nearly the same range, so very small or large values such as gradients during training rarely overflow or underflow, and converting FP32 models is easy. Precision is low, but training tolerates some error, and data size and arithmetic area are halved. Its significand is shorter than FP32's, and it is computed with floating-point, not integer, arithmetic.

In mixed-precision AI training, why are master weights kept in FP32 while most computation is done in FP16 or bfloat16?

  1. AWhen small updates are added to weights, a low-precision format would lose them to absorption
  2. BFP32 computes faster than FP16, so all weight calculations are left to FP32
  3. CFP16 and bfloat16 values are not allowed to be stored in memory
Show answer and explanation

Answer: A. When small updates are added to weights, a low-precision format would lose them to absorption

Training repeatedly adds very small amounts, learning rate × gradient, to the weights. FP16 and bfloat16 have short significands, so if an update is too small relative to the weight, the rounded sum equals the old weight and the update vanishes (absorption). Weights are therefore kept in FP32 so updates accumulate correctly, while lower-precision copies are used for the forward and backward passes. Lower precision computes faster, and low-precision values can certainly be stored.
