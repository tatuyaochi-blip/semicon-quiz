What is Secure boot?

A mechanism that verifies the digital signature of the next software at each boot stage and starts only authentic software, forming a chain of trust.

Field: Hardware Security

Secure boot in the explanations

  • In secure boot, immutable ROM code verifies the first bootloader's signature, that bootloader verifies the next stage or the OS kernel, and so on, forming a chain of trust.

  • Left active in a product, an attacker can connect equipment to the board's pins and read out firmware, bypass secure boot or extract keys.
