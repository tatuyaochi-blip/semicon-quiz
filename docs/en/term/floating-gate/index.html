What is Floating gate?

An electrode in a flash memory cell that is completely surrounded by insulator. Storing electrons on it shifts the transistor's threshold voltage, so data is kept even without power.

Japanese name: フローティングゲート

Try it: questions about Floating gate

In flash memory erase, what happens to a cell's threshold voltage when electrons are removed from the floating gate or similar layer?

  1. AIt rises
  2. BIt falls
  3. CIt does not change
Show answer and explanation

Answer: B. It falls

Electrons (negative charge) on the floating gate cancel part of the gate voltage, so more voltage is needed to form a channel and the threshold rises. Erasing removes electrons and lowers the threshold; programming adds them and raises it. NAND conventionally treats the erased (low-threshold) state as "1" and the programmed state as "0," which is why erased flash reads as 0xFF.
