What is Temporal locality?

The tendency to access the same data or instructions again soon after a first access, as with variables reused inside a loop. One of the reasons caches work.

Japanese name: 時間的局所性

Which is the best example of temporal locality?

  1. AReading each element of an array once, from start to end
  2. BUpdating the same sum variable many times inside a loop
  3. CReading data at a random address only once each time
Show answer and explanation

Answer: B. Updating the same sum variable many times inside a loop

Temporal locality is the tendency to reuse data soon after using it, and a variable read and written repeatedly inside a loop is the classic example. Such data is reused while still in the cache or registers, so accesses are fast. Reading an array from start to end is an example of spatial locality, using nearby addresses in succession, which is a different property. Reading random addresses once each has almost no locality of either kind.
