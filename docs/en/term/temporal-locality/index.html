What is Temporal locality?

The tendency to access the same data or instructions again soon after a first access, as with variables reused inside a loop. One of the reasons caches work.

Field: Memory Hierarchy

Temporal locality in the explanations

  • Temporal locality is the tendency to reuse data soon after using it, and a variable read and written repeatedly inside a loop is the classic example.

    Which is the best example of temporal locality?

  • Caches exploit temporal locality (reusing the same data soon) and spatial locality (using nearby addresses next), with L1 reachable in a few cycles and even L3 in tens of cycles.
