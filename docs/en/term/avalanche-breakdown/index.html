What is Avalanche breakdown?

A phenomenon in which carriers accelerated by a strong reverse field strike atoms and create new carriers, which multiply in a chain reaction so that a large current flows.

Field: PN junctions and diodes

Avalanche breakdown in the explanations

  • In avalanche breakdown, carriers accelerated by the strong depletion-region field strike atoms and create electron-hole pairs (impact ionization); these are accelerated in turn, and the current multiplies like an avalanche.
