What is Cycles per instruction (CPI)?

The average number of clock cycles per instruction, one factor in execution time = instruction count × CPI × cycle time, and the reciprocal of IPC.

Japanese name: CPI

Try it: questions about Cycles per instruction (CPI)

Approximately how many instructions per second can a processor with a 2 GHz clock and an average CPI (clocks per instruction) of 0.5 execute?

  1. A1 billion instructions
  2. B4 billion instructions
  3. C100 million instructions
Show answer and explanation

Answer: B. 4 billion instructions

There are 2×10⁹ clocks per second and each instruction averages 0.5 clocks, so 2×10⁹ ÷ 0.5 = 4×10⁹—4 billion instructions. CPI below 1 reflects superscalar execution of multiple instructions per clock. Performance is execution time = instruction count × CPI ÷ frequency, so no single one of the three factors suffices for comparison.

A processor has an average CPI of 1.0 with a perfect cache. Each instruction makes 1.3 memory accesses on average, with a 2% miss rate and a 100-cycle miss penalty. What is the actual average CPI?

  1. A3.0
  2. B3.6
  3. C1.3
Show answer and explanation

Answer: B. 3.6

Memory stall cycles per instruction are 1.3 accesses × 0.02 × 100 cycles = 2.6 cycles. Adding them to the ideal CPI gives 1.0 + 2.6 = 3.6, so performance falls to 1/3.6 of ideal. 3.0 wrongly assumes one access per instruction (1.0 + 1 × 0.02 × 100). 1.3 is the number of accesses per instruction, not the CPI. Even a small miss rate badly hurts performance when the miss penalty is large.
