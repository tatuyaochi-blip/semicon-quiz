What is Nanosheet?

A GAA transistor structure that stacks several thin, plate-like silicon channels vertically, each surrounded by the gate. Current can be tuned by the sheet width.

Japanese name: ナノシート

Compared with FinFETs, what is a design advantage of nanosheet GAA transistors?

  1. AChannel width can only be changed by the number of fins
  2. BDrive current can be adjusted more flexibly by changing the nanosheet width
  3. CGate length does not affect transistor characteristics
Show answer and explanation

Answer: B. Drive current can be adjusted more flexibly by changing the nanosheet width

A FinFET's channel width can change only by fin count, but in nanosheet GAA the stacked sheets' width (e.g., 15–50 nm) can be varied continuously in layout. Wide sheets suit high-performance cells and narrow ones suit low-power logic and SRAM, giving flexible control of drive current and capacitance. The all-around gate also resists short-channel effects, delivering more current than a FinFET in the same footprint.

In manufacturing nanosheet GAA transistors, why is only the SiGe selectively removed from stacked alternating Si and SiGe layers?

  1. ATo make the transistor lighter
  2. BSo that the gate insulator and gate electrode can be filled into the gaps, surrounding each Si nanosheet with the gate
  3. CBecause SiGe does not conduct electricity
Show answer and explanation

Answer: B. So that the gate insulator and gate electrode can be filled into the gaps, surrounding each Si nanosheet with the gate

Nanosheet GAA starts from an epitaxial stack of alternating Si and SiGe (about 25–30% Ge). After the dummy gate is removed, SiGe is etched away with high selectivity, leaving the Si sheets suspended. Filling the gaps with high-k and metal gate by ALD wraps each sheet on all sides. Selective etching that removes only SiGe without damaging the sheets is the manufacturing key.
