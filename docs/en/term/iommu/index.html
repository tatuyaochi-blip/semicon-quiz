What is IOMMU?

A unit that translates and protects the addresses peripherals use for DMA. It keeps devices from writing to unauthorized memory and is also used when assigning devices to virtual machines.

Japanese name: IOMMU

Answer: C. Translating device DMA addresses and blocking illegal access

Devices using DMA can read and write main memory directly, so a malfunctioning or malicious device could overwrite OS memory. Like an MMU for the CPU, an IOMMU translates device addresses into physical addresses and blocks access outside permitted ranges. It can also present scattered physical memory as contiguous to a device and is used when assigning devices directly to virtual machines. It neither translates instructions nor controls power.
