What is Barrier synchronization?

Synchronization in which threads that arrive first wait until all threads reach the same point, keeping them in step phase by phase. Distinct from a memory barrier.

Japanese name: バリア同期

Which describes barrier synchronization in parallel programs?

  1. AIt creates a region that only one thread can enter at a time
  2. BThreads that arrive first wait at that point until all threads have arrived
  3. CAn instruction that stops memory operations from being reordered
Show answer and explanation

Answer: B. Threads that arrive first wait at that point until all threads have arrived

In simulations and similar work, all threads must finish one step's computation before moving to the next. With barrier synchronization, each thread stops at the barrier, and when the last thread arrives they all proceed. If the workload is uneven, fast threads spend more time waiting for slow ones, so dividing work evenly matters for performance.
