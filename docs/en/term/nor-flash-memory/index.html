What is NOR flash memory?

Flash memory with cells connected in parallel. Random reads are fast, and it is used to store programs for microcontrollers and the like.

Japanese name: NOR型フラッシュメモリ

Answer: C. Storing program code for devices (such as boot programs)

NOR flash connects each cell in parallel to the bit line for fast random access, so a CPU can fetch and run code directly from it (execute in place, XIP). It is used for boot code, microcontroller firmware and automotive control software. Capacities are small (a few Mbit to a few Gbit) and cost per bit is higher than NAND, so bulk data storage uses NAND.
