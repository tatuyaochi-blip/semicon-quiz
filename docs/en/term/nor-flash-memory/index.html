What is NOR flash memory?

Flash memory with cells connected in parallel. Random reads are fast, and it is used to store programs for microcontrollers and the like.

Japanese name: NOR型フラッシュメモリ

Field: SRAM and flash memory

Cells connected in parallel

In NOR flash memory, each cell transistor has its drain connected to a bit line and its source to a common source line, so the cells sit in parallel along the bit line. The name comes from the resemblance to a NOR gate: if any one cell turns on, it pulls the bit line down. Each cell needs its own bit-line contact, so a NOR cell is larger than a NAND cell, but every cell can be read directly without going through other cells. As in NAND, the cell is a transistor with a charge-storage layer under the control gate, and the threshold voltage set by the stored electrons is read as 0 or 1.

Programming and erasing

Programming commonly uses channel hot-electron (CHE) injection: a voltage on the drain accelerates electrons along the channel, and some of them are injected into the storage layer. This is fast but draws a large current per cell, so only a limited number of bits can be programmed at once. Erasing usually removes electrons by Fowler-Nordheim (FN) tunneling and is done in units called sectors or blocks. Erased bits read as 1, and programming can only change 1s to 0s, so rewriting data requires an erase first. Erasing takes much longer than reading or programming.

XIP and main applications

NOR flash can read any address quickly, byte by byte or word by word, so the CPU can fetch and execute instructions directly from the flash, known as execute in place (XIP). Because a system can boot without first copying its program to RAM, NOR flash stores microcontroller firmware, BIOS/UEFI for PCs and servers, FPGA configuration data, and boot code for automotive and communications equipment. Capacities are small, from a few Mbit to a few Gbit, and the cost per bit is higher than NAND, so bulk data goes in NAND flash. NOR also often needs less aggressive error correction and bad-block management than NAND, another reason it suits code storage.

Parallel NOR and serial NOR

NOR flash comes as parallel NOR, with rows of address and data pins, and serial NOR, connected over SPI. Parallel NOR returns data directly once an address is applied, much like SRAM, and was long the standard place to store programs in embedded systems. Because it needs many pins, serial NOR, which uses only a few signal lines, is now the mainstream choice. Serial NOR speeds up reads with Quad SPI or Octal SPI, which widen the data path to four or eight lines, and with a microcontroller's memory-mapped mode it also supports XIP. Parallel NOR remains in use in automotive and industrial equipment that demands high reliability and long-term supply.

FAQ

What is the difference between NOR and NAND flash?

NOR flash connects each cell to the bit line in parallel, so any address can be read quickly, making it suitable for executing programs directly (XIP). NAND flash strings cells in series to cut the number of contacts, so its cells are small, dense and cheap, but it reads and writes in pages. NOR is used for boot code and firmware, NAND for bulk storage such as SSDs and memory cards.

Why is it called NOR flash?

Because the cells are connected in parallel to the bit line, and any one cell turning on pulls the bit line down, which resembles the transistor arrangement of a NOR gate. Likewise, NAND flash, whose cells are connected in series, is named for its resemblance to a NAND gate.

What is NOR flash used for?

It stores code that must be read quickly and reliably even though the capacity is small: firmware for microcontrollers and embedded devices, BIOS/UEFI in PCs, FPGA configuration data and boot code in automotive equipment. A key advantage is XIP, in which the CPU executes instructions directly from the flash.
