What is Credit-based flow control?

A scheme in which the receiver advertises free buffer space as credits and the sender transmits only within them, so buffers never overflow.

Japanese name: クレジット方式のフロー制御

Which describes the credit-based flow control used in PCI Express?

  1. AThe receiver advertises its free buffer space as credits, and the sender transmits packets only within those credits
  2. BThe sender transmits regardless of the receiver, and overflowing packets are discarded
  3. CUsers are billed according to the amount of data sent
Show answer and explanation

Answer: A. The receiver advertises its free buffer space as credits, and the sender transmits packets only within those credits

Sending a packet into a full receive buffer would waste effort in discarding and resending it. With credits, the receiver tells the sender how much more it can accept, the sender transmits only within that amount, and the receiver returns credits as it processes packets and frees buffer space. Overflow never occurs, so there is no discarding and resending.
