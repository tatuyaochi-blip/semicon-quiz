What is Gradient checkpointing?

Storing only some intermediate forward results and recomputing the rest during backpropagation, trading extra computation for less memory.

Field: AI Hardware & Software Stack

Gradient checkpointing in the explanations

  • Gradient checkpointing stores results only every few layers, and when backpropagation reaches a segment it reruns the forward pass from the saved point to regenerate the needed values.
