What is Gradient checkpointing?

Storing only some intermediate forward results and recomputing the rest during backpropagation, trading extra computation for less memory.

Japanese name: 勾配チェックポイント

Which describes gradient checkpointing (activation recomputation) used in training?

  1. AStore only some intermediate forward results and recompute the rest when needed during backpropagation, trading extra computation for less memory
  2. BSaving model weights to disk partway through training
  3. CTraining without computing gradients
Show answer and explanation

Answer: A. Store only some intermediate forward results and recompute the rest when needed during backpropagation, trading extra computation for less memory

Backpropagation needs each layer's intermediate forward results, but storing them all makes memory grow with layer count and batch size. Gradient checkpointing stores results only every few layers, and when backpropagation reaches a segment it reruns the forward pass from the saved point to regenerate the needed values. At the cost of roughly one extra forward pass, activation memory is greatly reduced.
