What is Refresh?

The periodic reading and rewriting of DRAM data before the charge in its capacitors is lost through leakage.

Field: DRAM

Refresh in the explanations

  • Refresh reads and rewrites each cell before its data becomes unreadable; standards typically require every row to be refreshed within 64 ms.

    Why does DRAM need periodic refresh operations?

  • As capacity grows, more cells must be refreshed in the same 64 ms, lengthening each refresh operation (tRFC).

  • To avoid losing data, refresh must occur more often, and many standards halve the refresh interval in the high-temperature range.
