What is SOT-MRAM?

MRAM that flips magnetization by spin-orbit torque from a current in a heavy-metal layer. The write and read current paths are separate, giving fast, durable writes.

Japanese name: SOT-MRAM

  1. AIt is written by irradiating it with light
  2. BIt stores data as charge in a capacitor
  3. CIt reverses magnetization with spin-orbit torque from current in a heavy-metal layer, allowing separate current paths for writing and reading
Show answer and explanation

Answer: C. It reverses magnetization with spin-orbit torque from current in a heavy-metal layer, allowing separate current paths for writing and reading

SOT-MRAM flips the free layer using spin-orbit torque generated by the spin Hall effect when current flows through a heavy-metal layer, such as tungsten or platinum, beneath the MTJ. Write current bypasses the tunnel barrier, avoiding its wear and separating read and write paths, and sub-nanosecond writes are possible. The three-terminal cell is larger, so it targets cache applications close to SRAM.
