What is Deadlock?

A state in which threads each hold a resource while waiting for one held by another, so none can proceed. Fixing a global lock order prevents it.

Japanese name: デッドロック

Try it: questions about Deadlock

Which is an example of deadlock?

  1. AThread 1 holds lock A and waits for lock B, while thread 2 holds lock B and waits for lock A
  2. BTwo threads update the same variable without synchronization and corrupt it
  3. COne thread acquires a lock and releases it immediately
Show answer and explanation

Answer: A. Thread 1 holds lock A and waits for lock B, while thread 2 holds lock B and waits for lock A

Deadlock is a state in which threads each hold a resource while waiting for one held by another, so none can proceed. In the example, thread 1 waits for B to be released and thread 2 waits for A, but neither gives up its own lock, so both stop forever. With locks that sleep while waiting, they stop without using the CPU, so the program simply appears frozen.

In a program using several locks, what is the most common way to prevent deadlock?

  1. AFix a single global order in which every thread acquires locks
  2. BNever release a lock once acquired
  3. CLimit the program to two threads or fewer
Show answer and explanation

Answer: A. Fix a single global order in which every thread acquires locks

Deadlock arises when threads form a cycle, each waiting for a lock held by another. If everyone follows "always take A before B", no thread can hold B while waiting for A, so no cycle forms. Other methods include acquiring all needed locks at once, or releasing held locks and retrying when a lock cannot be obtained.
