What is LVS?

Short for layout versus schematic: checking that the connectivity extracted from the layout matches the schematic or netlist. It is always run before tape-out, along with DRC.

Japanese name: LVS

Which correctly describes DRC (design rule check) in layout verification?

  1. AVerifying that the connectivity of the schematic and the layout match
  2. BVerifying that the layout satisfies manufacturing rules such as minimum width and spacing
  3. CVerifying the logic function of the RTL by simulation
Show answer and explanation

Answer: B. Verifying that the layout satisfies manufacturing rules such as minimum width and spacing

DRC checks whether layout shapes violate design rules derived from manufacturing, such as minimum width, spacing, overlap and density. Advanced processes have thousands of rules, verified automatically by tools. Checking that layout connectivity matches the schematic is LVS (layout versus schematic), and checking logic function is simulation. DRC and LVS are always run before mask data is released.

What is the set of design data, including design rules, device models and cell libraries, that a foundry provides to designers called?

  1. APDK (process design kit)
  2. BIP core
  3. CHDL
Show answer and explanation

Answer: A. PDK (process design kit)

A PDK contains a process's design rules, SPICE models for transistors and other devices, rule decks for DRC and LVS, parasitic extraction data, and layouts of basic devices. Using it, designers create circuits that the foundry can manufacture. Standard-cell libraries are sometimes supplied separately. An IP core is a circuit block and an HDL is a description language.
