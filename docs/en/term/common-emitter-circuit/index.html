What is Common-emitter circuit?

An amplifier circuit in which the emitter is the common terminal for input and output. It provides both current gain and voltage gain and is the most widely used configuration.

Japanese name: エミッタ接地回路

How does the phase of the output voltage of a common-emitter amplifier compare with the input voltage?

  1. AIn phase
  2. BInverted by 180°
  3. CLeading by 90°
Show answer and explanation

Answer: B. Inverted by 180°

In a common-emitter amplifier, raising the input (base) voltage increases collector current and the voltage drop across the collector resistor, so the output (collector) voltage falls. The output is therefore inverted by 180°, and the voltage gain is written with a negative sign, −gm·RC. It offers both high voltage and current gain among the three configurations and is the most widely used. Common-collector and common-base stages are non-inverting.

Which condition increases the small-signal input resistance (hie) of a common-emitter amplifier?

  1. AReducing the collector current, or using a transistor with a higher current gain
  2. BIncreasing the collector current
  3. CLowering the temperature
Show answer and explanation

Answer: A. Reducing the collector current, or using a transistor with a higher current gain

The common-emitter input resistance is hie ≈ hFE × VT/IC = hFE/gm, so it increases with lower collector current or higher hFE—about 2.6 kΩ for hFE = 100 and IC = 1 mA. Reducing current also lowers gm and gain, so the operating point balances input resistance against gain. For even higher input resistance, use an emitter follower, a Darlington, or emitter-resistor feedback.
