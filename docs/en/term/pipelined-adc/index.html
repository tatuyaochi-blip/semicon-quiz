What is Pipelined ADC?

An ADC that splits conversion into stages, each resolving a few bits and passing the residue to the next, like an assembly line. It combines high speed with medium to high resolution.

Japanese name: パイプライン型ADC

Answer: C. Pipeline

A pipelined ADC resolves a few bits per stage and amplifies the remaining error (residue) for the next stage. Each stage works on a different sample in parallel, combining tens to hundreds of MS/s with 10–16 bits of resolution. Stages carry a little extra resolution so that comparator errors can be digitally corrected. The trade-off is several clock cycles of latency; uses include communications, video and ultrasound imaging.
