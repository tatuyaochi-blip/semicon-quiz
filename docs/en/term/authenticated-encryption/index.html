What is Authenticated encryption (AEAD)?

A form of encryption that provides confidentiality and tamper detection in a single operation. AEAD stands for authenticated encryption with associated data: associated data such as headers, which are not encrypted but must be protected against tampering, can also be included in the authentication. A tag is computed during encryption and verified during decryption; if it does not match, an error is returned and no plaintext is released. AES-GCM and ChaCha20-Poly1305 are typical examples, and TLS 1.3 uses only AEAD. Reusing a nonce with the same key undermines both confidentiality and tamper detection.

Japanese name: 認証付き暗号(AEAD)

Which of the following does authenticated encryption (AEAD) such as AES-GCM provide in a single operation?

  1. AOnly the confidentiality of the data; detecting tampering requires a separate digital signature
  2. BThe confidentiality of the data and verification that the ciphertext and associated data have not been tampered with
  3. CNon-repudiation towards third parties, in addition to confidentiality and tamper detection
Show answer and explanation

Answer: B. The confidentiality of the data and verification that the ciphertext and associated data have not been tampered with

Authenticated encryption (AEAD: authenticated encryption with associated data) computes an authentication tag while encrypting and verifies the tag when decrypting; if the ciphertext has been tampered with, it returns an error without releasing any plaintext. Headers and other data that are not encrypted but must be protected against tampering can also be included in the tag computation as "associated data". GCM is a mode that combines encryption in CTR mode with authentication by GHASH, which uses multiplication in a Galois field, and TLS 1.3 uses only AEAD. Because the tag is made with a shared key, like a message authentication code it cannot provide non-repudiation.

Which of the following correctly describes the 96-bit nonce (IV) used in AES-GCM?

  1. AIt need not be secret and may be generated by a counter, but the same value must never be used twice with the same key
  2. BIf an attacker learns it, the plaintext leaks, so it must be kept secret and stored securely just like the key
  3. CIt must be chosen at random every time, and generating it with a counter incremented by 1 destroys security
Show answer and explanation

Answer: A. It need not be secret and may be generated by a counter, but the same value must never be used twice with the same key

What is required of a GCM nonce is that its values never repeat (are unique) under the same key. It need not be secret, and a counter that counts transmissions satisfies the requirement. Using the same nonce twice with the same key leaks the XOR of the plaintexts, as in CTR mode, and also allows the value used for authentication to be recovered, so tags may be forged. When nonces are chosen at random, a limit is placed on the number of encryptions under one key to avoid accidental repeats (2^32 in NIST SP 800-38D).
