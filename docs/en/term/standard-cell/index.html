What is Standard cell?

A pre-designed, pre-verified building block such as a logic gate or flip-flop. Cells share a common height so automatic place-and-route can line them up to build large circuits.

Japanese name: スタンダードセル

Field: IC design flow and EDA

Anatomy of a cell

A standard cell implements a small function, such as a NAND gate, multiplexer or flip-flop, as a fixed transistor layout. All cells in a library share the same height, while widths vary in multiples of a placement grid tied to the gate pitch. Power and ground rails run along the top and bottom edges, and alternate rows are flipped so neighboring rows share rails. Cells snap side by side into rows like bricks, with input and output pins on the lower metal layers for the router to reach. Each function usually comes in several drive strengths and threshold-voltage flavors to trade speed against leakage.

Track height and density

Cell height is quoted in tracks, the number of minimum-pitch routing wires that fit across it. Six tracks at a 28 nm metal pitch is about 170 nm. Fewer tracks give shorter cells and denser logic, and advanced nodes have moved from around 7.5 tracks toward 6 and 5. The cost is less room for internal wiring and pin access, which raises routing congestion, and fewer fins or nanosheets per transistor, which reduces drive strength. Low-track libraries therefore depend on features such as buried or backside power rails and careful pin design.

Library views and characterization

A library is delivered as several views of each cell: the transistor netlist and layout (GDS), an abstract physical view (LEF) giving size and pin shapes for place-and-route, functional models for simulation, and timing and power tables, typically in Liberty format. Library characterization fills those tables by circuit-simulating each cell across combinations of input transition time and output load, repeated at every process, voltage and temperature (PVT) corner. Synthesis and static timing analysis (STA) then look up and interpolate the tables to time millions of cells quickly.

Standard cells vs. full custom

In a standard-cell flow, synthesis maps register-transfer-level (RTL) code onto library cells, and automatic tools place them in rows, build the clock tree and route the wires. This semi-custom approach scales to billions of transistors with modest design effort. Full-custom design, where engineers draw each transistor, is reserved for structures where density or analog behavior justify the effort, such as SRAM bit cells, analog blocks and some high-performance datapaths. Libraries also include utility cells: fillers, well taps, decoupling capacitors and tie-high or tie-low cells.

FAQ

What does 6T or 7.5T mean for a standard cell library?

It is the cell height expressed in routing tracks, the number of minimum-pitch metal lines that fit over the cell. Fewer tracks mean a shorter cell and higher logic density but less routing room and lower drive strength.

What is a Liberty (.lib) file?

It is the library view containing each cell's timing, power and functional data, tabulated against input transition and output load at a given PVT corner, and used by synthesis and static timing analysis.

Why do all standard cells have the same height?

A common height lets cells abut in uniform rows that share power and ground rails and well regions, which makes automatic placement and routing possible.
