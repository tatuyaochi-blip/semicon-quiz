What is Array?

A data structure that stores values of the same type in sequence and identifies each element by an index. Because the elements are stored contiguously in memory, the position of any element can be computed from its index, so any element can be read or written in constant time. Some languages start indices at 0, while some notations start them at 1.

Japanese name: 配列

In a direct-mapped cache, elements of two arrays map to the same cache location and evict each other on every alternating access. How is this miss classified?

  1. ACompulsory miss
  2. BCapacity miss
  3. CConflict miss
Show answer and explanation

Answer: C. Conflict miss

Misses where two pieces of data fight over the same set and evict each other, even though the cache as a whole has room, are conflict misses. Raising associativity so a set can hold both, or offsetting one array so it maps to different sets, reduces them. Capacity misses arise because the working set exceeds the whole cache and persist even with full associativity. Compulsory misses happen on first access and do not describe repeated accesses.

When each row of a 2D array is 4,096 bytes (a power of two), walking down a column can cause many misses even though the cache has spare capacity. Which countermeasure is effective?

  1. APadding each row so its size is not a power of two
  2. BChanging the element type to a different type of the same size
  3. CRelocating the whole array so it starts on a large power-of-two address boundary
Show answer and explanation

Answer: A. Padding each row so its size is not a power of two

With rows exactly 4096 bytes long, elements down a column are spaced by multiples of 4096, so the index bits within the low 12 address bits are identical and the elements crowd into a few sets (all into the same set in an L1 cache with 4 KB or less per way). When more rows than the associativity map to one set, conflict misses occur even with capacity to spare. Padding each row by about one line shifts the set for each element and spreads them out. Aligning to a power of two leaves the problem intact, and a same-sized type changes nothing.
