What is Characteristic impedance?

The ratio of voltage to current seen by a wave traveling along a transmission line, set by trace width and layer spacing. Changes along the path cause reflections.

Japanese name: 特性インピーダンス

  1. ATo reduce trace resistance to zero and eliminate loss
  2. BTo make traces glow so they can be checked visually
  3. CTo prevent reflections at impedance discontinuities from distorting the waveform
Show answer and explanation

Answer: C. To prevent reflections at impedance discontinuities from distorting the waveform

At high speed, a trace behaves as a transmission line along which electrical waves travel. Wherever the characteristic impedance changes, at connectors, vias or mismatched terminations, part of the signal reflects back and overlaps later bits, distorting the waveform. Designers therefore tune trace width and layer spacing so that, for example, differential traces are 100 Ω, and terminate them with the same value.
