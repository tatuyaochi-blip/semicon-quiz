What is Characteristic impedance?

The ratio of voltage to current seen by a wave traveling along a transmission line, set by trace width and layer spacing. Changes along the path cause reflections.

Field: I/O Interfaces & Buses

Characteristic impedance in the explanations

  • Wherever the characteristic impedance changes, at connectors, vias or mismatched terminations, part of the signal reflects back and overlaps later bits, distorting the waveform.
