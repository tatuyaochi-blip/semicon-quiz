What is Sensitivity list?

The list in @( ) after a Verilog always that names the signals triggering the block. Omissions in combinational logic make simulation and hardware disagree.

Japanese name: センシティビティリスト

What does writing "always @(*)" mean in Verilog?

  1. AIt describes a flip-flop that runs on every rising clock edge
  2. BIt runs only once at the start of simulation
  3. CIt runs whenever any signal read inside the block changes, describing combinational logic
Show answer and explanation

Answer: C. It runs whenever any signal read inside the block changes, describing combinational logic

The list inside @( ) after always is called the sensitivity list and specifies which signal changes trigger the block. Writing "*" automatically includes every signal read in the block, correctly describing combinational logic. Listing signals by hand invites omissions, so "@(*)" or SystemVerilog's always_comb is the safe choice for combinational logic.
