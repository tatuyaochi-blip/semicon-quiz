What is High-level synthesis (HLS)?

Automatically generating RTL from an algorithm written in C, C++ or similar. It is used in developing FPGAs and accelerators.

Japanese name: 高位合成(HLS)

Answer: A. High-level synthesis (HLS)

High-level synthesis automatically allocates functional units and registers and schedules which clock cycle each operation occurs in, generating RTL from behavioral descriptions in C/C++ and similar languages. Different pipelining and parallelism options can be explored from the same source, raising abstraction and shortening development. It is used for signal-processing and AI accelerator design. Logic synthesis turns RTL into gates.
