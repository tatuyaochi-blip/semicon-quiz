What is Operational amplifier (op-amp)?

An amplifier with differential inputs and very high gain. Used with negative feedback in amplifiers, filters and more.

Japanese name: オペアンプ

Try it: questions about Operational amplifier (op-amp)

Which combination correctly describes an ideal op-amp?

  1. AInput impedance: infinite; output impedance: 0
  2. BInput impedance: 0; output impedance: infinite
  3. CInput impedance: 0; output impedance: 0
Show answer and explanation

Answer: A. Input impedance: infinite; output impedance: 0

An ideal op-amp is assumed to have infinite input impedance (no current into the inputs), zero output impedance (output voltage independent of load) and infinite open-loop gain. From these assumptions, a negative-feedback circuit keeps both inputs at the same voltage—the "virtual short"—so circuit gain depends only on resistor ratios. Real op-amps have open-loop gains of about 10⁵–10⁶, which fall with frequency.

In an inverting amplifier using an ideal op-amp, with input resistor Ri = 10 kΩ and feedback resistor Rf = 100 kΩ, what is the voltage gain?

  1. A+11
  2. B−0.1
  3. C−10
Show answer and explanation

Answer: C. −10

An inverting amplifier's gain is −Rf/Ri, here −100 kΩ/10 kΩ = −10. Because the inverting input is a virtual ground, the input current Vin/Ri flows entirely through Rf, giving an output of −Rf × Vin/Ri. The input impedance equals Ri (10 kΩ), which loads the signal source. +11 is the gain of a non-inverting amplifier with the same resistors (1 + Rf/Ri).
