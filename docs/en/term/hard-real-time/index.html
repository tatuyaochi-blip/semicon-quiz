What is Hard real-time?

A strict timing requirement in which missing a deadline even once is a system failure, as in automotive brake or airbag control. Where occasional lateness is acceptable, it is soft real-time.

Japanese name: ハードリアルタイム

Show answer and explanation

Answer: C. In hard real-time, missing a deadline even once is a system failure; in soft real-time, occasional lateness only degrades quality

Hard real-time examples include automotive airbag, engine and brake control, where missing a deadline can cause a serious accident. Meeting deadlines even in the worst case must be verified at design time. Soft real-time examples include video and audio playback, where occasional lateness only causes minor glitches. Which category applies greatly changes how rigorous the verification must be.
