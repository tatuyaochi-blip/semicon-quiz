What is Register spilling?

Saving some values to memory (the stack) during register allocation when more values are live than there are registers. The extra stores and reloads slow the code.

Japanese name: スピル

What can happen if a GPU kernel uses too many registers per thread?

  1. ARegisters grow automatically and performance always improves
  2. BResults are always wrong
  3. CEach SM has a fixed register file, so fewer threads fit at once and memory latency becomes harder to hide
Show answer and explanation

Answer: C. Each SM has a fixed register file, so fewer threads fit at once and memory latency becomes harder to hide

GPUs keep the registers of every active thread on chip so that switching warps is instantaneous. So if each thread uses many registers, fewer threads fit on an SM at once. Registers that do not fit are spilled to memory, which can also slow things down. Compiler options can cap register usage to balance it against thread count.

Which statement about GPU occupancy is correct?

  1. A100% occupancy always gives peak performance
  2. BEven with low occupancy, high performance is possible if each thread has many independent computations, raising instruction-level parallelism
  3. COccupancy has no relation to performance
Show answer and explanation

Answer: B. Even with low occupancy, high performance is possible if each thread has many independent computations, raising instruction-level parallelism

Occupancy is one means of hiding latency, not the goal. If each thread can issue several independent computations or memory loads, fewer warps suffice to fill the waiting time. Conversely, cutting registers to raise occupancy can increase spills to memory and slow things down. Measuring with a profiler is the reliable way to judge performance.
