What is Cache line?

The unit in which data moves between a cache and the level below, also called a cache block. Many CPUs use 64 bytes, and the low address bits give the position (offset) within the line.

Japanese name: キャッシュライン

Field: Memory Hierarchy

Why caches move whole lines

Programs that touch one address usually touch its neighbors soon after, a property called spatial locality. Caches exploit it by moving data in fixed blocks, typically 64 bytes, rather than single words, and the size conveniently matches one DRAM burst: eight transfers of 8 bytes on a 64-bit DDR4 channel. Each cached line carries a tag identifying its address, a valid bit marking real data, a dirty bit in write-back caches and replacement and coherence state. An address therefore splits into tag, index and offset fields; with 64-byte lines, the lowest 6 bits are the offset.

Line size and access patterns

Line size turns access patterns into miss rates. Reading an array of 4-byte integers in order misses once per 16 elements, a 6.25% miss rate, because each miss brings in the next 15 elements. Reading only every 16th element misses every time. C stores two-dimensional arrays in row-major order, so looping over the column index in the inner loop walks consecutive addresses, while swapping the loops jumps a full row per access and may evict lines before they are reused. Larger lines help sequential code but waste bandwidth and capacity when little of each line is used.

Coherence works per line

In a multicore processor, coherence protocols track ownership at line granularity. Under MESI, each line is Modified (changed and held only here, so memory is stale), Exclusive (clean and held only here), Shared (clean copies may exist elsewhere) or Invalid. A core that wants to write must first invalidate copies in other caches; a line already in M can be written repeatedly without notifying anyone. Small systems broadcast these requests, while large ones use directories that record which caches hold each line, so traffic scales with the number of cores.

False sharing

Because coherence is per line, two threads writing different variables that happen to share a 64-byte line still invalidate each other's copies on every write. The line bounces between cores, results stay correct, but performance can drop sharply. Arrays of per-thread counters or flags are the classic case. The fix is to pad or align each thread's data to its own line, for example with alignment attributes in C and C++. Contrast this with true sharing, where threads really do access the same variable and communication cannot be avoided by layout.

  1. A1 byte
  2. B64 bytes
  3. C64 MB
Show answer and explanation

Answer: B. 64 bytes

Most CPUs transfer data between cache and main memory in 64-byte lines. Neighboring addresses are often used together (spatial locality), so fetching them as a block is efficient, and it matches DRAM bursts (8 transfers × 8 bytes = 64 bytes in DDR4). In multithreaded code, beware of false sharing, where separate variables in the same line cause cores to contend for it.

What is the role of the valid bit attached to each cache line?

  1. AIt shows whether the line has been modified
  2. BIt shows the order in which the line will be evicted
  3. CIt shows if real data is present
Show answer and explanation

Answer: C. It shows if real data is present

Right after power-up or after a line is invalidated, cache contents are meaningless. A line whose valid bit is 0 is not counted as a hit even if its tag happens to match; the bit is set to 1 when correct data is loaded. This prevents empty lines from being mistaken for hits. Modification is shown by the dirty bit used in write-back caches, and eviction order is tracked by replacement information such as LRU state.

FAQ

How big is a cache line?

64 bytes on most current CPUs, though some processors use 32 or 128 bytes; the size is a hardware property that software can query.

What is the difference between a cache line and a page?

A cache line, usually 64 bytes, is the unit moved between cache levels and memory, while a page, often 4 KB, is the unit of virtual-memory mapping managed by the OS and MMU.

How do I avoid false sharing?

Place data written by different threads in separate cache lines, typically by padding or aligning per-thread structures to 64 bytes.
