What is Lint tool?

A tool that checks HDL or other code against rules without simulation, flagging problem-prone constructs such as width mismatches and unintended latches.

Field: HDL & Verification

Lint tool in the explanations

  • A lint tool statically checks HDL code against rules and flags constructs that are legal but prone to problems, such as assignments between different widths, incomplete sensitivity lists, inferred latches, mixed blocking and nonblocking assignments and clocking mistakes.

    What is the role of a lint tool in HDL verification?

  • Verilog does not reject assignments between different widths but truncates or extends them, so checking width mismatches with a lint tool is effective.
