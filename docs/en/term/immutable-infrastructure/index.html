What is Immutable infrastructure?

An operational approach in which servers (virtual machines or containers) are never changed once created; when an update is needed, new ones are created from an image containing the change and swapped in, and the old ones are discarded. Because every server is created from the same image, configurations do not drift apart through accumulated manual differences, and going back to the previous image easily restores the old state. Anything to be kept, such as logs and data, is placed in storage or databases outside the servers.

Japanese name: イミュータブルインフラストラクチャ
