What is Incremental backup?

A backup method that backs up only the data changed since the previous backup, whether full or incremental. Each backup is small and quick, but a restore requires restoring the full backup and then applying every incremental backup after it in order.

Japanese name: 増分バックアップ

A full backup is taken every Sunday night, and an incremental backup is taken every night from Monday to Saturday. A failure occurs at midday on Thursday, and it is decided to restore the data to the point of Wednesday night's backup. Which is the number of backups used for the restore?

  1. A2
  2. B3
  3. C4
Show answer and explanation

Answer: C. 4

An incremental backup contains only the changes since the previous backup, so after restoring Sunday's full backup, the incremental backups of Monday, Tuesday and Wednesday must be applied in order. The number of backups used is therefore 1 + 3 = 4. Two would be enough if differential backups were taken every night (the full backup and Wednesday's differential backup).
