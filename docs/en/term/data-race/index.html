What is Data race?

A situation in which threads access the same variable concurrently without synchronization and at least one access is a write. Results vary between runs; in C and C++ it is undefined behavior.

Field: Multicore & Synchronization

Data race in the explanations

  • A data race occurs when the order of reads and writes to one location is not fixed by synchronization, so the result depends on the order in which they happened to run.
