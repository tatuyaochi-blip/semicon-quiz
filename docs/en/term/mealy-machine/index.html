What is Mealy machine?

A state machine whose outputs depend on both the current state and the inputs. Input changes reach outputs within the same cycle, but so can input glitches. A Moore machine's outputs depend only on state.

Japanese name: ミーリ型

Mealy machine appears in 2 practice questions across 2 topics, including Logic circuits, HDL & Verification.

Field: HDL & Verification

Definition and structure of a Mealy machine

In a Mealy state machine, outputs depend on both the current state and the current inputs. Like a Moore machine, it consists of a state register, combinational logic for the next state and combinational logic for the outputs, but the inputs connect directly to the output logic. In a state diagram, outputs are written on the transition arrows as input/output rather than inside the states. Because outputs change as soon as inputs change, without waiting for the next clock, a Mealy machine can react one cycle sooner than a Moore machine and often implements the same function with fewer states.

Mealy vs. Moore

In a Moore machine, outputs depend only on the current state and are written inside the states in a state diagram. An input change reaches the outputs only after the clock changes the state, so the response is a cycle later, but input noise does not pass to the outputs and timing is easier to predict. Encoding the states so that outputs come directly from state-register bits also eliminates output glitches. In a Mealy machine, a combinational path runs from inputs to outputs, so input glitches appear at the outputs and timing paths that include the surrounding logic become longer.

Example: a sequence detector

Consider an overlapping sequence detector that outputs 1 when it finds 101 in an input bit stream. A Mealy machine needs only three states: nothing matched, matched 1, and matched 10. In the matched-10 state, the output goes to 1 as soon as a 1 arrives, and the machine moves to matched 1, treating that 1 as the start of the next candidate. A Moore machine needs an extra detected-101 state to represent output 1, giving four states, and its output becomes 1 only after the clock that captures the final 1. The Mealy machine thus uses fewer states and responds faster, while the Moore machine has the edge in output stability.

Design tips in HDL

In Verilog or VHDL it is common to write a sequential block that updates the state register separately from a combinational block that determines the next state and outputs; if the output expressions include inputs, the machine is a Mealy machine. Using asynchronous inputs directly disturbs the outputs, so inputs should be synchronized first. Connecting a Mealy output to the input of another Mealy machine can create a combinational loop, so care is needed. Registering the outputs through flip-flops removes glitches, but the timing then lags by one cycle, just like a Moore machine.

FAQ

What is the difference between a Mealy machine and a Moore machine?

A Mealy machine's outputs depend on both the current state and the inputs, while a Moore machine's depend only on the current state. A Mealy machine can respond to inputs in the same cycle and often needs fewer states, but input noise passes to its outputs more easily.

Which should I use, Mealy or Moore?

Mealy suits cases where response speed or fewer states matter; Moore suits cases where output stability and predictable timing matter. Real designs choose per output or combine both.

Can a Mealy machine be converted to a Moore machine?

Yes. Splitting each Mealy state according to the output of the transitions entering it into separate Moore states gives the same input-output relationship. The number of states may increase, however, and the outputs appear one clock later.
