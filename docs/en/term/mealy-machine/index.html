What is Mealy machine?

A state machine whose outputs depend on both the current state and the inputs. Input changes reach outputs within the same cycle, but so can input glitches. A Moore machine's outputs depend only on state.

Japanese name: ミーリ型

Which type of sequential circuit (state machine) has outputs determined only by the current state?

  1. AMealy machine
  2. BMoore machine
  3. CHarvard machine
Show answer and explanation

Answer: B. Moore machine

In a Moore machine, outputs depend only on the current state; in a Mealy machine, they depend on both state and inputs. Moore outputs come straight from the state register, so they are glitch-free, stable and predictable, but respond a clock later and often need more states. Mealy machines need fewer states and react immediately, but input changes pass directly to the outputs. Real designs mix both styles.

What characterizes a Mealy state machine?

  1. AOutputs depend only on the state and do not change until the next clock
  2. BOutputs depend on both current state and inputs, so input changes appear at the output within the same cycle
  3. CIt is combinational logic with no state
Show answer and explanation

Answer: B. Outputs depend on both current state and inputs, so input changes appear at the output within the same cycle

In a Mealy machine the output logic looks at inputs as well as the current state, so outputs change with inputs without waiting for a clock, reacting one cycle sooner. It may also need fewer states. But a combinational path runs from inputs to outputs, so input glitches can appear at outputs and timing paths get longer. Outputs are sometimes re-registered through flip-flops.
