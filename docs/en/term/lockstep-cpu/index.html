What is Lockstep CPU?

A scheme in which two identical CPU cores run the same program and a comparator checks their outputs to detect faults. To keep common-cause faults from corrupting both cores the same way, execution is offset by a few clocks or the cores are placed apart. Performance is that of one core.

Japanese name: ロックステップ

Which correctly describes how a lockstep CPU, used as a safety mechanism in automotive microcontrollers, works?

  1. ATwo CPU cores share different tasks between them, roughly doubling processing speed
  2. BTwo CPU cores execute the same instructions simultaneously, and their outputs are compared every clock cycle; a mismatch is reported as a fault
  3. CWhen a fault is detected, CPU operation is temporarily stopped (locked), switched to a spare circuit, and the faulty part is automatically repaired before resuming
Show answer and explanation

Answer: B. Two CPU cores execute the same instructions simultaneously, and their outputs are compared every clock cycle; a mismatch is reported as a fault

Lockstep is a scheme in which two identically configured CPU cores run the same program and a comparator checks their outputs against each other. If one result changes due to a bit flip from cosmic rays or a circuit fault, it is detected as a mismatch, giving high diagnostic coverage for CPU faults. Because the two cores do the same work, performance equals that of one core. Comparing two cores alone cannot tell which one is correct, so after detection the system performs a reset or a transition to a safe state.

What is the main reason for offsetting the execution of the two cores in a lockstep CPU by a few clock cycles, or placing the two cores apart on the chip?

  1. AIf the same cause, such as supply noise or radiation, produces the same error in both cores at the same time, the comparison cannot detect it, so this makes identical errors less likely
  2. BSo that one core can use the other core's computation results in advance, speeding up processing
  3. CSo that the two cores can each run different programs, increasing the number of usable cores
Show answer and explanation

Answer: A. If the same cause, such as supply noise or radiation, produces the same error in both cores at the same time, the comparison cannot detect it, so this makes identical errors less likely

Lockstep detects faults through differences between the two cores' results, so it cannot detect identical errors produced in both by the same cause. Such failures are called common cause failures. Momentary supply voltage drops or clock disturbances affect both cores simultaneously, so delaying one core's execution by, for example, 2 clock cycles and realigning the results for comparison makes it less likely that the same error occurs at the same timing. Placing the cores apart likewise keeps localized causes from affecting both.
