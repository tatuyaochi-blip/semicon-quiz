What is Same-origin policy?

A browser rule that restricts scripts on a page loaded from one origin from reading the contents of resources from another origin. An origin is the combination of scheme, host name and port number, and two URLs have the same origin only when all three match. It prevents a malicious page's script from reading information from other sites where the user is logged in. Embedding, such as loading images or scripts, is allowed; when a page needs to read responses from another origin, CORS, which is based on the server's permission, is used.

Japanese name: 同一オリジンポリシー

  1. Ahttps://www.example.com/data/list.json
  2. Bhttp://www.example.com/app/data.json
  3. Chttps://api.example.com/app/data.json
Show answer and explanation

Answer: A. https://www.example.com/data/list.json

An origin is determined by the combination of three things, the scheme, the host name and the port number, and two URLs have the same origin only when all three match. The path does not matter, so /data/list.json has the same origin. Under the same-origin policy, a page's JavaScript in principle cannot read the contents of responses received from other origins. This prevents a malicious page's script from reading information from other sites where the user is logged in.
