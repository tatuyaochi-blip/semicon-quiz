What is PAM4?

Four-level pulse amplitude modulation, sending 2 bits per symbol. It doubles the bit rate at the same symbol rate but reduces noise margin.

Japanese name: PAM4

PAM4 appears in 5 practice questions across 2 topics, including I/O Interfaces & Buses, Silicon photonics.

Field: I/O Interfaces & Buses

From NRZ to four levels

Non-return-to-zero (NRZ) signaling uses two levels and carries one bit per symbol. PAM4 uses four evenly spaced levels, so each symbol carries two bits, and the levels are usually Gray-coded (00, 01, 11, 10) so that mistaking a symbol for its neighbor corrupts only one bit. The symbol rate, measured in baud, is therefore half the bit rate: a 106 Gb/s lane runs at about 53 GBd. Halving the symbol rate halves the Nyquist frequency the channel must pass, and because copper traces and connectors lose much more at high frequencies, this is the main reason PAM4 is adopted.

The noise penalty

With the same peak-to-peak swing, PAM4 fits three eyes where NRZ has one, so the spacing between adjacent levels is one third. That costs about 9.5 dB of signal-to-noise ratio, which is 20 log10 of 3. PAM4 is also more sensitive to nonlinearity, since the levels must stay evenly spaced, and to reflections and crosstalk. Receivers therefore rely on strong equalization, often with analog-to-digital converters and digital signal processing in high-rate SerDes, and links accept a higher raw bit error rate that forward error correction (FEC) then cleans up.

Where PAM4 is used

PCI Express 6.0 moved to PAM4 to reach 64 GT/s at the same symbol rate as the NRZ-based 5.0 generation and added a lightweight FEC to handle the higher raw error rate. High-speed Ethernet electrical lanes and the optical links inside data centers also use it. In intensity modulation with direct detection (IM-DD), the transmitter sets the optical power to four levels and a photodiode converts power directly into current, which keeps transceivers simple and low-power. Long-haul links instead use coherent detection, which also encodes information in the phase and polarization of light.

When to choose PAM4 over NRZ

The decision is a trade between channel bandwidth and noise margin. If a channel's loss at the Nyquist frequency needed for NRZ would exceed what equalization can recover, halving that frequency with PAM4 wins despite the smaller eyes. On short, clean channels NRZ remains simpler, more power-efficient and more robust. Higher-order formats such as PAM8 or 16-level schemes push further in the same direction, cutting symbol rate again but shrinking level spacing more, which is why each step up requires better signal-to-noise ratio and more error correction.

Answer: C. Optical intensity (power)

In IM-DD (Intensity Modulation / Direct Detection), the transmitter modulates the light's intensity, and at the receiver a photodiode converts the intensity directly into current for decision. PAM4 varies the light's intensity in four levels, sending 2 bits per symbol. The photodetector can only detect intensity, but in return the setup is simple, low-cost and low-power. Putting information on the phase or polarization of light requires the coherent scheme, which detects the signal by interfering it with light from another laser at the receiver, making the circuits complex.

Answer: A. About 53 GBd

PAM4 carries 2 bits per symbol using four levels, so the symbol rate is half the bit rate, about 53 GBd (gigabaud). Sending the same bit rate with NRZ (two levels) would require about 106 GBd, demanding correspondingly wider-bandwidth modulators, photodetectors and electrical circuits. On the other hand, because PAM4 divides symbols into four levels, the spacing between adjacent levels is about one-third that of NRZ, making it more susceptible to noise. About 27 GBd is the value for a 16-level modulation sending 4 bits per symbol.

FAQ

What is the difference between baud and bit rate in PAM4?

Baud counts symbols per second, and each PAM4 symbol carries two bits, so the bit rate is twice the baud rate. A 106 Gb/s PAM4 signal runs at about 53 GBd.

Why is PAM4 more susceptible to noise than NRZ?

Four levels share the same voltage or optical power swing, so adjacent levels are only one third as far apart as the two NRZ levels. This corresponds to about a 9.5 dB loss in signal-to-noise ratio.

Why do PAM4 links need forward error correction?

The reduced level spacing makes raw bit errors far more frequent than in comparable NRZ links. FEC lets the receiver correct those errors with modest overhead, so the link still delivers a very low error rate.
