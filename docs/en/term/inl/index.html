What is INL (integral nonlinearity)?

The maximum deviation of an ADC's or DAC's actual transfer characteristic from the ideal straight line. It corresponds to the accumulated DNL.

Japanese name: INL(積分非直線性)

INL (integral nonlinearity) appears in 5 practice questions across 3 topics, including A/D and D/A conversion, Testing and inspection, How to read datasheets.

Field: A/D and D/A conversion

How INL is measured against a line

For an analog-to-digital converter (ADC), INL is evaluated at each code transition (or code center) as the distance from a reference straight line, expressed in least significant bits (LSB); the datasheet figure is the worst case over all codes. The line can be the endpoint line, drawn through the first and last transitions, or a best-fit line chosen to minimize deviations. Both remove offset and gain error, so INL describes only the curve's shape. A best-fit specification usually gives a smaller number, so check which definition a datasheet uses before comparing parts.

INL vs. DNL

Differential nonlinearity (DNL) is how far each individual step width differs from the ideal 1 LSB. INL is essentially the running sum of DNL, so many small errors of the same sign can add up to a large INL, while random errors tend to partially cancel. The two answer different questions: DNL governs missing codes, which occur when a code's width shrinks to zero (DNL of -1 LSB), whereas INL measures how far the overall transfer curve wanders from straight. A converter can have excellent DNL and still show a large bow.

Why INL is hard to calibrate away

Offset and gain errors are linear, so a two-point calibration at zero and a known voltage removes them. INL is a curvature or S-shape that varies code by code, and fixing it needs a multipoint lookup table or calibration built into the converter. Its typical sources are mismatch between capacitors or resistors that set the binary weights, amplifier nonlinearity and voltage-dependent components. On large signals, a bow-shaped error mainly creates second-harmonic distortion and an S-shaped error third-harmonic distortion, degrading total harmonic distortion in audio and measurement systems.

Measuring INL with histograms

In the histogram method, an ADC receives a signal with a known amplitude distribution and the occurrences of each output code are counted. A slow ramp or triangle wave gives nearly equal counts per code; a sine wave is easier to generate cleanly but dwells near its peaks, so counts are corrected against its theoretical distribution. Each code's relative count gives its width, and hence DNL, and accumulating DNL gives INL. DAC INL is measured more directly, by stepping through codes and reading each output with a precise voltmeter.

Answer: C. The maximum deviation of the actual transfer characteristic from an ideal straight line

INL is the maximum distance of the actual transfer curve from an ideal straight line, defined either through the endpoints or as a best-fit line. It corresponds to the accumulation of DNL. INL causes harmonic distortion of large signals, which matters in audio and measurement, and unlike offset and gain errors it is hard to remove by calibration.

FAQ

What is the difference between INL and DNL?

DNL is the error in each individual step width relative to 1 LSB, while INL is the deviation of the whole transfer curve from a straight line. INL roughly equals the accumulated DNL.

Can INL be removed by calibration?

Not with a simple two-point calibration, which only fixes offset and gain. Correcting INL requires multipoint correction such as a lookup table, or calibration circuitry inside the converter.

What is the difference between endpoint and best-fit INL?

Endpoint INL is measured from a line through the first and last code transitions, while best-fit INL uses a line chosen to minimize the deviations. The best-fit value is usually smaller for the same device.
