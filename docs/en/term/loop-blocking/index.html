What is Loop blocking?

An optimization that processes large arrays in small blocks that fit in the cache so loaded data is reused many times before eviction. Very effective for matrix multiplication.

Field: Memory Hierarchy

Loop blocking in the explanations

  • Loop blocking splits the matrices into small blocks that fit in the cache and finishes the work within each block, reusing loaded data many times and sharply reducing capacity misses.
