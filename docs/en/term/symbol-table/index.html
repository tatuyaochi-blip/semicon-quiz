What is Symbol table?

The list of function and variable names, with their addresses and attributes, contained in object files and executables. Used for linking and debugging; strip can remove it.

Japanese name: シンボルテーブル

Which statement is correct about the object file (.o) a compiler produces from one source file?

  1. AIt is a finished program that the OS can run as is
  2. BIt is just compressed source code and contains no machine code
  3. CIt contains machine code, but the addresses of functions and variables in other files are not yet fixed
Show answer and explanation

Answer: C. It contains machine code, but the addresses of functions and variables in other files are not yet fixed

An object file holds the machine code translated from that file's functions, initial values of variables, a list of names it defines and references (the symbol table) and a list of places whose addresses must be filled in later (relocation entries). An instruction calling a function in another file, such as printf, keeps a placeholder because the address is unknown. The linker combines several object files, fixes the addresses and produces an executable.

What happens when the strip command is applied to an executable?

  1. AThe machine instructions are optimized and run faster
  2. BThe executable is encrypted so others cannot run it
  3. CSymbol tables and debug information are removed; the file shrinks, but debuggers can no longer show function names and the like easily
Show answer and explanation

Answer: C. Symbol tables and debug information are removed; the file shrinks, but debuggers can no longer show function names and the like easily

An executable may contain a symbol table listing function and variable names, and debug information mapping code to source lines. These are not needed to run, so removing them with strip makes the file smaller. Function names and line numbers are then unavailable when investigating bugs, so the information is sometimes kept separately before stripping. Symbols needed for dynamic linking remain.
