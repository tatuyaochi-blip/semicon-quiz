What is Default gateway?

The router to which a host hands packets for destinations on other networks. The host uses its subnet mask to decide whether a destination is on the same network, and sends to this router if not.

Japanese name: デフォルトゲートウェイ

Try it: questions about Default gateway

A host (192.168.1.10/24, default gateway 192.168.1.1) sends a packet to server 203.0.113.80 on a different network. With an empty ARP cache, whose MAC address does the host look up with ARP?

  1. AThe default gateway, 192.168.1.1
  2. BThe server, 203.0.113.80
  3. CEvery router on the path to the server
Show answer and explanation

Answer: A. The default gateway, 192.168.1.1

The host first uses its own IP address and subnet mask to decide whether the destination is on the same network. 203.0.113.80 is outside 192.168.1.0/24, so the packet is handed to the default gateway (a router). The destination in the IP header stays the server's 203.0.113.80; only the frame's destination MAC address is set to the gateway's. So ARP looks up the MAC address of 192.168.1.1. ARP broadcasts do not cross routers, so the host cannot look up, and does not need, the MAC address of a server on another network. Each router along the path looks up the MAC address of the next device whenever it forwards.

Two routers, R1 (192.168.1.2) and R2 (192.168.1.3), are configured with VRRP using the virtual IP address 192.168.1.254. Normally R1 forwards traffic as the master. Which address should be set as the default gateway on the LAN hosts?

  1. A192.168.1.2 (R1's address)
  2. B192.168.1.3 (R2's address)
  3. C192.168.1.254 (the virtual IP address)
Show answer and explanation

Answer: C. 192.168.1.254 (the virtual IP address)

VRRP lets several routers form one virtual router that shares a virtual IP address and a virtual MAC address. Normally the master router forwards packets sent to the virtual address, and if the master fails, a backup router becomes the master and takes over forwarding. If hosts use the virtual IP address as their default gateway, they need no change whichever router is running. Mechanisms like this that make the default gateway redundant are collectively called FHRPs, and besides VRRP they include HSRP and others.
