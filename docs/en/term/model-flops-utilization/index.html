What is Model FLOPs utilization (MFU)?

The percentage of hardware peak performance achieved, computed from the operations a model actually requires.

Japanese name: MFU

Which describes MFU (Model FLOPs Utilization), a metric of large-scale training efficiency?

  1. AThe percentage of hardware peak performance achieved, computed from the operations the model actually requires
  2. BThe fraction of model weights that are non-zero
  3. CThe fraction of GPU memory in use
Show answer and explanation

Answer: A. The percentage of hardware peak performance achieved, computed from the operations the model actually requires

MFU derives the rate of useful computation from tokens processed per second and the operations the model requires, then divides it by the GPUs' peak performance. Communication waits, memory-bound operations, pipeline bubbles and recomputation all lower it. Because it shows how well the hardware is used, it guides improvements to training configuration and software.
