What is Retention register?

A flip-flop that keeps its state in a small always-powered storage element while the block is power-gated, allowing operation to resume where it left off.

Japanese name: リテンションレジスタ

  2. BFlip-flop contents are lost, so needed state is saved in retention registers or external memory before power-off

Show answer and explanation

Answer: B. Flip-flop contents are lost, so needed state is saved in retention registers or external memory before power-off

Flip-flops and SRAM in a powered-off block lose their contents, so to resume where it left off, state must be saved before cutting power. Options include retention registers, which pair each flip-flop with a small always-powered storage element, or software writing state out to memory. Saving, restoring and powering up cost time and energy, so for short idle periods it may be better not to cut power.
