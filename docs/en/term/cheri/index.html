What is CHERI?

Short for Capability Hardware Enhanced RISC Instructions. An instruction-set extension that replaces pointers with capabilities, which carry the range they may point to and their permissions in addition to the address, so that out-of-bounds accesses and forged pointers are stopped in hardware. It has been developed by the University of Cambridge and SRI International. Arm made Morello, a prototype processor based on it, available to researchers in the early 2020s.

What a capability contains

A conventional pointer is just an address, and the hardware has no way to check what it points to. A CHERI capability carries, in addition to the address, the lower and upper bounds of the range it may point to and permissions such as read, write and execute. For 64-bit addresses the bounds are stored in compressed form so that the capability fits in 128 bits, and one more tag bit is kept outside the normal memory contents. The CPU checks the bounds and permissions on every load and store and raises an exception if they are violated, so errors such as buffer overflows stop on the spot.

Tags that prevent forgery

The tag is set only when a capability is created by the proper instructions or derived from an existing capability by narrowing its range. If a capability is overwritten as ordinary data, its tag is cleared, and a value without a tag cannot be used as a pointer. Bounds and permissions can only be narrowed, never widened, so a program cannot create more authority than it was given. This property also allows a single program to be divided into small compartments, each limited to what it may access (compartmentalization).

Challenges for adoption

Because pointers double in size, memory use and cache efficiency are affected, and software that treats pointers as integers needs to be modified. Research has shown that many C and C++ programs run with small changes. As of the mid-2020s, implementations are mainly research prototypes and some microcontroller designs; CHERI is not found in the CPUs of ordinary PCs and smartphones.

FAQ

What is the difference between CHERI and MTE (Memory Tagging Extension)?

MTE compares 4-bit tags attached to memory and to pointers and finds errors probabilistically. CHERI gives each pointer its own bounds and permissions and stops out-of-bounds accesses deterministically. MTE is easier to bring to existing software, while CHERI gives stronger guarantees at the cost of larger changes to the instruction set and software.

Does CHERI eliminate all memory-safety problems?

It prevents out-of-bounds accesses and pointer forgery, but preventing use of memory after it has been freed needs additional work in the allocator. It also cannot prevent logic errors or the misuse of permissions that were legitimately granted. It is used together with other measures.
