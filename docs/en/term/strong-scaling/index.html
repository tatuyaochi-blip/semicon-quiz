What is Strong scaling?

Parallel performance evaluation that fixes problem size and measures how much time drops as processors are added.

Field: Performance Analysis

Strong scaling in the explanations

  • Strong scaling solves the same problem on more processors and measures how much time drops; serial parts and communication tend to make gains plateau as processors increase.
