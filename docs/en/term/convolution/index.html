What is Convolution?

An operation that time-reverses one of two sequences and, while shifting it, multiplies it by the other and adds up the products. In discrete time it is y[n] = Σx[k]h[n − k], and the output of an LTI system is the convolution of the input with the impulse response. Convolving sequences of lengths L and M gives a length of L + M − 1. Convolution on the time side becomes multiplication on the frequency side, so long convolutions can be computed quickly with the FFT. The "convolution" of convolutional neural networks is computed in many implementations as a cross-correlation without flipping the filter, but since the weights are learned, either definition works the same way after training.

Japanese name: 畳み込み

Answer: B. So that highly optimized matrix-multiplication libraries and matrix units such as tensor cores can be used

im2col builds a large matrix in which the input values of each convolution window are laid out as a column, then computes the convolution as a product with a matrix of filters. Overlapping windows duplicate input values and increase memory, but decades-optimized matrix-multiplication libraries and matrix units such as tensor cores can be used directly, so it is often faster overall. Some implementations achieve the same effect without materializing the duplicates.
