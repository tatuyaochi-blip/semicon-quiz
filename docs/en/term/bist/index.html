What is BIST (built-in self-test)?

Test circuitry built into the chip so that it generates test patterns and checks results by itself. It is widely used, for example, to test memories.

Japanese name: BIST(組み込み自己テスト)

BIST (built-in self-test) appears in 5 practice questions across 4 topics, including Testing and inspection, Automotive Semiconductors and Functional Safety, Logic circuits.

Field: Testing and inspection

How logic BIST works

A BIST controller, a test pattern generator and a response analyzer are built onto the chip. In logic BIST the pattern generator is usually a linear feedback shift register (LFSR), which produces pseudo-random bits that are shifted into the scan chains. After each capture clock, the chain outputs are compacted by a multiple-input signature register (MISR) into a short signature that is compared with the value expected from a fault-free design. Any unknown value, for example from an uninitialized memory, would corrupt the signature, so such sources must be blocked during test.

Memory BIST and repair

Embedded memories are dense and regular, so they are tested with algorithmic patterns rather than random ones. March tests walk through all addresses in ascending and descending order, writing and reading complementary data, and detect stuck-at, transition, coupling and address-decoder faults in a number of operations proportional to the memory size. Memory BIST runs at full speed from an on-chip clock. Combined with built-in redundancy analysis, it can decide which spare rows or columns should replace failing cells, and the repair is then programmed into fuses.

Why build test into the chip

BIST reduces the need for expensive tester channels, pattern memory and test time, which makes it easier to test many chips in parallel on one tester. It also enables at-speed testing with on-chip clocks and self-testing after the chip is in a product. Automotive microcontrollers run logic and memory BIST at power-up to find latent faults, including faults in the safety mechanisms themselves, which raises the latent fault metric required by functional safety standards. The costs are added area, startup time and a small chance that a faulty circuit produces the correct signature (aliasing).

BIST vs. scan ATPG

In scan testing driven by automatic test pattern generation (ATPG), software computes deterministic patterns that target specific faults, and the tester applies them, usually through on-chip compression. That reaches high coverage with relatively few patterns. Logic BIST's pseudo-random patterns need many more cycles and miss random-pattern-resistant faults unless extra test points are inserted, but they require almost nothing from outside the chip. In practice, production test commonly uses compressed ATPG for logic and memory BIST for memories, with logic BIST added where in-system self-test is needed.

Answer: A. To find latent faults that do not show up in normal operation, such as those in the safety mechanisms themselves, and raise the latent fault metric (LFM)

Even if safety mechanisms such as the ECC correction circuit or comparators are broken, this does not show up in normal operation, so such faults remain latent. Testing the chip's own circuits with logic BIST and memory BIST at power-up finds such faults before driving and raises the LFM. Running BIST takes time, during which normal processing cannot be done, so the design must also consider startup time constraints. It is not a replacement for shipment testing or a means of speeding up processing.

Answer: B. Test circuitry is built into the chip so that the chip tests itself

BIST builds pattern-generation and result-checking circuits into the chip so it can test itself. Memory BIST generates patterns such as March tests at speed, while logic BIST uses pseudo-random patterns. It reduces dependence on expensive testers and test time, and in automotive chips it enables self-diagnosis in the field, for example at every power-up.

FAQ

What is the difference between logic BIST and memory BIST?

Logic BIST applies pseudo-random patterns from an LFSR through scan chains and compresses responses into a signature. Memory BIST applies deterministic algorithms such as March tests to embedded memories and can also identify cells to repair.

Why do automotive chips run BIST at power-up?

Faults in safety mechanisms such as ECC logic or comparators stay hidden during normal operation. Running BIST at every start finds these latent faults before driving, as functional safety standards require.

Does BIST replace automatic test equipment?

Not entirely. BIST reduces tester requirements and test time, but production testing still uses testers for scan patterns, parametric measurements and to start BIST and read its results.
