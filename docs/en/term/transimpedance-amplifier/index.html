What is Transimpedance amplifier?

An amplifier that converts an input current to a voltage. The current enters the op-amp's inverting input and a feedback resistor turns it into a voltage. It is used to read photodiode signals.

Japanese name: トランスインピーダンスアンプ

Answer: C. Transimpedance amplifier (current-to-voltage converter)

In a transimpedance amplifier the inverting input is a virtual ground, so all input current flows through the feedback resistor and the output is −(input current × feedback resistance)—1 µA into 1 MΩ gives 1 V. Holding the photodiode at nearly 0 V improves speed and linearity. A small capacitor across the feedback resistor prevents oscillation. TIAs are used in optical-communication receivers, light sensors and CT-scanner detectors.
