What is Transimpedance amplifier?

An amplifier that converts an input current to a voltage. The current enters the op-amp's inverting input and a feedback resistor turns it into a voltage. It is used to read photodiode signals.

Field: Analog and electronic circuits

Transimpedance amplifier in the explanations

  • In a transimpedance amplifier the inverting input is a virtual ground, so all input current flows through the feedback resistor and the output is −(input current × feedback resistance)—1 µA into 1 MΩ gives 1 V.
