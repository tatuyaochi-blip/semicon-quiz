What is Stack?

A last-in, first-out (LIFO) data structure in which the element added last is removed first. Adding an element is called push and removing one is called pop. Stacks are used to manage return addresses and local variables in function calls (the call stack), to evaluate expressions in Reverse Polish notation and for depth-first search.

Japanese name: スタック

Try it: questions about Stack

On an empty stack, the operations push 1, push 2, pop, push 3, push 4, pop, pop are performed in this order. In what order are the values removed by pop?

  1. A1, 2, 3
  2. B2, 3, 4
  3. C2, 4, 3
Show answer and explanation

Answer: C. 2, 4, 3

A stack is a last-in, first-out (LIFO) structure: the item added last is removed first. After push 1 and push 2, pop removes the top value 2, leaving 1. Pushing 3 and 4 then gives 4, 3, 1 from the top, so the next two pops remove 4 and then 3. The values therefore come out as 2, 4, 3, and 1 remains on the stack. 1, 2, 3 is the order you would get from a queue (first-in, first-out, FIFO), which removes the earliest item first.

The expression “3 4 + 2 * 5 −” in reverse Polish notation (postfix notation) is evaluated by pushing each number onto a stack and, for each operator, popping two values, computing the result and pushing it back. What is the result? The left operand of an operator is the value that was pushed earlier.

  1. A−9
  2. B6
  3. C9
Show answer and explanation

Answer: C. 9

Push 3 and 4, then + pops them and pushes 3 + 4 = 7. Push 2, then * pushes 7 × 2 = 14. Push 5, then − subtracts the later value 5 from the earlier value 14, giving 14 − 5 = 9. In postfix notation the order of operations is fixed by the sequence itself, so no parentheses are needed; this expression corresponds to (3 + 4) × 2 − 5 in ordinary notation. −9 results from swapping the operands of the subtraction, and 6 from reading it as 3 + 4 × 2 − 5 without parentheses.
