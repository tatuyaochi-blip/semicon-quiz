What is Weak symbol?

A fallback definition replaced by any ordinary (strong) definition with the same name. Embedded code uses it for default interrupt handlers and similar.

Japanese name: 弱いシンボル

Answer: B. If an ordinary (strong) definition with the same name exists, it is used; otherwise the weak definition is used

A weak symbol is a fallback definition: "use this if there is no other". Embedded software often supplies default interrupt handlers as weak symbols so that a user-written function with the same name replaces them. Two strong definitions collide with a multiple-definition error, but overlapping with a weak definition is not an error.
