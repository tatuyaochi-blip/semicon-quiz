What is Sample-and-hold circuit?

A circuit that captures (samples) the input voltage at an instant and holds it constant until AD conversion finishes. It is built from a switch and a capacitor.

Japanese name: サンプルホールド回路

Try it: questions about Sample-and-hold circuit

What is the role of a sample-and-hold circuit placed before an ADC?

  1. ATo amplify the input signal
  2. BTo hold the input voltage constant while AD conversion is performed
  3. CTo generate a clock signal
Show answer and explanation

Answer: B. To hold the input voltage constant while AD conversion is performed

Conversion takes time, and if the input changes meanwhile, the result is wrong. A sample-and-hold closes a switch to capture the input on a capacitor (track) and, when the switch opens, holds that value until conversion ends (hold). Without it, converting a 10 kHz sine wave to 12-bit accuracy would allow only a few nanoseconds. In modern SAR ADCs, the internal capacitive DAC performs this function.

Which correctly describes the acquisition time of a sample-and-hold circuit?

  1. AThe time, in track mode, for the hold capacitor voltage to settle to the input within the required accuracy
  2. BHow fast the held voltage gradually decreases
  3. CThe time until the conversion result is output digitally
Show answer and explanation

Answer: A. The time, in track mode, for the hold capacitor voltage to settle to the input within the required accuracy

Acquisition time is the time needed in track mode for the hold capacitor's voltage to approach the input within a specified error. It is RC settling, so reaching 1/2 LSB takes (N+1)·ln2 time constants—about nine for 12 bits. If it is too short, the previous sample's influence remains, causing crosstalk when multiplexing channels. Higher source resistance requires longer acquisition time.
