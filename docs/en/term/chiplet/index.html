What is Chiplet?

A small chip made for a specific function. Several chiplets are connected inside one package to build a larger system.

Japanese name: チップレット

What is the data transfer capacity that can be secured per unit length of chip edge called, emphasized as a performance metric for chiplet interconnects?

  1. AFIT
  2. BBandwidth density (transfer rate per unit length of chip edge)
  3. CProcess capability index
Show answer and explanation

Answer: B. Bandwidth density (transfer rate per unit length of chip edge)

Chiplets usually connect through terminals lined up along their edges, so how much data can cross each millimeter of edge (bandwidth density, in units such as Gb/s/mm) is a key metric. Energy per bit (pJ/bit) is also important, and in-package links can be about an order of magnitude more efficient than board-level links. FIT is a failure rate and process capability index a quality metric.
