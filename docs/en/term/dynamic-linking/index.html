What is Dynamic linking?

Linking that loads and binds shared libraries at run time. Libraries can be shared between processes and fixed by replacement, but a compatible library must be present on the system.

Japanese name: 動的リンク

Try it: questions about Dynamic linking

What is an advantage of dynamic linking (shared libraries)?

  1. AIt always runs even if the library is missing from the system
  2. BSeveral programs can share one library in memory, and updating the library applies fixes without rebuilding
  3. CNo start-up work is needed, so it always starts faster than static linking
Show answer and explanation

Answer: B. Several programs can share one library in memory, and updating the library applies fixes without rebuilding

With dynamic linking, the executable records only which functions of which shared libraries it uses, and at run time the dynamic linker loads the libraries and binds them. Shared library code is never modified, so one copy in physical memory can be shared by many processes. Fixing a bug or vulnerability just means replacing the library. Binding does, however, add work at start-up.

When dynamic linking uses lazy binding through the PLT (procedure linkage table), which statement is correct?

  1. AA shared-library function's address is resolved the first time it is called, and later calls jump straight to the resolved address
  2. BAll function addresses are always resolved before the program starts
  3. CThe library file is reread from disk on every call
Show answer and explanation

Answer: A. A shared-library function's address is resolved the first time it is called, and later calls jump straight to the resolved address

The program calls external functions through small PLT stubs. With lazy binding, the first call makes the stub jump to the dynamic linker's resolver, which finds the real address and writes it into the GOT. Later calls jump directly to the address in the GOT. Skipping resolution of unused functions speeds up start-up. For security, though, resolving everything at start-up and making the GOT read-only is also widely used.
