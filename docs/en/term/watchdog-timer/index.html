What is Watchdog timer?

A timer that resets the microcontroller if software does not kick it within a set time, recovering from runaway or hung programs.

Japanese name: ウォッチドッグタイマ

Try it: questions about Watchdog timer

What is the role of the watchdog timer built into microcontrollers?

  1. ADisplaying the accurate time
  2. BRaising the clock frequency
  3. CResetting the system if the program runs away and fails to clear the timer within a set time
Show answer and explanation

Answer: C. Resetting the system if the program runs away and fails to clear the timer within a set time

A watchdog timer expects healthy software to reset it periodically; if a crash or hang lets it expire, it resets the microcontroller. This allows automatic recovery without human intervention after noise or unexpected states, which is essential in automotive, industrial and remote equipment. Running it from an independent clock, or using a window watchdog that also treats too-early resets as faults, improves reliability.

Why is it bad practice to kick (reset) the watchdog timer unconditionally inside a 1 ms timer interrupt handler?

  1. AThe watchdog may never be touched from inside an interrupt
  2. BEven if the main processing hangs in an endless loop, the interrupt keeps running, so the watchdog can no longer detect the fault
  3. CKicking every 1 ms damages the watchdog
Show answer and explanation

Answer: B. Even if the main processing hangs in an endless loop, the interrupt keeps running, so the watchdog can no longer detect the fault

A watchdog resets the microcontroller if it is not kicked within a set time, recovering from runaway code. But a timer interrupt keeps firing even when the main processing has hung, so kicking there unconditionally hides the hang. The basic practice is to confirm that the main loop and each task have completed a normal cycle and kick only when all have checked in.
