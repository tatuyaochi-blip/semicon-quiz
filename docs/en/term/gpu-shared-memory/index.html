What is GPU shared memory?

Small, fast memory inside each GPU SM that threads of the same block can share. The program decides what is stored there.

Japanese name: シェアードメモリ

What is a characteristic of CUDA shared memory?

  1. AA large main memory shared by all GPUs and the CPU
  2. BAn area where GPU memory is shared with the hard disk
  3. CA small, fast on-chip memory shared by threads of the same block and managed explicitly by the program
Show answer and explanation

Answer: C. A small, fast on-chip memory shared by threads of the same block and managed explicitly by the program

Shared memory is fast memory inside each SM, typically tens of KB per block, and can be read and written many times faster than global memory (the GPU's DRAM). Threads in the same block can place and share data in it, so it is used to load data from global memory once and reuse it many times, or to pass intermediate results between threads. Unlike a cache, the program decides what goes there.

Which describes a bank conflict in CUDA shared memory?

  1. ATwo GPUs using the same bank account
  2. BRunning out of shared memory capacity so the program stops
  3. CShared memory is split into 32 banks, and when several threads of a warp access different addresses in the same bank at once, the accesses are serialized
Show answer and explanation

Answer: C. Shared memory is split into 32 banks, and when several threads of a warp access different addresses in the same bank at once, the accesses are serialized

Shared memory consists of 32 banks assigned in rotation every 4 bytes, and each bank can serve only one address per access. If the 32 threads of a warp use different banks, one access suffices, but two threads hitting different addresses in the same bank split it into two. Reading every 32nd element, for example, piles all threads onto one bank and splits the access into 32. When all threads read the same address, it is broadcast and there is no conflict.
