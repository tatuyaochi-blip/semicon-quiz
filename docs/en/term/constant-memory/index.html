What is Constant memory?

A small GPU region for values that do not change during a kernel. When every thread in a warp reads the same address, one read is broadcast to all, which is fast.

Japanese name: 定数メモリ

Answer: A. When all threads of a warp read the same address (one read is broadcast to all)

Constant memory is a small region that does not change during a kernel and has its own cache. When every thread in a warp reads the same address, one read is broadcast to all of them, which is very fast. It suits values every thread uses, such as image filter coefficients or simulation parameters. Scattered addresses split the reads and make it slower instead.
