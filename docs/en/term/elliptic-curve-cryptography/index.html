What is Elliptic-curve cryptography?

A family of public-key cryptosystems that use arithmetic on points of an elliptic curve over a finite field. Their security rests on the difficulty of recovering the secret integer k from the point kG, the curve point G multiplied by k (the elliptic-curve discrete logarithm problem). For the same security they need much shorter keys than RSA: a 256-bit key is the guideline for about the same security as 3072-bit RSA (128-bit security). They are used for key exchange (ECDH and ECDHE) and signatures (ECDSA and EdDSA), with curves such as P-256 and Curve25519 in wide use. Because Shor's algorithm breaks them, they are among the schemes to be replaced by post-quantum cryptography.

In ECDSA digital signatures, a secret random number k is used for each signature. Which of the following correctly describes how k must be handled?

  1. Ak is included in the signature and made public, so using the same value any number of times does not affect security
  2. BIf the same k is used for signatures on different messages, the private key can be computed from the two signatures
  3. CEven if k is a predictable value, signatures cannot be forged unless the private key itself leaks
Show answer and explanation

Answer: B. If the same k is used for signatures on different messages, the private key can be computed from the two signatures

An ECDSA signature (r, s) is computed from k, the hash value of the message and the private key. If two messages are signed with the same k, k can be eliminated from the two equations for s, and both k and the private key can be found. It is known that even a partial bias or predictability in the bits of k can let the private key be recovered from many signatures. Therefore either a good-quality random number is used, or k is generated deterministically from the private key and the message, as in RFC 6979.
