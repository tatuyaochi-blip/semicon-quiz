What is Multi-factor authentication?

Authentication that verifies a person by combining two or more different factors among knowledge (such as a password), possession (such as a smartphone or smart card) and inherence (such as a fingerprint or face). Even if the password leaks, logging in is impossible without the other factors. Also called MFA.

The three authentication factors

Authentication factors are divided into something only the person knows (knowledge: passwords, PINs, security questions, etc.), something only the person has (possession: smartphones, smart cards, dedicated authentication devices, etc.) and characteristics of the person's body or behavior (inherence: fingerprints, face, vein patterns, voice, etc.). Because multi-factor authentication combines different kinds of factors, an attacker who steals one factor still cannot log in without obtaining the others.

Examples that are not multi-factor

Combining a password with a security question is not multi-factor authentication even though it checks twice, because both are knowledge factors (it is sometimes called two-step verification). Factors of the same kind can be stolen together by the same method, such as phishing. Conversely, a method in which the smartphone's fingerprint sensor unlocks a key stored in the device is multi-factor authentication, combining possession of the device with inherence.

Differences in strength between methods

Verification codes sent by SMS and one-time passwords shown by an app are far more secure than passwords alone, but they cannot fully stop attacks that get users to enter them on a fake site in real time (real-time phishing). Methods such as FIDO2 passkeys, which use a private key inside the device to create a signature bound to the site being accessed, do not work on fake sites and are therefore considered phishing-resistant; as of the mid-2020s their use is spreading.

Answer: A. Entering a password and then entering a one-time password shown in an app on the user's own smartphone

Multi-factor authentication combines two or more different factors among knowledge, possession and inherence. A password (knowledge) combined with a one-time password generated on the user's own smartphone (possession) uses two different factors, so it is multi-factor authentication. Even if the password leaks, an attacker cannot log in without the user's smartphone. A password and a security question are both knowledge factors, so even though they are checked in two steps, this is not multi-factor authentication (it is sometimes called two-step verification). Stacking factors of the same kind means they can be stolen together by the same method, such as tricking the user through phishing. One-time passwords can also be abused by attacks that get the user to enter them on a fake site in real time, so, as of the mid-2020s, methods with which authentication does not work on a fake site (such as FIDO2 passkeys) are spreading.

Answer: C. A stolen cookie represents a state in which multi-factor authentication has been completed, so revoke the session at once and combine passkey-style authentication, shorter sessions and detection of unusual use

When authentication succeeds, the service issues a token such as a session cookie, and subsequent requests are treated as coming from the user on the strength of the token alone. If the token is stolen through relay-type phishing (AiTM) or by information-stealing malware on the endpoint, the attacker can therefore impersonate the user in a state where multi-factor authentication has already been completed. On noticing the damage, not only must the password be changed, but the sessions already issued must be revoked. Prevention combines phishing-resistant authentication bound to the domain being connected to, such as passkeys, shorter session lifetimes and re-authentication or usage restrictions in response to changes in location or device.

FAQ

What is the difference between two-step verification and multi-factor authentication?

Two-step verification means there are two stages of checking, regardless of the kind of factor. Multi-factor authentication means combining factors of different kinds among knowledge, possession and inherence. Entering an SMS code after a password counts as both.

If I set up multi-factor authentication, can my password be simple?

No. Multi-factor authentication is a mechanism for staying protected even if one factor is broken, and it is safer the stronger each factor is. Use a long, hard-to-guess password and do not reuse it with other services.
