What is Cache coherency?

In a multicore CPU, the mechanism that keeps copies of the same address in different cores' caches consistent, for example by invalidating other copies when one core writes.

Japanese name: キャッシュコヒーレンシ

Try it: questions about Cache coherency

Two cores each hold a copy of variable x in their own caches. After core 0 writes x, what problem could occur when core 1 reads x if there were no cache coherence mechanism?

  1. ACore 1 reads the stale value left in its own cache
  2. BCore 1's read is always faster than core 0's write
  3. Cx is read as double its value
Show answer and explanation

Answer: A. Core 1 reads the stale value left in its own cache

In a multicore CPU, each core's cache can hold a copy of the same address. If core 0 updates x only in its own cache, core 1's cache keeps the old value and core 1 reads it. A cache coherence mechanism, for example by invalidating other cores' copies on a write, ensures that every core sees the latest value.

Which correctly lists the four states of the MESI cache coherence protocol?

  1. AMemory, Execute, Store, Index
  2. BModified, Exclusive, Shared, Invalid
  3. CMiss, Evict, Swap, Idle
Show answer and explanation

Answer: B. Modified, Exclusive, Shared, Invalid

In MESI, each cache line is in one of four states: Modified (changed and held only by this core), Exclusive (unchanged and held only by this core), Shared (several cores hold the same contents) or Invalid. The state changes whenever the core reads or writes, or learns of other cores' reads and writes, which prevents copies of the same address from disagreeing.
