What is Memory barrier?

An instruction guaranteeing that memory operations before it become visible to other cores before those after it, also called a fence, such as RISC-V fence.

Japanese name: メモリバリア

  3. CIt stops the program until every thread arrives
Show answer and explanation

Answer: A. It guarantees that memory operations before the barrier become visible to other cores before those after it

CPUs can reorder memory operations, so passing data to other cores in a fixed order requires an instruction that prevents it. A memory barrier makes all earlier reads and writes complete (become visible to other cores) before later ones are performed. Lock acquisition and release include this barrier effect, which is why variables protected by a lock are passed correctly.
