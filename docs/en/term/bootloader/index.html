What is Bootloader?

A small program that runs first at power-on, verifying and starting the main firmware or updating it with new firmware.

Japanese name: ブートローダ

Answer: A. It runs first at power-on, starting the main firmware or updating it with new firmware

A bootloader is a small program stored at a fixed location in flash that runs first at power-on. Normally it verifies the main firmware and starts it, but it can also receive new firmware over UART, USB, radio and so on and write it to flash. It is usually excluded from updates and protected so that the bootloader itself is never corrupted.
