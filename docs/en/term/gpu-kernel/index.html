What is GPU kernel?

A function that many threads execute simultaneously on a GPU. It is launched from the CPU-side program, and each thread uses its index to choose its data. Distinct from an OS kernel.

Japanese name: GPUカーネル

Answer: C. Each SM has a fixed register file, so fewer threads fit at once and memory latency becomes harder to hide

GPUs keep the registers of every active thread on chip so that switching warps is instantaneous. So if each thread uses many registers, fewer threads fit on an SM at once. Registers that do not fit are spilled to memory, which can also slow things down. Compiler options can cap register usage to balance it against thread count.
