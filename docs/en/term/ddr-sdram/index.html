What is DDR SDRAM?

Synchronous DRAM that transfers data on both the rising and falling clock edges. Successive generations such as DDR4 and DDR5 have raised the data rate. It is the standard main memory of PCs and servers.

Field: DRAM

Double data rate and how it is counted

Synchronous DRAM (SDRAM) takes commands on clock edges, which allows pipelined commands and burst transfers. DDR SDRAM additionally moves data on both rising and falling edges, so its speed is quoted in megatransfers per second (MT/s): DDR4-3200 uses a 1600 MHz clock to make 3200 MT/s. Peak bandwidth is the data rate times the bus width, so a 64-bit (8-byte) channel at 3200 MT/s delivers 25.6 GB/s. Real sustained bandwidth is lower because of row switches, refresh and bus turnarounds.

How the slow array keeps up

The memory array itself runs far slower than the interface. DDR bridges the gap with prefetch: each internal access fetches several words in parallel, which are then serialized onto the pins. The prefetch grew from 2n in DDR to 4n in DDR2 and 8n in DDR3 and DDR4, while DDR5 uses a burst length of 16. Data is captured with a data strobe (DQS) that travels alongside the data lines, so timing references and data experience similar delays, a source-synchronous scheme.

Generations and voltages

Each generation raised data rates and lowered supply voltage to save power: roughly 2.5 V for DDR, 1.8 V for DDR2, 1.5 V for DDR3, 1.2 V for DDR4 and 1.1 V for DDR5, where parts exceed 6400 MT/s. DDR5 also splits each module into two independent 32-bit subchannels, moves voltage regulation onto the module with a power-management IC, and adds on-die error correction inside the chips. Generations are not interchangeable: modules differ in key position, signaling and voltage.

DDR vs. LPDDR, GDDR and HBM

Standard DDR is optimized for capacity and cost on removable modules in PCs and servers. LPDDR targets phones and laptops with low-power states and is usually soldered next to the processor. GDDR serves graphics cards with very high per-pin data rates on point-to-point links, trading capacity for bandwidth. High-bandwidth memory (HBM) stacks DRAM dies with through-silicon vias and connects them through a very wide interface on an interposer. All share the same DRAM cell and row-column access principles.

Answer: A. Data is transferred on both the rising and falling edges of the clock

DDR transfers data on both the rising and falling clock edges, doubling throughput at the same clock frequency. Data rates are therefore given in MT/s (transfers per second) rather than MHz: DDR4-3200 runs a 1600 MHz clock at 3200 MT/s. Each generation has raised speed and lowered voltage—DDR4 at 1.2 V, DDR5 at 1.1 V—and DDR5 parts exceed 6400 MT/s.

FAQ

Why is DDR4-3200 called 3200 when the clock is 1600 MHz?

Data is transferred on both clock edges, so 1600 MHz yields 3200 million transfers per second. The number in the name is the data rate in MT/s, not the clock frequency.

How do you calculate DDR memory bandwidth?

Multiply the data rate in MT/s by the bus width in bytes and by the number of channels. One 64-bit channel of DDR4-3200 gives 3200 × 8 = 25,600 MB/s, or 25.6 GB/s peak.

Can DDR5 memory be used in a DDR4 slot?

No. The modules have different key notch positions, pinouts and supply arrangements, so they neither fit nor work in each other's slots.
