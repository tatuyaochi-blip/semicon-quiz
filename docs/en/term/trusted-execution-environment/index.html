What is Trusted execution environment (TEE)?

A hardware-protected execution environment isolated even from the normal OS, used for critical work such as key handling and authentication, for example Arm TrustZone.

Field: Hardware Security

Trusted execution environment (TEE) in the explanations

  • A TEE uses hardware mechanisms to create a small execution environment separated from the normal OS, where especially sensitive tasks run, such as fingerprint matching, payment processing and handling DRM keys.
