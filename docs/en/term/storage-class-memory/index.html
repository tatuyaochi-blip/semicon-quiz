What is Storage-class memory?

Non-volatile memory intended to bridge the gap in speed, capacity and cost between DRAM and NAND flash. Products based on 3D XPoint were the best-known example.

Japanese name: ストレージクラスメモリ

Storage-class memory appears in 2 practice questions across 1 topic, including Emerging memories.

Field: Emerging memories

The gap it is meant to fill

DRAM answers in tens of nanoseconds but is volatile and relatively expensive per bit, while NAND flash is cheap and non-volatile but needs tens of microseconds to read, roughly a thousand times longer. Storage-class memory (SCM) aims at the space between: non-volatile, denser and cheaper than DRAM, and orders of magnitude faster than NAND. Candidate technologies also avoid flash's erase-before-write, allowing data to be updated in place, and generally offer much higher write endurance than NAND.

Two ways to attach it

SCM can sit on the memory bus as modules that the processor reads and writes with ordinary load and store instructions, byte by byte. Used this way it acts as large persistent memory, but software must explicitly flush data out of the CPU caches to be sure it has reached the non-volatile medium. Alternatively, it can sit behind a storage interface such as NVMe as a very fast solid-state drive, where it is accessed in blocks and much of the latency comes from the interface and software stack rather than the medium.

Technologies behind it

The best-known example, 3D XPoint, was developed by Intel and Micron and sold as Optane. It stacked resistive storage elements, widely believed to be phase-change based, with ovonic threshold switch (OTS) selectors at the crossings of word lines and bit lines, with no transistor in each cell. Other candidates include phase-change memory, resistive RAM (ReRAM) and magnetoresistive RAM (MRAM), although MRAM's larger cells suit it better to embedded memory. Low-latency single-level-cell (SLC) NAND is a flash-based approach to part of the same space.

Why it struggled

To succeed, SCM has to be clearly cheaper than DRAM and clearly faster than NAND at the same time, while both incumbents keep improving: NAND cost falls as 3D layer counts rise, and DRAM keeps scaling. Applications also needed software changes to exploit persistent memory. Optane products never reached a large market, and their discontinuation was announced in 2022. Much of the tier is now served by low-latency SLC NAND and by memory attached through Compute Express Link (CXL), which expands capacity behind a standard interconnect.

Answer: A. A non-volatile memory that bridges the gap in speed, capacity and cost between DRAM and NAND flash

DRAM and NAND differ by about 1000× in access time (tens of ns versus tens of µs) and by tens of times in cost per bit. Storage-class memory (SCM) fills that gap: non-volatile, cheaper and denser than DRAM, and orders of magnitude faster than NAND. Intel's phase-change-based Optane was the flagship until its discontinuation was announced in 2022; today low-latency SLC NAND and CXL-attached memory occupy much of this space.

  1. A3D NAND
  2. B3D XPoint

Answer: B. 3D XPoint

3D XPoint stacked resistive storage elements (believed to be phase-change based) with OTS selectors at word-line/bit-line crossings. Announced in 2015 and productized as Optane, it claimed roughly 1000× NAND's speed with more capacity and lower cost than DRAM, appearing in SSDs and memory modules. Squeezed by steadily improving NAND and DRAM, the market never grew, and the business was wound down in 2022.

FAQ

Is Intel Optane DRAM or flash?

Neither. Optane used 3D XPoint, a non-volatile crosspoint memory believed to be based on phase change, positioned between DRAM and NAND flash in speed and cost.

Is storage-class memory volatile?

No. By definition it is non-volatile, keeping its data without power, which is the main thing that separates it from DRAM.

What replaced Intel Optane?

No single technology took its place. Low-latency SLC NAND SSDs cover much of the fast-storage role, and CXL-attached memory addresses capacity expansion beyond DRAM slots.
