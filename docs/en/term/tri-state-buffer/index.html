What is Tri-state buffer?

A buffer that can output 0, 1 or a disconnected high-impedance state. It prevents output conflicts when several circuits share one bus.

Japanese name: トライステートバッファ

Tri-state buffer appears in 1 practice question across 1 topic, including Logic circuits.

Field: Logic circuits

Three output states

A tri-state buffer (also written three-state or 3-state buffer) is a buffer that passes its input to its output, plus an enable input that decides whether the output is active. When enabled, it outputs 0 or 1 according to its input; when disabled, it puts the output in a high-impedance (Hi-Z) state, connected to neither the supply nor ground. Hi-Z is not a third logic value but a state in which the output is disconnected from the circuit, leaving other circuits to set the line's voltage. Parts come with active-high or active-low enables, and circuit diagrams show one as the triangular buffer symbol with the enable input drawn at its side.

Circuit structure

The output stage of a CMOS tri-state buffer consists of a pMOS on the supply side and an nMOS on the ground side, the same shape as an inverter. When enabled, it turns on only one of them according to the input; when disabled, it turns both off so the output connects to nothing. In a typical design, a NAND gate taking the data and the enable produces the pMOS gate signal, and a NOR gate taking the data and the inverted enable produces the nMOS gate signal. Another design stacks two pMOS and two nMOS transistors in series, with one pair controlled by the enable and the other by the data; this version inverts the output.

Use on buses and cautions

The main use of tri-state buffers is to let several circuits share a single bus. Enabling only one circuit at any moment and keeping the others in Hi-Z prevents signals from colliding. If two are enabled at once and drive opposite values, a bus conflict occurs in which a large current flows from supply to ground, causing malfunctions or device degradation. Conversely, if all are in Hi-Z, the line's voltage is undefined (floating), which can cause shoot-through current in the receiving input circuits or pick up noise, so pull-up or pull-down resistors or bus-hold circuits keep the value defined.

Bidirectional pins and use inside chips

Bidirectional pins, such as general-purpose I/O (GPIO) pins on microcontrollers and FPGAs or memory data lines, connect an output tri-state buffer and an input buffer to the same pin. To drive the pin, the buffer is enabled; to use it as an input, the buffer goes to Hi-Z and the pin receives external signals. Bidirectional bus ICs such as the 74HC245 contain this structure internally. Inside a chip, however, tri-state buses risk conflicts and floating nodes and complicate timing analysis, so multiplexers are generally used to select signals instead. In HDL, a tri-state output is described by assigning Z to it.

Answer: C. Disconnecting the output into a high-impedance state

A tri-state buffer can output 0, 1, or a disconnected high-impedance (Hi-Z) state. When several circuits share a bus, idle drivers go Hi-Z to avoid conflicts, and bidirectional I/O pins rely on them too. If two drive at once, bus contention causes large currents, so enable control must be managed carefully. If every driver is Hi-Z the line floats, so a pull-up or similar fixes its level.

FAQ

What is a tri-state buffer?

It is a buffer that, in addition to 0 and 1, can put its output in a disconnected high-impedance (Hi-Z) state. An enable input switches the output between active and inactive, preventing output conflicts when several circuits share one bus.

What does a tri-state buffer circuit look like?

The output stage is a pMOS on the supply side and an nMOS on the ground side. When enabled, one of them turns on according to the input; when disabled, both turn off and the output is disconnected. A typical design generates the gate signals with a NAND gate and a NOR gate.

Is high impedance (Hi-Z) the same as 0?

No. Hi-Z means the output is connected to neither the supply nor ground, and the line's voltage is set by other circuits or by pull-up or pull-down resistors. If nothing drives the line, its voltage is undefined.
