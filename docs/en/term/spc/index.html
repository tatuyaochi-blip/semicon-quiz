What is SPC (statistical process control)?

A method of maintaining quality by monitoring process data with control charts and the like and detecting anomalies statistically.

Japanese name: SPC(統計的工程管理)

Field: Yield and quality control

How SPC works

Statistical process control separates common-cause variation, the random scatter inherent to a stable process, from special-cause variation, which signals that something has changed. Measurements such as film thickness, critical dimension, overlay or particle counts are plotted in time order on control charts with a center line and control limits, usually at plus and minus three standard deviations of the in-control process. A point beyond the limits, or a non-random pattern such as a long run on one side of the center line, triggers an out-of-control action plan: hold the lot, check the tool, find the cause.

Control limits vs. specification limits

Control limits come from the process's own past behavior, while specification limits come from design or customer requirements. A process can be statistically in control yet still produce out-of-spec parts if its spread is too wide. Capability indices connect the two: Cp compares the specification width with six standard deviations, and Cpk also accounts for how far the mean sits from the nearer limit. A Cpk of 1.33 or more is a common minimum target, and critical steps often aim higher.

SPC vs. APC and FDC

SPC watches and stops; it does not correct. Advanced process control (APC) uses metrology data to adjust recipes automatically, for example extending polish time when incoming film is thick (run-to-run control). Fault detection and classification (FDC) monitors tool sensor traces such as pressure, power and flow in real time. Because sensor values are correlated, multivariate charts like Hotelling's T-squared can flag an abnormal combination even when each variable looks normal on its own chart. In practice, APC corrects drift and SPC confirms the corrected process stays stable.

Living with false alarms

With three-sigma limits, a stable, normally distributed process still puts about 0.27% of points outside the limits by chance. A fab running thousands of charts therefore sees false alarms every day, and adding pattern rules raises sensitivity at the cost of more alarms. Engineers tune chart types, sampling plans and rules per parameter, and must recompute limits after deliberate process changes. Too-loose limits hide real drift; too-tight ones cause needless lot holds and erode trust in the system.

Answer: A. Multivariate control charts (such as Hotelling's T²)

Tool sensor values are often correlated, so a state can be abnormal as a combination even when each value is within limits on its own chart. For example, pressure and flow normally move together, but one changes alone. Multivariate control charts using statistics such as Hotelling's T² account for correlation and monitor multiple values as a single index, detecting such anomalies.

FAQ

What is the difference between control limits and specification limits?

Control limits are calculated from the process's own variation and show whether it is behaving consistently. Specification limits are the acceptable range set by design requirements; a stable process can still violate them if its spread is too large.

What does a Cpk of 1.33 mean?

It means the nearer specification limit is four standard deviations from the process mean. For a normally distributed process this corresponds to only a few dozen out-of-spec parts per million on that side.

Is SPC the same as APC?

No. SPC detects abnormal variation and stops the process for investigation, while APC automatically adjusts tool settings based on measurements to keep results on target.
