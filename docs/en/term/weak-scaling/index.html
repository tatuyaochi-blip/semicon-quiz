What is Weak scaling?

Parallel performance evaluation that fixes problem size per processor while growing the total and checks whether time stays constant.

Japanese name: 弱いスケーリング

What is the difference between strong scaling and weak scaling in evaluating parallel computing?

  1. AStrong scaling fixes total problem size while adding processors; weak scaling fixes problem size per processor and grows the total
  2. BStrong scaling uses fast processors, weak scaling slow ones
  3. CBoth are the same measurement under different names
Show answer and explanation

Answer: A. Strong scaling fixes total problem size while adding processors; weak scaling fixes problem size per processor and grows the total

Strong scaling solves the same problem on more processors and measures how much time drops; serial parts and communication tend to make gains plateau as processors increase. Weak scaling keeps work per processor constant while growing the total and checks whether time stays constant. Results cannot be compared correctly without stating which kind of scaling was measured.
