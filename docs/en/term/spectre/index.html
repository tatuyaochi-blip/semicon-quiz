What is Spectre?

A class of vulnerabilities, disclosed in 2018, that induces mispredicted speculative execution to read secret data and infers its value from traces left in the cache.

Field: Hardware Security

Spectre in the explanations

  • In Spectre, an attacker trains the predictor to mispredict, so a path that should never execute reads secret data and loads a cache location that depends on its value.
