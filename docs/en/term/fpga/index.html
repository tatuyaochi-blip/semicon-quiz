What is FPGA?

A chip whose logic configuration the user can rewrite after manufacture. It is used for prototypes, low-volume products and ASIC verification.

Japanese name: FPGA

FPGA appears in 5 practice questions across 4 topics, including IC design flow and EDA, HDL & Verification, Logic circuits.

Try it: questions about FPGA

Which correctly describes the function of a multiplexer?

  1. AIt stores the input value for one clock cycle
  2. BIt inverts the logic of the input signal
  3. CIt selects one of several inputs according to select signals and outputs it
Show answer and explanation

Answer: C. It selects one of several inputs according to select signals and outputs it

A multiplexer (selector) routes one of several inputs to its output according to a select signal; n select bits choose among 2ⁿ inputs. CPUs use them to pick register values and switch buses, and FPGA logic blocks (LUTs) implement arbitrary logic with memory plus multiplexers. A circuit that routes one input to one of several outputs is a demultiplexer.

Which correctly describes a feature of FPGAs?

  1. AThe circuit is fixed at manufacture and cannot be changed
  2. BThey are devices dedicated to analog circuits
  3. CUsers can rewrite the configuration of the logic circuit after manufacturing
Show answer and explanation

Answer: C. Users can rewrite the configuration of the logic circuit after manufacturing

An FPGA consists of logic blocks with small lookup tables (LUTs) and programmable interconnect whose configuration can be rewritten after manufacture. With no fabrication lead time or mask costs, unlike an ASIC, it suits prototypes, low volumes and equipment needing updates. Its reconfiguration circuitry adds overhead, so the same function in an ASIC is faster, lower power and smaller. It is not an analog-only device.
