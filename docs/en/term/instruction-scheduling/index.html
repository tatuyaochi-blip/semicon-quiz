What is Instruction scheduling?

Reordering instructions without changing results so that latencies of operations and memory accesses are filled with independent instructions.

Japanese name: 命令スケジューリング

What is the main purpose of instruction scheduling in a compiler?

  1. AReducing the instruction count by any means, even if program results change
  2. BReordering without changing results to fill latencies
  3. CRearranging instructions into the order chosen by the OS scheduler
Show answer and explanation

Answer: B. Reordering without changing results to fill latencies

When a load or multiply result is not immediately available, placing its consumer right after it stalls the CPU. Instruction scheduling reorders instructions, respecting data dependences so results are unchanged, to insert independent instructions in between and make use of the waiting time. It is especially effective on in-order CPUs. Transformations that change results are not allowed, and the OS scheduler decides process switching, a separate mechanism.
