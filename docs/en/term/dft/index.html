What is DFT (design for testability)?

A design approach that builds test features such as scan chains and BIST into the circuit in advance.

Japanese name: DFT(テスト容易化設計)

DFT (design for testability) appears in 4 practice questions across 3 topics, including Testing and inspection, IC design flow and EDA, Environment, health and safety.

Field: Testing and inspection

Controllability and observability

Manufacturing test looks for physical defects, usually modeled as faults such as a node stuck at 0 or stuck at 1. Detecting a stuck-at-0 fault requires driving that node to 1 from the chip's inputs (controllability) and then propagating the resulting difference to an output where the tester can see it (observability). Deep inside a large sequential design, many nodes are almost impossible to reach from the pins, so test patterns become enormous and coverage stays poor. Design for testability (DFT) adds structures that raise both properties so faults can be detected with far fewer patterns.

How scan chains work

Scan design replaces each flip-flop with a scan flip-flop that has a multiplexer at its input. In test mode a scan-enable signal links the flip-flops into long shift registers called scan chains. The tester shifts a pattern in, switches to functional mode for one or a few capture clocks so the combinational logic responds, then shifts the captured values out while shifting the next pattern in. Because every flip-flop is now directly settable and readable, testing the sequential circuit reduces to testing combinational logic, and automatic test pattern generation (ATPG) tools can reach high fault coverage.

Built-in self-test and boundary scan

Built-in self-test (BIST) moves pattern generation onto the chip. Memory BIST runs march algorithms that write and read address sequences to find stuck, coupling and address-decoder faults in embedded SRAM, and its results can drive redundancy repair. Logic BIST uses a linear feedback shift register (LFSR) to generate pseudo-random patterns and compacts responses into a signature in a multiple-input signature register (MISR). BIST also allows testing in the field, for example at power-up. Boundary scan, standardized as IEEE 1149.1 (JTAG), places scan cells at the I/O pins to test board-level connections.

Costs and the DFM contrast

DFT is not free. Scan multiplexers add area and a little delay to every flip-flop, extra routing is needed for scan chains, and shifting patterns can toggle far more nodes than normal operation, so test power and IR drop must be checked. Test time on expensive automatic test equipment drives cost, which is why on-chip test compression is widely used. DFT should not be confused with design for manufacturability (DFM), which shapes layouts, for example with redundant vias and relaxed spacing, so that chips yield well in the first place.

Answer: C. Connecting the flip-flops in a circuit like a shift register to make it easy to set and observe internal states

Scan design adds a multiplexer at each flip-flop input; in test mode the flip-flops are chained into scan chains so arbitrary values can be shifted in and internal values shifted out. This turns sequential-circuit testing into combinational-circuit testing, letting ATPG automatically generate patterns with high fault coverage. It has nothing to do with microscope scanning or voltage sweeps.

Answer: B. Controllability and observability

Controllability is how easily an internal signal can be set to a desired value from outside; observability is how easily its value can be seen from outside. Detecting a fault requires driving the site to the opposite of the faulty value (control) and propagating the difference to an output (observe). DFT techniques such as scan and test-point insertion raise both so faults can be detected with fewer patterns.

FAQ

What does DFT stand for in chip design?

In chip design and test, DFT means design for testability: adding scan chains, built-in self-test and similar structures so manufactured chips can be tested efficiently. The same letters also stand for the discrete Fourier transform in signal processing and density functional theory in materials simulation.

What is a scan chain?

A scan chain is a set of flip-flops connected as a shift register in test mode, so the tester can load any internal state and read out the state after a capture clock. It makes internal logic controllable and observable through a few pins.

What is the difference between scan testing and BIST?

Scan testing relies on external test equipment to supply patterns through scan chains and compare results. BIST generates patterns and checks responses with on-chip circuits, so it needs little tester support and can also run in the field.
