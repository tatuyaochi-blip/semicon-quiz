What is Hard link?

Another name attached to the inode that manages a file's contents and attributes. It is created with ln existing-name new-name; both names are equal, and ls -i shows the same inode number. The inode counts the names pointing to it (the link count), and the contents are freed only when all the names are gone, so the file can still be read through the remaining name even after the original name is removed with rm. It can be created only within the same file system and normally not for directories.

Japanese name: ハードリンク
