What is Zener diode?

A diode that provides a constant voltage by using the nearly fixed reverse breakdown voltage.

Japanese name: ツェナーダイオード

Zener diode appears in 4 practice questions across 2 topics, including PN junctions and diodes, Image sensors and optical devices.

In a simple voltage regulator using a Zener diode, what is the role of the resistor placed in series with the diode?

  1. ATo limit the current through the diode and take up the difference between input and output voltage
  2. BTo amplify the signal
  3. CTo convert AC to DC
Show answer and explanation

Answer: A. To limit the current through the diode and take up the difference between input and output voltage

A Zener diode holds a nearly constant voltage in breakdown, but without current limiting it would be destroyed by excessive current and heat. The series resistor limits the current and absorbs variations in input voltage as its own voltage drop, keeping the output nearly constant. Its value is chosen as (minimum input voltage − Zener voltage) ÷ (load current + minimum Zener current). Because it is inefficient, this circuit suits low-current voltage references.
