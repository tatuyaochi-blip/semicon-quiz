What is Write-through?

A write policy that writes to the level below (such as main memory) at the same time as the cache. The lower level stays up to date, but write traffic is heavy, so it is paired with a write buffer.

Japanese name: ライトスルー方式

Try it: questions about Write-through

What is the main purpose of a write buffer in a write-through cache?

  1. ATo let the CPU continue without waiting for writes to main memory to complete
  2. BTo keep the data in the cache newer than in main memory
  3. CTo always fetch the line from main memory into the cache first on a write miss, then write it
Show answer and explanation

Answer: A. To let the CPU continue without waiting for writes to main memory to complete

A write-through cache also writes to main memory on every store, so waiting for each write to finish would stall the CPU constantly. A write buffer holds writes temporarily, letting the CPU move on immediately while the buffer drains to memory in the background. Keeping the cache newer than memory characterizes write-back caches; with write-through the two stay consistent. Whether to load a line on a write miss is the write-allocate decision, separate from the write buffer.

For code that writes to the same line many times, why is a write-back cache more advantageous than write-through?

  1. AWrites complete within the cache, and memory is written only once when the line is evicted
  2. BMemory is updated on every write, so no work is needed at eviction
  3. CCache and memory always match, so no coherence management is needed
Show answer and explanation

Answer: A. Writes complete within the cache, and memory is written only once when the line is evicted

A write-back cache absorbs repeated writes to the same line within the cache and writes the dirty line back just once on eviction, greatly reducing memory traffic and power. Updating memory on every write is the write-through behavior, which generates traffic each time the line is written. Cache and memory always matching is also write-through; with write-back they differ for a while.
