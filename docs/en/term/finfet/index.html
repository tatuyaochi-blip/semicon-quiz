What is FinFET?

A 3D transistor whose channel stands up like a fin and is surrounded by the gate on three sides. It suppresses short-channel effects well.

Japanese name: FinFET

Try it: questions about FinFET

Which correctly describes the structure of a FinFET?

  1. AThe gate wraps around a fin-shaped channel on three sides
  2. BA planar gate covers only the top of the channel
  3. CMetal contacts the channel directly with no gate insulator
Show answer and explanation

Answer: A. The gate wraps around a fin-shaped channel on three sides

A FinFET stands silicon up as a fin a few to over ten nm wide and tens of nm tall, with the gate wrapping both sidewalls and the top. Gate control from three sides suppresses short-channel effects better than planar devices, cutting off-state leakage, and the vertical dimension provides current-carrying width in a small footprint. It became the advanced-logic standard from the 22 nm generation.

How is the effective channel width of a FinFET adjusted?

  1. ABy changing the number of fins, so the width takes discrete values
  2. BBy changing the gate voltage
  3. CIt can be set to any continuous value, as in planar transistors
Show answer and explanation

Answer: A. By changing the number of fins, so the width takes discrete values

In a FinFET, fin height and width are fixed by the process, so channel width is adjusted only by the number of fins—a discrete quantity ("width quantization"). This makes it hard to set fine current ratios in analog circuits or tune the strength ratios among SRAM cell transistors, constraining design. Nanosheet GAA devices relax this limitation.
