What is FinFET?

A 3D transistor whose channel stands up like a fin and is surrounded by the gate on three sides. It suppresses short-channel effects well.

Field: Advanced transistors (FinFET and GAA)

FinFET in the explanations

  • A FinFET is a 3D transistor in which silicon is formed into a thin, upright fin, with the gate surrounding both sides and the top.

    Which correctly describes the structure of a FinFET?

  • In a FinFET, the fin height and width are fixed by the process, so the channel width is adjusted by the number of fins.

    How is the effective channel width of a FinFET adjusted?

  • In a FinFET the gate wraps both sidewalls and the top of the fin, so the effective channel width per fin is roughly 2 × height + width = 2 × 50 + 6 = 106 nm.
