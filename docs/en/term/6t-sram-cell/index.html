What is 6T SRAM cell?

The SRAM memory cell made of two cross-coupled inverters (four transistors) and two access transistors.

Japanese name: 6T SRAMセル

Field: SRAM and flash memory

How six transistors hold a bit

A 6T SRAM cell is a latch of two cross-coupled CMOS inverters, each built from a PMOS pull-up and an NMOS pull-down, so four transistors in all. Each inverter's output drives the other's input, and this positive feedback holds one storage node high and the other low indefinitely while power is applied, with no refresh. Two NMOS access transistors, gated by the word line, connect the two storage nodes to a complementary pair of bit lines, BL and BL-bar. The cell is static but not free: its transistors still leak continuously.

Read and write sizing

For a read, both bit lines are precharged high and the word line is raised; the node storing 0 pulls its bit line down slightly, and a sense amplifier detects the small difference. Current flowing in through the access transistor lifts that 0 node, so the pull-down must be stronger than the access transistor, a cell ratio of about 1.5 to 2.5, or the cell can flip. For a write, one bit line is driven low and the access transistor must overpower the pull-up PMOS holding the node high, so the pull-up is kept weakest of the three.

6T SRAM versus a DRAM cell

A 6T SRAM cell occupies roughly 120 to 150 F², where F is the minimum feature size, while a one-transistor, one-capacitor DRAM cell is about 6 F², so SRAM is around 20 times less dense and costs far more per bit. In return it needs no capacitor or special process, is built alongside logic transistors and can be accessed in about a nanosecond, against tens of nanoseconds for DRAM. That is why on-chip caches and register files use SRAM, while main memory uses DRAM.

Low-voltage limits and the 8T cell

Because read stability and writability pull the transistor sizes in opposite directions, random variation in threshold voltage makes some cells fail as supply voltage drops, which sets a minimum operating voltage for large arrays. An 8T cell adds a two-transistor read port whose bit line only senses a storage node through a transistor gate, so reads cannot disturb the stored value. Read and write paths can then be optimized separately and can operate at the same time, improving low-voltage operation at the cost of a larger cell.

An 8T cell adds a two-transistor read-only path; the storage node only drives a gate there, so reads cannot disturb it. In a 6T SRAM cell, which design is needed so that the cell contents are not flipped during a read (to prevent read upset)?

  2. BRemove the pull-up transistor
  3. CMake the pull-down (driver) transistor stronger than the access transistor

Answer: C. Make the pull-down (driver) transistor stronger than the access transistor

During a read, current flows from the precharged bit line through the access transistor into the node holding 0, raising its voltage slightly. If the pull-down transistor is sufficiently stronger than the access transistor (a cell ratio β = pull-down/access of about 1.5–2.5), the rise stays below the opposite inverter's switching threshold and the data does not flip. 8T cells and read-assist circuits also address this.

FAQ

Why does an SRAM cell have six transistors?

Four transistors form two cross-coupled inverters that hold the bit through positive feedback, and two access transistors connect the cell to the bit lines when the word line is selected. This gives a stable, refresh-free storage element built only from logic transistors.

Does SRAM need refresh like DRAM?

No. The cross-coupled inverters actively restore the stored levels as long as power is supplied, so SRAM needs no refresh, although the data is lost when power is removed.

What is the cell ratio in a 6T SRAM?

It is the strength of the pull-down transistor relative to the access transistor, typically about 1.5 to 2.5. A high enough ratio keeps the 0 node from rising past the switching threshold during a read, preventing read upset.
