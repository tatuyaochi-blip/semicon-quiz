What is Fixed point?

Representing fractions with ordinary integer bit patterns and an agreed binary-point position. Integer arithmetic circuits suffice, giving small, low-power hardware, but the range is narrow. Formats are often named by fraction bits, as in Q15.

Japanese name: 固定小数点

Field: Computer Arithmetic

How a fixed-point number is stored

A fixed-point number is an ordinary integer that the programmer agrees to divide by a fixed power of two. With 8 bits and 4 fraction bits, the pattern 0011 1000 reads as the integer 56, and dividing by 2⁴ = 16 gives 3.5: the upper bits are the integer part and the first fraction bit weighs 0.5. Q notation names the format: Q15 is a 16-bit signed number with 15 fraction bits, covering −1 to just under +1 with a step of 2⁻¹⁵, about 3.05 × 10⁻⁵. Qm.n states integer and fraction bits explicitly.

Arithmetic rules

Two numbers in the same format can be added with an ordinary integer adder, since their binary points already line up. Multiplication doubles the fraction bits: two Q15 values give a 32-bit product with 30 fraction bits, which is shifted right by 15 to return to Q15, with rounding if needed. Overflow is the main hazard. Ordinary integer hardware wraps around, turning a large positive result into a negative one, so DSPs provide saturating arithmetic that clamps to the largest representable value. In Q15, even −1 × −1 overflows because +1 cannot be represented.

Why hardware uses it

Because the contents are just integers, fixed point needs no exponent alignment, normalization or special-value handling, all of which make floating-point units larger and more power-hungry. Integer multipliers and adders are small and fast, which suits low-cost microcontrollers without a floating-point unit, signal-processing DSPs, and custom datapaths on FPGAs and ASICs where the designer can choose exactly as many bits as the algorithm needs. The price is design effort: every intermediate value must be scaled so it neither overflows nor loses too much precision.

Fixed point vs. floating point

Fixed-point values are evenly spaced, so absolute precision is the same everywhere but the range is narrow. Floating point stores a significand and an exponent, so spacing doubles each time the exponent rises: in single precision the gap between neighbors is about 1.2 × 10⁻⁷ near 1 but 8 near 100 million. Floating point therefore keeps relative precision roughly constant over an enormous range. Both formats have rounding error; the difference is that fixed point trades range for simple hardware and predictable, uniform resolution.

Try it: questions about Fixed point

In unsigned fixed point with the low 4 of 8 bits as the fraction, what value does the bit pattern 0011 1000 represent?

  1. A56
  2. B3.8
  3. C3.5
Show answer and explanation

Answer: C. 3.5

The upper four bits, 0011, are the integer part, 3; the lower four bits, 1000, are the fraction, where the first bit weighs 2⁻¹ = 0.5. Together that is 3 + 0.5 = 3.5. Equivalently, reading the bits as the integer 56 and dividing by 2⁴ = 16 for the four fraction bits gives 56 ÷ 16 = 3.5. 56 ignores the binary point, and 3.8 misreads binary 1000 as the decimal ".8".

FAQ

What does Q15 mean in fixed-point arithmetic?

Q15 is a 16-bit signed fixed-point format with 15 fraction bits and one sign bit. It represents values from −1 up to 1 − 2⁻¹⁵ in steps of about 3.05 × 10⁻⁵.

How do you convert a fixed-point value to decimal?

Read the bit pattern as an integer and divide by 2 raised to the number of fraction bits. For example, 0011 1000 with 4 fraction bits is 56 ÷ 16 = 3.5.

What is the difference between fixed point and floating point?

Fixed point uses a binary point at an agreed fixed position, giving uniform spacing and simple integer hardware but a narrow range. Floating point adds an exponent, giving a wide range with roughly constant relative precision at the cost of more complex hardware.
