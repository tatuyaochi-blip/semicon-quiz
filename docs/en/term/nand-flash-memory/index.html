What is NAND flash memory?

Non-volatile memory in which memory cells are connected in series. It is dense and easy to scale to large capacities, and is used in SSDs and memory cards.

Japanese name: NAND型フラッシュメモリ

Field: SRAM and flash memory

Cells in series

A NAND flash cell is a transistor with a charge-storage layer, either a floating gate or a charge-trap film, beneath its control gate. Dozens of cells are connected in series in a string between two select transistors, so the string needs contacts only at its ends, which makes area per bit very small. To read a cell, a read voltage is applied to its word line while all other word lines in the string get a higher pass voltage that turns their cells fully on; whether the string conducts reveals the selected cell's threshold.

Programming and erasing

Programming applies around 20 V to the control gate so electrons tunnel from the channel through a thin tunnel oxide into the storage layer by Fowler-Nordheim (FN) tunneling, raising the threshold voltage. Incremental step pulse programming (ISPP) raises the pulse voltage a few hundred millivolts at a time and verifies after each pulse for a tight distribution. Erasing raises the cell well to high voltage to pull electrons out of every cell in a block. The erased, low-threshold state reads as 1, so erased flash reads 0xFF.

Pages, blocks and the FTL

NAND reads and programs in pages of roughly 16 KB, the cells on one word line, but erases only whole blocks of hundreds of pages, several to tens of megabytes. Programming can only move bits from 1 to 0, so data cannot be overwritten in place. A flash translation layer (FTL) in the controller writes new data to a free page, remaps the logical address and marks the old page invalid; garbage collection later copies valid pages out of a block and erases it. Wear leveling spreads erases across blocks, and strong error-correcting codes handle bit errors.

Bits per cell and endurance

Storing N bits per cell requires 2^N threshold-voltage levels in roughly the same voltage window: 2 for SLC, 4 for MLC, 8 for TLC and 16 for QLC. Each extra bit lowers cost per gigabyte but narrows the gaps between levels, slowing programming and reducing endurance, because each program/erase cycle slightly degrades the tunnel oxide. Typical figures are about 50,000 to 100,000 cycles for SLC, a few thousand for TLC and around 1,000 for QLC. Modern 3D NAND stacks more than a hundred word-line layers vertically, mostly with charge-trap cells formed around vertical channel holes.

  3. CIt is volatile memory that loses data when the power is off

Answer: B. Cells are connected in series, so it is easy to make dense and suits high-capacity storage

NAND flash strings dozens of cells in series and omits per-cell contacts, so area per bit is small and it suits high-capacity SSDs and memory cards. Reading through the series string is slower, though, so access is page-based. NOR flash connects each cell in parallel to the bit line, giving fast random reads suited to executing code in place. Both are non-volatile.

What is the unit in which data is erased in NAND flash memory?

  1. ABit
  2. BBlock
  3. CByte
Show answer and explanation

Answer: B. Block

NAND reads and programs by page (around 16 KB), but erases only by block—hundreds to thousands of pages, several to tens of MB—because erase applies high voltage to an entire well to remove electrons in bulk. Even partial updates cannot overwrite in place: new data goes to a free page, the old page is marked invalid, and garbage collection later erases blocks in bulk.

FAQ

What is the difference between NAND and NOR flash?

NAND connects cells in series, giving the smallest cell and highest capacity but page-based access, so it is used for SSDs and memory cards. NOR connects each cell in parallel to the bit line, giving fast random reads suited to storing and executing code, at lower density.

Why can't NAND flash overwrite data in place?

Programming can only add charge and raise threshold voltages, and removing charge requires erasing an entire block. Controllers therefore write updated data to a fresh page and reclaim old blocks later through garbage collection.

What do SLC, MLC, TLC and QLC mean?

They denote 1, 2, 3 and 4 bits stored per cell, which require 2, 4, 8 and 16 distinguishable threshold-voltage levels. More bits per cell means cheaper capacity but slower writes and lower endurance.
