What is Microcontroller?

A small computer that integrates a CPU, memory and peripherals such as timers and ADCs on one chip. It is embedded in appliances, cars and other equipment to control them. Also called an MCU.

Japanese name: マイコン(マイクロコントローラ)

Try it: questions about Microcontroller

When a microcontroller produces an analog voltage by passing a PWM signal through a low-pass filter, what determines the output voltage?

  1. AThe duty cycle of the pulses (the fraction of each period that is on)
  2. BThe color of the pulses
  3. CThe memory capacity of the microcontroller
Show answer and explanation

Answer: A. The duty cycle of the pulses (the fraction of each period that is on)

Averaging a PWM signal with a low-pass filter gives an output of amplitude × duty cycle—about 2 V for 40% of 5 V. Resolution is set by the timer's count range, and placing the PWM frequency well above the filter cutoff reduces ripple. Since it produces analog voltages without a dedicated DAC, it is used for LED dimming, motor speed control and simple audio output, but response speed and accuracy trade off against ripple.

Which non-volatile memory has been integrated on the same chip as logic circuits to store microcontroller programs?

  1. AEmbedded flash memory
  2. BHBM
  3. CGDDR
Show answer and explanation

Answer: A. Embedded flash memory

Microcontrollers have long integrated embedded flash on the same die as logic to store programs and data. It keeps its contents without power and allows firmware updates after shipment. But it adds many process steps, such as forming floating gates, and is hard to integrate beyond about 28 nm or with high-k/metal gates, so MRAM and ReRAM, which need fewer extra steps, are replacing it.
