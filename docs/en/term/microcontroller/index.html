What is Microcontroller (MCU)?

A small computer that integrates a CPU, memory and peripherals such as timers and ADCs on one chip. It is embedded in appliances, cars and other equipment to control them. Also called an MCU.

Japanese name: マイコン(マイクロコントローラ)

Field: CPUs and architecture

What is inside an MCU

A microcontroller (MCU) puts a complete small computer on one die: a CPU core, embedded flash for the program, SRAM for working data, and peripherals that connect directly to the outside world. Typical peripherals include timers that generate PWM signals, a successive-approximation (SAR) ADC, general-purpose I/O pins, a watchdog timer and serial interfaces such as UART, SPI, I²C and CAN. Because the program is already stored on chip, an MCU starts running its firmware moments after power is applied, which suits control tasks that must be ready immediately.

Microcontroller vs. microprocessor

A microprocessor or application SoC aims at computing performance: it runs a full operating system from external DRAM and storage and needs supporting chips around it. An MCU aims at cost, size, low power and predictable real-time response, running bare-metal firmware or a small real-time operating system (RTOS) from its own memory. A single car contains dozens to over a hundred MCUs, and appliances and industrial equipment use them for motor control, sensing and user interfaces. Program storage is changing too: embedded flash is hard to integrate at advanced nodes, so MRAM and ReRAM are taking its place.

Connecting to the real world

MCU pins can source only small currents, so loads are driven through interface circuits. A transistor switch needs a base resistor sized from (drive voltage − 0.7 V) divided by the required base current, and power devices need a gate driver that turns a few-milliamp logic signal into amperes of gate current. Without a DAC, an analog voltage can be made by low-pass filtering PWM, giving amplitude × duty cycle. When measuring through a resistor divider, divider resistance and ADC loading must be considered, or the signal buffered.

Safety mechanisms in automotive MCUs

Automotive MCUs add hardware that detects faults rather than silently misbehaving. A window watchdog resets the system if software kicks it too late or too early. SEC-DED error-correcting code (ECC) corrects single-bit memory errors and flags double-bit errors so software can enter a safe state. Clock monitors compare the main clock against an independent oscillator, and voltage monitors with their own reference detect both under- and overvoltage. Logic and memory built-in self-test (BIST) at power-up uncovers latent faults in the safety circuits themselves before driving begins.

When a microcontroller produces an analog voltage by passing a PWM signal through a low-pass filter, what determines the output voltage?

  1. AThe duty cycle of the pulses (the fraction of each period that is on)
  2. BThe color of the pulses
  3. CThe memory capacity of the microcontroller
Show answer and explanation

Answer: A. The duty cycle of the pulses (the fraction of each period that is on)

Averaging a PWM signal with a low-pass filter gives an output of amplitude × duty cycle—about 2 V for 40% of 5 V. Resolution is set by the timer's count range, and placing the PWM frequency well above the filter cutoff reduces ripple. Since it produces analog voltages without a dedicated DAC, it is used for LED dimming, motor speed control and simple audio output, but response speed and accuracy trade off against ripple.

Which non-volatile memory has been integrated on the same chip as logic circuits to store microcontroller programs?

  1. AEmbedded flash memory
  2. BHBM
  3. CGDDR
Show answer and explanation

Answer: A. Embedded flash memory

Microcontrollers have long integrated embedded flash on the same die as logic to store programs and data. It keeps its contents without power and allows firmware updates after shipment. But it adds many process steps, such as forming floating gates, and is hard to integrate beyond about 28 nm or with high-k/metal gates, so MRAM and ReRAM, which need fewer extra steps, are replacing it.

FAQ

What is the difference between a microcontroller and a microprocessor?

A microcontroller integrates the CPU, program memory, RAM and I/O peripherals on one chip for self-contained control tasks. A microprocessor is mainly the CPU and relies on external memory and support chips, trading cost and power for computing performance.

What does a watchdog timer do in a microcontroller?

It must be cleared periodically by healthy software; if a crash or hang lets it expire, it resets the MCU automatically. A window watchdog also treats clears that come too early as faults.

How does a microcontroller output an analog voltage without a DAC?

It generates a PWM signal and passes it through a low-pass filter, so the output averages to the supply amplitude times the duty cycle. Resolution depends on the timer count range, and ripple trades off against response speed.
