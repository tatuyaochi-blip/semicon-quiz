What is Flip-flop?

The basic element of sequential circuits that stores one bit. A D flip-flop captures its input at a clock edge.

Field: Logic circuits

Flip-flop in the explanations

  • A D flip-flop captures its D input on the rising (or falling) clock edge and holds it until the next edge; changes between edges do not affect the output.

  • For a flip-flop to capture correctly, data must be stable for a certain time before the clock edge—the setup time.
