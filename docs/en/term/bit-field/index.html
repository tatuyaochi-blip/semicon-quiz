What is Bit-field?

A mechanism for declaring a member of a C struct as a field of a given number of bits, as in unsigned int x : 3; Because small values can be packed together, bit-fields are used to group flags and settings. Storing a value that does not fit in an unsigned field leaves the remainder modulo 2 to the power of the field width. Whether fields are laid out from the high or the low end of a word, and whether a field may straddle a boundary, may differ between implementations, so masks and shifts are often used instead to describe peripheral registers or communication formats.

Answer: B. Bit ordering and similar details of bit fields are implementation-defined, so another compiler may manipulate unintended bits

Bit fields read nicely, but the C standard leaves to the implementation whether bits are allocated from the top or bottom of a unit, how fields crossing boundaries are handled and the access width. Code that works with one compiler may therefore read or write different bits with another compiler or CPU. Headers supplied by microcontroller vendors are usually written with masks and shifts.
