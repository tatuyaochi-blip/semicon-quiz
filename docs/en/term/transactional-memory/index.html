What is Transactional memory?

A mechanism that runs critical sections speculatively, committing them as a whole if there is no conflict and rolling back and retrying if there is.

Japanese name: トランザクショナルメモリ

Show answer and explanation

Answer: A. Critical sections run speculatively; with no conflict with other threads they commit as a whole, and on conflict they abort and retry

In transactional memory, a critical section runs as a transaction whose writes stay tentative and invisible to others. If no other thread touched the same data, all writes commit at once at the end; on conflict, everything is rolled back and retried or the code falls back to an ordinary lock. When conflicts are rare, even coarse locks can achieve parallelism close to fine-grained locking.
