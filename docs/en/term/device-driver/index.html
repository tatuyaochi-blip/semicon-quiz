What is Device driver?

An OS component that operates a specific peripheral. It handles the device's registers and interrupts and lets applications use the device through a common interface.

Field: OS & Hardware

Device driver in the explanations

  • A device driver is the OS component that absorbs these differences: it initializes the device, reads and writes registers, sets up DMA and handles interrupts, while offering upper layers a common interface such as file-style reads and writes.
