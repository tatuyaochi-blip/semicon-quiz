What is eFuse?

One-time-programmable storage written bit by bit by blowing thin wires with current, used for per-device keys, settings and anti-rollback counters.

Japanese name: eFuse

Which method is commonly used to store keys written into a chip?

  1. AOne-time-programmable eFuses or OTP memory, or storing them encrypted in non-volatile memory
  2. BPrinting the key value on the chip surface
  3. CPlacing the key value as is in memory anyone can read externally
Show answer and explanation

Answer: A. One-time-programmable eFuses or OTP memory, or storing them encrypted in non-volatile memory

An eFuse is one-time-programmable storage written bit by bit by blowing a thin wire with a large current. Per-device keys and settings are written after manufacturing, sometimes made unreadable by software so that only the cryptographic engine can use them. Another approach stores keys in flash encrypted with a key derived from a PUF. In every approach, restricting read paths is essential.

When manufacturing many devices, why give each device its own key instead of the same key in all of them?

  1. ASo that even if one device is analyzed and its key extracted, the compromise does not spread to other devices
  2. BDifferent keys make devices run faster
  3. CManufacturing equipment cannot handle identical keys
Show answer and explanation

Answer: A. So that even if one device is analyzed and its key extracted, the compromise does not spread to other devices

If every device shares the same key, an attacker who obtains one unit and spends the time and money to extract the key endangers every device of that product. With per-device keys, a breach affects only that unit, and only its key needs revoking. Per-device keys are provisioned securely through PUFs, eFuse programming or key injection during manufacturing.
