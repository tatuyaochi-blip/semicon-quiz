What is Entry point?

The address where a program begins execution, recorded in the ELF header. In C it is usually start-up code such as _start, which initializes and then calls main.

Japanese name: エントリポイント

In a C program, which statement is correct about the address where the OS first starts execution (the entry point)?

  1. AIt is always the start of main
  2. BIt is always the first byte of the executable
  3. CIt is usually not main but start-up code such as _start, which initializes things and then calls main
Show answer and explanation

Answer: C. It is usually not main but start-up code such as _start, which initializes things and then calls main

The linker adds start-up objects supplied by the C runtime (such as crt1.o) to the program and makes the _start inside them the entry point. _start takes the command-line arguments from the stack, initializes the standard library and global objects, and then calls main. When main returns, its return value is passed to exit, which performs the shutdown steps.
