What is Measured boot?

A mechanism that cumulatively records hashes of each boot stage's software in a TPM or similar so the boot state can be verified later.

Field: Hardware Security

Measured boot in the explanations

  • In measured boot, each stage hashes the next piece of software and records it cumulatively in TPM registers (PCRs).
