What is DIMM?

A memory module that mounts several DRAM chips on a small board so it can be plugged into a slot in a PC or server.

Japanese name: DIMM

Answer: C. DIMM (memory module)

A DIMM (dual inline memory module) mounts several DRAM chips on one board; "dual" refers to the separate signals on the front and back contacts. It plugs into motherboard slots for replacement or upgrade, and the smaller laptop version is the SO-DIMM. Servers use registered DIMMs (RDIMMs) that buffer signals, and DDR5 modules carry their own power-management IC (PMIC).
