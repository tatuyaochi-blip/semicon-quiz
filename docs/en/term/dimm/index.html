What is DIMM?

A memory module that mounts several DRAM chips on a small board so it can be plugged into a slot in a PC or server.

Field: DRAM

DIMM in the explanations

  • A DIMM (dual inline memory module) mounts several DRAM chips on one board; "dual" refers to the separate signals on the front and back contacts.
