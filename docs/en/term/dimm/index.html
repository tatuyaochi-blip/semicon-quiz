What is DIMM?

A memory module that mounts several DRAM chips on a small board so it can be plugged into a slot in a PC or server.

Japanese name: DIMM

DIMM appears in 1 practice question across 1 topic, including DRAM.

Field: DRAM

Structure and the origin of the name

A DIMM (dual inline memory module) is a memory module that mounts several DRAM chips on a long, narrow printed circuit board so it can be plugged into a motherboard slot. On the earlier SIMM, the contacts on the front and back of the board were connected to the same signals; on a DIMM they carry different signals, hence 'dual'. Besides the DRAM chips, the board carries a small nonvolatile memory called the SPD, which records capacity, speed, timing and other information that the motherboard reads at startup to configure the memory. The position of the notch in the contact edge differs by generation, so a module of the wrong generation cannot be inserted by mistake.

Types and uses

Ordinary DIMMs for desktop PCs do not buffer signals and are also called UDIMMs (unbuffered DIMMs). Laptops use the shorter, smaller SO-DIMM. Servers use RDIMMs, which re-drive command and address signals through a register so that many chips can be driven, and LRDIMMs, which also buffer the data signals, allowing larger capacities. Modules with error correction (ECC) use a 72-bit width: 64 data bits plus 8 ECC bits. In DDR5, each module is split into two independent 32-bit subchannels, and the power circuitry (PMIC) is also mounted on the module.

Capacity and bandwidth

A DIMM's capacity is set by the capacity and number of DRAM chips on it. For example, a module with eight 16 Gb chips of 8-bit data width (x8) holds 16 Gb × 8 = 128 Gb = 16 GB. A set of chips that together provide the 64-bit data width is called a rank, and adding ranks increases capacity. Peak bandwidth is data rate times data width: a DDR4-3200 DIMM gives 3200 MT/s × 8 bytes = 25.6 GB/s, and DDR5-4800 gives 38.4 GB/s. Populating a DIMM on each of the CPU's memory channels multiplies bandwidth by the number of channels.

Things to watch when choosing

DIMMs of different generations, such as DDR4 and DDR5, differ in notch position, voltage and signaling and are not compatible. Even within a generation, RDIMMs and UDIMMs cannot be mixed, and whether ECC works depends on CPU and motherboard support. When DIMMs of different speeds are mixed, they generally run at the speed of the slowest. Installing more DIMMs on one channel increases the signal load and can lower the maximum supported speed. For laptops, JEDEC has also standardized CAMM2, a new thin module form factor that is easier to run at high speed.

Answer: C. DIMM (memory module)

A DIMM (dual inline memory module) mounts several DRAM chips on one board; "dual" refers to the separate signals on the front and back contacts. It plugs into motherboard slots for replacement or upgrade, and the smaller laptop version is the SO-DIMM. Servers use registered DIMMs (RDIMMs) that buffer signals, and DDR5 modules carry their own power-management IC (PMIC).

FAQ

What is the difference between a DIMM and an SO-DIMM?

Both are plug-in memory modules carrying DRAM chips. A DIMM is the longer type for desktop PCs and servers, and an SO-DIMM (small outline DIMM) is the shorter type for laptops and small PCs. They differ in pin count and notch position and do not fit each other's slots.

What is the difference between an RDIMM and a UDIMM?

An RDIMM re-drives command and address signals through a register on the module before distributing them to the DRAM chips, so it can drive many chips reliably and is used in high-capacity servers. A UDIMM has no buffer and is mainly used in PCs. They are electrically different and cannot be mixed in the same system.

What does 'dual' in DIMM mean?

It means the contacts on the front and back of the board each carry separate signals. On the previous generation, the SIMM (single inline memory module), the front and back contacts were connected to the same signals. It is unrelated to dual-channel memory, which means using two memory channels.
