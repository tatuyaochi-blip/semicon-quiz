What is BSS section?

The area for global and static variables with no initializer (or zero). Only its size is recorded in the file and it is zero-filled at load time, so it does not enlarge the executable.

Show answer and explanation

Answer: B. It holds variables with no initializer (or zero); the file records only its size, and it is zero-filled at load time

Global and static variables without an initializer start at zero by the rules of C. Storing a run of zeros in the file would be wasteful, so the .bss section records only its size, and the loader allocates and zero-fills the memory. For example, "static char buf[1000000];" does not make the executable 1 MB larger.
