What is BSS section?

The area for global and static variables with no initializer (or zero). Only its size is recorded in the file and it is zero-filled at load time, so it does not enlarge the executable.

What ends up in .bss

The C language requires every object with static storage duration, meaning globals and static variables, to start at zero if no initializer is given. Compilers place such variables, and usually also those explicitly initialized to 0, in the .bss section. Globals with a nonzero initial value go in .data, and const-qualified constants go in read-only .rodata. The static keyword does not choose the section; it only limits visibility to one file. Local automatic variables never appear in .bss, because they live on the stack and have no defined initial value.

Why .bss costs no file space

Storing a long run of zeros in the executable would only waste disk space and load time, so the .bss section records only its size and alignment. In ELF it is marked as occupying no file bytes. The loader maps the read-write segment containing .data and .bss, and where the segment's memory size exceeds its file size, the extra bytes are provided as zero-filled pages. As a result, a declaration such as static char buf[1000000]; adds about 1 MB to memory use but almost nothing to the file.

BSS on embedded systems

On a microcontroller without an operating system, nobody else zero-fills memory, so the start-up code does it. Before calling main, the reset handler typically copies initial values of .data from flash into RAM and clears the .bss range in RAM, using start and end addresses that the linker script exports as symbols. Forgetting either step leads to globals with garbage values. Tools such as the size command report text, data and bss separately, which helps estimate flash and RAM usage.

Where the name comes from

BSS is commonly expanded as block started by symbol, a name inherited from an assembler directive on early IBM mainframes that reserved an uninitialized block of storage under a label. The meaning survived into Unix object formats and later ELF, even though the directive itself is long gone. Today the name simply refers to the zero-initialized data section, alongside .text for code, .data for initialized data and .rodata for constants.

FAQ

What does BSS stand for?

BSS is usually expanded as block started by symbol, after an old assembler directive. In modern toolchains it simply names the section for zero-initialized global and static variables.

Does a large uninitialized array make the executable bigger?

No. A global or static array without an initializer goes in .bss, where only its size is recorded; the memory is allocated and zero-filled when the program is loaded.

What is the difference between .data and .bss?

The .data section holds globals and statics with nonzero initial values, which must be stored in the file. The .bss section holds those that start at zero, so it occupies memory at run time but no space for contents in the file.
