What is RTL (register-transfer level)?

A design abstraction that describes circuits by how data moves and is processed between registers. It is written in Verilog or VHDL and serves as the input to logic synthesis.

Field: IC design flow and EDA

RTL (register-transfer level) in the explanations

  • RTL design uses hardware description languages such as Verilog HDL (and its extension SystemVerilog) or VHDL to describe how data flows between registers each clock cycle.
