What is Transfer function?

The input–output relation of a linear time-invariant system expressed as the ratio G(s) = Y(s)/X(s) of the Laplace transforms of output and input with all initial values zero. It equals the Laplace transform of the impulse response. Values of s that make the denominator zero are poles and those that make the numerator zero are zeros; the pole positions show stability and speed of response. Setting s = jω gives the frequency response. For discrete-time systems it is written H(z) using the z-transform.

Japanese name: 伝達関数

Calculating with block diagrams

With transfer functions, elements in series multiply and elements in parallel add. In a negative-feedback loop with forward transfer function G(s) and feedback transfer function H(s), the closed-loop transfer function is G(s)/(1 + G(s)H(s)). The product G(s)H(s) is called the loop transfer function (open-loop transfer function) and is the starting point for examining stability and stability margins.

Typical forms

An RC low-pass filter is the first-order system 1/(1 + sRC), while RLC circuits and motor position loops are often represented as second-order systems. An integrator is 1/s, a differentiator s and a time delay L is e^(−Ls). A transfer function whose denominator degree is at least the numerator degree is called proper, and real physical systems normally take this form.

What poles and zeros tell you

A pole p produces a component e^(pt) in the response, so the system is stable if all poles have negative real parts. Poles closer to the imaginary axis decay more slowly, and larger imaginary parts oscillate faster. Zeros change the shape of the response; a system with a zero in the right half of the s-plane can show an inverse response, in which the step response first moves the wrong way, and fast control becomes difficult.

Try it: questions about Transfer function

When the frequency response of a discrete-time LTI system is obtained from its transfer function H(z), along which of the following is z moved?

  1. AAlong the unit circle of the z-plane (z = e^(jω), |z| = 1)
  2. BAlong the positive real axis of the z-plane (z = r, where r is a real number greater than 0)
  3. CAlong the imaginary axis of the z-plane (z = jω)
Show answer and explanation

Answer: A. Along the unit circle of the z-plane (z = e^(jω), |z| = 1)

The frequency response is H(z) with z = e^(jω) substituted; as ω goes from −π to π, z travels once around the unit circle. z = 1 (ω = 0) corresponds to DC and z = −1 (ω = π) to the Nyquist frequency. For the continuous-time Laplace transform the frequency response is found on the imaginary axis s = jω, and in discrete time the unit circle plays that role.

Which of the following is the transfer function H(z) = Y(z)/X(z) of the system described by the difference equation y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1]?

  1. A(1 + 0.5z⁻¹)/(1 + 0.25z⁻¹)
  2. B(1 − 0.25z⁻¹)/(1 + 0.5z⁻¹)
  3. C(1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)
Show answer and explanation

Answer: C. (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)

A delay of one sample corresponds to multiplying by z⁻¹ in the z-transform, so transforming both sides gives Y(z) = X(z) + 0.5z⁻¹X(z) + 0.25z⁻¹Y(z). Collecting the Y(z) terms on the left gives (1 − 0.25z⁻¹)Y(z) = (1 + 0.5z⁻¹)X(z), so H(z) = (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹). The numerator holds the coefficients on the input side and the denominator those of the output feedback; z = 0.25, which makes the denominator 0, is a pole, and z = −0.5, which makes the numerator 0, is a zero.

FAQ

What is the difference between a transfer function and a frequency response?

A transfer function G(s) is a function of the complex variable s, and restricting s to jω on the imaginary axis gives the frequency response G(jω). Plotting the magnitude and phase of the frequency response against frequency gives a Bode plot.

Do nonlinear systems have transfer functions?

Not as they are. Linearizing around an operating point allows a transfer function to be used for small changes near that point. Strong nonlinearities such as saturation and dead zones are handled by other methods.
