What is Pulse-width modulation (PWM)?

A method that adjusts average voltage or power by varying the high time of an output while keeping the period constant. Used to dim LEDs and control motor speed.

Japanese name: PWM(パルス幅変調)

Try it: questions about Pulse-width modulation (PWM)

When a microcontroller produces an analog voltage by passing a PWM signal through a low-pass filter, what determines the output voltage?

  1. AThe duty cycle of the pulses (the fraction of each period that is on)
  2. BThe color of the pulses
  3. CThe memory capacity of the microcontroller
Show answer and explanation

Answer: A. The duty cycle of the pulses (the fraction of each period that is on)

Averaging a PWM signal with a low-pass filter gives an output of amplitude × duty cycle—about 2 V for 40% of 5 V. Resolution is set by the timer's count range, and placing the PWM frequency well above the filter cutoff reduces ripple. Since it produces analog voltages without a dedicated DAC, it is used for LED dimming, motor speed control and simple audio output, but response speed and accuracy trade off against ripple.

A PWM signal has a period of 1000 counts, with the output high (1) for 250 counts of each period. What is the duty cycle?

  1. A75%
  2. B25%
  3. C250%
Show answer and explanation

Answer: B. 25%

The duty cycle is the fraction of each period during which the output is high: 250 ÷ 1000 = 25%. PWM (pulse-width modulation) adjusts average voltage or power by changing the high time while keeping the period constant. A microcontroller timer switches the output by comparing its counter with a compare value, so it can produce PWM continuously without CPU involvement.
