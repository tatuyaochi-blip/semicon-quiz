Information Theory and Coding Basics: key points

"How many bits is this information worth?" "How small can these data be made?" "How can bits corrupted by noise be found and fixed?" Information theory and coding theory, founded by Shannon, answer questions like these. They are at work everywhere in computers and communication: file compression, memory ECC, error correction on communication channels, CRCs in storage devices and more.

This topic checks through calculations the amount of information −log₂ p and entropy, the condition for maximum entropy, conditional entropy and mutual information, redundancy, and the number of bits needed to distinguish items. It goes on to fixed-length and variable-length codes, prefix codes and the Kraft inequality, how to build a Huffman code and its average code length, efficiency compared with the entropy, the effect of coding symbols together, run-length encoding and the LZ77 method, and when to use lossless or lossy compression. The second half deals with parity and vertical and horizontal parity, the weakness of checksums, calculating CRC check bits and detecting burst errors, Hamming distance and the number of bit errors that can be detected and corrected, locating an error with the syndrome of the Hamming (7, 4) code, the number of SECDED check bits, code rate, interleaving, ARQ and FEC, and the capacity of the binary symmetric channel and the channel coding theorem, and it ends with Gray code conversion. It helps with the basic theory (information theory and communication theory) of IT certification exams such as Japan's Fundamental and Applied Information Technology Engineer Examinations. The values in the calculation questions, including those of the wrong choices and the Huffman trees, have been checked by computing them in Python. Binary numbers and floating point are covered in "Computer Arithmetic"; calculating a parity bit and the properties of Gray code in "Logic circuits"; converting binary to Gray code in "Timing analysis and CDC"; the probability of errors that parity misses in "Probability, Statistics and Queueing"; channel capacity with the Shannon–Hartley theorem in "Wireless Communication Basics"; memory ECC in "DRAM"; 8b/10b encoding and the CRC of PCI Express in "I/O Interfaces & Buses"; Base64 and gzip in "Web Technology Basics"; cross-entropy in "Machine Learning Basics"; and hashes and cryptography in "Information Security Basics".
