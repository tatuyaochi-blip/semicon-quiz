Embedded Systems & Firmware: key points

New to this topic? Start with: What Is a Microcontroller? Tiny Computers in Everyday Things / How Do Touchscreens Work? Capacitive Touch Explained

Inside appliances, cars and industrial equipment, firmware running on microcontrollers controls the device. Firmware reads and writes peripheral registers directly, using bit manipulation to change specific bits, to drive pin I/O (GPIO), timers and communication peripherals.

Embedded code has its own rules, such as keeping interrupt handlers short and declaring shared variables volatile. From UART, SPI and I2C communication and RTOSes that switch tasks by priority to the boot loader that runs first at power-on and the watchdog that recovers from runaway code, this topic covers the software closest to the hardware.
