OS & Hardware: key points

An operating system (OS) is software that lets many programs share hardware such as CPUs, memory and I/O devices safely. To support it, CPUs provide privileged modes usable only by the OS, interrupt and exception mechanisms, and hardware that walks page tables for virtual memory.

Applications ask the OS for services through system calls; the OS switches between programs on timer interrupts (context switches) and responds to page faults by bringing the needed pages into memory. From device drivers and memory-mapped I/O to virtualization with hypervisors, this topic covers how hardware and software cooperate.
