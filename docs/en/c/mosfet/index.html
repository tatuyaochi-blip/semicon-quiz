MOSFET: key points

A MOSFET is a transistor that uses the gate voltage to create an inversion layer (channel) at the semiconductor surface and control the current between source and drain. Because the gate is separated by a thin insulator, almost no steady gate current flows.

Threshold voltage, the linear and saturation regions, short-channel effects, and CMOS circuits that combine nMOS and pMOS are key topics for understanding LSIs.
