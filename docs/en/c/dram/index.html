DRAM: key points

DRAM stores one bit with one transistor and one capacitor. Its simple cell structure makes high density easy, so it is widely used as computer main memory.

The charge in the capacitor is gradually lost through leakage current, so the data must be rewritten periodically (refresh). Reading also disturbs the cell's charge, so the data is amplified by a sense amplifier and then written back.
