I/O Interfaces & Buses: key points

Inside a computer, components such as the CPU, memory, GPU, storage and network are connected by various interfaces. For high-speed links, serial transmission, which sends very fast signals over a few wires, has replaced parallel buses with many wires, enabled by transceiver circuits called SerDes.

This topic covers calculating bandwidth from PCI Express lane count and per-lane speed, encoding efficiency, USB basics, on-chip buses such as AXI that connect blocks within a chip, and CXL for sharing memory. Understanding that bandwidth and latency are different quantities reveals what actually limits performance.
