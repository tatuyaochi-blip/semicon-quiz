GPU Programming: key points

A GPU is a processor that excels at running thousands to tens of thousands of threads simultaneously, applying the same operation to large amounts of data. Programs express parallelism in a hierarchy of grids, blocks and threads, and the hardware executes groups of about 32 threads, called warps, in lockstep.

Getting performance requires coalesced memory access, where neighboring threads read neighboring addresses; on-chip shared memory used within a block; avoiding divergence within a warp; and enough occupancy to hide memory latency. This topic focuses on principles that do not depend on product generations.
