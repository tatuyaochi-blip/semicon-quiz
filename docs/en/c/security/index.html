Information Security Basics: key points

New to this topic? Start with: What Does HTTPS Mean? What the Padlock Does and Doesn't Do / How Are Passwords Cracked? Why Length and Uniqueness Matter

Protecting information means keeping it in a state where only authorized people can see it (confidentiality), its contents stay correct (integrity) and it can be used when needed (availability). To achieve this, technologies such as encryption, hash functions and digital signatures are combined with authentication, access control, backups and organizational management.

This topic covers threats, vulnerabilities and risk and how to respond to risk, when to use symmetric-key or public-key cryptography and how to calculate the number of keys, hash functions and password storage, digital signatures and certificates, multi-factor authentication and the error rates of biometrics, and the principle of least privilege. It also explains malware, phishing and web attacks such as SQL injection and cross-site scripting in terms of how they work and how to defend against them, which helps with the security section of IT certification exams such as Japan's Fundamental and Applied Information Technology Engineer Examinations. Hardware-related security is covered in the Hardware Security topic.
