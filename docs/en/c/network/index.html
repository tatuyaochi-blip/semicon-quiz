Computer Networking Basics: key points

Even opening a single web page sets many mechanisms to work in turn: looking up an address from a name, choosing a route, delivering data reliably and protecting it with encryption. Computer networks organize these functions into layers, with each layer taking care of its own role only.

This topic covers the OSI reference model and the TCP/IP layers, MAC addresses and switches, IP addresses and subnet mask calculations, ARP and routing, TCP's three-way handshake, flow control and congestion control, and DNS, DHCP and TLS. It also covers calculating transfer times from bandwidth and latency, and the basics of wireless LAN, firewalls and VPNs, which helps with the network section of IT certification exams such as Japan's Fundamental Information Technology Engineer Examination.
