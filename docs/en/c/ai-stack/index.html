AI Hardware & Software Stack: key points

Most of the computation in neural networks is large matrix multiply-accumulate. AI hardware therefore lines up many multiply-accumulate units and is designed to reuse data as much as possible to reduce traffic to memory. Training requires far more computation and memory than inference, and also needs higher numerical precision.

Performance is not set by the number of compute units alone. Arithmetic intensity, the amount of computation per byte of data, together with the roofline model, shows whether a workload is limited by compute or by memory bandwidth. This topic also covers how AI compilers and inference runtimes unlock hardware performance through quantization, operator fusion and tiling.
