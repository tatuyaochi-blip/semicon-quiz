Etching: key points

Etching removes the parts of a film not covered by a mask such as resist to form patterns. There is wet etching, which uses chemical solutions, and dry etching, which uses plasma and similar means.

To process fine patterns accurately, anisotropy (etching only vertically) and selectivity (etching only the target film) are important. Reactive ion etching (RIE) is a representative technique.
