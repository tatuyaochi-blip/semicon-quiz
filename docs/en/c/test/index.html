Testing and inspection: key points

New to this topic? Start with: How Are Chips Made? The Semiconductor Manufacturing Process / Semiconductor Manufacturing Equipment: Types and Key Makers

Semiconductor products go through several stages of testing during and after manufacturing. Wafer testing before dicing finds defective chips, and final testing after packaging guarantees the characteristics of shipped products.

Burn-in, which removes early failures, and design for testability (DFT), which builds test features into circuits, keep quality high while holding down test costs.
