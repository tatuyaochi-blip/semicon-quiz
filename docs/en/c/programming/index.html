Programming Basics (Pseudocode Tracing): key points

To read a program's behavior accurately, you need to be able to follow by hand (trace) how the values of variables change line by line. Small oversights, such as miscounting a loop by one, losing a value through the order of assignments, or forgetting that integer division discards the fractional part, lead to wrong results and bugs.

This topic centers on questions that ask you to trace short programs and give the result. The programs follow the pseudo-language used in Part B of Japan's Fundamental Information Technology Engineer Examination, with type declarations, assignment with ←, if, while and for, and array indices that start at 1. The wrong choices are values produced by typical mistakes, such as getting the final value of a loop wrong or misreading operator precedence, and the explanations show which mistake each choice comes from.
