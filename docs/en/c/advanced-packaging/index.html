Advanced packaging (3D and chiplets): key points

As scaling alone has become less able to raise performance, technologies that combine several chips in one package are attracting attention. Building systems from small chips divided by function (chiplets) also has advantages in yield and cost.

3D integration, which stacks chips vertically with TSVs, and 2.5D integration, which places a processor and HBM side by side on an interposer, are used in high-performance chips for AI.
