SRAM and flash memory: key points

SRAM holds data in a latch made of two cross-coupled inverters. It needs no refresh and is fast, so it is used for CPU caches, but each bit takes up more area.

Flash memory is non-volatile: data remains even when the power is off. There is NAND flash, suited to high-capacity storage, and NOR flash, which offers fast random reads. Storing multiple bits per cell (multi-level cells) is also advancing.
