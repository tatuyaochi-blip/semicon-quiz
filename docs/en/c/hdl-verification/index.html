HDL & Verification: key points

Digital circuits are written in hardware description languages (HDLs) such as Verilog and SystemVerilog. The code looks like a program, but it describes hardware that operates concurrently. HDLs have their own rules: which constructs can be synthesized into circuits, when to use blocking versus nonblocking assignments, and how missing conditions create unintended latches.

Whether a circuit is correct is checked with a testbench that drives inputs. From writing state machines and automatically checking properties with assertions to measuring verification completeness with coverage and generating circuits from C with high-level synthesis, this topic covers the basics of designing and verifying with HDLs.
