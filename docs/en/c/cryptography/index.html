Applied Cryptography: key points

A secure algorithm alone does not make cryptography useful. Mistakes in how it is used, such as reusing a nonce, encrypting in ECB mode or failing to check the host name on a certificate, can easily break even strong cryptography. This topic goes one level deeper into how cryptography is combined and used inside real systems and protocols.

It starts with symmetric-key cryptography: block and stream ciphers, the block and key lengths of AES, modes of operation (ECB, CBC, CTR and GCM) and the requirements on initialization vectors and nonces, padding and padding oracle attacks, and authenticated encryption (AEAD), checking by calculation how plaintext leaks when a nonce is reused in CTR mode. It continues with SHA-2 and SHA-3, length extension attacks and HMAC, the limits of 64-bit blocks under the birthday attack, and key derivation functions, then works through RSA and Diffie–Hellman key exchange with small numbers to examine the discrete logarithm problem, man-in-the-middle attacks, guideline key lengths for elliptic-curve cryptography, forward secrecy and the handling of the random number in ECDSA. The second half covers certificate authorities and certificate chains, host name checks, Certificate Transparency, the changes and cipher suites of TLS 1.3, replay with 0-RTT and mutual TLS, and, for post-quantum cryptography, Grover's algorithm and key length, ML-KEM, ML-DSA and SLH-DSA standardized in August 2024, key encapsulation mechanisms, hybrid key exchange and how to think about the timing of migration. It ends with key management: HSMs, envelope encryption, key rotation and crypto agility. It helps with the security sections of IT certification exams such as Japan's Applied Information Technology Engineer Examination and Registered Information Security Specialist Examination. The values in the calculation questions, including those of the wrong choices, have been checked by computing them in Python. The basics of symmetric-key and public-key cryptography, counting keys, the properties of hash functions and password storage, and the difference between digital signatures and MACs are covered in "Information Security Basics"; side-channel attacks and constant-time implementation, AES-NI, TPMs and true random number generators in "Hardware Security"; Shor's algorithm and the scale of quantum computers in "Quantum Computing Hardware"; the number of round trips in TLS and what HTTPS protects in "Computer Networking Basics"; JWT and OAuth in "Web Technology Basics"; and entropy in "Information Theory and Coding Basics".
