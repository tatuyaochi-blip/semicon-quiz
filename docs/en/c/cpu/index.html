CPUs and architecture: key points

A CPU processes a program by repeatedly fetching, decoding and executing instructions. Most computers use the von Neumann architecture, in which programs and data are stored in the same main memory.

Performance-enhancing techniques include pipelining, which overlaps stages of instruction processing; caches, which bridge the speed gap with main memory; and parallel processing with multiple cores. Semiconductor scaling has supported all of these advances.
