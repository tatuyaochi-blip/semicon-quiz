Timing analysis and CDC: key points

New to this topic? Start with: RC Time Constant Explained: Wire Delay and Clock Speed

For a synchronous circuit to work correctly, data must arrive on every path between flip-flops in time to meet setup and hold times. Static timing analysis (STA) computes the slack of each path from the clock and input/output delay constraints given in SDC, accounting for skew, jitter and manufacturing variation, and finds violations.

Between asynchronous clocks, on the other hand, timing cannot be guaranteed and metastability is unavoidable. Designing and verifying clock domain crossings (CDC) that pass signals safely — with two-flip-flop synchronizers, handshakes and asynchronous FIFOs with Gray code pointers — is also a fundamental part of logic design.
