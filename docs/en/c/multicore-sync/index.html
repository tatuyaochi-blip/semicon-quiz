Multicore & Synchronization: key points

In a multicore CPU, several cores on one chip share the same memory while each keeps its own caches. Coherence protocols such as MESI manage cache-line states so that no core keeps using stale data after another core writes it.

Beyond that, you need to understand memory consistency models, which define the order in which writes become visible to other cores, atomic instructions that let cores update values safely, and locks and memory barriers. This topic also covers pitfalls such as false sharing and data races, which make programs that look correct run slowly or misbehave.
