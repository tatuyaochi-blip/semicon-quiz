Compilers: key points

A compiler translates programs written by people into machine code a CPU can execute. It passes through lexical analysis, which splits source code into tokens; parsing, which builds a tree according to the grammar; and semantic analysis, which checks types and names, before converting the program to an intermediate representation (IR).

On the IR it applies optimizations such as constant folding, common subexpression elimination, inlining, loop unrolling and vectorization, then generates code suited to the CPU through register allocation and instruction scheduling. Understanding these optimizations shows how to write fast code and how to get the most out of the hardware.
