Linkers, Loaders & Executables: key points

What a compiler produces is an object file, which cannot run on its own. A linker gathers object files and libraries, binds names of functions and variables (symbols) to actual addresses (symbol resolution), patches those addresses into instructions (relocation), and produces an executable.

A loader reads the executable into memory, sets up the text, data, BSS, heap and stack regions, and starts the program. Dynamic linking, which binds libraries at run time, and position-independent code (PIC), which runs at any address, help both to save memory and to improve security.
