Hardware Security: key points

Even when software is free of bugs, information can leak through properties of the hardware. Vulnerabilities known as Spectre and Meltdown exploit the fact that speculative execution and caches, which exist to improve performance, leave traces of data that should be invisible. Side-channel attacks can also infer cryptographic keys from tiny differences in power consumption or execution time.

Defensive technologies include secure boot, which starts only trusted software; trusted execution environments (TEEs), isolated even from the OS; PUFs, which use each chip's manufacturing variation like a fingerprint; and countermeasures against malicious circuits inserted during design or manufacturing (hardware Trojans). The goal is to understand principles and defenses, not attack procedures.
