Web Technology Basics: key points

When you open a URL in a browser, an HTTP request reaches a server, and the browser builds the screen from the HTML, CSS and JavaScript that come back. The web is made of many technologies working together: cookies that keep you logged in, APIs that connect to other services, and caches and CDNs that speed up display.

This topic covers the shape of HTTP requests and responses, the safety and idempotency of methods, status codes, cache control with headers, and the differences between HTTP/1.1, HTTP/2 and HTTP/3. It then deals with managing state with cookies, sessions and JWTs, OAuth 2.0 and OpenID Connect, REST APIs, the structure of URLs, percent-encoding and JSON, and WebSocket and webhooks. On the browser side, it covers the DOM, the CSS box model and specificity, the processing up to the first display, the JavaScript event loop, the same-origin policy and CORS, Service Workers and responsive design; on the delivery side, browser and CDN caches, compression and transfer-time calculations, Core Web Vitals, image formats, web and application servers, reverse proxies, and SSR, CSR and SSG. It also helps with the network and web-system sections of IT certification exams such as Japan's Fundamental and Applied Information Technology Engineer Examinations. How TCP/IP, DNS and TLS work is covered in "Computer Networking Basics", attacks and countermeasures such as XSS, CSRF and SQL injection in "Information Security Basics", and the design of load balancing and redundancy in "System Architecture and Reliability".
