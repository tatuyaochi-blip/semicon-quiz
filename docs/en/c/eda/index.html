IC design flow and EDA: key points

IC design proceeds by deciding the specification, describing the circuit at register-transfer level (RTL) in a hardware description language, converting it into a netlist of gates by logic synthesis, and creating the layout by place and route.

Each stage requires simulation with EDA tools, static timing analysis (STA) and verification. The larger the design, the greater the verification effort.
