Computer Arithmetic: key points

Computers represent numbers with a finite number of bits, so both range and precision are limited. Whereas fixed point keeps the binary point in a fixed position, IEEE 754 floating point splits a number into sign, exponent and significand to cover values from tiny to huge. It is important to understand normalization, subnormal numbers, rounding modes and special values such as infinity and NaN.

Floating-point calculations incur rounding error, and subtracting nearly equal numbers causes cancellation, which loses significant digits. AI uses short formats such as bfloat16, FP16, FP8 and INT8. Along with number formats, this topic covers the circuits that implement arithmetic in hardware, such as multipliers, dividers and carry-lookahead adders.
