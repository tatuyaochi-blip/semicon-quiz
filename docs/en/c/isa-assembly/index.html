ISA & Assembly: key points

An instruction set architecture (ISA) is the contract between software and hardware. It defines which instructions exist, how they are encoded as bits, and how registers and memory are specified. Any CPU that honors the same ISA can run the same programs, however different its internals.

Assembly language writes machine instructions in human-readable form. Knowing the core RISC-V instructions, register usage, how arguments and return values are passed between functions (the calling convention) and how stack frames are built shows you what compilers generate and how programs actually run on a CPU.
