DRAM vs SRAM: Key Differences Explained

DRAM stores each bit as charge on a tiny capacitor, so it is dense and cheap but must be refreshed. SRAM stores each bit in a latch built from transistors, so it is faster and needs no refresh, but takes much more area per bit. That is why computers use DRAM for large main memory and SRAM for small, fast caches.

AspectDRAMSRAM
Storage elementOne transistor and one capacitor (1T1C). The bit is the presence or absence of charge on the capacitorUsually six transistors (6T): two cross-coupled inverters forming a latch, plus two access transistors
RefreshRequired. Charge leaks away, so every row must be read and rewritten periodically (typically within 64 ms)Not required. The latch holds its data as long as power is applied
Without powerData is lost (volatile)Data is lost (volatile)
Area per bitSmall (a cell is about 6F², where F is the minimum feature size)Large (an order of magnitude or more bigger than DRAM)
SpeedSlower. A row must be activated and later precharged, so an access takes tens of nanosecondsFast. On-chip SRAM can be accessed in about a nanosecond, a few clock cycles
Cost per bitLowHigh (because of the larger area)
Standby powerNeeds refresh even when idle (reduced by self-refresh modes)No refresh, but transistor leakage in a large array adds up
ManufacturingUses deep capacitor structures and high-k dielectric films, and is made in dedicated memory fabsBuilt in a standard logic CMOS process, so it can sit on the same chip as the processor
Typical capacitySeveral to tens of gigabits per chipKilobytes to tens of megabytes per cache level in a typical processor
Typical usesMain memory (DDR, LPDDR) and graphics memory (GDDR, HBM)CPU and GPU caches, register files and small on-chip buffers

Figures are typical orders of magnitude and vary by process generation and product.

When to use which

DRAM
When you need a lot of memory at a low cost per bit and can tolerate some latency: main memory in PCs, servers and smartphones, and graphics memory for GPUs.
SRAM
When speed matters most and the capacity can be small: CPU caches, register files, and small buffers where you do not want refresh circuitry.
Together
Real computers use both. A fast SRAM cache holds frequently used data and hides the latency of the slower DRAM.
