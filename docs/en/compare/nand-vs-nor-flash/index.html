NAND vs NOR Flash: Differences and Uses

Both are non-volatile flash memories, but they are wired differently. NOR flash connects its cells in parallel, so it offers fast random reads and can run code in place, but it is expensive per bit. NAND flash connects its cells in series, so it packs far more bits into the same area and is cheap, but it reads and writes in pages and needs error correction. That is why NAND stores your data and NOR stores firmware.

When to use which

NAND flash
When you need a large amount of cheap, non-volatile storage and can read and write in pages: SSDs, phones, cameras, memory cards.
NOR flash
When you need to store program code that a processor reads directly and reliably, and the capacity is modest: boot ROM, firmware, small embedded systems.
Together
Many devices use both: a small NOR chip holds the boot code, which then loads the operating system from a large NAND device.

FAQ

Why is NAND flash cheaper than NOR flash?

NAND cells are connected in series strings and share contacts, so each bit takes much less area. Together with 3D stacking and multi-bit cells, this gives high density and a low cost per bit. NOR cells are wired in parallel and take more area.

Can a processor run code directly from NAND flash?

Not directly. NAND is read in pages and has bit errors, so code is usually copied to RAM first. NOR flash supports execute in place (XIP), which is why it stores boot code and firmware.

Which flash is used in SSDs and phones?

NAND flash. SSDs, USB drives, memory cards and phone storage such as eMMC and UFS all use NAND because of its low cost and high capacity.

Does NAND flash wear out faster than NOR?

Generally yes. NAND endurance ranges from about 100,000 cycles (SLC) down to around 1,000 (QLC), while NOR typically lasts around 100,000 cycles. NAND controllers use wear leveling and error correction to extend its life.

Check your understanding

Compared with NOR flash, which is a characteristic of NAND flash memory?

  1. AFast random access, suitable for executing program code directly
  2. BCells are connected in series, so it is easy to make dense and suits high-capacity storage
  3. CIt is volatile memory that loses data when the power is off
Show answer and explanation

Answer: B. Cells are connected in series, so it is easy to make dense and suits high-capacity storage

NAND flash strings dozens of cells in series and omits per-cell contacts, so area per bit is small and it suits high-capacity SSDs and memory cards. Reading through the series string is slower, though, so access is page-based. NOR flash connects each cell in parallel to the bit line, giving fast random reads suited to executing code in place. Both are non-volatile.

What is a typical use of NOR flash memory?

  1. AStoring large videos and photos
  2. BMain memory of a PC
  3. CStoring program code for devices (such as boot programs)
Show answer and explanation

Answer: C. Storing program code for devices (such as boot programs)

NOR flash connects each cell in parallel to the bit line for fast random access, so a CPU can fetch and run code directly from it (execute in place, XIP). It is used for boot code, microcontroller firmware and automotive control software. Capacities are small (a few Mbit to a few Gbit) and cost per bit is higher than NAND, so bulk data storage uses NAND.

What is the unit in which data is erased in NAND flash memory?

  1. ABit
  2. BBlock
  3. CByte
Show answer and explanation

Answer: B. Block

NAND reads and programs by page (around 16 KB), but erases only by block—hundreds to thousands of pages, several to tens of MB—because erase applies high voltage to an entire well to remove electrons in bulk. Even partial updates cannot overwrite in place: new data goes to a free page, the old page is marked invalid, and garbage collection later erases blocks in bulk.

Key terms explained

NAND flash memory
Non-volatile memory in which memory cells are connected in series. It is dense and easy to scale to large capacities, and is used in SSDs and memory cards.
NOR flash memory
Flash memory with cells connected in parallel. Random reads are fast, and it is used to store programs for microcontrollers and the like.
3D NAND
NAND flash in which memory cells are stacked vertically in many layers to increase capacity. It was introduced to get past the limits of planar scaling, and layer counts now exceed 200.
Nonvolatile memory
Memory that retains stored data when power is removed, such as flash memory and MRAM. DRAM and SRAM are volatile.
