MRAM vs ReRAM vs PCM vs FeRAM: Emerging Memories Compared

These four emerging non-volatile memories all try to combine the speed of RAM with data retention without power. They differ in what stores the bit: the magnetization of a thin film (MRAM), the resistance of a filament in an oxide (ReRAM), the crystalline or amorphous state of a material (PCM) or the polarization of a ferroelectric (FeRAM). None has replaced DRAM or flash broadly yet, but each has found a niche.

When to use which

MRAM
When you need non-volatile memory with flash-like retention but DRAM-like speed and almost unlimited endurance, for example embedded memory or frequent logging.
ReRAM
When you want a simple, dense, low-voltage cell, including for in-memory computing that does multiply-accumulate in the memory array.
PCM
When you want a denser memory between DRAM and flash, and can accept higher write energy.
FeRAM
When you need very low-power, fast, high-endurance memory in small amounts, such as smart cards and sensors.
