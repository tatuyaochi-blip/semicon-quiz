ASIC vs FPGA vs SoC: What Is the Difference?

These three terms describe different things. An ASIC is a chip custom-designed for one application. An FPGA is a chip whose logic you can reprogram after manufacturing. An SoC (system on chip) is a chip that integrates a whole system, such as CPU cores, a GPU, memory controllers and I/O. The terms overlap: a smartphone SoC is usually built as an ASIC, and some FPGAs include processor cores, which makes them SoCs too.

AspectASICFPGASoC
What it isA chip designed and manufactured for one specific applicationA chip with programmable logic blocks and interconnect that you configure after manufacturingA chip that integrates the main parts of a system: processor cores, memory controllers, I/O and accelerators
FlexibilityFixed once manufacturedReconfigurable, even in the fieldHardware is fixed, but the processors run software that can be updated
Performance and power efficiencyBest: the logic is tailored to the taskIn between: the programmable fabric costs area, speed and powerHigh, thanks to dedicated accelerators for common tasks
Up-front costVery high: design, verification and masks can cost millions to hundreds of millions of dollars at advanced nodesLow: you buy a ready-made deviceHigh, similar to an ASIC, because it is a custom chip
Unit cost at high volumeLowestHigher per unitLow
Time to marketLong: design, verification and fabrication take many months to yearsShort: a design can be running in days or weeksLong
Fixing a design bugExpensive: usually needs a new set of masks (a respin)Easy: reprogram the deviceExpensive, though some problems can be worked around in software
Typical usesCryptocurrency miners, network and storage controllers, dedicated codecsPrototyping, low-volume products, telecom and test equipment, hardware accelerationSmartphones, tablets, game consoles and many embedded devices

Figures are typical orders of magnitude and vary by process generation and product.

When to use which

ASIC
When the volume is high, the function is stable and you need the best performance and power efficiency per unit cost.
FPGA
When the volume is low, the requirements may change, or you need to start quickly: prototypes, early products, specialized equipment.
SoC
When you want a complete product in one chip, such as a phone. In practice an SoC is designed as an ASIC, and FPGAs are often used to prototype it before manufacturing.
