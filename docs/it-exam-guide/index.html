基本情報技術者試験・応用情報技術者試験のテクノロジ系を、このサイトの問題で学ぶ

基本情報技術者試験と応用情報技術者試験のテクノロジ系には、論理回路や数の表し方、CPU、メモリ、OSなど、ハードウェアに近い内容が含まれています。このページでは、それらの範囲を当サイトの分野・用語・練習問題に対応づけて紹介します。

このページの使い方

基本情報技術者試験と応用情報技術者試験は、IPA(情報処理推進機構)が実施する情報処理技術者試験の区分です。試験の範囲はシラバスで定められており、テクノロジ系には、基礎理論、コンピュータシステム、技術要素(データベース、ネットワーク、セキュリティなど)、開発技術といった大きな分類があります。

このページの分け方は、シラバスの分類をもとに、当サイトで学びやすいようにまとめた目安です。各項目の分野名を開くと説明と問題の一覧が、「10問解く」を押すとその分野から10問がランダムに出題されます。用語名を開くと、用語の説明と、その用語が出てくる問題を確かめられます。

当サイトの問題は、すべて当サイトが作ったオリジナルの3択問題で、試験の過去問題ではありません。出題の形式や難しさも本試験とは異なります。仕組みを理解するための補助教材として使い、試験対策の参考書や過去問題と組み合わせてください。

このサイトで学べる範囲

  • 数の表し方と計算(2進数、2の補数、浮動小数点数と誤差)
  • 論理回路(論理演算、組み合わせ回路、順序回路)
  • CPUの構成と命令の実行(パイプライン、命令セット、アドレッシング)
  • メモリ階層(キャッシュメモリ、主記憶、フラッシュメモリ)と入出力
  • OSとハードウェアの関わり(割り込み、仮想記憶、プロセスの切り替え、排他制御)
  • 性能の評価(CPI、アムダールの法則、スループット)
  • コンパイラ、リンカ・ローダなどの言語処理系
  • 組込みシステム、ハードウェア寄りのセキュリティ、AIを動かすハードウェア
  • 情報セキュリティの基礎(3要素とリスク、共通鍵暗号と公開鍵暗号、ハッシュ関数とデジタル署名、認証、Webの攻撃と対策)
  • データベースの基礎(SQLの検索・集計・結合、正規化とE-R図、トランザクションと排他制御、障害回復、インデックス)
  • ネットワークの基礎(TCP/IPの階層、IPアドレスとサブネットの計算、ルーティング、TCPとUDP、DNS・DHCP、TLS)

このサイトでは扱っていない範囲

次の範囲は、当サイトではほとんど扱っていません。試験対策の参考書や過去問題などで学んでください。

  • ネットワークのうち、ネットワーク機器の詳しい設定、無線LANの規格の詳細、ネットワーク管理などの細かい範囲
  • 情報セキュリティ管理の規格の詳細や、セキュリティ関連の法律・制度
  • アルゴリズムとプログラミング、ソフトウェアの開発手法・設計・テスト
  • 確率・統計、待ち行列などの応用数学
  • マネジメント系(プロジェクトマネジメント、サービスマネジメント、監査)とストラテジ系(企業活動、法務、システム戦略)

基礎理論: 数値表現・論理回路

2進数・16進数の変換、2の補数による負の数の表し方、シフト演算は、計算問題の土台になります。浮動小数点数では、符号・指数部・仮数の構成と、桁落ちや情報落ちのような誤差が起きる理由を押さえておきましょう。論理回路では、真理値表から論理式を作り、ド・モルガンの定理で変形し、半加算器・全加算器やフリップフロップの働きを説明できるようにしておくと役立ちます。

  • 計算機算術 10問解く
  • 論理回路 10問解く

主な用語:

2の補数 IEEE 754 桁落ち ド・モルガンの定理 全加算器 フリップフロップ

コンピュータ構成要素: CPU・メモリ・入出力

CPUについては、命令の取り出しから実行までの流れ、パイプライン処理で処理が速くなる理由と、分岐などで流れが乱れる理由を理解しておきましょう。メモリでは、キャッシュメモリが速さを補う仕組みと、ヒット率から平均のアクセス時間を求める計算がよく使われます。入出力では、割り込みやDMAによって、CPUの負担を減らしながら周辺装置とデータをやり取りする仕組みを押さえておくと役立ちます。

  • CPU・アーキテクチャ 10問解く
  • 命令セット・アセンブリ 10問解く
  • メモリ階層と性能 10問解く
  • DRAM 10問解く
  • SRAM・フラッシュメモリ 10問解く
  • インターフェース・バス規格 10問解く

DRAMやフラッシュメモリの分野には、セルの構造など試験より詳しい内容も含まれます。まずはCPUとメモリ階層の分野から始めるとよいでしょう。

主な用語:

パイプライン処理 アドレッシングモード キャッシュメモリ 平均メモリアクセス時間(AMAT) 割り込み DMA(ダイレクトメモリアクセス)

システム構成要素・ソフトウェア: OS・性能・信頼性

OSについては、仮想記憶とページング、ページの置き換え、プロセスの切り替え、セマフォなどによる排他制御とデッドロックが中心的な話題です。性能では、CPIやクロック周波数から処理時間を求める計算や、並列化の効果の限界を表すアムダールの法則を押さえておきましょう。コンパイラやリンカ・ローダの分野は、プログラムが実行できる形になるまでの流れを理解するのに役立ちます。

  • OSとハードウェア 10問解く
  • マルチコアと同期 10問解く
  • 性能評価・プロファイリング 10問解く
  • コンパイラ 10問解く
  • リンカ・ローダと実行形式 10問解く
  • 信頼性 10問解く

当サイトの「信頼性」の分野は、半導体部品の故障と寿命試験が中心です。故障率の考え方を学ぶのには使えますが、MTBF・MTTRからの稼働率の計算や、直列・並列につないだシステムの稼働率、RAIDなどのシステムの信頼性設計は扱っていないので、ほかの教材で学んでください。

主な用語:

仮想記憶 スラッシング セマフォ CPI アムダールの法則 バスタブ曲線

ハードウェア・組込みシステム

組込みシステムについては、センサやモータをマイコンで制御する仕組み(入出力ポート、タイマ、PWM、A/D変換)と、リアルタイムOSによるタスクの管理を押さえておきましょう。ハードウェアの話題では、FPGAやSoCのような部品の種類と使い分け、消費電力を抑える工夫も理解しておくと役立ちます。電気回路の基礎は、論理回路や組込みの問題を読み解く助けにもなります。

  • 組込み・ファームウェア 10問解く
  • AD/DA変換 10問解く
  • 電気回路・電磁気の基礎 10問解く
  • 電力管理(ソフトウェア制御) 10問解く
  • AIハードウェアとソフトウェアスタック 10問解く

「AIハードウェアとソフトウェアスタック」の分野は、AIの計算を速く動かすためのハードウェアとソフトウェアが中心です。機械学習の手法そのものを学ぶ分野ではないので、試験対策の補足として使ってください。

主な用語:

PWM(パルス幅変調) ウォッチドッグタイマ RTOS(リアルタイムOS) FPGA SoC(システムオンチップ)

技術要素: データベース

データベースでは、関係データベースの表と主キー・外部キーの役割を押さえたうえで、SQLの文を読んで結果の行を数えられるようにしておくことが大切です。WHERE句とHAVING句の違い、GROUP BYによる集計、NULLを含む列でのCOUNTやAVGの結果、内部結合と外部結合の行数、副問い合わせ(INやEXISTS)は、小さな表で実際に試すと身に付きます。表の設計では、関数従属から第3正規形まで分ける正規化とE-R図を、処理の面では、トランザクションのACID特性、更新の消失などの同時実行の問題と分離レベル、共有ロック・専有ロックとデッドロック、ログを使ったロールバック・ロールフォワードによる回復を理解しておきましょう。

  • データベースの基礎 10問解く

主な用語:

関係データベース SQL 主キー 外部キー 正規化 E-R図 トランザクション ACID特性 分離レベル インデックス

SQLは「SQL練習ツール」で、ブラウザの中の練習用の表に実際に実行して結果を確かめられます。

技術要素: ネットワーク

ネットワークでは、OSI参照モデルとTCP/IPの階層、それぞれの層で働く機器(ハブ、スイッチ、ルータ)の違いを押さえたうえで、IPアドレスとサブネットマスクの計算に慣れておくことが大切です。ネットワークアドレスやブロードキャストアドレス、収容できるホストの数(2の(32 − プレフィックス長)乗 − 2)は、計算問題としてよく使われます。TCPとUDPの違い、3ウェイハンドシェイク、ポート番号、DNSによる名前解決、DHCP、NATの働き、TLSで守られることの範囲も、仕組みとあわせて理解しておきましょう。転送時間の計算では、ビットとバイトの単位をそろえることを忘れないようにします。

  • ネットワークの基礎 10問解く

主な用語:

OSI参照モデル サブネットマスク CIDR 3ウェイハンドシェイク ポート番号 DNS DHCP NAT TLS

セキュリティ

情報セキュリティでは、機密性・完全性・可用性の3要素と、脅威・脆弱性・リスクの関係、リスクへの対応(回避・低減・移転・受容)を押さえたうえで、暗号の仕組みを理解することが中心になります。共通鍵暗号と公開鍵暗号の違いと鍵の数の計算、ハイブリッド暗号、ハッシュ関数とソルト、デジタル署名でどの鍵を使い何が確かめられるか、多要素認証、SQLインジェクションやXSSなどのWebの攻撃とその対策は、よく問われる題材です。

ハードウェアに関わる部分として、消費電力や処理時間から秘密を推測するサイドチャネル攻撃、耐タンパ性、鍵を安全に保管するTPM、正しいソフトウェアだけを起動するセキュアブートなども学べます。

  • 情報セキュリティの基礎 10問解く
  • ハードウェアセキュリティ 10問解く

主な用語:

公開鍵暗号 共通鍵暗号 ハッシュ関数 デジタル署名 多要素認証 SQLインジェクション XSS サイドチャネル攻撃 TPM セキュアブート

パスワードの強さは「パスワードの総当たり時間の計算ツール」で確かめられます。

おすすめの学習順

このページで紹介した範囲を順に練習するなら、学習コース「基本情報・応用情報のテクノロジ系」がおすすめです。計算機算術と論理回路から始め、CPU、メモリ階層、OS、性能評価、データベース、ネットワーク、情報セキュリティ、組込みの順に進みます。

ハードウェアの仕組みを下から順に理解したいときは、学習コース「トランジスタからソフトまで」も役立ちます。MOSFET、論理回路、計算機算術、命令セット、コンパイラ、OS、メモリ階層、GPUプログラミングの順に、ハードウェアの上でソフトウェアが動く仕組みをたどれます。間違えた問題は「苦手問題」でまとめて解き直せます。

2進数・浮動小数点数、論理回路、サブネット、待ち行列、稼働率などの計算は、計算ツールで答えを確かめられます。

よくある質問

このサイトの問題だけで合格を目指せますか?

このサイトだけでは、試験の範囲全体をカバーできません。当サイトが扱うのは、テクノロジ系のうちハードウェアに近い部分と、データベース・ネットワーク・情報セキュリティの基礎です。アルゴリズムとプログラミング、マネジメント系、ストラテジ系などは、試験対策の参考書や過去問題で学んでください。データベースとネットワークは基礎の範囲を扱っています。

本試験と同じ形式の問題ですか?

いいえ。当サイトの問題は、すべてオリジナルの3択問題で、試験の過去問題を転載したものではありません。本試験の形式や出題の範囲は、IPAの公式サイトで公開されている試験要綱・シラバスなどで確認してください。

基本情報技術者試験と応用情報技術者試験のどちらに向いていますか?

どちらの試験でも、テクノロジ系のハードウェアに近い範囲の理解を深めるのに使えます。応用情報技術者試験は基本情報技術者試験より上位の区分なので、同じテーマでも、用語を覚えるだけでなく、仕組みや計算の理由まで説明できるようにしておくと役立ちます。当サイトの解説は、答えだけでなく仕組みや理由も説明しているので、その確認に使えます。

試験の範囲や形式は、見直されることがあります。最新の試験要綱・シラバスはIPA(情報処理推進機構)の公式サイトで確認してください。このページの対応づけは当サイトによる目安で、IPAが作成・確認したものではありません。
