電路分析（交流電路、線性電路與暫態現象）的重點

本單元以「電路與電磁學基礎」學過的歐姆定律與克希荷夫定律為基礎，再往前一步，進入大學電機電子系一、二年級所學的電路理論。只要把交流電壓與電流以相量（複數）表示，含線圈與電容器的電路也能像直流一樣以聯立一次方程式求解。開關剛閉合時的暫態現象，則以微分方程式或拉普拉斯轉換求解，並由時間常數與阻尼比讀出響應的快慢與振盪情形。

本單元以計算確認阻抗與導納、串聯與並聯RLC電路的共振與Q值、頻寬、有效功率、虛功率、視在功率與功率因數改善用的電容器、共軛匹配的最大功率，以及三相交流Y接與Δ接的電壓、電流與功率。線性電路方面，介紹節點分析與網目分析、重疊定理、戴維寧定理與諾頓定理（含交流與相依電源的情形），以及二埠網路的Z參數。暫態現象方面，由電容器電壓與線圈電流的連續性決定初值與終值，學習RC、RL電路的時間常數、RLC電路的過阻尼、臨界阻尼與欠阻尼、含初始值電源的s域等效電路、轉移函數的極點、初值定理與終值定理，以及以部分分式展開進行的逆轉換。大部分題目附有電路圖，交流與暫態題目的解說會並列複數、相量圖、微分方程式、拉普拉斯轉換、時間常數的大略值等多種解法。有助於準備日本電氣主任技術者考試（第三種）「理論」科目的電路部分，以及大學電路學的練習。計算題的數值，包括錯誤選項的數值，都以Python計算確認。歐姆定律與電磁學在「電路與電磁學基礎」，運算放大器與濾波器電路在「類比與電子電路」，方塊圖、波德圖與穩定判別在「控制工程基礎」，z轉換與數位濾波器在「數位訊號處理基礎」，整流電路與逆變器則在「電力電子電路」單元中介紹。
