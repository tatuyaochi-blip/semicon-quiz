先進電晶體（FinFET與GAA）的重點

電晶體微縮之後，閘極越來越難控制通道，短通道效應因而成為問題。於是出現了將通道做成立體鰭片形狀、由閘極從三個方向包圍的FinFET，並進一步演進為包圍通道整個外周的GAA（環繞式閘極）。

抑制閘極漏電的High-k/金屬閘極，以及提高遷移率的應變技術，也都是支撐先進電晶體的重要技術。
