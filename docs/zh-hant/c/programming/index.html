程式設計基礎（虛擬碼追蹤）的重點

要正確讀懂程式的動作，必須具備親手追蹤變數的值如何逐行變化的能力。把迴圈次數數錯一次、因指派的順序而遺失值、整數除法捨去了小數部分等小小的疏忽，都會造成錯誤的結果或程式錯誤。

本單元以追蹤短程式並回答結果的題目為主。這些程式仿照日本基本資訊技術人員考試科目B所使用的虛擬碼撰寫，包含整數型的宣告、以 ← 指派、if・while・for，以及從1開始的陣列元素編號等。錯誤的選項是由弄錯終值、誤解運算子優先順序等典型錯誤所產生的值，解說中會說明各選項來自哪一種錯誤。
