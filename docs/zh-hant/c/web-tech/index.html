Web技術基礎的重點

在瀏覽器中開啟URL時，HTTP請求會送達伺服器，瀏覽器再根據回傳的HTML、CSS、JavaScript組成畫面。維持登入狀態的Cookie、與其他服務連結的API、加快顯示的快取與CDN等，Web的機制是由許多技術組合而成的。

本單元學習HTTP請求與回應的形式、方法的安全性與冪等性、狀態碼、以標頭控制快取，以及HTTP/1.1、HTTP/2、HTTP/3的差異。接著介紹以Cookie、工作階段與JWT管理狀態，OAuth 2.0與OpenID Connect，REST API與URL的結構、百分比編碼、JSON，以及WebSocket與Webhook。在瀏覽器方面，介紹DOM、CSS的盒子模型與權重、到首次顯示為止的處理流程、JavaScript的事件迴圈、同源政策與CORS、Service Worker、響應式設計；在傳送方面，則介紹瀏覽器與CDN的快取、壓縮與傳輸時間的計算、Core Web Vitals、影像格式、Web伺服器與應用程式伺服器、反向代理，以及SSR、CSR、SSG。也有助於準備資訊相關證照考試的網路與Web系統領域。TCP/IP、DNS、TLS的機制在「電腦網路基礎」，XSS、CSRF、SQL注入等攻擊與對策在「資訊安全基礎」，負載分散與備援的設計則在「系統架構與可靠度設計」單元中介紹。
