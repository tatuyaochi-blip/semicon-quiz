新世代記憶體的重點

為了彌補DRAM與快閃記憶體的極限，目前正在開發各種基於新原理的記憶體。其中多數是不靠電荷，而是以電阻值的差異或極化方向來記錄資訊的非揮發性記憶體。

MRAM利用磁穿隧接面的磁化方向，PCM利用結晶態與非晶態的電阻差，ReRAM利用氧化物中的導電路徑，FeRAM則利用鐵電體的極化。請區分並記住各自的原理與特點。
