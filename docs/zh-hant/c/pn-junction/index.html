PN接面與二極體的重點

將p型與n型半導體接合後，載子會在交界處附近擴散並復合，形成幾乎沒有載子的空乏區。空乏區中會產生內建電位，這就是讓電流只能單向流動的整流作用的由來。

在順向偏壓下，位障降低而有電流流通；在逆向偏壓下，空乏區擴大，幾乎沒有電流流通。若進一步提高逆向電壓就會發生崩潰，這個現象被應用在稽納二極體（定電壓二極體）上。
