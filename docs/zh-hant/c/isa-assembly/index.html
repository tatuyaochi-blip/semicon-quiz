指令集與組合語言的重點

指令集架構（ISA）是軟體與硬體之間的約定。其中規定了有哪些指令、指令以怎樣的位元排列表示，以及如何指定暫存器與記憶體。只要遵守相同的ISA，即使內部構造不同的CPU也能執行相同的程式。

組合語言是把機器語言的指令寫成人類可讀的形式。了解RISC-V的基本指令、暫存器的使用區分、呼叫函式時引數與回傳值的傳遞方式（呼叫慣例），以及堆疊框的建立方式，就能看懂編譯器輸出的程式碼，以及程式如何在CPU上執行。
