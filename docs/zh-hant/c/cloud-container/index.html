雲端與容器基礎的重點

如今許多 Web 服務與企業內部系統，都以封裝在容器中的應用程式形式在雲端上運作。容器是在共用主機作業系統核心的同時隔離行程的機制，以 Docker 建置映像檔，再以 Kubernetes 這類平台把容器配置到許多機器上、維持數量並進行更新。

本單元從命名空間與 cgroups、映像檔的層與寫入時複製、Dockerfile 的指令與建置快取、連接埠的公開、磁碟區與繫結掛載、標籤與摘要、多階段建置開始，介紹 Kubernetes 的 Pod、Deployment、Service、Ingress、Secret、期望狀態的宣告與調和、滾動更新的計算、readiness 探測與 liveness 探測、HorizontalPodAutoscaler 的計算，以及 requests、limits 與 Pod 的配置。接著確認雲端的共同責任模型、區域與可用區域、無伺服器與冷啟動、區塊、檔案與物件儲存、隨需計費的費用與預留方案的損益兩平點、資料傳輸費用、IaC 與不可變基礎設施、藍綠部署與金絲雀部署、成品只建置一次的想法、以環境變數提供設定，以及可觀測性。計算題的數值，包括錯誤選項的數值，都已用 Python 計算確認。價格全部是虛構的數值。超管理器、容器與虛擬機器的差異在「作業系統與硬體」，IaaS、PaaS、SaaS、水平擴展、冗餘化、即時遷移與CDN在「系統架構與可靠度設計」，負載平衡器與工作階段在「Web技術基礎」，CI/CD在「軟體開發與專案管理」，SLA在「IT服務管理與系統稽核」，Shell 與環境變數則在「Linux與命令列基礎」單元中介紹。
