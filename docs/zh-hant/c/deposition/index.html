薄膜沉積（CVD與PVD）的重點

薄膜沉積是在晶圓上製作絕緣膜、半導體膜、金屬膜等薄膜的製程。大致可分為利用氣體化學反應來沉積薄膜的CVD，以及像濺鍍與蒸鍍那樣以物理方式沉積的PVD。

隨著微縮與立體化的推進，能以原子層為單位控制膜厚、並能均勻沉積在深溝槽中的ALD，重要性日益提高。
