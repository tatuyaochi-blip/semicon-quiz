SRAM與快閃記憶體的重點

SRAM是以兩個交叉耦合的反相器所構成的閂鎖器保持資料的記憶體，不需要更新，速度快。常用於CPU的快取記憶體等，但每位元所佔面積較大。

快閃記憶體是即使切斷電源，資料也不會消失的非揮發性記憶體。有適合大容量儲存的NAND型，以及隨機讀取速度快的NOR型，並且在一個記憶單元中儲存多個位元的多值化也持續進展。
