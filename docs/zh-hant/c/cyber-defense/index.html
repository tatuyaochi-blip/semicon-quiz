網路攻擊與防禦實務的重點

第一次學習的人: 密碼為什麼會被破解？長度和不重複使用為何重要 / VPN是什麼？保護通訊的通道原理與做不到的事

網路攻擊並非利用一個弱點就結束，而是分階段進行：入侵、建立立足點、擴大權限、在內部移動、達成目標。防禦方也不能只想著在入口阻擋，而是要以會遭入侵為前提，以組織的形式具備儘早發現、阻止擴大、保留證據並排除原因、再運用到下一次的機制。本單元從防禦方的角度，學習組織實際上如何遭受攻擊、又如何防禦。

首先以網路攻擊鏈與MITRE ATT&CK整理攻擊的流程，介紹初始存取的手法、C2通訊的線索、權限提升、橫向移動，以及濫用正規工具的就地取材型攻擊。接著在防禦機制方面，學習零信任的原則與NIST SP 800-207的政策決策點與執行點、VPN與ZTNA的差異、端點偵測與回應（EDR）、SIEM、SOAR與資安監控中心（SOC）的角色、入侵偵測系統與入侵防禦系統、特徵比對型與異常偵測型的偵測、WAF，以及利用誘餌的偵測。在事件應變方面，確認NIST SP 800-61的階段、揮發性順序與證據監管鏈、IoC與IoA、CSIRT與PSIRT，以及日誌時間誤差的修正。後半部介紹結合CVSS與遭利用狀況的修補優先順序、滲透測試與紅隊演練、協調式弱點揭露、軟體物料清單（SBOM），以及相依性混淆和利用正規更新的供應鏈攻擊；在雲端與身分方面，學習儲存空間公開設定的錯誤、過廣的權限、MFA疲勞攻擊、通行金鑰能抵抗網路釣魚的理由、工作階段Cookie的竊取、特權存取管理，以及提交到儲存庫的機密資訊。最後以計算確認平均偵測時間、資安投資報酬率（ROSI）、IDS警示中真正攻擊的比例，以及所需的分析人員人數。有助於準備日本資訊技術人員考試等證照考試的資訊安全領域。計算題的數值，包括錯誤選項的數值，都已用 Python 計算確認。標示年份或版本的標準與事件，是當時的資訊。資訊安全三要素、風險處理、惡意程式與網路釣魚、Web應用程式的弱點、CVE與CVSS的基礎，以及感染勒索軟體時的初步應對在「資訊安全基礎」，密碼與憑證在「密碼學基礎與應用」，硬體的縱深防禦與安全開機在「硬體安全」，防火牆與VPN的基礎在「電腦網路基礎」，共同責任模型在「雲端與容器基礎」，ITIL的事件管理則在「IT服務管理與系統稽核」單元中介紹。
