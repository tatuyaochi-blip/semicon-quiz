雙載子電晶體的重點

雙載子電晶體具有射極、基極、集極三層結構，是電子與電洞都參與動作的元件。它以基極電流控制集極電流，達成電流放大。

在放大動作（主動區）中，基極—射極之間施加順向偏壓，基極—集極之間施加逆向偏壓。請掌握電流增益hFE、基極寬度與復合的關係，以及飽和區與截止區的意義。
