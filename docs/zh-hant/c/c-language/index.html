C語言基礎的重點

C語言至今仍廣泛用於作業系統、裝置驅動程式、微控制器韌體等貼近硬體的軟體。它能直接處理記憶體位址、寫出快速的程式碼，但也有許多不知道就難以察覺錯誤的規則，例如 int 的大小因處理系統而異、計算途中型別會改變、寫入超過陣列範圍也不會停止等。

本單元以追蹤短程式碼實際執行時之輸出的題目為主，學習整數型別的大小與 stdint.h 的固定寬度整數型別、整數除法、整數提升與有號／無號的比較、運算子優先順序、位元運算、短路求值、switch 敘述的貫穿、傳值與傳指標、static 變數與生命週期、指標運算與陣列、二維陣列的排列、字串與 strlen、sizeof、const 的加法，以及函式指標。接著介紹 malloc 與 free、記憶體洩漏、懸置指標、緩衝區溢位、NULL 指標、結構的填充、聯合與端序、位元欄位、巨集與引入防護、條件編譯、嵌入式中的 volatile，以及未定義行為與編譯器的最佳化。程式的輸出都已在 x86-64 Linux 上以 gcc 實際編譯確認。虛擬碼的追蹤在「程式設計基礎（虛擬碼追蹤）」，使用 volatile 的中斷與暫存器操作在「嵌入式與韌體」，編譯器最佳化的細節在「編譯器」，記憶體配置與連結則在「連結器與載入器與執行檔格式」單元中介紹。
