硬體安全的重點

即使軟體沒有錯誤，資訊也可能因為硬體的特性而洩漏。Spectre與Meltdown這類弱點，利用的正是為提升效能而設計的推測執行與快取，會留下原本應該看不到的資料痕跡。另外也有旁路攻擊，從耗電量或處理時間的細微差異推測出加密金鑰。

防禦方面的技術包括：只啟動正確軟體的安全開機、連OS也無法觸及的隔離安全執行環境（TEE）、把每顆晶片的製造差異當作指紋使用的PUF，以及針對在設計或製造過程中被植入的不當電路（硬體木馬）的對策。本單元的目的不在攻擊步驟，而在於理解原理與對策。
