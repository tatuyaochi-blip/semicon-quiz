記憶體階層與效能的重點

CPU的運算花不到1奈秒，但從主記憶體的DRAM讀取資料卻要數十到100奈秒。為了彌補這個差距，電腦將從小而快的快取，到大而慢的主記憶體與儲存裝置，層層堆疊成階層，並把常用的資料放在較快的地方。

快取之所以有效，是因為程式具有時間區域性與空間區域性。了解直接映射與集合相聯的組成、將位址分為標籤、索引、位移的計算、三種快取失誤，以及平均記憶體存取時間的求法，就能明白為什麼資料的排列方式與迴圈的順序會讓效能相差好幾倍。
