DRAM的重點

DRAM是以一個電晶體與一個電容儲存1位元的記憶體。由於記憶單元結構簡單，容易高度積體化，被廣泛用作電腦的主記憶體。

電容中的電荷會因漏電流而逐漸流失，因此每隔一定時間就必須重新寫入，這稱為更新（refresh）。此外，讀取時記憶單元的電荷會改變，所以要先以感測放大器放大，再進行回寫。

這個領域的比較

  • DRAM 與 SRAM 的差異：結構、速度、成本、用途比較從單元結構、更新、速度、積體度、成本、耗電量與用途等面向，以表格比較 DRAM 與 SRAM，並說明各自適用的時機。
  • DDR、LPDDR、GDDR、HBM 的差異：DRAM 的種類比較從使用的設備、匯流排寬度、速度、頻寬、耗電量、封裝、容量與成本等面向，以表格比較 DDR、LPDDR、GDDR、HBM。
  • DDR4 與 DDR5 的差異：速度、結構與升級的判斷依據以速度、電壓、通道結構、突發長度、記憶庫、晶粒內 ECC、電源管理、延遲、頻寬與相容性等面向，用表格比較 DDR4 與 DDR5。
  • DRAM 與 NAND 快閃記憶體的差異：揮發性、速度、容量、用途比較從記憶機制、揮發性、讀寫單位與速度、抹寫次數、提高積體度的方法、成本與用途等面向，以表格比較 DRAM 與 NAND 型快閃記憶體。可以了解主記憶體與儲存裝置在角色上的差異。
