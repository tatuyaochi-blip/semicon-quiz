多核心與同步的重點

在單一晶片上搭載多個核心的多核心CPU中，各核心擁有自己的快取，同時共用相同的記憶體。為了避免某個核心改寫的資料被其他核心繼續使用舊值，MESI這類快取一致性協定負責管理快取的狀態。

此外還必須理解：決定寫入以何種順序被其他核心看見的記憶體一致性模型、讓多個核心能安全更新數值的原子指令，以及鎖與記憶體屏障。偽共享與資料競爭等陷阱，會讓看似正確的程式變慢或出現錯誤動作，這部分也要一併學習。

這個領域的比較

  • 互斥鎖與號誌的差異：比較互斥與同步以目的、值、擁有者、操作、訊號、優先權反轉、用途與常見陷阱等面向，用表格比較互斥鎖與號誌。
  • MSI、MESI、MOESI 的差異：狀態數、Exclusive 狀態、Owned 狀態、通訊比較從狀態數與意義、Exclusive 狀態的優點、Owned 狀態的優點、寫回記憶體與電路複雜度等面向，以表格比較快取一致性的 MSI、MESI、MOESI 協定。
