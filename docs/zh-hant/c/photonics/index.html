矽光子的重點

第一次學習的人: 矽光子是什麼？用光配線的晶片原理 / 半導體雷射（雷射二極體）是什麼？與LED的差異和光通訊用途

矽光子是運用與CMOS相同的矽製造技術，將導光的波導、調變器、光偵測器等整合在1顆晶片上的技術。矽幾乎不吸收通訊所用的1.31～1.55 µm波段的光，且與周圍氧化層的折射率差很大，因此能將光緊密侷限在微小的電路中。

由於AI訓練等需求，資料中心的通訊量急遽增加，而電氣配線隨著高速化，損耗與功耗持續增加。光收發器，以及將光學元件安裝在交換器IC近旁的CPO等光互連，作為解決這些課題的核心技術而備受矚目。
