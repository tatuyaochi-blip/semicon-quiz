GPU程式設計的重點

GPU是擅長同時執行數千到數萬個執行緒，對大量資料一併進行相同處理的處理器。程式以格線（grid）、區塊（block）、執行緒（thread）的階層表示平行性，硬體則以稱為warp的單位，讓約32個執行緒以相同的指令執行。

要發揮效能，重要的做法包括：相鄰執行緒讀取相鄰位址的記憶體合併存取、區塊內共用的晶片上共享記憶體、避免warp內的分支，以及為了隱藏記憶體等待時間而確保佔用率。本單元以不受產品世代影響的原理為主進行學習。
