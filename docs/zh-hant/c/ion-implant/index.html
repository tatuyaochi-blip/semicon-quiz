離子佈植的重點

離子佈植是將雜質離子化，以電場加速後打入晶圓的技術。由於能精確控制佈植量（劑量）與深度，已成為目前導入雜質的主流方法。

被打入的離子會對晶體造成損傷，因此佈植後要以熱處理（退火）修復晶體，並使雜質在電性上活化。決定佈植深度的因素，以及防止通道效應的做法，也請一併掌握。
