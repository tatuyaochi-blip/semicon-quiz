介面與匯流排規格的重點

在電腦內部，CPU與記憶體、GPU、儲存裝置、網路等元件，以各種介面相連。在高速連接中，與其並排許多條線的並列傳輸，不如在少數線路上傳送極高速訊號的串列傳輸成為主流，而收發電路SerDes正是支撐它的關鍵。

本單元學習：由PCI Express的通道數與每通道速度計算頻寬、編碼造成的效率、USB的基本觀念、連接晶片內各區塊的AXI等匯流排，以及共用記憶體的CXL。理解頻寬與延遲是不同的量，就能看出究竟是什麼決定了效能。
