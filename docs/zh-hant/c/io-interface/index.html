介面與匯流排規格的重點

在電腦內部，CPU與記憶體、GPU、儲存裝置、網路等元件，以各種介面相連。在高速連接中，與其並排許多條線的並列傳輸，不如在少數線路上傳送極高速訊號的串列傳輸成為主流，而收發電路SerDes正是支撐它的關鍵。

本單元學習：由PCI Express的通道數與每通道速度計算頻寬、編碼造成的效率、USB的基本觀念、連接晶片內各區塊的AXI等匯流排，以及共用記憶體的CXL。理解頻寬與延遲是不同的量，就能看出究竟是什麼決定了效能。

這個領域的比較

  • NVMe 與 SATA SSD 的差異：速度、介面、選擇方式從介面、速度、延遲、指令佇列、外型、耗電量、相容性、價格與適合的使用者等面向，以表格比較 NVMe 與 SATA 的 SSD。
  • DMA 與程式化 I/O 的差異：比較資料傳輸方式以搬移資料的主體、CPU 負載、傳輸量、準備成本、複雜度、匯流排使用與用途等面向，用表格比較 DMA 與程式化 I/O(PIO)。
  • PCIe 3.0、4.0、5.0、6.0 的差異：比較速度與各世代的特徵以傳輸速率、每條通道與 ×4、×16 連結的頻寬、編碼、訊號方式與使用的裝置等面向，用表格比較 PCIe 3.0、4.0、5.0、6.0。
  • NRZ 與 PAM4 的差異：位元數、鮑率、眼圖張開度、FEC、規格世代比較從每個符號的位元數、相同位元率下的鮑率、眼圖張開度與 SNR、FEC 的必要性、電路、使用的規格世代等面向，以表格比較 NRZ 與 PAM4。
