電源管理（軟體控制）的重點

無論是智慧型手機的電池續航力，還是資料中心的電費，都會因晶片的用電方式而有很大的差異。CMOS電路的功耗，分為每次訊號切換就消耗的動態功耗，以及即使什麼都不做也會因漏電流而消耗的靜態功耗，兩者有效的對策各不相同。

本單元學習OS與韌體如何運用各項硬體機制：依負載降低電壓與頻率的DVFS、停止不使用電路之時脈的時脈閘控，以及連電源都切斷的電源閘控。也會介紹CPU的睡眠狀態與效能狀態，以及溫度過高時的熱節流觀念。
