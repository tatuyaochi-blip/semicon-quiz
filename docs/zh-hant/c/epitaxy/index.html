磊晶成長的重點

磊晶成長是在單晶基板上，使晶體方向與基板一致，成長出單晶薄膜的技術。由於能製作雜質濃度受到精密控制的層，被用於功率元件、雙載子元件與化合物半導體元件等。

成長與基板相同材料的稱為同質磊晶，成長不同材料的稱為異質磊晶；後者必須注意因晶格常數差異（晶格不匹配）所產生的缺陷。
