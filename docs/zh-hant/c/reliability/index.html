可靠度的重點

第一次學習的人: 阿瑞尼斯方程式是什麼？溫度讓反應和故障快幾倍 / 半導體封裝是什麼？保護晶片、對外連接的原理

可靠度是產品在規定條件下、規定期間內持續維持功能的能力。故障率隨時間的變化，以由早期故障期、隨機故障期、磨耗故障期所構成的浴缸曲線表示。

半導體特有的故障機制包括配線的電遷移、閘極絕緣膜的經時崩潰（TDDB）、電晶體特性劣化等。藉由加速試驗，可在短時間內估算壽命。

可靠度的題目列表（51題）
  1. 下列哪一項是構成表示故障率隨時間變化的浴缸曲線（bathtub curve）的三個時期的正確組合？
  2. 下列何者是對電遷移（electromigration）的正確說明？
  3. 下列何者是對MTBF（平均故障間隔時間）的正確說明？
  4. 在藉由提高溫度來縮短壽命試驗時間的加速試驗中，常用來表示溫度與壽命關係的模型是下列何者？
  5. 下列何者是對TDDB（經時絕緣破壞）的正確說明？
  6. 下列何者是對故障率單位FIT意義的正確說明？
  7. 溫度循環試驗主要評估的是下列何種故障？
  8. 作為ESD（靜電放電）對策，設置在LSI輸入輸出端子上的是下列何者？
  9. 當pMOS電晶體持續承受負的閘極電壓與高溫時，臨界電壓的絕對值會逐漸增加，這種劣化現象是下列何者？
  10. 下列何者是對CMOS電路閂鎖效應（latch-up）的正確說明？
  11. 在汲極附近的高電場下被加速的載子注入閘極絕緣膜，使電晶體特性劣化的現象是下列何者？
  12. 高溫高濕偏壓試驗（THB或HAST）主要評估的是下列何種故障？
  13. 常用於可靠度資料分析，且可依形狀參數的值表示早期故障型、偶發故障型與磨耗故障型的分佈是下列何者？
  14. 即使沒有電流流過，也會因配線內部的應力使金屬原子移動而產生空孔的現象是下列何者？
  15. 從錫鍍層的表面長出針狀金屬結晶，並與相鄰端子短路的現象稱為什麼？
  16. 讓產品在高溫下長時間運作，以評估壽命與故障率的代表性可靠度試驗是下列何者？
  17. 對於活化能0.7 eV的故障機制，以阿瑞尼斯模型求125 ℃相對於55 ℃的加速係數，大約是多少？（波茲曼常數 8.6×10⁻⁵ eV/K）
  18. 下列何者是進行故障分析時的正確一般流程？
  19. 在金線與鋁焊墊的接合處，高溫長時間存放會使金屬間化合物與空孔成長而使接合強度降低，這種現象的俗稱是下列何者？
  20. 下列哪一種環境中，源自宇宙射線的中子所造成的軟錯誤發生率會變高？
  21. 下列何者是廣泛用作車用積體電路可靠度試驗基準的規格？
  22. 當故障率λ為固定時，表示直到時間t為止不發生故障的機率（可靠度）R(t)的式子是下列何者？
  23. 故障率固定為1×10⁻⁵ /小時的零件，其平均故障時間（MTTF）為多少？
  24. 將2個可靠度0.9的零件並聯，只要其中一個運作系統就能發揮功能，此系統的可靠度是多少？
  25. 將2個可靠度0.9的零件串聯，兩者都運作才能發揮功能，此系統的可靠度是多少？
  26. 在TDDB的壽命評估中，以高於實際使用電壓的電壓進行試驗，其理由下列何者正確？
  27. 在智慧型手機等行動裝置中，對焊接接點的可靠度評估特別重視的試驗是下列何者？
  28. 當電遷移使配線產生凸起（hillock）時，可能發生的故障是下列何者？
  29. 為了以統計方式保證非常低的故障率，下列哪一項是適當的可靠度試驗條件？
  30. 在薄的閘極氧化膜中，於完全失去絕緣之前，漏電流呈階段性增加的輕微破壞稱為什麼？
  31. 在故障的分類中，「功能突然完全喪失的故障」與「特性逐漸變化而超出規格的故障」，其名稱的組合下列何者正確？
  32. 對一般民生用的半導體產品，可靠度設計中常設定的使用期間，下列何者最接近？
  33. 即使同為半導體，對民生機器用與汽車用所要求的可靠度水準，下列說明何者正確？
  34. 依據許多化學反應與劣化常用的經驗法則「溫度每上升10℃，反應速度約變為2倍」來考慮，將使用溫度降低10℃時，壽命大約會如何？
  35. 蒐集並分析市場上使用中產品的故障（現場故障）資訊，其主要目的是下列何者？
  36. 在評估ESD（靜電放電）耐受性的試驗模型中，「帶電的人觸碰IC端子時的放電」與「IC本身帶電而端子接觸金屬時的放電」，其名稱的組合下列何者正確？
  37. 除了溫度之外，還包含濕度、電壓等多種應力影響來表示壽命加速，且以熱力學為基礎的模型是下列何者？
  38. 以溫度變化幅度（應變大小）與反覆次數的關係，來表示溫度循環所造成焊接接點疲勞壽命的模型是下列何者？
  39. 在電遷移的壽命試驗中，常用來表示多條配線直到故障為止的時間分佈的統計分佈是下列何者？
  40. 在車用等領域，彙整產品在壽命期間會暴露於何種溫度、電壓、運作時間條件下的設想，稱為什麼？
  41. 使用10,000個故障率為100 FIT的零件，1年（約8,760小時）內預期故障數最接近下列何者？（1 FIT = 每10⁹小時1次故障）
  42. 在印刷電路板等上，於潮濕環境中，金屬（銀或銅等）在施加電壓的電極之間以離子形式溶出並移動，呈樹枝狀析出而造成短路的現象，稱為什麼？
  43. 在High-k／金屬閘極的nMOS電晶體中，持續施加正的閘極電壓與高溫時，臨界電壓會逐漸變化的劣化，稱為什麼？
  44. 在先進LSI的設計中，預期電晶體在使用期間會因BTI或HCI而劣化，並確認劣化後的特性是否仍能滿足時序的作法，稱為什麼？
  45. 由高溫高濕試驗結果推估實際使用壽命時，以相對濕度的冪次方表示濕度影響的常用模型是下列何者？
  46. 關於閘極絕緣膜的絕緣破壞壽命，必須考慮試驗所用元件的面積與實際晶片整體閘極面積之差異，其理由下列何者正確？
  47. 在覆晶（flip chip）的焊料凸塊中，因大電流而使電遷移成為問題時，已知特別容易發生故障的位置是哪裡？
  48. 關於BTI的劣化，移除應力後臨界電壓的變化會有一部分恢復，就此現象在評估上的注意事項，下列何者正確？
  49. 為了評估宇宙射線中子造成軟錯誤的發生難易度，以遠強於實際環境的中子照射並在短時間內量測的方法，下列何者正確？
  50. 將TDDB的試驗結果外插到使用電壓時的模型，有以指數函數表示壽命與電場關係的E模型，以及以指數函數表示壽命與電場倒數關係的1/E模型。關於兩者的差異，下列何者正確？
  51. 下列何者是HTOL會施加、但高溫儲存試驗不施加的應力？

這個領域的比較

  • HTOL、THB、HAST、溫度循環與高溫儲存試驗的差異：條件、目的、故障模式比較從目的、施加的應力、是否施加電壓、典型條件、試驗時間、故障機制、加速模型與標準範例等面向，以表格比較 HTOL、高溫高濕偏壓試驗（THB）、HAST、溫度循環試驗與高溫儲存試驗，並說明在認證試驗中的組合方式。
  • TDDB、HCI、NBTI的差異：劣化機制、應力條件、特性變化、評估方法比較從劣化機制、作用電場的方向、施加應力的條件、主要受影響的元件、變化的特性、隨時間的變化與恢復、對溫度與電壓的依存、評估方法、主要對策等面向，以表格比較電晶體代表性的磨耗劣化TDDB（經時介電崩潰）、HCI（熱載子注入）…
