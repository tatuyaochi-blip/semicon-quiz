LSI設計流程與EDA的重點

第一次學習的人: FPGA是什麼？做好之後還能改寫電路的晶片原理 / 積體電路（IC）是什麼？晶片、晶粒、LSI、SoC的差異

LSI的設計依下列流程進行：訂定規格，以硬體描述語言撰寫RTL（暫存器傳輸層級）電路，經邏輯合成轉換為邏輯閘的連接（網表），再藉由佈局繞線製作出佈局圖。

各階段都少不了以EDA工具進行的模擬、靜態時序分析（STA）與驗證。設計規模越大，驗證所需的工夫也越大。

  36. 事先製作好鋪滿電晶體的共通底板（母片，master），只針對各品種設計佈線層來製造的方式為下列何者？
  37. 在使用SystemVerilog的驗證中，用來建構容易重複使用之測試環境（測試平台，testbench）的標準方法論為下列何者？
  38. 在佈局驗證中，檢查輸入端子是否浮接（沒有連到任何地方）、電源之間是否短路等電氣連接錯誤的檢查為下列何者？
  39. 事先描述設計應滿足的性質（例如「收到請求後須在3個週期內回應」），並在模擬過程中或形式驗證時自動檢查的手法為下列何者？
  40. 在低功耗設計中，將電源域、電源切斷、位準轉換器（level shifter）等「電源意圖」與電路描述分開、彙整描述的標準格式為下列何者？
  41. 針對以不同時脈運作的電路之間傳遞訊號的部分，用專用工具確認是否正確加入同步化電路的驗證，稱為什麼？
  42. 將設計後期或製造途中發現的小修正，不重做整個設計，而是部分變更既有佈局來反映，稱為什麼？
  43. 在標準單元的配置中，為了填補單元之間的空隙、固定井的電位、抑制電源雜訊而放置的不具功能（或屬輔助性質）之單元組合，下列何者正確？
  44. 在各種輸入轉換時間、負載電容、電壓、溫度的條件下，對標準單元的延遲與耗電量進行電路模擬並彙整成表的作業，稱為什麼？
  45. 在靜態時序分析中，為了考慮即使在同一晶片內，電晶體或佈線的延遲也會因位置而有變異，而將延遲乘上係數以保留餘裕的手法，稱為什麼？
  46. 不是在角落條件下組合最差值，而是將延遲變異視為機率分布，求出滿足時序之機率的分析手法為下列何者？
  47. 在時序限制（SDC）中，用來指定作為時脈抖動（jitter）或偏斜預估值等而事先從時脈週期扣除之餘裕的設定，為下列何者？
  48. 在靜態時序分析中，針對容易偏悲觀的一般分析結果，對違反的路徑依據實際訊號的傳遞方式詳細重新計算，以去除多餘餘裕的手法，稱為什麼？
  49. 在類比電路設計中，隨機地反覆給予製造變異所造成的電晶體特性變化來進行模擬，以估算效能分布與良率的手法為下列何者？
  50. 在電路的邏輯模擬方式中，只有在訊號的值發生變化（事件）時，才計算受其影響之部分的方式為下列何者？
