LSI設計流程與EDA的重點

LSI的設計依下列流程進行：訂定規格，以硬體描述語言撰寫RTL（暫存器傳輸層級）電路，經邏輯合成轉換為邏輯閘的連接（網表），再藉由佈局繞線製作出佈局圖。

各階段都少不了以EDA工具進行的模擬、靜態時序分析（STA）與驗證。設計規模越大，驗證所需的工夫也越大。
