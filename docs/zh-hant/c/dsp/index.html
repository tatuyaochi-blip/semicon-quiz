數位訊號處理基礎的重點

經AD轉換器變成數值序列的訊號，會在處理器或FPGA上進行濾波、分析頻率成分、改變取樣頻率等處理。從音訊、通訊、感測器、馬達控制到量測儀器，數位訊號處理在幾乎所有電子產品中運作。

本單元從離散時間訊號的正規化頻率與週期、單位脈衝與步階、能量與功率開始，介紹線性非時變系統的性質（線性、非時變性、因果性、BIBO穩定）、脈衝響應與摺積，以及差分方程式的計算。接著確認DFT的頻率點間隔與編號、實數訊號頻譜的對稱性、FFT的運算量、補零、頻譜洩漏與窗函數、帕塞瓦定理、以z轉換求得的轉移函數與極點、零點、FIR濾波器與IIR濾波器、線性相位與群延遲、移動平均與指數平滑、雙線性轉換、係數量化、降取樣與升取樣，以及乘積累加運算次數與即時處理時間的估算。計算題的數值，包括錯誤選項的數值，都已用Python（NumPy）計算確認。取樣定理、混疊、量化雜訊、過取樣與ΔΣ式ADC在「AD/DA轉換」，類比濾波器與運算放大器在「類比與電子電路」，OFDM在「無線通訊基礎」，CNN的卷積在「機器學習基礎」，定點數的表示方式則在「電腦算術」單元中介紹。

數位訊號處理基礎的題目列表（40題）
  1. 以取樣頻率48 kHz對頻率6 kHz的正弦波取樣。此離散時間訊號的正規化角頻率ω（每個取樣點前進的相位）為下列何者？
  2. 離散時間訊號 x[n] = cos(0.3πn) 的基本週期（對所有整數 n 都使 x[n + N] = x[n] 成立的最小正整數 N）為下列何者？
  3. 對所有整數 n，與離散時間訊號 x[n] = cos(1.75πn) 取相同值的訊號為下列何者？
  4. 單位脈衝 δ[n]（n = 0 時為1，其他為0）與單位步階 u[n]（n ≥ 0 時為1，n < 0 時為0）的關係，下列何者正確？
  5. x[n] = (0.5)ⁿu[n]（n ≥ 0 時為0.5的n次方，n < 0 時為0）的能量 E = Σ|x[n]|² 為下列何者？
  6. x[n] = 2cos(πn/4) 的平均功率（|x[n]|² 在1個週期內的平均）為下列何者？
  7. 輸入為 x[n]、輸出為 y[n] 的系統中，既是線性又是非時變（LTI）的為下列何者？
  8. 以 y[n] = n·x[n] 表示的系統，其性質為下列何者？
  9. 輸入為 x[n]、輸出為 y[n] 的系統中，具因果性（輸出只由該時刻以前的輸入決定）的為下列何者？
  10. 設 u[n] 為單位步階。脈衝響應如下的LTI系統中，BIBO穩定（有界的輸入必定得到有界的輸出）的為下列何者？
  11. 把 x[n] = {1, 2, 3}（n = 0, 1, 2）輸入脈衝響應為 h[n] = {1, −1}（n = 0, 1）的LTI系統。輸出 y[0]～y[3] 為下列何者？
  12. 對差分方程式 y[n] = x[n] + 0.5y[n − 1] 表示的系統，從 n = 0 起輸入單位步階（n ≥ 0 時 x[n] = 1）。y[−1] = 0 時，y[2] 為下列何者？
  13. 以1024點的離散傅立葉轉換（DFT）分析取樣頻率48 kHz的訊號。頻率點（bin）的間隔為下列何者？
  14. 設 k = 0 為直流的頻率點。以256點的DFT分析以取樣頻率8 kHz取樣的1 kHz正弦波時，在正頻率側出現峰值的頻率點編號 k 為下列何者？
  15. 計算實數訊號 x[n] 的64點DFT，得到 X[10] = 3 + 4j。X[54] 為下列何者？
  16. 設8點實數訊號 x[n] = {3, 1, 3, 1, 3, 1, 3, 1} 的DFT為 X[k] = Σx[n]e^(−j2πkn/8)。對應奈奎斯特頻率的頻率點 X[4] 的值為下列何者？
  17. 假設N點的DFT依定義計算約需 N² 次運算，以FFT（快速傅立葉轉換）則約需 N log₂N 次。N = 1024 時，FFT減少運算次數的程度最接近下列何者？
  18. 在256點訊號之後補上768個0（補零），計算1024點的DFT。與直接以256點計算DFT相比，下列敘述何者正確？
  19. DFT產生頻譜洩漏的主要原因為下列何者？
  20. 關於DFT之前所乘的窗函數，比較方形窗（不乘任何窗）與漢寧窗（Hann窗）的敘述，下列何者正確？
  21. 設點數 N 足夠大。在方形窗的DFT中，當正弦波的頻率恰好位於相鄰兩個頻率點的正中間時，在最近的頻率點讀到的振幅，比頻率與頻率點中心一致時降低多少？最接近者為下列何者？
  22. 設4點訊號 x[n] = {1, −1, 2, 0} 的DFT為 X[k] = Σx[n]e^(−j2πkn/4)。Σ|X[k]|²（k = 0～3）為下列何者？
  23. 由離散時間LTI系統的轉移函數 H(z) 求頻率響應時，z 應沿著下列何處移動？
  24. 以差分方程式 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1] 表示的系統，其轉移函數 H(z) = Y(z)/X(z) 為下列何者？
  25. 轉移函數為 H(z) = 1/(1 − 1.3z⁻¹ + 0.4z⁻²) 的因果系統，其極點與穩定性的組合為下列何者？
  26. 有一個以取樣頻率8 kHz運作、轉移函數為 H(z) = 1 + z⁻²（y[n] = x[n] + x[n − 2]）的FIR濾波器。使輸出為0的正弦波輸入頻率為下列何者？
  27. 以 y[n] = x[n] − x[n − 1]（與前1個輸入的差）表示的濾波器，在直流與奈奎斯特頻率的增益大小組合為下列何者？
  28. 有限脈衝響應（FIR）濾波器的特徵為下列何者？
  29. 具有下列係數的5抽頭FIR濾波器中，具有線性相位特性的為下列何者？
  30. 101抽頭的線性相位FIR濾波器（係數左右對稱）的群延遲為下列何者？
  31. 在取樣頻率8 kHz下，使用取最近8個取樣點平均的移動平均濾波器 y[n] = (x[n] + x[n − 1] + … + x[n − 7])/8。使輸出為0的最低頻率為下列何者？
  32. 以指數平滑 y[n] = 0.2x[n] + 0.8y[n − 1] 表示的一階IIR低通濾波器，在直流與奈奎斯特頻率的增益組合為下列何者？
  33. 由類比濾波器的轉移函數 H(s) 設計數位濾波器時所用的雙線性轉換，下列敘述何者正確？
  34. 以係數位元數有限的定點數實作高階IIR濾波器時，下列注意事項何者正確？
  35. 把取樣頻率48 kHz的訊號每4個取樣點取出1個，降為12 kHz（1/4降取樣）。在抽取之前放置的低通濾波器應去除的頻率成分為下列何者？
  36. 為了把取樣頻率提高為 L 倍，在各取樣點之間插入 L − 1 個0（插零）。之後所需的處理，下列敘述何者正確？
  37. 為了把取樣頻率從44.1 kHz轉換為48 kHz，組合 L 倍的升取樣與 1/M 的降取樣。最小的整數組 (L, M) 為下列何者？
  38. 以取樣頻率44.1 kHz即時運作256抽頭的FIR濾波器。每秒所需的乘積累加運算（MAC）次數為下列何者？
  39. 以取樣頻率48 kHz，每個取樣點計算一次FIR濾波器的輸出。使用時脈200 MHz、每個時脈週期能做1次乘積累加的處理器，忽略其他處理的時間時，能即時處理的抽頭數上限最接近下列何者？
  40. 有一個FIR濾波器的計算，把16位元定點數的資料與係數的乘積以32位元表示，並把256個乘積相加。為了保證計算過程中不發生溢位，累加器所需的最少位元數為下列何者？
