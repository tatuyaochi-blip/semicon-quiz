硬體描述語言與驗證的重點

數位電路是以Verilog與SystemVerilog等硬體描述語言（HDL）撰寫的。外觀與程式相似，但所寫的內容表示的是同時運作的電路。HDL有其特有的規則，例如可由邏輯合成轉換為電路與不可轉換的寫法、阻塞式賦值與非阻塞式賦值的使用區分，以及因漏寫條件而產生非預期的閂鎖。

所寫的電路是否正確，要用測試平台（testbench）給予輸入來確認。本單元學習以HDL設計與驗證的基本觀念，包括狀態機的寫法、以斷言自動檢查性質、以涵蓋率評估驗證是否充分，以及從C語言等產生電路的高階合成。

這個領域的比較

  • Verilog 與 VHDL 的差異：兩種硬體描述語言比較從來歷、語法、型別、大小寫、驗證功能、使用領域與選擇方式等面向，以表格比較 Verilog 與 VHDL。
  • 阻塞賦值與非阻塞賦值的差異：求值時機、順序、使用場合比較從更新左邊的時機、對描述順序的依賴、使用場合（組合電路與循序電路）、模擬與合成的不一致等面向，以表格比較 Verilog 的阻塞賦值（=）與非阻塞賦值（<=）。
  • 同步重置與非同步重置的差異：時序、時脈、解除的注意事項比較從生效時機、是否需要時脈、抗突波能力、時序分析、重置解除時的同步化、面積與 Verilog 寫法等面向，以表格比較同步重置與非同步重置，並說明各自適合的電路。
