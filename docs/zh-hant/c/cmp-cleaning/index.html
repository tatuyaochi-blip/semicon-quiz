CMP與清洗的重點

第一次學習的人: 半導體晶片是怎麼做出來的？看懂前段、後段製程全貌 / 矽晶圓是什麼？從石頭到鏡面般圓板的製造過程

CMP（化學機械研磨）是結合研磨液的化學作用與研磨墊的機械研磨，使晶圓表面平坦的技術。對於多層配線，以及以鑲嵌法形成Cu配線而言不可或缺。

清洗是去除微粒、有機物、金屬汙染、原生氧化膜等的製程，在製造流程中會反覆進行多次。請掌握以RCA清洗為基礎的各種藥液的使用區分。
