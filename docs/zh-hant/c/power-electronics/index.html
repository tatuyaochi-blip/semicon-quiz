電力電子電路的重點

功率半導體元件本身無法轉換電力。將二極體、閘流體、MOSFET、IGBT與電感、電容、變壓器組合成電路，並在適當的時機切換，才能把交流變成直流、把直流變成其他電壓的直流、把直流變成交流。本單元學習這類電力轉換電路，以及由它驅動之電動機的基礎。

首先介紹單相與三相整流電路、全波整流的平均值、平滑電容漣波的估算、閘流體的相位控制與觸發角、電源換流，以及失真電流的功率因數。接著由電感電壓與時間乘積的平衡，確認降壓・升壓・升降壓轉換器的轉換比，並搭配計算學習電感電流漣波、連續導通模式與不連續導通模式的邊界、輸出電壓漣波、同步整流在死區時間中的電流、切換損耗與輕載效率。隔離型轉換器只介紹返馳式與順向式的動作入門。後半部介紹半橋與全橋逆變器、正弦波PWM與調變指數、三相逆變器的線電壓、過調變、載波頻率的選擇、死區時間造成的電壓誤差、自舉電容，以及升壓型的功率因數校正，最後確認感應電動機的同步轉速與轉差率、V/f控制、直流電動機的反電動勢與轉矩、無刷直流馬達、減速時的再生，以及理想變壓器的電流比。也可作為準備電機類證照考試（例如日本的電氣主任技術者考試、韓國的電氣技師考試）中電力電子與電機部分的入門。計算題的數值，包括錯誤選項的數值，都已用 Python（NumPy）計算確認。MOSFET、IGBT、SiC、GaN等元件的結構與特性、閘極驅動器、緩衝電路與柔性切換在「功率半導體」，LDO與切換式穩壓器的比較在「類比與電子電路」，交流電路與三相交流、變壓器的電壓比與阻抗轉換在「電路與電磁學基礎」，DC-DC轉換器的控制迴路與馬達的串級控制在「控制工程基礎」，PWM與責任週期在「嵌入式與韌體」，電動車的逆變器則在「車用半導體與功能安全」單元中介紹。
