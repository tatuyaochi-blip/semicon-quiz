化合物半導體的重點

第一次學習的人: LED為什麼會發光？用半導體把電變成光的原理 / 氮化鎵（GaN）是什麼？GaN充電器為何能做得這麼小

化合物半導體是像GaAs（砷化鎵）、GaN（氮化鎵）這樣由多種元素構成的半導體。以III族與V族元素的組合（III-V族）最具代表性。

與矽相比，有電子遷移率較高者、屬於直接能隙而能高效發光者、能隙較大者等，被活用於高頻元件、LED與雷射，以及功率元件。
