影像感測器與光電元件的重點

影像感測器是以每個像素的光電二極體將光轉換為電荷，再以電訊號讀出的元件。目前以CMOS影像感測器為主流，廣泛用於智慧型手機與車用相機。

從配線層的另一側入光的背照式，以及將像素與電路分別製作在不同晶片上再堆疊的堆疊式，對性能提升貢獻良多。LED與雷射等將電轉換為光的光電元件，也屬於這個領域。
