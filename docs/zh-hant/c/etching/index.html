蝕刻的重點

蝕刻是將未被光阻等遮罩覆蓋的部分薄膜去除，以形成圖案的製程。有使用藥液的濕式蝕刻，以及使用電漿等的乾式蝕刻。

要準確加工微細圖案，只往縱向蝕刻的異向性，以及只蝕刻目標薄膜的選擇比相當重要。反應性離子蝕刻（RIE）是代表性的方法。
