功率半導體的重點

功率半導體是負責電力轉換與控制的元件，用於變頻器、電源供應器、電動車等。它需要高耐壓、低導通電阻與高速切換。

除了矽的MOSFET與IGBT之外，使用能隙大、崩潰電場高的SiC與GaN的元件也逐漸普及。理解材料物性與元件結構之間的關係非常重要。
