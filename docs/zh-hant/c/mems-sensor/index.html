MEMS與感測器的重點

MEMS（微機電系統）是運用半導體的微細加工技術，將微小的機械結構與電子電路製作在一起的元件。廣泛用於智慧型手機的加速度感測器、陀螺儀、麥克風、壓力感測器等。

請掌握讓可動結構懸空的犧牲層蝕刻，以及將位移、應力、磁場等轉換為電訊號的原理（電容、壓阻效應、霍爾效應）。
