半導體物性的重點

半導體的性質，主要取決於價帶與導帶之間的能量差——能隙。矽的能隙在室溫下約為1.12 eV，既不像絕緣體那麼大，也不像金屬那樣為零。

摻入雜質後，就會成為電子較多的n型或電洞較多的p型半導體。載子濃度的溫度相依性、遷移率，以及漂移電流與擴散電流的差異，是日後理解元件動作的基礎。

這個領域的比較

  • 直接能隙與間接能隙半導體的差異：能帶結構、發光效率、光吸收、材料比較從能帶結構、聲子的參與、發光效率、載子壽命、光的吸收深度、代表性材料與用途等面向，以表格比較直接能隙與間接能隙半導體。
  • n 型半導體與 p 型半導體的差異：摻雜物、多數載子、費米能階、遷移率比較從添加的雜質（施體與受體）、多數載子、雜質能階、費米能階的位置、遷移率與電阻率，以及在元件中的使用位置等面向，以表格比較 n 型與 p 型半導體。
  • 導體、半導體、絕緣體的差異：能隙、電阻率、溫度特性比較從能帶結構、能隙、電阻率、載子數量、隨溫度與光的變化、代表性材料與在元件中的角色等面向，以表格比較導體（金屬）、半導體與絕緣體。
  • 本質半導體與雜質半導體的差異：載子、費米能階、溫度特性比較從載子的來源與密度、費米能階、電阻率、隨溫度的變化與用途等面向，以表格比較不含雜質的本質半導體，以及加入施體或受體的雜質半導體（外質半導體，n 型與 p 型）。
