編譯器的重點

編譯器是將人類撰寫的程式翻譯成CPU可執行的機器語言的軟體。它先經過將原始碼切分成詞彙的詞法分析、依文法建立樹狀結構的語法分析，以及檢查型別與名稱是否正確的語意分析，再轉換成中間表示（IR）。

在中間表示上進行常數摺疊、共同子運算式消除、內嵌展開、迴圈展開、向量化等最佳化，最後以暫存器配置與指令排程產生適合CPU的程式碼。了解最佳化的原理，就能知道如何寫出執行快速的程式，以及如何發揮硬體的效能。
