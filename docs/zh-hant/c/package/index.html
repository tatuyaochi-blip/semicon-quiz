封裝與構裝的重點

封裝的作用是保護晶片免受外部環境影響、與基板形成電性連接，並將熱量散出。從晶圓切下的晶片，經過黏晶、連接、封膠等製程後成為產品。

晶片與外部的連接方式有打線接合與覆晶；封裝的形狀也從引出引腳的類型，隨著接腳數增加，演進到在背面排列焊錫球的BGA等。

這個領域的比較

  • 打線接合與覆晶的差異：晶片連接方式比較以連接方式、輸入輸出數量、電氣性能、成本、尺寸、製程與用途等面向，用表格比較打線接合與覆晶。
  • BGA、QFP、QFN 的差異：比較 IC 封裝的種類以端子、腳位數、間距、大小、電氣性能與散熱、檢查與用途等面向，用表格比較 BGA、QFP、QFN 封裝。
  • 球形接合與楔形接合的差異：材料、製程、方向性、用途比較從接合的形狀、工具、接合的能量、線材材料（Au、Cu 與 Al、帶狀線）、線徑、方向性、速度、線弧、可靠度與用途等面向，以表格比較球形接合與楔形接合，並說明各自適用的時機。
