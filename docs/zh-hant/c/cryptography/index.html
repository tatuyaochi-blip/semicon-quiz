密碼學基礎與應用的重點

第一次學習的人: HTTPS是什麼？鎖頭圖示能保護與不能保護的事 / 密碼為什麼會被破解？長度和不重複使用為何重要

加密不是只要演算法安全就能派上用場。重複使用同一個nonce、以ECB模式加密、不確認憑證的主機名稱等用法上的錯誤，都會讓強大的加密輕易被攻破。本單元更深入一層，學習加密在實際的系統與協定中如何被組合運用。

首先在對稱式加密方面，介紹區塊加密與串流加密、AES的區塊長度與金鑰長度、區塊加密操作模式（ECB、CBC、CTR、GCM）與初始向量、nonce的條件、填充與填充預言攻擊，以及鑑別加密（AEAD），並以計算確認在CTR模式中重複使用nonce時明文洩漏的情形。接著學習SHA-2與SHA-3、長度擴充攻擊與HMAC、生日攻擊造成的64位元區塊的極限，以及金鑰衍生函數，再以小數字計算RSA與迪菲-赫爾曼金鑰交換，確認離散對數問題、中間人攻擊、橢圓曲線密碼金鑰長度的參考值、前向保密，以及ECDSA亂數的處理。後半部介紹憑證機構與憑證鏈、主機名稱的確認、憑證透明度、TLS 1.3的變更與加密套件、0-RTT的重放與相互TLS；在後量子密碼學方面，學習Grover演算法與金鑰長度、2024年8月標準化的ML-KEM、ML-DSA、SLH-DSA、金鑰封裝機制、混合金鑰交換，以及遷移時機的思考方式。最後確認硬體安全模組（HSM）、信封加密、金鑰輪替與密碼敏捷性等金鑰管理。有助於準備日本資訊技術人員考試等證照考試的資訊安全領域。計算題的數值，包括錯誤選項的數值，都已用 Python 計算確認。對稱式加密與公開金鑰加密的基礎、金鑰數的計算、雜湊函數的性質與密碼的儲存，以及數位簽章與MAC的差異在「資訊安全基礎」，旁通道攻擊與恆定時間實作、AES-NI、TPM、真亂數產生器在「硬體安全」，Shor演算法與量子電腦的規模在「量子電腦硬體」，TLS的往返次數與HTTPS所保護的內容在「電腦網路基礎」，JWT與OAuth在「Web技術基礎」，熵則在「資訊理論與編碼基礎」單元中介紹。
