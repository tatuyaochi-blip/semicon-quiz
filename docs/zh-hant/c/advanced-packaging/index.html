先進技術（3D構裝與小晶片）的重點

僅靠微縮已難以持續提升效能，將多個晶片整合在同一個封裝中以提高效能的技術因而備受矚目。把依功能拆分的小晶片（Chiplet）組合起來的做法，在良率與成本方面也有優勢。

以TSV將晶片垂直堆疊的3D構裝，以及在中介層上並排放置處理器與HBM的2.5D構裝，已用於AI用的高效能半導體。
