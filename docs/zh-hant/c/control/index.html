控制工程基礎的重點

冷氣的溫度、馬達的轉速、電源的輸出電壓、硬碟磁頭的位置等，我們身邊的許多量，都是以回授控制保持一定的：把感測器量測的結果與目標值比較，再改變操作量。本單元學習作為這類迴路設計與分析基礎的古典控制。

首先確認開迴路控制、回授控制與前饋控制的差異、方塊圖與閉迴路轉移函數，以及負回授對變動的抑制，並介紹拉普拉斯轉換、轉移函數與終值定理。接著以計算確認一階系統的時間常數與步階響應、二階系統的阻尼比與自然角頻率、過衝與安定時間、極點位置與響應的關係，以及穩態誤差與系統型別。在穩定性方面，學習以極點表示的穩定條件、羅斯-赫維茲穩定準則與奈奎斯特穩定準則；在頻率響應方面，介紹波德圖與漸近線近似、積分元件、時間延遲、增益邊限與相位邊限的讀法，以及相位邊限與過衝的關係。後半部確認P、PI、PID控制各動作的作用、Ziegler–Nichols極限增益法、積分飽和與對策、微分衝擊、在微控制器上進行的離散時間PI控制計算、零階保持造成的相位落後，以及s平面與z平面的對應，並介紹馬達的串級控制、DC-DC轉換器的控制迴路與順序控制的入門。也可作為日本電氣主任技術者考試（第三種，機械科目）與韓國電氣技士考試「電路理論及控制工程」中自動控制部分的入門。計算題的數值，包括錯誤選項的數值，都已用Python（NumPy）計算確認。負回授的增益、運算放大器的相位邊限與相位補償在「類比與電子電路」，RC電路的時間常數在「電路與電磁學基礎」，z轉換、差分方程式與雙線性轉換在「數位訊號處理基礎」，PWM與計時器中斷在「嵌入式與韌體」，定點數與飽和運算在「電腦算術」，半導體工廠的製程控制（APC）則在「良率與品質管理」單元中介紹。
