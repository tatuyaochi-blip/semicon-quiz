微影的重點

第一次學習的人: 半導體晶片是怎麼做出來的？看懂前段、後段製程全貌 / EUV微影是什麼？用13.5 nm的光畫出電路的原理

微影是以光將光罩（倍縮光罩）上的電路圖案轉印到晶圓上光阻的製程。它是決定微縮極限的關鍵製程，曝光機更是半導體製造設備中特別尖端的設備。

縮短曝光波長λ、增大透鏡的數值孔徑NA，解析度就會提升。ArF準分子雷射（193 nm）的浸潤式曝光，以及波長13.5 nm的EUV曝光，被用於製造先進產品。
