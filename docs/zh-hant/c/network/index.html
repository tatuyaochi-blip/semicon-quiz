電腦網路基礎的重點

光是開啟一個網頁，就有許多機制依序運作：由名稱查出位址、選擇路徑、確實送達資料，並以加密加以保護。電腦網路把這些功能分層整理，讓各層只負責自己的角色。

本單元學習OSI參考模型與TCP/IP的階層、MAC位址與交換器、IP位址與子網路遮罩的計算、ARP與路由、TCP的三向交握、流量控制與壅塞控制，以及DNS、DHCP、TLS。也會介紹由頻寬與延遲求出傳輸時間的計算，以及無線區域網路、防火牆與VPN的基本觀念，有助於準備資訊相關證照考試的網路領域。

電腦網路基礎的題目列表（40題）
  1. 在OSI參考模型中，使用IP位址這類邏輯位址，在不同網路之間轉送封包並送達目的地的是哪一層？
  2. 在TCP/IP的四層模型中，TCP與UDP屬於哪一層？
  3. 傳送網頁資料時，在傳送端每當資料從上層交給下層時會發生什麼事？下列何者正確？
  4. 下列關於MAC位址的敘述，何者正確？
  5. 與集線器（中繼器集線器）相比，下列何者正確描述了L2交換器的運作？
  6. 在一台L2交換器上設定VLAN，將連接埠1～4設為VLAN 10，連接埠5～8設為VLAN 20。下列關於其運作的敘述，何者正確？
  7. 依照省略規則，把IPv6位址 2001:0db8:0000:0000:0000:0000:0000:0001 正確縮寫的是下列何者？
  8. 某終端的IP位址為 192.168.1.10，子網路遮罩為 255.255.255.0。它所屬網路的網路位址是下列何者？
  9. 在 192.168.5.0/26 的網路中，可以分配給主機（終端或路由器介面）的IP位址有幾個？
  10. 某終端的IP位址為 192.168.10.77/27。它所屬子網路的廣播位址是下列何者？
  11. 想在一個子網路中容納500台主機。能滿足此需求的子網路中，最小的（前綴長度最長的）是下列何者？
  12. 以子網路遮罩表示CIDR表示法的 /20，是下列何者？
  13. 下列IPv4位址中，哪一個屬於私有位址的範圍？
  14. 家用寬頻路由器會執行NAT（網路位址轉譯）的一種，即NAPT（IP偽裝）。NAPT能做到什麼？下列何者正確？
  15. 在執行NAPT的路由器（外側全球位址為 198.51.100.7）內側的終端A（192.168.1.10），以來源連接埠50000連線到Web伺服器 203.0.113.5 的443號連接埠。路由器把來源轉譯為 198.51.100.7 的連接埠61000。Web伺服器送回的回應封包，其目的地是下列何者？
  16. 下列關於ARP功能的敘述，何者正確？
  17. 某終端（192.168.1.10/24，預設閘道 192.168.1.1）要把封包送到另一個網路上的伺服器 203.0.113.80。ARP快取為空時，終端以ARP查詢哪一個對象的MAC位址？
  18. 路由器的路由表中有 0.0.0.0/0（下一個轉送對象為路由器A）、10.0.0.0/8（路由器B）、10.1.0.0/16（路由器C）、10.1.2.0/24（路由器D）4條路由。目的地為 10.1.5.9 的封包會送往哪一台路由器？
  19. IPv4標頭中TTL（Time To Live，存活時間）的功能，下列何者正確？
  20. 下列關於動態路由的敘述，何者正確？
  21. 下列關於UDP特徵的敘述，何者正確？
  22. 在建立TCP連線的三向交握中，交換封包的順序下列何者正確？
  23. 以HTTPS（在TCP之上的TLS 1.3）重新連線到RTT（往返時間）為100 ms的Web伺服器，從送出第一個請求到開始收到回應，所需時間最接近下列何者？假設DNS名稱解析已完成，並忽略伺服器的處理時間與資料的傳輸時間。
  24. 下列協定與其伺服器標準使用之連接埠號碼的組合，何者正確？
  25. 在TCP的流量控制中，接收端向傳送端通知視窗大小（接收視窗）的目的，下列何者正確？
  26. 某TCP連線的接收視窗固定為65536位元組，RTT為10 ms，線路頻寬足夠大且沒有遺失。此連線可得到的傳輸量上限最接近下列何者？
  27. 下列關於TCP壅塞控制之基本概念的敘述，何者正確？
  28. TCP的傳送端判斷區段遺失而重傳的時機，下列何者正確？
  29. DNS（網域名稱系統）的主要功能，下列何者正確？
  30. 快取中沒有任何資料的完整服務解析器（快取DNS伺服器），查詢 www.example.com 的IP位址時，詢問的順序下列何者正確？
  31. 以DHCP讓終端取得IP位址時，訊息的順序下列何者正確？
  32. HTTPS（以TLS保護的HTTP通訊）能保護的是下列何者？
  33. 在TLS中，瀏覽器能判斷所連線的伺服器「不是冒充者」的理由，下列何者正確？
  34. 以100 Mbps的線路傳送100 MB的檔案，所需時間最接近下列何者？忽略標頭等額外負擔與延遲，並設 1 MB = 10^6 位元組。
  35. 在1 Gbps的乙太網路上，讓IP封包的大小填滿MTU的1500位元組，持續傳送TCP資料。設IPv4標頭為20位元組、TCP標頭為20位元組、乙太網路標頭與FCS合計18位元組、前置碼與訊框間隙合計20位元組，則應用程式資料之傳輸量的上限最接近下列何者？
  36. 在RTT為50 ms、頻寬為100 Mbps的線路上，以收完前一個回應後才送出下一個的方式，重複100次會收到10 KB回應的請求。所需時間最接近下列何者？每次的時間設為RTT加上回應的傳輸時間（資料量÷頻寬），1 KB = 1000位元組，並忽略伺服器的處理時間。
  37. 無線區域網路不採用有線乙太網路一直使用的CSMA/CD，而採用CSMA/CA的主要理由，下列何者正確？
  38. 下列關於無線區域網路2.4 GHz頻段與5 GHz頻段一般差異的敘述，何者正確？
  39. 下列關於防火牆（封包過濾型）基本功能的敘述，何者正確？
  40. 下列關於網際網路VPN的敘述，何者正確？
