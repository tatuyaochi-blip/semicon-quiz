量測與分析的重點

半導體製造過程中，會量測線寬、膜厚、雜質濃度、缺陷等，一邊確認製程是否正確進行一邊推進。微縮越先進，就越需要奈米等級的精確量測。

依目的不同而使用不同的方法，例如以電子顯微鏡（SEM、TEM）觀察形狀、以光學方式量測膜厚（橢圓偏光術）、以二次離子質譜術（SIMS）量測雜質分布，以及以四點探針法量測片電阻。
