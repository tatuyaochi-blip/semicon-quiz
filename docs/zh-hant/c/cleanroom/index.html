無塵室與製造設備的重點

半導體製造中，即使是微小的微粒也會造成不良，因此要在將空氣中粒子保持得極少的無塵室內作業。潔淨度以一定體積空氣中所含的粒子數來表示。

在300 mm晶圓的工廠中，一般的做法是將晶圓放入稱為FOUP的密閉容器中自動搬運，只在設備內部維持高潔淨度。
