機器學習基礎的重點

第一次學習的人: 生成式AI怎麼運作？大型語言模型（LLM）的原理 / 機器學習是什麼？電腦從資料中找出規則的原理

機器學習是從資料中自動學到規則，用來進行預測與分類的技術。有使用正確答案標籤的監督式學習、從沒有標籤的資料中找出群聚的非監督式學習，以及以獎勵為線索學習行動的強化學習；不論哪種方法，重要的都是對未用於訓練的資料能預測得多準確（泛化性能）。

本單元以計算題為主，學習訓練、驗證、測試資料的分法與交叉驗證、過擬合與偏差、變異、正規化與丟棄法、由混淆矩陣求出的精確率、召回率與F1分數、ROC曲線，以及均方誤差。接著在線性迴歸、邏輯斯迴歸、決策樹、隨機森林、k最近鄰法、SVM、單純貝氏等代表性模型之後，介紹神經網路的前向傳播、啟動函數、損失函數、梯度下降法與反向傳播、小批次與epoch、CNN的輸出大小、RNN與Transformer、遷移學習、生成模型，以及LLM的詞元（token）。也有助於準備日本資訊技術人員考試與G檢定（JDLA Deep Learning for GENERAL）中的AI相關範圍。

機器學習基礎的題目列表（40題）
  1. 下列監督式學習的任務中，屬於迴歸的是何者？
  2. 下列何者屬於非監督式學習？
  3. 下列關於強化學習的敘述，何者適當？
  4. 下列關於以k-平均演算法（k-means）進行分群的步驟，何者適當？
  5. 下列關於主成分分析（PCA）的敘述，何者適當？
  6. 將資料分成訓練、驗證、測試三份時，下列何者是驗證資料的主要用途？
  7. 以1000筆資料進行5折交叉驗證（k = 5 的k折交叉驗證）時，每一回訓練使用的資料筆數為何者？
  8. 下列何者是發生過擬合（過度擬合）時會看到的情形？
  9. 將模型的誤差分成偏差（bias）與變異（variance）來思考時，下列何者適當？
  10. 下列關於抑制過擬合的正規化等方法的敘述，何者適當？
  11. 下列建立機器學習模型的步驟中，何者造成了資料洩漏（評估用資料的資訊混入訓練中）？
  12. 以200筆測試資料評估某個二元分類模型，其混淆矩陣為真陽性（TP）45筆、偽陽性（FP）5筆、偽陰性（FN）45筆、真陰性（TN）105筆。精確率與召回率的組合，何者正確？
  13. 以200筆測試資料評估某個二元分類模型，結果為TP 20筆、FP 5筆、FN 30筆、TN 145筆。F1分數最接近下列何者？
  14. 下列關於評估二元分類模型所用之ROC曲線與AUC的敘述，何者適當？
  15. 對於1000筆中只有10筆陽性的資料，將全部預測為陰性之模型的準確率為何者？
  16. 4筆資料的實際值為3、5、2、6，模型的預測值分別為2、5、4、4時，均方誤差（MSE）為何者？
  17. 以最小平方法將直線 y = ax + b 擬合到3筆資料 (x, y) = (1, 3)、(2, 4)、(3, 8)。x = 4 時的預測值為何者？
  18. 在邏輯斯迴歸中，將 z = 2x − 4 代入S型函數 σ(z) = 1 ÷ (1 + e^(−z)) 所得的值，作為陽性的機率輸出。x = 2 時的輸出為何者？
  19. 決策樹的某個節點中，有類別A的資料6筆、類別B的資料4筆。此節點的吉尼不純度為何者？
  20. 下列關於集成學習中裝袋法（Bagging，例如隨機森林）與提升法（Boosting）之差異的敘述，何者適當？
  21. 以k最近鄰法預測二維點 (0, 0) 的類別。訓練資料為紅色的點 (1, 0)、(3, 0)、(0, −3) 與藍色的點 (0, 2)、(−2, 1)。以歐幾里得距離計算時，k = 3 與 k = 5 的預測組合何者正確？
  22. 下列關於支援向量機（SVM）的敘述，何者適當？
  23. 全部電子郵件中有20%是垃圾郵件。某個單字出現在50%的垃圾郵件，以及5%的非垃圾郵件中。含有此單字的郵件為垃圾郵件的機率最接近下列何者？
  24. 只由輸入層與輸出層構成的簡單感知器（以閾值輸出0或1的單一神經元）無法表示的邏輯函數為何者？
  25. 在3個類別的分類中，輸入softmax函數的值（logit）為3、1、0。第1個類別的輸出（機率）約為第2個類別輸出的幾倍？最接近下列何者？
  26. 某個輸入為 x₁ = 1、x₂ = 2 的小型神經網路，隱藏層的兩個神經元為 h₁ = ReLU(x₁ + x₂ − 1)、h₂ = ReLU(x₁ − 2x₂ + 1)，輸出為 y = 2h₁ + 3h₂ + 1。y的值為何者？
  27. 設模型對正確類別輸出的機率為p時，下列關於分類訓練所用之交叉熵損失 −log p 性質的敘述，何者適當？
  28. 在梯度下降法中，權重 w = 2.0 處損失的梯度 ∂L/∂w 為0.5、學習率為0.1時，更新一次後的權重為何者？
  29. 以 u = 2x + 1、y = u²，用連鎖律求 y = (2x + 1)² 在 x = 1 的導數 dy/dx 時，正確的值為何者？
  30. 在堆疊許多層的神經網路中，若啟動函數使用S型函數，靠近輸入的層會難以學習，其理由為何者？
  31. 以小批次大小（批次大小）50，訓練1萬筆訓練資料。1個epoch中權重的更新次數為何者？
  32. 輸入為64個、輸出為32個的全連接層（每個輸出各有1個偏差），可訓練的參數數量為何者？
  33. 對28×28的單通道影像，以5×5的濾波器進行卷積（步幅1、不填充），接著進行2×2的最大池化（步幅2）。輸出的高與寬為何者？
  34. 下列關於遞迴神經網路（RNN）與LSTM的敘述，何者適當？
  35. 下列關於Transformer所用之自注意力（self-attention）的敘述，何者適當？
  36. 將以大量資料訓練好的模型，用少量資料運用到其他任務的遷移學習，下列敘述何者適當？
  37. 下列關於生成影像等資料之模型的敘述，何者適當？
  38. 下列關於大型語言模型（LLM）處理文章之方式的敘述，何者適當？
  39. 以過去的錄取結果作為正確答案，建立由應徵資料預測是否錄取的模型時，下列何者是應注意的事項？
