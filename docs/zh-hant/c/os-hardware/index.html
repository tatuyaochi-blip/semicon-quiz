作業系統與硬體的重點

作業系統（OS）是讓許多程式安全地分享CPU、記憶體、輸入輸出裝置等硬體的軟體。為此，CPU具備只有OS能使用的特權模式、中斷與例外的機制，以及用於虛擬記憶體的分頁表查詢電路等。

應用程式以系統呼叫請OS代為處理，OS藉由計時器中斷切換程式（內容切換），並在發生分頁錯誤時將所需的分頁準備到記憶體中。從裝置驅動程式、記憶體映射I/O，到虛擬機器監視器（hypervisor）的虛擬化，要學習硬體與軟體協同運作的機制。
