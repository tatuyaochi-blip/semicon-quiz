氧化與擴散的重點

將矽在高溫的氧氣或水蒸氣環境中加熱，表面會形成高品質的SiO2膜。這稱為熱氧化，長期用於閘極絕緣膜、元件隔離與遮罩等。

熱擴散是在高溫下藉由原子擴散，將雜質導入矽中的方法。擴散的進行程度強烈依賴溫度，因此溫度與時間的管理十分重要。
