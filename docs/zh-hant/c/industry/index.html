半導體產業與市場的重點

在半導體產業中，除了一家公司包辦從設計到製造、銷售的IDM之外，由不擁有工廠而專注於設計的無晶圓廠（Fabless）企業，與專門接受委託製造的晶圓代工（Foundry）企業進行分工的模式也日益普及。

積體電路的電晶體數量每隔一段時間就增加一倍的摩爾定律，長年以來一直是業界技術開發的指標。
