製程材料（氣體與藥液）的重點

半導體製造使用許多材料，包括高純度的矽，用於薄膜沉積與蝕刻的特殊材料氣體，用於清洗的藥液與超純水，以及濺鍍靶材、光阻、CMP研磨液等。

即使是微量雜質也可能造成不良，因此材料要求極高的純度。此外，許多氣體具有自燃性或毒性，安全處理不可或缺。
