邏輯電路的重點

數位電路由AND、OR、NOT等基本邏輯閘，以及其組合NAND、NOR、XOR等構成。運用真值表、布林代數與笛摩根定理，可以化簡邏輯式，或改用其他邏輯閘來替換。

也請掌握輸出僅由輸入決定的組合電路，與利用正反器等保持狀態的循序電路之間的差異。

這個領域的比較

  • 閂鎖器與正反器的差異：比較動作與使用時機以觸發方式、輸出的動作、構成、尺寸、時序分析、突波與數位設計中的使用時機等面向，用表格比較閂鎖器與正反器。
  • 組合邏輯電路與循序邏輯電路的差異：比較輸出的決定方式以輸出由什麼決定、記憶元件、時脈、回授、範例、時序與 HDL 寫法等面向，用表格比較組合邏輯電路與循序邏輯電路。
  • CMOS 與 TTL 的差異：比較邏輯 IC 系列以電晶體、靜態耗電量、電源電壓、邏輯準位、雜訊邊限、速度、輸入與使用場合等面向，用表格比較 CMOS 與 TTL 邏輯 IC。
  • 建立時間與保持時間的差異：定義、延遲、頻率、修正方式比較從定義、檢查所用的延遲（max 或 min）、與時脈頻率的關係、時脈偏斜的影響、違規的修正方式與要確認的角落等面向，以表格比較正反器的建立時間與保持時間。
  • 開汲極與推挽輸出的差異：結構、上升時間、線及、用途比較從輸出級結構、輸出 H 的機制、上升速度、線及（wired-AND）、與不同電壓電路的連接、消耗電流與用途等面向，以表格比較開汲極輸出與推挽輸出。
