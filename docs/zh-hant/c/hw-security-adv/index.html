硬體安全的進階主題與趨勢的重點

隨著雲端、AI與物聯網設備的普及，硬體安全要保護的對象與攻擊手法都有了很大的變化。連雲端業者的管理員也無法存取資料的機密運算、以硬體阻止指標錯誤的機制、面向量子電腦時代的密碼硬體，以及如何保護由眾多公司參與的半導體供應鏈，都是目前的重要主題。本單元在「硬體安全」單元的基礎上，學習更新、更深入的內容。

首先在機密運算方面，介紹VM型TEE與飛地型的差異及必須信任的範圍（TCB）、除了加密之外還需要完整性保護的理由與其記憶容量負擔的計算、驗證者在證明報告中要確認的內容、Arm CCA的領域（Realm），以及包含GPU的機密運算。接著學習CHERI的能力（capability）、MTE標記偶然一致之機率的計算、指標驗證，以及以影子堆疊與間接分支保護實現的控制流程完整性。在對DRAM的攻擊方面，介紹列鎚攻擊因微縮而更容易發生的理由、繞過TRR的研究、ECC的限制、DDR5的PRAC，以及刷新頻率與啟動次數的計算；在暫態執行攻擊方面，介紹MDS、retpoline與IBRS，以及對策造成效能下降的計算。後半部學習以數論轉換加速多項式乘法、ML-KEM的金鑰大小、解封裝實作的注意事項、可替換密碼的硬體設計、OpenTitan與Caliptra、DICE、A/B方式的更新與防回滾、硬體物料清單（HBOM）、小晶片之間的信任、分割製造、IC偽裝與邏輯鎖定，以及以逆向工程為前提的金鑰保護方式。最後確認FIPS 140-3的等級、共同準則的EAL、PSA Certified與SESIP的組合想法、安全除錯、生命週期與RMA、掃描鏈的保護，以及以電壓突波、雷射與電磁脈衝進行的故障注入，並計算其成功機率與對策的效果。目的不在攻擊步驟，而在於從設計者與防禦者的角度理解原理與對策。計算題的數值，包括錯誤選項的數值，都已用 Python 計算確認。產品名稱、規格版本與年份，是各題中所示時間點的資訊。旁通道攻擊、Spectre、Meltdown與KPTI、功耗分析、故障注入與列鎚攻擊的基礎、安全開機、TPM、TEE、TrustZone與飛地、PUF、真亂數產生器、硬體木馬與停用JTAG在「硬體安全」，ML-KEM與ML-DSA的標準及HSM在「密碼學基礎與應用」，DRAM的刷新與列鎚攻擊這個現象的名稱在「DRAM」，小晶片與UCIe在「先進技術（3D構裝與小晶片）」，掃描設計在「測試與檢查」，A/B方式的韌體更新在「嵌入式與韌體」，ISO/SAE 21434則在「車用半導體與功能安全」單元中介紹。
