MOSFET的重點

第一次學習的人: 電晶體是什麼？手機裡超過100億個的小開關 / 積體電路（IC）是什麼？晶片、晶粒、LSI、SoC的差異

MOSFET是藉由閘極電壓在半導體表面形成反轉層（通道），以控制源極—汲極之間電流的電晶體。由於閘極被一層薄絕緣膜隔開，穩態下幾乎沒有閘極電流流動。

臨界電壓、線性區與飽和區、短通道效應，以及結合nMOS與pMOS的CMOS電路，都是理解LSI的重要主題。

這個領域的比較

  • JFET與MOSFET的差異：比較閘極結構與使用時機以閘極的結構、常開或常關、閘極電流、雜訊、抗靜電能力、整合度與用途等面向，用表格比較JFET與MOSFET。
  • nMOS 與 pMOS 的差異：載子、遷移率、臨界電壓、在 CMOS 中的角色比較從結構、載子、遷移率、臨界電壓的正負、導通條件、在 CMOS 中的角色、容易傳遞的邏輯準位、相同驅動力所需的閘極寬度等面向，以表格比較 nMOS 與 pMOS。
  • 增強型與空乏型 MOSFET 的差異：臨界電壓、符號、用途比較從閘極 0 V 時的狀態、臨界電壓的正負、通道的形成方式、截止電流的方法、電路符號、安全性與用途等面向，以表格比較增強型與空乏型 MOSFET。
  • DIBL、GIDL、貫穿的差異：發生位置、原因、Id-Vg 特性、對策比較從發生位置、明顯的偏壓條件、物理原因、在 Id-Vg 與 Id-Vd 特性上的表現、對閘極長度與電壓的依存性、對策、容易成為問題的情境等面向，以表格比較短通道 MOSFET 漏電相關的 DIBL（汲極引發位障降低）、G…
  • MOSFET截止區、線性區、飽和區的差異：條件、電流公式、用途比較從nMOS的VGS與VDS條件、通道狀態、汲極電流公式、電流的行為、小訊號下的等效、數值範例、主要用法、與雙極性電晶體工作區的對應、短通道下的差異等面向，以表格比較MOSFET的截止區、線性區（三極管區）與飽和區。
