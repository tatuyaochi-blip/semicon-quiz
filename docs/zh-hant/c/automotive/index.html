車用半導體與功能安全的重點

汽車的半導體在−40 ℃到高達150 ℃的溫度下使用15年左右，且故障攸關人命，因此要求比消費性產品更嚴格的品質與可靠度。AEC-Q100等認證試驗、以零不良為目標的品質管理、變更通知與可追溯性是其基礎。

此外，在ISO 26262的功能安全中，依危險的大小決定ASIL，並以鎖步CPU、ECC、電壓與時脈監視等安全機制偵測故障，轉移至安全狀態。從CAN與車載乙太網路等網路、48 V與800 V系統的電源，到ADAS的感測器與SOTIF，學習車用電子設計的基本觀念。
