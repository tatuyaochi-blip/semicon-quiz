系統架構與可靠度設計的重點

資訊系統的好用程度與不易停止的程度，不只取決於1台電腦的效能，更取決於如何組合設備，以及故障時如何繼續處理。像半導體工廠的製造執行系統（MES）或收集設備資料的伺服器這類一旦停止就直接影響生產的系統，這種設計格外重要。

本單元學習主從式架構、三層式架構、點對點、批次處理與線上處理等系統架構，以及雙重系統與雙工系統、熱備援、叢集、單一故障點等備援的概念。此外，也搭配計算題，介紹 RAID 的容量與可承受的故障台數、備份的還原步驟、RPO 與 RTO、失效安全等可靠度設計、IaaS、PaaS、SaaS 與即時遷移、SAN 與 NAS、PUE 與不斷電系統（UPS），以及所需伺服器台數的估算，有助於準備資訊相關證照考試的系統構成要素領域。

  1. 關於主從式架構（client-server）系統的說明，下列何者適當？
  2. 在三層式架構的主從式系統中，負責業務處理（商業邏輯）的是下列哪一層？
  3. 關於精簡型用戶端（thin client）的說明，下列何者適當？
  4. 關於點對點（P2P）式系統的特徵，下列何者適當？
  5. 與集中式處理相比，分散式處理的特徵為下列何者？
  6. 適合以批次處理進行的處理為下列何者？
  7. 在評估線上處理系統效能的指標中，關於回應時間（response time）的說明，下列何者適當？
  8. 某系統依序以 Web 伺服器層、應用程式伺服器層、資料庫伺服器層處理使用者的要求。每個要求各通過3層一次，各層能處理的最大件數為：Web 伺服器層每秒1,200件、應用程式伺服器層每秒1,000件、資料庫伺服器層每秒900件。將資料庫伺服器層強化為每秒可處理1,500件時，整個系統能處理的最大件數為下列何者？
  9. 關於雙重系統（dual system）的說明，下列何者適當？
  10. 將半導體工廠製造執行系統（MES）的伺服器，做成由主系統（運轉系統）與備援系統組成的雙工系統。當備援系統採用熱備援時，其特徵為下列何者？
  11. 某系統以2台負載平衡器做備援，其下配置3台 Web 伺服器，所有 Web 伺服器都使用1台資料庫伺服器。在此列出的設備中，屬於單一故障點（該處停止就會使整個系統停止的地方）的是下列何者？
  12. 某叢集採用主動/主動（active-active）架構，由5台伺服器平均分擔處理。使用率與處理量成正比。希望即使1台故障、由其餘4台平均接手處理時，各伺服器的使用率仍能保持在80%以下。平常時（5台都在運轉）各伺服器使用率的上限為下列何者？
  13. 某系統準備3台可用率為0.95的伺服器，只要其中2台以上在運轉，就能確保所需的處理能力。伺服器彼此獨立故障，且不考慮伺服器以外設備的故障。此系統的可用率為下列何者？
  14. 下列何者是基於失效弱化（fail-soft）概念的設計範例？
  15. 在半導體製造設備中，使用以氣壓開啟的常態關閉（normally closed）型氣體供應閥，使發生停電或壓縮空氣喪失時，閥門會關閉而停止危險氣體的供應。這種設計的概念為下列何者？
  16. 下列何者是基於防呆（fool-proof）概念的設計範例？
  17. 在提高系統可靠度的概念中，屬於避錯（fault avoidance）的是下列何者？
  18. 關於 RAID 1 的說明，下列何者適當？
  19. 以4台容量為4 TB的磁碟組成 RAID 5。可記錄資料的容量為下列何者？
  20. 以6台容量為8 TB的磁碟組成 RAID 6。可記錄資料的容量，與不失去資料而能承受同時故障的磁碟台數之組合，下列何者正確？
  21. 在以4台磁碟組成的 RAID 10（每2台組成1組鏡像，共2組，再對這2組做等量分割）中，4台裡有2台同時故障。若哪2台故障的機率都相等，資料遺失的機率為下列何者？
  22. 以4台每台每秒可進行200次隨機輸入輸出（IOPS）的磁碟組成 RAID 5。每進行1次小資料的隨機寫入，需要讀取舊資料與舊同位元、寫入新資料與新同位元，合計4次輸入輸出，且不考慮快取的效果。只進行寫入時，整個 RAID 5 能處理的寫入次數為下列何者？
  23. 關於差異備份的說明，下列何者適當？
  24. 每週日晚上進行完整備份，週一到週六每晚進行增量備份。週四中午發生故障，決定把資料還原到週三晚上備份的時間點。還原時使用的備份數量為下列何者？
  25. 在資料總量為500 GB的系統中，每週日進行完整備份，週一到週六每晚進行差異備份。假設每天都有之前未曾變更的另外20 GB資料被變更。週一到週六共6次差異備份的容量合計為下列何者？
  26. 關於營運持續計畫中所稱 RPO（復原點目標）的說明，下列何者適當？
  27. 某系統訂定 RPO（復原點目標）為4小時、RTO（復原時間目標）為2小時。故障隨時都可能發生，且備份所需的時間可以忽略。能滿足此目標的資料保護方式為下列何者？
  28. 在相距1,000 km的2座資料中心之間，對資料庫的更新進行同步複寫。每次更新都要等待1次往返通訊：傳送到另一端，以及寫入完成的通知。設光纖中的光速約為20萬 km/s，且光纖路徑的長度視為與直線距離相同時，僅因通訊傳播而使1次更新的回應時間增加的量，最接近下列何者？
  29. 在雲端運算服務的 IaaS 中，一般由使用者自行管理的是下列何者？
  30. 在提高系統處理能力的方法中，屬於水平擴展（scale-out）的是下列何者？
  31. 對於使用自動擴展（autoscaling）、依負載自動增減伺服器台數的系統，一般而言較理想的設計為下列何者？
  32. 關於虛擬化環境中即時遷移（live migration）的說明，下列何者適當？
  33. 關於 CDN（內容傳遞網路）的說明，下列何者適當？
  34. 在半導體工廠中，希望利用從許多製造設備以高頻率收集的感測器資料，即時偵測異常。不把資料全部送到遠方的雲端處理，而是在設備附近的電腦上處理，即採用邊緣運算。其主要的優點為下列何者？
  35. 在儲存設備的連接方式中，關於 SAN（儲存區域網路）的說明，下列何者適當？
  36. 從實體容量為100 TB的儲存池，以精簡配置（thin provisioning）建立了30個邏輯容量為5 TB的磁碟區。目前各磁碟區平均寫入了邏輯容量40%的資料，且資料每週合計增加2 TB。不考慮資料的刪除與壓縮時，儲存池的使用率達到80%的時間為下列何者？
  37. 某資料中心的 IT 設備耗電為800 kW、冷卻設備耗電為280 kW、電源設備的損失與照明等為120 kW。改善冷卻方式而只讓冷卻設備的耗電減半時，PUE 為下列何者？
  38. 資料中心將 UPS（不斷電系統）與自備發電設備搭配使用的理由，下列何者適當？
  39. 關於資料中心伺服器機櫃配置中所使用的熱通道/冷通道概念，下列何者適當？
  40. 設計一個尖峰時必須每秒處理1,800件要求的 Web 系統。1台伺服器最多每秒能處理250件，且希望各伺服器的使用率壓在70%以下。此外，即使1台伺服器故障，其餘伺服器也要滿足此條件（N+1 架構）。負載平均分散時，所需伺服器的最少台數為下列何者？
