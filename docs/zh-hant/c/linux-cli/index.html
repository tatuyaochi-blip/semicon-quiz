Linux與命令列基礎的重點

大多數的伺服器與雲端都以 Linux 運作，邏輯合成、電路模擬等 EDA 工具通常也在 Linux 伺服器上使用。在那裡，日常工作不是點按畫面上的按鈕，而是在 shell 中輸入指令：查看檔案、篩選日誌、讓耗時的處理在中斷連線後繼續執行等。

本單元學習目錄結構與絕對路徑、相對路徑、隱藏檔、硬連結與符號連結、萬用字元、檔案權限的 rwx 與八進位表示法、umask、目錄的執行權限，以及 sudo 與 setuid。接著介紹重新導向與管線、grep 與正規表示式、結合 sort 與 uniq 的統計、tail -f、cut、sed、awk、find、kill 與訊號、Ctrl+Z 與 bg、fg、nohup、結束狀態與 &&、||、引號與變數展開、腳本的引數、條件與迴圈、PATH 與 export，最後確認套件管理、systemctl、cron 排程、df 與 du、SSH 金鑰、tar，以及 Git 的 add、commit、push 與 .gitignore。指令的行為以 bash 與 GNU 的指令（coreutils、grep、sed、findutils、tar）為準，題目中的輸出都已在 Linux 上實際執行確認。行程與虛擬記憶體的機制在「作業系統與硬體」，連接埠編號與 DNS 在「電腦網路基礎」，存取控制的概念在「資訊安全基礎」，Git 的合併與開發的進行方式則在「軟體開發與專案管理」單元中介紹。
