AD/DA轉換的重點

ADC（類比數位轉換器）將類比訊號轉換為數位值，DAC（數位類比轉換器）則將數位值轉換為類比訊號。在感測器、通訊、音訊等連接現實訊號與數位處理的地方，一定會用到它們。

表示性能的基本指標是解析度（位元數）與轉換速度。請掌握取樣定理、量化誤差，以及快閃式、逐次逼近式、ΔΣ式等各種架構的特點。
