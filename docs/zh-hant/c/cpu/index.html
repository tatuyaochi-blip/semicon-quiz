CPU與架構的重點

第一次學習的人: CPU是什麼？它在電腦和手機裡做些什麼 / 手機裡有哪些半導體？主要晶片與各自的功能

CPU藉由重複指令的擷取、解碼與執行來處理程式。多數電腦採用將程式與資料放在同一個主記憶體中的馮紐曼架構。

提升效能的做法包括：將指令處理分成多個階段並重疊執行的管線、彌補與主記憶體速度差距的快取，以及利用多個核心進行平行處理等。半導體的微縮支撐了這些技術的演進。

這個領域的比較

  • RISC 與 CISC 的差異：指令集的設計理念與代表例比較從指令長度、記憶體存取、暫存器、解碼、程式碼大小，以及 ARM、RISC-V、x86 等實例的面向，以表格比較 RISC 與 CISC 的指令集架構。
  • ARM、RISC-V、x86 的差異：比較指令集架構以設計理念、指令長度、授權、暫存器、軟體生態、優勢與用途等面向，用表格比較 ARM、RISC-V、x86。
  • 馮紐曼架構與哈佛架構的差異：比較指令與資料的處理以記憶體、匯流排、傳輸量、靈活性、複雜度、代表性裝置與修正式哈佛架構等面向，用表格比較馮紐曼架構與哈佛架構。
  • 循序執行與亂序執行的差異：發出順序、危障、電路規模、IPC 比較從指令的發出順序、發生等待時的動作、危障的處理、暫存器重新命名與 ROB、電路規模與功耗、IPC、使用場合等面向比較循序執行與亂序執行。
