環境安全的重點

半導體工廠使用許多氫氟酸等化學品，以及具毒性、可燃性的特殊材料氣體。基本原則是了解化學物質的危險性，並依照SDS（安全資料表）正確處理。

廢氣要經過除害裝置處理後才排放。此外，減少用於蝕刻與設備清潔的PFC等溫室氣體的排放，也成為重要課題。
