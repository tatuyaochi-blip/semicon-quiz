連結器與載入器與執行檔格式的重點

編譯器輸出的是無法直接執行的目的檔。連結器會收集多個目的檔與函式庫，將函式與變數的名稱（符號）對應到實際位址（符號解析），再把這些位址寫入指令中（重定位），製作出執行檔。

載入器將執行檔讀入記憶體，整理好文字（text）、資料、BSS、堆積（heap）、堆疊（stack）等區域後開始執行程式。在執行時才連結函式庫的動態連結，以及不論放在哪個位址都能執行的位置無關程式碼（PIC），對節省記憶體與提升安全性都有幫助。

這個領域的比較

  • 靜態連結與動態連結的差異：比較函式庫的結合方式以連結時機、執行檔大小、記憶體使用量、更新、啟動、散布、效能與用途等面向，用表格比較靜態連結與動態連結。
  • 堆疊與堆積的差異：比較記憶體區域的使用方式以用途、配置方式、速度、生命週期、大小限制、位置、碎片化與常見錯誤等面向，用表格比較堆疊與堆積記憶體。
