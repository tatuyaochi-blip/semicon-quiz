矽晶圓的重點

多數半導體元件都製作在由高純度單晶矽切成薄片而成的晶圓上。單晶的製造方法有：從坩堝中熔融的矽拉出晶體的CZ法，以及不使用坩堝的FZ法。

拉出的晶體經過切片、研磨、清洗後成為晶圓。晶圓尺寸持續增大，在先進的量產產線上，300 mm晶圓是主流。
