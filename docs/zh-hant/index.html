學習課程

不知道該從哪裡學起時，請選擇符合目標的課程，依序學習吧。

初次認識半導體 從半導體的原理，到電晶體、晶片的製造方法以及產業全貌，快速瀏覽一遍。推薦作為第一步。 9個領域 深入了解元件 從物性基礎到電晶體、先進電晶體、功率與化合物半導體以及感測器，依序學習元件的原理。 9個領域 完整掌握製造製程 依流程順序學習前段製程：晶圓、無塵室、氧化、微影、蝕刻、薄膜沉積、配線、量測與良率。 13個領域 電路、設計與記憶體 從邏輯電路和類比電路，到 AD/DA 轉換、CPU、各類記憶體以及設計流程，學習晶片的內部與設計。 8個領域 後段製程、品質與安全 學習將晶片作為產品交付所需的知識：封裝與先進封裝、測試、可靠度、環境安全以及產業動向。 6個領域 從電晶體到軟體 從電晶體與邏輯電路，到電腦的數值表示方式、編譯器、作業系統、記憶體階層，由下而上逐步了解軟體如何在硬體上運作。 8個領域
