什麼是脈衝響應

對系統輸入單位脈衝 δ[n]（只有 n = 0 為1，其他為0）時的輸出 h[n]。對線性非時變（LTI）系統，任意輸入的輸出都可由輸入與 h[n] 的摺積 y[n] = Σx[k]h[n − k] 求得，因此 h[n] 代表系統的全部性質。h[n] 在有限長度結束的稱為FIR濾波器，無限延續的稱為IIR濾波器。Σ|h[n]| 為有限是BIBO穩定的條件，h[n] 的z轉換就是轉移函數 H(z)。

日文名稱: インパルス応答

練習脈衝響應的題目

設 u[n] 為單位步階。脈衝響應如下的LTI系統中，BIBO穩定（有界的輸入必定得到有界的輸出）的為下列何者？

  1. Ah[n] = (−0.9)ⁿu[n]
  2. Bh[n] = u[n]
  3. Ch[n] = (1.1)ⁿu[n]
查看答案與解析

正確答案：A. h[n] = (−0.9)ⁿu[n]

LTI系統BIBO穩定的充要條件，是脈衝響應絕對值的總和 Σ|h[n]| 為有限。h[n] = (−0.9)ⁿu[n] 的 Σ|h[n]| = Σ0.9ⁿ = 1/(1 − 0.9) = 10，為有限，因此穩定。h[n] = u[n] 是持續累加輸入的累加器，總和為無限大，對固定的輸入，輸出會無止境地增加。(1.1)ⁿ 隨時間變大，因此不穩定。

把 x[n] = {1, 2, 3}（n = 0, 1, 2）輸入脈衝響應為 h[n] = {1, −1}（n = 0, 1）的LTI系統。輸出 y[0]～y[3] 為下列何者？

  1. A−1, −1, −1, 3
  2. B1, 3, 5, 3
  3. C1, 1, 1, −3
查看答案與解析

正確答案：C. 1, 1, 1, −3

摺積（卷積）y[n] = Σx[k]h[n − k] 在 h[n] = {1, −1} 時成為 y[n] = x[n] − x[n − 1]（與前1個輸入的差）。y[0] = 1 − 0 = 1，y[1] = 2 − 1 = 1，y[2] = 3 − 2 = 1，y[3] = 0 − 3 = −3。輸出的長度由輸入長度3與脈衝響應長度2得 3 + 2 − 1 = 4。
