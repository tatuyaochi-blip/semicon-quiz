什麼是PID控制

把與誤差 e 成正比的項（P）、與誤差的積分成正比的項（I）、與誤差的微分成正比的項（D）相加，以決定操作量的回授控制。寫成 u = Kp(e + (1/Ti)∫e dt + Td·de/dt)，Kp 稱為比例增益，Ti 稱為積分時間，Td 稱為微分時間。比例負責速度，積分負責消除穩態誤差，微分負責抑制振盪。結構簡單，用於溫度、馬達、電源、化學製程等大部分的工業控制迴路。

日文名稱: PID制御

「PID控制」出現在2領域的9道練習題中（控制工程基礎, 類比與電子電路等）。

這個名詞所屬的領域: 控制工程基礎

3種動作的角色

比例動作的增益越高就越快，但單靠它會殘留穩態誤差（偏移），增益太高則會振盪。積分動作累積殘留的誤差，使穩態誤差為0，但會使相位落後而容易振盪。微分動作預先察覺誤差的變化以抑制振盪，但會放大雜訊，因此要與低通濾波器組合成不完全微分來使用。

增益的決定方式

若有受控體的模型，可以一邊以波德圖確認相位邊限一邊決定。沒有模型時，以Ziegler–Nichols的極限增益法或步階響應法等經驗法則決定初始值，再一邊觀察過衝與安定時間一邊調整。Ziegler–Nichols的值會給出相當振盪的響應，因此多半要從那裡再降低增益。

以數位方式實作時的注意事項

在微控制器上，每隔固定的取樣週期 Ts，以 Σe·Ts 計算積分，以 (e[k] − e[k − 1])/Ts 這類差分計算微分。對操作量飽和所造成的積分飽和，以條件積分等方法防範；對目標值急遽變化所造成的微分衝擊，則讓微分只作用在量測值上來防止。取樣與計算的延遲會使相位落後，因此取樣頻率要選得比增益交越頻率高很多。

練習PID控制的題目

在PI控制中，加入積分（I）動作的主要目的與其副作用的組合，正確的是下列何者？

  1. A目的是去除高頻的雜訊，副作用是穩態誤差變大
  2. B目的是消除對固定目標值或擾動的穩態誤差，副作用是相位落後而容易振盪
  3. C目的是預先察覺誤差的變化以加快響應並抑制超越，副作用是大幅放大高頻的雜訊
查看答案與解析

正確答案：B. 目的是消除對固定目標值或擾動的穩態誤差，副作用是相位落後而容易振盪

積分動作把誤差隨時間累積成操作量，因此只要還殘留一點誤差，就會持續改變操作量，最後使穩態誤差為0。另一方面，積分元件會使相位落後90°，因此相位邊限減少，容易發生過衝與振盪。所以要調整積分時間 Ti，避免設得太短。加快響應、抑制超越並容易放大雜訊，是微分動作的特徵。

PID控制的微分（D）動作的性質與實作上的對策，正確的組合是下列何者？

  1. A具有把誤差隨時間累積以消除穩態誤差的作用，為了防止積分飽和，要拿掉操作量的上限與下限
  2. B頻率越高增益越小，因此對雜訊很強；加入低通濾波器會使相位落後而不穩定，因此不加濾波器、直接使用
  3. C以與誤差變化速度相應的操作量抑制振盪，但會大幅放大高頻的雜訊，因此與低通濾波器組合成不完全微分
查看答案與解析

正確答案：C. 以與誤差變化速度相應的操作量抑制振盪，但會大幅放大高頻的雜訊，因此與低通濾波器組合成不完全微分

微分動作輸出與誤差變化速度成正比的操作量，在誤差變大之前搶先反應，因此具有抑制振盪、增加阻尼的作用。微分元件 s 的增益與頻率成正比地增大，因此會大幅放大感測器雜訊這類高頻成分。所以要像 Td·s/(1 + Td·s/N) 這樣組合一階低通濾波器（不完全微分），把高頻的增益限制在約 N 倍。N 多半選在8～20左右。

常見問題

PI控制與PID控制要如何區分使用？

流量、壓力、溫度等許多控制只用PI控制就足夠，微分容易受雜訊影響，因此也常常不使用。對慣性大、容易振盪的受控體，或需要快速響應的馬達位置控制等，則加上微分以增加阻尼。

並聯形式與標準形式有什麼不同？

並聯形式寫成 u = Kp·e + Ki∫e dt + Kd·de/dt，3個增益獨立表示。標準形式寫成 Kp(e + (1/Ti)∫e dt + Td·de/dt)，其中 Ki = Kp/Ti、Kd = Kp·Td。不同的產品與函式庫採用不同的形式，因此移轉參數時需要換算。
