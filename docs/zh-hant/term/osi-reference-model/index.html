什麼是OSI參考模型

把通訊功能分為實體層、資料連結層、網路層、傳輸層、會議層、表現層、應用層7層來整理的模型。用來作為分別思考各層角色的共通語言。

日文名稱: OSI参照モデル

「OSI參考模型」出現在1領域的2道練習題中（電腦網路基礎等）。

這個名詞所屬的領域: 電腦網路基礎

7層的角色

最下方的第1層（實體層）處理以纜線或電波把位元當作訊號傳送。第2層（資料連結層）以MAC位址把訊框送到同一網路內的相鄰設備。第3層（網路層）以IP位址選擇跨網路的路徑並轉送封包。第4層（傳輸層）處理終端上應用程式之間的通訊，例如TCP會控制重傳與順序。第5～7層（會議層、表現層、應用層）負責通訊開始與結束的管理、資料表示方式的轉換，以及應用程式的功能。

與TCP/IP四層的對應

實際的網際網路使用的是TCP/IP協定族，其模型以連結層、網際網路層、傳輸層、應用層4層表示。大致上，連結層對應OSI的第1～2層，網際網路層對應第3層，傳輸層對應第4層，應用層對應第5～7層。OSI的協定本身並未普及，但其層的編號至今仍用來表示設備或功能運作在哪一層，例如「L2交換器」「L3交換器」「L7負載平衡」。

分層的好處

各層只使用正下方一層提供的功能，並向正上方一層提供功能。傳送端由各層加上標頭把資料包起來（封裝），接收端則從下層依序移除。只要遵守層與層之間的約定，替換某一層的技術時，其他層也能照常使用。例如把有線區域網路換成無線區域網路，IP、TCP與Web瀏覽器都不需修改就能運作。

練習OSI參考模型的題目

在OSI參考模型中，使用IP位址這類邏輯位址，在不同網路之間轉送封包並送達目的地的是哪一層？

  1. A資料連結層（第2層）
  2. B網路層（第3層）
  3. C傳輸層（第4層）
查看答案與解析

正確答案：B. 網路層（第3層）

OSI參考模型將通訊功能從實體層到應用層分為7層來整理。網路層（第3層）使用IP位址這類邏輯位址，跨越多個網路選擇通往目的地的路徑並轉送封包。其下的資料連結層只負責在同一網路內，以MAC位址把訊框送到相鄰的設備。傳輸層處理終端上應用程式之間的通訊，例如TCP會負責重傳與順序的管理。以設備來說，路由器運作於第3層，L2交換器運作於第2層。

常見問題

OSI參考模型的7層由下而上是哪些？

實體層、資料連結層、網路層、傳輸層、會議層、表現層、應用層。路由器主要運作於第3層，L2交換器運作於第2層，集線器運作於第1層。

OSI參考模型與TCP/IP模型該記哪一個？

最好兩者的對應都掌握。實際使用的是TCP/IP的協定，但設備與功能的定位常以OSI參考模型的編號來表示，例如「第3層」「L7」。
