什麼是NPU(神經網路處理單元)

以高速且低消耗功率執行 AI 神經網路推論處理的專用電路。搭載於智慧型手機與個人電腦的 SoC。

日文名稱: NPU(ニューラルプロセッシングユニット)

「NPU(神經網路處理單元)」出現在2領域的6道練習題中（AI硬體與軟體堆疊, CPU與架構等）。

這個名詞所屬的領域: CPU與架構

NPU 計算的內容

神經網路推論以矩陣乘法與卷積為主，這些運算可分解為極大量的乘積累加（MAC）運算。NPU 在小面積內塞入數千個 MAC 單元，通常排列成脈動陣列或寬矩陣引擎，並透過專用的資料搬移引擎，從晶片內 SRAM 緩衝區供應資料。激活函數、池化與正規化則由獨立的單元處理。大多數行動裝置 NPU 以低精度運算，通常為 8 位元整數（INT8）或更低，或 16 位元浮點數。

為什麼效率勝過 CPU

通用 CPU 的大量能量花在指令擷取與解碼、分支預測及亂序執行的記錄管理上，而非算術運算本身。從外部 DRAM 擷取資料所耗的能量遠高於一次乘法，因此資料搬移往往才是真正的限制。NPU 去除通用用途的機制，將權重與激活值保存在本地記憶體中，讓每個數值被重複使用多次，並採用窄位元運算，因為乘法器的面積與能耗會隨位元寬度急劇增加。結果是在 AI 工作上獲得遠高的每瓦效能，代價則是彈性降低。

NPU、GPU 與 CPU 的比較

GPU 可執行數千個可程式化執行緒，能彈性處理浮點訓練與推論，但耗電量大得多。NPU 的適用範圍較窄，針對手機或筆電 SoC 僅數瓦的功率預算下的推論進行最佳化。CPU 仍是備援，因此 NPU 無法執行的層可能在 CPU 上執行得慢很多，並迫使代價高昂的資料傳輸。NPU 的處理能力以 TOPS（每秒兆次運算）表示，這是取決於精度與稀疏性假設的峰值數字；實際速度則取決於記憶體頻寬，以及模型與硬體的對應程度。

讓 NPU 可用的軟體

NPU 的實用程度取決於其軟體堆疊。以浮點訓練的模型會被量化為 INT8 或更低精度，可在訓練後進行，或透過量化感知訓練來維持準確度。接著 AI 編譯器與推論執行環境會融合運算、選擇記憶體配置、將運算切塊以放入晶片內緩衝區，並為特定 NPU 產生核心程式。這種裝置端推論可實現照片強化、語音辨識與翻譯等功能，延遲低且不需將資料傳送到伺服器。

練習NPU(神經網路處理單元)的題目

智慧型手機SoC上搭載的NPU，在AI推論上比CPU電力效率高，其主要原因為下列何者？

  1. A因為NPU不使用電力而是以光來計算
  2. B因為排列了大量INT8等低精度的乘加運算單元，並省去了AI計算不需要的通用電路
  3. C因為NPU必定以比CPU更高的時脈運作
查看答案與解析

正確答案：B. 因為排列了大量INT8等低精度的乘加運算單元，並省去了AI計算不需要的通用電路

CPU為了能執行任何事，每個指令都要驅動分支預測與指令重新排序等許多電路。NPU專精於矩陣的乘加，排列大量低精度的運算單元，並設計成讓資料在晶片內重複使用，因此每次運算所需的能量小了好幾個數量級。相對地，它不適合AI以外的處理，或不支援的運算。

常見問題

NPU 和 GPU 有什麼不同？

GPU 是彈性、可程式化的平行處理器，適合訓練與推論，但通常功耗較高。NPU 是專門用於低精度神經網路推論的加速器，能源效率較佳，但支援的運算種類較少。

NPU 的 TOPS 是什麼意思？

TOPS 是每秒兆次運算，一次乘積累加通常計為兩次運算。它是綁定特定精度的峰值數字，因此只能在相同精度下比較 TOPS，並將其視為上限。

為什麼 NPU 用 INT8 而不用浮點數？

窄位元整數運算所需的乘法器小得多、能耗也低，與 16 或 32 位元數值相比，記憶體流量可減為一半或四分之一。量化得當的模型在推論上通常只損失少許準確度。
