什麼是時間局部性

曾經存取過的資料或指令，在不久之後容易再次被存取的性質。例如在迴圈中重複使用的變數，是快取有效的原因之一。

日文名稱: 時間的局所性

「時間局部性」出現在2領域的2道練習題中（記憶體階層與效能, CPU與架構等）。

這個名詞所屬的領域: 記憶體階層與效能

時間局部性的意義

當程式使用的某個項目很可能在不久後再次被使用時，該程式就具有時間局部性。迴圈計數器、累加器、經常呼叫的函式，以及迴圈主體的指令都是典型例子：一旦載入，就會被一再存取。快取利用這一點，把最近使用的資料保存在靠近處理器的地方；LRU（最近最少使用）等替換策略則押注於「最近使用能預測未來使用」，逐出最久未被存取的項目。在最細的尺度上，當編譯器把常用變數完全保留在暫存器而不經過記憶體時，暫存器也是在利用時間局部性。

時間局部性與空間局部性

空間局部性是指傾向於使用與剛使用過的位址相鄰的位址，例如從頭到尾讀取一個陣列。快取利用這一點，在每次未命中時抓取一整條快取線，通常為 64 位元組。時間局部性則關乎同一項目隨時間的重複使用，由快取容量與替換策略加以利用。對巨大陣列只掃過一次，具有良好的空間局部性，但沒有時間局部性；反覆更新同一個加總變數具有很強的時間局部性；對隨機位址各讀取一次則兩者皆無。

重用距離及其重要性

量化時間局部性的實用方法是重用距離（reuse distance）：同一條快取線兩次使用之間所存取的不同快取線數量。在全關聯的 LRU 快取中，只要重用距離小於快取可容納的快取線數，存取就會命中。L1 只需幾個週期即可存取，L3 需要數十個週期，DRAM 則要數十到約 100 ns，也就是數百個週期，因此縮短重用距離對效能的影響，往往比減少運算次數本身更大。

在程式碼中改善時間局部性

程式設計師與編譯器透過重新排列工作順序來縮短重用距離。迴圈分塊（tiling）會在處理完快取大小的一塊資料的所有工作後才移到下一塊，迴圈融合則把存取同一陣列的兩個迴圈合併，讓資料趁仍在快取中時被重複使用。把常用值放在區域變數中，可讓編譯器將其保存在暫存器內。反之，只寫入一次且不會很快被再用的資料，可以用繞過快取的非時間性儲存（non-temporal store）寫入，以免逐出有用的快取線。

練習時間局部性的題目

下列何者最適合作為時間局部性的例子？

  1. A從頭開始依序將陣列的元素各讀取一次
  2. B在迴圈中多次更新同一個加總用的變數
  3. C每次都只讀取一次隨機位址的資料
查看答案與解析

正確答案：B. 在迴圈中多次更新同一個加總用的變數

時間局部性是指用過一次的資料在不久之後會再次被使用的性質，在迴圈內反覆讀寫的變數就是典型例子。這類資料在仍留在快取或暫存器的期間會被重複使用，因此存取速度變快。從頭依序讀取陣列，是連續使用相鄰位址的空間局部性的例子，與時間局部性是不同的性質。隨機只讀取一次的存取，幾乎兩種局部性都不具備。

常見問題

時間局部性有哪些例子？

在迴圈的每次迭代中更新同一個加總變數，或反覆執行同一組迴圈指令；同一個項目在上次使用後很快又被重複使用。

時間局部性和空間局部性有什麼差別？

時間局部性是指同一份資料很快又被重複使用；空間局部性是指接下來使用的是位址相鄰的資料，例如依序走訪陣列。

快取如何利用時間局部性？

快取把最近使用的資料保存在高速記憶體中，並優先逐出最近最少使用的項目，因此很快又會被使用的資料多半仍在快取中。
