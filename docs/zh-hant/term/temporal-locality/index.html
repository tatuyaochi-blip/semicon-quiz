什麼是時間局部性

曾經存取過的資料或指令，在不久之後容易再次被存取的性質。例如在迴圈中重複使用的變數，是快取有效的原因之一。

日文名稱: 時間的局所性

「時間局部性」出現在1領域的1道練習題中（CPU與架構等）。

這個名詞所屬的領域: 記憶體階層與效能

練習時間局部性的題目

設置快取記憶體的主要目的，下列何者正確？

  1. A為了在切斷電源後仍能保存資料
  2. B為了將常用資料放在 CPU 附近，縮小與主記憶體之間的速度差距
  3. C為了修正運算結果的錯誤
查看答案與解析

正確答案：B. 為了將常用資料放在 CPU 附近，縮小與主記憶體之間的速度差距

CPU 處理一個時脈只需 0.2〜0.3 ns，但存取 DRAM 需要數十〜100 ns，也就是數百個時脈。因此將常用的資料與指令放在高速 SRAM 的快取中，以減少等待時間。快取利用的是短時間內會再次使用相同資料的時間局部性，以及會連續使用相鄰位址的空間局部性；L1 只需數個時脈即可存取，即使是 L3 也只需數十個時脈。

解析中的「時間局部性」

  • 快取利用的是短時間內會再次使用相同資料的時間局部性，以及會連續使用相鄰位址的空間局部性；L1 只需數個時脈即可存取，即使是 L3 也只需數十個時脈。
