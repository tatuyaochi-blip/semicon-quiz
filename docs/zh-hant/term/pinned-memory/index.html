什麼是固定記憶體（Pinned memory）

經固定而使作業系統不會移動或換出實體分頁的記憶體。GPU 可透過 DMA 直接讀寫，傳輸更快，也能非同步進行。

日文名稱: ピン留めメモリ

「固定記憶體（Pinned memory）」出現在1領域的1道練習題中（GPU程式設計等）。

這個名詞所屬的領域: GPU程式設計

練習固定記憶體（Pinned memory）的題目

將CPU記憶體固定（鎖頁，page-lock）後再傳輸到GPU會比較快，其理由下列何者正確？

  1. A因為作業系統不會移動或換出該分頁，GPU能以DMA直接讀寫，不需中途的複製，也能進行非同步傳輸
  2. B因為固定之後資料會被壓縮
  3. C因為固定之後PCI Express的世代會提升
查看答案與解析

正確答案：A. 因為作業系統不會移動或換出該分頁，GPU能以DMA直接讀寫，不需中途的複製，也能進行非同步傳輸

一般的記憶體，作業系統可隨時將它移到其他實體分頁，或換出到儲存裝置，因此讓GPU的DMA直接讀寫是很危險的。所以通常會先複製到暫時固定好的區域後再傳輸。若一開始就使用固定的記憶體，就能省去這次多餘的複製，也可以與CPU的處理重疊而進行非同步傳輸。
