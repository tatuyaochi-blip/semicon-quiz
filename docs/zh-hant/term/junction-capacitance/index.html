什麼是接面電容(空乏層電容)

PN 接面的空乏層如同平行板電容器般作用而產生的電容。逆向偏壓增大時空乏層變寬，電容變小。變容二極體即利用此性質。

日文名稱: 接合容量(空乏層容量)

「接面電容(空乏層電容)」出現在5領域的11道練習題中（PN接面與二極體, 半導體物性, 雙載子電晶體等）。

這個名詞所屬的領域: PN接面與二極體

練習接面電容(空乏層電容)的題目

以接面面積A、空乏區寬度W、半導體介電常數ε表示逆向偏壓PN接面的空乏區電容（接面電容）C，下列哪個式子正確？

  1. AC = εA / W
  2. BC = εW / A
  3. CC = ε / (A × W)
查看答案與解析

正確答案：A. C = εA / W

空乏區的行為如同兩側累積電荷的絕緣層，因此與平行板電容器相同，可表示為 C = εA/W。在逆向偏壓下W變寬，電容就變小。例如在矽中，面積為100 µm見方、W = 1 µm 時，C ≈ 11.7 × 8.85×10⁻¹² × 10⁻⁸ ÷ 10⁻⁶ ≈ 1 pF。在高速電路中，這個電容會造成延遲，因此會縮小接面面積或降低濃度來減小它。

解析中的「接面電容(空乏層電容)」

  • 矽的相對介電常數約為11.7，用於計算空乏層寬度（W = √(2εV/qN)）和接面電容。

    下列何者最接近矽的相對介電常數？

  • 空乏區變寬後，接面電容（C = εA/W）會變小，此特性被用於變容二極體。

    增大施加於PN接面的逆向偏壓時，空乏區的寬度會如何變化？

  • 逆向偏壓增強時空乏區變寬，接面電容變小。

    變容二極體（varactor diode）利用的是下列哪種性質？

  • 逆向偏壓會使接面電容變小，因此響應也更快。

    將光二極體用於光偵測時，下列哪一種一般使用方式正確？

  • 寬的空乏區能承受高電壓，所以適用於高耐壓的整流二極體；而且光吸收區域寬、接面電容又小，所以適用於高速、高靈敏度的光偵測器。
