什麼是接面電容(空乏層電容)

PN 接面的空乏層如同平行板電容器般作用而產生的電容。逆向偏壓增大時空乏層變寬，電容變小。變容二極體即利用此性質。

日文名稱: 接合容量(空乏層容量)

「接面電容(空乏層電容)」出現在5領域的11道練習題中（PN接面與二極體, 半導體物性, 雙載子電晶體等）。

這個名詞所屬的領域: PN接面與二極體

電容從何而來

PN 接面的空乏區含有固定電荷：N 側是離子化的施體，P 側是離子化的受體，兩者之間幾乎沒有可移動的載子。當接面兩端電壓改變時，這個區域的邊緣會移動，使兩側增加或減少電荷，就如同電容器極板上的電荷增減一樣。因此單位面積的小訊號電容為 C = ε/W，其中 W 是空乏區寬度，ε 是矽的介電常數，約為真空的 11.7 倍。

如何隨偏壓變化

對單邊陡峭接面而言，W = √(2ε(Vbi + V)/qN)，其中 Vbi 是內建電位，V 是逆向偏壓，N 是低摻雜側的摻雜濃度。因此電容大致隨 1/√(Vbi + V) 下降，總電壓變為四倍時電容減半。電路模型寫成 Cj = Cj0/(1 + V/Vbi)^m，陡峭接面的 m = 1/2，線性漸變接面的 m = 1/3。將 1/C² 對 V 作圖會得到一條直線，由斜率可求得 N，由截距可求得 Vbi，這就是電容－電壓（C-V）摻雜分布量測的基礎。

接面電容與擴散電容

在逆向偏壓與小順向偏壓下，接面電容占主導。在較大的順向偏壓下，另一種效應會取而代之：注入的少數載子儲存在接面附近，由於這些儲存電荷會隨電壓改變，其行為就如同擴散電容，與電流及載子壽命成正比。擴散電容在大電流時可達奈法拉等級，並限制二極體與雙極性電晶體的切換速度。這個區別在設計上很重要：逆向偏壓的接面可當作小型、可由電壓調整的電容器，而順向偏壓的接面則會儲存電荷，必須在關斷前將其移除。

加以利用與設法抑制

變容二極體利用電容對電壓的依存性，在壓控振盪器與 PLL 中調諧 LC 諧振器，超陡峭摻雜分布可加寬調諧範圍。光二極體施加逆向偏壓，部分原因就是為了降低接面電容、加快響應；空乏型矽光調變器則藉由改變空乏寬度來移動多數載子，可達數十 GHz。在其他場合它則是寄生成分：MOSFET 的源極與汲極接面會成為每個邏輯節點的負載，而絕緣層上覆矽（SOI）晶圓將電晶體置於埋入氧化層上而非塊材接面上，藉此降低這項負載。

練習接面電容(空乏層電容)的題目

以接面面積A、空乏區寬度W、半導體介電常數ε表示逆向偏壓PN接面的空乏區電容（接面電容）C，下列哪個式子正確？

  1. AC = εA / W
  2. BC = εW / A
  3. CC = ε / (A × W)
查看答案與解析

正確答案：A. C = εA / W

空乏區的行為如同兩側累積電荷的絕緣層，因此與平行板電容器相同，可表示為 C = εA/W。在逆向偏壓下W變寬，電容就變小。例如在矽中，面積為100 µm見方、W = 1 µm 時，C ≈ 11.7 × 8.85×10⁻¹² × 10⁻⁸ ÷ 10⁻⁶ ≈ 1 pF。在高速電路中，這個電容會造成延遲，因此會縮小接面面積或降低濃度來減小它。

常見問題

為什麼接面電容會隨逆向偏壓變小？

逆向偏壓會使空乏區變寬，而電容等於介電常數除以寬度，所以區域越寬電容越小；以陡峭接面來說，大約與電壓的平方根成反比。

接面電容和擴散電容有什麼不同？

接面電容來自空乏區中的固定電荷，在逆向偏壓下占主導；擴散電容來自順向偏壓下儲存的少數載子，會隨電流增加而增大。

如何用接面電容量測摻雜濃度？

量測電容隨逆向偏壓的變化，並將 1/C² 對 V 作圖；對陡峭接面而言，斜率可求得低摻雜側的摻雜濃度，截距則可求得內建電位。
