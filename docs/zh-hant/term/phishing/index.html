什麼是網路釣魚

以假冒真實企業或組織的電子郵件、簡訊等誘導至假網站，讓人輸入帳號、密碼、信用卡號碼等並加以竊取的詐騙手法。

閱讀入門解說: 網路釣魚是什麼？假郵件、假網站的分辨方法與對策

日文名稱: フィッシング

「網路釣魚」出現在2領域的7道練習題中（網路攻擊與防禦實務, 資訊安全基礎等）。

這個名詞所屬的領域: 資訊安全基礎

練習網路釣魚的題目

下列網路釣魚的手法與使用者端對策的組合，正確的是哪一項？

  1. A傳送大量封包讓伺服器停擺。加大伺服器的線路頻寬
  2. B將電腦的檔案加密並要求贖金。事先做好離線備份
  3. C以假冒真實企業等的電子郵件或簡訊誘導至假網站，讓人輸入帳號、密碼、信用卡號碼等並加以竊取。不從訊息中的連結，而是從書籤或官方應用程式存取
查看答案與解析

正確答案：C. 以假冒真實企業等的電子郵件或簡訊誘導至假網站，讓人輸入帳號、密碼、信用卡號碼等並加以竊取。不從訊息中的連結，而是從書籤或官方應用程式存取

網路釣魚是以假冒金融機構、購物網站、物流業者、政府機關等的電子郵件或簡訊（利用簡訊者也稱為簡訊釣魚），誘導至與真網站幾乎一模一樣的假網站，讓人輸入帳號與密碼、信用卡號碼、一次性密碼等並加以竊取的手法。假網站的網址多半使用與真網站非常相似的網域名稱，僅憑外觀很難分辨。使用者端有效的對策包括：不從電子郵件或簡訊的連結輸入重要資訊、從書籤或官方應用程式開啟、啟用多因素驗證。服務端也有以寄件網域驗證（SPF、DKIM、DMARC）讓假冒自家公司的郵件不易送達的對策。

FIDO2（WebAuthn）通行金鑰的驗證，比一次性密碼（OTP）更能抵抗網路釣魚，正確的理由是下列何者？

  1. A私密金鑰的簽章與連線目標的網域綁定，因此假網站無法產生真網站用的簽章，即使轉送也無法使用
  2. B通行金鑰是6位數的數字，位數比OTP少，因此使用者在假網站上輸入前的時間也比較短
  3. C使用通行金鑰時，伺服器會保存使用者的密碼，因此即使在假網站上輸入，也能在伺服器比對時識破
查看答案與解析

正確答案：A. 私密金鑰的簽章與連線目標的網域綁定，因此假網站無法產生真網站用的簽章，即使轉送也無法使用

OTP是使用者看著畫面輸入的值，因此無法防止誘使使用者在假網站上輸入，再立刻轉送到真網站的攻擊（中間人型的網路釣魚）。在FIDO2中，會為每個網站建立一組公開金鑰與私密金鑰，只把公開金鑰註冊到網站；登入時則以私密金鑰對網站送來的值（挑戰）簽章。要使用哪個網站的金鑰，由瀏覽器確認的實際連線目標網域決定，被簽章的資訊中也包含該連線目標，因此假網站無法取得真網站用的簽章。此外，伺服器只保存公開金鑰，即使從伺服器外洩，也無法用於冒用身分。
