什麼是遠端證明（Remote attestation）

裝置以晶片內的金鑰簽署自己內部所執行軟體的狀態，出示給遠端伺服器，由其確認是否可信賴的機制。

日文名稱: リモートアテステーション

「遠端證明（Remote attestation）」出現在1領域的2道練習題中（硬體安全等）。

這個名詞所屬的領域: 硬體安全

練習遠端證明（Remote attestation）的題目

下列關於遠端證明（remote attestation）的說明，何者正確？

  1. A身處遠方的人看著機器的畫面進行操作
  2. B以GPS將機器的位置通知伺服器
  3. C機器將自己內部執行之軟體的狀態，以晶片內的金鑰簽章後出示給遠端伺服器，讓其確認是否可信
查看答案與解析

正確答案：C. 機器將自己內部執行之軟體的狀態，以晶片內的金鑰簽章後出示給遠端伺服器，讓其確認是否可信

在遠端證明中，機器將記錄於TPM或TEE的軟體度量值，以無法從晶片內取出的金鑰簽章後送給伺服器。伺服器驗證簽章與度量值，只對以指定軟體運作的機器提供機密資料或服務。用於委託雲端進行機密運算，或確認連接企業網路的機器等情況。
