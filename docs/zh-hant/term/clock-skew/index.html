什麼是時脈偏斜

同一個時脈訊號到達各個正反器的時間差異。由於會改變設定與保持的餘裕，因此在時脈樹合成時將其壓低。

日文名稱: クロックスキュー

「時脈偏斜」出現在1領域的1道練習題中（邏輯電路等）。

這個名詞所屬的領域: 邏輯電路

偏斜從何而來

在同步電路中，一個時脈源透過導線與緩衝器構成的網路，驅動數千到數百萬個正反器。導線長度、導線電阻與電容、緩衝器負載的差異，以及製程、電壓與溫度的局部變異，使同一個時脈邊緣抵達不同正反器的時間略有不同。這種空間上的抵達時間差就是時脈偏斜。不應將其與抖動（jitter）混淆，抖動是指在單一位置上時脈邊緣時間在週期之間的變動。對時序而言，重要的是彼此傳遞資料的每一對正反器之間的偏斜。

對設定與保持時間的影響

將偏斜定義為擷取時脈的抵達時間減去發送時脈的抵達時間。擷取時脈較晚抵達會給資料更多時間，有利於設定時間：條件變為 週期 + 偏斜 ≥ 時脈至輸出延遲 + 邏輯延遲 + 設定時間。以 2.0 ns 週期、0.2 ns 時脈至輸出延遲、1.4 ns 邏輯延遲與 0.1 ns 設定時間為例，偏斜為零時餘裕（slack）為 0.3 ns，有 0.1 ns 正偏斜時為 0.4 ns。同樣的晚到擷取卻不利於保持時間，因為新資料可能在擷取正反器鎖存舊資料之前就將其覆蓋：最小時脈至輸出延遲加上最小邏輯延遲，必須大於保持時間加上偏斜。

以時脈樹合成控制偏斜

時脈樹合成（CTS）會建構遍及整顆晶片的分配網路，選擇緩衝器位置並平衡導線長度與負載，使偏斜維持在數十皮秒以內。常見結構包括對稱的 H 樹、緩衝樹，以及將許多分支短接在一起的網格狀時脈網（clock mesh）。接著，靜態時序分析會以實際計算出的時脈抵達時間檢查每條路徑，並加入晶片上變異的降額（derating）。設計者有時會刻意引入偏斜，即有用偏斜（useful skew），延遲關鍵路徑的擷取時脈，向有多餘餘裕的相鄰路徑借用時間。

為什麼保持時間違規很危險

設定時間違規可以在製造後藉由降低時脈頻率來修正，因為較長的週期能給資料更多時間。保持時間違規則不行，因為保持條件完全不包含時脈週期；它是同一週期內新資料與時脈邊緣之間的競賽。因此，偏斜造成的保持時間問題要在投片（tape-out）前，透過在短路徑上插入延遲緩衝器來修正。在電路板層級，晶片間介面也適用同樣的計算，必須從時序預算中扣除時脈偏斜與抖動。

查看答案與解析

正確答案：B. 時脈訊號到達各正反器的時間差

時脈偏斜是同一個時脈因佈線長度或負載的差異，到達各正反器的時間不同所產生的差距。接收端的時脈延遲時，對設置有利但對保持不利，反之亦然。以CTS（時脈樹合成）設計涵蓋整個晶片的時脈樹，並統一緩衝器的配置與佈線長度，將偏斜抑制在數十ps以下。週期在時間上的抖動則是時脈抖動（jitter）。

常見問題

時脈偏斜和時脈抖動有什麼不同？

偏斜是同一週期內不同位置之間的時脈抵達時間差，而抖動是單一位置上時脈邊緣時間在週期之間的變動。

時脈偏斜一定是壞事嗎？

不一定。正偏斜可給路徑更多設定時間，設計者有時會刻意加入有用偏斜來平衡時序，但任何有利於設定時間的偏斜，都會減少同一路徑的保持時間餘裕。

保持時間違規可以靠降低時脈頻率修正嗎？

不行。保持時序與時脈週期無關，因此必須在短資料路徑上增加延遲或減少偏斜來修正。
