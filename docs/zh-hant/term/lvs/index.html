什麼是LVS(佈局與電路圖比對)

Layout Versus Schematic的簡稱。確認從佈局擷取出的電路連接，是否與電路圖或網表一致的驗證。與DRC一起，在投片前必定要執行。

日文名稱: LVS

「LVS(佈局與電路圖比對)」出現在1領域的5道練習題中（LSI設計流程與EDA等）。

這個名詞所屬的領域: LSI設計流程與EDA

練習LVS(佈局與電路圖比對)的題目

關於佈局驗證中DRC（設計規則檢查）的說明，下列何者正確？

  1. A驗證電路圖與佈局的連接是否一致
  2. B驗證佈局是否滿足最小線寬與間距等製造上的規則
  3. C以模擬驗證RTL的邏輯功能
查看答案與解析

正確答案：B. 驗證佈局是否滿足最小線寬與間距等製造上的規則

DRC是檢查佈局的圖形是否違反最小線寬、間距、重疊、密度等由製造製程所決定的設計規則之驗證。在先進製程中規則多達數千條，由工具自動確認。確認電路圖與佈局連接是否一致的是LVS（Layout Versus Schematic），確認邏輯功能的則是模擬。DRC與LVS在輸出光罩資料前必定要進行。

晶圓代工廠提供給設計者的設計規則、元件模型、單元庫等整套設計用資料，稱為什麼？

  1. APDK（製程設計套件）
  2. BIP核
  3. CHDL
查看答案與解析

正確答案：A. PDK（製程設計套件）

PDK包含該製程的設計規則、電晶體等的SPICE用模型、DRC與LVS用的規則檔、佈線寄生元件萃取的資料、基本元件的佈局等。設計者使用PDK，就能設計出可在該晶圓代工廠製造的電路。標準單元的庫有時也會與PDK分開提供。IP核是電路區塊，HDL則是描述語言。

解析中的「LVS(佈局與電路圖比對)」

  • 確認電路圖與佈局連接是否一致的是LVS（Layout Versus Schematic），確認邏輯功能的則是模擬。

    關於佈局驗證中DRC（設計規則檢查）的說明，下列何者正確？

  • PDK包含該製程的設計規則、電晶體等的SPICE用模型、DRC與LVS用的規則檔、佈線寄生元件萃取的資料、基本元件的佈局等。

    晶圓代工廠提供給設計者的設計規則、元件模型、單元庫等整套設計用資料，稱為什麼？

  • sign-off除了時序、DRC與LVS之外，還要進行電源佈線的電壓降（IR壓降），以及因佈線電流密度造成的電遷移的分析。

    在下線前的最終確認（sign-off）中，與時序驗證並行進行的電源佈線分析為下列何者？

  • 用作邏輯合成的輸出與佈局繞線的輸入，在LVS中則是比對從佈局萃取出的網表與電路圖的網表。

    關於網表（netlist）的說明，下列何者正確？

  • 它與檢查圖形尺寸規則的DRC、檢查是否與電路圖一致的LVS一同在sign-off時進行。

    在佈局驗證中，檢查輸入端子是否浮接（沒有連到任何地方）、電源之間是否短路等電氣連接錯誤的檢查為下列何者？
