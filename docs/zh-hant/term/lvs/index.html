什麼是LVS(佈局與電路圖比對)

Layout Versus Schematic的簡稱。確認從佈局擷取出的電路連接，是否與電路圖或網表一致的驗證。與DRC一起，在投片前必定要執行。

日文名稱: LVS

「LVS(佈局與電路圖比對)」出現在1領域的5道練習題中（LSI設計流程與EDA等）。

這個名詞所屬的領域: LSI設計流程與EDA

LVS的運作方式

佈局與電路圖比對（LVS）用來確認繪製的佈局是否完全實現了預期的電路。工具首先從佈局多邊形中擷取元件：多晶矽與擴散區重疊處形成電晶體，特定的標記層用來辨識電阻與電容，而接觸窗與導通孔將金屬圖形連接成線網。由此產生佈局網表。接著將它與來自電路圖或佈局繞線的參考網表比對，本質上是一個圖形匹配問題。除了連接關係外，LVS也會將電晶體寬度與長度、電阻值等元件參數與參考值比對。

LVS常抓到的錯誤

最常見的LVS錯誤是短路（本應分開的兩個線網相接觸）與斷路（線網中斷）。電源線網之間的短路尤其嚴重。其他報告還包括缺少或多出元件、接腳對調、尺寸錯誤的電晶體，以及位置錯誤或拼寫錯誤的接腳標籤，後者即使幾何正確也會使線網看起來未連接。除錯往往比檢查本身更困難，因為單一短路就會合併兩個大型線網，工具必須協助找出兩者相接的確切多邊形。

LVS、DRC與ERC的比較

簽核時通常會一起執行三種檢查。設計規則檢查（DRC）只看幾何：最小寬度、間距、包覆、密度等製造規則，在先進製程中多達數千條。LVS檢查連接關係與元件身分。電氣規則檢查（ERC）則找出電氣上可疑的連接，例如浮接輸入、由多個來源驅動的輸出、不同電源之間的短路，以及未連接的井。佈局可能通過DRC卻未通過LVS，反之亦然，因此在釋出光罩資料前全部都必須通過。

LVS在簽核中的位置

LVS規則檔來自晶圓代工廠的製程設計套件（PDK），同樣的元件辨識規則也是寄生參數擷取的基礎，因此LVS通過也是準確進行佈局後模擬與時序分析的前提。在數位流程中，LVS將完成繞線的佈局與閘級網表比對，標準元件則視為已驗證的建構單元。簽核另外還包括靜態時序分析，以及IR壓降與電遷移等電源網路檢查。只有在這些全部通過後，佈局才會以GDSII或OASIS資料釋出用於製作光罩，這個步驟稱為投片（tape-out）。

PDK包含該製程的設計規則、電晶體等的SPICE用模型、DRC與LVS用的規則檔、佈線寄生元件萃取的資料、基本元件的佈局等。設計者使用PDK，就能設計出可在該晶圓代工廠製造的電路。標準單元的庫有時也會與PDK分開提供。IP核是電路區塊，HDL則是描述語言。

常見問題

LVS是什麼的縮寫？

LVS是佈局與電路圖比對（layout versus schematic）的縮寫，是確認從晶片佈局擷取出的元件與連接是否與預期電路圖或網表一致的驗證步驟。

DRC和LVS有什麼差別？

DRC檢查佈局圖形是否符合晶圓代工廠的幾何製造規則，LVS則檢查佈局的元件與連接關係是否與電路網表一致。兩者都必須在投片前通過。

LVS短路錯誤的原因是什麼？

LVS短路表示本應分開的兩個線網在佈局中電氣相連，通常是因為金屬重疊、導通孔或接觸窗位置錯誤，或是標籤錯誤導致線網名稱合併。
