什麼是快取一致性

在多核心 CPU 中，各核心的快取內有相同位址的資料時，維持其內容一致性的機制。當某個核心改寫時，藉由讓其他核心的舊副本失效等方式來實現。

日文名稱: キャッシュコヒーレンシ

「快取一致性」出現在3領域的7道練習題中（多核心與同步, 介面與匯流排規格, 作業系統與硬體等）。

這個名詞所屬的領域: CPU與架構

練習快取一致性的題目

在硬體不維持快取一致性（非一致性，non-coherent）的系統中，於CPU讀取裝置以DMA寫入主記憶體的資料之前，軟體必須進行下列何種處理？

  1. A暫時降低CPU的時脈頻率
  2. B使對應範圍的快取內容無效，並改為從主記憶體重新讀取
  3. C將快取的內容全部寫回主記憶體後，丟棄經DMA送達的結果
查看答案與解析

正確答案：B. 使對應範圍的快取內容無效，並改為從主記憶體重新讀取

DMA不經過CPU，直接在裝置與主記憶體之間傳輸資料，因此在硬體不維持一致性的系統中，CPU的快取裡可能仍留有該範圍的舊資料。若直接讀取，讀到的會是舊值，而不是經DMA送達的新資料。所以驅動程式在讀取之前，要先使該範圍的快取無效，讓它從主記憶體讀取新值。相反地，要傳給裝置的資料，則須在開始DMA之前先從快取寫回。

兩個核心各自的快取中都有變數x的副本。核心0寫入x之後，核心1讀取x時，若沒有快取一致性（cache coherency）機制，可能發生下列何種問題？

  1. A核心1讀到自己快取中殘留的舊值
  2. B核心1的讀取一定比核心0的寫入更快
  3. C讀到的x值變成2倍
查看答案與解析

正確答案：A. 核心1讀到自己快取中殘留的舊值

在多核心CPU中，各核心的快取內會存有相同位址資料的副本。若核心0只在自己的快取內改寫x，核心1的快取就會殘留舊值，核心1便會讀到這個舊值。快取一致性機制會在寫入時使其他核心的副本失效等，讓無論從哪個核心讀取都能看到最新的值。
