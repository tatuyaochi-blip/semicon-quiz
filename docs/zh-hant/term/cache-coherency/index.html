什麼是快取一致性

在多核心 CPU 中，各核心的快取內有相同位址的資料時，維持其內容一致性的機制。當某個核心改寫時，藉由讓其他核心的舊副本失效等方式來實現。

日文名稱: キャッシュコヒーレンシ

「快取一致性」出現在1領域的2道練習題中（介面與匯流排規格等）。

練習快取一致性的題目

下列關於CXL（Compute Express Link）的說明，何者正確？

  1. A用於在封裝內連接小晶片（chiplet）之間的規格
  2. B使用PCI Express的實體層，使CPU與加速器或記憶體裝置之間能進行保持快取一致性的記憶體共享之規格
  3. C新的無線區域網路規格
查看答案與解析

正確答案：B. 使用PCI Express的實體層，使CPU與加速器或記憶體裝置之間能進行保持快取一致性的記憶體共享之規格

在PCI Express中，裝置的記憶體與CPU的快取一致性無法由硬體維持，必須由軟體加以留意。CXL是在與PCI Express相同的實體層上，加入維持快取一致性的通訊，以及讓CPU像讀寫一般記憶體一樣讀寫裝置記憶體的通訊之規格。用於與加速器共享資料，以及擴充記憶體。

構成CXL的3種協定之組合，下列何者正確？

  1. ACXL.usb、CXL.sata、CXL.hdmi
  2. BCXL.read、CXL.write、CXL.erase
  3. CCXL.io（相當於PCI Express的輸入輸出）、CXL.cache（裝置快取CPU的記憶體）、CXL.mem（CPU使用裝置的記憶體）
查看答案與解析

正確答案：C. CXL.io（相當於PCI Express的輸入輸出）、CXL.cache（裝置快取CPU的記憶體）、CXL.mem（CPU使用裝置的記憶體）

CXL.io是用於裝置的探索與設定、中斷等，與PCI Express幾乎相同的通訊。CXL.cache用於讓加速器在維持快取一致性的情況下，將CPU端的記憶體放入自己的快取。CXL.mem用於讓CPU像讀寫一般記憶體一樣讀寫裝置的記憶體。記憶體擴充裝置會使用CXL.io與CXL.mem，加速器則可能使用全部3種。
