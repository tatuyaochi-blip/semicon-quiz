什麼是堆疊指標

指向堆疊目前頂端位址的暫存器。在RISC-V中是sp(x2)。在多數ISA中，堆疊朝位址較小的方向延伸。

日文名稱: スタックポインタ

「堆疊指標」出現在4領域的4道練習題中（CPU與架構, 指令集與組合語言, 連結器與載入器與執行檔格式等）。

這個名詞所屬的領域: 指令集與組合語言

練習堆疊指標的題目

在程式中呼叫副程式（函式）時，一般用來暫時保存返回位址等的區域是下列何者？

  1. A堆疊（stack）
  2. B快取的標籤（tag）
  3. CROM 的固定區域
查看答案與解析

正確答案：A. 堆疊（stack）

呼叫副程式時，返回位址、應保存的暫存器值、區域變數等會被推入堆疊。堆疊是後放入的先取出（LIFO）的結構，即使呼叫形成巢狀或遞迴，也能依正確的順序返回。頂端位置由堆疊指標指示。遞迴過深而用盡區域時會發生堆疊溢位，也有藉由陣列越界改寫返回位址的攻擊。

在RISC-V的標準呼叫慣例中，呼叫一個有10個整數引數的函式時，第9個與第10個引數是在哪裡傳遞？

  1. As0與s1
  2. Bt0與t1
  3. C堆疊上
查看答案與解析

正確答案：C. 堆疊上

引數用的暫存器只有a0～a7共8個，所以第9個以後由呼叫端堆入堆疊，被呼叫端則從堆疊指標起算的固定位置讀取。由於記憶體的存取增加，引數非常多的函式會稍微變慢。常見的做法是設法減少引數，例如將大型結構體整個以指向結構體的指標來傳遞。

解析中的「堆疊指標」

  • 頂端位置由堆疊指標指示。

  • 執行檔中並沒有給區域變數用的區段，而是在函式開頭移動堆疊指標來配置空間。

    在C語言的函式中宣告、未加static的區域變數（自動變數），執行時會放在哪裡？

  • 在環境切換時，為了之後能從相同狀態繼續執行，會儲存通用暫存器、程式計數器、堆疊指標、運作模式等CPU的狀態，並載入接下來要執行行程的狀態。
