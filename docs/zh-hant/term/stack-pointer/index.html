什麼是堆疊指標

指向堆疊目前頂端位址的暫存器。在RISC-V中是sp(x2)。在多數ISA中，堆疊朝位址較小的方向延伸。

日文名稱: スタックポインタ

「堆疊指標」出現在1領域的1道練習題中（CPU與架構等）。

這個名詞所屬的領域: 指令集與組合語言

練習堆疊指標的題目

在程式中呼叫副程式（函式）時，一般用來暫時保存返回位址等的區域是下列何者？

  1. A堆疊（stack）
  2. B快取的標籤（tag）
  3. CROM 的固定區域
查看答案與解析

正確答案：A. 堆疊（stack）

呼叫副程式時，返回位址、應保存的暫存器值、區域變數等會被推入堆疊。堆疊是後放入的先取出（LIFO）的結構，即使呼叫形成巢狀或遞迴，也能依正確的順序返回。頂端位置由堆疊指標指示。遞迴過深而用盡區域時會發生堆疊溢位，也有藉由陣列越界改寫返回位址的攻擊。

解析中的「堆疊指標」

  • 頂端位置由堆疊指標指示。
