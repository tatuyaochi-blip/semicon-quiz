什麼是預除器（Prescaler）

以固定比例對輸入計時器等的時脈進行除頻的電路。將過快的時脈調整到計時器可計數的範圍。

日文名稱: プリスケーラ

「預除器（Prescaler）」出現在1領域的1道練習題中（嵌入式與韌體等）。

這個名詞所屬的領域: 嵌入式與韌體

預除器的作用

預除器（prescaler）是放在計時器或計數器之前，以固定比例N對輸入時脈進行除頻的電路。例如將16 MHz的時脈除以16，會變成1 MHz，計時器每計數一次為1 µs。若再設定為每1000次計數產生一次中斷，就能得到每1 ms一次的中斷。計數器的位元數有限，若直接計數高速時脈，很快就會繞回一圈，無法量測較長的時間。以預除器使計數間隔變粗，就能讓計數器的範圍符合所需的時間。

解析度與範圍的選擇

除頻比越大，可量測的時間越長，但每次計數的時間（解析度）也越粗。以16位元計數器、每次計數1 µs為例，約65.5 ms後就會繞回一圈。計時器的週期可用「除頻比×計數值÷輸入時脈頻率」求得。設定方式因微控制器而異，有些是從1、8、64、256、1024等固定值中選擇（如AVR），有些則能以16位元暫存器設定任意比例。也有像STM32的計時器那樣，以暫存器寫入值加1作為除頻比的方式，因此務必查閱資料手冊確認。

預除器電路的實作

2的冪次除頻可以用數級正反器串接而成的計數器實現，每一級頻率減半。若要以任意比例N除頻，則讓計數器數到N−1時歸零，並在此時輸出一個脈衝。在同步設計的微控制器中，除頻後的訊號多半不當作新的時脈使用，而是作為與原時脈同步、「每N次只有效1次」的致能訊號送給計時器，以避免時脈偏移與多時脈域的問題。ADC的時脈、看門狗計時器以及UART鮑率的產生，也採用相同的概念。

高頻PLL中使用的預除器

在無線設備的頻率合成器中，預除器在另一層意義上也很重要。VCO的輸出在GHz頻段，頻率很高，難以讓可自由改變除頻比的計數器直接以該頻率運作，因此先以高速預除器用固定比例P除頻，再交給低速計數器計數。為了能細緻地選擇除頻比，會使用可在除以P與除以P+1之間切換的雙模預除器，並以吞脈衝計數器決定除以P+1的次數，使整體除頻比能像P×N+A這樣以1為單位設定。頻率計數器也會使用預除器來擴大量測範圍。

練習預除器（Prescaler）的題目

將16 MHz的時脈經預除器除以16後供計時器計數，設定每計數1000次產生一次中斷。中斷的間隔是多少？

  1. A1 µs
  2. B1 ms
  3. C16 ms
查看答案與解析

正確答案：B. 1 ms

16 MHz除以16，計時器的時脈為1 MHz，每計數一次為1 µs。每1000次計數的話，間隔為1 µs×1000=1 ms。預除器的用途是將過快的時脈除頻，使其落在計時器可計數的範圍內。每1 ms一次的中斷，常用於時間管理、讀取開關以及RTOS的時間刻度等。

常見問題

預除器是什麼？

是以固定比例對輸入計時器或計數器的時脈進行除頻的電路。它讓過快的時脈計數間隔變粗，使計數器繞回一圈的時間符合所需的長度。英文拼法為prescaler。

預除器和後除器有什麼不同？

預除器在計數器之前對時脈除頻，改變每次計數的時間。後除器（postscaler）則位於計數器之後，計算比對成立或繞回的次數，藉此減少中斷等事件，只改變事件發生的間隔。也有像PIC微控制器的Timer2那樣兩者都具備的計時器。

預除器的設定值要怎麼計算？

將目標週期乘以輸入時脈頻率，求出所需的時脈數，再把它拆成落在計數器範圍內的「除頻比×計數值」。例如在16 MHz下要得到1 ms，需要16000個時脈，可以設為除以16、計數1000次。也有寫入暫存器的值為N−1的方式，需要注意。
