什麼是MEMS(微機電系統)

微機電系統。利用半導體的微細加工技術，將微小的機械結構與電子電路製作在一起的元件。

日文名稱: MEMS

「MEMS(微機電系統)」出現在5領域的7道練習題中（蝕刻, 影像感測器與光電元件, 矽晶圓等）。

這個名詞所屬的領域: MEMS與感測器

練習MEMS(微機電系統)的題目

在MEMS的犧牲層去除等情況中，不使用電漿即可對矽進行等向性蝕刻的氣體是下列何者？

  1. AO2（氧氣）
  2. BN2（氮氣）
  3. CXeF2（二氟化氙）
查看答案與解析

正確答案：C. XeF2（二氟化氙）

XeF2是在室溫附近就會昇華的氣體，與矽自發性反應生成SiF4等，不需電漿即可對矽進行等向性蝕刻（2XeF2 + Si → 2Xe + SiF4）。它對氧化層、氮化層、光阻及多數金屬的選擇比高達1000以上，且因不使用液體而不易發生黏附（stiction），因此用於將MEMS結構從矽犧牲層中釋放出來。

解析中的「MEMS(微機電系統)」
