什麼是良率

良品數量佔投入數量的比例。是對半導體製造成本影響極大的指標。

日文名稱: 歩留まり

「良率」出現在1領域的2道練習題中（矽晶圓等）。

這個名詞所屬的領域: 良率與品質管理

練習良率的題目

刻在晶圓正面或背面的雷射標記(ID標記)，其目的是哪一項？

  1. A裝飾晶圓
  2. B提高晶圓的強度
  3. C逐片識別晶圓，使製程履歷可以追蹤
查看答案與解析

正確答案：C. 逐片識別晶圓，使製程履歷可以追蹤

晶圓的正面或背面外周附近，會以雷射刻上獨一無二的編號(英數字或二維碼)。設備讀取後即可識別晶圓，並記錄它在哪台設備、以什麼條件處理，以及檢查結果為何(可追溯性)。發現不良時，可據此回溯原因製程與設備，也可與晶圓內的位置資訊結合來分析良率。

對大口徑晶圓進行高溫熱處理時會成為問題的「滑移(slip)」，其原因下列哪一項是正確的？

  1. A因晶圓內的溫度差或自重造成的應力，使晶面錯位而產生差排
  2. B異物附著在晶圓表面
  3. C雜質濃度下降
查看答案與解析

正確答案：A. 因晶圓內的溫度差或自重造成的應力，使晶面錯位而產生差排

高溫下矽的強度會大幅下降，因此急速加熱、冷卻造成的晶圓內溫差，以及支撐部分承受自重所產生的應力，會使晶面({111}面)滑動而產生差排(滑移)。滑移多半從外周支撐銷附近產生，會造成元件漏電、良率下降以及曝光的疊對偏移。可藉由減緩升降溫速度，或改良支撐方式與形狀來防止。
