什麼是取樣定理

以高於訊號所含最高頻率兩倍的頻率進行取樣，就能還原原始訊號的定理。也稱為奈奎斯特–香農取樣定理。

閱讀入門解說: 類比IC是什麼？和數位晶片有何不同、用在哪裡？

日文名稱: サンプリング定理

「取樣定理」出現在1領域的3道練習題中（AD/DA轉換等）。

這個名詞所屬的領域: AD/DA轉換

為何兩倍頻寬就足夠

以取樣率 fs 對訊號取樣，會使其頻譜在 fs 的每個整數倍處重複出現。若訊號在 fs/2（奈奎斯特頻率）及以上沒有任何成分，這些複製頻譜就不會重疊，理想的低通濾波器便能分離出原始頻譜，並精確地重建連續波形；在數學上是透過樣本之間的 sinc 內插。最低取樣率，即最高頻率的兩倍，稱為奈奎斯特率。恰好以兩倍頻率取樣並不足夠：例如 fs/2 的正弦波可能剛好在其過零點被取樣，而完全消失。

混疊：違反定理時會發生什麼

高於 fs/2 的成分不會消失；它會折返，出現在等於其與最接近之 fs 整數倍距離的較低頻率上。在 fs = 10 kHz 時，7 kHz 的音調所產生的樣本與 3 kHz 的音調完全相同。一旦取樣，兩者便無法區分，因此事後任何數位處理都無法去除混疊。唯一的解方是預防：在類比數位轉換器（ADC）之前放置類比抗混疊低通濾波器，衰減目標頻帶以上的所有成分，包括雜訊，而不只是訊號音調。

實務上的餘裕與超取樣

實際的濾波器在通帶與阻帶之間需要過渡帶，因此系統的取樣率會遠高於最低限度。音訊 CD 以 44.1 kHz 取樣 20 kHz 的頻帶，留下 20 至 22.05 kHz 供濾波器衰減；一般用途的設計常只使用取樣率的約 40%。超取樣是以遠高於所需的速率取樣，再以數位方式濾波與降頻，可大幅放寬類比濾波器的要求，也是三角積分轉換器的基礎。在輸出端，數位類比轉換器（DAC）需要重建濾波器來去除頻譜鏡像。

帶通取樣與其他細節

嚴格來說，必須低於 fs/2 的是訊號的頻寬，而不是其最高頻率。例如一個在遠高於此的載波周圍佔用數 MHz 的窄頻無線電訊號，只要該頻帶完全落在一個奈奎斯特區內，就能以低於載波頻率兩倍的速率取樣，刻意使其混疊到較低頻率。這種欠取樣需要類比輸入頻寬涵蓋載波的取樣保持電路，以及用來排除其他區的帶通濾波器。另請注意，取樣只會將時間離散化；將每個樣本捨入到離散位準是量化，屬於另一個步驟。

練習取樣定理的題目

要對含有最高20 kHz成分的類比訊號取樣而不產生混疊（aliasing），所需的取樣頻率為下列何者？

  1. A10 kHz以上
  2. B剛好20 kHz
  3. C高於40 kHz的頻率
查看答案與解析

正確答案：C. 高於40 kHz的頻率

依據取樣定理，以高於最高頻率2倍的頻率取樣即可還原原訊號，20 kHz則需要高於40 kHz的頻率。實務上無法以濾波器陡峭地截止，因此需保留餘裕，音樂CD以44.1 kHz取樣（將20～22.05 kHz用作濾波器的過渡頻帶）。取樣頻率的一半稱為奈奎斯特頻率。

表示ADC轉換速度的「MS/s（MSPS）」，其意義下列何者正確？

  1. A每秒百萬西門子
  2. B每秒能取樣（轉換）幾百萬次
  3. C一次轉換所需的毫秒數
查看答案與解析

正確答案：B. 每秒能取樣（轉換）幾百萬次

MS/s是Mega Samples per second的縮寫，表示每秒能轉換幾百萬次，100 MS/s即每秒1億次。依取樣定理，可處理的訊號頻寬最大為其一半（50 MHz），但實務上因濾波器的餘裕，約以4成為參考。也會用到kS/s（千次）與GS/s（十億次）。資料量為「取樣速度 × 位元數」，100 MS/s、12位元時高達1.2 Gb/s。

常見問題

什麼是奈奎斯特頻率？

它是取樣率的一半，也就是不發生混疊時所能表示的最高頻率。以 48 kHz 取樣時為 24 kHz。

為什麼音訊以 44.1 kHz 而不是 40 kHz 取樣？

超出 20 kHz 音訊頻帶兩倍的額外餘裕，讓抗混疊濾波器與重建濾波器有可以衰減的過渡帶。

取樣後還能去除混疊嗎？

不能。高頻成分一旦折入頻帶內，其樣本就與真正的低頻訊號完全相同，因此必須在取樣前就將其濾除。
