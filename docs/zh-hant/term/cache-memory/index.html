什麼是快取記憶體

設置在 CPU 附近的高速、小容量記憶體。保存常用資料，以緩和與主記憶體之間的速度差。主要由 SRAM 製成。

日文名稱: キャッシュメモリ

「快取記憶體」出現在2領域的3道練習題中（SRAM與快閃記憶體, CPU與架構等）。

這個名詞所屬的領域: CPU與架構

練習快取記憶體的題目

設置快取記憶體的主要目的，下列何者正確？

  1. A為了在切斷電源後仍能保存資料
  2. B為了將常用資料放在 CPU 附近，縮小與主記憶體之間的速度差距
  3. C為了修正運算結果的錯誤
查看答案與解析

正確答案：B. 為了將常用資料放在 CPU 附近，縮小與主記憶體之間的速度差距

CPU 處理一個時脈只需 0.2〜0.3 ns，但存取 DRAM 需要數十〜100 ns，也就是數百個時脈。因此將常用的資料與指令放在高速 SRAM 的快取中，以減少等待時間。快取利用的是短時間內會再次使用相同資料的時間局部性，以及會連續使用相鄰位址的空間局部性；L1 只需數個時脈即可存取，即使是 L3 也只需數十個時脈。

解析中的「快取記憶體」

  • 單元面積約為 120～150F²，大約是 DRAM 的 20 倍，但可用與邏輯電路相同的製程製作且速度快，因此是 CPU 快取記憶體的主力。

出現這個名詞的比較

  • DRAM 與 SRAM 的差異：結構、速度、成本、用途比較從單元結構、更新、速度、積體度、成本、耗電量與用途等面向，以表格比較 DRAM 與 SRAM，並說明各自適用的時機。
  • CPU 與 GPU 的差異：結構、擅長的運算、用途比較從設計目的、核心數、執行模型、快取、記憶體頻寬、分支、資料傳輸與擅長的運算等面向，以表格比較 CPU 與 GPU。
  • 寫透與寫回的差異：快取寫入方式比較以寫入方式、記憶體流量、速度、一致性、複雜度、逐出成本與用途等面向，用表格比較寫透與寫回的快取。
  • 馮紐曼架構與哈佛架構的差異：比較指令與資料的處理以記憶體、匯流排、傳輸量、靈活性、複雜度、代表性裝置與修正式哈佛架構等面向，用表格比較馮紐曼架構與哈佛架構。
