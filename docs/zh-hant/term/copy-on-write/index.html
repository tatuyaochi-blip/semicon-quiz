什麼是寫入時複製

複製出來的記憶體起初與原本共用，直到其中一方要寫入時，才只複製該頁面的方式。可加快行程的建立並節省記憶體。

日文名稱: コピーオンライト

「寫入時複製」出現在1領域的1道練習題中（連結器與載入器與執行檔格式等）。

這個名詞所屬的領域: 作業系統與硬體

練習寫入時複製的題目

當100個行程使用相同的共用函式庫時，關於實體記憶體的使用方式，下列何者正確？

  1. A不會被改寫的程式碼分頁共用一份副本，會被寫入的資料分頁則每個行程各自持有
  2. B程式碼與資料都為每個行程持有100份副本
  3. C包含資料分頁在內全部共用一份，行程之間會看到彼此的值
查看答案與解析

正確答案：A. 不會被改寫的程式碼分頁共用一份副本，會被寫入的資料分頁則每個行程各自持有

作業系統會將共用函式庫對應到各行程的虛擬位址空間，使不會被改寫的程式碼與常數的分頁指向相同的實體分頁。至於變數等會被寫入的資料分頁，則在被寫入的時點建立副本（寫入時複製，copy-on-write）等，讓每個行程各自獨立。如此一來，即使有100個行程，函式庫程式碼所佔的記憶體也只需要一份。

解析中的「寫入時複製」

  • 至於變數等會被寫入的資料分頁，則在被寫入的時點建立副本（寫入時複製，copy-on-write）等，讓每個行程各自獨立。
