什麼是記憶體一致性模型（Memory consistency model）

規定某個核心對多個位址所做的讀寫，在其他核心看來可能呈現何種順序的約定。有循序一致性、x86 的 TSO、ARM 與 RISC-V 的弱模型等。

日文名稱: メモリ一貫性モデル

「記憶體一致性模型（Memory consistency model）」出現在1領域的5道練習題中（多核心與同步等）。

這個名詞所屬的領域: 多核心與同步

練習記憶體一致性模型（Memory consistency model）的題目

記憶體一致性模型（memory consistency model）所規定的是下列何者？

  1. A快取列的大小與組（set）的數量
  2. B主記憶體DRAM所使用的電晶體種類
  3. C某個核心所進行的對多個位址的讀寫，從其他核心看來可能以什麼順序出現
查看答案與解析

正確答案：C. 某個核心所進行的對多個位址的讀寫，從其他核心看來可能以什麼順序出現

CPU為了提升效能，會把寫入暫存在儲存緩衝區（store buffer），或先行執行讀取，因此有時會改變記憶體操作的順序。在單一核心內雖然設計成結果不會改變，但從其他核心看來，順序可能顯得被調換了。記憶體一致性模型規定了哪些調換有可能發生，是讓程式設計師能寫出正確同步的一種約定。

關於x86的記憶體一致性模型（TSO，Total Store Order，全域儲存順序）的特徵，下列何者正確？

  1. A允許讀寫的任何組合被調換的、最弱的模型
  2. B完全不允許調換的循序一致性本身
  3. C只允許寫入之後對其他位址的讀取，比該寫入更早被看到的、相對較強的模型
查看答案與解析

正確答案：C. 只允許寫入之後對其他位址的讀取，比該寫入更早被看到的、相對較強的模型

在TSO中，寫入之間的順序、讀取之間的順序、讀取之後寫入的順序都會被保持，只有寫入之後對其他位址的讀取可以超前。這是直接反映儲存緩衝區存在的模型。多數程式在這個範圍內都能依直覺運作，所以在x86上需要屏障的場合相對較少。
