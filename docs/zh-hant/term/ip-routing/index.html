什麼是路由選擇（Routing）

在IP網路中，為了把封包送到目的地而決定經由哪條路徑傳送。各路由器持有路由表，選擇與目的地IP位址前綴一致最長的路由（最長前綴比對），交給下一個路由器。路由表可由人設定的靜態路由建立，也可由OSPF、RIP、BGP等路由協定自動建立的動態路由產生。

日文名稱: ルーティング(経路制御)

「路由選擇（Routing）」出現在2領域的9道練習題中（網路設計與維運, 電腦網路基礎等）。

這個名詞所屬的領域: 電腦網路基礎

練習路由選擇（Routing）的題目

路由器的路由表中有 0.0.0.0/0（下一個轉送對象為路由器A）、10.0.0.0/8（路由器B）、10.1.0.0/16（路由器C）、10.1.2.0/24（路由器D）4條路由。目的地為 10.1.5.9 的封包會送往哪一台路由器？

  1. A路由器B
  2. B路由器D
  3. C路由器C
查看答案與解析

正確答案：C. 路由器C

路由器會在與目的地位址相符的路由中，選擇前綴最長（最具體）的一條，這稱為最長前綴匹配。10.1.5.9 符合 0.0.0.0/0、10.0.0.0/8、10.1.0.0/16，但不在 10.1.2.0/24 的範圍（10.1.2.0～10.1.2.255）內。相符的路由中最長的是 /16，因此送往路由器C。0.0.0.0/0 是與所有目的地都相符的預設路由，只在沒有其他相符的路由時才使用。

下列關於動態路由的敘述，何者正確？

  1. A由管理者在各路由器上手動設定路由，發生故障時，在修改設定之前會持續使用相同的路由
  2. B路由器之間以路由協定交換路由資訊，當故障導致路由無法使用時，會自動切換到其他路徑
  3. C每個封包隨機選擇路徑，把負載平均分散到多條路徑上
查看答案與解析

正確答案：B. 路由器之間以路由協定交換路由資訊，當故障導致路由無法使用時，會自動切換到其他路徑

靜態路由是由管理者手動設定路由的方法。設定簡單、行為容易預測，適合小型網路或只有一個出口之據點的預設路由，但發生故障時不會自動切換。動態路由則由路由器以OSPF、BGP等路由協定交換資訊，自動建立路由表，鏈路斷線時會重新計算其他路徑。在網際網路上，組織網路（自治系統）之間的路由以BGP交換。實際的網路一般會將兩者組合使用。

出現這個名詞的比較

  • 距離向量型與鏈路狀態型路由協定的差異：以RIP與OSPF比較路由計算、收斂與規模從路由器掌握的資訊、路由的計算、度量值、更新的傳送方式、收斂速度與迴圈、網路規模、所需資源與設定、代表例等面向，以表格比較距離向量型（RIP等）與鏈路狀態型（OSPF等）的路由協定。
  • OSPF與BGP的差異：IGP與EGP、路由選擇方式、鄰居連線方式與規模比較從分類與使用範圍（IGP與EGP）、方式、路由的選擇方式、防止迴圈的方式、與鄰居路由器的連線方式、更新的傳送方式、收斂速度、處理的路由數量等面向，以表格比較OSPF與BGP。
  • 靜態路由與動態路由的差異：設定、故障時的切換、負載、規模與使用時機比較從路由的決定方式、故障時的動作、路由器的負載與頻寬、設定的工夫與規模、行為的可預測性、安全性、管理距離、適合的場合等面向，以表格比較靜態路由與動態路由。
