什麼是z轉換

把離散時間訊號 x[n] 轉換成複數 z 的函數 X(z) = Σx[n]z^(−n) 的方法。延遲1個取樣點相當於乘上 z⁻¹，因此差分方程式可當作 z 的分式（轉移函數 H(z)）處理。使 H(z) 的分母為0的 z 稱為極點，使分子為0的 z 稱為零點；因果系統在所有極點都位於單位圓內側時穩定。令 z = e^(jω) 在單位圓上求值，即可得到頻率響應。相當於連續時間的拉普拉斯轉換。

日文名稱: z変換

「z轉換」出現在1領域的1道練習題中（數位訊號處理基礎等）。

這個名詞所屬的領域: 數位訊號處理基礎

從差分方程式到轉移函數

例如把 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1] 兩邊做z轉換，得 Y(z) = X(z) + 0.5z⁻¹X(z) + 0.25z⁻¹Y(z)，整理後為 H(z) = (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)。分子代表輸入側，分母代表輸出回授側，只要直接對照係數，就能在濾波器的結構與轉移函數之間轉換。

極點、零點與頻率特性

某個頻率的增益大小，與單位圓上的點 e^(jω) 到各零點距離的乘積除以到各極點距離的乘積成正比。因此零點位於單位圓上時，該頻率的增益為0（陷波）；極點靠近單位圓時，該頻率附近的增益會大幅升高。只要看極點與零點的配置，就能知道濾波器特性的大致形狀。

穩定性的判斷

因果系統的脈衝響應對每個極點 p 含有 pⁿ 形式的成分，|p| < 1 時隨時間變小，|p| > 1 時持續變大。所有極點都在單位圓內側是穩定的條件；具有位於單位圓上極點的系統（例如累加器的 z = 1），有界的輸入可能使輸出無止境地增加，因此不是BIBO穩定。

練習z轉換的題目

以差分方程式 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1] 表示的系統，其轉移函數 H(z) = Y(z)/X(z) 為下列何者？

  1. A(1 + 0.5z⁻¹)/(1 + 0.25z⁻¹)
  2. B(1 − 0.25z⁻¹)/(1 + 0.5z⁻¹)
  3. C(1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)
查看答案與解析

正確答案：C. (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)

延遲1個取樣點在z轉換中相當於乘上 z⁻¹，因此兩邊做z轉換得 Y(z) = X(z) + 0.5z⁻¹X(z) + 0.25z⁻¹Y(z)。把 Y(z) 的項移到左邊，得 (1 − 0.25z⁻¹)Y(z) = (1 + 0.5z⁻¹)X(z)，所以 H(z) = (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)。分子表示輸入側的係數，分母表示輸出回授側的係數；使分母為0的 z = 0.25 是極點，使分子為0的 z = −0.5 是零點。

常見問題

z轉換與傅立葉轉換有什麼關係？

在z轉換中令 z = e^(jω)（單位圓上），就是離散時間傅立葉轉換（DTFT）。z轉換把 z 擴大到單位圓的內側與外側來考慮，使我們能從極點與零點的位置討論系統的穩定性與特性。有限長度訊號的DFT，相當於在單位圓上 N 個等間隔的點求DTFT。

為什麼 z⁻¹ 代表「延遲1個取樣點」？

因為 x[n − 1] 的z轉換為 Σx[n − 1]z^(−n)，令 m = n − 1 代換後成為 z⁻¹Σx[m]z^(−m) = z⁻¹X(z)。因此在方塊圖中把延遲元件寫成「z⁻¹」，並以乘法、加法與 z⁻¹ 的組合來表示數位濾波器。
