什麼是無滴答核心（Tickless kernel）

在沒有工作的 CPU 上停止固定間隔的計時滴答中斷，使其能休息到下一個工作為止的作業系統核心。

日文名稱: ティックレスカーネル

練習無滴答核心（Tickless kernel）的題目

關於Linux等OS所使用的無滴答（tickless）核心的概念，下列何者正確？

  1. A關閉時鐘的顯示，以降低螢幕的功率
  2. B在沒有工作時，停止以固定間隔喚醒的時間滴答中斷，使其能長時間休息到下一個工作為止
  3. C將時間滴答中斷增加到每秒數萬次
查看答案與解析

正確答案：B. 在沒有工作時，停止以固定間隔喚醒的時間滴答中斷，使其能長時間休息到下一個工作為止

傳統的OS以例如每秒100～1000次的時間滴答中斷來進行程式切換或時間管理，即使沒有事情可做，CPU也每次都會醒來。在無滴答核心中，沒有工作的CPU會停止滴答中斷，只在下一次必須醒來的時刻設定計時器。這樣CPU就能長時間深度休息，待機中的功率因而降低。

解析中的「無滴答核心（Tickless kernel）」

  • 在無滴答核心中，沒有工作的CPU會停止滴答中斷，只在下一次必須醒來的時刻設定計時器。
