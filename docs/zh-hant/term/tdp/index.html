什麼是TDP(熱設計功耗)

CPU 等以標準的高負載動作時所產生熱量的參考值。是散熱裝置設計的基準。

日文名稱: TDP(熱設計電力)

「TDP(熱設計功耗)」出現在2領域的2道練習題中（電源管理（軟體控制）, CPU與架構等）。

這個名詞所屬的領域: CPU與架構

練習TDP(熱設計功耗)的題目

在CPU的功率限制中，有一種設定允許在短時間內以超過長時間平均限制（接近TDP的值）的功率運作。這之所以成立的理由，下列何者正確？

  1. A晶片與散熱器具有蓄積熱量的容量，溫度不會立刻上升，所以在短時間內即使功率很大，也能遵守溫度限制
  2. B因為在短時間內，即使使用功率也不會產生熱
  3. C因為TDP不是功率的上限，而是表示最低值
查看答案與解析

正確答案：A. 晶片與散熱器具有蓄積熱量的容量，溫度不會立刻上升，所以在短時間內即使功率很大，也能遵守溫度限制

熱量會用來提高晶片、均熱片（heat spreader）與散熱片的溫度，到溫度完全上升為止需要數秒到數十秒。因此在短時間內，即使使用超過散熱能力的功率，也不會達到溫度限制。CPU具有長時間平均的功率限制，以及短時間內較高的限制，讓像是回應操作這類短暫的處理變得更快。若持續很久，就會降到長時間的限制。
