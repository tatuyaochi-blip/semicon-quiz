什麼是TDP(熱設計功耗)

CPU 等以標準的高負載動作時所產生熱量的參考值。是散熱裝置設計的基準。

日文名稱: TDP(熱設計電力)

「TDP(熱設計功耗)」出現在2領域的2道練習題中（電源管理（軟體控制）, CPU與架構等）。

這個名詞所屬的領域: CPU與架構

TDP 實際規定的是什麼

熱設計功耗（TDP）是以瓦特表示的散熱目標：在廠商定義的持續高負載下，散熱器必須能持續帶走的熱量，同時讓晶片保持在溫度上限之內。它不是晶片可汲取的最大電功率，而且各廠商的定義不盡相同。有些廠商由目標外殼溫度、環境溫度與參考散熱器的熱阻推導出 TDP。TDP 最好視為散熱片與風扇的設計指引，而不是功耗量測值。

為何晶片能暫時超過 TDP 運作

晶粒、均熱片與散熱片都具有熱容量，因此功率階躍上升後，溫度是在數秒到數十秒之間逐漸爬升，而非瞬間上升。所以處理器可以在短時間內汲取超過散熱器穩態能力的功率，而不會超過溫度上限。現代 CPU 利用這點設定兩種限制：接近 TDP 的長期平均功率，以及較高的短期限制，例如 Intel 稱之為 PL1 與 PL2。若高負載持續下去，功率就會回落到長期限制。

熱阻的計算

穩態接面溫度約等於環境溫度加上功率乘以從接面到環境的總熱阻。假設一顆 125 W 的晶片，必須在機殼內空氣達 35 °C 的情況下維持在 100 °C 以下。容許的溫升為 65 °C，因此包含熱介面材料、均熱片與散熱器在內的整條路徑，熱阻不得高於約 0.52 °C/W。這個簡單的計算說明了為何較高的 TDP 需要不成比例地更大或更好的散熱器。

TDP 與其他功率數值

由於加速（boost）行為讓實際功率可以超過 TDP，廠商越來越常分別標示基礎或持續功率與最大 turbo 功率。供電設計者還需要另一個數值：在快速負載暫態期間，電壓調節器必須供應的峰值電流，可能遠超過平均功率所暗示的水準。筆電處理器常支援可設定 TDP（configurable TDP），讓系統廠商在效能與散熱器尺寸之間取捨。顯示卡則通常以總板卡功耗（total board power）標示，除了晶片之外也包含記憶體與電壓調節器的損耗。

練習TDP(熱設計功耗)的題目

在CPU的功率限制中，有一種設定允許在短時間內以超過長時間平均限制（接近TDP的值）的功率運作。這之所以成立的理由，下列何者正確？

  1. A晶片與散熱器具有蓄積熱量的容量，溫度不會立刻上升，所以在短時間內即使功率很大，也能遵守溫度限制
  2. B因為在短時間內，即使使用功率也不會產生熱
  3. C因為TDP不是功率的上限，而是表示最低值
查看答案與解析

正確答案：A. 晶片與散熱器具有蓄積熱量的容量，溫度不會立刻上升，所以在短時間內即使功率很大，也能遵守溫度限制

熱量會用來提高晶片、均熱片（heat spreader）與散熱片的溫度，到溫度完全上升為止需要數秒到數十秒。因此在短時間內，即使使用超過散熱能力的功率，也不會達到溫度限制。CPU具有長時間平均的功率限制，以及短時間內較高的限制，讓像是回應操作這類短暫的處理變得更快。若持續很久，就會降到長時間的限制。

常見問題

TDP 是 CPU 的最大功耗嗎？

不是。TDP 是持續散熱的目標，現代 CPU 在溫度與功率限制允許時，經常在短暫的加速期間汲取更多功率。

為什麼我的 CPU 耗電超過 TDP？

它正在比接近 TDP 的長期限制更高的短期功率限制下運作，並把晶片與散熱器的熱質量當作緩衝。有些主機板也會預設提高或解除這些限制。

可以用額定值低於 CPU TDP 的散熱器嗎？

晶片通常會以降頻（throttling）自我保護，但在持續負載下會損失效能。若要完整發揮持續效能，散熱器至少應能應付長期功率限制。
