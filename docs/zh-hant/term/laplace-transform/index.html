什麼是拉普拉斯轉換

把時間的函數 f(t)（t ≥ 0）轉換為複數 s 的函數 F(s) = ∫₀^∞ f(t)e^(−st) dt 的方法。初始值為0時，微分對應乘以 s，積分對應除以 s，因此能把線性微分方程式當作 s 的代數式處理。它是控制工程中求轉移函數的基本工具，離散時間系統則由z轉換扮演同樣的角色。單位步階轉換為 1/s，e^(−at) 轉換為 1/(s + a)。

這個名詞所屬的領域: 控制工程基礎

常用的轉換對

單位脈衝 δ(t) 為1，單位步階為 1/s，斜坡 t 為 1/s²，e^(−at) 為 1/(s + a)，sin ωt 為 ω/(s² + ω²)。時間延後 L 會乘上 e^(−Ls)，乘上 e^(−at) 則把 s 換成 s + a。把這些轉換對與部分分式展開組合起來，許多響應都能一邊查表一邊做逆轉換。

終值定理與初值定理

只有在 sF(s) 的極點全部位於s平面左半部時，才能以 lim[t→∞] f(t) = lim[s→0] sF(s) 求出輸出的終值。例如轉移函數為 G(s) 的系統，其步階響應的終值為 G(0)，稱為穩態增益。初值則以 lim[t→+0] f(t) = lim[s→∞] sF(s) 求出。

與傅立葉轉換、z轉換的關係

在虛軸 s = jω 上計算拉普拉斯轉換，就相當於傅立葉轉換（頻率響應）。對取樣後的訊號，令 z = e^(sT) 的z轉換扮演同樣的角色，s平面的左半部對應z平面的單位圓內側。因此，連續時間的「極點實部為負則穩定」，在離散時間中成為「極點在單位圓內側則穩定」。

練習拉普拉斯轉換的題目

某電路電壓的拉普拉斯轉換為 V(s) = 10(s + 3)/(s(s + 2)(s + 5))。經過足夠時間後的電壓 v(∞) 為下列哪一項？

  1. A0 V
  2. B3 V
  3. C10 V
查看答案與解析

正確答案：B. 3 V

解法1（終值定理）：v(∞) = lim(s→0) sV(s) = 10 × 3/(2 × 5) = 3 V。此定理在 sV(s) 的極點全部位於左半平面（響應會收斂）時才能使用。解法2（以部分分式展開確認）：設 V(s) = A/s + B/(s + 2) + C/(s + 5)，得 A = 3、B = −5/3、C = −4/3，因此 v(t) = 3 − (5/3)e^(−2t) − (4/3)e^(−5t)。t → ∞ 時指數項消失而成為3 V，t = 0 時為 3 − 5/3 − 4/3 = 0，與初值定理 lim(s→∞) sV(s) = 0 也一致。

當初始值全為0時，時間函數的微分與積分在拉普拉斯轉換後的 s 域中所對應的運算，正確的組合是下列何者？

  1. A微分是乘以 s，積分是除以 s
  2. B微分是除以 s，積分是乘以 s
  3. C微分是加上 s，積分是減去 s
查看答案與解析

正確答案：A. 微分是乘以 s，積分是除以 s

在拉普拉斯轉換中，f(t) 的微分對應 sF(s) − f(0)，積分對應 F(s)/s。若初始值為0，微分就是乘以 s，積分就是除以 s，微分方程式因此變成 s 的多項式的運算。例如，RC電路的式子 RC·dv/dt + v = vin 變成 (RCs + 1)V(s) = Vin(s)，得到轉移函數 1/(1 + RCs)。單位步階函數轉換為 1/s，e^(−at) 轉換為 1/(s + a)。

常見問題

為什麼控制工程要使用拉普拉斯轉換？

因為它能把微分方程式變成代數式，所以連接多個元件的系統，其轉移函數可以用乘法與除法組合出來。由極點的位置也能讀出穩定性與響應的快慢。

初始值不為0時會怎樣？

微分的轉換成為 sF(s) − f(0)，會留下初始值的項。轉移函數是以初始值為0來定義的，因此由初始值造成的響應要另外加上來考慮。
