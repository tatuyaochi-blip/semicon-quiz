什麼是回歸測試（Regression testing）

每次變更設計，就重新一併執行至今的測試，確認先前正確的功能沒有被破壞。

日文名稱: 回帰テスト

練習回歸測試（Regression testing）的題目

關於電路設計中進行的迴歸測試（regression test）的說明，下列何者正確？

  1. A只對新做好的功能試驗1次
  2. B調查電路的性能逐年下降的趨勢
  3. C每次變更設計時，就重新批次執行至今的測試，確認以前正確的功能是否被破壞
查看答案與解析

正確答案：C. 每次變更設計時，就重新批次執行至今的測試，確認以前正確的功能是否被破壞

修正某個缺陷或增加功能時，有時會在意想不到的地方破壞其他部分。在迴歸測試中，會將至今做好的測試全部自動批次執行，確認以前通過的測試是否失敗。在大規模的設計中，幾乎每天都會執行成千上萬個測試，並以清單管理結果。有了自我檢查型測試平台，才能做到這樣的自動化。

解析中的「回歸測試（Regression testing）」

  • 在迴歸測試中，會將至今做好的測試全部自動批次執行，確認以前通過的測試是否失敗。

  • 另一個優點是，每次變更都能自動進行將既有測試全部重新執行的迴歸測試。
