什麼是常閉型(Normally-off)

閘極電壓為 0 V 時沒有電流流動的特性。即使驅動電路故障，電流也不會持續流動，因此在安全上是功率元件所要求的。

日文名稱: ノーマリーオフ

「常閉型(Normally-off)」出現在1領域的1道練習題中（新世代記憶體等）。

這個名詞所屬的領域: 功率半導體

練習常閉型(Normally-off)的題目

將非揮發性記憶體用於快取或暫存器等處所期待的系統節能機制，下列何者正確？

  1. A待機時即使關閉電源資料也不會消失，因此可大幅減少待機功耗
  2. B因為可以提高時脈頻率
  3. C因為記憶體容量增加
查看答案與解析

正確答案：A. 待機時即使關閉電源資料也不會消失，因此可大幅減少待機功耗

SRAM 與 DRAM 是揮發性的，為了保存資料必須持續供電，待機時也會因漏電流而耗電。若將非揮發性記憶體用於快取或暫存器，即使在沒有處理的瞬間細密地關閉電源，資料也會留存，因此可使待機功耗幾近於 0，恢復也更快（常閉運算，Normally-off Computing）。對於感測器節點等大部分時間處於待機的 IoT 裝置尤其有效。

解析中的「常閉型(Normally-off)」
