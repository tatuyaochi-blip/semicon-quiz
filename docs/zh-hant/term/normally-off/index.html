什麼是常閉型(Normally-off)

閘極電壓為 0 V 時沒有電流流動的特性。即使驅動電路故障，電流也不會持續流動，因此在安全上是功率元件所要求的。

日文名稱: ノーマリーオフ

「常閉型(Normally-off)」出現在4領域的5道練習題中（MOSFET, 化合物半導體, 新世代記憶體等）。

這個名詞所屬的領域: 功率半導體

練習常閉型(Normally-off)的題目

為了讓常開型（normally-on）的GaN HEMT能以常閉型（normally-off）的方式安全使用，而與低耐壓的矽MOSFET串聯組合的架構是下列何者？

  1. A橋式整流
  2. B達靈頓連接
  3. C疊接（cascode）架構
查看答案與解析

正確答案：C. 疊接（cascode）架構

在疊接架構中，將低耐壓（約30 V）的矽MOSFET串聯在GaN HEMT的源極側，並將HEMT的閘極接到MOSFET的源極。MOSFET關閉時，HEMT的閘極會被施加負偏壓而自動關閉，因此整體可視為常閉型元件，並能直接使用矽MOSFET用的閘極驅動電路。缺點是零件增加，且在高速時MOSFET側的寄生成分會造成影響。

解析中的「常閉型(Normally-off)」

  • MOSFET關閉時，HEMT的閘極會被施加負偏壓而自動關閉，因此整體可視為常閉型元件，並能直接使用矽MOSFET用的閘極驅動電路。

    為了讓常開型（normally-on）的GaN HEMT能以常閉型（normally-off）的方式安全使用，而與低耐…

  • VGS = 0 V時沒有通道而處於關閉狀態，因此即使閘極浮接也不易有電流流過（常閉型），適合邏輯電路與功率用途的安全性。

    增強型n通道MOSFET導通（ON）的正確條件為下列何者？（VGS：閘極-源極間電壓，Vth：臨界電壓）

  • 由於即使電源中斷也會導通，在安全方面需要留意，GaN的HEMT本質上也是常開型，因此會在結構上下工夫使其成為常閉型。

    關於空乏型MOSFET的特徵，下列何者正確？

  • 若將非揮發性記憶體用於快取或暫存器，即使在沒有處理的瞬間細密地關閉電源，資料也會留存，因此可使待機功耗幾近於 0，恢復也更快（常閉運算，Normally-off Computing）。

    將非揮發性記憶體用於快取或暫存器等處所期待的系統節能機制，下列何者正確？

  • 因此電源電路會要求常閉型。
