什麼是容錯（Fault tolerance）

承認零件或設備必然會故障，藉由多重化等方式，使一部分故障時系統整體仍能正確地繼續運作的概念。與讓故障本身不易發生的避錯（fault avoidance）相對。

日文名稱: フォールトトレランス

「容錯（Fault tolerance）」出現在1領域的2道練習題中（系統架構與可靠度設計等）。

這個名詞所屬的領域: 系統架構與可靠度設計

練習容錯（Fault tolerance）的題目

下列何者是基於防呆（fool-proof）概念的設計範例？

  1. A將重要的資料同時寫入2台磁碟
  2. B定期進行零件的點檢與更換，減少故障的發生
  3. C把連接器的形狀做成左右不對稱，使其無法反向插入
查看答案與解析

正確答案：C. 把連接器的形狀做成左右不對稱，使其無法反向插入

防呆是讓人即使進行了錯誤的操作，也不會變成危險狀態或誤動作，或者根本無法進行錯誤操作的設計概念。做成無法反向插入形狀的連接器，是以物理方式防止錯誤連接的代表性範例。將資料寫入2台磁碟是藉由備援達成的容錯，以定期點檢與更換減少故障則是避錯（fault avoidance）的概念。

在提高系統可靠度的概念中，屬於避錯（fault avoidance）的是下列何者？

  1. A選用可靠度高的零件，並在出貨前以篩選（預燒等）剔除容易發生早期失效的產品，使故障本身不易發生
  2. B將設備多重化，使一部分故障時系統整體仍能維持功能
  3. C使系統在發生故障時進入安全側的狀態
查看答案與解析

正確答案：A. 選用可靠度高的零件，並在出貨前以篩選（預燒等）剔除容易發生早期失效的產品，使故障本身不易發生

避錯是藉由使用高品質的零件、充分的測試與篩選、預防保養等，使故障本身不易發生的概念。預燒等篩選是為了在出貨前剔除屬於浴缸曲線早期失效期的故障而進行的。相對地，承認故障必然發生，藉由多重化等方式使故障時仍能維持功能的是容錯。故障時進入安全側的狀態，則是失效安全的概念。

解析中的「容錯（Fault tolerance）」

  • 將資料寫入2台磁碟是藉由備援達成的容錯，以定期點檢與更換減少故障則是避錯（fault avoidance）的概念。
