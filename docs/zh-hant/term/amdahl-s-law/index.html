什麼是阿姆達爾定律

只將程式的一部分平行化時，整體的加速受限於無法平行化的部分的定律。例如即使將 90% 平行化，最多也只能加速到 10 倍。

日文名稱: アムダールの法則

「阿姆達爾定律」出現在3領域的6道練習題中（效能評估與效能剖析, CPU與架構, 多核心與同步等）。

這個名詞所屬的領域: CPU與架構

公式與加速上限

阿姆達爾定律指出，若程式中可平行化的比例為p，並分散到N個處理器上執行，加速比為S = 1 / ((1 − p) + p/N)。當N無限增大時，p/N項趨近於零，加速比趨近1 / (1 − p)。p = 0.9時上限為10倍，而使用10個處理器時只有約5.3倍，等於一半的硬體實際上被浪費了。一旦平行部分被分割得夠細，序列部分無論看起來多小，最終都會主導執行時間。

同一定律適用於任何加速

這個定律適用於任何局部改善，而不只是增加核心數。若將佔執行時間50%的區段加快4倍，新的執行時間為原本的0.5 + 0.5/4 = 0.625，整體加速1.6倍；而且無論再怎麼最佳化該區段，都不可能超過2倍。即使將只佔1%時間的部分變得無限快，也只能獲得約1%的改善。這正是「讓常見情況變快」的定量依據，也是最佳化之前要先對程式進行效能剖析的原因。

阿姆達爾定律與古斯塔夫森定律

阿姆達爾定律假設問題規模固定，對應於強擴展（strong scaling）：將同一份工作分給更多處理器。古斯塔夫森定律則假設相反的情況：處理器越多，人們就會在相同時間內解更大的問題，例如更細的模擬網格。平行工作量隨問題規模增加，序列部分則大致不變，因此序列比例縮小，加速比幾乎與處理器數量成正比成長。這就是弱擴展（weak scaling）。兩個定律都沒有錯，只是針對工作負載的不同使用方式回答不同的問題。

實際程式為何比公式更差

阿姆達爾定律已假設平行部分能完美擴展，因此實測的加速比通常更低。執行緒會在鎖與屏障處等待，共用資料與偽共享（false sharing）使快取線在核心之間來回彈跳，工作分配不均讓部分核心閒置，大量執行緒也可能使記憶體頻寬飽和。通訊與同步的負擔甚至可能隨N增加，因此增加核心最終反而可能讓程式變慢。當每個執行緒主要處理私有資料、很少通訊或等待時，才能得到最理想的擴展性。

練習阿姆達爾定律的題目

將占整個處理50%的部分加快為4倍。整體的加速比是多少（阿姆達爾定律）？

  1. A2倍
  2. B1.6倍
  3. C4倍
查看答案與解析

正確答案：B. 1.6倍

改善後的時間，是未加速的其餘50%（0.5）與加快4倍的50%（0.5÷4 = 0.125）的總和，為0.625。加速比為1÷0.625 = 1.6倍。無論把加速的部分再加快多少，其餘的50%依然存在，所以整體最多也只能到2倍。要大幅加快整體，必須找出占用大量時間的部分來改善。

從阿姆達爾定律可得到的、關於效能改善作法的啟示，下列何者最適當？

  1. A優先加速花費大量時間的部分（常見情況）
  2. B先加速很少被執行的部分
  3. C無論加速哪個部分，對整體的效果都相同
查看答案與解析

正確答案：A. 優先加速花費大量時間的部分（常見情況）

即使把只占整體1%的部分加速到無限快，整體也只會變快約1%。相對地，若將占80%的部分加快2倍，整體約為1.7倍。因此基本作法是先用剖析器（profiler）等找出花費大量時間的部分，再從那裡開始改善。「加速常見情況」是電腦設計中也反覆使用的原則。

常見問題

如何用阿姆達爾定律計算加速比？

以1除以新的相對執行時間：S = 1 / ((1 − p) + p/s)，其中p是受影響的時間比例，s是該部分變快的倍數（N個處理器時s = N）。p = 0.5、s = 4時，結果為1 / 0.625 = 1.6倍。

如果程式有95%可以平行化，最大加速比是多少？

無論使用多少處理器，上限都是1 / (1 − 0.95) = 20倍。即使只是接近這個上限，也需要非常多的處理器，以及近乎完美的平行效率。

阿姆達爾定律和古斯塔夫森定律有什麼不同？

阿姆達爾定律固定問題規模，說明序列部分會限制加速比。古斯塔夫森定律則讓問題規模隨處理器數量成長，使序列比例縮小，因此可能達到接近線性的規模化加速。

解析中的「阿姆達爾定律」

  • 依據阿姆達爾定律（Amdahl's law），設可平行化的比例為 p、處理器數為 N，加速比為 1/((1 − p) + p/N)。

    對於整體處理中有 90% 可以平行化的程式，在無限增加處理器數量來執行時，理論上的最大加速比為何？

  • 妨礙平行化效果的主要原因包括：無法平行化的部分（阿姆達爾定律）、鎖或屏障造成的等待、共用資料或偽共享造成的快取列來回移動、工作的偏差，以及記憶體頻寬不足等。

    在平行程式中，即使增加核心數量，效能仍未如預期成長，下列何者不屬於其原因？

  • 阿姆達爾定律考慮的是在不改變問題規模的情況下增加處理器，因此無法平行化的部分決定了加速比的上限。

    古斯塔夫森定律（Gustafson's law）所表達的想法，下列何者正確？

  • 如同阿姆達爾定律所述，改善花費大量時間的部分才有效，所以先測量就是改善效能的第一步。
