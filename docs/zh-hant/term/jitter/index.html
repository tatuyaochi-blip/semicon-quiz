什麼是抖動(Jitter)

時脈或訊號邊緣的時序相對於理想值的細微時間性波動。取樣高頻訊號時，即使微小的抖動也會造成很大的電壓誤差。

日文名稱: ジッタ

「抖動(Jitter)」出現在7領域的13道練習題中（AD/DA轉換, 類比與電子電路, 作業系統與硬體等）。

這個名詞所屬的領域: AD/DA轉換

練習抖動(Jitter)的題目

輸入上升時與下降時的臨界值不同，可防止雜訊造成輸出抖動的電路是哪一個？

  1. APLL
  2. B取樣保持電路
  3. C史密特觸發器
查看答案與解析

正確答案：C. 史密特觸發器

史密特觸發器是將輸入上升時的臨界值設高、下降時設低，使其具有差值（遲滯）的電路。即使接收緩慢變化的訊號或含雜訊的訊號，也能防止輸出在臨界值附近反覆切換（彈跳）。它是對比較器施加正回授製成的，也有74HC14這類邏輯IC。也用於開關輸入的整形與RC振盪器（張弛振盪）。

對高頻訊號進行AD轉換時，取樣時脈在時間上的晃動（抖動，jitter）會成為問題，其原因下列何者正確？

  1. A因為時脈會停止
  2. B因為只有直流訊號會產生誤差
  3. C因為訊號變化越快，取樣時刻的些微偏差就會造成越大的電壓誤差
查看答案與解析

正確答案：C. 因為訊號變化越快，取樣時刻的些微偏差就會造成越大的電壓誤差

取樣時刻偏差Δt時，期間的訊號變化量就成為誤差。由於正弦波的斜率與頻率成正比，由抖動決定的SNR上限為SNR = −20 log₁₀(2πf·tj)。例如要在100 MHz的訊號得到70 dB，需將抖動降到約0.5 ps以下。因此在高速、高解析度的ADC或無線接收機中，相位雜訊小的時脈源設計左右著性能。

    在時序限制（SDC）中，用來指定作為時脈抖動（jitter）或偏斜預估值等而事先從時脈週期扣除之餘裕的設定，為下列何者？

  • 週期在時間上的抖動則是時脈抖動（jitter）。

    下列哪一項是對同步式電路「時脈偏斜」的正確說明？

  • 為了防止輸出因雜訊而抖動，有時也會加入遲滯。

    下列哪一項是比較器的正確功能？

  • 實際的ADC會再加上熱雜訊、失真與時脈抖動而低於此值，因此以由量測值反推的有效位元數（ENOB）來比較實力。
