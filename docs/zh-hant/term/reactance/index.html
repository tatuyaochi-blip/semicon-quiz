什麼是電抗

阻抗的虛部，表示線圈或電容器阻礙交流電流的程度 [Ω]。線圈為 XL = ωL = 2πfL，與頻率成正比增大；電容器為 XC = 1/(ωC) = 1/(2πfC)，與頻率成反比減小。例如1 µF的電容器在1 kHz時約為159 Ω。與電阻不同，電抗不消耗功率，並使電壓與電流的相位相差90°。

練習電抗的題目

靜電容量1 µF的電容器，在頻率1 kHz時的電抗大小最接近下列哪一個？

  1. A約6.3 mΩ
  2. B約159 Ω
  3. C1 kΩ
查看答案與解析

正確答案：B. 約159 Ω

容抗為 Xc = 1/(2πfC)。2π × 1×10³ × 1×10⁻⁶ ≈ 6.28×10⁻³，因此 Xc ≈ 1/(6.28×10⁻³) ≈ 159 Ω。頻率為10倍的10 kHz時約為15.9 Ω，與頻率成反比而變小。電感器的感抗 XL = 2πfL 則相反，與頻率成正比。

電阻R = 30 Ω與電抗XL = 40 Ω的線圈串聯的電路，其阻抗大小是多少？（忽略線圈的電阻成分）

  1. A70 Ω
  2. B10 Ω
  3. C50 Ω
查看答案與解析

正確答案：C. 50 Ω

電阻與線圈的電壓相位相差90°，因此不能直接相加，要以複數（向量）合成。Z = R + jXL = 30 + j40 Ω，大小為 √(30² + 40²) = √2500 = 50 Ω。電流比電壓落後 φ = tan⁻¹(40/30) ≈ 53°，功率因數為 cos φ = 30/50 = 0.6。
