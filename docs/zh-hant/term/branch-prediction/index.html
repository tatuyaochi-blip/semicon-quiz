什麼是分支預測

在執行前預測條件分支的結果，不使管線停頓而處理後續指令的技術。預測錯誤時會重新處理。

日文名稱: 分岐予測

「分支預測」出現在4領域的12道練習題中（硬體安全, CPU與架構, GPU程式設計等）。

這個名詞所屬的領域: CPU與架構

練習分支預測的題目

關於 CPU 分支預測的目的，下列何者正確？

  1. A預測分支指令的結果並提前執行後續指令，以減少管線停頓
  2. B預測功耗並控制電源
  3. C預測主記憶體的容量
查看答案與解析

正確答案：A. 預測分支指令的結果並提前執行後續指令，以減少管線停頓

在管線中，必須等到分支指令的結果確定，下一道指令才能決定，處理因而會停住。分支預測會根據過去的歷史等資訊預測分支目的地並繼續向前執行，只有在預測錯誤時才重做。程式中約每 5 道指令就有 1 道是分支，因此影響很大，現今的高效能 CPU 預測準確率超過 95%。一次預測失誤會損失十幾〜二十個時脈左右，因此即使準確率只提升一點點，也會影響效能。

解析中的「分支預測」

  • 分支預測會根據過去的歷史等資訊預測分支目的地並繼續向前執行，只有在預測錯誤時才重做。

    關於 CPU 分支預測的目的，下列何者正確？

  • 資料相依、分支、資源競爭會擾亂流程（危障，hazard），可用前饋（forwarding）與分支預測來因應。

    CPU 管線化（pipeline）處理的主要目的，下列何者正確？

  • 超純量、亂序執行、分支預測、大型快取，全都是提高 IPC 的技術。

    表示每個時脈可執行之指令數的指標是下列何者？

  • 當發生分支預測失誤或例外時，可捨棄其後指令的結果並恢復到正確的狀態，因此從外部看來，就像是依照程式原本順序執行一樣（精確例外，precise exception）。

    在亂序執行的 CPU 中，用來將調換順序執行之指令的結果，依程式原本的順序確定（引退，retire）的機制是下列何者？

  • CPU將電路用於大型快取、分支預測、亂序執行等，盡可能讓單一執行緒快速推進。
