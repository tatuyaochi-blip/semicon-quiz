什麼是分支預測

在執行前預測條件分支的結果，不使管線停頓而處理後續指令的技術。預測錯誤時會重新處理。

日文名稱: 分岐予測

「分支預測」出現在6領域的20道練習題中（硬體安全, CPU與架構, 效能評估與效能剖析等）。

這個名詞所屬的領域: CPU與架構

練習分支預測的題目

關於 CPU 分支預測的目的，下列何者正確？

  1. A預測分支指令的結果並提前執行後續指令，以減少管線停頓
  2. B預測功耗並控制電源
  3. C預測主記憶體的容量
查看答案與解析

正確答案：A. 預測分支指令的結果並提前執行後續指令，以減少管線停頓

在管線中，必須等到分支指令的結果確定，下一道指令才能決定，處理因而會停住。分支預測會根據過去的歷史等資訊預測分支目的地並繼續向前執行，只有在預測錯誤時才重做。程式中約每 5 道指令就有 1 道是分支，因此影響很大，現今的高效能 CPU 預測準確率超過 95%。一次預測失誤會損失十幾〜二十個時脈左右，因此即使準確率只提升一點點，也會影響效能。

以效能計數器發現分支預測錯誤非常多。下列何者是適用的改善方法？

  1. A在迴圈中再增加分支
  2. B將資料排序，使分支的結果更容易預測，或是以條件選擇或運算來消除分支本身
  3. C減少快取的容量
查看答案與解析

正確答案：B. 將資料排序，使分支的結果更容易預測，或是以條件選擇或運算來消除分支本身

一旦分支預測錯誤，CPU就必須丟棄推測性執行的指令並重新來過，每次會損失十幾個週期以上。若資料是隨機的，像「值在128以上的話」這類分支的結果就無法預測。若事先將資料排序，結果會趨於一致而使預測容易命中；若改用條件選擇指令或位元運算來撰寫，分支本身就會消失。也可以促使編譯器進行這類轉換。
