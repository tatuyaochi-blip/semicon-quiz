什麼是GPU 核心函式（GPU kernel）

在 GPU 上由大量執行緒同時執行的函式。從 CPU 端的程式啟動，各執行緒以自己的編號選擇負責的資料。與作業系統的核心（kernel）意義不同。

日文名稱: GPUカーネル

「GPU 核心函式（GPU kernel）」出現在1領域的17道練習題中（GPU程式設計等）。

這個名詞所屬的領域: GPU程式設計

關於CUDA等GPU程式設計所稱的「核心函式（kernel）」，下列說明何者正確？

  1. AGPU作業系統的核心部分
  2. B在GPU上由大量執行緒同時執行的函式
  3. C冷卻GPU晶片的零件
查看答案與解析

正確答案：B. 在GPU上由大量執行緒同時執行的函式

GPU程式設計中的核心函式（kernel），是由CPU端的程式啟動，並由GPU上的大量執行緒執行相同程式碼的函式。各執行緒使用自己的編號來選擇負責的資料元素。例如陣列相加時，將核心函式寫成由一個執行緒加總一個元素，再依元素數量啟動執行緒。雖然與作業系統的核心（kernel）用語相同，但意義不同。

在GPU核心函式中，若每個執行緒的暫存器使用量過多，下列何者是可能發生的情況？

  1. A暫存器會自動增加，效能必定提升
  2. B計算結果必定出錯
  3. C由於SM的暫存器總數是固定的，能同時載入的執行緒數量會減少，更難隱藏記憶體的延遲
查看答案與解析

正確答案：C. 由於SM的暫存器總數是固定的，能同時載入的執行緒數量會減少，更難隱藏記憶體的延遲

GPU將所有執行中的執行緒的暫存器都保留在晶片上，因此能瞬間切換線程束。所以一旦每個執行緒使用的暫存器較多，能同時載入SM的執行緒數量就會減少。不足的部分會被擠到記憶體（暫存器溢出，spill），有時也會變慢。有時會以編譯器的設定指定暫存器的上限，以取得與執行緒數量之間的平衡。
