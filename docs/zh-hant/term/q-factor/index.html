什麼是Q值（品質因數）

表示共振尖銳程度的無因次量。為共振頻率除以頻寬 Q = f0/BW，也對應於儲存能量與每週期損失能量之比。串聯RLC電路為 Q = (1/R)√(L/C)，並聯RLC電路為 Q = R√(C/L)，損失越小越大。石英振盪子與MEMS共振器可達數萬以上。

日文名稱: Q値(クオリティファクタ)

「Q值（品質因數）」出現在4領域的8道練習題中（MEMS與感測器, 類比與電子電路, 電路分析（交流電路、線性電路與暫態現象）等）。

這個名詞所屬的領域: 電路分析（交流電路、線性電路與暫態現象）

練習Q值（品質因數）的題目

諧振電路的Q值（品質因數）大，其意義下列哪一項正確？

  1. A諧振頻率高
  2. B損失小，諧振的峰值尖銳（頻寬窄）
  3. C損失大，頻寬寬
查看答案與解析

正確答案：B. 損失小，諧振的峰值尖銳（頻寬窄）

Q值表示諧振的尖銳程度，Q = f0/Δf（諧振頻率÷頻寬）。Q越大，損失越小，峰值越尖銳，頻寬越窄。例如 f0 = 1 MHz、Q = 100 時，頻寬為10 kHz。在串聯RLC電路中 Q = (1/R)√(L/C)，電阻（損失）越小就越大。頻率選擇性高的濾波器與相位雜訊小的振盪器都需要高Q。
