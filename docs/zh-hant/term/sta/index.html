什麼是STA(靜態時序分析)

不使用測試向量，而是計算電路中各路徑的延遲，驗證是否滿足時序限制的方法。

日文名稱: STA(静的タイミング解析)

「STA(靜態時序分析)」出現在4領域的22道練習題中（時序分析與CDC, LSI設計流程與EDA, 硬體描述語言與驗證等）。

這個名詞所屬的領域: LSI設計流程與EDA

STA 的運作方式

靜態時序分析把同步設計拆解成時序路徑，主要是從一個正反器到下一個正反器的路徑。對每條路徑，它把元件延遲（從以輸入轉態時間與輸出負載為索引的特性化元件庫表格內插而得）與導線延遲相加，得到資料到達時間。再把它與由時脈邊緣及擷取端正反器的設定或保持要求所決定的需求時間比較。餘裕（slack）等於需求時間減去到達時間；負的餘裕即為違規。由於不需要測試向量，所有路徑都會被涵蓋，但邏輯正確性仍須以模擬驗證。

約束條件告訴 STA 要檢查什麼

工具需要時序約束條件，通常採用 SDC 格式：時脈週期與波形、輸入與輸出延遲，以及例外設定。偽路徑（false path）用來排除永遠不會被觸發的連接，例如被互斥選擇訊號擋住的路徑。多週期路徑（multicycle path）讓某條路徑在設定時間檢查上有 N 個週期，通常還會設定 N − 1 的保持時間多週期，把保持檢查移回原本的邊緣。錯誤的約束條件很危險：晶片可能通過所有工具檢查，實際製成矽晶片後卻失效。報告會以最差負餘裕（WNS）與總負餘裕（TNS）彙整結果。

製程角與晶片內變異

延遲會隨製程、電壓與溫度（PVT）變化，因此要在多個製程角（corner）重複分析。設定時間通常在電晶體偏慢、電壓偏低的慢速角最差；保持時間則在快速角最差。在先進製程中，溫度反轉（低電壓電路溫度越低反而越慢）會增加需要分析的角落。在同一晶粒內，晶片內變異（OCV）降額會在設定時間檢查中讓資料路徑與發射時脈路徑變慢、擷取時脈路徑變快。共同路徑悲觀消除（CRPR）則會把兩條路徑共用的時脈緩衝器被同時當成慢與快這種不可能的處理所造成的悲觀量補回來。

修正違規

設定時間違規表示路徑太慢：對策包括減少邏輯級數、加大元件尺寸或改用較快的低臨界電壓元件、讓元件擺放得更近以縮短導線，或者最後手段是降低時脈頻率。保持時間違規表示路徑太快，由於該檢查不涉及時脈週期，因此要插入延遲緩衝器來修正。基於圖的分析在每個節點都採用最差的轉態，可能過於悲觀，因此基於路徑的分析（PBA）會以實際轉態重新計算失敗路徑，以避免不必要的修正。

練習STA(靜態時序分析)的題目

關於靜態時序分析（STA）的說明，下列何者正確？

  1. A實際試做晶片並量測運作速度
  2. B輸入大量測試圖樣，以模擬確認運作
  3. C不使用測試圖樣，而是計算電路各路徑的延遲，驗證是否滿足時序限制
查看答案與解析

正確答案：C. 不使用測試圖樣，而是計算電路各路徑的延遲，驗證是否滿足時序限制

STA是將電路所有訊號路徑（path）上單元與佈線的延遲累加計算，全面檢查是否滿足建立時間與保持時間等時序限制的方法。它不需要測試圖樣，連使用圖樣時會漏看的路徑也能完整確認，因此是大規模LSI時序驗證的核心。但它不會檢查邏輯是否正確，所以功能驗證必須另以模擬等方式進行。

在靜態時序分析中，訊號在時脈邊緣之後變化得太快，導致正反器無法正確保持先前資料的時序違反為下列何者？

  1. A建立時間違反
  2. B保持時間違反
  3. CDRC違反
查看答案與解析

正確答案：B. 保持時間違反

保持時間違反是指資料路徑太短，時脈邊緣之後資料沒有保持所需的時間，新資料在同一個邊緣就被擷取進去的違反。保持條件是比較同一個邊緣，不涉及週期，因此降低時脈頻率也無法解決，需插入延遲用的緩衝器來修正。路徑太長而來不及的是建立時間違反，DRC違反則是佈局的規則違反。

常見問題

靜態時序分析和時序模擬有什麼差別？

STA 不需輸入向量，直接根據電路結構計算每條路徑的最差延遲，因此涵蓋範圍完整且快速。時序模擬則施加特定向量並檢查行為，只能涵蓋這些向量所觸發的路徑，但也能驗證功能。

STA 中的 slack（餘裕）是什麼？

slack 是路徑的需求時間減去到達時間。正的 slack 表示約束條件已滿足且仍有裕度，負的 slack 則表示必須修正的違規。

時序報告中的 WNS 和 TNS 是什麼？

WNS（最差負餘裕）是最差那一條路徑的 slack，TNS（總負餘裕）則是所有違規端點負 slack 的總和。WNS 小而 TNS 大，表示有許多路徑只差一點點而失敗。
