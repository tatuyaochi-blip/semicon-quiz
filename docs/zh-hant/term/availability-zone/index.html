什麼是可用區域

在雲端的區域（region，設置資料中心的地理範圍）中，由電源、冷卻與網路彼此獨立的1座以上資料中心組成的集合。可用區域之間以低延遲的線路相連，因此把伺服器與資料的複本分散放在多個可用區域，即使1個可用區域發生故障（停電或設備故障等）也能繼續提供服務。影響整個地區的災害，則以複製到另一個區域（region）來防範。可用區域之間的通訊也有延遲，有時也會收費。

日文名稱: アベイラビリティゾーン

「可用區域」出現在1領域的2道練習題中（雲端與容器基礎等）。

這個名詞所屬的領域: 雲端與容器基礎

練習可用區域的題目

在雲端中，把 Web 伺服器與資料庫的複本分散放在同一區域（region）內的多個可用區域的主要目的，下列何者適當？

  1. A即使發生1座資料中心規模的故障（停電或冷卻故障等），也能在其他區域繼續提供服務
  2. B從靠近使用者的地點回應以減少通訊延遲，因此把伺服器分散放在世界各地
  3. C可用區域之間的通訊沒有延遲也不收費，因此比放在單一可用區域處理更快、更便宜
查看答案與解析

正確答案：A. 即使發生1座資料中心規模的故障（停電或冷卻故障等），也能在其他區域繼續提供服務

區域（region）是雲端業者設置資料中心的地理範圍，其中的可用區域，是電源、冷卻與網路彼此獨立的1座以上資料中心的集合。可用區域之間以低延遲的線路相連，因此把伺服器與資料複本分散放在多個可用區域，即使1個可用區域停止，也能以其餘的繼續提供服務。若要防範影響整個地區的災害，還要在另一個區域（region）放置複本。可用區域之間的通訊也有延遲，有時也會收費，因此要與資料複製的方式一起設計。

解析中的「可用區域」

  • 區域（region）是雲端業者設置資料中心的地理範圍，其中的可用區域，是電源、冷卻與網路彼此獨立的1座以上資料中心的集合。
