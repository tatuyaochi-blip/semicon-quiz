什麼是FZ法(浮動區熔法)

加熱使多晶矽棒的一部分熔融，並移動該熔融區帶而形成單晶的方法。由於不使用坩堝，氧含量低，適合高電阻率晶圓。

日文名稱: FZ法(フローティングゾーン法)

「FZ法(浮動區熔法)」出現在1領域的1道練習題中（矽晶圓等）。

這個名詞所屬的領域: 矽晶圓

以FZ法製作單晶的步驟

FZ法（浮動區熔法）是將高純度多晶矽棒垂直固定，以高頻感應線圈加熱其中一部分，使其熔成狹窄的帶狀。在棒的一端接上晶種後，讓線圈與棒相對緩慢移動，熔化的區帶（熔融區）便沿著棒前進，並在其後方凝固成與晶種同方向的單晶。熔融區靠表面張力保持在上下的固體之間，不接觸坩堝或任何容器。名稱中的「浮動」，就是指熔融區彷彿浮在空中的這種狀態。

氧含量低、純度高的原因

在CZ法中，從石英坩堝溶出的氧會以約10¹⁷～10¹⁸ cm⁻³進入晶體，而FZ法不使用坩堝，氧的混入少了好幾個數量級。此外，多數雜質的偏析係數小於1，比起凝固的晶體更容易留在熔融區，因此會隨熔融區移動而被帶往棒的末端（與區域精煉相同的原理）。如此可得到高純度、高電阻率的晶體，電阻率也可超過1000 Ω·cm。摻質則以在熔融區周圍通入原料氣體的方法，或以中子照射加入。

用於功率元件與偵測器的原因

FZ矽用於IGBT、閘流體、高耐壓二極體等功率元件，以及輻射偵測器。要得到高耐壓，需要厚且雜質少的漂移層，電阻率高且均勻的晶圓較為合適。氧含量少，也能避免熱處理時產生的氧相關熱施體造成電阻率變化。特別需要均勻性時，會使用照射中子、把部分Si-30轉變為磷的中子照射摻雜（NTD），將電阻率的變異壓在數%以下。

與CZ法的差異及限制

FZ法的弱點是大口徑化與量產性。熔融區只靠表面張力支撐，直徑越大越困難，上限約為200 mm。原料需要沒有裂痕且均質的多晶矽棒，成本也較高。此外，由於沒有氧固定差排的效果，FZ晶圓比CZ晶圓更容易在熱處理中發生晶格滑移或翹曲。因此，大口徑且要經過許多高溫製程的LSI使用CZ晶圓，FZ晶圓則限定用在高電阻率或高純度決定性能的用途。

FZ法是以高頻感應加熱將多晶矽棒的一部分熔成帶狀，再移動該熔融區使其單晶化的方法。由於不使用坩堝，氧的混入少，雜質也會集中到熔融區而被去除，因此可得到高純度、電阻率達1000 Ω·cm以上的晶體。它用於高耐壓的功率元件(IGBT等)與偵測器，但大口徑化以CZ法較為容易，FZ法的上限約為200 mm左右。

常見問題

FZ法與CZ法有什麼不同？

CZ法是從石英坩堝中熔化的矽拉出晶體，可大口徑化到300 mm，供應LSI用晶圓的大部分。FZ法不使用坩堝，而是熔化多晶矽棒的一部分並使其移動，可得到氧含量極低、高電阻率的晶體，但口徑只到約200 mm。

為什麼功率元件使用FZ矽？

高耐壓功率元件需要厚且雜質少的漂移層，而FZ晶圓電阻率高、均勻且氧含量少，正適合這種需求。若與中子照射摻雜搭配，電阻率還能更加均勻。

什麼是中子照射摻雜（NTD）？

這是以核反應爐的中子照射矽的摻雜方法：約占3%的同位素Si-30吸收中子成為Si-31，再以約2.6小時的半衰期進行β衰變而變成磷。由於中子能均勻到達整個晶體，可得到非常均勻的n型矽。
