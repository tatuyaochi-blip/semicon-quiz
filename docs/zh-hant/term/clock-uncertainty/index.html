什麼是時脈不確定性

作為抖動及尚未確定之時脈偏斜的預估，從時序分析可用時間中扣除的餘裕。在 SDC 中以 set_clock_uncertainty 指定，在時脈樹建立前的階段會連同偏斜部分設定得較大。

日文名稱: クロックの不確かさ

「時脈不確定性」出現在2領域的4道練習題中（時序分析與CDC, LSI設計流程與EDA等）。

這個名詞所屬的領域: 時序分析與CDC

如何納入時序檢查

在靜態時序分析中，時脈不確定性是由使用者指定的餘裕，使建立時間與保持時間檢查更加嚴格。對建立時間而言，它會從擷取邊緣之前的可用時間中扣除：週期 1.25 ns、建立時間 0.05 ns、不確定性 0.05 ns 時，資料必須在 1.15 ns 之前抵達。對保持時間而言，它會加到保持要求上，因此資料在邊緣之後必須維持穩定更久。它在 SDC（Synopsys Design Constraints）中以 set_clock_uncertainty -setup 0.05 [get_clocks clk] 等指令指定，並另外指定 -hold 的值。

餘裕涵蓋哪些內容

通常會納入三項要素。來自鎖相迴路（PLL）與時脈分配的抖動，會使邊緣在每個週期提早或延遲抵達。在時脈樹合成（CTS）之前，時脈是理想的，正反器之間的偏斜未知，因此會加入其估計值。許多團隊還會為該階段未精確建模的效應（例如電源雜訊）加上設計餘裕。週期抖動對跨越兩個不同邊緣的建立時間有影響，但對發射與擷取使用同一邊緣的保持時間則幾乎互相抵消；偏斜估計值則兩者都適用。

數值在流程中如何變化

在使用理想時脈的合成與擺置階段，不確定性會設得相對較大，以涵蓋抖動加上預期的偏斜。CTS 之後，時脈變為傳播時脈：工具會計算每個正反器實際的時脈延遲，因此偏斜會被明確分析，並從不確定性中移除，只留下抖動與餘裕。也可以使用 -from 與 -to 選項，在特定的時脈對之間設定不確定性，例如由不同 PLL 輸出產生的相關時脈之間的路徑。數值太大會過度約束設計，增加面積與功耗；太小則有在矽晶片上失效的風險。

不確定性與偏斜及降額的差異

偏斜是計算出來的兩個正反器時脈抵達時間差，只有在時脈樹存在後才能得知。時脈不確定性則不是計算出來的，而是套用在該時脈每條路徑上的假設性整體餘裕。晶片上變異（OCV）降額又是另一回事：它以係數縮放元件與導線延遲，使發射路徑變慢、擷取路徑變快（或反之），而不是扣除固定的時間。完整的簽核設定通常會結合傳播偏斜、降額以及少量剩餘的不確定性。

練習時脈不確定性的題目

在正反器之間的路徑上，時脈→輸出延遲為 0.15 ns，組合電路的最大延遲為 2.2 ns，建立時間為 0.15 ns。忽略時脈偏移與時脈不確定性時，此路徑可運作的最大時脈頻率是多少？

  1. A約 425 MHz
  2. B約 455 MHz
  3. C400 MHz
查看答案與解析

正確答案：C. 400 MHz

最小時脈週期為時脈→輸出延遲、組合電路延遲與建立時間的總和。0.15 + 2.2 + 0.15 = 2.5 ns，因此最大頻率為 1 ÷ 2.5 ns = 400 MHz。約 425 MHz 是由忘了計入建立時間的 2.35 ns 算出的值，約 455 MHz 是只由組合電路延遲 2.2 ns 算出的值。整顆晶片的最大頻率，由這類路徑中最嚴苛的關鍵路徑決定。

在時脈週期 1.25 ns（800 MHz）的路徑上，時脈→輸出延遲與組合電路延遲的總和為 1.05 ns，建立時間為 0.05 ns，建立時間用的時脈不確定性設定為 0.05 ns。建立時間的餘裕是多少？

  1. A0.15 ns
  2. B0.20 ns
  3. C0.10 ns
查看答案與解析

正確答案：C. 0.10 ns

時脈不確定性是作為抖動或尚未確定之時脈偏移的預估，從可用時間中扣除的裕度。要求時間為 1.25 − 0.05（不確定性）− 0.05（建立時間）= 1.15 ns，到達時間為 1.05 ns，因此餘裕為 0.10 ns。0.15 ns 是忘了減去不確定性的值，0.20 ns 是建立時間與不確定性都沒有減去的值。在佈局繞線之前還沒有時脈樹，因此一般會把時脈偏移的部分也納入不確定性，設定得大一些。

常見問題

時脈不確定性也適用於保持時間檢查嗎？

是的，但它是以 set_clock_uncertainty -hold 另外設定，且通常較小，因為發射與擷取共用同一邊緣時，週期抖動大多會互相抵消。在 CTS 之前，它仍包含預期的偏斜。

為什麼時脈樹合成後要降低時脈不確定性？

時脈樹一旦存在，工具便會根據時脈樹的延遲計算實際的時脈偏斜，因此餘裕中用來估計偏斜的部分就不再需要。只剩下抖動與設計餘裕。

如何在考慮時脈不確定性的情況下計算建立時間餘裕（slack）？

要求時間等於時脈週期減去建立時間再減去不確定性（並依時脈延遲調整），餘裕則是要求時間減去資料抵達時間。例如，要求時間 1.25 − 0.05 − 0.05 = 1.15 ns，抵達時間 1.05 ns，餘裕為 0.10 ns。
