什麼是非阻塞快取

在處理快取失誤的期間，仍可接受並處理其他存取的快取。可同時處理多個失誤，將記憶體的等待時間重疊隱藏起來。

日文名稱: ノンブロッキングキャッシュ

這個名詞所屬的領域: 記憶體階層與效能

練習非阻塞快取的題目

非阻塞式快取（在處理未命中的期間仍接受其他存取的快取）的主要優點為下列何者？

  1. A可比阻塞式減少快取未命中本身的次數
  2. B可更快地從主記憶體讀取未命中的資料
  3. C可讓多個未命中的等待時間重疊，期間也能處理命中
查看答案與解析

正確答案：C. 可讓多個未命中的等待時間重疊，期間也能處理命中

在阻塞式快取中，在一個未命中處理完成之前，後續的所有存取都得等待。非阻塞式快取具備記錄未命中資訊的專用暫存器（MSHR），處理期間仍可回應命中的存取，也能同時向主記憶體發出另一個未命中的請求。藉此可讓等待時間重疊而隱藏，但未命中的次數本身並不會減少，一次未命中從主記憶體讀取的時間也不變。與亂序執行（out-of-order execution）搭配時更能發揮效果。

解析中的「非阻塞快取」

  • 非阻塞式快取具備記錄未命中資訊的專用暫存器（MSHR），處理期間仍可回應命中的存取，也能同時向主記憶體發出另一個未命中的請求。
