什麼是互資訊

表示兩個隨機變數X與Y彼此帶有多少關於對方之資訊的量。I(X;Y) = H(X) − H(X|Y) = H(X) + H(Y) − H(X, Y)，相當於得知Y後X的不確定性（熵）平均減少多少。值在0以上，X與Y彼此獨立時為0。把X與Y對調也是相同的值。若通道的輸入為X、輸出為Y，它表示每次傳輸所傳達的資訊量，而改變輸入機率分布時的最大值就是通道容量。

日文名稱: 相互情報量

「互資訊」出現在1領域的3道練習題中（資訊理論與編碼基礎等）。

練習互資訊的題目

關於兩個隨機變數X、Y的條件熵 H(X|Y) 與互資訊 I(X;Y)，下列說明何者正確？

  1. A得知Y的值後，表示X之不確定性的 H(X|Y)，平均而言有時會比 H(X) 大
  2. B互資訊 I(X;Y) 在X與Y彼此獨立時最大，其值為 H(X) + H(Y)
  3. CI(X;Y) = H(X) − H(X|Y) 是得知Y後X之不確定性減少的量，若兩者獨立則為0
查看答案與解析

正確答案：C. I(X;Y) = H(X) − H(X|Y) 是得知Y後X之不確定性減少的量，若兩者獨立則為0

H(X|Y) 是得知Y的值後仍殘留之X的不確定性的平均；得知Y不會使平均的不確定性增加，因此 H(X|Y) ≤ H(X)。減少的量就是互資訊 I(X;Y) = H(X) − H(X|Y) = H(X) + H(Y) − H(X, Y)，若X與Y彼此獨立，從Y得不到任何關於X的訊息，因此為0。在通訊中，若X為送出的符號、Y為收到的符號，I(X;Y) 就相當於每次傳輸實際傳達的資訊量。

兩個隨機變數X（值為0或1）與Y（值為a、b、c之一）的聯合機率為 P(0, a) = P(0, b) = P(1, b) = P(1, c) = 1/4，其他組合的機率為0。互資訊 I(X;Y) 為下列何者？

  1. A0.5位元
  2. B1位元
  3. C1.5位元
查看答案與解析

正確答案：A. 0.5位元

X為0與1各1/2，因此 H(X) = 1 位元；Y為a 1/4、b 1/2、c 1/4，因此 H(Y) = 1.5 位元。4組各為1/4，因此 H(X, Y) = 2 位元，I(X;Y) = H(X) + H(Y) − H(X, Y) = 1 + 1.5 − 2 = 0.5 位元。若Y為a或c就能知道X的值，若為b則無法得知，因此可從Y得到關於X的一部分資訊。
