什麼是能隙

價電帶頂端與導電帶底端之間的能量差。矽在室溫下約為 1.12 eV。能隙越大，越耐高溫與高電壓。

日文名稱: バンドギャップ

「能隙」出現在15領域的66道練習題中（半導體物性, 化合物半導體, PN接面與二極體等）。

這個名詞所屬的領域: 半導體物性

能隙決定了什麼

能隙 Eg 決定半導體吸收或發射哪些波長的光，關係式為 λ (nm) ≈ 1240 / Eg (eV)：能隙約 1.12 eV 的矽可吸收到約 1.1 µm，約 0.66 eV 的鍺可達約 1.9 µm，而 1.42 eV 的 GaAs 則在約 870 nm 附近發光。能隙也決定本質載子濃度 ni ∝ T^(3/2)·exp(−Eg/2kT)，室溫下矽約為 1×10^10 cm^-3，鍺約為 2×10^13，GaAs 約為 2×10^6。ni 越小，接面漏電流越低，也越能以輕摻雜控制導電度。能隙本身會隨溫度略為縮小，矽約為 0.3 meV/K。

直接能隙與間接能隙

在 GaAs 或 InGaN 等直接能隙半導體中，導電帶最低點與價電帶最高點位於相同的晶體動量，因此電子與電洞能有效率地以發射光子的方式復合。矽屬於間接能隙，輻射復合還需要聲子參與，因此效率很低；復合主要是經由深能階缺陷進行（Shockley-Read-Hall 復合）。這就是 LED 與雷射採用化合物半導體的原因：藍光用 InGaN，提高銦含量則可得到綠光；紅光用能隙約 1.9–2.0 eV 的 AlGaInP；深紫外光則用 AlGaN。

功率元件用的寬能隙材料

能隙約 3 eV 以上的寬能隙半導體，由於熱激發的載子很少，能承受高電場與高溫。4H-SiC（約 3.26 eV）與 GaN（約 3.4 eV）的崩潰電場約為矽的十倍，因此在相同耐壓下，SiC 漂移層的厚度可縮減至約十分之一，摻雜濃度則可提高約 100 倍，大幅降低導通電阻。超寬能隙的 Ga2O3（約 4.5–4.9 eV）與鑽石（約 5.5 eV）更進一步。絕緣體的能隙更大：SiO2 約 9 eV，HfO2 約 5.8 eV。

能隙工程

合金可連續調整 Eg：AlGaAs 可從 1.42 eV 往上調整，同時與 GaAs 保持晶格匹配；成長在 InP 上的 In0.53Ga0.47As 能隙約 0.75 eV，用於 1.55 µm 光偵測器；HgCdTe 則涵蓋近 0 到 1.5 eV，用於紅外線偵測器。HBT 的窄能隙 SiGe 基極等異質接面，正是利用能隙差。極重摻雜會使表觀能隙變窄，而厚度僅數奈米的鰭片或奈米片中的量子侷限效應則會使能隙變寬。能隙也決定了單接面太陽能電池約 33% 的 Shockley-Queisser 極限；能隙基準電路（bandgap reference）輸出約 1.2 V，接近矽外推至 0 K 時的能隙。

練習能隙的題目

下列何者最接近室溫下矽（Si）的能隙？

  1. A約0.66 eV
  2. B約1.12 eV
  3. C約3.4 eV
查看答案與解析

正確答案：B. 約1.12 eV

矽的能隙在室溫下約為1.12 eV，可吸收的光波長上限約為1.1 µm（1240÷1.12）。約0.66 eV是鍺，因能隙較小，高溫時漏電流容易增加；約3.4 eV是GaN，為適合高耐壓、高溫操作及藍光LED的寬能隙半導體。矽介於兩者之間，再加上能製作出良好的熱氧化膜（SiO2），因而成為LSI的主角。

關於矽中磷所形成的施體能階在能隙內的位置，下列何者正確？

  1. A非常靠近導帶底端（低於導帶約0.045 eV）
  2. B非常靠近價電帶頂端
  3. C大致位於能隙中央
查看答案與解析

正確答案：A. 非常靠近導帶底端（低於導帶約0.045 eV）

磷的施體能階距導帶底端僅約0.045 eV，非常淺，即使是室溫的熱能（約0.026 eV），幾乎全部都會離子化而供應電子。砷約為0.054 eV，硼的受體能階距價電帶約0.045 eV。淺能階因母體介電常數而使束縛減弱，因此可用氫原子模型估算。能隙中央附近的深能階則來自金等雜質，會成為複合中心。

常見問題

能隙是什麼？簡單解釋

能隙是讓電子脫離鍵結、成為可導電狀態所需的最小能量，等於價電帶頂端與導電帶底端之間的能量差。金屬在費米能階處沒有能隙，半導體的能隙適中，絕緣體的能隙則非常大。

能隙如何換算成波長？

使用 λ (nm) ≈ 1240 / Eg (eV)。以矽的 1.12 eV 計算約為 1.1 µm，這是矽能有效吸收的最長波長。

直接能隙與間接能隙有什麼差別？

直接能隙的能帶邊緣在晶體動量上對齊，電子與電洞能有效率地復合並發光，例如 GaAs。間接能隙（如矽）還需要聲子參與，因此發光很弱。
