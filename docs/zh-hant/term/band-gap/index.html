什麼是能隙

價電帶頂端與導電帶底端之間的能量差。矽在室溫下約為 1.12 eV。能隙越大，越耐高溫與高電壓。

日文名稱: バンドギャップ

「能隙」出現在8領域的31道練習題中（化合物半導體, 影像感測器與光電元件, 雙載子電晶體等）。

這個名詞所屬的領域: 半導體物性

練習能隙的題目

能隙約1.42 eV的GaAs所發出的光，其大約的波長是下列何者？

  1. A約450 nm（藍色）
  2. B約870 nm（近紅外線）
  3. C約10 µm（遠紅外線）
查看答案與解析

正確答案：B. 約870 nm（近紅外線）

波長為 λ(nm) ≈ 1240/Eg(eV)，1240/1.42 ≈ 873 nm，是肉眼看不見的近紅外光。GaAs系的LED用於電視遙控器與光電感測器，GaAs/AlGaAs的VCSEL在850 nm附近，用於智慧型手機的臉部辨識與短距離光通訊。要發出可見光（約400～700 nm），需要像GaAsP或AlGaInP這類能隙較大的材料。

關於堆疊多層能隙相異的化合物半導體層所構成的多接面太陽能電池，下列特徵何者正確？

  1. A能有效率地利用太陽光的廣泛波長，轉換效率高
  2. B材料費最便宜
  3. C在照不到光的地方也能發電
查看答案與解析

正確答案：A. 能有效率地利用太陽光的廣泛波長，轉換效率高

單一材料無法吸收能量小於能隙的光，而能量大於能隙的光其多餘部分會變成熱。多接面太陽能電池如InGaP/GaAs/Ge的三接面，將能隙相異的層由上而下依能隙由大到小堆疊，各層吸收其擅長的波長，因此可得到超過40%的高轉換效率。由於價格昂貴，用於人造衛星以及以透鏡聚光的聚光型發電等。
