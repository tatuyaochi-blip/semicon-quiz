什麼是DMA(直接記憶體存取)

不經過 CPU，直接在周邊裝置與記憶體之間傳輸資料的機制。即使在大量資料傳輸期間，CPU 也能進行其他處理。

日文名稱: DMA(ダイレクトメモリアクセス)

「DMA(直接記憶體存取)」出現在7領域的11道練習題中（作業系統與硬體, CPU與架構, 介面與匯流排規格等）。

這個名詞所屬的領域: CPU與架構

DMA傳輸的運作方式

在程式控制I/O（programmed I/O）中，CPU以載入與儲存指令親自搬移每一個字組。使用直接記憶體存取（DMA）時，CPU則改為設定DMA控制器（或裝置本身的DMA引擎）的來源、目的地、長度與觸發條件，然後回頭處理其他工作。控制器取得匯流排控制權、搬移資料，並發出完成中斷。例如在微控制器中，可由計時器以固定間隔觸發ADC轉換，再由DMA將每次的結果存入陣列，只在緩衝區填滿時才喚醒CPU。

高速裝置中的描述符環

網路卡與NVMe SSD使用描述符環（descriptor ring）：這是位於主記憶體中的環狀表格，每個項目記載一個緩衝區的位址與長度。CPU填寫空閒的描述符，再寫入一次裝置暫存器（通常稱為門鈴），告知已寫到哪裡。裝置以DMA讀取描述符，自行執行傳輸，並將完成的項目標記為已完成。因此CPU與裝置不必互相等待，就能推進大量傳輸，而且分散於各處的緩衝區清單也能以一次操作處理，稱為分散-聚集（scatter-gather）。

快取與鎖定記憶體

DMA會繞過CPU快取，因此兩者看到的記憶體內容可能不一致。在硬體不維持一致性的系統中，驅動程式必須在裝置讀取緩衝區前，將髒快取線（dirty cache line）寫回記憶體；並在CPU讀取裝置寫入的資料前，使該範圍的快取失效，以免使用過時的數值。作業系統也可能隨時搬移或置換出一般的分頁，因此DMA用的緩衝區會被鎖定（pin）在原位；鎖定的主機記憶體讓GPU不必經過中間複製就能傳輸資料，並讓傳輸與運算重疊進行。

以IOMMU保護記憶體

由於DMA直接寫入記憶體，有缺陷或惡意的裝置可能覆寫核心資料或讀取加密金鑰，對於透過高速外接埠連接的裝置尤其令人擔憂。IOMMU（輸入輸出記憶體管理單元）為裝置所做的事，就如同MMU為CPU所做的：將裝置使用的位址轉譯為實體位址，並阻擋作業系統授權範圍以外的存取。它也能讓分散的實體分頁在裝置看來是連續的，並使將裝置直接指派給虛擬機器變得安全。

練習DMA(直接記憶體存取)的題目

下列關於網路卡或NVMe SSD等廣泛使用的、利用記憶體上描述子（descriptor）環（ring）的DMA機制，何者正確？

  1. ACPU將資料逐位元組寫入裝置的暫存器來傳輸
  2. BCPU只需將傳輸的位址與長度寫入描述子並通知裝置，裝置會自行讀取描述子並推進傳輸
  3. C描述子只存在於裝置內部，CPU看不到
查看答案與解析

正確答案：B. CPU只需將傳輸的位址與長度寫入描述子並通知裝置，裝置會自行讀取描述子並推進傳輸

描述子環是將排列在主記憶體上、寫著「從哪個位址傳送多少位元組」的表格，像環一樣循環使用的機制。CPU將傳輸內容寫入空閒的描述子，再向裝置的暫存器通知一次「已寫到這裡」。裝置以DMA讀取描述子、傳輸資料，並在完成的描述子上標記完成。CPU與裝置不必互相等待，即可推進許多傳輸。

在微控制器以固定間隔大量擷取ADC轉換結果時，使用DMA的優點，下列何者正確？

  1. AADC的解析度會自動提高
  2. B輸入電壓會自動變大
  3. C不需要每次轉換完成都由CPU以中斷讀取，DMA會將結果排列到記憶體，減輕CPU的負擔
查看答案與解析

正確答案：C. 不需要每次轉換完成都由CPU以中斷讀取，DMA會將結果排列到記憶體，減輕CPU的負擔

若每次轉換都以中斷由CPU讀取結果，在每秒數萬次的擷取下，光是中斷的負擔就會佔用CPU的大量時間。使用DMA的話，每次轉換完成，DMA會依序把結果寫入記憶體中的陣列，只有在陣列填滿時才通知CPU。若再搭配以計時器啟動轉換的設定，就能不靠CPU而持續以準確的間隔擷取。

常見問題

DMA是什麼的縮寫？

DMA是direct memory access（直接記憶體存取）的縮寫，這種機制讓周邊裝置不需由CPU逐字複製，就能與主記憶體互相傳輸資料，CPU因此可在傳輸期間處理其他工作。

DMA和程式控制I/O有什麼不同？

在程式控制I/O中，CPU親自向裝置讀寫每一個資料字組。使用DMA時，CPU只需設定傳輸，並在傳輸完成時收到通知，對於大量或頻繁的傳輸可節省CPU時間。

為什麼DMA將資料傳入記憶體後必須使快取失效？

在沒有硬體快取一致性的系統中，CPU快取可能仍保有該記憶體範圍的舊副本。使其失效可強制CPU讀取裝置所寫入的新資料。
