什麼是DMA(直接記憶體存取)

不經過 CPU，直接在周邊裝置與記憶體之間傳輸資料的機制。即使在大量資料傳輸期間，CPU 也能進行其他處理。

日文名稱: DMA(ダイレクトメモリアクセス)

「DMA(直接記憶體存取)」出現在1領域的2道練習題中（CPU與架構等）。

這個名詞所屬的領域: CPU與架構

練習DMA(直接記憶體存取)的題目

不經由 CPU，直接在周邊裝置與記憶體之間傳輸資料的機制是下列何者？

  1. ATLB
  2. BSIMD
  3. CDMA（直接記憶體存取）
查看答案與解析

正確答案：C. DMA（直接記憶體存取）

在 DMA 中，由專用控制器在記憶體與周邊裝置之間傳輸資料，CPU 只需啟動傳輸並接收完成通知（中斷），期間可繼續進行其他處理。它用於儲存裝置、網路、音訊、ADC 的資料擷取等處理大量資料的場合。必須留意 CPU 快取與傳輸資料之間的一致性，並由硬體或作業系統加以管理。

在快取的寫入方式中，關於寫回（write-back）方式的說明，下列何者正確？

  1. A不寫入快取，只更新主記憶體
  2. B每次寫入時，一定同時更新快取與主記憶體兩者
  3. C先只更新快取，待該資料從快取被逐出時，再寫回主記憶體
查看答案與解析

正確答案：C. 先只更新快取，待該資料從快取被逐出時，再寫回主記憶體

在寫回方式中，寫入只對快取進行，已更新（dirty）的快取列被逐出時，才一併寫回主記憶體。對相同位置的多次寫入，只需一次寫回即可完成，因此對主記憶體的通訊量大幅減少，許多 CPU 的 L1〜L3 都採用此方式。其代價是主記憶體與快取的內容會暫時不一致，因此需要管理一致性與 DMA 之間的一致性。
