什麼是有效質量

將晶體中的電子或電洞視為對外力自由的粒子時所使用的表觀質量。由能帶的彎曲程度決定，越小，遷移率越容易變高。

日文名稱: 有効質量

「有效質量」出現在4領域的9道練習題中（半導體物性, 化合物半導體, 先進電晶體（FinFET與GAA）等）。

這個名詞所屬的領域: 半導體物性

有效質量從何而來

晶體中的電子在原子的週期性位能中移動，因此它對外加力的反應與自由電子不同。能帶理論將這種效應納入能量－波向量關係 E(k) 中。在能帶邊緣附近，E 大致呈拋物線，E ≈ ħ²k²/2m*，有效質量則由曲率定義：m* = ħ² / (d²E/dk²)。彎曲劇烈的能帶對應輕的載子，平坦的能帶則對應重的載子。電子實際的靜止質量並沒有改變；m* 只是讓牛頓定律 F = m*a 能在晶體內成立的參數。

有效質量與遷移率

遷移率大致為 μ = qτ/m*，其中 τ 是兩次散射之間的平均時間，因此較輕的載子在碰撞之間能加速得更多。在室溫下的低摻雜矽中，電子遷移率約為 1400 cm²/V·s，電洞遷移率約為 450 cm²/V·s，主要原因就是電洞較重。這也是為什麼 CMOS 的 pMOS 通常畫成搭配的 nMOS 寬度的 2–3 倍，以匹配驅動電流。GaAs 的電子 m* 約為自由電子質量的 0.067 倍，遷移率可達約 8500 cm²/V·s，適合高頻放大器。

電洞、能谷與方向依存性

在價帶頂附近，曲率為負，因此那裡的電子會具有負的有效質量；將缺少的電子視為帶正電荷、具正質量的電洞，就能恢復直觀的行為，霍爾電壓的正負號也證實了這一點。有效質量也可能與方向有關。矽的導帶有六個等價能谷，每個能谷都有約 0.9–1.0 m0 的重縱向質量與約 0.19 m0 的輕橫向質量。在 GaAs 中，強電場可把電子推入能量較高、較重的 L 能谷，這就是耿氏二極體背後的電子轉移效應。

以應變調控有效質量

由於有效質量來自能帶結構，改變晶格就會改變有效質量。矽中的拉伸應變（例如在鬆弛的 SiGe 上成長的薄層）會使六個導帶能谷分裂，讓電子集中到在傳輸方向上呈現輕橫向質量的能谷，同時能谷間散射減少；電子遷移率可提高約 1.5–2 倍。對 pMOS 而言，嵌入式 SiGe 源極／汲極區產生的壓縮應變可讓電洞變輕。SiGe 與鍺通道之所以受到重視，是因為其電洞有效質量本來就比矽低。

練習有效質量的題目

關於矽中電子與電洞遷移率的比較，下列何者正確？

  1. A電子的遷移率較大
  2. B電洞的遷移率較大
  3. C兩者永遠相等
查看答案與解析

正確答案：A. 電子的遷移率較大

在矽中，室溫、低雜質濃度下電子的遷移率約為1400 cm²/V·s，電洞約為450 cm²/V·s，電子約大3倍，主要原因是電洞的有效質量較大。因此在相同尺寸下，nMOS能通過較大的電流，CMOS中基本做法是將pMOS的閘極寬度設為nMOS的2～3倍，以使驅動能力相當。先進製程則利用SiGe造成的壓縮應變來提高pMOS的遷移率。

為了從對外力的響應，將晶體中電子的運動當作自由電子來處理，所引入的質量稱為什麼？

  1. A靜止質量
  2. B原子量
  3. C有效質量
查看答案與解析

正確答案：C. 有效質量

晶體中的電子受到原子週期性電位的影響，對外力的反應方式與真空中的電子不同。將這些影響整合起來，當作具有另一種質量的粒子來處理，就是有效質量，由能帶的曲率決定（彎曲越陡，質量越輕）。有效質量越小，遷移率越大，GaAs的電子（約為自由電子的0.067倍）比矽更快即是這個緣故。電洞遷移率低也是因為有效質量較大。

常見問題

有效質量是電子真正的質量嗎？

不是。電子的靜止質量並沒有改變；有效質量是由能帶曲率推導出的參數，讓你能對晶體週期性位能中的載子套用 F = ma。

為什麼矽中電洞的遷移率比電子低？

矽中電洞的有效質量比導帶電子大，因此在相同電場下，兩次散射之間的加速較少。結果是室溫下遷移率約相差三倍。

有效質量可以是負的嗎？

可以。在能帶頂附近曲率為負，因此那裡的電子會具有負的有效質量。物理學家改以具正質量、帶正電荷的電洞來描述這些狀態。
