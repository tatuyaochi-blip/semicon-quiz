什麼是組相聯快取

資料可放在由位址決定的某一組內的多個位置(路)中任一處的快取結構。n路的話，每次存取要並行比對n個標籤。

日文名稱: セットアソシアティブ方式

「組相聯快取」出現在1領域的1道練習題中（記憶體階層與效能等）。

這個名詞所屬的領域: 記憶體階層與效能

練習組相聯快取的題目

在8路組相聯快取中，每次存取時平行比較的標籤數量為多少？

  1. A與快取整體的行數相同的數量
  2. B8個
  3. C1個
查看答案與解析

正確答案：B. 8個

在組相聯方式中，先以位址的索引選出一個組，再平行比較該組中所有路的標籤。8路時一組有8條快取行，所以比較的標籤為8個，所需的比較器也是8個。比較快取整體行數的標籤是全相聯方式，只比較1個的是直接映射方式。增加路數會使比較器與耗電量增加，因此L1的相聯度往往會保守一些。

出現「組相聯快取」的題目（1題）

  1. 在8路組相聯快取中，每次存取時平行比較的標籤數量為多少？

出現這個名詞的比較

  • 直接映射、組相聯、全相聯的差異：快取架構比較以區塊可放置的位置、標籤比較、速度、成本、衝突未命中與用途等面向，用表格比較直接映射、組相聯、全相聯的快取。

半導體計算工具

快取位址分割與平均記憶體存取時間由快取容量、快取行大小與相聯度計算標籤、索引、偏移位元數及平均記憶體存取時間
