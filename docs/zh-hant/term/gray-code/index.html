什麼是格雷碼

相鄰的值之間只有 1 個位元改變的編碼。用於旋轉編碼器，以及在不同時脈之間傳遞計數值時防止讀取錯誤。

日文名稱: グレイコード

「格雷碼」出現在3領域的11道練習題中（時序分析與CDC, 邏輯電路, SRAM與快閃記憶體等）。

這個名詞所屬的領域: 邏輯電路

二進位碼與格雷碼的互相轉換

一般所說的格雷碼是反射二進位碼：先列出n位元的序列，接上它的鏡像，再在前半段加上前綴0、後半段加上前綴1。從二進位B轉換只需一個式子：G = B XOR (B >> 1)，因此除了最高位元外，每個格雷碼位元都是兩個相鄰二進位位元的XOR。反向轉換則從最高位元往下逐位做累進XOR：最高位元直接複製，每個較低的二進位位元等於前一個二進位位元XOR目前的格雷碼位元。3位元的序列為000、001、011、010、110、111、101、100。

編碼器為何需要每次只變1位元

在一般二進位中，從0111變到1000會同時翻轉4個位元。旋轉式或線性絕對型編碼器以各自的軌道讀取每個位元，而這些軌道上的轉換點永遠無法完全對齊，因此在邊界上讀取時，可能混合新舊位元，回報一個與兩個位置都相差甚遠的數值。使用格雷碼時，每一步只有一條軌道改變，在邊界上讀到的只可能是舊值或新值，誤差都在一步以內。

非同步FIFO中的格雷碼指標

非同步FIFO在兩個時脈域之間傳遞資料，兩側都必須看到對方的讀取或寫入指標，才能計算滿與空旗標。讓二進位指標直接通過同步器正反器並不安全，因為多個位元可能同時改變，並在不同的時脈邊緣被擷取，產生一個從未存在過的指標值。格雷碼指標每次遞增只改變1個位元，即使該位元在轉換途中被擷取，接收端得到的也只會是舊指標或新指標。這只有在指標每個時脈前進1、且計數器在2的冪次處循環時才成立。

快閃記憶體與卡諾圖中的格雷碼

多階儲存單元（MLC）與三階儲存單元（TLC）NAND快閃記憶體，以4個或8個臨界電壓狀態之一來儲存2或3個位元。耗損與干擾會使狀態分布變寬，而誤讀幾乎總是落在相鄰的狀態。以格雷碼順序分配位元圖樣，例如TLC採用111、110、100、101、001、000、010、011，就能把每次誤讀變成單一位元錯誤，讓錯誤更正碼以低成本處理。卡諾圖的座標軸也採用相同順序，使實體上相鄰的格子只差一個變數，因而可以合併成組。

練習格雷碼的題目

下列哪一項是格雷碼的特徵？

  1. A以4位元表示十進位數每一位數的編碼
  2. B以同位元偵測錯誤的編碼
  3. C相鄰的值之間只有1位元變化的編碼
查看答案與解析

正確答案：C. 相鄰的值之間只有1位元變化的編碼

格雷碼是相鄰的值之間必定只有1位元變化的編碼，可由二進位數B以 B XOR (B >> 1) 求得。由於不會有多個位元同時改變，在旋轉編碼器的位置偵測，或在以不同時脈動作的電路之間傳遞FIFO指標時，不會有讀到中途錯誤值的風險。卡諾圖方格的排列也是格雷碼順序。以4位元表示十進位每一位數的則是BCD。

在非同步FIFO中，將寫入指標與讀取指標轉換為格雷碼後，再同步化到對方時脈域的理由何者正確？

  1. A轉換為格雷碼後位元數減半，所需的同步器較少
  2. B每前進1步只有1個位元改變，因此即使在變化途中取入，也會是前進前或前進後的正確值
  3. C格雷碼的訊號不會成為亞穩態，因此不需要同步化
查看答案與解析

正確答案：B. 每前進1步只有1個位元改變，因此即使在變化途中取入，也會是前進前或前進後的正確值

二進位的指標會像從 0111 變為 1000 這樣同時改變多個位元，若對各位元分別同步化，可能收到完全無關的值。若使用格雷碼，1次遞增只會改變1個位元，因此即使該位元成為亞穩態，無論穩定為新值或舊值，結果都會是前進前或前進後的值。只是看到稍舊的值，FIFO並不會因此損壞。位元數不變，亞穩態本身也可能發生，因此仍需要同步器。

常見問題

二進位要如何轉換成格雷碼？

將二進位數與自身右移1位元後的結果做XOR：G = B XOR (B >> 1)。最高位元保持不變，其餘每個格雷碼位元都是兩個相鄰二進位位元的XOR。

跨時脈域時，FIFO指標為什麼要用格雷碼？

格雷碼指標每次遞增只改變1個位元，因此同步器即使在轉換途中取樣，得到的仍是舊值或新值。二進位指標可能一次改變許多位元，被擷取成完全錯誤的數值。

格雷碼和BCD有什麼不同？

格雷碼是一種二進位圖樣的排列順序，相鄰數值之間只差1個位元。BCD（二進位編碼十進位）則是以4個位元分別編碼每個十進位數字，並不具備每次只變1位元的特性。
