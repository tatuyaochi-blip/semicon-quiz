什麼是格雷碼

相鄰的值之間只有 1 個位元改變的編碼。用於旋轉編碼器，以及在不同時脈之間傳遞計數值時防止讀取錯誤。

日文名稱: グレイコード

「格雷碼」出現在2領域的3道練習題中（邏輯電路, SRAM與快閃記憶體等）。

這個名詞所屬的領域: 邏輯電路

練習格雷碼的題目

下列哪一項是格雷碼的特徵？

  1. A以4位元表示十進位數每一位數的編碼
  2. B以同位元偵測錯誤的編碼
  3. C相鄰的值之間只有1位元變化的編碼
查看答案與解析

正確答案：C. 相鄰的值之間只有1位元變化的編碼

格雷碼是相鄰的值之間必定只有1位元變化的編碼，可由二進位數B以 B XOR (B >> 1) 求得。由於不會有多個位元同時改變，在旋轉編碼器的位置偵測，或在以不同時脈動作的電路之間傳遞FIFO指標時，不會有讀到中途錯誤值的風險。卡諾圖方格的排列也是格雷碼順序。以4位元表示十進位每一位數的則是BCD。

解析中的「格雷碼」

  • 格雷碼是相鄰的值之間必定只有1位元變化的編碼，可由二進位數B以 B XOR (B >> 1) 求得。

    下列哪一項是格雷碼的特徵？

  • 卡諾圖是將真值表排列成相鄰方格的輸入僅相差1位元（格雷碼順序）的圖。

    卡諾圖的主要用途是什麼？

  • 誤讀幾乎都是發生在相鄰狀態之間，因此若以相鄰狀態的位元串只相差 1 位元的格雷碼來分配，即使誤讀，錯誤也只有 1 位元，可將 ECC 的負擔降到最低。
