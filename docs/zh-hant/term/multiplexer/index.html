什麼是多工器

依選擇訊號，從多個輸入中選出 1 個輸出的電路。也稱為選擇器。反過來將 1 個輸入分配到多個輸出之一的電路稱為解多工器。

日文名稱: マルチプレクサ

「多工器」出現在4領域的5道練習題中（硬體描述語言與驗證, 邏輯電路, MOSFET等）。

這個名詞所屬的領域: 邏輯電路

多工器的選擇方式

2:1多工器（mux）的輸出為Y = S'·A + S·B：選擇訊號S為0時輸出輸入A，S為1時輸出輸入B。具有n個選擇位元的多工器可從2ⁿ個輸入中擇一，因此8:1多工器需要3條選擇線。在CMOS中，多工器可由AND-OR或NAND-NAND邏輯、傳輸閘構成，輸入較多時則以2:1多工器組成樹狀結構。多工器也是一種萬用邏輯元件：將資料輸入依真值表接到常數，2ⁿ:1多工器就能實現任意n輸入的布林函數。

多工器的應用場合

處理器的資料路徑中充滿多工器：用來從暫存器或立即值中選擇ALU運算元、經由旁路路徑轉送結果以避免管線停頓、選擇下一個程式計數器值，以及切換共用匯流排。FPGA的邏輯區塊以查找表（LUT）實現任意函數，而查找表就是透過多工器樹讀出的小型記憶體。在可測試性設計中，掃描正反器在資料輸入端加上多工器，讓正反器在測試模式下串接成移位暫存器。在電路板上，類比多工器讓多個感測器共用一顆ADC，I2C多工器則用來隔離位址相同的元件。

HDL與邏輯合成中的多工器

在Verilog或VHDL中，條件指定、if敘述或case敘述通常會合成為多工器。冗長的if/else-if鏈隱含優先順序，會產生一連串延遲較長的2:1多工器；而對互斥值的case敘述則傾向形成單一的寬並列多工器，不過現代合成工具常會將兩種寫法都最佳化。常見的陷阱是組合邏輯中有某個分支沒有指定值，這會推論出一個保持舊值的閂鎖器，而不是單純的多工器。

多工器與解多工器、解碼器的比較

解多工器的作用與多工器相反：依選擇位元，將一個輸入導向2ⁿ個輸出中的一個。解碼器將n位元的代碼轉換為2ⁿ條one-hot線，實質上就是資料輸入固定為1的解多工器；解碼器用於驅動大型多工器的選擇邏輯與記憶體的字元線。在通訊領域中，多工更廣泛地指透過時間、頻率或編碼，讓多個訊號共用一個通道。

  2. B將輸入訊號的邏輯反相
  3. C依選擇訊號，從多個輸入中選出一個輸出
查看答案與解析

正確答案：C. 依選擇訊號，從多個輸入中選出一個輸出

多工器（選擇器）是依選擇訊號的值，從多個輸入中選出一個傳到輸出的電路，若選擇訊號為n位元，可從2ⁿ個輸入中選擇。在CPU中用於暫存器值的選擇與匯流排的切換，FPGA的邏輯區塊（LUT）也是以記憶體與多工器實現任意邏輯。將一個輸入分配到多個輸出之一的電路則是解多工器。

常見問題

8對1多工器需要幾條選擇線？

3條，因為2³ = 8。一般而言，具有2ⁿ個資料輸入的多工器需要n條選擇線。

多工器和解多工器有什麼不同？

多工器從多個輸入中選擇一個，送到單一輸出；解多工器則將單一輸入導向多個輸出中的一個。

多工器如何實現任意邏輯函數？

將選擇線接到函數的輸入變數，並依真值表將每個資料輸入接到0或1。如此多工器對每種輸入組合都會輸出正確的真值表項目，FPGA的查找表正是以這種方式運作。
