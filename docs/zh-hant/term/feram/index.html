什麼是FeRAM(鐵電記憶體)

利用鐵電體的極化方向來儲存資訊的非揮發性記憶體。寫入快速且低功耗，用於 IC 卡等。

日文名稱: FeRAM(強誘電体メモリ)

「FeRAM(鐵電記憶體)」出現在1領域的9道練習題中（新世代記憶體等）。

這個名詞所屬的領域: 新世代記憶體

練習FeRAM(鐵電記憶體)的題目

FeRAM（鐵電記憶體）利用何種性質來記憶資訊？

  1. A氧化物中導電細絲的形成與消失
  2. B磁電阻效應
  3. C鐵電體自發極化（殘留極化）的方向
查看答案與解析

正確答案：C. 鐵電體自發極化（殘留極化）的方向

FeRAM 利用即使移除電壓極化仍然留存的鐵電體性質（殘留極化），以極化的方向記憶 0 與 1。寫入只是使極化反轉，因此不需要像快閃記憶體那樣的高電壓，速度快（數十 ns）、功耗小，改寫次數也多達 10¹² 次以上。過去使用的是 PZT（鋯鈦酸鉛）。使用細絲的是 ReRAM，利用磁電阻的是 MRAM。

近年作為 FeRAM 與鐵電電晶體（FeFET）材料而受到矚目、與 CMOS 製程相容性佳的鐵電材料是下列何者？

  1. A氧化鉿（HfO2）系
  2. B氯化鈉
  3. C聚乙烯
查看答案與解析

正確答案：A. 氧化鉿（HfO2）系

氧化鉿一直是 CMOS 中用作 High-k 閘極絕緣膜的材料，2011 年前後有報告指出，添加 Si 或 Zr 而成為特定的結晶相（斜方晶）後，即使厚度只有 10 nm 左右也顯現鐵電性。以往的 PZT 含鉛，變薄後特性下降，難以與 CMOS 整合；相對地，HfO2 系可以用 ALD 沉積出薄而均勻的膜，有望將 FeRAM 與 FeFET 嵌入微細的邏輯電路。

  • 以往的 PZT 含鉛，變薄後特性下降，難以與 CMOS 整合；相對地，HfO2 系可以用 ALD 沉積出薄而均勻的膜，有望將 FeRAM 與 FeFET 嵌入微細的邏輯電路。

    近年作為 FeRAM 與鐵電電晶體（FeFET）材料而受到矚目、與 CMOS 製程相容性佳的鐵電材料是下列何者？

  • 電容型 FeRAM 對單元施加電壓，以流向位元線的電荷量判斷極化是否反轉。

    電容型 FeRAM 的讀取特徵，下列何者正確？

  • FeRAM 寫入快、所需電力小、改寫次數也多，因此用於以非接觸電波取得的微量電力運作的交通 IC 卡與電子錢包卡。

    FeRAM 一直以來使用的代表性用途，下列何者正確？

  • FeRAM 的「Fe」是 Ferroelectric（鐵電體）的縮寫，並不是指使用鐵。
