什麼是組合電路

輸出僅由當下輸入決定的邏輯電路。例如加法器、多工器、解碼器等。

日文名稱: 組み合わせ回路

「組合電路」出現在3領域的18道練習題中（硬體描述語言與驗證, 邏輯電路, 測試與檢查等）。

這個名詞所屬的領域: 邏輯電路

練習組合電路的題目

在組合電路中，輸入變化時，因各路徑延遲的差異而在輸出瞬間出現的不需要的脈衝，稱為什麼？

  1. A亞穩態
  2. B突波（危態）
  3. C閂鎖效應
查看答案與解析

正確答案：B. 突波（危態）

當相同輸入的變化經由不同的路徑到達輸出時，因延遲的差異，輸出可能瞬間出現錯誤的值，這稱為突波（危態，glitch/hazard）。在同步式電路中，只要在時脈邊緣前穩定下來，功能上就沒有問題，但多餘的充放電會使功耗增加。另一方面，若時脈、非同步重置或送往其他晶片的控制訊號上出現突波，就會造成誤動作，因此這些訊號的鐵則是直接由正反器的輸出送出。

在組合電路的always區塊中，為了防止非預期的閂鎖器而常用的寫法為何？

  1. A盡量多寫條件分支，並省略else
  2. B在區塊開頭，先對輸出的所有訊號賦予預設值，再撰寫條件分支
  3. C將輸出的訊號全部設為wire，並在always中賦值
查看答案與解析

正確答案：B. 在區塊開頭，先對輸出的所有訊號賦予預設值，再撰寫條件分支

在區塊開頭像「y = 0; valid = 0;」一樣先為輸出賦予預設值，之後的條件分支無論走哪條路徑，至少都已賦予預設值，因此不需要保持值，也就不會產生閂鎖器。這在條件眾多的狀態機輸出描述等情況特別有用。若使用SystemVerilog的always_comb，產生閂鎖器時工具會發出警告。
