什麼是組合電路

輸出僅由當下輸入決定的邏輯電路。例如加法器、多工器、解碼器等。

日文名稱: 組み合わせ回路

「組合電路」出現在4領域的29道練習題中（硬體描述語言與驗證, 時序分析與CDC, 邏輯電路等）。

這個名詞所屬的領域: 邏輯電路

練習組合電路的題目

在組合電路中，輸入變化時，因各路徑延遲的差異而在輸出瞬間出現的不需要的脈衝，稱為什麼？

  1. A亞穩態
  2. B突波（危態）
  3. C閂鎖效應
查看答案與解析

正確答案：B. 突波（危態）

當相同輸入的變化經由不同的路徑到達輸出時，因延遲的差異，輸出可能瞬間出現錯誤的值，這稱為突波（危態，glitch/hazard）。在同步式電路中，只要在時脈邊緣前穩定下來，功能上就沒有問題，但多餘的充放電會使功耗增加。另一方面，若時脈、非同步重置或送往其他晶片的控制訊號上出現突波，就會造成誤動作，因此這些訊號的鐵則是直接由正反器的輸出送出。

在時脈週期為 2.0 ns 的同步電路中，發送端正反器的時脈→輸出延遲為 0.2 ns，組合電路的延遲為 1.4 ns，接收端正反器的建立時間為 0.1 ns。若時脈偏移為0，建立時間的餘裕是多少？

  1. A0.3 ns
  2. B0.4 ns
  3. C0.5 ns
查看答案與解析

正確答案：A. 0.3 ns

建立時間的餘裕以「要求時間 − 到達時間」求得。資料的到達時間為 0.2 + 1.4 = 1.6 ns，要求時間為下一個時脈邊緣減去建立時間的 2.0 − 0.1 = 1.9 ns，因此餘裕為 1.9 − 1.6 = 0.3 ns。由於是正值，表示滿足限制。0.4 ns 是忘了減去建立時間的值，0.5 ns 是反過來加上建立時間的值。餘裕為負即為違規。

出現「組合電路」的題目（29題）

  1. 在組合電路中，輸入變化時，因各路徑延遲的差異而在輸出瞬間出現的不需要的脈衝，稱為什麼？
  2. 在時脈週期為 2.0 ns 的同步電路中，發送端正反器的時脈→輸出延遲為 0.2 ns，組合電路的延遲為 1.4 ns，接收端正反器的建立時間為 0.1 ns。若時脈偏移為0，建立時間的餘裕是多少？
  3. 在正反器之間的路徑上，時脈→輸出延遲為 0.15 ns，組合電路的最大延遲為 2.2 ns，建立時間為 0.15 ns。忽略時脈偏移與時脈不確定性時，此路徑可運作的最大時脈頻率是多少？
  4. 有一條時脈週期 1.0 ns、時脈→輸出延遲 0.1 ns、組合電路延遲 0.85 ns、建立時間 0.08 ns 的路徑。當接收端正反器的時脈比發送端晚 0.05 ns 到達時，建立時間的餘裕是多少？
  5. 發送端的時脈→輸出延遲最小為 0.08 ns，組合電路的最小延遲為 0.02 ns，接收端的保持時間為 0.05 ns。當接收端的時脈比發送端晚 0.1 ns 到達時，保持時間的餘裕是多少？
  6. 在時脈週期 1.25 ns（800 MHz）的路徑上，時脈→輸出延遲與組合電路延遲的總和為 1.05 ns，建立時間為 0.05 ns，建立時間用的時脈不確定性設定為 0.05 ns。建立時間的餘裕是多少？
  7. 在以週期 2.0 ns 的時脈運作的電路中，有一條資料到達時間（時脈→輸出延遲與組合電路延遲的總和）為 3.3 ns、建立時間為 0.1 ns 的路徑。此路徑只需每2個週期取入一次，因此將建立時間的多週期路徑設為2。建立時間的餘裕是多少？
  8. 在週期 2.0 ns、工作週期50%的時脈下，有一條在上升邊緣送出、在下降邊緣取入的路徑。若建立時間為 0.1 ns、時脈偏移為0，時脈→輸出延遲與組合電路延遲的總和容許的最大值是多少？
  9. 在週期 2.5 ns（400 MHz）的時脈下，輸出端子設定了 set_output_delay 0.8 ns。驅動輸出端子之正反器的時脈→輸出延遲為 0.2 ns 時，從正反器到輸出端子的組合電路與繞線容許的最大延遲是多少（忽略時脈的延遲）？
