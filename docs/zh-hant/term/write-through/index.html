什麼是寫穿(Write-through)

寫入快取的同時，也寫入下層(主記憶體等)的方式。下層始終保持最新，但寫入的通訊量多，因此與寫入緩衝區組合使用。

日文名稱: ライトスルー方式

「寫穿(Write-through)」出現在2領域的2道練習題中（記憶體階層與效能, SRAM與快閃記憶體等）。

這個名詞所屬的領域: 記憶體階層與效能

寫穿快取如何處理儲存

在儲存命中時，寫穿快取會更新自身的副本，同時也將寫入送往下一層，例如 L2 快取或主記憶體。因此快取行永遠不會是髒的：不需要髒位元，被逐出的快取行可以直接丟棄，因為下層已持有相同的資料。在儲存失誤時，寫穿快取通常採用非寫入配置，直接將寫入送往下層而不載入該行，因為反正之後也不需要寫回。

寫入緩衝區

若每次儲存都要等待寫入記憶體完成，CPU 會不斷停頓，因此寫入會先進入寫入緩衝區，在 CPU 繼續執行的同時於背景排入下層。只有在緩衝區滿時 CPU 才會停頓，這發生在儲存到達的速度快於記憶體可吸收的速度時。發生失誤的載入必須檢查緩衝區，或等待其清空，才不會從記憶體讀到過時的資料。緩衝區常會將對同一快取行的多筆寫入合併為一次傳輸。

寫穿與寫回的比較

寫回只更新快取，並在髒快取行被逐出時才寫入記憶體一次，因此對同一行的重複寫入會合併為一次傳輸。這可節省頻寬與功耗，這也是大多數 CPU 的 L1 至 L3 快取都採用寫回的原因。寫穿在每次儲存時都會產生通訊量，但能讓下層始終保持最新，簡化與其他核心及 DMA 之間的一致性，並使復原變得容易：採用寫穿的 L1 可用簡單的同位元保護資料，並在發生錯誤時重新擷取乾淨的副本。

使用場合

寫穿出現在由寫回 L2 支援的小型第一層快取、簡單的嵌入式處理器，以及下層必須即時看到每一次寫入的記憶體區域；許多架構允許作業系統透過記憶體類型屬性，以分頁為單位選擇此方式。它較不適合 DRAM 之前的最後一層快取，因為儲存所產生的通訊量會消耗記憶體頻寬，而寫回策略原本可以省下這些頻寬。

練習寫穿(Write-through)的題目

在直寫（write-through）快取中，設置寫入緩衝器（write buffer）的主要目的為下列何者？

  1. A讓CPU不必等待對主記憶體的寫入完成，即可進行下一個處理
  2. B讓快取中的資料保持比主記憶體更新的狀態
  3. C對寫入時未命中的快取行，一定先從主記憶體載入快取後再寫入
查看答案與解析

正確答案：A. 讓CPU不必等待對主記憶體的寫入完成，即可進行下一個處理

直寫方式每次寫入時也會寫入主記憶體，若直接等待其完成，CPU會頻繁停頓。若將寫入暫時存放在寫入緩衝器，CPU就能立刻進入下一條指令，由緩衝器在背景寫出到主記憶體。讓快取比主記憶體更新是寫回（write-back）方式的性質，在直寫中兩者反而是一致的。未命中的快取行是否要載入，是寫入配置（write-allocate）的選擇，與寫入緩衝器是不同的問題。

常見問題

寫穿快取和寫回快取有什麼不同？

寫穿在每次儲存時都寫入下層，使下層始終保持最新。寫回只寫入快取，並在被修改的快取行逐出時才更新下層一次，從而減少通訊量。

寫穿快取為什麼需要寫入緩衝區？

沒有寫入緩衝區，CPU 就必須等待每一次儲存在較慢的記憶體中完成。緩衝區會將寫入排入佇列，讓 CPU 在寫入於背景排出的同時繼續執行。

寫穿快取需要髒位元嗎？

不需要。由於每次寫入都會立即傳遞下去，快取行永遠不會與下層不同，因此逐出時不必寫回任何資料。
