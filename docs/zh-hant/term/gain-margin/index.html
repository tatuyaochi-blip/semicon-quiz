什麼是增益邊限

在迴路轉移函數的相位達到 −180° 的頻率（相位交越頻率），增益比0 dB低多少dB的量。它表示迴路增益再提高幾倍就會不穩定，例如增益邊限約9.5 dB時，把增益提高為3倍就會到達穩定極限。與相位邊限組合起來表示穩定的餘裕，伺服系統常以約10～20 dB作為參考。

日文名稱: ゲイン余裕(利得余裕)

「增益邊限」出現在1領域的3道練習題中（控制工程基礎等）。

這個名詞所屬的領域: 控制工程基礎

練習增益邊限的題目

關於由迴路轉移函數的波德圖讀取的增益邊限與相位邊限的說明，正確的是下列何者？

  1. A增益邊限是增益為0 dB的頻率處相位距 −180° 的差，相位邊限是相位為 −180° 的頻率處增益距0 dB的差
  2. B增益邊限是相位為 −180° 的頻率處增益距0 dB的差，相位邊限是增益為0 dB的頻率處相位距 −180° 的差
  3. C增益邊限與相位邊限都在閉迴路的波德圖上，於增益為 −3 dB的頻率處讀取
查看答案與解析

正確答案：B. 增益邊限是相位為 −180° 的頻率處增益距0 dB的差，相位邊限是增益為0 dB的頻率處相位距 −180° 的差

增益邊限表示在相位達到 −180° 的相位交越頻率處，增益比0 dB低多少dB。相位邊限表示在增益為0 dB的增益交越頻率處，相位距 −180° 還有多少度。兩者都是表示迴路轉移函數有多接近點 −1（增益0 dB、相位 −180°）的指標，要由迴路轉移函數而非閉迴路讀取。在伺服系統中，常以增益邊限約10～20 dB、相位邊限約40～60°作為參考。

迴路轉移函數 L(s) = 2/(s(s + 1)(s + 2)) 的增益邊限最接近下列何者？

  1. A約4.8 dB
  2. B約9.5 dB
  3. C約15.6 dB
查看答案與解析

正確答案：B. 約9.5 dB

相位為 −90° − tan⁻¹ω − tan⁻¹(ω/2)，由兩個角之和為90°的條件 ω × (ω/2) = 1，可知相位為 −180° 是在 ω = √2 rad/s 時。該處的增益為 |L(j√2)| = 2/(√2 × √3 × √6) = 1/3，因此增益邊限為 20 log₁₀3 ≈ 9.5 dB。這表示把增益提高為3倍（K = 6）就會到達極限，與用羅斯-赫維茲穩定準則求得的穩定範圍 0 < K < 6 一致。
