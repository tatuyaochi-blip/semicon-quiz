什麼是轉換頻率

共射極電流增益降到 1 的頻率，記為 fT。是電晶體高頻性能的代表性指標。

日文名稱: トランジション周波数

「轉換頻率」出現在1領域的1道練習題中（雙載子電晶體等）。

這個名詞所屬的領域: 雙載子電晶體

fT的定義與量測方式

轉換頻率fT是指輸出端交流短路時，共射極電流增益|hfe|降到1（0 dB）的頻率。電流增益在低頻時大致為定值β0，但超過β截止頻率fβ後，會與頻率成反比下降（−20 dB/dec）。在這個區域中|hfe|×f大致固定，因此fT ≈ β0·fβ，fT也可視為電流增益的增益頻寬積。實務上，一般是在低於fT的頻率f量測|hfe|，再以fT = |hfe|×f求得，或是將由S參數求出的電流增益沿−20 dB/dec的斜率外插求得。

決定fT的延遲時間

fT的倒數對應於訊號從射極傳到集極所需時間的總和，大致可寫成 1/(2πfT) ≈ (Cje + Cμ)/gm + τB + τC。第一項是對接面電容充電的時間；τB是少數載子穿越基極的時間，對於均勻摻雜、寬度為WB、擴散係數為Dn的基極，約為WB²/(2Dn)；τC是穿越集極空乏區的時間。在小訊號等效電路中可寫成 fT ≈ gm/(2π(Cπ + Cμ))，其中Cπ也包含基極的擴散電容。將基極變薄，或在SiGe HBT中讓Ge濃度呈梯度分布以加速電子，主要都是為了縮短τB。

集極電流與fT的關係

fT會隨偏壓條件大幅改變。gm與集極電流IC成正比，因此在小電流區域，電容充電時間(Cje + Cμ)/gm占主導，IC越大fT越高。但電流密度過高時，流過集極的電子電荷會抵消空乏區的電場，使有效基極向集極側擴展，發生柯克效應（基極推出），τB急遽變長，fT隨之下降。因此fT會在某個IC出現峰值。資料表上的fT是在特定的IC與VCE下規定的，若電路的工作點不同，實際的fT也會不同，這點需要注意。

與fmax的差異及MOSFET的fT

fT是電流增益的指標，幾乎不反映基極電阻rb的影響。功率增益降到1的最大振盪頻率fmax大約為 √(fT/(8π·rb·Cμ))，rb或Cμ大時會降低，因此放大器或振盪器的實際能力也要一併參考fmax來判斷。fT的定義也適用於MOSFET與HEMT，fT ≈ gm/(2π(Cgs + Cgd))。在忽略Cgd的長通道近似下，fT ≈ 3μ(VGS − Vth)/(4πL²)，與閘極長度L的平方成反比；在速度飽和明顯的短通道中則約為vsat/(2πL)，因此fT會隨微縮而提高。

練習轉換頻率的題目

關於雙極性電晶體的轉換頻率fT（transition frequency），下列意義何者正確？

  1. A電源的頻率
  2. B共射極電流增益降到1的頻率
  3. C電路振盪的頻率
查看答案與解析

正確答案：B. 共射極電流增益降到1的頻率

電流增益隨頻率升高而下降，主因是通過基極的時間以及接面電容的充放電。共射極電流增益為1的頻率就是轉換頻率fT，大約為 fT ≈ gm/(2π(Cπ + Cμ))。這是高頻性能的指標，通用小訊號電晶體約為數百MHz，SiGe HBT則有超過300 GHz者。也會一併使用功率增益為1的最大振盪頻率fmax。

常見問題

簡單來說，轉換頻率是什麼？

它是共射極電流增益降到1的頻率，可作為電晶體能放大電流之上限的參考。記為fT，也稱為截止頻率或單位增益頻率。數值越大，就能放大到越高的頻率。

fT和增益頻寬積是同一件事嗎？

在β截止頻率fβ以上，電流增益與頻率成反比下降，因此|hfe|×f大致固定，這個值就是fT。在這個意義上，fT相當於電流增益的增益頻寬積，fT ≈ β0·fβ。不過，它與運算放大器等整個電路的增益頻寬積是不同的量。

fT和fmax有什麼不同？

fT是電流增益降到1的頻率，fmax是功率增益降到1的頻率。fmax受基極電阻與集極-基極間電容的影響很大，依元件結構不同，可能比fT高，也可能比fT低。
