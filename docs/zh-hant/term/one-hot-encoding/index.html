什麼是獨熱編碼（One-hot encoding）

為狀態機的每個狀態分配一個正反器，且始終只有一個為 1 的編碼。邏輯簡單、容易較快，常用於 FPGA。

日文名稱: ワンホット符号化

獨熱狀態編碼如何運作

在有限狀態機中，獨熱編碼為每個狀態分配一個專屬的正反器，任何時刻都恰好只有一個正反器為 1。四個狀態分別為 0001、0010、0100 與 1000。要判斷狀態機是否處於某個狀態，只需看一個位元，因此取決於狀態的輸出往往只是一個正反器，或是少數幾個的小型 OR。每個正反器的次態輸入，是進入該狀態之各轉移條件的 OR，每個條件再與來源狀態的位元做 AND，如此能讓邏輯層數保持淺，使狀態機運作快速。

獨熱編碼與二進位編碼

二進位編碼為狀態編號，只需要 log2 N 無條件進位個正反器：三個狀態用兩個正反器即可，而獨熱編碼需要三個；十六個狀態則是四個正反器對十六個。二進位編碼的代價是較寬的解碼邏輯，因為辨識一個狀態需要比較所有狀態位元。第三種選擇格雷碼編碼，會讓頻繁發生的轉移只改變一個位元，以降低切換活動。二進位編碼適合正反器稀少或狀態數很多的設計；獨熱編碼則適合在正反器充裕時追求速度與簡潔。

FPGA 為何偏好它

FPGA 的邏輯區塊將每個小型查找表（LUT）與一個或多個正反器搭配，因此暫存器很充裕，而寬的邏輯函數則必須拆分到多層 LUT 上。獨熱編碼非常契合這種結構：每個狀態位元的次態函數通常只涉及少數輸入，能放進單一 LUT，從而縮短關鍵路徑。邏輯合成工具通常會偵測狀態機並自動選擇編碼，對中小型狀態機常選擇獨熱編碼，不過設計者可以覆寫這個選擇。在正反器面積成本較高的 ASIC 中，二進位或其他精簡編碼較為常見。

非法狀態與復原

使用 N 個正反器時，獨熱編碼只用到 2^N 種可能樣式中的 N 種，因此全為 0 與多個位元為 1 的樣式都是非法的。雜訊、突波或輻射引起的位元翻轉，都可能讓狀態機進入其中某個狀態，使其停滯或行為無法預測。二進位編碼的未使用編碼也有同樣的問題，例如三狀態機中的 11。因此強健的設計會定義一個預設分支，將任何非預期的狀態帶回已知狀態，而邏輯合成工具也提供安全狀態機選項，保留這段復原邏輯，而不是將其最佳化掉。

練習獨熱編碼（One-hot encoding）的題目

在狀態機的狀態編碼中，獨熱編碼（one-hot）的特徵，下列何者正確？

  1. A以二進位表示狀態，使正反器的數量最少
  2. B所有的正反器隨時都為1
  3. C使用與狀態數量相同的正反器，且永遠只有一個為1，因此下一個狀態與輸出的邏輯簡單，容易變快
查看答案與解析

正確答案：C. 使用與狀態數量相同的正反器，且永遠只有一個為1，因此下一個狀態與輸出的邏輯簡單，容易變快

在獨熱編碼中，例如4個狀態表示為0001、0010、0100、1000，每個狀態分配一個正反器。雖然正反器會增加，但只要看1個位元就知道是否處於某個狀態，所以決定下一個狀態與輸出的邏輯會變得較淺而較快。常用於正反器豐富的FPGA，想減少正反器數量時則使用二進位編碼。

在具有3個狀態的狀態機中，記憶狀態所需的正反器數量的組合，下列何者正確（二進位編碼／獨熱編碼）？

  1. A3個／2個
  2. B2個／3個
  3. C1個／3個
查看答案與解析

正確答案：B. 2個／3個

在二進位編碼中，狀態以二進位的編號表示，因此3個狀態只要00、01、10共2位元（2個正反器）就足夠。在獨熱編碼中，每個狀態使用1個正反器，所以是3個。二進位中會剩下未使用的11編碼，為了在因雜訊等原因進入該編碼時能回到正確的狀態，先以default決定去處會比較安全。

常見問題

獨熱編碼需要幾個正反器？

每個狀態一個正反器，因此具有 N 個狀態的狀態機需要 N 個正反器。同一個狀態機若採用二進位編碼，只需要 log2 N 無條件進位個。

獨熱編碼和二進位狀態編碼有什麼不同？

獨熱編碼每個狀態使用一個正反器且只有一個位元為 1，解碼邏輯簡單快速，代價是需要更多暫存器。二進位編碼以最少的正反器儲存狀態編號，但需要較寬的邏輯來解碼各個狀態。

數位設計的獨熱編碼和機器學習的 one-hot 編碼是一樣的嗎？

概念相同：以恰好只有一個元素為 1 的向量，從一個集合中識別出一個項目。在硬體中，它用來編碼狀態機的目前狀態或選擇訊號；在機器學習中，則用來將類別值表示為數值向量。
