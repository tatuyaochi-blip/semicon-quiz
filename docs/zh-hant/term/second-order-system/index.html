什麼是二階系統

轉移函數以 G(s) = Kωn²/(s² + 2ζωn s + ωn²) 表示的系統。ωn 稱為自然角頻率，ζ 稱為阻尼比。0 < ζ < 1 時步階響應一邊振盪一邊趨近終值，ζ = 1 時沒有過衝且最快穩定，ζ > 1 時則慢慢趨近。彈簧、質量與阻尼器的機械系統、RLC電路、位置控制迴路等，都以這個形式表示。高階系統也常以主要的2個極點近似處理。

日文名稱: 二次遅れ系

「二階系統」出現在2領域的9道練習題中（控制工程基礎, 電路分析（交流電路、線性電路與暫態現象）等）。

這個名詞所屬的領域: 控制工程基礎

阻尼比與響應的形狀

過衝為 exp(−πζ/√(1 − ζ²))，只由 ζ 決定。ζ = 0.5 時約16%，ζ ≈ 0.707（1/√2）時約4.3%。超越量最大的時刻為 π/ωd，ωd = ωn√(1 − ζ²) 是一邊衰減一邊振盪的角頻率。ζ 越小，響應上升越快，但過衝與振盪越大。

與極點位置的對應

0 < ζ < 1 時極點為 s = −ζωn ± jωd，與原點的距離為 ωn，與負實軸所夾的角 θ 滿足 cos θ = ζ。實部 ζωn 決定衰減的快慢，±2%的安定時間約可估計為 4/(ζωn)。這個式子是由振盪的包絡線求出的近似，實際的值常比它稍短。

從頻率響應來看

在波德圖上，以 ωn 為轉折點，高頻時增益以 −40 dB/dec 下降，相位由0°變化到 −180°。ζ 小於約0.707時，在 ωn 附近會出現增益隆起的共振峰。在加上回授的系統中，相位邊限越小，閉迴路的 ζ 越小；作為參考，ζ 約為相位邊限（度）的100分之1。

練習二階系統的題目

在圖中的串聯RLC電路，L = 1 mH、C = 0.1 µF、R = 50 Ω。阻尼比 ζ 與步級響應種類的組合，下列哪一項正確？

  1. Aζ = 0.25，欠阻尼（阻尼振盪）
  2. Bζ = 0.50，欠阻尼（阻尼振盪）
  3. Cζ = 4.0，過阻尼
查看答案與解析

正確答案：A. ζ = 0.25，欠阻尼（阻尼振盪）

解法1（與標準形比較）：特性方程式為 s² + (R/L)s + 1/(LC) = 0，與標準形 s² + 2ζωn s + ωn² 比較得 ωn = 1/√(LC) = 1×10⁵ rad/s、2ζωn = R/L。由此 ζ = (R/2)√(C/L) = 25 × √(0.1×10⁻⁶/1×10⁻³) = 25 × 0.01 = 0.25。解法2（與臨界電阻的比）：臨界阻尼的電阻為 2√(L/C) = 200 Ω，因此也可由 ζ = R/(2√(L/C)) = 50/200 = 0.25 求得。ζ < 1，步級響應會超過最終值，並一邊振盪一邊收斂，為欠阻尼。

二階系統 G(s) = ωn²/(s² + 2ζωn s + ωn²) 的步階響應會超過終值、一邊振盪一邊趨近終值時，阻尼比 ζ 的範圍為下列何者？

  1. Aζ > 1
  2. Bζ = 1
  3. C0 < ζ < 1
查看答案與解析

正確答案：C. 0 < ζ < 1

0 < ζ < 1 時極點為共軛複數，響應一邊振盪一邊趨近終值（欠阻尼）。ζ = 1 時極點為負實數的重根，在沒有過衝的響應中最快穩定下來（臨界阻尼）。ζ > 1 時極點為兩個負實數，雖然沒有過衝，但會慢慢地趨近（過阻尼）。ζ = 0 時振盪不衰減而持續，ζ < 0 時則不穩定。

常見問題

阻尼比設計成多少比較好？

希望稍有超越而快速響應時，常選 ζ = 0.5～0.8左右。ζ ≈ 0.707 時過衝約4.3%，也是頻率響應開始出現共振峰的分界。不允許超越的用途，則設計成 ζ ≥ 1。

三階以上的系統也能用二階系統的式子嗎？

若最接近虛軸的2個極點（主極點）比其他極點慢很多，就能以這2個極點近似來估算。其他極點或零點靠近時誤差會變大，因此以數值計算確認才確實。
