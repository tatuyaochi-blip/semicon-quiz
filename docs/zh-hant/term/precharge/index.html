什麼是預充電

在記憶體讀出之前，預先將位元線充電至既定電位(DRAM 中為電源電壓的一半等)的動作。在 DRAM 中，也指關閉原本開啟的列、準備啟動下一列的操作。

日文名稱: プリチャージ

「預充電」出現在2領域的5道練習題中（DRAM, SRAM與快閃記憶體等）。

這個名詞所屬的領域: DRAM

DRAM 讀取路徑中的預充電

每個 DRAM 感測放大器都位於一對位元線上，在開啟某列之前，這對位元線會被均衡到陣列電源的一半 VDD/2。字元線導通時，單元電容與大得多的位元線電容分享電荷，儲存 1 時使該線略微上升，儲存 0 時略微下降。從中點開始使兩種情況對稱，感測放大器將受擾動的線與未受影響的另一條線比較，然後將兩者驅動到完整的邏輯位準，同時恢復單元的內容。

作為 DRAM 指令的預充電

在指令層級，預充電（PRE）會關閉某個 bank 的開啟列，讓字元線關閉、位元線回到 VDD/2，以便啟動另一列。典型的存取序列是啟動（ACT）、等待 tRCD、讀取或寫入，然後預充電，並在下一次啟動前等待 tRP。列週期時間 tRC 為 tRAS 加上 tRP。讀寫指令也可以附帶自動預充電，自動關閉該列；而全部預充電指令會關閉所有 bank，這在全 bank 刷新之前是必要的。

開頁與關頁策略

當某列保持開啟時，其資料存在於感測放大器中，因此對該列的另一次存取只需要一個行指令與 CAS 延遲。若改為存取同一 bank 中的另一列，則需付出預充電、啟動與行存取的代價，約為 tRP + tRCD + CL。因此記憶體控制器會選擇策略：存取具有局部性時讓頁保持開啟，存取隨機時則提早預充電。它們也會重新排列佇列中的請求以優先處理列命中。在 DDR4 與 DDR5 元件中，tRP 通常是接近 CAS 延遲的數值。

電路中其他地方的預充電

這個詞也出現在其他情境中。SRAM 的位元線通常預充電為高，一般為 VDD，讀取時以其中一條線略微放電來偵測。動態（骨牌）邏輯在一個時脈相位中將內部節點預充電為高，並在評估相位中有條件地將其放電。在電力電子中，預充電是指先經由電阻緩慢地為大型直流鏈電容組充電，以限制湧入電流，然後才閉合主接觸器。共同的概念是在實際操作開始之前，將節點準備在已知的電壓。

練習預充電的題目

在DRAM中，連續存取同一列（頁）時存取時間會縮短，其原因下列何者正確？

  1. A因為不再需要更新
  2. B因為電源電壓上升
  3. C因為曾啟動過的列的資料保持在感測放大器中，只要切換行就能讀出
查看答案與解析

正確答案：C. 因為曾啟動過的列的資料保持在感測放大器中，只要切換行就能讀出

啟動列後，該列所有單元的資料會被讀出到感測放大器，並以頁的形式保持開啟。若是同一列，不必重新啟動，只要更改行位址（耗費CAS延遲的時間）即可讀出，因此比移到其他列的情況（預充電＋啟動＋行存取）更快。記憶體控制器會將對同一列的請求集中等，重新排列存取順序以增加這種頁命中（page hit）。

將DRAM內部分成多個bank，其主要目的是下列何者？

  1. A為了減少容量
  2. B為了讓不同bank的動作重疊進行，提高實質的存取效能
  3. C為了增加發熱
查看答案與解析

正確答案：B. 為了讓不同bank的動作重疊進行，提高實質的存取效能

列的啟動與預充電需要十幾ns。將內部分成多個bank後，在某個bank進行這些動作的期間，可以存取其他bank，隱藏等待時間而提高傳輸效率。DDR4有16個bank（4個bank group），DDR5有32個bank（8個bank group）（DDR4為x4、x8晶片，DDR5為16 Gbit以上的x4、x8晶片時的數值，x16晶片皆為其一半）。由於多個bank可分別開啟不同的列，頁命中的機會也會增加。

常見問題

RAM 時序中的 tRP 是什麼？

tRP 是列預充電時間，即預充電指令與對同一 bank 的下一次啟動之間的最小延遲。在寫成 CL-tRCD-tRP 這類形式的時序中，它通常是第三個數字。

為什麼 DRAM 位元線要預充電到 VDD/2？

這樣單元就能以相近的微小幅度將位元線拉上或拉下，使感測放大器相對於中點參考，對 1 和 0 看到對稱的訊號。

DRAM 的預充電和刷新有什麼不同？

預充電關閉開啟的列並重設位元線；刷新則定期讀取並重寫各列，以恢復其流失的電荷。刷新在內部會對所涉及的列進行啟動與預充電。
