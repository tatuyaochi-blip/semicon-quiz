什麼是疊差

晶體原子面的堆疊順序發生紊亂的面狀缺陷。也稱為堆疊錯誤(Stacking fault)。在磊晶層、熱氧化(OSF)、SiC晶體等會成為問題。

日文名稱: 積層欠陥

「疊差」出現在2領域的4道練習題中（氧化與擴散, 矽晶圓等）。

這個名詞所屬的領域: 磊晶成長

練習疊差的題目

為了能用光學顯微鏡觀察矽晶體中的差排或疊差等，選擇性地淺蝕缺陷部分的方法是哪一種？

  1. A反應性離子蝕刻
  2. B選擇性蝕刻(Secco蝕刻等)
  3. C犧牲層蝕刻
查看答案與解析

正確答案：B. 選擇性蝕刻(Secco蝕刻等)

選擇性蝕刻使用的藥液(鉻酸系的Secco液、Wright液、不含鉻的藥液等)，會使缺陷周圍的應變部分比周圍蝕刻得更快，讓缺陷以蝕坑(凹陷)的形式浮現出來。由蝕坑的形狀評估缺陷的種類，由數量評估密度。這是晶體品質管理的基本手法，但屬於破壞性檢查，也正推動改用對環境負荷較小的藥液。
