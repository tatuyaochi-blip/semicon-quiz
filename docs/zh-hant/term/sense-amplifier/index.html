什麼是感測放大器

放大從記憶單元讀出的微小電壓差，判定為 0 或 1 的電路。

日文名稱: センスアンプ

「感測放大器」出現在2領域的9道練習題中（DRAM, SRAM與快閃記憶體等）。

這個名詞所屬的領域: DRAM

為什麼記憶體需要感測放大器

記憶單元被做得越小越好，因此無法快速驅動長長的位元線。在 DRAM 中，打開一個單元會讓其電荷與電容大上數倍的位元線分享，產生的擺幅只有約 (VDD/2)·Cs/(Cs + Cb)，也就是數十到約一百毫伏。在 SRAM 中，單元只能緩慢地讓預充電的位元線放電。感測放大器偵測這個微小的差異，並將其轉換為完整的邏輯位準，讓記憶體不必等待位元線擺動到底。

閂鎖型感測放大器如何運作

常見的形式是兩個交叉耦合的反相器，跨接在一對位元線之間，其中一條承載單元訊號，另一條則是參考。兩條線先被預充電並等化。啟用感測放大器時，稍高的一側會將另一側拉低，正回授在短時間內把微小差異再生放大到完整的電源軌。時機很重要：在訊號尚未充分建立前過早觸發，可能做出錯誤判定；過晚觸發則浪費存取時間。

DRAM 的讀取、回寫與預充電

DRAM 位元線被預充電到 VDD/2，使儲存的 1 或 0 讓其上升或下降相同的量。由於電荷分享會破壞儲存的值，解析位元線的感測放大器也會將其驅動到完整位準並回寫到單元，因此啟動一列就會自動更新該列。關閉該列並讓位元線回到 VDD/2 稱為預充電，其時間由 tRP 規定。摺疊式位元線陣列將一對位元線並排放置，使耦合雜訊相互抵消；開放式位元線陣列則將其分開，以容許更小的 6F² 單元。

偏移與其他記憶體類型

閂鎖電晶體之間隨機的臨界電壓不匹配，使每個感測放大器都有輸入偏移，此偏移必須遠低於可用訊號；這限制了一條位元線可以共用的單元數量，也促成了偏移補償方案。快閃記憶體等單端記憶體則將單元電流與參考電流或參考單元比較，而多階單元每次讀取需要進行多次比較。同樣的再生閂鎖概念也出現在類比數位轉換器的時脈比較器中。

練習感測放大器的題目

3D NAND 中，將感測放大器等周邊電路配置在記憶單元陣列下方的結構（CMOS under Array 等），其主要優點為何？

  1. A不再需要抹除
  2. B縮小晶片面積，增加一片晶圓可取得的容量
  3. C可減少堆疊層數
查看答案與解析

正確答案：B. 縮小晶片面積，增加一片晶圓可取得的容量

以往是將周邊電路排在單元陣列旁邊，若把周邊電路放在陣列正下方，就能減少該部分的晶片面積達 2～3 成，位元密度提高、成本降低（CMOS under Array、Periphery under Cell 等）。由於先製作周邊電路，必須顧及後續陣列形成的熱製程。此外，將周邊電路與陣列分別在不同晶圓上製作再貼合的方式（CBA 等）也已實用化。

常見問題

為什麼 DRAM 需要感測放大器？

單元電容遠小於位元線電容，因此讀取時只產生數十毫伏的變化。感測放大器將其放大到完整的邏輯位準，並且因為讀取會破壞單元電荷，也會將資料回寫到單元。

為什麼 DRAM 位元線要預充電到 VDD/2？

從一半開始，可讓儲存的 1 使位元線上升、儲存的 0 使其下降相近的量，因此感測放大器可以將位元線與相等的參考進行比較。這也使位元線擺幅減半，節省功耗。

DRAM 和 SRAM 的感測放大器有什麼差別？

兩者都使用再生閂鎖，但 DRAM 感測放大器還要回寫被破壞的單元資料，並從 VDD/2 預充電開始運作。SRAM 感測放大器只需偵測預充電到接近 VDD 之位元線上的微小差動，以加快讀取速度。
