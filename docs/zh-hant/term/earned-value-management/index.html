什麼是實獲值管理（EVM）

以計畫值（PV）、實獲值（EV）、實際成本（AC）這些金額尺度比較專案的進度與成本以進行管理的手法。由時程績效指數 SPI = EV ÷ PV 與成本績效指數 CPI = EV ÷ AC 判斷進度落後或預算超支，並估算完工時的總成本。

日文名稱: アーンドバリューマネジメント(EVM)

「實獲值管理（EVM）」出現在1領域的2道練習題中（軟體開發與專案管理等）。

這個名詞所屬的領域: 軟體開發與專案管理

3個值

計畫值（PV）是到該時間點為止預定完成之工作的預算。實獲值（EV）是到該時間點為止實際完成的工作，以預算金額計算的值。實際成本（AC）是到該時間點為止實際花費的成本。只看進度只能知道「完成了幾%」，只看成本只能知道「花了多少」，但以 EV 為基準同時與 PV 及 AC 比較，就能分別判斷落後與超支。

偏差與指數

時程偏差 SV = EV − PV 與時程績效指數 SPI = EV ÷ PV 表示進度，成本偏差 CV = EV − AC 與成本績效指數 CPI = EV ÷ AC 表示成本。SV 為負（SPI 小於1）表示比預定落後，CV 為負（CPI 小於1）表示超出預算。例如 PV 為500、EV 為400、AC 為450時，SPI = 0.8 表示落後，CPI = 400 ÷ 450 ≈ 0.89 表示超支。同時看金額的差與比率，就能知道問題的大小與效率兩方面。

完工時的估算

假設目前的成本效率持續到最後，完工估算為 EAC = BAC ÷ CPI（BAC 為完工預算）。以上例而言，BAC 為1,000時，EAC = 1,000 ÷ (400 ÷ 450) ≈ 1,125。若認為超支的原因是暫時性的，剩餘工作會依預算進行，則使用 EAC = AC + (BAC − EV)。使用哪個公式取決於超支的原因，因此不只看數值，也要結合原因分析來判斷。

練習實獲值管理（EVM）的題目

在完工預算（BAC）為2,000萬日圓的專案中，某時間點的計畫值（PV）為800萬日圓、實獲值（EV）為600萬日圓、實際成本（AC）為750萬日圓。此時間點專案的狀況，下列何者正確？

  1. A時程落後（SPI = 0.75），成本也超出預算（CPI = 0.8）
  2. B時程落後（SPI = 0.75），但成本在預算之內（CPI = 1.25）
  3. C時程超前（SPI = 1.33），但成本超出預算（CPI = 0.8）
查看答案與解析

正確答案：A. 時程落後（SPI = 0.75），成本也超出預算（CPI = 0.8）

時程績效指數 SPI = EV ÷ PV = 600 ÷ 800 = 0.75，小於1，因此比預定落後（時程偏差 SV = EV − PV = −200萬日圓）。成本績效指數 CPI = EV ÷ AC = 600 ÷ 750 = 0.8，小於1，因此花費的成本多於已完成工作的預算（成本偏差 CV = EV − AC = −150萬日圓）。在實獲值管理（EVM）中，將實獲值（EV）同時與計畫值（PV）及實際成本（AC）比較，以同一個金額尺度評估進度與成本。

在完工預算（BAC）為1,200萬日圓的專案中，目前的計畫值（PV）為600萬日圓、實獲值（EV）為480萬日圓、實際成本（AC）為600萬日圓。假設今後目前的成本效率持續下去，完工估算（EAC）為下列何者？

  1. A1,320萬日圓
  2. B1,500萬日圓
  3. C1,725萬日圓
查看答案與解析

正確答案：B. 1,500萬日圓

成本績效指數 CPI = EV ÷ AC = 480 ÷ 600 = 0.8，預算1日圓的工作要花1.25日圓。若此效率持續，EAC = BAC ÷ CPI = 1,200 ÷ 0.8 = 1,500萬日圓，預計超出預算300萬日圓。1,320萬日圓是假設剩餘工作（BAC − EV = 720萬日圓）依預算進行的 AC + (BAC − EV) 的值。1,725萬日圓是假設成本與時程兩方面的效率都影響剩餘工作的 AC + (BAC − EV) ÷ (CPI × SPI) = 600 + 720 ÷ 0.64 的值。

常見問題

SPI 與 CPI 哪個比較重要？

要兩者一起看。SPI 小於1但 CPI 在1以上，表示雖然落後但成本效率良好，還有增加人力趕上的餘地。兩者都小於1時，落後與超支同時發生，多半需要重新檢視範圍或計畫。

實獲值（EV）要如何量測？

為 WBS 的每個工作包分配預算，再將已完成工作的預算加總。進行中的工作以事先決定的規則計算，例如開始算50%、完成算100%的50/50規則，或完成前都算0%的0/100規則，可減少受負責人主觀影響。
