什麼是故障注入攻擊（Fault injection attack）

藉由電源電壓或時脈的擾動、雷射等，故意使晶片誤動作，以跳過認證或推測金鑰的攻擊。

日文名稱: 故障注入攻撃

「故障注入攻擊（Fault injection attack）」出現在2領域的2道練習題中（硬體安全, 硬體安全的進階主題與趨勢等）。

這個名詞所屬的領域: 硬體安全

練習故障注入攻擊（Fault injection attack）的題目

下列關於錯誤注入攻擊（故障注入攻擊）的說明，何者正確？

  1. A對電源電壓或時脈施加瞬間的擾動，或照射雷射，使晶片誤動作，藉以略過認證或推測金鑰的攻擊
  2. B計算程式中錯誤（bug）數量的工作
  3. C找出因製造不良而損壞的晶片的測試
查看答案與解析

正確答案：A. 對電源電壓或時脈施加瞬間的擾動，或照射雷射，使晶片誤動作，藉以略過認證或推測金鑰的攻擊

晶片被設計成在規定的電壓與時脈範圍內正確運作。錯誤注入攻擊是藉由將電源電壓瞬間降低、在時脈中加入短脈衝、照射雷射或電磁脈衝等方式，故意引發誤動作。已知可略過比較指令而繞過簽章驗證，或比較錯誤的密碼結果與正確的結果來推測金鑰。

在故障注入攻擊中，使用雷射的方法與使用電磁脈衝的方法，其特徵的組合正確的是下列何者？

  1. A雷射多半從已開封晶片的背面照射近紅外光，能精細地選擇目標位置。電磁脈衝以線圈施加，有時不開封也能使用，但能鎖定的範圍較大
  2. B雷射能穿透封裝的樹脂，因此不開封晶片也能照射到選定的單一電晶體。電磁脈衝則必須把晶片削到露出配線才能使用
  3. C雷射與電磁脈衝都是讓晶片局部溫度急遽上升，使配線或電晶體熔化，以造成無法恢復的故障來改變電路功能的方法
查看答案與解析

正確答案：A. 雷射多半從已開封晶片的背面照射近紅外光，能精細地選擇目標位置。電磁脈衝以線圈施加，有時不開封也能使用，但能鎖定的範圍較大

矽的能隙約為1.12 eV，波長比約1.1 µm長的光幾乎不被吸收。1 µm附近的近紅外光吸收較弱，因此能從減薄基板的背面深入，在電晶體附近有一部分被吸收，產生電子電洞對。正面覆蓋著多層金屬配線，因此雷射故障注入一般從背面照射，利用光產生的電流，鎖定特定的電晶體或SRAM記憶胞使其錯誤動作。電磁脈衝則是讓大電流短暫流過線圈，產生強烈的磁場變化，在晶片內的配線與電源網路上感應出電壓，引發錯誤動作。對策是組合偵測光或電磁場的感測器、重要運算的雙重化，以及偵測到錯誤時清除金鑰的機制等。
