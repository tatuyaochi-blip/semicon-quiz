什麼是前驅物

在CVD或ALD中，經反應成為目標薄膜的原料化合物。例如TEOS或有機金屬化合物。

日文名稱: プリカーサ(前駆体)

「前驅物」出現在2領域的2道練習題中（先進電晶體（FinFET與GAA）, 薄膜沉積（CVD與PVD）等）。

這個名詞所屬的領域: 製程材料（氣體與藥液）

前驅物如何變成薄膜

在化學氣相沉積（CVD）中，前驅物蒸氣流過加熱的晶圓，吸附在表面上並分解或與共反應物反應，留下固態薄膜，揮發性副產物則被抽走。矽烷（SiH4）分解為矽與氫，六氟化鎢（WF6）被還原為鎢並產生副產物 HF，TEOS 則分解為 SiO2。在原子層沉積（ALD）中，前驅物化學吸附在表面位置上直到填滿，多餘的部分被吹淨，再由水、臭氧或氨等另一種反應物完成反應，每循環約 0.1 nm。

好的前驅物需要什麼條件

實用的前驅物必須有足夠的揮發性，才能以蒸氣形式輸送；TEOS 等液體以載氣鼓泡或直接液體注入的方式汽化。它必須在輸送過程中不在氣相分解，卻又能在表面輕易反應。其配位基應能乾淨地脫離：HfCl4 等氯化物在約 300 °C 下熱穩定，但可能在膜中殘留氯；TEMAHf 等有機金屬化合物可在較低溫下反應，但可能殘留碳。安全性也很重要，這也是沉積氧化層時常以液態 TEOS 取代自燃性矽烷的原因。

反應限制與傳輸限制的成長

在低溫下，表面反應較慢並決定沉積速率，速率遵循 Arrhenius 定律、隨溫度呈指數變化，因此晶圓溫度均勻性決定了膜厚均勻性。由於前驅物分子在反應前能擴散到溝槽深處，此區間的階梯覆蓋性良好。在高溫下，反應很快，成長受前驅物的到達速率限制，因此氣流均勻性很重要，溝槽開口處會沉積較多膜而可能封口。大面積露出的區域會消耗較多前驅物而使沉積變慢，這種效應稱為負載效應（loading）。

晶圓廠常用的前驅物

矽膜與磊晶使用矽烷、二氯矽烷（SiH2Cl2）與三氯矽烷（SiHCl3），通常以氫氣稀釋，氫氣同時保持表面處於還原狀態，並將氯以 HCl 形式帶走。氧化層使用 TEOS，鎢插塞使用 WF6，氮化鈦則常使用 TiCl4。High-k ALD 使用 HfCl4 或 TEMAHf 搭配 H2O 或 O3，Al2O3 則在約 150 到 300 °C 的 ALD 窗口內使用三甲基鋁（TMA）與水。磷化氫與乙硼烷等摻雜氣體用於原位摻雜，聚焦離子束設備則注入前驅氣體來局部沉積鉑或鎢。

練習前驅物的題目

以MoS2等二維材料作為通道的電晶體，難以用原子層沉積（ALD）均勻形成high-k閘極絕緣膜的主要原因，下列何者正確？

  1. A二維材料是金屬，會與絕緣膜反應
  2. B表面幾乎沒有懸鍵，ALD前驅物可以吸附並開始成膜的位置很少
  3. C二維材料表面非常粗糙，ALD前驅物無法到達深處
查看答案與解析

正確答案：B. 表面幾乎沒有懸鍵，ALD前驅物可以吸附並開始成膜的位置很少

二維材料的層表面沒有懸鍵，因此即使厚度不到1 nm，遷移率也不易下降。但同樣的性質使ALD前驅物難以化學吸附在表面上，膜會從缺陷或晶界等處以島狀成長，難以成為薄而均勻的絕緣膜。使用電漿的方法容易損傷材料，因此正在研究先形成薄種子層等方法。

關於ALD（原子層沉積）的特徵，下列何者正確？

  1. A一次處理即可高速沉積數µm的薄膜
  2. B重複前驅物的自限性表面反應，可在原子層等級控制膜厚
  3. C是不需要真空的印刷技術
查看答案與解析

正確答案：B. 重複前驅物的自限性表面反應，可在原子層等級控制膜厚

ALD重複以下循環：供應原料氣體（前驅物）使其在表面僅吸附一層，以吹淨（purge）移除多餘氣體後，再供應反應氣體使其反應。當表面可反應的位置被填滿後反應即停止（自限性），因此每個循環可精密控制膜厚約0.1 nm，即使在深寬比達數十的深溝槽內也能均勻成膜。代價是成膜速度較慢。

常見問題

ALD 中的前驅物和反應物有什麼差別？

前驅物攜帶最終進入薄膜的元素，例如 HfCl4 中的鉿或三甲基鋁中的鋁。反應物通常是水、臭氧或氨，在另一個步驟中供應，將吸附的前驅物層轉化為氧化物或氮化物，並恢復表面反應位置以進行下一個循環。

為什麼氧化矽 CVD 常用 TEOS 而不用矽烷？

TEOS 在室溫下是液體且不會自燃，儲存與處理都比矽烷安全。其由表面主導的分解反應，也能在窄縫中形成保形性更好、階梯覆蓋更佳的氧化層。

載氣和前驅物是一樣的嗎？

不一樣。氫、氮或氬等載氣只負責輸送與稀釋前驅物蒸氣，不會向薄膜提供原子；不過在矽磊晶中，氫也作為還原劑，保持表面潔淨。
