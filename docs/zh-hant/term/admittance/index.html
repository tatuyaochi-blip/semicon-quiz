什麼是導納

阻抗的倒數 Y = 1/Z [S]。實部為電導G、虛部為電納B，寫成 Y = G + jB。並聯電路只要把各元件的導納相加，因此並聯RLC電路可簡單寫成 Y = 1/R + j(ωC − 1/(ωL))。Z = 3 + j4 Ω 時 Y = 0.12 − j0.16 S，電感性時電納為負。

練習導納的題目

阻抗為 Z = 3 + j4 [Ω] 的負載，其導納 Y 為下列哪一項？

  1. A0.12 − j0.16 S
  2. B0.12 + j0.16 S
  3. C約0.33 − j0.25 S
查看答案與解析

正確答案：A. 0.12 − j0.16 S

解法1（分母有理化）：將 Y = 1/(3 + j4) 的分子與分母同乘共軛複數 3 − j4，得 Y = (3 − j4)/(3² + 4²) = (3 − j4)/25 = 0.12 − j0.16 S。解法2（極座標形式）：|Z| = √(3² + 4²) = 5 Ω，角度約53.1°，因此 Y = (1/5)∠−53.1° = 0.2∠−53.1° S，換成直角座標形式同樣是 0.12 − j0.16 S。阻抗為電感性（虛部為正）時，導納的虛部（電納）為負。

  • 解法2（導納相加）：Y = 1/10 + 1/(−j10) = 0.1 + j0.1 S，因此 Zth = 1/Y = (0.1 − j0.1)/0.02 = 5 − j5 Ω。
