什麼是行程長度編碼（RLE）

把相同值連續的部分（行程）以該值與連續長度的組合取代以縮小資料的無失真壓縮方式。例如黑白像素的序列 0000000011110000，可以表示為「0有8個、1有4個、0有4個」。對白底較多的圖面、傳真影像、單色區域多的影像等相同值長長連續的資料，壓縮效果很好。值細微變化的資料行程很短，有時反而會變大。也稱為RLE。

練習行程長度編碼（RLE）的題目

以行程長度編碼壓縮40個字元的字串 AAAAAAAAAAAABBBBCCCCCCCCCCCCCCCCCCCCDDDD（A 12個、B 4個、C 20個、D 4個），把相同字元的連續以「字元（1位元組）與個數（1位元組）」的組合表示。原本的字串為每個字元1位元組，若壓縮率定義為「壓縮後大小 ÷ 壓縮前大小」，壓縮率為下列何者？

  1. A10%
  2. B20%
  3. C80%
查看答案與解析

正確答案：B. 20%

相同字元的連續（行程）有A、B、C、D共4個，因此壓縮後為 4 × 2 = 8 位元組。壓縮前為40位元組，因此壓縮率為 8 ÷ 40 = 0.2，也就是20%。行程長度編碼對相同值連續越長的資料，壓縮效果越好。

以行程長度編碼壓縮時，下列何種資料最容易變得最小？

  1. A在白色背景上以黑線繪製的圖面，以黑白2值表示的影像
  2. B像相片那樣，相鄰像素的值細微變化的影像
  3. C加密之後，0與1看起來隨機排列的資料
查看答案與解析

正確答案：A. 在白色背景上以黑線繪製的圖面，以黑白2值表示的影像

行程長度編碼以數字表示相同值連續的長度（行程），因此相同值連續越長的資料越能變小。白底較多的2值圖面中，白色像素長長地連續，因此效果很大，傳真的編碼也使用這種想法。值細微變化的資料行程很短，有時反而會變大。
