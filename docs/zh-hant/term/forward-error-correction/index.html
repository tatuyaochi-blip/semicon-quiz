什麼是前向錯誤更正（FEC）

在傳送端以加上冗餘位元的錯誤更正碼傳送，只在接收端更正錯誤的方式。為Forward Error Correction的縮寫。接收端不要求重送，因此用於沒有回傳通道的廣播、來回延遲大的衛星與太空通訊，以及不容許延遲的高速傳輸路徑。代表性的碼有漢明碼、BCH碼、里德－所羅門碼、LDPC碼等。與偵測錯誤後請對方重送的ARQ（自動重傳請求）相比，總是要付出冗餘位元所占的傳輸效率，但延遲固定。在使用PAM4的PCI Express 6.0等高速序列傳輸中也有使用。

練習前向錯誤更正（FEC）的題目

關於通訊中處理錯誤的方式ARQ（自動重傳請求）與FEC（前向錯誤更正），下列說明何者正確？

  1. AARQ只在接收端更正錯誤，因此不需要把通知送回傳送端的通道
  2. BFEC偵測到錯誤時會要求重送，因此錯誤多時延遲容易變大
  3. CFEC利用冗餘的位元在接收端更正錯誤，因此也能用於單向的廣播
查看答案與解析

正確答案：C. FEC利用冗餘的位元在接收端更正錯誤，因此也能用於單向的廣播

ARQ以CRC等偵測錯誤，通知傳送端未能收到並請對方重送，需要回傳的通道，並會因重送而延遲。FEC附加冗餘的位元後傳送，只在接收端更正錯誤，因此適合單向的廣播、來回需要很長時間的太空通訊，以及不容許延遲的通訊。實際的通訊中，也常以FEC更正大部分錯誤，剩下的錯誤再以ARQ重送的方式組合使用。

使用PAM4時，相較於NRZ，錯誤更正（FEC）更為重要，其原因為下列何者？

  1. A因為PAM4無法取出時脈，所以每次都會發生錯誤
  2. B因為在相同振幅中放入4階，階與階的間隔約變為1/3，容易因雜訊而誤判位元
  3. C因為PAM4的訊號已被加密，所以需要更正解密的錯誤
查看答案與解析

正確答案：B. 因為在相同振幅中放入4階，階與階的間隔約變為1/3，容易因雜訊而誤判位元

若電壓擺幅相同，兩階的NRZ在0與1之間有整個擺幅的間隔，但四階的PAM4相鄰階之間的間隔約為1/3。雜訊裕度約減少9.5 dB，因此位元更容易出錯。於是PCI Express 6.0加入輕量的錯誤更正碼，在接收端更正微小的錯誤後再使用。

解析中的「前向錯誤更正（FEC）」
