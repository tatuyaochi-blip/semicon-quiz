什麼是中斷

回應外部裝置的請求等，暫時中止執行中的處理，優先進行對應處理的 CPU 機制。結束後回到原本的處理。

日文名稱: 割り込み

「中斷」出現在18領域的61道練習題中（嵌入式與韌體, 作業系統與硬體, 介面與匯流排規格等）。

這個名詞所屬的領域: CPU與架構

受理中斷時發生了什麼

當裝置、計時器或其他來源發出中斷且該中斷已被致能時，CPU會將下一道指令的位址，連同特權模式與中斷致能位元等狀態，儲存到專用暫存器中。它取得代表中斷原因的向量編號，從作業系統設定的中斷向量表中讀出處理常式的起始位址，並跳躍過去。處理常式會保存它所使用的暫存器、為裝置提供服務、清除中斷來源、恢復狀態，再以RISC-V的mret或sret等特殊指令返回，這類指令能以不可分割的方式同時恢復模式與返回位址。

中斷、例外與輪詢

中斷是非同步的：計時器滴答或網路封包的到來，與目前正在執行哪一道指令無關。頁面錯誤、除以零或刻意發出的系統呼叫（RISC-V的ecall）等例外則是同步的，由特定指令所引起。輪詢（polling）是中斷以外的另一種做法，由CPU反覆讀取裝置狀態。事件稀少或CPU應進入睡眠時，中斷較為有利；但每次中斷都要付出保存狀態與跳躍的代價，因此在事件頻率極高的情況下（例如高速網路），批次輪詢可能更有效率。

優先權、遮罩與延遲

中斷控制器負責仲裁同時發生的請求，通常使用優先編碼器；支援巢狀中斷時，高優先權的中斷可以搶占低優先權的處理常式，例如Arm Cortex-M的NVIC。軟體可以遮罩中斷，但不可遮罩中斷（NMI）保留給無法更正的記憶體錯誤或看門狗逾時等嚴重事件。最差情況下的中斷延遲，主要取決於在中斷禁能狀態下執行的最長區段，因此作業系統會將處理拆成短小的緊急部分，以及之後在中斷致能狀態下執行的延後工作。PCI Express裝置則以記憶體寫入（MSI）取代專用接線來發出中斷。

嵌入式程式的常見陷阱

處理常式應保持簡短：不要使用printf或等待迴圈，只把資料移到緩衝區，或為主迴圈設定旗標。與處理常式共用的變數必須宣告為volatile，否則編譯器可能只讀取一次。像reg |= mask這類讀取-修改-寫入的更新，可能會遺失處理常式在中途改變的位元；8位元微控制器讀取32位元計數器時，也可能讀到只更新了一半的位元組；短暫禁能中斷可同時解決這兩個問題。週期性的計時器中斷可提供系統滴答，例如將16 MHz除以16後計數到1000，即可得到1 ms。

練習中斷的題目

暫時中斷執行中的處理，並優先處理來自外部裝置等請求的 CPU 機制是下列何者？

  1. A中斷（interrupt）
  2. B管線
  3. C快取
查看答案與解析

正確答案：A. 中斷（interrupt）

中斷是指當鍵盤輸入、計時器、通訊接收等事件發生時，CPU 中斷執行中的處理，保存暫存器等狀態並執行對應的處理（中斷處理常式），結束後再回到原來狀態的機制。在事件不頻繁時，相較於 CPU 持續檢查周邊裝置狀態的方式（輪詢，polling），浪費較少，且能一邊進行其他處理一邊迅速回應；事件非常頻繁時，輪詢有時反而更有效率。它還會設定優先順序，先處理重要的請求。

機器製造商在零組件採購上，為了防範某項半導體的供應中斷，而預先備妥可從其他供應商採購同等產品的做法，稱為什麼？

  1. A第二供應來源（Second Source，多源採購）
  2. B設計定案（Tape-out）
  3. C縮小改版（Shrink）
查看答案與解析

正確答案：A. 第二供應來源（Second Source，多源採購）

第二供應來源是指預先讓相同功能、規格的零組件可從多個供應商採購。即使因工廠事故、災害、供需吃緊等導致單一公司的供應中斷，也能持續生產，在價格談判上也較有利。過去因客戶將第二供應來源列為條件，也有授權其他公司製造的案例。經歷半導體短缺後，它再次受到重視。

常見問題

中斷和例外有什麼不同？

中斷是非同步的，來自指令流以外，例如計時器或I/O裝置。例外則是同步的，由執行特定指令所觸發，例如頁面錯誤、非法指令或系統呼叫。

什麼是中斷向量表？

中斷向量表是由作業系統或韌體設定的表格，將每個中斷或例外編號對應到其處理常式的起始位址。CPU利用它跳到對應各種原因的正確常式。

為什麼中斷處理常式要保持簡短？

處理常式執行期間，相同或較低優先權的中斷通常會被擱置，主程式也會停頓，因此處理常式越長，其他所有工作的延遲就越大。繁重的工作應延後到在中斷致能狀態下執行的任務或主迴圈中處理。
