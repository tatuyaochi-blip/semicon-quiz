什麼是NOR 型快閃記憶體

單元以並聯方式連接的快閃記憶體。隨機讀取速度快，用於儲存微控制器的程式等。

日文名稱: NOR型フラッシュメモリ

「NOR 型快閃記憶體」出現在1領域的1道練習題中（SRAM與快閃記憶體等）。

這個名詞所屬的領域: SRAM與快閃記憶體

單元並聯連接的結構

NOR型快閃記憶體將各單元電晶體的汲極接到位元線、源極接到共用的源極線，使單元沿著位元線並聯排列。只要其中任一個單元導通，就會把位元線拉低，這個形態與NOR閘相似，因而得名。每個單元都需要一個連到位元線的接點，所以單元面積比NAND型大，但任何單元都能直接讀取，不必經過其他單元。單元與NAND型一樣，是在控制閘極下方具有電荷儲存層的電晶體，以儲存的電子量所改變的臨界電壓來讀出0與1。

寫入與抹除

寫入時常用通道熱電子（CHE）注入：對汲極施加電壓，使電子沿通道加速，其中一部分被注入電荷儲存層。這種方式寫入快，但每個單元的電流大，所以一次能寫入的位元數有限。抹除一般以FN（富爾-諾德海姆）穿隧電流將電子抽出，並以稱為磁區（sector）或區塊（block）的單位進行。抹除後的位元為1，寫入只能把1改為0，因此要改寫內容必須先抹除。抹除是比讀取與寫入耗時得多的操作。

XIP與主要用途

NOR型能以位元組或字組為單位快速讀取任意位址，因此CPU可以直接從快閃記憶體擷取指令並執行，稱為XIP（Execute In Place，就地執行）。系統不必先把程式複製到RAM就能開機，所以NOR型用於儲存微控制器的韌體、個人電腦與伺服器的BIOS/UEFI、FPGA的組態資料，以及車用設備與通訊設備的開機程式碼等。容量小，僅數Mbit～數Gbit，每位元單價也比NAND型高，因此大容量資料的儲存使用NAND型。NOR型通常不像NAND型那樣需要強大的錯誤更正與壞區塊管理，這也是它適合儲存程式碼的原因之一。

並列NOR與序列NOR

NOR型快閃記憶體分為具有成排位址與資料接腳的並列NOR（parallel NOR），以及以SPI連接的序列NOR（serial NOR）。並列NOR只要給定位址，就能像SRAM一樣直接讀出資料，長年用於嵌入式設備的程式儲存。但由於需要許多接腳，現在以只需幾條訊號線的序列NOR為主流。序列NOR也以將資料線增為4條或8條的Quad SPI或Octal SPI加快讀取，搭配微控制器的記憶體映射模式也能進行XIP。在要求高可靠度與長期供貨的車用與工業設備中，並列NOR仍持續使用。

NOR 型的各單元並聯至位元線，隨機存取快，因此 CPU 可以直接從記憶體讀取並執行程式（XIP：Execute In Place）。所以用於裝置的開機程式、微控制器的韌體、車用設備的控制程式碼。容量小，僅數 Mbit～數 Gbit，每位元單價也比 NAND 高，因此大容量資料儲存使用 NAND 型。

常見問題

NOR型與NAND型快閃記憶體有什麼不同？

NOR型將每個單元並聯到位元線，能快速讀取任意位址，適合直接執行程式（XIP）。NAND型將單元串聯以減少接點，單元小、容量大、價格低，但以頁為單位讀寫。NOR型用於開機程式碼與韌體，NAND型則用於SSD與記憶卡等大容量儲存。

NOR快閃記憶體的名稱由來是什麼？

因為單元並聯在位元線上，只要任一個單元導通就會把位元線拉低，這種結構與NOR閘的電晶體排列相似。同樣地，將單元串聯的NAND型，也是因為與NAND閘相似而得名。

NOR快閃記憶體用在哪裡？

用於儲存容量雖小、但需要快速且可靠讀取的程式碼，例如微控制器與嵌入式設備的韌體、個人電腦的BIOS/UEFI、FPGA的組態資料、車用設備的開機程式碼等。CPU能直接從快閃記憶體執行指令的XIP是一大優點。
