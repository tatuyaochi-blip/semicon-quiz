什麼是暫態現象

開關切換或電源突然變化後，含電容器或線圈的電路從一個穩態移到下一個穩態期間所見的電壓與電流變化。利用電容器電壓與線圈電流不會突然改變來決定初始值，RC電路與RL電路以時間常數呈指數變化，RLC電路則依阻尼比一邊振盪或不振盪地收斂。以微分方程式或拉普拉斯轉換求解。

日文名稱: 過渡現象

「暫態現象」出現在1領域的1道練習題中（電路分析（交流電路、線性電路與暫態現象）等）。

這個名詞所屬的領域: 電路分析（交流電路、線性電路與暫態現象）

一階電路的暫態現象

RC電路與RL電路的響應形式為 x(t) = x(∞) + (x(0+) − x(∞))e^(−t/τ)，時間常數在RC電路為 τ = RC，在RL電路為 τ = L/R。只要知道初值 x(0+)、終值 x(∞) 與時間常數三項，不必解微分方程式就能畫出波形。t = τ 時完成約63.2%的變化，5τ 時約完成99.3%。

初值與終值的決定方法

電容器的電壓無法突然改變其能量 (1/2)CV²，因此是連續的，開關閉合瞬間若未充電即可視為短路。線圈的電流也是連續的，閉合瞬間電流為0時可視為開路。經過足夠時間的直流穩態則相反，電容器如同開路、線圈如同短路。

二階電路與解法

RLC電路的響應由特性方程式 Ls² + Rs + 1/C = 0 的根決定：相異實根為過阻尼、重根為臨界阻尼、複數根為欠阻尼（阻尼振盪）。使用拉普拉斯轉換時，把初始值當作電源放入s域電路，以代數計算與部分分式展開求出時間波形。若只需要終值，用終值定理 lim(s→0) sF(s) 即可立即求得。

練習暫態現象的題目

在圖中的RC電路，於 t = 0 閉合開關，對未充電的電容器加上直流電壓E。設時間常數 τ = RC，t = 5τ 時電容器電壓 vC 約為最終值E的百分之多少，最接近下列哪一項？

  1. A約95%
  2. B約99.3%
  3. C100%
查看答案與解析

正確答案：B. 約99.3%

解法1（代入公式）：電容器電壓為 vC(t) = E(1 − e^(−t/τ))，t = 5τ 時為 1 − e^(−5) ≈ 1 − 0.0067 = 0.993，約99.3%。解法2（每個時間常數的大略值）：每經過 τ，與最終值的差變為 e^(−1) ≈ 0.37 倍，因此到達率依序為 1τ 63%、2τ 86%、3τ 95%、4τ 98%、5τ 99.3%。理論上不會到達100%，實務上約經過5τ就視為暫態現象結束。

常見問題

含線圈的電路突然切斷開關時，為什麼會出現高電壓？

因為線圈電流無法瞬間降為0，開關切斷的瞬間仍會試圖繼續流動，若電流沒有去處，就會由 v = L di/dt 產生非常大的電壓。在繼電器線圈並聯二極體，就是為了提供電流的路徑來抑制電壓。

暫態現象大約多久可以視為結束？

一階電路經過時間常數的5倍後，與終值的差小於1%（約0.7%），因此實務上多以5τ視為結束。需要更高精度時，對容許誤差 ε 要等待 ln(1/ε) 倍的時間常數。
