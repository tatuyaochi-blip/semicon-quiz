什麼是電鍍

在鍍液中以晶圓側為陰極通電，使金屬析出的成膜方法。用於填充銅導線的溝槽，並藉由添加劑控制使其由底部先填滿。

日文名稱: 電解めっき

「電鍍」出現在4領域的8道練習題中（配線製程, 製程材料（氣體與藥液）, 薄膜沉積（CVD與PVD）等）。

這個名詞所屬的領域: 薄膜沉積（CVD與PVD）

練習電鍍的題目

在以電鍍填入Cu之前，以濺鍍形成的薄Cu膜，其作用下列何者正確？

  1. A防止Cu擴散的阻障層
  2. B供電鍍電流流通的導電層（晶種層）
  3. C層間絕緣
查看答案與解析

正確答案：B. 供電鍍電流流通的導電層（晶種層）

電鍍是讓電流流過晶圓表面，使Cu離子還原析出，因此需要連續延伸到溝槽內面的導電層。阻障層（TaN/Ta）電阻高，電鍍無法均勻起始，因此先在其上以濺鍍形成厚度數十nm的薄Cu晶種層，再以電鍍填入Cu。在微細溝槽中，晶種層既要薄到不堵住開口，又要連續到底部不中斷，兩者難以兼顧，因此也會使用釕襯層等。

電鍍形成的Cu膜即使在室溫下放置，晶粒也會隨時間變大、電阻率下降，這種現象稱為什麼？

  1. A電遷移
  2. B應力遷移
  3. C自我退火（self-annealing）
查看答案與解析

正確答案：C. 自我退火（self-annealing）

剛電鍍完的Cu膜因添加劑的混入等原因，晶粒只有數十nm，小而不穩定，即使在室溫下也會在數小時～數天內再結晶，晶粒長大到1 µm左右，電阻率降低約2成。這就是自我退火。由於放置時間不同會使特性與研磨速率改變，因此一般在電鍍後先以100～400 ℃左右進行熱處理，使晶粒成長完成，再進入CMP。

解析中的「電鍍」

  • 電鍍是讓電流流過晶圓表面，使Cu離子還原析出，因此需要連續延伸到溝槽內面的導電層。

    電鍍形成的Cu膜即使在室溫下放置，晶粒也會隨時間變大、電阻率下降，這種現象稱為什麼？

  • 在鑲嵌（damascene）法中，先在溝槽以濺鍍形成數nm～數十nm的阻障層（Ta/TaN等）與Cu晶種層，再以電鍍填入Cu。

    主要用來填充Cu配線溝槽的成膜方法為下列何者？

  • 鑲嵌法是先在絕緣膜上挖出導線形狀的溝槽，以濺鍍沉積阻障層與Cu晶種層後，再以電鍍填入Cu。

    關於Cu導線形成時一般採用的鑲嵌法（damascene），下列說明何者正確？

  • 與分別製作導孔和導線的單鑲嵌法相比，沉積、電鍍與CMP各少一次，導孔與導線之間也不會產生阻障層界面，因此在電阻與可靠度方面也較有利。
