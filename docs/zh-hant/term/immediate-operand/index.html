什麼是立即值

直接嵌入指令中的常數。在RISC-V的addi中是12位元的有號整數，使用前會進行符號擴展。

日文名稱: 即値

「立即值」出現在1領域的10道練習題中（指令集與組合語言等）。

這個名詞所屬的領域: 指令集與組合語言

練習立即值的題目

RISC-V的addi指令的立即值是12位元帶正負號的整數。下列何者是此立即值能表示的範圍？

  1. A0～4095
  2. B-2048～2047
  3. C-4096～4095
查看答案與解析

正確答案：B. -2048～2047

12位元的二補數所能表示的，是從-2的11次方＝-2048到2的11次方-1＝2047。立即值在計算前會先符號擴充為32位元（RV64則為64位元），所以負數也能直接相加。要使用超出此範圍的常數，需組合多個指令，例如以lui指令設定高20位元，再以addi加上低12位元。

在RISC-V中，要將無法收進12位元立即值的32位元常數（例：0x12345678）放入暫存器，一般的方法是下列何者？

  1. A使用一次addi，直接寫入32位元的立即值
  2. B以lui設定高20位元，再以addi加上低12位元
  3. C因為無法使用常數，所以必須從輸入讀取
查看答案與解析

正確答案：B. 以lui設定高20位元，再以addi加上低12位元

lui（load upper immediate）會將20位元的立即值放在暫存器的位元31～12，並將低12位元設為0。接著以addi加上低12位元，就能產生任意的32位元常數。在組合語言中寫下「li a0, 0x12345678」時，組譯器會視需要將其展開為這兩個指令。在指令長度固定的ISA中，將大的常數分開來產生是一般的做法。

解析中的「立即值」

  • 立即值在計算前會先符號擴充為32位元（RV64則為64位元），所以負數也能直接相加。

  • lui（load upper immediate）會將20位元的立即值放在暫存器的位元31～12，並將低12位元設為0。

    在RISC-V中，要將無法收進12位元立即值的32位元常數（例：0x12345678）放入暫存器，一般的方法是下列何者？

  • 「add rd, rs1, rs2」將兩個暫存器的和放入rd，「addi rd, rs1, imm」則是將暫存器與嵌入指令中的12位元常數（立即值）相加。

    下列何者是RISC-V的「add」指令與「addi」指令的差異？

  • RISC-V的算術指令依「指令 寫入目的地, 讀取來源1, 讀取來源2（或立即值）」的順序書寫，第一個暫存器是存放結果的地方。
