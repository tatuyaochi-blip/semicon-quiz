什麼是先行進位加法器

由各位數的產生訊號 g = a·b 與傳遞訊號 p = a ⊕ b，不等待來自低位的傳遞，並行求出進位的加法器。即使位元數多，延遲也小。也稱為進位前瞻加法器(carry-lookahead adder)。

日文名稱: 桁上げ先見加算器

「先行進位加法器」出現在1領域的1道練習題中（邏輯電路等）。

這個名詞所屬的領域: 電腦算術

產生訊號與傳遞訊號

對於輸入為 a 與 b 的每個位元，產生訊號 g = a·b 為 1 時，表示該位元不論輸入進位為何都會產生進位；傳遞訊號 p = a ⊕ b 為 1 時，表示輸入的進位會傳遞過去。輸出進位為 c(i+1) = g(i) + p(i)·c(i)，和為 s(i) = p(i) ⊕ c(i)。將此遞迴式展開可得 c1 = g0 + p0·c0、c2 = g1 + p1·g0 + p1·p0·c0，因此每個進位都能只用 g、p 訊號與輸入進位 c0 以兩級邏輯寫出。

漣波進位加法為何慢

在漣波進位加法器中，每個全加器都必須等待來自下一位元的進位。最壞情況下，例如對全為 1 的字組加 1，進位會穿過每一個位元，因此延遲隨位元寬度線性增加；對於以 GHz 時脈運作的處理器而言，64 位元漣波進位加法器實在太慢。先行進位加法器（CLA）則直接由輸入並行算出各進位，若採用階層式先行進位，延遲只會隨位元寬度的對數增加。

以階層方式建構寬位元加法器

完全展開的進位方程式很快就需要輸入數過多的邏輯閘，因此實際設計採用約 4 位元的區塊。每個區塊產生群組產生訊號 G = g3 + p3·g2 + p3·p2·g1 + p3·p2·p1·g0 與群組傳遞訊號 P = p3·p2·p1·p0。第二級先行進位單元將這些訊號完全當作單一位元的 g 與 p 訊號處理，算出進入各區塊的進位，第三級則將此架構擴展到 64 位元。Kogge-Stone、Brent-Kung 等平行前綴加法器將同樣的概念一般化，以佈線與面積換取更少的邏輯層數。

先行進位加法器的應用場合

高速加法器存在於 ALU、位址產生器、浮點運算單元，以及乘法器的最後一級。乘法器先用進位保存加法器（carry-save adder）縮減大量的部分積；進位保存加法器由彼此獨立的全加器組成，只需一個全加器延遲即可將三個數化為兩個數，且沒有進位傳遞。只有最後剩下的兩個數需要進行進位傳遞加法，由先行進位加法器或前綴加法器執行一次即可。其他折衷方案如進位選擇加法器與進位跳躍加法器，在速度與面積上介於漣波進位與完全先行進位之間。

練習先行進位加法器的題目

先行進位（carry-lookahead）加法器之所以高速，下列哪一項理由正確？

  1. A為了減少加法的位元數
  2. B為了使時脈頻率變為2倍
  3. C因為各位元的進位不必等待來自低位的傳遞，而是從輸入平行計算
查看答案與解析

正確答案：C. 因為各位元的進位不必等待來自低位的傳遞，而是從輸入平行計算

先行進位加法器利用各位元的產生 G = A·B（必定產生進位）與傳遞 P = A⊕B（讓低位的進位通過），如 C1 = G0 + P0·C0、C2 = G1 + P1·G0 + P1·P0·C0 … 這樣從輸入平行計算各位數的進位。延遲只隨位元數的對數成長。不過由於式子會變長，實際上是將4位元左右的區塊階層式地組合使用。

常見問題

為什麼先行進位加法器比漣波進位加法器快？

漣波進位加法器要等進位依序通過每個位元，因此延遲隨位元寬度線性增加。先行進位加法器則由產生與傳遞訊號並行算出所有進位，因此延遲大約只隨位元寬度的對數增加。

傳遞訊號可以用 OR 取代 XOR 嗎？

就進位鏈而言可以：p = a + b 會得到相同的進位，因為兩個輸入都是 1 時，產生項已經會產生進位。但和的位元仍需要 a ⊕ b，因此許多設計會以 XOR 計算 p，並將其同時用於兩者。

什麼是群組產生訊號與群組傳遞訊號？

它們是對一個位元區塊的彙總：群組產生訊號為 1 表示該區塊本身會產生輸出進位，群組傳遞訊號為 1 表示進入該區塊的進位會一路傳遞穿過。更高層級的先行進位邏輯利用它們快速算出各區塊的進位。
