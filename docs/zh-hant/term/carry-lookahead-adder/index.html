什麼是先行進位加法器

由各位數的產生訊號 g = a·b 與傳遞訊號 p = a ⊕ b，不等待來自低位的傳遞，並行求出進位的加法器。即使位元數多，延遲也小。也稱為進位前瞻加法器(carry-lookahead adder)。

日文名稱: 桁上げ先見加算器

「先行進位加法器」出現在1領域的1道練習題中（邏輯電路等）。

這個名詞所屬的領域: 電腦算術

練習先行進位加法器的題目

先行進位（carry-lookahead）加法器之所以高速，下列哪一項理由正確？

  1. A為了減少加法的位元數
  2. B為了使時脈頻率變為2倍
  3. C因為各位元的進位不必等待來自低位的傳遞，而是從輸入平行計算
查看答案與解析

正確答案：C. 因為各位元的進位不必等待來自低位的傳遞，而是從輸入平行計算

先行進位加法器利用各位元的產生 G = A·B（必定產生進位）與傳遞 P = A⊕B（讓低位的進位通過），如 C1 = G0 + P0·C0、C2 = G1 + P1·G0 + P1·P0·C0 … 這樣從輸入平行計算各位數的進位。延遲只隨位元數的對數成長。不過由於式子會變長，實際上是將4位元左右的區塊階層式地組合使用。
