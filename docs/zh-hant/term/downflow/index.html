什麼是下降氣流

從整面天花板朝地板單向送出潔淨空氣的無塵室氣流方式，可將產生的微粒迅速排至地板下方。

日文名稱: ダウンフロー

這個名詞所屬的領域: 無塵室與製造設備

下降氣流如何運作

在下降氣流（垂直單向流）無塵室中，幾乎整個天花板都覆蓋著高效率的 HEPA 或 ULPA 濾網，通常以風扇濾網機組（FFU）的形式安裝。過濾後的空氣直直向下流過作業空間，穿過有孔的地板進入地板下的回風空間，再經由側邊回風道或回風豎井回到天花板上方的空間重新過濾。人員與設備產生的微粒在橫向飄散或往上飄向晶圓之前，就被向下掃出房間。

單向流與混合流

傳統的無塵室只從天花板的一部分供應過濾空氣，依靠混合來稀釋微粒，因此污染會滯留並擴散。下降氣流則讓整個房間的空氣以平行流線移動，因此在某處產生的微粒會被帶走，而不只是被稀釋。這就是為什麼最潔淨的等級（約 ISO Class 5 以上）一般需要單向流，而混合流的房間則適用於要求較低的區域。代價是龐大的風量與風扇能耗。

典型數值

送風速度通常約為 0.3 至 0.5 m/s。流速過快會在人員與設備周圍形成紊流而揚起微粒，流速過慢則可能被高溫設備上升的熱羽流壓過。在 0.4 m/s 下，空氣每小時移動約 1,440 m，因此 3 至 4 m 高的房間每小時會被完全置換數百次，相較之下一般辦公室每小時只換氣數次。輸送這麼多空氣佔了晶圓廠用電的很大一部分。

地板、樓板與微環境

地板必須能讓空氣通過，因此以有孔地板或格柵鋪設在格子樓板（waffle slab）上，這是一種有網格狀孔洞的厚混凝土樓板，同時也提供微影掃描機為控制振動所需的剛性。現代晶圓廠以密封的晶圓盒搬運晶圓，並透過配備自身濾網機組的設備前端模組裝載，因此只有這些微環境內部需要最高的潔淨度。周圍的區域便可以降低濾網覆蓋率，在保護晶圓的同時節省能源。

常見問題

下降氣流無塵室使用多少風速？

通常約 0.3 至 0.5 m/s。這個速度足以壓過熱上升氣流，又慢到能在人員與設備周圍保持平順而非紊流。

為什麼無塵室的地板有孔？

這些孔讓向下的氣流進入地板下方的空間，再返回循環。實心地板會讓氣流轉向橫向，把微粒重新揚回房間內。

為什麼無塵室這麼耗電？

單向下降氣流每小時要置換房間空氣數百次，因此大型風扇必須持續運轉，而且空氣還必須維持在嚴格控制的溫度與濕度。
