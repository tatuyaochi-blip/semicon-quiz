什麼是硬體安全模組（HSM）

安全地產生與保管加密金鑰，並在內部進行簽章或解密等處理而不讓金鑰離開的專用裝置。具有抗竄改性，偵測到被撬開等情況時會清除金鑰。用於保護憑證機構的簽章金鑰、支付用的金鑰，以及雲端金鑰管理服務（KMS）的最上層金鑰等。許多產品取得了FIPS 140-3等標準的認證。除了PCIe卡與連接網路的設備形式外，也以雲端服務的形式提供。

  2. B在具有抗竄改性的裝置內產生與保管金鑰，並在不讓金鑰離開的情況下進行簽章或解密等處理的裝置
  3. C監看網路的通訊，找出並阻擋不正當封包或攻擊通訊的網路設備

正確答案：B. 在具有抗竄改性的裝置內產生與保管金鑰，並在不讓金鑰離開的情況下進行簽章或解密等處理的裝置

HSM是用來保護憑證機構的簽章金鑰、支付用的金鑰，以及雲端金鑰管理服務（KMS）的最上層金鑰等的專用裝置。金鑰在HSM內部產生，並設計成無法以明文離開，應用程式只要提出「用這把金鑰簽章」等請求，就只會收到結果。它具有被試圖打開時會清除金鑰等抗竄改性，許多產品取得了FIPS 140-3等標準的認證。智慧型手機的安全元件與PC的TPM，規模雖小，也以類似的想法保護金鑰。
