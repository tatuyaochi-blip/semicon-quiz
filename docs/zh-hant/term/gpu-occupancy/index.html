什麼是佔用率（GPU occupancy）

實際載入的 warp 數，相對於 GPU 的 SM 可同時載入的 warp 最大數的比例。由暫存器與共享記憶體的使用量決定。

日文名稱: 占有率

「佔用率（GPU occupancy）」出現在1領域的3道練習題中（GPU程式設計等）。

這個名詞所屬的領域: GPU程式設計

練習佔用率（GPU occupancy）的題目

關於GPU的佔用率（occupancy），下列說明何者正確？

  1. AGPU晶片面積中，運算單元所佔的比例
  2. B實際載入的線程束數量，相對於SM可同時載入之線程束最大數量的比例
  3. CGPU記憶體中，被資料填滿的比例
查看答案與解析

正確答案：B. 實際載入的線程束數量，相對於SM可同時載入之線程束最大數量的比例

每個SM可同時載入的線程束數量有上限，而實際載入的數量取決於每個執行緒的暫存器、每個區塊的共享記憶體、區塊的大小等。該比例就是佔用率。佔用率低時，可用來取代等待記憶體之線程束的其他可執行線程束就少，運算單元容易閒置。CUDA也提供了計算佔用率的工具。

關於GPU的佔用率，下列何者正確？

  1. A只要佔用率為100%，必定能發揮最高效能
  2. B即使佔用率低，只要讓每個執行緒擁有較多獨立的計算以提高指令的平行度，也可能達到高效能
  3. C佔用率與效能完全無關
查看答案與解析

正確答案：B. 即使佔用率低，只要讓每個執行緒擁有較多獨立的計算以提高指令的平行度，也可能達到高效能

佔用率是隱藏延遲的手段之一，而不是目的。若一個執行緒能並排發出多個彼此不相依的計算或記憶體讀取，即使線程束較少，也能填補等待時間。反之，為了提高佔用率而減少暫存器，被擠到記憶體的情形會增加，有時反而會變慢。效能還是要以分析工具（profiler）實際測量來判斷才可靠。
