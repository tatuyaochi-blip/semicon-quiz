什麼是堆疊式 CMOS 影像感測器

將像素部與訊號處理電路分別在不同晶片上製作，再疊合接合的影像感測器。可各自使用適合的製程，使晶片更小、處理更快。

日文名稱: 積層型CMOSイメージセンサ

這個名詞所屬的領域: 影像感測器與光電元件
