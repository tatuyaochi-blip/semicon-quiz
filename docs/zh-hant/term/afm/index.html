什麼是AFM(原子力顯微鏡)

以尖銳的探針沿著試樣表面掃描，由探針與表面之間的作用力，量測表面細微起伏的顯微鏡。用於表面粗糙度的評估等。

日文名稱: AFM(原子間力顕微鏡)

「AFM(原子力顯微鏡)」出現在1領域的7道練習題中（量測與分析等）。

這個名詞所屬的領域: 量測與分析

練習AFM(原子力顯微鏡)的題目

原子力顯微鏡（AFM）主要量測的是下列何者？

  1. A片電阻
  2. B雜質濃度的深度方向分布
  3. C表面的微細凹凸（形狀與粗糙度）
查看答案與解析

正確答案：C. 表面的微細凹凸（形狀與粗糙度）

AFM以裝有尖銳探針的板彈簧（懸臂）沿表面描掃，一邊以雷射反射偵測原子間作用力造成的彎曲一邊掃描，量測表面的凹凸。在高度方向連0.1 nm左右的差異都能量測，因此用於評估CMP後的表面粗糙度與薄膜的表面狀態。若採用使探針振動並輕觸的輕敲模式（tapping mode），則較不易損傷試片。片電阻與摻雜物的分布以其他手法量測。

以AFM量測非常窄的溝槽或陡峭側壁的形狀時，容易成為誤差原因的是下列何者？

  1. AAFM只能在真空中使用
  2. B由於探針前端的粗細與形狀是有限的，量得的形狀會疊上探針的形狀而被呈現出來
  3. CAFM無法量測表面的凹凸
查看答案與解析

正確答案：B. 由於探針前端的粗細與形狀是有限的，量得的形狀會疊上探針的形狀而被呈現出來

AFM是以探針沿表面描掃來量測形狀，因此探針前端無法探到比它更細的溝槽底部，而在陡峭的側壁上則是探針的側面先接觸。結果量得的形狀是實際形狀與探針形狀的疊合，溝槽看起來較淺較窄，線條看起來較粗。因此要使用前端較細的探針，或前端向橫向擴展的側壁量測用探針，並進行推估探針形狀來補正的分析。
