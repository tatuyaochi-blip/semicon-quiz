什麼是DRAM(動態隨機存取記憶體)

以 1 個電晶體與 1 個電容儲存 1 位元，並須在電荷因漏電消失前定期更新的揮發性記憶體。用於個人電腦與伺服器的主記憶體。

日文名稱: DRAM(ダイナミックRAM)

「DRAM(動態隨機存取記憶體)」出現在16領域的93道練習題中（DRAM, 新世代記憶體, 半導體產業與市場等）。

這個名詞所屬的領域: DRAM

DRAM 的名稱與基本結構

DRAM 是 Dynamic Random Access Memory 的縮寫，中文稱為動態隨機存取記憶體。它以 1 個電晶體與 1 個電容構成的 1T1C 單元儲存 1 位元，以電容有無電荷表示 0 與 1。記憶單元以格子狀排列在字元線與位元線的交點；以字元線使電晶體導通，電容就會連接到位元線。「隨機存取」是指不論順序都能存取任一位址；「動態」則是因為所儲存的電荷會因漏電逐漸流失，必須定期重新寫入。

讀取與更新

讀取時，將記憶單元的電容連接到預先充電至約電源電壓一半的位元線，電荷分享後產生的微小電壓差由感測放大器放大，判定為 0 或 1。此時單元中的電荷會被破壞（破壞性讀取），因此以放大後的電壓寫回單元。電荷也會經由接面漏電與次臨界漏電流失，因此必須每隔一定時間讀出所有列並重新寫入，這稱為更新（refresh）。大致的標準是：DDR4 以前的規格在一般溫度範圍內須於 64 ms 內、DDR5 須於 32 ms 內更新所有列，高溫時間隔還要更短。

與 SRAM、快閃記憶體的差異

SRAM 以 6 個電晶體構成閂鎖電路，不需要更新，存取時間約 1 ns，但單元面積大、每位元成本高。DRAM 以小型的 1T1C 單元，密度可達 SRAM 的 20 倍左右，適合大容量的主記憶體；代價是需要啟動列等動作，存取時間為數十 ns。NAND 型快閃記憶體是關閉電源後資料仍會保留的非揮發性記憶體，容量更大、成本更低，但寫入與抹除較慢，改寫次數也有上限。因此系統以 SRAM 作為快取、DRAM 作為主記憶體、SSD 作為儲存裝置，構成記憶體階層。

產品種類與微縮的課題

DRAM 產品可分為個人電腦與伺服器用的 DDR SDRAM、智慧型手機等用的低功耗 LPDDR、繪圖用的 GDDR，以及以 TSV 堆疊多個晶粒、具有極寬匯流排的 HBM 等。微縮的核心課題是：即使單元縮小，電容仍須儲存足以判讀資料的電荷。為此陸續導入了細而深的圓筒形電容、高介電常數（high-k）絕緣膜，以及抑制漏電的埋入式字元線電晶體等技術。高密度化也帶來可靠度問題，例如反覆啟動某一列會使相鄰列資料翻轉的列鎚（Rowhammer）現象。

練習DRAM(動態隨機存取記憶體)的題目

下列何者是一般DRAM的1位元記憶單元的正確結構？

  1. A1個電晶體與1個電容
  2. B6個電晶體
  3. C具有浮動閘極的1個電晶體
查看答案與解析

正確答案：A. 1個電晶體與1個電容

DRAM的單元由1個電晶體與1個電容（1T1C）構成，依電容中有無電荷來記憶1位元。電容約為10 fF左右，非常小，僅憑數萬個電子的差異來區分0與1。由於元件數量少，單元面積小至約6F²，適合大容量化。6個電晶體是SRAM，具有浮動閘極的電晶體則是快閃記憶體的單元結構。

DRAM需要定期執行更新（refresh）動作的原因，下列何者正確？

  1. A為了提高讀取速度
  2. B因為寫入次數有上限
  3. C因為儲存在電容中的電荷會因漏電流而逐漸流失
查看答案與解析

正確答案：C. 因為儲存在電容中的電荷會因漏電流而逐漸流失

電容的電荷會因單元電晶體的次臨界漏電（subthreshold leakage）與接面漏電而一點一點流失。在資料無法判讀之前先讀出並重新寫入，就是更新，在DDR4以前的規格中要在64 ms內、DDR5則要在32 ms內將所有列輪過一遍。更新期間該記憶體區塊（bank）無法存取，也會消耗電力，因此容量越大負擔越重。寫入次數有上限是快閃記憶體的特徵。

常見問題

DRAM 是什麼的縮寫？

Dynamic Random Access Memory（動態隨機存取記憶體）的縮寫。由於所儲存的電荷會隨時間流失，必須定期更新，因此稱為「動態」，以區別於通電期間不需更新即可保持資料的 SRAM（Static RAM）。

DRAM 和 SRAM 有什麼不同？

DRAM 使用小型的 1T1C 單元，可做到大容量、低成本，但需要更新，存取需數十 ns。SRAM 使用 6 電晶體單元，不需要更新且速度快，但面積較大。因此主記憶體使用 DRAM，CPU 快取則使用 SRAM。

DRAM 關閉電源後資料會消失嗎？

會。DRAM 是揮發性記憶體，關閉電源後更新停止，電荷會因漏電而流失。不過若加以冷卻，資料可能殘留數秒至數分鐘，利用這點讀出記憶體中加密金鑰的冷開機攻擊（cold boot attack）已為人所知。
