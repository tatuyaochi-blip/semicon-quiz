什麼是CXL（Compute Express Link）

Compute Express Link 的縮寫。使用 PCI Express 的實體層，使 CPU 與加速器或記憶體裝置之間能在維持快取一致性的前提下共用記憶體的規格。

日文名稱: CXL

「CXL（Compute Express Link）」出現在2領域的4道練習題中（介面與匯流排規格, 新世代記憶體等）。

這個名詞所屬的領域: 介面與匯流排規格

CXL 誕生的原因

PCI Express（PCIe）能有效率地搬移資料，但無法讓裝置記憶體與 CPU 快取保持一致，因此軟體要與加速器共享資料時，必須複製緩衝區並清除（flush）或使快取失效。Compute Express Link（CXL）沿用 PCIe 的實體層、連接器與電氣訊號，並加入能維持快取一致性的協定，讓 CPU 能以一般的載入與儲存指令存取裝置記憶體。CXL 1.x 與 2.0 以 PCIe 5.0 的每通道 32 GT/s 速率運作，CXL 3.x 則提升至 PCIe 6.0 的 64 GT/s。

CXL 的三種協定

CXL.io 基本上就是 PCIe，負責裝置探索、組態設定、中斷與 DMA。CXL.cache 讓裝置能將 CPU 記憶體快取在自己的快取中，並由硬體維持一致性。CXL.mem 讓 CPU 能讀寫裝置所附的記憶體，彷彿它是系統記憶體的一部分。裝置通常分為三種類型：Type 1 裝置（如智慧網路卡）使用 CXL.io 與 CXL.cache；擁有自己記憶體的 Type 2 加速器使用全部三種；Type 3 記憶體擴充裝置則使用 CXL.io 與 CXL.mem。

記憶體擴充與記憶體池化

CPU 能直接連接的 DRAM 受其記憶體通道數與 DIMM 插槽數限制。CXL 記憶體擴充裝置透過 PCIe 型式的鏈路增加容量與頻寬，而透過 CXL 交換器，一個記憶體池可由多台伺服器共享，並分配到需要的地方。其存取延遲高於直接連接的 DRAM，常被比喻為存取另一個 CPU 插槽上的記憶體，因此作業系統通常將 CXL 記憶體呈現為獨立的 NUMA 節點，作為一個分層使用，並將經常存取的資料保留在本地 DRAM 中。

CXL 在記憶體階層中的位置

DRAM 與 NAND 快閃記憶體的存取時間相差約 1000 倍，分別為數十奈秒與數十微秒，儲存級記憶體（storage-class memory）便是為了填補這個差距而提出的。在 Intel 於 2022 年宣布停產以相變化記憶體為基礎的 Optane 產品之後，這個區間大多由儲存端的低延遲 SLC NAND，以及記憶體端經由 CXL 連接的 DRAM 所取代。CXL 也讓裝置上的記憶體控制器能使用 CPU 原生不支援的記憶體類型。

練習CXL（Compute Express Link）的題目

  2. B使用PCI Express的實體層，使CPU與加速器或記憶體裝置之間能進行保持快取一致性的記憶體共享之規格
  3. C新的無線區域網路規格
查看答案與解析

正確答案：B. 使用PCI Express的實體層，使CPU與加速器或記憶體裝置之間能進行保持快取一致性的記憶體共享之規格

在PCI Express中，裝置的記憶體與CPU的快取一致性無法由硬體維持，必須由軟體加以留意。CXL是在與PCI Express相同的實體層上，加入維持快取一致性的通訊，以及讓CPU像讀寫一般記憶體一樣讀寫裝置記憶體的通訊之規格。用於與加速器共享資料，以及擴充記憶體。

下列關於使用CXL的記憶體擴充（CXL記憶體）之優點，何者正確？

  1. A延遲必定比直接連接CPU的DRAM更小
  2. B即使切斷電源，資料也必定不會消失
  3. C可不受CPU記憶體通道數的限制而增加容量，或讓多部伺服器分享記憶體
查看答案與解析

正確答案：C. 可不受CPU記憶體通道數的限制而增加容量，或讓多部伺服器分享記憶體

可直接連接CPU的記憶體容量，上限取決於記憶體通道與插槽的數量。CXL記憶體可將記憶體裝置連接到PCI Express插槽等來增加記憶體，還能利用交換器讓多部伺服器彈性調配共用的容量。不過延遲比直接連接的DRAM大，因此要區分為階層來使用，例如將常用的資料放在直接連接的記憶體。

常見問題

CXL 是什麼的縮寫？

CXL 是 Compute Express Link 的縮寫，是建立在 PCI Express 實體層之上的開放互連標準，為 CPU、加速器與記憶體裝置之間加入具快取一致性的記憶體存取。

CXL 和 PCIe 有什麼差別？

兩者共用相同的實體層與插槽，但一般的 PCIe 傳輸不具快取一致性。CXL 加入了 CXL.cache 與 CXL.mem 協定，讓裝置與 CPU 能以載入/儲存語意一致地共享記憶體。

什麼是 CXL Type 3 裝置？

Type 3 裝置是記憶體擴充裝置，使用 CXL.io 與 CXL.mem 為主機提供額外的記憶體容量，本身不快取主機記憶體。
