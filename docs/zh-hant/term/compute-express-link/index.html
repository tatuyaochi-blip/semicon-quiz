什麼是CXL（Compute Express Link）

Compute Express Link 的縮寫。使用 PCI Express 的實體層，使 CPU 與加速器或記憶體裝置之間能在維持快取一致性的前提下共用記憶體的規格。

日文名稱: CXL

「CXL（Compute Express Link）」出現在2領域的4道練習題中（介面與匯流排規格, 新世代記憶體等）。

這個名詞所屬的領域: 介面與匯流排規格

練習CXL（Compute Express Link）的題目

下列關於CXL（Compute Express Link）的說明，何者正確？

  1. A用於在封裝內連接小晶片（chiplet）之間的規格
  2. B使用PCI Express的實體層，使CPU與加速器或記憶體裝置之間能進行保持快取一致性的記憶體共享之規格
  3. C新的無線區域網路規格
查看答案與解析

正確答案：B. 使用PCI Express的實體層，使CPU與加速器或記憶體裝置之間能進行保持快取一致性的記憶體共享之規格

在PCI Express中，裝置的記憶體與CPU的快取一致性無法由硬體維持，必須由軟體加以留意。CXL是在與PCI Express相同的實體層上，加入維持快取一致性的通訊，以及讓CPU像讀寫一般記憶體一樣讀寫裝置記憶體的通訊之規格。用於與加速器共享資料，以及擴充記憶體。

下列關於使用CXL的記憶體擴充（CXL記憶體）之優點，何者正確？

  1. A延遲必定比直接連接CPU的DRAM更小
  2. B即使切斷電源，資料也必定不會消失
  3. C可不受CPU記憶體通道數的限制而增加容量，或讓多部伺服器分享記憶體
查看答案與解析

正確答案：C. 可不受CPU記憶體通道數的限制而增加容量，或讓多部伺服器分享記憶體

可直接連接CPU的記憶體容量，上限取決於記憶體通道與插槽的數量。CXL記憶體可將記憶體裝置連接到PCI Express插槽等來增加記憶體，還能利用交換器讓多部伺服器彈性調配共用的容量。不過延遲比直接連接的DRAM大，因此要區分為階層來使用，例如將常用的資料放在直接連接的記憶體。
