什麼是C 波段

光纖通訊使用的波長 1530〜1565 nm 附近的頻帶。石英光纖的損耗最小(約 0.2 dB/km)，且可用摻鉺光纖放大器(EDFA)放大，因此用於長距離通訊與高密度波長多工(DWDM)。

日文名稱: Cバンド

這個名詞所屬的領域: 矽光子

為何是這個波長範圍

石英光纖的損耗主要來自瑞利散射與玻璃的紅外線吸收；前者隨波長增加而急遽下降（約與波長的四次方成反比），後者則在較長波長處上升。標準單模光纖的最小損耗約 0.2 dB/km，位於 1550 nm 附近，因此 100 km 的光纖只損耗約 20 dB。同樣重要的是，以 980 nm 或 1480 nm 雷射激發的摻鉺光纖放大器（EDFA），可在約 1530 至 1565 nm 的範圍內提供增益，在光域中同時放大所有通道，而不需將其轉換成電訊號。

C 波段與其他通訊波段的比較

ITU（國際電信聯盟）將光纖的低損耗區域劃分為多個波段：O（original，約 1260 至 1360 nm）、E、S、C（conventional，1530 至 1565 nm）、L（long，約 1565 至 1625 nm）與 U。在標準單模光纖中，色散在約 1310 nm（O 波段）附近接近零，這就是資料中心內部等短距離連結常使用它的原因。C 波段損耗較低且有 EDFA 增益，但色散較大。L 波段則使用適用於較長波長的放大器來擴充容量。

高密度波長多工

高密度波長多工（DWDM）將許多雷射配置在 ITU-T 所定義的頻率柵格上，以 193.1 THz 為基準，間隔例如 100 GHz（約 0.8 nm）或 50 GHz（約 0.4 nm）。C 波段約跨越 4.4 THz，因此在 100 GHz 間隔下可容納約 40 個通道，在 50 GHz 間隔下約 80 個。由於間隔如此狹窄，雷射波長必須保持穩定（通常透過溫度控制），濾波器、多工器與環形共振器也必須調整對準柵格。

C 波段中的色散與矽光子

標準單模光纖在 1550 nm 處的色散約為 17 ps/(nm·km)，會使脈衝在長距離中展寬。較舊的系統以特殊光纖補償色散；現代同調接收器則以數位訊號處理加以消除。對整合光子而言，C 波段的光子能量約 0.8 eV，低於矽的 1.12 eV 能隙，因此矽波導是透明的，而成長於矽上的鍺則作為光偵測器。不過，矽的熱光效應很強，會使環形共振波長每 °C 偏移約 0.07 至 0.08 nm。

常見問題

C 波段是哪個波長範圍？

C 波段（conventional band）涵蓋約 1530 至 1565 nm，以頻率表示約為 191.6 至 195.9 THz。

為什麼長距離光纖通訊使用 1550 nm？

石英光纖在此處的損耗最低，約 0.2 dB/km，而且摻鉺光纖放大器可在整個波段內放大訊號，不需轉換成電訊號。

O 波段和 C 波段有什麼不同？

約 1310 nm 的 O 波段在標準光纖中色散接近零，適合短距離連結；約 1550 nm 的 C 波段損耗較低且可進行光放大，適合長途與 DWDM 系統。
