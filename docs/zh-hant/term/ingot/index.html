什麼是晶棒

以CZ法等長成、尚未切成晶圓的圓柱狀單晶塊。切除兩端並研磨外周使直徑一致後，再切成薄片。

日文名稱: インゴット

「晶棒」出現在1領域的11道練習題中（矽晶圓等）。

這個名詞所屬的領域: 矽晶圓

晶棒如何長成

在柴可拉斯基（CZ）法中，高純度多晶矽在石英坩堝中加熱熔化，溫度略高於矽約 1414 °C 的熔點。將晶種浸入熔湯，一邊使晶種與坩堝朝相反方向旋轉，一邊緩慢向上提拉，讓軸周圍的溫度均勻，從而得到圓柱狀晶體。首先以細的晶頸讓差排向外長出消失，接著直徑經由肩部（晶冠）擴大，進入等徑的晶身。攝影機追蹤晶體與熔湯交界處明亮的彎月面光環，並調整提拉速度與加熱器功率，以維持直徑固定。

沿晶棒方向的摻雜與偏析

摻雜物加入熔湯中：p 型使用硼，n 型使用磷、砷或銻。大多數摻雜物的偏析係數 k 小於 1，也就是成長中的晶體所吸收的雜質比熔湯中含有的少，被排出的摻雜物在逐漸減少的熔湯中累積，因此晶棒較晚長成的部分摻雜濃度較高、電阻率較低。磷的 k 約為 0.35，砷約為 0.3，銻約為 0.023，而硼約 0.8 的數值使 p 型晶棒相當均勻。只有電阻率符合規格範圍的區段才會成為產品。

晶冠、尾部與缺陷控制

只有等徑的晶身會被使用；晶冠與尾部都會切除。在晶體離開熔湯前，尾部會刻意收細成圓錐狀，因為全直徑的晶體若突然分離，會因熱衝擊產生滑移差排，而這些差排可能向晶身回傳約一個直徑的距離。提拉速度也會影響晶體品質，因為成長速度與溫度梯度之比（V/G）決定了空位型或間隙型點缺陷何者占優勢，所以直徑控制不能犧牲這一點。從石英坩堝溶出的氧也會被摻入晶體，並沿晶棒進行量測。

從晶棒到晶圓

晶棒經過去頭尾、研磨至精確直徑，並加工出定向用的缺口（notch），較舊的尺寸則是平邊（flat）。接著以數百條平行、粗約 0.1 mm 的線鋸，在一次數小時的加工中將其切成數百片厚度略低於 1 mm 的晶圓。晶圓經過邊緣倒角、為取得平坦度而進行的研磨（lapping 或 grinding）、去除切割損傷層的蝕刻，以及拋光成鏡面，然後再清洗與檢查。不使用坩堝的浮區（FZ）法所生產的晶棒含氧量極低，適用於高電阻率與部分功率元件。

練習晶棒的題目

從單晶晶錠製作晶圓的製程順序，下列哪一項最為適當？

  1. A切片 → 研磨(研削) → 蝕刻 → 鏡面拋光
  2. B鏡面拋光 → 切片 → 蝕刻 → 研磨
  3. C蝕刻 → 鏡面拋光 → 切片 → 研磨
查看答案與解析

正確答案：A. 切片 → 研磨(研削) → 蝕刻 → 鏡面拋光

先研削晶錠外周使直徑一致，加工出缺口後，以多線鋸切成不到1 mm的厚度(切片)。經倒角後，以研磨或研削調整厚度與平坦度，再以蝕刻去除加工所產生的數十µm損傷層，最後以雙面拋光與精拋光做成接近原子等級的鏡面。之後經過清洗與檢查，以潔淨的出貨用容器(FOSB)出貨。

一次將矽晶錠切成多片晶圓時，一般使用的設備是哪一種？

  1. A切割刀片
  2. B多線鋸
  3. CCMP設備
查看答案與解析

正確答案：B. 多線鋸

多線鋸是將數百條直徑0.1 mm左右的細線平行拉緊並高速運行，利用含磨粒的漿液或固定了鑽石的線，一次把晶錠切成數百片晶圓的設備。切口損失只有0.1 mm等級，能減少材料浪費。切一根晶錠需要數小時。切割刀片則用於把完成的晶圓切成一顆顆晶片。

常見問題

矽晶圓為什麼是圓的？

CZ 晶體是邊旋轉邊提拉的，因此長成圓柱狀，切片後就是圓形晶圓。圓形基板也適合旋轉塗佈、拋光及其他以旋轉為基礎的製程。

矽晶棒如何切成晶圓？

研磨到所需直徑後，以多線鋸切片，利用帶有研磨漿料或固定鑽石的細線同時切出數百片晶圓。之後再以研磨、蝕刻與拋光去除切割損傷。

為什麼晶棒從頭到尾的電阻率會不同？

大多數摻雜物在晶體成長時會偏析到熔湯中，因此熔湯中的摻雜物濃度隨時間增加，晶棒底部最後摻雜濃度較高。偏析係數接近 1 的硼，這種效應最不明顯。
