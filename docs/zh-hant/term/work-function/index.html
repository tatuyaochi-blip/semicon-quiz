什麼是功函數

從真空能階到費米能階的能量差，是將電子從物質中取出所需的最小能量。左右金屬閘極的臨界電壓與蕭特基位障的高度。

日文名稱: 仕事関数

「功函數」出現在4領域的7道練習題中（半導體物性, MOSFET, 先進電晶體（FinFET與GAA）等）。

這個名詞所屬的領域: 半導體物性

功函數與電子親和力

功函數是從費米能階量到真空能階，而電子親和力則是從導電帶邊緣量到真空能階。在金屬中，費米能階位於能帶內，因此功函數是單一的材料特性，通常約為 4 至 6 eV，並在一定程度上取決於晶面與表面潔淨度。在半導體中，功函數等於電子親和力加上導電帶與費米能階之間的差距。矽的電子親和力約為 4.05 eV，因此其功函數範圍約從 4.05 eV（重摻雜 n 型）到 5.17 eV（重摻雜 p 型）。

蕭特基位障與接觸

當金屬與 n 型半導體接觸時，電子的理想（Schottky-Mott）位障高度為金屬功函數減去半導體的電子親和力。因此高功函數金屬在 n 型矽上應會形成整流性的蕭特基接觸。實際上，界面能態會釘扎費米能階，因此矽上的位障高度隨金屬變化的幅度遠小於簡單規則的預測。所以歐姆接觸主要是透過在接觸下方重摻雜來製作，使位障變薄，讓載子穿隧通過。

設定臨界電壓

在 MOS 結構中，閘極與通道功函數的差決定了平帶電壓，而平帶電壓直接加到臨界電壓上。多晶矽閘極會自動提供合適的值：nMOS 用接近導電帶的 n+ 多晶矽，pMOS 用接近價電帶的 p+ 多晶矽。採用 high-k 介電質後，金屬閘極取代了多晶矽，因此金屬必須提供 nMOS 約 4.1 eV（TiAl 等含鋁堆疊）、pMOS 約 5.1 eV（TiN 系堆疊）的有效功函數。FinFET 與環繞式閘極元件使用輕摻雜通道，因此堆疊薄層來調整有效功函數，是提供多種臨界電壓選項的主要方法。

為什麼後閘極製程有幫助

金屬閘極的有效功函數取決於其與 high-k 薄膜界面上的反應，而用來活化源極與汲極、約 1000 °C 的退火可能使其發生無法預測的偏移。因此後閘極（gate-last），也就是取代金屬閘極（replacement metal gate）流程，會先以犧牲性的多晶矽閘極建構電晶體，在高溫步驟之後將其移除，然後才沉積 high-k 與功函數金屬。功函數也支配熱離子發射與光電發射，可用光電子能譜或 Kelvin 探針技術量測。

練習功函數的題目

  1. A真空能階到導帶底端的能量差
  2. B導帶底端到價電帶頂端的能量差
  3. C真空能階到費米能階的能量差
查看答案與解析

正確答案：C. 真空能階到費米能階的能量差

功函數是將位於費米能階的電子取出到真空中所需的能量，即真空能階與費米能階的差。在半導體中，費米能階會隨雜質濃度而移動，因此功函數也會改變（矽約為4.05～5.17 eV）。金屬與半導體的功函數差會左右蕭特基能障和MOS的臨界電壓，金屬閘極的材料（TiN、TiAl等）則是依能得到目標臨界電壓的功函數來選擇。

常見問題

功函數和電子親和力有什麼差別？

功函數是從費米能階到真空能階的能量；電子親和力是從導電帶邊緣到真空能階的能量。在半導體中，電子親和力由材料決定，功函數則隨摻雜改變。

摻雜會改變矽的功函數嗎？

會。摻雜會移動費米能階，因此矽的功函數從重摻雜 n 型時約 4.05 eV，變化到重摻雜 p 型時約 5.17 eV。

為什麼閘極金屬的功函數會影響臨界電壓？

閘極與通道之間的功函數差決定了平帶電壓，而平帶電壓會使臨界電壓等量偏移。因此選擇或調整閘極金屬，就能在不需重摻雜通道的情況下設定臨界電壓。
