什麼是功函數

從真空能階到費米能階的能量差，是將電子從物質中取出所需的最小能量。左右金屬閘極的臨界電壓與蕭特基位障的高度。

日文名稱: 仕事関数

「功函數」出現在4領域的7道練習題中（半導體物性, MOSFET, 先進電晶體（FinFET與GAA）等）。

這個名詞所屬的領域: 半導體物性

練習功函數的題目

關於物質功函數的定義，下列何者正確？

  1. A真空能階到導帶底端的能量差
  2. B導帶底端到價電帶頂端的能量差
  3. C真空能階到費米能階的能量差
查看答案與解析

正確答案：C. 真空能階到費米能階的能量差

功函數是將位於費米能階的電子取出到真空中所需的能量，即真空能階與費米能階的差。在半導體中，費米能階會隨雜質濃度而移動，因此功函數也會改變（矽約為4.05～5.17 eV）。金屬與半導體的功函數差會左右蕭特基能障和MOS的臨界電壓，金屬閘極的材料（TiN、TiAl等）則是依能得到目標臨界電壓的功函數來選擇。

解析中的「功函數」

  • 功函數是將位於費米能階的電子取出到真空中所需的能量，即真空能階與費米能階的差。

    關於物質功函數的定義，下列何者正確？

  • 相對地，功函數是從費米能階到真空能階的差，會隨雜質濃度而改變。

    半導體的真空能階到導帶底端的能量差稱為什麼？

  • 不過濃度過高會使遷移率下降，變異（摻雜物數量的起伏）也會增加，因此FinFET與GAA將通道設為幾乎不摻雜，以功函數決定Vth。

    提高nMOSFET的通道區域（p型基板）的雜質濃度時，臨界電壓會如何變化？

  • 平帶電壓VFB是半導體表面的能帶不彎曲而變平時的閘極電壓，由 VFB = φms − Qox/Cox（功函數差，以及絕緣膜中、界面的電荷）決定。

    關於MOS結構的平帶電壓的說明，下列何者正確？

  • 在金屬閘極中，閘極電極金屬的功函數會改變平帶電壓，進而決定臨界電壓。
