什麼是空乏層

PN 接面邊界附近幾乎不存在載子的區域。施加逆向偏壓時會變寬。

日文名稱: 空乏層

「空乏層」出現在6領域的15道練習題中（MOSFET, 半導體物性, 先進電晶體（FinFET與GAA）等）。

這個名詞所屬的領域: PN接面與二極體

空乏層如何形成

當 p 型與 n 型區域相接時，電子從 n 側擴散、電洞從 p 側擴散，在接面附近復合。它們留下固定電荷：n 側為帶正電的游離施體，p 側為帶負電的游離受體。這些電荷建立起從 n 指向 p 的內建電場，將載子推回，使淨擴散停止。由此產生的內建電位，在矽接面中依摻雜而定，通常約為 0.6 到 0.9 V。這個區域也稱為空間電荷區，因為其主要特徵就是未被補償的固定電荷。

寬度及摻雜如何分配寬度

電荷中性要求 NA·xp = ND·xn，因此空乏層會向摻雜較淡的一側延伸得更遠。對陡接面而言，總寬度為 W = √(2ε(Vbi + V)/q × (1/NA + 1/ND))，其中 V 為逆向偏壓。在 p+n 接面中，這可簡化為 W ≈ √(2ε(Vbi + V)/(qND))，而且幾乎整個空乏層都位於 n 側。典型寬度約為 0.1 到 1 µm；例如 ND = 10¹⁶ cm⁻³ 在零偏壓下約為 0.3 µm。Vbi + V 變為四倍時，寬度變為兩倍。

空乏電容

由於這個區域幾乎不含可移動的載子，其行為就像平行板電容器中的絕緣體，C = εA/W。當逆向偏壓使 W 變寬時，電容會下降，對陡接面而言大致與 (Vbi + V)^-1/2 成正比。變容二極體就是利用這種由電壓控制的電容來進行調諧。電容－電壓剖析也使用相同的關係：將 1/C² 對逆向偏壓作圖，可由其斜率萃取出淡摻雜側的摻雜濃度。接面電容也會成為每個電晶體汲極與源極的負載，增加電路延遲。

PN 二極體以外的空乏

這個概念遍及整個元件物理。在反轉發生之前，閘極電壓會使 MOS 閘極下方的矽空乏。多晶矽閘極電極本身也會空乏，使等效氧化層厚度增加約 0.3 到 0.5 nm，這就是它被高介電常數／金屬閘極技術取代的原因。光二極體能有效收集在空乏區內由光產生的載子，因此 PIN 二極體會插入一層寬的本質層。功率元件使用淡摻雜的漂移層，讓寬的空乏區能承受高電壓。請注意，邊緣分明的圖像是空乏近似；實際的邊緣會在數個德拜長度內逐漸變化。

練習空乏層的題目

p型半導體的多數載子為下列何者？

  1. A離子化的受體
  2. B電洞
  3. C電子
查看答案與解析

正確答案：B. 電洞

在p型中，受體從價電帶接受電子而使電洞增加，因此多數載子是電洞，少數載子是電子。離子化的受體是固定在晶格上的負電荷，本身無法移動。不過在空乏層中，這種固定電荷是產生電場與內建電位的主角。在MOSFET中，是在p型基板表面聚集少數載子的電子（反轉）而形成n通道。

電子與電洞經由禁帶中形成的深能階（陷阱）而複合的過程稱為什麼？

  1. ASRH（蕭克利-里德-霍爾）複合
  2. B輻射複合
  3. C歐傑複合
查看答案與解析

正確答案：A. SRH（蕭克利-里德-霍爾）複合

金屬雜質或晶體缺陷所形成的深能階（陷阱）依序捕獲電子與電洞，使其複合的過程就是SRH複合。陷阱的能階越接近能隙中央，作用越有效率。在矽這類間接躍遷型中，它是主要的複合過程，決定了少數載子的生命期。空乏層內由SRH過程造成的產生，也是pn接面逆向漏電流和影像感測器暗電流的主要原因。

常見問題

為什麼空乏區在逆向偏壓下會變寬？

逆向偏壓會疊加在內建電位上，因此必須暴露出更多固定電荷來支撐更大的電壓。由於摻雜物密度是固定的，唯一能暴露更多電荷的方法就是讓更寬的區域空乏，其寬度大致與總電壓的平方根成正比。

空乏區和空間電荷區是一樣的嗎？

是的。兩個名稱指的是接面周圍同一個區域，在那裡幾乎沒有可移動的載子，游離的摻雜物留下淨固定電荷。

沒有施加電壓時，PN 接面也有空乏層嗎？

有。它在熱平衡狀態下，經由載子的擴散與復合形成，並由內建電位維持。順向偏壓會使其變窄，逆向偏壓則使其變寬。
