什麼是空乏層

PN 接面邊界附近幾乎不存在載子的區域。施加逆向偏壓時會變寬。

日文名稱: 空乏層

「空乏層」出現在6領域的15道練習題中（MOSFET, 半導體物性, 先進電晶體（FinFET與GAA）等）。

這個名詞所屬的領域: PN接面與二極體

練習空乏層的題目

p型半導體的多數載子為下列何者？

  1. A離子化的受體
  2. B電洞
  3. C電子
查看答案與解析

正確答案：B. 電洞

在p型中，受體從價電帶接受電子而使電洞增加，因此多數載子是電洞，少數載子是電子。離子化的受體是固定在晶格上的負電荷，本身無法移動。不過在空乏層中，這種固定電荷是產生電場與內建電位的主角。在MOSFET中，是在p型基板表面聚集少數載子的電子（反轉）而形成n通道。

電子與電洞經由禁帶中形成的深能階（陷阱）而複合的過程稱為什麼？

  1. ASRH（蕭克利-里德-霍爾）複合
  2. B輻射複合
  3. C歐傑複合
查看答案與解析

正確答案：A. SRH（蕭克利-里德-霍爾）複合

金屬雜質或晶體缺陷所形成的深能階（陷阱）依序捕獲電子與電洞，使其複合的過程就是SRH複合。陷阱的能階越接近能隙中央，作用越有效率。在矽這類間接躍遷型中，它是主要的複合過程，決定了少數載子的生命期。空乏層內由SRH過程造成的產生，也是pn接面逆向漏電流和影像感測器暗電流的主要原因。
