什麼是離散傅立葉轉換

把 N 個取樣值 x[0]～x[N − 1] 轉換成 N 個頻率成分 X[0]～X[N − 1] 的計算。定義為 X[k] = Σx[n]e^(−j2πkn/N)，第 k 個成分對應頻率 k·fs/N。頻率點的間隔 fs/N 是觀測時間的倒數，可作為頻率解析度的參考。對實數訊號，X[N − k] 是 X[k] 的共軛複數，因此 k = 0～N/2 就包含全部資訊。依定義計算約需 N² 次運算，以快速傅立葉轉換（FFT）可減少到約 N log₂N 次。簡稱DFT，與可測試性設計的DFT是不同的詞。

日文名稱: 離散フーリエ変換

「離散傅立葉轉換」出現在2領域的2道練習題中（數位訊號處理基礎, 無線通訊基礎等）。

這個名詞所屬的領域: 數位訊號處理基礎

DFT的前提

DFT以觀測的 N 點區間週期性重複的訊號為前提。若正弦波的週期恰好整數個落在區間內，該成分會落在1個頻率點；若不是整數個，區間兩端會被當作不連續相接，能量擴散到周圍的頻率點（頻譜洩漏）。因此量測時常在DFT之前乘上窗函數，使區間兩端平滑。

頻率點的讀法

k = 0 對應直流（所有取樣值的和），k = N/2 對應奈奎斯特頻率。k 超過 N/2 的頻率點對應負頻率，對實數訊號與第 k 個頻率點互為鏡像。例如 fs = 48 kHz、N = 1024 時，頻率點間隔為 46.875 Hz，1 kHz的成分出現在 k ≈ 21.3，即 k = 21 與22之間。

反轉換與帕塞瓦定理

以反轉換 x[n] = (1/N)ΣX[k]e^(j2πkn/N) 可正確還原原本的取樣值。係數 1/N 放在哪一邊依慣例而異，也有兩邊各放 1/√N 的定義。若 X[k] 如上定義，時間側與頻率側的能量之間成立 Σ|X[k]|² = N·Σ|x[n]|² 的關係（帕塞瓦定理）。

練習離散傅立葉轉換的題目

以1024點的離散傅立葉轉換（DFT）分析取樣頻率48 kHz的訊號。頻率點（bin）的間隔為下列何者？

  1. A約23.4 Hz
  2. B約46.9 Hz
  3. C約93.8 Hz
查看答案與解析

正確答案：B. 約46.9 Hz

N點DFT的頻率點間隔為 Δf = fs/N，48000 ÷ 1024 = 46.875 Hz ≈ 46.9 Hz。第k個頻率點對應頻率 k × Δf，k = 0 為直流，k = N/2 = 512 為奈奎斯特頻率24 kHz。Δf 也是觀測時間 T = N/fs ≈ 21.3 ms 的倒數，要使頻率點的間隔更細，必須加長觀測時間。

常見問題

離散傅立葉轉換與FFT有什麼不同？

DFT是「計算什麼」的轉換定義，FFT則是「快速計算它的方法（演算法）」。FFT的結果除了捨入誤差之外，與DFT依定義計算的值一致。N = 1024 時，運算次數約減為100分之1。

補零能提高頻率解析度嗎？

不能。補0會使頻率點的間隔變細，得到頻譜內插後的值，但沒有加入新的資訊，因此分辨相近頻率的能力仍由實際觀測的資料長度決定。要提高分辨能力，必須取得更長時間的資料。
