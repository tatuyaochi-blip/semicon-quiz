什麼是CMP侵蝕

CMP時，導線密集排列的整個區域連同絕緣膜被過度研磨，而比周圍更低的現象。與寬幅導線凹陷的碟形凹陷並列為代表性的不良。

日文名稱: エロージョン

這個名詞所屬的領域: CMP與清洗

密集陣列為何會發生侵蝕

在鑲嵌式銅化學機械研磨（CMP）中，為了不留下任何金屬殘留，研磨會持續到場區清空之後。在導線緊密排列的區域，導線之間狹窄的介電質條無法單獨撐住研磨墊，研漿便會連同銅一起移除阻障層與介電質。因此整個陣列會低於周圍的開放介電質區域。侵蝕量通常以陣列內相對於場區所損失的介電質厚度來量測，並隨金屬圖案密度與過研磨時間增加而增大。

侵蝕與碟形凹陷的差異

碟形凹陷發生在單一寬導線或焊墊內部：中央較軟的銅被研磨到低於相鄰的介電質，形成碟狀凹陷，其深度隨線寬增加。侵蝕則是跨越許多細導線、金屬與介電質一起下降的區域性效應，取決於密度而非線寬。在密集陣列中兩者會同時作用，因此銅的總損失厚度約為侵蝕量加上每條導線的碟形凹陷量。兩者常合併以 CMP 後的表面形貌來報告。

為何重要

銅變薄意味著導線電阻升高，且晶粒內的電阻分布變寬，進而使時序偏移。下凹的陣列也會把表面形貌傳遞到下一層：表面不再平坦，會吃掉微影的焦深；而為下一層沉積的金屬在其本身 CMP 後，可能殘留在低窪處，形成使相鄰導線短路的殘留物。因此，侵蝕限制了製程所能容許的過研磨量。

如何控制

佈局規則會將晶片各區域的金屬密度維持在一定範圍內，並在稀疏區域插入虛擬填充（dummy fill），使研磨面對的圖案更均勻。在製程方面，研磨會分成使用不同研漿的多個步驟：先進行大量去除銅的步驟，再進行阻障層步驟，其選擇比經過調整，可停止在介電質上；終點偵測則用來限制過研磨。較硬的研磨墊也能使壓力更均勻地分散於陣列上。

常見問題

CMP 的碟形凹陷和侵蝕有什麼不同？

碟形凹陷是單一寬圖形內部金屬的下凹，隨線寬增加。侵蝕則是密集陣列上金屬與介電質一起損失，隨圖案密度增加。

虛擬填充如何減少 CMP 侵蝕？

虛擬金屬圖形使圖案密度更均勻，研磨墊因此能在各處以更一致的速率移除材料。這可減少密集陣列與周圍區域之間的高度差。

在半導體製程中，erosion（侵蝕）還有其他意思嗎？

有。這個詞也用來指磁控濺鍍靶材上被磨耗出的跑道狀溝槽、蝕刻遮罩邊緣逐漸損失的現象，以及電漿對腔體壁與零件的磨耗。
