什麼是LPDDR

為 Low Power DDR 的縮寫。針對智慧型手機與筆記型電腦，強化低電源電壓與省電功能的 DRAM 規格。

日文名稱: LPDDR

「LPDDR」出現在2領域的2道練習題中（DRAM, 半導體產業與市場等）。

這個名詞所屬的領域: DRAM

省電效果從何而來

LPDDR（低功耗雙倍資料速率）DRAM以多種方式節省能源。其電源與I/O電壓低於桌上型電腦用的DDR，而介面的動態功耗與電壓平方成正比。元件閒置時，深度低功耗狀態會關閉大部分內部電路；部分陣列自我更新只更新存有資料的記憶庫（bank）；溫度補償自我更新則在晶片溫度低時延長更新間隔，因為DRAM記憶單元在低溫下漏電較慢。手機大部分時間都處於閒置狀態，因此這些待機功能與運作時的功耗同樣重要。

短距離的焊接式連接

LPDDR是為短距離點對點連接而設計的。DRAM堆疊在應用處理器上方（堆疊封裝，PoP），或直接焊接在其旁邊，因此走線只有數毫米長，所需的驅動能力很小。介面被分割成較窄的通道，自LPDDR4起為16位元寬，讓處理器能獨立存取多個通道。由於記憶體是焊接上去的，而非插在DIMM插槽中，採用LPDDR的筆電或手機，其容量通常在購買時就已固定，日後無法升級。

LPDDR與DDR、GDDR、HBM的比較

這四者都是JEDEC制定的DRAM標準，但最佳化的方向各不相同。DIMM上的標準DDR以桌上型電腦與伺服器的容量和可升級性為優先。LPDDR以每位元能耗與待機功耗為優先，適用於電池供電的裝置，同時仍能達到高資料速率；LPDDR5X可達8533 MT/s以上。GDDR追求顯示卡的單一接腳速度，HBM則在矽中介層上以極寬的介面堆疊晶粒，以獲得最大頻寬。LPDDR的世代編號與DDR並非一一對應：LPDDR4與DDR4使用不同的介面與協定。

  2. B寫入光碟
  3. C智慧型手機等要求低耗電的裝置
查看答案與解析

正確答案：C. 智慧型手機等要求低耗電的裝置

LPDDR（Low Power DDR）是以低電源電壓、深度省電模式、依溫度的更新控制等方式降低耗電的行動裝置用DRAM。用於智慧型手機、平板電腦、輕薄筆電，並疊在處理器的封裝上（PoP）或放在緊鄰處，以縮短佈線。由於是直接安裝在基板上而非模組，多半無法事後擴充，最新的LPDDR5X已達8533 MT/s以上。

常見問題

LPDDR是什麼的縮寫？

LPDDR是low-power double data rate（低功耗雙倍資料速率）的縮寫，是JEDEC發布的行動裝置用DRAM標準系列。雙倍資料速率是指在時脈的上升與下降兩個邊緣都傳輸資料。

LPDDR記憶體可以升級嗎？

通常不行。為了縮短配線，LPDDR會焊接在電路板上或堆疊在處理器封裝上，因此裝置製造完成時，搭載的容量就已固定。

LPDDR比DDR慢嗎？

不一定；近期的LPDDR世代可達到與桌上型DDR相當甚至更高的資料速率。主要的取捨在於容量受限於焊接式封裝，以及沒有可升級的模組。

出現這個名詞的比較

  • DDR、LPDDR、GDDR、HBM 的差異：DRAM 的種類比較從使用的設備、匯流排寬度、速度、頻寬、耗電量、封裝、容量與成本等面向，以表格比較 DDR、LPDDR、GDDR、HBM。
  • DDR4 與 DDR5 的差異：速度、結構與升級的判斷依據以速度、電壓、通道結構、突發長度、記憶庫、晶粒內 ECC、電源管理、延遲、頻寬與相容性等面向，用表格比較 DDR4 與 DDR5。
