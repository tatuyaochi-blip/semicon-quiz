什麼是簡併半導體

雜質濃度非常高，費米能階進入導電帶或價電帶之中的半導體。呈現接近金屬的性質，用於穿隧二極體與低電阻接觸。

日文名稱: 縮退半導体

「簡併半導體」出現在1領域的2道練習題中（半導體物性等）。

這個名詞所屬的領域: 半導體物性

半導體何時變成簡併

在非簡併的 n 型半導體中，Ec − EF ≈ kT·ln(Nc/ND)，其中 Nc 為導電帶的有效狀態密度，矽在室溫下約為 3×10¹⁹ cm⁻³。當施體濃度 ND 接近 Nc 時，此差距縮小到零，費米能階進入能帶。實務上，矽從約 10¹⁸～10¹⁹ cm⁻³ 以上就被視為簡併，常用的判準是費米能階位於能帶邊緣數個 kT 以內或進入能帶中。p 型摻雜與價電帶的情況也相同。

物理上有什麼改變

費米－狄拉克統計的簡單波茲曼近似不再成立，因此以它為基礎的公式（包括 n × p = ni²）會變得不準確。施體能階展寬成雜質能帶並與導電帶合併，能隙實質上縮小，這種效應稱為能隙窄化。載子在低溫下不再凍結，電阻率隨溫度的變化很小，很像金屬。然而遷移率很低，因為載子會受到高密度游離雜質的強烈散射。

簡併摻雜用於何處

MOSFET 的源極與汲極以簡併摻雜來將串聯電阻降到最低。在金屬－半導體接觸處，極高的摻雜使空乏區薄到載子能穿隧通過蕭特基能障，形成低電阻的歐姆接觸。穿隧（江崎）二極體在兩側都採用簡併摻雜，使電子在小順向偏壓下直接在能帶之間穿隧，產生負微分電阻。雙極電晶體的射極，以及氧化銦錫等透明導電氧化物，也是簡併摻雜材料的例子。

簡併與非簡併半導體

在非簡併半導體中，費米能階位於能隙中，載子密度透過簡單的指數公式隨摻雜密度變化，材料明顯具半導體性。在簡併半導體中，費米能階位於能帶中，計算載子密度需要費米－狄拉克積分，導電呈準金屬性。元件模擬器會相應地切換統計方式；在極高摻雜下套用非簡併公式，會算錯費米能階的位置並忽略能隙窄化，使計算出的內建電位與電流失真。

練習簡併半導體的題目

關於n型半導體費米能階的位置，下列何者正確？

  1. A位於比本質費米能階更靠近價電帶的一側
  2. B位於比本質費米能階更靠近導帶的一側
  3. C永遠位於價電帶之中
查看答案與解析

正確答案：B. 位於比本質費米能階更靠近導帶的一側

n型中導帶的電子較多，因此費米能階會從能隙中央附近的本質費米能階移向導帶側。其位置由 Ec − EF ≈ kT·ln(Nc/ND) 決定，施體濃度每增為10倍，費米能階在室溫下約再靠近導帶60 mV。p型則相反，移向價電帶側。費米能階並非永遠位於禁帶之中，濃度非常高時會進入能帶內（簡併半導體）。

雜質濃度非常高、費米能階進入導帶或價電帶之中的半導體，稱為什麼？

  1. A本質半導體
  2. B絕緣體
  3. C簡併半導體
查看答案與解析

正確答案：C. 簡併半導體

當雜質濃度非常高（矽中約10¹⁸～10¹⁹ cm⁻³以上）時，費米能階會進入導帶或價電帶之中，呈現接近金屬的性質。這就是簡併半導體，此時 n × p = ni² 這個簡單的式子不再成立，能隙在表觀上也會變小（能隙窄化）。MOSFET的源極、汲極，與電極的低電阻接觸，以及穿隧二極體的高濃度區域都是例子。

常見問題

矽在什麼摻雜濃度下會變成簡併？

大約在 10¹⁸～10¹⁹ cm⁻³ 以上，此時費米能階到達或進入導電帶或價電帶；確切的門檻取決於溫度與所用的判準。

為什麼接觸要做在重摻雜區域？

簡併摻雜使金屬下方的空乏區非常薄，載子能穿隧通過能障，將整流性的蕭特基接觸變為低電阻的歐姆接觸。

簡併半導體是金屬嗎？

它的行為幾乎像金屬，電阻率的溫度相依性很弱，但它仍是摻雜的半導體，載子密度與遷移率都低於真正的金屬。
