什麼是製程能力指數(Cpk)

表示製程的變異與平均值偏移，相對於規格範圍尚有多少餘裕的指標。1.33以上是一個參考標準。

日文名稱: 工程能力指数(Cpk)

「製程能力指數(Cpk)」出現在1領域的1道練習題中（先進技術（3D構裝與小晶片）等）。

這個名詞所屬的領域: 良率與品質管理

練習製程能力指數(Cpk)的題目

作為小晶片間連接效能的指標而受到重視，每單位晶片邊長可確保的資料傳輸量稱為什麼？

  1. AFIT
  2. B頻寬密度（每單位晶片邊長的傳輸速率）
  3. C製程能力指數
查看答案與解析

正確答案：B. 頻寬密度（每單位晶片邊長的傳輸速率）

小晶片之間多半是以沿著晶片邊緣排列的端子連接，因此每1 mm邊長能傳輸多少資料（頻寬密度，單位如Gb/s/mm）是重要的指標。同時，傳送1位元所需的能量（pJ/bit）也受到重視，封裝內的連接可比經由基板的連接低約一個數量級。FIT是故障率，製程能力指數是品質的指標。
