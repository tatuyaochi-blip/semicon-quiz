什麼是製程能力指數(Cpk)

表示製程的變異與平均值偏移，相對於規格範圍尚有多少餘裕的指標。1.33以上是一個參考標準。

日文名稱: 工程能力指数(Cpk)

「製程能力指數(Cpk)」出現在3領域的5道練習題中（良率與品質管理, 封裝與構裝, 先進技術（3D構裝與小晶片）等）。

這個名詞所屬的領域: 良率與品質管理

Cp與Cpk的計算公式

製程能力指數Cp比較規格寬度與製程本身的自然變異：Cp = (USL − LSL)/6σ，其中USL與LSL分別為規格上限與規格下限，σ為製程標準差。Cp假設製程平均值位於規格中心。Cpk則去除這項假設，以3σ為單位，衡量平均值到較近規格界限的距離：Cpk = min(USL − μ, μ − LSL)/3σ。平均值置中時Cpk等於Cp，只要有任何偏移，Cpk就會變小。

計算範例與常見目標值

假設規格為目標值±6，σ = 1，則Cp = 12/6 = 2。若平均值偏離中心3個單位，較近的界限只剩3個單位，因此Cpk = 3/3 = 1，即使Cp並未改變。Cpk = 1代表最近的界限距平均值3σ，常態分布中約有0.135%落在界限之外。常見的最低要求為Cpk ≥ 1.33，此時最近界限位於4σ，超出界限的比例只有數十ppm。關鍵參數可能要求1.67以上。

管制界限與規格界限

規格界限來自客戶或設計需求，定義可接受的產品範圍。管制圖上的管制界限則由製程本身的平均值與變異計算而來，用以發出異常狀況的警訊。製程可能處於統計管制狀態，卻因變異過大而產出超規品；也可能符合規格，卻因突發偏移而處於失控狀態。Cp與Cpk連結了這兩個面向，但只有在製程穩定時才有意義；以不穩定的資料計算Cpk，無法預測未來的產出。

實務上的注意事項

上述ppm的解讀以近似常態分布為前提，但微粒數或漏電流等物理量未必符合。對於單邊規格，只使用相關的那一半，例如只有上限時採用(USL − μ)/3σ。許多品質系統會區分Cpk與Ppk：Cpk由短期的子群組內變異計算，Ppk則由整體長期標準差計算，Ppk通常較低。在晶圓廠中，這些指數會針對關鍵尺寸、膜厚、疊對以及電性測試結果等參數持續追蹤。

練習製程能力指數(Cpk)的題目

當製程的平均值偏離規格中心時，應使用的製程能力指數是下列何者？

  1. ACp
  2. BCpk
  3. CMTTR
查看答案與解析

正確答案：B. Cpk

Cp是假設平均位於規格中心的指數，而Cpk是以平均到較近一側規格界限的距離除以3σ求得，因此也反映平均的偏移。例如規格±6、σ=1時，Cp=2；但若平均偏離規格中心3，則Cpk=(6−3)/3=1，會下降。當平均位於中心時，Cp與Cpk相等。MTTR是平均修復時間，屬於維護的指標。

常見問題

Cp和Cpk有什麼不同？

Cp比較規格寬度與6σ的製程變異，並假設平均值置中。Cpk則採用實際平均值到較近規格界限的距離，因此也會反映製程偏離中心的影響。

Cpk多少才算好？

Cpk達1.33以上，也就是最近的規格界限距平均值至少4σ，是廣泛採用的最低標準；關鍵特性則常要求1.67以上。

Cpk有可能比Cp大嗎？

不可能。平均值恰好置中時Cpk等於Cp，只要平均值往任一界限偏移，Cpk就會比Cp小。
