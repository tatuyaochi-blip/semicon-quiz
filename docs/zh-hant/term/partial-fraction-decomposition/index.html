什麼是部分分式展開

把分式形式的式子，分解成依分母各因式的簡單分式之和。在拉普拉斯轉換中，把 F(s) = 6/((s + 1)(s + 3)) 分解為 3/(s + 1) − 3/(s + 3)，各項分別對應 e^(−t) 與 e^(−3t)，查表即可得到時間函數 3e^(−t) − 3e^(−3t)。單極點 s = p 的係數，可把 s = p 代入 (s − p)F(s) 求得（留數）。

「部分分式展開」出現在1領域的3道練習題中（電路分析（交流電路、線性電路與暫態現象）等）。

這個名詞所屬的領域: 電路分析（交流電路、線性電路與暫態現象）

練習部分分式展開的題目

在圖中的RC電路，E = 10 V、R = 10 kΩ、C = 100 µF，電容器起初未充電。於 t = 0 閉合開關2秒後，電容器電壓 vC 最接近下列哪一項？

  1. A約6.3 V
  2. B約8.6 V
  3. C約9.5 V
查看答案與解析

正確答案：B. 約8.6 V

解法1（微分方程式）：電路方程式為 RC dvC/dt + vC = E，vC(0) = 0 的解為 vC(t) = E(1 − e^(−t/RC))。τ = RC = 10×10³ × 100×10⁻⁶ = 1 s，因此 vC(2) = 10(1 − e^(−2)) ≈ 10 × 0.865 ≈ 8.6 V。解法2（拉普拉斯轉換）：在s域中 VC(s) = (E/s) × (1/(sC))/(R + 1/(sC)) = E/(s(1 + sRC))，以部分分式展開為 E(1/s − 1/(s + 1/RC))，逆轉換後得到相同的式子。解法3（時間常數的大略值）：1τ 為63%，2τ 時再加上剩餘37%的63%，達到約86%，因此可估計約8.6 V。

在圖中的串聯RLC電路，E = 6 V、R = 4 Ω、L = 1 H、C = 1/3 F，初始值全部為0。於 t = 0 閉合開關後的電流 i(t) [A] 為下列哪一項？

  1. A3e^(−t) + 3e^(−3t)
  2. B3e^(−t) − 3e^(−3t)
  3. C6e^(−t) − 6e^(−3t)
查看答案與解析

正確答案：B. 3e^(−t) − 3e^(−3t)

解法1（拉普拉斯轉換與部分分式展開）：在s域中 I(s) = (E/s)/(R + sL + 1/(sC)) = 6/(s² + 4s + 3) = 6/((s + 1)(s + 3))。以部分分式展開為 I(s) = A/(s + 1) + B/(s + 3)，A = 6/(−1 + 3) = 3、B = 6/(−3 + 1) = −3，因此 i(t) = 3e^(−t) − 3e^(−3t) A。解法2（微分方程式）：由特性方程式 s² + 4s + 3 = 0 的根 −1、−3，設 i = Ae^(−t) + Be^(−3t)，由 i(0+) = 0（線圈電流的連續性）與 di/dt(0+) = E/L = 6 A/s 得 A + B = 0、−A − 3B = 6，解得 A = 3、B = −3。電流在 t = (ln 3)/2 ≈ 0.55 s 達到最大約1.15 A，電容器充電後回到0。
