什麼是串擾

因相鄰導線之間的電容耦合等，使其中一條訊號的變化以雜訊形式出現在另一條上的現象。可藉由加大導線間距或加入屏蔽導線來抑制。

日文名稱: クロストーク

「串擾」出現在2領域的2道練習題中（影像感測器與光電元件, LSI設計流程與EDA等）。

這個名詞所屬的領域: 配線製程

練習串擾的題目

在微細像素之間挖出深溝並填入絕緣物等的結構（DTI），其主要目的為下列何者？

  1. A防止光或電荷洩漏至相鄰像素（串擾）
  2. B增大像素
  3. C使彩色濾光片變得不必要
查看答案與解析

正確答案：A. 防止光或電荷洩漏至相鄰像素（串擾）

當像素變小，斜向入射的光或在較深處產生的電荷會進入相鄰像素，造成顏色混合或解析度下降。DTI（Deep Trench Isolation，深溝槽隔離）是在像素之間挖出深度數µm的溝槽，並填入氧化膜或金屬等以阻隔光與電荷，抑制這種串擾。多數採用從背面挖溝的方式，抑制溝槽側壁所產生暗電流的處理也很重要。

從佈局繞線後的佈局中取出佈線電阻與電容的製程，稱為什麼？

  1. A邏輯合成
  2. BATPG
  3. C寄生元件萃取（RC萃取）
查看答案與解析

正確答案：C. 寄生元件萃取（RC萃取）

寄生元件萃取是依據佈局中佈線的形狀、間距、與上下層的重疊，計算並取出佈線的電阻與電容。使用該數值，可以準確進行靜態時序分析、耗電量與串擾（crosstalk）的分析。隨著微縮，佈線延遲相對於單元延遲變得更大，重要性也日益提高。邏輯合成是產生邏輯閘，ATPG則是產生測試圖樣。
