什麼是串擾

因相鄰導線之間的電容耦合等，使其中一條訊號的變化以雜訊形式出現在另一條上的現象。可藉由加大導線間距或加入屏蔽導線來抑制。

日文名稱: クロストーク

「串擾」出現在2領域的2道練習題中（影像感測器與光電元件, LSI設計流程與EDA等）。

這個名詞所屬的領域: 配線製程

耦合雜訊如何產生

兩條相鄰的導線會形成一個電容器。當干擾線（aggressor）切換時，會透過耦合電容 Cc 將電荷注入受害線（victim）。若受害線處於浮接或只受到微弱驅動，產生的突波大約是干擾線的電壓擺幅乘以 Cc / (Cc + Cg)，其中 Cg 是受害線對地及對其他導線的電容。受到驅動的受害線會以其驅動器電阻決定的速度拉回原本的準位，因此驅動能力弱且平行走線長時，突波最大、持續最久。突波若傳到閂鎖器、時脈或動態節點，可能使儲存的值翻轉。

串擾也會改變延遲

即使沒有產生突波，串擾仍然重要，因為它會改變時序。若受害線與干擾線同時朝相同方向切換，Cc 兩端的電壓幾乎不變，耦合電容實際上等於消失，使受害線變快。若兩者朝相反方向切換，Cc 兩端的電壓變化為擺幅的兩倍，電容實際上加倍，這是一種米勒因子效應，會使受害線變慢。因此，考慮訊號完整性的靜態時序分析會利用萃取出的耦合電容與切換時窗，來界定最佳與最差情況。

為什麼微縮會讓情況惡化

導線的電容包括對同層相鄰導線的橫向成分、對上下層及基板的垂直成分，以及電場繞過導線邊緣形成的邊緣成分。以平行板近似 C = εS/d 來看，間距減半時橫向電容約加倍。先進的金屬層為了壓低電阻，採用窄間距與高導線，厚寬比約為 2，進一步擴大了相對的側壁面積。因此橫向耦合成為總電容中的主要部分，需在佈局繞線後以場解算器進行寄生萃取來量化。

降低串擾

主要手段是間距、屏蔽與介電常數。在關鍵訊號線上加大間距、在敏感訊號之間加入電源或接地屏蔽線，以及以摻碳氧化物（約 2.7–3.0）或多孔膜（約 2.2–2.5）等低介電常數（low-k）材料取代 SiO2（約 3.9），都能降低耦合。較強的受害線驅動器恢復較快，避免長距離平行走線則可限制耦合長度。這個詞的用法不限於配線：影像感測器的像素會將光與電荷洩漏到相鄰像素，多工取樣保持輸入也可能殘留前一個通道的電荷。

練習串擾的題目

在微細像素之間挖出深溝並填入絕緣物等的結構（DTI），其主要目的為下列何者？

  1. A防止光或電荷洩漏至相鄰像素（串擾）
  2. B增大像素
  3. C使彩色濾光片變得不必要
查看答案與解析

正確答案：A. 防止光或電荷洩漏至相鄰像素（串擾）

當像素變小，斜向入射的光或在較深處產生的電荷會進入相鄰像素，造成顏色混合或解析度下降。DTI（Deep Trench Isolation，深溝槽隔離）是在像素之間挖出深度數µm的溝槽，並填入氧化膜或金屬等以阻隔光與電荷，抑制這種串擾。多數採用從背面挖溝的方式，抑制溝槽側壁所產生暗電流的處理也很重要。

從佈局繞線後的佈局中取出佈線電阻與電容的步驟，稱為什麼？

  1. A邏輯合成
  2. BATPG
  3. C寄生元件萃取（RC萃取）
查看答案與解析

正確答案：C. 寄生元件萃取（RC萃取）

寄生元件萃取是依據佈局中佈線的形狀、間距、與上下層的重疊，計算並取出佈線的電阻與電容。使用該數值，可以準確進行靜態時序分析、耗電量與串擾（crosstalk）的分析。隨著微縮，佈線延遲相對於單元延遲變得更大，重要性也日益提高。邏輯合成是產生邏輯閘，ATPG則是產生測試圖樣。

常見問題

串擾分析中的 aggressor 和 victim 是什麼？

Aggressor（干擾線）是切換時注入雜訊的線，victim（受害線）則是透過耦合電容接收雜訊的相鄰線。同一條線在某個分析中可能是干擾線，在另一個分析中則可能是受害線。

晶片佈局中如何降低串擾？

加大間距、插入接地或電源屏蔽線、縮短平行走線，並加強受害線的驅動器。在製程層面，low-k 介電質可降低耦合電容。

晶片內的串擾是電容性還是電感性？

短距離與中距離導線的晶片內串擾以電容耦合為主。對於長距離高速的全域導線、封裝與電路板，電感耦合才會變得顯著。
