什麼是無限脈衝響應濾波器（IIR）

具有把過去的輸出送回輸入側的回授，脈衝響應無限延續的數位濾波器（無限脈衝響應濾波器）。以 y[n] = 0.2x[n] + 0.8y[n − 1]（指數平滑）這類差分方程式計算，轉移函數有分母。能以較少的係數與運算量得到陡峭的特性，延遲也小，但相位不是線性的。若不是所有極點都在單位圓內側就會不穩定，高階濾波器對係數量化較敏感，因此常以二階區段（biquad）的串接實作。常用的設計方法是以雙線性轉換從類比濾波器轉換。

練習無限脈衝響應濾波器（IIR）的題目

以指數平滑 y[n] = 0.2x[n] + 0.8y[n − 1] 表示的一階IIR低通濾波器，在直流與奈奎斯特頻率的增益組合為下列何者？

  1. A直流為1，奈奎斯特頻率為0
  2. B直流為5，奈奎斯特頻率約為0.56
  3. C直流為1，奈奎斯特頻率約為0.11
查看答案與解析

正確答案：C. 直流為1，奈奎斯特頻率約為0.11

轉移函數為 H(z) = 0.2/(1 − 0.8z⁻¹)，在直流（z = 1）為 0.2/(1 − 0.8) = 1，在奈奎斯特頻率（z = −1）為 0.2/(1 + 0.8) = 1/9 ≈ 0.11（約 −19 dB）。新的輸入乘上0.2、之前的輸出乘上0.8的權重後相加，權重和為1，因此固定的輸入原樣通過。只要記住前1個輸出，就能得到對過去輸入施加指數遞減權重的平均。極點 z = 0.8 位於單位圓內側，因此穩定；回授係數越接近1，平滑越強，響應也越慢。

以係數位元數有限的定點數實作高階IIR濾波器時，下列注意事項何者正確？

  1. AIIR濾波器的極點不受係數量化的影響，因此係數的位元數只要依通帶增益的精度決定即可
  2. B係數量化後也和FIR濾波器一樣一定穩定，因此即使階數高，也最好以單一差分方程式實作
  3. C把高階的分母以單一式子實作時，係數的誤差會使極點移動而可能不穩定，因此要分解成二階區段的串接
查看答案與解析

正確答案：C. 把高階的分母以單一式子實作時，係數的誤差會使極點移動而可能不穩定，因此要分解成二階區段的串接

高階多項式的根（極點）對係數的微小變化很敏感，尤其是極點聚集在單位圓附近的陡峭濾波器，光是把係數捨入，就可能使極點跑到單位圓外側。因此把濾波器分解成各負責2個極點的二階區段（biquad），以串接方式連接，各區段的係數誤差不會影響其他極點，對量化較有抵抗力。FIR濾波器在係數量化後仍然穩定，但頻率特性會改變。
