什麼是中斷處理常式

發生中斷或例外時CPU所執行的處理。儲存被中斷處理的狀態，依原因進行相應處理後，回到原本的處理。原則上處理要盡可能簡短。

日文名稱: 割り込みハンドラ

「中斷處理常式」出現在1領域的1道練習題中（CPU與架構等）。

這個名詞所屬的領域: 作業系統與硬體

練習中斷處理常式的題目

暫時中斷執行中的處理，並優先處理來自外部裝置等請求的 CPU 機制是下列何者？

  1. A中斷（interrupt）
  2. B管線
  3. C快取
查看答案與解析

正確答案：A. 中斷（interrupt）

中斷是指當鍵盤輸入、計時器、通訊接收等事件發生時，CPU 中斷執行中的處理，保存暫存器等狀態並執行對應的處理（中斷處理常式），結束後再回到原來狀態的機制。相較於 CPU 持續檢查周邊裝置狀態的方式（輪詢，polling），浪費較少，回應也更快。它還會設定優先順序，先處理重要的請求。
