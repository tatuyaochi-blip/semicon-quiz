什麼是雜訊指數（NF）

表示放大器或接收機等電路因自身雜訊使訊雜比（S/N）惡化多少的指標。輸入S/N除以輸出S/N的比（雜訊因數）以dB表示者，稱為雜訊指數（NF）。以溫度290 K的熱雜訊為基準定義。串接電路整體的值可用弗里斯公式求得，主要由第一級的雜訊指數與增益決定。

日文名稱: 雑音指数(NF)

「雜訊指數（NF）」出現在1領域的3道練習題中（無線通訊基礎等）。

這個名詞所屬的領域: 無線通訊基礎

定義與雜訊溫度

雜訊因數F是輸入S/N除以輸出S/N的比，定義為輸入雜訊為溫度290 K之熱雜訊時的值。沒有雜訊的理想電路F = 1（0 dB），NF = 10·log₁₀ F。同樣的性能也可以用把電路雜訊換算到輸入端的溫度表示，等效雜訊溫度為 Te = 290 × (F − 1) K。例如NF 1 dB約相當於75 K，NF 3 dB約相當於290 K，在衛星通訊接收機這類低雜訊的領域常使用雜訊溫度。

弗里斯公式

在雜訊因數F1、增益G1的電路後面，接上雜訊因數F2、增益G2，以及F3的電路時，整體的雜訊因數為 F = F1 + (F2 − 1)/G1 + (F3 − 1)/(G1·G2) + …（全部為真值）。後級的雜訊會被其前方的增益除掉，因此在第一級放置雜訊指數小、增益大的LNA很重要。反之，天線與LNA之間的纜線或濾波器的損耗（L dB），會直接使雜訊指數惡化同樣的量。

與半導體元件的關係

LNA的雜訊指數由電晶體的熱雜訊、散粒雜訊、閘極或基極電阻等決定。在高頻下特別要求低雜訊指數的用途，一直使用電子遷移率高的GaAs或InP HEMT。另一方面，微縮的CMOS LNA在數GHz以下的手機與無線區域網路中也已能得到足夠的性能，並整合在收發器中。

練習雜訊指數（NF）的題目

接收機的第一級放置雜訊指數1.5 dB、增益15 dB的LNA，其後接上雜訊指數10 dB的電路。兩級整體的雜訊指數最接近下列何者？

  1. A1.5 dB
  2. B2.3 dB
  3. C11.5 dB
查看答案與解析

正確答案：B. 2.3 dB

串接電路的雜訊指數以弗里斯公式 F = F1 + (F2 − 1)/G1 求得，F（雜訊指數）與G（增益）要使用真值。F1 = 10^0.15 ≈ 1.41、F2 = 10、G1 = 10^1.5 ≈ 31.6，因此 F ≈ 1.41 + 9/31.6 ≈ 1.70，換算成dB為 10·log₁₀(1.70) ≈ 2.3 dB。後級的雜訊會被第一級的增益除掉，因此第一級的增益越大，影響越小。因此，接收機的雜訊性能主要由第一級的LNA決定。

設溫度290 K時熱雜訊的功率密度為−174 dBm/Hz。頻寬1 MHz、雜訊指數6 dB的接收機，解調所需的S/N為10 dB時，接收靈敏度（可接收的最小訊號功率）最接近下列何者？

  1. A−114 dBm
  2. B−108 dBm
  3. C−98 dBm
查看答案與解析

正確答案：C. −98 dBm

頻寬1 MHz的熱雜訊功率為 −174 + 10·log₁₀(10⁶) = −174 + 60 = −114 dBm。視為雜訊增加了接收機雜訊指數的量，換算到輸入端的雜訊功率為 −114 + 6 = −108 dBm。還需要比它大10 dB S/N的訊號，因此接收靈敏度為 −108 + 10 = −98 dBm。縮小頻寬，或降低雜訊指數或所需的S/N，接收靈敏度就會變好（數值更小）。

常見問題

雜訊指數3 dB是什麼意思？

表示通過電路後S/N惡化3 dB（約1/2）。換算到輸入端，相當於電路加入了與輸入熱雜訊同樣大小的雜訊。接收機的雜訊指數降低3 dB，接收靈敏度就改善3 dB。

混頻器或濾波器的損耗也會影響雜訊指數嗎？

會。匹配良好之被動損耗（濾波器或纜線）的雜訊指數，大約等於其損耗的dB值。放在LNA之前，該損耗會直接加到整體的雜訊指數上。放在LNA之後，依弗里斯公式會被LNA的增益除掉，影響變小。
