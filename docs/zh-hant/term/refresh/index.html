什麼是更新(Refresh)

在 DRAM 電容的電荷因漏電而消失之前，定期讀出資料並重新寫入的動作。

日文名稱: リフレッシュ

「更新(Refresh)」出現在18領域的62道練習題中（DRAM, 多核心與同步, 硬體描述語言與驗證等）。

這個名詞所屬的領域: DRAM

DRAM 為什麼需要更新

DRAM 記憶單元把一個位元以電荷形式儲存在小電容上，並透過一顆存取電晶體來存取（1T1C 單元）。即使電晶體處於關閉狀態，電荷仍會經由其次臨界電流，以及儲存節點的接面漏電而流失，包括閘極引發汲極漏電（GIDL）與缺陷輔助的載子產生。資料保存時間因單元而異，而最弱的一小群尾端單元決定了更新週期。因此標準要求在一般溫度範圍內，每一列都必須在約 64 ms 內完成更新。相對地，SRAM 以交叉耦合的閂鎖器保存資料，只要有供電就不需要更新。

更新如何進行

讀取 DRAM 單元是破壞性的：單元會與電容大得多的位元線分享電荷，感測放大器在判別數十毫伏的差異的同時，把完整位準寫回去。因此只要啟動某一列再關閉，就能更新該列的所有單元。在 DDR4 中，控制器在每個 64 ms 時間窗內發出 8,192 次更新命令，約每 7.8 µs 一次（tREFI），每次命令會在內部更新數列。每次命令會使該記憶庫（bank）忙碌 tRFC 的時間，而 tRFC 隨容量增加，16 Gbit 元件可達數百奈秒。

溫度、容量與功耗

漏電隨溫度上升而增加，經驗法則是溫度每升高 10 °C，保存時間約減半，因此 DDR 標準在 85 °C 以上會把更新間隔減半，DDR4 為 3.9 µs。容量越大的晶片要更新的列越多，更新佔用的時間與功耗比例也越來越高，在高密度元件中會損失數個百分點、最多約 10% 的效能；逐記憶庫更新（per-bank refresh）可讓其他記憶庫在此期間仍可使用。待機時，自我更新（self-refresh）讓 DRAM 依內部計時器自行更新，控制器則進入休眠；低功耗 DRAM 還加入了依溫度調整的更新與部分陣列更新。

與更新相關的可靠度問題

有些單元會出現可變保存時間（VRT）：某個缺陷切換狀態，使其漏電在不同數值之間跳動，因此通過測試的單元日後可能變弱；這由更新裕度與 ECC 來涵蓋。Row hammer 是另一項威脅：在一個更新時間窗內對某一列啟動數萬次，可能讓相鄰列的電荷流失而發生位元翻轉，這已被用於安全攻擊。DRAM 與控制器的對策是對頻繁啟動之列的相鄰列進行更新，例如透過目標列更新（target row refresh）及 DDR5 的更新管理命令等機制。

練習更新(Refresh)的題目

DRAM需要定期執行更新（refresh）動作的原因，下列何者正確？

  1. A為了提高讀取速度
  2. B因為寫入次數有上限
  3. C因為儲存在電容中的電荷會因漏電流而逐漸流失
查看答案與解析

正確答案：C. 因為儲存在電容中的電荷會因漏電流而逐漸流失

電容的電荷會因單元電晶體的次臨界漏電（subthreshold leakage）與接面漏電而一點一點流失。在資料無法判讀之前先讀出並重新寫入，就是更新，在DDR4以前的規格中要在64 ms內、DDR5則要在32 ms內將所有列輪過一遍。更新期間該記憶體區塊（bank）無法存取，也會消耗電力，因此容量越大負擔越重。寫入次數有上限是快閃記憶體的特徵。

在一般的DRAM規格中，規定為將所有單元輪流更新一遍的週期，最接近下列何者？（一般溫度範圍）

  1. A約64 ms
  2. B約64 µs
  3. C約64 s
查看答案與解析

正確答案：A. 約64 ms

在DDR3或DDR4中，規定在一般溫度範圍內，要於約64 ms內更新所有的列。實際上，是在這段時間內將更新指令分成8192次發出（DDR4約每7.8 µs一次，即tREFI），每次一併更新多列。DDR5與LPDDR4/5的間隔縮短為約3.9 µs，一輪約為32 ms，但選項中最接近的是64 ms。每次更新所需的時間（tRFC）隨容量增加，16 Gbit時為數百ns。

常見問題

DRAM 多久需要更新一次？

標準 DDR DRAM 在一般溫度下，必須在約 64 ms 內更新每一列，分散在 8,192 次更新命令中完成。超過 85 °C 時，間隔通常會減半。

SRAM 需要更新嗎？

不需要。SRAM 把每個位元儲存在交叉耦合的閂鎖器中，只要有供電就會主動保持狀態。DRAM 需要更新，是因為它把位元以電荷形式儲存在會漏電的電容上。

DRAM 的自我更新模式是什麼？

這是一種低功耗模式，DRAM 以內部計時器自行更新，因此可以停止外部時脈與記憶體控制器。它能在手機或電腦休眠時保存資料。
