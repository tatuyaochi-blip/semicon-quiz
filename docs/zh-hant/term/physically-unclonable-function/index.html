什麼是PUF（物理不可複製函數）

利用各晶片製造上的差異，產生該晶片獨有且難以複製之值的機制。不必保存金鑰即可產生出來。

日文名稱: PUF(物理的複製困難関数)

「PUF（物理不可複製函數）」出現在1領域的6道練習題中（硬體安全等）。

這個名詞所屬的領域: 硬體安全

練習PUF（物理不可複製函數）的題目

下列關於PUF（物理不可複製函數）的說明，何者正確？

  1. A利用各晶片製造上的差異，產生該晶片專屬且難以複製之值的機制
  2. B對所有晶片寫入相同值的機制
  3. C印在晶片表面的產品編號
查看答案與解析

正確答案：A. 利用各晶片製造上的差異，產生該晶片專屬且難以複製之值的機制

即使是相同設計的晶片，電晶體的臨界電壓與佈線的延遲，也會因製造差異而有些微不同。PUF讀出這些差異，產生每個晶片各不相同的值。由於差異連製造方都無法控制，要製造出具有相同值的晶片十分困難。用於機器認證，或作為產生金鑰的來源。

下列關於使用PUF保管金鑰的優點，何者正確？

  1. A金鑰的值可由使用者自由選擇
  2. B金鑰即使斷電也一定會留在記憶體中
  3. C不需要將金鑰寫在非揮發性記憶體中，而是在使用時才產生，因此即使晶片被分析也不易被取出
查看答案與解析

正確答案：C. 不需要將金鑰寫在非揮發性記憶體中，而是在使用時才產生，因此即使晶片被分析也不易被取出

若把金鑰寫在快閃記憶體或eFuse中，就會成為打開晶片直接讀取記憶內容之攻擊的目標。若使用PUF，金鑰是每次使用時由晶片的物理性質產生，斷電期間不會儲存在任何地方。此外，若為了讀取PUF的值而加工晶片，差異本身的性質就會改變，因此要取出會更加困難。

解析中的「PUF（物理不可複製函數）」

  • PUF讀出這些差異，產生每個晶片各不相同的值。

    下列關於PUF（物理不可複製函數）的說明，何者正確？

  • 若使用PUF，金鑰是每次使用時由晶片的物理性質產生，斷電期間不會儲存在任何地方。

    下列關於使用PUF保管金鑰的優點，何者正確？

  • PUF的值由製造差異決定，但在兩個候選之差很小的記憶胞中，值可能會因溫度、電壓與雜訊而在每次讀取時改變。

    下列關於由PUF產生金鑰時，要搭配錯誤更正機制（輔助資料等）的原因，何者正確？

  • 此外，也有把以PUF產生的金鑰加密後之金鑰放在快閃記憶體中的方法。

    下列何者是一般用來把金鑰寫入晶片內保存的方法？

  • 藉由寫入PUF或eFuse、製造時注入金鑰等方式，安全地讓每台機器持有專屬的金鑰。
