什麼是PUF（物理不可複製函數）

利用各晶片製造上的差異，產生該晶片獨有且難以複製之值的機制。不必保存金鑰即可產生出來。

日文名稱: PUF(物理的複製困難関数)

「PUF（物理不可複製函數）」出現在1領域的6道練習題中（硬體安全等）。

這個名詞所屬的領域: 硬體安全

晶片獨有的數值從何而來

從晶圓廠製造出來的電晶體沒有兩個是完全相同的：臨界電壓、閘極尺寸與導線延遲在各晶片之間都有隨機差異。物理不可複製函數（PUF）將這些差異放大成位元。SRAM PUF 讀取每個單元在上電時穩定於哪一邊，這由其兩個交叉耦合反相器中較強的一方決定。環形振盪器 PUF 比較名義上相同之振盪器的頻率。仲裁器 PUF 讓訊號沿兩條路徑競速（路徑配置由挑戰值設定），並記錄哪一條先抵達。由於這些差異是隨機且無法控制的，即使製造商也無法製作出具有指定回應的晶片。

從含雜訊的位元到穩定的金鑰

PUF 的回應並非完全可重現。兩種結果幾乎勢均力敵的單元或路徑，可能隨溫度、電源電壓、雜訊與老化而翻轉，但密碼金鑰每次都必須逐位元完全相同。因此在註冊時，晶片會記錄回應並計算輔助資料，也就是供錯誤更正碼使用的公開資訊。每次使用時重新讀取 PUF，錯誤更正碼藉助輔助資料修正翻轉的位元，再經由雜湊或金鑰衍生步驟產生最終金鑰。這種常被稱為模糊萃取器的架構，其設計使輔助資料不會洩漏金鑰。

PUF 與 eFuse、OTP 金鑰儲存的比較

傳統做法是將每個元件專屬的金鑰寫入一次性可程式化的 eFuse 或 OTP 記憶體，理想上只有加密引擎能讀取。這些位元永久存在，可能成為攻擊目標：打開封裝後對儲存區進行探測或成像。使用 PUF 時，金鑰只在需要時重新產生，斷電時不存在於任何地方，而侵入式探測往往會擾動定義金鑰的那些差異本身。常見的混合方式是將金鑰儲存在快閃記憶體中，並以 PUF 衍生的金鑰加密。無論採用哪種方式，限制金鑰的讀取路徑都是不可或缺的。

品質指標與限制

PUF 以以下指標評估：唯一性，即不同晶片回應之間的漢明距離，理想值為 50%；可靠性，即同一晶片多次讀取之間變化的位元有多少；均勻性，即 0 與 1 的平衡程度。SRAM PUF 等弱 PUF 只提供少數挑戰－回應對，適合金鑰產生。仲裁器 PUF 等強 PUF 提供非常多的挑戰－回應對，可用於認證，但其回應往往可透過機器學習建模攻擊，從觀察到的挑戰－回應對中學習出來。旁通道洩漏與輔助資料竄改則是另外的攻擊面。

  2. B對所有晶片寫入相同值的機制

查看答案與解析

正確答案：A. 利用各晶片製造上的差異，產生該晶片專屬且難以複製之值的機制

即使是相同設計的晶片，電晶體的臨界電壓與佈線的延遲，也會因製造差異而有些微不同。PUF讀出這些差異，產生每個晶片各不相同的值。由於差異連製造方都無法控制，要製造出具有相同值的晶片十分困難。用於機器認證，或作為產生金鑰的來源。

  1. A金鑰的值可由使用者自由選擇
  2. B金鑰即使斷電也一定會留在記憶體中
  3. C不需要將金鑰寫在非揮發性記憶體中，而是在使用時才產生，因此即使晶片被分析也不易被取出
查看答案與解析

正確答案：C. 不需要將金鑰寫在非揮發性記憶體中，而是在使用時才產生，因此即使晶片被分析也不易被取出

若把金鑰寫在快閃記憶體或eFuse中，就會成為打開晶片直接讀取記憶內容之攻擊的目標。若使用PUF，金鑰是每次使用時由晶片的物理性質產生，斷電期間不會儲存在任何地方。此外，依PUF的種類，若為了讀取值而加工晶片，差異本身的性質就會改變，因此要取出會更加困難。

常見問題

PUF 用在什麼地方？

PUF 提供晶片獨有的數值，用於元件認證，以及在不將金鑰永久儲存於非揮發性記憶體的情況下衍生密碼金鑰。它們用於安全微控制器、FPGA 以及其他需要硬體信任根的晶片。

PUF 和亂數產生器一樣嗎？

不一樣。真亂數產生器每次都必須產生新的、不可預測的位元，而 PUF 則必須在每次讀取時重現相同的晶片專屬數值。不過有些設計會把不穩定的 SRAM 單元另外拿來作為熵來源。

為什麼 SRAM PUF 需要錯誤更正？

有一部分 SRAM 單元幾乎處於平衡狀態，上電時的結果會隨溫度、電壓與雜訊而不同。利用輔助資料進行錯誤更正，可修正這些會翻轉的位元，使衍生出的金鑰每次都相同。
