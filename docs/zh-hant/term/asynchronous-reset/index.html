什麼是非同步重設（Asynchronous reset）

與時脈無關，重設訊號一旦有效就立即初始化正反器的重設。解除時基本上要與時脈同步。

日文名稱: 非同期リセット

「非同步重設（Asynchronous reset）」出現在1領域的2道練習題中（時序分析與CDC等）。

這個名詞所屬的領域: 硬體描述語言與驗證

非同步重設的寫法

在 Verilog 中，非同步重設會與時脈一起出現在敏感列表中，例如 always @(posedge clk or negedge rst_n) 之後接著 if (!rst_n) q <= 0; else q <= d;。由於 rst_n 的下降緣也會觸發該區塊，q 會在重設生效的瞬間清除，不必等待時脈邊緣。字尾 _n 是表示低態有效訊號的常見命名慣例。邏輯合成會將此模式對應到具有專用重設或清除腳位的正反器，因此重設不會經過資料路徑的邏輯。

非同步重設與同步重設

同步重設只是另一個在時脈邊緣被取樣的輸入：它經過正反器 D 輸入前方的邏輯，只有在時脈運作時才會生效。這讓時序分析很簡單，但無法初始化時脈已停止的區塊，也會在資料路徑上增加邏輯。非同步重設則使用正反器的重設腳位，即使沒有時脈也能立即生效，這在上電時或時脈被閘控時很有用。它的弱點在於解除的時間點，這個時間點有其自身的時序要求。

重設解除的問題

正反器規定了恢復時間（recovery time）與移除時間（removal time），它們對非同步重設的解除所扮演的角色，相當於建立時間與保持時間。若重設在太接近時脈邊緣時解除，正反器可能進入亞穩態，或者重設網路中不同位置的正反器會在不同的時脈週期離開重設狀態。若狀態機各位元的起始相差一個週期，就可能從非法狀態開始運作。由於外部重設來源與時脈無關，若不將解除同步化，就無法排除這種情況。

非同步觸發、同步解除

常見的解決方法是重設同步器：由目的時脈驅動的兩個串聯正反器，其非同步重設腳位由外部重設驅動，第一級的資料輸入則接到非有效準位。觸發重設時兩級會同時清除，因此重設依然立即生效。解除時，非有效準位必須依序通過兩個正反器，因此分配出去的重設會與時脈同步解除，而第二級則給第一級時間來脫離亞穩態。每個時脈域都需要自己的同步器。

練習非同步重設（Asynchronous reset）的題目

在帶非同步重設的正反器中，以STA檢查重設解除是否太接近時脈邊緣的是哪一項？

  1. A時脈閘控檢查
  2. B恢復（recovery）檢查與移除（removal）檢查
  3. C最大轉換時間（max transition）的檢查
查看答案與解析

正確答案：B. 恢復（recovery）檢查與移除（removal）檢查

非同步重設的解除與資料輸入一樣，必須與時脈邊緣相隔一定的時間。檢查解除是否太接近邊緣之前的是恢復檢查（相當於建立時間），檢查是否太接近邊緣之後的是移除檢查（相當於保持時間）。若發生違規，重設是否在該週期解除就無法確定，各正反器開始動作的週期會錯開。轉換時間的檢查是檢查訊號波形的鈍化，目的不同。

常見問題

同步重設和非同步重設有什麼差別？

同步重設只在有效時脈邊緣生效，需要時脈在運作；非同步重設則經由正反器的重設腳位立即生效，與時脈無關。

為什麼非同步重設的解除要同步化？

若重設在時脈邊緣附近解除，正反器可能違反恢復或移除時序、進入亞穩態，或在不同週期離開重設狀態；兩級正反器的同步器能讓解除與時脈對齊。

恢復時間（recovery time）和移除時間（removal time）是什麼？

它們是非同步重設必須在有效時脈邊緣之前解除（恢復時間）或之後維持（移除時間）的最短時間，類似於資料的建立時間與保持時間。
