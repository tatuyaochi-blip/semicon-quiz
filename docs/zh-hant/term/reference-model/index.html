什麼是參考模型（Reference model）

以 C 語言等另外撰寫、與電路功能相同的模型。給予相同輸入並比較結果，作為電路輸出的期望值。亦稱黃金模型。

日文名稱: 参照モデル

「參考模型（Reference model）」出現在1領域的1道練習題中（硬體描述語言與驗證等）。

這個名詞所屬的領域: 硬體描述語言與驗證

練習參考模型（Reference model）的題目

在驗證中，使用以C語言等撰寫的參考模型（黃金模型，golden model）的目的，下列何者正確？

  1. A作為製造電路用的設計圖，直接交給工廠
  2. B以另一種方法計算與電路相同的功能，並將其結果作為期望值與電路的輸出比較
  3. C使電路的動作變慢，讓它更容易觀察
查看答案與解析

正確答案：B. 以另一種方法計算與電路相同的功能，並將其結果作為期望值與電路的輸出比較

參考模型是不在意時序，以軟體直接地撰寫電路應實現的功能。將相同的輸入同時給予電路與參考模型並比較結果，即使是大量的隨機輸入，也能自動產生期望值。若由與設計相同的人根據相同的誤解來製作，就會漏掉錯誤，因此獨立於規格書來製作是很重要的。
