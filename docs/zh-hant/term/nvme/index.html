什麼是NVMe

用於高速操作以 PCI Express 連接之 SSD 的介面規格。可平行處理大量指令，延遲比為 HDD 設計的 SATA 更小。

日文名稱: NVMe

「NVMe」出現在2領域的3道練習題中（SRAM與快閃記憶體, 介面與匯流排規格等）。

這個名詞所屬的領域: SRAM與快閃記憶體

SSD為何需要新介面

SATA SSD使用AHCI，這是為硬碟設計的主機介面：只有一個最多容納32個指令的指令佇列，而且連結速度上限約600 MB/s。快閃記憶體能平行處理大量請求，因此這成了瓶頸。NVMe（NVM Express）是專為直接連接到PCI Express的非揮發性記憶體所設計的協定。它最多支援64K個I/O佇列，每個佇列深度最多64K個指令，採用精簡的指令集，並讓每個CPU核心擁有自己的佇列，減少軟體負擔與鎖定競爭。

提交佇列與完成佇列

NVMe佇列是位於主機記憶體中的環狀緩衝區。要發出讀取或寫入時，驅動程式將一個64位元組的指令放入提交佇列，並將新的尾端位置寫入元件上的門鈴（doorbell）暫存器。控制器以DMA擷取指令，直接在主機記憶體之間搬移資料，並將一筆16位元組的項目寫入成對的完成佇列，通常以MSI-X中斷通知主機。接著主機寫入完成佇列的頭端門鈴。主機與元件各自獨立推進，因此可同時進行大量傳輸。

頻寬與外形規格

由於NVMe建立在PCIe之上，其頻寬取決於連結的世代與通道數：PCIe 4.0 x4的硬碟約7 GB/s，PCIe 5.0 x4則超過10 GB/s。協定延遲只有數微秒，相較於數十微秒的快閃記憶體讀取時間很小。NVMe硬碟有小巧的M.2卡、2.5吋U.2硬碟與擴充卡等形式。請注意M.2只是一種連接器：M.2插槽可能走SATA或PCIe，因此M.2 SSD不一定是NVMe。NVMe over Fabrics則將此協定延伸到網路上。

管理類指令

除了讀取與寫入，NVMe也定義了建立佇列、識別控制器、管理命名空間與升級韌體等管理指令。資料集管理（Dataset Management）指令中的Deallocate操作相當於ATA的TRIM：它告訴SSD哪些邏輯區塊已不再存有有用的資料，讓垃圾回收可直接抹除而不必複製。這能降低寫入放大，提升持續寫入效能，並延長快閃記憶體的耐久度。

練習NVMe的題目

下列關於網路卡或NVMe SSD等廣泛使用的、利用記憶體上描述子（descriptor）環（ring）的DMA機制，何者正確？

  1. ACPU將資料逐位元組寫入裝置的暫存器來傳輸
  2. BCPU只需將傳輸的位址與長度寫入描述子並通知裝置，裝置會自行讀取描述子並推進傳輸
  3. C描述子只存在於裝置內部，CPU看不到
查看答案與解析

正確答案：B. CPU只需將傳輸的位址與長度寫入描述子並通知裝置，裝置會自行讀取描述子並推進傳輸

描述子環是將排列在主記憶體上、寫著「從哪個位址傳送多少位元組」的表格，像環一樣循環使用的機制。CPU將傳輸內容寫入空閒的描述子，再向裝置的暫存器通知一次「已寫到這裡」。裝置以DMA讀取描述子、傳輸資料，並在完成的描述子上標記完成。CPU與裝置不必互相等待，即可推進許多傳輸。

常見問題

NVMe是什麼的縮寫？

NVMe是Non-Volatile Memory Express的縮寫，也寫作NVM Express。它是透過PCI Express存取SSD及其他非揮發性記憶體的主機介面與指令協定。

NVMe SSD和SATA SSD有什麼不同？

SATA SSD使用AHCI協定，只有單一個32指令的佇列，連結速度上限約600 MB/s。NVMe SSD則透過PCIe連接，擁有數千個平行佇列，速度可達每秒數GB到超過10 GB，軟體延遲也較低。

NVMe支援TRIM嗎？

支援。NVMe透過資料集管理指令的Deallocate屬性提供相同功能，作業系統在刪除檔案時會發出此指令。
