什麼是對稱式加密

加密與解密使用相同金鑰的加密方式，也稱為秘密金鑰加密。計算量小，能快速加密大量資料，但如何與通訊對象安全地共享金鑰（金鑰配送）是課題。AES是代表。

日文名稱: 共通鍵暗号

「對稱式加密」出現在2領域的5道練習題中（資訊安全基礎, 量子電腦硬體等）。

這個名詞所屬的領域: 資訊安全基礎

練習對稱式加密的題目

下列何者正確描述對稱式加密的特徵？

  1. A加密與解密使用不同的金鑰，加密用的金鑰可以公開
  2. B加密與解密使用相同的金鑰，處理速度快，但如何與通訊對象安全地共享金鑰是個問題
  3. C不使用金鑰，只以固定的程序轉換資料，因此只要程序不被知道就安全
查看答案與解析

正確答案：B. 加密與解密使用相同的金鑰，處理速度快，但如何與通訊對象安全地共享金鑰是個問題

對稱式加密是加密與解密使用相同金鑰的方式，AES是代表。計算量小，能快速加密大量資料，因此用於通訊與磁碟加密的主體。另一方面，傳送者與接收者必須事先在不讓第三者知道的情況下共享同一把金鑰，這個金鑰配送問題是它的弱點。加密與解密使用不同金鑰、且加密金鑰可以公開的是公開金鑰加密。此外，現代密碼的設計原則是即使程序（演算法）公開，只要金鑰保密就安全（柯克霍夫原則）。

50名成員希望任兩人之間都能以加密方式通訊，且不讓其他成員知道內容。使用對稱式加密時所需的金鑰數，與使用公開金鑰加密時所需的金鑰數（公開金鑰與私密金鑰合計），正確的組合是哪一項？

  1. A對稱式加密1225把，公開金鑰加密100把
  2. B對稱式加密2450把，公開金鑰加密100把
  3. C對稱式加密100把，公開金鑰加密1225把
查看答案與解析

正確答案：A. 對稱式加密1225把，公開金鑰加密100把

使用對稱式加密時，每一組兩人都需要各自的金鑰，因為三人以上共用同一把金鑰，其他成員也能讀取內容。從n人中選出兩人的組合數是 n(n−1)/2，因此50人需要 50 × 49 / 2 = 1225把。使用公開金鑰加密時，每人各持有一把公開金鑰與一把私密金鑰，傳給任何人時都能用對方的公開金鑰加密，因此只需 2n = 2 × 50 = 100把。人數增加時，對稱式加密的金鑰數大約與人數的平方成正比增加，公開金鑰加密則只與人數成正比。這是公開金鑰加密讓金鑰管理變得輕鬆的原因之一。
