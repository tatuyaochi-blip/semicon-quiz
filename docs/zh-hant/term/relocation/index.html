什麼是重定位（Relocation）

在程式碼與資料的最終位址確定後，將指令或資料中的暫定位址改寫為正確數值的處理。由連結器進行，動態連結時有一部分由動態連結器在執行時進行。

日文名稱: 再配置

練習重定位（Relocation）的題目

關於連結器所進行的重定位（relocation），下列說明何者正確？

  1. A程式碼與資料的最終位址決定後，將指令或資料中的位址改寫為正確的值
  2. B在程式執行中，將其搬移到另一部電腦繼續執行
  3. C記憶體不足時，將分頁（page）換出到儲存裝置
查看答案與解析

正確答案：A. 程式碼與資料的最終位址決定後，將指令或資料中的位址改寫為正確的值

編譯器是將各檔案視為從位址0開始來產生的，並將要使用其他檔案函式或自身變數位址的位置記錄為重定位資訊。連結器排列所有檔案、決定實際位址後，會依所記錄的各個位置計算出正確的位址（或與PC的距離）並寫入指令。在動態連結中，類似的改寫有一部分是在執行時由動態連結器進行。

解析中的「重定位（Relocation）」

  • 編譯器是將各檔案視為從位址0開始來產生的，並將要使用其他檔案函式或自身變數位址的位置記錄為重定位資訊。

    關於連結器所進行的重定位（relocation），下列說明何者正確？

  • 目的檔中包含該檔案內函式經翻譯後的機器碼、變數的初始值、所定義與所參照的名稱清單（符號表），以及事後要填入位址的位置清單（重定位資訊）。

    關於編譯器從單一原始檔輸出的目的檔（.o），下列何者正確？

  • 連結器會將各目的檔中所參照的名稱（符號），對應到其他地方所定義的實體（符號解析），並排列各檔案的程式碼與資料以決定最終位址，再將指令中的暫時位址改寫為正確的值（重定位）。

    關於連結器的主要功能，下列何者正確？

  • 編譯器在不知道count位址的情況下產生參照它的指令，並將該位置記錄在重定位資訊中。

    在C語言中寫下「extern int count;」時，下列關於其意義的敘述何者正確？

  • 動態連結器會尋找並載入所需的共用函式庫，進行重定位與符號的結合，然後將控制權移交給程式的入口。
