什麼是一階系統

轉移函數以 G(s) = K/(1 + Ts) 表示的系統。K 為穩態增益，T 為時間常數。對步階輸入的輸出為 K(1 − e^(−t/T))，在 t = T 時達到終值的約63.2%，3T 時約95%，5T 時約99.3%，沒有過衝。RC電路、熱系統、液位系統等許多常見的系統，都能以這個形式近似。在頻率響應中，以角頻率 1/T 為轉折點，增益以 −20 dB/dec 下降。

日文名稱: 一次遅れ系

「一階系統」出現在1領域的5道練習題中（控制工程基礎等）。

這個名詞所屬的領域: 控制工程基礎

練習一階系統的題目

對轉移函數為 G(s) = 2/(1 + 0.5s) 的一階系統，在時刻0輸入大小為1的步階。t = 1 s 時的輸出最接近下列何者？

  1. A約1.26
  2. B約1.73
  3. C2
查看答案與解析

正確答案：B. 約1.73

一階系統 K/(1 + Ts) 的步階響應為 y(t) = K(1 − e^(−t/T))，此處 K = 2、T = 0.5 s。t = 1 s 是時間常數的2倍，因此 y = 2 × (1 − e^(−2)) ≈ 2 × 0.865 ≈ 1.73。響應在時間常數 T 時達到終值的約63.2%，3T 時約95%，5T 時約99.3%。

對某一階系統輸入大小為2的步階，輸出最終穩定在6，並在輸入後0.4 s達到終值的約63%。這個系統的轉移函數為下列何者？

  1. A3/(1 + 0.4s)
  2. B3/(1 + 2.5s)
  3. C6/(1 + 0.4s)
查看答案與解析

正確答案：A. 3/(1 + 0.4s)

穩態增益是輸出的終值除以輸入的大小，即 6 ÷ 2 = 3。一階系統的步階響應達到終值約63%（1 − e^(−1)）所需的時間就是時間常數，因此 T = 0.4 s。所以 G(s) = 3/(1 + 0.4s)。像這樣，由步階響應的終值與上升的時間，就能簡單建立一階系統的模型。
