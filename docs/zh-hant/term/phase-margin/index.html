什麼是相位邊限

在負回授迴路的增益為 1(0 dB)的頻率上，相位延遲到達 180° 之前的餘裕。太小則響應容易振盪，在 0 以下則會振盪。一般以 45〜60° 以上為目標。

日文名稱: 位相余裕(フェーズマージン)

這個名詞所屬的領域: 類比與電子電路

相位邊限的定義

取迴路增益 T = Aβ，也就是訊號沿回授迴路繞行一圈所得到的增益。在 T 的大小降到 1（0 dB）的交越頻率上，相位邊限是相位落後距離 180 度還有多少：落後 120 度時，邊限為 60 度。增益邊限是與之配套的指標，指在相位落後達到 180 度的頻率上，迴路增益比 0 dB 低多少。兩者都是從迴路增益的波德圖讀取，而非從閉迴路響應讀取。

數值在實務上的意義

邊限為零表示迴路維持持續振盪，邊限為負則表示振盪會增長。很小的正邊限，會在閉迴路頻率響應中表現為峰值，在步階響應中表現為過衝與振鈴。約 45 度時過衝明顯可見；約 60 度時響應快速且只有輕微過衝，這就是通常以 45 到 60 度以上為目標的原因。邊限非常大雖然穩定，但往往意味著犧牲了頻寬。

相位落後從何而來

迴路中的每個極點最多貢獻 90 度的落後，因此交越頻率附近的兩個極點會使總落後趨近 180 度。主極點補償將一個極點放在非常低的頻率（通用運算放大器中為數 Hz 到數十 Hz），常利用米勒效應，使小的晶片內電容就足夠。此時增益以每十倍頻 −20 dB 下降，並在下一個極點增加太多落後之前就穿越 0 dB。若只有一個第二極點，將它放在交越頻率的約 1.7 倍處，可得到約 60 度的邊限。代價是頻寬與迴轉率降低。

為什麼電壓隨耦器是最差情況

回授比例 β = 1 時，迴路增益等於完整的開迴路增益，交越發生在最高的頻率，最接近運算放大器的內部極點。閉迴路增益越高，β 越小，交越頻率越低，邊限越大，因此非完全補償型運算放大器會規定只在某個最小增益以上才穩定。電容性負載（與輸出電阻形成額外的極點）以及迴路中的延遲也會侵蝕邊限。同樣的分析也適用於穩壓器與鎖相迴路。

常見問題

放大器的相位邊限多少才算好？

常見的目標是 45 到 60 度以上。約 60 度可得到快速且過衝很小的步階響應，而遠小於 45 度則會造成明顯的振鈴。

相位邊限和增益邊限有什麼差別？

相位邊限是在迴路增益為 0 dB 的頻率上，相位距離 180 度落後還有多少。增益邊限則是在相位落後達到 180 度的頻率上，迴路增益比 0 dB 低多少。

為什麼運算放大器在單位增益時比較不穩定？

單位增益時全部輸出都被回授，因此迴路增益在最高的頻率穿越 0 dB，而運算放大器的高階極點在該處會增加最多的相位落後。提高閉迴路增益可降低交越頻率，並增加相位邊限。

出現這個名詞的比較

  • 運算放大器與比較器的差異：使用方式、輸出級、速度、相位補償比較從使用方式（負回授或開迴路）、輸出級、響應速度、飽和恢復、有無相位補償、遲滯與能否互相替代等面向，以表格比較運算放大器與比較器。
  • PLL 與 DLL 的差異：控制對象、倍頻、抖動、穩定性、用途比較從控制對象、VCO 與延遲線、倍頻、抖動的累積、迴路穩定性與用途（時脈產生與去偏斜）等面向，以表格比較 PLL（鎖相迴路）與 DLL（延遲鎖定迴路）。
