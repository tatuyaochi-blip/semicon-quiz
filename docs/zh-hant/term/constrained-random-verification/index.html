什麼是受限隨機驗證（Constrained random verification）

在規格允許範圍的條件內隨機產生輸入值，包含人想不到的情況在內，廣泛嘗試的驗證方法。

日文名稱: 制約付きランダム検証

「受限隨機驗證（Constrained random verification）」出現在1領域的1道練習題中（硬體描述語言與驗證等）。

這個名詞所屬的領域: 硬體描述語言與驗證

練習受限隨機驗證（Constrained random verification）的題目

關於SystemVerilog的約束隨機驗證（constrained-random verification）的說明，下列何者正確？

  1. A在規格允許的範圍或組合條件（約束）之內隨機產生輸入的值，連人想不到的情況也廣泛地嘗試
  2. B完全隨意地產生輸入的值，並給予許多規格中沒有的值
  3. C輸入的值全部由人以手工撰寫
查看答案與解析

正確答案：A. 在規格允許的範圍或組合條件（約束）之內隨機產生輸入的值，連人想不到的情況也廣泛地嘗試

只靠人設計的測試（指定型測試），容易漏掉設計者未預期的組合所造成的缺陷。在約束隨機驗證中，會寫下例如「位址是4的倍數」「長度為1～256」之類的約束，並在其中隨機產生輸入，因此只用有意義的輸入就能嘗試許多情況。嘗試了哪些情況以覆蓋率（coverage）來衡量，不足的部分則透過變更約束，或以指定型測試來補足。
