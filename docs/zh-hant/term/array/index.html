什麼是陣列

將相同型別的值排列儲存，並以元素編號（索引）指定各元素的資料結構。元素在記憶體中連續配置，因此可由元素編號計算位置，以固定的時間讀寫任何元素。有元素編號從0開始的語言，也有從1開始的寫法。

日文名稱: 配列

「陣列」出現在15領域的75道練習題中（程式設計基礎（虛擬碼追蹤）, 資料結構與演算法, GPU程式設計等）。

這個名詞所屬的領域: 程式設計基礎（虛擬碼追蹤）

練習陣列的題目

對於有 n 個元素的陣列，將所有不同的兩個元素組合各比較一次的處理（以雙重迴圈將第 i 個元素與其後的所有元素比較，並讓 i 逐一前進），其時間複雜度為下列何者？

  1. AO(n)
  2. BO(n log n)
  3. CO(n²)
查看答案與解析

正確答案：C. O(n²)

比較的組數為 (n−1) + (n−2) + … + 1 = n(n−1)/2，n = 10 時為45次，n = 1000 時為499,500次。時間複雜度的階只看 n 變大時的增加方式，因此省略係數1/2與低次項，表示為 O(n²)。n 變為2倍時，次數約變為4倍。O(n) 是每個元素只看一次的處理，O(n log n) 則是像合併排序那樣反覆對半分割的處理的複雜度。

以從開頭逐一比較的線性搜尋，在存有100個不同值的陣列中尋找目標值。若目標值一定在陣列中，且位於各位置的機率相等，則比較次數的平均為多少？

  1. A約7次
  2. B50.5次
  3. C100次
查看答案與解析

正確答案：B. 50.5次

目標值在第 k 個位置時要比較 k 次，因此平均為 (1 + 2 + … + 100) / 100 = 50.5次，一般而言為 (n + 1)/2 次。最佳情況（位於開頭）為1次，最差情況（位於末尾）為100次，平均與最差都與 n 成正比，因此時間複雜度為 O(n)。約7次相當於 log₂ 100 ≈ 6.6，是二分搜尋的次數，但資料未排序時無法使用。

解析中的「陣列」

  • 陣列可由起始位址與元素大小算出第 i 個元素的位址，因此能以 O(1) 讀取，但在中間插入時需要把後面的元素往後挪，要花 O(n)。

  • 這是因為資料已排序才能如此判斷，未排序的陣列無法使用。

  • 1, 3, 8, 5, 4 是找出最小值並與開頭交換的選擇排序進行1輪後的陣列，1, 3, 4, 5, 8 則是全部排序完成的結果。

  • 10, 14, 29, 37, 13 是插入排序插入2個元素後的陣列，10, 14, 13, 29, 37 則是泡沫排序進行2輪後的陣列。

出現「陣列」的題目（75題）

  1. 對於有 n 個元素的陣列，將所有不同的兩個元素組合各比較一次的處理（以雙重迴圈將第 i 個元素與其後的所有元素比較，並讓 i 逐一前進），其時間複雜度為下列何者？
  2. 以從開頭逐一比較的線性搜尋，在存有100個不同值的陣列中尋找目標值。若目標值一定在陣列中，且位於各位置的機率相等，則比較次數的平均為多少？
  3. 與陣列相比，鏈結串列（各元素持有指向下一個元素位置之指標的串列）的特徵，下列何者正確？
  4. 與陣列中央的元素比較、每次將搜尋範圍縮小一半的二分搜尋，其使用的前提條件為下列何者？
  5. 以二分搜尋在依升冪排列的陣列 a[0]～a[9] = 3, 8, 12, 17, 23, 31, 38, 45, 52, 60 中尋找38。搜尋範圍從下端 lo = 0、上端 hi = 9 開始，中央位置為 (lo + hi) ÷ 2 無條件捨去。依序排列與38比較的元素值，下列何者正確？
  6. 以泡沫排序將陣列 5, 3, 8, 1, 4 依升冪排列。從開頭比較相鄰的兩個元素，若左側較大就交換，這樣的操作進行到末尾1次（1輪）後，陣列為下列何者？
  7. 以選擇排序（從未排序部分找出最小值，並與未排序部分的開頭交換）將陣列 29, 10, 14, 37, 13 依升冪排列。進行此操作2次後，陣列為下列何者？
  8. 以插入排序將有10個元素的陣列依升冪排列。依序取出第2個以後的元素，從左側相鄰的元素開始依序比較，直到找到小於或等於取出值的元素，或到達開頭為止。一開始就是升冪時與一開始是降冪時，比較次數的組合為下列何者？
  9. 即使在最差情況下時間複雜度也是 O(n log n)，且幾乎不使用工作用陣列等額外記憶體就能排序的演算法為下列何者？
  10. 將二元堆積以根為 a[0] 的陣列 a[0], a[1], a[2], … 存放，從上層開始每層由左往右依序填入。a[4] 的子節點與父節點為下列何者？
  11. 以根為 a[0] 的陣列表示父節點值大於或等於子節點值的最大堆積。對堆積 50, 30, 40, 10, 20, 35 加入45：先放在末尾，只要比父節點大就與父節點交換。操作後的陣列為下列何者？
  12. 某個可變長度陣列在容量已滿時加入元素，會重新配置2倍容量的區域並複製所有元素。對容量為1的空陣列逐一加入1,000個元素時，被複製的元素總數為多少？
