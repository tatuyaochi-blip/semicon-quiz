什麼是輪詢（Polling）

CPU 反覆去檢查周邊電路的狀態，藉以發現變化的方式。雖然單純，但即使什麼都沒發生也持續檢查，因此耗費時間與電力。

日文名稱: ポーリング

「輪詢（Polling）」出現在3領域的3道練習題中（作業系統與硬體, 嵌入式與韌體, CPU與架構等）。

這個名詞所屬的領域: 嵌入式與韌體

練習輪詢（Polling）的題目

CPU不使用中斷而是反覆檢查裝置狀態的方式（輪詢，polling），在下列哪種情況較有利？

  1. A處理的發生頻率非常高，每次中斷所需的切換負擔很大時
  2. B處理的發生極為罕見，且希望把CPU用在其他工作時
  3. C為了盡量降低耗電量，希望讓CPU長時間休眠時
查看答案與解析

正確答案：A. 處理的發生頻率非常高，每次中斷所需的切換負擔很大時

當處理很罕見時，中斷可以讓CPU不被浪費，但每一次都有儲存狀態與跳到處理常式的負擔。若像高速網路那樣處理極為頻繁，中斷的負擔會累積而來不及處理，因此集中輪詢反而更有效率。處理罕見的情況，或想讓CPU休眠以降低功耗時，空轉持續檢查的輪詢十分浪費，較適合使用中斷。

在得知週邊電路狀態的方法中，輪詢（polling）與中斷的差異，下列何者正確？

  1. A輪詢是CPU反覆去檢查狀態，中斷是在狀態改變時由週邊電路通知CPU
  2. B輪詢與中斷是相同的東西
  3. C中斷是CPU反覆去檢查狀態的方式
查看答案與解析

正確答案：A. 輪詢是CPU反覆去檢查狀態，中斷是在狀態改變時由週邊電路通知CPU

輪詢的結構簡單，檢查的間隔固定，因此動作容易預測；但即使什麼都沒發生，CPU也持續檢查，會浪費時間與電力。中斷只在有變化時CPU才回應，因此等待期間可以做其他處理或進入睡眠。不過若中斷過於頻繁，反而會使處理的負擔變大，所以區分使用很重要。
