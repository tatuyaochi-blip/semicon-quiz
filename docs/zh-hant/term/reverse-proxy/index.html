什麼是反向代理

放在網頁伺服器前方，代替伺服器接收使用者的請求，並轉送給後方一台或多台伺服器的伺服器。負責集中處理HTTPS的加密（TLS終止）、保存並回傳常用的回應、把負載分散到多台伺服器、隱藏後方伺服器的架構等角色。與放在使用者端、代替使用者連線到外部網站的正向代理相比，放置的位置與保護的對象不同。

日文名稱: リバースプロキシ

「反向代理」出現在2領域的2道練習題中（Web技術基礎, 雲端與容器基礎等）。

關於反向代理的說明，下列何者正確？

  1. A公司內的電腦瀏覽網際網路上的網站時，代替電腦連線到外部伺服器，並記錄或限制瀏覽
  2. B代替使用者從根伺服器開始依序進行把網域名稱轉換為IP位址的查詢，並把結果保存一段時間
  3. C放在Web伺服器前方，代替伺服器接收使用者的請求並轉送給後方的伺服器，負責TLS處理等
查看答案與解析

正確答案：C. 放在Web伺服器前方，代替伺服器接收使用者的請求並轉送給後方的伺服器，負責TLS處理等

反向代理放在伺服器端，接收使用者的請求，再轉送給後方一台或多台伺服器。它負責集中進行HTTPS的加密處理（TLS終止）、保存並回傳常用的回應、分配請求給多台伺服器等角色，也能對使用者隱藏後方伺服器的架構。代替公司內使用者連線到外部的是正向代理，差別在於它放在使用者端。
