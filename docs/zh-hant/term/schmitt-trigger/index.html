什麼是施密特觸發器

輸入上升時與下降時的臨界值不同(具有遲滯)的電路。即使是緩慢變化或夾雜雜訊的訊號，輸出也不會抖動。

日文名稱: シュミットトリガ

這個名詞所屬的領域: 類比與電子電路

遲滯如何產生

施密特觸發器是具有正回授的比較器。在常見的反相形式中，輸入驅動反相輸入，而從輸出拉出的分壓器將輸出電壓的一部分回授到非反相輸入。輸出為高時，該部分設定較高的臨界值；輸出為低時，臨界值下移。若輸出擺幅為 ±Vsat，分壓器由輸出到非反相節點的 R2 與該節點到接地的 R1 構成，則臨界值為 ±Vsat·R1/(R1+R2)，遲滯寬度為其兩倍。

為什麼它能停止抖動

只有單一臨界值的比較器，每當雜訊使緩慢變化的訊號在臨界值附近來回穿越時都會切換，產生一連串稱為抖動（chattering）的輸出邊緣。在施密特觸發器中，輸出切換的瞬間，臨界值就會跳離輸入，因此小於遲滯寬度的雜訊無法使它切換回去。設計準則是讓遲滯大於預期的雜訊峰對峰值，同時又要夠小，使偏移的臨界值不會犧牲太多靈敏度或時序精度。

施密特輸入與一般邏輯輸入

標準 CMOS 邏輯輸入只有一個位於電源一半附近的切換點。若輸入邊緣緩慢，它會在上拉與下拉電晶體都導通的區域停留，消耗額外電流，甚至可能振盪。具施密特觸發輸入的邏輯閘，例如 74HC14 六反相器，有分開的上升與下降臨界值，可容忍緩慢或帶雜訊的邊緣。許多微控制器的輸入接腳也基於同樣原因內建施密特觸發器，有助於處理長電纜、經 RC 濾波的訊號與重設線。

會在哪裡遇到它

機械開關的接點在閉合時會彈跳數毫秒。電阻－電容濾波器使彈跳波形變緩，施密特觸發器再將其轉回一個乾淨的邊緣；另一種做法是以軟體等待後再讀取的防彈跳。單一施密特反相器加上從輸出到輸入的電阻與從輸入到接地的電容，可構成 RC 弛張振盪器：電容在兩個臨界值之間充放電，因此頻率取決於 RC 與遲滯。施密特觸發器也用於將正弦波與感測器訊號整形為方波。

常見問題

施密特觸發器的遲滯是什麼？

是輸入上升時的臨界值與輸入下降時的臨界值之差。只有在輸入穿越較遠的臨界值時輸出才會改變狀態，因此能抵抗小於該差距的雜訊。

如何用施密特觸發器為按鈕防彈跳？

在開關與施密特觸發輸入之間放置 RC 低通濾波器。濾波器將彈跳平滑成緩慢的斜坡，遲滯再將該斜坡轉換為單一乾淨的轉態。

比較器和施密特觸發器有什麼差別？

一般比較器在單一臨界值切換，遇到帶雜訊的輸入可能抖動。施密特觸發器是具有正回授的比較器，有兩個臨界值，能產生乾淨的單一轉態。
