什麼是CIDR

Classless Inter-Domain Routing（無類別域間路由）。以「/」之後的位元數（前綴長度）自由決定IP位址網路部長度的方式及其寫法，例如 192.168.1.0/24。

日文名稱: CIDR

「CIDR」出現在1領域的2道練習題中（電腦網路基礎等）。

這個名詞所屬的領域: 電腦網路基礎

練習CIDR的題目

以子網路遮罩表示CIDR表示法的 /20，是下列何者？

  1. A255.255.240.0
  2. B255.255.255.240
  3. C255.255.248.0
查看答案與解析

正確答案：A. 255.255.240.0

/20 是上位20位元為1的遮罩。前16位元為 255.255，其餘4位元落在第3個八位元組的上位4位元。二進位的 11110000 為 128 + 64 + 32 + 16 = 240，因此子網路遮罩為 255.255.240.0。主機部為12位元，可容納 2^12 − 2 = 4094 台。255.255.255.240 是上位28位元為1的 /28，255.255.248.0 是上位21位元為1的 /21。

解析中的「CIDR」

  • 255.255.255.0 的上位24位元為1，因此在CIDR表示法中寫成「/24」，例如 192.168.1.0/24。
