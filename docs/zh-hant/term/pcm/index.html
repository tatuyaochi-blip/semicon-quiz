什麼是PCM(相變記憶體)

利用硫族化合物材料的結晶狀態(低電阻)與非晶狀態(高電阻)之差異來儲存資訊的非揮發性記憶體。

日文名稱: PCM(相変化メモリ)

「PCM(相變記憶體)」出現在1領域的12道練習題中（新世代記憶體等）。

這個名詞所屬的領域: 新世代記憶體

Set、Reset 與讀取的原理

PCM 單元以電流脈衝寫入，藉焦耳熱加熱一小塊硫族化合物，通常為 GST（Ge2Sb2Te5）。Reset 使用大而短的脈衝（數十到數百 ns），將材料加熱到約 600 °C 以上使其熔化；在數 ns 內急冷，使雜亂的原子凍結成高電阻的非晶相。Set 使用較小、較長的脈衝，將材料保持在結晶溫度（GST 約 150 °C）與熔點之間，直到結晶為低電阻相。讀取時施加小偏壓感測電阻，加熱程度不足以改變單元狀態。

多階單元與電阻漂移

由於結晶相與非晶相的電阻相差兩到三個數量級，PCM 每個單元可儲存超過一位元。脈衝的振幅與時間決定非晶區域的大小，產生中間電阻位準。問題在於電阻漂移：非晶相會緩慢鬆弛，使電阻大約隨時間的冪次上升（R ∝ t^ν，ν 約 0.1）。兩階儲存可以容忍這種漂移，但間距很近的位準可能會混在一起，因此多階 PCM 仰賴寫入後驗證、與資料一起讀取的參考單元，以及低漂移材料。

微縮限制：Reset 電流與熱干擾

Reset 電流是 PCM 主要的功耗來源，因此單元設計會縮小必須熔化的體積。例如蘑菇型單元讓電流通過狹窄的加熱電極，只加熱一小塊圓頂狀的 GST。間距縮小還帶來第二個問題，即熱干擾：單元之間只相隔數十奈米時，Reset 產生的熱可能使相鄰的非晶單元部分結晶。在每個單元周圍使用隔熱介電層有助於改善。資料保存能力也受溫度限制，因為 GST 在約 150 °C 結晶，這也是車用等高溫應用採用富鍺成分的原因。

PCM 與其他非揮發性記憶體的比較

PCM 介於 NAND 快閃記憶體與 DRAM 之間。其約 10^6 到 10^9 次的耐久度優於 NAND 的數千到數萬次，但不及 MRAM（10^10 次以上）與實質上無限次的 DRAM。MRAM 以磁性穿隧接面的磁化方向儲存資料，ReRAM 在氧化物中形成與斷開導電細絲，而 PCM 則改變整塊體積的原子結構。在高密度交叉點陣列中，每個 PCM 元件會搭配一個雙向臨界開關（OTS）選擇器，阻擋流經未選取單元的潛行電流。

練習PCM(相變記憶體)的題目

  1. A磁性層磁化方向的差異
  2. B硫族化物材料的結晶狀態與非晶態之間的電阻差異
  3. C鐵電體極化的方向
查看答案與解析

正確答案：B. 硫族化物材料的結晶狀態與非晶態之間的電阻差異

PCM 以電流的焦耳熱對 GeSbTe 等硫族化物材料加熱、急速冷卻，在低電阻的結晶狀態與高電阻的非晶態之間切換。電阻差異高達 2～3 個數量級，也可以做出中間值來達成多值化。同樣的材料也利用結晶與非晶之間光反射率不同的性質，用於可重複寫入的 DVD 與藍光光碟。需要大電流才能寫入是其課題。

相變記憶體（PCM）中，使單元成為高電阻非晶態（重置）的方法，下列何者正確？

  1. A施加磁場使磁化反轉
  2. B以大電流脈衝加熱至熔點以上後急速冷卻
  3. C在結晶化溫度附近長時間保持
查看答案與解析

正確答案：B. 以大電流脈衝加熱至熔點以上後急速冷卻

重置時，以大電流脈衝（數十 ns 左右）將材料加熱到熔點（GST 約 600 ℃）以上使其熔化，並在數 ns 內急速冷卻，不給原子排列的時間而成為非晶態。相反地，設定時則是在結晶化溫度以上、熔點以下保持一段時間使其結晶化。重置電流大是 PCM 功耗上的課題，可藉由縮小加熱體積的結構來減少。

常見問題

PCM 和 ReRAM 有什麼差別？

兩者都以電阻狀態儲存資料，但 PCM 利用熱使硫族化合物在結晶相與非晶相之間切換，ReRAM 則在金屬氧化物中移動離子，形成或斷開細窄的導電細絲。因此 PCM 需要較大的寫入電流來熔化材料。

為什麼 PCM 的 Set 比 Reset 慢？

Reset 只需熔化材料並在數 ns 內急冷，而 Set 必須將材料維持在熔點以下夠長的時間，讓原子排列成晶體，通常需要數十到數百 ns。因此結晶時間是限制 PCM 寫入速度的因素。

相變記憶體中的 GST 是什麼？

GST 指鍺-銻-碲硫族合金，最常見的是 Ge2Sb2Te5。它結晶速度快，在室溫下又能保持穩定的非晶相；同一系列材料也曾用於可覆寫式光碟。
