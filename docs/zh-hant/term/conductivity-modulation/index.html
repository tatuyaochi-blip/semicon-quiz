什麼是導電度調變

大量少數載子被注入低濃度層，使該層電阻大幅下降的現象。在 PIN 二極體與 IGBT 中，用來同時達成高耐壓與低導通電壓。

日文名稱: 伝導度変調

「導電度調變」出現在1領域的2道練習題中（功率半導體等）。

這個名詞所屬的領域: PN接面與二極體

練習導電度調變的題目

關於IGBT的說明，下列何者正確？

  1. A僅具有2個PN接面的2端子元件
  2. B以MOS閘極驅動，並藉由雙極性動作的導電度調變獲得低導通電壓的元件
  3. C照光即導通的閘流體
查看答案與解析

正確答案：B. 以MOS閘極驅動，並藉由雙極性動作的導電度調變獲得低導通電壓的元件

IGBT是結合MOSFET的輸入部與雙極性電晶體的輸出部的元件，結構上在汲極側加上p+層。由於可用電壓驅動，驅動電路簡單；導通時，從p+層注入的電洞會大幅降低漂移層的電阻（導電度調變），因此即使在600 V～6.5 kV的高耐壓下，也能降低導通電壓。它是EV、鐵路、工業用逆變器的主力，但因為有尾電流，不適合高頻。

關於矽MOSFET與IGBT的一般使用區分，下列何者正確？

  1. AMOSFET適合較低電壓的高速切換，IGBT適合數百V以上的高電壓、大電流
  2. BIGBT適合低電壓、小電流，MOSFET適合高電壓、大電流
  3. C兩者只能用於相同的用途
查看答案與解析

正確答案：A. MOSFET適合較低電壓的高速切換，IGBT適合數百V以上的高電壓、大電流

矽MOSFET僅以多數載子運作，因此速度快，但耐壓一高導通電阻就急遽增大，所以大致用於數百V以下，尤其是低電壓的電源。IGBT藉由導電度調變，即使高耐壓也能將導通電壓維持得低，適合600 V以上的大電流用途（EV、工業用逆變器、鐵路），但因尾電流而偏慢。如今在這中間～高耐壓的領域，SiC MOSFET正逐漸取代兩者。

解析中的「導電度調變」

  • 由於可用電壓驅動，驅動電路簡單；導通時，從p+層注入的電洞會大幅降低漂移層的電阻（導電度調變），因此即使在600 V～6.5 kV的高耐壓下，也能降低導通電壓。

    關於IGBT的說明，下列何者正確？

  • IGBT藉由導電度調變，即使高耐壓也能將導通電壓維持得低，適合600 V以上的大電流用途（EV、工業用逆變器、鐵路），但因尾電流而偏慢。
