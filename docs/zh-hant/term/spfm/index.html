什麼是SPFM(單點故障指標)

ISO 26262 的硬體評估指標，表示在與安全相關的故障中，單獨即會導致違反安全目標的單點故障與殘餘故障所占比例很小。目標基準為 ASIL B 90% 以上、C 97% 以上、D 99% 以上。

日文名稱: SPFM(単一点故障指標)

「SPFM(單點故障指標)」出現在1領域的4道練習題中（車用半導體與功能安全等）。

練習SPFM(單點故障指標)的題目

關於單點故障指標（SPFM），ASIL D所要求之目標值的參考，正確的是下列何者？

  1. A90%以上
  2. B60%以上
  3. C99%以上
查看答案與解析

正確答案：C. 99%以上

SPFM是表示在安全相關的故障中，單獨就會導致違反安全目標的單點故障，以及安全機制未能完全偵測而殘留的殘餘故障較少的指標，由1減去兩者故障率所占的比例求得。目標值的參考為ASIL B 90%以上、ASIL C 97%以上、ASIL D 99%以上。潛伏故障指標（LFM）的參考為ASIL B 60%以上、ASIL C 80%以上、ASIL D 90%以上，因此90%與60%是容易與LFM或ASIL B之值混淆的數字。

安全相關硬體的故障率合計為1000 FIT，其中單點故障與殘餘故障（安全機制未偵測到而殘留的故障）的故障率合計為5 FIT時，單點故障指標（SPFM）是多少？

  1. A99.5%
  2. B95%
  3. C99.95%
查看答案與解析

正確答案：A. 99.5%

SPFM是以1減去「單點故障與殘餘故障的故障率合計」除以「安全相關故障率的合計」所得的值求得。此例中1 − 5 / 1000 = 1 − 0.005 = 0.995，因此為99.5%。這滿足ASIL D的參考值99%以上。95%是將比例多估一個數量級時的值，99.95%是少估一個數量級時的值。要提高SPFM，需加入診斷覆蓋率高的安全機制，減少未被偵測而殘留的故障。
