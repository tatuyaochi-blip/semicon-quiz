什麼是監督式學習（Supervised learning）

使用由輸入與正確答案（標籤）成對組成的資料，訓練能由輸入預測正確答案之模型的機器學習方法。預測的輸出為連續數值時稱為迴歸，為固定幾個類別之一時稱為分類。常用的模型有線性迴歸、邏輯斯迴歸、決策樹、支援向量機與神經網路等。準備標籤往往需要相當多的人力。

日文名稱: 教師あり学習

「監督式學習（Supervised learning）」出現在1領域的2道練習題中（機器學習基礎等）。

練習監督式學習（Supervised learning）的題目

下列監督式學習的任務中，屬於迴歸的是何者？

  1. A由電子郵件的內文判斷該郵件是否為垃圾郵件
  2. B辨識手寫數字的影像是0〜9中的哪一個數字
  3. C由坪數、到車站的距離等預測房屋的價格
查看答案與解析

正確答案：C. 由坪數、到車站的距離等預測房屋的價格

監督式學習是使用輸入與正確答案（標籤）的配對，訓練由輸入預測輸出之模型的方法。預測的輸出為連續數值時稱為迴歸，為固定幾個類別之一時稱為分類。房屋價格是連續數值，因此屬於迴歸。垃圾郵件判斷是二元分類，手寫數字辨識是10個類別的分類。

解析中的「監督式學習（Supervised learning）」

  • 監督式學習是使用輸入與正確答案（標籤）的配對，訓練由輸入預測輸出之模型的方法。
