什麼是線邊緣粗糙度(LER)

微細光阻圖案側面產生的奈米級凹凸。是造成線寬變異（LWR）的原因，並導致電晶體特性的變異。

日文名稱: ラインエッジラフネス(LER)

「線邊緣粗糙度(LER)」出現在2領域的3道練習題中（微影, 蝕刻等）。

這個名詞所屬的領域: 微影

練習線邊緣粗糙度(LER)的題目

下列何者是表示微細光阻圖案側面所產生之奈米等級凹凸的指標？

  1. A焦深（DOF）
  2. B數值孔徑（NA）
  3. C線邊緣粗糙度（LER）
查看答案與解析

正確答案：C. 線邊緣粗糙度（LER）

LER是表示圖案側面凹凸程度的指標（通常以3σ表示），以線寬變異來表示的則稱為LWR。當線寬縮到20 nm左右時，即使只有2～3 nm的凹凸也會超過線寬的一成，成為電晶體臨界電壓與配線電阻變異的原因。其成因是光阻分子的大小、酸的擴散，以及光子數的機率性起伏，可透過蝕刻時的平滑化等方式改善。

EUV曝光中成為問題的機率性起伏（隨機效應，stochastics）的主要原因，下列何者正確？

  1. A因為EUV光的波長比ArF長
  2. B因為EUV曝光使用透鏡
  3. C因為EUV光每個光子的能量大，即使曝光量相同，光子數也較少
查看答案與解析

正確答案：C. 因為EUV光每個光子的能量大，即使曝光量相同，光子數也較少

每個光子的能量與波長成反比，EUV（13.5 nm，約92 eV）約為ArF（193 nm，約6.4 eV）的14倍。若曝光量相同，照射到的光子數只有1/14，例如進入20 nm見方範圍內的光子只有數百至數千個左右，其數量在統計上會有約√N的變異。這就是隨機效應，會造成圖案缺損、橋接（相連）、LER，以及小孔無法開出等缺陷。增加曝光量可以改善，但產能會下降。
