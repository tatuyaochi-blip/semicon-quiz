什麼是廢氣處理設備

以燃燒、吸附、水洗等方式，去除製造設備排出廢氣中有害物質的設備。

日文名稱: 除害装置

「廢氣處理設備」出現在1領域的3道練習題中（環境安全等）。

這個名詞所屬的領域: 環境安全

練習廢氣處理設備的題目

蝕刻或設備清潔所使用的PFC（全氟碳化物）類排放被視為環境問題，其主要理由為下列何者？

  1. A因為是造成水質汙染的主要物質
  2. B因為是造成酸雨的主要物質
  3. C因為是全球暖化潛勢大、在大氣中壽命長的溫室氣體
查看答案與解析

正確答案：C. 因為是全球暖化潛勢大、在大氣中壽命長的溫室氣體

CF4或C2F6等PFC類的全球暖化潛勢為CO2的數千倍以上，其中CF4在大氣中的壽命約為5萬年，是壽命極長的溫室氣體。一旦排放，以人類的時間尺度而言不會消失，因此半導體業界透過廢氣處理設備分解、改用全球暖化潛勢較小的替代氣體、使用量最佳化等方式努力減少排放。它們並不是水質汙染或酸雨的主要成因物質。

使廢氣中的酸性氣體等與水或藥液接觸，以吸收、去除的裝置為下列何者？

  1. AULPA濾網
  2. BOHT
  3. C濕式洗滌塔
查看答案與解析

正確答案：C. 濕式洗滌塔

濕式洗滌塔是在填充了填料的塔中，使廢氣與水或中和用藥液的噴淋接觸，吸收並去除氟化氫、氯化氫等易溶於水的酸性氣體，以及氨等鹼性氣體的裝置。可用於全廠的排氣處理，或設備各自的廢氣處理設備的後段等。但難溶於水的PFC等無法去除。ULPA濾網是去除微粒的設施，OHT則是搬運設備。
