什麼是製程窗口

即使改變曝光劑量與對焦，圖案尺寸仍落在容許範圍內的條件範圍。範圍越寬，對製造變異的耐受性越強。

日文名稱: プロセスウィンドウ

「製程窗口」出現在1領域的3道練習題中（微影等）。

這個名詞所屬的領域: 微影

解讀劑量－對焦窗口

製程窗口通常是透過曝光對焦－曝光矩陣（focus-exposure matrix）來求得，這是一片讓每個曝光區接受不同劑量與對焦組合的晶圓，再量測所得的臨界尺寸（CD）。針對多個劑量繪製 CD 對對焦的曲線，即得到 Bossung 曲線。CD 維持在容許範圍內（例如目標值的 ±10%）的劑量與對焦區域，就是曝光－離焦窗口。它常以曝光寬容度（以百分比表示的容許劑量範圍）與焦深（DOF，在特定曝光寬容度下可用的對焦範圍）來概括。

什麼會使窗口縮小

解析度與製程窗口是不同的概念：圖案可能在最佳劑量與對焦下能成像，卻在微小偏差時失敗。將解析度因子 k1 壓得更低，會降低影像對比並使窗口變窄。DOF 大致與波長除以數值孔徑的平方成比例，因此 NA 越高的光學系統對焦餘裕越小。在量產中，對焦與劑量會隨曝光機變異、晶圓平坦度、下層高低起伏與光阻厚度變化而漂移，這些在考慮任何特定圖案的弱點之前，就已消耗掉餘裕。

不同圖案間的窗口重疊

光罩上的每個圖案都有各自的窗口。密集線、孤立線、線端與接觸孔的最佳對焦與劑量各不相同，因此可用的製程窗口是所有圖案窗口的重疊部分，而少數布局上的弱點（常稱為熱點，hotspot）就可能決定整個層的極限。光學鄰近效應修正（OPC）、次解析輔助圖形，以及同時調整照明形狀與光罩圖案的光源－光罩最佳化，其主要目的在於擴大這個共同窗口，而不只是提升最佳情況下的解析度。

在晶圓廠中的運用

工程師會將量產條件設定在窗口的中心，使正常變異在各方向都留有餘裕，並以監控圖案與曝光機調平資料追蹤劑量與對焦。窗口越大，漂移出規格的晶圓越少，重工也越少。導入新的布局或光阻時，比較窗口的大小與形狀，可提供直接且定量的方式來判斷哪個選項更容易製造，而不只是看最小圖形能否解析。

  2. B愈大，解析度愈高

正確答案：A. 是表示製程難度的係數，一次曝光的理論下限為0.25

k1是綜合表示光阻性能、光罩的巧思與照明條件等整體實力的係數，愈小愈能解析細微圖案，但製程窗口也會變窄而更困難。以一次曝光解析週期性圖案（線與間隔）的理論下限為0.25。1990年代約在0.6上下，之後藉由離軸照明、相位移光罩、OPC等解析度增強技術，即使在量產中也已降到0.27～0.3左右。

  1. A製程窗口
  2. B疊對
  3. C線邊緣粗糙度
查看答案與解析

正確答案：A. 製程窗口

製程窗口是指即使改變曝光量與對焦，圖案尺寸仍能落在容許範圍（例如目標值的±10%）內的範圍，以縱軸為曝光量、橫軸為對焦的圖（ED-window）來表示。在量產中，機台的變異、晶圓的凹凸與光阻厚度的變化會使曝光量與對焦產生波動，因此窗口愈寬，愈能穩定製造。OPC與照明條件的最佳化，主要就是為了擴大它而進行的。

常見問題

什麼是 Bossung 曲線？

Bossung 曲線是將臨界尺寸對對焦作圖，每個曝光劑量一條曲線。一組這樣的曲線可顯示圖案對對焦與劑量的敏感度，並用於決定製程窗口。

曝光寬容度和焦深是什麼？

曝光寬容度是 CD 維持在容許範圍內的劑量範圍，以百分比表示；焦深則是對應的可用對焦範圍。兩者共同描述製程窗口的大小。

如何擴大微影製程窗口？

常見方法包括光學鄰近效應修正、次解析輔助圖形、照明最佳化與光源－光罩最佳化、提升光阻對比，以及減少晶圓高低起伏與對焦誤差。
