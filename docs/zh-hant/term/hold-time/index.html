什麼是保持時間

正反器中，在時脈有效邊緣之後，資料輸入必須維持不變的最短時間。違反時即使降低時脈頻率也無法修正，因此以追加延遲來因應。

日文名稱: ホールド時間

「保持時間」出現在5領域的27道練習題中（時序分析與CDC, 邏輯電路, LSI設計流程與EDA等）。

這個名詞所屬的領域: 邏輯電路

保持時間保護的是什麼

正反器在有效時脈邊緣之後，內部閂鎖關閉的短暫時間窗內，需要資料輸入維持不變；這個最短間隔就是保持時間。設定時間則是邊緣之前的對應要求。保持時間的風險來自擷取資料的同一個邊緣：它同時也會讓上游正反器發出新資料，若新值經由非常短的路徑快速到達，就可能覆寫正在擷取的值。兩種違反都可能產生錯誤的值，或使正反器進入亞穩態。

以最小延遲檢查保持時間

保持時間分析使用最快的情況：最小時脈到輸出延遲加上最小邏輯與導線延遲，必須超過保持時間，並依擷取時脈實際到達的時間進行調整。若時脈到輸出為 0.08 ns、邏輯為 0.02 ns、保持時間為 0.05 ns，且擷取時脈晚到 0.1 ns，則到達時間為 0.10 ns，而要求為 0.15 ns，違反 −0.05 ns。電路板層級的介面也遵循相同邏輯，使用發送端的最小時脈到輸出延遲；若規格書未記載，假設為 0 ns 是安全的選擇。

為什麼降低時脈沒有幫助

對於由同一個時脈邊緣發出並擷取的一般路徑，時脈週期不會出現在保持時間的方程式中，因此降低頻率無法改變違反的情況。帶有實際保持時間違反而出貨的晶片，可能在任何速度下都無法使用。標準修正方式是在短資料路徑上插入緩衝器或延遲單元，通常在時脈樹合成之後、實際偏移已知時進行。移位暫存器與掃描鏈等幾乎沒有邏輯的路徑，是典型的保持時間風險，而正時脈偏移會使情況更糟。

元件庫數值與負保持時間

保持時間是每種正反器設計經特性化得出的屬性，取決於輸入轉換時間、負載與製程角落。它可能非常小、為零，甚至為負值，表示由於時脈腳位與取樣點之間的內部延遲，資料即使在時脈邊緣之前稍微改變也不會出錯。負保持時間讓保持時間較容易滿足，但並不能免除檢查，因為時脈偏移與晶片內變異仍會使每個端點的有效要求偏移。

練習保持時間的題目

以正反器接收非同步訊號時，因無法滿足設置時間或保持時間，導致輸出暫時無法確定是0還是1的狀態，稱為什麼？

  1. A亞穩態
  2. B突波
  3. C閂鎖效應

正確答案：A. 亞穩態

在亞穩態下，輸出會停留在中間電壓，或需要很長時間才會確定。原理上無法完全避免，只能讓機率隨著解決所需時間呈指數下降。因此非同步訊號以串接兩級以上正反器的同步電路接收，即使第一級不確定，到第二級為止確定的機率也能提高到足夠高（使平均故障間隔達數千年以上）。多位元的資料則以FIFO或交握（handshake）來傳遞。

  2. B從輸入時脈到輸出改變的時間
  3. C時脈有效邊緣之後，資料輸入也必須保持不變的時間
查看答案與解析

正確答案：C. 時脈有效邊緣之後，資料輸入也必須保持不變的時間

保持時間是時脈邊緣之後，資料必須保持穩定的最短時間。若從前一級正反器到下一級的路徑太短，在同一個邊緣更新的新資料會太早到達下一級而違規。由於與週期無關，放慢時脈也無法改善，對策是在資料路徑插入緩衝器以增加延遲。若在製造後才發現，晶片就無法使用，因此設計時的驗證很重要。

常見問題

設定時間和保持時間有什麼差別？

設定時間是資料在時脈邊緣之前必須穩定的時間，保持時間則是邊緣之後必須持續穩定的時間。設定時間違反來自太慢的路徑，保持時間違反則來自太快的路徑。

正反器的保持時間可以是負的嗎？

可以。內部延遲可能使資料實際上在外部時脈邊緣之前一點就被取樣，因此資料在邊緣之前稍微改變也不會出錯；此時元件庫會標示為負的保持時間值。

保持時間違反要怎麼修正？

用緩衝器或延遲單元在短資料路徑上增加延遲，或減少使擷取時脈延後的偏移。改變時脈頻率對同邊緣的保持時間檢查沒有任何影響。
