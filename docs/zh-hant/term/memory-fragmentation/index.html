什麼是記憶體碎裂（Memory fragmentation）

反覆配置與釋放的過程中，空閒記憶體被切得很零碎，即使總量足夠，也無法一次配置出大塊區域的現象。亦稱 fragmentation。

日文名稱: 断片化

「記憶體碎裂（Memory fragmentation）」出現在1領域的1道練習題中（記憶體階層與效能等）。

練習記憶體碎裂（Memory fragmentation）的題目

使用大分頁（巨型分頁）的主要優點與缺點的組合，下列何者正確？

  1. A優點是快取的未命中率下降，缺點是TLB未命中增加
  2. B優點是不再發生分頁錯誤，缺點是佔用較多磁碟容量
  3. C優點是TLB未命中減少，缺點是內部碎片容易增加
查看答案與解析

正確答案：C. 優點是TLB未命中減少，缺點是內部碎片容易增加

分頁變大後，一個TLB項目就能轉換較廣的範圍，因此在處理大量資料的程式中，TLB未命中會大幅減少。另一方面，即使只有少量資料也要以大分頁為單位配置，因此未使用的區域（內部碎片）會增加，記憶體的配置也變得不靈活。TLB未命中反而會減少，快取的未命中率也不會直接受分頁大小左右。分頁錯誤也不會因此消失。
