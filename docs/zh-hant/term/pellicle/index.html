什麼是光罩護膜

隔著一定間隔張設在光罩上方的薄膜。可防止異物直接附著在光罩面上，附著在護膜上的異物因焦點不對而不易被轉印。

日文名稱: ペリクル

「光罩護膜」出現在1領域的1道練習題中（製程材料（氣體與藥液）等）。

這個名詞所屬的領域: 微影

光罩為何需要保護

光罩（倍縮光罩，reticle）會成像到它所印製的每一片晶圓的每一個曝光區域上。因此，圖案面上只要有一顆微粒，就會成為重複性缺陷，可能讓數千片晶圓上同一位置的晶粒全部失效。光罩價格昂貴，反覆清洗又有損傷圖案的風險。光罩護膜解決了這個問題：它讓微粒完全無法接觸圖案面，使在搬運、存放與曝光期間附著的污染物落在無害的位置。

失焦原理如何發揮作用

光罩護膜是一層薄的透明膜，用於深紫外光機台時厚度不到1 µm，張設在距離圖案面約6 mm的框架上。投影鏡頭的焦點對準圖案，而其在光罩側的焦深遠小於1毫米。因此護膜上的微粒偏離焦點達數毫米，其影像極度模糊，只會讓大範圍的區域稍微變暗，而不會印成清晰的缺陷。這層膜必須以最小的損失讓曝光光線通過，並在長時間照射下保持穩定。

EUV光罩護膜為何困難

13.5 nm的極紫外光（EUV）會被所有材料強烈吸收，因此EUV光罩護膜只能有數十奈米厚，並以多晶矽或奈米碳管膜等材料製成，即使如此每次穿透也只有約90%的透射率。由於EUV光罩是反射式的，光線會兩次穿過護膜，損失因而加倍。這層膜還會吸收部分高光源功率而升溫，因此必須能耐受高溫，同時在整個光罩面積上保持機械完整性。

光罩護膜與其他保護層的區別

光罩護膜保護的是光罩，而不是晶圓。在ArF浸潤式微影中，光阻上方的頂部塗層（topcoat）可防止浸潤用水溶出光阻成分，光阻下方的抗反射底層膜（BARC）則用來控制反射；兩者都與光罩污染無關。光罩護膜也無法修正光罩圖案中原本就存在的缺陷，或在安裝時被困在其下方的微粒，因此光罩在貼上護膜之前必須先經過檢測。

練習光罩護膜的題目

在ArF浸潤式曝光中，塗佈於光阻之上、使浸潤用的水與光阻不直接接觸的薄膜為下列何者？

  1. ABARC（抗反射膜）
  2. B光罩護膜（pellicle）
  3. C頂層塗佈（topcoat）
查看答案與解析

正確答案：C. 頂層塗佈（topcoat）

在浸潤式曝光中，鏡頭與晶圓之間的水會接觸光阻，因此光酸產生劑等可能溶入水中而汙染鏡頭，或水滲入而造成圖案缺陷。頂層塗佈是塗在光阻之上的保護膜，可防止這些情況，並使表面具疏水性，讓水在載台高速移動時不致殘留。BARC是鋪在光阻下方的抗反射膜，光罩護膜是保護光罩的薄膜。

常見問題

微影中的光罩護膜（pellicle）是什麼？

光罩護膜是一層安裝在框架上、位於光罩圖案上方數毫米處的透明薄膜。微粒會落在這層膜上而非光罩上，由於偏離焦點，因此不會被印出。

為什麼EUV光罩護膜很難製作？

所有材料都會強烈吸收EUV，因此這層膜必須只有數十奈米厚，卻要覆蓋整個光罩、承受吸收功率造成的升溫，而且每次穿透仍要讓約90%的光通過。

光罩護膜能防止所有光罩缺陷嗎？

不能。它只能在安裝之後防止新的微粒落到圖案面上；圖案缺陷，或貼上護膜時被困在其下方的微粒，仍然會被印出。
