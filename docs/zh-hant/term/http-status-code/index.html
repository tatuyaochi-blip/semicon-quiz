什麼是HTTP狀態碼

放在HTTP回應第一行的3位數字，表示請求的結果。以百位數分類：1xx為資訊，2xx為成功（200 OK、201 Created、204 No Content），3xx為重新導向（301 Moved Permanently、302 Found、304 Not Modified），4xx為用戶端錯誤（400 Bad Request、401 Unauthorized、403 Forbidden、404 Not Found），5xx為伺服器端錯誤（500 Internal Server Error、503 Service Unavailable）。401用於沒有驗證資訊或驗證資訊不正確時，403用於已通過驗證但沒有權限時。

練習HTTP狀態碼的題目

HTTP狀態碼與其意義的組合，下列何者正確？

  1. A301：所請求的資源暫時位於其他URL
  2. B404：在伺服器上找不到所請求的資源
  3. C503：請求的寫法有誤，伺服器無法理解
查看答案與解析

正確答案：B. 404：在伺服器上找不到所請求的資源

狀態碼是3位數字，百位數表示分類。2xx為成功（200 OK、201 Created、204 No Content），3xx為重新導向（301 Moved Permanently、302 Found、304 Not Modified），4xx為用戶端錯誤（400 Bad Request、401 Unauthorized、403 Forbidden、404 Not Found），5xx為伺服器端錯誤（500 Internal Server Error、503 Service Unavailable）。404表示在伺服器上找不到URL所指的資源。

在會員制網站上，已登入的一般會員請求了只允許管理者存取的網頁。伺服器已能確認使用者是誰，但不允許存取這個網頁。此時回傳的狀態碼，下列何者最適當？

  1. A401 Unauthorized
  2. B403 Forbidden
  3. C404 Not Found
查看答案與解析

正確答案：B. 403 Forbidden

403 Forbidden表示伺服器理解請求，但不允許存取。401 Unauthorized與名稱相反，是表示沒有驗證資訊或驗證資訊不正確的代碼，並以WWW-Authenticate標頭告知驗證方式。這個情境中已能確認使用者是誰，不足的是權限（授權），因此適用403。也有為了不讓人知道管理畫面存在而刻意回傳404的設計，但如實表示狀況的是403。
