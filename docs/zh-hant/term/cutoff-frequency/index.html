什麼是截止頻率

濾波器或放大器的輸出從通帶下降 3 dB(約 0.707 倍)的頻率。在 RC 電路中為 1/(2πRC)。

日文名稱: カットオフ周波数

「截止頻率」出現在3領域的6道練習題中（類比與電子電路, 雙載子電晶體, AD/DA轉換等）。

這個名詞所屬的領域: 類比與電子電路

練習截止頻率的題目

由電阻R = 1 kΩ與電容C = 1 µF構成的RC低通濾波器，其截止頻率最接近下列哪一個？

  1. A約16 Hz
  2. B約160 Hz
  3. C約1.6 kHz
查看答案與解析

正確答案：B. 約160 Hz

RC濾波器的截止頻率為 fc = 1/(2πRC)，RC = 1×10³ × 1×10⁻⁶ = 1 ms，故 fc ≈ 159 Hz（約160 Hz）。在此頻率輸出為 −3 dB（約0.707倍），相位落後45°，高於此頻率後，頻率每增加10倍衰減 −20 dB。一階的衰減較為平緩，因此若要陡峭地截止，會使用運算放大器構成的二階以上主動濾波器。

解析中的「截止頻率」

  • RC濾波器的截止頻率為 fc = 1/(2πRC)，RC = 1×10³ × 1×10⁻⁶ = 1 ms，故 fc ≈ 159 Hz（約160 Hz）。

    由電阻R = 1 kΩ與電容C = 1 µF構成的RC低通濾波器，其截止頻率最接近下列哪一個？

  • 不過它會與下一級的輸入電阻R構成高通濾波器，低於截止頻率 f = 1/(2πRC) 的頻率會被衰減。

    放大電路的級與級之間加入的耦合電容，其作用下列何者正確？

  • 截止頻率與低通相同，為 1/(2πRC)，低於此頻率時，頻率每降為1/10衰減 −20 dB。

    將電容串聯在訊號路徑中，並將電阻接在輸出與接地之間的RC電路，其特性下列哪一項正確？

  • −3 dB相當於功率約1/2、電壓 1/√2 ≈ 0.707倍，在濾波器與放大器中，以此點作為截止頻率（頻帶的邊界）。

    在濾波器的頻率特性中，「−3 dB」點所表示的內容，下列哪一項正確？

  • 截止頻率處的衰減與階數無關，皆為−3 dB，其後n階以 −20n dB/dec 衰減。
