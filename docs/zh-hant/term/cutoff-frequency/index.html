什麼是截止頻率

濾波器或放大器的輸出從通帶下降 3 dB(約 0.707 倍)的頻率。在 RC 電路中為 1/(2πRC)。

日文名稱: カットオフ周波数

「截止頻率」出現在4領域的7道練習題中（類比與電子電路, 雙載子電晶體, AD/DA轉換等）。

這個名詞所屬的領域: 類比與電子電路

推導 RC 低通濾波器的 fc

RC 低通濾波器的轉移函數為 H = 1/(1 + jωRC)。當 ωRC = 1 時其大小等於 1/√2，因此截止頻率為 fc = 1/(2πRC)，此時相位落後恰好 45°。R = 1 kΩ、C = 1 µF 時，RC = 1 ms，fc ≈ 159 Hz。將 R 與 C 的位置對調，就成為 fc 相同的高通濾波器；RL 濾波器的 fc = R/(2πL)。

為什麼是 −3 dB 點

截止點定義在輸出電壓為通帶值的 1/√2 ≈ 0.707 之處。以分貝表示為 20·log10(0.707) ≈ −3.01 dB，又因功率與電壓平方成正比，它也是半功率點。不要與電壓減半的 −6 dB 混淆。部分濾波器類型，例如 Chebyshev 設計，常以其通帶漣波的邊緣而非 −3 dB 來規定，因此要確認所使用的定義。

截止點以外的斜率與濾波器階數

在遠高於 fc 處，一階濾波器以每十倍頻 20 dB（約每八度 6 dB）衰減，相當平緩：在 fc 的十倍處，訊號只降為十分之一。每增加一個極點就再增加每十倍頻 20 dB，因此 n 階濾波器以每十倍頻 20n dB 下降。更陡峭的截止，例如 ADC 前端抗混疊所需的，是以運算放大器構成二階或更高階的主動濾波器來實現。

作為放大器頻寬的截止頻率

對放大器而言，上側 −3 dB 頻率定義其頻寬，耦合電容也會產生下側截止。對電壓回授運算放大器而言，閉迴路頻寬約為增益頻寬積除以雜訊增益，因此增益越高頻寬越小。單極點系統也將頻寬與步階響應連結起來：10～90% 上升時間約為 0.35 除以 −3 dB 頻率，是時域與頻域之間方便的換算。

練習截止頻率的題目

由電阻R = 1 kΩ與電容C = 1 µF構成的RC低通濾波器，其截止頻率最接近下列哪一個？

  1. A約16 Hz
  2. B約160 Hz
  3. C約1.6 kHz
查看答案與解析

正確答案：B. 約160 Hz

RC濾波器的截止頻率為 fc = 1/(2πRC)，RC = 1×10³ × 1×10⁻⁶ = 1 ms，故 fc ≈ 159 Hz（約160 Hz）。在此頻率輸出為 −3 dB（約0.707倍），相位落後45°，高於此頻率後，頻率每增加10倍衰減 −20 dB。一階的衰減較為平緩，因此若要陡峭地截止，會使用運算放大器構成的二階以上主動濾波器。

常見問題

RC 濾波器的截止頻率公式是什麼？

fc = 1/(2πRC)。例如 1 kΩ 與 1 µF 得到約 159 Hz，此時輸出下降 3 dB，相移為 45°。

為什麼截止頻率定義在 −3 dB？

在 −3 dB 時，輸出電壓為通帶值的 1/√2，因此傳遞的功率減半；這個半功率點也恰好落在 RC 項等於 1 之處，得到簡單的公式。

截止頻率和頻寬一樣嗎？

對低通濾波器或放大器而言，頻寬通常以 −3 dB 截止頻率表示。對帶通濾波器而言，頻寬是上側與下側 −3 dB 頻率之差。

解析中的「截止頻率」

  • RC濾波器的截止頻率為 fc = 1/(2πRC)，RC = 1×10³ × 1×10⁻⁶ = 1 ms，故 fc ≈ 159 Hz（約160 Hz）。

    由電阻R = 1 kΩ與電容C = 1 µF構成的RC低通濾波器，其截止頻率最接近下列哪一個？

  • 不過它會與下一級的輸入電阻R構成高通濾波器，低於截止頻率 f = 1/(2πRC) 的頻率會被衰減。

    放大電路的級與級之間加入的耦合電容，其作用下列何者正確？

  • 截止頻率與低通相同，為 1/(2πRC)，低於此頻率時，頻率每降為1/10衰減 −20 dB。

    將電容串聯在訊號路徑中，並將電阻接在輸出與接地之間的RC電路，其特性下列哪一項正確？

  • −3 dB相當於功率約1/2、電壓 1/√2 ≈ 0.707倍，在濾波器與放大器中，以此點作為截止頻率（頻帶的邊界）。

    在濾波器的頻率特性中，「−3 dB」點所表示的內容，下列哪一項正確？

  • 截止頻率處的衰減與階數無關，皆為−3 dB，其後n階以 −20n dB/dec 衰減。
