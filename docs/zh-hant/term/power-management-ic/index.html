什麼是PMIC（電源管理 IC）

電源管理 IC。由電池等產生多種電壓，並管理電源開啟順序與電壓切換的元件。

日文名稱: PMIC

「PMIC（電源管理 IC）」出現在1領域的1道練習題中（DRAM等）。

這個名詞所屬的領域: 電源管理（軟體控制）

練習PMIC（電源管理 IC）的題目

在電腦的記憶體中，將多顆DRAM晶片裝在小型基板上、可供插入使用的零件稱為什麼？

  1. ASSD
  2. B主機板
  3. CDIMM（記憶體模組）
查看答案與解析

正確答案：C. DIMM（記憶體模組）

DIMM（Dual Inline Memory Module）是在1片基板上安裝多顆DRAM晶片的模組，因正反面的接點各自具有不同的訊號而稱為「雙（dual）」。可插入主機板的插槽進行更換、擴充，筆電用的小型品是SO-DIMM。伺服器用的有對訊號進行緩衝的RDIMM，DDR5的模組上還搭載了電源電路（PMIC）。
