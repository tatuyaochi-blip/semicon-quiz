什麼是TXRF(全反射X射線螢光分析)

使X射線以極小的掠射角照射晶圓表面而全反射，高靈敏度地量測表面微量金屬汙染所發出螢光X射線的分析法。

日文名稱: TXRF(全反射蛍光X線分析)

「TXRF(全反射X射線螢光分析)」出現在2領域的3道練習題中（量測與分析, 矽晶圓等）。

這個名詞所屬的領域: 量測與分析

全反射如何發揮作用

當 X 射線束以低於很小的臨界角（對矽而言約為 0.1° 的等級）照射平坦的拋光表面時，會被全反射，僅穿入數奈米。位於表面的原子同時受到入射束與反射束的激發，並放出具有各元素特徵能量的螢光 X 射線。置於晶圓上方近處的能量分散型偵測器會收集這些螢光。由於光束幾乎不進入基板，且散射的一次光束大多沿反射方向離開，因此背景非常低。

能偵測什麼、偵測得多好

TXRF 依螢光譜線的能量辨識元素，並依譜線強度定量，以參考樣品進行校正。鐵、鎳、銅、鋅等過渡金屬可在約 10⁹–10¹⁰ atoms/cm² 的等級進行非破壞量測，且一片晶圓可在多個點進行檢查。鈉與鋁等輕元素則難偵測得多，因為其低能量螢光微弱且容易被吸收。這些金屬之所以重要，是因為它們會在矽中形成深能階，縮短載子生命期、增加接面漏電流，並使閘極氧化層的完整性劣化。

以 VPD-TXRF 提高靈敏度

標準 TXRF 只對光束照射下的區域取樣。在氣相分解（VPD）中，氫氟酸蒸氣會溶解原生氧化膜，再以一小滴液滴掃過晶圓，收集整個表面的金屬。液滴乾燥後成為單一點，再以 TXRF 量測，使訊號濃縮，將靈敏度推進到約 10⁸–10⁹ atoms/cm²。所收集的液體也可改以感應耦合電漿質譜（ICP-MS）分析。與直接 TXRF 不同，此方法會消耗表面氧化膜，且無法提供空間資訊。

會在哪裡遇到

晶圓廠使用 TXRF 監控來自製程設備、化學品與搬運的金屬污染，例如在設備保養後讓裸測試晶圓通過該設備，或評估清洗步驟是否如預期去除金屬。它常與其他量測技術混淆：四點探針量測片電阻，橢圓偏光儀量測膜厚，兩者都無法看到微量污染。二次離子質譜（SIMS）同樣具有高靈敏度，但會濺擊樣品以取得縱深分布，而 TXRF 只觀察最外層表面。

練習TXRF(全反射X射線螢光分析)的題目

  2. BSEM觀察

正確答案：C. VPD(氣相分解)法

在VPD法中，以氫氟酸蒸氣分解晶圓表面的自然氧化膜，再以少量液滴在其上掃描，收集並回收表面的金屬雜質。將回收的液體以ICP-MS或全反射螢光X光(TXRF)分析，就能以10⁸〜10⁹ atoms/cm²左右的靈敏度量測整片晶圓的金屬汙染。這是監控設備與藥液汙染、評估清洗製程不可或缺的方法。

  1. A全反射X光螢光分析（TXRF）
  2. B四探針法
  3. C橢圓偏振術
查看答案與解析

正確答案：A. 全反射X光螢光分析（TXRF）

TXRF使X光以0.1°左右極淺的角度入射晶圓表面而發生全反射，量測表面附近原子放出的X光螢光。由於X光不會進入內部，來自基板的訊號很小，因此能以非破壞方式偵測約10⁹～10¹⁰ atoms/cm²的微量金屬。若先以氫氟酸蒸氣溶解表面氧化膜並收集到一點再量測，靈敏度還會更高。四探針法與橢圓偏振術無法得知污染。

常見問題

TXRF 的偵測極限是多少？

對矽晶圓上的過渡金屬而言，直接 TXRF 通常可達約 10⁹–10¹⁰ atoms/cm²；結合 VPD 預濃縮後，可改善到約 10⁸–10⁹ atoms/cm²。

為什麼 TXRF 使用掠射入射角？

在臨界角以下，X 射線會被全反射且只穿入數奈米，因此能強烈激發表面污染物，同時來自矽基板的背景訊號很少。

TXRF 能偵測鈉和鋁嗎？

效果很差。輕元素放出的低能量螢光微弱且容易被強烈吸收，因此一般較常使用 VPD-ICP-MS 等方法來分析它們。
