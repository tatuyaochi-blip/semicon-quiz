什麼是GPU

為 Graphics Processing Unit 的縮寫。擁有大量簡單運算單元，平行處理大量資料的處理器。除影像處理外，也廣泛用於 AI 的訓練與推論。

日文名稱: GPU

「GPU」出現在13領域的87道練習題中（GPU程式設計, AI硬體與軟體堆疊, 先進技術（3D構裝與小晶片）等）。

這個名詞所屬的領域: CPU與架構

GPU 的組成架構

GPU 內含許多串流多處理器（SM），每個 SM 是由簡單執行單元組成的叢集，擁有自己的暫存器與晶片內共享記憶體。GPU 不像 CPU 核心那樣以大型快取與精密的分支預測讓單一執行緒跑得快，而是讓數千個執行緒同時處於執行中，每當某一組在等待記憶體時就切換到另一組。這種做法以龐大的平行度來隱藏延遲，並將吞吐量最大化。執行緒以固定大小的群組排程，同一群組以鎖步方式一起發出相同指令；在 NVIDIA GPU 上，32 個執行緒組成一個 warp，這種模型稱為 SIMT（單指令多執行緒）。

SIMT 與 CPU 的 SIMD

CPU 的 SIMD 指令是對存放固定數量元素的向量暫存器套用同一個運算，程式設計師或編譯器必須針對該寬度撰寫程式。在 SIMT 中，程式設計師撰寫的是單一執行緒的一般程式碼，由硬體把執行緒分組成 warp。執行緒可以走不同的分支，但此時硬體會依序執行各條路徑，造成通道閒置浪費。因此，GPU 擅長以相同運算獨立處理每個元素的工作，而不擅長循序且依賴資料的工作，例如走訪鏈結串列。

記憶體頻寬是瓶頸

要供應數千個執行單元，需要極大的頻寬。繪圖卡使用 GDDR 記憶體，近幾代的每腳位速率超過 20 Gb/s，並以短走線配置在 GPU 周圍。AI 加速器則把堆疊式 HBM 透過矽中介層（2.5D 封裝）放在 GPU 旁邊；每個堆疊有 1,024 條資料線，因此數個堆疊可提供數 TB/s 的頻寬。軟體也必須配合：當相鄰執行緒讀取相鄰位址時，存取會合併為少數幾筆寬交易，這也是為什麼陣列結構（structure of arrays）通常勝過結構陣列（array of structures）。

GPU 程式如何撰寫

在 CUDA 及類似框架中，由 CPU 啟動 kernel，也就是讓許多 GPU 執行緒同時執行的函式。一次啟動會形成由多個 block 組成的 grid，每個 block 包含許多在同一個 SM 上執行、並可透過共享記憶體協作的執行緒。每個執行緒會計算自己的索引來選取一個資料元素，而防護條件 if (i < n) 可防止最後一個 block 中多出來的執行緒存取超出陣列範圍的記憶體。由於各 block 獨立執行，同一個程式可以在小型與大型 GPU 之間擴展。

練習GPU的題目

關於作為GPU圖形記憶體的GDDR，下列何者是其正確特徵？

  1. A是重視資料傳輸頻寬（速度）的規格
  2. B斷電後資料仍會保留
  3. C速度慢但非常便宜
查看答案與解析

正確答案：A. 是重視資料傳輸頻寬（速度）的規格

GDDR是為了讓GPU能高速處理大量影像資料而重視每支接腳傳輸速率的DRAM，以2025年時點的產品而言，GDDR6X達到20 Gb/s以上，GDDR7達到30 Gb/s左右（為DDR5的數倍）。它排列在基板上GPU的周圍，以短佈線連接。每單位容量的成本與耗電比DDR略高。需要更寬頻寬的AI加速器，則使用堆疊的HBM。

GPU 適合矩陣運算以及 AI 訓練與推論的主要原因為何？

  1. A因為時脈頻率是 CPU 的 100 倍以上
  2. B因為具有大量單純的運算單元，能平行處理大量資料
  3. C因為沒有記憶體
查看答案與解析

正確答案：B. 因為具有大量單純的運算單元，能平行處理大量資料

GPU 原本是為了同時處理螢幕上的大量像素，因此其結構是並排數千〜上萬個以上的單純運算單元。像矩陣運算這種對大量資料重複相同計算的處理，可藉由這種平行性發揮高效能。近年來 GPU 配備了矩陣運算專用單元（Tensor Core 等）與高頻寬的 HBM，已成為 AI 訓練的主角。分支多的循序處理則是 CPU 較為擅長。

常見問題

CPU 和 GPU 有什麼差別？

CPU 擁有少數幾個複雜核心，針對以低延遲完成個別工作而最佳化；GPU 則擁有大量簡單核心，針對高度平行工作的總吞吐量而最佳化。GPU 透過在數千個執行緒之間切換來隱藏記憶體延遲，而不是依賴大型快取。

AI 為什麼要用 GPU？

神經網路的訓練與推論主要由大型矩陣乘法構成，也就是對龐大陣列套用相同運算，這很自然地對應到數千個平行執行緒。HBM 等高頻寬記憶體則讓這些單元持續獲得資料供應。

什麼是 warp divergence（warp 分歧）？

指同一個 warp 中的執行緒走了不同分支；硬體會輪流執行每條路徑，其餘執行緒則閒置等待，使效率降低。讓同一 warp 內的分支條件一致即可避免。
