什麼是條件碼

表示比較或運算結果為零、負、進位、溢位等的旗標。x86與ARM的條件分支會查看它來分支。RISC-V沒有條件碼。

日文名稱: 条件コード

「條件碼」出現在1領域的1道練習題中（指令集與組合語言等）。

這個名詞所屬的領域: 指令集與組合語言

練習條件碼的題目

關於條件分支的機制，下列何者是RISC-V與x86的差異？

  1. ARISC-V查看旗標來分支，x86則由分支指令直接比較兩個暫存器
  2. B兩者都沒有條件分支的指令，而是以查表來決定跳躍目標
  3. CRISC-V由分支指令直接比較兩個暫存器，x86則查看比較指令所設定的旗標來分支
查看答案與解析

正確答案：C. RISC-V由分支指令直接比較兩個暫存器，x86則查看比較指令所設定的旗標來分支

在x86中，以「cmp eax, ebx」比較後會設定零或進位等旗標（條件碼），接著的「je」或「jl」查看旗標來分支。RISC-V沒有旗標，而是像「beq a0, a1, L」「blt a0, a1, L」這樣，由分支指令本身比較兩個暫存器。由於沒有旗標這種隱含的狀態，在重新排列指令或同時執行時，更容易追蹤相依關係。
