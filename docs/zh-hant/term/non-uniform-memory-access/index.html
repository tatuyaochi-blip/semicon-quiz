什麼是NUMA（非均勻記憶體存取）

Non-Uniform Memory Access 的縮寫。有離核心近與離核心遠的記憶體，存取遠處記憶體需要較長時間的架構。將資料與執行緒放在同一側會比較快。

日文名稱: NUMA

「NUMA（非均勻記憶體存取）」出現在1領域的1道練習題中（DRAM等）。

這個名詞所屬的領域: 多核心與同步

練習NUMA（非均勻記憶體存取）的題目

在現今多數電腦用處理器中，控制DRAM的記憶體控制器位於何處？

  1. ADRAM晶片之中
  2. B處理器的晶片（封裝）之中
  3. CSSD之中
查看答案與解析

正確答案：B. 處理器的晶片（封裝）之中

過去記憶體控制器位於主機板上的晶片組（北橋），但自2003年的AMD Opteron、2008年的Intel Core i7（Nehalem）以後，一般都內建在處理器中。CPU與記憶體之間的路徑縮短，延遲改善了數十%。在具有多顆CPU的伺服器中，會形成直接連接到各CPU的記憶體速度較快的NUMA架構。
