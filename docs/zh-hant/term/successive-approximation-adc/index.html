什麼是逐次逼近式ADC

使用內部的DAC與比較器，從高位元開始每次決定一個位元的ADC。速度、精度與耗電量的平衡良好。

日文名稱: 逐次比較型ADC

「逐次逼近式ADC」出現在1領域的3道練習題中（AD/DA轉換等）。

這個名詞所屬的領域: AD/DA轉換

二分搜尋，每步一個位元

逐次逼近暫存器（SAR）ADC 首先將輸入取樣到保持電容上。接著控制邏輯將內部 DAC 的最高有效位元設為 1，產生滿刻度的一半，由比較器判斷輸入在其之上或之下，並據此保留或清除該位元。然後試下一個位元，每次將剩餘範圍減半。經過 N 次比較後，暫存器便保存 N 位元的結果，因此轉換時間只隨解析度線性增加。

電容式 DAC

在大多數 CMOS SAR ADC 中，DAC 是一組二進位加權的電容陣列，同時兼作取樣電容，這種做法稱為電荷重分配。轉換期間，各電容的下極板在參考電壓之間切換，比較器則監看所產生的上極板電壓。由於陣列主要在切換時才消耗能量，且只有一個比較器，功耗大致與取樣率成正比，這就是 SAR 轉換器在微控制器與電池供電感測器中廣受歡迎的原因。

驅動輸入

擷取開始時，輸入端會看到數 pF 到數十 pF 的取樣電容，必須在短暫的擷取時間內充電完成。要穩定到 N 位元轉換器的半個 LSB 以內，約需 (N+1)·ln2 個時間常數，16 位元時約為 11.8 個時間常數。高阻抗的訊號源無法達到此要求，因此要使用低輸出阻抗的運算放大器驅動器，並搭配 RC 濾波器，由其電容（charge bucket）提供瞬間的電荷衝擊。

SAR 與快閃式、Δ-Σ ADC

快閃式 ADC 使用 2ᴺ − 1 個比較器一步完成轉換，因此速度非常快，但耗電且只限於低解析度。Δ-Σ ADC 透過超取樣與數位濾波達到高解析度，但頻寬較低，其數位濾波器還會增加延遲。SAR ADC 介於兩者之間，通常提供約 10 至 18 位元、取樣率最高每秒數百萬次的性能，且每次結果都沒有管線延遲，適合多工通道。

練習逐次逼近式ADC的題目

在逐次逼近式ADC的輸入前放置運算放大器等驅動電路的主要理由為下列何者？

  1. A為了改變輸入訊號的顏色
  2. B為了在短時間內對ADC內部的取樣電容充電，以準確取入輸入電壓
  3. C為了讓ADC的功耗變為0
查看答案與解析

正確答案：B. 為了在短時間內對ADC內部的取樣電容充電，以準確取入輸入電壓

SAR式ADC在取樣瞬間將內部電容（數pF～數十pF）接到輸入，因此若訊號源阻抗高，在短暫的擷取時間內無法充滿，就無法準確取入電壓。要穩定到N位元精度，需要時間常數約(N+1)·ln2倍的時間。對策是結合低輸出阻抗的驅動器，以及暫時供應電荷的RC濾波器（電荷桶，charge bucket）。

許多逐次逼近式ADC中，作為內部DAC使用的方式為下列何者？

  1. A僅限R-2R電阻梯形式
  2. B僅限電流導向式
  3. C利用電容比的電容陣列（電荷重新分配）式
查看答案與解析

正確答案：C. 利用電容比的電容陣列（電荷重新分配）式

許多SAR式ADC使用排列二進位權重（C、2C、4C…）電容的電容陣列，以開關切換電容下側的電位並重新分配電荷，藉此產生比較電壓。電容陣列可兼作取樣電容，且沒有靜態電流流過，因此功耗低。在CMOS中，電容比比電阻更容易做得精準也是優點，從微控制器到感測器都廣泛使用。

常見問題

SAR ADC 需要幾個時脈週期？

每個位元至少比較一次，因此 N 位元需要 N 個週期，另加上擷取時間，有時還有用來修正早期判定錯誤之冗餘位元的額外週期。

為什麼 SAR ADC 需要驅動放大器？

其切換式取樣電容在每次擷取時都會抽取一陣電荷，高阻抗訊號源無法及時準確地重新充電；以低阻抗運算放大器加上 RC charge-bucket 濾波器即可解決。

應該使用 SAR 還是 Δ-Σ ADC？

SAR 適合中高解析度、快速且無延遲的轉換，以及多工輸入；Δ-Σ 適合低頻寬下的極高解析度，例如精密感測器與音訊量測。
