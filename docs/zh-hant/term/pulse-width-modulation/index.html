什麼是PWM（脈衝寬度調變）

在週期固定的情況下，改變輸出為 High 的時間長度，以調整平均電壓與電力的方式。用於調整 LED 的亮度與馬達的轉速。

日文名稱: PWM(パルス幅変調)

「PWM（脈衝寬度調變）」出現在3領域的5道練習題中（嵌入式與韌體, 功率半導體, AD/DA轉換等）。

這個名詞所屬的領域: 嵌入式與韌體

工作週期與平均值

脈衝寬度調變（PWM）維持切換週期 T 固定，改變高電位時間 t_on。工作週期 D = t_on/T 決定平均輸出，即脈衝振幅的 D 倍：5 V 訊號在 40% 工作週期下平均為 2 V。資訊完全由時間承載，因此輸出級始終只處於兩種準位。相對於週期而言反應較慢的負載，例如馬達、加熱器、觀看 LED 的人眼，或是 RC 或 LC 濾波器，主要感受到的就是這個平均值。

微控制器計時器如何產生 PWM

硬體計時器從 0 開始計數時脈脈衝，直到週期值後重新開始。輸出在每個週期開始時設為高電位，當計數器與比較暫存器相符時清除為低電位。若週期為 1000 個計數、比較值為 250，輸出就有 25% 的時間為高電位。解析度由每週期的計數數決定，因此在計時器時脈固定的情況下，PWM 頻率越高，工作週期的步階就越粗。設定完成後，計時器無需 CPU 介入即可運作。類比 PWM 電路則以控制電壓與三角波或鋸齒波比較，完成同樣的工作。

切換為何有效率

切換用電晶體不是完全導通（兩端電壓很小），就是完全截止（幾乎沒有電流），因此其功耗遠低於線性電路中維持在中間電壓的電晶體。損耗主要來自導通電阻以及狀態之間短暫的轉換過程。頻率依負載而定：要高到看不出 LED 閃爍、馬達電流能被繞組電感平滑化，且常設在可聽範圍以上以避免馬達嘯叫，但又不能高到讓切換損耗成為主導。

PWM 作為 DAC 與在電力電子中的應用

將 PWM 通過低通濾波器，就能在沒有專用 DAC 硬體的情況下得到簡易的數位類比轉換器；將 PWM 頻率設得遠高於濾波器截止頻率可降低漣波，代價是響應變慢。同樣的原理也驅動著交換式電源供應器（理想的降壓轉換器輸出為輸入電壓的 D 倍），以及以數 kHz 到數十 kHz 切換功率元件、同時改變脈衝寬度以合成交流電的變頻器（inverter）。三相馬達變頻器使用 6 個開關，每個橋臂 2 個。

查看答案與解析

正確答案：A. 脈波的工作比（一個週期中導通時間所佔的比例）

將PWM訊號以低通濾波器平均後，輸出電壓為「振幅 × 工作比」，5 V、40%時約為2 V。解析度由計時器的計數值決定，若讓PWM頻率遠高於濾波器截止頻率，漣波會減少。由於不需專用DAC就能產生類比電壓，被用於LED調光、馬達速度控制與簡易的聲音輸出，但回應速度與精度需與漣波取捨。

在週期為1000計數的PWM訊號中，每個週期只有250計數的期間輸出為1（High）。工作週期（duty ratio）是多少？

  1. A75%
  2. B25%
  3. C250%
查看答案與解析

正確答案：B. 25%

工作週期是一個週期內輸出為High的時間所占的比例，250÷1000=25%。PWM（脈寬調變）在週期固定的情況下改變High的時間長度，藉此調整平均電壓或功率。微控制器的計時器透過比較計數器的值與比較值來切換輸出，不需CPU介入就能持續輸出PWM訊號。

常見問題

PWM 工作週期怎麼計算？

以高電位時間除以週期：工作週期 = t_on / T。例如在 1000 個計數的週期中有 250 個計數為高電位，工作週期即為 25%，平均輸出為脈衝振幅的 25%。

PWM 改變的是頻率還是電壓？

在基本形式下兩者都不變：頻率與脈衝振幅保持固定，只有脈衝寬度改變。由於導通時間所佔比例改變，傳送到負載的平均電壓或功率也隨之改變。

驅動馬達時，為什麼 PWM 比線性穩壓器有效率？

線性穩壓器將多餘的電壓降在承載全部電流的電晶體上，以熱的形式浪費掉。使用 PWM 時電晶體不是完全導通就是完全截止，因此其電壓與電流的乘積，也就是損耗，始終很小。
