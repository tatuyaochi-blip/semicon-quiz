什麼是無晶圓廠設計公司(Fabless)

自己不擁有製造工廠，專注於半導體設計與銷售的企業型態。

這個名詞所屬的領域: 半導體產業與市場

Fabless 公司如何打造晶片

Fabless 公司不擁有晶圓製造廠。它定義產品規格、撰寫並驗證暫存器傳輸級（RTL）設計，再使用代工廠的製程設計套件（PDK）、商用電子設計自動化（EDA）工具以及常見的授權 IP 區塊完成實體設計。完成的佈局交付（tape-out）給代工廠製造晶圓；封裝與測試則由委外封裝測試（OSAT）公司負責，近年也越來越多由代工廠承接。之後由 fabless 公司銷售產品，因此其價值在於架構、電路設計、軟體與客戶關係，而非製造。

這種模式為何普及

先進晶圓廠需要龐大投資，且每一世代都越來越昂貴，而單一公司的產品往往無法讓這樣的晶圓廠滿載。將製造集中到專業代工廠，可讓眾多客戶共用設備並維持高稼動率，設計公司也免於資本負擔。這降低了進入門檻，即使是年輕的公司也能將先進晶片推向市場。典型的 fabless 產品包括智慧型手機系統單晶片（SoC）、GPU、通訊與網路晶片。部分整合元件製造商也透過出售或關閉晶圓廠而轉向這種模式。

Fabless、IDM 與 Fab-lite

整合元件製造商（IDM）自行設計、製造、封裝並銷售晶片。設計與製程團隊在同一家公司內，較容易共同最佳化兩者，這在製造技術本身就是產品差異化關鍵的記憶體、功率與類比元件領域尤其重要。Fab-lite 公司介於兩者之間：保留其具獨特優勢的成熟製程與特殊技術晶圓廠，同時將先進產品委外給代工廠。這種模式常見於希望控制資本支出、又不想失去製造技術的微控制器、類比與功率半導體廠商。

Fabless 公司放棄了什麼

沒有自有晶圓廠，fabless 公司就得依賴代工廠的產能、價格與時程，產能短缺時還必須與其他客戶競爭投片量。它們只能在代工廠的規則與元件選項範圍內設計，客製化製程的能力有限，不過大客戶會與代工廠密切合作進行設計與技術協同最佳化。先進代工產能集中在少數地點，也使供應風險集中。作為交換，它們獲得了依產品選擇製程的彈性，並能將資本投入研發而非廠房。

  2. B不擁有自家製造工廠，專注於設計與銷售的企業
  3. C只接受半導體後段製程委託的企業
查看答案與解析

正確答案：B. 不擁有自家製造工廠，專注於設計與銷售的企業

無晶圓廠（fab-less）的意思是沒有製造工廠（fab）的企業。它將經營資源集中於設計與銷售，製造委託給晶圓代工廠，封裝與測試則委託給OSAT。由於不需要對工廠做龐大投資，新創企業也能推出先進產品，GPU與智慧型手機用SoC的大廠多半採取這種型態。從設計到製造皆由自家完成的企業是IDM，承接後段製程委託的企業則是OSAT。

與在自家工廠進行製造的IDM（整合元件製造商）相比，無晶圓廠（Fabless）企業的一般特徵，下列何者適當？

  1. A由於製造設備等有形固定資產多，工廠稼動率下降時，折舊費用等固定成本的負擔變重，利益容易大幅減少
  2. B由於沒有工廠，有形固定資產與固定成本相對較少，委託晶圓代工廠製造的費用主要是隨產量變動的費用
  3. C由於製造委外，產品設計與開發所需的研發費用幾乎不會發生
查看答案與解析

正確答案：B. 由於沒有工廠，有形固定資產與固定成本相對較少，委託晶圓代工廠製造的費用主要是隨產量變動的費用

無晶圓廠企業專注於設計與銷售，製造則委託晶圓代工廠，因此不必自行負擔龐大的工廠投資及其折舊費用。因此固定成本占比低，損益兩平點也較容易偏低，需求下滑時利益減少的幅度往往比IDM小。另一方面，由於無法自行確保製造產能，需求突然增加時能否確保晶圓代工廠的產能就成為課題，有時會以長期合約確保生產額度。

常見問題

半導體產業中的 fabless 是什麼意思？

Fabless 指公司沒有自己的晶圓廠（晶圓製造工廠）。它設計並銷售晶片，將製造委外給晶圓代工廠，封裝與測試則委外給 OSAT。

Fabless 和 IDM 有什麼差別？

Fabless 公司只負責設計與銷售晶片，仰賴外部廠商製造。IDM（整合元件製造商）則在公司內部完成設計、製造與銷售。

什麼是 fab-lite 公司？

Fab-lite 公司保留部分用於成熟或特殊製程的晶圓廠，同時將最先進的產品委外給代工廠。這是介於 fabless 與完整 IDM 之間的折衷做法。
