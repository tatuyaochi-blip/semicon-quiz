什麼是管線（|）

在 shell 中寫成「指令1 | 指令2」，把左邊指令的標準輸出直接連到右邊指令的標準輸入的機制。像 sort ips.txt | uniq -c | sort -nr 這樣串接多個小指令（管線），不必建立中間檔案就能組合出複雜的處理。兩側的指令同時運作，資料依序流過。標準錯誤輸出不會被連接，若要連錯誤一起傳遞，需搭配 2>&1。
