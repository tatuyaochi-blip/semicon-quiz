什麼是二分搜尋

在已排序的資料中，與中央元素比較，每次把搜尋範圍縮小一半的搜尋方法。從 n 個資料中最多以 ⌊log₂ n⌋ + 1 次比較找到，時間複雜度為 O(log n)。前提是資料已排序。

日文名稱: 二分探索

「二分搜尋」出現在3領域的7道練習題中（資料結構與演算法, AD/DA轉換, 軟體開發與專案管理等）。

這個名詞所屬的領域: 資料結構與演算法

練習二分搜尋的題目

與陣列中央的元素比較、每次將搜尋範圍縮小一半的二分搜尋，其使用的前提條件為下列何者？

  1. A資料的個數是2的冪次
  2. B資料依鍵的順序排序
  3. C資料中不含相同的值
查看答案與解析

正確答案：B. 資料依鍵的順序排序

二分搜尋依與中央元素比較的結果，判斷目標值在前半還是後半，將範圍減半。這是因為資料已排序才能如此判斷，未排序的陣列無法使用。即使資料個數不是2的冪次，只要以 (下端 + 上端) ÷ 2 無條件捨去等方式決定中央位置，就能正常運作。即使含有相同的值也能搜尋，會找到其中某一個（若要找出最前面的位置則需要一點技巧）。

以二分搜尋在依升冪排序的1,000個不同值中尋找某個值。若1次比較就能得知「相等、較小、較大」，包含找得到與找不到的情況，比較次數最多為幾次？

  1. A10次
  2. B32次
  3. C500次
查看答案與解析

正確答案：A. 10次

每比較1次，搜尋範圍約減為一半，而 2¹⁰ = 1024 ≥ 1000，因此最多10次範圍就會用盡（⌊log₂ 1000⌋ + 1 = 10）。時間複雜度為 O(log n)，即使有100萬個也最多只需20次。32次相當於 √1000 ≈ 31.6，500次則接近線性搜尋的平均（約 n/2）。不過，二分搜尋需要資料已排序，也必須考慮排序所需的 O(n log n) 工作量。

半導體、電子電路與資訊計算工具

二元搜尋樹與堆積視覺化工具將依序插入值所建立的二元搜尋樹或堆積畫成圖，並顯示前序、中序、後序的走訪順序、搜尋路徑與堆積的陣列時間複雜度（大O）比較工具以 O(log n)、O(n)、O(n log n)、O(n²)、O(2ⁿ) 等比較隨資料數而變的處理次數與時間，也能估算資料數改變時的處理時間
