什麼是HBM(高頻寬記憶體)

以TSV堆疊多個DRAM晶粒，藉由非常寬的匯流排寬度實現高頻寬的記憶體。

日文名稱: HBM

「HBM(高頻寬記憶體)」出現在10領域的29道練習題中（先進技術（3D構裝與小晶片）, 半導體產業與市場, DRAM等）。

練習HBM(高頻寬記憶體)的題目

下列關於HBM（High Bandwidth Memory，高頻寬記憶體）的說明，何者正確？

  1. A只使用一層快閃記憶體的低速記憶體
  2. B內建於CPU晶片內的SRAM快取
  3. C將多個DRAM晶粒以TSV堆疊，並以非常寬的匯流排寬度獲得高頻寬的記憶體
查看答案與解析

正確答案：C. 將多個DRAM晶粒以TSV堆疊，並以非常寬的匯流排寬度獲得高頻寬的記憶體

HBM是將多個DRAM晶粒以TSV堆疊，並以1,024條這種非常寬的資料匯流排與處理器連接，藉此實現高資料傳輸頻寬的記憶體。例如HBM3每條為6.4 Gb/s，單一堆疊約為819 GB/s。它用於與處理器並排配置在矽中介層等之上的2.5D封裝，並搭載於AI用GPU等產品。它與快閃記憶體或SRAM快取是不同的東西。

在AI用GPU中，將GPU晶片與HBM並排安裝在同一個矽中介層上的主要理由是下列何者？

  1. A為了增加零件數量
  2. B為了以極大量的配線在晶片之間短距離連接，獲得非常高的記憶體頻寬
  3. C為了減少記憶體容量
查看答案與解析

正確答案：B. 為了以極大量的配線在晶片之間短距離連接，獲得非常高的記憶體頻寬

HBM單一堆疊有1,024條資料線，並排多個堆疊就達到數千條，一般的封裝基板無法容納這麼多配線。在可製作微細配線的矽中介層上並排GPU與HBM，就能以大量配線在數mm的短距離內連接，實現AI運算所需的數TB/s記憶體頻寬。並不是為了增加零件數量或減少容量。
