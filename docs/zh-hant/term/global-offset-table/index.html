什麼是GOT（全域偏移表）

彙整外部變數與函式實際位址的表。由動態連結器在執行時填入，位置無關程式碼透過此表進行參照，因此不必改寫程式碼的分頁。

日文名稱: GOT(グローバルオフセットテーブル)

「GOT（全域偏移表）」出現在1領域的5道練習題中（連結器與載入器與執行檔格式等）。

  1. A是將函式庫中的函式名稱依字母順序排列的目錄
  2. B是暫時存放快取放不下的資料的表
  3. C是彙整外部變數與函式之實際位址的表，由動態連結器在執行時填入，程式碼透過這張表來參照
查看答案與解析

正確答案：C. 是彙整外部變數與函式之實際位址的表，由動態連結器在執行時填入，程式碼透過這張表來參照

位置獨立程式碼無法將位於其他函式庫中的變數位址直接寫入指令。因此每個模組會準備一張排列位址的表（GOT），程式碼以與PC的距離讀取GOT的項目，並使用其中的位址。動態連結器在載入時，會將實際位址寫入GOT。被改寫的只有可寫入的資料GOT，因此程式碼的分頁可維持共用。

  • 在位置獨立程式碼中，函式與資料不是以固定位址參照，而是透過與PC的距離，或彙整位址的表（GOT）來參照。

    關於位置獨立程式碼（PIC），下列說明何者正確？

  • 在延遲繫結中，第一次呼叫時入口會跳到動態連結器的解析處理，尋找真正的位址並寫入GOT。
