什麼是通道長度調變

處於飽和區的 MOSFET 中，提高汲極電壓時夾止點移向源極側，有效通道長度縮短，使汲極電流略為增加的現象。使輸出電阻成為有限值。

日文名稱: チャネル長変調

「通道長度調變」出現在1領域的2道練習題中（MOSFET等）。

這個名詞所屬的領域: MOSFET

飽和區中汲極電流為何持續上升

當VDS超過VGS − Vth時，通道汲極端的反轉層消失，這種狀態稱為夾止（pinch-off）。VDS再增加的部分，會由夾止點與汲極之間一段很短的空乏區承受，而這段空乏區會隨VDS增大而變寬。因此夾止點往源極移動，剩下有效長度為L − ΔL的導電通道。由於汲極電流與通道長度成反比，且剩餘通道兩端的電壓維持在VGS − Vth附近，電流會略為上升，而不是完全平坦。

λ模型與輸出電阻

通道長度調變通常是在平方律公式中加入一個因子來建模：ID = (1/2)μCox(W/L)(VGS − Vth)²(1 + λVDS)，其中λ為通道長度調變係數。ID對VDS的斜率約為λID，因此小訊號輸出電阻ro ≈ 1/(λID)。由於ΔL在短通道中所占比例較大，λ大致與L成反比，L加倍時ro也大約加倍。在短通道元件中，汲極引致能障降低（DIBL）也會增加輸出電導。

對類比設計的重要性

單一電晶體的本質增益為gm·ro，代入gm = 2ID/(VGS − Vth)後變成2/(λ(VGS − Vth))。在高度微縮的電晶體中，這個值只有約10–20，對許多放大器來說並不足夠。設計者的對策是在類比區塊中使用比最小尺寸更長的通道、堆疊疊接（cascode）元件以倍增輸出電阻，以及採用多級增益。通道長度調變也會劣化電流鏡：參考元件與輸出元件之間的汲極電壓不一致，會產生與λ成正比的電流誤差。

通道長度調變與爾利效應

雙載子電晶體也有類似的效應，稱為爾利效應（Early effect）或基極寬度調變。集極-射極電壓升高時，集極-基極空乏區變寬，使中性基極變窄，集極電流略為增加。其強度以爾利電壓VA表示，也就是外插後的輸出特性曲線與電壓軸的交點，可得ro ≈ VA/IC。對MOSFET而言，對應的量是1/λ，有時也稱為爾利電壓。兩種效應都會使原本平坦的輸出特性曲線傾斜，限制了單一元件所能提供的電壓增益。

練習通道長度調變的題目

以通道長度調變係數λ與汲極電流ID表示飽和區MOSFET的小訊號輸出電阻ro，下列何者為適當的公式？

  1. Aro ≈ 1 / (λ × ID)
  2. Bro ≈ ID / λ
  3. Cro ≈ λ × ID
查看答案與解析

正確答案：A. ro ≈ 1 / (λ × ID)

考慮通道長度調變時，飽和區的汲極電流呈 ID(1 + λVDS) 的形式，隨VDS略微增加，此斜率的倒數即為輸出電阻 ro ≈ 1/(λID)。λ幾乎與通道長度成反比，因此在相同汲極電流下將L加倍，ro也約加倍。單一電晶體的最大電壓增益為 gm·ro，在微細電晶體中只有10～20倍左右，因此要以疊接（cascode）或多級架構來確保增益。

常見問題

MOSFET汲極電流公式中的λ是什麼？

λ是通道長度調變係數，透過(1 + λVDS)這個因子，描述VDS每增加1 V時飽和汲極電流上升的程度。其倒數相當於爾利電壓，並決定輸出電阻ro ≈ 1/(λID)。

為什麼類比電路要使用較長的通道長度？

長通道中夾止點的移動只占L的一小部分，因此通道長度調變較弱。較長的元件具有較高的輸出電阻與本質增益，匹配性也較佳。

通道長度調變和爾利效應有什麼不同？

兩者都會讓輸出電流隨輸出電壓上升，並造成有限的輸出電阻。通道長度調變是縮短MOSFET的有效通道，爾利效應則是使雙載子電晶體的中性基極變窄。
