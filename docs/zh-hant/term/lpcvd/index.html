什麼是LPCVD(低壓化學氣相沉積)

在減壓下進行的熱CVD。由於氣體分子擴散較快，膜厚均勻性與階梯覆蓋率良好，且可在立式爐管中一次處理大量晶圓。用於多晶矽與氮化膜的成膜。

日文名稱: LPCVD(減圧CVD)

「LPCVD(低壓化學氣相沉積)」出現在1領域的6道練習題中（薄膜沉積（CVD與PVD）等）。

這個名詞所屬的領域: 薄膜沉積（CVD與PVD）

為什麼低壓能得到均勻的薄膜

低壓化學氣相沉積（LPCVD）是在約數十至數百帕斯卡下進行的熱 CVD。氣體擴散係數隨壓力降低而上升，因此反應物能迅速到達每個表面，成長速率由表面反應而非氣體傳輸決定。表面反應控制的製程主要取決於溫度，而熱壁式爐管能讓溫度維持非常均勻。這就是為什麼晶圓之間只隔數毫米、每次常放入超過一百片，仍能得到均勻、共形且階梯覆蓋良好的薄膜。

典型薄膜與化學反應

多晶矽是在約 600 至 650 °C 分解矽甲烷（SiH4）沉積而成；低於約 580 °C 時，薄膜會是非晶態。氮化矽由二氯矽烷與氨在約 700 至 800 °C 下生成，氧化層則在相近的爐管溫度下由 TEOS 分解而得。多晶矽可藉由加入磷化氫或乙硼烷進行臨場摻雜，這對覆蓋深溝槽內壁的薄膜很有用。沉積速率不高，通常為每分鐘數奈米到數十奈米，靠大批量來彌補。

LPCVD 與 PECVD 的比較

電漿增強 CVD（PECVD）以電漿在數百度下驅動反應，因此可在金屬化之後使用，但其薄膜密度較低、含氫較多，蝕刻速率也較快。LPCVD 薄膜緻密且接近化學計量比；LPCVD 氮化膜只含數 % 的氫，PECVD 氮化膜則約含 20%。化學計量比的 LPCVD 氮化膜也具有高拉伸應力，因此 MEMS 薄膜結構常使用富矽的低應力版本。LPCVD 品質的代價是它的熱預算。

會在哪裡遇到

由於需要 600 至 800 °C，LPCVD 屬於前段製程，用在鋁或銅配線形成之前。典型用途包括多晶矽閘極與電阻、氮化膜硬遮罩與側壁間隔層、隔離用的墊氮化層、DRAM 的電容電極、快閃記憶體的浮動閘極或電極，以及 MEMS 的結構層。薄膜也會沉積在爐管上以及每片晶圓的兩面，因此爐管需要定期清潔，背面的薄膜有時也必須去除。

正確答案：A. 因在低壓下進行，膜厚均勻性佳，且可一次處理大量晶圓

LPCVD是減壓至數十～數百Pa左右進行的熱CVD。減壓後氣體分子的擴散變快，成膜速率由表面反應決定（表面反應限速），因此即使將晶圓以數mm的間隔直立排列100片以上，也能得到均勻的薄膜。階梯覆蓋率也佳，用於多晶矽、氮化矽膜、TEOS氧化膜等的成膜。溫度高達600～800 ℃左右，無法用於配線形成之後。

以LPCVD沉積多晶矽膜時，一般使用的原料氣體為下列何者？

  1. A氬
  2. B矽烷（SiH4）
  3. C二氧化碳
查看答案與解析

正確答案：B. 矽烷（SiH4）

多晶矽是將矽烷在約600～650 ℃熱分解（SiH4 → Si + 2H2）而沉積。晶粒大小隨成膜溫度而異，低於約580 ℃時會成為非晶矽。用於閘極電極（High-k之前）、電阻、DRAM與快閃記憶體的電極、MEMS的結構體等，並在成膜中或事後摻入雜質以降低電阻。

常見問題

LPCVD 和 PECVD 有什麼差別？

LPCVD 只靠約 600 至 800 °C 的熱，能以大批量得到緻密、低含氫且均勻的薄膜。PECVD 以電漿在數百度下沉積，可以用在金屬之上，代價是薄膜的緻密度與純度。

為什麼 LPCVD 的沉積這麼均勻？

在低壓下氣體擴散很快，因此成長受表面反應限制，而表面反應主要取決於溫度。熱壁式爐管讓整批所有晶圓的溫度都保持均勻。

LPCVD 多晶矽在什麼溫度下沉積？

通常以矽甲烷在約 600 至 650 °C 下沉積。在約 580 °C 以下沉積會得到非晶矽，可在之後以退火使其結晶。
