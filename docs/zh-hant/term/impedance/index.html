什麼是阻抗

在交流電路中，以電壓相量除以電流相量所得的複數 Z = V/I [Ω]。實部為電阻R，虛部為電抗X，寫成 Z = R + jX。線圈為 jωL，電容器為 1/(jωC) = −j/(ωC)，大小會隨頻率改變。大小 |Z| 表示電壓與電流振幅的比，角度表示電壓相對於電流的相位超前。

這個名詞所屬的領域: 電路分析（交流電路、線性電路與暫態現象）

把電阻擴展到交流的量

阻抗讓直流的歐姆定律 V = RI 在交流中能以複數寫成 V = ZI。Z = 3 + j4 Ω 時，大小為 √(3² + 4²) = 5 Ω，角度約53.1°，電流比電壓落後53.1°。串聯時阻抗相加、並聯時倒數（導納）相加，計算規則與電阻相同。

隨頻率改變的元件性質

線圈的電抗 ωL 與頻率成正比增大，電容器的電抗 1/(ωC) 與頻率成反比減小。因此在直流時線圈如同短路、電容器如同開路，高頻時則相反。濾波器、共振電路與電源的去耦合，都是利用這種頻率相依性。

各式各樣的「阻抗」

放大電路的輸入阻抗與輸出阻抗、配線的特性阻抗、電源路徑的阻抗等，電子電路在許多場合都會用到這個詞。它們都是「從某對端子看進去的電壓與電流之比」這個相同的概念。高速信號中，若配線的特性阻抗與終端的阻抗不一致，就會產生反射。

練習阻抗的題目

電阻R = 30 Ω與電抗XL = 40 Ω的線圈串聯的電路，其阻抗大小是多少？（忽略線圈的電阻成分）

  1. A70 Ω
  2. B10 Ω
  3. C50 Ω
查看答案與解析

正確答案：C. 50 Ω

電阻與線圈的電壓相位相差90°，因此不能直接相加，要以複數（向量）合成。Z = R + jXL = 30 + j40 Ω，大小為 √(30² + 40²) = √2500 = 50 Ω。電流比電壓落後 φ = tan⁻¹(40/30) ≈ 53°，功率因數為 cos φ = 30/50 = 0.6。

在匝數比 N1:N2 = 10:1 的理想變壓器二次側接上8 Ω的電阻負載。從一次側看進去的阻抗是多少？

  1. A800 Ω
  2. B80 Ω
  3. C0.8 Ω
查看答案與解析

正確答案：A. 800 Ω

理想變壓器中，一次側電壓為二次側的 n = N1/N2 倍，電流為 1/n 倍，因此從一次側看進去的阻抗 V1/I1 是二次側 V2/I2 的 n² 倍。10² × 8 Ω = 800 Ω。由於這種阻抗轉換的性質，變壓器也用於放大器與喇叭之間等的阻抗匹配。

常見問題

阻抗與電阻有什麼不同？

電阻是電壓與電流之比不隨頻率改變、也沒有相位差的情形，相當於阻抗的實部。阻抗則以複數表示，也包含線圈與電容器造成的相位差與隨頻率的變化。

只靠阻抗的大小能計算功率嗎？

不能。求有效功率時，必須以電流的平方乘上實部（電阻成分），或使用功率因數 cos φ = R/|Z|。例如 8 + j6 Ω 上流過10 A時，消耗的功率為 10² × 8 = 800 W，用 |Z| = 10 Ω 算出的1,000 VA是視在功率。
