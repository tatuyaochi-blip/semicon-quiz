什麼是SWOT 分析

將企業內部的因素整理為優勢（Strengths）與劣勢（Weaknesses），將外部環境的因素整理為機會（Opportunities）與威脅（Threats），據以思考策略的手法。

日文名稱: SWOT分析

「SWOT 分析」出現在1領域的1道練習題中（經營策略與會計基礎等）。

這個名詞所屬的領域: 經營策略與會計基礎

練習SWOT 分析的題目

某生產車用功率半導體的企業進行了SWOT 分析。下列何者屬於「機會（Opportunities）」？

  1. A本公司擁有兼顧高耐壓與可靠度的獨家製造技術
  2. B以低價為武器的新競爭企業正進入同一市場
  3. C隨著電動車的普及，車用功率半導體的需求正在成長
查看答案與解析

正確答案：C. 隨著電動車的普及，車用功率半導體的需求正在成長

SWOT 分析是將企業內部的因素分為優勢（Strengths）與劣勢（Weaknesses），將外部環境的因素分為機會（Opportunities）與威脅（Threats）來整理的手法。市場需求的成長是企業無法決定的外部因素，對事業而言是順風，因此屬於機會。本公司的技術是內部因素，屬於優勢；新競爭企業的進入是外部因素，屬於威脅。整理的結果用於組合各項因素來思考策略，例如運用優勢掌握機會。
