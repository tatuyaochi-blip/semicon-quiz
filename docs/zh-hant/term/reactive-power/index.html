什麼是虛功率

交流電路中，只在電源與負載之間來回、平均而言不被消耗的功率。設電壓與電流的相位差為φ，Q = VI sin φ [var]，與有效功率 P = VI cos φ [W]、視在功率 S = VI [VA] 之間有 S² = P² + Q² 的關係（功率三角形）。複數功率為 S = V × （I的共軛） = P + jQ，例如 P = 800 W、Q = 600 var 時 S = 1,000 VA，功率因數0.8。虛功率會增加電線的電流而造成損失，因此會以電容器抵銷來改善功率因數。

練習虛功率的題目

在交流電路中，設有效功率為P [W]、視在功率為S [VA]，表示功率因數的式子是哪一個？

  1. AP / S
  2. BS / P
  3. CP × S
查看答案與解析

正確答案：A. P / S

功率因數是有效功率P與視在功率S（電壓有效值 × 電流有效值）之比 P/S。正弦波時，可用電壓與電流的相位差φ表示為 cos φ。例如 S = 2000 VA、P = 1800 W 時，功率因數為0.9。功率因數低時，傳送相同的有效功率需要較大的電流，配線與變壓器的損失會增加。

有效功率800 W、視在功率1000 VA的交流負載，其虛功率是多少？（電壓、電流為正弦波）

  1. A600 var
  2. B200 var
  3. C1800 var
查看答案與解析

正確答案：A. 600 var

視在功率S、有效功率P與虛功率Q之間有 S² = P² + Q² 的關係（功率三角形）。Q = √(1000² − 800²) = √360000 = 600 var，功率因數為 P/S = 0.8。虛功率只在電源與負載之間往返，平均而言不被消耗，但會增加電流，使配線與變壓器的損失增加。

出現「虛功率」的題目（8題）

  1. 在交流電路中，設有效功率為P [W]、視在功率為S [VA]，表示功率因數的式子是哪一個？
  2. 有效功率800 W、視在功率1000 VA的交流負載，其虛功率是多少？（電壓、電流為正弦波）
  3. 某負載的電壓與電流相量（有效值）為 V = 100∠0° V、I = 5∠−30° A。此負載的虛功率大小為下列哪一項？
  4. 如圖，在有效功率8 kW、功率因數0.8（落後）的電感性負載上並聯電容器C，想使從電源看的功率因數成為1。電容器應供給的虛功率大小為下列哪一項？
  5. 如圖，在有效功率8 kW、功率因數0.8（落後）的電感性負載上並聯電容器C，想把從電源看的功率因數改善為0.96（落後）。電容器應供給的虛功率最接近下列哪一項？
  6. 為了改善含有馬達等電感性負載電路的功率因數，一般採用的方法是哪一個？
  7. 在電阻 R = 8 Ω 與電抗 X = 6 Ω 的線圈串聯而成的負載上，加上有效值100 V的正弦波電壓。負載的有效功率為下列哪一項？
