什麼是聯合（union）

C語言中，多個成員從同一位址開始重疊放置的型別。以 union { uint32_t w; uint8_t b[4]; } u; 的方式宣告，大小為最大成員的大小（進位到對齊值的倍數）。同一時間只有一個成員持有有意義的值，用於把同一塊記憶體當作不同型別來看，或在資料只取其中一種形式時節省記憶體。寫入 u.w 再讀取 u.b[0] 的結果會因端序而異。
