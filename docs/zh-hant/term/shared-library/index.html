什麼是共享函式庫（Shared library）

在動態連結時於執行期載入的函式庫。在 Linux 為 .so，在 Windows 為 .dll。以位置無關程式碼建置，程式碼的分頁可由多個行程共用。

日文名稱: 共有ライブラリ

這個名詞所屬的領域: 連結器與載入器與執行檔格式

出現這個名詞的比較

  • 靜態連結與動態連結的差異：比較函式庫的結合方式以連結時機、執行檔大小、記憶體使用量、更新、啟動、散布、效能與用途等面向，用表格比較靜態連結與動態連結。
