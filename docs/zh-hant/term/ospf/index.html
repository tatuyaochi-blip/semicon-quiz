什麼是OSPF（開放最短路徑優先）

Open Shortest Path First的縮寫。在組織內部使用的鏈路狀態型路由協定。各路由器散播自己之鏈路的狀態以共享網路架構，並以戴克斯特拉演算法計算成本合計最小的路徑。成本一般由鏈路頻寬決定，並可把網路分成多個區域，以支援大規模的網路。

日文名稱: OSPF

「OSPF（開放最短路徑優先）」出現在2領域的6道練習題中（網路設計與維運, 電腦網路基礎等）。

這個名詞所屬的領域: 網路設計與維運

鏈路狀態的機制

OSPF路由器以Hello封包與相鄰路由器建立鄰接關係，並把表示自己鏈路狀態的資訊（LSA）散播給同一區域的所有路由器。各路由器根據收集到的LSA建立相同架構的地圖（鏈路狀態資料庫），以自己為起點用戴克斯特拉演算法計算最短路徑樹，並放入路由表。鏈路斷線時，該變化會立即被散播，各路由器重新計算，因此比距離向量型的RIP更快穩定到新的路由。

成本與參考頻寬

各介面的成本一般以「參考頻寬 ÷ 介面頻寬」決定，路由的成本是經過之介面成本的合計。若參考頻寬維持許多設備一直以來的預設值100 Mbps，100 Mbps以上的鏈路成本全部為1，無法區分1 Gbps與10 Gbps。因此，使用高速鏈路的網路會把參考頻寬設為較大的值，並在所有路由器上一致設定。成本也可以在各介面上手動設定。

以區域分層

路由器數量增加時，LSA的量與戴克斯特拉演算法的計算負擔都會變大。OSPF把網路分成多個區域，詳細的鏈路狀態只在區域內共享，區域之間只傳遞路由資訊。所有區域都必須連接到作為中心的骨幹區域（區域0），位於區域邊界的路由器（ABR）也可以把路由彙總後再傳遞（路由彙總）。

練習OSPF（開放最短路徑優先）的題目

某台路由器從OSPF與RIP兩者學到通往同一目的地 192.168.50.0/24 的路由。在這台路由器上，表示各路由來源優先程度的管理距離（值越小越優先），OSPF為110，RIP為120。放入路由表的路由，下列何者正確？

  1. A兩條路由都放入路由表，每個封包輪流使用
  2. B只放入RIP的路由
  3. C只放入OSPF的路由
查看答案與解析

正確答案：C. 只放入OSPF的路由

像OSPF的成本與RIP的跳數那樣，不同的路由協定表示路由好壞之值（度量值）的意義不同，無法直接比較。因此，從多個來源得到相同目的地、相同前綴長度的路由時，會採用代表各來源可信程度之管理距離較小的一方。這裡OSPF的110比RIP的120小，因此OSPF的路由會放入路由表。一般而言，直接相連的網路為0、靜態路由為1，人設定的路由值越小，但名稱與預設值依設備廠商而異。

路由器的路由表中有3條路由：靜態路由 10.0.0.0/8（下一個轉送對象為路由器A，管理距離1）、以OSPF學到的 10.1.0.0/16（路由器B，110）、以RIP學到的 10.1.1.0/24（路由器C，120）。目的地為 10.1.1.5 的封包會送往哪一台路由器？

  1. A路由器A（靜態路由）
  2. B路由器B（OSPF的路由）
  3. C路由器C（RIP的路由）
查看答案與解析

正確答案：C. 路由器C（RIP的路由）

3條路由的前綴長度不同，因此各自作為不同的路由放入路由表。轉送封包時，會選擇與目的地相符之路由中前綴最長的一條，不比較管理距離。10.1.1.5 與3條路由都相符，但會選擇最長的 /24 的RIP路由，送往路由器C。管理距離只用在從相同目的地、相同前綴長度的路由中，決定要把哪一條放入路由表時。

常見問題

OSPF與RIP有什麼不同？

RIP是距離向量型，只以經過的路由器數量（跳數，最多15）選擇路由，不考慮鏈路速度。OSPF是鏈路狀態型，以由頻寬決定的成本合計選擇路由，跟上變化的速度也較快，並可分成區域以支援大型網路。

OSPF與BGP如何分工？

OSPF是在一個組織（AS）內部迅速找出最短路徑的協定（IGP）。BGP是在組織之間依據路由屬性與政策交換路由的協定。大型組織常見的組合是內部使用OSPF，與網路服務供應商之間使用BGP。
