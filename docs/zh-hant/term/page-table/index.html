什麼是頁表

記錄虛擬位址的頁號到實體位址頁號之對應關係的表。由作業系統為每個行程建立，CPU的MMU參照它來轉換位址。每個項目也包含保護用的位元。

日文名稱: ページテーブル

「頁表」出現在3領域的3道練習題中（CPU與架構, 連結器與載入器與執行檔格式, 硬體安全等）。

這個名詞所屬的領域: 作業系統與硬體

練習頁表的題目

保存虛擬位址轉換為實體位址的結果，以加快位址轉換的快取是下列何者？

  1. AL3 快取
  2. BTLB（轉譯後備緩衝區）
  3. C暫存器檔案
查看答案與解析

正確答案：B. TLB（轉譯後備緩衝區）

在虛擬記憶體中，必須將程式所使用的虛擬位址轉換為實體位址，而轉換表（分頁表）位於記憶體上，若每次都去查詢，就得多次存取記憶體。因此將最近使用過的轉換結果保存在 TLB 中。TLB 很小，只有數十〜數千個項目，處理的記憶體範圍一大，未命中就會增加，所以有時會使用 2 MB 等大型分頁（巨型分頁，huge page）來擴大 TLB 的涵蓋範圍。

藉由不讓記憶體分頁同時具備「可寫入」與「可執行」（W^X，寫入與執行分離），較容易防禦的攻擊為下列何者？

  1. A以暴力法逐一嘗試密碼的攻擊
  2. B傳送大量通訊使伺服器停擺的攻擊
  3. C將攻擊用的機器碼寫入堆疊等資料區域，並跳到那裡執行的攻擊
查看答案與解析

正確答案：C. 將攻擊用的機器碼寫入堆疊等資料區域，並跳到那裡執行的攻擊

以往的攻擊常利用緩衝區溢位將機器碼寫入堆疊，並讓返回位址指向那裡來執行。CPU的分頁表中有禁止執行的位元（NX位元等），只要作業系統將堆疊、堆積、.data設為禁止執行，並將.text設為禁止寫入，這種方法就行不通了。像JIT編譯器那樣在執行中產生程式碼的情況，則是切換寫入與執行的權限來使用。
