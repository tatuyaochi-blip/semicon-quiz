什麼是缺陷檢測設備

找出晶圓上的異物或圖案缺陷的設備。有偵測照光時散射光的方式，以及比對相鄰晶粒影像的方式等。

日文名稱: 欠陥検査装置

「缺陷檢測設備」出現在1領域的3道練習題中（量測與分析等）。

這個名詞所屬的領域: 量測與分析

練習缺陷檢測設備的題目

偵測晶圓上異物或圖案缺陷的缺陷檢測設備，所使用的代表性原理是下列何者？

  1. A偵測照光時的散射光，或比對相鄰晶粒（die）的影像
  2. B晶圓重量的變化
  3. C敲擊晶圓時的聲音
查看答案與解析

正確答案：A. 偵測照光時的散射光，或比對相鄰晶粒（die）的影像

有異物時照射的光會散射，因此偵測散射光即可發現異物。圖案缺陷則是與具有相同圖案的相鄰晶粒影像比較，將有差異之處視為缺陷。比較兩個晶粒無法判定哪一個有問題，所以會比較三個晶粒，以多數決來判定。偵測到的缺陷以檢視用SEM（review SEM）詳細觀察並分類。重量或聲音無法得知缺陷。

在晶圓缺陷檢測設備中，與直接觀察圖案影像的明視野方式相比，僅捕捉散射光的暗視野方式，其特徵下列何者正確？

  1. A能以高靈敏度偵測來自異物等的散射光，容易高速檢測廣大範圍
  2. B解析度必定比明視野高
  3. C無法偵測異物
查看答案與解析

正確答案：A. 能以高靈敏度偵測來自異物等的散射光，容易高速檢測廣大範圍

暗視野方式不接收正反射的光，只捕捉被異物或缺陷散射的光，因此背景暗、小異物明亮地浮現，可高速檢測廣大範圍。明視野方式以反射光直接擷取圖案的影像，擅長偵測圖案形狀的缺陷，但檢測較慢。因此異物的監控使用暗視野，新製程的詳細評估則使用明視野，加以區分運用。

解析中的「缺陷檢測設備」

  • 缺陷檢測設備從一片晶圓有時會偵測到數千個缺陷，要調查各自的原因就必須進行種類分類。
