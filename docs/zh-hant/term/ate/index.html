什麼是ATE(自動測試設備)

對晶片施加測試向量並量測輸出，自動判定良否的設備。也稱為測試機。

日文名稱: ATE(自動試験装置)

「ATE(自動測試設備)」出現在1領域的1道練習題中（測試與檢查等）。

這個名詞所屬的領域: 測試與檢查

測試機的工作內容

自動測試設備（ATE）對待測元件（DUT）施加電源與訊號，量測其響應，與期望值比較，再將產品分類為合格、不合格或不同效能等級（bin）。測試程式負責安排各步驟的順序。測試機有數百到數千個通道；每個接腳的電子電路可依程式設定的時序驅動邏輯位準、在選通（strobe）時刻將輸出與期望值比較，並透過每腳獨立的參數量測單元施加電壓或電流並量測另一者。元件電源供應器負責提供並監控電源軌。

晶圓針測與最終測試

ATE 主要用於兩個階段。在晶圓測試（又稱晶圓針測，wafer sort）中，探針台將晶圓逐步移到探針卡下方，探針接觸每顆晶片寬數十微米的焊墊；針痕會經過檢查，確保不影響後續的打線或凸塊製程。不合格的晶粒會被標記，不進行封裝。在最終測試中，分類機（handler）將封裝好的產品放入負載板上的測試座，通常在高溫或低溫下測試，並依結果分類。

測試哪些項目

典型流程從檢查開路與短路的連續性測試開始，接著是漏電流與電源電流等直流參數測試，然後是功能測試與結構測試。對數位邏輯而言，由自動測試圖樣產生（ATPG）產生的掃描圖樣可偵測製造故障，通常以實際速度（at-speed）進行。記憶體則以演算法圖樣或內建自我測試（BIST）進行測試。類比、混合訊號與 RF 產品需要量測線性度、雜訊與頻率響應的儀器，因此測試機平台會針對邏輯與 SoC、記憶體、混合訊號或 RF 元件而專門化。

測試成本

測試機很昂貴，因此測試成本大致等於測試時間乘以測試機每秒成本。製造商透過同時測試多顆元件（多站點測試）、刪減重複的測試，以及加入可測試性設計（DFT）功能來降低成本。掃描鏈、壓縮與 BIST 讓適量的測試機接腳與有限的圖樣記憶體就能涵蓋大型晶片，而減少接腳數測試則讓較便宜的測試機能同時處理更多站點。

練習ATE(自動測試設備)的題目

關於ATE（自動測試設備）的說明，下列何者正確？

  1. A輸入測試圖樣，並將輸出與期望值比較以判定良否的裝置
  2. B在晶圓上曝光電路圖樣的裝置
  3. C清洗晶圓的裝置
查看答案與解析

正確答案：A. 輸入測試圖樣，並將輸出與期望值比較以判定良否的裝置

ATE（Automatic Test Equipment）是對受測晶片提供電源與訊號，量測輸出並與期望值比較，以判定良否的裝置。它具備數百至數千個通道的電路，每個腳位都能產生訊號、量測電壓與電流、判定時序。在晶圓測試時與探針台搭配，在最終測試時與分選機搭配使用。曝光或清洗是前段製程設備的工作。

常見問題

半導體中的 ATE 是什麼？

ATE 是 automatic test equipment（自動測試設備）的縮寫，是對晶片施加測試圖樣、量測其輸出，並自動判定合格與否的測試機。

探針台和分類機有什麼差別？

兩者都負責將元件送到 ATE。探針台將晶圓定位在探針卡下方進行晶圓級測試；分類機則拾取封裝好的晶片，放入測試座，並在最終測試後進行分類。

為什麼可測試性設計能降低 ATE 成本？

掃描鏈、測試壓縮與內建自我測試等結構，讓晶片能自我測試或只透過少數接腳進行測試，縮短測試時間，並能以較便宜的設備同時測試更多元件。
