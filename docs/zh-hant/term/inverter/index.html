什麼是逆變器

將直流電力轉換為任意頻率與大小之交流電力的裝置。把電力用開關（IGBT或MOSFET）接成橋式，以PWM切換導通與關斷來產生交流電壓。用於馬達的轉速控制、電動車的驅動、太陽能發電的功率調節器、不斷電系統（UPS）等。它與在邏輯電路中反轉0與1的反相器（NOT閘）是不同的東西。

日文名稱: インバータ

「逆變器」出現在4領域的24道練習題中（功率半導體, 電力電子電路, 車用半導體與功能安全等）。

這個名詞所屬的領域: 電力電子電路

電路的構成

單相的半橋使用2個開關，全橋使用4個，三相逆變器使用6個開關，每個開關都並聯一個讓反向電流流過的二極體。上下開關同時導通會使直流電源短路，因此在切換時設置兩者都關斷的死區時間。高側開關的閘極以自舉電路或隔離型閘極驅動器來驅動。

輸出的控制

正弦波PWM比較想輸出的正弦波與三角波載波來切換開關，以調變指數決定輸出電壓的大小，以訊號波的頻率決定輸出頻率。三相正弦波PWM在調變指數為1時，線電壓基本波的有效值約為直流電壓的0.61倍（600 V時約367 V）。驅動感應電動機時，會使用使電壓與頻率之比保持一定的V/f控制，或把電流分成磁通與轉矩成分來控制的向量控制。

電壓型與電流型

以平滑電容使直流電壓保持一定、以開關產生電壓脈衝的稱為電壓型逆變器，以大型電感使直流電流保持一定的稱為電流型逆變器。現在的馬達驅動與電源幾乎都是電壓型。由於直流側有電容，當馬達作為發電機運作時，回送的能量會使直流電壓上升，這一點需要注意。

練習逆變器的題目

功率電子中逆變器的主要作用為下列何者？

  1. A將直流轉換為交流
  2. B將交流轉換為直流
  3. C將光轉換為電
查看答案與解析

正確答案：A. 將直流轉換為交流

逆變器是以數kHz～數十kHz使功率半導體導通、截止，並改變脈衝寬度（PWM），從直流產生任意頻率、電壓之交流的裝置。它被用於冷氣與洗衣機的馬達轉速控制、EV的驅動、太陽能發電的功率調節器、鐵路等，讓馬達只依需求運轉，可大幅節能。將交流轉換為直流的是轉換器（整流器）。

SiC蕭特基能障二極體被用作逆變器等的續流二極體，其主要優點為下列何者？

  1. A因為比矽二極體便宜許多
  2. B因為會發光而能得知運作狀態
  3. C因為幾乎沒有逆向恢復電流，可減少切換損耗
查看答案與解析

正確答案：C. 因為幾乎沒有逆向恢復電流，可減少切換損耗

蕭特基能障二極體僅以多數載子運作，因此不會像PN接面二極體那樣因少數載子累積而產生逆向恢復電流。Si的蕭特基接面不易獲得高耐壓，而SiC則可製作600～1700 V等級。將其用作逆變器或PFC電路的續流二極體時，除了二極體本身的損耗外，對側開關的開啟損耗（turn-on 損耗）也能大幅減少。

常見問題

家電的「變頻控制」在做什麼？

先把商用交流整流成直流，再以逆變器轉回頻率與電壓經過改變的交流，讓冷氣壓縮機或洗衣機的馬達以需要的轉速運轉。與反覆運轉、停止的方式相比，能使溫度等保持穩定，同時減少耗電。

與邏輯電路的反相器有什麼不同？

邏輯電路的反相器就是NOT閘，是反轉輸入0與1、處理小訊號的電路。電力轉換的逆變器則是把直流轉為交流以傳送電力的裝置。兩者在英文中都稱為 inverter，日文也都寫作「インバータ」，需要依上下文區分。
