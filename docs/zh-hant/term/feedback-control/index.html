什麼是回授控制

以感測器量測受控量並與目標值比較，改變操作量使兩者之差（誤差）變小的控制。訊號沿迴路繞行一圈，因此也稱為閉迴路控制。無論原因為何都修正結果的偏差，因此對擾動與受控體的變化很強，但在誤差出現後才修正，因此有延遲，增益太高則會造成振盪或不穩定。PID控制是代表，廣泛用於溫度、速度、電壓、位置等的控制。

練習回授控制的題目

關於回授控制（閉迴路控制）的說明，正確的是下列何者？

  1. A不量測受控量，只依預先決定的操作量或程序運作，因此即使受控量因擾動而偏離，也不會自動修正
  2. B量測受控量並與目標值比較，改變操作量使兩者的差（誤差）變小，因此能減少擾動與受控體特性變化的影響
  3. C量測擾動，在它出現在受控量之前加上抵銷它的操作量，因此連未量測的擾動與模型誤差在內，都一定能使誤差為0

正確答案：B. 量測受控量並與目標值比較，改變操作量使兩者的差（誤差）變小，因此能減少擾動與受控體特性變化的影響

回授控制是將感測器量測到的受控量與目標值比較，依誤差決定操作量的控制。訊號由輸出回到輸入側，沿迴路繞行一圈，因此也稱為閉迴路控制。無論原因為何，都看著結果的偏差加以修正，因此對擾動與受控體特性的變化很強，這是它的優點。另一方面，它在誤差出現後才修正，因此有延遲，增益調得太高則會振盪或變得不穩定。

將前饋控制與回授控制組合使用的理由，正確的是下列何者？

  1. A前饋能在誤差出現之前，對可量測的擾動與目標值的變化作出反應，但無法修正未量測的擾動與模型誤差，因此剩下的部分由回授補足
  2. B加上前饋後，迴路轉移函數的增益與相位會改變，使相位邊限增加，因此即使加大回授的增益也能保持穩定
  3. C只用回授時，即使使用積分動作也一定會殘留穩態誤差，因此要使對固定目標值或擾動的穩態誤差為0，前饋是不可或缺的
查看答案與解析

正確答案：A. 前饋能在誤差出現之前，對可量測的擾動與目標值的變化作出反應，但無法修正未量測的擾動與模型誤差，因此剩下的部分由回授補足

前饋控制是量測擾動或目標值的變化，在它們影響受控量之前，加上依模型計算出的操作量的控制。它不等待誤差出現，因此反應快，但前提是模型準確且擾動可以量測。因此常見的組合是由前饋負責主要的擾動與目標值的追隨，再由回授修正剩下的偏差。前饋的路徑位於迴路之外，因此不會改變迴路的穩定性（相位邊限等）。
