什麼是PLL(鎖相迴路)

偵測與參考時脈的相位差並控制振盪器，產生與參考同步、頻率為整數倍等的時脈的電路。用於 CPU 的時脈產生與無線的頻率合成。

日文名稱: PLL(位相同期回路)

「PLL(鎖相迴路)」出現在7領域的8道練習題中（類比與電子電路, PN接面與二極體, 邏輯電路等）。

這個名詞所屬的領域: 類比與電子電路

練習PLL(鎖相迴路)的題目

變容二極體（varactor diode）利用的是下列哪種性質？

  1. A以順向電流發光的性質
  2. B電阻隨溫度改變的性質
  3. C接面電容隨逆向偏壓電壓而改變的性質
查看答案與解析

正確答案：C. 接面電容隨逆向偏壓電壓而改變的性質

逆向偏壓增強時空乏區變寬，接面電容變小。利用這個特性，使電容可由電壓控制的就是變容二極體（varactor）。採用雜質分布陡峭的超陡峭接面時，電容隨電壓的變化很大，可變範圍也變廣。由於諧振頻率 f = 1/(2π√(LC)) 可藉由電壓調整，因此被用於調諧器、壓控振盪器（VCO）與PLL。

每次輸入時脈輸出就反相的T型正反器1個，其輸出頻率是時脈頻率的幾倍？

  1. A2倍
  2. B1/2倍
  3. C1/4倍
查看答案與解析

正確答案：B. 1/2倍

T型正反器（T = 1）在每個時脈邊緣輸出就反相，因此2個時脈為1個週期，頻率為時脈的1/2。輸出的工作週期可精確為50%也是優點。串聯起來則成為1/4、1/8…的除頻器或漣波計數器。PLL的回授電路中也使用除頻器，例如從100 MHz的參考頻率改變除頻比，即可合成數GHz的頻率。

  • 代價是頻率幾乎無法改變，因此若要可變，需與PLL組合。
