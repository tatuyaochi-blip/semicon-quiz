什麼是AXI

Arm AMBA 規格之一，是連接 SoC 內部各區塊的匯流排。具有 5 個獨立通道與 VALID、READY 交握，另有 AXI4-Lite 與 AXI4-Stream 等種類。

日文名稱: AXI

「AXI」出現在1領域的6道練習題中（介面與匯流排規格等）。

這個名詞所屬的領域: 介面與匯流排規格

通道與交握

Advanced eXtensible Interface（AXI）將每個連接分成五個單向通道：讀取位址、讀取資料、寫入位址、寫入資料與寫入回應。每個通道都以相同的 VALID/READY 交握傳遞資訊，在兩個訊號皆為高的時脈邊緣完成一次傳輸。發送端不得等待 READY 之後才拉高 VALID，以避免死結；接收端則可以將 READY 保持為低以施加反壓。由於每個通道都是簡單的交握，因此可以在任何通道上插入管線暫存器切片，以利時序收斂而不改變行為。

突發傳輸與交易

一次位址交握可以啟動包含許多資料拍（beat）的突發傳輸。位址通道攜帶起始位址、突發長度、每拍大小與突發類型：類 FIFO 位址用 fixed，一般記憶體區塊用 incrementing，從關鍵字組開始的快取行填充則用 wrapping。在 AXI4 中，incrementing 突發最多可達 256 拍，而且突發不得跨越 4 KB 位址邊界，因此互連永遠不必把一個突發拆分到兩個目標。每個讀取拍與每個寫入突發都會回傳表示成功或錯誤的回應碼。

ID、未完成請求與互連

每筆交易都帶有一個 ID。主控端（manager）可以在先前的請求完成前發出許多請求，在記憶體延遲很長時仍讓匯流排保持忙碌。相同 ID 的交易必須依序完成，不同 ID 的交易則可以亂序完成，因此快速的周邊不必排在緩慢的 DRAM 後面等待。在 SoC 中，互連或交叉開關會解碼位址、在 CPU 與 DMA 引擎等主控端之間仲裁，並將請求路由到記憶體控制器等從屬端（subordinate），通常還會加入寬度、時脈域與協定轉換器。

AXI4-Lite、AXI4-Stream 與 APB

AXI4-Lite 保留五個通道，但省略了突發與大部分交易選項，每筆交易傳送一個資料字組，適合控制與狀態暫存器。AXI4-Stream 則完全沒有位址：單一的 TVALID/TREADY 通道承載連續資料，以 TLAST 標示封包結尾，適合影像、訊號處理與網路的資料路徑。Advanced Peripheral Bus（APB）是 Arm AMBA 規格的另一個成員，更加簡單且無管線，通常經由橋接器用於低速周邊。AXI 的一致性擴充則加入了用於快取一致性的窺探（snooping）功能。

練習AXI的題目

下列關於AXI匯流排之特徵，何者正確？

  1. A讀取位址、讀取資料、寫入位址、寫入資料、寫入回應這5個通道彼此獨立，可同時運作
  2. B以一條線交替傳送位址與資料
  3. C讀取與寫入絕對無法同時進行
查看答案與解析

正確答案：A. 讀取位址、讀取資料、寫入位址、寫入資料、寫入回應這5個通道彼此獨立，可同時運作

AXI具有讀取位址（AR）與資料（R）、寫入位址（AW）、資料（W）與回應（B）共5個通道。由於通道獨立，因此可同時進行讀取與寫入，也可先傳送位址、之後再傳送資料。各個通道都以相同的VALID與READY程序進行交握，因此結構一致。

在AXI各通道使用VALID與READY進行的交握（handshake）中，資料在何時完成傳遞？

  1. A傳送方的VALID與接收方的READY兩者都為1的時脈邊緣
  2. B傳送方將VALID設為1的瞬間，不論READY為何
  3. C接收方將READY設為1的瞬間，不論VALID為何
查看答案與解析

正確答案：A. 傳送方的VALID與接收方的READY兩者都為1的時脈邊緣

傳送方在有有效資料時將VALID設為1，接收方在能夠接收時將READY設為1。在時脈邊緣兩者皆為1時，傳遞即成立。接收方忙碌時可將READY設為0讓傳送方等待（背壓，backpressure），因此即使是速度不同的區塊之間，也能在不遺失資料的情況下相連。規定傳送方不等待READY就輸出VALID，以防止因互相等待而停滯。

常見問題

AXI4、AXI4-Lite 和 AXI4-Stream 有什麼差別？

完整的 AXI4 支援突發、ID 與多筆未完成交易，用於高吞吐量的記憶體流量。AXI4-Lite 每筆交易處理一個字組，用於暫存器存取；AXI4-Stream 則完全省略位址，用於承載連續資料流。

AXI 中 VALID 可以依賴 READY 嗎？

不可以。發送端有資料時就必須拉高 VALID，不能等待 READY，否則雙方可能永遠互相等待。接收端則可以等到 VALID 之後再拉高 READY。

AXI 和 APB 有什麼差別？

AXI 是高效能、管線化的介面，具有獨立的讀取與寫入通道以及突發傳輸。APB 則是用於周邊暫存器的簡單低速匯流排，通常經由橋接器連接到 AXI。
