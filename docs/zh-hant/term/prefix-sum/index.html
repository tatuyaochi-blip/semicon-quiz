什麼是前綴和（Prefix sum）

求出從陣列開頭起的累積和的計算。亦稱掃描（scan）。可平行計算，用於決定緊密寫出處理的寫入目的地。

日文名稱: プレフィックスサム

這個名詞所屬的領域: GPU程式設計
