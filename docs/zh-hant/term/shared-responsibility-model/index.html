什麼是共同責任模型

使用雲端時，由雲端業者與使用者分擔安全與營運責任的想法。資料中心的建築物與實體設備由業者負責，所儲存的資料、帳號與存取權限的設定、來自網路的連線許可等由使用者負責。兩者之間的範圍依 IaaS、PaaS、SaaS、託管服務等服務形態而改變。因設定錯誤造成的資訊外洩，多半發生在使用者責任的範圍內。

這個名詞所屬的領域: 雲端與容器基礎

練習共同責任模型的題目

使用雲端的託管資料庫服務（由業者營運資料庫軟體的服務）。依共同責任模型的想法，一般仍屬於使用者責任的是下列何者？

  1. A對執行資料庫的伺服器作業系統與資料庫軟體套用安全性修正
  2. B保護資料中心的建築物與伺服器等實體設備，免於故障與入侵
  3. C管理資料庫使用者的帳號與權限、允許連線的網路範圍，以及所儲存的資料
查看答案與解析

正確答案：C. 管理資料庫使用者的帳號與權限、允許連線的網路範圍，以及所儲存的資料

在共同責任模型中，雲端業者與使用者分擔安全與營運的責任，其分界依服務形態而改變。在託管資料庫服務中，除了實體設施之外，作業系統與資料庫軟體的更新也由業者負責。另一方面，允許誰存取哪些資料、允許從哪些網路連線、儲存什麼資料，在任何形態下都仍是使用者的責任。因設定錯誤而把資料庫公開到網際網路的事故，是使用者這一側的問題。
