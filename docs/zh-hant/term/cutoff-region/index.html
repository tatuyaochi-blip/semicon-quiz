什麼是截止區

雙載子電晶體的兩個接面都處於逆向偏壓，集極電流幾乎不流動的狀態。相當於開關關閉。

日文名稱: 遮断領域

「截止區」出現在1領域的4道練習題中（雙載子電晶體等）。

這個名詞所屬的領域: 雙載子電晶體

練習截止區的題目

雙極性電晶體處於截止區（關閉）時，接面的狀態下列何者正確？

  1. A基極-射極接面為順向偏壓，基極-集極接面為逆向偏壓
  2. B兩個接面皆為順向偏壓
  3. C基極-射極接面與基極-集極接面皆為逆向偏壓
查看答案與解析

正確答案：C. 基極-射極接面與基極-集極接面皆為逆向偏壓

在截止區，基極-射極接面與基極-集極接面皆為逆向偏壓（或VBE低於約0.5 V而幾乎沒有電流流過的狀態），集極只流過漏電流（nA左右）。這是開關的關閉狀態。若基極保持開路，漏電流會被放大而有時無法完全關閉，因此一般的做法是在基極與射極之間加入電阻以確實關閉。

解析中的「截止區」

  • 在截止區，基極-射極接面與基極-集極接面皆為逆向偏壓（或VBE低於約0.5 V而幾乎沒有電流流過的狀態），集極只流過漏電流（nA左右）。

    雙極性電晶體處於截止區（關閉）時，接面的狀態下列何者正確？

  • 若兩者皆為順向偏壓，則為飽和區（開關導通）；若兩者皆為逆向偏壓，則為截止區（關閉）。

    NPN電晶體用於放大（在主動區工作）時，正確的偏壓條件是哪一個？

  • 當作開關使用時，關閉為兩個接面皆為逆向偏壓的截止區，導通為兩者皆為順向偏壓的飽和區。

    將雙極性電晶體當作開關使用時，對應於導通狀態的工作區是哪一個？

  • 原點附近IC急遽上升的部分是飽和區，IB = 0 的線以下是截止區。

    以基極電流IB為參數繪出共射極電晶體的輸出特性（IC-VCE特性）時，主動區的特徵下列何者正確？

出現「截止區」的題目（4題）

  1. 雙極性電晶體處於截止區（關閉）時，接面的狀態下列何者正確？
  2. NPN電晶體用於放大（在主動區工作）時，正確的偏壓條件是哪一個？
  3. 將雙極性電晶體當作開關使用時，對應於導通狀態的工作區是哪一個？
