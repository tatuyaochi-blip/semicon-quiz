什麼是動態連結（Dynamic linking）

在執行時載入共享函式庫並加以結合的方式。函式庫可在行程間共用，抽換即可反映修正，但執行環境需要相符的函式庫。

日文名稱: 動的リンク

「動態連結（Dynamic linking）」出現在1領域的12道練習題中（連結器與載入器與執行檔格式等）。

這個名詞所屬的領域: 連結器與載入器與執行檔格式

程式啟動時發生了什麼

動態連結的執行檔並不包含函式庫程式碼。它記錄了需要哪些共享函式庫、使用其中哪些符號，在 Linux 上還會指定一個程式直譯器，也就是動態連結器。程式啟動時，核心將執行檔與動態連結器對應到記憶體，動態連結器再沿著搜尋路徑找到每個函式庫、將其對應到記憶體、解析符號參照、套用剩餘的重定位，並執行函式庫的初始化程序，然後才跳到程式的進入點。Windows 則利用每個執行檔的匯入表，為 DLL 完成相同的工作。

位置無關程式碼、GOT 與 PLT

為了讓函式庫程式碼的一份實體副本能服務多個行程，即使函式庫在每個行程中可能載入到不同位址，程式碼頁也絕不能被修改。因此共享函式庫會編譯成位置無關程式碼（PIC），而會變動的位址則放進一張資料表，也就是全域偏移表（GOT）。對外部函式的呼叫會經過小型的程序連結表（PLT）樁程式（stub），再透過 GOT 跳轉。採用延遲繫結（lazy binding）時，GOT 項目在第一次呼叫時才填入；在啟動時就解析所有符號，然後將 GOT 設為唯讀，則是常見的強化做法。

動態連結與靜態連結

靜態連結在建置時將所需的目的碼複製到執行檔中。結果是自給自足的，並且免除了執行期的符號查找，但檔案較大，而且必須重新建置才能套用函式庫的修正。動態連結讓各行程共享函式庫頁、節省磁碟空間，並只需替換一個檔案就能讓安全性修正生效於所有程式。代價是啟動時的工作量以及對目標系統的依賴：缺少或不相容的函式庫會使程式無法啟動，這就是函式庫帶有版本名稱與版本化符號的原因。

按需載入函式庫

除了在啟動時就確定的函式庫之外，執行中的程式也可以明確地載入函式庫，在 POSIX 系統上使用 dlopen，在 Windows 上使用 LoadLibrary，然後以 dlsym 或 GetProcAddress 依名稱查找函式。外掛架構與選用功能就是以這種方式運作的。由於符號繫結發生在執行期，預先載入的函式庫也可以插入自己版本的函式，分析器與記憶體除錯工具便利用了這個機制。ldd 等工具可以列出執行檔將載入哪些共享函式庫，以及它們位於何處。

練習動態連結（Dynamic linking）的題目

關於動態連結（共用函式庫）的優點，下列何者正確？

  1. A即使執行環境中沒有函式庫，也一定能運作
  2. B多個程式可在記憶體上共用一個函式庫，更新函式庫後不必重新建置即可反映修正
  3. C啟動時的處理完全不需要，一定比靜態連結啟動得更快
查看答案與解析

正確答案：B. 多個程式可在記憶體上共用一個函式庫，更新函式庫後不必重新建置即可反映修正

在動態連結中，執行檔只記錄「要使用哪個共用函式庫的哪個函式」，執行時由動態連結器載入函式庫並加以結合。共用函式庫的程式碼不會被改寫，因此實體記憶體上的同一份副本可由許多行程共用。錯誤與漏洞的修正，也只要替換函式庫即可。不過啟動時需要花費結合的功夫。

將使用動態連結的程式複製到另一部電腦上執行，卻無法啟動。最可能的原因為下列何者？

  1. A因為函式庫的程式碼全都包含在執行檔中，檔案太大了
  2. B因為動態連結的程式規定只能在建置它的電腦上運作
  3. C沒有安裝所需的共用函式庫，或只有不相容的版本
查看答案與解析

正確答案：C. 沒有安裝所需的共用函式庫，或只有不相容的版本

動態連結的程式會使用執行它的電腦上的共用函式庫。如果沒有所需的函式庫，或只有缺少函式的舊版本，動態連結器就無法結合，導致啟動失敗。在Linux中可用ldd指令確認程式所需的共用函式庫，以及是否能找到它們。為了便於散布，有時也會刻意採用靜態連結。

常見問題

靜態連結和動態連結有什麼差別？

靜態連結在建置時將函式庫程式碼複製到執行檔中，因此不需外部函式庫即可執行。動態連結則保留參照，由動態連結器在執行期解析，讓各行程共用一份函式庫副本，並可透過替換函式庫來取得修正。

PLT 和 GOT 是什麼？

全域偏移表（GOT）是一張可寫入的資料表，存放外部函式與變數在執行期的位址。程序連結表（PLT）包含程式碼所呼叫的小型樁程式，它們會透過 GOT 跳轉到實際的函式庫函式。

error while loading shared libraries: cannot open shared object file 是什麼意思？

動態連結器在其搜尋路徑中找不到程式所依賴的函式庫。解決方法是安裝該函式庫，或將其位置加入搜尋路徑，例如透過系統的連結器設定或 rpath。
