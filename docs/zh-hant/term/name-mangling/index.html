什麼是名稱修飾（Name mangling）

C++ 編譯器將引數型別與命名空間的資訊嵌入函式名稱中，產生符號名稱。亦稱 mangling。使連結器能區分多載的函式。

日文名稱: 名前修飾

「名稱修飾（Name mangling）」出現在1領域的1道練習題中（連結器與載入器與執行檔格式等）。

這個名詞所屬的領域: 連結器與載入器與執行檔格式

練習名稱修飾（Name mangling）的題目

C++編譯器在函式名稱上附加參數型別等資訊以產生符號名稱的「名稱修飾（name mangling）」，其主要目的為下列何者？

  1. A讓函式名稱無法閱讀，以免程式被竊取
  2. B縮短函式名稱，使執行檔變小
  3. C讓連結器能區分名稱相同但參數型別不同的函式（多載，overload）與命名空間
查看答案與解析

正確答案：C. 讓連結器能區分名稱相同但參數型別不同的函式（多載，overload）與命名空間

連結器僅以名稱字串來比對符號。在C++中可以建立如「print(int)」與「print(double)」這樣同名的函式，若維持原樣便無法區分。因此編譯器會像「_Z5printi」這樣，將參數型別等嵌入名稱中。C語言的函式不會被修飾，所以從C++呼叫C函式時，要加上「extern "C"」讓它不做修飾。
