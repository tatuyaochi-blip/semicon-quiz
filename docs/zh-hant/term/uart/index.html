什麼是UART

不使用時脈線，傳送端與接收端以相同鮑率進行通訊的非同步序列通訊電路。以起始位元與停止位元區分字元。

日文名稱: UART

「UART」出現在1領域的2道練習題中（CPU與架構等）。

這個名詞所屬的領域: 嵌入式與韌體

練習UART的題目

將 CPU、記憶體以及計時器、ADC 等周邊功能整合在一個晶片上，用於家電與機器控制的 LSI 是下列何者？

  1. AGPU
  2. B微控制器（MCU）
  3. CHBM
查看答案與解析

正確答案：B. 微控制器（MCU）

微控制器是在 CPU 之外，還將存放程式的快閃記憶體、作業用的 RAM、計時器、ADC、通訊介面（UART、SPI、I²C、CAN 等）整合在一個晶片上的 LSI。它用於家電、汽車（每輛數十〜100 顆以上）、工業設備等的控制，每年出貨數百億顆。其特徵是體積小、價格低、功耗小，且一通電即可立即運作。

在微控制器等中，將周邊裝置的暫存器對應到與記憶體相同的位址空間，並以一般的記憶體讀寫指令來操作的方式是下列何者？

  1. A虛擬記憶體
  2. B記憶體對映 I/O（memory-mapped I/O）
  3. C快取一致性
查看答案與解析

正確答案：B. 記憶體對映 I/O（memory-mapped I/O）

在記憶體對映 I/O 中，為計時器、UART 等周邊裝置的控制暫存器分配特定位址，以一般的載入／儲存指令來操作。與另行準備輸入輸出專用指令的方式（x86 的 IN/OUT 等埠對映 I/O）相比，可以使指令集更為單純，在 ARM 與 RISC-V 的微控制器上是標準做法。需要注意讓周邊暫存器不被快取、不讓編譯器對其最佳化（volatile）等事項。

出現這個名詞的比較

  • I2C、SPI、UART 的差異：佈線、速度、使用時機比較從佈線數量、時脈、速度、連接形態、位址、錯誤偵測與在微控制器上的主要用途等面向，以表格比較 I2C、SPI、UART。
