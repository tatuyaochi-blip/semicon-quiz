什麼是冷開機攻擊（Cold boot attack）

讀取斷電後仍會殘留一段時間的 DRAM 內容，取出金鑰等的攻擊。冷卻後會殘留更久。可用記憶體加密防禦。

日文名稱: コールドブート攻撃

「冷開機攻擊（Cold boot attack）」出現在2領域的2道練習題中（硬體安全, DRAM等）。

這個名詞所屬的領域: 硬體安全

練習冷開機攻擊（Cold boot attack）的題目

下列關於冷開機攻擊（cold boot attack）成立的原因與代表性對策的組合，何者正確？

  1. ADRAM一斷電就會瞬間完全消失。讓電源持續開啟
  2. BDRAM加溫後內容會變得容易讀取。加裝冷卻裝置
  3. CDRAM的內容即使斷電後仍會殘留數秒至數分鐘，冷卻後會殘留得更久。事先將記憶體的內容加密
查看答案與解析

正確答案：C. DRAM的內容即使斷電後仍會殘留數秒至數分鐘，冷卻後會殘留得更久。事先將記憶體的內容加密

DRAM記憶胞的電荷即使沒有了更新也不會立刻消失，內容在數秒至數分鐘內仍相當完整地殘留，低溫下殘留得更久。從剛關機的電腦取出記憶體，以其他機器讀出，有時就能找到磁碟加密的金鑰等。對策有以電路將記憶體內容加密、關機時清除金鑰、只將金鑰放在CPU內部等。

解析中的「冷開機攻擊（Cold boot attack）」

  • 不過，在剛斷電後立即冷卻，資料有時會殘留數秒至數分鐘，利用這一點讀取記憶體內加密金鑰的「冷開機攻擊（cold boot attack）」廣為人知。
