什麼是IP（網際網路協定）

Internet Protocol的縮寫。網路層（TCP/IP模型的網際網路層）的協定，使用IP位址把封包從來源終端送到目的地終端，途中由路由器依目的地轉送。它不保證送達與順序（盡力而為），可靠性由TCP等上層補足。目前使用的有IPv4與IPv6兩個版本。

日文名稱: IP(インターネットプロトコル)

「IP（網際網路協定）」出現在2領域的10道練習題中（電腦網路基礎, 系統架構與可靠度設計等）。

這個名詞所屬的領域: 電腦網路基礎

練習IP（網際網路協定）的題目

在TCP/IP的四層模型中，TCP與UDP屬於哪一層？

  1. A應用層
  2. B網際網路層
  3. C傳輸層
查看答案與解析

正確答案：C. 傳輸層

TCP/IP模型由下而上分為連結層（網路介面層）、網際網路層、傳輸層、應用層4層。TCP與UDP是傳輸層的協定，使用連接埠號碼區分通訊是要送給終端上的哪一個應用程式。網際網路層的IP負責把封包從一台終端送到另一台終端。HTTP與DNS則是應用層的協定。若與OSI參考模型對應，傳輸層相當於第4層，網際網路層相當於第3層。

家用寬頻路由器會執行NAT（網路位址轉譯）的一種，即NAPT（IP偽裝）。NAPT能做到什麼？下列何者正確？

  1. A家中多台終端以連接埠號碼區分，可同時共用一個全球IP位址與網際網路通訊
  2. B家中終端與網際網路之間的通訊會被加密，途中無法被竊聽
  3. C家中每台終端都會自動分配到各自不同的全球IP位址
查看答案與解析

正確答案：A. 家中多台終端以連接埠號碼區分，可同時共用一個全球IP位址與網際網路通訊

NAT（網路位址轉譯）是改寫經過路由器之封包的來源或目的地IP位址的技術。NAPT除了IP位址之外也改寫連接埠號碼，並把「內側位址與連接埠」和「外側連接埠」的對應記錄在轉譯表中。因此，使用私有位址的多台終端可以同時使用路由器所擁有的一個全球位址。回傳的封包則查轉譯表送到正確的終端。它只改寫位址，並不加密。此外，從外部發起的連線在轉譯表中沒有對應，預設無法到達內側的終端，若要在內側公開伺服器，需要設定連接埠轉送等。
