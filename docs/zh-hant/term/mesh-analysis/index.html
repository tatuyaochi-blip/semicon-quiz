什麼是網目分析

在畫於平面上的電路各網目（內部不含其他支路的迴路）設定假想的網目電流，對各網目套用克希荷夫電壓定律建立聯立方程式求解的方法。兩個網目共有的元件上流過兩個網目電流的差。在電壓源或串聯元件較多的電路中方程式較少。

日文名稱: 網目解析

「網目分析」出現在1領域的1道練習題中（電路分析（交流電路、線性電路與暫態現象）等）。

這個名詞所屬的領域: 電路分析（交流電路、線性電路與暫態現象）

練習網目分析的題目

在圖中的電路，E1 = 14 V、E2 = 7 V、R1 = 2 Ω、R2 = 1 Ω、R3 = 4 Ω。依圖中方向取網目電流 I1、I2，以網目分析求解時，流過 R3 的電流大小為下列哪一項？

  1. A1 A
  2. B2 A
  3. C3 A
查看答案與解析

正確答案：B. 2 A

左邊網目由 E1 = (R1 + R3)I1 − R3 I2 得 6I1 − 4I2 = 14；右邊網目的 E2 與 I2 方向相反，由 −E2 = (R2 + R3)I2 − R3 I1 得 −4I1 + 5I2 = −7。解此聯立方程式得 I1 = 3 A、I2 = 1 A。兩個網目電流以相反方向流過 R3，因此電流為 I1 − I2 = 2 A（向下）。由 R3 上方節點的電壓 4 × 2 = 8 V，也可確認 R1 的電流 (14 − 8)/2 = 3 A 與 R2 的電流 (8 − 7)/1 = 1 A。
