什麼是有限脈衝響應濾波器（FIR）

脈衝響應在有限長度內結束的數位濾波器（有限脈衝響應濾波器）。以 y[n] = Σh[k]x[n − k] 計算，把目前與過去 N 個輸入乘上係數後相加，沒有輸出的回授。極點只在 z = 0，因此不論係數為何都穩定；係數左右對稱時成為線性相位，所有頻率成分都延遲 (N − 1)/2 個取樣點。另一方面，要得到陡峭的特性需要很多抽頭，每輸出1個取樣點要進行與抽頭數相同次數的乘積累加運算。

日文名稱: FIRフィルタ

「有限脈衝響應濾波器（FIR）」出現在2領域的9道練習題中（數位訊號處理基礎, AD/DA轉換等）。

這個名詞所屬的領域: 數位訊號處理基礎

結構與運算量

排列每次延遲1個取樣點的延遲元件，把各級的值乘上係數後相加的結構，延遲元件的排列稱為抽頭延遲線。N個抽頭時每個輸出取樣點需要 N 次乘積累加，例如以44.1 kHz運作256個抽頭，每秒約需1130萬次乘積累加。DSP具備以1個週期完成乘積累加的指令或專用的乘積累加器，就是這個原因。

設計方法

最基本的方法是窗函數法：把理想特性的脈衝響應（低通時為 sinc 函數）截取成有限長度，再乘上窗函數以減輕兩端的影響。使與指定頻率特性之誤差的最大值最小化的Parks-McClellan法也很常用。不論哪一種，抽頭數越多越能接近理想特性。

線性相位與延遲

係數對稱的FIR濾波器使所有頻率成分延遲相同的時間，因此不會使脈衝或聲音的波形變形。其延遲為 (N − 1)/2 個取樣點，以48 kHz運作101個抽頭時約為1.04 ms。在延遲會造成問題的用途中，有時會放棄線性相位，改用延遲較小的最小相位FIR濾波器。

練習有限脈衝響應濾波器（FIR）的題目

有一個以取樣頻率8 kHz運作、轉移函數為 H(z) = 1 + z⁻²（y[n] = x[n] + x[n − 2]）的FIR濾波器。使輸出為0的正弦波輸入頻率為下列何者？

  1. A1 kHz
  2. B2 kHz
  3. C4 kHz
查看答案與解析

正確答案：B. 2 kHz

1 + z⁻² = 0 的解，也就是零點，由 z² = −1 得 z = ±j，位於單位圓上的 ω = ±π/2。ω = π/2 對應 f = ω·fs/(2π) = fs/4 = 2 kHz；2 kHz的正弦波與2個取樣點之前的值恰好符號相反，相加為0。零點位於單位圓上時，會形成把該頻率完全去除的陷波（notch）。在4 kHz（奈奎斯特頻率）時 z⁻² = 1，因此增益為2。

有限脈衝響應（FIR）濾波器的特徵為下列何者？

  1. A具有把輸出送回輸入側的回授，因此能以較少的係數得到陡峭的特性
  2. B脈衝響應無限延續，因此容易因係數量化而變得不穩定
  3. C沒有回授，因此一定穩定，係數對稱時可得到線性相位
查看答案與解析

正確答案：C. 沒有回授，因此一定穩定，係數對稱時可得到線性相位

FIR濾波器只是把目前與過去的輸入乘上係數後相加，沒有輸出的回授。脈衝響應在係數個數（抽頭數）結束，極點只在 z = 0，因此不論係數為何值都穩定。係數左右對稱時成為線性相位，所有頻率成分都延遲相同的時間，波形的形狀不會變形。相對地，要得到陡峭的特性，需要比IIR濾波器更多的抽頭。

常見問題

FIR濾波器與IIR濾波器如何選用？

需要線性相位、確實穩定，或希望不易受係數量化影響時，適合FIR濾波器。想以較少的運算量與較小的延遲得到陡峭的特性時，適合IIR濾波器，但相位不是線性的，且須注意係數量化造成的不穩定。

抽頭數如何決定？

過渡頻帶（從通帶到阻帶的寬度）越窄、阻帶的衰減越大，需要的抽頭越多。大致上，抽頭數與「取樣頻率 ÷ 過渡頻帶寬度」成正比，所需的衰減量越大，比例係數也越大。
