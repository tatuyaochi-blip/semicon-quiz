什麼是統一記憶體（Unified memory）

CPU 與 GPU 可使用同一個指標，並依存取而自動移動資料的記憶體。程式會變簡單，但要注意移動的開銷。

日文名稱: ユニファイドメモリ

「統一記憶體（Unified memory）」出現在2領域的2道練習題中（GPU程式設計, 效能評估與效能剖析等）。

這個名詞所屬的領域: GPU程式設計

練習統一記憶體（Unified memory）的題目

關於CUDA的統一記憶體（unified memory），下列說明何者正確？

  1. ACPU與GPU可使用同一個指標存取的記憶體，資料會視需要自動移動
  2. B將CPU與GPU的晶片在物理上合而為一
  3. C將GPU的記憶體全部設為唯讀
查看答案與解析

正確答案：A. CPU與GPU可使用同一個指標存取的記憶體，資料會視需要自動移動

在統一記憶體中，對所配置的區域，CPU與GPU都能以同一個指標存取，發生存取時資料會以分頁為單位移動到需要的一側。這讓程式變得簡單，也更容易處理比GPU記憶體還大的資料。不過每次移動都會發生分頁錯誤（page fault）與傳輸，因此在需要效能時，會採取預先下達移動指示等做法。

解析中的「統一記憶體（Unified memory）」

  • 在統一記憶體中，對所配置的區域，CPU與GPU都能以同一個指標存取，發生存取時資料會以分頁為單位移動到需要的一側。
