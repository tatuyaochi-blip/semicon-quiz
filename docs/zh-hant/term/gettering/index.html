什麼是吸附雜質技術(Gettering)

將晶圓內的金屬雜質聚集並捕捉在遠離製作元件之表面的位置的技術。利用氧析出物等達成。

日文名稱: ゲッタリング

「吸附雜質技術(Gettering)」出現在3領域的4道練習題中（矽晶圓, 磊晶成長, 量測與分析等）。

這個名詞所屬的領域: 矽晶圓

為什麼必須捕捉金屬

鐵、銅、鎳等過渡金屬會在矽的能隙中央附近形成深能階。這些能階會成為復合與產生中心，縮短載子生命期、增加接面漏電與影像感測器的暗電流，並使閘極氧化層劣化；表面濃度約 10¹⁰ atoms/cm² 就可能造成影響。這些金屬中有許多在製程溫度下擴散很快，冷卻時溶解度又會降低，因此往往會在任何找得到的吸附點析出。吸附雜質技術在遠離元件區的地方刻意提供吸附點，讓金屬最終聚集在那裡，而不是電晶體附近。

本質吸附與無缺陷區

柴可拉斯基（CZ）矽會從石英坩堝吸收氧，濃度通常約為 10¹⁷ 至 10¹⁸ cm⁻³，大多位於間隙位置，並以約 1107 cm⁻¹ 的紅外線吸收量測。在約 1100 °C 以上進行高溫退火，會把氧從表面趕出，形成數十微米深、沒有析出物的無缺陷區（DZ）。接著以較低溫度的退火，在內部使氧析出物成核並成長，稱為塊材微缺陷（BMD），密度約為 10⁸ 至 10¹⁰ cm⁻³。它們的應變場與相伴的差排會捕捉金屬，而元件則位於潔淨的表層中。

外質吸附

外質吸附是從晶體外部加入吸附點。晶圓背面的機械損傷，或沉積在背面的多晶矽層，可提供收集金屬的晶界與缺陷。重摻雜區也會吸引某些金屬，這是 p/p+ 磊晶晶圓的好處之一：輕摻雜的磊晶層位於重摻雜的 p+ 基板上。在歷史上，以磷矽玻璃（PSG）吸附鈉離子，對穩定早期 MOS 的臨界電壓至關重要。在 CZ 晶體中摻入約 10¹³ 至 10¹⁵ cm⁻³ 的微量氮，可增強析出，有利於本質吸附。

吸附與清洗

吸附是第二道防線，不能取代污染控制。清洗會把表面金屬維持在約 10⁹ 至 10¹⁰ atoms/cm² 以下，化學品與超純水則控制在 ppt（兆分之一）等級。只有當金屬能在晶圓實際經歷的熱步驟中擴散到吸附點，且析出物密度夠高又不侵入主動層時，吸附才會發揮作用。因此氧含量必須審慎規定：太少則吸附能力弱，太多則會產生近表面缺陷與熱施體。

  1. A將晶圓削薄的加工
  2. B將有害的金屬雜質捕捉到遠離元件形成區域之處的技術
  3. C將多片晶圓貼合的技術
查看答案與解析

正確答案：B. 將有害的金屬雜質捕捉到遠離元件形成區域之處的技術

吸附(gettering)是把會劣化元件特性的鐵、銅、鎳等金屬雜質，聚集並捕捉到遠離表面元件區域的晶圓內部或背面的缺陷等處的技術。金屬會造成漏電流增加與氧化膜劣化，即使只有10¹⁰ atoms/cm²左右的微量汙染也會成為問題。吸附有兩種：利用晶圓內部氧析出物的本質吸附(intrinsic gettering)，以及在背面設置加工應變或多晶膜的非本質吸附(extrinsic gettering)。

常見問題

本質吸附和外質吸附有什麼差別？

本質吸附利用在晶圓塊材內部成長的氧析出物作為吸附點；外質吸附則從外部加入吸附點，例如背面損傷、背面多晶矽膜或重摻雜層。

矽晶圓的無缺陷區（denuded zone）是什麼？

這是一層近表面的區域，深度通常為數十微米，其中的氧已藉由高溫退火向外擴散，因此在製作元件的位置不會形成氧析出物。

吸附雜質技術針對的是哪些金屬？

主要是鐵、銅、鎳等擴散快速的過渡金屬，它們會形成深能階，使漏電增加並縮短載子生命期。
