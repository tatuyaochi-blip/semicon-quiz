什麼是張量核心（Tensor core）

以一個指令一併計算小型矩陣之間乘加的 GPU 運算單元。主要用於低精度數值，可大幅加速 AI 的運算。

日文名稱: テンソルコア

「張量核心（Tensor core）」出現在3領域的4道練習題中（GPU程式設計, CPU與架構, AI硬體與軟體堆疊等）。

這個名詞所屬的領域: GPU程式設計

張量核心進行的計算

張量核心是NVIDIA GPU上專門進行矩陣運算的運算單元，能以一個指令一併計算D = A × B + C形式的小矩陣乘加。它最早搭載於2017年發表的Volta世代，每個張量核心每個時脈進行一次4×4矩陣之間的乘加，也就是64次乘加運算。從程式來看，它是以一個warp（32個執行緒）協力處理16×16這類稍大矩陣片段的指令來使用。神經網路的全連接層與卷積的大部分都能轉換為矩陣乘積，因此能大幅加速AI的計算。

低精度與高精度的組合

張量核心主要以FP16、BF16、FP8、INT8等低精度的輸入使用。以位元數較少的格式進行乘法，可以大幅節省運算單元的面積與功耗，以及記憶體的容量與頻寬。另一方面，加總數千個乘積的累加會累積捨入誤差，因此基本形式是以FP16輸入、以FP32累加的混合精度。隨著世代演進，支援的格式也增加，也有支援與FP32指數欄位相同的TF32，或雙精度FP64的產品。可使用哪些格式依世代而異。

為什麼比一般運算單元快

矩陣乘積可以多次重複利用同一筆資料。n×n矩陣相乘需要n³次乘加，資料卻只有n²的數量級，因此以小矩陣為單位一起計算，每次從暫存器讀取或每次發出指令所完成的計算量就會增加。一般運算單元（CUDA核心）是每個執行緒一次進行一個乘加，而張量核心把這種重複利用做進電路，因此在相同面積與功耗下能完成數倍的運算。相對地，它無法用於矩陣乘加以外的計算，資料也必須排列成固定的形狀。

使用方式與其他矩陣運算單元

多數情況下，張量核心不是直接撰寫程式使用，而是透過cuBLAS、cuDNN等函式庫，或PyTorch等框架來使用。將資料格式設為FP16或BF16，並把矩陣尺寸對齊到建議的倍數，函式庫就會選擇使用張量核心的計算方法。在CUDA中，也能透過以warp為單位處理矩陣片段的WMMA API，或PTX的mma指令直接使用。其他公司的GPU與AI加速器也有相同目的的矩陣運算單元，也有像Google TPU那樣以脈動陣列計算矩陣乘積的設計。

張量核心是能以一個指令一次進行如4×4或16×16這類小矩陣的乘法與加法的運算單元。與以一般運算單元逐次進行乘法與加法相比，在相同的面積與功耗下能完成數倍的計算。多半以FP16、BF16、FP8、INT8等低精度使用，能大幅加快佔神經網路訓練與推論大部分的矩陣乘積。

常見問題

張量核心與CUDA核心有什麼不同？

CUDA核心是每個執行緒一次進行一個FP32等乘加或整數運算的通用運算單元。張量核心則是以warp為單位的一個指令一併完成小矩陣乘加的專用運算單元，僅就矩陣乘積而言，每個時脈能完成多得多的運算。

TF32是什麼？

NVIDIA在Ampere世代的張量核心中導入的計算用格式，具有與FP32相同的8位元指數部，以及與FP16相同的10位元尾數。FP32的資料可以直接輸入，在維持與FP32相當的表示範圍下，以降低尾數精度換取張量核心的高速計算。

張量核心用於訓練還是推論？

兩者都會使用。訓練主要以BF16或FP16的混合精度進行，推論則常使用更低的FP8或INT8等，無論哪一種，都能加速佔計算大部分的矩陣乘積。
