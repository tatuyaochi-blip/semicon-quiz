什麼是布斯演算法(Booth's algorithm)

將乘數的位元序列每兩位元等分段，置換成有號的位數，以減少部分積數量的乘法方法。基數4的布斯法可使部分積減少約一半。

日文名稱: ブースのアルゴリズム

「布斯演算法(Booth's algorithm)」出現在1領域的1道練習題中（電腦算術等）。

這個名詞所屬的領域: 電腦算術

練習布斯演算法(Booth's algorithm)的題目

在乘法器中使用基數4的布斯演算法（Booth編碼）的主要效果為下列何者？

  1. A使乘法的結果不經捨入而能準確求得
  2. B將乘數置換為有號的位數，使部分積減少至約一半
  3. C雖然無法進行有號數的乘法，但能縮小電路
查看答案與解析

正確答案：B. 將乘數置換為有號的位數，使部分積減少至約一半

在一般的乘法中，乘數的每1位元都會產生1個部分積，因此n位元就必須加總n個部分積。基數4的布斯編碼會每2位元（觀察有重疊的3位元）將乘數置換為 −2、−1、0、+1、+2 的位數，因此部分積減少為約n/2個。−2倍或+2倍只要移1位元，負值則可用二補數產生，所以電路也很簡單。部分積減少的部分，使加總的電路變得更小且更快。有號數的乘法也能自然地處理。
