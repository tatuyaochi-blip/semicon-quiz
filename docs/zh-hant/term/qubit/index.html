什麼是量子位元

量子電腦中表示資訊的單位。可以處於 |0⟩ 與 |1⟩ 的疊加態 α|0⟩ + β|1⟩，量測時以機率 |α|² 得到 0、以機率 |β|² 得到 1。可用超導電路、離子、中性原子、矽中電子的自旋、光子等實現。

日文名稱: 量子ビット

「量子位元」出現在1領域的34道練習題中（量子電腦硬體等）。

這個名詞所屬的領域: 量子電腦硬體

狀態的表示與量測

1 個量子位元的狀態可寫成 α|0⟩ + β|1⟩，α 與 β 是滿足 |α|² + |β|² = 1 的複數（機率振幅）。量測時以機率 |α|² 得到 0、以機率 |β|² 得到 1，狀態也會變成與結果對應的狀態。1 次量測無法得知機率本身，因此要把同一電路重複執行許多次（每次稱為一個 shot），從結果的比例估算機率。機率為 0.5 時，即使重複 1 萬次，估計值仍有約 0.5% 的標準差。狀態可以用布洛赫球上的點表示，量子邏輯閘的操作相當於這個球的旋轉。

n 個量子位元與 2ⁿ 個振幅

n 個量子位元的狀態有 2ⁿ 個機率振幅，50 個量子位元時約為 10¹⁵ 個。以倍精度複數存放在古典電腦中約需 18 PB，量子位元每增加 1 個就變為 2 倍。不過，量測只能得到 n 位元，無法讀出全部的振幅。量子演算法的設計，是利用干涉讓正確答案的振幅變大，並讓錯誤答案的振幅互相抵消。

物理實現方式

超導電路（transmon）以相距約 5 GHz 的 2 個能階作為量子位元，冷卻到約 10 mK 後運作。離子阱與中性原子使用原子的能階，矽自旋量子位元使用困在量子點中電子的自旋方向，光量子平台則使用光子的偏振或路徑等性質。不論哪一種平台，決定效能的不只是量子位元數量，還有邏輯閘錯誤率、相干時間與量子位元之間的連接方式。錯誤更正則是以大量物理量子位元構成 1 個邏輯量子位元。

練習量子位元的題目

關於量子位元的敘述，下列何者正確？

  1. A是保存 0 與 1 之間電壓的類比記憶元件，讀取時會直接得到中間的值
  2. B可以處於 |0⟩ 與 |1⟩ 的疊加態，量測時會以一定機率得到 0 或 1 其中之一
  3. C因為同時保存 0 與 1，所以 1 次量測就能讀出 0 與 1 兩個值
查看答案與解析

正確答案：B. 可以處於 |0⟩ 與 |1⟩ 的疊加態，量測時會以一定機率得到 0 或 1 其中之一

量子位元的狀態可寫成 α|0⟩ + β|1⟩，α 與 β 是滿足 |α|² + |β|² = 1 的複數（機率振幅）。量測時，以機率 |α|² 得到 0、以機率 |β|² 得到 1，狀態也會變成與結果對應的狀態。疊加並不是「0 與 1 之間的值」，量測得到的一定是 0 或 1 其中之一。1 次量測只能得到 1 位元的資訊，無法直接讀出 α 與 β 本身的值。

量子位元處於 (√3/2)|0⟩ + (1/2)|1⟩ 的狀態時，量測得到 1 的機率為下列何者？

  1. A25%
  2. B50%
  3. C75%
查看答案與解析

正確答案：A. 25%

量測得到 1 的機率，是 |1⟩ 的機率振幅絕對值的平方，即 (1/2)² = 1/4 = 25%。得到 0 的機率為 (√3/2)² = 3/4 = 75%，兩者合計為 100%。若把振幅 1/2 直接當成機率，就會誤答 50%。

常見問題

從 n 個量子位元能取出多少位元的資訊？

以量測取出的古典資訊最多為 n 位元。即使保存了 2ⁿ 個振幅，也無法全部讀出。量子電腦的速度並非來自能讀出更多資訊，而是來自利用干涉，減少得到答案所需的步驟數。

物理量子位元與邏輯量子位元有什麼不同？

物理量子位元是實際做在裝置中的一個一個量子位元。邏輯量子位元則是以量子錯誤更正把大量物理量子位元組合起來、更能抵抗錯誤的 1 個量子位元。使用表面碼時，1 個邏輯量子位元可能需要數百個以上的物理量子位元。
