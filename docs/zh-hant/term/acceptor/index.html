什麼是受體

從半導體接收電子而產生電洞的雜質。對矽而言，是硼(B)等 III 族元素，用來形成 p 型半導體。

日文名稱: アクセプタ

「受體」出現在5領域的16道練習題中（半導體物性, 離子佈植, 化合物半導體等）。

這個名詞所屬的領域: 半導體物性

練習受體的題目

同時含有施體濃度5×10¹⁶ cm⁻³與受體濃度2×10¹⁶ cm⁻³的矽（室溫、全部離子化），其性質下列何者正確？

  1. A為p型，電洞濃度約2×10¹⁶ cm⁻³
  2. B為n型，電子濃度約3×10¹⁶ cm⁻³
  3. C為n型，電子濃度約7×10¹⁶ cm⁻³
查看答案與解析

正確答案：B. 為n型，電子濃度約3×10¹⁶ cm⁻³

施體與受體同時存在時會互相抵消（補償），呈現數量較多者的型別。施體較多所以是n型，電子濃度為兩者之差 5×10¹⁶ − 2×10¹⁶ = 3×10¹⁶ cm⁻³。不過，載子會被合計7×10¹⁶ cm⁻³的離子化雜質所散射，因此遷移率比相同電子濃度的無補償材料更低。在井（well）中製作源極、汲極時，也是利用這種抵消（反摻雜）來反轉導電型。

解析中的「受體」

  • 施體與受體同時存在時會互相抵消（補償），呈現數量較多者的型別。

    同時含有施體濃度5×10¹⁶ cm⁻³與受體濃度2×10¹⁶ cm⁻³的矽（室溫、全部離子化），其性質下列何者正確？

  • 若要形成p型，則摻入硼（B）等III族元素（受體）。

    在矽中摻入磷（P）作為雜質時，下列說明何者正確？

  • 砷約為0.054 eV，硼的受體能階距價電帶約0.045 eV。

    關於矽中磷所形成的施體能階在能隙內的位置，下列何者正確？

  • 若在其中摻入多1個價電子的V族（磷等）就成為施體，摻入少1個的III族（硼等）則成為受體，這就是摻雜的基本原理。

    1個矽原子具有的價電子（最外層電子）數是多少？

  • 硼是矽中具代表性的受體，其能階距價電帶約0.045 eV，很淺，在室溫下幾乎全部離子化。
