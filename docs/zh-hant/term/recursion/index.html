什麼是遞迴

函式在處理過程中呼叫自己。把問題分成形式相同的較小問題來解，並在不再分割的情況（基底情況）結束呼叫。每次呼叫都會使用堆疊，太深就會溢位。最後只呼叫自己的尾端遞迴可以轉換成迴圈。

日文名稱: 再帰

「遞迴」出現在8領域的14道練習題中（資料結構與演算法, 連結器與載入器與執行檔格式, 程式設計基礎（虛擬碼追蹤）等）。

這個名詞所屬的領域: 資料結構與演算法

練習遞迴的題目

在無向圖中，各頂點的相鄰頂點如下：A: B, C / B: A, D, E / C: A, F / D: B / E: B, F / F: C, E。從頂點 A 進行遞迴的深度優先搜尋。相鄰頂點依此處列出的順序檢查，一找到尚未拜訪的頂點就立刻前往。拜訪頂點的順序為下列何者？

  1. AA, B, C, D, E, F
  2. BA, B, D, E, C, F
  3. CA, B, D, E, F, C
查看答案與解析

正確答案：C. A, B, D, E, F, C

從 A 前往 B，再前往 B 的相鄰頂點中第一個未拜訪的 D。D 的相鄰頂點只有已拜訪的 B，因此回到 B 再前往下一個 E，接著從 E 前往未拜訪的 F，再從 F 前往其相鄰頂點 C。所以順序為 A, B, D, E, F, C。A, B, C, D, E, F 是依離起點由近到遠拜訪的廣度優先搜尋的順序。A, B, D, E, C, F 沒有從 E 前往未拜訪的 F 就折返了，不是深度優先搜尋的順序。

以遞迴將求費氏數的函數 fib(n) 定義為「若 n 在1以下則回傳 n，否則回傳 fib(n−1) + fib(n−2)」。呼叫 fib(5) 時，含第一次呼叫在內，fib 被呼叫幾次？

  1. A6次
  2. B9次
  3. C15次
查看答案與解析

正確答案：C. 15次

設 fib(n) 的呼叫次數為 C(n)，則 C(0) = C(1) = 1、C(n) = 1 + C(n−1) + C(n−2)，因此 C(2) = 3、C(3) = 5、C(4) = 9、C(5) = 15。由於相同的值被反覆重新計算，次數會隨 n 呈指數增加，fib(30) 約需269萬次。若使用把算過的值記在表中的記憶化（動態規劃），只需計算 fib(0)～fib(5) 這6種，呼叫也減為9次（2n − 1）。6次是不同引數的個數，9次是記憶化時的呼叫次數。
