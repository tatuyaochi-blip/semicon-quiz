什麼是CSP(晶片尺寸封裝)

縮小到與晶片幾乎相同大小之封裝的統稱。廣泛用於智慧型手機等小型設備。

日文名稱: CSP(チップサイズパッケージ)

「CSP(晶片尺寸封裝)」出現在1領域的2道練習題中（封裝與構裝等）。

這個名詞所屬的領域: 封裝與構裝

怎樣才算晶片尺寸

CSP 是一個類別名稱，而非單一結構。封裝的占位面積只比晶粒稍大，通常不超過晶粒面積的約 1.2 倍時，即可稱為晶片尺寸封裝。有幾種結構符合此定義：將晶粒安裝在小型基板上、底部有錫球陣列的封裝；底部具有端子的導線架型封裝；以及晶圓級 CSP（WLCSP），即直接在晶圓上形成重佈線與錫球，使完成的封裝與晶粒大小完全相同。

CSP 與傳統封裝的比較

DIP（雙列直插封裝）與 QFP（四方扁平封裝）等傳統封裝從封裝體邊緣引出接腳，因此接腳數受周長限制，封裝體也比晶粒大得多。CSP 在底部使用面陣列端子，類似 BGA（球柵陣列），但縮小到晶粒的占位面積。晶粒與電路板之間的連接短，寄生電感與電容較低。代價是端子間距必須很細，通常約 0.4–0.5 mm，需要精密的電路板設計與組裝。

板級可靠度

矽隨溫度的膨脹遠小於 FR-4 電路板，約為 3 ppm/K 對約 15 ppm/K。在 WLCSP 中，晶粒幾乎是直接焊在電路板上，因此溫度循環會使焊點承受應變，尤其是最外圈的錫球。因此大晶粒的 WLCSP 會限制尺寸，或以底部填充膠（underfill，一種流入封裝下方以分擔應力的環氧樹脂）加以補強。對手持產品中的 CSP 而言，機械落摔衝擊也是另一項關鍵的驗證測試。

扇入的限制與應用場合

扇入式 WLCSP 只能在晶粒輪廓內配置錫球，因此 I/O 多而面積小的晶粒會不夠空間；扇出型封裝則將重佈線層延伸到晶粒邊緣之外來解決此問題。凡是電路板面積與高度受限的地方都能見到 CSP：智慧型手機、穿戴裝置、耳機與相機模組，通常用於電源管理晶片、感測器、RF 元件與記憶體。接腳數極多的大型處理器則一般改用較大的覆晶 BGA 封裝。

正確答案：B. 縮小到與晶片幾乎相同大小的封裝

CSP是將封裝尺寸縮小到與晶片幾乎相同（一般為晶片的1.2倍左右以下）的封裝總稱。端子多為以格子狀排列在背面的BGA型，常用於智慧型手機或穿戴式裝置等希望減少安裝面積的產品。在晶圓狀態下就製作到端子的WLP，是尺寸與晶片相同的CSP之一。與並排多顆晶片的大型產品或QFP是不同的東西。

常見問題

CSP 和 BGA 有什麼差別？

BGA 描述的是端子形式，即封裝下方的錫球陣列；CSP 描述的是尺寸，即接近晶粒的占位面積。許多 CSP 使用 BGA 式的錫球，但 BGA 封裝往往比其晶粒大得多。

WLCSP 是 CSP 的一種嗎？

是的。晶圓級 CSP 在仍處於晶圓狀態時就形成佈線與錫球，因此切割後的封裝與晶粒大小完全相同。

晶片尺寸封裝比晶粒大多少？

通常定義為不超過晶粒面積的約 1.2 倍，而晶圓級 CSP 則與晶粒大小相同。

  • BGA、QFP、QFN 的差異：比較 IC 封裝的種類以端子、腳位數、間距、大小、電氣性能與散熱、檢查與用途等面向，用表格比較 BGA、QFP、QFN 封裝。
