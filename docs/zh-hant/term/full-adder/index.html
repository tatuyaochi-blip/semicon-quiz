什麼是全加器

將兩個位元與來自低位的進位共 3 個輸入相加，輸出和與往高位的進位的電路。沒有進位輸入的稱為半加器。串聯連接即成為多位元加法器。

日文名稱: 全加算器

「全加器」出現在2領域的5道練習題中（邏輯電路, 電腦算術等）。

這個名詞所屬的領域: 邏輯電路

全加器的邏輯

全加器將A、B與進位輸入Cin三個1位元輸入相加，輸出和S與進位輸出Cout，兩者合起來的數值等於輸入中為1的個數。和是輸入的奇偶性，S = A ⊕ B ⊕ Cin；進位則是多數決，Cout = AB + BC + CA。半加器只處理兩個輸入，和為A ⊕ B、進位為AB，因此一個全加器可由兩個半加器加上一個合併兩者進位的OR閘構成。

漣波進位加法與減法

將n個全加器串接，讓每個進位輸出接到下一級的進位輸入，就構成n位元漣波進位加法器。它面積小、結構規則，但最高位元必須等進位逐級傳過每一級才能穩定，因此延遲隨位元寬度線性增加：64位元加法器約需64個全加器延遲，對GHz等級的處理器資料路徑而言太慢。同一條加法器鏈也能做減法。將B反相並把最低位的進位輸入設為1，即可計算A + (¬B + 1)，也就是二補數表示下的A − B，因此ALU可用同一個加法器完成兩種運算。

加快進位的方法

高速加法器不必等待進位逐級傳遞就能算出進位。每個位元位置在G = AB時產生進位，在P = A ⊕ B時傳遞輸入的進位。前瞻進位加法器以G與P展開各位元群組的進位遞迴式。進位選擇加法器則針對兩種可能的進位輸入，預先算好高位的和，待實際進位抵達時再擇一輸出。平行前綴加法器（例如Kogge-Stone加法器）以樹狀結構組合G與P，使進位延遲隨log2 n成長，代價是大幅增加的繞線與面積。

加法器以外的全加器應用

乘法器需要同時加總許多部分積，此時全加器被當作3:2壓縮器使用：輸入三個相同權重的位元，輸出一個和位元與一個下一權重的進位位元。由這種進位儲存加法器構成的樹狀結構，例如Wallace樹或Dadda樹，會將多列部分積縮減為兩列，最後再由一個高速加法器算出最終結果。在電晶體層級，常見的靜態CMOS實作是28個電晶體的鏡像加法器，它共用進位邏輯，並由反相的進位產生和。

練習全加器的題目

下列哪一項是全加器輸入的正確組合？

  1. A要相加的兩個位元，以及來自低位的進位
  2. B只有要相加的兩個位元
  3. C只有時脈訊號
查看答案與解析

正確答案：A. 要相加的兩個位元，以及來自低位的進位

全加器由要相加的兩個位元A、B與來自低位的進位Cin這3個輸入，輸出和與往高位的進位。n位元的加法需串接n個全加器（漣波進位加法器）。將最低位的Cin設為1並將B反相，則 A − B = A + (¬B + 1)，同一個電路也能做減法。由於這個性質，CPU的ALU以一個加法器兼作加法與減法。

將全加器串聯而成的漣波進位加法器，其缺點下列哪一項正確？

  1. A無法處理負數
  2. B進位從低位依序傳遞，因此延遲與位元數成正比增加
  3. C即使位元數增加，電路規模也不變
查看答案與解析

正確答案：B. 進位從低位依序傳遞，因此延遲與位元數成正比增加

在漣波進位加法器中，各全加器要等待來自低位的進位後才進行計算，因此進位從最低位依序傳到最高位，延遲與位元數成正比增加。64位元時就是64級全加器的延遲，對於以GHz動作的CPU而言太慢。由於電路小而單純，用於不要求速度的用途。要提高速度，可使用先行進位、進位選擇、平行前綴（Kogge-Stone等）加法器。

常見問題

半加器和全加器有什麼不同？

半加器將兩個位元相加，輸出和與進位；全加器則將兩個位元再加上來自低位的進位輸入。只有全加器能串接起來進行多位元數的加法。

全加器的布林表示式是什麼？

和 = A ⊕ B ⊕ Cin，Cout = AB + BC + CA，也可等價寫成AB + Cin(A ⊕ B)。進位輸出就是三個輸入的多數決函數。

一個全加器需要幾個半加器？

兩個。第一個將A與B相加，第二個將該和與Cin相加，再以一個OR閘將兩個進位輸出合併為Cout。
