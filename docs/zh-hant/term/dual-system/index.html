什麼是雙重系統（Dual system）

以2套系統同時進行相同的處理，一邊比對結果一邊運轉的備援方式。可從結果的不一致察覺錯誤，一套故障時另一套也能直接繼續處理。可靠度高，但由2套設備進行相同的處理，費用較高。

日文名稱: デュアルシステム

「雙重系統（Dual system）」出現在1領域的2道練習題中（系統架構與可靠度設計等）。

這個名詞所屬的領域: 系統架構與可靠度設計

練習雙重系統（Dual system）的題目

關於雙重系統（dual system）的說明，下列何者適當？

  1. A準備主系統（運轉系統）與備援系統，平時只由主系統處理，主系統故障時切換到備援系統繼續處理
  2. B以多套系統分擔處理，提高整體的處理能力
  3. C以2套系統同時進行相同的處理並比對結果，即使其中一套故障，也能由另一套繼續處理
查看答案與解析

正確答案：C. 以2套系統同時進行相同的處理並比對結果，即使其中一套故障，也能由另一套繼續處理

雙重系統是以2套系統同時進行相同的處理，一邊比對結果一邊運轉的方式。結果不一致時就能察覺錯誤，一套故障時另一套也能直接繼續處理，因此用於要求高可靠度的處理。相對地，由2套設備進行相同的處理，費用較高。分為主系統與備援系統、故障時切換的方式是雙工系統。
