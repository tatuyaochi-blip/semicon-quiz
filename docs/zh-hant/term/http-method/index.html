什麼是HTTP方法

在HTTP請求中，表示要對資源進行何種操作的詞。有GET（取得）、HEAD（只取得標頭）、POST（處理或建立）、PUT（取代）、PATCH（部分更新）、DELETE（刪除）、OPTIONS（詢問可用的功能）等。不改變伺服器狀態的方法稱為「安全」，無論送出幾次都與送出1次時狀態相同的方法稱為「冪等」。GET既安全又冪等，PUT與DELETE冪等但不安全，POST一般兩者皆非。

日文名稱: HTTPメソッド

「HTTP方法」出現在1領域的2道練習題中（Web技術基礎等）。

練習HTTP方法的題目

HTTP方法之中，不是「安全」（不打算改變伺服器上資源的狀態），但屬於「冪等」（同一個請求無論送出幾次，狀態都與送出1次時相同）的是下列何者？

  1. AGET
  2. BPOST
  3. CPUT
查看答案與解析

正確答案：C. PUT

GET與HEAD是只讀取資源的安全方法，而安全的方法同時也是冪等的。PUT以送出的內容取代指定資源的狀態，因此無論送出幾次，結果都與1次相同，是冪等但不安全。DELETE同樣是冪等的。POST每次送出都可能建立新的訂單或貼文，因此一般不是冪等，PATCH也不一定冪等。冪等的請求有一個優點：因通訊失敗而不知道結果時，直接重送也不容易出問題。
