什麼是非揮發性記憶體

關閉電源後所記憶的資料也不會消失的記憶體。例如快閃記憶體與 MRAM 等。DRAM 與 SRAM 則是揮發性。

日文名稱: 不揮発性メモリ

「非揮發性記憶體」出現在4領域的10道練習題中（SRAM與快閃記憶體, 新世代記憶體, 可靠度等）。

這個名詞所屬的領域: SRAM與快閃記憶體

練習非揮發性記憶體的題目

為了儲存微控制器的程式，而一直與邏輯電路混載在同一晶片上的非揮發性記憶體是下列何者？

  1. A嵌入式快閃記憶體
  2. BHBM
  3. CGDDR
查看答案與解析

正確答案：A. 嵌入式快閃記憶體

微控制器一直將儲存程式與資料的嵌入式快閃記憶體與邏輯電路混載在同一晶片上。斷電後內容仍保留，出貨後也能改寫韌體。然而浮動閘極的形成等製程步驟多，在 28 nm 前後之後的世代，以及與 High-k／金屬閘極的混載都很困難，因此正逐漸被可用較少製程步驟製作的 MRAM 與 ReRAM 取代。

MRAM 作為微控制器等的嵌入式非揮發性記憶體而受到矚目，其理由之一，下列何者正確？

  1. A先進邏輯製程中嵌入式快閃記憶體的製造變得困難，而可在後段製程製作的 MRAM 成為替代候選
  2. B比 DRAM 容量大且便宜
  3. C斷電後資料會消失
查看答案與解析

正確答案：A. 先進邏輯製程中嵌入式快閃記憶體的製造變得困難，而可在後段製程製作的 MRAM 成為替代候選

嵌入式快閃記憶體因浮動閘極的形成等，需要追加 10 片以上的光罩，在 28 nm 前後之後的世代，以及與 High-k／金屬閘極的組合中，已難以實現。MRAM 可在後段製程中途製作 MTJ，追加的光罩也只要數片，因此台積電與三星等晶圓代工廠在 22 nm 以下提供嵌入式 MRAM。在車用微控制器等的採用持續增加。

解析中的「非揮發性記憶體」

  • 若將非揮發性記憶體用於快取或暫存器，即使在沒有處理的瞬間細密地關閉電源，資料也會留存，因此可使待機功耗幾近於 0，恢復也更快（常閉運算，Normally-off Computing）。

    將非揮發性記憶體用於快取或暫存器等處所期待的系統節能機制，下列何者正確？

  • MRAM 以磁性體的磁化方向記憶，因此是斷電後資料仍會保留的非揮發性記憶體，保存期間一般在 10 年以上。

    下列記憶體中，斷電後資料仍會保留的非揮發性記憶體是哪一個？

  • 快閃記憶體是將電子封閉在被絕緣膜包圍的浮動閘極或電荷捕捉層中來記憶，因此是斷電後資料仍會保留的非揮發性記憶體。

    關於快閃記憶體的性質，下列何者正確？

  • USB 隨身碟、SD 卡與 SSD 使用的是大容量且便宜的非揮發性記憶體 NAND 快閃記憶體，內部有 NAND 晶片，以及負責錯誤更正與損耗平均的控制器。

    USB 隨身碟與 SD 卡主要使用的記憶體是下列何者？

  • EEPROM 是可以 1 位元組為單位抹除、改寫的非揮發性記憶體，每個單元都要附加選擇電晶體，因此單元較大，容量約為數 Kbit～數 Mbit。
