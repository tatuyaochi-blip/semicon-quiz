什麼是電流增益(hFE)

雙載子電晶體的集極電流與基極電流之比(IC/IB)。

日文名稱: 電流増幅率(hFE)

「電流增益(hFE)」出現在1領域的22道練習題中（雙載子電晶體等）。

這個名詞所屬的領域: 雙載子電晶體

練習電流增益(hFE)的題目

表示雙極性電晶體直流電流增益hFE的算式是哪一個？（IC：集極電流、IB：基極電流、IE：射極電流）

  1. AIB / IC
  2. BIC / IB
  3. CIE / IC
查看答案與解析

正確答案：B. IC / IB

hFE是共射極的直流電流增益，hFE = IC/IB。小訊號電晶體一般為數十至數百，功率電晶體一般約為數十。即使是相同型號，個體差異也很大（例如依100〜400分級），而且會隨溫度與電流變化，因此電路設計的基本原則是不依賴hFE的數值就能正常工作。共基極的電流增益α為 IC/IE，是略小於1的值。

共基極電流增益α = 0.99的雙極性電晶體，其共射極電流增益β大約是多少？

  1. A0.99
  2. B9.9
  3. C99
查看答案與解析

正確答案：C. 99

α與β之間有 β = α/(1 − α) 的關係，α = 0.99 時 β = 0.99 ÷ 0.01 = 99。反過來，α = β/(1 + β)。若α = 0.995則β = 199，α只要稍微更接近1，β就會大幅改變。射極電流中在基極損失的比例（1 − α）為1%，代表基極電流約為集極電流的1/99，如何減少基極的損失是設計的關鍵。

解析中的「電流增益(hFE)」

  • hFE是共射極的直流電流增益，hFE = IC/IB。

    表示雙極性電晶體直流電流增益hFE的算式是哪一個？（IC：集極電流、IB：基極電流、IE：射極電流）

  • 矽電晶體的hFE一般會隨溫度上升而增加，約為每1 ℃增加0.5〜1%。

    矽雙極性電晶體的電流增益hFE，一般而言溫度上升時會如何？

  • 在主動區 IC = hFE × IB，所以 100 × 10 µA = 1,000 µA = 1 mA。

    對直流電流增益hFE = 100的電晶體施加10 μA的基極電流時，在主動區的集極電流大約是多少？

  • hFE是直流下集極電流與基極電流的比 IC/IB，hfe是工作點附近微小變化量的比 ΔIC/ΔIB。

    直流電流增益hFE與小訊號電流增益hfe的差異，下列何者正確？

  • 在小電流時，空乏區的復合電流（與exp(qV/2kT)成正比）在基極電流中所占的比例變大，使hFE下降。
