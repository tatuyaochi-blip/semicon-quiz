什麼是電流增益(hFE)

雙載子電晶體的集極電流與基極電流之比(IC/IB)。

日文名稱: 電流増幅率(hFE)

「電流增益(hFE)」出現在2領域的23道練習題中（雙載子電晶體, 車用半導體與功能安全等）。

這個名詞所屬的領域: 雙載子電晶體

從 α 到 β

電流增益有兩種表示方式。共基極增益 α = IC/IE 略小於 1，因為有一小部分射極電流在基極中損失。共射極增益寫作 β 或 hFE = IC/IB，可由 β = α/(1 − α) 求得。α = 0.99 時 β = 99；α = 0.995 時 β = 199，因此 α 的微小變化會造成 hFE 的大幅變動。在主動區 IC ≈ hFE × IB：基極電流 10 µA、hFE = 100 時約為 1 mA，前提是集極電路能供應這個電流。

電晶體內部什麼決定了 hFE

以 NPN 元件為例，基極電流主要由從基極反向注入射極的電洞，以及穿越基極時發生復合的電子所構成。高摻雜的射極可抑制反向注入的電洞，提高注入效率；基極厚度遠小於少數載子擴散長度，則讓幾乎所有電子都能抵達集極。射極摻雜過高時，最終會因能隙窄化而失去效果；異質接面雙載子電晶體（HBT）以較寬能隙的射極解決這個問題。基極變薄也會提高基極電阻與貫穿（punch-through）的風險。

為什麼電路設計不應依賴 hFE

小訊號電晶體的 hFE 通常為數十到數百，功率元件則為數十，但同一型號的個體差異很大，常依 100–400 等範圍分級出貨。hFE 也會隨溫度上升，約每 °C 增加 0.5–1%，並在中等集極電流時達到峰值；低電流時因空乏區復合而下降，高電流時則因高階注入與 Kirk 效應而下降。因此穩健的偏壓電路會使用射極電阻與電阻分壓式基極偏壓，讓工作點由電阻而非 hFE 決定。

hFE 與 hfe，以及開關應用

大寫的 hFE 是直流比值 IC/IB，用於偏壓計算；小寫的 hfe 是工作點附近的小訊號比值 ΔIC/ΔIB，用於交流增益與輸入電阻的計算。兩者通常接近但不相等。在開關應用中，電晶體被驅動至飽和區，此時集極電流受負載限制，IC/IB（強制 β）會刻意設定得低於 hFE。設計者通常提供 IC/hFE(min) 的 2–10 倍作為基極電流以確保飽和，代價是儲存電荷增加、關斷變慢。

練習電流增益(hFE)的題目

表示雙極性電晶體直流電流增益hFE的算式是哪一個？（IC：集極電流、IB：基極電流、IE：射極電流）

  1. AIB / IC
  2. BIC / IB
  3. CIE / IC
查看答案與解析

正確答案：B. IC / IB

hFE是共射極的直流電流增益，hFE = IC/IB。小訊號電晶體一般為數十至數百，功率電晶體一般約為數十。即使是相同型號，個體差異也很大（例如依100〜400分級），而且會隨溫度與電流變化，因此電路設計的基本原則是不依賴hFE的數值就能正常工作。共基極的電流增益α為 IC/IE，是略小於1的值。

共基極電流增益α = 0.99的雙極性電晶體，其共射極電流增益β大約是多少？

  1. A0.99
  2. B9.9
  3. C99
查看答案與解析

正確答案：C. 99

α與β之間有 β = α/(1 − α) 的關係，α = 0.99 時 β = 0.99 ÷ 0.01 = 99。反過來，α = β/(1 + β)。若α = 0.995則β = 199，α只要稍微更接近1，β就會大幅改變。射極電流中在基極損失的比例（1 − α）為1%，代表基極電流約為集極電流的1/99，如何減少基極的損失是設計的關鍵。

常見問題

hFE 和 β 有什麼不同？

實務上兩者指的是同一個量，即共射極電流增益 IC/IB。hFE 是規格書上用於直流值的 h 參數名稱，β 則是教科書與元件物理中常用的符號。

hFE 和 hfe 的差別是什麼？

hFE 是在特定工作點的直流電流增益 IC/IB，hfe 則是該工作點附近的小訊號增益 ΔIC/ΔIB。偏壓設計用 hFE，交流分析用 hfe。

為什麼不同電晶體的 hFE 差異這麼大？

hFE 取決於基極寬度、摻雜與復合，而這些因元件而異，並且還會隨溫度與集極電流變化。因此好的設計會用回授電阻來設定工作點，而不是依賴精確的 hFE 值。
