什麼是理想因子

二極體電流公式 I ∝ exp(qV/nkT) 中的 n。擴散電流占主導時為 1，空乏層內的復合電流占主導時趨近 2，是接面品質的指標。

日文名稱: 理想係数

「理想因子」出現在1領域的1道練習題中（PN接面與二極體等）。

這個名詞所屬的領域: PN接面與二極體

n = 1 與 n = 2 從何而來

在理想的擴散模型中，順向偏壓使空乏區各邊緣的少數載子濃度依 exp(qV/kT) 的比例上升，擴散到中性區的電流也遵循相同的規律，因此 n = 1。空乏區內的復合則不同：它在電子與電洞密度相等處最強，而在該處兩者各等於 ni·exp(qV/2kT)。由此產生的復合電流隨 exp(qV/2kT) 變化，因此以它為主的二極體會呈現 n ≈ 2。

從 I-V 曲線求出 n

將順向電流以對數軸對電壓作圖。在室溫下，理想二極體每約 60 mV 上升一個十倍，因為 kT/q × ln 10 ≈ 26 mV × 2.3；理想因子為 n 的二極體則每十倍需要 n × 60 mV。正式地，n = (q/kT)·dV/d(ln I)。應使用曲線中段的直線部分：在低電流時，並聯漏電會使其失真；在高電流時，串聯電阻會使曲線彎折，使表觀的 n 變大。

數值告訴你什麼

許多矽二極體在低電流時 n 接近 2，此時空乏區復合相對重要；在中等電流時則接近 1，此時以擴散為主。在高注入下，當注入的載子超過摻雜濃度時，n 又會向 2 上升。大於 2 的值則指向其他機制，例如穿隧或多個串聯的接面。由於復合取決於缺陷密度，n 被用作快速評估接面品質的指標，例如在太陽能電池中，它常以 n = 1 與 n = 2 的兩個二極體來建模。

與 MOSFET 次臨界擺幅的關聯

同樣的熱因子也限制著電晶體。低於臨界值的 MOSFET 是藉由越過能障的擴散而導電，因此其電流同樣隨電壓呈指數變化。其次臨界擺幅為 (kT/q)·ln 10 × (1 + Cd/Cox)，其中 Cd 為空乏電容，Cox 為閘極氧化層電容，因此在室溫下至少約為每十倍 60 mV。括號內的因子扮演理想因子的角色：閘極電壓只有一部分耦合到通道電位。

練習理想因子的題目

要使理想二極體（理想因子 n = 1）的順向電流增為10倍，在室溫下所需的順向電壓增量大約是多少？

  1. A約6 mV
  2. B約60 mV
  3. C約600 mV
查看答案與解析

正確答案：B. 約60 mV

順向電流與 exp(qV/kT) 成正比，因此要使電流增為10倍，只要將 V 增加 kT/q × ln10 ≈ 26 mV × 2.3 ≈ 60 mV 即可。因此常以「每一個數量級約60 mV」作為參考。理想因子n較大時，此值會變成 n × 60 mV，所以可由電流-電壓特性的半對數圖斜率求得n。MOSFET次臨界擺幅的理論極限也是同樣的值。

常見問題

理想因子為 2 代表什麼？

代表電流以空乏區內經由缺陷能階的復合為主，或二極體處於高注入狀態，而不是以理想的少數載子擴散為主。

如何從 I-V 曲線計算理想因子？

取順向電流對電壓之半對數圖在直線區域的斜率：n = (q/kT)·ΔV/Δ(ln I)，或者 n 等於實測的每十倍毫伏數除以室溫下的約 60 mV。

為什麼實測的理想因子在高電流時會增加？

串聯電阻使部分施加電壓降在接面之外，而高注入改變了物理機制，兩者都會使每十倍所需的電壓變大。
