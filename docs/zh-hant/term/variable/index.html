什麼是變數

在程式中用來記住值、附有名稱的容器。宣告整數型、實數型等型別後使用，並以指派改寫其值。指派新的值後，先前的值就會遺失。

日文名稱: 変数

「變數」出現在11領域的73道練習題中（程式設計基礎（虛擬碼追蹤）, 連結器與載入器與執行檔格式, 多核心與同步等）。

這個名詞所屬的領域: 程式設計基礎（虛擬碼追蹤）

練習變數的題目

在嵌入式程式中，存放32位元周邊暫存器值的變數，常以 stdint.h 的 uint32_t 宣告，而不是 unsigned int。主要理由為下列何者？

  1. Auint32_t 的值超過最大值時不會回到0，而是停在最大值（飽和）
  2. B以 uint32_t 宣告的變數，讀寫不會被編譯器的最佳化省略
  3. Cunsigned int 的大小因處理系統而異，而 uint32_t 規定為剛好32位元的無號整數
查看答案與解析

正確答案：C. unsigned int 的大小因處理系統而異，而 uint32_t 規定為剛好32位元的無號整數

stdint.h 的 uint8_t、uint16_t、uint32_t、int32_t 等，是位元數如名稱所示固定的整數型別（固定寬度整數型別）。unsigned int 可能是16位元也可能是32位元，因此在需要配合暫存器寬度，或要決定通訊資料格式的場合使用固定寬度的型別，即使移植到其他CPU，意義也不會改變。uint32_t 與其他無號整數型別一樣，溢位時會成為除以 2³² 的餘數。若要讓讀寫不被省略，需在型別之外另外加上 volatile。

C語言中，(1) 在函式中沒有加 static 宣告的區域變數、(2) 以 malloc 配置的區域、(3) 在函式外宣告的變數，各自存在的期間（生命週期）的組合，下列何者正確？

  1. A(1) 到程式結束為止、(2) 到配置它的函式返回為止、(3) 到程式結束為止
  2. B(1) 到離開宣告它的區塊為止、(2) 到以 free 釋放為止、(3) 到程式結束為止
  3. C(1) 到離開宣告它的區塊為止、(2) 到程式結束為止（中途無法釋放）、(3) 到最先使用該變數的函式返回為止
查看答案與解析

正確答案：B. (1) 到離開宣告它的區塊為止、(2) 到以 free 釋放為止、(3) 到程式結束為止

(1) 的自動變數一般放在堆疊上，進入宣告它的區塊時建立，離開時消失。(2) 以 malloc 配置的區域位於堆積，函式返回後仍保留，在以 free 釋放之前都能使用。(3) 函式外的變數（以及加上 static 的變數）在程式執行期間一直存在，放在 .data 或 .bss 這類靜態區域。使用指向生命週期已結束之區域的指標，或忘了 free 而讓區域一直殘留，是常見錯誤的原因。
