什麼是QFP(四方扁平封裝)

從封裝四邊伸出彎成鷗翼型之引腳的表面黏著封裝。接點容易目視檢查，廣泛用於微控制器等。

日文名稱: QFP

「QFP(四方扁平封裝)」出現在3領域的8道練習題中（封裝與構裝, 規格書的閱讀方法, 先進技術（3D構裝與小晶片）等）。

這個名詞所屬的領域: 封裝與構裝

QFP 的結構

QFP 是 Quad Flat Package 的縮寫，是使用導線架的封裝之一。晶粒放在晶粒座上，以打線接合連接引腳並以封裝膠體覆蓋後，將伸出的引腳切齊，彎成像海鷗翅膀的形狀（鷗翼型）。引腳間距多為約 0.4 至 0.8 mm，接腳數從數十支到數百支不等。依本體厚度有不同的名稱，例如一般約 1.4 mm 的 LQFP、約 1.0 mm 的 TQFP 等。可以看作將只從兩邊伸出引腳的 SOP 擴展到四邊的形式。

優點與缺點

引腳前端與接點可從外部看到，因此容易以目視或自動光學檢查確認焊接狀態，手工修補與更換也容易。彎曲的引腳能像彈簧一樣變形，吸收熱膨脹的差異，因此在溫度循環下焊點的壽命也往往較長。另一方面，端子只能排在周邊，接腳數增加時封裝就會變大。間距縮小後引腳容易彎曲，引腳前端高度的一致性（共面度）管理與焊料橋接會成為問題。

強化散熱的 QFP

一般的 QFP 中，晶粒的熱主要經由封裝膠體與引腳散出，因此熱阻較大。功耗大的產品會使用將晶粒座露出於底面並焊接到印刷電路板的裸露焊墊品種，或在封裝內裝入散熱片的品種。在裸露焊墊下方設置散熱導通孔，將熱擴散到內層或背面的銅箔。這類品種與 QFN 一樣，需要管理焊墊部分的焊料量與空洞。

QFP、QFN 與 BGA 的選用

QFP 的引腳向外伸出，占用面積較大，引腳長度也使電感較大，但因容易檢查、實裝容易處理，長期用於微控制器與工業設備用 IC 等。QFN 將端子收在底面，做得小而薄，散熱性與高頻特性優良。BGA 在整個底面排列錫球，同樣大小下可設置的端子遠多於 QFP，是多接腳高效能晶片的主流。選用時會比較接腳數、占用面積、散熱、檢查方法與基板成本。

練習QFP(四方扁平封裝)的題目

在高腳數的QFP中，若引腳間距過窄，容易發生下列何種問題？

  1. A封裝會發光
  2. B安裝時的焊錫橋接（與相鄰引腳短路）
  3. C封裝會變重
查看答案與解析

正確答案：B. 安裝時的焊錫橋接（與相鄰引腳短路）

引腳間距狹窄時，焊接時焊料容易在相鄰引腳之間相連而造成橋接。細引腳在運輸或處理時容易彎曲，浮腳不良也會增加。0.4 mm間距左右被視為實用上的極限，需要更多端子時，會使用能在整個底面排列端子的BGA等。發光或重量變化並不會發生。

在QFP或SOP等封裝中，一般的接腳編號方式何者正確？

  1. A定位標記附近為第1腳，從上方看依順時針方向編號遞增
  2. B定位標記附近為第1腳，從上方看依逆時針方向編號遞增
  3. C放在印字可閱讀的方向時，右下為第1腳，向左編號遞增
查看答案與解析

正確答案：B. 定位標記附近為第1腳，從上方看依逆時針方向編號遞增

封裝頂面有凹點、圓點、缺口、倒角等定位標記，其附近為第1腳。一般從上方看以逆時針方向依序為第2腳、第3腳。也務必確認規格書的接腳配置圖是頂視圖（Top View）還是底視圖（Bottom View）。底視圖看起來左右相反，若弄錯會導致電路板的焊墊佈局（footprint）變成鏡像的失誤。BGA則使用以英文字母表示列、數字表示行的A1這類編號。

常見問題

QFP 和 BGA 有什麼不同？

QFP 從四邊伸出引腳，接點容易目視確認，但端子只能排在周邊。BGA 在整個底面排列錫球，可設置更多端子，但接點被遮住，因此以 X 光檢查。

QFP 和 QFN 有什麼不同？

QFP 從側面伸出鷗翼型引腳，QFN 則不伸出引腳，而是在底面露出電極。QFN 小而薄、散熱性佳；QFP 的接點容易目視檢查，實裝後也容易修補。

LQFP 和 TQFP 有什麼不同？

主要是本體厚度的不同，一般 LQFP 約 1.4 mm，TQFP 則是約 1.0 mm 的薄型品。引腳間距與接腳數依品種而異，應以外形圖確認。
