什麼是磷化氫(PH3)

磷與氫的化合物氣體。用作對矽導入n型雜質(磷)的原料。毒性非常強。

日文名稱: ホスフィン(PH3)

「磷化氫(PH3)」出現在3領域的4道練習題中（磊晶成長, 氧化與擴散, 薄膜沉積（CVD與PVD）等）。

這個名詞所屬的領域: 製程材料（氣體與藥液）

練習磷化氫(PH3)的題目

矽的磊晶成長中，用作原料的氣體為下列何者？

  1. A只有氬氣
  2. B三氯矽烷（SiHCl3）或二氯矽烷（SiH2Cl2）
  3. C氧氣
查看答案與解析

正確答案：B. 三氯矽烷（SiHCl3）或二氯矽烷（SiH2Cl2）

矽的磊晶成長會將三氯矽烷、二氯矽烷、矽烷等含矽氣體與氫氣一起使用。它們在高溫下分解、還原，使矽析出於基板上，例如發生 SiHCl3 + H2 → Si + 3HCl 的反應。含氯越多的原料所需溫度越高，但由於HCl能抑制在氧化膜上析出，因此適合選擇性成長。摻雜時則加入磷化氫或乙硼烷。

在磊晶成長過程中通入摻雜氣體，於成長的同時添加雜質，稱為什麼？

  1. A原位摻雜
  2. B離子佈植
  3. C吸附（gettering）
查看答案與解析

正確答案：A. 原位摻雜

原位摻雜是在成長的同時通入摻雜氣體（磷化氫、乙硼烷等）使雜質被納入，因此不需要像離子佈植那樣的晶體損傷與為了活化而進行的高溫退火。藉由切換氣體流量，可在深度方向做出精密的濃度分布，也能提高活化率。在先進電晶體源極・汲極的SiGe:B或Si:P磊晶層中，已實現10²¹ cm⁻³等級的高濃度。

解析中的「磷化氫(PH3)」

  • 硼使用 BBr3，氣體則使用磷化氫或乙硼烷。

    在熱擴散中將磷導入矽時，一直被用作液態擴散源的化合物是哪一個？

  • 在成膜過程中一併通入摻雜氣體（磷化氫、乙硼烷等），在形成薄膜的同時將雜質納入的方法，稱為原位（in-situ）摻雜。
