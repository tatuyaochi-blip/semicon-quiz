什麼是Verilog

廣泛用於數位電路設計與驗證的硬體描述語言。以 module 為單位撰寫電路，並以 assign 與 always 表示行為。

日文名稱: Verilog

「Verilog」出現在2領域的21道練習題中（硬體描述語言與驗證, LSI設計流程與EDA等）。

這個名詞所屬的領域: 硬體描述語言與驗證

module、assign 與 always

Verilog 設計由模組（module）構成，每個模組都是宣告了輸入與輸出埠的一塊電路。模組可以在另一個模組中依需要多次實例化，並將埠連接起來，因此晶片是以元件的階層結構來描述的。在模組內，assign y = (a & b) | c 這類連續指定描述組合邏輯，其輸出隨時跟隨輸入變化。always 區塊描述由事件觸發的行為：always @(posedge clk) 會成為邊緣觸發的正反器，而 always @(*) 會在其讀取的任何訊號改變時重新求值，用來描述組合邏輯。

以硬體而非步驟來思考

Verilog 看起來像程式語言，但每個 assign 敘述與 always 區塊都是並行運作的，與其在檔案中的順序無關。在有時脈的區塊中，非阻塞指定（<=）先以邊緣前的值計算所有右側運算式，再一起更新，對應同時擷取資料的正反器；阻塞指定（=）則適合由上而下計算中間值的組合邏輯區塊。宣告為 reg 的訊號不一定是暫存器：若在 always @(*) 中指定，它就是組合邏輯。組合邏輯區塊中沒有 else 的 if 意味著需要記憶，會推論出非預期的鎖存器（latch）。位元寬度也很重要，因為指定時會默默截斷，而且訊號除非宣告為 signed，否則都是無號數。

模擬語意與四值邏輯

Verilog 模擬器是事件驅動的：只重新求值輸入有變化的邏輯，由於每個週期只有少數訊號會切換，這種方式很有效率。訊號有四種值：0、1、代表未知的 X，以及代表高阻抗的 Z。未初始化的暫存器與相衝突的驅動會產生 X，未被驅動的線網則產生 Z，因此在波形中看到其中任何一種，都是重要的除錯線索。有些語意是樂觀的：if 敘述會把 X 條件當作 false，隱藏了實際硬體會暴露的錯誤。當運算元含有 X 或 Z 時，== 運算子會回傳 X，而 === 則按字面比較，只用於測試平台。

Verilog、SystemVerilog 與 VHDL

Verilog 只有一部分是可合成的。#10 之類的延遲、$display 與檔案 I/O 僅用於模擬，會被邏輯合成忽略，因此測試平台可以自由使用，但 RTL 不應使用。後繼標準 SystemVerilog 加入了 logic 型別，幾乎消除了 wire/reg 的區別，也加入了 always_ff 與 always_comb，用來表明設計者的意圖，讓工具能標示出被推論出的鎖存器。它還加入了斷言與類別等大量驗證功能。VHDL 是另一種主要的硬體描述語言，型別檢查更嚴格、寫法較冗長；兩者都用於 RTL 設計。

正確答案：A. HDL的描述表示的是同時並行運作的電路

HDL外觀看起來像程式，但所寫的內容會經由邏輯合成變成閘極與正反器所構成的電路。電路的各個部分隨時都在同時運作，因此多個assign語句或always區塊，無論撰寫順序為何，都會並行運作。如果像軟體一樣以「這個處理結束後再做下一個」的方式思考，就無法得到預期的電路，所以撰寫時想像會產生什麼樣的電路是很重要的。

  2. B暫時停止程式的執行
  3. C將模擬的結果顯示在畫面上
查看答案與解析

正確答案：A. 定義具有輸入與輸出端子（連接埠）的電路零件，使其能在其他module中使用

module是定義具有輸入與輸出連接埠的電路單位，可表示加法器、計數器乃至整個CPU等。定義好的module可在其他module中當作零件重複使用（實體化），並將連接埠以佈線相連，組裝成更大的電路。就像在基板上排列零件並佈線一樣，可以階層式地建構電路。

常見問題

Verilog 的 wire 和 reg 有什麼差別？

wire 由連續指定或模組輸出驅動，reg 則在 always 或 initial 區塊內被指定。reg 只有在時脈邊緣更新時才會成為正反器；在 always @(*) 中它是組合邏輯。

什麼時候用阻塞指定（=），什麼時候用非阻塞指定（<=）？

在描述正反器的時脈 always 區塊中使用非阻塞指定，在組合邏輯 always 區塊中使用阻塞指定。在同一區塊混用兩者，或在循序邏輯中使用阻塞指定，可能讓模擬結果取決於敘述順序，並與硬體不一致。

Verilog 和 SystemVerilog 有什麼差別？

SystemVerilog 是 Verilog 的超集，加入了 logic 型別、always_ff、always_comb 等設計上的便利功能，以及斷言、受限隨機激勵與物件導向測試平台等驗證功能。
