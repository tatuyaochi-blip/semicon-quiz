什麼是三態緩衝器

除了 0 與 1 之外，還可呈現輸出被切離的高阻抗狀態的緩衝器。當多個電路共用 1 條匯流排時，可防止輸出衝突。

日文名稱: トライステートバッファ

「三態緩衝器」出現在1領域的1道練習題中（邏輯電路等）。

這個名詞所屬的領域: 邏輯電路

3種輸出狀態

三態緩衝器（tri-state buffer，也寫作3-state buffer）是在把輸入直接輸出的緩衝器上，加上決定輸出是否有效之致能（enable）輸入的電路。致能有效時，依輸入輸出0或1；致能無效時，使輸出既不接電源也不接地，成為高阻抗（Hi-Z）狀態。Hi-Z並不是第3種邏輯值，而是輸出與電路切離的狀態，線路的電位由其他電路決定。致能有高態有效與低態有效的產品，電路圖中以三角形緩衝器符號，並在其側邊畫出致能輸入來表示。

電路的構成

CMOS三態緩衝器的輸出級由電源側的pMOS與接地側的nMOS構成，形狀與反相器相同。致能有效時，依輸入只讓其中一個導通；致能無效時，兩者都截止，使輸出不接到任何地方。代表性的構成，是以輸入資料與致能的NAND閘產生pMOS的閘極訊號，以輸入資料與反相致能的NOR閘產生nMOS的閘極訊號。也有將pMOS與nMOS各2個串聯堆疊，一組由致能控制、另一組由資料控制的構成，這種構成的輸出是反相的。

在匯流排上的用法與注意事項

三態緩衝器的主要用途，是讓多個電路共用1條匯流排。任何時刻只讓1個電路有效，其他維持Hi-Z，訊號就不會衝突。若同時有2個有效並輸出相反的值，就會發生從電源到地流過大電流的匯流排衝突，造成誤動作或元件劣化。反之，若全部都是Hi-Z，線路的電位會不確定（浮接），可能使接收端的輸入電路流過貫通電流或拾取雜訊，因此要以上拉或下拉電阻、匯流排保持電路來維持數值。

雙向端子與晶片內部的處理

微控制器或FPGA的通用輸入輸出（GPIO）端子、記憶體資料線這類雙向端子，是把輸出用的三態緩衝器與輸入緩衝器接在同一個端子上的構成。輸出時讓緩衝器有效，作為輸入使用時則設為Hi-Z，接收外部的訊號。74HC245這類匯流排用的雙向IC，內部也具有這種構成。另一方面，晶片內部的訊號有衝突與浮接的風險，時序分析也會變得困難，因此一般以多工器選擇訊號，取代三態匯流排。在HDL中，以對輸出指定Z來描述三態。

練習三態緩衝器的題目

三態緩衝器的輸出可呈現的第3種狀態是哪一個？

  1. A輸出電源電壓一半的電壓的狀態
  2. B高速反覆0與1的狀態
  3. C將輸出切離而成為高阻抗的狀態
查看答案與解析

正確答案：C. 將輸出切離而成為高阻抗的狀態

三態緩衝器除了0與1之外，還能呈現將輸出切離的高阻抗（Hi-Z）狀態。當多個電路共用1條匯流排時，將不使用的電路設為Hi-Z以避免訊號衝突，也用於雙向的輸入輸出端子。若同時有2個輸出，會因匯流排衝突而流過大電流，因此控制訊號的管理很重要。若全部都是Hi-Z，線路的電位就不確定，因此要以上拉等方式固定其值。

常見問題

三態緩衝器是什麼？

是除了0與1之外，還能呈現把輸出切離之高阻抗（Hi-Z）狀態的緩衝器。以致能輸入切換輸出的有效與無效，在多個電路共用1條匯流排時防止輸出衝突。

三態緩衝器的電路是什麼樣子？

輸出級是電源側的pMOS與接地側的nMOS，致能有效時依輸入讓其中一個導通，致能無效時兩者都截止，使輸出切離。閘極訊號以NAND閘與NOR閘產生，是代表性的構成。

高阻抗（Hi-Z）和0一樣嗎？

不一樣。Hi-Z是輸出既不接電源也不接地的狀態，線路的電位由其他電路或上拉、下拉電阻決定。若沒有任何電路驅動，電位就不確定。
