什麼是HEPA濾網

可捕集99.97%以上粒徑0.3 µm微粒的高性能空氣濾網。能捕集更微細粒子的則是ULPA濾網。

日文名稱: HEPAフィルタ

「HEPA濾網」出現在1領域的4道練習題中（無塵室與製造設備等）。

這個名詞所屬的領域: 無塵室與製造設備

練習HEPA濾網的題目

下列關於HEPA濾網性能的一般定義，何者正確？

  1. A捕集粒徑0.3 µm的粒子達99.97%以上
  2. B捕集粒徑10 µm的粒子達50%以上
  3. C去除氣態分子達99.99%以上
查看答案與解析

正確答案：A. 捕集粒徑0.3 µm的粒子達99.97%以上

HEPA濾網的定義為：對接近最難過濾粒徑的0.3 µm左右的粒子，具有99.97%以上捕集效率的濾網（JIS等）。比這更大的粒子因慣性，更小的粒子則因布朗運動造成的擴散，容易被纖維捕捉，所以中間大小的粒子最容易穿透。性能更高的ULPA濾網，在0.15 µm時為99.9995%以上。兩者都無法去除氣體。

解析中的「HEPA濾網」

  • HEPA濾網的定義為：對接近最難過濾粒徑的0.3 µm左右的粒子，具有99.97%以上捕集效率的濾網（JIS等）。

    下列關於HEPA濾網性能的一般定義，何者正確？

  • HEPA濾網以及性能更高的ULPA濾網，是以折疊的細玻璃纖維等濾材捕捉空氣中微粒的空氣濾網，安裝在潔淨室的天花板等處。

    用來去除潔淨室空氣中微粒的高效率濾網是下列何者？

  • 玻璃纖維HEPA濾網中有使用硼矽玻璃的類型，與氫氟酸蒸氣等反應後，可能釋出含硼的氣體。

    從玻璃纖維濾網等釋出，可能造成晶圓非預期摻雜（污染）的元素是下列何者？

  • ULPA與HEPA濾網雖然能捕捉粒子，但氣態分子會穿過去。

    用來從潔淨室空氣中去除氨或有機物等分子態污染（AMC）的濾網是下列何者？

出現「HEPA濾網」的題目（4題）

  1. 下列關於HEPA濾網性能的一般定義，何者正確？
  2. 用來去除潔淨室空氣中微粒的高效率濾網是下列何者？
  3. 從玻璃纖維濾網等釋出，可能造成晶圓非預期摻雜（污染）的元素是下列何者？
  4. 用來從潔淨室空氣中去除氨或有機物等分子態污染（AMC）的濾網是下列何者？
