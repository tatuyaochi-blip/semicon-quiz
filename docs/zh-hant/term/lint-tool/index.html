什麼是Lint 檢查工具（Lint tool）

不經模擬，依規則檢查 HDL 等的描述，找出位元寬度不一致或非預期閂鎖等容易出問題寫法的工具。

日文名稱: Lint

「Lint 檢查工具（Lint tool）」出現在1領域的3道練習題中（硬體描述語言與驗證等）。

練習Lint 檢查工具（Lint tool）的題目

HDL驗證中所使用的Lint工具的作用，下列何者正確？

  1. A從晶片上去除電路的垃圾（棉絮）的裝置
  2. B將模擬波形漂亮地顯示的工具
  3. C不做模擬就檢查描述，找出位元寬度不一致、非預期的閂鎖器、無法合成的寫法等問題
查看答案與解析

正確答案：C. 不做模擬就檢查描述，找出位元寬度不一致、非預期的閂鎖器、無法合成的寫法等問題

Lint工具依照規則對HDL的描述進行靜態檢查，指出文法上雖然正確但容易出問題的寫法。例如寬度不同的訊號賦值、敏感度清單的遺漏、閂鎖器的推論、阻塞與非阻塞的混用、時脈處理的錯誤等。因為不必製作測試就能執行，所以若從設計的早期階段開始使用，可以減少後續驗證的工夫。
