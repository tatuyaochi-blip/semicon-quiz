什麼是進位保留加法器

將三個數在不傳遞進位的情況下，彙整成「和」與「進位」兩個數的加法器。只是逐位排列全加器，延遲固定，因此用於乘法器中加總大量部分積。

日文名稱: 桁上げ保存加算器

「進位保留加法器」出現在1領域的2道練習題中（電腦算術等）。

這個名詞所屬的領域: 電腦算術

將三個數合併為兩個的機制

進位保留加法器（CSA）是在每個位元各獨立放置一個全加器的電路。把三個數A、B、C同一位元的位元送入全加器，將各位元的和位元集合成數S，並將進位位元集合後左移1位成為數Cy，就會成立 A + B + C = S + Cy。例如4位元的5（0101）、6（0110）、7（0111），得到 S = 0100（4）、Cy = 1110（14），而 4 + 14 = 18 = 5 + 6 + 7。由於不把進位傳給相鄰位元，延遲與位元數無關，固定為1級全加器的時間。

與漣波進位加法器的差異

一般的加法器（漣波進位加法器）中，每個位元的結果都要等待來自低位的進位，最壞情況下進位要從最低位傳到最高位，延遲與位元數成正比。即使以先行進位加法器等加速，延遲仍會隨位元數的對數增加。進位保留加法器只是把進位「保留」下來交給下一級，因此不論相加多少個數，中間的加法都不必等待進位傳遞。代價是結果成為分成和與進位兩個數的冗餘形式，最後必須以一般加法器相加一次，才能得到單一的數。

在乘法器中的用法

n位元乘法會產生n個部分積，若依序相加會很慢。因此把進位保留加法器排成樹狀，在每一級平行地將三個數合併為兩個。每一級的數量約減為三分之二，所以減到兩個所需的級數大約只與位元數的對數成正比。這就是華里士樹（Wallace tree）；另有改良全加器用法以減少電路的Dadda樹。將四個數合併為兩個的4:2壓縮器也很常用。最後以先行進位加法器等高速加法器把剩下的兩個數相加，乘積即完成。一般也常與以布斯演算法減少部分積數量的方法搭配使用。

其他用途與注意事項

進位保留形式可用於所有持續加總大量數值的處理。乘積累加器（MAC）有時會把累加值維持在和與進位兩個數的形式，以省去每個週期的進位傳遞。密碼學中大整數的蒙哥馬利乘法，以及除法、平方根的計算，也會以冗餘形式保存中間值來加速。不過在冗餘形式下，無法立即判斷數值大小、符號與溢位，保存數值的暫存器也需要約2倍的位元數。因此在需要判斷時，會以一般加法器轉回單一的數。

練習進位保留加法器的題目

在乘法器中，加總大量部分積時會使用進位保留加法器，其主要理由為下列何者？

  1. A因為進位保留加法器能從一開始就將部分積的數量減為1個
  2. B因為進位保留加法器能不用加法就完成乘法
  3. C因為不傳遞進位即可將3個數合併為2個，且延遲固定
查看答案與解析

正確答案：C. 因為不傳遞進位即可將3個數合併為2個，且延遲固定

若以一般加法器逐一加總部分積，每次都必須等待進位由低位傳往高位。進位保留加法器是將全加器依各位數獨立排列而成，只是把3個數合併為「各位數的和」與「各位數的進位」這2個數，因此不必等待進位的傳遞，延遲固定為1級全加器的時間。重複此操作可將部分積減為2個，最後只要以超前進位加法器等相加1次即可。部分積無法一下子減為1個。

常見問題

進位保留加法器是什麼？

是在不傳遞進位的情況下，將三個數合併為「和」與「進位」兩個數的加法器。它只是逐位排列全加器，延遲固定，因此用於乘法器中加總大量部分積。

進位保留加法器和漣波進位加法器有什麼不同？

漣波進位加法器將兩個數相加得到一個結果，但進位要從低位依序傳到高位，延遲與位元數成正比。進位保留加法器只把三個數合併為兩個，不傳遞進位，因此延遲與位元數無關、固定不變。

為什麼只靠進位保留加法器無法完成加法？

因為輸出分成和與進位兩個數。要當作單一數值使用，最後必須以會傳遞進位的一般加法器把兩者相加。即使是加總大量數值，這個最後的加法也只需要一次。
