什麼是真亂數產生器（True random number generator, TRNG）

以熱雜訊或振盪器抖動等無法預測的物理現象為基礎產生亂數的電路。TRNG。是密碼金鑰產生的來源。

日文名稱: 真性乱数生成器

「真亂數產生器（True random number generator, TRNG）」出現在1領域的1道練習題中（硬體安全等）。

這個名詞所屬的領域: 硬體安全

與偽亂數的差異

電腦一般使用的偽亂數產生器，是從稱為種子（seed）的初始值以固定的運算產生數列，種子相同就會得到相同的數列。用於密碼金鑰或nonce的亂數，最重要的是不能被攻擊者猜到，因此種子本身必須是無法預測的值。真亂數產生器（TRNG）是從熱雜訊或振盪器週期的抖動等物理上無法預測的現象產生亂數位元的電路，也就是這種不可預測性的來源。內建於晶片中的稱為硬體TRNG，許多微控制器、SoC與安全晶片都有搭載。

熵源的例子

不可預測性的來源稱為熵源（entropy source）。晶片內建的方式中常見的，是以另一個時脈取樣自由振盪的環形振盪器輸出，從週期微小抖動（jitter）的累積中取出位元。其他還有放大電阻的熱雜訊、以比較器轉成0與1的方式，以及讓栓鎖器從不穩定狀態釋放、利用其最後穩定到哪一邊的方式等。在獨立元件中，也有利用二極體崩潰雜訊，或光子偵測這類量子現象的亂數源。無論哪種方式，估計所得位元實際含有多少不可預測性，都是設計的關鍵。

後處理與健康測試

直接從物理現象取出的位元，可能0與1的比例不均，或前後位元之間有相關性。因此會以雜湊函數等壓縮大量位元，提高每個位元的不可預測性（調節，conditioning）。實際產品一般會把這樣得到的值，作為密碼用確定性亂數位元產生器（DRBG）的種子，以快速產生大量亂數。此外還會內建健康測試，持續檢查同一個值是否連續出現過多、特定值的比例是否過高，雜訊源故障時就停止輸出。美國NIST的SP 800-90系列與德國聯邦資訊安全局的AIS 31，規定了評估的思考方式。

攻擊與設計上的注意事項

TRNG輸出的性質會隨溫度、電源電壓、製造變異與老化而改變。若攻擊者在電源上加入雜訊，或從外部施加電磁波使環形振盪器的頻率被牽引鎖定，抖動可能減少，輸出就可能變得容易預測。即使經過後處理後的輸出看起來是隨機的，若原本的熵不足，仍不安全。因此設計時會結合最差條件下的熵估計、啟動時與運作中的健康測試，以及異常時停止輸出的機制。通過統計亂數檢定是必要的，但單憑這一點並不能證明輸出無法預測。

正確答案：B. 以熱雜訊、振盪器的抖動等無法預測的物理現象為基礎來產生亂數的電路

偽亂數只要知道種子就能重新產生相同的序列，所以種子一旦被推測，金鑰也會被推測出來。真亂數產生器以電阻的熱雜訊、環形振盪器週期的抖動等無法預測的物理現象為基礎產生位元。實際上，多半是以TRNG的輸出產生密碼用偽亂數產生器的種子，兼顧速度與不可預測性。

常見問題

TRNG是什麼的縮寫？

是True Random Number Generator的縮寫，中文稱為真亂數產生器。這是以熱雜訊、振盪器抖動等物理現象為基礎產生亂數的電路，用於產生密碼金鑰與偽亂數產生器的種子。

為什麼不直接把TRNG的輸出當作金鑰？

因為原始位元常有偏差與相關性，每個位元所含的不可預測性往往不到1位元。因此一般會先以後處理加以壓縮，再作為密碼用確定性亂數位元產生器（DRBG）的種子。經由DRBG，就能快速產生大量亂數。

CPU裡也有TRNG嗎？

許多CPU與SoC都有。例如x86 CPU有讀取硬體亂數的RDRAND指令，以及讀取作為種子之值的RDSEED指令；Armv8.5-A也新增了RNDR等指令。作業系統會把這些亂數源與其他資訊來源結合，作為亂數的種子。
