什麼是頻率解析度

在頻譜分析中，能把頻率相近的兩個成分分辨為不同成分的精細程度。在DFT中以頻率點的間隔 Δf = fs/N 為參考，它等於觀測時間 T = N/fs 的倒數 1/T。例如 fs = 48 kHz、N = 1024 時約為46.9 Hz。實際能否分辨也取決於窗函數的主瓣寬度。補零只是使頻率點的間隔變細、對頻譜做內插，分辨能力仍由觀測時間決定。這與AD轉換器的解析度（位元數）意義不同。

日文名稱: 周波数分解能

「頻率解析度」出現在1領域的1道練習題中（數位訊號處理基礎等）。

練習頻率解析度的題目

在256點訊號之後補上768個0（補零），計算1024點的DFT。與直接以256點計算DFT相比，下列敘述何者正確？

  1. A頻譜以更細的間隔被內插，但分辨兩個頻率相近的正弦波的能力不變
  2. B頻率點間隔變成4分之1，分辨兩個頻率相近的正弦波的能力也提高為4倍
  3. C補上的0使區間的兩端平滑相接，因此頻譜洩漏消失，峰值的高度也能正確讀取
查看答案與解析

正確答案：A. 頻譜以更細的間隔被內插，但分辨兩個頻率相近的正弦波的能力不變

補零後頻率點間隔變細為 fs/1024，得到在256點頻譜之間內插的值。但沒有加入新的資訊，因此分辨兩個頻率的能力（頻率解析度）取決於實際觀測的256個取樣點的長度，仍約為 fs/256。要真正提高分辨能力，必須取得更長時間的資料。補零用於讓峰值的位置更容易讀取，或為了FFT把點數湊成2的冪次。
