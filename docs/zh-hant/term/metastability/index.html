什麼是亞穩態

正反器未遵守設定時間或保持時間時，輸出在一段時間內既不是 0 也不是 1 而無法確定的狀態。對於非同步訊號，以兩級正反器同步化來因應。

日文名稱: メタステーブル

「亞穩態」出現在3領域的10道練習題中（時序分析與CDC, 邏輯電路, LSI設計流程與EDA等）。

這個名詞所屬的領域: 邏輯電路

為什麼正反器會卡在 0 與 1 之間

正反器以交叉耦合的反相器儲存狀態，這種結構有兩個穩定點，以及介於兩者之間的一個不穩定平衡點。若資料輸入在由建立時間（時脈邊緣之前）與保持時間（時脈邊緣之後）定義的時窗內變化，閂鎖器就可能停留在該平衡點附近。正回授接著以時間常數 τ 放大微小的不平衡，但起始點越接近平衡，判定所需的時間就越長，而且沒有明確的上限。輸出可能停在中間電壓或延遲切換，最終值也無法預測。

同步器與 MTBF

對於非同步輸入，亞穩態只能變得罕見，而無法避免。雙正反器同步器讓第一級在第二級取樣之前，有將近一個時脈週期的時間來脫離亞穩態。平均故障間隔時間約為 MTBF = e^(t_r/τ) / (T_0 × f_clk × f_data)，其中 t_r 是可用的判定時間，τ 與 T_0 取決於正反器。由於 t_r 位於指數中，增加第三級可多出約一個週期，使 MTBF 大幅增加：當 τ = 20 ps 時，多出 1 ns 就能帶來 e^50 倍，超過 10^21。

同步器解決不了的問題

每個同步後的位元都可能提早或延遲一個週期擷取到變化，因此像 0111 變成 1000 這樣的多位元值，可能會以 1111 或 0000 的形式到達。因此計數器以格雷碼跨越時脈域，每一步只有一個位元改變，非同步 FIFO 的指標就是如此；任意資料則使用交握或非同步 FIFO。來自快速時脈域的短脈衝可能落在慢速時脈的兩個邊緣之間而消失，因此必須加以延展或轉換為切換訊號。跨越時脈域的訊號應直接來自正反器，因為組合邏輯的突波可能被當作有效值擷取。

亞穩態與一般時序違規

在單一同步時脈域中，建立時間違規代表資料路徑太慢，靜態時序分析可以找出來；降低時脈或加快路徑即可修正。在非同步時脈之間則沒有固定的相位關係，因此無論邏輯多快，違規終究會發生，時序分析也無法收斂。這就是設計要仰賴 CDC（時脈域跨越）驗證的原因：工具會找出每一個跨越點，檢查是否有適當的同步器、格雷碼指標或交握。這類錯誤很少發生，因此一般模擬很少能抓到。

練習亞穩態的題目

將2級正反器的同步器增加為3級時，因亞穩態造成之故障的平均間隔（MTBF）如何變化，下列何者正確？

  1. A亞穩態穩定下來可用的時間約增加1個週期，MTBF呈指數性延長
  2. B與級數成正比，MTBF變為1.5倍
  3. C亞穩態發生的難易度由輸入端決定，因此MTBF不變
查看答案與解析

正確答案：A. 亞穩態穩定下來可用的時間約增加1個週期，MTBF呈指數性延長

同步器的MTBF大致可表示為 MTBF = e^(t_r/τ) ÷ (T_0 × f_clk × f_data)。t_r 是亞穩態穩定下來可用的時間，τ 與 T_0 是由正反器特性決定的常數。每增加1級，t_r 約延長1個週期（精確來說是1個週期減去正反器的輸出延遲與建立時間）。例如 τ = 20 ps 時，若 t_r 增加 1 ns，MTBF會延長為 e^50 倍，也就是10的21次方倍以上。第1級成為亞穩態的機率不變，但在傳到下一級之前穩定下來的機率會大幅提高。

常見問題

正反器的亞穩態是什麼原因造成的？

資料在時脈邊緣前後的建立與保持時窗內變化，使內部閂鎖器停留在不穩定平衡點附近。當輸入與時脈非同步時，這是無法避免的。

為什麼非同步訊號要用兩個正反器同步？

第一個正反器可能進入亞穩態，第二個正反器在整整一個時脈週期後才取樣，此時它幾乎一定已經穩定。這能使 MTBF 呈指數增加，但無法讓失效完全不可能發生。

多位元匯流排可以用同步器處理嗎？

不能逐位元處理，因為不同位元可能在不同週期被擷取，產生無效的中間值。計數器請使用格雷碼，一般資料則使用交握或非同步 FIFO。
