什麼是窗函數

在DFT分析與FIR濾波器設計中，乘在訊號或係數的有限區間上的權重函數。只以區間截取（方形窗）時兩端不連續，會產生頻譜洩漏或漣波，因此乘上使兩端平滑趨近於0的窗來抑制。代表性的漢寧窗（Hann窗）最大旁瓣約為 −31 dB，低於方形窗的約 −13 dB，但主瓣寬度約為方形窗的2倍。依重視旁瓣低還是主瓣窄，選用漢明窗、布萊克曼窗、平頂窗等。

日文名稱: 窓関数

「窗函數」出現在1領域的2道練習題中（數位訊號處理基礎等）。

這個名詞所屬的領域: 數位訊號處理基礎

主瓣與旁瓣

窗的頻譜由中央的大峰（主瓣）與其兩側的小峰（旁瓣）構成。主瓣越窄，越容易分辨頻率相近的兩個成分；旁瓣越低，強成分附近的弱成分越不容易被淹沒。兩者有取捨關係，方形窗的主瓣最窄但旁瓣高，漢寧窗則相反。

振幅的讀取與修正

乘上窗後訊號的振幅平均會變小，因此讀取振幅時要除以窗的平均值（漢寧窗為0.5）來修正。此外，頻率位於頻率點中間時振幅會被讀小（扇形損失），其量在方形窗約3.9 dB，漢寧窗約1.4 dB。要準確量測振幅時，使用主瓣頂端平坦的平頂窗。

FIR濾波器設計中的窗

理想低通濾波器的脈衝響應（sinc函數）無限延續，因此必須以有限的抽頭數截取。單純截取會在通帶與阻帶產生漣波（吉布斯現象），但先乘上窗函數再使用，可得到抑制漣波的特性。窗的種類會改變阻帶衰減量與過渡頻帶寬度之間的平衡。

練習窗函數的題目

關於DFT之前所乘的窗函數，比較方形窗（不乘任何窗）與漢寧窗（Hann窗）的敘述，下列何者正確？

  1. A漢寧窗的主瓣寬度約為方形窗的一半，旁瓣也較低，因此在各方面都優於方形窗
  2. B漢寧窗的旁瓣較低，往遠處頻率點的洩漏較小，但主瓣寬度約為方形窗的2倍
  3. C漢寧窗的主瓣變窄，但相對地旁瓣比方形窗高
查看答案與解析

正確答案：B. 漢寧窗的旁瓣較低，往遠處頻率點的洩漏較小，但主瓣寬度約為方形窗的2倍

方形窗的主瓣寬度（到第一個零點）為 ±1 個頻率點，較窄；但最大的旁瓣約為 −13 dB，較高，洩漏會擴散到遠處的頻率點。漢寧窗讓區間的兩端平滑地變成0，最大旁瓣降到約 −31 dB，但主瓣寬度為 ±2 個頻率點，約為2倍。要觀察強訊號附近的弱訊號時適合漢寧窗這類窗函數，要分辨頻率相近且強度相當的訊號時適合方形窗，須依目的選用。

常見問題

什麼時候需要窗函數？

無法保證量測訊號的週期以整數個落在觀測區間內時，通常會乘上窗函數。週期恰好與區間吻合，或是在區間內完全衰減的暫態訊號，即使用方形窗（不加窗），洩漏也不會造成問題。

漢寧窗與漢明窗有什麼不同？

兩者都是餘弦形狀的窗，但漢寧窗兩端恰好為0，遠處的旁瓣衰減得快。漢明窗兩端不為0而保留約0.08，使最高的旁瓣降到約 −43 dB，但遠處旁瓣的衰減較慢。

解析中的「窗函數」
