什麼是IEEE 754

規定浮點數表示方式與運算規則的國際標準。規定單精度(32位元)、雙精度(64位元)等格式、捨入方法，以及無限大與NaN等特殊值，使計算結果不因電腦而異。

日文名稱: IEEE 754

「IEEE 754」出現在1領域的14道練習題中（電腦算術等）。

這個名詞所屬的領域: 電腦算術

位元如何編碼數值

二進位 IEEE 754 數值儲存一個符號位元、一個偏移後的指數欄位與一個小數部分，對正規數而言代表 (−1)^sign × 1.fraction × 2^(exponent − bias)。單精度（FP32）使用 1、8、23 位元，偏移值為 127；雙精度（FP64）使用 1、11、52 位元，偏移值為 1023。開頭的 1 是隱含的（隱藏位元），因此精度分別為 24 與 53 位元，約相當於 7 位與 15–16 位十進位數字。例如 1.0 的儲存指數為 127、小數部分全為 0，在 FP32 中為 0x3F800000。

特殊值與例外

指數的兩個極端編碼是保留的。指數全為 0 時編碼 ±0 與次正規數；次正規數捨去隱藏的 1，以等間距的微小數值填補最小正規數以下的空隙（漸進式下溢）。指數全為 1 時，小數部分為 0 表示 ±無限大，否則表示 NaN（非數值）。非零數除以零得到無限大，而 0 ÷ 0 或 ∞ − ∞ 則得到 NaN，NaN 即使與自己比較也不相等。+0 與 −0 比較時相等，但作為除數時會得到正負相反的無限大。預設情況下，這些事件只會設定狀態旗標，而不會中止程式。

捨入與精度限制

包括加法、乘法、除法與平方根在內的基本運算都必須正確捨入：結果等於將精確值捨入到某個可表示數值。預設模式為捨入到最接近值、同距時取偶數，可避免系統性地往上偏移。機器 epsilon（1.0 以上的間距）在 FP32 中為 2⁻²³（約 1.19 × 10⁻⁷），在 FP64 中為 2⁻⁵²，而整數分別只在 2²⁴ 與 2⁵³ 以內才能全部精確表示。0.1 這類十進位小數無法精確表示，且浮點加法不滿足結合律，因此結果應以容許誤差進行比較。

浮點數與定點數

定點數的數值等間距分布，因此絕對誤差固定，範圍也狹窄。浮點數則在極大的範圍內（FP64 約為 10⁻³⁰⁸ 至 10³⁰⁸）讓相對誤差大致維持固定，代價是對齊、正規化與捨入需要更複雜的硬體。該標準也定義了具有 5 位元指數的半精度，以及只捨入一次的融合乘加運算。機器學習硬體常使用 bfloat16，它保留 FP32 的 8 位元指數並搭配 7 位元小數部分；它沿用相同的編碼概念，但並不是該標準的格式之一。

練習IEEE 754的題目

  1. A符號、指數部分、尾數
  2. B整數部分、小數部分、進位
  3. C高位元組、低位元組、同位元
查看答案與解析

正確答案：A. 符號、指數部分、尾數

浮點數以「(−1)^符號 × 1.尾數 × 2^指數」的形式表示值，並以3個部分記錄：表示正負的符號位元、表示2的幾次方的指數部分，以及表示有效數字的尾數。由於可藉由指數移動小數點的位置，因此以相同的位元數就能表示從極小到極大的數。分成整數部分與小數部分是定點數的概念，同位元則是用於偵測錯誤的位元。

在IEEE 754的單精度（32位元）浮點數中，分配給符號、指數部分、尾數的位元數組合為下列何者？

  1. A1・11・20
  2. B1・8・23
  3. C1・5・26
查看答案與解析

正確答案：B. 1・8・23

單精度（FP32）由符號1位元、指數部分8位元、尾數23位元，共32位元構成。在正規化數中會省略尾數開頭的1，因此精度相當於24位元，換算成十進位約為7位數。雙精度（FP64）為符號1、指數部分11、尾數52位元，指數範圍較廣，精度也較高。1・11・20是與雙精度的指數部分寬度混淆的組合，1・5・26則是與半精度的指數部分寬度混淆。

常見問題

浮點數中 0.1 + 0.2 為什麼不等於 0.3？

這幾個十進位數值都沒有精確的二進位表示，因此各自都是捨入後儲存，而捨入誤差不會互相抵銷。在雙精度下，總和為 0.30000000000000004，因此相等判斷應使用容許誤差。

IEEE 754 單精度的指數偏移值是多少？

偏移值為 127，因此真正的指數等於儲存的 8 位元值減去 127。儲存值 0 與 255 保留給零、次正規數、無限大與 NaN，正規數使用 1–254。

NaN 為什麼不等於自己？

IEEE 754 把所有涉及 NaN 的比較都定義為無序，因此當 x 為 NaN 時，x == x 為假。應使用 isnan 等專用函式，而不要依賴這個技巧。
