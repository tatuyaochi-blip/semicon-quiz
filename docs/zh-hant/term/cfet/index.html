什麼是CFET(互補式場效電晶體)

將nMOS與pMOS電晶體垂直堆疊的結構。可大幅縮小CMOS電路的面積，因此持續進行開發。

日文名稱: CFET(相補型FET)

「CFET(互補式場效電晶體)」出現在1領域的4道練習題中（先進電晶體（FinFET與GAA）等）。

這個名詞所屬的領域: 先進電晶體（FinFET與GAA）

CFET 如何堆疊 CMOS 電晶體對

在傳統 CMOS 中，每個邏輯閘都將 nMOS 與 pMOS 電晶體並排放置，因此標準元件必須容納兩者的佔用面積以及兩者之間的間距。互補式場效電晶體（CFET）則將一個元件直接建構在另一個元件上方，通常是 nMOS 奈米片堆疊位於 pMOS 奈米片堆疊的上方或下方，並由一個垂直穿過兩者的共用閘極控制。由於反相器的兩個電晶體共用相同的輸入與輸出，將它們摺疊成一個垂直堆疊，就能以接近一半的面積實現相同功能。

CFET 為何難以製造

上下兩層需要不同的閘極功函數金屬與不同的源極／汲極磊晶，例如 p 型元件用摻硼 SiGe、n 型元件用摻磷矽，而這些全部都要在一個高聳的結構內形成。目前研究的路線大致有兩種：單晶片整合（monolithic），以一個連續流程同時圖案化兩層；以及循序整合（sequential），在完成的下層上方接合一層材料，再於其上建構上層。無論哪一種，熱預算、上下層之間的對準以及兩層之間的電性隔離都是主要難題。

GAA、叉型片與 CFET 的比較

環繞式閘極（GAA）奈米片電晶體以閘極完全包覆堆疊的水平片，但 n 型與 p 型元件仍然並排，通常相距數十奈米。叉型片（forksheet）FET 在 n 型與 p 型奈米片之間插入厚約十幾奈米的介電牆，使兩者能靠得更近，代價是閘極只能從三面包覆每一片。CFET 則將一個元件移到另一個上方，完全消除了 n 型與 p 型之間的橫向間距，因此通常被視為 GAA 與叉型片之後的下一步。

配線成為瓶頸

電晶體一旦堆疊起來，難點就在於如何連接它們。通往下層元件的接點必須從上層元件旁邊穿過而不與之短路，而且兩層都需要在縮小後的元件中取得電源與訊號連接。這就是 CFET 常與背面供電一起討論的原因：背面供電可從下方為下層供電，正面配線則負責訊號。開發目標是在 2030 年代實用化，而配線方案對成敗的影響與電晶體本身同樣重要。

CFET（互補式場效電晶體）是將nMOS與pMOS上下堆疊以縮小元件面積的結構。上下的閘極與輸出可以共用，但各自的源極必須接到不同的電源（VDD與VSS）。從正面連接下層，必須避開上層電晶體把接點拉深，使狹小元件內的配線擁擠。因此正在研究從晶圓背面直接連接下層、並與背面供電結合的方式；在2023年的IEDM上，英特爾報告了從背面直接連接下層之CFET反相器的運作。

常見問題

CFET 是什麼的縮寫？

CFET 是 complementary field-effect transistor（互補式場效電晶體）的縮寫，指將 CMOS 電路中的 nMOS 與 pMOS 電晶體垂直堆疊、而非並排放置的結構。

CFET 和 GAA 有什麼不同？

GAA 奈米片電晶體描述的是閘極如何包圍通道，n 型與 p 型元件仍彼此相鄰。CFET 保留奈米片式通道，但將 n 型與 p 型元件上下堆疊，以縮小元件佔用面積。

為什麼 CFET 能讓元件面積減少將近一半？

在 CMOS 閘中，nMOS 與 pMOS 共用輸入與輸出，因此大部分面積都用於並排放置兩個元件及其間距。將兩者上下堆疊可消除這種橫向重複，每一對 n-p 元件大約只需一個元件的佔用面積。
