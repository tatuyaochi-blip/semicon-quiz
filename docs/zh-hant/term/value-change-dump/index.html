什麼是VCD（值變更傾印）

Value Change Dump 的縮寫。記錄模擬過程中訊號值變化的標準檔案格式，可用波形顯示工具檢視並用於除錯。

VCD記錄的內容

VCD（Value Change Dump，值變更傾印）是在邏輯模擬期間，記錄各訊號的值於何時、如何改變的文字格式檔案。它是Verilog的IEEE 1364標準所定義的格式，多數模擬器都能輸出，可用GTKWave等波形顯示工具開啟並用於除錯。由於只記錄值改變的時刻與新值，比每個時脈寫下所有值要小。值以0、1、x（未知）、z（高阻抗）四種狀態表示，多位元訊號則整合成向量記錄。

檔案的結構

VCD檔案由前半的標頭與後半的值變化序列組成。標頭寫入建立日期（$date）、時間單位（$timescale）、模組階層（$scope、$upscope）與訊號定義（$var），並以$enddefinitions結束。$var會為各訊號分配「!」或「%」等簡短的識別符號。後半先寫出「#100」這樣的時刻，再以值與識別符號列出該時刻改變的訊號，例如「1!」（1位元）或「b1010 %」（向量）。格式簡單，自行撰寫的腳本也能讀寫。

在Verilog中的輸出方法與注意事項

在Verilog中，於測試平台內以$dumpfile指定輸出的檔名，以$dumpvars指定要記錄的範圍。$dumpvars(0, top)會記錄top模組以下所有階層的訊號。以$dumpoff與$dumpon可以暫停或恢復記錄，只保留想調查的時間區間。由於VCD是文字格式，長時間記錄大型電路的所有訊號，檔案會變得非常大，寫出檔案也會拖慢模擬。因此會縮小記錄的階層或期間，或改用經過壓縮的其他格式。

與其他波形格式及SAIF的差異

VCD是標準所定義的通用格式，因此方便在不同公司的模擬器與波形顯示工具之間傳遞資料。另一方面，大型設計常使用經過壓縮、讀取較快的專有格式（FST、FSDB、WLF等）。此外，從VCD的值變化計算訊號的轉換次數，也能用於功耗分析。只彙整轉換次數等資訊的SAIF格式比VCD小，常用於功耗估算。另外，IEEE 1364-2001也定義了額外記錄埠方向與訊號強度的擴充VCD。

正確答案：A. 以波形顯示工具查看訊號值隨時間的變化，調查缺陷的原因

VCD（Value Change Dump）是記錄模擬期間各訊號的值何時、如何改變的標準檔案格式。以波形顯示工具開啟後，可以沿著時間軸看到每個時脈訊號的變化，因此能追查在哪裡出現了與期望不同的值。記錄所有訊號會使檔案變得非常大，因此有時也會將範圍縮小到想調查的區間或訊號。

常見問題

要用什麼檢視VCD檔案？

以GTKWave等波形顯示工具開啟，就能把訊號的變化看成沿時間軸的波形。模擬器附帶的波形顯示工具多半也能讀入VCD。內容是文字，也可以直接用編輯器確認。

VCD檔案太大時該怎麼辦？

以$dumpvars縮小記錄的階層，或以$dumpoff與$dumpon限制記錄的期間，藉此減少資料。若模擬器支援，以FST或FSDB等壓縮格式輸出，檔案會變小，讀取也更快。

VCD與SAIF有什麼不同？

VCD會依時刻記錄各訊號的值於何時、如何改變的所有資訊。SAIF則只彙整每個訊號的轉換次數，以及處於0或1的時間長度等，雖然無法重現波形，但檔案小，適合功耗分析。
