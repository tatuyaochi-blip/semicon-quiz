什麼是PSRR(電源電壓變動拒斥比)

表示電源電壓的變動有多難傳遞到電路輸出的指標。越大，越能抵抗電源雜訊。

日文名稱: PSRR(電源電圧変動除去比)

「PSRR(電源電壓變動拒斥比)」出現在2領域的2道練習題中（規格書的閱讀方法, 類比與電子電路等）。

這個名詞所屬的領域: 類比與電子電路

PSRR 的定義

PSRR 比較電源軌上的變化與其在電路輸出端所造成的變化，由於它是電壓比，因此以 20 log₁₀ 換算成分貝表示。因此 60 dB 的 PSRR 表示電源擾動被衰減約 1000 倍，80 dB 則為 10,000 倍。資料手冊常為正負電源軌分別提供數值，有些則除以閉迴路增益，將結果換算到輸入端。各廠商的正負號慣例不同，同一元件可能被標為 +60 dB 或 −60 dB；重要的是其大小。

為什麼 PSRR 隨頻率下降

在運算放大器或低壓差穩壓器（LDO）中，電源拒斥主要來自回授迴路，它會偵測並修正電源耦合到訊號路徑中的任何成分。迴路增益隨頻率升高而下降，可用的修正變少，同時寄生電容又開啟了從電源到輸出的直接路徑。結果是一條曲線而非單一數值：在低頻有 80～100 dB 的元件，在數百 kHz 時可能只剩 20～30 dB。而那正是切換式穩壓器的漣波及其諧波常出現的位置。

數值的運用

要估算輸出漣波，先以 10^(PSRR/20) 將 PSRR 換算成線性比值，再以輸入漣波除以它：1 kHz、100 mV 的漣波經過 60 dB 後約剩 0.1 mV。若使用適用於功率比的 10 log₁₀，得到的答案會小了一千倍。務必從資料手冊的圖表讀取實際漣波頻率下的 PSRR。當 LDO 前方有 LC 濾波器時，兩者的衰減相乘，因此以分貝表示時大致相加，但訊號源與負載阻抗會使其並不精確。

PSRR 與 CMRR、線路調整率

共模拒斥比（CMRR）描述放大器忽略同時出現在其兩個輸入上之電壓的能力；PSRR 則描述它忽略電源接腳上變化的能力。兩者常被混淆，因為都是以分貝表示的拒斥比。線路調整率是穩壓器的規格，是 PSRR 的靜態或緩慢變化版本，通常以每伏特輸入變化所造成的輸出變化表示。PSRR 則是其動態對應，告訴你在各頻率下有多少漣波與雜訊會通過。

練習PSRR(電源電壓變動拒斥比)的題目

一顆PSRR（電源抑制比）在1 kHz時為60 dB的LDO，其輸入疊加了1 kHz、振幅100 mV的漣波。輸出出現的漣波參考值為何？

  1. A0.1 µV
  2. B約1.7 mV
  3. C0.1 mV
查看答案與解析

正確答案：C. 0.1 mV

以分貝表示電壓比時使用 20 log₁₀，因此60 dB為1/1000。100 mV ÷ 1000 = 0.1 mV 會出現在輸出。0.1 µV是以10 log₁₀（功率比）計算的錯誤，約1.7 mV是將100除以60的錯誤。PSRR一般在頻率升高時下降，即使在1 kHz有60 dB，也有產品在數百kHz時降到20〜30 dB左右。在交換式穩壓器後級放置LDO時，要以圖表確認在該切換頻率下的PSRR。

常見問題

如何從以 dB 表示的 PSRR 計算輸出漣波？

以輸入漣波振幅除以 10^(PSRR/20)，並使用漣波頻率下的 PSRR 值。例如 60 dB 相當於 1000 倍，因此 100 mV 的漣波會變成約 0.1 mV。

為什麼我的 LDO 無法去除切換式穩壓器的漣波？

LDO 的 PSRR 通常只在低頻時很高，在切換漣波所在的數百 kHz 處可能降到數十 dB。常見的解決方法是在 LDO 之前加上 LC 或鐵氧體濾波器，或選用規格標明高頻 PSRR 的 LDO。

以 dB 表示的 PSRR 是正值還是負值？

兩種形式都有，因為各廠商定義比值的方向相反。應將其大小視為拒斥程度：大小越大，表示到達輸出的電源雜訊越少。
