什麼是QFN(四方扁平無引腳封裝)

在封裝底面周邊露出電極、側面不突出引腳的表面黏著封裝。底面中央的散熱焊墊可焊接到基板，體積小且散熱性佳。

日文名稱: QFN

「QFN(四方扁平無引腳封裝)」出現在2領域的2道練習題中（封裝與構裝, 規格書的閱讀方法等）。

這個名詞所屬的領域: 封裝與構裝

QFN 的結構

QFN 是 Quad Flat No-lead 的縮寫，是使用導線架的封裝之一。晶粒放在晶粒座上，以打線接合連接周圍的引腳並以封裝膠體覆蓋，但引腳不從側面突出，而是沿封裝底面四邊露出作為電極。晶粒座通常也露出於底面中央，稱為裸露焊墊（exposed pad）或散熱焊墊。電極間距一般約為 0.4 至 0.65 mm。多數 QFN 是在導線架上排列許多顆一次封裝，再以切割刀分割而成。只有兩邊有電極的稱為 DFN 或 SON。

電氣特性與散熱

引腳位於封裝底面且很短，因此導線的電感與電阻小，適合處理高頻訊號的 RF 電路與高速切換的電源 IC。底面中央的散熱焊墊焊接到印刷電路板的焊墊上，再經由其下方的多個散熱導通孔將熱傳到內層或背面的銅箔，因此熱阻可比相同大小的有引腳封裝更小。散熱焊墊多半連接到接地，兼作電氣連接。由於占用面積小且薄，QFN 也廣泛用於智慧型手機等小型設備。

實裝與檢查的注意事項

電極位於底面，焊點大部分無法從外部看到，因此以 X 光檢查為主。在車用等需要以外觀檢查確認接合的用途中，會使用在電極側面加工、使焊料也能潤濕側面的可濕性側翼（wettable flank）品種。散熱焊墊上印刷的焊料太多會使封裝浮起，造成周邊接點不良；太少則散熱變差，因此會將鋼板開口分割成格子狀，以調整焊料量與空洞。由於焊料層很薄，大型封裝也須注意溫度循環下的接點疲勞。

VQFN 等名稱以及與 QFP、BGA 的差異

QFN 前面加上的 V、W、U 等字母主要是封裝厚度的分類，VQFN 是「very thin」的 QFN，也就是實裝高度大致在 1 mm 以下的薄型品。分類的界線與名稱依製造商而異，尺寸應以個別的外形圖確認。QFP 從四邊伸出鷗翼型引腳，接點容易目視檢查，但占用面積較大。BGA 在整個底面以格子狀排列錫球，可設置更多的端子。QFN 只能在周邊配置電極，因此特別常用於接腳數較少的 IC。

  2. B不向外引出引腳，在封裝底面四邊配置電極的小型封裝

正確答案：B. 不向外引出引腳，在封裝底面四邊配置電極的小型封裝

QFN是側面不突出引腳、而在底面周邊露出電極的封裝。由於引腳短，電感較小，可做到小型、薄型。底面中央有大面積的散熱墊，焊接到基板後可透過基板的導通孔散熱，因此散熱性也很優異。另一方面，接合處隱藏在底面，目視檢查較為困難。四邊引出長引腳的是QFP，排列焊球的是BGA。

QFN封裝底面的大型裸露焊墊（exposed pad），一般的處理方式何者正確？

  1. A焊接後容易因熱應力而破裂，因此電路板側不設焊墊，使其與封裝保持懸空狀態
  2. B為了保持電氣絕緣，電路板側對應的部分以防焊漆覆蓋，不予連接
  3. C電路板側也設置焊墊並焊接，連接到指定的電位（多為GND），並以散熱導通孔散熱
查看答案與解析

正確答案：C. 電路板側也設置焊墊並焊接，連接到指定的電位（多為GND），並以散熱導通孔散熱

裸露焊墊是承載晶片的晶片座背面露出封裝外的部分，是將熱導向電路板的主要路徑。規格書的θJA數值，一般是在此焊墊焊接到電路板、並以散熱導通孔連接到內層大面積鋪銅的狀態下量測的，若不焊接，散熱會大幅惡化。建議焊墊圖案中，也會列出為調整焊錫量以防止空洞或零件浮起而將鋼板開孔分割的範例。連接的電位依規格書的指定。

常見問題

QFN 是什麼的縮寫？

Quad Flat No-lead 的縮寫，指四邊有電極的扁平封裝中，側面不突出引腳的封裝。電極露出於封裝底面。

VQFN 和 QFN 有什麼不同？

VQFN 是指薄型（very thin）QFN 的名稱，結構相同。厚度的分類與名稱依製造商而異，應以外形圖確認尺寸。

QFN 底面中央的焊墊有什麼作用？

這是放置晶粒的晶粒座露出的部分，焊接到印刷電路板後，可經由散熱導通孔成為散熱路徑。多數情況也會連接到接地，兼作電氣連接。
