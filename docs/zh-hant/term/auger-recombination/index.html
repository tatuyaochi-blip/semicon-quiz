什麼是歐傑復合

電子與電洞復合時，將能量傳給另一個載子而不是以光釋出的過程。在載子濃度高時變得明顯，與高濃度層的生命期及 LED 的效率下降有關。

日文名稱: オージェ再結合

這個名詞所屬的領域: 半導體物性

三載子過程

在歐傑復合中，一個電子與一個電洞復合，並將釋放的能量（約等於能隙能量）交給第三個載子，可能是另一個電子（eeh 過程）或另一個電洞（ehh 過程）。該載子被激發到其能帶的高處，然後藉由發射聲子將能量以熱的形式散失。其速率通常寫成 R = Cn·n²p + Cp·np²，其中 Cn 與 Cp 為歐傑係數。在重摻雜的 n 型材料中，這使生命期隨摻雜濃度的平方下降。

比較三種復合途徑

比較各機制的一個簡單方法，是看它們的速率在高注入下如何隨載子密度 n 變化：SRH 復合大致與 n 成正比，輻射復合與 n² 成正比，歐傑復合與 n³ 成正比。在低密度時，矽中以 SRH 為主；在重摻雜或強注入造成的極高密度下，則由歐傑接手。能隙越窄，歐傑過程也越強，因此它是紅外線偵測器與長波長雷射中的關鍵損耗。

它在哪裡限制元件

雙極電晶體與太陽能電池的重摻雜射極受到歐傑生命期短的影響，降低射極效率並增加復合電流。PiN 二極體與 IGBT 等功率元件在高注入下運作，此時歐傑復合會限制儲存的載子密度。由於歐傑復合是材料本身固有的，無法以純化去除，因此它決定了矽少數載子生命期的基本上限，並影響矽太陽能電池的理論效率極限。

LED 效率下降

氮化銦鎵（InGaN）LED 在約數 A/cm² 這種相對低的電流密度下達到最高效率，隨著電流增加效率會降低，這種現象稱為效率下降（efficiency droop）。隨載子密度三次方增長的歐傑復合，以及電子越過主動區的洩漏，被認為是主要原因。常用的 ABC 模型將內部量子效率寫成 Bn² / (An + Bn² + Cn³)。高功率照明以使用較大或多顆晶片來降低電流密度。

常見問題

為什麼歐傑復合與載子密度的三次方成正比？

必須有三個載子相遇：一個電子、一個電洞，以及接收能量的第三個載子，因此速率與 n²p 或 np² 成正比，當 n 與 p 相近時大約為 n³。

歐傑復合會發光嗎？

不會。能量交給第三個載子並最終變成熱，這就是它在 LED 與雷射中屬於非輻射損耗的原因。

歐傑復合在矽中重要嗎？

重要，在重摻雜區域與高注入下，它會超越 SRH 復合成為主導，且無論材料純度如何都會限制生命期。
