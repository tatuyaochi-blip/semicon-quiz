什麼是物件導向

以把資料與操作資料的程序（方法）整合在一起的物件為單位來組成程式的思考方式。物件的設計圖稱為類別，從類別建立的各個物件稱為實例，每個實例各自擁有成員變數的值。

日文名稱: オブジェクト指向
