什麼是定址模式

指令指定資料或跳躍目的地位址的方法。有立即值、暫存器、基底暫存器+位移、PC相對等。

日文名稱: アドレッシングモード

「定址模式」出現在1領域的1道練習題中（編譯器等）。

這個名詞所屬的領域: 指令集與組合語言

練習定址模式的題目

關於程式碼產生階段之一的指令選擇（instruction selection）的說明，下列何者正確？

  1. A決定中介表示的運算要用目標CPU所擁有的哪一條指令來實現
  2. B決定作業系統要以什麼順序選擇要執行的行程
  3. C從原始碼中挑出以註解寫成的指令
查看答案與解析

正確答案：A. 決定中介表示的運算要用目標CPU所擁有的哪一條指令來實現

指令選擇是將中介表示的運算序列，對應到目標CPU的具體指令的處理。即使是相同的計算，各CPU可用的指令也不同，例如 a * b + c，若CPU有乘加運算（FMA）指令，就以一條指令實現，若沒有，則以乘法與加法兩條指令實現。將記憶體位址的計算整合進定址模式等，越能善用CPU的指令，就越能得到快速的程式碼。這與作業系統的排程或註解的處理無關。

解析中的「定址模式」

  • 將記憶體位址的計算整合進定址模式等，越能善用CPU的指令，就越能得到快速的程式碼。
