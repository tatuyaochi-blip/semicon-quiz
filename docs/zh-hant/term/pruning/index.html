什麼是剪枝（Pruning）

將神經網路中影響較小的權重設為 0，以減少運算與記憶體的方法。以固定形式設為 0 的結構化方式，在硬體上較容易加速。

日文名稱: プルーニング

「剪枝（Pruning）」出現在1領域的2道練習題中（AI硬體與軟體堆疊等）。

這個名詞所屬的領域: AI硬體與軟體堆疊

練習剪枝（Pruning）的題目

關於神經網路的剪枝（pruning），下列何者正確？

  1. A是將不重要的權重設為0而加以削減的方法，其中零散地設為0的非結構化方式，難以靠硬體加速
  2. B是增加權重而必定提高模型精度的方法
  3. C是減少訓練資料的方法
查看答案與解析

正確答案：A. 是將不重要的權重設為0而加以削減的方法，其中零散地設為0的非結構化方式，難以靠硬體加速

剪枝是將數值很小等影響較小的權重設為0，以減少計算與記憶體的方法。然而，若0零散分布，就要花功夫去找出哪裡是0，而矩陣運算單元與記憶體是以成塊的單位運作，因此實際上不太會變快。若是依通道或層，或以固定形式設為0的結構化剪枝，就容易靠硬體加速。
