什麼是XRD(X射線繞射)

對晶體照射X射線，由繞射X射線的角度與強度，檢查晶體結構、晶格常數、薄膜應變與晶體品質的分析法。

日文名稱: XRD(X線回折)

「XRD(X射線繞射)」出現在1領域的3道練習題中（量測與分析等）。

這個名詞所屬的領域: 量測與分析

繞射如何揭示晶格間距

被平行原子面散射的 X 射線，只有在路徑差為波長的整數倍時才會彼此加強，這就是布拉格定律 2d·sinθ = nλ。實驗室儀器常用銅 Kα 輻射，其波長約 0.154 nm，與原子間距相當。在 θ-2θ 掃描中，峰位置給出晶面間距 d，可用以鑑定晶相與晶格常數。峰的展寬反映微小的晶粒尺寸與不均勻應變，相對峰強度則顯示優選取向。

磊晶層的高解析 XRD

高解析 XRD（HRXRD）使用經調整、近乎單色的光束來解析極小的角度差。在矽上 SiGe 這類磊晶堆疊中，薄膜峰與基板峰的間隔給出晶格不匹配度，由此可推得應變與組成。薄膜峰周圍的干涉條紋則給出其厚度。搖擺曲線（rocking curve）是在固定偵測器的情況下掃描樣品角度，用以量測晶體的完美程度：近乎完美的矽寬度只有數角秒，而藍寶石上差排密集的 GaN 則達數百角秒。

薄膜與相關方法

對於多晶薄膜，低掠角入射 XRD 讓光束保持在表面附近，以增加來自薄膜而非基板的訊號；極圖量測則可描繪織構，例如銅導線晶粒的優選取向。倒晶格空間圖（reciprocal space map）能在磊晶層中將組成與應變鬆弛分開。X 射線反射率（XRR）以同一台儀器在極低角度下量測，即使是非晶薄膜也能得到厚度、密度與界面粗糙度，因為它依賴的是電子密度差而非晶面。

優點與限制

XRD 是非破壞性的，在多數情況下不需要真空或樣品製備，並在通常數毫米寬的光點範圍內取平均，統計性佳，但無法提供奈米尺度的細節；局部結構則以穿透式電子顯微鏡（TEM）觀察。它需要晶體有序性，因此非晶薄膜只會呈現寬廣的隆起。它也不同於 X 射線螢光（XRF），後者偵測元素發出的特徵 X 射線來量測成分，而非晶體結構。

正確答案：C. 晶體結構、晶格常數與膜的應變

XRD是根據X光在晶體原子面上繞射的布拉格條件 2d·sinθ=nλ，調查晶體結構與晶格面間距的方法。在高解析度XRD中，可由SiGe等磊晶膜繞射峰的位置評估組成與應變，由峰的寬度評估晶體的完整性。對於多晶膜，也能得知晶體方向的整齊程度。有機物污垢與片電阻則無法量測。

常見問題

X 射線繞射中的布拉格定律是什麼？

布拉格定律 2d·sinθ = nλ 指出：從間距為 d 的原子面反射的 X 射線，當路徑差等於波長的整數倍時，會在角度 θ 發生建設性干涉。因此量測繞射角即可得到晶面間距。

XRD 和 XRF 有什麼差別？

XRD 量測繞射角，以決定晶體結構、晶格常數與應變。XRF 量測原子發出的螢光 X 射線，以辨識存在哪些元素及其含量。

搖擺曲線的 FWHM 代表什麼？

它衡量薄膜中晶面方向的分散程度。半高寬窄表示差排少、鑲嵌性（mosaicity）低，寬則表示晶體缺陷多。
