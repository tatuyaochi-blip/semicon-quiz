什麼是XRD(X射線繞射)

對晶體照射X射線，由繞射X射線的角度與強度，檢查晶體結構、晶格常數、薄膜應變與晶體品質的分析法。

日文名稱: XRD(X線回折)

「XRD(X射線繞射)」出現在1領域的3道練習題中（量測與分析等）。

這個名詞所屬的領域: 量測與分析

練習XRD(X射線繞射)的題目

X光繞射（XRD）主要可評估下列何者？

  1. A表面的有機物污垢
  2. B片電阻
  3. C晶體結構、晶格常數與膜的應變
查看答案與解析

正確答案：C. 晶體結構、晶格常數與膜的應變

XRD是根據X光在晶體原子面上繞射的布拉格條件 2d·sinθ=nλ，調查晶體結構與晶格面間距的方法。在高解析度XRD中，可由SiGe等磊晶膜繞射峰的位置評估組成與應變，由峰的寬度評估晶體的完整性。對於多晶膜，也能得知晶體方向的整齊程度。有機物污垢與片電阻則無法量測。
