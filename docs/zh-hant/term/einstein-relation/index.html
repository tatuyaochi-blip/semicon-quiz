什麼是愛因斯坦關係式

連結載子擴散係數 D 與遷移率 μ 的關係式 D = μkT/q。表示遷移率越大的材料，越容易擴散。

日文名稱: アインシュタインの関係式

「愛因斯坦關係式」出現在1領域的1道練習題中（半導體物性等）。

這個名詞所屬的領域: 半導體物性

練習愛因斯坦關係式的題目

表示半導體載子的擴散係數D與遷移率μ之關係的愛因斯坦關係式，下列何者正確？（k：波茲曼常數、T：絕對溫度、q：基本電荷）

  1. AD = qμ
  2. BD = μ / (kT)
  3. CD = μkT / q
查看答案與解析

正確答案：C. D = μkT / q

愛因斯坦關係式為 D = μkT/q。無論擴散或漂移，都取決於載子在不被散射的情況下能移動多遠，因此兩者成正比。室溫下 kT/q ≈ 26 mV，所以電子（μ ≈ 1400 cm²/V·s）的 D ≈ 36 cm²/s，電洞（約450）則約為12 cm²/s。只要有遷移率的數據表，就能立即求出擴散係數，用於擴散長度和元件的計算。
