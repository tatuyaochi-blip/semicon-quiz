什麼是方塊圖

把控制系統的元件以寫有轉移函數的方框（方塊）表示，並以箭頭表示訊號的流向、以加總點表示訊號的加減、以分歧點表示訊號分支的圖。串聯的方塊可合併為轉移函數的乘積，並聯的方塊可合併為和，負回授迴路可替換為 G/(1 + GH) 這1個方塊。反覆進行這種等效轉換，就能求出由目標值或擾動到輸出的轉移函數。

日文名稱: ブロック線図

「方塊圖」出現在1領域的1道練習題中（控制工程基礎等）。

這個名詞所屬的領域: 控制工程基礎

練習方塊圖的題目

在前向路徑的轉移函數為 G(s)、回授路徑的轉移函數為 H(s) 的負回授方塊圖中，由目標值 R(s) 到輸出 Y(s) 的閉迴路轉移函數 Y(s)/R(s) 為下列何者？

  1. AG(s)/(1 − G(s)H(s))
  2. BG(s)H(s)/(1 + G(s)H(s))
  3. CG(s)/(1 + G(s)H(s))
查看答案與解析

正確答案：C. G(s)/(1 + G(s)H(s))

誤差為 E(s) = R(s) − H(s)Y(s)，輸出為 Y(s) = G(s)E(s)。由這兩式消去 E(s)，得到 Y(s) = G(s)R(s) − G(s)H(s)Y(s)，因此 Y(s)/R(s) = G(s)/(1 + G(s)H(s))。分母中的 G(s)H(s) 是訊號沿迴路繞行一圈時的轉移函數，稱為迴路轉移函數（開迴路轉移函數）。在 H(s) = 1 的單位回授中，成為 G(s)/(1 + G(s))。

出現這個名詞的比較

  • 開迴路控制與閉迴路控制的差異：運作方式、抗干擾能力、穩定性、感測器、用途比較從訊號的流向、是否需要感測器、對干擾的處理、對受控體變化的耐受度、響應速度、穩定性、穩態誤差、構成與成本、實例等面向，以表格比較開迴路控制與閉迴路控制（回授控制）。
