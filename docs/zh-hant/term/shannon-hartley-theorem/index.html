什麼是夏農定理（Shannon–Hartley theorem）

在頻寬B、訊雜比S/N的通道中，可無誤傳送之傳輸速率的理論上限（通道容量）為 C = B·log₂(1 + S/N) 的定理（夏農-哈特利定理）。S/N要使用真值。容量與頻寬成正比，但隨S/N只以對數增加。

日文名稱: シャノンの定理

「夏農定理（Shannon–Hartley theorem）」出現在2領域的3道練習題中（資訊理論與編碼基礎, 無線通訊基礎等）。

這個名詞所屬的領域: 無線通訊基礎

公式的意義

C = B·log₂(1 + S/N) 中，C是每秒的位元數，B是頻寬（Hz），S/N是訊號與雜訊的功率比（真值）。例如頻寬20 MHz、S/N 30 dB（功率比1000）時，C = 20×10⁶ × log₂(1001) ≈ 200 Mbit/s。容量除以頻寬的 C/B，表示每1 Hz可傳送之位元數（頻譜效率）的上限。

頻寬與S/N的影響

在S/N不變下把頻寬變為2倍，容量也變為2倍。另一方面，S/N很大時，即使把S/N變為2倍（約增加3 dB），容量每1 Hz也只增加約1 bit/s。不過，若在發射功率不變的情況下加寬頻寬，雜訊功率也會隨頻寬成正比增加而使S/N下降，因此容量不會與頻寬成正比地增加。為了高速化而使用能取得寬頻寬的毫米波頻段，就是這個原因。

與實際通訊的關係

夏農定理表示的是使用理想的編碼時，可使錯誤率任意小的上限，並不指出具體的方式。實際的無線通訊結合多階調變，以及渦輪碼、LDPC碼、極化碼等強大的錯誤更正碼，來接近這個上限。MIMO的空間多工則是藉由並列多個通道，得到超過單一通道上限的傳輸速率。

練習夏農定理（Shannon–Hartley theorem）的題目

某二元對稱通道傳送0與1，各位元彼此獨立地以機率0.1翻轉。設二元熵函數為 H(p) = −p log₂ p − (1 − p) log₂(1 − p)，則 H(0.1) ≈ 0.469。此通道每次傳輸的通道容量最接近下列何者？

  1. A約0.47位元
  2. B約0.53位元
  3. C0.9位元
查看答案與解析

正確答案：B. 約0.53位元

二元對稱通道的通道容量為 C = 1 − H(p)，是以相等機率傳送0與1時的互資訊值。p = 0.1 時 C ≈ 1 − 0.469 = 0.531，每次傳輸約0.53位元。只要使用適當的錯誤更正碼，就能以這個比例以內的速度，讓錯誤率任意小地傳送資料。p = 0.5 時收到的值與送出的值無關，容量為0。

頻寬20 MHz、S/N（訊雜比）30 dB的通道，依夏農定理求得的通道容量（可無誤傳送之傳輸速率的理論上限）最接近下列何者？

  1. A100 Mbit/s
  2. B200 Mbit/s
  3. C600 Mbit/s
查看答案與解析

正確答案：B. 200 Mbit/s

依夏農定理，通道容量為 C = B·log₂(1 + S/N)，S/N要使用真值（功率比）。30 dB的功率比為10³ = 1000，因此 C = 20×10⁶ × log₂(1001) ≈ 20×10⁶ × 9.97 ≈ 200 Mbit/s。在S/N不變下把頻寬變為2倍，容量也變為2倍；但S/N很大時，即使把S/N變為2倍（約增加3 dB），容量每1 Hz也只增加約1 bit/s。實際的通訊方式結合錯誤更正碼與多階調變，努力接近這個上限。

常見問題

S/N可以直接以dB代入公式嗎？

不行。公式中的S/N是功率比的真值。30 dB要換算成10³ = 1000，20 dB要換算成100後再計算。若把30 dB當成30計算，容量會被低估約一半。

與奈奎斯特公式有什麼不同？

奈奎斯特公式表示，在無雜訊、頻寬B的通道中，以M階訊號最多可傳送 2B·log₂ M 位元/秒。增加階數M似乎能無限提高速率，但實際上有雜訊，能區分的階數有限。把雜訊考慮進去而表示這個極限的，就是夏農定理。
