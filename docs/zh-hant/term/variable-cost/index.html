什麼是變動成本

材料費、委外加工費、銷售佣金等，與產量或營業收入成比例增減的成本。變動成本占營業收入的比率稱為變動成本率。

日文名稱: 変動費

「變動成本」出現在1領域的8道練習題中（經營策略與會計基礎等）。

這個名詞所屬的領域: 經營策略與會計基礎

練習變動成本的題目

在半導體工廠的費用中，一般被歸類為變動成本的是下列何者？

  1. A製造設備的折舊費用
  2. B晶圓或藥液等材料費
  3. C無塵室建築物的租金
查看答案與解析

正確答案：B. 晶圓或藥液等材料費

變動成本是與產量或營業收入成比例增減的費用，代表性的例子有晶圓、光阻、藥液、氣體等材料費，委外加工費，銷售佣金等。固定成本是不論產量多少，每期都會發生一定金額的費用，例如設備與建築物的折舊費用、租金、正職員工的薪資等。半導體工廠的設備投資龐大，固定成本占比高，因此稼動率一下降，利益就容易大幅減少。

某企業的營業收入為5,000萬日圓、變動成本為2,000萬日圓、固定成本為2,400萬日圓。此企業的損益兩平點營業收入為下列何者？

  1. A4,000萬日圓
  2. B4,400萬日圓
  3. C6,000萬日圓
查看答案與解析

正確答案：A. 4,000萬日圓

變動成本率為 2,000 ÷ 5,000 = 0.4，因此營業收入中可用來負擔固定成本的邊際貢獻率為 1 − 0.4 = 0.6。損益兩平點營業收入是邊際貢獻剛好能負擔固定成本的營業收入，因此為 2,400 ÷ 0.6 = 4,000萬日圓。目前的營業收入5,000萬日圓高於損益兩平點，利益為 5,000 − 2,000 − 2,400 = 600萬日圓。

出現「變動成本」的題目（8題）

  1. 在半導體工廠的費用中，一般被歸類為變動成本的是下列何者？
  2. 某企業的營業收入為5,000萬日圓、變動成本為2,000萬日圓、固定成本為2,400萬日圓。此企業的損益兩平點營業收入為下列何者？
  3. 營業收入為2億日圓、變動成本率為70%、固定成本為4,500萬日圓的企業，其安全邊際率為下列何者？
  4. 在固定成本為3,000萬日圓、變動成本率為60%的事業中，要獲得1,000萬日圓的利益，所需的營業收入為下列何者？
  5. 某半導體製造商要開發專用晶片。晶片的售價為4,000日圓，每顆的變動成本（晶圓、封裝、測試的費用等）為2,400日圓，光罩製作費與設計費等固定成本為8億日圓。損益兩平點的銷售數量為下列何者？
  6. 某事業的固定成本為2,700萬日圓、變動成本率為40%，且費用只有變動成本與固定成本。要使營業利益率（營業利益 ÷ 營業收入）達到15%，所需的營業收入為下列何者？
  7. 某產品的生產方式有方案A（固定成本1,000萬日圓、變動成本率60%），以及將生產線自動化的方案B（固定成本1,600萬日圓、變動成本率45%）。營業收入超過某個值時，方案B的利益會大於方案A。這個值為下列何者？
  8. 某工廠每月的晶圓投入片數x（千片）與電費y（百萬日圓）為 (x, y) = (2, 5)、(4, 9)、(6, 11)、(8, 15)。以最小平方法求迴歸直線 y = ax + b，並將斜率a視為每千片的變動成本、截距b視為固定成本時，其組合下列何者正確？
