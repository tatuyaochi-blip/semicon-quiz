什麼是訊息鑑別碼

由訊息與傳送者、接收者共享的對稱金鑰計算出的簡短值（MAC）。接收者以相同金鑰重新計算並比對，即可確認訊息來自知道金鑰的對象且未遭竄改。由於接收者也能產生相同的值，因此無法提供不可否認性。HMAC是代表。

日文名稱: メッセージ認証コード

練習訊息鑑別碼的題目

比較訊息鑑別碼（MAC）與數位簽章的說明，正確的是哪一項？

  1. AMAC可用公開金鑰讓任何人驗證，因此不可否認性的效果比數位簽章強
  2. BMAC以傳送者與接收者共享的對稱金鑰建立，因此能偵測竄改，但接收者也能建立相同的MAC，所以無法用於向第三者證明訊息由傳送者建立的不可否認性
  3. CMAC不使用金鑰，只計算雜湊值，因此即使攻擊者改寫訊息後重新計算MAC，接收者也能察覺
查看答案與解析

正確答案：B. MAC以傳送者與接收者共享的對稱金鑰建立，因此能偵測竄改，但接收者也能建立相同的MAC，所以無法用於向第三者證明訊息由傳送者建立的不可否認性

訊息鑑別碼（MAC）是由訊息與對稱金鑰計算出的簡短值，常用的是使用雜湊函數的HMAC。接收者以相同金鑰重新計算並比對，一致就能得知訊息來自知道金鑰的對象，且途中未遭竄改。不知道金鑰的攻擊者，無法為改寫後的訊息產生正確的MAC。然而接收者也持有相同的金鑰，也能建立MAC。因此接收者無法向第三者證明「這是傳送者建立的」，MAC無法提供不可否認性。數位簽章只能用傳送者的私密金鑰建立，任何人都能用公開金鑰驗證，因此可用於不可否認性。另一方面，MAC計算量小，廣泛用於當事人之間的確認，例如偵測連線中每個封包是否遭竄改。不使用金鑰的單純雜湊值，攻擊者可以連同改寫的訊息一起重新計算，因此無法用來偵測蓄意的竄改。
