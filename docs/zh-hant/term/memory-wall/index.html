什麼是記憶體牆

記憶體頻寬與延遲的改善跟不上處理器運算性能的提升，使整體性能受限的問題。以 HBM、快取容量增大、先進封裝等來因應。

日文名稱: メモリウォール

「記憶體牆」出現在2領域的2道練習題中（DRAM, 先進技術（3D構裝與小晶片）等）。

這個名詞所屬的領域: DRAM

練習記憶體牆的題目

相較於處理器效能的提升，記憶體的頻寬與延遲的改善跟不上，因而產生的效能限制稱為什麼？

  1. A摩爾定律
  2. B矽週期
  3. C記憶體牆（memory wall）
查看答案與解析

正確答案：C. 記憶體牆（memory wall）

處理器的運算效能曾有一段時期以每年50%以上的速度成長，但DRAM的存取延遲自數十ns起幾乎沒有改善，使CPU得等待資料長達數百個週期。這就是記憶體牆。作為對策，正持續推進多層快取、記憶體的平行存取、預取、HBM這類高頻寬記憶體，以及在記憶體附近進行運算的記憶體內處理（processing-in-memory）等。

相較於處理器運算效能的提升，從記憶體供應資料的速度跟不上，進而限制整體效能的問題稱為什麼？

  1. A熱牆
  2. B記憶體牆（memory wall）
  3. C摩爾定律
查看答案與解析

正確答案：B. 記憶體牆（memory wall）

處理器的運算效能快速提升，但與記憶體之間資料傳輸的速度（頻寬）成長較為緩慢，運算單元等待資料的時間因此增加。這稱為記憶體牆。大型AI模型每次運算都要讀取大量權重，因此特別嚴重，將HBM安裝在處理器附近的先進封裝，以及大容量快取的堆疊，就是因應的對策。
