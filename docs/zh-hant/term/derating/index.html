什麼是降額(Derating)

為了提高可靠度，不將電壓、電流、溫度等用到額定值上限，而是保留餘裕來使用。例如訂定電壓在額定值的 70〜80% 以下、接面溫度相對於最大額定 150 ℃ 在 125 ℃ 以下使用等基準。

日文名稱: ディレーティング

「降額(Derating)」出現在4領域的6道練習題中（時序分析與CDC, 規格書的閱讀方法, 功率半導體等）。

這個名詞所屬的領域: 規格書的閱讀方法

為什麼要在額定值以下使用元件

大多數故障機制都會隨應力加速：化學劣化與擴散隨溫度呈指數加快，介電質在較高電場下磨耗更快，電遷移則隨電流密度與溫度惡化。因此保留餘裕來使用元件，可以降低故障率，也能吸收額定工作點所掩蓋的實際效應，例如元件公差、暫態、極端環境溫度與老化。典型的準則是將施加電壓保持在額定值的約 70 至 80%，接面溫度相對於 150 °C 的最大值保持在約 125 °C，確切數字由公司或產業規範訂定。

功率元件的電壓餘裕

在電力電子中，讓電流在雜散電感中切換時，會產生比直流匯流排高出 L·di/dt 的電壓突波；而持續的高電壓會使元件容易遭受宇宙射線中子引發的單粒子燒毀（single-event burnout），此風險隨電壓與海拔急遽上升。因此設計者會選擇額定約為工作電壓 1.5 倍的元件，例如在 400 V 匯流排上使用 650 V 元件。陶瓷電容與電解電容也要降額使用，因為電容值、漏電與壽命都取決於施加電壓與溫度。

熱降額與功率限制

規格書常會列出功率降額曲線：在參考溫度以下可承受完整的額定功耗，之後以直線下降，在最大接面溫度時降為零。這源自 Tj = Ta + P·θJA，其中 θJA 是接面到環境的熱阻。若 Tj(max) = 125 °C、θJA = 50 °C/W、Ta = 85 °C，則容許功率為 (125 − 85)/50 = 0.8 W。由於 θJA 很大程度取決於電路板佈局與氣流，設計上會在此計算值之下再保留餘裕。

時序分析中的降額

在晶片設計中，這個詞有相關的意義。靜態時序分析中的晶片內變異（OCV）降額，是將路徑延遲乘上係數，以涵蓋電晶體、導線、電壓與溫度的局部差異。設定時間檢查時，發出時脈與資料路徑被設得較慢、擷取時脈較快；保持時間檢查時則反過來。接著共同路徑悲觀消除（CRPR）會把兩條路徑共用之時脈緩衝器上不可能出現的悲觀量加回來。進階 OCV 變體則依路徑深度或距離調整係數。

練習降額(Derating)的題目

在選擇功率元件時，額定電壓留有餘裕、使用耐壓高於實際使用電壓的元件（降額，derating）之主要理由為下列何者？

  1. A為了因應切換時的突波電壓或宇宙射線造成的故障等，以確保可靠度
  2. B為了降低零件價格
  3. C為了降低導通電阻
查看答案與解析

正確答案：A. 為了因應切換時的突波電壓或宇宙射線造成的故障等，以確保可靠度

在實際電路中，切換時除了會疊加寄生電感造成的突波電壓外，持續在高電壓下使用時，源自宇宙射線的中子會在元件內產生電荷，導致突然損壞（單一事件燒毀，single event burnout）的機率隨電壓急遽上升。因此一般會選擇額定值約為使用電壓1.5倍的元件，例如在400 V系統的電路中使用650 V的產品。在海拔高的場所，餘裕還要取得更大。

作為OCV降額（derating），在建立時間分析中將發送端時脈路徑與資料路徑的延遲乘以1.1倍，接收端時脈路徑的延遲乘以0.9倍。當發送端時脈路徑為 1.0 ns、資料路徑（含時脈→輸出）為 1.5 ns、接收端時脈路徑為 1.0 ns（無共同部分）、週期為 3.0 ns、建立時間為 0.1 ns 時，建立時間的餘裕是多少？

  1. A1.05 ns
  2. B1.40 ns
  3. C1.25 ns
查看答案與解析

正確答案：A. 1.05 ns

OCV降額是考量即使在同一晶片內，延遲也會因位置而變異，並對建立時間假設最不利之組合（發送端較慢、接收端的時脈較快）的方法。到達時間為 1.1 × (1.0 + 1.5) = 2.75 ns，要求時間為 3.0 + 0.9 × 1.0 − 0.1 = 3.8 ns，因此餘裕為 1.05 ns。1.40 ns 是未降額的值，1.25 ns 是只對資料路徑乘上係數的值。在保持時間分析中，係數的乘法方式相反。

常見問題

電子學中的降額是什麼意思？

它是指在低於電壓、電流、功率或溫度最大額定值的條件下使用元件，以提高可靠度並吸收暫態與公差。常見的規則是額定電壓的 70 至 80%，以及遠低於絕對最大值的接面溫度。

如何解讀功率降額曲線？

此曲線給出容許功耗與環境溫度或外殼溫度的關係：在參考點以下保持平坦，之後線性下降，在最大接面溫度時降為零。其斜率是熱阻的倒數。

靜態時序分析中的 OCV 降額是什麼？

它對單元與導線延遲套用乘數係數，讓發出路徑與擷取路徑以悲觀且不同的速度評估，以涵蓋同一晶片內隨位置而異的變異。
