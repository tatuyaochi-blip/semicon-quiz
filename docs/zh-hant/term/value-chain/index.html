什麼是價值鏈

由麥可・波特提出，將企業的活動分為主要活動（進料後勤、生產作業、出貨後勤、行銷與銷售、服務）與支援活動，分析在哪些活動中創造價值、在哪裡發生成本的思維。

日文名稱: バリューチェーン

「價值鏈」出現在1領域的1道練習題中（經營策略與會計基礎等）。

這個名詞所屬的領域: 經營策略與會計基礎

練習價值鏈的題目

在波特的價值鏈中，下列何者屬於主要活動？

  1. A技術發展
  2. B生產作業（製造）
  3. C人力資源管理
查看答案與解析

正確答案：B. 生產作業（製造）

價值鏈是將企業的活動分為沿著產品或服務送達顧客之流程的主要活動，以及支撐主要活動的支援活動，分析在哪些活動中創造價值、在哪裡發生成本的思維。主要活動有進料後勤、生產作業、出貨後勤、行銷與銷售、服務五項，支援活動有企業基礎設施、人力資源管理、技術發展、採購四項。技術發展不只是研發部門的工作，而是指支撐所有活動的技術方面的努力，因此包含在支援活動中。
