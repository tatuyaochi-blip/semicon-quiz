什麼是局部排氣裝置

在發生源附近，吸入並排出處理藥液的設備等所產生的氣體或霧氣的設施。防止作業人員吸入有害物質。

日文名稱: 局所排気装置

「局部排氣裝置」出現在1領域的3道練習題中（環境安全等）。

這個名詞所屬的領域: 環境安全

局部排氣如何捕集污染物

局部排氣裝置（LEV）在有害氣體、蒸氣、霧氣與粉塵釋放的地點，於其到達作業人員呼吸區之前就將其去除。典型系統由包圍發生源的氣罩或密閉箱、風管、必要時設置的洗滌塔等空氣清淨設備、風扇與排氣煙囪組成。關鍵設計參數是捕捉風速：在發散點需要多大的風速，才能克服氣流擾動與污染物本身的釋放動量，將其吸入氣罩。

局部排氣與整體換氣的比較

整體換氣（稀釋換氣）是將潔淨空氣混入整個房間以降低平均濃度，因此站在發生源附近的作業人員仍可能暴露，且需要大量風量。局部排氣則在污染物擴散前就將其去除，因此對有毒物質更有效，所需風量也少得多。在無塵室中，大量的循環氣流是為了控制微粒而設計，並非用於控制化學品暴露；化學煙霧由各設備與化學品站專用的排氣處理。

在晶圓廠中會遇到的地方

濕式清洗台會透過化學槽周圍的狹縫吸氣，化學品儲存櫃與供應櫃都設有排氣，而存放砷化氫、磷化氫等有毒氣體的氣瓶櫃則保持負壓，使任何洩漏都會被吸入排氣系統。製程設備的腔體與裝載區也設有排氣接口。研磨與拋光GaAs時會產生含砷粉塵，同樣仰賴局部排氣並搭配防護具。排氣通常依酸、鹼、溶劑等種類分流，經處理後才排放。

維持排氣效能

氣罩只有在真正達到設計風量時才能發揮保護作用，因此系統需定期檢查與測試，例如量測氣罩開口處的捕捉風速或面風速，許多國家與地區也依法規定須進行此類檢查。排氣壓力會持續監控，處理危險化學品的設備常設有連鎖，在失去排氣時停機或發出警報。實務習慣也很重要：不要擋住氣罩開口、將拉門維持在正確高度，並在捕集範圍內作業。

練習局部排氣裝置的題目

在處理藥液的設備等處，於發生源附近就將產生的氣體或霧氣吸入並排出的設施為下列何者？

  1. A局部排氣裝置
  2. B加濕器
  3. C照明器具
查看答案與解析

正確答案：A. 局部排氣裝置

局部排氣裝置是在發生源附近捕捉有害的氣體或霧氣並排出，以防止作業人員吸入的設施。由於能在有害物質擴散到整個房間之前就將其去除，因此比對整個房間換氣的全面換氣更有效率，所需排氣量也較少。被排出的氣體，視需要以洗滌塔等處理後才排放到大氣中。其性能會依吸入口的風速等定期檢查。

在處理有害化學物質的作業場所，定期測定空氣中有害物質濃度等以評估作業環境，稱為什麼？

  1. A產品檢驗
  2. B作業環境測定
  3. C統計製程管制
查看答案與解析

正確答案：B. 作業環境測定

作業環境測定是測定作業場所空氣中有害物質的濃度等，以評估是否維持了保護作業人員健康的環境。在日本，勞動安全衛生法規定了應測定的作業場所與測定頻率，並由具資格的作業環境測定士執行。結果以管理區分評估，若結果不佳，則採取改善局部排氣裝置等對策。產品檢驗或SPC則是品質管理的手法。

常見問題

什麼是局部排氣裝置？

局部排氣裝置是以氣罩或密閉箱在發生源處直接捕集有害氣體、蒸氣、霧氣或粉塵，並經由風管排出的系統，使作業人員不會吸入這些物質。

什麼是捕捉風速？

捕捉風速是在污染物釋放點將其吸入排氣罩所需的風速，是局部排氣系統設計與檢查的基本判定標準。

局部排氣和整體換氣有什麼差別？

整體換氣以大量風量稀釋整個房間內的污染物，而局部排氣則在污染物擴散前於發生源將其去除，能以少得多的風量提供更好的保護。
