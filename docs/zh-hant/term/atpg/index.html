什麼是ATPG(自動測試向量產生)

從電路的網表自動產生用以偵測故障的測試向量。與掃描設計搭配使用。

日文名稱: ATPG(自動テストパターン生成)

「ATPG(自動測試向量產生)」出現在4領域的7道練習題中（測試與檢查, 量測與分析, 良率與品質管理等）。

這個名詞所屬的領域: 測試與檢查

ATPG 如何找出測試

自動測試向量產生（ATPG）以閘級網表與故障模型為基礎。對每個目標故障，它必須啟動故障（把故障線驅動到與其固定值相反的值），並沿著敏化路徑將差異傳播到可觀察的輸出，同時找出能滿足這兩項條件的主要輸入值。D 演算法與 PODEM 等經典演算法就是在這個空間中搜尋。每產生一個新的向量，就以故障模擬標記它順帶偵測到的其他所有故障，並對向量進行壓縮，因為測試時間與測試機記憶體都會隨向量數量增加。

故障模型與涵蓋率

固定型（stuck-at）模型假設某條線永久為 0 或 1，n 條線就有 2n 個故障。它雖然抽象，但能偵測固定型故障的向量也能抓到許多真實的短路與斷路，至今仍是衡量故障涵蓋率（向量組能偵測到的模型化故障比例）的基準。只會讓訊號變慢的缺陷在靜態測試中看不出來，因此會加入轉態故障等延遲故障模型，以實速向量發出轉態，並在一個時脈後擷取結果。涵蓋率永遠是相對於某個模型而言，而不是相對於所有可能的實體缺陷。

為什麼掃描設計不可或缺

為深度循序電路產生測試非常困難，因為內部狀態必須經過許多時脈週期才能到達。掃描設計是一種可測試性設計（DFT）技術，在每個正反器輸入端加入多工器，使正反器在測試模式下串接成移位暫存器鏈。測試機將狀態移入，施加一個功能擷取時脈，再將結果移出。如此一來，ATPG 只需處理掃描單元之間的組合邏輯，這使得擁有數億個邏輯閘的晶片也能實際達到高涵蓋率。

ATPG 與功能驗證

功能驗證問的是設計是否正確；ATPG 則假設設計正確，問的是每顆製造出來的晶片是否與設計一致。其輸出是測試向量（test pattern，也稱 test vector）：每個時間步的輸入值加上預期回應，由自動測試設備施加並比對。其他篩選方法則與它互補。零件平均測試（PAT）會剔除量測值屬於統計離群值的晶片，即使這些晶片通過了測試，這在車用零件中很常見；而自動缺陷分類（ADC）則屬於晶圓檢測，而非電性測試。

練習ATPG(自動測試向量產生)的題目

關於可測試性設計（DFT）之一的掃描設計，下列說明何者正確？

  1. A以光學顯微鏡掃描晶片表面來尋找缺陷
  2. B測試時逐漸提高電源電壓，以調查運作極限
  3. C將電路內的正反器連接成位移暫存器的形式，使內部狀態的設定與觀測變得容易
查看答案與解析

正確答案：C. 將電路內的正反器連接成位移暫存器的形式，使內部狀態的設定與觀測變得容易

在掃描設計中，會在各正反器的輸入加上切換用的選擇器，測試時將它們串接起來（掃描鏈），能從外部以位移方式設定任意值，並以位移方式讀出內部的值。由於循序電路的測試被轉換為組合電路的測試，因此可用ATPG自動產生高故障涵蓋率的測試圖樣。這與以顯微鏡掃描或電壓掃描是不同的事。

關於邏輯電路測試中使用的固定型故障（stuck-at fault）模型，下列說明何者正確？

  1. A訊號傳遞變慢的故障
  2. B訊號線的值被固定為0或1的故障
  3. C晶片溫度上升的故障
查看答案與解析

正確答案：B. 訊號線的值被固定為0或1的故障

固定型故障模型假設電路內的某條訊號線永遠固定為0（stuck-at-0）或永遠固定為1（stuck-at-1），若訊號線有n條，則考慮2n個故障。它雖然簡單，卻能代表短路、斷線等許多實體缺陷，是ATPG與故障涵蓋率評估的基礎。訊號變慢的故障以延遲故障模型處理，溫度上升則不屬於故障模型。

常見問題

VLSI 測試中的 ATPG 是什麼？

它是根據電路網表，自動產生輸入向量與預期輸出的軟體，用以偵測固定型故障等模型化的製造故障。

ATPG 為什麼需要掃描鏈？

掃描鏈讓測試機能直接設定並讀取每個正反器，將困難的循序測試問題轉換為組合邏輯問題，使 ATPG 能有效率地以高涵蓋率求解。

固定型故障和轉態故障模型有什麼差別？

固定型故障模擬一條線固定為 0 或 1，可用靜態測試找出。轉態故障模擬一條線切換太慢，需要實速的發出與擷取向量。
