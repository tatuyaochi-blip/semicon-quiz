什麼是正反器

保存 1 位元資訊的循序電路基本元件。D 型會在時脈的邊緣擷取輸入。

日文名稱: フリップフロップ

「正反器」出現在7領域的57道練習題中（硬體描述語言與驗證, 時序分析與CDC, 邏輯電路等）。

這個名詞所屬的領域: 邏輯電路

D 型正反器的運作方式

D 型正反器在有效的時脈邊緣取樣 D 輸入，並將該值保持在 Q 直到下一個邊緣；兩個邊緣之間的變化都會被忽略。其內部通常是兩個以相反相位時脈驅動的閂鎖器，構成主從式結構。相對地，閂鎖器是位準觸發：在致能期間呈透通狀態，輸入會直接傳到輸出。邊緣觸發讓時序分析容易得多，因此在同步設計中，正反器構成 CPU 暫存器、管線級邊界、狀態機與計數器。

設定時間、保持時間與最高頻率

資料必須在邊緣之前穩定一段設定時間，並在邊緣之後穩定一段保持時間。在暫存器到暫存器的路徑上，時脈週期必須涵蓋時脈到輸出延遲、邏輯延遲與設定時間：若為 0.15 + 2.2 + 0.15 ns，最短週期為 2.5 ns，即 400 MHz。設定時間違規可以靠降低時脈頻率來修正，保持時間違規卻不行，因為該檢查比較的是在同一個邊緣發出與擷取的資料；設計者會改為加入延遲緩衝器。使擷取時脈延後的時脈偏移有利於設定時間，卻不利於保持時間。

亞穩態與同步器

若資料在設定—保持時間窗內變化，例如來自不相關時脈的訊號，正反器可能進入亞穩態，輸出停留在 0 與 1 之間。它仍未決定的機率會隨時間呈指數下降，但永遠不會降到零。由兩個以上串聯正反器組成的同步器，讓第一級有完整一個時脈週期可以穩定下來，使平均故障間隔時間延長到數千年以上。多位元數值則透過非同步 FIFO 或交握機制跨越時脈域，CDC（時脈域跨越）驗證工具會檢查這些結構是否存在。

其他類型與用途

JK 正反器在 J = 1 時設定、K = 1 時重置、兩者皆為 0 時保持、兩者皆為 1 時反轉，為 SR 正反器的禁止輸入賦予了意義。把輸入接到高電位就成為 T 正反器，每個邊緣反轉一次，將時脈頻率除以二並得到 50% 的工作週期；將其串接即可構成漣波計數器與除頻器。現代邏輯幾乎只使用 D 型正反器。為了測試，掃描設計會在每個正反器輸入端加入多工器，使正反器能串接成移位暫存器，用來載入並觀察內部狀態。

正確答案：C. 在時脈邊緣取入D輸入的值，並保持到下一個邊緣

D型正反器在時脈的上升（或下降）邊緣取入D輸入的值，並保持到下一個邊緣。由於只看邊緣的瞬間，期間即使輸入變化，輸出也不會改變。它是CPU的暫存器、管線級的分隔、計數器等序向電路的基本元件，內部是將兩個鎖存器以主從（Master-Slave）方式連接的結構。要正確取入資料，必須遵守設置時間與保持時間。

下列哪一項是對正反器設置時間的正確說明？

  1. A時脈邊緣之後，資料必須持續保持的最短時間
  2. B時脈邊緣之前，資料輸入必須保持穩定的最短時間
  3. C從開啟電源到開始動作的時間
查看答案與解析

正確答案：B. 時脈邊緣之前，資料輸入必須保持穩定的最短時間

正反器要正確取入資料，資料必須從時脈邊緣前一段時間起就保持穩定，這就是設置時間。當資料路徑的延遲超過時脈週期減去設置時間的值時即違規，放慢時脈即可解決。邊緣之後資料必須保持的時間是保持時間，只要有一項不滿足，就會造成取入錯誤的值或亞穩態。

常見問題

閂鎖器（latch）和正反器有什麼差別？

閂鎖器是位準觸發，只要處於致能狀態就會把輸入傳到輸出；正反器則是邊緣觸發，只在時脈邊緣取樣輸入。典型的 D 型正反器是由兩個在相反時脈相位致能的閂鎖器構成。

為什麼降低時脈頻率無法修正保持時間違規？

保持時間檢查比較的是在同一個時脈邊緣發出與擷取的資料，因此時脈週期不會出現在其中。修正方法是在短路徑上增加延遲，通常是加入緩衝器。

如何計算正反器路徑的最高時脈頻率？

將時脈到輸出延遲、最差情況的組合邏輯延遲與設定時間相加，並考慮時脈偏移加以調整，即得到最短週期；最高頻率為其倒數。晶片上最慢的這類路徑，也就是關鍵路徑，決定了晶片的上限。
