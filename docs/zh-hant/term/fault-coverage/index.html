什麼是故障涵蓋率

在所假設的故障中，該測試向量能偵測到的故障所佔比例。越高，越不易漏掉不良品。

日文名稱: 故障検出率(フォールトカバレッジ)

「故障涵蓋率」出現在1領域的5道練習題中（測試與檢查等）。

這個名詞所屬的領域: 測試與檢查

練習故障涵蓋率的題目

下列何者是測試圖樣的故障涵蓋率（fault coverage）的正確定義？

  1. A在所假設的故障中，該測試能偵測到的故障所占的比例
  2. B出貨產品中不良品所占的比例
  3. C晶圓上良品晶片所占的比例
查看答案與解析

正確答案：A. 在所假設的故障中，該測試能偵測到的故障所占的比例

故障涵蓋率是指在所建立模型的全部故障中，測試圖樣能偵測到的故障所占的比例。被漏掉的不良比例，可使用良率Y與故障涵蓋率T，以DL=1−Y^(1−T)估算，即使Y=0.5、T=99%，也約為0.7%（約7000 DPPM）。因此車用等領域要求遠高於99%的數值。它與出貨品的不良率或良率本身是不同的指標。

解析中的「故障涵蓋率」

  • 故障涵蓋率是指在所建立模型的全部故障中，測試圖樣能偵測到的故障所占的比例。

    下列何者是測試圖樣的故障涵蓋率（fault coverage）的正確定義？

  • 由於循序電路的測試被轉換為組合電路的測試，因此可用ATPG自動產生高故障涵蓋率的測試圖樣。

    關於可測試性設計（DFT）之一的掃描設計，下列說明何者正確？

  • 它雖然簡單，卻能代表短路、斷線等許多實體缺陷，是ATPG與故障涵蓋率評估的基礎。

    關於邏輯電路測試中使用的固定型故障（stuck-at fault）模型，下列說明何者正確？

  • 與掃描設計搭配，即使是數億閘的電路，也能有效率地建立高故障涵蓋率的圖樣。

    從電路的網表（netlist）自動產生用來偵測故障的測試圖樣，稱為什麼？

  • 結構性測試是針對電路的結構建立故障模型，使用掃描等方式有效率地偵測各部分故障的測試，可以數值管理故障涵蓋率。
