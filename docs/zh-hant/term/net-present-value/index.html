什麼是淨現值（NPV）

將投資在未來可得到的現金流量，以折現率換算為現值後加總，再減去投資額的值。大於0時，判斷在該折現率下值得投資。

日文名稱: 正味現在価値(NPV)

「淨現值（NPV）」出現在1領域的1道練習題中（經營策略與會計基礎等）。

這個名詞所屬的領域: 經營策略與會計基礎

現值與折現率

現在的100萬日圓若拿去運用，1年後會增加利息的部分，因此比1年後的100萬日圓更有價值。這個概念稱為金錢的時間價值，將未來的金額以折現率r，除以 (1 + r) 的年數次方，換算為現值。例如折現率5%時，1年後105萬日圓的現值為100萬日圓。折現率會使用籌措資金的成本（資本成本），或投資要求的最低報酬率。

以NPV判斷投資

淨現值是各年現金流量現值的合計，減去最初投資額的值。NPV大於0時，投資能產生高於折現率的報酬，因此值得投資；比較多個方案時，NPV大者較有利。若不折現而直接加總，會高估遙遠未來的效果。

與IRR及回收期間的差異

內部報酬率（IRR）是使NPV剛好為0的折現率，代表投資的報酬率。回收期間是表示幾年可回收投資額的指標，容易理解，但不考慮回收後的現金流量。比較規模不同的投資時，NPV與IRR的排序可能不同，因此依目的分別使用。

練習淨現值（NPV）的題目

投資1,000萬日圓導入業務系統後，預期今後3年每年年底可節省400萬日圓的費用。設折現率為年5%，1年後、2年後、3年後的現值係數（1 ÷ 1.05ⁿ）分別為0.952、0.907、0.864時，此投資的淨現值（NPV）最接近下列何者？

  1. A約89萬日圓
  2. B約143萬日圓
  3. C200萬日圓
查看答案與解析

正確答案：A. 約89萬日圓

將未來的效果換算為現值，為 400 × (0.952 + 0.907 + 0.864) = 400 × 2.723 = 1,089.2萬日圓。再減去投資額1,000萬日圓，淨現值約為89萬日圓，大於0，因此在折現率5%下可判斷值得投資。若不折現，以效果合計1,200萬日圓減去投資額則為200萬日圓（相對投資額為20%），但考慮金錢的時間價值，未來的400萬日圓價值低於現在的400萬日圓。

常見問題

折現率要如何決定？

一般以借款與向股東籌資之成本的平均，也就是資本成本為基準，風險越高的投資使用越高的折現率。折現率越高，遙遠未來之現金流量的現值越小，因此回收越花時間的投資，NPV越小。

NPV與ROI有什麼不同？

ROI（投資報酬率）是投資所得利益除以投資額的比率，多數情況下不考慮金錢的時間價值。NPV將未來的現金流量折現後以金額評價，因此能反映效果在何時取得的差異。
