什麼是看門狗計時器（Watchdog timer）

若未在規定時間內由軟體重設（kick），就會重設微控制器的計時器。可使系統從程式失控或停止中恢復。

日文名稱: ウォッチドッグタイマ

「看門狗計時器（Watchdog timer）」出現在3領域的3道練習題中（CPU與架構, 車用半導體與功能安全, 嵌入式與韌體等）。

這個名詞所屬的領域: 嵌入式與韌體

看門狗的運作方式

看門狗是一個獨立於其所監視之程式運作的遞減計數器。軟體必須定期對它「kick」（踢）、「feed」（餵）或「service」（服務），通常是將特定的鍵值寫入暫存器，使計數器重新載入。若因程式卡在迴圈中、當機進入錯誤處理常式或受到雜訊干擾，導致計數器歸零，看門狗就會發出重設（部分元件會先發出預警中斷），微控制器從已知狀態重新啟動。以專屬的低速振盪器提供其時脈，可確保主時脈故障時看門狗不會一併失效。

該在哪裡 kick

看門狗的效果取決於 kick 的位置。在週期性計時器中斷內無條件地 kick 是典型錯誤：即使主迴圈卡住，中斷仍會持續觸發，計數器永遠不會到期，當機也就不會被察覺。較好的做法是讓每個任務或主迴圈的各階段設定一個報到旗標，由監督常式在週期內確認所有旗標都已設定後才 kick 看門狗，然後清除旗標。逾時時間要比最壞情況的迴圈時間長，但又要夠短，以限制恢復所需的時間。

視窗看門狗與標準看門狗

標準看門狗只能偵測到太晚抵達的 kick。若故障使程式略過大部分工作、在仍包含 kick 的短迴圈中空轉，計時器被服務的頻率反而比預期更高，什麼都偵測不到。視窗看門狗加入了下限：只有在規定的時間視窗內的 kick 才被接受，太早的 kick 會和缺少的 kick 一樣被視為故障。這能抓到單純逾時所漏掉的控制流程錯誤，因此視窗看門狗在功能安全設計中很常見。

安全系統中的外部看門狗

在車用與工業設備中，看門狗常放在以獨立時脈運作的監控 IC 或電源管理 IC 中，使振盪器故障之類的共因無法同時讓處理器及其監視器停止。部分外部監視器採用問答方式，處理器必須在時間視窗內對挑戰傳回正確的回應。看門狗重設後，韌體通常會讀取重設原因暫存器，以便記錄並分析該事件，而不是讓它默默地重複發生。

練習看門狗計時器（Watchdog timer）的題目

搭載於微控制器的看門狗計時器（watchdog timer）的作用，下列何者正確？

  1. A顯示正確的時間
  2. B提高時脈頻率
  3. C當程式失控而未在一定時間內清除計時器時，重置系統
查看答案與解析

正確答案：C. 當程式失控而未在一定時間內清除計時器時，重置系統

看門狗計時器是以正常的程式會定期清除它為前提的計時器，若因失控或停止而未被清除就逾時，便會重置微控制器。即使因雜訊或意料之外的狀態而當機，也能在無人介入的情況下自動復原，因此對車載設備、工業設備、遠端裝置而言不可或缺。還可以讓它以與 CPU 不同的時脈運作，或做成連過早清除也視為異常的視窗型（window）來提高可靠度。

下列何者是視窗型看門狗計時器的正確特徵？

  1. A一旦被踢狗一次，之後便停止監視以降低功耗
  2. B不僅將比規定時間視窗太晚的踢狗（計時器清除），也將太早的踢狗視為異常而偵測
  3. C踢狗延遲時，視為程式正在進行繁重的處理，不施加重置而自動延長等待時間，讓處理繼續
查看答案與解析

正確答案：B. 不僅將比規定時間視窗太晚的踢狗（計時器清除），也將太早的踢狗視為異常而偵測

一般的看門狗若在一定時間內未被踢狗就會施加重置。然而，在程式跳過部分處理而執行短迴圈之類的異常中，踢狗會太早到來，可能因此被漏看。視窗型則規定可以踢狗的時間視窗，比視窗太早或太晚都視為異常。在車用領域中，有時也會讓以不同於微控制器之時脈運作的外接監視IC具備看門狗，以避免兩者因共同的原因而停止。

常見問題

看門狗計時器的 kick 或 feed 是什麼意思？

指寫入看門狗的重新載入或服務暫存器，使其計數器在到期之前重新開始。正常的軟體會定期這麼做；一旦停止，看門狗就會重設晶片。

可以在計時器中斷裡 kick 看門狗嗎？

不應無條件這麼做。即使主程式已經當機，計時器中斷仍會持續執行，因此會掩蓋故障；應在確認主迴圈與各任務都已完成正常的一個循環後才 kick。

視窗看門狗和一般看門狗有什麼差別？

一般看門狗只在 kick 太晚時重設。視窗看門狗還會把太早到來的 kick 視為故障，可抓到異常快速迴圈的程式。
