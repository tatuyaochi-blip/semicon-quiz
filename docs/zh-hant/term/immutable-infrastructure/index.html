什麼是不可變基礎設施

一旦建立的伺服器（虛擬機器或容器）就不再修改，需要更新時，從加入變更的映像檔建立新的伺服器來替換，並丟棄舊伺服器的營運想法。所有伺服器都由同一個映像檔建立，因此能防止手動作業的差異累積造成各伺服器的組成不一致，只要回到前一個映像檔就能輕易還原。日誌與資料等需要保留的東西，放在伺服器以外的儲存空間或資料庫中。

日文名稱: イミュータブルインフラストラクチャ

「不可變基礎設施」出現在1領域的1道練習題中（雲端與容器基礎等）。

這個名詞所屬的領域: 雲端與容器基礎

練習不可變基礎設施的題目

依不可變基礎設施的想法，更新正式環境伺服器軟體的方法，下列何者適當？

  1. A以 SSH 登入執行中的正式環境伺服器，更新套件後重新啟動服務
  2. B從加入更新的新映像檔建立新的伺服器並切換過去，舊伺服器不做修改直接丟棄
  3. C在不停止正式環境伺服器的情況下手動改寫設定檔，並把變更內容記錄在作業紀錄中
查看答案與解析

正確答案：B. 從加入更新的新映像檔建立新的伺服器並切換過去，舊伺服器不做修改直接丟棄

在不可變基礎設施中，一旦建立的伺服器（虛擬機器或容器）就不再修改，需要變更時，從加入變更的映像檔建立新的伺服器來替換。每台伺服器都由同一個映像檔建立，因此能防止手動作業的差異累積，造成各伺服器的組成不一致。發生問題時，只要從前一個映像檔重新建立就能還原。日誌與資料等需要保留的東西，要放在伺服器以外的儲存空間或資料庫中。
