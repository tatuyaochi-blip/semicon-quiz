什麼是RSA加密

由Rivest、Shamir、Adleman於1977年提出的公開金鑰加密。以兩個大質數 p、q 的乘積 n 與公開指數 e 為公開金鑰，以滿足 e × d ≡ 1 (mod (p − 1)(q − 1)) 的 d 為私密金鑰。加密為 c = m^e mod n，解密為 m = c^d mod n。安全性的根據在於 n 的質因數分解很困難，可同時用於加密與簽章。實際上要與OAEP或PSS這類含亂數的填充搭配使用。

以小數字為例

若 p = 5、q = 11，則 n = 55，(p − 1)(q − 1) = 40。設 e = 3，因為 3 × 27 = 81 ≡ 1 (mod 40)，所以 d = 27。明文 m = 7 加密為 7³ = 343 ≡ 13 (mod 55)，計算 13^27 mod 55 就會還原為7。

金鑰長度與安全性

在NIST SP 800-57的表中，2048位元的 n 相當於112位元、3072位元相當於128位元安全性的參考值。以相同安全性比較，需要比橢圓曲線密碼長得多的金鑰與簽章，金鑰產生與簽章的計算也較重。公開指數常用計算較快的65537（2^16 + 1）。

用法的變化

過去的TLS廣泛使用由用戶端把金鑰材料以伺服器的RSA公開金鑰加密後傳送的金鑰交換，但因為沒有前向保密，在TLS 1.3中已被廢除。目前RSA主要用於憑證與軟體的簽章。一旦大規模量子電腦實現，就會被Shor演算法破解，因此正在推動遷移到後量子密碼學。

練習RSA加密的題目

以小數字確認RSA加密的機制。由質數 p = 5、q = 11 作出 n = pq，公開指數設為 e = 3。令 φ(n) = (p − 1)(q − 1)，滿足 e × d ≡ 1 (mod φ(n)) 的私密指數 d（0 < d < φ(n)）為下列何者？

  1. A5
  2. B27
  3. C37
查看答案與解析

正確答案：B. 27

n = 5 × 11 = 55，φ(n) = 4 × 10 = 40。尋找使 3 × d 除以40餘1的 d，因為 3 × 27 = 81 = 2 × 40 + 1，所以 d = 27。公開金鑰為 (n, e) = (55, 3)，私密金鑰為 d = 27；不知道 p 與 q 就無法得知 φ(n)，也就求不出 d，這就是安全性的根據。實際的RSA加密中，p 與 q 各是超過1000位元的大質數，e 常使用65537。

在RSA加密中，設公開金鑰為 n = 55、e = 3。以 c = m^e mod n 加密明文 m = 7 時的密文 c 為下列何者？

  1. A13
  2. B21
  3. C23
查看答案與解析

正確答案：A. 13

7³ = 343，而 343 = 6 × 55 + 13，因此 c = 13。對應此公開金鑰的私密指數為 d = 27（p = 5、q = 11、φ(n) = 40，3 × 27 ≡ 1），計算 13^27 mod 55 就會還原成原本的明文7。加密只需要公開金鑰，但解密需要 d。

常見問題

為什麼 p 與 q 必須保密？

因為知道 p 與 q 就能計算 (p − 1)(q − 1)，再由公開的 e 求出 d。n 是公開的，所以安全性依賴於對 n 做質因數分解的困難度。

為什麼不直接用RSA加密檔案？

因為RSA一次只能加密小於 n 的數，計算也比對稱式加密重得多。實際上是以AES等對稱式加密來加密檔案，只用公開金鑰保護那把對稱金鑰，這稱為混合加密方式。
