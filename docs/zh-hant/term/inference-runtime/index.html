什麼是推論執行環境（Inference runtime）

載入已訓練的模型，進行圖的最佳化、量化、選擇適合硬體的核心函式等，以快速執行推論的軟體。

日文名稱: 推論ランタイム

「推論執行環境（Inference runtime）」出現在1領域的2道練習題中（AI硬體與軟體堆疊等）。

這個名詞所屬的領域: AI硬體與軟體堆疊

練習推論執行環境（Inference runtime）的題目

TensorRT或ONNX Runtime這類推論執行環境，比直接用訓練用框架進行推論更快，其主要原因為下列何者？

  1. A因為會將計算圖最佳化為僅推論所需的形式，進行運算融合、量化、選擇適合硬體的kernel等
  2. B因為推論執行環境會省略計算，給出大致的答案
  3. C因為推論執行環境會增加模型的權重數量
查看答案與解析

正確答案：A. 因為會將計算圖最佳化為僅推論所需的形式，進行運算融合、量化、選擇適合硬體的kernel等

訓練用框架重視寫法的靈活性以及為反向傳播所做的記錄，因此只用於推論時會有浪費。推論執行環境載入模型後，會去除推論不需要的部分、融合運算，並視需要將權重或啟動值轉為較低的精度，再為目標GPU或NPU選擇最快的kernel。如此一來，即使是相同的模型，也能大幅降低延遲與記憶體用量。

解析中的「推論執行環境（Inference runtime）」

  • 推論執行環境載入模型後，會去除推論不需要的部分、融合運算，並視需要將權重或啟動值轉為較低的精度，再為目標GPU或NPU選擇最快的kernel。
