什麼是IPC

為 Instructions Per Cycle 的縮寫，指每個時脈可執行的指令數。表示 CPU 設計上的效率，性能大致為 IPC 與時脈頻率的乘積。其倒數是 CPI。

日文名稱: IPC

「IPC」出現在2領域的5道練習題中（CPU與架構, 效能評估與效能剖析等）。

這個名詞所屬的領域: CPU與架構

練習IPC的題目

以效能計數器測量後，發現某程式的IPC（每個週期的指令數）非常低，為0.3，且最後一級快取的失誤很多。下列何者是最可能的狀況與對策的組合？

  1. A因等待記憶體，CPU停滯的時間很長。改變資料的排列方式或進行分塊（blocking），以有效利用快取
  2. B運算太快了。提高頻率
  3. C分支太少了。增加分支
查看答案與解析

正確答案：A. 因等待記憶體，CPU停滯的時間很長。改變資料的排列方式或進行分塊（blocking），以有效利用快取

現今的CPU每個週期可執行數個指令，所以IPC為0.3表示大部分時間都在等待某些東西。若最後一級快取的失誤很多，就可以認為是在長時間等待來自主記憶體的資料。將資料排在連續的位址、改變迴圈的順序、藉由分塊重複使用同樣的資料等，來減少快取失誤是有效的。
