什麼是順向偏壓

對 p 側施加正電壓、對 n 側施加負電壓。位障降低，電流容易流動。反過來施加則為逆向偏壓，幾乎沒有電流流動。

日文名稱: 順方向バイアス

「順向偏壓」出現在4領域的10道練習題中（雙載子電晶體, PN接面與二極體, 半導體物性等）。

這個名詞所屬的領域: PN接面與二極體

練習順向偏壓的題目

對PN接面二極體施加順向偏壓時，下列哪一種電壓施加方式正確？

  1. Ap側為正、n側為負
  2. Bp側為負、n側為正
  3. Cp側與n側為相同電位
查看答案與解析

正確答案：A. p側為正、n側為負

當p側（陽極）為正、n側（陰極）為負時，外部電壓的方向會抵消內建電位，使電位障壁降低，多數載子越過接面注入到對側。這就是順向偏壓，電流會隨電壓呈指數函數增加。反接時障壁變高，只有熱產生的少數載子形成極小的電流。在相同電位下，擴散與漂移達到平衡，電流為0。

在順向偏壓的PN接面中，因注入的少數載子累積而產生的電容為下列何者？

  1. A擴散電容
  2. B接面電容（空乏區電容）
  3. C配線電容
查看答案與解析

正確答案：A. 擴散電容

在順向偏壓下，接面兩側注入並累積少數載子，其量會隨電壓變化而改變，因此發揮電容的作用。這就是擴散電容，大致與電流成正比增大（Cd ≈ τI/(nkT/q)），在大電流下可達數nF。在逆向偏壓下占主導的是由空乏區形成的接面電容。擴散電容是限制二極體與雙極性電晶體高速運作的因素。

解析中的「順向偏壓」

  • 這就是順向偏壓，電流會隨電壓呈指數函數增加。

    對PN接面二極體施加順向偏壓時，下列哪一種電壓施加方式正確？

  • 在順向偏壓下，接面兩側注入並累積少數載子，其量會隨電壓變化而改變，因此發揮電容的作用。

    在順向偏壓的PN接面中，因注入的少數載子累積而產生的電容為下列何者？

  • 在PN接面中，平衡狀態下這兩者剛好互相抵消而使電流為0，順向偏壓時則擴散電流占優勢而有電流流動。

    半導體中擴散電流會流動的原因，下列何者正確？

  • 在主動區，基極-射極接面為順向偏壓，使電子從射極注入基極；基極-集極接面為逆向偏壓，以強電場將穿過基極的電子拉往集極。

    NPN電晶體用於放大（在主動區工作）時，正確的偏壓條件是哪一個？

  • 當作開關使用時，關閉為兩個接面皆為逆向偏壓的截止區，導通為兩者皆為順向偏壓的飽和區。

    將雙極性電晶體當作開關使用時，對應於導通狀態的工作區是哪一個？
