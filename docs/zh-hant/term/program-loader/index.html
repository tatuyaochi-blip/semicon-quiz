什麼是載入器（Loader）

將可執行檔讀入記憶體，依權限配置各個部分，並在堆疊上準備好引數等資料後啟動程式的作業系統功能。

日文名稱: ローダ

「載入器（Loader）」出現在1領域的5道練習題中（連結器與載入器與執行檔格式等）。

這個名詞所屬的領域: 連結器與載入器與執行檔格式

練習載入器（Loader）的題目

啟動程式時（Linux的execve等），作業系統的載入器所進行的事項，下列何者正確？

  1. A讀取原始碼，當場編譯後再執行
  2. B依照執行檔的程式標頭，將各部分配置到記憶體，並在堆疊上準備引數等，再從入口位址開始執行
  3. C先將執行檔的所有符號名稱顯示在畫面上再執行
查看答案與解析

正確答案：B. 依照執行檔的程式標頭，將各部分配置到記憶體，並在堆疊上準備引數等，再從入口位址開始執行

載入器會讀取執行檔的標頭，將程式標頭所記載的各部分（區段，segment）附上讀取、寫入、執行的權限，對應到虛擬位址空間。接著準備BSS用的0值區域與堆疊，並將命令列引數與環境變數推入堆疊。若是動態連結，就從動態連結器開始，否則從執行檔的入口位址開始執行。

解析中的「載入器（Loader）」

  • 載入器會讀取執行檔的標頭，將程式標頭所記載的各部分（區段，segment）附上讀取、寫入、執行的權限，對應到虛擬位址空間。

    啟動程式時（Linux的execve等），作業系統的載入器所進行的事項，下列何者正確？

  • 開頭的ELF標頭記載了目標CPU、是否為64位元、開始執行的位址等，其後接著.text、.data等區段，以及表示載入器要載入記憶體之單位的程式標頭（program header）。

    關於Linux等系統常用的ELF格式檔案，下列何者正確？

  • 若內容全部為0，將一長串0存入檔案是浪費，因此.bss區段只記錄大小，由載入器配置記憶體並以0填滿。

    關於.bss區段的特徵，下列何者正確？

  • 在個人電腦的作業系統中，位址是由載入器決定的，但在微控制器上，通電那一刻的位址就是直接使用的位址。

    關於嵌入式開發中使用的連結器腳本（linker script）的功用，下列何者正確？

  • 載入器則以程式標頭所記載的段為單位對應到記憶體，例如將.text與.rodata彙整到可讀取與執行的段，將.data與.bss彙整到可讀寫的段。
