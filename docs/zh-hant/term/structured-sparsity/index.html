什麼是結構化稀疏（Structured sparsity）

將權重的 0 排列成固定形式的稀疏。例如每 4 個權重中有 2 個為 0 的 2:4 稀疏，在矩陣運算單元上可加速約 2 倍。

日文名稱: 構造化スパース

「結構化稀疏（Structured sparsity）」出現在1領域的1道練習題中（AI硬體與軟體堆疊等）。

這個名詞所屬的領域: AI硬體與軟體堆疊

練習結構化稀疏（Structured sparsity）的題目

關於GPU的矩陣運算單元所支援的「2:4結構化稀疏」，下列說明何者正確？

  1. A將權重每4個分為一組，每組中有2個設為0的固定形式稀疏，矩陣運算單元可跳過0，最多約能以2倍的速度計算
  2. B從權重中每次隨機選出四分之二來計算
  3. C將矩陣分成2列4行來計算
查看答案與解析

正確答案：A. 將權重每4個分為一組，每組中有2個設為0的固定形式稀疏，矩陣運算單元可跳過0，最多約能以2倍的速度計算

在2:4稀疏中，會透過訓練或調整，使連續4個權重之中必定有2個為0。只需持有非0的2個值，以及表示其位置的少量資訊，因此記憶體減少，矩陣運算單元可跳過0的乘法，以約2倍的速度計算。藉由採用固定形式，實現了零散稀疏難以達成的硬體加速。
