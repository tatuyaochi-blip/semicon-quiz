什麼是伺服器端算繪（SSR）

每次收到請求時，都在伺服器產生網頁的HTML並回傳的方式。瀏覽器可以立即顯示收到的HTML，因此首次顯示快，內容也容易傳達給搜尋引擎。只送出最少的HTML與JavaScript、在瀏覽器中組成網頁的是用戶端算繪（CSR），在建置時就預先產生所有網頁之HTML的是靜態網站產生（SSG）。也有許多架構在顯示伺服器產生的HTML之後，再以JavaScript讓網頁可以操作。

日文名稱: サーバサイドレンダリング(SSR)

「伺服器端算繪（SSR）」出現在1領域的1道練習題中（Web技術基礎等）。

這個名詞所屬的領域: Web技術基礎

練習伺服器端算繪（SSR）的題目

製作網站網頁的方式之中，在建置階段就預先產生所有網頁的HTML檔案，對請求直接回傳這些檔案的方式為下列何者？

  1. ACSR（用戶端算繪）
  2. BSSR（伺服器端算繪）
  3. CSSG（靜態網站產生）
查看答案與解析

正確答案：C. SSG（靜態網站產生）

以SSG製作的網站是靜態網站，不會在每次請求時於伺服器上執行程式，因此能從提供靜態檔案的主機服務或CDN直接快速傳送，可被攻擊的部分也較少。例如在建置時由內容資料產生題目與詞彙表的網頁並加以傳送的網站就屬於這種，內容改變時再重新產生。SSR是每次請求時在伺服器產生HTML的動態方式，CSR則是送出最少的HTML與JavaScript，在瀏覽器中組成網頁的方式。
