什麼是組態管理（Configuration management）

識別構成IT服務的要素（組態項目，CI），並正確記錄其屬性（版本、設置地點、負責人等）以及與其他CI之間的關係，使其保持最新狀態的流程。記錄這些資訊的資料庫稱為CMDB（組態管理資料庫）。CI包括伺服器與網路設備、軟體、文件，以及服務本身等。掌握CI之間的關係，就容易調查故障的影響範圍與變更的影響。

  1. A將服務台收到的詢問件數，依月份與服務別加以統計的表格
  2. B提供服務所需並列為管理對象的硬體、軟體、文件等組成要素，並記錄其版本、設置地點以及與其他CI的關係
  3. C使用者個人購買並用於業務、組織既不掌握也不管理的軟體
