什麼是SystemVerilog

擴充 Verilog 的語言。具有 logic 型別與 always_ff、always_comb 等設計功能，以及類別、受限隨機、斷言等驗證功能。

日文名稱: SystemVerilog

「SystemVerilog」出現在2領域的10道練習題中（硬體描述語言與驗證, LSI設計流程與EDA等）。

這個名詞所屬的領域: 硬體描述語言與驗證

SystemVerilog 在設計方面新增了什麼

SystemVerilog 標準化為 IEEE 1800，是 Verilog 的超集，同時加入了撰寫硬體與驗證硬體的功能。在設計方面，logic 型別取代了 Verilog 中容易混淆的 wire 與 reg 區分，用於單一驅動源的訊號；always_ff、always_comb 與 always_latch 表明預期的硬體；enum、struct、package 與 interface 則讓 RTL 更易讀、更不易出錯。在 Verilog 中，reg 只代表在 always 區塊中被指定的訊號，不一定是正反器。具有多個驅動源的訊號（例如三態匯流排）仍使用 wire，而 logic 是能保存 X 與 Z 的四值型別。

及早抓出 RTL 錯誤

Verilog 常見的錯誤是非預期的鎖存器：組合邏輯 always 區塊若在某條路徑上沒有指定輸出，工具就必須記住舊值。標準的解法是在區塊開頭為每個輸出指定預設值。使用 always_comb 時，工具也知道設計者想要的是組合邏輯，在推論出鎖存器時會發出警告或錯誤，而且敏感列表會依讀取的訊號自動推導，避免手寫列表遺漏訊號的錯誤。always_ff 同樣會標示出無法對應到邊緣觸發正反器的程式碼。

驗證功能

SystemVerilog 新增的大部分功能是給測試平台用的。類別帶來物件導向程式設計；受限隨機產生能產生合法的激勵，例如字組對齊的位址或 1 到 256 的長度；covergroup 量測功能覆蓋率，顯示哪些情況已被測試到；SystemVerilog 斷言（SVA）則表達時序性質，例如在請求後 3 個週期內必須回應，可在模擬中檢查或由形式驗證工具證明。時脈區塊（clocking block）定義測試平台訊號的驅動與取樣時間點，防止與設計之間發生競爭。通用驗證方法學（UVM，IEEE 1800.2）就是在這些功能之上建構可重用的測試平台。

可合成程式碼與僅供測試平台的程式碼

SystemVerilog 只有一部分是用來描述硬體的。可合成子集包括 logic、always_ff、always_comb、enum、struct、package 與 interface，能被邏輯合成工具接受並轉換為邏輯閘。類別、隨機化、覆蓋率以及大部分動態資料型別只存在於模擬中，用來描述設計周圍的環境。斷言可以綁定到 RTL，用於模擬、形式驗證，有時也用於硬體模擬加速器（emulation），但不會被轉換為功能邏輯。VHDL 仍是主要的替代語言，在部分 FPGA 與航太團隊中尤其如此。

正確答案：C. UVM（Universal Verification Methodology）

UVM是用SystemVerilog將測試平台建構為零件（提供輸入的驅動器、監視輸出的監視器、與期望值比對的計分板等）組合的標準方法論與類別庫。零件可重複用於其他設計的驗證，也容易內建帶限制的隨機輸入產生與覆蓋率的收集。已標準化為IEEE 1800.2。OPC與CMP是製造的技術。

  2. B完全隨意地產生輸入的值，並給予許多規格中沒有的值
  3. C輸入的值全部由人以手工撰寫

正確答案：A. 在規格允許的範圍或組合條件（約束）之內隨機產生輸入的值，連人想不到的情況也廣泛地嘗試

只靠人設計的測試（指定型測試），容易漏掉設計者未預期的組合所造成的缺陷。在約束隨機驗證中，會寫下例如「位址是4的倍數」「長度為1～256」之類的約束，並在其中隨機產生輸入，因此只用有意義的輸入就能嘗試許多情況。嘗試了哪些情況以覆蓋率（coverage）來衡量，不足的部分則透過變更約束，或以指定型測試來補足。

常見問題

Verilog 和 SystemVerilog 有什麼差別？

SystemVerilog 是 Verilog 的超集，加入了 logic、always_ff、always_comb 等更安全的設計語法，以及類別、受限隨機激勵、功能覆蓋率與斷言等驗證功能。既有的 Verilog 程式碼一般也是合法的 SystemVerilog。

SystemVerilog 可以合成嗎？

其設計子集可以，包括 logic、always_ff、always_comb、struct、enum 與 interface。類別、隨機化與 covergroup 等驗證語法僅供模擬使用。

應該用 logic 取代 wire 和 reg 嗎？

對於只有單一驅動源的訊號，無論由 assign 敘述還是 always 區塊驅動，logic 都適用，因此在大多數程式碼中可同時取代兩者。具有多個驅動源的線網（例如三態匯流排）則使用 wire。
