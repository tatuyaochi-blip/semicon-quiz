什麼是ULPA濾網

可捕集比HEPA濾網更微細粒子的高性能空氣濾網。用於高潔淨度無塵室的天花板。

日文名稱: ULPAフィルタ

「ULPA濾網」出現在2領域的6道練習題中（無塵室與製造設備, 環境安全等）。

這個名詞所屬的領域: 無塵室與製造設備

練習ULPA濾網的題目

用來去除潔淨室空氣中微粒的高效率濾網是下列何者？

  1. A低通濾波器
  2. B彩色濾光片
  3. CULPA濾網（HEPA濾網）
查看答案與解析

正確答案：C. ULPA濾網（HEPA濾網）

HEPA濾網以及性能更高的ULPA濾網，是以折疊的細玻璃纖維等濾材捕捉空氣中微粒的空氣濾網，安裝在潔淨室的天花板等處。即使是比纖維間隙更小的粒子，也會因慣性與擴散而撞上纖維被捕捉。低通濾波器是在電路中去除高頻的電路，彩色濾光片則是影像感測器等用來分離顏色的零件。

在潔淨室中，向空氣供應離子以中和晶圓與設備帶電的裝置是下列何者？

  1. AULPA濾網
  2. B離子產生器（除靜電裝置）
  3. C洗滌塔（scrubber）
查看答案與解析

正確答案：B. 離子產生器（除靜電裝置）

在乾燥的潔淨室中容易產生靜電，帶電的晶圓與光罩會吸引微粒，也可能因靜電放電而損傷元件或光罩的圖案。離子產生器以電暈放電等方式產生正負離子並供應到空氣中，中和物體的帶電。對於無法接地的絕緣物，尤其有效。ULPA濾網用於去除粒子，洗滌塔則用於清洗排氣。
