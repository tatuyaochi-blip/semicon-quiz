什麼是SPI

配合主控端發出的時脈同時進行傳送與接收的同步序列通訊。以晶片選擇線選擇對象，用於連接高速的元件。

日文名稱: SPI

「SPI」出現在2領域的5道練習題中（嵌入式與韌體, CPU與架構等）。

這個名詞所屬的領域: 嵌入式與韌體

訊號與移位暫存器模型

SPI 使用由主控端驅動的時脈（SCLK）、主控端到從屬端的資料線（MOSI，也稱為 COPI 或 SDO）、從屬端到主控端的資料線（MISO，也稱為 CIPO 或 SDI），以及每個從屬端各一條的低態有效晶片選擇線（CS）。在內部，主控端與從屬端各有一個移位暫存器，兩個暫存器構成一個環：每個時脈都有一個位元離開主控端，同時有一個位元進入主控端。因此傳輸一定是全雙工。要從元件讀取資料時，主控端仍必須送出位元組（通常是虛擬位元組）來產生時脈。SPI 沒有位址也沒有應答；選擇元件完全靠其 CS 線。

時脈極性與相位：四種模式

SPI 模式由兩項設定決定。CPOL 設定時脈的閒置位準，CPHA 則選擇在 CS 啟動後的第一個還是第二個時脈邊緣取樣資料。四種組合即模式 0 到 3；模式 0 中時脈閒置為低準位、在上升邊緣取樣，模式 3 中時脈閒置為高準位，同樣在上升邊緣取樣。若主控端與元件的設定不一致，取樣會偏移半個時脈週期，導致位元錯位或亂碼，因此規格書上的模式、位元順序與最高時脈速率是首先要確認的項目。

SPI 與 I2C、UART 的比較

SPI 的推挽式輸出與專用線路允許數十 MHz 的時脈速率，這就是快閃記憶體、顯示器與高速 ADC 使用它的原因。代價是佈線：每多一個元件就需要多一條 CS 線。I2C 讓多個元件共用兩條帶上拉電阻的開汲極線路，以位址選擇元件並對每個位元組應答，但上拉電阻使其速度限制在約 100 kHz 到數 MHz。UART 以非同步方式只連接兩個元件，沒有時脈線，仰賴雙方約定相同的鮑率。選擇取決於速度、接腳數以及元件所支援的介面。

會遇到的變體

序列快閃記憶體與部分顯示器擴充了基本架構。Dual SPI 與 Quad SPI 將資料線變成兩條或四條雙向線路，使讀取的傳輸量倍增，部分微控制器甚至可以直接從 Quad SPI 快閃記憶體執行程式碼。多個元件也可以串接成菊鍊，讓資料依序通過每個移位暫存器，使它們共用一條 CS。由於 SPI 沒有內建的流量控制或錯誤檢查，建構在其上的協定常會加入狀態暫存器、忙碌旗標或檢查碼。

練習SPI的題目

關於SPI通訊的特徵，下列何者正確？

  1. A不使用時脈的非同步式，只以2條線連接
  2. B由主控端輸出時脈的同步式，可同時進行傳送與接收，並以晶片選擇線選擇對象
  3. C以位址選擇對象，所以不論連接幾台，線都只需2條
查看答案與解析

正確答案：B. 由主控端輸出時脈的同步式，可同時進行傳送與接收，並以晶片選擇線選擇對象

SPI是配合主控端輸出的時脈，以主控端到從屬端的線和從屬端到主控端的線同時互相傳送資料的同步式通訊。每個對象備有晶片選擇（CS）線，只與設為0的對象通訊。由於結構簡單，時脈可提高到數十MHz，因此常與快閃記憶體、顯示裝置、ADC等高速元件連接。

SPI一般使用的4條訊號的組合，下列何者正確？

  1. ASDA與SCL 2條，加上電源與接地
  2. BSCLK（時脈）、MOSI（主控端輸出）、MISO（主控端輸入）、CS（晶片選擇）
  3. CTX與RX 2條，加上RTS與CTS
查看答案與解析

正確答案：B. SCLK（時脈）、MOSI（主控端輸出）、MISO（主控端輸入）、CS（晶片選擇）

在SPI中，主控端在SCLK輸出時脈，以MOSI（Master Out Slave In）傳送資料，同時以MISO（Master In Slave Out）接收資料。CS是選擇與哪個從屬端通訊的線，若有3台從屬端，CS也需要3條。近來也使用COPI、CIPO或SDO、SDI等名稱來取代MOSI、MISO。

常見問題

SPI 需要幾條線？

基本的 SPI 使用 SCLK、MOSI、MISO 與 CS 四個訊號，再加上接地。每多一個從屬端通常需要自己的 CS 線，而三線式變體則將兩條資料線合併為一條。

SPI 模式 0 是什麼？

模式 0 表示 CPOL = 0 且 CPHA = 0：時脈閒置為低準位，並在上升邊緣取樣資料。它是支援最廣泛的模式，但應使用哪種模式，取決於元件的規格書。

SPI 比 I2C 快嗎？

一般來說是。SPI 的推挽式傳訊通常可運作在數十 MHz，而開汲極的 I2C 匯流排通常在約 100 kHz 到數 MHz 之間。
