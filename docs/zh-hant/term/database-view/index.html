什麼是檢視表

在關聯式資料庫中，為SELECT敘述命名而定義的虛擬表格。通常本身不保存資料，每次被參照時才從原始表格產生結果。用來簡化複雜的查詢，或限制顯示的欄位與資料列以限制可存取的範圍。

日文名稱: ビュー

「檢視表」出現在1領域的2道練習題中（資料庫基礎等）。

這個名詞所屬的領域: 資料庫基礎

練習檢視表的題目

關於關聯式資料庫的檢視表，下列敘述何者正確？

  1. A以SELECT敘述定義的虛擬表格，通常本身不保存資料，每次被參照時才從原始表格產生結果
  2. B複製並保存原始表格資料的表格，即使變更原始表格，檢視表的內容也不會改變
  3. C為了快速尋找表格中特定欄位的值而建立的樹狀結構資料
查看答案與解析

正確答案：A. 以SELECT敘述定義的虛擬表格，通常本身不保存資料，每次被參照時才從原始表格產生結果

檢視表是像 CREATE VIEW 業務人員 AS SELECT 員工編號, 姓名 FROM 員工 WHERE 部門 = '業務' 這樣，為SELECT敘述命名而定義的虛擬表格。一般的檢視表本身不保存資料，每次參照檢視表時才從原始表格（基底表格）產生結果，因此更新原始表格後，檢視表的內容也會直接反映。檢視表可用來讓常用的複雜查詢寫得更簡單，或只把允許查看的欄位與資料列做成檢視表並授予使用者權限，以限制可存取的範圍。另外也有事先計算並保存結果的具體化檢視表，讀取較快，但需要配合原始表格更新內容。用來快速尋找值的樹狀結構，是索引的說明。

解析中的「檢視表」

  • 檢視表是像 CREATE VIEW 業務人員 AS SELECT 員工編號, 姓名 FROM 員工 WHERE 部門 = '業務' 這樣，為SELECT敘述命名而定義的虛擬表格。
