什麼是資料平行（Data parallelism）

各 GPU 持有整個模型的副本，分割資料進行運算，並在所有 GPU 上平均梯度後再更新權重的分散式訓練方法。

日文名稱: データ並列

「資料平行（Data parallelism）」出現在3領域的5道練習題中（AI硬體與軟體堆疊, CPU與架構, GPU程式設計等）。

練習資料平行（Data parallelism）的題目

關於以多顆GPU訓練的資料平行，下列說明何者正確？

  1. A各GPU持有整個模型的副本，將資料分開計算，把求得的梯度在所有GPU上取平均後再更新權重
  2. B將模型的層分開，由各GPU負責不同的層
  3. C只用一顆GPU計算，其餘的GPU作為備用
查看答案與解析

正確答案：A. 各GPU持有整個模型的副本，將資料分開計算，把求得的梯度在所有GPU上取平均後再更新權重

在資料平行中，所有GPU都持有相同的模型，將訓練資料的批次分開，各自進行順向傳播與反向傳播。由於各GPU的梯度不同，要進行將所有GPU的梯度加總並取平均的通訊（All-Reduce），讓大家以相同的梯度更新權重，使模型的副本保持一致。若模型能放進一顆GPU，這種方式簡單又有效，但GPU數量增加時通訊會變得沉重。

    以一道指令同時對多筆資料進行相同運算的方式是下列何者？

  • GPU會將相同的處理分配給數千個執行緒並行執行，因此在可獨立計算大量元素的工作（資料平行）上能發揮威力，例如影像各像素的處理、矩陣乘法、向量運算。
