什麼是邏輯合成

將以RTL描述的電路，轉換為使用標準元件庫閘級元件之網表的設計步驟。

閱讀入門解說: 積體電路（IC）是什麼？晶片、晶粒、LSI、SoC的差異

日文名稱: 論理合成

「邏輯合成」出現在3領域的24道練習題中（LSI設計流程與EDA, 硬體描述語言與驗證, 邏輯電路等）。

這個名詞所屬的領域: LSI設計流程與EDA

合成工具做什麼

邏輯合成需要三項輸入：以硬體描述語言撰寫的 RTL、描述每個邏輯閘功能、時序、面積與功耗的元件庫，以及時脈週期與 I/O 延遲等約束條件（通常為 SDC 格式）。工具先將 RTL 轉譯成通用邏輯，推論出暫存器、多工器與算術運算子。接著在與製程技術無關的情況下最佳化布林邏輯，再將其對應到元件庫的元件，最後調整元件尺寸、插入緩衝器並重組路徑，以滿足約束條件。輸出為邏輯閘層級的網表（netlist），以及時序、面積與功耗報告。

RTL 如何變成硬體

合成是把程式碼變成電路，而不是指令，因此每個區塊都是同時運作的。always @(posedge clk) 區塊會變成邊緣觸發正反器。若組合邏輯區塊沒有在每個分支都對輸出賦值，例如有 if 而沒有 else，工具就不得不推論出閂鎖器來保持舊值。合成會忽略敏感列表，因此敏感列表不完整時，模擬結果會與邏輯閘不一致；使用 @(*) 可避免這個問題。#10 這類延遲與 $display 這類測試平台工作只用於模擬，會被忽略。

約束條件決定結果

同一份 RTL 可能產生截然不同的網表。嚴格的時脈會迫使工具選用較大、較快的元件、低臨界電壓元件與平行結構，例如以前瞻進位加法器取代漣波進位加法器，使面積與漏電增加；寬鬆的時脈則讓工具能將面積最小化。偽路徑與多週期路徑告訴工具哪些地方不必花力氣。錯誤的約束條件很危險：設計可能通過所有工具檢查，實際製成矽晶片後卻失效。由於佈局前的導線延遲只是估計值，具實體感知的合成會利用擺置資訊來改善相關性。

合成在設計流程中的位置

典型流程依序為規格、RTL 設計、邏輯合成、佈局繞線、寄生參數萃取，以及在投片（tape-out）前的簽核時序分析。高階合成（HLS）位於其上層，藉由將運算排程到各個時脈週期，從 C 或 C++ 產生 RTL；之後再由邏輯合成把 RTL 變成邏輯閘。形式等價性檢查不需模擬，就能證明網表實現了與 RTL 相同的邏輯。用於測試的掃描鏈插入，通常在合成期間或合成後立即進行。對 FPGA 而言，合成是把邏輯對應到查找表與正反器，而不是標準元件。

  2. B將RTL的描述轉換為由單元庫的邏輯閘所構成之網表的步驟
  3. C將電路圖案轉印到晶圓上的步驟

正確答案：B. 將RTL的描述轉換為由單元庫的邏輯閘所構成之網表的步驟

邏輯合成是將以RTL撰寫的電路動作描述，轉換為單元庫中邏輯閘與正反器的連接資訊（網表）的設計步驟。給定時序、面積、耗電量的限制條件後，工具會簡化邏輯式，並選擇驅動力適當的單元，進行最佳化以滿足限制條件。排列單元並繞線的是佈局繞線，轉印到晶圓上的則是微影。

不使用模擬，而以數學方式確認邏輯合成前後電路邏輯沒有改變的方法，為下列何者？

  1. A形式等價性驗證（形式驗證）
  2. BDRC
  3. C切割（dicing）
查看答案與解析

正確答案：A. 形式等價性驗證（形式驗證）

形式等價性驗證是以數學方法，全面確認兩個電路是否實現相同邏輯函數的驗證。不需要準備測試圖樣，就能保證所有輸入組合的等價性，因此用於邏輯合成、佈局繞線、ECO前後的確認。若以模擬嘗試所有組合，輸入只要有數十位元就不可能做到。DRC是檢查圖形規則。

常見問題

邏輯合成和高階合成有什麼差別？

高階合成把以 C 或 C++ 描述的演算法轉換成 RTL，並決定每個運算在哪個時脈週期執行。邏輯合成則把 RTL 轉換成由元件庫元件構成的邏輯閘層級網表。

為什麼合成會產生非預期的閂鎖器？

若組合邏輯區塊在某些路徑上沒有對輸出賦值，輸出就必須記住先前的值，而閂鎖器是唯一的實現方式。給定預設值或涵蓋所有情況即可消除。

邏輯合成的輸入和輸出是什麼？

輸入是 RTL、元件庫與時序約束條件（通常為 SDC）。輸出是邏輯閘層級的網表，以及時序、面積與功耗的報告。
