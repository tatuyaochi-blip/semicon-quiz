什麼是本體二極體

因功率 MOSFET 的結構，而在源極與汲極之間寄生形成的二極體。在變流器中可用作飛輪二極體，但需注意逆向恢復特性。

日文名稱: ボディダイオード

「本體二極體」出現在2領域的3道練習題中（功率半導體, 電力電子電路等）。

這個名詞所屬的領域: 功率半導體

本體二極體的由來

MOSFET是四端子元件：閘極、源極、汲極與本體。在垂直型n通道功率MOSFET中，源極金屬同時接觸n+源極與p型本體，主要目的是固定本體電位，讓由源極、本體與漂移區構成的寄生雙載子電晶體無法導通。本體與源極短路後，p型本體與n-漂移區之間的接面便連接在源極與汲極之間：形成一個陽極在源極、陰極在汲極的二極體，當汲極被拉到低於源極時就會導通。

飛輪與同步整流

在變流器與馬達驅動器中，開關關斷時，電感性負載的電流必須持續流動。在死區時間內，半橋的兩個開關都處於關閉狀態以防止上下臂直通（shoot-through），此時電流流經另一個MOSFET的本體二極體，因此本體二極體不需額外元件就能作為飛輪二極體。為了降低導通損耗，逆向導通期間通常會讓MOSFET通道導通，稱為同步整流，使電流流經低電阻的通道，而非承受二極體的順向壓降。

逆向恢復問題

本體二極體是雙極性的PN接面，因此導通時會在漂移區中儲存少數載子。當另一個開關導通、電壓反轉時，這些儲存電荷必須被掃出，產生逆向電流尖波，增加切換損耗、對開關造成應力，並引起振鈴與電磁干擾。矽功率MOSFET的逆向恢復相對較慢，因此高速切換的設計會盡量縮短二極體導通時間，或加裝外部快速二極體。SiC MOSFET的本體二極體儲存的電荷少得多，恢復也快得多。

SiC中的本體二極體劣化

SiC也有其特有的問題。由於能隙寬，SiC本體二極體的順向電壓高，通常約3 V以上，而且流經它的順向電流可能引發雙極性劣化：電子電洞復合所釋放的能量，會使晶體中的基面差排擴展成堆疊缺陷，這種平面缺陷會阻礙導通，使導通電壓隨時間上升。對策包括在磊晶成長時，以緩衝層將基面差排轉換為無害的類型，以及整合蕭特基二極體，讓本體二極體不必承載電流。

  1. A晶體中的基底面差排擴展成堆疊缺陷
  2. B閘極電極熔化
  3. C封裝發光
查看答案與解析

正確答案：A. 晶體中的基底面差排擴展成堆疊缺陷

當對SiC的本體二極體施加順向電流時，電子與電洞複合的能量可能使晶體中的基底面差排擴展成堆疊缺陷，導致導通電壓上升（雙極性劣化）。堆疊缺陷是阻礙導通的面狀缺陷。人們採取的對策包括：在磊晶成長過程中，以緩衝層將基底面差排轉換成其他種類差排；以及不依賴本體二極體，而是內建蕭特基二極體等。

常見問題

每個MOSFET都有本體二極體嗎？

任何MOSFET在本體與源極/汲極之間都有PN接面，但在分離式功率MOSFET中，本體與源極相接，因此其中一個接面就表現為源極與汲極之間的二極體。GaN HEMT沒有這種PN接面，因此沒有本體二極體，但仍可透過通道逆向導通。

本體二極體能取代外部飛輪二極體嗎？

通常可以，尤其是採用同步整流或SiC MOSFET時。若是本體二極體較慢的矽元件，高速切換電路可能會加裝外部快速二極體或蕭特基二極體，以限制逆向恢復損耗。

為什麼本體二極體會有逆向恢復？

它是雙極性的PN接面，順向導通時會在漂移區中儲存少數載子，這些電荷必須先被移除，二極體才能阻擋電壓，因而產生短暫的逆向電流。
