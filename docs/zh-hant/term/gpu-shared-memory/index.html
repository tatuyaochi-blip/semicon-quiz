什麼是共享記憶體（GPU shared memory）

位於 GPU 各 SM 內，可由同一區塊的執行緒共用的小型高速記憶體。由程式決定放置什麼內容。

日文名稱: シェアードメモリ

「共享記憶體（GPU shared memory）」出現在2領域的16道練習題中（GPU程式設計, AI硬體與軟體堆疊等）。

這個名詞所屬的領域: GPU程式設計

練習共享記憶體（GPU shared memory）的題目

關於CUDA共享記憶體（shared memory）的特徵，下列何者正確？

  1. A由所有GPU與CPU共享的大容量主記憶體
  2. BGPU記憶體與硬碟共享的區域
  3. C同一區塊的執行緒可共享、位於晶片上的小容量高速記憶體，由程式明確地使用
查看答案與解析

正確答案：C. 同一區塊的執行緒可共享、位於晶片上的小容量高速記憶體，由程式明確地使用

共享記憶體是位於各SM內、每個區塊數十KB左右的高速記憶體，讀寫速度比全域記憶體（GPU的DRAM）快數十倍。同一區塊的執行緒可以將資料放在其中共享，因此可用於從全域記憶體只讀入一次而重複使用，或讓執行緒之間傳遞中間結果等用途。與快取不同的是，要放什麼內容由程式決定。

關於CUDA共享記憶體的記憶庫衝突（bank conflict），下列說明何者正確？

  1. A兩個GPU使用同一個銀行帳戶的問題
  2. B共享記憶體容量不足而使程式停止的問題
  3. C共享記憶體分為32個記憶庫（bank），當線程束的多個執行緒同時讀取同一記憶庫中不同的位址時，存取會依序進行而變慢
查看答案與解析

正確答案：C. 共享記憶體分為32個記憶庫（bank），當線程束的多個執行緒同時讀取同一記憶庫中不同的位址時，存取會依序進行而變慢

共享記憶體由每4位元組依序分配的32個記憶庫構成，每個記憶庫一次只能讀寫一個位址。若線程束的32個執行緒使用各不相同的記憶庫，一次即可完成；但若有2個執行緒使用同一記憶庫的不同位址，就會分成2次。例如每隔32個元素讀取時，全員會集中在同一個記憶庫，而被分成32次。若全員讀取同一個位址，則是一併廣播，因此不會衝突。

解析中的「共享記憶體（GPU shared memory）」

  • 共享記憶體是位於各SM內、每個區塊數十KB左右的高速記憶體，讀寫速度比全域記憶體（GPU的DRAM）快數十倍。

    關於CUDA共享記憶體（shared memory）的特徵，下列何者正確？

  • 共享記憶體由每4位元組依序分配的32個記憶庫構成，每個記憶庫一次只能讀寫一個位址。

    關於CUDA共享記憶體的記憶庫衝突（bank conflict），下列說明何者正確？

  • 若分成圖塊讀入共享記憶體，區塊的所有執行緒就能反覆使用該圖塊，從全域記憶體讀取的量會隨圖塊大小成比例地減少。

    以GPU計算大型矩陣的乘積時，將矩陣分成小的圖塊（tile）讀入共享記憶體，其理由下列何者正確？

  • 若先將圖塊讀入共享記憶體，再交換執行緒的分工後讀出，對全域記憶體的讀取與寫入就都能使用連續的位址。

    以GPU轉置大型矩陣（b[j][i] = a[i][j]）時，經由共享記憶體的主要目的為下列何者？

  • 同一個區塊的執行緒會在同一個SM（運算單元的集合）上執行，可透過共享記憶體合作並進行同步。
