什麼是BGP（邊界閘道協定）

Border Gateway Protocol的縮寫。在網際網路上，於AS（自治系統，網路服務供應商等組織所管理的網路單位）之間交換路由資訊的路由協定。依據路由所附之經過AS的順序（AS_PATH）等屬性，以及各組織的政策選擇路由。路由器之間以TCP的179號連接埠連線交換資訊。

日文名稱: BGP

「BGP（邊界閘道協定）」出現在2領域的2道練習題中（電腦網路基礎, 網路設計與維運等）。

這個名詞所屬的領域: 網路設計與維運

AS與路徑向量

網際網路是由網路服務供應商與大型組織各自管理的許多AS（自治系統）連接而成，各AS以AS編號區分。BGP路由器以TCP與相鄰AS的路由器連線，互相通告「這個網路可經由這串AS到達」的路由。收到路由的路由器，若該順序中有自己的AS編號，就當作迴圈的路由丟棄。由於傳遞的不是路由的距離，而是經過的路徑，因此稱為路徑向量型。

屬性與路由的選擇方式

路由附有經過之AS的順序（AS_PATH）、下一跳（NEXT_HOP）、AS內的優先程度（LOCAL_PREF）、向相鄰AS表達希望入口的MED等屬性。同一目的地有多條路由時，依規定的順序比較這些屬性選出一條，AS_PATH的長短只是判斷依據之一。可以配合合約與費用等政策，決定要優先從哪個連接對象進來的路由，以及要把哪些路由通告給哪個對象，這是與組織內部使用之路由協定的一大差異。

eBGP與iBGP、維運上的注意

不同AS的路由器之間的BGP稱為eBGP，同一AS內部路由器之間的BGP稱為iBGP，iBGP用來把從外部學到的路由傳遍AS內部。BGP設定錯誤的影響很大，若誤把其他組織的位址通告出去，可能會從廣大範圍把送往該目的地的通訊吸引過來（路由劫持與洩漏）。因此會使用限制通告與接受之路由的過濾器，以及以數位簽章確認位址正當持有者的RPKI等對策。

正確答案：B. 路由器之間以路由協定交換路由資訊，當故障導致路由無法使用時，會自動切換到其他路徑

靜態路由是由管理者手動設定路由的方法。設定簡單、行為容易預測，適合小型網路或只有一個出口之據點的預設路由，但發生故障時不會自動切換。動態路由則由路由器以OSPF、BGP等路由協定交換資訊，自動建立路由表，鏈路斷線時會重新計算其他路徑。在網際網路上，組織網路（自治系統）之間的路由以BGP交換。實際的網路一般會將兩者組合使用。

在網際網路上，於網路服務供應商等組織所管理的網路單位（AS，自治系統）之間交換路由資訊，並依據經過之AS的順序（AS_PATH）等屬性與各組織的政策選擇路由的協定是下列何者？

  1. AOSPF
  2. BBGP
  3. CRIP
查看答案與解析

正確答案：B. BGP

BGP（Border Gateway Protocol，邊界閘道協定）是以AS編號區分的組織之間交換路由用的協定，網際網路上的路由基本上以BGP交換。路由附有經過之AS的順序（AS_PATH）與下一跳（NEXT_HOP）等屬性，路由器會丟棄含有自己AS編號的路由，以防止迴圈。選擇路由時，不只看AS_PATH的長短，還能以屬性表達要優先哪個連接對象等組織的政策並加以反映。OSPF與RIP是在一個組織內部使用的路由協定（IGP）。

常見問題

為什麼BGP對網際網路不可或缺？

網際網路沒有管理整體的單一組織。由許多獨立的AS以BGP互相通告路由，才建立起可到達世界上任何目的地的路由。因此，BGP的設定錯誤或故障，可能影響廣大範圍的通訊。

BGP會選擇最短的路由嗎？

不一定。BGP不只看AS_PATH的長度，還會優先依據以LOCAL_PREF等屬性表達的組織政策選擇路由。例如，即使經過的AS較多，也可以優先使用經由費用較低之連接對象的路由。
