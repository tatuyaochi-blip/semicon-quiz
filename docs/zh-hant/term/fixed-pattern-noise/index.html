什麼是固定圖樣雜訊

因每個像素或讀出電路的特性不均，而每次都在相同位置以相同方式出現的雜訊。以相關雙重取樣或校正去除。

日文名稱: 固定パターンノイズ

「固定圖樣雜訊」出現在1領域的1道練習題中（影像感測器與光電元件等）。

這個名詞所屬的領域: 影像感測器與光電元件

每次都出現在相同位置的雜訊

固定圖樣雜訊（FPN，也稱固定圖案雜訊）是因像素或讀出電路各自特性的細微差異，而在每次拍攝時都以相同方式出現在相同位置的雜訊。即使照射相同亮度的光，每個像素的輸出也會略有不同，使影像疊上粗糙感或圖樣。由於不隨時間變化，拍攝多張平均也不會消失，因此與每次拍攝都會改變的散粒雜訊或熱雜訊等時間性雜訊有所區別。反過來說，只要事先量測其圖樣，就能以校正去除。

主要原因與呈現方式

原因大致可分為2種。一種是沒有光時輸出的差異，來自像素放大電晶體的偏移，以及各像素暗電流的不同（DSNU）。另一種是對光的感度差異，來自光電二極體、微透鏡、彩色濾光片的細微差異（PRNU）。在CMOS影像感測器中，各行所具有的放大器或類比數位轉換器的差異，容易呈現為垂直條紋（行FPN），對人眼而言比點狀的差異更顯眼。暗電流會隨溫度大幅變化，因此暗時的FPN會隨溫度與曝光時間改變。

去除方法

各像素的偏移可用相關雙重取樣（CDS）去除。分別讀取剛重置後與轉移電荷後的輸出，以兩者之差作為訊號，兩者共通的偏移就會被抵銷。各行電路的差異，則以在行電路中同樣取差值的處理，或以遮光像素（optical black）的輸出為基準的校正來減少。感度的差異，以照射均勻光所量得的各像素係數加以校正（平場校正）。在天文攝影等領域，會減去關閉快門所拍攝的暗場影像，以去除暗電流造成的圖樣。

CCD與CMOS的差異

CCD影像感測器以同一個輸出放大器將所有像素的電荷轉換為電壓，因此放大差異造成的FPN小是其特長。CMOS影像感測器具有各像素的放大電晶體與各行的電路，早期FPN大是其弱點，但藉由CDS與行電路的改良已大幅改善。即便如此，在極暗的場景或高感度設定下，仍可能出現無法完全校正的垂直條紋或圖樣。FPN的大小多以相對於輸出平均值的標準差比例或電子數來表示，與時間性雜訊一同用於感測器的評估。

查看答案與解析

正確答案：C. 固定圖案雜訊

固定圖案雜訊是由各像素放大器的偏移、暗電流的差異、各行讀出電路或ADC的差異等所造成，每次拍攝都在相同位置以相同方式出現的雜訊。尤其是各行之間的偏差，會明顯呈現為垂直條紋。由於不隨時間變化，可藉由CDS、使用遮光像素數值的校正，以及出廠校準資料來消除。它與隨時間變動的散粒雜訊或熱雜訊不同。

常見問題

固定圖樣雜訊與隨機雜訊有什麼不同？

固定圖樣雜訊源於像素或電路特性的差異，每次都以相同方式出現在相同位置。散粒雜訊或熱雜訊這類隨機雜訊則每次拍攝都會改變。固定圖樣雜訊可事先量測並校正，隨機雜訊則以疊合多張影像平均等方式減少。

為什麼CMOS感測器會出現垂直條紋？

CMOS影像感測器多半每一行都有放大器或類比數位轉換器，其特性的差異會同樣地加在整行上，因此呈現為垂直條紋。由於比點狀的差異更顯眼，會以使用遮光像素的校正或行電路的改良來抑制。

相關雙重取樣能消除固定圖樣雜訊嗎？

像素放大器的偏移這類在重置時與讀出訊號時兩者共通的差異，可用CDS抵銷。不過，暗電流的差異與感度的差異無法以CDS去除，因此需搭配減去暗場影像、平場校正等方法。
