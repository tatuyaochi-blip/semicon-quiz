什麼是URL（網址）

Uniform Resource Locator的縮寫。表示網頁等資源所在位置的字串。像 https://www.example.com:8443/docs/page.html?q=1#top 這樣，由協定名稱（https）、主機名稱、連接埠號碼、路徑、查詢（?之後）、片段（#之後）組成。省略連接埠號碼時使用預設值（HTTPS為443），主機名稱以DNS轉換成IP位址。

日文名稱: URL

練習URL（網址）的題目

在瀏覽器中開啟 https://www.example.com:8443/docs/guide.html?lang=ja#install。這個URL中，不包含在送往伺服器的請求裡、只在網頁載入後於瀏覽器內使用的部分，為下列何者？

  1. A:8443
  2. B?lang=ja
  3. C#install
查看答案與解析

正確答案：C. #install

這個URL由配置（https）、主機名稱（www.example.com）、連接埠號碼（8443，省略時https為443）、路徑（/docs/guide.html）、查詢（lang=ja）、片段（install）組成。瀏覽器以連接埠號碼決定連線對象，並把路徑與查詢放進請求送往伺服器，但不會送出#之後的片段。片段只在瀏覽器內使用，例如移動到網頁中 id="install" 之元素的位置。

為了在URL的查詢中放入日文的「あ」，把這個字元以UTF-8表示的位元組序列（E3 81 82）進行百分比編碼。結果下列何者正確？

  1. A%E3%81%82
  2. B%u3042
  3. C&#x3042;
查看答案與解析

正確答案：A. %E3%81%82

百分比編碼是在把無法直接寫在URL中的字元，或 / ? # & 這類具有特殊意義的字元當作資料使用時，把字元轉為位元組序列，每個位元組以「%」加上2位十六進位數字表示。「あ」以UTF-8表示為 E3 81 82 這3個位元組，因此成為 %E3%81%82。空白會成為 %20（表單送出的格式中也會使用 +）。在JavaScript中可以用encodeURIComponent函式進行這個轉換。
