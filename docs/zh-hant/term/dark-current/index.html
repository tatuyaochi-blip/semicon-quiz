什麼是暗電流

在沒有光照射時流過光二極體的電流。起因於熱所造成的載子產生等，溫度上升時會增加，成為暗部影像的雜訊。

日文名稱: 暗電流

「暗電流」出現在4領域的8道練習題中（影像感測器與光電元件, 矽光子, 半導體物性等）。

這個名詞所屬的領域: 影像感測器與光電元件

暗電流從何而來

在逆向偏壓的光二極體中，無論是否由光產生，空乏區內部或附近產生的任何電子－電洞對都會被掃出並計入電流。即使沒有光，電子－電洞對仍會因熱而產生，主要是經由能隙中深能階的 Shockley-Read-Hall（SRH）產生；金屬污染、晶體缺陷以及矽／氧化層介面態在能隙中央附近形成的陷阱最為有效。從中性區擴散進來的少數載子則構成另一個成分。由於這兩種機制都取決於本質載子濃度，而本質載子濃度會隨溫度上升及能隙縮小呈指數增加，因此暗電流與溫度有很強的關係。

在影像中如何呈現

影像感測器的像素會將暗電流與光電流一起積分，因此暗訊號隨曝光時間與溫度增加，在矽中大約每 6–8 °C 增加一倍。它會造成偏移，而且由於暗電子是隨機到達的，還會增加與暗電荷平方根成正比的散粒雜訊。暗電流在像素之間的差異是固定圖案雜訊的一部分，個別的缺陷像素在長時間曝光時會變成熱像素。偏移可以利用光學遮光的參考像素或暗幀扣除，但散粒雜訊無法扣除，這就是天文相機要冷卻感測器的原因。

釘紮光二極體與其他對策

矽／氧化層介面有大量介面態，是主要的產生源。釘紮（或埋入式）光二極體將 n 型收集區置於表面下方，並以高摻雜的 p+ 層覆蓋，讓電洞填滿這些介面態，大幅抑制載子產生；完全空乏的 n 區也能完整轉移電荷，減少殘影與重置雜訊。潔淨的製程與吸雜可減少金屬陷阱，而像素間深溝槽隔離（DTI）的溝槽壁必須加以鈍化，以免用來抑制串擾的隔離結構本身增加暗電流。

暗電流與讀取雜訊、偏壓及材料

暗電流與讀取雜訊不同：讀取雜訊來自讀出電路，每幀發生一次，與曝光時間無關；暗電流則隨時間累積。偏壓也有影響；在零偏壓（光伏模式）下操作光二極體可降低暗電流，適合精密的弱光量測，而逆向偏壓雖能加快響應，代價是漏電增加。材料選擇則具有決定性。用於 1.31 與 1.55 µm 通訊波段的鍺偵測器，因鍺的能隙較小（約 0.66 eV），以及與矽約 4% 的晶格不匹配所造成的差排，暗電流較高。

正確答案：B. 即使沒有光照射也會流動的電流，溫度上升時會增加

暗電流是指即使沒有光照射，光電二極體中也會因熱而產生電荷所形成的電流，主要源自表面的界面能態、晶體缺陷以及金屬污染所造成的能階。它會成為在暗處拍攝或長時間曝光時產生雜訊與白點（白色瑕疵）的原因，溫度每上升約6～8 ℃就會增加為2倍。天文攝影用相機之所以要冷卻感測器，就是這個緣故。

  2. B因為Ge無法吸收通訊波長的光，流過的電流全都是暗電流
  3. C因為Si與Ge的晶格常數相差約4%，成長的膜容易產生差排等晶體缺陷
查看答案與解析

正確答案：C. 因為Si與Ge的晶格常數相差約4%，成長的膜容易產生差排等晶體缺陷

暗電流是沒有光照射時也會流過的電流，會增加光偵測器的雜訊、降低靈敏度。Si與Ge的晶格常數相差約4%，因此在Si上成長Ge時，在釋放應變的過程中會產生差排（穿透差排）等缺陷，容易經由缺陷能階產生載子。此外，Ge的能隙（約0.66 eV）比Si小，熱產生的載子也較多。可藉由成長後的熱處理減少差排，或縮小受光部面積來抑制暗電流。Ge是間接躍遷型，幾乎沒有發光的影響。

常見問題

為什麼暗電流會隨溫度增加？

暗電流來自熱產生的電子－電洞對，而驅動它的本質載子濃度會隨溫度呈指數上升。在矽影像感測器中，大約每 6–8 °C 增加一倍。

如何降低相機的暗電流雜訊？

冷卻感測器、縮短曝光時間，並扣除暗幀或光學遮光參考值以消除偏移。在元件層級，釘紮光二極體與潔淨且充分鈍化的介面可以減少載子產生本身。

暗電流和漏電流是一樣的嗎？

暗電流是在無光照時觀察到的光偵測器逆向漏電流，因此是接面漏電的一種特例。之所以稱為暗電流，是因為它決定了偵測器在黑暗中的訊號底限。
