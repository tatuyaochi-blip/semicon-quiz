什麼是4H-SiC

SiC的晶體多型之一，主要用於功率元件。能隙約3.3 eV很大，電子遷移率也相對較高。

日文名稱: 4H-SiC

「4H-SiC」出現在1領域的2道練習題中（磊晶成長等）。

這個名詞所屬的領域: 磊晶成長

練習4H-SiC的題目

在SiC磊晶成長中，使用從晶軸傾斜數度（具有偏角）的基板，其主要理由為下列何者？

  1. A使其從表面的原子階梯橫向成長（階梯流成長），承襲與基板相同的晶體多型
  2. B為了使基板便宜
  3. C為了使成長速率變為0
查看答案與解析

正確答案：A. 使其從表面的原子階梯橫向成長（階梯流成長），承襲與基板相同的晶體多型

SiC有許多原子堆疊方式不同的晶體多型（polytype），在平坦的面上成長時，容易混入其他多型（3C-SiC等）。在具有約4°偏角的基板上，表面有許多原子階梯，原料被階梯捕捉而橫向進行成長（階梯流成長），因此可得到承襲與基板相同的4H-SiC堆疊方式的晶體。

SiC功率元件主要使用的晶體多型（polytype）為下列何者？

  1. A4H-SiC
  2. B3C-SiC
  3. C15R-SiC
查看答案與解析

正確答案：A. 4H-SiC

SiC有200種以上的晶體多型，但功率元件主要使用4H-SiC。這是因為其能隙約為3.26 eV而較大、電子遷移率高達約1000 cm²/V·s，且方向性的差異（異向性）小。6H-SiC的遷移率異向性大，3C-SiC的能隙約為2.4 eV而偏小。高品質基板與磊晶成長技術已經確立，也是原因之一。
