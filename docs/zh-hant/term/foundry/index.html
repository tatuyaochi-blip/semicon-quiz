什麼是晶圓代工廠

專門承接其他公司所設計半導體的製造的企業或事業型態。

日文名稱: ファウンドリ

「晶圓代工廠」出現在5領域的17道練習題中（半導體產業與市場, LSI設計流程與EDA, 新世代記憶體等）。

這個名詞所屬的領域: 半導體產業與市場

晶圓代工模式如何運作

晶圓代工廠依客戶提供的電路佈局製造晶圓，設計歸客戶所有，成品晶片也由客戶銷售。客戶提交佈局資料，據此製作光罩，代工廠再讓晶圓經過前段與後段製程，於晶圓允收測試（WAT）中量測測試結構，確認臨界電壓與片電阻等參數，然後出貨。針測、切割與封裝可由代工廠進行，也可交給委外封裝測試（OSAT）公司。專業晶圓代工廠（pure-play foundry）不銷售自有晶片，因此永遠不會與客戶競爭。

PDK：設計者拿到什麼

設計者不了解製程規則就無法針對該製程進行設計，因此代工廠會提供製程設計套件（PDK）。其中包含設計規則、電晶體與被動元件的 SPICE 模型（含變異模型）、設計規則檢查（DRC）與佈局對電路圖比對（LVS）的規則檔、寄生參數萃取資料，以及基本元件的佈局。標準元件庫、記憶體編譯器與介面 IP 可能來自代工廠或第三方。PDK 就是雙方的契約：通過其檢查的設計，預期可以製造，且行為會與模型預測一致。

分攤成本與 MPW 共乘

先進晶圓廠的造價極高，很少有公司能以自家產品填滿產能，而代工廠能將成本分攤給眾多客戶。同樣的概念也適用於試產。多專案晶圓（MPW），又稱共乘（shuttle），將多家客戶的設計放在同一套光罩與同一批晶圓上，共同分擔光罩與製造費用；先進節點光是一套光罩就可能高達數千萬美元。每位參與者只拿到少量晶片，足以評估但不足以量產，因此 MPW 很受大學與新創公司歡迎。

晶圓代工、Fabless、IDM 與 OSAT

這四種商業模式分擔了產業的工作。無晶圓廠設計公司（fabless）設計並銷售晶片，但不擁有晶圓廠，仰賴代工廠製造。整合元件製造商（IDM）同時設計並製造自家產品，部分 IDM 也提供代工服務。晶圓代工廠為他人製造，OSAT 則負責封裝與測試。專業晶圓代工模式於 1987 年確立，如今先進邏輯製造高度集中在台灣，這也是其他國家政府將代工產能視為供應鏈風險的原因。

  2. BIP核
  3. CHDL

正確答案：A. PDK（製程設計套件）

PDK包含該製程的設計規則、電晶體等的SPICE用模型、DRC與LVS用的規則檔、佈線寄生元件萃取的資料、基本元件的佈局等。設計者使用PDK，就能設計出可在該晶圓代工廠製造的電路。標準單元的庫有時也會與PDK分開提供。IP核是電路區塊，HDL則是描述語言。

  2. B不擁有工廠，專注於半導體設計與銷售的企業
  3. C專門販售半導體製造設備零組件的企業
查看答案與解析

正確答案：A. 專門接受委託，製造其他公司所設計之半導體的企業

晶圓代工廠是依據客戶企業所設計的電路資料來製造晶圓的代工製造企業（或事業）。1987年成立的台積電（TSMC）確立了專業晶圓代工的型態。由於可由眾多客戶共同分攤需要龐大設備投資的先進工廠，與無晶圓廠（Fabless）企業之間的分工因而擴大。不擁有工廠而專注於設計與銷售的是無晶圓廠企業，販售設備零組件的則是設備相關企業。

常見問題

晶圓代工廠和 IC 設計公司（fabless）有什麼不同？

Fabless 公司設計並銷售晶片，但不擁有製造工廠；晶圓代工廠擁有晶圓廠，負責製造其他公司設計的晶片。兩種模式相互依存。

什麼是專業晶圓代工（pure-play foundry）？

專業晶圓代工廠只為客戶製造晶片，不銷售自有的晶片產品。這樣可避免與委託其製造的公司競爭，有助於贏得客戶信任。

晶圓代工廠會提供什麼給晶片設計者？

主要是製程設計套件（PDK），包含設計規則、元件模型、驗證規則檔與基本元件佈局，通常還會一併提供元件庫與 IP。設計者用它做出代工廠能夠製造的佈局。
