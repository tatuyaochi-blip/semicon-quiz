什麼是晶圓代工廠

專門承接其他公司所設計半導體的製造的企業或事業型態。

日文名稱: ファウンドリ

「晶圓代工廠」出現在5領域的17道練習題中（半導體產業與市場, LSI設計流程與EDA, 新世代記憶體等）。

練習晶圓代工廠的題目

晶圓代工廠提供給設計者的設計規則、元件模型、單元庫等整套設計用資料，稱為什麼？

  1. APDK（製程設計套件）
  2. BIP核
  3. CHDL
查看答案與解析

正確答案：A. PDK（製程設計套件）

PDK包含該製程的設計規則、電晶體等的SPICE用模型、DRC與LVS用的規則檔、佈線寄生元件萃取的資料、基本元件的佈局等。設計者使用PDK，就能設計出可在該晶圓代工廠製造的電路。標準單元的庫有時也會與PDK分開提供。IP核是電路區塊，HDL則是描述語言。

下列關於半導體產業中「晶圓代工廠（Foundry）」的說明，何者正確？

  1. A專門接受委託，製造其他公司所設計之半導體的企業
  2. B不擁有工廠，專注於半導體設計與銷售的企業
  3. C專門販售半導體製造設備零組件的企業
查看答案與解析

正確答案：A. 專門接受委託，製造其他公司所設計之半導體的企業

晶圓代工廠是依據客戶企業所設計的電路資料來製造晶圓的代工製造企業（或事業）。1987年成立的台積電（TSMC）確立了專業晶圓代工的型態。由於可由眾多客戶共同分攤需要龐大設備投資的先進工廠，與無晶圓廠（Fabless）企業之間的分工因而擴大。不擁有工廠而專注於設計與銷售的是無晶圓廠企業，販售設備零組件的則是設備相關企業。

解析中的「晶圓代工廠」

  • 設計者使用PDK，就能設計出可在該晶圓代工廠製造的電路。

    晶圓代工廠提供給設計者的設計規則、元件模型、單元庫等整套設計用資料，稱為什麼？

  • 晶圓代工廠是依據客戶企業所設計的電路資料來製造晶圓的代工製造企業（或事業）。

    下列關於半導體產業中「晶圓代工廠（Foundry）」的說明，何者正確？

  • 若將製造集中於專業的晶圓代工廠，便能由眾多客戶共用設備而維持高稼動率，設計企業則可不擁有工廠而專注於產品開發。

    下列何者適合作為晶圓代工廠與無晶圓廠之間分工擴大的背景？

  • 營運大規模資料中心的企業，開始自行設計（或與設計公司合作）針對自家服務最佳化的AI加速器與CPU等，並委託晶圓代工廠製造。

    大型雲端業者等為自家的資料中心，自行設計專門用於AI處理等的半導體，並交由晶圓代工廠製造的趨勢，稱為什麼？

  • 輕晶圓廠（Fab-lite）是指成熟製程與自家具優勢的產品在自家工廠製造，需要龐大投資的先進製程產品則委託給晶圓代工廠的型態。
