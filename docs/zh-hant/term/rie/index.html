什麼是RIE(反應式離子蝕刻)

結合電漿中的反應性粒子與經電場加速之離子來進行蝕刻的乾式蝕刻。可進行垂直的非等向性加工。

日文名稱: RIE(反応性イオンエッチング)

「RIE(反應式離子蝕刻)」出現在1領域的1道練習題中（蝕刻等）。

這個名詞所屬的領域: 蝕刻

練習RIE(反應式離子蝕刻)的題目

關於反應性離子蝕刻（RIE）的說明，下列何者正確？

  1. A在反應性氣體的電漿中，結合化學反應與離子轟擊來進行蝕刻
  2. B將晶圓浸入藥液中進行蝕刻
  3. C以研磨墊削除晶圓表面
查看答案與解析

正確答案：A. 在反應性氣體的電漿中，結合化學反應與離子轟擊來進行蝕刻

RIE是一種乾式蝕刻，結合了反應性氣體（氟系、氯系等）電漿所產生的自由基之化學反應，以及經電場加速的離子之轟擊。離子垂直入射晶圓，促進底面的反應，因此縱向蝕刻容易進行，可以做出高度非等向性的加工。與名稱給人的印象相反，它並不是只靠離子來蝕除，其本質在於與自由基的協同效應。

解析中的「RIE(反應式離子蝕刻)」

出現這個名詞的比較

  • 濕式蝕刻與乾式蝕刻的差異：方向性、選擇比、用途比較從介質、方向性、選擇比、微細化、產能、損傷、成本與使用的製程等面向，以表格比較濕式蝕刻與乾式蝕刻。
  • RIE、ICP-RIE 與 ALE 的差異：壓力、電漿密度、離子能量、精度比較從電漿的產生方式、壓力、電漿密度、離子能量的控制、蝕刻速率、損傷、深度精度與用途等面向，以表格比較電容耦合電漿式 RIE、ICP-RIE 與原子層蝕刻（ALE），並說明各自適用的時機。
  • CCP 與 ICP 的差異：電漿產生方式、密度、離子能量、用途比較從電極與線圈、電漿密度、離子能量的獨立控制、壓力、蝕刻用途（氧化膜與 Si、金屬）、電漿 CVD 等成膜應用等面向，以表格比較電容耦合電漿（CCP）與感應耦合電漿（ICP）。
