什麼是RIE(反應式離子蝕刻)

結合電漿中的反應性粒子與經電場加速之離子來進行蝕刻的乾式蝕刻。可進行垂直的非等向性加工。

日文名稱: RIE(反応性イオンエッチング)

「RIE(反應式離子蝕刻)」出現在1領域的1道練習題中（蝕刻等）。

這個名詞所屬的領域: 蝕刻

離子與自由基協同作用

反應性氣體電漿提供兩種成分：與膜層發生化學反應的中性自由基（例如氟或氯原子），以及轟擊表面的離子。兩者單獨作用時效率都不高。在 Coburn 與 Winters 的經典實驗中，XeF2 氣體或氬離子束各自蝕刻矽都很慢，但兩者並用時，蝕刻速度約為兩者相加的十倍。離子撞擊使表面無序化，並幫助揮發性產物脫附，因此受離子撞擊的表面蝕刻速度遠快於未受撞擊的表面。

方向性從何而來

在典型的平行板 RIE 機台中，射頻功率（通常為 13.56 MHz）施加於承載晶圓的電極。電子的反應比離子快，因此晶圓產生負的直流自偏壓，並在其上方形成鞘層。穿越鞘層的離子被加速成幾乎垂直於晶圓的方向，撞擊結構底部而非側壁。許多化學系統還會在側壁沉積一層薄的鈍化膜，例如氟碳聚合物，阻擋橫向蝕刻，進一步提高非等向性。

製程參數與取捨

較低的壓力會拉長離子的平均自由徑，使離子轟擊更具方向性；較高的離子能量則加快蝕刻，但會降低對遮罩與底層的選擇比，並可能損傷元件。在簡單的 RIE 反應器中，同一個射頻功率同時決定電漿密度與離子能量，因此感應耦合電漿（ICP）等高密度源會另加一個偏壓電源來獨立控制兩者。狹窄而深的結構也比寬的結構蝕刻得慢，這種效應稱為 RIE lag 或深寬比相依蝕刻。

RIE 與濕式蝕刻、離子銑削

濕式蝕刻大多是等向性的，會在遮罩下方側蝕約等於蝕刻深度的量，因此無法用於精細的垂直圖案。離子銑削是純物理的濺射：有方向性，但速度慢且選擇比差。RIE 結合了化學的選擇性與離子的方向性。典型的化學系統為：氧化物用氟碳化合物、矽與多晶矽用氯或 HBr、鋁用氯系氣體、光阻用氧。深矽蝕刻使用 Bosch 製程，交替進行 SF6 蝕刻與 C4F8 鈍化步驟。

正確答案：A. 在反應性氣體的電漿中，結合化學反應與離子轟擊來進行蝕刻

RIE是一種乾式蝕刻，結合了反應性氣體（氟系、氯系等）電漿所產生的自由基之化學反應，以及經電場加速的離子之轟擊。離子垂直入射晶圓，促進底面的反應，因此縱向蝕刻容易進行，可以做出高度非等向性的加工。與名稱給人的印象相反，它並不是只靠離子來蝕除，其本質在於與自由基的協同效應。

常見問題

反應式離子蝕刻是等向性還是非等向性？

主要是非等向性的：垂直於晶圓加速的離子驅動結構底部的蝕刻，側壁鈍化則限制橫向侵蝕。僅有自由基的條件可能增加等向性的成分。

RIE 使用哪些氣體？

取決於膜層：氧化矽用 CF4、CHF3 或 C4F8 等氟碳化合物，矽用 Cl2 或 HBr，鋁用氯系混合氣體，快速蝕刻矽用 SF6，光阻用 O2。

RIE 和 ICP 蝕刻有什麼差別？

ICP 是 RIE 的一種，使用感應耦合源產生高密度電漿，並以獨立的晶圓偏壓設定離子能量，提供簡單平行板 RIE 所缺乏的獨立控制。

  • 濕式蝕刻與乾式蝕刻的差異：方向性、選擇比、用途比較從介質、方向性、選擇比、微細化、產能、損傷、成本與使用的製程等面向，以表格比較濕式蝕刻與乾式蝕刻。
