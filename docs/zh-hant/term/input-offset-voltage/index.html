什麼是輸入偏移電壓

為使運算放大器輸出為 0 而必須施加在輸入之間的微小電壓，由內部元件的不匹配所產生。會乘上電路增益成為輸出誤差，例如 2 mV、增益 100 倍時，輸出最多偏移 200 mV。

日文名稱: 入力オフセット電圧

「輸入偏移電壓」出現在2領域的2道練習題中（類比與電子電路, 規格書的閱讀方法等）。

這個名詞所屬的領域: 規格書的閱讀方法

練習輸入偏移電壓的題目

下列哪一項是對運算放大器輸入偏移電壓的正確說明？

  1. A為了補償輸入為0時輸出不為0的情況，必須加在輸入端子間的微小電壓
  2. B可加在輸入上的最大電壓
  3. C運算放大器的電源電壓
查看答案與解析

正確答案：A. 為了補償輸入為0時輸出不為0的情況，必須加在輸入端子間的微小電壓

實際的運算放大器因輸入級電晶體的些微不匹配，即使輸入為相同電壓，輸出也不會是0。將此換算到輸入側就是輸入偏移電壓，通用品為數mV，精密品為數十µV以下。它在輸出會被放大(1 + Rf/Ri)倍後出現，且會隨溫度變化（漂移）。以高增益處理熱電偶等直流微小訊號時，會使用低偏移品或斬波穩定型。

用輸入偏移電壓為 max 2 mV 的運算放大器組成增益100倍的非反相放大電路。輸入為0 V時，輸出可能出現的最大誤差電壓參考值為何？

  1. A2 mV
  2. B200 mV
  3. C20 mV
查看答案與解析

正確答案：B. 200 mV

輸入偏移電壓的行為就像串聯在輸入上的小電壓源，會被放大為非反相放大電路的增益（1 + Rf/Ri）倍後出現在輸出。2 mV × 100 = 200 mV，例如相對於5 V的滿刻度為4%的誤差。要以max值而非typ值來估算，並再加上溫度漂移（µV/℃）造成的變化。精密量測時，可選擇偏移僅數µV左右的零漂移（截波）型，或以軟體校正。2 mV是忘了乘上增益的數值。
