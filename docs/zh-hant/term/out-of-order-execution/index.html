什麼是亂序執行

檢查指令的相依關係，從可執行的指令開始，以與程式順序不同的順序執行來提升性能的方式。結果以重排序緩衝區依原本的順序確定。

日文名稱: アウトオブオーダー実行

「亂序執行」出現在5領域的9道練習題中（CPU與架構, 指令集與組合語言, 記憶體階層與效能等）。

這個名詞所屬的領域: CPU與架構

亂序執行如何運作

前端仍依程式順序擷取並解碼指令。接著每個指令會經過重新命名，在重排序緩衝區（ROB）中取得一個項目，並放入發派佇列。排程邏輯會監看哪些指令的來源運算元已準備好，不論其在程式中的位置，都將其送往空閒的執行單元。等待慢速載入的指令會被擱在一旁，讓後面獨立的指令先執行。結果會一直保留到 ROB 依原本順序引退指令為止，因此軟體看到的行為與循序機器完全相同。在高效能核心中，這個視窗可涵蓋數百個指令。

暫存器重新命名與依序提交

程式重複使用少量的架構暫存器，這會產生假相依：後面的寫入不能超越前面對同一暫存器的讀取或寫入。暫存器重新命名將每個新值對應到新的實體暫存器，只留下真正的資料相依，也就是指令確實需要另一個指令計算出的值。透過 ROB 依序提交可提供精確例外，並讓核心能越過預測的分支繼續執行，在預測錯誤時丟棄錯誤路徑上的工作。ISA 的細節在這裡很重要；RV64I 將 lw 的結果符號擴展到整個暫存器，正是為了讓高位位元永遠不依賴該暫存器先前的值。

隱藏記憶體延遲

最大的效益出現在快取失誤期間。循序核心會停在失誤的載入之後；亂序核心則能持續找到獨立的工作，還能發出其他載入，讓它們的失誤與第一次失誤重疊。這需要非阻塞快取，以失誤狀態保存暫存器（MSHR）追蹤未完成的失誤，同時繼續處理命中。失誤次數與每次的延遲都沒有改變，但讓它們重疊可以隱藏大部分成本。結合超純量發派、分支預測與大容量快取，可提高 IPC（每時脈指令數），而效能則與 IPC 乘以頻率成正比。

亂序執行與超純量，以及其代價

超純量描述的是寬度，即每個週期發派多個指令；亂序執行描述的是指令執行的順序。核心可以是循序的超純量，而近年的高效能核心則兩者兼具，寬度約為 6–10 個指令。代價很大：相依性檢查大致隨寬度的平方增加，而重新命名表、喚醒邏輯與 ROB 會為每個指令增加面積與能耗。這就是手機 SoC 的效率核心較小、較簡單的原因，也是 GPU 將這些矽面積改用於大量簡單運算單元以追求產出量的原因。

練習亂序執行的題目

在亂序執行的 CPU 中，用來將調換順序執行之指令的結果，依程式原本的順序確定（引退，retire）的機制是下列何者？

  1. A重排緩衝區（reorder buffer）
  2. B窺探過濾器（snoop filter）
  3. CTLB
查看答案與解析

正確答案：A. 重排緩衝區（reorder buffer）

重排緩衝區是暫時保存調換順序執行之指令的結果，並依程式順序確定（引退）的機制，在近來的高效能核心中，其大小可達數百道指令。當發生分支預測失誤或例外時，可捨棄其後指令的結果並恢復到正確的狀態，因此從外部看來，就像是依照程式原本順序執行一樣（精確例外，precise exception）。

亂序執行 CPU 所使用之暫存器重新命名（register renaming）的主要目的為何？

  1. A減少暫存器的數量以縮小電路
  2. B在不改變程式所使用暫存器名稱的情況下，重新分配實體暫存器，以消除表面上的相依（WAR 與 WAW）
  3. C將暫存器的值加密
查看答案與解析

正確答案：B. 在不改變程式所使用暫存器名稱的情況下，重新分配實體暫存器，以消除表面上的相依（WAR 與 WAW）

指令集的暫存器數量有限，約 16〜32 個，因此同一個暫存器名稱會被重複使用，進而產生與真正資料流向無關的相依（反相依 WAR、輸出相依 WAW）。暫存器重新命名動態分配數百個實體暫存器，每次寫入都使用新的實體暫存器以消除這些相依，增加可平行執行的指令。真正的相依（RAW）則無法消除。

常見問題

亂序執行和超純量有什麼差別？

超純量是指每個時脈發派多個指令；亂序執行是指在相依關係允許時，以不同於程式順序的順序執行指令。兩者是彼此獨立的概念，高效能核心通常會結合兩者。

為什麼亂序執行 CPU 需要重排序緩衝區？

指令完成的順序是亂的，但架構狀態必須依程式順序更新，才能提供精確例外並丟棄預測錯誤的工作。重排序緩衝區會保存結果，直到每個指令能依序引退為止。

亂序執行會減少快取失誤嗎？

不會。它是在處理失誤期間執行獨立的工作（包括平行發出其他失誤）來隱藏失誤延遲，失誤次數本身不變。

解析中的「亂序執行」

  • 它會與調換指令順序的亂序執行（out-of-order execution）結合以提升效能，但相依關係檢查電路的複雜度約隨寬度的平方增加，因此不能任意加寬。

    在一個時脈週期內同時發出並執行多道指令的處理器方式稱為什麼？

  • 在亂序執行中，正在等待前一道指令的結果或來自記憶體資料的指令會被往後挪，先執行已準備就緒的後續指令。

    檢查指令的相依關係，從可以執行的指令開始，以不同於程式順序的次序執行以提升效能的方式是下列何者？

  • 超純量、亂序執行、分支預測、大型快取，全都是提高 IPC 的技術。

    表示每個時脈可執行之指令數的指標是下列何者？

  • 若讓高位保持原本的值，會產生對原值的相依，妨礙亂序執行，所以RISC-V不這麼做。

    在64位元的RV64I中執行lw指令時，讀入的32位元值是如何放入64位元暫存器的？

  • 與亂序執行（out-of-order execution）搭配時更能發揮效果。
