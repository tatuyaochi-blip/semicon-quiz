什麼是安全開機（Secure boot）

在開機的每個階段確認下一個要執行之軟體的數位簽章，只啟動正確者的機制。藉此串連信任鏈。

日文名稱: セキュアブート

「安全開機（Secure boot）」出現在1領域的1道練習題中（硬體安全等）。

這個名詞所屬的領域: 硬體安全

信任鏈如何運作

通電時，晶片 ROM 中的開機程式碼會載入第一個開機載入程式，並檢查其數位簽章：先計算映像檔的雜湊值，再驗證廠商對該雜湊值所做的簽章。只有在檢查通過時才會執行該開機載入程式，而它又會在交出控制權之前驗證下一個階段或作業系統核心。每個環節都為下一個環節擔保，形成信任鏈。只要任何一個簽章驗證失敗，開機就會停止，因此改寫開機載入程式或作業系統開機程式碼的惡意軟體無法執行。智慧型手機、PC 與許多嵌入式裝置都採用這種機制。

晶片中的信任根

信任鏈的強度取決於第一道檢查，因此信任根必須是不可變更的：在製造時就固定的光罩 ROM 開機程式碼，加上用來驗證簽章的公開金鑰，為了節省空間，公開金鑰常以雜湊值的形式存放在 eFuse（一次性可程式化熔絲）中。公開金鑰密碼學在這裡很重要。若採用對稱式方案，用來驗證的金鑰同樣可以用來簽章，因此只要從一台裝置中取出金鑰，就能為所有裝置製作假韌體。採用公開金鑰簽章時，裝置只持有驗證金鑰，用來簽章的私密金鑰則從不離開廠商的安全設施。

防回滾與鎖定除錯埠

僅靠簽章檢查仍會接受舊版韌體，因為廠商曾經正當地為其簽章。漏洞修補之後，攻擊者可能會重新安裝有漏洞的版本，因此映像檔會帶有版本號碼，晶片則在 eFuse 等只能寫入一次的儲存區中記錄最低允許版本，並在每次更新時調高。JTAG 與 SWD 等除錯埠可以讀寫記憶體並暫停處理器，等於完全繞過安全開機，因此出貨產品會以熔絲停用除錯埠，或只在通過密碼學認證後才開放。

安全開機與量測開機

安全開機負責強制執行：未經驗證的程式碼不會啟動。量測開機負責記錄：每個階段都計算下一個階段的雜湊值，並將結果延伸（extend）到 TPM（信賴平台模組）的平台組態暫存器中，新值只能由舊值與新雜湊值結合而成。無論如何開機都會繼續，但這份記錄讓軟體或遠端伺服器之後能確切驗證執行了什麼。另外要注意，簽章證明的是真實性而非機密性；要讓韌體保密需要加密。安全開機只保護啟動路徑，因此它是縱深防禦中的一層，與記憶體保護、可信執行環境及防竄改措施並列。

  2. B在啟動的每個階段，驗證接下來要執行之軟體的數位簽章，只啟動正確的軟體
  3. C每次啟動時都把磁碟的內容全部清除的機制
查看答案與解析

正確答案：B. 在啟動的每個階段，驗證接下來要執行之軟體的數位簽章，只啟動正確的軟體

在安全啟動中，無法改寫的ROM程式碼驗證第一個開機載入程式（bootloader）的簽章，該載入程式再驗證下一階段或作業系統核心的簽章，如此串接起信任鏈。只要任何一個階段的簽章不符就停止啟動，因此即使惡意軟體竄改了開機載入程式或作業系統的啟動部分，也無法讓它們運作。廣泛用於智慧型手機、電腦與嵌入式設備。

常見問題

安全開機的信任根是什麼？

晶片光罩 ROM 中不可變更的程式碼，以及用來驗證第一個開機載入程式的公開金鑰（或存放在 eFuse 中的其雜湊值）。信任鏈中之後的一切，都仰賴它無法被變更。

安全開機和量測開機有什麼差別？

安全開機會拒絕執行簽章驗證失敗的軟體。量測開機則讓所有程式都執行，但將雜湊值記錄在 TPM 中，讓開機狀態之後可以被檢查或證明。

為什麼安全開機需要防回滾保護？

舊版韌體同樣帶有有效的簽章，因此若沒有最低版本計數器，攻擊者就能重新安裝有已知漏洞的版本。
