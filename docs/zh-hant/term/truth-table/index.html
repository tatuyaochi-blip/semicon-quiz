什麼是真值表

列出所有輸入組合所對應輸出的表。用來表示邏輯電路的動作。

日文名稱: 真理値表

「真值表」出現在2領域的3道練習題中（邏輯電路, LSI設計流程與EDA等）。

這個名詞所屬的領域: 邏輯電路

如何建立真值表

將輸入列為欄，把每一種輸入組合寫成一列，通常按二進位計數順序從全 0 排到全 1，再為每個輸出加上一欄。有 n 個輸入就有 2ⁿ 列。例如兩輸入 XOR 有四列，只在 01 與 10 時輸出 1。具有多個輸出的電路，例如有和與進位的半加器，只要增加共用同一組輸入列的多個輸出欄即可。

從表格到布林表示式

每個輸出為 1 的列都對應一個最小項，即所有輸入以原形或補數形式相乘的積項。將這些最小項 OR 起來，就得到標準積之和表示式。若改從輸出為 0 的列著手，則得到最大項與和之積形式。這些標準表示式是正確的，但通常遠非最簡，因此下一步是以布林代數、卡諾圖或軟體化簡器進行化簡。

隨意項

有些輸入組合絕不會出現，或其輸出無關緊要。例如解碼二進位編碼十進位（BCD）數字的電路絕不會看到 1010 到 1111 的圖樣。這些列標記為 X，即隨意項（don't-care）。化簡時每個 X 都可視為 0 或 1，看哪一種能形成較大的群組與較小的電路，因此明確記錄隨意項往往能節省邏輯閘。

為什麼真值表無法擴展

由於每增加一個輸入列數就加倍，窮舉式的表格只適用於小型區塊。32 位元加法器有 64 個輸入，需要 2⁶⁴ 列。因此大型設計以布林表示式或硬體描述語言（HDL）階層式地描述，並以模擬與形式等價性檢查進行驗證。循序電路也需要比單純真值表更多的東西：其狀態表將目前狀態加為輸入，將下一狀態加為輸出。

練習真值表的題目

  1. A6列
  2. B9列
  3. C8列
查看答案與解析

正確答案：C. 8列

每個輸入有0或1兩種可能，因此3個輸入的組合有 2³ = 8 種，真值表為8列。n個輸入時為 2ⁿ 列，呈指數成長，因此32位元加法器（64個輸入）的真值表會是 2⁶⁴ 列，實際上不可能製作。所以大型電路是將小的零件組合起來設計，並以邏輯式或HDL描述後進行驗證。

常見問題

n 個輸入的真值表有幾列？

2ⁿ 列，因為每個輸入可以是 0 或 1。三個輸入有 8 列，四個輸入有 16 列，依此類推。

真值表和卡諾圖有什麼差別？

兩者包含相同的資訊。卡諾圖將各列以格雷碼順序重新排列成網格，使邏輯上相鄰的組合彼此相鄰，便於分組化簡。

真值表可以描述正反器嗎？

無法用單純的組合邏輯表格描述。正反器是以特性表或狀態表描述，其中包含作為輸入欄的目前狀態，以及作為輸出的下一狀態。
