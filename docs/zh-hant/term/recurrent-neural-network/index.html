什麼是遞迴神經網路（RNN）

將序列資料一次處理一個元素，並把到目前為止的資訊作為隱藏狀態傳給下一個時刻的神經網路。每個時刻重複使用相同的權重，因此能處理長度不同的序列。由於長序列容易發生梯度消失，因而發展出以閘門控制資訊保留與遺忘的LSTM與GRU。因為必須依時刻順序計算、難以平行化，在語言處理的許多用途上已被Transformer取代。

日文名稱: 再帰型ニューラルネットワーク(RNN)

「遞迴神經網路（RNN）」出現在1領域的2道練習題中（機器學習基礎等）。

這個名詞所屬的領域: 機器學習基礎

練習遞迴神經網路（RNN）的題目

下列關於遞迴神經網路（RNN）與LSTM的敘述，何者適當？

  1. ARNN是對影像的各位置套用相同濾波器以取出局部特徵的網路，LSTM則是改良其池化層、使其不易受位置偏移影響者
  2. BRNN將序列的所有元素彼此獨立處理，不使用前一個時刻的結果而同時平行處理，因此序列越長訓練越快
  3. CRNN將前一個時刻的隱藏狀態傳給下一個時刻，依序處理序列；LSTM則以閘門控制資訊的保留或遺忘，使長序列不易發生梯度消失
查看答案與解析

正確答案：C. RNN將前一個時刻的隱藏狀態傳給下一個時刻，依序處理序列；LSTM則以閘門控制資訊的保留或遺忘，使長序列不易發生梯度消失

RNN將文字、語音、感測器的時間序列等序列資料一次處理一個元素，並把到目前為止的資訊作為隱藏狀態傳給下一個時刻。由於誤差要沿時間回溯傳遞，長序列容易發生梯度消失或爆炸，難以學到遙遠過去的資訊。LSTM具有儲存資訊的記憶單元，以及輸入、遺忘、輸出閘門，能長時間保留需要的資訊。不過兩者都必須依時刻順序計算、難以平行化，改善這一點的是Transformer。
