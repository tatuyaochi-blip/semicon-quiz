什麼是ASIL(車用安全完整性等級)

ISO 26262 中，針對每個危害事件，由嚴重度 S、暴露度 E、可控性 C 三者決定的安全要求等級。分為 A〜D 四級，D 最嚴格；風險低而不需分配的則歸為 QM。

日文名稱: ASIL(自動車安全度水準)

「ASIL(車用安全完整性等級)」出現在1領域的10道練習題中（車用半導體與功能安全等）。

這個名詞所屬的領域: 車用半導體與功能安全

ASIL 如何決定

在危害分析與風險評估（HARA）中，每個危險事件依傷害的嚴重度（S1–S3）、處於可能發生該事件之行駛情境的暴露度（E1–E4），以及駕駛人或他人的可控度（C1–C3）進行評級。ISO 26262 中的對照表將這些組合對應到 ASIL A、B、C 或 D，若不需要 ASIL 則對應到 QM（品質管理）。一個方便的規則是：S + E + C 等於 10 為 D，9 為 C，8 為 B，7 為 A。只有 S3/E4/C3 會達到 D，任一因素降低一級，ASIL 就降低一級。

等級帶來的差異

ASIL 附屬於安全目標，並由從中衍生的需求繼承，再傳給實作這些需求的硬體與軟體。ASIL 越高，對開發與驗證的嚴謹度要求越高，硬體指標也越嚴格。單點故障度量（SPFM）的目標參考值為 B 90%、C 97%、D 99%；潛伏故障度量（LFM）為 60%、80%、90%。隨機硬體故障機率度量（PMHF）的目標為 B 與 C 低於 100 FIT，D 低於 10 FIT（即每小時 10⁻⁸）。QM 仍需要一般的品質工作。

指標計算實例

SPFM 是 1 減去安全相關故障率中屬於單點或殘餘故障的比例，這類故障是指單獨就會違反安全目標、或未被安全機制偵測而漏過的故障。若某區塊的安全相關故障為 1000 FIT，其中 5 FIT 為單點或殘餘故障，則 SPFM = 1 − 5/1000 = 99.5%，符合 ASIL D 的目標。要提升此值，就要加入診斷涵蓋率更高的安全機制，例如記憶體的 ECC、鎖步（lockstep）核心或監控電路，讓未被偵測的故障變少。

分解與混合關鍵性設計

一項需求可以拆分到足夠獨立的冗餘元件上，並在括號中註明原始等級：ASIL D 可以變成 B(D) + B(D)、C(D) + A(D) 或 D(D) + QM(D)。相依故障分析必須證明兩者不會因共同原因同時失效，而隨機硬體指標仍依循原始 ASIL。當不同 ASIL 的軟體共用一顆 SoC 時，必須以空間分割（例如記憶體保護單元或 hypervisor）與以執行時間監控進行的時間分割，證明彼此免於干擾；否則所有部分都必須按最高的 ASIL 開發。

練習ASIL(車用安全完整性等級)的題目

在ISO 26262中，以危害分析與風險評估（HARA）決定ASIL時，所評估的三個要素的正確組合是下列何者？

  1. A嚴重度（S）、暴露度（E）、可控度（C）
  2. B故障率（λ）、診斷覆蓋率（DC）、容錯時間間隔（FTTI）
  3. C零件的價格、生產台數、開發期間
查看答案與解析

正確答案：A. 嚴重度（S）、暴露度（E）、可控度（C）

ASIL是針對每個危險事件，評估表示傷害嚴重程度的嚴重度S、表示暴露於可能發生該危險之駕駛情境的頻率或時間的暴露度E，以及表示駕駛人等能迴避危險之可能性的可控度C這三者來決定。例如高速行駛中煞車突然失效的事件，嚴重度高且難以迴避，因此會是較高的ASIL。故障率、診斷覆蓋率、FTTI是在ASIL決定後，評估滿足其要求的設計時所使用的量。

下列何者是對ISO 26262之ASIL的正確說明？

  1. A分為A到D，ASIL A表示最嚴格的要求。QM表示比ASIL D更嚴格的要求
  2. B分為A到D，ASIL D表示最嚴格的要求。風險夠低時則歸為QM，以一般的品質管理因應
  3. C分為A到D，ASIL D表示故障率最高的零件。QM表示品質沒有問題，可省略所有試驗的零件
查看答案與解析

正確答案：B. 分為A到D，ASIL D表示最嚴格的要求。風險夠低時則歸為QM，以一般的品質管理因應

ASIL（Automotive Safety Integrity Level）分為A、B、C、D四個等級，D最嚴格，在開發流程、安全機制、故障率目標等方面都有很高的要求。例如安全氣囊、煞車、轉向控制的一部分，是常被要求ASIL D的代表性例子。風險低而不需分配ASIL時，則歸為QM（Quality Management），在一般的品質管理下進行開發。即使是QM也需要確保品質，並不代表可以省略試驗。

常見問題

哪個 ASIL 等級最嚴格？

ASIL D 最高，ASIL A 最低；QM 表示風險低到一般品質管理就已足夠。煞車、轉向與安全氣囊控制的部分功能，是典型的 ASIL D 例子。

ASIL B(D) 是什麼意思？

它表示這項需求是將原本 ASIL D 的需求分解到兩個獨立冗餘元件後，以 ASIL B 開發的結果。括號讓原始等級保持可見，因為部分義務（例如硬體指標目標）仍依循 ASIL D。

ASIL 和 SIL 一樣嗎？

不一樣。SIL 1–4 等級出自通用標準 IEC 61508，而 ASIL A–D 則由 ISO 26262 針對道路車輛、以嚴重度、暴露度與可控度定義。兩者在精神上相關，但在形式上不能互換。
