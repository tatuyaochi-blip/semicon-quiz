什麼是穩態誤差

控制系統的響應穩定下來之後，仍殘留的目標值與受控量之差，也稱為偏移。在單位回授系統中，對步階目標值為 1/(1 + Kp)（Kp = G(0) 為位置誤差常數），在前向路徑不含積分的（0型）系統中不會變成0。在含有1個積分的1型系統中，對步階的穩態誤差為0，對斜坡目標值則殘留 1/Kv（Kv 為速度誤差常數）的誤差。PI控制的積分動作就是用來消除這個誤差的。

日文名稱: 定常偏差

「穩態誤差」出現在1領域的5道練習題中（控制工程基礎等）。

這個名詞所屬的領域: 控制工程基礎

練習穩態誤差的題目

在單位回授系統中，前向轉移函數為 G(s) = 9/(1 + 2s)。對大小為1的步階目標值，穩態誤差為下列何者？

  1. A0
  2. B0.1
  3. C約0.11
查看答案與解析

正確答案：B. 0.1

單位回授系統對步階的穩態誤差為 1/(1 + Kp)，Kp = G(0) 稱為位置誤差常數。此處 Kp = 9，因此穩態誤差為 1/(1 + 9) = 0.1。在前向路徑不含積分的（0型）系統中，提高增益可使誤差變小，但不會變成0。要使誤差為0，需以PI控制等加入積分。

在閉迴路為穩定的單位回授系統中，前向轉移函數 G(s) 含有1個積分 1/s（1型系統）時，關於穩態誤差的說明，正確的是下列何者？

  1. A對步階目標值的穩態誤差為0，對以固定速度增加的斜坡目標值，則留下固定大小的誤差
  2. B對步階目標值也會留下固定大小的穩態誤差，對斜坡目標值，誤差則隨時間越來越大
  3. C對步階、斜坡，以及以固定加速度增加的目標值，穩態誤差都是0
查看答案與解析

正確答案：A. 對步階目標值的穩態誤差為0，對以固定速度增加的斜坡目標值，則留下固定大小的誤差

前向路徑所含積分的個數稱為系統的型別。在1型系統中，只要殘留一點誤差，積分就會持續改變操作量，因此對步階的穩態誤差為0。對斜坡目標值，為了持續追趕需要固定的誤差，其大小為 1/Kv（Kv = lim[s→0] sG(s) 為速度誤差常數）。例如 G(s) = 2/(s(s + 1)) 時 Kv = 2，對單位斜坡的穩態誤差為0.5。

    積分元件 G(s) = 1/s 的波德圖為下列何者？

  • 加大 Kp 會使響應變快，對步階的穩態誤差 1/(1 + Kp·K)（K 為受控體的穩態增益）也變小，但沒有誤差時操作量也會變成0，因此誤差不會變成0（偏移）。
