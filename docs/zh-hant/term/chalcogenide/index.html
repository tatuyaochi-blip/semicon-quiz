什麼是硫族化合物

含有硫、硒、碲等 16 族元素的化合物。用於相變記憶體的記錄材料(GST 等)，以及在某個電壓下會突然導通的選擇器(OTS)。

日文名稱: カルコゲナイド

這個名詞所屬的領域: 新世代記憶體

什麼算是硫族化合物

硫族元素是 16 族元素：氧、硫、硒與碲。雖然氧屬於此族，但氧化物通常被視為獨立的類別，因此在電子學中，硫族化合物通常是指以硫、硒，尤其是碲為基礎，並與鍺、銻或砷等元素結合的化合物。這類化合物中有許多容易形成玻璃，也就是在室溫下保持穩定的非晶態固體，其中有些還能藉由加熱在非晶相與結晶相之間來回切換。正是這樣的組合，使它們在記憶體元件中派上用場。

GST 如何儲存一個位元

在相變記憶體（PCM）中，記憶胞是一小塊硫族化合物，例如 Ge2Sb2Te5（GST），由記憶胞本身的電流加熱。短而大電流的 RESET 脈衝會使該區域熔化，快速冷卻則將其凍結成高電阻的非晶態材料。較長且較溫和的 SET 脈衝則將其維持在結晶溫度以上、熔點以下，使其在數十奈秒內再結晶成低電阻狀態。讀取時使用不會擾動相態的小電壓。由於兩種狀態的電阻相差兩到三個數量級，中間位準可以儲存超過一個位元。

臨界切換與 OTS 選擇器

非晶態硫族化合物會表現出臨界切換現象：超過臨界電壓時，會在數奈秒內驟然進入導通狀態，而當電流降到保持值以下時，又會回到高電阻。在 PCM 中，正是此效應讓足夠的電流能流過非晶態記憶胞，將其加熱並結晶化。雙向臨界開關（OTS）使用會以這種方式切換、但不會結晶的組成，因此不儲存任何資料，純粹作為選擇器。在交叉點陣列中與每個儲存元件串聯時，其極低的關閉電流可抑制經由未選取記憶胞的潛行路徑（sneak path），使堆疊式陣列得以實用化。

工程上的取捨

GST 約在 150 °C 結晶，因此以非晶態保存的資料在高溫下可能遺失；富鍺組成可提高此上限，適用於車用及其他高溫環境，在這些環境中，儲存的資料必須在高溫下長時間保存。RESET 操作需要相對較大的電流來熔化材料，這限制了存取元件的尺寸與功率預算。此外，非晶相的電阻在寫入後會緩慢向上漂移，由於各位準之間的間隔會隨時間改變，使多位準儲存變得更加複雜。

常見問題

氧是硫族元素嗎？

是的，氧是 16 族元素，因此屬於硫族元素，但氧化物依慣例會另外看待。在元件工程中，硫族化合物幾乎都是指硫化物、硒化物與碲化物。

相變記憶體中的 GST 是什麼？

GST 是鍺－銻－碲硫族化合物，典型組成為 Ge2Sb2Te5。它在電流脈衝加熱下，於低電阻的結晶相與高電阻的非晶相之間切換，並以此電阻差儲存資料。

OTS 和相變記憶胞有什麼不同？

兩者都是會發生臨界切換的硫族化合物，但相變記憶胞會結晶並保持其新狀態，而 OTS 維持非晶態，電流移除後就回到高電阻。因此 OTS 用作選擇器，而非用於儲存。
