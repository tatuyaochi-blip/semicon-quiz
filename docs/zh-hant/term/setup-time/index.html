什麼是設定時間

正反器中，在時脈有效邊緣之前，必須先確定資料輸入的最短時間。無法滿足的路徑會限制電路的最高動作頻率。

日文名稱: セットアップ時間

「設定時間」出現在1領域的1道練習題中（測試與檢查等）。

這個名詞所屬的領域: 邏輯電路

正反器為什麼需要設定時間

邊緣觸發正反器通常由兩個閂鎖器構成。在時脈邊緣之前，輸入必須通過第一個閂鎖器，其內部節點也必須穩定下來，才能在該閂鎖器關閉時確實保持數值。若資料在太接近邊緣時變化，正反器可能擷取到舊值或新值，或者進入亞穩態，需要無法預測的時間才能決定。設定時間是邊緣之前必須保持穩定的時間，保持時間則是邊緣之後的時間。兩者都會針對每個元件進行特性化，並隨轉換速率與操作條件而變化。

設定時間檢查與餘裕

在某個邊緣發出的資料，必須在下一個擷取邊緣之前至少提早一個設定時間到達。到達時間等於時脈到輸出延遲加上邏輯延遲；需求時間等於（經時脈偏移調整後的）週期減去設定時間與時脈不確定性。餘裕（slack）等於需求時間減去到達時間，負的餘裕即為違規。在週期 2.0 ns、時脈到輸出 0.2 ns、邏輯 1.4 ns、設定時間 0.1 ns 的情況下，餘裕為 0.3 ns。最慢的路徑，也就是關鍵路徑，決定了最高頻率：總計 2.5 ns 可達 400 MHz。

設定時間與保持時間

設定時間是相對於下一個邊緣的最大延遲檢查，因此只要降低時脈，或透過管線化、減少邏輯深度、加大元件尺寸或使用低臨界電壓元件來縮短路徑，違規就會消失。保持時間是相對於同一個邊緣的最小延遲檢查，與頻率無關，因此以增加延遲來修正。兩者朝相反方向拉扯：有利於設定時間的擷取時脈偏移，會不利於保持時間。在晶片內變異（OCV）降額下，設定時間檢查假設發射端較慢、擷取時脈較早；保持時間檢查則相反。

改變檢查方式的約束條件

2 的多週期路徑會把擷取邊緣移到兩個週期之後，但只有在致能訊號等邏輯確實每隔一個週期才擷取時才成立。在上升緣發出、下降緣擷取的半週期路徑，只有半個週期的時間。閂鎖器允許時間借用：在閂鎖器打開後才到達的資料，只要在關閉前到達仍可通過，等於從下一級借用時間。在晶片邊界，set_input_delay 與 set_output_delay 描述在晶片外部花費的時間。有益偏移（useful skew）則刻意延後擷取時脈，以重新平衡相鄰的各級。

AC測試會量測從輸入到輸出的傳遞延遲時間、設定時間與保持時間、輸出的上升與下降時間等與時間相關的特性。測試機會針對每個腳位細部設定輸出訊號的時序以及判定輸出的時序（strobe）來進行量測。漏電流屬於直流特性，所以由DC測試確認，外觀則由外觀檢查確認。

常見問題

設定時間和保持時間有什麼差別？

設定時間是資料在時脈邊緣之前必須保持穩定的時間，保持時間則是在邊緣之後必須保持穩定的時間。設定時間限制了最高頻率，而保持時間違規與時脈頻率無關。

設定時間的 slack 怎麼計算？

slack = 需求時間 − 到達時間，其中到達時間為時脈到輸出延遲加上邏輯延遲，需求時間為（經偏移調整後的）時脈週期減去設定時間與時脈不確定性。slack 為正表示該路徑符合時序要求。

降低時脈頻率可以修正設定時間違規嗎？

可以，較長的週期讓資料有更多時間到達，因此頻率降到夠低時，設定時間違規就會消失。保持時間違規則不會，因此一旦晶片製成，它更加危險。
