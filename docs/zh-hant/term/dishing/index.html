什麼是碟形凹陷

CMP時，寬幅金屬導線的中央部分被過度研磨而凹陷成碟狀的現象。

閱讀入門解說: CMP（化學機械研磨）是什麼？把晶圓磨平的理由與原理

日文名稱: ディッシング

「碟形凹陷」出現在1領域的1道練習題中（CMP與清洗等）。

這個名詞所屬的領域: CMP與清洗

碟形凹陷發生的原理

在銅導線的鑲嵌製程中，會在絕緣膜挖出的溝槽中填入銅，再以CMP去除溝槽外多餘的銅與阻障層。此時銅比周圍的絕緣膜柔軟，也容易受研磨液的化學作用而被移除，因此即使表面高度已經一致，銅的部分仍會持續被研磨。研磨墊會稍微彎曲而陷入導線中，因此越寬的導線或焊墊，中央被磨得越深，呈碟子（dish）狀凹陷。這就是碟形凹陷（又稱碟化）；一般而言，導線越寬、過研磨時間越長，凹陷就越深。

碟形凹陷與侵蝕的差異

碟形凹陷發生在單一條寬導線或焊墊內部，取決於導線寬度。相對地，侵蝕是細導線密集排列的整個區域，連同導線之間的絕緣膜一起被磨得比周圍低的現象，取決於導線密度。在密集區域兩者會同時發生，銅的總損失厚度大約是侵蝕量加上各導線碟形凹陷量的和。兩者也常合併成CMP後的表面段差來評估。在STI氧化層的CMP中，寬溝槽內的氧化層也會發生碟形凹陷。

在製造中成為問題的原因

導線中央凹陷後，銅變薄使導線電阻上升，且電阻因位置而異，會使電路的時序偏移。此外，凹陷的段差會延續到上層，消耗下一層微影的焦深。在上層金屬的CMP中，凹陷處可能殘留金屬，成為使相鄰導線短路的殘留物。在直接接合晶圓的混合接合（hybrid bonding）中，銅電極表面高度的管理特別重要，有時會刻意控制凹陷量。

抑制方法

在設計方面，會限制導線寬度的上限，並在寬導線或焊墊中開狹縫，分割為細導線的集合。在製程方面，會將研磨分為數個階段，先快速磨除大部分的銅，再以調整過對絕緣膜與阻障層選擇比的研磨液收尾，並以終點偵測將過研磨抑制在必要的最小限度。硬質研磨墊陷入導線的彎曲較小，有減少碟形凹陷的效果。也會在研磨液中加入保護銅表面的腐蝕抑制劑，抑制凹陷處的化學溶解。

練習碟形凹陷的題目

  2. B研磨液的粒子附著殘留在晶圓上的現象
  3. C寬幅配線部分的中央被過度研磨而低於周圍，呈碟狀凹陷的現象
查看答案與解析

正確答案：C. 寬幅配線部分的中央被過度研磨而低於周圍，呈碟狀凹陷的現象

碟化是指在寬幅的金屬配線或焊墊上，較軟的金屬中央部分被磨掉的量多於周圍的絕緣膜，呈碟子（dish）狀凹陷的現象，寬度愈寬愈嚴重。這會使配線變薄而電阻增加，或使上層殘留凹凸不平。配線密集的區域連同絕緣膜整體被過度磨除的現象則稱為侵蝕（erosion）。設計上可藉由限制配線寬度的上限，或以狹縫分割較粗的配線來加以抑制。

常見問題

碟形凹陷與侵蝕有什麼不同？

碟形凹陷是寬導線或焊墊中央像碟子般凹陷的現象，導線越寬越嚴重。侵蝕是導線密集排列的整個區域連同絕緣膜一起被磨低的現象，導線密度越高越嚴重。

為什麼導線越寬碟形凹陷越大？

因為研磨墊會稍微彎曲，在寬導線中能陷入到中央並壓在上面，使柔軟的銅持續被移除。在細導線中，兩側堅硬的絕緣膜會撐住研磨墊，因此凹陷較小。

如何抑制碟形凹陷？

在設計上限制導線寬度的上限，或以狹縫分割寬導線。在製程上將研磨分階段並調整選擇比，以終點偵測抑制過研磨，並使用硬質研磨墊等。
