什麼是語法分析

檢查語彙單元序列是否符合語言的文法，並將程式結構組成樹狀的編譯器階段。文法錯誤會在這裡被發現。

日文名稱: 構文解析

「語法分析」出現在1領域的6道練習題中（編譯器等）。

這個名詞所屬的領域: 編譯器

語法分析在編譯器中的位置

編譯器前端分階段運作。語彙分析將字元串流轉換為識別字、數字與符號等語彙單元，並捨棄空白與註解。接著語法分析（又稱剖析）檢查該語彙單元序列是否依語言文法構成有效的程式，並記錄各部分如何巢狀組合：哪些敘述構成迴圈本體、哪些運算元屬於哪個運算子。缺少分號或括號不對稱等錯誤會在此階段回報。之後是語意分析，檢查型別以及名稱是否已宣告，然後程式才被轉換為中間表示，以進行最佳化與程式碼產生。

為什麼需要上下文無關文法

語彙單元的規則夠簡單，可以用正規表示式與快速的有限狀態自動機處理，但程式結構則不然。巢狀括號以及if敘述中的if敘述需要計數到無限深度，這是正規表示式做不到的。因此程式語言以上下文無關文法描述，也就是像expr → expr + term這樣的改寫規則集合，常以巴科斯-諾爾範式（BNF）撰寫。設計良好的文法也會編入運算子的優先順序與結合性，使a + b * c先組合乘法。一個輸入可能產生兩棵樹的歧義文法必須避免，或以額外規則解決。

由上而下的LL與由下而上的LR剖析

LL剖析器由上而下運作：從起始符號開始，觀察接下來的一個或數個語彙單元來預測要套用哪條規則。手寫的遞迴下降剖析器為每條文法規則撰寫一個函式，屬於LL風格，因清晰易懂且錯誤訊息良好而被廣泛使用，但需要改寫左遞迴規則。LR剖析器則由下而上運作：將語彙單元移入堆疊，一旦辨識出完整的規則右側，就將其歸約為該規則。LR可處理更廣泛的文法類別，而yacc與Bison等剖析器產生器會自動建立LALR表。

剖析樹與抽象語法樹

完全依照文法會產生具體語法樹（又稱剖析樹），其中包含每個括號、分隔符號與中間規則。後續階段需要的資訊少得多，因此剖析器通常改為建立抽象語法樹（AST）。在(a + b) * c的AST中，加法節點直接位於乘法節點之下；樹的形狀本身就表達了求值順序，括號因此消失。AST是語意分析用來標註型別與作用域的資料結構，之後編譯器再將它轉換為中間碼。

練習語法分析的題目

  1. A從字元序列中移除空白與註解，並切分為單字
  2. B找出經常執行的部分，並在執行時轉換為機器碼
  3. C依照文法檢視token序列，將程式的結構組成樹狀結構

正確答案：C. 依照文法檢視token序列，將程式的結構組成樹狀結構

語法分析會檢查詞法分析所得的token序列是否符合語言的文法，並將if敘述的條件與主體、運算式中各運算的組合等結構組成樹狀結構（語法樹）。漏寫分號或括號不成對等文法錯誤，會在這個階段被發現。移除空白並切分為單字的是詞法分析，在執行時轉換為機器碼的則是JIT編譯。

下列何者是用來表示許多程式語言的文法、並成為語法分析之基礎的文法種類？

  1. A僅有正規文法
  2. B自然語言的文法
  3. C脈絡無關文法（context-free grammar）
查看答案與解析

正確答案：C. 脈絡無關文法（context-free grammar）

括號的巢狀結構，或if敘述裡面還有if敘述的結構，無法用正規表示式表示。許多程式語言的文法是用脈絡無關文法表示的，它是像「運算式 → 運算式 + 項」這樣的改寫規則的集合，語法分析就是依據這種文法來進行。解析方法有從上往下套用規則的LL法，以及從下往上組建的LR法等，也有能從文法自動產生解析器的工具。正規文法適用於詞法分析，無法處理巢狀結構。

常見問題

語彙分析和語法分析有什麼差別？

語彙分析將原始碼文字切分為語彙單元，並捨棄空白與註解。語法分析則接收這些語彙單元，依文法加以檢查，並建立描述程式結構的樹。

什麼是抽象語法樹？

抽象語法樹是只保留表達語意所需運算與敘述的程式樹狀表示。括號等分組符號會被省略，因為樹的形狀本身就表達了優先順序與巢狀關係。

LL剖析器和LR剖析器有什麼差別？

LL剖析器由上而下建樹，依接下來的語彙單元預測規則，手寫的遞迴下降剖析器也屬此類。LR剖析器則由下而上建樹，將語彙單元移入堆疊並歸約為規則，可接受更廣泛的文法類別。
