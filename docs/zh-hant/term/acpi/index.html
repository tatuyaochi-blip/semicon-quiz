什麼是ACPI

Advanced Configuration and Power Interface 的縮寫。供作業系統管理裝置電源狀態、省電與溫度的標準機制。

日文名稱: ACPI

「ACPI」出現在1領域的1道練習題中（電源管理（軟體控制）等）。

這個名詞所屬的領域: 電源管理（軟體控制）

  3. C無線區域網路的規格
查看答案與解析

正確答案：B. 讓OS進行機器的電源狀態、省電及溫度管理，位於硬體與OS之間的標準機制

ACPI（Advanced Configuration and Power Interface）是讓OS管理系統或機器電源狀態的標準機制。韌體會以表格的形式將機器的組態與電源操作方式告知OS，OS則利用它來進行轉換至睡眠（S3）或休眠狀態（S4）、控制CPU的C-state與P-state、依溫度控制風扇等。它同時也扮演對OS隱藏各機器差異的角色。
