什麼是二元對稱通道

傳送0或1，各位元不論送出的值為何，都以相同機率p翻轉，且彼此獨立地出錯的通道模型。也稱為BSC。通道容量為 C = 1 − H(p) 位元／次（H(p) = −p log₂ p − (1 − p) log₂(1 − p)），p = 0.1 時約為0.53位元，p = 0.5 時為0。p = 1 時一定會翻轉，因此只要把收到的值反轉就能無誤傳達，容量回到1。這是思考處理位元錯誤之錯誤更正碼性能時的基本模型。

練習二元對稱通道的題目

某二元對稱通道傳送0與1，各位元彼此獨立地以機率0.1翻轉。設二元熵函數為 H(p) = −p log₂ p − (1 − p) log₂(1 − p)，則 H(0.1) ≈ 0.469。此通道每次傳輸的通道容量最接近下列何者？

  1. A約0.47位元
  2. B約0.53位元
  3. C0.9位元
查看答案與解析

正確答案：B. 約0.53位元

二元對稱通道的通道容量為 C = 1 − H(p)，是以相等機率傳送0與1時的互資訊值。p = 0.1 時 C ≈ 1 − 0.469 = 0.531，每次傳輸約0.53位元。只要使用適當的錯誤更正碼，就能以這個比例以內的速度，讓錯誤率任意小地傳送資料。p = 0.5 時收到的值與送出的值無關，容量為0。
