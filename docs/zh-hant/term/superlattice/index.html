什麼是超晶格

將不同材料的層以數nm左右的厚度交替堆疊而成的週期性結構。會出現原本晶體所沒有的電子性質，用於雷射與緩衝層等。

日文名稱: 超格子

「超晶格」出現在2領域的3道練習題中（磊晶成長, 化合物半導體等）。

這個名詞所屬的領域: 磊晶成長

練習超晶格的題目

在異質接面的能帶排列方式中，下列何者是「第I型（Type I）」的正確說明？

  1. A能隙較小的材料的導帶下緣與價帶上緣，都落在能隙較大的材料的能隙內側
  2. B兩種材料的能隙不重疊
  3. C兩種材料的導帶與價帶錯開而呈交錯排列
查看答案與解析

正確答案：A. 能隙較小的材料的導帶下緣與價帶上緣，都落在能隙較大的材料的能隙內側

在第I型中，能隙較小的材料的能帶落在能隙較大的材料的能帶內側，因此電子與電洞兩者都被侷限在能隙較小的層（如GaAs/AlGaAs）。用於在LED或雷射的量子井中有效率地複合。交錯排列的第II型則是電子與電洞分別位於不同的層，用於長波長紅外線偵測器（InAs/GaSb超晶格）等。

當基板與成長膜的晶格常數差異（晶格不匹配）很大時，容易發生下列何種問題？

  1. A產生失配差排等晶體缺陷
  2. B膜一定會變成非晶質
  3. C成長速率變為0
查看答案與解析

正確答案：A. 產生失配差排等晶體缺陷

成長晶格常數不同的材料時，膜會配合基板而收縮或伸長，使應變累積，超過臨界膜厚後，為了釋放應變，界面上會產生失配差排。其中一部分會成為貫穿膜層的貫穿差排，導致漏電流、發光效率下降及壽命縮短。對策包括逐漸改變組成的緩衝層、使差排彎曲的超晶格，以及選擇性成長等。
