什麼是米利型（Mealy machine）

輸出由目前狀態與輸入兩者決定的狀態機。輸入的變化在同一週期就會反映在輸出，但輸入的雜訊也容易傳到輸出。輸出僅由狀態決定的是摩爾型。

米利型的定義與結構

在米利型狀態機（Mealy machine）中，輸出由目前的狀態與目前的輸入兩者決定。它與摩爾型一樣由狀態暫存器、決定下一狀態的組合電路以及決定輸出的組合電路構成，不同之處在於輸入直接連到輸出電路。在狀態轉移圖中，輸出不是寫在狀態裡，而是以「輸入/輸出」的形式寫在轉移箭頭上。由於輸入一改變，輸出不必等待下一個時脈就會改變，因此能比摩爾型早1個週期反應，而且常能以較少的狀態實現相同的功能。

與摩爾型的比較

摩爾型的輸出只由目前的狀態決定，在狀態轉移圖中輸出寫在狀態裡。輸入的變化要等時脈使狀態改變後才會反映到輸出，反應會慢1個週期，但輸入的雜訊不會傳到輸出，時序也容易預測。若將狀態編碼成可直接從狀態暫存器的位元取出輸出，還能消除輸出的突波。米利型從輸入到輸出有組合電路路徑相連，因此輸入的突波會出現在輸出，包含前後電路的時序路徑也會變長。

範例：以序列偵測器比較

以從輸入位元串中找到「101」就輸出1、允許重疊的序列偵測器來比較。米利型只需要「尚未匹配」「匹配到1」「匹配到10」3個狀態。因為只要在「匹配到10」的狀態下輸入1時就讓輸出為1，並把這個1當作下一個候選，轉到「匹配到1」即可。摩爾型則需要另外一個代表輸出1的「偵測到101」狀態，共4個狀態，而且要到擷取最後一個1的時脈之後輸出才會變為1。由此可見，米利型狀態少、反應快，而在輸出的穩定性上摩爾型較有利。

以HDL設計時的注意事項

在Verilog或VHDL中，一般會把更新狀態暫存器的序向電路區塊，與決定下一狀態及輸出的組合電路區塊分開撰寫；若輸出的式子中含有輸入，就是米利型。直接使用非同步輸入會使輸出紊亂，因此要先將輸入同步化。把米利型的輸出接到另一個米利型的輸入時，可能形成組合電路迴路，需要注意。若以正反器重新擷取輸出，突波會消失，但時序就會像摩爾型一樣慢1個週期。

練習米利型（Mealy machine）的題目

米利型（Mealy）狀態機的特徵，下列何者正確？

  1. A輸出只由目前的狀態決定，即使輸入改變，輸出也要到下一個時脈才會改變
  2. B輸出由目前的狀態與輸入兩者決定，因此輸入的變化會在同一個週期內反映到輸出
  3. C是不具狀態的組合電路
查看答案與解析

正確答案：B. 輸出由目前的狀態與輸入兩者決定，因此輸入的變化會在同一個週期內反映到輸出

在米利型中，輸出的邏輯除了目前的狀態之外也會看輸入，所以輸入一改變，輸出不必等待時脈就會改變，能早1個週期反應。狀態的數量也可能較少。另一方面，由於從輸入到輸出的組合電路路徑相連，輸入的雜訊會反映到輸出，時序路徑也會變長。也會將輸出以正反器重新接收後再使用。

常見問題

米利型和摩爾型有什麼不同？

米利型的輸出由目前的狀態與輸入兩者決定，摩爾型只由目前的狀態決定。米利型能在同一個週期內回應輸入，狀態數也常較少，但輸入的雜訊較容易傳到輸出。

米利型和摩爾型應該用哪一種？

若重視反應速度或較少的狀態數，適合米利型；若重視輸出的穩定性與時序的可預測性，適合摩爾型。實際設計中，會依各個輸出分別選用，或將兩者組合使用。

米利型可以轉換成摩爾型嗎？

可以。將米利型的每個狀態，依進入該狀態之轉移的輸出拆分成不同的摩爾型狀態，就能得到相同的輸入輸出關係。不過狀態數可能增加，而且輸出會晚1個時脈出現。
