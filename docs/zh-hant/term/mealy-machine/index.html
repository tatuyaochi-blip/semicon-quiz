什麼是米利型（Mealy machine）

輸出由目前狀態與輸入兩者決定的狀態機。輸入的變化在同一週期就會反映在輸出，但輸入的雜訊也容易傳到輸出。輸出僅由狀態決定的是摩爾型。

日文名稱: ミーリ型

「米利型（Mealy machine）」出現在1領域的1道練習題中（邏輯電路等）。

練習米利型（Mealy machine）的題目

輸出僅由目前狀態決定的序向電路（狀態機）類型是哪一個？

  1. A米利型
  2. B摩爾型
  3. C哈佛型
查看答案與解析

正確答案：B. 摩爾型

摩爾型的輸出僅由目前狀態決定，米利型的輸出則由狀態與輸入兩者決定。摩爾型的輸出直接來自狀態暫存器，因此突波少、穩定，時序也容易預測，但對輸入的反應會慢1個時脈，且狀態數容易增加。米利型可減少狀態數並能立即回應輸入，但輸入的變化會直接傳到輸出。實際設計中會將兩者組合使用。

解析中的「米利型（Mealy machine）」

  • 摩爾型的輸出僅由目前狀態決定，米利型的輸出則由狀態與輸入兩者決定。
