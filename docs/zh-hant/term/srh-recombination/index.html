什麼是SRH 復合(蕭克萊-里德-霍爾復合)

電子與電洞經由禁帶中產生的深能階(陷阱)而復合的過程。主要決定矽中少數載子的生命期，會因金屬汙染或晶體缺陷而加快。

日文名稱: SRH再結合(ショックレー・リード・ホール再結合)

這個名詞所屬的領域: 半導體物性

陷阱如何媒介復合

能隙中的深能階可以從導電帶捕獲一個電子，然後從價電帶捕獲一個電洞，以兩個步驟消滅這對載子；被捕獲的載子發射回其能帶則是與之競爭的過程。淨速率為 U = (np − ni²) / [τp(n + n1) + τn(p + p1)]，其中 n1 與 p1 描述陷阱的位置。靠近能隙中央的陷阱使 n1 與 p1 最小，因此效果最強。釋放的能量主要轉為晶格振動，而不是光。

生命期及其殺手

特徵捕獲生命期為 τ = 1/(σ·vth·Nt)，其中 σ 為捕獲截面積，vth 為熱速度，Nt 為陷阱密度，因此生命期與陷阱濃度成反比下降。鐵、金等重金屬，以及差排等晶體缺陷是典型的元兇。在輻射復合很弱的間接能隙半導體矽中，SRH 復合在中等載子密度下占主導，決定了少數載子生命期，而少數載子生命期通常以光電導衰減法量測。

刻意的生命期控制

快速切換元件有時需要短的生命期。快速恢復二極體與 IGBT 會刻意導入復合中心，方法是鉑或金擴散，或電子或質子照射，使儲存的少數載子在關斷時迅速消失。這會縮短逆向恢復時間並降低切換損耗，但也會提高順向壓降與漏電，因此生命期的調整是導通損耗與切換損耗之間的折衷。

SRH 產生與漏電

當 np 小於 ni² 時，例如在逆向偏壓的空乏區中，相同的陷阱會反向運作，產生電子－電洞對。這種產生電流是室溫下矽 pn 接面逆向漏電的主要來源，也是影像感測器暗電流的主要來源。它與 ni 成正比，而 ni 隨 exp(−Eg/2kT) 變化，因此其活化能約為能隙的一半；而與 ni² 成正比的擴散電流，活化能接近整個能隙，在高溫下會成為主導。

常見問題

為什麼位於能隙中央的陷阱是最有效的復合中心？

能隙中央的能階能以相近的速率捕獲電子與電洞，且很少以熱方式再發射，因此被捕獲的載子傾向於復合，而不是逃回其能帶。

SRH 復合、輻射復合與歐傑復合有什麼差別？

SRH 經由陷阱能階進行，在矽中於中等密度下占主導；輻射復合會發射光子，在直接能隙材料中很強；歐傑復合將能量交給第三個載子，在極高的載子密度下占主導。

什麼會縮短矽中的少數載子生命期？

鐵、金等深能階雜質與晶體缺陷，它們作為 SRH 復合中心；生命期大致與其密度成反比下降。
