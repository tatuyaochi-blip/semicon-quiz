什麼是共振電路

在線圈與電容器的電抗互相抵銷的頻率（共振頻率 f0 = 1/(2π√(LC))）出現特殊行為的電路。串聯共振時阻抗降到最小值R、電流最大；並聯共振時阻抗最大、電源電流最小。共振的尖銳程度以Q值表示，頻寬為 f0/Q。用於濾波器、振盪電路與無線電的調諧電路。

這個名詞所屬的領域: 電路分析（交流電路、線性電路與暫態現象）

串聯共振與並聯共振

串聯RLC電路的阻抗為 Z = R + j(ωL − 1/(ωC))，在 ω0 = 1/√(LC) 時虛部為0，電流 V/R 最大。並聯RLC電路則是導納 Y = 1/R + j(ωC − 1/(ωL)) 的虛部為0，阻抗最大。L = 1 mH、C = 10 nF 時，兩者都是 f0 ≈ 50.3 kHz。

Q值與電壓的放大

串聯共振時 Q = (1/R)√(L/C)，並聯共振時 Q = R√(C/L)。串聯共振時L與C的電壓為電源電壓的Q倍，並聯共振時L與C的電流為電源電流的Q倍。小電源也能得到大電壓或大電流，但要注意不可超過元件的耐壓與電流額定。

使用的場合

收音機的調諧電路利用LC共振只選出目標頻率的信號。LC振盪電路與石英振盪器利用共振的尖銳度產生穩定的頻率。另一方面，印刷電路板上電源配線與元件的寄生電感和電容若形成非預期的共振，在特定頻率下雜訊與電壓變動會變大。

練習共振電路的題目

L = 1 mH、C = 10 nF的串聯共振電路，其共振頻率最接近下列哪一個？

  1. A約50 kHz
  2. B約316 kHz
  3. C約5 kHz
查看答案與解析

正確答案：A. 約50 kHz

共振頻率為 f0 = 1/(2π√(LC))。LC = 1×10⁻³ × 10×10⁻⁹ = 1×10⁻¹¹，因此 √(LC) ≈ 3.16×10⁻⁶ s，f0 ≈ 1/(2π × 3.16×10⁻⁶) ≈ 50.3 kHz。此時線圈與電容器的電抗都等於 √(L/C) ≈ 316 Ω。共振頻率與LC乘積的平方根成反比，C變為100倍時共振頻率變為1/10。

R = 10 Ω、L = 1 mH、C = 10 nF的串聯RLC共振電路，其頻寬（電流降為共振時 1/√2 的兩個頻率之差）最接近下列哪一個？

  1. A約1.6 kHz
  2. B約10 kHz
  3. C約50 kHz
查看答案與解析

正確答案：A. 約1.6 kHz

共振頻率為 f0 = 1/(2π√(LC)) ≈ 50.3 kHz，Q值為 Q = (1/R)√(L/C) = (1/10) × √(1×10⁻³/(10×10⁻⁹)) ≈ 316/10 ≈ 31.6。頻寬為 BW = f0/Q ≈ 50.3 kHz/31.6 ≈ 1.59 kHz。串聯RLC也可直接由 BW = R/(2πL) = 10/(2π × 1×10⁻³) ≈ 1.59 kHz 求得。電阻越小頻寬越窄，頻率選擇性越高。

常見問題

為什麼在共振頻率時電流不會變成無限大？

因為串聯共振時即使電抗互相抵銷，電阻R仍然存在。電流由 V/R 決定，R越小Q值越高，電流的峰值越尖銳。實際線圈的繞線電阻與電容器的損失也會作為R作用。

並聯共振時L與C沒有電流流過嗎？

有電流流過。L與C的電流大小相等、方向相反，從電源看起來互相抵銷，但在L與C之間有電源電流Q倍的電流來回流動。能量在線圈的磁場與電容器的電場之間交替傳遞。
