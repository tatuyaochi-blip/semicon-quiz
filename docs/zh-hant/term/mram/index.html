什麼是MRAM

利用磁性穿隧接面(MTJ)磁化方向所造成的電阻差異來儲存資訊的非揮發性記憶體。

日文名稱: MRAM

「MRAM」出現在2領域的19道練習題中（新世代記憶體, SRAM與快閃記憶體等）。

這個名詞所屬的領域: 新世代記憶體

磁穿隧接面如何儲存位元

儲存元件是磁穿隧接面（MTJ）：一個固定的參考層與一個可切換的自由層，兩者都是鐵磁性材料，中間隔著約 1 nm 厚的絕緣穿隧能障。當兩者磁化方向平行時，電子容易穿隧，電阻低；反平行時電阻高。這種穿隧磁阻（TMR）用來區分 0 與 1。結晶 MgO 能障可得到數百% 的 TMR 比，遠高於非晶 Al2O3 的數十%。讀取時通入小電流並與參考值比較；讀取不會擾動磁化方向，因此不需要寫回。

以自旋轉移力矩寫入

在 STT-MRAM 中，寫入電流直接流過 MTJ 本身。被參考層自旋極化的電子把角動量轉移給自由層並使其翻轉；電流方向決定寫入的狀態。早期的 MRAM 是以鄰近導線產生的磁場寫入，STT 則不同，其寫入電流會隨單元面積縮小，因此能夠微縮。限制在於熱穩定性：能障等於異向性乘以自由層體積，其與 kT 的比值稱為 Δ，要保存十年資料，Δ 大約需達 60 以上。提高 Δ 會提高寫入電流，因此使用垂直磁化材料來取得兩者的平衡。

邏輯晶片中的嵌入式 MRAM

MTJ 是在電晶體完成後，於後段製程（BEOL）中建構在導線層之間，只需增加少數幾道光罩。相對地，嵌入式快閃記憶體的浮動閘極需要增加十道以上的光罩，在約 28 nm 以下或使用高介電常數/金屬閘極時變得不切實際。這使 MRAM 成為 22 nm 以下微控制器與車用晶片中嵌入式快閃記憶體的主要替代方案。整合上的挑戰包括承受約 400 °C 的 BEOL 熱製程，以及在不造成金屬再沉積的情況下對磁性薄膜進行圖案化，通常採用離子束蝕刻。

MRAM 與其他記憶體的比較

與快閃記憶體相比，MRAM 不需抹除步驟，寫入只需數奈秒到數十奈秒，耐久度超過 10¹⁰ 次，而 NAND 為數千到數萬次。與 DRAM 和 SRAM 不同，它是非揮發性的。其弱點在於密度與讀取裕度：單元比 NAND 單元大且無法 3D 堆疊，因此每位元成本高得多；而 2 到 3 倍的電阻比，使其讀取裕度小於 DRAM 或快閃記憶體。FeRAM 則改以鐵電極化儲存資料，相變化記憶體則以結晶態與非晶態的電阻差異儲存資料。

  2. B硫族化物材料的結晶狀態與非晶態之間的電阻差異
  3. C電容中有無儲存電荷
查看答案與解析

正確答案：A. 磁性穿隧接面（MTJ）因磁化方向不同而造成的電阻差異

MRAM 使用磁性穿隧接面（MTJ），即以兩個磁性層夾住厚約 1 nm 的絕緣層。磁化方向平行時電阻低，反平行時電阻高，利用這種穿隧磁電阻效應區分 0 與 1，且磁化不需電源即可保持，因此是非揮發性。其優勢在於改寫次數幾乎無限且速度快。利用結晶與非晶之間電阻差異的是相變記憶體，利用電荷的是 DRAM。

與快閃記憶體相比，MRAM 的一般優點，下列何者正確？

  1. A每位元成本低得多
  2. B斷電後資料就會消失
  3. C可改寫次數非常多，寫入也很快
查看答案與解析

正確答案：C. 可改寫次數非常多，寫入也很快

MRAM 以磁化方向記憶，因此改寫次數遠多於伴隨氧化膜劣化的快閃記憶體（10¹⁰ 次以上），寫入也很快，只要數～數十 ns，且不需要抹除步驟。因此在微控制器與車用設備的嵌入式記憶體，以及頻繁記錄資料的用途中，採用逐漸增加。另一方面，單元大又無法堆疊，在大容量化與每位元單價上遠不及 NAND 快閃記憶體。

常見問題

MRAM 是揮發性還是非揮發性記憶體？

MRAM 是非揮發性的：資料保存在自由層的磁化方向中，沒有電源也能維持，通常可達十年以上。同時它還兼具高速寫入與極高的耐久度。

STT-MRAM 和 toggle MRAM 有什麼差別？

toggle MRAM（磁場寫入式 MRAM）利用鄰近導線電流產生的磁場翻轉自由層，單元越小所需電流越大。STT-MRAM 則讓自旋極化電流直接通過 MTJ，因此寫入電流會隨單元尺寸縮小。

MRAM 為什麼會取代嵌入式快閃記憶體？

嵌入式快閃記憶體會增加許多製程步驟，在約 28 nm 以下或使用高介電常數/金屬閘極時難以整合。MRAM 建構在導線層中，只需增加少數幾道光罩，且寫入更快、耐久度更高。
