什麼是FOUP

用於以密閉狀態搬運與存放300 mm晶圓的容器。

日文名稱: FOUP

「FOUP」出現在1領域的2道練習題中（矽晶圓等）。

這個名詞所屬的領域: 無塵室與製造設備

練習FOUP的題目

從單晶晶錠製作晶圓的製程順序，下列哪一項最為適當？

  1. A切片 → 研磨(研削) → 蝕刻 → 鏡面拋光
  2. B鏡面拋光 → 切片 → 蝕刻 → 研磨
  3. C蝕刻 → 鏡面拋光 → 切片 → 研磨
查看答案與解析

正確答案：A. 切片 → 研磨(研削) → 蝕刻 → 鏡面拋光

先研削晶錠外周使直徑一致，加工出缺口後，以多線鋸切成不到1 mm的厚度(切片)。經倒角後，以研磨或研削調整厚度與平坦度，再以蝕刻去除加工所產生的數十µm損傷層，最後以雙面拋光與精拋光做成接近原子等級的鏡面。之後經過清洗與檢查，裝入潔淨容器(FOUP)出貨。

直徑300 mm、厚度775 µm的矽晶圓，每片的質量最接近下列哪一項？(矽的密度約為2.33 g/cm³)

  1. A約13 g
  2. B約1,280 g
  3. C約128 g
查看答案與解析

正確答案：C. 約128 g

體積為 π × (15 cm)² × 0.0775 cm ≈ 54.8 cm³，乘以密度2.33 g/cm³ 後約為128 g。200 mm晶圓(厚度725 µm)則約53 g。裝入25片300 mm晶圓的容器(FOUP)總重約8 kg，所以工廠中以天花板搬運系統(OHT)自動搬運。重量與易碎性，是大口徑化後不再以人工搬運的原因之一。
