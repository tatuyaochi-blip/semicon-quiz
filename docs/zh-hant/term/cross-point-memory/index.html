什麼是交叉點型記憶體

在縱橫配線的交點處放置記憶元件的結構之記憶體。可達到高密度，但為防止電流繞入未被選擇的單元，須在記憶元件上串聯選擇器(選擇元件)。

日文名稱: クロスポイント型メモリ

「交叉點型記憶體」出現在1領域的1道練習題中（新世代記憶體等）。

這個名詞所屬的領域: 新世代記憶體

練習交叉點型記憶體的題目

在將電阻變化元件配置於縱橫導線交點的交叉點型記憶體中，為了防止電流繞進未被選擇的單元，與記憶元件串聯的元件是下列何者？

  1. A電容
  2. B電感
  3. C選擇器（選擇元件）
查看答案與解析

正確答案：C. 選擇器（選擇元件）

交叉點型在各交點不放電晶體，而是把記憶元件直接放在縱橫導線的交點，因此單元面積可達最小的 4F²，也能堆疊多層。然而流過未選擇單元的潛行電流（sneak current）會妨礙讀取，因此要串聯在某一電壓以下幾乎不通電流的選擇器。選擇器被要求具備導通電流大、關閉電流小的高度非線性特性。
