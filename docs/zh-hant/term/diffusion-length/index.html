什麼是擴散長度

少數載子在復合之前藉由擴散前進的平均距離。由擴散係數 D 與生命期 τ 以 L = √(Dτ) 表示。與太陽能電池及受光元件的效率密切相關。

日文名稱: 拡散長

「擴散長度」出現在1領域的1道練習題中（雙載子電晶體等）。

這個名詞所屬的領域: 半導體物性

練習擴散長度的題目

使雙極性電晶體的基極寬度變薄，其主要理由以下何者最為適當？

  1. A為了提高集極的耐壓
  2. B為了降低基極電阻
  3. C為了減少基極中的復合，提高電流增益
查看答案與解析

正確答案：C. 為了減少基極中的復合，提高電流增益

從射極注入基極的載子，在通過基極的過程中有一部分會復合而消失，這部分就成為基極電流。若將基極做得遠比擴散長度薄，通過時間縮短，大部分載子都能到達集極，因此電流增益提高，高頻特性也變好。代價是基極電阻變大，且集極的空乏區容易延伸到射極而發生貫穿（punch-through），就耐壓而言較為不利。

解析中的「擴散長度」

  • 若將基極做得遠比擴散長度薄，通過時間縮短，大部分載子都能到達集極，因此電流增益提高，高頻特性也變好。
