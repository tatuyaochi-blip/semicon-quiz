什麼是擴散長度

少數載子在復合之前藉由擴散前進的平均距離。由擴散係數 D 與生命期 τ 以 L = √(Dτ) 表示。與太陽能電池及受光元件的效率密切相關。

日文名稱: 拡散長

「擴散長度」出現在2領域的3道練習題中（半導體物性, 雙載子電晶體等）。

這個名詞所屬的領域: 半導體物性

練習擴散長度的題目

表示半導體載子的擴散係數D與遷移率μ之關係的愛因斯坦關係式，下列何者正確？（k：波茲曼常數、T：絕對溫度、q：基本電荷）

  1. AD = qμ
  2. BD = μ / (kT)
  3. CD = μkT / q
查看答案與解析

正確答案：C. D = μkT / q

愛因斯坦關係式為 D = μkT/q。無論擴散或漂移，都取決於載子在不被散射的情況下能移動多遠，因此兩者成正比。室溫下 kT/q ≈ 26 mV，所以電子（μ ≈ 1400 cm²/V·s）的 D ≈ 36 cm²/s，電洞（約450）則約為12 cm²/s。只要有遷移率的數據表，就能立即求出擴散係數，用於擴散長度和元件的計算。

當少數載子的擴散係數為D、生命期為τ時，表示擴散長度L的式子為下列何者？

  1. AL = D / τ
  2. BL = √(D × τ)
  3. CL = D × τ
查看答案與解析

正確答案：B. L = √(D × τ)

擴散長度是少數載子在複合之前藉由擴散所前進的大致距離，L = √(Dτ)。例如 D = 36 cm²/s、τ = 10 µs 時，L = √(3.6×10⁻⁴) ≈ 190 µm。確認單位可得 √(cm²/s × s) = cm，只有這個式子能得到長度。在太陽能電池中，擴散長度比厚度越長，越容易收集光所產生的載子；在雙載子電晶體中，則要使基極寬度遠短於擴散長度。
