什麼是DIMM

將多顆 DRAM 晶片裝在小型基板上，可插入個人電腦與伺服器插槽的記憶體模組。

日文名稱: DIMM

「DIMM」出現在1領域的1道練習題中（DRAM等）。

這個名詞所屬的領域: DRAM

DIMM的結構與名稱由來

DIMM（Dual Inline Memory Module）是將多顆DRAM晶片裝在細長的印刷電路板上，可插入主機板插槽的記憶體模組。早期的SIMM正反兩面的接點連接到相同的訊號，而DIMM正反兩面的接點各自具有不同的訊號，因此稱為「雙（dual）」。基板上除了DRAM晶片之外，還有記錄容量、速度、時序等資訊、稱為SPD的小型非揮發性記憶體，主機板在開機時讀取它來設定記憶體。接點中間缺口的位置依世代而不同，避免誤插不同世代的模組。

種類與用途

桌上型電腦用的一般DIMM不對訊號進行緩衝，因此也稱為UDIMM（無緩衝DIMM）。筆電則使用長度較短的小型SO-DIMM。伺服器用的有以暫存器重新驅動命令與位址訊號、能驅動更多晶片的RDIMM，以及連資料訊號也加以緩衝的LRDIMM，可搭載更大的容量。支援錯誤更正（ECC）的模組，在DDR4以前使用在64位元資料上加上8位元ECC的72位元寬度（DDR5則是在每條32位元子通道加上8位元，成為40位元寬）。DDR5則把一片模組分成兩個獨立的32位元子通道，並將電源電路（PMIC）也裝在模組上。

容量與頻寬的算法

一片DIMM的容量由所搭載DRAM晶片的容量與數量決定。例如裝有8顆資料寬度8位元（x8）、16 Gb晶片的模組，容量為16 Gb × 8 = 128 Gb = 16 GB。共同構成64位元資料寬度的一組晶片稱為rank，增加rank就能增加容量。峰值頻寬是資料速率與資料寬度的乘積：DDR4-3200的DIMM為3200 MT/s × 8位元組 = 25.6 GB/s，DDR5-4800則為38.4 GB/s。在CPU的每個記憶體通道上各插一片DIMM，頻寬就會隨通道數增加。

選購時的注意事項

DDR4與DDR5等不同世代的DIMM，缺口位置、電壓與訊號都不同，沒有相容性。即使是同一世代，RDIMM與UDIMM也不能混用，能否使用ECC則取決於CPU與主機板是否支援。混用不同速度的DIMM時，一般會以最慢的速度運作。此外，在一個通道上插入更多片DIMM會增加訊號負載，可能使支援的最高速度下降。筆電方面，JEDEC也已制定了較薄且容易高速化的新型模組CAMM2。

正確答案：C. DIMM（記憶體模組）

DIMM（Dual Inline Memory Module）是在1片基板上安裝多顆DRAM晶片的模組，因正反面的接點各自具有不同的訊號而稱為「雙（dual）」。可插入主機板的插槽進行更換、擴充，筆電用的小型品是SO-DIMM。伺服器用的有對訊號進行緩衝的RDIMM，DDR5的模組上還搭載了電源電路（PMIC）。

常見問題

DIMM與SO-DIMM有什麼不同？

兩者都是搭載DRAM晶片的插入式記憶體模組。DIMM是桌上型電腦與伺服器用的長型模組，SO-DIMM（Small Outline DIMM）是筆電與小型電腦用的短型模組。兩者接點數與缺口位置不同，不能插入對方的插槽。

RDIMM與UDIMM有什麼不同？

RDIMM以模組上的暫存器重新驅動命令與位址訊號後，再分送給DRAM晶片，因此能穩定驅動大量晶片，用於大容量伺服器。UDIMM沒有緩衝器，主要用於個人電腦。兩者電氣特性不同，不能在同一系統中混用。

DIMM的「dual」是什麼意思？

意思是基板正反兩面的接點各自具有不同的訊號。前一代的SIMM（Single Inline Memory Module），正反兩面的接點連接到相同的訊號。這與使用兩個記憶體通道的「雙通道」是不同的概念。
