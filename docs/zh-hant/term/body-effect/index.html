什麼是基板偏壓效應

在源極與基板(本體)之間施加逆向偏壓時，空乏層的電荷增加而使臨界電壓上升的現象。也稱為本體效應。有時也用於調整臨界電壓。

日文名稱: 基板バイアス効果

「基板偏壓效應」出現在1領域的1道練習題中（MOSFET等）。

這個名詞所屬的領域: MOSFET

源極-本體電壓為何會使Vth上升

在n通道MOSFET中，閘極必須先支撐其下方空乏區的負電荷，才能形成反轉層。當源極-本體接面處於逆向偏壓（VSB大於零，即本體電位低於源極）時，空乏區變寬、電荷增加，因此需要更大的閘極電壓才能達到反轉。教科書上的公式為Vth = Vth0 + γ(√(2φF + VSB) − √(2φF))，其中本體效應係數γ = √(2qεSi·NA)/Cox，基板摻雜愈濃、閘極氧化層愈厚，γ就愈大。

本體效應在電路中出現的地方

在串聯的nMOS電晶體堆疊中，例如NAND閘的下拉網路，只有最底下的元件源極接地。上方元件的源極電位較高，因此Vth上升、導通電流變小。在閘極接VDD的單一nMOS傳輸電晶體中，輸出最多只能升到約VDD − Vth，而且Vth會隨源極電位上升而增加，所以最終電位還會更低。在源極隨耦器中，本體效應會增加背閘極轉導gmb，使電壓增益進一步低於1。

效應的典型大小

類比設計者常以gmb/gm的比值來表示本體效應，對塊材電晶體而言，這個比值依摻雜與偏壓不同，一般約在0.1到0.3之間。在常見的p型基板製程中，nMOS的本體接地，因此即使負載理想，源極隨耦器的增益也會被限制在約gm/(gm + gmb)。將電晶體放在獨立的井中並把本體與源極相接，即可消除這個效應，代價是額外的面積與井電容。

以基板偏壓作為調整手段

同樣的物理機制也可刻意利用。逆向基板偏壓可提高Vth，降低待機時的次臨界漏電；順向基板偏壓則可降低Vth以提升速度，也讓設計者能在製造後補償製程變異。這個手段的效果取決於元件結構。在FinFET中，薄鰭片幾乎完全由閘極控制，基板偏壓的效果很小；而具有薄埋入氧化層的FD-SOI（完全空乏型絕緣層上覆矽）電晶體，則能提供寬廣的背閘偏壓調整範圍。

練習基板偏壓效應的題目

在n通道MOSFET中，若相對於源極對基板（體）施加負電壓（施加基板偏壓），臨界電壓會如何變化？

  1. A上升
  2. B下降
  3. C不變
查看答案與解析

正確答案：A. 上升

在源極與基板之間施加逆向偏壓時，閘極下方的空乏層會擴大，空乏層電荷增加，為了抵消它就需要更大的閘極電壓，因此臨界電壓上升（基板偏壓效應、體效應）。在串聯的電晶體中，上方電晶體的源極電位會升高，因此這個效應使Vth上升而變慢。反過來，也有利用這個特性，以基板電壓調整Vth來減少漏電的手法。

常見問題

本體效應和基板偏壓效應是一樣的嗎？

是的。兩個名稱描述的都是源極與本體（基板）之間的電壓所造成的MOSFET臨界電壓變化；逆向偏壓使Vth上升，順向偏壓使Vth下降。

為什麼本體效應會降低源極隨耦器的增益？

當輸出（源極）電位變動時，源極-本體電壓隨之改變並使Vth偏移，其作用就像一個與訊號相抗的第二轉導gmb。增益因此約為gm/(gm + gmb)，而無法趨近於1。

如何消除本體效應？

將每個電晶體的本體連接到自己的源極即可消除VSB，但元件必須放在獨立的井中，不僅耗費面積，而且在特定製程中只有位於井內的那一型電晶體才能這麼做。
