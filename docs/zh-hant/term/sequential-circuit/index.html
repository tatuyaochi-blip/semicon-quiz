什麼是循序電路

以正反器等記憶狀態，輸出由輸入與過去狀態兩者共同決定的邏輯電路。例如計數器、暫存器等。

日文名稱: 順序回路

「循序電路」出現在1領域的1道練習題中（測試與檢查等）。

這個名詞所屬的領域: 邏輯電路

狀態、次態邏輯與時脈

同步循序電路由兩部分組成：以正反器構成的狀態暫存器，以及從目前狀態與輸入計算次態與輸出的組合邏輯。在每個有效時脈邊緣，暫存器載入次態。正是這個經過記憶元件的回授迴路，讓電路能夠計數、記住一個序列，或追蹤販賣機收到了多少硬幣。非同步循序電路使用鎖存器或沒有共同時脈的回授，因此較難可靠地設計。

Moore 機與 Mealy 機

在 Moore 機中，輸出只取決於目前狀態，因此只在時脈邊緣之後才改變，輸入的變化與突波不會直接傳到輸出。不過，由狀態產生輸出的組合邏輯仍可能出現突波，若將狀態編碼成可直接從狀態暫存器的位元取出輸出，即可消除。在 Mealy 機中，輸出取決於狀態與目前的輸入，因此能在同一個時脈週期內反應，通常也需要較少的狀態，但輸入的變化與突波會直接傳到輸出。實用的控制器經常混用兩種風格，在需要乾淨時序之處將輸出暫存。

循序電路與組合電路

加法器、解碼器或多工器等組合電路沒有記憶：相同的輸入在傳遞延遲之後總是得到相同的輸出。循序電路則可能因歷史不同，對相同的輸入給出不同的輸出。實際的數位系統交替使用兩者，以成排的暫存器夾著一團團組合邏輯，全部由時脈同步。鎖存器、正反器、計數器、移位暫存器與有限狀態機是標準的循序構建單元。

時序限制

同步設計要能運作，資料必須在時脈邊緣之前至少 setup 時間抵達每個正反器，並在邊緣之後保持穩定 hold 時間。最小時脈週期大約是時脈至輸出延遲加上最長組合路徑再加上 setup 時間，這決定了最高頻率。來自其他時脈域的輸入可能違反這些時間窗，使正反器進入亞穩態，因此要通過同步器，通常是兩個串聯的正反器。

正確答案：C. 將電路內的正反器連接成位移暫存器的形式，使內部狀態的設定與觀測變得容易

在掃描設計中，會在各正反器的輸入加上切換用的選擇器，測試時將它們串接起來（掃描鏈），能從外部以位移方式設定任意值，並以位移方式讀出內部的值。由於循序電路的測試被轉換為組合電路的測試，因此可用ATPG自動產生高故障涵蓋率的測試圖樣。這與以顯微鏡掃描或電壓掃描是不同的事。

常見問題

鎖存器是循序電路嗎？

是的。鎖存器儲存一個位元，其輸出取決於過去的輸入，因此是循序的；它是準位觸發的，而邊緣觸發的正反器只在時脈邊緣取樣。

循序電路有哪些例子？

計數器、移位暫存器、暫存器檔案、記憶體，以及通訊協定或紅綠燈控制器等有限狀態機，都是循序電路。

什麼限制了循序電路的時脈頻率？

最長的暫存器到暫存器路徑：時脈至輸出延遲加上組合邏輯延遲再加上 setup 時間，必須在一個時脈週期內完成，並為時脈偏斜保留一些邊限。
