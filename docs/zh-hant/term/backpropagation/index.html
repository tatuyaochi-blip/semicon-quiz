什麼是反向傳播（Backpropagation）

在神經網路的訓練中，將輸出與正確答案的誤差從輸出側往輸入側回溯傳遞，求出各權重梯度的運算。

日文名稱: 逆伝播

「反向傳播（Backpropagation）」出現在2領域的8道練習題中（AI硬體與軟體堆疊, 電腦算術等）。

這個名詞所屬的領域: AI硬體與軟體堆疊

反向傳播如何運作

訓練從前向傳遞開始，計算輸出以及衡量其與目標之間誤差的損失。反向傳播接著反向套用連鎖律：從損失開始，每一層接收相對於其輸出的梯度，並計算兩樣東西：相對於其權重的梯度，以及相對於其輸入的梯度，後者再傳給前一層。對全連接層而言，權重梯度是將傳入的梯度與前向傳遞時保存的輸入激活值結合而得。接著由最佳化器將每個權重朝與其梯度相反的方向微調。

計算圖與自動微分

框架將模型表示為計算圖，以矩陣乘積、加法與激活函數等運算為節點，以張量為邊。由於每個節點都知道自己的局部導數，框架可以反向走訪計算圖，自動計算所有梯度，這種技術稱為反向模式自動微分。計算圖也能顯示哪些運算彼此獨立。TensorRT 或 ONNX Runtime 等推論執行環境會捨棄反向傳播所需的紀錄資料，再融合運算、降低精度並選擇針對特定硬體的核心，這就是它們比直接用訓練框架做推論更快的原因。

運算與記憶體成本

反向傳遞的成本約為前向傳遞的兩倍，因為每一層都要同時計算其輸入與權重的梯度。對 N 個參數而言，前向傳遞每個 token 約需 2N 次運算，因此訓練每個 token 約需 6N 次，D 個 token 則約需 6ND 次；以 1 兆個 token 訓練 70 億參數的模型，約需 4.2 × 10^22 次運算。記憶體的增加更為顯著：訓練時要儲存中間激活值、數量與權重相同的梯度，以及最佳化器狀態，例如 Adam 的兩個移動平均。梯度檢查點只保存部分激活值，其餘重新計算，代價約為多一次前向傳遞。

數值精度與損失縮放

梯度往往非常小。FP16（1 個符號位元、5 個指數位元、10 個有效數位元）可表示的正值範圍包含次正規數在內，最小只有約 6 × 10^-8，最大為 65504，因此許多梯度會下溢為零，使學習停滯。損失縮放在反向傳播之前將損失乘上一個係數（例如 1024），把梯度提升到可表示的範圍內，並在更新權重之前再除回來。混合精度訓練通常也會保留一份較高精度的權重主副本。BF16 與 FP32 一樣有 8 個指數位元，範圍寬得多，很少需要損失縮放。

練習反向傳播（Backpropagation）的題目

  1. A尾數過長，使記憶體使用量增加
  2. B可表示的範圍狹窄，使微小的梯度變成0
  3. C被當作整數處理，無法表示小數

正確答案：B. 可表示的範圍狹窄，使微小的梯度變成0

FP16的指數部分只有5位元，因此可表示的正值約從6 × 10⁻⁸（含非正規化數）到65504，範圍狹窄。訓練中計算出的梯度有許多非常小的值，在FP16中會發生下溢而變成0，使訓練無法進行。損失縮放是先將損失乘以例如1024倍之後再進行反向傳播，把梯度提升到可表示的範圍內，並在更新權重之前還原。尾數為10位元，比FP32短，且也能表示小數。

  2. B訓練與推論都只做順向傳播
  3. C推論會更新權重，訓練不使用權重
查看答案與解析

正確答案：A. 訓練是反覆進行順向傳播、反向傳播與權重更新來決定權重，推論則以固定的權重只做順向傳播來得出答案

訓練時，會用大量資料反覆進行以下步驟：依序計算輸入以求得輸出（順向傳播）、從輸出端往輸入端回溯正確答案的誤差以求出各權重的梯度（反向傳播），再依梯度一點一點地修正權重。推論則是使用訓練所決定的權重，只做順向傳播。反向傳播所需的計算量約為順向傳播的2倍，而且還要保存中間結果，因此訓練是比推論沉重許多的處理。

常見問題

反向傳播和梯度下降有什麼差別？

反向傳播計算損失相對於每個權重的梯度。梯度下降或 Adam 等其他最佳化器則利用這些梯度來更新權重。

為什麼訓練比推論需要更多記憶體？

訓練必須為反向傳遞保留前向激活值，還要保存每個權重的梯度與最佳化器狀態；推論則只需要權重與暫時性的激活值。

反向傳遞的成本是前向傳遞的幾倍？

大約兩倍，因此一個訓練步驟的成本約等於三次前向傳遞，這就是每個 token 6N 次運算這條經驗法則的由來。
