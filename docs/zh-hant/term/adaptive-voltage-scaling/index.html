什麼是自適應電壓調整（Adaptive voltage scaling, AVS）

以電路量測各晶片的速度與溫度，將電壓調近各晶片能正確運作的最小電壓，以減少多餘電壓裕度的手法。AVS。

日文名稱: 適応電圧スケーリング

「自適應電壓調整（Adaptive voltage scaling, AVS）」出現在1領域的1道練習題中（電源管理（軟體控制）等）。

這個名詞所屬的領域: 電源管理（軟體控制）

練習自適應電壓調整（Adaptive voltage scaling, AVS）的題目

關於適應性電壓調整（AVS）的概念，下列何者正確？

  1. A讓所有晶片都以配合最慢晶片的較高電壓運作
  2. B每次都隨機改變電壓
  3. C以電路測量每顆晶片的速度或溫度，使各晶片趨近其能正確運作的最小電壓，減少不必要的電壓餘裕
查看答案與解析

正確答案：C. 以電路測量每顆晶片的速度或溫度，使各晶片趨近其能正確運作的最小電壓，減少不必要的電壓餘裕

由於製造的變異，即使是相同的產品，也會有快的晶片與慢的晶片。如果讓所有晶片都以連最慢的晶片也能運作的電壓來運作，快的晶片的電壓就會高於必要，造成功率的浪費。AVS會在晶片內部設置環形振盪器或測量延遲的電路來檢查實際的速度，同時也考慮溫度與劣化，將電壓調整為該晶片所需的程度。
