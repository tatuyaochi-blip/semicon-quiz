什麼是Spectre

使分支預測出錯，讓處理器推測性地讀取機密資料，並從快取中殘留的痕跡推測其值的弱點類型。於 2018 年公布。

日文名稱: Spectre

「Spectre」出現在1領域的1道練習題中（CPU與架構等）。

這個名詞所屬的領域: 硬體安全

練習Spectre的題目

利用投機執行的痕跡殘留在快取中，推測本來無法存取之資料的攻擊，其被揭露的漏洞例子是下列何者？

  1. ARowhammer
  2. BSpectre 與 Meltdown
  3. C閂鎖效應（latch-up）
查看答案與解析

正確答案：B. Spectre 與 Meltdown

2018 年公開的 Spectre 與 Meltdown，是利用投機執行的指令結果雖然被取消、但所讀取的資料仍留在快取中的特性，從存取時間的差異（旁通道，side channel）推測出原本無法讀取之機密資料的攻擊。幾乎所有高效能 CPU 都受到影響，因此進行了作業系統的修補與 CPU 設計的變更。這是顯示提升效能的機制也可能成為安全弱點的案例。
