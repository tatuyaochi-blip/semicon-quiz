什麼是環境變數

行程所持有的「名稱=值」組合的集合，用來從外部設定程式的行為。啟動行程時，父行程環境變數的副本會由子行程繼承。在 shell 中，只有像 export X=1 這樣 export 的變數才會成為環境變數並傳給子行程，只做了指定的變數只在該 shell 中使用。除了搜尋指令目錄的 PATH、家目錄的 HOME、搜尋共用函式庫的 LD_LIBRARY_PATH，也用於指定 EDA 工具的授權伺服器等。可用 env 或 printenv 列出。

練習環境變數的題目

目前目錄中有附加執行權限的腳本 run.sh，輸入「run.sh」執行時出現「command not found」，輸入「./run.sh」則能執行。理由是下列何者？

  1. Arun.sh 沒有執行權限，只有在前面加上 ./ 時才能在沒有權限的情況下執行
  2. B不含斜線的指令名稱只會在環境變數 PATH 的目錄中尋找，而目前目錄一般不包含在其中
  3. Crun.sh 第1行的 #!/bin/bash（shebang）只有在前面加上 ./ 執行時才會被讀取
查看答案與解析

正確答案：B. 不含斜線的指令名稱只會在環境變數 PATH 的目錄中尋找，而目前目錄一般不包含在其中

shell 收到不含斜線的指令名稱時，會依序在環境變數 PATH 中以冒號分隔列出的目錄（/usr/local/bin:/usr/bin 等）中尋找並執行。為了避免誤執行放在其他地方的同名惡意程式，一般不會把目前目錄放進 PATH。像 ./run.sh 這樣寫出含有斜線的路徑時，就不會搜尋 PATH，而是直接執行該檔案。第1行的 #!/bin/bash（shebang）不論以哪種方式啟動，都會指定執行該腳本的直譯器。

在 cron 中登錄了「30 2 * * 1 /home/alice/backup.sh」。backup.sh 執行的時間是下列何者？

  1. A每月1日的2點30分
  2. B每週一的2點30分
  3. C每週日的2點30分
查看答案與解析

正確答案：B. 每週一的2點30分

cron 的設定（crontab）每一行開頭的5個欄位由左而右是「分、時、日、月、星期」，後面接著要執行的指令。這一行的分為30、時為2、日與月為 *（全部）、星期為1，所以在每週一的2點30分執行。星期欄位中0是星期日、1是星期一，在許多實作中7也表示星期日。從 cron 執行的指令，是在與登入時不同的有限環境變數下運作，所以在腳本中要以絕對路徑寫出指令等，需要特別注意。
