什麼是堆疊

最後放入的元素最先取出的後進先出（LIFO）資料結構。放入元素的操作稱為 push，取出的操作稱為 pop。用於管理函式呼叫的返回位址與區域變數（呼叫堆疊）、計算逆波蘭表示法的算式、深度優先搜尋等。

日文名稱: スタック

「堆疊」出現在6領域的30道練習題中（指令集與組合語言, 連結器與載入器與執行檔格式, 資料結構與演算法等）。

練習堆疊的題目

不呼叫其他函式的函式（葉函式、leaf function），在很多情況下不需要將ra保存到堆疊。下列何者是其理由？

  1. A因為葉函式不使用ret指令
  2. B因為葉函式的返回位址是由CPU自動堆入堆疊
  3. C因為不呼叫其他函式，ra不會被覆寫，返回位址會原封不動地保留
查看答案與解析

正確答案：C. 因為不呼叫其他函式，ra不會被覆寫，返回位址會原封不動地保留

ra會在每次呼叫函式的jal時被覆寫，所以呼叫其他函式的函式，必須一開始就將自己的返回位址保存到堆疊。葉函式不使用jal，所以ra不會被破壞，不必保存就能ret。此外，如果也不使用被呼叫端保存的暫存器，甚至不需要建立堆疊框（stack frame）。x86的call指令一定會將返回位址堆入堆疊，這是與RISC-V的差異。

在RISC-V中撰寫呼叫自己的遞迴函式時，若忘了將ra保存到堆疊，會發生什麼事？

  1. Ara在內層的呼叫中被覆寫，外層的函式無法返回正確的呼叫端
  2. BCPU會自動保存ra，所以不會有任何問題
  3. C無論遞迴的深度，計算結果都會變成2倍
查看答案與解析

正確答案：A. ra在內層的呼叫中被覆寫，外層的函式無法返回正確的呼叫端

遞迴呼叫的jal會將ra覆寫為「自己內部呼叫的下一個指令」。若沒有保存，外層的函式在ret時就不會回到原本的呼叫端，而是回到自己內部，導致重複相同的地方或發生錯誤動作。因此，呼叫其他函式的函式，規定要在序言將ra保存到堆疊，並在結尾還原。
