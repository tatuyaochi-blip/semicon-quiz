什麼是多重圖案化

將單次曝光無法解析之細微間距的圖案，分成多次曝光或加工來形成的技術。分成兩次者稱為雙重圖案化。

日文名稱: マルチパターニング

「多重圖案化」出現在2領域的4道練習題中（微影, 薄膜沉積（CVD與PVD）等）。

這個名詞所屬的領域: 微影

為什麼一次曝光不夠

解析度遵循 R = k1·λ/NA。氟化氬（ArF）浸潤式微影結合 193 nm 波長與 NA 1.35，在 k1 接近其約 0.27 的實務極限時，最細的半間距約為 39 nm，即間距約 80 nm。先進邏輯與記憶體中的某些層需要比這更緊密的間距。多重圖案化透過多次曝光，或以製程步驟將寬鬆的圖案倍增，來建構最終圖案，藉此達到這些間距，使任何單次曝光都不必解析最終間距。

LELE：拆分佈局

在微影－蝕刻－微影－蝕刻（LELE）中，佈局被分解到兩片光罩上（常被描述為著色），使距離小於單次曝光極限的圖形落在不同的光罩上；各光罩依序曝光與蝕刻。使用三片光罩（LELELE）則是此概念的延伸。主要有兩個難題。曝光之間的疊對誤差會直接改變相鄰圖形之間的間隔，因此需要非常嚴格的對準。此外，有些佈局（例如三個彼此靠近的圖形）無法分成兩種顏色，因此設計規則必須禁止它們。

SADP 與 SAQP：由間隔物決定間距

自對準雙重圖案化（SADP）以寬鬆的間距印出芯軸線，以順形薄膜（通常以原子層沉積，ALD）覆蓋，再回蝕刻使兩側側壁留下間隔物。移除芯軸後，留下的間隔物線條間距為原本的一半，線寬由薄膜厚度決定，因此均勻性極佳，且兩半之間沒有疊對問題。重複此製程即為自對準四重圖案化（SAQP）。其結果是規則的光柵，因此需要額外的切割或阻擋光罩來移除不需要的區段，這使設計趨向單方向的線條。

成本與 EUV 這個替代方案

每增加一片光罩、一次沉積與一次蝕刻，都會增加成本、生產週期時間與產生缺陷的機會，而且每個步驟都會帶來變異：例如在間隔物方案中，芯軸寬度誤差會使交替的間隔不相等，這稱為間距偏移（pitch walking）。這些成本促使業界採用 13.5 nm 的極紫外光（EUV）微影，讓許多層回到單次曝光。在最緊密的間距下，EUV 本身也可能再次與多重圖案化結合。

  2. B將一次曝光無法解析的細間距圖案，分成多次曝光或加工來形成
  3. C只要塗佈兩層光阻就能讓解析度加倍
查看答案與解析

正確答案：B. 將一次曝光無法解析的細間距圖案，分成多次曝光或加工來形成

雙重圖案化是將一次無法解析的細間距圖案，拆成間隔抽掉的兩組圖案，分別曝光、加工（LELE），或是利用在側壁成膜的間隔層（spacer）使線條數量加倍（SADP、SAQP）來形成圖案的技術。它突破了ArF浸潤式的極限（間距約80 nm），使微縮得以推進到20 nm級的間距，但製程步驟數、光罩數與成本都大幅增加，因此持續推動EUV曝光的導入。

常見問題

LELE 和 SADP 有什麼差別？

LELE 將佈局拆分到兩片光罩上分別曝光與蝕刻，因此兩者之間的疊對很重要。SADP 則在單次印出的圖案上利用側壁間隔物，以自對準的方式將間距減半，線寬由薄膜厚度決定。

為什麼多重圖案化很昂貴？

每一層都需要額外的光罩、微影次數、沉積、蝕刻與檢查，這會提高成本與生產週期時間，並增加變異與缺陷的來源。

EUV 會讓多重圖案化消失嗎？

EUV 讓許多層可以單次曝光印出，大幅減少了對多重圖案化的需求。不過在最細的間距下，EUV 仍可能與雙重圖案化結合使用。
