什麼是差分方程式

以目前與過去的輸入，以及過去的輸出的加權和，來表示離散時間系統輸出的式子。例如 y[n] = x[n] + 0.5y[n − 1] 是把前1個輸出的一半加到目前的輸入上。右邊不含過去輸出的是FIR濾波器，含有過去輸出（有回授）的通常是脈衝響應無限延續的IIR濾波器。給定初始值即可依序計算，能直接以程式或硬體實作。兩邊做z轉換即得轉移函數 H(z)。

日文名稱: 差分方程式

「差分方程式」出現在1領域的2道練習題中（數位訊號處理基礎等）。

這個名詞所屬的領域: 數位訊號處理基礎

練習差分方程式的題目

對差分方程式 y[n] = x[n] + 0.5y[n − 1] 表示的系統，從 n = 0 起輸入單位步階（n ≥ 0 時 x[n] = 1）。y[−1] = 0 時，y[2] 為下列何者？

  1. A1.75
  2. B1.875
  3. C2
查看答案與解析

正確答案：A. 1.75

依序計算，y[0] = 1 + 0.5 × 0 = 1，y[1] = 1 + 0.5 × 1 = 1.5，y[2] = 1 + 0.5 × 1.5 = 1.75。繼續下去為 y[n] = 2 − 0.5ⁿ，逐漸接近終值 1/(1 − 0.5) = 2。由於使用過去的輸出（有回授），這是脈衝響應 0.5ⁿ 無限延續的IIR濾波器。

以差分方程式 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1] 表示的系統，其轉移函數 H(z) = Y(z)/X(z) 為下列何者？

  1. A(1 + 0.5z⁻¹)/(1 + 0.25z⁻¹)
  2. B(1 − 0.25z⁻¹)/(1 + 0.5z⁻¹)
  3. C(1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)
查看答案與解析

正確答案：C. (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)

延遲1個取樣點在z轉換中相當於乘上 z⁻¹，因此兩邊做z轉換得 Y(z) = X(z) + 0.5z⁻¹X(z) + 0.25z⁻¹Y(z)。把 Y(z) 的項移到左邊，得 (1 − 0.25z⁻¹)Y(z) = (1 + 0.5z⁻¹)X(z)，所以 H(z) = (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)。分子表示輸入側的係數，分母表示輸出回授側的係數；使分母為0的 z = 0.25 是極點，使分子為0的 z = −0.5 是零點。
