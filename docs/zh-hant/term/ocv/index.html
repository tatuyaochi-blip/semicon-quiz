什麼是OCV(晶片內變異)

即使在同一晶片中，電晶體與導線的延遲也會因位置而有所差異。STA 中對發送端與接收端路徑分別乘上不同係數(例如 1.1 倍與 0.9 倍)，假設最不利的組合進行分析。

日文名稱: OCV(オンチップばらつき)

「OCV(晶片內變異)」出現在2領域的3道練習題中（時序分析與CDC, LSI設計流程與EDA等）。

這個名詞所屬的領域: 時序分析與CDC

練習OCV(晶片內變異)的題目

作為OCV降額（derating），在建立時間分析中將發送端時脈路徑與資料路徑的延遲乘以1.1倍，接收端時脈路徑的延遲乘以0.9倍。當發送端時脈路徑為 1.0 ns、資料路徑（含時脈→輸出）為 1.5 ns、接收端時脈路徑為 1.0 ns（無共同部分）、週期為 3.0 ns、建立時間為 0.1 ns 時，建立時間的餘裕是多少？

  1. A1.05 ns
  2. B1.40 ns
  3. C1.25 ns
查看答案與解析

正確答案：A. 1.05 ns

OCV降額是考量即使在同一晶片內，延遲也會因位置而變異，並對建立時間假設最不利之組合（發送端較慢、接收端的時脈較快）的方法。到達時間為 1.1 × (1.0 + 1.5) = 2.75 ns，要求時間為 3.0 + 0.9 × 1.0 − 0.1 = 3.8 ns，因此餘裕為 1.05 ns。1.40 ns 是未降額的值，1.25 ns 是只對資料路徑乘上係數的值。在保持時間分析中，係數的乘法方式相反。

在使用OCV降額的STA中，當發送端與接收端的時脈路徑在中途之前為共同路徑時，所進行的CRPR（共同路徑悲觀消除）的說明何者正確？

  1. A將共同部分的延遲視為0，重新計算時脈的到達時間
  2. B去除因對共同部分分別套用慢速值與快速值所造成的、不可能發生的多餘悲觀
  3. C對共同部分乘上更大的降額係數，使其偏向安全側
查看答案與解析

正確答案：B. 去除因對共同部分分別套用慢速值與快速值所造成的、不可能發生的多餘悲觀

在OCV中，發送端的時脈路徑估得較慢、接收端估得較快，但從根部到分歧點的共同部分在物理上是相同的緩衝器與繞線，在一次邊緣中不可能既慢又快。若共同部分的延遲為 1.0 ns、係數為1.1與0.9，則 1.1 ns 與 0.9 ns 之差的 0.2 ns 就是多餘的悲觀。CRPR將這個差值加回餘裕，使結果更接近實際。這並不是把共同部分的延遲當作0，而加大係數則是相反的操作。
