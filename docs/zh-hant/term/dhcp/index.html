什麼是DHCP

Dynamic Host Configuration Protocol（動態主機設定協定）。為連上網路的終端，自動且有期限地分配IP位址、子網路遮罩、預設閘道、DNS伺服器等設定的協定。

日文名稱: DHCP

「DHCP」出現在1領域的3道練習題中（電腦網路基礎等）。

這個名詞所屬的領域: 電腦網路基礎

練習DHCP的題目

以DHCP讓終端取得IP位址時，訊息的順序下列何者正確？

  1. ARequest → Offer → Discover → Ack
  2. BDiscover → Offer → Request → Ack
  3. COffer → Discover → Ack → Request
查看答案與解析

正確答案：B. Discover → Offer → Request → Ack

尚未取得位址的終端也不知道DHCP伺服器在哪裡，因此首先以廣播送出Discover。伺服器以Offer提出可出借的位址等，終端以Request告知要接受哪一台伺服器的提議，伺服器再以Ack確定。取其字首稱為DORA。終端除了IP位址之外，也會收到子網路遮罩、預設閘道、DNS伺服器的位址等。位址是有期限（租約期間）的出借，終端會在到期前要求續約。若要使用路由器另一側的DHCP伺服器，需在路由器上設定DHCP中繼。
