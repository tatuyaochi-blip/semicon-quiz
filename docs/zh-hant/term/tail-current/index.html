什麼是尾電流

IGBT 關閉時，因累積的少數載子而使電流無法立即歸零，像拖著尾巴般持續流動的電流。是關閉損耗的成因。

日文名稱: テール電流

「尾電流」出現在3領域的5道練習題中（功率半導體, 車用半導體與功能安全, 離子佈植等）。

這個名詞所屬的領域: 功率半導體

為什麼 IGBT 的電流會拖尾

絕緣閘雙極電晶體（IGBT）具有 p+ 集極層，在元件導通時將電洞注入輕摻雜的 n 漂移區。這些少數載子充滿漂移區並降低其電阻，這種效應稱為導電度調變，使 IGBT 具有低導通電壓。關閉時，閘極移除 MOS 通道，電子供應幾乎立即停止，但儲存的電洞無法瞬間消失。它們必須透過複合，或被逐漸增強的電場掃出，集極電流也隨之衰減，因而形成尾電流。

尾電流與切換損耗

尾電流在集極–射極電壓已經上升到匯流排電壓之後才流動，因此這段期間電壓乘以電流很大，直接增加關閉能量（Eoff）。由於每個切換週期都要付出這份能量，矽 IGBT 的切換頻率被限制在大約數十 kHz 以下。尾電流在高溫時也會增大，因為矽中的載子壽命隨溫度增加。設計者面臨取捨：儲存的電荷越多，導通電壓越低，但尾電流越長，因此導通損耗與切換損耗是互相拉扯的。

如何縮短尾電流

壽命控制藉由引入複合中心，使儲存的載子更快消失；電子照射以及氫或氦佈植，可將這些缺陷放在選定的深度。場截止（field-stop）設計加入 n 型緩衝層，使漂移區可以更薄，因此儲存的電荷更少；而低注入集極則從一開始就減少進入的電洞數量。單極元件則完全沒有這個問題：矽 MOSFET 與 SiC MOSFET 只以多數載子導電，因此沒有尾電流，能以快得多的速度切換。

另一個意思：差動對的尾電流

在類比電路中，尾電流（tail current）指的是完全不相關的東西：連接到差動對共同射極或共同源極的電流源之偏壓電流。輸入電壓差會將這個固定電流在兩個電晶體之間分配，因此它決定了差動對的轉導、最大輸出電流，以及以其構成之放大器的迴轉率。尾電流源的輸出阻抗決定了差動對抑制共模訊號的能力，這反映在共模拒斥比（CMRR）上。

  1. A僅具有2個PN接面的2端子元件
  2. B以MOS閘極驅動，並藉由雙極性動作的導電度調變獲得低導通電壓的元件
  3. C照光即導通的閘流體
查看答案與解析

正確答案：B. 以MOS閘極驅動，並藉由雙極性動作的導電度調變獲得低導通電壓的元件

IGBT是結合MOSFET的輸入部與雙極性電晶體的輸出部的元件，結構上在汲極側加上p+層。由於可用電壓驅動，驅動電路簡單；導通時，從p+層注入的電洞會大幅降低漂移層的電阻（導電度調變），因此即使在600 V～6.5 kV的高耐壓下，也能降低導通電壓。它是EV、鐵路、工業用逆變器的主力，但因為有尾電流，不適合高頻。

IGBT在截止時，因累積的少數載子而使電流不會立即變為0、而是拖著尾巴般持續流通的現象稱為什麼？

  1. A突入電流
  2. B尾電流
  3. C暗電流
查看答案與解析

正確答案：B. 尾電流

IGBT在導通時會向漂移層注入少數載子（電洞）以降低電阻，因此截止時，電流會一直流通到這些載子經由複合或被抽出而消失為止。這就是尾電流；由於它是在電壓已上升的狀態下流通，成為截止損耗增大的主要原因，並將IGBT的切換頻率限制在數十kHz以下。可藉由生命週期控制或場截止結構來縮短它。MOSFET則沒有這種現象。

常見問題

為什麼 MOSFET 沒有尾電流？

MOSFET 只以多數載子經由通道導電，因此在閘極將其關閉時，沒有需要移除的少數載子儲存電荷。IGBT 依賴注入的少數載子進行導電度調變，而移除這些載子正是造成尾電流的原因。

IGBT 的尾電流會隨溫度增加嗎？

會。矽中的載子壽命隨溫度上升，因此儲存電荷衰減得更慢，在接面溫度升高時關閉能量會明顯增加。

差動放大器中的尾電流是什麼？

它是由差動對共同節點上的電流源所提供的偏壓電流。輸入差將這個電流分配到兩個電晶體之間，其數值決定了增益、迴轉率與輸出擺幅的極限。
