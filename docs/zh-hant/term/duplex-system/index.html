什麼是雙工系統（Duplex system）

以進行處理的主系統（運轉系統）與防備故障的備援系統2套組成系統，主系統故障時切換到備援系統繼續處理的備援方式。依備援系統的準備程度，分為熱備援、暖備援、冷備援。

日文名稱: デュプレックスシステム

「雙工系統（Duplex system）」出現在1領域的2道練習題中（系統架構與可靠度設計等）。

這個名詞所屬的領域: 系統架構與可靠度設計

與雙重系統的差異

雙重系統由2套系統同時進行相同的處理並比對結果。雙工系統平時只由主系統處理，備援系統則為防備主系統故障而待命。雙重系統在錯誤偵測與切換速度上較優，但2套系統一直在運轉，費用較高。雙工系統較容易壓低費用，但切換期間處理會停止，切換前一刻的處理也可能遺失。

熱備援、暖備援、冷備援

熱備援讓備援系統保持啟動，並隨時把主系統的資料反映到備援系統，能在短時間內切換。冷備援讓備援系統停止或用於其他工作，故障後才進行啟動與資料復原，切換需要時間，但能壓低費用。暖備援介於兩者之間，備援系統雖已啟動，但接手處理前需要啟動應用程式或反映資料等準備。選擇哪一種，取決於可容許的停機時間與費用。

切換的機制與注意事項

主系統的故障是透過主系統與備援系統之間定期交換訊號的心跳（heartbeat）等方式偵測，並自動把處理移到備援系統（failover）。為了防止因通訊故障使雙方都判斷對方已停止、兩者都以主系統身分運作的狀態（腦裂，split brain），有時會另外準備第三方的監視機制。此外，備援系統能否正確接手，必須定期進行切換測試來確認。

練習雙工系統（Duplex system）的題目

將半導體工廠製造執行系統（MES）的伺服器，做成由主系統（運轉系統）與備援系統組成的雙工系統。當備援系統採用熱備援時，其特徵為下列何者？

  1. A讓備援系統處於啟動狀態待命，並隨時把主系統的資料反映到備援系統，因此主系統故障時能在短時間內切換
  2. B備援系統平時關閉電源，主系統故障後才啟動並復原資料，因此切換需要時間，但能節省待命期間的電力與費用
  3. C主系統與備援系統同時進行相同的處理，一邊比對結果一邊運轉
查看答案與解析

正確答案：A. 讓備援系統處於啟動狀態待命，並隨時把主系統的資料反映到備援系統，因此主系統故障時能在短時間內切換

熱備援是讓備援系統保持啟動狀態，並隨時將主系統的資料反映到備援系統的方式，主系統故障時能在短時間內接手處理。MES 一旦停止，就無法指示批次的進行方式、指定設備的配方或記錄製造履歷，因此一般會選擇能在短時間內切換的架構。讓備援系統停止、故障後才啟動的方式是冷備援，兩者的中間（已啟動，但接手處理前需要準備）稱為暖備援。由2套系統同時進行相同的處理並比對的是雙重系統。

常見問題

雙工系統的備援系統什麼都不做嗎？

在冷備援的情況下，備援系統有時會停止，或用於不急的批次處理等其他工作。主系統故障時，就停止那些工作來接手主系統的處理。在熱備援中，備援系統持續接收主系統的資料，以能立即接手的狀態待命。

雙工系統的可用率如何計算？

若視為主系統與備援系統只要有一方運轉就能繼續處理，可用並聯公式 1 − (1 − a)² 概算。不過實際上有切換裝置、切換所需的時間，以及兩者共同的故障原因（電源或設置場所等），因此不會像這個公式的值那麼高。
