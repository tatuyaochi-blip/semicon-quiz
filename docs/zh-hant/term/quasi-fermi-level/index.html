什麼是準費米能階

在因光照射或電流注入而偏離熱平衡的半導體中，為了分別表示電子密度與電洞密度而引入的費米能階。兩者差距越大，表示注入的載子越多。

日文名稱: 擬フェルミ準位

「準費米能階」出現在1領域的1道練習題中（半導體物性等）。

這個名詞所屬的領域: 半導體物性

練習準費米能階的題目

在因光照射或電流注入而偏離熱平衡的半導體中，為了分別表示電子濃度與電洞濃度而引入的能階稱為什麼？

  1. A施體能階
  2. B準費米能階
  3. C本質費米能階
查看答案與解析

正確答案：B. 準費米能階

因光照射或電流注入而偏離熱平衡時，單一個費米能階無法同時表示電子與電洞的濃度。因此分別定出電子用與電洞用的準費米能階（Imref），並如 n = ni·exp((EFn−Ei)/kT) 般處理。兩者的差透過 np = ni²·exp(ΔEF/kT) 的關係，對應到施加於PN接面的電壓以及太陽能電池的開路電壓。電流則與準費米能階的斜率成正比而流動。
