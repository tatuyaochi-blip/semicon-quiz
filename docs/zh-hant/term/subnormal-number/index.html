什麼是非正規化數

指數部全為0的浮點數，不假設開頭的1，表示比正規化數更小、接近0的數。平滑地銜接與0之間(漸進式下溢)，使 x − y = 0 時 x = y 成立。

日文名稱: 非正規化数

「非正規化數」出現在1領域的7道練習題中（電腦算術等）。

這個名詞所屬的領域: 電腦算術

練習非正規化數的題目

IEEE 754的非正規化數（次正規數）所扮演的角色，下列何者正確？

  1. A表示比最大的正規化數更大的值，以防止溢位
  2. B偵測計算的錯誤，並將結果替換為NaN
  3. C填補正規化數與0之間的空隙，使下溢變得平緩
查看答案與解析

正確答案：C. 填補正規化數與0之間的空隙，使下溢變得平緩

若只有正規化數，則最小的正規化數（單精度約1.18 × 10⁻³⁸）與0之間會有很大的空隙，比它更小的結果會突然變成0。非正規化數將指數部分全設為0，且不假設開頭有1，以等間隔的微小數填補這段空隙（漸進式下溢）。這使得「x − y = 0 則 x = y」的性質得以保持。它並不是用來表示更大的值，那是以無限大來表示的。它也與錯誤的偵測無關。

在含有大量非正規化數的計算中，某些處理器的處理速度可能會大幅變慢。因此在重視效能的場合會使用的設定為下列何者？

  1. A將成為非正規化數的結果或輸入視為0的設定（flush-to-zero）
  2. B將所有計算自動從雙精度轉換為單精度的設定
  3. C一旦發現非正規化數就讓程式停止的設定
查看答案與解析

正確答案：A. 將成為非正規化數的結果或輸入視為0的設定（flush-to-zero）

非正規化數是不假設開頭有1的特殊形式，因此在某些處理器上無法以高速電路處理，而是透過微碼等花費時間處理，有時會比平常慢上數十倍。在語音處理或AI等不需要精確處理極接近0的值的場合，會採用將非正規化數視為0的flush-to-zero設定來維持速度。代價是0附近的精度以及漸進式下溢的性質會喪失。它並不會一律更改精度，也不會讓程式停止。
