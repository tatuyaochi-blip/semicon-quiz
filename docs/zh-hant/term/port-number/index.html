什麼是連接埠號碼

TCP與UDP用來區分通訊要給終端上哪一個應用程式的0～65535編號。HTTP的80、HTTPS的443、DNS的53等0～1023的編號稱為知名連接埠。

日文名稱: ポート番号

「連接埠號碼」出現在3領域的7道練習題中（電腦網路基礎, Web技術基礎, 網路攻擊與防禦實務等）。

這個名詞所屬的領域: 電腦網路基礎

練習連接埠號碼的題目

下列協定與其伺服器標準使用之連接埠號碼的組合，何者正確？

  1. AHTTP 80、HTTPS 443、DNS 53
  2. BHTTP 8080、HTTPS 443、DNS 25
  3. CHTTP 80、HTTPS 22、DNS 53
查看答案與解析

正確答案：A. HTTP 80、HTTPS 443、DNS 53

連接埠號碼是0～65535的16位元編號，用來在以IP位址送達的終端中，區分通訊是要給哪一個應用程式。0～1023稱為知名連接埠，分配給主要的服務。代表性的有 HTTP 80、HTTPS 443、DNS 53、SSH 22、SMTP（郵件傳送）25。用戶端則以作業系統每次選擇的編號（臨時連接埠）作為來源連接埠。服務也可以在非標準的編號上執行，8080常用於Web開發或代理伺服器等，但此時連線端必須指定編號。
