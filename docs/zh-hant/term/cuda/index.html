什麼是CUDA

在 NVIDIA 的 GPU 上進行通用運算的程式設計機制。以擴充 C++ 的語言撰寫核心函式，並以網格、區塊、執行緒的階層表示平行性。

日文名稱: CUDA

「CUDA」出現在1領域的20道練習題中（GPU程式設計等）。

這個名詞所屬的領域: GPU程式設計

kernel 與執行緒階層

在 CUDA 中，由 CPU（主機端）啟動 kernel，也就是讓許多 GPU 執行緒同時執行的函式。一次啟動會建立由多個 block 組成的 grid，每個 block 包含許多執行緒。每個執行緒會計算一個唯一的全域索引，通常為 i = blockIdx.x × blockDim.x + threadIdx.x，以選擇自己的資料元素：在每個 block 有 256 個執行緒時，block 2 的第 5 號執行緒負責第 517 個元素。由於執行緒是以整個 block 為單位啟動，最後一個 block 通常會有多餘的執行緒，因此 kernel 會以 if (i < n) 保護記憶體存取，避免寫到陣列範圍之外。

block 如何對應到 GPU

每個 block 會被分配到一個串流多處理器（SM），並在該處執行到結束，而一個 SM 可同時容納多個 block。在 SM 內部，執行緒以 32 個為一組的 warp 來執行。佔用率（occupancy）是常駐 warp 數與 SM 最大 warp 數的比值，受每個執行緒的暫存器數、每個 block 的共享記憶體與 block 大小所限制；佔用率過低時，可用來隱藏記憶體延遲的 warp 就太少。各 block 獨立執行且順序不定，因此在 kernel 內等待其他所有 block 可能造成死結；全域同步通常是把工作拆成兩次 kernel 啟動來達成。

記憶體空間

全域記憶體就是 GPU 的 DRAM：頻寬高、延遲也高，在相鄰執行緒存取相鄰位址時速度最快。共享記憶體是每個 block 專用的小型晶片內記憶體，由程式明確管理。它分成 32 個記憶庫（bank），同一個 warp 中的執行緒若存取同一個記憶庫的不同位址，就會被序列化。__syncthreads() 會讓 block 中的每個執行緒等待，直到所有執行緒都到達；若把它放在部分執行緒會跳過的分支內，會導致停滯或未定義的結果。統一記憶體（unified memory）讓主機端與裝置端共用同一個指標，分頁會依需要遷移。

讓 GPU 保持忙碌

從主機端到裝置端的複製要經過 PCI Express，常常是瓶頸所在。串流（stream）是由傳輸與 kernel 組成的有序佇列，不同串流中的工作可以重疊進行，因此可在運算目前這一塊資料的同時複製下一塊。每次 kernel 啟動也要花費數微秒，因此啟動數千個微小 kernel 的程式，可以藉由將其融合（這也能避免把中間結果寫入記憶體），或以 CUDA Graphs 一次提交預先錄製的啟動序列而受益。CUDA 本身只能在 NVIDIA GPU 上執行；OpenCL 等跨廠商的替代方案則採用類似的 kernel 與工作群組模型。

正確答案：B. 在GPU上由大量執行緒同時執行的函式

GPU程式設計中的核心函式（kernel），是由CPU端的程式啟動，並由GPU上的大量執行緒執行相同程式碼的函式。各執行緒使用自己的編號來選擇負責的資料元素。例如陣列相加時，將核心函式寫成由一個執行緒加總一個元素，再依元素數量啟動執行緒。雖然與作業系統的核心（kernel）用語相同，但意義不同。

下列何者是CUDA執行緒階層的正確組合（由大到小）？

  1. A網格 → 區塊 → 執行緒
  2. B執行緒 → 區塊 → 網格
  3. C區塊 → 執行緒 → 網格
查看答案與解析

正確答案：A. 網格 → 區塊 → 執行緒

啟動一次核心函式後，整體成為網格（grid），網格分為許多區塊（block），區塊再分為許多執行緒。同一個區塊的執行緒會在同一個SM（運算單元的集合）上執行，可透過共享記憶體合作並進行同步。不同的區塊則獨立執行，因此同時運作的區塊數量會隨GPU的規模而變，同一個程式可在大小不同的GPU上執行。

常見問題

CUDA 的 block 和 warp 有什麼差別？

block 是由程式設計師決定的一組執行緒，在一個 SM 上執行，可以共享記憶體並同步。warp 則是硬體在 block 內劃分的 32 個執行緒群組，以鎖步方式一起執行指令。

CUDA 的全域執行緒索引怎麼算？

一維啟動時使用 i = blockIdx.x * blockDim.x + threadIdx.x。存取陣列前要先檢查 i < n，因為最後一個 block 的執行緒數常常多於剩餘的元素數。

CUDA 的共享記憶體有什麼用途？

它是由同一個 block 的執行緒共用的高速晶片內記憶體，用來暫存從全域記憶體讀入、要重複使用的資料，以及交換中間結果。與快取不同，放什麼進去由程式決定，並以 __syncthreads() 安排存取順序。
