什麼是算術位移

有號整數右移時，將符號位元複製到空出的高位位元的方式。將負數右移1位元，會得到除以2後向較小方向捨去的值。填入0的是邏輯位移。

日文名稱: 算術シフト

「算術位移」出現在1領域的1道練習題中（電腦算術等）。

這個名詞所屬的領域: 電腦算術

算術右移的運作方式

算術右移是將以二補數表示的有號整數的位元向右移，並把原本的最高位元（符號位元）複製到空出來的高位位元。正數會補0、負數會補1，因此符號得以保持。例如將8位元的−8（1111 1000）右移1位元，會得到1111 1100，也就是−4。n位元的算術右移結果，等於將原值除以2的n次方後向較小方向（負無限大方向）取整的值。在高位補0的邏輯右移是針對無號整數，若用在負數上，會變成很大的正數。

與除法的差異及捨入方向

算術右移是向負無限大方向取整，因此與向0方向捨去的除法相比，負數時結果可能不同。在C語言（C99以後）中，−7 / 2 為 −3，但將 −7（1111 1001）以算術右移右移1位元，會得到1111 1100，也就是 −4。因此編譯器在將有號整數除以2的n次方置換為位移時，會加入修正指令，例如當值為負時，先加上2的n次方減1再位移。若是無號整數或已知為0以上的值，則不需修正即可置換為位移。

算術左移與溢位

左移時，無論算術位移或邏輯位移都在低位補0，位元的移動方式相同；x86的SAL指令與SHL指令行為相同，原因就在這裡。數值會變為2的n次方倍，但對有號整數而言，若被移出的位元或新的最高位元與原本的符號不同，就會發生溢位而改變符號。例如將8位元的64（0100 0000）左移1位元，會得到1000 0000，也就是−128。在C語言中，對負值左移，或是結果無法以該型別表示的有號整數左移，屬於未定義行為，需要注意。

指令集與電路的實作

多數指令集將算術右移與邏輯右移設為不同的指令：RISC-V為SRA/SRAI與SRL/SRLI，Arm為ASR與LSR，x86為SAR與SHR。在程式語言中，Java以 >> 表示算術右移、>>> 表示邏輯右移。在電路上，桶式位移器只要切換從高位送入的是符號位元還是0，就能同時實現兩者。定點數的DSP處理會用算術右移來縮小數值的比例，但因為捨入會偏向負方向，有時會先加上2的(n−1)次方，使其接近四捨五入。

練習算術位移的題目

將8位元有號整數 −8（1111 1000）以算術右移向右移1位元的結果為下列何者？

  1. A124（0111 1100）
  2. B−16（1111 0000）
  3. C−4（1111 1100）
查看答案與解析

正確答案：C. −4（1111 1100）

在算術位移（算術右移）中，空出來的最高位元會複製符號位元，因此 1111 1000 會變成 1111 1100，以二補數而言就是 −4。即使是負數，向右移1位元也會成為除以2的值。若是在最高位填入0的邏輯右移，則會成為 0111 1100 = 124，符號就改變了。−16則是向左移1位元的結果。另須注意，在C語言中將負的有號整數右移時會是哪一種，屬於實作定義（交由編譯系統決定）。

常見問題

算術位移和邏輯位移有什麼不同？

右移時，算術位移會把符號位元複製到空出的高位位元，邏輯位移則補0。算術位移用於有號整數，邏輯位移用於無號整數或位元串的操作。左移時兩者都在低位補0，位元的移動方式相同。

算術右移等於除以2嗎？

對正數而言相同，但對負數可能不同。算術右移是向負無限大方向取整，因此 −7 會變成 −4；而向0方向捨去的C語言除法則得到 −3。

C語言的 >> 是算術位移嗎？

對無號整數與0以上的有號整數，結果規定等於除以2的冪次。對負的有號整數右移則屬於實作定義，多數編譯器採用算術位移，但需要可移植性的程式碼，最好不要依賴這一點。
