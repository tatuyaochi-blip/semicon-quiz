什麼是公開金鑰加密

加密與解密使用成對但不同的金鑰（公開金鑰與私密金鑰）的加密方式。公開金鑰讓任何人知道都無妨，私密金鑰只由本人持有。金鑰配送變得容易，但計算量大，因此加密資料本體時要與對稱式加密搭配使用。RSA與橢圓曲線密碼是代表。

日文名稱: 公開鍵暗号

「公開金鑰加密」出現在2領域的8道練習題中（資訊安全基礎, 密碼學基礎與應用等）。

這個名詞所屬的領域: 資訊安全基礎

公開金鑰與私密金鑰的用法

在公開金鑰加密中，每個人都持有數學上成對的公開金鑰與私密金鑰。為了保密，傳送者以接收者的公開金鑰加密，只有接收者能以自己的私密金鑰解密。為了證明身分，本人以自己的私密金鑰建立簽章，任何人都能以本人的公開金鑰驗證（數位簽章）。安全性的根據在於由公開金鑰求出私密金鑰實際上不可能：RSA是因為大數的質因數分解很困難，橢圓曲線密碼則是因為橢圓曲線上離散對數問題的困難。

與對稱式加密的差異與金鑰數

使用對稱式加密時，每一組通訊的兩人都必須事先共享秘密金鑰，n人需要 n(n−1)/2 把金鑰。使用公開金鑰加密時，每人只需持有一對金鑰，總共 2n 把。例如100人時，對稱式加密需要4950把，公開金鑰加密需要200把。另一方面，公開金鑰加密的計算量比對稱式加密大好幾個數量級，因此實務上普遍採用混合式加密：資料本體以對稱式加密加密，金鑰的傳遞或協商則使用公開金鑰技術。

確認公開金鑰擁有者的機制

在公開金鑰加密中，所使用的公開金鑰是否真的屬於對方很重要。若攻擊者把自己的公開金鑰假冒成他人的交出去，原本要給該人的密文就會被攻擊者讀取。因此要使用由憑證機構（CA）對「這把公開金鑰屬於此人（網域名稱）」簽章的憑證，來保證公開金鑰的擁有者。這種機制稱為PKI（公開金鑰基礎建設），HTTPS所使用的TLS伺服器憑證就是代表例子。此外，在2020年代中期，為因應未來的量子電腦，也正在推動轉換到後量子密碼。

練習公開金鑰加密的題目

A想用公開金鑰加密，把訊息加密成只有B能讀取後傳送。加密時使用的是哪一把金鑰？

  1. AA的私密金鑰
  2. BB的公開金鑰
  3. CB的私密金鑰
查看答案與解析

正確答案：B. B的公開金鑰

在公開金鑰加密中，每個人都擁有一對公開金鑰與私密金鑰。公開金鑰讓任何人知道都無妨，私密金鑰則由本人嚴密保管。以公開金鑰加密的資料，只能用與之成對的私密金鑰解密。因此A用B的公開金鑰加密後傳送，B再用自己的私密金鑰解密。即使密文在途中被竊看，沒有B私密金鑰的人也無法讀取。B的私密金鑰只有B持有，A無法使用。以A的私密金鑰處理，是用於表明資料由A建立的數位簽章。

50名成員希望任兩人之間都能以加密方式通訊，且不讓其他成員知道內容。使用對稱式加密時所需的金鑰數，與使用公開金鑰加密時所需的金鑰數（公開金鑰與私密金鑰合計），正確的組合是哪一項？

  1. A對稱式加密1225把，公開金鑰加密100把
  2. B對稱式加密2450把，公開金鑰加密100把
  3. C對稱式加密100把，公開金鑰加密1225把
查看答案與解析

正確答案：A. 對稱式加密1225把，公開金鑰加密100把

使用對稱式加密時，每一組兩人都需要各自的金鑰，因為三人以上共用同一把金鑰，其他成員也能讀取內容。從n人中選出兩人的組合數是 n(n−1)/2，因此50人需要 50 × 49 / 2 = 1225把。使用公開金鑰加密時，每人各持有一把公開金鑰與一把私密金鑰，傳給任何人時都能用對方的公開金鑰加密，因此只需 2n = 2 × 50 = 100把。人數增加時，對稱式加密的金鑰數大約與人數的平方成正比增加，公開金鑰加密則只與人數成正比。這是公開金鑰加密讓金鑰管理變得輕鬆的原因之一。

常見問題

以公開金鑰加密時，要使用誰的金鑰？

使用接收者的公開金鑰加密。只有接收者持有的成對私密金鑰能夠解密。以自己的私密金鑰處理，是數位簽章而非加密。

為什麼不只用公開金鑰加密來加密大型檔案？

因為公開金鑰加密計算量大，不適合直接加密大量資料。實際上採用混合式加密：以快速的對稱式加密加密檔案，只以公開金鑰加密保護那把對稱金鑰。
