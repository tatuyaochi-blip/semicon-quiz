什麼是奈奎斯特頻率

取樣頻率一半的頻率。對超過此頻率的成分進行取樣時，會呈現為較低頻率的訊號(混疊)。

日文名稱: ナイキスト周波数

「奈奎斯特頻率」出現在1領域的3道練習題中（AD/DA轉換等）。

這個名詞所屬的領域: AD/DA轉換

頻率如何折疊

以速率 fs 對訊號取樣時，取樣值無法區分頻率 f 與 f 加減 fs 任意整數倍的頻率。因此，每個輸入成分都會出現在 0 到 fs/2（即奈奎斯特頻率）之間的某處，就像紙張在 fs/2 的每個整數倍處沿摺痕折回一樣。例如，以 12 kHz 取樣的 10 kHz 正弦波，位於 6 kHz 的奈奎斯特頻率之上，會出現在 |12 − 10| = 2 kHz。此時的取樣值與真正的 2 kHz 音調完全相同，之後任何處理都無法將其分開。

奈奎斯特頻率與奈奎斯特速率的比較

這兩個術語很容易混淆。奈奎斯特頻率是取樣器的特性：取樣率的一半，fs/2。奈奎斯特速率是訊號的特性：其最高頻率成分的兩倍，也就是取樣定理所要求的最低取樣率。因此，對 20 kHz 的音訊取樣，需要高於 40 kHz 的取樣率。恰好位於 fs/2 的成分具有不確定性，因為取樣得到的振幅取決於其相位，甚至可能為零，這就是取樣定理要求取樣速率必須嚴格高於最高頻率兩倍的原因。

抗混疊與過取樣

由於混疊無法復原，會在 ADC 之前放置低通抗混疊濾波器，以去除奈奎斯特頻率以上的成分。實際的濾波器在通帶與阻帶之間需要過渡帶，因此取樣率的選擇會保留餘裕：音樂 CD 以 44.1 kHz 對 20 kHz 頻帶取樣，留下 20 到 22.05 kHz 的區域供濾波器滾降。以遠高於必要的速率取樣，稱為過取樣，可將奈奎斯特頻率推到遠高於訊號頻帶之處，因此簡單的一階或二階 RC 濾波器就足夠，之後再由數位濾波器進行陡峭截止。

刻意的混疊與 DAC 端

混疊並不一定是錯誤。在欠取樣（undersampling），又稱帶通取樣中，位於較高奈奎斯特區的窄頻訊號，例如無線電接收機中的中頻載波，會被刻意以低於其頻率兩倍的速率取樣，使其折疊到方便處理的較低頻率。這只有在前端加上帶通濾波器，且 ADC 的類比頻寬與時脈抖動足以應付高輸入頻率時才可行。在輸出端，DAC 會在 fs ± f 處產生鏡像，由重建低通濾波器將其去除。

練習奈奎斯特頻率的題目

要對含有最高20 kHz成分的類比訊號取樣而不產生混疊（aliasing），所需的取樣頻率為下列何者？

  1. A10 kHz以上
  2. B剛好20 kHz
  3. C高於40 kHz的頻率
查看答案與解析

正確答案：C. 高於40 kHz的頻率

依據取樣定理，以高於最高頻率2倍的頻率取樣即可還原原訊號，20 kHz則需要高於40 kHz的頻率。實務上無法以濾波器陡峭地截止，因此需保留餘裕，音樂CD以44.1 kHz取樣（將20～22.05 kHz用作濾波器的過渡頻帶）。取樣頻率的一半稱為奈奎斯特頻率。

置於ADC前級的抗混疊濾波器，使用的是哪一種濾波器？

  1. A高通濾波器
  2. B帶拒濾波器
  3. C低通濾波器
查看答案與解析

正確答案：C. 低通濾波器

若超過奈奎斯特頻率（取樣頻率的一半）的成分進入ADC，就會折返成低頻的假訊號，事後既無法區分也無法去除。因此要在ADC前放置低通濾波器，去除高於奈奎斯特頻率的成分。由於陡峭的濾波器不易製作，也常見以過取樣拉開餘裕、僅用簡單的1～2階RC濾波器的設計。

常見問題

奈奎斯特頻率和奈奎斯特速率有什麼不同？

奈奎斯特頻率是取樣率的一半，也就是特定取樣器所能表示的最高頻率。奈奎斯特速率是訊號中最高頻率的兩倍，也就是擷取該訊號所需的最低取樣率。

混疊頻率怎麼計算？

找出最接近輸入頻率的取樣率整數倍，取兩者差的絕對值。例如，以 12 kHz 取樣的 10 kHz 訊號會出現在 |12 − 10| = 2 kHz。

為什麼 CD 音訊的取樣率是 44.1 kHz 而不是 40 kHz？

人類聽覺的上限約為 20 kHz，而高於 40 kHz 的額外餘裕可讓抗混疊濾波器擁有 20 到 22.05 kHz 的過渡帶，因為實際的濾波器無法瞬間截止。
