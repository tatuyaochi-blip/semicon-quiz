什麼是施體

對半導體提供電子的雜質。對矽而言，是磷(P)、砷(As)等 V 族元素，用來形成 n 型半導體。

日文名稱: ドナー

「施體」出現在6領域的18道練習題中（半導體物性, 離子佈植, 矽晶圓等）。

這個名詞所屬的領域: 半導體物性

施體如何提供電子

磷是 V 族原子，取代矽原子後，用其五個價電子中的四個形成鍵結。第五個電子只受到微弱的束縛，因為周圍的矽會屏蔽離子的電荷，使整個系統表現得像一個大而淺的氫原子。其施體能階對磷而言約位於導帶下方 0.045 eV，對砷約為 0.054 eV，與室溫約 0.026 eV 的熱能相比很小，因此幾乎每個施體都會游離。每個施體釋放一個可移動的電子，並成為晶格中固定的正離子。

載子濃度與費米能階

當所有施體都游離時，電子濃度等於施體濃度，而質量作用定律 n·p = ni² 決定電洞濃度：施體 10¹⁶ cm⁻³、ni = 10¹⁰ cm⁻³ 時，電洞只剩每立方公分 10⁴ 個，但這些少數載子主宰著接面漏電與雙極動作。摻雜濃度每增加一個數量級，費米能階約往導帶移動 60 mV，在極高摻雜下甚至進入導帶，使材料成為簡併半導體。摻雜的效果極為顯著：矽約有 5 × 10²² atoms/cm³，因此 10¹⁶ cm⁻³ 相當於五百萬個原子中只有一個，電阻率卻會降到約 0.5 Ω·cm。

凍結區與本質區

電子濃度只在中間的溫度範圍內才會接近施體濃度，這就是元件預定操作的外質區。在矽中，低於約 100 K 時，熱能太小而無法讓電子脫離施體，載子濃度急遽下降，這稱為凍結（freeze-out）。在高溫下，跨越能隙產生的本質載子急遽增加，最終超過施體濃度，摻雜便不再能控制導電。即使在那之前，少數載子濃度的上升也會增加漏電，這是高溫晶片漏電較多的原因之一。

實務上的施體

磷與砷是矽中最主要的施體。砷較重、擴散較慢，適合淺的 n+ 源極與汲極區；銻也用於需要緩慢擴散的地方，例如重摻雜基板與埋層。施體也可能在無意間出現：柴可拉斯基法矽中的氧，在約 450 °C 加熱時可能形成熱施體。在化合物半導體中，其行為可能取決於所佔的晶格位置；GaAs 中的矽通常佔據鎵位置，作為標準的施體。

練習施體的題目

施體濃度為1×10¹⁶ cm⁻³的n型矽（施體全部離子化，本質載子濃度ni = 1×10¹⁰ cm⁻³），其電洞濃度約為多少？

  1. A1×10⁴ cm⁻³
  2. B1×10⁶ cm⁻³
  3. C1×10¹⁰ cm⁻³
查看答案與解析

正確答案：A. 1×10⁴ cm⁻³

由於施體全部離子化，電子濃度為 n ≈ 1×10¹⁶ cm⁻³。根據質量作用定律 n × p = ni²，p = (1×10¹⁰)² ÷ 1×10¹⁶ = 1×10⁴ cm⁻³。雖然少數載子只有多數載子的一兆分之一，但PN接面的逆向電流和雙載子電晶體的動作都是由這些少數載子負責。ni隨溫度急遽增加，因此少數載子濃度在高溫下也會大幅增加。

關於矽中磷所形成的施體能階在能隙內的位置，下列何者正確？

  1. A非常靠近導帶底端（低於導帶約0.045 eV）
  2. B非常靠近價電帶頂端
  3. C大致位於能隙中央
查看答案與解析

正確答案：A. 非常靠近導帶底端（低於導帶約0.045 eV）

磷的施體能階距導帶底端僅約0.045 eV，非常淺，即使是室溫的熱能（約0.026 eV），幾乎全部都會離子化而供應電子。砷約為0.054 eV，硼的受體能階距價電帶約0.045 eV。淺能階因母體介電常數而使束縛減弱，因此可用氫原子模型估算。能隙中央附近的深能階則來自金等雜質，會成為複合中心。

常見問題

磷為什麼在矽中是施體？

磷有五個價電子，比矽形成四個鍵所需的多一個。這個多出的電子束縛很弱，位於導帶下方約 0.045 eV，因此在室溫下就會被釋放，使矽成為 n 型。

n 型矽的電洞濃度怎麼計算？

使用質量作用定律 p = ni²/n，並取 n ≈ ND。當 ND = 10¹⁶ cm⁻³、ni = 10¹⁰ cm⁻³ 時，p = 10⁴ cm⁻³。

什麼是載子凍結（freeze-out）？

在極低溫下（矽約低於 100 K），熱能不足以使施體游離，電子仍受束縛，自由載子濃度因而急遽下降。

出現這個名詞的比較

  • n 型半導體與 p 型半導體的差異：摻雜物、多數載子、費米能階、遷移率比較從添加的雜質（施體與受體）、多數載子、雜質能階、費米能階的位置、遷移率與電阻率，以及在元件中的使用位置等面向，以表格比較 n 型與 p 型半導體。
  • 本質半導體與雜質半導體的差異：載子、費米能階、溫度特性比較從載子的來源與密度、費米能階、電阻率、隨溫度的變化與用途等面向，以表格比較不含雜質的本質半導體，以及加入施體或受體的雜質半導體（外質半導體，n 型與 p 型）。
