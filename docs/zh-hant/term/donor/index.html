什麼是施體

對半導體提供電子的雜質。對矽而言，是磷(P)、砷(As)等 V 族元素，用來形成 n 型半導體。

日文名稱: ドナー

「施體」出現在3領域的4道練習題中（矽晶圓, 化合物半導體, 磊晶成長等）。

這個名詞所屬的領域: 半導體物性

練習施體的題目

將CZ矽在450℃附近熱處理時，氧原子會聚集並作為施體作用，使晶圓的電阻率改變。這稱為什麼？

  1. A吸附位置
  2. B熱施體
  3. C深受體
查看答案與解析

正確答案：B. 熱施體

將含有間隙氧的CZ矽在350〜500 ℃進行熱處理，會形成由數個氧原子聚集而成的集合體，作為釋放電子的施體發揮作用(熱施體，thermal donor)。它在450 ℃附近形成最快，最多可達10¹⁶ cm⁻³左右，所以特別是低濃度的p型晶圓，電阻率會大幅改變，甚至反轉成n型。可以用650 ℃左右以上的短時間熱處理消除，在晶圓出貨時就會處理。

解析中的「施體」

  • IV族的矽進入III族鎵的位置時，會多出1個價電子而成為施體，形成n型。

    在GaAs中添加矽使其成為n型時，矽主要取代的位置是下列何者？

  • 添加量極微，作為施體的影響幾乎不成問題。

    在CZ晶體成長中微量添加氮(氮摻雜)，其已知的效果是哪一項？

  • GaN會因成長中非刻意納入的氧或矽等施體而容易成為n型，若電流流過緩衝層，閘極就不易截止電流，高電壓下漏電也會增加。
