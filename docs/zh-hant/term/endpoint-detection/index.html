什麼是終點偵測

在蝕刻等製程中，偵測目標薄膜蝕刻完畢的時間點。常用的方法是監測電漿發光光譜的變化。

日文名稱: 終点検出

「終點偵測」出現在2領域的3道練習題中（蝕刻, CMP與清洗等）。

這個名詞所屬的領域: 蝕刻

為什麼需要終點偵測

在乾式蝕刻中，膜厚與蝕刻速率在晶圓面內及晶圓之間都有變異，若只依固定時間蝕刻，就會發生蝕刻殘留或底層被過度蝕刻。終點偵測是在蝕刻進行中即時掌握目標薄膜消失、底層露出的時間點，用來停止主蝕刻或切換製程條件的技術。由於在偵測到的時間點，部分區域往往仍殘留薄膜，一般會在之後追加一段固定時間的過蝕刻，並以對底層選擇比高的條件去除剩餘部分。

以發射光譜法（OES）偵測

最常用的是以光譜儀監測電漿發光的發射光譜法（OES）。蝕刻薄膜期間，蝕刻反應的生成物會發光；底層露出後，生成物的種類與量改變，特定波長的發光強度便隨之增加或減少。例如在氧化層蝕刻中，CO在483 nm附近的發光會隨底層露出而減弱。設備只需透過窗口觀察電漿的光，不必接觸晶圓即可量測。藉由組合多個波長或取強度比，可以抑制雜訊與腔體狀態變動的影響。

干涉儀等其他方法

像接觸孔這樣，蝕刻面積只占整片晶圓極小部分時，生成物的變化很小，OES的訊號會變弱。此時會使用對晶圓照光並監測反射光干涉的雷射干涉儀，或使用寬波段光的光譜反射法，直接追蹤剩餘膜厚。膜厚的變化會呈現為干涉強弱的週期，因此也可用於在中途深度停止的控制。另外也有監測電漿電氣阻抗變化的方法。CMP同樣會利用馬達扭矩、光反射率，或對金屬膜使用渦電流感測器來偵測研磨終點。

與時間控制的差異

控制蝕刻量的方法，有以時間決定的方法與使用終點偵測的方法。以時間決定時，時間由膜厚÷蝕刻速率求得。例如以100 nm/min蝕刻500 nm的薄膜需要5分鐘，加上20%的過蝕刻約為6分鐘。然而，設備狀態的變化與膜厚的變異，會直接變成蝕刻殘留或過度蝕刻。使用終點偵測，就能逐片吸收這些變異。終點只是「底層開始露出的時間點」，之後過蝕刻的量與條件，才是兼顧去除殘留物與保護底層的關鍵。

  1. A稱量晶圓的重量
  2. B監測電漿發光光譜的變化
  3. C蝕刻後以目視確認
查看答案與解析

正確答案：B. 監測電漿發光光譜的變化

當正在蝕刻的膜消失、底層露出時，電漿中反應生成物的種類與量會改變，特定波長的發光強度也隨之變化。例如在氧化層蝕刻中，CO（483 nm）的發光會減弱。藉由發射光譜法（OES）監測此變化，就能即時偵測蝕刻的終點。當露出的面積非常小時訊號會變弱，因此也會使用干涉儀量測膜厚等方法。

常見問題

蝕刻的終點如何偵測？

主要是以光譜儀監測電漿的發光（發射光譜法，OES）。底層露出時蝕刻生成物會改變，特定波長的發光強度隨之變化，便以該變化點作為終點。當露出面積小、訊號弱時，也會使用雷射干涉儀等直接量測膜厚的方法。

偵測到終點後會立刻停止蝕刻嗎？

一般不會停止，而是繼續進行過蝕刻。因為終點只代表部分區域的薄膜已消失，膜厚與蝕刻速率的變異、段差的側壁等處仍可能殘留薄膜。過蝕刻會切換為對底層選擇比高的條件進行。

什麼情況下終點偵測會變得困難？

像接觸孔或介層孔這樣，蝕刻面積只占晶圓極小部分的時候。生成物的變化小，發光的變化容易被雜訊淹沒。可利用多個波長的比值或統計處理提高靈敏度，或與干涉儀等其他方法併用。
