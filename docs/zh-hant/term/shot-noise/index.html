什麼是散粒雜訊

因光子或電子數量的統計起伏而產生的雜訊。若訊號電子數為 N，其大小與 √N 成正比，因此光越少，相對於訊號就越大。

日文名稱: ショットノイズ

「散粒雜訊」出現在1領域的5道練習題中（影像感測器與光電元件等）。

這個名詞所屬的領域: 影像感測器與光電元件

散粒雜訊的來源

光與電流都由在隨機時間抵達的離散粒子組成。當各事件相互獨立時，其計數服從泊松統計：變異數等於平均值，因此平均 N 個光電子的訊號，其起伏約為 N 的平方根。在電子電路中，當載子獨立地越過能障時（例如二極體接面或光二極體）也會出現相同效應，產生 2qI 的雜訊電流頻譜密度（肖特基公式）。它與電阻中的熱雜訊不同，熱雜訊源自隨機的熱運動，即使沒有電流也會存在。

影像中的訊雜比

由於雜訊隨 N 的平方根增加，受散粒雜訊限制的訊雜比（SNR）等於 N 除以其平方根，結果同樣是 N 的平方根：100 個電子時為 10，10,000 個電子時為 100。暗場景收集到的電子很少，因此光子雜訊與讀出雜訊相對於訊號很大，影像看起來顆粒感重。提高 ISO 主要是將訊號與雜訊一起放大，無法降低散粒雜訊。滿井容量則限制了單一像素單次曝光所能達到的最佳 SNR。

以光子轉換法評估感測器

由於以電子數計的光子散粒雜訊，其變異數等於平均值，因此可作為內建的校正來源。在光子轉換曲線（PTC）法中，於數個光強度下拍攝平場影像，並將輸出（以數位值計）的變異數對平均值作圖。斜率給出電子與數位值之間的轉換增益，低訊號時的底部給出讀出雜訊，變異數停止上升的點則標示滿井容量，由此可推得動態範圍。

與它共存：像素合併、多張疊合與 EUV

散粒雜訊是光本身的性質，因此更好的電路也無法消除；只有收集更多光子才有幫助。較大的像素、較亮的鏡頭、夜景模式的多張疊合以及像素合併都是這麼做。將 2×2 區塊合併可使訊號變為四倍，在散粒雜訊為主時 SNR 約提高為兩倍。光子散粒雜訊也限制了極紫外光（EUV）微影：每個 13.5 nm 光子攜帶約 92 eV 的能量，約為 193 nm 光子的十四倍，因此相同劑量所提供的光子數少得多，造成隨機的線邊緣粗糙度與隨機缺陷。

練習散粒雜訊的題目

關於光子數的統計漲落所造成的散粒雜訊大小，與訊號電子數N的關係，下列何者正確？

  1. A與N成正比
  2. B與√N成正比
  3. C與N無關而為定值
查看答案與解析

正確答案：B. 與√N成正比

光子是隨機到達的，因此平均N個訊號電子會有約√N的漲落（帕松分布）。這就是散粒雜訊，S/N = N/√N = √N，光越多S/N越好。例如100個時為10，1萬個時為100。由於這是光本身性質所造成的極限，不論如何改良電路都無法消除，根本的對策是以大像素或透鏡收集更多的光。

常見問題

為什麼散粒雜訊與訊號的平方根成正比？

隨機抵達的光子或電子服從泊松統計，其變異數等於平均值。因此代表雜訊的標準差，就是平均計數的平方根。

散粒雜訊和熱雜訊有什麼不同？

散粒雜訊來自電荷或光子的離散性，會隨電流或訊號而變化。熱雜訊則來自電阻中載子的隨機熱運動，即使沒有電流流動也會存在。

暗光下調高 ISO 能降低雜訊嗎？

沒有實質效果。較高的 ISO 會同等放大訊號與散粒雜訊。只有透過延長曝光、加大光圈或像素，或將多張影像平均來收集更多光，才能改善訊雜比。
