什麼是轉移函數

以初始值全為0時輸出與輸入的拉普拉斯轉換之比 G(s) = Y(s)/X(s)，表示線性非時變系統輸入與輸出關係的函數。等於系統脈衝響應的拉普拉斯轉換。使分母為0的 s 稱為極點，使分子為0的 s 稱為零點，由極點的位置可知穩定性與響應的快慢。令 s = jω 即得頻率響應。離散時間系統則使用z轉換，以 H(z) 表示。

日文名稱: 伝達関数

「轉移函數」出現在2領域的23道練習題中（控制工程基礎, 數位訊號處理基礎等）。

這個名詞所屬的領域: 控制工程基礎

以方塊圖計算

使用轉移函數時，元件的串聯以乘法表示，並聯以加法表示。在負回授迴路中，設前向轉移函數為 G(s)、回授轉移函數為 H(s)，閉迴路轉移函數為 G(s)/(1 + G(s)H(s))。乘積 G(s)H(s) 稱為迴路轉移函數（開迴路轉移函數），是探討穩定性與穩定邊限的出發點。

代表性的形式

RC低通濾波器是 1/(1 + sRC) 這種一階系統，RLC電路與馬達的位置控制迴路，則常以二階系統表示。積分為 1/s，微分為 s，時間 L 的時間延遲為 e^(−Ls)。分母次數不小於分子次數的轉移函數稱為真分式（proper），實際的物理系統通常是這種形式。

極點與零點告訴我們的事

極點 p 會在響應中產生 e^(pt) 的成分，因此所有極點的實部為負時系統就是穩定的。極點越接近虛軸，響應衰減越慢；虛部越大，振盪越快。零點會改變響應的形狀，在s平面右半部有零點的系統，步階響應可能出現一開始往反方向移動的逆響應，使快速控制變得困難。

練習轉移函數的題目

由離散時間LTI系統的轉移函數 H(z) 求頻率響應時，z 應沿著下列何處移動？

  1. Az平面的單位圓上（z = e^(jω)，|z| = 1）
  2. Bz平面的正實軸上（z = r，r 為大於0的實數）
  3. Cz平面的虛軸上（z = jω）
查看答案與解析

正確答案：A. z平面的單位圓上（z = e^(jω)，|z| = 1）

頻率響應是把 z = e^(jω) 代入 H(z) 所得，ω 從 −π 變到 π 時，z 沿單位圓繞1圈。z = 1（ω = 0）對應直流，z = −1（ω = π）對應奈奎斯特頻率。連續時間的拉普拉斯轉換是在虛軸 s = jω 上求頻率響應，而在離散時間中對應的就是單位圓。

以差分方程式 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1] 表示的系統，其轉移函數 H(z) = Y(z)/X(z) 為下列何者？

  1. A(1 + 0.5z⁻¹)/(1 + 0.25z⁻¹)
  2. B(1 − 0.25z⁻¹)/(1 + 0.5z⁻¹)
  3. C(1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)
查看答案與解析

正確答案：C. (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)

延遲1個取樣點在z轉換中相當於乘上 z⁻¹，因此兩邊做z轉換得 Y(z) = X(z) + 0.5z⁻¹X(z) + 0.25z⁻¹Y(z)。把 Y(z) 的項移到左邊，得 (1 − 0.25z⁻¹)Y(z) = (1 + 0.5z⁻¹)X(z)，所以 H(z) = (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)。分子表示輸入側的係數，分母表示輸出回授側的係數；使分母為0的 z = 0.25 是極點，使分子為0的 z = −0.5 是零點。

常見問題

轉移函數與頻率響應有什麼不同？

轉移函數 G(s) 是複數 s 的函數，把 s 限定在虛軸上的 jω 即為頻率響應 G(jω)。把頻率響應的大小與相位對頻率作圖，就是波德圖。

非線性系統也有轉移函數嗎？

直接是無法定義的。在操作點附近線性化後，就能對該點附近的微小變化使用轉移函數。飽和或死區這類強烈的非線性，要以其他方法處理。
