什麼是穩定排序

鍵相同的元素之間，在排序後仍保持原本順序的排序。泡沫排序、插入排序、合併排序是穩定的，選擇排序、快速排序、堆積排序一般不穩定。依多個鍵依序排序時需要這個性質。

日文名稱: 安定ソート

練習穩定排序的題目

（姓名, 分數）的資料 (A, 80)、(B, 70)、(C, 80)、(D, 70) 依此順序排列。以穩定排序依分數升冪重新排列時，姓名的順序為下列何者？

  1. AB, D, A, C
  2. BD, B, A, C
  3. CB, D, C, A
查看答案與解析

正確答案：A. B, D, A, C

在穩定排序中，鍵（這裡是分數）相同的元素之間，會維持排序前的順序。70分的 B 與 D 依原順序為 B、D，80分的 A 與 C 依原順序為 A、C，因此結果為 B, D, A, C。穩定的排序有泡沫排序、插入排序、合併排序，而選擇排序、快速排序、堆積排序一般不穩定。使用穩定排序，就能做到先依姓名排序、再依分數重新排序這類以多個鍵進行的排序。
