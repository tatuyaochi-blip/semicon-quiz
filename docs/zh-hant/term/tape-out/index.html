什麼是投片(Tape-out)

在設計與驗證完成後，將供製作光罩用的佈局資料交給製造端。名稱源自過去以磁帶交付資料。

日文名稱: テープアウト

「投片(Tape-out)」出現在1領域的1道練習題中（LSI設計流程與EDA等）。

這個名詞所屬的領域: LSI設計流程與EDA

交付了什麼

投片時，設計團隊以 GDSII 或 OASIS 檔案交付最終佈局，檔案中逐層列出多邊形。製造端接著進行光罩資料準備：套用光學鄰近修正（OPC）與其他解析度增強技術，將圖形分割成光罩寫入機可接受的格式，然後寫入並檢查光罩。之後晶圓才能開始投入生產。光罩製作所使用的並不是 Verilog 或 SPICE 網表等邏輯描述。

投片前的簽核檢查

由於投片後出錯的代價極高，投片必須通過簽核把關。靜態時序分析必須在各製程、電壓與溫度角落下通過。設計規則檢查（DRC）確認佈局符合製造規則，佈局與電路圖比對（LVS）確認佈局實現了預期的電路。電源網路分析涵蓋 IR 壓降與電遷移，其他檢查則針對天線效應、電氣規則與可製造性。晶圓代工廠也可能對收到的資料執行自己的檢查。

重新投片與金屬層修正

投片後發現錯誤就意味著需要新光罩。先進製程的一整套光罩可能花費數千萬美元，修正還會使產品延遲數個月，因此團隊會設法限制損害。散布在佈局中的備用元件（spare cell），讓許多邏輯修正只需變更金屬層與通孔層即可完成；這種工程變更命令（ECO）所需的新光罩遠少於完整的重新投片。

在時程中的位置

典型的數位流程從規格開始，經過 RTL 設計、邏輯合成、佈局繞線、簽核，最後投片。對於最先進的晶片，這可能需要一到兩年；投片後的晶圓加工還要再花數個月，第一批矽晶片才會送回測試。在原型階段，小型設計常透過多專案晶圓（MPW）與其他專案共用一片光罩，分攤光罩成本。

練習投片(Tape-out)的題目

一般數位LSI的設計流程順序，下列何者正確？

  1. A規格設計 → RTL設計 → 邏輯合成 → 佈局繞線
  2. B邏輯合成 → 規格設計 → 佈局繞線 → RTL設計
  3. C佈局繞線 → RTL設計 → 邏輯合成 → 規格設計
查看答案與解析

正確答案：A. 規格設計 → RTL設計 → 邏輯合成 → 佈局繞線

首先在規格設計決定功能與效能，並以Verilog或VHDL等硬體描述語言進行RTL設計。接著以邏輯合成轉換為閘級網表，再以佈局繞線製作晶片上的佈局。每個階段都要進行驗證，最後輸出為光罩資料。這是由抽象程度高的描述逐步落實為具體形態的流程，因此其他順序都不成立。先進產品從規格確定到下線（tape-out）有時需要1～2年。

常見問題

為什麼叫做 tape-out（投片）？

過去佈局資料是以磁帶交付給光罩廠。雖然現在檔案都以電子方式傳輸，這個名稱仍沿用至今。

投片之後會發生什麼？

佈局會經過包含 OPC 的光罩資料準備，接著寫入光罩並加工晶圓，之後進行封裝、測試與矽晶片初步驗證（bring-up）。

晶片設計中的 respin（重新投片）是什麼？

respin 是為了修正在矽晶片上發現的問題而進行的第二次（或之後的）投片。至少需要為變更的層製作新光罩，並會使產品延遲。
