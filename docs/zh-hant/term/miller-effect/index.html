什麼是米勒效應

反相放大電路的輸入與輸出之間的電容，從輸入側看來變成(1 + 增益)倍大的效應。會使共射極與共源極電路的高頻特性變差。

日文名稱: ミラー効果

「米勒效應」出現在4領域的6道練習題中（雙載子電晶體, MOSFET, 類比與電子電路等）。

這個名詞所屬的領域: 雙載子電晶體

電容為何看起來變大

考慮一個電容C，跨接在電壓增益為−Av的反相放大器的輸入與輸出之間。當輸入上升v時，輸出下降Av·v，因此電容兩端的電壓變化為(1 + Av)·v。輸入端必須提供接地電容時(1 + Av)倍的電荷，所以這個電容從輸入端看來就像C(1 + Av)。從輸出端看，同一個電容大約相當於C(1 + 1/Av)，接近C本身。這個等效輸入電容通常稱為米勒電容。

對放大器頻寬的影響

在共射極放大級中，被這樣放大的是基極-集極電容Cμ；在共源極放大級中則是閘極-汲極電容Cgd，其中包含閘極與汲極的重疊電容。若Cμ = 2 pF、增益為100，輸入端看到的約為200 pF。它與訊號源電阻Rs在約1/(2π·Rs·C_Miller)處形成低通極點，往往決定了該放大級的頻寬上限。因此增益越高，頻寬就直接被犧牲，這也是由高阻抗訊號源驅動的高增益反相放大級速度較慢的原因。

抑制米勒效應的方法

經典的對策是疊接（cascode）：在輸入元件上方疊加一個共基極（或共閘極）電晶體，使輸入電晶體的集極或汲極維持在近乎固定的電壓。如此一來，輸入元件的電壓增益只有約1，回授電容幾乎不會被放大，而整個放大級仍保有高增益。單獨使用共基極放大級也能避免此問題，因為其基極在交流上接地。降低驅動訊號源的電阻可提高極點頻率，選用回授電容小的元件也有幫助。

米勒效應的有益應用

同樣的放大作用會被刻意運用在運算放大器的頻率補償中。跨接在高增益反相放大級上的小電容，表現得如同大電容，可在低頻產生主極點，讓增益在其他極點帶來大幅相位偏移之前就降到1以下。如此一來，即使作為單位增益隨耦器使用，放大器仍能保持穩定，而不必在晶片上放置實體尺寸很大的電容。在功率MOSFET的切換中，米勒效應也說明了為何汲極電壓擺動、Cgd充電期間，閘極電壓會出現平台區（米勒平台）。

練習米勒效應的題目

關於使共射極放大電路高頻特性變差的米勒效應，下列說明何者正確？

  1. A基極-集極間的電容，會依電壓增益而從輸入側看起來像大電容
  2. B射極的電阻會隨溫度而變化
  3. C集極電流會因熱雜訊而起伏
查看答案與解析

正確答案：A. 基極-集極間的電容，會依電壓增益而從輸入側看起來像大電容

在共射極電路中，集極電壓與基極反相且大幅擺動，因此基極-集極間的電容Cμ從輸入側看起來約為(1 + |Av|)倍。例如Cμ = 2 pF、增益100時，約為200 pF，並與訊號源的電阻形成低通濾波器而使頻帶變窄。對策有：疊上共基極級而在集極側取得增益的疊接（cascode）連接，以及降低訊號源的電阻。

常見問題

什麼是米勒電容？

米勒電容是跨接在反相放大器輸入與輸出之間的電容，對訊號源所呈現的放大後輸入電容，約為C(1 + |Av|)。對電晶體而言，這個跨接電容通常是Cμ（雙載子）或Cgd（MOSFET）。

為什麼疊接（cascode）放大器能降低米勒效應？

在疊接結構中，輸入電晶體驅動的是共基極或共閘極元件的低阻抗，因此其本身的電壓增益約為1。回授電容只會被放大約2倍，而不是整個放大級的增益倍數。

非反相放大器也會有米勒效應嗎？

大幅度的放大需要反相增益；若是增益接近+1的隨耦器，跨接電容兩端的電壓幾乎不變，其等效輸入電容反而會縮小。這就是射極隨耦器與源極隨耦器具有良好高頻特性的原因。

解析中的「米勒效應」

  • 輸入阻抗約為1/gm（1 mA時約26 Ω）而偏低，且基極在交流上接地，不易受輸入輸出間回授電容的影響（米勒效應），因此能放大到高頻。

    關於共基極放大電路，下列特徵何者正確？

  • 這就是米勒效應，在MOSFET中其對象是閘極-汲極間電容Cgd。

    從放大電路的輸入側來看，閘極-汲極間的電容看起來被放大為(1 + 增益)倍，這種效應稱為什麼？

  • 重疊部分會成為閘極與源極、汲極之間的重疊電容，因米勒效應而使延遲增加。

  • 運算放大器利用米勒效應，以小電容製造低頻率的極點。

    下列哪一項是運算放大器相位補償中所用「主極點補償」的正確想法？

  • 閘極的輸入電容會隨電壓大幅變化（米勒效應），因此比起電容值，直接表示充電所需電荷的Qg在設計驅動電路時較為方便。
