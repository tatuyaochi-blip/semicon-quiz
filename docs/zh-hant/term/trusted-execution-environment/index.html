什麼是TEE（可信執行環境）

與一般作業系統也隔離、由硬體保護的執行環境。用於進行金鑰處理與認證等重要處理。例如 Arm 的 TrustZone。

日文名稱: TEE(信頼できる実行環境)

「TEE（可信執行環境）」出現在1領域的4道練習題中（硬體安全等）。

這個名詞所屬的領域: 硬體安全

練習TEE（可信執行環境）的題目

下列關於TEE（可信執行環境）的說明，何者正確？

  1. A與一般作業系統隔離、受硬體保護的執行環境，用來進行金鑰處理與認證等重要處理
  2. B用來加快網際網路通訊的環境
  3. C用來撰寫程式的文字編輯軟體
查看答案與解析

正確答案：A. 與一般作業系統隔離、受硬體保護的執行環境，用來進行金鑰處理與認證等重要處理

一般作業系統功能龐大且複雜，要完全消除漏洞並不容易。TEE藉由硬體機制，建立與一般作業系統分離的小型執行環境，指紋比對、付款處理、DRM金鑰的處理等特別需要保護的處理就在其中進行。目的是即使一般作業系統被劫持，也無法動到TEE內的記憶體與金鑰。Arm的TrustZone是代表性的例子。

下列關於Intel SGX這類「飛地（enclave）」型TEE的特徵，何者正確？

  1. A在外接硬碟上執行整個作業系統核心
  2. B在由CPU將記憶體加密保護的區域中執行應用程式的一部分，連作業系統或超管理器（hypervisor）也無法讀取其內容
  3. C飛地內的資料任何人都能自由改寫
查看答案與解析

正確答案：B. 在由CPU將記憶體加密保護的區域中執行應用程式的一部分，連作業系統或超管理器（hypervisor）也無法讀取其內容

在飛地中，只有應用程式處理機密的部分在特殊的記憶體區域中執行，該區域在CPU內經過加密與竄改偵測後才放到主記憶體。連作業系統、超管理器，以及以物理方式讀取記憶體的攻擊者都看不到內容。需要信任的只有CPU及其程式碼。不過也有報告指出其對旁路攻擊的脆弱性，使用時需要留意。

解析中的「TEE（可信執行環境）」

  • TEE藉由硬體機制，建立與一般作業系統分離的小型執行環境，指紋比對、付款處理、DRM金鑰的處理等特別需要保護的處理就在其中進行。

    下列關於TEE（可信執行環境）的說明，何者正確？

  • 在遠端證明中，機器將記錄於TPM或TEE的軟體度量值，以無法從晶片內取出的金鑰簽章後送給伺服器。

    下列關於遠端證明（remote attestation）的說明，何者正確？

  • 在縱深防禦中，會疊加安全啟動、記憶體保護、TEE、加密、旁路攻擊對策、物理防竄改性等性質不同的對策，使一個被突破時，下一層仍能守住。
