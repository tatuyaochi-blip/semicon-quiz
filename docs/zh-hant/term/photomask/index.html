什麼是光罩(Reticle)

描有電路圖案的曝光用原版。在石英玻璃基板上形成遮光膜圖案（EUV則為反射式）。縮小投影曝光設備的光罩，製作為晶圓上圖案的4倍大小。

日文名稱: フォトマスク(レチクル)

「光罩(Reticle)」出現在7領域的20道練習題中（LSI設計流程與EDA, 半導體產業與市場, 先進技術（3D構裝與小晶片）等）。

這個名詞所屬的領域: 微影

練習光罩(Reticle)的題目

完成設計與驗證後，將光罩製作用的資料交付給製造方，稱為什麼？

  1. A切割（dicing）
  2. B下線（tape-out）
  3. C打線（bonding）
查看答案與解析

正確答案：B. 下線（tape-out）

下線是將設計的最終資料（光罩資料）交付給製造方，是設計製程中重要的里程碑。名稱源自過去以磁帶交付資料。先進製程的整套光罩有時高達數十億日圓規模，若下線後才發現缺陷，就必須重製光罩（respin），造成龐大的費用與數個月的延誤。切割與打線則是後段製程的作業。

為了製作光罩而交付給製造方的佈局資料，代表性的格式為下列何者？

  1. AVerilog
  2. BSPICE網表
  3. CGDSII或OASIS
查看答案與解析

正確答案：C. GDSII或OASIS

GDSII與OASIS是按層描述佈局圖形（多邊形）的資料格式，在下線時交付給製造方，經過OPC等處理後用於製作光罩。GDSII是1970年代起的舊格式，針對資料量龐大的先進產品，開始使用壓縮效率更高的OASIS。Verilog是電路的描述語言，SPICE網表則是電路模擬用的資料。
