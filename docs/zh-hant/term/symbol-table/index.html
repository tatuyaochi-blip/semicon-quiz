什麼是符號表（Symbol table）

包含於目的檔或可執行檔中，記錄函式與變數的名稱和位址等的清單。用於連結與除錯，可用 strip 移除。

日文名稱: シンボルテーブル

「符號表（Symbol table）」出現在1領域的3道練習題中（連結器與載入器與執行檔格式等）。

這個名詞所屬的領域: 連結器與載入器與執行檔格式

練習符號表（Symbol table）的題目

關於編譯器從單一原始檔輸出的目的檔（.o），下列何者正確？

  1. A是可直接在作業系統上執行的完整程式
  2. B只是將原始碼壓縮而成，不含機器碼
  3. C含有機器碼，但其他檔案中的函式與變數的位址尚未決定
查看答案與解析

正確答案：C. 含有機器碼，但其他檔案中的函式與變數的位址尚未決定

目的檔中包含該檔案內函式經翻譯後的機器碼、變數的初始值、所定義與所參照的名稱清單（符號表），以及事後要填入位址的位置清單（重定位資訊）。像printf這樣呼叫其他檔案中函式的指令，由於不知道位址，仍保留暫時的值。連結器會將多個目的檔整合起來決定位址，進而產生執行檔。

關於連結器所進行的符號解析，下列說明何者正確？

  1. A將某檔案中使用的函式或變數名稱，對應到另一個檔案中的該定義
  2. B將原始碼的變數名稱換成較短的名稱，使其難以閱讀
  3. C將含有數學符號的算式重新計算成數值
查看答案與解析

正確答案：A. 將某檔案中使用的函式或變數名稱，對應到另一個檔案中的該定義

若在main.c中呼叫sum函式，並在sum.c中定義其內容，則main.o會記錄「參照sum」，sum.o會記錄「定義sum」。連結器會蒐集所有目的檔的符號表，為每個參照找出一個對應的定義。若找不到定義，就會出現「未定義的參照」錯誤；若有兩個以上，則會出現「重複定義」錯誤。

解析中的「符號表（Symbol table）」

  • 目的檔中包含該檔案內函式經翻譯後的機器碼、變數的初始值、所定義與所參照的名稱清單（符號表），以及事後要填入位址的位置清單（重定位資訊）。

    關於編譯器從單一原始檔輸出的目的檔（.o），下列何者正確？

  • 連結器會蒐集所有目的檔的符號表，為每個參照找出一個對應的定義。

    關於連結器所進行的符號解析，下列說明何者正確？

  • 執行檔中有時會包含排列函式與變數名稱的符號表，以及表示與原始碼行對應關係的除錯資訊。
