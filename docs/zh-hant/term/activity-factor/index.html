什麼是活動因子（Activity factor）

電路訊號每個時脈切換的比例。是動態功耗公式 αCV²f 中的 α。可藉由時脈閘控等降低。

日文名稱: 活動率

這個名詞所屬的領域: 電源管理（軟體控制）

活動因子計算的是什麼

活動因子 α 衡量一個節點相對於時脈實際切換的頻繁程度。每個週期都上升又下降的時脈線是基準情況，而只偶爾改變的資料位元則 α 很小。慣例有所不同：許多教材將 α 定義為每個週期發生 0 到 1 轉換的機率，因為每次上升轉換都會從電源汲取 CV²，因此 P = αCV²f，時脈的 α = 1。也有教材計算每一次切換，寫成 P = ½αCV²f。兩者描述的是相同的物理現象，因此要確認工具或教科書所用的是哪一種定義。

計算範例

設 α = 0.1、切換電容 C = 1 nF、V = 1 V、f = 1 GHz，則動態功耗為 0.1 × 10⁻⁹ F × (1 V)² × 10⁹ Hz = 0.1 W；奈與吉這兩個字首正好方便地互相抵消。乘積 αC 常被稱為有效切換電容，因為只有實際切換的電容才會耗費能量。功耗估算工具會從模擬中取得每條線網的 α，所使用的是執行實際工作負載時記錄的切換活動檔案，因為憑猜測得到的平均活動，對特定區塊可能嚴重失準。

降低切換活動的方法

時脈閘控是最廣泛使用的技術：它停止送往內容不會改變之暫存器的時脈，同時消除暫存器與局部時脈樹的切換，而由於時脈每個週期都會切換，時脈樹是耗電大戶。運算元隔離（operand isolation）讓閒置運算單元的輸入保持不變，使其不去計算無用的結果。編碼也有幫助，例如格雷碼計數器或匯流排反相編碼（bus-invert coding），可限制同時切換的導線數量。平衡各路徑的延遲則能減少突波（glitch），也就是增加活動卻沒有做任何有用工作的虛假轉換。

活動因子與漏電

降低 α 只會降低動態功耗。漏電功耗不論是否有任何切換，都會流經截止的電晶體，因此經過時脈閘控的區塊仍然會漏電。要削減靜態功耗需要不同的工具，例如切斷閒置區塊電源的電源閘控，或使用較高臨界電壓的電晶體。電源電壓則同時影響兩者：動態功耗與 V² 成正比，漏電在較低電壓下也會減少，這就是為什麼動態電壓頻率調整（DVFS）是降低活動的補充手段，而非替代手段。

常見問題

時脈訊號的活動因子是多少？

在將 α 定義為每週期發生上升轉換之機率的常見慣例下，時脈每個週期上升一次，因此 α = 1。一般資料訊號的活動通常低得多。

時脈閘控如何降低功耗？

時脈閘控停止送往不需要更新之暫存器的時脈，使這些暫存器及供應它們的時脈佈線停止切換。這會降低 P = αCV²f 中的活動因子 α，但無法消除漏電功耗。

為什麼叫做活動因子？

因為它描述電路訊號有多活躍，也就是平均每個時脈週期有多少比例的節點發生切換。活動越高的電路每個週期充放電的電容越多，因此消耗的動態功耗也越多。

出現這個名詞的比較

  • 靜態功耗與動態功耗的差異：成因、公式、溫度依存、降低方法比較從成因、公式、對電源電壓與頻率的依存、溫度依存、降低方法、微縮（scaling）所帶來的變化等面向，以表格比較 CMOS 電路的靜態功耗（漏電功耗）與動態功耗，並說明待機中與動作中有效對策的差異。
