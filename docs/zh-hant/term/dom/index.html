什麼是文件物件模型（DOM）

把HTML或XML文件，以元素、文字等為節點的樹狀結構表示，讓程式能夠讀寫的介面。瀏覽器解析HTML建立DOM，JavaScript以document.querySelector等方法找出元素，改寫文字、屬性、樣式，或加入元素。DOM改變時，瀏覽器會視需要重新進行版面配置的計算與繪製，因此變更過多會讓顯示變慢。

日文名稱: DOM(Document Object Model)

  1. A把伺服器資料庫的表格結構，轉換成HTML表格（table元素）的形式以便送往瀏覽器的東西
  2. B把HTML文件以元素等為節點的樹狀結構表示，可由JavaScript讀寫
  3. C為了縮小檔案、加快載入，去除空白而壓縮CSS規則的格式
查看答案與解析

正確答案：B. 把HTML文件以元素等為節點的樹狀結構表示，可由JavaScript讀寫

瀏覽器解析HTML，建立以html元素為根、head、body及其中的段落等為節點的樹狀結構（DOM樹）。JavaScript以document.querySelector找出元素、改寫文字或屬性、加入元素等，透過DOM改變網頁。DOM改變時，瀏覽器會視需要重新進行版面配置的計算與繪製。DOM被標準化為不依賴特定程式語言、用來操作文件的介面。
