什麼是FD-SOI(全空乏型SOI)

在埋入氧化膜上方非常薄的矽層中製作電晶體，使通道完全空乏的技術。可減少通道雜質，並容易以基板偏壓調整臨界電壓。

日文名稱: FD-SOI(完全空乏型SOI)

「FD-SOI(全空乏型SOI)」出現在1領域的3道練習題中（先進電晶體（FinFET與GAA）等）。

這個名詞所屬的領域: 先進電晶體（FinFET與GAA）

全空乏的意義

在絕緣層上覆矽（SOI）中，電晶體位於埋入氧化層（BOX）上方的矽薄膜中。若薄膜比閘極所產生的空乏區更厚，下方就會留下一個電性浮接的中性本體；這就是部分空乏型 SOI（PD-SOI），會受到浮體效應的影響，例如輸出曲線上的扭結（kink）。在 FD-SOI 中，薄膜只有約 5–7 nm 厚，因此整層薄膜都被空乏。不存在浮接的中性區域，也沒有遠離閘極的電流路徑。

未摻雜通道與較低的變異

由於薄膜本身就能抑制短通道效應，FD-SOI 不需要以高濃度通道摻雜來防止汲極控制通道。未摻雜或輕摻雜的通道可避免隨機摻雜擾動，也就是摻雜原子數量與位置的統計分散，這種分散會使小尺寸塊材電晶體的臨界電壓變動數十毫伏。臨界電壓則主要由閘極功函數決定。雜質散射減少也有助於載子遷移率，相鄰電晶體之間的匹配性也會改善，對 SRAM 與類比電路有利。

透過薄 BOX 進行基板偏壓

FD-SOI 中的 BOX 很薄，約 20 nm，因此其下方的摻雜基板區域可作為第二個閘極，即背閘極。在該處施加電壓會使臨界電壓偏移：順向基板偏壓會降低臨界電壓以提升速度，逆向基板偏壓則會提高臨界電壓以減少漏電。由於 BOX 將通道與井區隔離，偏壓範圍比塊材 CMOS 更寬，後者的順向偏壓受限於接面導通。設計者可在執行期間改變偏壓，在運作模式與待機模式之間權衡速度與漏電。

FD-SOI 與 FinFET 的比較

兩者都是全空乏元件。FinFET 以閘極從三個面包覆高聳的垂直鰭，在單位面積上提供更大的驅動電流，並更能微縮到最先進的製程節點。FD-SOI 維持平面結構，製程較簡單、光罩較少，並提供基板偏壓功能，而這是 FinFET 大致所缺乏的。取捨在於較昂貴的 SOI 晶圓（通常以 Smart Cut 接合與剝離製成），以及需要非常均勻的薄膜厚度。FD-SOI 適合低功耗 IoT、車用與 RF 晶片，而非頂級效能的處理器。

  2. B不再需要閘極電極
  3. C通道的雜質可以減少，能抑制臨界電壓的變異，並容易以基板偏壓調整臨界電壓
查看答案與解析

正確答案：C. 通道的雜質可以減少，能抑制臨界電壓的變異，並容易以基板偏壓調整臨界電壓

在 FD-SOI 中，厚度約 5～7 nm 的極薄矽層整體都會空乏，因此即使不在通道中摻入雜質也能抑制短通道效應，並減少隨機摻雜物波動所造成的變異。再者，若透過薄的埋入氧化膜（約 20 nm）從基板側施加電壓，就能動態改變臨界電壓，用於低電壓、低功耗的 IoT、車用與 RF 用途。

常見問題

FD-SOI 和 PD-SOI 有什麼不同？

在 FD-SOI 中，矽薄膜薄到完全空乏，因此不存在浮接的中性本體。PD-SOI 使用較厚的薄膜，會在通道下方留下中性區域，造成扭結效應等浮體效應。

FD-SOI 的基板偏壓是什麼？

就是對薄埋入氧化層下方的基板施加電壓，使其作用如同背閘極，降低臨界電壓以提升速度（順向偏壓），或提高臨界電壓以減少漏電（逆向偏壓）。

FD-SOI 比 FinFET 好嗎？

整體而言沒有哪一個比較好。FinFET 在先進製程節點提供更高的效能與密度，而 FD-SOI 提供較簡單的平面製程、寬廣的基板偏壓調整範圍，以及良好的 RF 與低功耗特性。
