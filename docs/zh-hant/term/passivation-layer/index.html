什麼是保護層(Passivation)

形成於晶片最上層，保護內部電路免受水氣、汙染與機械刮傷的薄膜。使用氮化矽或聚醯亞胺等。

日文名稱: パッシベーション膜

「保護層(Passivation)」出現在1領域的1道練習題中（製程材料（氣體與藥液）等）。

這個名詞所屬的領域: 配線製程

練習保護層(Passivation)的題目

作為EUV光罩反射多層膜所使用的材料組合，下列何者正確？

  1. A金與銀
  2. B銅與鋁
  3. C鉬與矽
查看答案與解析

正確答案：C. 鉬與矽

EUV光罩或曝光機的反射鏡，使用將鉬與矽的薄層以約7 nm的週期交替堆疊約40對的多層膜。其厚度經過設計，使在各界面稍微反射的光相位一致，因此能將13.5 nm的光反射約70%。EUV會被所有物質強烈吸收，所以需要的不是透鏡而是反射光學系統。表面以釕等保護層覆蓋。
