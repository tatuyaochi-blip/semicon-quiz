什麼是保護層(Passivation)

形成於晶片最上層，保護內部電路免受水氣、汙染與機械刮傷的薄膜。使用氮化矽或聚醯亞胺等。

日文名稱: パッシベーション膜

這個名詞所屬的領域: 配線製程

保護層的作用

保護層（passivation，也稱鈍化層）是覆蓋在晶片最上層導線上方的保護膜，也稱為最終保護層（final passivation）。它能防止外部進入的水氣，以及鈉等可動離子到達電路，抑制導線腐蝕與電晶體特性的變動。也能保護電路免受晶圓搬運與組裝時的刮傷和微粒影響。只有在以打線接合或凸塊與外部連接的電極焊墊部分，會以微影與蝕刻在膜上開孔（焊墊開窗），露出金屬。這也是承受高溫高濕可靠度試驗不可或缺的膜。

使用的材料與成膜

代表性的材料是不易讓水氣與離子通過、質地堅硬的氮化矽膜，厚度約數百nm到1 µm。由於下方的鋁或銅導線不能承受高溫，因此使用可在300–400 ℃低溫成膜的電漿CVD。電漿CVD的氮化膜含有大量氫，組成也偏離Si3N4，但作為保護膜具有足夠的性能。有時也會疊合氧化膜與氮化膜，或使用氮氧化膜，以調整膜應力與光的穿透。也常在上方再疊一層聚醯亞胺等樹脂膜，緩和來自封裝樹脂的應力。

與可靠度的關係

保護層若有裂痕或針孔，水氣會從該處進入，使鋁導線或焊墊腐蝕。因此會以在85 ℃、85%RH下施加電壓的高溫高濕偏壓試驗（THB），以及在更嚴苛條件下加速的HAST等確認耐濕性。膜應力過大時，會造成膜本身破裂，或下方導線的金屬移動而形成空洞的應力遷移。氮化膜中所含的氫有時也會影響電晶體特性，因此設計時也要考慮膜的組成與製程順序。

「鈍化（passivation）」的其他意思

在半導體領域中，passivation一詞更廣泛地泛指使表面不活潑、趨於穩定的各種處理。例如以氫終端矽與氧化膜界面殘留的未鍵結軌域（懸鍵），以減少界面態的合成氣體退火，也稱為鈍化。在結晶矽太陽能電池中，以氧化鋁等薄膜減少表面復合的表面鈍化，左右著轉換效率。在GaN HEMT中，以氮化膜抑制表面態的影響，可減少電流崩塌。乾式蝕刻時在側壁形成保護膜，也稱為鈍化。

常見問題

為什麼保護層多使用氮化矽膜？

因為它不易讓水氣與鈉等離子通過，質地堅硬、耐刮傷。而且使用電漿CVD可在300–400 ℃的低溫成膜，因此能在不損傷已形成之鋁或銅導線的情況下覆蓋最上層。

為什麼要再疊一層聚醯亞胺？

是為了緩和封裝樹脂在固化與溫度變化時收縮而施加在晶片表面的應力，防止氮化膜破裂與導線位移。也能保護晶片免受組裝時的刮傷。有時也會在覆晶凸塊下方作為應力緩衝層使用。

表面鈍化與保護層是同一件事嗎？

目的相似，但所指的對象不同。保護層是覆蓋晶片最上層、防止水氣、汙染與刮傷的保護膜。表面鈍化則是以氫或薄膜使半導體表面與界面的缺陷不活潑，以減少載子復合與界面態的處理，對太陽能電池與電晶體的界面很重要。

出現這個名詞的比較

  • LPCVD 與 PECVD 的差異：溫度、膜質、階梯覆蓋性、應力、用途比較從溫度、膜質、氫含量、階梯覆蓋性、薄膜應力、處理方式與產能、用途等面向，以表格比較低壓 CVD（LPCVD）與電漿輔助 CVD（PECVD）。
