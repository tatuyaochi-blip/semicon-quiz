什麼是波德圖

把系統的頻率響應，以頻率的對數為橫軸、增益（dB）與相位（度）為縱軸的2張圖表示者。轉移函數的乘積會成為增益（dB）與相位的和，因此可以把各元件的線相加來繪製。每增加1個極點，增益的斜率就改變 −20 dB/dec，相位最多落後90°。由迴路轉移函數的波德圖讀取增益邊限與相位邊限，以探討穩定性。

日文名稱: ボード線図

「波德圖」出現在1領域的4道練習題中（控制工程基礎等）。

這個名詞所屬的領域: 控制工程基礎

漸近線近似的畫法

一階元件 1/(1 + s/ωc)，在低於 ωc 的頻率以0 dB的水平線、在高於 ωc 的頻率以 −20 dB/dec 的直線近似。實際的增益在轉折點約為 −3 dB，相位在轉折點為 −45°，並在其10分之1到10倍的範圍內，由約0°變化到 −90°。零點則相反地加上 +20 dB/dec 的斜率與相位超前，積分 1/s 則對整體加上 −20 dB/dec 的斜率與 −90°。

讀取穩定邊限

在迴路轉移函數的增益穿越0 dB的頻率（增益交越頻率），相位距 −180° 還有多少度，就是相位邊限。在相位達到 −180° 的頻率（相位交越頻率），增益比0 dB低多少dB，就是增益邊限。增益交越頻率也是迴路快慢的參考，越高則閉迴路的響應越快。

與奈奎斯特圖的差異

把同樣的頻率響應在複數平面上畫成1條軌跡的，就是奈奎斯特圖（極座標圖）。波德圖的頻率刻度容易讀取，且能把元件相加來繪製，因此適合設計。奈奎斯特圖能由與點 −1 的位置關係直接判斷穩定性，迴路轉移函數本身不穩定時也能使用。

練習波德圖的題目

關於一階系統 G(s) = 1/(1 + sT) 的波德圖的特徵，正確的是下列何者？

  1. A在轉折角頻率 ω = 1/T 時增益約為 −3 dB、相位為 −45°，在遠高於此的頻率，增益以 −20 dB/dec 下降
  2. B在轉折角頻率 ω = 1/T 時增益為 −6 dB、相位為 −90°，在遠高於此的頻率，增益以 −40 dB/dec 的斜率下降
  3. C增益在任何頻率都是0 dB，只有相位與頻率成正比地落後
查看答案與解析

正確答案：A. 在轉折角頻率 ω = 1/T 時增益約為 −3 dB、相位為 −45°，在遠高於此的頻率，增益以 −20 dB/dec 下降

G(jω) = 1/(1 + jωT) 的大小為 1/√(1 + (ωT)²)，在 ω = 1/T 時為 1/√2（約 −3 dB），相位為 −45°。當 ω 遠大於 1/T 時，大小趨近 1/(ωT)，頻率每增加10倍，增益就下降20 dB（−20 dB/dec）。相位由低頻的0°變化到高頻的 −90°。在波德圖的漸近線近似中，轉折點以下以0 dB的水平線表示，以上以 −20 dB/dec 的直線表示。

積分元件 G(s) = 1/s 的波德圖為下列何者？

  1. A增益在任何頻率都是0 dB，相位在任何頻率都是 −90°
  2. B增益是在 ω = 1 rad/s 通過0 dB、斜率 +20 dB/dec 的直線，相位在任何頻率都是 +90°
  3. C增益是在 ω = 1 rad/s 通過0 dB、斜率 −20 dB/dec 的直線，相位在任何頻率都是 −90°
查看答案與解析

正確答案：C. 增益是在 ω = 1 rad/s 通過0 dB、斜率 −20 dB/dec 的直線，相位在任何頻率都是 −90°

G(jω) = 1/(jω) 的大小為 1/ω，因此在 ω = 1 rad/s 時為0 dB，頻率每增加10倍就下降20 dB。由於 1/j = −j，相位在任何頻率都是 −90°。頻率越低增益越大，因此含有積分的系統，能使對步階目標值的穩態誤差為0。斜率 +20 dB/dec、相位 +90° 的直線，屬於微分元件 s。

常見問題

波德圖的 −20 dB/dec 是什麼意思？

指頻率每增加10倍（1個十倍頻程），增益就下降20 dB、也就是振幅變為10分之1的斜率。每增加1個極點，這個斜率就再陡 −20 dB/dec。它與頻率每加倍就下降約6 dB的 −6 dB/oct 是相同的斜率。

波德圖要怎麼量測？

一邊改變正弦波的頻率一邊輸入，量測輸出的振幅與相位。在電源的控制迴路中，一般是在迴路中插入小電阻注入訊號，再以頻率響應分析儀量測迴路轉移函數。
