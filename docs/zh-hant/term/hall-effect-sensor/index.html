什麼是霍爾元件

利用霍爾效應偵測磁場的感測器。對通有電流的半導體施加磁場時，會在與電流及磁場垂直的方向產生電壓。用於馬達的旋轉偵測等。

日文名稱: ホール素子

「霍爾元件」出現在3領域的4道練習題中（MEMS與感測器, 化合物半導體, 功率半導體等）。

這個名詞所屬的領域: MEMS與感測器

練習霍爾元件的題目

下列何者是電子遷移率非常大、用於磁感測器（霍爾元件）等的化合物半導體？

  1. ASiC
  2. BInSb（銻化銦）
  3. CAlN
查看答案與解析

正確答案：B. InSb（銻化銦）

InSb在室溫下的電子遷移率約為77,000 cm²/(V·s)，是半導體中最大等級。霍爾元件的靈敏度與遷移率成正比，因此即使是微小的磁場也能得到大輸出，旭化成等公司量產，用於馬達旋轉位置的偵測與電子羅盤。由於能隙僅約0.17 eV，經冷卻後也用於偵測3～5 µm中紅外線的元件。

利用霍爾效應的感測器（霍爾元件）主要用來偵測下列何者？

  1. A溫度
  2. B磁場
  3. C濕度
查看答案與解析

正確答案：B. 磁場

當對有電流流過的半導體垂直施加磁場時，載子會受勞侖茲力而偏轉，在與電流及磁場兩者皆垂直的方向上產生電壓（霍爾電壓）。霍爾元件由此電壓偵測磁場，用於無刷馬達的旋轉位置偵測、非接觸式電流感測器、智慧型手機保護套的開闔偵測等。載子遷移率大的InSb與GaAs靈敏度高，也有整合在CMOS中的矽製元件。

解析中的「霍爾元件」

  • 霍爾元件的靈敏度與遷移率成正比，因此即使是微小的磁場也能得到大輸出，旭化成等公司量產，用於馬達旋轉位置的偵測與電子羅盤。

    利用霍爾效應的感測器（霍爾元件）主要用來偵測下列何者？

  • 在大電流下，也會使用無損耗的霍爾元件等磁式電流感測器。

    在電源電路等中，為了測量電流而串聯在電流路徑中的小電阻稱為什麼？

  • 電子羅盤以霍爾元件或磁阻元件（AMR、TMR等）在3軸上測量地磁（約25～65 µT）以求得方位。
