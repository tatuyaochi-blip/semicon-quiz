什麼是CMOS 影像感測器

每個像素都有放大電路，以 CMOS 製程製造的影像感測器。低功耗且可整合周邊電路，是智慧型手機相機等的主流。

日文名稱: CMOSイメージセンサー

「CMOS 影像感測器」出現在3領域的13道練習題中（影像感測器與光電元件, 磊晶成長, 離子佈植等）。

這個名詞所屬的領域: 影像感測器與光電元件

4T 像素中從光子到電壓的過程

每個像素的光二極體吸收光線，並依曝光量收集電子；可見光的量子效率通常約為 50–80%。在常見的四電晶體（4T）像素中，傳輸電晶體將這些電荷移到稱為浮動擴散區（FD）的小節點，源極隨耦器放大器將 FD 電壓緩衝輸出到行線，選擇電晶體負責連接該列，重置電晶體則清除 FD。轉換增益為 q/C_FD，1 fF 的節點約為每電子 160 µV。相鄰像素常共用 FD 與讀出電晶體以節省面積。

埋入式光二極體與 CDS

矽／氧化物表面的界面態會產生暗電流。埋入式光二極體（pinned photodiode）將 n 型收集區埋在高摻雜的 p+ 表面層下方，以電洞填滿這些界面態，抑制暗電流。埋入區也會完全空乏，使電荷轉移完整，避免殘影（image lag）。讀出採用相關雙取樣（CDS）：在重置後立即對 FD 取樣，電荷轉移後再取樣一次，兩者相減即可消除 kTC 重置雜訊與放大器偏移，將讀出雜訊降到數個電子以下。接著由行並列 ADC 在晶片上將訊號數位化。

前照式與背照式

在前照式（FSI）感測器中，光線必須穿過金屬配線層之間的空隙才能到達光二極體，造成光強度損失，入射角容許範圍也變小。背照式（BSI）感測器將晶圓薄化到數微米，從配線的另一側接收光線，使約 1 µm 的像素仍能保持高靈敏度，已成為智慧型手機相機的標準。堆疊式感測器更進一步，將像素晶圓與另一片承載 ADC 與影像處理的邏輯晶圓接合。像素區使用低缺陷的磊晶矽基板。

CMOS 與 CCD 感測器

電荷耦合元件（CCD）將電荷包在晶片上逐一移動到單一輸出放大器，需要多種時脈電壓，功耗也較大。CMOS 影像感測器在每個像素中放大，並透過行電路逐列讀出，因此功耗較低、讀出較快，還能將時序、ADC 與處理電路整合在同一晶粒上。逐列讀出會使快速運動的物體產生捲簾快門（rolling shutter）失真，全域快門像素則以像素內儲存來避免這個問題。雙轉換增益像素可切換額外的 FD 電容，同時涵蓋暗場景與亮場景。

正確答案：A. 光電二極體

在影像感測器的像素中，光電二極體吸收光後產生電子與電洞對，並在曝光期間累積與光量成比例的電子。CMOS影像感測器再利用像素內的電晶體將該電荷轉換為電壓後讀出。1個光子產生1個電子的比例（量子效率）在可見光約為50～80%。LED是將電轉換為光的元件，稽納二極體則用於定電壓。

關於背照式（BSI）CMOS影像感測器的主要優點，下列何者正確？

  1. A可以減少像素數
  2. B光不須穿過配線層即可到達光電二極體，因此容易提高感光度
  3. C不再需要彩色濾光片
查看答案與解析

正確答案：B. 光不須穿過配線層即可到達光電二極體，因此容易提高感光度

在前照式中，光必須穿過光電二極體上方多層配線的縫隙，因此會被配線遮擋或反射。背照式將晶圓研磨薄至數µm，從配線層的相反側入射光線，因此能有效率地吸收光，對斜向入射的光也更具優勢。2009年由Sony量產上市，由於即使在1 µm左右的微細像素中也能確保感光度，已成為智慧型手機相機的標準規格。

常見問題

CMOS 影像感測器和 CCD 有什麼差別？

CCD 將電荷在晶片上移動到一個共用的輸出放大器，而 CMOS 影像感測器在每個像素內將電荷轉換為電壓，再逐列讀出。CMOS 感測器功耗較低，且能整合 ADC 與邏輯電路，因此主導了手機與大多數相機市場。

影像感測器的 BSI 是什麼意思？

BSI 是 back-side illumination（背照式）的縮寫：將晶圓薄化，讓光從背面進入，不必穿過金屬配線層就能到達光二極體，提升小像素的靈敏度。

CMOS 影像感測器的相關雙取樣是什麼？

它在重置後讀取一次浮動擴散區，電荷轉移後再讀取一次，然後將兩者相減。重置（kTC）雜訊與放大器偏移同時出現在兩次取樣中而互相抵消，只留下真正的訊號。
