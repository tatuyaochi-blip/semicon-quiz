什麼是位元線

用來讀寫記憶單元資料的配線。在 DRAM 中，由感測放大器放大單元電荷所造成的位元線微小電位變化。

日文名稱: ビット線

「位元線」出現在4領域的18道練習題中（SRAM與快閃記憶體, DRAM, 邏輯電路等）。

這個名詞所屬的領域: DRAM

DRAM 讀取時位元線上發生了什麼

讀取前，位元線先預充電到 VDD/2。當字元線開啟單元的存取電晶體時，單元電容 Cs（約 10 fF）會與大得多的位元線電容 Cb（Cs 的數倍到約十倍）分享電荷。因此位元線只變化約 (VDD/2)·Cs/(Cs + Cb)，通常為數十到約一百 mV，儲存 1 時上升，儲存 0 時下降。感測放大器是一個交叉耦合的閂鎖電路，以正回授放大這個微小差異，同時將完整位準寫回，因為讀取已破壞了單元原本的電荷。

為什麼位元線長度有限制

訊號大小取決於轉移比 Cs/(Cs + Cb)，而連接在位元線上的每個單元都會增加電容。服務大量單元的長位元線會將訊號稀釋到感測放大器無法可靠分辨的程度，因此陣列會分割成多段，每條位元線只連接有限數量的單元，各段由各自的感測放大器服務。這是以面積換取訊號裕度。關閉一列後將位元線預充電回 VDD/2 需要時間，規格上稱為 tRP，會增加切換列時的延遲。

折疊式與開放式位元線

感測放大器比較兩條位元線，一條連接選定的單元，另一條作為參考。在折疊式架構中，這對位元線在同一陣列中並排走線，雜訊會同等地耦合到兩條線上而互相抵消；但每條字元線只能接觸成對位元線中一條上的單元，使單元面積為 8F²（F 為最小特徵尺寸）。在開放式架構中，成對的位元線位於不同陣列，對雜訊較敏感，但可實現 6F² 單元，是目前的主流配置。

SRAM 與快閃記憶體中的位元線

其他記憶體使用位元線的方式不同。SRAM 的每一行有一對預充電到 VDD 的互補位元線；選定的單元會讓其中一側稍微放電，當差異達到數十到約一百 mV 時，感測放大器啟動。寫入時將一條位元線拉低，在低電壓下則以負位元線輔助（negative bit-line assist）將其驅動到略低於地電位。NOR 快閃記憶體的每個單元並聯在位元線上以便快速隨機讀取，而 NAND 快閃記憶體只有串聯單元串列的末端連接到位元線。

練習位元線的題目

在DRAM的讀取中，位元線上出現的電壓變化非常小，其原因下列何者正確？

  1. A因為電源電壓非常高
  2. B因為位元線的電阻為0
  3. C因為單元電容的容量遠小於位元線的寄生電容
查看答案與解析

正確答案：C. 因為單元電容的容量遠小於位元線的寄生電容

讀取時，單元的電荷會與位元線分攤。單元電容Cs（約10 fF）小於位元線電容Cb（約其數倍～10倍），因此電壓變化約為 (VDD/2)·Cs/(Cs + Cb)，只有數十～一百數十mV。為了確保這個比值（傳輸比），會限制連接到1條位元線的單元數以減小Cb。感測放大器再藉由正回授將微小的差異一口氣放大，以判定0/1。

在DRAM的存取中，關閉原本開啟的列，並將位元線恢復到中間電位以準備啟動下一列的動作稱為什麼？

  1. A更新
  2. B預充電
  3. C抹除
查看答案與解析

正確答案：B. 預充電

在存取其他列之前，關閉目前的列並使位元線恢復到中間電位（VDD/2），稱為預充電。從中間電位開始，無論單元是0或1，位元線的電壓都會上下變動相同的幅度，讓感測放大器更容易判定。這段時間規定為tRP，包含在列切換的延遲之中。記憶體控制器會依存取的傾向，選擇讓頁保持開啟或關閉。

常見問題

字元線和位元線有什麼差別？

字元線沿著列走線，驅動存取電晶體的閘極，選擇要連接哪些單元。位元線沿著行走線，在選定的單元與感測放大器或寫入驅動器之間傳遞資料。

為什麼 DRAM 位元線要預充電到 VDD/2？

從中間值開始，位元線在儲存 1 時上升、儲存 0 時下降的幅度相近，感測放大器便能將它與維持在 VDD/2 的參考線比較。

為什麼 DRAM 的讀取是破壞性的？

將小的單元電容連接到大得多的位元線電容後，電荷會重新分配，單元便不再保持原本的電壓。感測放大器會將放大後的位準寫回單元，以恢復資料。
