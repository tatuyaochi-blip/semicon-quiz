什麼是位元線

用來讀寫記憶單元資料的配線。在 DRAM 中，由感測放大器放大單元電荷所造成的位元線微小電位變化。

日文名稱: ビット線

「位元線」出現在3領域的12道練習題中（SRAM與快閃記憶體, 邏輯電路, 新世代記憶體等）。

這個名詞所屬的領域: DRAM

練習位元線的題目

SRAM 讀取時，預先將位元線充電至電源電壓等的動作稱為什麼？

  1. A更新
  2. B抹除
  3. C預充電
查看答案與解析

正確答案：C. 預充電

SRAM 讀取時，首先將成對的位元線預充電到電源電壓，以字元線選擇單元後，保存 0 的那一側位元線會透過存取電晶體稍微放電。不必等到全擺幅，一旦形成數十～一百 mV 的差距，感測放大器就會放大，因此能高速讀取。讀取結束後再次預充電，為下一次存取做準備。

對 SRAM 單元寫入時，要將其中一條位元線拉低到 0 V 以反轉單元狀態。此時，對存取電晶體的要求，下列何者正確？

  1. A驅動能力要比單元內的上拉電晶體（pMOS）足夠強
  2. B驅動能力要比單元內任何電晶體都弱
  3. C必須一直保持關閉
查看答案與解析

正確答案：A. 驅動能力要比單元內的上拉電晶體（pMOS）足夠強

寫入時，必須透過存取電晶體把儲存節點拉到 0，克服想要維持 1 的上拉 pMOS，因此存取電晶體要設計得比 pMOS 足夠強（上拉比）。另一方面，為了讀取穩定性，又必須比下拉 nMOS 弱（單元比），這三者驅動能力的平衡是 SRAM 設計的核心。

    2輸入NOR閘的輸出何時為1？

  • 6T SRAM 單元由閂鎖電路（4 個電晶體，兩個反相器彼此的輸出接到對方的輸入）與 2 個控制位元線連接的存取電晶體所組成。

    下列關於一般 6 電晶體型 SRAM 單元的組成，何者正確？

  • NOR 型的各單元並聯至位元線，隨機讀取快，適合直接執行程式碼。

    與 NOR 型相比，NAND 型快閃記憶體的特徵，下列何者正確？

  • NOR 型的各單元並聯至位元線，隨機存取快，因此 CPU 可以直接從記憶體讀取並執行程式（XIP：Execute In Place）。
