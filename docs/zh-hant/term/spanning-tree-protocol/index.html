什麼是生成樹協定（STP）

Spanning Tree Protocol的縮寫。在以備援路徑連接交換器的網路中，於邏輯上封鎖部分連接埠，使路徑成為沒有迴圈的樹狀，以防止廣播風暴的協定（IEEE 802.1D）。使用中的路徑斷線時，會改用原本封鎖的連接埠切換路徑。加快切換速度的改良版為RSTP（快速生成樹協定）。

日文名稱: スパニングツリープロトコル(STP)

「生成樹協定（STP）」出現在1領域的5道練習題中（網路設計與維運等）。

這個名詞所屬的領域: 網路設計與維運

為什麼迴圈會成為問題

乙太網路訊框沒有像IP的TTL那樣計算經過次數並丟棄的機制。因此，把交換器連成迴圈時，廣播與目的地未知的訊框會在迴圈中不斷繞行，每經過交換器泛洪一次就增加一些（廣播風暴）。來自同一來源的訊框也會從不同的連接埠到達，使MAC位址表的學習變得混亂。另一方面，為了不因一條鏈路或一台交換器的故障而中斷通訊，路徑最好保持備援，因此使用在保留實體迴圈的同時，在邏輯上切斷迴圈的STP。

根橋接器與連接埠的角色

在STP中，交換器之間交換稱為BPDU的訊息，首先選出橋接器ID（優先順序與MAC位址）最小的交換器作為根橋接器。其他交換器把到根橋接器路徑成本最小的連接埠設為根連接埠。在每條鏈路上，靠近根橋接器一側的連接埠成為指定連接埠，既不是根連接埠也不是指定連接埠的連接埠會被封鎖。鏈路越快路徑成本越小，成本相同時以橋接器ID等的比較決定。

RSTP與多個VLAN

傳統的STP一面等待計時器一面把連接埠推進到轉送狀態，因此故障後的切換需要約30～50秒。RSTP（以IEEE 802.1w制定，之後併入802.1D）藉由相鄰交換器之間的提議與同意交換，以及事先決定的替代連接埠，多數情況下能在數秒以內完成切換。使用能為每組VLAN建立不同樹的MSTP（多重生成樹協定），可依VLAN分開使用的鏈路，讓備援鏈路也能發揮作用。

練習生成樹協定（STP）的題目

在以備援路徑連接交換器的網路中，生成樹協定（STP）所扮演的角色，下列何者正確？

  1. A在邏輯上停用部分連接埠，使路徑成為沒有迴圈的樹狀，防止廣播訊框不斷繞行
  2. B把訊框平均分配到交換器之間的多條鏈路上，以增加頻寬
  3. C在不同的VLAN之間轉送訊框，讓VLAN之間能夠通訊
查看答案與解析

正確答案：A. 在邏輯上停用部分連接埠，使路徑成為沒有迴圈的樹狀，防止廣播訊框不斷繞行

把交換器連成迴圈時，廣播與目的地未知的訊框會在迴圈中不斷繞行並增加（廣播風暴），使網路停擺。這是因為乙太網路訊框沒有像IP的TTL那樣計算經過次數並丟棄的機制。STP讓交換器之間交換稱為BPDU的訊息，封鎖部分連接埠，使路徑成為以根橋接器為根的樹狀。使用中的鏈路斷線時，會把原本封鎖的連接埠轉為轉送狀態，切換到其他路徑。

在STP中，已知3台交換器的橋接器ID如下：SW1的優先順序為32768、MAC位址為 00-00-5E-00-53-01；SW2的優先順序為61440、MAC位址為 00-00-5E-00-53-05；SW3的優先順序為4096、MAC位址為 00-00-5E-00-53-0A。被選為根橋接器的交換器是下列何者？

  1. ASW1
  2. BSW2
  3. CSW3
查看答案與解析

正確答案：C. SW3

在STP中，橋接器ID最小的交換器會成為根橋接器。橋接器ID是把優先順序放在上位、MAC位址放在下位的值，因此先比較優先順序，只有相同時才比較MAC位址。這裡優先順序最小的4096的SW3，不論MAC位址為何都會成為根橋接器。優先順序的預設值為32768，若不做任何設定，就會選出MAC位址最小的交換器，因此一般會把位於網路中心之交換器的優先順序設小。

常見問題

有了STP就不必擔心迴圈了嗎？

STP能防止在交換BPDU的交換器之間形成的迴圈，但無法防止經由停用STP的連接埠，或不處理BPDU的設備所形成的迴圈。一般會搭配在連接終端的連接埠收到BPDU時就停用該連接埠的功能，以及限制廣播量的功能一起使用。

被STP封鎖的鏈路不會浪費嗎？

在一棵樹中，被封鎖的鏈路處於待命狀態，平常不用於通訊。若也想使用其頻寬，可使用把多條鏈路綁成一條的鏈路聚合（STP視為一條鏈路）、依VLAN分開建立樹的MSTP，或在第3層進行路由的架構等。
