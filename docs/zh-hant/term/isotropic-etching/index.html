什麼是等向性蝕刻

縱向與橫向以相同速度進行的蝕刻。會蝕入遮罩下方（底切）。

日文名稱: 等方性エッチング

「等向性蝕刻」出現在1領域的4道練習題中（蝕刻等）。

這個名詞所屬的領域: 蝕刻

等向性與非等向性的差異

等向性蝕刻是縱向與橫向以相同速度進行的蝕刻。從遮罩開口開始蝕刻時，向下蝕除多少，就會向遮罩下方橫向蝕除多少（底切），剖面成為以開口為中心的圓弧形。例如將厚1 µm的膜蝕刻到底層時，從遮罩邊緣橫向也會蝕除約1 µm，過蝕刻的部分還會再擴大。相對地，非等向性蝕刻主要只沿垂直方向進行，可在不改變尺寸的情況下轉印遮罩圖形。非等向性的程度有時以A = 1 − (橫向速率 / 縱向速率)表示，等向性時A = 0。

進行等向性蝕刻的方法

代表性的是濕式蝕刻：藥液在所有接觸到的表面進行化學反應，因此非晶或多晶薄膜一般會被等向性地蝕刻。例如蝕刻氧化膜的氫氟酸系溶液、蝕刻氮化膜的熱磷酸，以及蝕刻矽的氫氟酸與硝酸混合液等。乾式蝕刻若不使用離子轟擊、只靠自由基反應，也會成為等向性。例如讓電漿產生處遠離晶圓的下游式（遠端電漿）蝕刻，以及不使用電漿、與矽自發反應的XeF2氣體。另外，以KOH等蝕刻單晶矽時，速率會因晶面而不同，因此不是等向性。

等向性蝕刻的用途

等向性蝕刻沒有離子轟擊，不易損傷底層，也容易提高材料之間的選擇比。因此廣泛用於膜的整面去除、光阻去除（灰化）、清洗等不講求尺寸精度的製程。也有積極利用底切的用途：在MEMS中，從側面蝕除結構下方的犧牲層，使結構懸空；在閘極全環繞（GAA）電晶體中，則用於從側面選擇性去除堆疊矽奈米片之間的SiGe層。

微細加工時的注意事項

等向性蝕刻會使尺寸擴大到與膜厚相當或更多，因此不適合加工比膜厚更細的圖案。有時會預估橫向蝕除量、把遮罩尺寸設計得小一些，但蝕除量會因膜質、溶液溫度與過蝕刻時間而變動。因此，微細圖案是以使用電漿的非等向性乾式蝕刻來形成，等向性蝕刻多半只在短時間內搭配使用，用於使轉角變圓、或橫向稍微內縮等有限的目的。

練習等向性蝕刻的題目

在MEMS的犧牲層去除等情況中，不使用電漿即可對矽進行等向性蝕刻的氣體是下列何者？

  1. AO2（氧氣）
  2. BN2（氮氣）
  3. CXeF2（二氟化氙）
查看答案與解析

正確答案：C. XeF2（二氟化氙）

XeF2是在室溫附近就會昇華的氣體，與矽自發性反應生成SiF4等，不需電漿即可對矽進行等向性蝕刻（2XeF2 + Si → 2Xe + SiF4）。它對氧化層、氮化層、光阻及多數金屬的選擇比高達1000以上，且因不使用液體而不易發生黏附（stiction），因此用於將MEMS結構從矽犧牲層中釋放出來。

常見問題

等向性蝕刻與非等向性蝕刻有什麼不同？

等向性蝕刻在縱向與橫向以相同速度蝕除，因此會鑽入遮罩下方。非等向性蝕刻主要沿垂直方向蝕除，因此能幾乎原樣轉印遮罩的形狀。一般而言，濕式蝕刻是等向性，使用離子的乾式蝕刻是非等向性。

乾式蝕刻也會是等向性嗎？

會。不使用離子轟擊、只靠自由基化學反應來蝕刻的方式，會以等向性進行。例如下游式（遠端電漿）蝕刻，以及以XeF2氣體蝕刻矽。

底切量大約是多少？

在完全等向性的蝕刻中，橫向蝕除量與縱向蝕除的深度大致相同。蝕穿厚1 µm的膜時，從遮罩邊緣橫向也會蝕除約1 µm，並隨過蝕刻時間進一步增加。
