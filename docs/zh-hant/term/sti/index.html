什麼是STI(淺溝槽隔離)

在矽上挖出淺溝槽並填入絕緣膜，再以CMP平坦化以隔離元件的方法。沒有LOCOS的鳥嘴效應，已成為微細LSI元件隔離的標準。

日文名稱: STI(シャロートレンチ分離)

「STI(淺溝槽隔離)」出現在5領域的14道練習題中（氧化與擴散, CMP與清洗, 薄膜沉積（CVD與PVD）等）。

這個名詞所屬的領域: 氧化與擴散

STI的製程流程

先沉積薄的墊氧化層與氮化矽層，再以微影與蝕刻在矽中開出深約200到300 nm的溝槽。接著成長一層薄的襯墊氧化層，通常採用熱氧化或ISSG氧化，以修復蝕刻損傷並使溝槽角落圓化。溝槽以CVD氧化膜填充，並經退火使其緻密化。化學機械研磨（CMP）去除多餘的氧化膜並停在氮化矽上，通常使用氧化物對氮化物選擇比達數十到超過100的氧化鈰研磨液。最後以約160 °C的熱磷酸去除氮化矽。

STI為何取代了LOCOS

在矽局部氧化（LOCOS）中，氮化矽遮蔽主動區，裸露的矽則被熱氧化，但氧化劑會從氮化矽邊緣下方橫向擴散，長出鳥嘴，兩側各可侵入約氧化膜厚度的一半。這會吃掉主動區面積、限制元件之間的間距，並留下表面段差。STI以蝕刻並填充的溝槽進行隔離，因此表面保持平坦，隔離寬度則由微影決定。它在0.25 µm世代左右取代了LOCOS，如今也用於隔離FinFET的鰭片。

溝槽填充與角落工程

一般CVD容易在溝槽開口處封口，在內部留下空洞。約從0.25 µm到65 nm世代，STI採用高密度電漿CVD填充，在沉積的同時濺擊角落；更窄、小至約10 nm的溝槽，則使用可流動式CVD或旋塗式介電材料，由底部向上填充後再轉化為氧化物。角落也很重要：尖銳的上緣角落會集中閘極電場，形成寄生的邊緣電晶體，而後續濕式清洗造成的氧化物凹陷（divot）會使情況更糟，因此角落圓化與凹陷控制都需要仔細調整。

應力與佈局效應

STI溝槽中的氧化物會對相鄰的矽施加應力，其大小取決於電晶體距離溝槽邊緣多遠，因此驅動電流可能隨主動區尺寸與佈局而變化。電路模型與設計規則會將此納入考量。溝槽蝕刻也必須避免在底部角落形成微溝槽（microtrenching），否則日後可能造成填充或電場集中的問題。在FinFET流程中，STI氧化物在CMP後會被回蝕，露出每個鰭片的上半部，回蝕深度即決定有效的鰭片高度。

練習STI(淺溝槽隔離)的題目

  1. A氧化鈰（ceria）
  2. B鐵粉
  3. C鑽石粗粒
查看答案與解析

正確答案：A. 氧化鈰（ceria）

氧化鈰（二氧化鈰）會與氧化膜產生化學鍵結而能有效率地研磨，另一方面，添加劑（胺基酸等界面活性劑）會吸附在氮化膜表面而抑制研磨，因此可使氧化膜相對於氮化膜的研磨選擇比達到數十至100以上。在以氮化膜作為停止層的STI之CMP中，用來兼顧平坦度與容易停止研磨。其特徵還有以較少的粒子即可快速研磨。

常見問題

STI和LOCOS有什麼不同？

LOCOS在未遮蔽區域成長厚的熱氧化膜，會有鳥嘴侵入與表面段差的問題。STI則蝕刻溝槽、以氧化膜填充並用CMP平坦化，得到平坦的表面與窄得多的隔離寬度。

為什麼稱為「淺」溝槽隔離？

它的溝槽只有數百奈米深，相較於部分雙載子、功率、影像感測器與舊世代DRAM技術所使用、深達數微米的深溝槽隔離（DTI）要淺得多。

為什麼STI的CMP要使用氧化鈰研磨液？

氧化鈰能有效去除氧化矽，搭配適當的添加劑時，幾乎不會研磨氮化矽。這種高氧化物對氮化物選擇比，讓研磨能可靠地停在氮化矽層上。
