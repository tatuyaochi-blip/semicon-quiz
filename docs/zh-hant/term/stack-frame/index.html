什麼是堆疊框

每次函式被呼叫時，在堆疊上配置的區域。放置返回位址、已儲存的暫存器、區域變數等，並在從函式返回時釋放。

日文名稱: スタックフレーム

「堆疊框」出現在3領域的5道練習題中（指令集與組合語言, 編譯器, 連結器與載入器與執行檔格式等）。

這個名詞所屬的領域: 指令集與組合語言

練習堆疊框的題目

不呼叫其他函式的函式（葉函式、leaf function），在很多情況下不需要將ra保存到堆疊。下列何者是其理由？

  1. A因為葉函式不使用ret指令
  2. B因為葉函式的返回位址是由CPU自動堆入堆疊
  3. C因為不呼叫其他函式，ra不會被覆寫，返回位址會原封不動地保留
查看答案與解析

正確答案：C. 因為不呼叫其他函式，ra不會被覆寫，返回位址會原封不動地保留

ra會在每次呼叫函式的jal時被覆寫，所以呼叫其他函式的函式，必須一開始就將自己的返回位址保存到堆疊。葉函式不使用jal，所以ra不會被破壞，不必保存就能ret。此外，如果也不使用被呼叫端保存的暫存器，甚至不需要建立堆疊框（stack frame）。x86的call指令一定會將返回位址堆入堆疊，這是與RISC-V的差異。

下列何者是在RISC-V函式開頭執行「addi sp, sp, -16」的目的？

  1. A讓堆疊往位址較小的方向延伸，確保16位元組的工作區域
  2. B釋放堆疊上的16位元組
  3. C將sp中的值減16，作為回傳值回傳
查看答案與解析

正確答案：A. 讓堆疊往位址較小的方向延伸，確保16位元組的工作區域

依包含RISC-V在內的許多ISA的慣例，堆疊是從位址較大的一方往較小的一方延伸。將sp減16，則從新的sp到原本的sp之間的16位元組，就成為這個函式的堆疊框，可以放置返回位址、已保存的暫存器及區域變數。在函式結束時以「addi sp, sp, 16」將sp還原，區域就會被釋放，回到與呼叫前相同的狀態。
