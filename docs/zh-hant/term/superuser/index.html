什麼是超級使用者

在 Linux 等系統中，基本上不受檔案權限限制、可以操作系統一切的管理者帳號。名稱為 root，用來區別使用者的編號（UID）為0。錯誤的操作可能破壞整個系統，被入侵時的損害也更大，因此一般平常以一般使用者作業，只用 sudo 以 root 權限執行需要的指令。以 root 作業時，shell 的提示字元常顯示為 # 而不是 $。

練習超級使用者的題目

目錄 d 的權限為 rwx--x--x（711），其中的檔案 f.txt 的權限為 rw-r--r--（644）。既不是擁有者也不是超級使用者的使用者執行「ls d」與「cat d/f.txt」時，結果是下列何者？

  1. Als d 可以顯示清單，但 cat d/f.txt 因目錄權限不足而不被允許
  2. Bls d 與 cat d/f.txt 都不被允許
  3. Cls d 不被允許，但 cat d/f.txt 可以顯示內容
查看答案與解析

正確答案：C. ls d 不被允許，但 cat d/f.txt 可以顯示內容

對目錄而言，r 是讀取其中名稱清單的權限，x 是進入其中、依名稱到達檔案的權限。其他人只有 x，所以 ls d 會出現「Permission denied」，但可以到達已知名稱的 d/f.txt。f.txt 本身對其他人也有 r，因此可以用 cat 顯示內容。反過來，只有 r 而沒有 x 的目錄，雖然看得到名稱清單，卻打不開其中的檔案。
