什麼是後閘極製程(取代式金屬閘極)

先以虛設閘極形成電晶體，在源極、汲極活化等高溫製程之後，移除虛設閘極並置換成High-k膜與金屬閘極的製法。

日文名稱: ゲートラスト(リプレースメントメタルゲート)

這個名詞所屬的領域: 先進電晶體（FinFET與GAA）

為什麼閘極最後才做

氧化鉿（HfO2）等high-k介電層搭配金屬閘極，取代了SiO2與多晶矽，以降低閘極漏電並消除多晶矽空乏。問題在於約1000 °C的源極／汲極活化退火，可能使金屬閘極堆疊的功函數偏移，並劣化high-k薄膜，使臨界電壓偏離目標。後閘極製程，即取代式金屬閘極（RMG）方法，在最高溫的步驟完成後才放入敏感的閘極堆疊，從而避開這個問題。

取代式金屬閘極的流程

首先圖案化多晶矽虛設閘極，用以對準間隔層與源極／汲極區；源極／汲極以離子佈植或磊晶成長形成，再以高溫活化。接著在整體上方沉積層間介電層，以化學機械研磨（CMP）平坦化，直到虛設閘極頂部露出。選擇性地蝕刻掉虛設多晶矽，在間隔層之間留下窄溝槽。將high-k介電層、為nMOS與pMOS分別選用的功函數金屬，以及低電阻填充金屬沉積到溝槽中，再以第二次CMP去除多餘部分。

先閘極與後閘極的比較

在先閘極（gate-first）流程中，high-k與金屬在一開始就沉積並圖案化，與傳統多晶矽閘極相同。步驟較少，但堆疊必須承受活化退火，因此難以維持理想的臨界電壓，pMOS尤其困難。後閘極需要多一道虛設閘極、額外一次CMP以及困難的溝槽填充，但可以自由選擇功函數金屬。Intel在45 nm世代採用了後閘極，之後它便成為主流方法。各種變化版本的差異在於high-k是在一開始沉積，還是在移除虛設閘極之後才沉積。

FinFET與GAA流程中的後閘極

取代式閘極自然地延續到FinFET中：移除虛設閘極後會在鰭片周圍騰出空間，讓high-k與金屬能包覆鰭片側面。在環繞式閘極奈米片流程中，同樣利用這個開口蝕刻掉矽奈米片之間的SiGe犧牲層，之後再以high-k與金屬填滿每片奈米片周圍的空隙。關鍵難點在於使虛設閘極露出的CMP，必須均勻停止以控制閘極高度，以及溝槽的無空洞填充，而溝槽寬度是由閘極長度決定的。

常見問題

什麼是取代式金屬閘極？

取代式金屬閘極是在暫時的多晶矽虛設閘極位置上製作的閘極。虛設閘極在高溫步驟中定義電晶體，之後被移除，再填入high-k介電層與金屬。

先閘極和後閘極有什麼差別？

先閘極在一開始就形成最終的high-k與金屬閘極，因此必須承受源極／汲極退火。後閘極則在最後才形成，以額外製程步驟為代價，保護其功函數不受高溫影響。

為什麼虛設閘極要用多晶矽？

多晶矽容易沉積並能精確圖案化，可承受高溫退火，而且在需要取代時，能相對於周圍的氧化物與氮化物間隔層被選擇性地蝕刻掉。
