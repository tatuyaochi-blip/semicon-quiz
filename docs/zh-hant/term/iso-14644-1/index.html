什麼是ISO 14644-1

依空氣中的微粒數量訂定無塵室潔淨度等級的國際標準。數字越小，潔淨度越高。

日文名稱: ISO 14644-1

「ISO 14644-1」出現在1領域的3道練習題中（無塵室與製造設備等）。

這個名詞所屬的領域: 無塵室與製造設備

等級如何定義

ISO 14644-1 根據每立方公尺空氣中所允許的最大微粒濃度，賦予 1 至 9 的等級數字 N。對於 0.1 µm 以上的微粒，Class N 每 m³ 最多允許 10^N 個，因此 N 每降低一級，允許的數量就減為十分之一。其他微粒尺寸 D（單位 µm）的限值依公式 10^N × (0.1/D)^2.08 計算，這就是較大微粒的允許數量迅速下降的原因。例如 Class 5 每 m³ 允許 0.1 µm 以上的微粒 100,000 個，但 0.5 µm 以上的微粒只允許 3,520 個。

與舊美國聯邦標準的對應

許多工程師仍在使用已廢止的美國聯邦標準 209E 的等級，它計算的是每立方英尺中 0.5 µm 以上的微粒。由於 1 立方英尺約為 28.3 公升，聯邦標準 Class 100（每 ft³ 100 個微粒）約相當於每 m³ 3,500 個，幾乎恰好等於 ISO Class 5。其餘等級也以相同方式對應：聯邦標準 Class 10 約為 ISO 4，Class 1,000 約為 ISO 6，Class 10,000 約為 ISO 7。

量測與使用狀態

等級判定使用光學微粒計數器，藉由微粒散射的光來偵測微粒，並在多個位置採樣空氣，採樣點數隨房間的樓地板面積增加。等級適用於所標明的使用狀態：建造完成（as-built，空房間且設施運轉中）、靜態（at-rest，設備已安裝但無人員）或動態（operational，正常作業進行中）。人員與移動的設備是主要的微粒來源，因此在靜態下獲得認證的房間，在動態下的表現可能較差。此標準只涵蓋空氣中的微粒濃度，而非質量；溫度、濕度、照明與化學污染則另外管控，不屬於等級的一部分。

半導體晶圓廠的潔淨度

尺寸與圖形相當的微粒就可能毀掉一顆晶粒，因此晶圓實際接觸的空氣必須極為潔淨，在先進晶圓廠中約為 ISO Class 1 至 3。現代晶圓廠並不是讓整棟建築都達到這種潔淨度，而是將晶圓保存在密封的載具與具有過濾下吹氣流的機台微環境中，周圍的區域則可維持在較寬鬆的等級。潔淨度的維持仰賴天花板上的 HEPA 或 ULPA（高效率與超低穿透率空氣）濾網、將微粒向下掃除的單向氣流、無塵衣穿著規定，以及略微正壓的室內壓力。

練習ISO 14644-1的題目

相當於舊美國聯邦規格等級100（每1立方英尺中0.5 µm以上的粒子在100個以下）的ISO 14644-1潔淨度等級是下列何者？

  1. AISO等級5
  2. BISO等級1
  3. CISO等級9
查看答案與解析

正確答案：A. ISO等級5

舊美國聯邦規格的等級100，是每1立方英尺（約28.3 L）中0.5 µm以上的粒子在100個以下，換算成每1 m³約為3500個。ISO 14644-1等級5中0.5 µm以上的上限為3520個/m³，所以大致相當。ISO等級每小一級，容許的粒子數就變為1/10，因此等級1非常嚴格，等級9則約等於一般室內。

下列關於ISO 14644-1潔淨度等級的說明，何者正確？

  1. A數字越大，潔淨度越高
  2. B不是由粒子的數量，而是由粒子的重量決定
  3. C等級數字N每小1，容許的粒子數大約變為十分之一
查看答案與解析

正確答案：C. 等級數字N每小1，容許的粒子數大約變為十分之一

在ISO 14644-1中，ISO等級為N時，每1 m³中0.1 µm以上粒子的上限規定為10的N次方個（其他粒徑的上限也由公式決定）。例如等級5為10萬個，等級4為1萬個，數字越小，潔淨度越高。它是由個數濃度決定，而不是重量。在先進的工廠中，晶圓所接觸的空間要求約為等級1～3。

常見問題

ISO Class 1 比 ISO Class 9 更乾淨嗎？

是的。等級數字越小越乾淨；Class 1 每立方公尺最多允許 10 個 0.1 µm 以上的微粒，而 Class 9 大致相當於一般室內空氣。

ISO Class 5 相當於什麼等級？

ISO Class 5 基本上等同於舊美國聯邦標準 Class 100，每立方公尺允許約 3,520 個 0.5 µm 以上的微粒，約相當於每立方英尺 100 個。

ISO Class 7 無塵室允許多少微粒？

每立方公尺約 352,000 個 0.5 µm 以上的微粒，相當於舊聯邦標準 Class 10,000。
