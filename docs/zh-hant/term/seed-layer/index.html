什麼是晶種層

以電鍍填入銅之前，先以濺鍍等方式薄薄形成的銅膜。成為讓電鍍電流通過的導電層。

日文名稱: シード層

「晶種層」出現在2領域的6道練習題中（配線製程, 薄膜沉積（CVD與PVD）等）。

這個名詞所屬的領域: 配線製程

練習晶種層的題目

濺鍍（sputtering）所進行的薄膜沉積，屬於下列何者？

  1. APVD（物理氣相沉積）
  2. BCVD（化學氣相沉積）
  3. C熱氧化
查看答案與解析

正確答案：A. PVD（物理氣相沉積）

濺鍍是將氬等電漿中的離子以數百V加速並撞擊靶材，使接受動量而被擊出的原子沉積在晶圓上的方法，不使用化學反應，屬於物理現象，因此歸類為PVD（物理氣相沉積）。用於金屬配線、阻障金屬（Ta、TiN等）、Cu的晶種層、電極等的成膜。CVD是利用原料氣體的化學反應，熱氧化則是矽本身的氧化。

將濺射出的原子游離，並以施加於晶圓的偏壓使其垂直被引入的濺鍍方式，其主要目的為下列何者？

  1. A改善深孔或深溝槽底部的薄膜覆蓋（底部覆蓋率）
  2. B降低成膜速率
  3. C改變膜的顏色
查看答案與解析

正確答案：A. 改善深孔或深溝槽底部的薄膜覆蓋（底部覆蓋率）

一般的濺鍍中，原子從各種方向飛來，因此深孔底部不易附著薄膜。離子化濺鍍（iPVD）使從靶材擊出的原子在高密度電漿中游離，再以施加於晶圓的偏壓使其垂直被引入，因此高深寬比孔洞的底部也容易附著薄膜。此外還可將底部的薄膜再濺射到側壁上，用於Cu配線的阻障層與晶種層的形成。

解析中的「晶種層」

  • 用於金屬配線、阻障金屬（Ta、TiN等）、Cu的晶種層、電極等的成膜。

    濺鍍（sputtering）所進行的薄膜沉積，屬於下列何者？

  • 此外還可將底部的薄膜再濺射到側壁上，用於Cu配線的阻障層與晶種層的形成。

    將濺射出的原子游離，並以施加於晶圓的偏壓使其垂直被引入的濺鍍方式，其主要目的為下列何者？

  • 雙鑲嵌法是以微影與蝕刻在絕緣膜上同時形成導孔的孔與導線的溝槽，再以阻障層、晶種層與Cu電鍍一併填入，最後以1次CMP完成。

    同時以Cu填滿導線溝槽與導孔，並以1次CMP完成的方法稱為什麼？

  • 在微細溝槽中，晶種層既要薄到不堵住開口，又要連續到底部不中斷，兩者難以兼顧，因此也會使用釕襯層等。

    在以電鍍填入Cu之前，以濺鍍形成的薄Cu膜，其作用下列何者正確？

  • 目前藉由電鍍液添加劑的由下而上填充，以及晶種層的改善，實現了無空洞的填充。
