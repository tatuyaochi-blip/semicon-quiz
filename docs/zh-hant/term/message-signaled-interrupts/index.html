什麼是MSI（訊息訊號中斷）

裝置藉由對指定位址進行寫入來通知中斷的方式。不需要專用的中斷線，且一個裝置可擁有許多中斷。

日文名稱: MSI(メッセージシグナル割り込み)

「MSI（訊息訊號中斷）」出現在1領域的1道練習題中（介面與匯流排規格等）。

這個名詞所屬的領域: 介面與匯流排規格

練習MSI（訊息訊號中斷）的題目

下列關於PCI Express所使用的MSI（訊息訊號中斷）之特徵，何者正確？

  1. A每次中斷時，裝置都打電話通知CPU
  2. B不使用中斷，由CPU持續檢查裝置的狀態
  3. C裝置透過對指定位址進行寫入來通知中斷，因此不需要專用的中斷線
查看答案與解析

正確答案：C. 裝置透過對指定位址進行寫入來通知中斷，因此不需要專用的中斷線

以前的裝置具有通知中斷用的專用線路，也有多個裝置共用一條線的情況。MSI是由裝置對OS所指定的位址寫入指定的資料，這會作為中斷傳達給CPU。由於沒有線路數量的限制，一個裝置可以擁有許多中斷，例如網路卡可以依每個接收佇列，將不同的中斷送到不同的核心。
