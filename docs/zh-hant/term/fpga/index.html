什麼是FPGA(現場可程式化閘陣列)

製造後，使用者可改寫邏輯電路組態的LSI。用於原型、少量生產的產品，以及ASIC的驗證等。

這個名詞所屬的領域: LSI設計流程與EDA

FPGA內部有什麼

現場可程式化閘陣列（FPGA）是由可程式化互連連接起來的可組態邏輯區塊陣列。每個邏輯區塊包含查找表（LUT），這是一種小型記憶體，其儲存的位元定義真值表，而輸入則驅動選擇輸出的多工器，因此k輸入LUT可實現任何k輸入的函數。正反器用來保存狀態。現代元件還包含硬體區塊，例如區塊RAM、DSP乘積累加單元、時脈管理器、高速序列收發器，有時還有處理器核心。在大多數FPGA中，組態資料存放在SRAM單元中，並在上電時從外部快閃記憶體載入。

從HDL到位元流

設計以Verilog或VHDL等硬體描述語言撰寫。合成會將邏輯對應到LUT、正反器與硬體區塊，並辨識標準的撰寫模式：與時脈同步寫入與讀取的暫存器陣列會被推論為區塊RAM，而非同步讀取則可能變成正反器或分散式記憶體。接著佈局與繞線分配資源與連線，靜態時序分析檢查時脈頻率，最後產生載入元件的位元流。各處理區塊之間常以AXI4-Stream等標準晶片內介面連接。

FPGA與ASIC的比較

FPGA不需要光罩，也沒有製造前置時間，且可在現場重新程式化，因此出貨後仍能修正錯誤或加入新功能。代價是額外開銷：可組態的繞線與LUT使相同功能比特殊應用積體電路（ASIC）更慢、更耗電、面積大得多，單價也更高。當產量大到足以分攤龐大的前期工程與光罩成本時，ASIC較有優勢；而原型、少量生產與需求變化快速的情況則是FPGA的天下。

會在哪裡遇到FPGA

FPGA出現在通訊設備、測試與量測儀器、影像與訊號處理管線、工業控制以及資料中心加速器中。它在大型SoC的驗證中也扮演核心角色：將設計對應到FPGA上（FPGA原型驗證），執行速度比軟體模擬快好幾個數量級，因此在晶片完成前就能執行真正的作業系統與應用程式。硬體模擬器（emulator）也有相同用途，且對內部訊號的可視性更好，但FPGA原型通常執行得更快。

正確答案：C. 製造後，使用者可以改寫邏輯電路的組態

FPGA是可在製造後以設定資料改寫具有小型真值表（LUT）的邏輯區塊及佈線連接方式的元件。由於不像ASIC那樣需要製造時間與光罩費用，因此用於試作、少量生產，以及需要功能更新的設備。另一方面，因為需要額外的改寫用電路，相同電路下ASIC在速度、耗電量、面積上都更有優勢。它並不是類比專用的元件。

  1. A模擬器硬體加速（emulation）或FPGA原型驗證
  2. BDRC
  3. CCMP
查看答案與解析

正確答案：A. 模擬器硬體加速（emulation）或FPGA原型驗證

以軟體進行邏輯模擬時，大規模電路運作1秒的內容可能要花上好幾天。將電路實作在模擬加速器或FPGA上運作，驗證速度可快上數個數量級，並能在實際運行OS與應用程式的同時，於晶片完成之前就進行軟體開發與驗證。兩者的差別在於：模擬加速器容易觀測內部訊號，FPGA原型則速度更快。

常見問題

FPGA是什麼的縮寫？

FPGA是現場可程式化閘陣列（field-programmable gate array）的縮寫：一種邏輯與連線可在製造後由使用者於現場組態的晶片，而不是在製造時就固定下來。

FPGA和微控制器有什麼差別？

微控制器擁有固定的處理器，依序執行軟體指令。FPGA沒有固定功能，而是組態硬體本身，因此每個時脈週期可平行執行許多運算，代價是設計流程較困難。

FPGA斷電後還會保留組態嗎？

大多數FPGA將組態存放在SRAM中，斷電後就會遺失，每次上電時再從外部快閃記憶體重新載入位元流。部分產品系列使用晶片內快閃記憶體或一次性反熔絲，屬於非揮發性。
