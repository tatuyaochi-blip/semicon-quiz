什麼是指令集架構(ISA)

處理器可執行的指令與暫存器等，從軟體角度看到的處理器規格。例如 x86、Arm、RISC-V 等。

日文名稱: 命令セットアーキテクチャ(ISA)

「指令集架構(ISA)」出現在4領域的12道練習題中（指令集與組合語言, CPU與架構, 效能評估與效能剖析等）。

這個名詞所屬的領域: CPU與架構

練習指令集架構(ISA)的題目

關於採用相同指令集架構（ISA）的兩顆CPU，下列何者正確？

  1. A因為以相同的電路架構製成，所以效能與耗電量都相同
  2. B即使內部電路架構不同，也能執行相同的機器語言程式
  3. C必須在同一座半導體工廠，使用相同的製程來製造
查看答案與解析

正確答案：B. 即使內部電路架構不同，也能執行相同的機器語言程式

ISA是規定指令的種類、指令的位元排列、暫存器數量等的軟體與硬體之間的約定。管線的級數、快取的大小、分支預測的方式等內部構造稱為微架構，與ISA分開決定。因此即使是相同的ISA，也有小型低功耗核心與大型高效能核心，效能與耗電量各不相同，但相同的機器語言程式都能執行。製造的工廠與製程也與ISA無關。

解析中的「指令集架構(ISA)」

  • ISA是規定指令的種類、指令的位元排列、暫存器數量等的軟體與硬體之間的約定。

    關於採用相同指令集架構（ISA）的兩顆CPU，下列何者正確？

  • ARM、x86、RISC-V 是指令集架構（ISA）的名稱，規定處理器所能理解的指令種類、暫存器、記憶體的處理方式等軟體與硬體之間的約定。

    ARM、x86、RISC-V 等名稱主要代表的是什麼？

  • RISC-V 是 2010 年起於加州大學柏克萊分校開始開發的開放式 ISA，規格公開，任何人都能免授權費地實作。

    關於 RISC-V 的特徵，下列何者正確？

  • 由於幾乎與指令一對一對應，ISA不同，組合語言也就不同。

    下列何者是組合語言與機器語言之間的關係？

  • 在指令長度固定的ISA中，將大的常數分開來產生是一般的做法。
