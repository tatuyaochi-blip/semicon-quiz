什麼是預設閘道

終端把送往其他網路之封包交給的路由器。終端以子網路遮罩判斷目的地是否在同一網路，若在外部就送給這台路由器。

日文名稱: デフォルトゲートウェイ

「預設閘道」出現在2領域的9道練習題中（網路設計與維運, 電腦網路基礎等）。

這個名詞所屬的領域: 電腦網路基礎

練習預設閘道的題目

某終端（192.168.1.10/24，預設閘道 192.168.1.1）要把封包送到另一個網路上的伺服器 203.0.113.80。ARP快取為空時，終端以ARP查詢哪一個對象的MAC位址？

  1. A預設閘道 192.168.1.1
  2. B伺服器 203.0.113.80
  3. C通往伺服器路徑上的所有路由器
查看答案與解析

正確答案：A. 預設閘道 192.168.1.1

終端首先根據自己的IP位址與子網路遮罩，判斷目的地是否在同一網路上。203.0.113.80 在 192.168.1.0/24 之外，因此封包交給預設閘道（路由器）。此時IP標頭的目的地仍是伺服器的 203.0.113.80，只有訊框的目的地MAC位址設為閘道的位址。因此以ARP查詢的是 192.168.1.1 的MAC位址。ARP廣播不會越過路由器，所以無法查到、也不需要知道另一個網路上伺服器的MAC位址。路徑上的每台路由器在轉送給下一台設備時，各自查詢對方的MAC位址。

以兩台路由器R1（192.168.1.2）與R2（192.168.1.3）組成VRRP，虛擬IP位址為 192.168.1.254。平常由R1作為主路由器（master）進行轉送。LAN終端的預設閘道應設定的位址，下列何者適當？

  1. A192.168.1.2（R1的位址）
  2. B192.168.1.3（R2的位址）
  3. C192.168.1.254（虛擬IP位址）
查看答案與解析

正確答案：C. 192.168.1.254（虛擬IP位址）

VRRP是以多台路由器組成一台虛擬路由器，讓它們共用虛擬IP位址與虛擬MAC位址的協定。平常由主路由器轉送送往虛擬位址的封包，主路由器停止時，備援路由器會成為主路由器並接手轉送。終端只要以虛擬IP位址作為預設閘道，不論哪一台路由器在運作都不必變更設定。這類讓預設閘道備援化的機制統稱為FHRP，除了VRRP之外還有HSRP等。

出現「預設閘道」的題目（9題）

  1. 某終端（192.168.1.10/24，預設閘道 192.168.1.1）要把封包送到另一個網路上的伺服器 203.0.113.80。ARP快取為空時，終端以ARP查詢哪一個對象的MAC位址？
  2. 以兩台路由器R1（192.168.1.2）與R2（192.168.1.3）組成VRRP，虛擬IP位址為 192.168.1.254。平常由R1作為主路由器（master）進行轉送。LAN終端的預設閘道應設定的位址，下列何者適當？
  3. 要從位於另一個網路的DHCP伺服器 10.0.0.5，為VLAN 20（192.168.20.0/24）的終端分配位址。為此，在作為VLAN 20預設閘道的L3交換器介面（192.168.20.1）上設定了DHCP中繼代理。下列關於中繼代理運作的敘述，何者正確？
  4. 以DHCP讓終端取得IP位址時，訊息的順序下列何者正確？
  5. 想以一條鏈路把路由器接到具有VLAN 10（192.168.10.0/24）與VLAN 20（192.168.20.0/24）的L2交換器，讓兩個VLAN之間能夠通訊。這種架構的設定，下列何者適當？
  6. 在執行NAPT的路由器（外側位址為 198.51.100.7）上，設定了「把到達外側TCP 8080號連接埠的通訊，轉送到內側Web伺服器 192.168.1.20 的80號連接埠」的連接埠轉送（只轉譯目的地的靜態設定）。網際網路上的終端 203.0.113.9 以來源連接埠51000連線到 198.51.100.7 的8080號連接埠時，Web伺服器收到之封包的目的地與來源組合，下列何者正確？
  7. 在IPv6中，只在同一鏈路內使用、且必定會自動設定在每個使用IPv6之介面上的鏈路本地位址，其範圍是下列何者？
  8. 在IPv6的SLAAC（無狀態位址自動設定）中，終端產生全球單播位址的方法，下列何者正確？
  9. 從某台PC指定IP位址的ping可以到達網際網路上的伺服器，但在瀏覽器指定網域名稱時，會顯示「找不到伺服器」而無法開啟網頁。首先應確認的設定，下列何者最適當？

出現這個名詞的比較

  • 集線器、交換器、路由器的差異：運作的層、使用的位址、轉送方式與網域劃分比較從運作的層、使用的位址、處理的資料單位、轉送方式、碰撞網域、廣播網域、連接不同網路的能力與配置位置等面向，以表格比較集線器（中繼器集線器）、交換器（L2交換器）與路由器。
  • DHCPv6與SLAAC的差異：IPv6位址的決定方式、狀態管理、閘道與DNS及使用時機比較從決定位址者、狀態的管理、所需條件、使用的訊息、預設閘道、DNS伺服器、介面識別碼、前綴長度與委派、掌握位址的難易度等面向，以表格比較自動設定IPv6位址的DHCPv6與SLAAC（無狀態位址自動設定）。
