什麼是6T SRAM 單元

由交叉耦合的兩個反相器(4 個電晶體)與 2 個存取用電晶體所構成的 SRAM 記憶單元。

日文名稱: 6T SRAMセル

「6T SRAM 單元」出現在1領域的2道練習題中（SRAM與快閃記憶體等）。

這個名詞所屬的領域: SRAM與快閃記憶體

六個電晶體如何保存一個位元

6T SRAM 單元是由兩個交叉耦合的 CMOS 反相器構成的閂鎖電路，每個反相器由 PMOS 上拉與 NMOS 下拉電晶體組成，共四個電晶體。每個反相器的輸出驅動另一個的輸入，這種正回授使一個儲存節點保持高電位、另一個保持低電位，只要有供電就能無限期保持，不需要更新。兩個由字元線控制閘極的 NMOS 存取電晶體，將兩個儲存節點連接到一對互補位元線 BL 與 BL-bar。單元雖然是靜態的，但並非不耗電：其電晶體仍會持續漏電。

讀取與寫入的尺寸設計

讀取時，兩條位元線都預充電到高電位，然後拉高字元線；儲存 0 的節點會將其位元線稍微拉低，由感測放大器偵測這個小差異。經由存取電晶體流入的電流會抬高該 0 節點，因此下拉電晶體必須比存取電晶體強，即單元比（cell ratio）約 1.5 到 2.5，否則單元可能翻轉。寫入時，一條位元線被驅動為低，存取電晶體必須壓過將節點維持在高電位的上拉 PMOS，因此上拉電晶體在三者中最弱。

6T SRAM 與 DRAM 單元的比較

6T SRAM 單元約佔 120 到 150 F²（F 為最小特徵尺寸），而一電晶體一電容的 DRAM 單元約為 6 F²，因此 SRAM 的密度約低 20 倍，每位元成本也高得多。作為回報，它不需要電容或特殊製程，可與邏輯電晶體一起製作，存取時間約 1 ns，而 DRAM 則為數十 ns。這就是晶片內快取與暫存器檔案使用 SRAM、主記憶體使用 DRAM 的原因。

低電壓限制與 8T 單元

由於讀取穩定性與可寫入性對電晶體尺寸的要求相反，臨界電壓的隨機變異會在電源電壓降低時使部分單元失效，這決定了大型陣列的最低工作電壓。8T 單元增加了一個雙電晶體讀取埠，其位元線只透過電晶體閘極感測儲存節點，因此讀取不會干擾儲存的值。讀取與寫入路徑便可分別最佳化，並能同時運作，以較大的單元面積為代價改善低電壓運作。

練習6T SRAM 單元的題目

6T SRAM 單元為了讓單元內容在讀取時不被反轉（防止讀取破壞），所需的設計下列何者正確？

  1. A使存取電晶體比下拉電晶體更強
  2. B移除上拉電晶體
  3. C使下拉（驅動）電晶體比存取電晶體更強
查看答案與解析

正確答案：C. 使下拉（驅動）電晶體比存取電晶體更強

讀取時，電流會從預充電的位元線透過存取電晶體流入保存 0 的節點，使電壓稍微上升。若下拉電晶體比存取電晶體足夠強（單元比 β = 下拉／存取 為 1.5～2.5 左右），這個上升量就能被抑制在小於對側反相器的臨界值，資料不會反轉。使用 8T 單元或讀取輔助也能對策。

常見問題

為什麼 SRAM 單元有六個電晶體？

四個電晶體構成兩個交叉耦合的反相器，以正回授保存位元；兩個存取電晶體在字元線被選取時將單元連接到位元線。這樣就能只用邏輯電晶體做出穩定且不需更新的儲存元件。

SRAM 需要像 DRAM 一樣更新嗎？

不需要。只要有供電，交叉耦合的反相器就會主動恢復儲存的位準，因此 SRAM 不需要更新，但斷電後資料會遺失。

6T SRAM 的單元比（cell ratio）是什麼？

單元比是下拉電晶體相對於存取電晶體的強度，通常約 1.5 到 2.5。比值夠高才能讓 0 節點在讀取時不會升過切換臨界點，防止讀取干擾翻轉（read upset）。
