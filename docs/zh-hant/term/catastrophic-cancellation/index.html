什麼是有效位數損失(Catastrophic cancellation)

將幾乎相等的兩個數相減時，高位數互相抵消，有效位數大幅減少的現象。原本數中所含捨入誤差的比例相對變大。可藉由變換算式來避免。

日文名稱: 桁落ち

「有效位數損失(Catastrophic cancellation)」出現在1領域的2道練習題中（電腦算術等）。

這個名詞所屬的領域: 電腦算術

罪魁禍首不是減法本身

出人意料的是，兩個相近浮點數的相減通常是精確的：若 x 與 y 彼此相差在 2 倍以內，x 減 y 可被精確表示，硬體不經捨入即可傳回它（此結果稱為 Sterbenz 引理）。損害來自運算元中早已存在的誤差，也就是先前的捨入、量測或轉換所造成的誤差。當前面的位數互相抵消時，這些小的絕對誤差仍然存在，而結果本身卻變得很小，因此相對誤差被放大。有效位數損失是把舊誤差暴露出來，而不是產生新的誤差。

放大的程度

若 a 與 b 各帶有約 e 的相對誤差，則 a 減 b 的誤差約為 e 乘以 (|a| + |b|) / |a - b|。因此，前 6 位有效數字相同的兩數相減，相對誤差會被放大約一百萬倍，用掉 double 約 16 位十進位精度中的 6 位。若運算元所有位數都相同，結果可能是純粹的雜訊或恰好為零。這個比值就是減法的條件數，它說明了為何此效應取決於輸入有多接近，而不只取決於格式。

標準的改寫方式

解法是用代數避免相近值相減。有理化可把 √(x + 1) − √x 變成 1 / (√(x + 1) + √x)。在二次方程式公式中，當 b² 遠大於 4ac 時，其中一個根會發生有效位數損失；先計算另一個根，再由根的乘積求出有問題的那個根（c / a 除以第一個根），即可避免。對於小的 x，1 − cos x 可改為 2 sin²(x / 2)；數學函式庫也提供 expm1(x) 與 log1p(x)，在接近零時精確計算 exp(x) − 1 與 log(1 + x)。

有效位數損失與吸收的比較

有效位數損失與吸收（absorption）是浮點數遺失資訊的兩種典型方式，而且很容易混淆。有效位數損失發生在幾乎相等的數相減時，結果中剩下的有意義位數太少。吸收則發生在大小相差懸殊的數相加時：較小運算元的低位數從有效數的尾端掉出去，例如在雙精度下 1.0e16 + 1 的結果恰好是 1.0e16。改用更寬的格式能延後這兩個問題，但無法消除它們；重新設計計算方式才能消除。

練習有效位數損失(Catastrophic cancellation)的題目

當 x 非常大時，以浮點數計算 √(x + 1) − √x 會發生位數消去。為了精確求得結果，下列何者是正確的改寫方式？

  1. A改為 1 ÷ (√(x + 1) + √x) 來計算
  2. B改為 √(x + 1 − x) 來計算
  3. C先將 √(x + 1) 與 √x 分別改為雙精度，再以相同的算式相減
查看答案與解析

正確答案：A. 改為 1 ÷ (√(x + 1) + √x) 來計算

√(x + 1) 與 √x 幾乎相等，因此直接相減時高位的位數會互相抵消。若將分子與分母同乘以 √(x + 1) + √x，便成為 (x + 1 − x) ÷ (√(x + 1) + √x) = 1 ÷ (√(x + 1) + √x)，不再有相近數之間的減法，因此能精確計算。√(x + 1 − x) 會變成1，作為算式是錯誤的。改用雙精度雖然會有所改善，但若x更大，仍會發生相同的問題，因此並非根本的對策。

常見問題

幾乎相等的浮點數相減，為什麼會損失精度？

相同的前導位數互相抵消，剩下的小結果主要由低位數構成，而這些位數正是早已被捨入誤差污染的部分。絕對誤差不變而數值變小，因此相對誤差急劇增加。

把 float 換成 double 能解決有效位數損失嗎？

它有幫助，因為有更多位數可以損失，但當運算元更加接近時，同樣的有效位數損失又會出現。改寫算式以避免相減才是真正的解法。

如何避免二次方程式公式中的有效位數損失？

先計算 -b 與平方根項同號的那個根，使兩者相加而非相消，再利用兩根之積等於 c / a 的關係求出另一個根。
