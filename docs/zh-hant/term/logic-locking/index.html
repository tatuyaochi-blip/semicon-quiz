什麼是邏輯鎖定

在電路中加入功能會隨金鑰值而改變的閘，使晶片在製造後寫入正確金鑰之前無法正確運作的技術。目的是防止承接製造的工廠盜用設計，或私下販售多做的晶片。已有研究顯示，取得可運作晶片的攻擊者能比對輸入與輸出，以SAT求解器縮小金鑰範圍，能抵抗此類攻擊之方式的研究仍在持續。

練習邏輯鎖定的題目

保護半導體設計的技術，與其主要假設之不可信對象的組合，正確的是下列何者？

  1. A分割製造對應購買完成晶片的使用者，IC偽裝對應承接製造的工廠，邏輯鎖定對應設計工具的開發商
  2. B分割製造對應承接製造的工廠，IC偽裝對應從晶片影像讀取電路的人，邏輯鎖定對應工廠或取得沒有金鑰之晶片的人
  3. C分割製造、IC偽裝、邏輯鎖定都只以侵入設備的軟體病毒為對象
查看答案與解析

正確答案：B. 分割製造對應承接製造的工廠，IC偽裝對應從晶片影像讀取電路的人，邏輯鎖定對應工廠或取得沒有金鑰之晶片的人

分割製造是由外部的最先進工廠製作電晶體與下層配線層（FEOL），再由可信的工廠製作上層配線層，因此外部工廠無法得知電路連接的全貌。IC偽裝使用外觀相同但功能不同的單元，或只是看起來有連接的假接點，提高從削層拍攝之晶片影像讀取電路的逆向工程難度，但對持有設計資料的工廠無效。邏輯鎖定在電路中加入功能隨金鑰改變的閘，使電路在製造後寫入正確金鑰之前無法正確運作，目的是防止工廠盜用設計或多做晶片。自2015年有研究顯示，取得可運作晶片的攻擊者能比對輸入與輸出、以SAT求解器縮小金鑰範圍以來，能抵抗此類攻擊之方式的研究仍在持續。

解析中的「邏輯鎖定」

  • 邏輯鎖定在電路中加入功能隨金鑰改變的閘，使電路在製造後寫入正確金鑰之前無法正確運作，目的是防止工廠盜用設計或多做晶片。
