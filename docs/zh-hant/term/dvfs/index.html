什麼是DVFS(動態電壓頻率調整)

依處理負載動態改變工作頻率與電源電壓的技術。由於動態消耗功率與電壓的平方成正比，在輕負載時降低電壓可大幅省電。

日文名稱: DVFS(動的電圧・周波数制御)

「DVFS(動態電壓頻率調整)」出現在2領域的6道練習題中（電源管理（軟體控制）, CPU與架構等）。

這個名詞所屬的領域: CPU與架構

練習DVFS(動態電壓頻率調整)的題目

在DVFS中，假設電源電壓可以隨頻率成比例地降低。當頻率減半時，動態功率與完成固定運算量所消耗的動態能量大約會如何變化？

  1. A功率變為八分之一，能量變為四分之一
  2. B功率與能量都減半
  3. C功率變為四分之一，能量不變
查看答案與解析

正確答案：A. 功率變為八分之一，能量變為四分之一

功率與V²f成正比，所以V與f都減半時為(1/2)²×1/2=1/8。運算所需的時間變為2倍，因此能量為1/8×2=1/4。每次切換的能量與CV²成正比，所以認為能量由電壓的平方決定，也會得到相同的結果。實際上電壓能降低的範圍有限，而且還有靜態功率，因此不會減少得這麼理想。

解析中的「DVFS(動態電壓頻率調整)」

  • 即便如此，若同時降低頻率與電壓，功耗會以接近三次方的幅度下降，因此以 DVFS 在處理較輕時降低電壓與頻率，是最有效的省電手段。

    在 CMOS 電路中，若其他條件不變，只將電源電壓減半，動態功耗會如何變化？

  • DVFS 是在處理較輕時降低頻率與電源電壓、較重時則提高的技術。

    為了降低 CPU 的功耗，依負載動態改變工作頻率與電源電壓的技術是下列何者？

  • OS或CPU內部的電源管理電路會配合負載來切換P-state（DVFS）。

    關於CPU的P-state（P狀態）的說明，下列何者正確？

  • PMIC是將多個切換式穩壓器與LDO整合在一起的零件，能從電池電壓有效率地產生所需的電壓，並依SoC的指示，進行DVFS所需的電壓變更、各區塊電源的開啟與關閉，以及依照既定順序的電源供應。

    關於智慧型手機等所使用的PMIC（電源管理IC）的作用，下列何者正確？

  • 不過降低電壓會使電路變慢，所以必須在能維持所需速度的範圍內降低，而依負載進行這件事的就是DVFS。

    只將電源電壓降低10%時（其他條件相同），動態功耗大約會減少幾%？

出現「DVFS(動態電壓頻率調整)」的題目（6題）

  1. 在DVFS中，假設電源電壓可以隨頻率成比例地降低。當頻率減半時，動態功率與完成固定運算量所消耗的動態能量大約會如何變化？
  2. 在 CMOS 電路中，若其他條件不變，只將電源電壓減半，動態功耗會如何變化？
  3. 為了降低 CPU 的功耗，依負載動態改變工作頻率與電源電壓的技術是下列何者？
  4. 關於CPU的P-state（P狀態）的說明，下列何者正確？
  5. 關於智慧型手機等所使用的PMIC（電源管理IC）的作用，下列何者正確？
  6. 只將電源電壓降低10%時（其他條件相同），動態功耗大約會減少幾%？
