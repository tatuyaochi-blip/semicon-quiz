什麼是DVFS(動態電壓頻率調整)

依處理負載動態改變工作頻率與電源電壓的技術。由於動態消耗功率與電壓的平方成正比，在輕負載時降低電壓可大幅省電。

日文名稱: DVFS(動的電圧・周波数制御)

「DVFS(動態電壓頻率調整)」出現在2領域的6道練習題中（電源管理（軟體控制）, CPU與架構等）。

這個名詞所屬的領域: CPU與架構

DVFS 如何運作

CMOS 晶片的動態功耗為 P = αCV²f，其中 α 為切換活動率，C 為被切換的電容，V 為電源電壓，f 為時脈頻率。電路只有在電源電壓夠高時才能在特定頻率下滿足時序，因此 DVFS 使用一張有效電壓–頻率組合的表格，稱為工作點或 P-state。作業系統或晶片上電源管理韌體中的調節器（governor）會監看負載與溫度並選擇工作點。加速時先提高電壓、再提高時脈；減速時先降低時脈、電壓隨後再降，讓邏輯永遠不會以超過其電源所能支撐的速度運作。

為什麼電壓是最大的槓桿

只降低頻率雖能使功耗線性下降，但每次運算的能量（與 CV² 成正比）不變，因為同樣的工作只是花更長時間完成。真正節省能量的是降低電壓。若電壓能與頻率成比例調整，兩者都減半時，動態功耗會降到八分之一，完成固定工作的能量則降到四分之一。即使只是 10% 的小幅降壓，也能減少約 19% 的動態功耗。實際上電壓無法永遠成比例下降，因此實際節省會小於這個理想的三次方圖像。

限制與 race-to-idle

有兩種效應限制了 DVFS。第一，存在最低可運作電壓：當電源接近電晶體的臨界電壓時，速度會急遽下降，SRAM 單元也變得不可靠，因此電壓範圍的下限遠高於零。第二，只要電路通電，漏電功率就會持續流動，因此以低速運作較長時間會累積漏電能量。當漏電顯著時，race to idle 可能更好：以高工作點完成工作，然後進入深度睡眠狀態（C-state），或對該區塊完全進行電源閘控。

會在哪裡遇到

DVFS 基本上在每顆智慧型手機 SoC、筆電 CPU、伺服器處理器與 GPU 中都在運作。每個電壓域（可能是單一核心或一組核心叢集）都需要自己的可調電源，通常由電源管理 IC（PMIC）或晶片上穩壓器提供，並依 SoC 的命令改變輸出。同樣的機制也實現了熱節流（降低工作點以將接面溫度維持在限制內）以及短暫的加速模式（在熱與電流餘裕允許時提高工作點）。

練習DVFS(動態電壓頻率調整)的題目

在DVFS中，假設電源電壓可以隨頻率成比例地降低。當頻率減半時，動態功率與完成固定運算量所消耗的動態能量大約會如何變化？

  1. A功率變為八分之一，能量變為四分之一
  2. B功率與能量都減半
  3. C功率變為四分之一，能量不變
查看答案與解析

正確答案：A. 功率變為八分之一，能量變為四分之一

功率與V²f成正比，所以V與f都減半時為(1/2)²×1/2=1/8。運算所需的時間變為2倍，因此能量為1/8×2=1/4。每次切換的能量與CV²成正比，所以認為能量由電壓的平方決定，也會得到相同的結果。實際上電壓能降低的範圍有限，而且還有靜態功率，因此不會減少得這麼理想。

常見問題

只降低 CPU 頻率能省電嗎？

它能降低功率，但不能降低每項工作的動態能量，因為每次運算仍需約 CV²，工作只是花更長時間完成；漏電能量甚至可能增加。節能效果來自較低頻率所允許的降壓。

P-state 和 C-state 有什麼差別？

P-state 是處理器執行時使用的電壓–頻率工作點，也就是 DVFS 所選擇的對象。C-state 則是沒有工作時使用、深度逐漸增加的閒置狀態，從停止時脈到切斷電源。

DVFS 和時脈閘控有什麼差別？

時脈閘控停止閒置邏輯的時脈，使其停止切換，但電源電壓與漏電仍然存在。DVFS 則是改變仍在工作的整個電壓域的電壓與頻率。

解析中的「DVFS(動態電壓頻率調整)」

  • 即便如此，若同時降低頻率與電壓，功耗會以接近三次方的幅度下降，因此以 DVFS 在處理較輕時降低電壓與頻率，是最有效的省電手段。

    為了降低 CPU 的功耗，依負載動態改變工作頻率與電源電壓的技術是下列何者？

  • OS或CPU內部的電源管理電路會配合負載來切換P-state（DVFS）。

    關於CPU的P-state（P狀態）的說明，下列何者正確？

  • PMIC是將多個切換式穩壓器與LDO整合在一起的零件，能從電池電壓有效率地產生所需的電壓，並依SoC的指示，進行DVFS所需的電壓變更、各區塊電源的開啟與關閉，以及依照既定順序的電源供應。

    關於智慧型手機等所使用的PMIC（電源管理IC）的作用，下列何者正確？

  • 不過降低電壓會使電路變慢，所以必須在能維持所需速度的範圍內降低，而依負載進行這件事的就是DVFS。
