什麼是FIPS 140-3

美國NIST制定的密碼模組安全要求與認證基準。以國際標準ISO/IEC 19790為基礎，作為FIPS 140-2的後繼標準，於2020年開始受理認證。評估密碼演算法的實作、金鑰管理、自我測試與實體安全性等，分為安全等級1至4。常被用作採購硬體安全模組（HSM）與安全晶片的條件。

日文名稱: FIPS 140-3

「FIPS 140-3」出現在2領域的2道練習題中（硬體安全的進階主題與趨勢, 密碼學基礎與應用等）。

這個名詞所屬的領域: 硬體安全的進階主題與趨勢

四個安全等級

等級1只要求正確實作核准的密碼演算法，在實體方面大致只要求使用一般產品品質的元件。等級2加上打開後會留下痕跡的封條或塗層等竄改證據，以及以角色為基礎的操作者驗證。等級3要求讓模組難以被打開或探測、偵測到時清除金鑰等重要值，並要求以個人身分為基礎的驗證。等級4更進一步，要求偵測從外殼任何方向的入侵並立即清除這些值，以及在電壓或溫度超出範圍時的保護。

評估什麼、如何評估

評估的對象是密碼模組，只要定義了邊界，IC晶片、電路板、整台設備或軟體程式庫都可以是對象。經認可的測試實驗室會測試演算法的實作是否產生正確結果，並檢查金鑰的產生、保管與清除方式、開機等時機的自我測試、實體防護等，再由NIST與加拿大機構共同運作的制度（CMVP）核發認證。FIPS 140-3在較高的等級中，也處理透過功耗或時間洩漏資訊之非侵入式攻擊的對策。

與其他認證的差異

FIPS 140-3是確認密碼模組是否符合既定要求的基準，由於美國與加拿大政府機關的採購要求它，民間產品也廣泛採用。共同準則（Common Criteria）則是更一般性的評估架構，由各產品以安全標的（Security Target）定義要保護的功能，並以EAL表示評估的嚴謹程度。也有像IC卡晶片這樣同時取得兩種認證的產品。

練習FIPS 140-3的題目

關於密碼模組認證基準FIPS 140-3的安全等級1至4，實體安全性要求的說明，正確的是下列何者？

  1. A等級1的要求最嚴格，數字越大要求越寬鬆，等級4是給只由軟體構成之密碼模組的等級
  2. B等級由可使用的金鑰長度決定，等級3表示使用AES-192、等級4表示使用AES-256，不包含實體安全性的要求
  3. C等級2要求打開後留下痕跡，等級3要求難以打開並在偵測到時清除金鑰，等級4更要求在整個外殼上偵測入侵，以及對電壓、溫度異常的對策
查看答案與解析

正確答案：C. 等級2要求打開後留下痕跡，等級3要求難以打開並在偵測到時清除金鑰，等級4更要求在整個外殼上偵測入侵，以及對電壓、溫度異常的對策

FIPS 140-3是美國NIST制定的密碼模組基準，以國際標準ISO/IEC 19790為基礎，作為FIPS 140-2的後繼，於2020年開始受理認證。等級1只要使用一般產品品質的元件；等級2要求打開後會留下痕跡的封條或塗層；等級3要求難以打開或探測，並在偵測到時清除金鑰等重要值；等級4則要求在整個外殼上偵測入侵，以及電壓或溫度超出範圍時的保護。認證的對象不只實體安全性，也包括密碼演算法的正確實作、金鑰管理與自我測試等。採購硬體安全模組（HSM）或安全晶片時，常以指定等級作為條件。

常見問題

取得FIPS 140-2認證的產品，現在還能用嗎？

依NIST的過渡計畫，FIPS 140-2的認證於2026年9月21日全部移到歷史（Historical）清單。移到歷史清單的產品仍可為既有系統購買與使用，但新採購時，最可靠的做法是以當時的清單確認是否取得FIPS 140-3認證（2026年10月時的資訊）。

應該選擇哪個等級？

依要保護之金鑰的價值與所處環境決定。像資料中心的金鑰管理這類也假設會有實體攻擊的情況，多採用等級3；最上層的金鑰或嚴苛環境中，有時會選擇等級4。等級越高，成本與限制也越多。
