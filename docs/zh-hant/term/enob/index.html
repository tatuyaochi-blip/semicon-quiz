什麼是ENOB(有效位元數)

將實際AD轉換器包含雜訊與失真的性能(SINAD)，換算成理想ADC位元數的值。即使是12位元的ADC，ENOB只有約10位元也不罕見。

日文名稱: ENOB(有効ビット数)

「ENOB(有效位元數)」出現在1領域的2道練習題中（AD/DA轉換等）。

這個名詞所屬的領域: AD/DA轉換

練習ENOB(有效位元數)的題目

理想N位元ADC由量化雜訊決定的訊雜比（SNR）的近似式為下列何者？（滿刻度正弦波輸入的情況）

  1. A6.02N + 1.76 dB
  2. B3N dB
  3. C20N dB
查看答案與解析

正確答案：A. 6.02N + 1.76 dB

理想ADC的SNR為6.02N + 1.76 dB，每增加1位元約改善6 dB。12位元約為74 dB，16位元約為98 dB。它是由量化雜訊的有效值LSB/√12與滿刻度正弦波有效值之比推導而來。實際的ADC會再加上熱雜訊、失真與時脈抖動而低於此值，因此以由量測值反推的有效位元數（ENOB）來比較實力。

將實際ADC包含雜訊與失真的性能，換算成理想ADC位元數的指標為下列何者？

  1. AENOB（有效位元數）
  2. BLSB
  3. CDNL
查看答案與解析

正確答案：A. ENOB（有效位元數）

ENOB由實測的SINAD（訊號對雜訊加失真比）以ENOB = (SINAD − 1.76)/6.02求得，表示實際ADC相當於理想ADC的幾位元。例如即使是12位元的ADC，若SINAD為62 dB，則ENOB約為10位元。輸入頻率變高時，ENOB會因抖動與頻寬的影響而下降，因此要確認是在哪個頻率下的值。這就是只看解析度（位元數）無法得知實力的原因。
