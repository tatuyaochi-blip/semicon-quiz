什麼是硬連結

為管理檔案內容與屬性的 inode 加上的另一個名稱。以 ln 原名稱 新名稱 建立，兩個名稱地位對等，ls -i 會顯示相同的 inode 編號。inode 會計算指向它的名稱數（連結數），所有名稱都消失後才會釋放內容，因此即使用 rm 刪除原本的名稱，仍能從剩下的名稱讀取。它只能在同一個檔案系統中建立，通常不能對目錄建立。

日文名稱: ハードリンク
