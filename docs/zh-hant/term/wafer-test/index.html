什麼是晶圓測試(探針測試)

在切割之前，將探針接觸晶圓上各晶片的電極，檢查電氣特性的步驟。可在組裝前找出不良晶片，避免無謂的組裝。

日文名稱: ウエハテスト(プローブテスト)

「晶圓測試(探針測試)」出現在3領域的13道練習題中（測試與檢查, 良率與品質管理, DRAM等）。

這個名詞所屬的領域: 測試與檢查

練習晶圓測試(探針測試)的題目

關於晶圓測試（探針測試）的說明，下列何者正確？

  1. A在切割前，將探針接觸晶圓上的各個晶片，檢測其電氣特性
  2. B在封裝密封後，僅檢查外觀
  3. C長期使用產品以調查其故障率
查看答案與解析

正確答案：A. 在切割前，將探針接觸晶圓上的各個晶片，檢測其電氣特性

在晶圓測試中，探針台（prober）會移動晶圓，使探針卡的探針接觸晶片的電極焊墊，並以測試機檢測電氣特性與功能。若能在此階段找出不良晶片，就不會浪費封裝的材料費與組裝的工夫。這是因為不良越晚在後段製程被發現，損失越大。封裝密封後的檢測是最終測試，長期使用以調查故障率的則是可靠度試驗。

關於將晶圓測試中判定為不良的晶片資訊，用於之後的組裝製程，目前一般的方法為下列何者？

  1. A不在不良晶片上做記號，而是在組裝製程中全部重新檢查
  2. B以電子資料的晶圓圖（wafer map）傳遞給組裝製程
  3. C由作業員以目視記住
查看答案與解析

正確答案：B. 以電子資料的晶圓圖（wafer map）傳遞給組裝製程

過去會以墨水在不良晶片上點記號，但現在一般是將晶圓測試的結果以晶圓圖的電子資料儲存，由組裝製程的黏晶機（die bonder）讀取該資料，只取出良品晶片。這樣沒有墨水污染或乾燥的麻煩，也能記錄性能等級。圖的資料也用於分析不良的分布。

解析中的「晶圓測試(探針測試)」

  • 在晶圓測試中，探針台（prober）會移動晶圓，使探針卡的探針接觸晶片的電極焊墊，並以測試機檢測電氣特性與功能。

    關於晶圓測試（探針測試）的說明，下列何者正確？

  • 過去會以墨水在不良晶片上點記號，但現在一般是將晶圓測試的結果以晶圓圖的電子資料儲存，由組裝製程的黏晶機（die bonder）讀取該資料，只取出良品晶片。

    關於將晶圓測試中判定為不良的晶片資訊，用於之後的組裝製程，目前一般的方法為下列何者？

  • 在晶圓測試中，使探針卡的許多探針接觸排列在各晶片周邊等處的電極焊墊，由測試機施加電源與訊號並量測回應。

    在晶圓測試中，探針卡的針所接觸的晶片上位置為下列何者？

  • 將晶圓測試時發現的不良位置位址，記錄在以雷射熔斷的熔絲（fuse）或以電氣方式寫入的反熔絲（antifuse）中，並把存取改接到備用列或行。

    關於為提升DRAM良率而使用的冗餘修復，下列說明何者正確？

  • 首先在完成前段製程的晶圓狀態下進行晶圓測試，判別不良晶片。
