什麼是OPC(光學鄰近效應修正)

預先預估光的繞射等造成的圖案變形，而事先修正光罩圖案的技術。

日文名稱: OPC(光学近接効果補正)

「OPC(光學鄰近效應修正)」出現在2領域的11道練習題中（微影, LSI設計流程與EDA等）。

這個名詞所屬的領域: 微影

印出的圖案為何會變形

當圖形尺寸接近解析度極限時（R = k1·λ/NA 中的 k1 很小），投影透鏡只能通過少數幾個繞射階，因此圖案的成像是光罩圖案模糊後的樣子。線端會縮回、轉角會變圓，而同樣畫法的線條，其寬度會因相鄰圖形密集或孤立而不同。光阻與蝕刻也會加入各自依圖案而異的偏差。若不加修正，這些效應會使電晶體閘極長度偏移，並可能造成導線橋接或頸縮，因此光罩必須與預期的晶圓圖案不同。

規則式與模型式 OPC

早期的 OPC 是規則式的：以查找表加上固定偏差、在轉角加上襯線（serif）、在線端加上錘頭（hammerhead）。現代的模型式 OPC 把多邊形的邊切成短片段，以依測試晶圓量測結果校準的模型模擬空間影像與光阻反應，並反覆移動每個片段，直到模擬輪廓符合目標，將邊緣放置誤差降到最小。通常還會在孤立圖形旁加入次解析度輔助圖形（SRAF），也就是細到不會被印出的額外線條，讓孤立圖形表現得更像密集圖形，以保持較寬的製程窗口。

解析度增強技術中的 OPC

OPC 是解析度增強技術之一，與離軸照明及相移光罩一起，把量產的 k1 從約 0.6 推進到約 0.27–0.3。它們的共同目標是寬廣的製程窗口，也就是讓尺寸維持在容許範圍內的劑量與焦點範圍。光源光罩最佳化（SMO）同時計算照明形狀與光罩圖案，反向微影技術（ILT）則從期望的影像推導出自由形狀的曲線光罩。EUV 仍然需要 OPC，包括針對反射鏡粗糙度造成的雜散光（flare）與光罩三維效應的修正。

OPC 在流程中的位置

OPC 在投片（tape-out）後進行，此時要將 GDSII 或 OASIS 格式的設計佈局轉換成光罩資料。修正後的資料會以微影模擬驗證，找出熱點，也就是即使符合設計規則也可能橋接或頸縮的位置，接著進行分割（fracture）並寫入光罩，通常使用電子束或多電子束寫入機。OPC 會使多邊形數量倍增，因此需要大型運算叢集與 GPU 加速，並延長光罩寫入時間。設計者的佈局本身不變；OPC 只改變放到光罩上的內容。

  1. A將光阻塗厚以提高解析度
  2. B清洗光罩以去除異物
  3. C事先修正光罩圖案，以縮小轉印後形狀的偏差
查看答案與解析

正確答案：C. 事先修正光罩圖案，以縮小轉印後形狀的偏差

在接近解析極限的圖案中，由於光的繞射與干涉，線條的端點會縮短（線端內縮）、轉角會變圓，線寬也會隨周圍圖案的密度而改變。OPC會藉由模擬預先估算這些變形，在光罩圖案的邊緣加上錘頭（hammerhead）、襯線（serif）等輔助圖形，或精細調整尺寸。先進光罩的OPC運算會動用大規模的電腦。

常見問題

規則式 OPC 和模型式 OPC 有什麼差別？

規則式 OPC 依局部幾何形狀，套用查找表中的固定修正。模型式 OPC 則模擬每個圖案的成像結果，反覆移動邊緣片段直到預測輪廓符合目標，對複雜佈局的處理能力遠勝前者。

OPC 中的 SRAF 是什麼？

次解析度輔助圖形是放在孤立圖案附近、細小到本身不會被印出的光罩圖形。它們讓孤立線條的成像更像密集線條，擴大劑量與焦點的窗口。

EUV 微影還需要 OPC 嗎？

需要。EUV 製程同樣在低 k1 下運作，而且還多了反射鏡粗糙度造成的雜散光與光罩三維陰影等效應，都必須由 OPC 修正。
