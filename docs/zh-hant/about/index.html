關於本站

半導體教室是透過三選一的選擇題輕鬆學習半導體知識的網站。內容涵蓋半導體物理、元件、製造製程、封裝與測試、設計與產業，以及在晶片上運行的電腦系統。不需要註冊帳號，所有內容皆可免費使用。

本站提供的內容

  • 練習題：77 個領域、共 3667 題，每一題都附有解析。
  • 名詞解釋：簡短說明半導體及相關領域的名詞，主要名詞另附詳細解說與常見問題。
  • 比較：以表格並列容易混淆的技術與方式，說明彼此的差異。
  • 圖解集：以圖說明結構與運作原理。
  • 計算工具：設計與評估時常用的公式，可直接在瀏覽器中計算。

關於題目

本站刊登的題目與解析皆為本站原創，並非轉載自其他網站、書籍或認證考試的題目。

出題時遵循以下原則：正確答案只有一個；數值會註明溫度、標準版本等條件；不把經驗法則當作絕對的定論。題目公開後仍會持續檢視，發現錯誤時會加以更正。

繁體中文的內容是由日文原文翻譯而成。我們力求內容正確，但仍可能有錯誤。若發現錯誤，請透過聯絡我們頁面告訴我們。

使用方法

  • 依領域：在首頁選擇領域，作答該領域的題目。
  • 隨機10題：從所有領域隨機出10題。
  • 弱項題目：只重做最近答錯的題目。
  • 模擬考試：從所有領域出30題，解析會在最後統一顯示。
  • 弱項診斷：每個領域各出1題，再顯示各領域的答對率與接下來該學的領域。
  • 每日一題：每天出一道題。每天作答就能累積連續學習天數。
  • 學習課程：依各個目標，將領域排成建議的學習順序，並顯示進度與下一個該學的領域。

你的作答紀錄只儲存在瀏覽器中，可在成績頁面查看。
