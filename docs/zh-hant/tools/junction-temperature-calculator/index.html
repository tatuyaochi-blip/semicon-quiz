接面溫度與熱阻計算器

輸入功耗、環境溫度及資料手冊中的熱阻，即可估算晶片內部的接面溫度 Tj。比較兩種情況：無散熱片（θJA）與有散熱片（θJC + θCS + θSA），並分別顯示與最大接面溫度的裕度及其容許的最大功率。

熱阻就像電路一樣

晶片中消耗的功率會轉為熱，從接面經由封裝及電路板或散熱片流向周圍空氣。熱阻 θ 是每瓦熱流所產生的溫差，單位為 ℃/W。將溫差視為電壓、熱流視為電流，就得到歐姆定律 ΔT = P × θ，而串聯的熱阻只需相加。因此接面溫度為 Tj = Ta + P × θJA。以預設值 P = 1 W、Ta = 25 ℃、θJA = 50 ℃/W 計算，Tj = 75 ℃，相對於 125 ℃ 的 Tj(max) 尚有 50 ℃ 的裕度。

θJA 為何取決於電路板，以及 ψJT

θJA 並非僅由封裝決定的特性。它會隨電路板尺寸、銅層數、銅箔面積及氣流大幅變化。資料手冊中的數值多半是在 JEDEC 標準測試板上、靜止空氣中量測，因此最適合用來比較不同封裝。在實際產品中，熱會經由電路板的銅箔擴散，θJA 可能高於或低於表中數值。在實際系統中，常以量測到的封裝頂面溫度 Tt 依 Tj = Tt + P × ψJT 估算 Tj。由於並非所有熱都從頂面散出，ψJT 被稱為熱特性參數，而非熱阻。

散熱片的熱路徑與介面材料

加裝散熱片時，熱主要從接面流到外殼、從外殼流到散熱片、再從散熱片流到環境，因此總熱阻為 θJC + θCS + θSA。θJC 屬於封裝內部，列於資料手冊中。θCS 是外殼與散熱片之間的接觸部分；粗糙表面間的微小空氣間隙會阻礙熱傳，因此以導熱膏或導熱墊等熱介面材料（TIM）填補。θSA 取決於散熱片尺寸、鰭片形狀與氣流。預設值合計為 4.5 ℃/W，在 1 W 時 Tj = 29.5 ℃，最大功率約為 22.2 W。

降額與設計裕度

對矽 IC 與功率元件而言，Tj(max) 最常見為 125 ℃ 或 150 ℃，容許功率為 Pmax = (Tj(max) − Ta) ÷ θ。由於裕度會隨環境溫度上升而縮小，資料手冊會提供降額曲線，使容許功率隨環境溫度線性降低。例如 θJA = 50 ℃/W、Tj(max) = 125 ℃ 時，25 ℃ 下的上限為 2.0 W，但在 85 ℃ 下僅有 0.8 W。較高的接面溫度也會提高故障率並縮短壽命，因此實際設計通常會保留額外裕度，而不會恰好在 Tj(max) 下運作。

練習資料手冊題目

將規格書所載的 θJA（接面至周圍的熱阻）用於實際設備的熱設計時，應注意的事項何者正確？

  1. A這是僅由封裝結構決定的數值，因此無論安裝在什麼樣的電路板上數值都不變
  2. B電路板的銅箔面積越大越容易積熱，θJA會變大
  3. C這是在測試用電路板上量測的數值，會因實際電路板的銅箔面積、層數及有無氣流而大幅改變
查看答案與解析

正確答案：C. 這是在測試用電路板上量測的數值，會因實際電路板的銅箔面積、層數及有無氣流而大幅改變

θJA是將IC安裝在JEDEC等規範所定的測試用電路板上，在無風的容器中量測的數值。熱多半從封裝經由腳位或底面焊墊流向電路板，因此θJA強烈依存於電路板。即使是相同的封裝，在單層小電路板與多層且大面積鋪銅較多的電路板之間，也可能相差將近2倍。擴大銅箔面積或吹風，θJA會變小（容易散熱）。規格書的數值應視為比較用的參考，在實機上要量測溫度來確認。

將最大接面溫度 Tj(max) = 125 ℃、θJA = 50 ℃/W 的IC，在周圍溫度 Ta = 85 ℃ 下使用時，容許的功耗上限為多少？

  1. A0.8 W
  2. B2.5 W
  3. C1.7 W
查看答案與解析

正確答案：A. 0.8 W

接面溫度可由 Tj = Ta + P × θJA 求得。將其對P求解，P = (Tj(max) − Ta)/θJA = (125 − 85)/50 = 0.8 W。周圍溫度越高，容許的溫升幅度越小，因此容許的功率也越小。2.5 W是忘了減去周圍溫度而算成125/50的錯誤，1.7 W是算成85/50的錯誤。實際上，要考慮θJA會因電路板而變以及降額的餘裕，將功率壓在比計算值更低的範圍來設計。

估算加裝散熱片使用之功率元件的接面溫度時，作為接面到周圍的熱阻應使用哪一種組合？

  1. A規格書的θJA（接面至周圍）加上散熱片至周圍的熱阻
  2. BθJC、外殼至散熱片之間的接觸熱阻、散熱片至周圍的熱阻之和
  3. C只用規格書的θJA（接面至周圍），即使加裝散熱片數值也不變
查看答案與解析

正確答案：B. θJC、外殼至散熱片之間的接觸熱阻、散熱片至周圍的熱阻之和

θJC是從接面到封裝散熱面（外殼）的熱阻，是在外殼保持一定溫度的狀態下量測。加裝散熱片後，熱的大部分會從外殼流向散熱片，因此要將θJC、散熱膏等的接觸熱阻θCS、散熱片的熱阻θSA串聯相加來考慮。例如 1.0 + 0.5 + 3.0 = 4.5 ℃/W，損耗10 W時溫升為45 ℃。θJA是不加散熱片、安裝在測試用電路板上量測的數值，因此不能用於這種情況。

一般矽功率元件的最大接面溫度（Tj max）額定值，常見的是下列何者？

  1. A約500℃
  2. B約50℃
  3. C約150～175℃
查看答案與解析

正確答案：C. 約150～175℃

矽功率元件一般將最大接面溫度規定為150 ℃或175 ℃。超過這個溫度，漏電流會急遽增加而容易發生熱失控，壽命也會大幅縮短。設計時會相對於最大值留有餘裕（例如以125 ℃左右運作）。SiC作為材料雖可承受300 ℃以上，但焊料、導線、樹脂等封裝材料的耐熱性成為實用上的限制。

常見問題

何時使用 θJA，何時使用 θJC？

θJA 是在不加散熱片、由電路板與周圍空氣冷卻時的接面至環境熱阻。θJC 是接面至外殼熱阻，加裝散熱片時要與 θCS 和 θSA 相加。在散熱片設計中把 θSA 加到 θJA 上是錯誤的。

在 Tj(max) = 125 ℃、θJA = 50 ℃/W、Ta = 85 ℃ 時，容許功率是多少？

Pmax = (125 − 85) ÷ 50 = 0.8 W。若環境溫度為 25 ℃，上限為 (125 − 25) ÷ 50 = 2.0 W，因此環境越熱，容許功率越低。

為什麼資料手冊的 θJA 與我的電路板不符？

θJA 是在 JEDEC 標準測試板等固定條件下量測的，會隨電路板尺寸、銅層數與氣流大幅變化。在實際系統中，常利用 ψJT 由量測到的封裝頂面溫度估算接面溫度。
