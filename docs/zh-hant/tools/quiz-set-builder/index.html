測驗題組產生器

為課堂、研究室或新進人員訓練建立測驗：選擇主題與題數，再分享連結即可。每位開啟連結的人都會拿到相同的題目，並附有完整解說。無需註冊。

收藏與最近使用的工具只儲存在這個瀏覽器（localStorage）中。

題組內容

主題

您的測驗題組連結

開啟確認

任何人開啟此連結都會拿到相同的題目（選項順序每次都會打亂）。作答結果只會保留在每個人的瀏覽器中，不會傳送給您或我們。

以圖表檢視

其他輸入維持目前的值，只讓選擇的輸入在目前值的 1/4 到 4 倍之間變化時的結果。紅點是目前的值。

使用方式

勾選主題、選擇題數，然後按下「建立連結」。題目會從所選主題中平均抽出。若輸入題組名稱，該名稱會顯示為測驗畫面的標題。您可以透過學習管理系統、電子郵件或聊天工具分享連結；開啟同一個連結，永遠會得到相同的題目。

成績與隱私

本網站不使用帳號，也沒有資料庫。作答結果只儲存在受測者的瀏覽器中。如果需要收集成績，請依課程需求，請學生繳交結果畫面的截圖或分數。

常見問題

測驗產生器是免費的嗎？

是的。完全免費、無需註冊，建立的連結也不會過期。

所有學生拿到的題目都一樣嗎？

是的，開啟同一個連結的人都會拿到相同的題目。答案選項的順序每次都會打亂，因此無法直接互相傳答案。
