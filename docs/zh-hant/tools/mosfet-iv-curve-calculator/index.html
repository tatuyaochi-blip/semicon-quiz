MOSFET I-V 特性（ID–VDS）

本計算器以長通道平方律模型加上通道長度調變計算 nMOSFET 的汲極電流，並繪製成一組 ID–VDS 曲線。可一眼看出您的工作點位於截止區、線性區或飽和區，以及該點的汲極電流與小訊號參數。

平方律模型

在長通道 nMOSFET 中，當 VGS 超過臨界電壓 Vth 時便會形成通道。在 VDS 較小的線性區（三極區），ID = µnCox(W/L)[(VGS − Vth)VDS − VDS²/2]，電晶體的行為如同電壓控制電阻。當 VDS 超過過驅動電壓 VGS − Vth 時，通道在汲極端夾止；在飽和區 ID = (1/2)µnCox(W/L)(VGS − Vth)²，幾乎與 VDS 無關。

通道長度調變與輸出電阻

在實際元件中，於飽和區提高 VDS 會使夾止點往源極移動、有效通道變短，因此電流仍會略微上升。此通道長度調變是以將 ID 乘上 (1 + λVDS) 來建模。由其斜率可得小訊號輸出電阻 ro ≈ 1/(λID)，它決定了放大器的本質增益 gm·ro。通道越短，λ 越大、ro 越小，這也是類比電路常採用比最小尺寸更長之通道的原因。

求轉導

在飽和區，電流隨閘極電壓的變化率為 gm = µnCox(W/L)(VGS − Vth) = 2ID/(VGS − Vth)。在固定電流下，過驅動電壓越小，gm 越大，但需要較大的元件（較大的 W/L），且會改變電壓餘裕。以預設值 Vth = 0.5 V、µnCox = 200 µA/V²、W/L = 10、λ = 0.05 /V、VGS = 1.5 V、VDS = 1.2 V 計算，ID ≈ 1.06 mA、gm ≈ 2.1 mS、ro ≈ 19 kΩ，gm·ro 約為 40。

模型的限制

平方律是針對長通道元件的近似。在現代短通道電晶體中，載子在強電場下會達到速度飽和，因此電流對 (VGS − Vth) 的依存關係較接近線性而非平方。低於臨界電壓時電流也不為零：次臨界電流隨閘極電壓呈指數變化，在室溫下每變化十倍至少需要約 60 mV。因此電路設計在模擬時仰賴 BSIM 等詳細的精簡模型。

MOSFET 練習題

長通道MOSFET在飽和區工作時，汲極電流ID大致與什麼成正比？（VGS：閘極-源極間電壓，Vth：臨界電壓）

  1. A(VGS − Vth)的平方
  2. BVGS − Vth
  3. CVGS的倒數
查看答案與解析

正確答案：A. (VGS − Vth)的平方

在長通道MOSFET的飽和區，ID = (1/2)μCox(W/L)(VGS − Vth)²，汲極電流與(VGS − Vth)的平方成正比（平方律）。VGS − Vth稱為過驅動電壓，是類比設計的基本參數。在短通道中，因速度飽和而趨近於一次方，再加上遷移率劣化與寄生電阻的影響而產生偏差，因此實際設計時會使用BSIM等精密模型。

在汲極-源極間電壓VDS夠小的線性區，關於MOSFET的行為，下列何者正確？

  1. A如同電阻值會隨閘極電壓改變的可變電阻
  2. B如同不論VDS為何都流過固定電流的定電流源
  3. C如同只讓電流單向流過的二極體
查看答案與解析

正確答案：A. 如同電阻值會隨閘極電壓改變的可變電阻

在線性區，汲極電流與VDS大致成正比，其斜率（電導）μCox(W/L)(VGS − Vth)會隨閘極電壓改變，因此如同可由閘極電壓控制的可變電阻。開關的導通狀態就處於此區域，閘極電壓越高，導通電阻越小。這個特性也用於類比開關與可變增益電路。當VDS超過 VGS − Vth 時，就進入飽和區。

長通道nMOSFET在飽和區工作的條件，下列何者正確？（設 VGS > Vth）

  1. AVDS = 0
  2. BVDS < VGS − Vth
  3. CVDS ≥ VGS − Vth
查看答案與解析

正確答案：C. VDS ≥ VGS − Vth

當 VGS > Vth 而存在通道時，若 VDS ≥ VGS − Vth，汲極端的閘極-通道間電壓會低於Vth而使通道夾止，汲極電流幾乎不再依賴VDS。這就是飽和區。放大電路在此區域使用，所需的最低VDS（= VGS − Vth）成為輸出擺幅的下限。在短通道中，由於速度飽和，電流在更低的VDS下就會飽和。

以通道長度調變係數λ與汲極電流ID表示飽和區MOSFET的小訊號輸出電阻ro，下列何者為適當的公式？

  1. Aro ≈ 1 / (λ × ID)
  2. Bro ≈ ID / λ
  3. Cro ≈ λ × ID
查看答案與解析

正確答案：A. ro ≈ 1 / (λ × ID)

考慮通道長度調變時，飽和區的汲極電流呈 ID(1 + λVDS) 的形式，隨VDS略微增加，此斜率的倒數即為輸出電阻 ro ≈ 1/(λID)。λ幾乎與通道長度成反比，因此在相同汲極電流下將L加倍，ro也約加倍。單一電晶體的最大電壓增益為 gm·ro，在微細電晶體中只有10～20倍左右，因此要以疊接（cascode）或多級架構來確保增益。

常見問題

MOSFET 何時處於飽和區？

對 nMOSFET 而言，VGS > Vth 時存在通道，而當 VDS ≥ VGS − Vth 時元件處於飽和區。VDS 較小時則處於線性區（三極區）。

MOSFET 與 BJT 的「飽和」意義相同嗎？

不同。MOSFET 的飽和區是電流幾乎與 VDS 無關的區域，用於放大。BJT 的飽和則表示電晶體完全導通，較接近 MOSFET 的線性區。

如何計算 MOSFET 的輸出電阻？

在飽和區，可由通道長度調變係數與汲極電流估算為 ro ≈ 1/(λID)。當 λ = 0.05 /V、ID = 1 mA 時，ro 約為 20 kΩ。
