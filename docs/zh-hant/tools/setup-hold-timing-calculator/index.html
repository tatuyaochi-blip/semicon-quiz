建立時間檢查

新資料抵達擷取端正反器的最晚時間，為最大時脈至 Q 延遲加上最大組合邏輯延遲。資料必須在下一個擷取邊緣（週期加上偏移）減去建立時間與時脈不確定性之前抵達。建立時間餘裕為期限減去抵達時間；若為負值，表示週期太短，必須降低頻率或縮短邏輯路徑。

保持時間檢查

保持時間檢查的是：在同一個時脈邊緣發送的資料，是否抵達得太快，以致破壞擷取端正反器仍在鎖存的值。最早抵達時間，即最小時脈至 Q 延遲加上最小組合邏輯延遲，必須晚於偏移加上保持時間。保持時間檢查中不含時脈週期，因此降低時脈頻率永遠無法修正保持時間違反；工具會改在短路徑上插入延遲緩衝器。

時脈偏移如何影響兩項檢查

當擷取時脈比發送時脈晚到（正偏移）時，建立時間期限會往後延，有利於建立時間，但不利於保持時間。負偏移則相反。設計者有時會刻意加入偏移來挽救關鍵的建立時間路徑（useful skew），但必須重新檢查保持時間。實際的 STA 會以最差情況檢查每一條路徑：建立時間在慢速角落（slow corner）檢查，保持時間在快速角落（fast corner）檢查。

最高頻率

建立時間餘裕恰好為零時的週期，即為該路徑的最小週期，其倒數就是最高頻率：fmax = 1 / (時脈至 Q 延遲 + 組合邏輯延遲 + 建立時間 + 不確定性 − 偏移)。晶片的最高頻率由其最慢的路徑，也就是關鍵路徑決定。增加管線級數可縮短每一級的邏輯，提高可達到的頻率。

練習邏輯設計題目

下列哪一項是對正反器設置時間的正確說明？

  1. A時脈邊緣之後，資料必須持續保持的最短時間
  2. B時脈邊緣之前，資料輸入必須保持穩定的最短時間
  3. C從開啟電源到開始動作的時間
查看答案與解析

正確答案：B. 時脈邊緣之前，資料輸入必須保持穩定的最短時間

正反器要正確取入資料，資料必須從時脈邊緣前一段時間起就保持穩定，這就是設置時間。當資料路徑的延遲超過時脈週期減去設置時間的值時即違規，放慢時脈即可解決。邊緣之後資料必須保持的時間是保持時間，只要有一項不滿足，就會造成取入錯誤的值或亞穩態。

下列哪一項是對正反器保持時間的正確說明？

  1. A時脈有效邊緣之前，必須先確定資料輸入的時間
  2. B從輸入時脈到輸出改變的時間
  3. C時脈有效邊緣之後，資料輸入也必須保持不變的時間
查看答案與解析

正確答案：C. 時脈有效邊緣之後，資料輸入也必須保持不變的時間

保持時間是時脈邊緣之後，資料必須保持穩定的最短時間。若從前一級正反器到下一級的路徑太短，在同一個邊緣更新的新資料會太早到達下一級而違規。由於與週期無關，放慢時脈也無法改善，對策是在資料路徑插入緩衝器以增加延遲。若在製造後才發現，晶片就無法使用，因此設計時的驗證很重要。

常見問題

建立時間違反與保持時間違反的修正方式有何不同？

建立時間違反可透過降低時脈頻率、加速或重新架構邏輯，或增加管線級數來修正。保持時間違反與頻率無關，因此要在短路徑上加入緩衝器以增加延遲來修正。

時脈偏移會影響建立時間還是保持時間？

兩者都會，且方向相反。正偏移（擷取時脈較晚抵達）有利於建立時間、不利於保持時間；負偏移則相反。

時序分析中的餘裕（slack）是什麼？

餘裕就是時序上的裕度：要求時間減去實際抵達時間。餘裕為正表示通過檢查；餘裕為負即為違反。
