熱氧化層厚度（Deal-Grove 模型）

本計算器使用 Deal-Grove 模型，求出矽在氧氣或水蒸氣中加熱時所成長的氧化層（SiO2）厚度。可切換乾式與濕式氧化、(100) 與 (111) 晶面，並改變溫度與時間，觀察成長速率及膜下被消耗的矽如何變化。

Deal-Grove 方程式

熱氧化時，O2 或 H2O 等氧化劑會擴散通過既有的氧化層，並在矽界面反應形成新的氧化層。令擴散通量等於反應通量，可得 x² + Ax = B(t + τ)。B 是由擴散決定的拋物線速率常數，B/A 是由界面反應決定的線性速率常數，τ = (xi² + A·xi)/B 則用來計入初始厚度 xi。以預設值乾式氧化、(100)、1000 °C、1 小時計算，B ≈ 0.0104 µm²/h，B/A ≈ 0.0449 µm/h，氧化層厚約 38.5 nm。

線性區與拋物線區

當膜很薄、t + τ 遠小於 A²/4B 時，x ≈ (B/A)(t + τ)，厚度與時間成正比成長（線性區）。此時成長受界面反應限制，而反應性取決於晶面方位，因此 (111) 矽的氧化速度比 (100) 快；在 (111) 上以預設條件可得約 54.2 nm。隨著膜變厚，氧化劑擴散通過所需的時間變長，成長便轉入拋物線區，x² ≈ Bt。此時厚度要加倍約需 4 倍時間，這就是曲線趨於平緩的原因。

乾式氧化與濕式氧化

濕式（水蒸氣）氧化比乾式氧化快得多，因為 H2O 在氧化層中的溶解度是 O2 的數百倍。在 (100)、1000 °C、1 小時的條件下，乾式氧化約成長 38.5 nm，濕式氧化則約成長 388 nm。乾式氧化速度慢，易於精確控制厚度，且能形成界面能態少的緻密膜，因此用於閘極氧化層等薄膜。濕式氧化則用於數百奈米以上的厚膜，例如 LOCOS 場氧化層與遮罩氧化層。

矽的消耗與注意事項

氧化層是消耗矽而成長的：形成厚度 x 的膜約會消耗 0.44x 的原有矽，因此約 44% 的膜位於原始表面下方，56% 位於上方。這會影響 LOCOS 的段差與鳥嘴，以及隔離結構的形狀。乾式氧化在約 30 nm 以下的初期成長比模型預測更快，因此 Deal 與 Grove 以相當於約 20 至 25 nm 的初始厚度（τ）加以修正。僅數奈米厚的閘極氧化層則需依實測結果調整。

練習氧化與擴散題目

將矽熱氧化形成厚度為 x 的 SiO2 薄膜時，被消耗的矽厚度約為多少？

  1. A約 0.44x
  2. B約 1.0x
  3. C約 2.2x
查看答案與解析

正確答案：A. 約 0.44x

熱氧化是矽本身與氧反應變成 SiO2。由矽的原子密度（約 5.0×10²² cm⁻³）與 SiO2 的分子密度（約 2.2×10²² cm⁻³）之比可知，形成厚度 x 的氧化層所消耗的矽約為 0.44x。氧化層約 44% 位於原始表面之下，56% 向上成長，體積膨脹約 2.2 倍。因此氧化的部分會形成階差，而介面總是新的潔淨表面。

熱氧化時，當氧化層變得夠厚後，氧化層厚度與氧化時間的關係，下列何者正確？

  1. A厚度大致與時間的平方根成正比（拋物線定律）
  2. B厚度與時間的平方成正比
  3. C厚度與時間無關，維持固定
查看答案與解析

正確答案：A. 厚度大致與時間的平方根成正比（拋物線定律）

在 Deal-Grove 模型中，x² + Ax = B(t + τ)。薄膜階段由介面反應主導，厚度大致與時間成正比（線性定律，x ≈ (B/A)t）；膜變厚後則由氧化劑在膜中的擴散主導，厚度與時間的平方根成正比（拋物線定律，x ≈ √(Bt)）。例如要使厚度加倍，約需 4 倍的時間。氧化層越厚越耗時，因此會以高溫、濕式、高壓的條件來加快速度。

在 Deal-Grove 模型中，熱氧化初期（氧化層仍薄時）的氧化層厚度與時間的關係，下列何者正確？

  1. A厚度與時間的平方根成正比
  2. B厚度大致與時間成正比（呈線性增加）
  3. C厚度與時間無關，維持固定
查看答案與解析

正確答案：B. 厚度大致與時間成正比（呈線性增加）

氧化層薄的時候，氧化劑很容易穿過膜，由介面的反應速度主導，因此厚度大致與時間成正比增加（線性定律，速率常數 B/A）。膜變厚後，由氧化劑在膜中的擴散主導，厚度便與時間的平方根成正比（拋物線定律，速率常數 B）。轉換的大致標準是厚度約 A/2，乾式氧化時約為數十 nm～100 nm 左右。

以乾式氧化製作厚度數十 nm 以下的薄氧化層時，已知會偏離 Deal-Grove 模型的是何者？

  1. A初期的氧化比模型預測進行得更快
  2. B完全不會氧化
  3. C氧化層變成導體
查看答案與解析

正確答案：A. 初期的氧化比模型預測進行得更快

Deal-Grove 模型能很好地描述厚氧化層的成長，但在乾式氧化中膜厚數十 nm 以下的初期區域，實際的氧化比模型預測進行得更快。認為原因可能是氧化劑通過薄膜的其他路徑，以及介面附近應力的影響等。模型將這一部分以初始膜厚（τ，相當於約 20 nm）加以修正，但要決定數 nm 閘極氧化層的厚度，仍必須透過實測來訂定條件。

常見問題

成長 100 nm 氧化層會消耗多少矽？

約為其 0.44 倍，即 44 nm。新氧化層中約 44 nm 位於原始矽表面下方，其餘 56 nm 位於上方。本計算器以成長厚度乘以 0.44 計算。

氧化時間加倍，厚度也會加倍嗎？

只有在薄膜的線性區才會。在拋物線區，厚度只會增加為 √2 ≈ 1.4 倍。例如在 1000 °C 下對 (100) 矽進行濕式氧化，1 小時約 388 nm，2 小時約 610 nm，約為 1.6 倍，介於兩個極限之間。

為什麼 (100) 與 (111) 矽的氧化速率不同？

描述界面反應的線性速率常數 B/A 取決於表面原子的排列。(111) 表面可供反應的鍵結較多，其 B/A 約為 (100) 的 1.68 倍。受擴散限制的 B 與晶面方位無關，因此膜越厚，差異越小。
