能隙與發光波長換算

LED 與雷射的發光波長，以及光偵測器可感測的波長上限，大致由材料的能隙決定。輸入能隙即可算出波長，輸入波長則可算出所需的能隙。

輸入的條件會寫入這個頁面的網址，加入書籤或分享後，就能開啟相同的計算結果。收藏與最近使用的工具只儲存在這個瀏覽器（localStorage）中。

換算公式 λ ≈ 1240/Eg

一個光子的能量為 E = hν = hc/λ。代入普朗克常數 h = 6.626×10⁻³⁴ J·s、光速 c = 2.998×10⁸ m/s、基本電荷 q = 1.602×10⁻¹⁹ C，並將單位統一為 eV 與 nm，即得 E[eV] × λ[nm] ≈ 1239.84，可記成 λ ≈ 1240/Eg。在半導體中，導帶底部的電子與價帶頂端的電洞復合而發光時，光子能量幾乎等於能隙，因此可用此式估算發光波長。反過來，光偵測器無法吸收波長比 1240/Eg 更長的光，這就是其靈敏度的極限（截止波長）。

前提條件

假設光子能量等於能隙，也就是只考慮導帶底部與價帶頂端之間的躍遷。實際 LED 的發光峰值會因載子的熱能（約 kT）而略偏向高能量側，並具有一定寬度。溫度升高時能隙變小，波長往長波長側偏移。InGaN、AlGaAs 等混晶的能隙隨組成改變，量子井還會加上侷限能量，因此即使材料名稱相同，各產品的發光波長也不盡相同。

計算範例

以預設的 GaAs（Eg = 1.42 eV）為例，λ ≈ 1239.84/1.42 ≈ 873 nm，是近紅外 LED 等元件使用的波長。Si（1.12 eV）約為 1107 nm，由此可知矽光偵測器為何幾乎感測不到比約 1.1 µm 更長的波長。GaN（3.4 eV）約為 365 nm 的紫外光；藍光 LED 則摻入 In 形成 InGaN，將能隙降至約 2.7 eV，發出約 460 nm 的藍光。反過來，對應光通訊 1550 nm 的能隙約為 0.80 eV，使用的是在 InP 上成長的 InGaAsP 等混晶。

使用的數值與出處類型

預設的能隙是半導體教科書與物性手冊所列、溫度 300 K 下的代表性物性值（Si 1.12、Ge 0.66、GaAs 1.42、InP 1.34、In₀.₅₃Ga₀.₄₇As 0.75、GaP 2.26、4H-SiC 3.26、GaN 3.4、ZnO 3.37、鑽石 5.47、AlN 6.2 eV）。不同文獻在小數第二位左右會有差異。直接能隙與間接能隙的區分也是代表性的分類。換算常數 1239.84 eV·nm 是由物理常數 h、c、q 的數值求得。

練習化合物半導體題目

波長620 nm的光，其1個光子所具有的能量最接近下列何者？（E [eV] ≈ 1240 / λ [nm]）

  1. A約1.0 eV
  2. B約3.0 eV
  3. C約2.0 eV
查看答案與解析

正確答案：C. 約2.0 eV

光子的能量為 E = hc/λ，以eV和nm表示時 E ≈ 1240/λ。λ = 620 nm（紅色）時，E ≈ 2.0 eV。利用這個換算式，可以馬上求出Si（1.12 eV）的吸收邊約為1.1 µm，GaN（3.4 eV）約為365 nm的紫外線。LED的發光顏色大致由能隙決定，因此紅光LED使用約1.9～2.0 eV的AlGaInP等。

能隙約1.42 eV的GaAs所發出的光，其大約的波長是下列何者？

  1. A約450 nm（藍色）
  2. B約870 nm（近紅外線）
  3. C約10 µm（遠紅外線）
查看答案與解析

正確答案：B. 約870 nm（近紅外線）

波長為 λ(nm) ≈ 1240/Eg(eV)，1240/1.42 ≈ 873 nm，是肉眼看不見的近紅外光。GaAs系的LED用於電視遙控器與光電感測器，GaAs/AlGaAs的VCSEL在850 nm附近，用於智慧型手機的臉部辨識與短距離光通訊。要發出可見光（約400～700 nm），需要像GaAsP或AlGaInP這類能隙較大的材料。

決定LED發光顏色（發光波長）的主要因素為下列何者？

  1. A封裝的形狀
  2. B驅動電流的方向
  3. C發光層所使用半導體的能隙
查看答案與解析

正確答案：C. 發光層所使用半導體的能隙

在LED中，電子與電洞復合時，會發出相當於能隙能量的光。波長約為 λ(nm) ≈ 1240/Eg(eV)，例如GaN系（InGaN）約2.7 eV，為藍光約460 nm；AlGaInP約1.9 eV，為紅光約650 nm。改變發光層的組成即可調整能隙，即使同為InGaN，增加In的比例就會變成綠光。白光LED是藍光LED與黃色螢光粉的組合。

常見問題

1240 這個數字是怎麼來的？

它是普朗克常數與光速的乘積除以基本電荷，即 hc/q = 1.23984×10⁻⁶ eV·m，再換算成 nm 單位的數值。表示光子能量（eV）與波長（nm）的乘積恆約為 1240 的關係。

為什麼矽不會發光？

矽是間接能隙材料，導帶底部與價帶頂端的電子動量不同，發光時需要聲子（晶格振動）的協助。這種過程的機率很低，產生熱的復合會先發生，所以發光非常微弱。至於吸收光，則可透過聲子進行，因此矽仍可用於光偵測器與影像感測器。

也能計算白光 LED 的波長嗎？

多數白光 LED 是以藍光 LED（約 450～460 nm）的光激發黃色螢光粉，混合後看起來呈白色。此公式能計算的是藍光 LED 的部分，螢光粉的發光則是另一種機制。
