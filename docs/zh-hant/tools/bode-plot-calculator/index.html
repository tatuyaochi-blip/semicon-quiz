波德圖計算

把轉移函數 G(s) 的分子與分母，以 10、s^2 + 3s + 2、(s+1)(s+2) 等 s 的式子輸入，即可繪製對角頻率 ω 的增益與相位圖（波德圖）。並把它視為開迴路轉移函數，求出相位邊限與增益邊限。

收藏與最近使用的工具只儲存在這個瀏覽器（localStorage）中。

轉移函數 G(s) = 分子 / 分母 · e^(−Ls)

乘號可省略，例如 2s、s(s+1)、(s+1)(s+2)。次方寫成 s^2。也可依次數由高到低，以空白分隔列出係數，例如「1 3 2」。

波德圖的讀法

波德圖是兩張圖，表示輸入正弦波時輸出的大小（增益）與相位偏移，對角頻率 ω 的變化。橫軸為對數刻度，增益以分貝 20·log10|G(jω)| 表示。取對數後，串接的轉移函數的增益與相位會變成相加，因此可疊加各要素的圖來思考整體。一階延遲 1/(Ts+1) 的增益在轉折角頻率 1/T 以前幾乎平坦，之後每 10 倍下降 20 dB，相位由 0° 變為 −90°。在轉折頻率處增益為 −3 dB、相位為 −45°。

相位邊限與增益邊限

回授控制的穩定裕度，可從開迴路轉移函數的波德圖讀出。在增益為 0 dB 的角頻率（增益交越頻率），相位距離 −180° 有多遠，就是相位邊限。在相位為 −180° 的角頻率（相位交越頻率），增益低於 0 dB 多少，就是增益邊限。範例 1/(s(s+1)) 的 ωgc ≈ 0.786 rad/s，相位邊限約 52°。10/((s+1)(s+2)(s+3)) 的 ωpc = √11 ≈ 3.32 rad/s，增益邊限約 15.6 dB，因此把增益提高約 6 倍到 60 就會臨界穩定。常用的參考值為相位邊限 40～60°、增益邊限約 10 dB 以上。

極點、零點與圖形

使分母為 0 的 s 是極點，使分子為 0 的 s 是零點。左半平面的實數極點，從與其大小相同的角頻率起，讓增益以 20 dB/dec 下降，並使相位延遲 90°。零點則相反，提高增益並使相位超前。原點的極點（積分）在所有頻率都加上 −20 dB/dec 與 −90°。一對共軛複數極點會在自然角頻率附近形成增益的峰（共振），阻尼比 ζ 越小峰越高。範例的二階延遲（ζ = 0.2）在 ω ≈ 1 rad/s 附近可看到增益的峰。

時間延遲的影響

時間延遲 e^(−Ls) 不改變增益，只讓相位延遲 ωL [rad]。頻率越高延遲越大，因此會減少相位邊限，並降低可提高增益的上限。範例 2e^(−0.5s)/(s+1) 的增益交越頻率為 √3 ≈ 1.73 rad/s，時間延遲造成約 50° 的延遲。相位邊限約 70°，若沒有時間延遲則約為 120°。含時間延遲的系統，其閉迴路的根無法由多項式求出，因此本工具會提示以邊限判斷閉迴路是否穩定。

練習控制工程的題目

關於一階系統 G(s) = 1/(1 + sT) 的波德圖的特徵，正確的是下列何者？

  1. A在轉折角頻率 ω = 1/T 時增益約為 −3 dB、相位為 −45°，在遠高於此的頻率，增益以 −20 dB/dec 下降
  2. B在轉折角頻率 ω = 1/T 時增益為 −6 dB、相位為 −90°，在遠高於此的頻率，增益以 −40 dB/dec 的斜率下降
  3. C增益在任何頻率都是0 dB，只有相位與頻率成正比地落後
查看答案與解析

正確答案：A. 在轉折角頻率 ω = 1/T 時增益約為 −3 dB、相位為 −45°，在遠高於此的頻率，增益以 −20 dB/dec 下降

G(jω) = 1/(1 + jωT) 的大小為 1/√(1 + (ωT)²)，在 ω = 1/T 時為 1/√2（約 −3 dB），相位為 −45°。當 ω 遠大於 1/T 時，大小趨近 1/(ωT)，頻率每增加10倍，增益就下降20 dB（−20 dB/dec）。相位由低頻的0°變化到高頻的 −90°。在波德圖的漸近線近似中，轉折點以下以0 dB的水平線表示，以上以 −20 dB/dec 的直線表示。

積分元件 G(s) = 1/s 的波德圖為下列何者？

  1. A增益在任何頻率都是0 dB，相位在任何頻率都是 −90°
  2. B增益是在 ω = 1 rad/s 通過0 dB、斜率 +20 dB/dec 的直線，相位在任何頻率都是 +90°
  3. C增益是在 ω = 1 rad/s 通過0 dB、斜率 −20 dB/dec 的直線，相位在任何頻率都是 −90°
查看答案與解析

正確答案：C. 增益是在 ω = 1 rad/s 通過0 dB、斜率 −20 dB/dec 的直線，相位在任何頻率都是 −90°

G(jω) = 1/(jω) 的大小為 1/ω，因此在 ω = 1 rad/s 時為0 dB，頻率每增加10倍就下降20 dB。由於 1/j = −j，相位在任何頻率都是 −90°。頻率越低增益越大，因此含有積分的系統，能使對步階目標值的穩態誤差為0。斜率 +20 dB/dec、相位 +90° 的直線，屬於微分元件 s。

以波德圖的漸近線近似，求 G(s) = 10/((1 + s/100)(1 + s/1000)) 在角頻率 ω = 10⁴ rad/s 時的增益，所得的值為下列何者？

  1. A−40 dB
  2. B−20 dB
  3. C0 dB
查看答案與解析

正確答案：A. −40 dB

低頻時的增益為 20 log₁₀10 = 20 dB。由100 rad/s到1000 rad/s以 −20 dB/dec 下降，在1000 rad/s成為0 dB，之後加上第2個極點，以 −40 dB/dec 下降。由1000 rad/s到10⁴ rad/s是1個十倍頻程，因此增益為 0 − 40 = −40 dB。實際的值也約為 −40.04 dB；在遠離轉折點的頻率，漸近線近似相當準確。

關於由迴路轉移函數的波德圖讀取的增益邊限與相位邊限的說明，正確的是下列何者？

  1. A增益邊限是增益為0 dB的頻率處相位距 −180° 的差，相位邊限是相位為 −180° 的頻率處增益距0 dB的差
  2. B增益邊限是相位為 −180° 的頻率處增益距0 dB的差，相位邊限是增益為0 dB的頻率處相位距 −180° 的差
  3. C增益邊限與相位邊限都在閉迴路的波德圖上，於增益為 −3 dB的頻率處讀取
查看答案與解析

正確答案：B. 增益邊限是相位為 −180° 的頻率處增益距0 dB的差，相位邊限是增益為0 dB的頻率處相位距 −180° 的差

增益邊限表示在相位達到 −180° 的相位交越頻率處，增益比0 dB低多少dB。相位邊限表示在增益為0 dB的增益交越頻率處，相位距 −180° 還有多少度。兩者都是表示迴路轉移函數有多接近點 −1（增益0 dB、相位 −180°）的指標，要由迴路轉移函數而非閉迴路讀取。在伺服系統中，常以增益邊限約10～20 dB、相位邊限約40～60°作為參考。

迴路轉移函數 L(s) = 2/(s(s + 1)(s + 2)) 的增益邊限最接近下列何者？

  1. A約4.8 dB
  2. B約9.5 dB
  3. C約15.6 dB
查看答案與解析

正確答案：B. 約9.5 dB

相位為 −90° − tan⁻¹ω − tan⁻¹(ω/2)，由兩個角之和為90°的條件 ω × (ω/2) = 1，可知相位為 −180° 是在 ω = √2 rad/s 時。該處的增益為 |L(j√2)| = 2/(√2 × √3 × √6) = 1/3，因此增益邊限為 20 log₁₀3 ≈ 9.5 dB。這表示把增益提高為3倍（K = 6）就會到達極限，與用羅斯-赫維茲穩定準則求得的穩定範圍 0 < K < 6 一致。

提高迴路轉移函數的增益後，相位邊限由60°減少為30°。閉迴路步階響應的變化正確的是下列何者？

  1. A過衝變小、振盪消失，但響應變慢
  2. B相位邊限是頻率響應的指標，因此不影響步階響應的形狀
  3. C響應有變快的傾向，但過衝變大，振盪也較難平息
查看答案與解析

正確答案：C. 響應有變快的傾向，但過衝變大，振盪也較難平息

提高增益會使增益交越頻率提高、響應變快，但相位邊限減少時，閉迴路的阻尼比會變小。作為經驗法則，阻尼比 ζ 可估計為相位邊限（度）的約100分之1。對迴路轉移函數為 ωn²/(s(s + 2ζωn)) 的標準系統，相位邊限60°時過衝約9%，30°時約42%。相位邊限趨近0時會接近持續振盪，變成負的時候則不穩定。

常見問題

相位邊限要多少才夠？

一般常用 40～60° 作為參考。相位邊限小時，閉迴路步階響應的超越量變大，容易振盪。以二階系統近似時，相位邊限約 45° 相當於阻尼比約 0.4，約 60° 相當於約 0.6。也要考慮元件誤差與溫度變化，保留餘裕。

dB 與倍率如何換算？

增益的 dB 為 20·log10(倍率)。2 倍約 6 dB，10 倍為 20 dB，1/√2 ≈ 0.707 倍約 −3 dB，0.1 倍為 −20 dB。增益邊限 15.6 dB 表示增益提高約 6 倍就會到達穩定極限。

為什麼開迴路的波德圖能判斷閉迴路是否穩定？

單位回授的閉迴路 G/(1 + G) 在 1 + G(jω) = 0 時不穩定，也就是 G(jω) 通過或包圍增益 1、相位 −180° 這一點時（奈奎斯特穩定判據）。對開迴路本身穩定的一般系統，若在相位交越頻率時增益小於 1 就是穩定的。若開迴路本身有不穩定極點，就需要在奈奎斯特圖上計算環繞次數。
