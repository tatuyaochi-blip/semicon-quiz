相位雜訊與抖動的關係

相位雜訊 L(f) 是在偏離載波 f 處、1 Hz 頻寬內的雜訊功率相對於載波功率的比值，單位為 dBc/Hz。若 A 為其在選定頻帶內的積分，則包含兩側邊帶的 RMS 相位起伏為 φ = √(2A) 弧度。一個週期 1/f0 對應 2π 弧度，因此以時間表示的 RMS 抖動為 φ/(2π·f0)。以預設的 100 MHz 時脈為例，A = −73.4 dBc、φ = 0.301 mrad，抖動約為 479 fs。

逐段積分與 −10 dB/dec 的情況

若各點之間的相位雜訊在對數頻率軸上呈直線，則每段的雜訊功率依 f 的冪次變化，可用解析式積分。只有以 −10 dB/dec（1/f）下降的區段，積分結果為對數，因此每個十倍頻程的貢獻相同。下降比 −10 dB/dec 更快的區段，積分由低頻端主導；較平緩或平坦的區段則由高頻端主導。在預設值下，12 kHz 至 100 kHz 約占 φ² 的 46.8%，100 kHz 至 1 MHz 約占 30.2%。

積分頻帶與載波頻率

抖動強烈取決於積分頻帶，因此資料手冊一定會註明。12 kHz 至 20 MHz 的頻帶源自 SONET 光纖網路標準，廣泛用於比較時脈。將預設值的下限放寬至 1 kHz，抖動會升至約 596 fs。在相位雜訊相同的情況下，f0 加倍會使抖動減半，約為 240 fs。反之，以 PLL 將頻率乘以 N 時，相位雜訊理想上會增加 20·log₁₀N dB，因此以時間表示的抖動維持不變。

抖動對效能的影響

在 ADC 中，取樣時間的誤差會使訊號在該時間內的變化成為誤差，因此抖動 tj 會將 SNR 限制在 −20·log₁₀(2π·fin·tj)。以預設的約 479 fs 計算，100 MHz 輸入的上限約為 70.4 dB。在高速序列鏈路中，抖動會縮小眼圖的水平開口。此處計算的 RMS 抖動描述的是隨機成分；估算位元錯誤率時需將其換算為峰值，而雜散造成的確定性抖動必須另外考慮。

練習類比與電子電路題目

對高頻訊號進行AD轉換時，取樣時脈在時間上的晃動（抖動，jitter）會成為問題，其原因下列何者正確？

  1. A因為時脈會停止
  2. B因為只有直流訊號會產生誤差
  3. C因為訊號變化越快，取樣時刻的些微偏差就會造成越大的電壓誤差
查看答案與解析

正確答案：C. 因為訊號變化越快，取樣時刻的些微偏差就會造成越大的電壓誤差

取樣時刻偏差Δt時，期間的訊號變化量就成為誤差。由於正弦波的斜率與頻率成正比，由抖動決定的SNR上限為SNR = −20 log₁₀(2πf·tj)。例如要在100 MHz的訊號得到70 dB，需將抖動降到約0.5 ps以下。因此在高速、高解析度的ADC或無線接收機中，相位雜訊小的時脈源設計左右著性能。

在與參考時脈同步相位的同時，產生其整數倍等頻率之時脈的電路是哪一個？

  1. APLL（鎖相迴路）
  2. B整流電路
  3. C取樣保持電路
查看答案與解析

正確答案：A. PLL（鎖相迴路）

PLL由相位比較器、迴路濾波器、壓控振盪器（VCO）與除頻器構成，控制使VCO輸出經除頻後的訊號與參考時脈的相位一致。將除頻比設為N，可得到參考頻率的N倍，例如可由25 MHz的石英產生數GHz的CPU時脈。以小數除頻（Fractional-N）也能合成精細的頻率，並用於無線的本地振盪器，以及高速序列通訊的時脈回復。

在時脈不確定性的設定中，建立時間用的通常會納入週期抖動，保持時間用的則多半不納入。其理由何者正確？

  1. A保持時間的檢查只在時脈的下降邊緣進行
  2. B抖動只在頻率高時發生，而保持時間的分析會降低頻率
  3. C保持時間是在同一時脈邊緣之間比較，因此邊緣時刻的變動會同樣作用於發送端與接收端而相互抵銷
查看答案與解析

正確答案：C. 保持時間是在同一時脈邊緣之間比較，因此邊緣時刻的變動會同樣作用於發送端與接收端而相互抵銷

週期抖動是指某個邊緣與下一個邊緣的間隔發生變動。建立時間以送出的邊緣與下一個邊緣的間隔判定，因此週期 1.0 ns 若有 ±30 ps 的抖動，可用時間最差會減少到 0.97 ns。保持時間以同一邊緣比較送出與取入，因此無論該邊緣提早或延後，兩者都會一起移動，抖動的影響幾乎相互抵銷。不過，時脈樹建立前的時脈偏移預估，也要納入保持時間用的不確定性。

  1. A將大量位元的波形重疊繪製而成，中央的「眼睛」在縱向與橫向都張得越大，表示裕度越大
  2. B眼睛閉得越緊，訊號品質越好
  3. C是用來檢查人眼健康狀態的圖
查看答案與解析

正確答案：A. 將大量位元的波形重疊繪製而成，中央的「眼睛」在縱向與橫向都張得越大，表示裕度越大

眼圖是將每一個位元週期的波形切出並重疊繪製而成。在0與1的波形之間會形成眼睛形狀的空隙，其高度代表對雜訊的裕度，寬度代表對時序偏差（抖動，jitter）的裕度。傳輸線路的損耗、反射或抖動越大，眼睛就越閉合。接收電路是在這隻眼睛的中央判定位元，因此眼睛的張開程度可作為品質的指標。

常見問題

相位雜訊改善 10 dB 時，抖動會降低多少？

若相位雜訊在所有偏移頻率都降低 10 dB，積分值 A 會降為 1/10，相位誤差與抖動則降為 1/√10，約 0.316 倍。若只有部分區段改善，抖動會依這些區段在 φ² 中所占的比例降低，因此改善貢獻最大的區段最有效。

積分頻帶該如何選擇？

請選擇會影響使用該時脈之電路的頻帶。低於下限的緩慢相位變化，常可由接收端的 PLL 或 CDR 追蹤消除；上限則由訊號頻寬或後級濾波決定。通訊標準常會規定頻帶，而以不同頻帶標示的抖動值無法直接比較。

相位抖動、週期抖動與相鄰週期抖動是相同的嗎？

不同。由相位雜訊求得的是各邊緣相對於理想時脈的 RMS 偏差，稱為相位抖動。週期抖動是單一週期長度的變動，相鄰週期抖動（cycle-to-cycle jitter）則是相鄰週期之間的差；時序分析通常使用後兩者。同一時脈的這些數值各不相同，因此請確認所指的是哪種定義。
