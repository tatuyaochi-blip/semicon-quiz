半導體、電子電路與資訊計算工具

從晶粒數、微影解析度等半導體數值，到合成電阻、運算放大器等電子電路，邏輯電路模擬器與卡諾圖，二進位、浮點數與 CRC，以及子網路、排隊理論與可用率，都能在瀏覽器上免費使用的工具。

最近使用的工具

收藏與最近使用的工具只儲存在這個瀏覽器（localStorage）中，不會與其他裝置或瀏覽器共用。

基礎

建立時間與保持時間時序計算器正反器到正反器路徑的建立時間與保持時間餘裕及最高時脈頻率MOSFET I-V 特性（ID–VDS）改變 Vth、W/L 與 λ，查看 ID–VDS 曲線與工作點：操作區、ID、gm 與 roADC SNR 與有效位元數（ENOB）由解析度、時脈抖動與過取樣計算 ADC 的 SNR 與有效位元數PN 接面的內建電位與空乏層寬度由摻雜濃度與逆向偏壓計算 PN 接面的內建電位、空乏層寬度、峰值電場與接面電容相位雜訊與 RMS 抖動的換算積分以 dBc/Hz 表示的相位雜訊曲線，求出時脈的 RMS 相位誤差與 RMS 抖動矽的電阻率與摻雜濃度換算矽的電阻率與摻雜濃度（n 型、p 型）互相換算，並顯示遷移率本質載子濃度的溫度相依性由溫度計算 Si、Ge、GaAs 的本質載子濃度 ni，輸入摻雜濃度還可得知轉為本質的溫度MOSFET 的臨界電壓由氧化層厚度、基板濃度、閘極材料、固定電荷與基板偏壓計算 MOSFET 的臨界電壓dB／dBm 換算工具dBm 與 mW、W 互換，計算負載上的電壓，並將 dB 換算成功率比與電壓比電阻色碼計算由色環讀出電阻值與誤差，或由電阻值查出色環分壓電路計算兩個電阻分出的電壓，以及接上負載時的電壓、電流與功耗LED 限流電阻計算由電源電壓、LED 順向電壓與電流，計算串聯電阻值與功耗RC 時間常數計算由電阻與電容計算時間常數、截止頻率與充放電比例邏輯電路模擬器放置邏輯閘與正反器並接線，切換開關即可觀察動作，還會自動產生真值表卡諾圖邏輯化簡工具在真值表或卡諾圖上點選輸入 0、1 或 X，即可求出最簡積之和與和之積，並以顏色標示分組合成電阻與合成電容計算電阻、電容器、電感串聯與並聯的合成值，以及接近目標值的 E24 兩顆組合運算放大器放大電路計算反相、非反相、差動放大電路的增益、dB、輸出電壓與飽和，以及接近目標增益的 E24 電阻組合影像・聲音・影片資料量計算工具由像素數與色彩深度計算影像、由取樣頻率與量化位元數計算聲音、由畫面更新率計算影片的資料量與位元率，也能計算壓縮後大小與傳輸時間狀態轉移圖工具由狀態轉移表繪製狀態轉移圖，並依輸入序列逐步追蹤狀態與輸出的變化。支援摩爾型、米利型與狀態最小化

元件

記憶體頻寬計算器由傳輸速率與匯流排寬度計算 DDR、LPDDR、GDDR 與 HBM 的峰值頻寬及有效頻寬能隙與發光波長換算能隙（eV）與發光波長（nm）互相換算，內建 Si、GaAs、GaN 等代表性材料

前段製程

微影解析度與焦深計算器由波長、NA 與 k1 求解析度（半間距）、焦深與間距分割數熱氧化層厚度（Deal-Grove 模型）以 Deal-Grove 模型由溫度、時間、乾式或濕式氣氛與晶面方位計算矽氧化層厚度與矽消耗量晶片內導線的 RC 延遲由金屬、線寬、厚度、間距、介電常數與長度，計算導線電阻與電容、分佈 RC 延遲，以及含驅動器與負載的延遲

後段製程與評估

每片晶圓晶粒數與良率計算器由晶圓直徑、晶粒尺寸與缺陷密度計算晶粒數、良率與每顆良品成本PDN 目標阻抗與去耦電容由電源電壓、容許漣波與電流步階求出目標阻抗，以及去耦電容的自諧振頻率與有效頻帶可用率計算工具由 MTBF 與 MTTR 求出可用率，並計算串聯、並聯與 n 中取 k 組合系統的可用率與每年停機時間

設計與產業

接面溫度與熱阻計算器由功耗與熱阻計算接面溫度、與 Tj(max) 的裕度及最大功率

電腦系統

阿姆達爾定律與平行加速比依阿姆達爾定律與古斯塔夫森定律，由平行比例與處理器數計算加速比與平行效率快取位址分割與平均記憶體存取時間由快取容量、快取行大小與相聯度計算標籤、索引、偏移位元數及平均記憶體存取時間CMOS 功耗（動態與靜態）由活動因子、電容、電壓、頻率與漏電流計算動態與靜態功耗，以及 DVFS 後的功耗進位轉換與二補數工具二進位、八進位、十進位、十六進位互相轉換，並顯示 8 至 64 位元的二補數與無號、有號值位元運算計算工具以二進位的位元排列確認 AND、OR、XOR、NOT，以及邏輯移位、算術移位與旋轉，支援 8～64 位元浮點數（IEEE 754）轉換工具將十進位數轉換為半精度、單精度、雙精度的位元串，並顯示實際儲存的值與誤差CRC 計算工具從字串或十六進位位元組計算 CRC-8、CRC-16、CRC-32 等，並逐步顯示多項式除法漢明碼計算工具將資料編成漢明碼，點選位元加入錯誤，確認以校驗子找出位置並更正的過程IP位址與子網路計算工具由IP位址與CIDR前綴長度或子網路遮罩，計算網路位址、廣播位址與主機數，並提供二進位顯示與子網路分割排隊理論計算器（M/M/1、M/M/c）由到達率、平均服務時間與服務台數量，計算 M/M/1 與 M/M/c 的使用率、平均等候時間、回應時間與排隊人數資料傳輸時間計算工具由資料量、線路速度與傳輸效率計算傳輸所需時間，並顯示位元組換算成位元的過程，以及在指定時間內傳完所需的線路速度密碼暴力破解時間計算工具由字元種類與長度求出組合數與熵，並估算暴力破解所需時間虛擬碼執行與追蹤工具執行以日本基本資訊技術人員考試科目 B 的虛擬碼撰寫的程式，逐行追蹤執行的行與變數的值SQL 練習工具在瀏覽器中執行 SQL 並確認結果，還能用 10 道練習題對答案排序演算法視覺化工具以長條圖逐步播放泡沫、選擇、插入、希爾、合併、快速、堆積共 7 種排序，並可比較比較次數與寫入次數戴克斯特拉演算法計算工具由邊的權重清單計算最短路徑與最短距離，並能以表格與圖逐步追蹤確定頂點的過程二元搜尋樹與堆積視覺化工具將依序插入值所建立的二元搜尋樹或堆積畫成圖，並顯示前序、中序、後序的走訪順序、搜尋路徑與堆積的陣列雜湊表計算工具以鏈結法、線性探測、二次探測、雙重雜湊顯示鍵放入雜湊表時的碰撞與儲存位置，並計算負載因子與平均探測次數時間複雜度（大O）比較工具以 O(log n)、O(n)、O(n log n)、O(n²)、O(2ⁿ) 等比較隨資料數而變的處理次數與時間，也能估算資料數改變時的處理時間逆波蘭表示法轉換工具將中序式轉換為逆波蘭表示法（後序式）與波蘭表示法（前序式），並顯示堆疊的動作、語法樹與計算過程分頁置換演算法計算工具由參考字串與頁框數，以表格顯示 FIFO、LRU、OPT、Clock 的分頁錯誤次數與頁框內容的變化CPU 排程計算工具由到達時間與執行時間，繪出 FCFS、SJF、SRT、循環分時、優先順序的甘特圖，並計算平均等待時間與往返時間要徑計算工具由作業的所需天數與前置作業，計算最早、最晚開始日、寬裕天數、要徑與整體天數，並以甘特圖顯示實獲值管理（EVM）計算工具由 PV、EV、AC 與完工預算，計算 SV、CV、SPI、CPI 與完工估算（EAC），並判斷進度落後與成本超支損益兩平點計算工具由營業收入、變動成本與固定成本計算損益兩平點營業額、變動成本率、邊際貢獻率、安全邊際率與達成目標利益所需的營業額，並以圖表顯示投資評估（NPV、IRR、回收期間）計算工具由初期投資、每年的現金流量與折現率，計算淨現值（NPV）、內部報酬率（IRR）、回收期間與獲利能力指數RAID 容量計算工具由磁碟數量與容量計算 RAID 0、1、5、6、10 的有效容量、容量效率、可承受幾台故障，以及遺失資料的機率混淆矩陣計算工具由 TP、FN、FP、TN 計算準確率、精確率、召回率、F1 分數、特異度、MCC 等評估指標CNN 輸出尺寸計算工具排列卷積層、池化層與全連接層，計算各層的輸出尺寸、參數數量與乘積累加運算次數
