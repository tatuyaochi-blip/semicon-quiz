實獲值管理（EVM）計算工具

計算以金額這個相同尺度管理專案進度與成本的實獲值管理（EVM）指標。輸入計畫中工作的價值、實際完成工作的價值與實際花費的成本，就能知道進度是否落後、是否超出預算，以及最後大概要花多少。

收藏與最近使用的工具只儲存在這個瀏覽器（localStorage）中。

目前的數值

BAC 請大於0，PV、EV、AC 請在0以上，已經過期間請在0～100%。

目前的狀況

時程偏差 SV = EV − PV
–
成本偏差 CV = EV − AC
–
時程績效指數 SPI = EV ÷ PV
–
成本績效指數 CPI = EV ÷ AC
–
完成比例 EV ÷ BAC
–

完工時的估算

EAC（目前的成本效率持續：BAC ÷ CPI）
–
EAC（剩餘工作依預算：AC + (BAC − EV)）
–
EAC（CPI 與 SPI 都有影響：AC + (BAC − EV) ÷ (CPI × SPI)）
–
完工尚需估算 ETC = EAC − AC
–
完工偏差 VAC = BAC − EAC
–
在預算內完成所需的效率 TCPI
–

ETC 與 VAC 是以目前成本效率持續時的 EAC（BAC ÷ CPI）為基礎計算。TCPI = (BAC − EV) ÷ (BAC − AC) 表示剩餘工作若以此效率完成，就能在預算內結束。圖表以通過「目前」PV 的折線表示計畫，以直線表示估算，是簡化的畫法。

什麼是實獲值管理

實獲值管理（EVM）是將專案工作的進度換算成金額，以相同尺度管理時程與成本的手法。到目前為止預定完成之工作的預算稱為計畫值（PV），實際完成之工作的預算稱為實獲值（EV），實際花費的成本稱為實際成本（AC）。只看完成率或只看支出金額，無法判斷是進度落後還是效率不佳，但比較這3個值就能兩者都知道。

偏差與績效指數

時程偏差 SV = EV − PV 為負，表示工作比預定落後。成本偏差 CV = EV − AC 為負，表示對已完成的工作花費了超過預算的成本。以比率表示的就是時程績效指數 SPI = EV ÷ PV 與成本績效指數 CPI = EV ÷ AC，小於1表示落後、超支。在「進度落後且超出預算」的例子中，PV 為500、EV 為400、AC 為450，因此 SV = −100、CV = −50、SPI = 0.8、CPI ≒ 0.89。

完工總成本的估算

完工估算（EAC）的公式，取決於認為今後的工作會以何種效率進行。若認為目前的成本效率會持續，EAC = BAC ÷ CPI；若認為到目前為止的超支是暫時的、剩餘部分會依預算進行，則 EAC = AC + (BAC − EV)。若認為為了趕上進度也會增加成本，則同時使用 CPI 與 SPI。範例中 BAC 為1000，若目前效率持續，EAC 為1125，預計超支125。

使用時的注意事項

EVM 數值的可靠程度，取決於工作的劃分方式（工作分解結構，WBS）與實獲值的量測方式。在工作進行中很難判斷「已完成一半」，因此會使用開始算50%、完成算100%（50/50規則）等規則。此外，SPI 在專案結束時必定趨近於1，因此在專案後期判斷時程時，要搭配要徑一起使用。

練習相關題目

在完工預算（BAC）為2,000萬日圓的專案中，某時間點的計畫值（PV）為800萬日圓、實獲值（EV）為600萬日圓、實際成本（AC）為750萬日圓。此時間點專案的狀況，下列何者正確？

  1. A時程落後（SPI = 0.75），成本也超出預算（CPI = 0.8）
  2. B時程落後（SPI = 0.75），但成本在預算之內（CPI = 1.25）
  3. C時程超前（SPI = 1.33），但成本超出預算（CPI = 0.8）
查看答案與解析

正確答案：A. 時程落後（SPI = 0.75），成本也超出預算（CPI = 0.8）

時程績效指數 SPI = EV ÷ PV = 600 ÷ 800 = 0.75，小於1，因此比預定落後（時程偏差 SV = EV − PV = −200萬日圓）。成本績效指數 CPI = EV ÷ AC = 600 ÷ 750 = 0.8，小於1，因此花費的成本多於已完成工作的預算（成本偏差 CV = EV − AC = −150萬日圓）。在實獲值管理（EVM）中，將實獲值（EV）同時與計畫值（PV）及實際成本（AC）比較，以同一個金額尺度評估進度與成本。

在完工預算（BAC）為1,200萬日圓的專案中，目前的計畫值（PV）為600萬日圓、實獲值（EV）為480萬日圓、實際成本（AC）為600萬日圓。假設今後目前的成本效率持續下去，完工估算（EAC）為下列何者？

  1. A1,320萬日圓
  2. B1,500萬日圓
  3. C1,725萬日圓
查看答案與解析

正確答案：B. 1,500萬日圓

成本績效指數 CPI = EV ÷ AC = 480 ÷ 600 = 0.8，預算1日圓的工作要花1.25日圓。若此效率持續，EAC = BAC ÷ CPI = 1,200 ÷ 0.8 = 1,500萬日圓，預計超出預算300萬日圓。1,320萬日圓是假設剩餘工作（BAC − EV = 720萬日圓）依預算進行的 AC + (BAC − EV) 的值。1,725萬日圓是假設成本與時程兩方面的效率都影響剩餘工作的 AC + (BAC − EV) ÷ (CPI × SPI) = 600 + 720 ÷ 0.64 的值。

常見問題

SPI 與 CPI 應該重視哪一個？

兩者都重要，但已知 CPI 一旦變差就不容易恢復，有助於及早估算完工時的預算超支。SPI 表示整個期間的落後，但落後的工作是否在要徑上，需要搭配時程計畫確認。

PV、EV、AC 的單位是什麼？

通常是金額，但有時也以工時（人日等）管理。只要這3個值與 BAC 的單位一致，計算方式都相同。

EV 比 PV 大，也可能超出預算嗎？

可能。即使完成了比預定更多的工作（SPI > 1），若花費的成本更多（AC > EV、CPI < 1），預算仍然超支。時程與成本要分開判斷。

考試中會怎麼出題？

日本的應用資訊技術人員考試與專案經理考試中，常出現由 PV、EV、AC 的數值或圖表判斷進度落後或成本超支的題目，以及計算完工估算的題目。
