投資評估（NPV、IRR、回收期間）計算工具

計算用來評估導入系統或設備投資是否值得的指標。把未來的錢視為比現在的錢價值低，折算成現值後與投資額比較。可同時確認淨現值（NPV）、內部報酬率（IRR），以及幾年能回本（回收期間）。

貨幣的時間價值與現值

現在的 100 萬日圓比 1 年後的 100 萬日圓更有價值，因為現在拿到就能拿去運用賺取利息，或投入其他投資。因此要以「折現率」把未來的現金流量折算成現在的價值（現值）再比較。折現率為 r 時，t 年後 C 的現值為 C ÷（1 + r）ᵗ。折現率 5% 時，1 年後的 105 與現在的 100 價值相同。

淨現值（NPV）

淨現值（NPV）是未來現金流量現值的合計減去初期投資。NPV 為正，代表該投資超過折現率所要求的報酬，值得執行；為負則不划算。在範例「初期投資 1,000、3 年分別為 300、400、500、折現率 5%」中，現值合計約 1,080.4，NPV 約為 80.4 的正值。單純相加是 1,200，可以看出折現後價值會變小。

內部報酬率（IRR）與回收期間

內部報酬率（IRR）是使 NPV 剛好為 0 的折現率，表示該投資每年能產生幾 % 的報酬。若 IRR 高於籌措資金的成本（資金成本）或公司要求的報酬率，就判斷值得投資。回收期間是現金流量累計達到初期投資所需的年數，計算簡單易懂，但缺點是不考慮回收後的現金流量與貨幣的時間價值。折現回收期間則以現值累計來計算回收期間。

IT 投資的評估

導入資訊系統時，會把減少人力、增加營收等效果估算成現金流量，再與導入費用和營運費用比較評估。效果中有像縮短作業時間這種容易換算成金額的，也有像提高顧客滿意度這種不易換算的，因此除了金額指標，也要一併考量質化的效果。比較多個方案時，也會使用規模不同也容易比較的 IRR 與獲利能力指數。

練習相關題目

投資1,000萬日圓導入業務系統後，預期今後3年每年年底可節省400萬日圓的費用。設折現率為年5%，1年後、2年後、3年後的現值係數（1 ÷ 1.05ⁿ）分別為0.952、0.907、0.864時，此投資的淨現值（NPV）最接近下列何者？

  1. A約89萬日圓
  2. B約143萬日圓
  3. C200萬日圓
查看答案與解析

正確答案：A. 約89萬日圓

將未來的效果換算為現值，為 400 × (0.952 + 0.907 + 0.864) = 400 × 2.723 = 1,089.2萬日圓。再減去投資額1,000萬日圓，淨現值約為89萬日圓，大於0，因此在折現率5%下可判斷值得投資。若不折現，以效果合計1,200萬日圓減去投資額則為200萬日圓（相對投資額為20%），但考慮金錢的時間價值，未來的400萬日圓價值低於現在的400萬日圓。

常見問題

折現率要怎麼決定？

一般使用借款或募資的成本（資金成本），或公司對該投資要求的最低報酬率（門檻報酬率）。風險越大的投資，使用越高的折現率。

NPV 與 IRR 的判斷會不同嗎？

比較規模或現金流量時點不同的方案時，NPV 較大的方案與 IRR 較高的方案可能不同。若重視能為公司增加多少價值，基本上以 NPV 判斷。

只看回收期間判斷可以嗎？

回收期間容易理解，可作為想盡早回收資金時的參考，但不考慮回收後取得的現金流量與貨幣的時間價值。一般建議與 NPV、IRR 一併使用。

考試會怎麼出題？

在日本的基本資訊技術人員考試、應用資訊技術人員考試等資訊類證照考試的策略領域中，會出現由折現率與各年現金流量求淨現值以比較投資方案，或求回收期間的題目。
