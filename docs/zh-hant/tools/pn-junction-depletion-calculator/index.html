PN 接面的內建電位與空乏層寬度

輸入 p 側與 n 側的摻雜濃度及逆向偏壓，即可依突變接面的空乏近似計算內建電位、空乏層寬度及其在兩側的分配、峰值電場與接面電容。可用數字看出空乏區如何隨摻雜與電壓變化。

內建電位與空乏層寬度

p 型與 n 型區域接觸時，邊界附近的電子與電洞會擴散並復合，留下由游離摻雜原子構成的空乏區。這些電荷形成內建電位 Vbi = (kT/q)ln(NA·ND/ni²)。以將區域內電荷密度視為定值的空乏近似求解帕松方程式，可得 W = √(2εs(Vbi + VR)/q × (1/NA + 1/ND))。以預設值 Si、NA = 10¹⁷ cm⁻³、ND = 10¹⁶ cm⁻³、VR = 0 V 計算，Vbi ≈ 0.774 V，W ≈ 0.332 µm。

空乏區向低摻雜側擴展

兩側的游離電荷必須平衡，因此 NA·xp = ND·xn，摻雜較低的一側空乏得較深。以預設值計算，空乏區向 n 側延伸 0.302 µm，向 p 側僅延伸 0.030 µm，接近單邊接面。電場在接面處達到峰值，Emax = qND·xn/εs = 2(Vbi + VR)/W，此處約為 46.6 kV/cm。在 5 V 逆向偏壓下，W 隨 (Vbi + VR) 的平方根增加至約 0.906 µm，Emax 則升至約 127 kV/cm。

接面電容與 C-V 量測

逆向偏壓下的空乏區如同兩側帶有電荷的平行板電容器，因此單位面積電容為 Cj = εs/W。預設值下約為 31.2 nF/cm²，在 5 V 逆向偏壓下降至約 11.4 nF/cm²。變容二極體就是利用這種隨電壓變化的電容。在單邊接面中，1/Cj² 與電壓呈線性關係，由其斜率可求出低摻雜側的濃度，因此 C-V 量測被用來分析摻雜分布。

材料差異與設計上的運用

能隙越寬、ni 越小的材料，內建電位越大：在相同摻雜下，Ge 約為 0.38 V，GaAs 約為 1.21 V。由於 ni 隨溫度急遽上升，接面升溫時 Vbi 會下降。當逆向偏壓使 Emax 接近臨界電場（Si 約為 3×10⁵ V/cm，依摻雜而異）時，就會發生累增崩潰。功率元件讓空乏區擴展到厚而低摻雜的漂移層中，以壓低電場並提高崩潰電壓；而兩側皆重摻雜時 W 變薄，會在低電壓下發生稽納穿隧崩潰。

練習 PN 接面題目

增大施加於PN接面的逆向偏壓時，空乏區的寬度會如何變化？

  1. A變窄
  2. B不變
  3. C變寬
查看答案與解析

正確答案：C. 變寬

在逆向偏壓下，外部電壓與內建電位同方向施加，載子被進一步拉離接面，因此空乏區會變寬。其寬度大致與 √(Vbi + V) 成正比，若V遠大於內建電位，例如電壓增為4倍時，寬度約變為2倍。空乏區變寬後，接面電容（C = εA/W）會變小，此特性被用於變容二極體。承受電場的寬度變大，也有助於確保耐壓。

在p側雜質濃度遠高於n側的PN接面（p+n接面）中，空乏區會如何擴展？

  1. A主要向雜質濃度低的n側擴展
  2. B主要向雜質濃度高的p側擴展
  3. C一定會在p側與n側均等擴展
查看答案與解析

正確答案：A. 主要向雜質濃度低的n側擴展

在空乏區兩側，離子化雜質的電荷量相等（NA·xp = ND·xn）。低濃度側為了得到相同的電荷，需要空乏的範圍較廣，因此在p+n接面中，空乏區大部分向n側擴展。因此耐壓與電容幾乎由低濃度側的濃度決定，計算時也可只以單側來近似（單側陡峭接面）。功率元件的低濃度漂移層就是利用這個特性來承受高電壓。

關於PN接面的內建電位（擴散電位）與兩側雜質濃度之間的關係，下列何者正確？

  1. A與雜質濃度無關，保持一定
  2. B雜質濃度越高越小
  3. C雜質濃度越高越大
查看答案與解析

正確答案：C. 雜質濃度越高越大

內建電位為 Vbi = (kT/q)·ln(NA·ND/ni²)，兩側雜質濃度越高則越大。由於是以對數方式作用，濃度增為10倍也只增加約60 mV，在矽中一般約為0.6～0.9 V。它無法用電壓計從外部量測（會被電極的接觸電位抵消），可作為順向電壓的參考，以及用於計算空乏區寬度。能隙越大的材料，ni 越小，Vbi 越大。

以接面面積A、空乏區寬度W、半導體介電常數ε表示逆向偏壓PN接面的空乏區電容（接面電容）C，下列哪個式子正確？

  1. AC = εA / W
  2. BC = εW / A
  3. CC = ε / (A × W)
查看答案與解析

正確答案：A. C = εA / W

空乏區的行為如同兩側累積電荷的絕緣層，因此與平行板電容器相同，可表示為 C = εA/W。在逆向偏壓下W變寬，電容就變小。例如在矽中，面積為100 µm見方、W = 1 µm 時，C ≈ 11.7 × 8.85×10⁻¹² × 10⁻⁸ ÷ 10⁻⁶ ≈ 1 pF。在高速電路中，這個電容會造成延遲，因此會縮小接面面積或降低濃度來減小它。

常見問題

p+n 接面的空乏區會往哪一側擴展？

幾乎全部擴展到低摻雜的 n 側。由 NA·xp = ND·xn，當 NA = 10¹⁹ cm⁻³、ND = 10¹⁶ cm⁻³ 時，99.9% 的空乏區位於 n 側，因此崩潰電壓與電容主要由較低的摻雜濃度決定。

逆向偏壓變為 4 倍時，空乏層寬度會如何變化？

W 與 (Vbi + VR) 的平方根成正比，因此當 VR 遠大於內建電位時，W 約變為 2 倍，接面電容約減半。在 Vbi 不可忽略的低電壓下，請先加上 Vbi 再比較。

本計算器可以用於順向偏壓嗎？

輸入負的 VR 時，電位會降為 Vbi − VF，可看出空乏區縮小。在大電流下空乏近似會變得不準確，而當 VF 達到 Vbi 時寬度變為零，公式便不再適用。
