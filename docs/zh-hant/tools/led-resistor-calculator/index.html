LED 限流電阻計算

計算與 LED 串聯的限流電阻值。也能確認選用市售電阻（E24 系列）時實際流過的電流、電阻的功耗，以及建議的額定功率。

輸入的條件會寫入這個頁面的網址，加入書籤或分享後，就能開啟相同的計算結果。收藏與最近使用的工具只儲存在這個瀏覽器（localStorage）中。

電源電壓不高於 LED 順向電壓的總和，LED 不會亮。請提高電源電壓或減少串聯的數量。

順向電壓會因 LED 的顏色、型號、電流與溫度而改變，請使用資料手冊上的數值。
