建立時間與保持時間

正反器要正確擷取資料，時脈邊緣前後有一段資料不可改變的時間。邊緣之前需要的時間稱為建立時間，邊緣之後需要的時間稱為保持時間。

資料到達太晚而無法滿足建立時間，就是建立時間違規，放慢時脈即可解決。資料太早變成下一筆而無法滿足保持時間，就是保持時間違規；這種情況即使降低時脈頻率也無法解決，必須加入延遲來修正。

動手確認：資料變化的時間點

以時脈邊緣為0，移動資料變成新值的時間（到達）與變成下一個值的時間，判斷是否滿足建立時間與保持時間。建立時間設為0.3 ns，保持時間設為0.2 ns。
