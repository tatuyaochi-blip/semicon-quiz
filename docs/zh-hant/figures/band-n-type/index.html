n型半導體的能帶圖

能帶圖是把電子可佔據的能量帶沿縱軸排列的圖。上方導帶的底部為Ec，下方價帶的頂部為Ev，兩者之差即為能隙Eg。在不含雜質的本質半導體中，費米能階大約位於能隙中央（本質費米能階Ei）。

在矽中摻入磷等施體後，導帶中的電子增加，費米能階往導帶一側上升。其位置為 EF − Ei = kT·ln(ND/ni)，室溫下濃度每增加10倍，就向導帶靠近約0.06 eV。p型則相反，會依受體濃度往價帶一側下降。

動手確認：施體濃度與費米能階

改變施體濃度，即可確認費米能階EF如何從本質費米能階Ei趨近導帶底Ec。條件為Si、300 K、ni = 1.0×10¹⁰ cm⁻³，以 EF − Ei = kT·ln(ND/ni) 計算（非簡併範圍 10¹⁴〜10¹⁹ cm⁻³）。
