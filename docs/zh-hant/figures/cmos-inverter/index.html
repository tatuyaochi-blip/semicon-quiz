CMOS反相器

CMOS反相器將電源側的pMOS與GND側的nMOS串聯，兩個閘極接同一個輸入。輸入為0時pMOS導通、nMOS截止，輸出為電源電壓（1）；輸入為1時pMOS截止、nMOS導通，輸出為0。

無論哪種狀態都有一個電晶體截止，因此電源到GND幾乎沒有電流流過，這正是CMOS功耗低的原因。不過在輸入切換的過程中，會有兩者同時導通的瞬間，產生貫穿電流。

動手確認：輸入電壓與輸出

將輸入電壓從0調到電源電壓，pMOS與nMOS的導通/截止與輸出電壓會隨之改變。右側圖表為輸入與輸出的關係（轉移特性）。條件為 VDD = 1.2 V、臨界電壓大小0.35 V、nMOS與pMOS驅動能力相同，以長通道平方律計算。
