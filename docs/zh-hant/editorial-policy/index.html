內容製作方針

半導體教室的題目、解析、名詞解釋、比較、圖解與計算工具，皆依照以下方針製作與檢視。

題目的製作方式

  • 正確答案只有一個：三個選項中只有一個是正確的。若題目問的是「最適當的選項」，解析中必須能清楚說明第二好的選項差在哪裡。
  • 註明條件：數值會附上溫度、電壓、材料、世代、標準版本等條件。會因條件而大幅變動的數值，以範圍表示。
  • 避免斷定：「必定」「總是」只在定義或物理定律成立時使用。經驗法則與業界慣例則寫成「一般而言」「作為參考」。
  • 註明時間點：市場規模、產品世代、價格等會隨時間變動的資訊，會註明是哪個時間點的資訊。
  • 計算題列出過程：計算題的解析會寫出計算過程，並讓正確答案的數值出現在解析中。

出處的處理

確認內容時，依下列順序優先採用資料。

  1. 標準（ISO、IEC、JEDEC、AEC、IEEE 等）
  2. 經同儕審查的論文與經典教科書
  3. 半導體製造商的技術文件
  4. 大學與研究機構的資料

對於付費標準等無法確認原文的內容，我們會避免斷定，並記錄為尚未確認的項目。

檢查與更正

題目與解析的製作與檢查會運用 AI，並對照上述基準確認內容。2026年10月，我們檢查了全部2,750題，並更正了其中71題的敘述（正確答案有誤的題目為0題）。

題目的正誤與數值，也會以程式進行機械式檢查（例如解析與正確答案的數值是否一致、各語言的數值寫法是否正確）。我們自行發現的錯誤，以及經指正後確認的錯誤都會加以更正，並記錄更正的內容與依據。若發現錯誤，請透過聯絡我們頁面告訴我們。

翻譯

原文以日文撰寫。其他語言的頁面是由日文原文翻譯而成，原文修改時，譯文也會一併修改。沒有譯文的題目，不會在該語言中出題。
