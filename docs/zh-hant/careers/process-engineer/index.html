製程工程師

在晶圓上製作電晶體與導線的前段製程中，負責薄膜沉積、蝕刻、微影等站點的條件設定與改善，並維持量產穩定的工程師。

工作內容

製程工程師負責在晶圓上製作電晶體與導線的前段製程，例如薄膜沉積、蝕刻、微影、離子佈植、CMP 等站點。多數情況下，一位工程師負責一個或幾個站點。主要工作是設定機台條件（配方，recipe），讓膜厚、尺寸與形貌達到目標，並在量產中監控變動、維持品質。當量測數據出現異常時，要找出原因並提出對策。在導入新產品或新製程時，也要規劃實驗，致力於擴大製程窗口。

合作對象與處理的事物

日常工作需要與設備工程師、負責前後站點的製程工程師、統整整體流程的製程整合工程師，以及良率與品質工程師合作。處理的事物包括：製造機台與其條件、膜厚與尺寸等量測數據、缺陷檢測結果，以及該站點的管制圖。在無塵室確認機台與晶圓的時間，與在辦公室分析數據、撰寫報告的時間比例，會依公司與負責的站點而不同。

需要的知識與技能

基礎是理解所負責站點的原理，例如電漿、化學反應、薄膜或光學。在此之上，處理變異所需的統計知識不可或缺，需要能運用 SPC（統計製程管制）與實驗設計（DOE），以少量實驗找出條件的影響。此外，一個站點的變更會影響前後站點與電性結果，因此了解電晶體結構與整個製程流程，能更快釐清原因。整理數據並清楚地向其他部門說明的能力也很重要。

從哪裡開始學

建議先透過「完整掌握製造製程」課程，掌握從晶圓到導線的整體流程。接著深入可能負責的站點所屬領域：形成圖形的站點看「微影」與「蝕刻」，成膜看「薄膜沉積（CVD與PVD）」，平坦化與清洗看「CMP與清洗」，摻雜則看「離子佈植」與「氧化與擴散」。製程管理所用的統計可在「良率與品質管理」領域學習，確認結果的方法則在「量測與分析」領域。第一次接觸半導體的人，請從「初次認識半導體」課程開始。

推薦課程

完整掌握製造製程依流程順序學習前段製程：晶圓、無塵室、氧化、微影、蝕刻、薄膜沉積、配線、量測與良率。初次認識半導體從半導體的原理，到電晶體、晶片的製造方法以及產業全貌，快速瀏覽一遍。推薦作為第一步。

常見問題

非理工背景或沒有經驗，可以成為製程工程師嗎？

一般來說，這個職務的徵才多以化學、物理、材料、電機等理工背景為前提。不過，也有公司會錄用其他領域出身或沒有相關經驗的人，在進公司後培訓。錄用條件依公司與時期而不同，請確認各職缺的說明。若能先自學各站點的原理與統計基礎，進公司後會更容易上手。

和設備工程師有什麼不同？

大致來說，製程工程師負責「對晶圓做什麼、怎麼做」（條件與結果），設備工程師負責「讓機台持續正常運作」（保養與裝機）。實務上兩者的界線有所重疊，常常需要一起調查異常的原因是出在機台還是條件。職責的劃分方式依公司而不同。

需要什麼證照嗎？

一般來說，成為製程工程師並沒有必備的執照或證照。有些職場會要求接受安全處理化學品與氣體的內部訓練，或依所處理的物質與設備，鼓勵取得相關資格。比起證照，通常更重視對製程原理與統計的理解，以及根據數據思考的能力。
