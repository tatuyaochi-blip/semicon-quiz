製程整合工程師

把眾多製程站點串接起來，組成讓元件整體能如預期運作的製造流程的工程師，在新世代製程與新產品導入時扮演核心角色。

工作內容

半導體製造是由薄膜沉積、微影、蝕刻、離子佈植等站點反覆多次組成的漫長流程。製程整合工程師負責設計整個流程，並確保各站點組合起來時，元件能達到目標的特性與良率。改變某一站點的條件，會影響前後站點與電性結果，因此需要從整體出發，決定最佳的組合。在導入新世代製程或新產品時，要訂定站點順序與目標值，評估試作結果，把製程推進到可以轉入量產的狀態。

合作對象與處理的事物

這個職務常居於各站點的製程工程師、打造特性的元件工程師、良率與品質工程師以及設計部門之間，扮演協調者的角色。處理的事物包括：記載站點順序與條件的製程流程（process flow）、做在晶圓上的評估用測試結構及其電性量測結果、剖面觀察影像、良率數據等。也可能參與交給設計人員的設計規則與 PDK（製程設計套件）的內容。量產開始後，若良率或特性的問題橫跨多個站點，也由他們統籌解決。

需要的知識與技能

比起深入鑽研單一站點，更需要廣泛理解所有站點的原理以及彼此如何串接。基本要求是能在腦中描繪從 STI（淺溝槽隔離）到電晶體、矽化物、導線的剖面結構。此外，還需要能從電性量測結果推斷可能出問題的站點。由於要整合眾多部門的意見並做出判斷，以根據進行邏輯說明、排定優先順序的協調能力也很重要。

從哪裡開始學

先透過「完整掌握製造製程」課程，依序學習前段製程的各領域。特別是「微影」「蝕刻」「薄膜沉積（CVD與PVD）」「離子佈植」「配線製程」，是建構製程流程不可缺少的基礎。製程如何影響元件特性，可在「MOSFET」與「先進電晶體（FinFET與GAA）」領域，或「深入了解元件」課程中學習。最後在「良率與品質管理」領域，掌握邁向量產的評估觀念。

推薦課程

完整掌握製造製程依流程順序學習前段製程：晶圓、無塵室、氧化、微影、蝕刻、薄膜沉積、配線、量測與良率。深入了解元件從物性基礎到電晶體、先進電晶體、功率與化合物半導體以及感測器，依序學習元件的原理。

常見問題

非理工背景或沒有經驗，可以成為製程整合工程師嗎？

這個職務同時運用整體製程與元件的知識，因此一般多以理工背景為前提。有些人是在擔任製程工程師或元件工程師後，運用經驗轉任；也有人是應屆畢業就被分派到這個職務，做法依公司而不同。無論哪種情況，起點都是大致理解各站點的原理與電晶體的結構。

和製程工程師有什麼不同？

製程工程師負責特定站點的條件與結果，深入鑽研該站點。製程整合工程師則負責站點組合的整體，以及最終的元件特性與良率。例如，由製程整合決定某個尺寸的目標值，再由製程工程師開發達成該尺寸的條件，可能是一種分工方式，但界線依公司而不同。

需要什麼證照嗎？

一般來說，沒有必備的執照或證照。重視的是對製程與元件的廣泛知識、從數據推斷原因的能力，以及與眾多部門協調的能力。學生時期若能接觸半導體製程或元件相關的實驗與研究，會更容易想像實際的工作。
