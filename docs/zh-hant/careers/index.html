半導體產業職務指南

半導體公司有製造、開發、設計、品質等各種工作。本指南依職務整理工作內容與值得先學習的領域，可用於求職、轉職或新職務的準備。

  • 製程工程師在晶圓上製作電晶體與導線的前段製程中，負責薄膜沉積、蝕刻、微影等站點的條件設定與改善，並維持量產穩定的工程師。
  • 設備工程師負責保養、故障排除與裝機，讓製造機台持續以規定性能運作的工程師。除了在晶圓廠工作，也有在設備商支援客戶工廠的工作型態。
  • 良率與品質工程師為了提高每片晶圓的良品比例（良率），透過數據與分析找出不良原因，並推動製程改善與品質穩定的工程師。
  • 元件工程師構思電晶體等元件的結構，量測並評估試作元件的電性，再整理成電路設計所用模型的工程師。
  • 製程整合工程師把眾多製程站點串接起來，組成讓元件整體能如預期運作的製造流程的工程師，在新世代製程與新產品導入時扮演核心角色。
  • 可靠度工程師透過加速試驗與失效機制分析，確認並保證產品在使用期間內不會故障、能持續運作的工程師。
  • 測試工程師開發以自動測試設備（ATE）確認晶圓與封裝後晶片是否符合規格的測試，在品質與測試成本之間取得平衡的工程師。
  • 封裝工程師負責封裝的設計與組裝製程，讓晶片與外部連接，並保護晶片免受熱、外力與濕氣影響的工程師，也處理整合多顆晶片的先進封裝。
  • 數位IC設計／驗證工程師以硬體描述語言設計邏輯電路，透過模擬確認正確性，再經過邏輯合成與時序分析，把設計做成晶片的工程師。
  • 類比IC設計工程師設計放大電路、AD/DA 轉換電路、電源電路等處理連續電壓與電流的電路，並考量到電晶體特性與佈局的工程師。
