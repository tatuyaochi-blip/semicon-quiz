設備工程師

負責保養、故障排除與裝機，讓製造機台持續以規定性能運作的工程師。除了在晶圓廠工作，也有在設備商支援客戶工廠的工作型態。

工作內容

設備工程師的工作，是讓無塵室中的薄膜沉積機台、蝕刻機台、曝光機台、清洗機台與搬運系統等，持續以規定的性能運作。主要內容包括：有計畫地更換零件與清潔的定期保養（PM）、讓停機的機台恢復生產的故障排除，以及從新機台進廠到性能確認的裝機。機台的稼動率直接關係到工廠的產能，因此分析故障趨勢、防止再發的改善也很重要。除了在半導體公司的晶圓廠工作，也有人在設備商擔任現場服務工程師，在客戶的工廠負責機台的安裝與保養。

合作對象與處理的事物

在工廠中，每天都要與設定機台條件的製程工程師，以及操作機台的生產部門人員合作，也經常與提供零件和保養服務的設備商工程師往來。處理的事物包括：真空幫浦、產生電漿的射頻電源、控制氣體流量的質量流量控制器（MFC）、固定晶圓的靜電吸盤、搬運機械手臂等零件，以及機台記錄的日誌與警報。有些機台會使用具毒性或可燃性的特殊材料氣體與化學品，因此遵守安全程序是工作的前提。

需要的知識與技能

機台結合了機械、電機、真空、控制與化學，因此廣泛的基礎知識很有幫助，例如真空與電漿的基本、電路與控制、管路與氣體的處理，以及機台日誌的閱讀方法。故障排除時，需要能從症狀縮小可能原因的範圍，再逐一確認的邏輯判斷能力。作業前，必須確實遵守安全的基本規定，例如切斷能源、避免機台誤動作的上鎖掛籤（LOTO），以及確認 SDS（安全資料表）。

從哪裡開始學

先在「無塵室與製造設備」與「環境安全」領域，掌握工廠環境與安全的基本。接著依可能負責的機台，學習「蝕刻」「薄膜沉積（CVD與PVD）」「微影」等領域，了解機台是用來做什麼的，與製程工程師的溝通也會更順暢。機台使用的氣體與化學品整理在「製程材料（氣體與藥液）」，確認機台狀態與加工結果的方法則在「量測與分析」領域。整體製程流程可透過「完整掌握製造製程」課程確認。

常見問題

非理工背景或沒有經驗，可以成為設備工程師嗎？

一般來說，機械、電機、電子等知識對這個職務很有幫助，也有在其他產業做過廠務設備維護或機械保養的人，運用這些經驗轉入。有些公司會錄用沒有相關經驗的人並在內部培訓，但錄用條件依公司與時期而不同。先學習電路、真空的基礎與安全觀念，進公司後會更快理解工作內容。

半導體公司的設備工程師，和設備商的現場服務工程師有什麼不同？

半導體公司的設備工程師，負責維持自家工廠中多種機台的運作，避免生產中斷。設備商的現場服務工程師，則是熟悉自家機台的專家，在客戶的工廠進行安裝、裝機、保養與故障排除，因此多半需要到所負責客戶的工廠工作。具體的工作方式依公司而不同。

需要什麼證照嗎？

一般來說，成為設備工程師並沒有必備的執照或證照。不過，依所處理的設備、氣體與作業內容，有時法規或公司規定會要求接受特定訓練或取得資格。需要哪些依國家與職場而不同，請向所屬單位確認。
