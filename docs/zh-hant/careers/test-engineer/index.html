測試工程師

開發以自動測試設備（ATE）確認晶圓與封裝後晶片是否符合規格的測試，在品質與測試成本之間取得平衡的工程師。

工作內容

測試工程師的工作，是建立確認製造出的晶片是否符合規格的測試，並讓它能用於量產。測試一般分為在切割前以晶圓狀態進行的晶圓測試（CP），以及封裝後進行的最終測試（FT）。他們開發在 ATE（自動測試設備）上執行的測試程式，決定量測電壓、電流、時序與功能的項目，以及合格與否的判定標準。既要確實抓出不良品，又要縮短每顆晶片的測試時間以降低成本，兩者兼顧正是展現功力之處。量產開始後，也會持續分析測試結果並加以改善。

合作對象與處理的事物

能測什麼取決於晶片的設計，因此要從早期就與電路設計人員合作，特別是負責 DFT（可測試性設計）的人員。測試結果也會用於良率分析，所以也要與良率與品質工程師合作。處理的事物包括：ATE、讓探針接觸晶圓上電極的探針卡、連接晶片與 ATE 的治具與電路板、測試程式，以及大量的測試結果數據。除了自家的測試產線，也可能與承接測試的 OSAT 合作推動量產。

需要的知識與技能

需要數位電路與類比電路兩方面的基礎。數位方面，了解掃描測試、ATPG（自動測試向量產生）與故障涵蓋率等觀念會很有幫助；類比方面，則要了解運算放大器與 ADC 特性的量測方法。此外，也需要撰寫測試程式的程式能力、精確閱讀規格書規格的能力，以及看出量測誤差與雜訊的能力。測試的遺漏會造成市場上的不良，過度測試則會增加成本，因此要有權衡兩者的觀點。

從哪裡開始學

先在「測試與檢查」領域，掌握晶圓測試、預燒測試、掃描測試等基本觀念。為了理解測試的對象，學習「邏輯電路」「類比與電子電路」「AD/DA轉換」等領域，就能明白要量測哪些項目、為什麼要量測。規格的讀法可在「規格書的閱讀方法」領域學習，測試結果的用途則在「良率與品質管理」領域。課程方面推薦「後段製程、品質與安全」與「電路、設計與記憶體」。

推薦課程

後段製程、品質與安全學習將晶片作為產品交付所需的知識：封裝與先進封裝、測試、可靠度、環境安全以及產業動向。電路、設計與記憶體從邏輯電路和類比電路，到 AD/DA 轉換、CPU、各類記憶體以及設計流程，學習晶片的內部與設計。

常見問題

非理工背景或沒有經驗，可以成為測試工程師嗎？

這個職務同時運用電路知識與程式能力，因此一般來說，具備電機電子或資訊相關知識的人較常成為錄用對象。軟體開發的經驗，在開發測試程式時有機會派上用場。錄用條件依公司與時期而不同，但先學好電路基礎與測試的觀念，能更快理解工作內容。

和設計驗證工程師有什麼不同？

驗證工程師在製造之前，主要以模擬等方式確認設計本身是否符合規格。測試工程師則是用設備確認製造出來的每一顆晶片，是否有製造時產生的缺陷。可以理解為前者找出設計的錯誤，後者找出製造的不良。

需要什麼證照嗎？

一般來說，成為測試工程師並沒有必備的執照或證照。實務上重視的是對電路的理解、撰寫測試程式的程式能力，以及分析數據並推動改善的能力。使用的 ATE 與程式寫法依職場而不同，多半是進公司後再學習。
