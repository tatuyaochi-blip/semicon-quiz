封裝工程師

負責封裝的設計與組裝製程，讓晶片與外部連接，並保護晶片免受熱、外力與濕氣影響的工程師，也處理整合多顆晶片的先進封裝。

工作內容

封裝工程師的工作，是把從晶圓切下的晶片與外部電路板做電性連接，並做成能保護晶片免受熱、外力與濕氣影響的形態。工作大致分為兩類：決定封裝結構與材料的設計開發，以及晶圓切割、晶粒接合、打線接合或覆晶連接、封膠等組裝製程的條件設定與量產維持。他們以模擬與評估確認產品的熱要如何散出，以及能否承受溫度變化所造成的翹曲與應變。把多顆晶片整合在一個封裝中的先進封裝，也是這個職務所處理的範圍。

合作對象與處理的事物

他們與晶片設計人員討論接腳配置與供電方式，與可靠度工程師討論溫度循環等試驗結果，與測試工程師討論最終測試的方法。也經常與封裝基板、封膠樹脂等材料供應商，以及承接組裝的 OSAT 合作。處理的事物包括：導線架、封裝基板、錫球、封膠樹脂、底部填充膠等材料，以及組裝設備、熱與應力的模擬，還有剖面觀察與 X 光檢查的結果。

需要的知識與技能

這個職務需要跨越材料、機械、熱與電機的知識。基本包括：不同材料熱膨脹差異所產生的應力、焊點等接合部的疲勞，以及依熱阻估算溫度上升等。處理高速訊號的產品時，也需要考量導線寄生成分與訊號品質的電性設計知識。有些職場會使用有限元素法等模擬。在先進封裝中，還需要 TSV（矽穿孔）、重佈線層（RDL）、混合鍵合等接近前段製程的微細加工知識。

從哪裡開始學

先在「封裝與構裝」領域，學習打線接合、覆晶、BGA 等基本結構與組裝流程。接著在「先進技術（3D構裝與小晶片）」領域，掌握連接多顆晶片的技術。影響封裝壽命的失效在「可靠度」領域，熱阻與 MSL 等規格在「規格書的閱讀方法」領域，組裝後的檢查則可在「測試與檢查」領域學習。整個後段製程可透過「後段製程、品質與安全」課程一併確認。

常見問題

非理工背景或沒有經驗，可以成為封裝工程師嗎？

材料、機械、電機等理工知識對這個職務很有幫助。電子零件組裝、印刷電路板、機構設計等相近領域的經驗，有機會派上用場。錄用與培訓沒有相關經驗者的方針依公司與時期而不同，請確認各職缺的說明。

和前段製程的製程工程師有什麼不同？

前段製程的製程工程師，負責在晶圓上製作電晶體與導線的站點。封裝工程師則負責從切下完成的晶片到做成產品為止的過程，主要課題是熱、機械強度與不同材料之間的接合。不過在先進封裝中，常在晶圓狀態下進行佈線與接合，兩者的界線正在接近。

需要什麼證照嗎？

一般來說，沒有必備的執照或證照。實務上重視的是材料與熱、機械的基礎，以及評估與模擬的經驗。有人會利用電子組裝或焊接相關的技能檢定來學習，但在錄用時的重視程度依公司而不同。
