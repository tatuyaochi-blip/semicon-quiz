功率半導體是什麼？電動車和家電轉換電力的原理

約 11 分鐘 · 更新：2026年10月23日

功率半導體是改變電的形式、調整送給馬達電量的半導體零件。它負責交流與直流的轉換、電壓的升降、馬達轉速的控制等。它讓大電流以極快的速度開關，藉此把電整理好，所以能減少浪費掉的熱。

這篇文章可以了解

  • 「轉換電力」是在做什麼（交流與直流、電壓、馬達的轉速）
  • 不把電變成熱丟掉，而是用快速開關來整理的原理
  • 主要零件（二極體、功率MOSFET、IGBT）的角色差異
  • 和計算用晶片的差異，以及SiC、GaN受到注目的原因

先備知識：不需要。如果知道電晶體是「用電來切換的開關」，會比較容易閱讀（「電晶體是什麼？」）。

生活中的例子：從充電器到新幹線

手機的充電器，會把插座的電轉成手機能接收的形式。家用插座送來的，是100多伏特的交流電（台灣是110伏特，日本是100伏特）。另一方面，手機接收的是電壓低得多的直流電。在這個轉換中擔任核心的零件，就是功率半導體。

直流電是一直朝同一個方向流動的電，電池放出來的就是這種。交流電是流動方向每秒來回50次或60次的電（台灣是60次）。交流電容易改變電壓，適合送到遠處，所以輸電和插座都使用交流電。

同樣的轉換，在生活周遭到處都有。

  • 冷氣、冰箱、洗衣機：很多機型會先把插座的交流電轉成直流電，再重新做成任意快慢的交流電，藉此改變馬達的轉速
  • 電動車：把電池的直流電轉成交流電，讓馬達轉動
  • 電車：把從架空線接收的電，重新做成驅動馬達用的交流電
  • 太陽能發電：把面板產生的直流電，轉成家裡能用的交流電

其中，把直流電轉成交流電的裝置，稱為逆變器（英文inverter）。「變頻冷氣」能改變轉速，靠的就是逆變器。

「轉換電力」是什麼意思

電壓是推動電的力道，電流是流動的電量。電每秒搬運的能量稱為電功率，以電壓乘以電流來表示。同樣的電功率，可以用「高電壓、小電流」或「低電壓、大電流」等不同形式來搬運。

功率半導體做的「電力轉換」，就是配合使用的設備，改變這個形式。大致可以分成下面4種。

轉換名稱例子
交流 → 直流整流充電器、家電的電源
直流 → 交流逆變器驅動馬達、太陽能發電
直流 → 電壓不同的直流DC-DC轉換器電腦內部、電動車
交流 → 頻率不同的交流（多半先經過直流）冷氣、電車

頻率是交流電每秒來回的次數。就像表格最後一列，常常會先轉成直流電，再重新做成交流電。

下圖大致畫出電動車裡的轉換。

電動車的電池，是數百伏特的直流電。也有像2019年保時捷「Taycan」這樣的800伏特級車款。逆變器會把這個直流電轉成交流電，讓馬達轉動。車燈和導航等設備用12伏特的直流電運作，所以也需要降低電壓的轉換。

踩煞車時，馬達會變成發電機。逆變器反向運作，把產生的交流電轉成直流電，送回電池。這稱為「再生」（再生煞車）。

原理①：不把多餘的電變成熱丟掉

例如，假設要把12伏特的直流電降到5伏特。最簡單的方法，是在中間放一個不容易導電的零件，把多出的7伏特變成熱丟掉。這時入口和出口的電流相同，能用上的最多只有12分之5，約42%。其餘都變成熱（本站計算）。

很多使用功率半導體的電源，採用另一種做法。用開關把12伏特以極快的速度反覆「接通、切斷」。讓接通的時間占全部的12分之5，平均下來就是5伏特。

切成小段的電，維持鋸齒狀是不能用的。要用能暫時儲存電、再一點一點放出的零件（電感和電容），把它變平滑。像這樣改變「開」的時間比例來調整輸出的方法，稱為PWM（脈衝寬度調變）。

這種方法產生的熱比較少，是因為開關損失的電功率，是「開關兩端的電壓」乘以「流過的電流」。「開」的時候有電流，但開關兩端幾乎沒有電壓。「關」的時候有電壓，但沒有電流。不管哪種狀態，相乘的結果都很小。

不過，損失的電功率不是零。即使在「開」的時候，開關也還留著一點點電阻。這稱為導通電阻，越小損失就越少。

另一種損失，發生在開與關切換的途中。因為在切換的一瞬間，電壓和電流會同時存在。這稱為切換損耗。切換次數越多，損耗越大，所以需要能快速切換的零件。損失的部分會變成熱，因此處理大電力的零件，一定要在散熱上下功夫。

用比喻來說

用熱丟掉的方法和用開關整理的方法，差別很像腳踏車的煞車和變速齒輪。下坡要壓低速度時，煞車會把多餘的衝勁變成熱丟掉。變速齒輪只是改變踩踏快慢和力道的組合，幾乎不會丟掉衝勁。使用功率半導體的轉換，目標就像齒輪一樣「改變形式，但不丟掉」。

比喻的限制：腳踏車的齒輪會一直平順地轉動，功率半導體卻是反覆把電切成小段再接起來。另外，實際的轉換在導通電阻和切換時，都會產生一點熱。這個比喻只表示「丟掉」還是「改變形式」的差別。

原理②：主要零件：二極體、功率MOSFET、IGBT

這裡把功率半導體代表性的3種零件，大幅簡化後介紹。

二極體：單向通行的閥門

二極體是只讓電流往一個方向通過的零件。它沒有用來操作的端子，只由電壓的方向決定通過或擋住。組合4個二極體，就能把來回流動的交流電，整理成單一方向的流動。這個作用稱為整流。在逆變器裡，它也負責在開關切斷的瞬間，替馬達的電流留一條出路。

功率MOSFET：能快速切換的開關

在「電晶體是什麼？」這篇文章介紹過的MOSFET，是只要在稱為閘極的電極加上電壓，就能開關的開關。把它做成能承受大電流和高電壓的，就是功率MOSFET。它的優點是切換非常快。矽做的功率MOSFET，主要用在數百伏特以下的充電器和電腦電源等。

IGBT：在高電壓下通過大電流的開關

IGBT（絕緣閘雙極電晶體）也和MOSFET一樣，用閘極的電壓來操作。不同的是，它在內部用電子和電洞（電子離開後留下的空位）2種粒子來搬運電。「開」的時候，2種粒子大量進入內部，讓電流容易通過。因此，即使是耐高電壓的零件，也能減少「開」的時候的損失。

相對地，在關掉時，電流會稍微拖個尾巴，切換比MOSFET慢。矽的IGBT，有到6,500伏特級的產品。它廣泛用在電動車的逆變器、電車、工廠的馬達、冷氣等。兩者的使用時機，整理在「IGBT與功率MOSFET的差異」的表格中。

原理③：用逆變器改變馬達的轉速

冷氣和電動車的馬達，很多會配合交流電的頻率轉動。只要能改變頻率，就能自由改變轉速。常見形式的逆變器，會讓6個開關依固定順序開關，做出任意頻率和大小的交流電。

沒有逆變器的冷氣，讓負責冷卻的裝置（壓縮機）以固定速度轉動，靠反覆停止和啟動來維持溫度。如果能用逆變器改變轉速，房間變涼之後，就能慢慢地持續轉動。這就是「變頻冷氣」。東芝在1980年推出商用、1981年推出家用的這種冷氣，是世界上首次量產。那是室內機和室外機分開的形式。這項成就在2020年，獲電機電子學會IEEE認定為「里程碑」。

在電動車上，逆變器會配合油門的踩法，改變頻率和電壓的大小。藉此細緻地調整馬達的轉速和力道。

和計算用晶片的差異：重點不是縮小，而是「承受」

CPU這類計算用的晶片，是把在1伏特左右的低電壓下運作的小電晶體，排上幾十億個。電晶體做得越小，能放的數量越多，性能也越高（「「2奈米」是什麼的長度？」）。

功率半導體的目標不一樣。它要承受數十伏特到數千伏特的高電壓，並以很少的損失通過大電流。因此，決定性能的不是縮小的競賽，而是材料、構造和散熱方式的設計。

要承受高電壓，得用一層不容易導電的厚層來擋住電壓。電壓越高，這一層就要越厚。在很多功率半導體裡，電流會從晶片的表面往背面，縱向穿過這一層。晶片的整個面積都能當作電流的通道，所以能通過大電流。

用比喻來說

厚層有點像河川的堤防。水位越高的河川，擋水的堤防就要做得越厚、越堅固。功率半導體也是，要擋住的電壓越高，就需要越厚的一層。相似的只有「推力越強，擋住它的部分就要越厚」這一點。

比喻的限制：堤防不讓水通過，但功率半導體的厚層，在「開」的時候會變成電流的通道。這一層越厚，電流越難通過，損失也越大，這是個難題。減輕這個難題的，就是下一節的材料。

SiC與GaN：為什麼新材料受到注目

功率半導體大多是矽做的。這幾年在新聞中常看到的，是SiC（碳化矽）和GaN（氮化鎵）這兩種材料。

差異的根源，是材料裡的電子要能自由移動，必須越過的「台階」有多高。這稱為能隙（詳見「半導體是什麼？」）。SiC和GaN的台階，約是矽的3倍。這樣的材料，稱為寬能隙半導體。

台階高的材料，即使加上很強的電場（推動電的力），也不容易損壞。在東芝資料的表中，SiC和GaN能承受而不損壞的電場強度，約是矽的10倍。因此，同樣的電壓，用薄得多的一層就能擋住。層薄，電流就容易通過，所以能減少「開」的時候的損失。

台階高，即使變熱，電子也不容易自己越過台階，所以在高溫下也能確實擋住電。SiC傳熱的能力也約是矽的3倍，是容易散熱的材料（GaN和矽差不多）。不過，產品實際能使用的溫度上限，也會受到封裝等因素影響。

SiC：用於高電壓和大電力

SiC主要做成600伏特級以上的MOSFET和二極體。它不會像矽的IGBT那樣讓電流拖尾巴，所以也能減少切換損耗。在電動車的逆變器、快速充電器、太陽能發電的轉換裝置等，它開始取代矽的IGBT。

電裝（DENSO）在2023年，開發出公司第一款使用SiC的逆變器，搭載在Lexus的電動車「RZ」上。根據該公司的說法，在特定條件的測試中，損失降到矽的一半以下。2020年開始營運的新幹線N700S，驅動裝置也使用SiC，讓車底的設備變得更小更輕。

弱點是價格。SiC在一般壓力下不會變成液體，所以無法像矽那樣，從熔化的液體中把晶體拉出來。主要的方法，是在超過2,000℃的高溫下讓原料變成氣體，在當作種子的晶體上一點一點堆積長大。因此很費工夫和時間（根據三菱電機的說明資料）。

GaN：以極快的切換做到小型化

GaN的功率半導體，很多是在矽的基板上長出GaN的薄膜來製作。它以數百伏特以下的用途為主，特色是切換非常快。

增加切換次數，就能把撫平鋸齒狀的電感、改變電壓的變壓器做小。因為每次儲存再放出的電量變少了。手掌大小的小型充電器使用GaN，就是這個原因。資料中心的伺服器電源，也有使用GaN。

GaN也是藍光LED的材料。發明高效率藍光LED的赤崎勇、天野浩、中村修二3人，獲得了2014年的諾貝爾物理學獎。

矽能便宜地大量製造，所以現在仍被廣泛使用。這3種材料，依電壓、速度和價格分別使用。差異整理在「SiC與GaN的差異」「Si與SiC的差異」的表格中。

日本與功率半導體

日本有許多開發、製造功率半導體的公司。2023年12月，日本經濟產業省核准了羅姆（ROHM）和東芝的集團子公司共同推動的增產計畫。羅姆重點投資SiC，東芝方面重點投資矽的功率半導體，並互相使用對方的生產能力。國家的補助最多1,294億日圓。

常見的誤解

誤解：功率半導體也和CPU一樣，「幾奈米」做得越小性能越高

實際上，為了承受高電壓，需要厚的層和大的面積。決定性能的是材料、構造和散熱方式。新聞裡兩者都叫「半導體」，所以容易用同一把尺來衡量。

誤解：SiC和GaN總有一天會取代所有矽的功率半導體

實際上，它們依用途分別使用。SiC損失小，但價格高；GaN以數百伏特以下的用途為主。矽的MOSFET和IGBT能便宜地製造，所以現在仍用在許多設備上。新材料的話題比較顯眼，容易讓人覺得會一口氣全面取代。

誤解：變頻冷氣裡的逆變器（inverter），和把0與1反過來的電路是同一種東西

實際上，它們只是英文名稱相同，是不同的東西。把0和1反過來的邏輯電路（NOT閘），英文也叫inverter，中文稱為「反相器」。在電力領域，把交流電轉成直流電稱為「整流」，反過來把直流電轉成交流電稱為「逆變」。做逆變的裝置就是逆變器。兩者的英文都來自「反轉」的意思，所以容易混淆。
