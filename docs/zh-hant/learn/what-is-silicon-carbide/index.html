碳化矽（SiC）是什麼？改變電動車電力轉換的半導體

約 11 分鐘 · 更新：2026年10月23日

碳化矽（SiC）是矽和碳以1比1結合而成的結晶半導體。它能承受的電場（推動電的力量）約是矽的10倍，所以用很薄的一層就能擋住高電壓。因此，在轉動電動車馬達的裝置等地方，可以減少損耗和熱。缺點是結晶很難長，價格也高。

  • SiC有什麼特別之處，能帶來什麼好處（用薄層承受高電壓）
  • SiC的MOSFET和矽的IGBT如何分工
  • 結晶難做、價格高的原因，以及業界的動向

先備知識：如果知道功率半導體是「快速開關電、藉此改變電的形式的零件」，會比較容易閱讀（「功率半導體是什麼？」）。

生活中的例子：從研磨材料到電動車

SiC其實不是新的物質。1891年，美國的艾奇遜（Acheson）在電爐的實驗中偶然發現了它。因為非常硬，它以「金剛砂（Carborundum）」之名，作為切削、研磨東西的研磨材料普及開來（美國電化學學會的介紹）。

讓它以半導體身分廣為人知的契機，是電動車。根據2018年報導的拆解調查，特斯拉「Model 3」的馬達用裝置裡，有24個SiC零件。製造商是意法半導體（STMicroelectronics）。這個裝置是把電池的直流電轉成馬達用交流電的逆變器。

到2026年為止，SiC主要用在下面這些地方。

  • 電動車的逆變器：在搭載高電壓電池的車上，好處特別大。英飛凌（Infineon）在2021年，推出了這類車用的SiC功率模組。採用它的韓國現代汽車（Hyundai）表示，可行駛的距離比用矽時增加了5%以上
  • 車載充電器和快速充電器：用在把家用插座的交流電轉成電池用直流電的車內充電器，以及充電站內部的轉換（羅姆的資料）
  • 太陽能發電：用在把太陽能板的直流電，轉成家庭或電網使用的交流電的裝置。Cree在2011年推出的SiC MOSFET，也把它列為主要用途
  • 鐵路：以日本為例，三菱電機在2014年宣布，接到小田急電鐵車輛用、全部以SiC製成的逆變器訂單。新幹線N700S的例子，在「功率半導體是什麼？」中有介紹

SiC是什麼樣的材料？

SiC是矽（Si）原子和碳（C）原子以相同數量交互結合而成的結晶。矽和碳的結合非常強，所以結晶非常硬。以硬度的指標莫氏硬度來看約為9.5，接近最硬的鑽石的10。

SiC有許多原子組合相同、但排列方式不同的結晶。差別在於堆疊原子層時，錯開位置的順序不同。這種像兄弟一樣的結晶，稱為「晶體多型」。SiC已知的晶體多型有200種以上。

用在功率半導體的，是每4層重複一次相同堆法的4H-SiC。「4」代表4層，「H」代表六角形（英文的hexagonal）。排列方式不同，電子移動的難易度也會不同。4H-SiC的電子比較容易移動，方向造成的差異也小，所以被選用。

原理①：和矽比較的3個數字

材料的性格，可以用3個數字來掌握。各數字的意思已在「功率半導體是什麼？」中說明，這裡只把數字並排列出（根據東芝電子元件及儲存裝置公司的資料）。

項目矽4H-SiC有什麼作用
電子開始移動所需跨越的台階（能隙）1.12 eV3.26 eV變熱時也容易擋住電
不損壞所能承受的電場約0.3 MV/cm約2.8 MV/cm用薄層承受高電壓
導熱能力約1.5 W/(cm·K)約4.9 W/(cm·K)熱容易散到晶片外

eV（電子伏特）是台階高度的單位。MV/cm表示「每1公分厚度能承受幾百萬伏特」，W/(cm·K)表示導熱的難易度。和矽相比，SiC的台階約3倍，能承受的電場接近10倍，導熱能力約3倍。最關鍵的是第2個：能承受的電場。下一節會看到，它會大幅改變零件裡一層重要結構的厚度。

原理②：用薄層承受高電壓

功率半導體裡，有一層刻意做得不太導電的厚層。關閉時用這一層承受高電壓，導通時電流則縱向穿過這一層。這一層稱為「漂移層」。

能承受的電壓，大致與「能承受的電場」和「層的厚度」的乘積成正比（這裡做了簡化）。能承受的電場約是10倍，同樣的電壓只要約10分之1的厚度就能擋住。以1,200伏特單純計算，矽約80微米，SiC約9微米。1微米是1毫米的1000分之1。

好處不只是層變薄而已。層裡會混入少量雜質，用來增加運送電的電子。雜質越多，層就越不耐電場。但SiC本來就很強，所以能混入多得多的雜質。層薄、電子又多，導通時的電阻（導通電阻）就會大幅下降。在能承受相同電壓的層之間比較，理論上是矽的數百分之一（羅姆的說明）。

電阻小，流過相同電流時產生的熱就少。熱少了，冷卻裝置就能做小，整個機器也會變得更小更輕。不過，實際能使用的溫度上限，也取決於包住晶片的封裝等材料。

原理③：SiC的MOSFET和矽的IGBT如何分工

用矽處理像轉動馬達這樣的高電壓、大電流時，過去主要使用IGBT。因為在矽的MOSFET（用電壓開關的電晶體）裡，厚漂移層的電阻會變得太大。IGBT讓電子和電洞（電子離開後留下的空位）兩種粒子充滿這一層，藉此降低電阻。

相對地，IGBT在關閉時，要等層裡殘留的粒子跑掉，電流才會停下，所以會拖一點尾巴。這稱為尾電流，每次切換都會造成損耗。因此，IGBT一般用在每秒切換數萬次（數十千赫）左右以下的場合。

如果用SiC，漂移層很薄，即使是1,200伏特等級，MOSFET的電阻也能做小。MOSFET只靠電子運送電流，所以沒有尾電流。美國的Cree（現在的Wolfspeed）在2011年1月，發表了1,200伏特的SiC MOSFET。該公司稱之為「首款商用產品」。

場合主要零件選擇的理由
400伏特級電池的電動車矽的IGBT、650～750伏特級的SiC兩者都有人用。比較價格和效率
800伏特級電池的電動車1,200伏特級的SiC MOSFET電壓越高，SiC的好處越大
數千伏特、大電流（電車、工廠、輸電）多為矽的IGBT。也有3,300伏特級的SiCIGBT勝在實績和價格。重視節能時用SiC

表格只是大致的參考。實際上，會比較零件的價格，和減少損耗所得到的好處來選擇。SiC零件即使比較貴，如果能把冷卻裝置或電池做小，以整台車來看有時反而划算。差異的表格整理在「Si與SiC的差異」「IGBT與功率MOSFET的差異」。

為什麼SiC難做又昂貴？

從氣體長出結晶

矽的結晶，是從熔化的液體中往上拉而長成的（「矽晶圓是什麼？」）。SiC在一般壓力下不會變成液體，而是從固體直接變成氣體。固體不經過液體、直接變成氣體，稱為「昇華」。

所以，SiC是利用昇華來長晶。在石墨容器的底部放入原料SiC粉末，在蓋子內側貼上當作晶種的結晶。把容器加熱到2,100～2,500℃，粉末就會變成氣體。氣體在溫度稍低的晶種上變回固體，依照和晶種相同的排列一層層堆積。這種長晶方法稱為「昇華法」，也稱為物理氣相傳輸法（PVT）（根據2024年的論文）。

這個方法的源頭，是蘇聯的Tairov和Tsvetkov在1978年提出、使用晶種的昇華法。結晶生長的速度，每小時約0.3～0.8毫米。如果想加快，結晶就容易出現缺陷，或混入其他排列方式的結晶（2024年的論文）。以這個速度，光是長幾公分就要好幾天（本站的計算）。

用比喻來說

昇華法有點像冷凍庫壁上結的霜。霜是空氣中的水蒸氣不經過液態的水，直接在冰冷的壁上變成的冰。昇華法也一樣，變成氣體的SiC，會在溫度稍低的晶種上直接變回固體。相似的只有一點：「氣體在冷的地方直接變成固體」。

比喻的限制：霜是小冰粒朝各個方向聚集而成的。昇華法則是延續晶種的原子排列，長出一整塊大結晶。溫度也不同，霜在0℃以下，SiC則是超過2,000℃的世界。

結晶裡的缺陷

從氣體長出的結晶，容易出現原子排列的錯位。長久以來的大問題，是縱向貫穿結晶、像細管一樣的孔洞。這稱為「微管缺陷」，做在它上面的零件容易損壞。經過改良，高品質的結晶已降到每平方公分不到1個。

現在仍需注意的，是沿著原子層橫向出現的排列錯位。這稱為「基面差排」。電流流過SiC MOSFET裡當作二極體運作的部分時，電子和電洞相遇後會消失。這時放出的能量，有時會讓這種錯位擴大。

擴大的錯位，會變成層的堆疊順序亂掉的面。這稱為疊差（也稱堆疊缺陷）。疊差不容易導電，所以使用一段時間後，導通時的電壓會上升。對策之一，是在底部的結晶和零件的層之間，夾入一層抑制錯位危害的層。

很硬，切割和研磨都很費工

長好的結晶要切成薄片，再磨成像鏡子一樣，做成晶圓。SiC的硬度接近鑽石。即使用附著鑽石顆粒的線鋸或砂輪也很花時間，工具也會磨損。它雖然硬卻很脆，所以邊緣容易缺角，表面下方也容易出現看不見的損傷。

在磨好的晶圓上，會以超過1,500℃的溫度，從氣體原料長出漂移層等零件用的層。這是延續底部結晶的排列，長出一層薄結晶的技術。這稱為磊晶成長，這一步也需要設法減少結晶的缺陷。

晶圓不容易做大

SiC晶圓長期以直徑150毫米為主流。和矽最大的300毫米相比，面積只有4分之1。意法半導體在2021年7月，宣布做出了試作用的直徑200毫米晶圓。該公司表示，200毫米可用的面積幾乎是150毫米的2倍，能取得的良品晶片是1.8～1.9倍。

工廠也正逐漸轉向200毫米。Wolfspeed在2022年4月，於美國紐約州啟用了200毫米工廠。英飛凌也在2024年8月，於馬來西亞啟用了200毫米工廠的第一期。意法半導體也在2024年5月，宣布了在義大利興建200毫米工廠的計畫（預計2026年開始生產）。2026年1月，Wolfspeed宣布做出了直徑300毫米的單晶晶圓，但還沒有進入量產。

和閘極薄膜的交界

MOSFET在叫做閘極的電極和電子的通道之間，夾著一層像玻璃一樣的薄膜（「電晶體是什麼？」）。SiC也能讓表面氧化，做出和矽一樣的氧化膜。但是，SiC和薄膜的交界處，容易殘留很多捕捉電子的「陷阱」（界面能態）。

陷阱一多，通道裡的電子就不容易移動。移動的難易度，往往只有結晶內部的10分之1以下。陷阱捕捉或放開電子時，開關開始導通的電壓（臨界電壓）也會一點一點偏移（2021年的論文）。製造商在薄膜的做法上下工夫，並反覆進行確認能否長期使用的測試。

業界動向：從結晶到零件都自己做

在SiC領域，晶圓的品質和數量，左右著零件的性能和價格。因此，大廠一直設法在自家集團內，包辦從長晶到零件的工作。羅姆在2009年買下德國的SiCrystal，意法半導體在2019年買下瑞典的Norstel。安森美（onsemi）也在2021年11月，買下負責長晶的美國GT Advanced Technologies。

SiC晶圓和零件的大廠，是美國的Wolfspeed。過去也做LED等產品的Cree，把事業集中在SiC，並在2021年10月改了公司名稱。2025年6月30日，它為了減少負債，依照美國《破產法》第11章申請了重整程序。這是讓公司繼續營運、同時整理債務的制度。同年9月完成程序，並宣布負債減少了約7成（該公司的公告）。

其他還有英飛凌、三菱電機、東芝、電裝（DENSO）等公司在生產SiC零件。羅姆和東芝集團子公司的增產計畫，在「功率半導體是什麼？」中有介紹。

常見的誤解

誤解：電動車已經全部都用SiC了

實際上，使用矽IGBT的車也很多。在400伏特級的車上使用的650伏特級零件，IGBT通電時的損耗也很小，價格也便宜。特斯拉在2023年3月也表示，新的平價車款用的驅動裝置，會把SiC的用量減少75%。該公司表示，性能不會變差。因為SiC的話題很搶眼，容易讓人以為已經全面替換了。

誤解：SiC和GaN幾乎是一樣的材料

實際上，兩者只是台階大小相近，做法和擅長的場合都不同。SiC是在同樣是SiC的晶圓上，做電流縱向流動的零件。GaN大多是在矽晶圓上長出薄膜，做電流沿著表面橫向流動的零件。SiC擅長600伏特級以上的大電力，GaN擅長數百伏特以下的高速切換（「氮化鎵（GaN）是什麼？」）。兩者常被一起介紹為「次世代功率半導體」，所以容易混淆。

誤解：SiC是最近才發現的新材料

實際上，它從1891年起就被當作研磨材料生產。英飛凌在2001年推出SiC二極體，Cree在2011年推出SiC MOSFET。花了很長時間的，是做出缺陷少到能用在零件上的大結晶的技術。新的不是物質，而是製作方法。

SiC的優點和缺點，來自同一個根源。原子之間的結合很強，所以它耐電場也耐熱。也正因為這份強度，它不易熔化又很硬，長晶和加工都很費工。
