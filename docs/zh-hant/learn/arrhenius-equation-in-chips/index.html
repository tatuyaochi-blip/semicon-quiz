阿瑞尼斯方程式是什麼？溫度讓反應和故障快幾倍

約 11 分鐘 · 更新：2026年10月23日

阿瑞尼斯方程式，是表示化學反應和零件的劣化，會因溫度變快幾倍的式子。能越過反應所需「能量之牆」的原子或分子比例，會隨溫度急遽增加，所以速度對溫度呈指數變化。在半導體中，它用在氧化膜的成長、雜質的擴散，以及把晶片放在高溫下試驗來估算壽命的計算。

這篇文章可以了解

  • 溫度只要稍微上升，反應就會快很多的原因
  • 阿瑞尼斯方程式的意思，以及活化能的讀法
  • 高溫的試驗相當於實際使用幾年的計算（加速因子）
  • 在半導體的製程和可靠度試驗中，這個式子出現的地方
  • 這個式子不能用的情況

先備知識：指數（以10倍、100倍這樣按位數增加）和對數的大概意思。式子會先用文字說明，再列出來。

生活中的例子

把食物放進冰箱，就能放得比較久。因為讓食物變質的化學反應和微生物的活動，溫度越低就越慢。反過來，在炎熱的夏天，同樣的食物會壞得快很多。

半導體晶片也會隨著時間一點一點劣化。不過，在一般的使用方式下，要好幾年才會壞。所以廠商會讓晶片在125 ℃左右的高溫下持續運作，刻意加快劣化來調查。計算高溫下的1000小時，相當於平常溫度下的幾年份時，用的就是阿瑞尼斯方程式。

在製造晶片的工廠裡，溫度也是重要的「旋鈕」。在矽的表面長出膜，或讓摻入的原子擴散開來的製程，是在1000 ℃左右的爐子裡進行的。溫度只要稍微改變，完成後的厚度和深度就會大幅改變。

原理1：決定速度的是「能越過牆的粒子」的數量

物體裡的原子和分子，總是在細微地振動或四處飛動。溫度是這種振動激烈程度的指標。不過，並不是所有粒子都以相同的力道運動，有慢的粒子，也有非常有力的粒子。

要發生反應，或讓原子移到旁邊的位置，途中必須經過一次能量較高的狀態。就像不越過山，就到不了旁邊的山谷。這座山的高度稱為活化能（Ea）。能越過山的，只有碰巧擁有很大能量的極少數粒子。

山的高度，多半用eV（電子伏特）這個單位表示。1 eV是1個電子被1伏特的電壓推動時得到的能量。在半導體的劣化和反應中，山的高度約為零點幾 eV到數 eV。

溫度不是用平常的℃，而是用絕對溫度來思考。絕對溫度是℃的值加上273.15，單位是K（克耳文）。這是以粒子振動最小的溫度為0 K的刻度，所以大致和振動的激烈程度成正比。

熱造成的振動大小，用絕對溫度T乘上常數k的「kT」來表示。k是波茲曼常數（約8.617×10⁻⁵ eV/K），是把溫度換算成能量的係數。在25 ℃（298 K）時，kT約為0.026 eV。

重要的是，山的高度是kT的幾倍這個比值。根據熱的物理學（統計力學），能量每高出1個kT，能到達那裡的粒子數量就減為約2.7分之1。如果山的高度是kT的3倍，就是把2.7分之1乘3次，約20分之1。這裡為了簡化，省略了細部的係數。

同樣的比例要乘很多次，所以次數只要稍微增加，結果就會差好幾個位數。這就是指數函數的性質。2.7…這個數稱為e，「e的−3次方」寫成exp(−3)。能越過的比例的指標exp(−Ea/kT)，稱為波茲曼因子。

例如山的高度是0.7 eV時，在55 ℃，山的高度約為kT的25倍。等於把2.7分之1乘約25次，能越過的粒子約為560億個中有1個。在125 ℃，kT變大，比值降到約20倍。乘的次數只少了4次多，能越過的粒子就變成約7億個中有1個，也就是增加約78倍。用絕對溫度來看，只上升了2成而已。

用比喻來說

想像很多人各自朝著一根很高的橫桿跳。大部分的人都碰不到，能跳過去的，只有碰巧跳得特別高的極少數人。當所有人都能跳得稍微高一點，即使平均只上升一點點，跳過橫桿的人數也會增加好幾倍。因為起作用的，只有少數派的「頂端」。

比喻的限制：人能跳多高，幾乎由每個人的能力決定。原子和分子則是每次互相碰撞都會交換能量，有力的粒子不斷替換。而且人的跳躍能力的分布，並不符合波茲曼因子的形式。這個比喻只表現「只有頂端能越過」這一點。

原理2：用文字讀懂阿瑞尼斯方程式

反應的速度，可以想成「挑戰山的次數」乘上「能越過的比例」。挑戰的次數，不太會隨溫度大幅改變。速度隨溫度的變化，幾乎都來自能越過的比例，也就是波茲曼因子。

把這寫成式子，就是阿瑞尼斯方程式。把挑戰次數等合併成係數A，就寫成下面這樣。

速度 = A × exp(−Ea / kT)

教科書中，左邊的速度（速率常數）有時也用k這個字母，寫成 k = A·exp(−Ea/kT)。這2個k是不同的東西，右邊的k是波茲曼常數。

名稱來自瑞典的阿瑞尼斯。他在1889年研究酸讓砂糖（蔗糖）分解的反應的論文中，說明了這個式子的意思。化學教科書不是用1個粒子，而是用每1莫耳（固定數量的粒子集合）的能量，寫成 exp(−Ea/RT)。內容是同一個式子。

這裡把A和Ea當作不隨溫度改變的量。這是阿瑞尼斯原本形式的約定。實際上A有時也會隨溫度稍微改變，但和指數部分的變化相比，只是很小的差異。

原理3：從阿瑞尼斯圖讀出活化能

某個反應的活化能，只要在幾個溫度下測量速度就能求出。橫軸取絕對溫度的倒數（1/T），縱軸取速度的對數，畫成圖。這種圖稱為阿瑞尼斯圖。

這樣一來，測得的點會排成一條直線。式子指數的內容是「−Ea/k × 1/T」，所以把1/T當橫軸，再用對數拿掉指數，就變成單純的直線式。線的斜率越陡，活化能越大，是對溫度越敏感的反應。

就算不畫圖，只要知道2個溫度下的速度比，也能把下一節的計算反過來求出活化能。例如55 ℃和125 ℃的速度相差約78倍，活化能就約為0.7 eV。

點落在1條直線上，可以當作在測量的溫度範圍內，由同一種機制決定速度的指標。如果點在途中折彎，就表示換成了另一種機制。這一點會用在後面的「這個式子不適用的時候」。

從數字來看：125 ℃的1000小時是幾年份？

試驗溫度下的劣化，比使用溫度下快幾倍，稱為加速因子。這是用阿瑞尼斯方程式，把試驗溫度下的速度，除以使用溫度下的速度。A在除法中消掉，只由活化能和2個溫度決定。

加速因子 = exp[(Ea / k) × (1/T使用 − 1/T試驗)]

假設活化能是0.7 eV，計算在55 ℃使用的晶片，以125 ℃試驗的情況。

  1. 把溫度換成絕對溫度：55 ℃ = 328.15 K，125 ℃ = 398.15 K
  2. 倒數的差：1/328.15 − 1/398.15 ≈ 0.000536（1/K）
  3. Ea/k：0.7 ÷ 0.00008617 ≈ 8,120（K）
  4. 相乘約為4.35。e的4.35次方，加速因子約為78

也就是說，125 ℃下的1000小時，相當於55 ℃下約7萬8000小時，約8.9年份的劣化。這裡的溫度不是房間的溫度，而是運作中晶片內部的溫度（接面溫度）。晶片會因自己發的熱比周圍更熱，所以要先用接面溫度計算器估算再使用。

假設的活化能加速因子（55 ℃ → 125 ℃）125 ℃的1000小時相當於
0.3 eV約6.5倍約0.7年份
0.5 eV約22倍約2.6年份
0.7 eV約78倍約8.9年份
1.0 eV約500倍約57年份

如表所示，答案會因為活化能的假設而相差數十倍。該用哪個值，依劣化的原因（故障機制）而不同。業界團體JEDEC的文件JEP122，整理了各種原因的活化能和模型。原因不明時，常用0.7 eV當暫定值，廠商的可靠度資料中也有這樣的例子。這終究只是暫定值。

在半導體的哪些地方出現

熱氧化：氧化膜的成長速度

把矽放在高溫的氧氣中，表面就會長出氧化膜（SiO₂）。這稱為熱氧化。膜的成長方式，用1965年的Deal-Grove模型來表示。這個模型的2個常數，都遵循阿瑞尼斯方程式。

膜還薄的時候，和矽交界處的反應決定速度，活化能約2.0 eV。膜變厚之後，氧氣穿過膜的速度成為關鍵，用乾燥氧氣成長的乾式氧化約為1.2 eV。從1000 ℃升到1100 ℃，前者約變成3.8倍，後者約變成2.3倍。可以用熱氧化計算器改變溫度來確認。

雜質的擴散：原子擴散開來的速度

摻入矽中的硼或磷原子，在高溫下會在晶體中一點一點移動而擴散開來。利用這個性質摻入雜質的方法，就是熱擴散。表示擴散難易度的擴散係數D，也是 D = D0·exp(−Ea/kT) 這種阿瑞尼斯的形式。代表性的值，硼和磷約3.5～3.7 eV，砷約4 eV左右，比較大。

如果是3.5 eV，只要把1000 ℃提高到1100 ℃，擴散係數就會變成約10倍。所以工廠會管理在什麼溫度下加熱了幾分鐘的累積量（熱預算），也會使用只加熱極短時間的方法（爐管退火、RTA、雷射退火的差異）。實際的擴散也會受雜質濃度和晶體缺陷影響，所以這個式子只是出發點。

CVD：反應限制與供應限制

讓氣體原料在表面反應來鍍膜的方法，稱為CVD。在比較低的溫度下，表面的反應很慢，反應速度決定了鍍膜的速度。這稱為反應限制，速度正如阿瑞尼斯方程式，對溫度很敏感。

溫度升高、反應變得夠快之後，換成氣體送到表面的速度跟不上。這稱為供應限制，就算提高溫度，速度也不太會改變。在阿瑞尼斯圖上，線看起來會在途中折彎。在減壓下進行的CVD，大多用在容易讓整片晶圓膜厚一致的反應限制那一側。

可靠度試驗：HTOL與電遷移

讓晶片在高溫下、加上電壓持續運作的試驗，稱為HTOL。這是依據JEDEC規格JESD22-A108的試驗，廠商的可靠度資料中常見125 ℃、1000小時的條件。把結果換算成使用溫度下的年數，用的就是剛才的加速因子。

配線的金屬原子被流動的電子推著一點一點移動，最後讓配線斷掉的現象，稱為電遷移。它的壽命用Black方程式估算。這是把電流密度的項，和阿瑞尼斯形式的溫度項相乘的式子，活化能會因金屬的種類和原子移動的路徑而改變。

漏電流：熱產生的電子

應該關閉的電晶體或二極體，也會漏出微小的電流。其中一部分，是由熱在矽中產生的電子和電洞所搬運的，這也遵循波茲曼因子，隨溫度急遽增加。熱讓電子增加的原理，在「半導體是什麼？」中說明。

這時的「牆」，和能隙（矽約1.12 eV）有關。依漏電的機制不同，表觀的活化能約為它的一半，或幾乎相同（施敏的教科書）。純矽中由熱產生的電子數（本質載子濃度），從25 ℃到85 ℃約變成67倍。可以用本質載子濃度計算器確認。漏電流中和這個數成正比的部分，會增加差不多的倍數，和這個數的平方成正比的部分，則會增加數千倍。

這個式子不適用的時候

限制機制切換時：像CVD的例子那樣，決定速度的機制隨溫度範圍而替換時，就無法用1條直線表示。把低溫測得的直線延長到高溫，就會偏離。

原因不只一個時：實際的晶片有好幾種劣化原因，各自的活化能都不同。整體的故障率，要把各原因的故障率相加來估算。用1個值概括，會隨溫度而有很大的偏差。

溫度以外的因素有影響時：濕度和電壓也會加快劣化。濕度用Peck模型，電壓等溫度以外的條件用Eyring型的模型等，要組合其他的式子。施加濕度的試驗例子，就是HAST。

常見的誤解

誤解：「上升10 ℃速度變2倍」是物理定律

實際上，這是隨活化能和溫度而變的參考值。在室溫附近剛好變成2倍，是活化能約0.55 eV的時候。如果是0.7 eV，從25 ℃到35 ℃約2.4倍，從115 ℃到125 ℃約1.7倍。同樣是10 ℃，溫度越高，倍率越小。因為容易記，才去掉條件流傳開來。

誤解：試驗溫度越高，時間越短越好

實際上，溫度升得太高，會出現使用時不會發生的其他劣化。和CVD的折彎一樣，換成高溫時起作用的其他機制後，用加速因子換算回使用時的計算就不成立了。也有封裝材料承受不了的溫度。所以試驗溫度要配合規格和產品的使用方式，在和使用時相同機制起作用的範圍內決定。

誤解：活化能是那顆晶片固定的常數

實際上，它是每種劣化或反應機制的值。即使在同一顆晶片中，絕緣膜損壞的現象和配線斷掉的現象，值也不同。製程或材料改變，同一種現象的值也可能改變。因為0.7 eV這類單一數字很常用，看起來才像是晶片的性質。
