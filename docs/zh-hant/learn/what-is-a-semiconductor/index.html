半導體是什麼？導電性可以大幅改變的材料

約 10 分鐘 · 更新：2026年10月23日

半導體是一種導電性介於金屬（導體）與玻璃、橡膠（絕緣體）之間的材料。重點不在於「介於中間」，而在於只要加入極少量的雜質，或改變電壓、光線、溫度，就能大幅改變它的導電性。利用這個性質，可以做出讓電流導通或切斷的開關，所以半導體成了手機、電腦和汽車電子零件的基礎。

前提知識：國中理化（電流、電壓、原子與電子）的程度。不使用公式。

生活中的例子

手機裡有負責計算的零件、記住照片和聯絡人的零件，以及收發電波的零件。這些零件的核心，全都是用半導體做成的。相機中把光轉換成電訊號的零件也是半導體，稱為影像感測器。

在家裡，LED燈泡發光的部分、屋頂上的太陽能電池都是半導體。LED把電變成光，太陽能電池則把光變成電。冷氣和電動車裡，有能快速導通、切斷大電流的零件，負責調整送往馬達的電。這類零件稱為功率半導體。

新聞說「半導體短缺」「半導體工廠」時，「半導體」多半不是指材料本身。它指的是用半導體做成的零件，尤其是在小小的板子上塞滿電路的「晶片」。這些用法的差別，會在後半的「『半導體』一詞的3種意思」中整理。

「半導體」這個名稱的意思

物質可以依導電性，大致分成3類。銅、鋁這類金屬很容易導電，稱為「導體」。玻璃、橡膠、塑膠幾乎不導電，稱為「絕緣體」。半導體則是介於兩者之間的材料。英文的 semiconductor 也是「一半（semi）的導體（conductor）」的意思。

比較不同材料時，會看它們做成相同形狀、相同大小時，電流通過的困難程度。這個值稱為「電阻率」，單位是Ω·cm（歐姆·公分）。數值越小，代表材料越容易導電。銅和玻璃的主要成分二氧化矽（SiO₂）相比，電阻率相差約10的20次方倍（1後面接20個0）。

不過，如果記成「只導一半的電」，就會忽略半導體最重要的一點。如圖所示，純矽其實是相當不容易導電的材料。半導體真正的特點，是導電性可以從外部大幅改變。下一節就來看這一點。

最重要的一點：導電性可以改變

電之所以能流動，是因為帶電的微小粒子在移動。金屬裡原本就有很多能自由移動的電子。在半導體中，這種「搬運電的粒子」的數量，可以在事後增加或減少。

半導體的導電性，可以用下面4種方法改變。換成金屬，不論用哪一種方法，導電性都不太會變。

  • 加入雜質：混入極少量的其他元素。這是決定零件性質的方法，也是製造半導體最核心的方法。混入的量非常少，例如每500萬個矽原子只加1個，導電性也會變成數十萬倍。
  • 施加電壓：隔著一層薄薄的絕緣膜放上金屬板（電極），再加上電壓。搬運電的粒子會被吸過來，只有膜的正下方變得能夠導電。電晶體這種開關，就是利用這個原理。
  • 照光：光的能量會產生搬運電的粒子，讓電更容易流動。相機的影像感測器和太陽能電池，都利用了這個性質。
  • 改變溫度：純的半導體溫度越高，越容易導電，和金屬的方向相反。這個性質也用在測量溫度的零件上。

對電子產品來說，特別重要的是前2種。先用雜質做出不同種類、不同數量的搬運電的粒子，再用電壓讓該處的電流導通或切斷。這個組合，就是半導體零件的基本。

為什麼使用矽

能成為半導體的物質有好幾種。即使如此，電腦和手機中負責計算、記憶的晶片，大部分還是用矽做的。理由主要有3個。

1. 原料很多

覆蓋地球表面的岩石層稱為地殼，矽占地殼重量的四分之一以上。它是僅次於氧、含量第2多的元素。沙子和水晶的主要成分，也是矽和氧結合而成的物質。不過，沙子不能直接拿來用，必須經過好幾個階段的精煉。

2. 容易做出能隔開電的優質薄膜

把矽放在氧氣中以高溫加熱，表面就會形成一層漂亮的二氧化矽（SiO₂）膜。這個方法稱為熱氧化。SiO₂幾乎不導電，而且和矽之間的交界缺陷很少。因此，它可以用來當作隔開電的膜，例如電晶體電極下方的薄膜。

其實，第一個電晶體（1947年，美國貝爾實驗室）是用另一種叫作鍺的半導體做的。後來矽成為主角，很大的原因就是能做出這種優質薄膜。此外，矽在溫度升高時也比較不容易漏電。

3. 能做出非常純、尺寸很大的晶體

半導體零件使用的是原子排列整齊的晶體。整塊排列成單一晶體的，稱為「單晶」。矽已經有製造直徑30 cm單晶的成熟技術。把它切成薄薄的圓形板子（晶圓），再在上面做出零件。

原料矽的純度達到99.999999999%的水準。因為有11個9，所以稱為「11個9」（11N）。也就是說，每1000億個原子中，雜質不到1個。把純度提高到這種程度，是為了只加入極少量指定的雜質，來決定材料的性質。如果一開始就混有多餘的東西，就做不出預期的性質。

n型與p型：用雜質做出「搬運電的粒子」

矽原子的最外層有4個電子。在晶體中，它會和相鄰的4個原子互相提供電子，像手牽手一樣結合在一起。所有電子都用在結合上，因此純矽中幾乎沒有能自由移動的電子。這就是純矽不容易導電的原因。

在這裡少量混入最外層有5個電子的磷（P）。磷會進入原本矽的位置，用4個電子形成結合。剩下的1個電子只被輕輕拉住，在室溫下幾乎全部都會脫離，四處移動。像這樣提供電子的雜質，稱為施體（提供者）。

加入施體，讓帶負電的電子負責搬運電，這樣的材料稱為「n型半導體」。n是 negative（負）的第一個字母。電子雖然增加了，磷那一邊也留下等量的正電。因此，整體並不會帶負電。

相反地，如果混入最外層只有3個電子的硼（B），結合就會少1個電子。當相鄰結合的電子移到這個空位，空位就往反方向移動。空位的行為就像帶正電的粒子，因此稱為「電洞」。

像硼這樣接受電子的雜質，稱為受體（接受者）。加入受體，讓電洞負責搬運電的，就是「p型半導體」。p是 positive（正）的第一個字母。

像電子和電洞這樣搬運電的粒子，統稱為「載子」（搬運者）。在n型中，數量較多的載子是電子；在p型中則是電洞。這稱為多數載子。不論哪一型，加入的雜質和矽原子相比都只有極少量。

用比喻來說

電洞的移動方式，很像一排快坐滿的電影院座位。這排有1個空位，旁邊的人一個接一個往旁邊挪，空位就往人移動的反方向前進。實際移動的是人，但把空位當成一個東西來追蹤，說明起來比較簡單。電洞也一樣，實際移動的是電子，但把空位當成「帶正電的粒子」來處理。

比喻的限制：座位上的人是照自己的意思移動，晶體中的電子則是被電壓推著移動。此外，真正的電洞表現得像一種獨立的粒子，移動的難易度和電子不同（在矽中，電子大約比電洞容易移動3倍）。座位的比喻無法表現這個差異。

更進一步：能隙這道「高低差」

到目前為止，我們是用原子相連的圖來思考。物理課本則用電子能量的「階層」來說明同一件事。用這個角度，就能在1張圖上比較導體、半導體和絕緣體的差異。

晶體中的電子所能擁有的能量，只限於幾個固定的範圍（帶）。在半導體和絕緣體中，下方的帶已經被電子塞滿，電子無法直接移動。升到上方帶的電子，以及這時在下方帶留下的空位（電洞），才能搬運電。2個帶之間有一段電子無法擁有的空隙，它的大小稱為能隙。

空隙的大小用eV（電子伏特）這個單位表示。1 eV是1個電子被1伏特的電壓推動時得到的能量。矽的空隙約1.1 eV，絕緣體二氧化矽約9 eV。金屬中，裝有電子的帶上方緊接著就有空位，沒有空隙。

矽的空隙大小，剛好是室溫的熱能可以讓極少數電子越過的程度。溫度上升，越過的電子就增加，所以純的半導體溫度越高越容易導電。照光時變得容易導電，也是因為光的能量讓電子越過了空隙。另一方面，施體的電子只要比空隙小得多的能量，就能移到上方的帶。

用比喻來說

能隙很像2層樓停車場的「樓層高度」。1樓停滿了車，每輛車都動不了。2樓空蕩蕩的，但車要開上2樓，需要爬坡的力氣。開上去的車就能自由行駛。這道坡的高度就相當於能隙。坡越高，能開上2樓的車越少，電就越難流動。

比喻的限制：停車場的1樓和2樓是不同的地點，但電子的「階層」並不是地點的差別。在同一個晶體的同一個位置，只是電子的能量值不同。此外，電子不能像車子那樣一輛一輛分辨、追蹤它的動向。這個比喻只表現了「往上需要能量」這一點。

所以能做出開關

把p型和n型接在一起，交界處的導電就會有方向性。p型那一側接正極時，電流很容易流動；反過來接，就幾乎不流動。這種只讓電流容易往單一方向流動的性質，稱為「整流作用」。

具有整流作用的零件，就是二極體。插座的交流電，是方向來回變化的電。電子產品使用的直流電，則是方向固定的電。二極體就用在把交流電轉換成直流電的電路等地方。LED也是一種把電轉換成光的二極體。p型和n型的交界發生了什麼事，可以在PN接面的圖解中一邊操作一邊確認。

再進一步，把n型和p型組合起來並裝上電極，就能做出一種零件：依電極上的電壓，讓電流的通路出現或消失。這就是電晶體。它用電壓這個小訊號，切換電流的導通與切斷，是靠電來操作的開關。詳細原理在下一篇文章「電晶體是什麼？」中說明。

開關的導通與切斷，可以代表0和1兩種狀態。把大量電晶體組合起來，就成了能用0和1計算、記憶的電路。像手機CPU這樣負責計算的零件，追根究柢也是這些小開關的集合（「CPU是什麼？」）。

「半導體」一詞的3種意思

「半導體」這個詞依場合不同，會指3種東西。看新聞時，留意說的是哪一種，就比較容易掌握內容。

指的是什麼例子常出現的場合
材料矽、碳化矽（SiC）、氮化鎵（GaN）物理或材料的話題
零件（單獨1個就能運作）二極體、功率半導體電源或馬達的話題
晶片（積體電路）CPU、記憶體「半導體短缺」「半導體工廠」

第3種的晶片，是在一小片矽上做出大量電晶體和配線的東西。正式名稱是積體電路，英文縮寫為IC。新聞中的「半導體」大多是指這種IC。

像第2種那樣，單獨1個負責1種功能的零件，為了和IC區分，稱為離散式半導體。從家電到汽車，所有產品都少不了半導體。因此在日本，半導體也長期被稱為「產業之米」，意思是像主食的米一樣不可缺少。

常見的誤解

誤解：半導體是「只導一半電」的材料

實際上，它的特點是導電性可以大幅改變。純矽反而是不容易導電的材料。依雜質的量，可以從相當不易導電的狀態，一直變到接近金屬的狀態，相差好幾個位數。「一半的導體」這個名稱，加上「電阻率介於中間」的說明被廣為流傳，才產生了這個誤解。

誤解：「半導體」就是指晶片（IC）

實際上，它可以指材料、零件、晶片3種東西。LED燈泡發光的部分和太陽能電池也是半導體，但它們並不是集合大量電晶體的IC。新聞常把「半導體晶片」簡稱為「半導體」，因此產生了這個誤解。

誤解：半導體全都是用矽做的

實際上，依用途也會使用其他材料。藍光和白光的LED，是用氮化鎵（GaN）一類的材料做的，因為矽不擅長發光。電動車等使用的功率半導體，也廣泛採用耐高電壓的碳化矽（SiC）。由於負責計算和記憶的晶片大多是用矽做的，才容易有這種想法。
