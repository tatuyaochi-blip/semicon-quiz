主動降噪（ANC）是什麼？降噪耳機用聲音消除聲音的原理

約 10 分鐘 · 更新：2026年10月23日

主動降噪（ANC）是用麥克風收錄噪音，再由晶片做出波峰與波谷相反的聲音，在耳朵裡疊加、互相抵消的原理。電車或飛機那種低沉、持續的「轟——」聲，可以消除得很好。另一方面，人聲或餐具碰撞聲這類高音、突然的聲音，時機很難對準，不太能消除。

先備知識：不需要。文中會出現dB（分貝）的數字，每次都會說明。

生活中的例子

無線耳機和耳罩式耳機中，有些附有「降噪」按鈕。在電車上打開它，行駛時「轟——」的聲響會一下子變小。即使沒有播放音樂，耳朵周圍也會變安靜。

不過，旁邊的人說話的聲音、車站的廣播，還是聽得到。有些聲音會消失，有些聲音不容易消失。這篇文章會從聲音的本質開始，依序來看這個差別是從哪裡來的。

聲音是空氣壓力的微小起伏

聲音是空氣被輕微壓縮、又變稀薄的起伏（振動）。這種振動以波的形式在空氣中傳播。耳朵深處的鼓膜會隨著傳來的振動而動，我們就把它感覺成聲音。

振動每秒重複幾次，稱為頻率，單位是Hz（赫茲）。次數越少，聽起來越低沉；次數越多，聽起來越高。電車或飛機引擎的聲響，主要是低音。對聽懂人聲很重要的成分，以及餐具碰撞的聲音，則是更高的聲音。

聲音的大小，用dB（分貝）這種刻度表示。這種算法以剛好聽得到的聲音為基準，聲音的強度每變成10倍，就增加10 dB。詳細內容在「分貝（dB）是什麼？」中說明。

這種振動非常微小。即使是相當吵的80 dB聲音，壓力的起伏也只有約0.2 Pa（帕斯卡，壓力的單位）。這只有周圍氣壓（約101,300 Pa）的約50萬分之1。

兩種防護方式：擋住，或用聲音消除

減少噪音的方法，大致有2種。第1種是像耳塞、或整個罩住耳朵的耳罩那樣，用東西擋住聲音的通道。這稱為被動式降噪，也就是被動隔音。它不用電。

擋住的方法對高音很有效。另一方面，低音容易讓薄牆或耳塞跟著振動而穿過去，所以很難減少。若要連低音都擋住，就需要又重又厚的罩子。

第2種是這篇文章的主角，也就是主動降噪，取英文字首也稱為ANC。它讓抵消噪音的聲音去碰上噪音本身。擋住的方法不擅長的低音，就由這種方法負責。實際的產品是把2種方法組合起來使用。

原理1：疊加波峰與波谷相反的波

兩個聲波來到同一個地方時，壓力的起伏會相加。波峰和波峰重疊，起伏就變大；波峰和波谷重疊，就互相抵消。請想像湖面上兩圈波紋相撞的地方。

波現在處在一次振動的哪個階段（波峰、波谷，或兩者之間），稱為相位。和噪音剛好波峰與波谷互換的波，是「反相的波」。在耳朵裡疊加一個和噪音大小相同的反相聲波，總和的起伏就幾乎是0。

重點是，要抵消，「大小」和「時機」兩者都必須對上。反相聲波稍微延遲或太大，就會有消不掉的殘留。反相聲波若偏移半次振動，就變成波峰與波峰重疊，反而讓噪音變大。

用比喻來說

想讓擺動中的鞦韆停下來時，在剛好的時機，朝鞦韆過來的反方向推回去，擺動就會變小。推的時機若錯了半次，反而會讓擺動變強。相似的地方是「在正確的時機疊加反方向的力，就能抵消」。擺得越慢的鞦韆，時機越容易對準，這點也一樣。

比喻的限制：鞦韆是一個物體，聲音卻是在空間中擴散的波。即使在耳朵的位置抵消了，稍微離開一點的地方就抵消不了。因此ANC無法減少周圍其他人聽到的噪音，只能讓耳朵裡這個狹小的地方變安靜。

原理2：麥克風 → 晶片 → 喇叭

反相聲波，是由耳機裡的零件以接力的方式做出來的。首先，外側的小麥克風收錄噪音，把壓力的起伏轉換成電壓的起伏。小麥克風的原理，在「MEMS是什麼？」中也有介紹。

接著，把電壓轉換成數字。做這件事的電路，稱為類比數位轉換器（ADC）。轉成數字之後，就能用固定步驟的計算，自由地重新做出波形。

接收轉成數字的噪音、計算出反相聲波的，是數位訊號處理器（DSP）。DSP是擅長以極快速度重複固定形式乘法與加法的晶片。

計算出的數字，由數位類比轉換器（DAC）變回電壓的波，驅動喇叭。喇叭在播放音樂的同時，也播出反相聲波。這樣一來，從外面漏進來的噪音與反相聲波，就在耳朵裡重疊。在電壓與數字之間轉換的電路原理，在「類比IC是什麼？」中有詳細說明。

計算反相聲波時常用的方法，是把麥克風送來的最近幾個數字，各乘上一個權重後相加。這種計算方法稱為有限脈衝響應濾波器（FIR）。耳機的配戴方式和噪音的種類時時刻刻在變，所以也有不斷一點一點修正權重的方式。這裡簡化計算的內容，省略詳細的算式。

原理3：外側麥克風與內側麥克風

麥克風的位置，有2種想法。一種是把麥克風放在耳機外側，在噪音傳到耳朵之前就先聽到，預先做出反相聲波。這稱為前饋式。它不確認結果，而是靠預測搶先一步。

另一種是把麥克風放在喇叭旁邊、耳朵裡面。這個麥克風聽的是抵消後殘留的聲音。它會持續修正反相聲波，讓殘留變小。這種量測結果再修正的做法稱為回授控制，在ANC中稱為回授式。

兩者各有擅長與不擅長之處。外側麥克風能搶先一步，卻不知道耳朵裡是否真的消掉了。內側麥克風能確認結果，但修正的力道太強，就會變得不穩定，像持續發出「嗶——」的聲音。因此，也有把兩者組合起來的產品。例如Apple說明，它用朝外與朝內的兩種麥克風做出反相聲波。兩種控制的差異，在「開迴路控制與閉迴路控制的差異」中比較。

原理4：比聲音更早完成計算

ANC最嚴苛的是時間。空氣中的聲速，在20 °C時約每秒343 m。1毫秒（1000分之1秒）約前進34 cm，1微秒（100萬分之1秒）約前進0.3 mm。

從外側麥克風到鼓膜，耳機大約只有幾cm。假設是3 cm、聲音直線前進，約90微秒就會通過。前饋式必須在這段短短的時間內，完成ADC → DSP → DAC → 喇叭的全部步驟。來不及的話，反相聲波就成了「延遲的反相聲波」，無法順利抵消。

因此，ANC用的晶片特別縮短了從輸入到輸出的延遲。例如Analog Devices的晶片（ADAU1787），就為ANC準備了捷徑。在省略計算的設定下，從入口到出口的延遲是5微秒。這是聲音前進約1.7 mm的時間。晶片的說明文件中，有時會把這種延遲寫成群延遲。

另外，用藍牙從手機傳來音樂的延遲，是另一回事。ANC在耳機內部就完成計算，所以不受電波延遲的影響。藍牙的延遲在「藍牙是什麼？」中說明。

低音會消失，人聲與高音會留下的原因

同樣的延遲，對低音和高音的影響完全不同。振動1次所需的時間，100 Hz的低音是10毫秒，5 kHz（5000 Hz）的高音是0.2毫秒。反相聲波延遲0.1毫秒時，100 Hz只偏移振動1次的1%。5 kHz卻偏移半次，波峰與波峰重疊，反而變大。

用計算來確認，在0.1毫秒的延遲下，100 Hz振動的幅度約變成16分之1。以聲音的強度來說，約是250分之1（約−24 dB）。1 kHz時，振動的幅度只變成約0.6倍（約−4 dB）。這裡假設反相聲波的大小剛好，只有延遲。

還有位置的問題。聲音振動1次期間前進的長度，稱為波長。100 Hz的波長約3.4 m，5 kHz約7 cm。波長長的低音，在耳朵周圍任何地方的振動方式幾乎相同，可以一起抵消。波長短的高音，只要偏移幾mm，振動方式就會改變，很難在整個耳朵裡消除。

突然的聲音也是弱項。餐具的「鏘」、關門的「砰」，都是突然開始，並含有很多高音。另一方面，引擎或行駛聲這種以同樣調子持續的聲音，容易預料稍後的振動，權重的調整也跟得上。由於這些原因，高音不靠ANC，而是交給耳塞套或耳罩擋住的力量。

聽外界聲音的「通透模式」

附有ANC的產品中，有些也有相反的、讓外界聲音更容易聽到的模式。依製造商不同，稱為通透模式、環境音模式等。它不是抵消外側麥克風收到的聲音，而是把它直接從喇叭播出。

即使用耳機塞住耳朵，也聽得到車站廣播或別人的呼喚。根據Apple的說明，這個模式會讓外界聲音進來，讓你聽得到周圍發生的事。不過，走在路上或騎腳踏車時，要注意使用方式，以免漏聽外界的聲音。

風聲與耳朵悶塞的感覺

開著ANC走在戶外，有時風的「噗噗噗」聲會很明顯。風直接吹到麥克風時，空氣的擾動會讓麥克風振動，被當成很大的低音收錄進去。這是和傳到耳朵的噪音不同的振動，若配合它做出反相聲波，有時反而會增加雜音。Sony也提供了使用ANC時減少風聲的設定與對策。

打開ANC時，有些人會覺得耳朵悶悶的，好像氣壓改變了。不過，ANC抵消的是聲音的微小起伏，如前面所見，只有氣壓的50萬分之1左右。它並不會產生持續壓迫鼓膜的壓力。這種感覺因人而異，研究也很少，原因還沒有確認。在意的話，可以減弱ANC，或中途休息一下。

降噪的發展歷程

用反相聲音消除聲音的想法，比耳機古老得多。德國的保羅·呂格（Paul Lueg），想出了用反相的波消除管子裡等處聲音的機制。他在1936年取得美國專利。不過，以當時的零件，還做不成產品。

1950年代，美國的勞倫斯·佛格（Lawrence J. Fogel）推進了研究。目的是在飛機或直升機的噪音中，讓通訊更容易聽清楚。他的專利（美國專利第2,966,549號）在1950年代提出申請，1960年獲得核准。名稱是「在噪音大的地方改善聽取的裝置」。

把它變成產品的，是美國的音響製造商Bose。根據該公司的年表，創辦人阿瑪·伯斯（Amar Bose）在1978年為機艙裡的噪音所苦，因而開始研究。1986年，他把原型機提供給挑戰不加油環球飛行的飛機「航海家號」（Voyager）的飛行員。1989年推出航空用耳機，2000年推出一般消費者用的耳機。之後，晶片變得更小、更省電，現在連入耳式耳機也裝得下。

常見的誤解

誤解：降噪會把周圍的聲音全部消除

實際上，容易消除的是低沉而持續的聲音，人聲、高音、突然的聲音則會留下。Sony的說明書也說，它對飛機、電車、空調這類低音有效，對人聲這類高音不太有效。以為「全部都會消除」，留下高音時就容易誤以為是故障。

誤解：因為會發出反相聲波，所以對耳朵不好

實際上，反相聲波和要抵消的噪音差不多大，傳到耳朵的聲音總和會變小。2022年的研究中，打開ANC後，鼓膜附近的低音下降了；使用塞進耳道的耳機時，人選擇的音量也降低了。WHO也建議，在吵雜的地方利用降噪，避免把音量調高。

誤解：在吵鬧的電車裡，只要把音量調大、蓋過噪音就好

實際上，耳朵的負擔是以「聲音的大小 × 聽的時間」累積的。WHO（世界衛生組織）提出的參考標準是，平均約80 dB的音量，每週可以安全地聽到40小時。依同樣的想法，聲音的強度變成2倍（+3 dB），時間就要減半為20小時。與其把音量調大到蓋過噪音，不如用ANC減少噪音、控制音量，更能保護耳朵。

項目數字

5 kHz聲音的波長／振動1次的時間約7 cm／0.2毫秒

ANC能減少的量，會因產品與耳朵的貼合情況而有很大差異。表中1992年的評估，只靠ANC的作用最多減少15～22 dB，但高音幾乎沒有變化。20 dB代表聲音的強度變成100分之1。有一種參考說法是，聲音的強度變成10分之1（−10 dB）時，感覺到的音量約減半。dB數字的讀法，請參考前面提過的「分貝（dB）是什麼？」。
