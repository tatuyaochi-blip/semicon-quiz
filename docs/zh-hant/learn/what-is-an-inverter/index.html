逆變器（變頻器）是什麼？變頻冷氣與電動車的原理

約 11 分鐘 · 更新：2026年10月23日

逆變器是把直流電重新做成交流電的裝置，而且可以自己選擇交流電的頻率和電壓。裡面的半導體開關每秒導通、關斷約一千次到數萬次，靠導通時間的長短做出波形。台灣常說的「變頻冷氣」「變頻冰箱」，就是用逆變器自由改變馬達的轉速；用來控制馬達的逆變器，也常被稱為變頻器。

先備知識：大致知道直流電和交流電的差異（「交流電和直流電有什麼不同？」）。如果知道功率半導體是「讓大電流快速導通、關斷的開關」，會比較容易閱讀（「功率半導體是什麼？」）。

生活中的例子：從冷氣到停電的備用電源

在家電賣場，常會看到「變頻冷氣」「變頻冰箱」這些字。這裡的「變頻」，指的就是裝了逆變器、能改變馬達轉速。根據大金（Daikin）公關人員的說法，住宅用冷氣中變頻機的比例，在日本、歐盟、澳洲是100%。另一方面，在美國等地仍只占一部分（2024年8月，Weathernews的採訪）。以日本為例，就算不特別挑選，幾乎所有冷氣都是變頻的。

逆變器在家電以外的地方也在工作。

  • 電動車、油電混合車：把電池的直流電轉成交流電，讓行駛用的馬達轉動
  • 太陽能發電：把面板產生的直流電，轉成家裡能用的交流電。這種裝置稱為太陽能逆變器（日本稱為「功率調節器」）
  • 不斷電系統（UPS）：停電時把電池的直流電轉成交流電，繼續供電給電腦和伺服器
  • 電車：用從架空線接收的電，做出適合馬達的交流電

UPS有一種方式，平時就先把電轉成直流電，再用逆變器轉回交流電送出。用這種方式，停電時供電也不會中斷。停電後才切換到電池的方式，則會中斷約100分之1秒（ITmedia與ASCII.jp的說明）。

不論哪個例子，都是「只有直流電，卻需要交流電」或「想改變交流電快慢」的場合。

逆變器做的事：從直流電到「照訂單做的交流電」

直流電是從電池或太陽能板流出、方向始終相同的電。交流電是方向規律地來回變換的電。每秒來回的次數稱為頻率。以日本為例，插座依地區是每秒50次或60次。

逆變器接收直流電，做出交流電。它的特點是，頻率和電壓的大小，都能配合使用端的需求來選擇。插座的頻率是固定的，逆變器則不同，每秒來回10次也行，超過100次也做得到。

相對於把交流轉成直流的「順向轉換」，把直流轉成交流稱為「逆向轉換」。逆變器就是做逆向轉換的裝置（Panasonic的名詞解說）。技術資料和本站的名詞解釋寫作「逆變器」，指的是同一個東西。

原理①：用4個開關切換電流的方向

把直流變成交流的基本想法非常簡單。只要在電池和馬達之間，快速切換連接的方向就行了。不必用手把電池反過來接，而是改用4個能以電訊號操作的開關。

如下圖，把4個開關排成英文字母H的形狀，在中間橫槓的位置放上馬達。這種排法稱為「H橋」或「全橋」。

讓左上的S1和右下的S4導通，電流就向右流過馬達。接著讓左下的S2和右上的S3導通，電流就向左流。只要輪流重複，就能得到方向來回變換的電，也就是交流電。改變切換的節奏，頻率也跟著改變。

開關使用能承受大電流和高電壓的功率半導體，例如IGBT、功率MOSFET、SiC（碳化矽）MOSFET等。它們各自的特性，在「功率半導體是什麼？」和「IGBT與功率MOSFET的差異」中有說明。這裡請把它想成「能用電訊號非常快速導通、關斷的開關」。

有一種狀態絕對必須避免：同一直列的上下兩個開關（例如S1和S2）同時導通。這時電源的正極和負極只隔著開關直接相連，大電流流過，零件就會損壞。開關完全切斷需要一點點時間。所以切換時，會插入一段上下都關斷的極短等待時間。這稱為死區時間。

馬達無法讓正在流動的電流突然停止。因此每個開關都並聯一個只讓電流單向通過的零件（二極體），作為切斷瞬間電流的出路（「二極體是什麼？」）。

原理②：改變切割方式，接近平滑的波

只切換方向的話，電壓會在「正的最大」和「負的最大」之間來回，成為方形的波。插座的交流電，是平滑起伏的正弦波。要讓馬達安靜、不浪費地轉動，接近正弦波的形狀比較適合。

所以，要把開關切得更細。在交流電來回1次的期間，導通、關斷重複數十次到數百次。在波峰附近讓導通時間變長，在接近0的地方變短。這樣一來，平均後的電壓，就會沿著正弦波的形狀起伏。

用導通時間的長短（脈衝的寬度）來決定平均電壓的方法，稱為PWM（脈寬調變）。逆變器會隨著時間，配合波形改變這個寬度。

決定寬度的方法有好幾種，代表性的是拿想做的正弦波，和快得多的三角波互相比較。正弦波較高的期間讓正側開關導通，較低的期間讓負側導通。這種做法稱為正弦波PWM（這裡只介紹名稱）。

實際的電壓，仍然是只有導通或關斷的脈衝。即使如此，流過馬達的電流還是會變得平滑。因為馬達中纏繞電線的部分（線圈），變化越快越難讓電流通過（「交流電和直流電有什麼不同？」）。細小的鋸齒被抹平，緩慢的正弦波變化則留在電流中。

頻率和電壓的選擇，也是在這裡決定的。加快寬度變寬、變窄的節奏，頻率就會升高。整體寬度偏寬，電壓就升高；偏窄，電壓就降低。哪個開關何時切換，是由微控制器等控制用晶片計算決定的（「微控制器是什麼？」）。

用比喻來說

PWM有點像印刷照片的「網點」。用放大鏡看報紙的黑白照片，灰色的部分也只由黑點和白紙組成。點大的地方看起來深，點小的地方看起來淺。逆變器也只有「導通」和「關斷」兩種狀態，卻能靠改變導通的比例，表現出中間的電壓。相似的只有這一點。

比喻的限制：把網點平均起來的是人的眼睛，是在紙面的位置上平均。逆變器則是馬達的線圈，在時間的流動中把電流平均。此外，沒能抹平的小波動會留在電流裡，成為聲音和熱的來源。

原理③：用6個開關做出三相交流電

冷氣的壓縮機（把冷媒氣體壓縮的機器）和電動車的馬達，很多是用3條線接收電力。3條線中流著形狀相同的交流電，時間各錯開來回1次的3分之1。這種送電方式稱為三相交流。3個波依序變強，所以馬達裡會產生不停旋轉的磁力。

三相逆變器，是把上下2個開關組成的一組排成3列，共用6個開關。每一列用PWM做出1條線的電壓。讓3列的波時間各錯開3分之1，就成為三相交流電。

旋轉磁力的速度，由交流電的頻率決定。頻率減半，馬達的轉速也大約減半。工廠的泵浦和風扇常用的一種馬達感應電動機（也稱感應馬達），也有這種性質。不過，只降低頻率的話，馬達會流過太多電流。所以基本做法是配合頻率，把電壓也降低（這裡做了簡化）。

在電動車上，逆變器會配合油門的踩法，時時刻刻改變頻率和電壓。煞車時把電送回電池的流程，在「功率半導體是什麼？」的圖中有介紹。

為什麼改變轉速能省電

沒有逆變器的冷氣（定頻冷氣），壓縮機總是以相同的速度轉動。房間太冷就停機，變熱又全力運轉，如此反覆。變頻冷氣則可以一開始轉快、迅速降溫，之後持續慢慢轉。這種方式的冷氣，由東芝在1980年推出業務用、1981年推出家用，是全球首次量產。電機電子領域的國際學會IEEE，已將它認定為歷史性的成就。

停了又開的運轉方式有浪費。根據大金的說法，冷氣在室溫和設定溫度差距大的剛開機時，耗電特別多（2016年的發表）。若能細微改變轉速，全力運轉的次數會減少，溫度的起伏也會變小。大金在2023年聯合國氣候變遷會議（COP28）上介紹了高效率機型。該公司的說明是，比起非變頻機型，耗電可減少50%以上。

對風扇和泵浦來說，降低轉速的效果更大。因為它們需要的電功率，大約和轉速的3次方（同一個數乘3次的值）成正比。美國能源部的資料指出，轉速降低2成，需要的電功率約減為一半。0.8乘3次約為0.51，和計算結果相符（本站的計算）。

這裡大幅簡化，說明為什麼是3次方。風扇轉慢時，每秒送出的風量會與轉速成正比減少。同時，推出風的壓力會以轉速的2次方減弱。需要的電功率由「風量 × 壓力」決定，所以合起來就以轉速的3次方減少。

不過，冷氣的壓縮機不會像風扇減少那麼多。同一份資料指出，壓縮空氣的壓縮機等，電功率大致與轉速成正比。冷氣省電的一大原因，是能減少前面提到的「停了又全力運轉」的浪費。

熱與損耗：開關也會稍微發熱

逆變器也無法把接收的電力全部送出去，損失的部分會變成熱。日立在2017年發表的太陽能發電用功率調節器（太陽能逆變器），轉換效率是96.5%。意思是接收的電力中，能送出96.5%。假設以這個效率送出額定的5.5千瓦，變成熱的約為0.2千瓦（本站的計算）。

第一種損耗，來自導通的開關上殘留的少許電阻。只要電流在流，就會一直發熱。這個電阻稱為導通電阻，由它造成的損耗稱為導通損耗。

第二種是在導通和關斷切換途中的一瞬間產生的切換損耗。因為切換途中，開關上同時有電壓和電流。

這裡就是設計上的難題。切得越頻繁，電流越平滑，馬達的聲音也越小。可是每次切換都會產生損耗，所以次數越多，熱也越多。切換損耗小的SiC和GaN零件，能減輕這個難題，因而受到注目（「氮化鎵（GaN）是什麼？」）。

名詞整理：和轉換器、整流的差異

轉換常用的名稱例子
交流 → 直流整流、轉換器（順向轉換）充電器、冷氣的電源入口
直流 → 交流逆變器（逆向轉換）驅動馬達、太陽能發電
直流 → 電壓不同的直流DC-DC轉換器電腦內部、電動車

「轉換器」是廣泛指「改變電的形式的裝置」的詞。把交流電整理成單一方向流動的作用，特別稱為整流。

變頻冷氣裡，其實兩者都有。先用轉換器把插座的交流電轉成直流電。再用逆變器重新做成任意頻率的交流電，讓壓縮機的馬達轉動。冷氣或冰箱說「變頻」時，意思就是用這種方式「能改變馬達轉速」的產品。日光燈的電子式安定器也是一種逆變器，但它是提高送給燈管的電的頻率，目的不同。

差異整理在「轉換器與逆變器的差異」的表格中。另外，把0和1反過來的邏輯電路「反相器」（NOT閘），英文也叫inverter，但只是名字相同，是完全不同的東西（「邏輯閘是什麼？」）。

聲音、雜訊、安全

由逆變器驅動的馬達，有時會發出「嘰——」的高音。這是因為馬達的鐵心配合開關切換的節奏，產生微小的振動。以日本為例，京急電鐵的部分電車，發車時這個聲音聽起來像音階，被稱為「會唱歌的電車」。那是1998年登場的2100型等車輛所搭載、西門子製裝置的聲音，2021年夏天之後就聽不到了。

如果切換次數超過人耳聽得到的範圍（每秒約2萬次以內），聲音就會變小。不過，影響周圍機器的電氣雜訊會增加（江森自控的說明書）。切換次數變多，損耗也隨之增加。為了防止收音機雜音等，逆變器內建了抑制雜訊的零件（濾波器）。

在安全方面，關掉電源後也要注意。逆變器裡有儲存直流電的大型電容器（「電容器是什麼？」）。即使關掉電源，高電壓有時仍會殘留一段時間。德國廠商SEW-EURODRIVE的說明書，要求關掉電源後至少等待10分鐘。等待時間依產品而異，寫在各自的說明書中。請避免打開家電內部觸摸，維修請交給專業人員。

常見的誤解

誤解：只要是變頻的，不論怎麼使用都一定省電

實際上，只有能降速運轉的時間夠長時才會省電。一直全力運轉的機器，改變轉速沒有好處。反而可能因為逆變器本身的損耗（數%），電力稍微增加。冷氣也會因使用方式而有差別。大金2016年的驗證顯示，白天外出約30分鐘的話，開著比關掉划算。不過，該公司也表示任何時候都一直開著反而有反效果。廣告強調「變頻＝省電」，所以容易被認為任何情況都划算。

誤解：逆變器做出的交流電，比插座的交流電更「乾淨」

實際上，逆變器做出的是排列著導通、關斷脈衝的電壓。以馬達用來說，平滑的是被線圈抹平後的電流。也有確實加裝抹平脈衝零件的「正弦波輸出」裝置。另一方面，便宜的裝置中，也有輸出方波或階梯狀波的產品。施耐德電機提醒，輸出方波的UPS，有些機器無法對應。「用電子技術做出的電」這種印象，讓人容易以為比原本的電更高級。
