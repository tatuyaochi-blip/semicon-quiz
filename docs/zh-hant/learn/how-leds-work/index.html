LED為什麼會發光？用半導體把電變成光的原理

約 11 分鐘 · 更新：2026年10月23日

LED是讓電流通過兩種性質不同的半導體交界處的元件。在那裡，電子會和「電子的空位（電洞）」相遇，相遇時釋放的能量就變成光。光的顏色，由每種材料固有的「高低差」（能隙）大小決定。大多數白光LED，是用會發黃光的材料，把藍光LED的一部分光轉換後混合而成。

先備知識：如果知道n型與p型、電子的空位「電洞」、以及「高低差」（能隙），會比較容易閱讀（「半導體是什麼？」）。

生活中的例子

LED燈泡、紅綠燈、車燈、手機的手電筒，都是靠LED發光。電視遙控器的前端，也裝著發出肉眼看不見的紅外線的LED。

LED是Light Emitting Diode的縮寫，中文叫做發光二極體。二極體是只讓電流往一個方向順利流動的元件。LED是其中特別做成通電就會發光的一種。真正發光的，是裡面一小片半導體（晶片）。

原理1：電子和電洞在交界處相遇

LED的核心，是n型和p型半導體相接的交界處。n型裡有很多能自由移動的電子，p型裡有很多電子的空位，也就是電洞。這個交界處稱為「PN接面」。

把p型那一側接到電池的正極，n型那一側接到負極，電流就能順利流動。這種施加電壓的方向，稱為順向偏壓。這時，電子從n型那一側、電洞從p型那一側，接連被送往交界處。

電子能自由移動的狀態，能量比有電洞的狀態高，兩者的差距由材料決定。這個差距稱為高低差（能隙）。

電子在交界處遇到電洞時，會掉進空位，兩者一起消失。這稱為「復合」，電子會釋放出相當於高低差的能量。在LED用的材料裡，這份能量會變成光的粒子放出來。

用比喻來說

復合就像球從台階上掉下來。台階越高，掉下來時釋放的能量就越大。在LED裡，這個「每次釋放的能量」決定了光的顏色。電流增加，掉下來的球變多，光就變亮。但每一階的高度不變，所以顏色幾乎不變。

比喻的限制：真正的高低差不是位置的高度，而是電子能量的差距。另外，掉下來的電子的能量，也可能沒有變成光，而是變成熱。這個比喻只說明「高低差的大小決定每次的能量」這一點。

原理2：和太陽能電池、影像感測器相反

LED裡發生的事，和太陽能電池或相機感測器正好相反。在太陽能電池和感測器裡，光會產生成對的電子和電洞，交界處的電力再把它們分開，變成電流（「太陽能電池為什麼能發電？」「影像感測器是什麼？」）。在LED裡，則是用電流把電子和電洞集中到交界處，讓它們相遇並發光。

不過，擅長哪個方向，要看材料。相機的感測器可以用矽來做，但LED幾乎無法用矽來做。原因後面會說明。

原理3：顏色由「高低差」的大小決定

光的顏色，會隨波的長度（波長）改變。人眼看得見的，大約是380〜780奈米（nm，1 nm是10億分之1公尺）的範圍。波長越短看起來越偏藍或紫，越長就越偏紅。再更長的光，就是看不見的紅外線。

波長越短，每個光粒子的能量就越大。所以高低差越大的材料，發出的光越接近藍色。高低差的單位是eV（電子伏特）。1 eV是1個電子被1伏特的電壓推動時得到的能量。

有一個大致的關係：「1240除以高低差（eV），就是波長（nm）」。反過來算，藍光（450 nm）需要1240÷450，約2.76 eV的高低差。紅光（630 nm）則是1240÷630，約1.97 eV。其他數值可以用能隙與波長換算工具確認。

要做出不同顏色，就改變材料的組合與混合比例。藍光和綠光用氮化鎵摻入銦的氮化銦鎵（InGaN）。紅光和黃光用由鋁、鎵、銦、磷組成的AlGaInP。紅外線則用砷化鎵（GaAs）等材料。這些都是把週期表第13族（舊稱III族）和第15族（舊稱V族）元素組合起來的III-V 族化合物半導體。

點亮LED所需的電壓，也接近高低差的數值。以ROHM（羅姆）產品的典型值來看，紅光LED是1.9 V，藍光LED是3.2 V（20 mA時）。

為什麼矽不會發光

矽的高低差約1.1 eV，照計算應該能發出約1,100奈米的紅外線。但是，即使讓電流通過矽，也只會發出極少的光。這是因為電子和電洞相遇時，除了能量之外，還有一樣東西必須對上。

晶體中的電子，除了能量，還帶有「運動的衝勁」。物理上稱為動量，這裡簡化說成「衝勁」。光的粒子幾乎帶不走這種衝勁。所以，如果電子和電洞的衝勁原本就不一致，發光的復合就很難發生。

電子和電洞聚集的狀態衝勁一致的材料，稱為直接能隙半導體。氮化鎵和砷化鎵就屬於這一型。相遇的電子和電洞，很容易發光並復合。

矽則是電子和電洞衝勁錯開的間接能隙半導體。要發光，必須由晶體原子的振動來補足衝勁的差距，這樣的相遇很少發生。在等待的時候，多數電子會經由晶體的缺陷等途徑復合，把能量變成熱釋放掉。詳細可以在「直接能隙與間接能隙的差異」的表格中比較。

另一方面，在接收光這一側，矽很好用。雖然矽吸收光不如直接能隙材料容易，但光的粒子在被吸收前會一直在晶體中前進。只要把矽做厚一點，就能接收大部分的光。因為不像發光時那樣，要和變成熱的快速途徑競爭。

藍光LED為什麼難做，又為什麼重要

1962年，美國奇異公司（GE）的尼克·何倫亞克，做出了發出可見紅光的LED。這是實用LED的起點。之後，紅、黃、綠色的LED普及到指示燈等用途。但是很長一段時間，都做不出明亮的藍光LED。

藍光需要約2.7 eV的大高低差。候選材料氮化鎵（GaN），是非常難長出漂亮晶體的材料。因為沒有原子排列間距相符的基底晶體，長出來的晶體到處都是缺陷。電洞多的p型氮化鎵，也一直做不出來。

赤崎勇和天野浩在1986年，在基底的藍寶石之間夾入一層薄層，做出品質良好的晶體。1989年，又做出p型，實現了PN接面的LED。日亞化學工業的中村修二，自行改良了長晶的設備，在1993年做出明亮的藍光LED。

三人獲得了2014年的諾貝爾物理學獎。得獎理由的英文原文翻譯過來是「表彰發明高效率的藍光LED，使明亮且節能的白光光源成為可能」。藍光到位後，光的三原色都能用LED做出來，白光LED照明也成為可能。氮化鎵現在也用在電源用的功率半導體上。

白光LED的原理

沒有哪一種高低差能直接發出白色的光，因為白光是各種顏色的光混合而成的。所以大多數白光LED，是用會發黃光的材料，覆蓋在發藍光的LED晶片上。

這種會發黃光的材料稱為「螢光粉」。螢光粉會吸收某種顏色的光，再發出波長較長的另一種顏色的光。藍光有一部分直接穿過，其餘的被螢光粉轉換成黃光。藍光和黃光混合後，人眼看起來就是白色。黃色螢光粉常用在YAG晶體中加入鈰的材料（YAG:Ce）。

這種方式是日亞化學工業在1996年開發的。另外也有混合紅、綠、藍3顆LED的方法，以及用接近紫外線的LED讓幾種螢光粉發光的方法。不過在照明上，藍光LED加螢光粉的組合仍是主流。熄燈時LED發光的部分看起來偏黃，就是這種螢光粉的顏色。

比白熾燈泡省電的原因

白熾燈泡是把細細的金屬線（燈絲）加熱到非常高的溫度來發光。熱的物體會發光，但大部分是看不見的紅外線。白熾燈泡用掉的能量，約有90%變成熱（美國的節能認證制度ENERGY STAR）。

LED不是靠熱來發光，而是把電子的能量直接變成光。照明的效率，用每1瓦電力能得到多少亮度，也就是「lm/W（流明每瓦）」的發光效率來比較。

一般60 W的白熾燈泡約16 lm/W（美國能源資訊署，2014年）。根據國際能源總署（IEA），2026年市售LED的平均接近100 lm/W，也有超過200 lm/W的產品。換算下來，同樣的亮度，電力大約只要6分之1。

LED還是會發熱的原因

LED的光幾乎不含紅外線，所以被照到的東西不太會變熱。但是在LED內部，仍有很多電力變成了熱。因為有些電子復合時沒有發光，螢光粉轉換顏色時和電源電路裡，也有一部分能量變成熱。

和上限比較，就能大致估計有多少變成熱。美國能源部（DOE）2020年的資料，把LED白光效率的理論上限定為325 lm/W。100 lm/W的燈，還不到它的3分之1。沒有變成光的部分，就變成了熱。這是省略細節的估算，但可以認為一半以上的電力都變成了熱。

白熾燈泡的熱，會以紅外線的形式向周圍擴散。LED的熱，則悶在小小的晶片裡。熱累積起來，光會變弱，壽命也會縮短。所以LED燈泡的底座，裝有把熱導走的金屬等零件（散熱片）。

LED還有一個性質：流過單一晶片的電流越大，變成光的比例就越低。這稱為效率下垂（droop，也常稱為效率衰減）。明亮的照明會把晶片做大，或排列很多顆，來壓低每顆的電流。

壽命數字的看法

LED很少突然壞掉，而是一點一點變暗。所以LED的壽命，一般用亮度降到初始值70%為止的點亮時間來表示。這寫成L70，也就是「光通量維持率70%」。

LED燈泡的包裝上，常寫著「額定壽命40,000小時」這樣的數字。這是平均的參考值，不是保證的時間。如果1天點亮8小時，40,000小時約為13.7年。電源電路也可能先損壞，日本照明工業會把照明器具的更換參考時間定為8〜10年。

LED要用「固定的電流」來驅動

LED的電壓超過某個值之後，電壓只要稍微升高，電流就會急遽增加。溫度上升後，電流還會更容易流動。如果直接接到電池等電源，電流可能過大而燒壞。

所以LED不是決定電壓，而是決定電流來驅動。像指示燈這樣的小LED，串接1個電阻來限制電流就可以了。像照明這樣要通入大電流時，會使用讓電流保持固定的「定電流電路」。

LED燈泡的底座裡，也有一個小電路，把家用插座的交流電，轉換成適合LED的固定直流電流。調整亮度的調光，常用的方法是讓LED以人眼察覺不到的速度快速閃爍，改變點亮時間所占的比例。

表親元件：雷射二極體

雷射二極體（半導體雷射）也是在PN接面讓電子和電洞相遇而發光，這點和LED相同。不同的是，晶片兩端做成像鏡子一樣，讓光在裡面來回反射很多次。來回的光會接連引發同顏色、同方向的光，變成整齊的細光束射出。

LED的光顏色有一點範圍，而且往很廣的方向擴散，適合照明和顯示。雷射二極體的光顏色範圍很窄，往單一方向前進，用在光纖通訊和讀取藍光光碟等地方。差異整理在「LED與半導體雷射的差異」的表格中。

常見的誤解

誤解：LED不會發熱

實際上，通入LED的電力，現在仍有一半以上變成熱。因為光裡幾乎沒有紅外線，被照的一側不會變熱，所以感覺好像不發熱。熱會悶在晶片裡，必須用散熱片導走。

誤解：LED的顏色是由有顏色的塑膠外殼決定的

實際上，顏色是由晶片材料的高低差決定的。即使是透明外殼的LED，紅光LED也會發紅光，藍光LED也會發藍光。以前的指示燈，很多都裝了和發光顏色相同的外殼，所以容易看起來像是外殼造成了顏色。

誤解：白光LED直接發出白光

實際上，多數白光LED是藍光LED加上發黃光的螢光粉，靠混合顏色讓人看起來是白色。發光時只看得到白色，所以不容易察覺裡面其實在混色。
