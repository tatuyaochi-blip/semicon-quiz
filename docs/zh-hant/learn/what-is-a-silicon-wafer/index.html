矽晶圓是什麼？從石頭到鏡面般圓板的製造過程

約 10 分鐘 · 更新：2026年10月23日

矽晶圓是用整體原子排列一致的矽晶體做成、厚度不到1 mm的圓形薄板。表面拋光得像鏡子一樣。在這片板子上，可以一次做出數百到數千顆晶片。它之所以是圓形，是因為要把從熔化的矽中一邊旋轉一邊拉起、長成圓柱的晶體，切成一片片。

先備知識：不需要。如果知道「晶片是在一片板子上一起做出來的」，會比較容易閱讀。整體流程請見「半導體晶片是怎麼做出來的？」。

生活周遭

在半導體工廠的新聞裡，常用「月產◯萬片」這種片數來表示產量。這個「片」所計算的，就是晶圓。晶圓是製作晶片的基礎，是一片圓形的薄板。送到工廠時，它還沒有任何電路，是一片像鏡子般閃亮的板子。

日本以擁有強大的晶圓製造商而聞名。全球主要的晶圓製造商中，有2家是日本公司，台灣的環球晶圓也名列其中（後半會介紹）。進入半導體公司後，常會聽到「12吋」「notch」「epi」等和晶圓有關的詞。本文也會依序說明這些詞的意思。

晶圓是什麼：由一整塊晶體構成的圓板

量產使用的最大晶圓，直徑是300 mm，大約是一個大盤子的大小。厚度約0.775 mm，和信用卡（約0.76 mm）差不多。重量經計算約130 g。

重要的是，整片板子是一塊晶體。晶體是指原子依固定規則排列的固體。在晶圓中，原子的排列從一端到另一端都朝同一方向對齊。這樣的晶體稱為「單晶」。

如果是由排列方向不同的小晶粒聚集而成，電流的流動方式在晶粒的交界處就會改變。晶片裡有數十億個電晶體（電的開關），必須讓它們具有相同的性質。所以，需要無論哪個位置排列都相同的單晶。

做出電路的，只有晶圓表面非常淺的部分。其餘的厚度，是為了在製作途中不破裂、不翹曲的支撐。電路完成後，多數情況會先把晶圓背面磨薄，再切成一顆顆晶片。

為什麼要在圓板上一起製作

晶片非常小，一顆顆製作既費工，品質也不一致。因此，要在一片板子上像棋盤格一樣排滿相同的晶片，一起加工。直徑300 mm的晶圓，大約可以排下600顆10 mm見方的晶片。

晶圓是圓形的，是因為長晶體時要一邊旋轉一邊往上拉。晶體會長成圓柱形，再把它切成一片片，所以成為圓板。把方形的晶片排在圓板上，邊緣會出現缺角的晶片。即使如此，要做出又大又好的單晶，這種長法還是最合適。

從石頭到高純度的矽

矽以二氧化矽（矽與氧結合而成的物質）的形式，大量存在於沙子和岩石中。原料使用含有大量二氧化矽的矽石（石英岩）。並不是直接使用海邊的沙子。

首先，把矽石和碳一起放進電爐，加熱到高溫。碳會奪走氧，留下矽。這樣做出來的東西稱為「金屬矽」。純度約98～99%，用在半導體上還不夠。

接著，讓金屬矽和氯化氫反應，轉成常溫下是液體的化合物。液體可以反覆蒸餾，去除雜質。把純化後的化合物和氫一起送進反應爐，矽就會一點點堆積在加熱的細矽棒表面。這種製法稱為西門子法。

堆積而成的矽，是許多小晶粒聚集在一起的東西。每個晶粒的原子排列方向都不同，所以稱為「多晶矽」。純度雖然非常高，但這樣還不能用來做晶片。

純度會用「99.9999999%」這種連續9的數字來表示。許多資料把半導體用的水準，定為9連續出現9～11個。日本的大型材料廠商，把11個9（11N）視為理所當然的水準（2026年的報導）。這表示每1000億個原子中，雜質在1個以下。

純度要提高到這種程度，是為了刻意加入極少量的雜質，來決定導電的難易度。詳細說明請見「半導體是什麼？」。

長出單晶：CZ法

把多晶矽放進石英做的耐熱容器（坩堝），在1,400 ℃多的溫度下熔化。這時，要先加入極微量的硼或磷等元素。這是為了讓長出的晶體，具有預定的導電程度。

在熔化的矽表面，浸入一小塊單晶。這一小塊稱為「晶種」。一邊旋轉晶種，一邊慢慢往上拉。

碰到晶種的熔融矽，會稍微冷卻而凝固。凝固時，原子會和晶種朝同一方向排列。這樣一層接一層，就會保持和晶種相同的排列，往下長出又粗又長的單晶。調整拉起的速度和溫度，讓粗細保持一定。

這種長法稱為CZ法（柴可拉斯基法）。它源自波蘭出身的化學家柴可拉斯基在1916年發現的方法。原本是用來研究金屬晶體的方法，後來才用在矽上。

用比喻來說

晶種的作用，就像貼磁磚時的第一片。照著第一片的方向一片片貼下去，整面牆的磚縫就會筆直對齊。CZ法也一樣，晶種的原子排列成為範本，長出的整塊晶體方向都會和晶種相同。相似的只有一點：「最初的一個，決定了整體的方向」。

比喻的限制：磁磚是人一片片貼上的，晶體則是從液體凝固的原子，自己排進範本的位置。另外，磁磚是排在平面上，晶體卻是立體地生長。排列也不是完全不會亂，溫度等條件一走樣，晶體就會產生缺陷。

長成的圓柱塊稱為晶棒。切掉兩端粗細不一致的部分，再研削外圍，讓直徑一致。

在CZ法中，石英坩堝會一點點溶進熔融的矽裡。因此，晶體中會混入微量的氧。如果用不使用坩堝的FZ法（浮動區熔法），矽不碰觸容器，就能做出不易混入氧等雜質的晶體。不過，這種方法很難做出大直徑的晶體，只用在處理高電壓的功率半導體等部分用途。量產晶圓的大部分，都是用CZ法製造。兩者的差異，可以在「CZ法與FZ法的差異」中比較。

切割、研削，再拋光成鏡面

從晶棒到晶圓，要經過好幾道加工。以下依序來看。

  1. 做記號：在外圍刻一個小小的V字形缺口。這是表示晶體排列方向的記號，稱為缺口（notch）。工廠的設備會看這個記號，把晶圓的方向對齊。
  2. 切成薄片：用平行拉了數百條細線、讓線來回移動的切割機，把晶棒一次切成許多圓板。厚度不到1 mm。
  3. 磨圓邊緣：板子的邊緣如果有稜角，碰撞時會缺角，成為破裂或微粒的來源。因此要把邊緣磨圓。
  4. 調整厚度與平坦度：研削兩面，讓板子的厚度一致，並且變平。
  5. 溶掉受損層：用機械切割或研削後，表面附近會留下細小的刮痕和應變。用藥液把這一層溶掉去除。
  6. 拋光成鏡面：用含有極細顆粒的藥液和柔軟的研磨墊拋光表面。藥液和表面的矽反應，讓它變得容易削去，再由顆粒一點點削掉。
  7. 清洗與檢查：洗掉表面的小微粒和髒汙，量測平坦度和厚度。

檢查時，會用雷射光照射表面。只要有小微粒，光就會在那裡散射，所以能知道微粒的數量和位置。合格的晶圓，會放進不讓微粒進入的專用容器出貨。

依用途不同，有時會在拋光好的晶圓上，再長一層薄薄的單晶。因為這層會延續下方晶體的排列生長，這種方法稱為磊晶成長。這樣做出的晶圓，就是現場稱為「epi」的「磊晶晶圓」。它可以只減少表層的缺陷，或改變表層的導電程度。

此外，也有在表面薄薄的矽層下方，夾著一層不導電膜的晶圓。可以在「SOI與塊材矽的差異」中，和一般的晶圓比較。

為什麼要平坦，而且不能有微粒

在晶片工廠，要用光把電路圖案轉印到晶圓上。這項作業稱為曝光。曝光機會用透鏡或反射鏡，把圖案縮小投射到晶圓上。這時，圖案能清楚成像的高度範圍非常窄。

這個範圍稱為焦深。為了轉印細微的圖案，越是使用能從廣角度收光的透鏡，焦深就越淺。晶圓表面只要有些微凹凸，那裡就會失焦，圖案變得模糊。

曝光機會在每個位置量測高度，重新對焦。即使如此，一次轉印的範圍（數公分見方）內的細小凹凸，還是無法完全修正。所以，晶圓本身必須做得非常平坦。轉印細微圖案的曝光原理，在「EUV微影是什麼？」中有說明。

微粒也是大敵。微粒所在的位置，圖案可能無法正確轉印，導線也可能誤接或斷開。那顆晶片就會成為不良品，良品的比例（良率）也會下降。所以，晶圓在出貨前，連微粒的數量都受到嚴格檢查。

晶圓為什麼越做越大

早期的晶圓，直徑只有幾公分。之後主要依100 mm、150 mm、200 mm、300 mm的順序，逐步變大。以300 mm晶圓量產，大約始於2001年。300 mm在現場也稱為「12吋」（精確來說，12吋約是305 mm）。

變大的理由，是為了增加一片晶圓能切出的晶片數。面積和直徑的平方成正比，所以300 mm晶圓的面積是200 mm的2.25倍。許多製程是一片片處理，或是多片一起處理，所以一片越大，一次處理能做出的晶片就越多。

能切出的晶片數，增加得比面積比還多。用本站的計算工具，算算10 mm見方的晶片。200 mm約260顆，300 mm約610顆，約2.4倍。這是因為晶圓越大，邊緣缺角浪費的比例就越小。缺角的部分是沿著邊緣的細帶，它的長度（圓周）只和直徑成正比增加。可以用晶粒良率計算器，改變晶圓直徑或晶片大小試試看。

另一方面，改變直徑時，工廠的設備幾乎都得重新製作。為了下一代的450 mm，2011年在美國成立了共同開發的組織（G450C）。英特爾、台積電、三星電子等公司都有參加。但參加的公司判斷，還不是進入下一階段的時候。這個組織在2016年底結束了活動（EE Times，2017年1月的報導）。到了2026年，量產使用的最大晶圓仍是300 mm。

小尺寸的晶圓也沒有消失。功率半導體、感測器、類比元件等，現在仍在200 mm晶圓的工廠生產（產業團體SEMI的說明）。不需要最先進細度的零件，用熟悉的設備製造更合適。

晶圓由誰製造？

晶圓通常不是半導體廠商自己做，而是向專門的晶圓製造商購買。晶圓製造商負責從長晶、拋光、檢查到出貨的工作。在晶圓上做出電路的，是買下晶圓的半導體廠商，或是接受委託製造的公司（晶圓代工廠）。

矽晶圓的主要製造商，常被列舉的是以下5家。

  • 信越化學工業（日本。由集團旗下的信越半導體製造晶圓）
  • SUMCO（日本）
  • 環球晶圓（GlobalWafers，台灣）
  • Siltronic（德國）
  • SK siltron（韓國）

市場占有率（市占率）的數字，會因調查機構和年份而有差異。所以本文沒有列出。製造原料多晶矽的公司，以及製造長晶設備的公司，也都各自是不同的公司。

常見的誤解

誤解：晶圓是把海邊的沙子熔化做成的

實際上，是以含有大量二氧化矽的矽石為原料。成分和沙子相同，但並不是直接熔化。而是先做成金屬矽，再轉成液態化合物來精製，最後長成單晶。「晶片是從沙子做出來的」這種說法，是表示成分相同的簡略說法。

誤解：晶圓的整個厚度裡，都塞滿了電路

實際上，做出電路的只有表面非常淺的部分。其餘的厚度，是為了在製程途中不破裂、不翹曲的支撐。完成後，多數情況會把背面磨薄。剖面圖常把電路的部分放大來畫，所以容易讓人這樣以為。

誤解：晶圓越大，做出的晶片效能越好

實際上，晶圓直徑改變的，主要是一片能切出的晶片數和成本。晶片的速度和省電程度，由電路的細度和設計決定。用200 mm晶圓製造的功率半導體和感測器，在各自的用途中也是重要的零件。因為最先進的晶片是用300 mm製造，所以大小和效能容易被連在一起。

深入學習

  • 閱讀下一道製程：轉印電路圖案的曝光，請見「EUV微影是什麼？」；製程全貌，請見「半導體晶片是怎麼做出來的？」。
  • 用表格看差異：CZ法與FZ法的差異、SOI與塊材矽的差異、磊晶成長與CVD的差異
  • 用數字試試：可以用晶粒良率計算器，從晶圓直徑（150～450 mm）和晶片大小，計算能切出的晶片數。
  • 查詢詞語：晶體方向（表示晶體朝向的方式）、吸附雜質技術（gettering，捕捉金屬汙染的技術）、MCZ法（對坩堝施加磁場的CZ法）
  • 看圖解：加上設備零件名稱的CZ法圖解等，都收錄在圖解一覽中。
