SSD（固態硬碟）是什麼？快閃記憶體記住資料的原理

約 11 分鐘 · 更新：2026年10月23日

SSD（固態硬碟）是把資料以電子的量，記在快閃記憶體這種半導體晶片裡的儲存裝置。因為沒有會動的零件，所以比HDD快，也更耐撞擊。不過，記憶單元每次覆寫都會一點一點受損。所以SSD裡的控制晶片，會用分散寫入位置等做法來延長壽命。

先備知識：先讀過「記憶體和儲存空間有什麼不同？」，大致了解儲存空間和快閃記憶體，會比較容易閱讀。

生活中的例子：電腦變得安靜又快速的原因

現在的筆記型電腦，按下電源很快就能開機，也幾乎聽不到運轉的聲音。主要原因之一，是儲存裝置從HDD換成了固態硬碟（SSD）。

HDD（硬碟）用磁性把資料記錄在旋轉的圓盤上，並移動讀寫用的零件，去找要讀寫的位置。SSD沒有會動的零件，所以能馬上讀到想讀的位置，也不會發出聲音。另一方面，同樣的容量，HDD大多比較便宜，所以仍用來保存大量資料（差異的一覽請看「SSD與HDD的差異」）。

手機的儲存空間，也是和SSD同一種的晶片（「手機裡有哪些半導體？」）。

SSD裡面裝了什麼？

SSD的電路板上，數量最多的零件，是記住資料的晶片。這就是NAND型快閃記憶體，本文簡稱為「快閃記憶體」。

另一個重要的零件，是控制晶片（控制器）。它是SSD專用的小電腦，接收電腦「讀取」「寫入」的要求，再對快閃記憶體下指令。同時驅動好幾顆快閃記憶體來提高速度，以及後面要說明的延長壽命的做法，都是這顆晶片的工作。

很多SSD還裝有DRAM（關掉電源內容就會消失的高速記憶體）。這是為了存放一張對照表，記錄電腦指定的位址的資料，在哪一顆快閃記憶體的哪個位置。不裝DRAM的便宜SSD中，也有向電腦借用一點記憶體的產品（HMB）。

連接電腦和SSD的規則，有從HDD沿用下來的SATA，以及為SSD設計的NVMe。SATA的SSD，即使是2009年的3.0版，上限也約為每秒550 MB。NVMe使用電腦裡的高速通道（PCI Express），所以能快得多（「NVMe與SATA SSD的差異」）。

原理①：記憶單元用「開啟的電壓」的偏移來記住資料

快閃記憶體記住資料的最小單位，稱為記憶單元。記憶單元是1個有點特別的電晶體。電晶體是一種開關，在稱為閘極的電極加上電壓，電流就會流動（開啟）（「電晶體是什麼？」）。

閘極的電壓超過某個值，電晶體就開始開啟。這個「開始開啟的電壓」，稱為臨界電壓。快閃記憶體的記憶單元特別的地方，是這個值可以在事後改變。

記憶單元的閘極下方，有被絕緣膜包圍、用來存放電子的地方（圖請看「記憶體和儲存空間有什麼不同？」）。電子是帶負電的小粒子。電子存進這裡後，閘極正電壓的效果就會減弱。所以要開啟，就需要更高的電壓。也就是說，存的電子越多，臨界電壓越高。

讀取時，在閘極加上1個「分界」的電壓，檢查電流會不會流動。有流動就是電子少的狀態，沒有流動就是電子多的狀態。把這2種狀態分配給1和0。電子被絕緣膜包圍，很難跑掉，所以關掉電源後，資料也會保留。

存放電子的地方，有能導電的小板子（浮動閘極），也有能抓住電子的絕緣膜。現在的大容量產品大多是後者，稱為電荷捕捉型記憶單元。把電子推過絕緣膜的原理，在「穿隧效應是什麼？」中說明。

原理②：1個記憶單元存幾位元？SLC、TLC、QLC

把電子的量分成「少、多」2個等級來用，1個記憶單元就能記住1位元。這就是SLC。把電子的量分得更細來寫入，1個記憶單元就能塞進更多位元。

每增加1位元，要區分的等級數就變成2倍。2位元的MLC是4個等級，3位元的TLC是8個等級，4位元的QLC是16個等級。同樣數量的記憶單元，能記住的量是SLC的2倍、3倍、4倍。所以能降低每單位容量的價格。

即使寫入相同的資料，記憶單元的電壓也會有些差異，形成像圖中那樣的山。等級分得越細，山和山之間的間隔就越窄。所以「加入一點電子再確認」的步驟會變多，寫入就變慢。讀取時，也要改變分界的電壓，檢查好幾次。即使只漏掉一點電子，也容易和相鄰的等級分不清，所以能承受的覆寫次數也會減少。

總結來說，從SLC往QLC，會越來越便宜、容量越大，但也越慢、越容易磨損。所以現在電腦用的SSD，大多使用TLC或QLC。而且很多產品會把空著的記憶單元的一部分，暫時當成SLC使用，來彌補寫入的速度（「SLC、MLC、TLC、QLC的差異」）。

用比喻來說

多值的記憶單元，就像用杯子裡的水位來傳達數字。如果只有「空的或滿的」2種，就不會弄錯。用8種水位能傳達更多，但水只要少一點，就會讀錯。相似的是「等級分得越細，越經不起量的微小偏差」這一點。

比喻的限制：記憶單元裡電子的量，無法像用眼睛看那樣直接測量。要一邊改變電壓，一邊多次確認「會不會開啟」，才能判斷是哪個等級。

原理③：為什麼會磨損？

把資料寫入記憶單元時，用高電壓把電子推過絕緣膜。抹除時，用反方向的電壓把電子拉出來。這樣「寫入再抹除」1個來回，算作覆寫1次。

電子每次在強電壓下穿過絕緣膜，膜裡就會產生小小的損傷。電子卡在損傷裡，臨界電壓就會一點一點偏移。損傷變多，也會成為存著的電子漏出去的通道。就這樣，山的形狀變形，等級變得難以區分，這就是快閃記憶體磨損的原理。

能承受的覆寫次數，依記憶單元的方式和產品世代而有很大的不同。參考值是SLC約10萬次，TLC數千次，QLC約1,000次。出處是廠商金士頓（Kingston）的說明，以及2024年業界媒體的報導。

少量的讀取錯誤，由控制晶片來修正。寫入時加上用來檢查的額外資訊，讀取時找出錯誤的位元並改正。這稱為錯誤更正，記憶單元的等級越多、越小，就越不可缺少。

原理④：「以頁寫入，以區塊抹除」

快閃記憶體還有一個特性。已經有資料的位置不能直接覆蓋，必須先抹除再寫入。寫入時，以數萬個記憶單元組成的「頁」（page）為單位。抹除時，則以包含許多頁的「區塊」（block）為單位。1個區塊大約是64～512頁（2026年首爾大學的講義資料）。

用比喻來說

區塊就像用原子筆寫的裝訂筆記本。空白的頁可以一頁一頁寫上去，但寫過的頁不能用橡皮擦擦掉。要讓筆記本回到空白，只能整本重做。相似的是「寫入是一頁一頁，抹除是整本一起」這一點。

比喻的限制：真正的筆記本重做後就是新的。快閃記憶體的區塊每抹除一次就受損一點，而且會一直使用同一個區塊。另外，筆記本的頁可以照喜歡的順序寫，但快閃記憶體的區塊裡，通常只能照固定的順序寫入。

那麼，改寫檔案的一部分時會怎樣呢？控制晶片不會在原地改寫舊的頁，而是把新的內容寫到別的空白頁。然後更新對照表，在舊的頁標上「不再使用」的記號。就這樣，不再使用的頁，會一點一點累積在各個區塊裡。

原理⑤：控制晶片的4個做法

空白的頁不夠時，控制晶片就開始整理。它選出不再使用的頁較多的區塊，只把還需要的頁複製到別的區塊。接著把原本的區塊整個抹除，讓它恢復成空的。這種整理稱為垃圾回收。

圖中②的複製不是電腦要求的，但記憶單元還是會磨損。像這樣，實際寫入快閃記憶體的量，比電腦寫入的量還多，稱為寫入放大。整理時，區塊裡留下的需要的頁越多，要複製的量就越多，寫入放大也越大。

要減少複製的量，重要的是讓控制晶片早點知道哪些頁不需要了。但是刪除檔案時，通常只會改變電腦那邊的管理資訊。所以作業系統（OS）會通知SSD，刪除的位置「不再使用」。這個通知稱為TRIM，讓不需要的資料在整理時不必複製。

此外，SSD會裝比標示容量多一點的快閃記憶體，把多出來的部分當成使用者看不到的工作用空間。這稱為預留空間（over-provisioning）。空間越充裕，整理時能選的區塊就越多，能減少複製的量。

最後，寫入新資料時，會選擇損傷較少的區塊，幾乎不會變動的資料也會偶爾搬移。讓所有區塊以差不多的速度磨損，這個做法就是損耗平均。

原理⑥：3D NAND，把記憶單元垂直堆疊

長期以來，快閃記憶體的容量，是靠把記憶單元做小來增加的。但在平面上一直縮小，能存的電子會變少，相鄰的記憶單元也會互相影響。到了2010年代初期，這個做法已經接近極限。

於是，把記憶單元垂直堆疊的方法開始實用化。這稱為3D NAND。三星（Samsung）在2013年8月，宣布最多24層的產品開始量產。美光（Micron）在2022年7月，宣布232層的產品開始量產和出貨。SK海力士（SK hynix）在2024年11月，宣布321層的產品開始量產。

堆疊起來，不必擴大晶片的面積，就能增加記憶單元的數量，所以能更便宜地做出同樣容量的SSD。不過層數越多，準確地挖出深孔等製程就越困難。

關掉電源放著會怎樣？

即使被絕緣膜包圍，經過很長的時間，電子也會一點一點漏掉，臨界電壓會逐漸偏移。溫度越高，漏得越快；因覆寫而使膜受損的記憶單元，也越容易漏（溫度和速度的關係，請看「阿瑞尼斯方程式是什麼？」）。

業界團體JEDEC的JESD218規格，訂定了SSD應保持資料的期間。家庭和公司電腦用（用戶端用）的，是關掉電源、在30 ℃下1年。資料中心用（企業用）的，是在40 ℃下3個月。兩者都是用完保證的寫入量、在最受損的狀態下的最低值。即便如此，還是避免把多年不通電的SSD當成唯一的保存位置，比較安全。

壽命數字的看法：TBW和DWPD

SSD壽命的參考值，以保固期間內可以寫入的總量來表示。這就是TBW（terabytes written，總寫入量）。依照JEDEC的規格，寫入這個量之後，仍必須符合規定的錯誤率和資料保持期間。

另一種表示方式，是DWPD（drive writes per day，每日全碟寫入次數）。意思是「在保固期間內，每天可以寫入幾次全部容量」。例如三星990 PRO的1 TB款式，是600 TBW、保固5年。600 TB除以約1,800天，等於每天約330 GB，也就是約0.33 DWPD。

TBW是保固的參考值，超過不代表馬上會壞，在那之前也不保證一定不壞。

快閃記憶體與日本

快閃記憶體是在日本誕生的技術。東芝的舛岡富士雄等人，在1984年發表了NOR型，1987年發表了NAND型的快閃記憶體。SSD使用的，是適合大容量的NAND型（「NAND型與NOR型快閃記憶體的差異」）。

承接東芝記憶體事業的，是鎧俠（Kioxia）。截至2026年，鎧俠在日本四日市（三重縣）和北上（岩手縣）的工廠生產。

常見的誤解

誤解：SSD就算正常使用，也很快就會磨損壞掉

實際上，以一般的使用方式，要用完保證的寫入量，需要很多年。例如在600 TBW的SSD上每天寫入50 GB，也要30年以上才會達到600 TB。如果只聽到「次數有上限」，就會覺得好像很快會壞。不過，SSD也會因為零件故障等磨損以外的原因而損壞。重要的資料，也要複製一份到別的地方。

誤解：刪除檔案後，晶片上的資料會馬上消失

實際上，刪除後，記憶單元裡的電子並不會馬上被拉出來。用TRIM通知的位置，要等之後控制晶片整理時，才會以區塊為單位抹除。在那之前，資料有可能還留在記憶單元裡。要轉讓或丟棄SSD時，使用廠商或作業系統提供、能抹除整個SSD的功能，比較確實。

誤解：快閃記憶體的層數越多，SSD越快

實際上，層數主要影響的是1顆晶片能塞進多少（容量和價格）。SSD的速度，取決於連接方式（SATA或NVMe）、控制晶片、同時驅動幾顆晶片等。1顆晶片的容量增加後，同樣容量的SSD裝的晶片會變少，能同時驅動的數量也可能減少。層數多的新世代，輸入輸出通常也會改良，所以兩者容易被混為一談。
