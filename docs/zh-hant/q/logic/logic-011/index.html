邏輯電路

將2輸入NAND閘的兩個輸入接在一起成為1個輸入時，其作用為何？

  1. AAND
  2. BNOT（反相器）
  3. CXOR
查看答案與解析

正確答案：B. NOT（反相器）

當兩個輸入都輸入相同的值A時，輸出為 NOT(A AND A) = NOT A，作用如同反相器。只要能用NAND做出NOT，AND = NAND之後接NOT，OR = 將輸入各自反相後再接NAND（笛摩根），因此僅用NAND即可構成任意邏輯電路。NOR也是同樣的通用閘。不過在實際電路中，將輸入並接會使輸入電容增加，因此使用專用的反相器較有效率。
