邏輯電路

下列哪一項是多工器的正確功能？

  1. A將輸入的值記憶1個時脈
  2. B將輸入訊號的邏輯反相
  3. C依選擇訊號，從多個輸入中選出一個輸出
查看答案與解析

正確答案：C. 依選擇訊號，從多個輸入中選出一個輸出

多工器（選擇器）是依選擇訊號的值，從多個輸入中選出一個傳到輸出的電路，若選擇訊號為n位元，可從2ⁿ個輸入中選擇。在CPU中用於暫存器值的選擇與匯流排的切換，FPGA的邏輯區塊（LUT）也是以記憶體與多工器實現任意邏輯。將一個輸入分配到多個輸出之一的電路則是解多工器。
