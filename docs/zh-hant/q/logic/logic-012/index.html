邏輯電路

卡諾圖的主要用途是什麼？

  1. A測量電路的延遲時間
  2. B設計類比濾波器
  3. C化簡邏輯式
查看答案與解析

正確答案：C. 化簡邏輯式

卡諾圖是將真值表排列成相鄰方格的輸入僅相差1位元（格雷碼順序）的圖。將相鄰的1以1、2、4、8個的矩形圈起來，該範圍內變化的變數就會消去，邏輯式因而簡化。重點是將圖的兩端也視為相鄰。手工作業的極限約為4〜5個變數，超過時則以奎因-麥克拉斯基法或邏輯合成工具的演算法來化簡。

邏輯電路的其他題目

  1. 下列哪一項是對正反器設置時間的正確說明？
  2. 4位元的二進位計數器可表示的狀態數是多少？
  3. 下列哪一項是格雷碼的特徵？
  4. 下列哪一項是對D鎖存器動作的正確說明？
  5. 以正反器接收非同步訊號時，因無法滿足設置時間或保持時間，導致輸出暫時無法確定是0還是1的狀態，稱為什麼？

這個領域的比較

  • 閂鎖器與正反器的差異：比較動作與使用時機以觸發方式、輸出的動作、構成、尺寸、時序分析、突波與數位設計中的使用時機等面向，用表格比較閂鎖器與正反器。
  • 組合邏輯電路與循序邏輯電路的差異：比較輸出的決定方式以輸出由什麼決定、記憶元件、時脈、回授、範例、時序與 HDL 寫法等面向，用表格比較組合邏輯電路與循序邏輯電路。
  • CMOS 與 TTL 的差異：比較邏輯 IC 系列以電晶體、靜態耗電量、電源電壓、邏輯準位、雜訊邊限、速度、輸入與使用場合等面向，用表格比較 CMOS 與 TTL 邏輯 IC。
