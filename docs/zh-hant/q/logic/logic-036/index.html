邏輯電路

1位元組是幾位元？

  1. A8位元
  2. B4位元
  3. C16位元
查看答案與解析

正確答案：A. 8位元

1位元組為8位元，可表示256種（0〜255）的值，相當於半形英數字1個字元，或影像1個像素1種顏色（0〜255的濃淡）。4位元稱為半位元組（nibble），對應十六進位的1位數。早期的電腦中，1位元組也有6位元或9位元的情況，因此要嚴格指稱8位元時稱為「八位元組（octet）」，用於通訊規格等。

  • A. 正確。1位元組 = 8位元。
  • B. 4位元稱為半位元組（nibble），是半個位元組。
  • C. 16位元是2位元組。
