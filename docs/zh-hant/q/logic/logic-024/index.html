邏輯電路

將二進位數向左移1位元，其值會如何？（無溢位時）

  1. A變成2倍
  2. B變成一半
  3. C只增加1
查看答案與解析

正確答案：A. 變成2倍

在二進位數中，各位元的權重依次為2倍，因此向左移1位元並在最低位補0，值變為2倍，向右移則變為一半（捨去）。移n位元即為 2ⁿ 倍、1/2ⁿ。由於遠比乘除法器小且快，編譯器會將 x × 8 取代為 x << 3。有號數的右移必須使用複製符號位元的算術移位，否則負數無法正確除。
