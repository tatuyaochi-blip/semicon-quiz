邏輯電路

8位元的二補數表示所能表示的整數範圍是哪一個？

  1. A−128 〜 +127
  2. B−127 〜 +127
  3. C0 〜 255
查看答案與解析

正確答案：A. −128 〜 +127

n位元的二補數可表示 −2ⁿ⁻¹〜2ⁿ⁻¹ − 1，8位元為 −128〜+127。由於0的表示只有1種（00000000），負的一側會多1個。例如 −128 乘以 −1 無法表示而溢位，邊界值的處理需要注意。16位元為 −32,768〜+32,767，32位元約為±21億。0〜255是將同樣的8位元以無號數來解讀的範圍。

  • A. 正確。是 −2⁷ 〜 2⁷ − 1。
  • B. −127 〜 +127 是0有2種表示的符號加絕對值表示等的範圍。
  • C. 0 〜 255 是無號8位元的範圍。
