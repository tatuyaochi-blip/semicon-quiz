邏輯電路

以正反器接收非同步訊號時，因無法滿足設置時間或保持時間，導致輸出暫時無法確定是0還是1的狀態，稱為什麼？

  1. A亞穩態
  2. B突波
  3. C閂鎖效應
查看答案與解析

正確答案：A. 亞穩態

在亞穩態下，輸出會停留在中間電壓，或需要很長時間才會確定。原理上無法完全避免，只能讓機率隨著解決所需時間呈指數下降。因此非同步訊號以串接兩級以上正反器的同步電路接收，即使第一級不確定，到第二級為止確定的機率也能提高到足夠高（使平均故障間隔達數千年以上）。多位元的資料則以FIFO或交握（handshake）來傳遞。
