邏輯電路

依據3位元的輸入，在8條輸出中只讓1條有效的電路是哪一個？

  1. A編碼器
  2. B解碼器
  3. C計數器
查看答案與解析

正確答案：B. 解碼器

解碼器是依據n位元的輸入，在2ⁿ條輸出中只讓對應的1條有效的電路，3位元即為8條。它用於由記憶體位址選擇字元線或行的電路、CPU的指令解碼、七段顯示器的驅動等。由於各輸出對應輸入組合（最小項），也能以解碼器加OR閘做出任意的邏輯函數。與之作用相反的是編碼器。

  3. 對7位元的資料 1011001 加上偶同位元時，同位元的值是哪一個？
