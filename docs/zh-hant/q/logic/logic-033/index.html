邏輯電路

下列哪一項是NOT閘（反相器）的正確作用？

  1. A輸出兩個輸入的和
  2. B將輸入原樣輸出
  3. C將輸入的0與1反相後輸出
查看答案與解析

正確答案：C. 將輸入的0與1反相後輸出

NOT閘將輸入反相，輸入0時輸出1，輸入1時輸出0。在CMOS中是由nMOS與pMOS各1個組合而成的反相器，是邏輯電路最基本的構成元件。它不僅用於邏輯反相，也用作整理並放大衰減訊號波形的緩衝器（兩級則為非反相），將奇數個首尾相接成環則成為環形振盪器，用於評估製程的速度。

  • A. 處理兩個輸入的是AND、OR等2輸入閘。
  • B. 將輸入原樣輸出的是緩衝器。
  • C. 正確。將0與1反相。
