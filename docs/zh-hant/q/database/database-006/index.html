資料庫基礎

SQL敘述可分為資料定義語言（DDL）、資料操作語言（DML）與資料控制語言（DCL）。屬於DDL的是下列何者？

  1. AUPDATE 員工 SET 部門 = '研發' WHERE 員工編號 = 5
  2. BCREATE TABLE 部門 (部門編號 INTEGER PRIMARY KEY, 部門名稱 CHAR(10))
  3. CGRANT SELECT ON 員工 TO 田中
查看答案與解析

正確答案：B. CREATE TABLE 部門 (部門編號 INTEGER PRIMARY KEY, 部門名稱 CHAR(10))

DDL（Data Definition Language）是定義表格、檢視表、索引等資料庫結構的敘述，包括CREATE、ALTER、DROP。DML（Data Manipulation Language）是處理表格中資料的敘述，包括SELECT、INSERT、UPDATE、DELETE。DCL（Data Control Language）是控制權限等的敘述，包括授予使用者權限的GRANT與撤銷權限的REVOKE。確認交易的COMMIT與取消交易的ROLLBACK，有時歸入DCL，有時另外分為交易控制敘述。選項中，建立表格的CREATE TABLE屬於DDL。

  • A. UPDATE是改寫表格中資料的敘述，屬於DML。
  • B. 正確。定義表格結構的CREATE TABLE屬於DDL。
  • C. GRANT是授予使用者權限的敘述，屬於DCL。
