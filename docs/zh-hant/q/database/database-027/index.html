資料庫基礎

在交易應具備的ACID特性中，「從帳戶A扣款並存入帳戶B的轉帳處理，即使途中發生故障，也只會是兩者都完成或完全不進行」的性質是下列何者？

  1. A一致性（Consistency）
  2. B持久性（Durability）
  3. C原子性（Atomicity）
查看答案與解析

正確答案：C. 原子性（Atomicity）

ACID特性取自交易應滿足之4項性質的字首。原子性（Atomicity）是交易中的處理要不全部執行、要不完全不執行的性質，發生故障時會取消執行到一半的更新。一致性（Consistency）是交易前後資料持續滿足完整性限制（餘額不為負、外鍵的參照對象存在等）的性質。隔離性（Isolation）是同時執行的多筆交易彼此不干擾，結果與逐一依序執行時相同的性質。持久性（Durability）是已提交之交易的結果，即使之後發生故障也不會遺失的性質。題目中「全有或全無」的性質是原子性。

  • A. 一致性是交易前後資料持續滿足完整性限制的性質。
  • B. 持久性是已提交的結果在故障後也不會遺失的性質。
  • C. 正確。要不全部執行、要不完全不執行的性質就是原子性。
