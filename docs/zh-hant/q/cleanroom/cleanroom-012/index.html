無塵室與製造設備

在潔淨室中，尤其是曝光區域，將溫度控制得非常嚴格且恆定的主要理由為何？

  1. A僅僅是為了作業人員的舒適
  2. B為了防止晶圓與設備因熱膨脹造成位置偏移或尺寸誤差
  3. C為了讓照明更亮
查看答案與解析

正確答案：B. 為了防止晶圓與設備因熱膨脹造成位置偏移或尺寸誤差

矽的熱膨脹係數約為2.6×10⁻⁶ /K，300 mm的晶圓只要溫度改變0.1 ℃，就會伸縮約80 nm。曝光需要奈米等級的疊對精度，因此即使是些微的溫度變化也會造成位置偏移。因此在曝光機內部與周邊，會將溫度管理在±0.1 ℃以下的狹窄範圍內。這並不只是為了作業人員的舒適或照明。
