無塵室與製造設備

潔淨室中主要的發塵源之一，需靠穿著無塵衣來因應的是下列何者？

  1. A作業人員（人）
  2. B晶圓
  3. C天花板的濾網
查看答案與解析

正確答案：A. 作業人員（人）

人會持續釋放皮膚碎屑、頭髮、衣服纖維等，光是走路，每分鐘就可能釋放數百萬個粒子，是主要的發塵源。因此作業人員要穿著包覆全身的無塵衣、口罩與手套，並經過風淋室後才能進入。透過自動化讓人遠離晶圓，也是減少發塵的重要手段。天花板的濾網是去除粒子的一方。
