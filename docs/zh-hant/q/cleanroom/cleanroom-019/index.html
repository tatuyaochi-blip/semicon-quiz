無塵室與製造設備

下列何者被嚴格限制帶入潔淨室？

  1. A潔淨室專用紙（無塵紙）
  2. BFOUP
  3. C一般的紙或鉛筆等容易發塵的物品
查看答案與解析

正確答案：C. 一般的紙或鉛筆等容易發塵的物品

一般的紙纖維容易掉落，鉛筆則會產生削屑與筆芯粉末，因此在潔淨室中不能使用。取而代之的是使用低發塵的無塵紙與專用原子筆。化妝品與整髮用品也會造成粒子或分子態污染，因此有時受到限制。要帶入的物品需經過擦拭或換裝到專用袋，再從傳遞窗等處送入。無塵紙與FOUP則是可以使用的東西。
