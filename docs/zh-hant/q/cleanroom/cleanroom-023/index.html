無塵室與製造設備

在下吹流方式的潔淨室中，地板使用有孔面板（格柵板）的理由，下列何者正確？

  1. A為了地板防滑
  2. B為了讓地板變輕
  3. C為了讓從天花板吹出的空氣穿過地板下方並循環
查看答案與解析

正確答案：C. 為了讓從天花板吹出的空氣穿過地板下方並循環

在下吹流方式中，從天花板濾網吹出的空氣，會經由有孔的地板被吸入地板下的空間，再通過側面的通道等回到天花板循環。若地板不透氣，空氣會在地板上反彈並向橫向擴散，使粒子揚起。由於空氣持續單向流動，產生的粒子會立即被帶往地板下方。目的並不是防滑或減輕重量。
