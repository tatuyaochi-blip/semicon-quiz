無塵室與製造設備

下列何者是不讓潔淨室的濕度過度偏低而加以管理的理由之一？

  1. A因為容易發霉
  2. B因為濕度過低時容易產生靜電
  3. C因為照明會變暗
查看答案與解析

正確答案：B. 因為濕度過低時容易產生靜電

空氣過於乾燥時容易產生靜電，成為粒子附著在晶圓上，以及靜電放電損傷元件的原因。另一方面，濕度過高時，光阻的感度與附著性會改變，金屬的腐蝕也會加劇。因此潔淨室的濕度大多管理在40～45%RH左右的一定範圍內。理由並不是發霉或照明的亮度。
