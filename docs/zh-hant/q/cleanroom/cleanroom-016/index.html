無塵室與製造設備

下列關於無塵衣所需性質的敘述，何者正確？

  1. A保暖性非常高
  2. B顏色醒目
  3. C纖維屑等發塵少，且不易讓人體產生的粒子散到外面
查看答案與解析

正確答案：C. 纖維屑等發塵少，且不易讓人體產生的粒子散到外面

無塵衣以聚酯纖維等長纖維製成的低發塵布料製作，包覆全身，以免人體產生的皮屑、頭髮、衣服纖維等散出去。頸部、手腕、腳踝處採用束緊的結構，也有為了防止帶電而織入導電絲的款式。洗滌也在專用的工廠進行。保暖性與醒目的顏色並不是所需的性質。
