無塵室與製造設備

微影製程區域使用黃色照明的主要理由為何？

  1. A為了防止作業人員眼睛疲勞
  2. B為了不含會使光阻感光的短波長光
  3. C為了防止產生靜電
查看答案與解析

正確答案：B. 為了不含會使光阻感光的短波長光

光阻會對紫外線、藍光等波長約短於500 nm的光產生反應。一般白色照明含有這類光，因此改用截去短波長的黃色照明，以防止從塗佈到顯影之間發生非預期的感光。這樣的區域稱為黃光室。其目的並不是防止眼睛疲勞或靜電。
