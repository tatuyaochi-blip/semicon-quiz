無塵室與製造設備

潔淨室的地板材料或作業台使用具導電性（讓靜電逸散的性質）材料的主要理由為何？

  1. A為了讓地板發亮而更明亮
  2. B為了防止因帶電產生的靜電放電損壞元件，或粒子被靜電吸引而附著
  3. C為了通電讓地板變暖
查看答案與解析

正確答案：B. 為了防止因帶電產生的靜電放電損壞元件，或粒子被靜電吸引而附著

潔淨室中有許多樹脂製的容器與衣物，而且環境乾燥，容易累積靜電。若帶電的物體或人發生放電（ESD），元件可能損壞，而帶電的晶圓會吸引粒子。結合導電性的地板與作業台、接地的腕帶、導電性的鞋子，將電荷釋放到大地。目的並不是外觀或地板暖氣。

  • A. 不是為了外觀。
  • B. 正確。是為了不累積靜電。
  • C. 不是為了地板暖氣。
