無塵室與製造設備

從玻璃纖維濾網等釋出，可能造成晶圓非預期摻雜（污染）的元素是下列何者？

  1. A硼（boron）
  2. B金
  3. C鐵
查看答案與解析

正確答案：A. 硼（boron）

玻璃纖維HEPA濾網中有使用硼矽玻璃的類型，與氫氟酸蒸氣等反應後，可能釋出含硼的氣體。若附著在晶圓表面，就會作為p型雜質造成非預期的摻雜，使特性偏移。因此會使用低硼濾材的濾網，以及化學濾網。金與鐵是形成深能階的金屬污染，並不是濾網來源的代表。
