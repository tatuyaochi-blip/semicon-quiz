無塵室與製造設備

在潔淨室的空調中，將引入的外氣除塵、調整溫度與濕度後，再供應給室內循環空氣的裝置是下列何者？

  1. A裝載埠
  2. B洗滌塔
  3. C外氣處理空調機（外調機，MAU）
查看答案與解析

正確答案：C. 外氣處理空調機（外調機，MAU）

潔淨室為了維持正壓與補充排氣而引入外氣，但外氣的溫度與濕度會隨季節大幅變化，也含有髒污。一般的分工是：以外氣處理空調機將其除塵，並使溫度與濕度保持一定，室內則一邊以FFU等淨化循環空氣，一邊進行細部的溫度調整。由於濕度管理可集中到外調機，室內的控制會更穩定。

  • A. 裝載埠是放置FOUP並傳遞給設備的部分。
  • B. 洗滌塔是清洗排氣的裝置。
  • C. 正確。統一對外氣進行前處理。
