無塵室與製造設備

用來測量潔淨室空氣中所含微粒的數量與大小的裝置是下列何者？

  1. A光散射式粒子計數器
  2. B四點探針量測儀
  3. C橢圓偏光儀（ellipsometer）
查看答案與解析

正確答案：A. 光散射式粒子計數器

光散射式粒子計數器，是對吸入的空氣照射雷射光，由粒子散射光的強度求出粒子的大小，由光脈衝的數量求出個數。可計數至約0.1 µm的粒子，除了在規定的位置與吸氣量下測量以評估ISO等級之外，也常設置於現場，日常監控潔淨度的變化。也有計數液體中粒子的裝置，用於超純水與藥液的管理。

  • A. 正確。以散射光計數粒子。
  • B. 四點探針量測儀是量測薄膜或晶圓電阻率的裝置。
  • C. 橢圓偏光儀是量測薄膜厚度與折射率的裝置。
