測試與檢查

連接測試機與IC的測試用治具中，使用以彈簧伸縮的細針使其確實接觸端子的零件為下列何者？

  1. A接合線（bonding wire）
  2. B錫球
  3. C彈簧針（pogo pin，彈簧探針）
查看答案與解析

正確答案：C. 彈簧針（pogo pin，彈簧探針）

彈簧針是在筒內裝入彈簧的細小接觸針，壓在IC的端子或電路板的電極上時，能以適當的力確實接觸，並吸收端子高度的變異。大量用於測試插座，以及測試頭與負載板的連接等處。反覆接觸數十萬次後，前端會磨損並沾上髒污，因此需定期清潔與更換。接合線或錫球則是產品的一部分。

  • A. 接合線是連接晶片與封裝的永久性配線。
  • B. 錫球是將封裝接合到電路板的端子。
  • C. 正確。是以彈簧伸縮的接觸針。

測試與檢查的其他題目

  1. 安裝於測試機的測試頭，承載IC的插座與周邊零件，並依產品將訊號引導至IC的印刷電路板，稱為什麼？
  2. 在探針卡的方式中，將針垂直於焊墊豎立排列的垂直式，其主要優點為下列何者？
  3. 持續進行晶圓測試後，焊墊的鋁屑等會附著在探針的針尖上。此時定期進行的處理為下列何者？
  4. 在探針台上，使承載晶圓的平台（載台，chuck）的溫度能控制在高溫或低溫，其目的為下列何者？
  5. 在邏輯電路的測試中，使用掃描等方式全面偵測電路結構上的故障（固定型故障等）的測試，與依實際運作確認功能的測試，其名稱的組合下列何者正確？
