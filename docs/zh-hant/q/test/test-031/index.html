測試與檢查

製造半導體產品時進行測試的主要目的為下列何者？

  1. A找出並剔除製造中產生的不良品，只出貨符合規格的產品
  2. B為了確認晶片的顏色
  3. C為了量測晶片的重量
查看答案與解析

正確答案：A. 找出並剔除製造中產生的不良品，只出貨符合規格的產品

無論管理得多好，製造過程中仍會以一定比例產生具有缺陷的晶片。透過測試檢查電氣特性與功能並剔除不良品，只出貨符合規格的產品。不良越晚被發現損失越大，若在市場上被發現，則會成為召回等重大問題。測試的結果也是探究不良原因、改善製造製程的資料。

  • A. 正確。剔除不良品，只出貨良品。
  • B. 確認顏色並不是目的。
  • C. 量測重量並不是目的。
