測試與檢查

量測CMOS電路靜止狀態時的電源電流，以偵測橋接故障等缺陷的測試稱為什麼？

  1. AIDDQ測試
  2. B功能測試
  3. CBurn-in（老化測試）
查看答案與解析

正確答案：A. IDDQ測試

CMOS電路在靜止狀態下，pMOS與nMOS其中之一必定為關閉，因此幾乎沒有電源電流流過。若有配線之間的短路（橋接）或閘極氧化膜的缺陷，靜止時電流會從電源流向接地，因此量測靜止時的電源電流（IDDQ）即可偵測缺陷。不過隨著微縮，漏電流變大，與正常品的區別變得困難。
