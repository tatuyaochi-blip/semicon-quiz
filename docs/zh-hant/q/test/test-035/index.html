測試與檢查

設置於晶圓上晶片之間（切割道，scribe line）等處，用來量測電晶體或電阻等的特性以評估製程的專用圖樣，稱為什麼？

  1. A虛設閘極（dummy gate）
  2. B對準標記
  3. CTEG（測試元件群）
查看答案與解析

正確答案：C. TEG（測試元件群）

TEG是為了評估製程成果，由電晶體、電阻、電容、配線鏈等簡單結構所組成的集合。由於產品電路複雜，無法直接量測個別元件的特性，因此以TEG量測具代表性元件的特性。設置在切割道的TEG會在切割時被切除，所以不需占用產品的面積。在開發階段也會製作專用的TEG晶圓。

  • A. 虛設閘極是為了加工均勻性等目的而設置、沒有功能的閘極。
  • B. 對準標記是曝光時用於位置對準的記號。
  • C. 正確。是用於製程評估的測試圖樣。

測試與檢查的其他題目

  1. 對完成前段製程的晶圓，量測TEG的臨界電壓或片電阻等，確認製程是否依規格完成的檢驗，稱為什麼？
  2. 連接測試機與IC的測試用治具中，使用以彈簧伸縮的細針使其確實接觸端子的零件為下列何者？
  3. 安裝於測試機的測試頭，承載IC的插座與周邊零件，並依產品將訊號引導至IC的印刷電路板，稱為什麼？
  4. 在探針卡的方式中，將針垂直於焊墊豎立排列的垂直式，其主要優點為下列何者？
  5. 持續進行晶圓測試後，焊墊的鋁屑等會附著在探針的針尖上。此時定期進行的處理為下列何者？

這個領域的比較

  • 靜態、動態與晶圓級預燒測試的差異：應力、涵蓋性、成本比較從施加應力的方式、進行的階段、典型條件、承受應力的範圍、設備與治具、監控、成本、課題與用途等面向，以表格比較靜態預燒測試、動態預燒測試與晶圓級預燒測試，並說明各自適用的時機。
  • 掃描測試與內建自我測試（BIST）的差異：測試向量、測試機、對象、追加電路比較從測試向量的產生方式（ATPG 與內建產生器）、對測試機的依賴、對象（邏輯與記憶體）、故障涵蓋率、追加電路與測試時間等面向，比較掃描測試與 BIST（內建自我測試）。
  • 晶圓測試與最終測試的差異：時機、接觸方式、溫度、項目、目的比較從測試時機與對象、接觸方式（探針卡與測試座）、溫度、測試項目、找出不良品的目的與 KGD 等面向，以表格比較晶圓測試（探針測試）與最終測試。
