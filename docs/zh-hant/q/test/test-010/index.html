測試與檢查

為了降低測試成本，以測試機同時量測多個晶片的手法稱為什麼？

  1. ABurn-in（老化測試）
  2. B多點測試（multi-site test，同時量測）
  3. C打線接合
查看答案與解析

正確答案：B. 多點測試（multi-site test，同時量測）

測試成本幾乎與使用昂貴測試機的時間成正比。在多點測試中，以一台測試機並行量測多個晶片，降低每個晶片的測試時間與成本。記憶體測試甚至會同時量測數百個。由於同時量測的晶片數量有多少，就需要多少測試機通道，因此會搭配以BIST或掃描壓縮減少所需腳位的作法。
