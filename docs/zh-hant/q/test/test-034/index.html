測試與檢查

在測試中，依序施加於晶片輸入的0與1訊號的排列，以及與之對應的期望值所組成的組合，稱為什麼？

  1. A配方（recipe）
  2. B測試圖樣（測試向量）
  3. C光罩
查看答案與解析

正確答案：B. 測試圖樣（測試向量）

測試圖樣（測試向量）是彙整了各時刻施加於晶片輸入的訊號值，以及此時應輸出的期望值。能有效率偵測故障的圖樣，可由ATPG自動產生，或將設計時驗證用的模擬轉換而製成。圖樣越長，測試時間就越長，因此要加以最佳化，使得以較少的圖樣偵測較多的故障。

  • A. 配方是指製造設備的處理條件設定。
  • B. 正確。是輸入的排列與期望值的組合。
  • C. 光罩是用於在曝光時轉印圖樣的原版。

  1. 設置於晶圓上晶片之間（切割道，scribe line）等處，用來量測電晶體或電阻等的特性以評估製程的專用圖樣，稱為什麼？
