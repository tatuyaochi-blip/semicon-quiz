測試與檢查

在高速串列通訊介面的測試中，將晶片傳送電路的輸出折返連接到接收電路，由晶片自行確認通訊的方法為下列何者？

  1. AIDDQ測試
  2. BBurn-in（老化測試）
  3. C迴路測試（loopback test）
查看答案與解析

正確答案：C. 迴路測試（loopback test）

對於高達數十Gb/s的高速SerDes等，僅靠測試機直接量測既困難又昂貴。在迴路測試中，從傳送電路輸出偽隨機資料並送回接收電路，由晶片內的電路計算位元錯誤。有在晶片內折返的方法，也有經由負載板上的配線從外部折返的方法，可用通用的測試機有效率地測試高速介面。

  • A. IDDQ測試是以靜止時的電源電流偵測缺陷的測試。
  • B. Burn-in是剔除早期不良的應力試驗。
  • C. 正確。是將傳送折返到接收來確認的方法。
