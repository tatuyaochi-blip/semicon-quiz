測試與檢查

安裝於測試機的測試頭，承載IC的插座與周邊零件，並依產品將訊號引導至IC的印刷電路板，稱為什麼？

  1. A負載板（load board，DUT板）
  2. B主機板
  3. C封裝基板
查看答案與解析

正確答案：A. 負載板（load board，DUT板）

負載板（DUT板）是連接測試機與受測元件（DUT）、依產品而定的專用電路板。上面搭載插座、電源的去耦電容、繼電器與負載電路等，將測試機的訊號正確地佈線至IC的端子。高速訊號還必須使配線長度與特性阻抗一致，因此依產品逐一設計、製作。它與主機板或封裝基板是不同的東西。

  • A. 正確。是連接測試機與IC、依產品而定的專用電路板。
  • B. 主機板是個人電腦等的主要電路板。
  • C. 封裝基板是承載晶片的封裝的一部分。

測試與檢查的其他題目

  1. 在探針卡的方式中，將針垂直於焊墊豎立排列的垂直式，其主要優點為下列何者？
  2. 持續進行晶圓測試後，焊墊的鋁屑等會附著在探針的針尖上。此時定期進行的處理為下列何者？
  3. 在探針台上，使承載晶圓的平台（載台，chuck）的溫度能控制在高溫或低溫，其目的為下列何者？
  4. 在邏輯電路的測試中，使用掃描等方式全面偵測電路結構上的故障（固定型故障等）的測試，與依實際運作確認功能的測試，其名稱的組合下列何者正確？
  5. 因測試的判定過於嚴格或量測不穩定，而將原本是良品的晶片判定為不良並丟棄，稱為什麼？

這個領域的比較

  • 靜態、動態與晶圓級預燒測試的差異：應力、涵蓋性、成本比較從施加應力的方式、進行的階段、典型條件、承受應力的範圍、設備與治具、監控、成本、課題與用途等面向，以表格比較靜態預燒測試、動態預燒測試與晶圓級預燒測試，並說明各自適用的時機。
  • 掃描測試與內建自我測試（BIST）的差異：測試向量、測試機、對象、追加電路比較從測試向量的產生方式（ATPG 與內建產生器）、對測試機的依賴、對象（邏輯與記憶體）、故障涵蓋率、追加電路與測試時間等面向，比較掃描測試與 BIST（內建自我測試）。
  • 晶圓測試與最終測試的差異：時機、接觸方式、溫度、項目、目的比較從測試時機與對象、接觸方式（探針卡與測試座）、溫度、測試項目、找出不良品的目的與 KGD 等面向，以表格比較晶圓測試（探針測試）與最終測試。
