測試與檢查

依據晶圓測試等過程中的結果與統計，依晶片、依批次動態改變測試項目或判定值的手法稱為什麼？

  1. A自適應測試（adaptive test）
  2. B虛設測試（dummy test）
  3. C黑箱測試（black box test）
查看答案與解析

正確答案：A. 自適應測試（adaptive test）

在自適應測試中，依據前一個製程或同一晶圓上其他晶片的結果、統計上離群值的偵測等，追加或省略測試，或改變判定值。例如，剔除即使在規格內也與周圍晶片有大幅偏離之值的晶片的PAT（零件平均測試，part average test），用於車用產品以減少潛在不良。在維持品質的同時，也能減少測試時間。

  • A. 正確。是依據結果動態改變測試的手法。
  • B. 這並不是這類名稱的一般手法。
  • C. 黑箱測試是不看內部結構、僅以輸入輸出確認的軟體測試觀念。
