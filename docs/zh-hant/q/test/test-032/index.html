測試與檢查

在晶圓測試中，探針卡的針所接觸的晶片上位置為下列何者？

  1. A電晶體的閘極上方
  2. B晶片的電極焊墊
  3. C僅晶圓背面的中央
查看答案與解析

正確答案：B. 晶片的電極焊墊

在晶圓測試中，使探針卡的許多探針接觸排列在各晶片周邊等處的電極焊墊，由測試機施加電源與訊號並量測回應。焊墊也是之後打線接合或凸塊連接所使用的電極，大小為數十µm見方。為了避免針痕妨礙接合，也會檢查針痕的大小與位置。電晶體位於配線層之下，無法直接接觸。

  • A. 電晶體的閘極位於配線層之下，無法直接以針接觸。
  • B. 正確。使針接觸電極焊墊。
  • C. 僅憑晶圓背面無法連接電路的各端子。

這個領域的比較

  • 靜態、動態與晶圓級預燒測試的差異：應力、涵蓋性、成本比較從施加應力的方式、進行的階段、典型條件、承受應力的範圍、設備與治具、監控、成本、課題與用途等面向，以表格比較靜態預燒測試、動態預燒測試與晶圓級預燒測試，並說明各自適用的時機。
  • 掃描測試與內建自我測試（BIST）的差異：測試向量、測試機、對象、追加電路比較從測試向量的產生方式（ATPG 與內建產生器）、對測試機的依賴、對象（邏輯與記憶體）、故障涵蓋率、追加電路與測試時間等面向，比較掃描測試與 BIST（內建自我測試）。
  • 晶圓測試與最終測試的差異：時機、接觸方式、溫度、項目、目的比較從測試時機與對象、接觸方式（探針卡與測試座）、溫度、測試項目、找出不良品的目的與 KGD 等面向，以表格比較晶圓測試（探針測試）與最終測試。
