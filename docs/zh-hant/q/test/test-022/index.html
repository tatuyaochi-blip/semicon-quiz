測試與檢查

在測試程式的開發中，為了降低測試成本而重視的事項，下列何者正確？

  1. A在能充分偵測不良的範圍內，最佳化量測項目與順序以縮短測試時間
  2. B將所有項目都以最多的次數量測
  3. C省略不良多的項目的測試
查看答案與解析

正確答案：A. 在能充分偵測不良的範圍內，最佳化量測項目與順序以縮短測試時間

由於測試成本幾乎與測試時間成正比，因此在能確保品質的範圍內縮減量測項目，並設法調整量測的順序與條件以縮短測試時間。例如先量測容易不良的項目以便提早中止，或根據過去的資料檢討幾乎不出現不良的項目。若省略不良多的項目，漏檢會增加；若將所有項目都量測最多次，成本則會膨脹。
