測試與檢查

在記憶體測試中，一邊依序走訪位址，一邊反覆寫入與讀出0和1，也能偵測相鄰單元之間干擾等不良的測試圖樣為下列何者？

  1. AIDDQ測試
  2. BShmoo圖
  3. CMarch測試
查看答案與解析

正確答案：C. March測試

March測試是一種記憶體的測試演算法，一邊以升冪或降冪走訪位址，一邊對每個單元依規定順序進行寫入與讀出。具代表性的March C−每個單元進行10次操作，除了固定型故障之外，也能偵測相鄰單元之間的干擾（耦合故障）以及位址解碼器的不良。由於測試時間與單元數成正比，因此也可用於大容量記憶體。
