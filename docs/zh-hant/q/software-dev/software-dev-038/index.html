軟體開發與專案管理

關於用於估算軟體規模的功能點分析法，下列說明何者適當？

  1. A以過去開發的類似系統實績為基礎，修正差異後估算整體的規模與工時
  2. B估算原始碼的行數，以此作為輸入，用計算公式求出工時與工期
  3. C從外部輸入、外部輸出、外部查詢、內部邏輯檔案、外部介面檔案的數量與複雜度，將使用者看到的功能量換算為點數來估算
查看答案與解析

正確答案：C. 從外部輸入、外部輸出、外部查詢、內部邏輯檔案、外部介面檔案的數量與複雜度，將使用者看到的功能量換算為點數來估算

功能點分析法是將系統提供給使用者的功能量，以輸入輸出、查詢、處理的檔案（資料）的數量與複雜度換算成點數來衡量的方法。其優點是不依賴程式語言，而且從需求或外部設計階段就能估算。從原始碼行數以計算公式求工時的是 COCOMO 等方法，以過去類似系統為基礎的則是類比估算法。實務上常以多種方法估算並比較結果。

  • A. 這是類比估算法的說明。
  • B. 這是從原始碼行數（LOC）以計算公式求工時的 COCOMO 等方法的說明。
  • C. 正確。將使用者看到之功能的數量與複雜度換算成點數，以衡量規模。
