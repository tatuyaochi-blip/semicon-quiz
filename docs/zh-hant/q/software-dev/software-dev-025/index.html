軟體開發與專案管理

在規模25 k行（2萬5,000行）韌體的整合測試中，發現了30件缺陷。依組織過去的實績，此工程發現缺陷的參考值為每1 k行2～4件。對此結果的評估，下列何者最適當？

  1. A缺陷密度在參考範圍內，因此判斷品質符合計畫
  2. B缺陷密度為每1 k行1.2件，低於參考值，因此不應斷定品質良好，要確認是否測試不足（測試案例有遺漏）
  3. C缺陷密度為每1 k行1.2件，低於參考值，因此判斷品質非常好，省略其餘的測試
查看答案與解析

正確答案：B. 缺陷密度為每1 k行1.2件，低於參考值，因此不應斷定品質良好，要確認是否測試不足（測試案例有遺漏）

缺陷密度為 30件 ÷ 25 k行 = 每1 k行1.2件，低於參考值的2～4件。低於參考值時，可能是做得好，但也可能是測試案例未充分涵蓋規格、測試觀點有偏頗等，因測試不足而未能找出缺陷。因此要先分析測試的涵蓋狀況與缺陷內容再評估。高於參考值時，則要調查設計與實作的品質是否有問題。

  • A. 每1 k行1.2件，在參考值2～4件的範圍之外。
  • B. 正確。低於參考值時，要懷疑測試不足並加以確認。
  • C. 數量少的原因可能是測試不足，未經確認就省略測試是危險的。
