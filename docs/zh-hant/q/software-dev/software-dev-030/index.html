軟體開發與專案管理

將結點設為①～⑥，以「名稱：起點→終點、所需天數」表示作業，有一張箭線圖為：A：①→②、6天，B：①→③、4天，C：②→④、4天，D：③→⑤、4天，E：④→⑥、2天，F：⑤→⑥、3天，虛作業：②→③（所需天數0）。專案整體最短的所需天數為下列何者？

  1. A11天
  2. B12天
  3. C13天
查看答案與解析

正確答案：C. 13天

虛作業②→③表示作業 D 要開始，不只 B，A 也必須已經完成。各結點的最早時間為：②是6天，③是 max(4, 6 + 0) = 6天，④是 6 + 4 = 10天，⑤是 6 + 4 = 10天，⑥是 max(10 + 2, 10 + 3) = 13天，因此整體所需天數為13天，要徑為 A→虛作業→D→F。若漏看虛作業，D 就變成可在第4天開始，使 A→C→E 的12天成為最長。11天只是 B→D→F 路徑的天數。

  • A. 只有 B→D→F（4 + 4 + 3）的天數，忽略了 D 之前 A 也必須完成。
  • B. 這是漏看虛作業的情況，A→C→E（6 + 4 + 2）會成為最長。
  • C. 正確。A→虛作業→D→F 的 6 + 0 + 4 + 3 = 13天為最長。

軟體開發與專案管理的其他題目

  1. 某專案的作業、所需天數與前置作業為：A：4天（無前置作業）、B：2天（無）、C：3天（A）、D：2天（B）、E：5天（C）、F：4天（C 與 D）、G：2天（F）。其他作業都盡早開始時，作業 B 延後開始而不使整體所需天數增加的最大天數為下列何者？
  2. 某專案的作業、所需天數與前置作業為：A：6天（無）、B：4天（無）、C：4天（A）、D：4天（A 與 B）、E：2天（C）、F：3天（D），整體所需天數為13天。各作業縮短1天所需的追加費用為：A 30萬日圓、B 5萬日圓、C 10萬日圓、D 20萬日圓、E 8萬日圓、F 25萬日圓。要將整體所需天數縮短1天，追加費用最少的方法為下列何者？
  3. 以三點估計估算某作業的所需天數，得到樂觀值4天、最可能值7天、悲觀值16天。以 PERT 公式求得的所需天數期望值為下列何者？
  4. 在完工預算（BAC）為2,000萬日圓的專案中，某時間點的計畫值（PV）為800萬日圓、實獲值（EV）為600萬日圓、實際成本（AC）為750萬日圓。此時間點專案的狀況，下列何者正確？
  5. 在完工預算（BAC）為1,200萬日圓的專案中，目前的計畫值（PV）為600萬日圓、實獲值（EV）為480萬日圓、實際成本（AC）為600萬日圓。假設今後目前的成本效率持續下去，完工估算（EAC）為下列何者？
