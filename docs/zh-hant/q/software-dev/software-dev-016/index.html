軟體開發與專案管理

關於黑箱測試的說明，下列何者適當？

  1. A不看程式的內部結構，依據規格決定輸入與預期輸出，確認是否正確運作
  2. B著眼於程式的內部結構，以敘述或分支是否被執行為基準建立測試案例
  3. C使用者在實際的業務環境中，最後確認系統能否依需求使用
查看答案與解析

正確答案：A. 不看程式的內部結構，依據規格決定輸入與預期輸出，確認是否正確運作

黑箱測試是將測試對象視為看不到內部的箱子，只依據規格建立測試案例的方法，技法有等價類劃分、邊界值分析、因果圖、決策表等。它容易找出規格中有但未實作的功能等，但無法得知是否走過實作中的特定路徑。著眼於內部結構、以涵蓋率為基準的是白箱測試。使用者的最終確認是驗收測試，這是測試階段的名稱。

  • A. 正確。只依據規格建立測試案例，以輸入與輸出確認。
  • B. 這是白箱測試的說明。
  • C. 這是驗收測試的說明，指的不是測試案例的建立方式，而是測試階段。
