軟體開發與專案管理

在 UML 中，將多個物件之間往來的訊息（呼叫或回應）依時間順序由上往下排列表示的圖為下列何者？

  1. A活動圖
  2. B循序圖
  3. C類別圖
查看答案與解析

正確答案：B. 循序圖

在循序圖中，每個物件畫一條垂直線（生命線），並以箭頭依時間順序畫出它們之間的訊息。例如，用來確認應用程式呼叫驅動程式、驅動程式寫入周邊電路的暫存器、再以中斷通知完成這類往來的順序。活動圖是像流程圖一樣，表示處理流程與分支、平行處理的圖。類別圖表示的不是時間順序，而是類別的結構與關係。

  • A. 表示處理流程與分支、平行處理的圖，不是將物件間的訊息依時間順序排列的圖。
  • B. 正確。依時間順序表示物件之間的訊息往來。
  • C. 表示類別結構與關係的靜態圖，不表示時間順序。
