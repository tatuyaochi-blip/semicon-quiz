軟體開發與專案管理

在設計書或原始碼的審查方法中，由主持人（moderator）主導、決定參加者的角色、使用檢查表等正式進行，並記錄找到的缺陷且確認到修正完成的是下列何者？

  1. A檢驗（inspection）
  2. B走查（walkthrough）
  3. C輪流審查（round robin）
查看答案與解析

正確答案：A. 檢驗（inspection）

檢驗是由主持人管理從規劃、主持到確認修正（後續追蹤）的最正式審查。參加者事先準備，依檢查表尋找缺陷，並記錄找到的缺陷數量與種類，因此可用於品質的評估與改善。走查是由作者主導，依序說明產出物的內容，由參加者找出錯誤的方法。輪流審查是參加者輪流擔任主持人或審查負責人的方法。

  • A. 正確。由主持人主導，使用檢查表與缺陷紀錄的正式審查。
  • B. 由作者主導、一邊說明內容一邊進行的審查，不如檢驗正式。
  • C. 參加者輪流擔任主持人或審查負責人的方法。
