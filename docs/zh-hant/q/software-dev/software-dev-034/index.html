軟體開發與專案管理

在完工預算（BAC）為2,000萬日圓的專案中，某時間點的計畫值（PV）為800萬日圓、實獲值（EV）為600萬日圓、實際成本（AC）為750萬日圓。此時間點專案的狀況，下列何者正確？

  1. A時程落後（SPI = 0.75），成本也超出預算（CPI = 0.8）
  2. B時程落後（SPI = 0.75），但成本在預算之內（CPI = 1.25）
  3. C時程超前（SPI = 1.33），但成本超出預算（CPI = 0.8）
查看答案與解析

正確答案：A. 時程落後（SPI = 0.75），成本也超出預算（CPI = 0.8）

時程績效指數 SPI = EV ÷ PV = 600 ÷ 800 = 0.75，小於1，因此比預定落後（時程偏差 SV = EV − PV = −200萬日圓）。成本績效指數 CPI = EV ÷ AC = 600 ÷ 750 = 0.8，小於1，因此花費的成本多於已完成工作的預算（成本偏差 CV = EV − AC = −150萬日圓）。在實獲值管理（EVM）中，將實獲值（EV）同時與計畫值（PV）及實際成本（AC）比較，以同一個金額尺度評估進度與成本。

  • A. 正確。SPI = 600 ÷ 800 = 0.75、CPI = 600 ÷ 750 = 0.8，兩者都小於1。
  • B. 這是把 CPI 反過來以 AC ÷ EV 計算的值。CPI = EV ÷ AC = 0.8，超出預算。
  • C. 這是把 SPI 反過來以 PV ÷ EV 計算的值。SPI = EV ÷ PV = 0.75，時程落後。
