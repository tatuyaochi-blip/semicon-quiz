C語言基礎

void f(int x) { x = 10; }
void g(int *p) { *p = 20; }
int main(void) {
    int a = 1, b = 1;
    f(a);
    g(&b);
    printf("%d %d\n", a, b);
    return 0;
}

執行上方程式時的輸出，下列何者正確？

  1. A1 20
  2. B10 1
  3. C10 20
查看答案與解析

正確答案：A. 1 20

C語言函式的引數是傳值，呼叫 f(a) 時，a 的值1會被複製到 x。即使在 f 中把 x 改為10，改變的也只是複本，呼叫端的 a 仍是1。g(&b) 傳入的是 b 的位址，因此 g 中的 *p = 20 寫入的是 b 本身，b 變成20。要在被呼叫的函式中改變呼叫端的變數時，就像這樣傳入指標。

  • A. 正確。以值傳入的 a 不變，傳入位址的 b 變成20。
  • B. 這是把 f 與 g 的作用想反時的值。傳值的 f 不會改變 a，接收位址的 g 會改變 b。
  • C. 在 f 中改變的只有引數 x（a 的複本），a 仍是1。
