CMP與清洗

下列關於CMP相較於熱回流或回蝕（etch-back）平坦化所具有的優點，何者正確？

  1. A一定成本較低
  2. B完全不產生研磨屑
  3. C可做到涵蓋整片晶圓的大範圍平坦化（全域平坦化）
查看答案與解析

正確答案：C. 可做到涵蓋整片晶圓的大範圍平坦化（全域平坦化）

BPSG的熱回流或使用光阻的回蝕，雖然能使局部段差變平緩，但要在數mm到數cm的範圍內平坦化則有困難。CMP以硬研磨墊優先研磨凸出部分，因此可在整個晶片乃至整片晶圓上得到高度的平坦性（全域平坦化）。這使表面得以落在曝光的聚焦深度內，並促成了超過10層的多層配線與銅配線的實現。
