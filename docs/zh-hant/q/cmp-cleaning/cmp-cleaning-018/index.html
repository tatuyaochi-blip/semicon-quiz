CMP與清洗

下列關於晶圓表面的鐵、銅等金屬汙染所引起的問題，何者正確？

  1. A載子生命週期降低，以及閘極氧化膜耐壓降低等所造成的特性與可靠度劣化
  2. B晶圓變輕
  3. C晶圓發光
查看答案與解析

正確答案：A. 載子生命週期降低，以及閘極氧化膜耐壓降低等所造成的特性與可靠度劣化

鐵、銅等金屬雜質會在矽中的能隙中間附近形成深能階而成為複合中心，使載子生命週期降低，並增加接面的漏電流或影像感測器的白點。若被帶入閘極氧化膜，則會降低耐壓與可靠度。因此要藉由清洗將金屬汙染抑制在約10⁹～10¹⁰ atoms/cm²以下，藥液與純水中的金屬雜質也要以ppt（兆分之一）等級管理。
