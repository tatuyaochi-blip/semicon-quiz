CMP與清洗

在SC-1這類鹼性清洗液中，一度脫離的微粒不易再度附著，其原因下列何者正確？

  1. A因為清洗液的黏度非常高
  2. B因為晶圓表面與粒子帶有相同符號的電荷而相互排斥
  3. C因為粒子溶解於清洗液中而消失
查看答案與解析

正確答案：B. 因為晶圓表面與粒子帶有相同符號的電荷而相互排斥

在鹼性液體中，矽表面與許多粒子（二氧化矽、氮化物等）的表面都帶負電（界面電位為負）。同符號的電荷會相互排斥，因此離開表面的粒子不易再度附著。相反地，在酸性液體中，界面電位的符號會因粒子而異，容易發生再附著。這是SC-1在去除微粒上有效的原因之一。
