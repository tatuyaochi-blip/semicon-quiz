CMP與清洗

將剛完成CMP的晶圓在不使其乾燥、保持濕潤的狀態下搬運至清洗步驟被視為重要，其原因為下列何者？

  1. A為了維持晶圓的重量
  2. B為了冷卻晶圓
  3. C因為殘留在表面的研磨液粒子或藥液一旦乾燥固著，之後的清洗就難以去除
查看答案與解析

正確答案：C. 因為殘留在表面的研磨液粒子或藥液一旦乾燥固著，之後的清洗就難以去除

研磨後的表面殘留著研磨液的粒子與反應生成物。一旦乾燥，粒子與表面之間會產生化學鍵結而牢牢固著，清洗時難以去除而成為缺陷。此外，銅表面在乾燥過程中容易腐蝕。因此將CMP設備與清洗部整合，讓晶圓保持濕潤狀態連續處理至清洗、乾燥的「乾進乾出（dry-in dry-out）」設備構成已成為標準。

  • A. 並非為了維持重量。
  • B. 目的不是冷卻。
  • C. 正確。乾燥後粒子固著，難以去除。
