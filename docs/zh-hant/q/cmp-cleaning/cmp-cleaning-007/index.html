CMP與清洗

CMP之後的清洗中，特別需要去除的是下列何者？

  1. A光阻膜
  2. B殘留在晶圓表面的研磨液之研磨粒子與金屬汙染
  3. C底層的所有氧化膜
查看答案與解析

正確答案：B. 殘留在晶圓表面的研磨液之研磨粒子與金屬汙染

CMP之後的晶圓表面會殘留研磨液的研磨粒子（每片晶圓有時附著數百萬個以上）、研磨屑、銅等金屬離子，以及防蝕劑的有機物。這些會造成配線短路、腐蝕與缺陷，因此要以PVA（聚乙烯醇）刷的刷洗，或稀釋氫氟酸、有機酸等藥液清洗加以去除，再進行旋轉乾燥。CMP與清洗是在同一台設備中完成的。
