CMP與清洗

在清洗後的晶圓乾燥步驟中使用IPA（異丙醇）的主要目的為下列何者？

  1. A防止水痕（乾燥斑）產生
  2. B蝕刻晶圓表面
  3. C使晶圓表面氧化
查看答案與解析

正確答案：A. 防止水痕（乾燥斑）產生

若水殘留在表面上自然乾燥，溶解在水中的二氧化矽與髒汙會殘留而形成水痕（斑點），尤其容易發生在疏水性的矽表面。IPA易與水混合，且表面張力約為水的1/3而較小，因此可置換水而快速乾燥，或利用噴向液面的IPA蒸氣所造成的表面張力差（馬蘭哥尼效應）將水從晶圓上拉開，防止水痕與微細圖案倒塌。
