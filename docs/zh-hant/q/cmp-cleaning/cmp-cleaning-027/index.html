CMP與清洗

針對CMP研磨量會隨晶片內圖案密度而改變的問題，下列何者是正確的設計對策？

  1. A改變晶片的顏色
  2. B配置虛擬圖案（dummy pattern），使圖案密度均勻
  3. C減少圖案的數量
查看答案與解析

正確答案：B. 配置虛擬圖案（dummy pattern），使圖案密度均勻

圖案密集的地方膜面積大、研磨進行得慢，圖案稀疏的地方局部壓力高、磨得快，因此CMP後的膜厚會不均勻。在設計階段於空白處配置電氣上不使用的虛擬圖案（填充，fill）以使密度一致，就能讓膜厚均勻。以設計工具進行密度檢查與自動配置已是標準做法，也是設計與製造合作以提高良率的DFM（可製造性設計）實例之一。
