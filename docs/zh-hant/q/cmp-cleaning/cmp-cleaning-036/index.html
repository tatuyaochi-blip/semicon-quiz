CMP與清洗

在Cu配線的CMP中，一般將研磨分成數個階段進行的原因，下列何者正確？

  1. A因為Cu與其下方的阻障金屬（TaN等）適合的研磨條件不同，所以先去除大部分的Cu，再去除阻障金屬
  2. B為了讓研磨設備休息
  3. C為了讓Cu變厚
查看答案與解析

正確答案：A. 因為Cu與其下方的阻障金屬（TaN等）適合的研磨條件不同，所以先去除大部分的Cu，再去除阻障金屬

在Cu配線中，要依序研磨溝槽外的厚Cu（數百nm～1 µm）、其下數nm的阻障金屬（Ta/TaN等），以及再下方的絕緣膜。由於各材料最適合的研磨速率與選擇比不同，因此分為先快速研磨Cu的階段（去除大部分的Cu）、接著細心研磨Cu並使其停止的階段，以及最後去除阻障金屬與少許絕緣膜而平坦收尾的階段，並分別使用不同的研磨液。

  • A. 正確。依各材料改變條件，分階段研磨。
  • B. 並非為了讓設備休息。
  • C. CMP是研削Cu的步驟。
