記憶體階層與效能

寫出一次寫入後暫時不會再讀回的大量資料時，使用不經過快取的儲存（非暫存儲存，non-temporal store）的主要優點為下列何者？

  1. A寫入的資料會長時間留在快取中，之後讀取時會變快
  2. B不會讓不重複使用的資料佔滿快取
  3. C寫入順序不再受保證，因此更容易發現程式的錯誤
查看答案與解析

正確答案：B. 不會讓不重複使用的資料佔滿快取

一般的寫入會因寫入配置而先從主記憶體載入快取行再寫入，所以即使是只寫入的資料也會產生載入的傳輸，並把其他會重複使用的資料逐出。非暫存儲存會將寫入集中、直接送往主記憶體，不污染快取，也省去不必要的載入。寫入的資料不會留在快取中，因此若立刻讀回反而會變慢。順序處理方式的改變是副作用，不是優點。

  • A. 寫入的資料不會留在快取中，若馬上讀取反而更慢。
  • B. 正確。不會讓不重複使用的資料佔滿快取，也省去不必要的載入。
  • C. 順序處理方式的改變是需注意的地方，不是優點。
