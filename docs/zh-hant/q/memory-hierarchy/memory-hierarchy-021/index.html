記憶體階層與效能

在分頁大小4 KB、快取行大小64位元組的系統中，想讓L1快取採用虛擬索引、實體標籤（VIPT）方式，且索引與偏移量僅由頁面內的位元構成。若為8路組相聯，快取容量最大可以做到多少？

  1. A32 KB
  2. B4 KB
  3. C256 KB
查看答案與解析

正確答案：A. 32 KB

頁面內的位址 4 KB = 2¹²，所以是12位元，這個範圍在虛擬位址與實體位址中相同。要讓索引與偏移量合計在12位元以內，每一路的容量必須在 2¹² = 4 KB以下。8路的話，可做到 4 KB × 8 = 32 KB。4 KB只是回答了單一路的容量。若做到256 KB，索引中會包含頁碼的位元，會產生相同實體位址進入不同組的問題。

  • A. 正確。每路4 KB × 8路 = 32 KB。
  • B. 4 KB是單一路的容量。
  • C. 256 KB的話，索引無法容納在頁面內。
