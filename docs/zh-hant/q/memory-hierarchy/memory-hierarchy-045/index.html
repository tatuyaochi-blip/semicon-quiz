記憶體階層與效能

從主記憶體載入未命中的快取行時，先送出CPU所需的字組（word），其餘的稍後再送的手法為下列何者？

  1. A關鍵字優先（critical word first）
  2. B寫入配置
  3. C犧牲快取
查看答案與解析

正確答案：A. 關鍵字優先（critical word first）

若等整條64位元組的快取行全部到達後才交出資料，CPU的等待就會相應延長。關鍵字優先會先傳輸被要求的字組並立刻交給CPU，快取行的其餘部分稍後再填入，因此能縮短實質的未命中代價。寫入配置是寫入未命中時是否載入快取行的方式，犧牲快取則是暫時保存被逐出快取行的小型緩衝器。兩者都與傳輸的順序無關。

  • A. 正確。先送出所需的字組，縮短等待時間。
  • B. 寫入配置是寫入未命中時的處理方式。
  • C. 犧牲快取是保存被逐出快取行的緩衝器。
