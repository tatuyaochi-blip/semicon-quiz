記憶體階層與效能

L1快取的未命中率（佔全部存取的比例）為4%，L2快取的全域未命中率（全部存取中連L2也未命中的比例）為1%時，L2的區域未命中率為多少？

  1. A25%
  2. B4%
  3. C1%
查看答案與解析

正確答案：A. 25%

區域未命中率是到達該快取的存取之中發生未命中的比例。到達L2的是L1未命中的全體之4%，其中佔全體1%的存取在L2也未命中，所以區域未命中率為 1 ÷ 4 = 25%。L2的區域未命中率看起來很高，但這是因為到達L2的只有L1沒能處理掉的局部性較低的存取，並不一定表示L2的效果小。1%是相對於全體的全域未命中率，4%則是L1的未命中率。

  • A. 正確。到達L2的4%之中有1%未命中，所以是25%。
  • B. 4%是L1的未命中率。
  • C. 1%是相對於全部存取的全域未命中率。
