記憶體階層與效能

從直接映射方式改為組相聯方式時所產生的變化，下列何者正確？

  1. A衝突未命中減少，但因標籤的比較與路的選擇，命中時間容易變長
  2. B衝突未命中增加，但電路變簡單，命中時間變短
  3. C與相聯度無關，未命中率與命中時間完全不變
查看答案與解析

正確答案：A. 衝突未命中減少，但因標籤的比較與路的選擇，命中時間容易變長

在組相聯方式中，一個組有多條路，能放入多筆對應到同一組的資料，因此衝突未命中比直接映射少。代價是需要平行比較多個標籤、並選出一致那一路資料的電路，命中時間與耗電量容易增加。衝突未命中增加且電路變簡單，是直接映射一側的性質。未命中率與命中時間會隨相聯度而改變。

  • A. 正確。衝突未命中減少，但命中時間容易變長。
  • B. 說明顛倒了，描述的是直接映射的性質。
  • C. 未命中率與命中時間都會隨相聯度而改變。
