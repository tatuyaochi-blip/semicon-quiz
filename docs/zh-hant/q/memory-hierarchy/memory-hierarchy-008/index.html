記憶體階層與效能

作為減少程式第一次存取某資料時所發生的快取未命中的方法，下列何者有效？

  1. A利用預取（prefetch）事先載入
  2. B將快取的相聯度（路數）加倍
  3. C只將快取的容量加倍
查看答案與解析

正確答案：A. 利用預取（prefetch）事先載入

第一次存取時發生的強制性未命中，是因為該資料從未進入過快取，所以即使增加容量或相聯度也不會減少。在需要之前以預取先行載入，或加大快取行以一併帶入附近的資料，則可以減少。提高相聯度所能減少的是爭奪同一組的衝突未命中，增加容量所能減少的是工作集溢出的容量未命中。

  • A. 正確。事先讀取尚未載入的資料是有效的。
  • B. 提高相聯度所減少的是衝突未命中。
  • C. 增加容量所減少的是容量未命中。
