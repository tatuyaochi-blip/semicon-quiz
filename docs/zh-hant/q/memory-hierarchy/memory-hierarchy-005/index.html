記憶體階層與效能

在全相聯（fully associative）快取中，位址之中用於索引（選擇組的部分）的位元數為下列何者？

  1. A由快取行大小決定的6位元
  2. B與行數相同的位元數
  3. C0位元
查看答案與解析

正確答案：C. 0位元

在全相聯方式中，任何資料都能放在快取內的任何位置，因此整體只有一組。因為不需要選擇組，索引為0位元，位址只分為偏移量與標籤，每次存取都要與所有快取行的標籤比較。因此需要大量比較器，不適合大型快取，而被用於TLB等小型結構。由快取行大小決定的是偏移量的位元數，並非索引。

  • A. 由快取行大小決定的是偏移量的位元數。
  • B. 需要配合行數的位元數的是直接映射的索引。
  • C. 正確。因為只有一組，所以不需要索引。
