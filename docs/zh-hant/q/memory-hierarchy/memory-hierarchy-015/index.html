記憶體階層與效能

硬體預取特別容易發揮效果的存取為下列何者？

  1. A以固定間隔（步幅，stride）依序讀取陣列的存取
  2. B從頭開始逐一元素走訪鏈結串列的存取
  3. C以隨機的鍵值查找雜湊表的存取
查看答案與解析

正確答案：A. 以固定間隔（步幅，stride）依序讀取陣列的存取

硬體預取器會找出先前存取位址的規律（連續或固定間隔），預測接下來的位址並事先載入。以固定步幅讀取陣列的存取容易預測，效果很大。鏈結串列在讀取目前元素之前，無法得知下一個元素的位址，沒有規律因此無法預測。以隨機鍵值參照雜湊表，位址同樣沒有規律，效果也很小。

  • A. 正確。規則間隔的存取容易預測，效果很大。
  • B. 在讀取目前元素之前無法得知下一個位址，因此無法預測。
  • C. 位址沒有規律，所以效果很小。
