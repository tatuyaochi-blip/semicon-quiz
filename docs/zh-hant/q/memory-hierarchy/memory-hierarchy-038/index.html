記憶體階層與效能

在對同一條快取行多次寫入的處理中，寫回方式比直寫方式更有利的主要理由為下列何者？

  1. A因為寫入在快取內完成，逐出時只要對主記憶體寫入一次即可
  2. B因為每次寫入主記憶體也會是最新的，所以逐出時不需要處理
  3. C因為快取與主記憶體的內容始終一致，所以不需要一致性管理
查看答案與解析

正確答案：A. 因為寫入在快取內完成，逐出時只要對主記憶體寫入一次即可

在寫回方式中，對同一條快取行的多次寫入只在快取內完成，逐出時只需將髒的快取行寫回一次。因此能大幅減少對主記憶體的傳輸量與耗電。每次寫入時主記憶體也保持最新是直寫方式的性質，對同一條快取行多次寫入時，每次都會產生傳輸。快取與主記憶體始終一致也是直寫的性質，在寫回中有不一致的期間。

  • A. 正確。多次寫入會合併成逐出時的一次寫回。
  • B. 每次寫入都更新主記憶體的是直寫方式。
  • C. 始終一致的是直寫方式，在寫回中有不一致的期間。
