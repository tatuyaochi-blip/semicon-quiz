記憶體階層與效能

在快取行大小64位元組、組數64的快取中，位址0x1234的資料所放入的組編號為下列何者？

  1. A4
  2. B52
  3. C8
查看答案與解析

正確答案：C. 8

偏移量是 64 = 2⁶，為低位的6位元；索引是組數 64 = 2⁶，為其上的6位元。0x1234 = 4660 除以64，4660 ÷ 64 = 72 餘52，所以快取行編號為72。組編號是快取行編號除以組數的餘數，72 mod 64 = 8。52是除以64的餘數，是表示快取行內位置（偏移量）的值。4只是取出位址十六進位的最後一位數，與組無關。

  • A. 4是十六進位的最後一位數，與組無關。
  • B. 52是快取行內的位置（偏移量）。
  • C. 正確。快取行編號72除以64的餘數8。
