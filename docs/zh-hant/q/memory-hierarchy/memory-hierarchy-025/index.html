記憶體階層與效能

非阻塞式快取（在處理未命中的期間仍接受其他存取的快取）的主要優點為下列何者？

  1. A可比阻塞式減少快取未命中本身的次數
  2. B可更快地從主記憶體讀取未命中的資料
  3. C可讓多個未命中的等待時間重疊，期間也能處理命中
查看答案與解析

正確答案：C. 可讓多個未命中的等待時間重疊，期間也能處理命中

在阻塞式快取中，在一個未命中處理完成之前，後續的所有存取都得等待。非阻塞式快取具備記錄未命中資訊的專用暫存器（MSHR），處理期間仍可回應命中的存取，也能同時向主記憶體發出另一個未命中的請求。藉此可讓等待時間重疊而隱藏，但未命中的次數本身並不會減少，一次未命中從主記憶體讀取的時間也不變。與亂序執行（out-of-order execution）搭配時才能發揮效果。

  • A. 未命中的次數不變，效果在於讓等待時間重疊而隱藏。
  • B. 從主記憶體讀取的時間本身不會改變。
  • C. 正確。可讓未命中的等待時間重疊，期間也能處理命中。

記憶體階層與效能的其他題目

  1. L1快取的未命中率（佔全部存取的比例）為4%，L2快取的全域未命中率（全部存取中連L2也未命中的比例）為1%時，L2的區域未命中率為多少？
  2. TLB的項目有64個、分頁大小為4 KB時，不發生TLB未命中即可存取的記憶體範圍（TLB涵蓋範圍，TLB reach）為多少？
  3. 使用大分頁（巨型分頁）的主要優點與缺點的組合，下列何者正確？
  4. 二維陣列的一列大小為4096位元組（2的冪次）時，沿著行方向走訪元素，即使快取容量有餘裕，未命中也可能變多。作為對策，下列何者有效？
  5. 存取主記憶體DRAM所需的時間，大約是L1快取命中時間的幾倍？（以一般PC或伺服器的CPU為例）

這個領域的比較

  • 寫透與寫回的差異：快取寫入方式比較以寫入方式、記憶體流量、速度、一致性、複雜度、逐出成本與用途等面向，用表格比較寫透與寫回的快取。
  • 直接映射、組相聯、全相聯的差異：快取架構比較以區塊可放置的位置、標籤比較、速度、成本、衝突未命中與用途等面向，用表格比較直接映射、組相聯、全相聯的快取。
  • L1、L2、L3 快取的差異：容量、延遲、共用範圍、包含關係比較以一般 PC 與伺服器的 CPU 為例，從容量與延遲的參考值、每個核心專用或共用、指令與資料的分離、包含關係、設計重點等面向，以表格比較 L1、L2、L3 快取。
