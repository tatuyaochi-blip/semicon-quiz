網路設計與維運

要從位於另一個網路的DHCP伺服器 10.0.0.5，為VLAN 20（192.168.20.0/24）的終端分配位址。為此，在作為VLAN 20預設閘道的L3交換器介面（192.168.20.1）上設定了DHCP中繼代理。下列關於中繼代理運作的敘述，何者正確？

  1. A接收終端以廣播送出的DHCP訊息，寫入自己VLAN 20側的位址 192.168.20.1，以單播轉送給 10.0.0.5。伺服器根據這個位址，從 192.168.20.0/24 用的範圍中選擇位址
  2. BL3交換器會開始把收到的廣播轉送到所有網路，DHCP訊息因此到達伺服器
  3. CL3交換器代替DHCP伺服器決定位址並出借給終端，只把結果通知 10.0.0.5
查看答案與解析

正確答案：A. 接收終端以廣播送出的DHCP訊息，寫入自己VLAN 20側的位址 192.168.20.1，以單播轉送給 10.0.0.5。伺服器根據這個位址，從 192.168.20.0/24 用的範圍中選擇位址

還沒有位址的終端會以廣播送出尋找DHCP伺服器的Discover，但路由器與L3交換器不會把廣播轉送到其他網路。DHCP中繼代理接收這個訊息，以單播轉送給伺服器，再把伺服器的回應傳回終端。轉送時，會在訊息中的欄位（giaddr）寫入終端側介面的位址（這裡是 192.168.20.1）。伺服器根據這個位址得知終端所在的子網路（192.168.20.0/24），從該子網路用的範圍中選擇位址。如此一來，不必在每個VLAN都設置伺服器，一台DHCP伺服器就能負責許多子網路。

  • A. 正確。把廣播改為單播轉送，並告知伺服器終端屬於哪個子網路。
  • B. 中繼代理只把DHCP訊息轉送到指定的伺服器，並不是轉送所有廣播。
  • C. 決定並出借位址的是DHCP伺服器。中繼代理只負責轉送。
