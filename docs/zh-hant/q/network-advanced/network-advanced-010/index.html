網路設計與維運

把兩台交換器之間4條1 Gbps的鏈路，以鏈路聚合綁成一條邏輯鏈路。訊框依一般的方式分配，也就是依來源與目的地之位址與連接埠號碼的組合（資料流）決定使用哪一條鏈路傳送。一條TCP連線可獲得之傳輸量的上限，最接近下列何者？

  1. A1 Gbps
  2. B2 Gbps
  3. C4 Gbps
查看答案與解析

正確答案：A. 1 Gbps

在鏈路聚合中，同一個資料流的訊框一般會以同一條鏈路傳送。若把一個資料流的訊框分散到多條鏈路，抵達順序可能顛倒，使TCP的效能下降。因此，一條TCP連線最多只能達到一條鏈路的1 Gbps。若有許多資料流，就會分散到4條鏈路，合計最多可使用4 Gbps。任何一條鏈路斷線都能以其餘鏈路繼續通訊，而且STP把它視為一條鏈路，綁在一起的鏈路也不會被封鎖。

  • A. 正確。一個資料流以一條鏈路傳送，因此上限是一條鏈路的頻寬。
  • B. 一個資料流不會被分到兩條鏈路傳送。
  • C. 這是有許多資料流時的合計上限。一條連線達不到這個值。
