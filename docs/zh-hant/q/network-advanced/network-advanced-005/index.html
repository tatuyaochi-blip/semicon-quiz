網路設計與維運

兩台交換器SW1與SW2都有VLAN 10與VLAN 20的連接埠。想用一條纜線連接兩台交換器，讓相同VLAN的設備可以跨交換器通訊。連接用連接埠的設定，下列何者適當？

  1. A在兩台交換器上，把連接用的連接埠設為VLAN 10的存取連接埠
  2. B取消VLAN 20並併入VLAN 10，把連接用的連接埠設為VLAN 10的存取連接埠
  3. C在兩台交換器上，把連接用的連接埠設為主幹（trunk）連接埠，以IEEE 802.1Q的標籤區分VLAN來傳送訊框
查看答案與解析

正確答案：C. 在兩台交換器上，把連接用的連接埠設為主幹（trunk）連接埠，以IEEE 802.1Q的標籤區分VLAN來傳送訊框

存取連接埠只屬於一個VLAN，用來連接終端。要以一條鏈路搬運多個VLAN的訊框，需設為主幹連接埠，並在每個訊框加上IEEE 802.1Q標籤的VLAN ID後傳送。接收端的交換器查看標籤判斷訊框屬於哪個VLAN，只轉送到該VLAN的連接埠。也可以指定一個不加標籤傳送的原生VLAN，其值必須在兩端一致。

  • A. 只有VLAN 10的訊框能通過，因此VLAN 20的設備無法跨交換器通訊。
  • B. 雖然能夠通訊，但劃分VLAN的意義（分割廣播網域、為了安全而隔離）就消失了。
  • C. 正確。主幹連接埠藉由標籤，可在一條鏈路上搬運多個VLAN。
