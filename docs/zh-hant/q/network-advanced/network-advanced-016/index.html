網路設計與維運

分公司的路由器R2與總公司的路由器R1以 10.255.0.0/30 的鏈路相連，R1端的位址為 10.255.0.1，R2端為 10.255.0.2。在R2上設定通往總公司網路 192.168.1.0/24 的靜態路由時，指定為下一個轉送對象（下一跳）的位址，下列何者適當？

  1. A10.255.0.1
  2. B10.255.0.2
  3. C192.168.1.1（R1在總公司LAN側的位址）
查看答案與解析

正確答案：A. 10.255.0.1

靜態路由要設定目的地網路，以及為了送往該處而交給下一台路由器的位址（下一跳）。下一跳原則上是位於自己直接連接之網路上的相鄰路由器的位址。這裡是鏈路另一端R1的 10.255.0.1，R2會以ARP查出這個位址的MAC位址再送出訊框。分公司只有一個出口時，也常不逐一寫出各目的地的路由，而只設定一條 0.0.0.0/0 的預設路由。

  • A. 正確。這是直接相連的相鄰路由器R1的位址。
  • B. 這是R2自己的位址，不能作為下一個交付的對象。
  • C. 這個位址不在R2直接連接的網路上，R2也沒有通往它的路由，因此不能作為下一跳。

網路設計與維運的其他題目

  2. 路由器的路由表中有3條路由：靜態路由 10.0.0.0/8（下一個轉送對象為路由器A，管理距離1）、以OSPF學到的 10.1.0.0/16（路由器B，110）、以RIP學到的 10.1.1.0/24（路由器C，120）。目的地為 10.1.1.5 的封包會送往哪一台路由器？
  3. 下列關於鏈路狀態型路由協定的敘述，何者正確？
  4. 在OSPF中，路由器R1通往R4另一側網路的路徑有3條。路徑A的R1–R5為10 Gbps、R5–R4為1 Gbps的鏈路；路徑B是直接連接R1–R4的100 Mbps鏈路；路徑C的R1–R2、R2–R3、R3–R4都是1 Gbps的鏈路。設各鏈路的成本為「參考頻寬10 Gbps ÷ 鏈路頻寬」，且R4之後的成本在各路徑都相同。R1選擇的路徑是下列何者？
  5. 在網際網路上，於網路服務供應商等組織所管理的網路單位（AS，自治系統）之間交換路由資訊，並依據經過之AS的順序（AS_PATH）等屬性與各組織的政策選擇路由的協定是下列何者？
