網路設計與維運

想把只以IPv6運作的兩個據點，透過只以IPv4運作的網路連接起來，讓據點之間維持以IPv6封包通訊。使用的方法，下列何者適當？

  1. A在據點的終端也設定IPv4位址，成為雙協定堆疊，讓據點之間以IPv4通訊
  2. B加大IPv4網路中路由器的MTU，讓它直接轉送IPv6封包
  3. C在據點出口的路由器建立隧道，把IPv6封包放進IPv4封包中搬運，到對方據點再取出
查看答案與解析

正確答案：C. 在據點出口的路由器建立隧道，把IPv6封包放進IPv4封包中搬運，到對方據點再取出

隧道是把某種協定的封包，放進另一種協定之封包的資料部分來搬運的方法。在IPv6 over IPv4隧道中，IPv4網路的路由器看到的是普通的IPv4封包，因此即使途中的設備不支援IPv6也能搬運。雙協定堆疊是在一台設備上同時運作IPv4與IPv6的方法，常用於IPv4與IPv6並存的時期，但在這個情況下，據點之間的通訊會變成IPv4。隧道會增加標頭，能在其中搬運的封包也會相應變小。

  • A. 據點之間的通訊會變成IPv4，不符合維持以IPv6封包通訊的條件。
  • B. 只支援IPv4的路由器不論MTU為何，都無法解讀並轉送IPv6封包。
  • C. 正確。把IPv6封包放進IPv4封包中搬運。
