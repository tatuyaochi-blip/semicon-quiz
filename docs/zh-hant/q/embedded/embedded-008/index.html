嵌入式與韌體

使用微控制器的GPIO（通用輸入輸出）腳位時，首先必須設定的是下列何者？

  1. A該腳位要作為輸入還是輸出使用（方向）
  2. B腳位的顏色
  3. C撰寫程式的程式設計師姓名
查看答案與解析

正確答案：A. 該腳位要作為輸入還是輸出使用（方向）

GPIO腳位可由軟體決定作為輸入或輸出。以方向暫存器設為輸出後，寫入輸出暫存器的值會成為腳位電壓；設為輸入後，則可從輸入暫存器讀取腳位電壓。許多微控制器還能設定是否啟用上拉、輸出形式（推挽或開汲極），以及是否作為其他週邊電路的腳位使用。

  • A. 正確。以方向暫存器設定。
  • B. 腳位的顏色無關。
  • C. 程式設計師的姓名無關。

這個領域的比較

  • I2C、SPI、UART 的差異：佈線、速度、使用時機比較從佈線數量、時脈、速度、連接形態、位址、錯誤偵測與在微控制器上的主要用途等面向，以表格比較 I2C、SPI、UART。
  • MCU與MPU的差異：微控制器與微處理器比較以整合度、時脈、記憶體、作業系統、即時性、耗電量、開機時間、成本與用途等面向，用表格比較MCU與MPU。
  • 中斷與輪詢的差異：比較機制與使用時機以機制、CPU 使用、回應時間、額外負擔、複雜度、耗電量，以及在嵌入式與作業系統中的用途等面向，用表格比較中斷與輪詢。
