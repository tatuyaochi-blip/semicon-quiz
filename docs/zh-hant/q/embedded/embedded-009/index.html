嵌入式與韌體

按下機械式開關時，接點細微彈跳，在短時間內反覆多次導通與斷開的現象稱為什麼？

  1. A閂鎖效應（Latch-up）
  2. B串擾（Crosstalk）
  3. C彈跳（Chattering）
查看答案與解析

正確答案：C. 彈跳（Chattering）

機械式開關在接點接觸的瞬間，金屬會彈動，在數毫秒內反覆導通與斷開。微控制器讀取腳位的速度非常快，直接計數的話，一次按下會被計成好幾次。因此要用軟體等待一段時間後再重新讀取，或以電容、史密特觸發器電路使波形平滑，來消除此現象。這種處理稱為去彈跳（debounce）。

  • A. 閂鎖效應是CMOS電路持續流過大電流的現象。
  • B. 串擾是相鄰佈線的訊號洩漏進來的現象。
  • C. 正確。只按一次卻會被讀成按了好幾次。
