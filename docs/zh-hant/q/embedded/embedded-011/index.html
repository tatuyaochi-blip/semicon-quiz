嵌入式與韌體

將16 MHz的時脈經預除器除以16後供計時器計數，設定每計數1000次產生一次中斷。中斷的間隔是多少？

  1. A1 µs
  2. B1 ms
  3. C16 ms
查看答案與解析

正確答案：B. 1 ms

16 MHz除以16，計時器的時脈為1 MHz，每計數一次為1 µs。每1000次計數的話，間隔為1 µs×1000=1 ms。預除器的用途是將過快的時脈除頻，使其落在計時器可計數的範圍內。每1 ms一次的中斷，常用於時間管理、讀取開關以及RTOS的時間刻度等。

  • A. 1 µs是計數一次的時間。
  • B. 正確。1 µs×1000=1 ms。
  • C. 不是乘以16，而是除以16。
