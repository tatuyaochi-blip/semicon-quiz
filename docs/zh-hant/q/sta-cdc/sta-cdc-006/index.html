時序分析與CDC

發送端的時脈→輸出延遲最小為 0.08 ns，組合電路的最小延遲為 0.02 ns，接收端的保持時間為 0.05 ns。當接收端的時脈比發送端晚 0.1 ns 到達時，保持時間的餘裕是多少？

  1. A+0.05 ns（滿足）
  2. B+0.15 ns（滿足）
  3. C−0.05 ns（違規）
查看答案與解析

正確答案：C. −0.05 ns（違規）

保持時間的餘裕為「到達時間 − 要求時間」，檢查資料是否過早到達。資料的最小到達時間為 0.08 + 0.02 = 0.10 ns，要求時間為接收端時脈到達的 0.1 ns 加上保持時間 0.05 ns 的 0.15 ns，因此餘裕為 0.10 − 0.15 = −0.05 ns，屬於違規。+0.05 ns 是忽略時脈偏移的值，+0.15 ns 是把時脈偏移以有利的方向加上去的值。這是在移位暫存器等中間邏輯很少的路徑上容易發生的違規。

時序分析與CDC的其他題目

  2. 為了修正保持時間違規，在資料路徑中插入延遲用的緩衝器。此時最重要的確認事項是哪一項？

  4. 在時脈不確定性的設定中，建立時間用的通常會納入週期抖動，保持時間用的則多半不納入。其理由何者正確？
