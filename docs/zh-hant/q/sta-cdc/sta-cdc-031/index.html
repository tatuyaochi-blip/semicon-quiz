時序分析與CDC

對4位元資料的各位元分別加上2級同步器，傳到另一個時脈域。當資料從 0111 變為 1000 時，可能發生的問題何者正確？

  1. A各位元被取入的週期錯開，可能收到 1111 或 0000 這類中間值
  2. B經過同步器後，所有位元會在同一週期對齊，因此不會發生問題
  3. C4個位元全部成為亞穩態，就此無法回到0或1
查看答案與解析

正確答案：A. 各位元被取入的週期錯開，可能收到 1111 或 0000 這類中間值

2級同步器對每個位元而言，變化是在這次邊緣還是下一次邊緣被取入並不確定。從 0111 變為 1000 時4個位元全部改變，因此可能在1個週期內收到只有部分位元變成新值的 1111、0000、0100 等。接收端若使用該值就會誤動作。亞穩態隨著時間經過會穩定為0或1。若是計數器的值，可轉換為格雷碼使每次只有1個位元改變；若是任意資料，則使用交握或非同步FIFO。

時序分析與CDC的其他題目

  1. 將多位元資料安全地傳到另一個時脈域的方法，何者正確？
  2. 將在 500 MHz 時脈域中只有1個週期（2 ns）為1的脈衝，以2級同步器傳到 100 MHz 時脈域。可能發生的問題何者正確？
  3. 為了以同步器將位準訊號確實從 400 MHz 時脈域傳到 100 MHz 時脈域，希望訊號寬度達到接收端時脈週期的1.5倍以上。以發送端的時脈計算，最少應為幾個週期的寬度？
  4. 在翻轉同步（每當脈衝到來時，在發送端產生反相的位準訊號並傳遞的方式）中，在接收端取回原本脈衝的方法何者正確？
  5. 以翻轉同步將脈衝從快速時脈域傳到慢速時脈域時，下列限制何者正確？
