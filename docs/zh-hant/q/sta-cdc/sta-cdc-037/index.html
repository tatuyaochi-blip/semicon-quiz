時序分析與CDC

在使用req與ack的4相交握中，傳遞1筆資料時訊號的順序何者正確？

  1. A將req設為1的同時開始改變資料 → 接收端將ack設為1 → 將req與ack同時設為0
  2. B接收端先將ack設為1 → 發送端確定資料並將req設為1 → 接收端取入資料 → 將req與ack同時設為0
  3. C確定資料並將req設為1 → 接收端取入資料並將ack設為1 → 將req設為0 → 將ack設為0
查看答案與解析

正確答案：C. 確定資料並將req設為1 → 接收端取入資料並將ack設為1 → 將req設為0 → 將ack設為0

在4相交握中，req與ack各上升、下降1次，共4次變化完成1次傳遞。發送端確定資料後拉高req，接收端看到同步化後的req就取入資料並拉高ack。發送端看到同步化後的ack就拉低req，接收端看到req下降後拉低ack。req與ack都是1位元，因此可用2級同步器安全傳遞。若一邊改變資料一邊拉高req，接收端可能取入變化中的值。
