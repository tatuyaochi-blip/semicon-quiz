時序分析與CDC

在使用OCV降額的STA中，當發送端與接收端的時脈路徑在中途之前為共同路徑時，所進行的CRPR（共同路徑悲觀消除）的說明何者正確？

  1. A將共同部分的延遲視為0，重新計算時脈的到達時間
  2. B去除因對共同部分分別套用慢速值與快速值所造成的、不可能發生的多餘悲觀
  3. C對共同部分乘上更大的降額係數，使其偏向安全側
查看答案與解析

正確答案：B. 去除因對共同部分分別套用慢速值與快速值所造成的、不可能發生的多餘悲觀

在OCV中，發送端的時脈路徑估得較慢、接收端估得較快，但從根部到分歧點的共同部分在物理上是相同的緩衝器與繞線，在一次邊緣中不可能既慢又快。若共同部分的延遲為 1.0 ns、係數為1.1與0.9，則 1.1 ns 與 0.9 ns 之差的 0.2 ns 就是多餘的悲觀。CRPR將這個差值加回餘裕，使結果更接近實際。這並不是把共同部分的延遲當作0，而加大係數則是相反的操作。

時序分析與CDC的其他題目

  1. 在以週期 2.0 ns 的時脈運作的電路中，有一條資料到達時間（時脈→輸出延遲與組合電路延遲的總和）為 3.3 ns、建立時間為 0.1 ns 的路徑。此路徑只需每2個週期取入一次，因此將建立時間的多週期路徑設為2。建立時間的餘裕是多少？
  2. 將建立時間的多週期路徑設為 N（N ≥ 2）時，保持時間通常也要將多週期路徑設為 N − 1。其理由何者正確？
  3. 適合設定偽路徑（set_false_path）的路徑是哪一條？
  4. 在週期 2.0 ns、工作週期50%的時脈下，有一條在上升邊緣送出、在下降邊緣取入的路徑。若建立時間為 0.1 ns、時脈偏移為0，時脈→輸出延遲與組合電路延遲的總和容許的最大值是多少？
  5. 在週期 2.0 ns 的時脈下，有一條從在時刻0的上升邊緣輸出資料的正反器，到在時刻 1.0 ns 開啟（變為透通）、在時刻 2.0 ns 關閉之鎖存器的路徑。當資料在時刻 1.4 ns 到達鎖存器時，此鎖存器借用的時間（時間借用）是多少？
