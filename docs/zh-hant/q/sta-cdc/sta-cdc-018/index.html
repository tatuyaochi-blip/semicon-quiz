時序分析與CDC

在週期 2.0 ns 的時脈下，有一條從在時刻0的上升邊緣輸出資料的正反器，到在時刻 1.0 ns 開啟（變為透通）、在時刻 2.0 ns 關閉之鎖存器的路徑。當資料在時刻 1.4 ns 到達鎖存器時，此鎖存器借用的時間（時間借用）是多少？

  1. A0.6 ns
  2. B0.4 ns
  3. C1.4 ns
查看答案與解析

正確答案：B. 0.4 ns

鎖存器在開啟期間會讓輸入直接通過，因此即使資料比開啟邊緣晚到，只要在關閉前到達就能正確接收。超過開啟邊緣（1.0 ns）所使用的 1.4 − 1.0 = 0.4 ns 即為時間借用，下一級可用的時間也會減少相同的量。0.6 ns 是到關閉為止的剩餘時間，1.4 ns 是到達時間本身。可借用的上限，為關閉邊緣減去鎖存器建立時間的時刻。
