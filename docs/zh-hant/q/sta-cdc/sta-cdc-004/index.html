時序分析與CDC

有一條時脈週期 1.0 ns、時脈→輸出延遲 0.1 ns、組合電路延遲 0.85 ns、建立時間 0.08 ns 的路徑。當接收端正反器的時脈比發送端晚 0.05 ns 到達時，建立時間的餘裕是多少？

  1. A−0.03 ns
  2. B+0.02 ns
  3. C−0.08 ns
查看答案與解析

正確答案：B. +0.02 ns

接收端的時脈較晚到達（正的時脈偏移）時，取入資料的邊緣往後移，因此建立時間可用的時間增加。要求時間為 1.0 + 0.05 − 0.08 = 0.97 ns，到達時間為 0.1 + 0.85 = 0.95 ns，因此餘裕為 +0.02 ns。−0.03 ns 是忽略時脈偏移的值，−0.08 ns 是把時脈偏移的方向弄反（當成接收端較早到達）的值。需注意，同樣的時脈偏移對保持時間是不利的。

時序分析與CDC的其他題目

  1. 接收端正反器的時脈比發送端晚到達（正的時脈偏移）時，對建立時間與保持時間的影響，下列何者正確？
  2. 發送端的時脈→輸出延遲最小為 0.08 ns，組合電路的最小延遲為 0.02 ns，接收端的保持時間為 0.05 ns。當接收端的時脈比發送端晚 0.1 ns 到達時，保持時間的餘裕是多少？
  3. 在以同一時脈的上升邊緣進行送出與取入的一般路徑上，發現了保持時間違規（餘裕 −0.03 ns）。將時脈頻率降為一半時，關於此違規的敘述何者正確？
  4. 為了修正保持時間違規，在資料路徑中插入延遲用的緩衝器。此時最重要的確認事項是哪一項？
  5. 在時脈週期 1.25 ns（800 MHz）的路徑上，時脈→輸出延遲與組合電路延遲的總和為 1.05 ns，建立時間為 0.05 ns，建立時間用的時脈不確定性設定為 0.05 ns。建立時間的餘裕是多少？
