時序分析與CDC

從低態有效的外部重設，產生「非同步確立、同步解除」之內部重設的重設同步器，其構成何者正確？

  1. A將外部重設接到2級正反器的非同步重設端子，第1級的D輸入固定為1，以第2級的輸出作為內部重設
  2. B將外部重設送入2級正反器的D輸入進行同步化，只以其輸出作為內部重設
  3. C將外部重設與時脈做AND後的訊號，直接作為內部重設
查看答案與解析

正確答案：A. 將外部重設接到2級正反器的非同步重設端子，第1級的D輸入固定為1，以第2級的輸出作為內部重設

外部重設變為0時，兩個正反器會藉由非同步重設端子，不等待時脈立即變為0，施加內部重設。外部重設回到1之後，第1級D的1會每個時脈前進1級，在第2次時脈時第2級的輸出變為1，解除重設。解除與時脈對齊，即使第1級成為亞穩態，到傳至第2級為止也確保了1個週期的穩定時間。只以D輸入同步化的話，時脈停止時重設就無法施加。
