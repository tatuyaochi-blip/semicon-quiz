環境安全

關於環境管理系統的國際標準為下列何者？

  1. AISO 14001
  2. BISO 9001
  3. CISO 14644
查看答案與解析

正確答案：A. ISO 14001

ISO 14001是讓組織管理對環境的影響並持續改善的機制（環境管理系統）的國際標準。制定環境方針後，以PDCA循環反覆進行目標的設定、執行、確認與檢討。可透過第三方稽核取得驗證，有時也會成為交易的條件。ISO 9001是品質管理系統，ISO 14644則是與潔淨室潔淨度等有關的標準。
