環境安全

以事業使用的電力100%採用再生能源為目標的企業所參與的國際倡議為下列何者？

  1. AISO 14644
  2. BRE100
  3. CJEDEC
查看答案與解析

正確答案：B. RE100

RE100是以事業活動所使用的電力100%採用再生能源為目標的企業所參與的國際倡議，於2014年啟動。大量用電的半導體企業也有參與，透過設置太陽能發電、與發電業者簽訂長期契約的購電協議（PPA）、再生能源憑證等方式，推動範疇2排放的減量。ISO 14644是潔淨室的標準，JEDEC則是標準化組織。

  • A. ISO 14644是潔淨室的標準。
  • B. 正確。是以100%採用再生能源為目標的倡議。
  • C. JEDEC是半導體的標準化組織。
