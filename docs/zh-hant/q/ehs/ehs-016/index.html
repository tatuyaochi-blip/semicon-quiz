環境安全

在藥液儲存時，將混合後可能劇烈反應的物質分開存放，其理由下列何者正確？

  1. A為了防止因混觸而發熱、產生有毒氣體、發生火災等
  2. B為了讓外觀整齊
  3. C為了降低儲存費用
查看答案與解析

正確答案：A. 為了防止因混觸而發熱、產生有毒氣體、發生火災等

酸與鹼、氧化劑與可燃物、氫氟酸與玻璃等，有些組合混合後會劇烈發熱、產生有毒氣體或引發火災。例如次氯酸鹽與酸混合會產生有毒的氯氣。為了在洩漏時也不致混合，會分隔區域，或各自設置防液堤來儲存。並不是為了外觀或費用。
