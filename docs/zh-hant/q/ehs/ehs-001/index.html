環境安全

關於氫氟酸（氫氟酸）的處理，下列說明何者正確？

  1. A附著在皮膚上會滲透至深部，可能造成嚴重傷害
  2. B因為不會揮發，所以不需要通風
  3. C只要用水稀釋就可以徒手處理
查看答案與解析

正確答案：A. 附著在皮膚上會滲透至深部，可能造成嚴重傷害

氫氟酸會從皮膚滲透到體內深處，氟離子與鈣、鎂結合而破壞組織，量大時還會使血中鈣濃度下降，引發心律不整。濃度低時，疼痛可能在數小時後才出現，也有發現得太晚的危險。氫氟酸具揮發性，需要通風，即使稀釋也不可徒手處理。若沾到皮膚，須立即用大量的水沖洗，並前往醫療機構就診。
