良率與品質管理

在品質管理與業務改善中所使用的「PDCA循環」，其順序下列何者正確？

  1. A計畫（Plan）→ 執行（Do）→ 查核（Check）→ 行動（Act）
  2. B執行 → 計畫 → 行動 → 查核
  3. C查核 → 行動 → 計畫 → 執行
查看答案與解析

正確答案：A. 計畫（Plan）→ 執行（Do）→ 查核（Check）→ 行動（Act）

PDCA循環是反覆進行擬定計畫（Plan）、執行（Do）、評估結果（Check）、採取改善措施（Act）這4個階段，以持續改善品質與業務的想法。將改善所得的做法固定為標準，並作為下一次計畫的起點，就能呈螺旋狀逐步提升水準。它由休哈特與戴明推廣，對日本的品質管理影響很大。

  • A. 正確。順序為計畫、執行、查核、行動。
  • B. 在計畫之前就執行，順序顛倒了。
  • C. 從查核開始並不是PDCA的順序。
