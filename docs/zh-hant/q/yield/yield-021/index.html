良率與品質管理

在同一片晶圓上，縮小晶片面積後，1片可切出的良品晶片數會大幅增加，其理由下列何者正確？

  1. A因為晶片變輕
  2. B因為晶圓的顏色改變
  3. C因為晶片的數量增加，且每顆晶片含有缺陷的機率也下降
查看答案與解析

正確答案：C. 因為晶片的數量增加，且每顆晶片含有缺陷的機率也下降

晶片縮小後，1片晶圓可切出的晶片數增加。此外，在缺陷密度相同時，晶片越小，含有缺陷的機率越低，良率也越高。例如D=0.2個/cm²，將面積由2 cm²縮為1 cm²時，晶片數約為2倍，良率由約67%提升到約82%，良品數約為2.4倍。重量與顏色則無關。
