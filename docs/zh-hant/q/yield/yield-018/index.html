良率與品質管理

表示新製程導入後，透過反覆進行不良原因的分析與對策，使良率隨時間提升的情形，稱為什麼？

  1. A浴缸曲線
  2. B良率學習曲線
  3. CS形曲線
查看答案與解析

正確答案：B. 良率學習曲線

新製程剛導入時良率偏低，透過反覆進行不良分析與對策，良率會逐漸提升。表示這種變化的就是良率學習曲線。量產初期因價格高而賣得出去，所以越早將良率提升到高水準，利潤就越大，並直接關係到競爭力。浴缸曲線是表示產品故障率隨時間變化的可靠度曲線。
