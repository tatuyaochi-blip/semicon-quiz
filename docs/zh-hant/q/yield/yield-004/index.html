良率與品質管理

關於品質管理中所使用的柏拉圖（Pareto chart）的目的，下列何者正確？

  1. A調查兩個變數之間的相關關係
  2. B以時間序列監控製程的異常
  3. C將不良項目依件數由多到少排列，找出應重點對策的項目
查看答案與解析

正確答案：C. 將不良項目依件數由多到少排列，找出應重點對策的項目

柏拉圖是將不良的項目或原因依件數（或損失金額）由多到少以長條圖排列，並疊加累積比率折線的圖。通常前2～3個項目就占了整體的7～8成（柏拉圖法則），因此能一眼看出在人力有限的情況下應從何處著手。用來觀察兩個變數相關性的是散佈圖，以時間序列監控製程異常的則是管制圖。
