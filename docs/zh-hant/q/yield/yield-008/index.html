良率與品質管理

分析將晶圓測試結果依晶片在晶圓上的位置顯示良否的晶圓圖（wafer map），其主要目的為下列何者？

  1. A決定晶片的售價
  2. B從不良的分布圖案推測造成不良的製程或設備
  3. C決定切割的順序
查看答案與解析

正確答案：B. 從不良的分布圖案推測造成不良的製程或設備

分布圖案會依原因而有特徵：若不良晶片集中在晶圓外圍，就是沉積或蝕刻的面內均勻性問題；若在相同位置重複出現，就是光罩的缺陷；若呈條紋狀排列，則是刮傷或搬運的問題。分析晶圓圖，並將多片晶圓疊合後，即可推測有問題的製程或設備。它並不是用來決定價格或切割順序的。
