良率與品質管理

關於管制圖的管制界限與產品的規格界限之差異，下列何者正確？

  1. A管制界限依製程的實際變異決定，規格界限依產品所要求的需求決定
  2. B管制界限與規格界限永遠是相同的值
  3. C管制界限由客戶決定，規格界限由製程的資料計算
查看答案與解析

正確答案：A. 管制界限依製程的實際變異決定，規格界限依產品所要求的需求決定

管制界限是依製程穩定時資料的平均與變異所計算出的線，用來判斷製程是否發生異常。規格界限則是依客戶的要求或設計，決定作為產品所容許的範圍。即使在管制界限內也可能超出規格，反之即使在規格內，若超出管制界限，也表示製程發生了變化。Cp、Cpk則是以數值表示兩者之間的關係。
