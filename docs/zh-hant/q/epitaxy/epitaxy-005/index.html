磊晶成長

下列關於MBE（分子束磊晶）的特徵，何者正確？

  1. A在大氣壓下高速成長厚膜
  2. B在超高真空中將原料以分子束供應至基板，可在原子層等級精密控制膜厚與組成
  3. C將晶圓浸入液體原料中使其成長
查看答案與解析

正確答案：B. 在超高真空中將原料以分子束供應至基板，可在原子層等級精密控制膜厚與組成

MBE是在10⁻⁸ Pa左右的超高真空裝置內，將原料加熱成分子（原子）束照射到基板上以成長晶體的方法。藉由快門的開關可瞬間切換原料，並能以RHEED即時觀察成長情形，同時以原子層為單位控制膜厚與組成。成長速率慢，每小時約1 µm，量產性不如MOCVD，但用於研究開發以及高性能HEMT、量子元件。
