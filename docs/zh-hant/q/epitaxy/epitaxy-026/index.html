磊晶成長

下列何者是用來形成SiGe HBT基極層的技術？

  1. A磊晶成長（有時也會使Ge濃度在深度方向變化）
  2. BCMP
  3. C濺鍍
查看答案與解析

正確答案：A. 磊晶成長（有時也會使Ge濃度在深度方向變化）

SiGe HBT的基極，是在矽上一邊添加硼，一邊以低溫磊晶成長出厚度數十nm的SiGe層而製成。若使Ge濃度從射極側的0%朝集極側增加到20～30%，能隙的斜率會在基極內形成電場，使電子加速而縮短行進時間。也會採用加入少量碳以抑制硼擴散、維持薄基極的做法。
