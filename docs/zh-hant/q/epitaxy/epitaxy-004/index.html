磊晶成長

當基板與成長膜的晶格常數差異（晶格不匹配）很大時，容易發生下列何種問題？

  1. A產生失配差排等晶體缺陷
  2. B膜一定會變成非晶質
  3. C成長速率變為0
查看答案與解析

正確答案：A. 產生失配差排等晶體缺陷

成長晶格常數不同的材料時，膜會配合基板而收縮或伸長，使應變累積，超過臨界膜厚後，為了釋放應變，界面上會產生失配差排。其中一部分會成為貫穿膜層的貫穿差排，導致漏電流、發光效率下降及壽命縮短。對策包括逐漸改變組成的緩衝層、使差排彎曲的超晶格，以及選擇性成長等。
