磊晶成長

矽磊晶成長之前，在高溫氫氣環境中加熱晶圓，其主要目的為下列何者？

  1. A使表面形成厚氧化層
  2. B高濃度添加雜質
  3. C去除表面的原生氧化膜，使潔淨的晶面裸露
查看答案與解析

正確答案：C. 去除表面的原生氧化膜，使潔淨的晶面裸露

若表面殘留原生氧化膜（約1 nm）或碳等污染，其上就無法順利成長單晶，成為堆疊缺陷等的原因。成長前在氫氣中加熱至約1100 ℃（氫烘烤）時，SiO2會與矽反應成為SiO而蒸發，使潔淨的矽晶面裸露。在需要抑制熱預算的先進製程中，會結合事前的藥液清洗或電漿處理，在更低的溫度下進行。
