可靠度

為了以統計方式保證非常低的故障率，下列哪一項是適當的可靠度試驗條件？

  1. A以大量樣本進行長時間試驗，並利用加速條件
  2. B只以1個樣本進行短時間試驗
  3. C不進行試驗就予以保證
查看答案與解析

正確答案：A. 以大量樣本進行長時間試驗，並利用加速條件

在故障率非常低的情況下，只用少量樣本進行短時間試驗不會發生故障，無法得出具統計意義的結論。因此以大量樣本進行長時間試驗，並利用溫度與電壓的加速，在考量信賴水準的同時推估故障率的上限。例如以1000個樣本進行1000小時、加速係數80的試驗，若故障數為0，則在信賴水準60%下，可說故障率約為12 FIT以下。
