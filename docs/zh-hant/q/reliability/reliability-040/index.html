可靠度

在車用等領域，彙整產品在壽命期間會暴露於何種溫度、電壓、運作時間條件下的設想，稱為什麼？

  1. A任務剖面（mission profile）
  2. B資料手冊（datasheet）
  3. C網表（netlist）
查看答案與解析

正確答案：A. 任務剖面（mission profile）

任務剖面是對產品使用期間內使用條件的設想，例如在哪種溫度下運作幾小時、在哪種電壓下運作，以及承受幾次溫度循環或電源開關。例如車用的情形，會將行駛中與停放中各自的溫度分佈累積整個年數。由於要依此決定所需的可靠度試驗時間與條件，以及設計的餘裕，因此做出貼近實際的設想很重要。

  • A. 正確。這是對壽命期間使用條件的設想。
  • B. 資料手冊是彙整產品規格的資料。
  • C. 網表是表示電路連接關係的資料。

可靠度的其他題目

  1. 使用10,000個故障率為100 FIT的零件，1年（約8,760小時）內預期故障數最接近下列何者？（1 FIT = 每10⁹小時1次故障）
  2. 在印刷電路板等上，於潮濕環境中，金屬（銀或銅等）在施加電壓的電極之間以離子形式溶出並移動，呈樹枝狀析出而造成短路的現象，稱為什麼？
  3. 在High-k／金屬閘極的nMOS電晶體中，持續施加正的閘極電壓與高溫時，臨界電壓會逐漸變化的劣化，稱為什麼？
  4. 在先進LSI的設計中，預期電晶體在使用期間會因BTI或HCI而劣化，並確認劣化後的特性是否仍能滿足時序的作法，稱為什麼？
  5. 由高溫高濕試驗結果推估實際使用壽命時，以相對濕度的冪次方表示濕度影響的常用模型是下列何者？
