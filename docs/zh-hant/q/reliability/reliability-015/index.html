可靠度

從錫鍍層的表面長出針狀金屬結晶，並與相鄰端子短路的現象稱為什麼？

  1. A凸起（hillock）
  2. B空孔（void）
  3. C晶鬚（whisker）
查看答案與解析

正確答案：C. 晶鬚（whisker）

晶鬚是指因內部的壓縮應力等原因，從錫鍍層等的表面長出直徑數µm的細針狀結晶的現象，有時可長到數mm。它會接觸到相鄰端子而造成短路。添加鉛的錫鉛鍍層可抑制這種現象，因此在無鉛化之後再度成為問題。可藉由鍍後熱處理、鎳底層、鍍層成分的調整等方式抑制。凸起是配線的突起，空孔則是空洞。
