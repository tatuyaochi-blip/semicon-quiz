可靠度

常用於可靠度資料分析，且可依形狀參數的值表示早期故障型、偶發故障型與磨耗故障型的分佈是下列何者？

  1. A韋伯分佈（Weibull distribution）
  2. B均勻分佈
  3. C二項分佈
查看答案與解析

正確答案：A. 韋伯分佈（Weibull distribution）

韋伯分佈在形狀參數m小於1時，表示故障率隨時間減少的早期故障型；m等於1時為固定的偶發故障型；m大於1時則為故障率增加的磨耗故障型。其特長是只要改變形狀參數的值，就能以同一種分佈表示浴缸曲線三個時期中的任一個。不過，單一韋伯分佈的故障率只會隨時間單調增加或減少，因此整條浴缸曲線要組合m不同的分佈來表示。將故障資料繪於韋伯機率紙上會呈直線，其斜率即為m。均勻分佈是數值均等出現的分佈，二項分佈則是成功次數的分佈。
