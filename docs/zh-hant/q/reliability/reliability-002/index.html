可靠度

下列何者是對電遷移（electromigration）的正確說明？

  1. A因濕氣而使配線腐蝕的現象
  2. B因電流使配線的金屬原子移動，產生空孔（void）或凸起（hillock）的現象
  3. C因靜電放電而使元件損壞的現象
查看答案與解析

正確答案：B. 因電流使配線的金屬原子移動，產生空孔（void）或凸起（hillock）的現象

電遷移是指在配線中流動的電子與金屬原子碰撞並傳遞動量，使原子逐漸往電子流動的方向移動的現象。原子離開之處會形成空孔而造成斷線，原子堆積之處會形成凸起而與相鄰配線短路。壽命可用布萊克方程式（Black's equation）表示，與電流密度的約2次方成反比，溫度越高則壽命越短。因濕氣造成的腐蝕與因靜電造成的損壞則是其他的故障。
