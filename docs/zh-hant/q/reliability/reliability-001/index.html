可靠度

下列哪一項是構成表示故障率隨時間變化的浴缸曲線（bathtub curve）的三個時期的正確組合？

  1. A早期故障期、偶發故障期、磨耗故障期
  2. B設計期、製造期、出貨期
  3. C試產期、量產期、維護期
查看答案與解析

正確答案：A. 早期故障期、偶發故障期、磨耗故障期

浴缸曲線由三個時期構成：剛開始使用時因製造缺陷而故障率較高的早期故障期、故障率低且接近固定的偶發故障期，以及因劣化而故障率上升的磨耗故障期，其形狀類似浴缸的剖面。早期故障可在出貨前以burn-in（預燒）等方式剔除，磨耗故障則設計成發生在產品預期壽命之後。設計、製造、出貨等是產品生命週期的階段，並不是故障率的時期。
