可靠度

下列何者是對TDDB（經時絕緣破壞）的正確說明？

  1. A因電流使配線的金屬原子移動的現象
  2. B因溫度變化的反覆作用，使焊接接點疲勞的現象
  3. C對閘極絕緣膜持續施加電場，經過一定時間後發生絕緣破壞的現象
查看答案與解析

正確答案：C. 對閘極絕緣膜持續施加電場，經過一定時間後發生絕緣破壞的現象

TDDB（Time Dependent Dielectric Breakdown）是指即使電場不足以使絕緣膜立刻損壞，長時間持續施加後，絕緣膜中會逐漸產生缺陷，當缺陷相連而橋接電極之間時就會導致絕緣破壞的現象。閘極絕緣膜越薄，電場越強，因此成為重要的可靠度項目。配線之間的Low-k膜也會有此問題。配線原子的移動是電遷移，焊料的疲勞則是溫度循環的故障。
