可靠度

蒐集並分析市場上使用中產品的故障（現場故障）資訊，其主要目的是下列何者？

  1. A為了提高產品價格
  2. B為了完全不用再做試驗
  3. C為了掌握實際使用條件下的故障傾向，並用於改善設計、製造與試驗的條件
查看答案與解析

正確答案：C. 為了掌握實際使用條件下的故障傾向，並用於改善設計、製造與試驗的條件

可靠度試驗只是模擬實際使用條件而已，在市場上有時會因意料之外的使用方式或環境而發生故障。藉由分析退回的故障品，掌握故障率與故障模式的傾向，可用於改善設計、製造製程與試驗條件。也能調查對以同一批次或設備製造的其他產品之影響，必要時還能促成停止出貨的判斷。

  • A. 目的不是提高價格。
  • B. 即使有現場資訊，出貨前的試驗仍是必要的。
  • C. 正確。掌握實際的故障傾向並用於改善。

可靠度的其他題目

  1. 在評估ESD（靜電放電）耐受性的試驗模型中，「帶電的人觸碰IC端子時的放電」與「IC本身帶電而端子接觸金屬時的放電」，其名稱的組合下列何者正確？
  2. 除了溫度之外，還包含濕度、電壓等多種應力影響來表示壽命加速，且以熱力學為基礎的模型是下列何者？
  3. 以溫度變化幅度（應變大小）與反覆次數的關係，來表示溫度循環所造成焊接接點疲勞壽命的模型是下列何者？
  4. 在電遷移的壽命試驗中，常用來表示多條配線直到故障為止的時間分佈的統計分佈是下列何者？
  5. 在車用等領域，彙整產品在壽命期間會暴露於何種溫度、電壓、運作時間條件下的設想，稱為什麼？
