可靠度

以溫度變化幅度（應變大小）與反覆次數的關係，來表示溫度循環所造成焊接接點疲勞壽命的模型是下列何者？

  1. A科芬－曼森定律（Coffin-Manson law）
  2. B布萊克方程式
  3. C摩爾定律
查看答案與解析

正確答案：A. 科芬－曼森定律（Coffin-Manson law）

科芬－曼森定律表示反覆施加的應變大小，與因疲勞而破壞為止的反覆次數之間的關係，在溫度循環中可寫成N∝(ΔT)^(−m)。對焊料而言，m被認為在2前後，因此若將溫度變化幅度減半，壽命的次數約變為4倍。它被用來由嚴苛條件的溫度循環試驗結果，推估較溫和的實際使用環境下的壽命。

  • A. 正確。表示溫度變化幅度與疲勞壽命的關係。
  • B. 布萊克方程式是電遷移的壽命公式。
  • C. 摩爾定律是關於積體度提升的經驗法則。
