可靠度

作為ESD（靜電放電）對策，設置在LSI輸入輸出端子上的是下列何者？

  1. A發光二極體
  2. B冷卻風扇
  3. CESD保護電路（保護二極體等）
查看答案與解析

正確答案：C. ESD保護電路（保護二極體等）

人體或設備上累積的靜電可高達數千V，若對LSI的端子放電，薄的閘極氧化膜或接面會在瞬間被破壞。因此在輸入輸出端子設置由保護二極體，或電源與接地之間的箝位電路等構成的ESD保護電路，將放電電流導向電源或接地。製造現場也會採取腕帶、導電性地板與容器、離子產生器等靜電對策。
