可靠度

除了溫度之外，還包含濕度、電壓等多種應力影響來表示壽命加速，且以熱力學為基礎的模型是下列何者？

  1. A波松模型
  2. B歐姆定律
  3. C艾林模型（Eyring model）
查看答案與解析

正確答案：C. 艾林模型（Eyring model）

艾林模型是由熱力學導出化學反應速度的模型，其形式是在阿瑞尼斯的溫度項上，再乘以濕度、電壓、電流等應力的項，用來表示多種應力造成的壽命加速。它被用來由高溫高濕偏壓試驗等的結果，推估實際使用條件下的壽命。以冪次方表示濕度項的濕度用佩克模型（Peck's model），也是這種想法的一種。

  • A. 波松模型用於良率的計算等。
  • B. 歐姆定律是電壓、電流與電阻的關係。
  • C. 正確。這是包含多種應力的加速模型。

可靠度的其他題目

  1. 以溫度變化幅度（應變大小）與反覆次數的關係，來表示溫度循環所造成焊接接點疲勞壽命的模型是下列何者？
  2. 在電遷移的壽命試驗中，常用來表示多條配線直到故障為止的時間分佈的統計分佈是下列何者？
  3. 在車用等領域，彙整產品在壽命期間會暴露於何種溫度、電壓、運作時間條件下的設想，稱為什麼？
  4. 使用10,000個故障率為100 FIT的零件，1年（約8,760小時）內預期故障數最接近下列何者？（1 FIT = 每10⁹小時1次故障）
  5. 在印刷電路板等上，於潮濕環境中，金屬（銀或銅等）在施加電壓的電極之間以離子形式溶出並移動，呈樹枝狀析出而造成短路的現象，稱為什麼？
