可靠度

下列何者是進行故障分析時的正確一般流程？

  1. A一開始就破壞封裝來觀察內部
  2. B故障品立即丟棄，改調查新的產品
  3. C先進行外觀觀察、X光透視、電性量測等非破壞性分析，之後再進行開封或剖面觀察等破壞性分析
查看答案與解析

正確答案：C. 先進行外觀觀察、X光透視、電性量測等非破壞性分析，之後再進行開封或剖面觀察等破壞性分析

如果先進行破壞性分析，故障的痕跡可能會消失而無法得知原因。因此要先以外觀觀察、X光透視、超音波顯微鏡、電氣特性量測等非破壞性分析縮小故障的狀態與位置範圍，之後再進入開封、發光分析、剖面觀察等破壞性分析。故障品是得知原因的唯一線索，因此以收到時的狀態保管，並保護其免受靜電與濕氣影響也很重要。
