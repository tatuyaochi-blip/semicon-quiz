硬體安全

下列何者不屬於用來因應Spectre這類推測執行漏洞的對策？

  1. A在危險的分支之後插入停止推測執行的屏障（barrier）指令
  2. B提高CPU的時脈頻率
  3. C對陣列的索引進行遮罩處理，使其收斂在範圍之內，讓範圍之外無法被推測讀取
查看答案與解析

正確答案：B. 提高CPU的時脈頻率

因應Spectre的對策，有在條件分支之後插入停止推測執行的指令（x86的lfence等）、遮罩索引使範圍之外無法讀取、避免間接分支預測被濫用的寫法（retpoline等），以及藉由更新CPU微碼控制預測器等。若完全停止推測執行，效能會大幅下降，因此一般是只限縮在危險的地方使用。

  • A. 這是實際使用的對策。
  • B. 正確。頻率與推測的問題無關。
  • C. 這是實際使用的對策。
