硬體安全

下列關於產生密碼金鑰時，若使用容易被預測的低品質亂數，可能發生的情況，何者正確？

  1. A密碼處理變快
  2. B密文的長度變成2倍
  3. C即使密碼演算法很強，金鑰仍被推測出來而使密碼被破解
查看答案與解析

正確答案：C. 即使密碼演算法很強，金鑰仍被推測出來而使密碼被破解

密碼的安全性仰賴於攻擊者不知道金鑰。若產生金鑰的亂數有偏差，或剛通電後尚未累積足夠的不可預測性，金鑰的候選就會變少，而被暴力窮舉找到。實際上也有報告指出，因亂數的缺陷，許多機器持有了相似的金鑰。亂數的產生是安全性中最基本的零件之一。

  • A. 與速度無關。
  • B. 與長度無關。
  • C. 正確。金鑰的不可預測性是安全的基礎。
