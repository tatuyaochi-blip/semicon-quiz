硬體安全

下列關於作為快取旁路對策，將共用快取分割（partitioning）的概念，何者正確？

  1. A把快取物理地割成兩半後丟掉
  2. B把快取容量增為2倍
  3. C依行程或虛擬機器劃分可使用的快取範圍，使彼此無法擠出對方的資料，讓痕跡無法被觀察
查看答案與解析

正確答案：C. 依行程或虛擬機器劃分可使用的快取範圍，使彼此無法擠出對方的資料，讓痕跡無法被觀察

快取旁路是在攻擊者與受害者爭奪相同快取位置時才成立。若將快取的一部分路（way）或組（set）分配給各行程或虛擬機器，就無法互相擠出對方的資料，也就無法觀察對方存取的痕跡。有些CPU具備控制快取分配的功能。不過，各自可用的容量會減少，因此需要在效能上取捨。

  • A. 並不是物理地分割。
  • B. 增加容量，只要共用，痕跡仍會殘留。
  • C. 正確。代價是可用的快取減少。
