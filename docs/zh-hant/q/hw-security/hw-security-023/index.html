硬體安全

下列關於電腦等搭載的TPM（可信平台模組）的主要作用，何者正確？

  1. A用來加快畫面顯示的專用電路
  2. B管理CPU散熱的零件
  3. C提供安全地產生與保管金鑰、保存已啟動軟體的記錄並證明其狀態等安全功能
查看答案與解析

正確答案：C. 提供安全地產生與保管金鑰、保存已啟動軟體的記錄並證明其狀態等安全功能

TPM是進行金鑰的產生與保管、密碼處理、亂數產生、記錄已啟動軟體的雜湊值等，不易從外部被竄改的安全用晶片（或內建於CPU的功能）。例如，若設計成只有在啟動狀態正確時才能取出磁碟加密的金鑰，那麼即使磁碟被抽走，或啟動軟體被改寫，資料也不易被讀取。

  • A. 不是顯示電路。
  • B. 不是散熱零件。
  • C. 正確。也用於保護磁碟加密的金鑰等。
