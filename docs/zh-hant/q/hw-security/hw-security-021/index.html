硬體安全

下列關於安全啟動中，以公開金鑰密碼學驗證軟體簽章的優點，何者正確？

  1. A機器上只需放置驗證用的公開金鑰，製作簽章的私密金鑰可由開發方嚴密保管，因此即使機器被分析，也無法製作出偽造的簽章
  2. B公開金鑰密碼學一定比對稱金鑰密碼學快
  3. C公開金鑰必須保密
查看答案與解析

正確答案：A. 機器上只需放置驗證用的公開金鑰，製作簽章的私密金鑰可由開發方嚴密保管，因此即使機器被分析，也無法製作出偽造的簽章

若採用以對稱金鑰驗證的方式，驗證所用的金鑰也能製作簽章，因此只要從1台機器取出金鑰，就可能被製作出針對所有機器的偽造軟體。若採用公開金鑰密碼學，機器上放置的是只能用於驗證的公開金鑰，製作簽章的私密金鑰則只放在開發方的安全設施內。即使公開金鑰被知道，也無法製作出偽造的簽章。

  • A. 正確。不必擔心私密金鑰被從機器取出。
  • B. 一般而言公開金鑰密碼學較慢。
  • C. 公開金鑰即使被知道也沒有問題。
