硬體安全

下列關於內建於晶片的真亂數產生器（TRNG）的說明，何者正確？

  1. A以固定的運算式，從種子（seed）產生亂數序列的程式
  2. B以熱雜訊、振盪器的抖動等無法預測的物理現象為基礎來產生亂數的電路
  3. C直接把時鐘的時間當作亂數使用的電路
查看答案與解析

正確答案：B. 以熱雜訊、振盪器的抖動等無法預測的物理現象為基礎來產生亂數的電路

偽亂數只要知道種子就能重新產生相同的序列，所以種子一旦被推測，金鑰也會被推測出來。真亂數產生器以電阻的熱雜訊、環形振盪器週期的抖動等無法預測的物理現象為基礎產生位元。實際上，多半是以TRNG的輸出產生密碼用偽亂數產生器的種子，兼顧速度與不可預測性。

  • A. 那是偽亂數產生器。
  • B. 正確。作為產生密碼金鑰的來源使用。
  • C. 時間可預測，所以不適合作為亂數。
