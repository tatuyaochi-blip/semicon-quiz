硬體安全

下列何者是利用快取的旁路攻擊得以成立的主要原因？

  1. A快取可能在行程之間共用，其他行程使用了哪些資料，可由自己存取的快慢（命中或未命中）差異觀察到
  2. B任何人都可以直接讀出快取的內容
  3. C快取會不加密就把資料儲存到磁碟
查看答案與解析

正確答案：A. 快取可能在行程之間共用，其他行程使用了哪些資料，可由自己存取的快慢（命中或未命中）差異觀察到

存在於快取中的資料讀取較快，不在其中的資料讀取較慢。攻擊者先以自己的資料填滿共用快取的一部分，之後測量讀取這些資料的時間，就能得知其他行程是否使用了該位置而把自己的資料擠出去。當密碼處理依金鑰不同而讀取表格中不同位置時，這種方法就會洩漏金鑰的資訊。

  • A. 正確。存取時間成為痕跡。
  • B. 並非直接讀取內容，而是從時間差異推測。
  • C. 快取不會儲存到磁碟。
