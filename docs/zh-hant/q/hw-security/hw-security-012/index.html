硬體安全

在利用進行密碼處理的晶片耗電量波形的功耗分析中，下列關於差分功耗分析（DPA）的特徵，何者正確？

  1. A蒐集大量處理的功耗波形並進行統計處理，取出單一波形中看不到的、與金鑰相關的微小差異
  2. B只要用眼睛看單一功耗波形，就能得知整個金鑰
  3. C關閉晶片電源後取出金鑰
查看答案與解析

正確答案：A. 蒐集大量處理的功耗波形並進行統計處理，取出單一波形中看不到的、與金鑰相關的微小差異

CMOS電路在訊號切換時會消耗電力，因此耗電量會隨處理的資料而有些微變化。簡單功耗分析是從單一波形的形狀解讀處理流程，而差分功耗分析則是蒐集數千次密碼處理的波形，針對每個金鑰候選計算預測的中間值與波形的相關性，找出正確的金鑰。其特徵是即使是淹沒在雜訊中的微小差異，也能以統計取出。

  • A. 正確。以統計使雜訊中的微小差異浮現。
  • B. 那是簡單功耗分析（SPA）理想地成功時的情況。
  • C. 電源關閉就不會進行處理。
