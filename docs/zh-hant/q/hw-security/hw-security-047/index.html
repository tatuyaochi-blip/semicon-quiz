硬體安全

下列何者是對於連接在電腦上的外部機器利用DMA擅自讀寫主記憶體內容的攻擊的對策？

  1. A提高外部機器的電源電壓
  2. B加快DMA的傳輸
  3. C使用IOMMU，將各機器可透過DMA存取的記憶體範圍，限制在作業系統許可的區域內
查看答案與解析

正確答案：C. 使用IOMMU，將各機器可透過DMA存取的記憶體範圍，限制在作業系統許可的區域內

DMA是機器不經過CPU就直接讀寫記憶體的機制，因此若連接上惡意或被劫持的機器，就能讀取或竄改作業系統的記憶體與金鑰。以高速外部連接埠連接的機器尤其成為問題。若使用IOMMU，就能把各機器可存取的位址限制在作業系統決定的範圍內，因此對未獲許可位置的DMA會被拒絕。

  • A. 與電壓無關。
  • B. 加快也無法防範。
  • C. 正確。針對每個機器進行位址轉換與保護。
