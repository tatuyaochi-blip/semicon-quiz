硬體安全

下列何者是發現CPU硬體漏洞時，針對已出貨CPU所採取的對策之一？

  1. A回收所有CPU，逐一更換電晶體
  2. B更新CPU的微碼，改變有問題的內部動作，或加入作業系統可使用的新控制功能
  3. C更換CPU表面的印字
查看答案與解析

正確答案：B. 更新CPU的微碼，改變有問題的內部動作，或加入作業系統可使用的新控制功能

許多CPU是以可改寫的微碼來執行複雜指令的處理與部分內部控制。發現漏洞時，CPU廠商會發布微碼更新，透過BIOS或作業系統在每次啟動時載入。如此就能抑制有問題的動作，或加入清除分支預測器的指令等新控制。電路本身的問題，則在下一代CPU中根本地修正。

  • A. 無法更換電晶體。
  • B. 正確。與作業系統及編譯器的對策搭配使用。
  • C. 更換印字不會改變動作。
