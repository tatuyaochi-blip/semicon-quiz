離子佈植

形成淺p型接面時，將碳等與硼一起佈植（共佈植）的主要目的，下列何者正確？

  1. A將p型轉變為n型
  2. B使晶圓發光
  3. C抑制硼的擴散，使接面維持淺層
查看答案與解析

正確答案：C. 抑制硼的擴散，使接面維持淺層

硼會藉由晶格間矽的幫助而使擴散增強（暫態增強擴散）。若一起佈植約10¹⁵ cm⁻²的碳，碳會捕捉並消耗晶格間矽，因此硼的擴散受到抑制，即使退火後也能維持淺接面。氟或氮的共佈植也用於類似的目的。同樣地，磷的擴散也可被碳抑制，因此nMOS磊晶的Si:P中有時也會添加碳。
