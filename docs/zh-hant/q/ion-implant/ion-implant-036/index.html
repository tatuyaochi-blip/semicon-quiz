離子佈植

在一般的離子佈植機中，離子所經過的順序，下列何者正確？

  1. A離子源 → 質量分析 → 加速部 → 掃描 → 晶圓
  2. B加速部 → 離子源 → 質量分析 → 晶圓
  3. C質量分析 → 離子源 → 晶圓 → 加速部
查看答案與解析

正確答案：A. 離子源 → 質量分析 → 加速部 → 掃描 → 晶圓

在離子源將氣體製成電漿並取出離子，以質量分析磁鐵僅選出目標離子，再於加速部加速到所需的能量。之後掃描離子束，均勻佈植到整片晶圓，並以法拉第杯量測劑量。依機台不同，順序也有差異，例如先加速再分析，或以高能量傳輸、最後再減速。

  • A. 正確。從離子源開始，經篩選、加速、掃描後到達晶圓。
  • B. 不可能在產生離子之前就加速。
  • C. 不可能在離子源之前進行質量分析。
