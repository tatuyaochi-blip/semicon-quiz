離子佈植

下列何者是使用高達數MeV之高能量離子佈植的應用範例？

  1. A形成表面極淺的接面
  2. B在影像感測器或功率元件等中，將雜質導入深處
  3. C形成金屬配線
查看答案與解析

正確答案：B. 在影像感測器或功率元件等中，將雜質導入深處

高能量離子佈植可將雜質導入距表面數µm～10 µm左右的深處。用於CMOS影像感測器的深層光電二極體與像素間隔離、功率元件的深層（超接面的柱狀結構等）、逆向摻雜井的形成等。為了獲得數MeV的能量，會使用以高頻分多段加速的線性加速器（LINAC），或使用負離子的串聯式（tandem）加速器。
