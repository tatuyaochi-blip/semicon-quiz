MEMS與感測器

常用於測量室內二氧化碳（CO2）濃度的NDIR方式氣體感測器，其原理下列何者正確？

  1. A直接秤量CO2的重量
  2. B利用CO2會吸收特定波長的紅外線，由穿透的紅外線量求得濃度
  3. C利用CO2會導電
查看答案與解析

正確答案：B. 利用CO2會吸收特定波長的紅外線，由穿透的紅外線量求得濃度

NDIR（非分散式紅外線吸收）方式利用CO2會強烈吸收波長約4.3 µm紅外線的性質。以裝有只讓該波長通過之濾光片的偵測器，測量光源發出的紅外線在通過氣體期間減弱了多少，再依朗伯-比爾定律求得濃度。由於不易對其他氣體起反應，且長期穩定，用於通風管理（以1000 ppm以下為參考標準）、農業溫室、空調控制。

  • A. 這不是直接秤量重量的方式。
  • B. 正確。由紅外線的吸收量求得CO2的濃度。
  • C. 這不是利用CO2導電性的方式。
