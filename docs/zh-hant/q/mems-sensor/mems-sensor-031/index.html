MEMS與感測器

利用電阻會隨溫度大幅變化的性質所製成的溫度感測器為下列何者？

  1. A熱敏電阻
  2. B霍爾元件
  3. C光電二極體
查看答案與解析

正確答案：A. 熱敏電阻

熱敏電阻是以錳、鎳、鈷等金屬氧化物的燒結體製成，電阻值會隨溫度大幅變化的元件。以溫度上升時電阻下降的NTC熱敏電阻為代表，變化率每1 ℃約為−3～−5%，約為鉑測溫電阻體的10倍，價格便宜且靈敏度高。用於電池的溫度監控、冷氣機與冰箱的溫度控制等。電阻會急遽增加的PTC則用於過電流保護。

  • A. 正確。這是利用電阻的溫度變化的溫度感測器。
  • B. 霍爾元件是偵測磁場的感測器。
  • C. 光電二極體是偵測光的感測器。
