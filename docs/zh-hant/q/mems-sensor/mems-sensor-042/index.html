MEMS與感測器

有時用於智慧型手機的螢幕下指紋感測器或醫療用超音波診斷、以MEMS製成的超音波元件為下列何者？

  1. AVCSEL
  2. BCCD
  3. CPMUT・CMUT（微加工超音波換能器）
查看答案與解析

正確答案：C. PMUT・CMUT（微加工超音波換能器）

PMUT（壓電式）與CMUT（電容式）是以MEMS技術製成的超音波收發元件，使薄膜振動以發出超音波，並偵測反射回來的超音波。與傳統較厚的壓電陶瓷元件相比，可用半導體製程將多個元件以細間距排成陣列，並與電路整合。用於智慧型手機的螢幕下超音波指紋感測器、掌上型超音波診斷裝置、距離感測器等。

  • A. VCSEL是面射型半導體雷射。
  • B. CCD是偵測光的影像感測器。
  • C. 正確。這是以MEMS製成的超音波換能器。
