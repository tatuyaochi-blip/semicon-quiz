MEMS與感測器

在汽車的LiDAR等裝置中，用來掃描雷射光的MEMS元件為下列何者？

  1. AMEMS麥克風
  2. B加速度感測器
  3. CMEMS反射鏡（掃描光的微小可動反射鏡）
查看答案與解析

正確答案：C. MEMS反射鏡（掃描光的微小可動反射鏡）

MEMS反射鏡是以靜電力或電磁力使直徑約1 mm的微小鏡面以數kHz至數十kHz共振或傾斜，藉此改變反射雷射光方向的元件。與以馬達旋轉的多面鏡相比，體積小、重量輕，且不需要機械旋轉零件而耐振動，用於LiDAR的掃描、抬頭顯示器或AR眼鏡的雷射投影、光開關等。
