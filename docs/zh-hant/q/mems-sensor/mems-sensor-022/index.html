MEMS與感測器

長期用於判定汽車安全氣囊是否啟動的MEMS感測器為下列何者？

  1. A加速度感測器
  2. BMEMS麥克風
  3. CDMD
查看答案與解析

正確答案：A. 加速度感測器

以加速度感測器偵測碰撞時的急遽減速（數十G），並根據其大小與時間變化，在十幾ms內判定是否引爆安全氣囊。1990年代初期，Analog Devices將MEMS加速度感測器（ADXL50）量產用於車輛，憑藉體積小、價格低、可靠度高的優點，成為MEMS普及的契機。現在為了防止誤動作，會結合車體多處感測器的資訊來判定。
