MEMS與感測器

在晶片上製作微小流道，以少量液體進行化學分析或檢驗的技術為下列何者？

  1. A微流體元件（晶片實驗室）
  2. B光罩
  3. C接合線
查看答案與解析

正確答案：A. 微流體元件（晶片實驗室）

微流體元件是以MEMS的加工技術在晶片上製作寬度數十～數百µm的流道、混合部與反應部，以µL以下的極少量樣本進行分析或檢驗的元件。也稱為晶片實驗室（Lab-on-a-chip），由於樣本與試劑用量少、反應快速，並可做成便於攜帶的裝置，因此用於新冠病毒的快速檢驗、血液檢驗、基因分析、細胞篩選等。材料除了玻璃與矽之外，也使用便宜的樹脂（PDMS）。

  • A. 正確。在晶片上的微小流道中進行分析。
  • B. 光罩是以曝光轉印電路圖案的原版。
  • C. 接合線是連接晶片與端子的細金屬線。
