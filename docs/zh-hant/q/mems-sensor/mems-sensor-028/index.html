MEMS與感測器

作為時脈源，有時會用來取代石英振盪器的MEMS振盪器，其優點下列何者正確？

  1. A頻率穩定度必定比石英高
  2. B可用半導體製程製造，因此體積小、耐衝擊，且容易與IC整合
  3. C尺寸大而容易處理
查看答案與解析

正確答案：B. 可用半導體製程製造，因此體積小、耐衝擊，且容易與IC整合

MEMS振盪器是結合矽的微小振子，以及驅動、溫度補償、PLL的電路而成，可用半導體製程量產。由於矽的共振頻率會隨溫度大幅變化，因此以電路進行補償，近年也能達到±數ppm左右的精度。因體積小、耐衝擊與振動、頻率可自由設定，且供應容易穩定，在車用設備與穿戴式裝置等領域用來取代石英。
