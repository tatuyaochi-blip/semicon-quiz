MEMS與感測器

利用物質附著在微小懸臂樑或石英振子表面時共振頻率會改變的性質，來偵測極微小質量的方法，下列說明何者正確？

  1. A附著的質量增加時，共振頻率上升
  2. B附著的質量增加時，共振頻率下降，並由其變化量求得質量
  3. C共振頻率與質量無關
查看答案與解析

正確答案：B. 附著的質量增加時，共振頻率下降，並由其變化量求得質量

共振頻率與 √(k/m) 成正比，因此當物質附著在表面使質量m增加時，頻率會下降，變化微小時 Δf/f ≈ −Δm/(2m)。振子越小越輕，微小的質量變化就會使頻率大幅改變，在奈米等級的樑上甚至能偵測到接近單一分子的質量。石英晶體微天平（QCM）廣泛用作蒸鍍設備的膜厚監控器，也應用於氣體與生物分子的感測器。

  • A. 質量增加時，共振頻率會下降。
  • B. 正確。由頻率的下降求得附著的質量。
  • C. 共振頻率取決於質量。
