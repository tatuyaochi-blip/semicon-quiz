MEMS與感測器

廣泛用於人體感應器（人來即開燈）、利用溫度變化會產生電荷的材料的感測器為下列何者？

  1. A焦電型紅外線感測器
  2. B霍爾元件
  3. C應變計
查看答案與解析

正確答案：A. 焦電型紅外線感測器

焦電型紅外線感測器使用溫度變化時表面會出現電荷的焦電體（PZT或鉭酸鋰等），偵測人體發出的波長約10 µm的紅外線量的變化。由於只對溫度的變化起反應，因此人移動時會輸出訊號，而靜止的人則較難偵測。以菲涅耳透鏡劃分視野來捕捉動作，用於照明、廁所、冷氣機、防盜裝置的人體感應器。

  • A. 正確。以焦電效應偵測紅外線的變化。
  • B. 霍爾元件是偵測磁場的感測器。
  • C. 應變計是測量變形所造成電阻變化的感測器。
