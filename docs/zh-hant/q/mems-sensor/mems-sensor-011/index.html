MEMS與感測器

以MEMS技術製成的噴墨印表機列印頭，其一般的墨水噴出方式為下列何者？

  1. A靠重力讓墨水自然滴落
  2. B使墨水帶電並以磁鐵吸引
  3. C以壓電元件的變形，或加熱器加熱所產生氣泡的壓力將墨水擠出
查看答案與解析

正確答案：C. 以壓電元件的變形，或加熱器加熱所產生氣泡的壓力將墨水擠出

噴墨列印頭有兩種方式：一是對壓電元件施加電壓使其變形，以其壓力擠出墨水的壓電式（Epson等）；二是以加熱器在數µs內將墨水加熱到300 ℃以上產生氣泡，以其壓力擠出的熱感式（Canon、HP等）。直徑數十µm的數千個噴嘴與流道以MEMS技術製成，可噴出數pL的液滴。除了列印之外，也應用於顯示器的製造等。
