MEMS與感測器

利用在壓電基板表面傳遞的彈性波，用於智慧型手機等高頻濾波器的元件為下列何者？

  1. ALCD面板
  2. BDRAM記憶胞
  3. CSAW濾波器（表面聲波濾波器）
查看答案與解析

正確答案：C. SAW濾波器（表面聲波濾波器）

SAW濾波器是在鉭酸鋰等壓電基板的表面製作梳形電極（IDT），將電訊號轉換為沿表面傳遞的彈性波，只讓由電極週期決定的特定頻率通過。彈性波比電磁波慢約10萬倍，因此波長短，能以小晶片處理高頻。在行動電話數百MHz～2 GHz左右的頻段大量使用，更高的頻率則使用BAW濾波器。

  • A. LCD面板是顯示裝置。
  • B. DRAM記憶胞是記憶元件。
  • C. 正確。這是利用沿表面傳遞的彈性波的濾波器。
