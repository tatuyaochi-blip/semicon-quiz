MEMS與感測器

對堆疊在基板上的薄膜進行加工以製作可動結構的MEMS加工法，為下列何者？

  1. A體型微加工
  2. B表面微加工
  3. C鑲嵌法
查看答案與解析

正確答案：B. 表面微加工

表面微加工是在基板上堆疊犧牲層（SiO2等）與結構層（多晶矽等）的薄膜並加工，最後移除犧牲層使結構懸浮的方法，能以接近LSI的製程做出厚度數µm的結構。從背面深度蝕刻基板本身以製作薄膜或孔洞的方法則是體型微加工，使用KOH的異向性蝕刻或Deep RIE，用來製作壓力感測器的膜片等。
