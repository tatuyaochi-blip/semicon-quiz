MEMS與感測器

通以定電流的矽PN接面，其順向電壓的溫度依存性，下列何者正確？

  1. A溫度上升時，每℃約減少2 mV
  2. B溫度上升時會變大
  3. C不受溫度影響而保持固定
查看答案與解析

正確答案：A. 溫度上升時，每℃約減少2 mV

在定電流下，矽PN接面的順向電壓每當溫度上升1 ℃，約減少2 mV。由於電流密度不同的兩個接面的電壓差與絕對溫度成正比（PTAT），利用此特性可輕易在LSI中內建精度約±1 ℃的溫度感測器。用於CPU的過熱保護與電池監控，而將其組合成抵消電壓溫度變化的電路，就是能隙參考電壓電路。
