MEMS與感測器

要提高由彈簧與質量塊構成的MEMS結構的共振頻率，下列方法何者正確？

  1. A使彈簧變軟、質量塊變重
  2. B使彈簧變硬，或使質量塊變輕
  3. C改變結構的顏色
查看答案與解析

正確答案：B. 使彈簧變硬，或使質量塊變輕

彈簧常數為k、質量為m的結構，其共振頻率為 f = (1/2π)√(k/m)，使彈簧變硬或質量塊變輕就會升高。在加速度感測器中，質量塊的位移與加速度÷(2πf)²成正比，因此共振頻率越高，靈敏度越低。另一方面，可回應的頻寬與耐衝擊性會提高，所以要在靈敏度與頻寬之間取得平衡，來決定共振頻率（數kHz左右）。
