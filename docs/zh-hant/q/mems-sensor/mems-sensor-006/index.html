MEMS與感測器

振動型MEMS陀螺儀為了偵測角速度所利用的力，下列何者正確？

  1. A科氏力
  2. B僅有庫侖力
  3. C浮力
查看答案與解析

正確答案：A. 科氏力

當振動的物體旋轉時，在與振動方向及旋轉軸皆垂直的方向上，會產生與速度和角速度成正比的科氏力。MEMS陀螺儀先使質量塊以數kHz至數十kHz共振，再以電容等方式偵測旋轉時在正交方向產生的微小位移，進而求得角速度。用於相機的防手震、智慧型手機的姿態偵測、汽車的防側滑、無人機的控制等。
