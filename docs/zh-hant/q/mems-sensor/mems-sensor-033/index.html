MEMS與感測器

智慧手錶等從手腕測量心率的光學式感測器，其原理下列何者正確？

  1. A測量皮膚的溫度變化
  2. B僅從手臂動作的加速度計算
  3. C照射LED的光，以光電二極體偵測血流變化所造成的反射光強度變化
查看答案與解析

正確答案：C. 照射LED的光，以光電二極體偵測血流變化所造成的反射光強度變化

光學式心率感測器將綠色等LED的光照射在皮膚上，以光電二極體偵測隨脈搏變化的血液量所造成的反射光強度變化（光體積變化描記圖，PPG）。綠光容易被血液中的血紅素吸收，因此變化較明顯。身體動作造成的雜訊，則以加速度感測器的資訊進行補正。比較紅光與紅外光吸收的差異，還可測量血氧飽和度（SpO2）。

  • A. 皮膚的溫度變化難以捕捉脈搏。
  • B. 加速度感測器用於動作的補正，但心率的偵測本身是靠光來進行。
  • C. 正確。以光電二極體偵測反射光的變化。
