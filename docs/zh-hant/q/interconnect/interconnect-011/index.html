配線製程

將導線之間絕緣膜的一部分做成空洞（空氣間隙，air gap）的技術，主要目的為下列何者？

  1. A提高導線的機械強度
  2. B降低導線間的電容（空氣的相對介電常數約為1）
  3. C降低導線的電阻
查看答案與解析

正確答案：B. 降低導線間的電容（空氣的相對介電常數約為1）

空氣（真空）的相對介電常數約為1，比任何絕緣材料都低，因此將導線之間做成空洞，可使導線間電容降低約20～30%。作法有形成導線後去除其間的絕緣膜再從上方封住，以及在沉積時刻意留下空洞等。由於有機械強度、散熱不易，以及上層導孔會落入空洞等問題，因此僅用於特別需要降低電容的密集層。
