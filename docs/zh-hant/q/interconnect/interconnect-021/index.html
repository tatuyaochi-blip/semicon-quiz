配線製程

同時以Cu填滿導線溝槽與導孔，並以1次CMP完成的方法稱為什麼？

  1. A單鑲嵌法
  2. B回蝕法
  3. C雙鑲嵌法
查看答案與解析

正確答案：C. 雙鑲嵌法

雙鑲嵌法是以微影與蝕刻在絕緣膜上同時形成導孔的孔與導線的溝槽，再以阻障層、晶種層與Cu電鍍一併填入，最後以1次CMP完成。與分別製作導孔和導線的單鑲嵌法相比，沉積、電鍍與CMP各少一次，導孔與導線之間也不會產生阻障層界面，因此在電阻與可靠度方面也較有利。依先開孔還是先開溝槽，方式可再區分。
