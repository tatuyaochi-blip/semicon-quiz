配線製程

作為取代Cu的微細導線材料而被研究的釕（Ru）等金屬，其優點下列何者正確？

  1. A即使導線很細，電阻率的上升也相對較小，且有可能將阻障層做得更薄（或不需要）
  2. B比銅便宜許多
  3. C能讓光穿透，因此容易檢查
查看答案與解析

正確答案：A. 即使導線很細，電阻率的上升也相對較小，且有可能將阻障層做得更薄（或不需要）

Cu在粗導線中電阻率雖低，但在寬度10～20 nm級的極細導線中，表面與晶界的散射增加，又必須有數nm的阻障層，因此有效電阻上升。釕與鉬的電子平均自由路徑短，僅數nm～十幾nm，即使變細電阻率的上升也小，而且向絕緣膜的擴散少，有可能將阻障層做薄或省去。能以蝕刻加工也是其優點。
