在微縮持續推進的多層導線中，導孔電阻成為問題的主要原因，下列何者正確？

  1. A導孔的剖面積變小，且電阻高的阻障金屬所占的比例變大
  2. B導孔變長了
  3. C電流不再流過導孔
查看答案與解析

正確答案：A. 導孔的剖面積變小，且電阻高的阻障金屬所占的比例變大

導孔變細時，剖面積變小使電阻上升，而且為防止Cu擴散所需的高電阻阻障金屬（厚度2～3 nm）無法做得太薄，因此在直徑20 nm的導孔中，阻障層占了剖面相當大的部分。再加上導孔底部的阻障層串聯在電流通道中，對電阻的影響更大。因此正在研究使阻障層變薄的ALD、去除底部阻障層的技術，以及不需阻障層的材料。

  • A. 正確。原因是剖面積縮小與阻障層比例增加。
  • B. 微縮並不會使導孔變長。
  • C. 導孔中也有電流流過。
