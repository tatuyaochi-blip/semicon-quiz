電阻率2 µΩ·cm的導線，長度1 mm、寬度與厚度各為100 nm時，電阻約為多少？

  1. A約2 Ω
  2. B約2 kΩ
  3. C約2 MΩ
查看答案與解析

正確答案：B. 約2 kΩ

電阻為R = ρL/(W × T)，由ρ = 2×10⁻⁸ Ω·m、L = 1×10⁻³ m、W × T = 1×10⁻¹⁴ m²，得R = 2000 Ω（約2 kΩ）。即使只有1 mm這麼短的距離，剖面為100 nm見方的導線也會有這麼大的電阻，與導線電容（1 mm約0.2 pF）組合後，RC延遲達數百ps。因此長導線會使用上層的粗導線，或插入中繼器。
