配線製程

設置於Cu導線上表面，兼具防止向絕緣膜側擴散與蝕刻終止作用的膜，一般為下列何者？

  1. A光阻
  2. B多晶矽
  3. CSiCN等介電質覆蓋膜
查看答案與解析

正確答案：C. SiCN等介電質覆蓋膜

在CMP後露出的Cu導線上表面，會形成SiCN或SiN等介電質覆蓋膜（厚度數nm～數十nm），其作用是防止Cu向上方的絕緣膜擴散，並使下一層導孔的蝕刻停止。覆蓋膜與導線的界面也是電遷移的主要路徑，因此界面的附著性決定了可靠度。由於相對介電常數在5左右，相對偏高，為避免增加導線間電容，要求將其做薄。

  • A. 光阻是加工用的暫時性膜。
  • B. 多晶矽具導電性，不會用作導線上方的絕緣覆蓋。
  • C. 正確。使用SiCN等介電質覆蓋膜。
