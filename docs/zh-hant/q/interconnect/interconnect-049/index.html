配線製程

沉積加入少量錳等的Cu合金，藉由熱處理使其在與絕緣膜的界面自然形成薄阻障層的技術，為下列何者？

  1. A自形成阻障層（self-forming barrier）
  2. BLOCOS
  3. C離子佈植
查看答案與解析

正確答案：A. 自形成阻障層（self-forming barrier）

使用Cu-Mn合金的晶種層時，熱處理會使Mn移動到界面，與絕緣膜的SiO2反應，自然形成厚度數nm以下的MnSiOx等阻障層。Mn聚集在界面，也使殘留Cu內部的雜質減少。由於不再需要另外沉積較厚的阻障金屬，可在細導線或導孔中增加低電阻Cu的比例，這也是日本研究團隊主導開發的技術之一。

  • A. 正確。是在界面自然形成阻障層的技術。
  • B. LOCOS是以選擇性氧化進行的元件隔離。
  • C. 離子佈植是植入雜質的製程。
