電腦網路基礎

下列關於動態路由的敘述，何者正確？

  1. A由管理者在各路由器上手動設定路由，發生故障時，在修改設定之前會持續使用相同的路由
  2. B路由器之間以路由協定交換路由資訊，當故障導致路由無法使用時，會自動切換到其他路徑
  3. C每個封包隨機選擇路徑，把負載平均分散到多條路徑上
查看答案與解析

正確答案：B. 路由器之間以路由協定交換路由資訊，當故障導致路由無法使用時，會自動切換到其他路徑

靜態路由是由管理者手動設定路由的方法。設定簡單、行為容易預測，適合小型網路或只有一個出口之據點的預設路由，但發生故障時不會自動切換。動態路由則由路由器以OSPF、BGP等路由協定交換資訊，自動建立路由表，鏈路斷線時會重新計算其他路徑。在網際網路上，組織網路（自治系統）之間的路由以BGP交換。實際的網路一般會將兩者組合使用。

  • A. 這是靜態路由的說明。
  • B. 正確。會配合故障自動重建路由表。
  • C. 動態路由的路徑也是依協定計算出的路由表決定，並非隨機。
