電腦網路基礎

快取中沒有任何資料的完整服務解析器（快取DNS伺服器），查詢 www.example.com 的IP位址時，詢問的順序下列何者正確？

  1. A根伺服器 → .com 的DNS伺服器 → example.com 的權威DNS伺服器
  2. Bexample.com 的權威DNS伺服器 → .com 的DNS伺服器 → 根伺服器
  3. C.com 的DNS伺服器 → 根伺服器 → www.example.com 的Web伺服器
查看答案與解析

正確答案：A. 根伺服器 → .com 的DNS伺服器 → example.com 的權威DNS伺服器

終端向網路服務供應商或公司內部的解析器查詢，再由解析器代替終端從上而下追溯網域名稱的階層。首先詢問根伺服器，得知管理 .com 的伺服器（頂級網域伺服器）；接著在那裡得知 example.com 的權威DNS伺服器；最後由權威DNS伺服器取得 www.example.com 的位址。得到的答案會在記錄所附的有效期間（TTL，與IP標頭的TTL不同）內被快取，第二次以後就能立即回答。因此即使變更了DNS設定，在舊答案的快取到期之前，仍可能使用先前的位址。

  • A. 正確。從階層上方依序追溯，每一步都被告知下一個詢問對象。
  • B. 階層要從上方（根）開始追溯。解析器一開始並不知道哪台是權威DNS伺服器。
  • C. 要從根開始。而且不會向Web伺服器查詢名稱。
