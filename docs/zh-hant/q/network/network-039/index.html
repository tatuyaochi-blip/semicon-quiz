電腦網路基礎

下列關於防火牆（封包過濾型）基本功能的敘述，何者正確？

  1. A把通訊內容加密，防止在途中的路徑上被竊聽
  2. B依據以來源與目的地IP位址、連接埠號碼等為基礎的規則，只讓允許的通訊通過，其餘一律阻擋
  3. C把收到的封包分配給多台伺服器，以分散處理負載
查看答案與解析

正確答案：B. 依據以來源與目的地IP位址、連接埠號碼等為基礎的規則，只讓允許的通訊通過，其餘一律阻擋

防火牆設置於公司內部網路與網際網路的邊界等處，依預先決定的規則允許或拒絕通訊。例如設定為「從外部只允許連到公開Web伺服器443號連接埠的通訊，其他從外部發起的連線一律拒絕」。現在多數的防火牆會進行記錄通訊狀態的狀態檢測（stateful inspection），自動放行從內側發起之通訊的回傳封包。防火牆不會加密，因此要保護通訊需與TLS或VPN搭配。此外，它無法阻擋經由允許之連接埠進來的攻擊（例如利用Web應用程式弱點的攻擊），因此也會搭配WAF等其他對策。

  • A. 加密是TLS或VPN的功能。
  • B. 正確。以位址與連接埠號碼的規則篩選通訊。
  • C. 這是負載平衡器的功能。
