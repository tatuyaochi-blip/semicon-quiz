電腦網路基礎

無線區域網路不採用有線乙太網路一直使用的CSMA/CD，而採用CSMA/CA的主要理由，下列何者正確？

  1. A在無線環境中，很難一邊傳送一邊接收其他終端的微弱電波來偵測碰撞，因此在傳送前先等待一段時間，盡量避免碰撞
  2. B無線比有線更快，即使發生碰撞對效能的影響也很小
  3. C在無線區域網路中，終端與存取點總是一對一通訊，不可能發生碰撞
查看答案與解析

正確答案：A. 在無線環境中，很難一邊傳送一邊接收其他終端的微弱電波來偵測碰撞，因此在傳送前先等待一段時間，盡量避免碰撞

CSMA/CD用於以集線器連接的早期乙太網路這類共用的有線媒介：傳送中偵測到碰撞就停止傳送，隨機等待一段時間後再重送。在無線環境中，自己送出的電波太強，很難同時接收遠處終端的微弱電波；而且彼此電波到達不了的終端（隱藏終端）之間的碰撞，傳送端也無從得知。因此CSMA/CA在確認頻道空閒後，還要再等待固定時間加上隨機的等待時間（退避）才傳送。接收端正確收到後回傳ACK，若沒有收到ACK，傳送端便視為發生碰撞等而重傳。附帶一提，現在以全雙工連接交換器的有線乙太網路不會發生碰撞，CSMA/CD實際上已不再使用。

  • A. 正確。因為無法偵測碰撞，所以事先避免，並以ACK確認送達。
  • B. 無線一般比有線慢，碰撞造成的損失反而是更大的問題。
  • C. 許多終端以同一個頻道共用一台存取點，因此可能發生碰撞。
