電腦網路基礎

在TCP的流量控制中，接收端向傳送端通知視窗大小（接收視窗）的目的，下列何者正確？

  1. A偵測網路壅塞，讓路徑上的路由器降低轉送速度
  2. B決定一個區段所傳送資料的最大長度，以避免在IP中分割
  3. C為了不讓接收端的緩衝區溢出，告知傳送端在不等待確認應答（ACK）的情況下可以傳送多少資料
查看答案與解析

正確答案：C. 為了不讓接收端的緩衝區溢出，告知傳送端在不等待確認應答（ACK）的情況下可以傳送多少資料

TCP的傳送端不必等待確認應答（ACK），就可以連續傳送多個區段。但若接收端的應用程式讀取資料較慢，接收緩衝區就會溢出。因此接收端每次回傳ACK時，都把緩衝區的剩餘空間以視窗大小告知，傳送端則讓尚未被確認的資料不超過這個量。剩餘空間變為0時，傳送端會等到有空間為止。這就是流量控制，是傳送端與接收端兩者之間的調整。配合網路壅塞改變傳送量的是另一個機制，即壅塞控制；一個區段的最大長度則在建立連線時以MSS告知。

  • A. 應對壅塞的是壅塞控制，由傳送端自行調整傳送量，並不是讓路由器降低速度。
  • B. 這是MSS（最大區段長度）的說明。
  • C. 正確。依接收緩衝區的剩餘空間限制傳送端的傳送量。
