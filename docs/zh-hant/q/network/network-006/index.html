電腦網路基礎

在一台L2交換器上設定VLAN，將連接埠1～4設為VLAN 10，連接埠5～8設為VLAN 20。下列關於其運作的敘述，何者正確？

  1. AVLAN 10與VLAN 20接在同一台交換器上，所以不需路由器就能直接通訊
  2. B把VLAN分成兩個後，每個連接埠的通訊速度都會減半
  3. CVLAN 10的設備送出的廣播不會到達VLAN 20的連接埠，VLAN 10與VLAN 20之間的通訊需要路由器（或L3交換器）
查看答案與解析

正確答案：C. VLAN 10的設備送出的廣播不會到達VLAN 20的連接埠，VLAN 10與VLAN 20之間的通訊需要路由器（或L3交換器）

VLAN（虛擬區域網路）是以交換器的連接埠等為單位，在實體上相同的設備上建立邏輯上各自獨立之網路的功能。每個VLAN的廣播可到達範圍（廣播網域）各自分開，交換器只在同一VLAN的連接埠之間轉送訊框。因此，像本例的VLAN 10與VLAN 20這樣不同VLAN之間的通訊，必須經過在第3層轉送的路由器或L3交換器。跨多台交換器使用VLAN時，會在訊框中加入IEEE 802.1Q所定義的標籤（VLAN ID），以區分訊框屬於哪個VLAN。VLAN可用來依部門劃分網路，或把訪客用的無線區域網路與公司內部網路隔開。

  • A. VLAN不同時交換器不會直接轉送，需要在第3層轉送。
  • B. VLAN是邏輯上的劃分，各連接埠的速度不變。
  • C. 正確。每個VLAN各自是一個廣播網域。
