矽晶圓

將晶圓外周倒角(斜角加工，bevel)，主要目的是哪一項？

  1. A防止搬運與製程中的崩缺(chipping)與破裂，並抑制外周處的膜隆起等
  2. B使晶圓變輕
  3. C改變晶圓的顏色
查看答案與解析

正確答案：A. 防止搬運與製程中的崩缺(chipping)與破裂，並抑制外周處的膜隆起等

晶圓的邊角若保持尖銳，搬運時接觸容易崩缺，崩缺的碎片會成為微粒，也會成為破裂的起點。將外周倒成圓角(斜角加工)可防止崩缺與破裂，也能抑制光阻與磊晶層在外周隆起(冠狀隆起，crown)。外周部分雖然不用於晶片，但容易成為膜剝落與微粒的來源，所以斜角部的清洗與膜的去除也很重要。
