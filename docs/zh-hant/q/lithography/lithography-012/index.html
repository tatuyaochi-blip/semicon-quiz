微影

關於掃描式曝光機的特徵，下列何者正確？

  1. A一次將整片晶圓全面曝光
  2. B不使用光罩，直接描繪
  3. C對狹縫狀的光，一邊讓光罩與晶圓同步移動一邊曝光
查看答案與解析

正確答案：C. 對狹縫狀的光，一邊讓光罩與晶圓同步移動一邊曝光

掃描機只讓光照射寬度數mm的狹縫狀區域，並使光罩與晶圓以4:1的速度比反向同步掃描，藉此曝光1個曝光區（26×33 mm）。這樣可以只使用透鏡像差較小的中央部分，也能曝光掃描方向上較長的區域，曝光區內的變異也會被平均化。載台以數m/s²的加速度移動，同時維持nm等級的精度。靜止並一次曝光的是步進機（stepper）。
