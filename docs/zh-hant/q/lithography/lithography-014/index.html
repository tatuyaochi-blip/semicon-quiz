微影

微影的一般製程順序，下列何者正確？

  1. A曝光 → 光阻塗佈 → 顯影 → 預烤
  2. B光阻塗佈 → 預烤 → 曝光 → 曝光後烘烤 → 顯影
  3. C顯影 → 曝光 → 光阻塗佈 → 蝕刻
查看答案與解析

正確答案：B. 光阻塗佈 → 預烤 → 曝光 → 曝光後烘烤 → 顯影

首先以HMDS處理提高附著性，塗佈抗反射膜與光阻，再以預烤（約100 ℃）蒸發溶劑。接著進行曝光，化學放大型光阻則以曝光後烘烤（PEB）推進反應。最後以鹼性顯影液顯影形成圖案，必要時再以後烤硬化。從塗佈到顯影，是在與曝光機連線的塗佈顯影機（coater/developer）中進行，並將溫度管控在±0.1 ℃左右。
