微影

以有機溶劑對正型化學放大光阻進行顯影，溶解未曝光部分的方法是下列何者？

  1. A正調顯影
  2. BEUV曝光
  3. C負調顯影（NTD）
查看答案與解析

正確答案：C. 負調顯影（NTD）

負調顯影是在使用正型化學放大光阻的情況下，以有機溶劑（乙酸丁酯等）的顯影液溶解未曝光的部分，讓曝光的部分留下來。對於細溝或小孔的圖案，光罩的明亮部分能減少（暗場）時，影像的對比會比較好，因此用於ArF浸潤式曝光的接觸孔與配線溝槽的形成等。光阻膨潤較少也是優點。
