類比與電子電路

下列哪一項是在反相放大電路的反相輸入端子上，經由電阻連接多個輸入之電路的正確功能？

  1. A輸出各輸入電壓的乘積
  2. B比較輸入電壓的大小
  3. C輸出各輸入電壓的加權和（符號反相）
查看答案與解析

正確答案：C. 輸出各輸入電壓的加權和（符號反相）

由於反相輸入端為虛接地，從各輸入經電阻流入的電流彼此互不影響地相加，流向回授電阻。結果為 Vout = −Rf(V1/R1 + V2/R2 + …)，可進行加權相加（反相加法電路）。用於音訊混音器、將電阻設為二進位權重（R、2R、4R…）的簡易DA轉換器，以及對感測器訊號加上偏移。
