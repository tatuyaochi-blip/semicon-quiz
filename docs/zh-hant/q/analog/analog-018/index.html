類比與電子電路

將電容串聯在訊號路徑中，並將電阻接在輸出與接地之間的RC電路，其特性下列哪一項正確？

  1. A衰減高頻，讓低頻通過
  2. B衰減低頻，讓高頻通過
  3. C所有頻率都同樣通過
查看答案與解析

正確答案：B. 衰減低頻，讓高頻通過

電容在頻率越低時阻抗越大，因此串聯後低頻較難通過，這個電路成為高通濾波器。截止頻率與低通相同，為 1/(2πRC)，低於此頻率時，頻率每降為1/10衰減 −20 dB。用於去除直流成分而只傳遞交流訊號的耦合電容，以及去除麥克風輸入的低頻雜訊。
