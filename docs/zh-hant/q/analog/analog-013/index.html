類比與電子電路

下列哪一項是運算放大器迴轉率的正確意義？

  1. A輸出電壓所能變化的最大速度
  2. B流入輸入端子的電流大小
  3. C輸出所含雜訊的大小
查看答案與解析

正確答案：A. 輸出電壓所能變化的最大速度

迴轉率是輸出電壓所能變化的最大速度，以V/µs表示。主要取決於以有限電流對內部相位補償電容充電的速度。能輸出振幅Vp的正弦波的最大頻率為 f = SR/(2πVp)，例如 SR = 0.5 V/µs、Vp = 10 V 時只能輸出約8 kHz，超過此頻率會失真成三角波狀。它與小訊號的頻寬（GBW）不同，是限制大振幅頻寬的因素。
