類比與電子電路

下列哪一項是運算放大器相位補償中所用「主極點補償」的正確想法？

  1. A將所有的極點集中在相同頻率
  2. B使增益在所有頻率下都為0 dB
  3. C將一個極點置於足夠低的頻率，在到達其他極點之前將增益降到1以下以求穩定
查看答案與解析

正確答案：C. 將一個極點置於足夠低的頻率，在到達其他極點之前將增益降到1以下以求穩定

在主極點補償中，加入電容將一個極點移到足夠低的頻率（數Hz〜數十Hz）。增益從該處起以 −20 dB/dec 下降，在其他極點使相位大幅轉動之前就低於0 dB，因此即使增益為1（隨耦器）也能得到足夠的相位餘裕。運算放大器利用米勒效應，以小電容製造低頻率的極點。代價是頻寬與迴轉率受到限制。

  • A. 將極點集中在同一頻率，相位會急遽轉動，反而變得不穩定。
  • B. 使增益在所有頻率下為0 dB，就無法作為放大器使用。
  • C. 正確。藉由主導極點提早降低增益以求穩定。
