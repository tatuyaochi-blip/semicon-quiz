類比與電子電路

用來高精度放大感測器微小差動訊號、由3個運算放大器等構成的放大器是哪一個？

  1. A功率放大器
  2. B儀表放大器（instrumentation amplifier）
  3. C積分電路
查看答案與解析

正確答案：B. 儀表放大器（instrumentation amplifier）

儀表放大器的結構是以輸入側的兩個運算放大器確保高輸入阻抗與增益，並以第3個差動放大去除共模成分，有些產品的CMRR超過100 dB。可精確放大如應變計電橋或心電圖電極這類疊加在大共模電壓上的微小差動訊號。增益可由1個外接電阻設定，電阻的匹配則在晶片內完成。
