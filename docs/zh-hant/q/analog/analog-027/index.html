類比與電子電路

輸入上升時與下降時的臨界值不同，可防止雜訊造成輸出抖動的電路是哪一個？

  1. APLL
  2. B取樣保持電路
  3. C史密特觸發器
查看答案與解析

正確答案：C. 史密特觸發器

史密特觸發器是將輸入上升時的臨界值設高、下降時設低，使其具有差值（遲滯）的電路。即使接收緩慢變化的訊號或含雜訊的訊號，也能防止輸出在臨界值附近反覆切換（彈跳）。它是對比較器施加正回授製成的，也有74HC14這類邏輯IC。也用於開關輸入的整形與RC振盪器（張弛振盪）。
