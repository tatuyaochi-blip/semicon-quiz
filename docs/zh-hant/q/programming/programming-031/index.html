程式設計基礎（虛擬碼追蹤）

以元素數為5的整數型陣列 st 與整數型變數 top 表示堆疊。st 的元素一開始全為0，top 從0開始。push(v) 先把 top 加1再執行 st[top] ← v，pop() 回傳 st[top] 的值後把 top 減1（不改變 st 的元素）。執行下列程式後 top 與 st 為下列何者？

push(5)
push(8)
pop()
push(3)
push(9)
pop()
push(7)
pop()
  1. Atop = 2, st = {5, 3, 0, 0, 0}
  2. Btop = 2, st = {5, 3, 7, 0, 0}
  3. Ctop = 5, st = {5, 8, 3, 9, 7}
查看答案與解析

正確答案：B. top = 2, st = {5, 3, 7, 0, 0}

push(5)、push(8) 使 st[1] = 5、st[2] = 8、top = 2，pop() 回傳8而 top = 1。push(3) 以3覆寫 st[2]，push(9) 使 st[3] = 9，pop() 使 top 回到2。push(7) 以7覆寫 st[3]，最後的 pop() 使 top = 2。pop() 只減少 top，因此取出的7仍留在 st[3]，st = {5, 3, 7, 0, 0}。堆疊中有效的內容是 st[1]〜st[top] 的5與3。

  • A. 這是以為 pop() 會把元素清為0時的內容。pop() 只減少 top。
  • B. 正確。top = 2，取出的7仍留在 st[3]。
  • C. 這是以為 pop() 不減少 top、每次 push 都加在後面時的內容。
