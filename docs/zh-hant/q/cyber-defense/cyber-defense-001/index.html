網路攻擊與防禦實務

洛克希德・馬丁公司於2011年提出的網路攻擊鏈（Cyber Kill Chain），把目標式攻擊的流程分為7個階段。階段的正確順序是下列何者？

  1. A遞送 → 偵察 → 武器化 → 漏洞利用 → 安裝 → C2（遠端操控） → 達成目標
  2. B偵察 → 武器化 → 遞送 → 漏洞利用 → 安裝 → C2（遠端操控） → 達成目標
  3. C偵察 → 遞送 → 武器化 → 安裝 → 漏洞利用 → 達成目標 → C2（遠端操控）
查看答案與解析

正確答案：B. 偵察 → 武器化 → 遞送 → 漏洞利用 → 安裝 → C2（遠端操控） → 達成目標

網路攻擊鏈以偵察（調查目標）、武器化（準備夾帶攻擊程式碼的檔案等）、遞送（以電子郵件附件或網站送達目標）、漏洞利用（利用弱點執行程式碼）、安裝（讓惡意程式常駐）、C2（建立與外部命令伺服器的通訊管道）、達成目標（竊取或破壞資訊）7個階段描述攻擊。防禦方依能在哪個階段切斷攻擊來安排對策，越早切斷，損害就越小。例如在電子郵件階段攔下可疑的附件，攻擊就在遞送階段結束。不過它不易表現內部不法行為，以及入侵後長期持續的活動，因此會與更細緻的MITRE ATT&CK搭配使用。

  • A. 沒有準備攻擊程式碼（武器化）就無法遞送。偵察與武器化在遞送之前。
  • B. 正確。依序是準備（偵察、武器化）、入侵（遞送、漏洞利用、安裝）、入侵後（C2、達成目標）。
  • C. 是在利用弱點執行程式碼（漏洞利用）之後，才讓惡意程式常駐（安裝）。此外，達成目標是最後一個階段。
