編譯器

關於交叉編譯器（cross compiler）的說明，下列何者正確？

  1. A將兩種程式語言混合成一個新語言的編譯器
  2. B產生與執行它的電腦不同的CPU所用之機器碼的編譯器
  3. C比較多個編譯器的輸出，並選出最快者的工具
查看答案與解析

正確答案：B. 產生與執行它的電腦不同的CPU所用之機器碼的編譯器

交叉編譯器是例如在x86的個人電腦上執行，卻產生面向Arm或RISC-V微控制器的機器碼的編譯器。在嵌入式裝置等情況下，若目標裝置的效能或記憶體不足以執行編譯器，它就不可或缺。所產生的機器碼，會寫入目標裝置，或在模擬該裝置的模擬器上執行來確認。它不是混合語言，也不是比較多個編譯器結果的工具。

  • A. 它不是混合語言的編譯器。
  • B. 正確。產生另一種CPU所用的機器碼。
  • C. 它不是比較結果的工具。
