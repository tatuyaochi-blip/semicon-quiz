編譯器

從C語言的程式到產生執行檔的一般流程，下列何者正確？

  1. A連結 → 編譯 → 組譯
  2. B組譯 → 連結 → 編譯
  3. C編譯 → 組譯 → 連結
查看答案與解析

正確答案：C. 編譯 → 組譯 → 連結

C語言的原始檔，首先由編譯器轉換為接近機器碼的組合語言（或直接轉成目的檔），再由組譯器變成機器碼的目的檔。最後由連結器將多個目的檔與函式庫彙整在一起，決定函式與變數的位址，產生執行檔。在目的檔的階段，位於其他檔案中的函式位址還沒有決定。若是其他順序，前一階段的輸出就無法成為下一階段的輸入。

  • A. 連結是最後的階段。
  • B. 組譯之前需要先編譯。
  • C. 正確。依編譯、組譯、連結的順序。
