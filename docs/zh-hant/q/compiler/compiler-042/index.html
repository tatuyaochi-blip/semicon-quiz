編譯器

在上方程式碼中，將 sq 行內展開之後接著生效的最佳化，以及其結果，下列何者正確？

static int sq(int v) { return v * v; }
int g(void) { return sq(6) + 1; }
  1. A藉由共同子運算式消除，g 會變成呼叫 sq 兩次
  2. B藉由常數摺疊，g 會變成只回傳 37 的程式碼
  3. C藉由迴圈展開，v * v 被替換為6次加法
查看答案與解析

正確答案：B. 藉由常數摺疊，g 會變成只回傳 37 的程式碼

將 sq 行內展開後，g 的內容會變成 return 6 * 6 + 1;，乘法的運算元全部成為常數。接著進行常數摺疊，就能算出 6 * 6 = 36、36 + 1 = 37，g 就變成只回傳37的程式碼。行內展開不僅能消除呼叫的開銷，也能像這樣使運用呼叫端的值的最佳化成為可能，這是它的一大優點。這裡沒有迴圈，也不會變成呼叫 sq 兩次。

  • A. 呼叫反而會消失。
  • B. 正確。展開後常數摺疊生效，只剩下37。
  • C. 這段程式碼中沒有迴圈。
