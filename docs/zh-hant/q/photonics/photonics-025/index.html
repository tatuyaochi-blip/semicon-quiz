矽光子

在光接收器中，緊接在光電二極體後方的轉阻放大器（TIA）的作用為何？

  1. A將電訊號轉換為光強度的變化，不經調變器直接送入光纖
  2. B將光電二極體輸出的微小電流，轉換為後級容易處理的電壓訊號並放大
  3. C提高施加在光電二極體的逆偏壓，藉累增倍增增加光本身以提高靈敏度
查看答案與解析

正確答案：B. 將光電二極體輸出的微小電流，轉換為後級容易處理的電壓訊號並放大

光電二極體會輸出與光強度相應的電流，但接收功率約0.1 mW時電流也只有約0.1 mA，直接使用無法由判定電路處理。TIA是將輸入電流轉換為電壓的放大器，輸出與回授電阻值相應大小的電壓。它必須兼顧數十 GHz的頻寬與低雜訊，且為了減小其間配線的電容，會放在光電二極體近旁。將電訊號轉換為光，是發射端驅動器與調變器的作用。
