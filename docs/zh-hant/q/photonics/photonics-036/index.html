矽光子

CPO中常考慮將雷射光源置於交換器IC的封裝外、僅以光纖供應光的外部雷射光源。其主要理由為何？

  1. A因為雷射在高溫下效率與壽命容易下降，要使其遠離發熱大的交換器IC，也便於更換
  2. B因為將雷射放在封裝外時，以光纖傳送光的耦合損耗會完全消失
  3. C因為矽調變器即使沒有雷射光，也能僅靠電訊號產生光
查看答案與解析

正確答案：A. 因為雷射在高溫下效率與壽命容易下降，要使其遠離發熱大的交換器IC，也便於更換

半導體雷射在溫度升高時閾值電流增加、效率下降，劣化也加快。CPO中光引擎放在消耗數百 W的交換器IC近旁，若將雷射放入封裝內，就得在嚴苛的溫度下運作。若採用外部雷射光源，就能在溫度相對較低的位置運作，也能從前面板等處插拔更換。代價是以光纖將雷射光導引至光引擎會增加耦合損耗，必須相應提高雷射輸出。調變器不會產生光。
