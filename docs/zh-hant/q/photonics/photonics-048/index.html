矽光子

量測矽波導傳播損耗的截斷法（cut-back法），其說明下列何者正確？

  1. A對1條波導輸入強光，由出口光的顏色（波長）變化求出傳播損耗
  2. B量測長度不同的波導損耗，由對長度的斜率求出傳播損耗，由外插至長度0求出耦合損耗
  3. C切斷波導並以電子顯微鏡觀察截面，僅由側壁粗糙的大小計算損耗
查看答案與解析

正確答案：B. 量測長度不同的波導損耗，由對長度的斜率求出傳播損耗，由外插至長度0求出耦合損耗

波導的入口與出口也會因與光纖耦合而產生損耗，因此僅量測1條波導的穿透，無法區分傳播損耗與耦合損耗。截斷法準備結構相同、僅長度不同的波導（例如1、2、4 cm），以dB量測整體損耗，並對長度作圖。直線斜率為每1 cm的傳播損耗（dB/cm），長度0處的值（截距）則為入口與出口耦合損耗的合計。統一耦合條件是精度的關鍵，常使用相同形狀的光柵耦合器在晶圓上量測。
