矽光子

波長1.55 µm、量子效率80%的光電二極體，其響應度（每1 W光所流過的電流）最接近下列何者（R [A/W] ≈ 量子效率 × λ [µm] / 1.24）？

  1. A約0.6 A/W
  2. B約1.5 A/W
  3. C約1.0 A/W
查看答案與解析

正確答案：C. 約1.0 A/W

響應度為 R ≈ η × λ / 1.24，0.8 × 1.55 / 1.24 ≈ 1.0 A/W。波長越長，單一光子的能量越小，因此同樣是1 W，波長越長光子數越多，在量子效率相同下流過的電流就越大。例如在1.31 µm、量子效率80%時約為0.85 A/W。即使量子效率為100%，1.55 µm的上限也約為1.25 A/W，因此約1.5 A/W（未除以1.24而是相乘所得的值）是不可能的。約0.6 A/W是把波長與1.24顛倒所得的值。
