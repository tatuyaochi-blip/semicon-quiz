矽光子

在跨機架等數 m以上的高速連接中，光纖比銅纜線或基板配線有利的主要理由為何？

  1. A因為光的傳播速度比銅線中的電訊號快10倍以上，延遲幾乎消失
  2. B因為光纖也導電，能在傳送訊號的同時向設備供電
  3. C因為光纖的損耗幾乎不受訊號速度影響，傳輸1 km也只有0.5 dB左右以下，很小
查看答案與解析

正確答案：C. 因為光纖的損耗幾乎不受訊號速度影響，傳輸1 km也只有0.5 dB左右以下，很小

在銅配線中，因集膚效應與介電損耗，訊號頻率越高損耗越大，速度越快能傳的距離就越短。為了補償而使用的等化器與重定時器（retimer）會增加功耗。另一方面，光纖的損耗幾乎與調變速度無關，單模光纖在1.31 µm約0.35 dB/km、在1.55 µm約0.2 dB/km，損耗小，而且細、輕，也不受電磁雜訊影響。電訊號在纜線或基板中也以光速的一半～8成左右傳播，與光纖中的光（光速的約3分之2）相差不大。
