矽光子

矽光子中，有時會將氮化矽（SiN）波導與矽波導搭配使用。SiN波導的特徵下列何者正確？

  1. A折射率約2.0，與周圍（SiO2）的差比矽小，容易降低傳播損耗及特性隨溫度的變化
  2. B折射率比矽大，能以更小的半徑急彎，使電路更加小型化
  3. C導電性良好，因此能輕易製作利用載子色散效應的高速調變器
查看答案與解析

正確答案：A. 折射率約2.0，與周圍（SiO2）的差比矽小，容易降低傳播損耗及特性隨溫度的變化

SiN的折射率約2.0，與SiO2的差比矽（約3.5）小，因此光的侷限較弱，彎曲半徑較大。相對地，側壁粗糙造成的散射小，容易製作低損耗的波導。熱光係數也小到只有矽的數分之1以下，適合用於耐溫度變化的濾波器等。由於能隙大，即使是強光也不易發生雙光子吸收，這也是優點。另一方面，SiN是絕緣體，無法製作利用載子色散效應的調變器。
