矽光子

資料中心用光收發器的CWDM（粗波長分波多工）中，例如以1271、1291、1311、1331 nm這樣20 nm的間隔排列波長。間隔取得較寬的主要理由為何？

  1. A因為波長間隔越寬，光纖的損耗與色散越小，不需放大器光就能傳得更遠
  2. B因為即使不進行將雷射溫度保持一定的控制，溫度造成的波長偏移也不易與相鄰波長重疊
  3. C因為間隔小於20 nm的多工器與解多工器在原理上無法製作
查看答案與解析

正確答案：B. 因為即使不進行將雷射溫度保持一定的控制，溫度造成的波長偏移也不易與相鄰波長重疊

半導體雷射的振盪波長會隨溫度改變，DFB雷射每1 ℃約偏移0.1 nm。溫度變化數十 ℃時會偏移數 nm，因此若間隔太窄就會與相鄰波長重疊。CWDM採取20 nm的寬間隔，使雷射不需以帕爾帖元件等進行溫度控制即可使用，成本低且功耗也小。另一方面，長距離通訊使用的DWDM以0.8 nm（100 GHz）等窄間隔排列多個波長，因此溫度控制不可或缺。加大間隔並不會使光纖損耗變小。
