矽光子

縮短微環共振器的周長時，下列變化何者正確？

  1. A相鄰共振波長的間隔（FSR）變寬
  2. B相鄰共振波長的間隔（FSR）變窄
  3. C不再發生共振，所有波長都會通過
查看答案與解析

正確答案：A. 相鄰共振波長的間隔（FSR）變寬

FSR（自由光譜範圍）是相鄰共振波長的間隔，大約可表示為 FSR ≈ λ² /(ng × L)（ng為群折射率，L為周長），與周長成反比。例如λ = 1.55 µm、ng ≈ 4.2、L ≈ 63 µm（半徑約10 µm）時，FSR約為9 nm。周長減半時FSR約變為2倍，在處理多個波長的WDM中，較容易避免1個環也對其他波長產生反應。不過，彎曲越急彎曲損耗越大，因此縮小有其極限。
