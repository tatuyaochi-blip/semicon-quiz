矽光子

連接光纖與矽光電路的光柵耦合器，其優點下列何者正確？

  1. A在寬廣的波長範圍內不受偏振影響，能以比邊緣耦合器更小的損耗與光纖耦合
  2. B研磨晶片端面，讓光纖從側面對接耦合，因此與光纖對準容易
  3. C可配置在晶片表面任何位置，能在晶圓狀態下從上方放置光纖量測光學特性
查看答案與解析

正確答案：C. 可配置在晶片表面任何位置，能在晶圓狀態下從上方放置光纖量測光學特性

光柵耦合器是在波導上製作週期性溝槽（繞射光柵），藉由繞射將光的方向轉為斜上方，與放在上方的光纖耦合。不需將波導拉到晶片邊緣，可在切割前以晶圓狀態量測，因此容易自動檢測大量晶片，這是一大優點。另一方面，由於繞射條件依賴波長與偏振，可耦合的頻寬僅數十 nm左右而偏窄，通常只能對應特定偏振，且損耗一般也比邊緣耦合器大。從端面耦合的是邊緣耦合器。
