機率、統計與等候理論

10張籤中有3張中獎籤。連續一張一張抽出2張，抽出的籤不放回。2張都中獎的機率為下列何者？

  1. A1/45
  2. B1/15
  3. C9/100
查看答案與解析

正確答案：B. 1/15

第1張中獎的機率為3/10。在第1張中獎的條件下，剩下的9張中有2張中獎籤，因此第2張中獎的條件機率為2/9。所以2張都中獎的機率為 3/10 × 2/9 = 6/90 = 1/15。以組合來思考，將從3張中獎籤選出2張的 C(3, 2) = 3種，除以從10張選出2張的 C(10, 2) = 45種，也得到 3/45 = 1/15。

  • A. 這是在從10張選出2張的45種中，把2張中獎籤的組合只算成1種的值。從3張中獎籤選出2張的組合有3種。
  • B. 正確。3/10 × 2/9 = 1/15。
  • C. 這是抽出的籤放回時的 (3/10)² = 9/100。不放回時，第2張中獎的機率會變為2/9。
