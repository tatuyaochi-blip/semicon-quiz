機率、統計與等候理論

從不良品比例為20%的製程中取出5個產品。各產品是否不良彼此獨立。5個之中恰有1個不良的機率最接近下列何者？

  1. A0.082
  2. B0.33
  3. C0.41
查看答案與解析

正確答案：C. 0.41

不良的個數服從 n = 5、p = 0.2 的二項分布。恰有1個不良的機率，是把從5個中選出哪一個不良的 C(5, 1) = 5種，乘以該1個不良且其餘4個為良品的機率 0.2 × 0.8⁴ = 0.08192，得到 5 × 0.08192 = 0.4096 ≈ 0.41。

  • A. 0.2 × 0.8⁴ ≈ 0.082 是只有特定1個為不良的機率。不良的是哪1個共有5種。
  • B. 0.8⁵ ≈ 0.33 是5個全部為良品的機率。
  • C. 正確。C(5, 1) × 0.2 × 0.8⁴ = 0.4096 ≈ 0.41。
