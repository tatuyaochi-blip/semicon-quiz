控制工程基礎

當初始值全為0時，時間函數的微分與積分在拉普拉斯轉換後的 s 域中所對應的運算，正確的組合是下列何者？

  1. A微分是乘以 s，積分是除以 s
  2. B微分是除以 s，積分是乘以 s
  3. C微分是加上 s，積分是減去 s
查看答案與解析

正確答案：A. 微分是乘以 s，積分是除以 s

在拉普拉斯轉換中，f(t) 的微分對應 sF(s) − f(0)，積分對應 F(s)/s。若初始值為0，微分就是乘以 s，積分就是除以 s，微分方程式因此變成 s 的多項式的運算。例如，RC電路的式子 RC·dv/dt + v = vin 變成 (RCs + 1)V(s) = Vin(s)，得到轉移函數 1/(1 + RCs)。單位步階函數轉換為 1/s，e^(−at) 轉換為 1/(s + a)。

  • A. 正確。因此積分元件寫成 1/s，微分元件寫成 s。
  • B. 相反了。乘以 s 是微分，除以 s 是積分。
  • C. 不是加法與減法，而是乘法與除法。
