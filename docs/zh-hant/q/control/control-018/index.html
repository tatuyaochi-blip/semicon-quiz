控制工程基礎

閉迴路系統的特性方程式如下時，穩定的系統為下列何者？

  1. As² + 3s + 2 = 0
  2. Bs² − 3s + 2 = 0
  3. Cs² + 4 = 0
查看答案與解析

正確答案：A. s² + 3s + 2 = 0

s² + 3s + 2 = (s + 1)(s + 2)，因此極點為 s = −1、−2，實部都是負的，所以穩定。s² − 3s + 2 = (s − 1)(s − 2) 的極點為 s = 1、2，響應呈指數增大，因此不穩定。s² + 4 = 0 的極點為 s = ±j2，角頻率2 rad/s的振盪不衰減而持續。對二階的特性方程式而言，係數全部同號且沒有缺項，是穩定的充分必要條件。

  • A. 正確。極點為 −1 與 −2。
  • B. 極點 s = 1、2 位於s平面的右半部，因此不穩定。
  • C. 極點位於虛軸上（±j2），會持續振盪。
