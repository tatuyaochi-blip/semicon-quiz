控制工程基礎

以近似式 ts ≈ 4/(ζωn) 估算轉移函數為 G(s) = 25/(s² + 4s + 25) 的系統，其步階響應進入終值±2%以內所需的安定時間，所得的值為下列何者？

  1. A0.5 s
  2. B0.8 s
  3. C2 s
查看答案與解析

正確答案：C. 2 s

這個系統 ωn = 5 rad/s、ζ = 0.4，因此 ζωn = 2 s⁻¹，ts ≈ 4/2 = 2 s。振盪的包絡線以 e^(−ζωn t) 縮小，而 e^(−4) ≈ 0.018 低於2%，這就是這個近似式的由來。±5%的安定時間則使用 ts ≈ 3/(ζωn)。由於是以包絡線估算，結果常比實際稍長；以數值計算這個系統，±2%的安定時間約為1.7 s。

  • A. 這是 1/(ζωn)，即包絡線的時間常數。要進入±2%以內，需要它的約4倍。
  • B. 這是 4/ωn，忘了乘上 ζ。
  • C. 正確。安定時間由極點的實部 ζωn 決定。
