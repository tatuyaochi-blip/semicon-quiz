硬體安全的進階主題與趨勢

假設有人會把晶片逐層削去並以電子顯微鏡拍攝，或以X射線拍攝內部，以讀取電路進行逆向工程時，適當的設計想法是下列何者？

  1. A遮罩式ROM的值與配線的形狀可能從影像中被讀出，因此私密金鑰不做進電路的形狀中，而是讓每台設備各不相同，並搭配實體對策保護
  2. B只要把電路的配置做得夠複雜，就無法從影像讀出電路，因此可以把所有設備共用的私密金鑰寫進遮罩式ROM
  3. CX射線拍不到晶片內部的電路，因此只要以堅硬的膜覆蓋晶片表面、使其無法被削層，就足以對抗逆向工程
查看答案與解析

正確答案：A. 遮罩式ROM的值與配線的形狀可能從影像中被讀出，因此私密金鑰不做進電路的形狀中，而是讓每台設備各不相同，並搭配實體對策保護

遮罩式ROM的值是以電晶體或接點的有無，做進電路的形狀之中，因此削層拍攝就能讀出。而且，以同一套光罩製造的所有晶片都含有相同的值，只要解析其中一顆，所有設備的機密就會洩漏。2020年代也有研究報告，以X射線拍攝能在不破壞晶片的情況下細緻地拍到內部配線。因此，機密不依賴電路的形狀，而是讓每台設備各不相同；對於像eFuse這樣寫入痕跡可能被看見的記憶，則以PUF產生的金鑰加密後存放等方式處理，並限制讀出路徑，再搭配抗竄改的對策。

  • A. 正確。不把機密寄託在電路形狀上，而以每台設備的金鑰與實體對策保護。
  • B. 即使配置複雜，只要投入時間與費用仍會被讀出。把機密寄託在隱藏形狀上很危險。
  • C. 已有研究顯示X射線也能拍攝內部結構，只把表面變硬並不足夠。
