硬體安全的進階主題與趨勢

以瞬間降低電源電壓的電壓突波使晶片發生錯誤動作的主要理由，正確的是下列何者？

  1. A電壓下降的瞬間，晶片內暫存器與記憶體中的所有資料都會清除為0，回到剛接上電源時的狀態
  2. B電壓下降時，晶片內部時脈振盪電路的頻率會自動升高，指令的執行也隨之加快
  3. C電壓下降時電晶體變慢，訊號無法在下一個時脈前到達正反器，於是取入錯誤的值
查看答案與解析

正確答案：C. 電壓下降時電晶體變慢，訊號無法在下一個時脈前到達正反器，於是取入錯誤的值

電源電壓下降時，電晶體能流過的電流減少，閘的延遲變大。當設計時確認過的「訊號在時脈週期內到達」這項時序條件（建立時間）無法滿足時，正反器就會取入錯誤的值。結果比較的結果可能改變，分支或指令可能被跳過，簽章確認因而可能被略過。在時脈中混入過短週期的時脈突波，也同樣會破壞時序條件而引發錯誤動作。

  • A. 一瞬間的電壓下降並不會清除所有資料。攻擊瞄準的是特定時間點的錯誤動作。
  • B. 電壓下降時時脈頻率不會升高。變慢的是電晶體。
  • C. 正確。時序條件被破壞是錯誤動作的原因。
