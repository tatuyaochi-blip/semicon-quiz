硬體安全的進階主題與趨勢

在機密運算所使用的TEE中，關於保護整個虛擬機器的VM型（AMD SEV-SNP、Intel TDX等）與保護應用程式一部分的飛地型（Intel SGX等）之差異的說明，正確的是下列何者？

  1. AVM型不加密虛擬機器的記憶體，只靠確認存取權限來保護，只有飛地型會加密記憶體
  2. BVM型幾乎可以直接執行既有的OS與應用程式，但整個客體OS會被納入必須信任的範圍（TCB）
  3. C飛地型連OS與超管理器也納入必須信任的範圍，而VM型只需要信任CPU
查看答案與解析

正確答案：B. VM型幾乎可以直接執行既有的OS與應用程式，但整個客體OS會被納入必須信任的範圍（TCB）

飛地型只把應用程式中處理機密的部分放在受保護的區域執行，因此必須信任的範圍（TCB：Trusted Computing Base）可縮小到CPU與飛地的程式碼，但必須把應用程式拆分改寫。VM型則加密整個虛擬機器的記憶體，使其不受超管理器與雲端管理員存取，因此既有軟體幾乎可以直接移植。相對地，客體OS及其上的所有軟體都會進入TCB，只要其中有漏洞，機密就可能洩漏。TCB越小越容易驗證，可被攻擊的面也越窄，因此要在易用性與信任範圍的大小之間權衡選擇。

  • A. VM型TEE也會由CPU以每個虛擬機器各自的金鑰加密虛擬機器的記憶體。
  • B. 正確。以較大的信任範圍換取移植的容易度。
  • C. 正好相反。飛地型不信任OS與超管理器，VM型則把客體OS納入信任範圍。
