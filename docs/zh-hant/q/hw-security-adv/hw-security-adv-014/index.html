硬體安全的進階主題與趨勢

「只要使用具ECC的記憶體，就不必擔心列鎚攻擊」這種想法的問題點，正確的是下列何者？

  1. A一般的ECC（SECDED）每個字組只能更正1位元的錯誤，許多位元翻轉時，可能既無法更正也無法偵測
  2. BECC只是讓資料讀取變慢的機制，本來就沒有更正記憶體中翻轉之位元的功能
  3. C為了放置ECC的檢查位元，列數會增加，被啟動之列的間隔變窄，使列鎚攻擊的發生機率變成2倍
查看答案與解析

正確答案：A. 一般的ECC（SECDED）每個字組只能更正1位元的錯誤，許多位元翻轉時，可能既無法更正也無法偵測

伺服器所用的SECDED方式ECC，在64位元的資料上附加8位元的檢查位元，能更正1位元錯誤，偵測2位元錯誤。列鎚攻擊有時會在同一個字組中翻轉3個以上的位元，此時可能察覺不到錯誤，或誤認為另一個值而錯誤地更正。ECC是能抑制許多翻轉的有效防護層，但必須與TRR或刷新管理等防止翻轉本身發生的對策搭配使用。

  • A. 正確。無法處理超過更正能力的翻轉數。
  • B. ECC能更正1位元的錯誤。其限制在於許多位元同時翻轉的情況。
  • C. 使用ECC並不會改變列鎚攻擊發生的難易度。
