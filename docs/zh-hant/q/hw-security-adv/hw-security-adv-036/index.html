硬體安全的進階主題與趨勢

在進行密碼處理的晶片中，掃描測試用的掃描鏈可能成為攻擊途徑的理由，與其對策的組合，正確的是下列何者？

  1. A在處理途中切換到測試模式，可能讀出與金鑰相關之暫存器的值。切換模式時清除機密，出貨後停用掃描或要求驗證
  2. B掃描鏈在運作中消耗大量電力，使功耗波形紊亂，功耗分析就無法進行。因此掃描鏈要盡量串得越長越好
  3. C掃描鏈只會增加晶片內部的配線，無法用來把晶片內部的資料讀到外部。因此不需要特別的對策
查看答案與解析

正確答案：A. 在處理途中切換到測試模式，可能讀出與金鑰相關之暫存器的值。切換模式時清除機密，出貨後停用掃描或要求驗證

掃描設計把晶片內部的正反器串接起來，使內部狀態能從外部設定與讀出。研究顯示，若能透過掃描讀出密碼電路的中間狀態，就能一面改變輸入一面比較中間值，進而推測出金鑰。因此要組合以下對策：切換到測試模式時重設金鑰等暫存器、把金鑰暫存器從掃描鏈中移除、打亂掃描輸出，以及在出貨時以eFuse停用掃描，或只在通過驗證時才能使用。測試的容易度與機密的保護是互相衝突的，因此要在設計的早期階段同時考慮兩者。

  • A. 正確。不讓測試用的讀出路徑被用來讀出機密。
  • B. 掃描鏈不是防止功耗分析的機制，加長也不構成對策。
  • C. 掃描鏈本身正是用來讀出內部狀態的機制。
