硬體安全的進階主題與趨勢

將安全晶片的生命週期狀態分為測試、正式量產（production）、退貨故障解析（RMA）等來管理。從正式量產狀態移到RMA狀態以進行故障解析時，適當的處理是下列何者？

  1. A為了方便解析，在保留正式量產時使用的金鑰與使用者資料的情況下，開啟所有測試與除錯功能
  2. B先清除或停用正式量產時使用的金鑰等機密，再開啟解析用的功能，並使其無法回到正式量產狀態
  3. C移到RMA狀態的晶片，在解析結束後立即回到正式量產狀態，以便當作新品再次出貨
查看答案與解析

正確答案：B. 先清除或停用正式量產時使用的金鑰等機密，再開啟解析用的功能，並使其無法回到正式量產狀態

故障解析需要開啟強大的測試與除錯功能，但若直接開啟，正式量產時使用的金鑰與使用者資料可能被讀出。因此，在移到RMA狀態的程序中，先清除正式量產的機密，或切斷使用它們的路徑，之後才能使用解析功能。若把狀態轉換記錄在OTP或eFuse中使其成為單向，並使其無法從RMA狀態回到正式量產，為解析而開啟的晶片就不會再次流入市面。OpenTitan等公開的信任根設計，也規定了這類生命週期狀態的管理。

  • A. 在保留機密的情況下開啟除錯功能，金鑰與使用者資料可能被讀出。
  • B. 正確。先清除機密再開啟解析功能，並使其無法回復。
  • C. 若把為解析而開啟功能的晶片回到正式量產，就無法保證安全。
