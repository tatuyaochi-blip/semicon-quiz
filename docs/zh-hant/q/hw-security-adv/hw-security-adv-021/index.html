硬體安全的進階主題與趨勢

ML-KEM-768的公開金鑰為1,184位元組、密文為1,088位元組，而橢圓曲線金鑰交換X25519的公開值為32位元組。ML-KEM-768的公開金鑰是X25519公開值的幾倍，正確的是下列何者？

  1. A37倍
  2. B71倍
  3. C296倍
查看答案與解析

正確答案：A. 37倍

1,184 ÷ 32 = 37，因此是37倍。金鑰交換時還要傳送1,088位元組的密文，比起互相傳送32位元組公開值的橢圓曲線金鑰交換，交換的資料量大得多。在IC卡或小型微控制器上，必須重新檢視存放金鑰與中間值的RAM與緩衝區大小、一次能傳送之資料大小的上限等，會影響硬體設計。在簽章方面，ML-DSA-65的簽章也有3,309位元組，遠大於橢圓曲線的簽章。

  • A. 正確。1,184 ÷ 32 = 37。
  • B. 這是把公開金鑰與密文相加的 (1,184 + 1,088) ÷ 32 = 71，不是只有公開金鑰的比值。
  • C. 這是把1,184位元組換算成位元的9,472，再除以仍以位元組計的32所得的值。
