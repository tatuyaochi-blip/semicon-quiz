硬體安全的進階主題與趨勢

DRAM越微縮，越容易發生列鎚攻擊（Rowhammer）的理由，正確的是下列何者？

  1. A微縮後就不需要刷新，記憶胞的電荷一次也沒有補充，就經過很長的時間
  2. B記憶胞之間的間隔變窄，記憶胞儲存的電荷也變少，容易受到相鄰列啟動所造成之干擾的影響
  3. C微縮後的DRAM在規格上禁止多次啟動同一列，違反這個限制就會發生錯誤動作
查看答案與解析

正確答案：B. 記憶胞之間的間隔變窄，記憶胞儲存的電荷也變少，容易受到相鄰列啟動所造成之干擾的影響

每次啟動一列時，字元線的電位會大幅擺動，使附近列中記憶胞的電荷容易流失。微縮使記憶胞之間的距離縮短，干擾就會增強；同時記憶胞的電容變小，位元翻轉之前的餘裕也變小。研究報告指出，越新世代的DRAM，發生第一次位元翻轉所需的啟動次數有越少的傾向。因此，DRAM的世代越進步，列鎚攻擊的對策就越重要。

  • A. 微縮後仍需要刷新，保持資料的餘裕反而變小。
  • B. 正確。干擾增強與餘裕變小兩者都有影響。
  • C. 反覆啟動同一列本身，是正常運作所允許的。
