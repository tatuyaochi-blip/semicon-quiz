硬體安全的進階主題與趨勢

某種故障注入嘗試每次成功的機率為0.1%，各次結果互相獨立。嘗試1,000次時，至少成功1次的機率最接近下列何者？

  1. A約0.1%
  2. B約63%
  3. C100%
查看答案與解析

正確答案：B. 約63%

一次都沒有成功的機率為 (1 − 0.001)¹⁰⁰⁰ ≈ e⁻¹ ≈ 0.368，因此至少成功1次的機率為 1 − 0.368 ≈ 0.632，約63%。即使每次的成功率很低，能自動嘗試數千次的攻擊，成功的可能性也相當高。因此對策除了降低每次的成功率之外，還要組合偵測到幾次異常就清除金鑰、計數並限制嘗試次數等機制。單純計算 0.1% × 1,000 = 100%，是把成功多次的情況重複計算的錯誤。

  • A. 這是只嘗試1次時的機率。
  • B. 正確。1 − 0.999¹⁰⁰⁰ ≈ 63%。
  • C. 這是單純相乘 0.1% × 1,000 的值，作為機率計算是錯誤的。
