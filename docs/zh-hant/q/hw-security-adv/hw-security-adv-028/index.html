硬體安全的進階主題與趨勢

把多家公司的小晶片組合在1個封裝中時，關於安全性的想法，適當的是下列何者？

  1. A同一封裝內的小晶片全都可以無條件信任，因此小晶片之間的通訊不需要特別保護
  2. B小晶片之間的通訊不會離開封裝，因此在組裝或流通過程中，沒有被換成偽造小晶片的疑慮
  3. C以驗證或證明確認各小晶片是真品且以正確的韌體運作，必要時也保護晶粒之間的通訊
查看答案與解析

正確答案：C. 以驗證或證明確認各小晶片是真品且以正確的韌體運作，必要時也保護晶粒之間的通訊

在單一晶片中，過去一般是由一家公司設計所有電路，並在同一座工廠製造。小晶片則是組合由不同公司設計、在不同工廠製造的晶粒，因此必須考慮其中某個晶粒可能是偽造品，或含有硬體木馬。因此，正在研議的方法包括由具有信任根的晶粒確認其他晶粒的識別資訊與量測值，以及在晶粒之間的連結上使用加密與竄改偵測等。封裝的組裝製程與測試用的連接埠，也要加以管理，避免成為攻擊的入口。

  • A. 由於組合了不同供應來源的晶粒，無條件信任的前提很難成立。
  • B. 在組裝或流通階段，有被換成偽造晶粒的疑慮。
  • C. 正確。即使在封裝內，也要逐一確認各晶粒是否可信。
