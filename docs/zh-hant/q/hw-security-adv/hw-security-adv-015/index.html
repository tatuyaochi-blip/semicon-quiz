硬體安全的進階主題與趨勢

在2024年更新的DDR5規格（JESD79-5C）中加入的PRAC（逐列啟動計數），其想法正確的是下列何者？

  1. A記憶體控制器不再計數啟動次數，DRAM內部的刷新也全部由外部控制器逐列下令執行
  2. BDRAM逐列計數啟動次數，若有列超過門檻值就通知控制器，取得刷新相鄰列的時間
  3. C被啟動超過規定次數的列，由DRAM永久停用，並以製造時準備的備用列取代
查看答案與解析

正確答案：B. DRAM逐列計數啟動次數，若有列超過門檻值就通知控制器，取得刷新相鄰列的時間

過去的對策是由DRAM內部的TRR只追蹤少數列，或像DDR5的RFM那樣，由記憶體控制器計數每個記憶庫的啟動次數，再給DRAM額外的時間。PRAC則由DRAM為每一列保有計數器，每次啟動都計數該列的次數，因此不會因能追蹤之列數的限制而漏掉。次數超過門檻值時，DRAM通知控制器暫停存取一段時間，並刷新被鎖定之列的周圍。據說為了更新計數器，關閉一列所需的時間等時序規定會變長，需要與效能權衡。

  • A. PRAC是在DRAM內部逐列計數的機制，並不是全部刷新都由外部下令的機制。
  • B. 正確。逐列正確計數，並在必要時要求對策所需的時間。
  • C. 不是停用該列，而是刷新相鄰列來防止翻轉。
