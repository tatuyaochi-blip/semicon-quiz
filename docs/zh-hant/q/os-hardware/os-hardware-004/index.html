作業系統與硬體

關於中斷與例外的差異，下列何者是一般的說明？

  1. A中斷只由軟體引發，例外只由硬體電路引發
  2. B中斷由裝置等外部因素引發，例外則是指令執行的結果所引發
  3. C中斷處理後無法返回原處，例外則一定能返回原本的處理
查看答案與解析

正確答案：B. 中斷由裝置等外部因素引發，例外則是指令執行的結果所引發

中斷是由輸入輸出裝置的完成通知或計時器等，與執行中指令無關的外部因素所引發，何時發生並不固定（非同步）。例外則是除以零、非法指令、分頁錯誤（page fault）、系統呼叫指令等，因執行特定指令的結果而發生（同步）。兩者多半都能在中斷處理常式處理完後返回原本的處理，並非以能否返回來區分。

  • A. 以軟體與硬體來區分發生來源的說明並不正確。
  • B. 正確。中斷是外部因素造成的非同步事件，例外是指令結果造成的同步事件。
  • C. 兩者多半都能在處理後返回原處，並不以能否返回來區別。
