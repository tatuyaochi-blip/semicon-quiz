作業系統與硬體

關於RISC-V特權架構所規定的主要運作模式組合，下列何者正確？

  1. A機器模式、監督者模式、使用者模式
  2. B真實模式、保護模式、長模式
  3. C位址模式、資料模式、指令模式
查看答案與解析

正確答案：A. 機器模式、監督者模式、使用者模式

RISC-V的特權架構規定了特權最高的機器模式（M）、執行作業系統核心的監督者模式（S），以及執行應用程式的使用者模式（U）。機器模式一定會實作，剛通電時及韌體都在此模式下運作。小型微控制器只有M與U，執行作業系統時一般則具備M、S、U，在虛擬化擴充中還會加入虛擬機器監視器用的模式。真實、保護、長模式是x86的用語。

  • A. 正確。M、S、U三種模式。
  • B. 這是x86運作模式的用語。
  • C. 並沒有這樣的模式劃分。
