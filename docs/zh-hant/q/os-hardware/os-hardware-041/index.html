作業系統與硬體

分頁大小為4 KB時，虛擬位址中表示分頁內位置（位移，offset）的是幾個位元？

  1. A4位元
  2. B12位元
  3. C22位元
查看答案與解析

正確答案：B. 12位元

4 KB = 4096位元組 = 2¹²位元組，因此要區分分頁內的每個位元組需要12位元。虛擬位址的低12位元會直接當作分頁內的位置，用於實體位址，其餘的高位元則作為分頁編號，由頁表或TLB進行轉換。4位元是被「4 KB」的4所誤導的錯誤，22位元則是4 MB分頁時的值。低12位元不經轉換這一點，也被運用在快取的設計上。

  • A. 4位元只能區分16位元組。
  • B. 正確。4096 = 2¹²，所以是12位元。
  • C. 22位元是4 MB分頁時的值。
