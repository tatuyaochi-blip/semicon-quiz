作業系統與硬體

CPU接受中斷時，一般的處理流程為下列何者？

  1. A捨棄執行中的程式，從頭重新執行
  2. B執行中斷處理常式後，不回到原本的程式，而是開始執行下一個程式
  3. C儲存執行中的位置與狀態，執行中斷處理常式後，再回到儲存的位置
查看答案與解析

正確答案：C. 儲存執行中的位置與狀態，執行中斷處理常式後，再回到儲存的位置

接受中斷後，CPU會儲存原本接著要執行的指令位址與運作模式等狀態，並跳到由中斷向量表等所決定的中斷處理常式。處理常式會視需要儲存暫存器並進行處理，結束後還原狀態，從中斷的位置繼續執行原本的程式。不會捨棄程式，也不會從頭重來。處理常式結束後有時會切換到其他行程，但那是作業系統的判斷。

  • A. 不會捨棄程式。
  • B. 基本上會回到原處。是否切換則由作業系統判斷。
  • C. 正確。儲存狀態、執行處理常式後再返回原處。
