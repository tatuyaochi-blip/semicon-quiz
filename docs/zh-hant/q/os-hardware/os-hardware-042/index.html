作業系統與硬體

分頁大小為4 KB時，32位元虛擬位址0x00403ABC的分頁編號與分頁內位移的組合，下列何者正確？

  1. A分頁編號0x00403、位移0xABC0
  2. B分頁編號0x004、位移0x03ABC
  3. C分頁編號0x00403、位移0xABC
查看答案與解析

正確答案：C. 分頁編號0x00403、位移0xABC

分頁大小4 KB = 2¹²，所以低12位元（十六進位的末3位數）為位移，其餘的高20位元（前5位數）為分頁編號。將0x00403ABC拆開，分頁編號為0x00403，位移為0xABC。以頁表將0x00403轉換為實體分頁編號，再接上0xABC，即成為實體位址。若以末4位或末5位數當作位移，是把分頁大小誤認為64 KB或1 MB的切法。

  • A. 位移的0xABC0位數錯位了。
  • B. 以末5位數為位移，是1 MB分頁時的情況。
  • C. 正確。末3位數0xABC是位移，前5位數0x00403是分頁編號。
