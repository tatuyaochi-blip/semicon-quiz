作業系統與硬體

在重要處理的過程中暫時停用（遮罩）中斷時，下列何者是正確的注意事項？

  1. A停用的時間過長會延遲對其他中斷的回應，因此要盡可能縮短
  2. B一旦停用中斷，送達的中斷全部都會遺失，永遠不會被處理
  3. C一旦停用中斷，CPU的耗電量會大幅增加，因此不可使用
查看答案與解析

正確答案：A. 停用的時間過長會延遲對其他中斷的回應，因此要盡可能縮短

停用中斷後，雖然共用資料的更新不會被中途打斷，但這段期間送達的中斷必須等待。停用的時間若太長，通訊接收或計時器的處理就會延遲，造成資料遺漏或回應變慢，因此停用的區間要盡可能縮短。送達的中斷多半會被保留，待解除停用後再處理，並不會全部遺失。耗電量也不會大幅增加。

  • A. 正確。為了避免回應延遲，要縮短停用的區間。
  • B. 多半情況下中斷會被保留，並在解除後處理。
  • C. 停用中斷並不會使耗電量大幅增加。
