作業系統與硬體

因實體記憶體不足，持續不斷地換出與載入分頁，導致處理幾乎無法進行的狀態稱為什麼？

  1. A死結（deadlock）
  2. B快取一致性（cache coherency）
  3. C抖動（thrashing）
查看答案與解析

正確答案：C. 抖動（thrashing）

當同時運作的行程所使用的分頁總和（工作集，working set）大於實體記憶體時，每次載入需要的分頁，就會換出其他行程使用的分頁，而那些分頁很快又會被需要，如此不斷重複。時間幾乎都花在等待磁碟讀寫，CPU的使用率也會下降。這就是抖動，減少執行的行程或增加記憶體即可解決。死結則是彼此等待對方的資源而停住的狀態。

  • A. 死結是彼此等待資源而停住的狀態。
  • B. 快取一致性是快取內容一致性的問題。
  • C. 正確。這是因記憶體不足而持續置換分頁的狀態。
