作業系統與硬體

在分頁置換使用FIFO方式時，即使增加了實體記憶體的分頁數，分頁錯誤有時反而會增加。這種現象稱為什麼？

  1. A抖動（thrashing）
  2. B貝萊迪異常（Belady's anomaly）
  3. C寫入時複製（copy-on-write）
查看答案與解析

正確答案：B. 貝萊迪異常（Belady's anomaly）

直覺上增加實體分頁應該會讓分頁錯誤減少，但已知在FIFO方式中，對於特定的存取序列，將分頁數從3增加到4，錯誤反而會增加。這稱為貝萊迪異常。像LRU這類即使增加分頁數，保留的分頁集合也必定包含先前集合的方式（堆疊演算法），則不會發生。抖動是因記憶體不足而持續置換的狀態，寫入時複製則是寫入時才複製的方式。

  • A. 抖動是因記憶體不足而持續置換的狀態。
  • B. 正確。這是在FIFO中增加分頁反而使錯誤增加的現象。
  • C. 寫入時複製是在寫入時才複製的方式。
