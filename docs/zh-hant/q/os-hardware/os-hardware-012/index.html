作業系統與硬體

存取已被換出到磁碟的分頁而發生分頁錯誤時，作業系統的處理流程為下列何者？

  1. A立即讓程式異常終止，不載入分頁
  2. B載入分頁後，跳過引發錯誤的指令，從下一個指令繼續執行
  3. C準備好分頁並從磁碟載入，更新頁表後重新執行指令
查看答案與解析

正確答案：C. 準備好分頁並從磁碟載入，更新頁表後重新執行指令

對於合法存取所造成的分頁錯誤，作業系統會尋找空閒的實體分頁（若沒有則換出其他分頁），從磁碟載入內容，並使頁表項目生效。接著從頭重新執行引發錯誤的指令，因此程式會若無其事地繼續執行。若跳過指令，該次存取就不會執行，結果會出錯。會讓程式異常終止的，是對未配置的位址進行非法存取的情況。

  • A. 合法的存取不會異常終止，而是準備好分頁。
  • B. 跳過指令會使存取沒有執行，導致結果錯誤。
  • C. 正確。準備好分頁、更新頁表後重新執行指令。
