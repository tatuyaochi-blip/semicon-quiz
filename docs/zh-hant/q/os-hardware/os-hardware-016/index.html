作業系統與硬體

關於頁表的各個項目中通常包含的資訊組合，下列何者正確？

  1. A實體分頁編號，以及有效、保護、參照與修改位元
  2. B該分頁的資料內容本身，以及最後寫入的時間
  3. C使用該分頁的行程名稱，以及使用時間的總計
查看答案與解析

正確答案：A. 實體分頁編號，以及有效、保護、參照與修改位元

頁表的項目中，除了對應的實體分頁編號外，還包含：表示該分頁是否在實體記憶體中的有效位元；讀寫、執行及使用者模式存取的許可；以及由硬體設定的已存取（參照）位元與已修改（dirty）位元。作業系統依據參照位元判斷分頁置換，並依據dirty位元判斷換出時是否需要寫回。資料內容與行程名稱不會放在其中。

  • A. 正確。包含實體分頁編號，以及保護與狀態位元。
  • B. 資料內容存在分頁本身，不會放在表中。
  • C. 行程名稱與使用時間由其他地方管理。
