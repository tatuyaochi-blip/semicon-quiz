作業系統與硬體

許多作業系統會將核心的區域配置在各行程位址空間的一部分（例如高位範圍），並以頁表的保護位元禁止使用者模式存取。這種配置的主要優點為何？

  1. A進入核心時，不需要切換位址空間
  2. B應用程式可以不經系統呼叫，直接呼叫核心的函式
  3. C各行程可以任意改寫並共用核心的記憶體
查看答案與解析

正確答案：A. 進入核心時，不需要切換位址空間

若將核心以相同方式配置在各行程的位址空間中，那麼在因系統呼叫或中斷而進入核心時，不必切換頁表就能直接存取核心的程式碼與資料，也不需要清空TLB。由於使用者模式的存取已被頁表的保護位元所禁止，應用程式無法直接呼叫核心的函式，也無法改寫核心的記憶體。這項保護一旦被突破，就會成為嚴重的漏洞。

  • A. 正確。進入核心時不需要切換位址空間。
  • B. 因為被保護位元禁止，所以無法直接呼叫。
  • C. 使用者模式無法改寫。
