作業系統與硬體

CPU不使用中斷而是反覆檢查裝置狀態的方式（輪詢，polling），在下列哪種情況較有利？

  1. A處理的發生頻率非常高，每次中斷所需的切換負擔很大時
  2. B處理的發生極為罕見，且希望把CPU用在其他工作時
  3. C為了盡量降低耗電量，希望讓CPU長時間休眠時
查看答案與解析

正確答案：A. 處理的發生頻率非常高，每次中斷所需的切換負擔很大時

當處理很罕見時，中斷可以讓CPU不被浪費，但每一次都有儲存狀態與跳到處理常式的負擔。若像高速網路那樣處理極為頻繁，中斷的負擔會累積而來不及處理，因此集中輪詢反而更有效率。處理罕見的情況，或想讓CPU休眠以降低功耗時，空轉持續檢查的輪詢十分浪費，較適合使用中斷。

  • A. 正確。處理頻繁時，輪詢比中斷的負擔更有效率。
  • B. 處理罕見時，輪詢會浪費CPU。
  • C. 持續檢查的輪詢無法讓CPU休眠，會增加耗電。
