蝕刻

偵測到蝕刻終點之後，為了確實去除晶圓整面的膜而再持續蝕刻一段時間，這稱為什麼？

  1. A過蝕刻
  2. B灰化
  3. C沉積
查看答案與解析

正確答案：A. 過蝕刻

由於晶圓面內蝕刻速率與膜厚的變異，以及殘留在段差側壁的膜等原因，即使在偵測到終點的時間點，部分區域仍可能殘留著膜。因此會進行例如主蝕刻時間約20～50%的過蝕刻，以確實去除。在此期間露出的底層會持續被蝕刻，所以一般會切換為對底層具有高選擇比的條件。

這個領域的比較

  • 濕式蝕刻與乾式蝕刻的差異：方向性、選擇比、用途比較從介質、方向性、選擇比、微細化、產能、損傷、成本與使用的製程等面向，以表格比較濕式蝕刻與乾式蝕刻。
  • RIE、ICP-RIE 與 ALE 的差異：壓力、電漿密度、離子能量、精度比較從電漿的產生方式、壓力、電漿密度、離子能量的控制、蝕刻速率、損傷、深度精度與用途等面向，以表格比較電容耦合電漿式 RIE、ICP-RIE 與原子層蝕刻（ALE），並說明各自適用的時機。
  • CCP 與 ICP 的差異：電漿產生方式、密度、離子能量、用途比較從電極與線圈、電漿密度、離子能量的獨立控制、壓力、蝕刻用途（氧化膜與 Si、金屬）、電漿 CVD 等成膜應用等面向，以表格比較電容耦合電漿（CCP）與感應耦合電漿（ICP）。
