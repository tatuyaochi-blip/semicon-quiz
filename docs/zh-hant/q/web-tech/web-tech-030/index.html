Web技術基礎

在內容因使用者而異的「我的頁面」回應中，加上Cache-Control: private, max-age=60。這項設定的效果，下列何者正確？

  1. A只有CDN這類共用快取在60秒內重複使用，使用者瀏覽器的快取不會保存
  2. B瀏覽器的快取可在60秒內直接重複使用，但CDN或代理伺服器這類共用快取不會保存
  3. C不保存在任何快取中，連瀏覽器每次都要重新向伺服器取得
查看答案與解析

正確答案：B. 瀏覽器的快取可在60秒內直接重複使用，但CDN或代理伺服器這類共用快取不會保存

瀏覽器的快取只供一位使用者使用，CDN或代理伺服器的快取則由許多使用者共用。private表示該回應不可保存在共用快取中，max-age=60表示保存後60秒內可以不向伺服器確認就使用。若每位使用者專屬的網頁被保存在CDN中，就會導致其他使用者看到別人資訊的事故。完全不讓保存時使用no-store，可以保存但每次使用都要向伺服器確認時使用no-cache。

  • A. private是不讓共用快取保存的設定，能保存的是使用者瀏覽器的快取。
  • B. 正確。瀏覽器在60秒內可不向伺服器確認就使用，但共用快取不會保存。
  • C. 完全不讓保存的設定是no-store。若為private，瀏覽器的快取會保存。
