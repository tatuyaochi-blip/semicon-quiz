雙載子電晶體

將開關用電晶體從深度飽和狀態關閉時，直到關閉為止需要花時間，其主要理由是哪一個？

  1. A因為電晶體的溫度下降
  2. B因為接面電容變為0
  3. C因為要花時間移除儲存在基極區域的過量少數載子
查看答案與解析

正確答案：C. 因為要花時間移除儲存在基極區域的過量少數載子

在飽和狀態下，基極-集極接面也呈順向偏壓，基極與集極會儲存超過需要的少數載子。即使想要關閉，在這些載子被抽出或復合之前，集極電流仍會持續流動（儲存時間ts）。對策包括：以蕭特基二極體箝位以防止深度飽和、對基極施加反向電流以迅速抽出電荷（加速電容等）、避免基極過度驅動。
