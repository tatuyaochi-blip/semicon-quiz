雙載子電晶體

NPN電晶體用於放大（在主動區工作）時，正確的偏壓條件是哪一個？

  1. A基極-射極間為順向偏壓，基極-集極間為逆向偏壓
  2. B基極-射極間為逆向偏壓，基極-集極間為順向偏壓
  3. C基極-射極間與基極-集極間皆為順向偏壓
查看答案與解析

正確答案：A. 基極-射極間為順向偏壓，基極-集極間為逆向偏壓

在主動區，基極-射極接面為順向偏壓，使電子從射極注入基極；基極-集極接面為逆向偏壓，以強電場將穿過基極的電子拉往集極。集極電流幾乎不受集極電壓影響，而是由基極電流（或VBE）決定，因此可以放大。若兩者皆為順向偏壓，則為飽和區（開關導通）；若兩者皆為逆向偏壓，則為截止區（關閉）。
