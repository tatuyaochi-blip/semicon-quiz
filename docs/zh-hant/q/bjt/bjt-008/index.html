雙載子電晶體

關於雙極性電晶體的厄利效應（Early effect），下列說明何者正確？

  1. A溫度上升時電流增益下降的效應
  2. B集極-基極間的逆向偏壓增大時，有效基極寬度變窄，集極電流增加的效應
  3. C照射光線時基極電流流動的效應
查看答案與解析

正確答案：B. 集極-基極間的逆向偏壓增大時，有效基極寬度變窄，集極電流增加的效應

提高集極電壓時，集極-基極接面的空乏區也會向基極側延伸，使有效基極寬度變窄。如此一來少數載子的濃度梯度變陡，集極電流略為增加。這就是厄利效應，將輸出特性曲線向左延長，會在電壓軸上的一點（−VA，厄利電壓）相交。VA愈大，輸出電阻 ro = VA/IC 愈大，放大電路的最大增益 gm·ro = VA/VT 也愈高。
