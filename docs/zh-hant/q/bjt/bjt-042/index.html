雙載子電晶體

在電晶體放大電路的輸出特性圖上畫的「負載線」，其所表示的內容下列何者正確？

  1. A電晶體的最大額定值
  2. B溫度與集極電流的關係
  3. C由負載電阻與電源電壓決定的、VCE與IC可能的組合
查看答案與解析

正確答案：C. 由負載電阻與電源電壓決定的、VCE與IC可能的組合

當集極側有電阻RC與電源VCC時，VCE = VCC − IC × RC 成立，將這條直線畫在輸出特性上就是負載線。兩端為：IC = 0 時 VCE = VCC（截止），VCE = 0 時 IC = VCC/RC（飽和）。負載線與IB曲線的交點就是工作點，加入訊號後會在這條線上移動。若另有交流負載，則要考慮直流與交流斜率不同的兩條負載線。

  • A. 最大額定值以損耗曲線等表示，與負載線不同。
  • B. 負載線不表示與溫度的關係。
  • C. 正確。表示外部電路所允許的VCE與IC的組合。
