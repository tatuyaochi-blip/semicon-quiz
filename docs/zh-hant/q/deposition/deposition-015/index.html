薄膜沉積（CVD與PVD）

在磁控濺鍍中，將磁鐵置於靶材背面的主要目的為下列何者？

  1. A為了冷卻靶材
  2. B為了固定晶圓
  3. C為了以磁場將電子侷限在靶材附近以提高電漿密度，進而提升成膜速率
查看答案與解析

正確答案：C. 為了以磁場將電子侷限在靶材附近以提高電漿密度，進而提升成膜速率

在靶材背面放置磁鐵後，表面附近會形成與電場正交的磁場，電子一邊螺旋運動一邊停留，促進氣體的游離而產生高密度電漿。如此即使在約0.1～1 Pa的低壓下也能得到高成膜速率，並減少電子撞擊晶圓所造成的加熱。靶材只有磁場強的部分會被削去而形成溝槽（侵蝕），因此以旋轉磁鐵來提高利用率。

這個領域的比較

  • CVD與PVD的差異：薄膜沉積方法比較以原理、主要材料、階梯覆蓋性、溫度、純度、環境、危險性與晶片製造中的用途等面向，用表格比較CVD與PVD。
  • ALD與CVD的差異：原子層沉積比較以機制、膜厚控制、覆蓋性、速度、溫度、均勻性與先進晶片中的用途等面向，用表格比較ALD與CVD。
  • LPCVD 與 PECVD 的差異：溫度、膜質、階梯覆蓋性、應力、用途比較從溫度、膜質、氫含量、階梯覆蓋性、薄膜應力、處理方式與產能、用途等面向，以表格比較低壓 CVD（LPCVD）與電漿輔助 CVD（PECVD）。
