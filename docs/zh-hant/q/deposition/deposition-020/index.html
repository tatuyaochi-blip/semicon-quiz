薄膜沉積（CVD與PVD）

在成膜或蝕刻裝置中，以靜電力將晶圓固定在載台上的機構為下列何者？

  1. A真空鑷子
  2. B靜電吸盤（ESC）
  3. CFOUP
查看答案與解析

正確答案：B. 靜電吸盤（ESC）

靜電吸盤是對陶瓷載台內部的電極施加數百V～數kV的電壓，利用與晶圓之間作用的靜電力吸附並固定。它可在真空中使用，且能均勻地保持整片晶圓，因此可在晶圓與載台之間通入氦氣傳熱，精密控制晶圓溫度。這是直接影響蝕刻與成膜均勻性的零件，在取下晶圓（解吸附）時殘留電荷的處理也很重要。
