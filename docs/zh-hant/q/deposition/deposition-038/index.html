薄膜沉積（CVD與PVD）

在濺鍍裝置中，於靶材與晶圓之間放置具有眾多孔洞的板子（準直器，collimator），其目的為下列何者？

  1. A遮擋斜向飛行的原子，只讓接近垂直的原子通過，使薄膜容易附著到孔洞底部
  2. B為了提高成膜速率
  3. C為了冷卻晶圓
查看答案與解析

正確答案：A. 遮擋斜向飛行的原子，只讓接近垂直的原子通過，使薄膜容易附著到孔洞底部

準直器是像蜂巢一樣開孔的板子（孔長與孔徑之比約為1～2），遮擋斜向飛來的濺射原子，只讓幾乎垂直射向晶圓的原子通過。這可改善薄膜在深孔底部的附著（底部覆蓋率）。但準直器上也會附著薄膜，使成膜速率下降，附著的薄膜剝落還會成為微粒，因此現在以離子化濺鍍為主流。

  • A. 正確。只讓接近垂直的原子通過。
  • B. 因為遮擋了一部分原子，成膜速率反而會下降。
  • C. 目的並非冷卻晶圓。
