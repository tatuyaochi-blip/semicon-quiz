薄膜沉積（CVD與PVD）

對以低溫CVD等沉積的氧化膜，在成膜後進行高溫熱處理的「緻密化（densify）」，其主要目的為下列何者？

  1. A為了使薄膜變厚
  2. B為了使薄膜成為導體
  3. C為了使薄膜緻密並驅除水分等，使蝕刻速率與電性接近熱氧化膜
查看答案與解析

正確答案：C. 為了使薄膜緻密並驅除水分等，使蝕刻速率與電性接近熱氧化膜

低溫成膜的氧化膜空隙多，含有水分、氫、Si-OH鍵等，因此在氫氟酸中蝕刻較快，絕緣性也容易較差。以600～1000 ℃左右熱處理後，薄膜會收縮而變薄數%，所含的雜質逸出，蝕刻速率與電性便接近熱氧化膜。在熱預算嚴格的製程中，由於無法提高緻密化的溫度，會以電漿處理或紫外線照射等來替代。

  • A. 熱處理會使薄膜收縮，反而稍微變薄。
  • B. 絕緣膜不會因此變成導體。
  • C. 正確。使其緻密以改善膜質。
