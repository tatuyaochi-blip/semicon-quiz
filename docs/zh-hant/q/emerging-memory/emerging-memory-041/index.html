新世代記憶體

使用 MRAM 時需要注意的外部環境，下列何者正確？

  1. A強光
  2. B強外部磁場
  3. C低濕度
查看答案與解析

正確答案：B. 強外部磁場

MRAM 以磁化方向記憶，因此暴露於強外部磁場時，記錄層的磁化可能被擾亂而遺失資料。作為標準，數十 mT 以上的磁場會成為問題，例如智慧型手機附近的磁鐵與馬達、醫療用 MRI 的周邊等。依用途會使用附磁屏蔽的封裝，並遵守資料手冊所規定的耐磁場值來設計。

  • A. MRAM 並非以光記憶資訊。
  • B. 正確。強磁場可能擾亂資料。
  • C. 濕度與 MRAM 的記憶原理沒有直接關係。
