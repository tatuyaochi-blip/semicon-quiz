新世代記憶體

關於 SOT-MRAM 的特徵，下列何者正確？

  1. A照射光線進行寫入
  2. B以電容的電荷記憶
  3. C以通過重金屬層的電流所產生的自旋軌道力矩使磁化反轉，並可將寫入與讀取的電流路徑分開
查看答案與解析

正確答案：C. 以通過重金屬層的電流所產生的自旋軌道力矩使磁化反轉，並可將寫入與讀取的電流路徑分開

SOT-MRAM 在 MTJ 下方的鎢或鉑等重金屬層通以電流時，藉由自旋霍爾效應產生的自旋軌道力矩，使記錄層的磁化反轉。由於寫入電流不通過穿隧位障，位障不易劣化，且可將寫入與讀取的路徑分開，也能做到 1 ns 以下的高速寫入。代價是單元變成三端子而面積變大，因此期待用於接近 SRAM 的快取用途。
