新世代記憶體

STT-MRAM 中，必須限制讀取電流大小的理由，下列何者正確？

  1. A讀取電流大的話，MTJ 的電阻會永久改變
  2. B因為讀取電流也會產生自旋力矩，過大時會誤使記錄層的磁化反轉
  3. C讀取電流大的話，磁性層會熔化
查看答案與解析

正確答案：B. 因為讀取電流也會產生自旋力矩，過大時會誤使記錄層的磁化反轉

STT-MRAM 的讀取與寫入都是對 MTJ 通以電流，因此若讀取電流接近寫入的反轉電流，每次讀取都可能機率性地使磁化反轉（讀取干擾）。所以讀取電流要設計得遠小於寫入電流，但太小則訊號變弱，讀取變慢且容易出錯。隨著元件微縮而寫入電流下降，這種兼顧就越困難。

  • A. 並非以電阻永久改變的劣化為主要理由。
  • B. 正確。讀取電流也可能造成誤寫入。
  • C. 一般的讀取電流不會使磁性層熔化。
