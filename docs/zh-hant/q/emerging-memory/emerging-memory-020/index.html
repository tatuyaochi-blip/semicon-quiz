新世代記憶體

相變記憶體（PCM）中，非晶態的電阻值隨時間逐漸增加的現象稱為什麼？

  1. A黏附（Stiction）
  2. B電阻漂移
  3. C暫態增強擴散
查看答案與解析

正確答案：B. 電阻漂移

PCM 的非晶相會隨時間使原子排列略微鬆弛，電阻值逐漸上升，上升幅度與時間的對數成正比（R ∝ t^ν，ν 約 0.1）。這就是電阻漂移。若是高電阻與低電阻的二值記憶，不太成為問題，但若以中間電阻進行多值化，就難以區分相鄰的位準。對策有一併讀取作為基準的參考單元、選擇漂移小的材料等。
