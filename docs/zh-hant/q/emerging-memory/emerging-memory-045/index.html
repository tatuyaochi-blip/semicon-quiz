新世代記憶體

銀或銅等金屬離子在固態電解質中移動，形成或切斷導電路徑而改變電阻的記憶體是下列何者？

  1. ACBRAM（導電橋接記憶體）
  2. BFeRAM
  3. CSTT-MRAM
查看答案與解析

正確答案：A. CBRAM（導電橋接記憶體）

CBRAM 中，銀或銅等活性金屬電極的金屬離子溶入固態電解質層，因電壓而移動到對側電極，形成金屬導電橋，或以反向電壓使其溶解而切斷，藉此在低電阻與高電阻之間切換。其特徵是操作電壓低，寫入能量也小。被視為與利用氧空缺的氧化物型並列的 ReRAM 之一，已作為低功耗的嵌入式記憶體商品化。

  • A. 正確。是使用金屬離子形成導電橋的記憶體。
  • B. FeRAM 以鐵電體的極化記憶。
  • C. STT-MRAM 以磁化方向記憶。
