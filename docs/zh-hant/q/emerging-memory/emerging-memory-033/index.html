新世代記憶體

許多新世代記憶體的研究開發一直以「通用記憶體」為目標，關於其想法，下列何者正確？

  1. A可插入任何裝置的記憶卡
  2. B一定使用磁性的記憶體
  3. C一個記憶體就兼具 DRAM 等級的速度與改寫次數，以及快閃記憶體等級的非揮發性與大容量
查看答案與解析

正確答案：C. 一個記憶體就兼具 DRAM 等級的速度與改寫次數，以及快閃記憶體等級的非揮發性與大容量

通用記憶體的想法，是用一個記憶體同時實現 DRAM 與 SRAM 的速度與改寫耐久性，以及快閃記憶體的非揮發性、大容量與低成本，若能實現，就能簡化記憶體階層。然而實際上各有擅長與不擅長之處，例如 MRAM 速度快但大容量化困難，PCM 適合大容量但寫入功耗大。現在是以填補既有記憶體之間空隙的形式，依用途分別使用。

  • A. 與記憶卡規格無關。
  • B. 記憶原理不限於磁性。
  • C. 正確。目標是一個記憶體兼具速度與非揮發性等優點。
