新世代記憶體

MRAM 與 FeRAM 有時用於太空設備等輻射多的環境，其理由下列何者正確？

  1. A因為由能吸收輻射並加以屏蔽的材料所構成
  2. B因為一定比快閃記憶體容量大
  3. C因為不使用電荷記憶，所以不易發生因輻射造成的資料反轉
查看答案與解析

正確答案：C. 因為不使用電荷記憶，所以不易發生因輻射造成的資料反轉

DRAM 與快閃記憶體以電荷量記憶，因此宇宙射線與輻射所產生的電荷可能使資料反轉，或擾亂已累積的電荷。MRAM 以磁化、FeRAM 以極化記憶，因此記憶本身不易受輻射影響，有時用於人造衛星、探測器與核能相關設備。不過周邊的 CMOS 電路會受輻射影響，需要另行採取對策。

  • A. 理由並不是屏蔽輻射的材料。
  • B. 容量一般是快閃記憶體較大。
  • C. 正確。因以電荷以外的物理量記憶，所以傾向耐輻射。
