新世代記憶體

關於「儲存級記憶體」的定位，下列何者正確？

  1. A填補 DRAM 與 NAND 快閃記憶體之間速度、容量與成本差距的非揮發性記憶體
  2. BCPU 內部的暫存器
  3. C光碟的一種
查看答案與解析

正確答案：A. 填補 DRAM 與 NAND 快閃記憶體之間速度、容量與成本差距的非揮發性記憶體

DRAM 與 NAND 之間，存取時間約差 1000 倍（數十 ns 對數十 µs），每位元單價約差 10 倍。填補其間、比 DRAM 便宜且容量大、又比 NAND 快上數個數量級的非揮發性記憶體，稱為儲存級記憶體（SCM）。使用相變記憶體的 Intel Optane 是代表例，但已於 2022 年宣布終止，現在由高速的 SLC 型 NAND 與透過 CXL 連接的記憶體等擔任這個領域。
