新世代記憶體

利用鐵電體極化的方向使通過薄鐵電層的穿隧電流大小改變的元件是下列何者？

  1. AFTJ（鐵電穿隧接面）
  2. BMTJ（磁性穿隧接面）
  3. CMIM 電容
查看答案與解析

正確答案：A. FTJ（鐵電穿隧接面）

FTJ（Ferroelectric Tunnel Junction）是以電極夾住數 nm 極薄鐵電層的元件，隨極化方向不同，位障的高度與形狀會改變，穿隧電阻也隨之變化。與電容型 FeRAM 不同，不必使極化反轉就能作為電阻來讀取，因此可非破壞性讀取，電流小而功耗低。隨著 HfO2 系鐵電體的出現而有所研究進展，也被期待用作 AI 用的類比運算元件。

  • A. 正確。是穿隧電阻隨鐵電體極化而改變的元件。
  • B. MTJ 是穿隧電阻隨磁化方向而改變的元件。
  • C. MIM 電容是金屬-絕緣體-金屬的電容器，並非利用電阻變化。
