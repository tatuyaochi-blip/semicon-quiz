新世代記憶體

MRAM 資料的讀取方法，下列何者正確？

  1. A對 MTJ 通以小電流，檢測電阻的高低
  2. B施加強磁場觀察其反應
  3. C照射光線測量反射光
查看答案與解析

正確答案：A. 對 MTJ 通以小電流，檢測電阻的高低

MRAM 讀取時，對 MTJ 通以比寫入更小的電流，以與基準電阻比較，將平行（低電阻）或反平行（高電阻）檢測為電流或電壓的差異。即使 TMR 比有 100～200% 左右，電阻差也只有 2～3 倍，讀取餘裕比 DRAM 或快閃記憶體小一些。由於是不使磁化反轉的非破壞性讀取，讀取後不需要寫回。
