新世代記憶體

下列記憶體中，斷電後資料仍會保留的非揮發性記憶體是哪一個？

  1. AMRAM
  2. BDRAM
  3. CSRAM
查看答案與解析

正確答案：A. MRAM

MRAM 以磁性體的磁化方向記憶，因此是斷電後資料仍會保留的非揮發性記憶體，保存期間一般在 10 年以上。DRAM 與 SRAM 都是斷電後資料會消失的揮發性記憶體。MRAM 兼具接近 SRAM 的速度與非揮發性，因此在頻繁關閉電源的省電系統，以及希望在停電時也保護資料的工業設備中備受重視。

  • A. 正確。MRAM 是以磁化方向記憶的非揮發性記憶體。
  • B. DRAM 是揮發性的，斷電後資料會消失。
  • C. SRAM 也是揮發性的，斷電後資料會消失。
