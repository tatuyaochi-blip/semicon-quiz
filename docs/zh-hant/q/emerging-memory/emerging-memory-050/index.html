為了降低 MRAM 寫入能量而正被研究的，以電壓改變磁性層磁異向性的效應是下列何者？

  1. A席貝克效應
  2. BVCMA（電壓控制磁異向性）
  3. C壓阻效應
查看答案與解析

正確答案：B. VCMA（電壓控制磁異向性）

VCMA（Voltage-Controlled Magnetic Anisotropy）是對薄磁性層與絕緣層（MgO 等）的界面施加電壓時，界面的電子狀態改變，使磁化的易取向程度（磁異向性）改變的效應。由於幾乎不必通過電流就能輔助磁化反轉，期待比以電流寫入的 STT 方式降低 1～2 個數量級的寫入能量。如何精確地在適當時機停止反轉的時序控制是課題。

  • A. 席貝克效應是由溫差產生電壓的熱電效應。
  • B. 正確。是以電壓改變磁異向性的效應。
  • C. 壓阻效應是電阻隨應力改變的效應，用於壓力感測器等。
