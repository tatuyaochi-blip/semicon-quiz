新世代記憶體

構成 MTJ 的兩個磁性層的作用，下列何者正確？

  1. A一個是磁化方向固定的參考層，另一個是會因寫入而改變方向的自由層
  2. B每次寫入時兩層的磁化都會反轉
  3. C兩層的磁化始終固定
查看答案與解析

正確答案：A. 一個是磁化方向固定的參考層，另一個是會因寫入而改變方向的自由層

MTJ 的一個是磁化方向固定的參考層（固定層），另一個是可因寫入而使方向反轉的自由層（記錄層），以自由層與參考層是平行還是反平行來記憶 0 與 1。參考層以反鐵磁體，或使磁化互相抵消的雙層結構（合成反鐵磁體）強力固定，使其不會被寫入電流或外部磁場移動。自由層則是在保存與易寫入之間取得平衡來設計。

  • A. 正確。是參考層與自由層的組合。
  • B. 作為基準的參考層，其方向不會改變。
  • C. 兩層都固定的話就無法寫入資訊。
