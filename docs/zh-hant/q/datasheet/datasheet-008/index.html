規格書的閱讀方法

對輸入臨界值規定為 VIH(min) = 2.0 V、VIL(max) = 0.8 V 的IC輸入腳位施加1.4 V的電壓。會如何判定？

  1. A低於VIH(min)的2.0 V，因此一定判定為L
  2. B高於VIL(max)的0.8 V，因此一定判定為H
  3. C不保證會判定為H或L中的哪一個
查看答案與解析

正確答案：C. 不保證會判定為H或L中的哪一個

VIH(min)是保證判定為H的最低電壓，VIL(max)是保證判定為L的最高電壓。兩者之間的0.8〜2.0 V，是可能因產品或溫度而判定為任一方的不定區域。輸入若長時間停留在此區域，輸出可能不穩定地振盪，或輸入級的pMOS與nMOS同時導通而流過貫穿電流。接收緩慢變化的訊號時，應使用具遲滯特性的施密特觸發輸入。
