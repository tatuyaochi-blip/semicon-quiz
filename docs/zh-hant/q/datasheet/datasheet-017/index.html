規格書的閱讀方法

具有核心用1.0 V與I/O用3.3 V兩個電源的IC，其規格書指定電源的上電順序，主要原因為何？

  1. A上電順序會決定該產品能穩定達到的最高工作頻率上限
  2. B順序錯誤時內部會流過非預期的電流，成為閂鎖效應、損壞或誤動作的原因
  3. C順序只影響啟動時的功耗，不影響功能與可靠度
查看答案與解析

正確答案：B. 順序錯誤時內部會流過非預期的電流，成為閂鎖效應、損壞或誤動作的原因

具有多個電源的IC，在只有其中一個電源開啟的狀態下，可能經由電源之間或輸入輸出腳位的保護二極體等流過預料之外的電流。這會成為閂鎖效應、元件損壞，以及內部電路處於不定狀態而誤動作的原因。規格書中會列出「先開啟核心電源，並以相反順序關閉」「將電源間的電壓差保持在一定值以下」等條件。實際的電路板上，會利用穩壓器的致能腳位或Power Good訊號來建立順序。
