規格書的閱讀方法

電氣特性表的註腳寫著「由設計及特性評估保證，未進行出貨測試」，此項目的意義何者正確？

  1. A雖未全數量測，但製造商依據設計與評估資料保證的數值
  2. B僅供參考而列出的數值，製造商對此數值不作任何保證
  3. C出貨前全數量測的數值，是表中管理最嚴格的數值
查看答案與解析

正確答案：A. 雖未全數量測，但製造商依據設計與評估資料保證的數值

量產時的出貨測試，基於測試時間與成本的考量，並不會對所有項目都全數量測。輸入電容或部分時序等難以量測的項目，是以設計分析，或改變溫度與電源電壓所做的特性評估資料來保證。有此註記的數值只要是min/max，就可視為保證值，但由於依據並非全數測試，保留餘裕使用較為安全。閱讀時要與不受保證的typ值區分。
