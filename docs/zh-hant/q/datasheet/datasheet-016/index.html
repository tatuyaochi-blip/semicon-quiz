規格書的閱讀方法

關於線性穩壓器「靜態電流（IQ）」的說明，下列何者正確？

  1. A關閉輸出時，從輸出端子往輸入端子側逆流的漏電流
  2. B該穩壓器可供應給負載、規格書保證的輸出電流最大值
  3. C除了流向負載的電流之外，為了穩壓器本身運作而流向接地的電流
查看答案與解析

正確答案：C. 除了流向負載的電流之外，為了穩壓器本身運作而流向接地的電流

靜態電流是參考電壓源與誤差放大器等穩壓器內部電路所消耗的電流，關係為輸入電流 = 負載電流 + 靜態電流。依產品不同，從1 µA以下到數mA都有。例如在待機時負載電流為10 µA的裝置上使用靜態電流50 µA的穩壓器，電池消耗的大部分就會是穩壓器本身。也有靜態電流會隨負載電流增加的產品，因此要確認無負載時與有負載時的數值或圖表。
