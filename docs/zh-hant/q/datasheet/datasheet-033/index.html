規格書的閱讀方法

關於功率MOSFET安全工作區（SOA）圖的讀法，下列何者正確？

  1. A直流（DC）的線位於最外側，以脈衝工作時，時間越短受到的限制比直流越嚴格
  2. B邊界線僅由VDS與ID的絕對最大額定值決定，因此不會因脈衝寬度或外殼溫度而改變
  3. C脈衝寬度越短可容許的功率越大，且多為25 ℃、單一脈衝下的數值，需依溫度折減
查看答案與解析

正確答案：C. 脈衝寬度越短可容許的功率越大，且多為25 ℃、單一脈衝下的數值，需依溫度折減

SOA是以VDS為橫軸、ID為縱軸的對數圖，表示元件不損壞即可使用的電壓與電流組合。邊界由RDS(on)造成的限制、電流額定值、熱（功率）造成的限制等決定，熱造成的限制在脈衝寬度越短時越寬鬆，因此會畫出10 µs、1 ms、DC等多條線。大多數圖是外殼溫度25 ℃、單一脈衝下的數值，因此要配合實際溫度或重複動作進行折減。在限制湧入電流的電路等於線性區使用時，尤其重要。
