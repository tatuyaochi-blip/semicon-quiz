規格書的閱讀方法

用輸入偏移電壓為 max 2 mV 的運算放大器組成增益100倍的非反相放大電路。輸入為0 V時，輸出可能出現的最大誤差電壓參考值為何？

  1. A2 mV
  2. B200 mV
  3. C20 mV
查看答案與解析

正確答案：B. 200 mV

輸入偏移電壓的行為就像串聯在輸入上的小電壓源，會被放大為非反相放大電路的增益（1 + Rf/Ri）倍後出現在輸出。2 mV × 100 = 200 mV，例如相對於5 V的滿刻度為4%的誤差。要以max值而非typ值來估算，並再加上溫度漂移（µV/℃）造成的變化。精密量測時，可選擇偏移僅數µV左右的零漂移（截波）型，或以軟體校正。2 mV是忘了乘上增益的數值。

規格書的閱讀方法的其他題目

  1. 以單電源5 V使用的運算放大器，其規格書寫著輸入共模電壓範圍為「0 V〜(V+ − 1.5 V)」。下列何者正確？
  2. 輸出3.3 V的LDO，其壓降規定為 max 300 mV（輸出電流500 mA時）。在流過500 mA的同時維持輸出電壓，所需的最低輸入電壓為多少？
  3. 一顆PSRR（電源抑制比）在1 kHz時為60 dB的LDO，其輸入疊加了1 kHz、振幅100 mV的漣波。輸出出現的漣波參考值為何？
  4. 與AD轉換器規格書中「無遺失碼（no missing codes）」的保證關係最密切的條件為何？
  5. 某16位元的AD轉換器，SINAD（訊號對雜訊及失真比）規定為74 dB。有效位元數（ENOB）大約為多少？
