規格書的閱讀方法

電氣特性表開頭寫著「除非另有註明，Ta = 25 ℃、VDD = 3.3 V」。閱讀此表時應注意的事項，下列何者正確？

  1. A溫度或電源電壓不同時數值可能改變，因此也要確認在全溫度範圍內規定的數值與圖表
  2. B這個條件只是記錄量測裝置的設定，設計時不需特別在意
  3. C25 ℃時的數值是最差的數值，因此在其他溫度下會比這個數值更好
查看答案與解析

正確答案：A. 溫度或電源電壓不同時數值可能改變，因此也要確認在全溫度範圍內規定的數值與圖表

電氣特性的數值，要與溫度、電源電壓、負載等量測條件一起看才有意義。開頭的條件適用於各列未另外註明條件的所有項目。漏電流在高溫時增加、輸出驅動能力在電源電壓低時下降等，條件改變時數值會大幅變化。許多規格書會以另外的欄位或粗體標示在 −40〜85 ℃等全溫度範圍內保證的數值，因此要讀取符合實際使用條件的那一列。
