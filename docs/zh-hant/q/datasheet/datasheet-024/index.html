規格書的閱讀方法

在時序圖中，以上下兩條平行線描繪位址或資料匯流排，並在某些地方交叉成×形的標記方式，其意義何者正確？

  1. A平行線的區間表示訊號在H與L之間高速振盪
  2. B平行線的區間表示數值已確定，在×的位置數值切換
  3. C×的位置表示在該時間點輸出變為高阻抗（開路）狀態
查看答案與解析

正確答案：B. 平行線的區間表示數值已確定，在×的位置數值切換

多位元匯流排中，各位元是H或L依資料而異，因此平行畫出H與L兩條線，表示「某個數值已確定」的區間。×的交叉是該數值切換的時間點，建立時間與保持時間就以此切換位置與時脈邊緣之間的間隔來圖示。高阻抗一般以上下中間高度的一條線表示，數值無效的區間則以斜線（陰影）描繪。標記的約定請以規格書的圖例確認。

規格書的閱讀方法的其他題目

  1. 將規格書所載的 θJA（接面至周圍的熱阻）用於實際設備的熱設計時，應注意的事項何者正確？
  2. 將最大接面溫度 Tj(max) = 125 ℃、θJA = 50 ℃/W 的IC，在周圍溫度 Ta = 85 ℃ 下使用時，容許的功耗上限為多少？
  3. 估算加裝散熱片使用之功率元件的接面溫度時，作為接面到周圍的熱阻應使用哪一種組合？
  4. 規格書中 ψJT（接面至封裝頂面的熱特性參數）的用法，下列何者正確？
  5. 有一種封裝，其容許損耗在周圍溫度25 ℃以下為1.0 W，高於此溫度時呈直線減少，至150 ℃時為0 W。周圍溫度75 ℃時的容許損耗為多少？
