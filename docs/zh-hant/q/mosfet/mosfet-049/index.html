MOSFET

以通道長度調變係數λ與汲極電流ID表示飽和區MOSFET的小訊號輸出電阻ro，下列何者為適當的公式？

  1. Aro ≈ 1 / (λ × ID)
  2. Bro ≈ ID / λ
  3. Cro ≈ λ × ID
查看答案與解析

正確答案：A. ro ≈ 1 / (λ × ID)

考慮通道長度調變時，飽和區的汲極電流呈 ID(1 + λVDS) 的形式，隨VDS略微增加，此斜率的倒數即為輸出電阻 ro ≈ 1/(λID)。λ幾乎與通道長度成反比，因此將L加倍，ro也約加倍。單一電晶體的最大電壓增益為 gm·ro，在微細電晶體中只有10～20倍左右，因此要以疊接（cascode）或多級架構來確保增益。

  • A. 正確。ro ≈ 1/(λID)。
  • B. ID/λ 的單位是電流×電壓，並不是電阻。
  • C. λ × ID 的單位是電流/電壓，並不是電阻。
