SRAM與快閃記憶體

SRAM 讀取時，預先將位元線充電至電源電壓等的動作稱為什麼？

  1. A更新
  2. B抹除
  3. C預充電
查看答案與解析

正確答案：C. 預充電

SRAM 讀取時，首先將成對的位元線預充電到電源電壓，以字元線選擇單元後，保存 0 的那一側位元線會透過存取電晶體稍微放電。不必等到全擺幅，一旦形成數十～一百 mV 的差距，感測放大器就會放大，因此能高速讀取。讀取結束後再次預充電，為下一次存取做準備。
