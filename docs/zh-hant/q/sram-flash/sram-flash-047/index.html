SRAM與快閃記憶體

防止低電壓下 SRAM 寫入失敗的「寫入輔助」，下列何者為例？

  1. A寫入時將 0 側的位元線稍微拉低到負電壓
  2. B寫入時提高單元的電源電壓
  3. C降低字元線的電壓
查看答案與解析

正確答案：A. 寫入時將 0 側的位元線稍微拉低到負電壓

在低電壓下，存取電晶體的驅動能力不足，無法克服單元的上拉，容易寫入失敗。在負位元線方式中，把寫入 0 那一側的位元線拉低到負電壓（−100～−200 mV 左右），存取電晶體的閘極-源極間電壓增加，就更容易寫入。也會使用寫入時降低單元電源電壓、削弱上拉的方式，先進製程的 SRAM 不可缺少這類輔助電路。

  • A. 正確。以負位元線輔助寫入。
  • B. 寫入時降低單元的電源電壓，才更容易使單元反轉。
  • C. 降低字元線會削弱存取電晶體，使寫入更困難。
