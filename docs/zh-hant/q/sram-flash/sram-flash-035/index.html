SRAM與快閃記憶體

SRAM 主要使用的用途，下列何者最恰當？

  1. A數位相機的記錄媒體
  2. B大容量資料的長期保存
  3. CCPU 的快取記憶體
查看答案與解析

正確答案：C. CPU 的快取記憶體

SRAM 不需更新、可用與邏輯相同的製程製作，且能在約 1 ns 內存取，因此用於 CPU 的快取（L1～L3）與暫存器檔案。最近的 CPU 中，也有擁有數十～數百 MB 的 L3 快取者，還出現了將晶片縱向堆疊以增加 SRAM 的產品。每位元面積大、成本高，因此不適合大容量的主記憶體。

  • A. 記錄媒體使用的是非揮發性的 NAND 快閃記憶體。
  • B. SRAM 是揮發性的，無法用於長期保存。
  • C. 正確。高速的 SRAM 用於快取。
