SRAM與快閃記憶體

快閃記憶體的資料保存（retention）特性容易變差的條件為何？

  1. A在低溫下保存時
  2. B在暗處保存時
  3. C在高溫下保存時
查看答案與解析

正確答案：C. 在高溫下保存時

儲存的電子在溫度越高時獲得越多熱能，越容易穿過絕緣膜，因此在高溫下保存會縮短資料保存期間。利用此特性，會進行在高溫下保存、以短時間估算長期保存的加速試驗（阿瑞尼斯模型）。若因反覆改寫而使氧化膜劣化，保存特性會更差，因此使用已久的 SSD 最好避免長時間不通電放置。
