系統架構與可靠度設計

在提高系統處理能力的方法中，屬於水平擴展（scale-out）的是下列何者？

  1. A增加相同配置的伺服器台數，並以負載平衡器分配處理
  2. B把伺服器的 CPU 換成更高效能的產品，並增加記憶體
  3. C減少伺服器的台數，提高每台的使用率
查看答案與解析

正確答案：A. 增加相同配置的伺服器台數，並以負載平衡器分配處理

水平擴展是增加伺服器的台數來分擔處理，以提高整個系統處理能力的方法。只要增加台數就容易累加能力，1台故障時其餘的也能繼續處理，但必須事先把系統設計成可以分割處理。把1台伺服器的零件換成更高效能的是垂直擴展（scale-up），架構簡單，但1台所能達到的效能有其極限。減少台數則稱為水平縮減（scale-in）。

  • A. 正確。增加台數來分擔處理。
  • B. 這是提高1台效能的垂直擴展。
  • C. 這是減少台數的水平縮減，處理能力會下降。
