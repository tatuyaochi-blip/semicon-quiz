系統架構與可靠度設計

每週日晚上進行完整備份，週一到週六每晚進行增量備份。週四中午發生故障，決定把資料還原到週三晚上備份的時間點。還原時使用的備份數量為下列何者？

  1. A2
  2. B3
  3. C4
查看答案與解析

正確答案：C. 4

增量備份只包含自上一次備份以來的變更，因此還原週日的完整備份後，必須依序套用週一、週二、週三的增量備份。所以使用的備份為 1 + 3 = 4 份。若每晚進行的是差異備份，則只需2份（完整備份與週三的差異備份）。

  • A. 這是差異備份時的數量。增量備份需要中間所有的增量備份。
  • B. 這只算了3份增量備份，沒有算作為基礎的週日完整備份。
  • C. 正確。完整備份1份，加上週一到週三的增量備份3份。
