系統架構與可靠度設計

某系統依序以 Web 伺服器層、應用程式伺服器層、資料庫伺服器層處理使用者的要求。每個要求各通過3層一次，各層能處理的最大件數為：Web 伺服器層每秒1,200件、應用程式伺服器層每秒1,000件、資料庫伺服器層每秒900件。將資料庫伺服器層強化為每秒可處理1,500件時，整個系統能處理的最大件數為下列何者？

  1. A每秒1,000件
  2. B每秒1,200件
  3. C每秒1,500件
查看答案與解析

正確答案：A. 每秒1,000件

在要求依序通過所有層的系統中，整體能處理的件數由處理能力最小的層（瓶頸）決定。強化之前，由資料庫伺服器層的每秒900件決定。將資料庫伺服器層提高到每秒1,500件後，min(1,200, 1,000, 1,500) = 1,000，接著應用程式伺服器層成為瓶頸，整體停留在每秒1,000件。消除一個瓶頸後，下一個能力較小的地方會限制整體，因此改善效能時必須著眼於整體的流程。

  • A. 正確。應用程式伺服器層的每秒1,000件成為新的瓶頸。
  • B. 這是漏看應用程式伺服器層的能力，而把 Web 伺服器層的能力當作整體的值。
  • C. 這是強化後資料庫伺服器層的能力。系統無法超過其他層的能力進行處理。
