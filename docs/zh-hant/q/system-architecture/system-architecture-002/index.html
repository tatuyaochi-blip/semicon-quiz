系統架構與可靠度設計

在三層式架構的主從式系統中，負責業務處理（商業邏輯）的是下列哪一層？

  1. A展示層
  2. B功能層（應用層）
  3. C資料層（資料庫存取層）
查看答案與解析

正確答案：B. 功能層（應用層）

三層式架構將處理分為負責與使用者互動（接受輸入與顯示結果）的展示層、負責業務處理的功能層，以及負責存取資料庫的資料層。業務規則與計算集中在功能層，因此即使更換畫面或資料庫，對業務處理的影響也較小。此外，用戶端只需放置展示層，因此容易做成以網頁瀏覽器作為終端機的架構。

  • A. 這是負責接受輸入與顯示結果等、與使用者互動的層。
  • B. 正確。這是負責業務規則與計算等商業邏輯的層。
  • C. 這是負責在資料庫中查詢與更新資料的層。
