系統架構與可靠度設計

關於虛擬化環境中即時遷移（live migration）的說明，下列何者適當？

  1. A將運作中的虛擬機器，以使用者所見的中斷極短的方式，移到另一台實體伺服器
  2. B停止虛擬機器並複製其磁碟映像，在另一台實體伺服器上重新啟動
  3. C把在實體伺服器上運作的作業系統與應用程式，重新建置成虛擬機器並移轉
查看答案與解析

正確答案：A. 將運作中的虛擬機器，以使用者所見的中斷極短的方式，移到另一台實體伺服器

即時遷移是一邊讓虛擬機器運作，一邊把其記憶體內容反覆複製到目的地的實體伺服器，最後只停止極短的時間來移轉剩餘的內容與 CPU 的狀態，藉此把虛擬機器移到另一台實體伺服器的機制。在實體伺服器維護或消除負載不均時，幾乎不必停止服務。一般而言，來源與目的地必須共用同一個儲存設備，或連同儲存內容一起移轉，也要求 CPU 功能的相容性。

  • A. 正確。在運作中、幾乎不停止地移轉。
  • B. 這是停止虛擬機器後移轉的冷遷移（cold migration）的說明。
  • C. 這是把實體伺服器移轉到虛擬機器的 P2V（Physical to Virtual）的說明。
