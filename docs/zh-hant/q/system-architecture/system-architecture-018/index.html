系統架構與可靠度設計

關於 RAID 1 的說明，下列何者適當？

  1. A將資料分散寫入多台磁碟（等量分割，striping），加快讀寫速度，但沒有冗餘
  2. B將相同的資料寫入2台磁碟（鏡像，mirroring），即使1台故障也不會失去資料
  3. C將資料與用於錯誤更正的同位元（parity）分散寫入多台磁碟，即使1台故障也能復原資料
查看答案與解析

正確答案：B. 將相同的資料寫入2台磁碟（鏡像，mirroring），即使1台故障也不會失去資料

RAID 1 是將相同的資料寫入2台磁碟的鏡像，即使1台故障，也能以另1台的資料繼續處理。可記錄資料的容量為2台磁碟合計的一半。只有等量分割而沒有冗餘的是 RAID 0，分散寫入同位元的是 RAID 5。另外，RAID 是防備磁碟故障的機制，誤刪的資料或遭勒索軟體加密的資料會同時反映到兩台磁碟，因此無法取代備份。

  • A. 這是 RAID 0 的說明。只要1台故障，資料就會遺失。
  • B. 正確。以鏡像承受1台磁碟的故障。
  • C. 這是 RAID 5 的說明。
