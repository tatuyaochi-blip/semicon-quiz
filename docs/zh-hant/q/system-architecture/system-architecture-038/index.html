系統架構與可靠度設計

資料中心將 UPS（不斷電系統）與自備發電設備搭配使用的理由，下列何者適當？

  1. AUPS 用於防備長時間停電，自備發電設備用於防備瞬間電壓下降
  2. B從停電發生後到自備發電設備啟動、電力穩定為止的期間由 UPS 的蓄電池銜接，之後長時間的供電由自備發電設備負責
  3. C同時使用 UPS 與自備發電設備，IT 設備的耗電會減少
查看答案與解析

正確答案：B. 從停電發生後到自備發電設備啟動、電力穩定為止的期間由 UPS 的蓄電池銜接，之後長時間的供電由自備發電設備負責

自備發電設備只要有燃料就能長時間供電，但偵測到停電後啟動、到電壓與頻率穩定為止需要時間。UPS 能以蓄電池等儲存的電力，從停電發生的瞬間起不中斷地供電，但能供電的時間有限。因此兩者搭配使用，由 UPS 銜接停電後的短時間，長時間的供電則由自備發電設備負責。

  • A. 角色相反。UPS 負責短時間，自備發電設備負責長時間。
  • B. 正確。由 UPS 銜接到發電設備穩定為止的期間。
  • C. 即使搭配使用，IT 設備的耗電也不會減少。
