系統架構與可靠度設計

將半導體工廠製造執行系統（MES）的伺服器，做成由主系統（運轉系統）與備援系統組成的雙工系統。當備援系統採用熱備援時，其特徵為下列何者？

  1. A讓備援系統處於啟動狀態待命，並隨時把主系統的資料反映到備援系統，因此主系統故障時能在短時間內切換
  2. B備援系統平時關閉電源，主系統故障後才啟動並復原資料，因此切換需要時間，但能節省待命期間的電力與費用
  3. C主系統與備援系統同時進行相同的處理，一邊比對結果一邊運轉
查看答案與解析

正確答案：A. 讓備援系統處於啟動狀態待命，並隨時把主系統的資料反映到備援系統，因此主系統故障時能在短時間內切換

熱備援是讓備援系統保持啟動狀態，並隨時將主系統的資料反映到備援系統的方式，主系統故障時能在短時間內接手處理。MES 一旦停止，就無法指示批次的進行方式、指定設備的配方或記錄製造履歷，因此一般會選擇能在短時間內切換的架構。讓備援系統停止、故障後才啟動的方式是冷備援，兩者的中間（已啟動，但接手處理前需要準備）稱為暖備援。由2套系統同時進行相同的處理並比對的是雙重系統。

  • A. 正確。備援系統保持啟動，資料也保持同步，因此能立即切換。
  • B. 這是冷備援的說明。
  • C. 這是雙重系統的說明。
