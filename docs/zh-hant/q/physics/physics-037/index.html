半導體物性

當電子濃度為n、電洞濃度為p、電子遷移率為μn、電洞遷移率為μp、基本電荷為q時，表示半導體電導率σ的式子為下列何者？

  1. Aσ = q(nμn − pμp)
  2. Bσ = (nμn + pμp) / q
  3. Cσ = q(nμn + pμp)
查看答案與解析

正確答案：C. σ = q(nμn + pμp)

電子與電洞的移動方向相反，但電荷的正負號也相反，因此電流朝同一方向流動，電導率是兩者之和 σ = q(nμn + pμp)。電阻率則是其倒數。在摻雜的半導體中，只取多數載子的項就足以近似，例如n型時 σ ≈ qnμn。在本質矽中 n = p = ni，所以 σ = q·ni(μn + μp)，電阻率高達約2×10⁵ Ω·cm。

  • A. 電洞與電子朝相反方向移動，但電荷也相反，所以電流方向相同，應為和而不是差。
  • B. 電導率與基本電荷q成正比，因此除以q是錯誤的。
  • C. 正確。將電子與電洞的貢獻相加。
