半導體物性

下列何者是縮短矽中少數載子生命期（壽命）的典型因素？

  1. A金等會形成深能階的雜質及晶體缺陷
  2. B將溫度降到極低溫
  3. C將晶圓放在真空中
查看答案與解析

正確答案：A. 金等會形成深能階的雜質及晶體缺陷

金、鐵等重金屬及晶體缺陷會在能隙中間附近形成深能階，成為促成電子與電洞複合的複合中心（SRH複合）。能階越接近中央，越能促進複合，因此生命期越短。反之，在快速二極體和IGBT中，為了迅速消除累積的少數載子，會藉由鉑擴散或電子束、質子照射刻意縮短生命期。極低溫和真空都不是縮短生命期的典型因素。
