LSI設計流程與EDA

在靜態時序分析中發現建立時間違反時，適當的對策為下列何者？

  1. A簡化路徑上的邏輯，或換成驅動力較大的單元以減少延遲
  2. B在路徑上加入延遲用的緩衝器以增加延遲
  3. C提高時脈頻率
查看答案與解析

正確答案：A. 簡化路徑上的邏輯，或換成驅動力較大的單元以減少延遲

建立時間違反是資料路徑太長，在下一個時脈前資料來不及抵達的違反。可藉由減少邏輯級數、換成驅動力較大或臨界電壓較低的快速單元、拉近擺放位置以縮短佈線等方式減少延遲。降低時脈頻率也能解決，但效能會下降。加入延遲用緩衝器是保持時間違反的對策，而提高頻率會使違反更加惡化。
