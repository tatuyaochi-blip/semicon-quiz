雲端與容器基礎

在多個服務協同運作的系統中，想調查使用者的1個要求依什麼順序經過了哪些服務、在各服務分別花了多少時間。在用於可觀測性的資料中，最適合的是下列何者？

  1. A指標（CPU使用率、要求數等數值的時間序列）
  2. B日誌（各服務輸出的事件紀錄）
  3. C追蹤（1個要求的路徑與各區段時間的紀錄）
查看答案與解析

正確答案：C. 追蹤（1個要求的路徑與各區段時間的紀錄）

可觀測性是能從系統輸出的資料推斷其內部狀態的程度，常被列舉的資料有指標（metrics）、日誌（logs）與追蹤（traces）。在追蹤（分散式追蹤）中，為要求加上共用的識別碼並在服務之間傳遞，記錄各服務中處理區段（span）的開始與結束時刻，組合出1個要求的路徑與時間的明細。指標適合掌握整體趨勢與偵測異常，日誌適合詳細調查個別事件，但要追蹤跨服務的1個要求的流程，最適合的是追蹤。實務上也會把追蹤的識別碼寫進日誌，結合三者來調查原因。

  • A. 指標是彙整數值的時間序列，適合了解整體趨勢與異常，但看不出1個要求的路徑。
  • B. 日誌是個別事件的紀錄，且依服務分開，單靠它難以串起1個要求的流程。
  • C. 正確。追蹤記錄1個要求跨服務經過的路徑與時間。
