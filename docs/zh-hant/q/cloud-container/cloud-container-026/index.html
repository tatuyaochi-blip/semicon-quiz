雲端與容器基礎

有一個可分配資源為CPU 4核心、記憶體 8 GiB 的節點。各 Pod 的容器設定了 requests 為CPU 500m、記憶體 1.5 GiB，limits 為CPU 1核心、記憶體 2 GiB。沒有其他 Pod 與系統預留。這個節點最多可放置的 Pod 數為下列何者？

  1. A4個
  2. B5個
  3. C8個
查看答案與解析

正確答案：B. 5個

排程器配置時，會讓節點上 Pod 的 requests 合計在CPU與記憶體上分別不超過可分配的量。以CPU來看可放到 4000m ÷ 500m = 8個，但以記憶體來看 8 ÷ 1.5 = 5.33…，只能到5個。必須同時滿足兩個條件，所以是5個。limits 不用於配置的判斷，因此5個 Pod 的 limits 合計（CPU 5核心、記憶體 10 GiB）超過了節點的資源，若所有 Pod 同時用到上限，資源就會不足。

  • A. 這是以 limits 計算的值（CPU 4 ÷ 1 = 4，記憶體 8 ÷ 2 = 4）。配置是以 requests 判斷的。
  • B. 正確。CPU可放8個、記憶體可放5個，取較少的5個。
  • C. 這是只以CPU的 requests 計算的值。記憶體的 requests 合計也必須落在 8 GiB 以內。
