雲端與容器基礎

在每小時接收12,000件要求的服務中，以金絲雀部署發布新版本，只把5%的要求送到新版本。新版本有使所收要求的3%失敗的缺陷，1小時後發現並把所有要求切回原本的版本。這1小時內因缺陷而失敗的要求件數為下列何者？

  1. A18件
  2. B360件
  3. C600件
查看答案與解析

正確答案：A. 18件

送到新版本的要求為 12,000 × 5% = 600件，其中3%失敗，所以是 600 × 3% = 18件。若一次把所有要求切換到新版本，會有 12,000 × 3% = 360件失敗。金絲雀部署就是這樣把受缺陷影響的要求限制在一部分，一邊觀察錯誤率與回應時間等指標，沒有問題再逐步提高比例的方法。比較新舊版本的指標需要足夠數量的要求，因此要一併決定送出的比例與觀察的時間。

  • A. 正確。12,000 × 0.05 × 0.03 = 18件。
  • B. 這是把所有要求都送到新版本時的件數（12,000 × 0.03）。
  • C. 這是送到新版本的要求件數（12,000 × 0.05），失敗的是其中的3%。
