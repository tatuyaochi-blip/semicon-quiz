雲端與容器基礎

準備2套與正式環境組成相同的環境，一套維持執行目前的版本，另一套放入新版本並確認後，一次切換負載平衡器的導向目標。若有問題，就把導向目標切回，立即回到原本的版本。這種發布方法是下列何者？

  1. A藍綠部署
  2. B金絲雀部署
  3. C滾動更新
查看答案與解析

正確答案：A. 藍綠部署

藍綠部署是準備2套環境（藍與綠），把使用者的通訊一次切換到新環境的方法。舊環境會暫時原樣保留，因此即使發生問題，只要切回就能回到原本的版本。另一方面，切換前後需要2套環境份的資源，資料庫結構的變更也必須做成新舊兩個版本都能使用的形式。金絲雀部署是只讓一部分要求使用新版本的方法，滾動更新則是逐步替換伺服器的方法。

  • A. 正確。準備2套環境，一次切換導向目標。
  • B. 金絲雀部署是先只把一部分要求送到新版本，一邊觀察一邊提高比例的方法。
  • C. 滾動更新是把1套環境中的伺服器或 Pod 逐步替換成新版本的方法。
