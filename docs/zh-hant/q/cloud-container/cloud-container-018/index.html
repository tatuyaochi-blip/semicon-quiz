雲端與容器基礎

在 Kubernetes 中，Pod 每次重新建立時IP位址都會改變。讓其他應用程式能以不變的名稱與位址，連線到以標籤選出的多個 Pod 並分散負載的資源，是下列何者？

  1. AConfigMap
  2. BService
  3. CPersistentVolume
查看答案與解析

正確答案：B. Service

Service 為符合其標籤選擇器的一群 Pod，提供在叢集內不會改變的虛擬IP位址與DNS名稱，並把收到的通訊分配給這些 Pod。即使 Pod 被替換，只要以 Service 的名稱連線即可，連線端不需要知道 Pod 的位址。要公開到叢集外時，可把 type 設為 NodePort 或 LoadBalancer，或使用 Ingress。ConfigMap 是處理設定值的資源，PersistentVolume 則是處理永續儲存空間的資源。

  • A. ConfigMap 是把設定值與映像檔分開並傳給 Pod 的資源。
  • B. 正確。Service 以穩定的名稱與位址，把通訊分配給多個 Pod。
  • C. PersistentVolume 是表示即使 Pod 重新建立也會保留的儲存空間的資源。
