車用半導體與功能安全

車用IC的閂鎖效應（latch-up）試驗被要求在比室溫更嚴苛的產品最高動作溫度下進行，正確的理由是下列何者？

  1. A溫度越高寄生電晶體越不易作用，越不容易發生閂鎖效應，因此能在容易合格的條件下試驗
  2. B溫度越高寄生電晶體的電流增益與井的電阻越大，越容易發生閂鎖效應
  3. C在高溫下ESD保護電路會失效，因此能同時完成ESD的試驗
查看答案與解析

正確答案：B. 溫度越高寄生電晶體的電流增益與井的電阻越大，越容易發生閂鎖效應

CMOS的閂鎖效應是指寄生形成的pnp與npn電晶體以閘流體的形式導通，持續流過大電流的現象。溫度升高時，寄生電晶體的電流增益上升，井與基板的電阻也變大，因此即使微小的電流也容易引起導通。所以，AEC-Q100依JESD78 Class II的條件，將對端子注入電流或施加過電壓的試驗，在由溫度等級決定的最高動作溫度（環境溫度，例如等級1為125 ℃）下進行。高溫並非為了放寬條件，而且也與ESD的試驗分開進行。
