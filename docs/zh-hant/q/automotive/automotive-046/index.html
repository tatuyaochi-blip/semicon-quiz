車用半導體與功能安全

下列何者是對車用電源中成為問題的「負載突降（load dump）」的正確說明？

  1. A引擎起動時大電流流入起動馬達，使電池電壓大幅下降的現象
  2. B在交流發電機（alternator）充電期間電池連接脫落，電源線上產生大突波電壓的現象
  3. C車身遭雷擊時，大電流流入電源線而使零件損壞的現象
查看答案與解析

正確答案：B. 在交流發電機（alternator）充電期間電池連接脫落，電源線上產生大突波電壓的現象

負載突降是指發電機以大電流充電期間，因端子脫落等使電池被切離，失去去處的能量使電源線電壓急遽上升的現象。即使是12 V系統，若沒有抑制電路，參考值可達接近100 V，並可能持續數十～數百 ms（ISO 16750-2的Test A中，12 V系統為40～400 ms）。在由發電機端抑制電壓的車輛（Test B）中會被限制在35 V左右，因此直接連接電池的IC多具有40 V左右以上的耐壓，並再以TVS二極體等加以保護。起動時的電壓下降是稱為cranking的另一種現象。
