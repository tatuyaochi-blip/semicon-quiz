車用半導體與功能安全

下列何者是對汽車功能安全概念的正確說明？

  1. A只選用高品質的零件，使零件的故障率為零，保證在車輛的使用期間內絕不會發生任何故障
  2. B將車輛設計成無論駕駛人做出任何錯誤操作，都絕對不會發生事故
  3. C並非使故障為零，而是即使發生故障也能偵測出來並轉移至安全狀態等，將風險降低至可容許的水準
查看答案與解析

正確答案：C. 並非使故障為零，而是即使發生故障也能偵測出來並轉移至安全狀態等，將風險降低至可容許的水準

零件的故障無法完全消除，因此功能安全的目標是在發生故障時不會進入危險的狀態。例如在電動輔助轉向中發現馬達控制異常時，便停止輔助並以警示燈告知，轉移至駕駛人可用手操作的狀態。ISO 26262將功能安全定義為不存在因電氣、電子系統的功能異常所引起之危害而導致的不合理風險。它並不是保證絕對不會發生事故。
