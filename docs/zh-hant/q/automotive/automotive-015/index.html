車用半導體與功能安全

評估某個危險事件後，結果為嚴重度S3、暴露度E4、可控度C3，判定為ASIL D。若同一事件只有可控度為C2（通常多數駕駛人可以迴避），ASIL會變成如何？

  1. AASIL D
  2. BASIL B
  3. CASIL C
查看答案與解析

正確答案：C. ASIL C

在ISO 26262的ASIL表中，只有S3、E4、C3的組合為ASIL D，S、E、C中任一個降低一級，ASIL也會降低一級而成為ASIL C。作為參考，可以記成S的數字（1～3）、E的數字（1～4）、C的數字（1～3）的合計為10則為D、9為C、8為B、7為A，更低則為QM，相當方便。此例中3 + 4 + 2 = 9，因此為ASIL C。既不會維持ASIL D不變，也不會降低兩級。
