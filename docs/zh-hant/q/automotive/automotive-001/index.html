車用半導體與功能安全

在車用IC可靠度試驗的標準AEC-Q100中，動作溫度等級1所規定的環境溫度範圍是下列何者？

  1. A−40～85 ℃
  2. B−40～125 ℃
  3. C−40～150 ℃
查看答案與解析

正確答案：B. −40～125 ℃

AEC-Q100的等級表示環境溫度的範圍，數字越小上限越高。等級0為−40～150 ℃，等級1為−40～125 ℃，等級2為−40～105 ℃，等級3為−40～85 ℃。−40～150 ℃是最嚴格的等級0，−40～85 ℃則是等級3的範圍。晶片的接面溫度會因自身發熱而高於環境溫度，因此在熱設計時也要將此差距納入考量。
