車用半導體與功能安全

ISO 26262所區分的隨機硬體故障與系統性故障，兩者說明的正確組合是下列何者？

  1. A隨機硬體故障是使用中因劣化或宇宙射線等而機率性發生的故障，系統性故障是因規格或設計的錯誤等而在特定條件下發生的故障
  2. B隨機硬體故障是因規格或設計的錯誤而在特定條件下發生的故障，系統性故障是使用中機率性發生的故障
  3. C隨機硬體故障是只發生在軟體的故障，系統性故障是只發生在硬體的故障
查看答案與解析

正確答案：A. 隨機硬體故障是使用中因劣化或宇宙射線等而機率性發生的故障，系統性故障是因規格或設計的錯誤等而在特定條件下發生的故障

隨機硬體故障是零件劣化或宇宙射線造成的位元翻轉等，何時發生只能以機率預測的故障，使用故障率（FIT）以SPFM或PMHF等進行定量評估。系統性故障則是因需求遺漏、設計錯誤、軟體臭蟲等所造成，只要相同條件齊備就必定重現。這類故障不以機率評估，而是以依ASIL進行的審查與驗證等開發流程來防止。硬體的設計錯誤也屬於系統性故障。
