影像感測器與光電元件

智慧型手機用高像素影像感測器的像素尺寸，最接近下列何者？

  1. A約1 mm
  2. B約1 µm左右
  3. C約100 µm
查看答案與解析

正確答案：B. 約1 µm左右

智慧型手機用高像素感測器的像素尺寸為1 µm左右，甚至已縮小到約0.6 µm。由於接近可見光的波長（0.4～0.7 µm），光的繞射使聚光變得困難。為了在小像素下維持感光度，除了背照式、DTI、堆疊式之外，還組合了將4個（或9個、16個）同色像素並排、合併使用的四拜耳（Quad Bayer）排列等。數位單眼相機的像素約為4～6 µm。
