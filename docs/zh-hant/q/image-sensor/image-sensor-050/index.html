影像感測器與光電元件

在醫療用X光攝影所使用的間接轉換型平板偵測器中，偵測X光的方法，下列何者正確？

  1. A以透鏡聚集X光並照射到矽上
  2. B以閃爍體將X光轉換為可見光，再以像素的光電二極體偵測該光
  3. C以X光改變磁性體的方向並加以記錄
查看答案與解析

正確答案：B. 以閃爍體將X光轉換為可見光，再以像素的光電二極體偵測該光

矽的光電二極體幾乎無法吸收穿透力強的X光，因此間接轉換型以製成針狀結晶的碘化銫等閃爍體將X光轉換為可見光，再以並排了非晶矽TFT與光電二極體的大面積像素陣列偵測該光。以非晶硒等將X光直接轉換為電荷的直接轉換型，由於沒有光的擴散，解析度優異，用於乳房X光攝影等。

  • A. X光無法以一般的透鏡聚集。
  • B. 正確。以閃爍體轉換為可見光後再偵測。
  • C. 不是以磁性記錄的方式。
