影像感測器與光電元件

關於廣播用攝影機等所使用的「3板式」攝像方式，下列說明何者正確？

  1. A以3個鏡頭拍攝立體影像
  2. B曝光3次並合成亮度
  3. C以稜鏡將光分為紅、綠、藍，並分別由不同的影像感測器接收
查看答案與解析

正確答案：C. 以稜鏡將光分為紅、綠、藍，並分別由不同的影像感測器接收

3板式以分光稜鏡將光分為紅、綠、藍，並以3片影像感測器分別接收各色。由於每個像素都具有所有顏色的資訊，因此不需要色彩內插，也不會以濾光片捨棄光線，所以感光度也高，色彩還原與解析感優異。代價是包含稜鏡的光學系統龐大且昂貴，3片之間也需要對位。其用於廣播用攝影機與部分業務用攝影機。

  • A. 不是拍攝立體影像的方式。
  • B. 不是合成亮度的HDR方式。
  • C. 正確。將光分為3色，並由不同的感測器分別接收。
