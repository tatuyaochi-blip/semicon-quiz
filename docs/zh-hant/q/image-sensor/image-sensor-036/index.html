影像感測器與光電元件

關於CMOS影像感測器的「轉換增益」，下列說明何者正確？

  1. A像素所儲存的每個電子對應的輸出電壓（例如 µV/e⁻）
  2. B鏡頭的放大倍率
  3. C將像素數加倍的倍率
查看答案與解析

正確答案：A. 像素所儲存的每個電子對應的輸出電壓（例如 µV/e⁻）

轉換增益是指轉移至浮動擴散層（FD）的1個電子會成為多少µV的電壓，由 q/C_FD 決定。若FD的電容為1 fF，則約為160 µV/e⁻。增益大時，後級電路雜訊的影響相對變小，對暗處場景較有利，但可處理的電子數會減少。因此採用雙增益方式，切換是否在FD上追加電容，以在暗處與亮處場景分別使用不同的轉換增益。

  • A. 正確。是每個電子的電壓變化。
  • B. 不是鏡頭的放大倍率。
  • C. 與像素數無關。
