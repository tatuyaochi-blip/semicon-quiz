影像感測器與光電元件

許多CMOS影像感測器所採用的、在像素的每一行設置類比數位轉換器並行轉換的方式，其主要優點為下列何者？

  1. A不再需要彩色濾光片
  2. B可使像素大小加倍
  3. C相較於以1個類比數位轉換器依序轉換所有像素，能以較低速的類比數位轉換器實現較高的畫面更新率
查看答案與解析

正確答案：C. 相較於以1個類比數位轉換器依序轉換所有像素，能以較低速的類比數位轉換器實現較高的畫面更新率

行並行（column）ADC方式在像素陣列的每一行並排類比數位轉換器，同時轉換一列份的像素。由於數千行並行運作，每個ADC只需花費一列份的時間（數µs）轉換即可，以低速、低耗電、低雜訊的電路，就能整體實現高畫面更新率。常使用以比較器與計數器進行轉換的單斜率型，而修正各行的差異很重要。

  • A. 要獲得顏色資訊，仍需要彩色濾光片。
  • B. 與像素的大小無關。
  • C. 正確。藉由並行轉換而達到高速化。
