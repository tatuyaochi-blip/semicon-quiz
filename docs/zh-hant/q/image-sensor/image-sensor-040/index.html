影像感測器與光電元件

為了抑制拍攝細密條紋的被攝體時，因與像素排列干涉而出現原本不存在的紋路（摩爾紋），有時會置於感測器前方的零件為下列何者？

  1. A光學低通濾光片
  2. B微透鏡
  3. C偏光片
查看答案與解析

正確答案：A. 光學低通濾光片

比像素間隔更細的紋路無法被正確呈現，會因折疊（混疊）而出現摩爾紋與偽色。光學低通濾光片利用雙折射的水晶板等，將光稍微向2個方向偏移而模糊化，濾除過於細微的成分。相對地，由於解析感會下降，在像素數夠多的相機，或能以影像處理修正偽色的相機中，越來越常省略不用。

  • A. 正確。將光稍微模糊化，濾除過於細微的成分。
  • B. 微透鏡是用來將光聚集到像素受光部的元件。
  • C. 偏光片是讓特定方向的偏振光通過的元件，並非摩爾紋對策。
