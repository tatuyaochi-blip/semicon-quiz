影像感測器與光電元件

關於影像感測器像素的「開口率（填充因子）」之意義，下列何者正確？

  1. A鏡頭光圈的大小
  2. B有效畫素數相對於畫素數的比例
  3. C像素面積中，接收光並轉換為電荷的部分所占的比例
查看答案與解析

正確答案：C. 像素面積中，接收光並轉換為電荷的部分所占的比例

開口率是1個像素的面積中，能作為光電二極體接收光的部分所占的比例。若電晶體或配線多，開口率就會下降，感光度也隨之降低。早期的CMOS感測器開口率僅有30%左右，相較於CCD較為不利。藉由微透鏡聚光來提高有效開口率，再加上背照式使配線離開光路，實質上已能達到接近100%的受光。

  • A. 鏡頭光圈以F值表示，與像素的開口率是不同的東西。
  • B. 是與有效畫素數比例不同的指標。
  • C. 正確。是像素中可受光的面積比例。
