影像感測器與光電元件

從改變亮度所拍攝影像的訊號平均值與離散程度（變異數）的關係，求出影像感測器轉換增益等的評估方法為下列何者？

  1. AC-V量測
  2. B光子轉移曲線（PTC）法
  3. C四點探針法
查看答案與解析

正確答案：B. 光子轉移曲線（PTC）法

就光子的散粒雜訊而言，訊號電子數的變異數等於平均值（帕松分布）。因此將以各種亮度的均勻光所拍攝影像的輸出（DN）的平均值與變異數繪圖，由 變異數 = 平均值 × (1/K) 的關係，即可由斜率求得每個電子的輸出K（轉換增益）。讀出雜訊、飽和電子數、動態範圍也都能由這一項量測評估，是感測器評估的標準手法。

  • A. C-V量測是由電容與電壓的關係評估MOS結構等的方法。
  • B. 正確。由平均值與變異數的關係求出轉換增益。
  • C. 四點探針法是精密量測電阻的方法。
