影像感測器與光電元件

在將人或物體的溫度轉為影像的熱像儀中，主要用於偵測的紅外線波長帶為下列何者？

  1. A約0.4～0.7 µm（可見光）
  2. B約8～14 µm（長波長紅外線）
  3. C約0.01 µm（極紫外光）
查看答案與解析

正確答案：B. 約8～14 µm（長波長紅外線）

依據維因位移定律（λmax ≈ 2898/T µm），常溫（約300 K）物體的熱輻射在波長約10 µm處最強。此外，8～14 µm波段是大氣吸收較少的「大氣窗口」，因此熱像儀偵測的就是這種長波長紅外線。矽不會吸收此波長，因此使用微測輻射熱計這類熱型感測器，或是將HgCdTe等冷卻後使用的量子型感測器。

  • A. 可見光不用於量測物體的溫度。
  • B. 正確。使用常溫熱輻射較強的8～14 µm波段。
  • C. 極紫外線是EUV曝光所使用的波長。
