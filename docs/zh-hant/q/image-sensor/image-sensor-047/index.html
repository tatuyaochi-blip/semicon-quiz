影像感測器與光電元件

在CMOS影像感測器中，從光電二極體到浮動擴散層的電荷轉移不完全時，會發生的問題為下列何者？

  1. A前一個畫面的電荷殘留，影響下一張影像，產生殘影（延遲）
  2. B彩色濾光片的顏色改變
  3. C像素數減少
查看答案與解析

正確答案：A. 前一個畫面的電荷殘留，影響下一張影像，產生殘影（延遲）

在4電晶體像素中，前提是要將曝光時儲存的電荷，以轉移閘極全部移到浮動擴散層。若在光電二極體與轉移閘極之間存在電位障壁或凹陷，電荷就會被遺留，並加到下一個畫面的訊號上而形成殘影（影像延遲）。遺留的量每次都會漲落，因此也會成為雜訊的原因。可藉由雜質分布的設計，製作出使電荷自然流向轉移閘極的電位梯度來防止。

  • A. 正確。遺留的電荷會形成殘影。
  • B. 轉移的問題不會使濾光片的顏色改變。
  • C. 像素數不會改變。
