影像感測器與光電元件

與CCD影像感測器相比，CMOS影像感測器的一般特長，下列何者正確？

  1. A依序傳輸像素的電荷，並由1處輸出部讀出
  2. B容易將周邊電路整合在同一晶片上，且耗電量小
  3. C無法使用CMOS製程進行製造
查看答案與解析

正確答案：B. 容易將周邊電路整合在同一晶片上，且耗電量小

CMOS影像感測器每個像素都有放大用電晶體，可用一般的CMOS製程製造，因此容易將類比數位轉換器與影像處理電路整合於同一晶片或堆疊的晶片上，具有低電壓、低耗電的特點，讀出速度也快。CCD是依序傳輸電荷並由1處輸出部讀出的方式，雖然雜訊少，但需要高驅動電壓與專用製程，目前以CMOS為主流。
