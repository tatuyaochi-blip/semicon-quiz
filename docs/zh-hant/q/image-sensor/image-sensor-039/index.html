影像感測器與光電元件

接收到極亮的光的像素，其電荷溢出，使周圍像素也變白並擴散成像的現象，稱為什麼？

  1. A零串擾
  2. B光暈（blooming）
  3. C滾動快門變形
查看答案與解析

正確答案：B. 光暈（blooming）

當超過像素飽和電荷量的強光照射時，溢出的電荷會流入相鄰像素，使明亮部分擴散到周圍成像。這就是光暈（blooming），在CCD中，沿傳輸方向有時還會出現垂直的條紋（拖影，smear）。在CMOS中，則以將溢出電荷排向電源的溢出汲極，或透過重置電晶體的排出路徑來抑制。在HDR中，反而也有將溢出電荷儲存到另一個電容中加以利用的方式。

  • A. 沒有這樣名稱的現象。
  • B. 正確。是溢出的電荷擴散到周圍的現象。
  • C. 滾動快門變形是因各列的曝光時刻錯開，使移動的被攝體變形的現象。
