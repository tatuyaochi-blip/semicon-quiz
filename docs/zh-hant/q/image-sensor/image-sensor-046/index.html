影像感測器與光電元件

僅偵測每個像素亮度的變化，並僅將有變化的像素資訊以非同步方式輸出的影像感測器為下列何者？

  1. A線型感測器
  2. BCCD影像感測器
  3. C事件式視覺感測器
查看答案與解析

正確答案：C. 事件式視覺感測器

事件式視覺感測器並非每隔固定畫面就讀取所有像素，而是只有亮度變化達一定程度以上的像素，才會將其位置、時刻與增減方向作為事件以非同步方式輸出。沒有動作的背景不會產生資料，因此資料量少，並能獲得微秒等級的時間解析度與120 dB以上的動態範圍。其用於高速物體的追蹤、工廠的振動監視、機器人的視覺等。

  • A. 線型感測器是將像素排成1列的感測器，用於掃描器等。
  • B. CCD是每個畫面依序傳輸並讀出所有像素的電荷。
  • C. 正確。僅以非同步方式輸出有變化的像素。
