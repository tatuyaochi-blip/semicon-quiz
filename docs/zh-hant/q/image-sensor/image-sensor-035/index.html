影像感測器與光電元件

在暗處拍攝的影像看起來粗糙（雜訊明顯），其主要原因為下列何者？

  1. A因為變暗時影像感測器的像素數會減少
  2. B因為變暗時光的波長會變長
  3. C因為進入像素的光子數少，雜訊相對於訊號變得較大
查看答案與解析

正確答案：C. 因為進入像素的光子數少，雜訊相對於訊號變得較大

在暗處，到達像素的光子少而訊號變小，但光子數的漲落（散粒雜訊，√N）與讀出電路的雜訊仍然存在，因此訊噪比下降，影像變得粗糙。即使提高ISO感光度，也只是將訊號與雜訊一起放大。因此會以大型感測器或明亮的鏡頭收集更多光，或是疊合多張影像取平均（夜景模式）等方法來改善訊噪比。

  • A. 像素數不會因亮度而改變。
  • B. 光的波長不會因為變暗而改變。
  • C. 正確。訊號變小，訊噪比因而下降。
