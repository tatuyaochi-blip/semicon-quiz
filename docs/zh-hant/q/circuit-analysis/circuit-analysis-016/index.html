電路分析（交流電路、線性電路與暫態現象）

在圖(b)的RC高通濾波器輸入角頻率 ω = 1/(RC) 的正弦波。輸出相對於輸入的振幅與相位關係，下列哪一項正確？

  1. A振幅約為0.71倍，輸出比輸入落後45°
  2. B振幅約為0.71倍，輸出比輸入超前45°
  3. C振幅為0.5倍，輸出與輸入同相
查看答案與解析

正確答案：B. 振幅約為0.71倍，輸出比輸入超前45°

解法1（複數）：轉移函數為 H(jω) = jωRC/(1 + jωRC)，ωRC = 1 時 H = j/(1 + j) = (1 + j)/2。大小為 1/√2 ≈ 0.71（−3 dB），角度為 +45°，因此輸出比輸入超前45°。解法2（相量圖）：RC串聯電路呈電容性，電流比輸入電壓超前，ω = 1/(RC) 時 R 與 1/(ωC) 相等，超前角正好是45°。輸出是R上的電壓，與電流同相，因此輸出也比輸入超前45°。在相同頻率下，圖(a)低通濾波器的輸出則落後45°。

  • A. 大小正確，但落後45°的是圖(a)的低通濾波器。
  • B. 正確。H = (1 + j)/2，約0.71倍、超前45°。
  • C. 這是不考慮相位、把電壓平分給 R 與 1/(ωC) 的錯誤。兩個電壓互成直角，各為輸入的 1/√2 倍。
