電路分析（交流電路、線性電路與暫態現象）

在圖中的串聯RLC電路，L = 1 mH、C = 0.1 µF、R = 50 Ω。阻尼比 ζ 與步級響應種類的組合，下列哪一項正確？

  1. Aζ = 0.25，欠阻尼（阻尼振盪）
  2. Bζ = 0.50，欠阻尼（阻尼振盪）
  3. Cζ = 4.0，過阻尼
查看答案與解析

正確答案：A. ζ = 0.25，欠阻尼（阻尼振盪）

解法1（與標準形比較）：特性方程式為 s² + (R/L)s + 1/(LC) = 0，與標準形 s² + 2ζωn s + ωn² 比較得 ωn = 1/√(LC) = 1×10⁵ rad/s、2ζωn = R/L。由此 ζ = (R/2)√(C/L) = 25 × √(0.1×10⁻⁶/1×10⁻³) = 25 × 0.01 = 0.25。解法2（與臨界電阻的比）：臨界阻尼的電阻為 2√(L/C) = 200 Ω，因此也可由 ζ = R/(2√(L/C)) = 50/200 = 0.25 求得。ζ < 1，步級響應會超過最終值，並一邊振盪一邊收斂，為欠阻尼。

  • A. 正確。ζ = 50/200 = 0.25，為欠阻尼。
  • B. R√(C/L) = 0.5 忘了 ζ 公式中的1/2。
  • C. 4.0 是 ζ 的倒數，把 √(L/C) 與 √(C/L) 弄反了。
