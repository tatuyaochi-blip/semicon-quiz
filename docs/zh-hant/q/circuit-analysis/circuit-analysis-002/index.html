電路分析（交流電路、線性電路與暫態現象）

阻抗為 Z = 3 + j4 [Ω] 的負載，其導納 Y 為下列哪一項？

  1. A0.12 − j0.16 S
  2. B0.12 + j0.16 S
  3. C約0.33 − j0.25 S
查看答案與解析

正確答案：A. 0.12 − j0.16 S

解法1（分母有理化）：將 Y = 1/(3 + j4) 的分子與分母同乘共軛複數 3 − j4，得 Y = (3 − j4)/(3² + 4²) = (3 − j4)/25 = 0.12 − j0.16 S。解法2（極座標形式）：|Z| = √(3² + 4²) = 5 Ω，角度約53.1°，因此 Y = (1/5)∠−53.1° = 0.2∠−53.1° S，換成直角座標形式同樣是 0.12 − j0.16 S。阻抗為電感性（虛部為正）時，導納的虛部（電納）為負。

  • A. 正確。(3 − j4)/25 = 0.12 − j0.16 S。
  • B. 虛部的符號相反。計算 1/(a + jb) 時要乘上共軛複數，因此虛部的符號會反轉。
  • C. 這是把實部與虛部分別取倒數的 1/3 − j(1/4)，不是複數倒數的正確算法。
