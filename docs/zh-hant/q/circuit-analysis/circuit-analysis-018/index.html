電路分析（交流電路、線性電路與暫態現象）

在圖中的並聯RLC電路，R = 20 kΩ、L = 1 mH、C = 10 nF。在共振頻率附近，電路阻抗大小降為共振時 1/√2 的兩個頻率之差（頻寬）最接近下列哪一項？

  1. A約800 Hz
  2. B約50 kHz
  3. C約3.2 MHz
查看答案與解析

正確答案：A. 約800 Hz

解法1（由Q值）：共振頻率為 f0 = 1/(2π√(LC)) ≈ 50.3 kHz。並聯共振電路的Q值為 Q = R√(C/L) = 20×10³ × √(10×10⁻⁹/1×10⁻³) ≈ 63.2，頻寬為 BW = f0/Q ≈ 50.3 kHz/63.2 ≈ 796 Hz。解法2（直接由導納）：使 Y = 1/R + j(ωC − 1/(ωL)) 虛部大小等於實部 1/R 的兩個角頻率之差為 1/(RC)，因此 BW = 1/(2πRC) = 1/(2π × 20×10³ × 10×10⁻⁹) ≈ 796 Hz。並聯共振時R越大，Q值越高，頻寬越窄。

  • A. 正確。BW = 1/(2πRC) ≈ 796 Hz。
  • B. 約50 kHz 是共振頻率 f0 本身。
  • C. 約3.2 MHz 是套用串聯共振電路公式 BW = R/(2πL) 的值。並聯共振時R的作用相反，Q = R√(C/L)。
