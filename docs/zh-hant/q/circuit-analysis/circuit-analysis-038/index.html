電路分析（交流電路、線性電路與暫態現象）

在圖(a)的RC低通濾波器，R = 1 kΩ、C = 1 µF。轉移函數 H(s) = Vout(s)/Vin(s) 的極點為下列哪一項？

  1. As = −1,000 s⁻¹
  2. Bs = −159 s⁻¹
  3. Cs = −0.001 s⁻¹
查看答案與解析

正確答案：A. s = −1,000 s⁻¹

解法1（由轉移函數）：由分壓公式得 H(s) = (1/(sC))/(R + 1/(sC)) = 1/(1 + sRC)，使分母為0的 s = −1/(RC) 即為極點。RC = 1×10³ × 1×10⁻⁶ = 1×10⁻³ s，因此極點為 s = −1,000 s⁻¹。解法2（與時間響應的對應）：極點 s = −a 對應步級響應等的 e^(−at) 項，由RC電路的響應 e^(−t/RC) 可讀出極點為 −1/τ = −1/(1 ms)。極點的大小1,000 rad/s 就是截止角頻率，換成頻率約為159 Hz。

  • A. 正確。s = −1/(RC) = −1,000 s⁻¹。
  • B. 159 是截止頻率 1000/(2π) ≈ 159 Hz 的數值。s平面上的極點以角頻率的單位（s⁻¹ = rad/s）表示。
  • C. 0.001 是時間常數 RC = 1 ms 的值，極點是其倒數再加上負號。
