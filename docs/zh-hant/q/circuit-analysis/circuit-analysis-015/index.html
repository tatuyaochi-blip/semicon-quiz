電路分析（交流電路、線性電路與暫態現象）

在圖(a)的RC低通濾波器輸入角頻率 ω = 10/(RC) 的正弦波。輸出振幅相對於輸入振幅的比（增益）最接近下列哪一項？

  1. A−20 dB
  2. B−10 dB
  3. C−3 dB
查看答案與解析

正確答案：A. −20 dB

解法1（以複數計算）：轉移函數為 H(jω) = 1/(1 + jωRC)，ωRC = 10 時 |H| = 1/√(1 + 10²) = 1/√101 ≈ 0.0995。換成分貝為 20 log10 0.0995 ≈ −20.0 dB，相位為 −tan⁻¹ 10 ≈ −84.3°。解法2（波德圖的折線近似）：在截止角頻率 ωc = 1/(RC) 以上，增益以 −20 dB/dec 下降。ω = 10ωc 正好比截止角頻率高1個十倍頻（1 decade），因此可讀出約 −20 dB。在截止頻率附近，折線近似最多有3 dB的誤差，但離得越遠就越吻合。

  • A. 正確。|H| ≈ 0.0995，約 −20 dB。
  • B. 這是求出振幅比約1/10後，用 10 log10 把電壓比換成dB的錯誤。電壓比要用 20 log10 表示。
  • C. −3 dB 是截止角頻率 ω = 1/(RC) 時的值。
