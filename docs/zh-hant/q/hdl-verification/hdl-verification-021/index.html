硬體描述語言與驗證

在上方狀態機的描述中，於第2個always區塊開頭寫「next = state;」的原因，下列何者正確？

always @(posedge clk)
    state <= next;
always @(*) begin
    next = state;
    case (state)
        IDLE: if (start) next = RUN;
        RUN:  if (done)  next = IDLE;
    endcase
end
  1. A表示不符合條件時就停留在目前的狀態，並在所有情況下都決定next的值以防止閂鎖器
  2. B為了每次都讓狀態回到IDLE
  3. C為了停止時脈
查看答案與解析

正確答案：A. 表示不符合條件時就停留在目前的狀態，並在所有情況下都決定next的值以防止閂鎖器

將狀態機分成更新狀態的暫存器區塊與決定下一個狀態的組合電路區塊來撰寫，是常見的形式。在組合電路這一側，若start或done為0時沒有對next賦值，就會產生閂鎖器。若在開頭寫「next = state;」，就能清楚表達「不符合任何條件時停留在目前的狀態」的意圖，同時防止閂鎖器。

  • A. 正確。先決定了預設值。
  • B. 意思是保持目前的狀態，並不是回到IDLE。
  • C. 與時脈無關。
