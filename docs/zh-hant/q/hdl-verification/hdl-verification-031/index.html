硬體描述語言與驗證

關於在HDL中輸出Z（高阻抗）的三態描述，一般而言下列何者正確？

  1. A晶片內部的訊號，通常全部都以三態來製作
  2. B用於與晶片外部相連的雙向端子等，晶片內部的訊號通常使用多工器
  3. CZ與0的意思相同，所以在任何地方使用都一樣
查看答案與解析

正確答案：B. 用於與晶片外部相連的雙向端子等，晶片內部的訊號通常使用多工器

三態是用來切斷輸出，使多個電路共用一條線的機制，用於外部匯流排或記憶體資料線這類雙向端子。若在晶片內部使用，會有同時被2個驅動而衝突的危險，或是沒有人驅動而浮接的危險，時序分析也會變得困難。因此在內部，一般是採用以多工器選擇訊號的描述。

  • A. 在內部，一般是以多工器來選擇。
  • B. 正確。內部的三態會使時序與驗證變得困難。
  • C. Z是未被任何地方驅動的狀態，與0不同。
