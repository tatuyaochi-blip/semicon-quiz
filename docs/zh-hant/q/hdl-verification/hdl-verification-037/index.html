硬體描述語言與驗證

將模擬的結果輸出成VCD等格式的檔案，其主要目的為何？

  1. A以波形顯示工具查看訊號值隨時間的變化，調查缺陷的原因
  2. B將電路的設計圖寄送給工廠
  3. C使模擬變快
查看答案與解析

正確答案：A. 以波形顯示工具查看訊號值隨時間的變化，調查缺陷的原因

VCD（Value Change Dump）是記錄模擬期間各訊號的值何時、如何改變的標準檔案格式。以波形顯示工具開啟後，可以沿著時間軸看到每個時脈訊號的變化，因此能追查在哪裡出現了與期望不同的值。記錄所有訊號會使檔案變得非常大，因此有時也會將範圍縮小到想調查的區間或訊號。

  • A. 正確。這是除錯的基本工具。
  • B. 這不是要送給工廠的資料。
  • C. 由於要輸出，模擬反而會變慢。
