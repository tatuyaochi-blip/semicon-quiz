硬體描述語言與驗證

自我檢查型測試平台的特徵，下列何者正確？

  1. A由人以肉眼查看波形，每次判斷是否正確
  2. B自動將輸出與期望值比較，由測試平台本身判定是否一致並回報
  3. C製造電路之後，以實物來確認
查看答案與解析

正確答案：B. 自動將輸出與期望值比較，由測試平台本身判定是否一致並回報

以肉眼查看波形來確認的方法，對於小型電路的確認很方便，但測試數量增加後就會出現疏漏，每次變更也無法重新檢視。自我檢查型測試平台會針對每個輸入計算期望的輸出，或以表格持有，並與電路的輸出自動比較，若有不一致就當作錯誤回報。可以在夜間自動執行成千上萬個測試，只需確認結果即可。

  • A. 那不是自我檢查。
  • B. 正確。可以自動執行大量的測試。
  • C. 是在製造前以模擬來進行。
