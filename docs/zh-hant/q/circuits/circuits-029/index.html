電路與電磁學基礎

有效功率800 W、視在功率1000 VA的交流負載，其虛功率是多少？（電壓、電流為正弦波）

  1. A600 var
  2. B200 var
  3. C1800 var
查看答案與解析

正確答案：A. 600 var

視在功率S、有效功率P與虛功率Q之間有 S² = P² + Q² 的關係（功率三角形）。Q = √(1000² − 800²) = √360000 = 600 var，功率因數為 P/S = 0.8。虛功率只在電源與負載之間往返，平均而言不被消耗，但會增加電流，使配線與變壓器的損失增加。

  • A. 正確。√(1000² − 800²) = 600 var。
  • B. 200 var是直接相減的值，沒有考慮功率三角形。
  • C. 1800 var是直接相加的值。
