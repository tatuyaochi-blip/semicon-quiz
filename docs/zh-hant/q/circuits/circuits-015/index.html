電路與電磁學基礎

貫穿線圈的磁通發生變化時，線圈會產生電動勢（電磁感應）。決定此感應電動勢大小的因素，下列哪一項正確？

  1. A該瞬間磁通的大小
  2. B線圈導線的電阻值
  3. C磁通隨時間變化的快慢與線圈的匝數
查看答案與解析

正確答案：C. 磁通隨時間變化的快慢與線圈的匝數

依法拉第電磁感應定律，感應電動勢的大小為 e = N × ΔΦ/Δt，與匝數N及磁通隨時間變化的快慢成正比。磁通即使很大，若不變化就不會產生電動勢。導線電阻會影響電動勢所驅動的電流大小，但不決定電動勢本身。發電機、變壓器、電磁爐等都利用此原理。

  • A. 磁通即使很大，若不變化也不會產生電動勢。
  • B. 電阻影響流過的電流，但不決定電動勢的大小。
  • C. 正確。e = N × ΔΦ/Δt，與變化快慢及匝數成正比。

電路與電磁學基礎的其他題目

  1. 在12 V直流電源上，從正極側依序串聯電阻R1 = 2 kΩ、R2 = 1 kΩ（R2的另一端接負極）。R2兩端的電壓是多少？（不從輸出取出電流）
  2. 將10 Ω與20 Ω的電阻並聯，總共流入3 A的電流。流過20 Ω電阻的電流是多少？
  3. 在10 V直流電壓源（內阻為0）上串聯電阻R1 = 6 kΩ與R2 = 4 kΩ，以R2兩端為輸出端子。從輸出端子看進去的戴維寧等效電路（等效電壓Vth與等效電阻Rth），下列哪一項正確？
  4. 與電動勢12 V、內阻4 Ω的電壓源等效的諾頓等效電路（電流源與電阻），下列哪一項正確？
  5. 在電動勢10 V、內阻50 Ω的直流電源上接負載電阻RL。改變RL時，負載消耗功率的最大值是多少？
