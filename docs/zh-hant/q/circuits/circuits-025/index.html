電路與電磁學基礎

電阻R = 30 Ω與電抗XL = 40 Ω的線圈串聯的電路，其阻抗大小是多少？（忽略線圈的電阻成分）

  1. A70 Ω
  2. B10 Ω
  3. C50 Ω
查看答案與解析

正確答案：C. 50 Ω

電阻與線圈的電壓相位相差90°，因此不能直接相加，要以複數（向量）合成。Z = R + jXL = 30 + j40 Ω，大小為 √(30² + 40²) = √2500 = 50 Ω。電流比電壓落後 φ = tan⁻¹(40/30) ≈ 53°，功率因數為 cos φ = 30/50 = 0.6。

  • A. 70 Ω是直接相加的值，忽略了相位差。
  • B. 10 Ω是相減的值，合成方法錯誤。
  • C. 正確。√(30² + 40²) = 50 Ω。
