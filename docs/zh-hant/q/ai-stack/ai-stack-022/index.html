AI硬體與軟體堆疊

關於ONNX，下列說明何者正確？

  1. AAI專用半導體晶片的名稱
  2. B壓縮AI訓練資料的方式
  3. C用於在不同框架或推論執行環境之間交換模型的通用模型格式
查看答案與解析

正確答案：C. 用於在不同框架或推論執行環境之間交換模型的通用模型格式

ONNX（Open Neural Network Exchange）是以通用格式表示模型的計算圖與權重的規格。以PyTorch等訓練的模型，只要輸出為ONNX，就能由其他公司的推論執行環境或各種硬體的工具載入並執行。由於能將訓練環境與推論環境分離，因此容易依裝置選擇最佳的執行機制。

  • A. 不是晶片的名稱。
  • B. 不是資料的壓縮方式。
  • C. 正確。是Open Neural Network Exchange的縮寫。
