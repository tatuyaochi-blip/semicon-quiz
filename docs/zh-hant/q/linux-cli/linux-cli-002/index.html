Linux與命令列基礎

關於 Linux 的 /proc 目錄，下列敘述何者正確？

  1. A集中存放核心與各項服務在開機時讀取的設定檔，一般使用者無法寫入的地方
  2. B存放裝置檔的地方，裝置檔把硬碟、USB 隨身碟、終端機等裝置表示成可以像檔案一樣讀寫的形式
  3. C核心以檔案的形式呈現執行中的行程與系統狀態的虛擬檔案系統，內容並未儲存在磁碟上
查看答案與解析

正確答案：C. 核心以檔案的形式呈現執行中的行程與系統狀態的虛擬檔案系統，內容並未儲存在磁碟上

/proc 是稱為 procfs 的虛擬檔案系統，每次讀取檔案時，核心都會產生當下的資訊並傳回。用 cat /proc/cpuinfo 可以查看 CPU 的型號與核心數，用 cat /proc/meminfo 可以查看記憶體的使用狀況，/proc/<行程ID>/ 底下則有各行程的資訊。由於這些檔案並不存在於磁碟上，許多檔案顯示的大小為0。在執行 EDA 工具的伺服器上，也常用來確認 CPU 核心數與記憶體容量。

  • A. 設定檔放在 /etc。/proc 不是用來儲存檔案的地方。
  • B. 裝置檔放在 /dev（/dev/sda、/dev/null 等）。
  • C. 正確。這是每次讀取時由核心產生內容的虛擬檔案系統。
