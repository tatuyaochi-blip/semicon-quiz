Linux與命令列基礎

關於 Linux 的 sudo 指令，下列敘述何者正確？

  1. A加上 sudo 的指令，只要知道 root 的密碼誰都能執行，而且任何地方都不會留下誰執行過的紀錄
  2. B加上 sudo 的指令會由核心給予比其他行程更高的優先順序，可以優先使用 CPU，所以執行得更快
  3. C讓 sudoers 中允許的使用者以另一位使用者（預設為 root）的權限執行指令，預設輸入的是自己的密碼
查看答案與解析

正確答案：C. 讓 sudoers 中允許的使用者以另一位使用者（預設為 root）的權限執行指令，預設輸入的是自己的密碼

root 是基本上不受檔案權限限制、可以操作系統一切的管理者帳號（超級使用者）。sudo 是讓 /etc/sudoers 等處允許的使用者，能逐一以 root 等權限執行指令的機制，預設設定下會以本人的密碼確認，並記錄執行過的指令。與共用 root 密碼、總是以 root 登入相比，更容易追查誰做了什麼，也只在需要時才使用強大的權限。把權限限制在必要最小範圍的想法，是根據資訊安全的最小權限原則。

  • A. 只有 sudoers 中允許的使用者才能使用 sudo，預設設定下會記錄執行過的指令。
  • B. 改變處理的優先順序要用 nice 或 renice。sudo 改變的是權限，速度不會改變。
  • C. 正確。允許的使用者只以另一位使用者的權限執行需要的指令。
