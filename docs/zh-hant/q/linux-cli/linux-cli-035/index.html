Linux與命令列基礎

Linux 伺服器出現「磁碟空間不足」的警告。查詢各檔案系統的使用量與剩餘容量的指令，以及加總查詢目錄中檔案所用容量的指令，下列哪一個組合正確？

  1. Adf 與 du
  2. Bdu 與 df
  3. Cfree 與 du
查看答案與解析

正確答案：A. df 與 du

df（disk free）會依掛載的檔案系統顯示總容量、使用量與剩餘容量，加上 -h 則以 G、M 等單位易讀地顯示。du（disk usage）會加總指定目錄底下的檔案所用的容量，像 du -sh * 這樣使用，可以找出哪個目錄比較大。先用 df 找出已滿的檔案系統，再用 du 縮小範圍找出其中較大的目錄，是常見的步驟。已刪除但仍有行程開啟著的檔案，在 df 中會算作使用中，在 du 中則不計入，因此兩者的值有時對不起來。

  • A. 正確。各檔案系統的剩餘空間用 df，目錄使用量的合計用 du 查詢。
  • B. df 與 du 的作用顛倒了。
  • C. free 顯示的不是磁碟，而是記憶體（主記憶體與 swap）的使用量。
