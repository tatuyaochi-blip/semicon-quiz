Linux與命令列基礎

執行「tar -czf proj.tar.gz proj/」時的動作是下列何者？

  1. A把整個 proj 目錄整合成一個檔案，建立以 gzip 壓縮的 proj.tar.gz
  2. B解開 proj.tar.gz，把其中的檔案取出到 proj 目錄
  3. C把 proj 目錄中的每個檔案分別逐一壓縮成不同的 .gz 檔案
查看答案與解析

正確答案：A. 把整個 proj 目錄整合成一個檔案，建立以 gzip 壓縮的 proj.tar.gz

tar 是把多個檔案與目錄整合成一個檔案（封存檔）的指令，-c 表示建立，-z 表示以 gzip 壓縮，-f 表示接在後面的是封存檔的檔名。原本的 proj 目錄會保持原樣。解開時用 -x 取代 -c，寫成「tar -xzf proj.tar.gz」，查看內容清單則用 -t。單獨使用 gzip 只能壓縮一個檔案，所以要整批傳送目錄時會與 tar 搭配使用。

  • A. 正確。用 -c 建立，用 -z 套用 gzip 壓縮。
  • B. 解開是加上 -x 的時候。-c 是建立封存檔。
  • C. 把檔案逐一壓縮成 .gz 是 gzip -r 的動作。tar 會整合成一個封存檔。
