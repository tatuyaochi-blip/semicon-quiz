量測與分析

對週期性圖案照光，將反射、繞射光的光譜與模型比較，以求出線寬與剖面形狀的量測，稱為什麼？

  1. ASIMS
  2. B散射量測術（光學式CD量測，OCD）
  3. CTEM觀察
查看答案與解析

正確答案：B. 散射量測術（光學式CD量測，OCD）

散射量測術是量測來自測試用週期圖案的反射、繞射光之光譜，將形狀建立模型，並與以電磁場計算得到的光譜比對，藉此求出線寬、高度、側壁角等。它是非破壞且快速，還能取得剖面形狀的資訊，因此廣泛用於量產線的尺寸管理。不過，若未準備正確的模型，就會得出錯誤的答案。SIMS與TEM則是破壞性的分析。
