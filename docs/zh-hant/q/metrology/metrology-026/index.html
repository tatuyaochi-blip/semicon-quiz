量測與分析

以SEM觀察絕緣物試片時，用來防止充電（charge-up）的方法，下列何者正確？

  1. A降低加速電壓，或在試片表面鍍上薄導電膜
  2. B盡可能提高加速電壓
  3. C將試片浸入水中
查看答案與解析

正確答案：A. 降低加速電壓，或在試片表面鍍上薄導電膜

對絕緣物照射電子束時，電荷無法逸散而累積，使影像扭曲或亮度紊亂。降低加速電壓後，入射電子與射出的二次電子數量較容易平衡，充電便會減少。也有在試片表面鍍上金或碳等薄導電膜，或在以氣體分子中和電荷的低真空條件下觀察的方法。提高加速電壓反而容易使充電惡化，而浸入水中則無法在真空中觀察。
