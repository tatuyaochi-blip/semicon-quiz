量測與分析

光學顯微鏡無法直接觀察數十nm的微細圖案，主要的理由是下列何者？

  1. A因為有光的繞射造成的解析度極限（約為光的波長左右）
  2. B因為光學顯微鏡不會有顏色
  3. C因為光學顯微鏡太暗
查看答案與解析

正確答案：A. 因為有光的繞射造成的解析度極限（約為光的波長左右）

光學顯微鏡的解析度受光的繞射限制，大約為0.61λ/NA（λ為波長，NA為數值孔徑）。可見光的波長約為400～700 nm，因此即使在最佳條件下，極限也在200 nm左右，無法分辨數十nm的圖案。因此會使用波長短得多的電子束的SEM或TEM。這不是亮度或顏色的問題。
