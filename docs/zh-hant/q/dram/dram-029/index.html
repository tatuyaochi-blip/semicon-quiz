DRAM

DDR5所採用的、在DRAM晶片內部更正錯誤的功能是哪一個？

  1. A晶片內建ECC（on-die ECC）
  2. B磨損平均（wear leveling）
  3. CTRIM
查看答案與解析

正確答案：A. 晶片內建ECC（on-die ECC）

DDR5為因應微縮導致單元不良與錯誤增加，在DRAM晶片內部內建了錯誤更正電路（on-die ECC）。它在128位元的資料上加8位元的檢查位元，於晶片內部更正單一位元的錯誤。不過，外部只看得到更正後的結果，無法保護資料傳輸過程中的錯誤，因此伺服器仍然需要系統端的ECC。
