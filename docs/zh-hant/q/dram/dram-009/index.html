DRAM

關於記憶體的軟性錯誤（soft error），下列說明何者正確？

  1. A因輻射等使記憶的資料暫時翻轉、不伴隨元件損壞的錯誤
  2. B因製造時的佈線不良造成的永久性故障
  3. C因老化劣化而使元件損壞的故障
查看答案與解析

正確答案：A. 因輻射等使記憶的資料暫時翻轉、不伴隨元件損壞的錯誤

軟性錯誤是指封裝材料釋出的α射線或宇宙射線產生的中子在矽中產生電荷，使記憶的資料翻轉的現象。由於元件並未損壞，重新寫入即可恢復正常。海拔越高中子越多，在飛機內可達地面的數百倍。對策是ECC，也會降低材料中的放射性雜質。因製造不良或劣化造成的永久性故障則是硬性錯誤（hard error）。
