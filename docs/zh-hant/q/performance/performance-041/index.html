效能評估與效能剖析

改善程式效能時的進行方式，下列何者最適當？

  1. A先測量以找出花費時間的地方，改善該處，改善後再測量一次以確認效果
  2. B推測看起來慢的地方，不經測量就改寫
  3. C對所有函式都進行相同程度的最佳化
查看答案與解析

正確答案：A. 先測量以找出花費時間的地方，改善該處，改善後再測量一次以確認效果

對於哪裡慢的推測，即使是有經驗的人也常常猜錯。應先以剖析器或效能計數器測量，查明花費大量時間的地方及其原因（運算、記憶體、分支、輸入輸出等）。加入改善後，再以相同條件測量一次，確認是否真的變快，以及其他部分是否變慢。這樣的反覆過程，就是確實提升效能的方法。

  • A. 正確。反覆進行測量、改善、確認。
  • B. 推測常常會猜錯。
  • C. 將沒有花費時間的部分最佳化是沒有效果的。
