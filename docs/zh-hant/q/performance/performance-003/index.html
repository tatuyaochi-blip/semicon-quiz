效能評估與效能剖析

因CPU設計變更，時脈頻率變為1.5倍，但CPI也增加為1.2倍（指令數相同）。執行速度會變為原來的幾倍？

  1. A1.25倍
  2. B1.5倍
  3. C1.8倍
查看答案與解析

正確答案：A. 1.25倍

執行時間為指令數×CPI÷頻率，所以新的時間為原來的1.2÷1.5 = 0.8倍，速度為1÷0.8 = 1.25倍。加深流水線以提高頻率時，常因分支預測錯誤時的損失等而使CPI增加。只看頻率似乎是1.5倍，但實際效果只有1.25倍。效能必須以三個要素的乘積來判斷。

  • A. 正確。1.5÷1.2 = 1.25。
  • B. 沒有考慮CPI增加的部分。
  • C. 把1.5與1.2相乘了。

效能評估與效能剖析的其他題目

  1. 透過編譯器的新最佳化，執行的指令數減少了20%，但平均CPI增加了10%（頻率相同）。關於這項最佳化的效果，下列何者正確？
  2. 某程式的指令比例為：整數運算50%（CPI 1）、載入與儲存30%（CPI 2）、分支20%（CPI 5）。平均CPI是多少？
  3. 以「每秒可執行的指令數（百萬指令每秒）」來比較CPU的效能時，下列注意事項何者正確？
  4. 表示效能改善程度的「加速比（speedup）」，其求法下列何者正確？
  5. 將占整個處理50%的部分加快為4倍。整體的加速比是多少（阿姆達爾定律）？
