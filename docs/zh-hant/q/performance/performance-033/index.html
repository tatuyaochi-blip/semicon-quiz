效能評估與效能剖析

在使用效能計數器的由上而下分析（Top-down Microarchitecture Analysis）中，將CPU處理指令的槽位使用情形加以區分的大分類，下列何者正確？

  1. A快、慢、普通這三種
  2. B前端停滯、後端停滯、推測白費、正確完成指令（退休，retire）這四種
  3. C磁碟、網路、螢幕、鍵盤這四種
查看答案與解析

正確答案：B. 前端停滯、後端停滯、推測白費、正確完成指令（退休，retire）這四種

在由上而下分析中，將每個週期處理指令的槽位，區分為：因負責取得並解碼指令的前段（前端，frontend）來不及而空著、因運算單元或記憶體等待而在後段（後端，backend）停滯、被用在預測錯誤而丟棄的指令上，以及被用在正確完成的指令上。從最大的分類逐步縮小到更細的原因，就能有效率地找出瓶頸。

  • A. 並不是這樣的分類。
  • B. 正確。從上述分類依序縮小到更細的原因。
  • C. 不是CPU內部的分類。
