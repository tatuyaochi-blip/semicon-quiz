效能評估與效能剖析

關於在函式的入口與出口插入測量時間的程式碼來進行記錄的檢測（instrumentation）式剖析器，下列何者正確？

  1. A記錄的處理完全不花時間
  2. B能準確記錄被呼叫的次數等，但記錄的處理本身會花費時間，尤其在小函式很多的程式中，結果可能會失真
  3. C函式的入口與出口，在任何程式中都不存在
查看答案與解析

正確答案：B. 能準確記錄被呼叫的次數等，但記錄的處理本身會花費時間，尤其在小函式很多的程式中，結果可能會失真

檢測式會記錄所有函式的呼叫，因此能不遺漏且準確地得知次數與呼叫關係。然而，每次呼叫函式都會多出記錄用的處理，所以在大量呼叫小函式的程式中，記錄的時間有時會超過原本處理的時間。因此要區分使用：時間的比例用取樣式，準確的次數用檢測式。

  • A. 因為會執行記錄用的指令，所以要花時間。
  • B. 正確。這是測量改變了被測對象的例子。
  • C. 函式一定有入口與出口。
