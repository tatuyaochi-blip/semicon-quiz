效能評估與效能剖析

評估Web服務的回應時間時，常不只看平均值，還會看第99百分位數（從慢的一端算起1%的分界）的值，其理由下列何者正確？

  1. A即使平均很好，仍可能有部分請求非常慢，而在需要等待許多元件回應的處理中，這些慢的回應會決定整體的緩慢程度
  2. B第99百分位數的值一定比平均小
  3. C因為無法計算平均值
查看答案與解析

正確答案：A. 即使平均很好，仍可能有部分請求非常慢，而在需要等待許多元件回應的處理中，這些慢的回應會決定整體的緩慢程度

回應時間的分布往往呈現大部分很快、只有極少部分非常慢的形狀。只看平均會隱藏這些慢的部分。再者，在顯示一個畫面需要等待100個元件回應的處理中，只要有任何一個慢，整體就會變慢，所以那1%的慢回應會影響大部分的使用者。因此要以慢的一側的值（尾端延遲，tail latency）為目標來管理。

  • A. 正確。這稱為尾端延遲。
  • B. 因為是慢的一側的值，所以通常會比平均大。
  • C. 平均也可以計算，但僅憑平均是不夠的。

效能評估與效能剖析的其他題目

  1. 某伺服器每秒收到100件請求，每件的處理平均花0.2秒（假設為穩態）。伺服器內同時處理中的請求平均有幾件（利特爾法則，Little's law）？
  2. 當伺服器的使用率（忙碌時間的比例）接近100%時，請求的等待時間會如何變化？
  3. 改善程式效能時使用剖析器（profiler）的目的，下列何者正確？
  4. 關於取樣式（sampling）剖析器的特徵，下列何者正確？
  5. 關於在函式的入口與出口插入測量時間的程式碼來進行記錄的檢測（instrumentation）式剖析器，下列何者正確？
