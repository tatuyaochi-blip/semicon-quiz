效能評估與效能剖析

關於取樣式（sampling）剖析器的特徵，下列何者正確？

  1. A完全不遺漏地記錄所有函式的進出
  2. B以固定的間隔中斷程式，記錄當時執行的位置，並將被記錄較多次的位置視為花費時間的位置
  3. C只讀取程式的原始碼，不執行
查看答案與解析

正確答案：B. 以固定的間隔中斷程式，記錄當時執行的位置，並將被記錄較多次的位置視為花費時間的位置

取樣式是透過計時器或效能計數器的中斷，例如每秒記錄數千次執行中指令的位置（以及呼叫的串接）。花費時間越多的位置，被記錄的次數就越多，因此在統計上就能知道哪裡比較重。由於不需要改寫程式，測量造成的延遲小，可在接近實際的狀態下測量，但無法得知極短處理的準確次數等。

  • A. 那是檢測（instrumentation）方式。
  • B. 正確。優點是測量的負擔小。
  • C. 是一邊執行一邊測量。
