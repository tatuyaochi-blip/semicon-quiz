效能評估與效能剖析

關於程式效能分析中所謂熱點（hotspot）的說明，下列何者正確？

  1. A晶片溫度最高的地方
  2. B可以使用無線區域網路的地方
  3. C占用大部分執行時間的、程式中極少部分的程式碼
查看答案與解析

正確答案：C. 占用大部分執行時間的、程式中極少部分的程式碼

在許多程式中，相當於整體程式碼數%的迴圈或函式，占用了大部分的執行時間。這個部分稱為熱點。以剖析器找出熱點，並將演算法的改善與記憶體使用方式的調整集中在那裡，就能以少量的功夫得到很大的效果。相反地，即使把幾乎不被執行的部分最佳化得再好，整體也幾乎不會變快。

  • A. 本題談的是程式。
  • B. 與無線區域網路的熱點意義不同。
  • C. 正確。改善這裡是最有效的。
