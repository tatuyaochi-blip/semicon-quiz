效能評估與效能剖析

只測量一次非常短的處理時間時的問題與對策，下列組合何者正確？

  1. A短的處理不花時間，所以不需要測量
  2. B測量短的處理會使CPU損壞
  3. C相較於計時器的解析度與讀取時間的負擔，處理過短而無法準確測量。應重複執行處理許多次，測量總時間後再除以次數
查看答案與解析

正確答案：C. 相較於計時器的解析度與讀取時間的負擔，處理過短而無法準確測量。應重複執行處理許多次，測量總時間後再除以次數

讀取時間的函式，有時鐘刻度精細程度（解析度）的限制，以及呼叫函式本身所需的時間。若想測量的處理與這些相當或更短，結果幾乎都會是測量的誤差。將處理重複數千次、數萬次，測量整體的時間再除以次數，就能準確估算每次的時間。不過要注意，重複執行會使資料較容易留在快取中，造成與實際使用時的條件不同。

  • A. 即使是短的處理，若被呼叫許多次，也會成為很長的時間。
  • B. CPU不會損壞。
  • C. 正確。可以減小測量負擔的影響。

效能評估與效能剖析的其他題目

  2. 關於表示伺服器效能的吞吐量（throughput）與延遲（latency）的說明，下列何者正確？
  3. 評估Web服務的回應時間時，常不只看平均值，還會看第99百分位數（從慢的一端算起1%的分界）的值，其理由下列何者正確？
  4. 某伺服器每秒收到100件請求，每件的處理平均花0.2秒（假設為穩態）。伺服器內同時處理中的請求平均有幾件（利特爾法則，Little's law）？
  5. 當伺服器的使用率（忙碌時間的比例）接近100%時，請求的等待時間會如何變化？
