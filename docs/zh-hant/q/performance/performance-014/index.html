效能評估與效能剖析

關於SPEC CPU這類標準基準測試的說明，下列何者正確？

  1. A依固定規則執行許多以實際應用程式為基礎的程式，並以與基準電腦的比值彙整後的值來表示效能
  2. B只測量一個加法能做幾次
  3. C基準測試的結果可由製造商自由決定
查看答案與解析

正確答案：A. 依固定規則執行許多以實際應用程式為基礎的程式，並以與基準電腦的比值彙整後的值來表示效能

SPEC CPU是由編譯器、壓縮、物理模擬等許多以實際應用程式為基礎的程式所組成的基準測試。它求出各程式的執行時間與基準電腦的時間之比，再以幾何平均彙整成一個值。編譯器的設定與執行方式也有規則，結果會連同詳細條件一併公開。

  • A. 正確。訂定規則，以便公平比較。
  • B. 它使用許多接近實際程式的程式。
  • C. 是依固定規則測量並回報結果。
