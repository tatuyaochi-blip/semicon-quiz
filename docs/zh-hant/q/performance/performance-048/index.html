效能評估與效能剖析

評估「以新方法加快了100倍」這項主張時，應確認的重點下列何者最適當？

  1. A100這個數字是否為偶數
  2. B提出主張者的名字長度
  3. C比較的對象（基準）是否已充分最佳化，是否以相同的條件、相同的精度進行比較
查看答案與解析

正確答案：C. 比較的對象（基準）是否已充分最佳化，是否以相同的條件、相同的精度進行比較

加速比會因與什麼比較而有很大的改變。若與未經最佳化的舊程式，或是只使用一個核心的程式比較，就容易出現很大的倍率。此外，若資料的大小、精度、測量的範圍（是否包含傳輸時間）等不同，就不能算是公平的比較。要正確評估主張，重要的是確認基準的內容與測量條件是否有清楚說明。

  • A. 數字的性質無關。
  • B. 名字無關。
  • C. 正確。視基準而定，倍率可以被誇大到任意大。

效能評估與效能剖析的其他題目

  1. SSD的效能除了連續讀取的頻寬（MB/s）之外，也常以4 KB隨機讀取的IOPS（每秒輸入輸出的次數）來表示，其理由下列何者正確？
  2. 一邊逐漸增大陣列的大小，一邊測量重複讀取陣列的處理每個元素所需的時間，發現每到某些大小，時間就會階段性增加。其理由下列何者正確？
  3. 下列何者是表示程式在CPU上執行時間的基本公式？
  4. 以平均CPI為2、時脈頻率為2 GHz的CPU，執行一個包含10億個指令的程式。執行時間是多少？
  5. 因CPU設計變更，時脈頻率變為1.5倍，但CPI也增加為1.2倍（指令數相同）。執行速度會變為原來的幾倍？
