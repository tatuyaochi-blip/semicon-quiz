效能評估與效能剖析

以內建於CPU的效能計數器（PMU）可計數的項目，下列何者為正確的例子？

  1. A執行的指令數、快取失誤的次數、分支預測錯誤的次數等
  2. B撰寫程式的人數
  3. C鍵盤的按鍵數
查看答案與解析

正確答案：A. 執行的指令數、快取失誤的次數、分支預測錯誤的次數等

效能計數器是計算CPU內部發生的各種事件的硬體計數器。可由週期數與指令數求得IPC，也能得知各層級的快取失誤、TLB失誤、分支預測錯誤等的次數。可使用Linux的perf等工具，一邊執行程式一邊計數，作為區分花費時間的原因是記憶體、分支，還是運算本身的線索。

  • A. 正確。計算CPU內部發生的事件。
  • B. 無法計算人數。
  • C. 與鍵盤無關。

效能評估與效能剖析的其他題目

  2. 以效能計數器發現分支預測錯誤非常多。下列何者是適用的改善方法？
  3. 在使用效能計數器的由上而下分析（Top-down Microarchitecture Analysis）中，將CPU處理指令的槽位使用情形加以區分的大分類，下列何者正確？
  4. 程式很慢，但CPU使用率只有20%左右。最可能的原因為下列何者？
  5. 為了確認某程式是運算受限（compute-bound）還是記憶體受限（memory-bound），改變CPU的頻率來測量執行時間。若為記憶體受限，一般會得到怎樣的結果？
