效能評估與效能剖析

以「每秒可執行的指令數（百萬指令每秒）」來比較CPU的效能時，下列注意事項何者正確？

  1. A指令集不同時，一個指令能完成的工作量也不同，所以即使指令數較多，也不一定能更快完成同一個程式
  2. B這個值較大的CPU，無論什麼程式一定都比較快
  3. C這個值表示記憶體的容量
查看答案與解析

正確答案：A. 指令集不同時，一個指令能完成的工作量也不同，所以即使指令數較多，也不一定能更快完成同一個程式

每秒的指令數是容易理解的指標，但指令集不同，完成同樣工作所需的指令數也不同。使用大量簡單指令的CPU，這個值容易變大，但實際處理不一定較快。即使是相同的指令集，若程式的指令組成不同，值也會改變。比較效能最可靠的方法，是執行同一個程式並測量時間。

  • A. 正確。該比較的是完成同樣工作所花的時間。
  • B. 結果會因指令的內容與程式而改變。
  • C. 與記憶體的容量無關。
