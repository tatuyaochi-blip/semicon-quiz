效能評估與效能剖析

因為加入了測量效能的機制，而使想測量的程式本身的行為改變，這種現象稱為什麼？

  1. A快取一致性（cache coherency）
  2. B探針效應（觀測效應，probe effect）
  3. C流水線處理
查看答案與解析

正確答案：B. 探針效應（觀測效應，probe effect）

輸出日誌、插入測量時間的程式碼、以除錯器暫停等測量用的處理，本身就會消耗時間與快取，並改變時序。因此，測得的結果可能與不測量時的行為不同，像資料競爭（data race）這類取決於時序的錯誤，也可能只在測量時消失。選擇取樣或效能計數器這類影響較小的方法，並確認測量影響的大小，是很重要的。

  • A. 指的是快取一致性的機制。
  • B. 正確。需要想辦法減小測量的影響。
  • C. 指的是重疊執行指令的機制。
