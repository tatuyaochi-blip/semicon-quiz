效能評估與效能剖析

在筆記型電腦上測量基準測試，結果發現即使是同一個程式，每次的結果也有很大的變動。下列關於CPU方面可能原因與其對策的組合，何者正確？

  1. ACPU的指令集每次都會改變。固定指令集
  2. BCPU的核心數每次都會改變。增加核心
  3. C渦輪（turbo）運作與溫度造成的頻率變化。固定頻率，或在溫度穩定的條件下測量
查看答案與解析

正確答案：C. 渦輪（turbo）運作與溫度造成的頻率變化。固定頻率，或在溫度穩定的條件下測量

近年的CPU會依溫度與電力的餘裕自動調升或調降頻率。從冷卻的狀態開始時，會因渦輪運作而較快，持續運作後溫度上升，頻率就會下降，因此即使是同一個程式，每次測量的結果也會不同。要正確看出想比較的變更所帶來的效果，需要固定頻率、統一電源設定、等到溫度穩定、多次測量並取統計等作法。

  • A. 指令集不會每次執行都改變。
  • B. 核心數不會改變。
  • C. 正確。電源的設定也會影響結果。
