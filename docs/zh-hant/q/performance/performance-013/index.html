效能評估與效能剖析

以基準測試（benchmark）評估電腦的效能時，下列想法何者最適當？

  1. A以接近實際用途的程式來測量，並以其結果進行比較
  2. B無論什麼用途，都只以一個小迴圈的速度來決定
  3. C只以製造商公布的時脈頻率來決定
查看答案與解析

正確答案：A. 以接近實際用途的程式來測量，並以其結果進行比較

某部電腦是否夠快，會因用途而異。整數處理、浮點運算、大量使用記憶體的處理、大量輸入輸出的處理等，各自擅長的工作都不同。因此，以盡可能接近實際用途的程式，或是彙整許多代表性程式的標準基準測試來測量，並在條件相同的情況下進行比較，是很重要的。

  • A. 正確。哪一部電腦比較快會因用途而異。
  • B. 小迴圈的結果可能與實際用途有很大的差異。
  • C. 僅憑頻率無法決定效能。
