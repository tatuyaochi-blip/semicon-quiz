AD/DA轉換

8位元的ADC（類比數位轉換器）能表示的輸出階數是多少？

  1. A8階
  2. B256階
  3. C1024階
查看答案與解析

正確答案：B. 256階

N位元的轉換器可表示2ᴺ階，8位元即2⁸ = 256階。每增加1位元，階數就加倍，10位元為1024、12位元為4096、16位元為65536階。例如將3.3 V以8位元轉換時，每階約為13 mV，若為12位元則約0.8 mV。用途的參考標準為：微控制器內建的是10～12位元，音訊是16～24位元，量測則是24位元等級。
