AD/DA轉換

下列何者最適合作為DAC的使用例？

  1. A讀取溫度感測器的電壓並取入微控制器
  2. B將數位聲音資料轉為可由喇叭播放的類比訊號
  3. C將相機影像感測器的像素電壓轉為數值
查看答案與解析

正確答案：B. 將數位聲音資料轉為可由喇叭播放的類比訊號

DAC將數位值轉換為類比電壓或電流。代表例是將數位聲音還原為可由放大器與喇叭播放的訊號，此外也用於無線發射訊號的產生、顯示器的灰階電壓、馬達控制的指令值，以及ADC內部比較電壓的產生。輸出會呈階梯狀，因此以後級的低通濾波器（重建濾波器）使其平滑。將感測器電壓轉為數值的是ADC。

  • A. 將感測器電壓轉為數值是ADC的作用。
  • B. 正確。將數位聲音轉換為類比訊號的是DAC。
  • C. 將像素電壓轉為數值是ADC的作用。
