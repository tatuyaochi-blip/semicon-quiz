音樂CD的取樣頻率為下列何者？

  1. A44.1 kHz
  2. B8 kHz
  3. C1 MHz
查看答案與解析

正確答案：A. 44.1 kHz

音樂CD以44.1 kHz、16位元、2聲道記錄，資料量約為1.4 Mb/s。這個數值略高於可聽範圍上限約20 kHz的2倍，據說是由當時容易記錄在專業錄影設備上的數值決定的。16位元的動態範圍約為96 dB。廣播與影像使用48 kHz，高解析音源使用96 kHz或192 kHz、24位元，電話語音則使用8 kHz。

  • A. 正確。CD以44.1 kHz取樣。
  • B. 8 kHz是電話語音等使用的值，用於音樂太低。
  • C. 1 MHz遠高於CD的規格。
