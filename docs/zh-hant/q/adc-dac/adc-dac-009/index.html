AD/DA轉換

關於R-2R梯形（ladder）式DAC的特徵，下列何者正確？

  1. A只需兩種電阻值（R與2R）即可構成，所需的電阻值種類少
  2. B僅由電容構成
  3. C使用線圈切換電流
查看答案與解析

正確答案：A. 只需兩種電阻值（R與2R）即可構成，所需的電阻值種類少

R-2R梯形式將電阻R與2R組成梯狀，利用從各節點看進去的電阻處處相等的性質，逐位元將電流對半分配。即使位元數增加，電阻值也只需兩種，而且將兩個相同電阻串聯即可做出2R，因此優點是容易使比值的精度一致。精度取決於電阻的匹配，位元越高需要越高的精度。
