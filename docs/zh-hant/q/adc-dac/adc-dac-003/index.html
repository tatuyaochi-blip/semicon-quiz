AD/DA轉換

關於快閃式（Flash）ADC的特徵，下列何者正確？

  1. A並聯排列大量比較器，一次完成轉換，因此速度快，但提高解析度時電路規模會急遽增加
  2. B逐位元依序比較來進行轉換，因此速度慢但電路小
  3. C對輸入電壓進行長時間積分，因此精度高但轉換慢
查看答案與解析

正確答案：A. 並聯排列大量比較器，一次完成轉換，因此速度快，但提高解析度時電路規模會急遽增加

快閃式以2ᴺ−1個比較器同時將輸入與所有臨界值比較，一次比較即完成轉換，是最快的方式（可達數GS/s等級）。代價是N位元需要2ᴺ−1個比較器，8位元為255個、10位元為1023個，急遽增加，面積、功耗與輸入電容都會變大。因此用於6～8位元左右的超高速用途，也被用作管線式與子範圍式的組成元件。
