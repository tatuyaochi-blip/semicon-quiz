AD/DA轉換

關於數位電錶等常用的雙斜率（雙積分）式ADC的特徵，下列何者正確？

  1. A排列大量比較器，因此最快
  2. B一次比較就完成轉換
  3. C轉換慢但精度高，且藉由積分不易受雜訊影響
查看答案與解析

正確答案：C. 轉換慢但精度高，且藉由積分不易受雜訊影響

雙斜率式先對輸入積分一定時間，接著以參考電壓反向積分，計算回到0所需的時間。積分器的RC與時脈的誤差對兩次積分的影響相同而抵消，因此精度高。將積分時間設為電源週期（50/60 Hz）的整數倍，還能去除由電源感應的交流雜訊（哼聲）。一次轉換需要數十ms以上，因此用於數位電錶等低速量測儀器。
