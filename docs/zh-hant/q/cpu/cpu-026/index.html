CPU與架構

為了降低 CPU 的功耗，依負載動態改變工作頻率與電源電壓的技術是下列何者？

  1. ADVFS（動態電壓頻率調整）
  2. B超頻
  3. CSIMD
查看答案與解析

正確答案：A. DVFS（動態電壓頻率調整）

DVFS 是在處理較輕時降低頻率與電源電壓、較重時則提高的技術。由於動態功耗與電壓的平方及頻率成正比，因此同時降低電壓與頻率時，功耗大約以三次方的幅度減少。例如將頻率降低 2 成、電壓也降低 1 成，功耗約可減少 35%。作業系統或韌體會觀察負載與溫度，以數 ms 為單位進行切換，支撐著智慧型手機與筆記型電腦的電池續航力。
