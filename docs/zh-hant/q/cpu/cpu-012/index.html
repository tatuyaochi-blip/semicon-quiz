CPU與架構

關於 RISC-V 的特徵，下列何者正確？

  1. A是只有特定一家公司才能使用的專用指令集
  2. B是 GPU 專用的指令集
  3. C是規格公開、無需授權費即可使用的指令集架構
查看答案與解析

正確答案：C. 是規格公開、無需授權費即可使用的指令集架構

RISC-V 是 2010 年起於加州大學柏克萊分校開始開發的開放式 ISA，規格公開，任何人都能免授權費地實作。基本的整數指令約 40 個，相當精簡，可依用途選擇並組合浮點數、向量等擴充。由於也能新增自訂指令，因此在嵌入式微控制器、儲存裝置的控制器、AI 加速器等領域的採用日益普及。
