CPU與架構

在 AI 用加速器等中，將多個乘加運算單元排列成格狀，讓資料依序流向相鄰運算單元的同時計算矩陣乘積的架構是下列何者？

  1. A脈動陣列（systolic array）
  2. B交叉開關（crossbar switch）
  3. C環形緩衝區（ring buffer）
查看答案與解析

正確答案：A. 脈動陣列（systolic array）

脈動陣列是將乘加運算單元（MAC）以二維方式排列，並讓資料規律地傳送到相鄰運算單元的同時進行計算的架構，其名稱源自心臟收縮（systole）將血液送出的比喻。讀入一次的資料可由多個運算單元重複使用，因此能減少對記憶體的存取，有效率地進行矩陣運算。Google 的 TPU 配備了 128×128 等大型陣列。

  • A. 正確。將運算單元排成格狀，邊流動資料邊計算。
  • B. 交叉開關是可自由切換連接多個輸入與輸出的連接電路。
  • C. 環形緩衝區是循環使用的資料儲存區域。
