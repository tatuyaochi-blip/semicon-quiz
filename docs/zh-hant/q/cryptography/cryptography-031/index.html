密碼學基礎與應用

關於相互TLS（mTLS）的說明，正確的是下列何者？

  1. A把TLS的加密重疊進行兩次，使加密強度加倍的方式
  2. B在1個連線中，同時使用TLS 1.2與TLS 1.3兩種協定的方式
  3. C不只伺服器，用戶端也出示憑證，雙方互相驗證對方的方式
查看答案與解析

正確答案：C. 不只伺服器，用戶端也出示憑證，雙方互相驗證對方的方式

一般的TLS中，用戶端只確認伺服器的憑證，用戶端的驗證則以密碼或權杖等TLS之上的機制進行。相互TLS中，伺服器也要求用戶端提供憑證，用戶端傳送憑證，以及以對應的私密金鑰產生的簽章。常用於微服務之間的通訊、IoT設備與伺服器的連線、基於零信任概念的網路等沒有人操作的機器之間的驗證。

  • A. 這不是重疊加密的方式。「相互」表示驗證是雙向的。
  • B. 1個連線使用的TLS版本只有1個，由交握決定。
  • C. 正確。用戶端也以憑證與私密金鑰進行驗證。
