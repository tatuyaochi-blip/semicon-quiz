密碼學基礎與應用

關於憑證透明度（Certificate Transparency，CT）機制的說明，正確的是下列何者？

  1. A把憑證的內容加密，使第三者看不到是哪個網域名稱之憑證的機制
  2. B瀏覽器在連線時當場找出憑證機構誤發的憑證，並自動使其失效的機制
  3. C讓已簽發的憑證記錄在任何人都能查看、僅能附加的公開日誌中，使不當簽發事後能被發現的機制
查看答案與解析

正確答案：C. 讓已簽發的憑證記錄在任何人都能查看、僅能附加的公開日誌中，使不當簽發事後能被發現的機制

過去曾發生憑證機構遭入侵或程序出錯，而對原本擁有者以外的人簽發憑證的事件。在CT中，憑證機構簽發的憑證會登錄在以Merkle樹使竄改可被察覺、僅能附加的公開日誌中，並把日誌回傳的證明（SCT）包含在憑證等處。Chrome與Safari等主要瀏覽器（截至2025年）採取不接受未附SCT之憑證的方針，網域擁有者可以監看日誌，確認是否有自己不知情的憑證被簽發。CT並不是防止不當簽發本身，而是讓簽發變得可見以便及早發現的機制。

  • A. CT反而是公開憑證的機制，記錄在日誌中的網域名稱任何人都看得到。
  • B. CT是記錄簽發並使其可見的機制。誤發之憑證的廢止，是在發現後由憑證機構進行。
  • C. 正確。這是讓不當簽發能被發現，而不是防止它的機制。
