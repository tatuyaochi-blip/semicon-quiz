製程材料（氣體與藥液）

關於化學增幅型光阻的主要構成要素組合，下列何者正確？

  1. A基底樹脂、光酸產生劑（PAG）、溶劑
  2. B銅的粒子與水
  3. C矽單晶與氧
查看答案與解析

正確答案：A. 基底樹脂、光酸產生劑（PAG）、溶劑

化學增幅型光阻以基底樹脂、光酸產生劑（PAG）、溶劑為主要成分，再加入抑制酸擴散的淬滅劑等。曝光時由PAG產生的酸，在曝光後烘烤（PEB）期間作為催化劑，一個酸就能移除許多保護基，改變樹脂的溶解性。藉由這種增幅作用大幅提升感度，因此用於光較弱的KrF、ArF、EUV曝光。
