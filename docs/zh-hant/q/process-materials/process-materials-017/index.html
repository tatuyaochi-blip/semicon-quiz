製程材料（氣體與藥液）

半導體廠中用量最大的氣體之一，並作為吹驅（purge）或環境氣體經由管線供應的是下列何者？

  1. A磷化氫
  2. B氮（N2）
  3. C三氟化氮（NF3）
查看答案與解析

正確答案：B. 氮（N2）

氮氣惰性且價格低廉，因此大量用於設備與管線的吹驅、FOUP或設備內環境的置換、真空幫浦的保護等。大型工廠會在廠區內或鄰近處設置空氣分離裝置，並以管線供應。由於用量大，若洩漏到狹窄的場所，氧濃度會降到18%以下，有缺氧症的危險。磷化氫或NF3是僅用於特定製程的特殊材料氣體。
