電腦算術

在乘法器中，加總大量部分積時會使用進位保留加法器，其主要理由為下列何者？

  1. A因為進位保留加法器能從一開始就將部分積的數量減為1個
  2. B因為進位保留加法器能不用加法就完成乘法
  3. C因為不傳遞進位即可將3個數合併為2個，且延遲固定
查看答案與解析

正確答案：C. 因為不傳遞進位即可將3個數合併為2個，且延遲固定

若以一般加法器逐一加總部分積，每次都必須等待進位由低位傳往高位。進位保留加法器是將全加器依各位數獨立排列而成，只是把3個數合併為「各位數的和」與「各位數的進位」這2個數，因此不必等待進位的傳遞，延遲固定為1級全加器的時間。重複此操作可將部分積減為2個，最後只要以超前進位加法器等相加1次即可。部分積無法一下子減為1個。

  • A. 一次只能由3個減為2個，無法減為1個。
  • B. 是用於加總部分積的加法本身。
  • C. 正確。不傳遞進位即可將3個合併為2個，且延遲固定。
