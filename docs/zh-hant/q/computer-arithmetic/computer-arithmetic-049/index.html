電腦算術

在金額的計算中，多半不使用二進位浮點數，而是以最小單位（1圓或1分）為1的整數來處理，其主要理由為下列何者？

  1. A因為浮點數完全無法表示大額的金額
  2. B因為整數一定比浮點數的記憶體使用量更少
  3. C因為十進位的小數無法以二進位準確表示，會產生誤差
查看答案與解析

正確答案：C. 因為十進位的小數無法以二進位準確表示，會產生誤差

十進位的0.1或0.01在二進位浮點數中無法準確表示，會成為捨入後的近似值。重複加法時誤差會累積，可能發生合計差1圓之類的問題。金額即使是1圓的誤差也不被允許，因此會以最小單位為1的整數來計算，或使用直接以十進位計算的格式。浮點數也能表示大額金額的大致數值，記憶體使用量也不是理由。

  • A. 大的值雖然只能以近似值表示，但問題在於誤差。
  • B. 記憶體使用量不是主要理由。
  • C. 正確。因為無法準確表示十進位的小數，誤差會成為問題。
