電腦算術

關於高速乘法器所使用的華勒斯樹（Wallace tree）的特徵，下列何者正確？

  1. A以進位保留加法器構成的樹平行地減少部分積，級數約為對數等級
  2. B將部分積逐一依序相加，因此電路最小但較慢
  3. C只要從表中查出乘法的結果，因此完全不使用加法器
查看答案與解析

正確答案：A. 以進位保留加法器構成的樹平行地減少部分積，級數約為對數等級

n位元的乘法會產生n個部分積。華勒斯樹在每一級平行地以進位保留加法器進行將3個合併為2個的處理，使部分積的數量在每一級約減為3分之2。因此減到2個為止所需的級數，大約只與位元數的對數成正比，比依序相加的方式快得多。最後將剩下的2個數以高速加法器相加即完成。依序相加是電路小但較慢的陣列式方法，而查表的方式在位元數大時無法使用。

  • A. 正確。平行地減少部分積，級數約為對數等級。
  • B. 依序相加是另一種電路小但較慢的方式。
  • C. 查表的方式在位元數大時並不實際。
