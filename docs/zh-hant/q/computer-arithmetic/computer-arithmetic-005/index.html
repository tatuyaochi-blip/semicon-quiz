電腦算術

在IEEE 754的單精度中，當指數部分所記錄的值為130時，實際的指數（2的幾次方）是多少？

  1. A3
  2. B130
  3. C2
查看答案與解析

正確答案：A. 3

為了也能表示負的指數，指數部分記錄的是實際指數加上偏移值（bias）後的值。單精度的偏移值為127，因此實際指數為 130 − 127 = 3，也就是將尾數乘上2³ = 8。指數部分為127時是乘上2⁰ = 1倍，為1時則是乘上2⁻¹²⁶倍。指數部分的0與全為1（255）是保留給非正規化數以及無限大、NaN使用的。直接把130當作指數，是忘了偏移值的錯誤。

  • A. 正確。130 − 127 = 3。
  • B. 130是減去偏移值之前的記錄值。
  • C. 2是把偏移值誤認為128時的值。
