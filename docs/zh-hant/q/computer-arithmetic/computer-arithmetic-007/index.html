電腦算術

將十進位的1.0以IEEE 754的單精度表示，其位元串以十六進位書寫為下列何者？

  1. A0x00000001
  2. B0x3F000000
  3. C0x3F800000
查看答案與解析

正確答案：C. 0x3F800000

由於1.0 = 1.0 × 2⁰，符號為0，實際指數為0，因此指數部分為 0 + 127 = 127 = 0111 1111，尾數（去除開頭的1之後的部分）全為0。排列起來是 0 01111111 000…0，每4位元分組後為 0011 1111 1000 0000 …，即 0x3F800000。0x00000001是整數1的位元串，在浮點數中則表示極小的非正規化數。0x3F000000的指數部分為126，表示0.5。

  • A. 0x00000001是整數1的位元串，在浮點數中是非正規化數。
  • B. 0x3F000000的指數部分為126，表示0.5。
  • C. 正確。符號0、指數部分127、尾數0，即0x3F800000。
