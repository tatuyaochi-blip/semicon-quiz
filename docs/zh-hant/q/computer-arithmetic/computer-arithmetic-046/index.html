電腦算術

在無號整數彼此的加法中，判定結果超過可表示範圍（位數溢出）的方法，下列何者正確？

  1. A查看結果的最高位元是否為1
  2. B查看兩個輸入的最高位元是否相等
  3. C查看從最高位元是否有進位溢出到外部
查看答案與解析

正確答案：C. 查看從最高位元是否有進位溢出到外部

在無號數的加法中，當從最高位元再向上產生進位時，結果就超過了該位元數所能表示的最大值。在CPU中，這個進位會留作進位旗標（carry flag），檢查它即可判定。結果的最高位元為1，只是變成了較大的數，並非位數溢出。比較進位到最高位元與從最高位元進位的差異，是有號數的溢位判定方法。

  • A. 即使最高位元為1，也可能是範圍內的較大數。
  • B. 僅比較輸入的最高位元無法判定。
  • C. 正確。以從最高位的進位（carry）來判定。
