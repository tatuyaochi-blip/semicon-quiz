數位訊號處理基礎

在取樣頻率8 kHz下，使用取最近8個取樣點平均的移動平均濾波器 y[n] = (x[n] + x[n − 1] + … + x[n − 7])/8。使輸出為0的最低頻率為下列何者？

  1. A500 Hz
  2. B1 kHz
  3. C4 kHz
查看答案與解析

正確答案：B. 1 kHz

N點移動平均的增益在直流為 (1 + 1 + … + 1)/N = 1，在頻率 fs/N 的整數倍（直流除外）為0。fs/N = 8000 ÷ 8 = 1 kHz的正弦波恰好在8個取樣點完成1個週期，其平均為0。移動平均是計算簡單的低通濾波器，但零點之間有增益回升的旁瓣，截止特性不太陡峭。

  • A. 這是 fs/(2N) = 8000 ÷ 16 的值。第一個零點在 fs/N。
  • B. 正確。在8個取樣點完成1個週期的1 kHz，平均為0。
  • C. 這是奈奎斯特頻率。此處也為0，但最低的零點是1 kHz。
