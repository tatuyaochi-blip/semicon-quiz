數位訊號處理基礎

單位脈衝 δ[n]（n = 0 時為1，其他為0）與單位步階 u[n]（n ≥ 0 時為1，n < 0 時為0）的關係，下列何者正確？

  1. Aδ[n] = u[n] + u[n − 1]
  2. Bδ[n] = u[n] × u[n − 1]
  3. Cδ[n] = u[n] − u[n − 1]
查看答案與解析

正確答案：C. δ[n] = u[n] − u[n − 1]

從 u[n] 減去延遲1個取樣點的 u[n − 1]，在 n ≥ 1 時為 1 − 1 = 0，n = 0 時為 1 − 0 = 1，n < 0 時為0，與 δ[n] 一致。反過來說，u[n] 是把 δ[n] 累加到 n 為止的累積和。這是以差分與累積和來表示連續時間中「步階微分得到脈衝，脈衝積分得到步階」的關係。

  • A. 相加時，n = 0 為1，n ≥ 1 為2。
  • B. 相乘時在 n ≥ 1 為1，與 u[n − 1] 相同。
  • C. 正確。與延遲1個取樣點的步階相減，只在 n = 0 留下1。
