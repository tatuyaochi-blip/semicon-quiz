數位訊號處理基礎

離散時間訊號 x[n] = cos(0.3πn) 的基本週期（對所有整數 n 都使 x[n + N] = x[n] 成立的最小正整數 N）為下列何者？

  1. A約6.7個取樣點
  2. B20個取樣點
  3. C沒有週期（不是週期訊號）
查看答案與解析

正確答案：B. 20個取樣點

離散時間的正弦波 cos(ω₀n) 只有在 ω₀/2π 為有理數 k/N（最簡分數）時才是週期訊號，基本週期為 N。ω₀/2π = 0.3π/2π = 0.15 = 3/20，因此 N = 20 個取樣點（其間恰好3個週期）。若以連續時間的想法取 2π/ω₀ ≈ 6.67，不是整數，取樣點的位置會隨每個週期偏移。像 cos(n) 這樣 ω₀/2π = 1/(2π) 為無理數時，無論等多久都不會回到相同的數值排列，因此不是週期訊號。

  • A. 2π/ω₀ = 2/0.3 ≈ 6.67 是連續時間的週期。取樣點的編號是整數，不會每6.67個取樣點回到相同的值。
  • B. 正確。0.3π/2π = 3/20，因此20個取樣點經過3個週期後回到原狀。
  • C. ω₀/2π = 0.15 是有理數，因此是週期訊號。不是週期訊號的是 ω₀/2π 為無理數的情況。
