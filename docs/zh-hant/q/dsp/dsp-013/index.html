數位訊號處理基礎

以1024點的離散傅立葉轉換（DFT）分析取樣頻率48 kHz的訊號。頻率點（bin）的間隔為下列何者？

  1. A約23.4 Hz
  2. B約46.9 Hz
  3. C約93.8 Hz
查看答案與解析

正確答案：B. 約46.9 Hz

N點DFT的頻率點間隔為 Δf = fs/N，48000 ÷ 1024 = 46.875 Hz ≈ 46.9 Hz。第k個頻率點對應頻率 k × Δf，k = 0 為直流，k = N/2 = 512 為奈奎斯特頻率24 kHz。Δf 也是觀測時間 T = N/fs ≈ 21.3 ms 的倒數，要使頻率點的間隔更細，必須加長觀測時間。

  • A. 這是 fs/(2N) = 24000 ÷ 1024 的值。頻率點的間隔為 fs/N。
  • B. 正確。48000 ÷ 1024 = 46.875 Hz。
  • C. 這是以正頻率的頻率點數 N/2 = 512 去除 fs 的值（48000 ÷ 512）。
