數位訊號處理基礎

關於DFT之前所乘的窗函數，比較方形窗（不乘任何窗）與漢寧窗（Hann窗）的敘述，下列何者正確？

  1. A漢寧窗的主瓣寬度約為方形窗的一半，旁瓣也較低，因此在各方面都優於方形窗
  2. B漢寧窗的旁瓣較低，往遠處頻率點的洩漏較小，但主瓣寬度約為方形窗的2倍
  3. C漢寧窗的主瓣變窄，但相對地旁瓣比方形窗高
查看答案與解析

正確答案：B. 漢寧窗的旁瓣較低，往遠處頻率點的洩漏較小，但主瓣寬度約為方形窗的2倍

方形窗的主瓣寬度（到第一個零點）為 ±1 個頻率點，較窄；但最大的旁瓣約為 −13 dB，較高，洩漏會擴散到遠處的頻率點。漢寧窗讓區間的兩端平滑地變成0，最大旁瓣降到約 −31 dB，但主瓣寬度為 ±2 個頻率點，約為2倍。要觀察強訊號附近的弱訊號時適合漢寧窗這類窗函數，要分辨頻率相近且強度相當的訊號時適合方形窗，須依目的選用。

  • A. 主瓣反而變寬。降低旁瓣會使主瓣變寬，兩者有取捨關係。
  • B. 正確。旁瓣從約 −13 dB 降到約 −31 dB，主瓣從 ±1 個頻率點變寬為 ±2 個頻率點。
  • C. 剛好相反。漢寧窗的旁瓣較低，主瓣較寬。
