機器學習基礎

以k最近鄰法預測二維點 (0, 0) 的類別。訓練資料為紅色的點 (1, 0)、(3, 0)、(0, −3) 與藍色的點 (0, 2)、(−2, 1)。以歐幾里得距離計算時，k = 3 與 k = 5 的預測組合何者正確？

  1. Ak = 3 為紅色，k = 5 為紅色
  2. Bk = 3 為紅色，k = 5 為藍色
  3. Ck = 3 為藍色，k = 5 為紅色
查看答案與解析

正確答案：C. k = 3 為藍色，k = 5 為紅色

與 (0, 0) 的距離為：紅色 (1, 0) 為1，藍色 (0, 2) 為2，藍色 (−2, 1) 為√5 ≈ 2.24，紅色 (3, 0) 與 (0, −3) 都是3。k = 3 時最近的3點為紅色1點、藍色2點，多數決為藍色；k = 5 時使用全部的點，紅色3點、藍色2點，因此為紅色。k最近鄰法在訓練時不做計算，而是在預測時尋找鄰近的點，結果會如此例因k值而改變。由於以距離比較，將特徵的單位與大小統一的標準化非常重要。

  • A. k = 3 時，最近的3點為紅色1點、藍色2點，多數決為藍色。
  • B. k = 3 與 k = 5 的結果顛倒了。k = 3 為藍色2點、紅色1點，k = 5 為紅色3點、藍色2點。
  • C. 正確。k = 3 為藍色2點、紅色1點，因此為藍色；k = 5 為紅色3點、藍色2點，因此為紅色。
