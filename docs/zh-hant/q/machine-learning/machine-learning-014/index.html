機器學習基礎

下列關於評估二元分類模型所用之ROC曲線與AUC的敘述，何者適當？

  1. A一邊改變判定的閾值，一邊以偽陽性率為橫軸、真陽性率為縱軸畫出的曲線，其下方面積（AUC）越接近1，越能區分陽性與陰性
  2. B將閾值固定為一個值時的準確率，依訓練次數（epoch）排列畫出的曲線，AUC表示該曲線的最大值，越大代表訓練越快
  3. CAUC為0.5的模型，能以一半以上的機率正確區分陽性與陰性，因此可說是實用上足夠的模型
查看答案與解析

正確答案：A. 一邊改變判定的閾值，一邊以偽陽性率為橫軸、真陽性率為縱軸畫出的曲線，其下方面積（AUC）越接近1，越能區分陽性與陰性

ROC曲線是一邊移動「模型輸出的分數超過多少就判為陽性」的閾值，一邊以偽陽性率 FP ÷ (FP + TN) 為橫軸、真陽性率 TP ÷ (TP + FN) 為縱軸畫出的曲線。AUC是曲線下方的面積，等於隨機選出的陽性樣本分數高於隨機選出的陰性樣本分數的機率。能完全區分的模型AUC為1，隨機判斷的模型為0.5。可用於比較決定閾值之前模型的區分能力，但在陽性極少的資料中，畫出精確率與召回率關係的PR曲線，有時更能看出差異。

  • A. 正確。表示改變閾值時真陽性率與偽陽性率的關係，AUC越接近1，區分能力越高。
  • B. 表示訓練過程的是學習曲線。ROC曲線表示改變閾值時真陽性率與偽陽性率的關係。
  • C. AUC為0.5與隨機判斷相同，表示沒有區分能力。
