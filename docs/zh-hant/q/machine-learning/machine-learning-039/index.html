機器學習基礎

以過去的錄取結果作為正確答案，建立由應徵資料預測是否錄取的模型時，下列何者是應注意的事項？

  1. A若過去的判斷有性別等造成的偏差，模型可能學到該偏差，並原樣重現或加以強化
  2. B只要資料筆數夠多，即使原始資料有偏差也會互相抵消，模型的預測自然會變得公平
  3. C只要事先從輸入中刪除性別欄位，偏差就不會透過其他特徵進入模型
查看答案與解析

正確答案：A. 若過去的判斷有性別等造成的偏差，模型可能學到該偏差，並原樣重現或加以強化

機器學習的模型會原樣學習訓練資料中的傾向，因此過去判斷中含有的歧視，或特定族群資料偏少等資料的偏差（bias），也會一併學到。增加帶有偏差的資料並不會消除偏差本身，即使刪除性別欄位，偏差也可能透過經歷、興趣等與其關係密切的特徵殘留下來。重新檢視資料的蒐集方式，並確認各族群的錯誤率等以評估公平性，是很重要的。

  • A. 正確。模型可能學到資料中的偏差，並原樣重現。
  • B. 帶有偏差的資料再怎麼增加，偏差也不會消失。
  • C. 偏差可能透過與性別關係密切的其他特徵（代理變數）殘留下來。
