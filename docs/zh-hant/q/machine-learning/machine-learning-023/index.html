機器學習基礎

全部電子郵件中有20%是垃圾郵件。某個單字出現在50%的垃圾郵件，以及5%的非垃圾郵件中。含有此單字的郵件為垃圾郵件的機率最接近下列何者？

  1. A0.10
  2. B0.50
  3. C0.71
查看答案與解析

正確答案：C. 0.71

由貝氏定理，P（垃圾郵件｜單字）= P（單字｜垃圾郵件）× P（垃圾郵件）÷ P（單字）。分子為 0.5 × 0.2 = 0.10，含有該單字的機率為 P（單字）= 0.5 × 0.2 + 0.05 × 0.8 = 0.14，因此為 0.10 ÷ 0.14 ≈ 0.71。單純貝氏分類假設多個單字（特徵）在每個類別中彼此獨立，將各自的機率相乘來進行此計算，很早就被用於垃圾郵件的判斷。

  • A. 這是「是垃圾郵件且含有此單字」的機率 0.5 × 0.2 = 0.10，沒有除以含有該單字的機率0.14。
  • B. 這是垃圾郵件中含有此單字的機率 P（單字｜垃圾郵件），與所求的 P（垃圾郵件｜單字）條件相反。
  • C. 正確。0.10 ÷ 0.14 ≈ 0.71。
