氧化與擴散

將矽熱氧化形成厚度為 x 的 SiO2 薄膜時，被消耗的矽厚度約為多少？

  1. A約 0.44x
  2. B約 1.0x
  3. C約 2.2x
查看答案與解析

正確答案：A. 約 0.44x

熱氧化是矽本身與氧反應變成 SiO2。由矽的原子密度（約 5.0×10²² cm⁻³）與 SiO2 的分子密度（約 2.2×10²² cm⁻³）之比可知，形成厚度 x 的氧化層所消耗的矽約為 0.44x。氧化層約 44% 位於原始表面之下，56% 向上成長，體積膨脹約 2.2 倍。因此氧化的部分會形成階差，而介面總是新的潔淨表面。
