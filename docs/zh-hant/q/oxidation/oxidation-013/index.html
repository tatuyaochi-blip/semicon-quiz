氧化與擴散

熱氧化時添加少量氯化氫（HCl）等含氯氣體，其主要目的為何？

  1. A使氧化層具有導電性
  2. B使氧化速率降為 0
  3. C抑制鈉等可動離子與金屬汙染的影響
查看答案與解析

正確答案：C. 抑制鈉等可動離子與金屬汙染的影響

在添加數 % 氯化氫（HCl）等的氣氛中氧化，鈉、鐵等金屬汙染會以揮發性氯化物的形式被移除，或被氧化層中的氯捕捉而失去活性。結果可減少可動離子造成的臨界電壓變動，並提升氧化層的介電崩潰耐壓等可靠度，同時也有減少氧化誘生疊差缺陷的效果。由於具腐蝕性，近年也會使用其他氯源。
