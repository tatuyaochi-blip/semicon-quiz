氧化與擴散

在矽中的熱處理擴散相對較慢、容易形成淺接面的 n 型雜質是哪一個？

  1. A硼（B）
  2. B磷（P）
  3. C砷（As）
查看答案與解析

正確答案：C. 砷（As）

在 n 型雜質中，砷的原子比磷大、擴散係數小，質量為 75，是磷（31）的兩倍以上，因此在離子佈植時也只會淺淺地打入。此外，其固溶度高，可達到高濃度，因此被用於要求淺、陡峭、低電阻接面的 nMOS 源極、汲極與延伸區。磷擴散快，用於深井區，近年也作為磊晶的 SiP 使用。硼則是 p 型。
