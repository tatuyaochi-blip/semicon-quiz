氧化與擴散

關於矽中雜質的擴散係數與溫度的關係，下列何者正確？

  1. A與溫度無關
  2. B溫度上升時變小
  3. C溫度上升時呈指數函數增大
查看答案與解析

正確答案：C. 溫度上升時呈指數函數增大

擴散係數以阿瑞尼斯（Arrhenius）形式 D = D0·exp(−Ea/kT) 表示，矽中硼與磷的活化能 Ea 約為 3.5 eV。因此溫度每升高 100 ℃，擴散係數約增大一個數量級，些微的溫差就會使擴散深度大幅改變。在擴散製程與熱處理中，溫度須以 ±1 ℃ 以下的精度管理；在先進製程中，則盡量縮短暴露於高溫的時間，以維持淺接面。
