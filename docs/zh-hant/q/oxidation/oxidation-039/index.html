氧化與擴散

在熱擴散中將磷導入矽時，一直被用作液態擴散源的化合物是哪一個？

  1. A砷化氫（AsH3）
  2. B三氯氧磷（POCl3）
  3. C乙硼烷（B2H6）
查看答案與解析

正確答案：B. 三氯氧磷（POCl3）

三氯氧磷（POCl3）在室溫下為液體，以氮氣起泡使其氣化，與氧一起通入爐中，便會在矽表面形成含磷的玻璃層（PSG），磷再由此擴散。由於可一次處理數百片且成本低，至今仍廣泛用於結晶矽太陽能電池 n 型射極層的形成等。硼使用 BBr3，氣體則使用磷化氫或乙硼烷。

  • A. 砷化氫是含砷的氣體。
  • B. 正確。這是磷的液態擴散源。
  • C. 乙硼烷是含硼的氣體。
