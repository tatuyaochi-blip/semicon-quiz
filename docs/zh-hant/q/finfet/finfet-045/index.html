先進電晶體（FinFET與GAA）

通道變得非常短，載子從源極到汲極幾乎不受散射而一路奔馳的狀態，稱為什麼？

  1. A彈道傳導
  2. B擴散傳導
  3. C跳躍傳導
查看答案與解析

正確答案：A. 彈道傳導

當通道長度與載子的平均自由路徑（矽中電子在室溫下約 10～20 nm）相同或更短時，載子幾乎不受散射地從源極移動到汲極。這就是彈道傳導，電流不是由遷移率決定，而是由從源極注入通道的速度（注入速度）決定。即使完全是彈道傳導，電阻也不會變為 0，仍會殘留由量子力學決定的接觸電阻（量子電阻）。

  • A. 正確。是不受散射而奔馳的傳導。
  • B. 擴散傳導是歷經多次散射前進的一般傳導。
  • C. 跳躍傳導是載子在局域能階之間跳躍的傳導，可見於非晶質材料等。
