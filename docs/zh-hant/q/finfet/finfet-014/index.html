先進電晶體（FinFET與GAA）

在微小的電晶體中，因通道中雜質原子的數量與位置的統計變異，而使臨界電壓產生變異的現象稱為什麼？

  1. A隨機摻雜物波動（RDF）
  2. B電遷移
  3. C經時介電崩潰（TDDB）
查看答案與解析

正確答案：A. 隨機摻雜物波動（RDF）

電晶體變小後，通道中的雜質原子只有數十至數百個左右，由於其數量與配置的隨機變異，臨界電壓會有數十 mV 的變動。變異約與「1/√(閘極面積)」成正比（Pelgrom 定律），在像 SRAM 這樣大量使用最小尺寸元件的電路中特別成為問題。可使通道不摻雜的 FinFET 與 FD-SOI，在這點上也具有優勢。
