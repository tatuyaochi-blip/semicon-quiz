資訊理論與編碼基礎

在32位元的資料上附加可更正1位元錯誤、偵測2位元錯誤的SECDED碼。漢明碼的檢查位元數r是滿足 2^r ≥ 資料位元數 + r + 1 的最小值，SECDED再加上1位元的整體同位位元。所需的檢查位元數為下列何者？

  1. A6位元
  2. B7位元
  3. C8位元
查看答案與解析

正確答案：B. 7位元

r = 5 時 2⁵ = 32 < 32 + 5 + 1 = 38，不夠；r = 6 時 2⁶ = 64 ≥ 32 + 6 + 1 = 39，因此漢明碼的檢查位元為6位元。SECDED為了區分1位元錯誤與2位元錯誤，再加上1位元的整體同位位元，因此為7位元，碼字為39位元。64位元的資料以相同計算可得8位元，成為伺服器用記憶體之ECC所使用的72位元寬度。

  • A. 6位元是只做1位元更正之漢明碼的檢查位元數。要偵測2位元錯誤，還需要多1位元的整體同位位元。
  • B. 正確。6 + 1 = 7 位元。
  • C. 8位元是在64位元資料上附加SECDED時的檢查位元數。
