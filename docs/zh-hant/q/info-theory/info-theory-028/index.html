資訊理論與編碼基礎

要在資料 1101 後附加生成多項式 x³ + x + 1（位元串 1011）之循環冗餘檢查（CRC）的3位元檢查碼。檢查碼是把資料後面加上3個0的 1101000 除以 1011 的餘數，除法中以互斥或代替減法。檢查碼為下列何者？

  1. A001
  2. B101
  3. C110
查看答案與解析

正確答案：A. 001

把 1101000 除以 1011。開頭的 1101 與 1011 的互斥或為 0110，放下一個位元後的 1100 與 1011 的互斥或為 0111，1110 與 1011 為 0101，最後 1010 與 1011 為 0001，因此餘數為 001。送出的是 1101001，接收端若除以 1011 的餘數為0，就判斷沒有錯誤。

  • A. 正確。以互斥或進行之除法的餘數為 001，送出的碼字為 1101001。
  • B. 101 是把 1101000 與 1011 當作一般二進位數104與11相除所得的餘數5。CRC使用不借位、以互斥或進行的除法。
  • C. 110 是沒有加上3個0，直接把 1101 除以 1011 的餘數。必須先加上與檢查位元數相同個數的0再相除。
