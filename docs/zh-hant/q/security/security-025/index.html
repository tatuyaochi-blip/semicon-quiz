資訊安全基礎

在惡意軟體的種類中，下列何者正確描述蠕蟲的特徵？

  1. A不寄生在其他檔案中，以單獨的程式運作，透過網路把自己的複製品送進其他電腦，自行擴散感染
  2. B寄生在其他程式的檔案中，在該程式執行時運作並擴散感染
  3. C偽裝成便利的軟體讓使用者安裝，在背後進行不當的動作，但不會自行擴散複製品
查看答案與解析

正確答案：A. 不寄生在其他檔案中，以單獨的程式運作，透過網路把自己的複製品送進其他電腦，自行擴散感染

惡意軟體是進行不當動作之軟體的總稱。狹義的電腦病毒寄生在其他程式等檔案中，在該程式執行時運作，並把感染擴散到其他檔案。蠕蟲不需要寄生的對象，可以單獨運作，利用網路上其他電腦的漏洞等，把自己的複製品送進去而自行擴散。因此若有尚未修補的漏洞，可能在短時間內擴散到整個組織。特洛伊木馬偽裝成有用的軟體讓使用者執行，在背後竊取資訊，或建立供外部操作的入口（後門），但不會自行增殖。

  • A. 正確。單獨運作並透過網路自行擴散複製品的是蠕蟲。
  • B. 寄生在其他程式中擴散感染，是狹義病毒的特徵。
  • C. 偽裝成有用的軟體入侵、但不會自行增殖，是特洛伊木馬的特徵。
