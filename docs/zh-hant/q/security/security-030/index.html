資訊安全基礎

收到自稱合作廠商窗口的電子郵件，表示「收款帳戶已變更，請從這次的請款起匯到新帳戶」。懷疑是商業電子郵件詐騙（BEC，俗稱變臉詐騙）時，最適當的處置是哪一項？

  1. A打電話到郵件中所寫的新電話號碼，確認是否為本人
  2. B以電子郵件以外的方式，聯絡原本就知道的合作廠商聯絡方式（電話號碼等），確認帳戶變更是否屬實
  3. C寄件者的姓名與簽名檔與平常的窗口相同，因此直接匯款到新帳戶
查看答案與解析

正確答案：B. 以電子郵件以外的方式，聯絡原本就知道的合作廠商聯絡方式（電話號碼等），確認帳戶變更是否屬實

商業電子郵件詐騙（BEC）是以冒充合作廠商或自家公司經營者的電子郵件，讓受害者匯款到假帳戶的詐騙。攻擊者可能盜用真正窗口的電子郵件帳號，或使用非常相似的網域名稱，因此寄件者的姓名、簽名檔甚至過去往來的內容，都可能看起來與真的一樣。這類郵件多半不含惡意軟體或惡意連結，光靠技術對策無法完全防範。對於變更匯款帳戶這類重要的要求，基本原則是不使用郵件中所寫的聯絡方式，而是以電話等其他方式，向原本就知道的聯絡方式確認。郵件中所寫的電話號碼可能會接到攻擊者本人。公司內部也可以訂定變更匯款帳戶需經多人核准等程序，這很有效。

  • A. 郵件中所寫的電話號碼可能是攻擊者準備的。確認時要使用原本就知道的聯絡方式。
  • B. 正確。基本原則是以電子郵件以外的方式，向已知的聯絡方式確認。
  • C. BEC會使用遭盜用的帳號或與真的一模一樣的簽名檔，因此姓名與簽名檔相同也不代表是真的。
