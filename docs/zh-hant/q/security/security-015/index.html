資訊安全基礎

A在要傳給B的文件上附加數位簽章。建立與驗證簽章所用的金鑰，以及數位簽章能確認的事項，正確的組合是哪一項？

  1. A以A的私密金鑰建立簽章，B以A的公開金鑰驗證。可確認文件是A所製作，且途中未遭竄改
  2. B以B的公開金鑰建立簽章，B以自己的私密金鑰驗證。可確認文件內容不會被第三者讀取
  3. C以A的公開金鑰建立簽章，B以A的私密金鑰驗證。可確認文件內容是正確的事實
查看答案與解析

正確答案：A. 以A的私密金鑰建立簽章，B以A的公開金鑰驗證。可確認文件是A所製作，且途中未遭竄改

數位簽章中，簽署者（A）以自己的私密金鑰處理文件的雜湊值來建立簽章，附加在文件上傳送。收到的B以A的公開金鑰驗證簽章，確認它與由文件計算出的雜湊值相對應。私密金鑰只有A持有，因此驗證成功就能得知文件是由A簽署（真確性），且簽署後連1位元都未被改寫（完整性）。A事後也難以否認曾經簽署（不可否認性）。不過，該公開金鑰是否確實屬於A，需要另外確認，為此會使用憑證。另一方面，數位簽章並不加密文件，因此無法讓內容保密；需要保密時要另外搭配加密。此外，簽章只能表明由誰簽署，無法得知所寫內容是否為事實。

  • A. 正確。以私密金鑰簽署、以公開金鑰驗證，可得知簽署者以及內容未遭竄改。
  • B. B的公開金鑰任何人都能使用，以它建立的簽章無法表明是誰建立的。數位簽章也不會讓內容保密。
  • C. 私密金鑰與公開金鑰的用法相反，A的私密金鑰只有A持有。此外，簽章也無法確認內容的正確性。
