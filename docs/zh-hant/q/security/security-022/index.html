資訊安全基礎

下列何者正確描述單一登入（SSO）？

  1. A只要驗證一次，就能使用多個相互串接的服務而不必重新登入的機制，便利性提高，但該驗證一旦被突破就會影響許多服務，因此最好搭配多因素驗證
  2. B指所有服務都重複使用同一組密碼，為提高安全性而受到推薦
  3. C讓一個服務同時只能有一個人登入的機制
查看答案與解析

正確答案：A. 只要驗證一次，就能使用多個相互串接的服務而不必重新登入的機制，便利性提高，但該驗證一旦被突破就會影響許多服務，因此最好搭配多因素驗證

在單一登入（SSO）中，使用者登入一次負責驗證的系統（IdP，身分識別提供者）後，結果會以安全的方式傳給各個串接的服務，不必在每個服務重新登入就能使用。代表性的協定有SAML與OpenID Connect。由於不必把密碼交給各個服務，需要管理的密碼減少，也有能在一處停用離職人員帳號等管理上的好處。然而IdP的帳號一旦遭盜用，所有串接的服務都會被入侵，因此在IdP實施多因素驗證特別重要。重複使用密碼則是另一回事，它會讓從某個服務外洩的密碼被用來登入其他服務（撞庫攻擊）。

  • A. 正確。驗證一次就能使用多個服務，但被突破時影響很大，因此要搭配多因素驗證。
  • B. 重複使用密碼是一處外洩就會讓其他服務也被入侵的危險用法，與SSO不同。
  • C. 限制同時登入人數的機制與SSO無關。
