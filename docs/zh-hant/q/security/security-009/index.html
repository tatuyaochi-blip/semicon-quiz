資訊安全基礎

把大型檔案加密後傳給對方時，常用的混合式加密方式的程序，正確的是哪一項？

  1. A直接以對方的公開金鑰加密檔案，不使用對稱式加密
  2. B以對稱金鑰加密檔案，該金鑰不加密就與檔案一起傳送
  3. C以一次性的對稱金鑰加密檔案，再以對方的公開金鑰加密該對稱金鑰，一起傳送
查看答案與解析

正確答案：C. 以一次性的對稱金鑰加密檔案，再以對方的公開金鑰加密該對稱金鑰，一起傳送

公開金鑰加密讓金鑰配送變得容易，但計算量大，不適合加密大量資料。對稱式加密速度快，但如何把金鑰安全地交給對方是課題。混合式加密結合兩者的優點：資料本體以當場產生的一次性對稱金鑰（工作階段金鑰）快速加密，只把這把簡短的對稱金鑰以對方的公開金鑰加密後一起傳送。接收者用自己的私密金鑰取出對稱金鑰，再用它解密資料。電子郵件加密等就使用這種方式。在TLS中，主流做法是不以公開金鑰加密傳送對稱金鑰，而是透過金鑰交換程序讓雙方產生相同的對稱金鑰，但「用公開金鑰技術安全地準備對稱金鑰，資料則以對稱式加密保護」的想法相同。

  • A. 公開金鑰加密計算量大，不適合直接加密大量資料。
  • B. 直接傳送對稱金鑰，途中竊看的人就能解密檔案。
  • C. 正確。資料以快速的對稱式加密保護，金鑰的傳遞則以公開金鑰加密保護。
