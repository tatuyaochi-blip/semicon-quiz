資訊安全基礎

員工有數千人的公司，使用角色型存取控制（RBAC）管理權限。下列何者正確描述RBAC的概念？

  1. A由檔案的擁有者自由決定每個檔案允許誰讀寫
  2. B依「會計人員」「人事人員」等角色彙整定義權限，再把角色指派給使用者
  3. C對所有使用者與所有檔案的每一種組合逐一設定權限
查看答案與解析

正確答案：B. 依「會計人員」「人事人員」等角色彙整定義權限，再把角色指派給使用者

在角色型存取控制（RBAC）中，事先依職務的角色彙整定義所需的權限，再把角色指派給使用者。使用者只能使用所指派角色的權限。人員調動時，只要變更角色的指派，就能一次正確地切換權限。依使用者與檔案的每種組合設定權限的方法，在人數或檔案增加時會變得難以管理，也容易忘記刪除不需要的權限。由檔案擁有者自由決定權限的方式稱為自主存取控制（DAC），用於許多作業系統的檔案權限，但難以統一整個組織的政策。

  • A. 由擁有者自由決定的方式是自主存取控制（DAC），不是RBAC。
  • B. 正確。依角色彙整權限，再把角色指派給使用者。
  • C. 依使用者與檔案的組合逐一設定，規模一大就難以管理。RBAC正是以角色彙整它們的方法。
