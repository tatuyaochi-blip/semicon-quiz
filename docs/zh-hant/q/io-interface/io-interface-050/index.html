介面與匯流排規格

下列關於PCI Express連結的省電功能（ASPM的L0s或L1狀態），何者正確？

  1. A在不傳送資料期間，讓連結進入低功耗狀態，但恢復到原本狀態需要時間，有時會使延遲增加
  2. B是提高連結速度、增加耗電的功能
  3. C即使在省電狀態，資料收發的速度也完全不變
查看答案與解析

正確答案：A. 在不傳送資料期間，讓連結進入低功耗狀態，但恢復到原本狀態需要時間，有時會使延遲增加

SerDes即使在不傳送資料期間，為了維持訊號也會消耗電力。在ASPM中，若有一段時間沒有通訊，就會讓連結進入L0s或L1這種低功耗狀態，並停止部分收發電路。L1的耗電較小，但恢復所需的時間較長。筆記型電腦為了延長電池續航力而使用，重視延遲的伺服器則有時會關閉。

  • A. 正確。要考量電力與回應速度的平衡來設定。
  • B. 是為了省電的功能。
  • C. 會因恢復所需的時間，而使最初的傳輸延遲。
