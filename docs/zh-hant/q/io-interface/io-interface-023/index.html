介面與匯流排規格

下列關於USB Type-C的敘述，何者正確？

  1. A只要是USB Type-C的傳輸線，不論哪一條都一定能以最高速度通訊
  2. BUSB Type-C無法用於供電
  3. C是連接器形狀的規格，上下哪個方向都能插入，但通訊速度由另外的規格決定
查看答案與解析

正確答案：C. 是連接器形狀的規格，上下哪個方向都能插入，但通訊速度由另外的規格決定

USB Type-C是不分正反面都能插入的小型連接器規格。即使連接器形狀相同，其中流通的通訊也有各種不同，從USB 2.0的480 Mb/s到USB 3.x、USB4的數十Gb/s，由傳輸線與雙方裝置所支援的規格決定。它也用於供電與影像輸出，因此需注意即使外觀相同，能做的事情也不同。

  • A. 速度會因傳輸線或裝置所支援的規格而異。
  • B. 透過USB PD等也能傳送大功率的電力。
  • C. 正確。形狀與速度要分開考量。
