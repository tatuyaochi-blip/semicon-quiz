介面與匯流排規格

下列關於AXI突發傳輸（burst transfer）之優點，何者正確？

  1. A因為壓縮資料後傳送，所以傳送量減少
  2. B每次傳輸都重新確認位址，因此不會有錯誤
  3. C一次位址即可傳送連續位址的多筆資料，因此可減少傳送位址的負擔，有效利用頻寬
查看答案與解析

正確答案：C. 一次位址即可傳送連續位址的多筆資料，因此可減少傳送位址的負擔，有效利用頻寬

由於常需要像讀取快取列（cache line）那樣，一次處理連續位址的資料，AXI只傳送起始位址與長度，就能連續傳遞資料，這就是突發傳輸。不必每筆資料都傳送位址，因此位址通道可以空出來，資料通道也能不間斷地使用。DRAM本身也擅長以突發方式讀寫，所以是相性良好的方式。

  • A. 不會進行壓縮。
  • B. 優點不是重新確認，而是省去位址。
  • C. 正確。適合快取列的讀寫等。
