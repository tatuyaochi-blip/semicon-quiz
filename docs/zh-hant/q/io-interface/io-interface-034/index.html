介面與匯流排規格

在大型SoC中，改用晶片上網路（NoC）取代一條共用匯流排，其原因為下列何者？

  1. A因為使用NoC可以在晶片內進行無線通訊
  2. B因為共用匯流排一次只能通過一筆傳輸，區塊增加後會壅塞，配線也會變長
  3. C因為在共用匯流排上，CPU無法讀取記憶體
查看答案與解析

正確答案：B. 因為共用匯流排一次只能通過一筆傳輸，區塊增加後會壅塞，配線也會變長

區塊較少時共用匯流排就已足夠，但當CPU核心、GPU與各種加速器連接多達數十個時，一次只能通過一筆傳輸的匯流排就會壅塞。NoC將路由器與連結排列成網狀，把資料封包化並選擇路徑傳送，因此可同時承載相距較遠的區塊之間的許多傳輸。配線可分成短區段，即使在高頻率下也容易運作。

  • A. NoC也是以配線連接。
  • B. 正確。NoC可並列承載許多傳輸。
  • C. 即使是共用匯流排也能讀取記憶體。
