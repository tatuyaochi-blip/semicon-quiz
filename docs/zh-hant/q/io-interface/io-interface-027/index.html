介面與匯流排規格

在SoC內部，廣泛用於連接CPU、記憶體控制器與周邊電路等區塊的Arm AMBA規格匯流排為下列何者？

  1. AAXI
  2. BUSB
  3. CSATA
查看答案與解析

正確答案：A. AXI

AXI（Advanced eXtensible Interface）是Arm公開的AMBA規格群之一，廣泛用作連接晶片內區塊之間的匯流排。只要依照規定的訊號約定來設計，即使是不同公司設計的IP之間也能相連。其種類有高效能的AXI、用於簡單暫存器設定的AXI4-Lite、用於資料串流的AXI4-Stream等。

  • A. 正確。是連接晶片內區塊之間的匯流排。
  • B. USB是連接裝置之間的外部規格。
  • C. SATA是連接儲存裝置的外部規格。
