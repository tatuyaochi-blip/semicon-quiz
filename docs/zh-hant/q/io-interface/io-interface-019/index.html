介面與匯流排規格

下列關於表示介面效能的「頻寬」與「延遲（latency）」之差異，何者正確？

  1. A頻寬與延遲只是以不同單位表示同一件事
  2. B頻寬越大，延遲必定越小
  3. C頻寬是單位時間內可傳送的資料量，延遲是一筆資料送達所需的時間
查看答案與解析

正確答案：C. 頻寬是單位時間內可傳送的資料量，延遲是一筆資料送達所需的時間

頻寬可比喻為道路的車道數，延遲則是到達目的地的所需時間。增加車道可一次通過更多車輛，但一輛車抵達的時間不會縮短。傳送大量資料時由頻寬決定效能，反覆交換小量資料時則由延遲決定效能。判斷哪一個是影響因素，是改善效能的第一步。

  • A. 是不同的量。
  • B. 也有頻寬大但延遲也大的連接。
  • C. 正確。因為是不同的量，所以要分開考量。
