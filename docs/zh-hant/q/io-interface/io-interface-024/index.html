介面與匯流排規格

下列關於USB Power Delivery（USB PD）的說明，何者正確？

  1. A供電端與受電端彼此通訊以協商電壓與電流，使其能以高於5 V的電壓傳送大功率
  2. B透過電力線進行USB的資料通訊
  3. C對任何裝置都固定施加20 V以加快充電
查看答案與解析

正確答案：A. 供電端與受電端彼此通訊以協商電壓與電流，使其能以高於5 V的電壓傳送大功率

USB的基本供電為5 V，能傳送的電力很小。在USB PD中，連接後雙方會透過CC線通訊，協商受電端能支援的電壓與電流後再提高電壓。用於筆記型電腦的充電等，隨著規格擴充，最大可傳送48 V、5 A（240 W）。在協商完成之前，會維持安全的5 V。

  • A. 正確。在最新規格中可處理到48 V、240 W。
  • B. 並非電力線通訊的規格。
  • C. 未經協商就施加高電壓，裝置會損壞。
