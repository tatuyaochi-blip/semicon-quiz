介面與匯流排規格

串列傳輸中使用8b/10b編碼（將8位元的資料轉為10位元的編碼後傳送的方式），其目的為下列何者？

  1. A壓縮資料以減少傳送量
  2. B消除0與1數量的偏差，讓訊號以足夠的頻率切換，使接收端能取出時脈
  3. C將資料加密，使第三者無法讀取
查看答案與解析

正確答案：B. 消除0與1數量的偏差，讓訊號以足夠的頻率切換，使接收端能取出時脈

若0或1連續很長，接收端的CDR會失去時序，而且訊號的平均電壓會偏移，導致無法正確判定。8b/10b編碼會將8位元的資料，替換為0與1數量大致相等且連續長度很短的10位元編碼。代價是傳送的位元增加25%，因此作為資料的效率為80%。PCI Express的第1、第2代以及USB 3.0等都曾使用。

  • A. 反而傳送量會增加25%。
  • B. 正確。目的是確保直流平衡（DC balance）與訊號切換。
  • C. 並不會加密。
