介面與匯流排規格

在頻寬10 GB/s、延遲1 µs的連接上，傳送一次64位元組的資料所需時間最接近下列何者？（時間＝延遲＋資料量÷頻寬）

  1. A約6.4 ns
  2. B約1 µs
  3. C約101 µs
查看答案與解析

正確答案：B. 約1 µs

64位元組÷10 GB/s=6.4 ns，因此時間為1 µs+0.0064 µs≒1 µs，幾乎全是延遲。另一方面，若傳送1 MB，則為100 µs+1 µs≒101 µs，幾乎由頻寬決定。反覆傳送小量資料時，即使增加頻寬也不會變快，因此需要將資料集中傳送、使用延遲較小的連接等方法。

  • A. 只是傳輸時間，沒有加上延遲。
  • B. 正確。幾乎只由延遲決定。
  • C. 這是接近傳送1 MB時的時間。
