介面與匯流排規格

在AXI中，不必等待前一次讀取的回應就能發出下一次讀取請求（可同時持有多個未完成的請求），其優點為下列何者？

  1. A在記憶體延遲期間也能持續推進後續請求，可隱藏延遲並提高頻寬
  2. B請求的數量減少，因此電路變小
  3. C回應的順序必定與請求的順序相反
查看答案與解析

正確答案：A. 在記憶體延遲期間也能持續推進後續請求，可隱藏延遲並提高頻寬

若等待一個請求的回應後才發出下一個，當記憶體延遲為100個時脈時，匯流排大部分時間都處於閒置。AXI可為請求附上ID並同時發出多個，因此在延遲期間資料也會陸續回傳，能有效利用頻寬。ID不同的請求，回應順序可以對調，所以也可從先完成的開始回傳。

  • A. 正確。以ID來區分。
  • B. 請求的數量不會減少。
  • C. 順序由各ID的規則決定，並非必定相反。
