介面與匯流排規格

對於與裝置之間逐一交換數千次小量資料的程式，下列哪一種加速方法最有效？

  1. A只換成頻寬為2倍的世代之連接
  2. B將資料集中成較大的區塊，減少交換的次數
  3. C將每次的資料再切得更小
查看答案與解析

正確答案：B. 將資料集中成較大的區塊，減少交換的次數

在小量交換中，每次都會產生延遲與軟體處理的負擔，頻寬幾乎沒有被使用。若將資料集中一次傳送，付出延遲的次數會減少，頻寬也能有效利用。在儲存裝置與網路中，將多個請求累積在佇列中一次交給對方、合併中斷等相同想法的做法被廣泛使用。

  • A. 小量資料由延遲主導，因此效果很小。
  • B. 正確。付出延遲的次數會減少。
  • C. 次數會增加，反而更慢。
