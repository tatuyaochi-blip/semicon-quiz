介面與匯流排規格

像100吉位元乙太網路這樣的高速連接，有時是將例如4條25 Gb/s的通道合併而成。下列關於這種做法的敘述，何者正確？

  1. A4條中有3條是備用，實際上只用1條傳送資料
  2. B在4條線上傳送相同的資料，藉由多數決來更正錯誤
  3. C因為每條線的速度有限，所以將資料分配到多個SerDes通道，以取得整體的頻寬
查看答案與解析

正確答案：C. 因為每條線的速度有限，所以將資料分配到多個SerDes通道，以取得整體的頻寬

單一SerDes通道所能達到的速度，受限於電路與傳輸線路的技術。因此將資料分配到多個通道傳送，並在接收端對齊後還原為原本的順序，就能取得整體上較大的頻寬。技術進步使單一通道的速度提高後，相同頻寬便能以較少的通道實現，例如也可用一條使用PAM4的100 Gb/s通道來傳送100吉位元。

  • A. 所有通道都用來傳送資料。
  • B. 不是傳送相同的資料，而是分開傳送。
  • C. 正確。與PCI Express的通道是相同的想法。
