封裝與構裝

在使用無鉛焊料（Sn-Ag-Cu系）的回焊中，零件所承受的峰值溫度，最接近下列何者？

  1. A約500℃
  2. B約100℃
  3. C約245～260℃
查看答案與解析

正確答案：C. 約245～260℃

Sn-Ag-Cu系的無鉛焊料熔點約為217～220 ℃，為了確實熔化並潤濕，回焊的峰值溫度設為約245～260 ℃。Sn-Pb焊料（熔點183 ℃）的峰值約為220～235 ℃，因此零件耐熱性的基準提高到260 ℃。溫度越高，吸濕的封裝越容易損壞，MSL的管理也變得更加重要。

  • A. 約500℃會損傷封裝的樹脂等。
  • B. 約100℃無鉛焊料不會熔化。
  • C. 正確。峰值約為245～260℃。
