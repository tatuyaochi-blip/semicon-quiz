封裝與構裝

打線接合中，由金（Au）線改用銅（Cu）線的趨勢不斷進展，其主要原因為何？

  1. A因為銅比金不易氧化
  2. B因為銅比金柔軟，容易接合
  3. C因為能大幅降低材料成本，且導電性也良好
查看答案與解析

正確答案：C. 因為能大幅降低材料成本，且導電性也良好

在金價高漲的背景下，改用材料費便宜的銅線的趨勢不斷進展。銅的導電性與導熱性也優於金。另一方面，銅比金容易氧化且較硬，因此在製作球時要以氮氣與氫氣的混合氣體防止氧化，並使用鍍鈀的導線，或調整接合條件以防止焊墊破裂。不易氧化、柔軟這兩個選項與事實相反。
