封裝與構裝

下列關於晶圓級封裝（WLP）的特徵，何者正確？

  1. A先將晶片一顆顆切出後再組裝封裝
  2. B以樹脂熔化晶片來製作外形
  3. C在晶圓狀態下進行重佈線與外部端子的形成，之後再單顆化
查看答案與解析

正確答案：C. 在晶圓狀態下進行重佈線與外部端子的形成，之後再單顆化

WLP是在切割之前的晶圓狀態下，一次形成重佈線層與焊球，最後再切分成一顆顆晶片。有將端子收在晶片面積內的扇入（fan-in），以及製作以樹脂嵌入晶片的重組晶圓、將配線擴展到晶片外側的扇出（fan-out）。扇出不使用基板，可以做得更薄，因此也用於智慧型手機的處理器等產品。
