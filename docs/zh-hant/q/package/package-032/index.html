封裝與構裝

在完成的IC封裝表面標示品名與批號等的製程，一般為下列何者？

  1. A磊晶成長
  2. B以雷射等進行標記（印字）
  3. C離子佈植
查看答案與解析

正確答案：B. 以雷射等進行標記（印字）

封裝表面會以雷射燒灼樹脂表面或以油墨印刷，標示產品名稱、批號、製造週別等。這稱為標記，在發現不良時，用於追溯製造履歷的可追溯性。雷射標記不易消失且速度快，因此成為主流，也會刻上二維條碼。零件很小時，也會只刻符號而不刻文字。

  • A. 磊晶成長是讓晶圓上成長結晶的製程。
  • B. 正確。以雷射等進行標記。
  • C. 離子佈植是將雜質打入晶圓的製程。
