封裝與構裝

在太空用途等要求高可靠度的場合所使用，以陶瓷或金屬將內部密閉的封裝為何？

  1. A樹脂模封封裝
  2. B氣密封裝（hermetic seal）封裝
  3. C捲帶式載體封裝
查看答案與解析

正確答案：B. 氣密封裝（hermetic seal）封裝

氣密封裝是將晶片收納於陶瓷或金屬封裝中，以焊接或硬焊將金屬蓋密閉，使水分無法進入內部的封裝。內部充填乾燥的氮氣等，並以氦氣進行洩漏測試來確認氣密性。由於樹脂會緩慢透過水分，在需要長壽命並耐受嚴苛環境的太空、國防、醫療等用途中，會選用氣密封裝。
