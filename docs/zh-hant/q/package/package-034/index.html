封裝與構裝

將表面黏著用的IC逐顆放入有凹槽的膠帶中捲繞，供應給貼片機的包裝形態稱為什麼？

  1. A晶圓卡匣
  2. B捲帶包裝（tape and reel）
  3. CFOUP
查看答案與解析

正確答案：B. 捲帶包裝（tape and reel）

捲帶包裝是在有放置零件凹槽（口袋）的載帶上排列零件，以蓋帶封住後捲在捲盤上的包裝形態。裝到貼片機上後，一邊送出膠帶，一邊以吸嘴陸續吸起零件放到基板上。大型BGA等有時以托盤供應，插件零件則有時以棒狀的管子供應。

  • A. 晶圓卡匣是排列放入晶圓的容器。
  • B. 正確。是放入膠帶並捲在捲盤上的包裝形態。
  • C. FOUP是在工廠內搬運晶圓的密閉容器。
