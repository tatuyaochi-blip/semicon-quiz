封裝與構裝

在封裝或印刷電路板上配置去耦電容（旁路電容），其主要目的為何？

  1. A放大訊號
  2. B抑制電源電壓的變動（雜訊），並針對急遽的電流變化供應電荷
  3. C使晶片發光
查看答案與解析

正確答案：B. 抑制電源電壓的變動（雜訊），並針對急遽的電流變化供應電荷

LSI會因運作而使電源電流急遽變化，由於電源配線的電感L，會產生L·di/dt的電壓變動。在晶片附近放置去耦電容後，針對急遽的電流變化，電容會供應電荷，抑制電源電壓的波動。各頻率範圍有效的位置不同，因此會在晶片內、封裝、基板上分別配置大小不同的電容。放大訊號並非其作用。
