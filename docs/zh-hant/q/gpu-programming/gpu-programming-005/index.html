GPU程式設計

下列何者是CUDA執行緒階層的正確組合（由大到小）？

  1. A網格 → 區塊 → 執行緒
  2. B執行緒 → 區塊 → 網格
  3. C區塊 → 執行緒 → 網格
查看答案與解析

正確答案：A. 網格 → 區塊 → 執行緒

啟動一次核心函式後，整體成為網格（grid），網格分為許多區塊（block），區塊再分為許多執行緒。同一個區塊的執行緒會在同一個SM（運算單元的集合）上執行，可透過共享記憶體合作並進行同步。不同的區塊則獨立執行，因此同時運作的區塊數量會隨GPU的規模而變，同一個程式可在大小不同的GPU上執行。

  • A. 正確。一次啟動的整體就是網格。
  • B. 這是由小到大的順序。
  • C. 順序不正確。
