GPU程式設計

關於CUDA共享記憶體（shared memory）的特徵，下列何者正確？

  1. A由所有GPU與CPU共享的大容量主記憶體
  2. BGPU記憶體與硬碟共享的區域
  3. C同一區塊的執行緒可共享、位於晶片上的小容量高速記憶體，由程式明確地使用
查看答案與解析

正確答案：C. 同一區塊的執行緒可共享、位於晶片上的小容量高速記憶體，由程式明確地使用

共享記憶體是位於各SM內、每個區塊數十KB左右的高速記憶體，讀寫速度比全域記憶體（GPU的DRAM）快數十倍。同一區塊的執行緒可以將資料放在其中共享，因此可用於從全域記憶體只讀入一次而重複使用，或讓執行緒之間傳遞中間結果等用途。與快取不同的是，要放什麼內容由程式決定。

  • A. 這比較接近全域記憶體或統一記憶體的說明。
  • B. 與磁碟無關。
  • C. 正確。可當作由程式管理的快取來使用。
