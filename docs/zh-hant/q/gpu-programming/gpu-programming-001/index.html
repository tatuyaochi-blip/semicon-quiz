GPU程式設計

關於CPU與GPU設計理念的差異，下列何者正確？

  1. ACPU以眾多簡單的核心重視處理量，GPU則以少數強力的核心加快單一處理
  2. BCPU與GPU的差異只在名稱，構造相同
  3. CCPU重視以少數強力的核心盡快完成單一處理，GPU則重視以眾多簡單的運算單元提升整體處理量
查看答案與解析

正確答案：C. CPU重視以少數強力的核心盡快完成單一處理，GPU則重視以眾多簡單的運算單元提升整體處理量

CPU將電路用於大型快取、分支預測、亂序執行等，盡可能讓單一執行緒快速推進。GPU則簡化這些電路，並排上更多運算單元，同時執行數千個執行緒，以提高整體處理量。雖然每個執行緒都很慢，但在對大量資料進行相同處理的工作上，GPU可以快上數倍。

  • A. 說反了。
  • B. 構造差異很大。
  • C. 正確。這是重視延遲與重視吞吐量的差異。
