GPU程式設計

下列何者是使用多個CUDA串流（stream）的主要目的？

  1. A增加GPU冷卻的氣流
  2. B讓資料傳輸與核心函式的執行重疊並同時進行，縮短整體的時間
  3. C提高影片串流的畫質
查看答案與解析

正確答案：B. 讓資料傳輸與核心函式的執行重疊並同時進行，縮短整體的時間

串流是對GPU發出之處理（傳輸或核心函式啟動）的順序序列。在同一個串流中會依序執行，但不同串流的處理可以同時進行。將資料分割，在計算第一部分的同時傳輸第二部分，像這樣重疊起來，傳輸與計算的時間大部分就會重疊，整體時間便會縮短。

  • A. 與冷卻無關。
  • B. 正確。可以隱藏傳輸的時間。
  • C. 與影片串流的串流是不同的意義。
