GPU程式設計

對於只對陣列元素做一次加法這類輕量的處理，若將資料傳送到GPU，有時會比用CPU計算還慢。下列何者是主要原因？

  1. A因為GPU無法做加法
  2. B因為透過PCI Express複製資料所花的時間，比GPU能加快的計算時間還長
  3. C因為將資料傳送到GPU後，值會改變
查看答案與解析

正確答案：B. 因為透過PCI Express複製資料所花的時間，比GPU能加快的計算時間還長

PCI Express的頻寬比GPU記憶體的頻寬小一個數量級以上，因此光是傳送資料就要花時間。若每個元素只做一次加法，相對於傳送的時間，計算的時間微乎其微，無法發揮GPU的速度。GPU能佔優勢的情況，是對所傳送的資料進行大量計算，或將資料留在GPU記憶體中反覆處理時。

  • A. GPU很擅長加法。
  • B. 正確。相對於傳輸，計算量太少了。
  • C. 值不會改變。
