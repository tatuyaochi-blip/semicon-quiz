Verilog 與 VHDL 的差異：兩種硬體描述語言比較

Verilog 與 VHDL 是為了模擬與邏輯合成而描述數位電路的兩種主要硬體描述語言（HDL）。Verilog 的語法簡短，類似 C 語言，容易入門。VHDL 的描述較長，型別嚴格，因此容易及早發現錯誤。兩者都能描述相同的電路，選擇的依據多半是業界、公司與既有的程式碼。

適用於什麼情況

Verilog / SystemVerilog
在晶片的設計與驗證上，先選這個較為穩當。因為業界的工具與函式庫是以 SystemVerilog 為中心製作的。
VHDL
適合重視嚴格型別與長期維護容易性的場合。例如安全攸關的開發與國防相關等。
實際上
很多時候也會需要閱讀兩者。其基本觀念（模組或實體、並行運作的訊號、以時脈運作的程序）是相同的。

常見問題

Verilog 與 VHDL 哪一個比較容易學？

Verilog。因為語法簡短，類似 C 語言。VHDL 的描述較長，型別也嚴格，起初較難，但可以在編譯時發現更多錯誤。

業界比較常用哪一個？

在 ASIC 與 SoC 的設計與驗證上，尤其是美國與亞洲，以 SystemVerilog 為主流。VHDL 則用於歐洲、航太與國防，以及許多 FPGA 開發。

Verilog 與 VHDL 可以在一個專案中混用嗎？

可以。主要的模擬器與邏輯合成工具支援混合語言的設計，以其中一種語言撰寫的模組，可以在另一種語言中使用。

什麼是 SystemVerilog？

是擴充 Verilog 的語言，加入了類別、限制式隨機測試、斷言與 UVM 的方法。已成為晶片驗證的標準。

理解度檢測

以Verilog等HDL撰寫的描述，與C語言等軟體程式的最大差異，下列何者正確？

  1. AHDL的描述表示的是同時並行運作的電路
  2. BHDL的描述是從上一行起逐行依序執行的指令序列
  3. CHDL中無法使用變數或條件分支
查看答案與解析

正確答案：A. HDL的描述表示的是同時並行運作的電路

HDL外觀看起來像程式，但所寫的內容會經由邏輯合成變成閘極與正反器所構成的電路。電路的各個部分隨時都在同時運作，因此多個assign語句或always區塊，無論撰寫順序為何，都會並行運作。如果像軟體一樣以「這個處理結束後再做下一個」的方式思考，就無法得到預期的電路，所以撰寫時想像會產生什麼樣的電路是很重要的。

在Verilog中使用module的目的，下列何者正確？

  1. A定義具有輸入與輸出端子（連接埠）的電路零件，使其能在其他module中使用
  2. B暫時停止程式的執行
  3. C將模擬的結果顯示在畫面上
查看答案與解析

正確答案：A. 定義具有輸入與輸出端子（連接埠）的電路零件，使其能在其他module中使用

module是定義具有輸入與輸出連接埠的電路單位，可表示加法器、計數器乃至整個CPU等。定義好的module可在其他module中當作零件重複使用（實體化），並將連接埠以佈線相連，組裝成更大的電路。就像在基板上排列零件並佈線一樣，可以階層式地建構電路。

Verilog的wire型與reg型的差異，下列何者正確？

  1. Areg一定會成為正反器，wire一定會成為組合電路
  2. Bwire表示以assign語句等相連的佈線，reg表示在always區塊中被賦值的訊號，但reg不一定會成為正反器
  3. Cwire是用來放入數值的型別，reg是用來放入文字的型別
查看答案與解析

正確答案：B. wire表示以assign語句等相連的佈線，reg表示在always區塊中被賦值的訊號，但reg不一定會成為正反器

在Verilog中，規定由assign語句或module輸出所驅動的訊號宣告為wire，在always區塊中被賦值的訊號宣告為reg。reg看起來像是「暫存器（register）」的縮寫，但若在always @(*)中賦值，就會成為組合電路，而不是正反器。是否成為正反器，取決於是否以時脈邊緣更新值的寫法。在SystemVerilog中，兩者都可以用logic型來撰寫。

前往硬體描述語言與驗證的練習題

相關名詞的解說

Verilog
廣泛用於數位電路設計與驗證的硬體描述語言。以 module 為單位撰寫電路，並以 assign 與 always 表示行為。
SystemVerilog
擴充 Verilog 的語言。具有 logic 型別與 always_ff、always_comb 等設計功能，以及類別、受限隨機、斷言等驗證功能。
硬體描述語言（Hardware description language, HDL）
以文字描述數位電路結構與行為的語言。HDL。有 Verilog、SystemVerilog、VHDL，並藉由邏輯合成轉換為電路。
RTL(暫存器傳輸層級)
以資料如何在暫存器之間傳輸與處理來描述電路的設計抽象層級。以Verilog或VHDL撰寫，是邏輯合成的輸入。
