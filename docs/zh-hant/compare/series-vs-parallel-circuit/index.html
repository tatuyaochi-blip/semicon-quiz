串聯與並聯的差異：電流、電壓、合成電阻、電容、電池比較

把元件排成一列連接是串聯，把兩端對齊並排連接是並聯。串聯時，所有元件流過相同的電流，電壓分配在各元件上。並聯時，所有元件承受相同的電壓，電流分配到各元件。因此電阻在串聯時為各值的和，並聯時則為倒數和的倒數，比最小的電阻還小。只有電容的公式相反，並聯時相加，串聯時為倒數和的倒數。

項目串聯並聯
共同的量電流（所有元件流過相同的電流）電壓（所有元件承受相同的電壓）
分配的量電壓。與電阻大小成正比分配（分壓）。12 V接2 kΩ與1 kΩ時為8 V與4 V電流。與電阻大小成反比分配（分流）。3 A流入10 Ω與20 Ω時為2 A與1 A
合成電阻R = R1 + R2 + …。100 Ω、200 Ω、300 Ω為600 Ω1/R = 1/R1 + 1/R2 + …。100 Ω、200 Ω、300 Ω約為54.5 Ω。2個時為積÷和
合成電容1/C = 1/C1 + 1/C2 + …，會變小。10 µF與22 µF約為6.88 µFC = C1 + C2 + …，直接相加。10 µF與22 µF為32 µF
合成電感（無磁耦合時）L = L1 + L2 + …（與電阻相同的形式）1/L = 1/L1 + 1/L2 + …（與電阻相同的形式）
功率較大的元件電流相同，因此是電阻較大者（P = I²R）電壓相同，因此是電阻較小者（P = V²/R）。相同值的2個電阻各分擔一半功率，但額定值仍要保留餘裕（降額）
其中一個斷路（開路）時整個電路的電流停止其他元件仍持續有電流流過
連接電池時電壓相加（2顆1.5 V的乾電池為3 V）。容量（mAh）仍為1顆的量電壓仍為1顆的量。容量相加，可用得更久
電子電路中的例子分壓電路、限制LED電流的電阻、熱阻的疊加（接面→外殼→散熱器）並聯功率MOSFET以降低導通電阻、並列多個通孔與電源配線以減少IR壓降、去耦電容、家用插座

數值為具代表性的大致參考值，會因世代或產品而異。

適用於什麼情況

串聯
想分配電壓時（分壓電路）、想讓所有元件流過相同電流時（例如以相同電流點亮多顆LED），或想用電池組成較高電壓時。
並聯
想讓每個元件承受相同電壓，且其中一個損壞時其他仍能運作時（家用配線），或想降低電阻、增加可流過的電流或電容值時。

常見問題

為什麼並聯會使合成電阻變小？

因為電流的通路增加，在相同電壓下流過整體的電流變多。由歐姆定律R = V/I，電流增加則合成電阻變小。不論並聯加上什麼值的電阻，合成電阻都會比最小的電阻還小，6 Ω與3 Ω並聯為18 ÷ 9 = 2 Ω。

為什麼只有電容的串聯與並聯公式相反？

平行板電容的電容值為C = εS/d（S：極板面積，d：極板間距），並聯相當於擴大極板面積，相同電容串聯則相當於加大極板間距。以式子來看，串聯時各電容累積相同的電荷Q，電壓Q/C1 + Q/C2 + …相加，因此成為1/C = 1/C1 + 1/C2 + …。

為什麼分壓電路接上負載後，輸出電壓會下降？

因為負載與下側電阻並聯，該部分的合成電阻變小。以10 kΩ與10 kΩ分配10 V時輸出為5 V，但在下側接上10 kΩ的負載後，下側變成5 kΩ，輸出降為10 × 5/15 ≈ 3.33 V。要讓分壓電阻遠小於負載，或以緩衝器（電壓隨耦器）接收。

電池並聯時要注意什麼？

電壓不同的電池並聯時，電流會從電壓高的電池流入電壓低的電池。應連接同種類且剩餘電量一致的電池。組合鋰離子電池時，不論串聯或並聯，都要使用監視每顆電池電壓的保護電路。

理解度檢測

將100 Ω、200 Ω、300 Ω三個電阻串聯時，合成電阻是多少？

  1. A約55 Ω
  2. B600 Ω
  3. C200 Ω
查看答案與解析

正確答案：B. 600 Ω

串聯的合成電阻為各電阻之和，100 + 200 + 300 = 600 Ω。串聯時三個電阻流過相同的電流，電壓依電阻值成比例分配。例如加上12 V時，電流為 12 V/600 Ω = 20 mA，各電阻的電壓分別為2 V、4 V、6 V。若將相同的三個電阻並聯，合成電阻約為55 Ω，比最小的100 Ω還小。

將6 Ω與3 Ω的電阻並聯時，合成電阻是多少？

  1. A2 Ω
  2. B9 Ω
  3. C4.5 Ω
查看答案與解析

正確答案：A. 2 Ω

兩個電阻並聯的合成電阻為 R1R2/(R1 + R2)（積除以和），6 × 3/(6 + 3) = 18/9 = 2 Ω。也可由倒數和 1/6 + 1/3 = 1/2 取倒數求得。並聯的合成電阻會比最小的電阻（3 Ω）還小。並聯時兩者承受相同電壓，電流與電阻成反比分配，因此3 Ω流過的電流是6 Ω的2倍。

平行板電容器若將極板面積加倍、極板間距減半，靜電容量會變為幾倍？（極板間的介電質不變）

  1. A1倍（不變）
  2. B4倍
  3. C2倍
查看答案與解析

正確答案：B. 4倍

平行板電容器的電容為 C = εS/d（ε：介電係數，S：極板面積，d：間距），與面積成正比、與間距成反比。面積加倍時變為2倍，間距減半時再變為2倍，合計 2 × 2 = 4倍。若極板間填滿相對介電常數為εr的介電質，電容變為εr倍。積層陶瓷電容器即是將許多薄介電層堆疊以獲得大電容。

  1. 在12 V直流電源上，從正極側依序串聯電阻R1 = 2 kΩ、R2 = 1 kΩ（R2的另一端接負極）。R2兩端的電壓是多少？（不從輸出取出電流）
  2. 將10 Ω與20 Ω的電阻並聯，總共流入3 A的電流。流過20 Ω電阻的電流是多少？

前往電路與電磁學基礎的練習題

相關名詞的解說

導通電阻
功率半導體在導通時，電流流經路徑的電阻。越小，導通時的損耗越少。
熱阻
表示熱不易傳遞程度的量，單位為℃/W。將消耗功率乘以熱阻即可求得溫度上升。從晶片接面到周圍空氣的熱阻寫作θJA。
IR壓降
電流(I)流過電源導線的電阻(R)，使送達電路的電源電壓下降的現象。會造成電路延遲增加與誤動作。
導通孔
在多層導線中，電性連接上下導線層之間的導體。在絕緣膜上開孔並填入金屬而成。
降額(Derating)
為了提高可靠度，不將電壓、電流、溫度等用到額定值上限，而是保留餘裕來使用。例如訂定電壓在額定值的 70〜80% 以下、接面溫度相對於最大額定 150 ℃ 在 125 ℃ 以下使用等基準。
