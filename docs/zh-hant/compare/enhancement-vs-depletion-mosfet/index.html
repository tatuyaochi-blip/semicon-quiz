增強型與空乏型 MOSFET 的差異：臨界電壓、符號、用途比較

增強型是在閘極電壓為 0 V 時沒有通道，必須對閘極施加電壓形成反轉層後才會有電流流過的 MOSFET（常閉型，normally-off）。空乏型則預先形成了通道，閘極為 0 V 時也有電流流過，對閘極施加反向電壓使通道消失後，電流才會停止（常開型，normally-on）。在 n 通道中，增強型的臨界電壓為正，空乏型為負。包括 CMOS 邏輯電路在內，幾乎所有用途都使用增強型。

項目增強型空乏型
閘極為 0 V 時沒有通道，關閉（常閉型）有通道，導通（常開型）
臨界電壓的正負（n 通道）正負
臨界電壓的正負（p 通道）負正
通道的形成方式以閘極電壓在基板表面感應出反轉層以離子佈植等方式，預先在表面形成薄的通道層
截止電流的方法（n 通道）將閘極電壓降到臨界值以下（設為 0 V 即可）對閘極施加負電壓，使通道空乏
名稱的由來以閘極電壓增加通道（enhance）以閘極電壓減少通道（deplete）
電路符號通道的線為分成 3 段的虛線通道的線為 1 條實線
驅動電路停止時會關閉，因此安全可能導通，需注意短路等問題

數值為具代表性的大致參考值，會因世代或產品而異。

適用於什麼情況

增強型
幾乎所有情況。只要將閘極設為 0 V 就能確實關閉，因此用於邏輯電路的開關，以及需要安全關閉的功率開關。
空乏型
想在沒有閘極電壓的情況下讓電流流過時。例如取代電阻的負載元件、將閘極與源極相連的簡易定電流源、在電源上升前就開始運作的啟動電路等。
使用常開型元件時
像 GaN HEMT 這種本質上為常開型的元件，會透過改良閘極結構，或與低耐壓的矽 MOSFET 串聯成疊接（cascode）組態，當作常閉型來使用。

常見問題

為什麼功率用途要求常閉型？

因為常開型元件在閘極驅動電路的電源中斷或故障時會導通，可能使電源短路而流過大電流。若是增強型，閘極為 0 V 時即關閉，因此安全。

空乏型過去用在哪些電路中？

在 CMOS 成為主流之前的 NMOS 邏輯中，將閘極與源極相連的空乏型元件被當作取代電阻的負載元件使用。現在仍用於簡易的定電流源、電源的啟動電路等。

在電路符號上如何區分？

以代表通道的線來區分。增強型為了表示不施加閘極電壓就沒有通道，以分成 3 段的虛線來畫。空乏型一開始就有通道，因此以 1 條實線來畫。

可以用臨界電壓的值來區分嗎？

可以。在 n 通道中，臨界電壓為正是增強型，為負是空乏型。在 p 通道中正負相反，為負是增強型，為正是空乏型。

理解度檢測

關於空乏型MOSFET的特徵，下列何者正確？

  1. A沒有閘極
  2. B閘極電壓為0 V時通道仍然存在，有電流流過
  3. C即使閘極電壓高於臨界電壓也沒有電流流過
查看答案與解析

正確答案：B. 閘極電壓為0 V時通道仍然存在，有電流流過

空乏型是通道事先已形成、即使閘極電壓為0 V也有電流流過（常開型）的MOSFET。若為n通道，則以負的閘極電壓消除通道來截止電流。在早期的NMOS邏輯中被用作負載元件。由於即使電源中斷也會導通，在安全方面需要留意，GaN的HEMT本質上也是常開型，因此會在結構上下工夫使其成為常閉型。

增強型n通道MOSFET導通（ON）的正確條件為下列何者？（VGS：閘極-源極間電壓，Vth：臨界電壓）

  1. AVGS為0 V
  2. BVGS大於Vth
  3. CVGS為負電壓
查看答案與解析

正確答案：B. VGS大於Vth

增強型nMOSFET中，當對閘極施加超過Vth的正電壓時，電子會被吸引到p型基板表面而形成反轉層（通道），電流便在源極與汲極之間流動。VGS = 0 V時沒有通道而處於關閉狀態，因此即使閘極浮接也不易有電流流過（常閉型），適合邏輯電路與功率用途的安全性。Vth在先進邏輯製程中通常為0.2～0.4 V，功率用途則約為1～4 V。

增強型p通道MOSFET的臨界電壓（以源極為基準）的正負號為下列何者？

  1. A正值
  2. B負值
  3. C必定為0 V
查看答案與解析

正確答案：B. 負值

在pMOS中，對閘極施加比源極低的電壓時，n型基板（n井）表面會形成電洞的反轉層而導通。因此增強型pMOS的臨界電壓為負值（例如 −0.4 V）。在電路中可這樣理解：將源極接到電源VDD，使閘極比VDD低|Vth|以上就會導通。設計資料中為避免正負號混淆，常以絕對值|Vth|來比較。

前往MOSFET的練習題

相關名詞的解說

臨界電壓
MOSFET 中形成通道(反轉層)而開始有電流流動的閘極電壓。記為 Vth。
常閉型(Normally-off)
閘極電壓為 0 V 時沒有電流流動的特性。即使驅動電路故障，電流也不會持續流動，因此在安全上是功率元件所要求的。
反轉層
因閘極電壓使與原本型態相反的載子聚集在半導體表面而形成的層。成為 MOSFET 的通道。
