基礎

半導體物性這個領域的題目 →

直接能隙與間接能隙半導體的差異：能帶結構、發光效率、光吸收、材料比較
從能帶結構、聲子的參與、發光效率、載子壽命、光的吸收深度、代表性材料與用途等面向，以表格比較直接能隙與間接能隙半導體。
n 型半導體與 p 型半導體的差異：摻雜物、多數載子、費米能階、遷移率比較
從添加的雜質（施體與受體）、多數載子、雜質能階、費米能階的位置、遷移率與電阻率，以及在元件中的使用位置等面向，以表格比較 n 型與 p 型半導體。
導體、半導體、絕緣體的差異：能隙、電阻率、溫度特性比較
從能帶結構、能隙、電阻率、載子數量、隨溫度與光的變化、代表性材料與在元件中的角色等面向，以表格比較導體（金屬）、半導體與絕緣體。
本質半導體與雜質半導體的差異：載子、費米能階、溫度特性比較
從載子的來源與密度、費米能階、電阻率、隨溫度的變化與用途等面向，以表格比較不含雜質的本質半導體，以及加入施體或受體的雜質半導體（外質半導體，n 型與 p 型）。

PN接面與二極體這個領域的題目 →

PN 接面二極體與蕭特基二極體的差異：結構、順向電壓、逆向恢復、漏電流比較
從結構、傳導電流的載子、順向電壓、逆向恢復、逆向漏電流、耐壓、溫度特性與用途等面向，以表格比較 PN 接面二極體與蕭特基能障二極體。
齊納崩潰與累增崩潰的差異：機制、雜質濃度、崩潰電壓、溫度係數比較
從機制、雜質濃度、空乏區寬度、崩潰電壓參考值、溫度係數的正負、崩潰的陡峭程度與用途等面向，以表格比較 PN 接面的齊納崩潰與累增（雪崩）崩潰。

BJT 與 MOSFET 的差異：控制方式、速度、用途比較
從控制方式、輸入電流、載子、速度、導通狀態、溫度特性、積體度與用途等面向，以表格比較雙極性電晶體（BJT）與 MOSFET。
NPN 電晶體與 PNP 電晶體的差異：結構、電流方向、電路符號、使用方式比較
從半導體的排列、主要載子、偏壓方式、電流方向、電路符號的箭頭、作為開關的接法與性能等面向，以表格比較雙極性電晶體的 NPN 型與 PNP 型。

MOSFET這個領域的題目 →

JFET與MOSFET的差異：比較閘極結構與使用時機
以閘極的結構、常開或常關、閘極電流、雜訊、抗靜電能力、整合度與用途等面向，用表格比較JFET與MOSFET。
nMOS 與 pMOS 的差異：載子、遷移率、臨界電壓、在 CMOS 中的角色比較
從結構、載子、遷移率、臨界電壓的正負、導通條件、在 CMOS 中的角色、容易傳遞的邏輯準位、相同驅動力所需的閘極寬度等面向，以表格比較 nMOS 與 pMOS。
增強型與空乏型 MOSFET 的差異：臨界電壓、符號、用途比較
從閘極 0 V 時的狀態、臨界電壓的正負、通道的形成方式、截止電流的方法、電路符號、安全性與用途等面向，以表格比較增強型與空乏型 MOSFET。

邏輯電路這個領域的題目 →

閂鎖器與正反器的差異：比較動作與使用時機
以觸發方式、輸出的動作、構成、尺寸、時序分析、突波與數位設計中的使用時機等面向，用表格比較閂鎖器與正反器。
組合邏輯電路與循序邏輯電路的差異：比較輸出的決定方式
以輸出由什麼決定、記憶元件、時脈、回授、範例、時序與 HDL 寫法等面向，用表格比較組合邏輯電路與循序邏輯電路。
CMOS 與 TTL 的差異：比較邏輯 IC 系列
以電晶體、靜態耗電量、電源電壓、邏輯準位、雜訊邊限、速度、輸入與使用場合等面向，用表格比較 CMOS 與 TTL 邏輯 IC。
建立時間與保持時間的差異：定義、延遲、頻率、修正方式比較
從定義、檢查所用的延遲（max 或 min）、與時脈頻率的關係、時脈偏斜的影響、違規的修正方式與要確認的角落等面向，以表格比較正反器的建立時間與保持時間。
開汲極與推挽輸出的差異：結構、上升時間、線及、用途比較
從輸出級結構、輸出 H 的機制、上升速度、線及（wired-AND）、與不同電壓電路的連接、消耗電流與用途等面向，以表格比較開汲極輸出與推挽輸出。

類比與電子電路這個領域的題目 →

LDO 與切換式穩壓器的差異：效率、雜訊、元件、用途比較
從動作原理、效率、發熱、雜訊、元件數量、能否升壓、對負載的響應與用途等面向，以表格比較線性穩壓器（LDO）與切換式穩壓器（DC-DC 轉換器），並說明結合兩者的電源架構。
抖動與相位雜訊的差異：量測量、單位、量測儀器、換算、選用比較
從量測的量、單位、量測儀器、代表性指標、積分換算成 RMS 抖動、使用領域等面向，比較在時域看時脈擾動的抖動與在頻域看的相位雜訊。
A類、AB類、D類放大器的差異：動作原理、效率、失真、發熱、用途比較
從動作原理、導通角、理論最大效率、失真、發熱、雜訊與用途等面向，以表格比較 A類、AB類、D類功率放大器，並說明與 B類的關係。
運算放大器與比較器的差異：使用方式、輸出級、速度、相位補償比較
從使用方式（負回授或開迴路）、輸出級、響應速度、飽和恢復、有無相位補償、遲滯與能否互相替代等面向，以表格比較運算放大器與比較器。
PLL 與 DLL 的差異：控制對象、倍頻、抖動、穩定性、用途比較
從控制對象、VCO 與延遲線、倍頻、抖動的累積、迴路穩定性與用途（時脈產生與去偏斜）等面向，以表格比較 PLL（鎖相迴路）與 DLL（延遲鎖定迴路）。

AD/DA轉換這個領域的題目 →

SAR、ΔΣ、管線式、快閃式ADC的差異：架構比較
以機制、解析度、速度、延遲、耗電量、面積與用途等面向，用表格比較快閃式、SAR式、管線式、ΔΣ式的ADC。

DRAM 與 NAND 快閃記憶體的差異：揮發性、速度、容量、用途比較
從記憶機制、揮發性、讀寫單位與速度、抹寫次數、提高積體度的方法、成本與用途等面向，以表格比較 DRAM 與 NAND 型快閃記憶體。可以了解主記憶體與儲存裝置在角色上的差異。

從單元的連接方式、讀取速度、抹除單位、容量、成本、可靠度與用途等面向，以表格比較 NAND 型與 NOR 型快閃記憶體。
SLC、MLC、TLC、QLC 的差異：壽命、速度、成本比較
從每個單元的位元數、抹寫壽命、速度、成本、錯誤率與使用的 SSD 等面向，以表格比較 SLC、MLC、TLC、QLC 的 NAND 型快閃記憶體。
SSD 與 HDD 的差異：比較速度、耐用度與成本
以資料記錄方式、速度、延遲、耐衝擊性、噪音、耗電量、每 TB 成本、容量、壽命與適合的用途等面向，用表格比較 SSD 與 HDD。

MRAM、ReRAM、PCM、FeRAM 的差異：新型記憶體比較
從記憶原理、寫入方法、速度、抹寫壽命、積體度、課題與用途等面向，以表格比較 MRAM、ReRAM、PCM、FeRAM。

功率半導體這個領域的題目 →

IGBT與功率MOSFET的差異：使用時機比較
以結構、耐壓範圍、導通損耗、切換速度、尾電流、本體二極體與用途等面向，用表格比較IGBT與功率MOSFET。
降壓轉換器與升壓轉換器的差異：轉換比、元件配置、電流、效率、用途比較
從輸出電壓範圍、理想電壓轉換比（D 與 1/(1−D)）、元件配置、輸入與輸出電流的連續性、效率、控制與用途等面向，比較降壓（Buck）轉換器與升壓（Boost）轉換器。
Si（矽）與 SiC（碳化矽）功率半導體的差異：物性、耐壓、損耗、用途比較
從能隙、崩潰電場、熱導率、使用的元件、耐壓、切換損耗、晶圓與成本、課題與用途等面向，以表格比較矽（Si）與 SiC（碳化矽）功率半導體。

LED 與半導體雷射的差異：發光機制、光的性質、用途比較
