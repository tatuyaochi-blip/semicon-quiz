DDR4 與 DDR5 的差異：速度、結構與升級的判斷依據

DDR5 是 DDR4 的後繼規格，起始資料速率約為兩倍，電壓降低，記憶體模組的組成也改變了。一條模組具有兩個獨立的 32 位元子通道，電源調節電路移到模組上。晶片內部也加入了錯誤更正。不過 DDR5 與 DDR4 並不相容。以時脈數計算的延遲變大，因此實際效果會依處理內容而異。

適用於什麼情況

DDR4
對於現有的環境，或記憶體頻寬不構成限制的用途，仍是便宜而穩當的選擇。
DDR5
適合新系統、核心數多的系統、內建顯示，以及需要記憶體頻寬的用途。例如伺服器、內容創作、新遊戲用的平台。
注意
無法混用。可使用的種類由平台(CPU 與主機板)決定。

常見問題

DDR5 比 DDR4 快嗎？

資料速率較高。DDR5 從 4,800 MT/s 起跳，而標準的 DDR4 上限約在 3,200 MT/s 前後，因此每個通道的頻寬是兩倍。以奈秒計算的延遲一開始大致相同，所以日常作業不一定會明顯變快。

DDR4 的插槽能使用 DDR5 嗎？

不能。插槽的缺口與電氣設計都不同，所以並不相容。可使用的種類由 CPU 與主機板決定。

DDR5 的晶粒內 ECC 是什麼？

DDR5 的所有晶片在內部都具備錯誤更正，可提高高密度下的可靠度。這與保護模組匯流排上資料的完整 ECC 記憶體是不同的東西。

為什麼 DDR5 的一個模組有兩個子通道？

DDR5 模組不是一個 64 位元通道，而是有兩個獨立的 32 位元子通道。因為可以同時進行兩個存取，所以效率提高。

理解度檢測

DDR5所採用的、在DRAM晶片內部更正錯誤的功能是哪一個？

  1. A晶片內建ECC（on-die ECC）
  2. B磨損平均（wear leveling）
  3. CTRIM
查看答案與解析

正確答案：A. 晶片內建ECC（on-die ECC）

DDR5為因應微縮導致單元不良與錯誤增加，在DRAM晶片內部內建了錯誤更正電路（on-die ECC）。它在128位元的資料上加8位元的檢查位元，於晶片內部更正單一位元的錯誤。不過，外部只看得到更正後的結果，無法保護資料傳輸過程中的錯誤，因此伺服器仍然需要系統端的ECC。

資料傳輸速率3,200 MT/s、資料匯流排寬度64位元的DDR4記憶體1個通道，其尖峰頻寬最接近下列何者？

  1. A約204.8 GB/s
  2. B約25.6 GB/s
  3. C約3.2 GB/s
查看答案與解析

正確答案：B. 約25.6 GB/s

尖峰頻寬為傳輸次數 × 匯流排寬度，即 3,200 × 10⁶ 次/s × 8位元組 = 25.6 GB/s。名稱中的「DDR4-3200」表示傳輸次數（MT/s），而模組的規格名稱「PC4-25600」表示頻寬（MB/s）。實際上，因更新、列切換、讀寫切換會產生等待時間，有效頻寬多半約為尖峰的七到八成。

DDR4 SDRAM等所使用的「8n預取（prefetch）」，其概念下列何者正確？

  1. A從內部單元陣列一次取出8倍寬度的資料，並在外部接腳以高速依序輸出
  2. B將8次的更新合併進行
  3. C將相同的資料寫入8顆晶片
查看答案與解析

正確答案：A. 從內部單元陣列一次取出8倍寬度的資料，並在外部接腳以高速依序輸出

由於單元陣列本身的運作速度不會隨世代有太大改變，DDR4在內部以1次存取一併讀出接腳寬度8倍（8n）的資料，再由外部高速的介面依序送出。因此突發長度為8。DDR5為16n預取，在不提高內部速度的情況下，將外部傳輸速率提升為2倍。這是隨世代從DDR（2n）、DDR2（4n）一路倍增而來的機制。

前往DRAM的練習題

相關名詞的解說

DDR SDRAM
在時脈的上升與下降兩個邊緣都傳輸資料的同步式 DRAM。歷經 DDR4、DDR5 等世代而不斷提高傳輸速度。是個人電腦與伺服器主記憶體的標準。
LPDDR
為 Low Power DDR 的縮寫。針對智慧型手機與筆記型電腦，強化低電源電壓與省電功能的 DRAM 規格。
