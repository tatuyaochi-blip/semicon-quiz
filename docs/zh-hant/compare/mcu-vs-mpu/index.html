MCU與MPU的差異：微控制器與微處理器比較

微控制器(MCU)將處理器、快閃記憶體、RAM，以及計時器、ADC、通訊介面等周邊功能整合在一顆晶片中，只靠一顆晶片就能運作小型系統。微處理器(MPU)主要是高速的處理器，需要外接DRAM與儲存裝置，多半執行Linux這類完整的作業系統。MCU適合簡單、低耗電的即時控制，MPU則適合複雜、軟體資源豐富的裝置。

適用於什麼情況

MCU
工作內容為控制與感測，需要非常低的耗電量與快速啟動，且程式能放進晶片內的記憶體時。
MPU
需要豐富的使用者介面、網路、檔案系統，或依賴作業系統的大型軟體時。
兩者並用
也有許多產品結合兩者。由MPU執行使用者介面與應用程式，由MCU負責對時間要求嚴格的控制與電源管理。

常見問題

微控制器(MCU)與微處理器(MPU)有什麼差異？

微控制器將CPU、快閃記憶體、RAM與周邊功能整合在一顆晶片中，只靠一顆晶片就能運作小型系統。微處理器主要是CPU，需要外接DRAM與儲存裝置，多半執行Linux等作業系統。

Raspberry Pi是微控制器嗎？

不是。Raspberry Pi使用微處理器等級的晶片與外接記憶體，並執行Linux。Raspberry Pi Pico則是微控制器的電路板。

哪一種耗電量比較小？

微控制器。休眠時為微安培等級，有時一顆鈕扣電池可運作數年。微處理器則為數百毫瓦到數瓦。

微控制器能執行Linux嗎？

一般不能。因為Linux需要MMU，以及比一般微控制器多得多的記憶體。微控制器執行的是不使用作業系統的程式碼，或小型即時作業系統。

使用微控制器的GPIO（通用輸入輸出）腳位時，首先必須設定的是下列何者？

  1. A該腳位要作為輸入還是輸出使用（方向）
  2. B腳位的顏色
  3. C撰寫程式的程式設計師姓名
查看答案與解析

正確答案：A. 該腳位要作為輸入還是輸出使用（方向）

GPIO腳位可由軟體決定作為輸入或輸出。以方向暫存器設為輸出後，寫入輸出暫存器的值會成為腳位電壓；設為輸入後，則可從輸入暫存器讀取腳位電壓。許多微控制器還能設定是否啟用上拉、輸出形式（推挽或開汲極），以及是否作為其他週邊電路的腳位使用。

在微控制器上調整LED亮度或馬達轉速時，常用的方法是下列何者？

  1. A把電源線加粗或變細
  2. B暫時停止程式的執行
  3. C以PWM高速反覆開關，並改變導通時間的比例
查看答案與解析

正確答案：C. 以PWM高速反覆開關，並改變導通時間的比例

以PWM高速開關LED或馬達時，在人眼看來亮度會依導通時間的比例而定，馬達則因慣性而以對應平均功率的速度旋轉。電晶體只在完全導通或截止的狀態下使用，因此比在中間電壓下使用的發熱損耗更少，可有效率地調整。頻率要選擇不會察覺LED閃爍或馬達噪音的值。

關於UART序列通訊的特徵，下列何者正確？

  1. A傳送端輸出時脈線，接收端以該時脈讀取資料
  2. B不使用時脈線，傳送端與接收端設定相同的通訊速度（鮑率），以起始位元通知區段的開始
  3. C在1條線上連接多個裝置，以位址選擇對象
查看答案與解析

正確答案：B. 不使用時脈線，傳送端與接收端設定相同的通訊速度（鮑率），以起始位元通知區段的開始

UART是以傳送與接收2條線（加上接地）進行通訊的非同步序列通訊。未傳送時維持在1的狀態，以0的起始位元通知字元的開始，在資料位元之後以1的停止位元結束。由於不傳送時脈，雙方必須設定為115200 bps等相同的速度。常用於除錯輸出，以及與GPS、無線模組的連接。

相關名詞的解說

微控制器
將 CPU、記憶體，以及計時器與 ADC 等周邊功能整合於 1 顆晶片的小型電腦。嵌入家電與汽車等設備中，負責控制。也稱為 MCU。
GPIO（通用輸入輸出）
通用輸入輸出（General Purpose Input/Output）的接腳。可由軟體設定為輸入或輸出，用於讀取開關與點亮 LED 等。
中斷
回應外部裝置的請求等，暫時中止執行中的處理，優先進行對應處理的 CPU 機制。結束後回到原本的處理。
