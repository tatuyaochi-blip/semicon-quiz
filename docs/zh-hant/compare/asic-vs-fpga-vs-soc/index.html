ASIC、FPGA、SoC 的差異：靈活性、成本、用途比較

這三個詞各自表示不同的事物。ASIC 是為特定用途專門設計的晶片。FPGA 是製造後可以改寫邏輯的晶片。SoC（系統單晶片）則是將 CPU 核心、GPU、記憶體控制器、輸入輸出等整個系統整合在一顆晶片上。這些詞的涵蓋範圍有重疊之處，智慧型手機的 SoC 多半是以 ASIC 的形式製造，內建處理器的 FPGA 也屬於 SoC。

項目ASICFPGASoC

靈活性製造後無法更改即使在現場也能改寫硬體固定，但在處理器上執行的軟體可以更新

適用於什麼情況

ASIC
生產數量多、功能已經確定，且想要將每單位成本的效能與電力效率發揮到最大時。
FPGA
生產數量少、規格可能變更、想要立刻開始時。例如試作、產品的導入期、專業設備等。
SoC
像智慧型手機那樣，想以一顆晶片實現完整的產品時。實際上 SoC 是以 ASIC 的形式設計，在製造前也常常先用 FPGA 試作。

常見問題

SoC 是 ASIC 嗎？

實際上多半是的。SoC 表示晶片上整合了什麼（整個系統），ASIC 則表示它是如何設計的（用途專用）。智慧型手機的 SoC 通常是以 ASIC 的形式製造。

為什麼要用 FPGA 來試作 ASIC？

FPGA 可以在數小時內改寫，因此在花錢製作昂貴的光罩之前，可以先測試並修正邏輯。ASIC 若在製造後才發現錯誤，多半需要重新流片（respin）。

ASIC 在什麼情況下比 FPGA 便宜？

生產數量多的時候。ASIC 的前期費用非常高，但每顆的成本最低；FPGA 的前期費用低，但每顆的成本較高。

FPGA 比 ASIC 慢嗎？

一般而言是的。用於改寫的電路會造成面積、速度與耗電的負擔，因此執行相同工作的專用 ASIC 速度更快，電力效率也更高。

理解度檢測

關於FPGA的特徵，下列何者正確？

  1. A電路在製造時即固定，無法變更
  2. B是類比電路專用的元件
  3. C製造後，使用者可以改寫邏輯電路的組態
查看答案與解析

正確答案：C. 製造後，使用者可以改寫邏輯電路的組態

FPGA是可在製造後以設定資料改寫具有小型真值表（LUT）的邏輯區塊及佈線連接方式的元件。由於不像ASIC那樣需要製造時間與光罩費用，因此用於試作、少量生產，以及需要功能更新的設備。另一方面，因為需要額外的改寫用電路，相同電路下ASIC在速度、耗電量、面積上都更有優勢。它並不是類比專用的元件。

將CPU、GPU、記憶體控制器、通訊功能等系統所需的功能整合於單一晶片的LSI，稱為什麼？

  1. ASiP（系統級封裝）
  2. B通用DRAM
  3. CSoC（系統單晶片）
查看答案與解析

正確答案：C. SoC（系統單晶片）

SoC是將系統所需的多項功能整合於單一晶片的LSI，智慧型手機用的處理器是其代表例。由於省去了晶片間的配線，零組件數量減少，可做到小型、高速、低耗電。另一方面，也有晶片變大導致良率下降，以及不易混合不同製程之電路的缺點。它與將多個晶片收納於一個封裝的SiP有所區別。通用DRAM則是單純的記憶體產品。

針對特定用途或特定客戶專門設計的LSI稱為什麼？

  1. A通用記憶體
  2. BASIC（特定應用積體電路）
  3. CFPGA
查看答案與解析

正確答案：B. ASIC（特定應用積體電路）

ASIC（Application Specific Integrated Circuit）是為了特定產品或用途而專門設計的LSI。由於可針對所需功能最佳化，在效能與耗電方面具有優勢，但包含光罩費用在內的開發費用高，且開發期間也需數個月以上，因此用於預期有一定產量的產品。製造後可改寫的FPGA適合少量產品與試產，通用記憶體則是多種用途共通的產品。

相關名詞的解說

ASIC(特殊應用積體電路)
針對特定用途或客戶專門設計的LSI。在性能與耗電量上比通用品有利，但開發費用大，適合預期有量的用途。
FPGA(現場可程式化閘陣列)
製造後，使用者可改寫邏輯電路組態的LSI。用於原型、少量生產的產品，以及ASIC的驗證等。
SoC(系統單晶片)
將CPU、GPU、記憶體控制器、通訊功能等系統所需功能整合在一個晶片上的LSI。智慧型手機的核心就是代表例子。
