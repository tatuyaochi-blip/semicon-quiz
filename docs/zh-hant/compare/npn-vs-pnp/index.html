NPN 電晶體與 PNP 電晶體的差異：結構、電流方向、電路符號、使用方式比較

NPN 電晶體是以 n 型的射極與集極夾住 p 型的基極，PNP 電晶體則相反，是以 p 型的射極與集極夾住 n 型的基極。NPN 主要由電子傳導電流，PNP 主要由電洞傳導電流，電壓與電流的方向全部相反。在矽中，電子的遷移率大於電洞，因此在相同尺寸下，NPN 較快，電流增益也較容易做高，所以較常使用。

適用於什麼情況

NPN
猶豫時的第一選擇。常用於從微控制器的接腳在 GND 側讓 LED 或繼電器導通與截止的電路，以及一般的放大電路。
PNP
想在電源側讓負載導通與截止時，或想製作從電源送出電流的電流源時使用。
搭配使用
用特性相匹配的 NPN 與 PNP 一組（互補對），可以製作分別負責正、負半週的推挽放大電路。B 類會產生交越失真，因此一般會做成流過少量偏壓電流的 AB 類。

常見問題

如何分辨 NPN 與 PNP 的電路符號？

以射極上箭頭的方向來分辨。箭頭表示基極與射極之間的 PN 接面中順向電流流動的方向（從 p 型到 n 型），NPN 是從射極朝外，PNP 是朝內指向射極。

為什麼 NPN 比較常用？

因為在矽中，電子的遷移率約為電洞的 2～3 倍，在相同結構下，NPN 的電流增益與運作速度較容易做高。此外，在以 GND 為基準的電路中，NPN 的低側開關較容易組成，這也是原因之一。

可以把 NPN 換成 PNP 嗎？

無法直接替換。電壓與電流的方向全部相反，因此包括電源極性與負載位置在內，都必須重新設計電路。若將整個電路在電源側與 GND 側之間上下翻轉，就能實現相同的功能。

如何讓 PNP 電晶體導通？

使基極電壓比射極低約 0.6～0.7 V，從基極汲出電流。在射極接電源的高側開關中，透過電阻將基極拉往 GND 側即導通，使其與射極同電壓則截止。

理解度檢測

NPN電晶體用於放大（在主動區工作）時，正確的偏壓條件是哪一個？

  1. A基極-射極間為順向偏壓，基極-集極間為逆向偏壓
  2. B基極-射極間為逆向偏壓，基極-集極間為順向偏壓
  3. C基極-射極間與基極-集極間皆為順向偏壓
查看答案與解析

正確答案：A. 基極-射極間為順向偏壓，基極-集極間為逆向偏壓

在主動區，基極-射極接面為順向偏壓，使電子從射極注入基極；基極-集極接面為逆向偏壓，以強電場將穿過基極的電子拉往集極。集極電流幾乎不受集極電壓影響，而是由基極電流（或VBE）決定，因此可以放大。若兩者皆為順向偏壓，則為飽和區（開關導通）；若兩者皆為逆向偏壓，則為截止區（關閉）。

在PNP電晶體中，從射極注入基極並主要傳導電流的載子是哪一個？

  1. A電子
  2. B電洞
  3. C離子
查看答案與解析

正確答案：B. 電洞

在PNP電晶體中，電洞從p型射極注入n型基極，穿過基極後被p型集極收集。NPN中則由電子擔任相同的角色。電子的遷移率約為電洞的3倍，因此相同結構下NPN速度較快、電流增益也較高，是主流。PNP用於與NPN組合的推挽電路，或電源正側的開關（高側）等，電壓與電流的方向與NPN相反。

在NPN電晶體的電路符號中，射極上箭頭的方向，下列何者正確？

  1. A從集極朝向射極的方向
  2. B從基極朝向射極外側的方向
  3. C從射極外側朝向基極的方向
查看答案與解析

正確答案：B. 從基極朝向射極外側的方向

電路符號的箭頭表示基極-射極PN接面中順向電流流動的方向（p→n）。NPN中電流從基極（p）流向射極（n），所以箭頭朝外；PNP則朝內。有一個常見的記法是「NPN: Not Pointing iN（不指向內）」。箭頭只畫在射極側，因此從符號也能分辨射極與集極。

前往雙載子電晶體的練習題

相關名詞的解說

電流增益(hFE)
雙載子電晶體的集極電流與基極電流之比(IC/IB)。
主動區
基極-射極間為順向偏壓、基極-集極間為逆向偏壓的狀態。流過與基極電流成正比的集極電流，用於放大。
飽和區
雙載子電晶體的基極-射極接面與基極-集極接面都處於順向偏壓的狀態。集極-射極間電壓降到約 0.1〜0.3 V，相當於開關導通。
射極隨耦器
共集極的放大電路。電壓增益約為 1，但輸入阻抗高、輸出阻抗低，因此用作不衰減訊號即可驅動下一級的緩衝器。
交越失真
在 B 類推挽放大電路中，負責正、負半週期的電晶體切換的 0 V 附近，因兩者都不導通而產生的失真。可藉由流過少許偏壓電流的 AB 類來減輕。
