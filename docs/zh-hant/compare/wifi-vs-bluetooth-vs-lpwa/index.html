Wi-Fi、藍牙與LPWA的差異：距離、速度、功耗、頻率、用途比較

三者都是以無線連接設備的方式，但在傳輸距離、速度與功耗之間的取捨不同。Wi-Fi是IEEE 802.11標準的無線區域網路，讓電腦與智慧型手機高速連上網際網路。藍牙在數公尺到數十公尺的短距離內，直接連接耳機、鍵盤、穿戴式裝置等，省電的低功耗藍牙（BLE）也用在以鈕扣電池運作的感測器上。LPWA是壓低速度、換取數公里以上距離與以年計電池壽命的IoT通訊方式的總稱。

項目Wi-Fi藍牙LPWA
標準IEEE 802.11（由Wi-Fi Alliance認證）由Bluetooth SIG制定。有傳統的BR/EDR與省電的低功耗藍牙（BLE）方式的總稱。有使用免執照頻段的LoRaWAN等，以及使用行動電話頻段的LTE-M、NB-IoT等
頻段2.4 GHz頻段、5 GHz頻段（Wi-Fi 6E起也有6 GHz頻段）2.4 GHz頻段主要為Sub-GHz頻段（日本為920 MHz頻段）或行動電話的頻段
通訊距離估計室內數十公尺數公尺至數十公尺左右（依功率與方式可達100 m以上）數公里至十幾公里左右（依視線與環境而定）
傳輸速度估計數十Mbps至數Gbps（依標準的世代與條件而定）BLE最高1至2 Mbps（實際可傳送的速度更低）。BR/EDR最高3 Mbps數百bps至數百kbps左右（LTE-M可達約1 Mbps）
功耗大。適合接電源的設備或經常充電的設備BR/EDR中等。BLE只短時間通訊後就休眠，有些設備以鈕扣電池可運作數個月到數年非常小。傳送資料少時，以電池運作數年至10年左右是常見的估計
連接方式以存取點為中心的星狀。由存取點連到LAN與網際網路與智慧型手機等以一對一或一對多直接連接。也有以廣播（advertising）運作的信標與網狀網路由終端到基地台（閘道器）的星狀。主要由終端將少量資料送往雲端

執照與線路免執照。自行設置存取點免執照。設備之間直接連接LoRaWAN等免執照，也可自行設置閘道器。LTE-M與NB-IoT需與電信業者簽約使用其網路
主要用途電腦與智慧型手機的網際網路連線、影片觀看、家電與攝影機的網路連線無線耳機、鍵盤與滑鼠、智慧手錶、信標、健康照護設備電力、瓦斯、自來水的抄表，農地或設備的感測器，物品的位置追蹤

數值為具代表性的大致參考值，會因世代或產品而異。

適用於什麼情況

Wi-Fi
想高速傳送大量資料，或想直接連上網際網路時。適合接電源的設備或充電使用的設備。
藍牙
連接智慧型手機或電腦旁邊的周邊設備時。想以電池長時間運作的感測器或穿戴式裝置，則使用BLE。
LPWA
想從沒有電源的地方，以電池持續數年把少量資料傳到遠處時。不適合即時控制或傳送影像與影片。

常見問題

Wi-Fi與藍牙同在2.4 GHz頻段，不會互相干擾嗎？

因為使用相同的2.4 GHz頻段，有時會互相干擾。藍牙以跳頻不斷改變使用的頻率，並以避開壅塞通道的適應性跳頻來減少影響。Wi-Fi改用5 GHz頻段，就能避開2.4 GHz頻段的壅塞。微波爐也會發出2.4 GHz頻段的電波，因此在附近時通訊可能受到干擾。

為什麼LPWA能以很少的電力傳到遠處？

因為它大幅降低傳輸速度以提高每位元的能量，並縮窄接收頻寬以減少雜訊，讓微弱的電波也能接收。此外，像日本920 MHz頻段這樣的Sub-GHz頻段，以相同增益的天線比較時，自由空間路徑損耗比2.4 GHz頻段小約8 dB，也較容易繞射到建築物等的後方。功耗小則是因為傳送的資料少，且幾乎所有時間都在休眠。

BLE與傳統藍牙有什麼不同？

BLE讓通訊時間非常短，其餘時間關閉電路休眠，以降低功耗，適合間歇傳送少量資料的感測器與信標。傳統藍牙（BR/EDR）一直用於連續傳送聲音等用途。兩者都使用2.4 GHz頻段，但方式不同，無法直接互相通訊（也有同時支援兩者的設備）。

Wi-Fi的標準名稱與世代名稱如何對應？

IEEE 802.11n稱為Wi-Fi 4，802.11ac稱為Wi-Fi 5，802.11ax稱為Wi-Fi 6，而把802.11ax擴展到6 GHz頻段的是Wi-Fi 6E。802.11ac只使用5 GHz頻段，802.11n與802.11ax則同時使用2.4 GHz與5 GHz頻段。

理解度檢測

設收發天線的增益為0 dBi，頻率2.4 GHz（波長0.125 m）的電波在自由空間中傳播100 m時，自由空間路徑損耗最接近下列何者？

  1. A40 dB
  2. B60 dB
  3. C80 dB
查看答案與解析

正確答案：C. 80 dB

自由空間路徑損耗是在等向性天線之間，功率隨距離呈球面擴散而減弱的比例，以 L = (4πd/λ)² 表示。d = 100 m、λ = 0.125 m 時，4πd/λ ≈ 1.0×10⁴，因此 L = 20·log₁₀(1.0×10⁴) ≈ 80 dB。以dB表示時，距離每變為2倍損耗約增加6 dB，每變為10倍增加20 dB。在這個公式中，相同距離下頻率越高（波長越短），損耗越大。

IEEE 802.11ac（Wi-Fi 5）的無線區域網路所使用的頻段為下列何者？

  1. A只有2.4 GHz頻段
  2. B2.4 GHz頻段與5 GHz頻段兩者
  3. C只有5 GHz頻段
查看答案與解析

正確答案：C. 只有5 GHz頻段

IEEE 802.11的各規格分別規定了使用的頻段。802.11b與802.11g使用2.4 GHz頻段，802.11a與802.11ac使用5 GHz頻段，802.11n（Wi-Fi 4）與802.11ax（Wi-Fi 6）則同時使用2.4 GHz頻段與5 GHz頻段。把802.11ax擴展到6 GHz頻段的稱為Wi-Fi 6E。即使是同時支援2.4 GHz與5 GHz頻段的存取點，以802.11ac通訊的也只有5 GHz頻段那一側。

為了減輕無線區域網路的隱藏節點問題而使用的RTS/CTS機制，下列說明何者適當？

  1. A想要傳送的終端送出傳送要求（RTS），存取點回覆允許傳送（CTS），收到CTS的周圍終端在該通訊期間暫停傳送
  2. B終端一邊傳送一邊監視接收的電波，偵測到碰撞時立即停止傳送
  3. C把所有終端的發射功率調到最大，讓彼此的電波都能到達
查看答案與解析

正確答案：A. 想要傳送的終端送出傳送要求（RTS），存取點回覆允許傳送（CTS），收到CTS的周圍終端在該通訊期間暫停傳送

隱藏節點問題發生在兩台終端的電波都能到達存取點，但終端之間因距離或障礙物而無法收到彼此電波的情況。由於彼此察覺不到對方的傳送，會判斷通道空閒而同時傳送，在存取點發生碰撞。在RTS/CTS中，存取點回覆的CTS記載了通訊所需的時間，收到CTS的終端在這段時間內暫停傳送。RTS與CTS的交換會降低效率，因此也有只在傳送大訊框時才使用的設定。

前往無線通訊基礎的練習題

相關名詞的解說

Wi-Fi
依據IEEE 802.11規格之無線區域網路的通稱，也是表示設備通過業界團體Wi-Fi Alliance認證的名稱。主要使用2.4 GHz、5 GHz、6 GHz頻段的電波，經由存取點連接到區域網路。以CSMA/CA協調電波的使用，並以OFDM、MIMO，以及從Wi-Fi 6（802.11ax）開始的OFDMA提高速度與效率。通訊以WPA2或WPA3加密。
低功耗藍牙（BLE）
使用2.4 GHz頻段之短距離無線通訊藍牙中，重視降低耗電的方式。把通訊時間縮到極短，其餘時間停止電路休眠，使設備即使用鈕扣電池也能長時間運作。用於週期性送出稱為廣播（advertising）之短訊號的信標，以及穿戴式裝置、感測器等。與傳統藍牙（BR/EDR）彼此無法直接通訊。
低功耗廣域網路（LPWA）
目的在於把感測器數值這類少量資料，從以電池運作數年的設備傳送到數公里以上遠處的無線通訊總稱。壓低傳輸速率，使微弱的電波也能接收，藉此延長通訊距離。有像LoRaWAN這樣使用免執照頻段（在日本為920 MHz頻段等）的，也有像LTE-M與NB-IoT這樣使用行動電話頻段的。
正交分頻多工（OFDM）
把資料分配到彼此正交的許多子載波上，各自以低符元率調變後平行傳送的方式。使子載波間隔等於符元長度的倒數，即使頻譜重疊也能互不干擾地分離。不易受多路徑影響，用於無線區域網路、4G LTE、5G NR、地面數位電視廣播等。
隱藏節點問題
在無線區域網路中，兩台終端的電波都能到達存取點，但終端之間因距離或障礙物而無法收到彼此電波時發生的問題。由於察覺不到彼此的傳送而同時傳送，在存取點發生碰撞。可用RTS/CTS減輕，以存取點回覆的CTS使周圍的終端暫停傳送。
自由空間路徑損耗（FSPL）
在沒有障礙物與反射的自由空間中，等向性天線之間電波功率隨距離呈球面擴散而減弱的比例。以 L = (4πd/λ)² 表示，以dB表示時，距離每變為2倍約增加6 dB，每變為10倍增加20 dB。在鏈路預算的計算中，作為傳播損耗的基準使用。
鏈路預算（Link budget）
把從發射功率到接收功率之間的增益與損耗累加起來，估算到達接收機的功率，以及相對於接收所需功率（接收靈敏度）之餘裕的計算。使用dB與dBm，以發射功率 + 天線增益 − 傳播損耗 − 纜線損耗等加減求得。除了無線之外，光通訊的功率預算也使用相同的概念。
