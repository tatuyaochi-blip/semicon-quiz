ARM、RISC-V、x86 的差異：比較指令集架構

ARM、RISC-V、x86 是三種指令集架構(ISA)，是軟體與處理器之間的約定。ARM 與 RISC-V 是 RISC 式的設計，x86 則是歷經數十年成長而來的 CISC 式設計。最大的差異在於誰能製造，以及軟體生態的規模。x86 在個人電腦與伺服器上占優勢，ARM 在智慧型手機上占優勢，並正擴展到筆記型電腦與伺服器。RISC-V 是開放標準，在嵌入式領域快速擴展。

常見問題

ARM 比 x86 快嗎？

並非與生俱來就是如此。效能取決於各個處理器的設計與製程。ARM 的設計傾向於電源效率高，x86 的設計則常在單執行緒的最高效能上領先。

為什麼 RISC-V 是免費的？

RISC-V 是由 RISC-V International 管理的開放標準，任何人都能免授權費製造晶片。ARM 與 x86 則是專有的。

能在 x86 上執行 ARM 用的軟體嗎，或反過來？

無法直接執行。因為指令集不同，必須重新編譯程式，或是透過模擬器或轉換機制來執行。

Apple 的 Mac 使用什麼處理器？

Apple 晶片的 Mac 使用 Apple 自行設計、以 ARM 為基礎的處理器。

正確答案：B. 指令集架構（ISA）

ARM、x86、RISC-V 是指令集架構（ISA）的名稱，規定處理器所能理解的指令種類、暫存器、記憶體的處理方式等軟體與硬體之間的約定。只要是相同的 ISA，即使設計的企業不同，也能執行相同的程式。x86 由 Intel 與 AMD 用於個人電腦與伺服器，ARM 用於智慧型手機與 Apple 的 Mac，RISC-V 則以嵌入式領域為中心持續擴展。

  2. B是 GPU 專用的指令集
  3. C是規格公開、無需授權費即可使用的指令集架構
查看答案與解析

正確答案：C. 是規格公開、無需授權費即可使用的指令集架構

RISC-V 是 2010 年起於加州大學柏克萊分校開始開發的開放式 ISA，規格公開，任何人都能免授權費地實作。基本的整數指令約 40 個，相當精簡，可依用途選擇並組合浮點數、向量等擴充。由於也能新增自訂指令，因此在嵌入式微控制器、儲存裝置的控制器、AI 加速器等領域的採用日益普及。

關於 RISC（精簡指令集電腦）的特徵，下列何者正確？

  1. A具有大量複雜且長度不一的指令
  2. B將指令精簡為單純且數量少的集合，使管線化處理更容易進行
  3. C完全沒有指令
查看答案與解析

正確答案：B. 將指令精簡為單純且數量少的集合，使管線化處理更容易進行

RISC 的設計理念是將指令精簡為單純且長度一致的集合，運算在暫存器之間進行，與記憶體的往來僅限於載入（load）與儲存（store）指令。由於各指令的處理時間一致，適合管線化，代表例有 ARM 與 RISC-V。具有複雜指令的 CISC（如 x86）現今在內部也會將指令分解成單純的 μOP 來執行，因此兩者的差異正在縮小。

相關名詞的解說

指令集架構(ISA)
處理器可執行的指令與暫存器等，從軟體角度看到的處理器規格。例如 x86、Arm、RISC-V 等。

  • 馮紐曼架構與哈佛架構的差異：比較指令與資料的處理以記憶體、匯流排、傳輸量、靈活性、複雜度、代表性裝置與修正式哈佛架構等面向，用表格比較馮紐曼架構與哈佛架構。
  • 循序執行與亂序執行的差異：發出順序、危障、電路規模、IPC 比較從指令的發出順序、發生等待時的動作、危障的處理、暫存器重新命名與 ROB、電路規模與功耗、IPC、使用場合等面向比較循序執行與亂序執行。

  • NAND 型與 NOR 型快閃記憶體的差異：速度、容量、用途比較從單元的連接方式、讀取速度、抹除單位、容量、成本、可靠度與用途等面向，以表格比較 NAND 型與 NOR 型快閃記憶體。
  • FinFET 與 GAA 電晶體的差異：結構、控制性、製造比較從閘極結構、通道、靜電控制、寬度調整、製造與採用現況等面向，以表格比較 FinFET 與環繞式閘極（GAA）奈米片電晶體。
