LED 與半導體雷射的差異：發光機制、光的性質、用途比較

LED 與半導體雷射都是對 PN 接面施加順向電流，在電子與電洞復合時發光。LED 的光來自自發放射，波長範圍寬，並朝各個方向發散。半導體雷射具有讓光來回反射的共振腔，以受激放射放大光，因此能得到波長與相位一致、直線前進的強光。照明與顯示使用 LED，光通訊、光碟與感測則使用雷射。

項目LED半導體雷射
發光機制自發放射。電子與電洞各自在隨機的時間點復合而發光受激放射。光會進一步產生相同波長、相位與方向的光而被放大
光學共振腔無有。在劈裂的端面（邊射型）或多層膜反射鏡（VCSEL）之間讓光來回反射

適用於什麼情況

LED
想明亮地照亮大範圍時，或用於顯示時。便宜、壽命長，驅動也簡單。
半導體雷射
想將光聚成細光束傳送到遠處時、想快速調變以傳送資訊時，或需要波長一致的光時。用於光通訊、距離量測、加工等。
共同點
兩者發出的光的顏色（波長），主要都由發光層半導體的能隙決定。使用的是發光效率高的 GaN 系、GaAs 系、InP 系等直接能隙化合物半導體，間接能隙的矽則不適合作為發光元件。

常見問題

LED 與雷射的光有什麼不同？

雷射的光波長與相位一致，直線前進且不易發散，相對地 LED 的光波長範圍寬，並朝各個方向發散。這是因為 LED 是以自發放射發光，雷射則是以共振腔內的受激放射發光。

什麼是半導體雷射的臨界電流？

是開始雷射振盪的電流。在共振腔內，受激放射造成的光放大超過損耗時就會振盪，電流大於此值時，光輸出會隨電流急遽增加。電流小於臨界值時，只會發出像 LED 那樣微弱的自發放射光。

LED 的顏色由什麼決定？

主要由發光層半導體的能隙決定，有波長 λ(nm) ≈ 1240 / Eg(eV) 的關係。藍色與綠色使用 InGaN，紅色使用 AlGaInP 等。大多數白光 LED 是用螢光粉將藍光 LED 的部分光轉換成黃色等再加以混合。

為什麼很難用矽製作 LED 或雷射？

因為矽是間接能隙半導體，電子與電洞復合發光時，還需要聲子（晶格振動）參與，發光效率非常低。在矽光子學中，會搭配使用 InP 等化合物半導體的雷射。

理解度檢測

關於半導體雷射與LED的差異，下列何者正確？

  1. ALED的波長寬度較窄，單色性較高
  2. B半導體雷射藉由受激輻射與光共振腔，發出波長與相位一致且指向性高的光
  3. C半導體雷射不通電流也能發光
查看答案與解析

正確答案：B. 半導體雷射藉由受激輻射與光共振腔，發出波長與相位一致且指向性高的光

LED發出的是自發輻射的光，波長寬度達數十nm，並向各個方向擴散。半導體雷射在以劈裂面等形成的光共振腔中，通以超過臨界值的電流以引發受激輻射，發出波長與相位一致、寬度窄（可達1 nm以下）且指向性高的光。其用於光通訊、光碟、雷射印表機、LiDAR、加工等領域。

決定LED發光顏色（發光波長）的主要因素為下列何者？

  1. A封裝的形狀
  2. B驅動電流的方向
  3. C發光層所使用半導體的能隙
查看答案與解析

正確答案：C. 發光層所使用半導體的能隙

在LED中，電子與電洞復合時，會發出相當於能隙能量的光。波長約為 λ(nm) ≈ 1240/Eg(eV)，例如GaN系（InGaN）約2.7 eV，為藍光約460 nm；AlGaInP約1.9 eV，為紅光約650 nm。改變發光層的組成即可調整能隙，即使同為InGaN，增加In的比例就會變成綠光。白光LED是藍光LED與黃色螢光粉的組合。

關於LED發光的機制，下列何者正確？

  1. A順向偏壓注入的電子與電洞復合時發出光
  2. B因逆向崩潰電流而高溫，由熱輻射發光
  3. C有光照射時電流流動
查看答案與解析

正確答案：A. 順向偏壓注入的電子與電洞復合時發出光

對LED施加順向電壓時，電子從n側、電洞從p側注入接面處，復合時會以光的形式釋放相當於能隙的能量。發光顏色由材料決定，紅光為AlGaInP，藍光與綠光為InGaN系。白光LED是在藍光LED上搭配黃色螢光粉。要有效率地發光需要直接躍遷型材料，因此矽無法做出實用的LED。

相關名詞的解說

順向偏壓
對 p 側施加正電壓、對 n 側施加負電壓。位障降低，電流容易流動。反過來施加則為逆向偏壓，幾乎沒有電流流動。
直接能隙
導電帶底部與價電帶頂端位於相同波數的能帶結構。電子與電洞復合時能有效率地發光。例如 GaAs 等。
能隙
價電帶頂端與導電帶底端之間的能量差。矽在室溫下約為 1.12 eV。能隙越大，越耐高溫與高電壓。
量子井
以能隙大的層夾住數 nm 厚、能隙小的薄層的結構。因為能侷限載子而容易發生復合，用於 LED 與雷射的發光層。
VCSEL(垂直共振腔面射型雷射)
朝垂直於基板的方向發出光的半導體雷射。可在晶圓狀態下檢測，也容易排成二維陣列，因此用於資料通訊與臉部辨識的光源等。
