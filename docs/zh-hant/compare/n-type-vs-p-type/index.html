n 型半導體與 p 型半導體的差異：摻雜物、多數載子、費米能階、遷移率比較

n 型半導體是在矽中加入磷或砷等 V 族雜質（施體），以多出的電子作為多數載子。p 型半導體是加入硼等 III 族雜質（受體），以電子不足所形成的電洞作為多數載子。費米能階在 n 型中偏向導帶側，在 p 型中偏向價帶側。在矽中，電子的遷移率約為電洞的 2 至 3 倍，因此在相同雜質濃度下，n 型的電阻率較低。

適用於什麼情況

n 型
想讓電子流動時。用於 nMOS 的源極、汲極、npn 電晶體的射極與集極，以及製作 pMOS 的 n 井等。
p 型
想讓電洞流動時。用於 pMOS 的源極、汲極、npn 電晶體的基極，以及製作 nMOS 的 p 井等。
搭配使用
n 型與 p 型接觸便形成 PN 接面，是二極體、電晶體、太陽能電池、LED 等的基礎。在製造中，也會在既有的層中大量加入相反型的雜質，使其型別反轉（反摻雜）。

常見問題

n 型半導體電子很多，整體是否帶負電？

不，整體是電中性的。施體放出 1 個電子後，施體本身會成為正離子留在晶格中，與電子的負電荷互相抵消。p 型也一樣，電洞的正電荷與離子化受體的負電荷互相平衡。

n 型中也有電洞嗎？

有。在熱平衡下，電子密度與電洞密度的乘積等於本質載子密度的平方（n × p = ni²），因此若施體濃度為 1×10¹⁶ cm⁻³，室溫下的電洞密度約為 1×10⁴ cm⁻³。數量雖少，但這些少數載子在 PN 接面與雙極性電晶體的運作中扮演重要角色。

同時加入施體與受體會怎樣？

兩者會互相抵消（補償），變成較多一方的型別。載子密度大致由濃度差決定，但遷移率會因兩種離子化雜質的散射而下降。在井中製作相反型的源極、汲極時，就是利用此性質使型別反轉。

為什麼 n 型與 p 型的費米能階位置不同？

因為費米能階是電子佔據機率為 1/2 的能量，代表載子的分布。在導帶電子多的 n 型中偏向導帶側，在價帶電子缺少、電洞多的 p 型中偏向價帶側。在室溫的矽中，雜質濃度每增加 10 倍，就向能帶邊緣靠近約 60 mV。

理解度檢測

在矽中摻入磷（P）作為雜質時，下列說明何者正確？

  1. A成為以電洞為多數載子的p型半導體
  2. B成為以電子為多數載子的n型半導體
  3. C載子不會增加，仍是本質半導體
查看答案與解析

正確答案：B. 成為以電子為多數載子的n型半導體

磷屬於V族，有5個價電子，在矽（IV族）的共價鍵中會多出1個未被使用的電子。這個電子只是鬆散地束縛在約0.045 eV的淺能階上，因此在室溫下幾乎全部會躍遷到導帶而成為傳導電子。這類雜質稱為施體，會形成n型半導體。此外，砷（As）和銻（Sb）也是施體。若要形成p型，則摻入硼（B）等III族元素（受體）。

在矽中摻入硼（B）作為雜質時，下列說明何者正確？

  1. A電性上不活躍，導電型不變
  2. B作為施體，成為n型半導體
  3. C作為受體，成為p型半導體
查看答案與解析

正確答案：C. 作為受體，成為p型半導體

硼屬於III族，有3個價電子，共價鍵中少1個電子，因此會從周圍接受電子。如此一來價電帶中產生電洞，矽就成為p型。硼是矽中具代表性的受體，其能階距價電帶約0.045 eV，很淺，在室溫下幾乎全部離子化。由於原子輕、擴散快，形成淺接面時會使用低能量植入或BF2的植入。

p型半導體的多數載子為下列何者？

  1. A離子化的受體
  2. B電洞
  3. C電子
查看答案與解析

正確答案：B. 電洞

在p型中，受體從價電帶接受電子而使電洞增加，因此多數載子是電洞，少數載子是電子。離子化的受體是固定在晶格上的負電荷，本身無法移動。不過在空乏層中，這種固定電荷是產生電場與內建電位的主角。在MOSFET中，是在p型基板表面聚集少數載子的電子（反轉）而形成n通道。

前往半導體物性的練習題

相關名詞的解說

施體
對半導體提供電子的雜質。對矽而言，是磷(P)、砷(As)等 V 族元素，用來形成 n 型半導體。
受體
從半導體接收電子而產生電洞的雜質。對矽而言，是硼(B)等 III 族元素，用來形成 p 型半導體。
費米能階
電子佔據該能階的機率剛好為 1/2 的能量。n 型偏向導電帶側，p 型偏向價電帶側。
遷移率
施加電場時載子移動的難易程度。在矽中，電子的遷移率比電洞大。
本質載子濃度
不含雜質的半導體中，因熱而產生的電子與電洞的密度(記為 ni)。在矽中室溫下約為 1×10¹⁰ cm⁻³，溫度上升時急遽增加。熱平衡時 n × p = ni² 成立。
