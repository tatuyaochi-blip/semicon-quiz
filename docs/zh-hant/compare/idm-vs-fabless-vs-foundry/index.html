IDM、無晶圓廠、晶圓代工的差異：半導體企業的商業模式比較

IDM（垂直整合元件製造商）是從設計、製造到銷售都由自家完成的企業。無晶圓廠（Fabless）不擁有工廠（晶圓廠），專注於設計與銷售，製造則委託晶圓代工。晶圓代工是承接其他公司所設計晶片之製造的企業。隨著先進工廠的興建與製造技術的開發需要巨額投資，設計與製造的分工也逐漸擴大。

項目IDM無晶圓廠晶圓代工
負責的製程設計、前段製程、後段製程與銷售全部（有時會將後段製程等部分委外）設計與銷售。製造委託外部前段製程的製造（晶圓的製造）。也承接先進封裝等部分後段製程
自家工廠有無有（製造是事業核心）
銷售的東西自有品牌的半導體產品自有品牌的半導體產品製造服務。原則上不擁有自有品牌產品
主要投資工廠與研發兩者設計人員、EDA 工具、IP、光罩與試產費用。不需要投資工廠工廠與製造技術的開發。先進工廠需要巨額投資
優勢可以整體最佳化設計與製造，容易掌握獨家製程與供應沒有工廠的固定成本，可將資源集中於設計，並能選用最先進的製程匯集眾多客戶的訂單提高工廠稼動率，回收巨額投資
劣勢需求下滑時工廠的固定成本沉重，持續投資先進製程的負擔也很大產能與價格受晶圓代工左右，製造吃緊時難以確保供應受客戶需求波動影響，必須持續進行先進技術的開發競爭與設備投資
代表性企業Intel、Samsung、Texas Instruments、KioxiaNVIDIA、Qualcomm、AMD、Broadcom、MediaTekTSMC、UMC、GlobalFoundries、SMIC
常見的產品領域記憶體（DRAM、NAND）、類比、功率半導體、微控制器、CPUGPU、智慧型手機用 SoC、通訊用 IC、FPGA以客戶設計的邏輯半導體為主的各種晶片

適用於什麼情況

IDM
常見於製造技術本身就是產品差異的領域。在記憶體、類比與功率半導體中，同時精進製程與設計就是競爭力。
無晶圓廠
適合以電路設計或軟體做出差異的產品。由於不擁有工廠，即使是新創企業也能做出採用先進製程的晶片。
晶圓代工
統一承接眾多客戶製造的形態。先進工廠需要巨額投資，因此先進邏輯的製造逐漸集中到能匯集大量訂單的晶圓代工。
中間形態與周邊企業
也有以自家工廠生產部分產品、將先進產品等委託晶圓代工的輕晶圓廠（Fab-lite）形態。後段製程由 OSAT 負責，電路設計資產的授權則由 IP 供應商負責，共同支撐分工體系。

常見問題

無晶圓廠與晶圓代工有什麼不同？

無晶圓廠是不擁有工廠、設計並銷售晶片的企業，晶圓代工是製造其他公司所設計晶片的企業。分工方式是由無晶圓廠將設計資料交給晶圓代工，晶圓代工製造出晶圓後，再由 OSAT 等進行封裝，做成產品。

為什麼設計與製造的分工會擴大？

因為先進工廠的興建與製造技術的開發需要巨額投資，單一公司難以同時在設計與製造兩方面保持最先進。晶圓代工匯集眾多客戶的訂單來回收投資，無晶圓廠則能在沒有工廠負擔的情況下專注於設計。

什麼是輕晶圓廠（Fab-lite）？

是一邊以自家工廠生產部分產品，一邊將需要先進製程的產品等委託晶圓代工的形態。多為想壓低工廠投資的 IDM 所採用，介於 IDM 與無晶圓廠之間。

一家公司會同時兼具多種形態嗎？

會。Samsung既是生產自家記憶體等產品的 IDM，同時也經營為其他公司製造晶片的晶圓代工事業。Intel 也已開始晶圓代工事業，並將部分自家產品委託外部晶圓代工製造。

理解度檢測

從設計、前段與後段製程的製造到銷售皆由自家一貫完成的半導體企業型態為何？

  1. AIDM（垂直整合元件製造商）
  2. B無晶圓廠（Fabless）
  3. COSAT
查看答案與解析

正確答案：A. IDM（垂直整合元件製造商）

IDM（Integrated Device Manufacturer）是設計、製造到銷售皆由自家完成的企業。其優點是設計與製造的人員距離近，容易共同最佳化製程與產品，但需要對工廠做龐大的投資。在製造技術本身就會造成產品差異的記憶體、功率半導體、類比半導體等領域中較為常見。無晶圓廠沒有工廠，OSAT則承接後段製程委託。

下列關於「無晶圓廠（Fabless）」企業的說明，何者正確？

  1. A從設計到製造、銷售皆由自家一貫完成的企業
  2. B不擁有自家製造工廠，專注於設計與銷售的企業
  3. C只接受半導體後段製程委託的企業
查看答案與解析

正確答案：B. 不擁有自家製造工廠，專注於設計與銷售的企業

無晶圓廠（fab-less）的意思是沒有製造工廠（fab）的企業。它將經營資源集中於設計與銷售，製造委託給晶圓代工廠，封裝與測試則委託給OSAT。由於不需要對工廠做龐大投資，新創企業也能推出先進產品，GPU與智慧型手機用SoC的大廠多半採取這種型態。從設計到製造皆由自家完成的企業是IDM，承接後段製程委託的企業則是OSAT。

  1. A專門接受委託，製造其他公司所設計之半導體的企業
  2. B不擁有工廠，專注於半導體設計與銷售的企業
  3. C專門販售半導體製造設備零組件的企業
查看答案與解析

正確答案：A. 專門接受委託，製造其他公司所設計之半導體的企業

晶圓代工廠是依據客戶企業所設計的電路資料來製造晶圓的代工製造企業（或事業）。1987年成立的台積電（TSMC）確立了專業晶圓代工的型態。由於可由眾多客戶共同分攤需要龐大設備投資的先進工廠，與無晶圓廠（Fabless）企業之間的分工因而擴大。不擁有工廠而專注於設計與銷售的是無晶圓廠企業，販售設備零組件的則是設備相關企業。

前往半導體產業與市場的練習題

相關名詞的解說

IDM(整合元件製造商)
從設計、前段與後段製造到銷售，全部由自家一貫完成的半導體企業。
無晶圓廠設計公司(Fabless)
自己不擁有製造工廠，專注於半導體設計與銷售的企業型態。
晶圓代工廠
專門承接其他公司所設計半導體的製造的企業或事業型態。
OSAT(封裝測試代工廠)
承接半導體組裝與測試等後段製程的企業。
MPW(多專案晶圓)
讓多個客戶的設計共用一片晶圓(一組光罩)進行試作的機制。可分攤昂貴的光罩費用，因此用於大學與新創公司的試作。

相關的比較

  • 半導體前段製程與後段製程的差異：製程內容、設備、負責企業比較從主要製程、處理單位、尺寸、期間、設備、檢測與負責企業等面向，以表格比較半導體製造的前段製程（在晶圓上製作電路的製程）與後段製程（切割出晶片、組裝成封裝並進行測試的製程）。
  • ASIC、FPGA、SoC 的差異：靈活性、成本、用途比較說明 ASIC、FPGA、SoC 各是什麼，並從靈活性、效能、前期費用與單價、開發期間與用途等面向，以表格比較。
  • 2.5D與3D封裝的差異：晶片整合方式比較以結構、連接、頻寬、熱、複雜度、HBM與CoWoS等範例，以及使用時機等面向，用表格比較2.5D封裝與3D封裝。
  • 混合鍵合與微凸塊的差異：間距、連接密度、平坦度比較從有無焊料、連接間距、連接密度、表面平坦度、製程、電氣特性與用途等面向，以表格比較用於晶片堆疊的混合鍵合與微凸塊。
  • 扇入型與扇出型晶圓級封裝的差異：重佈線、面積、端子數、重構晶圓、用途比較從重佈線的範圍、封裝與晶片的面積、端子數、製造方法、翹曲等課題、成本與用途等面向，比較扇入型與扇出型晶圓級封裝。
  • 矽中介層、有機中介層、矽橋的差異：佈線密度、尺寸、成本比較從製作方式、放置矽的範圍、佈線細微度、尺寸限制、是否需要 TSV、成本、熱膨脹與翹曲、電氣特性與主要用途等面向，以表格比較 2.5D 封裝中連接晶片的矽中介層、有機（RDL）中介層與嵌入式矽橋。
