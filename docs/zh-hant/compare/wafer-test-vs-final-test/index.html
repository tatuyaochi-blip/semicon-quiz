晶圓測試與最終測試的差異：時機、接觸方式、溫度、項目、目的比較

晶圓測試是在前段製程結束、切割之前的晶圓上，將探針卡的探針接觸各晶片的電極墊，檢查良否的測試。在封裝之前剔除不良晶片，就不會浪費封裝與組裝的費用。最終測試是將組裝成封裝後的 IC 以分類機放入測試座進行量測的測試，連同組裝時產生的不良在內，確認其符合規格運作後再出貨。

項目晶圓測試（探針測試）最終測試
時機前段製程結束後、切割之前組裝（封入封裝）完成後、出貨之前
對象晶圓上的所有晶片封入封裝的 IC（將晶圓測試中為良品的晶片組裝而成）
接觸方式由針測機移動晶圓，讓探針卡的探針接觸晶片的電極墊由分類機將 IC 放入測試座，以彈簧針等接觸封裝的端子（引腳或錫球）
使用的設備測試機、針測機、探針卡測試機、分類機、裝有測試座的負載板
溫度改變承載晶圓的吸盤溫度進行量測。除了室溫之外，有時也在高溫或低溫下量測以分類機加熱或冷卻 IC，多在產品保證溫度範圍的高溫與低溫下量測
主要測試項目直流特性（漏電流等）、功能測試、掃描測試。記憶體還要進行將不良位元替換成備用的修復用量測功能、直流特性、時序等交流特性、實際速度下的運作。依速度等進行等級分類
高速訊號的量測受探針電氣特性的限制，高速訊號或大電流的量測有時較困難測試座在電氣上較有利，較容易量測高速訊號
找出不良品的目的在組裝前剔除不良晶片，節省封裝與組裝的費用。從晶圓圖及早發現製程問題連同組裝時產生的不良（連接不良等）一併剔除，保證品質後出貨
不良品的處理將不良晶片記錄在晶圓圖的電子資料中，組裝時不使用（過去以墨水做記號）剔除不良品，良品依性能等分類後出貨
與 KGD 的關係將多顆晶片裝在 1 個封裝中時，需要在這個階段確認為良品的晶片（KGD）組裝後才發現不良，也很難只替換不良的晶片

數值為具代表性的大致參考值，會因世代或產品而異。

適用於什麼情況

晶圓測試
想在組裝前剔除不良晶片，節省封裝與組裝的費用時。在 1 個封裝中裝載多顆晶片的產品，只想使用確認為良品的晶片（KGD）時。
最終測試
組裝後，保證其在封裝狀態下符合規格運作再出貨時。想確認在保證溫度範圍與實際速度下的運作時。
搭配使用
一般產品依晶圓測試 → 組裝 → 最終測試 → 出貨的順序進行兩種測試。由兩種測試分擔測試項目，減少重複以降低測試成本。

常見問題

既然有最終測試，為什麼還要做晶圓測試？

因為組裝不良的晶片，會浪費封裝材料與組裝費用。在晶圓階段剔除不良，就能只組裝良品。此外，觀察晶圓圖上不良的分布，就能及早找出造成問題的製程。

晶圓測試與 WAT（參數測試）有什麼不同？

WAT 是在晶圓上的 TEG（評估用圖案）量測臨界電壓與片電阻等，確認製程是否符合規格完成的檢查。晶圓測試則是檢查產品的各晶片是否正確運作，以判定良否的測試。

什麼是 KGD？

指在構裝之前已確認為良品的晶片（Known Good Die）。將多顆晶片裝在 1 個封裝中時，只要混入 1 顆不良晶片，整個封裝就會成為不良品，因此必須在晶圓測試階段充分確認。

預燒在哪個階段進行？

預燒是施加高溫與高電壓，以剔除容易發生早期故障之晶片的試驗，多在組裝成封裝後進行。在需要 KGD 等情況下，也有在晶圓狀態下進行的晶圓級預燒。

理解度檢測

關於晶圓測試（探針測試）的說明，下列何者正確？

  1. A在切割前，將探針接觸晶圓上的各個晶片，檢測其電氣特性
  2. B在封裝密封後，僅檢查外觀
  3. C長期使用產品以調查其故障率
查看答案與解析

正確答案：A. 在切割前，將探針接觸晶圓上的各個晶片，檢測其電氣特性

在晶圓測試中，探針台（prober）會移動晶圓，使探針卡的探針接觸晶片的電極焊墊，並以測試機檢測電氣特性與功能。若能在此階段找出不良晶片，就不會浪費封裝的材料費與組裝的工夫。這是因為不良越晚在後段製程被發現，損失越大。封裝密封後的檢測是最終測試，長期使用以調查故障率的則是可靠度試驗。

下列何者是一般半導體產品測試流程的正確順序？

  1. A最終測試 → 晶圓測試 → 組裝 → 出貨
  2. B組裝 → 晶圓測試 → 出貨 → 最終測試
  3. C晶圓測試 → 組裝 → 最終測試 → 出貨
查看答案與解析

正確答案：C. 晶圓測試 → 組裝 → 最終測試 → 出貨

首先在完成前段製程的晶圓狀態下進行晶圓測試，判別不良晶片。只有良品晶片會在組裝製程中放入封裝，並在最終測試確認特性後出貨。依產品不同，也會在最終測試的前後進行burn-in或系統級測試。最終測試在組裝之後，且沒有在出貨之後才進行的測試，因此其他順序都不成立。

關於探針卡的說明，下列何者正確？

  1. A用來封裝晶片的模具
  2. B用來搬運晶圓的容器
  3. C使針接觸晶圓上晶片的電極，與測試機形成電氣連接的治具
查看答案與解析

正確答案：C. 使針接觸晶圓上晶片的電極，與測試機形成電氣連接的治具

探針卡是配合晶片電極焊墊的配置排列許多探針、依產品而定的專用治具。探針台以相機對準晶圓的位置，抬高載台（chuck）使探針與焊墊接觸，將測試機與晶片電氣連接。探針的方式有斜針的懸臂式、垂直式，以及以MEMS技術製作的類型。這與封裝用的模具或搬運容器是不同的東西。

前往測試與檢查的練習題

相關名詞的解說

晶圓測試(探針測試)
在切割之前，將探針接觸晶圓上各晶片的電極，檢查電氣特性的步驟。可在組裝前找出不良晶片，避免無謂的組裝。
探針卡
在晶圓狀態下，將多根探針接觸晶片電極，使其與測試機電性連接的治具。
KGD(已知良品晶粒)
在構裝之前已確認為良品的晶片。將多顆晶片疊入同一封裝時，只要混入一顆不良品整體就會成為不良，因此相當重要。
預燒測試(Burn-in)
在高溫、高電壓等應力條件下使產品運作，於出貨前剔除容易發生早期失效之產品的測試。
晶圓切割
將晶圓切成一個個晶片（晶粒）的步驟。除了以旋轉刀片切割的方法外，還有以雷射在內部形成改質層的隱形切割等。

  • 扇入型與扇出型晶圓級封裝的差異：重佈線、面積、端子數、重構晶圓、用途比較從重佈線的範圍、封裝與晶片的面積、端子數、製造方法、翹曲等課題、成本與用途等面向，比較扇入型與扇出型晶圓級封裝。
  • 打線接合與覆晶的差異：晶片連接方式比較以連接方式、輸入輸出數量、電氣性能、成本、尺寸、製程與用途等面向，用表格比較打線接合與覆晶。
