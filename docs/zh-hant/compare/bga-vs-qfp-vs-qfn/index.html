BGA、QFP、QFN 的差異：比較 IC 封裝的種類

這三種都是常見的表面黏著 IC 封裝，差別在於連接的位置。QFP 的四邊伸出鷗翼形的引腳。QFN 沒有引腳，在底面邊緣有平坦的焊墊。BGA 則在整個底面以格狀排列焊球。BGA 能以最小的面積得到最多的連接，QFN 小巧且散熱優異，QFP 則最容易檢查，也最容易手焊。

項目BGAQFPQFN
端子底面以格狀排列的焊球四邊的鷗翼形引腳底面邊緣的平坦焊墊，與中央外露的散熱焊墊
一般的腳位數數百〜數千約 32〜300約 8〜100
一般的間距約 0.4〜1.27 mm約 0.4〜0.8 mm約 0.4〜0.65 mm
大小相對於腳位數而言小最大。引腳會伸出本體之外小而薄
電氣性能路徑短，電感小引腳長，電感大路徑短，電感小
散熱良好。經由焊球與散熱用的導通孔中等優異。經由外露的焊墊
檢查與重工接點被隱藏，需要 X 光檢查，重工也困難容易。引腳看得見，也能手焊略為困難。部分接點隱藏在封裝底下
窄間距的問題需要細小的導通孔與許多基板層數間距非常窄時，引腳會彎曲或產生橋接中等
主要用途CPU、GPU、FPGA、SoC、記憶體微控制器、較舊的 ASIC微控制器、RF、電源管理、感測器

數值為具代表性的大致參考值，會因世代或產品而異。

適用於什麼情況

BGA
需要以小面積得到許多腳位與良好的電氣性能時。處理器或記憶體等。
QFP
比起大小，更重視安裝、檢查與試作的容易程度時。
QFN
需要小而薄的封裝、散熱也佳，且腳位數為中等時。

常見問題

為什麼 CPU 使用 BGA？

因為 BGA 在整個底面以格狀排列焊球，能以小面積得到數百〜數千個連接，路徑短，電感也小。

QFN 比 BGA 容易焊接嗎？

一般來說是的，但 QFN 的部分接點隱藏在封裝底下，所以比 QFP 困難。BGA 的接點則完全隱藏，需要 X 光檢查。

QFN 的外露焊墊是什麼？

位於底面中央的金屬焊墊，焊接到基板上以導出熱量。也常兼作接地連接。

最適合手焊的封裝是哪一種？

QFP。因為引腳看得見，手也伸得進去。

理解度檢測

下列關於BGA（球柵陣列）封裝的特徵，何者正確？

  1. A從封裝的兩側引出引腳
  2. B從封裝的四邊引出鷗翼狀引腳
  3. C在封裝背面以格子狀配置焊球
查看答案與解析

正確答案：C. 在封裝背面以格子狀配置焊球

BGA是將焊球以格子狀排列在整個封裝背面，作為外部端子。由於可用面積取得端子，相較於只能在周邊引出引腳的QFP，在相同大小下可配置更多端子，配線也更短。另一方面，接合處隱藏在背面無法目視，因此以X光檢查。從兩側引出引腳的是SOP，從四邊引出鷗翼狀引腳的是QFP。

下列關於QFN（Quad Flat No-lead）封裝的特徵，何者正確？

  1. A從封裝四邊向外引出長引腳
  2. B不向外引出引腳，在封裝底面四邊配置電極的小型封裝
  3. C在整個底面以格子狀排列焊球
查看答案與解析

正確答案：B. 不向外引出引腳，在封裝底面四邊配置電極的小型封裝

QFN是側面不突出引腳、而在底面周邊露出電極的封裝。由於引腳短，電感較小，可做到小型、薄型。底面中央有大面積的散熱墊，焊接到基板後可透過基板的導通孔散熱，因此散熱性也很優異。另一方面，接合處隱藏在底面，目視檢查較為困難。四邊引出長引腳的是QFP，排列焊球的是BGA。

從封裝兩側引出鷗翼狀引腳的表面黏著封裝為何？

  1. ASOP
  2. BQFP
  3. CBGA
查看答案與解析

正確答案：A. SOP

SOP（Small Outline Package）是從封裝長邊的兩側，引出如海鷗翅膀般向外彎曲的引腳（鷗翼）的表面黏著封裝。由於引腳前端可見，容易以目視確認焊接狀態，廣泛用於低腳數的IC。薄型化的TSOP則長期用於記憶體等。從四邊引出引腳的是QFP，在底面排列球的是BGA。

相關名詞的解說

BGA(球柵陣列)
球柵陣列。在封裝背面以格狀排列焊球、適用於多接腳的封裝。
CSP(晶片尺寸封裝)
縮小到與晶片幾乎相同大小之封裝的統稱。廣泛用於智慧型手機等小型設備。
