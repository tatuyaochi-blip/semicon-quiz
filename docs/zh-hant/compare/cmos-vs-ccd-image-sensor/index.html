CMOS 影像感測器與 CCD 的差異：讀出、速度、用途比較

兩種感測器都在各個像素中將光轉換為電荷，但讀出電荷的方式不同。CCD 將電荷由像素依序傳送到下一個像素，一路運送到單一的輸出放大器。CMOS 感測器則在各個像素內將電荷轉換為電壓，並平行讀出許多像素。CMOS 感測器便宜、快速、耗電小，還能將 ADC 與影像處理放在同一顆晶片上，因此在大部分消費性產品中已取代 CCD。

適用於什麼情況

CMOS
現在幾乎所有用途都適用。例如智慧型手機、相機、汽車、保全與工業用相機等。便宜、快速又靈活，背照式與堆疊式更提升了感光度與速度。
CCD
重視低雜訊且均勻這項長久實績的特殊場合。例如部分科學、天文、太空用的設備等。

常見問題

為什麼 CMOS 感測器取代了 CCD？

CMOS 感測器便宜、快速、耗電小，還能將 ADC 與影像處理放在同一顆晶片上。隨著雜訊與感光度的改善，CCD 最大的優勢也消失了。

什麼是捲簾快門？

捲簾快門是依序讀出 CMOS 感測器的各列，因此快速移動的被攝體會看起來扭曲。全域快門則同時曝光所有像素，但每個像素都需要增加電路。

CCD 現在還在使用嗎？

是的。部分重視低雜訊且均勻這項長久實績的科學、天文、工業與太空攝影仍在使用。

什麼是光暈（blooming）？

是明亮像素的電荷溢出，流入相鄰像素的現象。CCD 比 CMOS 感測器更容易發生。

理解度檢測

與CCD影像感測器相比，CMOS影像感測器的一般特長，下列何者正確？

  1. A依序傳輸像素的電荷，並由1處輸出部讀出
  2. B容易將周邊電路整合在同一晶片上，且耗電量小
  3. C無法使用CMOS製程進行製造
查看答案與解析

正確答案：B. 容易將周邊電路整合在同一晶片上，且耗電量小

CMOS影像感測器每個像素都有放大用電晶體，可用一般的CMOS製程製造，因此容易將類比數位轉換器與影像處理電路整合於同一晶片或堆疊的晶片上，具有低電壓、低耗電的特點，讀出速度也快。CCD是依序傳輸電荷並由1處輸出部讀出的方式，雖然雜訊少，但需要高驅動電壓與專用製程，目前以CMOS為主流。

關於CCD影像感測器的訊號讀出方式，下列何者正確？

  1. A像接力傳水桶般依序傳輸像素的電荷，並在輸出部轉換為電壓
  2. B以各像素的放大器轉換為電壓，並逐列讀出
  3. C將光直接轉換為數位訊號
查看答案與解析

正確答案：A. 像接力傳水桶般依序傳輸像素的電荷，並在輸出部轉換為電壓

CCD藉由依序切換電極的電壓，像接力傳水桶般傳輸像素所儲存的電荷，再由輸出部的1個放大器轉換為電壓。傳輸效率高達99.999%以上，且輸出放大器只有1個，因此像素間的差異少、雜訊低。然而它需要10 V以上的驅動電壓與專用製程，耗電量大，讀出也慢，因此除了天文觀測等部分用途外，已被CMOS取代。

在CMOS影像感測器的滾動快門方式中，快速移動的被攝體會變形成像，其原因為下列何者？

  1. A因為各列的曝光與讀出時序有所錯開
  2. B因為所有像素同時曝光
  3. C因為彩色濾光片的排列
查看答案與解析

正確答案：A. 因為各列的曝光與讀出時序有所錯開

滾動快門方式是逐列依序對像素進行曝光與讀出，因此上方的列與下方的列在拍攝時間上會相差數ms～數十ms。因此快速移動的被攝體會被拍成斜向變形，日光燈的閃爍也會變成條紋。讓所有像素同時曝光的全域快門方式不會產生變形，用於工業檢查相機與車載應用，但像素內需要暫時保存電荷的電路，因此像素會變大。

前往影像感測器與光電元件的練習題

相關名詞的解說

CMOS 影像感測器
每個像素都有放大電路，以 CMOS 製程製造的影像感測器。低功耗且可整合周邊電路，是智慧型手機相機等的主流。
CCD 影像感測器
像接力傳水桶般依序傳輸像素的電荷，並在輸出部轉換為電壓的影像感測器。雜訊低、畫質高，但消耗功率大，現在在許多用途中已被 CMOS 取代。
堆疊式 CMOS 影像感測器
將像素部與訊號處理電路分別在不同晶片上製作，再疊合接合的影像感測器。可各自使用適合的製程，使晶片更小、處理更快。
