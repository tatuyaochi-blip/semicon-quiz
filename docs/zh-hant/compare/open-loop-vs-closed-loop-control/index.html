開迴路控制與閉迴路控制的差異：運作方式、抗干擾能力、穩定性、感測器、用途比較

開迴路控制只是由目標值決定操作量並施加於受控體，不會量測結果的控制量來確認。閉迴路控制以感測器量測控制量並與目標值比較，持續修正操作量，使兩者的差（誤差）變小。由於訊號從輸出回到輸入側、繞迴路一圈，也稱為回授控制。開迴路控制簡單又便宜，受控體穩定時也不會因控制而振盪，但無法修正干擾或受控體變化造成的偏差。閉迴路控制能自動修正偏差，但需要感測器，增益調得太高時會振盪或變得不穩定。

項目開迴路控制閉迴路控制（回授控制）
訊號的流向目標值 → 控制器 → 受控體 → 控制量。輸出不會回到輸入側以感測器量測控制量，將與目標值的差（誤差）送回控制器。訊號繞迴路一圈
感測器（量測控制量）不需要需要。感測器的精度與雜訊左右控制的精度
對干擾的處理無法修正。負載或周圍溫度改變時，就一直維持偏差不論原因為何，都會修正以誤差形式出現的偏差
受控體特性的變化變化直接反映在結果上。受控體的增益下降50%，輸出也下降50%影響會變小。G = 100、H = 0.1的負回授中，即使G減半，閉迴路增益也只下降約8.3%
響應速度只有受控體本身的延遲。不必等誤差出現就能操作誤差出現後才修正，因此有延遲。不過提高增益後，也能比只有受控體時響應得更快
穩定性受控體穩定時，不會因控制而振盪或發散增益太高或時間延遲等延遲太大時會振盪、發散。以增益邊限與相位邊限確認
穩態誤差模型準確時可為0，但模型誤差與干擾的部分會原樣殘留只有比例動作時會殘留誤差（0型系統對步階為1/(1 + G(0))）。加入積分動作即可為0
構成與成本簡單、便宜。精度取決於模型與零件的準確度需要感測器，以及比較並修正的電路或軟體。必須考量迴路穩定性來設計與調整
實例只靠時間決定烘烤程度的烤麵包機、以脈波數決定角度的步進馬達定位、按固定時間切換的紅綠燈冷氣的室溫、汽車的定速巡航、DC-DC轉換器的輸出電壓、馬達的速度與位置

數值為具代表性的大致參考值，會因世代或產品而異。

適用於什麼情況

開迴路控制
干擾小、受控體的特性清楚且不易改變時。無法安裝感測器，或安裝成本太高時也會使用。受控體穩定時不必擔心振盪，調整也簡單。
閉迴路控制（回授控制）
即使有干擾、負載變化、零件的差異或劣化，也想讓結果準確對齊目標值時。溫度、速度、位置、電壓等多數控制屬於此類，PID控制是代表。

常見問題

前饋控制是開迴路控制嗎？

只看前饋的路徑，它不量測控制量，而是由模型決定操作量，因此是開迴路的結構。它量測干擾或目標值的變化，在誤差出現前加入抵消的操作量，所以反應快，但無法修正未量測的干擾或模型誤差。因此一般會與回授控制搭配，由回授修正剩下的偏差。前饋路徑位於迴路之外，不會改變迴路的穩定性。

為什麼閉迴路控制不怕受控體特性的變化？

在前向增益G、回授增益H的負回授中，閉迴路增益為G/(1 + GH)，當GH遠大於1時約為1/H，幾乎與G無關。G = 100、H = 0.1時閉迴路增益約為9.09，即使G減半為50也約為8.33，只下降約8.3%。開迴路時，G減半結果也減半。

為什麼閉迴路控制會變得不穩定？

因為受控體與感測器的延遲，使修正的操作晚一步才生效。增益高時，為了強力修正偏差而往反方向衝過頭，反覆下去就會振盪。若在迴路轉移函數相位達到−180°的頻率下，增益為1（0 dB）以上，振盪會持續變大而發散。設計時以增益邊限與相位邊限確認距離不穩定還有多少餘裕。

理解度檢測

關於回授控制（閉迴路控制）的說明，正確的是下列何者？

  1. A不量測受控量，只依預先決定的操作量或程序運作，因此即使受控量因擾動而偏離，也不會自動修正
  2. B量測受控量並與目標值比較，改變操作量使兩者的差（誤差）變小，因此能減少擾動與受控體特性變化的影響
  3. C量測擾動，在它出現在受控量之前加上抵銷它的操作量，因此連未量測的擾動與模型誤差在內，都一定能使誤差為0

正確答案：B. 量測受控量並與目標值比較，改變操作量使兩者的差（誤差）變小，因此能減少擾動與受控體特性變化的影響

回授控制是將感測器量測到的受控量與目標值比較，依誤差決定操作量的控制。訊號由輸出回到輸入側，沿迴路繞行一圈，因此也稱為閉迴路控制。無論原因為何，都看著結果的偏差加以修正，因此對擾動與受控體特性的變化很強，這是它的優點。另一方面，它在誤差出現後才修正，因此有延遲，增益調得太高則會振盪或變得不穩定。

將前饋控制與回授控制組合使用的理由，正確的是下列何者？

  1. A前饋能在誤差出現之前，對可量測的擾動與目標值的變化作出反應，但無法修正未量測的擾動與模型誤差，因此剩下的部分由回授補足
  2. B加上前饋後，迴路轉移函數的增益與相位會改變，使相位邊限增加，因此即使加大回授的增益也能保持穩定
  3. C只用回授時，即使使用積分動作也一定會殘留穩態誤差，因此要使對固定目標值或擾動的穩態誤差為0，前饋是不可或缺的

正確答案：A. 前饋能在誤差出現之前，對可量測的擾動與目標值的變化作出反應，但無法修正未量測的擾動與模型誤差，因此剩下的部分由回授補足

前饋控制是量測擾動或目標值的變化，在它們影響受控量之前，加上依模型計算出的操作量的控制。它不等待誤差出現，因此反應快，但前提是模型準確且擾動可以量測。因此常見的組合是由前饋負責主要的擾動與目標值的追隨，再由回授修正剩下的偏差。前饋的路徑位於迴路之外，因此不會改變迴路的穩定性（相位邊限等）。

在前向路徑的轉移函數為 G(s)、回授路徑的轉移函數為 H(s) 的負回授方塊圖中，由目標值 R(s) 到輸出 Y(s) 的閉迴路轉移函數 Y(s)/R(s) 為下列何者？

  1. AG(s)/(1 − G(s)H(s))
  2. BG(s)H(s)/(1 + G(s)H(s))
  3. CG(s)/(1 + G(s)H(s))
查看答案與解析

正確答案：C. G(s)/(1 + G(s)H(s))

誤差為 E(s) = R(s) − H(s)Y(s)，輸出為 Y(s) = G(s)E(s)。由這兩式消去 E(s)，得到 Y(s) = G(s)R(s) − G(s)H(s)Y(s)，因此 Y(s)/R(s) = G(s)/(1 + G(s)H(s))。分母中的 G(s)H(s) 是訊號沿迴路繞行一圈時的轉移函數，稱為迴路轉移函數（開迴路轉移函數）。在 H(s) = 1 的單位回授中，成為 G(s)/(1 + G(s))。

相關名詞的解說

回授控制
以感測器量測受控量並與目標值比較，改變操作量使兩者之差（誤差）變小的控制。訊號沿迴路繞行一圈，因此也稱為閉迴路控制。無論原因為何都修正結果的偏差，因此對擾動與受控體的變化很強，但在誤差出現後才修正，因此有延遲，增益太高則會造成振盪或不穩定。PID控制是代表，廣泛用於溫度、速度、電壓、位置等的控制。
前饋控制
量測擾動或目標值的變化，在它們影響受控量之前，加上依受控體模型求出的操作量的控制。它不等待誤差出現，因此反應快，但無法修正模型誤差與未量測的擾動，因此多半與回授控制組合使用。它的路徑位於迴路之外，因此不會改變回授迴路的穩定性。在半導體工廠中，依前一製程步驟的量測結果修正下一步驟條件的控制，也稱為前饋控制。
方塊圖
把控制系統的元件以寫有轉移函數的方框（方塊）表示，並以箭頭表示訊號的流向、以加總點表示訊號的加減、以分歧點表示訊號分支的圖。串聯的方塊可合併為轉移函數的乘積，並聯的方塊可合併為和，負回授迴路可替換為 G/(1 + GH) 這1個方塊。反覆進行這種等效轉換，就能求出由目標值或擾動到輸出的轉移函數。
轉移函數
以初始值全為0時輸出與輸入的拉普拉斯轉換之比 G(s) = Y(s)/X(s)，表示線性非時變系統輸入與輸出關係的函數。等於系統脈衝響應的拉普拉斯轉換。使分母為0的 s 稱為極點，使分子為0的 s 稱為零點，由極點的位置可知穩定性與響應的快慢。令 s = jω 即得頻率響應。離散時間系統則使用z轉換，以 H(z) 表示。
穩態誤差
控制系統的響應穩定下來之後，仍殘留的目標值與受控量之差，也稱為偏移。在單位回授系統中，對步階目標值為 1/(1 + Kp)（Kp = G(0) 為位置誤差常數），在前向路徑不含積分的（0型）系統中不會變成0。在含有1個積分的1型系統中，對步階的穩態誤差為0，對斜坡目標值則殘留 1/Kv（Kv 為速度誤差常數）的誤差。PI控制的積分動作就是用來消除這個誤差的。
增益邊限
在迴路轉移函數的相位達到 −180° 的頻率（相位交越頻率），增益比0 dB低多少dB的量。它表示迴路增益再提高幾倍就會不穩定，例如增益邊限約9.5 dB時，把增益提高為3倍就會到達穩定極限。與相位邊限組合起來表示穩定的餘裕，伺服系統常以約10～20 dB作為參考。
PID控制
把與誤差 e 成正比的項（P）、與誤差的積分成正比的項（I）、與誤差的微分成正比的項（D）相加，以決定操作量的回授控制。寫成 u = Kp(e + (1/Ti)∫e dt + Td·de/dt)，Kp 稱為比例增益，Ti 稱為積分時間，Td 稱為微分時間。比例負責速度，積分負責消除穩態誤差，微分負責抑制振盪。結構簡單，用於溫度、馬達、電源、化學製程等大部分的工業控制迴路。
