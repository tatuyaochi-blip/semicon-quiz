MRAM、ReRAM、PCM、FeRAM 的差異：新型記憶體比較

這四種新型非揮發性記憶體，都以同時實現如同 RAM 的速度與斷電後資料仍保留為目標。差異在於以什麼來記憶位元。分別是薄膜的磁化（MRAM）、氧化物中燈絲的電阻（ReRAM）、材料的結晶態與非晶態（PCM）、鐵電體的極化（FeRAM）。它們都還沒有廣泛取代 DRAM 或快閃記憶體，但各自找到了擅長的領域。

適用於什麼情況

MRAM
想要像快閃記憶體一樣保存資料、像 DRAM 一樣快速，且抹寫次數幾乎無限的非揮發性記憶體時。例如嵌入式記憶體與頻繁的資料記錄等。
ReRAM
想要簡單、高密度、低電壓的單元時。也適合在記憶體陣列中進行積和運算的記憶體內運算。
PCM
想要介於 DRAM 與快閃記憶體之間、密度更高的記憶體，且能接受寫入能量較多時。
FeRAM
只需要少量耗電非常小、速度快、抹寫壽命長的記憶體時。例如智慧卡與感測器等。

常見問題

最接近取代 DRAM 或 SRAM 的新型記憶體是哪一種？

MRAM 在速度與抹寫壽命上最接近，寫入為數～數十 ns，抹寫超過 10¹⁰ 次。不過單元較大，在容量與每位元的成本上遠不及 DRAM 或快閃記憶體，因此作為嵌入式記憶體使用。

相變化記憶體如何記憶資料？

藉由加熱材料，在結晶態（低電阻）與非晶態（高電阻）之間切換。再將其電阻讀取為 0 或 1。

為什麼電容型 FeRAM 的讀取是破壞性讀取？

讀取時是藉由使極化反轉來偵測，因此原本記憶的值會消失，每次讀取後都必須將資料寫回。

什麼是 ReRAM 的記憶體內運算？

ReRAM 陣列將各單元的電阻作為權重使用，可直接在記憶體中進行積和運算。適合 AI 處理，不需要在記憶體與處理器之間搬移資料。

理解度檢測

關於 MRAM 的記憶原理，下列何者正確？

  1. A磁性穿隧接面（MTJ）因磁化方向不同而造成的電阻差異
  2. B硫族化物材料的結晶狀態與非晶態之間的電阻差異
  3. C電容中有無儲存電荷
查看答案與解析

正確答案：A. 磁性穿隧接面（MTJ）因磁化方向不同而造成的電阻差異

MRAM 使用磁性穿隧接面（MTJ），即以兩個磁性層夾住厚約 1 nm 的絕緣層。磁化方向平行時電阻低，反平行時電阻高，利用這種穿隧磁電阻效應區分 0 與 1，且磁化不需電源即可保持，因此是非揮發性。其優勢在於改寫次數幾乎無限且速度快。利用結晶與非晶之間電阻差異的是相變記憶體，利用電荷的是 DRAM。

關於相變記憶體（PCM）的記憶原理，下列何者正確？

  1. A磁性層磁化方向的差異
  2. B硫族化物材料的結晶狀態與非晶態之間的電阻差異
  3. C鐵電體極化的方向
查看答案與解析

正確答案：B. 硫族化物材料的結晶狀態與非晶態之間的電阻差異

PCM 以電流的焦耳熱對 GeSbTe 等硫族化物材料加熱、急速冷卻，在低電阻的結晶狀態與高電阻的非晶態之間切換。電阻差異高達 2～3 個數量級，也可以做出中間值來達成多值化。同樣的材料也利用結晶與非晶之間光反射率不同的性質，用於可重複寫入的 DVD 與藍光光碟。需要大電流才能寫入是其課題。

FeRAM（鐵電記憶體）利用何種性質來記憶資訊？

  1. A氧化物中導電細絲的形成與消失
  2. B磁電阻效應
  3. C鐵電體自發極化（殘留極化）的方向
查看答案與解析

正確答案：C. 鐵電體自發極化（殘留極化）的方向

FeRAM 利用即使移除電壓極化仍然留存的鐵電體性質（殘留極化），以極化的方向記憶 0 與 1。寫入只是使極化反轉，因此不需要像快閃記憶體那樣的高電壓，速度快（數十 ns）、功耗小，改寫次數也多達 10¹² 次以上。過去使用的是 PZT（鋯鈦酸鉛）。使用細絲的是 ReRAM，利用磁電阻的是 MRAM。

前往新世代記憶體的練習題

相關名詞的解說

MRAM
利用磁性穿隧接面(MTJ)磁化方向所造成的電阻差異來儲存資訊的非揮發性記憶體。
PCM(相變記憶體)
利用硫族化合物材料的結晶狀態(低電阻)與非晶狀態(高電阻)之差異來儲存資訊的非揮發性記憶體。
ReRAM(電阻式記憶體)
施加電壓在氧化物等之中形成或切斷導電路徑，利用電阻差異來儲存資訊的非揮發性記憶體。
FeRAM(鐵電記憶體)
利用鐵電體的極化方向來儲存資訊的非揮發性記憶體。寫入快速且低功耗，用於 IC 卡等。
磁性穿隧接面(MTJ)
以兩層磁性層夾住薄絕緣膜的結構。兩層磁化方向一致時電阻低，方向相反時電阻高。是 MRAM 的記憶元件。
