PLL 與 DLL 的差異：控制對象、倍頻、抖動、穩定性、用途比較

兩者都會偵測與參考時脈之間的相位差，並以回授控制使其歸零，但調整的對象不同。PLL 調整壓控振盪器（VCO）的頻率，讓自己振盪產生的時脈對齊參考時脈，因此與除頻器搭配，就能產生參考頻率數倍的頻率。DLL 則讓輸入時脈本身通過延遲線，只調整其延遲來對齊相位，因此無法改變頻率，但具有抖動不會累積、迴路穩定且容易設計的特點。

適用於什麼情況

PLL
需要與參考時脈頻率不同（多半高出數倍）的時脈時。由石英振盪器的參考產生 CPU 或 SerDes 的時脈，或產生無線通訊的頻率時。
DLL
頻率相同即可，想抵消晶片內部的延遲以對齊時脈相位時。DDR DRAM 資料輸出的時序對齊，以及時脈去偏斜。
搭配使用
常見的組合是以 PLL 產生所需頻率的時脈，再在記憶體介面等處以該時脈為參考，用 DLL 進行細微的相位調整（例如將選通訊號錯開 1/4 週期）。

常見問題

為什麼 DLL 無法改變頻率？

因為 DLL 的輸出是將輸入時脈以延遲線延遲後的時脈。無論如何改變延遲，邊緣的間隔都與輸入相同，頻率不會改變。PLL 具有自行振盪的 VCO，並讓除頻後的時脈對齊參考，因此能產生參考 N 倍的頻率。

為什麼 DLL 的抖動不會累積？

因為 DLL 輸出的每個邊緣，都是將輸入的每個邊緣延遲而得，不會承接前一個週期的誤差。PLL 的 VCO 從前一個週期的結束處開始下一個週期，因此擾動會累積，直到迴路修正為止都會殘留。相對地，DLL 會讓輸入的抖動直接通過。

PLL 的迴路頻寬如何決定？

頻寬越寬，越能快速修正 VCO 的擾動，但參考時脈的抖動也越容易通過。頻寬越窄，越能濾除參考的抖動，但 VCO 的擾動會殘留，鎖定也會變慢。需視參考與 VCO 何者的雜訊較小，以及迴路的穩定性（相位裕度）來決定。

為什麼 DDR DRAM 使用 DLL？

晶片內部的時脈路徑與輸出電路有延遲，且會隨電壓與溫度變化。以 DLL 抵消這個延遲，就能對齊外部時脈的邊緣輸出資料。由於不需要改變頻率，不易增加抖動的 DLL 很適合。

理解度檢測

在與參考時脈同步相位的同時，產生其整數倍等頻率之時脈的電路是哪一個？

  1. APLL（鎖相迴路）
  2. B整流電路
  3. C取樣保持電路
查看答案與解析

正確答案：A. PLL（鎖相迴路）

PLL由相位比較器、迴路濾波器、壓控振盪器（VCO）與除頻器構成，控制使VCO輸出經除頻後的訊號與參考時脈的相位一致。將除頻比設為N，可得到參考頻率的N倍，例如可由25 MHz的石英產生數GHz的CPU時脈。以小數除頻（Fractional-N）也能合成精細的頻率，並用於無線的本地振盪器，以及高速序列通訊的時脈回復。

下列哪一項是對同步式電路「時脈偏斜」的正確說明？

  1. A時脈的頻率隨時間變動
  2. B時脈訊號到達各正反器的時間差
  3. C時脈訊號的電壓高於電源電壓
查看答案與解析

正確答案：B. 時脈訊號到達各正反器的時間差

時脈偏斜是同一個時脈因佈線長度或負載的差異，到達各正反器的時間不同所產生的差距。接收端的時脈延遲時，對設置有利但對保持不利，反之亦然。以CTS（時脈樹合成）設計涵蓋整個晶片的時脈樹，並統一緩衝器的配置與佈線長度，將偏斜抑制在數十ps以下。週期在時間上的抖動則是時脈抖動（jitter）。

佈局繞線階段中，時脈樹合成（CTS）的主要目的為下列何者？

  1. A縮小時脈訊號抵達各正反器的時間差異（偏斜，skew）
  2. B提高電源電壓
  3. C修正佈局的設計規則違反
查看答案與解析

正確答案：A. 縮小時脈訊號抵達各正反器的時間差異（偏斜，skew）

晶片內數百萬個正反器收到時脈的時刻若參差不齊，就會造成時序違反。CTS將緩衝器如樹狀配置來分配時脈，縮小各正反器抵達時刻的差異（偏斜）。由於時脈持續切換，時脈樹有時會占晶片耗電量的很大一部分。這與電源電壓或修正DRC違反是不同的目的。

前往類比與電子電路的練習題

相關名詞的解說

PLL(鎖相迴路)
偵測與參考時脈的相位差並控制振盪器，產生與參考同步、頻率為整數倍等的時脈的電路。用於 CPU 的時脈產生與無線的頻率合成。
抖動(Jitter)
時脈或訊號邊緣的時序相對於理想值的細微時間性波動。取樣高頻訊號時，即使微小的抖動也會造成很大的電壓誤差。
時脈偏斜
同一個時脈訊號到達各個正反器的時間差異。由於會改變設定與保持的餘裕，因此在時脈樹合成時將其壓低。
相位邊限
在負回授迴路的增益為 1(0 dB)的頻率上，相位延遲到達 180° 之前的餘裕。太小則響應容易振盪，在 0 以下則會振盪。一般以 45〜60° 以上為目標。
