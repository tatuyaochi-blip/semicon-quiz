前照式、背照式與堆疊式影像感測器的差異：結構、感度、速度比較

CMOS 影像感測器依光從哪一面入射、電路放在哪裡，可分為 3 種結構。前照式（FSI）從有導線層的正面讓光入射，因此部分光線會被導線遮擋。背照式（BSI）將晶圓翻面並薄化至數 µm，從沒有導線的背面讓光入射，因此即使畫素很小也能確保感度。堆疊式是將 BSI 的畫素晶片，與具有讀出及影像處理電路的邏輯晶片貼合而成的結構，可以縮小晶片並加快讀出。

項目前照式（FSI）背照式（BSI）堆疊式
光的入射面有導線層的正面。光線穿過微透鏡、彩色濾光片及多層導線之間，到達光二極體導線層的另一側（背面）。不經過導線即到達光二極體背面。畫素晶片為 BSI 結構

適用於什麼情況

前照式（FSI）
畫素大、導線造成的光損失小時，或想將成本壓到最低時。
背照式（BSI）
畫素即使小到約 1 µm 前後，仍想確保感度時。這是智慧型手機相機的標準結構。
堆疊式
想縮小晶片時，或想在感測器上搭載高速讀出與影像處理功能時。
三者的關係
三者是依序發展而來的結構。BSI 為了貼合需要支撐晶圓，將該支撐晶圓換成內含電路的邏輯晶片，就是堆疊式。

常見問題

為什麼背照式的感度較高？

在前照式中，光到達光二極體之前要穿過多層導線之間，因此部分光線會被遮擋或反射。背照式從沒有導線的背面讓光入射，因此幾乎整個畫素面積都能受光，斜向的光也不易損失。

堆疊式也是背照式嗎？

是的。堆疊式的畫素晶片為背照式結構，其下方貼合了具有讀出及影像處理電路的邏輯晶片。「背照式」指的是光的入射方式，「堆疊式」指的是電路的配置方式。

前照式已經不再使用了嗎？

仍在使用。只要畫素夠大，導線造成的光損失就小，製程也簡單便宜，因此在畫素較大的感測器或低成本感測器中，至今仍有選用前照式的情況。

理解度檢測

關於背照式（BSI）CMOS影像感測器的主要優點，下列何者正確？

  1. A可以減少像素數
  2. B光不須穿過配線層即可到達光電二極體，因此容易提高感光度
  3. C不再需要彩色濾光片
查看答案與解析

正確答案：B. 光不須穿過配線層即可到達光電二極體，因此容易提高感光度

在前照式中，光必須穿過光電二極體上方多層配線的縫隙，因此會被配線遮擋或反射。背照式將晶圓研磨薄至數µm，從配線層的相反側入射光線，因此能有效率地吸收光，對斜向入射的光也更具優勢。2009年由Sony量產上市，由於即使在1 µm左右的微細像素中也能確保感光度，已成為智慧型手機相機的標準規格。

關於堆疊式CMOS影像感測器，下列說明何者正確？

  1. A將多片透鏡疊在一起的結構
  2. B不使用光電二極體的結構
  3. C將像素部與訊號處理電路分別製作成不同晶片，再疊合接合的結構
查看答案與解析

正確答案：C. 將像素部與訊號處理電路分別製作成不同晶片，再疊合接合的結構

堆疊式是將像素部晶片，以及進行類比數位轉換與影像處理的邏輯電路晶片，分別以最適合的製程製作，再以銅對銅直接接合（Cu-Cu接合）等方式疊合接合。2012年由Sony量產上市，可在縮小晶片面積的同時，實現高速讀出、HDR、動態影像的高畫面更新率等。也有夾入記憶體的3層結構產品。

關於影像感測器像素的「開口率（填充因子）」之意義，下列何者正確？

  1. A鏡頭光圈的大小
  2. B有效畫素數相對於畫素數的比例
  3. C像素面積中，接收光並轉換為電荷的部分所占的比例
查看答案與解析

正確答案：C. 像素面積中，接收光並轉換為電荷的部分所占的比例

開口率是1個像素的面積中，能作為光電二極體接收光的部分所占的比例。若電晶體或配線多，開口率就會下降，感光度也隨之降低。早期的CMOS感測器開口率僅有30%左右，相較於CCD較為不利。藉由微透鏡聚光來提高有效開口率，再加上背照式使配線離開光路，實質上已能達到接近100%的受光。

前往影像感測器與光電元件的練習題

相關名詞的解說

背照式(BSI)
從沒有配線層的基板背面入射光線的影像感測器結構。光線不會被配線遮擋，即使是小像素靈敏度也高。
堆疊式 CMOS 影像感測器
將像素部與訊號處理電路分別在不同晶片上製作，再疊合接合的影像感測器。可各自使用適合的製程，使晶片更小、處理更快。
微透鏡
設置在影像感測器各像素上方的小透鏡。匯聚光線並有效率地導入光二極體，以提高靈敏度。
CMOS 影像感測器
每個像素都有放大電路，以 CMOS 製程製造的影像感測器。低功耗且可整合周邊電路，是智慧型手機相機等的主流。
混合鍵合
不使用凸塊，將銅電極與絕緣膜的表面直接接合的技術。可在極窄的間距上進行大量連接。
