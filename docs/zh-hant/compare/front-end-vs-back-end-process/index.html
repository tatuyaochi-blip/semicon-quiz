半導體前段製程與後段製程的差異：製程內容、設備、負責企業比較

半導體的製造大致分為前段製程與後段製程。前段製程是在矽晶圓上反覆進行薄膜沉積、曝光、蝕刻、離子佈植等，做出電晶體與導線的製程。後段製程是將完成的晶圓切成一顆顆晶片，組裝成封裝並與外部連接，經測試後出貨的製程。近年來，隨著小晶片等先進封裝的發展，介於兩者之間的製程也越來越重要。

項目前段製程後段製程
目的在晶圓上做出電晶體與導線，完成電路切割出晶片、組裝成封裝並與外部連接，成為可以出貨的產品
主要製程清洗、氧化、薄膜沉積（CVD、PVD）、微影、蝕刻、離子佈植、熱處理、CMP、導線的形成背面研磨、切割、黏晶、以打線接合或覆晶進行連接、樹脂封裝（模封）、打印、最終測試

主要設備曝光機、蝕刻設備、薄膜沉積設備、離子佈植機、CMP 設備、清洗設備切割機、黏晶機、打線機、模封設備、測試機（ATE）、分類機（handler）

適用於什麼情況

前段製程
是決定晶片性能、耗電量與積體度的部分。是微縮競爭的核心，對曝光機等的投資也很龐大。
後段製程
是保護晶片、散熱並與基板連接的部分。封裝的形式與連接方式，會影響產品的尺寸、散熱與訊號速度。
中段製程
TSV、微細的重佈線、凸塊的形成等，以晶圓的狀態將接近前段製程的技術用於封裝的製程，有時稱為中段製程（middle-end）。在小晶片與堆疊記憶體中越來越重要。

常見問題

前段製程與後段製程的分界在哪裡？

一般而言，到在晶圓上完成電路為止是前段製程，從將晶圓切割成晶片、組裝成封裝的製程開始是後段製程。每顆晶片的電性測試（晶圓測試）要歸入哪一邊，依公司與資料而異。

為什麼前段製程比較花時間？

因為薄膜沉積、曝光、蝕刻等製程，要依電晶體與導線的層數反覆進行數十次。在先進邏輯半導體中，步驟多達一千個以上，從投入晶圓到前段製程結束需要 3 個月以上。

為什麼後段製程受到關注？

因為光靠微縮已難以持續提升性能，而透過小晶片與 3D 封裝，將多顆晶片高密度地排列或堆疊在同一個封裝中來提升性能的方法正逐漸普及。像在處理器旁堆疊記憶體的 HBM 這樣，後段製程的技術左右產品性能的例子越來越多。

什麼是 OSAT？

是 Outsourced Semiconductor Assembly and Test 的縮寫，指承接後段製程組裝與測試的企業。從無晶圓廠企業或晶圓代工接收完成的晶圓，進行封裝與測試。

理解度檢測

下列關於半導體製造「前段製程」與「後段製程」之劃分，何者正確？

  1. A前段製程是設計，後段製程是製造
  2. B前段製程是在晶圓上製作電路的製程，後段製程是切割出晶片並進行組裝、檢測的製程
  3. C前段製程是檢測，後段製程是晶圓的製造
查看答案與解析

正確答案：B. 前段製程是在晶圓上製作電路的製程，後段製程是切割出晶片並進行組裝、檢測的製程

前段製程是反覆進行薄膜沉積、微影、蝕刻、離子佈植等，在晶圓上製作電路的製程。後段製程則是將自晶圓切割出的晶片組裝成封裝、檢測後出貨的製程。設計是製造之前的另一個階段。近年來，在晶圓狀態下進行重佈線與晶片堆疊的先進封裝重要性提升，兩者的界線逐漸變得模糊。

在先進的邏輯半導體中，從將晶圓投入製造線到前段製程完成所需的期間，下列何者最接近其參考值？

  1. A約1天
  2. B數個月（大致3個月以上）
  3. C約10年
查看答案與解析

正確答案：B. 數個月（大致3個月以上）

在先進的邏輯半導體中，曝光、薄膜沉積、蝕刻等製程合計達上千個步驟，光是前段製程就需要3個月以上。再加上後段製程與測試，且興建新工廠需要2年以上，因此即使需求突然增加，供給也無法立刻增加，這是容易發生供需落差與缺貨的原因之一。1天無法完成眾多的製程，10年則太長了。

下列何者適合作為近年後段製程（封裝）重要性提高的理由？

  1. A因為後段製程變得不需要了
  2. B因為封裝的成本幾乎變成0
  3. C因為小晶片（Chiplet）與先進封裝已成為提升系統效能的重要手段
查看答案與解析

正確答案：C. 因為小晶片（Chiplet）與先進封裝已成為提升系統效能的重要手段

在僅靠微縮已難以提升效能的情況下，將多個晶片高密度連接的先進封裝，成為提高效能與電力效率的手段。在AI用的半導體上，將HBM排列在處理器旁邊、以矽中介層（interposer）連接的2.5D封裝，其產能甚至左右了產品的供應量。後段製程並未變得不需要，成本也不是變成0。

相關名詞的解說

晶圓切割
將晶圓切成一個個晶片（晶粒）的步驟。除了以旋轉刀片切割的方法外，還有以雷射在內部形成改質層的隱形切割等。
背面研磨
為使封裝變薄，在切割前研磨晶圓背面使其變薄的步驟。堆疊用的晶片會被減薄到數十µm。
打線接合
以金或銅等細金屬線，將晶片的電極焊墊與導線架或基板連接起來的接合方法。
晶圓測試(探針測試)
在切割之前，將探針接觸晶圓上各晶片的電極，檢查電氣特性的步驟。可在組裝前找出不良晶片，避免無謂的組裝。
OSAT(封裝測試代工廠)
承接半導體組裝與測試等後段製程的企業。

相關的比較

  • IDM、無晶圓廠、晶圓代工的差異：半導體企業的商業模式比較從負責的製程、是否擁有工廠、投資、優勢與劣勢、代表性企業與產品等面向，以表格比較半導體企業的三種經營形態：IDM（垂直整合型）、無晶圓廠（Fabless）與晶圓代工。也說明輕晶圓廠（Fab-lite）與 OSAT。
  • 晶圓測試與最終測試的差異：時機、接觸方式、溫度、項目、目的比較從測試時機與對象、接觸方式（探針卡與測試座）、溫度、測試項目、找出不良品的目的與 KGD 等面向，以表格比較晶圓測試（探針測試）與最終測試。
  • 打線接合與覆晶的差異：晶片連接方式比較以連接方式、輸入輸出數量、電氣性能、成本、尺寸、製程與用途等面向，用表格比較打線接合與覆晶。
  • 球形接合與楔形接合的差異：材料、製程、方向性、用途比較從接合的形狀、工具、接合的能量、線材材料（Au、Cu 與 Al、帶狀線）、線徑、方向性、速度、線弧、可靠度與用途等面向，以表格比較球形接合與楔形接合，並說明各自適用的時機。
  • 靜態、動態與晶圓級預燒測試的差異：應力、涵蓋性、成本比較從施加應力的方式、進行的階段、典型條件、承受應力的範圍、設備與治具、監控、成本、課題與用途等面向，以表格比較靜態預燒測試、動態預燒測試與晶圓級預燒測試，並說明各自適用的時機。
  • ASIC、FPGA、SoC 的差異：靈活性、成本、用途比較說明 ASIC、FPGA、SoC 各是什麼，並從靈活性、效能、前期費用與單價、開發期間與用途等面向，以表格比較。
