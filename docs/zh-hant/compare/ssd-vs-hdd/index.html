SSD 與 HDD 的差異：比較速度、耐用度與成本

硬碟機(HDD)以磁性方式把資料記錄在旋轉的碟片上，並用移動的磁頭讀寫。固態硬碟(SSD)把資料記錄在 NAND 型快閃記憶體晶片中，沒有可動零件。SSD 快上數倍、安靜且耐衝擊；另一方面，HDD 每 TB 的成本便宜許多，也能做到大容量。因此常把兩者組合起來，系統與作業中的檔案用 SSD，大量保存用 HDD。

適用於什麼情況

SSD
所有重視速度與反應快慢的用途。系統磁碟、應用程式、筆記型電腦、行動裝置。
HDD
以最低的每 TB 成本，保存很少存取的大量資料時。備份、媒體庫、封存等。
組合
系統與作業用的快速 SSD，加上保存用的大容量 HDD，是常見的配置。

常見問題

SSD 總是比 HDD 快嗎？

大部分作業都是如此。SSD 的存取時間是數十微秒，HDD 則是毫秒。循序速度方面，SSD 約為 500 MB/s 到 14 GB/s，HDD 約為 100〜250 MB/s。

SSD 會劣化嗎？

快閃記憶體的儲存格能承受的寫入與抹除次數有限。以損耗平均與預留空間來分散磨損，磁碟以 TBW 評等，但這個數值遠大於多數使用方式實際寫入的量。

為什麼 HDD 現在仍被使用？

因為每 TB 便宜許多，也能做到更大的容量，所以仍然是大量保存、備份與封存的選擇。

TRIM 是什麼？

作業系統通知 SSD 哪些區塊不再使用的指令。垃圾回收可以先抹除它們，維持寫入效能。

理解度檢測

與 HDD（硬碟）相比，SSD 的特徵下列何者正確？

  1. A使碟片旋轉，以磁性方式記錄
  2. B沒有機械運動的零件，隨機存取快，耐衝擊
  3. C相同容量下一定比 HDD 便宜
查看答案與解析

正確答案：B. 沒有機械運動的零件，隨機存取快，耐衝擊

SSD 以 NAND 快閃記憶體記錄，因此沒有碟片或磁頭之類的可動零件。HDD 因磁頭移動與等待碟片旋轉，一次存取需要數 ms，而 SSD 約為數十～100 µs，尤其是隨機存取快了數百倍。耐衝擊、耐震動且安靜。另一方面，每容量的價格 HDD 較便宜，大容量儲存方面仍持續使用 HDD。

SSD 等所使用的損耗平均（Wear Leveling）的目的，下列何者正確？

  1. A壓縮資料以增加容量
  2. B加密資料以保護資料
  3. C不讓寫入集中在特定區塊，而是分散到整體以延長壽命
查看答案與解析

正確答案：C. 不讓寫入集中在特定區塊，而是分散到整體以延長壽命

區塊有改寫次數的上限，因此若總是寫入相同的邏輯位址，只有該處會提早到達壽命。損耗平均中，控制器管理邏輯位址與實體區塊的對應表（FTL），將寫入分配到抹除次數較少的區塊。對於很少改寫的靜態資料也會不時搬移，使所有區塊的損耗一致，進而延長整個產品的壽命。

關於 SSD 的垃圾回收（Garbage Collection），下列說明何者正確？

  1. A從含有無效資料的區塊中，將有效資料搬到別處，再抹除該區塊以製造空白區域的處理
  2. B移除電腦病毒的處理
  3. C壓縮資料的處理
查看答案與解析

正確答案：A. 從含有無效資料的區塊中，將有效資料搬到別處，再抹除該區塊以製造空白區域的處理

NAND 無法覆寫，抹除又只能以區塊為單位，因此每次改寫，舊版本都會以無效頁的形式留下。控制器選擇無效頁較多的區塊，將有效資料搬到別的區塊後抹除原區塊，製造出空白區域。這種多餘的複製是寫入放大的成因，空白容量越少就越頻繁，寫入效能也會下降。

前往SRAM與快閃記憶體的練習題

相關名詞的解說

NAND 型快閃記憶體
記憶單元以串聯方式連接的非揮發性記憶體。容易高密度、大容量化，用於 SSD 與記憶卡。
3D NAND
將 NAND 快閃記憶體的記憶單元在垂直方向堆疊許多層以達成大容量。為突破平面微縮的極限而導入，堆疊層數已達 200 層以上。
