四點探針法與霍爾效應量測的差異：可得知的量、試片準備、是否破壞、用途比較

兩者都是量測半導體層電性的方法，但能得知的內容不同。四點探針法將排成一直線的4根探針接觸晶圓，在外側2根通電流、以內側2根量測電壓，求出片電阻。霍爾效應量測則在切下的小試片上製作電極，除了電阻之外，也量測施加磁場時產生的霍爾電壓。由此可分別得知載子是電子還是電洞，以及其濃度與遷移率。四點探針法用於快速簡便的製程監控，霍爾效應量測則用於材料本身的評估。

項目四點探針法霍爾效應量測(范德堡法)
可得知的量片電阻(Ω/□)。若已知膜厚則可得電阻率片電阻(電阻率)之外，還有載子類型、濃度與遷移率
原理在外側2根探針通電流，以內側2根量測電壓。足夠寬的薄層中Rs≈4.53×V/I以試片周圍的4個電極量測電阻，再施加垂直於試片的磁場，量測勞侖茲力產生的霍爾電壓
載子類型(n型或p型)無法得知可由霍爾電壓的正負得知
試片準備幾乎不需要。只要將探針接觸晶圓切成小片，並在周圍製作歐姆接觸的電極
磁場不需要需要
是否破壞只留下探針痕跡，可直接量測整片晶圓。多半使用監控晶圓而非產品需要切割與製作電極，屬破壞性
速度與分布量測快。量測晶圓全面多點分布很常見一次一個試片，耗時較長。也能改變溫度量測
主要用途離子佈植、退火、擴散層、金屬膜的製程監控磊晶層、化合物半導體、新材料的評估，以及載子濃度與遷移率的評估

數值為具代表性的大致參考值，會因世代或產品而異。

適用於什麼情況

四點探針法
想以日常製程管理的方式，快速確認離子佈植、退火或成膜的結果時使用。由與基準晶圓相比的片電阻變化，可察覺劑量、活化或金屬膜厚的異常。
霍爾效應量測
想分別得知磊晶層或新材料的載子類型、濃度與遷移率時使用。因為只看電阻，無法區分是載子多，還是載子容易移動。

常見問題

為什麼四點探針法不受接觸電阻影響？

因為通電流的探針與量測電壓的探針是分開的。量測電壓的內側探針幾乎沒有電流流過，探針與試片之間的接觸電阻不會造成壓降，因此只量到層本身的電壓。

為什麼霍爾效應量測能得知遷移率？

由霍爾電壓可得知載子濃度，由電阻量測可得知電導率。電導率可表示為電荷×載子濃度×遷移率，因此結合兩者即可求出遷移率。這樣求得的值稱為霍爾遷移率，依散射機制不同，可能與漂移遷移率略有差異。

什麼是范德堡法？

只要試片厚度均勻且沒有孔洞，不論形狀為何，都能只用周圍4個小電極量測電阻率與霍爾係數的方法。量測時會交換通電流與量測電壓的電極組合，再取平均。

四點探針法能得知佈植劑量嗎？

無法直接得知。片電阻取決於已活化的雜質量與遷移率，因此在相同退火條件下，劑量越多片電阻越低。因此會透過與基準晶圓比較，或事先建立的換算關係，監控劑量或活化的異常。

理解度檢測

四探針法主要量測的是下列何者？

  1. A片電阻
  2. B膜的應力
  3. C表面的粗糙度
查看答案與解析

正確答案：A. 片電阻

四探針法是將排成一直線的4根探針接觸試片，在外側2根通入電流，以內側2根量測電壓。由於量測電壓的探針幾乎沒有電流流過，因此不受接觸電阻影響即可量測片電阻。對於夠寬的薄膜，可由Rs=(π/ln2)×V/I≒4.53×V/I求得。用於擴散層與金屬膜的評估。應力是由晶圓的翹曲、粗糙度則是以AFM等來量測。

從霍爾效應的量測中可以得知什麼？

  1. A載子的種類（電子或電洞）與載子濃度
  2. B能隙的大小
  3. C晶體的熔點
查看答案與解析

正確答案：A. 載子的種類（電子或電洞）與載子濃度

對通有電流的試片垂直施加磁場時，載子會因勞侖茲力偏向一側，在橫向產生霍爾電壓。由電壓的正負號可知載子是電子還是電洞，由大小（V_H = IB/qnt）可知載子濃度。與電阻率組合後還能求出遷移率（μ = 1/qnρ），並與范德堡法結合，廣泛用於薄膜的評估。能隙是以光吸收等方式，熔點則以熱分析來檢測。

當電子濃度為n、電洞濃度為p、電子遷移率為μn、電洞遷移率為μp、基本電荷為q時，表示半導體電導率σ的式子為下列何者？

  1. Aσ = q(nμn − pμp)
  2. Bσ = (nμn + pμp) / q
  3. Cσ = q(nμn + pμp)
查看答案與解析

正確答案：C. σ = q(nμn + pμp)

電子與電洞的移動方向相反，但電荷的正負號也相反，因此電流朝同一方向流動，電導率是兩者之和 σ = q(nμn + pμp)。電阻率則是其倒數。在摻雜的半導體中，只取多數載子的項就足以近似，例如n型時 σ ≈ qnμn。在本質矽中 n = p = ni，所以 σ = q·ni(μn + μp)，電阻率高達約2～3×10⁵ Ω·cm。

前往量測與分析的練習題

相關名詞的解說

四點探針法
在排成一直線的4根探針中，對外側2根通電流，量測內側2根的電壓，以求出晶圓或薄膜片電阻的方法。
遷移率
施加電場時載子移動的難易程度。在矽中，電子的遷移率比電洞大。
離子佈植
將雜質離子化、加速後打入晶圓的技術。可精密控制佈植劑量與深度。
佈植劑量
離子佈植時，每單位面積打入的離子數。以cm⁻²為單位表示，由離子束電流與佈植時間決定。
退火
即熱處理。用於離子佈植後修復晶體缺陷及活化雜質等。
歐姆接觸
與電流方向無關、電阻小，且電流與電壓成正比的金屬與半導體接觸。將半導體表面高濃度摻雜，使位障容易被穿隧通過而製成。
監控晶圓
為確認設備狀態或量測膜厚、微粒等，與產品分開送入製程的晶圓。也稱為測試晶圓。使用後多半去除薄膜並重新研磨，作為再生晶圓再利用。
