关于本站

“半导体教室”是一个通过三选一练习题学习半导体技术的非官方学习网站，内容参照日本“半导体技术者检定”（半導体技術者検定）的出题范围。

关于非官方

本站由个人运营，与半导体技术者检定的主办机构及相关机构没有任何关系。报名方法、考试范围等官方信息，请以主办机构的公告为准。

关于题目

本站刊登的题目和解析均为原创，未使用官方的历年真题。题目从半导体基础到器件、制造工艺、封装与测试、设计与产业，共分为36个领域。

中文题目是根据日文原题翻译的。我们会尽力保证内容准确，但仍可能存在错误。如发现错误，请通过联系我们页面告知。

使用方法

  • 按领域练习：在首页选择领域，练习该领域的题目。
  • 随机10题：从所有领域随机抽取10道题。
  • 错题练习：只重做最近答错的题目。
  • 模拟考试：从所有领域抽取30道题，最后统一显示解析。

答题记录只保存在你的浏览器中，可以在学习记录页面查看。无需注册账号。
