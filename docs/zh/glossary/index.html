半导体术语表

汇总了学习半导体时经常出现的基本术语，可以输入关键词进行筛选。

采样定理
只要以高于信号最高频率两倍的频率进行采样，就能恢复原始信号的定理，也称奈奎斯特采样定理。 相关：AD/DA转换 →
超纯水
将离子、颗粒、有机物等去除到极限的水。大量用于晶圆清洗，用电阻率等指标管理纯度。 相关：工艺材料（气体与化学品） →
触发器
保存1位信息的时序电路基本元件。D触发器在时钟边沿采样输入。 相关：逻辑电路 →
大马士革工艺
在绝缘膜上刻出沟槽并填入金属，再用CMP去除多余金属以形成布线的方法。用于铜布线。 相关：布线工艺 →
倒装芯片
将芯片电路面朝下，通过凸点直接与基板连接的封装方法。连接短，适合多引脚。 相关：封装与组装 →
低k材料
介电常数低的层间绝缘材料。可降低布线间电容，减少信号延迟和功耗。 相关：布线工艺 →
电流放大系数（hFE）
双极型晶体管的集电极电流与基极电流之比（IC/IB）。 相关：双极型晶体管 →
电迁移
电流使布线中的金属原子发生迁移的现象。会产生空洞和小丘，导致断路或短路。 相关：可靠性 →
高速缓存
放置在CPU附近的高速、小容量存储器。保存常用数据，以缓解与主存之间的速度差。主要由SRAM构成。 相关：CPU与体系结构 →
高k/金属栅
高介电常数栅绝缘膜与金属栅电极的组合。在抑制栅极漏电的同时保证栅电容。 相关：先进晶体管（FinFET与GAA） →
各向异性刻蚀
刻蚀只沿特定方向（主要是垂直方向）进行的性质。加工微细图形时必不可少。 相关：刻蚀 →
光电二极管
受光后产生电荷（电流）的二极管。用作图像传感器像素的受光元件。 相关：图像传感器与光器件 →
光刻胶
受光后在显影液中的溶解性发生变化的感光材料。正性胶曝光部分溶解，负性胶曝光部分保留。 相关：光刻 →
耗尽层
在PN结界面附近形成的、几乎不存在载流子的区域。加反向偏压时会变宽。 相关：PN结与二极管 →
溅射
PVD的一种。用等离子体中的离子轰击靶材，使被溅射出的原子沉积在晶圆上。 相关：成膜（CVD与PVD） →
禁带宽度（带隙）
价带顶与导带底之间的能量差。硅在室温下约为1.12 eV。带隙越大，越能耐受高温和高电压。 相关：半导体物理 →
晶圆代工（Foundry）
专门为其他公司设计的半导体提供制造服务的企业或经营模式。 相关：半导体产业与市场 →
老化筛选（Burn-in）
在高温、高电压等应力下使产品工作，于出货前剔除容易发生早期失效的产品的试验。 相关：测试与检验 →
离子注入
将杂质离子化并加速后注入晶圆的技术。可以精确控制注入剂量和深度。 相关：离子注入 →
良率
合格品占投入总数的比例。对半导体制造成本影响很大的指标。 相关：良率与质量管理 →
灵敏放大器
将从存储单元读出的微小电压差放大，并判断是0还是1的电路。 相关：DRAM →
逻辑综合
将用RTL描述的电路转换为由单元库中的门电路构成的网表的设计步骤。 相关：LSI设计流程与EDA →
齐纳二极管
利用反向击穿电压几乎恒定的特性来获得稳定电压的二极管，也称稳压二极管。 相关：PN结与二极管 →
迁移率
施加电场时载流子运动的难易程度。在硅中，电子的迁移率大于空穴。 相关：半导体物理 →
热氧化
在氧气或水蒸气中加热硅，在表面形成SiO2膜的方法。分为干氧氧化和湿氧氧化。 相关：氧化与扩散 →
施主
向半导体提供电子的杂质。对硅而言，磷(P)、砷(As)等V族元素是施主，可形成n型半导体。 相关：半导体物理 →
受主
从半导体接受电子并产生空穴的杂质。对硅而言，硼(B)等III族元素是受主，可形成p型半导体。 相关：半导体物理 →
数值孔径（NA）
表示透镜可收集光线角度范围的数值。数值越大，分辨率越高。 相关：光刻 →
刷新
在DRAM电容的电荷因漏电而丢失之前，定期读出并重新写入数据的操作。 相关：DRAM →
退火
即热处理。用于修复离子注入后的晶格损伤、激活杂质等。 相关：离子注入 →
外延生长
在单晶衬底上生长与衬底晶向一致的单晶薄膜的技术。 相关：外延生长 →
无晶圆厂（Fabless）
不拥有自己的制造工厂，专注于半导体设计与销售的企业模式。 相关：半导体产业与市场 →
芯粒（Chiplet）
按功能分开制造的小芯片。将多个芯粒在一个封装内互连，构成大规模系统。 相关：先进封装（3D集成与芯粒） →
选择比
刻蚀中，待刻蚀膜与掩模或下层膜的刻蚀速率之比。选择比越大，越不容易损伤下层。 相关：刻蚀 →
引线键合
用金、铜等细金属线连接芯片电极焊盘与引线框架或基板的连接方法。 相关：封装与组装 →
浴盆曲线
表示失效率随时间变化的曲线。由早期失效期、偶然失效期和耗损失效期组成，形状像浴盆。 相关：可靠性 →
阈值电压
MOSFET中形成沟道（反型层）、开始有电流流过时的栅极电压，记作Vth。 相关：MOSFET →
运算放大器
具有差分输入和极高增益的放大器。通常加负反馈，用于放大电路、滤波器等。 相关：模拟电路与电子电路 →
直接带隙
导带底与价带顶位于相同波矢处的能带结构。电子与空穴复合时能高效发光，如GaAs。 相关：化合物半导体 →
直拉法（CZ法）
将籽晶浸入坩埚中熔化的硅，一边旋转一边缓慢提拉，从而制造单晶的方法。 相关：硅晶圆 →
ALD
原子层沉积。重复进行前驱体气体的自限制表面反应，以原子层为单位控制膜厚的成膜方法。 相关：成膜（CVD与PVD） →
BGA
球栅阵列。在封装底面以网格状排列焊球的多引脚封装。 相关：封装与组装 →
CD-SEM
用于测量图形线宽（CD）的扫描电子显微镜。用于光刻和刻蚀后的尺寸管理。 相关：量测与分析 →
CMOS
将nMOS和pMOS互补组合的电路方式。稳态下几乎没有直通电流，功耗低。 相关：MOSFET →
CMP
化学机械抛光。结合抛光液的化学作用与抛光垫的机械研磨，使晶圆表面平坦化。 相关：CMP与清洗 →
CVD
化学气相沉积。利用原料气体的化学反应在晶圆上沉积薄膜的方法。 相关：成膜（CVD与PVD） →
DFT（可测试性设计）
预先在电路中加入扫描链、BIST等便于测试的结构的设计方法。 相关：测试与检验 →
EUV光刻
使用波长13.5 nm的极紫外光的光刻技术。采用反射光学系统和真空环境。 相关：光刻 →
FinFET（鳍式场效应晶体管）
沟道像鳍一样竖立、栅极从三面包围沟道的立体结构晶体管。容易抑制短沟道效应。 相关：先进晶体管（FinFET与GAA） →
FOUP
用于在密封状态下搬运和保存300 mm晶圆的容器。 相关：洁净室与制造设备 →
GaN（氮化镓）
带隙约3.4 eV的III-V族化合物半导体。用于蓝光LED以及高频和功率器件。 相关：化合物半导体 →
HBM（高带宽存储器）
用TSV堆叠多个DRAM裸片，通过极宽的总线实现高带宽的存储器。 相关：先进封装（3D集成与芯粒） →
IGBT
绝缘栅双极型晶体管。由MOS栅极驱动，利用电导调制效应，即使在高耐压下也能获得较低的导通电压。 相关：功率半导体 →
MEMS（微机电系统）
利用半导体微细加工技术，将微小机械结构和电子电路制作在一起的器件。 相关：MEMS与传感器 →
MRAM（磁阻随机存储器）
利用磁隧道结(MTJ)磁化方向不同导致的电阻差异来存储信息的非易失性存储器。 相关：新型存储器 →
NAND闪存
存储单元串联连接的非易失性存储器。集成度高，易于实现大容量，用于SSD和存储卡等。 相关：SRAM与闪存 →
RCA清洗
用SC-1（氨水与过氧化氢）去除颗粒和有机物，用SC-2（盐酸与过氧化氢）去除金属污染的清洗方法。 相关：CMP与清洗 →
SDS（安全数据表）
记载化学品的危险有害性、操作方法、急救措施等内容的文件。 相关：环境与安全 →
SiC（碳化硅）
带隙约3.3 eV的宽禁带半导体。击穿电场强度高，用于高耐压、低损耗的功率器件。 相关：功率半导体 →
SIMS（二次离子质谱）
用一次离子溅射样品并对二次离子进行质谱分析，以高灵敏度测量杂质深度分布的方法。 相关：量测与分析 →
STA（静态时序分析）
不使用测试向量，计算电路中各条路径的延迟，验证是否满足时序约束的方法。 相关：LSI设计流程与EDA →
TSV（硅通孔）
贯穿硅衬底的电极。以很短的距离在垂直方向连接堆叠的芯片。 相关：先进封装（3D集成与芯粒） →
