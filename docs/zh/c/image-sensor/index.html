图像传感器与光器件要点

图像传感器用每个像素中的光电二极管将光转换为电荷，再作为电信号读出。目前CMOS图像传感器是主流，广泛用于智能手机和车载摄像头。

从布线层的另一侧入射光的背照式结构，以及将像素和电路分别制作在不同芯片上再堆叠的堆叠式结构，提高了传感器的性能。LED、激光器等将电转换为光的光器件也属于本领域。
