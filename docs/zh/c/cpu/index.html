CPU与体系结构要点

CPU通过反复进行取指令、译码和执行来处理程序。大多数计算机采用将程序和数据存放在同一主存中的冯·诺依曼结构。

提高性能的方法包括将指令处理分阶段重叠进行的流水线、弥补与主存速度差的高速缓存，以及利用多个核心的并行处理。半导体的微缩化支撑了这些进步。
