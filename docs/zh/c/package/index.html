封装与组装要点

封装的作用是保护芯片免受外界环境影响、将芯片与基板电连接并散热。从晶圆上切下的芯片经过贴片、互连、塑封等工序成为产品。

芯片与外部的连接方式有引线键合和倒装芯片。为适应多引脚化，封装形态也从引出引脚的类型发展到在底面排列焊球的BGA等类型。
