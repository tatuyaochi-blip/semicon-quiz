MOSFET要点

MOSFET利用栅极电压在半导体表面形成反型层（沟道），从而控制源极与漏极之间的电流。由于栅极被很薄的绝缘膜隔开，几乎没有稳定的栅极电流。

阈值电压、线性区与饱和区、短沟道效应，以及将nMOS和pMOS组合起来的CMOS电路，是理解大规模集成电路的重要内容。
