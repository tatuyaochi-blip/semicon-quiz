半导体物理要点

半导体的性质在很大程度上由带隙决定，即价带与导带之间的能量差。硅的带隙在室温下约为1.12 eV，既不像绝缘体那样大，也不像金属那样为零。

添加杂质后，可以得到电子较多的n型半导体或空穴较多的p型半导体。载流子浓度的温度特性、迁移率以及漂移电流与扩散电流的区别，是理解后续器件工作原理的基础。
