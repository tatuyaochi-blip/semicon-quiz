LSI设计流程与EDA要点

LSI的设计流程是：先确定规格，用硬件描述语言在RTL（寄存器传输级）描述电路，通过逻辑综合转换为门级连接（网表），再通过布局布线生成版图。

每个阶段都离不开使用EDA工具进行的仿真、静态时序分析（STA）和验证。设计规模越大，验证所需的工作量也越大。
