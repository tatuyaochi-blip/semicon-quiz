良率与质量管理要点

良率是投入产品中合格品所占的比例，是对半导体工厂收益影响很大的指标。在缺陷密度相同时，芯片面积越大，含有缺陷的概率越高，良率就越低。

为了保持工序稳定，要用控制图等统计方法（SPC）监控数据，尽早发现异常并采取对策。
