逻辑电路要点

数字电路由与门、或门、非门等基本逻辑门及其组合（与非门、或非门、异或门等）构成。利用真值表、布尔代数和德摩根定律，可以化简逻辑表达式或用其他门进行替换。

还要理解输出只由输入决定的组合逻辑电路，与通过触发器等保存状态的时序逻辑电路之间的区别。
