工艺材料（气体与化学品）要点

半导体制造使用大量材料，包括高纯度硅、用于成膜和刻蚀的特种气体、用于清洗的化学品和超纯水、溅射靶材、光刻胶、CMP抛光液等。

极少量的杂质也可能导致不良，因此这些材料要求极高的纯度。此外，许多气体具有自燃性或毒性，安全操作必不可少。
