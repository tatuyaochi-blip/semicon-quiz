环境与安全要点

半导体工厂使用大量氢氟酸等化学品，以及具有毒性或可燃性的特种气体。了解化学品的危险性，并按照SDS（安全数据表）正确操作是基本要求。

废气需经尾气处理装置处理后再排放。此外，减少用于刻蚀和设备清洗的PFC等温室气体的排放也是重要课题。
