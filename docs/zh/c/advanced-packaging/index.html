先进封装（3D集成与芯粒）要点

仅靠微缩化提升性能变得越来越困难，因此将多个芯片集成在一个封装中以提升性能的技术备受关注。按功能拆分的小芯片（芯粒）组合方式在良率和成本方面也有优势。

用TSV将芯片纵向堆叠的3D集成，以及在中介层上并排放置处理器和HBM的2.5D集成，已被用于AI用的高性能半导体。
