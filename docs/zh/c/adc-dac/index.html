AD/DA转换要点

AD转换器（ADC）将模拟信号转换为数字值，DA转换器（DAC）则将数字值转换为模拟信号。在传感器、通信、音频等连接现实信号与数字处理的地方都会用到。

衡量性能的基本指标是分辨率（位数）和转换速度。需要掌握采样定理、量化误差，以及快闪型、逐次逼近型、ΔΣ型等各种方式的特点。
