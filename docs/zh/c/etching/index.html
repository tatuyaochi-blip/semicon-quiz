刻蚀要点

刻蚀是去除未被光刻胶等掩模覆盖部分的薄膜、从而形成图形的工序。分为使用化学药液的湿法刻蚀，以及使用等离子体等的干法刻蚀。

要准确加工微细图形，只沿垂直方向刻蚀的各向异性，以及只刻蚀目标膜的选择比非常重要。反应离子刻蚀（RIE）是代表性的方法。
