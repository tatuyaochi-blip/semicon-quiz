MEMS与传感器要点

MEMS（微机电系统）是利用半导体微细加工技术，将微小机械结构与电子电路制作在一起的器件。广泛用于智能手机中的加速度传感器、陀螺仪、麦克风和压力传感器等。

需要理解使可动结构悬空的牺牲层刻蚀，以及将位移、应力、磁场等转换为电信号的原理（电容、压阻效应、霍尔效应）。
