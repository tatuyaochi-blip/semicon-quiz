功率半导体要点

功率半导体负责电力的转换与控制，用于逆变器、电源和电动汽车等。它们需要高耐压、低导通电阻和高速开关。

除硅MOSFET和IGBT外，使用带隙大、击穿电场高的SiC和GaN制造的器件正在普及。理解材料特性与器件结构之间的关系非常重要。
