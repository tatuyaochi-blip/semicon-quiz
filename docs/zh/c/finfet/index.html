先进晶体管（FinFET与GAA）要点

晶体管微缩后，会出现栅极难以控制沟道的短沟道效应。于是出现了将沟道做成鳍状、由栅极从三面包围的FinFET，并进一步发展为从四周包围沟道的GAA（全环绕栅极）晶体管。

抑制栅极漏电的高k/金属栅，以及提高迁移率的应变技术，也是支撑先进晶体管的重要技术。
