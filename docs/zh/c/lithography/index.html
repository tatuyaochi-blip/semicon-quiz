光刻要点

光刻是用光将掩模（掩模版）上的电路图形转移到晶圆上的光刻胶中的工序。它决定了微缩化的极限，曝光设备也是半导体制造设备中技术难度最高的设备之一。

曝光波长λ越短、透镜的数值孔径NA越大，分辨率就越高。先进产品的制造使用ArF准分子激光（193 nm）浸没式光刻以及波长13.5 nm的EUV光刻。
