成膜（CVD与PVD）要点

成膜是在晶圆上形成绝缘膜、半导体膜、金属膜等薄膜的工序，大致分为利用气体化学反应沉积薄膜的CVD，以及通过溅射、蒸镀等物理方法沉积的PVD。

随着器件的微缩化和立体化，能够以原子层为单位控制膜厚、并在深沟槽内均匀成膜的ALD越来越重要。
