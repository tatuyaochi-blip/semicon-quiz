布线工艺要点

在大规模集成电路中，晶体管之间由多层金属布线连接。随着微缩化的发展，布线电阻和电容引起的延迟（RC延迟）开始左右电路性能，布线材料也不断得到改进。

电阻比铝低的铜布线难以进行干法刻蚀，因此采用将铜填入沟槽、再用CMP去除多余部分的大马士革工艺制作。层间绝缘膜使用介电常数低的低k材料。
