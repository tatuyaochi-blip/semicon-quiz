量测与分析要点

在半导体制造中，需要一边测量线宽、膜厚、杂质浓度和缺陷等，一边确认各道工序是否正确完成。微缩化越深入，就越需要纳米级的精确测量。

根据目的使用不同的方法：用电子显微镜（SEM、TEM）观察形貌，用椭偏仪测量膜厚，用二次离子质谱（SIMS）测量杂质分布，用四探针法测量方块电阻等。
