化合物半导体要点

化合物半导体是由多种元素组成的半导体，如GaAs（砷化镓）和GaN（氮化镓）。III族与V族元素的组合（III-V族）最为典型。

有的电子迁移率比硅高，有的是能高效发光的直接带隙材料，有的带隙很大。它们被用于高频器件、LED与激光器以及功率器件。
