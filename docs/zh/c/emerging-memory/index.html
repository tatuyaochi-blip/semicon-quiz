新型存储器要点

为了弥补DRAM和闪存的局限，各种基于新原理的存储器正在开发中。它们大多是非易失性存储器，不是用电荷，而是用电阻或极化方向的差异来存储信息。

MRAM利用磁隧道结的磁化方向，PCM利用晶态与非晶态的电阻差，ReRAM利用氧化物中的导电通路，FeRAM利用铁电体的极化。要能够区分这些原理和特点。
