CMP与清洗要点

CMP（化学机械抛光）结合抛光液的化学作用和抛光垫的机械研磨，使晶圆表面平坦化。它是多层布线以及用大马士革工艺形成铜布线时不可缺少的技术。

清洗是去除颗粒、有机物、金属污染和自然氧化膜等的工序，在制造过程中要重复很多次。需要掌握以RCA清洗为基础的各种药液的用途区分。
