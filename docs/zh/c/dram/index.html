DRAM要点

DRAM用1个晶体管和1个电容存储1位数据。单元结构简单，易于高密度集成，因此被广泛用作计算机的主存储器。

电容中的电荷会因漏电流而逐渐丢失，因此需要定期重写数据（刷新）。此外，读出操作会改变单元中的电荷，所以要先用灵敏放大器放大，再写回单元。
