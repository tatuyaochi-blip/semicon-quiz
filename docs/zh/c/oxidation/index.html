氧化与扩散要点

在氧气或水蒸气中加热硅，可以在表面形成优质的SiO2膜。这称为热氧化，一直被用于栅极绝缘膜、器件隔离和掩模等。

热扩散是在高温下通过原子扩散将杂质导入硅中的方法。扩散的进行强烈依赖于温度，因此温度和时间的控制非常重要。
