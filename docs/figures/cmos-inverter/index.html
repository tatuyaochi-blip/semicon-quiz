CMOSインバータ

CMOSインバータは、電源側のpMOSとGND側のnMOSを直列につなぎ、2つのゲートに同じ入力を入れた回路です。入力が0のときはpMOSがオン、nMOSがオフで出力は電源電圧(1)、入力が1のときはpMOSがオフ、nMOSがオンで出力は0になります。

どちらの状態でも片方のトランジスタがオフなので、電源からGNDへ電流がほとんど流れません。これがCMOSの消費電力が小さい理由です。ただし入力が切り替わる途中では両方が同時に導通する瞬間があり、貫通電流が流れます。

動かして確かめる：入力電圧と出力

入力電圧を0から電源電圧まで動かすと、pMOSとnMOSのオン・オフと出力電圧が変わります。右のグラフは入力と出力の関係(伝達特性)です。条件は VDD = 1.2 V、しきい値電圧の大きさ0.35 V、nMOSとpMOSの駆動力は同じとし、長チャネルの2乗則で計算しています。
