n型半導体のエネルギーバンド図

エネルギーバンド図は、電子がとれるエネルギーの帯を縦軸に並べた図です。上の伝導帯の端をEc、下の価電子帯の端をEv、その差がバンドギャップEgです。不純物を含まない真性半導体では、フェルミ準位はバンドギャップのほぼ中央(真性フェルミ準位Ei)にあります。

シリコンにリンなどのドナーを添加すると、伝導帯の電子が増え、フェルミ準位は伝導帯側へ上がります。その位置は EF − Ei = kT·ln(ND/ni) で、濃度が10倍になるごとに室温で約0.06 eVずつ伝導帯に近づきます。p型では逆に、アクセプタの濃度に応じて価電子帯側へ下がります。

動かして確かめる：ドナー濃度とフェルミ準位

ドナー濃度を変えると、フェルミ準位EFが真性フェルミ準位Eiから伝導帯の端Ecへ近づいていく様子を確かめられます。条件はSi、300 K、ni = 1.0×10¹⁰ cm⁻³ で、EF − Ei = kT·ln(ND/ni) で計算しています(縮退しない範囲として10¹⁴〜10¹⁹ cm⁻³)。
