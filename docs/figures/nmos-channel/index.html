nチャネルMOSFETの断面（オンの状態）

nチャネルMOSFETは、p型の基板にn⁺のソースとドレインを作り、その間の表面を薄いゲート絶縁膜を挟んでゲート電極で覆った構造です。ゲートに電圧をかけないときは、ソースとドレインの間はp型なので電流は流れません。

ゲートに正の電圧をかけていくと、表面の正孔が追い払われて空乏層ができ、さらにしきい値電圧を超えると表面に電子が集まってn型に反転します。この電子の層(反転層)がチャネルとなってソースとドレインをつなぎ、トランジスタがオンになります。

動かして確かめる：ゲート電圧とチャネル

ゲート電圧VGSを上げていくと、ゲートの下の正孔が追い払われて空乏層が広がり、しきい値電圧を超えると表面に電子が集まって反転層(チャネル)ができます。しきい値電圧は0.46 V、フラットバンド電圧は約−1.0 V(しきい値電圧の計算ツールの既定値)としています。
