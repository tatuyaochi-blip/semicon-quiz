A/D·D/A 변환

양과 음의 전압을 모두 다루는 ADC에서 사용되는 "오프셋 바이너리" 부호에 대한 설명으로 옳은 것은 무엇인가?

  1. A최상위 비트만으로 부호를 나타내고 나머지로 절댓값을 나타낸다
  2. B음의 풀스케일을 모두 0, 양의 풀스케일을 모두 1로 하고 0 V는 중앙의 코드로 나타낸다
  3. C음의 값을 모두 0 코드로 모은다
정답과 해설 보기

정답: B. 음의 풀스케일을 모두 0, 양의 풀스케일을 모두 1로 하고 0 V는 중앙의 코드로 나타낸다

오프셋 바이너리는 음의 풀스케일을 000…0, 양의 풀스케일을 111…1로 하고, 0 V를 중앙 부근의 코드(100…0)로 나타내는 방식입니다. 2의 보수와는 최상위 비트를 반전한 것뿐인 관계라 변환이 간단합니다. ADC 내부에서는 아래에서부터 단순히 세는 오프셋 바이너리가 자연스러우므로 출력에 많이 쓰이며, 디지털 처리 쪽에서 2의 보수로 고쳐서 계산합니다.

  • A. 최상위 비트를 부호, 나머지를 절댓값으로 하는 것은 부호 절댓값 표현입니다.
  • B. 옳습니다. 전체 범위를 0부터 차례로 할당하며, 0 V는 중앙이 됩니다.
  • C. 음의 값을 하나의 코드로 모으면 정보가 손실됩니다.
