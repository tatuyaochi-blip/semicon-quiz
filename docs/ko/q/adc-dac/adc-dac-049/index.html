A/D·D/A 변환

여러 ADC를 번갈아 동작시키는 타임 인터리브형 ADC에서 각 ADC의 오프셋, 이득, 타이밍의 어긋남(미스매치)으로 인해 생기는 문제는 무엇인가?

  1. A샘플링 주파수와 관련된 특정 주파수에 불요 스퓨리어스가 나타난다
  2. B입력 범위가 자동으로 넓어진다
  3. C미싱 코드가 반드시 없어진다
정답과 해설 보기

정답: A. 샘플링 주파수와 관련된 특정 주파수에 불요 스퓨리어스가 나타난다

인터리브한 각 ADC의 특성이 조금씩 다르면 그 차이가 ADC를 전환하는 주기로 반복되는 오차가 됩니다. M개의 ADC를 샘플링 주파수 fs로 동작시키면, 오프셋의 어긋남은 fs/M의 배수 위치에, 이득이나 타이밍의 어긋남은 입력 주파수 fin에 대해 k·fs/M ± fin 위치에 스퓨리어스가 나타납니다. 고성능 인터리브 ADC에서는 이를 디지털 보정으로 제거합니다.

  • A. 옳습니다. 전환 주기와 관련된 스퓨리어스가 나타납니다.
  • B. 미스매치로 입력 범위가 넓어지는 일은 없습니다.
  • C. 미스매치에는 미싱 코드를 없애는 효과가 없습니다.
