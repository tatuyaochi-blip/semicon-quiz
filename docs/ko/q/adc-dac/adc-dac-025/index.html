정답: C. 글리치

글리치는 여러 비트가 동시에 전환될 때 스위치 타이밍의 미세한 어긋남으로 중간의 잘못된 코드가 순간적으로 나타나는 것 등으로 생기는, 스파이크 모양의 출력 교란입니다. 특히 0111…에서 1000…처럼 모든 비트가 바뀌는 중앙 코드(메이저 캐리)에서 커집니다. 상위 비트를 온도계 코드로 하거나, 출력을 샘플 앤 홀드로 정리하거나, 스위치 구동 타이밍을 맞추는 등의 방법으로 억제합니다.

  3. 많은 축차 비교형 ADC에서 내부 DAC로 사용되는 방식은 무엇인가?

  5. ADC 방식 중 오버샘플링형으로 분류되는 것은 무엇인가?
