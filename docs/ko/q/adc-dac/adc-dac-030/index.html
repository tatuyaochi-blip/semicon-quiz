ADC 방식 중 오버샘플링형으로 분류되는 것은 무엇인가?

  1. A플래시형
  2. BΔΣ형
  3. C축차 비교형
정답과 해설 보기

정답: B. ΔΣ형

ADC는 나이퀴스트 주파수의 2배 정도로 샘플링하는 나이퀴스트형(플래시형, 축차 비교형, 파이프라인형 등)과, 그보다 훨씬 높은 주파수로 샘플링하는 오버샘플링형으로 나뉩니다. ΔΣ형은 오버샘플링형의 대표이며, 오버샘플링비(OSR)는 수십~수백 배가 일반적입니다. 나이퀴스트형은 1샘플씩 독립적으로 변환하므로 다채널 전환에도 적합합니다.
