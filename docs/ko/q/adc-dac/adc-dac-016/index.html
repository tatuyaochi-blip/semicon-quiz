A/D·D/A 변환

실제 ADC의 잡음과 왜곡을 포함한 성능을 이상적인 ADC의 비트 수로 환산한 지표는 무엇인가?

  1. AENOB(유효 비트 수)
  2. BLSB
  3. CDNL
정답과 해설 보기

정답: A. ENOB(유효 비트 수)

ENOB는 실측한 SINAD(신호 대 잡음+왜곡비)로부터 ENOB = (SINAD − 1.76)/6.02로 구하며, 실제 ADC가 이상적인 ADC의 몇 비트에 해당하는지를 나타냅니다. 예를 들어 12비트 ADC라도 SINAD가 62 dB이면 ENOB는 약 10비트입니다. 입력 주파수가 높아지면 지터와 대역의 영향으로 ENOB가 떨어지므로, 어느 주파수에서의 값인지 확인해야 합니다. 분해능(비트 수)만으로는 실력을 알 수 없는 이유입니다.

A/D·D/A 변환의 다른 문제

  1. 변환을 여러 단으로 나누어 조립 라인처럼 처리하여 고속과 중~고분해능을 양립하는 ADC는 무엇인가?
  2. 노이즈 셰이핑을 하지 않는 단순한 오버샘플링에서 샘플링 주파수를 4배로 했을 때 얻어지는 양자화 잡음의 개선량은 무엇인가?
  3. 높은 주파수의 신호를 AD 변환할 때 샘플링 클록의 시간적 흔들림(지터)이 문제가 되는 이유로 옳은 것은 무엇인가?
  4. 마이크로컨트롤러에서 PWM 신호를 로우패스 필터에 통과시켜 아날로그 전압을 만드는 방법에서 출력 전압을 결정하는 것은 무엇인가?
  5. ADC의 변환 속도를 나타내는 "MS/s(MSPS)"의 의미로 옳은 것은 무엇인가?
