A/D·D/A 변환

ADC 앞단에 두는 안티에일리어싱 필터로 사용되는 필터의 종류는 무엇인가?

  1. A하이패스 필터
  2. B밴드스톱 필터
  3. C로우패스 필터
정답과 해설 보기

정답: C. 로우패스 필터

나이퀴스트 주파수(샘플링 주파수의 절반)를 넘는 성분이 ADC에 들어오면 접혀서 낮은 주파수의 가짜 신호가 되며, 이후에는 구별도 제거도 할 수 없습니다. 그래서 ADC 앞에 로우패스 필터를 두어 나이퀴스트 주파수보다 높은 성분을 제거합니다. 가파른 필터는 만들기 어렵기 때문에, 오버샘플링으로 여유 대역을 넓혀 간단한 1~2차 RC 필터로 해결하는 설계도 일반적입니다.
