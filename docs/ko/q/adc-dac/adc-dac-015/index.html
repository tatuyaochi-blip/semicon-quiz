A/D·D/A 변환

고속 DAC에 많이 사용되는 전류 스티어링형의 특징으로 옳은 것은 무엇인가?

  1. A입력을 오랫동안 적분하여 출력을 만들기 때문에 느리다
  2. B커패시터의 전하를 조금씩 방전하여 출력을 만든다
  3. C다수의 전류원의 전류 경로를 스위치로 전환하여 출력을 만들기 때문에 고속 동작에 적합하다
정답과 해설 보기

정답: C. 다수의 전류원의 전류 경로를 스위치로 전환하여 출력을 만들기 때문에 고속 동작에 적합하다

전류 스티어링형 DAC는 다수의 전류원을 준비하고, 디지털 입력에 따라 각 전류를 출력 쪽 또는 더미 쪽으로 전환하여 합계 전류로 출력을 만듭니다. 전류원을 끄지 않고 경로만 전환하므로 수 GS/s에 이르는 고속 동작이 가능합니다. 상위 비트를 같은 가중치의 전류원 개수로 나타내는 온도계 코드를 사용하면 글리치와 DNL을 억제할 수 있으며, 통신 장비나 파형 발생기의 고속 DAC에 사용되고 있습니다.

A/D·D/A 변환의 다른 문제

  1. 실제 ADC의 잡음과 왜곡을 포함한 성능을 이상적인 ADC의 비트 수로 환산한 지표는 무엇인가?
  2. 변환을 여러 단으로 나누어 조립 라인처럼 처리하여 고속과 중~고분해능을 양립하는 ADC는 무엇인가?
  3. 노이즈 셰이핑을 하지 않는 단순한 오버샘플링에서 샘플링 주파수를 4배로 했을 때 얻어지는 양자화 잡음의 개선량은 무엇인가?
  4. 높은 주파수의 신호를 AD 변환할 때 샘플링 클록의 시간적 흔들림(지터)이 문제가 되는 이유로 옳은 것은 무엇인가?
  5. 마이크로컨트롤러에서 PWM 신호를 로우패스 필터에 통과시켜 아날로그 전압을 만드는 방법에서 출력 전압을 결정하는 것은 무엇인가?
