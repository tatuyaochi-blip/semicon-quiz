신뢰성

온도를 올려 수명 시험 시간을 단축하는 가속 시험에서, 온도와 수명의 관계를 나타내기 위해 자주 사용되는 모델은?

  1. A무어의 법칙
  2. B아레니우스 모델
  3. C옴의 법칙
정답과 해설 보기

정답: B. 아레니우스 모델

아레니우스 모델은 열화 반응 속도가 exp(−Ea/kT)(Ea: 활성화 에너지, k: 볼츠만 상수, T: 절대 온도)에 비례한다는 사고방식으로, 온도를 올리면 수명이 지수 함수적으로 짧아짐을 나타냅니다. 고온에서 시험한 결과로부터 실제 사용 온도에서의 수명을 추정하는 데 사용됩니다. Ea는 고장 메커니즘마다 다르며 0.5~1 eV 정도의 값이 자주 사용됩니다. 무어의 법칙이나 옴의 법칙은 수명과 관계가 없습니다.
