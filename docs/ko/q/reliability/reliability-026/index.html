정답과 해설 보기

정답: A. 고장을 가속시켜 짧은 시간에 수명을 추정하기 위해

실제 사용 전압에서는 TDDB에 의한 고장이 일어나기까지 몇 년이 걸립니다. 높은 전압과 높은 온도를 가하면 고장이 수 시간~수 주 만에 일어나므로, 그 결과와 전압 의존성 모델을 사용하여 실제 사용 조건에서의 수명을 추정합니다. 외삽 거리가 길기 때문에 모델 선택에 따라 예측이 몇 자릿수나 달라질 수 있어 적절한 가속 모델의 선택이 중요합니다. 사용 전압에서 망가지지 않음을 직접 확인하는 것은 시간적으로 불가능합니다.
