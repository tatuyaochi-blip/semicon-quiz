신뢰성

고장률 λ가 일정할 때 시간 t까지 고장 나지 않을 확률(신뢰도) R(t)를 나타내는 식은?

  1. Aλt
  2. B1 / (λt)
  3. Cexp(−λt)
정답과 해설 보기

정답: C. exp(−λt)

고장률이 일정한 우발 고장기에서는 고장까지의 시간이 지수 분포를 따르며, 신뢰도는 R(t)=exp(−λt)로 나타냅니다. 이때 평균 고장 시간(MTTF)은 1/λ이고, t=MTTF에서의 신뢰도는 exp(−1)≈37%에 불과합니다. 즉 평균 고장 시간까지 사용하면 6할 이상이 고장 납니다. λt는 λt가 작을 때 고장 날 확률의 근사이고, 1/(λt)는 의미 있는 식이 아닙니다.
