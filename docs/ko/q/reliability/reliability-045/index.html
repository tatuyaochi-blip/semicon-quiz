신뢰성

고온 고습 시험 결과로부터 실사용 수명을 추정할 때, 습도의 영향을 상대 습도의 거듭제곱으로 나타내는 모델로 자주 사용되는 것은?

  1. A펙의 모델
  2. B데나드 스케일링 법칙
  3. C쇼클리의 식
정답과 해설 보기

정답: A. 펙의 모델

펙의 모델은 수명이 상대 습도 RH의 거듭제곱(RH^(−n), n은 대략 3 정도)과 아레니우스형 온도 항의 곱으로 결정된다는 모델입니다. 85 ℃/85%RH나 HAST 등 가속 시험 결과를 실제 온도·습도 환경에서의 수명으로 환산하는 데 사용됩니다. 예를 들어 n=3이면 습도가 85%에서 40%로 내려가는 것만으로 수명은 약 10배가 됩니다. 데나드의 법칙과 쇼클리의 식은 다른 분야의 식입니다.

  2. 플립칩의 솔더 범프에서 큰 전류로 인해 일렉트로마이그레이션이 문제가 될 때, 특히 고장이 일어나기 쉬운 곳으로 알려진 곳은?

  4. 우주선 중성자에 의한 소프트 에러 발생 용이성을 평가하기 위해, 실제 환경보다 훨씬 강한 중성자를 쪼여 단시간에 측정하는 방법으로 올바른 것은?
