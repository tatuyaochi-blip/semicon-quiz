신뢰성

차량용 집적 회로의 신뢰성 시험 기준으로 널리 사용되는 규격은?

  1. AAEC-Q100
  2. BISO 14001
  3. CISO 9001
정답과 해설 보기

정답: A. AEC-Q100

AEC-Q100은 자동차 전자 부품 업계 단체인 AEC(Automotive Electronics Council)가 정한 차량용 IC의 신뢰성 시험 기준입니다. 고온 동작 수명, 온도 사이클, 고온 고습, ESD, 래치업 등의 시험 항목과 조건, 동작 온도 등급이 정해져 있으며, 차량용 반도체는 이에 준거한 시험을 하는 것이 일반적입니다. ISO 14001은 환경 경영, ISO 9001은 품질 경영 규격입니다.

신뢰성의 다른 문제

  1. 고장률 λ가 일정할 때, 시간 t까지 고장 나지 않을 확률(신뢰도) R(t)를 나타내는 식은?
  2. 고장률이 일정하고 1×10⁻⁵ /시간인 부품의 평균 고장 시간(MTTF)은 얼마인가?
  3. 신뢰도 0.9인 부품 2개를 병렬로 접속하고, 어느 한쪽이 동작하면 기능하는 시스템의 신뢰도는 얼마인가?
  4. 신뢰도 0.9인 부품 2개를 직렬로 접속하고, 둘 다 동작해야 기능하는 시스템의 신뢰도는 얼마인가?
  5. TDDB 수명 평가에서 실제 사용 전압보다 높은 전압을 가하여 시험하는 이유로 올바른 것은?
