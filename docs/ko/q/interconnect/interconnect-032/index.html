배선 공정

LSI의 '다층 배선'에 대한 설명으로 올바른 것은?

  1. A배선을 1층만 평면에 늘어놓은 것
  2. B절연막을 사이에 두고 배선층을 여러 층 쌓고 층 사이를 비아로 연결한 것
  3. C배선 없이 무선으로 신호를 보내는 것
정답과 해설 보기

정답: B. 절연막을 사이에 두고 배선층을 여러 층 쌓고 층 사이를 비아로 연결한 것

다층 배선에서는 배선층과 절연막을 번갈아 쌓고 상하 층의 배선을 비아로 연결합니다. 평면만으로는 배선할 수 없는 다수의 접속을 입체적으로 배치할 수 있으며, 일반적으로 층마다 배선 방향을 세로·가로로 번갈아 바꾸어 혼잡을 줄입니다. 1960년대의 집적 회로는 배선이 1층이었지만, CMP에 의한 평탄화 도입으로 층을 쌓기 쉬워져 현재 첨단 로직에서는 15층 전후가 되었습니다.
