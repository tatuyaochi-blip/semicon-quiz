시스템 구성과 신뢰성 설계

집중 처리와 비교한 분산 처리의 특징으로 적절한 것은?

  1. A전체의 운영 관리나 보안 관리를 1곳에서 수행할 수 있으므로 관리가 쉬워진다
  2. B컴퓨터 간의 통신이 필요 없어지므로 네트워크 장애의 영향을 받지 않는다
  3. C처리를 여러 컴퓨터로 나누므로 1대의 장애가 미치는 영향을 국소화하기 쉽고 대수를 늘려 처리 능력을 높이기 쉽지만, 운영 관리나 데이터 일관성의 확보는 복잡해진다

정답: C. 처리를 여러 컴퓨터로 나누므로 1대의 장애가 미치는 영향을 국소화하기 쉽고 대수를 늘려 처리 능력을 높이기 쉽지만, 운영 관리나 데이터 일관성의 확보는 복잡해진다

분산 처리는 처리를 여러 컴퓨터로 나누어 수행하는 방식입니다. 1대가 고장 나도 영향을 일부에 그치게 하기 쉽고, 부하에 따라 컴퓨터를 추가하기 쉬운 이점이 있습니다. 한편 컴퓨터 간의 통신이 필요해지고, 기기 관리, 보안 대책, 데이터 일관성의 확보가 복잡해집니다. 관리를 1곳에서 수행하기 쉬운 것은 1대의 컴퓨터로 처리하는 집중 처리의 이점입니다.

시스템 구성과 신뢰성 설계의 다른 문제

  1. 일괄 처리(배치 처리)로 수행하기에 적합한 처리는?
  2. 온라인 처리 시스템의 성능을 평가하는 지표 중 응답 시간(response time)에 대한 설명으로 적절한 것은?
  3. 이용자의 요청을 웹 서버 계층, 애플리케이션 서버 계층, 데이터베이스 서버 계층의 순서로 처리하는 시스템이 있다. 각 요청은 3개 계층을 각각 1번씩 통과하며, 각 계층이 처리할 수 있는 최대 건수는 웹 서버 계층이 초당 1,200건, 애플리케이션 서버 계층이 초당 1,000건, 데이터베이스 서버 계층이 초당 900건이다. 데이터베이스 서버 계층을 증강하여 초당 1,500건을 처리할 수 있게 했을 때, 시스템 전체에서 처리할 수 있는 최대 건수로 올바른 것은?
  4. 듀얼 시스템에 대한 설명으로 적절한 것은?
  5. 반도체 공장의 제조 실행 시스템(MES) 서버를 주 시스템(운용계)과 대기 시스템으로 이루어진 듀플렉스 시스템으로 구성한다. 대기 시스템을 핫 스탠바이로 했을 때의 특징으로 적절한 것은?
