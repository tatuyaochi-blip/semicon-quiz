시스템 구성과 신뢰성 설계

시스템의 처리 능력을 높이는 방법 중 스케일 아웃에 해당하는 것은?

  1. A같은 구성의 서버 대수를 늘리고, 로드 밸런서로 처리를 분배한다
  2. B서버의 CPU를 더 고성능인 것으로 교체하고 메모리를 늘린다
  3. C서버 대수를 줄여 1대당 사용률을 높인다
정답과 해설 보기

정답: A. 같은 구성의 서버 대수를 늘리고, 로드 밸런서로 처리를 분배한다

스케일 아웃은 서버 대수를 늘려 처리를 나누어 맡고, 시스템 전체의 처리 능력을 높이는 방법입니다. 대수를 늘리기만 하면 능력을 더하기 쉽고, 1대가 고장 나도 나머지로 처리를 계속할 수 있지만, 처리를 나눌 수 있도록 시스템을 설계해 두어야 합니다. 1대의 서버 부품을 더 고성능으로 하는 것은 스케일 업으로, 구성은 간단하지만 1대로 실현할 수 있는 성능에는 한계가 있습니다. 대수를 줄이는 것은 스케일 인이라고 부릅니다.
