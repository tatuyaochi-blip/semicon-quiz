시스템 구성과 신뢰성 설계

가동률 0.95인 서버를 3대 준비하고, 그중 2대 이상이 동작하고 있으면 필요한 처리 능력을 확보할 수 있는 시스템이 있다. 서버는 서로 독립적으로 고장 나며, 서버 이외의 기기 고장은 고려하지 않는다. 이 시스템의 가동률로 올바른 것은?

  1. A0.9025
  2. B0.99275
  3. C0.999875
정답과 해설 보기

정답: B. 0.99275

3대 중 2대 이상이 동작하고 있을 확률을 더합니다. 정확히 2대가 동작하고 있을 확률은 3 × 0.95² × 0.05 = 0.135375, 3대 모두 동작하고 있을 확률은 0.95³ = 0.857375이므로, 가동률은 0.135375 + 0.857375 = 0.99275입니다. 0.9025는 필요한 2대를 직렬로 연결한 값으로, 예비 1대의 효과가 들어 있지 않습니다. 0.999875는 3대 중 1대라도 동작하면 되는 병렬의 경우의 값입니다.
