시스템 구성과 신뢰성 설계

온라인 처리 시스템의 성능을 평가하는 지표 중 응답 시간(response time)에 대한 설명으로 적절한 것은?

  1. A이용자가 처리 요청의 입력을 마친 후부터 시스템이 결과 출력을 시작할 때까지의 시간
  2. B처리 요청을 내기 시작한 후부터 결과 출력이 모두 끝날 때까지의 시간
  3. C시스템이 단위 시간당 처리할 수 있는 작업의 양
정답과 해설 보기

정답: A. 이용자가 처리 요청의 입력을 마친 후부터 시스템이 결과 출력을 시작할 때까지의 시간

응답 시간은 이용자가 단말에서 처리 요청을 다 입력한 후부터 시스템이 결과 출력을 시작할 때까지의 시간입니다. 이용자가 화면 앞에서 기다리는 온라인 처리에서는 특히 중시됩니다. 작업(job)을 투입한 후부터 결과가 모두 출력될 때까지의 시간은 반환 시간(턴어라운드 타임)이라고 부르며, 주로 일괄 처리의 평가에 사용합니다. 단위 시간당 작업의 양은 처리량(스루풋)입니다.

시스템 구성과 신뢰성 설계의 다른 문제

  1. 이용자의 요청을 웹 서버 계층, 애플리케이션 서버 계층, 데이터베이스 서버 계층의 순서로 처리하는 시스템이 있다. 각 요청은 3개 계층을 각각 1번씩 통과하며, 각 계층이 처리할 수 있는 최대 건수는 웹 서버 계층이 초당 1,200건, 애플리케이션 서버 계층이 초당 1,000건, 데이터베이스 서버 계층이 초당 900건이다. 데이터베이스 서버 계층을 증강하여 초당 1,500건을 처리할 수 있게 했을 때, 시스템 전체에서 처리할 수 있는 최대 건수로 올바른 것은?
  2. 듀얼 시스템에 대한 설명으로 적절한 것은?
  3. 반도체 공장의 제조 실행 시스템(MES) 서버를 주 시스템(운용계)과 대기 시스템으로 이루어진 듀플렉스 시스템으로 구성한다. 대기 시스템을 핫 스탠바이로 했을 때의 특징으로 적절한 것은?
  4. 2대의 로드 밸런서(부하 분산 장치)를 이중화하고, 그 아래에 웹 서버를 3대 두며, 모든 웹 서버가 1대의 데이터베이스 서버를 사용하는 시스템이 있다. 여기에 든 기기 중 단일 장애점(그곳이 멈추면 시스템 전체가 멈추는 곳)이 되는 것은?
  5. 5대의 서버가 처리를 균등하게 나누어 맡는 액티브/액티브 구성의 클러스터가 있다. 사용률은 처리의 양에 비례한다고 한다. 1대가 고장 났을 때 나머지 4대가 처리를 균등하게 인계하더라도 각 서버의 사용률을 80% 이하로 유지하고 싶다. 평상시(5대 모두 동작 중) 각 서버의 사용률 상한으로 올바른 것은?
