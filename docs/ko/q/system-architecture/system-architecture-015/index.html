시스템 구성과 신뢰성 설계

반도체 제조 장비에서 공기압으로 열리는 상시 닫힘(노멀 클로즈)형 가스 공급 밸브를 사용하여, 정전이나 압축 공기 상실이 일어났을 때는 밸브가 닫혀 위험한 가스의 공급이 멈추도록 하고 있다. 이 설계의 개념은?

  1. A페일 세이프
  2. B페일 소프트
  3. C풀 프루프
정답과 해설 보기

정답: A. 페일 세이프

고장이나 이상이 일어났을 때 시스템이 안전한 쪽의 상태가 되도록 설계하는 개념을 페일 세이프라고 합니다. 상시 닫힘형 밸브는 열기 위한 공기압이나 전력이 사라지면 스프링의 힘으로 닫히므로, 전원이나 공기에 이상이 생겼을 때는 가스가 멈추는 안전한 상태가 됩니다. 고장 나도 기능을 낮추어 계속 동작하는 것은 페일 소프트, 사람의 잘못된 조작을 막는 것은 풀 프루프입니다.
