시스템 구성과 신뢰성 설계

씬 클라이언트에 대한 설명으로 적절한 것은?

  1. A이용자의 단말에 고성능 CPU와 대용량 기억 장치를 갖추어, 네트워크에 연결되어 있지 않아도 단독으로 처리할 수 있게 하는 방식
  2. B단말의 기능을 최소한으로 하는 대신, 네트워크가 끊겨도 단말만으로 업무를 계속할 수 있게 하는 방식
  3. C이용자의 단말에는 입출력 등 최소한의 기능만 갖추고, 애플리케이션의 실행과 데이터의 저장은 서버 쪽에서 수행하는 방식
정답과 해설 보기

정답: C. 이용자의 단말에는 입출력 등 최소한의 기능만 갖추고, 애플리케이션의 실행과 데이터의 저장은 서버 쪽에서 수행하는 방식

씬 클라이언트는 단말에 입력과 화면 표시 등 최소한의 기능만 갖추고, 애플리케이션의 실행과 데이터의 저장을 서버 쪽에서 수행하는 방식입니다. 단말에 데이터가 남지 않으므로 단말의 분실이나 도난에 의한 정보 유출을 막기 쉽고, 소프트웨어 업데이트도 서버 쪽에서 한꺼번에 수행할 수 있습니다. 그 대신 네트워크나 서버가 멈추면 단말에서는 업무를 계속할 수 없습니다. 단말만으로 많은 처리를 수행하는 방식은 팻 클라이언트(리치 클라이언트)라고 부릅니다.

시스템 구성과 신뢰성 설계의 다른 문제

  2. 집중 처리와 비교한 분산 처리의 특징으로 적절한 것은?
  3. 일괄 처리(배치 처리)로 수행하기에 적합한 처리는?
  4. 온라인 처리 시스템의 성능을 평가하는 지표 중 응답 시간(response time)에 대한 설명으로 적절한 것은?
  5. 이용자의 요청을 웹 서버 계층, 애플리케이션 서버 계층, 데이터베이스 서버 계층의 순서로 처리하는 시스템이 있다. 각 요청은 3개 계층을 각각 1번씩 통과하며, 각 계층이 처리할 수 있는 최대 건수는 웹 서버 계층이 초당 1,200건, 애플리케이션 서버 계층이 초당 1,000건, 데이터베이스 서버 계층이 초당 900건이다. 데이터베이스 서버 계층을 증강하여 초당 1,500건을 처리할 수 있게 했을 때, 시스템 전체에서 처리할 수 있는 최대 건수로 올바른 것은?
