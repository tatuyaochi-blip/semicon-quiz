일괄 처리(배치 처리)로 수행하기에 적합한 처리는?

  1. A은행 ATM에서 이용자가 예금을 인출하는 처리
  2. B하루 치 제조 장비의 로그를 야간에 한꺼번에 집계하여 수율 등의 일일 보고서를 만드는 처리
  3. C열차 좌석을 예약하고 그 자리에서 좌석을 확보하는 처리
정답과 해설 보기

정답: B. 하루 치 제조 장비의 로그를 야간에 한꺼번에 집계하여 수율 등의 일일 보고서를 만드는 처리

일괄 처리는 일정 기간이나 일정량의 데이터를 모아 두었다가 한꺼번에 처리하는 방식입니다. 하루 치 로그의 집계나 월말 급여 계산처럼 바로 결과를 돌려줄 필요가 없고, 대량의 데이터를 효율적으로 처리하고 싶은 작업에 적합합니다. ATM에서의 인출이나 좌석 예약처럼 요청이 올 때마다 즉시 처리하여 결과를 돌려주어야 하는 작업은 온라인 실시간 처리로 수행합니다.

시스템 구성과 신뢰성 설계의 다른 문제

  1. 온라인 처리 시스템의 성능을 평가하는 지표 중 응답 시간(response time)에 대한 설명으로 적절한 것은?
  2. 이용자의 요청을 웹 서버 계층, 애플리케이션 서버 계층, 데이터베이스 서버 계층의 순서로 처리하는 시스템이 있다. 각 요청은 3개 계층을 각각 1번씩 통과하며, 각 계층이 처리할 수 있는 최대 건수는 웹 서버 계층이 초당 1,200건, 애플리케이션 서버 계층이 초당 1,000건, 데이터베이스 서버 계층이 초당 900건이다. 데이터베이스 서버 계층을 증강하여 초당 1,500건을 처리할 수 있게 했을 때, 시스템 전체에서 처리할 수 있는 최대 건수로 올바른 것은?
  3. 듀얼 시스템에 대한 설명으로 적절한 것은?
  4. 반도체 공장의 제조 실행 시스템(MES) 서버를 주 시스템(운용계)과 대기 시스템으로 이루어진 듀플렉스 시스템으로 구성한다. 대기 시스템을 핫 스탠바이로 했을 때의 특징으로 적절한 것은?
  5. 2대의 로드 밸런서(부하 분산 장치)를 이중화하고, 그 아래에 웹 서버를 3대 두며, 모든 웹 서버가 1대의 데이터베이스 서버를 사용하는 시스템이 있다. 여기에 든 기기 중 단일 장애점(그곳이 멈추면 시스템 전체가 멈추는 곳)이 되는 것은?
