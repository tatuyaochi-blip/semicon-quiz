시스템 구성과 신뢰성 설계

1대당 초당 200회의 랜덤 입출력(IOPS)이 가능한 디스크 4대로 RAID5를 구성했다. 작은 데이터의 랜덤 쓰기를 1회 수행할 때마다 이전 데이터와 이전 패리티의 읽기, 새 데이터와 새 패리티의 쓰기를 합쳐 4회의 입출력이 필요하다고 하고, 캐시의 효과는 고려하지 않는다. 쓰기만 수행할 때 RAID5 전체에서 처리할 수 있는 쓰기 횟수로 올바른 것은?

  1. A초당 200회
  2. B초당 400회
  3. C초당 800회
정답과 해설 보기

정답: A. 초당 200회

디스크 4대 전체에서 처리할 수 있는 입출력은 4 × 200 = 초당 800회입니다. RAID5에서는 1회의 쓰기에 4회의 입출력이 필요하므로 쓰기 횟수는 800 ÷ 4 = 초당 200회가 됩니다. 이처럼 쓰기 1회에 필요한 입출력 횟수가 늘어나는 것을 '쓰기 페널티'라고 부르며, 미러링인 RAID10에서는 2회이므로 초당 400회가 됩니다. 쓰기가 많은 용도에서는 용량 효율뿐만 아니라 이 성능 차이도 고려하여 RAID 레벨을 선택합니다.
