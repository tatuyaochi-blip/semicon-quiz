클라우드 서비스의 IaaS에서 일반적으로 이용자가 직접 관리하는 것은?

  1. A데이터 센터 건물과 전원·공조 설비
  2. B서버나 스토리지 등의 물리적인 기기와 가상화 기반
  3. C가상 머신 위에서 동작하는 OS, 미들웨어, 애플리케이션
정답과 해설 보기

정답: C. 가상 머신 위에서 동작하는 OS, 미들웨어, 애플리케이션

IaaS(Infrastructure as a Service)에서는 사업자가 건물과 설비, 물리적인 기기, 가상화 기반을 관리하고, 이용자는 가상 머신 위의 OS부터 위쪽을 직접 관리합니다. PaaS에서는 OS나 미들웨어까지를 사업자가 관리하고 이용자는 애플리케이션과 데이터를, SaaS에서는 애플리케이션까지를 사업자가 관리하고 이용자는 데이터나 이용 설정을 관리합니다. 이처럼 서비스 형태에 따라 사업자와 이용자가 책임을 나누어 맡는 범위가 달라집니다.
