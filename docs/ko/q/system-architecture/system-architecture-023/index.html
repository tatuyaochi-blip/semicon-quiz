차등 백업에 대한 설명으로 적절한 것은?

  1. A직전의 백업(전체 백업인지 증분 백업인지는 묻지 않는다) 이후에 변경된 데이터만 백업한다
  2. B변경 여부와 관계없이 모든 데이터를 백업한다
  3. C직전의 전체 백업 이후에 변경된 데이터를 모두 백업한다
정답과 해설 보기

정답: C. 직전의 전체 백업 이후에 변경된 데이터를 모두 백업한다

차등 백업은 직전의 전체 백업 이후에 변경된 데이터를 모두 백업하는 방법입니다. 전체 백업으로부터 날짜가 지날수록 1회의 양은 늘어나지만, 복원할 때는 전체 백업과 최신 차등 백업 2개만으로 충분합니다. 직전의 백업 이후의 변경만 받는 것은 증분 백업으로, 1회의 양은 적은 대신 복원에는 전체 백업과 그 후의 모든 증분 백업이 필요합니다.

시스템 구성과 신뢰성 설계의 다른 문제

  1. 매주 일요일 밤에 전체 백업을 받고, 월요일부터 토요일까지는 매일 밤 증분 백업을 받고 있다. 목요일 낮에 장애가 일어나, 수요일 밤의 백업 시점까지 데이터를 되돌리기로 했다. 복원에 사용하는 백업의 개수로 올바른 것은?
  2. 데이터 전체가 500 GB인 시스템에서 매주 일요일에 전체 백업을 받고, 월요일부터 토요일까지는 매일 밤 차등 백업을 받는다. 매일 그때까지 변경되지 않았던 다른 데이터가 20 GB씩 변경된다고 한다. 월요일부터 토요일까지 6회의 차등 백업 용량의 합계로 올바른 것은?
  3. 사업 연속성 계획에서 말하는 RPO(목표 복구 시점)에 대한 설명으로 적절한 것은?
  4. 어떤 시스템에서 RPO(목표 복구 시점)를 4시간, RTO(목표 복구 시간)를 2시간으로 정했다. 장애는 언제든 일어날 수 있다고 하고, 백업 취득에 걸리는 시간은 무시할 수 있다고 한다. 이 목표를 만족하는 데이터 보호 방식으로 적절한 것은?
  5. 1,000 km 떨어진 2곳의 데이터 센터 사이에서 데이터베이스 갱신을 동기 레플리케이션한다. 갱신할 때마다 다른 쪽으로의 전송과 쓰기 완료 통지의 1왕복 통신을 기다린다고 한다. 광섬유 안의 빛의 속도를 약 200,000 km/s로 하고, 광섬유 경로의 길이는 직선거리와 같다고 볼 때, 통신의 전파만으로 1회 갱신의 응답 시간이 늘어나는 양에 가장 가까운 것은?
