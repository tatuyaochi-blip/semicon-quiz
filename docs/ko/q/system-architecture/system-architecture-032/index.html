가상화 환경에서의 라이브 마이그레이션에 대한 설명으로 적절한 것은?

  1. A동작 중인 가상 머신을, 이용자가 보기에 중단을 아주 짧게 하여 다른 물리 서버로 옮긴다
  2. B가상 머신을 정지하고 디스크 이미지를 복사하여 다른 물리 서버에서 다시 기동한다
  3. C물리 서버에서 동작하고 있는 OS와 애플리케이션을 가상 머신으로 다시 만들어 옮긴다
정답과 해설 보기

정답: A. 동작 중인 가상 머신을, 이용자가 보기에 중단을 아주 짧게 하여 다른 물리 서버로 옮긴다

라이브 마이그레이션은 동작 중인 가상 머신의 메모리 내용을 동작시킨 채로 이동 대상 물리 서버에 반복하여 복사하고, 마지막에 아주 짧은 시간만 멈추어 남은 내용과 CPU 상태를 옮김으로써 가상 머신을 다른 물리 서버로 옮기는 구조입니다. 물리 서버의 보수나 부하 편중 해소 때 서비스를 거의 멈추지 않고 끝낼 수 있습니다. 일반적으로 이동 원본과 이동 대상이 같은 스토리지를 공유하고 있거나 스토리지 내용도 함께 옮겨야 하며, CPU 기능의 호환성도 요구됩니다.

  3. 스토리지 접속 방식 중 SAN(스토리지 영역 네트워크)에 대한 설명으로 적절한 것은?
  4. 물리 용량이 100 TB인 스토리지 풀에서 씬 프로비저닝으로 논리 용량 5 TB의 볼륨을 30개 만들었다. 현재 각 볼륨에는 평균하여 논리 용량의 40%의 데이터가 기록되어 있고, 데이터는 매주 합계 2 TB씩 늘고 있다. 데이터의 삭제나 압축은 고려하지 않을 때, 풀의 사용률이 80%에 도달하는 시기로 올바른 것은?
  5. IT 기기의 소비 전력이 800 kW, 냉각 설비의 소비 전력이 280 kW, 전원 설비의 손실과 조명 등이 120 kW인 데이터 센터가 있다. 냉각 방식을 개선하여 냉각 설비의 소비 전력만 절반으로 했을 때, PUE로 올바른 것은?
