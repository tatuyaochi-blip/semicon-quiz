논리 회로

NOT 게이트(인버터)의 기능으로 올바른 것은?

  1. A두 입력의 합을 출력한다
  2. B입력을 그대로 출력한다
  3. C입력의 0과 1을 반전하여 출력한다
정답과 해설 보기

정답: C. 입력의 0과 1을 반전하여 출력한다

NOT 게이트는 입력을 반전하여 0이면 1, 1이면 0을 출력합니다. CMOS에서는 nMOS와 pMOS를 1개씩 조합한 인버터이며 논리 회로의 가장 기본적인 구성 요소입니다. 논리 반전뿐 아니라 약해진 신호의 파형을 정돈하고 증폭하는 버퍼(2단으로 비반전)로도 사용되며, 홀수 개를 고리로 연결하면 링 오실레이터가 되어 공정의 속도 평가에 사용됩니다.

논리 회로의 다른 문제

  1. 10진수 13을 2진수로 나타낸 것은?
  2. 3입력 논리 회로의 진리표는 몇 행입니까?
  3. 1바이트는 몇 비트입니까?
  4. 16진수 1A를 10진수로 나타내면 얼마입니까?
  5. JK 플립플롭에서 J = 1, K = 1일 때 클록이 들어왔을 때의 동작은?

이 분야의 비교

  • 래치 vs 플립플롭: 차이점 설명래치와 플립플롭을 표로 비교합니다: 트리거 방식, 출력 동작, 구성, 크기, 타이밍 분석, 글리치, 디지털 설계에서의 활용 시점.
  • 조합 논리 vs 순차 논리: 차이점 설명조합 논리와 순차 논리를 표로 비교합니다: 출력이 의존하는 것, 기억 소자, 클럭, 피드백, 예시, 타이밍, HDL 작성 방식.
  • CMOS vs TTL 로직: 차이점 설명CMOS와 TTL 로직을 표로 비교합니다: 트랜지스터, 정적 전력, 공급 전압, 논리 레벨, 잡음 여유, 속도, 입력, 주요 사용처.
