논리 회로

시프트 레지스터의 일부 출력의 XOR를 입력으로 되돌리는 선형 피드백 시프트 레지스터(LFSR)의 대표적인 용도는?

  1. A의사 난수 패턴 생성이나 테스트에서의 패턴 생성·CRC 계산
  2. B정확한 시각 측정
  3. C아날로그 신호 증폭
정답과 해설 보기

정답: A. 의사 난수 패턴 생성이나 테스트에서의 패턴 생성·CRC 계산

LFSR은 적절한 탭을 선택하면 n비트에서 모두 0을 제외한 2ⁿ − 1가지 상태를 순환하는, 얼핏 무작위로 보이는 계열(M 계열)을 생성합니다. XOR와 플립플롭만으로 만들 수 있으므로 내장 테스트(BIST)의 패턴 생성과 결과 압축, 이더넷 등의 CRC 계산, 신호를 평균화하여 전자기 노이즈를 줄이는 스크램블러에 사용됩니다. 계열은 예측 가능하므로 암호용 난수로는 사용할 수 없습니다.

관련 계산 도구

셋업·홀드 타이밍 계산기플립플롭 간 경로의 셋업·홀드 슬랙과 최대 클럭 주파수CMOS 소비 전력 (동적·정적)활동률, 용량, 전압, 주파수, 누설 전류로 동적·정적 소비 전력과 DVFS 적용 후 전력 계산

논리 회로의 다른 문제

  1. 오픈 드레인 출력 회로를 여러 개, 풀업 저항이 있는 하나의 신호선에 연결했을 때의 동작으로 올바른 것은?
  2. 2입력 NAND 게이트의 출력이 0이 되는 것은 언제입니까?
  3. 드모르간의 정리에 따르면 NOT(A AND B)와 같은 논리식은?
  4. D형 플립플롭의 동작으로 올바른 것은?
  5. 2입력 XOR(배타적 논리합) 게이트의 출력이 1이 되는 것은 언제입니까?

이 분야의 비교

  • 래치 vs 플립플롭: 차이점 설명래치와 플립플롭을 표로 비교합니다: 트리거 방식, 출력 동작, 구성, 크기, 타이밍 분석, 글리치, 디지털 설계에서의 활용 시점.
  • 조합 논리 vs 순차 논리: 차이점 설명조합 논리와 순차 논리를 표로 비교합니다: 출력이 의존하는 것, 기억 소자, 클럭, 피드백, 예시, 타이밍, HDL 작성 방식.
  • CMOS vs TTL 로직: 차이점 설명CMOS와 TTL 로직을 표로 비교합니다: 트랜지스터, 정적 전력, 공급 전압, 논리 레벨, 잡음 여유, 속도, 입력, 주요 사용처.
