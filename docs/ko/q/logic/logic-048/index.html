논리 회로

n개의 플립플롭으로 구성한 존슨 카운터(트위스트 링 카운터)가 취하는 상태의 수는 몇 개입니까?

  1. An
  2. B2n
  3. C2ⁿ
정답과 해설 보기

정답: B. 2n

존슨 카운터는 시프트 레지스터의 마지막 출력을 반전하여 처음으로 되돌리는 구성으로, n개의 플립플롭으로 2n개의 상태를 차례로 취합니다(3개라면 000→100→110→111→011→001). 이웃한 상태에서 1비트만 바뀌므로 2입력 게이트만으로 각 상태를 디코드할 수 있고 글리치도 일어나기 어려운 특징이 있습니다. 위상이 조금씩 어긋난 여러 클록을 만드는 용도로도 사용됩니다.

논리 회로의 다른 문제

  1. 시프트 레지스터의 일부 출력의 XOR를 입력으로 되돌리는 선형 피드백 시프트 레지스터(LFSR)의 대표적인 용도는?
  2. 오픈 드레인 출력 회로를 여러 개, 풀업 저항이 있는 하나의 신호선에 연결했을 때의 동작으로 올바른 것은?
  3. 2입력 NAND 게이트의 출력이 0이 되는 것은 언제입니까?
  4. 드모르간의 정리에 따르면 NOT(A AND B)와 같은 논리식은?
  5. D형 플립플롭의 동작으로 올바른 것은?

이 분야의 비교

  • 래치 vs 플립플롭: 차이점 설명래치와 플립플롭을 표로 비교합니다: 트리거 방식, 출력 동작, 구성, 크기, 타이밍 분석, 글리치, 디지털 설계에서의 활용 시점.
  • 조합 논리 vs 순차 논리: 차이점 설명조합 논리와 순차 논리를 표로 비교합니다: 출력이 의존하는 것, 기억 소자, 클럭, 피드백, 예시, 타이밍, HDL 작성 방식.
  • CMOS vs TTL 로직: 차이점 설명CMOS와 TTL 로직을 표로 비교합니다: 트랜지스터, 정적 전력, 공급 전압, 논리 레벨, 잡음 여유, 속도, 입력, 주요 사용처.
