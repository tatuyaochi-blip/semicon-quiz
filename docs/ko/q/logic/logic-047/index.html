논리 회로

2의 보수 표현 수끼리의 덧셈에서 오버플로(자리 넘침)가 발생했음을 판정하는 조건으로 올바른 것은?

  1. A최상위 비트로의 올림수와 최상위 비트에서의 올림수가 다를 때
  2. B결과가 0이 되었을 때
  3. C최하위 비트의 합이 1이 되었을 때
정답과 해설 보기

정답: A. 최상위 비트로의 올림수와 최상위 비트에서의 올림수가 다를 때

2의 보수 덧셈에서는 양수끼리 더해 음수가 되거나 음수끼리 더해 양수가 되었을 때가 오버플로이며, 최상위 비트로의 올림수와 최상위 비트에서의 올림수가 다른 것(둘의 XOR가 1)으로 판정할 수 있습니다. 예를 들어 4비트에서 0111(7) + 0001(1) = 1000(−8)입니다. 부호가 다른 수끼리의 덧셈에서는 오버플로가 일어나지 않습니다. CPU는 이를 V 플래그, 부호 없는 자리 넘침을 C 플래그로 구분합니다.

논리 회로의 다른 문제

  1. n개의 플립플롭으로 구성한 존슨 카운터(트위스트 링 카운터)가 취하는 상태의 수는 몇 개입니까?
  2. 시프트 레지스터의 일부 출력의 XOR를 입력으로 되돌리는 선형 피드백 시프트 레지스터(LFSR)의 대표적인 용도는?
  3. 오픈 드레인 출력 회로를 여러 개, 풀업 저항이 있는 하나의 신호선에 연결했을 때의 동작으로 올바른 것은?
  4. 2입력 NAND 게이트의 출력이 0이 되는 것은 언제입니까?
  5. 드모르간의 정리에 따르면 NOT(A AND B)와 같은 논리식은?

이 분야의 비교

  • 래치 vs 플립플롭: 차이점 설명래치와 플립플롭을 표로 비교합니다: 트리거 방식, 출력 동작, 구성, 크기, 타이밍 분석, 글리치, 디지털 설계에서의 활용 시점.
  • 조합 논리 vs 순차 논리: 차이점 설명조합 논리와 순차 논리를 표로 비교합니다: 출력이 의존하는 것, 기억 소자, 클럭, 피드백, 예시, 타이밍, HDL 작성 방식.
  • CMOS vs TTL 로직: 차이점 설명CMOS와 TTL 로직을 표로 비교합니다: 트랜지스터, 정적 전력, 공급 전압, 논리 레벨, 잡음 여유, 속도, 입력, 주요 사용처.
