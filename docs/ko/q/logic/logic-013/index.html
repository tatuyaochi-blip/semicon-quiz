논리 회로

플립플롭의 셋업 시간에 대한 설명으로 올바른 것은?

  1. A클록 에지 이후에 데이터를 계속 유지해야 하는 최소 시간
  2. B클록 에지 이전에 데이터 입력이 안정되어 있어야 하는 최소 시간
  3. C전원을 켠 후 동작하기까지의 시간
정답과 해설 보기

정답: B. 클록 에지 이전에 데이터 입력이 안정되어 있어야 하는 최소 시간

플립플롭이 올바르게 받아들이려면 클록 에지보다 일정 시간 전부터 데이터가 안정되어 있어야 하며, 이것이 셋업 시간입니다. 데이터 경로의 지연이 클록 주기에서 셋업 시간을 뺀 값을 넘으면 위반이 되며, 클록을 느리게 하면 해소할 수 있습니다. 에지 이후 데이터를 유지해야 하는 시간은 홀드 시간이며, 둘 중 하나라도 만족하지 못하면 잘못된 값의 취득이나 메타스터빌리티의 원인이 됩니다.

관련 계산 도구

셋업·홀드 타이밍 계산기플립플롭 간 경로의 셋업·홀드 슬랙과 최대 클럭 주파수CMOS 소비 전력 (동적·정적)활동률, 용량, 전압, 주파수, 누설 전류로 동적·정적 소비 전력과 DVFS 적용 후 전력 계산

논리 회로의 다른 문제

  1. 4비트 바이너리 카운터가 나타낼 수 있는 상태의 수는 몇 개입니까?
  2. 그레이 코드의 특징으로 올바른 것은?
  3. D 래치의 동작에 대한 설명으로 올바른 것은?
  4. 비동기 신호를 플립플롭으로 받았을 때 셋업 시간이나 홀드 시간을 만족하지 못해 출력이 일시적으로 0도 1도 아닌 불확정 상태가 되는 것을 무엇이라고 합니까?
  5. 출력이 현재 상태만으로 결정되는 순차 회로(스테이트 머신)의 유형은?

이 분야의 비교

  • 래치 vs 플립플롭: 차이점 설명래치와 플립플롭을 표로 비교합니다: 트리거 방식, 출력 동작, 구성, 크기, 타이밍 분석, 글리치, 디지털 설계에서의 활용 시점.
  • 조합 논리 vs 순차 논리: 차이점 설명조합 논리와 순차 논리를 표로 비교합니다: 출력이 의존하는 것, 기억 소자, 클럭, 피드백, 예시, 타이밍, HDL 작성 방식.
  • CMOS vs TTL 로직: 차이점 설명CMOS와 TTL 로직을 표로 비교합니다: 트랜지스터, 정적 전력, 공급 전압, 논리 레벨, 잡음 여유, 속도, 입력, 주요 사용처.
