논리 회로

멀티플렉서의 기능으로 올바른 것은?

  1. A입력 값을 1클록 동안 기억한다
  2. B입력 신호의 논리를 반전한다
  3. C선택 신호에 따라 여러 입력 중 하나를 골라 출력한다
정답과 해설 보기

정답: C. 선택 신호에 따라 여러 입력 중 하나를 골라 출력한다

멀티플렉서(셀렉터)는 선택 신호의 값에 따라 여러 입력 중 하나를 골라 출력에 전달하는 회로로, 선택 신호가 n비트이면 2ⁿ개의 입력 중에서 고를 수 있습니다. CPU에서는 레지스터 값의 선택이나 버스 전환에 사용되며, FPGA의 논리 블록(LUT)도 메모리와 멀티플렉서로 임의의 논리를 구현합니다. 하나의 입력을 여러 출력 중 하나로 분배하는 회로는 디멀티플렉서입니다.

논리 회로의 다른 문제

  1. 2입력 NAND 게이트의 두 입력을 연결해 1입력으로 만들면 어떤 동작을 합니까?
  2. 카르노 맵의 주된 용도는?
  3. 플립플롭의 셋업 시간에 대한 설명으로 올바른 것은?
  4. 4비트 바이너리 카운터가 나타낼 수 있는 상태의 수는 몇 개입니까?
  5. 그레이 코드의 특징으로 올바른 것은?

이 분야의 비교

  • 래치 vs 플립플롭: 차이점 설명래치와 플립플롭을 표로 비교합니다: 트리거 방식, 출력 동작, 구성, 크기, 타이밍 분석, 글리치, 디지털 설계에서의 활용 시점.
  • 조합 논리 vs 순차 논리: 차이점 설명조합 논리와 순차 논리를 표로 비교합니다: 출력이 의존하는 것, 기억 소자, 클럭, 피드백, 예시, 타이밍, HDL 작성 방식.
  • CMOS vs TTL 로직: 차이점 설명CMOS와 TTL 로직을 표로 비교합니다: 트랜지스터, 정적 전력, 공급 전압, 논리 레벨, 잡음 여유, 속도, 입력, 주요 사용처.
