1바이트는 몇 비트입니까?

  1. A8비트
  2. B4비트
  3. C16비트
정답과 해설 보기

정답: A. 8비트

1바이트는 8비트로, 256가지(0~255)의 값을 나타낼 수 있으며 반각 영숫자 1글자나 이미지의 1화소 1색분(0~255의 농담)에 해당합니다. 4비트는 니블(반 바이트)이며 16진수 한 자리에 대응합니다. 초기 컴퓨터에서는 1바이트가 6비트나 9비트인 경우도 있었기 때문에, 엄밀하게 8비트를 가리킬 때는 「옥텟」이라고 하며 통신 규격 등에서 사용됩니다.

  • A. 맞습니다. 1바이트 = 8비트입니다.
  • B. 4비트는 니블이라고 하며 반 바이트입니다.
  • C. 16비트는 2바이트입니다.

  3. 클록이 들어올 때마다 출력이 반전되는 T 플립플롭 1개의 출력 주파수는 클록 주파수의 몇 배가 됩니까?
  4. 여러 입력이 동시에 1이 되었을 때 우선순위가 가장 높은 입력의 번호를 2진수로 출력하는 회로는 무엇입니까?
  5. 전가산기를 직렬로 연결한 리플 캐리 가산기의 단점으로 올바른 것은 무엇입니까?

이 분야의 비교

  • 래치 vs 플립플롭: 차이점 설명래치와 플립플롭을 표로 비교합니다: 트리거 방식, 출력 동작, 구성, 크기, 타이밍 분석, 글리치, 디지털 설계에서의 활용 시점.
  • 조합 논리 vs 순차 논리: 차이점 설명조합 논리와 순차 논리를 표로 비교합니다: 출력이 의존하는 것, 기억 소자, 클럭, 피드백, 예시, 타이밍, HDL 작성 방식.
  • CMOS vs TTL 로직: 차이점 설명CMOS와 TTL 로직을 표로 비교합니다: 트랜지스터, 정적 전력, 공급 전압, 논리 레벨, 잡음 여유, 속도, 입력, 주요 사용처.
