논리 회로

3입력 논리 회로의 진리표는 몇 행입니까?

  1. A6행
  2. B9행
  3. C8행
정답과 해설 보기

정답: C. 8행

각 입력은 0 또는 1의 2가지이므로 3입력의 조합은 2³ = 8가지이고 진리표는 8행이 됩니다. n입력에서는 2ⁿ행으로 지수함수적으로 늘어나므로, 32비트 가산기(64입력)의 진리표는 2⁶⁴행이 되어 만드는 것이 현실적이지 않습니다. 그래서 큰 회로는 작은 부품을 조합하여 설계하고, 논리식이나 HDL로 기술하여 검증합니다.

논리 회로의 다른 문제

  1. 1바이트는 몇 비트입니까?
  2. 16진수 1A를 10진수로 나타내면 얼마입니까?
  3. JK 플립플롭에서 J = 1, K = 1일 때 클록이 들어왔을 때의 동작은?
  4. 클록이 들어올 때마다 출력이 반전되는 T 플립플롭 1개의 출력 주파수는 클록 주파수의 몇 배입니까?
  5. 여러 입력이 동시에 1이 되었을 때 가장 우선순위가 높은 입력의 번호를 2진수로 출력하는 회로는?

이 분야의 비교

  • 래치 vs 플립플롭: 차이점 설명래치와 플립플롭을 표로 비교합니다: 트리거 방식, 출력 동작, 구성, 크기, 타이밍 분석, 글리치, 디지털 설계에서의 활용 시점.
  • 조합 논리 vs 순차 논리: 차이점 설명조합 논리와 순차 논리를 표로 비교합니다: 출력이 의존하는 것, 기억 소자, 클럭, 피드백, 예시, 타이밍, HDL 작성 방식.
  • CMOS vs TTL 로직: 차이점 설명CMOS와 TTL 로직을 표로 비교합니다: 트랜지스터, 정적 전력, 공급 전압, 논리 레벨, 잡음 여유, 속도, 입력, 주요 사용처.
