소프트웨어 개발과 프로젝트 관리

모듈의 독립성을 평가하는 모듈 강도(응집도) 중 가장 강도가 높고 바람직하다고 여겨지는 것은?

  1. A기능적 강도
  2. B논리적 강도
  3. C우연적 강도
정답과 해설 보기

정답: A. 기능적 강도

모듈 강도는 하나의 모듈 안의 처리끼리가 얼마나 강하게 관계되어 있는지를 나타내며, 강할수록 독립성이 높고 변경이나 테스트가 쉬워집니다. 강한 순서로 기능적 강도, 정보적 강도, 연락적 강도, 절차적 강도, 시간적 강도, 논리적 강도, 우연적 강도로 분류됩니다. 기능적 강도는 모듈이 하나의 명확한 기능만을 실현하고 있는 상태입니다. 논리적 강도는 관련된 여러 기능을 인수로 전환하여 실행하는 것, 우연적 강도는 관계없는 처리를 우연히 하나로 묶은 것입니다.
