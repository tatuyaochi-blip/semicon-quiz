소프트웨어 개발과 프로젝트 관리

프로젝트의 산출물과 작업을 계층적으로 분해한 WBS에서, 가장 아래 계층에 있으며 소요 기간이나 비용을 추정하고 담당자를 할당하는 단위는?

  1. A작업 패키지
  2. B마일스톤
  3. C간트 차트
정답과 해설 보기

정답: A. 작업 패키지

WBS(Work Breakdown Structure)는 프로젝트에서 만드는 산출물과 그것을 위한 작업을 상위에서 하위로 트리 형태로 분해한 것입니다. 가장 아래 계층의 요소를 작업 패키지(워크 패키지)라고 부르며, 추정·일정·담당 할당·진척 관리의 단위로 삼습니다. 마일스톤은 '기본 설계 완료'처럼 진척을 확인하는 중요한 시점입니다. 간트 차트는 작업을 가로 막대로 나타내어 일정을 보여 주는 그림으로, WBS로 분해한 작업의 일정을 그리는 데 씁니다.

소프트웨어 개발과 프로젝트 관리의 다른 문제

  1. 결합점을 ①~⑥으로 하고 작업을 '이름: 시작점→끝점, 소요 일수'로 나타내면, A: ①→②, 6일, B: ①→③, 4일, C: ②→④, 4일, D: ③→⑤, 4일, E: ④→⑥, 2일, F: ⑤→⑥, 3일, 더미 작업: ②→③(소요 일수 0)이 되는 화살표 다이어그램이 있다. 프로젝트 전체의 최단 소요 일수는?
  2. 작업과 소요 일수, 선행 작업이 A: 4일(선행 작업 없음), B: 2일(없음), C: 3일(A), D: 2일(B), E: 5일(C), F: 4일(C와 D), G: 2일(F)인 프로젝트가 있다. 다른 작업은 가능한 한 일찍 시작할 때, 작업 B의 시작을 늦춰도 전체 소요 일수가 늘어나지 않는 최대 일수는?
  3. 작업과 소요 일수, 선행 작업이 A: 6일(없음), B: 4일(없음), C: 4일(A), D: 4일(A와 B), E: 2일(C), F: 3일(D)이고, 전체 소요 일수가 13일인 프로젝트가 있다. 각 작업을 1일 단축하는 데 드는 추가 비용은 A가 30만 엔, B가 5만 엔, C가 10만 엔, D가 20만 엔, E가 8만 엔, F가 25만 엔이다. 전체 소요 일수를 1일 단축하는 데 추가 비용이 가장 적은 방법은?
  4. 어떤 작업의 소요 일수를 3점 추정으로 추정했더니 낙관치가 4일, 최빈치가 7일, 비관치가 16일이었다. PERT 식으로 구한 소요 일수의 기댓값은?
  5. 완료 시점 예산(BAC)이 2,000만 엔인 프로젝트에서, 어느 시점의 계획 가치(PV)가 800만 엔, 획득 가치(EV)가 600만 엔, 실제 비용(AC)이 750만 엔이었다. 이 시점의 프로젝트 상황으로 올바른 것은?
