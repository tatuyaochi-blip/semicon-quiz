소프트웨어 개발과 프로젝트 관리

결합점을 ①~⑥으로 하고 작업을 '이름: 시작점→끝점, 소요 일수'로 나타내면, A: ①→②, 6일, B: ①→③, 4일, C: ②→④, 4일, D: ③→⑤, 4일, E: ④→⑥, 2일, F: ⑤→⑥, 3일, 더미 작업: ②→③(소요 일수 0)이 되는 화살표 다이어그램이 있다. 프로젝트 전체의 최단 소요 일수는?

  1. A11일
  2. B12일
  3. C13일
정답과 해설 보기

정답: C. 13일

더미 작업 ②→③은 작업 D를 시작하려면 B뿐만 아니라 A도 끝나 있어야 함을 나타냅니다. 각 결합점의 가장 이른 결합점 시각은 ②가 6일, ③이 max(4, 6 + 0) = 6일, ④가 6 + 4 = 10일, ⑤가 6 + 4 = 10일, ⑥이 max(10 + 2, 10 + 3) = 13일이므로, 전체 소요 일수는 13일이고 임계 경로는 A→더미→D→F입니다. 더미 작업을 놓치면 D를 4일째부터 시작할 수 있는 것이 되어, A→C→E의 12일이 최장이 되어 버립니다. 11일은 B→D→F 경로만의 일수입니다.

소프트웨어 개발과 프로젝트 관리의 다른 문제

  1. 작업과 소요 일수, 선행 작업이 A: 4일(선행 작업 없음), B: 2일(없음), C: 3일(A), D: 2일(B), E: 5일(C), F: 4일(C와 D), G: 2일(F)인 프로젝트가 있다. 다른 작업은 가능한 한 일찍 시작할 때, 작업 B의 시작을 늦춰도 전체 소요 일수가 늘어나지 않는 최대 일수는?
  2. 작업과 소요 일수, 선행 작업이 A: 6일(없음), B: 4일(없음), C: 4일(A), D: 4일(A와 B), E: 2일(C), F: 3일(D)이고, 전체 소요 일수가 13일인 프로젝트가 있다. 각 작업을 1일 단축하는 데 드는 추가 비용은 A가 30만 엔, B가 5만 엔, C가 10만 엔, D가 20만 엔, E가 8만 엔, F가 25만 엔이다. 전체 소요 일수를 1일 단축하는 데 추가 비용이 가장 적은 방법은?
  3. 어떤 작업의 소요 일수를 3점 추정으로 추정했더니 낙관치가 4일, 최빈치가 7일, 비관치가 16일이었다. PERT 식으로 구한 소요 일수의 기댓값은?
  4. 완료 시점 예산(BAC)이 2,000만 엔인 프로젝트에서, 어느 시점의 계획 가치(PV)가 800만 엔, 획득 가치(EV)가 600만 엔, 실제 비용(AC)이 750만 엔이었다. 이 시점의 프로젝트 상황으로 올바른 것은?
  5. 완료 시점 예산(BAC)이 1,200만 엔인 프로젝트에서, 현시점의 계획 가치(PV)가 600만 엔, 획득 가치(EV)가 480만 엔, 실제 비용(AC)이 600만 엔이다. 앞으로도 현재의 원가 효율이 계속된다고 할 때, 완료 시점 산정치(EAC)는?
