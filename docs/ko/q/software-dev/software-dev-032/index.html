소프트웨어 개발과 프로젝트 관리

작업과 소요 일수, 선행 작업이 A: 6일(없음), B: 4일(없음), C: 4일(A), D: 4일(A와 B), E: 2일(C), F: 3일(D)이고, 전체 소요 일수가 13일인 프로젝트가 있다. 각 작업을 1일 단축하는 데 드는 추가 비용은 A가 30만 엔, B가 5만 엔, C가 10만 엔, D가 20만 엔, E가 8만 엔, F가 25만 엔이다. 전체 소요 일수를 1일 단축하는 데 추가 비용이 가장 적은 방법은?

  1. A작업 B를 1일 단축한다(5만 엔)
  2. B작업 D를 1일 단축한다(20만 엔)
  3. C작업 A를 1일 단축한다(30만 엔)
정답과 해설 보기

정답: B. 작업 D를 1일 단축한다(20만 엔)

임계 경로는 A→D→F(6 + 4 + 3 = 13일)이며, 다른 경로는 A→C→E가 12일, B→D→F가 11일입니다. 전체를 줄이려면 임계 경로 위의 작업을 단축해야 하며, 그중 비용이 가장 적은 것은 D의 20만 엔으로, 단축 후에는 A→D→F와 A→C→E가 모두 12일이 됩니다. B가 가장 싸지만 임계 경로 위에 없으므로, 단축해도 전체는 13일 그대로입니다. A를 단축해도 전체는 12일이 되지만, 비용은 30만 엔이 듭니다. 이처럼 비용을 들여 작업 기간을 줄이는 것을 크래싱이라고 합니다.

  3. 완료 시점 예산(BAC)이 1,200만 엔인 프로젝트에서, 현시점의 계획 가치(PV)가 600만 엔, 획득 가치(EV)가 480만 엔, 실제 비용(AC)이 600만 엔이다. 앞으로도 현재의 원가 효율이 계속된다고 할 때, 완료 시점 산정치(EAC)는?
  4. 늦어지고 있는 소프트웨어 개발 프로젝트에서 개발자를 5명에서 10명으로 늘렸다. 두 사람 사이의 의사소통 경로 수(두 사람 쌍의 수)는 늘리기 전의 몇 배가 되는가?
  5. 프로젝트의 리스크 대응 중, 발생했을 때의 손실에 대비해 보험에 들거나 계약으로 그 작업을 전문 회사에 맡기거나 하여 영향을 제3자에게 옮기는 것은?
