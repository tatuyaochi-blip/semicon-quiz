소프트웨어 개발과 프로젝트 관리

어떤 작업의 소요 일수를 3점 추정으로 추정했더니 낙관치가 4일, 최빈치가 7일, 비관치가 16일이었다. PERT 식으로 구한 소요 일수의 기댓값은?

  1. A7일
  2. B8일
  3. C9일
정답과 해설 보기

정답: B. 8일

PERT의 3점 추정에서는 기댓값을 (낙관치 + 4 × 최빈치 + 비관치) ÷ 6으로 구하므로, (4 + 4 × 7 + 16) ÷ 6 = 48 ÷ 6 = 8일입니다. 비관치가 크게 떨어져 있는 만큼, 최빈치인 7일보다 길어집니다. 편차의 기준이 되는 표준 편차는 (비관치 − 낙관치) ÷ 6 = 2일입니다. 9일은 세 값의 단순 평균 (4 + 7 + 16) ÷ 3입니다.

소프트웨어 개발과 프로젝트 관리의 다른 문제

  1. 완료 시점 예산(BAC)이 2,000만 엔인 프로젝트에서, 어느 시점의 계획 가치(PV)가 800만 엔, 획득 가치(EV)가 600만 엔, 실제 비용(AC)이 750만 엔이었다. 이 시점의 프로젝트 상황으로 올바른 것은?
  2. 완료 시점 예산(BAC)이 1,200만 엔인 프로젝트에서, 현시점의 계획 가치(PV)가 600만 엔, 획득 가치(EV)가 480만 엔, 실제 비용(AC)이 600만 엔이다. 앞으로도 현재의 원가 효율이 계속된다고 할 때, 완료 시점 산정치(EAC)는?
  3. 늦어지고 있는 소프트웨어 개발 프로젝트에서 개발자를 5명에서 10명으로 늘렸다. 두 사람 사이의 의사소통 경로 수(두 사람 쌍의 수)는 늘리기 전의 몇 배가 되는가?
  4. 프로젝트의 리스크 대응 중, 발생했을 때의 손실에 대비해 보험에 들거나 계약으로 그 작업을 전문 회사에 맡기거나 하여 영향을 제3자에게 옮기는 것은?
  5. 소프트웨어의 규모 추정에 쓰는 기능 점수(Function Point) 기법의 설명으로 적절한 것은?
