소프트웨어 개발과 프로젝트 관리

소프트웨어의 규모 추정에 쓰는 기능 점수(Function Point) 기법의 설명으로 적절한 것은?

  1. A과거에 개발한 비슷한 시스템의 실적을 바탕으로, 차이를 보정하여 전체 규모나 공수를 추정한다
  2. B소스 코드의 행 수를 추정하고, 그것을 입력으로 하여 공수나 기간을 계산식으로 구한다
  3. C외부 입력·외부 출력·외부 조회·내부 논리 파일·외부 인터페이스 파일의 수와 복잡도로부터, 사용자에게 보이는 기능의 양을 점수로 만들어 추정한다
정답과 해설 보기

정답: C. 외부 입력·외부 출력·외부 조회·내부 논리 파일·외부 인터페이스 파일의 수와 복잡도로부터, 사용자에게 보이는 기능의 양을 점수로 만들어 추정한다

기능 점수 기법은 시스템이 사용자에게 제공하는 기능의 양을 입출력이나 조회, 다루는 파일(데이터)의 수와 복잡도로 점수화하여 측정하는 방법입니다. 프로그래밍 언어에 의존하지 않고, 요구사항이나 외부 설계 단계부터 추정할 수 있는 것이 이점입니다. 소스 코드의 행 수로부터 공수를 계산식으로 구하는 것은 COCOMO 등의 방법이고, 과거의 비슷한 시스템을 바탕으로 하는 것은 유추 추정법입니다. 실제로는 여러 방법으로 추정하여 결과를 비교하는 경우가 많습니다.
