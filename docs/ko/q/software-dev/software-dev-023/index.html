상향식 테스트에서 아직 완성되지 않은 상위 모듈 대신, 테스트 대상인 하위 모듈을 호출하여 테스트 데이터를 넘기고 결과를 받기 위해 만드는 것은?

  1. A드라이버
  2. B스텁
  3. C인서킷 에뮬레이터

정답: A. 드라이버

상향식 테스트는 하위 모듈부터 차례로 통합해 가는 방법으로, 호출하는 쪽인 상위 모듈이 아직 없으므로 대신 호출하는 테스트용 프로그램인 드라이버를 만듭니다. 반대로 상위부터 차례로 통합하는 하향식 테스트에서는 아직 완성되지 않은 하위 모듈 대신, 정해진 값을 반환하기만 하는 스텁을 만듭니다. 인서킷 에뮬레이터는 마이컴 대신 기판에 연결하여, 실기 위에서 프로그램의 실행을 멈추거나 내부를 관찰하는 디버그용 장치입니다.

소프트웨어 개발과 프로젝트 관리의 다른 문제

  1. 테스트 공정에서 테스트 시간(또는 테스트 케이스의 소화 수)을 가로축에, 발견된 결함의 누적 건수를 세로축에 잡은 신뢰도 성장 곡선을 그렸다. 곡선이 아직 오른쪽 위로 올라가는 채이고, 포화하는(평평해지는) 모습이 보이지 않을 때의 판단으로 가장 적절한 것은?
  2. 규모가 25 k스텝(25,000행)인 펌웨어의 통합 테스트에서 결함이 30건 발견되었다. 조직의 과거 실적으로부터 이 공정에서 발견되는 결함의 기준은 1 k스텝당 2~4건으로 되어 있다. 이 결과의 평가로 가장 적절한 것은?
  3. Git에서 두 개발자가 같은 파일의 같은 행을 각각 다른 브랜치에서 고쳐 쓰고, 한쪽 브랜치를 다른 쪽에 병합했다. 이때 일어나는 일로 적절한 것은?
  4. 설계서나 소스 코드의 리뷰 방법 중, 모더레이터(진행자)가 주도하고 참가자의 역할을 정하며, 체크리스트 등을 사용해 공식적으로 수행하고, 발견한 결함을 기록하여 수정까지 확인하는 것은?
  5. 올바르게 동작하는 것으로 알려진 펌웨어 버전 뒤에 1,000개의 커밋이 있고, 최신 커밋에서는 결함이 일어난다. 결함은 어느 한 커밋에서 들어왔고, 그 이후의 커밋에서는 모두 일어난다고 한다. git bisect처럼 이진 탐색으로 원인 커밋을 특정할 때, 빌드하여 테스트하는 횟수의 최댓값은?
