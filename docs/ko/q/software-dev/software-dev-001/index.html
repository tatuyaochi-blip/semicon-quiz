소프트웨어 개발과 프로젝트 관리

소프트웨어 개발의 폭포수 모델의 특징으로 적절한 것은?

  1. A요구사항 정의·설계·구현·테스트 등의 공정을 상류부터 차례로 진행하며, 원칙적으로 앞 공정의 산출물이 확정된 뒤에 다음 공정으로 나아간다
  2. B짧은 기간의 반복을 되풀이하며, 그때마다 동작하는 소프트웨어를 만들어 사용자의 의견을 반영한다
  3. C처음에 시제품(프로토타입)을 만들어 사용자에게 보여 주고, 요구를 확인한 뒤에 본격적으로 개발한다
정답과 해설 보기

정답: A. 요구사항 정의·설계·구현·테스트 등의 공정을 상류부터 차례로 진행하며, 원칙적으로 앞 공정의 산출물이 확정된 뒤에 다음 공정으로 나아간다

폭포수 모델은 물이 위에서 아래로 흐르듯이 요구사항 정의, 설계, 프로그래밍, 테스트의 순서로 공정을 진행하는 개발 모델입니다. 공정마다 산출물을 리뷰로 확정하므로 계획을 세우기 쉽고 진척도 관리하기 쉬운 반면, 뒤 공정에서 요구사항의 오류가 발견되면 재작업이 커집니다. 요구사항이 명확하고 잘 바뀌지 않는 개발이나, 하드웨어와 함께 사양을 일찍 굳혀야 하는 개발에 쓰입니다. 반복하며 사용자의 의견을 반영하는 것은 애자일 개발 등의 반복형, 시제품으로 요구를 확인하는 것은 프로토타이핑 모델의 특징입니다.
