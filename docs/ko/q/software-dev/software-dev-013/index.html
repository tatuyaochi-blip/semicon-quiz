소프트웨어 개발과 프로젝트 관리

모듈 간의 결합도 중 가장 결합도가 약하고 모듈의 독립성이 높은 것은?

  1. A공통 결합
  2. B제어 결합
  3. C데이터 결합
정답과 해설 보기

정답: C. 데이터 결합

결합도는 모듈끼리가 얼마나 서로 의존하는지를 나타내며, 약할수록 독립성이 높아 바람직하다고 여겨집니다. 약한 순서로 데이터 결합, 스탬프 결합, 제어 결합, 외부 결합, 공통 결합, 내용 결합으로 분류됩니다. 데이터 결합은 필요한 데이터만을 단순한 인수로 주고받는 결합입니다. 제어 결합은 처리의 흐름을 전환하는 플래그 등을 넘기는 결합, 공통 결합은 여러 모듈이 같은 전역 데이터(전역 변수)를 참조하는 결합으로, 둘 다 상대 모듈의 내부 구조에 의존하기 쉬워집니다.
