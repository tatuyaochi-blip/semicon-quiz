어떤 업무 시스템의 요구사항 중 비기능 요구사항에 해당하는 것은?

  1. A사용자가 많은 시간대에도 화면의 95% 이상을 3초 이내에 표시한다
  2. B주문을 받으면 재고를 할당하고, 재고가 부족하면 입고 예정일을 표시한다
  3. C매월 말에 거래처별 청구서를 작성한다
정답과 해설 보기

정답: A. 사용자가 많은 시간대에도 화면의 95% 이상을 3초 이내에 표시한다

기능 요구사항은 시스템이 무엇을 하는지(업무 처리나 기능)를 정하는 요구사항이고, 비기능 요구사항은 성능(응답 시간·처리 건수), 신뢰성·가용성, 보안, 유지보수 용이성, 이행 등 얼마나 잘 동작하는지를 정하는 요구사항입니다. '화면의 95% 이상을 3초 이내에 표시한다'는 응답 시간 목표는 성능에 관한 비기능 요구사항입니다. 재고 할당이나 청구서 작성은 시스템이 수행하는 처리 그 자체이므로 기능 요구사항입니다. 비기능 요구사항은 사용자가 명시하기 어려우므로, 수치로 확인할 수 있는 형태로 만들어 합의해 두는 것이 중요합니다.
