사회공학 기법의 예로 해당하는 것은?

  1. A시스템 관리자를 자칭하며 전화를 걸어 '장애 대응을 위해서'라고 말하고 직원에게서 비밀번호를 알아낸다
  2. B웹 애플리케이션의 입력란에 특수한 문자열을 입력하여 데이터베이스를 부정하게 조작한다
  3. C비밀번호 후보를 프로그램으로 차례로 시도하여 로그인할 수 있는 것을 찾는다
정답과 해설 보기

정답: A. 시스템 관리자를 자칭하며 전화를 걸어 '장애 대응을 위해서'라고 말하고 직원에게서 비밀번호를 알아낸다

사회공학 기법(소셜 엔지니어링)은 기술적인 수단이 아니라 사람의 심리나 습관, 부주의를 파고들어 비밀번호 등의 중요한 정보를 알아내거나 조작을 하게 하는 수법의 총칭입니다. 관리자나 거래처, 상사를 자칭하는 전화나 메일, 어깨 너머로 화면이나 키 입력을 엿보는 것(숄더 해킹), 버려진 서류를 뒤지는 것(트래싱) 등이 있습니다. '서둘러', '긴급', '비밀로'처럼 생각할 시간을 주지 않는 말투가 자주 사용되는 것이 특징입니다. 대책으로는 전화나 메일로 비밀번호를 알려 주지 않는다는 규칙을 만들어 알리고, 상대의 신원을 안내받은 연락처가 아니라 원래 알고 있는 연락처로 문의하여 확인합니다. 피싱도 사람을 속인다는 점에서 사회공학 기법의 일종입니다. 입력란에 특수한 문자열을 넣는 것은 SQL 인젝션 같은 기술적인 공격이고, 후보를 차례로 시도하는 것은 무차별 대입 공격입니다.

  3. SQL 인젝션 대책으로서 플레이스홀더를 사용하는 프리페어드 스테이트먼트(매개변수화 쿼리)가, 입력 안의 위험한 문자를 제거하는 방법보다 근본적인 대책으로 여겨지는 이유로 올바른 것은?
  4. 게시판 웹 애플리케이션에서 이용자가 게시한 글 안의 스크립트가 다른 열람자의 브라우저에서 실행되어 버리는 취약점이 있었다. 이 취약점의 이름과 근본적인 대책의 조합으로 올바른 것은?
  5. 웹 애플리케이션에서 로그인한 상태의 이용자가 공격자가 준비한 함정 페이지를 열면, 이용자의 브라우저에서 정규 사이트로 이용자가 의도하지 않은 송금이나 설정 변경 요청이 보내지는 취약점이 있다. 이 취약점에 대한 대책으로 적절한 것은?
