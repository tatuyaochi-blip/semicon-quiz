  2. B컴퓨터 안의 파일을 멋대로 암호화하는 등으로 사용할 수 없게 하고, 원래대로 되돌리는 대가로 금전(몸값)을 요구하는 악성코드

정답: B. 컴퓨터 안의 파일을 멋대로 암호화하는 등으로 사용할 수 없게 하고, 원래대로 되돌리는 대가로 금전(몸값)을 요구하는 악성코드

랜섬웨어는 감염된 컴퓨터나 네트워크 안의 파일을 암호화하는 등으로 사용할 수 없게 하고, 원래대로 되돌리기 위한 키를 대가로 몸값을 요구하는 악성코드입니다. 2020년대 중반 시점에는 조직의 네트워크에 침입하여 많은 서버를 일제히 암호화하거나, 암호화 전에 훔친 데이터를 '공개하겠다'고 협박하는 수법(이중 협박)이 많이 보고되고 있습니다. 몸값을 내도 원래대로 돌아온다는 보장이 없고 범죄자의 자금이 되기도 하므로, 지불하지 않는 것이 권장됩니다. 대책의 중심은 침입 입구가 되는 취약점에 대한 수정 적용, 원격 접속의 다요소 인증, 권한의 최소화, 그리고 네트워크에서 분리된 곳에 보관하는 백업입니다.
