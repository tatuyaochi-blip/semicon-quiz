랜섬웨어 대비로서의 백업에 대해 '3-2-1 규칙'에 따른 방법으로 가장 적절한 것은?

  1. A같은 파일 서버 안에 폴더를 3개 만들고 2시간마다 1번 복사한다
  2. B항상 네트워크로 연결된 백업용 디스크를 3대 준비하여 2대를 같은 서버에, 1대를 같은 방에 둔다
  3. C원래 데이터를 포함하여 3개의 복사본을 가지고, 2종류의 서로 다른 매체에 저장하며, 그중 1개는 다른 장소(네트워크에서 분리된 장소 등)에 둔다
정답과 해설 보기

정답: C. 원래 데이터를 포함하여 3개의 복사본을 가지고, 2종류의 서로 다른 매체에 저장하며, 그중 1개는 다른 장소(네트워크에서 분리된 장소 등)에 둔다

3-2-1 규칙은 데이터의 복사본을 원래 데이터를 포함하여 3개 이상 가지고, 2종류 이상의 서로 다른 매체(디스크, 테이프, 클라우드 등)에 저장하며, 그중 1개 이상을 다른 장소에 둔다는 백업의 기준입니다. 기기 한 대의 고장, 매체 종류에 공통된 결함, 화재나 재해 같은 한 장소에서의 피해가 모든 복사본에 동시에 미치지 않도록 하기 위한 생각입니다. 랜섬웨어는 네트워크로 연결되어 있고 쓰기가 가능한 백업도 암호화하거나 지우는 경우가 있으므로, 적어도 하나는 오프라인(네트워크에서 분리)이나 일정 기간 변경할 수 없는 설정(이뮤터블)으로 해 두는 것이 중요합니다. 또한 막상 필요할 때 복원할 수 있는지를 복원 시험으로 정기적으로 확인해 두어야 합니다.
