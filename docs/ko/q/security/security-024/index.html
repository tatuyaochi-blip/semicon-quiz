정보 보안 기초

직원이 수천 명인 회사에서 역할 기반 접근 제어(RBAC)를 사용하여 권한을 관리한다. RBAC의 개념으로 올바른 것은?

  1. A파일의 소유자가 파일마다 누구에게 읽기·쓰기를 허용할지 자유롭게 정한다
  2. B'경리 담당', '인사 담당' 같은 역할(롤)마다 권한을 묶어서 정하고, 이용자에게는 역할을 할당한다
  3. C모든 이용자와 모든 파일의 조합마다 하나씩 권한을 설정한다
정답과 해설 보기

정답: B. '경리 담당', '인사 담당' 같은 역할(롤)마다 권한을 묶어서 정하고, 이용자에게는 역할을 할당한다

역할 기반 접근 제어(RBAC)에서는 직무에 따른 역할(롤)마다 필요한 권한을 묶어서 정해 두고, 이용자에게는 롤을 할당합니다. 이용자는 할당된 롤의 권한만 사용할 수 있습니다. 사람이 이동했을 때는 롤의 할당을 바꾸기만 하면 권한을 한꺼번에 올바르게 전환할 수 있습니다. 이용자와 파일의 조합마다 권한을 설정하는 방법은 인원이나 파일이 늘면 관리할 수 없게 되고, 불필요한 권한을 지우는 것을 잊는 일도 일어나기 쉬워집니다. 파일의 소유자가 자유롭게 권한을 정하는 방식은 임의 접근 제어(DAC)라고 하며 많은 OS의 파일 권한에 사용되지만, 조직 전체의 방침을 맞추기는 어려워집니다.
