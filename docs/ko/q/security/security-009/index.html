큰 파일을 상대에게 암호화하여 보낼 때 자주 사용되는 하이브리드 암호 방식의 절차로 올바른 것은?

  1. A파일을 상대의 공개 키로 직접 암호화하고 대칭 키 암호는 사용하지 않는다
  2. B파일을 대칭 키로 암호화하고, 그 대칭 키를 암호화하지 않고 파일과 함께 보낸다
  3. C일회용 대칭 키로 파일을 암호화하고, 그 대칭 키를 상대의 공개 키로 암호화하여 함께 보낸다
정답과 해설 보기

정답: C. 일회용 대칭 키로 파일을 암호화하고, 그 대칭 키를 상대의 공개 키로 암호화하여 함께 보낸다

공개 키 암호는 키 배송이 쉽지만 계산이 무거워 큰 데이터의 암호화에는 적합하지 않습니다. 대칭 키 암호는 빠르지만 키를 안전하게 상대에게 전달하는 방법이 과제입니다. 하이브리드 암호 방식은 양쪽의 장점을 조합하여, 데이터 본체는 그 자리에서 만든 일회용 대칭 키(세션 키)로 빠르게 암호화하고, 그 짧은 대칭 키만 상대의 공개 키로 암호화하여 보냅니다. 수신자는 자신의 개인 키로 대칭 키를 꺼내고, 그것으로 데이터를 복호화합니다. 전자 메일 암호화 등에 사용됩니다. TLS에서는 대칭 키를 공개 키로 암호화해 보내는 대신 키 교환 절차로 양쪽이 같은 대칭 키를 만드는 방식이 주류이지만, '공개 키 기술로 대칭 키를 안전하게 준비하고, 데이터는 대칭 키 암호로 보호한다'는 생각은 같습니다.

  2. 출력이 256비트인 이상적인 해시 함수에 대해 무차별 대입로 공격할 때 필요한 계산 횟수의 기준으로, '주어진 해시값이 되는 입력을 찾는(역상 공격)' 경우와 '같은 해시값이 되는 서로 다른 두 입력을 아무것이나 찾는(충돌 공격)' 경우의 조합으로 올바른 것은?
