정보 보안 기초

어떤 얼굴 인증 장치에서는 임곗값을 A·B·C의 3가지로 설정할 수 있으며, 각각의 타인 수락률(FAR)과 본인 거부율(FRR)은 A가 1%와 0.5%, B가 0.1%와 2%, C가 0.01%와 8%이다. 연구실 출입 관리에서 'FAR을 0.1% 이하로 한다'는 것을 조건으로 하고, 그런 다음 정당한 이용자가 가능한 한 거부되지 않도록 하고 싶다. 골라야 할 임곗값은?

  1. A임곗값 A
  2. B임곗값 B
  3. C임곗값 C
정답과 해설 보기

정답: B. 임곗값 B

먼저 조건을 만족하는 것을 고릅니다. FAR이 0.1% 이하인 것은 B(0.1%)와 C(0.01%)이며, A(1%)는 타인이 100번에 1번 받아들여지므로 조건을 만족하지 않습니다. 다음으로 조건을 만족하는 B와 C 중 정당한 이용자가 거부되기 어려운 것은 FRR이 낮은 쪽이며, B의 2%는 C의 8%보다 낮으므로 B를 고릅니다. C는 타인을 더 확실하게 거부할 수 있지만, 본인이 100번 중 약 8번 거부되어 사용하기 불편해집니다. 임곗값을 A에서 C로 엄격하게 할수록 FAR이 내려가고 FRR이 올라가는 것도 확인할 수 있습니다. 보안 요구를 조건으로 먼저 만족시키고, 그런 다음 편의성을 최대로 한다는 것이 임곗값을 정하는 기본입니다.
