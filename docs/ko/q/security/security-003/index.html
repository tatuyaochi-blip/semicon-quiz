정보 보안 기초

정보 유출이 일어났을 때의 손해 배상에 대비하여 사이버 보험에 가입했다. 이 위험 대응은 어느 것에 해당하는가?

  1. A위험 회피
  2. B위험 전가
  3. C위험 수용
정답과 해설 보기

정답: B. 위험 전가

위험 대응은 크게 네 가지로 나눌 수 있습니다. 위험 회피는 위험의 원인이 되는 업무나 시스템을 그만두는 것입니다. 위험 감소는 대책을 시행하여 일어날 가능성이나 영향을 줄이는 것입니다. 위험 전가는 보험 가입이나 업무의 외부 위탁 등으로 손실 부담을 다른 조직과 나누는 것으로, 위험 공유라고도 합니다. 위험 수용(보유)은 영향이 작은 경우 등에 특별한 대책 없이 그 위험을 받아들이는 것입니다. 보험에서는 손해 배상 등 금전적 손실의 일부를 보험사로 옮기므로 위험 전가에 해당합니다. 다만 정보 유출 그 자체나 신뢰 저하는 옮길 수 없으므로 위험 감소 대책과 조합합니다.

정보 보안 기초의 다른 문제

  1. 어떤 정보 시스템에서 한 번 일어나면 2000만 엔의 손실이 나는 사고가 연 0.1회의 빈도로 일어난다고 추정된다. 연간 50만 엔의 비용이 드는 대책을 시행하면 발생 빈도가 연 0.02회로 떨어진다. 이 대책에 의한 연간 순효과(손실 기댓값의 감소액에서 대책 비용을 뺀 것)는 얼마인가?
  2. ISMS(정보 보안 관리 체계)를 PDCA 사이클로 운영할 때 Check(평가) 단계에서 하는 일로 적절한 것은?
  3. 대칭 키 암호의 특징으로 올바른 것은?
  4. 공개 키 암호를 사용하여 A 씨가 B 씨만 읽을 수 있도록 메시지를 암호화해 보내려고 한다. 암호화에 사용하는 키는?
  5. 50명의 구성원이 두 사람씩 짝지은 모든 조합에서 다른 구성원에게 내용을 알리지 않고 암호 통신을 하려고 한다. 대칭 키 암호를 사용하는 경우에 필요한 키의 수와 공개 키 암호를 사용하는 경우에 필요한 키의 수(공개 키와 개인 키의 합계)의 조합으로 올바른 것은?
