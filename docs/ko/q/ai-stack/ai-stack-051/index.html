AI 하드웨어·소프트웨어 스택

뉴로모픽 컴퓨팅의 하드웨어가 낮은 소비 전력을 목표로 할 수 있는 주된 이유로 올바른 것은?

  1. A모든 뉴런을 높은 클록 주파수로 항상 동시에 동작시키기 때문에
  2. B모든 계산을 64비트 부동소수점으로 수행하기 때문에
  3. C스파이크가 도달한 부분만 동작하는 이벤트 구동 방식이며, 가중치를 저장하는 메모리를 연산 가까이에 두어 데이터 이동을 줄이기 때문에

정답: C. 스파이크가 도달한 부분만 동작하는 이벤트 구동 방식이며, 가중치를 저장하는 메모리를 연산 가까이에 두어 데이터 이동을 줄이기 때문에

뉴로모픽 컴퓨팅은 뇌의 신경 회로를 본떠 정보를 스파이크라는 펄스로 전달합니다. 입력에 변화가 있어 스파이크가 도달한 부분만 동작하므로, 활동이 드문드문한 처리에서는 아무 일도 하지 않는 회로가 전력을 거의 쓰지 않습니다. 또한 시냅스의 가중치를 각 코어 안의 메모리에 두어 연산기와의 긴 데이터 이동을 줄입니다. 이러한 특징이 밀집된 행렬 연산을 일제히 수행하는 GPU와의 차이입니다.

AI 하드웨어·소프트웨어 스택의 다른 문제

  1. 뉴로모픽 컴퓨팅에서 동작시키는 스파이킹 신경망(SNN)을 일반적인 신경망의 오차 역전파법으로 그대로 학습시키기 어려운 주된 이유로 올바른 것은?
  2. 신경망의 '학습'과 '추론'의 차이로 올바른 것은 무엇인가?
  3. 학습에 필요한 메모리가 같은 모델의 추론보다 훨씬 커지는 이유로 해당하지 않는 것은 무엇인가?
  4. 파라미터 수 70억(7B)의 모델을 가중치, 기울기, Adam의 두 상태를 모두 FP32(4바이트)로 가지고 학습한다. 활성화를 제외하고 필요한 메모리에 가장 가까운 것은 무엇인가?
  5. 파라미터 수 70억(7B)의 모델 가중치를 FP16(2바이트)으로 가지면, 가중치 메모리는 대략 얼마인가?

이 분야의 비교

  • CPU·GPU·NPU의 차이: 설계 사상·연산기·데이터 타입·전력 효율 비교CPU·GPU·NPU를 설계 사상, 연산기 구성, 제어 방식, 메모리, 데이터 타입(INT8, FP16 등), 성능 표기, 전력 효율, 유연성, 프로그래밍 관점에서 비교합니다.
  • AI 학습과 추론의 차이점 정리AI 학습과 추론을 표로 비교합니다. 계산 내용(순전파·역전파), 계산량, 필요 메모리, 수치 형식, 배치 크기, 지연과 처리량, 하드웨어, 에너지를 안내합니다.
