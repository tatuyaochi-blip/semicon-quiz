계측과 분석

동작시킨 칩의 미소한 발열을, 가하는 전력을 주기적으로 바꾸고 동기시킨 열화상을 적산하여 고감도로 검출함으로써 고장 위치를 특정하는 수법은?

  1. A락인 서모그래피
  2. B엘립소메트리
  3. CSIMS
정답과 해설 보기

정답: A. 락인 서모그래피

락인 서모그래피는 칩에 거는 전압을 일정한 주기로 온·오프하고, 그 주기에 동기한 적외선 열화상만 적산하여 쇼트 등으로 인한 µW 수준의 미약한 발열 위치를 검출합니다. 주기와 관계없는 노이즈는 적산으로 상쇄되므로 통상의 열화상보다 감도가 자릿수 단위로 높아집니다. 패키지 바깥에서도 위치를 좁힐 수 있으므로 고장 해석 초기에 사용됩니다.

계측과 분석의 다른 문제

  1. 패키지나 기판의 배선에 고속 펄스를 보내 반사되어 오는 파형으로부터 단선이나 쇼트 위치를 구하는 방법은?
  2. 빛을 사용하는 결함 검사에서 이물이 작아질수록 검출이 급격히 어려워지는 이유로 올바른 것은?
  3. 여러 서로 다른 계측 수법(광학식·CD-SEM·AFM 등)의 데이터를 조합하여 하나의 수법만 사용하는 것보다 정확하게 치수나 형상을 구하는 개념을 무엇이라고 합니까?
  4. 주사 전자 현미경(SEM)의 원리로 올바른 것은?
  5. 엘립소메트리(분광 엘립소메트리)로 주로 측정하는 것은?
