계측과 분석

동작시킨 칩의 미소한 발열을, 가하는 전력을 주기적으로 바꾸고 이에 동기한 열화상을 적산함으로써 고감도로 검출하여 고장 위치를 특정하는 기법은?

  1. A락인 서모그래피
  2. B엘립소메트리
  3. CSIMS
정답과 해설 보기

정답: A. 락인 서모그래피

락인 서모그래피는 칩에 거는 전압을 일정한 주기로 켜고 끄며, 그 주기에 동기한 적외선 열화상만을 적산하여 단락 등으로 인한 µW 수준의 미약한 발열 위치를 검출합니다. 주기와 관계없는 잡음은 적산으로 상쇄되므로 일반 열화상보다 감도가 자릿수 단위로 향상됩니다. 패키지 바깥에서도 위치를 좁힐 수 있어 고장 해석의 초기에 사용됩니다.

  • A. 올바릅니다. 주기에 동기한 열화상으로 미소 발열을 검출합니다.
  • B. 엘립소메트리는 막 두께를 측정하는 방법입니다.
  • C. SIMS는 원소의 깊이 방향 분포를 조사하는 방법입니다.

계측과 분석의 다른 문제

  1. 패키지나 기판의 배선에 고속 펄스를 보내고, 반사되어 오는 파형으로부터 단선이나 단락의 위치를 구하는 방법은?
  2. 빛을 사용하는 결함 검사에서 이물이 작아질수록 검출이 급격히 어려워지는 이유로 올바른 것은?
  3. 여러 다른 계측 기법(광학식·CD-SEM·AFM 등)의 데이터를 조합하여, 하나의 기법만 사용할 때보다 정확하게 치수나 형상을 구하는 개념을 무엇이라고 하는가?
  4. 주사전자현미경(SEM)의 원리로 올바른 것은?
  5. 엘립소메트리(분광 엘립소메트리)로 주로 측정하는 것은?
