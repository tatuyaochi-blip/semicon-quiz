계측과 분석

웨이퍼의 캐리어 라이프타임을 비접촉으로 측정하여 금속 오염 등을 평가하는 방법은?

  1. A마이크로파 광도전 감쇠법(μ-PCD)
  2. BSIMS
  3. CXRD
정답과 해설 보기

정답: A. 마이크로파 광도전 감쇠법(μ-PCD)

μ-PCD에서는 웨이퍼에 광 펄스를 쪼여 캐리어를 발생시키고, 그것이 재결합하여 줄어드는 모습을 마이크로파 반사율의 변화로부터 측정합니다. 철 등의 금속 오염은 재결합 중심이 되어 라이프타임을 짧게 하므로, 열처리로의 오염 감시나 웨이퍼 품질 평가에 사용됩니다. 전극을 붙이지 않고 측정할 수 있으므로 웨이퍼 전면의 분포도도 그릴 수 있습니다. SIMS와 XRD로는 라이프타임을 측정할 수 없습니다.

  3. 제조 라인에서 공정 도중에 계측이나 검사를 수행하는 주된 목적은?
  4. 제조 라인의 계측에서 모든 웨이퍼나 모든 지점을 측정하지 않고 일부를 골라 측정하는 경우가 많은 주된 이유는?
  5. 단면 형상을 자세히 조사하기 위해 웨이퍼를 쪼개거나 깎은 뒤 관찰하는 방법의 특징으로 올바른 것은?
