정답: B. 공정의 이상을 빨리 발견하여 멈춤으로써 불량품을 대량으로 계속 만드는 것을 방지하기 위해

첨단 LSI는 1000을 넘는 공정을 거쳐 완성까지 수개월이 걸립니다. 완성된 뒤에 문제를 알게 되면 그동안 흘러간 대량의 웨이퍼가 불량이 되어 버립니다. 공정 도중에 계측·검사를 수행하여 이상을 빨리 발견하고 원인이 되는 장비나 공정을 멈춰 조건을 수정함으로써 손실을 작게 억제합니다. 측정 결과를 다음 웨이퍼의 조건 보정에 사용하는 제어에도 도움이 됩니다.
