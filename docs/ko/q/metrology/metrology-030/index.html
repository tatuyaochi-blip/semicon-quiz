계측과 분석

검사에서 발견된 결함을 SEM으로 촬영하고, 그 이미지로부터 결함의 종류를 자동으로 분류하는 기능은?

  1. AATPG
  2. B자동 결함 분류(ADC)
  3. CAPC
정답과 해설 보기

정답: B. 자동 결함 분류(ADC)

결함 검사 장비는 웨이퍼 한 장에서 수천 개의 결함을 검출하기도 하므로, 각각의 원인을 조사하려면 종류별 분류가 필요합니다. 자동 결함 분류(ADC)는 리뷰 SEM 이미지로부터 이물, 패턴 결함, 스크래치 등으로 자동 분류하여 원인 공정이나 장비의 특정을 앞당깁니다. 최근에는 머신러닝도 활용되고 있습니다. ATPG는 테스트 패턴 생성, APC는 공정 자동 제어입니다.

계측과 분석의 다른 문제

  2. 제조 라인에서 공정 중간에 계측이나 검사를 수행하는 주된 목적은?

  4. 단면 형상을 자세히 조사하기 위해 웨이퍼를 쪼개거나 깎은 다음 관찰하는 방법의 특징으로 올바른 것은?
  5. 계측기의 성능에서 「같은 것을 몇 번 측정해도 값의 산포가 작은 것」과 「측정한 값이 참값에 가까운 것」을 부르는 말의 조합으로 올바른 것은?
