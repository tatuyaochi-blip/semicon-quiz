확률·통계와 대기행렬

가설 검정에서 얻어지는 p값의 의미로 적절한 것은?

  1. A관측된 데이터로부터 계산한, 귀무가설 자체가 옳을 확률
  2. Bp값이 0.03이면, 대립가설이 옳을 확률은 97%라는 것
  3. C귀무가설이 옳다고 가정했을 때, 관측된 결과나 그보다 극단적인 결과가 얻어질 확률
정답과 해설 보기

정답: C. 귀무가설이 옳다고 가정했을 때, 관측된 결과나 그보다 극단적인 결과가 얻어질 확률

가설 검정에서는 '차이가 없다' 등의 귀무가설을 세우고, 그것이 옳다고 가정했을 때 실제 데이터와 같은 결과가 얼마나 일어나기 어려운지를 p값으로 나타냅니다. p값이 미리 정한 유의 수준(예를 들어 0.05)보다 작으면, 귀무가설을 기각하고 차이가 있다고 판단합니다. p값은 귀무가설이나 대립가설 자체가 옳을 확률이 아닙니다.

확률·통계와 대기행렬의 다른 문제

  2. 1시간당 평균 12건의 의뢰가 도착하고, 1건의 처리에 평균 4분이 걸리는 창구가 있다. M/M/1 대기행렬로 볼 때, 창구의 사용률은?
  3. 1분당 평균 3건의 요청이 도착하고, 1건의 처리에 평균 15초가 걸리는 서버를 M/M/1 대기행렬로 본다. 요청이 도착하고 나서 처리가 끝날 때까지의 평균 시간(평균 응답 시간)은?
  4. 어떤 웹 서버 안에는 처리 중인 것과 대기 중인 것을 합해 평균 12건의 요청이 있다. 요청은 초당 40건의 비율로 도착하고, 같은 비율로 처리되고 있다(정상 상태). 리틀의 법칙으로 구한, 1건의 요청이 서버 안에 머무는 평균 시간은?
  5. M/M/1 대기행렬로 볼 수 있는 서버에서, 평균 서비스 시간은 그대로인 채 도착률이 늘어나 사용률이 0.8에서 0.9로 올라갔다. 평균 대기 시간 Wq(행렬에서 기다리는 시간)는 몇 배가 되는가? 가장 가까운 것은?
