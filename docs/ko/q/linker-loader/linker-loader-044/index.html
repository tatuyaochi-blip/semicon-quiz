정답과 해설 보기

정답: A. 그 실행 파일이 필요로 하는 공유 라이브러리와 각각이 발견되는 위치

ldd는 동적 링크 실행 파일이나 공유 라이브러리가 사용하는 공유 라이브러리의 목록과, 각각이 어느 파일로 해석되는지를 표시합니다. 발견되지 않는 것은 'not found'로 표시되므로 기동하지 않는 원인을 조사하는 데 도움이 됩니다. 다만 신뢰할 수 없는 실행 파일에 사용하면 안의 코드가 실행될 수 있으므로 주의가 필요합니다.

링커, 로더, 실행 파일의 다른 문제

  1. 주요 OS에서 사용되는 실행 파일 형식의 조합으로 올바른 것은 무엇입니까?
  2. 재귀가 너무 깊어져 스택 상한을 넘었을 때 Linux 등에서 일반적으로 일어나는 일로 올바른 것은 무엇입니까?
  3. C 언어에서 초기값을 쓰지 않은 지역 변수와 전역 변수의 사용 시작 시 값에 대해 올바른 것은 무엇입니까?
  4. malloc과 free를 반복하는 동안, 빈 메모리의 합계는 충분한데도 큰 영역을 한꺼번에 확보할 수 없게 되는 경우가 있습니다. 이 현상을 무엇이라고 합니까?
  5. 공유 라이브러리를 만들 때 외부에서 사용할 함수만 공개하고 내부 함수는 심볼 가시성(visibility)을 'hidden'으로 하는 이점으로 올바른 것은 무엇입니까?
