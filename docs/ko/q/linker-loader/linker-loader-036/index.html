Linux의 dlopen 함수(Windows의 LoadLibrary에 해당)의 용도로 가장 적절한 것은 무엇입니까?

  1. A프로그램의 소스 코드를 열어 편집한다
  2. B플러그인처럼 실행 중에 필요해진 공유 라이브러리를 읽어 들여 함수를 호출한다
  3. C파일을 열어 안의 데이터를 읽고 쓴다
정답과 해설 보기

정답: B. 플러그인처럼 실행 중에 필요해진 공유 라이브러리를 읽어 들여 함수를 호출한다

일반적인 동적 링크에서는 사용할 공유 라이브러리가 기동 시에 정해져 있습니다. dlopen을 사용하면 실행 중에 이름을 지정하여 라이브러리를 읽어 들이고, dlsym으로 함수 주소를 꺼내 호출할 수 있습니다. 어떤 라이브러리를 사용할지 설정이나 사용자의 선택으로 정할 수 있으므로, 플러그인 구조나 있으면 사용하는 선택 기능의 구현에 자주 사용됩니다.

링커, 로더, 실행 파일의 다른 문제

  1. 100개의 프로세스가 같은 공유 라이브러리를 사용하고 있을 때 물리 메모리 사용 방식으로 올바른 것은 무엇입니까?
  2. 오브젝트 파일을 역어셈블했더니 외부 함수 printf를 호출하는 명령의 점프 대상이 0 같은 임시 값이었습니다. 이 값은 언제 올바르게 채워집니까?
  3. 임베디드 개발에서 사용하는 링커 스크립트의 역할로 올바른 것은 무엇입니까?
  4. OS가 없는 마이크로컨트롤러에서 전원을 켠 직후 기동 코드가 main을 호출하기 전에 수행하는 처리로 올바른 것은 무엇입니까?
  5. ELF 파일에서 '섹션'과 '세그먼트'의 차이로 올바른 것은 무엇입니까?
