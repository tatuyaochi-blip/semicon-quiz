정답과 해설 보기

정답: A. 프로그램의 기계어 명령

.text 섹션에는 함수를 번역한 기계어 명령이 들어갑니다. 실행 중에는 읽기와 실행만 허용하고 쓰기를 금지하는 것이 보통이며, 잘못된 쓰기나 공격자에 의한 코드 변조를 막을 수 있습니다. 또한 바뀌지 않으므로 같은 프로그램이나 공유 라이브러리를 여러 프로세스에서 실행할 때 물리 메모리 상의 하나의 사본을 공유할 수 있습니다.

링커, 로더, 실행 파일의 다른 문제

  1. C 언어에서 파일 바깥에 'int limit = 100;'이라고 쓴 전역 변수는 일반적으로 어느 섹션에 놓입니까?
  2. .bss 섹션의 특징으로 올바른 것은 무엇입니까?
  3. C 언어의 'char *p = "hello"; p[0] = 'H';'를 실행하면 많은 환경에서 비정상 종료됩니다. 그 이유로 올바른 것은 무엇입니까?
  4. 위의 전역 변수 중 일반적으로 .bss 섹션에 놓이는 것의 조합은 무엇입니까?
  5. C 언어 함수 안에서 선언한, static이 붙지 않은 지역 변수(자동 변수)는 실행 중 어디에 놓입니까?

이 분야의 비교

  • 정적 링킹 vs 동적 링킹: 차이점 설명정적 링킹과 동적 링킹을 표로 비교합니다: 링킹 시점, 실행 파일 크기, 메모리 사용, 업데이트, 시작 시간, 배포, 성능, 주요 용도.
  • 스택 vs 힙 메모리: 차이점 설명스택과 힙 메모리를 표로 비교합니다: 용도, 할당, 속도, 수명, 크기 제한, 배치, 단편화, 흔한 오류.
