링커, 로더, 실행 파일

위의 전역 변수 중 일반적으로 .bss 섹션에 놓이는 것의 조합은 무엇입니까?

int a = 5;
int b;
static int c = 0;
const int d = 7;
  1. Aa와 b
  2. Bb와 c
  3. Cc와 d
정답과 해설 보기

정답: B. b와 c

a는 0이 아닌 초기값이 있으므로 .data, b는 초기값이 없어 0에서 시작하므로 .bss, c는 초기값 0이므로 파일에 0을 저장할 필요가 없어 .bss에 놓입니다. d는 const 상수이므로 쓰기 금지인 .rodata에 놓입니다. static은 다른 파일에서 보이는지를 정하는 것이며, 어느 섹션에 놓이는지는 초기값과 const로 정해집니다.

링커, 로더, 실행 파일의 다른 문제

  1. C 언어 함수 안에서 선언한, static이 붙지 않은 지역 변수(자동 변수)는 실행 중 어디에 놓입니까?
  2. C 언어의 malloc으로 확보한 메모리는 일반적으로 프로세스의 어느 영역에서 가져옵니까?
  3. Linux 등의 일반적인 프로세스 메모리 배치를 주소가 작은 쪽부터 나열한 것으로 올바른 것은 무엇입니까?
  4. 프로세스의 힙과 스택을 사이에 넓은 빈 공간을 두고 반대 방향으로 늘어나는 배치로 하는 이점으로 올바른 것은 무엇입니까?
  5. 정적 링크의 설명으로 올바른 것은 무엇입니까?

이 분야의 비교

  • 정적 링킹 vs 동적 링킹: 차이점 설명정적 링킹과 동적 링킹을 표로 비교합니다: 링킹 시점, 실행 파일 크기, 메모리 사용, 업데이트, 시작 시간, 배포, 성능, 주요 용도.
  • 스택 vs 힙 메모리: 차이점 설명스택과 힙 메모리를 표로 비교합니다: 용도, 할당, 속도, 수명, 크기 제한, 배치, 단편화, 흔한 오류.
