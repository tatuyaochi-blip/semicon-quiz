링커, 로더, 실행 파일

.bss 섹션의 특징으로 올바른 것은 무엇입니까?

  1. A함수의 지역 변수를 호출될 때마다 두는 영역이다
  2. B초기값이 없는(또는 0인) 변수의 영역이며, 파일에는 크기만 기록하고 읽어 들일 때 0으로 채운다
  3. C상수 문자열을 두는 쓰기 불가 영역이다
정답과 해설 보기

정답: B. 초기값이 없는(또는 0인) 변수의 영역이며, 파일에는 크기만 기록하고 읽어 들일 때 0으로 채운다

초기값을 쓰지 않은 전역 변수나 정적 변수는 C 언어의 규칙상 0에서 시작합니다. 내용이 모두 0이라면 파일에 0을 나열하여 저장하는 것은 낭비이므로, .bss 섹션에는 크기만 기록하고 로더가 메모리를 확보하여 0으로 채웁니다. 예를 들어 'static char buf[1000000];'이 있어도 실행 파일이 1 MB 커지지는 않습니다.

링커, 로더, 실행 파일의 다른 문제

  1. C 언어의 'char *p = "hello"; p[0] = 'H';'를 실행하면 많은 환경에서 비정상 종료됩니다. 그 이유로 올바른 것은 무엇입니까?
  2. 위의 전역 변수 중 일반적으로 .bss 섹션에 놓이는 것의 조합은 무엇입니까?
  3. C 언어 함수 안에서 선언한, static이 붙지 않은 지역 변수(자동 변수)는 실행 중 어디에 놓입니까?
  4. C 언어의 malloc으로 확보한 메모리는 일반적으로 프로세스의 어느 영역에서 가져옵니까?
  5. Linux 등의 일반적인 프로세스 메모리 배치를 주소가 작은 쪽부터 나열한 것으로 올바른 것은 무엇입니까?

  • 정적 링킹 vs 동적 링킹: 차이점 설명정적 링킹과 동적 링킹을 표로 비교합니다: 링킹 시점, 실행 파일 크기, 메모리 사용, 업데이트, 시작 시간, 배포, 성능, 주요 용도.
