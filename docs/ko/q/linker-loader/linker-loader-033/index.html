링커, 로더, 실행 파일

실행 파일에 strip 명령을 사용했을 때 일어나는 일로 올바른 것은?

  1. A기계어 명령이 최적화되어 실행이 빨라진다
  2. B실행 파일이 암호화되어 다른 사람이 실행할 수 없게 된다
  3. C심볼 테이블이나 디버그 정보가 제거되어 파일은 작아지지만, 디버거에서 함수 이름 등이 잘 보이지 않게 된다
정답과 해설 보기

정답: C. 심볼 테이블이나 디버그 정보가 제거되어 파일은 작아지지만, 디버거에서 함수 이름 등이 잘 보이지 않게 된다

실행 파일에는 함수나 변수의 이름을 나열한 심볼 테이블이나, 소스 코드의 줄과의 대응을 나타내는 디버그 정보가 포함되어 있을 수 있습니다. 이것들은 실행에는 필요 없으므로 strip으로 제거하면 파일이 작아집니다. 다만 결함을 조사할 때 함수 이름이나 줄 번호를 볼 수 없게 되므로, 제거하기 전의 정보를 따로 보관해 두기도 합니다. 동적 링크에 필요한 심볼은 남습니다.

  • A. 명령은 바뀌지 않으므로 속도도 변하지 않습니다.
  • B. 암호화는 하지 않습니다.
  • C. 올바릅니다. 실행에 필요하지 않은 정보를 깎아 냅니다.
