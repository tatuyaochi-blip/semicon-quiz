링커, 로더, 실행 파일

C++에서 전역 오브젝트의 생성자가 main보다 먼저 실행되는 구조로 올바른 것은 무엇입니까?

  1. ACPU가 생성자를 찾아 자동으로 먼저 실행한다
  2. Bmain 함수의 첫 줄에 컴파일러가 반드시 모든 생성자를 옮겨 적는다
  3. C생성자를 호출하는 함수의 주소가 .init_array 등의 테이블에 모이고, 기동 코드가 main 앞에서 차례로 호출한다
정답과 해설 보기

정답: C. 생성자를 호출하는 함수의 주소가 .init_array 등의 테이블에 모이고, 기동 코드가 main 앞에서 차례로 호출한다

컴파일러는 각 파일의 전역 오브젝트를 초기화하는 함수를 만들고 그 주소를 .init_array라는 특별한 섹션에 넣습니다. 링커는 모든 파일의 .init_array를 하나의 테이블로 합치고, 기동 코드나 동적 링커가 main 앞에서 이 테이블의 함수를 차례로 호출합니다. 반대로 종료 시 처리는 .fini_array에 모입니다. 파일을 넘나드는 초기화 순서는 정해져 있지 않으므로 의존하지 않도록 주의가 필요합니다.

링커, 로더, 실행 파일의 다른 문제

  1. 컴파일러가 하나의 소스 파일에서 출력하는 오브젝트 파일(.o)에 대해 올바른 것은 무엇입니까?
  2. 링커의 주된 역할로 올바른 것은 무엇입니까?
  3. 링커가 수행하는 심볼 해석의 설명으로 올바른 것은 무엇입니까?
  4. 링커가 수행하는 재배치(relocation)의 설명으로 올바른 것은 무엇입니까?
  5. C 언어 프로그램을 링크했을 때 "undefined reference to `foo'"(foo에 대한 정의되지 않은 참조) 오류가 나왔습니다. 가장 가능성이 높은 원인은 무엇입니까?
