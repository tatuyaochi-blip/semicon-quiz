MEMS와 센서

MEMS 정전 액추에이터에서 2장의 평행한 전극 사이에 가하는 전압을 2배로 하면 전극 사이에 작용하는 정전 인력은 대략 몇 배가 되는가?(전극 간격은 변하지 않는다고 한다)

  1. A1/2배
  2. B2배
  3. C4배
정답과 해설 보기

정답: C. 4배

평행 평판 전극 사이에 작용하는 정전 인력은 F = εAV²/(2d²)이며 전압 V의 제곱에 비례하므로, 전압을 2배로 하면 힘은 4배가 됩니다. 또한 간격 d의 제곱에 반비례하므로 간극을 절반으로 해도 4배가 됩니다. MEMS의 힘은 작아서 수십 µN을 얻는 데에도 수십 V가 필요할 수 있으므로 차지 펌프 등으로 전압을 올려 구동합니다. 부호와 무관하게 인력만 작용한다는 점에도 주의해야 합니다.

MEMS와 센서의 다른 문제

  2. 평행 평판형 정전 액추에이터에서 전압을 올려 가다가 가동 전극이 어느 위치를 넘는 순간 갑자기 고정 전극에 끌려가 달라붙는 현상을 무엇이라 하는가?
  3. MEMS 자이로스코프의 바이어스 안정성(출력의 느린 변동)을 평가하는 데 널리 사용되는 기법은?
