MEMS와 센서

미소한 유로를 칩 위에 만들어, 소량의 액체로 화학 분석이나 검사를 수행하는 기술은?

  1. A마이크로 유체 디바이스(랩온어칩)
  2. B포토마스크
  3. C본딩 와이어
정답과 해설 보기

정답: A. 마이크로 유체 디바이스(랩온어칩)

마이크로 유체 디바이스는 MEMS 가공 기술로 칩 위에 폭 수십~수백 µm의 유로와 혼합부, 반응부를 만들어, µL 이하의 극소량 시료로 분석이나 검사를 수행하는 것입니다. 랩온어칩(lab-on-a-chip)이라고도 하며, 시료와 시약이 적고 반응이 빠르며 휴대 가능한 장치로 만들 수 있어, 코로나19 신속 검사나 혈액 검사, 유전자 분석, 세포 선별 등에 사용됩니다. 재료로는 유리나 실리콘 외에 저렴한 수지(PDMS)도 사용됩니다.

  • A. 올바릅니다. 칩 위의 미소한 유로에서 분석을 수행합니다.
  • B. 포토마스크는 노광으로 회로 패턴을 전사하기 위한 원판입니다.
  • C. 본딩 와이어는 칩과 단자를 잇는 가는 금속선입니다.

MEMS와 센서의 다른 문제

  1. 실내 이산화탄소(CO2) 농도 측정에 자주 사용되는 NDIR 방식 가스 센서의 원리로 올바른 것은?
  2. 스마트폰의 디스플레이 내장 지문 센서나 의료용 초음파 진단에 사용되는 경우가 있는, MEMS로 만드는 초음파 소자는?
  3. 표면 마이크로머시닝에서 구조층에 사용하는 폴리실리콘 등의 박막에 내부 잔류 응력이 크면 어떤 문제가 생기는가?
  4. MEMS 정전 액추에이터에서 평행한 두 전극 사이에 가하는 전압을 2배로 하면, 전극 사이에 작용하는 정전 인력은 대략 몇 배가 되는가? (전극 간격은 변하지 않는다고 한다)
  5. MEMS 가속도 센서의 사양에서 측정 범위(예: ±2 G와 ±16 G)를 고르는 방법으로 올바른 사고방식은?
