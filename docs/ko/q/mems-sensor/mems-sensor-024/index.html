MEMS와 센서

기판 위에 적층한 박막을 가공하여 가동 구조를 만드는 MEMS 가공법은?

  1. A벌크 마이크로머시닝
  2. B표면 마이크로머시닝
  3. C다마신법
정답과 해설 보기

정답: B. 표면 마이크로머시닝

표면 마이크로머시닝은 희생층(SiO2 등)과 구조층(폴리실리콘 등)의 박막을 기판 위에 쌓아 가공하고, 마지막에 희생층을 제거하여 구조를 띄우는 방법으로, 두께 수 µm의 구조를 LSI에 가까운 공정으로 만들 수 있습니다. 기판 자체를 뒷면에서 깊게 깎아 막이나 구멍을 만드는 방법은 벌크 마이크로머시닝이며, KOH에 의한 이방성 식각이나 Deep RIE가 사용되어 압력 센서의 다이어프램 등을 만듭니다.
