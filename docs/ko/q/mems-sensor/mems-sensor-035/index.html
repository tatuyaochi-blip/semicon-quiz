MEMS와 센서

통화 중 얼굴을 가까이 대면 화면을 꺼서 오작동을 방지하기 위해 스마트폰에서 사용되는 센서의 일반적인 원리는?

  1. A소리의 크기를 측정한다
  2. B지자기의 세기를 측정한다
  3. C적외선을 내보내고 물체에 반사되어 돌아오는 빛의 세기를 수광 소자로 검출한다
정답과 해설 보기

정답: C. 적외선을 내보내고 물체에 반사되어 돌아오는 빛의 세기를 수광 소자로 검출한다

근접 센서는 적외선 LED 등에서 940 nm 전후의 눈에 보이지 않는 빛을 내보내고, 가까운 물체(얼굴 등)에 반사되어 돌아오는 빛을 수광 소자로 검출합니다. 반사광이 일정 이상 강하면 물체가 가깝다고 판단하여, 통화 중 화면을 꺼서 터치 오작동을 방지합니다. 주변 광의 영향을 제거하기 위해 LED를 점멸시켜 점등 시와 소등 시의 차를 취합니다. 최근에는 ToF 방식으로 거리를 직접 측정하는 것도 있습니다.
