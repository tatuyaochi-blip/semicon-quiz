  1. A조합할 수 없다
  2. B반드시 같은 칩에 집적해야 한다
  3. C같은 칩에 집적하는 방법과, 별도의 칩을 하나의 패키지에 넣는 방법이 있다
정답과 해설 보기

정답: C. 같은 칩에 집적하는 방법과, 별도의 칩을 하나의 패키지에 넣는 방법이 있다

MEMS와 신호 처리 회로를 같은 칩에 만들어 넣으면 기생 용량이 작고 소형화할 수 있지만, 두 공정을 양립시켜야 하므로 복잡합니다. 각각 최적의 공정으로 칩을 만들어 하나의 패키지에 나란히 놓거나 쌓는 방법도 널리 사용되며, 많은 스마트폰용 센서가 이 방식입니다. 최근에는 MEMS 웨이퍼와 CMOS 웨이퍼를 접합하여 일체화하는 방법도 사용됩니다.
