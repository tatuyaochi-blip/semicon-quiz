MEMS와 센서

스마트워치 등에서 손목으로 심박수를 측정하는 광학식 센서의 원리로 올바른 것은?

  1. A피부의 온도 변화를 측정한다
  2. B팔 움직임의 가속도만으로 계산한다
  3. CLED 빛을 비추고 혈류 변화에 의한 반사광 세기의 변화를 포토다이오드로 검출한다
정답과 해설 보기

정답: C. LED 빛을 비추고 혈류 변화에 의한 반사광 세기의 변화를 포토다이오드로 검출한다

광학식 심박 센서는 녹색 등의 LED 빛을 피부에 비추고, 박동에 맞춰 변하는 혈액량에 의한 반사광 세기의 변화를 포토다이오드로 검출합니다(광용적맥파, PPG). 녹색은 혈액의 헤모글로빈에 잘 흡수되므로 변화가 크게 나타납니다. 신체 움직임에 의한 노이즈는 가속도 센서의 정보로 보정합니다. 적색과 적외선 빛의 흡수 차이를 비교하면 혈중 산소 포화도(SpO2)도 측정할 수 있습니다.

  2. 통화 중 얼굴을 가까이 대면 화면을 꺼서 오작동을 방지하기 위해 스마트폰에서 사용되는 센서의 일반적인 원리는?
  3. MEMS 액추에이터로 사용되는 "빗살형(콤 드라이브)"의 구동 원리로 올바른 것은?
  4. 압전 기판 표면을 전파하는 탄성파를 이용하여 스마트폰 등의 고주파 필터에 사용되는 디바이스는?
  5. 사람이 다가오면 조명을 켜는 인체 감지 센서에 널리 사용되는, 온도 변화에 의해 전하가 발생하는 재료를 이용한 센서는?
