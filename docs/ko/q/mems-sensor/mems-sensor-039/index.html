MEMS와 센서

MEMS의 "에너지 하베스팅(환경 발전)"의 예로 올바른 것은?

  1. A콘센트에서 전력을 얻는다
  2. B주변 진동을 압전체 등으로 전기로 바꿔 센서의 전원으로 삼는다
  3. C배터리를 병렬로 연결하여 용량을 늘린다
정답과 해설 보기

정답: B. 주변 진동을 압전체 등으로 전기로 바꿔 센서의 전원으로 삼는다

에너지 하베스팅은 주변의 진동·열·빛·전파 등 미소한 에너지를 전기로 바꿔 이용하는 기술입니다. MEMS 압전 소자로 기계의 진동을 전기로 바꾸면 얻는 것은 µW~mW 정도이지만, 간헐적으로 동작하는 저전력 무선 센서라면 충분히 구동할 수 있습니다. 공장 설비의 진동 감시, 교량 등 구조물 모니터링, 배터리 교체가 어려운 장소의 IoT 센서 등에서 사용되기 시작했습니다.

  2. 실내 이산화탄소(CO2) 농도 측정에 자주 사용되는 NDIR 방식 가스 센서의 원리로 올바른 것은?
  3. 스마트폰의 화면 내 지문 센서나 의료용 초음파 진단에 사용되기도 하는, MEMS로 만드는 초음파 소자는?
  4. 표면 마이크로머시닝에서 구조층에 사용하는 폴리실리콘 등의 박막 내부에 큰 잔류 응력이 있으면 어떤 문제가 생기는가?
  5. MEMS 정전 액추에이터에서 2장의 평행한 전극 사이에 가하는 전압을 2배로 하면 전극 사이에 작용하는 정전 인력은 대략 몇 배가 되는가?(전극 간격은 변하지 않는다고 한다)
