MEMS와 센서

표면 마이크로머시닝에서 구조층에 사용하는 폴리실리콘 등의 박막 내부에 큰 잔류 응력이 있으면 어떤 문제가 생기는가?

  1. A막의 저항이 0이 된다
  2. B희생층을 제거하여 띄웠을 때 구조가 휘거나 좌굴한다
  3. C막이 투명해진다
정답과 해설 보기

정답: B. 희생층을 제거하여 띄웠을 때 구조가 휘거나 좌굴한다

성막 시 생기는 잔류 응력이 크면, 희생층을 제거하여 구조를 띄웠을 때 압축 응력을 가진 양단 지지 빔은 좌굴하여 물결 모양이 되고, 두께 방향으로 응력 분포가 있으면 캔틸레버 빔이 휩니다. 설계대로의 형상이나 공진 주파수가 나오지 않고, 전극에 닿아 움직이지 않게 되기도 합니다. 폴리실리콘에서는 성막 온도나 어닐링으로 응력을 수십 MPa 이하로 제어하고, 질화막에서는 조성으로 인장 응력으로 조정합니다.

MEMS와 센서의 다른 문제

  1. MEMS 정전 액추에이터에서 2장의 평행한 전극 사이에 가하는 전압을 2배로 하면 전극 사이에 작용하는 정전 인력은 대략 몇 배가 되는가?(전극 간격은 변하지 않는다고 한다)
  2. MEMS 가속도 센서의 사양에서 측정 범위(예: ±2 G와 ±16 G)를 선택하는 올바른 사고방식은?
  3. 평행 평판형 정전 액추에이터에서 전압을 올려 가다가 가동 전극이 어느 위치를 넘는 순간 갑자기 고정 전극에 끌려가 달라붙는 현상을 무엇이라 하는가?
  4. MEMS 자이로스코프의 바이어스 안정성(출력의 느린 변동)을 평가하는 데 널리 사용되는 기법은?
  5. MEMS의 가동판이 아주 가까운 고정면을 향해 움직일 때, 사이에 있는 기체가 밀려나면서 생기는 감쇠를 무엇이라 하는가?
