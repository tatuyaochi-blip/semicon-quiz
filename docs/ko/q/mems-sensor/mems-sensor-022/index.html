정답: A. 가속도 센서

충돌 시의 급격한 감속(수십 G)을 가속도 센서로 검출하고, 그 크기와 시간 변화로부터 십수 ms 이내에 에어백을 전개할지 판정합니다. 1990년대 초 Analog Devices가 MEMS 가속도 센서(ADXL50)를 차량용으로 양산했으며, 소형·저가·고신뢰성이라는 장점으로 MEMS가 보급되는 계기가 되었습니다. 현재는 오작동을 막기 위해 차체 여러 곳의 센서 정보를 조합하여 판정합니다.
