MEMS와 센서

MEMS 자이로스코프의 바이어스 안정성(출력의 느린 변동)을 평가하는 데 널리 사용되는 기법은?

  1. A앨런 분산(앨런 편차) 해석
  2. BC-V 측정
  3. C4탐침법
정답과 해설 보기

정답: A. 앨런 분산(앨런 편차) 해석

앨런 분산은 정지 상태에서 수 시간 기록한 출력을 다양한 평균 시간 τ로 나누고, 이웃한 구간의 평균값 차이의 편차를 조사하는 기법입니다. 양대수 그래프의 기울기로부터, 짧은 시간에서 지배적인 랜덤 잡음(각도 랜덤 워크, 기울기 −1/2)이나 바닥 부분에 나타나는 바이어스 불안정성(°/h) 등의 성분을 나누어 평가할 수 있습니다. 자이로나 가속도 센서, 발진기의 성능 비교에 쓰이는 표준적인 방법입니다.

  • A. 올바릅니다. 앨런 분산으로 잡음과 바이어스 변동을 평가합니다.
  • B. C-V 측정은 MOS 구조 등의 용량을 평가하는 방법입니다.
  • C. 4탐침법은 박막이나 웨이퍼의 저항률을 측정하는 방법입니다.
