MEMS와 센서

스마트폰의 화면 내 지문 센서나 의료용 초음파 진단에 사용되기도 하는, MEMS로 만드는 초음파 소자는?

  1. AVCSEL
  2. BCCD
  3. CPMUT·CMUT(미세 가공 초음파 트랜스듀서)
정답과 해설 보기

정답: C. PMUT·CMUT(미세 가공 초음파 트랜스듀서)

PMUT(압전형)와 CMUT(정전 용량형)는 MEMS 기술로 만드는 초음파 송수신 소자로, 얇은 멤브레인을 진동시켜 초음파를 내고 반사되어 오는 초음파를 검출합니다. 기존의 두꺼운 압전 세라믹 소자와 비교해 반도체 공정으로 다수의 소자를 미세한 피치의 어레이로 배열하고 회로와 일체화할 수 있습니다. 스마트폰의 화면 내 초음파 지문 센서, 손바닥 크기의 초음파 진단 장치, 거리 센서 등에 사용됩니다.

MEMS와 센서의 다른 문제

  1. 표면 마이크로머시닝에서 구조층에 사용하는 폴리실리콘 등의 박막 내부에 큰 잔류 응력이 있으면 어떤 문제가 생기는가?
  2. MEMS 정전 액추에이터에서 2장의 평행한 전극 사이에 가하는 전압을 2배로 하면 전극 사이에 작용하는 정전 인력은 대략 몇 배가 되는가?(전극 간격은 변하지 않는다고 한다)
  3. MEMS 가속도 센서의 사양에서 측정 범위(예: ±2 G와 ±16 G)를 선택하는 올바른 사고방식은?
  4. 평행 평판형 정전 액추에이터에서 전압을 올려 가다가 가동 전극이 어느 위치를 넘는 순간 갑자기 고정 전극에 끌려가 달라붙는 현상을 무엇이라 하는가?
  5. MEMS 자이로스코프의 바이어스 안정성(출력의 느린 변동)을 평가하는 데 널리 사용되는 기법은?
