성능 분석

서버의 사용률(바쁜 시간의 비율)이 100%에 가까워지면 요청의 대기 시간은 어떻게 됩니까?

  1. A급격히 길어진다(사용률이 올라갈수록 증가 폭이 커진다)
  2. B사용률에 비례하여 조금씩 길어진다
  3. C사용률이 높을수록 대기 시간은 짧아진다
정답과 해설 보기

정답: A. 급격히 길어진다(사용률이 올라갈수록 증가 폭이 커진다)

요청이 불규칙하게 도착하는 경우, 서버가 놀고 있는 시간이 있어도 우연히 요청이 겹치면 대기 행렬이 생깁니다. 사용률이 높을수록 놀고 있는 시간이 적어 생긴 행렬이 해소되기 어려워지므로, 대기 시간은 사용률을 ρ라고 할 때 1÷(1−ρ)와 같은 형태로 급격히 늘어납니다. 예를 들어 사용률 50%와 90%에서는 대기 시간에 몇 배의 차이가 납니다. 그래서 응답 속도가 중요한 시스템에서는 사용률에 여유를 남겨 둡니다.

성능 분석의 다른 문제

  3. 함수의 입구와 출구에 시간을 측정하는 코드를 넣어 기록하는 계측(인스트루멘테이션) 방식 프로파일러에 대해 올바른 것은?
  4. 프로그램 성능 분석에서 말하는 핫스팟에 대한 설명으로 올바른 것은?
  5. 프로파일 결과를 나타내는 플레임 그래프의 읽는 법으로 올바른 것은?
