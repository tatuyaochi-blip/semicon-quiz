성능 분석

어떤 프로그램의 명령어 비율이 정수 연산 50%(CPI 1), 로드와 스토어 30%(CPI 2), 분기 20%(CPI 5)였다. 평균 CPI는 얼마입니까?

  1. A2.1
  2. B2.67
  3. C8
정답과 해설 보기

정답: A. 2.1

평균 CPI는 명령어 종류별 CPI에 그 종류가 전체에서 차지하는 비율을 곱하여 합한 것입니다. 0.5×1+0.3×2+0.2×5=0.5+0.6+1.0=2.1이 됩니다. 이 예에서 분기는 전체의 20%인데도 CPI 합계의 절반 가까이를 차지합니다. 어느 종류의 명령어가 시간을 많이 쓰는지 알 수 있으므로 개선할 곳을 찾는 단서가 됩니다.

성능 분석의 다른 문제

  1. CPU 성능을 '1초당 실행할 수 있는 명령어 수(MIPS)'로 비교할 때의 주의점으로 올바른 것은?
  2. 성능 개선을 나타내는 '속도 향상률(스피드업)'을 구하는 방법으로 올바른 것은?
  3. 전체 처리의 50%를 차지하는 부분을 4배 빠르게 했다. 전체의 속도 향상률은 얼마입니까?(암달의 법칙)
  4. 전체 처리의 60%를 차지하는 부분만 빠르게 하여 전체를 2배 빠르게 하고 싶다. 그 부분을 몇 배 빠르게 해야 합니까?
  5. 암달의 법칙에서 얻을 수 있는 성능 개선 방법에 대한 교훈으로 가장 적절한 것은?
