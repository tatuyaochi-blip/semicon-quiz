성능 분석

전체 처리의 50%를 차지하는 부분을 4배 빠르게 했다. 전체 속도 향상률은 얼마인가(암달의 법칙)?

  1. A2배
  2. B1.6배
  3. C4배
정답과 해설 보기

정답: B. 1.6배

개선 후 시간은 빠르게 하지 않은 나머지 50%(0.5)와 4배 빠르게 한 50%(0.5÷4=0.125)의 합인 0.625가 됩니다. 속도 향상률은 1÷0.625=1.6배입니다. 빠르게 한 부분이 아무리 빨라져도 나머지 50%는 그대로 남으므로 전체는 최대 2배밖에 되지 않습니다. 전체를 크게 빠르게 하려면 시간을 많이 차지하는 부분을 찾아 개선해야 합니다.

  • A. 빠르게 한 부분을 0으로 만들어도 2배가 상한입니다.
  • B. 올바릅니다. 1÷(0.5+0.5÷4)=1.6입니다.
  • C. 빠르게 한 것은 전체의 절반뿐입니다.

  2. 암달의 법칙에서 얻을 수 있는, 성능 개선을 진행하는 방법에 대한 교훈으로 가장 적절한 것은?
