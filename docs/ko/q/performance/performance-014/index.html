성능 분석

SPEC CPU와 같은 표준 벤치마크에 대한 설명으로 올바른 것은?

  1. A실제 애플리케이션을 바탕으로 한 다수의 프로그램을 정해진 규칙으로 실행하고, 기준 컴퓨터와의 비를 종합한 값으로 성능을 나타낸다
  2. B덧셈 하나를 몇 번 할 수 있는지만 측정한다
  3. C벤치마크 결과는 제조사가 자유롭게 정해도 된다
정답과 해설 보기

정답: A. 실제 애플리케이션을 바탕으로 한 다수의 프로그램을 정해진 규칙으로 실행하고, 기준 컴퓨터와의 비를 종합한 값으로 성능을 나타낸다

SPEC CPU는 컴파일러, 압축, 물리 시뮬레이션 등 실제 애플리케이션을 바탕으로 한 다수의 프로그램으로 이루어진 벤치마크입니다. 각 프로그램의 실행 시간을 기준 컴퓨터의 시간과 비교한 비를 구하고, 이를 기하평균으로 종합해 하나의 값으로 만듭니다. 컴파일러 설정이나 실행 방법에도 규칙이 있으며, 결과는 자세한 조건과 함께 공개됩니다.

  • A. 올바릅니다. 규칙을 정해 공정하게 비교할 수 있게 합니다.
  • B. 실제 프로그램에 가까운 것을 다수 사용합니다.
  • C. 정해진 규칙으로 측정하고 결과를 보고합니다.

  2. 같은 수의 명령어를 가진 두 프로그램을 하나는 초당 1000백만 명령어, 다른 하나는 500백만 명령어의 속도로 연달아 실행했다. 전체 평균 속도는 얼마인가?
