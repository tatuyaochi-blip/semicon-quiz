성능 분석

SPEC CPU와 같은 표준 벤치마크에 대한 설명으로 올바른 것은?

  1. A실제 애플리케이션을 기반으로 한 다수의 프로그램을 정해진 규칙으로 실행하고, 기준 컴퓨터와의 비를 종합한 값으로 성능을 나타낸다
  2. B하나의 덧셈을 몇 번 할 수 있는지만 측정한다
  3. C벤치마크 결과는 제조사가 자유롭게 정해도 된다
정답과 해설 보기

정답: A. 실제 애플리케이션을 기반으로 한 다수의 프로그램을 정해진 규칙으로 실행하고, 기준 컴퓨터와의 비를 종합한 값으로 성능을 나타낸다

SPEC CPU는 컴파일러, 압축, 물리 시뮬레이션 등 실제 애플리케이션을 기반으로 한 다수의 프로그램으로 이루어진 벤치마크입니다. 각 프로그램의 실행 시간을 기준 컴퓨터의 시간과 비교한 비를 구하고, 그것들을 기하 평균으로 종합하여 하나의 값으로 만듭니다. 컴파일러 설정이나 실행 방법에도 규칙이 있으며, 결과는 상세한 조건과 함께 공개됩니다.

관련 계산 도구

암달의 법칙과 병렬 속도 향상병렬화 비율과 프로세서 수로 암달의 법칙과 구스타프슨의 법칙에 따른 속도 향상률과 병렬 효율 계산

성능 분석의 다른 문제

  1. 여러 벤치마크의 기준 컴퓨터 대비 속도 비를 종합할 때 기하 평균이 자주 사용되는 이유로 올바른 것은?
  2. 같은 수의 명령어를 가진 두 프로그램을 하나는 1000 MIPS(초당 10억 개의 명령어), 다른 하나는 500 MIPS의 속도로 연속해서 실행했다. 전체 평균 속도는 얼마입니까?
  3. 위와 같은 작은 루프로 계산 속도를 측정했더니 N을 크게 해도 시간이 거의 0이었다. 가장 가능성이 높은 원인은?
  4. 프로그램의 실행 시간을 측정할 때 같은 측정을 여러 번 반복하고 처음 몇 번의 결과를 제외하는 경우가 많은 이유로 올바른 것은?
  5. 매우 짧은 처리의 시간을 한 번만 측정하려 할 때의 문제와 대책의 조합으로 올바른 것은?

이 분야의 비교

  • 암달의 법칙과 구스타프슨의 법칙의 차이: 전제·식·스케일링·예 비교병렬화에 의한 속도 향상을 추정하는 암달의 법칙과 구스타프슨의 법칙을 전제, 식, 비율의 측정 방법, 상한, 강한 스케일링과 약한 스케일링, 계산 예 관점에서 표로 비교합니다.
