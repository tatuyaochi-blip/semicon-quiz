성능 분석

CPU 성능을 '1초당 실행할 수 있는 명령어 수(MIPS)'로 비교할 때의 주의점으로 올바른 것은?

  1. A명령어 세트가 다르면 명령어 1개로 할 수 있는 일의 양이 다르므로, 명령어 수가 많아도 같은 프로그램이 빨리 끝난다고는 할 수 없다
  2. B이 값이 큰 CPU는 어떤 프로그램에서도 반드시 빠르다
  3. C이 값은 메모리 용량을 나타낸다
정답과 해설 보기

정답: A. 명령어 세트가 다르면 명령어 1개로 할 수 있는 일의 양이 다르므로, 명령어 수가 많아도 같은 프로그램이 빨리 끝난다고는 할 수 없다

1초당 명령어 수는 알기 쉬운 지표이지만, 명령어 세트가 다르면 같은 일에 필요한 명령어 수가 다릅니다. 단순한 명령어를 많이 사용하는 CPU는 이 값이 커지기 쉽지만 실제 처리가 빠르다고는 할 수 없습니다. 같은 명령어 세트라도 프로그램에 따라 명령어 구성이 다르면 값이 달라집니다. 성능을 비교하는 가장 확실한 방법은 같은 프로그램을 실행하여 시간을 측정하는 것입니다.

성능 분석의 다른 문제

  1. 성능 개선을 나타내는 '속도 향상률(스피드업)'을 구하는 방법으로 올바른 것은?
  2. 전체 처리의 50%를 차지하는 부분을 4배 빠르게 했다. 전체의 속도 향상률은 얼마입니까?(암달의 법칙)
  3. 전체 처리의 60%를 차지하는 부분만 빠르게 하여 전체를 2배 빠르게 하고 싶다. 그 부분을 몇 배 빠르게 해야 합니까?
  4. 암달의 법칙에서 얻을 수 있는 성능 개선 방법에 대한 교훈으로 가장 적절한 것은?
  5. 구스타프슨의 법칙이 나타내는 사고방식으로 올바른 것은?
