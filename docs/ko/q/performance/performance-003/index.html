성능 분석

CPU 설계 변경으로 클럭 주파수는 1.5배가 되었지만 CPI도 1.2배로 늘었다(명령어 수는 동일). 실행 속도는 원래의 몇 배가 되는가?

  1. A1.25배
  2. B1.5배
  3. C1.8배
정답과 해설 보기

정답: A. 1.25배

실행 시간은 명령어 수×CPI÷주파수이므로 새로운 시간은 원래의 1.2÷1.5=0.8배이고, 속도는 1÷0.8=1.25배입니다. 파이프라인을 깊게 하여 주파수를 높이면 분기 예측이 빗나갔을 때의 손실 등으로 CPI가 늘어나는 일이 흔합니다. 주파수만 보면 1.5배처럼 보여도 실제 효과는 1.25배에 그칩니다. 성능은 세 요소의 곱으로 판단해야 합니다.

  • A. 올바릅니다. 1.5÷1.2=1.25입니다.
  • B. CPI가 늘어난 만큼을 고려하지 않았습니다.
  • C. 1.5와 1.2를 곱해 버렸습니다.

성능 분석의 다른 문제

  1. 컴파일러의 새로운 최적화로 실행하는 명령어 수는 20% 줄었지만 평균 CPI가 10% 늘었다(주파수는 동일). 이 최적화의 효과로 올바른 것은?
  2. 어떤 프로그램의 명령어 비율이 정수 연산 50%(CPI 1), 로드와 스토어 30%(CPI 2), 분기 20%(CPI 5)였다. 평균 CPI는 얼마인가?
  3. CPU 성능을 「초당 실행할 수 있는 명령어 수(MIPS, 백만 명령어/초)」로 비교할 때의 주의점으로 올바른 것은?
  4. 성능 개선을 나타내는 「속도 향상률(스피드업)」을 구하는 방법으로 올바른 것은?
  5. 전체 처리의 50%를 차지하는 부분을 4배 빠르게 했다. 전체 속도 향상률은 얼마인가(암달의 법칙)?
