성능 분석

성능 개선을 나타내는 '속도 향상률(스피드업)'을 구하는 방법으로 올바른 것은?

  1. A개선 전 실행 시간 ÷ 개선 후 실행 시간
  2. B개선 후 실행 시간 ÷ 개선 전 실행 시간
  3. C개선 전 실행 시간 − 개선 후 실행 시간
정답과 해설 보기

정답: A. 개선 전 실행 시간 ÷ 개선 후 실행 시간

속도 향상률은 개선 전 시간을 개선 후 시간으로 나눈 값입니다. 예를 들어 10초 걸리던 처리가 4초가 되면 10÷4=2.5배의 속도 향상입니다. '60% 짧아졌다'와 '2.5배 빨라졌다'는 같은 것을 나타내지만 표현을 혼동하기 쉬우므로 주의가 필요합니다. 병렬화의 효과를 보일 때는 코어 1개일 때의 시간을 기준으로 코어 수를 늘렸을 때의 속도 향상률을 나타냅니다.

성능 분석의 다른 문제

  1. 전체 처리의 50%를 차지하는 부분을 4배 빠르게 했다. 전체의 속도 향상률은 얼마입니까?(암달의 법칙)
  2. 전체 처리의 60%를 차지하는 부분만 빠르게 하여 전체를 2배 빠르게 하고 싶다. 그 부분을 몇 배 빠르게 해야 합니까?
  3. 암달의 법칙에서 얻을 수 있는 성능 개선 방법에 대한 교훈으로 가장 적절한 것은?
  4. 구스타프슨의 법칙이 나타내는 사고방식으로 올바른 것은?
  5. 병렬 계산 평가에서 말하는 '강한 스케일링'과 '약한 스케일링'의 차이로 올바른 것은?

이 분야의 비교

  • 암달의 법칙과 구스타프슨의 법칙의 차이: 전제·식·스케일링·예 비교병렬화에 의한 속도 향상을 추정하는 암달의 법칙과 구스타프슨의 법칙을 전제, 식, 비율의 측정 방법, 상한, 강한 스케일링과 약한 스케일링, 계산 예 관점에서 표로 비교합니다.
