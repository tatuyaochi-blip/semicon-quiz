성능 분석

8코어로 병렬 실행했더니 1코어일 때보다 6배 빨라졌다. 병렬 효율은 얼마입니까?

  1. A75%
  2. B133%
  3. C48%
정답과 해설 보기

정답: A. 75%

병렬 효율은 속도 향상률을 코어 수로 나눈 값으로, 코어가 얼마나 유효하게 사용되고 있는지를 나타냅니다. 6÷8=75%이므로 이상(8배)에 대해 4분의 3의 효과를 얻고 있습니다. 나머지 25%는 동기화 대기, 작업 편중, 통신, 메모리 대역폭 경쟁 등으로 손실됩니다. 코어를 늘릴수록 병렬 효율은 떨어지기 쉬우므로, 효율이 어디까지 유지되는지를 보고 사용할 코어 수를 정합니다.

성능 분석의 다른 문제

  1. 성능을 측정하기 위한 장치를 넣은 탓에 측정하려는 프로그램의 동작 자체가 바뀌어 버리는 현상을 무엇이라고 합니까?
  2. 프로그램 성능을 개선할 때의 진행 방식으로 가장 적절한 것은?
  3. 대량의 데이터를 처리하는 프로그램에서 가장 큰 속도 향상을 얻을 가능성이 높은 개선은?
  4. 소프트웨어 개발에서 변경할 때마다 벤치마크를 자동으로 실행하여 결과를 기록해 두는 목적으로 올바른 것은?
  5. 노트북에서 벤치마크를 측정했더니 같은 프로그램인데도 결과가 매번 크게 흔들렸다. CPU 측의 원인으로 생각할 수 있는 것과 그 대책의 조합으로 올바른 것은?
