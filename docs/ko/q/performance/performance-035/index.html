성능 분석

어떤 프로그램이 연산 바운드인지 메모리 바운드인지 확인하는 방법으로 CPU 주파수를 바꿔 실행 시간을 측정했다. 메모리 바운드라면 일반적으로 어떤 결과가 나옵니까?

  1. A주파수에 반비례하여 실행 시간이 짧아진다
  2. B주파수를 올려도 실행 시간이 별로 짧아지지 않는다
  3. C주파수를 올리면 실행 시간이 길어진다
정답과 해설 보기

정답: B. 주파수를 올려도 실행 시간이 별로 짧아지지 않는다

연산 바운드 프로그램은 CPU 안의 연산에 시간을 쓰므로 주파수를 1.5배로 하면 실행 시간은 거의 1/1.5이 됩니다. 메모리 바운드 프로그램은 주기억장치로부터 데이터가 도착하기를 기다리는 시간이 대부분이며, 그 대기 시간은 CPU 주파수를 올려도 변하지 않으므로 실행 시간은 별로 변하지 않습니다. 성능 카운터와 함께 이 성질을 사용하면 어느 쪽 개선에 힘을 쏟아야 하는지 알 수 있습니다.

  2. STREAM 벤치마크로 주로 측정하는 것은?
  3. 병렬 프로그램의 확장성(스케일러빌리티)을 조사하는 방법으로 가장 적절한 것은?
  4. 8코어로 병렬 실행했더니 1코어일 때보다 6배 빨라졌다. 병렬 효율은 얼마입니까?
  5. 성능을 측정하기 위한 장치를 넣은 탓에 측정하려는 프로그램의 동작 자체가 바뀌어 버리는 현상을 무엇이라고 합니까?
