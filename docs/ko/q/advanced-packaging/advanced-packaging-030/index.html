  1. A아무것도 하지 않고 자연스럽게 식기를 기다린다
  2. B패키지를 단열재로 덮는다

정답: C. 냉각판에 액체를 흘리는 방식이나 액침 냉각 등 액체를 이용한 냉각

AI용 GPU 등은 패키지 하나에서 수백 W에서 1 kW를 넘는 전력을 소비하므로 공기 냉각으로는 열을 다 내보낼 수 없게 되었습니다. 공기보다 물이 훨씬 많은 열을 운반할 수 있으므로, 냉각판(콜드 플레이트)에 냉각액을 흘리는 방식이나 서버 전체를 절연성 액체에 담그는 액침 냉각 등의 도입이 진행되고 있습니다. 자연 냉각을 기다리거나 단열하면 온도가 올라 고장 납니다.

첨단 패키징(3D와 칩렛)의 다른 문제

  1. 칩을 수직으로 쌓는 3D 실장의 기본적인 이점으로 올바른 것은?
  2. 프로세서의 연산 성능 향상에 비해 메모리에서 데이터를 공급하는 속도가 따라가지 못해 전체 성능을 제한해 버리는 문제를 무엇이라 하는가?
  3. 스마트폰 메모리 등에 오래전부터 사용되어 온, 여러 개의 칩을 조금씩 어긋나게 쌓고 각각을 와이어 본딩으로 기판에 연결하는 적층 방식은?
  4. 칩렛과 대비하여, 시스템에 필요한 기능을 모두 하나의 큰 칩에 만들어 넣는 종래의 형태를 무엇이라 하는가?
  5. TSV나 미세 재배선층 형성 등 전공정에 가까운 미세 가공 기술을 웨이퍼 상태에서 사용하는 첨단 패키지 공정이 전공정과 후공정의 사이에 해당하기 때문에 불리는 이름은?

이 분야의 비교

  • 2.5D vs 3D 패키징: 칩 집적 방식 비교2.5D와 3D 첨단 패키징을 표로 비교합니다: 구조, 인터커넥트, 대역폭, 발열, 복잡도, HBM과 CoWoS 같은 사례, 각각의 활용 시점.
  • 하이브리드 본딩과 마이크로 범프의 차이: 피치·접속 밀도·평탄도 비교칩을 적층하는 하이브리드 본딩과 마이크로 범프를 솔더 유무, 접속 피치, 접속 밀도, 표면 평탄도, 공정, 전기 특성, 용도 관점에서 표로 비교합니다.
