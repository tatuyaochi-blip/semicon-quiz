첨단 패키징(3D와 칩렛)

칩렛에 대한 설명으로 올바른 것은?

  1. A기능별로 나눈 여러 개의 작은 칩을 하나의 패키지 안에서 연결하여 하나의 시스템으로 동작하게 하는 기술
  2. B웨이퍼 한 장 전체를 하나의 칩으로 사용하는 기술
  3. C패키지 없이 칩을 기판에 직접 솔더링하는 기술
정답과 해설 보기

정답: A. 기능별로 나눈 여러 개의 작은 칩을 하나의 패키지 안에서 연결하여 하나의 시스템으로 동작하게 하는 기술

칩렛은 큰 칩 하나에 모든 기능을 담는 대신, 연산부와 입출력부 등을 각각 작은 칩으로 만들어 패키지 안에서 고밀도로 연결하는 방식입니다. 작은 칩은 결함을 포함할 확률이 낮아 수율이 높고, 기능별로 가장 적합한 제조 공정을 선택할 수 있습니다. 서버용 CPU와 AI용 GPU에서 널리 채택되고 있습니다. 웨이퍼 전체를 사용하는 것은 웨이퍼 스케일, 기판에 직접 붙이는 것은 베어칩 실장입니다.
