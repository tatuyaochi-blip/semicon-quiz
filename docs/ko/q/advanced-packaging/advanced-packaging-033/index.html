첨단 패키징(3D와 칩렛)

스마트폰 메모리 등에 오래전부터 사용되어 온, 여러 개의 칩을 조금씩 어긋나게 쌓고 각각을 와이어 본딩으로 기판에 연결하는 적층 방식은?

  1. ATSV에 의한 적층
  2. B하이브리드 본딩에 의한 적층
  3. C와이어 본딩으로 연결하는 칩 적층(스택드 MCP)
정답과 해설 보기

정답: C. 와이어 본딩으로 연결하는 칩 적층(스택드 MCP)

스택드 MCP에서는 얇게 만든 칩을 계단 모양으로 어긋나게 쌓거나 스페이서를 끼워 쌓고, 각 칩 끝의 전극에서 금속 세선으로 기판에 연결합니다. TSV와 같은 특수한 가공이 필요 없어 저렴하게 만들 수 있으므로 NAND 플래시나 DRAM을 쌓은 메모리 제품에 널리 사용되며, NAND에서는 16장 이상을 쌓기도 합니다. 다만 배선이 길고 개수도 제한되므로, 초고대역폭이 필요한 용도에는 TSV나 하이브리드 본딩이 사용됩니다.

  • A. TSV는 실리콘을 관통하는 전극으로 위아래를 연결하는 방식입니다.
  • B. 하이브리드 본딩은 전극끼리를 직접 접합하는 방식입니다.
  • C. 올바르다. 와이어 본딩으로 각 칩을 연결하는 방식입니다.

  2. TSV나 미세 재배선층 형성 등 전공정에 가까운 미세 가공 기술을 웨이퍼 상태에서 사용하는 첨단 패키지 공정이 전공정과 후공정의 사이에 해당하기 때문에 불리는 이름은?
  3. TSMC의 2.5D 실장 기술로, AI용 GPU와 HBM을 실리콘 인터포저 위에 나란히 놓고 연결하는 용도로 널리 사용되는 것은?
  4. TSMC가 개발한 팬아웃형 웨이퍼 레벨 패키지 기술로, 2016년 스마트폰 프로세서에 채택되어 널리 알려진 것은?
  5. 웨이퍼끼리 통째로 붙이는 웨이퍼 온 웨이퍼(W2W) 접합의 과제로 올바른 것은?

이 분야의 비교

  • 2.5D vs 3D 패키징: 칩 집적 방식 비교2.5D와 3D 첨단 패키징을 표로 비교합니다: 구조, 인터커넥트, 대역폭, 발열, 복잡도, HBM과 CoWoS 같은 사례, 각각의 활용 시점.
  • 하이브리드 본딩과 마이크로 범프의 차이: 피치·접속 밀도·평탄도 비교칩을 적층하는 하이브리드 본딩과 마이크로 범프를 솔더 유무, 접속 피치, 접속 밀도, 표면 평탄도, 공정, 전기 특성, 용도 관점에서 표로 비교합니다.
