I/O 인터페이스와 버스

PAM4를 사용하면 NRZ에 비해 오류 정정(FEC)이 더 중요해지는 이유로 올바른 것은?

  1. APAM4에서는 클록을 추출할 수 없어 매번 오류가 발생하기 때문
  2. B같은 진폭 안에 4단계를 넣으므로 단계 간 간격이 약 1/3이 되어 노이즈로 비트를 오판하기 쉬워지기 때문
  3. CPAM4 신호는 암호화되어 있어 복호 오류를 정정해야 하기 때문
정답과 해설 보기

정답: B. 같은 진폭 안에 4단계를 넣으므로 단계 간 간격이 약 1/3이 되어 노이즈로 비트를 오판하기 쉬워지기 때문

전압 진폭이 같다면 2단계인 NRZ에서는 0과 1 사이에 진폭 전체만큼의 간격이 있지만, 4단계인 PAM4에서는 인접 단계와의 간격이 약 1/3이 됩니다. 노이즈 여유가 약 9.5 dB 작아지므로 비트 오류가 발생하기 쉬워집니다. 그래서 PCI Express 6.0에서는 가벼운 오류 정정 부호를 추가하여 수신 측에서 작은 오류를 정정한 뒤 사용합니다.

  1. x4 PCI Express SSD를 메인보드의 x16 길이 슬롯에 꽂으면 어떻게 되는가(슬롯이 x4 이상의 배선을 가진다고 가정)?
  2. PCI Express의 구성에 대해 올바른 것은?
  3. PCI Express의 통신 구조로 올바른 것은?
  4. PCI Express의 데이터 링크 계층이 전송 중 비트 오류에 대해 수행하는 일로 올바른 것은?
  5. PCI Express 기기의 레지스터나 메모리를 CPU에서 읽고 쓸 수 있게 하는 구조로 올바른 것은?

이 분야의 비교

  • NVMe와 SATA SSD: 속도, 인터페이스, 선택 기준NVMe와 SATA SSD를 표로 비교합니다. 인터페이스, 속도, 지연 시간, 명령 큐, 폼팩터, 전력, 호환성, 가격, 각각에 알맞은 사용자를 다룹니다.
  • DMA vs 프로그램 방식 I/O: 차이점 설명DMA와 프로그램 방식 I/O(PIO)를 표로 비교합니다: 데이터를 옮기는 주체, CPU 부하, 처리량, 설정 비용, 복잡도, 버스 사용, 주요 용도.
  • PCIe 3.0 vs 4.0 vs 5.0 vs 6.0: 속도와 차이점PCIe 3.0, 4.0, 5.0, 6.0을 표로 비교합니다: 전송률, 레인당 및 x4, x16 링크 대역폭, 인코딩, 시그널링, 주요 장치.
