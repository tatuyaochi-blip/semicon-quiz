I/O 인터페이스와 버스

PCI Express 링크의 절전 기능(ASPM에 의한 L0s나 L1 상태)에 대해 올바른 것은?

  1. A데이터를 보내지 않는 동안 링크를 낮은 전력 상태로 하지만, 원래 상태로 복귀하는 데 시간이 걸려 지연이 늘어날 수 있다
  2. B링크 속도를 높여 소비 전력을 늘리는 기능이다
  3. C절전 상태에서도 데이터 송수신 속도는 전혀 변하지 않는다
정답과 해설 보기

정답: A. 데이터를 보내지 않는 동안 링크를 낮은 전력 상태로 하지만, 원래 상태로 복귀하는 데 시간이 걸려 지연이 늘어날 수 있다

SerDes는 데이터를 보내지 않는 동안에도 신호를 유지하기 위해 전력을 사용합니다. ASPM에서는 한동안 주고받음이 없으면 링크를 L0s나 L1이라는 낮은 전력 상태로 만들어 송수신 회로의 일부를 멈춥니다. L1이 전력은 더 작아지지만 복귀하는 데 걸리는 시간이 길어집니다. 노트북에서는 배터리 지속 시간을 위해 사용하고, 지연을 중시하는 서버에서는 꺼 두기도 합니다.
