I/O 인터페이스와 버스

AXI 버스트 전송의 장점으로 올바른 것은?

  1. A데이터를 압축하여 보내므로 보내는 양이 줄어든다
  2. B전송마다 주소를 다시 확인하므로 오류가 없어진다
  3. C한 번의 주소로 연속된 주소의 여러 데이터를 보낼 수 있어 주소를 보내는 부담이 줄고 대역폭을 효과적으로 사용할 수 있다
정답과 해설 보기

정답: C. 한 번의 주소로 연속된 주소의 여러 데이터를 보낼 수 있어 주소를 보내는 부담이 줄고 대역폭을 효과적으로 사용할 수 있다

캐시 라인 읽기처럼 연속된 주소의 데이터를 한꺼번에 다루는 경우가 많으므로, AXI는 시작 주소와 길이만 보내고 데이터를 연속으로 전달하는 버스트 전송을 할 수 있습니다. 데이터마다 주소를 보낼 필요가 없으므로 주소 채널을 비워 둘 수 있고, 데이터 채널을 쉬지 않고 사용할 수 있습니다. DRAM도 버스트로 읽고 쓰는 것이 특기이므로 궁합이 좋은 방식입니다.
