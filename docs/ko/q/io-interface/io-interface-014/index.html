I/O 인터페이스와 버스

PCI Express의 구성에 대해 올바른 것은?

  1. A모든 기기가 1개의 공유 버스에 연결되어 한 번에 하나의 기기만 사용할 수 있다
  2. B기기끼리 무선으로 연결된다
  3. CCPU 측 루트 컴플렉스에서 스위치를 거쳐 각 기기(엔드포인트)로 점대점 접속으로 트리 형태로 연결된다
정답과 해설 보기

정답: C. CPU 측 루트 컴플렉스에서 스위치를 거쳐 각 기기(엔드포인트)로 점대점 접속으로 트리 형태로 연결된다

예전 PCI는 여러 기기가 1개의 버스를 공유하고 사용 권한을 다투는 방식이었습니다. PCI Express에서는 CPU나 메모리와 연결되는 루트 컴플렉스를 뿌리로 하여 스위치로 분기하며, 각 링크는 두 기기만 잇는 점대점 접속입니다. 링크마다 대역폭을 독점할 수 있으므로 기기가 늘어나도 서로 대역폭을 빼앗기 어렵고 신호 품질도 유지하기 쉽습니다.

I/O 인터페이스와 버스의 다른 문제

  2. PCI Express의 데이터 링크 계층이 전송 중 비트 오류에 대해 수행하는 일로 올바른 것은?
  3. PCI Express 기기의 레지스터나 메모리를 CPU에서 읽고 쓸 수 있게 하는 구조로 올바른 것은?
  4. PCI Express에서 사용되는 MSI(메시지 시그널 인터럽트)의 특징으로 올바른 것은?
  5. 인터페이스 성능을 나타내는 "대역폭"과 "지연(레이턴시)"의 차이로 올바른 것은?

이 분야의 비교

  • NVMe와 SATA SSD: 속도, 인터페이스, 선택 기준NVMe와 SATA SSD를 표로 비교합니다. 인터페이스, 속도, 지연 시간, 명령 큐, 폼팩터, 전력, 호환성, 가격, 각각에 알맞은 사용자를 다룹니다.
  • DMA vs 프로그램 방식 I/O: 차이점 설명DMA와 프로그램 방식 I/O(PIO)를 표로 비교합니다: 데이터를 옮기는 주체, CPU 부하, 처리량, 설정 비용, 복잡도, 버스 사용, 주요 용도.
  • PCIe 3.0 vs 4.0 vs 5.0 vs 6.0: 속도와 차이점PCIe 3.0, 4.0, 5.0, 6.0을 표로 비교합니다: 전송률, 레인당 및 x4, x16 링크 대역폭, 인코딩, 시그널링, 주요 장치.
