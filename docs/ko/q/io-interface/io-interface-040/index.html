I/O 인터페이스와 버스

직렬 전송의 속도를 높일수록 같은 길이의 기판 배선으로 신호를 보내기가 어려워져 중간에 리타이머 등을 넣기도 합니다. 그 주된 이유는 무엇입니까?

  1. A배선의 손실은 주파수가 높을수록 커지므로 빠른 신호일수록 도달하기까지 크게 약해지기 때문
  2. B빠른 신호는 배선 안을 빛보다 빠르게 진행해 버리기 때문
  3. C빠른 신호일수록 배선의 저항이 0에 가까워져 전류가 너무 많이 흐르기 때문
정답과 해설 보기

정답: A. 배선의 손실은 주파수가 높을수록 커지므로 빠른 신호일수록 도달하기까지 크게 약해지기 때문

배선에서는 표피 효과에 의한 도체 손실과 기판 재료에 의한 유전체 손실이 모두 주파수와 함께 증가합니다. 속도를 2배로 하면 같은 길이에서도 신호가 크게 약해져 수신 측 이퀄라이저만으로는 보상할 수 없게 됩니다. 그래서 손실이 작은 기판 재료를 사용하거나, 중간에 리타이머를 넣어 신호를 일단 수신한 뒤 깨끗한 신호로 다시 보냅니다.

  • A. 올바릅니다. 리타이머는 신호를 다시 받아 재송신합니다.
  • B. 빛보다 빠르게 진행하는 일은 없습니다.
  • C. 주파수가 높을수록 손실은 오히려 증가합니다.

I/O 인터페이스와 버스의 다른 문제

  1. 고속 직렬 전송의 요구 사항으로 「비트 오류율(BER)이 10의 -12승 이하」라고 되어 있을 때의 의미로 올바른 것은 무엇입니까?
  2. 고속 신호 배선에서 배선의 특성 임피던스를 송수신 회로와 맞추는(정합을 취하는) 목적으로 올바른 것은 무엇입니까?
  3. 100기가비트 이더넷 같은 고속 연결이 예를 들어 25 Gb/s 레인 4개를 묶어 만들어지기도 합니다. 이 발상으로 올바른 것은 무엇입니까?
  4. PCI Express 등에서 사용되는 스프레드 스펙트럼 클록(SSC)의 목적으로 올바른 것은 무엇입니까?
  5. PCI Express의 1레인이 「전이중」이라는 것의 의미로 올바른 것은 무엇입니까?

이 분야의 비교

  • NVMe와 SATA SSD: 속도, 인터페이스, 선택 기준NVMe와 SATA SSD를 표로 비교합니다. 인터페이스, 속도, 지연 시간, 명령 큐, 폼팩터, 전력, 호환성, 가격, 각각에 알맞은 사용자를 다룹니다.
  • DMA vs 프로그램 방식 I/O: 차이점 설명DMA와 프로그램 방식 I/O(PIO)를 표로 비교합니다: 데이터를 옮기는 주체, CPU 부하, 처리량, 설정 비용, 복잡도, 버스 사용, 주요 용도.
  • PCIe 3.0 vs 4.0 vs 5.0 vs 6.0: 속도와 차이점PCIe 3.0, 4.0, 5.0, 6.0을 표로 비교합니다: 전송률, 레인당 및 x4, x16 링크 대역폭, 인코딩, 시그널링, 주요 장치.
