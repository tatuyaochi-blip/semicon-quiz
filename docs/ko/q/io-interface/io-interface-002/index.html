I/O 인터페이스와 버스

고속 직렬 전송에서 사용되는 SerDes(시리얼라이저/디시리얼라이저)의 역할로 올바른 것은 무엇입니까?

  1. A데이터를 암호화하여 엿보기를 막는다
  2. B송신 측에서 칩 내부의 병렬 데이터를 1개의 빠른 비트열로 바꾸고, 수신 측에서 원래의 병렬 데이터로 되돌린다
  3. C전원 전압을 다른 회로에 맞게 변환한다
정답과 해설 보기

정답: B. 송신 측에서 칩 내부의 병렬 데이터를 1개의 빠른 비트열로 바꾸고, 수신 측에서 원래의 병렬 데이터로 되돌린다

칩 내부에서 데이터는 수십 비트 폭으로 느리게 움직입니다. SerDes의 송신 측은 이를 1개의 매우 빠른 비트열로 재배열하여 내보내고, 수신 측은 비트열에서 클록을 추출해 비트를 판정한 뒤 원래 폭의 데이터로 되돌립니다. PCI Express, USB, 이더넷, 스토리지 연결 등 많은 고속 인터페이스의 물리 계층은 SerDes로 구성됩니다.

  • A. 암호화 회로가 아닙니다.
  • B. 올바릅니다. 직렬 전송의 송수신 중심이 되는 회로입니다.
  • C. 전원 변환과는 관계가 없습니다.

I/O 인터페이스와 버스의 다른 문제

  1. 고속 직렬 전송에서 2개의 선에 반대 방향의 신호를 흘리는 차동 신호가 사용되는 주된 이유는 무엇입니까?
  2. 고속 직렬 전송의 수신 측에 있는 클록 데이터 리커버리(CDR) 회로의 역할로 올바른 것은 무엇입니까?
  3. 직렬 전송에서 8b/10b 부호화(8비트 데이터를 10비트 부호로 만들어 보내는 방식)가 사용되어 온 목적으로 올바른 것은 무엇입니까?
  4. 8b/10b 부호화를 사용하는 전송로의 신호 속도가 5 Gb/s일 때, 데이터로서 보낼 수 있는 실효 속도는 얼마입니까?
  5. PCI Express 3.0 이후 채택된 128b/130b 부호화의 효율에 가장 가까운 것은 무엇입니까?
