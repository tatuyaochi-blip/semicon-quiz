AXI4-Stream의 특징으로 올바른 것은?

  1. A메모리 주소를 지정하여 랜덤하게 읽고 쓰기 위한 규격이다
  2. B주소를 갖지 않고 데이터를 한 방향으로 계속 흘리기 위한 규격으로, 영상이나 신호 처리 파이프라인에 적합하다
  3. C칩 외부의 디스플레이에 연결하기 위한 커넥터 규격이다
정답과 해설 보기

정답: B. 주소를 갖지 않고 데이터를 한 방향으로 계속 흘리기 위한 규격으로, 영상이나 신호 처리 파이프라인에 적합하다

영상 필터나 통신 신호 처리처럼 데이터가 처리 단계에서 단계로 순서대로 흘러가는 회로에서는 주소가 필요 없습니다. AXI4-Stream은 데이터와 VALID·READY 절차만 가지고, 패킷의 끝을 나타내는 신호 등을 붙여 한 방향으로 계속 흘릴 수 있게 한 규격입니다. FPGA 설계에서도 처리 블록을 연결하는 데 자주 사용됩니다.
