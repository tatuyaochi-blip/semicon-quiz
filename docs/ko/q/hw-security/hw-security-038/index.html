하드웨어 보안

하드웨어 트로이에 대한 대책에 해당하지 않는 것은 무엇입니까?

  1. A칩을 출하한 뒤에 소프트웨어 업데이트로 트로이 회로를 삭제한다
  2. B설계 데이터나 사용하는 IP를 신뢰할 수 있는 상대로부터만 받고, 변경을 엄격하게 관리한다
  3. C정상 칩과 비교하여 소비 전력이나 지연 등 특성의 차이를 조사한다
정답과 해설 보기

정답: A. 칩을 출하한 뒤에 소프트웨어 업데이트로 트로이 회로를 삭제한다

하드웨어 트로이는 회로로 만들어 넣어진 것이므로 출하 후에 제거할 수 없습니다. 대책은 신뢰할 수 있는 설계 도구나 IP, 제조 위탁처를 선택하기, 설계 데이터의 변경을 기록하고 확인하기, 제조한 칩의 일부를 분해하여 설계와 비교하기, 정상 칩과의 소비 전력이나 지연 차이를 조사하기, 중요한 부분을 서로 다른 공장에서 제조하기 등을 조합하여 수행합니다.

하드웨어 보안의 다른 문제

  1. 반도체 유통에서 문제가 되는 위조 칩(리마크 제품 등)의 위험으로 올바른 것은 무엇입니까?
  2. 제품으로 출하하는 기기에서 JTAG 등의 디버그용 포트를 비활성화하거나 인증이 필요하게 하는 이유로 올바른 것은 무엇입니까?
  3. IC 카드 등 보안용 칩에 요구되는 내탬퍼성(tamper resistance)의 설명으로 올바른 것은 무엇입니까?
  4. 칩 안에 키를 기록하여 저장하는 방법으로 일반적으로 사용되는 것은 무엇입니까?
  5. CPU에 AES 암호 전용 명령(AES-NI 등)을 갖추는 이점으로, 속도 외에 꼽을 수 있는 것은 무엇입니까?
