키 보관에 PUF를 사용하는 이점으로 올바른 것은 무엇입니까?

  1. A키 값을 이용자가 자유롭게 고를 수 있다
  2. B키가 전원을 꺼도 반드시 메모리에 남는다
  3. C키를 비휘발성 메모리에 기록해 둘 필요 없이 사용할 때만 만들어 내므로, 칩을 분석당해도 꺼내기 어렵다
정답과 해설 보기

정답: C. 키를 비휘발성 메모리에 기록해 둘 필요 없이 사용할 때만 만들어 내므로, 칩을 분석당해도 꺼내기 어렵다

키를 플래시나 eFuse에 기록해 두면 칩을 열어 저장 내용을 직접 읽어내는 공격의 대상이 됩니다. PUF를 사용하면 키는 칩의 물리적 성질로부터 사용할 때마다 만들어지고, 전원이 꺼져 있는 동안에는 어디에도 저장되어 있지 않습니다. 또한 PUF 값을 읽으려고 칩을 가공하면 편차의 성질 자체가 바뀌어 버리므로, 추출은 더욱 어려워집니다.
