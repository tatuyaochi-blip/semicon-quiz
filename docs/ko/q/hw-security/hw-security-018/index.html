하드웨어 보안

콜드 부트 공격이 성립하는 이유와 대표적인 대책의 조합으로 올바른 것은 무엇입니까?

  1. ADRAM은 전원을 끄면 순식간에 완전히 사라진다. 전원을 켜 둔 채로 둔다
  2. BDRAM은 따뜻하게 하면 내용을 읽기 쉬워진다. 냉각 장치를 단다
  3. CDRAM의 내용은 전원을 꺼도 수 초~수 분 남고, 차갑게 하면 더 오래 남는다. 메모리 내용을 암호화해 둔다
정답과 해설 보기

정답: C. DRAM의 내용은 전원을 꺼도 수 초~수 분 남고, 차갑게 하면 더 오래 남는다. 메모리 내용을 암호화해 둔다

DRAM 셀의 전하는 리프레시가 없어져도 곧바로 사라지지 않고, 수 초에서 수 분은 내용이 상당히 남으며 저온에서는 더 오래 남습니다. 전원을 끈 직후의 PC에서 메모리를 꺼내 다른 기기로 읽으면 디스크 암호화 키 등이 발견될 수 있습니다. 메모리 내용을 회로에서 암호화하거나, 전원을 끌 때 키를 지우거나, 키를 CPU 안에만 두는 등의 대책이 있습니다.

하드웨어 보안의 다른 문제

  1. 시큐어 부트의 설명으로 올바른 것은 무엇입니까?
  2. 시큐어 부트의 '루트 오브 트러스트(신뢰의 기점)'로서 칩 안에 두는 것으로 가장 적절한 것은 무엇입니까?
  3. 시큐어 부트에서 소프트웨어 서명 확인에 공개 키 암호를 사용하는 이점으로 올바른 것은 무엇입니까?

  5. PC 등에 탑재되는 TPM(신뢰 플랫폼 모듈)의 주된 역할로 올바른 것은 무엇입니까?
