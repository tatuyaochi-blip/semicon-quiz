하드웨어 보안

투기적 실행 취약점에 대한 대책에 관해 일반적으로 올바른 것은 무엇입니까?

  1. A대책을 넣어도 성능은 전혀 변하지 않는다
  2. B투기적 실행이나 캐시 공유를 제한할수록 안전해지지만 성능이 떨어지므로, 안전과 성능의 균형을 고려하여 선택한다
  3. C투기적 실행을 없애면 CPU는 빨라진다
정답과 해설 보기

정답: B. 투기적 실행이나 캐시 공유를 제한할수록 안전해지지만 성능이 떨어지므로, 안전과 성능의 균형을 고려하여 선택한다

투기적 실행, 분기 예측, 공유 캐시는 현재 CPU의 높은 성능을 뒷받침하는 구조입니다. 이것들을 제한하면 유출되는 정보는 줄지만 그만큼 성능이 떨어집니다. 그래서 OS, 컴파일러, CPU 설계에서는 지켜야 할 정보와 위협의 크기에 따라 어디까지 대책을 넣을지 선택하고 있습니다. 새로운 CPU에서는 성능 영향이 작은 대책을 회로에 내장하는 노력이 진행되고 있습니다.
