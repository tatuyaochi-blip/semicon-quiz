오류 주입 공격에 대한 대책에 해당하지 않는 것은 무엇입니까?

  1. A전압이나 클럭의 이상을 검출하는 센서를 두고, 이상이 있으면 처리를 멈춘다
  2. B처리를 빠르게 하기 위해 중요한 확인을 한 번만 한다
  3. C중요한 계산을 두 번 하거나 역계산으로 확인하여, 결과가 일치하지 않으면 출력하지 않는다
정답과 해설 보기

정답: B. 처리를 빠르게 하기 위해 중요한 확인을 한 번만 한다

오류 주입은 한 번의 오동작으로 방어를 뚫으려 하므로, 확인을 한 번만 하면 그곳이 약점이 됩니다. 대책으로는 전압, 클럭, 빛을 검출하는 센서, 중요한 계산이나 비교를 반복하여 결과를 대조하는 중복화, 오동작을 발견하면 키를 지우는 반응 등이 있습니다. 소프트웨어에서도 중요한 분기를 이중으로 확인하거나, 성공과 실패의 값을 비트 차이가 큰 값으로 하는 등의 노력을 합니다.
