하드웨어 트로이가 일반적인 테스트에서 발견되기 어려운 주된 이유는 무엇입니까?

  1. A하드웨어 트로이는 칩 바깥에 부착되어 있기 때문에
  2. B하드웨어 트로이는 테스트 장비를 망가뜨리기 때문에
  3. C매우 드문 입력이나 조건(트리거)일 때만 동작하도록 만들어져 있어, 평소에는 정상 회로와 똑같이 동작하기 때문에

정답: C. 매우 드문 입력이나 조건(트리거)일 때만 동작하도록 만들어져 있어, 평소에는 정상 회로와 똑같이 동작하기 때문에

제조 테스트는 설계대로의 기능이 올바르게 동작하는지 확인하는 것입니다. 하드웨어 트로이는 특정 32비트 값이 입력되었을 때, 어떤 카운터가 수십억 회에 도달했을 때 등 테스트에서는 거의 일어나지 않는 조건에서만 동작하도록 만들어지므로 평소에는 정상으로 보입니다. 회로 규모도 전체 수십억 개의 트랜지스터에 비해 극히 일부로 충분하므로 외관 검사로 발견하기도 어렵습니다.
