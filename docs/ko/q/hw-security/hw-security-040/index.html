정답: C. 디버그 포트로는 메모리나 레지스터의 읽기/쓰기, 프로그램 정지가 가능하므로, 그대로 두면 펌웨어나 키를 도난당하거나 변조될 수 있기 때문에

JTAG나 SWD 같은 디버그 포트는 개발 중에 칩 내부를 자유롭게 조사할 수 있는 강력한 도구입니다. 제품에 그대로 남아 있으면 공격자가 기판 단자에 장비를 연결하여 펌웨어를 읽어내거나, 시큐어 부트를 건너뛰거나, 키를 꺼낼 수 있습니다. 출하 시에 eFuse로 비활성화하거나, 암호 인증을 통과한 경우에만 사용할 수 있게 하는 등의 대책을 취합니다.

하드웨어 보안의 다른 문제

  1. IC 카드 등 보안용 칩에 요구되는 내탬퍼성(tamper resistance)의 설명으로 올바른 것은 무엇입니까?
  2. 칩 안에 키를 기록하여 저장하는 방법으로 일반적으로 사용되는 것은 무엇입니까?
  3. CPU에 AES 암호 전용 명령(AES-NI 등)을 갖추는 이점으로, 속도 외에 꼽을 수 있는 것은 무엇입니까?
  4. 암호 처리를 '정시간(constant-time)'으로 구현할 때 지켜야 할 것으로 올바른 것은 무엇입니까?
  5. 캐시 사이드 채널에 대한 대책으로, 공유 캐시를 분할(파티셔닝)하는 개념으로 올바른 것은 무엇입니까?
