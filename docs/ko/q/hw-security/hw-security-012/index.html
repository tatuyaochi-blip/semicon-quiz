하드웨어 보안

암호 처리를 하는 칩의 소비 전력 파형을 이용하는 전력 분석 중 차분 전력 분석(DPA)의 특징으로 올바른 것은 무엇입니까?

  1. A많은 처리의 전력 파형을 모아 통계적으로 처리하여, 한 번의 파형으로는 보이지 않는 키와 관련된 작은 차이를 추출한다
  2. B한 번의 전력 파형을 눈으로 보는 것만으로 키를 모두 알 수 있다
  3. C칩의 전원을 끄고 키를 꺼낸다
정답과 해설 보기

정답: A. 많은 처리의 전력 파형을 모아 통계적으로 처리하여, 한 번의 파형으로는 보이지 않는 키와 관련된 작은 차이를 추출한다

CMOS 회로는 신호가 전환될 때 전력을 사용하므로, 다루는 데이터에 따라 소비 전력이 미세하게 달라집니다. 단순 전력 분석은 한 번의 파형 모양에서 처리 흐름을 읽어내지만, 차분 전력 분석은 수천 번의 암호 처리 파형을 모아 키 후보별로 예상한 중간 값과 파형의 상관을 계산하여 올바른 키를 찾습니다. 노이즈에 묻힌 작은 차이도 통계로 추출할 수 있는 것이 특징입니다.

하드웨어 보안의 다른 문제

  2. 전자파를 이용한 사이드 채널 분석의 특징으로 올바른 것은 무엇입니까?
  3. 오류 주입 공격(fault injection)의 설명으로 올바른 것은 무엇입니까?
  4. 오류 주입 공격에 대한 대책에 해당하지 않는 것은 무엇입니까?
  5. DRAM 로우해머(Rowhammer)에 대한 대책에 해당하는 것은 무엇입니까?
