정답: A. 한 대를 분석당해 키를 빼앗겨도 다른 기기의 안전으로 번지지 않도록 하기 위해

모든 기기가 같은 키를 가지고 있으면, 공격자가 한 대를 입수하여 시간과 비용을 들여 키를 꺼내면 같은 제품의 모든 기기가 위험해집니다. 기기마다 다른 키를 갖게 해 두면 한 대가 뚫려도 피해는 그 기기에 그치고, 그 키만 무효화하면 됩니다. PUF나 eFuse에 대한 기록, 제조 시의 키 주입 등으로 기기별 키를 안전하게 갖게 합니다.
