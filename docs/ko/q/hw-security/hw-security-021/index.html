하드웨어 보안

시큐어 부트에서 소프트웨어 서명 확인에 공개 키 암호를 사용하는 이점으로 올바른 것은 무엇입니까?

  1. A기기에는 확인용 공개 키만 두면 되고, 서명을 만드는 개인 키는 개발사가 엄중히 보관할 수 있으므로, 기기를 분석당해도 위조 서명을 만들 수 없다
  2. B공개 키 암호는 공통 키 암호보다 반드시 빠르기 때문에
  3. C공개 키는 비밀로 해 두어야 하기 때문에
정답과 해설 보기

정답: A. 기기에는 확인용 공개 키만 두면 되고, 서명을 만드는 개인 키는 개발사가 엄중히 보관할 수 있으므로, 기기를 분석당해도 위조 서명을 만들 수 없다

공통 키로 확인하는 방식에서는 확인에 쓰는 키로 서명도 만들 수 있으므로, 한 대의 기기에서 키를 꺼내면 모든 기기용 위조 소프트웨어를 만들 우려가 있습니다. 공개 키 암호라면 기기에는 확인에만 쓸 수 있는 공개 키를 두고, 서명을 만드는 개인 키는 개발사의 안전한 설비 안에만 둘 수 있습니다. 공개 키가 알려져도 위조 서명은 만들 수 없습니다.
