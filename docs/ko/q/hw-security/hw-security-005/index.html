캐시를 이용한 사이드 채널 공격이 성립하는 주된 이유는 무엇입니까?

  1. A캐시는 프로세스 간에 공유되는 경우가 있어, 다른 프로세스가 어떤 데이터를 사용했는지가 자신의 접근 속도(히트 또는 미스)의 차이로 관찰되기 때문에
  2. B캐시의 내용은 누구나 직접 읽어낼 수 있기 때문에
  3. C캐시는 데이터를 암호화하지 않고 디스크에 저장하기 때문에
정답과 해설 보기

정답: A. 캐시는 프로세스 간에 공유되는 경우가 있어, 다른 프로세스가 어떤 데이터를 사용했는지가 자신의 접근 속도(히트 또는 미스)의 차이로 관찰되기 때문에

캐시에 들어 있는 데이터는 빠르게, 들어 있지 않은 데이터는 느리게 읽힙니다. 공격자가 공유 캐시의 일부를 자신의 데이터로 채워 두고 나중에 그 읽기 시간을 측정하면, 다른 프로세스가 그 위치를 사용해 자신의 데이터가 밀려났는지를 알 수 있습니다. 암호 처리가 키에 따라 다른 테이블 위치를 읽는 경우, 이 방법으로 키 정보가 유출됩니다.
