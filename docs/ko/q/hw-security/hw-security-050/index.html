하드웨어 보안

CPU의 하드웨어 취약점이 발견되었을 때 출하된 CPU에서 이루어지는 대책의 하나로 올바른 것은 무엇입니까?

  1. A모든 CPU를 회수하여 트랜지스터를 하나씩 교체한다
  2. BCPU 마이크로코드를 업데이트하여 문제가 있는 내부 동작을 바꾸거나, OS가 사용할 수 있는 새로운 제어 기능을 추가한다
  3. CCPU 표면의 인쇄를 바꾼다
정답과 해설 보기

정답: B. CPU 마이크로코드를 업데이트하여 문제가 있는 내부 동작을 바꾸거나, OS가 사용할 수 있는 새로운 제어 기능을 추가한다

많은 CPU는 복잡한 명령의 실행이나 일부 내부 제어를 갱신할 수 있는 마이크로코드로 수행합니다. 취약점이 발견되면 CPU 회사는 마이크로코드 업데이트를 배포하고, BIOS나 OS를 통해 기동할 때마다 읽어 들이게 합니다. 이로써 문제가 있는 동작을 억제하거나, 분기 예측기를 비우는 명령 등 새로운 제어를 추가할 수 있습니다. 회로 자체의 문제는 다음 세대 CPU에서 근본적으로 고칩니다.
