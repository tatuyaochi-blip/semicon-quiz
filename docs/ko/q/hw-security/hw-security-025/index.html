원격 증명(리모트 어테스테이션)의 설명으로 올바른 것은 무엇입니까?

  1. A멀리 있는 사람이 기기의 화면을 보고 조작한다
  2. B기기의 위치를 GPS로 서버에 알린다
  3. C기기가 자신 안에서 실행 중인 소프트웨어의 상태를, 칩 안의 키로 서명한 형태로 원격 서버에 제시하여 신뢰할 수 있는지 확인받는다
정답과 해설 보기

정답: C. 기기가 자신 안에서 실행 중인 소프트웨어의 상태를, 칩 안의 키로 서명한 형태로 원격 서버에 제시하여 신뢰할 수 있는지 확인받는다

원격 증명에서는 기기가 TPM이나 TEE에 기록된 소프트웨어 측정 값을, 칩 안에서 꺼낼 수 없는 키로 서명하여 서버에 보냅니다. 서버는 서명과 측정 값을 확인하고, 정해진 소프트웨어로 동작하는 기기에만 비밀 데이터나 서비스를 제공합니다. 클라우드에 기밀 계산을 맡길 때나 기업 네트워크에 연결하는 기기를 확인할 때 등에 사용됩니다.
