시큐어 부트와 측정 부트(Measured Boot)의 차이로 올바른 것은 무엇입니까?

  1. A둘은 같은 것이며 부르는 이름만 다르다
  2. B시큐어 부트는 올바르지 않은 소프트웨어의 기동을 막고, 측정 부트는 기동한 소프트웨어의 해시 값을 TPM 등에 기록하여 나중에 상태를 확인할 수 있게 한다
  3. C측정 부트는 기동에 걸리는 시간을 측정하기만 하는 기능이다
정답과 해설 보기

정답: B. 시큐어 부트는 올바르지 않은 소프트웨어의 기동을 막고, 측정 부트는 기동한 소프트웨어의 해시 값을 TPM 등에 기록하여 나중에 상태를 확인할 수 있게 한다

측정 부트에서는 기동의 각 단계에서 다음 소프트웨어의 해시 값을 계산하여 TPM 레지스터(PCR)에 쌓아 가듯이 기록합니다. PCR은 이전 값과 새 해시 값을 조합해서만 갱신할 수 있으므로 기록을 위조할 수 없습니다. 기동 자체는 막지 않지만, 기록된 값을 보면 어떤 소프트웨어가 기동했는지를 나중에 확인하거나 원격 서버에 증명할 수 있습니다.
