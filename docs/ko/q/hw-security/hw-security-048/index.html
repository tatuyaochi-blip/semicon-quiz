하드웨어 보안

하드웨어와 소프트웨어 보안에서 중시되는 「다층 방어(defense in depth)」의 개념으로 올바른 것은?

  1. A가장 강력한 대책 하나만 고르고 나머지는 모두 생략한다
  2. B하나의 대책이 뚫려도 전체가 뚫리지 않도록, 성질이 다른 여러 대책을 겹쳐 둔다
  3. C아무 대책도 하지 않고 공격당한 뒤에 생각한다
정답과 해설 보기

정답: B. 하나의 대책이 뚫려도 전체가 뚫리지 않도록, 성질이 다른 여러 대책을 겹쳐 둔다

어떤 대책에도 아직 알려지지 않은 약점이 있을 수 있습니다. 다층 방어에서는 보안 부트, 메모리 보호, TEE, 암호화, 사이드 채널 대책, 물리적 내탬퍼성 등 성질이 다른 대책을 겹쳐서, 하나가 뚫려도 다음 층에서 지킬 수 있게 합니다. 공격자에게 모든 층을 동시에 뚫는 데 드는 수고와 비용이 커지는 것이 전체의 안전으로 이어집니다.

  • A. 하나가 뚫리면 전체가 뚫려 버립니다.
  • B. 올바릅니다. 완전한 대책은 하나로 만들 수 없다는 전제입니다.
  • C. 사전 대책이 필요합니다.

하드웨어 보안의 다른 문제

  1. 많은 기기를 제조할 때, 모든 기기에 같은 키를 넣지 않고 기기마다 다른 키를 갖게 하는 이유로 올바른 것은?
  2. CPU의 하드웨어 취약점이 발견되었을 때, 출하된 CPU에 대해 이루어지는 대책의 하나로 올바른 것은?
  3. 하드웨어 보안에서 다루는 문제의 설명으로 가장 적절한 것은?
  4. 사이드 채널 공격(side-channel attack)의 설명으로 올바른 것은?
  5. 타이밍 공격(timing attack)이 성립하는 원리와 대표적인 대책의 조합으로 올바른 것은?
