하드웨어 보안

Spectre와 같은 투기적 실행 취약점에 대한 대책으로 사용되는 것에 해당하지 않는 것은?

  1. A위험한 분기 뒤에 투기적 실행을 멈추는 배리어 명령을 넣는다
  2. BCPU 클록 주파수를 높인다
  3. C배열 인덱스를 범위 안으로 제한하는 마스크 처리를 하여 범위 밖을 투기적으로 읽지 못하게 한다
정답과 해설 보기

정답: B. CPU 클록 주파수를 높인다

Spectre 대책에는 조건 분기 뒤에 투기적 실행을 멈추는 명령(x86의 lfence 등)을 넣는 방법, 인덱스를 마스크하여 범위 밖을 읽지 못하게 하는 방법, 간접 분기 예측이 악용되지 않도록 하는 작성 방식(retpoline 등), CPU 마이크로코드 업데이트로 예측기를 제어하는 방법 등이 있습니다. 투기적 실행을 전부 멈추면 성능이 크게 떨어지므로, 위험한 곳에 한정해 사용하는 것이 일반적입니다.

  • A. 이것은 실제로 사용되는 대책입니다.
  • B. 올바릅니다. 주파수는 투기와 관계가 없습니다.
  • C. 이것은 실제로 사용되는 대책입니다.
