하드웨어 보안

PC 등에 탑재되는 TPM(신뢰 플랫폼 모듈)의 주된 역할로 올바른 것은 무엇입니까?

  1. A화면 표시를 빠르게 하기 위한 전용 회로
  2. BCPU 냉각을 관리하는 부품
  3. C키를 안전하게 생성하고 보관하며, 기동한 소프트웨어의 기록을 유지하여 그 상태를 증명하는 등의 보안 기능을 제공한다
정답과 해설 보기

정답: C. 키를 안전하게 생성하고 보관하며, 기동한 소프트웨어의 기록을 유지하여 그 상태를 증명하는 등의 보안 기능을 제공한다

TPM은 키의 생성과 보관, 암호 처리, 난수 생성, 기동한 소프트웨어의 해시 값 기록 등을 수행하는, 외부에서 변조되기 어려운 보안용 칩(또는 CPU에 내장된 기능)입니다. 예를 들어 기동 상태가 올바를 때만 디스크 암호화 키를 꺼낼 수 있게 하면, 디스크를 빼내거나 부트 소프트웨어를 바꿔 쓰더라도 데이터를 읽기 어려워집니다.

하드웨어 보안의 다른 문제

  1. 시큐어 부트와 측정 부트(Measured Boot)의 차이로 올바른 것은 무엇입니까?
  2. 원격 증명(리모트 어테스테이션)의 설명으로 올바른 것은 무엇입니까?
  3. TEE(신뢰 실행 환경)의 설명으로 올바른 것은 무엇입니까?
  4. Arm TrustZone의 기본 구조로 올바른 것은 무엇입니까?
  5. Intel SGX와 같은 '엔클레이브' 방식 TEE의 특징으로 올바른 것은 무엇입니까?

이 분야의 비교

  • 보안 부팅과 측정 부팅의 차이: 서명 검증·TPM 기록·증명 비교보안 부팅과 측정 부팅을 한 장의 표로 비교합니다. 무엇을 확인하는지, 멈추는지 기록하는지, 신뢰의 근간, 변조되었을 때의 동작, 필요한 것, 결과의 활용, 한계와 조합 방법을 정리합니다.
  • TPM·HSM·시큐어 엘리먼트의 차이: 위치·용도·키 보호 방식·인증 비교TPM, HSM, 시큐어 엘리먼트를 한 장의 표로 비교합니다. 위치, 주된 목적, 대표 사용자, 키 보호 방식, 암호 처리 성능, 내탬퍼성과 인증(FIPS 140-3, Common Criteria…
  • TrustZone·SGX·SEV/TDX의 차이: 격리 단위·신뢰 범위·메모리 암호화 비교Arm TrustZone, Intel SGX 엔클레이브, AMD SEV와 Intel TDX의 기밀 VM을 한 장의 표로 비교합니다. 격리 단위, 무엇으로부터 지키는지, 신뢰해야 하는 범위(TCB)…
