하드웨어 보안

PC 등에 탑재되는 TPM(신뢰 플랫폼 모듈, Trusted Platform Module)의 주된 역할로 올바른 것은?

  1. A화면 표시를 빠르게 하기 위한 전용 회로
  2. BCPU 냉각을 관리하는 부품
  3. C키를 안전하게 생성·보관하고, 부팅한 소프트웨어의 기록을 유지하여 그 상태를 증명하는 등의 보안 기능을 제공한다
정답과 해설 보기

정답: C. 키를 안전하게 생성·보관하고, 부팅한 소프트웨어의 기록을 유지하여 그 상태를 증명하는 등의 보안 기능을 제공한다

TPM은 키의 생성과 보관, 암호 처리, 난수 생성, 부팅한 소프트웨어의 해시 값 기록 등을 수행하는, 외부에서 변조되기 어려운 보안용 칩(또는 CPU에 내장된 기능)입니다. 예를 들어 부팅 상태가 올바를 때만 디스크 암호화 키를 꺼낼 수 있게 하면, 디스크를 빼내거나 부팅 소프트웨어를 바꿔도 데이터를 읽히기 어려워집니다.

  • A. 표시 회로가 아닙니다.
  • B. 냉각 부품이 아닙니다.
  • C. 올바릅니다. 디스크 암호화 키의 보호 등에도 사용됩니다.
