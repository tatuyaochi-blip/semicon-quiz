OS와 하드웨어

인터럽트 벡터 테이블의 역할로 올바른 것은?

  1. A인터럽트가 발생한 횟수를 종류별로 기록해 둔다
  2. B인터럽트나 예외의 종류별로 처리를 시작할 주소를 정해 둔다
  3. C다음에 어떤 프로세스를 실행할지의 순서를 기록해 둔다
정답과 해설 보기

정답: B. 인터럽트나 예외의 종류별로 처리를 시작할 주소를 정해 둔다

인터럽트나 예외가 발생하면 CPU는 그 원인에 대응하는 번호(벡터 번호)를 얻어 인터럽트 벡터 테이블에서 핸들러의 시작 주소를 읽고 그곳으로 처리를 옮깁니다. 표의 내용은 OS가 부팅 시 설정하며, 타이머, 각 장치, 페이지 폴트, 시스템 콜 등에서 서로 다른 핸들러를 호출할 수 있게 합니다. 횟수를 세는 것은 통계를 위한 별도의 구조이고, 실행할 프로세스의 순서는 OS의 스케줄러가 관리합니다.
