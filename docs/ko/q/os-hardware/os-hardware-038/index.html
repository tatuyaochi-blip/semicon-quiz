OS와 하드웨어

준가상화(파라버추얼라이제이션)에 대한 설명으로 올바른 것은?

  1. A가상 머신의 OS를 전혀 변경하지 않고 실제 하드웨어의 장치를 모두 그대로 재현한다
  2. B가상 머신의 OS가 가상화되어 있음을 전제로 하이퍼바이저용 효율적인 절차를 사용한다
  3. C하이퍼바이저를 사용하지 않고 하나의 OS 안에서 여러 애플리케이션을 실행한다
정답과 해설 보기

정답: B. 가상 머신의 OS가 가상화되어 있음을 전제로 하이퍼바이저용 효율적인 절차를 사용한다

실제 장치를 세부까지 재현하면 장치 레지스터에 접근할 때마다 하이퍼바이저로의 전환이 일어나 느려집니다. 준가상화에서는 게스트 OS에 가상화용 드라이버를 넣고 공유 메모리의 큐로 요청을 모아 주고받는 등, 가상화되어 있음을 전제로 한 효율적인 절차를 사용합니다. 가상 디스크와 가상 네트워크 장치에서 널리 사용됩니다. OS를 바꾸지 않고 장치를 완전히 재현하는 것은 완전 가상화의 개념입니다.
