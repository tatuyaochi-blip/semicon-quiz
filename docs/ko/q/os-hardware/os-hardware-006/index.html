OS와 하드웨어

CPU가 인터럽트를 받아들였을 때의 일반적인 처리 흐름으로 올바른 것은?

  1. A실행 중인 프로그램을 폐기하고 처음부터 다시 실행한다
  2. B인터럽트 핸들러를 실행한 후 원래 프로그램으로 돌아가지 않고 다음 프로그램을 시작한다
  3. C실행 중인 위치와 상태를 저장하고 인터럽트 핸들러를 실행한 뒤 저장한 위치로 돌아간다
정답과 해설 보기

정답: C. 실행 중인 위치와 상태를 저장하고 인터럽트 핸들러를 실행한 뒤 저장한 위치로 돌아간다

인터럽트를 받아들이면 CPU는 다음에 실행할 예정이던 명령의 주소와 동작 모드 등의 상태를 저장하고, 인터럽트 벡터 테이블 등으로 정해진 인터럽트 핸들러로 이동합니다. 핸들러는 필요한 레지스터를 저장하고 처리를 수행한 뒤, 끝나면 상태를 복원하여 중단된 곳에서 원래 프로그램을 재개합니다. 프로그램을 폐기하거나 처음부터 다시 실행하지 않습니다. 핸들러 후에 다른 프로세스로 전환되기도 하지만 그것은 OS의 판단입니다.
