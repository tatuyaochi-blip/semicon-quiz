OS와 하드웨어

가상 머신의 OS가 특권이 필요한 명령을 실행했을 때 하이퍼바이저로 처리가 넘어가고, 하이퍼바이저가 그 명령의 효과를 대신 재현하는 방식을 무엇이라고 합니까?

  1. A트랩 앤 에뮬레이트
  2. B카피 온 라이트
  3. C디맨드 페이징
정답과 해설 보기

정답: A. 트랩 앤 에뮬레이트

가상 머신의 OS는 하드웨어를 직접 조작하는 것으로 알고 특권 명령을 실행하지만, 실제로는 특권이 낮은 모드에서 실행되고 있으므로 예외(트랩)가 발생합니다. 하이퍼바이저는 그것을 받아 그 가상 머신에게 올바른 결과가 되도록 명령의 효과를 재현(에뮬레이트)하고 가상 머신으로 돌려보냅니다. CPU의 가상화 지원 기능은 이러한 전환을 빠르고 확실하게 수행할 수 있게 합니다. 카피 온 라이트와 디맨드 페이징은 메모리 관리 방식입니다.

OS와 하드웨어의 다른 문제

  1. 준가상화(파라버추얼라이제이션)에 대한 설명으로 올바른 것은?
  2. 컨테이너와 가상 머신의 차이로 올바른 것은?
  3. 많은 OS에서 커널 영역을 각 프로세스 주소 공간의 일부(예를 들어 상위 범위)에 할당해 두고 페이지 테이블의 보호 비트로 사용자 모드로부터의 접근을 금지합니다. 이 배치의 주된 장점은?
  4. 페이지 크기가 4 KB일 때 가상 주소 중 페이지 내 위치(오프셋)를 나타내는 것은 몇 비트입니까?
  5. 페이지 크기가 4 KB일 때 32비트 가상 주소 0x00403ABC의 페이지 번호와 페이지 내 오프셋의 조합으로 올바른 것은?

이 분야의 비교

  • 프로세스 vs 스레드: 차이점 설명프로세스와 스레드를 표로 비교합니다: 메모리, 생성 비용, 컨텍스트 스위칭, 통신, 격리, 동기화, 대표 용도.
  • 사용자 모드와 커널 모드의 차이점 정리사용자 모드와 커널 모드를 표로 비교합니다. 실행할 수 있는 명령어, 접근할 수 있는 메모리, 전환 계기, 전환 비용, 오류의 영향, 보호의 목적을 다룹니다.
