OS와 하드웨어

메모리 접근 시간이 100 ns, 페이지 폴트 처리에 8 ms가 걸릴 때, 100만 번에 한 번 페이지 폴트가 일어나면 평균 접근 시간은 대략 얼마입니까?

  1. A약 108 ns
  2. B약 100 ns
  3. C약 8 ms
정답과 해설 보기

정답: A. 약 108 ns

평균 접근 시간은 (1 − p) × 100 ns + p × 8 ms이며, p = 10⁻⁶이므로 대략 100 ns + 10⁻⁶ × 8,000,000 ns = 100 + 8 = 108 ns가 됩니다. 100만 번에 한 번이라는 낮은 빈도에서도 평균이 8% 느려질 만큼 페이지 폴트 처리는 무겁다는 것을 알 수 있습니다. 약 100 ns는 페이지 폴트의 영향을 무시한 값이고, 약 8 ms는 페이지 폴트가 매번 일어난 경우의 값입니다.
