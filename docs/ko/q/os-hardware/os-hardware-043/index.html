OS와 하드웨어

RISC-V 특권 아키텍처에서 정해진 주요 동작 모드의 조합으로 올바른 것은?

  1. A머신 모드, 슈퍼바이저 모드, 사용자 모드
  2. B리얼 모드, 프로텍트 모드, 롱 모드
  3. C어드레스 모드, 데이터 모드, 명령 모드
정답과 해설 보기

정답: A. 머신 모드, 슈퍼바이저 모드, 사용자 모드

RISC-V 특권 아키텍처에서는 가장 특권이 높은 머신 모드(M), OS 커널이 동작하는 슈퍼바이저 모드(S), 애플리케이션이 동작하는 사용자 모드(U)가 정해져 있습니다. 머신 모드는 반드시 구현되며, 전원 투입 직후나 펌웨어가 여기에서 동작합니다. 작은 마이컴에서는 M과 U만, OS를 실행하는 경우에는 M·S·U를 갖는 것이 일반적이며, 가상화 확장에서는 하이퍼바이저용 모드가 추가됩니다. 리얼·프로텍트·롱 모드는 x86의 용어입니다.

  3. NMI(마스크 불가능 인터럽트)에 대한 설명으로 올바른 것은?

  5. 프로그램이 OS가 할당하지 않은 주소에 접근했을 때 일반적으로 일어나는 일은?
