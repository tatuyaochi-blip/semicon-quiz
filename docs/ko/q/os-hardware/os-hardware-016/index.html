OS와 하드웨어

페이지 테이블의 각 항목에 보통 포함되는 정보의 조합으로 올바른 것은?

  1. A물리 페이지 번호와 유효·보호·참조·수정 비트
  2. B해당 페이지의 데이터 내용 자체와 마지막으로 기록한 시각
  3. C해당 페이지를 사용하는 프로세스의 이름과 사용한 시간의 합계
정답과 해설 보기

정답: A. 물리 페이지 번호와 유효·보호·참조·수정 비트

페이지 테이블 항목에는 대응하는 물리 페이지 번호 외에, 그 페이지가 물리 메모리에 있는지 나타내는 유효 비트, 읽기·쓰기·실행 및 사용자 모드 접근의 허가, 하드웨어가 설정하는 접근됨(참조) 비트와 수정됨(더티) 비트가 들어 있습니다. OS는 참조 비트로 페이지 교체를 판단하고, 더티 비트로 내보낼 때 다시 쓸 필요가 있는지 판단합니다. 데이터 내용이나 프로세스 이름은 들어 있지 않습니다.

OS와 하드웨어의 다른 문제

  1. 프로세스를 복제할 때 카피 온 라이트를 사용하는 장점으로 올바른 것은?
  2. 디맨드 페이징에 대한 설명으로 올바른 것은?
  3. 페이지 교체의 클록 방식(세컨드 찬스 방식)에서 각 페이지의 참조 비트를 사용하는 목적은?
  4. 페이지 교체에서 FIFO 방식을 사용하면 물리 메모리의 페이지 수를 늘렸는데도 페이지 폴트가 늘어나는 경우가 있습니다. 이 현상을 무엇이라고 합니까?
  5. 물리 메모리가 부족하여 페이지를 내보내고 읽어 들이는 일만 계속되어 처리가 거의 진행되지 않는 상태를 무엇이라고 합니까?
