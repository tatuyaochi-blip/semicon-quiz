OS와 하드웨어

페이지 테이블의 역할로 올바른 것은?

  1. A가상 주소의 페이지 번호를 물리 주소의 페이지 번호에 대응시킨다
  2. B물리 메모리에 있는 데이터의 내용을 페이지별로 복제하여 저장한다
  3. C실행 중인 프로세스의 우선순위를 페이지 순서대로 정렬하여 관리한다
정답과 해설 보기

정답: A. 가상 주소의 페이지 번호를 물리 주소의 페이지 번호에 대응시킨다

가상 메모리에서는 프로그램이 사용하는 가상 주소를 실제 물리 메모리의 주소로 변환하여 사용합니다. 페이지 테이블은 가상 페이지 번호마다 대응하는 물리 페이지 번호와 읽기·쓰기 허가 등의 보호 정보를 기록한 표로, OS가 프로세스마다 만들고 CPU의 MMU가 참조합니다. 자주 쓰는 변환 결과는 TLB에 보관됩니다. 데이터 내용 자체를 복제하거나 프로세스 우선순위를 관리하는 표가 아닙니다.

OS와 하드웨어의 다른 문제

  1. 페이지 폴트가 일어나는 경우로 올바른 것은?
  2. 내보내져 디스크에 있는 페이지에 접근하여 페이지 폴트가 일어났을 때 OS가 수행하는 처리 흐름으로 올바른 것은?
  3. 페이지 테이블을 1단이 아니라 다단(계층형)으로 하는 주된 이유는?
  4. 가상 주소가 32비트, 페이지 크기가 4 KB, 페이지 테이블 1항목이 4바이트일 때 1단 페이지 테이블의 크기는 얼마입니까?
  5. 가상 주소 중 48비트를 사용하고, 페이지 크기 4 KB, 각 단의 표가 512항목(9비트)인 다단 페이지 테이블에서는 몇 단의 표를 거쳐야 합니까?

이 분야의 비교

  • 프로세스 vs 스레드: 차이점 설명프로세스와 스레드를 표로 비교합니다: 메모리, 생성 비용, 컨텍스트 스위칭, 통신, 격리, 동기화, 대표 용도.
  • 사용자 모드와 커널 모드의 차이점 정리사용자 모드와 커널 모드를 표로 비교합니다. 실행할 수 있는 명령어, 접근할 수 있는 메모리, 전환 계기, 전환 비용, 오류의 영향, 보호의 목적을 다룹니다.
