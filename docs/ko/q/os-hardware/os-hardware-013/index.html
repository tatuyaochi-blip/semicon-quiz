OS와 하드웨어

페이지 테이블을 1단이 아니라 다단(계층형)으로 하는 주된 이유는?

  1. A사용하지 않는 범위의 표를 생략할 수 있어 페이지 테이블의 메모리를 절약할 수 있기 때문에
  2. B주소 변환 시마다 읽는 표의 수가 줄어 TLB 미스 처리가 빨라지기 때문에
  3. C물리 메모리 용량을 가상 주소 공간보다 크게 할 수 있기 때문에
정답과 해설 보기

정답: A. 사용하지 않는 범위의 표를 생략할 수 있어 페이지 테이블의 메모리를 절약할 수 있기 때문에

1단 페이지 테이블에서는 사용 여부와 관계없이 가상 주소 공간의 모든 페이지 몫의 항목이 필요하여, 64비트 환경에서는 표가 거대해집니다. 다단으로 하면 사용 중인 범위의 하위 표만 만들고 사용하지 않는 범위는 상위 표의 항목을 무효로 해 둘 수 있어, 프로그램이 사용하는 양에 맞는 메모리로 충분합니다. 그 대신 TLB 미스 때 거치는 표의 수가 단수만큼 늘어 느려집니다. 물리 메모리의 크기와는 관계가 없습니다.
