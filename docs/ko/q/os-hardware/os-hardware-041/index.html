OS와 하드웨어

페이지 크기가 4 KB일 때 가상 주소 중 페이지 내 위치(오프셋)를 나타내는 것은 몇 비트입니까?

  1. A4비트
  2. B12비트
  3. C22비트
정답과 해설 보기

정답: B. 12비트

4 KB = 4096바이트 = 2¹²바이트이므로 페이지 내 각 바이트를 구별하려면 12비트가 필요합니다. 가상 주소의 하위 12비트는 페이지 내 위치로서 그대로 물리 주소에 사용되고, 나머지 상위 비트가 페이지 번호로서 페이지 테이블이나 TLB에서 변환됩니다. 4비트는 '4 KB'의 4에 끌린 오답이고, 22비트는 4 MB 페이지인 경우의 값입니다. 하위 12비트가 변환되지 않는다는 점은 캐시 설계에도 이용됩니다.

  2. RISC-V 특권 아키텍처에서 정해진 주요 동작 모드의 조합으로 올바른 것은?
