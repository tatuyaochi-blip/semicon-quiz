OS와 하드웨어

한 대의 컴퓨터 위에서 여러 OS를 각각 독립된 가상 머신으로 동시에 실행하기 위한 소프트웨어를 무엇이라고 합니까?

  1. A컴파일러
  2. B디바이스 드라이버
  3. C하이퍼바이저
정답과 해설 보기

정답: C. 하이퍼바이저

하이퍼바이저(가상 머신 모니터)는 CPU, 메모리, 장치를 여러 가상 머신에 나누어 주어, 각 OS가 자기 전용 컴퓨터를 사용하는 것처럼 보이게 합니다. 가상 머신끼리는 격리되므로 하나가 고장나도 다른 쪽에 영향을 주기 어려워 클라우드 서버에서 널리 사용됩니다. CPU의 가상화 지원 기능과 중첩 페이징이 그 성능을 뒷받침합니다. 컴파일러는 프로그램 번역, 디바이스 드라이버는 장치 조작을 담당합니다.

OS와 하드웨어의 다른 문제

  1. 하이퍼바이저의 유형에 대한 설명으로 올바른 것은?
  2. 중첩 페이징(2단 주소 변환)을 사용한 가상화에서 하드웨어가 수행하는 주소 변환에 대한 설명으로 올바른 것은?
  3. 게스트도 호스트도 4단 페이지 테이블을 사용하는 중첩 페이징에서 TLB 미스가 일어났을 때 최악의 경우 몇 번의 메모리 접근이 필요합니까?
  4. 가상 머신의 OS가 특권이 필요한 명령을 실행했을 때 하이퍼바이저로 처리가 넘어가고, 하이퍼바이저가 그 명령의 효과를 대신 재현하는 방식을 무엇이라고 합니까?
  5. 준가상화(파라버추얼라이제이션)에 대한 설명으로 올바른 것은?
