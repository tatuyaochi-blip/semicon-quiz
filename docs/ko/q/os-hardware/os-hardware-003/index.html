OS와 하드웨어

위 RISC-V 코드의 마지막 ecall 명령이 실행되었을 때 일어나는 일로 올바른 것은?

li   a7, 64      # システムコールの番号
li   a0, 1       # 引数1
la   a1, msg     # 引数2
li   a2, 13      # 引数3
ecall
  1. A지정한 번호의 주소로 특권 모드를 유지한 채 일반 함수 호출로 분기한다
  2. B인터럽트가 금지되고 다음 인터럽트가 올 때까지 CPU가 정지한다
  3. C예외로 특권 모드로 전환되어 커널의 처리가 실행된다
정답과 해설 보기

정답: C. 예외로 특권 모드로 전환되어 커널의 처리가 실행된다

ecall은 의도적으로 예외를 일으키는 명령입니다. CPU는 현재 명령의 주소를 저장하고 더 높은 특권 모드로 전환하여 OS가 설정한 예외 처리 입구로 진행합니다. 커널은 a7의 번호로 어떤 시스템 콜인지 판단하고 a0~a2를 인수로 처리한 뒤 결과를 돌려주고 사용자 모드로 돌아갑니다. 사용자 모드에서 커널 함수로 직접 분기할 수는 없으며, CPU를 정지시키는 것은 wfi 같은 다른 명령입니다.
