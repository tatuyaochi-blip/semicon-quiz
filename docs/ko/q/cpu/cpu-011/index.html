  2. B명령어 세트 아키텍처(ISA)

정답과 해설 보기

정답: B. 명령어 세트 아키텍처(ISA)

ARM, x86, RISC-V는 명령어 세트 아키텍처(ISA)의 이름으로, 프로세서가 이해하는 명령어의 종류, 레지스터, 메모리를 다루는 방식 등 소프트웨어와 하드웨어 사이의 약속을 정합니다. 같은 ISA라면 설계한 기업이 달라도 같은 프로그램이 동작합니다. x86은 Intel과 AMD가 PC와 서버에서, ARM은 스마트폰과 Apple의 Mac에서, RISC-V는 임베디드를 중심으로 확산되고 있습니다.
