폰 노이만형 컴퓨터의 특징으로 올바른 것은?

  1. A명령어와 데이터를 반드시 별도의 메모리에 둔다
  2. B배선을 바꿔 연결하는 방식으로 프로그램을 변경한다
  3. C프로그램(명령어)과 데이터를 같은 주기억장치에 저장하고 명령어를 차례로 읽어 실행한다
정답과 해설 보기

정답: C. 프로그램(명령어)과 데이터를 같은 주기억장치에 저장하고 명령어를 차례로 읽어 실행한다

폰 노이만형(프로그램 내장 방식)에서는 명령어와 데이터를 같은 주기억장치에 두고 CPU가 명령어를 차례로 읽어 실행합니다. 프로그램을 데이터로서 고쳐 쓸 수 있는 유연성이 강점이며 현재 컴퓨터의 기본입니다. 한편 명령어와 데이터가 같은 경로를 두고 다투는 것이 속도의 제약이 되며, 이를 폰 노이만 병목이라고 합니다. 그래서 많은 CPU는 L1 캐시를 명령어용과 데이터용으로 나눕니다(하버드형의 사고방식).
