CPU와 아키텍처

CPU의 프로그램 카운터(PC)가 보유하고 있는 것은?

  1. A다음에 실행할 명령어의 주소
  2. B실행한 명령어의 총수
  3. CCPU의 온도
정답과 해설 보기

정답: A. 다음에 실행할 명령어의 주소

프로그램 카운터는 다음에 인출하여 실행할 명령어의 메모리상 주소를 보유하는 레지스터입니다. 보통은 명령어를 하나 실행할 때마다 명령어 길이만큼(예: 4바이트) 증가하며, 분기나 점프 명령어에서는 점프 목적지 주소로, 인터럽트에서는 인터럽트 처리의 시작 주소로 바뀝니다. 함수 호출에서는 복귀 주소로서 현재 값이 스택이나 링크 레지스터에 저장됩니다.

  • A. 정답입니다. 다음에 실행할 명령어의 주소를 보유합니다.
  • B. 실행한 명령어의 수를 세는 것은 성능 카운터 등입니다.
  • C. 온도는 센서로 측정하는 것이며 프로그램 카운터와는 관계가 없습니다.
