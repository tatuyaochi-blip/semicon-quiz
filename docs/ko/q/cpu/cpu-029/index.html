CPU와 아키텍처

1클록당 실행할 수 있는 명령어 수를 나타내는 지표는?

  1. AIPC
  2. BCPI
  3. CTDP
정답과 해설 보기

정답: A. IPC

IPC(Instructions Per Clock)는 1클록당 평균 실행 명령어 수로 CPI의 역수입니다. 성능은 「IPC × 클록 주파수」에 비례하므로 주파수가 같다면 IPC가 클수록 빠릅니다. 슈퍼스칼라, 비순차 실행, 분기 예측, 큰 캐시는 모두 IPC를 높이는 기술입니다. 최근에는 주파수의 상승이 둔화되었기 때문에 세대별 성능 향상은 IPC 개선에 의존하는 부분이 커지고 있습니다.
