CPU와 아키텍처

프로그램의 성능이 연산 성능과 메모리 대역폭 중 어느 쪽에 의해 제한되는지를 연산 강도(1바이트당 연산 수)를 가로축으로 하여 도시하는 모델은?

  1. A암달의 법칙
  2. B루프라인 모델
  3. C푸아송 모델
정답과 해설 보기

정답: B. 루프라인 모델

루프라인 모델에서는 가로축에 연산 강도(메모리에서 1바이트를 읽을 때의 연산 수), 세로축에 성능을 잡습니다. 연산 강도가 낮은 처리는 메모리 대역폭에서 한계에 부딪히고(비스듬한 선), 높은 처리는 최대 연산 성능에서 한계에 부딪힙니다(수평선). 예를 들어 대역폭 1 TB/s, 연산 성능 100 TFLOPS라면 연산 강도 100 FLOP/바이트 미만인 처리는 메모리 율속입니다. 개선 방침(데이터 재사용인지 연산 효율화인지)을 판단하는 데 쓰입니다.

  • A. 암달의 법칙은 병렬화할 수 없는 부분에 의한 고속화의 한계를 나타냅니다.
  • B. 정답입니다. 연산 성능과 메모리 대역폭의 제약을 도시하는 모델입니다.
  • C. 푸아송 모델은 수율 계산 등에 쓰입니다.

  2. 캐시 메모리를 두는 주된 목적으로 올바른 것은?
  3. 폰 노이만형 컴퓨터의 특징으로 올바른 것은?
  4. 하나의 칩에 여러 프로세서 코어를 탑재하는(멀티코어화) 주된 목적은?
  5. RISC(축소 명령어 세트 컴퓨터)의 특징으로 올바른 것은?

이 분야의 비교

  • RISC와 CISC의 차이와 대표 예시RISC와 CISC 명령어 집합 구조를 표로 비교합니다. 명령어 길이, 메모리 접근, 레지스터, 디코딩, 코드 크기, ARM, RISC-V, x86 같은 예시를 다룹니다.
  • ARM vs RISC-V vs x86: 명령어 집합 구조 비교ARM, RISC-V, x86을 표로 비교합니다: 설계 방식, 명령어 길이, 라이선스, 레지스터, 생태계, 강점, 주요 용도.
  • 폰 노이만 vs 하버드 아키텍처: 차이점 설명폰 노이만과 하버드 아키텍처를 표로 비교합니다: 메모리, 버스, 처리량, 유연성, 복잡도, 주요 장치, 수정된 하버드 설계.
