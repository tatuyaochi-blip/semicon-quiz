CPU와 아키텍처

비순차 실행 CPU에서 순서를 바꿔 실행한 명령어의 결과를 프로그램 본래의 순서대로 확정(리타이어)시키기 위한 구조는?

  1. A리오더 버퍼
  2. B스눕 필터
  3. CTLB
정답과 해설 보기

정답: A. 리오더 버퍼

리오더 버퍼는 순서를 바꿔 실행된 명령어의 결과를 일시적으로 보관했다가 프로그램 순서대로 확정(리타이어)시키는 구조이며, 최근 고성능 코어에서는 수백 명령어 분량의 크기입니다. 분기 예측 실패나 예외가 발생했을 때 그 이후 명령어의 결과를 버리고 올바른 상태로 되돌릴 수 있어, 외부에서 보면 프로그램대로 실행된 것처럼 보입니다(정확한 예외).

  • A. 정답입니다. 실행 결과를 본래의 순서로 확정시킵니다.
  • B. 스눕 필터는 캐시 코히런시 통신을 줄이는 구조입니다.
  • C. TLB는 주소 변환 결과를 보관하는 캐시입니다.
