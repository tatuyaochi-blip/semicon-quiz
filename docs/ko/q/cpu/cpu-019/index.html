CPU와 아키텍처

하나의 명령어로 여러 데이터에 같은 연산을 동시에 수행하는 방식은?

  1. ASISD
  2. BSIMD
  3. CMISD
정답과 해설 보기

정답: B. SIMD

SIMD는 하나의 명령어로 여러 데이터에 같은 연산을 병렬로 수행하는 방식으로, 예를 들어 512비트 레지스터라면 32비트 수치 16개를 한 번에 계산할 수 있습니다. x86의 SSE·AVX, ARM의 NEON·SVE 등이 있으며 이미지 처리, 동영상 압축, 행렬 연산 등에서 수 배 이상의 고속화를 얻을 수 있습니다. 플린의 분류에는 이 밖에 SISD(일반적인 순차 처리), MIMD(멀티코어) 등이 있습니다.

CPU와 아키텍처의 다른 문제

  2. 명령어의 의존 관계를 조사해, 실행할 수 있는 명령어부터 프로그램 순서와 다른 순서로 실행하여 성능을 높이는 방식은?
  3. 실행 중인 처리를 일시적으로 중단하고 외부 기기의 요청 등에 따른 처리를 우선 수행하는 CPU의 구조는?
  4. CPU를 거치지 않고 주변 장치와 메모리 사이에서 직접 데이터를 전송하는 구조는?
  5. CPU, 메모리, 타이머나 ADC 등의 주변 기능을 1칩에 담아 가전이나 기기 제어에 사용되는 LSI는?
