CPU와 아키텍처

CPU 내부 ALU(산술 논리 연산 장치)의 역할로 올바른 것은?

  1. A명령어와 데이터를 장기간 저장한다
  2. B화면에 이미지를 표시한다
  3. C덧셈이나 논리 연산 등의 계산을 수행한다
정답과 해설 보기

정답: C. 덧셈이나 논리 연산 등의 계산을 수행한다

ALU(Arithmetic Logic Unit)는 덧셈·뺄셈 등의 산술 연산과 AND·OR·비교·시프트 등의 논리 연산을 수행하는 회로이며 중심은 가산기입니다. 명령어 해독 결과에 따라 레지스터에서 데이터를 받아 결과와 「0인가」「음수인가」「자리 넘침이 있었는가」 등의 플래그를 돌려주며, 분기 판단에 사용됩니다. 고성능 CPU는 여러 개의 ALU와 곱셈기, 부동소수점 연산기를 별도로 갖추고 있습니다.

  • A. 데이터의 장기 보존은 기억장치의 역할입니다.
  • B. 이미지 표시는 GPU나 표시 회로의 역할입니다.
  • C. 정답입니다. 산술 연산과 논리 연산을 수행합니다.
