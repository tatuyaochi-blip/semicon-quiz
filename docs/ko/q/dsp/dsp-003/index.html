디지털 신호 처리의 기초

이산 시간 신호 x[n] = cos(1.75πn)과 모든 정수 n에서 같은 값을 갖는 신호는 어느 것인가?

  1. Acos(0.25πn)
  2. Bcos(0.75πn)
  3. Ccos(0.875πn)
정답과 해설 보기

정답: A. cos(0.25πn)

이산 시간 사인파는 n이 정수이므로, 각주파수가 2π 달라져도 완전히 같은 값의 배열이 됩니다. cos(1.75πn) = cos(1.75πn − 2πn) = cos(−0.25πn)이며, cos는 우함수이므로 cos(0.25πn)과 같습니다. 이것은 디지털 쪽에서 본 접힘(에일리어싱)으로, ω = π를 넘는 주파수는 2π − ω의 낮은 주파수와 구별할 수 없습니다. 샘플링 주파수로 말하면 0.875fs의 사인파가 0.125fs의 사인파와 같은 샘플 열이 되는 것에 해당합니다.
