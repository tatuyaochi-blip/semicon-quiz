디지털 신호 처리의 기초

샘플링 주파수 48 kHz의 신호를 1024점 이산 푸리에 변환(DFT)으로 해석한다. 주파수 빈의 간격으로 올바른 것은?

  1. A약 23.4 Hz
  2. B약 46.9 Hz
  3. C약 93.8 Hz
정답과 해설 보기

정답: B. 약 46.9 Hz

N점 DFT의 빈 간격은 Δf = fs/N으로, 48000 ÷ 1024 = 46.875 Hz ≈ 46.9 Hz입니다. k번째 빈은 주파수 k × Δf에 대응하며, k = 0이 직류, k = N/2 = 512가 나이퀴스트 주파수인 24 kHz입니다. Δf는 관측 시간 T = N/fs ≈ 21.3 ms의 역수이기도 하므로, 빈의 간격을 촘촘하게 하려면 관측 시간을 길게 해야 합니다.

  2. 실수 신호 x[n]의 64점 DFT를 계산했더니 X[10] = 3 + 4j였다. X[54]로 올바른 것은?
  3. 8점 실수 신호 x[n] = {3, 1, 3, 1, 3, 1, 3, 1}의 DFT를 X[k] = Σx[n]e^(−j2πkn/8)이라 한다. 나이퀴스트 주파수에 해당하는 빈 X[4]의 값으로 올바른 것은?
  4. N점 DFT를 정의대로 계산하면 약 N²회, FFT(고속 푸리에 변환)로는 약 N log₂N회의 연산으로 충분하다고 하자. N = 1024일 때, FFT에 의한 연산 횟수의 감소 정도로 가장 가까운 것은?
  5. 256점 신호 뒤에 0을 768개 덧붙여(제로 패딩) 1024점 DFT를 계산했다. 256점 그대로 DFT를 계산한 경우와 비교한 설명으로 올바른 것은?
