디지털 신호 처리의 기초

점수 N은 충분히 크다고 한다. 직사각형 창의 DFT에서 사인파의 주파수가 인접한 두 빈의 정확히 중간에 있을 때, 가장 가까운 빈에서 읽히는 진폭이 주파수가 빈의 중심과 일치하는 경우보다 얼마나 낮아지는지에 가장 가까운 것은?

  1. A약 1.4 dB
  2. B약 3.9 dB
  3. C약 6.0 dB
정답과 해설 보기

정답: B. 약 3.9 dB

직사각형 창에서는 빈의 중심에서 δ빈 벗어난 사인파의 진폭이 sin(πδ)/(πδ)배로 읽히며, δ = 0.5에서는 sin(π/2)/(π/2) = 2/π ≈ 0.637배가 됩니다. 20 log₁₀(0.637) ≈ −3.9 dB로, 진폭을 최대 약 36% 작게 읽게 됩니다. 이 저하를 스캘러핑 손실이라고 하며, 해닝 창에서는 약 1.4 dB로 작아집니다. 진폭을 정확하게 읽어야 하는 측정에서는 메인 로브의 꼭대기가 평평한 플랫톱 창도 사용됩니다.

디지털 신호 처리의 기초의 다른 문제

  1. 4점 신호 x[n] = {1, −1, 2, 0}의 DFT를 X[k] = Σx[n]e^(−j2πkn/4)라 한다. Σ|X[k]|²(k = 0~3)로 올바른 것은?
  2. 이산 시간 LTI 시스템의 전달 함수 H(z)에서 주파수 응답을 구할 때, z를 움직이는 곳으로 올바른 것은?
  3. 차분 방정식 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1]로 표현되는 시스템의 전달 함수 H(z) = Y(z)/X(z)로 올바른 것은?
  4. 전달 함수 H(z) = 1/(1 − 1.3z⁻¹ + 0.4z⁻²)로 표현되는 인과적인 시스템의 극점과 안정성의 조합으로 올바른 것은?
  5. 샘플링 주파수 8 kHz로 동작하는, 전달 함수 H(z) = 1 + z⁻²(y[n] = x[n] + x[n − 2])인 FIR 필터가 있다. 출력이 0이 되는 사인파 입력의 주파수로 올바른 것은?
