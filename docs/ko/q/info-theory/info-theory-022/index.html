정보 이론과 부호의 기초

ZIP이나 gzip 등에서 사용되는 LZ77 방식의 개념으로 올바른 것은?

  1. A출현 확률이 높은 기호에 짧은 부호어를, 낮은 기호에 긴 부호어를 할당한다
  2. B사람의 눈이나 귀로 알아차리기 어려운 성분을 버려 데이터를 작게 한다
  3. C앞에 나타난 문자열과 같은 문자열을, 앞의 위치까지의 거리와 길이의 쌍으로 치환한다
정답과 해설 보기

정답: C. 앞에 나타난 문자열과 같은 문자열을, 앞의 위치까지의 거리와 길이의 쌍으로 치환한다

LZ77 방식은 이미 처리한 데이터를 사전처럼 사용하여, 같은 문자열이 다시 나타나면 '몇 문자 앞에서부터, 몇 문자만큼'이라는 거리와 길이의 쌍으로 치환합니다. 기호의 확률을 미리 알지 못해도 반복이 많은 데이터를 작게 할 수 있으며, 원래 데이터를 완전히 복원할 수 있는 무손실 압축입니다. ZIP이나 gzip의 Deflate 방식은 LZ77로 치환한 결과를 다시 허프만 부호로 부호화합니다.

정보 이론과 부호의 기초의 다른 문제

  1. LZ77 방식으로 압축한 데이터를 복원한다. 데이터는 '문자 A', '문자 B', '(거리 2, 길이 5)'의 순서로 늘어서 있다. (거리 d, 길이 L)은 '복원한 문자열의 끝에서 d문자 앞의 문자를 끝에 복사하는' 것을 1문자씩 L번 반복함을 나타낸다. 복원한 문자열은?
  2. 데이터를 압축할 때, 손실 압축이 아니라 무손실 압축을 사용해야 하는 것은?
  3. 데이터 비트열에 1의 개수가 짝수가 되도록 짝수 패리티 비트를 하나 붙여 보낸다. 수신 측에서 1의 개수를 조사하는 검사의 성질로 올바른 것은?
  4. 4비트 데이터 4행에 대해, 각 행의 오른쪽 끝에 그 행의 짝수 패리티 비트를, 마지막에 각 열의 짝수 패리티를 늘어놓은 행을 붙여 보냈다(수직 수평 패리티). 수신한 비트는 1행 1011 1, 2행 0100 0, 3행 1100 0, 4행 0101 0, 패리티 행 0100이었다(각 행의 오른쪽 끝 1비트가 행의 패리티). 1비트만 잘못되었을 때, 잘못된 비트의 위치는?
  5. 데이터를 1바이트씩 더하여, 합의 하위 8비트를 검사값(체크섬)으로 붙여 보낸다. 이 검사로 검출할 수 없는 오류는?
