정보 이론과 부호의 기초

4비트 데이터에 3비트 검사 비트를 붙여 7비트 부호어로 만드는 해밍 부호(7, 4)의 부호화율에 가장 가까운 것은?

  1. A약 0.43
  2. B약 0.57
  3. C1.75
정답과 해설 보기

정답: B. 약 0.57

부호화율은 부호어의 길이 n 중 데이터 비트 수 k가 차지하는 비율 k/n입니다. 해밍 부호(7, 4)에서는 4/7 ≈ 0.57로, 보내는 비트의 약 57%가 데이터입니다. 부호화율이 낮을수록 검사 비트가 많아 오류에 강하게 만들기 쉬운 반면, 데이터를 보내는 효율은 떨어집니다.

정보 이론과 부호의 기초의 다른 문제

  1. 해밍 부호(7, 4)에서 7비트를 왼쪽부터 1~7번째 비트로 하고, 1, 2, 4번째 비트를 검사 비트로 한다. 검사 1은 1, 3, 5, 7번째 비트, 검사 2는 2, 3, 6, 7번째 비트, 검사 4는 4, 5, 6, 7번째 비트의 1의 개수가 각각 짝수가 되도록 만든다. 수신한 0110001에 1비트 오류가 있을 때, 잘못된 비트는?
  2. 32비트 데이터에, 1비트 오류를 정정하고 2비트 오류를 검출할 수 있는 SECDED 부호를 붙인다. 해밍 부호의 검사 비트 수 r은 2^r ≥ 데이터 비트 수 + r + 1을 만족하는 최솟값이며, SECDED에서는 여기에 전체 패리티를 1비트 더한다. 필요한 검사 비트 수는?
  3. 해밍 부호(7, 4)의 부호어 5개를 늘어놓고, 각 부호어의 1번째 비트 5개, 다음으로 2번째 비트 5개라는 순서로 보낸다(깊이 5의 인터리브). 수신 측에서 원래 순서로 되돌린 뒤 부호어마다 1비트 오류를 정정한다. 연속된 비트에 집중하여 일어나는 버스트 오류 중, 반드시 정정할 수 있는 최대 길이는?
  4. 통신에서 오류에 대처하는 방식인 ARQ(자동 재전송 요구)와 FEC(순방향 오류 정정)의 설명으로 올바른 것은?
  5. 0과 1을 보내며, 각 비트가 서로 독립적으로 확률 0.1로 반전하는 이진 대칭 채널이 있다. 이진 엔트로피 함수를 H(p) = −p log₂ p − (1 − p) log₂(1 − p)라 하면 H(0.1) ≈ 0.469이다. 이 채널의 1회 전송당 채널 용량에 가장 가까운 것은?
