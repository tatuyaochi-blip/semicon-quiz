정보 이론과 부호의 기초

4비트 데이터 4행에 대해, 각 행의 오른쪽 끝에 그 행의 짝수 패리티 비트를, 마지막에 각 열의 짝수 패리티를 늘어놓은 행을 붙여 보냈다(수직 수평 패리티). 수신한 비트는 1행 1011 1, 2행 0100 0, 3행 1100 0, 4행 0101 0, 패리티 행 0100이었다(각 행의 오른쪽 끝 1비트가 행의 패리티). 1비트만 잘못되었을 때, 잘못된 비트의 위치는?

  1. A1행 3열
  2. B2행 3열
  3. C3행 2열
정답과 해설 보기

정답: B. 2행 3열

각 행에서 패리티를 포함한 1의 개수를 세면 1행은 4, 2행은 1, 3행은 2, 4행은 2로, 홀수가 되는 것은 2행뿐입니다. 각 열에서 패리티 행을 포함한 1의 개수를 세면 1열은 2, 2열은 4, 3열은 1, 4열은 2로, 홀수가 되는 것은 3열뿐입니다. 따라서 2행과 3열이 만나는 비트가 잘못되었으며, 이를 반전하면 정정할 수 있습니다.

정보 이론과 부호의 기초의 다른 문제

  1. 데이터를 1바이트씩 더하여, 합의 하위 8비트를 검사값(체크섬)으로 붙여 보낸다. 이 검사로 검출할 수 없는 오류는?
  2. 데이터 1101에 생성 다항식 x³ + x + 1(비트열 1011)의 CRC 검사 비트 3비트를 붙인다. 검사 비트는 데이터 뒤에 0을 3개 붙인 1101000을 1011로 나눈 나머지이며, 나눗셈에서는 뺄셈 대신 배타적 논리합을 사용한다. 검사 비트는?
  3. 생성 다항식의 차수가 r(검사 비트가 r비트)이고 상수항이 1인 CRC의 성질로 올바른 것은?
  4. 두 7비트 부호어 1011010과 0110011의 해밍 거리는?
  5. 어떤 부호의 최소 해밍 거리(어느 두 부호어 사이의 해밍 거리 중 최솟값)가 5이다. 오류 검출에만 사용하는 경우와 정정에만 사용하는 경우를 생각한다. 확실히 검출할 수 있는 오류의 비트 수와, 확실히 정정할 수 있는 오류의 비트 수의 조합으로 올바른 것은?
