정보 이론과 부호의 기초

데이터를 1바이트씩 더하여, 합의 하위 8비트를 검사값(체크섬)으로 붙여 보낸다. 이 검사로 검출할 수 없는 오류는?

  1. A어느 한 바이트 안에서 1비트만 반전하는 오류
  2. B어느 한 바이트의 값이 1 증가하는 오류
  3. C두 바이트의 순서가 뒤바뀌는 오류
정답과 해설 보기

정답: C. 두 바이트의 순서가 뒤바뀌는 오류

덧셈은 순서를 바꾸어도 결과가 변하지 않으므로, 두 바이트가 뒤바뀌어도 합은 같아져 오류를 검출할 수 없습니다. 1비트의 반전이나 한 바이트의 값이 1 바뀌는 오류에서는 합의 하위 8비트가 반드시 바뀌므로 검출할 수 있습니다. CRC에서는 비트의 위치에 따라 나눗셈의 나머지에 미치는 영향이 달라지므로, 이러한 뒤바뀜도 많은 경우에 검출할 수 있습니다.

정보 이론과 부호의 기초의 다른 문제

  1. 데이터 1101에 생성 다항식 x³ + x + 1(비트열 1011)의 CRC 검사 비트 3비트를 붙인다. 검사 비트는 데이터 뒤에 0을 3개 붙인 1101000을 1011로 나눈 나머지이며, 나눗셈에서는 뺄셈 대신 배타적 논리합을 사용한다. 검사 비트는?
  2. 생성 다항식의 차수가 r(검사 비트가 r비트)이고 상수항이 1인 CRC의 성질로 올바른 것은?
  3. 두 7비트 부호어 1011010과 0110011의 해밍 거리는?
  4. 어떤 부호의 최소 해밍 거리(어느 두 부호어 사이의 해밍 거리 중 최솟값)가 5이다. 오류 검출에만 사용하는 경우와 정정에만 사용하는 경우를 생각한다. 확실히 검출할 수 있는 오류의 비트 수와, 확실히 정정할 수 있는 오류의 비트 수의 조합으로 올바른 것은?
  5. 4개의 부호어 00000, 01011, 10101, 11110으로 이루어진 부호의 최소 해밍 거리와, 확실히 정정할 수 있는 오류의 비트 수의 조합으로 올바른 것은?
