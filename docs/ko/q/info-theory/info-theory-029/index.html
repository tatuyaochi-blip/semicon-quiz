정보 이론과 부호의 기초

생성 다항식의 차수가 r(검사 비트가 r비트)이고 상수항이 1인 CRC의 성질로 올바른 것은?

  1. A1비트 오류라면 어느 비트가 잘못되었는지 특정하여 정정하는 것이 주된 사용법이다
  2. B길이가 r비트 이하인 버스트 오류(연속된 범위에 들어가는 오류)는 모두 검출할 수 있다
  3. C생성 다항식을 잘 고르면 어떤 오류 패턴이라도 모두 검출할 수 있다
정답과 해설 보기

정답: B. 길이가 r비트 이하인 버스트 오류(연속된 범위에 들어가는 오류)는 모두 검출할 수 있다

오류 패턴을 다항식 E(x)로 나타내면, CRC로 검출할 수 없는 것은 E(x)가 생성 다항식 G(x)로 나누어떨어질 때뿐입니다. 길이 r 이하의 버스트 오류는 x^i × B(x)(B(x)는 차수가 r − 1 이하이고 상수항이 1)로 쓸 수 있으며, 상수항이 1인 r차 G(x)로는 나누어떨어지지 않으므로 반드시 검출할 수 있습니다. 한편 G(x) 그 자체의 형태의 오류처럼 나누어떨어지는 패턴은 검출할 수 없습니다. CRC는 주로 오류 검출에 사용되며, 오류가 있으면 데이터를 다시 보내 달라고 합니다.

정보 이론과 부호의 기초의 다른 문제

  1. 두 7비트 부호어 1011010과 0110011의 해밍 거리는?
  2. 어떤 부호의 최소 해밍 거리(어느 두 부호어 사이의 해밍 거리 중 최솟값)가 5이다. 오류 검출에만 사용하는 경우와 정정에만 사용하는 경우를 생각한다. 확실히 검출할 수 있는 오류의 비트 수와, 확실히 정정할 수 있는 오류의 비트 수의 조합으로 올바른 것은?
  3. 4개의 부호어 00000, 01011, 10101, 11110으로 이루어진 부호의 최소 해밍 거리와, 확실히 정정할 수 있는 오류의 비트 수의 조합으로 올바른 것은?
  4. 4비트 데이터에 3비트 검사 비트를 붙여 7비트 부호어로 만드는 해밍 부호(7, 4)의 부호화율에 가장 가까운 것은?
  5. 해밍 부호(7, 4)에서 7비트를 왼쪽부터 1~7번째 비트로 하고, 1, 2, 4번째 비트를 검사 비트로 한다. 검사 1은 1, 3, 5, 7번째 비트, 검사 2는 2, 3, 6, 7번째 비트, 검사 4는 4, 5, 6, 7번째 비트의 1의 개수가 각각 짝수가 되도록 만든다. 수신한 0110001에 1비트 오류가 있을 때, 잘못된 비트는?
