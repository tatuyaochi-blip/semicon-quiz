두 7비트 부호어 1011010과 0110011의 해밍 거리는?

  1. A0
  2. B3
  3. C4
정답과 해설 보기

정답: C. 4

해밍 거리는 같은 위치의 비트가 다른 곳의 수입니다. 두 부호어의 배타적 논리합은 1101001이고 1의 개수가 4이므로, 해밍 거리는 4입니다. 1비트씩 비교하면 1, 2, 4, 7번째 비트가 다릅니다.

정보 이론과 부호의 기초의 다른 문제

  1. 어떤 부호의 최소 해밍 거리(어느 두 부호어 사이의 해밍 거리 중 최솟값)가 5이다. 오류 검출에만 사용하는 경우와 정정에만 사용하는 경우를 생각한다. 확실히 검출할 수 있는 오류의 비트 수와, 확실히 정정할 수 있는 오류의 비트 수의 조합으로 올바른 것은?
  2. 4개의 부호어 00000, 01011, 10101, 11110으로 이루어진 부호의 최소 해밍 거리와, 확실히 정정할 수 있는 오류의 비트 수의 조합으로 올바른 것은?
  3. 4비트 데이터에 3비트 검사 비트를 붙여 7비트 부호어로 만드는 해밍 부호(7, 4)의 부호화율에 가장 가까운 것은?
  4. 해밍 부호(7, 4)에서 7비트를 왼쪽부터 1~7번째 비트로 하고, 1, 2, 4번째 비트를 검사 비트로 한다. 검사 1은 1, 3, 5, 7번째 비트, 검사 2는 2, 3, 6, 7번째 비트, 검사 4는 4, 5, 6, 7번째 비트의 1의 개수가 각각 짝수가 되도록 만든다. 수신한 0110001에 1비트 오류가 있을 때, 잘못된 비트는?
  5. 32비트 데이터에, 1비트 오류를 정정하고 2비트 오류를 검출할 수 있는 SECDED 부호를 붙인다. 해밍 부호의 검사 비트 수 r은 2^r ≥ 데이터 비트 수 + r + 1을 만족하는 최솟값이며, SECDED에서는 여기에 전체 패리티를 1비트 더한다. 필요한 검사 비트 수는?
