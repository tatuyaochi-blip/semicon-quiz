수율과 품질 관리

문제가 일어났을 때 실제 현장에서 실제 물건을 보고 실제 상황을 확인하는 것을 중시하는 사고방식을 무엇이라고 합니까?

  1. A형식주의
  2. B성과주의
  3. C삼현주의(현장·현물·현실)
정답과 해설 보기

정답: C. 삼현주의(현장·현물·현실)

삼현주의는 보고나 추측만으로 판단하지 않고 현장에 가서 현물(불량품이나 장비)을 보고 현실(실제 상황이나 데이터)을 확인하는 것을 중시하는, 일본 제조업에서 소중히 여겨 온 문제 해결의 기본 자세입니다. 회의실에서 생각한 원인은 선입견에 빠지기 쉽고, 실물을 보면 보고에 없던 단서를 발견하는 경우가 많기 때문입니다. 원리·원칙을 더해 오현주의라고도 합니다.

  • A. 형식주의는 내용보다 형식을 중시하는 태도입니다.
  • B. 성과주의는 인사 평가의 개념입니다.
  • C. 올바릅니다. 현장·현물·현실을 중시하는 사고방식입니다.

수율과 품질 관리의 다른 문제

  1. 공정 조건(온도, 시간, 가스 유량 등)을 여러 개 동시에 계획적으로 바꾸어, 적은 실험 횟수로 각 요인의 영향을 효율적으로 조사하는 기법은 무엇입니까?
  2. 제조 장비의 센서 데이터(온도·압력·전력 등)를 처리 중에 감시하여 평소와 다른 상태를 감지하고 이상을 빨리 알리는 구조를 무엇이라고 합니까?
  3. 제조 장비의 생산성을 가동 시간의 비율·성능(속도)·양품률을 곱하여 평가하는 지표는 무엇입니까?
  4. 반도체 공장에서 웨이퍼 투입부터 완성까지 걸리는 시간을 무엇이라고 합니까?
  5. 공정 평균의 변화와 산포의 변화를 동시에 감시하기 위해, 샘플의 평균값과 범위(최대−최소)를 각각 시계열로 그리는 관리도는 무엇입니까?
