수율과 품질 관리

결함이 웨이퍼 위에서 치우쳐 모여서 발생하는(클러스터링하는) 것을 고려한 수율 모델로 사용되는 것은?

  1. A음이항 분포 모델
  2. B옴의 법칙
  3. C데나드 스케일링 법칙
정답과 해설 보기

정답: A. 음이항 분포 모델

푸아송 모델은 결함이 무작위로 균일하게 분포한다고 가정하지만 실제 결함은 국소적으로 모이는 경향이 있습니다. 음이항 분포 모델은 클러스터링 정도를 나타내는 매개변수 α를 포함하며 Y=(1+DA/α)^(−α)로 표현됩니다. DA=1일 때 푸아송에서는 약 37%, α=1에서는 50%가 되어, 결함이 뭉칠수록 무결함 칩이 많이 남습니다. α가 클수록 푸아송 모델에 가까워집니다.

수율과 품질 관리의 다른 문제

  1. 결함 검사에서 발견된 결함의 종류별로, 그 결함이 있던 칩 중 실제로 전기적 불량이 된 비율을 나타내는 양을 무엇이라 부르는가?
  2. 공장 안의 재공품(WIP) 양, 처리 속도(스루풋), 사이클 타임의 관계를 나타내는 '리틀의 법칙'의 내용으로 올바른 것은?
  3. 수율이 낮은 로트에 공통적으로 사용된 장비나 챔버, 재료 등을 다수 로트의 제조 이력으로부터 통계적으로 찾아내는 해석을 무엇이라 부르는가?
  4. 서로 상관이 있는 여러 특성값을 하나씩이 아니라 한꺼번에 감시하여 조합으로서의 이상을 검출하는 통계적 공정 관리 기법은?
  5. 같은 종류의 장비가 여러 대 있을 때, 장비나 챔버 간에 가공 결과의 차이가 작아지도록 조정·관리하는 것을 무엇이라 부르는가?
