수율과 품질 관리

공장 안에서 어떤 로트가 어느 공정·장비에 있고 어떤 조건으로 처리되었는지 등을 관리하며 생산 흐름을 지시·기록하는 시스템은?

  1. ABIST
  2. BMES(제조 실행 시스템)
  3. CEDA
정답과 해설 보기

정답: B. MES(제조 실행 시스템)

MES(Manufacturing Execution System)는 로트의 진행 상황, 장비 상태, 처리 조건(레시피), 작업 기록 등을 관리하고 다음에 어느 장비에서 무엇을 처리할지 지시하는 시스템입니다. 잘못된 레시피로의 처리나 공정 건너뛰기를 막는 역할도 하며, 자동 반송 시스템과 연계하여 공장 전체를 움직입니다. 제조 이력 추적(트레이서빌리티)의 기반도 됩니다. BIST는 테스트 회로, EDA는 설계 툴입니다.

수율과 품질 관리의 다른 문제

  1. 많은 제품 중 일부를 샘플링하여 검사하고 로트 전체를 합격으로 할지 불합격으로 할지 판정하는 방식에서, 합격으로 간주하는 품질 수준을 나타내는 지표는?
  2. 수율 데이터를 분석할 때의 주의점으로, '두 양에 상관이 있어도 한쪽이 다른 쪽의 원인이라고는 할 수 없다'는 것을 보여 주는 예로 올바른 것은?
  3. 공장에 축적된 대량의 장비 데이터·계측 데이터·테스트 결과를 머신러닝 등으로 해석하여 수율을 높이려는 노력에 대한 설명으로 올바른 것은?
  4. 결함이 웨이퍼 위에서 치우쳐 모여서 발생하는(클러스터링하는) 것을 고려한 수율 모델로 사용되는 것은?
  5. 결함 검사에서 발견된 결함의 종류별로, 그 결함이 있던 칩 중 실제로 전기적 불량이 된 비율을 나타내는 양을 무엇이라 부르는가?
