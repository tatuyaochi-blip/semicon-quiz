수율과 품질 관리

웨이퍼 1장에서 칩 500개가 나왔고 그중 450개가 양품이었다. 이 웨이퍼의 수율은 얼마인가?

  1. A80%
  2. B90%
  3. C95%
정답과 해설 보기

정답: B. 90%

수율은 '양품 수 ÷ 전체 수'로 구합니다. 450 ÷ 500 = 0.9이므로 수율은 90%입니다. 80%라면 양품은 400개, 95%라면 475개가 되어야 합니다. 실제 공장에서는 전공정의 라인 수율, 웨이퍼 테스트 수율, 조립·최종 테스트 수율을 단계별로 관리하고 이들을 곱하여 종합 수율을 구합니다. 수율이 1% 포인트만 올라도 이익에 미치는 영향은 큽니다.

수율과 품질 관리의 다른 문제

  1. 결함 밀도가 같은 조건에서 칩 면적을 크게 하면 수율은 일반적으로 어떻게 되는가?
  2. 공정 관리에 사용되는 관리도(슈하트 관리도)에서 관리 한계선은 일반적으로 어떻게 설정하는가?
  3. 품질 관리에서 사용되는 파레토도의 목적으로 올바른 것은?
  4. 공정 능력 지수 Cp(규격의 중심과 공정의 평균이 일치하는 경우)를 구하는 식은? (σ: 공정의 표준 편차)
  5. 수율 저하 요인 중 설계와 제조 공정의 궁합 등으로 인해 특정 패턴에서 반복적으로 발생하는 불량을 무엇이라 부르는가?
