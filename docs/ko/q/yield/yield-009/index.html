수율과 품질 관리

다른 조건이 같을 때, 웨이퍼 직경을 200 mm에서 300 mm로 하면 웨이퍼 면적은 대략 몇 배가 되는가?

  1. A약 2.25배
  2. B1.5배
  3. C3배
정답과 해설 보기

정답: A. 약 2.25배

면적은 직경의 제곱에 비례하므로 (300 / 200)² = 1.5² = 2.25배가 됩니다. 1.5배는 직경의 비를 그대로 사용한 오류이고, 3배는 과대입니다. 실제로는 외주에서 잘려 사용할 수 없는 칩의 비율이 줄어들기 때문에 얻을 수 있는 칩 수는 2.25배보다 많아집니다. 장비 1대당 처리 면적도 늘어나므로 칩 1개당 비용이 내려갑니다. 이것이 대구경화를 추진해 온 이유입니다.
