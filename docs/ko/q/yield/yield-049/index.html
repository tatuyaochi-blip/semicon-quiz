수율과 품질 관리

서로 상관이 있는 여러 특성값을 하나씩이 아니라 한꺼번에 감시하여 조합으로서의 이상을 검출하는 통계적 공정 관리 기법은?

  1. A다변량 관리도(호텔링의 T² 등)
  2. B체크 시트
  3. CX̄-R 관리도뿐
정답과 해설 보기

정답: A. 다변량 관리도(호텔링의 T² 등)

장비 센서 값 등은 서로 상관되어 있는 경우가 많아, 하나씩의 관리도에서는 정상 범위 내여도 조합으로서는 이상한 상태가 있을 수 있습니다. 예를 들어 압력과 유량이 평소에는 함께 움직이는데 한쪽만 변한 경우입니다. 호텔링의 T² 통계량 등을 사용하는 다변량 관리도에서는 상관을 고려하여 여러 값을 한꺼번에 하나의 지표로 감시할 수 있어 이러한 이상을 검출할 수 있습니다.

수율과 품질 관리의 다른 문제

  1. 같은 종류의 장비가 여러 대 있을 때, 장비나 챔버 간에 가공 결과의 차이가 작아지도록 조정·관리하는 것을 무엇이라 부르는가?
  2. 웨이퍼 1장에서 칩 500개가 나왔고 그중 450개가 양품이었다. 이 웨이퍼의 수율은 얼마인가?
