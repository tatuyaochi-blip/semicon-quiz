수율과 품질 관리

품질 관리와 업무 개선에서 사용되는 'PDCA 사이클'의 순서로 올바른 것은?

  1. A계획(Plan) → 실행(Do) → 평가(Check) → 개선(Act)
  2. B실행 → 계획 → 개선 → 평가
  3. C평가 → 개선 → 계획 → 실행
정답과 해설 보기

정답: A. 계획(Plan) → 실행(Do) → 평가(Check) → 개선(Act)

PDCA 사이클은 계획을 세우고(Plan), 실행하고(Do), 결과를 평가하고(Check), 개선 조치를 취하는(Act) 네 단계를 반복하여 품질이나 업무를 지속적으로 개선하는 사고방식입니다. 개선으로 얻은 방식을 표준으로 정착시켜 다음 계획의 출발점으로 삼음으로써 나선형으로 수준을 높여 갑니다. 슈하트와 데밍이 널리 알렸으며 일본의 품질 관리에 큰 영향을 주었습니다.
