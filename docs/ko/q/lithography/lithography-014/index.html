포토리소그래피

리소그래피의 일반적인 공정 순서로 올바른 것은 무엇입니까?

  1. A노광 → 레지스트 도포 → 현상 → 프리베이크
  2. B레지스트 도포 → 프리베이크 → 노광 → 노광 후 베이크 → 현상
  3. C현상 → 노광 → 레지스트 도포 → 식각
정답과 해설 보기

정답: B. 레지스트 도포 → 프리베이크 → 노광 → 노광 후 베이크 → 현상

먼저 HMDS 처리로 밀착성을 높이고, 반사 방지막과 레지스트를 도포하며, 프리베이크(약 100 ℃)로 용제를 날립니다. 다음으로 노광하고, 화학 증폭형 레지스트에서는 노광 후 베이크(PEB)로 반응을 진행시킵니다. 마지막으로 알칼리 현상액으로 현상하여 패턴을 형성하고, 필요에 따라 포스트 베이크로 경화시킵니다. 도포부터 현상까지는 노광 장치와 연결된 코터/디벨로퍼에서 온도를 ±0.1 ℃ 정도로 관리하면서 이루어집니다.

관련 계산 도구

노광 해상도 및 초점 심도 계산기파장, NA, k1로 해상도(하프 피치), 초점 심도, 피치 분할 수 계산

포토리소그래피의 다른 문제

  1. 미세한 패턴을 가진 몰드(주형)를 레지스트에 눌러 패턴을 전사하는 기술을 무엇이라고 합니까?
  2. 포토마스크(레티클)의 패턴을 그리는 데 주로 사용되는 장치는 무엇입니까?
  3. 포토마스크 위에 일정한 간격을 두고 씌우는 얇은 막(펠리클)의 역할은 무엇입니까?
  4. 레지스트 아래에 도포하는 반사 방지막(BARC)의 주된 목적은 무엇입니까?
  5. 차세대 EUV 노광 장치로 개발된 'High-NA EUV'의 특징으로 올바른 것은 무엇입니까?

이 분야의 비교

  • EUV와 DUV 리소그래피의 차이는 무엇일까EUV와 DUV(ArF 액침) 리소그래피를 표로 비교합니다. 파장, 광원, 광학계, 마스크, 해상도, 비용, 결함, 각각의 사용처를 다룹니다.
  • 포지티브 vs 네거티브 포토레지스트: 차이점 설명포지티브와 네거티브 포토레지스트를 표로 비교합니다: 빛에 대한 반응, 패턴 극성, 해상도, 현상액, 프로파일, 재료, 대표 용도.
