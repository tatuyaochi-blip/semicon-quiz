포토리소그래피

'리소그래피(lithography)'라는 말의 원래 의미로 올바른 것은 무엇입니까?

  1. A전자를 세는 기술
  2. B석판을 사용한 인쇄 기술
  3. C빛을 휘게 하는 기술
정답과 해설 보기

정답: B. 석판을 사용한 인쇄 기술

리소그래피는 그리스어 lithos(돌)와 graphein(쓰다)에서 유래했으며, 원래는 1798년 독일에서 발명된, 물과 기름의 반발을 이용해 석판으로 인쇄하는 기술을 가리킵니다. 원판의 패턴을 다른 것에 옮긴다는 개념이 공통되기 때문에 반도체의 패턴 전사에도 이 이름이 사용되었고, 빛을 사용하므로 포토리소그래피라고도 불립니다.

포토리소그래피의 다른 문제

  1. 포토레지스트에 대한 설명으로 올바른 것은 무엇입니까?
  2. EUV 노광 장치를 사실상 1개 회사가 공급하고 있는 기업은 어디입니까?
  3. KrF 엑시머 레이저 노광에서 사용되는 빛의 파장은 무엇입니까?
  4. 레지스트를 도포하기 전에 웨이퍼 표면을 HMDS 등으로 처리하는 주된 목적은 무엇입니까?
  5. 미세화 지표로 사용되는 '하프 피치'의 의미로 올바른 것은 무엇입니까?

이 분야의 비교

  • EUV와 DUV 리소그래피의 차이는 무엇일까EUV와 DUV(ArF 액침) 리소그래피를 표로 비교합니다. 파장, 광원, 광학계, 마스크, 해상도, 비용, 결함, 각각의 사용처를 다룹니다.
  • 포지티브 vs 네거티브 포토레지스트: 차이점 설명포지티브와 네거티브 포토레지스트를 표로 비교합니다: 빛에 대한 반응, 패턴 극성, 해상도, 현상액, 프로파일, 재료, 대표 용도.
