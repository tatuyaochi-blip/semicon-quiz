정답: B. 유도 자기조립(DSA)

블록 공중합체는 성질이 다른 두 종류의 고분자(예를 들어 폴리스티렌과 PMMA)가 연결된 재료로, 서로 분리되려는 성질 때문에 분자의 길이로 정해지는 수 nm~수십 nm의 규칙적인 줄무늬나 점 무늬를 저절로 만듭니다. DSA는 리소그래피로 만든 가이드 패턴으로 배열 위치와 방향을 제어하여, 해상 한계보다 미세한 패턴을 만드는 기술입니다. 저렴하게 미세화할 수 있는 가능성이 있는 한편, 결함이 적어야 한다는 점이 양산의 과제입니다.

포토리소그래피의 다른 문제

  1. 반도체 제조에서 리소그래피의 역할로 올바른 것은 무엇입니까?
  2. '리소그래피(lithography)'라는 말의 원래 의미로 올바른 것은 무엇입니까?
  3. 포토레지스트에 대한 설명으로 올바른 것은 무엇입니까?
  4. EUV 노광 장치를 사실상 1개 회사가 공급하고 있는 기업은 어디입니까?
  5. KrF 엑시머 레이저 노광에서 사용되는 빛의 파장은 무엇입니까?

이 분야의 비교

  • EUV와 DUV 리소그래피의 차이는 무엇일까EUV와 DUV(ArF 액침) 리소그래피를 표로 비교합니다. 파장, 광원, 광학계, 마스크, 해상도, 비용, 결함, 각각의 사용처를 다룹니다.
  • 포지티브 vs 네거티브 포토레지스트: 차이점 설명포지티브와 네거티브 포토레지스트를 표로 비교합니다: 빛에 대한 반응, 패턴 극성, 해상도, 현상액, 프로파일, 재료, 대표 용도.
