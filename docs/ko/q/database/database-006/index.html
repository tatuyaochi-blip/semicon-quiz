데이터베이스 기초

SQL 문은 데이터 정의어(DDL), 데이터 조작어(DML), 데이터 제어어(DCL)로 나뉜다. DDL로 분류되는 것은?

  1. AUPDATE 사원 SET 부서 = '개발' WHERE 사원번호 = 5
  2. BCREATE TABLE 부서 (부서ID INTEGER PRIMARY KEY, 부서명 CHAR(10))
  3. CGRANT SELECT ON 사원 TO 다나카
정답과 해설 보기

정답: B. CREATE TABLE 부서 (부서ID INTEGER PRIMARY KEY, 부서명 CHAR(10))

DDL(Data Definition Language)은 표, 뷰, 인덱스 같은 데이터베이스의 구조를 정의하는 문으로, CREATE, ALTER, DROP이 있습니다. DML(Data Manipulation Language)은 표 안의 데이터를 다루는 문으로, SELECT, INSERT, UPDATE, DELETE가 있습니다. DCL(Data Control Language)은 권한 등을 제어하는 문으로, 이용자에게 권한을 주는 GRANT, 권한을 취소하는 REVOKE가 있습니다. 트랜잭션을 확정하는 COMMIT이나 취소하는 ROLLBACK은 DCL에 포함하기도 하고, 트랜잭션 제어문으로 따로 나누기도 합니다. 선택지 중 표를 만드는 CREATE TABLE이 DDL입니다.

데이터베이스 기초의 다른 문제

  1. 상품 표에 (상품명, 가격)이 (펜, 120), (노트, 250), (지우개, 80), (파일, 300), (자, 150)인 5개 행이 있다. SELECT 상품명 FROM 상품 WHERE 가격 >= 150 ORDER BY 가격 DESC의 결과로 반환되는 행을 순서대로 나열한 것은?
  2. 사원 표의 부서 열에 위의 행부터 차례로 영업, 개발, 영업, 총무, 개발, 영업의 값이 들어 있다(전체 6행). SELECT DISTINCT 부서 FROM 사원의 결과는 몇 행이 되는가?
  3. SQL에서 DELETE FROM 사원을 WHERE 절 없이 실행했을 때의 결과로 올바른 것은?
  4. 시험 표의 점수 열에 80, NULL, 70, 90의 4개 값이 있다(NULL은 미응시를 나타낸다). SELECT AVG(점수) FROM 시험의 결과는?
  5. 성적 표의 점수 열에 50, NULL, 70, NULL, 90, 30의 6개 값이 있다. SELECT COUNT(*), COUNT(점수), AVG(점수) FROM 성적의 결과를 순서대로 나열한 것은?

이 분야의 비교

  • 관계형 데이터베이스(RDB)와 NoSQL의 차이: 데이터 모델·스키마·조인·일관성·확장 비교관계형 데이터베이스(RDB)와 NoSQL을 데이터 표현 방식, 스키마, 질의, 테이블 조인, 트랜잭션과 일관성, 확장 방식, 정규화, 적합한 용도의 관점에서 표로 비교합니다.
