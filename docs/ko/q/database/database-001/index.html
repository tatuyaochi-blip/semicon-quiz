데이터베이스 기초

관계형 데이터베이스의 용어에서 표(릴레이션)의 한 행에 해당하는 것은?

  1. A튜플
  2. B속성
  3. C도메인
정답과 해설 보기

정답: A. 튜플

관계형 데이터베이스는 데이터를 행과 열로 이루어진 표(관계, 릴레이션)의 형태로 나타내고, 표끼리를 값으로 연관 지어 다루는 데이터베이스입니다. 관계 모델의 용어로는 표의 한 행을 튜플(조), 한 열을 속성(애트리뷰트), 어떤 속성이 가질 수 있는 값의 집합을 도메인(정의역)이라고 합니다. 예를 들어 사원 표에서 사원 한 명의 데이터 행이 튜플, '이름'이나 '부서' 열이 속성, '나이' 열이 가질 수 있는 0 이상의 정수 범위가 도메인입니다. 관계 모델에서는 표를 행의 집합으로 다루므로 행의 순서에는 의미가 없고, 완전히 같은 행이 2개 있는 것도 허용하지 않습니다(실제 SQL의 표에서는 기본 키를 정하지 않으면 같은 행이 들어가는 경우가 있습니다).

데이터베이스 기초의 다른 문제

  1. 관계형 데이터베이스의 표에서 기본 키로 지정하는 열(또는 열의 조합)이 반드시 만족해야 하는 조건은?
  2. 사원 표(사원번호, 이메일주소, 이름, 부서)에서 사원번호와 이메일주소는 둘 다 사원마다 다르며 NULL이 되지 않는다. 이름과 부서는 다른 사원과 같아질 수 있다. 이 표의 후보 키를 모두 든 것은?
  3. 수강 표(학생번호, 과목번호, 성적)는 어느 학생이 어느 과목을 수강하여 어떤 성적을 받았는지를 기록한다. 한 학생은 여러 과목을 수강하고, 한 과목은 여러 학생이 수강한다. 같은 학생이 같은 과목을 두 번 등록하는 일은 없을 때, 이 표의 기본 키로 적절한 것은?
  4. 고객 표(고객ID, 이름)의 기본 키는 고객ID이며, 주문 표(주문ID, 고객ID)의 고객ID는 고객 표의 고객ID를 참조하는 외래 키로 정의되어 있다. 고객 표에는 고객ID가 'C1'과 'C2'인 행만 있다. 이 상태에서 INSERT INTO 주문 VALUES ('O9', 'C5')를 실행했을 때의 결과로 올바른 것은?
  5. SQL 문은 데이터 정의어(DDL), 데이터 조작어(DML), 데이터 제어어(DCL)로 나뉜다. DDL로 분류되는 것은?
