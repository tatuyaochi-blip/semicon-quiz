아날로그·전자 회로

4개의 저항 R1·R2·R3·R4로 만든 휘트스톤 브리지(R1과 R2, R3과 R4가 각각 직렬이고 그 2조가 병렬)에서 2조의 중점 사이에 전류가 흐르지 않는(평형하는) 조건은 무엇입니까?

  1. AR1 + R2 = R3 + R4
  2. BR1 / R2 = R3 / R4
  3. CR1 × R2 = R3 × R4
정답과 해설 보기

정답: B. R1 / R2 = R3 / R4

2조의 직렬 저항 중점 전압이 같으면 중점 사이에 전류가 흐르지 않습니다. 중점 전압은 각각의 분압비로 결정되므로 R1/R2 = R3/R4(R1 × R4 = R2 × R3)가 평형 조건입니다. 평형점 부근에서는 하나의 저항이 약간만 변해도 차 전압으로 나타나며, 전원 전압 변동에도 강합니다. 스트레인 게이지, 백금 측온 저항체, 압력 센서 등 미소한 저항 변화의 측정에 사용됩니다.

  • A. 저항의 합이 같아도 분압비가 같지 않으면 평형하지 않습니다.
  • B. 정답입니다. 양쪽의 분압비가 같은 것이 평형 조건입니다.
  • C. 곱의 조합은 R1 × R4 = R2 × R3이 올바르며, R1 × R2 = R3 × R4가 아닙니다.

  3. 이상적인 전류원의 출력 임피던스는 무엇입니까?
  4. 수정 발진기가 시계나 마이컴의 클록원으로 널리 사용되는 주된 이유는 무엇입니까?
  5. LDO(저드롭아웃 리니어 레귤레이터)의 '드롭아웃 전압'의 의미로 올바른 것은 무엇입니까?

이 분야의 비교

  • LDO vs 스위칭 레귤레이터: 효율·노이즈·부품·용도 비교리니어 레귤레이터(LDO)와 스위칭 레귤레이터(DC-DC 컨버터)를 표로 비교합니다: 동작 원리, 효율, 발열, 노이즈, 부품 수, 승압 가능 여부, 부하 응답, 용도. 둘을 조합하는 전원 구성도…
