  3. C발진을 일으키기 위해

정답: B. 입력 바이어스 전류로 인한 출력의 오프셋 오차를 상쇄하기 위해

연산 증폭기의 입력 단자에는 입력 바이어스 전류가 흐르고, 반전 입력 측에서 본 저항(Ri∥Rf)에서 전압 강하가 생겨 출력에 오차가 나타납니다. 비반전 입력 측에도 같은 값의 저항을 넣으면 양쪽 입력에서 같은 전압 강하가 일어나 상쇄되고, 남는 것은 두 바이어스 전류의 차(입력 오프셋 전류)로 인한 오차뿐입니다. 바이어스 전류가 pA 수준인 CMOS 입력이나 JFET 입력 연산 증폭기에서는 보통 이 저항이 필요 없습니다.

  • A. 이 저항은 이득을 바꾸지 않습니다.
  • B. 정답입니다. 바이어스 전류로 인한 전압 강하를 양쪽 입력에서 같게 하여 상쇄합니다.
  • C. 발진을 일으키는 것이 목적이 아닙니다.

아날로그·전자 회로의 다른 문제

  1. 이상적인 연산 증폭기의 특성으로 올바른 조합은 무엇입니까?
  2. 이상적인 연산 증폭기를 사용한 반전 증폭 회로에서 입력 저항 Ri = 10 kΩ, 귀환 저항 Rf = 100 kΩ일 때 전압 이득은 얼마입니까?
  3. 저항 R = 1 kΩ과 커패시터 C = 1 µF로 구성한 RC 저역 통과 필터의 차단 주파수에 가장 가까운 것은 무엇입니까?
  4. 이상적인 연산 증폭기를 사용한 비반전 증폭 회로에서 입력 측 저항 R1 = 10 kΩ, 귀환 저항 R2 = 90 kΩ일 때 전압 이득은 얼마입니까?
  5. 연산 증폭기를 사용한 전압 팔로워에 대한 설명으로 올바른 것은 무엇입니까?

이 분야의 비교

  • LDO vs 스위칭 레귤레이터: 효율·노이즈·부품·용도 비교리니어 레귤레이터(LDO)와 스위칭 레귤레이터(DC-DC 컨버터)를 표로 비교합니다: 동작 원리, 효율, 발열, 노이즈, 부품 수, 승압 가능 여부, 부하 응답, 용도. 둘을 조합하는 전원 구성도…
  • 지터와 위상 잡음의 차이: 측정량·단위·측정기·환산·구분 사용 비교클록의 흔들림을 시간 영역에서 보는 지터와 주파수 영역에서 보는 위상 잡음을 측정량, 단위, 측정기, 대표 지표, 적분에 의한 RMS 지터 환산, 사용 분야 관점에서 비교합니다.
  • A급, AB급, D급 앰프의 차이점 정리A급, AB급, D급 전력 증폭기를 표로 비교합니다. 동작 원리, 도통각, 이론 최대 효율, 왜곡, 발열, 노이즈, 용도와 B급과의 관계를 안내합니다.
