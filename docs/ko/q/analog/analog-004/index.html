아날로그·전자 회로

이상적인 연산 증폭기를 사용한 비반전 증폭 회로에서 입력 측 저항 R1 = 10 kΩ, 귀환 저항 R2 = 90 kΩ일 때 전압 이득은 얼마입니까?

  1. A−9배
  2. B+9배
  3. C+10배
정답과 해설 보기

정답: C. +10배

비반전 증폭 회로의 이득은 1 + R2/R1이며, 1 + 90/10 = 10배이고 출력은 입력과 동상입니다. 입력이 비반전 입력 단자에 직접 들어가므로 입력 임피던스가 매우 높아 신호원에 부담을 주지 않는 것이 장점입니다. 이득은 1배 미만으로 만들 수 없습니다(R2 = 0이면 전압 팔로워). 반전 증폭 회로의 −R2/R1(여기서는 −9배)과 혼동하지 않도록 합시다.

아날로그·전자 회로의 다른 문제

  1. 연산 증폭기를 사용한 전압 팔로워에 대한 설명으로 올바른 것은 무엇입니까?
  2. 증폭 회로에 부귀환을 걸었을 때의 효과로 올바른 것은 무엇입니까?
  3. 차동 증폭 회로의 CMRR(동상 신호 제거비)이 크다는 것의 의미로 올바른 것은 무엇입니까?
  4. 전압 이득이 100배인 증폭 회로의 이득을 데시벨로 나타내면 얼마입니까?
  5. 연산 증폭기의 반전 증폭 회로에서 귀환 저항을 커패시터로 바꾼 회로를 무엇이라고 합니까?
