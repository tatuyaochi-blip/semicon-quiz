아날로그·전자 회로

귀환형 발진 회로가 발진을 지속하기 위한 조건으로 올바른 것은 무엇입니까?

  1. A루프 이득이 0이고 위상이 180° 어긋날 것
  2. B루프 이득이 1 이상이고 루프를 한 바퀴 돈 위상 어긋남이 0°(360°)일 것
  3. C입력 신호가 항상 0일 것
정답과 해설 보기

정답: B. 루프 이득이 1 이상이고 루프를 한 바퀴 돈 위상 어긋남이 0°(360°)일 것

발진이 지속되려면 증폭 회로와 귀환 회로를 한 바퀴 돈 신호가 원래와 같은 위상으로, 같거나 그 이상의 크기로 돌아와야 합니다(바르크하우젠 조건: 루프 이득 ≥ 1, 위상 0°). 실제로는 기동 시 루프 이득을 1보다 크게 하여 잡음으로부터 진폭을 키우고, 진폭이 커지면 소자의 포화나 자동 이득 제어로 1에 수렴시킵니다. 대표적인 예는 RC 위상 천이형, 빈 브리지형, 콜피츠형, 수정 발진 회로입니다.

아날로그·전자 회로의 다른 문제

  1. 부귀환을 건 이상적인 연산 증폭기 회로에서 두 입력 단자의 전압이 거의 같아지는 성질을 무엇이라고 합니까?
  2. 연산 증폭기의 입력 오프셋 전압에 대한 설명으로 올바른 것은 무엇입니까?
  3. 커패시터를 신호 경로에 직렬로 넣고 저항을 출력과 접지 사이에 넣은 RC 회로의 특성으로 올바른 것은 무엇입니까?
  4. 리니어 레귤레이터(LDO 등)와 비교했을 때 스위칭 레귤레이터의 특징으로 올바른 것은 무엇입니까?
  5. RC 회로의 계단 응답에서 커패시터 전압이 최종값의 약 63%에 도달하기까지의 시간은 무엇입니까?

이 분야의 비교

  • LDO vs 스위칭 레귤레이터: 효율·노이즈·부품·용도 비교리니어 레귤레이터(LDO)와 스위칭 레귤레이터(DC-DC 컨버터)를 표로 비교합니다: 동작 원리, 효율, 발열, 노이즈, 부품 수, 승압 가능 여부, 부하 응답, 용도. 둘을 조합하는 전원 구성도…
  • 지터와 위상 잡음의 차이: 측정량·단위·측정기·환산·구분 사용 비교클록의 흔들림을 시간 영역에서 보는 지터와 주파수 영역에서 보는 위상 잡음을 측정량, 단위, 측정기, 대표 지표, 적분에 의한 RMS 지터 환산, 사용 분야 관점에서 비교합니다.
  • A급, AB급, D급 앰프의 차이점 정리A급, AB급, D급 전력 증폭기를 표로 비교합니다. 동작 원리, 도통각, 이론 최대 효율, 왜곡, 발열, 노이즈, 용도와 B급과의 관계를 안내합니다.
