아날로그·전자 회로

부귀환을 건 이상적인 연산 증폭기 회로에서 두 입력 단자의 전압이 거의 같아지는 성질을 무엇이라고 합니까?

  1. A슬루 레이트
  2. B오프셋
  3. C가상 단락(이매지너리 쇼트)
정답과 해설 보기

정답: C. 가상 단락(이매지너리 쇼트)

개루프 이득 A가 매우 큰 연산 증폭기에 부귀환을 걸면 출력이 유한한 값에서 균형을 이루기 때문에 입력 단자 간 전압차는 Vout/A로 거의 0이 됩니다. 실제로 연결되어 있지 않은데도 단락된 것처럼 보이므로 가상 단락이라고 하며, 비반전 입력이 접지되어 있으면 반전 입력도 0 V(가상 접지)로 볼 수 있습니다. 연산 증폭기 회로 해석의 기본이지만, 출력이 포화되었을 때나 정귀환 회로(컴퍼레이터)에서는 성립하지 않습니다.

아날로그·전자 회로의 다른 문제

  1. 연산 증폭기의 입력 오프셋 전압에 대한 설명으로 올바른 것은 무엇입니까?
  2. 커패시터를 신호 경로에 직렬로 넣고 저항을 출력과 접지 사이에 넣은 RC 회로의 특성으로 올바른 것은 무엇입니까?
  3. 리니어 레귤레이터(LDO 등)와 비교했을 때 스위칭 레귤레이터의 특징으로 올바른 것은 무엇입니까?
  4. RC 회로의 계단 응답에서 커패시터 전압이 최종값의 약 63%에 도달하기까지의 시간은 무엇입니까?
  5. 포토다이오드의 전류를 전압으로 변환하기 위해 연산 증폭기의 반전 입력에 전류를 넣고 귀환 저항으로 전압으로 바꾸는 회로는 무엇입니까?
