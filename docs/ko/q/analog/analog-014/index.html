아날로그·전자 회로

반전 증폭 회로의 반전 입력 단자에 저항을 통해 여러 입력을 연결한 회로의 역할로 올바른 것은 무엇입니까?

  1. A각 입력 전압의 곱을 출력한다
  2. B입력 전압의 대소를 비교한다
  3. C각 입력 전압의 가중합(부호는 반전)을 출력한다
정답과 해설 보기

정답: C. 각 입력 전압의 가중합(부호는 반전)을 출력한다

반전 입력 단자는 가상 접지이므로 각 입력에서 저항을 통해 흘러 들어오는 전류가 서로 영향을 주지 않고 더해져 귀환 저항으로 흐릅니다. 그 결과 Vout = −Rf(V1/R1 + V2/R2 + …)가 되어 가중 가산이 가능합니다(반전 가산 회로). 오디오 믹서, 저항을 2진 가중치(R, 2R, 4R…)로 한 간단한 DA 컨버터, 센서 신호에 대한 오프셋 가산에 사용됩니다.

아날로그·전자 회로의 다른 문제

  1. 귀환형 발진 회로가 발진을 지속하기 위한 조건으로 올바른 것은 무엇입니까?
  2. 부귀환을 건 이상적인 연산 증폭기 회로에서 두 입력 단자의 전압이 거의 같아지는 성질을 무엇이라고 합니까?
  3. 연산 증폭기의 입력 오프셋 전압에 대한 설명으로 올바른 것은 무엇입니까?
  4. 커패시터를 신호 경로에 직렬로 넣고 저항을 출력과 접지 사이에 넣은 RC 회로의 특성으로 올바른 것은 무엇입니까?
  5. 리니어 레귤레이터(LDO 등)와 비교했을 때 스위칭 레귤레이터의 특징으로 올바른 것은 무엇입니까?
