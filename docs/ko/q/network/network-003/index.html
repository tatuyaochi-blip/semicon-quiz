네트워크 기초

웹 페이지의 데이터를 보낼 때, 송신 측에서 데이터가 위 계층에서 아래 계층으로 넘겨질 때마다 일어나는 일로 올바른 것은?

  1. A각 계층이 각자의 제어 정보(헤더)를 붙여 감싸고, 수신 측에서는 아래 계층부터 차례로 떼어 낸다
  2. B각 계층이 데이터를 압축하므로 아래 계층일수록 보내는 데이터가 작아진다
  3. C위 계층의 헤더를 제거한 뒤 그 계층의 헤더로 바꿔 붙인다
정답과 해설 보기

정답: A. 각 계층이 각자의 제어 정보(헤더)를 붙여 감싸고, 수신 측에서는 아래 계층부터 차례로 떼어 낸다

이 구조를 캡슐화라고 합니다. 애플리케이션의 데이터에 TCP 헤더가 붙어 세그먼트가 되고, IP 헤더가 붙어 패킷이 되며, 이더넷 헤더와 오류 검출 부호(FCS)가 붙어 프레임이 됩니다. 수신 측은 아래 계층부터 차례로 헤더를 읽고 떼어 내며, 각 계층은 자기 헤더의 정보만 보고 처리합니다. 각 계층이 다른 계층의 내용을 몰라도 되므로, 예를 들어 유선 LAN을 무선 LAN으로 바꾸어도 위 계층은 그대로 사용할 수 있습니다. 그 대신 헤더만큼 회선에 흐르는 비트는 애플리케이션의 데이터보다 많아집니다.
