네트워크 기초

NAPT를 수행하는 라우터(외부 공인 주소는 198.51.100.7) 안쪽에 있는 단말 A(192.168.1.10)가 출발지 포트 50000으로 웹 서버 203.0.113.5의 443번 포트에 접속했다. 라우터는 출발지를 198.51.100.7의 포트 61000으로 변환했다. 웹 서버가 돌려보내는 응답 패킷의 목적지는?

  1. A192.168.1.10의 포트 50000
  2. B198.51.100.7의 포트 443
  3. C198.51.100.7의 포트 61000
정답과 해설 보기

정답: C. 198.51.100.7의 포트 61000

서버에서 보이는 출발지는 변환 후의 198.51.100.7 포트 61000이므로 응답은 그곳으로 돌아옵니다. 라우터는 변환 테이블에서 '61000 ↔ 192.168.1.10의 포트 50000' 대응을 찾아 목적지 주소와 포트를 바꿔 써서 단말 A에 전달합니다. 서버는 사설 주소인 192.168.1.10을 알지 못합니다. 설령 안다고 해도 인터넷에는 사설 주소로 가는 경로가 없으므로 도달하지 않습니다. 443은 서버 측 포트(HTTPS)이며, 응답 패킷에서는 출발지 포트가 됩니다.
