네트워크 기초

인터넷 VPN에 대한 설명으로 올바른 것은?

  1. A통신 경로를 전용 물리 회선으로 전환하여 인터넷을 거치지 않게 한다
  2. BVPN을 사용하면 접속한 서버나 단말이 악성코드에 감염되어 있어도 안전하게 통신할 수 있다
  3. C인터넷 위에 암호화와 인증을 수행하는 가상의 전용 통신로(터널)를 만들어, 떨어진 거점이나 재택 단말을 사내 네트워크에 연결된 것처럼 다룬다
정답과 해설 보기

정답: C. 인터넷 위에 암호화와 인증을 수행하는 가상의 전용 통신로(터널)를 만들어, 떨어진 거점이나 재택 단말을 사내 네트워크에 연결된 것처럼 다룬다

VPN(가상 사설망)에서는 원래 패킷을 암호화하여 다른 패킷 안에 넣어(캡슐화하여) 보내고, 상대편 VPN 장치에서 꺼냅니다. 도중의 경로에서는 내용이나 사내 주소가 보이지 않으며 변조도 검출할 수 있습니다. 사용되는 프로토콜로는 IPsec, TLS를 사용하는 것, WireGuard 등이 있습니다. 물리적으로는 공유된 인터넷을 거친다는 점이 전용선과 다릅니다. 보호되는 것은 터널 구간뿐이므로, 접속 대상 자체의 안전이나 VPN 출구 너머 통신의 안전은 따로 생각해야 합니다.
