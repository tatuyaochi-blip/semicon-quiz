네트워크 기초

IP 주소 192.168.10.77/27인 단말이 속한 서브넷의 브로드캐스트 주소는?

  1. A192.168.10.95
  2. B192.168.10.127
  3. C192.168.10.255
정답과 해설 보기

정답: A. 192.168.10.95

/27은 호스트부가 32 − 27 = 5비트이므로 서브넷 하나의 주소는 2^5 = 32개이고, 네 번째 옥텟은 0, 32, 64, 96… 단위로 구획이 시작됩니다. 77은 64~95 범위에 있으므로 네트워크 주소는 192.168.10.64이고, 호스트부를 모두 1로 한 브로드캐스트 주소는 64 + 32 − 1 = 95로 192.168.10.95입니다. 호스트에 할당할 수 있는 것은 .65~.94의 30개입니다. /27의 서브넷 마스크는 255.255.255.224입니다.
