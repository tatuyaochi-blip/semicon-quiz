네트워크 기초

CIDR 표기 /20을 서브넷 마스크로 나타낸 것은?

  1. A255.255.240.0
  2. B255.255.255.240
  3. C255.255.248.0
정답과 해설 보기

정답: A. 255.255.240.0

/20은 상위 20비트가 1인 마스크입니다. 처음 16비트로 255.255가 되고, 나머지 4비트는 세 번째 옥텟의 상위 4비트에 들어갑니다. 2진수 11110000은 128 + 64 + 32 + 16 = 240이므로 서브넷 마스크는 255.255.240.0입니다. 호스트부는 12비트이며 2^12 − 2 = 4094대를 수용할 수 있습니다. 255.255.255.240은 상위 28비트가 1인 /28, 255.255.248.0은 상위 21비트가 1인 /21입니다.
