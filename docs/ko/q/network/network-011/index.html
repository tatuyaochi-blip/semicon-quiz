네트워크 기초

서브넷 하나에 호스트 500대를 수용하려고 한다. 이를 만족하는 서브넷 중 가장 작은 것(프리픽스 길이가 가장 긴 것)은?

  1. A/24
  2. B/22
  3. C/23
정답과 해설 보기

정답: C. /23

프리픽스 길이 n인 서브넷에 수용할 수 있는 호스트 수는 2^(32 − n) − 2입니다. /24는 호스트부 8비트로 2^8 − 2 = 254대이므로 부족합니다. /23은 호스트부 9비트로 2^9 − 2 = 510대가 되어 500대를 수용할 수 있습니다. /22는 2^10 − 2 = 1022대로 수용은 가능하지만 필요한 양의 약 2배의 주소를 사용하게 됩니다. /23의 서브넷 마스크는 255.255.254.0이며, 예를 들어 10.0.2.0/23은 10.0.2.0~10.0.3.255 범위가 됩니다.
