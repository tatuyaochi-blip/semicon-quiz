GPU 프로그래밍

GPU 캐시에 대해 CPU와 비교한 일반적인 특징으로 올바른 것은?

  1. AGPU에는 캐시가 전혀 없다
  2. BGPU에도 L1이나 L2 캐시는 있지만 동시에 동작하는 스레드 수가 매우 많아서 스레드당 캐시 용량은 훨씬 작다
  3. CGPU 캐시는 스레드당 CPU의 몇 배나 크다
정답과 해설 보기

정답: B. GPU에도 L1이나 L2 캐시는 있지만 동시에 동작하는 스레드 수가 매우 많아서 스레드당 캐시 용량은 훨씬 작다

GPU도 SM별 L1 캐시와 칩 전체가 공유하는 L2 캐시를 가지고 있지만, 수만 개의 스레드가 동시에 동작하므로 스레드당 사용할 수 있는 용량은 CPU의 스레드 하나보다 자릿수가 다르게 작아집니다. 캐시에 의존하여 지연을 줄이는 것이 아니라, 다수의 워프 전환으로 지연을 숨기고 병합 접근이나 공유 메모리로 메모리 사용 방식을 궁리하는 것이 GPU의 사고방식입니다.
