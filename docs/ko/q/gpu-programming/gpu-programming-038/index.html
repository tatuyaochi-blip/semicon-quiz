GPU 프로그래밍

가정용 게임 GPU 대부분에서 배정밀도(FP64) 연산 성능이 단정밀도(FP32)보다 훨씬 낮은(수십 분의 일 등) 이유로 가장 적절한 것은?

  1. A그래픽스나 AI에서는 단정밀도 이하로 충분하므로 회로 면적을 배정밀도 연산기에 많이 할애하지 않기 때문
  2. B배정밀도 계산은 물리적으로 불가능하기 때문
  3. C배정밀도 계산은 CPU에만 허용되어 있기 때문
정답과 해설 보기

정답: A. 그래픽스나 AI에서는 단정밀도 이하로 충분하므로 회로 면적을 배정밀도 연산기에 많이 할애하지 않기 때문

배정밀도 연산기는 단정밀도의 수 배의 면적과 전력을 사용합니다. 게임 영상이나 AI 추론에서는 단정밀도나 반정밀도로 충분하므로, 가정용 GPU는 배정밀도 연산기를 줄이고 그만큼을 단정밀도 등에 돌립니다. 기상이나 유체 시뮬레이션처럼 배정밀도가 필요한 과학기술 계산에는 배정밀도 성능을 높인 데이터센터용 GPU가 사용됩니다.
