정답과 해설 보기

정답: B. 데이터 전송과 커널 실행을 겹쳐서 동시에 진행하여 전체 시간을 단축하기 위해

스트림은 GPU에 내리는 처리(전송이나 커널 실행)의 순서열입니다. 같은 스트림 안에서는 순서대로 실행되지만, 다른 스트림의 처리는 동시에 진행할 수 있습니다. 데이터를 나누어 첫 번째 부분을 계산하는 동안 두 번째 부분을 전송하는 식으로 겹치면, 전송과 계산 시간의 대부분이 겹쳐져 전체 시간이 단축됩니다.
