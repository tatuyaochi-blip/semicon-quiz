GPU의 점유율에 대해 올바른 것은?

  1. A점유율이 100%이면 반드시 최고 성능이 나온다
  2. B점유율이 낮아도 한 스레드에 독립적인 계산을 많이 갖게 하여 명령 수준 병렬성을 높이면 높은 성능이 나오는 경우가 있다
  3. C점유율은 성능과 전혀 관계가 없다
정답과 해설 보기

정답: B. 점유율이 낮아도 한 스레드에 독립적인 계산을 많이 갖게 하여 명령 수준 병렬성을 높이면 높은 성능이 나오는 경우가 있다

점유율은 지연을 숨기기 위한 수단의 하나이지 목적이 아닙니다. 한 스레드가 서로 의존하지 않는 여러 계산이나 메모리 읽기를 나란히 발행할 수 있다면 적은 워프로도 대기 시간을 메울 수 있습니다. 반대로 점유율을 높이려고 레지스터를 줄이면 메모리로의 밀려남이 늘어 느려질 수도 있습니다. 성능은 프로파일러로 실제로 측정하여 판단하는 것이 확실합니다.
