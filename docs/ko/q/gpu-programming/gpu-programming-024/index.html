GPU 프로그래밍

GPU가 메모리의 긴 지연(수백 클럭)을 숨기는 주된 방법으로 올바른 것은?

  1. ACPU보다 몇 배나 큰 캐시를 스레드마다 가진다
  2. B어떤 워프가 메모리를 기다리는 동안 실행 가능한 다른 워프로 전환하여 연산기를 계속 가동한다
  3. C메모리를 기다리지 않고 데이터 값을 추측하여 계산한다
정답과 해설 보기

정답: B. 어떤 워프가 메모리를 기다리는 동안 실행 가능한 다른 워프로 전환하여 연산기를 계속 가동한다

CPU는 대용량 캐시와 복잡한 회로로 하나의 스레드의 대기를 줄이지만, GPU는 수많은 워프를 올려 두고 메모리를 기다리는 워프는 옆으로 치워 둔 채 바로 실행할 수 있는 다른 워프의 명령을 발행합니다. 레지스터가 모두 칩 상에 있으므로 전환에 부담이 없습니다. 충분한 수의 워프가 있으면 메모리 지연 동안에도 연산기를 쉬게 하지 않을 수 있습니다.
