GPU 프로그래밍

CUDA에서 블록당 스레드 수를 정할 때의 일반적인 기준으로 올바른 것은?

  1. A워프 크기인 32의 배수로 한다(128이나 256 등)
  2. B반드시 1로 한다
  3. C반드시 소수로 한다
정답과 해설 보기

정답: A. 워프 크기인 32의 배수로 한다(128이나 256 등)

블록의 스레드는 32개씩 워프로 나뉘므로, 예컨대 100개로 하면 마지막 워프는 4개만 사용하고 나머지 28개 분량의 실행 슬롯이 낭비됩니다. 32의 배수로 해 두면 모든 워프를 가득 사용할 수 있습니다. 실제로는 128~256개 정도가 자주 사용되며, 점유율이나 공유 메모리 사용 방식을 보면서 조정합니다.
