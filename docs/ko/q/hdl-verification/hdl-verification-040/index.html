HDL과 검증

회로 설계에서 수행하는 회귀 테스트(리그레션 테스트)에 대한 설명으로 올바른 것은?

  1. A새로 만든 기능만 한 번 시험한다
  2. B회로의 성능이 해마다 떨어지는 경향을 조사한다
  3. C설계를 변경할 때마다 지금까지의 테스트를 한꺼번에 다시 실행하여, 이전에는 올바르던 기능이 망가지지 않았는지 확인한다
정답과 해설 보기

정답: C. 설계를 변경할 때마다 지금까지의 테스트를 한꺼번에 다시 실행하여, 이전에는 올바르던 기능이 망가지지 않았는지 확인한다

어떤 불량을 고치거나 기능을 추가하면 뜻하지 않은 곳에서 다른 부분이 망가지는 경우가 있습니다. 회귀 테스트에서는 지금까지 만든 테스트를 모두 한꺼번에 자동으로 실행하여, 이전에 통과하던 테스트가 실패하지 않는지 확인합니다. 대규모 설계에서는 수천 개의 테스트를 거의 매일 실행하고 결과를 목록으로 관리합니다. 자체 검사형 테스트벤치가 있어야 비로소 이러한 자동화가 가능합니다.

  • 블로킹 할당 vs 논블로킹 할당: 평가 타이밍·순서·사용 위치 비교Verilog의 블로킹 할당(=)과 논블로킹 할당(<=)을 표로 비교합니다: 좌변을 갱신하는 타이밍, 기술 순서에 대한 의존성, 사용 위치(조합 회로와 순차 회로), 시뮬레이션과 합성의 불일치.
