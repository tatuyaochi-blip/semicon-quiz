HDL과 검증

위 기술의 리셋 종류와 동작으로 올바른 것은?

always @(posedge clk or negedge rst_n)
    if (!rst_n) q <= 0;
    else        q <= d;
  1. A동기 리셋으로, rst_n이 0인 상태에서 클럭이 상승했을 때에만 q가 0이 된다
  2. B비동기 리셋으로, rst_n이 0이 되면 클럭을 기다리지 않고 곧바로 q가 0이 된다
  3. Crst_n이 1이 되면 q가 0이 된다
정답과 해설 보기

정답: B. 비동기 리셋으로, rst_n이 0이 되면 클럭을 기다리지 않고 곧바로 q가 0이 된다

센서티비티 리스트에 'negedge rst_n'이 포함되어 있으므로, rst_n이 1에서 0으로 바뀌는 순간에도 블록이 실행되어 클럭과 관계없이 q가 0이 됩니다. 이것이 비동기 리셋입니다. 이름의 '_n'은 0에서 유효해지는 부논리 신호를 나타내는 관례입니다. 클럭이 멈춰 있어도 리셋할 수 있다는 장점이 있지만, 리셋을 해제하는 타이밍에는 주의가 필요합니다.
