HDL과 검증

위의 Verilog 기술이 논리 합성으로 만드는 회로로 올바른 것은?

always @(posedge clk)
    q <= d;
  1. Ad와 clk의 AND 회로
  2. B클럭의 상승 에지에서 d를 받아들이는 D 플립플롭
  3. C클럭이 1인 동안 계속 d를 통과시키는 래치
정답과 해설 보기

정답: B. 클럭의 상승 에지에서 d를 받아들이는 D 플립플롭

'always @(posedge clk)'는 클럭이 상승하는 순간에만 안의 대입을 수행한다는 의미이며, 논리 합성은 이를 에지에서 동작하는 플립플롭으로 만듭니다. q는 클럭 상승 시점의 d 값을 다음 상승까지 유지합니다. 동기식 회로에서는 대부분의 기억 소자가 이 형태로 기술됩니다. 클럭 에지가 아닌 레벨로 동작하는 래치와는 구별해야 합니다.
