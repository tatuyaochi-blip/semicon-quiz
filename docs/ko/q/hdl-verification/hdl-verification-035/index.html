HDL과 검증

자기 검사형(self-checking) 테스트벤치의 특징으로 올바른 것은?

  1. A사람이 파형을 눈으로 보고 올바른지 매번 판단한다
  2. B출력을 기대값과 자동으로 비교하고, 일치하는지를 테스트벤치 스스로 판정하여 보고한다
  3. C회로를 제조한 뒤 실물로 확인한다
정답과 해설 보기

정답: B. 출력을 기대값과 자동으로 비교하고, 일치하는지를 테스트벤치 스스로 판정하여 보고한다

파형을 눈으로 확인하는 방법은 작은 회로의 확인에는 편리하지만, 테스트 수가 늘어나면 놓치는 부분이 생기고 변경할 때마다 다시 확인할 수도 없습니다. 자기 검사형 테스트벤치는 입력마다 기대되는 출력을 계산하거나 표로 가지고 있다가 회로의 출력과 자동으로 비교하며, 불일치가 있으면 오류로 보고합니다. 수천 개의 테스트를 밤사이에 자동으로 실행하고 결과만 확인할 수 있습니다.

  • A. 그것은 자기 검사가 아닙니다.
  • B. 올바릅니다. 대량의 테스트를 자동으로 돌릴 수 있습니다.
  • C. 제조 전 시뮬레이션에서 수행합니다.

HDL과 검증의 다른 문제

  1. 검증에서 C 언어 등으로 작성한 참조 모델(골든 모델)을 사용하는 목적으로 올바른 것은?
  2. 시뮬레이션 결과를 VCD 등의 형식 파일로 내보내는 주된 목적은?
  3. 랜덤 입력을 사용하는 테스트에서 난수 시드(seed)를 기록해 두는 이유로 올바른 것은?
  4. SystemVerilog의 제약 조건 기반 랜덤 검증(constrained random verification)에 대한 설명으로 올바른 것은?
  5. 회로 설계에서 수행하는 회귀 테스트(regression test)의 설명으로 올바른 것은?
