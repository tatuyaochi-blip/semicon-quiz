HDL과 검증

Verilog에서 8비트 신호 a와 b를 더하여 그 결과를 8비트 신호 s에 대입했다(assign s = a + b;). 주의해야 할 점으로 올바른 것은?

  1. A8비트끼리의 덧셈은 Verilog에서는 쓸 수 없다
  2. B결과는 자동으로 16비트로 확장된다
  3. C합이 255를 넘으면 9번째 비트의 자리올림이 버려지므로, 자리올림이 필요하면 s를 9비트로 한다
정답과 해설 보기

정답: C. 합이 255를 넘으면 9번째 비트의 자리올림이 버려지므로, 자리올림이 필요하면 s를 9비트로 한다

8비트끼리의 합은 최대 255+255=510이 되어 나타내려면 9비트가 필요합니다. 대입 대상 s가 8비트이면 상위 자리올림은 조용히 버려져, 예를 들어 200+100은 44가 되어 버립니다. 자리올림도 사용하고 싶을 때는 s를 9비트로 선언합니다. Verilog는 폭이 다른 신호의 대입을 에러로 처리하지 않고 잘라내거나 확장하므로, Lint 툴로 폭 불일치를 검사하는 것이 효과적입니다.

  2. Verilog 시뮬레이션에서 사용되는 4값 논리의 값의 조합으로 올바른 것은?
  3. 시뮬레이션에서 리셋이 없는 레지스터의 값이 처음에 X였다. 실제 칩에서는 어떻게 된다고 생각할 수 있습니까?
  4. 위 기술에서 sel이 X(불정)일 때 Verilog 시뮬레이션에서는 y에 b가 선택된다. 이 성질이 검증에서 문제가 되는 이유로 올바른 것은?
  5. HDL에서 Z(하이 임피던스)를 출력하는 트라이스테이트 기술에 대해 일반적으로 올바른 것은?

이 분야의 비교

  • Verilog와 VHDL: 두 HDL의 차이점Verilog와 VHDL을 표로 비교합니다. 기원, 문법, 타입 체계, 대소문자 구분, 검증 기능, 사용층, 선택 방법을 다룹니다.
  • 블로킹 할당 vs 논블로킹 할당: 평가 타이밍·순서·사용 위치 비교Verilog의 블로킹 할당(=)과 논블로킹 할당(<=)을 표로 비교합니다: 좌변을 갱신하는 타이밍, 기술 순서에 대한 의존성, 사용 위치(조합 회로와 순차 회로), 시뮬레이션과 합성의 불일치.
  • 동기 리셋 vs 비동기 리셋: 타이밍·클럭·해제 시 주의점 비교동기 리셋과 비동기 리셋을 표로 비교합니다: 적용되는 타이밍, 클럭 필요 여부, 글리치에 대한 강도, 타이밍 분석, 리셋 해제 시 동기화, 면적, Verilog 작성법. 각각에 적합한 회로도 설명…
