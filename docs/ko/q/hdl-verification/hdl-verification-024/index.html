HDL과 검증

3개의 상태를 가진 상태 머신에서 상태를 기억하는 데 필요한 플립플롭 수의 조합으로 올바른 것은?(바이너리 부호화/원핫 부호화)

  1. A3개/2개
  2. B2개/3개
  3. C1개/3개
정답과 해설 보기

정답: B. 2개/3개

바이너리 부호화에서는 상태를 2진수 번호로 나타내므로, 3개의 상태에는 00, 01, 10의 2비트(플립플롭 2개)면 충분합니다. 원핫 부호화에서는 상태마다 플립플롭 하나를 사용하므로 3개입니다. 바이너리에서는 사용하지 않는 11 부호가 남으므로, 노이즈 등으로 그곳에 들어갔을 때 올바른 상태로 복귀할 수 있도록 default에서 이동 위치를 정해 두면 안전합니다.

HDL과 검증의 다른 문제

  1. 위의 4비트 카운터에서 count가 15일 때 클럭이 상승하면 count는 얼마가 됩니까?
  2. Verilog에서 8비트 신호 a와 b를 더하여 그 결과를 8비트 신호 s에 대입했다(assign s = a + b;). 주의해야 할 점으로 올바른 것은?
  3. a를 부호 있는 -1로 의도하여 위와 같이 작성했더니 gt가 1이 되었다. 이유로 올바른 것은?
  4. Verilog 시뮬레이션에서 사용되는 4값 논리의 값의 조합으로 올바른 것은?
  5. 시뮬레이션에서 리셋이 없는 레지스터의 값이 처음에 X였다. 실제 칩에서는 어떻게 된다고 생각할 수 있습니까?
