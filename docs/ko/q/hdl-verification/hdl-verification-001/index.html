HDL과 검증

Verilog 같은 HDL로 작성한 기술과 C 언어 같은 소프트웨어 프로그램의 큰 차이로 올바른 것은?

  1. AHDL 기술은 동시에 병렬로 동작하는 회로를 나타낸다
  2. BHDL 기술은 위쪽 행부터 한 줄씩 순서대로 실행되는 명령의 나열이다
  3. CHDL에서는 변수나 조건 분기를 사용할 수 없다
정답과 해설 보기

정답: A. HDL 기술은 동시에 병렬로 동작하는 회로를 나타낸다

HDL은 겉모습이 프로그램과 비슷하지만, 작성한 내용은 논리 합성을 통해 게이트와 플립플롭 회로가 됩니다. 회로의 각 부분은 항상 동시에 동작하므로, 여러 assign문이나 always 블록은 작성한 순서와 관계없이 병렬로 작동합니다. 소프트웨어처럼 "이 처리가 끝나면 다음"이라고 생각하면 의도한 회로가 만들어지지 않으므로, 어떤 회로가 만들어질지 상상하면서 작성하는 것이 중요합니다.

  • A. 올바릅니다. 각 부분의 회로는 항상 동시에 동작합니다.
  • B. 그것은 소프트웨어의 사고방식입니다.
  • C. HDL에서도 신호와 조건 분기를 사용할 수 있습니다.
