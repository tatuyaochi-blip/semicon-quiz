HDL과 검증

상태 머신의 상태 부호화에서 원핫(one-hot) 부호화의 특징으로 올바른 것은?

  1. A상태를 2진수로 나타내며 플립플롭 수를 가장 적게 한다
  2. B모든 플립플롭이 항상 1이 된다
  3. C상태 수만큼 플립플롭을 사용하고 항상 하나만 1이 되므로, 다음 상태나 출력의 논리가 간단하고 빨라지기 쉽다
정답과 해설 보기

정답: C. 상태 수만큼 플립플롭을 사용하고 항상 하나만 1이 되므로, 다음 상태나 출력의 논리가 간단하고 빨라지기 쉽다

원핫 부호화에서는 예를 들어 4개의 상태를 0001, 0010, 0100, 1000처럼 나타내고 각 상태에 플립플롭 하나를 할당합니다. 플립플롭은 늘어나지만 특정 상태에 있는지는 1비트만 보면 알 수 있으므로, 다음 상태나 출력을 결정하는 논리가 얕고 빨라집니다. 플립플롭이 풍부한 FPGA에서 자주 사용되며, 플립플롭 수를 줄이고 싶을 때는 바이너리 부호화를 사용합니다.

HDL과 검증의 다른 문제

  1. 3개의 상태를 가진 상태 머신에서 상태를 기억하는 데 필요한 플립플롭 수의 조합으로 올바른 것은?(바이너리 부호화/원핫 부호화)
  2. 위의 4비트 카운터에서 count가 15일 때 클럭이 상승하면 count는 얼마가 됩니까?
  3. Verilog에서 8비트 신호 a와 b를 더하여 그 결과를 8비트 신호 s에 대입했다(assign s = a + b;). 주의해야 할 점으로 올바른 것은?
  4. a를 부호 있는 -1로 의도하여 위와 같이 작성했더니 gt가 1이 되었다. 이유로 올바른 것은?
  5. Verilog 시뮬레이션에서 사용되는 4값 논리의 값의 조합으로 올바른 것은?

이 분야의 비교

  • Verilog와 VHDL: 두 HDL의 차이점Verilog와 VHDL을 표로 비교합니다. 기원, 문법, 타입 체계, 대소문자 구분, 검증 기능, 사용층, 선택 방법을 다룹니다.
  • 블로킹 할당 vs 논블로킹 할당: 평가 타이밍·순서·사용 위치 비교Verilog의 블로킹 할당(=)과 논블로킹 할당(<=)을 표로 비교합니다: 좌변을 갱신하는 타이밍, 기술 순서에 대한 의존성, 사용 위치(조합 회로와 순차 회로), 시뮬레이션과 합성의 불일치.
  • 동기 리셋 vs 비동기 리셋: 타이밍·클럭·해제 시 주의점 비교동기 리셋과 비동기 리셋을 표로 비교합니다: 적용되는 타이밍, 클럭 필요 여부, 글리치에 대한 강도, 타이밍 분석, 리셋 해제 시 동기화, 면적, Verilog 작성법. 각각에 적합한 회로도 설명…
