HDL과 검증

HDL로 작성하는 상태 머신(스테이트 머신)의 기본 구성으로 올바른 것은?

  1. A상태를 기억하는 메모리만 있고 논리 회로는 사용하지 않는다
  2. B출력을 정하는 회로만 있고 상태는 기억하지 않는다
  3. C현재 상태를 기억하는 레지스터, 다음 상태를 정하는 조합 회로, 출력을 정하는 조합 회로
정답과 해설 보기

정답: C. 현재 상태를 기억하는 레지스터, 다음 상태를 정하는 조합 회로, 출력을 정하는 조합 회로

상태 머신은 현재 상태를 플립플롭 레지스터에 기억해 두고, 현재 상태와 입력으로부터 다음 상태를 조합 회로로 정하여 클록 에지에서 상태를 갱신합니다. 출력은 현재 상태(와 입력)로부터 조합 회로로 정합니다. 통신 절차 제어나 자동판매기, 신호등 제어처럼 절차에 따라 동작하는 회로의 대부분은 상태 머신으로 기술됩니다.

  • A. 다음 상태를 정하는 논리가 필요합니다.
  • B. 상태를 기억하는 레지스터가 필요합니다.
  • C. 올바릅니다. 상태는 클록으로 갱신합니다.

HDL과 검증의 다른 문제

  1. 위 상태 머신 기술에서 두 번째 always 블록 맨 앞에 "next = state;"를 쓴 이유로 올바른 것은?
  2. 밀리(Mealy)형 상태 머신의 특징으로 올바른 것은?
  3. 상태 머신의 상태 부호화에서 원핫(one-hot) 부호화의 특징으로 올바른 것은?
  4. 3개의 상태를 가진 상태 머신에서 상태를 기억하는 데 필요한 플립플롭 수의 조합으로 올바른 것은? (바이너리 부호화/원핫 부호화)
  5. 위 4비트 카운터에서 count가 15일 때 클록이 상승하면 count는 얼마가 되는가?
