  1. AMRAM
  2. BDRAM
  3. CSRAM
정답과 해설 보기

정답: A. MRAM

MRAM은 자성체의 자화 방향으로 기억하므로 전원을 꺼도 데이터가 남는 비휘발성 메모리이며, 유지 기간은 일반적으로 10년 이상입니다. DRAM과 SRAM은 모두 전원을 끄면 데이터가 사라지는 휘발성 메모리입니다. MRAM은 SRAM에 가까운 속도와 비휘발성을 겸비하고 있어, 전원을 빈번하게 끄는 저전력 시스템이나 정전 시에도 데이터를 지키고 싶은 산업 기기에서 중요하게 쓰이고 있습니다.

차세대 메모리의 다른 문제

  1. MRAM의 'M'이 나타내는 것으로 올바른 것은 무엇입니까?
  2. 많은 차세대 메모리의 연구 개발에서 목표로 삼아 온 '유니버설 메모리'의 개념으로 올바른 것은 무엇입니까?
  3. FeRAM의 'Fe'가 나타내는 것으로 올바른 것은 무엇입니까?
  4. MRAM에서 1비트의 정보를 기억하는 소자로 사용되는, 두 개의 자성층이 얇은 절연층을 끼운 구조를 무엇이라고 합니까?
  5. MTJ의 터널 자기저항비(TMR비)에 대한 설명으로 올바른 것은 무엇입니까?
