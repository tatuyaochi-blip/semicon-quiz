차세대 메모리

강유전체의 히스테리시스 곡선(분극-전계 특성)에서 전계를 0으로 되돌려도 남는 분극을 무엇이라고 합니까?

  1. A잔류 분극
  2. B포화 자화
  3. C절연 파괴 전계
정답과 해설 보기

정답: A. 잔류 분극

강유전체에 전계를 가해 분극시킨 뒤 전계를 0으로 되돌려도 남는 분극을 잔류 분극(Pr)이라고 하며, 그 방향(양인지 음인지)으로 0과 1을 기억하는 것이 FeRAM의 원리입니다. 분극을 반전시키는 데 필요한 전계를 항전계(Ec)라고 합니다. 읽기 신호는 잔류 분극의 크기에 비례하므로, Pr이 크고 Ec가 적당히 작은(저전압으로 쓸 수 있는) 재료가 요구됩니다.

차세대 메모리의 다른 문제

  1. MRAM을 사용할 때 주의가 필요한 외부 환경으로 올바른 것은 무엇입니까?
  2. MRAM이나 FeRAM이 우주 기기 등 방사선이 많은 환경에서 사용되는 경우가 있는 이유로 올바른 것은 무엇입니까?
  3. 과거 Intel과 Micron이 공동 개발하여 'Optane'이라는 제품명으로 판매된 스토리지 클래스 메모리 기술은 무엇입니까?
  4. 상변화 메모리(PCM)에서 하나의 셀에 여러 비트를 기억시키는(다치화하는) 방법으로 올바른 것은 무엇입니까?
  5. 은이나 구리 등의 금속 이온이 고체 전해질 속을 이동하여 전도 경로를 만들거나 끊음으로써 저항을 바꾸는 메모리는 무엇입니까?
