차세대 메모리

FeRAM의 'Fe'가 나타내는 것으로 올바른 것은 무엇입니까?

  1. A고속(Fast)이라는 것
  2. B강유전체(Ferroelectric)를 사용한다는 것
  3. C철(원소 기호 Fe)을 기억층에 사용한다는 것
정답과 해설 보기

정답: B. 강유전체(Ferroelectric)를 사용한다는 것

FeRAM의 'Fe'는 Ferroelectric(강유전체)의 약자이며, 철을 사용한다는 의미가 아닙니다. 강유전체의 '강'은 자석의 강자성체(ferromagnet)와의 유사성에서 이름 붙여진 것으로, 분극과 전계의 관계가 자화와 자기장의 관계처럼 히스테리시스를 그리는 데서 유래합니다. 대표적인 재료는 PZT나 SBT, 새로운 것으로는 HfO2 계열이며, 어느 쪽도 철이 주성분은 아닙니다.

차세대 메모리의 다른 문제

  1. MRAM에서 1비트의 정보를 기억하는 소자로 사용되는, 두 개의 자성층이 얇은 절연층을 끼운 구조를 무엇이라고 합니까?
  2. MTJ의 터널 자기저항비(TMR비)에 대한 설명으로 올바른 것은 무엇입니까?
  3. MTJ에서 두 자성층의 자화 방향이 평행일 때와 반평행일 때의 저항 관계로 올바른 것은 무엇입니까?
  4. MTJ를 구성하는 두 자성층의 역할로 올바른 것은 무엇입니까?
  5. 상변화 메모리(PCM)에서 셀을 저저항의 결정 상태로 만들(셋할) 때의 가열 방법으로 올바른 것은 무엇입니까?
