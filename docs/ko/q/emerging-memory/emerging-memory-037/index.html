차세대 메모리

MTJ에서 두 자성층의 자화 방향이 평행일 때와 반평행일 때의 저항 관계로 올바른 것은 무엇입니까?

  1. A둘 다 같은 저항이다
  2. B평행일 때가 저항이 높다
  3. C평행일 때가 저항이 낮다
정답과 해설 보기

정답: C. 평행일 때가 저항이 낮다

자성체 내에서는 다수 스핀과 소수 스핀의 전자에서 상태 수가 다릅니다. 자화가 평행일 때는 양쪽에서 다수 스핀끼리 대응하므로 전자가 터널링하기 쉬워 저항이 낮아지고, 반평행일 때는 한쪽의 다수 스핀이 다른 쪽의 소수 스핀 상태에만 들어갈 수 있어 터널링하기 어려우므로 저항이 높아집니다. 이 저항의 차이로 0과 1을 구분합니다.

차세대 메모리의 다른 문제

  1. MTJ를 구성하는 두 자성층의 역할로 올바른 것은 무엇입니까?
  2. 상변화 메모리(PCM)에서 셀을 저저항의 결정 상태로 만들(셋할) 때의 가열 방법으로 올바른 것은 무엇입니까?
  3. 강유전체의 히스테리시스 곡선(분극-전계 특성)에서 전계를 0으로 되돌려도 남는 분극을 무엇이라고 합니까?
  4. MRAM을 사용할 때 주의가 필요한 외부 환경으로 올바른 것은 무엇입니까?
  5. MRAM이나 FeRAM이 우주 기기 등 방사선이 많은 환경에서 사용되는 경우가 있는 이유로 올바른 것은 무엇입니까?
