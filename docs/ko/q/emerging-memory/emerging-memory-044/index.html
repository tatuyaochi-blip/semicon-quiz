차세대 메모리

상변화 메모리(PCM)에서 하나의 셀에 여러 비트를 기억시키는(다치화하는) 방법으로 올바른 것은 무엇입니까?

  1. A셀의 색을 바꾼다
  2. B셀의 자화 방향을 여러 가지로 한다
  3. C셀 속 비정질 영역의 크기 등을 제어하여 중간 저항값을 만들어 구분한다
정답과 해설 보기

정답: C. 셀 속 비정질 영역의 크기 등을 제어하여 중간 저항값을 만들어 구분한다

PCM에서는 셀 내 비정질 영역의 크기(결정 부분과의 비율)를 쓰기 펄스의 높이나 길이로 제어하면, 고저항과 저저항 사이의 중간 저항값을 만들 수 있습니다. 저항 차이가 2~3자릿수로 크므로 여러 레벨을 구분하면 1셀에 2비트 이상을 기억시킬 수 있습니다. 다만 저항 드리프트나 온도에 의한 변화가 있으므로, 쓰기 후 확인하여 조정하는 방식이나 드리프트를 보정하는 읽기 방법이 필요합니다.

차세대 메모리의 다른 문제

  1. 은이나 구리 등의 금속 이온이 고체 전해질 속을 이동하여 전도 경로를 만들거나 끊음으로써 저항을 바꾸는 메모리는 무엇입니까?
  2. ReRAM의 동작 방식에서 '바이폴라형'과 '유니폴라형'의 차이로 올바른 것은 무엇입니까?
  3. 크로스포인트형 PCM 등에서 기억 소자와 직렬로 두는 셀렉터로 사용되는, 어떤 전압을 넘으면 갑자기 도통하는 칼코게나이드 재료 소자는 무엇입니까?
  4. STT-MRAM에서 읽기 전류의 크기에 제한이 필요한 이유로 올바른 것은 무엇입니까?
  5. 강유전체의 분극 방향에 따라 얇은 강유전체층을 통과하는 터널 전류의 크기가 달라지는 것을 이용하는 소자는 무엇입니까?
