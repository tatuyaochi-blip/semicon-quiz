차세대 메모리

최근 STT-MRAM에서 자화 방향이 막면에 수직인 MTJ(수직 자화 MTJ)가 주류가 된 이유로 올바른 것은 무엇입니까?

  1. A제조에 자성 재료가 필요 없어지기 때문
  2. B미세화해도 열 안정성을 유지하기 쉽고 쓰기 전류도 낮추기 쉽기 때문
  3. C읽기에 빛을 사용할 수 있기 때문
정답과 해설 보기

정답: B. 미세화해도 열 안정성을 유지하기 쉽고 쓰기 전류도 낮추기 쉽기 때문

막면 내 자화를 가진 MTJ는 타원형 등의 소자 형상으로 자화 방향을 안정시키므로, 작게 하면 안정성을 유지할 수 없습니다. 수직 자화 MTJ는 CoFeB와 MgO의 계면 등에서 생기는 수직 자기 이방성으로 자화를 안정시키므로, 원형의 작은 소자에서도 열 안정성을 확보할 수 있고 쓰기 전류도 작게 할 수 있습니다. 이 재료 기술이 STT-MRAM의 양산화(2010년대 후반)를 가능하게 했습니다.

차세대 메모리의 다른 문제

  1. 저항 변화 소자를 가로세로 배선의 교점에 배치하는 크로스포인트형 메모리에서, 선택하지 않은 셀로 전류가 우회하는 것을 막기 위해 기억 소자와 직렬로 넣는 소자는 무엇입니까?
  2. 게이트 절연막에 강유전체를 사용한 FeFET의 특징으로 올바른 것은 무엇입니까?
  3. 상변화 메모리(PCM)에서 비정질 상태의 저항값이 시간이 지남에 따라 조금씩 증가하는 현상을 무엇이라고 합니까?
  4. MRAM의 데이터 읽기 방법으로 올바른 것은 무엇입니까?
  5. 상변화 메모리의 기록 재료로 대표적인 GST는 어떤 재료입니까?
