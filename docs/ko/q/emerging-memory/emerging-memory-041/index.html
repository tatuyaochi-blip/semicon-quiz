정답: B. 강한 외부 자기장

MRAM은 자화 방향으로 기억하므로, 강한 외부 자기장에 노출되면 기록층의 자화가 흐트러져 데이터가 손실될 우려가 있습니다. 기준으로 수십 mT 이상의 자기장이 문제가 되며, 스마트폰 근처의 자석이나 모터, 의료용 MRI 주변 등이 그 예입니다. 용도에 따라서는 자기 차폐가 있는 패키지를 사용하고, 데이터시트에 정해진 내자기장 값을 지키도록 설계합니다.

차세대 메모리의 다른 문제

  1. MRAM이나 FeRAM이 우주 기기 등 방사선이 많은 환경에서 사용되는 경우가 있는 이유로 올바른 것은 무엇입니까?
  2. 과거 Intel과 Micron이 공동 개발하여 'Optane'이라는 제품명으로 판매된 스토리지 클래스 메모리 기술은 무엇입니까?
  3. 상변화 메모리(PCM)에서 하나의 셀에 여러 비트를 기억시키는(다치화하는) 방법으로 올바른 것은 무엇입니까?
  4. 은이나 구리 등의 금속 이온이 고체 전해질 속을 이동하여 전도 경로를 만들거나 끊음으로써 저항을 바꾸는 메모리는 무엇입니까?
  5. ReRAM의 동작 방식에서 '바이폴라형'과 '유니폴라형'의 차이로 올바른 것은 무엇입니까?
