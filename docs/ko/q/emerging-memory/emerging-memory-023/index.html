차세대 메모리

ReRAM의 저항 변화층으로 연구, 실용화되고 있는 재료의 예로 올바른 것은 무엇입니까?

  1. A구리 단체
  2. B산화하프늄이나 산화탄탈럼 등의 금속 산화물
  3. C단결정 실리콘
정답과 해설 보기

정답: B. 산화하프늄이나 산화탄탈럼 등의 금속 산화물

ReRAM에는 산화하프늄, 산화탄탈럼, 산화티타늄 등의 금속 산화물이 자주 사용됩니다. 전압에 의해 산소 이온이 이동하여 산소가 빠진 부분(산소 결손)이 모인 전도 경로가 생기거나 사라지면서 저항이 변합니다. 산화하프늄이나 산화탄탈럼은 CMOS의 게이트 절연막이나 커패시터에 사용되어 왔기 때문에, 제조 장비와 공정을 그대로 활용하기 쉽다는 점도 장점입니다.
