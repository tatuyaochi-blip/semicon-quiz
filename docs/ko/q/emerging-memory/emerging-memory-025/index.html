정답과 해설 보기

정답: C. 고속, 저소비 전력 쓰기를 살린 IC 카드 등

FeRAM은 쓰기가 빠르고 필요한 전력이 작으며 재기록 횟수도 많아, 비접촉 전파에서 얻는 미세한 전력으로 동작하는 교통카드 IC 카드나 전자 화폐 카드에 사용되어 왔습니다. 그 밖에 전원이 갑자기 꺼져도 데이터를 잃고 싶지 않은 계량기나 의료 기기, 빈번하게 기록하는 계측 기기 등에도 사용됩니다. 한편 커패시터의 미세화가 어려워 용량은 수 Mbit 정도에 그치므로 대용량 용도에는 적합하지 않습니다.
