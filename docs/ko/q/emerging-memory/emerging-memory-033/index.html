차세대 메모리

많은 차세대 메모리의 연구 개발에서 목표로 삼아 온 '유니버설 메모리'의 개념으로 올바른 것은 무엇입니까?

  1. A어떤 기기에도 꽂을 수 있는 메모리 카드
  2. B반드시 자기를 사용하는 메모리
  3. CDRAM 수준의 속도와 재기록 횟수, 플래시 수준의 비휘발성과 대용량을 하나로 겸비한 메모리
정답과 해설 보기

정답: C. DRAM 수준의 속도와 재기록 횟수, 플래시 수준의 비휘발성과 대용량을 하나로 겸비한 메모리

유니버설 메모리는 DRAM이나 SRAM의 속도와 재기록 내구성, 플래시의 비휘발성과 대용량, 저비용을 하나로 구현하려는 개념으로, 실현되면 기억 계층을 단순화할 수 있습니다. 그러나 실제로는 MRAM은 빠르지만 대용량화가 어렵고, PCM은 대용량에 적합하지만 쓰기 전력이 크다는 등 각각 장단점이 있습니다. 현재는 기존 메모리 사이의 틈을 메우는 형태로 용도별로 구분하여 사용되고 있습니다.

차세대 메모리의 다른 문제

  1. FeRAM의 'Fe'가 나타내는 것으로 올바른 것은 무엇입니까?
  2. MRAM에서 1비트의 정보를 기억하는 소자로 사용되는, 두 개의 자성층이 얇은 절연층을 끼운 구조를 무엇이라고 합니까?
  3. MTJ의 터널 자기저항비(TMR비)에 대한 설명으로 올바른 것은 무엇입니까?
  4. MTJ에서 두 자성층의 자화 방향이 평행일 때와 반평행일 때의 저항 관계로 올바른 것은 무엇입니까?
  5. MTJ를 구성하는 두 자성층의 역할로 올바른 것은 무엇입니까?
