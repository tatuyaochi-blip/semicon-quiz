  1. ADRAM과 NAND 플래시 사이의 속도, 용량, 비용 격차를 메우는 비휘발성 메모리
  2. BCPU 내부의 레지스터
  3. C광디스크의 일종
정답과 해설 보기

정답: A. DRAM과 NAND 플래시 사이의 속도, 용량, 비용 격차를 메우는 비휘발성 메모리

DRAM과 NAND 사이에는 액세스 시간이 약 1000배(수십 ns 대 수십 µs), 비트당 단가가 수십 배의 차이가 있습니다. 그 사이를 메우는, DRAM보다 저렴하고 대용량이며 NAND보다 자릿수가 다르게 빠른 비휘발성 메모리를 스토리지 클래스 메모리(SCM)라고 부릅니다. 상변화 메모리를 사용한 Intel의 Optane이 대표적이었지만 2022년에 단종이 발표되어, 현재는 고속 SLC형 NAND나 CXL로 연결하는 메모리 등이 이 영역을 담당하고 있습니다.

차세대 메모리의 다른 문제

  1. 플래시 메모리와 비교했을 때 MRAM의 일반적인 장점으로 올바른 것은 무엇입니까?
  2. 최근 FeRAM이나 강유전체 트랜지스터(FeFET)의 재료로 주목받고 있는, CMOS 공정과 궁합이 좋은 강유전체 재료는 무엇입니까?
  3. 상변화 메모리(PCM)에서 셀을 고저항의 비정질 상태로 만드는(리셋하는) 방법으로 올바른 것은 무엇입니까?
  4. 저항 변화형 메모리 등을 사용한 인메모리 컴퓨팅에서 기대되는 주된 용도는 무엇입니까?
  5. 커패시터형 FeRAM의 읽기 특징으로 올바른 것은 무엇입니까?
