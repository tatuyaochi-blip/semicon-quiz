차세대 메모리

상변화 메모리(PCM)에서 비정질 상태의 저항값이 시간이 지남에 따라 조금씩 증가하는 현상을 무엇이라고 합니까?

  1. A스틱션
  2. B저항 드리프트
  3. C과도 증속 확산

정답: B. 저항 드리프트

PCM의 비정질상은 시간이 지나면서 원자 배치가 약간 완화되어 저항값이 시간의 로그에 비례하도록 서서히 올라갑니다(R ∝ t^ν, ν는 0.1 정도). 이것이 저항 드리프트입니다. 고저항과 저저항의 2치라면 문제가 되기 어렵지만, 중간 저항으로 다치화하면 인접한 레벨과의 구분이 어려워집니다. 기준이 되는 참조 셀을 함께 읽거나 드리프트가 작은 재료를 선택하는 등의 대책을 취합니다.

차세대 메모리의 다른 문제

  1. MRAM의 데이터 읽기 방법으로 올바른 것은 무엇입니까?
  2. 상변화 메모리의 기록 재료로 대표적인 GST는 어떤 재료입니까?
  3. ReRAM의 저항 변화층으로 연구, 실용화되고 있는 재료의 예로 올바른 것은 무엇입니까?
  4. 비휘발성 메모리를 캐시나 레지스터 등에 사용함으로써 기대되는 시스템 저전력화의 원리로 올바른 것은 무엇입니까?
  5. FeRAM이 사용되어 온 대표적인 용도로 올바른 것은 무엇입니까?
