  1. AMTJ에 작은 전류를 흘려 저항의 높고 낮음을 검출한다
  2. B강한 자기장을 걸어 반응을 본다
  3. C빛을 비추어 반사광을 측정한다
정답과 해설 보기

정답: A. MTJ에 작은 전류를 흘려 저항의 높고 낮음을 검출한다

MRAM의 읽기에서는 MTJ에 쓰기보다 작은 전류를 흘려, 평행(저저항)인지 반평행(고저항)인지를 기준 저항과의 비교를 통해 전류나 전압의 차이로 검출합니다. TMR비가 100~200% 정도 되어도 저항 차이는 2~3배밖에 되지 않아, DRAM이나 플래시보다 읽기 마진이 작은 편입니다. 자화를 반전시키지 않는 비파괴 읽기이므로 읽은 후 다시 쓸 필요가 없습니다.
