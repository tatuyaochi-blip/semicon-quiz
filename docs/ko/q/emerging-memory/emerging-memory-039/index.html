차세대 메모리

상변화 메모리(PCM)에서 셀을 저저항의 결정 상태로 만들(셋할) 때의 가열 방법으로 올바른 것은 무엇입니까?

  1. A융점을 넘을 때까지 급속히 가열하고 즉시 급랭한다
  2. B결정화 온도 이상, 융점 미만의 온도를 비교적 오랜 시간 유지한다
  3. C전혀 가열하지 않는다
정답과 해설 보기

정답: B. 결정화 온도 이상, 융점 미만의 온도를 비교적 오랜 시간 유지한다

셋에서는 비정질 상태의 재료를 결정화 온도(GST는 약 150 ℃) 이상, 융점(약 600 ℃) 미만의 온도로 수십~수백 ns 정도 유지하여 원자가 배열되어 결정화되기를 기다립니다. 이 시간이 PCM의 쓰기 속도를 결정하는 요인이며, 리셋보다 느립니다. 결정화가 빠른 재료를 선택하거나 결정핵이 생기기 쉬운 조성으로 하여 고속화를 도모하고 있습니다.

차세대 메모리의 다른 문제

  1. 강유전체의 히스테리시스 곡선(분극-전계 특성)에서 전계를 0으로 되돌려도 남는 분극을 무엇이라고 합니까?
  2. MRAM을 사용할 때 주의가 필요한 외부 환경으로 올바른 것은 무엇입니까?
  3. MRAM이나 FeRAM이 우주 기기 등 방사선이 많은 환경에서 사용되는 경우가 있는 이유로 올바른 것은 무엇입니까?
  4. 과거 Intel과 Micron이 공동 개발하여 'Optane'이라는 제품명으로 판매된 스토리지 클래스 메모리 기술은 무엇입니까?
  5. 상변화 메모리(PCM)에서 하나의 셀에 여러 비트를 기억시키는(다치화하는) 방법으로 올바른 것은 무엇입니까?
