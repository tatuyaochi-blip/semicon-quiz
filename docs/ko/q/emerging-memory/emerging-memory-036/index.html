차세대 메모리

MTJ의 터널 자기저항비(TMR비)에 대한 설명으로 올바른 것은 무엇입니까?

  1. A자화가 평행일 때와 반평행일 때의 저항 차이를 평행일 때의 저항으로 나눈 비
  2. B절연층 두께와 자성층 두께의 비
  3. CMTJ에 흘릴 수 있는 최대 전류
정답과 해설 보기

정답: A. 자화가 평행일 때와 반평행일 때의 저항 차이를 평행일 때의 저항으로 나눈 비

TMR비는 (R반평행 − R평행)/R평행이며, 두 상태의 저항 차이의 크기를 나타냅니다. 예를 들어 R평행 = 2 kΩ, R반평행 = 5 kΩ이면 TMR비는 150%입니다. 클수록 0과 1을 구분해 읽기 쉽고 읽기를 빠르게 할 수 있습니다. MgO 장벽에서 상온 600%를 넘는 값도 보고되었지만, 양산 MRAM에서는 소자의 소형화와 내열성 사이의 균형 때문에 100~200% 정도입니다.

차세대 메모리의 다른 문제

  1. MTJ에서 두 자성층의 자화 방향이 평행일 때와 반평행일 때의 저항 관계로 올바른 것은 무엇입니까?
  2. MTJ를 구성하는 두 자성층의 역할로 올바른 것은 무엇입니까?
  3. 상변화 메모리(PCM)에서 셀을 저저항의 결정 상태로 만들(셋할) 때의 가열 방법으로 올바른 것은 무엇입니까?
  4. 강유전체의 히스테리시스 곡선(분극-전계 특성)에서 전계를 0으로 되돌려도 남는 분극을 무엇이라고 합니까?
  5. MRAM을 사용할 때 주의가 필요한 외부 환경으로 올바른 것은 무엇입니까?

이 분야의 비교

  • MRAM, ReRAM, PCM, FeRAM: 차세대 메모리 비교MRAM, ReRAM, PCM, FeRAM을 표로 비교합니다. 저장 원리, 쓰기 방식, 속도, 내구성, 집적도, 주요 과제, 대표 용도를 다룹니다.
