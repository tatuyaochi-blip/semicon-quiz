차세대 메모리

플래시 메모리와 비교했을 때 MRAM의 일반적인 장점으로 올바른 것은 무엇입니까?

  1. A비트당 비용이 훨씬 낮다
  2. B전원을 끄면 데이터가 사라진다
  3. C재기록 가능 횟수가 매우 많고 쓰기도 빠르다
정답과 해설 보기

정답: C. 재기록 가능 횟수가 매우 많고 쓰기도 빠르다

MRAM은 자화 방향으로 기억하므로 산화막 열화를 수반하는 플래시보다 재기록 횟수가 훨씬 많고(10¹⁰회 이상), 쓰기도 수~수십 ns로 빠르며, 소거 절차도 필요 없습니다. 그래서 마이컴이나 차량용 기기의 내장 메모리, 데이터를 자주 기록하는 용도에서 채택이 늘고 있습니다. 한편 셀이 크고 적층도 할 수 없어, 대용량화나 비트당 단가 면에서는 NAND 플래시에 크게 미치지 못합니다.

차세대 메모리의 다른 문제

  1. 최근 FeRAM이나 강유전체 트랜지스터(FeFET)의 재료로 주목받고 있는, CMOS 공정과 궁합이 좋은 강유전체 재료는 무엇입니까?
  2. 상변화 메모리(PCM)에서 셀을 고저항의 비정질 상태로 만드는(리셋하는) 방법으로 올바른 것은 무엇입니까?
  3. 저항 변화형 메모리 등을 사용한 인메모리 컴퓨팅에서 기대되는 주된 용도는 무엇입니까?
  4. 커패시터형 FeRAM의 읽기 특징으로 올바른 것은 무엇입니까?
  5. MRAM의 자기터널접합(MTJ)에서 터널 장벽층으로 널리 사용되며 큰 터널 자기저항비를 얻을 수 있는 재료는 무엇입니까?
