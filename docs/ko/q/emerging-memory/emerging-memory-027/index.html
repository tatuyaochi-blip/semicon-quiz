차세대 메모리

상변화 메모리를 미세화할 때 문제가 되는, 쓰기 시의 열이 인접 셀에 전달되어 상태를 바꿔 버리는 현상은 무엇입니까?

  1. A로 해머
  2. B정전기 방전
  3. C열 디스터브(열적 크로스토크)
정답과 해설 보기

정답: C. 열 디스터브(열적 크로스토크)

PCM의 쓰기에서는 재료를 수백 ℃(리셋에서는 600 ℃ 이상)로 가열합니다. 셀 간격이 수십 nm 이하로 좁아지면 그 열이 인접 셀에 전달되어, 비정질인 인접 셀이 의도치 않게 결정화될 우려가 있습니다. 이것이 열 디스터브입니다. 가열부를 전극의 가는 부분으로 한정하는 구조(머시룸형 등)나, 열이 잘 전달되지 않는 절연 재료로 둘러싸는 단열 구조로 대책을 세웁니다.

차세대 메모리의 다른 문제

  1. STT-MRAM의 쓰기가 확률적인 성질을 가짐으로써 생기는 설계상의 과제로 올바른 것은 무엇입니까?
  2. ReRAM 셀의 저항값 편차가 큰 것으로 인한 과제로 올바른 것은 무엇입니까?
  3. 일반적으로 재기록 가능 횟수가 가장 적은 메모리는 무엇입니까?
  4. 다음 메모리 중 전원을 꺼도 데이터가 남는 비휘발성 메모리는 무엇입니까?
  5. MRAM의 'M'이 나타내는 것으로 올바른 것은 무엇입니까?
