차세대 메모리

MRAM의 쓰기 에너지를 낮추는 방법으로 연구되고 있는, 전압으로 자성층의 자기 이방성을 바꾸는 효과는 무엇입니까?

  1. A제벡 효과
  2. BVCMA(전압 제어 자기 이방성)
  3. C압저항 효과
정답과 해설 보기

정답: B. VCMA(전압 제어 자기 이방성)

VCMA(Voltage-Controlled Magnetic Anisotropy)는 얇은 자성층과 절연층(MgO 등)의 계면에 전압을 인가하면 계면의 전자 상태가 변하여 자화의 향하기 쉬운 정도(자기 이방성)가 변하는 효과입니다. 전류를 거의 흘리지 않고 자화 반전을 도울 수 있으므로, 전류로 쓰는 STT 방식보다 쓰기 에너지를 1~2자릿수 낮출 수 있을 것으로 기대됩니다. 반전을 정확하게 멈추는 타이밍 제어가 과제입니다.
