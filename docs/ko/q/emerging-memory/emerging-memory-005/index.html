  2. B자외선을 조사하여 쓴다

정답과 해설 보기

정답: C. 스핀 편극 전류에 의한 스핀 전달 토크로 자화를 반전시킨다

STT-MRAM에서는 MTJ에 전류를 흘려, 기준층에서 스핀 방향이 정렬된 전자가 기록층에 각운동량을 전달하는 것(스핀 전달 토크)으로 자화를 반전시킵니다. 전류의 방향으로 0과 1을 구분하여 씁니다. 외부 자기장으로 쓰는 초기 MRAM은 소자를 작게 할수록 큰 전류가 필요했지만, STT에서는 쓰기 전류가 소자 면적에 비례하여 작아지므로 미세화에 적합하며 현재의 주류입니다.

차세대 메모리의 다른 문제

  1. '스토리지 클래스 메모리'의 위상으로 올바른 것은 무엇입니까?
  2. 플래시 메모리와 비교했을 때 MRAM의 일반적인 장점으로 올바른 것은 무엇입니까?
  3. 최근 FeRAM이나 강유전체 트랜지스터(FeFET)의 재료로 주목받고 있는, CMOS 공정과 궁합이 좋은 강유전체 재료는 무엇입니까?
  4. 상변화 메모리(PCM)에서 셀을 고저항의 비정질 상태로 만드는(리셋하는) 방법으로 올바른 것은 무엇입니까?
  5. 저항 변화형 메모리 등을 사용한 인메모리 컴퓨팅에서 기대되는 주된 용도는 무엇입니까?
