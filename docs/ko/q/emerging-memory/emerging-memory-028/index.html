차세대 메모리

STT-MRAM의 쓰기가 확률적인 성질을 가짐으로써 생기는 설계상의 과제로 올바른 것은 무엇입니까?

  1. A쓰기에 빛이 필요해진다
  2. B쓰기 전류나 펄스 폭에 여유를 두거나 오류 정정을 조합해야 한다
  3. C쓰기가 반드시 실패한다
정답과 해설 보기

정답: B. 쓰기 전류나 펄스 폭에 여유를 두거나 오류 정정을 조합해야 한다

STT-MRAM의 자화 반전은 열 요동의 영향을 받는 확률적 현상이어서, 같은 전류와 펄스 폭이라도 드물게 쓰기에 실패합니다(쓰기 오류율). 전류를 늘리면 실패는 줄지만 MgO 장벽이 절연 파괴에 가까워져 수명이 단축됩니다. 그래서 전류나 펄스 폭에 여유를 두거나, 쓰기 후 확인하여 필요하면 다시 쓰거나, ECC를 조합하는 등의 방법으로 신뢰성을 확보합니다.

  3. 다음 메모리 중 전원을 꺼도 데이터가 남는 비휘발성 메모리는 무엇입니까?
  4. MRAM의 'M'이 나타내는 것으로 올바른 것은 무엇입니까?
