클라우드와 컨테이너의 기초

할당 가능한 자원이 CPU 4코어, 메모리 8 GiB인 노드가 있다. 각 Pod의 컨테이너에는 requests로 CPU 500m·메모리 1.5 GiB, limits로 CPU 1코어·메모리 2 GiB를 설정했다. 다른 Pod나 시스템 예약은 없다고 하자. 이 노드에 둘 수 있는 Pod의 최대 수로 올바른 것은?

  1. A4개
  2. B5개
  3. C8개
정답과 해설 보기

정답: B. 5개

스케줄러는 노드에 둔 Pod들의 requests 합계가 CPU와 메모리 각각에서 할당 가능한 양을 넘지 않도록 배치합니다. CPU로는 4000m ÷ 500m = 8개까지 둘 수 있지만, 메모리로는 8 ÷ 1.5 = 5.33…이므로 5개까지입니다. 두 조건을 모두 만족해야 하므로 5개가 됩니다. limits는 배치 판단에 사용되지 않으므로 5개의 limits 합계(CPU 5코어·메모리 10 GiB)는 노드의 자원을 넘고 있어, 모든 Pod가 동시에 상한까지 사용하면 자원이 부족해집니다.

클라우드와 컨테이너의 기초의 다른 문제

  1. 클라우드의 관리형 데이터베이스 서비스(사업자가 데이터베이스 소프트웨어를 운용하는 서비스)를 사용한다. 공동 책임 모델의 관점에서 일반적으로 이용자의 책임으로 남는 것은?
  2. 클라우드에서 같은 리전 안의 여러 가용 영역에 웹 서버와 데이터베이스의 복제본을 나누어 두는 주된 목적으로 적절한 것은?
  3. 서버리스 함수(FaaS)에서, 한동안 호출되지 않았던 함수의 첫 호출만 응답이 수백 밀리초에서 수 초 늦어지는 경우가 있다. 이 현상의 설명으로 올바른 것은?
  4. 클라우드 스토리지를 ① 가상 머신에 디스크로 연결하여 파일 시스템을 만들고 데이터베이스의 데이터 파일을 둔다, ② 여러 서버에서 동시에 마운트하여 공유 디렉터리로 사용한다, ③ HTTP의 API로 키(이름)를 지정하여 대량의 이미지를 읽고 쓰며, 용량을 미리 정하지 않고 늘린다는 세 가지 용도로 사용한다. ①~③에 적합한 스토리지 종류의 조합으로 적절한 것은?
  5. 1시간당 40엔(가상의 단가)으로, 사용한 시간만큼만 요금이 드는 가상 머신을 사용한다. 평상시에는 2대를 1개월(30일) 동안 계속 가동하고, 평일 20일은 매일 6시간만 부하에 맞추어 4대를 추가한다. 1개월의 요금으로 올바른 것은?

이 분야의 비교

  • 가상 머신과 컨테이너의 차이: 가상화하는 계층·커널·시작 속도·격리 강도·용도 비교가상 머신과 컨테이너를 가상화하는 계층, OS 커널, 실행할 수 있는 OS, 이미지 크기, 시작 속도, 격리 강도, 자원 효율, 주요 용도의 관점에서 표로 비교합니다.
  • IaaS·PaaS·SaaS의 차이: 제공 범위·사용자가 관리하는 것·자유도·운영 부담 비교IaaS·PaaS·SaaS를 사업자가 제공하는 것, 사용자가 관리하는 것, 자유도, 운영 부담, 주요 사용자, 요금 방식, 공동 책임 모델에서의 분담, 대표적인 예의 관점에서 표로 비교합니다.
