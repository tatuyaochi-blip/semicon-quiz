클라우드와 컨테이너의 기초

클라우드 스토리지를 ① 가상 머신에 디스크로 연결하여 파일 시스템을 만들고 데이터베이스의 데이터 파일을 둔다, ② 여러 서버에서 동시에 마운트하여 공유 디렉터리로 사용한다, ③ HTTP의 API로 키(이름)를 지정하여 대량의 이미지를 읽고 쓰며, 용량을 미리 정하지 않고 늘린다는 세 가지 용도로 사용한다. ①~③에 적합한 스토리지 종류의 조합으로 적절한 것은?

  1. A① 오브젝트 스토리지, ② 블록 스토리지, ③ 파일 스토리지
  2. B① 파일 스토리지, ② 오브젝트 스토리지, ③ 블록 스토리지
  3. C① 블록 스토리지, ② 파일 스토리지, ③ 오브젝트 스토리지
정답과 해설 보기

정답: C. ① 블록 스토리지, ② 파일 스토리지, ③ 오브젝트 스토리지

블록 스토리지는 정해진 크기의 영역을 가상 디스크로 가상 머신에 연결하는 것으로, 파일 시스템을 만들어 사용하며 데이터베이스처럼 세세한 읽기와 쓰기를 빠르게 수행하는 용도에 적합합니다. 파일 스토리지는 NFS나 SMB 등으로 여러 서버에서 동시에 마운트할 수 있는 공유 파일 시스템을 제공합니다. 오브젝트 스토리지는 데이터를 키로 식별하는 오브젝트로서 HTTP의 API로 통째로 읽고 쓰는 것으로, 용량을 거의 신경 쓰지 않고 늘릴 수 있어 이미지나 백업, 로그의 저장에 적합합니다. 오브젝트의 일부만 수정하는 사용 방식에는 적합하지 않으므로 데이터베이스의 데이터 파일은 두지 않습니다.

클라우드와 컨테이너의 기초의 다른 문제

  1. 1시간당 40엔(가상의 단가)으로, 사용한 시간만큼만 요금이 드는 가상 머신을 사용한다. 평상시에는 2대를 1개월(30일) 동안 계속 가동하고, 평일 20일은 매일 6시간만 부하에 맞추어 4대를 추가한다. 1개월의 요금으로 올바른 것은?
  2. 어떤 가상 머신은 사용한 시간만큼 지불하는 온디맨드로는 1시간당 50엔, 1년분의 이용을 미리 약정하는 예약으로는 사용한 시간과 관계없이 1년에 262,800엔이 든다(둘 다 가상의 가격). 1년을 8,760시간이라고 하면, 1년간의 이용 시간이 어떤 시간을 넘었을 때 예약 쪽이 저렴해진다. 그 시간으로 올바른 것은?
  3. 많은 퍼블릭 클라우드의 데이터 전송 요금의 사고방식으로 일반적으로 들어맞는 것은?
  4. 선언적인 IaC(Infrastructure as Code) 도구로, 네트워크와 가상 머신 2대의 구성을 정의한 파일을 적용하여 환경을 만들었다. 그 직후에 아무것도 바꾸지 않고 같은 파일을 한 번 더 적용했을 때 일어나는 일로 적절한 것은?
  5. 이뮤터블 인프라스트럭처의 사고방식에 따른, 운영 서버의 소프트웨어 업데이트 방법으로 적절한 것은?
