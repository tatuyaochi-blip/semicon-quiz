클라우드와 컨테이너의 기초

이미지를 registry.example.com/team/web:1.4로 지정하여 가져온다(pull). 이 지정의 각 부분이 뜻하는 바의 조합으로 올바른 것은?

  1. Aregistry.example.com: 리포지토리, team/web: 태그, 1.4: 이미지의 내용으로부터 계산한 다이제스트
  2. Bregistry.example.com: 레지스트리(이미지를 보관하는 서버), team/web: 리포지토리, 1.4: 태그
  3. Cregistry.example.com: 레지스트리, team: 리포지토리, web: 태그, 1.4: 시작할 컨테이너의 이름
정답과 해설 보기

정답: B. registry.example.com: 레지스트리(이미지를 보관하는 서버), team/web: 리포지토리, 1.4: 태그

이미지의 지정은 '레지스트리/리포지토리:태그' 형식으로, 레지스트리는 이미지를 보관하고 배포하는 서버, 리포지토리는 같은 종류의 이미지를 모은 것, 태그는 버전 등을 나타내는 이름이며, 이 예에서는 registry.example.com이 레지스트리, team/web이 리포지토리, 1.4가 태그입니다. 레지스트리를 생략하면 기본 레지스트리(Docker Hub)가, 태그를 생략하면 latest가 사용됩니다. 태그는 이용자가 붙이는 이름이어서, 같은 태그를 나중에 다른 이미지에 옮겨 붙일 수도 있습니다. 내용이 바뀌면 반드시 바뀌는 식별자는 sha256으로 시작하는 다이제스트로, @ 뒤에 써서 지정합니다.

클라우드와 컨테이너의 기초의 다른 문제

  1. scratch는 파일을 하나도 포함하지 않는 빈 이미지이다. 위의 멀티 스테이지 빌드 Dockerfile로 만든 최종 이미지에 포함되는 것으로 올바른 것은?
  2. Kubernetes에서 배포하고 관리하는 최소 단위로, 하나 이상의 컨테이너를 묶어 같은 IP 주소와 볼륨을 공유하게 하는 것은?
  3. Kubernetes에서 replicas: 3을 지정한 Deployment의 Pod가 3개 동작하고 있다. 이 중 하나의 Pod를 kubectl delete pod로 삭제했을 때 일어나는 일로 올바른 것은?
  4. Kubernetes의 Deployment에서 Pod 템플릿의 컨테이너 이미지를 새 버전으로 변경했다. 기본 업데이트 방식(RollingUpdate)에서 일어나는 일로 올바른 것은?
  5. replicas: 10인 Deployment에서 롤링 업데이트 설정을 maxSurge: 25%, maxUnavailable: 25%로 했다. 업데이트 도중의 Pod 총수의 상한과 이용 가능한 Pod 수의 하한의 조합으로 올바른 것은?

이 분야의 비교

  • 가상 머신과 컨테이너의 차이: 가상화하는 계층·커널·시작 속도·격리 강도·용도 비교가상 머신과 컨테이너를 가상화하는 계층, OS 커널, 실행할 수 있는 OS, 이미지 크기, 시작 속도, 격리 강도, 자원 효율, 주요 용도의 관점에서 표로 비교합니다.
  • IaaS·PaaS·SaaS의 차이: 제공 범위·사용자가 관리하는 것·자유도·운영 부담 비교IaaS·PaaS·SaaS를 사업자가 제공하는 것, 사용자가 관리하는 것, 자유도, 운영 부담, 주요 사용자, 요금 방식, 공동 책임 모델에서의 분담, 대표적인 예의 관점에서 표로 비교합니다.
