바이폴라 트랜지스터

NPN 트랜지스터를 증폭에 사용할 때(능동 영역에서 동작시킬 때)의 바이어스 조건으로 올바른 것은?

  1. A베이스-에미터 간은 순방향, 베이스-컬렉터 간은 역방향
  2. B베이스-에미터 간은 역방향, 베이스-컬렉터 간은 순방향
  3. C베이스-에미터 간, 베이스-컬렉터 간 모두 순방향
정답과 해설 보기

정답: A. 베이스-에미터 간은 순방향, 베이스-컬렉터 간은 역방향

능동 영역에서는 베이스-에미터 접합을 순방향으로 하여 에미터에서 베이스로 전자를 주입하고, 베이스-컬렉터 접합을 역방향으로 하여 베이스를 통과한 전자를 강한 전계로 컬렉터로 끌어당깁니다. 컬렉터 전류는 컬렉터 전압에 거의 좌우되지 않고 베이스 전류(또는 VBE)로 결정되므로 증폭이 가능합니다. 둘 다 순방향이면 포화 영역(스위치 온), 둘 다 역방향이면 차단 영역(오프)입니다.

바이폴라 트랜지스터의 다른 문제

  1. 바이폴라 트랜지스터의 직류 전류 증폭률 hFE를 나타내는 식은? (IC: 컬렉터 전류, IB: 베이스 전류, IE: 에미터 전류)
  2. 바이폴라 트랜지스터의 베이스 폭을 얇게 하는 주된 이유로 가장 적절한 것은?
  3. 바이폴라 트랜지스터를 스위치로 사용할 때 온 상태에 해당하는 동작 영역은?
  4. 에미터 접지 증폭 회로의 출력 전압 위상은 입력 전압에 대해 어떻게 되는가?
  5. NPN 트랜지스터에서 에미터의 불순물 농도를 베이스보다 높게 하는 주된 이유는?
