바이폴라 트랜지스터

증폭 회로에서 입력 신호가 없을 때 트랜지스터의 직류 전압·전류 상태를 무엇이라 부르는가?

  1. A동작점(바이어스점)
  2. B차단점
  3. C핀치오프점
정답과 해설 보기

정답: A. 동작점(바이어스점)

동작점은 신호가 없을 때 바이어스 회로로 정해지는 직류 전압과 전류의 상태입니다. 신호는 이 점을 중심으로 위아래로 흔들리므로, 왜곡 없이 큰 진폭을 다루려면 부하선의 중앙 부근(예: VCE를 전원 전압의 약 절반)에 두는 것이 기본입니다. 치우치면 한쪽 진폭에서 포화나 차단에 이르러 파형이 클리핑됩니다. 동작점은 gm이나 입력 저항 등의 소신호 파라미터도 결정하므로 가장 먼저 정하는 설계값입니다.

바이폴라 트랜지스터의 다른 문제

  1. NPN과 PNP 트랜지스터로 양과 음의 반주기를 분담하는 B급 푸시풀 증폭 회로에서 발생하기 쉬운 왜곡은?
  2. 증폭 회로의 단과 단 사이에 넣는 결합 커패시터의 역할로 올바른 것은?
  3. 실리콘 바이폴라 트랜지스터의 전류 증폭률 hFE는 일반적으로 온도가 오르면 어떻게 되는가?
  4. 에미터 접지 증폭 회로의 소신호 입력 저항(hie)을 크게 하는 조건으로 올바른 것은?
  5. 증폭 회로의 부하 저항 대신 전류원으로 동작하는 트랜지스터를 사용하는 능동 부하의 이점으로 올바른 것은?
