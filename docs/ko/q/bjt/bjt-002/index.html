바이폴라 트랜지스터

바이폴라 트랜지스터의 직류 전류 증폭률 hFE를 나타내는 식은? (IC: 컬렉터 전류, IB: 베이스 전류, IE: 에미터 전류)

  1. AIB / IC
  2. BIC / IB
  3. CIE / IC
정답과 해설 보기

정답: B. IC / IB

hFE는 에미터 접지에서의 직류 전류 증폭률이며 hFE = IC/IB입니다. 소신호용 트랜지스터에서는 수십~수백, 파워 트랜지스터에서는 수십 정도가 일반적입니다. 같은 형번이라도 개체 편차가 크고(예: 100~400처럼 등급으로 분류됨) 온도나 전류에 따라서도 변하므로, 회로는 hFE 값에 의존하지 않고 동작하도록 설계하는 것이 기본입니다. 베이스 접지의 전류 증폭률 α는 IC/IE이며 1보다 약간 작은 값입니다.
