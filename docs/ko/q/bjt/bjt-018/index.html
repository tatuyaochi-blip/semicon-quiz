바이폴라 트랜지스터

두 트랜지스터의 에미터를 공통의 전류원에 연결한 차동쌍의 동작으로 올바른 것은?

  1. A두 입력 전압의 합을 증폭한다
  2. B두 입력 전압의 차를 증폭한다
  3. C입력 전압을 정류한다
정답과 해설 보기

정답: B. 두 입력 전압의 차를 증폭한다

차동쌍에서는 두 입력 전압의 차에 따라 공통 전류원의 전류가 두 트랜지스터로 분배됩니다. 두 입력이 똑같이 변해도(동상) 분배는 변하지 않으므로 차이만 증폭되고, 전원 노이즈나 온도 변화처럼 양쪽에 똑같이 실리는 성분은 상쇄됩니다. 차동 이득과 동상 이득의 비를 CMRR(동상 제거비)이라고 합니다. 연산 증폭기의 입력단이나 고속 차동 전송(LVDS 등)의 수신 회로에 사용됩니다.

바이폴라 트랜지스터의 다른 문제

  1. 컬렉터 전류 1 mA로 동작하는 바이폴라 트랜지스터의 상호 컨덕턴스 gm은 대략 얼마인가? (상온, 열전압 VT ≈ 26 mV로 한다)
  2. LED와 포토트랜지스터를 하나의 패키지에 조합한 포토커플러의 주된 용도는?
  3. 트랜지스터 증폭 회로에서 에미터 저항을 넣은 전류 피드백 바이어스 회로를 사용하는 주된 이유는?
  4. 증폭 회로에서 입력 신호가 없을 때 트랜지스터의 직류 전압·전류 상태를 무엇이라 부르는가?
  5. NPN과 PNP 트랜지스터로 양과 음의 반주기를 분담하는 B급 푸시풀 증폭 회로에서 발생하기 쉬운 왜곡은?

이 분야의 비교

  • BJT와 MOSFET의 차이점 정리BJT와 MOSFET을 표로 비교합니다. 제어 방식, 입력 전류, 캐리어, 속도, 온 상태 특성, 온도 특성, 집적도, 대표 용도를 다룹니다.
  • NPN 트랜지스터와 PNP 트랜지스터의 차이: 구조·전류 방향·회로 기호·사용법 비교바이폴라 트랜지스터의 NPN형과 PNP형을 반도체 배열, 주 캐리어, 바이어스 방법, 전류 방향, 회로 기호의 화살표, 스위치로서의 연결 방법, 성능 관점에서 표로 비교합니다.
