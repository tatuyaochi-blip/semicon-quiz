바이폴라 트랜지스터

바이폴라 트랜지스터의 에미터 전류 IE, 베이스 전류 IB, 컬렉터 전류 IC의 관계로 올바른 것은?

  1. AIE = IC − IB
  2. BIE = IB × IC
  3. CIE = IB + IC
정답과 해설 보기

정답: C. IE = IB + IC

트랜지스터로 흘러 들어가는 전류와 흘러 나오는 전류는 같으므로(키르히호프의 전류 법칙) IE = IB + IC입니다. NPN에서는 베이스와 컬렉터로 흘러 들어간 전류가 에미터에서 한꺼번에 흘러 나옵니다. IB는 IC의 1/100 정도이므로 IE ≈ IC로 간주할 수 있는 경우가 많으며, 예를 들어 에미터 저항의 전압으로 컬렉터 전류를 추정할 수 있습니다. α와 β의 관계 β = α/(1 − α)도 이 식에서 유도됩니다.

  • A. 베이스 전류와 컬렉터 전류는 모두 에미터로 흘러 들어가므로(NPN의 경우) 차가 아니라 합이 됩니다.
  • B. 전류의 관계는 합이며 곱이 아닙니다.
  • C. 올바릅니다. 키르히호프의 전류 법칙에 의해 IE = IB + IC입니다.
