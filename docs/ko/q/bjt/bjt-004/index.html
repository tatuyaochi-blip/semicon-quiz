바이폴라 트랜지스터

바이폴라 트랜지스터를 스위치로 사용할 때 온 상태에 해당하는 동작 영역은?

  1. A차단 영역
  2. B능동 영역
  3. C포화 영역
정답과 해설 보기

정답: C. 포화 영역

스위치로 사용할 경우 오프는 두 접합이 모두 역바이어스인 차단 영역, 온은 두 접합이 모두 순바이어스인 포화 영역입니다. 포화 영역에서는 VCE(sat)가 약 0.1~0.3 V로 작아 스위치가 닫힌 상태에 가깝습니다. 확실하게 포화시키기 위해 베이스 전류는 「IC ÷ hFE」의 2~10배 정도 흘리는 것이 일반적입니다(오버드라이브). 다만 깊이 포화시킬수록 축적 전하가 늘어 오프로 돌아가는 것이 느려집니다.

바이폴라 트랜지스터의 다른 문제

  1. 에미터 접지 증폭 회로의 출력 전압 위상은 입력 전압에 대해 어떻게 되는가?
  2. NPN 트랜지스터에서 에미터의 불순물 농도를 베이스보다 높게 하는 주된 이유는?
  3. 베이스 접지 전류 증폭률 α = 0.99인 바이폴라 트랜지스터의 에미터 접지 전류 증폭률 β는 대략 얼마인가?
  4. 바이폴라 트랜지스터의 얼리 효과에 대한 설명으로 올바른 것은?
  5. 두 개의 트랜지스터를 조합한 달링턴 접속의 특징으로 올바른 것은?

이 분야의 비교

  • BJT와 MOSFET의 차이점 정리BJT와 MOSFET을 표로 비교합니다. 제어 방식, 입력 전류, 캐리어, 속도, 온 상태 특성, 온도 특성, 집적도, 대표 용도를 다룹니다.
