바이폴라 트랜지스터

NPN과 PNP 트랜지스터로 양과 음의 반주기를 분담하는 B급 푸시풀 증폭 회로에서 발생하기 쉬운 왜곡은?

  1. A양자화 오차
  2. B에일리어싱
  3. C크로스오버 왜곡
정답과 해설 보기

정답: C. 크로스오버 왜곡

B급 푸시풀에서는 입력이 0 부근일 때 어느 트랜지스터도 VBE가 약 0.6 V에 이르지 못해 도통하지 않는 구간이 생기고, 파형이 전환되는 부분이 왜곡됩니다. 이것이 크로스오버 왜곡이며 작은 음량일수록 두드러집니다. 다이오드나 VBE 멀티플라이어로 약 1.2 V의 바이어스를 걸어 약간의 전류를 흘리는 AB급으로 하면 줄일 수 있습니다. 오디오 앰프 출력단의 대부분이 AB급입니다.

바이폴라 트랜지스터의 다른 문제

  2. 실리콘 바이폴라 트랜지스터의 전류 증폭률 hFE는 일반적으로 온도가 오르면 어떻게 되는가?
  3. 에미터 접지 증폭 회로의 소신호 입력 저항(hie)을 크게 하는 조건으로 올바른 것은?
  4. 증폭 회로의 부하 저항 대신 전류원으로 동작하는 트랜지스터를 사용하는 능동 부하의 이점으로 올바른 것은?
  5. 스위치용 트랜지스터를 깊은 포화 상태에서 오프로 할 때, 오프가 되기까지 시간이 걸리는 주된 이유는?
