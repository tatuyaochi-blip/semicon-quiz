임베디드 시스템과 펌웨어

마이크로컨트롤러의 브라운아웃 검출(BOD, 브라운아웃 리셋)의 역할로 올바른 것은 무엇입니까?

  1. A전원 전압이 동작에 필요한 값보다 떨어졌을 때 마이크로컨트롤러를 리셋하여 불확실한 동작을 막는다
  2. B방이 어두워졌을 때 LED를 점등시킨다
  3. C전원 전압을 자동으로 높인다
정답과 해설 보기

정답: A. 전원 전압이 동작에 필요한 값보다 떨어졌을 때 마이크로컨트롤러를 리셋하여 불확실한 동작을 막는다

배터리가 줄거나 전원이 불안정해져 전압이 떨어지면 마이크로컨트롤러의 회로는 올바르게 동작한다는 보장이 없어져, 명령을 잘못 실행하거나 플래시에 엉뚱한 값을 쓸 우려가 있습니다. 브라운아웃 검출은 전압이 정해진 값을 밑돌면 마이크로컨트롤러를 리셋 상태로 유지하고, 전압이 충분히 회복된 뒤에 동작을 시작하게 합니다. 데이터를 지키기 위해 중요한 기능입니다.

임베디드 시스템과 펌웨어의 다른 문제

  1. 인터럽트에 우선순위를 줄 수 있는 마이크로컨트롤러에서, 우선순위가 낮은 인터럽트의 핸들러를 실행 중에 우선순위가 높은 인터럽트가 발생했습니다. 일반적으로 어떻게 됩니까? (인터럽트 중첩을 허용하는 설정으로 가정)
  2. C 언어에서 레지스터 reg의 비트 3만 1로 만들고 나머지 비트는 바꾸지 않는 올바른 표기는 무엇입니까?
  3. C 언어에서 레지스터 reg의 비트 3만 0으로 만들고 나머지 비트는 바꾸지 않는 올바른 표기는 무엇입니까?
  4. LED를 연결한 출력 핀의 비트를 실행할 때마다 점등과 소등으로 번갈아 바꾸고 싶습니다. 올바른 C 언어 표기는 무엇입니까?
  5. 입력용 레지스터 in의 비트 5가 1인지 검사하는 올바른 C 언어 조건은 무엇입니까?

이 분야의 비교

  • I2C, SPI, UART의 차이와 선택 기준I2C, SPI, UART를 표로 비교합니다. 배선 수, 클록, 속도, 토폴로지, 주소 지정, 오류 검사, 마이크로컨트롤러 프로젝트에서의 대표 용도를 다룹니다.
  • MCU vs MPU: 마이크로컨트롤러와 마이크로프로세서 비교MCU와 MPU를 표로 비교합니다: 집적도, 클록 속도, 메모리, 운영체제, 실시간성, 전력, 부팅 시간, 비용, 대표 용도.
  • 인터럽트 vs 폴링: 차이점과 사용 시기인터럽트와 폴링을 표로 비교합니다: 동작 방식, CPU 사용, 지연 시간, 오버헤드, 복잡도, 전력, 임베디드 및 운영체제에서의 주요 용도.
