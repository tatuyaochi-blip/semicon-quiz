무선 통신의 기초

직접 확산 방식(DSSS) 대역 확산(스펙트럼 확산)에 대한 설명으로 적절한 것은?

  1. A송신하는 데이터의 속도를 낮추어, 사용하는 주파수의 대역폭을 가능한 한 좁게 하는 방식
  2. B데이터에 그보다 빠르게 변화하는 확산 부호를 곱해 넓은 대역으로 퍼뜨려 보내고, 수신 측에서 같은 부호를 곱하여 원래대로 되돌리는 방식
  3. C송신하는 주파수를 정해진 순서로 짧은 시간마다 전환하면서 보내는 방식
정답과 해설 보기

정답: B. 데이터에 그보다 빠르게 변화하는 확산 부호를 곱해 넓은 대역으로 퍼뜨려 보내고, 수신 측에서 같은 부호를 곱하여 원래대로 되돌리는 방식

직접 확산 방식에서는 데이터 비트보다 빠르게 변화하는 확산 부호(그 하나하나를 칩이라고 부릅니다)를 데이터에 곱하여 신호를 넓은 대역으로 퍼뜨려 보냅니다. 수신 측에서 같은 부호를 곱하면 목적 신호는 원래의 좁은 대역으로 돌아오는 한편, 도중에 섞여 들어온 좁은 대역의 간섭은 반대로 넓은 대역으로 퍼지므로 그 영향을 작게 할 수 있습니다. 얼마나 넓혔는지의 비를 처리 이득(확산 이득)이라고 부릅니다. 다른 부호를 사용하면 같은 주파수를 여러 이용자가 공용할 수 있으며, 이것이 CDMA의 기본입니다.

무선 통신의 기초의 다른 문제

  1. 여러 이용자가 같은 주파수를 같은 시간에 사용하고, 이용자마다 다른 부호로 신호를 구별하는 다중 접속 방식은?
  2. OFDMA(Orthogonal Frequency-Division Multiple Access)에 대한 설명으로 적절한 것은?
  3. 송신 안테나 4개, 수신 안테나 2개인 MIMO에서 공간 다중화에 의해 같은 주파수·같은 시간에 보낼 수 있는 독립된 데이터 흐름(스트림) 수의 상한은?
  4. 여러 안테나 소자에서 보내는 신호의 위상(과 진폭)을 소자마다 조정하여, 특정 방향으로 전파를 보강시켜 보내는 기술은?
  5. 5G 밀리미터파 대역의 기지국이나 단말에서 다수의 안테나 소자를 늘어놓은 어레이 안테나에 의한 빔포밍이 사용되는 주된 이유로 가장 적절한 것은?
