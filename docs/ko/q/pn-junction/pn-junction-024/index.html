PN 접합과 다이오드

정전압 다이오드를 사용한 간단한 정전압 회로에서 다이오드와 직렬로 넣는 저항의 역할로 올바른 것은 무엇입니까?

  1. A다이오드에 흐르는 전류를 제한하고, 입력 전압과 출력 전압의 차이를 담당한다
  2. B신호를 증폭한다
  3. C교류를 직류로 변환한다
정답과 해설 보기

정답: A. 다이오드에 흐르는 전류를 제한하고, 입력 전압과 출력 전압의 차이를 담당한다

정전압 다이오드는 항복 영역에서 전압이 거의 일정해지지만, 전류를 제한하지 않으면 과대한 전류와 발열로 파괴됩니다. 직렬 저항이 전류를 제한하고 입력 전압의 변동분을 전압 강하로 담당함으로써 출력이 거의 일정하게 유지됩니다. 저항값은 '(입력 전압의 최솟값 − 제너 전압) ÷ (부하 전류 + 필요한 최소 제너 전류)'로 정합니다. 효율이 나쁘므로 소전류 기준 전압용 회로입니다.

PN 접합과 다이오드의 다른 문제

  1. 양쪽을 매우 고농도로 한 PN 접합에서, 순방향 전압을 올리면 전류가 줄어드는 부성 저항 영역이 나타나는 다이오드는 무엇입니까?
  2. 결정 실리콘 태양전지 셀 1장의 개방 전압의 기준으로 올바른 것은 무엇입니까?
  3. 단접합 태양전지의 이론적인 변환 효율 상한(쇼클리-콰이서 한계)에 가장 가까운 값은 무엇입니까?
  4. 애벌란시 항복의 항복 전압은 온도가 올라가면 일반적으로 어떻게 됩니까?
  5. PIN 다이오드에 순방향 전류를 흘렸을 때, i층에 대량의 캐리어가 주입되어 저항이 크게 낮아지는 현상을 무엇이라고 합니까?
