암호 기술의 기초와 응용

HSM(하드웨어 보안 모듈)의 역할로 올바른 것은?

  1. A암호화한 데이터를 대량으로 저장하기 위한, 암호화 기능을 내장한 고속 스토리지 장치
  2. B변조 방지성이 있는 장치 안에서 키를 생성·보관하고, 키를 밖으로 내보내지 않고 서명이나 복호화 등의 처리를 수행하는 장치
  3. C네트워크 통신을 감시하여 부정한 패킷이나 공격 통신을 찾아내 차단하는 네트워크 기기
정답과 해설 보기

정답: B. 변조 방지성이 있는 장치 안에서 키를 생성·보관하고, 키를 밖으로 내보내지 않고 서명이나 복호화 등의 처리를 수행하는 장치

HSM은 인증 기관의 서명 키, 결제 키, 클라우드 키 관리 서비스(KMS)의 최상위 키 등을 지키기 위한 전용 장치입니다. 키는 HSM 안에서 생성되며 평문 그대로 밖으로 내보낼 수 없도록 만들어져 있고, 애플리케이션은 '이 키로 서명해 달라'와 같이 의뢰하여 결과만 받습니다. 장치를 열려고 하면 키를 소거하는 등의 변조 방지성을 가지며, 많은 제품은 FIPS 140-3 등의 기준에 의한 인증을 받고 있습니다. 스마트폰의 시큐어 엘리먼트나 PC의 TPM도 규모는 작지만 비슷한 사고방식으로 키를 지킵니다.
