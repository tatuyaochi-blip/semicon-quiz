암호 기술의 기초와 응용

어떤 장치에서 56비트 키를 모두 시도하는 무차별 대입에 약 20시간이 걸린다. 같은 장치에서 64비트 키를 모두 시도하는 데 걸리는 시간에 가장 가까운 것은?

  1. A약 23시간
  2. B약 160시간
  3. C약 213일
정답과 해설 보기

정답: C. 약 213일

키 길이가 n비트인 키의 후보는 2ⁿ개이므로, 키 길이가 8비트 늘면 후보는 2⁸ = 256배가 됩니다. 따라서 20시간 × 256 = 5,120시간 = 약 213일입니다. 키 길이를 1비트 늘릴 때마다 무차별 대입의 수고는 2배가 되며, AES-128 키의 후보는 56비트 키의 2⁷²배(약 4.7 × 10²¹배)입니다.

암호 기술의 기초와 응용의 다른 문제

  1. 해시 함수 SHA-2와 SHA-3에 대한 설명으로 올바른 것은?
  2. 비밀 키 K와 메시지 m을 이은 값의 해시값 SHA-256(K ‖ m)을 변조 검출용 태그로 사용하는 것은 위험하다고 여겨진다. 그 이유로 올바른 것은?
  3. 1 GiB = 2³⁰바이트, 1 EiB = 2⁶⁰바이트로 한다. 블록 길이가 64비트인 블록 암호(3DES 등)를 CBC 모드로 사용하여, 하나의 키로 대량의 데이터를 암호화한다. 암호문 블록을 무작위 64비트 값으로 간주할 때, 생일 역설에 의해 같은 암호문 블록 쌍이 나타날 확률을 무시할 수 없게 되는 데이터양의 기준은?
  4. TLS 1.3 등의 프로토콜에서 ECDHE 키 교환으로 얻은 공유 비밀을 그대로 암호 키로 사용하지 않고, HKDF 같은 키 유도 함수(KDF)를 거쳐 키를 만드는 이유로 적절한 것은?
  5. RSA 암호의 구조를 작은 수로 확인한다. 소수 p = 5, q = 11로부터 n = pq를 만들고, 공개 지수를 e = 3으로 한다. φ(n) = (p − 1)(q − 1)이라 할 때, e × d ≡ 1 (mod φ(n))을 만족하는 비밀 지수 d(0 < d < φ(n))는?
