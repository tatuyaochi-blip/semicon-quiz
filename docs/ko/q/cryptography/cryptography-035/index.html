암호 기술의 기초와 응용

양자 내성 암호로 이행하는 도중에 사용되는, X25519(타원 곡선을 사용하는 디피-헬먼 키 교환)와 ML-KEM을 조합한 하이브리드 키 교환의 사고방식으로 올바른 것은?

  1. A두 방식으로 얻은 공유 비밀을 둘 다 키 유도에 넣어, 어느 한쪽이 안전한 한 만들어지는 키가 안전하도록 한다
  2. B두 방식 중 핸드셰이크에서 먼저 끝난 쪽의 공유 비밀만 사용하고, 다른 쪽은 버린다
  3. CML-KEM은 양자 컴퓨터가 실현될 때까지는 사용하지 않고, 실현되었을 때 자동으로 전환되도록 둘 다 준비해 둔다
정답과 해설 보기

정답: A. 두 방식으로 얻은 공유 비밀을 둘 다 키 유도에 넣어, 어느 한쪽이 안전한 한 만들어지는 키가 안전하도록 한다

ML-KEM은 새로운 방식이어서 구현 실수나 새로운 공격이 발견될 우려를 아직 충분히 부정할 수 없습니다. 한편 X25519는 양자 컴퓨터에는 약하지만, 고전 컴퓨터에 대한 안전성에는 오랜 실적이 있습니다. 하이브리드 키 교환에서는 양쪽 공유 비밀을 이어서 키 유도 함수에 넣으므로, 공격자는 양쪽을 모두 깨지 않으면 키를 얻을 수 없으며, 지금 기록된 통신이 미래의 양자 컴퓨터로 해독되는 것도 막을 수 있습니다. 2025년 시점에서 이 조합(X25519MLKEM768 등)이 TLS 1.3에서 사용되기 시작하고 있습니다.

암호 기술의 기초와 응용의 다른 문제

  2. HSM(하드웨어 보안 모듈)의 역할로 올바른 것은?
  3. DEK를 데이터 암호화 키, KEK를 키 암호화 키라 한다. 클라우드 스토리지 등에서 사용되는 봉투 암호화에 대한 설명으로 올바른 것은?
