암호 기술의 기초와 응용

TLS 1.3의 암호 스위트 TLS_AES_128_GCM_SHA256이 지정하는 것의 조합으로 올바른 것은?

  1. A데이터 암호화에 사용하는 AEAD(AES-128-GCM)와, 키 유도(HKDF) 등에 사용하는 해시 함수(SHA-256)
  2. B키 교환 방식(AES-128)과, 서버 인증서의 서명 방식(SHA-256)
  3. C데이터 암호화에 사용하는 AES-128-GCM과, 각 레코드에 붙이는 변조 검출용 HMAC-SHA256
정답과 해설 보기

정답: A. 데이터 암호화에 사용하는 AEAD(AES-128-GCM)와, 키 유도(HKDF) 등에 사용하는 해시 함수(SHA-256)

TLS 1.2의 암호 스위트, 예를 들어 TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256은 키 교환(ECDHE), 인증(RSA), 암호(AES-128-GCM), 해시 함수를 한꺼번에 지정하고 있었습니다. TLS 1.3에서는 키 교환 그룹(X25519 등)과 서명 방식은 별도의 확장으로 협상하게 되었고, 암호 스위트는 AEAD와 HKDF 해시 함수의 조합만을 나타냅니다. AEAD가 데이터 변조 검출도 수행하므로 레코드마다 HMAC을 붙이는 일은 없으며, SHA-256은 핸드셰이크 내용의 해시와 키 유도에 사용됩니다.
