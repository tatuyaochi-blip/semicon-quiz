암호 기술의 기초와 응용

해시 함수 SHA-2와 SHA-3에 대한 설명으로 올바른 것은?

  1. ASHA-3은 SHA-2와 같은 내부 구조 그대로 출력을 길게 한 개량판이다
  2. BSHA-3은 SHA-2와는 다른 스펀지 구조에 기반한 방식이며, SHA-2도 현재 널리 사용되고 있다
  3. CSHA-256은 SHA-3의 일종으로, SHA-3 계열 중 출력이 256비트인 것을 SHA-256이라고 부른다
정답과 해설 보기

정답: B. SHA-3은 SHA-2와는 다른 스펀지 구조에 기반한 방식이며, SHA-2도 현재 널리 사용되고 있다

SHA-2는 SHA-224, SHA-256, SHA-384, SHA-512 등으로 이루어진 해시 함수의 한 계열로, 블록을 차례로 압축 함수에 통과시키는 Merkle–Damgård 구조로 되어 있습니다. SHA-3은 NIST의 공모에서 선정된 Keccak을 바탕으로 2015년에 FIPS 202로 표준화된 것으로, 큰 내부 상태에 입력을 흡수하고 출력을 짜내는 스펀지 구조를 사용합니다. SHA-3은 SHA-2가 깨졌기 때문에 만들어진 것이 아니라 구조가 다른 대안을 마련해 둔다는 의미를 가지며, SHA-2는 현재도 널리 사용되고 있습니다. 한편 SHA-1은 2017년에 실제 충돌 사례가 공표되어, 디지털 서명 등에는 사용되지 않게 되었습니다.

암호 기술의 기초와 응용의 다른 문제

  1. 비밀 키 K와 메시지 m을 이은 값의 해시값 SHA-256(K ‖ m)을 변조 검출용 태그로 사용하는 것은 위험하다고 여겨진다. 그 이유로 올바른 것은?
  2. 1 GiB = 2³⁰바이트, 1 EiB = 2⁶⁰바이트로 한다. 블록 길이가 64비트인 블록 암호(3DES 등)를 CBC 모드로 사용하여, 하나의 키로 대량의 데이터를 암호화한다. 암호문 블록을 무작위 64비트 값으로 간주할 때, 생일 역설에 의해 같은 암호문 블록 쌍이 나타날 확률을 무시할 수 없게 되는 데이터양의 기준은?
  3. TLS 1.3 등의 프로토콜에서 ECDHE 키 교환으로 얻은 공유 비밀을 그대로 암호 키로 사용하지 않고, HKDF 같은 키 유도 함수(KDF)를 거쳐 키를 만드는 이유로 적절한 것은?
  4. RSA 암호의 구조를 작은 수로 확인한다. 소수 p = 5, q = 11로부터 n = pq를 만들고, 공개 지수를 e = 3으로 한다. φ(n) = (p − 1)(q − 1)이라 할 때, e × d ≡ 1 (mod φ(n))을 만족하는 비밀 지수 d(0 < d < φ(n))는?
  5. RSA 암호에서 공개 키를 n = 55, e = 3으로 한다. 평문 m = 7을 c = m^e mod n으로 암호화했을 때의 암호문 c는?
