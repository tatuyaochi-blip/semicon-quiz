  1. A두 개의 프로그래밍 언어를 하나의 새로운 언어로 섞는 컴파일러
  2. B실행되는 컴퓨터와는 다른 CPU용 기계어를 생성하는 컴파일러
  3. C여러 컴파일러의 출력을 비교해 가장 빠른 것을 고르는 도구
정답과 해설 보기

정답: B. 실행되는 컴퓨터와는 다른 CPU용 기계어를 생성하는 컴파일러

크로스 컴파일러는 예를 들어 x86 PC 위에서 동작하면서 Arm이나 RISC-V 마이크로컨트롤러용 기계어를 생성하는 컴파일러입니다. 임베디드 기기처럼 대상 기기에서 컴파일러를 돌리기에는 성능이나 메모리가 부족한 경우에 꼭 필요합니다. 생성한 기계어는 대상 기기에 써 넣거나 그 기기를 모사하는 에뮬레이터에서 실행해 확인합니다. 언어를 섞거나 여러 컴파일러의 결과를 비교하는 도구가 아닙니다.

  • A. 언어를 섞는 컴파일러가 아닙니다.
  • B. 올바릅니다. 다른 종류의 CPU용 기계어를 생성합니다.
  • C. 결과를 비교하는 도구가 아닙니다.
