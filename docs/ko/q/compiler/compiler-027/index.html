컴파일러

컴파일러의 최적화 수준을 지정하는 옵션에서 최적화를 하지 않는 설정(-O0 등)이 자주 사용되는 상황은?

  1. A제품으로 배포할, 가능한 한 빠른 프로그램을 만들 때
  2. B디버거로 한 줄씩 동작을 확인하면서 오류를 찾을 때
  3. C프로그램의 크기를 가장 작게 하고 싶을 때
정답과 해설 보기

정답: B. 디버거로 한 줄씩 동작을 확인하면서 오류를 찾을 때

최적화를 하지 않는 설정에서는 소스 코드의 각 줄이 거의 그대로의 순서로 기계어에 대응하고 변수도 항상 메모리나 레지스터에 남으므로, 디버거로 한 줄씩 실행하거나 변수의 값을 확인하기 쉬워집니다. 최적화를 적용하면 명령의 재배열이나 변수의 삭제로 인해 소스와의 대응을 알기 어려워집니다. 제품으로 빠른 프로그램을 만들 때는 높은 최적화 수준을, 크기를 줄이고 싶을 때는 크기 우선 설정을 사용합니다.

  • A. 빠른 프로그램에는 높은 최적화 수준을 사용합니다.
  • B. 올바릅니다. 소스와의 대응을 알기 쉬워 디버깅에 적합합니다.
  • C. 크기를 줄이려면 크기 우선 설정을 사용합니다.
