컴파일러

많은 프로그래밍 언어의 문법을 나타내는 데 사용되며 구문 분석의 기초가 되는 문법의 종류는?

  1. A정규 문법뿐
  2. B자연어의 문법
  3. C문맥 자유 문법
정답과 해설 보기

정답: C. 문맥 자유 문법

괄호의 중첩이나 if문 안에 또 if문이 있는 구조는 정규 표현식으로는 나타낼 수 없습니다. 프로그래밍 언어의 문법 대부분은 「식 → 식 + 항」과 같은 재작성 규칙의 모음인 문맥 자유 문법으로 표현되며, 구문 분석은 이 문법에 기반하여 이루어집니다. 위에서부터 규칙을 적용해 가는 LL 방식이나 아래에서부터 구성해 가는 LR 방식 등의 분석 방법이 있으며, 문법으로부터 분석기를 자동으로 만드는 도구도 있습니다. 정규 문법은 어휘 분석용이며 중첩 구조는 다룰 수 없습니다.

  • A. 정규 문법으로는 괄호의 중첩 같은 구조를 나타낼 수 없습니다.
  • B. 프로그래밍 언어는 자연어의 문법으로 정의하지 않습니다.
  • C. 올바릅니다. 구문 분석은 문맥 자유 문법에 기반합니다.

컴파일러의 다른 문제

  1. 식 2 + 3 * 4의 추상 구문 트리의 형태로 올바른 것은?
  2. 중간 표현의 하나인 3-주소 코드의 특징으로 올바른 것은?
  3. 레지스터 할당의 준비로 수행하는 생존 구간(라이브니스) 분석에서 구하는 것은?
  4. 어떤 함수 안에서 동시에 살아 있는 값의 수가 가장 많은 곳에서 5개였다. 간섭 그래프가 이 5개 이외의 제약을 만들지 않는 단순한 경우, 모든 값을 스필 없이 레지스터에 두려면 레지스터가 최소 몇 개 필요한가?
  5. 반복 횟수가 100회인 루프를 본체를 4번 분량 나열하는 루프 전개로 바꿔 쓰면, 횟수 판정과 분기는 몇 번이 되는가? (100은 4로 나누어떨어진다고 가정한다)
