IC 설계 흐름과 EDA

스탠더드 셀의 지연과 소비 전력을 다양한 입력 천이 시간, 부하 커패시턴스, 전압, 온도 조건에서 회로 시뮬레이션하여 표로 정리하는 작업을 무엇이라고 하는가?

  1. A테이프아웃
  2. B다이싱
  3. C라이브러리 특성화(캐릭터라이제이션)
정답과 해설 보기

정답: C. 라이브러리 특성화(캐릭터라이제이션)

캐릭터라이제이션에서는 각 셀에 대해 입력 천이의 빠르기와 출력 부하 커패시턴스를 바꾼 조합으로 지연과 전력을 회로 시뮬레이션하여 표(Liberty 형식 등)로 정리합니다. 이를 PVT 코너별로 수행하므로 방대한 수의 시뮬레이션이 필요합니다. 논리 합성이나 정적 타이밍 분석은 이 표를 참조하고 보간함으로써 대규모 회로의 지연을 고속으로 계산합니다.

  • A. 테이프아웃은 제조 데이터의 인계입니다.
  • B. 다이싱은 웨이퍼를 칩으로 절단하는 공정입니다.
  • C. 맞습니다. 셀의 특성을 측정하여 표로 만드는 작업입니다.

IC 설계 흐름과 EDA의 다른 문제

  1. 정적 타이밍 분석에서 같은 칩 안에서도 위치에 따라 트랜지스터와 배선의 지연이 달라지는 것을 고려하기 위해 지연에 계수를 곱해 여유를 두는 기법을 무엇이라고 하는가?
  2. 코너 조건에서 최악의 값을 조합하는 대신 지연의 편차를 확률 분포로 다루어 타이밍을 만족할 확률을 구하는 분석 기법은 무엇인가?
  3. 타이밍 제약(SDC)에서 클록 지터나 스큐 예상분 등으로서 클록 주기에서 미리 빼 두는 여유를 지정하는 것은 무엇인가?
  4. 정적 타이밍 분석에서 비관적이 되기 쉬운 일반 분석의 결과를, 위반된 경로에 대해 실제 신호 전달 방식에 기반하여 상세히 재계산하여 불필요한 여유를 제거하는 기법을 무엇이라고 하는가?
  5. 아날로그 회로 설계에서 제조 편차에 의한 트랜지스터 특성의 변화를 무작위로 여러 번 부여하여 시뮬레이션하고 성능 분포와 수율을 추정하는 기법은 무엇인가?

이 분야의 비교

  • ASIC, FPGA, SoC의 차이는 무엇일까ASIC, FPGA, SoC를 표로 비교합니다. 각각이 무엇인지, 유연성, 성능, 초기 비용과 단가, 출시 기간, 대표 용도를 다룹니다.
