IC 설계 흐름과 EDA

일반적인 디지털 LSI 설계 흐름의 순서로 올바른 것은?

  1. A사양 설계 → RTL 설계 → 논리 합성 → 배치 배선
  2. B논리 합성 → 사양 설계 → 배치 배선 → RTL 설계
  3. C배치 배선 → RTL 설계 → 논리 합성 → 사양 설계
정답과 해설 보기

정답: A. 사양 설계 → RTL 설계 → 논리 합성 → 배치 배선

먼저 사양 설계에서 기능과 성능을 정하고, Verilog나 VHDL 같은 하드웨어 기술 언어로 RTL 설계를 합니다. 다음으로 논리 합성에서 게이트 레벨 넷리스트로 변환하고, 배치 배선에서 칩 상의 레이아웃을 만듭니다. 각 단계에서 검증을 수행하고, 마지막으로 마스크 데이터로 출력합니다. 추상도가 높은 기술에서 구체적인 형태로 차례로 풀어 가는 흐름이므로 다른 순서는 성립하지 않습니다. 선단 제품에서는 사양 결정부터 테이프아웃까지 1~2년이 걸리기도 합니다.
