IC 설계 흐름과 EDA

설계가 만족해야 할 성질(예: '요청이 오면 3사이클 이내에 응답한다')을 기술해 두고 시뮬레이션 중이나 형식 검증에서 자동으로 검사하게 하는 기법은 무엇인가?

  1. A스텔스 다이싱
  2. B어서션 기반 검증
  3. C더미 필
정답과 해설 보기

정답: B. 어서션 기반 검증

어서션은 회로가 항상 만족해야 할 성질이나 신호의 시간적 관계를 기술한 것입니다. 시뮬레이션 중에 위반을 자동으로 검출하거나 형식 검증으로 수학적으로 증명할 수 있어 결함을 발생원 가까이에서 일찍 찾을 수 있습니다. 출력 파형을 사람이 보고 확인하는 것보다 놓치는 일이 적습니다. SystemVerilog Assertions(SVA) 등으로 기술합니다. 스텔스 다이싱과 더미 필은 제조 기술입니다.

  • A. 스텔스 다이싱은 웨이퍼를 절단하는 방법입니다.
  • B. 맞습니다. 성질을 기술하여 자동으로 검사하는 기법입니다.
  • C. 더미 필은 CMP를 위해 두는 무기능 패턴입니다.

셋업·홀드 타이밍 계산기플립플롭 간 경로의 셋업·홀드 슬랙과 최대 클럭 주파수칩 내부 배선의 RC 지연금속, 폭, 두께, 간격, 유전율, 길이로 배선 저항과 커패시턴스, 분포 RC 지연, 드라이버와 부하를 포함한 지연 계산

IC 설계 흐름과 EDA의 다른 문제

  1. 저전력 설계에서 전원 도메인, 전원 차단, 레벨 시프터 등 '전원 의도'를 회로 기술과 별도로 모아서 기술하는 표준 형식은 무엇인가?
  2. 서로 다른 클록으로 동작하는 회로 사이에서 신호를 주고받는 부분에 동기화 회로가 올바르게 들어 있는지 전용 툴로 확인하는 검증을 무엇이라고 하는가?
  3. 설계 막바지나 제조 도중에 발견된 작은 수정을 설계 전체를 다시 하지 않고 기존 레이아웃을 부분적으로 변경하여 반영하는 것을 무엇이라고 하는가?
  4. 스탠더드 셀 배치에서 셀 사이의 틈을 메우거나, 웰의 전위를 고정하거나, 전원 노이즈를 억제하기 위해 두는 기능이 없는(또는 보조적인) 셀의 조합으로 올바른 것은 무엇인가?
  5. 스탠더드 셀의 지연과 소비 전력을 다양한 입력 천이 시간, 부하 커패시턴스, 전압, 온도 조건에서 회로 시뮬레이션하여 표로 정리하는 작업을 무엇이라고 하는가?
