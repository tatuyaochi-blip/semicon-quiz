IC 설계 흐름과 EDA

LSI 설계에서 사용되는 'IP(IP 코어)'의 의미로 올바른 것은?

  1. A인터넷 주소
  2. BCPU나 인터페이스 등 재사용할 수 있는 설계 완료 회로 블록
  3. C제조 장치의 명칭
정답과 해설 보기

정답: B. CPU나 인터페이스 등 재사용할 수 있는 설계 완료 회로 블록

IP 코어는 CPU 코어, 메모리, USB나 PCIe 등의 인터페이스 회로처럼 다른 설계에서 재사용할 수 있도록 준비된 설계 완료 회로 블록입니다. 자사에서 개발하는 것 외에, 전문 기업으로부터 라이선스를 받아 사용료를 내고 쓰기도 합니다. 검증된 부품을 조합함으로써 대규모 SoC의 개발 기간과 리스크를 줄일 수 있습니다. IP는 Intellectual Property(지적 재산)의 약어이며, 네트워크의 IP 주소와는 별개입니다.

IC 설계 흐름과 EDA의 다른 문제

  1. 정적 타이밍 분석에서 신호가 클록 에지 직후에 너무 빨리 변화하여 플립플롭이 이전 데이터를 올바르게 유지하지 못하게 되는 타이밍 위반은?
  2. 파운드리가 설계자에게 제공하는, 디자인 룰·디바이스 모델·셀 라이브러리 등 설계용 데이터 일체를 무엇이라고 하는가?
  3. 트랜지스터 레벨 회로의 전압과 전류를 디바이스 모델을 사용하여 상세히 계산하는 회로 시뮬레이터의 대표는?
  4. C 언어나 C++ 등으로 작성한 알고리즘 기술로부터 RTL을 자동으로 생성하는 기술을 무엇이라고 하는가?
  5. 사용하지 않는 회로 블록에 대한 클록 공급을 멈춰 불필요한 소비 전력을 줄이는 저전력 설계 기법은?
