타이밍 분석과 CDC

주기 2.0 ns인 클럭에서 입력 단자에 set_input_delay 0.6 ns가 설정되어 있습니다. 내부 플립플롭의 셋업 타임이 0.1 ns이고 클럭의 지연과 스큐를 무시하면, 입력 단자에서 플립플롭까지의 칩 내부 경로에 허용되는 최대 지연은 얼마입니까?

  1. A1.3 ns
  2. B1.9 ns
  3. C1.4 ns
정답과 해설 보기

정답: A. 1.3 ns

set_input_delay는 외부 송신 측 디바이스의 클럭→출력 지연이나 기판의 배선 지연 등, 클럭 에지부터 데이터가 입력 단자에 도착하기까지 칩 외부에서 쓰이는 시간을 지정합니다. 칩 내부에서 쓸 수 있는 것은 나머지 시간으로, 2.0 − 0.6 − 0.1 = 1.3 ns입니다. 1.9 ns는 입력 지연을 고려하지 않은 값, 1.4 ns는 셋업 타임을 빼는 것을 잊은 값입니다. 입력 지연을 올바르게 지정하지 않으면 입력 단자로부터의 경로가 올바르게 분석되지 않습니다.

타이밍 분석과 CDC의 다른 문제

  1. set_output_delay에 지정하는 값이 나타내는 것으로 올바른 것은?
  2. 주기 2.5 ns(400 MHz)인 클럭에서 출력 단자에 set_output_delay 0.8 ns가 설정되어 있습니다. 출력 단자를 구동하는 플립플롭의 클럭→출력 지연이 0.2 ns일 때, 플립플롭에서 출력 단자까지의 조합 회로와 배선에 허용되는 최대 지연은 얼마입니까(클럭의 지연은 무시합니다)?
  3. 주기 1.0 ns인 클럭으로 플립플롭 A→B→C로 연결되는 경로가 있습니다. A→B는 클럭→출력 지연과 셋업 타임을 포함해 1.2 ns가 필요하고, B→C는 0.8 ns면 충분합니다. 스큐를 의도적으로 이용해 양쪽의 셋업을 만족하려면 B의 클럭을 어떻게 하면 됩니까(A와 C의 클럭은 동시에 도착하는 것으로 합니다)?
  4. 클럭을 분주 회로로 2분주하여 다른 회로에 사용하는 경우, SDC에서의 처리로 올바른 것은?
  5. 비동기 리셋이 있는 플립플롭에서 리셋 해제가 클럭 에지에 너무 가깝지 않은지 STA로 조사하는 체크는?
