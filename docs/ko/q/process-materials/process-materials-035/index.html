공정 재료(가스와 케미칼)

고순도 가스 배관에 일반적으로 사용되는 재료와 표면 처리의 조합으로 올바른 것은?

  1. A염화비닐 관
  2. B철 배관에 도장한 것
  3. C스테인리스강(SUS316L 등)의 내면을 전해 연마한 것
정답과 해설 보기

정답: C. 스테인리스강(SUS316L 등)의 내면을 전해 연마한 것

고순도 가스 배관에는 내식성이 높은 SUS316L 등의 저탄소 스테인리스강을 사용하고, 내면을 전해 연마하여 매우 매끄럽게 합니다. 표면적이 줄어 수분이나 불순물의 흡착이 줄고 파티클도 나오기 어려워집니다. 전해 연마로 표면에 크롬 산화물이 풍부한 부동태막이 생겨 부식에도 강해집니다. 염화비닐은 가스를 투과·방출하고, 도장한 철은 부식이나 도막으로부터의 오염이 문제가 됩니다.
