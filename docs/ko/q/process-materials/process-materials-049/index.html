공정 재료(가스와 케미칼)

가스 라인을 개방하거나 다른 가스로 전환하기 전에 불활성 가스로의 가압과 배기를 여러 번 반복하는 조작을 무엇이라 하는가?

  1. A사이클 퍼지
  2. B드라이 에칭
  3. C어닐
정답과 해설 보기

정답: A. 사이클 퍼지

사이클 퍼지는 배관 속을 질소 등의 불활성 가스로 가압한 뒤 진공 배기나 배기를 하는 조작을 여러 번 반복하여 남은 가스나 수분을 희석해 내보내는 방법입니다. 1회마다 농도가 일정 비율로 내려가므로, 예를 들어 1회에 1/10이 되는 조건이면 5회에 10만분의 1까지 낮출 수 있습니다. 독성 가스 봄베 교체 시 등에 안전과 순도를 확보하기 위해 수행합니다.

  2. CVD 등의 원료로 사용되는 실란(SiH4)의 취급상 주된 위험성은?

  4. 반도체 제조에 사용하는 초순수의 순도 관리에 사용되는 대표적인 지표는?
  5. 실리콘 산화막(SiO2)의 드라이 에칭에 주로 사용되는 가스는?
