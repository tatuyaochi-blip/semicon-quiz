이온 주입

MOSFET의 문턱 전압 조정이나 웰과 같은 중간 정도의 도즈량 주입에 주로 사용되는 이온 주입 장치는 무엇인가?

  1. ACMP 장치
  2. B중전류 이온 주입 장치
  3. C전자빔 묘화 장치
정답과 해설 보기

정답: B. 중전류 이온 주입 장치

이온 주입 장치는 도즈량과 에너지의 범위에 따라 중전류(문턱 조정이나 할로 주입 등, 10¹¹~10¹⁴ cm⁻²), 고전류(소스·드레인 등의 고도즈), 고에너지(깊은 웰 등)로 나뉩니다. 중전류 장치는 빔이 가늘고 안정적이어서 도즈 정밀도와 주입 각도의 정밀한 제어(0.1° 단위)에 뛰어나며, 각도 편차가 트랜지스터 특성에 직결되는 주입에 사용됩니다.

  • A. CMP 장치는 연마로 평탄화하는 장치입니다.
  • B. 올바릅니다. 중간 정도의 도즈 주입에 사용됩니다.
  • C. 전자빔 묘화 장치는 패턴을 그리는 장치입니다.

이온 주입의 다른 문제

  1. 주입된 이온이 실리콘 원자를 튕겨 냈을 때 결정 안에 생기는, 공공과 격자간 원자의 쌍을 무엇이라 하는가?
  2. 대전류 이온 주입 중에 웨이퍼를 냉각하는 주된 이유는 무엇인가?
  3. 이온 주입으로 생기는 결정 손상의 분포로 일반적으로 올바른 것은 무엇인가?
  4. MOSFET의 폴리실리콘 게이트 전극을 저저항으로 만들기 위해 게이트에 불순물을 도입하는 방법으로 일반적으로 사용되어 온 것은 무엇인가?
  5. 이미 p형인 영역에 n형 불순물을 주입하여 순 불순물 농도를 낮추거나 도전형을 반전시키는 기법을 무엇이라 하는가?
