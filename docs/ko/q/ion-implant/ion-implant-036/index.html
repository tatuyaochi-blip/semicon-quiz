이온 주입

일반적인 이온 주입 장비에서 이온이 지나는 순서로 올바른 것은?

  1. A이온 소스 → 질량 분석 → 가속부 → 스캔 → 웨이퍼
  2. B가속부 → 이온 소스 → 질량 분석 → 웨이퍼
  3. C질량 분석 → 이온 소스 → 웨이퍼 → 가속부
정답과 해설 보기

정답: A. 이온 소스 → 질량 분석 → 가속부 → 스캔 → 웨이퍼

이온 소스에서 가스를 플라즈마로 만들어 이온을 인출하고, 질량 분석 자석으로 목적 이온만 골라내며, 가속부에서 필요한 에너지까지 가속합니다. 그 후 빔을 스캔하여 웨이퍼 전면에 균일하게 주입하고, 패러데이 컵으로 도즈를 측정합니다. 장비에 따라서는 먼저 가속한 뒤 분석하거나, 고에너지로 수송한 뒤 마지막에 감속하는 등 순서가 다릅니다.

이온 주입의 다른 문제

  1. 같은 가속 에너지로 실리콘에 주입했을 때 비소(질량수 75)와 인(질량수 31)의 비정 관계로 올바른 것은?
  2. 이온 주입 장비에서 가속 전압 50 kV로 2가 이온(전하가 2배)을 가속했을 때의 에너지는 얼마입니까?
  3. MOSFET의 문턱 전압 조정이나 웰과 같은 중간 정도의 도즈량 주입에 주로 사용되는 이온 주입 장비는?
  4. 주입된 이온이 실리콘 원자를 튀어나오게 했을 때 결정 속에 생기는 공공과 격자 간 원자의 쌍을 무엇이라고 합니까?
  5. 대전류 이온 주입 중 웨이퍼를 냉각하는 주된 이유는?
