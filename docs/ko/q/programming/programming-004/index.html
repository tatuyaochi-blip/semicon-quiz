프로그래밍의 기초(의사 코드 트레이스)

i를 2씩 늘리는 다음 for 문을 실행한 후의 s의 값은?

integer: s ← 0
for (i from 1 to 10 step 2)
  s ← s + i
endfor
  1. A25
  2. B30
  3. C36
정답과 해설 보기

정답: A. 25

i는 1, 3, 5, 7, 9로 2씩 늘어나고, 다음 값 11은 종료값 10을 넘으므로 반복이 끝납니다. s = 1 + 3 + 5 + 7 + 9 = 25입니다. for 문에서는 제어 변수가 종료값을 넘은 시점에서 반복을 빠져나가므로, 종료값을 넘은 값으로 안쪽 처리를 실행하는 일은 없습니다.
