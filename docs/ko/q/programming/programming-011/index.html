프로그래밍의 기초(의사 코드 트레이스)

배열의 인덱스는 1부터 시작한다. 이웃한 요소를 비교하는 다음 프로그램을 실행한 후의 c의 값은?

integer array: a ← {2, 2, 3, 3, 3, 1, 1}
integer: c ← 0
for (i from 1 to length(a) − 1 step 1)
  if (a[i] = a[i + 1])
    c ← c + 1
  endif
endfor
  1. A4
  2. B6
  3. C7
정답과 해설 보기

정답: A. 4

이웃한 두 요소가 같은 쌍의 수를 셉니다. i는 1부터 6까지 움직이며, a[1]과 a[2], a[3]과 a[4], a[4]와 a[5], a[6]과 a[7]의 4쌍이 같으므로 c = 4입니다. 비교는 7 − 1 = 6회 이루어집니다. 종료값을 요소 수 − 1로 한 것은 a[i + 1]이 배열의 범위를 넘지 않도록 하기 위해서입니다.
