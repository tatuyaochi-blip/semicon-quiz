차량용 반도체와 기능 안전

차량용 마이컴의 안전 메커니즘으로 사용되는 락스텝 CPU의 구조로 올바른 것은?

  1. A2개의 CPU 코어에 서로 다른 처리를 분담시켜 처리 속도를 약 2배로 한다
  2. B2개의 CPU 코어에 같은 명령을 동시에 실행시키고, 출력을 클록마다 비교하여 일치하지 않으면 고장으로 알린다
  3. C고장이 발견되면 CPU의 동작을 일시적으로 멈추고(락), 예비 회로로 전환하여 고장 난 부분을 자동으로 수리한 뒤 재개한다
정답과 해설 보기

정답: B. 2개의 CPU 코어에 같은 명령을 동시에 실행시키고, 출력을 클록마다 비교하여 일치하지 않으면 고장으로 알린다

락스텝은 같은 구성의 CPU 코어를 2개 준비하여 같은 프로그램을 실행시키고, 비교 회로로 출력을 대조하는 방식입니다. 우주선에 의한 비트 반전이나 회로 고장으로 한쪽 결과가 바뀌면 불일치로 검출할 수 있으므로, CPU 고장에 대해 높은 진단 커버리지를 얻을 수 있습니다. 2개의 코어는 같은 처리를 하고 있으므로 성능은 1코어분입니다. 2개 코어의 비교만으로는 어느 쪽이 올바른지 알 수 없으므로, 검출 후에는 리셋이나 안전한 상태로의 전환을 수행합니다.
