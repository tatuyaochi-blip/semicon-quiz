차량용 반도체와 기능 안전

CAN FD의 특징으로 올바른 것은?

  1. A중재 부분은 기존 CAN과 같은 속도로 수행하고 데이터 부분만 빠른 통신 속도로 전환하며, 1프레임으로 최대 64바이트까지 보낼 수 있다
  2. B전선 대신 광섬유를 사용하여, 기존 CAN과 같은 최대 8바이트의 데이터를 더 빠르게 보낸다
  3. C중재를 없애고, 시간을 슬롯으로 나누어 각 노드가 송신할 시각을 미리 정해 두는 시간 트리거 방식으로 바꾸어 대폭 고속화했다
정답과 해설 보기

정답: A. 중재 부분은 기존 CAN과 같은 속도로 수행하고 데이터 부분만 빠른 통신 속도로 전환하며, 1프레임으로 최대 64바이트까지 보낼 수 있다

기존 CAN(클래시컬 CAN)은 최대 1 Mbit/s이고, 1프레임의 데이터는 최대 8바이트였습니다. CAN FD에서는 모든 노드가 비트를 맞춰 보아야 하는 중재 부분은 기존대로의 속도로 수행하고, 데이터 부분만 수 Mbit/s의 속도로 전환합니다. 데이터 길이도 최대 64바이트로 늘어나, 소프트웨어 재기록이나 센서 데이터 송신을 효율적으로 할 수 있습니다. 광섬유는 사용하지 않으며, 시간 트리거 방식은 FlexRay의 특징입니다.
