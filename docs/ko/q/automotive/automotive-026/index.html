차량용 반도체와 기능 안전

차량용 마이컴의 메모리에서 1비트 오류를 정정하고 2비트 오류를 검출할 수 있는 ECC(SEC-DED)를 사용하고 있다. 읽어 낸 데이터에 2비트 오류가 일어났을 때 일반적으로 어떻게 되는가?

  1. A2비트까지의 오류는 검사 비트를 사용하여 자동으로 정정되므로, 에러는 아무것도 통지되지 않고 그대로 처리가 계속된다
  2. B오류는 검출도 정정도 할 수 없으므로, 잘못된 데이터가 그대로 사용되어 처리가 계속된다
  3. C정정은 할 수 없지만 검출은 할 수 있으므로, 에러로 통지하고 시스템을 안전한 상태로 전환하는 등의 조치를 취한다
정답과 해설 보기

정답: C. 정정은 할 수 없지만 검출은 할 수 있으므로, 에러로 통지하고 시스템을 안전한 상태로 전환하는 등의 조치를 취한다

SEC-DED(Single Error Correction, Double Error Detection)는 예를 들어 64비트 데이터에 8비트의 검사 비트를 붙여, 1비트 오류는 정정하고 2비트 오류는 정정할 수 없지만 확실하게 검출합니다. 2비트 오류가 발견되면 마이컴은 에러를 통지하고, 소프트웨어는 데이터를 사용하지 않고 리셋이나 안전한 상태로의 전환을 수행합니다. 1비트 오류도 정정한 뒤 기록해 두면, 오류가 누적되기 전에 이상의 징후를 파악할 수 있습니다.
