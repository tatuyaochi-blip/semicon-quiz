차량용 반도체와 기능 안전

어떤 위험 사건을 평가한 결과 심각도 S3·노출도 E4·제어 가능성 C3으로 ASIL D가 되었다. 같은 사건에서 제어 가능성만 C2(보통은 대부분의 운전자가 회피할 수 있음)였다고 하면 ASIL은 어떻게 되는가?

  1. AASIL D
  2. BASIL B
  3. CASIL C
정답과 해설 보기

정답: C. ASIL C

ISO 26262의 ASIL 표에서는 S3·E4·C3 조합만 ASIL D가 되며, S·E·C 중 어느 하나가 1단계 내려가면 ASIL도 1단계 내려가 ASIL C가 됩니다. 기준으로서 S의 숫자(1~3)·E의 숫자(1~4)·C의 숫자(1~3)의 합계가 10이면 D, 9이면 C, 8이면 B, 7이면 A이고, 그 이하는 QM이 된다고 기억하면 편리합니다. 이 예에서는 3 + 4 + 2 = 9이므로 ASIL C입니다. ASIL D 그대로 변하지 않는 것도, 2단계 내려가는 것도 아닙니다.
