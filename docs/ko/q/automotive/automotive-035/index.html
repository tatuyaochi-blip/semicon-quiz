차량용 반도체와 기능 안전

CAN에서 2개의 노드가 동시에 프레임을 보내기 시작했을 때의 동작으로 올바른 것은?

  1. A2개의 프레임이 충돌하여 둘 다 깨지므로, 두 노드가 무작위 시간만큼 기다린 뒤 다시 보낸다
  2. BID 값이 작은(우선순위가 높은) 프레임이 그대로 송신을 계속하고, 진 노드는 송신을 멈추고 나중에 다시 보내므로 이긴 프레임은 깨지지 않는다
  3. CID 값이 큰 프레임이 우선되며, ID 값이 작은 프레임은 버려지고 다시 보내지지 않는다
정답과 해설 보기

정답: B. ID 값이 작은(우선순위가 높은) 프레임이 그대로 송신을 계속하고, 진 노드는 송신을 멈추고 나중에 다시 보내므로 이긴 프레임은 깨지지 않는다

CAN 버스에서는 0(도미넌트)과 1(리세시브)이 동시에 출력되면 0이 이깁니다. 송신 중인 노드는 자신이 낸 비트와 버스 상태를 1비트씩 비교하여, 1을 냈는데 0이 보이면 중재에서 졌다고 판단하고 송신을 멈춥니다. ID는 앞부분부터 보내지므로 값이 작은 ID일수록 우선순위가 높아지고, 이긴 프레임은 깨지지 않고 그대로 도착합니다. 이를 비파괴 중재라고 부릅니다. 충돌 후 무작위 시간을 기다리는 것은 예전 이더넷의 CSMA/CD 방식입니다.
