차량용 반도체와 기능 안전

차량용 마이컴의 클록 감시 안전 메커니즘으로 적절한 것은?

  1. A메인 클록과는 독립된 별도의 발진기를 기준으로 하여, 메인 클록의 정지나 주파수 어긋남을 검출한다
  2. B메인 클록 자신으로부터 만든 기준을 사용하여, 같은 메인 클록의 주파수를 측정한다
  3. C클록 주파수를 규격보다 높게 설정하여, 고장 나도 처리가 시간 안에 끝나도록 한다
정답과 해설 보기

정답: A. 메인 클록과는 독립된 별도의 발진기를 기준으로 하여, 메인 클록의 정지나 주파수 어긋남을 검출한다

클록이 멈추거나 주파수가 어긋나면 타이머의 시간이나 통신 속도가 틀어져 제어를 올바르게 할 수 없게 됩니다. 그래서 내장 발진기 등 메인 클록과는 독립된 별도의 기준으로 클록 주기를 세어, 정한 범위를 벗어나면 이상으로 알립니다. 감시 대상과 같은 클록으로부터 만든 기준으로는 그 클록이 멈추면 감시도 멈추므로 이상을 찾아낼 수 없습니다. 주파수를 규격보다 높이면 오히려 오동작의 원인이 됩니다.
