차량용 반도체와 기능 안전

다음 중 ISO 26262(기능 안전)가 아니라 주로 SOTIF(ISO 21448, 의도된 기능의 안전성)에서 다루는 문제는?

  1. A레이더 송신 회로의 부품이 오랜 사용 중에 온도 변화 등의 스트레스로 열화되어 고장 나, 전방의 물체를 검출할 수 없게 된다
  2. B브레이크 제어 소프트웨어의 오류 때문에 특정 조건에서 제동력 계산을 잘못한다
  3. C고장 나지 않은 카메라가 강한 역광 때문에 전방의 보행자를 인식하지 못해 자동 브레이크가 작동하지 않는다
정답과 해설 보기

정답: C. 고장 나지 않은 카메라가 강한 역광 때문에 전방의 보행자를 인식하지 못해 자동 브레이크가 작동하지 않는다

SOTIF는 부품이 고장 나지 않았더라도 센서의 성능 한계나 인식 알고리즘의 부족, 사양의 불충분함, 예견 가능한 오용 등으로 생기는 위험을 다룹니다. 역광으로 보행자를 인식하지 못하는 것은 고장이 아니라 기능의 한계로 인한 문제이므로 SOTIF의 대상입니다. 부품 열화로 인한 고장은 랜덤 하드웨어 고장, 소프트웨어 오류는 체계적 고장으로, 둘 다 ISO 26262에서 다룹니다. SOTIF에서는 시험이나 시뮬레이션으로 미지의 위험한 시나리오를 줄여 나갑니다.

차량용 반도체와 기능 안전의 다른 문제

  2. 차량용 전자 부품의 인증 시험 기준인 AEC-Q100·AEC-Q101·AEC-Q200이 주로 대상으로 하는 부품의 조합으로 올바른 것은?
  3. 어떤 차량용 부품이 15년 동안 하루 24시간 내내 계속 동작한다고 가정한다. 총 동작 시간은 대략 몇 시간인가?
  4. 차량용 반도체에 요구되는 "제로 디펙트(무결함)"의 사고방식으로 가장 적절한 것은?
  5. 자동차 업계에서 사용되는 PPAP(양산 부품 승인 프로세스)의 설명으로 올바른 것은?
