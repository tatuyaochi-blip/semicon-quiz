차량용 반도체와 기능 안전

여러 ECU의 기능을 하나의 고성능 SoC에 통합하고, 서로 다른 ASIL의 소프트웨어를 함께 동작시킬 때 요구되는 것으로 올바른 것은?

  1. AASIL이 낮은 소프트웨어와 ASIL이 높은 소프트웨어를 같은 메모리 영역에 두고, 데이터를 자유롭게 읽고 쓰게 한다
  2. BASIL이 낮은 소프트웨어의 오동작이 ASIL이 높은 소프트웨어의 메모리나 실행 시간을 침범하지 않도록, 메모리 보호나 시간 감시 등으로 분리한다
  3. CASIL이 낮은 소프트웨어에 높은 우선순위를 주고, ASIL이 높은 소프트웨어는 빈 시간에만 실행한다
정답과 해설 보기

정답: B. ASIL이 낮은 소프트웨어의 오동작이 ASIL이 높은 소프트웨어의 메모리나 실행 시간을 침범하지 않도록, 메모리 보호나 시간 감시 등으로 분리한다

하나의 SoC에 여러 기능을 모으면 부품이나 ECU의 수를 줄일 수 있지만, ASIL이 낮은 소프트웨어의 버그가 메모리를 덮어써 망가뜨리거나 CPU 시간을 다 써 버려 ASIL이 높은 기능을 방해할 우려가 있습니다. 그래서 메모리 보호 유닛이나 하이퍼바이저에 의한 공간 분리, 실행 시간의 할당과 감시에 의한 시간 분리 등으로 간섭이 없음(Freedom from Interference)을 보여 줍니다. 분리하지 않는 경우에는 모두를 가장 높은 ASIL로 개발해야 하므로 수고가 커집니다.
