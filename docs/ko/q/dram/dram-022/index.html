정답과 해설 보기

정답: B. 서로 다른 뱅크의 동작을 겹쳐 수행하여 실효 액세스 성능을 높이기 위해

행의 활성화나 프리차지에는 십수 ns가 걸립니다. 내부를 여러 뱅크로 나누면 어떤 뱅크가 이러한 동작을 하는 동안 다른 뱅크에 액세스할 수 있어, 대기 시간을 숨기고 전송 효율을 높일 수 있습니다. DDR4는 16뱅크(4개의 뱅크 그룹), DDR5는 32뱅크입니다. 여러 뱅크에서 서로 다른 행을 열어 둘 수 있으므로 페이지 히트의 기회도 늘어납니다.

DRAM의 다른 문제

  2. 향후 DRAM의 대용량화 수단으로 연구 개발이 진행되고 있는 3D DRAM의 개념으로 올바른 것은?
  3. DRAM에서 특정 행을 짧은 시간에 여러 번 활성화하면 인접한 행의 데이터가 반전되는 현상을 무엇이라 하는가?
  4. DRAM 셀의 데이터 유지 시간을 결정하는 주된 누설 경로로 올바른 것은?
  5. DRAM의 셀 면적을 나타낼 때 사용하는 '6F²'의 F의 의미로 올바른 것은?

이 분야의 비교

  • DRAM과 SRAM의 차이점 한눈에 정리DRAM과 SRAM을 한 장의 표로 비교합니다. 셀 구조, 리프레시, 속도, 집적도, 비용, 전력, 대표 용도와 각각을 언제 쓰는지 안내합니다.
  • DDR, LPDDR, GDDR, HBM: DRAM 종류 비교DDR, LPDDR, GDDR, HBM을 표로 비교합니다. 대상 기기, 버스 폭, 속도, 대역폭, 전력, 패키징, 용량, 비용을 다룹니다.
  • DDR4 vs DDR5: 차이점과 업그레이드할 가치DDR4와 DDR5를 표로 비교합니다: 속도, 전압, 채널 구조, 버스트 길이, 뱅크, 온다이 ECC, 전력 관리, 지연 시간, 대역폭, 호환성.
