DRAM

DDR4 SDRAM 등에서 사용되는 「8n 프리페치」의 개념으로 올바른 것은?

  1. A내부 셀 어레이에서 한 번에 8배 폭의 데이터를 꺼내, 외부 단자에서 고속으로 차례로 출력한다
  2. B8회 분량의 리프레시를 한꺼번에 수행한다
  3. C8개의 칩에 같은 데이터를 쓴다
정답과 해설 보기

정답: A. 내부 셀 어레이에서 한 번에 8배 폭의 데이터를 꺼내, 외부 단자에서 고속으로 차례로 출력한다

셀 어레이 자체의 동작 속도는 세대가 바뀌어도 거의 변하지 않으므로, DDR4에서는 내부에서 1회 접근으로 단자 폭의 8배(8n) 데이터를 한꺼번에 읽어 내고, 외부의 고속 인터페이스로 차례로 내보냅니다. 그래서 버스트 길이는 8이 됩니다. DDR5는 16n 프리페치로, 내부 속도를 올리지 않고 외부 전송 속도를 2배로 했습니다. DDR(2n), DDR2(4n)와 세대마다 배로 늘려 온 구조입니다.

  • A. 올바릅니다. 내부에서 넓은 폭의 데이터를 읽어 외부에서 고속으로 출력합니다.
  • B. 리프레시를 모으는 구조가 아닙니다.
  • C. 같은 데이터를 여러 칩에 쓰는 구조가 아닙니다.

  3. DRAM의 워드라인을 구동하는 전압으로 전원 전압보다 높은 승압 전압(VPP)이 사용되는 주된 이유는?

이 분야의 비교

  • DRAM과 SRAM의 차이점 한눈에 정리DRAM과 SRAM을 한 장의 표로 비교합니다. 셀 구조, 리프레시, 속도, 집적도, 비용, 전력, 대표 용도와 각각을 언제 쓰는지 안내합니다.
  • DDR, LPDDR, GDDR, HBM: DRAM 종류 비교DDR, LPDDR, GDDR, HBM을 표로 비교합니다. 대상 기기, 버스 폭, 속도, 대역폭, 전력, 패키징, 용량, 비용을 다룹니다.
  • DDR4 vs DDR5: 차이점과 업그레이드할 가치DDR4와 DDR5를 표로 비교합니다: 속도, 전압, 채널 구조, 버스트 길이, 뱅크, 온다이 ECC, 전력 관리, 지연 시간, 대역폭, 호환성.
