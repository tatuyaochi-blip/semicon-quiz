DRAM

DDR4 SDRAM 등에서 사용되는 '8n 프리페치'의 개념으로 올바른 것은?

  1. A내부 셀 어레이에서 한 번에 8배 폭의 데이터를 꺼내 외부 핀에서 고속으로 차례로 출력한다
  2. B8회분의 리프레시를 한꺼번에 수행한다
  3. C8개의 칩에 같은 데이터를 쓴다
정답과 해설 보기

정답: A. 내부 셀 어레이에서 한 번에 8배 폭의 데이터를 꺼내 외부 핀에서 고속으로 차례로 출력한다

셀 어레이 자체의 동작 속도는 세대가 바뀌어도 거의 변하지 않으므로, DDR4에서는 내부에서 한 번의 액세스로 핀 폭의 8배(8n) 데이터를 한꺼번에 읽어 외부의 고속 인터페이스로 차례로 내보냅니다. 그래서 버스트 길이는 8이 됩니다. 프리페치는 DDR(2n), DDR2(4n), DDR3(8n)로 두 배씩 늘었고, DDR4는 8n 그대로 뱅크 그룹으로 고속화했습니다. DDR5는 16n 프리페치로, 내부 속도를 높이지 않고 외부 전송 속도를 높이고 있습니다.
