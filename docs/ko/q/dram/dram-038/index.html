DRAM

DRAM의 버스트 전송에 대한 설명으로 올바른 것은?

  1. A한 번의 읽기 명령으로 연속된 여러 데이터를 클록마다 이어서 전송한다
  2. B데이터를 압축하여 전송한다
  3. C리프레시와 데이터 전송을 동시에 수행한다
정답과 해설 보기

정답: A. 한 번의 읽기 명령으로 연속된 여러 데이터를 클록마다 이어서 전송한다

버스트 전송에서는 한 번의 읽기/쓰기 명령으로 연속된 주소의 여러 데이터를 클록마다 이어서 전송합니다. DDR4의 버스트 길이는 8, DDR5는 16이며, 64비트 폭의 DDR4라면 8 × 8바이트 = 64바이트로 CPU 캐시 라인(64바이트) 1개 분량에 딱 맞습니다. 명령 횟수를 줄일 수 있으므로 한정된 명령 버스 대역폭으로도 높은 데이터 전송 속도를 실현할 수 있습니다.

DRAM의 다른 문제

  1. 데이터 전송 속도 3,200 MT/s, 데이터 버스 폭 64비트인 DDR4 메모리 1채널의 피크 대역폭에 가장 가까운 것은?
  2. PC에서 메모리를 '듀얼 채널'로 동작시키는 주된 효과는?
  3. DRAM 모듈의 '랭크'에 대한 설명으로 올바른 것은?
  4. 데이터 폭 8비트(x8)의 DRAM 칩으로 64비트 폭의 데이터 버스를 구성하려면 1랭크당 몇 개의 칩이 필요한가? (ECC 없음)
  5. 현재 대부분의 PC용 프로세서에서 DRAM을 제어하는 메모리 컨트롤러가 놓여 있는 곳은?

이 분야의 비교

  • DRAM과 SRAM의 차이점 한눈에 정리DRAM과 SRAM을 한 장의 표로 비교합니다. 셀 구조, 리프레시, 속도, 집적도, 비용, 전력, 대표 용도와 각각을 언제 쓰는지 안내합니다.
  • DDR, LPDDR, GDDR, HBM: DRAM 종류 비교DDR, LPDDR, GDDR, HBM을 표로 비교합니다. 대상 기기, 버스 폭, 속도, 대역폭, 전력, 패키징, 용량, 비용을 다룹니다.
  • DDR4 vs DDR5: 차이점과 업그레이드할 가치DDR4와 DDR5를 표로 비교합니다: 속도, 전압, 채널 구조, 버스트 길이, 뱅크, 온다이 ECC, 전력 관리, 지연 시간, 대역폭, 호환성.
