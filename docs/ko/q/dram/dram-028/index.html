DRAM

DRAM 접근에서 열려 있던 행을 닫고 비트라인을 중간 전위로 되돌려 다음 행의 활성화에 대비하는 동작을 무엇이라 하는가?

  1. A리프레시
  2. B프리차지
  3. C소거
정답과 해설 보기

정답: B. 프리차지

다른 행에 접근하기 전에 현재 행을 닫고 비트라인을 중간 전위(VDD/2)로 되돌리는 것이 프리차지입니다. 중간 전위에서 시작하면 셀의 0과 1 어느 쪽이든 비트라인 전압이 위아래로 같은 만큼 움직여 센스 앰프가 판정하기 쉬워집니다. 이 시간은 tRP로 규정되며 행 전환 지연에 포함됩니다. 메모리 컨트롤러는 페이지를 열어 둘지 닫을지를 접근 경향에 따라 선택합니다.

DRAM의 다른 문제

  1. DDR5에서 채택된, DRAM 칩 내부에서 오류를 정정하는 기능은?
  2. 프로세서의 성능 향상에 비해 메모리의 대역이나 지연의 개선이 따라가지 못해 생기는 성능 제약을 무엇이라 하는가?
  3. DRAM의 「RAM(Random Access Memory)」의 의미로 올바른 것은?
  4. PC나 서버에서 DRAM이 주로 사용되는 용도는?
  5. PC의 메모리로서, 여러 DRAM 칩을 작은 기판에 얹어 꽂을 수 있게 만든 부품을 무엇이라 하는가?

이 분야의 비교

  • DRAM과 SRAM의 차이점 한눈에 정리DRAM과 SRAM을 한 장의 표로 비교합니다. 셀 구조, 리프레시, 속도, 집적도, 비용, 전력, 대표 용도와 각각을 언제 쓰는지 안내합니다.
  • DDR, LPDDR, GDDR, HBM: DRAM 종류 비교DDR, LPDDR, GDDR, HBM을 표로 비교합니다. 대상 기기, 버스 폭, 속도, 대역폭, 전력, 패키징, 용량, 비용을 다룹니다.
  • DDR4 vs DDR5: 차이점과 업그레이드할 가치DDR4와 DDR5를 표로 비교합니다: 속도, 전압, 채널 구조, 버스트 길이, 뱅크, 온다이 ECC, 전력 관리, 지연 시간, 대역폭, 호환성.
