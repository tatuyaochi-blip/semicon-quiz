DRAM

데이터 폭 8비트(x8)의 DRAM 칩으로 64비트 폭의 데이터 버스를 구성하려면 1랭크당 몇 개의 칩이 필요한가? (ECC 없음)

  1. A4개
  2. B64개
  3. C8개
정답과 해설 보기

정답: C. 8개

64비트 ÷ 8비트 = 8이므로, x8 칩 8개를 나란히 놓고 동시에 액세스하면 64비트 폭이 됩니다. x4 칩이라면 16개, x16이라면 4개입니다. ECC 포함 모듈은 검사 비트 8개분의 칩을 추가하여 x8이라면 9개(72비트 폭)가 됩니다. DDR5 모듈은 32비트의 서브 채널 2개로 나뉘며, ECC 포함 시 각 서브 채널이 40비트 폭이 됩니다.

DRAM의 다른 문제

  1. 현재 대부분의 PC용 프로세서에서 DRAM을 제어하는 메모리 컨트롤러가 놓여 있는 곳은?
  2. DRAM 규격에서 칩 온도가 높은 범위(예: 85℃ 초과)에서 요구되는 대응으로 일반적인 것은?
  3. DRAM의 용량이 커짐에 따라 리프레시와 관련하여 문제가 되기 쉬운 것은?
  4. DRAM 셀 어레이의 비트 라인 구성에서 쌍을 이루는 비트 라인을 같은 셀 어레이 안에 나란히 배치하는 방식은?
  5. DDR4 SDRAM 등에서 사용되는 '8n 프리페치'의 개념으로 올바른 것은?

이 분야의 비교

  • DRAM과 SRAM의 차이점 한눈에 정리DRAM과 SRAM을 한 장의 표로 비교합니다. 셀 구조, 리프레시, 속도, 집적도, 비용, 전력, 대표 용도와 각각을 언제 쓰는지 안내합니다.
  • DDR, LPDDR, GDDR, HBM: DRAM 종류 비교DDR, LPDDR, GDDR, HBM을 표로 비교합니다. 대상 기기, 버스 폭, 속도, 대역폭, 전력, 패키징, 용량, 비용을 다룹니다.
  • DDR4 vs DDR5: 차이점과 업그레이드할 가치DDR4와 DDR5를 표로 비교합니다: 속도, 전압, 채널 구조, 버스트 길이, 뱅크, 온다이 ECC, 전력 관리, 지연 시간, 대역폭, 호환성.
