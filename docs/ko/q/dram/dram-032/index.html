DRAM

PC나 서버에서 DRAM이 주로 사용되는 용도는?

  1. ACPU 내부의 레지스터
  2. B실행 중인 프로그램과 데이터를 두는 메인 메모리
  3. C전원을 꺼도 데이터를 남기기 위한 장기 보존
정답과 해설 보기

정답: B. 실행 중인 프로그램과 데이터를 두는 메인 메모리

DRAM은 대용량이면서 비교적 고속이므로 CPU가 실행 중인 프로그램과 데이터를 두는 메인 메모리로 사용됩니다. 용량은 PC에서 8~64 GB, 서버에서는 한 대에 수 TB에 달합니다. 휘발성이므로 장기 보존에는 SSD나 HDD를 사용하고, CPU 내부의 레지스터와 캐시에는 SRAM이나 플립플롭을 사용합니다. 속도, 용량, 가격이 다른 메모리를 조합한 메모리 계층의 중간에 위치합니다.

DRAM의 다른 문제

  1. PC의 메모리로, 여러 DRAM 칩을 작은 기판에 탑재하여 꽂을 수 있게 한 부품을 무엇이라 하는가?
  2. SDRAM의 'S(Synchronous)'가 나타내는 특징으로 올바른 것은?
  3. DRAM 세계 시장에서 큰 점유율을 가진 주요 제조사 3사의 조합으로 올바른 것은?
  4. 일반적인 DRAM 규격에서 모든 셀을 한 번씩 리프레시하는 주기로 정해진 시간에 가장 가까운 것은? (통상 온도 범위)
  5. DRAM의 타이밍 규격 'tRCD'가 나타내는 것은?

이 분야의 비교

  • DRAM과 SRAM의 차이점 한눈에 정리DRAM과 SRAM을 한 장의 표로 비교합니다. 셀 구조, 리프레시, 속도, 집적도, 비용, 전력, 대표 용도와 각각을 언제 쓰는지 안내합니다.
  • DDR, LPDDR, GDDR, HBM: DRAM 종류 비교DDR, LPDDR, GDDR, HBM을 표로 비교합니다. 대상 기기, 버스 폭, 속도, 대역폭, 전력, 패키징, 용량, 비용을 다룹니다.
  • DDR4 vs DDR5: 차이점과 업그레이드할 가치DDR4와 DDR5를 표로 비교합니다: 속도, 전압, 채널 구조, 버스트 길이, 뱅크, 온다이 ECC, 전력 관리, 지연 시간, 대역폭, 호환성.
