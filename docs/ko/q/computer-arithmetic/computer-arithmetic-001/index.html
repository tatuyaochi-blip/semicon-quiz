컴퓨터 산술

8비트 중 하위 4비트를 소수부로 하는 고정소수점(부호 없음)에서, 비트열 0011 1000이 나타내는 값은 얼마입니까?

  1. A56
  2. B3.8
  3. C3.5
정답과 해설 보기

정답: C. 3.5

상위 4비트의 0011이 정수부로 3이고, 하위 4비트의 1000이 소수부입니다. 첫 번째 비트의 가중치가 2⁻¹ = 0.5이므로 0.5를 나타냅니다. 합하면 3 + 0.5 = 3.5입니다. 달리 말하면, 비트열을 정수로 읽은 56을 소수부 4비트만큼의 2⁴ = 16으로 나눈 값입니다(56 ÷ 16 = 3.5). 56은 소수점을 무시하고 정수로 읽은 값이고, 3.8은 2진수 1000을 10진수의 「.8」로 잘못 읽은 값입니다.

컴퓨터 산술의 다른 문제

  1. IEEE 754 부동소수점수를 구성하는 3가지 부분의 조합으로 올바른 것은 무엇입니까?
  2. IEEE 754 단정밀도(32비트) 부동소수점수에서 부호·지수부·가수에 할당되는 비트 수의 조합은 무엇입니까?
  3. IEEE 754 배정밀도(64비트) 부동소수점수에서 지수부와 가수의 비트 수 조합으로 올바른 것은 무엇입니까?
  4. IEEE 754 단정밀도에서 지수부에 기록된 값이 130일 때, 실제 지수(2의 몇 제곱인지)는 얼마입니까?
  5. IEEE 754 정규화수에서 가수의 맨 앞 1을 기록하지 않는 것(숨겨진 비트)의 효과로 올바른 것은 무엇입니까?

이 분야의 비교

  • 고정소수점과 부동소수점의 차이점 정리고정소수점과 부동소수점을 표로 비교합니다. 표현 방식, 표현 범위와 정밀도, 연산기의 규모와 전력, 오버플로 처리, 프로그래밍의 수고, 사용처를 다룹니다.
  • FP32, FP16, BF16, INT8의 차이점 정리FP32, FP16, BF16, INT8을 표로 비교합니다. 비트 구성(부호·지수·가수), 표현 범위, 정밀도, FP32에서의 변환, 메모리, 연산기 효율, 학습과 추론 용도를 안내합니다.
