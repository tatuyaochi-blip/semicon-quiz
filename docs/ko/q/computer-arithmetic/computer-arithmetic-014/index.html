컴퓨터 산술

비정규화수를 많이 포함하는 계산에서 일부 프로세서는 처리가 크게 느려질 수 있습니다. 그래서 성능을 우선하는 상황에서 사용되는 설정은 무엇입니까?

  1. A비정규화수가 되는 결과나 입력을 0으로 간주하는 설정(플러시 투 제로)
  2. B모든 계산을 배정밀도에서 단정밀도로 자동 변환하는 설정
  3. C비정규화수를 발견하면 프로그램을 중지시키는 설정
정답과 해설 보기

정답: A. 비정규화수가 되는 결과나 입력을 0으로 간주하는 설정(플러시 투 제로)

비정규화수는 맨 앞의 1을 가정하지 않는 특별한 형태이므로, 일부 프로세서에서는 고속 회로로 처리하지 못하고 마이크로코드 등으로 시간을 들여 처리하여 평소보다 수십 배 느려지기도 합니다. 음성 처리나 AI처럼 0에 매우 가까운 값을 정확히 다룰 필요가 없는 상황에서는, 비정규화수를 0으로 취급하는 플러시 투 제로 설정으로 속도를 유지합니다. 그 대신 0 근처의 정밀도와 점진적 언더플로의 성질은 잃게 됩니다. 정밀도를 일괄적으로 바꾸거나 중지시키지는 않습니다.

  2. x가 NaN일 때, 많은 프로그래밍 언어에서 x == x를 평가한 결과는 무엇입니까?
  3. IEEE 754 단정밀도에서 지수부가 모두 1(255)인 비트열이 나타내는 것의 설명으로 올바른 것은 무엇입니까?
  4. IEEE 754 부동소수점수에서 +0과 −0에 대한 설명으로 올바른 것은 무엇입니까?
  5. IEEE 754에서 기본 반올림 방법으로 정해진 것은 무엇입니까?
