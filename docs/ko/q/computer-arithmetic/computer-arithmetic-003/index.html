IEEE 754 단정밀도(32비트) 부동소수점수에서 부호·지수부·가수에 할당되는 비트 수의 조합은 무엇입니까?

  1. A1·11·20
  2. B1·8·23
  3. C1·5·26
정답과 해설 보기

정답: B. 1·8·23

단정밀도(FP32)는 부호 1비트, 지수부 8비트, 가수 23비트로 합계 32비트입니다. 정규화된 수에서는 가수의 맨 앞 1을 생략하므로 정밀도는 24비트분이 되며, 10진수로 약 7자리입니다. 배정밀도(FP64)는 부호 1·지수부 11·가수 52비트로, 지수부가 넓고 정밀도도 높습니다. 1·11·20은 배정밀도의 지수부 폭과 혼동한 조합이고, 1·5·26은 반정밀도의 지수부 폭과 혼동한 것입니다.

컴퓨터 산술의 다른 문제

  1. IEEE 754 배정밀도(64비트) 부동소수점수에서 지수부와 가수의 비트 수 조합으로 올바른 것은 무엇입니까?
  2. IEEE 754 단정밀도에서 지수부에 기록된 값이 130일 때, 실제 지수(2의 몇 제곱인지)는 얼마입니까?
  3. IEEE 754 정규화수에서 가수의 맨 앞 1을 기록하지 않는 것(숨겨진 비트)의 효과로 올바른 것은 무엇입니까?
  4. 10진수 1.0을 IEEE 754 단정밀도로 나타낸 비트열을 16진수로 쓰면 무엇입니까?
  5. −6.25를 단정밀도로 변환할 때, 부호·지수부·가수를 나열한 비트열을 16진수로 나타내면 무엇입니까?

이 분야의 비교

  • 고정소수점과 부동소수점의 차이점 정리고정소수점과 부동소수점을 표로 비교합니다. 표현 방식, 표현 범위와 정밀도, 연산기의 규모와 전력, 오버플로 처리, 프로그래밍의 수고, 사용처를 다룹니다.
  • FP32, FP16, BF16, INT8의 차이점 정리FP32, FP16, BF16, INT8을 표로 비교합니다. 비트 구성(부호·지수·가수), 표현 범위, 정밀도, FP32에서의 변환, 메모리, 연산기 효율, 학습과 추론 용도를 안내합니다.
