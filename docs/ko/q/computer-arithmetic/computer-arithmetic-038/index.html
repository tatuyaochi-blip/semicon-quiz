컴퓨터 산술

고속 승산기에서 사용되는 월리스 트리의 특징으로 올바른 것은 무엇입니까?

  1. A캐리 세이브 가산기의 트리로 부분곱을 병렬로 줄이며, 단 수는 대수(로그) 정도
  2. B부분곱을 하나씩 순서대로 더하므로 회로는 가장 작지만 느리다
  3. C곱셈 결과를 표에서 찾기만 하므로 가산기를 전혀 사용하지 않는다
정답과 해설 보기

정답: A. 캐리 세이브 가산기의 트리로 부분곱을 병렬로 줄이며, 단 수는 대수(로그) 정도

n비트 곱셈에서는 n개의 부분곱이 생깁니다. 월리스 트리는 캐리 세이브 가산기로 3개를 2개로 합치는 처리를 각 단에서 병렬로 수행하여 부분곱의 수를 각 단에서 대략 3분의 2로 줄여 갑니다. 그래서 2개가 될 때까지의 단 수는 비트 수의 로그에 비례하는 정도로 끝나, 순서대로 더하는 방식보다 크게 빨라집니다. 마지막에 남은 2개의 수를 고속 가산기로 더하면 완성입니다. 순서대로 더하는 것은 작지만 느린 배열형 방식이며, 표를 찾는 방식은 큰 비트 수에서는 쓸 수 없습니다.
