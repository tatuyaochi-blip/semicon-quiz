부호 없는 8비트 수끼리를 곱했을 때 결과를 오버플로 없이 나타내는 데 필요한 비트 수는 무엇입니까?

  1. A8비트
  2. B9비트
  3. C16비트

정답: C. 16비트

8비트 부호 없는 수의 최댓값은 255이므로 최대 곱은 255 × 255 = 65025입니다. 이는 2¹⁶ = 65536보다 작고 2¹⁵ = 32768보다 크므로 16비트라면 반드시 나타낼 수 있고 15비트로는 부족합니다. 일반적으로 n비트와 m비트 수의 곱은 n + m비트로 나타낼 수 있습니다. 그래서 승산기의 출력은 입력의 2배 폭을 가지는 것이 보통입니다. 9비트는 덧셈 결과(합은 n + 1비트)에 필요한 폭입니다.
