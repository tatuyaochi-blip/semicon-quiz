컴퓨터 산술

−6.25를 단정밀도로 변환할 때, 부호·지수부·가수를 나열한 비트열을 16진수로 나타내면 무엇입니까?

  1. A0xC0C80000
  2. B0x40C80000
  3. C0xC0A80000
정답과 해설 보기

정답: A. 0xC0C80000

6.25를 2진수로 나타내면 110.01이고, 정규화하면 1.1001 × 2²입니다. 부호는 음수이므로 1, 지수부는 2 + 127 = 129 = 1000 0001, 가수는 소수부의 1001에 0을 이어 붙인 것입니다. 나열하면 1 10000001 1001000…0이고, 4비트씩 끊으면 1100 0000 1100 1000 0000 … 이 되어 0xC0C80000입니다. 0x40C80000은 부호 비트가 0으로 +6.25를 나타내며, 0xC0A80000은 가수가 0101로 −5.25를 나타냅니다.
