정답: C. 손실된 부분을 기록해 두었다가 다음에 보충하여 오차를 억제하기 위해

커진 합계에 작은 값을 더할 때마다 작은 값의 하위 자릿수가 정보 누락으로 사라지고, 이것이 쌓이면 큰 오차가 됩니다. 카한 합산에서는 더한 뒤에 「실제로 늘어난 양」과 「더하려던 값」의 차를 계산하여 손실된 부분을 보정용 변수에 기록하고, 다음 값에 더한 뒤 합산합니다. 계산 수고는 몇 배가 되지만 오차의 누적을 크게 억제할 수 있습니다. 횟수를 줄이는 방법도, 정수로 변환하는 방법도 아닙니다.

  4. FP16(부호 1·지수부 5비트(바이어스 15)·가수 10비트)으로 나타낼 수 있는 최대 유한값은 얼마입니까?
  5. FP8의 두 형식인 E4M3(지수부 4·가수 3비트)와 E5M2(지수부 5·가수 2비트)의 구분 사용으로 일반적인 것은 무엇입니까?

이 분야의 비교

  • 고정소수점과 부동소수점의 차이점 정리고정소수점과 부동소수점을 표로 비교합니다. 표현 방식, 표현 범위와 정밀도, 연산기의 규모와 전력, 오버플로 처리, 프로그래밍의 수고, 사용처를 다룹니다.
  • FP32, FP16, BF16, INT8의 차이점 정리FP32, FP16, BF16, INT8을 표로 비교합니다. 비트 구성(부호·지수·가수), 표현 범위, 정밀도, FP32에서의 변환, 메모리, 연산기 효율, 학습과 추론 용도를 안내합니다.
