정답: C. 손실된 부분을 기록해 두었다가 다음에 보충하여 오차를 억제하기 위해

커진 합계에 작은 값을 더할 때마다 작은 값의 하위 자릿수가 정보 누락으로 사라지고, 이것이 쌓이면 큰 오차가 됩니다. 카한 합산에서는 더한 뒤에 「실제로 늘어난 양」과 「더하려던 값」의 차를 계산하여 손실된 부분을 보정용 변수에 기록하고, 다음 값에 더한 뒤 합산합니다. 계산 수고는 몇 배가 되지만 오차의 누적을 크게 억제할 수 있습니다. 횟수를 줄이는 방법도, 정수로 변환하는 방법도 아닙니다.
