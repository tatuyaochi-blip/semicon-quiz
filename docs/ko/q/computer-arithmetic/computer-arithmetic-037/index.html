컴퓨터 산술

승산기에서 다수의 부분곱을 더하는 데 캐리 세이브 가산기가 사용되는 주된 이유는 무엇입니까?

  1. A캐리 세이브 가산기는 부분곱의 수를 처음부터 하나로 줄일 수 있기 때문
  2. B캐리 세이브 가산기는 곱셈을 덧셈 없이 수행할 수 있기 때문
  3. C올림을 전달하지 않고 3개를 2개로 합치며 지연이 일정하기 때문
정답과 해설 보기

정답: C. 올림을 전달하지 않고 3개를 2개로 합치며 지연이 일정하기 때문

일반 가산기로 부분곱을 하나씩 더해 가면 그때마다 올림이 하위에서 상위로 전달되기를 기다려야 합니다. 캐리 세이브 가산기는 전가산기를 자리별로 독립적으로 늘어놓은 것으로, 3개의 수를 「각 자리의 합」과 「각 자리의 올림」이라는 2개의 수로 합치기만 하므로 올림의 전달을 기다리지 않고 지연은 전가산기 1단분으로 일정합니다. 이를 겹쳐 부분곱을 2개까지 줄이고, 마지막에 한 번만 캐리 룩어헤드 가산기 등으로 더합니다. 부분곱을 단번에 하나로 만들 수는 없습니다.

컴퓨터 산술의 다른 문제

  2. 승산기에서 기수 4 부스 알고리즘(부스 부호화)을 사용하는 주된 효과는 무엇입니까?
  3. 부호 없는 8비트 수끼리를 곱했을 때 결과를 오버플로 없이 나타내는 데 필요한 비트 수는 무엇입니까?
  4. 정수 x를 10배 하는 계산을 곱셈 명령을 쓰지 않고 시프트와 덧셈으로 수행하는 식으로 올바른 것은 무엇입니까?
  5. 일반적인 정수 제산기(1비트씩 몫을 구하는 복원형·비복원형 등)가 승산기보다 느려지기 쉬운 이유로 올바른 것은 무엇입니까?
