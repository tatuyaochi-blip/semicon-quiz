컴퓨터 산술

IEEE 754에서 기본 반올림 방법으로 정해진 것은 무엇입니까?

  1. A가장 가까운 값으로 반올림하고, 정확히 중간이면 짝수 쪽으로 반올림한다
  2. B항상 0에 가까운 쪽으로 버린다
  3. C항상 큰 쪽으로 올린다
정답과 해설 보기

정답: A. 가장 가까운 값으로 반올림하고, 정확히 중간이면 짝수 쪽으로 반올림한다

IEEE 754의 기본 반올림은 표현 가능한 값 중 가장 가까운 것으로 반올림하고, 정확히 중간일 때는 최하위 비트가 0(짝수)이 되는 쪽을 선택하는 최근접 짝수 반올림입니다. 중간을 항상 올림하면 오차가 한 방향으로 치우쳐 계산을 거듭할수록 어긋남이 커지지만, 짝수 쪽으로 반올림하면 위아래로 반반 나뉘어 서로 상쇄됩니다. 0 방향이나 양의 방향으로의 반올림도 규격에 정해져 있지만, 구간 연산 등 특별한 목적으로 선택하여 사용하는 것이며 기본값은 아닙니다.

컴퓨터 산술의 다른 문제

  1. 최근접 짝수 반올림으로 정수로 반올림할 때, 2.5와 3.5는 각각 얼마가 됩니까?
  2. 거의 같은 두 부동소수점수를 뺄셈했을 때 유효한 자릿수가 크게 줄어드는 현상을 무엇이라 합니까?
  3. x가 매우 클 때 √(x + 1) − √x를 부동소수점으로 계산하면 자리 상쇄가 일어납니다. 결과를 정밀하게 구하기 위한 변형으로 올바른 것은 무엇입니까?
  4. 단정밀도 부동소수점수에서 1억(10⁸)에 1을 더해도 결과가 1억 그대로입니다. 이 현상의 설명으로 올바른 것은 무엇입니까?
  5. 대량의 부동소수점수를 합산할 때 사용되는 카한 합산(보정 합산)의 목적으로 올바른 것은 무엇입니까?
