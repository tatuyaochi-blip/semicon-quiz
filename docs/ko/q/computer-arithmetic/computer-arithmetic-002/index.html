컴퓨터 산술

IEEE 754 부동소수점수를 구성하는 3가지 부분의 조합으로 올바른 것은 무엇입니까?

  1. A부호, 지수부, 가수
  2. B정수부, 소수부, 올림수
  3. C상위 바이트, 하위 바이트, 패리티
정답과 해설 보기

정답: A. 부호, 지수부, 가수

부동소수점수는 값을 「(−1)^부호 × 1.가수 × 2^지수」의 형태로 나타내며, 양수인지 음수인지를 나타내는 부호 비트, 2의 몇 제곱인지를 나타내는 지수부, 유효숫자를 나타내는 가수의 3가지 부분으로 기록합니다. 지수로 소수점의 위치를 움직일 수 있으므로 매우 작은 수부터 큰 수까지 같은 비트 수로 나타낼 수 있습니다. 정수부와 소수부로 나누는 것은 고정소수점의 개념이며, 패리티는 오류 검출을 위한 비트입니다.

컴퓨터 산술의 다른 문제

  1. IEEE 754 단정밀도(32비트) 부동소수점수에서 부호·지수부·가수에 할당되는 비트 수의 조합은 무엇입니까?
  2. IEEE 754 배정밀도(64비트) 부동소수점수에서 지수부와 가수의 비트 수 조합으로 올바른 것은 무엇입니까?
  3. IEEE 754 단정밀도에서 지수부에 기록된 값이 130일 때, 실제 지수(2의 몇 제곱인지)는 얼마입니까?
  4. IEEE 754 정규화수에서 가수의 맨 앞 1을 기록하지 않는 것(숨겨진 비트)의 효과로 올바른 것은 무엇입니까?
  5. 10진수 1.0을 IEEE 754 단정밀도로 나타낸 비트열을 16진수로 쓰면 무엇입니까?
