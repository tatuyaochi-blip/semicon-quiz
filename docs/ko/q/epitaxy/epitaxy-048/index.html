정답: B. 버퍼층을 고저항으로 만들어 오프 시의 누설 전류와 단채널 효과를 억제하기 위해

GaN은 성장 중에 의도치 않게 유입되는 산소나 실리콘 등의 도너 때문에 n형이 되기 쉽고, 버퍼층으로 전류가 흐르면 게이트로 전류를 차단하기 어려워지며 고전압에서 누설도 늘어납니다. 탄소나 철을 첨가하여 깊은 준위에서 전자를 포획함으로써 버퍼층을 고저항으로 만듭니다. 다만 포획된 전하가 빠져나올 때까지 2DEG가 줄어 전류가 일시적으로 감소하는 전류 콜랩스의 원인이 되기도 하므로, 첨가량과 위치의 조정이 중요합니다.
