이미지 센서와 광소자

광통신에서 단일 파장으로 안정적으로 발진시키기 위해 회절 격자를 내장한 반도체 레이저는 무엇입니까?

  1. ALED
  2. BDFB 레이저(분포 귀환형 레이저)
  3. C유기 EL
정답과 해설 보기

정답: B. DFB 레이저(분포 귀환형 레이저)

DFB 레이저는 발광층 근처에 주기 수백 nm의 회절 격자를 만들어 넣어, 격자의 주기로 정해지는 특정 파장의 빛만 강하게 귀환시켜 단일 파장으로 발진시킵니다. 단면의 반사로 공진하는 일반 레이저(패브리-페로형)는 여러 파장으로 발진하지만, DFB는 스펙트럼이 좁고 온도나 전류에 의해 파장이 튀기 어려워 장거리 광섬유 통신이나 파장을 다중화하는 WDM의 광원으로 사용됩니다.

이미지 센서와 광소자의 다른 문제

  1. '1,200만 화소' 이미지 센서에 대한 설명으로 올바른 것은 무엇입니까?
  2. 컬러 이미지를 촬영하는 이미지 센서에서 화소 위에 컬러 필터를 두어야 하는 이유로 올바른 것은 무엇입니까?
  3. 현재 스마트폰 카메라에 주로 사용되는 이미지 센서는 무엇입니까?
  4. 역바이어스를 건 포토다이오드에 닿는 빛을 강하게 하면, 흐르는 전류(광전류)는 어떻게 됩니까?
  5. 어두운 곳에서 촬영한 이미지가 거칠게(노이즈가 눈에 띄게) 보이는 주된 이유는 무엇입니까?

이 분야의 비교

  • CMOS와 CCD 이미지 센서의 차이점CMOS와 CCD 이미지 센서를 표로 비교합니다. 판독 방식, 전력, 속도, 노이즈, 셔터 방식, 집적도, 비용, 대표 용도를 다룹니다.
  • 전면 조사형 vs 후면 조사형 vs 적층형 이미지 센서: 구조·감도·속도 비교전면 조사형(FSI), 후면 조사형(BSI), 적층형 CMOS 이미지 센서를 표로 비교합니다: 빛이 들어오는 면, 구조, 개구율과 감도, 배선과 주변 회로, 칩 면적, 속도, 제조 난이도, 과제,…
  • 롤링 셔터 vs 글로벌 셔터: 노광·왜곡·노이즈·용도 비교롤링 셔터와 글로벌 셔터를 표로 비교합니다: 노광 타이밍, 읽기, 움직이는 피사체의 왜곡, 깜빡이는 빛, 화소 회로, 화소 크기와 감도, 노이즈, 비용, 용도. 각각을 언제 쓰는지도 설명합니다.
