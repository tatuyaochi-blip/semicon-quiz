이미지 센서와 광소자

밝은 부분과 어두운 부분이 섞인 장면을 촬영하기 위한 이미지 센서의 HDR(하이 다이내믹 레인지)화 기법으로 올바른 것은?

  1. A화소의 수를 줄인다
  2. B컬러 필터를 제거한다
  3. C노광 시간이나 감도가 다른 신호를 조합하여 합성한다
정답과 해설 보기

정답: C. 노광 시간이나 감도가 다른 신호를 조합하여 합성한다

HDR에서는 짧은 노광으로 밝은 부분을, 긴 노광이나 높은 감도로 어두운 부분을 포착하여 합성함으로써 화이트 아웃이나 블랙 아웃이 적은 이미지를 만듭니다. 여러 번 촬영하면 움직이는 피사체가 어긋나므로, 1회 촬영으로 크고 작은 화소, 변환 게인의 전환, 화소 내 전하 넘침의 축적을 이용하는 방식도 있습니다. 터널의 출구처럼 명암 차가 큰 장면을 찍는 차량용 카메라에서는 120 dB 이상이 요구됩니다.

이미지 센서와 광소자의 다른 문제

  1. 이미지 센서의 양자 효율의 정의로 올바른 것은?
  2. 실리콘 이미지 센서에서 근적외광의 감도를 높이기 어려운 이유로 올바른 것은?
  3. CMOS 이미지 센서의 읽기에서 사용되는 상관 이중 샘플링(CDS)의 목적으로 올바른 것은?
  4. 유기 EL(OLED) 디스플레이의 특징으로 올바른 것은?
  5. CMOS 이미지 센서의 대표적인 4 트랜지스터 화소에서 포토다이오드의 전하를 플로팅 디퓨전(부유 확산층)으로 옮기는 역할을 하는 트랜지스터는?
