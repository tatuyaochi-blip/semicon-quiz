이미지 센서와 광소자

미세한 화소 사이에 깊은 홈을 파고 절연물 등을 매립하는 구조(DTI)의 주된 목적은?

  1. A이웃 화소로의 빛이나 전하의 누설(크로스토크)을 방지한다
  2. B화소를 크게 한다
  3. C컬러 필터를 불필요하게 한다
정답과 해설 보기

정답: A. 이웃 화소로의 빛이나 전하의 누설(크로스토크)을 방지한다

화소가 작아지면 비스듬히 들어온 빛이나 깊은 위치에서 발생한 전하가 이웃 화소로 들어가 색이 섞이거나 해상도가 떨어집니다. DTI(Deep Trench Isolation)는 화소 사이에 깊이 수 µm의 홈을 파고 산화막이나 금속 등을 매립하여 빛과 전하를 차단함으로써 이 크로스토크를 억제합니다. 후면에서 파는 방식이 많으며, 홈의 벽에서 발생하는 암전류를 억제하는 처리도 중요합니다.

이미지 센서와 광소자의 다른 문제

  2. CCD 이미지 센서의 신호 읽기 방식으로 올바른 것은 무엇입니까?
  3. 스마트폰용 고화소 이미지 센서의 화소 크기로 가장 가까운 것은 무엇입니까?
  4. 이미지 센서의 일부 화소에서 렌즈의 좌우로 들어오는 빛을 나누어 받아 구현하는 오토포커스 방식은 무엇입니까?
  5. 이미지 센서의 한 화소에 저장할 수 있는 전자의 최대 수를 무엇이라고 합니까?
