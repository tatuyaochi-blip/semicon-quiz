정답: C. 이벤트 기반 비전 센서

이벤트 기반 비전 센서는 정해진 프레임마다 전 화소를 읽는 것이 아니라, 밝기가 일정 이상 변화한 화소만 그 위치, 시각, 증감 방향을 이벤트로 비동기 출력합니다. 움직임이 없는 배경은 데이터가 되지 않으므로 데이터 양이 적고, 마이크로초 수준의 시간 분해능과 120 dB 이상의 다이내믹 레인지를 얻을 수 있습니다. 고속 물체 추적, 공장의 진동 감시, 로봇의 시각 등에 사용됩니다.

이미지 센서와 광소자의 다른 문제

  1. CMOS 이미지 센서에서 포토다이오드로부터 플로팅 디퓨전으로의 전하 전송이 불완전할 때 일어나는 문제는 무엇입니까?
  2. 이미지 센서의 변환 이득 등을, 밝기를 바꾸어 촬영한 이미지 신호의 평균값과 편차(분산)의 관계로부터 구하는 평가 방법은 무엇입니까?
  3. 실리콘으로는 검출할 수 없는 단파 적외(SWIR, 약 1~2 µm)를 저렴한 이미지 센서로 검출하기 위해 연구, 실용화가 진행되고 있는 수광 재료의 예는 무엇입니까?
  4. 의료용 X선 촬영에 사용되는 간접 변환형 플랫 패널 검출기에서 X선을 검출하는 방법으로 올바른 것은 무엇입니까?
  5. CMOS 이미지 센서의 각 화소에서 빛을 전하로 변환하는 소자는?
