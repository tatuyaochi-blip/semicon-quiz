이미지 센서와 광소자

매우 밝은 빛을 받은 화소에서 전하가 넘쳐 주변 화소까지 하얗게 번져 찍히는 현상을 무엇이라고 합니까?

  1. A제로 크로스토크
  2. B블루밍
  3. C롤링 셔터 왜곡
정답과 해설 보기

정답: B. 블루밍

화소의 포화 전하량을 넘는 강한 빛이 닿으면 넘친 전하가 이웃 화소로 흘러 들어가 밝은 부분이 주변으로 번져 찍힙니다. 이것이 블루밍이며, CCD에서는 전송 방향으로 세로 줄무늬(스미어)가 나타나기도 합니다. CMOS에서는 넘친 전하를 전원으로 빼내는 오버플로 드레인이나 리셋 트랜지스터를 통한 배출 경로로 억제합니다. HDR에서는 반대로 넘친 전하를 별도의 용량에 저장하여 이용하는 방식도 있습니다.

이미지 센서와 광소자의 다른 문제

  1. 미세한 줄무늬 피사체를 촬영했을 때 화소 배열과의 간섭으로 본래 없는 무늬(모아레)가 나타나는 것을 억제하기 위해 센서 앞에 놓이기도 하는 부품은 무엇입니까?
  2. 사람이나 물체의 온도를 이미지로 만드는 서모그래피에서 주로 검출에 사용되는 적외선의 파장대는 무엇입니까?
  3. 이미지 센서 화소의 '개구율(필 팩터)'의 의미로 올바른 것은 무엇입니까?
  4. 베이어 배열 등의 컬러 필터를 사용한 센서의 출력으로부터, 각 화소의 빨강, 초록, 파랑 모든 값을 주변 화소로 보완하여 구하는 처리를 무엇이라고 합니까?
  5. 방송용 카메라 등에서 사용되는 '3판식' 촬상 방식에 대한 설명으로 올바른 것은 무엇입니까?
