이미지 센서와 광소자

CMOS 이미지 센서의 '변환 이득(conversion gain)'에 대한 설명으로 올바른 것은 무엇입니까?

  1. A화소에 저장한 전자 1개당 출력 전압(예를 들어 µV/e⁻)
  2. B렌즈의 확대율
  3. C화소 수를 2배로 하는 배율
정답과 해설 보기

정답: A. 화소에 저장한 전자 1개당 출력 전압(예를 들어 µV/e⁻)

변환 이득은 플로팅 디퓨전(FD)으로 전송된 전자 1개가 몇 µV의 전압이 되는가를 나타내며, q/C_FD로 결정됩니다. FD의 용량이 1 fF이면 약 160 µV/e⁻입니다. 크면 후단 회로의 노이즈 영향이 상대적으로 작아져 어두운 장면에 강한 반면, 다룰 수 있는 전자 수는 줄어듭니다. 그래서 FD에 용량을 추가할지 여부를 전환하여 어두운 장면과 밝은 장면에서 변환 이득을 구분해 쓰는 듀얼 게인 방식이 사용됩니다.

이미지 센서와 광소자의 다른 문제

  1. 많은 CMOS 이미지 센서에서 채택하고 있는, 화소의 열마다 AD 변환기를 두어 병렬로 변환하는 방식의 주된 장점은 무엇입니까?
  2. 이미지 센서의 '화소 비닝(pixel binning)'에 대한 설명으로 올바른 것은 무엇입니까?
  3. 매우 밝은 빛을 받은 화소에서 전하가 넘쳐 주변 화소까지 하얗게 번져 찍히는 현상을 무엇이라고 합니까?
  4. 미세한 줄무늬 피사체를 촬영했을 때 화소 배열과의 간섭으로 본래 없는 무늬(모아레)가 나타나는 것을 억제하기 위해 센서 앞에 놓이기도 하는 부품은 무엇입니까?
  5. 사람이나 물체의 온도를 이미지로 만드는 서모그래피에서 주로 검출에 사용되는 적외선의 파장대는 무엇입니까?
