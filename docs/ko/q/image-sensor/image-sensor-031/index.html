이미지 센서와 광소자

'1,200만 화소' 이미지 센서에 대한 설명으로 올바른 것은 무엇입니까?

  1. A빛을 받는 화소(수광 소자)가 약 1,200만 개 배열되어 있다
  2. B1초 동안 1,200만 장의 이미지를 촬영할 수 있다
  3. C1,200만 가지 색을 구분할 수 있다
정답과 해설 보기

정답: A. 빛을 받는 화소(수광 소자)가 약 1,200만 개 배열되어 있다

화소 수는 이미지 센서에 배열된 수광 소자(화소)의 수이며, 1,200만 화소라면 예를 들어 가로 4,000 × 세로 3,000입니다. 다만 베이어 배열에서는 각 화소가 한 가지 색만 측정하므로 색 해상도는 그보다 낮아집니다. 화질은 화소 수뿐만 아니라 센서의 크기, 화소 크기, 렌즈로 결정됩니다. 촬영 속도는 프레임 레이트, 색의 수는 계조(비트 수)로 나타내는 별개의 성능입니다.

이미지 센서와 광소자의 다른 문제

  1. 컬러 이미지를 촬영하는 이미지 센서에서 화소 위에 컬러 필터를 두어야 하는 이유로 올바른 것은 무엇입니까?
  2. 현재 스마트폰 카메라에 주로 사용되는 이미지 센서는 무엇입니까?
  3. 역바이어스를 건 포토다이오드에 닿는 빛을 강하게 하면, 흐르는 전류(광전류)는 어떻게 됩니까?
  4. 어두운 곳에서 촬영한 이미지가 거칠게(노이즈가 눈에 띄게) 보이는 주된 이유는 무엇입니까?
  5. CMOS 이미지 센서의 '변환 이득(conversion gain)'에 대한 설명으로 올바른 것은 무엇입니까?
