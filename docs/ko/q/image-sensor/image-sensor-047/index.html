이미지 센서와 광소자

CMOS 이미지 센서에서 포토다이오드로부터 플로팅 디퓨전으로의 전하 전송이 불완전할 때 일어나는 문제는 무엇입니까?

  1. A이전 프레임의 전하가 남아 다음 이미지에 영향을 주는 잔상(래그)이 생긴다
  2. B컬러 필터의 색이 변한다
  3. C화소 수가 줄어든다
정답과 해설 보기

정답: A. 이전 프레임의 전하가 남아 다음 이미지에 영향을 주는 잔상(래그)이 생긴다

4트랜지스터 화소에서는 노출로 저장한 전하를 전송 게이트로 플로팅 디퓨전에 모두 옮기는 것이 전제입니다. 포토다이오드와 전송 게이트 사이에 전위 장벽이나 웅덩이가 있으면 전하가 남아 다음 프레임의 신호에 더해져 잔상(이미지 래그)이 됩니다. 남는 양은 매번 요동하므로 노이즈의 원인이 되기도 합니다. 불순물 분포 설계로 전하가 전송 게이트로 자연스럽게 흐르는 전위 구배를 만들어 방지합니다.

이미지 센서와 광소자의 다른 문제

  1. 이미지 센서의 변환 이득 등을, 밝기를 바꾸어 촬영한 이미지 신호의 평균값과 편차(분산)의 관계로부터 구하는 평가 방법은 무엇입니까?
  2. 실리콘으로는 검출할 수 없는 단파 적외(SWIR, 약 1~2 µm)를 저렴한 이미지 센서로 검출하기 위해 연구, 실용화가 진행되고 있는 수광 재료의 예는 무엇입니까?
  3. 의료용 X선 촬영에 사용되는 간접 변환형 플랫 패널 검출기에서 X선을 검출하는 방법으로 올바른 것은 무엇입니까?
  4. CMOS 이미지 센서의 각 화소에서 빛을 전하로 변환하는 소자는?
  5. 후면 조사형(BSI) CMOS 이미지 센서의 주된 이점으로 올바른 것은?
