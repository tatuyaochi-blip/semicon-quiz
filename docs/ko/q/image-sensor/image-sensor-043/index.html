이미지 센서와 광소자

베이어 배열 등의 컬러 필터를 사용한 센서의 출력으로부터, 각 화소의 빨강, 초록, 파랑 모든 값을 주변 화소로 보완하여 구하는 처리를 무엇이라고 합니까?

  1. A상관 이중 샘플링
  2. B디모자이크(색 보간)
  3. C화이트 밸런스
정답과 해설 보기

정답: B. 디모자이크(색 보간)

베이어 배열의 각 화소는 한 가지 색의 정보만 가지고 있으므로, 부족한 두 가지 색의 값을 주변 화소로부터 추정하여 보완해야 하며, 이것이 디모자이크(색 보간)입니다. 단순한 평균으로는 윤곽에 위색이나 톱니 모양이 생기므로, 에지 방향을 조사하여 보간하는 방법이나 AI를 사용하는 방법이 이용됩니다. 카메라 이미지 처리(ISP)의 중요한 공정이며, RAW 현상 소프트웨어에서 처리 방법을 선택할 수 있는 경우도 있습니다.

이미지 센서와 광소자의 다른 문제

  1. 방송용 카메라 등에서 사용되는 '3판식' 촬상 방식에 대한 설명으로 올바른 것은 무엇입니까?
  2. 항복 전압을 넘는 역바이어스로 동작시켜, 광자 1개라도 애벌란시 증배에 의한 펄스를 발생시키는 수광 소자는 무엇입니까?
  3. 화소마다 밝기의 변화만 검출하고, 변화가 있었던 화소의 정보만 비동기로 출력하는 이미지 센서는 무엇입니까?
  4. CMOS 이미지 센서에서 포토다이오드로부터 플로팅 디퓨전으로의 전하 전송이 불완전할 때 일어나는 문제는 무엇입니까?
  5. 이미지 센서의 변환 이득 등을, 밝기를 바꾸어 촬영한 이미지 신호의 평균값과 편차(분산)의 관계로부터 구하는 평가 방법은 무엇입니까?
