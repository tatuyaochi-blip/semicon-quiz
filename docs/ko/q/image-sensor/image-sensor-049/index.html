정답: A. PbS 등의 콜로이드 양자점 막

PbS 등의 콜로이드 양자점은 직경 수 nm 입자의 크기로 밴드갭을 조정할 수 있어(작을수록 커짐) 1~2 µm의 SWIR을 흡수하도록 만들 수 있습니다. 용액에서 도포하여 읽기 회로 칩 위에 직접 막을 만들 수 있으므로, InGaAs처럼 별도의 칩을 접합할 필요가 없어 저렴하고 고화소화하기 쉬운 장점이 있습니다. 식품이나 의약품의 선별, 안개를 투과해 보는 카메라 등에 응용이 기대됩니다.

이미지 센서와 광소자의 다른 문제

  1. 의료용 X선 촬영에 사용되는 간접 변환형 플랫 패널 검출기에서 X선을 검출하는 방법으로 올바른 것은 무엇입니까?
  2. CMOS 이미지 센서의 각 화소에서 빛을 전하로 변환하는 소자는?
  3. 후면 조사형(BSI) CMOS 이미지 센서의 주된 이점으로 올바른 것은?
  4. LED의 발광색(발광 파장)을 결정하는 주된 요인은?
  5. CCD 이미지 센서와 비교했을 때 CMOS 이미지 센서의 일반적인 특징으로 올바른 것은?

이 분야의 비교

  • CMOS와 CCD 이미지 센서의 차이점CMOS와 CCD 이미지 센서를 표로 비교합니다. 판독 방식, 전력, 속도, 노이즈, 셔터 방식, 집적도, 비용, 대표 용도를 다룹니다.
  • 전면 조사형 vs 후면 조사형 vs 적층형 이미지 센서: 구조·감도·속도 비교전면 조사형(FSI), 후면 조사형(BSI), 적층형 CMOS 이미지 센서를 표로 비교합니다: 빛이 들어오는 면, 구조, 개구율과 감도, 배선과 주변 회로, 칩 면적, 속도, 제조 난이도, 과제,…
  • 롤링 셔터 vs 글로벌 셔터: 노광·왜곡·노이즈·용도 비교롤링 셔터와 글로벌 셔터를 표로 비교합니다: 노광 타이밍, 읽기, 움직이는 피사체의 왜곡, 깜빡이는 빛, 화소 회로, 화소 크기와 감도, 노이즈, 비용, 용도. 각각을 언제 쓰는지도 설명합니다.
