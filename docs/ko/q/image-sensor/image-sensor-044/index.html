이미지 센서와 광소자

방송용 카메라 등에서 사용되는 '3판식' 촬상 방식에 대한 설명으로 올바른 것은 무엇입니까?

  1. A세 개의 렌즈로 입체 영상을 촬영한다
  2. B세 번 노출하여 밝기를 합성한다
  3. C프리즘으로 빛을 빨강, 초록, 파랑으로 나누어 각각 별도의 이미지 센서로 받는다
정답과 해설 보기

정답: C. 프리즘으로 빛을 빨강, 초록, 파랑으로 나누어 각각 별도의 이미지 센서로 받는다

3판식에서는 다이크로익 프리즘으로 빛을 빨강, 초록, 파랑으로 나누고, 3장의 이미지 센서로 각각의 색을 받습니다. 각 화소가 모든 색의 정보를 가지므로 색 보간이 필요 없고, 빛을 필터로 버리지 않아 감도도 높으며, 색 재현과 해상감이 뛰어납니다. 그 대신 프리즘을 포함한 광학계가 크고 비싸지며, 3장의 위치 정렬도 필요합니다. 방송용 카메라나 일부 업무용 비디오 카메라에서 사용됩니다.

이미지 센서와 광소자의 다른 문제

  1. 항복 전압을 넘는 역바이어스로 동작시켜, 광자 1개라도 애벌란시 증배에 의한 펄스를 발생시키는 수광 소자는 무엇입니까?
  2. 화소마다 밝기의 변화만 검출하고, 변화가 있었던 화소의 정보만 비동기로 출력하는 이미지 센서는 무엇입니까?
  3. CMOS 이미지 센서에서 포토다이오드로부터 플로팅 디퓨전으로의 전하 전송이 불완전할 때 일어나는 문제는 무엇입니까?
  4. 이미지 센서의 변환 이득 등을, 밝기를 바꾸어 촬영한 이미지 신호의 평균값과 편차(분산)의 관계로부터 구하는 평가 방법은 무엇입니까?
  5. 실리콘으로는 검출할 수 없는 단파 적외(SWIR, 약 1~2 µm)를 저렴한 이미지 센서로 검출하기 위해 연구, 실용화가 진행되고 있는 수광 재료의 예는 무엇입니까?

이 분야의 비교

  • CMOS와 CCD 이미지 센서의 차이점CMOS와 CCD 이미지 센서를 표로 비교합니다. 판독 방식, 전력, 속도, 노이즈, 셔터 방식, 집적도, 비용, 대표 용도를 다룹니다.
  • 전면 조사형 vs 후면 조사형 vs 적층형 이미지 센서: 구조·감도·속도 비교전면 조사형(FSI), 후면 조사형(BSI), 적층형 CMOS 이미지 센서를 표로 비교합니다: 빛이 들어오는 면, 구조, 개구율과 감도, 배선과 주변 회로, 칩 면적, 속도, 제조 난이도, 과제,…
  • 롤링 셔터 vs 글로벌 셔터: 노광·왜곡·노이즈·용도 비교롤링 셔터와 글로벌 셔터를 표로 비교합니다: 노광 타이밍, 읽기, 움직이는 피사체의 왜곡, 깜빡이는 빛, 화소 회로, 화소 크기와 감도, 노이즈, 비용, 용도. 각각을 언제 쓰는지도 설명합니다.
