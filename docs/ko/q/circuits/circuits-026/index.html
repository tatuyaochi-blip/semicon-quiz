전기 회로·전자기학의 기초

L = 1 mH, C = 10 nF인 직렬 공진 회로의 공진 주파수에 가장 가까운 것은?

  1. A약 50 kHz
  2. B약 316 kHz
  3. C약 5 kHz
정답과 해설 보기

정답: A. 약 50 kHz

공진 주파수는 f0 = 1/(2π√(LC))입니다. LC = 1×10⁻³ × 10×10⁻⁹ = 1×10⁻¹¹이므로 √(LC) ≈ 3.16×10⁻⁶ s, f0 ≈ 1/(2π × 3.16×10⁻⁶) ≈ 50.3 kHz입니다. 이때 코일과 커패시터의 리액턴스는 둘 다 √(L/C) ≈ 316 Ω으로 같아집니다. 공진 주파수는 L과 C의 곱의 제곱근에 반비례하므로, C를 100배로 하면 1/10이 됩니다.
