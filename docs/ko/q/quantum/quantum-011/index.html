양자 컴퓨터의 하드웨어

양자 오류 정정에서 고전적인 오류 정정처럼 '같은 데이터를 3개 복사하여 다수결을 취하는' 방법을 그대로 쓸 수 없는 이유로 올바른 것은?

  1. A미지의 양자 상태는 정확히 복제할 수 없고(복제 불가능 정리), 값을 확인하려고 측정하면 중첩이 깨져 버리기 때문
  2. B큐비트는 0과 1의 두 값만 취하므로, 다수결을 취할 의미가 없기 때문
  3. C큐비트의 오류는 비트 반전뿐이므로, 복사하지 않아도 패리티를 하나 붙이는 것만으로 정정할 수 있기 때문
정답과 해설 보기

정답: A. 미지의 양자 상태는 정확히 복제할 수 없고(복제 불가능 정리), 값을 확인하려고 측정하면 중첩이 깨져 버리기 때문

복제 불가능 정리에 의해, 미지의 양자 상태 α|0⟩ + β|1⟩를 다른 큐비트에 그대로 옮겨 적는 조작은 존재하지 않습니다. 또한 데이터를 가진 큐비트를 직접 측정하면 중첩이 깨져 버립니다. 그래서 양자 오류 정정에서는 하나의 논리 큐비트의 정보를 여러 물리 큐비트의 얽힌 상태로 펼쳐서 갖게 하고, 보조 큐비트를 사용하여 이웃한 큐비트의 패리티 같은 오류의 단서(신드롬)만을 측정합니다. 큐비트의 오류에는 비트 반전 외에 위상 반전도 있어, 둘 다 검출해야 합니다.

양자 컴퓨터의 하드웨어의 다른 문제

  1. 큐비트의 에너지 완화 시간 T1에 대한 설명으로 올바른 것은?
  2. 큐비트의 위상 완화 시간 T2와 에너지 완화 시간 T1의 관계로 올바른 것은?
  3. 1회당 충실도가 99.5%(오류율 0.5%)인 2큐비트 게이트를 100회 연속으로 사용하는 회로에서, 오류가 각각 독립적으로 일어난다고 할 때, 도중에 한 번도 오류가 일어나지 않을 확률에 가장 가까운 것은?
  4. 양자 컴퓨터의 성능을 큐비트의 수만으로 비교할 수 없는 이유로 가장 적절한 것은?
  5. 초전도 큐비트(트랜스몬)가 큐비트로 동작하기 위해 빼놓을 수 없는 소자는?
