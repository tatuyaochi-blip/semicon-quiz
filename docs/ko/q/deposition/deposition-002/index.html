박막 증착(CVD와 PVD)

ALD(원자층 증착)의 특징으로 올바른 것은?

  1. A1회 공정으로 수 µm의 막을 고속으로 증착할 수 있다
  2. B전구체의 자기 제한적 표면 반응을 반복하여 원자층 수준으로 막 두께를 제어할 수 있다
  3. C진공이 필요 없는 인쇄 기술이다
정답과 해설 보기

정답: B. 전구체의 자기 제한적 표면 반응을 반복하여 원자층 수준으로 막 두께를 제어할 수 있다

ALD에서는 원료 가스(전구체)를 공급하여 표면에 1층만큼만 흡착시키고, 남은 가스를 퍼지로 제거한 뒤 반응 가스를 공급해 반응시키는 사이클을 반복합니다. 표면의 반응 가능한 자리가 모두 채워지면 반응이 멈추기(자기 제한적) 때문에 1사이클당 약 0.1 nm씩 막 두께를 정밀하게 제어할 수 있고, 종횡비가 수십인 깊은 트렌치 안에도 균일하게 성막할 수 있습니다. 대신 성막 속도는 느립니다.

  2. 성막에서 스텝 커버리지(단차 피복성)에 대한 설명으로 올바른 것은?
  3. Cu 배선의 트렌치를 매립하기 위해 주로 사용되는 성막 방법은?
  4. 감압 CVD(LPCVD)의 특징으로 올바른 것은?
  5. LPCVD로 폴리실리콘막을 성막할 때 일반적으로 사용되는 원료 가스는?

이 분야의 비교

  • CVD vs PVD: 박막 증착 방식 비교CVD와 PVD를 표로 비교합니다: 원리, 대표 재료, 단차 피복성, 온도, 순도, 환경, 위험 요소, 반도체 제조에서의 쓰임.
  • ALD vs CVD: 원자층 증착 비교ALD와 CVD를 표로 비교합니다: 작동 방식, 두께 제어, 컨포멀리티, 속도, 온도, 균일도, 첨단 칩에서의 대표 용도.
  • LPCVD와 PECVD의 차이: 온도·막질·단차 피복성·응력·용도 비교저압 CVD(LPCVD)와 플라즈마 CVD(PECVD)를 온도, 막질, 수소 함유량, 단차 피복성, 막 응력, 처리 방식과 스루풋, 용도 관점에서 표로 비교합니다.
