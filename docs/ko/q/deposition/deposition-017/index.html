박막 증착(CVD와 PVD)

실레인을 열분해하여 실리콘 막을 증착할 때, 성막 온도를 낮추면 만들어지는 막은 무엇인가?

  1. A단결정 실리콘
  2. B비정질 실리콘
  3. C이산화실리콘
정답과 해설 보기

정답: B. 비정질 실리콘

실레인의 열분해로 만든 실리콘 막은 대략 580 ℃보다 낮은 온도에서는 비정질이 되고, 그보다 높은 온도에서는 다결정(폴리실리콘)이 됩니다. 비정질로 성막한 뒤 600 ℃ 전후에서 장시간 열처리하면 핵이 적은 채로 결정이 성장하므로, 직접 성막한 막보다 결정립이 큰(이동도가 높은) 막을 얻을 수 있습니다. 액정 디스플레이의 박막 트랜지스터(TFT)에서는 레이저로 결정화하는 방법도 사용됩니다.

박막 증착(CVD와 PVD)의 다른 문제

  1. ALD로 성막되는 대표적인 재료의 예로 옳은 것은 무엇인가?
  2. 스퍼터된 원자를 이온화하여 웨이퍼에 건 바이어스로 수직으로 끌어당기는 스퍼터 방식의 주된 목적은 무엇인가?
  3. 성막이나 식각 장치에서 웨이퍼를 정전기력으로 스테이지에 고정하는 기구는 무엇인가?
  4. 열 CVD로 실리콘 질화막(Si3N4)을 성막할 때 사용되는 원료 가스의 조합으로 올바른 것은?
  5. 티타늄 타깃을 질소를 포함한 가스 속에서 스퍼터하여 질화티타늄(TiN)막을 형성하는 방법을 무엇이라고 합니까?

이 분야의 비교

  • CVD vs PVD: 박막 증착 방식 비교CVD와 PVD를 표로 비교합니다: 원리, 대표 재료, 단차 피복성, 온도, 순도, 환경, 위험 요소, 반도체 제조에서의 쓰임.
  • ALD vs CVD: 원자층 증착 비교ALD와 CVD를 표로 비교합니다: 작동 방식, 두께 제어, 컨포멀리티, 속도, 온도, 균일도, 첨단 칩에서의 대표 용도.
