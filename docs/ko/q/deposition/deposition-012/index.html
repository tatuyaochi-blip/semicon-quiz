박막 증착(CVD와 PVD)

텅스텐 CVD의 원료로 사용되는 가스는 무엇인가?

  1. ATEOS
  2. B실레인(SiH4)
  3. C육불화텅스텐(WF6)
정답과 해설 보기

정답: C. 육불화텅스텐(WF6)

텅스텐 CVD에서는 WF6를 수소로 환원(WF6 + 3H2 → W + 6HF)하여 텅스텐 막을 증착하며, 초기 핵 형성에는 실레인 등을 사용합니다. 스텝 커버리지가 좋아 직경 수십 nm의 가는 콘택트 홀도 매립할 수 있고, 융점이 높아 전류에 의한 열화에도 강하기 때문에 트랜지스터와 배선을 잇는 콘택트 플러그나 3D NAND의 워드라인 형성에 사용됩니다.

박막 증착(CVD와 PVD)의 다른 문제

  1. 고밀도 플라즈마 CVD(HDP-CVD)가 좁은 트렌치의 절연막 매립에 사용되어 온 이유로 옳은 것은 무엇인가?
  2. 실리콘 질화막(Si3N4)의 용도로 옳은 것은 무엇인가?
  3. 마그네트론 스퍼터링에서 타깃 뒷면에 자석을 두는 주된 목적은 무엇인가?
  4. CVD에서 스텝 커버리지(컨포멀성)가 좋아지는 조건으로 옳은 것은 무엇인가?
  5. 실레인을 열분해하여 실리콘 막을 증착할 때, 성막 온도를 낮추면 만들어지는 막은 무엇인가?

이 분야의 비교

  • CVD vs PVD: 박막 증착 방식 비교CVD와 PVD를 표로 비교합니다: 원리, 대표 재료, 단차 피복성, 온도, 순도, 환경, 위험 요소, 반도체 제조에서의 쓰임.
  • ALD vs CVD: 원자층 증착 비교ALD와 CVD를 표로 비교합니다: 작동 방식, 두께 제어, 컨포멀리티, 속도, 온도, 균일도, 첨단 칩에서의 대표 용도.
  • LPCVD와 PECVD의 차이: 온도·막질·단차 피복성·응력·용도 비교저압 CVD(LPCVD)와 플라즈마 CVD(PECVD)를 온도, 막질, 수소 함유량, 단차 피복성, 막 응력, 처리 방식과 스루풋, 용도 관점에서 표로 비교합니다.
