박막 증착(CVD와 PVD)

LSI 제조 공정의 기본적인 구성 방식으로 올바른 것은?

  1. A부품을 접착제로 붙여서 만든다
  2. B성막·리소그래피·식각 등의 공정을 수십 번 반복하며 층을 쌓아 간다
  3. C웨이퍼를 한 번만 가공하여 완성한다
정답과 해설 보기

정답: B. 성막·리소그래피·식각 등의 공정을 수십 번 반복하며 층을 쌓아 간다

LSI는 막을 형성하고(성막), 패턴을 전사하고(리소그래피), 불필요한 부분을 깎고(식각), 불순물을 주입하고, 평탄화하고, 세정하는 등의 공정을 반복하여 트랜지스터와 십여 층의 배선을 쌓아 만듭니다. 첨단 로직에서는 공정 수가 1000을 넘으며, 웨이퍼 투입부터 완성까지 3개월 안팎이 걸립니다. 이러한 반복의 각 단계에서 검사·계측도 이루어집니다.
