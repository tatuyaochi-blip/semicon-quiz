산화와 확산

정답: C. 플라즈마 질화

플라즈마 질화에서는 질소 플라즈마로 만든 활성 질소를 수백 ℃ 정도의 비교적 낮은 온도에서 산화막 표면 부근에 도입하여, 질소를 10~20% 정도 포함한 산질화막(SiON)으로 만듭니다. 질소를 표면 쪽에 집중시킬 수 있으므로 Si/SiO2 계면의 특성(이동도 등)을 해치지 않고 붕소의 침투를 억제하며 유전율을 높여 EOT를 얇게 할 수 있습니다. 열 질화(NO·N2O 어닐링)에서는 질소가 계면에 모입니다.

산화와 확산의 다른 문제

  1. 같은 희석 불산으로 식각했을 때, 열산화막과 CVD로 성막한 산화막의 식각 속도의 일반적인 관계로 올바른 것은?
  2. 열산화 시 산화로 생긴 과잉 격자간 실리콘이 실리콘 내로 주입되어 성장하는 결함은?
  3. 열산화의 온도를 올리면, 같은 시간에 얻어지는 산화막의 두께는 어떻게 됩니까?
  4. LOCOS(선택 산화)에서 질화막 마스크 가장자리 아래로 산화막이 새 부리 모양으로 파고드는 현상을 무엇이라고 합니까?
  5. 높은 압력의 산화 분위기에서 열산화를 하는 이점으로 올바른 것은?
