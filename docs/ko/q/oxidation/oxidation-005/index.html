산화와 확산

열산화에서 산화막이 충분히 두꺼워졌을 때, 산화막 두께와 산화 시간의 관계로 올바른 것은?

  1. A막 두께는 시간의 제곱근에 거의 비례한다(포물선 법칙)
  2. B막 두께는 시간의 제곱에 비례한다
  3. C막 두께는 시간과 관계없이 일정하다
정답과 해설 보기

정답: A. 막 두께는 시간의 제곱근에 거의 비례한다(포물선 법칙)

Deal-Grove 모델에서는 x² + Ax = B(t + τ)가 되며, 막이 얇을 때는 계면 반응이 율속이어서 막 두께가 시간에 거의 비례하고(선형 법칙, x ≈ (B/A)t), 두꺼워지면 산화제의 막 내 확산이 율속이 되어 시간의 제곱근에 비례합니다(포물선 법칙, x ≈ √(Bt)). 예를 들어 막 두께를 2배로 하려면 약 4배의 시간이 걸립니다. 두꺼운 산화막일수록 시간이 걸리므로 고온, 습식, 고압 조건으로 속도를 높입니다.
