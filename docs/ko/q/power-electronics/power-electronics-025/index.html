파워 일렉트로닉스 회로

직류 전압 E로부터 단상 교류를 만드는 인버터에서, 하프 브리지(스위치 2개)와 풀 브리지(스위치 4개)의 출력 전압을 비교한 설명으로 올바른 것은?

  1. A하프 브리지의 출력은 +E/2와 −E/2 사이에서 흔들리고, 풀 브리지는 +E와 −E 사이에서 흔들리므로 출력 전압의 크기를 2배로 할 수 있다
  2. B풀 브리지는 스위치 수가 2배가 되는 만큼 손실이 늘어날 뿐이며, 얻을 수 있는 출력 전압의 크기는 하프 브리지와 완전히 같다
  3. C하프 브리지는 한 방향의 직류 전압밖에 출력할 수 없으므로, 부하에 교류 전압을 가하려면 풀 브리지가 필요하다
정답과 해설 보기

정답: A. 하프 브리지의 출력은 +E/2와 −E/2 사이에서 흔들리고, 풀 브리지는 +E와 −E 사이에서 흔들리므로 출력 전압의 크기를 2배로 할 수 있다

하프 브리지에서는 직류 전원을 2개의 커패시터로 나눈 중점과 2개의 스위치의 접속점 사이에 부하를 연결하므로, 부하에는 +E/2 또는 −E/2가 걸립니다. 풀 브리지에서는 2개의 레그의 접속점 사이에 부하를 연결하므로, +E와 −E에 더해 양쪽을 같은 쪽에 연결한 0도 출력할 수 있습니다. 같은 직류 전압으로 2배의 출력 전압을 얻을 수 있고, 3개의 레벨을 사용하여 PWM의 고조파를 줄일 수도 있습니다. 3상 인버터는 3개의 레그(6개의 스위치)로 만듭니다.

파워 일렉트로닉스 회로의 다른 문제

  1. 직류 전압 600 V인 인버터의 레그를 정현파 PWM으로 동작시키고 변조율을 0.8로 했다. 직류 전원의 중점에 대한 레그 출력 전압의 기본파 진폭(최댓값)으로 올바른 것은?
  2. 직류 전압 400 V의 3상 인버터를 정현파 PWM으로 동작시키고 변조율을 1로 했다. 출력 선간 전압의 기본파 실효값에 가장 가까운 것은?
  3. 정현파 PWM 인버터에서 변조율을 1보다 크게 했을(과변조로 했을) 때 일어나는 일로 올바른 것은?
  4. 모터를 구동하는 PWM 인버터에서 반송파 주파수를 높였을 때의 영향으로 올바른 것은?
  5. 전압형 PWM 인버터에서 데드 타임이 출력 전압에 주는 영향으로 올바른 것은?
