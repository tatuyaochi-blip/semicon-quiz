테스트와 검사

논리 회로 테스트에서 칩이 정상인지 판정하는 기본적인 방법은?

  1. A칩을 현미경으로 바라보기만 한다
  2. B칩의 온도만 측정한다
  3. C입력에 테스트 패턴을 가하고, 출력을 정상 회로에서 얻어져야 할 기대값과 비교한다
정답과 해설 보기

정답: C. 입력에 테스트 패턴을 가하고, 출력을 정상 회로에서 얻어져야 할 기대값과 비교한다

논리 회로 테스트에서는 테스터가 테스트 패턴(입력 신호의 나열)을 칩에 가하고, 정해진 타이밍에 출력을 받아들여 정상 회로에서 얻어져야 할 기대값과 비교합니다. 한 곳이라도 일치하지 않으면 불량으로 판정합니다. 기대값은 설계 데이터의 시뮬레이션으로 구합니다. 외관이나 온도만으로는 내부 논리가 올바르게 동작하는지 알 수 없습니다.

  • A. 외관을 보는 것만으로는 내부의 전기적 불량을 알 수 없습니다.
  • B. 온도만으로는 기능의 양부를 판정할 수 없습니다.
  • C. 올바릅니다. 출력을 기대값과 비교하여 판정합니다.

테스트와 검사의 다른 문제

  1. 테스트에서 칩의 입력에 차례로 가하는 0과 1 신호의 나열과, 그에 대한 기대값의 쌍을 무엇이라고 부릅니까?
  2. 웨이퍼 위 칩 사이(스크라이브 라인) 등에 배치되어, 트랜지스터나 저항 등의 특성을 측정하여 공정을 평가하기 위한 전용 패턴을 무엇이라고 부릅니까?
  3. 전공정을 마친 웨이퍼에서 TEG의 문턱 전압이나 시트 저항 등을 측정하여, 공정이 규격대로 만들어졌는지 확인하는 검사를 무엇이라고 부릅니까?
  4. 테스터와 IC를 연결하는 테스트용 지그로, 스프링으로 신축하는 가는 핀을 사용하여 단자에 확실하게 접촉시키는 부품은?
  5. 테스터의 테스트 헤드에 장착하여 IC의 소켓과 주변 부품을 싣고, 품종별로 신호를 IC로 끌어 주는 인쇄 회로 기판을 무엇이라고 부릅니까?
