테스트와 검사

회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것을 무엇이라고 합니까?

  1. ADRC
  2. BATPG(자동 테스트 패턴 생성)
  3. CCTS
정답과 해설 보기

정답: B. ATPG(자동 테스트 패턴 생성)

ATPG는 고착 고장 등의 고장 모델에 기초하여, 각 고장을 출력까지 전달하여 검출할 수 있는 입력 패턴을 넷리스트로부터 자동으로 생성하는 기술입니다. 스캔 설계와 조합하면 수억 게이트의 회로에서도 높은 고장 검출률의 패턴을 효율적으로 만들 수 있습니다. DRC는 레이아웃의 설계 규칙 검사, CTS는 클록 트리 합성으로, 둘 다 설계 공정입니다.

테스트와 검사의 다른 문제

  1. CMOS 회로가 정지 상태일 때의 전원 전류를 측정하여 브리지 고장 등의 결함을 검출하는 테스트를 무엇이라고 합니까?
  2. IEEE 1149.1(JTAG)에서 규정된 바운더리 스캔의 주된 용도는 무엇입니까?
  3. 패키지 후의 최종 테스트에서 테스터와 조합하여 IC를 자동으로 공급하고 테스트 결과에 따라 분류하는 장치는 무엇입니까?
  4. 전원 전압이나 동작 주파수 등의 조건을 바꾸면서 합격 여부를 조사하고 그 결과를 2차원 도표로 정리한 것을 무엇이라고 합니까?
  5. 일반적인 반도체 제품의 테스트 흐름으로 올바른 것은 무엇입니까?
