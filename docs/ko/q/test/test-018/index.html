정답: A. 테스트 압축(스캔 압축)

대규모 LSI에서는 스캔 테스트의 패턴 양이 방대해져 테스터의 메모리와 테스트 시간이 문제가 됩니다. 테스트 압축에서는 적은 입력 데이터를 칩 안의 전개 회로가 다수의 짧은 스캔 체인으로 배분하고, 출력도 압축 회로로 모아서 비교합니다. 패턴의 대부분의 비트는 어느 쪽이든 상관없는 값이므로, 데이터 양과 테스트 시간을 수십 분의 1 이하로 줄일 수 있습니다.

테스트와 검사의 다른 문제

  1. 실제 동작 주파수에서 테스트를 수행하여 신호가 전달되는 속도가 너무 느린 불량을 검출하는 테스트를 무엇이라고 합니까?
  2. 테스트 결과에 기초하여 동작 속도나 소비 전력 등 성능별로 제품을 분류하는 것을 무엇이라고 합니까?
  3. 테스트에서 측정 오차나 경시 변화를 고려하여 제품 규격보다 약간 엄격한 판정값을 두는 것을 무엇이라고 합니까?
  4. 테스트 프로그램 개발에서 테스트 비용을 낮추기 위해 중시되는 것으로 올바른 것은 무엇입니까?
  5. 웨이퍼 테스트에서 불량으로 판정한 칩의 정보를 이후 조립 공정에서 사용하는 방법으로 현재 일반적인 것은 무엇입니까?
