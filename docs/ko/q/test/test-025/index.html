정답: C. 마치 테스트

마치 테스트는 주소를 오름차순이나 내림차순으로 따라가면서 각 셀에 정해진 순서로 쓰기와 읽기를 수행하는 메모리 테스트 알고리즘입니다. 대표적인 March C−는 셀 1개당 10회의 연산으로, 고착 고장에 더해 인접 셀끼리의 간섭(커플링 고장)이나 주소 디코더의 불량도 검출할 수 있습니다. 테스트 시간이 셀 수에 비례하므로 대용량 메모리에도 사용할 수 있습니다.
