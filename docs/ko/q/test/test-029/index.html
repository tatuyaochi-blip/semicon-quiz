정답: A. 시스템 레벨 테스트(SLT)

시스템 레벨 테스트에서는 칩을 실제 제품에 가까운 보드에 올리고, OS를 부팅하거나 애플리케이션을 구동하여 동작을 확인합니다. 여러 블록이 동시에 동작할 때의 전원 노이즈나, 구조적 테스트 패턴으로는 재현하기 어려운 조합에서 일어나는 불량을 검출할 수 있습니다. 테스트 시간이 길기 때문에 다수의 보드에서 병행하여 수행하며, 주로 고성능 프로세서에서 사용됩니다.
