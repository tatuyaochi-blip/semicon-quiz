테스트와 검사

웨이퍼 테스트에서 프로브 카드의 바늘을 접촉시키는 칩 위의 장소는?

  1. A트랜지스터 게이트의 위
  2. B칩의 전극 패드
  3. C웨이퍼 뒷면의 중앙만
정답과 해설 보기

정답: B. 칩의 전극 패드

웨이퍼 테스트에서는 프로브 카드의 다수 바늘을 각 칩의 주변 등에 늘어선 전극 패드에 접촉시키고, 테스터에서 전원이나 신호를 가해 응답을 측정합니다. 패드는 뒤 와이어 본딩이나 범프 접속에도 사용하는 전극으로, 수십 µm 각의 크기입니다. 바늘 자국이 접합에 방해가 되지 않도록 바늘 자국의 크기와 위치도 검사합니다. 트랜지스터는 배선층 아래에 있어 직접 건드릴 수 없습니다.

  • A. 트랜지스터 게이트는 배선층 아래에 있어 직접 바늘을 댈 수 없습니다.
  • B. 올바릅니다. 전극 패드에 바늘을 접촉시킵니다.
  • C. 웨이퍼 뒷면만으로는 회로의 각 단자에 접속할 수 없습니다.
