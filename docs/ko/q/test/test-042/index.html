테스트와 검사

논리 회로 테스트에서 스캔 등을 사용하여 회로의 구조상 고장(고착 고장 등)을 망라적으로 검출하는 테스트와, 실제 동작대로 기능을 확인하는 테스트의 명칭 조합으로 올바른 것은?

  1. ADC 테스트와 AC 테스트
  2. B웨이퍼 테스트와 번인
  3. C스트럭처럴 테스트와 펑셔널 테스트
정답과 해설 보기

정답: C. 스트럭처럴 테스트와 펑셔널 테스트

스트럭처럴 테스트는 회로의 구조에 대해 고장 모델을 생각하고 스캔 등을 사용하여 각 부분의 고장을 효율적으로 검출하는 테스트로, 고장 검출률을 수치로 관리할 수 있습니다. 펑셔널 테스트는 실제 사용 방식에 가까운 입력을 주어 사양대로 기능하는지를 확인하는 테스트입니다. 전자는 망라성, 후자는 실사용에 가까운 조건에서의 확인에 강하며, 둘을 조합하여 품질을 확보합니다.

  • A. DC 테스트와 AC 테스트는 직류 특성과 타이밍 등 교류 특성의 테스트입니다.
  • B. 웨이퍼 테스트와 번인은 테스트 시기나 종류에 의한 구분입니다.
  • C. 올바릅니다. 구조에 기반한 테스트와 기능에 기반한 테스트입니다.

테스트와 검사의 다른 문제

  1. 테스트 판정이 너무 엄격하거나 측정이 불안정하여, 본래 양품인 칩을 불량으로 판정해 버리는 것을 무엇이라고 부릅니까?
  2. 메모리 테스트에서 어느 주소의 어느 비트가 불량이었는지를 기록한 그림을 만드는 주된 목적은?
  3. 스캔 테스트에서 출력을 압축할 때, 시뮬레이션에서 값이 0인지 1인지 정해지지 않는 신호(불정값 X)를 제거하는 처리가 필요한 이유는?
  4. 고속 시리얼 통신 인터페이스 테스트에서, 칩의 송신 회로 출력을 수신 회로로 되돌려 연결하여 칩 자체로 통신을 확인하는 방법은?
  5. 웨이퍼 테스트 등의 도중 결과나 통계에 기반하여, 칩별·로트별로 테스트 항목이나 판정값을 동적으로 바꾸는 기법을 무엇이라고 부릅니까?
