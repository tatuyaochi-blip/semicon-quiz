테스트와 검사

반도체 DC 테스트(직류 특성 시험)에서 주로 확인하는 항목은 무엇입니까?

  1. A입출력 단자의 누설 전류와 전압 레벨, 소비 전류
  2. B회로의 논리 기능만
  3. C패키지의 외관
정답과 해설 보기

정답: A. 입출력 단자의 누설 전류와 전압 레벨, 소비 전류

DC 테스트에서는 입출력 단자의 누설 전류, 출력 전압의 H와 L 레벨, 입력의 문턱값, 대기 시와 동작 시의 소비 전류 등 직류적인 전기 특성이 규격을 만족하는지 측정합니다. 먼저 각 단자의 보호 다이오드에 전류를 흘려 침의 접촉이나 단선, 단락을 확인하는 콘택트 테스트를 하는 것이 일반적입니다. 논리 기능은 펑션 테스트, 외관은 외관 검사로 확인합니다.

테스트와 검사의 다른 문제

  1. BIST(내장 자체 테스트)에 대한 설명으로 올바른 것은 무엇입니까?
  2. 프로브 카드에 대한 설명으로 올바른 것은 무엇입니까?
  3. 로직 회로 테스트에서 사용되는 고착 고장(스턱앳 고장) 모델에 대한 설명으로 올바른 것은 무엇입니까?
  4. 테스트 패턴의 고장 검출률(폴트 커버리지)의 정의로 올바른 것은 무엇입니까?
  5. 여러 칩을 하나의 패키지에 실장할 때 중요해지는 KGD(Known Good Die)란 무엇입니까?

이 분야의 비교

  • 정적 번인 vs 동적 번인 vs 웨이퍼 레벨 번인: 스트레스·커버리지·비용 비교정적 번인, 동적 번인, 웨이퍼 레벨 번인을 표로 비교합니다: 스트레스를 가하는 방식, 수행 단계, 대표 조건, 스트레스가 걸리는 범위, 장비와 지그, 모니터링, 비용, 과제, 용도. 구분해서 쓰…
  • 스캔 테스트와 BIST의 차이점 정리스캔 테스트와 BIST(내장 자체 테스트)를 표로 비교합니다. 패턴 생성 방법, 테스터 의존도, 대상, 고장 검출률, 추가 회로, 테스트 시간을 안내합니다.
  • 웨이퍼 테스트와 파이널 테스트의 차이점 정리웨이퍼 테스트(프로브 테스트)와 파이널 테스트를 표로 비교합니다. 시기와 대상, 접촉 방식, 온도, 테스트 항목, 불량 검출 목적, KGD를 안내합니다.
