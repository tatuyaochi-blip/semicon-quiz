  2. B침에 기름을 바른다
  3. C침을 구부린다
정답과 해설 보기

정답: A. 연마 시트 등으로 침 끝을 클리닝한다

침 끝에 알루미늄 부스러기나 산화물이 부착되면 접촉 저항이 올라 올바르게 측정할 수 없고, 양품을 불량으로 오판정하는 원인이 됩니다. 그래서 일정 수의 칩을 측정할 때마다 연마 시트 등으로 침 끝을 문질러 클리닝하여 접촉을 안정시킵니다. 너무 문지르면 침이 마모되어 짧아지므로 클리닝 빈도도 관리합니다. 기름이나 구부림은 접촉 불량을 악화시킵니다.

  2. 로직 회로 테스트에서, 스캔 등을 사용하여 회로의 구조상 고장(고착 고장 등)을 망라적으로 검출하는 테스트와, 실제 동작대로 기능을 확인하는 테스트의 명칭 조합으로 올바른 것은 무엇입니까?
  3. 테스트 판정이 지나치게 엄격하거나 측정이 불안정하여, 본래 양품인 칩을 불량으로 판정하여 버리는 것을 무엇이라고 합니까?
