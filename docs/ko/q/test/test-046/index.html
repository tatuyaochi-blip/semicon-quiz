정답: C. 루프백 테스트

수십 Gb/s에 달하는 고속 SerDes 등을 테스터만으로 직접 측정하는 것은 어렵고 비용이 많이 듭니다. 루프백 테스트에서는 송신 회로에서 의사 난수 데이터를 내보내 수신 회로로 되돌리고, 칩 내 회로에서 비트 오류를 셉니다. 칩 내에서 되돌리는 방법과, 로드 보드 상의 배선으로 바깥을 거쳐 되돌리는 방법이 있으며, 범용 테스터로 고속 인터페이스를 효율적으로 테스트할 수 있습니다.

테스트와 검사의 다른 문제

  1. 웨이퍼 테스트 등의 도중 결과나 통계에 기초하여, 칩별, 로트별로 테스트 항목이나 판정값을 동적으로 바꾸는 기법을 무엇이라고 합니까?
  2. AD 컨버터 테스트에서, 천천히 변화하는 정현파 등을 입력하고 각 출력 코드가 나타나는 횟수(히스토그램)를 세는 주된 목적은 무엇입니까?
  3. 스캔 테스트에서 불량이 된 칩에 대해, 어느 출력의 어느 패턴에서 불일치가 나왔는지의 정보로부터 고장 났을 것 같은 위치의 후보를 논리적으로 좁혀 가는 처리를 무엇이라고 합니까?
  4. 표준 셀 내부 트랜지스터의 단락이나 개방 등의 결함을, 셀의 회로를 바탕으로 모델화하여 테스트 패턴을 생성하는 기법은 무엇입니까?
  5. 웨이퍼 테스트(프로브 테스트)에 대한 설명으로 올바른 것은 무엇입니까?
