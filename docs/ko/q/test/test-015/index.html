테스트와 검사

전원 전압이나 동작 주파수 등의 조건을 바꿔 가며 합격 여부를 조사하고, 그 결과를 2차원 그림으로 정리한 것을 무엇이라고 부릅니까?

  1. A파레토도
  2. B웨이퍼 맵
  3. C슈무 플롯
정답과 해설 보기

정답: C. 슈무 플롯

슈무 플롯은 예를 들어 가로축에 동작 주파수, 세로축에 전원 전압을 잡고, 각 조건에서 테스트에 합격했는지 불합격했는지를 칸으로 나타낸 그림입니다. LSI가 어느 범위의 조건에서 올바르게 동작하는지(동작 마진)를 한눈에 확인할 수 있고, 합격 경계의 모양에서 속도로 정해지는 불량인지 전압으로 정해지는 불량인지를 추정할 수 있습니다. 파레토도는 불량이 많은 순서의 막대그래프, 웨이퍼 맵은 칩 위치별 결과입니다.

테스트와 검사의 다른 문제

  1. 일반적인 반도체 제품 테스트의 흐름으로 올바른 것은?
  2. AC 테스트에서 주로 확인하는 항목은?
  3. 스캔 테스트의 데이터량과 테스트 시간을 줄이기 위해 칩 안에서 테스트 패턴을 전개하고 응답을 압축하는 기술을 무엇이라고 부릅니까?
  4. 실제 동작 주파수로 테스트를 하여, 신호가 전달되는 속도가 너무 느린 불량을 검출하는 테스트를 무엇이라고 부릅니까?
  5. 테스트 결과에 기반하여 동작 속도나 소비 전력 등 성능별로 제품을 분류하는 것을 무엇이라고 부릅니까?
