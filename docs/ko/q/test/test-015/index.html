  1. A파레토 차트
  2. B웨이퍼 맵
  3. C슈무 플롯
정답과 해설 보기

정답: C. 슈무 플롯

슈무 플롯은 예를 들어 가로축에 동작 주파수, 세로축에 전원 전압을 잡고, 각 조건에서 테스트에 합격했는지 불합격했는지를 칸으로 나타낸 도표입니다. LSI가 어느 범위의 조건에서 올바르게 동작하는지(동작 마진)를 한눈에 확인할 수 있고, 합격 경계의 모양으로부터 속도로 결정되는 불량인지 전압으로 결정되는 불량인지를 추정할 수 있습니다. 파레토 차트는 불량이 많은 순서의 막대 그래프, 웨이퍼 맵은 칩 위치별 결과입니다.

테스트와 검사의 다른 문제

  1. 일반적인 반도체 제품의 테스트 흐름으로 올바른 것은 무엇입니까?
  2. AC 테스트에서 주로 확인하는 항목은 무엇입니까?
  3. 스캔 테스트의 데이터 양과 테스트 시간을 줄이기 위해 칩 안에서 테스트 패턴을 전개하고 응답을 압축하는 기술을 무엇이라고 합니까?
  4. 실제 동작 주파수에서 테스트를 수행하여 신호가 전달되는 속도가 너무 느린 불량을 검출하는 테스트를 무엇이라고 합니까?
  5. 테스트 결과에 기초하여 동작 속도나 소비 전력 등 성능별로 제품을 분류하는 것을 무엇이라고 합니까?

이 분야의 비교

  • 정적 번인 vs 동적 번인 vs 웨이퍼 레벨 번인: 스트레스·커버리지·비용 비교정적 번인, 동적 번인, 웨이퍼 레벨 번인을 표로 비교합니다: 스트레스를 가하는 방식, 수행 단계, 대표 조건, 스트레스가 걸리는 범위, 장비와 지그, 모니터링, 비용, 과제, 용도. 구분해서 쓰…
  • 스캔 테스트와 BIST의 차이점 정리스캔 테스트와 BIST(내장 자체 테스트)를 표로 비교합니다. 패턴 생성 방법, 테스터 의존도, 대상, 고장 검출률, 추가 회로, 테스트 시간을 안내합니다.
  • 웨이퍼 테스트와 파이널 테스트의 차이점 정리웨이퍼 테스트(프로브 테스트)와 파이널 테스트를 표로 비교합니다. 시기와 대상, 접촉 방식, 온도, 테스트 항목, 불량 검출 목적, KGD를 안내합니다.
