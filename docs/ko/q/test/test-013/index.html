테스트와 검사

IEEE 1149.1(JTAG)에서 규정된 바운더리 스캔의 주된 용도는 무엇입니까?

  1. A웨이퍼 상 막 두께의 측정
  2. B배선의 일렉트로마이그레이션 평가
  3. C인쇄 회로 기판에 실장한 LSI의 단자끼리의 접속 등을, 프로브를 대지 않고 테스트한다
정답과 해설 보기

정답: C. 인쇄 회로 기판에 실장한 LSI의 단자끼리의 접속 등을, 프로브를 대지 않고 테스트한다

바운더리 스캔에서는 LSI의 각 단자 안쪽에 스캔용 셀을 두고 이들을 직렬로 연결하여, TDI, TDO, TCK, TMS의 4개(및 리셋) 신호로 외부에서 값을 설정하고 관측합니다. 단자에 프로브를 댈 수 없는 BGA 등에서도 기판 상의 납땜 접속의 단선이나 단락을 검사할 수 있습니다. 이 단자는 디버그나 플래시 메모리 기록에도 널리 사용됩니다.

테스트와 검사의 다른 문제

  1. 패키지 후의 최종 테스트에서 테스터와 조합하여 IC를 자동으로 공급하고 테스트 결과에 따라 분류하는 장치는 무엇입니까?
  2. 전원 전압이나 동작 주파수 등의 조건을 바꾸면서 합격 여부를 조사하고 그 결과를 2차원 도표로 정리한 것을 무엇이라고 합니까?
  3. 일반적인 반도체 제품의 테스트 흐름으로 올바른 것은 무엇입니까?
  4. AC 테스트에서 주로 확인하는 항목은 무엇입니까?
  5. 스캔 테스트의 데이터 양과 테스트 시간을 줄이기 위해 칩 안에서 테스트 패턴을 전개하고 응답을 압축하는 기술을 무엇이라고 합니까?
