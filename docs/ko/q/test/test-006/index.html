프로브 카드에 대한 설명으로 올바른 것은?

  1. A칩을 봉지하기 위한 금형
  2. B웨이퍼를 운반하기 위한 용기
  3. C웨이퍼 위 칩의 전극에 바늘을 접촉시켜 테스터와 전기적으로 연결하는 지그
정답과 해설 보기

정답: C. 웨이퍼 위 칩의 전극에 바늘을 접촉시켜 테스터와 전기적으로 연결하는 지그

프로브 카드는 칩의 전극 패드 배치에 맞춰 다수의 바늘을 늘어놓은, 품종별 전용 지그입니다. 프로버가 카메라로 웨이퍼의 위치를 맞추고 척을 올려 바늘과 패드를 접촉시켜, 테스터와 칩을 전기적으로 연결합니다. 바늘의 방식에는 비스듬한 바늘의 캔틸레버형, 수직형, MEMS 기술로 만드는 형이 있습니다. 봉지용 금형이나 운반 용기와는 별개입니다.

테스트와 검사의 다른 문제

  1. 논리 회로 테스트에서 사용되는 고착 고장(스턱 앳 고장) 모델에 대한 설명으로 올바른 것은?
  2. 테스트 패턴의 고장 검출률(폴트 커버리지)의 정의로 올바른 것은?
  3. 여러 칩을 하나의 패키지에 실장할 때 중요해지는 KGD(Known Good Die)란 무엇입니까?
  4. 테스트 비용을 낮추기 위해 테스터로 여러 칩을 동시에 측정하는 기법을 무엇이라고 부릅니까?
  5. 회로의 넷리스트에서 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것을 무엇이라고 부릅니까?
