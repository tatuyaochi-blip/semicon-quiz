정답: B. 멀티사이트 테스트(동시 측정)

테스트 비용은 고가의 테스터를 사용하는 시간에 거의 비례합니다. 멀티사이트 테스트에서는 1대의 테스터로 여러 칩을 병행하여 측정해 칩 1개당 테스트 시간과 비용을 낮춥니다. 메모리 테스트에서는 수백 개를 동시에 측정하기도 합니다. 동시에 측정하는 칩 수만큼 테스터 채널이 필요하므로, BIST나 스캔 압축으로 필요한 핀을 줄이는 연구와 함께 사용합니다.

테스트와 검사의 다른 문제

  1. 회로의 넷리스트에서 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것을 무엇이라고 부릅니까?
  2. CMOS 회로가 정지 상태일 때의 전원 전류를 측정하여 브리지 고장 등의 결함을 검출하는 테스트를 무엇이라고 부릅니까?
  3. IEEE 1149.1(JTAG)에서 규정된 바운더리 스캔의 주된 용도는?
  4. 패키지 후의 최종 테스트에서 테스터와 조합하여 IC를 자동으로 공급하고, 테스트 결과에 따라 분류하는 장치는?
  5. 전원 전압이나 동작 주파수 등의 조건을 바꿔 가며 합격 여부를 조사하고, 그 결과를 2차원 그림으로 정리한 것을 무엇이라고 부릅니까?
