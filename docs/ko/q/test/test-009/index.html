테스트와 검사

여러 칩을 하나의 패키지에 실장할 때 중요해지는 KGD(Known Good Die)란 무엇입니까?

  1. A대형 칩
  2. B고장 난 칩
  3. C실장 전에 양품임이 확인된 칩(다이)
정답과 해설 보기

정답: C. 실장 전에 양품임이 확인된 칩(다이)

여러 칩을 하나의 패키지에 넣는 경우, 하나라도 불량 칩이 포함되면 다른 양품 칩까지 포함하여 패키지 전체가 불량이 됩니다. 예를 들어 양품률 99%인 칩을 8개 쌓으면 전부 양품일 확률은 0.99⁸≒92%까지 떨어집니다. 그래서 실장 전 다이 단계에서 충분히 테스트한 양품(KGD)을 사용하는 것이 중요하며, HBM이나 칩렛에서 특히 중시됩니다.

테스트와 검사의 다른 문제

  1. 테스트 비용을 낮추기 위해 테스터로 여러 칩을 동시에 측정하는 기법을 무엇이라고 합니까?
  2. 회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것을 무엇이라고 합니까?
  3. CMOS 회로가 정지 상태일 때의 전원 전류를 측정하여 브리지 고장 등의 결함을 검출하는 테스트를 무엇이라고 합니까?
  4. IEEE 1149.1(JTAG)에서 규정된 바운더리 스캔의 주된 용도는 무엇입니까?
  5. 패키지 후의 최종 테스트에서 테스터와 조합하여 IC를 자동으로 공급하고 테스트 결과에 따라 분류하는 장치는 무엇입니까?
