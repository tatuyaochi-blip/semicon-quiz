정답: B. 셀 어웨어 테스트

종래의 고착 고장 등의 모델은 셀의 입출력 단자에만 주목했습니다. 셀 어웨어 테스트에서는 셀의 레이아웃으로부터 일어날 수 있는 트랜지스터의 단락이나 개방 등을 추출하고, 각각을 트랜지스터 레벨에서 시뮬레이션하여 검출할 수 있는 입력 조합을 패턴 생성에 반영합니다. 미세 공정에서 늘어난 셀 내부 결함에 의한 시장 불량을 줄이는 데 도움이 됩니다.
