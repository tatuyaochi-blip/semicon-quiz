테스트와 검사

테스트에서 측정 오차나 경시 변화를 고려하여 제품 규격보다 약간 엄격한 판정값을 두는 것을 무엇이라고 합니까?

  1. A비닝
  2. B테스트 압축
  3. C가드밴드
정답과 해설 보기

정답: C. 가드밴드

테스터에는 측정 오차가 있고, 제품의 특성도 온도나 경년으로 조금씩 변합니다. 규격 아슬아슬한 제품을 양품으로 판정해 버리지 않도록 판정값을 규격보다 여유를 두고 엄격하게 설정합니다. 이 여유를 가드밴드라고 합니다. 너무 넓게 잡으면 양품까지 불량으로 판정하여 수율이 떨어지므로, 측정의 재현성을 높여 가드밴드를 줄이려는 노력이 계속됩니다.

테스트와 검사의 다른 문제

  1. 테스트 프로그램 개발에서 테스트 비용을 낮추기 위해 중시되는 것으로 올바른 것은 무엇입니까?
  2. 웨이퍼 테스트에서 불량으로 판정한 칩의 정보를 이후 조립 공정에서 사용하는 방법으로 현재 일반적인 것은 무엇입니까?
  3. 차량용 반도체에서 상온뿐만 아니라 고온이나 저온에서도 테스트를 수행하는 주된 이유는 무엇입니까?
  4. 메모리 테스트에서 주소를 차례로 따라가며 0과 1의 쓰기와 읽기를 반복하여, 인접 셀 간의 간섭 등의 불량도 검출하는 테스트 패턴은 무엇입니까?
  5. ATE(자동 시험 장치)에 대한 설명으로 올바른 것은 무엇입니까?
