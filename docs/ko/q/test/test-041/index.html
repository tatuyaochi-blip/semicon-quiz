테스트와 검사

프로버에서 웨이퍼를 올려놓는 대(척)의 온도를 고온이나 저온으로 제어할 수 있게 하는 목적은 무엇입니까?

  1. A웨이퍼를 건조시키기 위해
  2. B실제 사용 온도 범위에서 칩이 규격을 만족하는지를 웨이퍼 단계에서 확인하기 위해
  3. C칩을 접착하기 위해
정답과 해설 보기

정답: B. 실제 사용 온도 범위에서 칩이 규격을 만족하는지를 웨이퍼 단계에서 확인하기 위해

칩의 특성은 온도에 따라 변하며, 고온에서 누설 전류가 늘거나 저온에서 타이밍이 변하기도 합니다. 척의 온도를 −40~150 ℃ 정도 범위에서 제어하여 웨이퍼 테스트를 하면, 패키지하기 전에 온도에 의존하는 불량을 찾아내어 조립 비용의 낭비를 줄일 수 있습니다. 저온에서는 결로를 막기 위해 건조 공기로 웨이퍼 주위를 채웁니다.

테스트와 검사의 다른 문제

  1. 로직 회로 테스트에서, 스캔 등을 사용하여 회로의 구조상 고장(고착 고장 등)을 망라적으로 검출하는 테스트와, 실제 동작대로 기능을 확인하는 테스트의 명칭 조합으로 올바른 것은 무엇입니까?
  2. 테스트 판정이 지나치게 엄격하거나 측정이 불안정하여, 본래 양품인 칩을 불량으로 판정하여 버리는 것을 무엇이라고 합니까?
  3. 메모리 테스트에서 어느 주소의 어느 비트가 불량이었는지를 기록한 도표를 만드는 주된 목적은 무엇입니까?
  4. 스캔 테스트에서 출력을 압축할 때, 시뮬레이션에서 값이 0인지 1인지 정해지지 않는 신호(불정값 X)를 제거하는 처리가 필요한 이유는 무엇입니까?
  5. 고속 직렬 통신 인터페이스 테스트에서, 칩의 송신 회로 출력을 수신 회로로 되돌려 연결하여 칩 스스로 통신을 확인하는 방법은 무엇입니까?
