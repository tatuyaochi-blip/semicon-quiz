정답: B. 테스트 패턴(테스트 벡터)

테스트 패턴(테스트 벡터)은 각 시각에 칩의 입력에 가하는 신호 값과 그때 출력되어야 할 기대값을 모은 것입니다. 고장을 효율적으로 검출할 수 있는 패턴은 ATPG로 자동 생성하거나, 설계 시 검증용 시뮬레이션에서 변환하여 만듭니다. 패턴이 길수록 테스트 시간이 늘어나므로, 적은 패턴으로 많은 고장을 검출할 수 있도록 최적화합니다.

  2. 전공정을 마친 웨이퍼에서 TEG의 문턱 전압이나 시트 저항 등을 측정하여 공정이 규격대로 만들어졌는지 확인하는 검사를 무엇이라고 합니까?
