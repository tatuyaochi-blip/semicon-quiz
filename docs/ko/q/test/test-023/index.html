테스트와 검사

웨이퍼 테스트에서 불량으로 판정한 칩의 정보를 뒤 조립 공정에서 사용하는 방법으로 현재 일반적인 것은?

  1. A불량 칩에 표시를 하지 않고 조립 공정에서 전부 재검사한다
  2. B전자 데이터인 웨이퍼 맵으로 조립 공정에 넘긴다
  3. C작업자가 눈으로 보고 기억해 둔다
정답과 해설 보기

정답: B. 전자 데이터인 웨이퍼 맵으로 조립 공정에 넘긴다

예전에는 불량 칩에 잉크로 점을 찍었지만, 현재는 웨이퍼 테스트 결과를 웨이퍼 맵의 전자 데이터로 저장하고, 조립 공정의 다이 본더가 그 데이터를 읽어 양품 칩만 집어내는 것이 일반적입니다. 잉크 오염이나 건조의 수고가 없고, 성능 등급도 기록할 수 있습니다. 맵 데이터는 불량 분포의 해석에도 사용됩니다.
