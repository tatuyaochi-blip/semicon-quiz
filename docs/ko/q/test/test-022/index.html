테스트와 검사

테스트 프로그램 개발에서 테스트 비용을 낮추기 위해 중시되는 것으로 올바른 것은?

  1. A불량을 충분히 검출할 수 있는 범위에서 측정 항목과 순서를 최적화하여 테스트 시간을 단축한다
  2. B모든 항목을 최대 횟수씩 측정한다
  3. C불량이 많은 항목의 테스트를 생략한다
정답과 해설 보기

정답: A. 불량을 충분히 검출할 수 있는 범위에서 측정 항목과 순서를 최적화하여 테스트 시간을 단축한다

테스트 비용은 테스트 시간에 거의 비례하므로, 품질을 확보할 수 있는 범위에서 측정 항목을 줄이고 측정 순서와 조건을 연구하여 테스트 시간을 단축합니다. 예를 들어 불량이 되기 쉬운 항목을 먼저 측정해 일찍 중단하거나, 과거 데이터에서 불량이 거의 나오지 않는 항목을 재검토합니다. 불량이 많은 항목을 생략하면 놓치는 불량이 늘고, 모든 항목을 최대 횟수 측정하면 비용이 불어납니다.

테스트와 검사의 다른 문제

  1. 웨이퍼 테스트에서 불량으로 판정한 칩의 정보를 뒤 조립 공정에서 사용하는 방법으로 현재 일반적인 것은?
  2. 차량용 반도체에서 실온뿐 아니라 고온이나 저온에서도 테스트를 하는 주된 이유는?
  3. 메모리 테스트에서 주소를 차례로 따라가며 0과 1의 쓰기와 읽기를 반복하여, 인접한 셀 간 간섭 등의 불량도 검출하는 테스트 패턴은?
  4. ATE(자동 시험 장치)에 대한 설명으로 올바른 것은?
  5. 웨이퍼 테스트에서 프로브의 바늘이 전극 패드에 닿은 뒤, 조금 더 눌러서 확실하게 접촉시키는 것을 무엇이라고 부릅니까?
