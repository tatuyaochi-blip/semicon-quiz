정답: C. 불량 위치에 기반하여 용장 행·열로 교체하는 구제를 하고, 불량 원인 해석에도 사용하기 위해

페일 비트맵은 불량 비트의 위치를 주소에 대응시켜 나타낸 것입니다. 불량 행이나 열을 예비 행·열로 교체하는 용장 구제 계산에 사용하며, 구제는 레이저나 전기로 퓨즈를 끊어서 합니다. 불량의 늘어선 모양(1비트, 행 전체, 열 전체, 덩어리 등)에서 파티클이나 배선 단락 등 제조 공정 결함의 종류를 추정하는 해석에도 도움이 됩니다.

  • A. 불량 기록으로 용량이 늘어나는 것은 아닙니다.
  • B. 색과는 관계가 없습니다.
  • C. 올바릅니다. 구제와 불량 해석에 사용합니다.

테스트와 검사의 다른 문제

  1. 스캔 테스트에서 출력을 압축할 때, 시뮬레이션에서 값이 0인지 1인지 정해지지 않는 신호(불정값 X)를 제거하는 처리가 필요한 이유는?
  2. 고속 시리얼 통신 인터페이스 테스트에서, 칩의 송신 회로 출력을 수신 회로로 되돌려 연결하여 칩 자체로 통신을 확인하는 방법은?
  3. 웨이퍼 테스트 등의 도중 결과나 통계에 기반하여, 칩별·로트별로 테스트 항목이나 판정값을 동적으로 바꾸는 기법을 무엇이라고 부릅니까?
  4. AD 컨버터 테스트에서 천천히 변화하는 정현파 등을 입력하여 각 출력 코드가 나타나는 횟수(히스토그램)를 세는 주된 목적은?
  5. 스캔 테스트에서 불량이 된 칩에 대해, 어느 출력의 어느 패턴에서 불일치가 나왔는지 정보로부터 고장 났을 것 같은 위치의 후보를 논리적으로 좁혀 가는 처리를 무엇이라고 부릅니까?
