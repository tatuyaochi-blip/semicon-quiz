정답: C. 불량 위치에 기초하여 용장 행, 열로 교체하는 구제를 수행하고, 불량 원인 해석에도 사용하기 위해

페일 비트 맵은 불량 비트의 위치를 주소에 대응시켜 나타낸 것입니다. 불량 행이나 열을 예비 행, 열로 교체하는 용장 구제 계산에 사용하며, 구제는 레이저나 전기로 퓨즈를 끊어 수행합니다. 불량의 배열 양상(1비트, 행 전체, 열 전체, 덩어리 등)으로부터 파티클이나 배선 단락 등 제조 공정 결함의 종류를 추정하는 해석에도 도움이 됩니다.

테스트와 검사의 다른 문제

  1. 스캔 테스트에서 출력을 압축할 때, 시뮬레이션에서 값이 0인지 1인지 정해지지 않는 신호(불정값 X)를 제거하는 처리가 필요한 이유는 무엇입니까?
  2. 고속 직렬 통신 인터페이스 테스트에서, 칩의 송신 회로 출력을 수신 회로로 되돌려 연결하여 칩 스스로 통신을 확인하는 방법은 무엇입니까?
  3. 웨이퍼 테스트 등의 도중 결과나 통계에 기초하여, 칩별, 로트별로 테스트 항목이나 판정값을 동적으로 바꾸는 기법을 무엇이라고 합니까?
  4. AD 컨버터 테스트에서, 천천히 변화하는 정현파 등을 입력하고 각 출력 코드가 나타나는 횟수(히스토그램)를 세는 주된 목적은 무엇입니까?
  5. 스캔 테스트에서 불량이 된 칩에 대해, 어느 출력의 어느 패턴에서 불일치가 나왔는지의 정보로부터 고장 났을 것 같은 위치의 후보를 논리적으로 좁혀 가는 처리를 무엇이라고 합니까?

이 분야의 비교

  • 정적 번인 vs 동적 번인 vs 웨이퍼 레벨 번인: 스트레스·커버리지·비용 비교정적 번인, 동적 번인, 웨이퍼 레벨 번인을 표로 비교합니다: 스트레스를 가하는 방식, 수행 단계, 대표 조건, 스트레스가 걸리는 범위, 장비와 지그, 모니터링, 비용, 과제, 용도. 구분해서 쓰…
  • 스캔 테스트와 BIST의 차이점 정리스캔 테스트와 BIST(내장 자체 테스트)를 표로 비교합니다. 패턴 생성 방법, 테스터 의존도, 대상, 고장 검출률, 추가 회로, 테스트 시간을 안내합니다.
  • 웨이퍼 테스트와 파이널 테스트의 차이점 정리웨이퍼 테스트(프로브 테스트)와 파이널 테스트를 표로 비교합니다. 시기와 대상, 접촉 방식, 온도, 테스트 항목, 불량 검출 목적, KGD를 안내합니다.
