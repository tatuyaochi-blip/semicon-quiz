테스트와 검사

  2. B웨이퍼에 회로 패턴을 노광하는 장치
  3. C웨이퍼를 세정하는 장치
정답과 해설 보기

정답: A. 테스트 패턴을 입력하고 출력을 기대값과 비교하여 양부를 판정하는 장치

ATE(Automatic Test Equipment)는 테스트 대상 칩에 전원과 신호를 주고, 출력을 측정하여 기대값과 비교해 양부를 판정하는 장치입니다. 핀마다 신호 발생, 전압과 전류 측정, 타이밍 판정이 가능한 회로를 수백~수천 채널 갖추고 있습니다. 웨이퍼 테스트에서는 프로버, 최종 테스트에서는 핸들러와 조합하여 사용합니다. 노광이나 세정은 전공정 장치의 역할입니다.

테스트와 검사의 다른 문제

  1. 웨이퍼 테스트에서 프로브의 침이 전극 패드에 닿은 뒤, 조금 더 눌러 확실하게 접촉시키는 것을 무엇이라고 합니까?
  2. 테스트 용이화 설계에서 높이는 것을 목표로 하는 두 가지 성질의 조합으로 올바른 것은 무엇입니까?
  3. 실제 사용 상태에 가까운 환경에서 OS나 애플리케이션을 동작시켜 칩의 양부를 판정하는 테스트를 무엇이라고 합니까?
  4. 출하한 제품 100만 개당 불량 수를 나타내는 품질 지표는 무엇입니까?
  5. 반도체 제품 제조에서 테스트를 수행하는 주된 목적은 무엇입니까?
