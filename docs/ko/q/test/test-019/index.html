정답: C. 실속도(앳 스피드) 테스트

미세한 LSI에서는 논리적으로는 올바르게 동작해도 사소한 결함 때문에 신호가 전달되는 시간이 늘어나는 지연 불량이 문제가 됩니다. 앳 스피드 테스트에서는 스캔으로 값을 설정한 뒤, 칩 내의 PLL에서 실제 동작 주파수의 클럭을 2회 연속으로 주어 신호 변화가 1주기 안에 도달하는지를 조사합니다. 천이 고장 등 지연 고장 모델에 기반한 패턴을 사용합니다.

테스트와 검사의 다른 문제

  1. 테스트 결과에 기반하여 동작 속도나 소비 전력 등 성능별로 제품을 분류하는 것을 무엇이라고 부릅니까?
  2. 테스트에서 측정 오차나 경시 변화를 고려하여 제품의 규격보다 조금 엄격한 판정값을 두는 것을 무엇이라고 부릅니까?
  3. 테스트 프로그램 개발에서 테스트 비용을 낮추기 위해 중시되는 것으로 올바른 것은?
  4. 웨이퍼 테스트에서 불량으로 판정한 칩의 정보를 뒤 조립 공정에서 사용하는 방법으로 현재 일반적인 것은?
  5. 차량용 반도체에서 실온뿐 아니라 고온이나 저온에서도 테스트를 하는 주된 이유는?
