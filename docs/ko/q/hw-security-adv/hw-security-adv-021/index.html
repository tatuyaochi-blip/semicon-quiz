하드웨어 보안의 최신 동향

ML-KEM-768의 공개 키는 1,184바이트, 암호문은 1,088바이트이고, 타원 곡선 키 교환 X25519의 공개 값은 32바이트이다. ML-KEM-768 공개 키의 크기가 X25519 공개 값의 몇 배인지로 올바른 것은?

  1. A37배
  2. B71배
  3. C296배
정답과 해설 보기

정답: A. 37배

1,184 ÷ 32 = 37이므로 37배입니다. 키 교환에서는 1,088바이트의 암호문도 보내므로, 32바이트의 공개 값을 주고받는 타원 곡선 키 교환에 비해 주고받는 데이터가 훨씬 커집니다. IC 카드나 작은 마이컴에서는 키나 중간값을 두는 RAM이나 버퍼의 크기, 한 번에 보낼 수 있는 데이터 크기의 상한 등을 재검토해야 하며, 하드웨어 설계에 영향을 줍니다. 서명에서도 ML-DSA-65의 서명은 3,309바이트로, 타원 곡선 서명보다 훨씬 커집니다.

하드웨어 보안의 최신 동향의 다른 문제

  1. ML-KEM의 캡슐화 해제에서는 받은 암호문을 개인 키로 복호화한 결과로부터 암호문을 다시 한번 만들어, 받은 암호문과 일치하는지를 비교한다. 이 부분의 구현상 주의점으로 올바른 것은?
  2. 10년 이상 사용되는 임베디드 기기의 SoC를 설계한다. 앞으로의 암호 이행(양자 내성 암호로의 이행 등)에 대비하는 하드웨어와 펌웨어의 설계로 적절한 것은?
  3. OpenTitan이나 Caliptra처럼 신뢰의 근간(Root of Trust) 회로의 설계를 공개하는 활동의 이점으로 가장 적절한 것은?
  4. TCG가 정한 DICE(Device Identifier Composition Engine)의 구조로 올바른 것은?
  5. A면과 B면 2개의 영역을 사용해 펌웨어를 업데이트하는 기기에서, 롤백 방지를 위해 eFuse에 기록하는 최저 버전 번호를 새 버전 번호로 올리는 시기로 가장 적절한 것은?
