하드웨어 보안의 최신 동향

반도체 설계를 보호하는 기술과, 주로 상정하는 신뢰할 수 없는 상대의 조합으로 올바른 것은?

  1. A분할 제조는 완성된 칩을 산 이용자, IC 카무플라주는 제조를 위탁받은 공장, 로직 로킹은 설계 툴 개발사
  2. B분할 제조는 제조를 위탁받은 공장, IC 카무플라주는 칩 이미지로부터 회로를 읽어 내는 자, 로직 로킹은 공장이나 키가 없는 칩을 손에 넣은 자
  3. C분할 제조, IC 카무플라주, 로직 로킹은 모두 기기에 침입하는 소프트웨어 바이러스만을 상대로 한다
정답과 해설 보기

정답: B. 분할 제조는 제조를 위탁받은 공장, IC 카무플라주는 칩 이미지로부터 회로를 읽어 내는 자, 로직 로킹은 공장이나 키가 없는 칩을 손에 넣은 자

분할 제조에서는 트랜지스터와 아래쪽 배선층(FEOL)을 외부의 최첨단 공장에서 만들고, 위쪽 배선층을 신뢰할 수 있는 공장에서 만들므로, 외부 공장은 회로 연결의 전체를 알 수 없습니다. IC 카무플라주는 겉보기가 같고 기능이 다른 셀이나, 연결된 것처럼 보이기만 하는 가짜 접점을 사용하여, 칩을 깎아 내며 촬영한 이미지로부터 회로를 읽어 내는 역설계를 어렵게 하지만, 설계 데이터를 가진 공장에는 효과가 없습니다. 로직 로킹은 키에 따라 동작이 바뀌는 게이트를 회로에 넣고, 올바른 키를 제조 후에 기록할 때까지 올바르게 동작하지 않게 하여, 공장에 의한 설계 도용이나 초과 제조를 막는 것을 노립니다. 동작하는 칩을 손에 넣은 공격자가 입력과 출력을 대조하여 SAT 솔버로 키를 좁혀 가는 공격이 2015년에 제시된 이후, 이에 견디는 방식의 연구가 이어지고 있습니다.

하드웨어 보안의 최신 동향의 다른 문제

  1. 칩의 층을 한 장씩 깎아 내어 전자 현미경으로 촬영하거나 X선으로 내부를 촬영하여 회로를 읽어 내는 역설계를 전제로 했을 때, 설계의 사고방식으로 적절한 것은?
  2. 암호 모듈 인증 기준인 FIPS 140-3의 보안 레벨 1~4에 대해, 물리적 안전성 요구의 설명으로 올바른 것은?
  3. 보안 제품을 평가하는 국제 규격인 공통 평가 기준(Common Criteria, ISO/IEC 15408)의 EAL(평가 보증 등급)이 나타내는 것으로 올바른 것은?
  4. IoT 기기용 보안 인증 프레임워크인 PSA Certified나 SESIP에서 중시되는 합성(컴포지션)의 개념으로 올바른 것은?
  5. 출하한 제품의 디버그 포트를 제조사의 기술자만 열 수 있게 하는 인증 디버그의 설계로 가장 적절한 것은?
