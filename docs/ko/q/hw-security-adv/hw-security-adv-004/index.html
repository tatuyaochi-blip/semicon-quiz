하드웨어 보안의 최신 동향

기밀 컴퓨팅에서 이용자의 검증 서버(검증자)가 VM형 TEE로부터 받은 증명(attestation) 보고서를 확인한 뒤에 데이터를 복호화하는 키를 넘겨준다. 검증자가 확인하는 내용의 조합으로 가장 적절한 것은?

  1. A서명이 CPU 제조사의 키로 이어지는 것, 부팅 시의 측정값이 기대한 대로인 것, TCB 버전이 수정된 버전 이상인 것, 검증자가 보낸 논스를 포함하는 것
  2. B보고서의 서명이 진짜 CPU 제조사의 키로 이어져 있으면 안에서 동작하는 소프트웨어도 안전하다고 할 수 있으므로, 측정값이나 버전 번호까지는 확인하지 않아도 된다
  3. C보고서에 적힌 가상 머신의 이름이나 IP 주소, 메모리 용량이 클라우드 사업자와 계약했을 때의 내용과 일치하는 것
정답과 해설 보기

정답: A. 서명이 CPU 제조사의 키로 이어지는 것, 부팅 시의 측정값이 기대한 대로인 것, TCB 버전이 수정된 버전 이상인 것, 검증자가 보낸 논스를 포함하는 것

서명 확인으로 알 수 있는 것은 보고서가 진짜 TEE에서 나왔다는 것뿐입니다. 안에서 무엇이 부팅되었는지는 측정값을 올바르다고 알려진 값과 비교하여 확인하고, 검증자가 보낸 논스가 포함되어 있는 것으로 지금 만들어진 보고서이며 리플레이가 아님을 확인합니다. 또한 취약점이 수정되기 전의 펌웨어나 마이크로코드로 동작하는 TEE도 올바르게 서명된 보고서를 낼 수 있으므로, 보고서에 포함된 TCB 버전(보안 버전 번호)이 수정된 버전 이상인지도 확인합니다. 보고서에 통신용 공개 키의 해시값을 포함해 두면, 넘겨주는 키가 그 가상 머신 안에만 도달하게 할 수 있습니다.

하드웨어 보안의 최신 동향의 다른 문제

  1. 2020년대 중반 시점에서 데이터센터용 일부 GPU는 CPU의 TEE와 조합하여 기밀 컴퓨팅에 사용할 수 있는 기능을 갖추고 있다. 이 구조의 개념으로 올바른 것은?
  2. Arm CCA(Confidential Compute Architecture)에서 도입된 렐름(Realm)의 설명으로 올바른 것은?
  3. CHERI라고 불리는 명령어 집합 확장에서 쓰이는 케이퍼빌리티(capability)의 설명으로 올바른 것은?
  4. Arm의 MTE(메모리 태깅 확장)에서는 메모리의 16바이트마다 4비트 태그를 붙이고, 포인터의 상위 비트에도 4비트 태그를 넣어, 접근할 때마다 둘이 일치하는지를 CPU가 확인한다. 해제한 영역을 가리키는 오래된 포인터로 그 영역에 접근하는 오류를 생각한다. 영역을 다시 할당할 때의 새 태그가 16가지 중에서 균일하게 무작위로 선택된다고 하면, 태그가 우연히 일치하여 오류를 놓칠 확률은?
  5. Arm의 포인터 인증(PAC) 구조로 올바른 것은?
