하드웨어 보안의 최신 동향

칩의 층을 한 장씩 깎아 내어 전자 현미경으로 촬영하거나 X선으로 내부를 촬영하여 회로를 읽어 내는 역설계를 전제로 했을 때, 설계의 사고방식으로 적절한 것은?

  1. A마스크 ROM의 값이나 배선의 형태는 이미지로부터 읽혀질 수 있으므로, 비밀 키는 회로의 형태로 만들어 넣지 않고 기기별로 다른 값으로 하여 물리적 대책과 함께 보호한다
  2. B회로 배치를 충분히 복잡하게 해 두면 이미지로부터 회로를 읽힐 일은 없으므로, 모든 기기에 공통인 비밀 키를 마스크 ROM에 써 두어도 된다
  3. CX선으로는 칩 내부의 회로가 찍히지 않으므로, 층을 깎이지 않도록 칩 표면을 단단한 막으로 덮어 두면 역설계 대책으로 충분하다
정답과 해설 보기

정답: A. 마스크 ROM의 값이나 배선의 형태는 이미지로부터 읽혀질 수 있으므로, 비밀 키는 회로의 형태로 만들어 넣지 않고 기기별로 다른 값으로 하여 물리적 대책과 함께 보호한다

마스크 ROM의 값은 트랜지스터나 접점의 유무로서 회로의 형태에 만들어 넣어지므로, 층을 깎아 내어 촬영하면 읽어 낼 수 있습니다. 또한 같은 마스크로 만든 모든 칩에 같은 값이 들어가므로, 하나가 해석되면 모든 기기의 비밀이 새어 나갑니다. 2020년대에는 X선 촬영으로 칩을 파괴하지 않고 내부 배선을 세밀하게 촬영하는 연구도 보고되어 있습니다. 그래서 비밀은 회로의 형태에 의존하지 않고 기기별로 다른 값으로 하며, eFuse처럼 기록한 흔적이 보일 수 있는 저장소에서는 PUF로부터 만든 키로 암호화하여 두는 등의 방법을 써서 읽어 내는 경로를 제한하고, 내탬퍼성 대책과 조합합니다.

하드웨어 보안의 최신 동향의 다른 문제

  1. 암호 모듈 인증 기준인 FIPS 140-3의 보안 레벨 1~4에 대해, 물리적 안전성 요구의 설명으로 올바른 것은?
  2. 보안 제품을 평가하는 국제 규격인 공통 평가 기준(Common Criteria, ISO/IEC 15408)의 EAL(평가 보증 등급)이 나타내는 것으로 올바른 것은?
  3. IoT 기기용 보안 인증 프레임워크인 PSA Certified나 SESIP에서 중시되는 합성(컴포지션)의 개념으로 올바른 것은?
  4. 출하한 제품의 디버그 포트를 제조사의 기술자만 열 수 있게 하는 인증 디버그의 설계로 가장 적절한 것은?
  5. 보안 칩의 라이프사이클 상태를 테스트, 프로덕션(본 운용), 고장품 해석(RMA) 등으로 나누어 관리한다. 프로덕션 상태에서 고장 해석을 위해 RMA 상태로 옮길 때의 처리로 적절한 것은?
