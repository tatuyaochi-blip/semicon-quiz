하드웨어 보안의 최신 동향

2024년에 갱신된 DDR5 규격(JESD79-5C)에 추가된 PRAC(행별 활성화 계수)의 개념으로 올바른 것은?

  1. A메모리 컨트롤러가 활성화 횟수를 세는 것을 그만두고, DRAM 내부의 리프레시도 모두 외부 컨트롤러가 1행씩 명령하여 수행한다
  2. BDRAM이 행마다 활성화 횟수를 세어, 임곗값을 넘은 행이 있으면 컨트롤러에 알리고 이웃 행을 리프레시할 시간을 받는다
  3. C정해진 횟수보다 많이 활성화된 행을 DRAM이 영구히 사용할 수 없게 하고, 제조 시 준비한 예비 행으로 교체한다
정답과 해설 보기

정답: B. DRAM이 행마다 활성화 횟수를 세어, 임곗값을 넘은 행이 있으면 컨트롤러에 알리고 이웃 행을 리프레시할 시간을 받는다

그때까지의 대책에서는 DRAM 내부의 TRR이 소수의 행만 추적하거나, DDR5의 RFM처럼 메모리 컨트롤러가 뱅크별 활성화 횟수를 세어 DRAM에 추가 시간을 주었습니다. PRAC에서는 DRAM이 행마다 카운터를 가지고 활성화할 때마다 그 행의 횟수를 세므로, 추적할 수 있는 행 수의 한계로 인한 놓침이 없어집니다. 횟수가 임곗값을 넘으면 DRAM은 컨트롤러에 알려 접근을 일시적으로 멈추게 하고, 표적이 된 행의 주변을 리프레시합니다. 카운터를 갱신하기 위해 행을 닫는 시간 등의 타이밍 규정이 길어진다고 하며, 성능과의 균형 문제가 있습니다.

하드웨어 보안의 최신 동향의 다른 문제

  1. 같은 뱅크에서 행을 활성화할 수 있는 최단 간격을 간단히 tRC = 50 ns로 한다. 리프레시 주기가 64 ms일 때, 어떤 행이 리프레시된 후 다음에 리프레시될 때까지 이웃한 1개 행을 활성화할 수 있는 횟수는 최대 64 ms ÷ 50 ns가 된다. 리프레시 빈도를 2배로 했을 때 이 최대 횟수는?
  2. 2019년에 공표된 MDS(마이크로아키텍처 데이터 샘플링)라고 불리는 취약점의 특징으로 올바른 것은?
  3. 간접 분기의 예측을 악용하는 Spectre의 변종(분기 타깃 인젝션)에 대한 대책인 retpoline과 IBRS의 설명 조합으로 올바른 것은?
  4. 어떤 처리는 투기적 실행에 대한 대책을 넣기 전에 10초가 걸렸고, 그동안 시스템 콜을 500만 회 호출했다. 대책을 넣으면 시스템 콜 1회당 처리 시간이 0.4 µs에서 0.6 µs로 늘어나고, 그 이외 부분의 시간은 변하지 않는다고 한다. 처리 전체 시간의 증가 비율은?
  5. 격자 기반 양자 내성 암호에서는 차수 n = 256인 다항식의 곱셈을 여러 번 수행한다. 계수끼리 모두 곱하는 소박한 방법으로는 약 n²회, 수론 변환(NTT)을 사용하는 방법으로는 약 n log₂ n회의 곱셈이 필요하다고 하면, NTT를 사용함으로써 곱셈 횟수가 대략 몇 분의 1이 되는지에 가장 가까운 것은?
