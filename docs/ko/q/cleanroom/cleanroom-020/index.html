클린룸과 장비

반도체 공장에서 일반적인 장비 레이아웃의 개념으로 올바른 것은 무엇인가?

  1. A자동차 공장처럼 공정 순서대로 장비를 일직선으로 배치하는 방식만 사용된다
  2. B같은 종류의 장비를 모은 베이(구역)별로 배치하고 반송 시스템으로 연결하는 잡숍형 방식
  3. C모든 장비를 한 대씩 별도의 건물에 두는 방식
정답과 해설 보기

정답: B. 같은 종류의 장비를 모은 베이(구역)별로 배치하고 반송 시스템으로 연결하는 잡숍형 방식

반도체 제조에서는 성막·리소그래피·식각 등을 수십 번 반복하므로 웨이퍼는 같은 종류의 장비를 여러 번 방문합니다. 공정 순서대로 일직선으로 배치하면 같은 장비를 수십 대 마련해야 하므로, 같은 종류의 장비를 베이에 모아 배치하고 자동 반송 시스템으로 연결하는 잡숍형 배치가 일반적입니다. 장비를 한 대씩 별도의 건물에 두는 일은 없습니다.
