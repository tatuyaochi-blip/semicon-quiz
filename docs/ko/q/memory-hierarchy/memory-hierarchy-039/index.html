메모리 계층 구조

가장 오랫동안 사용되지 않은 것을 쫓아내는 LRU에 대해, 앞으로 가장 오랫동안 사용되지 않을 것을 쫓아내는 방식(최적 교체, OPT)에 대한 설명으로 올바른 것은?

  1. A실제 캐시에서 널리 사용되는 가장 일반적인 교체 방식이다
  2. B실현할 수는 없지만 다른 방식의 미스 수의 하한을 보여 주는 기준이 된다
  3. C어떤 접근 순서에서도 LRU와 완전히 같은 미스 수가 된다
정답과 해설 보기

정답: B. 실현할 수는 없지만 다른 방식의 미스 수의 하한을 보여 주는 기준이 된다

최적 교체(벨러디의 OPT)는 미래의 접근 순서를 알고 있다고 가정하고 다음에 사용되는 시점이 가장 먼 데이터를 쫓아내는 방식으로, 미스 수가 이론상 최소가 됩니다. 그러나 실제 하드웨어는 미래의 접근을 알 수 없으므로 실현할 수 없고, 기록한 접근 순서에 적용하여 LRU 등의 방식이 얼마나 최적에 가까운지 평가하는 데 사용합니다. LRU와는 쫓아내는 데이터가 다르므로 미스 수는 일반적으로 다릅니다.

메모리 계층 구조의 다른 문제

  1. 캐시 용량을 크게 하면 일반적으로 히트 시간은 어떻게 되는가? 그 이유와 함께 올바른 것은?
  2. 위 연결 리스트를 따라가는 처리가 같은 수의 요소를 가진 배열을 차례로 읽는 것보다 크게 느려지기 쉬운 이유는?
  3. 1회 미스로 64바이트 라인을 읽고 주기억장치의 대기 시간이 100 ns일 때, 동시에 처리할 수 있는 미스가 하나뿐이면 읽기 대역폭은 약 0.64 GB/s에 그친다. 동시에 10개의 미스를 처리할 수 있다면 대역폭은 대략 얼마가 되는가? (다른 제약은 없다고 가정한다)
  4. 한 번 쓴 뒤 당분간 다시 읽지 않는 큰 데이터를 쓸 때, 캐시를 거치지 않는 스토어(논템포럴 스토어)를 사용하는 주된 이점은?
  5. 캐시 히트율이 95%일 때, 미스율은 얼마인가?

이 분야의 비교

  • 라이트스루 vs 라이트백 캐시: 차이점 설명라이트스루와 라이트백 캐시를 표로 비교합니다: 쓰기 정책, 메모리 트래픽, 속도, 일관성, 복잡도, 축출 비용, 대표 용도.
  • 직접 사상 vs 세트 연관 vs 완전 연관 캐시직접 사상, 세트 연관, 완전 연관 캐시를 표로 비교합니다: 블록 배치 위치, 태그 비교, 속도, 비용, 충돌 미스, 용도.
