메모리 계층 구조

페이지 크기 4 KB, 라인 크기 64바이트인 시스템에서 L1 캐시를 가상 인덱스·물리 태그(VIPT) 방식으로 하고, 인덱스와 오프셋을 페이지 내 비트만으로 구성하고 싶다. 8웨이 세트 어소시에이티브라면 캐시 용량은 최대 얼마까지 가능한가?

  1. A32 KB
  2. B4 KB
  3. C256 KB
정답과 해설 보기

정답: A. 32 KB

페이지 내 주소는 4 KB = 2¹²이므로 12비트이고, 이 범위는 가상 주소와 물리 주소가 같습니다. 인덱스와 오프셋을 합쳐 12비트 이내로 하려면 1웨이당 용량을 2¹² = 4 KB 이하로 해야 합니다. 8웨이라면 4 KB × 8 = 32 KB까지 가능합니다. 4 KB는 1웨이 분의 용량만 답한 값입니다. 256 KB로 하면 인덱스에 페이지 번호의 비트가 들어가 같은 물리 주소가 다른 세트에 들어가는 문제가 생깁니다.

메모리 계층 구조의 다른 문제

  1. L1 캐시에 가상 인덱스·물리 태그(VIPT) 방식이 자주 사용되는 주된 이유는?
  2. 캐시의 히트 시간이 2사이클, 미스율이 4%, 미스 페널티가 150사이클일 때, 평균 메모리 접근 시간은 몇 사이클인가?
  3. 캐시가 이상적이면 평균 CPI가 1.0인 프로세서에서, 명령 1개당 평균 1.3회의 메모리 접근이 있고 그 미스율이 2%, 미스 페널티가 100사이클일 때, 실제 평균 CPI는 얼마인가?
  4. 논블로킹 캐시(미스를 처리하는 중에도 다른 접근을 받아들이는 캐시)의 주된 이점은?
  5. L1 캐시의 미스율(전체 접근에 대한 비율)이 4%, L2 캐시의 글로벌 미스율(전체 접근 중 L2에서도 미스하는 비율)이 1%일 때, L2의 로컬 미스율은 얼마인가?

이 분야의 비교

  • 라이트스루 vs 라이트백 캐시: 차이점 설명라이트스루와 라이트백 캐시를 표로 비교합니다: 쓰기 정책, 메모리 트래픽, 속도, 일관성, 복잡도, 축출 비용, 대표 용도.
  • 직접 사상 vs 세트 연관 vs 완전 연관 캐시직접 사상, 세트 연관, 완전 연관 캐시를 표로 비교합니다: 블록 배치 위치, 태그 비교, 속도, 비용, 충돌 미스, 용도.
