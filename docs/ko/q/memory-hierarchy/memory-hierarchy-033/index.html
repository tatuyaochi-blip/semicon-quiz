메모리 계층 구조

L1 캐시 아래에 L2 캐시를 두는 다단계 캐시에서 L2 캐시의 주된 역할은 무엇입니까?

  1. AL1 캐시보다 빠른 히트 시간으로 L1의 미스 자체를 없앤다
  2. BL1보다 크고 느리지만 L1의 미스 페널티를 작게 한다
  3. C주기억장치 대신 프로그램의 모든 데이터를 항상 보유한다
정답과 해설 보기

정답: B. L1보다 크고 느리지만 L1의 미스 페널티를 작게 한다

L1은 속도를 우선하여 작게 만들기 때문에 미스가 어느 정도 일어납니다. L2는 L1보다 크고 히트 시간은 길지만 주기억장치보다는 훨씬 빠르므로, L1에서 미스한 접근의 대부분을 L2에서 받아 내어 L1의 미스 페널티를 주기억장치까지 가는 것보다 크게 줄입니다. L1보다 빠른 것은 아니며, L1의 미스를 없앨 수도 없습니다. 용량은 주기억장치보다 훨씬 작아 모든 데이터를 보유할 수도 없습니다.

  • A. L2는 L1보다 느리며, L1의 미스를 없앨 수 없습니다.
  • B. 올바릅니다. L1의 미스 대부분을 받아 내어 미스 페널티를 작게 합니다.
  • C. 용량은 주기억장치보다 훨씬 작아 모든 데이터가 들어가지 않습니다.

메모리 계층 구조의 다른 문제

  1. 하위 캐시(L2 등)가 상위 캐시(L1)의 내용을 모두 포함하는 포함(inclusive) 방식의 특징으로 올바른 것은 무엇입니까?
  2. 직접 사상 방식에서 세트 연관 방식으로 바꿨을 때 일어나는 변화로 올바른 것은 무엇입니까?
  3. 8-way 세트 연관 캐시에서 1회 접근할 때마다 병렬로 비교하는 태그의 수는 몇 개입니까?
  4. 라인 크기 64바이트, 세트 수 64인 캐시에서 주소 0x1234의 데이터가 들어가는 세트 번호는 무엇입니까?
  5. 같은 라인에 여러 번 쓰는 처리에서 라이트 스루 방식보다 라이트 백 방식이 유리한 주된 이유는 무엇입니까?
