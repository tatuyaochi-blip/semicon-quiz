메모리 계층 구조

하위 캐시(L2 등)가 상위 캐시(L1)의 내용을 모두 포함하는 인클루시브 방식의 특징으로 올바른 것은?

  1. A상위와 하위가 같은 데이터를 갖지 않으므로 합계 용량을 가장 효과적으로 사용할 수 있다
  2. B하위 캐시는 상위보다 반드시 작아야 한다
  3. C일관성 관리가 쉽지만 같은 데이터를 중복해서 가진다
정답과 해설 보기

정답: C. 일관성 관리가 쉽지만 같은 데이터를 중복해서 가진다

인클루시브 방식에서는 L1에 있는 데이터는 반드시 L2에도 있으므로, 다른 코어로부터의 조회에는 L2를 조사하면 답할 수 있어 L1까지 확인하는 수고가 줄어듭니다. 그 대신 같은 데이터를 이중으로 가지므로 실질 용량은 L2 분량이 됩니다. 상위와 하위가 중복해서 갖지 않는 것은 익스클루시브 방식이며 합계 용량을 효과적으로 사용할 수 있습니다. 하위 캐시는 보통 상위보다 크게 만듭니다.

메모리 계층 구조의 다른 문제

  1. 다이렉트 매핑 방식에서 세트 어소시에이티브 방식으로 바꿨을 때 일어나는 변화로 올바른 것은?
  2. 8웨이 세트 어소시에이티브 방식 캐시에서 한 번 접근할 때마다 병렬로 비교하는 태그의 수는 몇 개인가?
  3. 라인 크기 64바이트, 세트 수 64인 캐시에서 주소 0x1234의 데이터가 들어가는 세트 번호는?
  4. 같은 라인에 여러 번 쓰는 처리에서 라이트 스루 방식보다 라이트 백 방식이 유리해지는 주된 이유는?
  5. 가장 오랫동안 사용되지 않은 것을 쫓아내는 LRU에 대해, 앞으로 가장 오랫동안 사용되지 않을 것을 쫓아내는 방식(최적 교체, OPT)에 대한 설명으로 올바른 것은?

이 분야의 비교

  • 라이트스루 vs 라이트백 캐시: 차이점 설명라이트스루와 라이트백 캐시를 표로 비교합니다: 쓰기 정책, 메모리 트래픽, 속도, 일관성, 복잡도, 축출 비용, 대표 용도.
  • 직접 사상 vs 세트 연관 vs 완전 연관 캐시직접 사상, 세트 연관, 완전 연관 캐시를 표로 비교합니다: 블록 배치 위치, 태그 비교, 속도, 비용, 충돌 미스, 용도.
