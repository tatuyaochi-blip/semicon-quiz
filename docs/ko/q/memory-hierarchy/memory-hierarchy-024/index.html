메모리 계층 구조

캐시가 이상적이면 평균 CPI가 1.0인 프로세서에서, 명령 1개당 평균 1.3회의 메모리 접근이 있고 그 미스율이 2%, 미스 페널티가 100사이클일 때, 실제 평균 CPI는 얼마인가?

  1. A3.0
  2. B3.6
  3. C1.3
정답과 해설 보기

정답: B. 3.6

명령 1개당 메모리 정지 사이클은 1.3회 × 0.02 × 100사이클 = 2.6사이클입니다. 이를 이상적인 CPI에 더하면 1.0 + 2.6 = 3.6이 되어 성능은 이상의 3.6분의 1로 떨어집니다. 3.0은 명령 1개당 접근을 1회로 잘못 본 값(1.0 + 1 × 0.02 × 100)입니다. 1.3은 명령 1개당 접근 횟수이며 CPI가 아닙니다. 약간의 미스율이어도 미스 페널티가 크면 성능을 크게 떨어뜨린다는 것을 알 수 있습니다.

메모리 계층 구조의 다른 문제

  1. 논블로킹 캐시(미스를 처리하는 중에도 다른 접근을 받아들이는 캐시)의 주된 이점은?
  2. L1 캐시의 미스율(전체 접근에 대한 비율)이 4%, L2 캐시의 글로벌 미스율(전체 접근 중 L2에서도 미스하는 비율)이 1%일 때, L2의 로컬 미스율은 얼마인가?
  3. TLB의 엔트리가 64개이고 페이지 크기가 4 KB일 때, TLB 미스 없이 접근할 수 있는 메모리 범위(TLB 리치)는 얼마인가?
  4. 큰 페이지(Huge Page)를 사용하는 주된 이점과 단점의 조합으로 올바른 것은?
  5. 2차원 배열의 한 행 크기가 4096바이트(2의 거듭제곱)일 때, 열 방향으로 요소를 따라가면 캐시 용량에 여유가 있어도 미스가 많아지는 경우가 있다. 그 대책으로 효과가 있는 것은?
