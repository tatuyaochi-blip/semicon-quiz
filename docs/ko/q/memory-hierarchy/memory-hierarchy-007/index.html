메모리 계층 구조

직접 사상 캐시에서 두 배열의 요소가 같은 캐시 위치에 대응하여, 번갈아 접근할 때마다 서로를 쫓아내고 있습니다. 이 미스의 분류는 무엇입니까?

  1. A강제 미스(compulsory miss)
  2. B용량 미스(capacity miss)
  3. C충돌 미스(conflict miss)
정답과 해설 보기

정답: C. 충돌 미스(conflict miss)

캐시 전체에는 여유가 있는데도 두 데이터가 같은 세트를 두고 다투며 서로 쫓아내는 미스는 충돌 미스입니다. 연관도를 높여 같은 세트에 둘 이상을 둘 수 있게 하거나, 배열의 시작 위치를 어긋나게 하여 다른 세트에 대응시키면 줄일 수 있습니다. 용량 미스는 작업 집합(working set)이 캐시 전체보다 큰 것이 원인이며, 완전 연관으로 해도 줄지 않습니다. 강제 미스는 처음 접근할 때 일어나는 것으로, 반복되는 접근에는 해당하지 않습니다.

  • A. 강제 미스는 처음 접근했을 때만 일어납니다.
  • B. 용량 미스는 캐시 전체가 부족할 때의 미스입니다.
  • C. 올바릅니다. 같은 세트를 두고 다투는 충돌 미스입니다.

메모리 계층 구조의 다른 문제

  1. 프로그램이 어떤 데이터에 처음 접근했을 때 일어나는 캐시 미스를 줄이는 방법으로 효과가 있는 것은 무엇입니까?
  2. 캐시를 완전 연관 방식으로 해도 줄지 않는 미스로 올바른 것은 무엇입니까?
  3. 캐시의 라인 크기를 키웠을 때의 영향으로 올바른 것은 무엇입니까?
  4. 라이트 스루(write-through) 캐시에서 쓰기 버퍼(write buffer)를 두는 주된 목적은 무엇입니까?
  5. 라이트 백(write-back) 캐시에서 각 라인에 붙이는 더티 비트(dirty bit)의 역할로 올바른 것은 무엇입니까?

이 분야의 비교

  • 라이트스루 vs 라이트백 캐시: 차이점 설명라이트스루와 라이트백 캐시를 표로 비교합니다: 쓰기 정책, 메모리 트래픽, 속도, 일관성, 복잡도, 축출 비용, 대표 용도.
  • 직접 사상 vs 세트 연관 vs 완전 연관 캐시직접 사상, 세트 연관, 완전 연관 캐시를 표로 비교합니다: 블록 배치 위치, 태그 비교, 속도, 비용, 충돌 미스, 용도.
