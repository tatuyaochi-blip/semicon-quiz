메모리 계층 구조

캐시의 히트 시간이 2사이클, 미스율이 4%, 미스 페널티가 150사이클일 때, 평균 메모리 접근 시간은 몇 사이클인가?

  1. A8사이클
  2. B6사이클
  3. C152사이클
정답과 해설 보기

정답: A. 8사이클

평균 메모리 접근 시간 = 히트 시간 + 미스율 × 미스 페널티 = 2 + 0.04 × 150 = 2 + 6 = 8사이클입니다. 히트 시간은 모든 접근에서 소요되고, 미스했을 때만 미스 페널티가 더해진다고 생각합니다. 6사이클은 미스 분량만 계산하고 히트 시간을 더하는 것을 잊은 값입니다. 152사이클은 미스한 접근 1회에 걸리는 시간이며 평균이 아닙니다. 미스율이 겨우 4%여도 평균이 4배가 된다는 것을 알 수 있습니다.

메모리 계층 구조의 다른 문제

  1. 캐시가 이상적이면 평균 CPI가 1.0인 프로세서에서, 명령 1개당 평균 1.3회의 메모리 접근이 있고 그 미스율이 2%, 미스 페널티가 100사이클일 때, 실제 평균 CPI는 얼마인가?
  2. 논블로킹 캐시(미스를 처리하는 중에도 다른 접근을 받아들이는 캐시)의 주된 이점은?
  3. L1 캐시의 미스율(전체 접근에 대한 비율)이 4%, L2 캐시의 글로벌 미스율(전체 접근 중 L2에서도 미스하는 비율)이 1%일 때, L2의 로컬 미스율은 얼마인가?
  4. TLB의 엔트리가 64개이고 페이지 크기가 4 KB일 때, TLB 미스 없이 접근할 수 있는 메모리 범위(TLB 리치)는 얼마인가?
  5. 큰 페이지(Huge Page)를 사용하는 주된 이점과 단점의 조합으로 올바른 것은?
