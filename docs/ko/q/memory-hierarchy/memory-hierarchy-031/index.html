메모리 계층 구조

캐시의 각 라인에 붙는 유효 비트(valid bit)의 역할로 올바른 것은?

  1. A그 라인이 변경되었는지를 나타낸다
  2. B그 라인을 다음에 쫓아낼 순서를 나타낸다
  3. C의미 있는 데이터가 들어 있는지를 나타낸다
정답과 해설 보기

정답: C. 의미 있는 데이터가 들어 있는지를 나타낸다

전원을 켠 직후나 라인을 무효화한 뒤에는 캐시의 내용이 의미 없는 값입니다. 유효 비트가 0인 라인은 태그가 우연히 일치해도 히트로 간주되지 않으며, 올바른 데이터를 읽어 왔을 때 1이 됩니다. 이로써 빈 라인을 잘못하여 히트로 판정하는 것을 막습니다. 변경되었는지를 나타내는 것은 라이트 백 방식에서 사용하는 더티 비트이고, 쫓아낼 순서는 LRU 등 교체를 위한 정보가 관리합니다.

메모리 계층 구조의 다른 문제

  1. 소용량 풀 어소시에이티브 방식 버퍼에 L1 캐시에서 쫓겨난 라인을 임시로 보관하는 빅팀 캐시의 주된 효과는?
  2. L1 캐시 아래에 L2 캐시를 두는 다단 캐시에서 L2 캐시의 주된 역할은?
  3. 하위 캐시(L2 등)가 상위 캐시(L1)의 내용을 모두 포함하는 인클루시브 방식의 특징으로 올바른 것은?
  4. 다이렉트 매핑 방식에서 세트 어소시에이티브 방식으로 바꿨을 때 일어나는 변화로 올바른 것은?
  5. 8웨이 세트 어소시에이티브 방식 캐시에서 한 번 접근할 때마다 병렬로 비교하는 태그의 수는 몇 개인가?

이 분야의 비교

  • 라이트스루 vs 라이트백 캐시: 차이점 설명라이트스루와 라이트백 캐시를 표로 비교합니다: 쓰기 정책, 메모리 트래픽, 속도, 일관성, 복잡도, 축출 비용, 대표 용도.
  • 직접 사상 vs 세트 연관 vs 완전 연관 캐시직접 사상, 세트 연관, 완전 연관 캐시를 표로 비교합니다: 블록 배치 위치, 태그 비교, 속도, 비용, 충돌 미스, 용도.
