하드웨어 프리페치가 특히 효과를 발휘하기 쉬운 접근은 무엇입니까?

  1. A배열을 일정한 간격(스트라이드)으로 차례로 읽어 나가는 접근
  2. B연결 리스트를 처음부터 한 요소씩 따라가는 접근
  3. C해시 테이블을 임의의 키로 조회하는 접근
정답과 해설 보기

정답: A. 배열을 일정한 간격(스트라이드)으로 차례로 읽어 나가는 접근

하드웨어 프리페처는 직전 접근 주소의 규칙성(연속이나 일정한 간격)을 찾아내어 다음에 올 주소를 예측해 미리 읽어 옵니다. 배열을 일정한 스트라이드로 읽는 접근은 예측하기 쉬워 효과가 큽니다. 연결 리스트는 다음 요소의 주소를 현재 요소를 읽기 전까지 알 수 없으므로 규칙성이 없어 예측할 수 없습니다. 임의의 키로 해시 테이블을 참조하는 것도 주소에 규칙성이 없어 효과가 작습니다.

  • A. 올바릅니다. 규칙적인 간격의 접근은 예측하기 쉬워 효과가 큽니다.
  • B. 다음 주소를 현재 요소를 읽기 전까지 알 수 없으므로 예측할 수 없습니다.
  • C. 주소에 규칙성이 없으므로 효과가 작습니다.
