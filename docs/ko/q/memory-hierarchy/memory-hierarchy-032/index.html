메모리 계층 구조

소용량 풀 어소시에이티브 방식 버퍼에 L1 캐시에서 쫓겨난 라인을 임시로 보관하는 빅팀 캐시의 주된 효과는?

  1. A쫓아낸 직후 다시 사용하는 라인을 빠르게 되찾을 수 있어 충돌 미스의 손실을 줄일 수 있다
  2. BL1 캐시의 용량을 키운 것과 같은 정도로 용량 미스를 줄일 수 있다
  3. C초기 참조 미스를 없애고 프리페치를 불필요하게 한다
정답과 해설 보기

정답: A. 쫓아낸 직후 다시 사용하는 라인을 빠르게 되찾을 수 있어 충돌 미스의 손실을 줄일 수 있다

다이렉트 매핑 방식 등에서는 같은 세트를 두고 다투는 데이터가 서로 쫓아내며, 방금 쫓아낸 라인을 곧바로 다시 사용하는 일이 자주 있습니다. 빅팀 캐시는 쫓겨난 라인을 몇 개~십수 개 보관하여, L1에서 미스해도 거기에 있으면 하위 계층보다 빠르게 되찾을 수 있습니다. 작기 때문에 용량 미스를 크게 줄이는 효과는 없고, 한 번도 읽지 않은 데이터의 초기 참조 미스에도 효과가 없습니다.

메모리 계층 구조의 다른 문제

  1. L1 캐시 아래에 L2 캐시를 두는 다단 캐시에서 L2 캐시의 주된 역할은?
  2. 하위 캐시(L2 등)가 상위 캐시(L1)의 내용을 모두 포함하는 인클루시브 방식의 특징으로 올바른 것은?
  3. 다이렉트 매핑 방식에서 세트 어소시에이티브 방식으로 바꿨을 때 일어나는 변화로 올바른 것은?
  4. 8웨이 세트 어소시에이티브 방식 캐시에서 한 번 접근할 때마다 병렬로 비교하는 태그의 수는 몇 개인가?
  5. 라인 크기 64바이트, 세트 수 64인 캐시에서 주소 0x1234의 데이터가 들어가는 세트 번호는?

이 분야의 비교

  • 라이트스루 vs 라이트백 캐시: 차이점 설명라이트스루와 라이트백 캐시를 표로 비교합니다: 쓰기 정책, 메모리 트래픽, 속도, 일관성, 복잡도, 축출 비용, 대표 용도.
  • 직접 사상 vs 세트 연관 vs 완전 연관 캐시직접 사상, 세트 연관, 완전 연관 캐시를 표로 비교합니다: 블록 배치 위치, 태그 비교, 속도, 비용, 충돌 미스, 용도.
