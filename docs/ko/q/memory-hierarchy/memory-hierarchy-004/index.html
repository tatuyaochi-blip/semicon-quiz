메모리 계층 구조

주소가 32비트, 용량 32 KB, 라인 크기 64바이트인 4웨이 세트 어소시에이티브 방식 캐시의 세트 수는 얼마인가?

  1. A128
  2. B512
  3. C32
정답과 해설 보기

정답: A. 128

라인 수는 32 KB ÷ 64 B = 512입니다. 4웨이에서는 하나의 세트에 4개의 라인이 들어가므로 세트 수는 512 ÷ 4 = 128 = 2⁷이 되고, 인덱스는 7비트, 태그는 32 − 7 − 6 = 19비트가 됩니다. 512는 라인 수 자체이며 다이렉트 매핑일 때의 세트 수입니다. 연관도를 높이면 세트 수가 줄고 그만큼 태그 비트 수가 늘어나며 비교기도 늘어납니다. 32는 세트 수 128을 다시 웨이 수 4로 나누어 버린 값입니다.

관련 계산 도구

메모리 계층 구조의 다른 문제

  1. 풀 어소시에이티브 방식 캐시에서 주소 중 인덱스(세트를 선택하는 부분)에 사용하는 비트 수는?
  2. L1 캐시의 히트 시간이 1 ns, 미스율이 5%, L2 캐시의 히트 시간이 10 ns, L2의 로컬 미스율이 20%, 주기억장치의 접근 시간이 100 ns일 때, 평균 메모리 접근 시간은 얼마인가?
  3. 다이렉트 매핑 방식 캐시에서 두 배열의 요소가 같은 캐시 위치에 대응하여, 번갈아 접근할 때마다 서로를 쫓아내고 있다. 이 미스의 분류는?
  4. 프로그램이 어떤 데이터에 처음 접근했을 때 일어나는 캐시 미스를 줄이는 방법으로 효과가 있는 것은?
  5. 캐시를 풀 어소시에이티브 방식으로 해도 줄지 않는 미스로 올바른 것은?

이 분야의 비교

  • 라이트스루 vs 라이트백 캐시: 차이점 설명라이트스루와 라이트백 캐시를 표로 비교합니다: 쓰기 정책, 메모리 트래픽, 속도, 일관성, 복잡도, 축출 비용, 대표 용도.
  • 직접 사상 vs 세트 연관 vs 완전 연관 캐시직접 사상, 세트 연관, 완전 연관 캐시를 표로 비교합니다: 블록 배치 위치, 태그 비교, 속도, 비용, 충돌 미스, 용도.
  • L1, L2, L3 캐시의 차이점 정리L1, L2, L3 캐시를 일반적인 PC·서버 CPU를 예로 표로 비교합니다. 용량과 레이턴시, 코어별 또는 공유, 명령어와 데이터의 분리, 포함 관계, 설계에서 중시하는 점을 다룹니다.
