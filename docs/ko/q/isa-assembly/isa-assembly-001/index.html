ISA와 어셈블리

동일한 명령어 집합 아키텍처(ISA)를 채택한 두 CPU에 대해 올바른 것은?

  1. A같은 회로 구성으로 만들어지므로 성능도 소비 전력도 같다
  2. B내부 회로 구성이 달라도 같은 기계어 프로그램을 실행할 수 있다
  3. C같은 반도체 공장에서 같은 제조 공정을 사용해 만들어야 한다
정답과 해설 보기

정답: B. 내부 회로 구성이 달라도 같은 기계어 프로그램을 실행할 수 있다

ISA는 명령어의 종류, 명령어의 비트 배치, 레지스터의 수 등을 정한 소프트웨어와 하드웨어 사이의 약속입니다. 파이프라인 단수, 캐시 크기, 분기 예측 방식 같은 내부 구조는 마이크로아키텍처라고 하며 ISA와 별도로 결정됩니다. 그래서 같은 ISA라도 작은 저전력 코어와 큰 고성능 코어가 있어 성능도 전력도 다르지만 같은 기계어 프로그램이 동작합니다. 제조 공장이나 공정도 ISA와는 관계가 없습니다.
