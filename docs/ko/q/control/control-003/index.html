제어 공학의 기초

전향 경로의 전달 함수가 G(s), 피드백 경로의 전달 함수가 H(s)인 부귀환 블록 선도가 있다. 목표값 R(s)에서 출력 Y(s)까지의 폐루프 전달 함수 Y(s)/R(s)로 올바른 것은?

  1. AG(s)/(1 − G(s)H(s))
  2. BG(s)H(s)/(1 + G(s)H(s))
  3. CG(s)/(1 + G(s)H(s))
정답과 해설 보기

정답: C. G(s)/(1 + G(s)H(s))

편차는 E(s) = R(s) − H(s)Y(s), 출력은 Y(s) = G(s)E(s)입니다. 두 식에서 E(s)를 소거하면 Y(s) = G(s)R(s) − G(s)H(s)Y(s)가 되고, Y(s)/R(s) = G(s)/(1 + G(s)H(s))를 얻습니다. 분모의 G(s)H(s)는 신호가 루프를 한 바퀴 돌 때의 전달 함수로, 루프 전달 함수(개루프 전달 함수)라고 부릅니다. H(s) = 1인 단위 피드백에서는 G(s)/(1 + G(s))가 됩니다.

제어 공학의 기초의 다른 문제

  1. 전향 이득 G = 100, 피드백 이득 H = 0.1인 부귀환 시스템이 있다. 부품 열화로 G가 50으로 반감했을 때, 폐루프 이득의 감소 비율에 가장 가까운 것은?
  2. 초기값을 모두 0으로 할 때, 시간 함수의 미분과 적분을 라플라스 변환한 s 영역에서 나타내는 계산의 조합으로 올바른 것은?
  3. 전달 함수 G(s) = 5/(s + 2)인 시스템에 크기 1의 계단 입력을 가했다. 출력의 최종값(t → ∞에서의 값)으로 올바른 것은?
  4. 선형 시불변 시스템의 전달 함수 설명으로 올바른 것은?
  5. 전달 함수 G(s) = 2/(1 + 0.5s)인 1차 지연계에 시각 0에서 크기 1의 계단 입력을 가했다. t = 1 s에서의 출력에 가장 가까운 것은?
