제어 공학의 기초

루프 전달 함수가 K/(s(s + 1)(s + 2))인 단위 피드백 시스템이 있다. 폐루프 시스템이 안정해지는 K의 범위로 올바른 것은?

  1. A0 < K < 2
  2. B0 < K < 3
  3. C0 < K < 6
정답과 해설 보기

정답: C. 0 < K < 6

특성 방정식은 s(s + 1)(s + 2) + K = s³ + 3s² + 2s + K = 0입니다. 라우스-후르비츠 안정 판별법에 따르면 3차 방정식 s³ + a₂s² + a₁s + a₀ = 0이 안정할 조건은 계수가 모두 양이고 a₂a₁ > a₀인 것이므로, 3 × 2 > K, 즉 0 < K < 6입니다. K = 6에서는 극점이 s = ±j√2에 와서 각주파수 약 1.41 rad/s(주기 약 4.4 s)의 지속 진동이 됩니다. K가 이보다 크면 진동이 계속 커집니다.
