제어 공학의 기초

전달 함수 G(s) = 25/(s² + 4s + 25)인 2차 지연계의 고유 각주파수 ωn과 감쇠비 ζ의 조합으로 올바른 것은?

  1. Aωn = 5 rad/s, ζ = 0.4
  2. Bωn = 5 rad/s, ζ = 0.8
  3. Cωn = 25 rad/s, ζ = 0.08
정답과 해설 보기

정답: A. ωn = 5 rad/s, ζ = 0.4

표준형 ωn²/(s² + 2ζωn s + ωn²)과 비교하면 ωn² = 25에서 ωn = 5 rad/s입니다. s의 계수는 2ζωn = 4이므로 ζ = 4/(2 × 5) = 0.4가 됩니다. 극점은 s = −2 ± j4.58이며, 실수부 −ζωn = −2가 감쇠의 빠르기를, 허수부 ωn√(1 − ζ²) ≈ 4.58 rad/s가 진동의 각주파수를 나타냅니다.
