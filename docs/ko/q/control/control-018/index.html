제어 공학의 기초

폐루프 시스템의 특성 방정식이 다음과 같을 때, 안정한 시스템은?

  1. As² + 3s + 2 = 0
  2. Bs² − 3s + 2 = 0
  3. Cs² + 4 = 0
정답과 해설 보기

정답: A. s² + 3s + 2 = 0

s² + 3s + 2 = (s + 1)(s + 2)이므로 극점은 s = −1, −2이고, 둘 다 실수부가 음이므로 안정합니다. s² − 3s + 2 = (s − 1)(s − 2)의 극점은 s = 1, 2이고 응답이 지수 함수적으로 커지므로 불안정합니다. s² + 4 = 0의 극점은 s = ±j2이고, 각주파수 2 rad/s의 진동이 감쇠하지 않고 계속됩니다. 2차 특성 방정식에서는 계수가 모두 같은 부호이고 빠진 항이 없는 것이 안정의 필요충분조건이 됩니다.
