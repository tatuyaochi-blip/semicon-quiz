SRAM과 플래시 메모리

NOR형과 비교했을 때 NAND형 플래시 메모리의 특징으로 올바른 것은?

  1. A랜덤 액세스가 빠르고 프로그램 코드의 직접 실행에 적합하다
  2. B메모리 셀을 직렬로 연결하기 때문에 고집적화가 쉽고 대용량 스토리지에 적합하다
  3. C전원을 끄면 데이터가 사라지는 휘발성 메모리이다
정답과 해설 보기

정답: B. 메모리 셀을 직렬로 연결하기 때문에 고집적화가 쉽고 대용량 스토리지에 적합하다

NAND형은 메모리 셀을 수십 개 직렬로 연결하고 셀마다 있는 콘택트를 생략했기 때문에 1비트당 면적이 작아 대용량화에 적합하며, SSD와 메모리 카드에 사용됩니다. 대신 읽기는 직렬로 연결된 셀을 거쳐야 하므로 느리고 페이지 단위로 접근합니다. NOR형은 각 셀이 비트선에 병렬로 연결되어 있어 랜덤 읽기가 빠르고 코드의 직접 실행에 적합합니다. 둘 다 비휘발성입니다.

이 분야의 비교

  • NAND 플래시와 NOR 플래시의 차이와 용도NAND와 NOR 플래시 메모리를 표로 비교합니다. 셀 연결 방식, 읽기·쓰기 속도, 소거 단위, 집적도, 비용, 신뢰성, 대표 용도를 다룹니다.
  • SLC, MLC, TLC, QLC 낸드의 차이점SLC, MLC, TLC, QLC 낸드 플래시를 표로 비교합니다. 셀당 비트 수, 내구성, 속도, 비용, 오류율, 각 유형을 쓰는 SSD를 다룹니다.
  • SSD vs HDD: 속도, 내구성, 비용의 차이SSD와 HDD를 표로 비교합니다: 데이터 저장 방식, 속도, 지연 시간, 내구성, 소음, 전력, 테라바이트당 비용, 용량, 수명, 적합한 용도.
