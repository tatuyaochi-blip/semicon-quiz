SRAM과 플래시 메모리

NAND 플래시 컨트롤러에서 다치화에 따른 읽기 오류 증가에 대응하기 위해 사용되는 기술은?

  1. A데이터 암호화
  2. B강력한 오류 정정 부호(LDPC 부호 등)
  3. C클럭 고속화
정답과 해설 보기

정답: B. 강력한 오류 정정 부호(LDPC 부호 등)

1셀에 많은 비트를 기억할수록 문턱 전압 분포의 간격이 좁아져 읽기 오류가 늘어납니다. 그래서 NAND 컨트롤러는 수 KB의 데이터에 수백 바이트의 검사 비트를 붙이는 LDPC 부호 등의 강력한 오류 정정을 사용합니다. LDPC는 「얼마나 확실한가」라는 연판정 정보를 사용할 수 있기 때문에, 읽기 전압을 조금씩 바꿔 다시 읽어 정정 능력을 더욱 높입니다.

SRAM과 플래시 메모리의 다른 문제

  1. NOR형 플래시 메모리의 대표적인 용도는?
  2. SSD의 가비지 컬렉션에 대한 설명으로 올바른 것은?
  3. SRAM 읽기에서 비트선을 미리 전원 전압 등으로 충전해 두는 동작을 무엇이라고 부릅니까?
  4. NAND형 플래시 메모리의 쓰기(프로그램)에서 주로 사용되는 전자 주입 방식은?
  5. NAND 플래시에서 같은 블록을 여러 번 읽는 동안, 읽지 않은 셀의 문턱 전압이 조금씩 변해 버리는 현상을 무엇이라고 부릅니까?

이 분야의 비교

  • NAND 플래시와 NOR 플래시의 차이와 용도NAND와 NOR 플래시 메모리를 표로 비교합니다. 셀 연결 방식, 읽기·쓰기 속도, 소거 단위, 집적도, 비용, 신뢰성, 대표 용도를 다룹니다.
  • SLC, MLC, TLC, QLC 낸드의 차이점SLC, MLC, TLC, QLC 낸드 플래시를 표로 비교합니다. 셀당 비트 수, 내구성, 속도, 비용, 오류율, 각 유형을 쓰는 SSD를 다룹니다.
  • SSD vs HDD: 속도, 내구성, 비용의 차이SSD와 HDD를 표로 비교합니다: 데이터 저장 방식, 속도, 지연 시간, 내구성, 소음, 전력, 테라바이트당 비용, 용량, 수명, 적합한 용도.
