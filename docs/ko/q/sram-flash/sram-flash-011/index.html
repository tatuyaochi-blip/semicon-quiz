SRAM과 플래시 메모리

플래시 메모리의 데이터 보존(리텐션) 특성이 나빠지기 쉬운 조건은 무엇입니까?

  1. A저온에서 보관했을 때
  2. B어두운 곳에서 보관했을 때
  3. C고온에서 보관했을 때
정답과 해설 보기

정답: C. 고온에서 보관했을 때

저장된 전자는 온도가 높을수록 열에너지를 얻어 절연막을 빠져나가기 쉬워지므로, 고온에서 보관하면 데이터 보존 기간이 짧아집니다. 이 성질을 이용해 고온에서 보관하여 짧은 시간에 장기 보존을 추정하는 가속 시험(아레니우스 모델)이 이루어집니다. 재기록을 반복하여 산화막이 열화되어 있으면 보존 특성이 더욱 나빠지므로, 많이 사용한 SSD를 장기간 통전하지 않고 방치하는 것은 피하는 것이 무난합니다.

SRAM과 플래시 메모리의 다른 문제

  1. 최근 첨단 공정에서 로직 회로에 비해 SRAM 셀의 면적이 축소되기 어려워지고 있는 이유로 가장 적절한 것은 무엇입니까?
  2. NAND 플래시 컨트롤러에서 다치화에 따른 읽기 오류 증가에 대응하기 위해 사용되는 기술은 무엇입니까?
  3. NOR형 플래시 메모리의 대표적인 용도는 무엇입니까?
  4. SSD의 가비지 컬렉션의 설명으로 올바른 것은 무엇입니까?
  5. SRAM 읽기에서 비트 라인을 미리 전원 전압 등으로 충전해 두는 동작을 무엇이라고 합니까?

이 분야의 비교

  • NAND 플래시와 NOR 플래시의 차이와 용도NAND와 NOR 플래시 메모리를 표로 비교합니다. 셀 연결 방식, 읽기·쓰기 속도, 소거 단위, 집적도, 비용, 신뢰성, 대표 용도를 다룹니다.
  • SLC, MLC, TLC, QLC 낸드의 차이점SLC, MLC, TLC, QLC 낸드 플래시를 표로 비교합니다. 셀당 비트 수, 내구성, 속도, 비용, 오류율, 각 유형을 쓰는 SSD를 다룹니다.
  • SSD vs HDD: 속도, 내구성, 비용의 차이SSD와 HDD를 표로 비교합니다: 데이터 저장 방식, 속도, 지연 시간, 내구성, 소음, 전력, 테라바이트당 비용, 용량, 수명, 적합한 용도.
