SRAM과 플래시 메모리

NAND형 플래시 메모리에서 데이터 읽기와 쓰기(프로그램)를 수행하는 기본 단위는 무엇입니까?

  1. A블록
  2. B페이지
  3. C칩 전체
정답과 해설 보기

정답: B. 페이지

NAND에서 읽기와 쓰기는 페이지(수 KB~십수 KB, 최근에는 16 KB 안팎) 단위, 소거는 수백 페이지의 블록 단위로 수행합니다. 페이지는 워드 라인 1개 분량의 셀에 대응하며, 다치 셀에서는 워드 라인 1개에 여러 페이지(TLC라면 3페이지)가 할당됩니다. 쓰기와 소거의 단위가 다르다는 것이 가비지 컬렉션 등의 관리가 필요한 근본적인 이유입니다.

SRAM과 플래시 메모리의 다른 문제

  1. 고속 SSD와 호스트의 접속에 널리 사용되는, PCI Express를 이용한 인터페이스 규격은 무엇입니까?
  2. SRAM에서 대기 중에 전원 전압을 낮춰 누설 전류를 줄일 때의 하한을 정하는 '데이터 유지 전압'의 설명으로 올바른 것은 무엇입니까?
  3. 6T SRAM 셀에서 읽기 시 셀의 내용이 반전되지 않도록(읽기 파괴를 방지하도록) 필요한 설계로 올바른 것은 무엇입니까?
  4. 저전압에서 SRAM의 쓰기 실패를 막는 '쓰기 어시스트'의 예로 올바른 것은 무엇입니까?
  5. 다치(MLC나 TLC) NAND 플래시에서 이웃한 문턱 전압 상태에 할당하는 비트 배열을 1비트만 다르게 하는 이유로 올바른 것은 무엇입니까?

이 분야의 비교

  • NAND 플래시와 NOR 플래시의 차이와 용도NAND와 NOR 플래시 메모리를 표로 비교합니다. 셀 연결 방식, 읽기·쓰기 속도, 소거 단위, 집적도, 비용, 신뢰성, 대표 용도를 다룹니다.
  • SLC, MLC, TLC, QLC 낸드의 차이점SLC, MLC, TLC, QLC 낸드 플래시를 표로 비교합니다. 셀당 비트 수, 내구성, 속도, 비용, 오류율, 각 유형을 쓰는 SSD를 다룹니다.
  • SSD vs HDD: 속도, 내구성, 비용의 차이SSD와 HDD를 표로 비교합니다: 데이터 저장 방식, 속도, 지연 시간, 내구성, 소음, 전력, 테라바이트당 비용, 용량, 수명, 적합한 용도.
