SRAM과 플래시 메모리

SRAM의 전원 전압을 낮춰 갈 때 일어나기 쉬운 문제로 올바른 것은?

  1. A읽기·쓰기 안정성의 여유(노이즈 마진)가 작아져 오동작하기 쉬워진다
  2. B액세스가 너무 빨라진다
  3. C기억 용량이 늘어난다
정답과 해설 보기

정답: A. 읽기·쓰기 안정성의 여유(노이즈 마진)가 작아져 오동작하기 쉬워진다

SRAM 셀은 래치의 안정성과 액세스 트랜지스터와의 구동력 균형으로 동작합니다. 전원 전압을 낮추면 노이즈 마진이 작아지고 트랜지스터의 편차가 상대적으로 크게 작용하여, 읽기 시 데이터 반전이나 쓰기 실패가 일어나기 쉬워집니다. 그래서 SRAM의 최저 동작 전압(Vmin)이 칩 전체의 전원 전압 하한을 결정하는 경우가 많아, 저전압화의 벽이 되고 있습니다.

SRAM과 플래시 메모리의 다른 문제

  1. 6T SRAM에 읽기 전용 트랜지스터를 추가한 8T SRAM 셀의 장점으로 올바른 것은?
  2. 플래시 메모리의 소거에서 플로팅 게이트 등으로부터 전자를 빼내면 셀의 문턱 전압은 어떻게 됩니까?
  3. 최근 3D NAND의 적층 수로 가장 가까운 것은?
  4. NAND 플래시에서 직렬로 연결된 메모리 셀의 양 끝에 설치되는 선택 트랜지스터의 역할로 올바른 것은?
  5. SRAM 셀에 쓸 때는 비트선의 한쪽을 0 V로 끌어내려 셀의 상태를 반전시킵니다. 이때 액세스 트랜지스터에 요구되는 조건으로 올바른 것은?

이 분야의 비교

  • NAND 플래시와 NOR 플래시의 차이와 용도NAND와 NOR 플래시 메모리를 표로 비교합니다. 셀 연결 방식, 읽기·쓰기 속도, 소거 단위, 집적도, 비용, 신뢰성, 대표 용도를 다룹니다.
  • SLC, MLC, TLC, QLC 낸드의 차이점SLC, MLC, TLC, QLC 낸드 플래시를 표로 비교합니다. 셀당 비트 수, 내구성, 속도, 비용, 오류율, 각 유형을 쓰는 SSD를 다룹니다.
  • SSD vs HDD: 속도, 내구성, 비용의 차이SSD와 HDD를 표로 비교합니다: 데이터 저장 방식, 속도, 지연 시간, 내구성, 소음, 전력, 테라바이트당 비용, 용량, 수명, 적합한 용도.
