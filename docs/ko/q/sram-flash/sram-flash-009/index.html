SRAM과 플래시 메모리

SRAM의 성질로 올바른 것은 무엇입니까?

  1. A전원이 켜져 있는 동안은 리프레시 없이 데이터를 유지하지만, 전원을 끄면 데이터를 잃는다
  2. B전원을 꺼도 데이터가 남는다
  3. C정기적인 리프레시가 필요하다
정답과 해설 보기

정답: A. 전원이 켜져 있는 동안은 리프레시 없이 데이터를 유지하지만, 전원을 끄면 데이터를 잃는다

SRAM은 래치 회로의 양의 피드백으로 데이터를 유지하므로 전원이 켜져 있는 한 리프레시가 필요 없지만, 휘발성이어서 전원을 끄면 사라집니다. 액세스는 1 ns 안팎으로 고속이며 CPU의 캐시나 레지스터 파일에 사용됩니다. 대기 중에도 트랜지스터의 누설 전류가 흐르므로 대용량이 되면 대기 전력이 문제가 되어, 전원을 낮춰 유지하는 저전력 모드가 사용됩니다.

SRAM과 플래시 메모리의 다른 문제

  1. 3D NAND에서 많이 사용되는 전하 트랩형 셀에서, 전하를 저장하는 층의 재료로 일반적인 것은 무엇입니까?
  2. 플래시 메모리의 데이터 보존(리텐션) 특성이 나빠지기 쉬운 조건은 무엇입니까?
  3. 최근 첨단 공정에서 로직 회로에 비해 SRAM 셀의 면적이 축소되기 어려워지고 있는 이유로 가장 적절한 것은 무엇입니까?
  4. NAND 플래시 컨트롤러에서 다치화에 따른 읽기 오류 증가에 대응하기 위해 사용되는 기술은 무엇입니까?
  5. NOR형 플래시 메모리의 대표적인 용도는 무엇입니까?

이 분야의 비교

  • NAND 플래시와 NOR 플래시의 차이와 용도NAND와 NOR 플래시 메모리를 표로 비교합니다. 셀 연결 방식, 읽기·쓰기 속도, 소거 단위, 집적도, 비용, 신뢰성, 대표 용도를 다룹니다.
  • SLC, MLC, TLC, QLC 낸드의 차이점SLC, MLC, TLC, QLC 낸드 플래시를 표로 비교합니다. 셀당 비트 수, 내구성, 속도, 비용, 오류율, 각 유형을 쓰는 SSD를 다룹니다.
