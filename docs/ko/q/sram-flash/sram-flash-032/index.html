SRAM과 플래시 메모리

USB 메모리나 SD 카드에 주로 사용되는 메모리는?

  1. ASRAM
  2. BNAND형 플래시 메모리
  3. CDRAM
정답과 해설 보기

정답: B. NAND형 플래시 메모리

USB 메모리나 SD 카드, SSD에는 대용량이고 저렴한 비휘발성 메모리인 NAND 플래시가 사용되며, 내부에는 NAND 칩과 오류 정정이나 웨어 레벨링을 담당하는 컨트롤러가 들어 있습니다. 저가 제품은 컨트롤러가 단순하여 장기 보존 신뢰성이 낮은 경우도 있습니다. DRAM이나 SRAM은 휘발성이라 전원을 끄면 데이터가 사라지므로 휴대용 기억 매체에는 사용되지 않습니다.

  • A. SRAM은 휘발성이며 주로 캐시 등에 사용됩니다.
  • B. 올바릅니다. 대용량이고 비휘발성인 NAND형 플래시가 사용됩니다.
  • C. DRAM은 휘발성이며 주로 메인 메모리로 사용됩니다.
