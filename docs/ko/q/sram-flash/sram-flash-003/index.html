SRAM과 플래시 메모리

플래시 메모리에서 하나의 메모리 셀에 3비트의 정보를 기억하는 방식을 무엇이라고 합니까?

  1. ASLC
  2. BMLC
  3. CTLC
정답과 해설 보기

정답: C. TLC

셀당 비트 수에 따라 SLC(1비트), MLC(2), TLC(3), QLC(4)라고 부릅니다. TLC에서는 8개의 문턱 전압 상태를 구별하며, 같은 셀 수로 SLC의 3배 용량이 됩니다. 비트 수가 많을수록 저렴하지만 상태 간격이 좁아지므로 재기록 횟수, 속도, 데이터 보존 면에서 불리합니다. 현재 일반적인 SSD는 TLC가 주류이며, 대용량용으로 QLC도 늘고 있습니다.

SRAM과 플래시 메모리의 다른 문제

  1. 플래시 메모리의 데이터 쓰기·지우기 원리로 올바른 것은 무엇입니까?
  2. 3D NAND형 플래시 메모리의 설명으로 올바른 것은 무엇입니까?
  3. 플래시 메모리의 재기록 가능 횟수에 상한이 있는 주된 이유는 무엇입니까?
  4. SSD 등에서 사용되는 웨어 레벨링의 목적으로 올바른 것은 무엇입니까?
  5. NAND형 플래시 메모리에서 데이터를 지우는 단위로 올바른 것은 무엇입니까?

이 분야의 비교

  • NAND 플래시와 NOR 플래시의 차이와 용도NAND와 NOR 플래시 메모리를 표로 비교합니다. 셀 연결 방식, 읽기·쓰기 속도, 소거 단위, 집적도, 비용, 신뢰성, 대표 용도를 다룹니다.
  • SLC, MLC, TLC, QLC 낸드의 차이점SLC, MLC, TLC, QLC 낸드 플래시를 표로 비교합니다. 셀당 비트 수, 내구성, 속도, 비용, 오류율, 각 유형을 쓰는 SSD를 다룹니다.
  • SSD vs HDD: 속도, 내구성, 비용의 차이SSD와 HDD를 표로 비교합니다: 데이터 저장 방식, 속도, 지연 시간, 내구성, 소음, 전력, 테라바이트당 비용, 용량, 수명, 적합한 용도.
