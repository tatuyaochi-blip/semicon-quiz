SRAM과 플래시 메모리

저전압에서 SRAM의 쓰기 실패를 막는 '쓰기 어시스트'의 예로 올바른 것은 무엇입니까?

  1. A쓰기 시 0 쪽 비트 라인을 약간 음의 전압으로 끌어내린다
  2. B셀의 전원 전압을 쓰기 시에 올린다
  3. C워드 라인의 전압을 낮춘다
정답과 해설 보기

정답: A. 쓰기 시 0 쪽 비트 라인을 약간 음의 전압으로 끌어내린다

저전압에서는 액세스 트랜지스터의 구동력이 부족해 셀의 풀업을 이기지 못하고 쓰기에 실패하기 쉬워집니다. 0을 쓰는 쪽 비트 라인을 음의 전압(−100~−200 mV 정도)까지 끌어내리는 네거티브 비트 라인 방식에서는 액세스 트랜지스터의 게이트-소스 간 전압이 늘어 쓰기가 쉬워집니다. 쓰기 시 셀의 전원 전압을 낮춰 풀업을 약하게 하는 방식도 사용되며, 첨단 공정의 SRAM에서는 이러한 어시스트 회로가 빠질 수 없습니다.

SRAM과 플래시 메모리의 다른 문제

  1. 다치(MLC나 TLC) NAND 플래시에서 이웃한 문턱 전압 상태에 할당하는 비트 배열을 1비트만 다르게 하는 이유로 올바른 것은 무엇입니까?
  2. 3D NAND에서 쌓아 올린 각 층의 워드 라인에 배선을 연결하기 위해 끝부분을 계단 모양으로 가공한 구조를 무엇이라고 합니까?
  3. 3D NAND에서 메모리 셀 어레이 아래에 센스 앰프 등 주변 회로를 배치하는 구조(CMOS under Array 등)의 주된 이점은 무엇입니까?
  4. 일반적인 6트랜지스터형 SRAM 셀의 구성으로 올바른 것은 무엇입니까?
  5. NOR형과 비교했을 때 NAND형 플래시 메모리의 특징으로 올바른 것은 무엇입니까?

이 분야의 비교

  • NAND 플래시와 NOR 플래시의 차이와 용도NAND와 NOR 플래시 메모리를 표로 비교합니다. 셀 연결 방식, 읽기·쓰기 속도, 소거 단위, 집적도, 비용, 신뢰성, 대표 용도를 다룹니다.
  • SLC, MLC, TLC, QLC 낸드의 차이점SLC, MLC, TLC, QLC 낸드 플래시를 표로 비교합니다. 셀당 비트 수, 내구성, 속도, 비용, 오류율, 각 유형을 쓰는 SSD를 다룹니다.
  • SSD vs HDD: 속도, 내구성, 비용의 차이SSD와 HDD를 표로 비교합니다: 데이터 저장 방식, 속도, 지연 시간, 내구성, 소음, 전력, 테라바이트당 비용, 용량, 수명, 적합한 용도.
