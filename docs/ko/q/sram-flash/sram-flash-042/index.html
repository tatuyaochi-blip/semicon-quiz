SRAM과 플래시 메모리

SSD의 '쓰기 증폭(Write Amplification)'의 설명으로 올바른 것은 무엇입니까?

  1. A쓰기 속도가 2배가 되는 것
  2. B쓰기 전압이 평소보다 높아지는 것
  3. C호스트가 쓴 데이터량보다 플래시 메모리에 실제로 쓰이는 데이터량이 많아지는 것
정답과 해설 보기

정답: C. 호스트가 쓴 데이터량보다 플래시 메모리에 실제로 쓰이는 데이터량이 많아지는 것

플래시는 덮어쓰기가 불가능하고 소거가 블록 단위이므로, 가비지 컬렉션에서 유효한 데이터를 다른 블록으로 복사하는 등 추가 쓰기가 발생하여 실제 쓰기량이 호스트의 쓰기량보다 많아집니다. 이 비율이 쓰기 증폭 계수(WAF)이며, 랜덤한 작은 쓰기가 많으면 몇 배가 되기도 합니다. TRIM, 여분 영역, 데이터 압축 등으로 줄여 수명과 성능을 지킵니다.

SRAM과 플래시 메모리의 다른 문제

  1. NAND형 플래시 메모리에서 데이터 읽기와 쓰기(프로그램)를 수행하는 기본 단위는 무엇입니까?
  2. 고속 SSD와 호스트의 접속에 널리 사용되는, PCI Express를 이용한 인터페이스 규격은 무엇입니까?
  3. SRAM에서 대기 중에 전원 전압을 낮춰 누설 전류를 줄일 때의 하한을 정하는 '데이터 유지 전압'의 설명으로 올바른 것은 무엇입니까?
  4. 6T SRAM 셀에서 읽기 시 셀의 내용이 반전되지 않도록(읽기 파괴를 방지하도록) 필요한 설계로 올바른 것은 무엇입니까?
  5. 저전압에서 SRAM의 쓰기 실패를 막는 '쓰기 어시스트'의 예로 올바른 것은 무엇입니까?

이 분야의 비교

  • NAND 플래시와 NOR 플래시의 차이와 용도NAND와 NOR 플래시 메모리를 표로 비교합니다. 셀 연결 방식, 읽기·쓰기 속도, 소거 단위, 집적도, 비용, 신뢰성, 대표 용도를 다룹니다.
  • SLC, MLC, TLC, QLC 낸드의 차이점SLC, MLC, TLC, QLC 낸드 플래시를 표로 비교합니다. 셀당 비트 수, 내구성, 속도, 비용, 오류율, 각 유형을 쓰는 SSD를 다룹니다.
  • SSD vs HDD: 속도, 내구성, 비용의 차이SSD와 HDD를 표로 비교합니다: 데이터 저장 방식, 속도, 지연 시간, 내구성, 소음, 전력, 테라바이트당 비용, 용량, 수명, 적합한 용도.
