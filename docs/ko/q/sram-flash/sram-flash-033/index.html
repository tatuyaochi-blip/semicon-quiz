SRAM과 플래시 메모리

SLC(Single-Level Cell)형 플래시 메모리는 하나의 셀에 몇 비트를 기억합니까?

  1. A2비트
  2. B4비트
  3. C1비트
정답과 해설 보기

정답: C. 1비트

SLC는 하나의 셀에 1비트(2상태)를 기억합니다. 상태를 구별하기 쉬우므로 쓰기가 빠르고, 재기록 횟수는 약 10만 회로 많으며, 데이터 보존이나 고온에도 강한 반면, 같은 셀 수에서의 용량은 가장 작습니다. 그래서 산업 기기나 차량용 등 높은 신뢰성이 요구되는 용도에 사용됩니다. MLC는 2비트, TLC는 3비트, QLC는 4비트입니다.

SRAM과 플래시 메모리의 다른 문제

  1. HDD(하드 디스크)와 비교했을 때 SSD의 특징으로 올바른 것은 무엇입니까?
  2. SRAM이 주로 사용되는 용도로 가장 적절한 것은 무엇입니까?
  3. NAND형 플래시 메모리에서 이미 데이터가 쓰인 페이지에 새 데이터를 쓸 때 필요한 것은 무엇입니까?
  4. EEPROM과 플래시 메모리의 차이로 올바른 것은 무엇입니까?
  5. SRAM 셀의 안정성을 나타내는 정적 노이즈 마진(SNM)의 설명으로 올바른 것은 무엇입니까?

이 분야의 비교

  • NAND 플래시와 NOR 플래시의 차이와 용도NAND와 NOR 플래시 메모리를 표로 비교합니다. 셀 연결 방식, 읽기·쓰기 속도, 소거 단위, 집적도, 비용, 신뢰성, 대표 용도를 다룹니다.
  • SLC, MLC, TLC, QLC 낸드의 차이점SLC, MLC, TLC, QLC 낸드 플래시를 표로 비교합니다. 셀당 비트 수, 내구성, 속도, 비용, 오류율, 각 유형을 쓰는 SSD를 다룹니다.
  • SSD vs HDD: 속도, 내구성, 비용의 차이SSD와 HDD를 표로 비교합니다: 데이터 저장 방식, 속도, 지연 시간, 내구성, 소음, 전력, 테라바이트당 비용, 용량, 수명, 적합한 용도.
