상시 인버터 급전 방식 UPS(무정전 전원 장치)의 특징으로 적절한 것은?

  1. A평상시에도 상용 전원을 일단 직류로 변환하고 인버터로 교류로 되돌려 급전하므로, 정전 시 전환에 의한 순간 정전이 없고 전압이나 주파수 변동의 영향도 받기 어렵다
  2. B평상시에는 상용 전원을 그대로 급전하고 정전을 검출한 뒤에 인버터 급전으로 전환하므로, 전환하는 순간에 짧은 순간 정전이 일어날 수 있다
  3. C연료를 계속 보급하면 정전이 며칠 계속되어도 급전을 계속할 수 있다
정답과 해설 보기

정답: A. 평상시에도 상용 전원을 일단 직류로 변환하고 인버터로 교류로 되돌려 급전하므로, 정전 시 전환에 의한 순간 정전이 없고 전압이나 주파수 변동의 영향도 받기 어렵다

상시 인버터 급전 방식(온라인 방식)의 UPS는 상용 전원을 정류기로 직류로 만들고, 축전지를 충전하면서 인버터로 안정된 교류를 만들어 항상 급전합니다. 정전되어도 축전지에서 인버터로의 급전이 계속될 뿐이므로 전환에 의한 순간 정전이 없고, 전압이나 주파수의 흐트러짐도 기기에 잘 전달되지 않기 때문에 서버 등에 널리 사용됩니다. 한편 항상 변환을 하므로 상시 상용 급전 방식보다 전력 손실이 커집니다. 긴 시간의 정전에는 UPS가 급전하는 동안 기동하는 자가 발전 설비로 대비합니다.
