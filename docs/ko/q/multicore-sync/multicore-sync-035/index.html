정답: B. 필요한 순서 보장만 선택함으로써 불필요한 배리어를 피해 성능을 유지할 수 있기 때문

원자적 변수의 연산은 기본적으로 순차 일관성(memory_order_seq_cst)이며, 가장 이해하기 쉬운 대신 배리어의 부담이 커집니다. 단순한 카운터라면 불가분이기만 하면 되므로 relaxed, 데이터를 주고받는 플래그라면 acquire와 release로 충분합니다. 컴파일러는 지정에 맞추어 CPU의 메모리 모델에 필요한 최소한의 명령을 내보냅니다.
