멀티코어와 동기화

Linux의 NUMA 시스템에서 흔히 쓰이는 퍼스트 터치 정책(처음 페이지에 쓴 스레드가 실행 중인 노드의 메모리에 그 페이지를 배치)에서 주의할 점으로 올바른 것은 무엇입니까?

  1. A퍼스트 터치에서는 페이지가 무작위 노드에 배치된다
  2. Bmalloc을 호출한 시점에 모든 페이지의 배치 위치가 정해진다
  3. C큰 배열을 하나의 스레드만으로 0으로 초기화하면 전부 하나의 노드에 배치되어, 다른 노드의 스레드가 먼 메모리를 사용하게 된다
정답과 해설 보기

정답: C. 큰 배열을 하나의 스레드만으로 0으로 초기화하면 전부 하나의 노드에 배치되어, 다른 노드의 스레드가 먼 메모리를 사용하게 된다

malloc으로 확보했을 뿐으로는 물리 페이지가 할당되지 않고, 처음 쓸 때의 페이지 폴트로 그 스레드가 있는 노드의 메모리에 배치됩니다. 그래서 초기화를 하나의 스레드로 수행하면 배열 전체가 그 노드에 모이고, 병렬 계산에서 각 스레드가 담당하는 부분의 상당수가 먼 메모리가 됩니다. 초기화도 계산과 같은 분담으로 병렬로 수행하면 각 부분이 담당 스레드 가까이에 배치됩니다.

멀티코어와 동기화의 다른 문제

  1. 병렬 프로그램에서 코어 수를 늘려도 성능이 기대만큼 늘지 않는 원인에 해당하지 않는 것은 무엇입니까?
  2. 루프의 반복을 여러 스레드로 나눌 때, 반복마다 계산량이 크게 편차를 보이는 경우에 적합한 분할 방법은 무엇입니까?
  3. 배열의 모든 요소의 합계를 여러 스레드로 구할 때, 성능을 위해 적합한 방법은 무엇입니까?
  4. 읽기-쓰기 락(리더-라이터 락)의 특징으로 올바른 것은 무엇입니까?
  5. 카운터가 있는 세마포어의 사용법으로 가장 적절한 것은 무엇입니까?
