반도체 산업과 시장

CPU 등의 설계 자산(IP)을 다른 회사에 라이선스하여 사용료를 받는 비즈니스 모델의 기업을 무엇이라고 합니까?

  1. A파운드리
  2. BIP 벤더
  3. COSAT
정답과 해설 보기

정답: B. IP 벤더

IP 벤더는 CPU 코어나 인터페이스 회로 등의 설계 자산을 개발하여 반도체 기업에 라이선스하고, 계약 시의 라이선스료와 제품별 사용료(로열티)를 받습니다. 스마트폰 프로세서의 대부분은 IP 벤더로부터 라이선스를 받은 CPU 코어를 사용합니다. IP를 활용하면 반도체 기업은 개발 기간과 비용을 줄일 수 있습니다. 파운드리는 제조를, OSAT는 후공정을 위탁받습니다.

반도체 산업과 시장의 다른 문제

  1. 반도체가 다양한 제품에 필수적인 기초 부품이라는 점에서 일본에서 비유하여 불러 온 표현은?
  2. 메모리 반도체 시장에서 매출의 대부분을 차지하는 두 제품의 조합으로 올바른 것은?
  3. 대만에 본사를 두고 파운드리(반도체 위탁 제조)로서 세계 최대 점유율을 가진 기업은?
  4. 2020년부터 2021년경에 일어난 반도체 부족에서 자동차 생산이 큰 영향을 받은 이유로 적절한 것은?
  5. 가전제품이나 자동차 등의 기기에 내장되어 그 제어를 담당하는, CPU와 메모리, 입출력 회로를 1칩으로 합친 작은 컴퓨터는?
