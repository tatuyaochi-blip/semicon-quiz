패키징과 조립

반도체 패키지의 주된 역할을 올바르게 조합한 것은?

  1. A칩을 외부 환경으로부터 보호하고, 인쇄 회로 기판과 전기적으로 연결하며, 발생한 열을 방출한다
  2. B칩의 회로를 설계한다
  3. C칩 안의 트랜지스터를 늘린다
정답과 해설 보기

정답: A. 칩을 외부 환경으로부터 보호하고, 인쇄 회로 기판과 전기적으로 연결하며, 발생한 열을 방출한다

패키지는 깨지기 쉬운 칩을 수분, 충격, 빛과 오염으로부터 보호하고, 칩 위의 수십 µm 간격 전극을 인쇄 회로 기판에서 솔더링할 수 있는 0.4~1 mm 정도 간격의 단자로 변환하며, 칩에서 발생한 열을 외부로 방출하는 역할을 합니다. 최근에는 여러 칩을 고밀도로 연결하는 첨단 패키지가 성능을 좌우하게 되어, 패키지는 단순한 용기가 아니게 되었습니다.

  • A. 올바릅니다. 보호, 전기적 접속, 방열이 주된 역할입니다.
  • B. 회로 설계는 설계 공정에서 이루어집니다.
  • C. 트랜지스터 수는 칩 제조 공정에서 결정됩니다.
