패키징과 조립

흡습한 수지 패키지를 솔더 리플로로 가열했을 때 내부 수분이 급격히 기화·팽창하여 패키지가 깨지는 현상을 무엇이라 하는가?

  1. A위스커
  2. B팝콘 현상
  3. C스티션
정답과 해설 보기

정답: B. 팝콘 현상

수지 패키지는 보관 중에 공기 중의 수분을 흡수합니다. 그 상태에서 리플로의 약 260 ℃에 노출되면 내부 수분이 급격히 수증기가 되어 팽창하고 수지의 박리나 크랙을 일으킵니다. 소리를 내며 깨지기 때문에 팝콘 현상이라고 하며, 방습 포장과 개봉 후 방치 시간 관리, 필요하면 실장 전 베이킹으로 방지합니다. 위스커는 주석 도금에서 자라나는 바늘 모양 결정, 스티션은 MEMS의 달라붙음입니다.

패키징과 조립의 다른 문제

  1. 와이어 본딩에서 금(Au) 와이어에서 구리(Cu) 와이어로의 대체가 진행된 주된 이유는?
  2. 패키지의 방열 성능을 나타내는, 칩 접합부에서 주위 공기까지의 열저항을 나타내는 기호는?
  3. 인쇄 회로 기판에 솔더 페이스트를 인쇄하고 부품을 올린 뒤 노에서 가열하여 솔더링하는 방법은?
  4. 프로세서 패키지 위에 메모리 패키지를 겹쳐 실장하는 방식을 무엇이라 하는가?
  5. 패키지 양쪽에 2열로 핀을 배열하고 기판의 구멍에 꽂아 실장하는 오래된 패키지는?

이 분야의 비교

  • 와이어 본딩 vs 플립 칩: 칩 인터커넥트 비교와이어 본딩과 플립 칩을 표로 비교합니다: 칩 연결 방식, I/O 수, 전기적 성능, 비용, 크기, 공정, 대표 용도.
  • BGA vs QFP vs QFN: IC 패키지 유형 비교BGA, QFP, QFN 패키지를 표로 비교합니다: 단자, 핀 수, 피치, 크기, 전기적 및 열 성능, 검사, 주요 용도.
