플립칩 실장에 대한 설명으로 올바른 것은?

  1. A칩을 수지로 봉지하지 않고 출하하는 방식
  2. B칩의 회로면을 아래로 향하게 하여 범프로 기판과 직접 연결하는 방식
  3. C칩을 기판에 대해 수직으로 세워 실장하는 방식
정답과 해설 보기

정답: B. 칩의 회로면을 아래로 향하게 하여 범프로 기판과 직접 연결하는 방식

플립칩은 칩의 회로면에 형성한 솔더나 구리 필러 범프를 통해 칩을 뒤집은 상태로 기판과 연결하는 방식입니다. 와이어보다 연결이 짧아 인덕턴스가 작으므로 고속 신호와 전원 공급에 유리하고, 칩 전면에 단자를 배열할 수 있어 수천 단자의 다핀화에도 적합합니다. 1960년대에 IBM이 개발한 C4가 기원입니다. 봉지하지 않고 출하하는 것이나 수직으로 세우는 실장과는 관계가 없습니다.
