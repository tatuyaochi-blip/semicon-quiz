플립칩 실장에 대한 설명으로 올바른 것은?

  1. A칩을 수지로 봉지하지 않고 출하하는 방식
  2. B칩의 회로면을 아래로 향하게 하여 범프로 기판과 직접 접속하는 방식
  3. C칩을 기판에 대해 수직으로 세워 실장하는 방식
정답과 해설 보기

정답: B. 칩의 회로면을 아래로 향하게 하여 범프로 기판과 직접 접속하는 방식

플립칩은 칩의 회로면에 형성한 솔더나 구리 필러 범프를 통해 칩을 뒤집은 상태로 기판과 접속하는 방식입니다. 와이어보다 접속이 짧아 인덕턴스가 작으므로 고속 신호나 전원 공급에 유리하고, 칩 전면에 단자를 배치할 수 있어 수천 단자의 다핀화에도 적합합니다. 1960년대 IBM이 개발한 C4가 기원입니다. 봉지 없는 출하나 수직으로 세우는 실장과는 관계가 없습니다.

패키징과 조립의 다른 문제

  1. BGA(볼 그리드 어레이) 패키지의 특징으로 올바른 것은?
  2. 다이싱에 대한 설명으로 올바른 것은?
  3. 일반적인 수지 봉지 패키지의 봉지재로 주로 사용되는 재료는?
  4. 리드프레임의 재료로 일반적으로 사용되는 것은?
  5. CSP(칩 사이즈 패키지)에 대한 설명으로 올바른 것은?

이 분야의 비교

  • 와이어 본딩 vs 플립 칩: 칩 인터커넥트 비교와이어 본딩과 플립 칩을 표로 비교합니다: 칩 연결 방식, I/O 수, 전기적 성능, 비용, 크기, 공정, 대표 용도.
  • BGA vs QFP vs QFN: IC 패키지 유형 비교BGA, QFP, QFN 패키지를 표로 비교합니다: 단자, 핀 수, 피치, 크기, 전기적 및 열 성능, 검사, 주요 용도.
  • 볼 본딩 vs 웨지 본딩: 재료·공정·방향성·용도 비교볼 본딩과 웨지 본딩을 표로 비교합니다: 접합 형태, 공구, 접합 에너지, 와이어 재료(Au·Cu와 Al·리본), 굵기, 방향성, 속도, 루프, 신뢰성, 용도. 각각을 언제 쓰는지도 설명합니다.
