패키징과 조립

플립칩 BGA 등에 사용되는, 절연층과 미세 배선층을 쌓아 만드는 유기 패키지 기판은?

  1. A리드 프레임
  2. B세라믹 단층판
  3. C빌드업 기판
정답과 해설 보기

정답: C. 빌드업 기판

빌드업 기판은 유리 에폭시 코어층의 양면에 절연 수지 필름과 미세한 구리 배선층을 한 층씩 쌓아 올려 만드는 기판입니다. 층간은 레이저로 뚫은 작은 비아로 연결하며, 수천 개 범프에서 나온 배선을 끌어와 인쇄 회로 기판의 넓은 피치로 확장합니다. 프로세서 등의 플립칩 BGA 기판으로 사용됩니다. 리드 프레임이나 단층 세라믹판으로는 이 정도 밀도의 배선을 만들 수 없습니다.
