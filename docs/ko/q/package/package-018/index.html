패키징과 조립

프로세서 패키지 위에 메모리 패키지를 겹쳐 실장하는 방식을 무엇이라고 합니까?

  1. AQFP
  2. BDIP
  3. CPoP(패키지 온 패키지)
정답과 해설 보기

정답: C. PoP(패키지 온 패키지)

PoP는 아래쪽 패키지(프로세서 등) 위에 다른 패키지(DRAM 등)를 겹쳐 솔더링하는 방식입니다. 기판상의 실장 면적을 줄일 수 있고 프로세서와 메모리 사이의 배선도 짧아지므로 스마트폰 등에 널리 쓰입니다. 메모리와 프로세서를 따로 시험한 뒤 겹칠 수 있어 양품끼리만 조합할 수 있다는 장점도 있습니다. QFP와 DIP는 단독 패키지의 형태입니다.

패키징과 조립의 다른 문제

  1. 패키지 양쪽에 핀을 2열로 배치하고 기판의 구멍에 꽂아 실장하는, 오래된 패키지는?
  2. 대형 패키지에서 리플로 시 가열로 인한 휨(워피지)이 문제가 되는 이유로 올바른 것은?
  3. 표면 실장 패키지에서 방습 포장을 개봉한 뒤 리플로까지 방치해도 되는 시간 등을 정한 흡습 관련 등급은?
  4. 발열이 큰 프로세서 패키지에서 칩 위에 올려 열을 퍼뜨리는 금속판을 무엇이라고 합니까?
  5. 플립칩 BGA 등에 사용되는, 절연층과 미세 배선층을 쌓아 만드는 유기 패키지 기판은?

  • 와이어 본딩 vs 플립 칩: 칩 인터커넥트 비교와이어 본딩과 플립 칩을 표로 비교합니다: 칩 연결 방식, I/O 수, 전기적 성능, 비용, 크기, 공정, 대표 용도.
  • BGA vs QFP vs QFN: IC 패키지 유형 비교BGA, QFP, QFN 패키지를 표로 비교합니다: 단자, 핀 수, 피치, 크기, 전기적 및 열 성능, 검사, 주요 용도.
