패키징과 조립

패키지 양쪽에 2열로 핀을 배열하고 기판의 구멍에 꽂아 실장하는 오래된 패키지는?

  1. ADIP(듀얼 인라인 패키지)
  2. BBGA
  3. CCSP
정답과 해설 보기

정답: A. DIP(듀얼 인라인 패키지)

DIP는 패키지 양쪽에서 2.54 mm 간격으로 2열의 핀을 내어 기판 구멍에 꽂아 솔더링하는 삽입 실장형 패키지입니다. 브레드보드에 그대로 꽂을 수 있어 시제품이나 교육용 등에서 지금도 사용됩니다. 다만 단자가 주변 2열로 제한되고 부품도 커서 다핀화나 소형화에는 적합하지 않아 표면 실장형 패키지가 주류가 되었습니다. BGA와 CSP는 표면 실장형입니다.

패키징과 조립의 다른 문제

  1. 대형 패키지에서 리플로 시 가열에 의한 휨(워페이지)이 문제가 되는 이유로 올바른 것은?
  2. 표면 실장 패키지에서 방습 포장을 개봉한 후 리플로까지 방치해도 되는 시간 등을 정한 흡습 관련 등급은?
  3. 발열이 큰 프로세서 패키지에서 칩 위에 올려 열을 확산시키는 금속 판을 무엇이라 하는가?
  4. 플립칩 BGA 등에서 사용되는, 절연층과 미세 배선층을 쌓아 만드는 유기 패키지 기판은?
  5. 금 와이어 끝을 방전으로 녹여 볼을 만들고 열과 초음파를 가해 전극에 접합하는 와이어 본딩 방식은?

이 분야의 비교

  • 와이어 본딩 vs 플립 칩: 칩 인터커넥트 비교와이어 본딩과 플립 칩을 표로 비교합니다: 칩 연결 방식, I/O 수, 전기적 성능, 비용, 크기, 공정, 대표 용도.
  • BGA vs QFP vs QFN: IC 패키지 유형 비교BGA, QFP, QFN 패키지를 표로 비교합니다: 단자, 핀 수, 피치, 크기, 전기적 및 열 성능, 검사, 주요 용도.
  • 볼 본딩 vs 웨지 본딩: 재료·공정·방향성·용도 비교볼 본딩과 웨지 본딩을 표로 비교합니다: 접합 형태, 공구, 접합 에너지, 와이어 재료(Au·Cu와 Al·리본), 굵기, 방향성, 속도, 루프, 신뢰성, 용도. 각각을 언제 쓰는지도 설명합니다.
