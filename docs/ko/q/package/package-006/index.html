패키징과 조립

리드프레임의 재료로 일반적으로 사용되는 것은?

  1. A구리 합금이나 철-니켈 합금(42 얼로이)
  2. B유리
  3. C에폭시 수지
정답과 해설 보기

정답: A. 구리 합금이나 철-니켈 합금(42 얼로이)

리드프레임은 칩을 올려놓고 외부 단자 역할도 하는 금속 프레임입니다. 전기와 열을 잘 전달하는 구리 합금과, 열팽창 계수가 실리콘에 가까운 철-니켈 합금(42 얼로이)이 대표적이며, 얇은 금속판을 프레스나 식각으로 가공하여 만듭니다. 표면에는 솔더링성과 와이어 접합성을 높이는 도금을 합니다. 유리나 에폭시 수지는 절연체이므로 단자가 될 수 없습니다.

패키징과 조립의 다른 문제

  1. CSP(칩 사이즈 패키지)에 대한 설명으로 올바른 것은?
  2. 웨이퍼 레벨 패키지(WLP)의 특징으로 올바른 것은?
  3. 플립칩 실장에서 칩과 기판 사이 틈에 언더필 수지를 충전하는 주된 목적은?
  4. 환경 규제에 대응한 무연 솔더로 널리 사용되는 조성은?
  5. QFN(Quad Flat No-lead) 패키지의 특징으로 올바른 것은?

이 분야의 비교

  • 와이어 본딩 vs 플립 칩: 칩 인터커넥트 비교와이어 본딩과 플립 칩을 표로 비교합니다: 칩 연결 방식, I/O 수, 전기적 성능, 비용, 크기, 공정, 대표 용도.
  • BGA vs QFP vs QFN: IC 패키지 유형 비교BGA, QFP, QFN 패키지를 표로 비교합니다: 단자, 핀 수, 피치, 크기, 전기적 및 열 성능, 검사, 주요 용도.
  • 볼 본딩 vs 웨지 본딩: 재료·공정·방향성·용도 비교볼 본딩과 웨지 본딩을 표로 비교합니다: 접합 형태, 공구, 접합 에너지, 와이어 재료(Au·Cu와 Al·리본), 굵기, 방향성, 속도, 루프, 신뢰성, 용도. 각각을 언제 쓰는지도 설명합니다.
