패키징과 조립

환경 규제에 대응한 무연 솔더로 널리 사용되는 조성은?

  1. ASn-Pb 공정
  2. BSn-Ag-Cu계
  3. CHg-Au계
정답과 해설 보기

정답: B. Sn-Ag-Cu계

EU의 RoHS 지침 등으로 납 사용이 제한되면서 주석·은·구리를 주성분으로 하는 Sn-Ag-Cu(SAC)계 솔더가 널리 사용되게 되었습니다. 대표적인 SAC305는 Sn-3.0%Ag-0.5%Cu이며 융점은 약 217~220 ℃로, Sn-Pb 공정 솔더의 183 ℃보다 높아 리플로 온도도 높아집니다. Hg-Au계는 솔더가 아닙니다.
