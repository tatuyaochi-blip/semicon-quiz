패키징과 조립

일반적인 수지 봉지 패키지의 봉지재로 주로 사용되는 재료는?

  1. A순수 구리
  2. B에폭시 수지
  3. C실리콘 단결정
정답과 해설 보기

정답: B. 에폭시 수지

수지 봉지 패키지에서는 실리카 필러를 70~90 wt% 정도 첨가한 에폭시 수지를 가열한 금형에 밀어 넣어 칩을 봉지합니다(트랜스퍼 몰드). 칩을 습기와 충격, 빛으로부터 보호하며, 필러로 열팽창 계수를 칩이나 기판에 가깝게 맞춥니다. 대형 패키지나 웨이퍼 레벨 봉지에서는 수지를 금형에 올려 압축하는 방식도 사용됩니다. 순수 구리나 단결정 실리콘은 봉지재가 아닙니다.

패키징과 조립의 다른 문제

  1. 리드프레임의 재료로 일반적으로 사용되는 것은?
  2. CSP(칩 사이즈 패키지)에 대한 설명으로 올바른 것은?
  3. 웨이퍼 레벨 패키지(WLP)의 특징으로 올바른 것은?
  4. 플립칩 실장에서 칩과 기판 사이 틈에 언더필 수지를 충전하는 주된 목적은?
  5. 환경 규제에 대응한 무연 솔더로 널리 사용되는 조성은?

이 분야의 비교

  • 와이어 본딩 vs 플립 칩: 칩 인터커넥트 비교와이어 본딩과 플립 칩을 표로 비교합니다: 칩 연결 방식, I/O 수, 전기적 성능, 비용, 크기, 공정, 대표 용도.
  • BGA vs QFP vs QFN: IC 패키지 유형 비교BGA, QFP, QFN 패키지를 표로 비교합니다: 단자, 핀 수, 피치, 크기, 전기적 및 열 성능, 검사, 주요 용도.
  • 볼 본딩 vs 웨지 본딩: 재료·공정·방향성·용도 비교볼 본딩과 웨지 본딩을 표로 비교합니다: 접합 형태, 공구, 접합 에너지, 와이어 재료(Au·Cu와 Al·리본), 굵기, 방향성, 속도, 루프, 신뢰성, 용도. 각각을 언제 쓰는지도 설명합니다.
