패키징과 조립

칩을 리드프레임이나 기판의 정해진 위치에 접착·고정하는 공정을 무엇이라 하는가?

  1. A와이어 본딩
  2. B다이싱
  3. C다이 본딩
정답과 해설 보기

정답: C. 다이 본딩

다이 본딩은 잘라낸 칩을 은 페이스트나 솔더, 다이 어태치 필름 등의 접착재로 리드프레임이나 기판에 고정하는 공정입니다. 전류와 발열이 큰 파워 디바이스에서는 열과 전기를 잘 전달하는 솔더나 소결 은을 사용하고, 칩을 쌓는 메모리에서는 두께를 균일하게 맞추기 쉬운 필름을 사용합니다. 이후 와이어 본딩으로 전기적으로 접속합니다. 다이싱은 절단하는 공정입니다.

패키징과 조립의 다른 문제

  1. 패키지를 얇게 만들기 위해 다이싱 전에 웨이퍼 뒷면을 연삭하여 얇게 하는 공정을 무엇이라 하는가?
  2. 흡습한 수지 패키지를 솔더 리플로로 가열했을 때 내부 수분이 급격히 기화·팽창하여 패키지가 깨지는 현상을 무엇이라 하는가?
  3. 와이어 본딩에서 금(Au) 와이어에서 구리(Cu) 와이어로의 대체가 진행된 주된 이유는?
  4. 패키지의 방열 성능을 나타내는, 칩 접합부에서 주위 공기까지의 열저항을 나타내는 기호는?
  5. 인쇄 회로 기판에 솔더 페이스트를 인쇄하고 부품을 올린 뒤 노에서 가열하여 솔더링하는 방법은?
