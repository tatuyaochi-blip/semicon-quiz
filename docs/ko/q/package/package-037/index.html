패키징과 조립

무연 솔더(Sn-Ag-Cu계)를 사용하는 리플로에서 부품이 받는 피크 온도의 기준으로 가장 가까운 것은?

  1. A약 500℃
  2. B약 100℃
  3. C약 245~260℃
정답과 해설 보기

정답: C. 약 245~260℃

Sn-Ag-Cu계 무연 솔더는 융점이 약 217~220 ℃이며, 확실하게 녹여 젖게 하기 위해 리플로 피크 온도를 약 245~260 ℃로 합니다. Sn-Pb 솔더(융점 183 ℃)의 피크는 220~235 ℃ 정도였으므로 부품의 내열성 기준이 260 ℃로 상향되었습니다. 고온일수록 흡습한 패키지의 파손이 일어나기 쉬워 MSL 관리가 더욱 중요해졌습니다.
