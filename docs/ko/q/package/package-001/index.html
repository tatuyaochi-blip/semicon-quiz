패키징과 조립

와이어 본딩에 대한 설명으로 올바른 것은?

  1. A칩의 전극 패드와 리드 프레임이나 기판을 금속 세선으로 연결하는 방법
  2. B칩을 뒤집어 범프로 기판과 직접 연결하는 방법
  3. C칩을 수지로 봉지하는 방법
정답과 해설 보기

정답: A. 칩의 전극 패드와 리드 프레임이나 기판을 금속 세선으로 연결하는 방법

와이어 본딩은 금·구리·알루미늄 등의 가는 와이어로 칩의 전극 패드와 리드 프레임이나 기판의 단자를 연결하는 방법입니다. 150~200 ℃ 정도로 가열하면서 압력과 초음파를 가해 금속끼리 접합합니다. 설비가 저렴하고 배선을 유연하게 할 수 있어, 생산 수량 기준으로는 지금도 가장 많이 쓰이는 연결 방법입니다. 칩을 뒤집어 범프로 연결하는 것은 플립칩, 수지로 감싸는 것은 몰드(봉지)입니다.

이 분야의 비교

  • 와이어 본딩 vs 플립 칩: 칩 인터커넥트 비교와이어 본딩과 플립 칩을 표로 비교합니다: 칩 연결 방식, I/O 수, 전기적 성능, 비용, 크기, 공정, 대표 용도.
