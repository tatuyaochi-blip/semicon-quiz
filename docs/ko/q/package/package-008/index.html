패키징과 조립

웨이퍼 레벨 패키지(WLP)의 특징으로 올바른 것은?

  1. A칩을 하나씩 잘라낸 뒤에 패키지를 조립한다
  2. B칩을 수지로 녹여 형태를 만든다
  3. C웨이퍼 상태 그대로 재배선과 외부 단자 형성을 수행한 뒤 개별화한다
정답과 해설 보기

정답: C. 웨이퍼 상태 그대로 재배선과 외부 단자 형성을 수행한 뒤 개별화한다

WLP에서는 다이싱하기 전 웨이퍼 상태에서 재배선층과 솔더 볼을 일괄 형성하고, 마지막에 개별 칩으로 잘라 나눕니다. 칩 면적 안에 단자를 수용하는 팬인과, 칩을 수지로 매립한 재구성 웨이퍼를 만들어 칩 바깥까지 배선을 넓히는 팬아웃이 있습니다. 팬아웃은 기판을 쓰지 않아 얇게 만들 수 있으므로 스마트폰 프로세서 등에도 사용됩니다.

패키징과 조립의 다른 문제

  1. 플립칩 실장에서 칩과 기판 사이의 틈에 언더필 수지를 충전하는 주된 목적은?
  2. 환경 규제에 대응한 무연 솔더로 널리 쓰이는 조성은?
  3. QFN(Quad Flat No-lead) 패키지의 특징으로 올바른 것은?
  4. 칩을 리드 프레임이나 기판의 정해진 위치에 접착·고정하는 공정을 무엇이라고 합니까?
  5. 패키지를 얇게 만들기 위해 다이싱 전에 웨이퍼 뒷면을 연삭하여 얇게 하는 공정을 무엇이라고 합니까?

이 분야의 비교

  • 와이어 본딩 vs 플립 칩: 칩 인터커넥트 비교와이어 본딩과 플립 칩을 표로 비교합니다: 칩 연결 방식, I/O 수, 전기적 성능, 비용, 크기, 공정, 대표 용도.
  • BGA vs QFP vs QFN: IC 패키지 유형 비교BGA, QFP, QFN 패키지를 표로 비교합니다: 단자, 핀 수, 피치, 크기, 전기적 및 열 성능, 검사, 주요 용도.
