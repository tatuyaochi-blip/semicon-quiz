패키징과 조립

와이어 본딩 시의 힘이나 초음파로 인해 전극 패드 아래의 절연막이나 실리콘이 깨지는 불량을 무엇이라고 합니까?

  1. A펀치스루
  2. B크레이터링(패드 아래의 균열)
  3. C디싱
정답과 해설 보기

정답: B. 크레이터링(패드 아래의 균열)

본딩 하중이나 초음파 에너지가 너무 크거나 와이어가 단단하면 패드 아래 층에 균열이 생겨 구덩이(크레이터)처럼 깨질 수 있습니다. 금보다 단단한 구리 와이어나, 기계적으로 약한 Low-k 막 위의 패드에서는 특히 주의가 필요합니다. 패드의 알루미늄을 두껍게 하거나, 패드 아래에 보강 구조를 넣거나, 접합 조건을 최적화하여 방지합니다.

  • A. 펀치스루는 트랜지스터의 소스와 드레인의 공핍층이 이어지는 현상입니다.
  • B. 올바릅니다. 패드 아래가 깨지는 불량입니다.
  • C. 디싱은 CMP에서 배선 중앙이 오목해지는 현상입니다.
