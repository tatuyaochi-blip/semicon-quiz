패키징과 조립

칩과 기판을 가열·가압하면서 하나씩 접합하며, 휨이 큰 얇은 칩이나 좁은 피치 범프의 접속에 사용되는 방법은?

  1. A리플로 솔더링
  2. B와이어 본딩
  3. C열압착 본딩(TCB)
정답과 해설 보기

정답: C. 열압착 본딩(TCB)

열압착 본딩에서는 본딩 헤드로 칩을 누르면서 가열·가압하여 범프를 칩 하나씩 접합합니다. 리플로 노에서 전체를 가열하는 방법과 달리 칩의 휨을 억제한 채 접합할 수 있고 위치도 정확하게 맞출 수 있어, HBM과 같은 얇은 칩의 적층이나 좁은 피치 마이크로 범프의 접속에 사용됩니다. 칩 하나씩 처리하므로 생산성은 리플로보다 낮아집니다.

패키징과 조립의 다른 문제

  1. 봉지 수지에 대량의 실리카 필러를 첨가하는 주된 목적은?
  2. 패키지나 인쇄 회로 기판에 디커플링 커패시터(바이패스 커패시터)를 배치하는 주된 목적은?
  3. 반도체 패키지의 주된 역할의 조합으로 올바른 것은?
  4. 완성된 IC 패키지 표면에 품명이나 로트 번호 등을 표시하는 공정으로 일반적인 것은?
  5. 와이어 본딩에서 사용되는 와이어 굵기로 일반적인 것은?

이 분야의 비교

  • 와이어 본딩 vs 플립 칩: 칩 인터커넥트 비교와이어 본딩과 플립 칩을 표로 비교합니다: 칩 연결 방식, I/O 수, 전기적 성능, 비용, 크기, 공정, 대표 용도.
  • BGA vs QFP vs QFN: IC 패키지 유형 비교BGA, QFP, QFN 패키지를 표로 비교합니다: 단자, 핀 수, 피치, 크기, 전기적 및 열 성능, 검사, 주요 용도.
