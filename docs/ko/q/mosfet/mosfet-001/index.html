MOSFET

인핸스먼트형 n채널 MOSFET이 켜지는(도통하는) 조건으로 올바른 것은 무엇입니까? (VGS: 게이트-소스 간 전압, Vth: 문턱 전압)

  1. AVGS가 0 V일 것
  2. BVGS가 Vth보다 클 것
  3. CVGS가 음의 전압일 것
정답과 해설 보기

정답: B. VGS가 Vth보다 클 것

인핸스먼트형 nMOSFET에서는 게이트에 Vth를 넘는 양의 전압을 가하면 p형 기판 표면에 전자가 끌려와 반전층(채널)이 생기고, 소스와 드레인 사이에 전류가 흐릅니다. VGS = 0 V에서는 채널이 없어 꺼져 있으므로 게이트가 플로팅되어도 전류가 흐르기 어렵고(노멀리 오프), 논리 회로나 파워 용도의 안전성에 적합합니다. Vth는 첨단 로직에서 0.2~0.4 V, 파워용에서 1~4 V 정도가 일반적입니다.

MOSFET의 다른 문제

  1. 게이트 절연막의 재료와 면적을 바꾸지 않고 막 두께만 얇게 하면, 단위 면적당 게이트 커패시턴스는 어떻게 됩니까?
  2. CMOS 인버터의 정적(정상 상태) 소비 전력이 작은 이유로 올바른 것은 무엇입니까?
  3. 장채널 MOSFET이 포화 영역에서 동작할 때, 드레인 전류 ID는 대략 무엇에 비례합니까? (VGS: 게이트-소스 간 전압, Vth: 문턱 전압)
  4. 같은 치수의 nMOS와 pMOS에서는 일반적으로 nMOS의 구동 전류가 더 큽니다. 그 주된 이유는 무엇입니까?
  5. n채널 MOSFET에서 소스에 대해 기판(바디)에 음의 전압을 가하면(기판 바이어스를 가하면) 문턱 전압은 어떻게 됩니까?

이 분야의 비교

  • JFET vs MOSFET: 차이점 설명JFET와 MOSFET을 표로 비교합니다: 게이트 구조, 노멀리 온/오프 동작, 게이트 전류, 노이즈, ESD 내성, 집적도, 대표 용도.
  • nMOS와 pMOS의 차이: 캐리어·이동도·문턱 전압·CMOS에서의 역할 비교nMOS와 pMOS를 구조, 캐리어, 이동도, 문턱 전압의 부호, 온이 되는 조건, CMOS에서의 역할, 잘 전달하는 논리 레벨, 같은 구동력에 필요한 게이트 폭 관점에서 표로 비교합니다.
  • 인핸스먼트형과 디플리션형 MOSFET의 차이: 문턱 전압·기호·용도 비교인핸스먼트형과 디플리션형 MOSFET을 게이트 0 V에서의 상태, 문턱 전압의 부호, 채널 형성 방식, 전류 차단 방법, 회로 기호, 안전성, 용도 관점에서 표로 비교합니다.
