MOSFET

MOSFET의 펀치스루의 설명으로 올바른 것은 무엇입니까?

  1. A채널의 이동도가 온도로 떨어지는 것
  2. B소스와 드레인의 공핍층이 이어져 게이트로 제어할 수 없는 전류가 흐르는 것
  3. C게이트 절연막이 절연 파괴되는 것
정답과 해설 보기

정답: B. 소스와 드레인의 공핍층이 이어져 게이트로 제어할 수 없는 전류가 흐르는 것

채널이 짧고 기판 농도가 낮으면 드레인 전압에 의해 드레인 쪽 공핍층이 소스 쪽 공핍층과 이어져, 게이트와 무관하게 기판 깊은 곳을 전류가 흘러 끌 수 없게 됩니다. 이것이 펀치스루입니다. 대책은 소스·드레인 아래에 고농도층(헤일로/포켓 주입)을 넣거나, 접합을 얕게 하거나, 나아가 FinFET이나 GAA처럼 게이트로 채널을 둘러싸 제어할 수 없는 전류 경로를 없애는 것입니다.

MOSFET의 다른 문제

  1. nMOSFET 1개만 사용한 패스 트랜지스터(스위치)에서 게이트를 전원 전압 VDD로 하고 입력의 VDD를 출력 쪽으로 전달할 때, 출력 전압은 대략 어디까지 올라갑니까?
  2. CMOS 인버터에서 입력이 전환되는 도중에 전원에서 그라운드로 흐르는 전류를 무엇이라고 합니까?
  3. 파워 MOSFET을 여러 개 병렬로 접속하여 사용하기 쉬운 이유로, 온 저항의 온도 의존성에 관한 설명으로 올바른 것은 무엇입니까?
  4. 데나드 스케일링 법칙(정전계 스케일링)에서 치수와 전압을 각각 1/k로 했을 때의 설명으로 올바른 것은 무엇입니까?
  5. MOS 구조의 플랫밴드 전압의 설명으로 올바른 것은 무엇입니까?

이 분야의 비교

  • JFET vs MOSFET: 차이점 설명JFET와 MOSFET을 표로 비교합니다: 게이트 구조, 노멀리 온/오프 동작, 게이트 전류, 노이즈, ESD 내성, 집적도, 대표 용도.
  • nMOS와 pMOS의 차이: 캐리어·이동도·문턱 전압·CMOS에서의 역할 비교nMOS와 pMOS를 구조, 캐리어, 이동도, 문턱 전압의 부호, 온이 되는 조건, CMOS에서의 역할, 잘 전달하는 논리 레벨, 같은 구동력에 필요한 게이트 폭 관점에서 표로 비교합니다.
  • 인핸스먼트형과 디플리션형 MOSFET의 차이: 문턱 전압·기호·용도 비교인핸스먼트형과 디플리션형 MOSFET을 게이트 0 V에서의 상태, 문턱 전압의 부호, 채널 형성 방식, 전류 차단 방법, 회로 기호, 안전성, 용도 관점에서 표로 비교합니다.
