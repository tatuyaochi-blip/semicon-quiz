MOSFET

포화 영역에 있는 MOSFET의 소신호 출력 저항 ro를 채널 길이 변조 계수 λ와 드레인 전류 ID로 나타낸 식으로 적절한 것은 무엇입니까?

  1. Aro ≈ 1 / (λ × ID)
  2. Bro ≈ ID / λ
  3. Cro ≈ λ × ID
정답과 해설 보기

정답: A. ro ≈ 1 / (λ × ID)

채널 길이 변조를 고려하면, 포화 영역의 드레인 전류는 ID(1 + λVDS) 형태로 VDS와 함께 약간 늘어나며, 이 기울기의 역수가 출력 저항 ro ≈ 1/(λID)입니다. λ는 채널 길이에 거의 반비례하므로 L을 2배로 하면 ro도 약 2배가 됩니다. 트랜지스터 단체의 최대 전압 이득은 gm·ro이며, 미세한 트랜지스터에서는 10~20배 정도밖에 안 되므로 캐스코드나 다단 구성으로 이득을 확보합니다.

MOSFET의 다른 문제

  1. MOSFET의 문턱 전압을 정의할 때 사용되는 '강반전'의 조건으로 일반적인 것은 무엇입니까? (φF: 페르미 전위)
  2. 인핸스먼트형 n채널 MOSFET이 켜지는(도통하는) 조건으로 올바른 것은 무엇입니까? (VGS: 게이트-소스 간 전압, Vth: 문턱 전압)
  3. 게이트 절연막의 재료와 면적을 바꾸지 않고 막 두께만 얇게 하면, 단위 면적당 게이트 커패시턴스는 어떻게 됩니까?
  4. CMOS 인버터의 정적(정상 상태) 소비 전력이 작은 이유로 올바른 것은 무엇입니까?
  5. 장채널 MOSFET이 포화 영역에서 동작할 때, 드레인 전류 ID는 대략 무엇에 비례합니까? (VGS: 게이트-소스 간 전압, Vth: 문턱 전압)
