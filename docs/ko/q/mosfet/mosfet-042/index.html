MOSFET

nMOSFET 1개만 사용한 패스 트랜지스터(스위치)에서 게이트를 전원 전압 VDD로 하고 입력의 VDD를 출력 쪽으로 전달할 때, 출력 전압은 대략 어디까지 올라갑니까?

  1. AVDD까지
  2. BVDD + Vth까지
  3. CVDD − Vth까지
정답과 해설 보기

정답: C. VDD − Vth까지

nMOS는 게이트-소스 간 전압이 Vth를 밑돌면 꺼지므로, 출력(소스 쪽)이 VDD − Vth에 가까워지면 전류가 거의 흐르지 않아 그 이상 올라가지 않습니다. 또한 소스 전위가 올라가면 바디 효과로 Vth도 올라가므로, 실제 도달 전압은 조금 더 낮아집니다. 약한 1은 다음 단의 pMOS를 완전히 끌 수 없어 누설 전류의 원인이 됩니다. 0은 완전히 전달되므로 pMOS와 조합한 트랜스미션 게이트가 사용됩니다.

MOSFET의 다른 문제

  1. CMOS 인버터에서 입력이 전환되는 도중에 전원에서 그라운드로 흐르는 전류를 무엇이라고 합니까?
  2. 파워 MOSFET을 여러 개 병렬로 접속하여 사용하기 쉬운 이유로, 온 저항의 온도 의존성에 관한 설명으로 올바른 것은 무엇입니까?
  3. 데나드 스케일링 법칙(정전계 스케일링)에서 치수와 전압을 각각 1/k로 했을 때의 설명으로 올바른 것은 무엇입니까?
  4. MOS 구조의 플랫밴드 전압의 설명으로 올바른 것은 무엇입니까?
  5. p형 기판의 MOS 커패시터를 고주파로 측정한 C-V 특성에서, 게이트에 큰 양의 전압을 가해 강반전시켰을 때 커패시턴스는 어떻게 됩니까?
