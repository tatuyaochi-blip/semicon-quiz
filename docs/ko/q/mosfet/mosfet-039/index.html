MOSFET

다른 조건을 바꾸지 않고 게이트 절연막을 두껍게 하면, nMOSFET의 문턱 전압의 크기는 일반적으로 어떻게 됩니까?

  1. A0이 된다
  2. B커진다
  3. C작아진다
정답과 해설 보기

정답: B. 커진다

게이트 절연막을 두껍게 하면 Cox가 작아져 같은 공핍층 전하를 지탱하는 데 필요한 게이트 전압이 늘어나므로, 문턱 전압의 크기는 커집니다(Vth = VFB + 2φF + Qd/Cox의 제3항이 증가). 같은 칩 안에서도 코어 회로에는 얇은 막, 1.8 V나 3.3 V의 입출력 회로에는 두꺼운 막의 트랜지스터를 구분하여 사용합니다(듀얼 게이트 산화막). 두꺼운 막의 트랜지스터는 내압이 높은 대신 느리고 Vth도 높은 편입니다.

MOSFET의 다른 문제

  1. MOSFET의 게이트 길이(마스크 상이나 가공 후 게이트 전극의 길이)와 실효 채널 길이의 관계로 일반적으로 올바른 것은 무엇입니까?
  2. MOSFET의 펀치스루의 설명으로 올바른 것은 무엇입니까?
  3. nMOSFET 1개만 사용한 패스 트랜지스터(스위치)에서 게이트를 전원 전압 VDD로 하고 입력의 VDD를 출력 쪽으로 전달할 때, 출력 전압은 대략 어디까지 올라갑니까?
  4. CMOS 인버터에서 입력이 전환되는 도중에 전원에서 그라운드로 흐르는 전류를 무엇이라고 합니까?
  5. 파워 MOSFET을 여러 개 병렬로 접속하여 사용하기 쉬운 이유로, 온 저항의 온도 의존성에 관한 설명으로 올바른 것은 무엇입니까?

이 분야의 비교

  • JFET vs MOSFET: 차이점 설명JFET와 MOSFET을 표로 비교합니다: 게이트 구조, 노멀리 온/오프 동작, 게이트 전류, 노이즈, ESD 내성, 집적도, 대표 용도.
  • nMOS와 pMOS의 차이: 캐리어·이동도·문턱 전압·CMOS에서의 역할 비교nMOS와 pMOS를 구조, 캐리어, 이동도, 문턱 전압의 부호, 온이 되는 조건, CMOS에서의 역할, 잘 전달하는 논리 레벨, 같은 구동력에 필요한 게이트 폭 관점에서 표로 비교합니다.
  • 인핸스먼트형과 디플리션형 MOSFET의 차이: 문턱 전압·기호·용도 비교인핸스먼트형과 디플리션형 MOSFET을 게이트 0 V에서의 상태, 문턱 전압의 부호, 채널 형성 방식, 전류 차단 방법, 회로 기호, 안전성, 용도 관점에서 표로 비교합니다.
