MOSFET

nMOS와 pMOS를 병렬로 접속한 트랜스미션 게이트의 이점으로 올바른 것은 무엇입니까?

  1. A0도 1도 전압 저하 없이 전달할 수 있다
  2. B신호 전류를 증폭할 수 있다
  3. C데이터를 기억할 수 있다
정답과 해설 보기

정답: A. 0도 1도 전압 저하 없이 전달할 수 있다

nMOS 단독으로는 1을 전달할 때 VDD − Vth에서 멈추고, pMOS 단독으로는 0을 전달할 때 |Vth|까지밖에 내려가지 않습니다. 둘을 병렬로 하여 상보적인 게이트 신호로 구동하면 서로의 약점을 보완하여 0도 1도 전압 저하 없이 전달할 수 있습니다. 양방향으로 신호를 통과시킬 수 있어 멀티플렉서, 래치, 아날로그 스위치(4066 등)에 사용됩니다. 다만 구동력은 없으며 여러 단을 직렬로 하면 느려지므로 버퍼를 끼웁니다.

MOSFET의 다른 문제

  1. MOSFET의 게이트-소스 간에 정격을 크게 넘는 전압을 가했을 때 발생할 수 있는 파괴는 무엇입니까?
  2. MOSFET 채널의 이동도가 실리콘 결정 내부의 이동도보다 작아지는 주된 이유로 올바른 것은 무엇입니까?
  3. 단채널 MOSFET에서 드레인 전류가 (VGS − Vth)의 제곱 법칙보다 작아지고 1제곱에 가까운 의존성을 보이게 되는 주된 원인은 무엇입니까?
  4. CMOS 논리 게이트의 지연 시간을 대략적으로 나타내는 식으로 적절한 것은 무엇입니까? (C: 부하 커패시턴스, V: 전원 전압, I: 구동 전류)
  5. 인핸스먼트형 p채널 MOSFET의 문턱 전압(소스 기준)의 부호는 무엇입니까?

  • JFET vs MOSFET: 차이점 설명JFET와 MOSFET을 표로 비교합니다: 게이트 구조, 노멀리 온/오프 동작, 게이트 전류, 노이즈, ESD 내성, 집적도, 대표 용도.
  • nMOS와 pMOS의 차이: 캐리어·이동도·문턱 전압·CMOS에서의 역할 비교nMOS와 pMOS를 구조, 캐리어, 이동도, 문턱 전압의 부호, 온이 되는 조건, CMOS에서의 역할, 잘 전달하는 논리 레벨, 같은 구동력에 필요한 게이트 폭 관점에서 표로 비교합니다.
