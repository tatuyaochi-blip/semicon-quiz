첨단 트랜지스터(FinFET과 GAA)

CFET(상보형 FET)에서 위아래로 쌓은 트랜지스터 중 아래층 트랜지스터로의 연결에 대해 올바른 것은?

  1. A아래층 트랜지스터는 게이트가 없으므로 소스와 드레인에만 연결하면 된다
  2. B바로 위에 위층 트랜지스터가 있으므로 앞면 쪽에서는 위층을 피해 연결을 통과시켜야 하며, 뒷면에서 아래층에 직접 연결하는 방식이 검토되고 있다
  3. C위아래 트랜지스터는 소스와 드레인을 모두 공유하므로 아래층에 개별 연결은 필요 없다
정답과 해설 보기

정답: B. 바로 위에 위층 트랜지스터가 있으므로 앞면 쪽에서는 위층을 피해 연결을 통과시켜야 하며, 뒷면에서 아래층에 직접 연결하는 방식이 검토되고 있다

CFET(상보형 FET)는 nMOS와 pMOS를 위아래로 쌓아 셀 면적을 줄이는 구조입니다. 위아래의 게이트나 출력은 공유할 수 있지만, 각각의 소스는 서로 다른 전원(VDD와 VSS)에 연결해야 합니다. 앞면 쪽에서 아래층에 연결하려면 위층 트랜지스터를 피해 콘택트를 깊게 통과시켜야 해서, 좁은 셀 안에서 배선이 혼잡해집니다. 그래서 웨이퍼 뒷면에서 아래층에 직접 연결하고 후면 전원 공급과 결합하는 방식이 검토되고 있으며, 2023년 IEDM에서는 Intel이 뒷면에서 아래층에 직접 연결한 CFET 인버터의 동작을 보고했습니다.
