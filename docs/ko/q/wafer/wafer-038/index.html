정답: A. 주형 안에서 융액을 한 방향으로 응고시키는 캐스트법

캐스트법(일방향 응고법)에서는 녹인 실리콘을 사각 주형 안에서 바닥부터 조금씩 굳혀 수백 kg~1톤의 큰 다결정 잉곳을 만듭니다. 사각형이라 셀을 배열했을 때 낭비가 적고 단결정보다 저렴하게 대량 생산할 수 있어 2010년대 전반까지 태양전지의 주류였습니다. 결정립계에서 효율이 떨어지므로 현재는 고효율 단결정(CZ)이 9할 이상을 차지합니다.

실리콘 웨이퍼의 다른 문제

  1. CZ법으로 단결정 인상을 마칠 때 잉곳 직경을 조금씩 가늘게 하여(테일을 좁혀) 융액에서 분리하는 주된 이유는?
  2. CZ법으로 성장시킨 실리콘 결정에 포함된 격자 간 산소 농도의 기준으로 가장 가까운 것은?
  3. 실리콘 웨이퍼의 경면 연마(CMP에 의한 마무리 연마)에서 연마액의 연마 입자로 일반적으로 사용되는 것은?
  4. 비소나 안티몬을 고농도로 첨가한 저저항 n⁺ 실리콘 웨이퍼의 주된 용도로 올바른 것은?
  5. CZ 실리콘을 450℃ 부근에서 열처리하면 산소 원자가 모여 도너로 작용하여 웨이퍼의 저항률이 변하는 경우가 있습니다. 이를 무엇이라고 합니까?
