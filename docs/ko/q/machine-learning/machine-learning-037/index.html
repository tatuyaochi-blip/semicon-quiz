머신러닝의 기초

이미지 등을 생성하는 모델에 대한 설명으로 적절한 것은?

  1. AGAN(생성적 적대 신경망)은 진짜와 가짜를 구별하는 판별자만 학습하고, 데이터를 만드는 생성자는 학습하지 않는다
  2. B확산 모델은 잡음을 제거하는 계산을 1회만 수행하여 이미지를 만들므로, 생성에 필요한 계산이 GAN보다 적다
  3. C확산 모델은 데이터에 잡음을 조금씩 더하는 과정을 생각하고, 그 잡음을 단계적으로 제거하는 처리를 학습하여 잡음으로부터 이미지를 생성한다
정답과 해설 보기

정답: C. 확산 모델은 데이터에 잡음을 조금씩 더하는 과정을 생각하고, 그 잡음을 단계적으로 제거하는 처리를 학습하여 잡음으로부터 이미지를 생성한다

GAN은 데이터를 만드는 생성자와, 진짜 데이터인지 생성자가 만든 데이터인지를 구별하는 판별자의 두 가지를 서로 경쟁시키듯이 번갈아 학습합니다. 확산 모델은 데이터에 잡음을 조금씩 더해 가는 과정을 거꾸로 거슬러 가도록, 각 단계에서 잡음을 추정하여 제거하는 네트워크를 학습하고, 순수한 잡음으로부터 단계적으로 데이터를 생성합니다. 확산 모델은 생성에 많은 단계의 계산이 필요하지만, 학습이 안정되기 쉽고 다양하고 질 높은 이미지를 만들기 쉬운 방법입니다.
