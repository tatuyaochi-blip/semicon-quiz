머신러닝의 기초

로지스틱 회귀에서 z = 2x − 4를 시그모이드 함수 σ(z) = 1 ÷ (1 + e^(−z))에 통과시킨 값을 양성일 확률로 출력한다. x = 2일 때의 출력은?

  1. A0
  2. B0.5
  3. C1
정답과 해설 보기

정답: B. 0.5

x = 2일 때 z = 2 × 2 − 4 = 0이므로, σ(0) = 1 ÷ (1 + e⁰) = 1 ÷ 2 = 0.5입니다. 시그모이드 함수는 어떤 실수든 0에서 1 사이의 값으로 변환하는 함수로, z가 클수록 1에, 작을수록 0에 가까워집니다. 로지스틱 회귀는 이 값을 양성일 확률로 보고 0.5 등의 임계값으로 2개의 클래스로 나누는 모델로, 이름에 '회귀'가 들어 있지만 분류를 위한 모델입니다.
