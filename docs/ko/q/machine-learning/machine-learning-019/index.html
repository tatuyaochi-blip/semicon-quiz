머신러닝의 기초

결정 트리의 어떤 노드에 클래스 A의 데이터가 6건, 클래스 B의 데이터가 4건 있다. 이 노드의 지니 불순도는?

  1. A0.24
  2. B0.40
  3. C0.48
정답과 해설 보기

정답: C. 0.48

지니 불순도는 각 클래스의 비율을 p로 하여 1 − Σp²로 구합니다. 클래스 A의 비율은 0.6, 클래스 B의 비율은 0.4이므로 1 − (0.36 + 0.16) = 0.48입니다. 하나의 클래스만 있는 노드에서는 0이 되고, 2클래스가 절반씩일 때 최대인 0.5가 됩니다. 결정 트리는 나눈 뒤의 자식 노드의 불순도(지니 불순도나 엔트로피)의 가중 평균이 가장 작아지도록 특성과 임계값을 골라 데이터를 나누어 갑니다.
