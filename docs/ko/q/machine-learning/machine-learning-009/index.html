머신러닝의 기초

모델의 오차를 편향(bias)과 분산(variance)으로 나누어 생각할 때 적절한 것은?

  1. A편향이 큰 모델은 학습용 데이터를 고르는 방법에 따라 예측이 크게 바뀌며, 과적합을 일으키기 쉽다
  2. B모델을 복잡하게 할수록 편향과 분산이 둘 다 작아지므로, 되도록 복잡한 모델을 사용하는 것이 좋다
  3. C모델을 복잡하게 하면 편향은 작아지기 쉽지만 분산은 커지기 쉬우므로, 둘의 균형이 맞는 복잡도를 고른다
정답과 해설 보기

정답: C. 모델을 복잡하게 하면 편향은 작아지기 쉽지만 분산은 커지기 쉬우므로, 둘의 균형이 맞는 복잡도를 고른다

제곱 오차로 생각하면, 새로운 데이터에 대한 오차의 기댓값은 편향의 제곱, 분산, 데이터 자체의 잡음이라는 3가지의 합으로 나눌 수 있습니다. 편향은 모델이 너무 단순해서 참된 관계를 다 포착하지 못해 생기는 오차로, 크면 과소적합이 됩니다. 분산은 학습용 데이터를 고르는 방법에 따라 예측이 흩어져서 생기는 오차로, 크면 과적합이 됩니다. 일반적으로 모델을 복잡하게 하면 편향은 줄고 분산은 늘어나므로, 둘의 균형이 맞는 복잡도를 검증용 데이터나 교차 검증으로 고릅니다.

머신러닝의 기초의 다른 문제

  1. 과적합을 억제하는 정칙화 등의 기법에 대한 설명으로 적절한 것은?
  2. 머신러닝 모델을 만드는 절차 중 데이터 누수(평가에 사용하는 데이터의 정보가 학습에 섞여 들어가는 것)를 일으키는 것은?
  3. 2클래스 분류 모델을 200건의 테스트 데이터로 평가한 혼동 행렬에서 진양성(TP)이 45건, 위양성(FP)이 5건, 위음성(FN)이 45건, 진음성(TN)이 105건이었다. 정밀도와 재현율의 조합으로 올바른 것은?
  4. 2클래스 분류 모델을 200건의 테스트 데이터로 평가했더니 TP가 20건, FP가 5건, FN이 30건, TN이 145건이었다. F값(F1 점수)에 가장 가까운 것은?
  5. 2클래스 분류 모델의 평가에 사용하는 ROC 곡선과 AUC에 대한 설명으로 적절한 것은?
