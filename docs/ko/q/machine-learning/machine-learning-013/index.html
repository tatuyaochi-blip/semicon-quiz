머신러닝의 기초

2클래스 분류 모델을 200건의 테스트 데이터로 평가했더니 TP가 20건, FP가 5건, FN이 30건, TN이 145건이었다. F값(F1 점수)에 가장 가까운 것은?

  1. A0.40
  2. B0.53
  3. C0.60
정답과 해설 보기

정답: B. 0.53

먼저 정밀도는 20 ÷ (20 + 5) = 0.8, 재현율은 20 ÷ (20 + 30) = 0.4입니다. F값은 정밀도와 재현율의 조화 평균으로, 2 × 0.8 × 0.4 ÷ (0.8 + 0.4) = 0.64 ÷ 1.2 ≈ 0.53입니다. 조화 평균은 작은 쪽 값에 끌려가므로, 어느 한쪽만 높아서는 F값이 높아지지 않습니다. 참고로 정확도는 (20 + 145) ÷ 200 = 0.825로 높아 보이지만, 이 모델은 양성 10건 중 6건꼴로 놓치고 있습니다.
