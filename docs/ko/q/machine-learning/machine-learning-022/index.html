머신러닝의 기초

서포트 벡터 머신(SVM)에 대한 설명으로 적절한 것은?

  1. A학습용 데이터의 모든 점을 되도록 균등하게 사용하여, 모든 점에서 경계까지의 거리의 평균이 최대가 되도록 경계를 긋는다
  2. B2개의 클래스를 나누는 경계 중, 경계에 가장 가까운 데이터(서포트 벡터)까지의 거리(마진)가 최대가 되는 것을 고른다
  3. C각 특성이 클래스별로 서로 독립이라고 가정하고, 베이즈 정리로 각 클래스의 확률을 구하여 분류한다
정답과 해설 보기

정답: B. 2개의 클래스를 나누는 경계 중, 경계에 가장 가까운 데이터(서포트 벡터)까지의 거리(마진)가 최대가 되는 것을 고른다

SVM은 2개의 클래스를 나누는 경계(초평면) 중 마진이 가장 커지는 것을 고르는 분류 방법입니다. 경계는 경계에 가장 가까운 몇 개의 데이터(서포트 벡터)만으로 정해지며, 그 밖의 데이터가 조금 움직여도 바뀌지 않습니다. 마진이 큰 경계일수록 새로운 데이터에 대해서도 틀리기 어렵다고 생각할 수 있습니다. 직선으로 나눌 수 없는 데이터에는 커널 기법을 사용하여, 높은 차원의 공간에서 나눈 것과 같은 효과를 얻는 방법이 있습니다.

머신러닝의 기초의 다른 문제

  1. 전체 메일의 20%가 스팸이다. 어떤 단어는 스팸의 50%와 스팸이 아닌 메일의 5%에 포함된다. 이 단어를 포함하는 메일이 스팸일 확률에 가장 가까운 것은?
  2. 입력층과 출력층만으로 이루어진 단순 퍼셉트론(임계값으로 0 또는 1을 출력하는 하나의 뉴런)으로 나타낼 수 없는 논리 함수는?
  3. 3클래스 분류에서 소프트맥스 함수에 입력하는 값(로짓)이 3, 1, 0이었다. 1번째 클래스의 출력(확률)은 2번째 클래스 출력의 약 몇 배인가? 가장 가까운 것은?
  4. 입력이 x₁ = 1, x₂ = 2인 작은 신경망에서 은닉층의 두 뉴런이 h₁ = ReLU(x₁ + x₂ − 1), h₂ = ReLU(x₁ − 2x₂ + 1)이고, 출력이 y = 2h₁ + 3h₂ + 1이다. y의 값은?
  5. 정답 클래스에 대해 모델이 출력한 확률을 p라고 할 때, 분류 학습에서 사용하는 교차 엔트로피 손실 −log p의 성질로 적절한 것은?
