머신러닝의 기초

28×28의 1채널 이미지에 5×5 필터로 합성곱(스트라이드 1, 패딩 없음)을 수행하고, 이어서 2×2 최대 풀링(스트라이드 2)을 수행한다. 출력의 세로와 가로 크기는?

  1. A12×12
  2. B14×14
  3. C24×24
정답과 해설 보기

정답: A. 12×12

합성곱 출력의 크기는 입력의 크기를 N, 필터의 크기를 F, 패딩을 P, 스트라이드를 S로 하여 (N + 2P − F) ÷ S + 1로 구합니다. (28 + 0 − 5) ÷ 1 + 1 = 24이므로, 합성곱 뒤에는 24×24입니다. 2×2 최대 풀링을 스트라이드 2로 수행하면 2×2 영역마다 최댓값을 하나만 남기므로, 세로와 가로가 절반인 12×12가 됩니다. 풀링에는 학습하는 파라미터가 없으며, 데이터를 작게 하여 계산을 줄이고 위치의 작은 어긋남의 영향을 덜 받게 하는 작용이 있습니다.
