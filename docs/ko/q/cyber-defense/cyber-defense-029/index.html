사이버 공격과 방어의 실무

클라우드의 오브젝트 스토리지에 둔 고객 정보 파일이 인터넷의 누구나 읽을 수 있는 상태였다는 것이 밝혀졌다. 이러한 정보 유출의 전형적인 원인과 재발을 막는 대책의 조합으로 적절한 것은?

  1. A사용자의 설정 오류로 공개되어 있었다. 계정 전체에서 공개를 금지하는 설정으로 하고, 설정 오류를 자동으로 검사한다
  2. B클라우드 사업자의 암호 방식이 약해서 파일이 해독되었다. 파일을 압축한 후 저장하도록 한다
  3. C클라우드 사업자 데이터 센터의 물리적 경비가 불충분했다. 자사 직원을 데이터 센터에 상주시켜 감시하게 한다
정답과 해설 보기

정답: A. 사용자의 설정 오류로 공개되어 있었다. 계정 전체에서 공개를 금지하는 설정으로 하고, 설정 오류를 자동으로 검사한다

클라우드의 공동 책임 모델에서는 스토리지의 접근 설정은 사용자의 책임이며, 공개 설정 오류로 인한 정보 유출은 되풀이하여 일어나고 있습니다. 테스트를 위해 일시적으로 공개한 설정을 되돌리는 것을 잊거나, 허가 대상의 의미를 오해하여 넓게 허가해 버리는 오류가 전형적입니다. 대책으로서 계정이나 조직 전체에서 공개를 금지하는 설정을 기본으로 하고, 설정 상태를 자동으로 검사하는 구조(CSPM: 클라우드 보안 태세 관리)로 공개 설정이나 암호화 설정 누락 등을 지속적으로 찾아내어 고칩니다.

사이버 공격과 방어의 실무의 다른 문제

  1. 클라우드에서 동작하는 배치 처리에, 모든 조작을 허가한 관리자 권한의 액세스 키(장기간 유효한 인증 정보)를 설정 파일에 적어 넘기고 있었다. 이 키가 유출되었을 때의 피해를 작게 하기 위한 재검토로 가장 적절한 것은?
  2. 공격자가 직원의 비밀번호를 입수하고 로그인을 수십 번 반복하여, 직원의 스마트폰에 승인을 요구하는 알림을 대량으로 보냈다. 직원은 귀찮아져서 그만 '승인'을 눌러 버렸다. 이 공격에 대한 대책으로 가장 적절한 것은?
  3. FIDO2(WebAuthn)의 패스키에 의한 인증이 일회용 비밀번호(OTP)와 비교하여 피싱에 강하다고 여겨지는 이유로 올바른 것은?
  4. 어떤 웹 서비스에서 서로 다른 많은 IP 주소로부터, 각각 다른 사용자의 ID와 비밀번호 쌍으로 로그인이 대량으로 시도되었고 일부가 성공했다. 시도된 쌍의 대부분은 다른 서비스에서 유출된 것과 일치했다. 이 공격의 이름은?
  5. 다요소 인증을 사용하는 클라우드 메일 서비스에서, 직원이 진짜와 똑같은 로그인 화면으로 유도되어 비밀번호와 일회용 비밀번호를 입력했다. 공격자는 그 화면을 진짜 서비스와의 중계에 사용하여, 로그인 후에 발급된 세션 쿠키를 훔쳐 직원으로 사칭했다. 이 공격과 대책에 대한 설명으로 가장 적절한 것은?
