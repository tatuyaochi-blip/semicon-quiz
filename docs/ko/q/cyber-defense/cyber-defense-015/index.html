사이버 공격과 방어의 실무

WAF(웹 애플리케이션 방화벽)에 대한 설명으로 올바른 것은?

  1. AIP 주소와 포트 번호만 보고 통신을 통과시킬지 차단할지를 정하는 장비로, HTTP의 내용은 조사하지 않는다
  2. BWAF를 두면 웹 애플리케이션의 취약점을 수정하지 않아도 SQL 인젝션 등 모든 공격을 완전히 막을 수 있다
  3. C웹 애플리케이션 앞에 두고 HTTP 요청의 내용을 조사하여, 전형적인 공격 문자열을 포함한 요청을 차단한다
정답과 해설 보기

정답: C. 웹 애플리케이션 앞에 두고 HTTP 요청의 내용을 조사하여, 전형적인 공격 문자열을 포함한 요청을 차단한다

일반적인 방화벽은 IP 주소나 포트 번호 등으로 통신을 제어하므로, 허가한 HTTPS 포트를 지나는 웹 애플리케이션에 대한 공격은 막지 못합니다. WAF는 HTTP 요청의 URL, 파라미터, 헤더 등의 내용을 조사하여, SQL 인젝션이나 크로스 사이트 스크립팅에 전형적인 패턴이나, 애플리케이션에 맞춰 정한 규칙에 맞지 않는 요청을 차단합니다. 취약점이 발견된 후 수정이 끝날 때까지의 일시적인 방어(가상 패치)로도 사용됩니다. 다만 규칙을 빠져나가는 공격도 있으므로 취약점 자체의 수정을 대신할 수는 없습니다.

사이버 공격과 방어의 실무의 다른 문제

  1. 사내 파일 서버에 업무에서는 아무도 사용하지 않는 '미끼' 파일이나, 어느 시스템에서도 사용되지 않는 미끼 관리자 계정을 두고, 그것들에 대한 접근을 감시한다. 이 대책의 주된 이점은?
  2. 미국 NIST가 2012년에 공개한 인시던트 대응 지침 SP 800-61 제2판(Rev. 2)은 인시던트 대응을 4개 단계의 반복으로 제시한다. 단계의 순서로 올바른 것은?
  3. 인시던트가 일어난 서버에서 조사를 위한 증거를 수집한다. 증거를 사라지기 쉬운 순서(휘발성이 높은 순서)로 수집한다는 사고방식에 따른 순서로 가장 적절한 것은?
  4. 인시던트 조사에서 디스크 복제본 등의 증거를 나중에 소송이나 경찰 신고에도 사용할 수 있도록 다루고 싶다. 증거 보관의 연속성(Chain of Custody)이라는 사고방식에 따른 취급으로 가장 적절한 것은?
  5. 위협 탐지에서 사용되는 IoC(Indicator of Compromise)와 IoA(Indicator of Attack)에 대한 설명으로 올바른 것은?
