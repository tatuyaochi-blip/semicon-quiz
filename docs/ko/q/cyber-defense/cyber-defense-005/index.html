사이버 공격과 방어의 실무

웹 애플리케이션의 취약점을 파고든 공격자가 웹 서버 프로그램과 같은 일반 사용자 권한으로 명령을 실행할 수 있게 되었다. 이후 공격자가 수행하는 '권한 상승'의 예로 올바른 것은?

  1. A같은 일반 사용자 권한 그대로, 훔친 비밀번호로 사내의 다른 서버에 SSH로 접속을 시도한다
  2. BOS 커널의 수정되지 않은 취약점 등을 이용하여 root 권한을 얻는다
  3. C일정한 간격으로 외부 서버에 접속하여 다음 지령을 받는다
정답과 해설 보기

정답: B. OS 커널의 수정되지 않은 취약점 등을 이용하여 root 권한을 얻는다

권한 상승은 공격자가 현재 가진 권한보다 높은 권한을 취약점이나 설정 미비를 이용하여 얻는 것입니다. Linux에서는 수정되지 않은 커널의 취약점, 불필요하게 SUID 비트가 붙은 프로그램, 비밀번호 없이 무엇이든 실행할 수 있도록 설정된 sudo 등이 악용됩니다. 관리자 권한을 얻으면 로그 삭제, 보안 소프트웨어 중지, 인증 정보 탈취를 할 수 있게 되므로 피해가 크게 확대됩니다. 수정 적용, 최소 권한의 원칙, 관리자 권한으로 동작하는 프로그램을 줄이는 것이 대책의 기본입니다.

사이버 공격과 방어의 실무의 다른 문제

  1. 직원 PC 한 대가 공격자에게 탈취되더라도, 거기서 사내의 다른 PC나 서버로 침해가 퍼지는 '측면 이동'을 어렵게 하는 대책으로 가장 적절한 것은?
  2. 침입한 공격자가 독자적인 악성코드를 되도록 사용하지 않고, PowerShell이나 WMI, 표준 원격 관리 기능 등 원래 OS에 들어 있는 정규 도구로 활동하는 수법을 '환경 기생형(Living off the Land)'이라고 한다. 이 수법에 대한 대책의 사고방식으로 가장 적절한 것은?
  3. 제로 트러스트의 사고방식에 기반한 접근 제어의 설명으로 올바른 것은?
  4. NIST SP 800-207의 제로 트러스트 아키텍처에서는 접근을 허가할지 판단하는 '정책 결정 지점(PDP)'과 판단을 실행하는 '정책 시행 지점(PEP)'을 나누어 생각한다. 직원이 업무 애플리케이션에 접근할 때 두 가지의 역할에 대한 설명으로 올바른 것은?
  5. 재택근무 직원이 사내 시스템을 사용하기 위한 방식으로서, 기존의 원격 접속 VPN과 ZTNA(Zero Trust Network Access)를 비교한 설명으로 올바른 것은?
