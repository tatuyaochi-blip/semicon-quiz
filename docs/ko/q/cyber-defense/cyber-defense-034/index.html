사이버 공격과 방어의 실무

다요소 인증을 사용하는 클라우드 메일 서비스에서, 직원이 진짜와 똑같은 로그인 화면으로 유도되어 비밀번호와 일회용 비밀번호를 입력했다. 공격자는 그 화면을 진짜 서비스와의 중계에 사용하여, 로그인 후에 발급된 세션 쿠키를 훔쳐 직원으로 사칭했다. 이 공격과 대책에 대한 설명으로 가장 적절한 것은?

  1. A다요소 인증을 사용하고 있으면, 로그인 후에 세션 쿠키를 도난당해도 공격자는 서비스를 사용할 수 없다
  2. B비밀번호를 더 긴 것으로 하면, 중계된 로그인에서는 세션 쿠키가 발급되지 않게 된다
  3. C도난당한 쿠키는 다요소 인증을 마친 상태를 나타내므로, 즉시 세션을 무효화하고 패스키 같은 인증, 세션 단축, 평소와 다른 이용의 탐지를 조합한다
정답과 해설 보기

정답: C. 도난당한 쿠키는 다요소 인증을 마친 상태를 나타내므로, 즉시 세션을 무효화하고 패스키 같은 인증, 세션 단축, 평소와 다른 이용의 탐지를 조합한다

인증이 성공하면 서비스는 세션 쿠키 등의 토큰을 발급하고, 이후의 요청은 토큰만으로 본인으로 취급합니다. 따라서 중계형 피싱(AiTM)이나 단말에 감염된 정보 탈취형 악성코드로 토큰을 도난당하면, 다요소 인증을 마친 상태 그대로 공격자가 사칭할 수 있습니다. 피해를 알아채면 비밀번호 변경뿐만 아니라 발급된 세션을 무효화할 필요가 있습니다. 예방에는 접속 대상의 도메인에 묶인 패스키 같은 피싱에 강한 인증, 세션 유효 기간 단축, 위치나 단말의 변화에 따른 재인증이나 이용 제한을 조합합니다.

사이버 공격과 방어의 실무의 다른 문제

  1. 서버의 관리자 계정을 지키기 위한 특권 접근 관리(PAM)의 사고방식으로 가장 적절한 것은?
  2. 개발자가 클라우드 서비스의 API 키를 포함한 설정 파일을 실수로 공개 Git 리포지토리에 커밋해 버렸다. 알아챈 즉시 그 파일을 삭제하는 변경을 커밋했다. 이후에 해야 할 대응으로 가장 적절한 것은?
  3. 어떤 조직에서 일어난 인시던트 4건에 대해 발생부터 탐지까지의 시간과 탐지부터 봉쇄까지의 시간은 건 1이 10시간과 4시간, 건 2가 30시간과 2시간, 건 3이 2시간과 6시간, 건 4가 6시간과 4시간이었다. 발생부터 탐지까지의 평균 시간(MTTD)과 탐지부터 봉쇄까지의 평균 시간(MTTC)의 조합으로 올바른 것은?
  4. 랜섬웨어 피해에 대해 1회 피해액(SLE)을 4000만 엔, 연간 발생 횟수(ARO)를 0.5회로 추정했다. 대책 A는 연간 비용이 600만 엔이며 발생 횟수를 연 0.2회로 낮춘다. 대책 B는 연간 비용이 300만 엔이며 발생 횟수는 바뀌지 않지만 복구를 앞당겨 1회 피해액을 2400만 엔으로 낮춘다. 연간 예상 손실액(ALE) = SLE × ARO, ROSI = (ALE 감소액 − 대책의 연간 비용) ÷ 대책의 연간 비용으로 할 때, ROSI가 큰 쪽의 대책과 그 값의 조합으로 올바른 것은?
  5. 어떤 IDS는 하루에 100만 건의 접속을 조사한다. 그중 실제 공격은 100건이다. 이 IDS는 공격의 99%를 탐지하고, 공격이 아닌 접속의 0.1%를 잘못 공격으로 판정한다. IDS가 낸 경고 중 실제로 공격인 것의 비율에 가장 가까운 것은?
