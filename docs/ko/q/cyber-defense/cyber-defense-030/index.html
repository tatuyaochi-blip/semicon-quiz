사이버 공격과 방어의 실무

클라우드에서 동작하는 배치 처리에, 모든 조작을 허가한 관리자 권한의 액세스 키(장기간 유효한 인증 정보)를 설정 파일에 적어 넘기고 있었다. 이 키가 유출되었을 때의 피해를 작게 하기 위한 재검토로 가장 적절한 것은?

  1. A액세스 키 문자열을 더 긴 것으로 바꿔 공격자가 추측하기 어렵게 하고, 권한은 지금 그대로 바꾸지 않고 계속 사용한다
  2. B처리에 필요한 조작과 대상만 허가한 역할(Role)을 할당하고, 실행 환경에서 자동으로 발급되는 짧은 시간만 유효한 인증 정보를 사용한다
  3. C액세스 키를 설정 파일에서 프로그램 소스 코드 안으로 옮기고, 소스 코드와 함께 리포지토리에서 관리하여 공유한다
정답과 해설 보기

정답: B. 처리에 필요한 조작과 대상만 허가한 역할(Role)을 할당하고, 실행 환경에서 자동으로 발급되는 짧은 시간만 유효한 인증 정보를 사용한다

모든 조작을 허가한 장기간 유효한 키가 유출되면, 공격자는 계정 안의 모든 리소스를 읽거나, 삭제하거나, 새 리소스를 만들어 악용할 수 있으므로 피해가 가장 커집니다. 최소 권한의 원칙에 따라 처리에 필요한 조작과 대상만 허가한 역할을 할당하고, 가상 머신이나 컨테이너에 연결한 역할로부터 몇 시간 등으로 만료되는 임시 인증 정보를 자동으로 받는 방식으로 하면, 키를 저장해 둘 필요도 없어집니다. 아울러 사용되지 않는 권한을 정기적으로 재검토하고, 평소와 다른 조작 호출을 감시합니다.

사이버 공격과 방어의 실무의 다른 문제

  1. 공격자가 직원의 비밀번호를 입수하고 로그인을 수십 번 반복하여, 직원의 스마트폰에 승인을 요구하는 알림을 대량으로 보냈다. 직원은 귀찮아져서 그만 '승인'을 눌러 버렸다. 이 공격에 대한 대책으로 가장 적절한 것은?
  2. FIDO2(WebAuthn)의 패스키에 의한 인증이 일회용 비밀번호(OTP)와 비교하여 피싱에 강하다고 여겨지는 이유로 올바른 것은?
  3. 어떤 웹 서비스에서 서로 다른 많은 IP 주소로부터, 각각 다른 사용자의 ID와 비밀번호 쌍으로 로그인이 대량으로 시도되었고 일부가 성공했다. 시도된 쌍의 대부분은 다른 서비스에서 유출된 것과 일치했다. 이 공격의 이름은?
  4. 다요소 인증을 사용하는 클라우드 메일 서비스에서, 직원이 진짜와 똑같은 로그인 화면으로 유도되어 비밀번호와 일회용 비밀번호를 입력했다. 공격자는 그 화면을 진짜 서비스와의 중계에 사용하여, 로그인 후에 발급된 세션 쿠키를 훔쳐 직원으로 사칭했다. 이 공격과 대책에 대한 설명으로 가장 적절한 것은?
  5. 서버의 관리자 계정을 지키기 위한 특권 접근 관리(PAM)의 사고방식으로 가장 적절한 것은?
