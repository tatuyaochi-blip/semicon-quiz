사이버 공격과 방어의 실무

인시던트가 일어난 서버에서 조사를 위한 증거를 수집한다. 증거를 사라지기 쉬운 순서(휘발성이 높은 순서)로 수집한다는 사고방식에 따른 순서로 가장 적절한 것은?

  1. A메모리 내용과 현재의 네트워크 연결 상태 → 디스크 내용 → 외부에 보관된 백업이나 아카이브
  2. B외부에 보관된 백업이나 아카이브 → 디스크 내용 → 메모리 내용과 현재의 네트워크 연결 상태
  3. C디스크 내용 → 전원을 끈 다음 메모리 내용과 현재의 네트워크 연결 상태 → 외부에 보관된 백업
정답과 해설 보기

정답: A. 메모리 내용과 현재의 네트워크 연결 상태 → 디스크 내용 → 외부에 보관된 백업이나 아카이브

디지털 포렌식에서 증거를 수집할 때의 지침인 RFC 3227(2002년)은 사라지기 쉬운 것부터 순서대로 수집할 것을 권장합니다. CPU의 레지스터나 캐시, 메모리 내용, 실행 중인 프로세스나 네트워크 연결 상태는 시간이 지나거나 전원을 끄면 사라지므로 가장 먼저 수집합니다. 메모리에는 디스크에 남지 않는 악성코드나 복호화된 상태의 정보가 남아 있는 경우가 있습니다. 디스크 내용은 그 후에 복제하여 조사하고, 외부에 보관된 백업이나 아카이브는 잘 바뀌지 않으므로 마지막이어도 됩니다.

사이버 공격과 방어의 실무의 다른 문제

  1. 인시던트 조사에서 디스크 복제본 등의 증거를 나중에 소송이나 경찰 신고에도 사용할 수 있도록 다루고 싶다. 증거 보관의 연속성(Chain of Custody)이라는 사고방식에 따른 취급으로 가장 적절한 것은?
  2. 위협 탐지에서 사용되는 IoC(Indicator of Compromise)와 IoA(Indicator of Attack)에 대한 설명으로 올바른 것은?
  3. 조직 안에 두는 CSIRT와 PSIRT의 역할 차이로 올바른 것은?
  4. 침입 조사에서 서버 2대의 로그를 대조한다. 웹 서버의 로그는 협정 세계시(UTC)로 기록되었고, 시계는 NTP로 정확하게 맞춰져 있었다. 파일 서버의 로그는 일본 시간(UTC+9시간)으로 기록되었고, 시계는 정확한 시각보다 4분 빨랐다. 웹 서버의 로그에는 수상한 로그인이 01:52(UTC), 파일 서버의 로그에는 대량의 파일 읽기가 10:58(일본 시간)로 기록되어 있었다. 파일 읽기가 실제로 일어난 것은 수상한 로그인의 몇 분 후인가?
  5. 같은 주에 취약점 3개의 수정이 공개되었다. 운영 담당자는 하루에 하나씩만 수정을 적용할 수 있다. 가장 먼저 수정을 적용해야 할 것과 그 이유의 조합으로 가장 적절한 것은?
