사이버 공격과 방어의 실무

조직 안에 두는 CSIRT와 PSIRT의 역할 차이로 올바른 것은?

  1. ACSIRT는 자기 조직의 시스템에서 일어난 인시던트에 대응하고, PSIRT는 자사 제품의 취약점에 대응한다
  2. BCSIRT는 제품의 취약점 대응만 담당하며, 자기 조직의 정보 시스템에서 일어난 인시던트에는 관여하지 않는다
  3. CPSIRT는 외부 공격자 그룹을 부르는 이름이고, CSIRT는 그 공격을 받는 쪽 조직을 부르는 이름이다
정답과 해설 보기

정답: A. CSIRT는 자기 조직의 시스템에서 일어난 인시던트에 대응하고, PSIRT는 자사 제품의 취약점에 대응한다

CSIRT(Computer Security Incident Response Team)는 조직의 시스템에서 일어난 보안 인시던트의 접수, 분석, 대응 조정, 외부 기관과의 연락을 담당하는 팀입니다. PSIRT(Product Security Incident Response Team)는 자사가 제공하는 제품이나 서비스의 취약점에 대해 외부 연구자 등의 보고를 접수하고, 수정 개발, 사용자에 대한 공표와 수정 배포를 진행합니다. 기기나 반도체 제조사처럼 제품을 출하하는 조직에서는 두 가지를 모두 두고 연계합니다.

사이버 공격과 방어의 실무의 다른 문제

  1. 침입 조사에서 서버 2대의 로그를 대조한다. 웹 서버의 로그는 협정 세계시(UTC)로 기록되었고, 시계는 NTP로 정확하게 맞춰져 있었다. 파일 서버의 로그는 일본 시간(UTC+9시간)으로 기록되었고, 시계는 정확한 시각보다 4분 빨랐다. 웹 서버의 로그에는 수상한 로그인이 01:52(UTC), 파일 서버의 로그에는 대량의 파일 읽기가 10:58(일본 시간)로 기록되어 있었다. 파일 읽기가 실제로 일어난 것은 수상한 로그인의 몇 분 후인가?
  2. 같은 주에 취약점 3개의 수정이 공개되었다. 운영 담당자는 하루에 하나씩만 수정을 적용할 수 있다. 가장 먼저 수정을 적용해야 할 것과 그 이유의 조합으로 가장 적절한 것은?
  3. 조직의 방어를 확인하는 방법 중 취약점 스캔, 침투 테스트, 레드팀 훈련의 차이에 대한 설명으로 올바른 것은?
  4. 외부 보안 연구자가 어떤 기업의 제품에서 공표되지 않은 취약점을 발견했다. 조정된 취약점 공개(Coordinated Vulnerability Disclosure)의 사고방식에 따른 진행 방법으로 가장 적절한 것은?
  5. SBOM(소프트웨어 자재 명세서)을 만들어 관리하는 주된 목적으로 올바른 것은?
