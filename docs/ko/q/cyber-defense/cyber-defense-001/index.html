사이버 공격과 방어의 실무

록히드 마틴사가 2011년에 제시한 사이버 킬 체인은 표적형 공격의 흐름을 7개 단계로 나눈다. 단계의 순서로 올바른 것은?

  1. A전달 → 정찰 → 무기화 → 익스플로잇 → 설치 → C2(원격 조작) → 목적 실행
  2. B정찰 → 무기화 → 전달 → 익스플로잇 → 설치 → C2(원격 조작) → 목적 실행
  3. C정찰 → 전달 → 무기화 → 설치 → 익스플로잇 → 목적 실행 → C2(원격 조작)
정답과 해설 보기

정답: B. 정찰 → 무기화 → 전달 → 익스플로잇 → 설치 → C2(원격 조작) → 목적 실행

사이버 킬 체인은 정찰(표적 조사), 무기화(공격 코드를 심은 파일 등의 준비), 전달(메일 첨부 파일이나 웹사이트로 표적에 보내는 것), 익스플로잇(취약점을 파고들어 코드를 실행시키는 것), 설치(악성코드를 눌러앉히는 것), C2(외부 지령 서버와의 통신로 확립), 목적 실행(정보 탈취나 파괴)의 7단계로 공격을 나타냅니다. 방어하는 쪽은 어느 단계에서 공격을 끊을 수 있는지를 생각하여 대책을 배치하며, 이른 단계에서 끊을수록 피해는 작아집니다. 예를 들어 수상한 첨부 파일을 메일 단계에서 막으면 공격은 전달 단계에서 끝납니다. 다만 내부자 부정이나 침입 후의 활동이 오래 이어지는 공격은 나타내기 어려우므로, 더 세밀한 MITRE ATT&CK와 함께 사용됩니다.

사이버 공격과 방어의 실무의 다른 문제

  1. MITRE ATT&CK는 실제 공격에서 관측된 수법을, 공격자의 목적을 나타내는 '전술(Tactics)'과 그 목적을 달성하는 구체적인 방법을 나타내는 '기법(Techniques)'으로 나누어 정리한 지식 베이스이다. 관측된 행동과 그것이 해당하는 전술의 조합으로 올바른 것은?
  2. 공격자가 조직의 네트워크에 처음 들어오는 '초기 접근'의 수법에 해당하는 것은?
  3. 사내 네트워크의 통신 기록을 조사했더니 다음과 같은 통신이 발견되었다. 악성코드가 외부 지령 서버(C2 서버)와 통신하고 있을 의심이 가장 강한 것은?
  4. 웹 애플리케이션의 취약점을 파고든 공격자가 웹 서버 프로그램과 같은 일반 사용자 권한으로 명령을 실행할 수 있게 되었다. 이후 공격자가 수행하는 '권한 상승'의 예로 올바른 것은?
  5. 직원 PC 한 대가 공격자에게 탈취되더라도, 거기서 사내의 다른 PC나 서버로 침해가 퍼지는 '측면 이동'을 어렵게 하는 대책으로 가장 적절한 것은?
