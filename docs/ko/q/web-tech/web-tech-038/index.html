웹 기술 기초

리버스 프록시에 대한 설명으로 올바른 것은?

  1. A사내 PC가 인터넷상의 사이트를 볼 때, PC 대신 외부 서버에 접속하여 열람 기록이나 제한을 수행한다
  2. B도메인 이름을 IP 주소로 변환하는 질의를 이용자 대신 루트 서버부터 차례로 수행하고, 결과를 한동안 저장해 둔다
  3. C웹 서버 앞에 놓여 이용자로부터의 요청을 대신 받아 뒤쪽 서버로 중계하고, TLS 처리 등을 담당한다
정답과 해설 보기

정답: C. 웹 서버 앞에 놓여 이용자로부터의 요청을 대신 받아 뒤쪽 서버로 중계하고, TLS 처리 등을 담당한다

리버스 프록시는 서버 쪽에 놓여 이용자로부터의 요청을 받고, 뒤에 있는 한 대 또는 여러 대의 서버로 중계합니다. HTTPS 암호 처리를 한곳에서 모아 수행하는 것(TLS 종료), 자주 사용되는 응답을 저장해 두었다가 돌려주는 것, 여러 서버로 분배하는 것과 같은 역할을 담당하며, 뒤쪽 서버의 구성을 이용자로부터 숨길 수도 있습니다. 사내 이용자 대신 외부로 접속하는 것은 포워드 프록시로, 이용자 쪽에 놓인다는 점이 다릅니다.

웹 기술 기초의 다른 문제

  1. CGI에서는 웹 서버가 요청을 받을 때마다 프로그램을 새로운 프로세스로 기동하고, 처리가 끝나면 프로세스는 종료된다. FastCGI나 애플리케이션 서버 방식이 CGI에 비해 많은 요청을 효율적으로 처리할 수 있는 주된 이유는?
  2. 웹사이트의 페이지를 만드는 방식 중, 빌드 단계에서 모든 페이지의 HTML 파일을 미리 생성해 두고, 요청에는 그 파일을 그대로 돌려주는 방식은?
  3. HTTP/1.1 요청의 첫 줄(요청 라인)에 나열되는 요소의 조합으로 올바른 것은?
  4. HTTP 메서드 중 '안전'(서버상의 리소스 상태를 바꾸는 것을 의도하지 않음)하지는 않지만 '멱등'(같은 요청을 몇 번 보내도 한 번 보냈을 때와 같은 상태가 됨)한 것은?
  5. HTTP의 상태 코드와 그 의미의 조합으로 올바른 것은?
