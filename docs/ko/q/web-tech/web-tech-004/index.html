웹 기술 기초

회원제 웹사이트에서 로그인한 일반 회원이 관리자에게만 허용된 페이지를 요청했다. 서버는 이용자가 누구인지 확인했지만, 이 페이지에 대한 접근은 허가하지 않는다. 이때 돌려줄 상태 코드로 가장 적절한 것은?

  1. A401 Unauthorized
  2. B403 Forbidden
  3. C404 Not Found
정답과 해설 보기

정답: B. 403 Forbidden

403 Forbidden은 서버가 요청을 이해한 뒤 접근을 허가하지 않음을 나타냅니다. 401 Unauthorized는 이름과 달리 인증 정보가 없거나 올바르지 않음을 나타내는 코드로, WWW-Authenticate 헤더로 인증 방법을 알립니다. 이 상황에서는 이용자가 누구인지 확인되었고 부족한 것은 권한(인가)이므로 403이 해당합니다. 관리 화면이 있다는 것 자체를 알리고 싶지 않을 때 일부러 404를 돌려주는 설계도 있지만, 상황을 그대로 나타내는 것은 403입니다.

웹 기술 기초의 다른 문제

  1. 웹 API가 응답 본문으로 JSON 형식의 데이터를 돌려준다. 본문의 형식을 나타내기 위해 응답에 붙이는 헤더로 일반적으로 사용되는 것은?
  2. 브라우저가 이전에 받은 이미지를, 그때의 응답에 붙어 있던 ETag 값을 If-None-Match 헤더에 넣어 다시 요청했다. 서버의 이미지가 바뀌지 않았을 때 서버의 응답으로 올바른 것은?
  3. HTTP/2와 HTTP/3에 대한 설명으로 올바른 것은?
  4. RTT가 40 ms인 웹 서버에서 HTML 하나와 거기서 참조하는 이미지 4개를 하나씩 차례로 가져온다. TCP 연결 설정에 1왕복, 각 요청과 응답에 1왕복이 걸린다고 하고, 데이터 전송 시간, 서버의 처리 시간, TLS, 연결 종료는 고려하지 않는다. 객체마다 새로운 TCP 연결을 여는 경우와 하나의 TCP 연결을 재사용하는 지속 연결의 경우에 걸리는 시간의 차이는?
  5. HTTP는 무상태(stateless) 프로토콜이다. 이것과, 웹사이트에서 로그인한 상태를 유지하는 일반적인 방법에 대한 설명으로 올바른 것은?
