웹 기술 기초

.card {
  box-sizing: content-box;
  width: 200px;
  padding: 10px;
  border: 2px solid #333;
  margin: 20px;
}

위의 CSS를 지정한 요소에서, 좌우 보더의 바깥쪽 끝에서 끝까지의 폭은?

  1. A200px
  2. B224px
  3. C264px
정답과 해설 보기

정답: B. 224px

CSS 박스 모델에서 요소는 안쪽부터 콘텐츠, 패딩, 보더, 마진 순으로 겹쳐 있습니다. box-sizing: content-box(기본값)에서는 width가 콘텐츠의 폭만을 나타내므로, 보더 바깥쪽까지의 폭은 200 + 10 × 2 + 2 × 2 = 224px입니다. 마진은 보더 바깥쪽의 여백으로, 다른 요소와의 간격이 됩니다. box-sizing: border-box로 하면 width가 보더까지 포함한 폭이 되어, 콘텐츠의 폭은 200 − 24 = 176px이 됩니다.
