웹 기술 기초

웹사이트의 페이지를 만드는 방식 중, 빌드 단계에서 모든 페이지의 HTML 파일을 미리 생성해 두고, 요청에는 그 파일을 그대로 돌려주는 방식은?

  1. ACSR(클라이언트 사이드 렌더링)
  2. BSSR(서버 사이드 렌더링)
  3. CSSG(정적 사이트 생성)
정답과 해설 보기

정답: C. SSG(정적 사이트 생성)

SSG로 만든 사이트는 정적 사이트로, 요청마다 서버에서 프로그램을 실행하지 않으므로 정적 파일을 배포하는 호스팅이나 CDN에서 그대로 빠르게 배포할 수 있고, 공격 대상이 되는 부분도 적어집니다. 예를 들어 문제나 용어집 페이지를 콘텐츠 데이터로부터 빌드로 생성하여 배포하는 사이트가 이에 해당하며, 내용을 바꾸었을 때는 다시 생성합니다. SSR은 요청마다 서버에서 HTML을 만드는 동적인 방식이고, CSR은 최소한의 HTML과 JavaScript를 보내 브라우저 안에서 페이지를 조립하는 방식입니다.

웹 기술 기초의 다른 문제

  1. HTTP/1.1 요청의 첫 줄(요청 라인)에 나열되는 요소의 조합으로 올바른 것은?
  2. HTTP 메서드 중 '안전'(서버상의 리소스 상태를 바꾸는 것을 의도하지 않음)하지는 않지만 '멱등'(같은 요청을 몇 번 보내도 한 번 보냈을 때와 같은 상태가 됨)한 것은?
  3. HTTP의 상태 코드와 그 의미의 조합으로 올바른 것은?
  4. 회원제 웹사이트에서 로그인한 일반 회원이 관리자에게만 허용된 페이지를 요청했다. 서버는 이용자가 누구인지 확인했지만, 이 페이지에 대한 접근은 허가하지 않는다. 이때 돌려줄 상태 코드로 가장 적절한 것은?
  5. 웹 API가 응답 본문으로 JSON 형식의 데이터를 돌려준다. 본문의 형식을 나타내기 위해 응답에 붙이는 헤더로 일반적으로 사용되는 것은?
