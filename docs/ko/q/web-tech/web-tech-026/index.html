웹 기술 기초

브라우저의 동일 출처 정책에서 https://www.example.com/app/index.html과 같은 출처로 간주되는 URL은?

  1. Ahttps://www.example.com/data/list.json
  2. Bhttp://www.example.com/app/data.json
  3. Chttps://api.example.com/app/data.json
정답과 해설 보기

정답: A. https://www.example.com/data/list.json

출처(origin)는 스킴, 호스트 이름, 포트 번호 세 가지의 조합으로 정해지며, 세 가지가 모두 같을 때 동일 출처로 간주됩니다. 경로는 관계가 없으므로 /data/list.json은 같은 출처입니다. 동일 출처 정책에 의해 페이지의 JavaScript는 다른 출처에서 받은 응답의 내용을 원칙적으로 읽을 수 없습니다. 이로써 이용자가 로그인해 있는 다른 사이트의 정보를 악의적인 페이지의 스크립트가 읽어 내는 것을 막고 있습니다.

  2. Service Worker에 대한 설명으로 올바른 것은?
  3. 스마트폰에도 대응하는 반응형 디자인 페이지에서 <head>에 <meta name="viewport" content="width=device-width, initial-scale=1">을 쓰는 주된 목적은?
  4. 이용자마다 내용이 다른 마이페이지의 응답에 Cache-Control: private, max-age=60을 붙였다. 이 지정의 효과로 올바른 것은?
  5. 웹 서버가 응답을 gzip이나 Brotli로 압축하여 보낼 때, 압축에 의한 전송량 절감이 일반적으로 가장 작은 것은?
