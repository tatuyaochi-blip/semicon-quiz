웹 기술 기초

웹 페이지의 사용 경험을 나타내는 지표인 Core Web Vitals 중 CLS(Cumulative Layout Shift)가 나타내는 것은?

  1. A페이지를 읽어 들일 때, 화면 안에서 가장 큰 이미지나 텍스트 덩어리가 표시되기까지의 시간
  2. B이용자의 클릭이나 키 입력부터 그 결과가 화면에 그려지기까지의 지연
  3. C표시 도중에 나중에 읽어 들여진 이미지나 광고 등으로 인해 요소의 위치가 예기치 않게 어긋난 양
정답과 해설 보기

정답: C. 표시 도중에 나중에 읽어 들여진 이미지나 광고 등으로 인해 요소의 위치가 예기치 않게 어긋난 양

Core Web Vitals는 읽어 들이기 속도를 나타내는 LCP(Largest Contentful Paint), 조작에 대한 응답 속도를 나타내는 INP(Interaction to Next Paint), 표시의 안정성을 나타내는 CLS의 세 지표로 이루어집니다(INP는 2024년 3월에 FID를 대신하여 추가되었습니다). CLS는 나중에 나타난 이미지나 광고 때문에 텍스트 등이 아래로 밀려나는 것 같은, 예기치 않은 위치 어긋남을 수치로 나타낸 것입니다. 이미지나 동영상에 width와 height를 지정하여 표시할 자리를 미리 확보해 두면 CLS를 작게 할 수 있습니다.

웹 기술 기초의 다른 문제

  1. 웹 페이지에서 사용하는 이미지 형식과 그 일반적인 사용법의 조합으로 적절한 것은?
  2. 3,000바이트의 이미지 데이터를 Base64로 인코딩하여 HTML 안에 삽입한다. 줄 바꿈을 넣지 않을 때, 인코딩한 후의 문자 수는?
  3. 웹 시스템을 웹 서버, 애플리케이션 서버, 데이터베이스 서버의 3계층으로 구성한다. 애플리케이션 서버가 주로 담당하는 처리로 적절한 것은?
  4. 리버스 프록시에 대한 설명으로 올바른 것은?
  5. CGI에서는 웹 서버가 요청을 받을 때마다 프로그램을 새로운 프로세스로 기동하고, 처리가 끝나면 프로세스는 종료된다. FastCGI나 애플리케이션 서버 방식이 CGI에 비해 많은 요청을 효율적으로 처리할 수 있는 주된 이유는?

이 분야의 비교

  • HTTP/1.1·HTTP/2·HTTP/3의 차이: 전송 방식·다중화·HOL 블로킹·헤더 압축·암호화 비교HTTP/1.1, HTTP/2, HTTP/3를 한 장의 표로 비교합니다. 사양, 전송 방식(트랜스포트), 메시지 형식, 다중화, HOL 블로킹, 헤더 압축, 암호화, 연결 수립까지의 왕복 횟수, …
