웹 기술 기초

웹 페이지에서 사용하는 이미지 형식과 그 일반적인 사용법의 조합으로 적절한 것은?

  1. A배경을 투명하게 하고 싶은 로고: JPEG. 투명한 부분을 그대로 저장할 수 있다
  2. B풍경 사진: PNG. 무손실 압축이므로 사진에서는 JPEG보다 반드시 작아진다
  3. C회사 로고나 아이콘: SVG. 도형을 좌표와 식으로 나타내므로 확대해도 흐려지지 않는다
정답과 해설 보기

정답: C. 회사 로고나 아이콘: SVG. 도형을 좌표와 식으로 나타내므로 확대해도 흐려지지 않는다

JPEG는 손실 압축으로 사진을 작게 할 수 있지만 투명한 부분을 다룰 수 없습니다. PNG는 무손실 압축으로 투명도 다룰 수 있어 글자나 선이 선명한 이미지에 적합하지만, 사진에서는 일반적으로 JPEG보다 훨씬 커집니다. SVG는 도형을 XML 텍스트로 나타내는 벡터 형식이므로 어떤 크기에서도 매끄럽게 표시할 수 있어 로고나 아이콘에 적합합니다. WebP나 AVIF는 손실과 무손실 양쪽의 압축과 투명을 지원하며, 같은 화질이라면 JPEG나 PNG보다 일반적으로 작게 할 수 있는 형식입니다.

  2. 웹 시스템을 웹 서버, 애플리케이션 서버, 데이터베이스 서버의 3계층으로 구성한다. 애플리케이션 서버가 주로 담당하는 처리로 적절한 것은?
  3. 리버스 프록시에 대한 설명으로 올바른 것은?
  4. CGI에서는 웹 서버가 요청을 받을 때마다 프로그램을 새로운 프로세스로 기동하고, 처리가 끝나면 프로세스는 종료된다. FastCGI나 애플리케이션 서버 방식이 CGI에 비해 많은 요청을 효율적으로 처리할 수 있는 주된 이유는?
  5. 웹사이트의 페이지를 만드는 방식 중, 빌드 단계에서 모든 페이지의 HTML 파일을 미리 생성해 두고, 요청에는 그 파일을 그대로 돌려주는 방식은?
