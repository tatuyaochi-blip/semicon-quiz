정답: B. 정공

p형에서는 억셉터가 가전자대에서 전자를 받아들이므로 정공이 늘어나며, 다수 캐리어는 정공, 소수 캐리어는 전자가 됩니다. 이온화된 억셉터는 격자에 고정된 음전하로 스스로는 움직일 수 없습니다. 다만 공핍층에서는 이 고정 전하가 전계와 내장 전위를 만들어 내는 주역이 됩니다. MOSFET에서는 p형 기판 표면에 소수 캐리어인 전자를 모아(반전) n채널을 만듭니다.
