반도체 물리

전자 밀도 n, 정공 밀도 p, 전자 이동도 μn, 정공 이동도 μp, 전하 소량 q일 때, 반도체의 전도율 σ를 나타내는 식은 무엇입니까?

  1. Aσ = q(nμn − pμp)
  2. Bσ = (nμn + pμp) / q
  3. Cσ = q(nμn + pμp)
정답과 해설 보기

정답: C. σ = q(nμn + pμp)

전자와 정공은 움직이는 방향이 반대이지만 전하의 부호도 반대이므로 전류는 같은 방향으로 흐르며, 전도율은 합인 σ = q(nμn + pμp)가 됩니다. 저항률은 그 역수입니다. 도핑된 반도체에서는 다수 캐리어 항만으로 충분히 근사할 수 있으며, 예를 들어 n형이라면 σ ≈ qnμn입니다. 진성 실리콘에서는 n = p = ni이므로 σ = q·ni(μn + μp)가 되어 저항률은 약 2~3×10⁵ Ω·cm로 커집니다.

관련 계산 도구

실리콘의 비저항과 불순물 농도 환산실리콘의 비저항과 불순물 농도(n형·p형)를 서로 환산하고 이동도도 표시진성 캐리어 밀도의 온도 의존성Si·Ge·GaAs의 진성 캐리어 밀도 ni를 온도로 계산. 불순물 농도를 넣으면 진성화 온도도 확인

반도체 물리의 다른 문제

  1. 금지대 안에 생긴 깊은 준위(트랩)를 통해 전자와 정공이 재결합하는 과정을 무엇이라고 합니까?
  2. 소수 캐리어의 확산 계수를 D, 라이프타임을 τ라고 할 때, 확산 길이 L을 나타내는 식은 무엇입니까?
  3. 실리콘의 밴드갭은 온도가 올라가면 어떻게 됩니까?
  4. 실리콘 속 전자에 강한 전계를 가하면 드리프트 속도는 어떻게 됩니까?
  5. 파장 620 nm인 빛의 광자 1개가 가진 에너지에 가장 가까운 값은 무엇입니까? (E [eV] ≈ 1240 / λ [nm])

이 분야의 비교

  • 직접 천이형과 간접 천이형 반도체의 차이점직접 천이형과 간접 천이형 반도체를 표로 비교합니다. 밴드 구조, 포논의 관여, 발광 효율, 캐리어 수명, 빛의 흡수 깊이, 대표 재료, 용도를 다룹니다.
  • n형 반도체와 p형 반도체의 차이점 정리n형과 p형 반도체를 표로 비교합니다. 첨가하는 불순물(도너와 억셉터), 다수 캐리어, 불순물 준위, 페르미 준위의 위치, 이동도와 비저항, 소자에서 쓰이는 곳을 다룹니다.
  • 도체·반도체·절연체의 차이: 밴드갭·비저항·온도 특성 비교도체(금속)·반도체·절연체를 밴드 구조, 밴드갭, 비저항, 캐리어 수, 온도와 빛에 따른 변화, 대표 재료, 소자에서의 역할 관점에서 표로 비교합니다.
