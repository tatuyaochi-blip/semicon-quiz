정답: B. 전도대와 가전자대의 유효 상태 밀도(유효 질량)가 다르기 때문에

진성 반도체에서는 전자 밀도와 정공 밀도가 같아지는 위치에 페르미 준위가 옵니다. 전도대와 가전자대의 유효 상태 밀도는 유효 질량의 차이로 같지 않으므로(Nc > Nv) Ei = (Ec+Ev)/2 + (kT/2)·ln(Nv/Nc)가 되며, 실리콘에서는 중앙보다 약 0.01 eV 가전자대 쪽으로 어긋납니다. 갭 1.12 eV에 비하면 작으므로 보통은 거의 중앙으로 보고 계산합니다.

반도체 물리의 다른 문제

  1. 실온에서 실리콘(Si)의 밴드갭에 가장 가까운 값은 무엇입니까?
  2. 실리콘에 인(P)을 불순물로 첨가했을 때의 설명으로 올바른 것은 무엇입니까?
  3. 진성 반도체의 온도를 올렸을 때 진성 캐리어 밀도는 어떻게 됩니까?
  4. 실리콘에서 전자와 정공의 이동도 비교로 올바른 것은 무엇입니까?
  5. n형 반도체의 페르미 준위 위치로 올바른 것은 무엇입니까?

이 분야의 비교

  • 직접 천이형과 간접 천이형 반도체의 차이점직접 천이형과 간접 천이형 반도체를 표로 비교합니다. 밴드 구조, 포논의 관여, 발광 효율, 캐리어 수명, 빛의 흡수 깊이, 대표 재료, 용도를 다룹니다.
  • n형 반도체와 p형 반도체의 차이점 정리n형과 p형 반도체를 표로 비교합니다. 첨가하는 불순물(도너와 억셉터), 다수 캐리어, 불순물 준위, 페르미 준위의 위치, 이동도와 비저항, 소자에서 쓰이는 곳을 다룹니다.
  • 도체·반도체·절연체의 차이: 밴드갭·비저항·온도 특성 비교도체(금속)·반도체·절연체를 밴드 구조, 밴드갭, 비저항, 캐리어 수, 온도와 빛에 따른 변화, 대표 재료, 소자에서의 역할 관점에서 표로 비교합니다.
