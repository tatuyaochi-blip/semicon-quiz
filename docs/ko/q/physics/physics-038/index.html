반도체 물리

  2. B방사 재결합
  3. C오제 재결합

정답: A. SRH(쇼클리-리드-홀) 재결합

금속 불순물이나 결정 결함이 만드는 깊은 준위(트랩)가 전자와 정공을 차례로 붙잡아 재결합시키는 과정이 SRH 재결합입니다. 트랩의 준위가 갭 중앙에 가까울수록 효율적으로 작용합니다. 실리콘 같은 간접 천이형에서는 주요 재결합 과정이며 소수 캐리어의 라이프타임을 결정합니다. 공핍층 안에서의 SRH 과정에 의한 생성은 pn 접합의 역방향 누설 전류나 이미지 센서의 암전류의 주된 원인이기도 합니다.

반도체 물리의 다른 문제

  1. 소수 캐리어의 확산 계수를 D, 라이프타임을 τ라고 할 때, 확산 길이 L을 나타내는 식은 무엇입니까?
  2. 실리콘의 밴드갭은 온도가 올라가면 어떻게 됩니까?
  3. 실리콘 속 전자에 강한 전계를 가하면 드리프트 속도는 어떻게 됩니까?
  4. 파장 620 nm인 빛의 광자 1개가 가진 에너지에 가장 가까운 값은 무엇입니까? (E [eV] ≈ 1240 / λ [nm])
  5. 실리콘의 불순물 농도를 높이면 캐리어의 이동도는 일반적으로 어떻게 됩니까?

이 분야의 비교

  • 직접 천이형과 간접 천이형 반도체의 차이점직접 천이형과 간접 천이형 반도체를 표로 비교합니다. 밴드 구조, 포논의 관여, 발광 효율, 캐리어 수명, 빛의 흡수 깊이, 대표 재료, 용도를 다룹니다.
  • n형 반도체와 p형 반도체의 차이점 정리n형과 p형 반도체를 표로 비교합니다. 첨가하는 불순물(도너와 억셉터), 다수 캐리어, 불순물 준위, 페르미 준위의 위치, 이동도와 비저항, 소자에서 쓰이는 곳을 다룹니다.
