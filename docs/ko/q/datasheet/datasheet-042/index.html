데이터시트 읽는 법

QFP나 SOP 등의 패키지에서 핀 번호를 매기는 일반적인 방법으로 올바른 것은 무엇입니까?

  1. A인덱스 마크 근처가 1번 핀이며, 위에서 보았을 때 시계 방향으로 번호가 증가한다
  2. B인덱스 마크 근처가 1번 핀이며, 위에서 보았을 때 반시계 방향으로 번호가 증가한다
  3. C인쇄된 문자를 읽을 수 있는 방향으로 놓았을 때 오른쪽 아래가 1번 핀이며, 왼쪽으로 번호가 증가한다
정답과 해설 보기

정답: B. 인덱스 마크 근처가 1번 핀이며, 위에서 보았을 때 반시계 방향으로 번호가 증가한다

패키지 상면에는 움푹 파인 홈이나 점, 노치, 모따기 등의 인덱스 마크가 있으며, 그 근처가 1번 핀입니다. 위에서 보았을 때 반시계 방향으로 2번, 3번으로 번호가 증가하는 것이 일반적입니다. 데이터시트의 핀 배치도가 상면도(Top View)인지 저면도(Bottom View)인지도 반드시 확인합니다. 저면도에서는 좌우가 반전되어 보이므로, 혼동하면 기판의 풋프린트가 거울상이 되는 실수로 이어집니다. BGA에서는 행을 알파벳, 열을 숫자로 나타낸 A1과 같은 번호를 사용합니다.

데이터시트 읽는 법의 다른 문제

  1. QFN 패키지 뒷면에 있는 큰 노출 패드(익스포즈드 패드)의 일반적인 취급으로 올바른 것은 무엇입니까?
  2. 데이터시트에 'ESD 내성: HBM ±2 kV, CDM ±500 V'라고 되어 있다. 이 값의 해석으로 올바른 것은 무엇입니까?
  3. MSL 3(습기 민감도 레벨 3)으로 표시된 표면 실장 부품의 취급으로 올바른 것은 무엇입니까?
  4. 전자 부품의 'RoHS 대응'의 의미로 올바른 것은 무엇입니까?
  5. 데이터시트의 개정 이력(Revision History)을 확인하는 주된 목적은 무엇입니까?
