데이터시트 읽는 법

CMOS 로직 IC의 출력 하나에 다수의 CMOS 입력을 연결했을 때 주로 문제가 되는 것은 무엇입니까?

  1. A입력에 흐르는 직류 전류의 합계가 mA 단위가 되어, 출력이 H 레벨을 유지할 수 없게 된다
  2. B연결한 입력의 수에 비례하여, 출력의 H 레벨 전압이 전원 전압보다 높아져 간다
  3. C입력 용량의 합계가 커져, 신호의 상승·하강이 느려지고 전파 지연이 늘어난다
정답과 해설 보기

정답: C. 입력 용량의 합계가 커져, 신호의 상승·하강이 느려지고 전파 지연이 늘어난다

출력 하나에 연결할 수 있는 입력의 수를 팬아웃이라고 합니다. CMOS 입력의 직류 입력 전류는 max로도 수 µA 이하로 작기 때문에, 직류 전류만으로 생각하면 팬아웃은 거의 제한되지 않습니다. 실제로는 입력 하나당 수 pF의 입력 용량이 병렬로 더해지므로, 입력을 늘릴수록 충방전에 시간이 걸려 지연이 증가합니다. 데이터시트의 전파 지연은 CL = 15 pF나 50 pF 등의 부하 용량 조건에서 규정되어 있으므로, 배선을 포함한 용량과 비교하여 읽습니다.

데이터시트 읽는 법의 다른 문제

  1. 동작 전류가 '120 µA/MHz'로 규정된 마이크로컨트롤러를 16 MHz로 동작시킬 때, 동작 전류는 대략 얼마입니까?
  2. 대기 전류가 '25 ℃에서 typ 0.5 µA, 85 ℃에서 max 10 µA'와 같이 온도별로 규정되어 있는 주된 이유는 무엇입니까?
  3. 리니어 레귤레이터의 '정지 전류(IQ)'에 대한 설명으로 올바른 것은 무엇입니까?
  4. 코어용 1.0 V와 I/O용 3.3 V의 두 전원을 가진 IC의 데이터시트에서 전원 투입 순서가 지정되어 있는 주된 이유는 무엇입니까?
  5. 전원이 들어가지 않은 IC의 입력 단자에 다른 회로로부터 3.3 V 신호가 인가되었을 때 일어날 수 있는 일로 올바른 것은 무엇입니까?
