데이터시트 읽는 법

전기적 특성표의 각주에 '설계 및 특성 평가로 보증. 출하 시험은 실시하지 않음'이라고 적힌 항목의 의미로 올바른 것은 무엇입니까?

  1. A전수 측정은 하지 않았지만, 설계와 평가 데이터를 근거로 제조사가 보증하는 값
  2. B참고용으로 제시했을 뿐인 값으로, 제조사는 이 값에 대해 아무것도 보증하지 않는다
  3. C출하 전에 전수 측정한 값으로, 표 중에서도 가장 엄격하게 관리되는 값
정답과 해설 보기

정답: A. 전수 측정은 하지 않았지만, 설계와 평가 데이터를 근거로 제조사가 보증하는 값

양산 시 출하 시험에서는 시험 시간이나 비용 문제로 모든 항목을 전수 측정하지는 않습니다. 입력 커패시턴스나 일부 타이밍처럼 측정이 어려운 항목은 설계 해석이나, 온도와 전원 전압을 바꿔 가며 수행한 특성 평가 데이터로 보증합니다. 이 주석이 있는 값도 min/max라면 보증값으로 취급할 수 있지만, 근거가 전수 시험이 아니므로 여유를 두고 사용하는 것이 안전합니다. 보증이 없는 typ 값과는 구별하여 읽습니다.

데이터시트 읽는 법의 다른 문제

  2. 출력 측 IC가 VOH(min) = 2.9 V, VOL(max) = 0.4 V, 입력 측 IC가 VIH(min) = 2.0 V, VIL(max) = 0.8 V일 때 L 레벨의 노이즈 마진은 얼마입니까?
  3. 3.3 V 전원 IC의 출력을 5 V 전원으로 동작하는 CMOS 입력(VIH(min) = 0.7 × VDD)에 직접 연결할 때의 문제로 올바른 것은 무엇입니까?
