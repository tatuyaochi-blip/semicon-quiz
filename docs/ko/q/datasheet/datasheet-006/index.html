데이터시트 읽는 법

전기적 특성표 첫머리에 '특별한 언급이 없는 한 Ta = 25 ℃, VDD = 3.3 V'라고 적혀 있다. 이 표를 읽을 때의 주의점으로 올바른 것은 무엇입니까?

  1. A온도나 전원 전압이 다르면 값이 달라질 수 있으므로, 전체 온도 범위에서 규정된 값이나 그래프도 확인한다
  2. B이 조건은 측정 장비의 설정을 기록한 것에 불과하므로, 설계에서는 특별히 신경 쓸 필요가 없다
  3. C25 ℃에서의 값이 가장 나쁜 값이므로, 다른 온도에서는 이보다 좋은 값이 된다
정답과 해설 보기

정답: A. 온도나 전원 전압이 다르면 값이 달라질 수 있으므로, 전체 온도 범위에서 규정된 값이나 그래프도 확인한다

전기적 특성 값은 온도, 전원 전압, 부하 등의 측정 조건과 함께여야 의미를 가집니다. 첫머리의 조건은 각 행에 별도 조건이 적혀 있지 않은 모든 항목에 적용됩니다. 누설 전류는 고온에서 증가하고 출력 구동 능력은 전원 전압이 낮으면 떨어지는 등, 조건이 바뀌면 값이 크게 달라집니다. 많은 데이터시트에서는 −40~85 ℃ 등 전체 온도 범위에서 보증하는 값을 별도 열이나 굵은 글씨로 표시하므로, 실제 사용 조건에 맞는 행을 읽습니다.

데이터시트 읽는 법의 다른 문제

  1. 전기적 특성표의 각주에 '설계 및 특성 평가로 보증. 출하 시험은 실시하지 않음'이라고 적힌 항목의 의미로 올바른 것은 무엇입니까?
  2. 입력 임계값이 VIH(min) = 2.0 V, VIL(max) = 0.8 V로 규정된 IC의 입력 단자에 1.4 V의 전압을 인가했다. 어떻게 판정됩니까?
  3. 출력 측 IC가 VOH(min) = 2.9 V, VOL(max) = 0.4 V, 입력 측 IC가 VIH(min) = 2.0 V, VIL(max) = 0.8 V일 때 L 레벨의 노이즈 마진은 얼마입니까?
  4. 3.3 V 전원 IC의 출력을 5 V 전원으로 동작하는 CMOS 입력(VIH(min) = 0.7 × VDD)에 직접 연결할 때의 문제로 올바른 것은 무엇입니까?
  5. 데이터시트에서 입력 단자가 '5 V 톨러런트'라고 되어 있는 의미로 올바른 것은 무엇입니까?
