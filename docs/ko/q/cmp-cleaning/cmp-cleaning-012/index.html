CMP와 세정

STI 형성 CMP에서 실리콘 질화막에 대한 산화막의 연마 선택비를 높이기 위해 자주 사용되는 연마 입자는?

  1. A세리아(산화세륨)
  2. B철 분말
  3. C다이아몬드 거친 입자
정답과 해설 보기

정답: A. 세리아(산화세륨)

세리아(산화세륨)는 산화막과 화학적으로 결합하여 효율적으로 깎이는 한편, 첨가제(아미노산 등의 계면활성제)가 질화막 표면에 흡착하여 연마를 억제하므로, 질화막에 대한 산화막의 연마 선택비를 수십~100 이상으로 높일 수 있습니다. 질화막을 스토퍼로 사용하는 STI의 CMP에서 평탄도와 연마 정지 용이성을 동시에 확보하기 위해 사용됩니다. 적은 입자로도 빠르게 연마할 수 있다는 것도 특징입니다.

CMP와 세정의 다른 문제

  1. MHz 대역의 초음파를 세정액에 가하여 웨이퍼 표면의 미세한 파티클을 제거하는 세정 방법은?
  2. 오존을 녹인 초순수(오존수)를 세정에 사용하는 주된 목적은?
  3. Cu 배선 CMP 슬러리에 첨가되는 벤조트리아졸(BTA) 등의 역할로 올바른 것은?
  4. CMP 연마 헤드에서 웨이퍼 주위를 둘러싸는 리테이너 링의 역할은?
  5. SC-1과 같은 알칼리성 세정액에서 한 번 떨어져 나간 파티클이 재부착되기 어려운 이유로 올바른 것은?

이 분야의 비교

  • SC-1·SC-2·희석 불산의 차이: 약액·제거하는 오염·세정 후 표면 비교RCA 세정의 SC-1(APM), SC-2(HPM), 희석 불산(DHF)을 표로 비교합니다. 약액, pH와 온도, 제거하는 것, 원리, 식각, 세정 후 표면, 부작용과 공정 순서를 정리합니다.
