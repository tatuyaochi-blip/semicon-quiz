정답: A. 텅스텐 표면을 연마하기 쉬운 산화물로 바꾸기 위해

텅스텐은 단단한 금속이라 그대로 기계적으로 연마하기가 어렵습니다. 과산화수소나 철염 등의 산화제로 표면을 무른 산화텅스텐으로 바꾸고, 이를 연마 입자로 제거하는 과정을 반복하며 연마가 진행됩니다. 연마 속도는 산화제 농도에 크게 의존하며, CMP에서 '화학' 부분의 역할을 잘 보여 주는 예입니다. 한편 오목부의 산화·부식을 억제하는 방안도 필요합니다.
