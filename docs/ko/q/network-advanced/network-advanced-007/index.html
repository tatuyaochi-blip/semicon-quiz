네트워크 설계와 운용

STP에서 스위치 3대의 브리지 ID가 다음과 같이 알려져 있다. SW1은 우선순위 32768, MAC 주소 00-00-5E-00-53-01, SW2는 우선순위 61440, MAC 주소 00-00-5E-00-53-05, SW3은 우선순위 4096, MAC 주소 00-00-5E-00-53-0A이다. 루트 브리지로 선출되는 스위치는?

  1. ASW1
  2. BSW2
  3. CSW3
정답과 해설 보기

정답: C. SW3

STP에서는 브리지 ID가 가장 작은 스위치가 루트 브리지가 됩니다. 브리지 ID는 우선순위를 상위에, MAC 주소를 하위에 나열한 값이므로, 먼저 우선순위를 비교하고 같을 때만 MAC 주소를 비교합니다. 여기서는 우선순위가 가장 작은 4096인 SW3이 MAC 주소와 관계없이 루트 브리지가 됩니다. 우선순위의 기본값은 32768이며, 아무것도 설정하지 않으면 MAC 주소가 가장 작은 스위치가 선출되어 버리므로, 중심에 둘 스위치의 우선순위를 작게 설정해 두는 것이 일반적입니다.

네트워크 설계와 운용의 다른 문제

  1. 스위치 SW1, SW2, SW3 3대를 서로 링크 1개씩으로 삼각형으로 연결했다. STP의 루트 브리지는 SW1이고, 브리지 ID는 SW2가 SW3보다 작다. 모든 링크의 경로 비용은 같다고 한다. 차단되는(프레임을 전달하지 않는) 포트는?
  2. 기존의 STP(IEEE 802.1D)는 기본 타이머 그대로라면 장애 후 차단되어 있던 포트가 전송을 시작하기까지 30~50초 정도 걸린다. RSTP가 전환을 빠르게 한 구조로 올바른 것은?
  3. 스위치 2대 사이의 1 Gbps 링크 4개를 링크 어그리게이션으로 하나의 논리적인 링크로 묶었다. 프레임은 출발지와 목적지의 주소나 포트 번호의 조합(플로)마다 어느 링크로 보낼지 정하는 일반적인 방식으로 분배한다. TCP 연결 하나로 얻을 수 있는 처리량의 상한에 가장 가까운 것은?
  4. VLAN 10(192.168.10.0/24)과 VLAN 20(192.168.20.0/24)을 가진 L2 스위치에 라우터를 링크 하나로 연결하여, 두 VLAN 사이에서 통신할 수 있게 하고 싶다. 이 구성의 설정으로 적절한 것은?
  5. 라우터 R1(192.168.1.2)과 R2(192.168.1.3) 2대로 VRRP를 구성하고, 가상 IP 주소를 192.168.1.254로 했다. 평소에는 R1이 마스터로서 전달하고 있다. LAN 단말의 기본 게이트웨이로 설정할 주소로 적절한 것은?
