네트워크 설계와 운용

VLAN 20(192.168.20.0/24)의 단말에 다른 네트워크에 있는 DHCP 서버 10.0.0.5로부터 주소를 할당한다. 이를 위해 VLAN 20의 기본 게이트웨이인 L3 스위치의 인터페이스(192.168.20.1)에 DHCP 릴레이 에이전트를 설정했다. 릴레이 에이전트의 동작으로 올바른 것은?

  1. A단말이 브로드캐스트로 보낸 DHCP 메시지를 받아, 자신의 VLAN 20 쪽 주소 192.168.20.1을 기록하고 10.0.0.5로 유니캐스트로 전달한다. 서버는 이 주소를 보고 192.168.20.0/24용 범위에서 주소를 고른다
  2. BL3 스위치가 받은 브로드캐스트를 모든 네트워크로 전달하게 되어, DHCP 메시지가 서버에 도달한다
  3. CL3 스위치가 DHCP 서버 대신 주소를 정해 단말에 대여하고, 10.0.0.5에는 결과를 알리기만 하게 된다
정답과 해설 보기

정답: A. 단말이 브로드캐스트로 보낸 DHCP 메시지를 받아, 자신의 VLAN 20 쪽 주소 192.168.20.1을 기록하고 10.0.0.5로 유니캐스트로 전달한다. 서버는 이 주소를 보고 192.168.20.0/24용 범위에서 주소를 고른다

아직 주소가 없는 단말은 DHCP 서버를 찾는 Discover를 브로드캐스트로 보내지만, 라우터나 L3 스위치는 브로드캐스트를 다른 네트워크로 전달하지 않습니다. DHCP 릴레이 에이전트는 이 메시지를 받아 서버로 유니캐스트로 중계하고, 서버의 응답을 단말에 돌려줍니다. 중계할 때는 메시지 안의 필드(giaddr)에 단말 쪽 인터페이스의 주소(여기서는 192.168.20.1)를 기록합니다. 서버는 이 주소를 보고 단말이 있는 서브넷(192.168.20.0/24)을 알아내, 그 서브넷용 범위에서 주소를 고릅니다. 이렇게 하면 VLAN마다 서버를 두지 않아도 DHCP 서버 1대로 많은 서브넷을 담당할 수 있습니다.

네트워크 설계와 운용의 다른 문제

  1. 어떤 도메인 앞으로 온 전자 메일을 받는 메일 서버를 지정하는 DNS 리소스 레코드는?
  2. DNS 이름 해석에서 재귀적 질의와 비재귀적(반복적) 질의가 쓰이는 방식으로 올바른 것은?
  3. 웹 서버 이전으로 www.example.com의 A 레코드의 IP 주소를 변경한다. 이 레코드의 TTL은 현재 86400초이며, 변경 후 오래된 주소가 쓰이는 시간을 최대로도 5분 정도로 하고 싶으므로, 미리 TTL을 300초로 낮춰 둔다. 리졸버는 TTL대로 캐시한다고 한다. TTL을 낮추는 설정을 하는 기한으로 올바른 것은?
  4. NAPT를 하는 라우터(외부 주소는 198.51.100.7)에 '외부 TCP 8080번 포트에 도착한 통신을 내부 웹 서버 192.168.1.20의 80번 포트로 전달한다'는 포트 포워딩(목적지만 변환하는 정적 설정)을 했다. 인터넷상의 단말 203.0.113.9가 출발지 포트 51000으로 198.51.100.7의 8080번 포트에 접속했을 때, 웹 서버가 받는 패킷의 목적지와 출발지 조합은?
  5. 라우터의 인터페이스에, 들어오는 패킷을 위에서부터 차례로 검사하는 ACL을 설정했다. 규칙 1은 '목적지 10.0.0.10의 TCP 443번 포트로 가는 통신을 허용', 규칙 2는 '출발지가 192.168.1.0/24인 통신을 모두 거부', 규칙 3은 '출발지가 192.168.0.0/16이고 목적지가 TCP 80번 포트인 통신을 허용'이며, 그 밖의 규칙은 없다. ㄱ '192.168.1.5에서 10.0.0.10의 TCP 443번 포트로', ㄴ '192.168.1.5에서 10.0.0.20의 TCP 80번 포트로', ㄷ '192.168.2.5에서 10.0.0.20의 TCP 80번 포트로', ㄹ '192.168.2.5에서 10.0.0.20의 TCP 22번 포트로'의 4개 패킷 중 통과할 수 있는 것을 모두 고른 것은?

이 분야의 비교

  • 거리 벡터형과 링크 상태형 라우팅 프로토콜의 차이: RIP와 OSPF로 보는 경로 계산·수렴·규모 비교거리 벡터형(RIP 등)과 링크 상태형(OSPF 등) 라우팅 프로토콜을 한 장의 표로 비교합니다. 각 라우터가 아는 것, 경로 계산, 메트릭, 갱신 방식, 수렴 속도와 루프, 네트워크 규모, 자원…
  • OSPF와 BGP의 차이: IGP와 EGP·경로 선택 방식·이웃 라우터와의 연결 방식·규모 비교OSPF와 BGP를 한 장의 표로 비교합니다. 분류와 범위(IGP와 EGP), 프로토콜 방식, 경로 선택, 루프 방지, 이웃과의 연결 방식, 갱신 방식, 수렴 속도, 다루는 경로 수를 정리합니다.
  • STP와 RSTP의 차이: 포트의 상태와 역할·전환 속도·BPDU·호환성 비교STP(IEEE 802.1D)와 RSTP(IEEE 802.1w)를 한 장의 표로 비교합니다. 규격, 포트 상태, 포트 역할, 장애 후 복구 시간, 빠른 전환의 구조, BPDU 송신과 장애 감지, …
