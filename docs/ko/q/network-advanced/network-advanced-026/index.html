네트워크 설계와 운용

NAPT를 하는 라우터(외부 주소는 198.51.100.7)에 '외부 TCP 8080번 포트에 도착한 통신을 내부 웹 서버 192.168.1.20의 80번 포트로 전달한다'는 포트 포워딩(목적지만 변환하는 정적 설정)을 했다. 인터넷상의 단말 203.0.113.9가 출발지 포트 51000으로 198.51.100.7의 8080번 포트에 접속했을 때, 웹 서버가 받는 패킷의 목적지와 출발지 조합은?

  1. A목적지 198.51.100.7:8080, 출발지 203.0.113.9:51000
  2. B목적지 192.168.1.20:80, 출발지 203.0.113.9:51000
  3. C목적지 192.168.1.20:80, 출발지 198.51.100.7:51000
정답과 해설 보기

정답: B. 목적지 192.168.1.20:80, 출발지 203.0.113.9:51000

포트 포워딩에서 라우터는 외부 주소와 포트(198.51.100.7:8080) 앞으로 도착한 패킷의 목적지를 설정한 내부 주소와 포트(192.168.1.20:80)로 바꿔 씁니다. 출발지는 바꿔 쓰지 않으므로, 웹 서버에는 203.0.113.9:51000에서 온 것으로 보이며 접속 기록에도 상대의 실제 주소가 남습니다. 서버의 응답은 기본 게이트웨이인 이 라우터를 지나며, 라우터는 변환 테이블을 보고 출발지를 198.51.100.7:8080으로 되돌려 쓴 뒤 단말에 돌려줍니다. 외부에서 시작되는 통신은 평소의 NAPT로는 변환 테이블에 대응이 없어 내부에 도달하지 않으므로, 내부에서 서버를 공개하려면 이 설정이 필요합니다.

네트워크 설계와 운용의 다른 문제

  1. 라우터의 인터페이스에, 들어오는 패킷을 위에서부터 차례로 검사하는 ACL을 설정했다. 규칙 1은 '목적지 10.0.0.10의 TCP 443번 포트로 가는 통신을 허용', 규칙 2는 '출발지가 192.168.1.0/24인 통신을 모두 거부', 규칙 3은 '출발지가 192.168.0.0/16이고 목적지가 TCP 80번 포트인 통신을 허용'이며, 그 밖의 규칙은 없다. ㄱ '192.168.1.5에서 10.0.0.10의 TCP 443번 포트로', ㄴ '192.168.1.5에서 10.0.0.20의 TCP 80번 포트로', ㄷ '192.168.2.5에서 10.0.0.20의 TCP 80번 포트로', ㄹ '192.168.2.5에서 10.0.0.20의 TCP 22번 포트로'의 4개 패킷 중 통과할 수 있는 것을 모두 고른 것은?
  2. IPv6에서 같은 링크 안에서만 쓰이며, IPv6를 쓰는 인터페이스에는 반드시 자동으로 설정되는 링크 로컬 주소의 범위는?
  3. IPv6의 SLAAC(상태 비저장 주소 자동 설정)에서 단말이 글로벌 유니캐스트 주소를 만드는 방법으로 올바른 것은?
  4. MAC 주소가 00-1A-2B-3C-4D-5E인 인터페이스가 프리픽스 2001:db8:1:1::/64와 EUI-64 형식의 인터페이스 ID로 SLAAC에 의해 주소를 만든다. 만들어지는 주소는?
  5. IPv6로만 동작하는 두 거점을 IPv4로만 동작하는 네트워크를 통해 연결하고, 거점 사이를 IPv6 패킷 그대로 통신시키고 싶다. 사용할 방법으로 적절한 것은?

이 분야의 비교

  • 거리 벡터형과 링크 상태형 라우팅 프로토콜의 차이: RIP와 OSPF로 보는 경로 계산·수렴·규모 비교거리 벡터형(RIP 등)과 링크 상태형(OSPF 등) 라우팅 프로토콜을 한 장의 표로 비교합니다. 각 라우터가 아는 것, 경로 계산, 메트릭, 갱신 방식, 수렴 속도와 루프, 네트워크 규모, 자원…
  • OSPF와 BGP의 차이: IGP와 EGP·경로 선택 방식·이웃 라우터와의 연결 방식·규모 비교OSPF와 BGP를 한 장의 표로 비교합니다. 분류와 범위(IGP와 EGP), 프로토콜 방식, 경로 선택, 루프 방지, 이웃과의 연결 방식, 갱신 방식, 수렴 속도, 다루는 경로 수를 정리합니다.
  • STP와 RSTP의 차이: 포트의 상태와 역할·전환 속도·BPDU·호환성 비교STP(IEEE 802.1D)와 RSTP(IEEE 802.1w)를 한 장의 표로 비교합니다. 규격, 포트 상태, 포트 역할, 장애 후 복구 시간, 빠른 전환의 구조, BPDU 송신과 장애 감지, …
