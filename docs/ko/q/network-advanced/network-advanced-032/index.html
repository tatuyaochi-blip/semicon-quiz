네트워크 설계와 운용

traceroute에서 출발지로부터 세어 4번째 라우터가 ICMP 시간 초과(Time Exceeded) 메시지를 돌려보내게 하려고 보내는 패킷의 IP 헤더 TTL 값은?

  1. A3
  2. B4
  3. C5
정답과 해설 보기

정답: B. 4

라우터는 패킷을 전달할 때마다 TTL을 1 줄이고, 0이 된 패킷은 버리고 출발지에 ICMP 시간 초과 메시지를 돌려보냅니다. TTL을 4로 하여 보내면 1번째에서 3, 2번째에서 2, 3번째에서 1이 되고 4번째에서 0이 되므로, 4번째 라우터가 메시지를 돌려보냅니다. traceroute는 TTL을 1, 2, 3…으로 하나씩 늘리면서 패킷을 보내고, 돌아온 메시지의 출발지 주소와 시간으로부터 경로상의 라우터와 지연을 차례로 표시합니다. 목적지까지 도달하면 목적지로부터의 응답(ICMP 에코 응답이나 목적지 포트에 도달할 수 없음을 나타내는 메시지)으로 끝을 압니다.

네트워크 설계와 운용의 다른 문제

  1. 어떤 단말에서 웹 서버 198.51.100.80까지 traceroute를 실행했더니, 1~5번째 줄에 192.168.1.1, 10.0.0.1, '* * *'(응답 없음), 203.0.113.1, 198.51.100.80 순으로 표시되었고, 웹 서버도 문제없이 쓸 수 있었다. 3번째 줄의 해석으로 가장 적절한 것은?
  2. IPv4에서 전체 길이 4000바이트(헤더 20바이트, 데이터 3980바이트)의 패킷이 MTU가 1500바이트인 링크에서 분할(프래그먼트화)된다. 분할된 패킷의 헤더도 20바이트이며, 분할해도 되는 설정이라고 한다. 마지막 프래그먼트의 프래그먼트 오프셋 필드 값은?
  3. 거점 간 VPN 터널을 통해 먼 곳의 웹 서버와 통신하고 있다. TCP 연결은 확립되고 작은 페이지는 표시되지만, 큰 파일의 다운로드만 도중에 멈춰 버린다. 터널 안의 MTU는 1400바이트이며, 서버는 1500바이트의 패킷을 분할 금지(DF 비트를 1)로 하여 보내고 있다. 또한 서버 앞단의 방화벽은 ICMP를 모두 버리는 설정으로 되어 있다. 원인으로 가장 적절한 것은?
  4. QoS 제어에서 쓰이는 IP 헤더의 DSCP에 대한 설명으로 올바른 것은?
  5. 라우터 출구의 70 Mbps 링크에서 3개의 큐를 가중치 4:2:1의 가중 라운드 로빈으로 내보낸다. 3개의 큐에는 항상 보낼 패킷이 쌓여 있고, 패킷 크기는 모두 같다고 한다. 가중치 2인 큐가 쓸 수 있는 대역폭에 가장 가까운 것은?

이 분야의 비교

  • 거리 벡터형과 링크 상태형 라우팅 프로토콜의 차이: RIP와 OSPF로 보는 경로 계산·수렴·규모 비교거리 벡터형(RIP 등)과 링크 상태형(OSPF 등) 라우팅 프로토콜을 한 장의 표로 비교합니다. 각 라우터가 아는 것, 경로 계산, 메트릭, 갱신 방식, 수렴 속도와 루프, 네트워크 규모, 자원…
  • OSPF와 BGP의 차이: IGP와 EGP·경로 선택 방식·이웃 라우터와의 연결 방식·규모 비교OSPF와 BGP를 한 장의 표로 비교합니다. 분류와 범위(IGP와 EGP), 프로토콜 방식, 경로 선택, 루프 방지, 이웃과의 연결 방식, 갱신 방식, 수렴 속도, 다루는 경로 수를 정리합니다.
  • STP와 RSTP의 차이: 포트의 상태와 역할·전환 속도·BPDU·호환성 비교STP(IEEE 802.1D)와 RSTP(IEEE 802.1w)를 한 장의 표로 비교합니다. 규격, 포트 상태, 포트 역할, 장애 후 복구 시간, 빠른 전환의 구조, BPDU 송신과 장애 감지, …
