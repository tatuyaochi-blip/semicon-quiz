실리콘 포토닉스

광 트랜시버에서 4가닥의 광섬유에 1파장씩 신호를 보내는 병렬 방식과, 4개의 파장을 한 가닥의 광섬유로 묶는 CWDM 방식의 비교로 올바른 것은?

  1. A병렬 방식은 광섬유 1가닥으로 충분하지만, 파장이 다른 4개의 레이저와 합분파기가 필요하다
  2. B병렬 방식은 합파기나 분파기가 필요 없지만 광섬유가 많이 필요하고, CWDM 방식은 광섬유가 적지만 합분파기가 필요하다
  3. CCWDM 방식은 송신에만 4가닥의 광섬유가 필요하지만, 모두 같은 파장의 레이저로 충분하다
정답과 해설 보기

정답: B. 병렬 방식은 합파기나 분파기가 필요 없지만 광섬유가 많이 필요하고, CWDM 방식은 광섬유가 적지만 합분파기가 필요하다

병렬 방식(PSM이라고도 합니다)은 송신용과 수신용으로 각각 4가닥, 합계 8가닥의 단일 모드 광섬유를 사용하며, 각 광섬유에 같은 파장의 빛으로 1레인분의 신호를 보냅니다. 합파기나 분파기가 필요 없고 하나의 레이저 빛을 나누어 사용할 수도 있지만, 광섬유나 다심 커넥터의 수가 늘어납니다. CWDM 방식은 송신과 수신에 1가닥씩, 합계 2가닥의 광섬유로 충분해 기존 배선을 활용하기 쉬운 반면, 파장이 다른 4개의 레이저와 합파기·분파기가 필요합니다. 거리나 배선 사정에 따라 구분하여 사용됩니다.
