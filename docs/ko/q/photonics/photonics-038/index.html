실리콘 포토닉스

DSP를 생략한 리니어 드라이브 광 트랜시버의 과제로 올바른 것은?

  1. ADSP가 없는 만큼 모듈의 소비 전력이 DSP를 사용하는 방식보다 커져 버린다
  2. B신호 보상을 호스트의 SerDes에 의존하므로, 호스트나 기판 배선을 포함한 시스템 전체에서 성능을 보증해야 한다
  3. CDSP가 없으면 광 신호를 만들 수 없으므로, 전기 배선 대신 사용할 수 없다
정답과 해설 보기

정답: B. 신호 보상을 호스트의 SerDes에 의존하므로, 호스트나 기판 배선을 포함한 시스템 전체에서 성능을 보증해야 한다

리니어 드라이브에서는 모듈 안에서 신호를 다시 받아 정돈하는 부분이 없기 때문에, 호스트 SerDes의 송신 파형, 기판 배선의 손실, 드라이버와 변조기, 광섬유, 수신 측의 특성이 모두 이어진 하나의 전송로로서 성능이 결정됩니다. 어느 한 부분의 성능이 부족하면 전체의 오류가 늘어나고, 서로 다른 회사의 제품을 조합했을 때의 상호 운용성 확인도 어려워집니다. 또한 모듈 안에서 신호를 다시 정돈할 수 없는 만큼, 도달 거리는 데이터센터 내의 비교적 짧은 범위가 중심입니다. 소비 전력과 지연은 DSP를 사용하는 방식보다 작아집니다.
