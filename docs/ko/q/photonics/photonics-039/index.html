실리콘 포토닉스

데이터센터 내 광 연결에서 널리 사용되는 강도 변조·직접 검파(IM-DD) 방식에서 PAM4를 사용할 때, 4가지 값으로 바꾸고 있는 것은?

  1. A빛의 위상
  2. B빛의 편광 방향
  3. C빛의 세기(파워)
정답과 해설 보기

정답: C. 빛의 세기(파워)

IM-DD(Intensity Modulation / Direct Detection)에서는 송신 측에서 빛의 세기를 변조하고, 수신 측에서는 포토다이오드로 빛의 세기를 직접 전류로 바꾸어 판정합니다. PAM4에서는 빛의 세기를 4단계로 바꾸어, 하나의 심볼로 2비트를 보냅니다. 광검출기는 빛의 세기만 검출할 수 있지만, 그만큼 구성이 간단하여 저비용·저소비 전력입니다. 빛의 위상이나 편광에도 정보를 실으려면 수신 측에서 별도 레이저의 빛과 간섭시켜 검출하는 코히어런트 방식이 필요하며, 회로가 복잡해집니다.

실리콘 포토닉스의 다른 문제

  1. PAM4로 1파장당 약 106 Gb/s(오류 정정 부호 등을 포함)의 신호를 보낼 때의 심볼 레이트(1초당 심볼 수)에 가장 가까운 것은?
  2. 데이터센터 간을 잇는 수십 km 이상의 연결 등에 사용되는 코히어런트 방식의, IM-DD 방식과 비교한 특징으로 올바른 것은?
  3. 800 Gb/s 광 트랜시버의 소비 전력이 16 W일 때, 1비트당 에너지는 얼마인가?
  4. 총 51.2 Tb/s의 대역을 가진 스위치에서 모든 광 연결을 1비트당 5 pJ로 수행할 때, 광 연결의 소비 전력에 가장 가까운 것은?
  5. 파장 850 nm 부근의 VCSEL과 다중 모드 광섬유를 조합한 광 연결의 특징으로 올바른 것은?

이 분야의 비교

  • 싱글모드와 멀티모드 광섬유의 차이점싱글모드와 멀티모드 광섬유를 표로 비교합니다. 코어 직경, 사용 파장과 광원, 도달 거리, 모드 분산, 손실, 부품 비용, 용도를 다룹니다.
