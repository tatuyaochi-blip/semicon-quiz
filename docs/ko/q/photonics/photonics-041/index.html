실리콘 포토닉스

데이터센터 간을 잇는 수십 km 이상의 연결 등에 사용되는 코히어런트 방식의, IM-DD 방식과 비교한 특징으로 올바른 것은?

  1. A광검출기로 빛의 세기만 직접 검출하므로, IM-DD 방식보다 구성이 간단하고 부품도 저렴하다
  2. B위상이나 편광에도 정보를 실어 장거리·대용량에 적합하지만, DSP 등의 회로가 복잡하고 소비 전력도 크다
  3. C빛의 위상을 사용하지 않기 때문에, 레이저 파장의 순도(선폭)는 거의 문제가 되지 않는다
정답과 해설 보기

정답: B. 위상이나 편광에도 정보를 실어 장거리·대용량에 적합하지만, DSP 등의 회로가 복잡하고 소비 전력도 크다

코히어런트 방식에서는 빛의 진폭과 위상, 나아가 직교하는 두 편광 각각에 정보를 실어(편광 다중 16QAM 등), 1심볼로 많은 비트를 보낼 수 있습니다. 수신 측에서는 국부 발진용 레이저의 빛과 신호광을 간섭시켜 위상을 추출하고, 고성능 DSP로 파장 분산 등을 한꺼번에 보상합니다. 따라서 장거리에서도 높은 속도를 유지할 수 있지만, 선폭이 좁은 레이저와 복잡한 회로가 필요하여 소비 전력과 비용이 커집니다. 데이터센터 내의 짧은 연결에서는 구성이 간단한 IM-DD 방식이 주류입니다.
