Linux와 커맨드 라인 기초

systemd를 사용하는 Linux에서, 서비스 license.service에 대한 'systemctl start license.service'와 'systemctl enable license.service'의 차이로 올바른 것은?

  1. Astart는 다음에 컴퓨터를 부팅했을 때부터 자동으로 실행되도록 설정하고, enable은 지금 즉시 서비스를 시작한다
  2. Bstart는 지금 즉시 서비스를 시작하고, enable은 컴퓨터를 부팅할 때 자동으로 시작되도록 설정한다
  3. Cstart는 root만 쓸 수 있는 서비스로 시작하고, enable은 일반 사용자에게도 서비스 조작을 허가한다
정답과 해설 보기

정답: B. start는 지금 즉시 서비스를 시작하고, enable은 컴퓨터를 부팅할 때 자동으로 시작되도록 설정한다

systemctl start는 그 서비스를 지금 즉시 시작하지만, 재부팅한 후까지 시작 상태가 남지는 않습니다. systemctl enable은 시스템 부팅 시에 그 서비스가 자동으로 시작되도록 설정하는 것으로, enable만으로는 지금 시작되지 않습니다. 둘을 한 번에 하려면 systemctl enable --now를 사용하며, 멈추는 것은 stop, 자동 시작 설정을 해제하는 것은 disable입니다. 서비스가 동작하고 있는지 여부나 최근 로그는 systemctl status로 확인할 수 있습니다.

Linux와 커맨드 라인 기초의 다른 문제

  2. Linux 서버에서 '디스크 여유 공간이 적다'는 경고가 나왔다. 파일 시스템별 사용량과 여유 용량을 조사하는 명령과, 디렉터리 안의 파일이 사용하는 용량을 합계하여 조사하는 명령의 조합으로 올바른 것은?
