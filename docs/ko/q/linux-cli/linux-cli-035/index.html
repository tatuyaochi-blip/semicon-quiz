Linux와 커맨드 라인 기초

Linux 서버에서 '디스크 여유 공간이 적다'는 경고가 나왔다. 파일 시스템별 사용량과 여유 용량을 조사하는 명령과, 디렉터리 안의 파일이 사용하는 용량을 합계하여 조사하는 명령의 조합으로 올바른 것은?

  1. Adf와 du
  2. Bdu와 df
  3. Cfree와 du
정답과 해설 보기

정답: A. df와 du

df(disk free)는 마운트되어 있는 파일 시스템별로 전체 크기, 사용량, 여유 용량을 표시하며, -h를 붙이면 G나 M 단위로 읽기 쉽게 표시합니다. du(disk usage)는 지정한 디렉터리 아래에 있는 파일이 사용하는 용량을 합계하며, du -sh *처럼 사용하면 어느 디렉터리가 큰지 찾을 수 있습니다. 먼저 df로 가득 찬 파일 시스템을 찾고, 다음으로 du로 그 안의 큰 디렉터리를 좁혀 가는 것이 정석적인 순서입니다. 삭제했지만 아직 열고 있는 프로세스가 있는 파일은 df에서는 사용 중으로 세어지고 du에서는 세어지지 않으므로, 두 값이 맞지 않는 경우가 있습니다.
