Linux와 커맨드 라인 기초

$ name=world
$ echo 'Hello $name'
$ echo "Hello $name"

위의 명령을 순서대로 실행했을 때, 두 echo의 출력으로 올바른 것은?

  1. A첫 번째는 Hello world, 두 번째는 Hello $name
  2. B첫 번째도 두 번째도 Hello world
  3. C첫 번째는 Hello $name, 두 번째는 Hello world
정답과 해설 보기

정답: C. 첫 번째는 Hello $name, 두 번째는 Hello world

셸(shell)에서는 작은따옴표('…')로 감싼 부분은 쓴 그대로의 문자열이 되며, $name 같은 변수는 확장되지 않습니다. 큰따옴표("…") 안에서는 변수가 확장되므로, 두 번째는 Hello world가 됩니다. 큰따옴표는 변수의 값에 공백이 포함되어 있어도 하나의 인수로 다루게 하는 데에도 사용합니다. 또한 대입 'name=world'에서는 = 앞뒤에 공백을 넣을 수 없습니다.
