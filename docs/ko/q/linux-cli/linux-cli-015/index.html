Linux와 커맨드 라인 기초

$ cat words.txt
bat
bt
boat
abet
bit.txt
$ grep '^b.t' words.txt

위의 조작에서 마지막 grep이 출력하는 줄로 올바른 것은?

  1. Abat, bit.txt
  2. Bbat, abet, bit.txt
  3. Cbat, bt, boat, bit.txt
정답과 해설 보기

정답: A. bat, bit.txt

정규 표현식의 ^는 줄의 시작, .은 임의의 한 문자, $는 줄의 끝을 나타냅니다. ^b.t는 '줄의 시작이 b, 이어서 임의의 한 문자, 이어서 t'이므로 bat와 bit.txt에 일치합니다. bt는 b와 t 사이에 문자가 없고, boat는 b의 두 문자 뒤가 a이므로 일치하지 않습니다. abet는 bet 부분이 b.t에 맞지만, 줄의 시작이 a이므로 ^의 조건에 맞지 않습니다.
