성능 분석: 핵심 정리

프로그램의 속도는 실행된 명령어 수, 명령어당 평균 사이클 수(CPI), 사이클 시간의 곱입니다. 한 요소를 개선해도 다른 요소가 나빠지면 프로그램은 빨라지지 않습니다. 암달의 법칙에 따르면 프로그램의 일부만 빠르게 해서는 나머지 부분이 전체 속도 향상의 상한을 결정합니다.

성능을 올바르게 비교하려면 벤치마크를 고르고, 측정하고, 결과를 평균하는 방법에 주의해야 합니다. 이 주제는 CPU 성능 카운터로 캐시 미스와 분기 예측 실패를 세거나, 루프라인 모델로 연산과 메모리 중 어느 쪽이 한계인지 판별하는 등 병목을 분리하는 방법을 다룹니다.
