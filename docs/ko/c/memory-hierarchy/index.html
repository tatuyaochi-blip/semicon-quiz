메모리 계층 구조: 핵심 정리

CPU의 연산은 1 나노초도 걸리지 않지만, DRAM 주기억장치에서 데이터를 읽는 데는 수십에서 100 나노초가 걸립니다. 이 격차를 메우기 위해 컴퓨터는 작고 빠른 캐시에서 크고 느린 주기억장치와 스토리지까지 계층을 쌓고, 자주 쓰는 데이터를 빠른 계층에 둡니다.

캐시가 효과를 내는 것은 프로그램이 시간적·공간적 지역성을 보이기 때문입니다. 직접 사상과 세트 연관 구성, 주소를 태그·인덱스·오프셋으로 나누는 방법, 세 가지 미스 유형, 평균 메모리 접근 시간의 계산 방법을 이해하면 데이터 배치나 루프 순서에 따라 성능이 몇 배나 달라지는 이유를 알 수 있습니다.

이 분야의 비교

  • 라이트스루 vs 라이트백 캐시: 차이점 설명라이트스루와 라이트백 캐시를 표로 비교합니다: 쓰기 정책, 메모리 트래픽, 속도, 일관성, 복잡도, 축출 비용, 대표 용도.
  • 직접 사상 vs 세트 연관 vs 완전 연관 캐시직접 사상, 세트 연관, 완전 연관 캐시를 표로 비교합니다: 블록 배치 위치, 태그 비교, 속도, 비용, 충돌 미스, 용도.
