머신러닝의 기초: 핵심 정리

머신러닝은 데이터로부터 규칙을 자동으로 학습하여 예측이나 분류를 수행하는 기술입니다. 정답 레이블을 사용하는 지도 학습, 레이블이 없는 데이터에서 묶음을 찾아내는 비지도 학습, 보상을 단서로 행동을 학습하는 강화 학습이 있으며, 어느 방법이든 학습에 사용하지 않은 데이터로 얼마나 올바르게 예측할 수 있는지(일반화 성능)가 중요합니다.

여기서는 학습용·검증용·테스트용 데이터를 나누는 방법과 교차 검증, 과적합과 편향·분산, 정칙화나 드롭아웃, 혼동 행렬로부터 구하는 정밀도·재현율·F값, ROC 곡선, 평균 제곱 오차를 계산 문제 중심으로 학습합니다. 선형 회귀, 로지스틱 회귀, 결정 트리, 랜덤 포레스트, k-최근접 이웃 알고리즘, SVM, 나이브 베이즈 같은 대표적인 모델에 이어, 신경망의 순전파, 활성화 함수, 손실 함수, 경사 하강법과 오차 역전파법, 미니배치와 에폭, CNN 출력의 크기, RNN과 Transformer, 전이 학습, 생성 모델, LLM의 토큰까지를 다룹니다. IT 자격시험이나 딥러닝 관련 자격시험의 AI 분야 학습에도 도움이 됩니다.

머신러닝의 기초 전체 문제 (40)
  1. 지도 학습의 과제 중 회귀에 해당하는 것은?
  2. 비지도 학습에 해당하는 것은?
  3. 강화 학습에 대한 설명으로 적절한 것은?
  4. k-평균 알고리즘(k-means)에 의한 클러스터링의 절차로 적절한 것은?
  5. 주성분 분석(PCA)에 대한 설명으로 적절한 것은?
  6. 데이터를 학습용·검증용·테스트용의 3가지로 나눌 때, 검증용 데이터의 주된 용도로 적절한 것은?
  7. 1000건의 데이터로 5-겹 교차 검증(k = 5인 k-겹 교차 검증)을 수행할 때, 1회마다 학습에 사용하는 데이터 건수는?
  8. 과적합(과대적합)이 일어나고 있을 때 보이는 모습으로 적절한 것은?
  9. 모델의 오차를 편향(bias)과 분산(variance)으로 나누어 생각할 때 적절한 것은?
  10. 과적합을 억제하는 정칙화 등의 기법에 대한 설명으로 적절한 것은?
  11. 머신러닝 모델을 만드는 절차 중 데이터 누수(평가에 사용하는 데이터의 정보가 학습에 섞여 들어가는 것)를 일으키는 것은?
  12. 2클래스 분류 모델을 200건의 테스트 데이터로 평가한 혼동 행렬에서 진양성(TP)이 45건, 위양성(FP)이 5건, 위음성(FN)이 45건, 진음성(TN)이 105건이었다. 정밀도와 재현율의 조합으로 올바른 것은?
  13. 2클래스 분류 모델을 200건의 테스트 데이터로 평가했더니 TP가 20건, FP가 5건, FN이 30건, TN이 145건이었다. F값(F1 점수)에 가장 가까운 것은?
  14. 2클래스 분류 모델의 평가에 사용하는 ROC 곡선과 AUC에 대한 설명으로 적절한 것은?
  15. 1000건 중 양성이 10건밖에 없는 데이터에 대해, 모두를 음성으로 예측하는 모델의 정확도는?
  16. 4건의 데이터의 실제 값이 3, 5, 2, 6이고, 모델의 예측값이 각각 2, 5, 4, 4일 때 평균 제곱 오차(MSE)는?
  17. 3개의 데이터 (x, y) = (1, 3), (2, 4), (3, 8)에 최소 제곱법으로 직선 y = ax + b를 맞추었다. x = 4일 때의 예측값은?
  18. 로지스틱 회귀에서 z = 2x − 4를 시그모이드 함수 σ(z) = 1 ÷ (1 + e^(−z))에 통과시킨 값을 양성일 확률로 출력한다. x = 2일 때의 출력은?
  19. 결정 트리의 어떤 노드에 클래스 A의 데이터가 6건, 클래스 B의 데이터가 4건 있다. 이 노드의 지니 불순도는?
  20. 앙상블 학습의 배깅(랜덤 포레스트 등)과 부스팅의 차이로 적절한 것은?
  21. 2차원 점 (0, 0)의 클래스를 k-최근접 이웃 알고리즘으로 예측한다. 학습용 데이터는 빨간 점 (1, 0), (3, 0), (0, −3)과 파란 점 (0, 2), (−2, 1)이다. 거리를 유클리드 거리로 할 때, k = 3과 k = 5의 예측 조합으로 올바른 것은?
  22. 서포트 벡터 머신(SVM)에 대한 설명으로 적절한 것은?
  23. 전체 메일의 20%가 스팸이다. 어떤 단어는 스팸의 50%와 스팸이 아닌 메일의 5%에 포함된다. 이 단어를 포함하는 메일이 스팸일 확률에 가장 가까운 것은?
  24. 입력층과 출력층만으로 이루어진 단순 퍼셉트론(임계값으로 0 또는 1을 출력하는 하나의 뉴런)으로 나타낼 수 없는 논리 함수는?
  25. 3클래스 분류에서 소프트맥스 함수에 입력하는 값(로짓)이 3, 1, 0이었다. 1번째 클래스의 출력(확률)은 2번째 클래스 출력의 약 몇 배인가? 가장 가까운 것은?
  26. 입력이 x₁ = 1, x₂ = 2인 작은 신경망에서 은닉층의 두 뉴런이 h₁ = ReLU(x₁ + x₂ − 1), h₂ = ReLU(x₁ − 2x₂ + 1)이고, 출력이 y = 2h₁ + 3h₂ + 1이다. y의 값은?
  27. 정답 클래스에 대해 모델이 출력한 확률을 p라고 할 때, 분류 학습에서 사용하는 교차 엔트로피 손실 −log p의 성질로 적절한 것은?
  28. 경사 하강법에서 가중치 w = 2.0에서의 손실의 기울기 ∂L/∂w가 0.5, 학습률이 0.1일 때, 1회 갱신 후의 가중치는?
  29. y = (2x + 1)²의 x = 1에서의 미분 계수 dy/dx를 u = 2x + 1, y = u²로 두고 연쇄 법칙으로 구할 때, 올바른 값은?
  30. 많은 층을 쌓은 신경망에서 활성화 함수로 시그모이드 함수를 사용하면 입력에 가까운 층의 학습이 잘 진행되지 않는 이유로 적절한 것은?
  31. 10,000건의 학습용 데이터를 미니배치 크기(배치 크기) 50으로 학습한다. 1에폭에서의 가중치 갱신 횟수는?
  32. 입력이 64개, 출력이 32개인 완전 연결층(각 출력에 바이어스가 1개씩 있다)의 학습하는 파라미터 수는?
  33. 28×28의 1채널 이미지에 5×5 필터로 합성곱(스트라이드 1, 패딩 없음)을 수행하고, 이어서 2×2 최대 풀링(스트라이드 2)을 수행한다. 출력의 세로와 가로 크기는?
  34. 순환 신경망(RNN)과 LSTM에 대한 설명으로 적절한 것은?
  35. Transformer에서 사용되는 셀프 어텐션(자기 주의 메커니즘)에 대한 설명으로 적절한 것은?
  36. 대량의 데이터로 학습을 마친 모델을 다른 과제에 적은 데이터로 활용하는 전이 학습에 대한 설명으로 적절한 것은?
  37. 이미지 등을 생성하는 모델에 대한 설명으로 적절한 것은?
  38. 대규모 언어 모델(LLM)이 문장을 처리하는 구조에 대한 설명으로 적절한 것은?
  39. 과거의 채용 결과를 정답으로 삼아 지원 서류로부터 채용 여부를 예측하는 모델을 만들 때 주의해야 할 점으로 적절한 것은?
  40. 설명 가능한 AI(XAI)에 대한 설명으로 적절한 것은?
