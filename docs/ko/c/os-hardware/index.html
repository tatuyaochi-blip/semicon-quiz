OS와 하드웨어: 핵심 정리

운영체제(OS)는 여러 프로그램이 CPU, 메모리, I/O 장치 같은 하드웨어를 안전하게 공유할 수 있게 하는 소프트웨어입니다. 이를 지원하기 위해 CPU는 OS만 사용할 수 있는 특권 모드, 인터럽트와 예외 메커니즘, 가상 메모리를 위해 페이지 테이블을 탐색하는 하드웨어를 제공합니다.

애플리케이션은 시스템 콜로 OS에 서비스를 요청하고, OS는 타이머 인터럽트로 프로그램을 전환하며(컨텍스트 스위치), 페이지 폴트가 발생하면 필요한 페이지를 메모리로 가져옵니다. 디바이스 드라이버와 메모리 맵 I/O부터 하이퍼바이저에 의한 가상화까지, 이 주제는 하드웨어와 소프트웨어가 협력하는 방식을 다룹니다.

  9. 인터럽트 핸들러의 처리를 즉시 수행하는 짧은 부분과 나중에 일반 컨텍스트에서 수행하는 나머지 부분으로 나누는 이유로 올바른 것은?

  12. 내보내져 디스크에 있는 페이지에 접근하여 페이지 폴트가 일어났을 때 OS가 수행하는 처리 흐름으로 올바른 것은?
  13. 페이지 테이블을 1단이 아니라 다단(계층형)으로 하는 주된 이유는?
  14. 가상 주소가 32비트, 페이지 크기가 4 KB, 페이지 테이블 1항목이 4바이트일 때 1단 페이지 테이블의 크기는 얼마입니까?

  16. 페이지 테이블의 각 항목에 보통 포함되는 정보의 조합으로 올바른 것은?
  17. 프로세스를 복제할 때 카피 온 라이트를 사용하는 장점으로 올바른 것은?
  18. 디맨드 페이징에 대한 설명으로 올바른 것은?
  19. 페이지 교체의 클록 방식(세컨드 찬스 방식)에서 각 페이지의 참조 비트를 사용하는 목적은?
  20. 페이지 교체에서 FIFO 방식을 사용하면 물리 메모리의 페이지 수를 늘렸는데도 페이지 폴트가 늘어나는 경우가 있습니다. 이 현상을 무엇이라고 합니까?
  21. 물리 메모리가 부족하여 페이지를 내보내고 읽어 들이는 일만 계속되어 처리가 거의 진행되지 않는 상태를 무엇이라고 합니까?
  22. 메모리 접근 시간이 100 ns, 페이지 폴트 처리에 8 ms가 걸릴 때, 100만 번에 한 번 페이지 폴트가 일어나면 평균 접근 시간은 대략 얼마입니까?
  23. 컨텍스트 스위치에서 전환 전 프로세스에 대해 저장해 두어야 하는 것은?
  24. 프로세스의 컨텍스트 스위치가 레지스터 저장·복원에 걸리는 시간보다 실제로는 더 큰 성능 저하를 초래하는 경우가 있는 주된 이유는?
  25. TLB의 각 항목에 ASID(주소 공간 식별자)를 붙이는 장점으로 올바른 것은?
  26. OS가 스스로 CPU를 내놓지 않는 프로그램으로부터도 일정 시간마다 CPU를 되찾아 다른 프로세스로 전환할 수 있는 것은 주로 어떤 구조 덕분입니까?
  27. 위와 같이 장치의 상태 레지스터를 메모리 맵 I/O로 읽을 때, volatile을 붙이고 그 영역을 캐시하지 않도록 설정하는 이유로 올바른 것은?
  28. 장치의 상태를 인터럽트를 사용하지 않고 CPU가 반복해서 조사하는 방식(폴링)이 유리한 경우는?
  29. 캐시 일관성을 하드웨어가 유지하지 않는(비코히런트) 시스템에서, 장치가 DMA로 주기억장치에 쓴 데이터를 CPU가 읽기 전에 소프트웨어가 수행해야 하는 처리는?
  30. IOMMU의 주된 역할로 올바른 것은?

  32. 일반적인 OS에서 애플리케이션이 장치 레지스터를 직접 읽고 쓰지 못하게 하는 주된 이유는?
  33. 한 대의 컴퓨터 위에서 여러 OS를 각각 독립된 가상 머신으로 동시에 실행하기 위한 소프트웨어를 무엇이라고 합니까?
  34. 하이퍼바이저의 유형에 대한 설명으로 올바른 것은?
  35. 중첩 페이징(2단 주소 변환)을 사용한 가상화에서 하드웨어가 수행하는 주소 변환에 대한 설명으로 올바른 것은?

  37. 가상 머신의 OS가 특권이 필요한 명령을 실행했을 때 하이퍼바이저로 처리가 넘어가고, 하이퍼바이저가 그 명령의 효과를 대신 재현하는 방식을 무엇이라고 합니까?

  42. 페이지 크기가 4 KB일 때 32비트 가상 주소 0x00403ABC의 페이지 번호와 페이지 내 오프셋의 조합으로 올바른 것은?
  43. RISC-V 특권 아키텍처에서 정해진 주요 동작 모드의 조합으로 올바른 것은?

  45. 실시간성이 요구되는 시스템에서 인터럽트가 발생한 뒤 핸들러가 동작하기 시작할 때까지의 시간(인터럽트 지연)을 크게 만드는 요인으로 가장 적절한 것은?

  47. 여러 코어를 가진 시스템에서 OS가 어떤 페이지의 페이지 테이블 항목을 재작성하여 대응을 취소했을 때 필요한 처리로 올바른 것은?

  49. 파일을 메모리에 대응시키는(mmap과 같은) 구조에서 파일 내용을 읽을 때 일어나는 일에 대한 설명으로 올바른 것은?
