이온 주입: 핵심 정리

이온 주입은 불순물을 이온화하여 전계로 가속한 뒤 웨이퍼 속으로 박아 넣는 방법입니다. 도즈와 깊이를 정밀하게 제어할 수 있어 현재 도펀트 도입의 주된 방법입니다.

주입된 이온은 결정에 손상을 주므로, 주입 후에는 어닐링으로 결정을 회복시키고 도펀트를 전기적으로 활성화합니다. 주입 깊이를 결정하는 요인과 채널링을 방지하는 방법도 이해해 두세요.

  • 열확산 vs 이온 주입: 도핑 방법 비교열확산과 이온 주입을 표로 비교합니다: 원리, 도즈 제어, 깊이 분포, 온도, 결정 손상, 비용, 대표 용도.
