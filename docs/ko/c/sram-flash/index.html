SRAM과 플래시 메모리: 핵심 정리

SRAM은 서로 교차 연결된 두 인버터로 이루어진 래치에 데이터를 유지합니다. 리프레시가 필요 없고 속도가 빨라 CPU 캐시에 사용되지만, 비트당 면적이 큽니다.

플래시 메모리는 전원이 꺼져도 데이터가 남는 비휘발성 메모리입니다. 대용량 저장에 적합한 NAND 플래시와 빠른 랜덤 읽기가 가능한 NOR 플래시가 있습니다. 셀당 여러 비트를 저장하는 다치(멀티레벨) 셀 기술도 발전하고 있습니다.
