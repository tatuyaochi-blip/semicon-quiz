링커, 로더, 실행 파일: 핵심 정리

컴파일러가 만들어 내는 것은 오브젝트 파일이며, 이것만으로는 실행할 수 없습니다. 링커는 오브젝트 파일과 라이브러리를 모아 함수와 변수의 이름(심벌)을 실제 주소에 연결하고(심벌 해석), 그 주소를 명령어에 반영하여(재배치) 실행 파일을 만듭니다.

로더는 실행 파일을 메모리에 읽어 들여 텍스트, 데이터, BSS, 힙, 스택 영역을 구성하고 프로그램을 시작합니다. 실행 시점에 라이브러리를 연결하는 동적 링킹과 어떤 주소에서도 실행되는 위치 독립 코드(PIC)는 메모리 절약과 보안 향상에 모두 도움이 됩니다.

링커, 로더, 실행 파일 전체 문제 (50)
  1. 컴파일러가 하나의 소스 파일에서 출력하는 오브젝트 파일(.o)에 대해 올바른 것은 무엇입니까?
  2. 링커의 주된 역할로 올바른 것은 무엇입니까?
  3. 링커가 수행하는 심볼 해석의 설명으로 올바른 것은 무엇입니까?
  4. 링커가 수행하는 재배치(relocation)의 설명으로 올바른 것은 무엇입니까?
  5. C 언어 프로그램을 링크했을 때 "undefined reference to `foo'"(foo에 대한 정의되지 않은 참조) 오류가 나왔습니다. 가장 가능성이 높은 원인은 무엇입니까?
  6. a.c와 b.c 양쪽에서 static을 붙이지 않은 같은 이름의 전역 함수 void init(void)를 정의하고 링크했습니다. 일어나는 일로 올바른 것은 무엇입니까?
  7. C 언어에서 함수에 static을 붙여 정의했을 때(예: static int helper(void))의 효과로 올바른 것은 무엇입니까?
  8. C 언어에서 'extern int count;'라고 썼을 때의 의미로 올바른 것은 무엇입니까?
  9. Linux 등에서 자주 사용되는 ELF 형식 파일에 대해 올바른 것은 무엇입니까?
  10. 실행 파일의 .text 섹션에 들어 있는 것은 무엇입니까?
  11. C 언어에서 파일 바깥에 'int limit = 100;'이라고 쓴 전역 변수는 일반적으로 어느 섹션에 놓입니까?
  12. .bss 섹션의 특징으로 올바른 것은 무엇입니까?
  13. C 언어의 'char *p = "hello"; p[0] = 'H';'를 실행하면 많은 환경에서 비정상 종료됩니다. 그 이유로 올바른 것은 무엇입니까?
  14. 위의 전역 변수 중 일반적으로 .bss 섹션에 놓이는 것의 조합은 무엇입니까?
  15. C 언어 함수 안에서 선언한, static이 붙지 않은 지역 변수(자동 변수)는 실행 중 어디에 놓입니까?
  16. C 언어의 malloc으로 확보한 메모리는 일반적으로 프로세스의 어느 영역에서 가져옵니까?
  17. Linux 등의 일반적인 프로세스 메모리 배치를 주소가 작은 쪽부터 나열한 것으로 올바른 것은 무엇입니까?
  18. 프로세스의 힙과 스택을 사이에 넓은 빈 공간을 두고 반대 방향으로 늘어나는 배치로 하는 이점으로 올바른 것은 무엇입니까?
  19. 정적 링크의 설명으로 올바른 것은 무엇입니까?
  20. 동적 링크(공유 라이브러리)의 이점으로 올바른 것은 무엇입니까?
  21. 동적 링크를 사용한 프로그램을 다른 컴퓨터에 복사하여 실행했더니 기동하지 않았습니다. 가장 가능성이 높은 원인은 무엇입니까?
  22. 정적 라이브러리(.a 파일)와 함께 링크할 때 링커가 실행 파일에 포함시키는 것으로 올바른 것은 무엇입니까?
  23. GNU 링커에서 'gcc -lmylib main.o'처럼 정적 라이브러리를 그것을 사용하는 오브젝트 파일보다 앞에 쓰면 정의되지 않은 참조 오류가 나는 경우가 있습니다. 그 이유로 올바른 것은 무엇입니까?
  24. 위치 독립 코드(PIC)의 설명으로 올바른 것은 무엇입니까?
  25. 공유 라이브러리에서 사용되는 GOT(Global Offset Table)의 역할로 올바른 것은 무엇입니까?
  26. 동적 링크에서 PLT(Procedure Linkage Table)를 사용한 지연 바인딩(lazy binding)을 수행하는 경우의 설명으로 올바른 것은 무엇입니까?
  27. Linux에서 동적 링크 프로그램을 기동할 때 동작하는 동적 링커(ld.so 등)의 역할로 올바른 것은 무엇입니까?
  28. ASLR(주소 공간 배치 무작위화)의 목적으로 올바른 것은 무엇입니까?
  29. 실행 파일을 PIE(위치 독립 실행 파일)로 만드는 주된 이유는 무엇입니까?
  30. 프로그램을 기동할 때(Linux의 execve 등) OS 로더가 수행하는 일로 올바른 것은 무엇입니까?
  31. C 언어 프로그램에서 OS가 처음 실행을 시작하는 주소(엔트리 포인트)에 대해 올바른 것은 무엇입니까?
  32. C 언어의 main 함수가 'return 3;'으로 끝났을 때, 그 값 3은 일반적으로 어떻게 됩니까?
  33. 실행 파일에 strip 명령을 사용했을 때 일어나는 일로 올바른 것은 무엇입니까?
  34. 링커에서 약한 심볼(weak symbol)의 취급으로 올바른 것은 무엇입니까?
  35. C++ 컴파일러가 함수 이름에 인수 타입 등의 정보를 덧붙여 심볼 이름을 만드는 '네임 맹글링(name mangling)'의 주된 목적은 무엇입니까?
  36. Linux의 dlopen 함수(Windows의 LoadLibrary에 해당)의 용도로 가장 적절한 것은 무엇입니까?
  37. 100개의 프로세스가 같은 공유 라이브러리를 사용하고 있을 때 물리 메모리 사용 방식으로 올바른 것은 무엇입니까?
  38. 오브젝트 파일을 역어셈블했더니 외부 함수 printf를 호출하는 명령의 점프 대상이 0 같은 임시 값이었습니다. 이 값은 언제 올바르게 채워집니까?
  39. 임베디드 개발에서 사용하는 링커 스크립트의 역할로 올바른 것은 무엇입니까?
  40. OS가 없는 마이크로컨트롤러에서 전원을 켠 직후 기동 코드가 main을 호출하기 전에 수행하는 처리로 올바른 것은 무엇입니까?
  41. ELF 파일에서 '섹션'과 '세그먼트'의 차이로 올바른 것은 무엇입니까?
  42. 메모리 페이지에 '쓰기 가능'과 '실행 가능'을 동시에 허용하지 않는 것(W^X, 쓰기와 실행의 분리)으로 막기 쉬워지는 공격은 무엇입니까?
  43. Linux 공유 라이브러리에서 libfoo.so.1의 '.1'과 같은 soname 버전 번호를 올리는 것은 일반적으로 어떤 경우입니까?
  44. Linux에서 ldd 명령을 실행 파일에 사용하면 알 수 있는 것은 무엇입니까?
  45. 주요 OS에서 사용되는 실행 파일 형식의 조합으로 올바른 것은 무엇입니까?
  46. 재귀가 너무 깊어져 스택 상한을 넘었을 때 Linux 등에서 일반적으로 일어나는 일로 올바른 것은 무엇입니까?
  47. C 언어에서 초기값을 쓰지 않은 지역 변수와 전역 변수의 사용 시작 시 값에 대해 올바른 것은 무엇입니까?
  48. malloc과 free를 반복하는 동안, 빈 메모리의 합계는 충분한데도 큰 영역을 한꺼번에 확보할 수 없게 되는 경우가 있습니다. 이 현상을 무엇이라고 합니까?
  49. 공유 라이브러리를 만들 때 외부에서 사용할 함수만 공개하고 내부 함수는 심볼 가시성(visibility)을 'hidden'으로 하는 이점으로 올바른 것은 무엇입니까?
  50. C++에서 전역 오브젝트의 생성자가 main보다 먼저 실행되는 구조로 올바른 것은 무엇입니까?
