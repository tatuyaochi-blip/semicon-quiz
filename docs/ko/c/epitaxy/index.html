에피택셜 성장: 핵심 정리

에피택셜 성장은 단결정 기판 위에 기판과 같은 결정 방향을 가진 단결정 박막을 성장시키는 기술입니다. 불순물 농도를 정밀하게 제어한 층을 만들 수 있어 전력 소자, 바이폴라 소자, 화합물 반도체 소자에 사용됩니다.

기판과 같은 재료를 성장시키면 호모에피택시, 다른 재료를 성장시키면 헤테로에피택시입니다. 헤테로에피택시에서는 격자 상수의 차이(격자 부정합)로 인한 결함을 고려해야 합니다.
