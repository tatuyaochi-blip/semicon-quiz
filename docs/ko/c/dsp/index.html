디지털 신호 처리의 기초: 핵심 정리

AD 변환기로 수치의 열이 된 신호는 프로세서나 FPGA 위에서 필터를 거치거나, 주파수 성분을 조사하거나, 샘플링 주파수를 바꾸는 방식으로 처리됩니다. 오디오, 통신, 센서, 모터 제어, 계측기 등 디지털 신호 처리는 거의 모든 전자 기기 안에서 동작합니다.

여기서는 이산 시간 신호의 정규화 주파수와 주기, 단위 임펄스와 단위 계단, 에너지와 전력에서 시작하여 선형 시불변 시스템의 성질(선형성·시불변성·인과성·BIBO 안정), 임펄스 응답과 합성곱, 차분 방정식의 계산을 다룹니다. 이어서 DFT 빈의 간격과 번호, 실수 신호 스펙트럼의 대칭성, FFT의 연산량, 제로 패딩, 스펙트럼 누설과 창 함수, 파스발 정리, z 변환에 의한 전달 함수와 극점·영점, FIR 필터와 IIR 필터, 선형 위상과 군지연, 이동 평균과 지수 평활화, 쌍선형 변환, 계수 양자화, 데시메이션과 보간, 곱셈-누산 연산 횟수와 실시간 처리 시간의 추정을 확인합니다. 계산 문제의 값은 오답 선택지의 값까지 포함하여 Python(NumPy)으로 계산해 확인했습니다. 샘플링 정리, 에일리어싱, 양자화 잡음, 오버샘플링, ΔΣ형 ADC는 'A/D·D/A 변환', 아날로그 필터와 연산 증폭기는 '아날로그·전자 회로', OFDM은 '무선 통신의 기초', CNN의 합성곱은 '머신러닝의 기초', 고정 소수점 표현은 '컴퓨터 산술' 분야에서 다룹니다.

디지털 신호 처리의 기초 전체 문제 (40)
  1. 샘플링 주파수 48 kHz로 주파수 6 kHz의 사인파를 샘플링했다. 이 이산 시간 신호의 정규화 각주파수 ω(1샘플당 진행하는 위상)로 올바른 것은?
  2. 이산 시간 신호 x[n] = cos(0.3πn)의 기본 주기(모든 정수 n에서 x[n + N] = x[n]이 되는 가장 작은 양의 정수 N)로 올바른 것은?
  3. 이산 시간 신호 x[n] = cos(1.75πn)과 모든 정수 n에서 같은 값을 갖는 신호는 어느 것인가?
  4. 단위 임펄스 δ[n](n = 0에서 1, 그 밖에서 0)과 단위 계단 u[n](n ≥ 0에서 1, n < 0에서 0)의 관계로 올바른 것은?
  5. x[n] = (0.5)ⁿu[n](n ≥ 0에서 0.5의 n제곱, n < 0에서 0)의 에너지 E = Σ|x[n]|²로 올바른 것은?
  6. x[n] = 2cos(πn/4)의 평균 전력(1주기에 걸친 |x[n]|²의 평균)으로 올바른 것은?
  7. 입력 x[n], 출력 y[n]인 시스템 중에서 선형이면서 시불변(LTI)인 것은?
  8. y[n] = n·x[n]으로 표현되는 시스템의 성질로 올바른 것은?
  9. 입력 x[n], 출력 y[n]인 시스템 중에서 인과적(출력이 그 시각까지의 입력만으로 결정됨)인 것은?
  10. u[n]을 단위 계단이라 한다. 임펄스 응답이 다음과 같이 표현되는 LTI 시스템 중에서 BIBO 안정(유계 입력에 대해 출력이 반드시 유계)인 것은?
  11. x[n] = {1, 2, 3}(n = 0, 1, 2)을 임펄스 응답 h[n] = {1, −1}(n = 0, 1)인 LTI 시스템에 입력했다. 출력 y[0]~y[3]으로 올바른 것은?
  12. 차분 방정식 y[n] = x[n] + 0.5y[n − 1]로 표현되는 시스템에 n = 0부터 단위 계단(n ≥ 0에서 x[n] = 1)을 입력했다. y[−1] = 0일 때, y[2]로 올바른 것은?
  13. 샘플링 주파수 48 kHz의 신호를 1024점 이산 푸리에 변환(DFT)으로 해석한다. 주파수 빈의 간격으로 올바른 것은?
  14. k = 0을 직류 빈이라 한다. 샘플링 주파수 8 kHz로 샘플링한 1 kHz의 사인파를 256점 DFT로 해석했을 때, 양의 주파수 쪽에서 피크가 나타나는 빈의 번호 k로 올바른 것은?
  15. 실수 신호 x[n]의 64점 DFT를 계산했더니 X[10] = 3 + 4j였다. X[54]로 올바른 것은?
  16. 8점 실수 신호 x[n] = {3, 1, 3, 1, 3, 1, 3, 1}의 DFT를 X[k] = Σx[n]e^(−j2πkn/8)이라 한다. 나이퀴스트 주파수에 해당하는 빈 X[4]의 값으로 올바른 것은?
  17. N점 DFT를 정의대로 계산하면 약 N²회, FFT(고속 푸리에 변환)로는 약 N log₂N회의 연산으로 충분하다고 하자. N = 1024일 때, FFT에 의한 연산 횟수의 감소 정도로 가장 가까운 것은?
  18. 256점 신호 뒤에 0을 768개 덧붙여(제로 패딩) 1024점 DFT를 계산했다. 256점 그대로 DFT를 계산한 경우와 비교한 설명으로 올바른 것은?
  19. DFT에서 스펙트럼 누설이 생기는 주된 원인으로 올바른 것은?
  20. DFT 앞에 곱하는 창 함수에 대해, 직사각형 창(아무것도 곱하지 않는 경우)과 해닝 창(Hann 창)을 비교한 설명으로 올바른 것은?
  21. 점수 N은 충분히 크다고 한다. 직사각형 창의 DFT에서 사인파의 주파수가 인접한 두 빈의 정확히 중간에 있을 때, 가장 가까운 빈에서 읽히는 진폭이 주파수가 빈의 중심과 일치하는 경우보다 얼마나 낮아지는지에 가장 가까운 것은?
  22. 4점 신호 x[n] = {1, −1, 2, 0}의 DFT를 X[k] = Σx[n]e^(−j2πkn/4)라 한다. Σ|X[k]|²(k = 0~3)로 올바른 것은?
  23. 이산 시간 LTI 시스템의 전달 함수 H(z)에서 주파수 응답을 구할 때, z를 움직이는 곳으로 올바른 것은?
  24. 차분 방정식 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1]로 표현되는 시스템의 전달 함수 H(z) = Y(z)/X(z)로 올바른 것은?
  25. 전달 함수 H(z) = 1/(1 − 1.3z⁻¹ + 0.4z⁻²)로 표현되는 인과적인 시스템의 극점과 안정성의 조합으로 올바른 것은?
  26. 샘플링 주파수 8 kHz로 동작하는, 전달 함수 H(z) = 1 + z⁻²(y[n] = x[n] + x[n − 2])인 FIR 필터가 있다. 출력이 0이 되는 사인파 입력의 주파수로 올바른 것은?
  27. y[n] = x[n] − x[n − 1](하나 앞의 입력과의 차)로 표현되는 필터의, 직류와 나이퀴스트 주파수에서의 이득 크기의 조합으로 올바른 것은?
  28. FIR 필터(유한 임펄스 응답 필터)의 특징으로 올바른 것은?
  29. 다음 계수를 갖는 5탭 FIR 필터 중에서 선형 위상(직선 위상) 특성을 갖는 것은?
  30. 101탭 선형 위상 FIR 필터(계수가 좌우 대칭)의 군지연으로 올바른 것은?
  31. 샘플링 주파수 8 kHz에서, 최근 8샘플의 평균을 구하는 이동 평균 필터 y[n] = (x[n] + x[n − 1] + … + x[n − 7])/8을 사용한다. 출력이 0이 되는 가장 낮은 주파수로 올바른 것은?
  32. 지수 평활화 y[n] = 0.2x[n] + 0.8y[n − 1]로 표현되는 1차 IIR 저역 통과 필터의, 직류와 나이퀴스트 주파수에서의 이득 조합으로 올바른 것은?
  33. 아날로그 필터의 전달 함수 H(s)로부터 디지털 필터를 설계할 때 사용하는 쌍선형 변환의 설명으로 올바른 것은?
  34. 차수가 높은 IIR 필터를 계수의 비트 수가 제한된 고정 소수점으로 구현할 때의 주의점으로 올바른 것은?
  35. 샘플링 주파수 48 kHz의 신호를 4샘플마다 하나씩 꺼내 12 kHz로 낮춘다(1/4 데시메이션). 솎아 내기 전에 두는 저역 통과 필터로 제거해 두어야 하는 주파수 성분으로 올바른 것은?
  36. 샘플링 주파수를 L배로 하기 위해 각 샘플 사이에 L − 1개의 0을 삽입했다(제로 삽입). 이후에 필요한 처리의 설명으로 올바른 것은?
  37. 샘플링 주파수를 44.1 kHz에서 48 kHz로 변환하기 위해 L배 업샘플링과 1/M 다운샘플링을 조합한다. 가장 작은 정수 쌍 (L, M)으로 올바른 것은?
  38. 256탭 FIR 필터를 샘플링 주파수 44.1 kHz로 실시간 동작시킨다. 1초당 필요한 곱셈-누산 연산(MAC)의 횟수로 올바른 것은?
  39. 샘플링 주파수 48 kHz에서 1샘플마다 FIR 필터의 출력을 계산한다. 클록 200 MHz로 1사이클에 1회의 곱셈-누산을 할 수 있는 프로세서를 사용하고 다른 처리의 시간을 무시할 때, 실시간으로 처리할 수 있는 탭 수의 상한에 가장 가까운 것은?
  40. 16비트 고정 소수점 데이터와 계수의 곱을 32비트로 나타내고, 그 곱을 256개 더하는 FIR 필터 계산이 있다. 도중에 오버플로가 일어나지 않음을 보장하는 데 필요한 누산기 비트 수의 최솟값으로 올바른 것은?
