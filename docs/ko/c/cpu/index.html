CPU와 아키텍처: 핵심 정리

CPU는 명령어의 인출, 해독, 실행을 반복하며 프로그램을 처리합니다. 대부분의 컴퓨터는 프로그램과 데이터를 같은 주기억장치에 저장하는 폰 노이만 구조를 채택하고 있습니다.

성능 향상 기법으로는 명령어 처리 단계를 겹쳐 실행하는 파이프라인, 주기억장치와의 속도 차이를 메우는 캐시, 여러 코어를 이용한 병렬 처리가 있습니다. 반도체 미세화가 이 모든 발전을 뒷받침해 왔습니다.

  26. CPU의 소비 전력을 줄이기 위해 부하에 따라 동작 주파수와 전원 전압을 동적으로 바꾸는 기술은?
  27. 투기적 실행의 흔적이 캐시에 남는 것을 악용하여, 본래 접근할 수 없는 데이터를 추측하는 공격이 밝혀진 취약점의 예는?
