임베디드 시스템과 펌웨어: 핵심 정리

가전제품, 자동차, 산업 장비 내부에서는 마이크로컨트롤러에서 실행되는 펌웨어가 기기를 제어합니다. 펌웨어는 주변장치 레지스터를 직접 읽고 쓰며, 비트 조작으로 특정 비트를 바꾸어 핀 입출력(GPIO), 타이머, 통신 주변장치를 구동합니다.

임베디드 코드에는 인터럽트 핸들러를 짧게 유지하고 공유 변수를 volatile로 선언하는 등 고유한 규칙이 있습니다. UART, SPI, I2C 통신과 우선순위로 태스크를 전환하는 RTOS부터, 전원 투입 시 가장 먼저 실행되는 부트로더와 폭주를 복구하는 워치독까지, 이 주제는 하드웨어와 가장 가까운 소프트웨어를 다룹니다.

임베디드 시스템과 펌웨어 전체 문제 (50)

  1. C 언어에서 레지스터 reg의 비트 3만 1로 만들고 나머지 비트는 바꾸지 않는 올바른 표기는 무엇입니까?
  2. C 언어에서 레지스터 reg의 비트 3만 0으로 만들고 나머지 비트는 바꾸지 않는 올바른 표기는 무엇입니까?
  3. LED를 연결한 출력 핀의 비트를 실행할 때마다 점등과 소등으로 번갈아 바꾸고 싶습니다. 올바른 C 언어 표기는 무엇입니까?
  4. 입력용 레지스터 in의 비트 5가 1인지 검사하는 올바른 C 언어 조건은 무엇입니까?
  5. 위의 코드는 레지스터 reg의 여러 비트로 이루어진 설정 필드를 바꿔 쓰고 있습니다. 무엇을 하고 있습니까?
  6. 메인 처리에서 레지스터 비트를 'reg |= mask;'(읽기-수정-쓰기)로 조작하는 도중에 인터럽트 핸들러가 같은 레지스터의 다른 비트를 바꾸면 발생할 수 있는 문제와 대책의 조합으로 올바른 것은 무엇입니까?
  7. 마이크로컨트롤러의 입력 핀에 스위치만 연결하고 풀업이나 풀다운 저항을 달지 않았습니다. 스위치가 열려 있을 때 일어날 수 있는 일은 무엇입니까?
  8. 마이크로컨트롤러의 GPIO(범용 입출력) 핀을 사용할 때 가장 먼저 설정해야 하는 것으로 올바른 것은 무엇입니까?
  9. 기계식 스위치를 눌렀을 때 접점이 잘게 튀어 짧은 시간에 여러 번 온과 오프를 반복하는 현상을 무엇이라고 합니까?
  10. 소프트웨어로 스위치의 채터링을 제거하는 방법으로 가장 적절한 것은 무엇입니까?
  11. 16 MHz 클럭을 프리스케일러로 16분주한 것으로 타이머를 세고, 1000카운트마다 인터럽트가 발생하도록 설정했습니다. 인터럽트 간격은 얼마입니까?
  12. 주기가 1000카운트인 PWM 신호에서 1주기 중 250카운트 동안만 출력을 1(High)로 하고 있습니다. 듀티비는 얼마입니까?
  13. 마이크로컨트롤러에서 LED의 밝기나 모터의 회전 속도를 조절할 때 자주 사용되는 방법은 무엇입니까?
  14. 마이크로컨트롤러 타이머의 입력 캡처(input capture) 기능의 용도로 올바른 것은 무엇입니까?
  15. 인터럽트 핸들러 안에서 피해야 할 것으로 가장 적절한 것은 무엇입니까?
  16. 위의 프로그램을 최적화를 켜고 컴파일하면 타이머 인터럽트가 발생해도 led_on()이 호출되지 않는 경우가 있습니다. 원인과 대책의 조합으로 올바른 것은 무엇입니까?
  17. 8비트 마이크로컨트롤러에서 타이머 인터럽트가 32비트 변수 ticks를 1씩 증가시키고, 메인 처리가 ticks를 읽어 경과 시간을 구하고 있습니다. 드물게 크게 어긋난 값이 읽히는 원인으로 올바른 것은 무엇입니까?
  18. UART를 이용한 시리얼 통신의 특징으로 올바른 것은 무엇입니까?
  19. 115200 bps UART에서 데이터 8비트, 패리티 없음, 스톱 비트 1(8N1) 형식으로 보낼 때, 1초 동안 보낼 수 있는 바이트 수에 가장 가까운 것은 무엇입니까?
  20. UART의 송신 측과 수신 측의 보 레이트가 조금 어긋나면 문자가 깨지는 경우가 있습니다. 어긋남의 허용 범위가 대략 몇 % 정도로 제한되는 이유로 올바른 것은 무엇입니까?

  23. SPI 부품을 연결했는데 올바른 데이터를 읽을 수 없을 때, 확인해야 할 설정으로 가장 적절한 것은 무엇입니까?

  29. OS를 사용하지 않는 마이크로컨트롤러 프로그램에서 흔히 볼 수 있는 '슈퍼 루프' 구성의 설명으로 올바른 것은 무엇입니까?

  34. RTOS에서 센서를 읽는 태스크에서 표시하는 태스크로 데이터를 전달할 때 큐(메시지 큐)를 사용하는 이점으로 올바른 것은 무엇입니까?
  35. 하드 리얼타임과 소프트 리얼타임의 차이로 올바른 것은 무엇입니까?
