프로그래밍의 기초(의사 코드 트레이스): 핵심 정리

프로그램의 동작을 정확히 읽으려면 변수의 값이 1행마다 어떻게 바뀌는지를 직접 손으로 따라가는(트레이스하는) 능력이 꼭 필요합니다. 반복 횟수를 하나 잘못 세거나, 대입 순서 때문에 값을 잃거나, 정수 나눗셈에서 소수점 이하가 버려지는 것을 놓치는 등의 작은 실수가 잘못된 결과나 버그의 원인이 됩니다.

일본 기본정보기술자시험 과목 B에서 사용하는 의사 코드(형의 선언, ←에 의한 대입, if·while·for, 1부터 시작하는 배열의 인덱스 등)를 따라 쓴 짧은 프로그램을 트레이스하고 결과를 답하는 문제를 중심으로 학습합니다. 오답 선택지는 종료값의 혼동이나 연산자 우선순위의 오해 등 전형적인 실수에서 생기는 값으로 되어 있으며, 해설에서는 각 선택지가 어떤 실수에서 나왔는지를 설명합니다.
