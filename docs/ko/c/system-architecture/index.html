시스템 구성과 신뢰성 설계: 핵심 정리

정보 시스템은 1대의 컴퓨터 성능뿐만 아니라, 기기를 어떻게 조합하고 고장 났을 때 어떻게 처리를 계속하는지에 따라 사용하기 쉬움과 잘 멈추지 않음이 크게 달라집니다. 반도체 공장의 제조 실행 시스템(MES)이나 장비 데이터를 수집하는 서버처럼, 멈추면 생산에 직접 영향을 주는 시스템에서는 이 설계가 특히 중요합니다.

클라이언트 서버, 3계층 클라이언트 서버, 피어 투 피어, 일괄 처리와 온라인 처리 등의 시스템 구성, 듀얼 시스템과 듀플렉스 시스템, 핫 스탠바이나 클러스터, 단일 장애점과 같은 이중화의 개념을 학습합니다. 나아가 RAID의 용량과 견딜 수 있는 고장 대수, 백업 복원 절차, RPO와 RTO, 페일 세이프 등의 신뢰성 설계, IaaS·PaaS·SaaS나 라이브 마이그레이션, SAN·NAS, PUE나 UPS, 필요한 서버 대수의 산정을 계산 문제를 섞어 다룹니다. IT 자격시험의 시스템 구성 요소 분야 학습에도 도움이 됩니다.
