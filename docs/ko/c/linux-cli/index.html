Linux와 커맨드 라인 기초: 핵심 정리

서버나 클라우드의 대부분은 Linux로 동작하며, 논리 합성이나 회로 시뮬레이션 같은 EDA 도구도 보통 Linux 서버 위에서 사용합니다. 그곳에서는 화면의 버튼이 아니라 셸에 명령을 입력하여 파일을 조사하고, 로그를 걸러 내고, 긴 처리를 실행시킨 채 접속을 끊는 것과 같은 작업이 매일의 일이 됩니다.

여기서는 디렉터리 구성과 절대 경로·상대 경로, 숨김 파일, 하드 링크와 심볼릭 링크, 와일드카드, 파일 권한의 rwx와 8진수 표기, umask, 디렉터리의 실행 권한, sudo와 setuid를 학습합니다. 이어서 리다이렉션과 파이프, grep과 정규 표현식, sort와 uniq를 조합한 집계, tail -f, cut, sed, awk, find, kill과 시그널, Ctrl+Z와 bg·fg, nohup, 종료 상태와 &&·||, 따옴표와 변수 확장, 스크립트의 인수와 조건과 반복, PATH와 export를 다루고, 마지막으로 패키지 관리, systemctl, cron, df와 du, SSH 키, tar, Git의 add·commit·push와 .gitignore를 확인합니다. 명령의 동작은 bash와 GNU 명령(coreutils, grep, sed, findutils, tar)을 기준으로 하며, 문제의 출력은 Linux에서 실제로 실행하여 확인했습니다. 프로세스나 가상 메모리의 구조는 'OS와 하드웨어', 포트 번호나 DNS는 '네트워크 기초', 접근 제어의 개념은 '정보 보안 기초', Git의 병합이나 개발 진행 방식은 '소프트웨어 개발과 프로젝트 관리' 분야에서 다룹니다.
