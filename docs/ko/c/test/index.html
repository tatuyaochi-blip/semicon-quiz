테스트와 검사: 핵심 정리

반도체 제품은 제조 중과 제조 후에 여러 단계의 테스트를 거칩니다. 다이싱 전의 웨이퍼 테스트에서는 불량 칩을 찾아내고, 패키징 후의 최종 테스트에서는 출하 제품의 특성을 보증합니다.

초기 불량을 제거하는 번인과, 회로에 테스트 기능을 내장하는 테스트 용이화 설계(DFT)는 테스트 비용을 억제하면서 품질을 높게 유지해 줍니다.

테스트와 검사 전체 문제 (50)
  1. 웨이퍼 테스트(프로브 테스트)에 대한 설명으로 올바른 것은 무엇입니까?
  2. 번인(burn-in)의 목적으로 올바른 것은 무엇입니까?
  3. 테스트 용이화 설계(DFT)의 하나인 스캔 설계에 대한 설명으로 올바른 것은 무엇입니까?
  4. 반도체 DC 테스트(직류 특성 시험)에서 주로 확인하는 항목은 무엇입니까?
  5. BIST(내장 자체 테스트)에 대한 설명으로 올바른 것은 무엇입니까?
  6. 프로브 카드에 대한 설명으로 올바른 것은 무엇입니까?
  7. 로직 회로 테스트에서 사용되는 고착 고장(스턱앳 고장) 모델에 대한 설명으로 올바른 것은 무엇입니까?
  8. 테스트 패턴의 고장 검출률(폴트 커버리지)의 정의로 올바른 것은 무엇입니까?
  9. 여러 칩을 하나의 패키지에 실장할 때 중요해지는 KGD(Known Good Die)란 무엇입니까?
  10. 테스트 비용을 낮추기 위해 테스터로 여러 칩을 동시에 측정하는 기법을 무엇이라고 합니까?
  11. 회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것을 무엇이라고 합니까?
  12. CMOS 회로가 정지 상태일 때의 전원 전류를 측정하여 브리지 고장 등의 결함을 검출하는 테스트를 무엇이라고 합니까?
  13. IEEE 1149.1(JTAG)에서 규정된 바운더리 스캔의 주된 용도는 무엇입니까?
  14. 패키지 후의 최종 테스트에서 테스터와 조합하여 IC를 자동으로 공급하고 테스트 결과에 따라 분류하는 장치는 무엇입니까?
  15. 전원 전압이나 동작 주파수 등의 조건을 바꾸면서 합격 여부를 조사하고 그 결과를 2차원 도표로 정리한 것을 무엇이라고 합니까?
  16. 일반적인 반도체 제품의 테스트 흐름으로 올바른 것은 무엇입니까?
  17. AC 테스트에서 주로 확인하는 항목은 무엇입니까?
  18. 스캔 테스트의 데이터 양과 테스트 시간을 줄이기 위해 칩 안에서 테스트 패턴을 전개하고 응답을 압축하는 기술을 무엇이라고 합니까?
  19. 실제 동작 주파수에서 테스트를 수행하여 신호가 전달되는 속도가 너무 느린 불량을 검출하는 테스트를 무엇이라고 합니까?
  20. 테스트 결과에 기초하여 동작 속도나 소비 전력 등 성능별로 제품을 분류하는 것을 무엇이라고 합니까?
  21. 테스트에서 측정 오차나 경시 변화를 고려하여 제품 규격보다 약간 엄격한 판정값을 두는 것을 무엇이라고 합니까?
  22. 테스트 프로그램 개발에서 테스트 비용을 낮추기 위해 중시되는 것으로 올바른 것은 무엇입니까?
  23. 웨이퍼 테스트에서 불량으로 판정한 칩의 정보를 이후 조립 공정에서 사용하는 방법으로 현재 일반적인 것은 무엇입니까?
  24. 차량용 반도체에서 상온뿐만 아니라 고온이나 저온에서도 테스트를 수행하는 주된 이유는 무엇입니까?
  25. 메모리 테스트에서 주소를 차례로 따라가며 0과 1의 쓰기와 읽기를 반복하여, 인접 셀 간의 간섭 등의 불량도 검출하는 테스트 패턴은 무엇입니까?
  26. ATE(자동 시험 장치)에 대한 설명으로 올바른 것은 무엇입니까?
  27. 웨이퍼 테스트에서 프로브의 침이 전극 패드에 닿은 뒤, 조금 더 눌러 확실하게 접촉시키는 것을 무엇이라고 합니까?
  28. 테스트 용이화 설계에서 높이는 것을 목표로 하는 두 가지 성질의 조합으로 올바른 것은 무엇입니까?
  29. 실제 사용 상태에 가까운 환경에서 OS나 애플리케이션을 동작시켜 칩의 양부를 판정하는 테스트를 무엇이라고 합니까?
  30. 출하한 제품 100만 개당 불량 수를 나타내는 품질 지표는 무엇입니까?
  31. 반도체 제품 제조에서 테스트를 수행하는 주된 목적은 무엇입니까?
  32. 웨이퍼 테스트에서 프로브 카드의 침을 접촉시키는 칩 상의 장소는 어디입니까?
  33. 로직 회로 테스트에서 칩이 정상인지 판정하는 기본적인 방법은 무엇입니까?
  34. 테스트에서 칩의 입력에 순서대로 가하는 0과 1 신호의 나열과 그에 대한 기대값의 쌍을 무엇이라고 합니까?
  35. 웨이퍼 상의 칩 사이(스크라이브 라인) 등에 배치되어, 트랜지스터나 저항 등의 특성을 측정해 공정을 평가하기 위한 전용 패턴을 무엇이라고 합니까?
  36. 전공정을 마친 웨이퍼에서 TEG의 문턱 전압이나 시트 저항 등을 측정하여 공정이 규격대로 만들어졌는지 확인하는 검사를 무엇이라고 합니까?
  37. 테스터와 IC를 잇는 테스트용 지그에서, 스프링으로 신축하는 가는 핀을 사용하여 단자에 확실하게 접촉시키는 부품은 무엇입니까?
  38. 테스터의 테스트 헤드에 장착하여 IC 소켓이나 주변 부품을 탑재하고, 품종별로 신호를 IC로 연결하는 인쇄 회로 기판을 무엇이라고 합니까?
  39. 프로브 카드 방식 중 침을 패드에 대해 수직으로 세워 배열하는 수직형의 주된 장점은 무엇입니까?
  40. 웨이퍼 테스트를 계속하면 프로브 침 끝에 패드의 알루미늄 부스러기 등이 부착된다. 이때 정기적으로 수행하는 처리는 무엇입니까?
  41. 프로버에서 웨이퍼를 올려놓는 대(척)의 온도를 고온이나 저온으로 제어할 수 있게 하는 목적은 무엇입니까?
  42. 로직 회로 테스트에서, 스캔 등을 사용하여 회로의 구조상 고장(고착 고장 등)을 망라적으로 검출하는 테스트와, 실제 동작대로 기능을 확인하는 테스트의 명칭 조합으로 올바른 것은 무엇입니까?
  43. 테스트 판정이 지나치게 엄격하거나 측정이 불안정하여, 본래 양품인 칩을 불량으로 판정하여 버리는 것을 무엇이라고 합니까?
  44. 메모리 테스트에서 어느 주소의 어느 비트가 불량이었는지를 기록한 도표를 만드는 주된 목적은 무엇입니까?
  45. 스캔 테스트에서 출력을 압축할 때, 시뮬레이션에서 값이 0인지 1인지 정해지지 않는 신호(불정값 X)를 제거하는 처리가 필요한 이유는 무엇입니까?
  46. 고속 직렬 통신 인터페이스 테스트에서, 칩의 송신 회로 출력을 수신 회로로 되돌려 연결하여 칩 스스로 통신을 확인하는 방법은 무엇입니까?
  47. 웨이퍼 테스트 등의 도중 결과나 통계에 기초하여, 칩별, 로트별로 테스트 항목이나 판정값을 동적으로 바꾸는 기법을 무엇이라고 합니까?
  48. AD 컨버터 테스트에서, 천천히 변화하는 정현파 등을 입력하고 각 출력 코드가 나타나는 횟수(히스토그램)를 세는 주된 목적은 무엇입니까?
  49. 스캔 테스트에서 불량이 된 칩에 대해, 어느 출력의 어느 패턴에서 불일치가 나왔는지의 정보로부터 고장 났을 것 같은 위치의 후보를 논리적으로 좁혀 가는 처리를 무엇이라고 합니까?
  50. 표준 셀 내부 트랜지스터의 단락이나 개방 등의 결함을, 셀의 회로를 바탕으로 모델화하여 테스트 패턴을 생성하는 기법은 무엇입니까?
