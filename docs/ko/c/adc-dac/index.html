A/D·D/A 변환: 핵심 정리

아날로그-디지털 변환기(ADC)는 아날로그 신호를 디지털 값으로, 디지털-아날로그 변환기(DAC)는 그 반대로 변환합니다. 센서, 통신, 오디오 등 현실 세계의 신호가 디지털 처리와 만나는 곳이면 어디서나 사용됩니다.

기본 성능 지표는 분해능(비트 수)과 변환 속도입니다. 표본화 정리, 양자화 오차, 그리고 플래시형, 축차 비교형, 델타-시그마형 등 각 방식의 특징을 이해해 두세요.

A/D·D/A 변환 전체 문제 (50)
  1. 8비트 ADC가 표현할 수 있는 출력 단계 수는 몇 개인가?
  2. 최대 20 kHz 성분을 포함하는 아날로그 신호를 에일리어싱(앨리어싱) 없이 샘플링하려면 필요한 샘플링 주파수는 무엇인가?
  3. 플래시형 ADC의 특징으로 옳은 것은 무엇인가?
  4. 축차 비교형(SAR형) ADC의 동작으로 옳은 것은 무엇인가?
  5. 이상적인 ADC에서 양자화 오차의 최댓값은 무엇인가? (LSB: 최하위 비트 1개에 해당하는 전압)
  6. ΔΣ(델타 시그마)형 ADC의 특징으로 옳은 것은 무엇인가?
  7. 분해능 10비트, 풀스케일 입력 1.024 V인 ADC의 1 LSB에 해당하는 전압은 얼마인가?
  8. ADC 앞단에 두는 안티에일리어싱 필터로 사용되는 필터의 종류는 무엇인가?
  9. R-2R 래더형 DAC의 특징으로 옳은 것은 무엇인가?
  10. ADC 앞단에 두는 샘플 앤 홀드 회로의 역할은 무엇인가?
  11. 이상적인 N비트 ADC에서 양자화 잡음으로 결정되는 신호 대 잡음비(SNR)의 근사식은 무엇인가? (풀스케일 사인파 입력인 경우)
  12. 디지털 멀티미터 등에 많이 사용되는 이중 적분형 ADC의 특징으로 옳은 것은 무엇인가?
  13. ADC의 미분 비선형성(DNL)에 대한 설명으로 옳은 것은 무엇인가?
  14. 입력을 변화시켜도 특정 출력 코드가 한 번도 나타나지 않는 ADC의 결함을 무엇이라 하는가?
  15. 고속 DAC에 많이 사용되는 전류 스티어링형의 특징으로 옳은 것은 무엇인가?
  16. 실제 ADC의 잡음과 왜곡을 포함한 성능을 이상적인 ADC의 비트 수로 환산한 지표는 무엇인가?
  17. 변환을 여러 단으로 나누어 조립 라인처럼 처리하여 고속과 중~고분해능을 양립하는 ADC는 무엇인가?
  18. 노이즈 셰이핑을 하지 않는 단순한 오버샘플링에서 샘플링 주파수를 4배로 했을 때 얻어지는 양자화 잡음의 개선량은 무엇인가?
  19. 높은 주파수의 신호를 AD 변환할 때 샘플링 클록의 시간적 흔들림(지터)이 문제가 되는 이유로 옳은 것은 무엇인가?
  20. 마이크로컨트롤러에서 PWM 신호를 로우패스 필터에 통과시켜 아날로그 전압을 만드는 방법에서 출력 전압을 결정하는 것은 무엇인가?
  21. ADC의 변환 속도를 나타내는 "MS/s(MSPS)"의 의미로 옳은 것은 무엇인가?
  22. ADC의 입출력 특성에서 입력이 0일 때 출력이 0에서 벗어나 있는 오차를 무엇이라 하는가?
  23. ADC에 차동 입력을 사용하는 장점으로 옳은 것은 무엇인가?
  24. ΔΣ형 ADC에서 고속의 거친 양자화 출력을 낮은 샘플링 주파수의 고분해능 데이터로 변환하는 디지털 회로는 무엇인가?
  25. DAC에서 입력 코드가 전환되는 순간 출력에 나타나는 일시적인 스파이크 모양의 오차를 무엇이라 하는가?
  26. 여러 ADC를 조금씩 어긋난 타이밍으로 번갈아 동작시켜 전체적으로 높은 샘플링 속도를 얻는 방식은 무엇인가?
  27. 축차 비교형 ADC의 입력 앞에 연산 증폭기 등의 드라이버 회로를 두는 주된 이유는 무엇인가?
  28. 많은 축차 비교형 ADC에서 내부 DAC로 사용되는 방식은 무엇인가?
  29. 저항을 직렬로 다수 연결한 저항 스트링형 DAC의 특징으로 옳은 것은 무엇인가?
  30. ADC 방식 중 오버샘플링형으로 분류되는 것은 무엇인가?
  31. ADC(아날로그-디지털 변환기)의 역할로 옳은 것은 무엇인가?
  32. DAC(디지털-아날로그 변환기)가 사용되는 예로 가장 적절한 것은 무엇인가?
  33. 입력 범위가 같은 ADC에서 분해능(비트 수)을 크게 하면 어떻게 되는가?
  34. AD 변환에서 "샘플링(표본화)"에 대한 설명으로 옳은 것은 무엇인가?
  35. AD 변환에서 "양자화"로 인해 생기는 오차를 무엇이라 하는가?
  36. 음악 CD의 샘플링 주파수로 옳은 것은 무엇인가?
  37. ADC의 적분 비선형성(INL)에 대한 설명으로 옳은 것은 무엇인가?
  38. ADC의 이득 오차(게인 오차)에 대한 설명으로 옳은 것은 무엇인가?
  39. DAC가 "단조성을 갖는다"는 것은 무슨 뜻인가?
  40. 각 비트에 가중치가 다른 저항(R, 2R, 4R…)을 할당하는 가중 저항형 DAC의 단점으로 옳은 것은 무엇인가?
  41. 3비트 플래시형 ADC에 필요한 비교기(컴패레이터)의 수는 몇 개인가?
  42. 10 kHz 사인파를 안티에일리어싱 필터 없이 샘플링 주파수 12 kHz로 샘플링하면 몇 Hz의 신호로 나타나는가?
  43. ADC의 성능을 나타내는 SFDR(스퓨리어스 프리 다이내믹 레인지)에 대한 설명으로 옳은 것은 무엇인가?
  44. N비트 축차 비교형 ADC가 1회 변환에서 수행하는 비교 횟수로 기본적으로 옳은 것은 무엇인가?
  45. 샘플 앤 홀드 회로의 "어퀴지션 시간"에 대한 설명으로 옳은 것은 무엇인가?
  46. 중심 주파수 70 MHz, 대역폭 10 MHz의 신호를 그보다 낮은 샘플링 주파수로 의도적으로 샘플링하여 주파수 변환도 겸하는 기법은 무엇인가?
  47. AD 변환 전에 작은 잡음(디더)을 일부러 더하는 주된 목적은 무엇인가?
  48. ΔΣ형 ADC 변조기의 차수를 높이는 것(예를 들어 1차에서 2차로)의 효과로 옳은 것은 무엇인가?
  49. 여러 ADC를 번갈아 동작시키는 타임 인터리브형 ADC에서 각 ADC의 오프셋, 이득, 타이밍의 어긋남(미스매치)으로 인해 생기는 문제는 무엇인가?
