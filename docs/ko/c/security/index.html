정보 보안 기초: 핵심 정리

정보를 지킨다는 것은 허가된 사람만 볼 수 있고(기밀성), 올바른 내용이 유지되며(무결성), 필요할 때 사용할 수 있는(가용성) 상태를 유지하는 것입니다. 이를 위해 암호, 해시 함수, 디지털 서명 같은 기술과 인증, 접근 제어, 백업, 조직으로서의 관리 체계를 조합합니다.

위협·취약점·위험의 개념과 위험 대응, 대칭 키 암호와 공개 키 암호의 구분과 키 개수 계산, 해시 함수와 비밀번호 저장, 디지털 서명과 인증서, 다요소 인증과 생체 인증의 오류율, 최소 권한의 원칙을 학습합니다. 악성코드와 피싱, SQL 인젝션과 크로스 사이트 스크립팅 등의 웹 공격을 구조와 대책의 관점에서 다루며, IT 자격시험의 보안 분야 학습에도 도움이 됩니다. 하드웨어와 관련된 보안은 '하드웨어 보안' 분야에서 다룹니다.

정보 보안 기초 전체 문제 (40)
  1. 사내 업무 시스템이 대량의 접근을 받아 응답하지 않게 되어, 이용자가 필요할 때 사용할 수 없게 되었다. 정보 보안의 3요소(기밀성·무결성·가용성) 중 주로 손상된 것은?
  2. 정보 보안의 위험을 생각할 때의 '위협'과 '취약점' 중 취약점에 해당하는 것은?
  3. 정보 유출이 일어났을 때의 손해 배상에 대비하여 사이버 보험에 가입했다. 이 위험 대응은 어느 것에 해당하는가?
  4. 어떤 정보 시스템에서 한 번 일어나면 2000만 엔의 손실이 나는 사고가 연 0.1회의 빈도로 일어난다고 추정된다. 연간 50만 엔의 비용이 드는 대책을 시행하면 발생 빈도가 연 0.02회로 떨어진다. 이 대책에 의한 연간 순효과(손실 기댓값의 감소액에서 대책 비용을 뺀 것)는 얼마인가?
  5. ISMS(정보 보안 관리 체계)를 PDCA 사이클로 운영할 때 Check(평가) 단계에서 하는 일로 적절한 것은?
  6. 대칭 키 암호의 특징으로 올바른 것은?
  7. 공개 키 암호를 사용하여 A 씨가 B 씨만 읽을 수 있도록 메시지를 암호화해 보내려고 한다. 암호화에 사용하는 키는?
  8. 50명의 구성원이 두 사람씩 짝지은 모든 조합에서 다른 구성원에게 내용을 알리지 않고 암호 통신을 하려고 한다. 대칭 키 암호를 사용하는 경우에 필요한 키의 수와 공개 키 암호를 사용하는 경우에 필요한 키의 수(공개 키와 개인 키의 합계)의 조합으로 올바른 것은?
  9. 큰 파일을 상대에게 암호화하여 보낼 때 자주 사용되는 하이브리드 암호 방식의 절차로 올바른 것은?
  10. 암호에서 사용되는 해시 함수(암호학적 해시 함수)의 성질로 올바른 것은?
  11. 출력이 256비트인 이상적인 해시 함수에 대해 무차별 대입로 공격할 때 필요한 계산 횟수의 기준으로, '주어진 해시값이 되는 입력을 찾는(역상 공격)' 경우와 '같은 해시값이 되는 서로 다른 두 입력을 아무것이나 찾는(충돌 공격)' 경우의 조합으로 올바른 것은?
  12. 웹 서비스에서 이용자의 비밀번호를 저장할 때, 비밀번호에 이용자마다 다른 무작위 값(솔트)을 더한 뒤 해시값을 계산하여 저장한다. 솔트를 사용하는 주된 목적은?
  13. 비밀번호 저장에 SHA-256 같은 고속 해시 함수를 그대로 사용하지 않고, bcrypt나 Argon2처럼 일부러 계산에 시간이 걸리도록 설계된 방식을 사용하는 것이 권장되는 이유로 올바른 것은?
  14. 8자 비밀번호를 모든 후보를 시도하는 무차별 대입로 찾는다. 초당 1×10^10개의 후보를 시도할 수 있을 때, 영문 소문자(26종류)만으로 만든 비밀번호와 영문 대문자·영문 소문자·숫자(62종류)로 만든 비밀번호에 대해 모든 후보를 다 시도할 때까지의 시간의 조합으로 가장 가까운 것은?
  15. A 씨가 B 씨에게 보내는 문서에 디지털 서명을 붙인다. 서명의 생성과 검증에 사용하는 키와, 디지털 서명으로 확인할 수 있는 것의 조합으로 올바른 것은?
  16. 메시지 인증 코드(MAC)와 디지털 서명을 비교한 설명으로 올바른 것은?
  17. 웹 서버의 서버 인증서에 대응하는 개인 키가 유출되었을 우려가 있음이 밝혀졌다. 인증서의 유효 기간은 아직 남아 있다. 운영자가 취해야 할 대응으로 가장 적절한 것은?
  18. 이용자를 확인하는 인증의 3요소(지식·소유·생체) 중 사원증 IC 카드를 사용하는 인증이 해당하는 것은?
  19. 다음 인증 방법 중 다요소 인증에 해당하는 것은?
  20. 지문을 이용한 생체 인증에서 본인으로 판정하기 위한 일치 정도의 임곗값을 엄격하게(높게) 했다. 일반적으로 일어나는 변화로 올바른 것은?
  21. 어떤 얼굴 인증 장치에서는 임곗값을 A·B·C의 3가지로 설정할 수 있으며, 각각의 타인 수락률(FAR)과 본인 거부율(FRR)은 A가 1%와 0.5%, B가 0.1%와 2%, C가 0.01%와 8%이다. 연구실 출입 관리에서 'FAR을 0.1% 이하로 한다'는 것을 조건으로 하고, 그런 다음 정당한 이용자가 가능한 한 거부되지 않도록 하고 싶다. 골라야 할 임곗값은?
  22. 싱글 사인온(SSO)에 대한 설명으로 올바른 것은?
  23. 최소 권한의 원칙에 따른 운영으로 올바른 것은?
  24. 직원이 수천 명인 회사에서 역할 기반 접근 제어(RBAC)를 사용하여 권한을 관리한다. RBAC의 개념으로 올바른 것은?
  25. 악성코드의 종류 중 웜의 특징으로 올바른 것은?

  27. 랜섬웨어 대비로서의 백업에 대해 '3-2-1 규칙'에 따른 방법으로 가장 적절한 것은?
  28. 피싱의 수법과 이용자 측 대책의 조합으로 올바른 것은?
  29. 사회공학 기법의 예로 해당하는 것은?
  30. 거래처 담당자를 자칭하는 메일로 '입금 계좌가 바뀌었으니 이번 청구부터는 이쪽으로 지불해 달라'는 의뢰를 받았다. 비즈니스 이메일 침해(BEC) 사기를 의심할 때의 대응으로 가장 적절한 것은?
  31. 로그인 화면에서 비밀번호 칸에 ' OR '1'='1 같은 문자열을 입력하면 비밀번호를 몰라도 로그인할 수 있게 되는 웹 애플리케이션이 있다. 이 공격의 이름은?
  32. SQL 인젝션 대책으로서 플레이스홀더를 사용하는 프리페어드 스테이트먼트(매개변수화 쿼리)가, 입력 안의 위험한 문자를 제거하는 방법보다 근본적인 대책으로 여겨지는 이유로 올바른 것은?
  33. 게시판 웹 애플리케이션에서 이용자가 게시한 글 안의 스크립트가 다른 열람자의 브라우저에서 실행되어 버리는 취약점이 있었다. 이 취약점의 이름과 근본적인 대책의 조합으로 올바른 것은?
  34. 웹 애플리케이션에서 로그인한 상태의 이용자가 공격자가 준비한 함정 페이지를 열면, 이용자의 브라우저에서 정규 사이트로 이용자가 의도하지 않은 송금이나 설정 변경 요청이 보내지는 취약점이 있다. 이 취약점에 대한 대책으로 적절한 것은?
  35. 웹 애플리케이션이 URL 매개변수로 지정된 파일 이름을 공개용 폴더의 이름과 이어 붙여 읽어 들여 표시하고 있다. 파일 이름에 ../를 포함한 값을 지정하면 공개용 폴더 밖에 있는 설정 파일 등을 읽어 낼 수 있게 된다. 이 공격의 이름과 대책의 조합으로 올바른 것은?
  36. 웹 애플리케이션에서 로그인 전과 후에 같은 세션 ID를 계속 사용하면, 공격자가 미리 준비한 세션 ID를 이용자가 사용하게 하고, 이용자가 로그인한 뒤 그 ID로 이용자를 사칭할 우려가 있다. 이 공격에 대한 대책으로 가장 적절한 것은?
