C 언어의 정수형 크기와 고정 폭 정수형, 정수 승격과 부호 있는·부호 없는 변환, 연산자 우선순위, 비트 연산, switch 문, 값 전달과 포인터, static 변수, 배열과 포인터 연산, 문자열과 sizeof, const, 함수 포인터, malloc·free와 메모리 누수, 댕글링 포인터, 버퍼 오버플로, 구조체의 패딩, 공용체와 엔디언, 비트 필드, 매크로와 조건부 컴파일, volatile, 미정의 동작을 짧은 코드를 따라가는 객관식 문제로 학습합니다.

C 언어 기초: 핵심 정리

C 언어는 OS나 디바이스 드라이버, 마이컴의 펌웨어 등 하드웨어에 가까운 소프트웨어에서 지금도 널리 사용되고 있습니다. 메모리의 주소를 직접 다룰 수 있어 빠른 코드를 쓸 수 있는 반면, int의 크기가 처리계에 따라 다르거나, 계산 도중에 형이 바뀌거나, 배열의 범위를 넘어도 멈추지 않는 등 모르면 실수를 알아차리기 어려운 규칙이 많이 있습니다.

여기서는 짧은 코드를 실제로 실행했을 때의 출력을 따라가는 문제를 중심으로, 정수형의 크기와 stdint.h의 고정 폭 정수형, 정수의 나눗셈, 정수 승격과 부호 있는·부호 없는 값의 비교, 연산자 우선순위, 비트 연산, 단락 평가, switch 문의 폴스루, 값 전달과 포인터 전달, static 변수와 수명, 포인터 연산과 배열, 2차원 배열의 배치, 문자열과 strlen·sizeof, const를 붙이는 위치, 함수 포인터를 학습합니다. 이어서 malloc과 free, 메모리 누수, 댕글링 포인터, 버퍼 오버플로, NULL 포인터, 구조체의 패딩, 공용체와 엔디언, 비트 필드, 매크로와 인클루드 가드, 조건부 컴파일, 임베디드에서의 volatile, 미정의 동작과 컴파일러의 최적화를 다룹니다. 프로그램의 출력은 x86-64 Linux의 gcc로 실제로 컴파일하여 확인했습니다. 의사 코드의 트레이스는 '프로그래밍의 기초(의사 코드 트레이스)', volatile을 사용한 인터럽트나 레지스터 조작은 '임베디드 시스템과 펌웨어', 컴파일러 최적화의 자세한 내용은 '컴파일러', 메모리 배치와 링크는 '링커, 로더, 실행 파일' 분야에서 다룹니다.
