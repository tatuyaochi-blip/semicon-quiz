차세대 메모리: 핵심 정리

DRAM과 플래시 메모리의 한계를 넘기 위해 다양한 새로운 원리에 기반한 메모리가 개발되고 있습니다. 대부분 비휘발성이며, 전하가 아니라 저항의 차이나 분극 방향으로 정보를 저장합니다.

MRAM은 자기터널접합의 자화 방향, PCM은 결정질과 비정질 상태의 저항 차이, ReRAM은 산화물 속 전도 경로, FeRAM은 강유전체의 분극을 이용합니다. 이러한 원리와 특징을 구분할 수 있도록 학습하세요.
