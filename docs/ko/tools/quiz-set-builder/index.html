퀴즈 세트 만들기

수업, 연구실 그룹, 신입 사원 교육용 퀴즈를 만듭니다. 주제와 문항 수를 고른 뒤 링크를 공유하면 됩니다. 링크를 연 모든 사람이 자세한 해설이 포함된 같은 문제를 풉니다. 가입은 필요 없습니다.

세트 구성

주제

퀴즈 세트 링크

열어서 확인

이 링크를 여는 사람은 누구나 같은 문제를 받습니다(보기 순서는 매번 섞입니다). 결과는 각자의 브라우저에만 남으며 선생님이나 저희에게 전송되지 않습니다.

사용 방법

주제를 체크하고 원하는 문항 수를 고른 뒤 [링크 만들기]를 누릅니다. 문제는 선택한 주제에서 고르게 출제됩니다. 세트 이름을 입력하면 퀴즈 화면의 제목으로 표시됩니다. 링크는 학습 관리 시스템(LMS), 이메일, 메신저 등으로 공유할 수 있으며, 같은 링크를 열면 항상 같은 문제가 나옵니다.

성적과 개인정보

이 사이트는 계정도 데이터베이스도 사용하지 않습니다. 결과는 퀴즈를 푼 사람의 브라우저에만 저장됩니다. 점수를 모아야 한다면 수업 방식에 맞게 결과 화면 스크린숏이나 점수를 제출하도록 학생들에게 안내해 주십시오.

자주 묻는 질문

퀴즈 만들기는 무료입니까?

네. 무료이며 가입이 필요 없고, 만든 링크에는 유효 기간이 없습니다.

모든 학생이 같은 문제를 받습니까?

네, 같은 링크를 연 사람은 모두 같은 문제를 받습니다. 보기 순서는 매번 섞이므로 정답을 그대로 돌려 볼 수 없습니다.
