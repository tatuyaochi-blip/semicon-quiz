6T SRAM 셀란?

교차 연결된 두 인버터(4개)와 접근용 트랜지스터 2개로 이루어진 SRAM의 메모리 셀.

일본어 명칭: 6T SRAMセル

6T SRAM 셀은(는) SRAM과 플래시 메모리 등 1개 분야의 연습 문제 2개에 나와요.

분야: SRAM과 플래시 메모리

도전해 보기: 6T SRAM 셀 관련 문제

6T SRAM 셀에서 읽기 시 셀의 내용이 반전되지 않도록(읽기 파괴를 방지하도록) 필요한 설계로 올바른 것은 무엇입니까?

  1. A액세스 트랜지스터를 풀다운 트랜지스터보다 강하게 한다
  2. B풀업 트랜지스터를 제거한다
  3. C풀다운(구동) 트랜지스터를 액세스 트랜지스터보다 강하게 한다
정답과 해설 보기

정답: C. 풀다운(구동) 트랜지스터를 액세스 트랜지스터보다 강하게 한다

읽기 시 0을 유지하는 노드에는 프리차지된 비트 라인에서 액세스 트랜지스터를 통해 전류가 흘러들어 전압이 조금 올라갑니다. 풀다운 트랜지스터가 액세스 트랜지스터보다 충분히 강하면(셀 비 β = 풀다운/액세스를 1.5~2.5 정도로) 이 상승이 반대쪽 인버터의 문턱보다 작게 억제되어 데이터가 반전되지 않습니다. 8T 셀이나 읽기 어시스트로도 대책을 세울 수 있습니다.

해설 속 6T SRAM 셀

  • 6T SRAM 셀은 두 인버터를 서로의 출력이 상대의 입력이 되도록 접속한 래치(4개)와, 비트 라인과의 접속을 제어하는 액세스 트랜지스터 2개로 구성됩니다.

6T SRAM 셀이(가) 나오는 문제 (2)

  1. 6T SRAM 셀에서 읽기 시 셀의 내용이 반전되지 않도록(읽기 파괴를 방지하도록) 필요한 설계로 올바른 것은 무엇입니까?
  2. 일반적인 6트랜지스터형 SRAM 셀의 구성으로 올바른 것은 무엇입니까?

이 용어가 포함된 비교

  • DRAM과 SRAM의 차이점 한눈에 정리DRAM과 SRAM을 한 장의 표로 비교합니다. 셀 구조, 리프레시, 속도, 집적도, 비용, 전력, 대표 용도와 각각을 언제 쓰는지 안내합니다.
