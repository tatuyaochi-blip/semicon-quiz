조합 루프(Combinational Loop)란?

플립플롭을 거치지 않고 조합 회로의 출력이 자신의 입력으로 돌아오는 구조. 발진하거나 값이 정해지지 않고 타이밍 분석도 할 수 없으므로 피한다.

일본어 명칭: 組み合わせループ

분야: HDL과 검증

관련 용어

4값 논리(four-valued logic) 게이트 레벨 시뮬레이션(Gate-level Simulation) 논블로킹 대입(Non-blocking Assignment) 동기 리셋(synchronous reset) 리셋 동기화 회로(Reset Synchronizer) 민감도 목록(Sensitivity List) 밀리형(Mealy Machine) 블로킹 할당(blocking assignment) 비동기 리셋(Asynchronous Reset) 원핫 인코딩(One-hot Encoding)
