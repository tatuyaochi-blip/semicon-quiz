진리표란?

입력의 모든 조합에 대한 출력을 나열한 표. 논리 회로의 동작을 나타내는 데 사용한다.

일본어 명칭: 真理値表

진리표은(는) 논리 회로, IC 설계 흐름과 EDA 등 2개 분야의 연습 문제 3개에 나와요.

분야: 논리 회로

진리표 작성 방법

입력을 열로 나열하고, 모든 입력 조합을 보통 모두 0부터 모두 1까지 2진수 카운트 순서로 행에 적은 다음, 출력마다 열을 하나씩 추가합니다. 입력이 n개이면 행은 2ⁿ개입니다. 예를 들어 2입력 XOR은 4개 행을 가지며 01과 10일 때만 1을 출력합니다. 합(sum)과 자리올림(carry)을 내는 반가산기처럼 출력이 여러 개인 회로는 같은 입력 행을 공유하는 출력 열을 여러 개 가지면 됩니다.

진리표에서 불 식으로

출력이 1인 각 행은 모든 입력을 원래 형태나 보수 형태로 곱한 최소항(minterm)에 대응합니다. 이 최소항들을 OR하면 정준 곱의 합(SOP) 식이 됩니다. 대신 출력이 0인 행에서 출발하면 최대항(maxterm)과 합의 곱(POS) 형태가 나옵니다. 이러한 정준식은 올바르지만 보통 최소와는 거리가 멀기 때문에, 다음 단계로 불 대수, 카르노 맵 또는 소프트웨어 최소화 툴로 간략화합니다.

돈케어 항목

어떤 입력 조합은 결코 발생하지 않거나 출력이 중요하지 않습니다. 예를 들어 BCD(2진화 10진) 숫자를 디코딩하는 회로는 1010부터 1111까지의 패턴을 결코 받지 않습니다. 이런 행은 돈케어(don't-care)를 뜻하는 X로 표시합니다. 간략화할 때 각 X는 더 큰 그룹과 더 작은 회로를 만드는 쪽에 따라 0 또는 1로 취급할 수 있으므로, 돈케어를 명시적으로 기록하면 게이트를 절약할 수 있는 경우가 많습니다.

진리표가 확장되지 않는 이유

입력이 하나 늘 때마다 행 수가 두 배가 되므로, 모든 경우를 나열하는 표는 작은 블록에만 실용적입니다. 32비트 가산기는 입력이 64개이므로 2⁶⁴개의 행이 필요합니다. 따라서 대규모 설계는 불 식이나 하드웨어 기술 언어(HDL)로 계층적으로 기술하고, 시뮬레이션과 형식 등가성 검사로 검증합니다. 순차 회로도 단순한 진리표 이상이 필요합니다. 상태표는 현재 상태를 입력으로, 다음 상태를 출력으로 추가합니다.

3입력 논리 회로의 진리표는 몇 행입니까?

  1. A6행
  2. B9행
  3. C8행
정답과 해설 보기

정답: C. 8행

각 입력은 0 또는 1의 2가지이므로 3입력의 조합은 2³ = 8가지이고 진리표는 8행이 됩니다. n입력에서는 2ⁿ행으로 지수함수적으로 늘어나므로, 32비트 가산기(64입력)의 진리표는 2⁶⁴행이 되어 만드는 것이 현실적이지 않습니다. 그래서 큰 회로는 작은 부품을 조합하여 설계하고, 논리식이나 HDL로 기술하여 검증합니다.

자주 묻는 질문

입력이 n개인 진리표의 행 수는?

각 입력이 0 또는 1일 수 있으므로 2ⁿ개입니다. 입력이 3개면 8행, 4개면 16행과 같은 식입니다.

진리표와 카르노 맵의 차이는 무엇인가요?

담고 있는 정보는 같습니다. 카르노 맵은 행을 그레이 코드 순서의 격자로 재배열하여, 논리적으로 인접한 조합이 서로 이웃하게 만들고 간략화를 위해 묶을 수 있게 한 것입니다.

진리표로 플립플롭을 표현할 수 있나요?

단순한 조합 진리표로는 표현할 수 없습니다. 플립플롭은 현재 상태를 입력 열로, 다음 상태를 출력으로 포함하는 특성표나 상태표로 기술합니다.

해설 속 진리표

  • 각 입력은 0 또는 1의 2가지이므로 3입력의 조합은 2³ = 8가지이고 진리표는 8행이 됩니다.

    3입력 논리 회로의 진리표는 몇 행입니까?

  • 카르노 맵은 진리표를 이웃한 칸의 입력이 1비트만 다르도록(그레이 코드 순) 배열한 도표입니다.

    카르노 맵의 주된 용도는?

  • FPGA는 작은 진리표(LUT)를 가진 논리 블록과 배선의 연결 방식을 제조 후에 설정 데이터로 다시 쓸 수 있는 디바이스입니다.
