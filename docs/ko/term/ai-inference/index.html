추론(Inference)란?

학습으로 정해진 가중치를 사용하여 입력으로부터 순전파만 수행해 답을 내는 AI 처리. 학습보다 연산과 메모리가 적게 든다.

일본어 명칭: 推論

추론(Inference)은(는) AI 하드웨어·소프트웨어 스택, CPU와 아키텍처, GPU 프로그래밍 등 6개 분야의 연습 문제 24개에 나와요.

분야: AI 하드웨어·소프트웨어 스택

추론과 학습의 차이

학습은 순전파를 실행하고, 손실을 계산하고, 기울기를 역전파하고, 가중치를 갱신하는 과정을 데이터셋 전체에 대해 여러 번 반복합니다. 역전파를 위해 중간 활성화 값을 보관하고 옵티마이저 상태를 저장해야 하며, 작은 기울기를 표현할 수 있는 범위를 가진 부동소수점 포맷이 보통 필요합니다. 추론은 고정된 가중치로 입력 하나 또는 배치 하나씩 순전파만 실행합니다. 샘플당 필요한 메모리와 연산이 훨씬 적고 훨씬 낮은 정밀도를 허용하므로 8비트 정수나 그보다 좁은 포맷이 흔히 쓰입니다. 학습은 모델 버전마다 한 번 이루어지지만, 추론은 모델을 사용할 때마다 실행됩니다.

추론 속도를 제한하는 요인

연산의 대부분은 행렬 곱과 컨볼루션 내부의 곱셈-누산 연산이며, 그래서 가속기는 수천 개의 곱셈-누산 유닛을 집적합니다. 실제 병목은 이 유닛들에 데이터를 공급하는 것인 경우가 많습니다. 배치 크기가 1이면 메모리에서 가져온 각 가중치가 입력 하나에만 쓰이므로 성능은 연산이 아니라 메모리 대역폭에 의해 제한됩니다. 새 토큰마다 모든 가중치를 읽는 대규모 언어 모델의 텍스트 생성이 전형적인 예입니다. 여러 요청을 배치로 묶으면 가져온 가중치를 재사용해 지연 시간을 대가로 처리량을 높일 수 있습니다. 따라서 지연 시간과 처리량은 따로 명시해야 합니다.

모델을 더 작고 저렴하게

FP32에서 INT8로의 양자화는 가중치 저장 용량과 메모리 트래픽을 1/4로 줄이고 소형 정수 유닛으로 연산할 수 있게 하며, 그 대가인 작은 정확도 저하 위험은 캘리브레이션이나 양자화 인식 학습으로 관리합니다. 증류(distillation)는 작은 학생 모델이 큰 교사 모델을 모방하도록 학습시킵니다. 가지치기(pruning)는 기여도가 낮은 가중치나 채널 전체를 제거하며, 구조적 희소성 패턴을 사용하면 하드웨어가 0을 건너뛸 수 있습니다. 이 기법들은 서로 조합되며, 스마트폰이나 임베디드 기기의 메모리, 전력, 발열 예산 안에서 모델을 실행할 수 있게 해 주는 것이 바로 이들입니다.

클라우드 추론과 엣지 추론

데이터 센터 추론은 메모리와 전력이 풍부한 GPU나 전용 가속기에서 대형 모델을 실행합니다. 엣지 추론은 디바이스에서 실행되며, 일반적으로 SoC에 내장된 신경망 처리 장치(NPU)를 사용합니다. NPU는 저정밀도 행렬 연산에 특화되어 있고, 데이터를 칩 내에서 재사용하며, 분기 예측 같은 범용 기구를 생략하므로 CPU보다 에너지 효율이 훨씬 높습니다. 디바이스에서 실행하면 네트워크 지연을 피하고, 오프라인에서도 동작하며, 사진과 음성을 기기 안에 두고, 서버 비용을 절약할 수 있습니다. 트레이드오프는 매우 큰 모델은 강한 압축 없이는 디바이스의 한계 안에 들어가지 않는다는 점입니다.

  2. B데이터양이 4분의 1이 되어 빠르고 저전력으로 계산할 수 있다
  3. C학습을 다시 하지 않아도 모델 성능이 반드시 향상된다
정답과 해설 보기

정답: B. 데이터양이 4분의 1이 되어 빠르고 저전력으로 계산할 수 있다

32비트 가중치를 8비트로 하면 메모리 사용량과 읽어 들이는 양이 4분의 1이 되어, 메모리 대역폭이 제한된 추론에서 큰 효과가 있습니다. 또한 8비트 정수 곱셈기는 부동소수점 곱셈기보다 훨씬 작고 저전력이므로 같은 면적과 전력으로 더 많은 연산을 할 수 있습니다. 그 대신 표현할 수 있는 값이 256가지로 제한되므로 오차가 생겨 정밀도가 조금 떨어질 수 있습니다. 정밀도가 올라가거나 성능이 반드시 향상되는 것은 아닙니다.

GPU가 행렬 연산이나 AI의 학습·추론에 적합한 주된 이유는?

  1. A클록 주파수가 CPU의 100배 이상이기 때문
  2. B단순한 연산기를 다수 갖추고 있어 대량의 데이터를 병렬로 처리할 수 있기 때문
  3. C메모리를 갖지 않기 때문
정답과 해설 보기

정답: B. 단순한 연산기를 다수 갖추고 있어 대량의 데이터를 병렬로 처리할 수 있기 때문

GPU는 원래 화면의 수많은 화소를 동시에 처리하기 위해 단순한 연산기를 수천~1만 개 이상 늘어놓은 구조를 가지고 있습니다. 행렬 연산처럼 같은 계산을 대량의 데이터에 반복하는 처리에서는 이 병렬성으로 높은 성능을 발휘합니다. 최근에는 행렬 연산 전용 유닛(Tensor Core 등)과 광대역 HBM을 갖추어 AI 학습의 주역이 되었습니다. 분기가 많은 순차적 처리는 CPU가 더 잘합니다.

AI 학습과 추론의 차이

학습은 데이터셋에 대해 순전파와 역전파를 수행해 모델의 가중치를 조정하는 과정으로, 연산과 메모리를 매우 많이 사용합니다. 추론은 학습된 고정 가중치를 사용해 새로운 입력에 대한 출력을 순전파만으로 계산합니다.

AI 추론이 메모리 대역폭에 제한되는 경우가 많은 이유

배치가 작으면 메모리에서 읽은 각 가중치가 몇 번의 계산에만 쓰이므로 연산 유닛이 데이터를 기다리게 됩니다. 텍스트 생성처럼 배치 크기 1로 실행하는 대형 모델이 가장 메모리 바운드한 경우입니다.

스마트폰은 왜 CPU 대신 NPU로 추론하나요?

NPU는 저정밀도 곱셈-누산 유닛을 많이 집적하고 범용 제어의 오버헤드가 없으므로 연산당 에너지가 훨씬 적습니다. 그래서 배터리와 발열 한계 안에서 온디바이스 기능을 실용화할 수 있습니다.
