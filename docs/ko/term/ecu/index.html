ECU(전자 제어 장치)란?

엔진, 브레이크, 도어 등을 제어하는, 마이크로컨트롤러를 중심으로 한 차량용 제어 장치. 기능마다 늘어나 1대에 100개를 넘기도 하며, 존 아키텍처 등에 의한 통합이 진행되고 있다.

일본어 명칭: ECU(電子制御ユニット)

ECU(전자 제어 장치)은(는) 차량용 반도체와 기능 안전, 반도체 산업과 시장 등 2개 분야의 연습 문제 5개에 나와요.

분야: 차량용 반도체와 기능 안전

도전해 보기: ECU(전자 제어 장치) 관련 문제

여러 ECU의 기능을 하나의 고성능 SoC에 통합하고, 서로 다른 ASIL의 소프트웨어를 함께 동작시킬 때 요구되는 것으로 올바른 것은?

  1. AASIL이 낮은 소프트웨어와 ASIL이 높은 소프트웨어를 같은 메모리 영역에 두고, 데이터를 자유롭게 읽고 쓰게 한다
  2. BASIL이 낮은 소프트웨어의 오동작이 ASIL이 높은 소프트웨어의 메모리나 실행 시간을 침범하지 않도록, 메모리 보호나 시간 감시 등으로 분리한다
  3. CASIL이 낮은 소프트웨어에 높은 우선순위를 주고, ASIL이 높은 소프트웨어는 빈 시간에만 실행한다
정답과 해설 보기

정답: B. ASIL이 낮은 소프트웨어의 오동작이 ASIL이 높은 소프트웨어의 메모리나 실행 시간을 침범하지 않도록, 메모리 보호나 시간 감시 등으로 분리한다

하나의 SoC에 여러 기능을 모으면 부품이나 ECU의 수를 줄일 수 있지만, ASIL이 낮은 소프트웨어의 버그가 메모리를 덮어써 망가뜨리거나 CPU 시간을 다 써 버려 ASIL이 높은 기능을 방해할 우려가 있습니다. 그래서 메모리 보호 유닛이나 하이퍼바이저에 의한 공간 분리, 실행 시간의 할당과 감시에 의한 시간 분리 등으로 간섭이 없음(Freedom from Interference)을 보여 줍니다. 분리하지 않는 경우에는 모두를 가장 높은 ASIL로 개발해야 하므로 수고가 커집니다.

해설 속 ECU(전자 제어 장치)

  • 하나의 SoC에 여러 기능을 모으면 부품이나 ECU의 수를 줄일 수 있지만, ASIL이 낮은 소프트웨어의 버그가 메모리를 덮어써 망가뜨리거나 CPU 시간을 다 써 버려 ASIL이 높은 기능을 방해할 우려가 있습니다.

    여러 ECU의 기능을 하나의 고성능 SoC에 통합하고, 서로 다른 ASIL의 소프트웨어를 함께 동작시킬 때…

  • FlexRay는 통신 주기 안에 각 ECU가 송신할 시간 슬롯을 미리 할당하는 시간 트리거 방식으로, 데이터가 도착하기까지의 시간이 정해져 있는 것이 특징입니다.

    차량용 네트워크 FlexRay의 특징으로 올바른 것은?

  • CAN보다 훨씬 넓은 대역이 있으므로 카메라나 디스플레이의 데이터, ECU 사이를 잇는 기간 네트워크, 소프트웨어 재기록 등에 사용됩니다.

    차량용 이더넷(100BASE-T1이나 1000BASE-T1 등)의 특징으로 올바른 것은?

  • 기존에는 기능을 추가할 때마다 전용 ECU가 늘어나, 고급차에서는 100개를 넘기도 하는 ECU와 길고 무거운 와이어 하네스가 사용되게 되었습니다.

    자동차 전자 시스템에서 진행되고 있는 "존 아키텍처"로의 이행에 대한 설명으로 올바른 것은?

  • 인포테인먼트와 통신 기능, 다수의 전자 제어 유닛(ECU)도 늘어나 1대당 반도체 탑재량이 크게 증가하고 있습니다.
