위치 독립 코드(PIC)란?

메모리의 어느 번지에 적재해도 코드를 고치지 않고 동작하는 기계어. PIC라고도 한다. PC 상대 참조나 GOT를 이용하며 공유 라이브러리와 PIE에서 쓰인다.

일본어 명칭: 位置独立コード

위치 독립 코드(PIC)은(는) 링커, 로더, 실행 파일, ISA와 어셈블리 등 2개 분야의 연습 문제 5개에 나와요.

위치 독립 코드(PIC)의 설명으로 올바른 것은 무엇입니까?

  1. A어떤 CPU에서도 똑같이 동작하는 기계어
  2. B실행 중에 자신의 위치를 계속 옮기는 기계어
  3. C메모리의 어느 주소에 읽어 들여도 코드를 고쳐 쓰지 않고 올바르게 동작하도록 만들어진 기계어
정답과 해설 보기

정답: C. 메모리의 어느 주소에 읽어 들여도 코드를 고쳐 쓰지 않고 올바르게 동작하도록 만들어진 기계어

공유 라이브러리는 프로세스마다 다른 주소에 읽혀질 수 있습니다. 위치 독립 코드에서는 함수나 데이터를 고정 주소가 아니라 PC로부터의 거리나 주소를 모아 둔 테이블(GOT)을 통해 참조합니다. 이렇게 하면 읽어 들이는 주소가 바뀌어도 코드 페이지를 고쳐 쓰지 않아도 되므로, 물리 메모리 상의 하나의 사본을 많은 프로세스가 공유할 수 있습니다.

해설 속 위치 독립 코드(PIC)

  • 위치 독립 코드에서는 함수나 데이터를 고정 주소가 아니라 PC로부터의 거리나 주소를 모아 둔 테이블(GOT)을 통해 참조합니다.

    위치 독립 코드(PIC)의 설명으로 올바른 것은 무엇입니까?

  • 이는 공유 라이브러리 등에서 사용하는 위치 독립 코드(PIC)의 토대가 됩니다.

    분기나 점프에 PC 상대 주소 지정을 사용하는 것의 이점으로 올바른 것은?

  • 이에 따라 프로그램을 어디에 로드해도 동작하는 위치 독립 코드에서 먼 함수를 호출하거나 전역 변수를 읽을 수 있습니다.

    RISC-V의 auipc 명령어(add upper immediate to PC)의 동작으로 올바른 것은?

  • 위치 독립 코드는 다른 라이브러리에 있는 변수의 주소를 명령에 직접 쓸 수 없습니다.

    공유 라이브러리에서 사용되는 GOT(Global Offset Table)의 역할로 올바른 것은 무엇입니까?

  • PIE는 본체도 위치 독립 코드로 만들어 어디에 읽혀도 동작하게 한 것으로, 본체의 주소도 무작위로 할 수 있습니다.

    실행 파일을 PIE(위치 독립 실행 파일)로 만드는 주된 이유는 무엇입니까?
