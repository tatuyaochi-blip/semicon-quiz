가상 단락(Imaginary Short)란?

부귀환을 건 이상적인 연산 증폭기에서 두 입력 단자의 전압이 거의 같아지는 성질. 전류는 흐르지 않지만 단락된 것처럼 다룰 수 있어 증폭 회로의 이득을 쉽게 구할 수 있다.

일본어 명칭: 仮想短絡(イマジナリーショート)

가상 단락(Imaginary Short)은(는) 아날로그·전자 회로 등 1개 분야의 연습 문제 2개에 나와요.

분야: 아날로그·전자 회로

입력이 같아지는 이유

연산 증폭기의 출력은 Vout = A(V+ − V−)이며, 개루프 이득 A는 매우 커서 일반적인 실제 소자의 경우 저주파에서 약 10⁵~10⁶입니다. 부귀환이 걸리면 회로는 출력이 유한한 지점에서 안정되므로, 입력 차이는 Vout/A가 되어야 합니다. 출력이 10 V이고 A = 10⁵이면 입력 차이는 100 µV에 불과합니다. 이상적인 해석에서는 A가 무한대이므로 차이가 0이 되고, 두 입력을 같은 전압으로 취급할 수 있습니다.

활용 예: 반전 증폭기

반전 증폭기에서는 비반전 입력이 접지되어 있으므로, 가상 단락에 의해 반전 입력이 0 V가 되며, 이 특수한 경우를 가상 접지라고 합니다. 이때 입력 전류는 Vin/R1입니다. 이상적인 연산 증폭기의 입력은 전류를 흘리지 않으므로 그 전류는 모두 귀환 저항 Rf를 통해 흐르고, Vout = −(Rf/R1)·Vin이 됩니다. 같은 두 가지 규칙으로 비반전 증폭기의 이득 1 + Rf/R1을 구하고, 가산 증폭기, 적분기, 차동 증폭기를 해석할 수 있습니다.

가상 단락과 실제 단락

실제 단락이라면 입력 사이에 전류가 흐르겠지만, 가상 단락에서는 흐르지 않습니다. 따라서 해석에서는 이상적인 연산 증폭기에 대한 두 가지 별개의 가정을 함께 사용합니다. 귀환과 높은 이득 때문에 입력이 같은 전압이 된다는 것과, 무한대의 입력 임피던스 때문에 어느 입력으로도 전류가 들어가지 않는다는 것입니다. 한 입력에서 다른 입력으로 전류가 흐르게 하는 식으로 둘을 혼동하면 틀린 답이 나옵니다. 이 같음은 어떤 연결이 아니라 출력에 의해 능동적으로 유지됩니다.

가정이 성립하지 않는 경우

가상 단락은 부귀환이 작동하는 동안에만 성립합니다. 출력이 전원 레일에서 포화되거나, 슬루율 제한에 걸리거나, 신호 주파수가 너무 높아 루프 이득이 떨어지면 입력이 서로 벌어집니다. 비교기와 슈미트 트리거는 개루프 또는 정귀환으로 동작하므로 입력이 의도적으로 같지 않습니다. 실제 연산 증폭기에는 수 µV에서 수 mV의 입력 오프셋 전압도 있으며, 이는 입력 간의 작고 일정한 차이로 나타납니다.

  2. B입력 임피던스: 0, 출력 임피던스: 무한대
  3. C입력 임피던스: 0, 출력 임피던스: 0
정답과 해설 보기

정답: A. 입력 임피던스: 무한대, 출력 임피던스: 0

이상적인 연산 증폭기는 입력 임피던스가 무한대(입력 단자로 전류가 흐르지 않음), 출력 임피던스가 0(부하와 관계없이 출력 전압이 결정됨), 개루프 이득이 무한대라고 가정합니다. 이 가정에서 부귀환 회로는 두 입력 단자의 전압이 같아지는 '가상 단락'이 성립하고, 회로의 이득이 저항비만으로 결정됩니다. 실제 연산 증폭기의 개루프 이득은 10⁵~10⁶ 정도이며 주파수가 높아질수록 감소합니다.

부귀환을 건 이상적인 연산 증폭기 회로에서 두 입력 단자의 전압이 거의 같아지는 성질을 무엇이라고 합니까?

  1. A슬루 레이트
  2. B오프셋
  3. C가상 단락(이매지너리 쇼트)
정답과 해설 보기

정답: C. 가상 단락(이매지너리 쇼트)

개루프 이득 A가 매우 큰 연산 증폭기에 부귀환을 걸면 출력이 유한한 값에서 균형을 이루기 때문에 입력 단자 간 전압차는 Vout/A로 거의 0이 됩니다. 실제로 연결되어 있지 않은데도 단락된 것처럼 보이므로 가상 단락이라고 하며, 비반전 입력이 접지되어 있으면 반전 입력도 0 V(가상 접지)로 볼 수 있습니다. 연산 증폭기 회로 해석의 기본이지만, 출력이 포화되었을 때나 정귀환 회로(컴퍼레이터)에서는 성립하지 않습니다.

자주 묻는 질문

가상 단락과 가상 접지의 차이는 무엇인가요?

가상 단락은 부귀환 하에서 두 입력이 같은 전압이 된다는 일반적인 성질이고, 가상 접지는 한 입력이 접지되어 다른 입력이 0 V로 유지되는 경우입니다.

가상 단락을 통해 전류가 흐르나요?

흐르지 않습니다. 입력은 같은 전압이지만 연결되어 있지 않으며, 이상적인 연산 증폭기는 입력 전류를 끌어가지 않습니다.

비교기에는 가상 단락을 적용할 수 없는 이유는?

비교기에는 부귀환이 없으므로 출력이 레일까지 스윙하며, 입력을 같은 전압으로 만드는 작용이 없기 때문입니다.
