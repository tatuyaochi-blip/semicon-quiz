인수(Argument)란?

함수나 프로시저를 호출할 때 넘기는 값. 선언하는 쪽에서 값을 받는 변수를 형식 인수(매개변수), 호출하는 쪽에서 넘기는 값을 실인수라고 한다. 값을 복사하여 넘기는 값에 의한 전달과, 변수나 배열 자체를 참조하게 하는 참조에 의한 전달이 있다.

일본어 명칭: 引数

인수(Argument)은(는) 링커, 로더, 실행 파일, 프로그래밍의 기초(의사 코드 트레이스), 컴파일러 등 9개 분야의 연습 문제 23개에 나와요.
