차분 방정식(Difference Equation)란?

이산 시간 시스템의 출력을 현재와 과거의 입력 및 과거 출력의 가중합으로 나타낸 식. 예를 들어 y[n] = x[n] + 0.5y[n − 1]은 하나 앞 출력의 절반을 현재 입력에 더한다. 우변에 과거의 출력을 포함하지 않는 것은 FIR 필터이고, 과거의 출력을 포함하는 것(귀환이 있는 것)은 보통 임펄스 응답이 무한히 계속되는 IIR 필터가 된다. 초깃값을 주면 차례로 계산할 수 있으며, 그대로 프로그램이나 하드웨어로 구현할 수 있다. 양변을 z 변환하면 전달 함수 H(z)를 얻는다.

일본어 명칭: 差分方程式

차분 방정식(Difference Equation)은(는) 디지털 신호 처리의 기초 등 1개 분야의 연습 문제 2개에 나와요.

분야: 디지털 신호 처리의 기초

도전해 보기: 차분 방정식(Difference Equation) 관련 문제

차분 방정식 y[n] = x[n] + 0.5y[n − 1]로 표현되는 시스템에 n = 0부터 단위 계단(n ≥ 0에서 x[n] = 1)을 입력했다. y[−1] = 0일 때, y[2]로 올바른 것은?

  1. A1.75
  2. B1.875
  3. C2
정답과 해설 보기

정답: A. 1.75

차례로 계산하면 y[0] = 1 + 0.5 × 0 = 1, y[1] = 1 + 0.5 × 1 = 1.5, y[2] = 1 + 0.5 × 1.5 = 1.75입니다. 이대로 계속하면 y[n] = 2 − 0.5ⁿ이 되어 최종값 1/(1 − 0.5) = 2에 가까워집니다. 과거의 출력을 사용하므로(귀환이 있으므로) 임펄스 응답 0.5ⁿ이 무한히 계속되는 IIR 필터입니다.

차분 방정식 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1]로 표현되는 시스템의 전달 함수 H(z) = Y(z)/X(z)로 올바른 것은?

  1. A(1 + 0.5z⁻¹)/(1 + 0.25z⁻¹)
  2. B(1 − 0.25z⁻¹)/(1 + 0.5z⁻¹)
  3. C(1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)
정답과 해설 보기

정답: C. (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)

1샘플의 지연은 z 변환에서는 z⁻¹을 곱하는 것에 해당하므로, 양변을 z 변환하면 Y(z) = X(z) + 0.5z⁻¹X(z) + 0.25z⁻¹Y(z)입니다. Y(z)의 항을 좌변으로 모으면 (1 − 0.25z⁻¹)Y(z) = (1 + 0.5z⁻¹)X(z)가 되어 H(z) = (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)입니다. 분자는 입력 쪽, 분모는 출력의 귀환 쪽 계수를 나타내며, 분모를 0으로 만드는 z = 0.25가 극점, 분자를 0으로 만드는 z = −0.5가 영점입니다.

차분 방정식(Difference Equation)이(가) 나오는 문제 (2)

  1. 차분 방정식 y[n] = x[n] + 0.5y[n − 1]로 표현되는 시스템에 n = 0부터 단위 계단(n ≥ 0에서 x[n] = 1)을 입력했다. y[−1] = 0일 때, y[2]로 올바른 것은?
  2. 차분 방정식 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1]로 표현되는 시스템의 전달 함수 H(z) = Y(z)/X(z)로 올바른 것은?
