ARP(주소 결정 프로토콜)란?

Address Resolution Protocol의 약자. IP 주소로부터 같은 네트워크에 있는 기기의 MAC 주소를 알아내는 프로토콜. 요청을 브로드캐스트로 보내고, 해당하는 기기가 응답한다.

일본어 명칭: ARP

ARP(주소 결정 프로토콜)은(는) 네트워크 기초 등 1개 분야의 연습 문제 2개에 나와요.

ARP의 역할로 올바른 것은?

  1. AIP 주소를 바탕으로 같은 네트워크에 있는 기기의 MAC 주소를 알아낸다
  2. B도메인 이름을 바탕으로 서버의 IP 주소를 알아낸다
  3. C네트워크에 연결한 단말에 IP 주소를 자동으로 할당한다
정답과 해설 보기

정답: A. IP 주소를 바탕으로 같은 네트워크에 있는 기기의 MAC 주소를 알아낸다

ARP(Address Resolution Protocol)에서는 송신하려는 단말이 '이 IP 주소를 가진 기기는 MAC 주소를 알려 주세요'라는 요청을 브로드캐스트로 보내고, 해당하는 기기만 자신의 MAC 주소를 유니캐스트로 돌려줍니다. 얻은 대응은 ARP 캐시에 일정 시간 저장되어 재사용됩니다. 이더넷에서는 프레임을 MAC 주소로 전달하므로 IP 패킷을 보내기 전에 이 대응이 필요합니다. 도메인 이름으로 IP 주소를 알아내는 것은 DNS, IP 주소의 자동 할당은 DHCP의 역할입니다. IPv6에서는 ARP 대신 ICMPv6의 이웃 탐색(NDP)을 사용합니다.

단말(192.168.1.10/24, 기본 게이트웨이 192.168.1.1)이 다른 네트워크에 있는 서버 203.0.113.80으로 패킷을 보낸다. ARP 캐시가 비어 있을 때, 단말이 ARP로 MAC 주소를 알아내는 상대는?

  1. A기본 게이트웨이 192.168.1.1
  2. B서버 203.0.113.80
  3. C서버까지의 경로상에 있는 모든 라우터
정답과 해설 보기

정답: A. 기본 게이트웨이 192.168.1.1

단말은 먼저 자신의 IP 주소와 서브넷 마스크로 목적지가 같은 네트워크에 있는지를 판단합니다. 203.0.113.80은 192.168.1.0/24 밖이므로 패킷은 기본 게이트웨이(라우터)에 넘깁니다. 이때 IP 헤더의 목적지는 서버의 203.0.113.80 그대로이고, 프레임의 목적지 MAC 주소만 게이트웨이의 것으로 합니다. 그래서 ARP로 알아내는 것은 192.168.1.1의 MAC 주소입니다. ARP 브로드캐스트는 라우터를 넘지 않으므로 다른 네트워크에 있는 서버의 MAC 주소는 알아낼 수 없고, 알 필요도 없습니다. 경로상의 각 라우터가 다음 기기로 보낼 때마다 각자 상대의 MAC 주소를 알아냅니다.
