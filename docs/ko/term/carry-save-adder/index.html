캐리 세이브 가산기(carry-save adder)란?

세 수를 캐리를 전파하지 않고 합과 캐리 두 수로 줄이는 가산기입니다. 비트마다 독립된 전가산기로 구성되어 지연이 일정하므로, 곱셈기가 많은 부분곱을 더할 때 사용합니다.

일본어 명칭: 桁上げ保存加算器

캐리 세이브 가산기(carry-save adder)은(는) 컴퓨터 산술 등 1개 분야의 연습 문제 2개에 나와요.

분야: 컴퓨터 산술

도전해 보기: 캐리 세이브 가산기(carry-save adder) 관련 문제

승산기에서 다수의 부분곱을 더하는 데 캐리 세이브 가산기가 사용되는 주된 이유는 무엇입니까?

  1. A캐리 세이브 가산기는 부분곱의 수를 처음부터 하나로 줄일 수 있기 때문
  2. B캐리 세이브 가산기는 곱셈을 덧셈 없이 수행할 수 있기 때문
  3. C올림을 전달하지 않고 3개를 2개로 합치며 지연이 일정하기 때문
정답과 해설 보기

정답: C. 올림을 전달하지 않고 3개를 2개로 합치며 지연이 일정하기 때문

일반 가산기로 부분곱을 하나씩 더해 가면 그때마다 올림이 하위에서 상위로 전달되기를 기다려야 합니다. 캐리 세이브 가산기는 전가산기를 자리별로 독립적으로 늘어놓은 것으로, 3개의 수를 「각 자리의 합」과 「각 자리의 올림」이라는 2개의 수로 합치기만 하므로 올림의 전달을 기다리지 않고 지연은 전가산기 1단분으로 일정합니다. 이를 겹쳐 부분곱을 2개까지 줄이고, 마지막에 한 번만 캐리 룩어헤드 가산기 등으로 더합니다. 부분곱을 단번에 하나로 만들 수는 없습니다.

해설 속 캐리 세이브 가산기(carry-save adder)

  • 캐리 세이브 가산기는 전가산기를 자리별로 독립적으로 늘어놓은 것으로, 3개의 수를 「각 자리의 합」과 「각 자리의 올림」이라는 2개의 수로 합치기만 하므로 올림의 전달을 기다리지 않고 지연은 전가산기 1단분으로 일정합니다.

    승산기에서 다수의 부분곱을 더하는 데 캐리 세이브 가산기가 사용되는 주된 이유는 무엇입니까?

  • 월리스 트리는 캐리 세이브 가산기로 3개를 2개로 합치는 처리를 각 단에서 병렬로 수행하여 부분곱의 수를 대략 3분의 2씩 줄여 갑니다.

    고속 승산기에서 사용되는 월리스 트리의 특징으로 올바른 것은 무엇입니까?

  2. 고속 승산기에서 사용되는 월리스 트리의 특징으로 올바른 것은 무엇입니까?
