정보 누락(Absorption)란?

절댓값이 크게 다른 두 수를 더할 때 작은 쪽 수의 하위 자릿수가 가수에 다 들어가지 못하고 소실되는 현상. 작은 값을 대량으로 더하는 경우에 문제가 된다.

일본어 명칭: 情報落ち

정보 누락(Absorption)은(는) 컴퓨터 산술 등 1개 분야의 연습 문제 4개에 나와요.

분야: 컴퓨터 산술

도전해 보기: 정보 누락(Absorption) 관련 문제

거의 같은 두 부동소수점수를 뺄셈했을 때 유효한 자릿수가 크게 줄어드는 현상을 무엇이라 합니까?

  1. A정보 누락(정보 손실)
  2. B오버플로
  3. C유효숫자 상실(자리 상쇄)
정답과 해설 보기

정답: C. 유효숫자 상실(자리 상쇄)

예를 들어 유효숫자 7자리로 1.234567 − 1.234566 = 0.000001을 계산하면 상위 6자리가 서로 상쇄되어 결과의 유효한 자릿수는 1자리밖에 남지 않습니다. 원래 수에 포함되어 있던 미세한 반올림 오차가 결과에 대해서는 상대적으로 매우 커집니다. 이것이 자리 상쇄(유효숫자 상실)이며, 식을 변형해 가까운 수끼리의 뺄셈을 피하는 것이 대책입니다. 정보 누락은 크기가 다른 수의 덧셈에서 작은 쪽의 자릿수가 사라지는 별개의 현상입니다.

단정밀도 부동소수점수에서 1억(10⁸)에 1을 더해도 결과가 1억 그대로입니다. 이 현상의 설명으로 올바른 것은 무엇입니까?

  1. A1억은 단정밀도로 나타낼 수 없으므로 결과가 NaN이 되어 있다
  2. B유효 자릿수가 약 7자리밖에 없어 1이 반올림으로 사라지기 때문
  3. C덧셈 명령이 큰 수의 계산을 생략하도록 정해져 있다
정답과 해설 보기

정답: B. 유효 자릿수가 약 7자리밖에 없어 1이 반올림으로 사라지기 때문

단정밀도는 유효숫자가 약 7자리이며, 1억 부근에서는 표현 가능한 수의 간격이 8입니다. 1억 + 1은 표현 가능한 두 값 사이에 들어가므로 가장 가까운 1억으로 반올림되어 1이 사라집니다. 이처럼 크기가 다른 수를 더하면 작은 쪽의 정보가 사라지는 현상을 정보 누락(정보 손실)이라 합니다. 작은 값을 대량으로 더할 때는 작은 것부터 먼저 더하거나 보정이 있는 덧셈을 사용하는 등의 방법을 씁니다. 1억은 표현 가능한 수이며 NaN이 되지 않습니다.

정보 누락(Absorption)이(가) 나오는 문제 (4)

  1. 거의 같은 두 부동소수점수를 뺄셈했을 때 유효한 자릿수가 크게 줄어드는 현상을 무엇이라 합니까?
  2. 단정밀도 부동소수점수에서 1억(10⁸)에 1을 더해도 결과가 1억 그대로입니다. 이 현상의 설명으로 올바른 것은 무엇입니까?
  3. 대량의 부동소수점수를 합산할 때 사용되는 카한 합산(보정 합산)의 목적으로 올바른 것은 무엇입니까?
  4. AI 혼합 정밀도 학습에서 계산의 대부분을 FP16이나 bfloat16으로 수행하면서 가중치의 원래 값(마스터 가중치)을 FP32로 유지해 두는 주된 이유는 무엇입니까?
