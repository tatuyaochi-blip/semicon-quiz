평균 메모리 접근 시간(AMAT)란?

1회 메모리 접근에 걸리는 시간의 평균. 히트 시간 + 미스율 × 미스 페널티로 구하며, 캐시 성능을 비교하는 기본 지표이다.

일본어 명칭: 平均メモリアクセス時間(AMAT)

평균 메모리 접근 시간(AMAT)은(는) 메모리 계층 구조 등 1개 분야의 연습 문제 4개에 나와요.

분야: 메모리 계층 구조

도전해 보기: 평균 메모리 접근 시간(AMAT) 관련 문제

L1 캐시의 히트 시간이 1 ns, 미스율이 5%, L2 캐시의 히트 시간이 10 ns, L2의 로컬 미스율이 20%, 주기억장치의 접근 시간이 100 ns일 때, 평균 메모리 접근 시간은 얼마인가?

  1. A2.0 ns
  2. B2.5 ns
  3. C6.0 ns
정답과 해설 보기

정답: B. 2.5 ns

L1의 미스 페널티는 L2의 평균 접근 시간 10 + 0.2 × 100 = 30 ns입니다. 따라서 평균 메모리 접근 시간은 1 + 0.05 × 30 = 1 + 1.5 = 2.5 ns가 됩니다. 2.0 ns는 L2 히트 시간 10 ns를 더하는 것을 잊고 1 + 0.05 × (0.2 × 100)으로 계산한 값입니다. 6.0 ns는 주기억장치의 100 ns에 L1 미스율을 직접 곱해 더한 값으로, L2의 효과를 무시한 것입니다.

캐시의 히트 시간이 2사이클, 미스율이 4%, 미스 페널티가 150사이클일 때, 평균 메모리 접근 시간은 몇 사이클인가?

  1. A8사이클
  2. B6사이클
  3. C152사이클
정답과 해설 보기

정답: A. 8사이클

평균 메모리 접근 시간 = 히트 시간 + 미스율 × 미스 페널티 = 2 + 0.04 × 150 = 2 + 6 = 8사이클입니다. 히트 시간은 모든 접근에서 소요되고, 미스했을 때만 미스 페널티가 더해진다고 생각합니다. 6사이클은 미스 분량만 계산하고 히트 시간을 더하는 것을 잊은 값입니다. 152사이클은 미스한 접근 1회에 걸리는 시간이며 평균이 아닙니다. 미스율이 겨우 4%여도 평균이 4배가 된다는 것을 알 수 있습니다.

평균 메모리 접근 시간(AMAT)이(가) 나오는 문제 (4)

  1. L1 캐시의 히트 시간이 1 ns, 미스율이 5%, L2 캐시의 히트 시간이 10 ns, L2의 로컬 미스율이 20%, 주기억장치의 접근 시간이 100 ns일 때, 평균 메모리 접근 시간은 얼마인가?
  2. 캐시의 히트 시간이 2사이클, 미스율이 4%, 미스 페널티가 150사이클일 때, 평균 메모리 접근 시간은 몇 사이클인가?
  3. 캐시 성능을 평가할 때 미스율뿐 아니라 평균 메모리 접근 시간으로 비교해야 하는 이유로 올바른 것은?
  4. 캐시 히트율이 95%일 때, 미스율은 얼마인가?
