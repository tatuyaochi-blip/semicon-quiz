전달 함수(Transfer Function)란?

선형 시불변 시스템의 입력과 출력의 관계를, 초기값을 모두 0으로 했을 때 출력과 입력의 라플라스 변환의 비 G(s) = Y(s)/X(s)로 나타낸 것. 시스템의 임펄스 응답의 라플라스 변환과 같다. 분모를 0으로 만드는 s를 극점, 분자를 0으로 만드는 s를 영점이라 부르며, 극점의 위치로 안정성이나 응답 속도를 알 수 있다. s = jω로 두면 주파수 응답을 얻는다. 이산 시간 시스템에서는 z 변환을 써서 H(z)로 나타낸다.

일본어 명칭: 伝達関数

전달 함수(Transfer Function)은(는) 제어 공학의 기초, 디지털 신호 처리의 기초 등 2개 분야의 연습 문제 23개에 나와요.

분야: 제어 공학의 기초

블록 선도에서의 계산

전달 함수를 쓰면 요소의 직렬 연결은 곱셈, 병렬 연결은 덧셈으로 나타낼 수 있습니다. 부귀환 루프에서는 전향 전달 함수를 G(s), 피드백 전달 함수를 H(s)라고 하면 폐루프 전달 함수는 G(s)/(1 + G(s)H(s))가 됩니다. 곱 G(s)H(s)는 루프 전달 함수(개루프 전달 함수)라고 불리며, 안정성이나 안정 여유를 조사할 때의 출발점이 됩니다.

대표적인 형태

RC 회로의 로우패스 필터는 1/(1 + sRC)라는 1차 지연계이고, RLC 회로나 모터 위치 제어 루프는 2차 지연계로 나타내는 경우가 많습니다. 적분은 1/s, 미분은 s, 시간 L의 부동작 시간은 e^(−Ls)입니다. 분모의 차수가 분자의 차수 이상인 전달 함수를 프로퍼(proper)라고 부르며, 실제 물리적 시스템은 보통 이 형태가 됩니다.

극점과 영점이 알려 주는 것

극점 p는 응답에 e^(pt) 성분을 만들므로, 모든 극점의 실수부가 음이면 시스템은 안정합니다. 극점이 허수축에 가까울수록 응답은 천천히 감쇠하고, 허수부가 클수록 빠르게 진동합니다. 영점은 응답의 형태를 바꾸며, s 평면의 오른쪽 절반에 영점을 가진 시스템에서는 계단 응답이 처음에 반대 방향으로 움직이는 역응답이 나타날 수 있어 빠른 제어가 어려워집니다.

도전해 보기: 전달 함수(Transfer Function) 관련 문제

이산 시간 LTI 시스템의 전달 함수 H(z)에서 주파수 응답을 구할 때, z를 움직이는 곳으로 올바른 것은?

  1. Az 평면의 단위원 위(z = e^(jω), |z| = 1)
  2. Bz 평면의 양의 실수축 위(z = r, r은 0보다 큰 실수)
  3. Cz 평면의 허수축 위(z = jω)
정답과 해설 보기

정답: A. z 평면의 단위원 위(z = e^(jω), |z| = 1)

주파수 응답은 H(z)에 z = e^(jω)를 대입한 것으로, ω를 −π부터 π까지 움직이면 z는 단위원을 한 바퀴 돕니다. z = 1(ω = 0)이 직류, z = −1(ω = π)이 나이퀴스트 주파수에 해당합니다. 연속 시간의 라플라스 변환에서는 허수축 s = jω 위에서 주파수 응답을 구하지만, 이산 시간에서는 그것이 단위원에 대응합니다.

차분 방정식 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1]로 표현되는 시스템의 전달 함수 H(z) = Y(z)/X(z)로 올바른 것은?

  1. A(1 + 0.5z⁻¹)/(1 + 0.25z⁻¹)
  2. B(1 − 0.25z⁻¹)/(1 + 0.5z⁻¹)
  3. C(1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)
정답과 해설 보기

정답: C. (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)

1샘플의 지연은 z 변환에서는 z⁻¹을 곱하는 것에 해당하므로, 양변을 z 변환하면 Y(z) = X(z) + 0.5z⁻¹X(z) + 0.25z⁻¹Y(z)입니다. Y(z)의 항을 좌변으로 모으면 (1 − 0.25z⁻¹)Y(z) = (1 + 0.5z⁻¹)X(z)가 되어 H(z) = (1 + 0.5z⁻¹)/(1 − 0.25z⁻¹)입니다. 분자는 입력 쪽, 분모는 출력의 귀환 쪽 계수를 나타내며, 분모를 0으로 만드는 z = 0.25가 극점, 분자를 0으로 만드는 z = −0.5가 영점입니다.

자주 묻는 질문

전달 함수와 주파수 응답의 차이는 무엇인가요?

전달 함수 G(s)는 복소수 s의 함수이며, s를 허수축 위의 jω로 한정한 것이 주파수 응답 G(jω)입니다. 주파수 응답의 크기와 위상을 주파수에 대해 그린 것이 보드 선도입니다.

비선형 시스템에도 전달 함수가 있나요?

그대로는 정의할 수 없습니다. 동작점 근처에서 선형화하면 그 근처의 작은 변화에 대해 전달 함수를 쓸 수 있습니다. 포화나 불감대 같은 강한 비선형성은 다른 방법으로 다룹니다.

해설 속 전달 함수(Transfer Function)

  • 분모의 G(s)H(s)는 신호가 루프를 한 바퀴 돌 때의 전달 함수로, 루프 전달 함수(개루프 전달 함수)라고 부릅니다.

    전향 경로의 전달 함수가 G(s), 피드백 경로의 전달 함수가 H(s)인 부귀환 블록 선도가 있다. 목표값…

  • 전달 함수는 초기값을 모두 0으로 했을 때 출력과 입력의 라플라스 변환의 비입니다.

    선형 시불변 시스템의 전달 함수 설명으로 올바른 것은?

  • 둘 다 루프 전달 함수가 점 −1(이득 0 dB, 위상 −180°)에 얼마나 가까운지를 나타내는 지표이며, 폐루프가 아니라 루프 전달 함수에서 읽습니다.

    루프 전달 함수의 보드 선도에서 읽어 내는 이득 여유와 위상 여유의 설명으로 올바른 것은?

  • 루프 전달 함수가 ωn²/(s(s + 2ζωn))인 표준적인 시스템에서는 위상 여유 60°에서 오버슈트가 약 9%, 30°에서는 약 42%가 됩니다.

    루프 전달 함수의 이득을 올렸더니 위상 여유가 60°에서 30°로 줄었다. 폐루프 계단 응답의 변화로 올바…

  • 전달 함수는 H(z) = 1 − z⁻¹이며, 직류는 z = 1, 나이퀴스트 주파수는 z = −1에 해당합니다.

    y[n] = x[n] − x[n − 1](하나 앞의 입력과의 차)로 표현되는 필터의, 직류와 나이퀴스트 주…

전달 함수(Transfer Function)이(가) 나오는 문제 (23)

  1. 이산 시간 LTI 시스템의 전달 함수 H(z)에서 주파수 응답을 구할 때, z를 움직이는 곳으로 올바른 것은?
  2. 차분 방정식 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1]로 표현되는 시스템의 전달 함수 H(z) = Y(z)/X(z)로 올바른 것은?
  3. 전달 함수 H(z) = 1/(1 − 1.3z⁻¹ + 0.4z⁻²)로 표현되는 인과적인 시스템의 극점과 안정성의 조합으로 올바른 것은?
  4. 샘플링 주파수 8 kHz로 동작하는, 전달 함수 H(z) = 1 + z⁻²(y[n] = x[n] + x[n − 2])인 FIR 필터가 있다. 출력이 0이 되는 사인파 입력의 주파수로 올바른 것은?
  5. 아날로그 필터의 전달 함수 H(s)로부터 디지털 필터를 설계할 때 사용하는 쌍선형 변환의 설명으로 올바른 것은?
  6. 전향 경로의 전달 함수가 G(s), 피드백 경로의 전달 함수가 H(s)인 부귀환 블록 선도가 있다. 목표값 R(s)에서 출력 Y(s)까지의 폐루프 전달 함수 Y(s)/R(s)로 올바른 것은?
  7. 전달 함수 G(s) = 5/(s + 2)인 시스템에 크기 1의 계단 입력을 가했다. 출력의 최종값(t → ∞에서의 값)으로 올바른 것은?
  8. 선형 시불변 시스템의 전달 함수 설명으로 올바른 것은?
  9. 전달 함수 G(s) = 2/(1 + 0.5s)인 1차 지연계에 시각 0에서 크기 1의 계단 입력을 가했다. t = 1 s에서의 출력에 가장 가까운 것은?
  10. 어떤 1차 지연계에 크기 2의 계단 입력을 가했더니, 출력은 최종적으로 6에 수렴하고 입력으로부터 0.4 s 후에 최종값의 약 63%에 도달했다. 이 시스템의 전달 함수로 올바른 것은?
  11. 전달 함수 G(s) = 25/(s² + 4s + 25)인 2차 지연계의 고유 각주파수 ωn과 감쇠비 ζ의 조합으로 올바른 것은?
  12. 전달 함수 G(s) = 25/(s² + 4s + 25)인 시스템의 계단 응답이 최종값의 ±2% 이내에 들어올 때까지의 정정 시간을 근사식 ts ≈ 4/(ζωn)으로 어림한 값으로 올바른 것은?
  13. 단위 피드백 시스템에서 전향 전달 함수가 G(s) = 9/(1 + 2s)이다. 크기 1의 계단 목표값에 대한 정상 편차로 올바른 것은?
  14. 폐루프가 안정한 단위 피드백 시스템에서 전향 전달 함수 G(s)가 적분 1/s를 1개 포함할(1형 시스템일) 때, 정상 편차의 설명으로 올바른 것은?
  15. 루프 전달 함수가 K/(s(s + 1)(s + 2))인 단위 피드백 시스템이 있다. 폐루프 시스템이 안정해지는 K의 범위로 올바른 것은?
