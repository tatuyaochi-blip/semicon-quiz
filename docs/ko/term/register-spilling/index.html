스필(Spill)란?

레지스터 할당에서 동시에 쓰는 값이 레지스터 수보다 많을 때 일부 값을 메모리(스택)로 대피시키는 것. 대피·복원 명령이 늘어 느려진다.

일본어 명칭: スピル

스필(Spill)은(는) 컴파일러, GPU 프로그래밍 등 2개 분야의 연습 문제 4개에 나와요.

분야: 컴파일러

도전해 보기: 스필(Spill) 관련 문제

레지스터 할당에서 「스필」이 일어나면 생성되는 코드는 어떻게 되는가?

  1. A값을 스택에 내보내고 다시 읽어 들이는 명령이 늘어 느려지기 쉽다
  2. B레지스터의 수가 자동으로 늘어나 모든 값을 레지스터에 둘 수 있게 된다
  3. C사용되지 않는 값이 삭제되어 명령의 수가 줄어든다
정답과 해설 보기

정답: A. 값을 스택에 내보내고 다시 읽어 들이는 명령이 늘어 느려지기 쉽다

스필은 동시에 살아 있는 값이 레지스터 수보다 많을 때 일부 값을 메모리(스택)에 두는 것입니다. 그 값을 사용할 때마다 읽기 명령, 바꿀 때마다 쓰기 명령이 필요해 명령이 늘고 메모리 접근만큼 느려지기 쉽습니다. 그래서 컴파일러는 루프 안 등 자주 사용되는 값을 레지스터에 남기고, 별로 사용되지 않는 값을 골라 스필시킵니다. 레지스터의 수는 CPU로 정해져 있어 늘어나지 않으며, 불필요한 값의 삭제와도 다른 이야기입니다.

어떤 함수 안에서 동시에 살아 있는 값의 수가 가장 많은 곳에서 5개였다. 간섭 그래프가 이 5개 이외의 제약을 만들지 않는 단순한 경우, 모든 값을 스필 없이 레지스터에 두려면 레지스터가 최소 몇 개 필요한가?

  1. A5개
  2. B4개
  3. C10개
정답과 해설 보기

정답: A. 5개

동시에 살아 있는 5개의 값은 서로 모두 간섭하므로, 간섭 그래프 안에서 5개의 노드가 모두 간선으로 연결된 형태(완전 그래프)가 되어 칠하는 데 최소 5색이 필요합니다. 직선적인 코드처럼 생존 구간을 구간으로 나타낼 수 있는 단순한 경우에는 동시에 살아 있는 값의 최대 개수만큼의 색으로 칠할 수 있으므로 5개의 레지스터로 충분합니다. 4개로는 어딘가에서 하나의 값을 메모리로 내보내는 스필이 필요해집니다. 10개는 필요 이상으로 많은 수입니다.

스필(Spill)이(가) 나오는 문제 (4)

  1. 레지스터 할당에서 「스필」이 일어나면 생성되는 코드는 어떻게 되는가?
  2. 어떤 함수 안에서 동시에 살아 있는 값의 수가 가장 많은 곳에서 5개였다. 간섭 그래프가 이 5개 이외의 제약을 만들지 않는 단순한 경우, 모든 값을 스필 없이 레지스터에 두려면 레지스터가 최소 몇 개 필요한가?
  3. 컴파일러의 레지스터 할당에서 간섭 그래프를 색칠하는(채색하는) 방법을 사용할 때, 그래프의 노드와 간선이 나타내는 것의 조합으로 올바른 것은?
  4. GPU 커널에서 스레드당 레지스터 사용량이 너무 많을 때 일어날 수 있는 일로 올바른 것은?
