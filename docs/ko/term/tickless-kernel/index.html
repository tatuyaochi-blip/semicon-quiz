틱리스 커널(tickless kernel)란?

할 일이 없는 CPU에서 일정 간격의 타이머 틱 인터럽트를 멈춰 다음 작업까지 오래 쉴 수 있도록 한 OS 커널.

일본어 명칭: ティックレスカーネル

틱리스 커널(tickless kernel)은(는) 전력 관리 등 1개 분야의 연습 문제 1개에 나와요.

Linux 등의 OS에서 사용되는 틱리스(tickless) 커널의 개념으로 올바른 것은?

  1. A시계 표시를 꺼서 화면 전력을 줄인다
  2. B일이 없을 때는 일정 간격으로 발생하는 시간 눈금 인터럽트를 멈추고 다음 일까지 오래 쉴 수 있게 한다
  3. C시간 눈금 인터럽트를 초당 수만 번으로 늘린다
정답과 해설 보기

정답: B. 일이 없을 때는 일정 간격으로 발생하는 시간 눈금 인터럽트를 멈추고 다음 일까지 오래 쉴 수 있게 한다

기존 OS는 예를 들어 초당 100~1000회의 시간 눈금 인터럽트로 프로그램 전환과 시간 관리를 했으며, 할 일이 없을 때도 CPU는 그때마다 깨어났습니다. 틱리스 커널에서는 일이 없는 CPU에서 눈금 인터럽트를 멈추고, 다음에 깨어나야 하는 시각에만 타이머를 설정합니다. 이로써 CPU는 오래 깊게 쉴 수 있게 되어 대기 중 전력이 줄어듭니다.
