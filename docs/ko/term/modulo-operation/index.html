나머지 연산(Modulo Operation)란?

나눗셈의 나머지를 구하는 연산으로, 의사 코드에서는 mod, 많은 언어에서는 %로 쓴다. x mod 10으로 일의 자리, x mod 2로 짝수인지 홀수인지, i mod n + 1로 1~n을 순환하는 번호를 얻을 수 있다. 음수의 나머지 부호는 언어에 따라 다르다.

일본어 명칭: 剰余演算

나머지 연산(Modulo Operation)은(는) 프로그래밍의 기초(의사 코드 트레이스), 암호 기술의 기초와 응용, 자료 구조와 알고리즘 등 4개 분야의 연습 문제 13개에 나와요.

도전해 보기: 나머지 연산(Modulo Operation) 관련 문제

크기 7인 해시 테이블(위치 0~6)에 해시 함수 h(k) = k mod 7로 키 10, 17, 24, 3을 이 순서로 저장한다. 충돌했을 때는 위치를 하나씩 뒤로 옮기며(6 다음은 0) 빈 위치를 찾는 선형 탐사법을 사용한다. 키 3이 저장되는 위치는?

  1. A위치 3
  2. B위치 4
  3. C위치 6
정답과 해설 보기

정답: C. 위치 6

네 키는 모두 7로 나눈 나머지가 3이므로, 전부 위치 3을 처음에 조사합니다. 10은 위치 3에 들어가고, 17은 위치 3이 차 있으므로 위치 4, 24는 위치 3, 4가 차 있으므로 위치 5에 들어갑니다. 3은 위치 3, 4, 5가 차 있으므로 위치 6에 저장됩니다. 이처럼 선형 탐사법에서는 채워진 위치가 뭉쳐서 늘어서고(클러스터), 나중에 오는 키일수록 조사하는 횟수가 늘어납니다.

함수 f(x, y)를 'y가 0이면 x를 반환하고, 그렇지 않으면 f(y, x mod y)를 반환한다'로 정의한다. f(84, 36)을 호출했을 때의 반환값과, f가 호출되는 횟수(첫 호출 포함)의 조합은?

  1. A반환값 12, 호출 횟수 3회
  2. B반환값 12, 호출 횟수 4회
  3. C반환값 6, 호출 횟수 3회
정답과 해설 보기

정답: A. 반환값 12, 호출 횟수 3회

f(84, 36)은 84 mod 36 = 12이므로 f(36, 12)를 호출하고, 36 mod 12 = 0이므로 f(12, 0)을 호출하며, y가 0이므로 12를 반환합니다. 호출은 f(84, 36), f(36, 12), f(12, 0)의 3회이며, 이는 유클리드 호제법에 의한 최대공약수 계산입니다. 이 함수는 재귀 호출의 결과를 그대로 반환하는 꼬리 재귀이므로, 컴파일러가 꼬리 호출 최적화를 수행하면 루프로 변환할 수 있어, 호출이 깊어져도 스택을 계속 소비하지 않습니다.

  1. 크기 7인 해시 테이블(위치 0~6)에 해시 함수 h(k) = k mod 7로 키 10, 17, 24, 3을 이 순서로 저장한다. 충돌했을 때는 위치를 하나씩 뒤로 옮기며(6 다음은 0) 빈 위치를 찾는 선형 탐사법을 사용한다. 키 3이 저장되는 위치는?
  2. 함수 f(x, y)를 'y가 0이면 x를 반환하고, 그렇지 않으면 f(y, x mod y)를 반환한다'로 정의한다. f(84, 36)을 호출했을 때의 반환값과, f가 호출되는 횟수(첫 호출 포함)의 조합은?
  3. 요소 수 4인 문자열형 배열 q를 원형으로 사용하는 큐가 있다. head와 tail의 초기값은 1이며, enq(v)는 q[tail] ← v 다음에 tail ← tail mod 4 + 1을 수행하고, deq()는 q[head]의 값을 반환한 다음에 head ← head mod 4 + 1을 수행한다. 다음 프로그램을 실행했을 때 "E"가 저장되는 q의 요소는?
  4. RSA 암호의 구조를 작은 수로 확인한다. 소수 p = 5, q = 11로부터 n = pq를 만들고, 공개 지수를 e = 3으로 한다. φ(n) = (p − 1)(q − 1)이라 할 때, e × d ≡ 1 (mod φ(n))을 만족하는 비밀 지수 d(0 < d < φ(n))는?
  5. RSA 암호에서 공개 키를 n = 55, e = 3으로 한다. 평문 m = 7을 c = m^e mod n으로 암호화했을 때의 암호문 c는?
  6. 교과서 그대로의 RSA 암호(평문 m을 그대로 c = m^e mod n으로 하는 방식)를 패딩을 붙이지 않고 실제 통신에 사용하는 것의 문제점으로 올바른 것은?
  7. 디피-헬먼 키 교환에서는 소수 p와 생성원 g를 공개하고, A 씨와 B 씨가 각각 비밀 값 a, b를 골라 g^a mod p와 g^b mod p를 서로 보낸다. 도청자가 이렇게 공개된 값을 모두 보더라도 공유 비밀 g^(ab) mod p를 구할 수 없다고 생각되는 이유로 올바른 것은?
  8. 디피-헬먼 키 교환을 작은 수로 확인한다. p = 23, g = 5로 하고, A 씨는 비밀 값 a = 6, B 씨는 비밀 값 b = 15를 고른다. A 씨는 A = g^a mod p를, B 씨는 B = g^b mod p를 서로 보낸다. 두 사람이 얻는 공유 비밀은?
