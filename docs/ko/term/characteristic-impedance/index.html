특성 임피던스(characteristic impedance)란?

전송선로를 따라 진행하는 파동이 보는 전압과 전류의 비로, 배선 폭과 층 간격으로 정해집니다. 경로 중에 값이 변하면 반사가 생깁니다.

일본어 명칭: 特性インピーダンス

특성 임피던스(characteristic impedance)은(는) I/O 인터페이스와 버스, 테스트와 검사 등 2개 분야의 연습 문제 2개에 나와요.

정답: C. 임피던스가 불연속인 곳에서 신호가 반사되어 파형이 흐트러지는 것을 막기 위해

빠른 신호에서 배선은 전기 파동이 진행하는 전송로로 동작합니다. 도중에 특성 임피던스가 바뀌는 곳(커넥터, 비아, 종단 저항의 차이 등)이 있으면 신호의 일부가 반사되어 돌아와 뒤 비트에 겹치며 파형을 흐트러뜨립니다. 그래서 배선의 폭이나 층 간격을 조정하여, 예를 들어 차동 배선을 100 Ω 등으로 만들고 종단도 같은 값에 맞춥니다.

해설 속 특성 임피던스(characteristic impedance)

  • 도중에 특성 임피던스가 바뀌는 곳(커넥터, 비아, 종단 저항의 차이 등)이 있으면 신호의 일부가 반사되어 돌아와 뒤 비트에 겹치며 파형을 흐트러뜨립니다.

    고속 신호 배선에서 배선의 특성 임피던스를 송수신 회로와 맞추는(정합을 취하는) 목적으로 올바른 것은 무엇…

  • 고속 신호에서는 배선의 길이나 특성 임피던스도 맞춰야 하며, 품종마다 설계·제작합니다.

    테스터의 테스트 헤드에 장착하여 IC의 소켓과 주변 부품을 싣고, 품종별로 신호를 IC로 끌어 주는 인쇄 …

특성 임피던스(characteristic impedance)이(가) 나오는 문제 (2)

  1. 고속 신호 배선에서 배선의 특성 임피던스를 송수신 회로와 맞추는(정합을 취하는) 목적으로 올바른 것은 무엇입니까?
  2. 테스터의 테스트 헤드에 장착하여 IC의 소켓과 주변 부품을 싣고, 품종별로 신호를 IC로 끌어 주는 인쇄 회로 기판을 무엇이라고 부릅니까?
