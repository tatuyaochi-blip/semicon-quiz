inode(아이노드)란?

Linux 등의 파일 시스템에서 하나의 파일에 대해 크기, 소유자, 퍼미션, 갱신 시각, 내용이 놓인 디스크상의 위치 등을 기록한 관리 정보. 파일 시스템 안에서 번호(inode 번호)로 구별되며, ls -i나 stat으로 확인할 수 있다. 파일 이름은 inode에 포함되지 않으며, 디렉터리가 '이름과 inode 번호의 대응'을 가지고 있다. 그래서 하나의 inode에 여러 이름(하드 링크)을 붙일 수 있다. 파일 시스템을 만들 때 inode의 수가 정해지는 방식에서는 작은 파일이 매우 많으면 용량에 여유가 있어도 inode를 다 써 버려 새 파일을 만들 수 없게 되는 경우가 있으며, df -i로 사용 상황을 확인한다.
