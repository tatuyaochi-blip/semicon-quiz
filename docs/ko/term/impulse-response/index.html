임펄스 응답(Impulse Response)란?

시스템에 단위 임펄스 δ[n](n = 0에서만 1이고 나머지는 0)을 입력했을 때의 출력 h[n]. 선형 시불변(LTI) 시스템에서는 임의의 입력에 대한 출력이 입력과 h[n]의 합성곱 y[n] = Σx[k]h[n − k]로 구해지므로, h[n]이 시스템의 성질을 모두 나타낸다. h[n]이 유한한 길이로 끝나는 것을 FIR 필터, 무한히 계속되는 것을 IIR 필터라고 한다. Σ|h[n]|이 유한한 것이 BIBO 안정의 조건이며, h[n]의 z 변환이 전달 함수 H(z)가 된다.

일본어 명칭: インパルス応答

임펄스 응답(Impulse Response)은(는) 디지털 신호 처리의 기초 등 1개 분야의 연습 문제 5개에 나와요.

도전해 보기: 임펄스 응답(Impulse Response) 관련 문제

u[n]을 단위 계단이라 한다. 임펄스 응답이 다음과 같이 표현되는 LTI 시스템 중에서 BIBO 안정(유계 입력에 대해 출력이 반드시 유계)인 것은?

  1. Ah[n] = (−0.9)ⁿu[n]
  2. Bh[n] = u[n]
  3. Ch[n] = (1.1)ⁿu[n]
정답과 해설 보기

정답: A. h[n] = (−0.9)ⁿu[n]

LTI 시스템이 BIBO 안정일 필요충분조건은 임펄스 응답의 절댓값의 총합 Σ|h[n]|이 유한한 것입니다. h[n] = (−0.9)ⁿu[n]에서는 Σ|h[n]| = Σ0.9ⁿ = 1/(1 − 0.9) = 10으로 유한하므로 안정합니다. h[n] = u[n]은 입력을 계속 더하는 누산기로, 총합이 무한대가 되어 일정한 입력에 대해 출력이 한없이 커집니다. (1.1)ⁿ은 시간이 지남에 따라 커지므로 불안정합니다.

x[n] = {1, 2, 3}(n = 0, 1, 2)을 임펄스 응답 h[n] = {1, −1}(n = 0, 1)인 LTI 시스템에 입력했다. 출력 y[0]~y[3]으로 올바른 것은?

  1. A−1, −1, −1, 3
  2. B1, 3, 5, 3
  3. C1, 1, 1, −3
정답과 해설 보기

정답: C. 1, 1, 1, −3

합성곱 y[n] = Σx[k]h[n − k]는 h[n] = {1, −1}인 경우 y[n] = x[n] − x[n − 1](하나 앞의 입력과의 차)이 됩니다. y[0] = 1 − 0 = 1, y[1] = 2 − 1 = 1, y[2] = 3 − 2 = 1, y[3] = 0 − 3 = −3입니다. 출력의 길이는 입력의 길이 3과 임펄스 응답의 길이 2로부터 3 + 2 − 1 = 4가 됩니다.
