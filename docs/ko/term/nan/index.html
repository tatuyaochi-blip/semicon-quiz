NaN란?

Not a Number의 약어로, 0 ÷ 0이나 음수의 제곱근처럼 결과가 수로 정해지지 않는 연산에서 생기는 부동소수점 특수값. 지수부가 모두 1이고 가수가 0이 아닌 값으로 나타내며, NaN끼리 비교해도 같지 않다.

일본어 명칭: NaN

NaN은(는) 컴퓨터 산술 등 1개 분야의 연습 문제 6개에 나와요.

분야: 컴퓨터 산술

NaN의 인코딩

IEEE 754 이진 형식에서 지수 필드가 모두 1인 경우는 특수 값용으로 예약되어 있습니다. 가수가 0이면 무한대, 0이 아닌 가수는 모두 NaN을 뜻합니다. NaN에서 부호 비트는 의미가 없습니다. NaN에는 두 종류가 있습니다. quiet NaN은 산술 연산을 조용히 통과하고, signaling NaN은 사용될 때 무효 연산 예외를 일으킵니다. 2008년 개정판이 권고하고 일반 프로세서가 사용하는 인코딩에서는 가수 최상위 비트가 1이면 quiet NaN이며, 나머지 비트는 진단 정보를 담을 수 있는 페이로드가 됩니다.

NaN을 만드는 연산

NaN은 의미 있는 수치 결과가 없는 무효 연산의 기본 결과입니다. 0 ÷ 0, ∞ − ∞, 0 × ∞, ∞ ÷ ∞, 음수의 제곱근 등이 해당하며, 이들은 무효 연산 상태 플래그도 설정합니다. 0이 아닌 수를 0으로 나누는 것은 다릅니다. 부호가 있는 무한대를 반환하고 0으로 나누기 플래그를 설정합니다. 일단 생성된 NaN은 전파되므로 NaN이 포함된 거의 모든 연산이 NaN을 반환하며, 덕분에 계산을 끝까지 마친 뒤 마지막에 문제를 검출할 수 있습니다.

비교와 그 함정

NaN은 자기 자신을 포함한 어떤 값과도 순서가 없습니다(unordered). NaN 피연산자가 들어간 <, <=, == 같은 순서 비교는 모두 거짓이고 !=는 참이며, 그래서 x != x가 고전적인 NaN 판별법입니다. 이 때문에 NaN 하나가 일관된 순서를 가정하는 정렬 루틴이나 탐색을 망가뜨릴 수 있습니다. 공격적인 컴파일러 최적화 옵션은 NaN이 절대 나오지 않는다고 가정하고 x != x 검사를 제거할 수 있으므로, isnan 같은 라이브러리 함수가 더 안전한 판별법입니다. 최솟값·최댓값 함수도 NaN을 반환하는지 다른 피연산자를 반환하는지가 서로 다릅니다.

NaN을 만나게 되는 곳

최대 유한값이 65504인 16비트 부동소수점을 쓰는 머신러닝에서는 오버플로가 먼저 무한대를 만들고, 이후 ∞ − ∞나 0 × ∞ 같은 연산이 이를 NaN으로 바꿔 손실과 가중치 전체로 퍼뜨립니다. 손실 스케일링과 오버플로 검사가 이를 막습니다. 수치 계산 코드에서는 무효 연산 예외에 대한 트랩을 켜면 첫 NaN에서 실행이 멈추므로 원인을 찾을 수 있습니다. 정수에는 NaN이 아예 없습니다. 정수를 0으로 나누면 특수 값을 만드는 대신 보통 트랩이 걸리거나 정의되지 않은 동작이 됩니다.

정답과 해설 보기

정답: B. 거짓

IEEE 754에서 NaN은 「숫자가 아닌」 값이므로 어떤 값과 비교해도 같아지지 않으며, NaN 자신과의 비교에서도 x == x는 거짓이 됩니다(x != x는 참). 이 성질을 이용해 x != x로 NaN인지 판정하는 방식도 쓰이지만, 보통은 전용 함수(isnan 등)를 사용합니다. NaN은 0 ÷ 0이나 ∞ − ∞ 등에서 생기며, 이후의 계산에도 퍼져 나갑니다. 비교에서 예외가 발생해 멈추는 것은 기본 동작이 아닙니다.

자주 묻는 질문

NaN은 왜 자기 자신과 같지 않나요?

IEEE 754는 NaN을 특정한 수를 나타내지 않는 unordered 값으로 정의하므로, NaN이 관여하는 모든 등가 비교와 순서 비교는 거짓입니다. 그 결과 x가 NaN이면 x == x는 거짓이고 x != x는 참입니다.

NaN과 무한대의 차이는 무엇인가요?

무한대는 오버플로나 0이 아닌 수를 0으로 나눈 정당한 결과이며 여전히 부호와 순서를 가집니다. NaN은 0 ÷ 0처럼 값이 정의되지 않는 연산의 결과이며 순서를 매길 수 없습니다.

quiet NaN과 signaling NaN의 차이는 무엇인가요?

quiet NaN은 예외를 일으키지 않고 계산을 통해 전파됩니다. signaling NaN은 사용될 때 무효 연산 예외를 일으키므로, 초기화되지 않은 데이터를 잡아내는 데 유용합니다.
