메모리 배리어(Memory Barrier)란?

배리어 이전의 메모리 연산이 이후의 연산보다 먼저 다른 코어에서 보이는 것을 보장하는 명령. 펜스라고도 한다. RISC-V의 fence 등.

일본어 명칭: メモリバリア

메모리 배리어(Memory Barrier)은(는) 멀티코어와 동기화 등 1개 분야의 연습 문제 2개에 나와요.

  2. B메모리를 물리적으로 구분하여 접근을 금지한다
  3. C프로그램 실행을 모든 스레드가 모일 때까지 멈춘다
정답과 해설 보기

정답: A. 배리어 이전의 메모리 연산이 배리어 이후의 연산보다 먼저 다른 코어에서 보이는 것을 보장한다

CPU는 메모리 연산의 순서를 바꾸는 경우가 있으므로, 다른 코어와 정해진 순서로 데이터를 주고받으려면 이를 막는 지시가 필요합니다. 메모리 배리어는 그 이전의 읽기와 쓰기를 모두 끝낸 뒤(다른 코어에 보이게 한 뒤) 이후의 읽기와 쓰기를 수행하게 합니다. 락의 획득과 해제 안에도 배리어의 역할이 포함되어 있어, 락으로 보호한 변수가 올바르게 전달됩니다.

해설 속 메모리 배리어(Memory Barrier)

  • 메모리 배리어는 그 이전의 읽기와 쓰기를 모두 끝낸 뒤(다른 코어에 보이게 한 뒤) 이후의 읽기와 쓰기를 수행하게 합니다.

    메모리 배리어(펜스) 명령의 역할로 올바른 것은 무엇입니까?
