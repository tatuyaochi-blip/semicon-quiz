플로팅 게이트(Floating Gate)란?

플래시 메모리 셀에서 주위가 절연막으로 둘러싸인 전극. 여기에 전자를 저장하면 트랜지스터의 문턱 전압이 바뀌어 전원을 꺼도 데이터가 유지된다.

일본어 명칭: フローティングゲート

플로팅 게이트(Floating Gate)은(는) SRAM과 플래시 메모리, DRAM, 차세대 메모리 등 4개 분야의 연습 문제 9개에 나와요.

도전해 보기: 플로팅 게이트(Floating Gate) 관련 문제

플래시 메모리의 소거에서 플로팅 게이트 등에서 전자를 빼내면 셀의 문턱 전압은 어떻게 됩니까?

  1. A높아진다
  2. B낮아진다
  3. C변하지 않는다
정답과 해설 보기

정답: B. 낮아진다

플로팅 게이트에 전자(음전하)가 있으면 게이트 전압의 일부가 상쇄되어 채널을 만드는 데 더 큰 전압이 필요하므로 문턱 전압이 높아집니다. 소거로 전자를 빼내면 문턱 전압이 낮아지고, 쓰기로 전자를 주입하면 높아집니다. NAND에서는 일반적으로 소거 상태(낮은 문턱)를 '1', 쓰기 상태를 '0'으로 하며, 소거한 플래시의 내용이 0xFF가 되는 것은 이 때문입니다.

해설 속 플로팅 게이트(Floating Gate)

  • 플로팅 게이트에 전자(음전하)가 있으면 게이트 전압의 일부가 상쇄되어 채널을 만드는 데 더 큰 전압이 필요하므로 문턱 전압이 높아집니다.

    플래시 메모리의 소거에서 플로팅 게이트 등에서 전자를 빼내면 셀의 문턱 전압은 어떻게 됩니까?

  • 트랜지스터 6개는 SRAM, 플로팅 게이트 트랜지스터는 플래시 메모리의 셀 구성입니다.

    일반적인 DRAM의 1비트 메모리 셀 구성으로 올바른 것은?

  • 플로팅 게이트와 전하 트랩은 플래시의 구조입니다.

    DRAM 셀에서 커패시터 용량을 확보하기 위해 사용되어 온 입체 구조의 조합으로 올바른 것은?

  • 플래시 셀은 게이트 아래에 전자를 저장하는 플로팅 게이트(또는 전하 트랩층)를 가진 트랜지스터입니다.

    플래시 메모리의 데이터 쓰기·지우기 원리로 올바른 것은 무엇입니까?

  • 전하 트랩형 셀에서는 도전성 플로팅 게이트 대신, 절연체인 실리콘 질화막 속의 포획 준위(트랩)에 전자를 저장합니다.

    3D NAND에서 많이 사용되는 전하 트랩형 셀에서, 전하를 저장하는 층의 재료로 일반적인 것은 무엇입니까?

플로팅 게이트(Floating Gate)이(가) 나오는 문제 (9)

  1. 플래시 메모리의 소거에서 플로팅 게이트 등에서 전자를 빼내면 셀의 문턱 전압은 어떻게 됩니까?
  2. 일반적인 DRAM의 1비트 메모리 셀 구성으로 올바른 것은?
  3. DRAM 셀에서 커패시터 용량을 확보하기 위해 사용되어 온 입체 구조의 조합으로 올바른 것은?
  4. 플래시 메모리의 데이터 쓰기·지우기 원리로 올바른 것은 무엇입니까?
  5. 3D NAND에서 많이 사용되는 전하 트랩형 셀에서, 전하를 저장하는 층의 재료로 일반적인 것은 무엇입니까?
  6. 마이크로컨트롤러의 프로그램을 저장하기 위해 로직 회로와 같은 칩에 혼재되어 온 비휘발성 메모리는 무엇입니까?
  7. 플래시 메모리의 성질로 올바른 것은 무엇입니까?
  8. MRAM이 마이컴 등의 내장 비휘발성 메모리로 주목받는 이유의 하나로 올바른 것은 무엇입니까?
  9. 불순물을 많이 포함한 다결정 실리콘(폴리실리콘)을 열산화했을 때의 특징으로 올바른 것은?
