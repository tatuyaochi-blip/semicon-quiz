VCD란?

Value Change Dump의 약자. 시뮬레이션 중 신호 값의 변화를 기록하는 표준 파일 형식으로, 파형 표시 도구로 보며 디버그에 쓴다.

VCD(Value Change Dump)는 시뮬레이션 중 각 신호의 값이 언제 어떻게 바뀌었는지를 기록하는 표준 파일 형식입니다. 파형 표시 툴로 열면 클럭마다의 신호 변화를 시간축을 따라 볼 수 있으므로, 어디에서 기대와 다른 값이 되었는지 추적할 수 있습니다. 모든 신호를 기록하면 파일이 매우 커지므로 조사하려는 범위나 신호로 한정하기도 합니다.
