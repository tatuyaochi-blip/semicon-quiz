미싱 코드(Missing Code)란?

입력을 변화시켜도 AD 변환기의 특정 출력 코드가 한 번도 나타나지 않는 불량. DNL이 −1 LSB에 이르면 발생한다.

일본어 명칭: ミッシングコード

미싱 코드(Missing Code)은(는) A/D·D/A 변환, 데이터시트 읽는 법 등 2개 분야의 연습 문제 3개에 나와요.

분야: A/D·D/A 변환

코드가 사라지는 원리

ADC는 입력 범위를 전이 전압으로 구분된 코드 빈(bin)으로 나눕니다. 이상적으로는 모든 빈의 폭이 정확히 1 LSB입니다. 미분 비선형성(DNL)은 각 빈의 실제 폭에서 1 LSB를 뺀 값으로, 폭이 1.5 LSB인 빈은 DNL = +0.5 LSB입니다. DNL이 −1 LSB에 이르면 빈의 폭이 0이 되어 두 전이 전압이 일치하고, 어떤 입력 전압으로도 그 코드가 나오지 않습니다. 이것이 미싱 코드입니다. 빈 폭의 합은 전체 범위와 같아야 하므로, 미싱 코드 옆에는 폭이 너무 넓은 코드가 함께 나타나는 경우가 많습니다.

발생 원인

미싱 코드는 보통 0111…1에서 1000…0으로 바뀌는 것처럼 많은 비트가 한꺼번에 바뀌는 주요 캐리 전이에서 나타납니다. SAR(축차 비교형) ADC에서는 내부 용량성 DAC(디지털-아날로그 변환기)가 판정 레벨을 정하는데, 상위 비트의 가중치가 하위 비트 가중치의 합보다 약간 작으면 그 전이 바로 아래의 코드가 사라질 수 있고, 반대로 가중치가 너무 크면 폭이 넓은 코드가 생깁니다. 파이프라인 ADC와 서브레인징 ADC는 단 사이의 비교기 오프셋에 취약하므로, 미싱 코드 없음을 보장하기 위해 리던던시와 디지털 오차 보정을 추가합니다.

테스트와 데이터시트 사양

미싱 코드는 히스토그램 테스트로 찾습니다. 느린 램프나 사인파를 인가하고 많은 샘플을 수집한 뒤 코드별 발생 횟수를 셉니다. 램프를 사용하면 각 코드의 횟수가 그 폭에 비례하고, 사인파를 사용하면 사인파의 진폭 분포에 맞춰 횟수를 보정합니다. 발생 횟수가 0인 코드가 미싱 코드입니다. 데이터시트는 미싱 코드 없음이 보장되는 분해능을 명시합니다. 예를 들어 16비트 출력에 대해 16비트 또는 15비트에서 미싱 코드 없음을 보장하는 식이며, 이는 해당 분해능에서 DNL이 −1 LSB보다 크다는 것을 보장하는 것과 같습니다.

미싱 코드와 INL, DAC 단조성

적분 비선형성(INL)은 전달 곡선이 이상적인 직선에서 벗어난 누적 편차입니다. ADC는 INL이 수 LSB이더라도 모든 코드를 출력할 수 있으므로 INL이 미싱 코드를 직접 결정하지는 않습니다. DAC에서 이에 해당하는 관심사는 단조성으로, DNL이 −1 LSB보다 크게 유지되면 코드가 증가할 때 출력이 감소하지 않습니다. 미싱 코드는 건너뛴 코드가 루프 이득의 갑작스러운 도약처럼 작용해 리밋 사이클을 일으킬 수 있는 제어 루프와, 코드 히스토그램을 만드는 측정 시스템에서 특히 중요합니다.

도전해 보기: 미싱 코드(Missing Code) 관련 문제

AD 컨버터 데이터시트에 있는 '미싱 코드 없음(no missing codes)' 보증과 가장 관계가 깊은 조건은 무엇입니까?

  1. A적분 비선형성(INL)이 ±0.5 LSB 이내일 것
  2. B미분 비선형성(DNL)이 −1 LSB보다 클 것
  3. C유효 비트 수(ENOB)가 분해능 비트 수와 같을 것
정답과 해설 보기

정답: B. 미분 비선형성(DNL)이 −1 LSB보다 클 것

DNL은 인접한 코드 사이의 간격(코드 폭)이 이상적인 1 LSB에서 얼마나 벗어나 있는지를 나타냅니다. DNL이 −1 LSB가 되면 그 코드의 폭이 0이 되어, 입력을 어떻게 바꿔도 그 코드가 출력되지 않는 미싱 코드가 발생합니다. 따라서 DNL이 −1 LSB보다 크면 미싱 코드는 발생하지 않습니다. 데이터시트에서는 '12비트, 미싱 코드 없음'과 같이 분해능과 함께 보증됩니다. INL은 이상 직선으로부터의 편차의 누적으로, 미싱 코드의 유무를 직접 결정하지는 않습니다.

자주 묻는 질문

ADC 데이터시트의 no missing codes는 무슨 뜻인가요?

명시된 분해능에서 모든 출력 코드가 어떤 입력 전압에서든 반드시 나타난다는 보장이며, 이는 DNL이 −1 LSB보다 크게 유지된다는 것과 같습니다.

INL 때문에 미싱 코드가 생길 수 있나요?

직접적으로는 아닙니다. INL은 직선으로부터의 누적 편차이고, 미싱 코드는 하나의 코드 빈 폭이 0으로 줄어드는 것으로, 이는 DNL 조건입니다.

ADC 미싱 코드 테스트 방법은?

느린 램프나 사인파를 인가하고 많은 수의 샘플을 수집하여 출력 코드의 히스토그램을 만듭니다. 발생 횟수가 0인 코드가 미싱 코드입니다.

해설 속 미싱 코드(Missing Code)

  • DNL이 −1 LSB가 되면 그 코드의 폭이 0이 되어, 입력을 어떻게 바꿔도 그 코드가 출력되지 않는 미싱 코드가 발생합니다.

    AD 컨버터 데이터시트에 있는 '미싱 코드 없음(no missing codes)' 보증과 가장 관계가 깊은…

  • DNL이 −1 LSB가 되면 그 코드가 나타나지 않게 되고(미싱 코드), +1 LSB를 넘으면 분해능이 실질적으로 떨어집니다.

    ADC의 미분 비선형성(DNL)에 대한 설명으로 옳은 것은 무엇인가?

  • 이것이 미싱 코드이며, 예를 들어 SAR형 ADC 내부 DAC의 상위 비트 가중치가 너무 작으면 코드가 건너뛰어질 수 있습니다.

    입력을 변화시켜도 특정 출력 코드가 한 번도 나타나지 않는 ADC의 결함을 무엇이라 하는가?
