라우터(Router)란?

서로 다른 네트워크 사이에서 패킷을 중계하는 네트워크 계층(3계층)의 기기. 받은 패킷의 목적지 IP 주소를 라우팅 테이블과 대조하여, 다음에 넘길 라우터(넥스트 홉)와 출구 인터페이스를 정해 내보낸다. 가정용 라우터는 NAPT나 DHCP 서버, 방화벽 기능도 함께 가진다.

일본어 명칭: ルータ

라우터(Router)은(는) 네트워크 설계와 운용, 네트워크 기초, 정보 보안 기초 등 3개 분야의 연습 문제 39개에 나와요.

분야: 네트워크 기초

패킷을 중계하는 절차

라우터는 도착한 프레임에서 IP 패킷을 꺼내 목적지 IP 주소와 라우팅 테이블을 대조합니다. 해당하는 경로가 여러 개면 프리픽스가 가장 길게 일치하는 것(최장 일치)을 고릅니다. 다음으로 TTL(IPv6에서는 홉 리밋)을 1 줄이고, IPv4라면 헤더 체크섬을 다시 계산합니다. 그리고 ARP 등으로 다음 라우터의 MAC 주소를 알아내, 목적지와 출발지 MAC 주소를 바꿔 쓴 새 프레임으로 내보냅니다. IP 주소는 NAT를 하지 않는 한 바뀌지 않습니다. TTL이 0이 된 패킷은 버리고 출발지에 ICMP로 알립니다. traceroute는 이 통지를 이용해 경로를 조사합니다.

라우팅 테이블을 만드는 방법

라우팅 테이블에는 자신에게 직접 연결된 네트워크, 사람이 설정하는 정적 경로, 라우팅 프로토콜로 자동으로 익힌 경로가 들어갑니다. 어디에도 해당하지 않는 목적지는 기본 경로(0.0.0.0/0) 쪽으로 보냅니다. 조직 안에서는 링크 상태를 교환하여 각 라우터가 다익스트라 알고리즘으로 최단 경로를 계산하는 OSPF나, 이웃에게서 들은 거리(홉 수)를 쓰는 RIP가 쓰입니다. 인터넷 서비스 제공자끼리처럼 조직(AS) 사이에서는 BGP로 경로 정보를 주고받습니다.

스위치와의 차이와 라우터의 내부

L2 스위치는 MAC 주소를 보고 같은 네트워크 안에서 프레임을 전달합니다. 라우터는 IP 주소를 보고 서로 다른 네트워크 사이를 중계하며, 브로드캐스트를 밖으로 통과시키지 않으므로 네트워크를 나누는 역할도 합니다. 라우팅 기능을 하드웨어로 수행하는 스위치를 L3 스위치라고 부릅니다. 대형 라우터에서는 경로 계산을 하는 제어 부분(컨트롤 플레인, CPU가 담당)과 패킷을 전달하는 부분(데이터 플레인)을 나누고, 데이터 플레인에서는 전용 ASIC과 최장 일치 검색을 1회에 수행하는 TCAM 등으로 패킷을 고속으로 처리합니다.

도전해 보기: 라우터(Router) 관련 문제

192.168.5.0/26 네트워크에서 호스트(단말이나 라우터의 인터페이스)에 할당할 수 있는 IP 주소는 몇 개인가?

  1. A64개
  2. B30개
  3. C62개
정답과 해설 보기

정답: C. 62개

/26은 네트워크부가 26비트이므로 호스트부는 32 − 26 = 6비트이고, 주소는 2^6 = 64개 있습니다. 이 중 호스트부가 모두 0인 네트워크 주소(192.168.5.0)와 모두 1인 브로드캐스트 주소(192.168.5.63)는 호스트에 할당할 수 없으므로 64 − 2 = 62개가 됩니다. 일반적으로 프리픽스 길이가 n일 때 할당할 수 있는 수는 2^(32 − n) − 2입니다. /26의 서브넷 마스크는 255.255.255.192입니다.

가정용 브로드밴드 라우터는 NAT(네트워크 주소 변환)의 일종인 NAPT(IP 마스커레이드)를 수행한다. NAPT로 가능해지는 것으로 올바른 것은?

  1. A가정 내 여러 단말이 포트 번호로 구별됨으로써 하나의 공인 IP 주소를 동시에 공유하여 인터넷과 통신할 수 있다
  2. B가정 내 단말과 인터넷 사이의 통신이 암호화되어 도중에 엿볼 수 없게 된다
  3. C가정 내 단말마다 서로 다른 공인 IP 주소가 자동으로 할당된다
정답과 해설 보기

정답: A. 가정 내 여러 단말이 포트 번호로 구별됨으로써 하나의 공인 IP 주소를 동시에 공유하여 인터넷과 통신할 수 있다

NAT(네트워크 주소 변환)는 라우터를 지나는 패킷의 출발지나 목적지 IP 주소를 바꿔 쓰는 기술입니다. NAPT는 IP 주소에 더해 포트 번호도 바꿔 쓰고, '내부의 주소와 포트'와 '외부의 포트'의 대응을 변환 테이블에 기록합니다. 그래서 사설 주소를 쓰는 여러 단말이 라우터가 가진 하나의 공인 주소를 동시에 사용할 수 있습니다. 돌아온 패킷은 변환 테이블을 보고 올바른 단말로 전달됩니다. 주소를 바꿔 쓸 뿐 암호화는 하지 않습니다. 또한 외부에서 시작되는 통신은 변환 테이블에 없으므로 그대로는 내부 단말에 도달하지 않으며, 내부에서 서버를 공개하려면 포트 포워딩 등의 설정이 필요합니다.

자주 묻는 질문

라우터와 스위치의 차이는 무엇인가요?

스위치(L2 스위치)는 MAC 주소를 보고 같은 네트워크 안에서 기기끼리 연결합니다. 라우터는 IP 주소를 보고 서로 다른 네트워크 사이에서 패킷을 중계하며, 어느 경로로 보낼지 정합니다. 가정용 라우터에는 스위치 포트나 무선 LAN 액세스 포인트도 들어 있는 경우가 많습니다.

기본 게이트웨이란 라우터를 말하나요?

거의 같은 뜻입니다. 단말에서 보아 자신의 네트워크 밖으로 패킷을 보낼 때의 송신처가 되는 라우터를 그 주소로 설정한 것이 기본 게이트웨이입니다.

  • 정적 라우팅과 동적 라우팅의 차이: 설정·장애 시 전환·부하·규모·선택 기준 비교정적 라우팅과 동적 라우팅을 한 장의 표로 비교합니다. 경로를 정하는 방법, 장애 시 동작, 라우터의 부하와 대역폭, 설정의 수고와 규모, 예측 가능성, 보안, 관리 거리, 적합한 곳을 정리합니다.
