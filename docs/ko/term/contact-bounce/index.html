채터링(Chattering)란?

기계식 스위치의 접점이 튀어 누른 순간 등에 짧은 시간 동안 여러 번 온과 오프를 반복하는 현상. 디바운스로 제거한다.

일본어 명칭: チャタリング

채터링(Chattering)은(는) 아날로그·전자 회로, 임베디드 시스템과 펌웨어 등 2개 분야의 연습 문제 3개에 나와요.

도전해 보기: 채터링(Chattering) 관련 문제

소프트웨어로 스위치의 채터링을 제거하는 방법으로 가장 적절한 것은 무엇입니까?

  1. A핀을 읽는 횟수를 늘리고 한 번이라도 1이 되면 눌렸다고 간주한다
  2. B수 ms마다 핀을 읽어 같은 값이 여러 번 이어졌을 때 비로소 상태가 바뀐 것으로 간주한다
  3. C스위치가 눌리면 마이크로컨트롤러를 재시작한다
정답과 해설 보기

정답: B. 수 ms마다 핀을 읽어 같은 값이 여러 번 이어졌을 때 비로소 상태가 바뀐 것으로 간주한다

채터링은 수 ms 안에 가라앉으므로, 예를 들어 5 ms마다 핀을 읽어 같은 값이 3회 이어지면 상태가 바뀐 것으로 판단하면 튀는 동안의 변화를 무시할 수 있습니다. 타이머 인터럽트로 주기적으로 읽도록 하면 다른 처리를 멈추지 않아도 됩니다. 대기 시간을 너무 길게 하면 반응이 느리게 느껴지므로 스위치의 특성에 맞춰 정합니다.

해설 속 채터링(Chattering)

  • 채터링은 수 ms 안에 가라앉으므로, 예를 들어 5 ms마다 핀을 읽어 같은 값이 3회 이어지면 상태가 바뀐 것으로 판단하면 튀는 동안의 변화를 무시할 수 있습니다.

    소프트웨어로 스위치의 채터링을 제거하는 방법으로 가장 적절한 것은 무엇입니까?

  • 마이컴 리셋 회로의 지연, 스위치 채터링 제거, 카메라 플래시의 충전 시간 추정 등에 사용됩니다.

    RC 회로의 계단 응답에서 커패시터 전압이 최종값의 약 63%에 도달하기까지의 시간은 무엇입니까?

  • 천천히 변화하는 신호나 노이즈를 포함한 신호를 받아도 임계값 부근에서 출력이 여러 번 전환되는 것(채터링)을 방지할 수 있습니다.

    입력이 올라갈 때와 내려갈 때의 임계값이 달라 노이즈로 인한 출력의 흔들림을 방지하는 회로는 무엇입니까?
