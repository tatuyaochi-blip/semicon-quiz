INT8란?

いんとはち

8ビットの符号付き整数(−128〜127)。AIの推論で、重みや活性化の値をスケールを掛けてINT8に変換(量子化)すると、計算とメモリが大きく減り、整数の小さな回路で高速に処理できる。

정답과 해설 보기

정답: A. 대표적인 입력 데이터를 흘려 보내 각 층의 활성화 값의 범위를 조사하고 양자화 스케일을 정한다

가중치는 학습이 끝나면 값이 정해져 있지만, 활성화 값은 입력에 따라 달라집니다. 그래서 실제 사용에 가까운 입력을 수백 건 정도 흘려 보내 각 층의 활성화가 취하는 값의 범위와 분포를 조사하고, 어느 범위를 INT8의 -127~127에 대응시킬지(스케일)를 정합니다. 최댓값에 맞추면 이상치 때문에 세밀함이 사라지므로, 분포의 대부분이 들어가도록 범위를 조금 좁히기도 합니다.

해설 속 INT8

  • 그래서 실제 사용에 가까운 입력을 수백 건 정도 흘려 보내 각 층의 활성화가 취하는 값의 범위와 분포를 조사하고, 어느 범위를 INT8의 -127~127에 대응시킬지(스케일)를 정합니다.
