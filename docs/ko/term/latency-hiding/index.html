지연 시간 은닉(latency hiding)란?

메모리 대기 같은 지연이 성능에 드러나지 않도록 그동안 다른 작업을 수행하는 것입니다. GPU는 많은 워프를 전환하며 이를 실현합니다.

일본어 명칭: レイテンシ隠蔽

분야: GPU 프로그래밍

관련 용어

고정 메모리(pinned memory) 그리드 스트라이드 루프(grid-stride loop) 메모리 코얼레싱(memory coalescing) 뱅크 충돌(bank conflict) 병렬 리덕션(parallel reduction) 상수 메모리(constant memory) 스레드 블록(thread block) 스트리밍 멀티프로세서(streaming multiprocessor, SM) 워프 다이버전스(warp divergence) 텐서 코어(tensor core)
