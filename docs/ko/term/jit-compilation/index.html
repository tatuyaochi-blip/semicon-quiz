JIT 컴파일란?

프로그램 실행 중에 자주 실행되는 부분을 기계어로 컴파일하는 방식. 실행 시 정보를 이용한 최적화가 가능하다. Java와 JavaScript의 실행 환경 등에서 쓰인다.

일본어 명칭: JITコンパイル

JIT 컴파일은(는) 컴파일러, 링커, 로더, 실행 파일, 성능 분석 등 3개 분야의 연습 문제 5개에 나와요.

분야: 컴파일러

도전해 보기: JIT 컴파일 관련 문제

JIT 컴파일을 사용하는 실행 환경의 특징으로 올바른 것은?

  1. A프로그램을 실행하기 전에 모든 것을 기계어로 번역한 뒤 배포한다
  2. B실행 중에 자주 쓰는 부분을 기계어로 만들고 실행 시의 정보도 활용할 수 있다
  3. C기계어를 전혀 사용하지 않고 언제까지나 바이트코드를 한 명령씩 해석한다
정답과 해설 보기

정답: B. 실행 중에 자주 쓰는 부분을 기계어로 만들고 실행 시의 정보도 활용할 수 있다

JIT 컴파일에서는 처음에는 바이트코드를 해석하면서 실행하다가, 여러 번 실행되는 부분(핫스폿)을 발견하면 실행 중에 그 부분을 기계어로 컴파일합니다. 실제로 지나가는 분기나 전달되는 타입 같은 실행 시의 정보를 활용하여, 사전에 하는 컴파일로는 어려운 과감한 최적화를 할 수 있습니다. 가정이 빗나가면 해석 실행으로 되돌아가는 구조도 갖추고 있습니다. 사전에 모든 것을 번역하는 것은 사전(AOT) 컴파일, 해석만 계속하는 것은 순수한 인터프리터입니다.

해설 속 JIT 컴파일

  • JIT 컴파일에서는 처음에는 바이트코드를 해석하면서 실행하다가, 여러 번 실행되는 부분(핫스폿)을 발견하면 실행 중에 그 부분을 기계어로 컴파일합니다.

    JIT 컴파일을 사용하는 실행 환경의 특징으로 올바른 것은?

  • 공백을 제거하고 단어로 구분하는 것은 어휘 분석, 실행 중에 기계어로 변환하는 것은 JIT 컴파일입니다.

    컴파일러의 구문 분석에서 하는 일로 올바른 것은?

  • 실제로는 바이트코드로 번역한 뒤 해석하고, 자주 쓰는 부분을 JIT 컴파일하는 등 둘을 조합한 방식도 많이 사용됩니다.

    컴파일러와 인터프리터의 차이로 올바른 것은?

  • JIT 컴파일러처럼 실행 중에 코드를 만드는 경우에는 쓰기와 실행 권한을 전환하여 사용합니다.

    메모리 페이지에 '쓰기 가능'과 '실행 가능'을 동시에 허용하지 않는 것(W^X, 쓰기와 실행의 분리)으로…

  • 처음 실행에서는 캐시나 TLB, 분기 예측기가 빈 상태에서 시작하고, 파일이 OS 캐시에 없어 디스크에서 읽어야 하며, JIT 컴파일러를 사용하는 언어에서는 기계어로의 변환도 이루어집니다.

    프로그램의 실행 시간을 측정할 때 같은 측정을 여러 번 반복하고 처음 몇 번의 결과를 제외하는 경우가 많은…

JIT 컴파일이(가) 나오는 문제 (5)

  1. JIT 컴파일을 사용하는 실행 환경의 특징으로 올바른 것은?
  2. 컴파일러의 구문 분석에서 하는 일로 올바른 것은?
  3. 컴파일러와 인터프리터의 차이로 올바른 것은?

  5. 프로그램의 실행 시간을 측정할 때 같은 측정을 여러 번 반복하고 처음 몇 번의 결과를 제외하는 경우가 많은 이유로 올바른 것은?
