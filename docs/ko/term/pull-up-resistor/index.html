풀업 저항(pull-up resistor)란?

신호선을 전원에 연결하여 아무도 구동하지 않을 때 논리 1로 유지하는 저항입니다. 입력 핀이 부유하지 않게 하며 I2C 선 등에 사용됩니다.

일본어 명칭: プルアップ抵抗

풀업 저항(pull-up resistor)은(는) 임베디드 시스템과 펌웨어, 논리 회로 등 2개 분야의 연습 문제 3개에 나와요.

도전해 보기: 풀업 저항(pull-up resistor) 관련 문제

오픈 드레인 출력 회로를 여러 개, 풀업 저항이 있는 하나의 신호선에 연결했을 때의 동작으로 올바른 것은 무엇입니까?

  1. A출력끼리 충돌하여 반드시 망가진다
  2. B어느 하나라도 0을 내면 선이 0이 되어 와이어드 AND로 동작한다
  3. C어느 하나라도 1을 내면 선이 1이 된다
정답과 해설 보기

정답: B. 어느 하나라도 0을 내면 선이 0이 되어 와이어드 AND로 동작한다

오픈 드레인 출력은 트랜지스터로 선을 그라운드로 끌어내리거나 분리하는 2가지 상태이며, 1은 풀업 저항이 만듭니다. 어느 하나라도 0을 내면 선은 0이 되고, 모두가 분리했을 때만 1이 되는 와이어드 AND로 동작하며, 출력끼리 충돌해도 망가지지 않습니다. I²C 버스나 인터럽트선, 서로 다른 전원 전압의 회로 사이의 레벨 변환에 사용됩니다. 상승은 풀업 저항과 배선 용량으로 결정되므로 느려집니다.

해설 속 풀업 저항(pull-up resistor)

  • 오픈 드레인 출력은 트랜지스터로 선을 그라운드로 끌어내리거나 분리하는 2가지 상태이며, 1은 풀업 저항이 만듭니다.

    오픈 드레인 출력 회로를 여러 개, 풀업 저항이 있는 하나의 신호선에 연결했을 때의 동작으로 올바른 것은 …

  • 풀업 저항으로 전원에 연결해 두면 스위치가 열려 있을 때는 1, 닫혀서 접지되면 0으로 확실하게 읽을 수 있습니다.

    마이크로컨트롤러의 입력 핀에 스위치만 연결하고 풀업이나 풀다운 저항을 달지 않았습니다. 스위치가 열려 있을…

  • 선은 오픈 드레인이며 풀업 저항으로 1로 끌어올리고, 어느 기기든 0으로 끌어내릴 수 있게 되어 있습니다.

풀업 저항(pull-up resistor)이(가) 나오는 문제 (3)

  1. 오픈 드레인 출력 회로를 여러 개, 풀업 저항이 있는 하나의 신호선에 연결했을 때의 동작으로 올바른 것은 무엇입니까?
  2. 마이크로컨트롤러의 입력 핀에 스위치만 연결하고 풀업이나 풀다운 저항을 달지 않았습니다. 스위치가 열려 있을 때 일어날 수 있는 일은 무엇입니까?
  3. I2C 통신의 특징으로 올바른 것은 무엇입니까?
