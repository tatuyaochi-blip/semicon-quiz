보드 선도(Bode Plot)란?

시스템의 주파수 응답을 가로축에 주파수의 로그, 세로축에 이득(dB)과 위상(도)을 잡은 2개의 그래프로 나타낸 것. 전달 함수의 곱은 이득(dB)과 위상의 합이 되므로, 요소별 선을 더해 그릴 수 있다. 극점이 1개 늘 때마다 이득의 기울기가 −20 dB/dec 바뀌고 위상이 최대 90° 늦어진다. 루프 전달 함수의 보드 선도에서 이득 여유와 위상 여유를 읽어 안정성을 조사한다.

일본어 명칭: ボード線図

보드 선도(Bode Plot)은(는) 제어 공학의 기초 등 1개 분야의 연습 문제 4개에 나와요.

분야: 제어 공학의 기초

점근선 근사로 그리는 법

1차 요소 1/(1 + s/ωc)는 ωc보다 낮은 주파수에서는 0 dB의 수평선, 높은 주파수에서는 −20 dB/dec의 직선으로 근사합니다. 실제 이득은 절점에서 약 −3 dB이고, 위상은 절점에서 −45°가 되며, 그 10분의 1에서 10배의 범위에서 대략 0°에서 −90°까지 바뀝니다. 영점은 반대로 +20 dB/dec의 기울기와 위상 앞섬을 더하고, 적분 1/s는 전체에 −20 dB/dec의 기울기와 −90°를 더합니다.

안정 여유 읽기

루프 전달 함수의 이득이 0 dB를 가로지르는 주파수(이득 교차 주파수)에서 위상이 −180°까지 몇 도 남아 있는지가 위상 여유입니다. 위상이 −180°가 되는 주파수(위상 교차 주파수)에서 이득이 0 dB보다 몇 dB 낮은지가 이득 여유입니다. 이득 교차 주파수는 루프 속도의 기준도 되며, 높을수록 폐루프 응답은 빨라집니다.

나이퀴스트 선도와의 차이

같은 주파수 응답을 복소 평면 위에 1개의 궤적으로 그린 것이 나이퀴스트 선도(벡터 궤적)입니다. 보드 선도는 주파수 눈금을 읽기 쉽고 요소를 더해 그릴 수 있으므로 설계에 적합합니다. 나이퀴스트 선도는 점 −1과의 위치 관계로 안정성을 직접 판별할 수 있으며, 루프 전달 함수 자체가 불안정한 경우에도 쓸 수 있습니다.

도전해 보기: 보드 선도(Bode Plot) 관련 문제

1차 지연계 G(s) = 1/(1 + sT)의 보드 선도의 특징으로 올바른 것은?

  1. A절점 각주파수 ω = 1/T에서 이득은 약 −3 dB, 위상은 −45°이며, 그보다 충분히 높은 주파수에서는 이득이 −20 dB/dec로 떨어진다
  2. B절점 각주파수 ω = 1/T에서 이득은 −6 dB, 위상은 −90°이며, 그보다 충분히 높은 주파수에서는 이득이 −40 dB/dec의 기울기로 떨어진다
  3. C이득은 어느 주파수에서나 0 dB이고, 위상만 주파수에 비례하여 늦어져 간다
정답과 해설 보기

정답: A. 절점 각주파수 ω = 1/T에서 이득은 약 −3 dB, 위상은 −45°이며, 그보다 충분히 높은 주파수에서는 이득이 −20 dB/dec로 떨어진다

G(jω) = 1/(1 + jωT)의 크기는 1/√(1 + (ωT)²)이며, ω = 1/T에서는 1/√2(약 −3 dB), 위상은 −45°입니다. ω가 1/T보다 충분히 크면 크기는 1/(ωT)에 가까워지고, 주파수가 10배가 될 때마다 이득이 20 dB 떨어집니다(−20 dB/dec). 위상은 낮은 주파수의 0°에서 높은 주파수의 −90°로 바뀝니다. 보드 선도의 점근선 근사에서는 절점보다 아래를 0 dB의 수평선, 위를 −20 dB/dec의 직선으로 나타냅니다.

적분 요소 G(s) = 1/s의 보드 선도로 올바른 것은?

  1. A이득은 어느 주파수에서나 0 dB이고, 위상은 어느 주파수에서나 −90°가 된다
  2. B이득은 ω = 1 rad/s에서 0 dB를 지나는 +20 dB/dec의 직선이고, 위상은 어느 주파수에서나 +90°가 된다
  3. C이득은 ω = 1 rad/s에서 0 dB를 지나는 −20 dB/dec의 직선이고, 위상은 어느 주파수에서나 −90°가 된다
정답과 해설 보기

정답: C. 이득은 ω = 1 rad/s에서 0 dB를 지나는 −20 dB/dec의 직선이고, 위상은 어느 주파수에서나 −90°가 된다

G(jω) = 1/(jω)의 크기는 1/ω이므로 ω = 1 rad/s에서 0 dB가 되고, 주파수가 10배가 될 때마다 20 dB 떨어집니다. 1/j = −j이므로 위상은 어느 주파수에서나 −90°입니다. 낮은 주파수일수록 이득이 커지므로, 적분을 포함하는 시스템은 계단 목표값에 대한 정상 편차를 0으로 만들 수 있습니다. +20 dB/dec이고 위상이 +90°인 직선이 되는 것은 미분 요소 s입니다.

자주 묻는 질문

보드 선도의 −20 dB/dec란 무엇인가요?

주파수가 10배(1디케이드)가 될 때마다 이득이 20 dB, 즉 진폭이 10분의 1이 되는 기울기입니다. 극점이 1개 늘 때마다 이 기울기가 −20 dB/dec씩 가팔라집니다. 주파수가 2배가 될 때마다 약 6 dB 떨어지는 −6 dB/oct와 같은 기울기입니다.

보드 선도는 어떻게 측정하나요?

사인파의 주파수를 바꾸면서 입력하고 출력의 진폭과 위상을 측정합니다. 전원의 제어 루프에서는 루프 도중에 작은 저항을 넣어 신호를 주입하고, 주파수 응답 분석기로 루프 전달 함수를 측정하는 것이 일반적입니다.
