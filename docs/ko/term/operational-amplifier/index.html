연산 증폭기(Op-amp)란?

차동 입력과 높은 증폭률을 갖는 증폭기. 부귀환을 걸어 증폭 회로나 필터 등에 사용한다.

일본어 명칭: オペアンプ

연산 증폭기(Op-amp)은(는) 아날로그·전자 회로, 데이터시트 읽는 법, 바이폴라 트랜지스터 등 5개 분야의 연습 문제 26개에 나와요.

분야: 아날로그·전자 회로

연산 증폭기의 내부 구성

일반적인 연산 증폭기(op-amp)는 세 부분으로 이루어집니다. 입력단은 차동 쌍으로, 테일 전류원이 두 입력 전압의 차에 따라 두 트랜지스터에 전류를 나누어 흘리므로 양 입력에 공통인 신호는 대부분 상쇄되며, 이것이 높은 동상 신호 제거비(CMRR)를 만듭니다. 전류 미러 능동 부하는 이 단의 출력을 높은 이득의 단일 종단 신호로 변환하고, 두 번째 이득단이 이득을 더하며, 출력단이 부하 전류를 공급합니다. 두 번째 단에 걸쳐 연결된 보상 커패시터는 밀러 효과로 증폭되어 주파수 응답을 결정합니다. 개루프 이득은 보통 10^5–10^6입니다.

부귀환과 가상 단락

연산 증폭기는 거의 항상 부귀환을 걸어 사용합니다. 이상적인 모델은 입력 임피던스 무한대, 출력 임피던스 0, 개루프 이득 무한대를 가정하며, 귀환이 걸리면 출력은 두 입력 사이의 전압이 사실상 0이 되는 지점에서 안정됩니다. 이것이 가상 단락입니다. 이때 이득은 부품 값에만 의존합니다. 반전 증폭기는 −Rf/Ri의 이득과 Ri의 입력 임피던스를, 비반전 증폭기는 1 + R2/R1의 이득과 매우 높은 입력 임피던스를 가집니다. R2가 없는 전압 팔로워는 이득이 1이며 버퍼로 쓰입니다. 귀환 경로에 커패시터를 넣으면 적분기가 되고, 귀환 저항만 있으면 트랜스임피던스 증폭기로서 전류를 전압으로 변환합니다.

대역폭과 슬루율

내부 보상형 연산 증폭기의 이득은 디케이드당 20 dB씩 떨어지므로, 이득과 대역폭의 곱은 거의 일정합니다. 이득 대역폭 곱(GBW)이 1 MHz이면 비반전 이득 10에서 남는 대역폭은 약 100 kHz입니다. 엄밀히는 노이즈 이득 1 + Rf/Ri로 나누어야 합니다. 큰 신호에는 별도의 한계인 슬루율, 즉 출력이 변할 수 있는 최대 속도가 적용됩니다. 피크 진폭 Vp인 정현파는 SR/(2πVp)를 넘는 주파수에서 왜곡되며, 0.5 V/µs에 10 V라면 약 8 kHz밖에 되지 않습니다.

실제 오차와 비교기

입력 트랜지스터의 부정합은 입력 오프셋 전압을 만들며, 그 크기는 범용 부품에서 수 밀리볼트, 정밀형이나 초퍼 안정화형에서는 수십 마이크로볼트 이하이고, 출력에는 노이즈 이득만큼 곱해져 나타납니다. 바이폴라 입력은 바이어스 전류도 흘리므로, Ri와 Rf의 병렬값과 같은 저항을 비반전 입력에 넣어 그 영향을 상쇄합니다. 비교기는 겉보기에 비슷하지만 귀환 없이 동작하도록 설계되어 완전히 스위칭하고 포화에서 빨리 회복하며, 오픈 드레인 출력과 노이즈로 인한 채터링을 막는 히스테리시스를 갖춘 경우가 많습니다.

  1. A입력 임피던스: 무한대, 출력 임피던스: 0
  2. B입력 임피던스: 0, 출력 임피던스: 무한대
  3. C입력 임피던스: 0, 출력 임피던스: 0
정답과 해설 보기

정답: A. 입력 임피던스: 무한대, 출력 임피던스: 0

이상적인 연산 증폭기는 입력 임피던스가 무한대(입력 단자로 전류가 흐르지 않음), 출력 임피던스가 0(부하와 관계없이 출력 전압이 결정됨), 개루프 이득이 무한대라고 가정합니다. 이 가정에서 부귀환 회로는 두 입력 단자의 전압이 같아지는 '가상 단락'이 성립하고, 회로의 이득이 저항비만으로 결정됩니다. 실제 연산 증폭기의 개루프 이득은 10⁵~10⁶ 정도이며 주파수가 높아질수록 감소합니다.

이상적인 연산 증폭기를 사용한 반전 증폭 회로에서 입력 저항 Ri = 10 kΩ, 귀환 저항 Rf = 100 kΩ일 때 전압 이득은 얼마입니까?

  1. A+11배
  2. B−0.1배
  3. C−10배
정답과 해설 보기

정답: C. −10배

반전 증폭 회로의 이득은 −Rf/Ri이며, −100 kΩ/10 kΩ = −10배입니다. 반전 입력이 가상 접지가 되므로 입력 전류 Vin/Ri가 모두 Rf로 흐르고, 출력은 −Rf × Vin/Ri가 됩니다. 입력 임피던스는 Ri 그대로(10 kΩ)이므로 신호원에 부담이 된다는 점에 유의해야 합니다. +11배는 같은 저항으로 비반전 증폭 회로를 구성했을 때의 이득(1 + Rf/Ri)입니다.

자주 묻는 질문

연산 증폭기의 가상 단락이란 무엇인가요?

부귀환이 걸려 있고 개루프 이득이 매우 높으면, 연산 증폭기는 두 입력이 연결되어 있지 않아도 두 입력 전압이 거의 같아지도록 출력을 구동합니다. 이는 출력이 포화되지 않고 귀환이 부귀환일 때만 성립합니다.

연산 증폭기를 비교기로 사용할 수 있나요?

저속에서는 동작할 수 있지만, 연산 증폭기는 귀환 동작에 최적화되어 있어 포화에서 회복이 느리거나 출력 레벨이 로직에 맞지 않을 수 있습니다. 전용 비교기는 더 빠르게 스위칭하고 오픈 드레인 출력인 경우가 많으며, 개루프로 동작하도록 설계되어 있습니다.

이득 대역폭 곱(GBW)이란 무엇인가요?

이득 대역폭 곱은 연산 증폭기의 개루프 이득이 1로 떨어지는 주파수이며, 보상형 연산 증폭기에서는 폐루프 이득과 대역폭의 곱이 대략 이 값과 같습니다. 예를 들어 GBW가 10 MHz인 부품은 노이즈 이득 100에서 약 100 kHz의 대역폭을 가집니다.

해설 속 연산 증폭기(Op-amp)

  • 이상적인 연산 증폭기는 입력 임피던스가 무한대(입력 단자로 전류가 흐르지 않음), 출력 임피던스가 0(부하와 관계없이 출력 전압이 결정됨), 개루프 이득이 무한대라고 가정합니다.

    이상적인 연산 증폭기의 특성으로 올바른 조합은 무엇입니까?

  • 부귀환이 가장 깊은 구성이어서 연산 증폭기에 따라 위상 여유가 부족해 발진하기 쉬우므로, 데이터시트에서 '유니티 게인 안정' 여부를 확인합니다.

    연산 증폭기를 사용한 전압 팔로워에 대한 설명으로 올바른 것은 무엇입니까?

  • 직류에서는 연산 증폭기의 오프셋도 적분되어 출력이 포화되므로, 실용에서는 C에 병렬로 큰 저항을 넣습니다.

    연산 증폭기의 반전 증폭 회로에서 귀환 저항을 커패시터로 바꾼 회로를 무엇이라고 합니까?

  • 내부에서 위상 보상된 연산 증폭기는 개루프 이득이 −20 dB/dec로 떨어지므로 이득과 대역폭의 곱이 거의 일정합니다.

    이득 대역폭 곱(GBW)이 1 MHz인 연산 증폭기로 이득 10배의 비반전 증폭 회로를 만들었을 때 대역폭…

  • 개루프 이득 A가 매우 큰 연산 증폭기에 부귀환을 걸면 출력이 유한한 값에서 균형을 이루기 때문에 입력 단자 간 전압차는 Vout/A로 거의 0이 됩니다.

    부귀환을 건 이상적인 연산 증폭기 회로에서 두 입력 단자의 전압이 거의 같아지는 성질을 무엇이라고 합니까?
