연산 증폭기(Op-amp)란?

차동 입력과 높은 증폭률을 갖는 증폭기. 부귀환을 걸어 증폭 회로나 필터 등에 사용한다.

일본어 명칭: オペアンプ

연산 증폭기(Op-amp)은(는) 아날로그·전자 회로, 바이폴라 트랜지스터, A/D·D/A 변환 등 4개 분야의 연습 문제 23개에 나와요.

분야: 아날로그·전자 회로

도전해 보기: 연산 증폭기(Op-amp) 관련 문제

이상적인 연산 증폭기의 특성으로 올바른 조합은 무엇입니까?

  1. A입력 임피던스: 무한대, 출력 임피던스: 0
  2. B입력 임피던스: 0, 출력 임피던스: 무한대
  3. C입력 임피던스: 0, 출력 임피던스: 0
정답과 해설 보기

정답: A. 입력 임피던스: 무한대, 출력 임피던스: 0

이상적인 연산 증폭기는 입력 임피던스가 무한대(입력 단자로 전류가 흐르지 않음), 출력 임피던스가 0(부하와 관계없이 출력 전압이 결정됨), 개루프 이득이 무한대라고 가정합니다. 이 가정에서 부귀환 회로는 두 입력 단자의 전압이 같아지는 '가상 단락'이 성립하고, 회로의 이득이 저항비만으로 결정됩니다. 실제 연산 증폭기의 개루프 이득은 10⁵~10⁶ 정도이며 주파수가 높아질수록 감소합니다.

이상적인 연산 증폭기를 사용한 반전 증폭 회로에서 입력 저항 Ri = 10 kΩ, 귀환 저항 Rf = 100 kΩ일 때 전압 이득은 얼마입니까?

  1. A+11배
  2. B−0.1배
  3. C−10배
정답과 해설 보기

정답: C. −10배

반전 증폭 회로의 이득은 −Rf/Ri이며, −100 kΩ/10 kΩ = −10배입니다. 반전 입력이 가상 접지가 되므로 입력 전류 Vin/Ri가 모두 Rf로 흐르고, 출력은 −Rf × Vin/Ri가 됩니다. 입력 임피던스는 Ri 그대로(10 kΩ)이므로 신호원에 부담이 된다는 점에 유의해야 합니다. +11배는 같은 저항으로 비반전 증폭 회로를 구성했을 때의 이득(1 + Rf/Ri)입니다.

해설 속 연산 증폭기(Op-amp)

  • 이상적인 연산 증폭기는 입력 임피던스가 무한대(입력 단자로 전류가 흐르지 않음), 출력 임피던스가 0(부하와 관계없이 출력 전압이 결정됨), 개루프 이득이 무한대라고 가정합니다.

    이상적인 연산 증폭기의 특성으로 올바른 조합은 무엇입니까?

  • 부귀환이 가장 깊은 구성이어서 연산 증폭기에 따라 위상 여유가 부족해 발진하기 쉬우므로, 데이터시트에서 '유니티 게인 안정' 여부를 확인합니다.

    연산 증폭기를 사용한 전압 팔로워에 대한 설명으로 올바른 것은 무엇입니까?

  • 직류에서는 연산 증폭기의 오프셋도 적분되어 출력이 포화되므로, 실용에서는 C에 병렬로 큰 저항을 넣습니다.

    연산 증폭기의 반전 증폭 회로에서 귀환 저항을 커패시터로 바꾼 회로를 무엇이라고 합니까?

  • 내부에서 위상 보상된 연산 증폭기는 개루프 이득이 −20 dB/dec로 떨어지므로 이득과 대역폭의 곱이 거의 일정합니다.

    이득 대역폭 곱(GBW)이 1 MHz인 연산 증폭기로 이득 10배의 비반전 증폭 회로를 만들었을 때 대역폭…

  • 개루프 이득 A가 매우 큰 연산 증폭기에 부귀환을 걸면 출력이 유한한 값에서 균형을 이루기 때문에 입력 단자 간 전압차는 Vout/A로 거의 0이 됩니다.

    부귀환을 건 이상적인 연산 증폭기 회로에서 두 입력 단자의 전압이 거의 같아지는 성질을 무엇이라고 합니까?

  3. 이상적인 연산 증폭기를 사용한 비반전 증폭 회로에서 입력 측 저항 R1 = 10 kΩ, 귀환 저항 R2 = 90 kΩ일 때 전압 이득은 얼마입니까?
  4. 연산 증폭기를 사용한 전압 팔로워에 대한 설명으로 올바른 것은 무엇입니까?
  5. 연산 증폭기의 반전 증폭 회로에서 귀환 저항을 커패시터로 바꾼 회로를 무엇이라고 합니까?
  6. 이득 대역폭 곱(GBW)이 1 MHz인 연산 증폭기로 이득 10배의 비반전 증폭 회로를 만들었을 때 대역폭은 대략 얼마입니까?
  7. 연산 증폭기의 슬루 레이트의 의미로 올바른 것은 무엇입니까?
  8. 부귀환을 건 이상적인 연산 증폭기 회로에서 두 입력 단자의 전압이 거의 같아지는 성질을 무엇이라고 합니까?
  9. 연산 증폭기의 입력 오프셋 전압에 대한 설명으로 올바른 것은 무엇입니까?
  10. 포토다이오드의 전류를 전압으로 변환하기 위해 연산 증폭기의 반전 입력에 전류를 넣고 귀환 저항으로 전압으로 바꾸는 회로는 무엇입니까?
  11. 센서의 미소한 차동 신호를 고정밀로 증폭하기 위해 사용되는, 연산 증폭기 3개 등으로 구성된 증폭기는 무엇입니까?
  12. 연산 증폭기의 반전 증폭 회로에서 입력 저항을 커패시터로 바꾼 회로는 무엇이라고 합니까?
  13. 연산 증폭기의 위상 보상에 사용되는 '지배 극점 보상'의 개념으로 올바른 것은 무엇입니까?
  14. 바이폴라 입력 연산 증폭기를 사용한 반전 증폭 회로에서 비반전 입력과 그라운드 사이에, 입력 저항과 귀환 저항의 병렬값과 같은 저항을 넣는 목적은 무엇입니까?
  15. 축차 비교형 ADC의 입력 앞에 연산 증폭기 등의 드라이버 회로를 두는 주된 이유는 무엇인가?
