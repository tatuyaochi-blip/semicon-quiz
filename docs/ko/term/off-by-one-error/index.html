오프 바이 원 오류(Off-by-one Error)란?

반복 횟수나 배열의 범위가 하나만 어긋나는 오류. 종료값을 포함할지 여부, 인덱스가 0부터 시작하는지 1부터 시작하는지, 구간의 수와 점의 수(울타리 기둥 문제)의 혼동 등으로 일어난다. 경계값으로 트레이스하여 확인하면 찾기 쉽다.

일본어 명칭: オフバイワンエラー

오프 바이 원 오류(Off-by-one Error)은(는) 프로그래밍의 기초(의사 코드 트레이스) 등 1개 분야의 연습 문제 2개에 나와요.

해설 속 오프 바이 원 오류(Off-by-one Error)

  • 인덱스가 0부터 시작하는 언어에서의 작성법(0부터 요소 수 − 1까지)을 1부터 시작하는 배열에 그대로 적용하면, 이처럼 하나 어긋나는 오류(오프 바이 원 오류)가 일어납니다.

    배열 a의 모든 요소의 합계를 구할 생각으로 다음 프로그램을 작성했다. 배열의 인덱스는 1부터 시작한다. …

  • 울타리 기둥 세기와 마찬가지로, 구간의 수와 점의 수를 혼동하면 하나 어긋나는 오류(오프 바이 원 오류)가 됩니다.
