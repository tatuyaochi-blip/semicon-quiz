게이트 레벨 시뮬레이션(gate-level simulation)란?

합성 후 또는 배치배선 후의 넷리스트를, 필요하면 지연 정보와 함께 시뮬레이션하여 RTL에서는 보이지 않는 문제를 찾는 것입니다.

일본어 명칭: ゲートレベルシミュレーション

게이트 레벨 시뮬레이션(gate-level simulation)은(는) HDL과 검증 등 1개 분야의 연습 문제 1개에 나와요.

분야: HDL과 검증

도전해 보기: 게이트 레벨 시뮬레이션(gate-level simulation) 관련 문제

논리 합성이나 배치 배선 후의 회로(게이트 레벨 넷리스트)에서 지연 정보를 넣어 시뮬레이션하는 주된 목적은?

  1. ARTL 시뮬레이션보다 빠르게 대량의 테스트를 실행한다
  2. BRTL 시뮬레이션에서는 보이지 않는 초기화나 리셋의 불량, 합성 결과의 차이, 지연과 관련된 문제를 확인한다
  3. C회로의 면적을 줄인다
정답과 해설 보기

정답: B. RTL 시뮬레이션에서는 보이지 않는 초기화나 리셋의 불량, 합성 결과의 차이, 지연과 관련된 문제를 확인한다

RTL 시뮬레이션은 빠르지만, X 낙관주의로 불정 값의 문제가 가려지거나 합성에서 기술과 다른 회로가 되었을 때는 알아차릴 수 없습니다. 게이트 레벨 시뮬레이션에서는 실제로 만들어진 게이트와 플립플롭으로 동작을 확인하며, SDF 형식으로 각 게이트와 배선의 지연을 주면 지연과 관련된 문제도 볼 수 있습니다. 다만 매우 느리므로 한정된 테스트로만 수행하는 것이 일반적입니다.
