위상 여유(Phase Margin)란?

부귀환 루프의 이득이 1(0 dB)이 되는 주파수에서 위상 지연이 180°에 이르기까지의 여유. 작으면 응답이 진동적이 되고, 0 이하에서는 발진한다. 일반적으로 45~60° 이상을 기준으로 한다.

일본어 명칭: 位相余裕(フェーズマージン)

위상 여유(Phase Margin)은(는) 아날로그·전자 회로 등 1개 분야의 연습 문제 4개에 나와요.

분야: 아날로그·전자 회로

도전해 보기: 위상 여유(Phase Margin) 관련 문제

연산 증폭기를 사용한 전압 팔로워에 대한 설명으로 올바른 것은 무엇입니까?

  1. A전압 이득이 1이고 입력 임피던스가 높으며 출력 임피던스가 낮아 버퍼로 사용한다
  2. B전압 이득이 무한대인 비교기로 사용한다
  3. C입력 전류를 전압으로 변환하는 회로로 사용한다
정답과 해설 보기

정답: A. 전압 이득이 1이고 입력 임피던스가 높으며 출력 임피던스가 낮아 버퍼로 사용한다

전압 팔로워는 출력을 반전 입력에 직접 연결한 비반전 증폭 회로(이득 1)로, 출력이 입력과 같은 전압이 됩니다. 입력 임피던스가 매우 높고 출력 임피던스가 낮아, 내부 저항이 큰 센서나 분압 회로의 신호를 값의 변화 없이 후단이나 부하로 전달하는 버퍼로 사용됩니다. 부귀환이 가장 깊은 구성이어서 연산 증폭기에 따라 위상 여유가 부족해 발진하기 쉬우므로, 데이터시트에서 '유니티 게인 안정' 여부를 확인합니다.

증폭 회로에 부귀환을 걸었을 때의 효과로 올바른 것은 무엇입니까?

  1. A이득은 작아지지만 이득의 안정성 향상, 주파수 대역 확대, 왜곡 감소를 얻을 수 있다
  2. B이득이 무한대가 된다
  3. C반드시 발진하게 된다
정답과 해설 보기

정답: A. 이득은 작아지지만 이득의 안정성 향상, 주파수 대역 확대, 왜곡 감소를 얻을 수 있다

부귀환을 걸면 출력의 일부를 입력에서 빼기 때문에 이득이 작아집니다. 그 대신 폐루프 이득이 약 1/β(귀환율의 역수)가 되어 소자 편차나 온도에 영향을 덜 받고, 대역이 넓어지며, 왜곡과 출력 임피던스도 (1 + 루프 이득)분의 1로 줄어듭니다. 연산 증폭기 회로는 이 성질을 전제로 합니다. 다만 위상이 크게 돌아가는 주파수에서 정귀환이 되면 발진하므로 위상 여유를 확보해야 합니다.

해설 속 위상 여유(Phase Margin)

  • 부귀환이 가장 깊은 구성이어서 연산 증폭기에 따라 위상 여유가 부족해 발진하기 쉬우므로, 데이터시트에서 '유니티 게인 안정' 여부를 확인합니다.

    연산 증폭기를 사용한 전압 팔로워에 대한 설명으로 올바른 것은 무엇입니까?

  • 다만 위상이 크게 돌아가는 주파수에서 정귀환이 되면 발진하므로 위상 여유를 확보해야 합니다.

    증폭 회로에 부귀환을 걸었을 때의 효과로 올바른 것은 무엇입니까?

  • 위상 여유는 루프 이득이 1(0 dB)이 되는 주파수에서 위상 지연이 180°에 대해 얼마나 여유가 있는지를 나타냅니다.

    부귀환 증폭 회로가 발진하지 않고 안정적으로 동작하는지를 판단하는 지표는 무엇입니까?

  • 이득은 거기서부터 −20 dB/dec로 떨어지고, 다른 극점에서 위상이 크게 돌아가기 전에 0 dB 아래로 내려가므로 이득 1(팔로워)에서도 충분한 위상 여유를 얻을 수 있습니다.

    연산 증폭기의 위상 보상에 사용되는 '지배 극점 보상'의 개념으로 올바른 것은 무엇입니까?

위상 여유(Phase Margin)이(가) 나오는 문제 (4)

  1. 연산 증폭기를 사용한 전압 팔로워에 대한 설명으로 올바른 것은 무엇입니까?
  2. 증폭 회로에 부귀환을 걸었을 때의 효과로 올바른 것은 무엇입니까?
  3. 부귀환 증폭 회로가 발진하지 않고 안정적으로 동작하는지를 판단하는 지표는 무엇입니까?
  4. 연산 증폭기의 위상 보상에 사용되는 '지배 극점 보상'의 개념으로 올바른 것은 무엇입니까?
