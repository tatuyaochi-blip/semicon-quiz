시프트 레지스터(Shift Register)란?

플립플롭을 직렬로 연결하여 클록마다 데이터를 1비트씩 옆으로 옮기는 회로. 직렬·병렬 데이터 변환이나 스캔 테스트 체인에 사용된다.

일본어 명칭: シフトレジスタ

시프트 레지스터(Shift Register)은(는) 논리 회로, HDL과 검증, 타이밍 분석과 CDC 등 3개 분야의 연습 문제 5개에 나와요.

분야: 논리 회로

시프트 레지스터의 구성

시프트 레지스터는 D 플립플롭을 사슬처럼 연결하여 각 출력이 다음 단의 입력이 되게 하고, 모든 플립플롭이 하나의 클록을 공유합니다. 유효 클록 에지마다 각 비트가 사슬을 따라 한 단씩 이동합니다. 변형은 데이터가 들어오고 나가는 방식으로 분류합니다. 직렬 입력 직렬 출력은 지연선으로 동작하고, 직렬 입력 병렬 출력은 들어오는 비트를 모아 워드로 만들며, 병렬 입력 직렬 출력은 워드를 로드하여 시프트 아웃하고, 양방향으로 시프트하는 설계도 있습니다. HDL에서는 q1 <= d; q2 <= q1;처럼 각 단을 논블로킹 대입문으로 기술해야 합니다.

직렬-병렬 변환과 스캔 체인

직렬-병렬 변환은 대표적인 용도입니다. 고속 직렬 링크(SerDes, 직렬화기/역직렬화기)는 넓은 병렬 버스를 소수의 매우 빠른 직렬 레인으로 변환하고 다시 되돌려 배선과 핀 수를 줄입니다. 74HC595 같은 간단한 직렬 입력 병렬 출력 칩을 사용하면 마이크로컨트롤러가 핀 3개로 많은 LED를 구동할 수 있습니다. 칩 테스트에서는 스캔 설계가 블록의 플립플롭을 스캔 체인으로 연결합니다. 테스트 모드에서 플립플롭들이 시프트 레지스터를 이루므로, 테스트 패턴을 시프트 인하고 기능 클록을 한 번 인가한 뒤 캡처된 응답을 시프트 아웃할 수 있습니다.

시프트 레지스터로 만드는 카운터

출력을 입력으로 되먹이면 시프트 레지스터가 카운터가 됩니다. 링 카운터는 하나의 1을 순환시키며, 플립플롭 n개로 n개의 상태를 갖습니다. 존슨 카운터(트위스티드 링 카운터)는 마지막 출력을 반전하여 되먹이며, 3단의 경우 000, 100, 110, 111, 011, 001처럼 2n개의 상태를 순환합니다. 이웃한 상태 사이에서 한 비트만 바뀌므로 각 상태를 2입력 게이트 하나로 글리치 위험이 적게 디코딩할 수 있고, 출력은 균등하게 어긋난 클록 위상을 제공합니다.

선형 귀환 시프트 레지스터

선형 귀환 시프트 레지스터(LFSR)는 탭이라 불리는 선택된 출력들의 XOR을 입력으로 되먹입니다. 탭을 적절히 고르면 n비트 LFSR은 반복되기 전에 0이 아닌 2ⁿ − 1개의 모든 상태를 거치며, 이는 무작위처럼 보이는 최대 길이 수열입니다. 플립플롭과 XOR 게이트만으로 만들 수 있는 LFSR은 내장 자체 테스트(BIST)에서 테스트 패턴을 생성하고 응답을 압축하며, 순환 중복 검사(CRC)를 계산하고, 통신 링크에서 데이터를 스크램블하는 데 쓰입니다. 출력은 몇 비트만 알면 완전히 예측할 수 있으므로 암호용 난수에는 적합하지 않습니다.

정답과 해설 보기

정답: C. 직렬 데이터와 병렬 데이터의 변환

시프트 레지스터는 한 가닥의 선으로 차례로 들어오는 직렬 데이터를 저장해 두었다가 한꺼번에 병렬로 꺼내거나, 그 반대를 할 수 있습니다. 고속 통신 인터페이스(SerDes)는 이 변환을 수십 Gb/s로 수행하여 배선 수를 줄입니다. 그 밖에 다수의 LED 제어(74HC595), 지연선, 반도체 테스트에서 플립플롭을 염주처럼 연결하는 스캔 체인에도 사용됩니다.

시프트 레지스터의 일부 출력의 XOR를 입력으로 되돌리는 선형 피드백 시프트 레지스터(LFSR)의 대표적인 용도는?

  1. A의사 난수 패턴 생성이나 테스트에서의 패턴 생성·CRC 계산
  2. B정확한 시각 측정
  3. C아날로그 신호 증폭
정답과 해설 보기

정답: A. 의사 난수 패턴 생성이나 테스트에서의 패턴 생성·CRC 계산

LFSR은 적절한 탭을 선택하면 n비트에서 모두 0을 제외한 2ⁿ − 1가지 상태를 순환하는, 얼핏 무작위로 보이는 계열(M 계열)을 생성합니다. XOR와 플립플롭만으로 만들 수 있으므로 내장 테스트(BIST)의 패턴 생성과 결과 압축, 이더넷 등의 CRC 계산, 신호를 평균화하여 전자기 노이즈를 줄이는 스크램블러에 사용됩니다. 계열은 예측 가능하므로 암호용 난수로는 사용할 수 없습니다.

자주 묻는 질문

시프트 레지스터는 어디에 사용하나요?

시프트 레지스터는 직렬 데이터와 병렬 데이터 사이의 변환, 지연선과 카운터의 구성, LFSR로서의 의사 난수열 생성, 그리고 칩 테스트에 쓰이는 스캔 체인 구성에 사용됩니다.

존슨 카운터의 상태 수는 몇 개인가요?

플립플롭 n개로 만든 존슨 카운터는 2n개의 상태를 순환하며, 이는 같은 수의 플립플롭으로 만든 링 카운터의 두 배입니다.

Verilog에서 시프트 레지스터에 논블로킹 대입문을 써야 하는 이유는 무엇인가요?

블로킹 대입문을 쓰면 각 단이 즉시 갱신되어 다음 단이 같은 클록에서 새 값을 받게 되므로, 사슬이 하나의 단으로 축소됩니다. 논블로킹 대입문을 쓰면 모든 단이 에지 이전의 값을 받습니다.
