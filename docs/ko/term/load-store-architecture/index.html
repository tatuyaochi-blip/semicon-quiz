로드-스토어 아키텍처(load-store architecture)란?

메모리 접근은 로드와 스토어 명령어만 하고 산술 연산은 레지스터에서만 수행하는 ISA 방식입니다. RISC-V와 Arm이 채택하며, 명령어 형태가 균일하여 파이프라인 처리가 쉽습니다.

일본어 명칭: ロード・ストア・アーキテクチャ

로드-스토어 아키텍처(load-store architecture)은(는) ISA와 어셈블리 등 1개 분야의 연습 문제 1개에 나와요.

RISC-V와 같은 로드-스토어 아키텍처의 특징으로 올바른 것은?

  1. A덧셈 등의 연산 명령어가 메모리 상의 값을 직접 읽어 계산하고 결과를 메모리에 다시 쓴다
  2. B메모리를 읽고 쓸 수 있는 것은 로드 명령어와 스토어 명령어뿐이며, 연산은 레지스터끼리 수행한다
  3. C레지스터를 두지 않고 모든 값을 스택에 쌓아 계산한다
정답과 해설 보기

정답: B. 메모리를 읽고 쓸 수 있는 것은 로드 명령어와 스토어 명령어뿐이며, 연산은 레지스터끼리 수행한다

로드-스토어 아키텍처에서는 메모리의 값을 먼저 로드 명령어로 레지스터에 읽어 들이고, 덧셈이나 비교 같은 연산은 레지스터끼리 수행하며, 결과가 필요하면 스토어 명령어로 메모리에 다시 씁니다. 연산 명령어가 메모리를 직접 다루지 않으므로 명령어 형태가 균일해지고 파이프라인으로 처리하기 쉬워집니다. x86의 'add eax, [mem]'처럼 연산 명령어가 메모리를 읽을 수 있는 방식과는 대조적입니다.

해설 속 로드-스토어 아키텍처(load-store architecture)

  • 로드-스토어 아키텍처에서는 메모리의 값을 먼저 로드 명령어로 레지스터에 읽어 들이고, 덧셈이나 비교 같은 연산은 레지스터끼리 수행하며, 결과가 필요하면 스토어 명령어로 메모리에 다시 씁니다.
