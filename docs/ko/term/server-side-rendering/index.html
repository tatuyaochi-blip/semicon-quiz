서버 사이드 렌더링(SSR)란?

요청을 받을 때마다 서버에서 페이지의 HTML을 생성하여 돌려주는 방식. 브라우저는 도착한 HTML을 바로 표시할 수 있으므로 첫 표시가 빠르고, 검색 엔진에도 내용이 전달되기 쉽다. 브라우저에 최소한의 HTML과 JavaScript를 보내 브라우저 안에서 페이지를 조립하는 것이 클라이언트 사이드 렌더링(CSR), 빌드할 때 모든 페이지의 HTML을 미리 생성해 두는 것이 정적 사이트 생성(SSG)이다. 서버에서 만든 HTML을 표시한 후에 JavaScript로 조작할 수 있게 하는 구성도 많다.

일본어 명칭: サーバサイドレンダリング(SSR)

정답과 해설 보기

정답: C. SSG(정적 사이트 생성)

SSG로 만든 사이트는 정적 사이트로, 요청마다 서버에서 프로그램을 실행하지 않으므로 정적 파일을 배포하는 호스팅이나 CDN에서 그대로 빠르게 배포할 수 있고, 공격 대상이 되는 부분도 적어집니다. 예를 들어 문제나 용어집 페이지를 콘텐츠 데이터로부터 빌드로 생성하여 배포하는 사이트가 이에 해당하며, 내용을 바꾸었을 때는 다시 생성합니다. SSR은 요청마다 서버에서 HTML을 만드는 동적인 방식이고, CSR은 최소한의 HTML과 JavaScript를 보내 브라우저 안에서 페이지를 조립하는 방식입니다.
