이동 평균 필터(Moving Average Filter)란?

최근 N개 샘플의 평균을 출력하는 가장 간단한 저역 통과 필터. y[n] = (x[n] + x[n − 1] + … + x[n − N + 1])/N으로, 계수가 모두 1/N인 FIR 필터이다. 직류 이득은 1이고 주파수 fs/N의 정수배에서 이득이 0이 되므로, 예를 들어 전원 주기에 정확히 맞춘 구간에서 평균하면 전원 주파수와 그 고조파의 잡음을 제거할 수 있다. 계수가 대칭이므로 선형 위상이며, 지연은 (N − 1)/2샘플이다. 새 샘플을 더하고 가장 오래된 샘플을 빼서 합을 갱신하면 N과 관계없이 적은 연산으로 계산할 수 있다.

일본어 명칭: 移動平均フィルタ

도전해 보기: 이동 평균 필터(Moving Average Filter) 관련 문제

샘플링 주파수 8 kHz에서, 최근 8샘플의 평균을 구하는 이동 평균 필터 y[n] = (x[n] + x[n − 1] + … + x[n − 7])/8을 사용한다. 출력이 0이 되는 가장 낮은 주파수로 올바른 것은?

  1. A500 Hz
  2. B1 kHz
  3. C4 kHz
정답과 해설 보기

정답: B. 1 kHz

N샘플 이동 평균의 이득은 직류에서 (1 + 1 + … + 1)/N = 1이며, 주파수 fs/N의 정수배(직류 제외)에서 0이 됩니다. fs/N = 8000 ÷ 8 = 1 kHz의 사인파는 8샘플에서 정확히 1주기이므로, 그 평균은 0이 됩니다. 이동 평균은 계산이 간단한 저역 통과 필터이지만, 영점 사이에서 이득이 다시 올라가는 사이드 로브가 있어 차단 특성이 그다지 급준하지 않습니다.
