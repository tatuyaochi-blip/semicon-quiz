CXL란?

Compute Express Link의 약어. PCI Express 물리 계층을 사용해 CPU와 가속기·메모리 장치 사이에서 캐시 일관성을 유지한 메모리 공유를 가능하게 하는 규격.

일본어 명칭: CXL

CXL은(는) I/O 인터페이스와 버스, 차세대 메모리 등 2개 분야의 연습 문제 4개에 나와요.

분야: I/O 인터페이스와 버스

CXL이 만들어진 이유

PCI Express(PCIe)는 데이터를 효율적으로 전송하지만 장치 메모리를 CPU 캐시와 일관되게 유지하지는 않으므로, 가속기와 데이터를 공유하려면 소프트웨어가 버퍼를 복사하고 캐시를 플러시하거나 무효화해야 합니다. Compute Express Link(CXL)는 PCIe의 물리 계층, 커넥터, 전기적 신호 방식을 재사용하고, 캐시 일관성을 유지하며 CPU가 일반 로드·저장 명령으로 장치 메모리에 접근할 수 있게 하는 프로토콜을 추가합니다. CXL 1.x와 2.0은 레인당 32 GT/s인 PCIe 5.0 속도로 동작하고, CXL 3.x는 64 GT/s인 PCIe 6.0 속도로 넘어갑니다.

CXL의 세 가지 프로토콜

CXL.io는 사실상 PCIe와 같으며 장치 탐색, 구성, 인터럽트, DMA를 담당합니다. CXL.cache는 장치가 CPU 메모리를 자신의 캐시에 캐싱하고 하드웨어가 그 일관성을 유지하게 합니다. CXL.mem은 CPU가 장치에 연결된 메모리를 시스템 메모리의 일부처럼 읽고 쓸 수 있게 합니다. 장치는 보통 세 가지 유형으로 분류됩니다. 스마트 네트워크 카드 같은 Type 1 장치는 CXL.io와 CXL.cache를, 자체 메모리를 가진 Type 2 가속기는 세 가지 모두를, Type 3 메모리 확장 장치는 CXL.io와 CXL.mem을 사용합니다.

메모리 확장과 풀링

CPU에 직접 연결할 수 있는 DRAM은 메모리 채널 수와 DIMM 슬롯 수로 제한됩니다. CXL 메모리 확장 장치는 PCIe 방식의 링크를 통해 용량과 대역폭을 추가하며, CXL 스위치를 사용하면 메모리 풀을 여러 서버가 공유하고 필요한 곳에 할당할 수 있습니다. 접근 지연은 직접 연결된 DRAM보다 길며, 흔히 다른 CPU 소켓의 메모리에 접근하는 경우에 비유됩니다. 그래서 운영체제는 보통 CXL 메모리를 별도의 NUMA 노드로 보여 주고 계층(티어)으로 사용하며, 자주 접근하는 데이터는 로컬 DRAM에 둡니다.

메모리 계층에서의 CXL

DRAM과 NAND 플래시는 접근 시간이 수십 나노초 대 수십 마이크로초로 약 1000배 차이가 나며, 그 간극을 메우기 위해 스토리지 클래스 메모리가 제안되었습니다. 2022년 Intel이 상변화 메모리 기반의 Optane 제품을 단종하겠다고 발표한 이후, 이 영역의 상당 부분은 스토리지 쪽에서는 저지연 SLC NAND가, 메모리 쪽에서는 CXL 연결 DRAM이 차지하게 되었습니다. CXL은 또한 장치 측 메모리 컨트롤러가 CPU가 기본 지원하는 것과 다른 종류의 메모리를 사용할 수 있게 해 줍니다.

  2. BPCI Express의 물리 계층을 사용하여 CPU와 가속기나 메모리 장치 사이에서 캐시 일관성을 유지한 메모리 공유를 가능하게 하는 규격

정답과 해설 보기

정답: B. PCI Express의 물리 계층을 사용하여 CPU와 가속기나 메모리 장치 사이에서 캐시 일관성을 유지한 메모리 공유를 가능하게 하는 규격

PCI Express에서는 기기의 메모리와 CPU 캐시의 일관성이 하드웨어로 유지되지 않아 소프트웨어가 신경 써야 했습니다. CXL은 PCI Express와 같은 물리 계층 위에 캐시 일관성을 유지하는 통신과, CPU가 기기의 메모리를 일반 메모리처럼 읽고 쓰는 통신을 더한 규격입니다. 가속기와의 데이터 공유나 메모리 증설에 사용됩니다.

  1. ACPU에 직결된 DRAM보다 지연이 반드시 작아진다
  2. B전원을 꺼도 데이터가 반드시 사라지지 않게 된다
  3. CCPU의 메모리 채널 수에 얽매이지 않고 용량을 늘리거나 여러 서버가 메모리를 나눠 쓸 수 있다
정답과 해설 보기

정답: C. CPU의 메모리 채널 수에 얽매이지 않고 용량을 늘리거나 여러 서버가 메모리를 나눠 쓸 수 있다

CPU에 직접 연결할 수 있는 메모리 양은 메모리 채널과 슬롯 수로 상한이 정해집니다. CXL 메모리는 PCI Express 슬롯 등에 메모리 장치를 연결해 메모리를 늘릴 수 있을 뿐 아니라, 스위치를 사용해 여러 서버가 공유 용량을 융통할 수도 있습니다. 다만 직결 DRAM보다 지연이 크므로 자주 쓰는 데이터는 직결 메모리에 두는 등 계층으로 구분하여 사용합니다.

자주 묻는 질문

CXL은 무엇의 약자인가요?

CXL은 Compute Express Link의 약자로, PCI Express 물리 계층 위에 구축되어 CPU, 가속기, 메모리 장치 사이에 캐시 일관성을 갖춘 메모리 접근을 추가한 개방형 인터커넥트 표준입니다.

CXL과 PCIe의 차이는 무엇인가요?

같은 물리 계층과 슬롯을 공유하지만, 일반 PCIe 전송은 캐시 일관성이 없습니다. CXL은 CXL.cache와 CXL.mem 프로토콜을 추가해 장치와 CPU가 로드/저장 방식으로 일관성을 유지하며 메모리를 공유할 수 있게 합니다.

CXL Type 3 장치란 무엇인가요?

Type 3 장치는 CXL.io와 CXL.mem을 사용해 호스트에 추가 메모리 용량을 제공하는 메모리 확장 장치이며, 호스트 메모리를 자체적으로 캐싱하지는 않습니다.
