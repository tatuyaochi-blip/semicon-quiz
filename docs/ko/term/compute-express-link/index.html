CXL란?

Compute Express Link의 약어. PCI Express 물리 계층을 사용해 CPU와 가속기·메모리 장치 사이에서 캐시 일관성을 유지한 메모리 공유를 가능하게 하는 규격.

일본어 명칭: CXL

CXL은(는) I/O 인터페이스와 버스, 차세대 메모리 등 2개 분야의 연습 문제 4개에 나와요.

도전해 보기: CXL 관련 문제

CXL(Compute Express Link)에 대한 설명으로 올바른 것은?

  1. A칩렛끼리를 패키지 안에서 연결하기 위한 규격
  2. BPCI Express의 물리 계층을 사용하여 CPU와 가속기나 메모리 장치 사이에서 캐시 일관성을 유지한 메모리 공유를 가능하게 하는 규격
  3. C무선 LAN의 새로운 규격
정답과 해설 보기

정답: B. PCI Express의 물리 계층을 사용하여 CPU와 가속기나 메모리 장치 사이에서 캐시 일관성을 유지한 메모리 공유를 가능하게 하는 규격

PCI Express에서는 기기의 메모리와 CPU 캐시의 일관성이 하드웨어로 유지되지 않아 소프트웨어가 신경 써야 했습니다. CXL은 PCI Express와 같은 물리 계층 위에 캐시 일관성을 유지하는 통신과, CPU가 기기의 메모리를 일반 메모리처럼 읽고 쓰는 통신을 더한 규격입니다. 가속기와의 데이터 공유나 메모리 증설에 사용됩니다.

CXL을 이용한 메모리 확장(CXL 메모리)의 장점으로 올바른 것은?

  1. ACPU에 직결된 DRAM보다 지연이 반드시 작아진다
  2. B전원을 꺼도 데이터가 반드시 사라지지 않게 된다
  3. CCPU의 메모리 채널 수에 얽매이지 않고 용량을 늘리거나 여러 서버가 메모리를 나눠 쓸 수 있다
정답과 해설 보기

정답: C. CPU의 메모리 채널 수에 얽매이지 않고 용량을 늘리거나 여러 서버가 메모리를 나눠 쓸 수 있다

CPU에 직접 연결할 수 있는 메모리 양은 메모리 채널과 슬롯 수로 상한이 정해집니다. CXL 메모리는 PCI Express 슬롯 등에 메모리 장치를 연결해 메모리를 늘릴 수 있을 뿐 아니라, 스위치를 사용해 여러 서버가 공유 용량을 융통할 수도 있습니다. 다만 직결 DRAM보다 지연이 크므로 자주 쓰는 데이터는 직결 메모리에 두는 등 계층으로 구분하여 사용합니다.

해설 속 CXL

  • CXL은 PCI Express와 같은 물리 계층 위에 캐시 일관성을 유지하는 통신과, CPU가 기기의 메모리를 일반 메모리처럼 읽고 쓰는 통신을 더한 규격입니다.

    CXL을 이용한 메모리 확장(CXL 메모리)의 장점으로 올바른 것은?

  • CXL.io는 기기 검색이나 설정, 인터럽트 등에 사용하는, PCI Express와 거의 같은 통신입니다.

    CXL을 구성하는 3가지 프로토콜의 조합으로 올바른 것은?

  • 상변화 메모리를 사용한 Intel의 Optane이 대표적이었지만 2022년에 단종이 발표되어, 현재는 고속 SLC형 NAND나 CXL로 연결하는 메모리 등이 이 영역을 담당하고 있습니다.
