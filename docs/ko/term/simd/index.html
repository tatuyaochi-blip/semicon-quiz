SIMD란?

Single Instruction, Multiple Data의 약어. 하나의 명령으로 여러 데이터에 같은 연산을 동시에 수행하는 방식. 영상 처리와 AI 연산을 고속화한다.

일본어 명칭: SIMD

SIMD은(는) 컴파일러, GPU 프로그래밍, CPU와 아키텍처 등 5개 분야의 연습 문제 7개에 나와요.

분야: CPU와 아키텍처

도전해 보기: SIMD 관련 문제

GPU의 SIMT(단일 명령·다중 스레드) 방식과 CPU의 SIMD 명령의 차이로 올바른 것은?

  1. ASIMT는 하나의 데이터에 여러 명령을 동시에 수행하고, SIMD는 하나의 명령을 하나의 데이터에 수행한다
  2. BSIMT와 SIMD는 완전히 같은 것이며 이름만 다르다
  3. CSIMT에서는 각 스레드를 독립된 프로그램으로 작성할 수 있고 분기도 하드웨어가 처리하지만, SIMD에서는 프로그래머나 컴파일러가 폭이 정해진 벡터 명령을 명시적으로 사용한다
정답과 해설 보기

정답: C. SIMT에서는 각 스레드를 독립된 프로그램으로 작성할 수 있고 분기도 하드웨어가 처리하지만, SIMD에서는 프로그래머나 컴파일러가 폭이 정해진 벡터 명령을 명시적으로 사용한다

CPU의 SIMD에서는 4개나 8개의 데이터를 묶은 벡터 레지스터에 하나의 명령을 적용하므로, 프로그램은 벡터 폭을 의식하여 작성합니다. GPU의 SIMT에서는 프로그래머가 하나의 스레드 처리를 평범하게 작성하면 하드웨어가 32개씩 묶어 같은 명령으로 실행합니다. 스레드별로 분기해도 되며 하드웨어가 갈라진 경로를 차례로 실행하지만, 이때는 효율이 떨어집니다.

해설 속 SIMD

  • 벡터화에서는 예를 들어 4개 요소의 계산을 하나의 SIMD 명령으로 동시에 수행합니다.

    위의 루프를 SIMD 명령으로 벡터화하기 어려운 주된 이유는?

  • CPU의 SIMD에서는 4개나 8개의 데이터를 묶은 벡터 레지스터에 하나의 명령을 적용하므로, 프로그램은 벡터 폭을 의식하여 작성합니다.

    GPU의 SIMT(단일 명령·다중 스레드) 방식과 CPU의 SIMD 명령의 차이로 올바른 것은?

  • SIMD는 하나의 명령어로 여러 데이터에 같은 연산을 병렬로 수행하는 방식으로, 예를 들어 512비트 레지스터라면 32비트 수치 16개를 한 번에 계산할 수 있습니다.

    하나의 명령어로 여러 데이터에 같은 연산을 동시에 수행하는 방식은?

  • DSP나 SIMD 명령에 마련되어 있습니다.

    신호 처리에서 사용되는 포화 연산의 설명으로 올바른 것은 무엇입니까?

  • 자동 벡터화는 배열의 요소마다 같은 계산을 하는 루프를 찾아 여러 요소를 한꺼번에 처리하는 SIMD 명령으로 대체하는 최적화입니다.

    컴파일러의 자동 벡터화에서 사용되는 명령의 종류로 올바른 것은 무엇인가?

SIMD이(가) 나오는 문제 (7)

  1. 위의 루프를 SIMD 명령으로 벡터화하기 어려운 주된 이유는?
  2. GPU의 SIMT(단일 명령·다중 스레드) 방식과 CPU의 SIMD 명령의 차이로 올바른 것은?
  3. 하나의 명령어로 여러 데이터에 같은 연산을 동시에 수행하는 방식은?
  4. 신호 처리에서 사용되는 포화 연산의 설명으로 올바른 것은 무엇입니까?
  5. 컴파일러의 자동 벡터화에서 사용되는 명령의 종류로 올바른 것은 무엇인가?
  6. 위와 같이 x 좌표만 합산하는 처리를 구조체의 배열(각 성분을 별도의 배열로 만드는 형태)로 바꾸면 빨라지기 쉬운 이유는?
  7. 입자의 위치 x, y, z를 가진 데이터를 GPU에서 처리할 때, 메모리 병합 접근 측면에서 유리한 배치는?
