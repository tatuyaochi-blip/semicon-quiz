연산 융합(Operator Fusion)란?

여러 연산을 하나의 커널로 묶어, 중간 결과를 메모리에 쓰고 다시 읽는 부담을 없애는 최적화. 오퍼레이터 퓨전.

일본어 명칭: 演算の融合

정답과 해설 보기

정답: A. 여러 연산을 하나의 커널로 묶어, 중간 결과를 메모리에 쓰고 다시 읽는 수고를 없앤다

행렬 곱 뒤에 바이어스 덧셈, 활성화 함수, 정규화 등의 요소별 연산이 이어지는 경우가 많습니다. 이를 별개의 커널로 수행하면 매번 중간 결과를 메모리에 쓰고 다음 커널에서 다시 읽으므로, 계산보다 메모리 읽기/쓰기에 시간이 걸립니다. 하나의 커널로 묶으면 중간 결과를 레지스터나 칩 위의 메모리에 둔 채로 이어서 계산할 수 있습니다.
