해시 테이블(Hash Table)란?

키로부터 해시 함수로 저장할 위치를 계산하여, 평균 O(1)로 탐색·삽입·삭제를 할 수 있는 자료 구조. 서로 다른 키가 같은 위치가 되는 충돌을 체이닝이나 개방 주소법으로 처리한다. 해시 표라고도 한다.

일본어 명칭: ハッシュテーブル

해시 테이블(Hash Table)은(는) 자료 구조와 알고리즘, 메모리 계층 구조, 멀티코어와 동기화 등 3개 분야의 연습 문제 6개에 나와요.

분야: 자료 구조와 알고리즘

구조와 충돌 처리

해시 테이블은 키를 해시 함수로 정수로 바꾸고, 표의 크기로 나눈 나머지 등을 저장할 위치로 삼습니다. 키의 종류는 표의 크기보다 훨씬 많으므로, 서로 다른 키가 같은 위치가 되는 충돌은 피할 수 없습니다. 체이닝은 같은 위치의 원소를 연결 리스트 등으로 잇습니다. 개방 주소법은 표 안의 다른 빈 위치를 찾으며, 이웃을 차례로 조사하는 선형 탐사나 다른 해시 함수로 간격을 정하는 이중 해싱 등이 있습니다.

적재율과 재해싱

저장한 원소의 수를 표의 크기로 나눈 값을 적재율이라고 합니다. 체이닝에서는 리스트의 평균 길이가 적재율에 비례하고, 개방 주소법에서는 적재율이 1에 가까워지면 빈자리를 찾는 횟수가 급격히 늘어납니다. 그래서 적재율이 정해 둔 값을 넘으면 표를 2배 정도로 키워 모든 원소를 다시 넣습니다(재해싱). 1회의 재해싱에는 O(n)이 걸리지만, 키우는 간격이 배로 넓어지므로 추가 1회당 수고는 분할 상환 O(1)에 들어갑니다.

성능과 주의점

평균 O(1)은 해시 함수가 키를 표 전체에 고르게 흩뜨린다는 것이 전제입니다. 치우친 해시 함수나 의도적으로 충돌을 일으키는 입력(해시 플러딩 공격)에서는 최악 O(n)까지 느려지므로, 웹 서버 등에서는 난수 시드를 섞은 해시 함수를 사용합니다. 또한 해시 테이블은 원소를 순서대로 늘어놓아 갖지 않으므로, 범위 검색이나 순서대로의 열거에는 이진 탐색 트리나 B 트리가 더 적합합니다. 실제 속도는 캐시가 듣는 정도에도 좌우되어, 선형 탐사처럼 이웃을 조사하는 방식은 포인터를 따라가는 체이닝보다 빠른 경우가 많습니다.

정답과 해설 보기

정답: B. 서로 다른 키에서 같은 해시값(저장할 위치)이 구해지는 것

해시 테이블은 키로부터 해시 함수로 저장할 위치를 계산하여, 평균 O(1)로 탐색·삽입·삭제를 할 수 있는 자료 구조입니다. 키의 종류는 표의 크기보다 훨씬 많으므로, 서로 다른 키가 같은 위치가 되는 것(충돌)은 피할 수 없습니다. 그래서 같은 위치의 원소를 리스트로 잇는 체이닝이나, 비어 있는 다른 위치를 찾는 개방 주소법 등으로 충돌을 처리합니다. 같은 키에서는 반드시 같은 해시값이 구해지지 않으면 탐색을 할 수 없으며, 해시값에서 원래 키를 알 수 있는지는 암호에 사용할 때의 성질로, 충돌과는 별개의 이야기입니다.

크기 7인 해시 테이블(위치 0~6)에 해시 함수 h(k) = k mod 7로 키 10, 17, 24, 3을 이 순서로 저장한다. 충돌했을 때는 위치를 하나씩 뒤로 옮기며(6 다음은 0) 빈 위치를 찾는 선형 탐사법을 사용한다. 키 3이 저장되는 위치는?

  1. A위치 3
  2. B위치 4
  3. C위치 6
정답과 해설 보기

정답: C. 위치 6

네 키는 모두 7로 나눈 나머지가 3이므로, 전부 위치 3을 처음에 조사합니다. 10은 위치 3에 들어가고, 17은 위치 3이 차 있으므로 위치 4, 24는 위치 3, 4가 차 있으므로 위치 5에 들어갑니다. 3은 위치 3, 4, 5가 차 있으므로 위치 6에 저장됩니다. 이처럼 선형 탐사법에서는 채워진 위치가 뭉쳐서 늘어서고(클러스터), 나중에 오는 키일수록 조사하는 횟수가 늘어납니다.

자주 묻는 질문

해시 테이블과 해시 함수는 어떤 관계인가요?

해시 함수는 키로부터 정해진 범위의 값을 계산하는 함수이고, 해시 테이블은 그것을 저장할 위치의 계산에 사용하는 자료 구조입니다. 해시 테이블용 해시 함수는 속도와 고르게 흩어지는 성질을 중시하며, 암호용 해시 함수 같은 일방향성까지는 요구하지 않는 것이 보통입니다.

해시 테이블은 어디에 쓰이나요?

프로그래밍 언어의 딕셔너리(연관 배열)나 집합(set), 컴파일러의 심볼 테이블, 데이터베이스의 해시 조인이나 해시 인덱스, 캐시 관리 등 키로 값을 빠르게 찾는 장면의 대부분에서 쓰입니다.
