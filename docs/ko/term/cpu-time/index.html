CPU 시간(CPU time)란?

CPU가 해당 프로그램의 명령을 실행한 시간의 합계. 대기 시간은 포함하지 않으며 병렬로 동작하면 벽시계 시간보다 길어질 수 있다.

일본어 명칭: CPU時間

CPU 시간(CPU time)은(는) 성능 분석, 차량용 반도체와 기능 안전, 멀티코어와 동기화 등 4개 분야의 연습 문제 4개에 나와요.

분야: 성능 분석

CPU 시간과 벽시계 시간

벽시계 시간(wall-clock time)은 경과 시간 또는 실제 시간이라고도 하며, 사용자가 시작부터 끝까지 기다리는 시간입니다. 여기에는 디스크, 네트워크, 락을 기다리는 시간과 다른 프로그램에 할당된 타임 슬라이스가 포함됩니다. CPU 시간은 프로세서가 실제로 그 프로그램을 실행하는 데 쓴 시간만 셉니다. 유닉스 계열 시스템에서는 time 명령이 둘 다 보여 줍니다. real은 벽시계 시간이고, user와 sys는 CPU 시간을 프로그램 자체 코드의 실행 시간과 시스템 콜처럼 커널이 프로그램 대신 수행한 작업 시간으로 나눈 것입니다.

비율 읽는 법

두 값을 비교하면 시간이 어디에 쓰였는지 알 수 있습니다. 싱글 스레드 프로그램에서 벽시계 시간이 CPU 시간보다 훨씬 크면 대부분 대기 중이라는 뜻이며, 보통 I/O나 락을 기다리는 것이므로 더 빠른 프로세서는 거의 도움이 되지 않습니다. CPU 시간이 벽시계 시간에 가까우면 그 프로그램은 연산 바운드입니다. 여러 스레드가 병렬로 실행되면 총 CPU 시간이 벽시계 시간을 넘을 수 있습니다. 예를 들어 각각 10 s 동안 바쁜 스레드 4개는 약 10 s의 경과 시간 동안 약 40 s의 CPU 시간을 소비합니다.

CPU 성능 방정식

컴퓨터 아키텍처에서 프로그램의 CPU 시간은 명령어 수 × CPI(명령어당 평균 클록 사이클 수) × 클록 주기, 또는 동등하게 명령어 수 × CPI ÷ 클록 주파수로 표현됩니다. 이 방정식은 컴파일러와 명령어 세트(명령어 수), 마이크로아키텍처(CPI), 회로 기술(클록 속도)의 기여를 분리합니다. 또한 주파수를 높이는 대신 CPI가 나빠지는 것처럼 한 요소를 개선하면서 다른 요소를 희생하면 프로그램이 빨라지지 않을 수 있는 이유도 보여 줍니다.

예산으로서의 CPU 시간

바쁜 CPU 시간이 항상 유용한 작업인 것은 아닙니다. 오랫동안 점유된 락에서 스핀하는 스레드는 아무 일도 하지 않으면서 CPU 시간을 소모하며, 싱글 코어에서는 타임 슬라이스가 끝날 때까지 락 보유자를 오히려 지연시킬 수도 있습니다. 대기가 길면 슬립하는 뮤텍스를 써야 합니다. 실시간 시스템과 차량용 시스템에서는 CPU 시간을 태스크별로 할당하고 감시하며, 시간 분할(temporal partitioning)을 통해 오동작하는 낮은 중요도의 태스크가 안전 필수 소프트웨어에 필요한 실행 시간을 소비하지 못하도록 합니다.

실행 시간 측정 방법 중 '벽시계 시간'과 'CPU 시간'의 차이로 올바른 것은?

  1. A벽시계 시간은 시작부터 끝까지의 실제 경과 시간으로 입출력 대기 등도 포함하며, CPU 시간은 CPU가 그 프로그램을 실행하고 있던 시간만 센다
  2. B벽시계 시간과 CPU 시간은 반드시 같은 값이 된다
  3. CCPU 시간은 방의 시계로 측정한 시간을 말한다
정답과 해설 보기

정답: A. 벽시계 시간은 시작부터 끝까지의 실제 경과 시간으로 입출력 대기 등도 포함하며, CPU 시간은 CPU가 그 프로그램을 실행하고 있던 시간만 센다

벽시계 시간은 사용자가 실제로 기다리는 시간으로, 디스크나 네트워크 대기, 다른 프로그램에 순서를 양보하던 시간도 포함합니다. CPU 시간은 CPU가 그 프로그램의 명령어를 실행하던 시간의 합계입니다. 벽시계 시간이 CPU 시간보다 훨씬 길다면 무언가를 기다리는 시간이 길다는 것을 알 수 있습니다. 반대로 여러 스레드로 병렬 동작하면 CPU 시간의 합계가 벽시계 시간보다 길어집니다.

자주 묻는 질문

CPU 시간이 실제 시간보다 큰 이유는?

프로그램이 여러 코어에서 동시에 실행되는 여러 스레드나 프로세스를 사용했고, CPU 시간은 그 모두의 시간을 합산하기 때문입니다. 예를 들어 완전히 바쁜 스레드 4개는 경과 시간 1초당 약 4초의 CPU 시간을 누적합니다.

time 명령의 real, user, sys는 무슨 뜻인가요?

real은 경과한 벽시계 시간, user는 프로그램 자체 코드에서 소비한 CPU 시간, sys는 시스템 콜 처리처럼 커널이 프로그램을 대신해 소비한 CPU 시간입니다.

CPU 시간에 I/O 대기 시간이 포함되나요?

포함되지 않습니다. 프로그램이 디스크나 네트워크를 기다리는 동안에는 실행되고 있지 않으므로, 그 시간은 벽시계 시간에는 나타나지만 CPU 시간에는 나타나지 않습니다.
