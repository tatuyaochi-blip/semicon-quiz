아레니우스 모델(Arrhenius model)란?

반응이나 열화의 속도가 온도에 대해 exp(−Ea/kT)로 변한다고 보는 모델. 온도를 높인 가속 시험 결과로부터 실제 사용 온도에서의 수명을 추정하는 데 쓴다.

일본어 명칭: アレニウスモデル

아레니우스 모델(Arrhenius model)은(는) 신뢰성, SRAM과 플래시 메모리 등 2개 분야의 연습 문제 4개에 나와요.

분야: 신뢰성

도전해 보기: 아레니우스 모델(Arrhenius model) 관련 문제

활성화 에너지 0.7 eV인 고장 메커니즘에 대해 아레니우스 모델로 55 ℃에 대한 125 ℃의 가속 계수를 구하면 대략 얼마입니까?(볼츠만 상수 8.6×10⁻⁵ eV/K)

  1. A약 2배
  2. B약 80배
  3. C약 8000배
정답과 해설 보기

정답: B. 약 80배

가속 계수는 exp{(Ea/k)(1/T1 − 1/T2)}로 구합니다. T1 = 55+273 = 328 K, T2 = 125+273 = 398 K이므로 (0.7 / 8.6×10⁻⁵) × (1/328 − 1/398) ≈ 8140 × 0.000536 ≈ 4.4가 되어 exp(4.4) ≈ 80배입니다. 125 ℃에서 1000시간 시험은 55 ℃에서 약 8만 시간(약 9년)에 해당합니다. 온도를 섭씨 그대로 계산하면 크게 틀리므로 절대 온도로 환산하는 것이 중요합니다.

해설 속 아레니우스 모델(Arrhenius model)

  • 이 성질을 이용해 고온에서 보관하여 짧은 시간에 장기 보존을 추정하는 가속 시험(아레니우스 모델)이 이루어집니다.

    플래시 메모리의 데이터 보존(리텐션) 특성이 나빠지기 쉬운 조건은 무엇입니까?

  • 아레니우스 모델은 열화 반응 속도가 exp(−Ea/kT)(Ea: 활성화 에너지, k: 볼츠만 상수, T: 절대 온도)에 비례한다는 사고방식으로, 온도를 올리면 수명이 지수 함수적으로 짧아짐을 나타냅니다.

    온도를 올려 수명 시험 시간을 단축하는 가속 시험에서, 온도와 수명의 관계를 나타내기 위해 자주 사용되는 …

  • 정확하게는 아레니우스 모델을 사용합니다.

    많은 화학 반응이나 열화의 기준으로 자주 사용되는 '온도가 10 ℃ 오르면 반응 속도가 대략 2배가 된다'…

아레니우스 모델(Arrhenius model)이(가) 나오는 문제 (4)

  1. 활성화 에너지 0.7 eV인 고장 메커니즘에 대해 아레니우스 모델로 55 ℃에 대한 125 ℃의 가속 계수를 구하면 대략 얼마입니까?(볼츠만 상수 8.6×10⁻⁵ eV/K)
  2. 플래시 메모리의 데이터 보존(리텐션) 특성이 나빠지기 쉬운 조건은 무엇입니까?
  3. 온도를 올려 수명 시험 시간을 단축하는 가속 시험에서, 온도와 수명의 관계를 나타내기 위해 자주 사용되는 모델은?
  4. 많은 화학 반응이나 열화의 기준으로 자주 사용되는 '온도가 10 ℃ 오르면 반응 속도가 대략 2배가 된다'는 경험칙으로 생각할 때, 사용 온도를 10 ℃ 낮추면 수명은 대략 어떻게 됩니까?
