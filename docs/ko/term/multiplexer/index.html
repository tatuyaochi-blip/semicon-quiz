멀티플렉서(Multiplexer)란?

선택 신호에 따라 여러 입력 중 하나를 골라 출력하는 회로. 셀렉터라고도 한다. 반대로 하나의 입력을 여러 출력 중 하나로 분배하는 회로는 디멀티플렉서라고 한다.

일본어 명칭: マルチプレクサ

멀티플렉서(Multiplexer)은(는) HDL과 검증, 논리 회로, MOSFET 등 4개 분야의 연습 문제 5개에 나와요.

분야: 논리 회로

멀티플렉서가 입력을 선택하는 방식

2:1 멀티플렉서(MUX)는 Y = S'·A + S·B를 출력하여, 선택 신호 S가 0이면 입력 A를, 1이면 입력 B를 내보냅니다. 선택 비트가 n개이면 2ⁿ개의 입력 중 하나를 고를 수 있으므로, 8:1 MUX에는 선택선이 3개 필요합니다. CMOS에서 MUX는 AND-OR 또는 NAND-NAND 논리, 전송 게이트로 만들며, 입력이 많으면 2:1 MUX를 트리 형태로 구성합니다. MUX는 범용 논리 소자이기도 합니다. 데이터 입력을 진리표의 상수에 연결하면 2ⁿ:1 MUX로 임의의 n입력 불 함수를 구현할 수 있습니다.

멀티플렉서가 쓰이는 곳

프로세서의 데이터패스에는 MUX가 가득합니다. 레지스터나 즉치값 중에서 ALU 피연산자를 선택하고, 파이프라인 스톨을 피하기 위해 바이패스 경로로 결과를 포워딩하며, 다음 프로그램 카운터를 고르고, 공유 버스를 전환합니다. FPGA 논리 블록은 룩업 테이블(LUT)로 임의의 함수를 구현하는데, LUT는 MUX 트리를 통해 읽어 내는 작은 메모리입니다. 테스트 용이화 설계에서는 스캔 플립플롭의 데이터 입력에 MUX를 추가하여, 테스트 모드에서 플립플롭들을 시프트 레지스터로 연결할 수 있게 합니다. 보드에서는 아날로그 멀티플렉서로 여러 센서가 하나의 ADC를 공유하고, I2C 멀티플렉서로 주소가 같은 소자들을 분리합니다.

HDL과 논리 합성에서의 멀티플렉서

Verilog나 VHDL에서 조건부 대입문, if 문, case 문은 보통 멀티플렉서로 합성됩니다. 긴 if/else-if 체인은 우선순위를 암시하므로 2:1 MUX가 직렬로 이어져 지연이 길어지고, 상호 배타적인 값에 대한 case 문은 하나의 넓은 병렬 MUX가 되는 경향이 있습니다. 다만 최신 합성 도구는 어느 형태든 최적화하는 경우가 많습니다. 흔한 실수는 조합 논리에서 일부 분기에 대입을 빠뜨리는 것으로, 이 경우 순수한 MUX 대신 이전 값을 유지하기 위한 래치가 추론됩니다.

멀티플렉서와 디멀티플렉서, 디코더

디멀티플렉서는 멀티플렉서와 반대로 동작하여, 하나의 입력을 선택 비트로 지정한 2ⁿ개의 출력 중 하나로 보냅니다. 디코더는 n비트 코드를 2ⁿ개의 원핫(one-hot) 신호선으로 변환하며, 사실상 데이터 입력이 1로 고정된 디멀티플렉서입니다. 디코더는 대형 MUX의 선택 논리와 메모리의 워드 라인을 구동합니다. 통신 분야에서 멀티플렉싱은 더 넓게, 시간, 주파수 또는 부호를 이용해 여러 신호가 하나의 채널을 공유하는 것을 뜻합니다.

정답과 해설 보기

정답: C. 선택 신호에 따라 여러 입력 중 하나를 골라 출력한다

멀티플렉서(셀렉터)는 선택 신호의 값에 따라 여러 입력 중 하나를 골라 출력에 전달하는 회로로, 선택 신호가 n비트이면 2ⁿ개의 입력 중에서 고를 수 있습니다. CPU에서는 레지스터 값의 선택이나 버스 전환에 사용되며, FPGA의 논리 블록(LUT)도 메모리와 멀티플렉서로 임의의 논리를 구현합니다. 하나의 입력을 여러 출력 중 하나로 분배하는 회로는 디멀티플렉서입니다.

자주 묻는 질문

8:1 멀티플렉서에는 선택선이 몇 개 필요한가요?

2³ = 8이므로 3개가 필요합니다. 일반적으로 데이터 입력이 2ⁿ개인 MUX에는 n개의 선택선이 필요합니다.

멀티플렉서와 디멀티플렉서의 차이는 무엇인가요?

멀티플렉서는 여러 입력 중 하나를 골라 하나의 출력으로 전달합니다. 디멀티플렉서는 하나의 입력을 받아 여러 출력 중 하나로 보냅니다.

멀티플렉서로 어떻게 임의의 논리 함수를 구현하나요?

선택선을 함수의 입력 변수에 연결하고, 각 데이터 입력을 진리표에 따라 0 또는 1에 연결합니다. 그러면 MUX는 모든 입력 조합에 대해 진리표의 올바른 값을 출력하며, FPGA의 룩업 테이블이 바로 이 원리로 동작합니다.
