멀티플렉서(multiplexer)란?

선택 신호에 따라 여러 입력 중 하나를 골라 출력으로 내보내는 회로입니다. 반대로 하나의 입력을 여러 출력 중 하나로 보내는 것은 디멀티플렉서입니다.

일본어 명칭: マルチプレクサ

멀티플렉서(multiplexer)은(는) HDL과 검증, 논리 회로, MOSFET 등 4개 분야의 연습 문제 5개에 나와요.

분야: 논리 회로

멀티플렉서의 기능으로 올바른 것은 무엇입니까?

  1. A입력의 값을 1클록 동안 기억한다
  2. B입력 신호의 논리를 반전한다
  3. C선택 신호에 따라 여러 입력 중 하나를 골라 출력한다
정답과 해설 보기

정답: C. 선택 신호에 따라 여러 입력 중 하나를 골라 출력한다

멀티플렉서(셀렉터)는 선택 신호의 값에 따라 여러 입력 중 하나를 골라 출력으로 전달하는 회로이며, 선택 신호가 n비트이면 2ⁿ개의 입력 중에서 고를 수 있습니다. CPU에서는 레지스터 값의 선택이나 버스 전환에 쓰이고, FPGA의 논리 블록(LUT)도 메모리와 멀티플렉서로 임의의 논리를 구현합니다. 하나의 입력을 여러 출력 중 하나로 분배하는 회로는 디멀티플렉서입니다.

해설 속 멀티플렉서(multiplexer)

  • 멀티플렉서(셀렉터)는 선택 신호의 값에 따라 여러 입력 중 하나를 골라 출력으로 전달하는 회로이며, 선택 신호가 n비트이면 2ⁿ개의 입력 중에서 고를 수 있습니다.

    멀티플렉서의 기능으로 올바른 것은 무엇입니까?

  • 양방향으로 신호를 통과시킬 수 있어 멀티플렉서, 래치, 아날로그 스위치(4066 등)에 사용됩니다.

    nMOS와 pMOS를 병렬로 접속한 트랜스미션 게이트의 장점으로 올바른 것은?

  • 바꿀 수 없는 경우에는 마이크로컨트롤러의 다른 I2C 주변 회로를 사용하거나, I2C 선을 전환하는 부품(멀티플렉서)으로 나누어 연결합니다.

    같은 모델명의 I2C 온도 센서 2개를 같은 I2C 선에 연결하고 싶은데, 둘 다 같은 주소를 가지고 있습…

  • 그래서 내부에서는 멀티플렉서로 신호를 선택하는 기술로 하는 것이 일반적입니다.

    HDL에서 Z(하이 임피던스)를 출력하는 트라이스테이트 기술에 대해 일반적으로 올바른 것은?

  • if・else if의 연속은 "첫 번째 조건이 성립하면 그것, 아니면 다음을 조사한다"는 의미이므로, 우선순위가 붙은 회로(우선순위 인코더 같은 형태)가 되어 조건 수만큼 멀티플렉서가 직렬로 이어져 지연이 길어지기 쉽습니다.

    조합 회로에서 if・else if를 길게 이은 기술과 조건이 서로 겹치지 않는 case문 기술을 비교했을 …

멀티플렉서(multiplexer)이(가) 나오는 문제 (5)

  1. 멀티플렉서의 기능으로 올바른 것은 무엇입니까?
  2. nMOS와 pMOS를 병렬로 접속한 트랜스미션 게이트의 장점으로 올바른 것은?
  3. 같은 모델명의 I2C 온도 센서 2개를 같은 I2C 선에 연결하고 싶은데, 둘 다 같은 주소를 가지고 있습니다. 대책으로 올바른 것은 무엇입니까?
  4. HDL에서 Z(하이 임피던스)를 출력하는 트라이스테이트 기술에 대해 일반적으로 올바른 것은?
  5. 조합 회로에서 if・else if를 길게 이은 기술과 조건이 서로 겹치지 않는 case문 기술을 비교했을 때의 설명으로 올바른 것은?
