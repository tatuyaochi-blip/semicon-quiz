APC(첨단 공정 제어)란?

이전 공정의 계측 결과 등을 바탕으로 다음 로트나 웨이퍼의 장비 가공 조건을 자동으로 보정하는 제어. Run-to-Run 제어 등이 있으며 편차를 줄인다.

일본어 명칭: APC(先進的プロセス制御)

APC(첨단 공정 제어)은(는) 수율과 품질 관리, 계측과 분석 등 2개 분야의 연습 문제 3개에 나와요.

분야: 수율과 품질 관리

Run-to-Run 제어의 원리

첨단 공정 제어(APC)는 계측과 공정 장비 사이에 루프를 닫습니다. Run-to-Run(R2R) 제어에서는 레시피 조절 변수와 결과를 연결하는 간단한 모델을 사용합니다. 예를 들어 CMP의 연마 시간과 제거 두께의 관계입니다. 각 로트나 웨이퍼를 측정한 뒤, 제어기는 측정 노이즈를 걸러 내기 위해 흔히 지수 가중 이동 평균(EWMA)을 이용해 장비의 현재 거동 추정치를 갱신하고 다음 런의 설정값을 계산합니다. 최근 데이터에 가중치를 크게 주면 드리프트를 빠르게 따라가지만 노이즈도 쫓게 되고, 가중치를 작게 주면 부드럽지만 반응이 느립니다.

피드포워드와 피드백

APC는 두 방향의 정보를 사용합니다. 피드포워드 제어는 같은 웨이퍼에서 해당 공정 전에 측정한 값을 사용합니다. 들어오는 막이 두껍게 측정되면 다음 CMP 연마 시간을 늘려 최종 두께가 목표에 맞도록 합니다. 피드백 제어는 앞서 처리한 웨이퍼의 공정 후 측정 결과를 이용해 패드나 챔버의 노화에 따른 제거 속도 감소 같은 장비의 느린 변화를 보정합니다. 노광량, 포커스, 정렬 오프셋을 로트마다 조정하는 리소그래피의 오버레이 및 CD 제어는 두 가지를 결합한 대표적인 예입니다.

APC와 SPC의 비교

통계적 공정 관리(SPC)는 관리도로 공정을 감시하다가 파라미터가 관리 한계를 벗어나면 경보를 울리거나 장비를 멈춥니다. 즉 문제를 검출하지만 고치지는 않습니다. APC는 매 런마다 공정을 목표 쪽으로 능동적으로 조정하므로, 이상이 발생하기를 기다리지 않고 편차를 줄입니다. 둘은 함께 작동합니다. APC로 제어되는 출력에도 여전히 SPC 한계가 적용되며, 많은 팹에서는 장비 센서 신호를 실시간으로 감시하는 이상 감지 및 분류(FDC)도 APC의 범주에 포함합니다.

혼동하기 쉬운 용어

수율과 관련된 여러 약어가 APC와 비슷해 보이지만 하는 일은 다릅니다. 자동 결함 분류(ADC)는 리뷰 SEM의 결함 이미지를 파티클이나 스크래치 같은 범주로 분류합니다. 부품 평균 테스트(PAT)는 규격은 만족하더라도 로트 안에서 테스트 결과가 통계적 이상값인 칩을 불량 처리하는 기법으로, 차량용 품질에 사용됩니다. ATPG(자동 테스트 패턴 생성)는 로직용 테스트 벡터를 만듭니다. 이 가운데 웨이퍼의 가공 방식을 바꾸는 것은 APC뿐이며, 나머지는 결함을 분류하거나 완성된 칩을 선별합니다.

도전해 보기: APC(첨단 공정 제어) 관련 문제

검사에서 발견된 결함을 SEM으로 촬영하고 그 이미지로부터 결함 종류를 자동으로 분류하는 기능은?

  1. AATPG
  2. B자동 결함 분류(ADC)
  3. CAPC
정답과 해설 보기

정답: B. 자동 결함 분류(ADC)

결함 검사 장비는 웨이퍼 1장에서 수천 개의 결함을 검출하기도 하며, 각각의 원인을 조사하려면 종류 분류가 필요합니다. 자동 결함 분류(ADC)는 리뷰 SEM의 이미지로부터 이물, 패턴 결함, 스크래치 등으로 자동 분류하여 원인 공정이나 장비의 특정을 앞당깁니다. 최근에는 머신러닝도 활용되고 있습니다. ATPG는 테스트 패턴 생성, APC는 공정 자동 제어입니다.

앞 공정의 계측 결과 등을 바탕으로 다음 로트나 웨이퍼의 장비 가공 조건을 자동으로 보정하는 제어는?

  1. AFMEA
  2. B파레토 분석
  3. CAPC(Run-to-Run 제어 등)
정답과 해설 보기

정답: C. APC(Run-to-Run 제어 등)

APC(Advanced Process Control)는 계측 데이터를 사용해 장비 조건을 자동으로 조정하여 공정의 변동을 줄이는 제어입니다. 대표적인 Run-to-Run 제어에서는 예를 들어 앞 공정에서 측정한 막 두께가 두꺼우면 다음 CMP 시간을 늘립니다. 이상을 감시하여 멈추는 SPC에 대해, 적극적으로 보정하여 중심에 가깝게 만드는 방법입니다. FMEA는 사전 리스크 평가, 파레토 분석은 중점 항목 발견에 사용합니다.

자주 묻는 질문

반도체 제조에서 APC와 SPC의 차이는 무엇인가요?

SPC는 관리도로 공정 데이터를 감시하다가 공정이 관리 상태를 벗어나면 알리거나 멈춥니다. APC는 같은 종류의 측정값을 이용해 다음 로트나 웨이퍼의 레시피를 자동으로 조정하여 편차를 능동적으로 줄입니다.

Run-to-Run 제어란 무엇인가요?

이전 런의 측정 결과를 바탕으로 런과 런 사이에 장비 레시피를 갱신하는 APC의 한 형태입니다. 예를 들어 앞선 웨이퍼의 측정된 제거량으로 CMP 연마 시간을 조정합니다. 한 런 도중에는 아무것도 바꾸지 않고 느린 드리프트를 보정합니다.

APC의 피드포워드 제어란 무엇인가요?

앞 공정에서 측정한 입고 웨이퍼의 값을 이용해 현재 공정의 설정을 정하는 제어입니다. 예를 들어 들어오는 막이 평소보다 두꺼우면 연마 시간을 늘려 최종 두께가 목표에 맞도록 합니다.
