명령어 집합 구조(ISA)란?

프로세서가 실행할 수 있는 명령어와 레지스터 등 소프트웨어 관점에서의 프로세서 사양. x86, Arm, RISC-V 등이 있다.

일본어 명칭: 命令セットアーキテクチャ(ISA)

명령어 집합 구조(ISA)은(는) ISA와 어셈블리, CPU와 아키텍처, 성능 분석 등 4개 분야의 연습 문제 12개에 나와요.

동일한 명령어 집합 아키텍처(ISA)를 채택한 두 CPU에 대해 올바른 것은?

  1. A같은 회로 구성으로 만들어지므로 성능도 소비 전력도 같다
  2. B내부 회로 구성이 달라도 같은 기계어 프로그램을 실행할 수 있다
  3. C같은 반도체 공장에서 같은 제조 공정을 사용해 만들어야 한다
정답과 해설 보기

정답: B. 내부 회로 구성이 달라도 같은 기계어 프로그램을 실행할 수 있다

ISA는 명령어의 종류, 명령어의 비트 배열, 레지스터의 수 등을 정한 소프트웨어와 하드웨어 사이의 약속입니다. 파이프라인 단수, 캐시 크기, 분기 예측 방식 같은 내부 구조는 마이크로아키텍처라고 하며 ISA와 별도로 결정됩니다. 그래서 같은 ISA라도 작은 저전력 코어와 큰 고성능 코어가 있어 성능도 전력도 다르지만 같은 기계어 프로그램이 동작합니다. 제조 공장이나 공정도 ISA와는 관계가 없습니다.

해설 속 명령어 집합 구조(ISA)

  • ISA는 명령어의 종류, 명령어의 비트 배열, 레지스터의 수 등을 정한 소프트웨어와 하드웨어 사이의 약속입니다.

    동일한 명령어 집합 아키텍처(ISA)를 채택한 두 CPU에 대해 올바른 것은?

  • ARM, x86, RISC-V는 명령어 세트 아키텍처(ISA)의 이름으로, 프로세서가 이해하는 명령어의 종류, 레지스터, 메모리를 다루는 방식 등 소프트웨어와 하드웨어 사이의 약속을 정합니다.

    ARM, x86, RISC-V라는 이름이 주로 나타내는 것은?

  • RISC-V는 2010년 캘리포니아대학교 버클리에서 개발이 시작된 오픈 ISA로, 사양이 공개되어 있고 라이선스 비용 없이 누구나 구현할 수 있습니다.

    RISC-V의 특징으로 올바른 것은?

  • 명령어와 거의 1대1로 대응하므로 ISA가 다르면 어셈블리도 다릅니다.

    어셈블리 언어와 기계어의 관계로 올바른 것은?
