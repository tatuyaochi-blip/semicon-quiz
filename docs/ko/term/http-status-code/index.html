HTTP 상태 코드(HTTP Status Code)란?

HTTP 응답의 첫 줄에 들어가는 3자리 수로, 요청의 결과를 나타낸다. 백의 자리로 분류하며, 1xx는 정보, 2xx는 성공(200 OK, 201 Created, 204 No Content), 3xx는 리다이렉트(301 Moved Permanently, 302 Found, 304 Not Modified), 4xx는 클라이언트 측 오류(400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found), 5xx는 서버 측 오류(500 Internal Server Error, 503 Service Unavailable)를 나타낸다. 401은 인증 정보가 없거나 올바르지 않을 때, 403은 인증되었더라도 권한이 없을 때 사용한다.

HTTP의 상태 코드와 그 의미의 조합으로 올바른 것은?

  1. A301: 요구된 리소스가 일시적으로 다른 URL에 있다
  2. B404: 요구된 리소스를 서버에서 찾지 못했다
  3. C503: 요청의 작성 방식에 오류가 있어 서버가 이해하지 못했다
정답과 해설 보기

정답: B. 404: 요구된 리소스를 서버에서 찾지 못했다

상태 코드는 3자리 수로, 백의 자리가 분류를 나타냅니다. 2xx는 성공(200 OK, 201 Created, 204 No Content), 3xx는 리다이렉트(301 Moved Permanently, 302 Found, 304 Not Modified), 4xx는 클라이언트 측 오류(400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found), 5xx는 서버 측 오류(500 Internal Server Error, 503 Service Unavailable)입니다. 404는 URL로 나타낸 리소스를 서버에서 찾지 못했음을 나타냅니다.

회원제 웹사이트에서 로그인한 일반 회원이 관리자에게만 허용된 페이지를 요청했다. 서버는 이용자가 누구인지 확인했지만, 이 페이지에 대한 접근은 허가하지 않는다. 이때 돌려줄 상태 코드로 가장 적절한 것은?

  1. A401 Unauthorized
  2. B403 Forbidden
  3. C404 Not Found
정답과 해설 보기

정답: B. 403 Forbidden

403 Forbidden은 서버가 요청을 이해한 뒤 접근을 허가하지 않음을 나타냅니다. 401 Unauthorized는 이름과 달리 인증 정보가 없거나 올바르지 않음을 나타내는 코드로, WWW-Authenticate 헤더로 인증 방법을 알립니다. 이 상황에서는 이용자가 누구인지 확인되었고 부족한 것은 권한(인가)이므로 403이 해당합니다. 관리 화면이 있다는 것 자체를 알리고 싶지 않을 때 일부러 404를 돌려주는 설계도 있지만, 상황을 그대로 나타내는 것은 403입니다.
