링커 스크립트(Linker Script)란?

각 섹션을 메모리의 어느 주소에 배치할지 링커에 지시하는 파일. 임베디드 개발에서 플래시와 RAM 배치, 인터럽트 벡터의 주소를 정하는 데 사용한다.

일본어 명칭: リンカスクリプト

링커 스크립트(Linker Script)은(는) 링커, 로더, 실행 파일 등 1개 분야의 연습 문제 2개에 나와요.

분야: 링커, 로더, 실행 파일

링커 스크립트가 기술하는 것

컴파일러가 만드는 오브젝트 파일에서 코드와 데이터는 .text(명령어), .rodata(상수), .data(초기화된 변수), .bss(0으로 초기화되는 변수) 같은 섹션으로 묶여 있지만 최종 주소는 없습니다. 링커 스크립트는 이들을 어떻게 결합할지 링커에 지시합니다. GNU ld 문법에서 MEMORY 블록은 시작 주소와 길이로 영역을 선언하며(예: 한 주소에 플래시, 다른 주소에 RAM), SECTIONS 블록은 입력 섹션을 출력 섹션에 매핑하고 각각을 영역에 할당합니다. 영역이 넘치면 링커가 오류를 보고합니다.

임베디드 시스템에 필요한 이유

PC에서는 운영체제의 로더가 프로그램이 메모리의 어디에 놓일지 정하므로, 기본 링커 스크립트로 거의 모든 경우가 해결됩니다. OS가 없는 마이크로컨트롤러는 전원이 켜지면 고정된 주소에서 실행을 시작하므로, 프로그램을 정확한 메모리 맵에 맞춰 빌드해야 합니다. 인터럽트 벡터 테이블은 하드웨어가 기대하는 위치에 있어야 하고, 코드와 상수는 비휘발성 플래시에, 쓰기 가능한 변수와 힙, 스택은 RAM에 있어야 합니다. 같은 제품군의 다른 칩은 메모리 크기만 달라 링커 스크립트만 바꾸면 되는 경우가 많습니다.

로드 주소와 실행 주소

초기화된 변수는 특별한 문제를 안고 있습니다. 초기값은 전원이 꺼져도 남아 있어야 하므로 플래시에 저장되지만, 프로그램이 값을 쓰므로 실행 중에는 RAM에 있어야 합니다. 그래서 링커 스크립트는 .data에 플래시의 로드 주소와 RAM의 실행 주소라는 두 주소를 부여합니다. 또한 .data와 .bss의 시작과 끝, 그리고 흔히 스택의 최상단을 표시하는 심볼도 정의합니다. 스타트업 코드는 이 심볼들을 이용해 main을 호출하기 전에 .data를 플래시에서 RAM으로 복사하고 .bss를 0으로 채워, C가 약속하는 초기 상태를 만듭니다.

흔한 함정

베어메탈 프로젝트의 많은 문제는 링커 스크립트에서 비롯됩니다. 사용하지 않는 섹션 제거가 활성화되어 있으면, 벡터 테이블처럼 하드웨어만 참조하는 섹션은 유지하도록 표시하지 않는 한 버려질 수 있습니다. 스택 영역 크기를 너무 작게 잡으면 링크 오류는 나지 않지만 실행 중에 다른 데이터를 조용히 덮어씁니다. 섹션을 잘못된 로드 주소에 배치하면 변수가 쓰레기 초기값을 갖게 됩니다. 링커가 생성할 수 있는 맵 파일에는 모든 심볼의 주소와 각 영역의 사용량이 나와 있으므로, 이를 읽는 것이 결과를 확인하는 표준적인 방법입니다.

정답과 해설 보기

정답: A. 각 섹션을 플래시나 RAM 등 어느 주소에 배치할지 링커에 지시한다

PC의 OS에서는 로더가 주소를 정하지만, 마이크로컨트롤러에서는 전원을 켠 시점의 주소가 그대로 사용됩니다. 링커 스크립트에는 플래시와 RAM의 시작 주소와 크기를 쓰고, .text나 상수는 플래시에, .data, .bss, 스택은 RAM에 두는 식으로 배치를 지정합니다. 인터럽트 벡터처럼 정해진 주소에 놓아야 하는 것도 여기서 지정합니다.

자주 묻는 질문

링커 스크립트는 무엇에 쓰나요?

링커 스크립트는 어떤 메모리 영역이 있는지, 각 코드와 데이터 섹션을 어느 주소에 배치할지 링커에 알려 줍니다. 임베디드 프로젝트에서는 코드를 플래시에, 변수를 RAM에, 인터럽트 벡터 테이블을 정해진 주소에 두는 데 사용합니다.

.data와 .bss의 차이는 무엇인가요?

.data는 0이 아닌 초기값을 가진 변수를 담으며, 이 값은 플래시에 저장되었다가 시작 시 RAM으로 복사됩니다. .bss는 0에서 시작하는 변수를 담으므로 플래시 공간을 차지하지 않고, main이 실행되기 전에 RAM에서 0으로 지워지기만 합니다.

링커 스크립트에서 .data에 주소가 두 개인 이유는?

초기값은 비휘발성 플래시에 저장해야 하지만, 변수는 실행 중에 수정되므로 RAM에 있어야 합니다. 로드 주소는 플래시에 있는 사본을, 실행 주소는 코드가 실제로 사용하는 RAM 위치를 가리킵니다.
