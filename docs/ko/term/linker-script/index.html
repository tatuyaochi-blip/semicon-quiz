링커 스크립트(linker script)란?

각 섹션을 어느 메모리 주소에 배치할지 링커에 알려 주는 파일입니다. 임베디드 개발에서 플래시와 RAM의 배치 및 인터럽트 벡터 주소를 고정하는 데 사용합니다.

일본어 명칭: リンカスクリプト

링커 스크립트(linker script)은(는) 링커, 로더, 실행 파일 등 1개 분야의 연습 문제 2개에 나와요.

임베디드 개발에서 사용하는 링커 스크립트의 역할로 올바른 것은?

  1. A각 섹션을 플래시나 RAM 등의 어느 주소에 배치할지 링커에 지시한다
  2. B프로그램 테스트를 자동으로 실행하는 절차를 적는다
  3. C소스 코드 작성 규칙을 정하고 위반을 알려 준다
정답과 해설 보기

정답: A. 각 섹션을 플래시나 RAM 등의 어느 주소에 배치할지 링커에 지시한다

PC의 OS에서는 로더가 주소를 정하지만, 마이컴에서는 전원을 켠 시점의 주소가 그대로 사용됩니다. 링커 스크립트에는 플래시와 RAM의 시작 주소와 크기를 적고, .text나 상수는 플래시에, .data와 .bss, 스택은 RAM에 놓는 식으로 배치를 지정합니다. 인터럽트 벡터처럼 정해진 주소에 놓아야 하는 것도 여기서 지정합니다.

해설 속 링커 스크립트(linker script)

  • 링커 스크립트에는 플래시와 RAM의 시작 주소와 크기를 적고, .text나 상수는 플래시에, .data와 .bss, 스택은 RAM에 놓는 식으로 배치를 지정합니다.

    임베디드 개발에서 사용하는 링커 스크립트의 역할로 올바른 것은?

  • 링커 스크립트에서는 .data에 대해 「플래시에 놓는 주소」와 「실행 시 RAM에서 사용하는 주소」를 따로 지정합니다.
