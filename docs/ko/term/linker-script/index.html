링커 스크립트(Linker Script)란?

각 섹션을 메모리의 어느 주소에 배치할지 링커에 지시하는 파일. 임베디드 개발에서 플래시와 RAM 배치, 인터럽트 벡터의 주소를 정하는 데 사용한다.

정답과 해설 보기

정답: A. 각 섹션을 플래시나 RAM 등 어느 주소에 배치할지 링커에 지시한다

PC의 OS에서는 로더가 주소를 정하지만, 마이크로컨트롤러에서는 전원을 켠 시점의 주소가 그대로 사용됩니다. 링커 스크립트에는 플래시와 RAM의 시작 주소와 크기를 쓰고, .text나 상수는 플래시에, .data, .bss, 스택은 RAM에 두는 식으로 배치를 지정합니다. 인터럽트 벡터처럼 정해진 주소에 놓아야 하는 것도 여기서 지정합니다.

해설 속 링커 스크립트(Linker Script)

  • 링커 스크립트에는 플래시와 RAM의 시작 주소와 크기를 쓰고, .text나 상수는 플래시에, .data, .bss, 스택은 RAM에 두는 식으로 배치를 지정합니다.

  • 링커 스크립트에서는 .data에 대해 '플래시에 두는 주소'와 '실행 시 RAM에서 사용하는 주소'를 따로 지정합니다.
