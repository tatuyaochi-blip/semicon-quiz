로우해머(Rowhammer)란?

DRAM에서 같은 행을 짧은 시간에 여러 번 활성화하면 인접 행 셀의 전하가 소실되어 데이터가 반전되는 현상. 보안 공격에 악용될 수 있어 DRAM과 메모리 컨트롤러에서 대책이 마련되어 있다.

일본어 명칭: ロウハンマー

로우해머(Rowhammer)은(는) 하드웨어 보안 등 1개 분야의 연습 문제 1개에 나와요.

분야: DRAM

도전해 보기: 로우해머(Rowhammer) 관련 문제

DRAM 로우해머(Rowhammer)에 대한 대책에 해당하는 것은 무엇입니까?

  1. ADRAM 용량을 절반으로 한다
  2. B여러 번 활성화된 행의 인접 행을 일찍 리프레시하거나(TRR 등) 리프레시 빈도를 높인다
  3. CCPU 클럭을 멈춘다
정답과 해설 보기

정답: B. 여러 번 활성화된 행의 인접 행을 일찍 리프레시하거나(TRR 등) 리프레시 빈도를 높인다

로우해머는 어떤 행을 짧은 시간에 여러 번 활성화하면 전기적 간섭으로 인접 행의 셀 전하가 새어 비트가 반전되는 현상입니다. 권한 없는 프로그램이 다른 프로세스나 커널의 데이터를 바꿔 쓰는 공격에 사용될 우려가 있습니다. 대책으로 많이 활성화된 행의 인접 행을 추가로 리프레시하는 구조, 리프레시 빈도를 높이는 방법, ECC로 반전을 발견하고 정정하는 방법 등이 조합됩니다.
