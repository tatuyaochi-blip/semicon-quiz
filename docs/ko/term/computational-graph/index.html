계산 그래프(Computational Graph)란?

연산을 노드로, 텐서의 전달을 화살표로 하여 모델의 계산을 나타낸 그림. 자동 미분과 AI 컴파일러 최적화의 토대가 된다.

일본어 명칭: 計算グラフ

계산 그래프(Computational Graph)은(는) AI 하드웨어·소프트웨어 스택 등 1개 분야의 연습 문제 4개에 나와요.

분야: AI 하드웨어·소프트웨어 스택

노드, 엣지, 그리고 그것이 나르는 것

계산 그래프는 보통 방향성 비순환 그래프(DAG)입니다. 노드는 행렬 곱셈, 합성곱, 덧셈, 활성화 함수 같은 연산이고, 엣지는 텐서로서 각각 정해진 형상과 데이터 형식을 가지며 그것을 만드는 연산에서 그것을 소비하는 연산으로 흐릅니다. 입력과 학습 가능한 가중치는 소스 노드로 나타납니다. 의존 관계가 명시적이므로 어떤 연산이 병렬로 실행될 수 있고 어떤 연산이 기다려야 하는지 그래프에서 한눈에 알 수 있으며, 그래프를 만든 Python 코드와 독립적으로 모델을 완전하고 분석 가능한 형태로 소프트웨어에 제공합니다.

그래프와 자동 미분

학습에는 모든 가중치에 대한 손실의 기울기(그래디언트)가 필요합니다. 순전파 중에 프레임워크가 그래프를 기록하고, 역방향 모드 자동 미분이 손실에서부터 그래프를 거꾸로 따라가며 각 연산의 국소 미분 규칙과 연쇄 법칙을 적용해 기울기를 누적합니다. 이것이 역전파입니다. 이를 위해서는 순전파에서 저장해 둔 중간 출력(활성값)이 필요하며, 학습이 추론보다 훨씬 많은 메모리를 쓰는 이유가 이것입니다. 활성값 체크포인팅은 일부 활성값을 버렸다가 역전파 때 다시 계산함으로써 연산량을 늘리는 대신 메모리를 절약합니다.

정적 그래프와 동적 그래프

정적인 define-and-run 방식에서는 그래프 전체를 먼저 만든 뒤 실행하므로 전역 최적화가 쉽지만, 데이터에 의존하는 제어 흐름과 디버깅이 복잡해집니다. 동적인 define-by-run 또는 eager 방식에서는 프로그램이 실행되는 대로 연산이 즉시 실행되고 그래프가 그때그때 기록되므로 유연하지만, 연산 간 최적화의 여지가 거의 없습니다. 현대 프레임워크는 흔히 두 가지를 섞습니다. 코드는 eager 방식으로 작성하고, 컴파일 단계에서 그래프를 트레이스하거나 캡처해 실행 전에 컴파일러가 최적화하도록 합니다.

컴파일러와 런타임이 그래프로 하는 일

AI 컴파일러는 코드를 생성하기 전에 그래프를 재작성합니다. 연산자 퓨전은 행렬 곱셈, 바이어스 덧셈, 활성화 같은 연쇄를 하나의 커널로 합쳐, 중간 텐서가 DRAM을 왕복하지 않고 온칩 메모리에 머물게 합니다. 그 밖의 패스로는 상수 폴딩, 사용되지 않는 노드 제거, 텐서 메모리 레이아웃 선택, 캐시나 스크래치패드에 맞추는 타일링, 수명이 겹치지 않는 버퍼를 재사용하는 메모리 계획이 있습니다. ONNX(Open Neural Network Exchange) 같은 교환 형식은 그래프와 가중치를 직렬화해, 서로 다른 런타임과 하드웨어 툴체인이 같은 모델을 실행할 수 있게 합니다.

정답과 해설 보기

정답: C. 연산을 노드, 데이터(텐서)의 전달을 화살표로 하여 모델의 계산을 표현한 도식

계산 그래프는 행렬 곱, 덧셈, 활성화 함수 등의 연산을 노드로, 그 사이를 흐르는 텐서를 화살표로 한 모델 계산의 설계도입니다. 프레임워크는 이 그래프를 거꾸로 따라가며 역전파의 기울기를 자동으로 계산하고, 컴파일러는 그래프 전체를 보고 융합이나 재배열 최적화를 수행합니다. 어떤 연산이 독립적으로 병렬 실행될 수 있는지도 그래프에서 알 수 있습니다.

자주 묻는 질문

딥러닝에서 계산 그래프란

모델을 연산(노드)과 연산끼리 주고받는 텐서(엣지)로 연결해 나타낸 것입니다. 프레임워크는 이를 이용해 기울기를 자동으로 계산하고, 컴파일러는 실행을 최적화하는 데 사용합니다.

연산자 퓨전으로 신경망이 빨라지는 이유

활성화나 정규화 같은 많은 연산은 메모리 율속이어서, 출력을 DRAM에 쓰고 다시 읽는 시간이 대부분을 차지합니다. 이들을 하나의 커널로 합치면 중간 결과가 칩 위에 머물러 메모리 트래픽이 줄어듭니다.

eager 실행과 그래프 모드 차이

eager 실행은 Python이 각 연산에 도달하는 즉시 실행하고, 그래프 모드는 그래프 전체를 먼저 만들거나 캡처한 뒤 최적화해 실행합니다. eager는 디버깅이 쉽고, 그래프 모드는 퓨전 등 모델 전체에 걸친 최적화가 가능합니다.
