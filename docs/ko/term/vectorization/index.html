벡터화(vectorization)란?

루프 안에서 요소마다 하는 같은 계산을 SIMD 명령을 사용해 여러 요소를 한꺼번에 처리하는 형태로 바꾸는 최적화. 반복 간에 데이터 의존이 없어야 한다.

일본어 명칭: ベクトル化

벡터화(vectorization)은(는) 컴파일러, 메모리 계층 구조 등 2개 분야의 연습 문제 4개에 나와요.

정답과 해설 보기

정답: B. 여러 데이터를 동시에 다루는 SIMD 명령

자동 벡터화는 배열의 요소마다 같은 계산을 하는 루프를 찾아 여러 요소를 한꺼번에 처리하는 SIMD 명령으로 대체하는 최적화입니다. 예를 들어 128비트 SIMD 레지스터라면 32비트 수를 4개 동시에 더할 수 있으므로, 잘 되면 루프의 연산 횟수가 4분의 1이 됩니다. 반복 사이에 의존이 없을 것, 데이터의 배열이 연속일 것 등이 조건이 되며, 포인터가 겹칠 가능성이 있으면 보류되기도 합니다. 인터럽트나 캐시 조작 명령과는 관계가 없습니다.

해설 속 벡터화(vectorization)

  • 벡터화에서는 예를 들어 4개 요소의 계산을 하나의 SIMD 명령으로 동시에 수행합니다.

  • 결과의 차이를 허용하는 설정(고속 수학 설정 등)을 선택하면 벡터화를 위해 재배열하기도 합니다.
