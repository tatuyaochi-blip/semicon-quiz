정상 편차(Steady-state Error)란?

제어계의 응답이 수렴한 뒤에 남는 목표값과 제어량의 차. 오프셋이라고도 부른다. 단위 피드백 시스템에서는 계단 목표값에 대해 1/(1 + Kp)(Kp = G(0)은 위치 편차 상수)가 되며, 전향 경로에 적분을 포함하지 않는(0형) 시스템에서는 0이 되지 않는다. 적분을 1개 포함하는 1형 시스템에서는 계단 입력에 대한 정상 편차가 0이 되고, 램프 목표값에 대해서는 1/Kv(Kv는 속도 편차 상수)의 편차가 남는다. PI 제어의 적분 동작은 이 편차를 없애기 위해 쓰인다.

일본어 명칭: 定常偏差

정상 편차(Steady-state Error)은(는) 제어 공학의 기초 등 1개 분야의 연습 문제 5개에 나와요.

도전해 보기: 정상 편차(Steady-state Error) 관련 문제

단위 피드백 시스템에서 전향 전달 함수가 G(s) = 9/(1 + 2s)이다. 크기 1의 계단 목표값에 대한 정상 편차로 올바른 것은?

  1. A0
  2. B0.1
  3. C약 0.11
정답과 해설 보기

정답: B. 0.1

단위 피드백 시스템의 계단 입력에 대한 정상 편차는 1/(1 + Kp)이며, Kp = G(0)을 위치 편차 상수라고 부릅니다. 여기서는 Kp = 9이므로 정상 편차는 1/(1 + 9) = 0.1입니다. 전향 경로에 적분을 포함하지 않는(0형) 시스템에서는 이득을 올리면 편차는 작아지지만 0이 되지는 않습니다. 편차를 0으로 하려면 PI 제어 등으로 적분을 더합니다.

폐루프가 안정한 단위 피드백 시스템에서 전향 전달 함수 G(s)가 적분 1/s를 1개 포함할(1형 시스템일) 때, 정상 편차의 설명으로 올바른 것은?

  1. A계단 목표값에 대한 정상 편차는 0이 되고, 일정한 속도로 증가하는 램프 목표값에 대해서는 일정한 크기의 편차가 남는다
  2. B계단 목표값에 대해서도 일정한 크기의 정상 편차가 남고, 램프 목표값에 대해서는 편차가 시간이 지남에 따라 계속 커진다
  3. C계단, 램프, 일정한 가속도로 증가하는 목표값 어느 것에 대해서도 정상 편차는 0이 된다
정답과 해설 보기

정답: A. 계단 목표값에 대한 정상 편차는 0이 되고, 일정한 속도로 증가하는 램프 목표값에 대해서는 일정한 크기의 편차가 남는다

전향 경로에 포함된 적분의 수를 시스템의 형이라고 부릅니다. 1형 시스템에서는 편차가 조금이라도 남으면 적분이 조작량을 계속 바꾸므로, 계단 입력에 대한 정상 편차는 0이 됩니다. 램프 목표값에 대해서는 계속 따라가기 위해 일정한 편차가 필요하며, 그 크기는 1/Kv(Kv = lim[s→0] sG(s)는 속도 편차 상수)입니다. 예를 들어 G(s) = 2/(s(s + 1))에서는 Kv = 2이고, 단위 램프에 대한 정상 편차는 0.5가 됩니다.
