네트워크 온 칩(Network-on-Chip)란?

칩 안에 라우터와 링크를 그물망처럼 배치하고 데이터를 패킷으로 보내는 연결 방식. NoC. 다수 블록의 전송을 동시에 운반할 수 있다.

일본어 명칭: ネットワークオンチップ

네트워크 온 칩(Network-on-Chip)은(는) I/O 인터페이스와 버스 등 1개 분야의 연습 문제 1개에 나와요.

분야: I/O 인터페이스와 버스

도전해 보기: 네트워크 온 칩(Network-on-Chip) 관련 문제

대형 SoC에서 1개의 공유 버스 대신 네트워크 온 칩(NoC)이 사용되게 된 이유로 올바른 것은?

  1. ANoC를 사용하면 칩 안에서 무선 통신을 할 수 있기 때문
  2. B공유 버스는 한 번에 하나의 전송만 처리할 수 있어 블록이 늘면 혼잡해지고 배선도 길어지기 때문
  3. C공유 버스에서는 CPU가 메모리를 읽을 수 없기 때문
정답과 해설 보기

정답: B. 공유 버스는 한 번에 하나의 전송만 처리할 수 있어 블록이 늘면 혼잡해지고 배선도 길어지기 때문

블록이 적을 때는 공유 버스로 충분하지만, CPU 코어나 GPU, 각종 가속기가 수십 개 연결되면 한 번에 하나만 지나갈 수 있는 버스는 혼잡해집니다. NoC는 라우터와 링크를 그물망처럼 배치하고 데이터를 패킷으로 만들어 경로를 선택해 보내므로, 떨어진 블록끼리의 많은 전송을 동시에 처리할 수 있습니다. 배선을 짧은 구간으로 나눌 수 있어 높은 주파수에서도 동작시키기 쉬워집니다.
