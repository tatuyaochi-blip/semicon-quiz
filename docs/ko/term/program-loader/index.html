로더(Loader)란?

실행 파일을 메모리에 읽어 들이고 각 부분을 권한을 지정해 배치하며 스택에 인자 등을 준비하여 프로그램을 시작시키는 OS의 기능.

일본어 명칭: ローダ

로더(Loader)은(는) 링커, 로더, 실행 파일 등 1개 분야의 연습 문제 5개에 나와요.

분야: 링커, 로더, 실행 파일

도전해 보기: 로더(Loader) 관련 문제

프로그램을 기동할 때(Linux의 execve 등) OS 로더가 수행하는 일로 올바른 것은 무엇입니까?

  1. A소스 코드를 읽어 들여 그 자리에서 컴파일한 뒤 실행한다
  2. B실행 파일의 프로그램 헤더에 따라 각 부분을 메모리에 배치하고, 스택에 인수 등을 준비한 뒤 입구 주소부터 실행을 시작한다
  3. C실행 파일의 모든 심볼 이름을 화면에 표시한 뒤 실행한다
정답과 해설 보기

정답: B. 실행 파일의 프로그램 헤더에 따라 각 부분을 메모리에 배치하고, 스택에 인수 등을 준비한 뒤 입구 주소부터 실행을 시작한다

로더는 실행 파일의 헤더를 읽고, 프로그램 헤더에 적힌 각 부분(세그먼트)을 읽기, 쓰기, 실행 권한을 붙여 가상 주소 공간에 대응시킵니다. BSS를 위한 0 영역과 스택을 준비하고, 커맨드라인 인수와 환경 변수를 스택에 쌓습니다. 동적 링크라면 동적 링커를, 그렇지 않으면 실행 파일의 입구 주소부터 실행을 시작합니다.

해설 속 로더(Loader)

  • 로더는 실행 파일의 헤더를 읽고, 프로그램 헤더에 적힌 각 부분(세그먼트)을 읽기, 쓰기, 실행 권한을 붙여 가상 주소 공간에 대응시킵니다.

    프로그램을 기동할 때(Linux의 execve 등) OS 로더가 수행하는 일로 올바른 것은 무엇입니까?

  • 맨 앞의 ELF 헤더에 대상 CPU, 64비트 여부, 실행을 시작할 주소 등이 적혀 있고, 그 뒤에 .text, .data 등의 섹션과 로더가 메모리에 읽어 들이는 단위를 나타내는 프로그램 헤더가 이어집니다.

    Linux 등에서 자주 사용되는 ELF 형식 파일에 대해 올바른 것은 무엇입니까?

  • 내용이 모두 0이라면 파일에 0을 나열하여 저장하는 것은 낭비이므로, .bss 섹션에는 크기만 기록하고 로더가 메모리를 확보하여 0으로 채웁니다.

    .bss 섹션의 특징으로 올바른 것은 무엇입니까?

  • PC의 OS에서는 로더가 주소를 정하지만, 마이크로컨트롤러에서는 전원을 켠 시점의 주소가 그대로 사용됩니다.

    임베디드 개발에서 사용하는 링커 스크립트의 역할로 올바른 것은 무엇입니까?

  • 로더는 프로그램 헤더에 적힌 세그먼트를 단위로 메모리에 대응시키며, 예를 들어 읽기·실행 세그먼트에 .text와 .rodata를, 읽기·쓰기 세그먼트에 .data와 .bss를 모읍니다.

    ELF 파일에서 '섹션'과 '세그먼트'의 차이로 올바른 것은 무엇입니까?

로더(Loader)이(가) 나오는 문제 (5)

  1. 프로그램을 기동할 때(Linux의 execve 등) OS 로더가 수행하는 일로 올바른 것은 무엇입니까?
  2. Linux 등에서 자주 사용되는 ELF 형식 파일에 대해 올바른 것은 무엇입니까?
  3. .bss 섹션의 특징으로 올바른 것은 무엇입니까?
  4. 임베디드 개발에서 사용하는 링커 스크립트의 역할로 올바른 것은 무엇입니까?
  5. ELF 파일에서 '섹션'과 '세그먼트'의 차이로 올바른 것은 무엇입니까?
