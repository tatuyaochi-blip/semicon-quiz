스토어 버퍼(Store Buffer)란?

코어가 쓰기를 일시적으로 모아 두는 작은 버퍼. 쓰기 완료를 기다리지 않고 다음 명령으로 진행할 수 있지만, 다른 코어에서는 쓰기가 늦게 보인다.

일본어 명칭: ストアバッファ

스토어 버퍼(Store Buffer)은(는) 멀티코어와 동기화 등 1개 분야의 연습 문제 4개에 나와요.

정답과 해설 보기

정답: C. 어떤 코어가 수행한 여러 주소에 대한 읽기와 쓰기가, 다른 코어에서 어떤 순서로 보일 수 있는가

CPU는 성능을 위해 쓰기를 스토어 버퍼에 모아 두거나 읽기를 먼저 수행하는 등 메모리 연산의 순서를 바꾸는 경우가 있습니다. 하나의 코어 안에서는 결과가 달라지지 않도록 만들어져 있지만, 다른 코어에서는 순서가 바뀌어 보일 수 있습니다. 메모리 일관성 모델은 어떤 순서 변경이 일어날 수 있는지를 규정하며, 프로그래머가 올바른 동기화를 작성하기 위한 약속이 됩니다.

순차 일관성(시퀀셜 컨시스턴시)에 대한 설명으로 올바른 것은 무엇입니까?

  1. A각 코어의 연산이 매번 무작위 순서로 실행된다
  2. B모든 코어의 연산이 하나의 순서로 나열되고, 각 코어의 연산은 프로그램에 쓴 순서대로 나타나는 것처럼 보인다
  3. C모든 연산이 하나의 코어에서만 실행된다
정답과 해설 보기

정답: B. 모든 코어의 연산이 하나의 순서로 나열되고, 각 코어의 연산은 프로그램에 쓴 순서대로 나타나는 것처럼 보인다

순차 일관성에서는 여러 코어의 연산이 카드를 섞듯이 한 줄로 나열되고, 각 코어의 연산은 그 안에서 프로그램 순서를 유지하는 것처럼 보입니다. 프로그래머에게 가장 이해하기 쉬운 모델이지만, 하드웨어가 스토어 버퍼 등으로 순서를 바꾸는 최적화를 크게 제한하므로, 실제 많은 CPU는 더 느슨한 모델을 채택하고 있습니다.
