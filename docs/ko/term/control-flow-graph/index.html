제어 흐름 그래프(Control Flow Graph)란?

기본 블록을 노드로, 블록 간의 분기나 이동을 화살표로 하여 프로그램의 실행 흐름을 나타낸 그래프. 루프 검출과 데이터 흐름 분석에 사용한다.

일본어 명칭: 制御フローグラフ

제어 흐름 그래프(Control Flow Graph)은(는) 컴파일러 등 1개 분야의 연습 문제 3개에 나와요.

분야: 컴파일러

노드로서의 기본 블록

제어 흐름 그래프(CFG)는 기본 블록, 즉 첫 명령어로만 진입하고 마지막 명령어로만 빠져나가는 최대 길이의 명령어 열로 구성됩니다. 이를 만들기 위해 컴파일러는 리더(leader), 즉 함수의 첫 명령어, 모든 분기 대상, 분기 바로 다음의 모든 명령어를 표시합니다. 각 블록은 리더에서 다음 리더 직전까지입니다. 블록 안의 명령어는 항상 순서대로 실행되므로, 공통 부분식 제거 같은 지역 최적화를 블록 하나 안에서 쉽게 적용할 수 있습니다.

에지와 형태가 드러내는 것

에지는 가능한 제어 이동을 나타냅니다. 조건 분기는 블록에 분기 대상과 폴스루 블록이라는 두 후속 블록을 주고, 무조건 점프는 하나를 줍니다. 많은 분석은 단일 진입 노드와 출구 노드를 추가합니다. 그래프의 형태는 구조를 드러냅니다. 진입에서 n까지의 모든 경로가 d를 지나면 블록 d가 블록 n을 지배(dominate)한다고 하며, 대상이 출발 블록을 지배하는 에지는 루프를 식별하는 백 에지입니다. 진입에서 도달할 수 없는 블록은 제거 가능한 죽은 코드입니다.

CFG 위의 데이터 흐름 분석

많은 최적화는 CFG 에지를 따라 정보를 전파하고 더 이상 변화가 없을 때까지 반복하는 데이터 흐름 분석에 의존합니다. 활성 변수 분석(liveness analysis)은 역방향으로 진행하여 각 지점에서 나중에 읽힐 수 있는 값을 찾으며, 그 결과로 레지스터 할당에 사용하는 간섭 그래프를 만듭니다. 도달 정의 분석(reaching definitions)은 순방향으로 진행하여 어떤 대입이 변수의 값을 공급할 수 있는지 찾습니다. 대부분의 최신 컴파일러가 사용하는 정적 단일 대입(SSA) 형식도 CFG 위에서 구성되며, 제어 흐름 경로가 합류하는 곳에 phi 함수를 삽입합니다.

CFG와 호출 그래프

CFG는 하나의 함수 안의 흐름을 나타내고, 호출 그래프는 함수 전체를 노드로, 호출을 에지로 가집니다. 프로시저 간 분석은 둘 다 사용합니다. CFG는 컴파일러 밖에서도 등장합니다. 테스트의 분기 커버리지는 모든 CFG 에지가 실행되었는지를 묻고, 바이너리 분석 도구는 기계어에서 CFG를 재구성하며, 제어 흐름 무결성(CFI) 방어는 간접 점프를 CFG가 허용하는 에지로 제한하여 실행을 의도하지 않은 코드로 돌리는 공격을 차단합니다.

제어 흐름 그래프에서 노드와 화살표가 나타내는 것의 조합으로 올바른 것은?

  1. A노드는 변수, 화살표는 변수에 값을 대입한 순서
  2. B노드는 기본 블록, 화살표는 블록 사이의 분기나 전이
  3. C노드는 함수, 화살표는 파일끼리의 읽어 들이기 관계
정답과 해설 보기

정답: B. 노드는 기본 블록, 화살표는 블록 사이의 분기나 전이

제어 흐름 그래프는 기본 블록을 노드로, 어떤 블록의 실행 뒤에 이어질 가능성이 있는 블록으로의 전이(조건 분기의 양쪽 목적지나 그대로 다음 블록으로 진행하는 흐름)를 화살표로 나타낸 그래프입니다. 뒤로 향하는 화살표에서 루프를 찾거나, 변수의 값이 어디에서 어디로 도달하는지를 분석하는 데 사용됩니다. 함수끼리의 호출 관계는 별도의 호출 그래프로 나타내며, 파일의 읽어 들이기 관계와는 무관합니다.

자주 묻는 질문

제어 흐름 그래프의 기본 블록이란?

위쪽에 진입점 하나, 아래쪽에 출구 하나를 가진 직선형 명령어 열로, 첫 명령어가 실행되면 모든 명령어가 순서대로 실행됩니다.

제어 흐름 그래프에서 루프를 찾는 방법은?

지배자(dominator)를 계산하고, 대상이 출발 블록을 지배하는 에지인 백 에지를 찾습니다. 각 백 에지는 대상 블록을 헤더로 하는 자연 루프를 정의합니다.

제어 흐름 그래프와 호출 그래프의 차이는?

제어 흐름 그래프는 하나의 함수 안에서 기본 블록 간의 가능한 경로를 나타내고, 호출 그래프는 어떤 함수가 어떤 다른 함수를 호출하는지를 나타냅니다.

  • 블록 안에서는 실행 순서가 정해져 있으므로 국소적인 최적화가 쉽고, 블록을 노드로 한 제어 흐름 그래프로 전체의 흐름을 나타냅니다.
