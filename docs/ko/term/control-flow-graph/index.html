제어 흐름 그래프(Control Flow Graph)란?

기본 블록을 노드로, 블록 간의 분기나 이동을 화살표로 하여 프로그램의 실행 흐름을 나타낸 그래프. 루프 검출과 데이터 흐름 분석에 사용한다.

일본어 명칭: 制御フローグラフ

제어 흐름 그래프(Control Flow Graph)은(는) 컴파일러 등 1개 분야의 연습 문제 3개에 나와요.

분야: 컴파일러

도전해 보기: 제어 흐름 그래프(Control Flow Graph) 관련 문제

제어 흐름 그래프에서 노드와 화살표가 나타내는 것의 조합으로 올바른 것은?

  1. A노드는 변수, 화살표는 변수에 값을 대입한 순서
  2. B노드는 기본 블록, 화살표는 블록 사이의 분기나 전이
  3. C노드는 함수, 화살표는 파일끼리의 읽어 들이기 관계
정답과 해설 보기

정답: B. 노드는 기본 블록, 화살표는 블록 사이의 분기나 전이

제어 흐름 그래프는 기본 블록을 노드로, 어떤 블록의 실행 뒤에 이어질 가능성이 있는 블록으로의 전이(조건 분기의 양쪽 목적지나 그대로 다음 블록으로 진행하는 흐름)를 화살표로 나타낸 그래프입니다. 뒤로 향하는 화살표에서 루프를 찾거나, 변수의 값이 어디에서 어디로 도달하는지를 분석하는 데 사용됩니다. 함수끼리의 호출 관계는 별도의 호출 그래프로 나타내며, 파일의 읽어 들이기 관계와는 무관합니다.

해설 속 제어 흐름 그래프(Control Flow Graph)

  • 제어 흐름 그래프는 기본 블록을 노드로, 어떤 블록의 실행 뒤에 이어질 가능성이 있는 블록으로의 전이(조건 분기의 양쪽 목적지나 그대로 다음 블록으로 진행하는 흐름)를 화살표로 나타낸 그래프입니다.

    제어 흐름 그래프에서 노드와 화살표가 나타내는 것의 조합으로 올바른 것은?

  • 블록 안에서는 실행 순서가 정해져 있으므로 국소적인 최적화가 쉽고, 블록을 노드로 한 제어 흐름 그래프로 전체의 흐름을 나타냅니다.

    기본 블록에 대한 설명으로 올바른 것은?

  • 생존 구간 분석에서는 프로그램의 각 시점에서 어떤 값이 이후에 읽힐 가능성이 있는지(살아 있는지)를 제어 흐름 그래프를 따라가며 구합니다.

    레지스터 할당의 준비로 수행하는 생존 구간(라이브니스) 분석에서 구하는 것은?

  2. 기본 블록에 대한 설명으로 올바른 것은?
  3. 레지스터 할당의 준비로 수행하는 생존 구간(라이브니스) 분석에서 구하는 것은?
