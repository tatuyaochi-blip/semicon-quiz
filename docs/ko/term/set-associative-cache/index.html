세트 연관(Set-associative) 방식란?

주소로 정해지는 하나의 세트 안에서 여러 위치(웨이)의 어디에든 데이터를 둘 수 있는 캐시 구성. n웨이라면 매 접근마다 n개의 태그를 병렬로 비교한다.

일본어 명칭: セットアソシアティブ方式

세트 연관(Set-associative) 방식은(는) CPU와 아키텍처 등 1개 분야의 연습 문제 1개에 나와요.

세트 연관(셋 어소시에이티브) 방식 캐시의 설명으로 올바른 것은?

  2. B어떤 주소의 데이터를 둘 수 있는 위치가 캐시 내 한 곳으로 정해져 있다
  3. C데이터를 캐시의 어디에든 둘 수 있다
정답과 해설 보기

정답: A. 어떤 주소의 데이터를 정해진 세트 안의 여러 위치(웨이) 중 어디에든 둘 수 있다

세트 연관 방식에서는 주소의 일부로 세트가 정해지고, 그 안의 여러 웨이 중 어디에든 데이터를 둘 수 있습니다. 예를 들어 8웨이라면 8곳의 후보가 있어 직접 사상 방식보다 같은 위치를 두고 다투는 일(충돌 미스)을 줄일 수 있습니다. 웨이를 늘리면 비교 회로와 전력이 늘어나므로 L1에서 8~12웨이 정도, L3에서 16웨이 전후가 일반적입니다. 어디에든 둘 수 있는 것은 완전 연관 방식입니다.

이 용어가 포함된 비교

  • 직접 사상 vs 세트 연관 vs 완전 연관 캐시직접 사상, 세트 연관, 완전 연관 캐시를 표로 비교합니다: 블록 배치 위치, 태그 비교, 속도, 비용, 충돌 미스, 용도.
