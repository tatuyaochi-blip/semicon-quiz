세트 연관 캐시(set-associative cache)란?

주소로 선택된 하나의 세트 안에서 여러 위치(웨이) 중 어디에든 데이터를 둘 수 있는 캐시 구성입니다. n-웨이 캐시는 접근할 때마다 n개의 태그를 병렬로 비교합니다.

일본어 명칭: セットアソシアティブ方式

세트 연관 캐시(set-associative cache)은(는) 메모리 계층 구조 등 1개 분야의 연습 문제 2개에 나와요.

분야: 메모리 계층 구조

도전해 보기: 세트 연관 캐시(set-associative cache) 관련 문제

주소가 32비트, 용량 32 KB, 라인 크기 64바이트인 4-way 세트 연관 캐시의 세트 수는 얼마입니까?

  1. A128
  2. B512
  3. C32
정답과 해설 보기

정답: A. 128

라인 수는 32 KB ÷ 64 B = 512입니다. 4-way에서는 하나의 세트에 4개의 라인이 들어가므로 세트 수는 512 ÷ 4 = 128 = 2⁷ 이 되고, 인덱스는 7비트, 태그는 32 − 7 − 6 = 19비트가 됩니다. 512는 라인 수 그 자체로, 직접 사상일 때의 세트 수입니다. 연관도(associativity)를 높이면 세트 수가 줄어든 만큼 태그 비트 수가 늘고 비교기도 늘어납니다. 32는 라인 크기 64를 잘못하여 way 수로 나눈 값입니다.

8-way 세트 연관 캐시에서 1회 접근할 때마다 병렬로 비교하는 태그의 수는 몇 개입니까?

  1. A캐시 전체의 라인 수와 같은 수
  2. B8개
  3. C1개
정답과 해설 보기

정답: B. 8개

세트 연관 방식에서는 먼저 주소의 인덱스로 하나의 세트를 고르고, 그 세트에 있는 모든 way의 태그를 병렬로 비교합니다. 8-way라면 한 세트에 8라인이 있으므로 비교하는 태그는 8개이며, 이를 위한 비교기도 8개 필요합니다. 캐시 전체의 라인 수만큼 비교하는 것은 완전 연관 방식이고, 1개만 비교하는 것은 직접 사상 방식입니다. way를 늘리면 비교기와 소비 전력이 늘어나므로 L1의 연관도는 낮게 잡는 경우가 많습니다.

세트 연관 캐시(set-associative cache)이(가) 나오는 문제 (2)

  1. 주소가 32비트, 용량 32 KB, 라인 크기 64바이트인 4-way 세트 연관 캐시의 세트 수는 얼마입니까?
  2. 8-way 세트 연관 캐시에서 1회 접근할 때마다 병렬로 비교하는 태그의 수는 몇 개입니까?

이 용어가 포함된 비교
