페이지 폴트(page fault)란?

접근한 페이지가 물리 메모리에 대응되어 있지 않거나 허용되지 않은 접근일 때 발생하는 예외입니다. OS는 페이지를 마련해 명령어를 재실행하거나, 불법 접근으로 처리합니다.

일본어 명칭: ページフォルト

페이지 폴트(page fault)은(는) OS와 하드웨어, 링커, 로더, 실행 파일, 멀티코어와 동기화 등 4개 분야의 연습 문제 14개에 나와요.

페이지 폴트가 발생하는 경우로 올바른 것은 무엇입니까?

  1. A캐시에 데이터가 없어 주기억장치에서 읽어 들였을 때
  2. B접근한 페이지가 물리 메모리에 할당되어 있지 않을 때
  3. CTLB에 변환 결과가 있어 곧바로 물리 주소를 알 수 있었을 때
정답과 해설 보기

정답: B. 접근한 페이지가 물리 메모리에 할당되어 있지 않을 때

페이지 폴트는 접근한 페이지의 페이지 테이블 항목이 무효일 때, 즉 물리 메모리에 할당되어 있지 않을 때(디스크로 내보내졌거나 아직 읽어 들이지 않은 경우 등)나, 읽기 전용 페이지에 쓰기를 하는 등 허용되지 않는 접근을 했을 때 발생하는 예외입니다. OS가 페이지를 준비하고 명령을 다시 실행합니다. 캐시 미스는 하드웨어만으로 처리되며 예외가 되지 않습니다. TLB에 있으면 곧바로 변환할 수 있으므로 폴트는 일어나지 않습니다.

내보내져 디스크에 있는 페이지에 접근하여 페이지 폴트가 발생했을 때 OS가 수행하는 처리 흐름으로 올바른 것은 무엇입니까?

  1. A프로그램을 즉시 비정상 종료시키고 페이지는 읽어 들이지 않는다
  2. B페이지를 읽어 들인 뒤 폴트를 일으킨 명령을 건너뛰고 다음 명령부터 재개한다
  3. C페이지를 준비하여 디스크에서 읽어 들이고 표를 갱신한 뒤 명령을 다시 실행한다
정답과 해설 보기

정답: C. 페이지를 준비하여 디스크에서 읽어 들이고 표를 갱신한 뒤 명령을 다시 실행한다

정당한 접근으로 인한 페이지 폴트에서는 OS가 빈 물리 페이지를 찾고(없으면 다른 페이지를 내보내고) 디스크에서 내용을 읽어 들여 페이지 테이블 항목을 유효하게 합니다. 그런 다음 폴트를 일으킨 명령을 처음부터 다시 실행하므로 프로그램은 아무 일도 없었던 것처럼 계속됩니다. 명령을 건너뛰면 그 접근이 실행되지 않아 결과가 틀려집니다. 비정상 종료시키는 것은 할당되지 않은 주소에 대한 잘못된 접근의 경우입니다.

페이지 폴트(page fault)이(가) 나오는 문제 (14)

  1. 페이지 폴트가 발생하는 경우로 올바른 것은 무엇입니까?
  2. 내보내져 디스크에 있는 페이지에 접근하여 페이지 폴트가 발생했을 때 OS가 수행하는 처리 흐름으로 올바른 것은 무엇입니까?
  3. 페이지 교체에서 FIFO 방식을 사용하면 물리 메모리의 페이지 수를 늘렸는데도 페이지 폴트가 늘어나는 경우가 있습니다. 이 현상을 무엇이라고 합니까?
  4. 메모리 접근 시간이 100 ns, 페이지 폴트 처리에 8 ms가 걸리고, 100만 번에 한 번 페이지 폴트가 발생할 때 평균 접근 시간은 대략 얼마입니까?
  5. 재귀가 너무 깊어져 스택의 상한을 넘었을 때, Linux 등에서 일반적으로 일어나는 일로 올바른 것은?
  6. 인터럽트와 예외의 차이에 대한 일반적인 설명은 무엇입니까?
  7. 다음 중 명령 실행과 무관하게 언제 발생할지 정해져 있지 않은 비동기 요인은 무엇입니까?
  8. 인터럽트 벡터 테이블의 역할로 올바른 것은 무엇입니까?
  9. 프로세스를 복제할 때 카피 온 라이트(copy-on-write)를 사용하는 이점으로 올바른 것은 무엇입니까?
  10. 디맨드 페이징에 대한 설명으로 올바른 것은 무엇입니까?
  11. 프로그램이 OS가 할당하지 않은 주소에 접근했을 때 일반적으로 일어나는 일은 무엇입니까?
  12. 파일을 메모리에 대응시키는(mmap과 같은) 구조에서 파일 내용을 읽을 때 일어나는 일에 대한 설명으로 올바른 것은 무엇입니까?
  13. Linux의 NUMA 시스템에서 자주 사용되는 퍼스트 터치(first-touch) 정책(처음 페이지에 쓴 스레드가 동작 중인 노드의 메모리에 그 페이지를 배치)에서 주의해야 할 점으로 올바른 것은?
  14. CUDA 유니파이드 메모리(통합 메모리)에 대한 설명으로 올바른 것은?
