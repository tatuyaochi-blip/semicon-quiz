프리필(Prefill)란?

대규모 언어 모델의 추론에서 입력 문장의 토큰을 한꺼번에 처리하는 첫 단계. 연산 바운드(compute-bound)이 되기 쉽다. 이어지는 한 토큰씩의 생성은 디코드라 한다.

일본어 명칭: プリフィル

프리필(Prefill)은(는) AI 하드웨어·소프트웨어 스택 등 1개 분야의 연습 문제 2개에 나와요.

분야: AI 하드웨어·소프트웨어 스택

도전해 보기: 프리필(Prefill) 관련 문제

대규모 언어 모델의 추론은 입력 문장을 한꺼번에 처리하는 단계(프리필)와 토큰을 하나씩 출력으로 만드는 단계(디코드)로 나뉜다. 각각의 성능을 주로 결정하는 것의 조합으로 올바른 것은 무엇인가(배치가 작은 경우)?

  1. A프리필은 메모리 대역폭, 디코드는 연산 성능
  2. B프리필은 연산 성능, 디코드는 메모리 대역폭
  3. C둘 다 스토리지의 속도
정답과 해설 보기

정답: B. 프리필은 연산 성능, 디코드는 메모리 대역폭

프리필에서는 입력의 수백~수천 토큰을 한꺼번에 계산하므로 가중치를 많은 토큰에서 재사용할 수 있고, 행렬끼리의 곱이 되어 연산 율속이 됩니다. 디코드에서는 토큰 하나를 만들 때마다 모든 가중치를 읽어 오면서 토큰 한 개분의 계산만 하므로 연산 강도가 낮아 메모리 율속이 됩니다. 그래서 디코드의 속도는 대체로 메모리 대역폭 ÷ 가중치 크기로 결정됩니다.

프리필(Prefill)이(가) 나오는 문제 (2)

  1. 대규모 언어 모델의 추론은 입력 문장을 한꺼번에 처리하는 단계(프리필)와 토큰을 하나씩 출력으로 만드는 단계(디코드)로 나뉜다. 각각의 성능을 주로 결정하는 것의 조합으로 올바른 것은 무엇인가(배치가 작은 경우)?
  2. 대규모 언어 모델의 추론에서 활성화는 FP16 그대로 두고 가중치만 4비트로 하는(W4A16) 양자화가 디코드를 특히 빠르게 하는 이유로 올바른 것은 무엇인가?
