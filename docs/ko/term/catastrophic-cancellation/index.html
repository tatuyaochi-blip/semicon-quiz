유효 숫자 손실(Cancellation)란?

거의 같은 두 수를 뺄 때 상위 자릿수가 서로 상쇄되어 유효 자릿수가 크게 줄어드는 현상. 원래 수에 포함된 반올림 오차의 비율이 상대적으로 커진다. 계산식을 변형하여 피한다.

일본어 명칭: 桁落ち

분야: 컴퓨터 산술

뺄셈 자체가 범인은 아님

놀랍게도 가까운 두 부동소수점 수의 뺄셈은 보통 정확합니다. x와 y가 서로 2배 이내에 있으면 x − y는 정확히 표현 가능하며, 하드웨어는 반올림 없이 그 값을 돌려줍니다(Sterbenz 보조정리로 알려진 결과). 손상은 앞선 반올림, 측정, 변환 등으로 피연산자에 이미 들어 있던 오차에서 옵니다. 상위 자릿수가 상쇄되면 그 작은 절대 오차는 그대로 남는데 결과 자체는 매우 작아지므로, 상대 오차가 확대됩니다. 유효 숫자 손실은 새로운 오차를 만드는 것이 아니라 기존 오차를 드러내는 것입니다.

증폭의 크기

a와 b가 각각 약 e의 상대 오차를 가지면, a − b의 오차는 대략 e에 (|a| + |b|) / |a - b|를 곱한 값입니다. 따라서 처음 6자리 유효 숫자가 일치하는 수끼리 빼면 상대 오차가 약 100만 배로 증폭되어, double의 약 16자리 중 6자리가 소모됩니다. 피연산자의 모든 자릿수가 일치하면 결과는 순전히 잡음이거나 정확히 0이 될 수 있습니다. 이 비율이 뺄셈의 조건수이며, 효과가 형식만이 아니라 입력이 얼마나 가까운지에 따라 달라지는 이유를 설명합니다.

표준적인 식 변형

해결책은 가까운 값끼리의 뺄셈을 피하는 대수적 변형입니다. 유리화를 하면 √(x + 1) − √x는 1 / (√(x + 1) + √x)가 됩니다. 근의 공식에서 b²가 4ac보다 훨씬 클 때는 한 근에서 유효 숫자 손실이 일어나므로, 다른 근을 먼저 계산하고 문제가 되는 근은 두 근의 곱을 이용해 c / a를 첫 번째 근으로 나누어 구하면 이를 피할 수 있습니다. x가 작을 때 1 − cos x는 2 sin²(x / 2)로 바꾸며, 수학 라이브러리는 0 근처에서 exp(x) − 1과 log(1 + x)를 정확하게 계산하는 expm1(x)와 log1p(x)를 제공합니다.

유효 숫자 손실과 정보 흡수(absorption)의 차이

유효 숫자 손실과 흡수는 부동소수점이 정보를 잃는 두 가지 전형적인 방식이며 혼동하기 쉽습니다. 유효 숫자 손실은 거의 같은 수를 뺄 때 일어나 결과에 의미 있는 자릿수가 너무 적게 남는 현상입니다. 흡수는 크기가 매우 다른 수를 더할 때 일어나며, 작은 피연산자의 하위 자릿수가 가수 끝에서 떨어져 나갑니다. 예를 들어 배정밀도에서 1.0e16 + 1은 정확히 1.0e16이 됩니다. 더 넓은 형식으로 바꾸면 두 문제가 뒤로 미뤄질 뿐 사라지지는 않으며, 계산을 재구성해야 해결됩니다.

자주 묻는 질문

거의 같은 부동소수점 수를 빼면 왜 정밀도가 떨어지나요?

일치하는 상위 자릿수가 상쇄되어, 이미 반올림 오차에 오염된 하위 자릿수가 대부분인 작은 결과만 남기 때문입니다. 절대 오차는 그대로인데 값이 작아지므로 상대 오차가 급격히 커집니다.

float을 double로 바꾸면 유효 숫자 손실이 해결되나요?

잃을 자릿수가 많아지므로 도움은 되지만, 피연산자가 더 가까워지면 같은 손실이 다시 나타납니다. 뺄셈을 피하도록 식을 변형하는 것이 진정한 해결책입니다.

근의 공식에서 유효 숫자 손실은 어떻게 피하나요?

-b와 제곱근 항의 부호가 같아 서로 상쇄되지 않고 더해지는 근을 먼저 계산한 뒤, 두 근의 곱이 c / a라는 관계로 다른 근을 구합니다.
