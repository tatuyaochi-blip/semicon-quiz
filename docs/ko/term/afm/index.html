AFM(원자간력 현미경)란?

날카로운 탐침으로 시료 표면을 훑으며, 탐침과 표면 사이에 작용하는 힘으로 표면의 미세한 요철을 측정하는 현미경. 표면 거칠기 평가 등에 사용된다.

일본어 명칭: AFM(原子間力顕微鏡)

AFM(원자간력 현미경)은(는) 계측과 분석 등 1개 분야의 연습 문제 7개에 나와요.

분야: 계측과 분석

도전해 보기: AFM(원자간력 현미경) 관련 문제

원자간력 현미경(AFM)으로 주로 측정하는 것은?

  1. A면저항
  2. B불순물 농도의 깊이 방향 분포
  3. C표면의 미세한 요철(형상이나 거칠기)
정답과 해설 보기

정답: C. 표면의 미세한 요철(형상이나 거칠기)

AFM은 끝이 뾰족한 탐침이 달린 판 스프링(캔틸레버)으로 표면을 훑으며, 원자간력에 의한 휨을 레이저 반사로 검출하면서 주사하여 표면의 요철을 측정합니다. 높이 방향으로는 0.1 nm 정도의 차이도 측정할 수 있으므로, CMP 후의 표면 거칠기나 박막의 표면 상태 평가에 사용됩니다. 탐침을 진동시켜 가볍게 접촉하는 태핑 모드라면 시료를 손상시키기 어렵습니다. 면저항이나 도펀트 분포는 다른 수법으로 측정합니다.

AFM으로 매우 가는 홈이나 가파른 측벽의 형상을 측정할 때 오차의 원인이 되기 쉬운 것은?

  1. AAFM은 진공에서만 사용할 수 있다는 점
  2. B탐침 끝의 굵기와 형상이 유한하기 때문에, 측정한 형상에 탐침의 형상이 겹쳐서 찍히는 점
  3. CAFM은 표면의 요철을 측정할 수 없다는 점
정답과 해설 보기

정답: B. 탐침 끝의 굵기와 형상이 유한하기 때문에, 측정한 형상에 탐침의 형상이 겹쳐서 찍히는 점

AFM은 탐침으로 표면을 훑어 형상을 측정하기 때문에 탐침 끝보다 가는 홈의 바닥에는 닿지 못하고, 가파른 측벽에서는 탐침의 측면이 먼저 닿습니다. 그 결과 측정한 형상은 실제 형상과 탐침 형상을 겹친 것이 되어, 홈은 얕고 좁게, 선은 굵게 보입니다. 끝이 가는 탐침이나 끝이 옆으로 넓어진 측벽 측정용 탐침을 사용하고, 탐침의 형상을 추정하여 보정하는 해석도 수행합니다.

  2. AFM으로 매우 가는 홈이나 가파른 측벽의 형상을 측정할 때 오차의 원인이 되기 쉬운 것은?
  3. 여러 서로 다른 계측 수법(광학식·CD-SEM·AFM 등)의 데이터를 조합하여 하나의 수법만 사용하는 것보다 정확하게 치수나 형상을 구하는 개념을 무엇이라고 합니까?
  4. 4탐침법으로 주로 측정하는 것은?
  5. X선을 조사하여 방출되는 광전자의 에너지로부터 표면의 원소와 화학 결합 상태를 조사하는 분석법은?

  7. 가는 바늘로 시료 표면을 훑어 바늘의 상하 움직임으로부터 단차 높이나 표면 형상을 측정하는 장비는?
