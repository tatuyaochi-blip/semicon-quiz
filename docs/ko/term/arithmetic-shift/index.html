산술 시프트(Arithmetic Shift)란?

부호 있는 정수의 오른쪽 시프트에서 비는 상위 비트에 부호 비트를 복사하는 방식. 음수를 오른쪽으로 1비트 밀면 2로 나누어 작은 쪽으로 내림한 값이 된다. 0을 채우는 것은 논리 시프트.

일본어 명칭: 算術シフト

산술 시프트(Arithmetic Shift)은(는) 논리 회로, 컴퓨터 산술, C 언어 기초 등 3개 분야의 연습 문제 3개에 나와요.

분야: 컴퓨터 산술

도전해 보기: 산술 시프트(Arithmetic Shift) 관련 문제

2진수를 1비트 왼쪽으로 시프트하면 값은 어떻게 됩니까? (오버플로가 없는 경우)

  1. A2배가 된다
  2. B절반이 된다
  3. C1만큼 증가한다
정답과 해설 보기

정답: A. 2배가 된다

2진수에서는 각 자리가 2배씩의 가중치를 가지므로, 1비트 왼쪽으로 시프트하고 최하위에 0을 넣으면 값은 2배, 오른쪽으로 시프트하면 절반(버림)이 됩니다. n비트 시프트는 2ⁿ배·1/2ⁿ입니다. 곱셈·나눗셈기보다 훨씬 작고 빠르기 때문에 컴파일러는 x × 8을 x << 3으로 치환합니다. 부호 있는 수의 오른쪽 시프트에서는 부호 비트를 복제하는 산술 시프트를 사용하지 않으면 음수를 올바르게 나눌 수 없습니다.

8비트 부호 있는 정수에서 −8(1111 1000)을 산술 오른쪽 시프트로 1비트 오른쪽으로 이동한 결과는 무엇입니까?

  1. A124(0111 1100)
  2. B−16(1111 0000)
  3. C−4(1111 1100)
정답과 해설 보기

정답: C. −4(1111 1100)

산술 시프트(산술 오른쪽 시프트)에서는 비어 있는 최상위 비트에 부호 비트를 복사하므로 1111 1000은 1111 1100이 되고, 이는 2의 보수로 −4입니다. 음수에서도 오른쪽으로 1비트 이동하면 2로 나눈 값이 됩니다. 최상위에 0을 넣는 논리 오른쪽 시프트에서는 0111 1100 = 124가 되어 부호가 바뀌어 버립니다. −16은 왼쪽으로 1비트 이동한 결과입니다. C 언어에서 음의 부호 있는 정수를 오른쪽 시프트했을 때 어느 쪽이 되는지는 처리계 정의(처리계에 맡겨져 있음)라는 점에도 주의해야 합니다.
