DMA(ダイレクトメモリアクセス)란?

でぃーえむえー

CPUを介さずに、周辺装置とメモリの間で直接データを転送する仕組み。大量のデータ転送の間もCPUが別の処理を進められる。

일본어 명칭: DMA(ダイレクトメモリアクセス)

DMA(ダイレクトメモリアクセス)은(는) CPU와 아키텍처 등 1개 분야의 연습 문제 2개에 나와요.

분야: CPU와 아키텍처

도전해 보기: DMA(ダイレクトメモリアクセス) 관련 문제

CPU를 거치지 않고 주변 장치와 메모리 사이에서 직접 데이터를 전송하는 구조는?

  1. ATLB
  2. BSIMD
  3. CDMA(직접 메모리 접근)
정답과 해설 보기

정답: C. DMA(직접 메모리 접근)

DMA에서는 전용 컨트롤러가 메모리와 주변 장치 사이에서 데이터를 전송하므로, CPU는 전송의 시작과 완료 통지(인터럽트)만 받으면 되고 그동안 다른 처리를 진행할 수 있습니다. 스토리지, 네트워크, 오디오, ADC의 데이터 수집 등 대량의 데이터를 다루는 상황에서 쓰입니다. CPU 캐시와 전송 데이터의 일관성에 주의해야 하며, 하드웨어나 OS가 관리합니다.

캐시의 쓰기 방식 중 라이트백 방식의 설명으로 올바른 것은?

  1. A캐시에는 쓰지 않고 주기억장치만 갱신한다
  2. B쓰기를 할 때마다 캐시와 주기억장치를 반드시 모두 갱신한다
  3. C먼저 캐시만 갱신하고, 그 데이터가 캐시에서 밀려날 때 주기억장치에 다시 쓴다
정답과 해설 보기

정답: C. 먼저 캐시만 갱신하고, 그 데이터가 캐시에서 밀려날 때 주기억장치에 다시 쓴다

라이트백 방식에서는 쓰기를 캐시에만 수행하고, 갱신된(더티) 라인이 밀려날 때 한꺼번에 주기억장치에 다시 씁니다. 같은 위치에 대한 여러 번의 쓰기가 1회의 되쓰기로 끝나므로 주기억장치로의 통신량이 크게 줄어들어 많은 CPU의 L1~L3에서 사용됩니다. 대신 주기억장치와 캐시의 내용이 일시적으로 어긋나므로 코히런시나 DMA와의 일관성 관리가 필요합니다.
