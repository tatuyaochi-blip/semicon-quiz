DMA(직접 메모리 접근)란?

CPU를 거치지 않고 주변장치와 메모리 사이에서 데이터를 직접 전송하는 방식입니다. 대용량 전송 중에도 CPU가 다른 작업을 할 수 있습니다.

일본어 명칭: DMA(ダイレクトメモリアクセス)

DMA(직접 메모리 접근)은(는) OS와 하드웨어, CPU와 아키텍처, 임베디드 시스템과 펌웨어 등 6개 분야의 연습 문제 10개에 나와요.

도전해 보기: DMA(직접 메모리 접근) 관련 문제

캐시 일관성을 하드웨어가 유지하지 않는(비코히런트) 시스템에서, 장치가 DMA로 주기억장치에 쓴 데이터를 CPU가 읽기 전에 소프트웨어가 해야 하는 처리는 무엇입니까?

  1. ACPU의 클록 주파수를 일시적으로 낮춘다
  2. B해당 범위의 캐시 내용을 무효화하여 주기억장치에서 다시 읽도록 한다
  3. C캐시 내용을 모두 주기억장치에 다시 쓴 뒤, DMA로 도착한 결과를 폐기한다
정답과 해설 보기

정답: B. 해당 범위의 캐시 내용을 무효화하여 주기억장치에서 다시 읽도록 한다

DMA는 CPU를 거치지 않고 장치와 주기억장치 사이에서 데이터를 전송하므로, 하드웨어가 일관성을 유지하지 않는 시스템에서는 CPU 캐시에 그 범위의 오래된 데이터가 남아 있을 수 있습니다. 그대로 읽으면 DMA로 도착한 새 데이터가 아니라 오래된 값을 읽게 됩니다. 그래서 드라이버는 읽기 전에 그 범위의 캐시를 무효화하여 주기억장치에서 새 값을 읽게 합니다. 반대로 장치로 보낼 데이터는 DMA를 시작하기 전에 캐시에서 다시 써 둡니다.

마이크로컨트롤러에서 AD 컨버터의 변환 결과를 일정한 간격으로 대량으로 가져올 때 DMA를 사용하는 이점으로 올바른 것은 무엇입니까?

  1. AAD 컨버터의 분해능이 자동으로 올라간다
  2. B입력 전압이 자동으로 커진다
  3. C변환이 끝날 때마다 CPU가 인터럽트로 읽을 필요 없이 DMA가 메모리에 나열해 주므로 CPU의 부담이 줄어든다
정답과 해설 보기

정답: C. 변환이 끝날 때마다 CPU가 인터럽트로 읽을 필요 없이 DMA가 메모리에 나열해 주므로 CPU의 부담이 줄어든다

변환할 때마다 인터럽트로 CPU가 결과를 읽으면, 1초에 수만 번 가져오는 경우 인터럽트 오버헤드만으로 CPU 시간의 상당 부분이 쓰입니다. DMA를 사용하면 변환이 끝날 때마다 DMA가 결과를 메모리 배열에 차례로 쓰고, 배열이 가득 찼을 때만 CPU에 알립니다. 타이머로 변환을 시작하도록 설정하는 것과 조합하면, 정확한 간격으로 데이터를 CPU 없이 계속 가져올 수 있습니다.

  • DMA는 기기가 CPU를 거치지 않고 메모리를 직접 읽고 쓰는 구조이므로, 악의적인 기기나 탈취된 기기가 연결되면 OS의 메모리나 키를 읽거나 바꿀 수 있습니다.

  • DMA에서는 전용 컨트롤러가 메모리와 주변 장치 사이에서 데이터를 전송하므로, CPU는 전송의 시작과 완료 통지(인터럽트)만 받으면 되고 그동안 다른 처리를 진행할 수 있습니다.

DMA(직접 메모리 접근)이(가) 나오는 문제 (10)

  1. 캐시 일관성을 하드웨어가 유지하지 않는(비코히런트) 시스템에서, 장치가 DMA로 주기억장치에 쓴 데이터를 CPU가 읽기 전에 소프트웨어가 해야 하는 처리는 무엇입니까?
  2. 마이크로컨트롤러에서 AD 컨버터의 변환 결과를 일정한 간격으로 대량으로 가져올 때 DMA를 사용하는 이점으로 올바른 것은 무엇입니까?
  3. 네트워크 카드나 NVMe SSD 등에서 널리 사용되는, 메모리 상의 기술자(디스크립터) 링을 사용한 DMA 구조에 대해 올바른 것은 무엇입니까?
  4. PC에 연결한 외부 기기가 DMA를 이용해 메인 메모리의 내용을 멋대로 읽고 쓰는 공격에 대한 대책으로 올바른 것은?
  5. CPU를 거치지 않고 주변 장치와 메모리 사이에서 직접 데이터를 전송하는 구조는?
  6. 캐시의 쓰기 방식 중 라이트백 방식의 설명으로 올바른 것은?
  7. IOMMU의 주된 역할로 올바른 것은 무엇입니까?
  8. 디바이스 드라이버의 역할로 올바른 것은 무엇입니까?
  9. 일반적인 OS에서 애플리케이션이 장치의 레지스터를 직접 읽고 쓰지 못하게 하는 주된 이유는 무엇입니까?
  10. CPU 메모리를 핀 고정(페이지 락)한 뒤 GPU로 전송하면 빨라지는 이유로 올바른 것은?
