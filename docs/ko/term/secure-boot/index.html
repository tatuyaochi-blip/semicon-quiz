보안 부팅(Secure Boot)란?

부팅 각 단계에서 다음에 실행할 소프트웨어의 전자 서명을 확인하여 올바른 것만 기동하는 구조. 신뢰 체인을 이어 간다.

일본어 명칭: セキュアブート

분야: 하드웨어 보안

관련 용어

롤백 방지(Anti-rollback) 변조 방지성(Tamper Resistance) 사이드 채널 공격(Side-channel Attack) 상수 시간 구현(Constant-time Implementation) 신뢰의 근간(Root of Trust) 엔클레이브(Enclave) 원격 증명(Remote Attestation) 위조 칩(Counterfeit Chip) 전력 분석 공격(Power Analysis Attack) 진성 난수 생성기(True Random Number Generator)
