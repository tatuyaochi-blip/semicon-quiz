보안 부팅(secure boot)란?

부팅 단계마다 다음 소프트웨어의 디지털 서명을 검증하여 정당한 소프트웨어만 시작하는 메커니즘으로, 신뢰 사슬을 이룹니다.

일본어 명칭: セキュアブート

보안 부팅(secure boot)은(는) 하드웨어 보안 등 1개 분야의 연습 문제 1개에 나와요.

보안 부트(Secure Boot)의 설명으로 올바른 것은?

  1. APC를 빠르게 부팅하기 위한 구조
  2. B부팅의 각 단계에서 다음에 실행할 소프트웨어의 전자 서명을 확인하고, 올바른 것만 부팅한다
  3. C부팅할 때마다 디스크 내용을 모두 삭제하는 구조
정답과 해설 보기

정답: B. 부팅의 각 단계에서 다음에 실행할 소프트웨어의 전자 서명을 확인하고, 올바른 것만 부팅한다

보안 부트에서는 변경할 수 없는 ROM 코드가 첫 번째 부트로더의 서명을 확인하고, 그 부트로더가 다음 단계나 OS 커널의 서명을 확인하는 식으로 신뢰의 사슬(chain of trust)을 이어 갑니다. 어느 단계에서든 서명이 맞지 않으면 부팅을 멈추므로, 악성코드가 부트로더나 OS의 부팅 부분을 바꿔도 실행할 수 없습니다. 스마트폰, PC, 임베디드 기기에서 널리 사용됩니다.
