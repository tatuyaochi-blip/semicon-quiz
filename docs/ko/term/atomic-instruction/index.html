원자적 명령어(atomic instruction)란?

메모리의 읽기와 쓰기를 도중에 다른 코어가 끼어들 수 없는 하나의 동작으로 수행하는 명령. CAS, 페치 앤드 애드, LR/SC 등.

일본어 명칭: アトミック命令

분야: 멀티코어와 동기화

일반 로드와 스토어로는 부족한 이유

counter++ 같은 문장은 로드, 덧셈, 스토어로 컴파일됩니다. 두 코어가 동시에 이를 실행하면 둘 다 같은 이전 값을 로드하고 둘 다 이전 값 + 1을 저장하여 증가 한 번이 사라질 수 있습니다. 원자적 명령어는 읽기-수정-쓰기 전체를 하나의 분할 불가능한 동작으로 수행합니다. 그 위치에 대한 다른 코어의 접근이 중간에 끼어들 수 없고, 다른 코어는 동작 이전 또는 이후의 값만 관찰합니다. 이 보장은 멀티코어 프로세서에서 락, 카운터, 락프리 자료 구조의 기반입니다.

대표적인 원자적 연산의 종류

테스트 앤드 셋(test-and-set)과 원자적 스왑은 새 값을 쓰고 이전 값을 반환합니다. 페치 앤드 애드(fetch-and-add)는 메모리에 값을 더하고 이전 값을 반환합니다. 비교 후 교환(CAS)은 메모리가 아직 기댓값을 가지고 있을 때만 새 값을 쓰고 성공 여부를 알려 줍니다. 로드 예약/조건부 스토어(LR/SC)는 연산을 예약하는 로드와, 예약이 사라졌으면 실패하는 스토어로 나눕니다. RISC-V는 amoadd, amoswap 같은 원자적 메모리 연산(AMO) 명령어도 제공하며, x86은 cmpxchg, xadd 같은 명령어에 LOCK 접두사를 붙입니다.

하드웨어가 원자성을 유지하는 방법

초기 시스템은 연산하는 동안 공유 버스를 잠갔습니다. 최신 코어는 대신 캐시 일관성 프로토콜을 사용합니다. 코어가 MESI 계열 프로토콜의 Modified 또는 Exclusive 상태로 캐시 라인의 독점 소유권을 얻고, 읽기-수정-쓰기가 끝날 때까지 그 라인에 대한 다른 코어의 요청을 지연시킵니다. 따라서 원자적 연산은 캐시된 일반 로드보다 훨씬 느리며, 경합이 있으면 라인이 코어 사이를 오갑니다. 원자적 연산은 메모리 순서와도 상호 작용하며, x86에서 LOCK이 붙은 명령어는 완전한 메모리 배리어로 동작합니다.

원자적 명령어에서 락으로

스핀락은 원자적 명령어로 락 변수를 설정하려 시도하고, 이미 잡혀 있으면 루프에서 재시도합니다. 원자적 쓰기를 직접 재시도하면 시도할 때마다 독점 소유권을 요구하므로 일관성 트래픽이 많아집니다. 테스트 앤드 테스트 앤드 셋(test-and-test-and-set) 패턴은 로컬 캐시에 있는 공유 사본을 일반 읽기로 스핀하다가 락이 비어 보일 때만 원자적 연산을 시도합니다. 락프리 구조는 CAS나 LR/SC를 직접 사용하지만, CAS 기반 설계는 값이 바뀌었다가 원래대로 돌아와 알아채지 못하는 ABA 문제에 대비해야 합니다.

자주 묻는 질문

원자적 명령어와 락의 차이는 무엇인가요?

원자적 명령어는 하나의 메모리 위치에 대한 한 번의 읽기-수정-쓰기를 하드웨어에서 분할 불가능하게 만듭니다. 락은 원자적 명령어로 만든 소프트웨어 구조로, 여러 위치에 접근하는 더 긴 코드 구간을 보호합니다.

비교 후 교환(CAS)이란?

메모리 위치가 아직 기댓값을 가지고 있을 때만 새 값을 쓰고, 성공 또는 실패를 알려 주는 것을 모두 하나의 원자적 연산으로 수행하는 것입니다.

원자적 연산이 느린 이유는?

코어가 캐시 라인의 독점 소유권을 얻어야 하고 흔히 메모리 순서도 강제해야 하며, 여러 코어가 같은 라인을 두고 경합하면 라인이 코어 사이에서 반복적으로 전송되고 무효화되기 때문입니다.

이 용어가 포함된 비교

  • 스핀락과 뮤텍스의 차이점 정리스핀락과 뮤텍스를 표로 비교합니다. 대기 방식(바쁜 대기와 슬립), CPU 사용, 적합한 보유 시간, 커널 안에서의 사용, 우선순위 역전, futex를 안내합니다.

관련 용어

거짓 공유(False Sharing) 데드락(Deadlock) 데이터 레이스(Data Race) 디렉터리 방식(Directory-based Coherence) 락 프리(Lock-free) 메모리 배리어(Memory Barrier) 메모리 일관성 모델(Memory Consistency Model) 뮤텍스(Mutex) 배리어 동기화(Barrier Synchronization) 세마포어(Semaphore)
