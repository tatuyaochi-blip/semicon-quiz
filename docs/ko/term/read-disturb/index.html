리드 디스터브(Read Disturb)란?

NAND 플래시에서 같은 블록을 여러 번 읽는 동안 읽지 않은 셀에도 약한 전압이 걸려 문턱 전압이 조금씩 변하는 현상.

일본어 명칭: リードディスターブ

리드 디스터브(Read Disturb)은(는) SRAM과 플래시 메모리 등 1개 분야의 연습 문제 1개에 나와요.

분야: SRAM과 플래시 메모리

한 페이지를 읽을 때 이웃 셀이 스트레스를 받는 이유

NAND 플래시 셀은 스트링 단위로 직렬 연결되어 있습니다. 하나의 워드 라인을 읽으려면 선택된 셀의 게이트에 읽기 전압을 인가하고, 블록 안의 다른 모든 워드 라인에는 저장 데이터와 무관하게 셀을 완전히 켤 만큼 높은 수 볼트의 패스 전압을 인가합니다. 이 패스 전압은 선택되지 않은 셀의 터널 산화막에 약한 전계를 만들고, 읽을 때마다 그 저장층에 아주 적은 양의 전하가 주입됩니다. 읽기가 반복되면 이 셀들의 문턱 전압이 서서히 올라갑니다. 문턱 전압이 가장 낮은 소거 상태의 셀이 보통 가장 취약합니다.

리드 디스터브가 문제가 되는 경우

한 번의 읽기로 인한 변동은 무시할 수 있지만, 같은 블록을 수만에서 수십만 번 읽으면 리드 디스터브가 무시할 수 없게 됩니다. 따라서 부트 코드나 자주 참조되는 룩업 테이블처럼 매우 자주 읽히지만 거의 다시 쓰이지 않는 데이터를 담은 블록이 영향을 받습니다. 여러 비트를 저장하는 셀(MLC, TLC, QLC)은 상태를 구분하는 문턱 전압 간격이 좁아 더 민감하며, 프로그램/소거를 많이 반복해 마모된 셀은 더욱 취약합니다.

SSD 컨트롤러의 대응 방법

컨트롤러는 블록마다 읽기 카운터를 관리합니다. 카운트가 한계에 가까워지거나 오류 정정(ECC)에서 정정된 비트 수가 늘어나기 시작하면, 컨트롤러는 데이터를 새 블록으로 복사하고 나중에 이전 블록을 소거합니다. 이 과정을 흔히 리드 리클레임 또는 리프레시라고 합니다. 변동은 영구적인 손상이 아니라 추가된 전하 때문이므로, 블록을 소거하고 다시 쓰면 원래대로 돌아옵니다. 기준 전압을 이동시켜 다시 읽는 리드 리트라이로도 분포가 이동한 페이지를 복구할 수 있습니다.

리드 디스터브와 데이터 보존, 다른 메모리에서의 현상

리드 디스터브는 문턱 전압을 높이며 블록을 읽는 빈도에 따라 달라집니다. 반면 보존(retention) 손실은 데이터에 전혀 접근하지 않아도 저장된 전하가 시간이 지나면서 빠져나가 문턱 전압을 낮춥니다. 이 용어는 다른 메모리에서도 쓰입니다. STT-MRAM에서는 쓰기에 쓰는 것과 같은 자기 터널 접합으로 읽기 전류가 흐르므로, 비트가 반전되지 않도록 스위칭 전류보다 충분히 작게 유지해야 하지만, 전류가 너무 작으면 신호가 약해집니다. SRAM에서는 셀에 접근할 때 저장된 값이 뒤집힐 수 있는 관련 위험을 읽기 안정성(read stability)으로 나타냅니다.

정답: B. 리드 디스터브

NAND 읽기에서는 선택하지 않은 셀에도 수 V의 패스 전압을 걸어 도통시키므로, 반복해서 읽는 동안 미량의 전자가 주입되어 문턱 전압이 올라갑니다. 이것이 리드 디스터브이며 수만~수십만 회 읽기에서 문제가 됩니다. 읽기 빈도가 높은 데이터가 모인 블록에서 일어나기 쉬우며, 컨트롤러는 읽기 횟수를 세어 상한이 가까워지면 데이터를 다른 블록에 다시 씁니다.

자주 묻는 질문

NAND 플래시의 리드 디스터브란 무엇인가요?

리드 디스터브는 읽을 때마다 인가되는 패스 전압 때문에 NAND 블록 안의 선택되지 않은 셀의 문턱 전압이 서서히 올라가는 현상입니다. 읽기 횟수가 충분히 많아지면 저장된 비트가 뒤집힐 수 있습니다.

리드 디스터브는 영구적인 손상인가요?

아닙니다. 변동은 셀에 추가로 주입된 전하에서 비롯되므로, 프로그램/소거 반복에 의한 마모와 달리 블록을 소거하고 데이터를 다시 쓰면 정상적인 마진이 회복됩니다.

리드 디스터브와 데이터 보존 오류의 차이는 무엇인가요?

리드 디스터브는 블록의 읽기 횟수에 비례하여 전하를 더하고 문턱 전압을 높입니다. 보존 오류는 시간이 지나면서 전하가 빠져나가 생기며, 데이터에 접근하지 않아도 문턱 전압이 낮아집니다.
