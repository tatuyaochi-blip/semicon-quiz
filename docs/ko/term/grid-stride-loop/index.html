그리드 스트라이드 루프(Grid-stride Loop)란?

각 스레드가 전체 스레드 수 간격으로 요소를 처리하는 루프로 커널을 작성하는 방법. 실행하는 스레드 수와 요소 수를 분리할 수 있다.

일본어 명칭: グリッドストライドループ

그리드 스트라이드 루프(Grid-stride Loop)은(는) GPU 프로그래밍 등 1개 분야의 연습 문제 1개에 나와요.
