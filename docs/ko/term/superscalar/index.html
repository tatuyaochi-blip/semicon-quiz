슈퍼스칼라(Superscalar)란?

1클록 사이클에 여러 명령을 동시에 발행·실행하는 프로세서 방식. 여러 연산기를 나란히 두고 서로 의존하지 않는 명령을 병렬로 처리한다.

일본어 명칭: スーパースカラ

슈퍼스칼라(Superscalar)은(는) CPU와 아키텍처, ISA와 어셈블리 등 2개 분야의 연습 문제 4개에 나와요.

분야: CPU와 아키텍처

슈퍼스칼라 코어의 동작 원리

슈퍼스칼라 프로세서는 클록당 여러 명령을 페치하고 디코딩하며, 그중 어떤 명령이 서로 의존하는지 확인한 뒤, 독립적인 명령을 정수 ALU, 로드/스토어 유닛, 부동소수점 유닛, 분기 유닛 같은 여러 실행 유닛에 디스패치합니다. 따라서 처리량이 클록당 1명령을 넘을 수 있으며, 이는 클록당 명령 수(IPC)가 1보다 크거나 명령당 클록 수(CPI)가 1보다 작다는 뜻입니다. 평균 CPI가 0.5인 2 GHz 코어는 초당 40억 개의 명령을 실행합니다. 최근 고성능 코어의 폭은 약 6~10명령입니다.

슈퍼스칼라와 파이프라이닝, VLIW

파이프라이닝은 연속된 명령의 단계를 겹쳐 실행하며, 최선의 경우 클록당 1명령을 완료합니다. 슈퍼스칼라 코어는 사실상 여러 파이프라인을 나란히 실행합니다. VLIW(very long instruction word) 머신도 사이클당 여러 연산을 실행하지만, 컴파일러가 병렬성을 찾아 각 명령에 채워 넣는 반면, 슈퍼스칼라 코어는 실행 시 하드웨어로 병렬성을 찾으므로 기존 바이너리도 재컴파일 없이 이점을 얻습니다. 슈퍼스칼라 발행은 순차(in-order) 방식일 수도 있고, 대부분의 고성능 코어에서처럼 비순차(out-of-order) 실행 및 레지스터 리네이밍과 결합될 수도 있습니다.

폭을 무한정 늘릴 수 없는 이유

실제 프로그램이 제공하는 명령어 수준 병렬성에는 한계가 있습니다. 데이터 의존성, 분기, 캐시 미스가 발행 슬롯을 멈추게 하므로, 넓은 머신을 계속 가동하려면 분기 예측, 비순차 실행 윈도, 대용량 캐시가 필요합니다. 하드웨어 비용도 급격히 증가합니다. 동시에 발행되는 명령 사이의 의존성 검사와 결과 포워딩 경로는 폭의 대략 제곱에 비례해 늘어나고, 레지스터 파일에는 더 많은 포트가 필요합니다. 어느 지점을 넘으면 슬롯 하나를 추가해도 상당한 면적, 전력, 타이밍상의 어려움에 비해 IPC가 거의 늘지 않습니다.

프런트엔드의 중요성

사이클당 많은 명령을 발행하려면 사이클당 많은 명령을 디코딩해야 합니다. 고정 길이 명령어 세트는 명령의 경계를 미리 알 수 있어 이것이 쉽습니다. x86 같은 가변 길이 명령어 세트는 먼저 경계를 찾은 뒤 복잡한 명령을 더 단순한 마이크로 연산으로 분해해야 하며, 많은 코어가 자주 실행되는 코드가 디코딩을 건너뛸 수 있도록 마이크로 연산 캐시를 둡니다. 슈퍼스칼라 실행은 멀티코어나 SIMD와도 다릅니다. 이들은 이웃한 명령 사이가 아니라 스레드 간, 데이터 요소 간의 병렬성을 활용합니다.

정답과 해설 보기

정답: A. 슈퍼스칼라

슈퍼스칼라는 여러 연산기를 갖추고 서로 의존하지 않는 명령어를 1클록에 여러 개 발행하여 IPC를 1보다 크게 만드는 방식입니다. 최근 고성능 코어는 1클록에 6~10개 명령어 정도를 처리할 수 있는 폭을 갖습니다. 명령어의 순서를 바꿔 실행하는 비순차 실행과 결합해 성능을 높이지만, 의존 관계 검사 회로는 폭의 제곱 정도로 복잡해지기 때문에 무작정 넓힐 수는 없습니다.

클록 주파수 2 GHz, 평균 CPI(명령어 1개당 평균 클록 수) 0.5인 프로세서가 1초 동안 실행할 수 있는 명령어 수는 대략 얼마인가?

  1. A10억 명령어
  2. B40억 명령어
  3. C1억 명령어
정답과 해설 보기

정답: B. 40억 명령어

1초 동안의 클록 수는 2×10⁹이고 명령어 1개당 평균 0.5클록이므로 2×10⁹ ÷ 0.5 = 4×10⁹, 즉 40억 명령어입니다. CPI가 1 미만인 것은 슈퍼스칼라로 1클록에 여러 명령어를 실행하기 때문입니다. 성능은 「명령어 수 × CPI ÷ 주파수」인 실행 시간으로 결정되므로 명령어 수, CPI, 주파수 중 하나만으로는 비교할 수 없습니다.

자주 묻는 질문

슈퍼스칼라와 파이프라인 프로세서의 차이

파이프라인 프로세서는 연속된 명령의 단계를 겹쳐 실행하며 클록당 최대 약 1명령을 완료합니다. 슈퍼스칼라 프로세서는 여러 파이프라인과 실행 유닛을 가지므로 클록당 여러 명령을 발행하고 완료할 수 있습니다.

CPU의 IPC란?

IPC는 클록당 명령 수(instructions per clock)로, 사이클당 완료되는 평균 명령 수이며 CPI의 역수입니다. 명령 수가 같다면 성능은 IPC × 클록 주파수에 비례합니다.

슈퍼스칼라와 멀티코어는 같은 것인가요?

다릅니다. 슈퍼스칼라 실행은 하나의 코어 안에서 한 스레드의 여러 명령을 병렬로 실행하고, 멀티코어는 칩에 여러 코어를 두어 별도의 스레드를 실행합니다.
