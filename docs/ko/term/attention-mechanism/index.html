어텐션(attention)란?

각 토큰이 다른 모든 토큰과의 관계 강도를 계산해 정보를 모으는 Transformer의 구조. 계산량은 시퀀스 길이의 제곱에 비례한다.

일본어 명칭: アテンション

어텐션(attention)은(는) AI 하드웨어·소프트웨어 스택 등 1개 분야의 연습 문제 5개에 나와요.

분야: AI 하드웨어·소프트웨어 스택

도전해 보기: 어텐션(attention) 관련 문제

Transformer 셀프 어텐션의 계산량은 입력 시퀀스 길이 n에 대해 어떻게 늘어나는가?

  1. An에 비례하여 늘어난다
  2. Bn의 제곱에 비례하여 늘어난다
  3. Cn과 관계없이 일정하다
정답과 해설 보기

정답: B. n의 제곱에 비례하여 늘어난다

셀프 어텐션에서는 각 토큰의 Query와 모든 토큰의 Key 사이의 내적을 계산하여 n×n 가중치 표를 만듭니다. 따라서 계산량과, 단순하게 만들었을 때의 중간 표의 메모리는 시퀀스 길이의 제곱에 비례합니다. 길이가 2배가 되면 어텐션 부분은 4배가 되므로, 긴 문장을 다룰수록 어텐션의 효율이 성능을 좌우합니다.

FlashAttention 등 고속 어텐션 구현의 주된 발상으로 올바른 것은 무엇인가?

  1. A계산을 타일로 나누어 칩 위의 메모리에서 진행하고, n×n의 큰 중간 표를 HBM에 쓰지 않음으로써 메모리 읽기/쓰기를 줄인다
  2. B어텐션 계산을 생략하고 근사한 답을 낸다
  3. C어텐션을 CPU에서 계산한다
정답과 해설 보기

정답: A. 계산을 타일로 나누어 칩 위의 메모리에서 진행하고, n×n의 큰 중간 표를 HBM에 쓰지 않음으로써 메모리 읽기/쓰기를 줄인다

단순한 구현에서는 n×n 표를 HBM에 쓰고, 소프트맥스를 위해 다시 읽고, 다시 Value와의 곱을 위해 또 읽으므로 메모리 읽기/쓰기가 성능을 결정해 버립니다. FlashAttention은 Query와 Key·Value를 블록으로 나누어 공유 메모리에 읽어 들이고, 소프트맥스를 조금씩 갱신하면서 계산을 한 번에 진행하여 표를 HBM에 쓰지 않습니다. 계산량은 같아도 메모리 읽기/쓰기가 크게 줄어 빨라집니다.

해설 속 어텐션(attention)

  • 셀프 어텐션에서는 각 토큰의 Query와 모든 토큰의 Key 사이의 내적을 계산하여 n×n 가중치 표를 만듭니다.

  • 어텐션 계산에서는 새 토큰이 그때까지의 모든 토큰의 Key와 Value를 참조합니다.

어텐션(attention)이(가) 나오는 문제 (5)

  1. Transformer 셀프 어텐션의 계산량은 입력 시퀀스 길이 n에 대해 어떻게 늘어나는가?
  2. FlashAttention 등 고속 어텐션 구현의 주된 발상으로 올바른 것은 무엇인가?
  3. 파라미터 수 N의 대규모 언어 모델에서 토큰 1개를 생성하는 추론에 필요한 연산 수의 기준은 무엇인가(어텐션 부분 제외)?
  4. 대규모 언어 모델의 추론에서 사용되는 KV 캐시의 역할로 올바른 것은 무엇인가?
  5. 소프트맥스 함수 exp(xi)/Σexp(xj)를 계산할 때 각 xi에서 최댓값을 뺀 뒤 계산하는 경우가 많은 이유로 올바른 것은 무엇인가?
