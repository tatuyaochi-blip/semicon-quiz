마이컴(마이크로컨트롤러)란?

CPU, 메모리, 타이머와 ADC 등의 주변 기능을 1칩에 통합한 작은 컴퓨터. 가전이나 자동차 등의 기기에 내장되어 제어를 담당한다. MCU라고도 한다.

일본어 명칭: マイコン(マイクロコントローラ)

마이컴(마이크로컨트롤러)은(는) 임베디드 시스템과 펌웨어, 차량용 반도체와 기능 안전, 반도체 산업과 시장 등 23개 분야의 연습 문제 74개에 나와요.

분야: CPU와 아키텍처

MCU의 내부 구성

마이크로컨트롤러(MCU)는 완전한 소형 컴퓨터를 하나의 다이에 담습니다. CPU 코어, 프로그램을 저장하는 내장 플래시, 작업 데이터용 SRAM, 그리고 외부 세계와 직접 연결되는 주변 장치입니다. 대표적인 주변 장치로는 PWM 신호를 만드는 타이머, 축차 비교형(SAR) ADC, 범용 I/O 핀, 워치독 타이머, 그리고 UART, SPI, I²C, CAN 같은 직렬 인터페이스가 있습니다. 프로그램이 이미 칩 안에 저장되어 있으므로 MCU는 전원을 넣자마자 곧바로 펌웨어 실행을 시작하며, 이는 즉시 준비되어야 하는 제어 작업에 적합합니다.

마이크로컨트롤러와 마이크로프로세서

마이크로프로세서나 애플리케이션 SoC는 연산 성능을 목표로 합니다. 외부 DRAM과 스토리지에서 완전한 운영체제를 실행하며 주변에 지원 칩이 필요합니다. MCU는 비용, 크기, 저전력, 예측 가능한 실시간 응답을 목표로 하며, 자체 메모리에서 베어메탈 펌웨어나 소형 실시간 운영체제(RTOS)를 실행합니다. 자동차 한 대에는 수십에서 백 개가 넘는 MCU가 들어가며, 가전과 산업 장비에서도 모터 제어, 센싱, 사용자 인터페이스에 쓰입니다. 프로그램 저장 방식도 바뀌고 있습니다. 내장 플래시는 첨단 노드에서 집적하기 어려워 MRAM과 ReRAM이 그 자리를 대신하고 있습니다.

실제 세계와의 연결

MCU 핀은 작은 전류만 공급할 수 있으므로 부하는 인터페이스 회로를 거쳐 구동합니다. 트랜지스터 스위치에는 (구동 전압 − 0.7 V)를 필요한 베이스 전류로 나눈 값으로 정한 베이스 저항이 필요하며, 전력 소자에는 수 밀리암페어의 로직 신호를 암페어 단위의 게이트 전류로 바꾸는 게이트 드라이버가 필요합니다. DAC가 없어도 PWM을 저역 통과 필터로 거르면 진폭 × 듀티비의 아날로그 전압을 만들 수 있습니다. 저항 분압기로 측정할 때는 분압 저항과 ADC의 부하 효과를 고려하거나 신호를 버퍼링해야 합니다.

차량용 MCU의 안전 메커니즘

차량용 MCU는 조용히 오동작하는 대신 고장을 검출하는 하드웨어를 추가합니다. 윈도 워치독은 소프트웨어가 너무 늦거나 너무 이르게 클리어하면 시스템을 리셋합니다. SEC-DED 오류 정정 부호(ECC)는 메모리의 1비트 오류를 정정하고 2비트 오류를 표시해 소프트웨어가 안전 상태로 전환할 수 있게 합니다. 클록 모니터는 메인 클록을 독립된 발진기와 비교하고, 자체 기준 전압을 가진 전압 모니터는 저전압과 과전압을 모두 검출합니다. 전원 투입 시 로직 및 메모리 내장 자체 테스트(BIST)는 주행을 시작하기 전에 안전 회로 자체의 잠재 고장을 찾아냅니다.

수정 발진기가 시계나 마이컴의 클록원으로 널리 사용되는 주된 이유는 무엇입니까?

  1. A출력 전력이 매우 크기 때문
  2. B수정 진동자의 Q값이 매우 높고 주파수가 정확하며 안정적이기 때문
  3. C주파수를 넓은 범위에서 자유롭게 바꿀 수 있기 때문
정답과 해설 보기

정답: B. 수정 진동자의 Q값이 매우 높고 주파수가 정확하며 안정적이기 때문

수정 진동자는 압전 효과를 이용한 기계적 공진자로, Q값이 수만~수십만으로 매우 높고 주파수 오차는 보통 ±수십 ppm 이내입니다. 시계용 32.768 kHz(2¹⁵ Hz)는 15번의 2분주로 1초를 만들 수 있어 사용됩니다. 온도 보상형(TCXO)은 ±1 ppm 이하, 항온조형(OCXO)은 더 높은 안정도를 얻을 수 있습니다. 대신 주파수를 거의 바꿀 수 없으므로, 가변으로 하려면 PLL과 조합합니다.

마이크로컨트롤러에서 PWM 신호를 로우패스 필터에 통과시켜 아날로그 전압을 만드는 방법에서 출력 전압을 결정하는 것은 무엇인가?

  1. A펄스의 듀티비(한 주기 중 켜져 있는 시간의 비율)
  2. B펄스의 색
  3. C마이크로컨트롤러의 메모리 용량
정답과 해설 보기

정답: A. 펄스의 듀티비(한 주기 중 켜져 있는 시간의 비율)

PWM 신호를 로우패스 필터로 평균화하면 출력 전압은 "진폭 × 듀티비"가 되어, 5 V에서 40%라면 약 2 V입니다. 분해능은 타이머의 카운트 수로 결정되며, PWM 주파수를 필터의 차단 주파수보다 충분히 높게 하면 리플이 줄어듭니다. 전용 DAC 없이 아날로그 전압을 만들 수 있어 LED 조광, 모터 속도 제어, 간이 음성 출력에 사용되지만, 응답 속도와 정밀도는 리플과 트레이드오프 관계입니다.

자주 묻는 질문

마이크로컨트롤러와 마이크로프로세서 차이

마이크로컨트롤러는 자체 완결형 제어 작업을 위해 CPU, 프로그램 메모리, RAM, I/O 주변 장치를 하나의 칩에 통합합니다. 마이크로프로세서는 주로 CPU로 구성되며 외부 메모리와 지원 칩에 의존하고, 비용과 전력을 희생해 연산 성능을 얻습니다.

마이컴에서 워치독 타이머는 무슨 역할을 하나요?

정상적인 소프트웨어가 주기적으로 클리어해야 하며, 크래시나 멈춤으로 타이머가 만료되면 MCU를 자동으로 리셋합니다. 윈도 워치독은 너무 이른 클리어도 고장으로 처리합니다.

DAC 없이 마이컴으로 아날로그 전압을 출력하는 방법은?

PWM 신호를 생성해 저역 통과 필터에 통과시키면 출력이 평균적으로 전원 진폭 × 듀티비가 됩니다. 분해능은 타이머의 카운트 범위에 따라 정해지며, 리플과 응답 속도는 트레이드오프 관계입니다.
