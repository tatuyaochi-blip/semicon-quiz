인메모리 컴퓨팅(in-memory computing)란?

메모리 어레이 안에서 곱셈-누산 등의 연산을 수행해 메모리와 프로세서 사이의 데이터 이동을 줄이는 개념. 저항 변화 소자 등을 AI 추론 처리에 쓰는 연구가 진행 중이다.

일본어 명칭: インメモリコンピューティング

인메모리 컴퓨팅(in-memory computing)은(는) 차세대 메모리 등 1개 분야의 연습 문제 1개에 나와요.

정답과 해설 보기

정답: C. 메모리 어레이 안에서 곱셈 누산 연산을 수행하여 AI 처리의 데이터 이동과 소비 전력을 줄인다

AI 처리에는 방대한 곱셈 누산 연산이 필요하며, 메모리와 연산기 사이의 데이터 이동이 소비 전력의 대부분을 차지합니다. 저항 변화 소자를 어레이로 배열하고 가중치를 컨덕턴스로 기억시킨 뒤 입력을 전압으로 주면, 옴의 법칙(I = GV)으로 곱셈, 키르히호프의 전류 법칙으로 덧셈을 배선 위에서 한 번에 수행할 수 있습니다. 다만 아날로그 연산이므로 소자의 편차와 ADC의 정밀도가 과제입니다.
