봉투 암호화(Envelope Encryption)란?

데이터를 데이터 암호화 키(DEK)로 암호화하고, 그 DEK를 별도의 키 암호화 키(KEK)로 암호화(래핑)하여 데이터와 함께 저장하는 방식. KEK는 KMS나 HSM 안에 두고 밖으로 내보내지 않으며, 큰 데이터는 로컬에서 암호화할 수 있다. KEK를 갱신할 때는 데이터 전체가 아니라 작은 DEK만 다시 암호화하면 된다. 클라우드 스토리지나 데이터베이스의 암호화에서 널리 사용된다.

  1. A데이터를 DEK로 암호화하고, DEK는 키 관리 서비스 안의 KEK로 암호화하여 데이터와 함께 저장한다
  2. B모든 데이터를 키 관리 서비스로 보내, 키 관리 서비스 안에 있는 하나의 키로 데이터를 직접 암호화해 받는다
  3. C데이터를 암호화한 키를 암호문과 같은 장소에 암호화하지 않고 저장하여 꺼내기 쉽게 한다

정답: A. 데이터를 DEK로 암호화하고, DEK는 키 관리 서비스 안의 KEK로 암호화하여 데이터와 함께 저장한다

봉투 암호화에서는 데이터마다 DEK를 만들어 데이터를 대칭 키 암호로 암호화하고, DEK는 KMS나 HSM 안에 있는 KEK로 암호화(래핑)하여 암호화한 데이터 옆에 저장합니다. 큰 데이터를 키 관리 서비스로 보낼 필요가 없고 KEK는 장치 밖으로 나가지 않으므로, 엄중하게 지켜야 할 키를 소수로 모을 수 있습니다. KEK를 갱신할 때는 데이터 전체를 다시 암호화하지 않고 작은 DEK만 다시 암호화하면 됩니다. 데이터를 읽을 때는 래핑된 DEK를 KMS에서 복호화해 받고, 로컬에서 데이터를 복호화합니다.
