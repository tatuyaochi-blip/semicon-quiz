CAS 레이턴시(CAS Latency)란?

DRAM에서 열 주소를 지정한 읽기 명령부터 데이터가 출력되기까지의 클록 수. CL로 줄여 쓴다. 값이 작을수록 응답이 빠르다.

일본어 명칭: CASレイテンシ

CAS 레이턴시(CAS Latency)은(는) DRAM 등 1개 분야의 연습 문제 2개에 나와요.

분야: DRAM

CAS 레이턴시가 나타내는 것

CAS는 column address strobe(열 주소 스트로브)의 약자입니다. DRAM 읽기는 먼저 행을 활성화하여 센스 앰프에 복사한 다음, 열 주소를 담은 읽기 명령을 내립니다. CAS 레이턴시(CL)는 이 읽기 명령부터 첫 데이터가 출력에 나타날 때까지의 클록 사이클 수입니다. 그 뒤 버스트의 나머지 데이터가 연속된 클록 에지에서 이어집니다. CL은 사이클 수로 세므로 실제 지연 시간(ns)은 CL에 클록 주기를 곱한 값이며, CL이 작을수록 빠른 것은 클록 속도가 같을 때뿐입니다.

CL을 나노초로 환산하는 방법

DDR 메모리의 데이터 전송률은 클록 주파수의 2배이므로, DDR4-3200은 주기 0.625 ns인 1600 MHz 클록으로 초당 32억 회 전송합니다. 이때 CL22는 22 × 0.625 ns ≈ 13.75 ns에 해당합니다. DDR3-1600은 주기 1.25 ns인 800 MHz 클록으로 동작하므로 CL11도 약 13.75 ns입니다. 새 세대의 CL 숫자가 더 크더라도 실제 지연은 거의 변하지 않은 것인데, 메모리 셀 어레이의 속도는 세대 간에 거의 개선되지 않는 반면 인터페이스 클록은 계속 높아지기 때문입니다.

DRAM 타이밍 중 CL의 위치

CL은 접근 과정의 일부일 뿐입니다. 필요한 행이 열려 있지 않으면 컨트롤러는 먼저 뱅크를 프리차지하여 이전 행을 닫고(tRP), 새 행을 활성화한 뒤 RAS-CAS 지연(tRCD)을 기다리고 나서야 읽기 명령을 내리며, 그다음에 CL을 기다립니다. 타이밍은 CL-tRCD-tRP처럼 함께 표기하는 경우가 많습니다. 행이 이미 센스 앰프에 열려 있는 페이지 히트에서는 CL만 필요하므로, 메모리 컨트롤러는 요청 순서를 바꿔 같은 행에 대한 접근을 묶고 히트 비율을 높입니다.

레이턴시와 대역폭

CAS 레이턴시는 첫 워드가 나오기까지 걸리는 시간을 나타내고, 대역폭은 일단 시작된 데이터가 얼마나 빠르게 흐르는지를 나타냅니다. 메모리 세대가 빨라지면 주로 데이터 전송률과 버스트 길이를 늘려 대역폭이 높아지며, 나노초 단위의 첫 워드 레이턴시는 비슷한 범위에 머물러 왔습니다. 큰 블록을 스트리밍하는 작업은 대역폭의 이점을 얻고, 포인터 추적이나 프로세서 캐시에서 미스가 나는 랜덤 접근은 레이턴시에 더 민감합니다. 따라서 모듈을 비교할 때는 CL 숫자만 보지 말고, CL을 나노초로 환산하고 다른 타이밍도 함께 고려해야 합니다.

정답과 해설 보기

정답: B. 읽기 명령(열 주소 지정)부터 데이터가 출력될 때까지의 클록 수

CAS 레이턴시는 열 주소를 지정하는 읽기 명령부터 첫 데이터가 나올 때까지의 클록 수입니다. 실제 시간은 CL × 클록 주기이므로, DDR4-3200 CL22는 22 × 0.625 ns ≈ 13.75 ns, DDR3-1600 CL11도 11 × 1.25 ns ≈ 13.75 ns로, 수치가 커도 시간은 거의 같습니다. 셀 어레이의 속도는 세대가 바뀌어도 거의 변하지 않으므로 CL 수치는 세대와 함께 커지고 있습니다.

자주 묻는 질문

RAM의 CAS 레이턴시는 무엇을 의미하나요?

CAS 레이턴시는 열 주소를 지정한 읽기 명령부터 첫 데이터가 출력될 때까지의 메모리 클록 사이클 수입니다. 여기에 클록 주기를 곱하면 나노초 단위의 실제 지연 시간이 됩니다.

CAS 레이턴시가 낮으면 항상 더 빠른가요?

클록 속도가 같을 때만 그렇습니다. 주파수가 더 높은 모듈은 CL이 더 크더라도 나노초 단위의 레이턴시가 같거나 더 낮을 수 있으므로, 비교하기 전에 클록 주기를 이용해 CL을 환산해야 합니다.

새로운 DDR 세대일수록 CAS 레이턴시 숫자가 커지는 이유는 무엇인가요?

DRAM 셀 어레이의 나노초 단위 응답 시간은 거의 변하지 않은 반면 클록 주기는 계속 짧아지고 있습니다. 따라서 거의 같은 지연을 채우는 데 더 많은 클록 사이클이 필요합니다.
