포트 번호(Port Number)란?

TCP나 UDP에서 단말 안의 어느 애플리케이션으로 가는 통신인지를 구별하는 0~65535의 번호. HTTP의 80, HTTPS의 443, DNS의 53 등 0~1023은 잘 알려진 포트(well-known port)라고 한다.

일본어 명칭: ポート番号

포트 번호(Port Number)은(는) 네트워크 기초 등 1개 분야의 연습 문제 4개에 나와요.

정답과 해설 보기

정답: A. HTTP 80, HTTPS 443, DNS 53

포트 번호는 0~65535의 16비트 번호로, IP 주소로 도착한 단말 안에서 어느 애플리케이션으로 가는 통신인지를 구별합니다. 0~1023은 잘 알려진 포트(well-known port)라고 하며 주요 서비스에 할당되어 있습니다. 대표적인 것은 HTTP 80, HTTPS 443, DNS 53, SSH 22, SMTP(메일 전송) 25입니다. 클라이언트 쪽은 OS가 그때그때 고른 번호(임시 포트, ephemeral port)를 출발지 포트로 사용합니다. 표준과 다른 번호로 서비스를 운영할 수도 있으며, 8080은 웹 개발용이나 프록시 서버 등에 자주 쓰이지만, 그 경우에는 접속하는 쪽이 번호를 지정해야 합니다.

해설 속 포트 번호(Port Number)

  • 포트 번호는 0~65535의 16비트 번호로, IP 주소로 도착한 단말 안에서 어느 애플리케이션으로 가는 통신인지를 구별합니다.

  • TCP와 UDP는 전송 계층의 프로토콜로, 포트 번호를 사용하여 단말 안의 어느 애플리케이션으로 가는 통신인지를 구별합니다.

    TCP/IP의 4계층 모델에서 TCP와 UDP가 속하는 계층은?

  • NAPT는 IP 주소에 더해 포트 번호도 바꿔 쓰고, '내부의 주소와 포트'와 '외부의 포트'의 대응을 변환 테이블에 기록합니다.

    가정용 브로드밴드 라우터는 NAT(네트워크 주소 변환)의 일종인 NAPT(IP 마스커레이드)를 수행한다. …

  • UDP는 IP 위에 포트 번호와 간단한 오류 검출(체크섬)만 더한 가벼운 프로토콜로, 헤더는 8바이트입니다(TCP는 옵션 없이 20바이트).
