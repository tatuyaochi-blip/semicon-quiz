포트 번호(Port Number)란?

TCP나 UDP에서 단말 안의 어느 애플리케이션으로 가는 통신인지를 구별하는 0~65535의 번호. HTTP의 80, HTTPS의 443, DNS의 53 등 0~1023은 잘 알려진 포트(well-known port)라고 한다.

일본어 명칭: ポート番号

포트 번호(Port Number)은(는) 네트워크 기초, 네트워크 설계와 운용, 웹 기술 기초 등 4개 분야의 연습 문제 9개에 나와요.

  1. AHTTP 80, HTTPS 443, DNS 53
  2. BHTTP 8080, HTTPS 443, DNS 25
  3. CHTTP 80, HTTPS 22, DNS 53
정답과 해설 보기

정답: A. HTTP 80, HTTPS 443, DNS 53

포트 번호는 0~65535의 16비트 번호로, IP 주소로 도착한 단말 안에서 어느 애플리케이션으로 가는 통신인지를 구별합니다. 0~1023은 잘 알려진 포트(well-known port)라고 하며 주요 서비스에 할당되어 있습니다. 대표적인 것은 HTTP 80, HTTPS 443, DNS 53, SSH 22, SMTP(메일 전송) 25입니다. 클라이언트 쪽은 OS가 그때그때 고른 번호(임시 포트, ephemeral port)를 출발지 포트로 사용합니다. 표준과 다른 번호로 서비스를 운영할 수도 있으며, 8080은 웹 개발용이나 프록시 서버 등에 자주 쓰이지만, 그 경우에는 접속하는 쪽이 번호를 지정해야 합니다.

스위치 2대 사이의 1 Gbps 링크 4개를 링크 어그리게이션으로 하나의 논리적인 링크로 묶었다. 프레임은 출발지와 목적지의 주소나 포트 번호의 조합(플로)마다 어느 링크로 보낼지 정하는 일반적인 방식으로 분배한다. TCP 연결 하나로 얻을 수 있는 처리량의 상한에 가장 가까운 것은?

  1. A1 Gbps
  2. B2 Gbps
  3. C4 Gbps
정답과 해설 보기

정답: A. 1 Gbps

링크 어그리게이션에서는 같은 플로의 프레임을 같은 링크 하나로 보내는 것이 일반적입니다. 하나의 플로의 프레임을 여러 링크로 나누면 도착 순서가 뒤바뀌어 TCP의 성능이 떨어질 우려가 있기 때문입니다. 그래서 TCP 연결 하나는 링크 1개분인 1 Gbps까지만 나옵니다. 플로가 많으면 4개로 분산되어 합계로는 최대 4 Gbps를 쓸 수 있습니다. 어느 하나가 끊어져도 나머지 링크로 통신을 계속할 수 있고, STP에서는 하나의 링크로 취급되므로 묶은 링크가 차단되는 일도 없습니다.
