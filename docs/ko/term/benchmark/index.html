벤치마크(Benchmark)란?

컴퓨터나 프로그램의 성능을 비교하기 위해 정해진 조건에서 실행하는 대표적인 프로그램. 실제 용도에 가까운 것을 고르는 것이 중요하다.

일본어 명칭: ベンチマーク

벤치마크(Benchmark)은(는) 성능 분석 등 1개 분야의 연습 문제 7개에 나와요.

분야: 성능 분석

도전해 보기: 벤치마크(Benchmark) 관련 문제

컴퓨터 성능을 벤치마크로 평가할 때의 사고방식으로 가장 적절한 것은?

  1. A실제로 사용하는 용도에 가까운 프로그램으로 측정하고 그 결과로 비교한다
  2. B어떤 용도에서도 하나의 작은 루프의 속도만으로 결정한다
  3. C제조사가 공표한 클럭 주파수만으로 결정한다
정답과 해설 보기

정답: A. 실제로 사용하는 용도에 가까운 프로그램으로 측정하고 그 결과로 비교한다

어떤 컴퓨터가 빠른지는 무엇에 사용하느냐에 따라 달라집니다. 정수 처리, 부동소수점 계산, 메모리를 대량으로 사용하는 처리, 입출력이 많은 처리 등 잘하는 일이 각각 다릅니다. 따라서 실제 용도에 최대한 가까운 프로그램이나, 많은 대표적 프로그램을 모은 표준 벤치마크로 측정하고 조건을 맞춰 비교하는 것이 중요합니다.

SPEC CPU와 같은 표준 벤치마크에 대한 설명으로 올바른 것은?

  1. A실제 애플리케이션을 기반으로 한 다수의 프로그램을 정해진 규칙으로 실행하고, 기준 컴퓨터와의 비를 종합한 값으로 성능을 나타낸다
  2. B하나의 덧셈을 몇 번 할 수 있는지만 측정한다
  3. C벤치마크 결과는 제조사가 자유롭게 정해도 된다
정답과 해설 보기

정답: A. 실제 애플리케이션을 기반으로 한 다수의 프로그램을 정해진 규칙으로 실행하고, 기준 컴퓨터와의 비를 종합한 값으로 성능을 나타낸다

SPEC CPU는 컴파일러, 압축, 물리 시뮬레이션 등 실제 애플리케이션을 기반으로 한 다수의 프로그램으로 이루어진 벤치마크입니다. 각 프로그램의 실행 시간을 기준 컴퓨터의 시간과 비교한 비를 구하고, 그것들을 기하 평균으로 종합하여 하나의 값으로 만듭니다. 컴파일러 설정이나 실행 방법에도 규칙이 있으며, 결과는 상세한 조건과 함께 공개됩니다.

벤치마크(Benchmark)이(가) 나오는 문제 (7)

  1. 컴퓨터 성능을 벤치마크로 평가할 때의 사고방식으로 가장 적절한 것은?
  2. SPEC CPU와 같은 표준 벤치마크에 대한 설명으로 올바른 것은?
  3. 여러 벤치마크의 기준 컴퓨터 대비 속도 비를 종합할 때 기하 평균이 자주 사용되는 이유로 올바른 것은?
  4. 소프트웨어 개발에서 변경할 때마다 벤치마크를 자동으로 실행하여 결과를 기록해 두는 목적으로 올바른 것은?
  5. 노트북에서 벤치마크를 측정했더니 같은 프로그램인데도 결과가 매번 크게 흔들렸다. CPU 측의 원인으로 생각할 수 있는 것과 그 대책의 조합으로 올바른 것은?
  6. 위와 같은 작은 루프로 계산 속도를 측정했더니 N을 크게 해도 시간이 거의 0이었다. 가장 가능성이 높은 원인은?
  7. STREAM 벤치마크로 주로 측정하는 것은?
