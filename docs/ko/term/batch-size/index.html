배치 크기(Batch Size)란?

한꺼번에 처리하는 입력의 수. 크게 하면 가중치를 재사용할 수 있어 효율이 오르지만 응답 지연과 메모리가 늘어난다.

일본어 명칭: バッチサイズ

배치 크기(Batch Size)은(는) AI 하드웨어·소프트웨어 스택 등 1개 분야의 연습 문제 7개에 나와요.

분야: AI 하드웨어·소프트웨어 스택

도전해 보기: 배치 크기(Batch Size) 관련 문제

입력이 하나뿐일 때(배치 크기 1), 완전 연결층의 계산(가중치 행렬과 벡터의 곱)이 메모리 율속이 되기 쉬운 이유로 올바른 것은 무엇인가?

  1. A벡터의 요소 수가 너무 많아 연산기에 다 들어가지 않기 때문
  2. B행렬과 벡터의 곱은 GPU에서는 계산할 수 없기 때문
  3. C가중치의 각 요소를 메모리에서 읽어도 한 번의 곱셈-덧셈에만 사용하므로 연산 강도가 매우 낮기 때문
정답과 해설 보기

정답: C. 가중치의 각 요소를 메모리에서 읽어도 한 번의 곱셈-덧셈에만 사용하므로 연산 강도가 매우 낮기 때문

행렬과 벡터의 곱에서는 가중치 행렬의 각 요소를 한 번 읽어 입력의 한 요소와 한 번 곱해 더할 뿐입니다. FP16이면 2바이트당 2번의 연산이므로 연산 강도는 약 1입니다. 가중치를 읽는 데 시간이 걸리고 연산기는 대부분 기다립니다. 같은 가중치를 여러 입력에 사용할 수 있도록 입력을 모으면(배치를 키우면) 연산 강도가 올라갑니다.

추론에서 배치 크기(한꺼번에 처리하는 입력의 수)를 키우면 전체 처리 효율이 올라가기 쉬운 이유는 무엇인가?

  1. A입력이 많을수록 입력 하나의 계산 횟수가 줄어들기 때문
  2. B배치를 키우면 가중치의 수가 줄어들기 때문
  3. C한 번 읽은 가중치를 여러 입력의 계산에 사용할 수 있어 연산 강도가 올라가고 연산기를 효과적으로 쓸 수 있기 때문
정답과 해설 보기

정답: C. 한 번 읽은 가중치를 여러 입력의 계산에 사용할 수 있어 연산 강도가 올라가고 연산기를 효과적으로 쓸 수 있기 때문

배치 크기가 B이면 가중치 행렬과 B개 벡터의 곱은 가중치 행렬과 폭 B인 행렬의 곱이 됩니다. 가중치 읽기는 같은데 연산은 B배가 되므로 연산 강도도 대략 B배가 되어, 메모리 율속에서 연산 율속에 가까워집니다. 서버에서의 추론은 많은 이용자의 요청을 모아 처리함으로써 GPU를 효율적으로 사용합니다.

해설 속 배치 크기(Batch Size)

  • 배치 크기가 B이면 가중치 행렬과 B개 벡터의 곱은 가중치 행렬과 폭 B인 행렬의 곱이 됩니다.

    추론에서 배치 크기(한꺼번에 처리하는 입력의 수)를 키우면 전체 처리 효율이 올라가기 쉬운 이유는 무엇인가?

  • 계산은 크게 줄지만, 저장하는 Key와 Value의 양은 문장 길이와 배치 크기에 비례하여 늘어납니다.

    대규모 언어 모델의 추론에서 사용되는 KV 캐시의 역할로 올바른 것은 무엇인가?

  • KV 캐시의 크기는 층 수 × Key와 Value의 차원 × 토큰 수 × 배치 크기 × 요소 하나당 바이트 수로 결정됩니다.

    대규모 언어 모델의 추론에서 긴 문장이나 큰 배치를 다룰 때 문제가 되기 쉬운 것은 무엇인가?

  • 역전파에서는 각 층의 순전파 중간 결과가 필요하지만, 전부 저장하면 층 수와 배치 크기에 비례하여 메모리가 늘어납니다.

    학습에서 사용되는 기울기 체크포인팅(활성화 재계산)의 설명으로 올바른 것은 무엇인가?

배치 크기(Batch Size)이(가) 나오는 문제 (7)

  1. 입력이 하나뿐일 때(배치 크기 1), 완전 연결층의 계산(가중치 행렬과 벡터의 곱)이 메모리 율속이 되기 쉬운 이유로 올바른 것은 무엇인가?
  2. 추론에서 배치 크기(한꺼번에 처리하는 입력의 수)를 키우면 전체 처리 효율이 올라가기 쉬운 이유는 무엇인가?
  3. 추론에서 배치 크기를 지나치게 키웠을 때의 단점으로 올바른 것은 무엇인가?
  4. FP16으로 약 14 GB의 가중치를 가진 모델을 메모리 대역폭 2 TB/s의 GPU에서 배치 크기 1로 디코드한다. 토큰 하나를 생성하는 데 걸리는 시간의 하한에 가장 가까운 것은 무엇인가?
  5. 대규모 언어 모델의 추론에서 사용되는 KV 캐시의 역할로 올바른 것은 무엇인가?
  6. 대규모 언어 모델의 추론에서 긴 문장이나 큰 배치를 다룰 때 문제가 되기 쉬운 것은 무엇인가?
  7. 학습에서 사용되는 기울기 체크포인팅(활성화 재계산)의 설명으로 올바른 것은 무엇인가?
