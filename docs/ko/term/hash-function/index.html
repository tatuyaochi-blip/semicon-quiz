해시 함수(Hash Function)란?

임의 길이의 데이터로부터 정해진 길이의 값(해시값)을 계산하는 함수. 암호에서 사용하는 것(SHA-256 등)은 해시값으로부터 원래 데이터를 구하는 것도, 같은 해시값이 되는 두 데이터를 찾는 것도 현실적으로 불가능하도록 만들어지며, 변조 검출, 디지털 서명, 비밀번호 저장에 사용된다.

일본어 명칭: ハッシュ関数

해시 함수(Hash Function)은(는) 정보 보안 기초, 암호 기술의 기초와 응용, 자료 구조와 알고리즘 등 5개 분야의 연습 문제 13개에 나와요.

암호학적 해시 함수에 요구되는 성질

암호에서 사용하는 해시 함수에는 세 가지 성질이 요구됩니다. 역상 저항성(일방향성)은 해시값으로부터 그 해시값이 되는 입력을 찾기가 어렵다는 것입니다. 제2 역상 저항성은 어떤 입력이 주어졌을 때 같은 해시값이 되는 다른 입력을 찾기가 어렵다는 것입니다. 충돌 저항성은 같은 해시값이 되는 서로 다른 두 입력을 아무것이나 찾기가 어렵다는 것입니다. 또한 입력이 1비트만 달라도 출력의 약 절반의 비트가 바뀌는 성질(눈사태 효과)도 가집니다.

출력 길이와 안전성

출력이 n비트인 이상적인 해시 함수에서는 역상을 무차별 대입로 찾으려면 대략 2^n회의 계산이 필요하지만, 충돌은 생일 역설에 의해 약 2^(n/2)회로 찾을 가능성이 높아집니다. 이 때문에 SHA-256의 충돌에 대한 강도는 약 128비트 상당으로 여겨집니다. MD5나 SHA-1은 무차별 대입보다 훨씬 적은 계산으로 충돌을 만드는 방법이 발견되었으므로, 디지털 서명 등 안전이 필요한 용도에는 사용하지 않게 되어 있습니다.

주요 용도

해시값은 데이터의 '지문'으로 사용할 수 있습니다. 내려받은 파일의 해시값을 공식적으로 제시된 값과 비교하면 손상되거나 바꿔치기되지 않았는지 알 수 있습니다(다만 공식 값 자체를 신뢰할 수 있는 경로로 얻었다는 것이 전제입니다). 디지털 서명에서는 긴 문서 대신 그 해시값에 서명합니다. 비밀번호 저장에서는 솔트를 더하고, bcrypt나 Argon2처럼 일부러 계산을 무겁게 한 방식을 사용합니다. 키와 조합한 HMAC은 메시지 인증 코드로서 변조 검출에 사용됩니다.

  1. A위치 3
  2. B위치 4
  3. C위치 6
정답과 해설 보기

정답: C. 위치 6

네 키는 모두 7로 나눈 나머지가 3이므로, 전부 위치 3을 처음에 조사합니다. 10은 위치 3에 들어가고, 17은 위치 3이 차 있으므로 위치 4, 24는 위치 3, 4가 차 있으므로 위치 5에 들어갑니다. 3은 위치 3, 4, 5가 차 있으므로 위치 6에 저장됩니다. 이처럼 선형 탐사법에서는 채워진 위치가 뭉쳐서 늘어서고(클러스터), 나중에 오는 키일수록 조사하는 횟수가 늘어납니다.

해시 함수는 임의 길이의 데이터로부터 정해진 길이의 값(해시값, 다이제스트)을 계산하는 함수입니다. 예를 들어 SHA-256은 입력 길이와 관계없이 256비트 값을 출력합니다. 같은 입력에서는 반드시 같은 값이 얻어지고, 입력이 조금이라도 다르면 출력은 예측할 수 없을 만큼 크게 바뀝니다. 암호에서 사용하는 해시 함수에는 나아가 해시값으로부터 원래 입력을 구하는 것이 현실적으로 불가능할 것(일방향성, 역상 저항성)과, 같은 해시값이 되는 서로 다른 두 입력을 찾기 어려울 것(충돌 저항성)이 요구됩니다. 해시 함수는 키를 사용하지 않는 계산이며 암호화가 아니므로, 복호화하여 원래대로 되돌릴 수도 없습니다. 변조 검출, 디지털 서명, 비밀번호 저장 등에 사용됩니다.

자주 묻는 질문

해시 함수와 암호화의 차이는 무엇인가요?

암호화는 키를 사용하여 원래대로 되돌릴 수 있는(복호화할 수 있는) 변환이지만, 해시 함수는 키를 사용하지 않고 원래대로 되돌릴 수 없는 일방향 계산입니다. 그래서 해시값은 비밀을 지키기 위해서가 아니라 데이터가 같은지 확인하기 위해 사용합니다.

SHA-256의 해시값은 몇 비트인가요?

입력 길이와 관계없이 256비트(16진수로 64자)입니다. 1글자의 데이터든 큰 파일이든 같은 길이의 값이 됩니다.
