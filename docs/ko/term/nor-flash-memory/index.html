NOR형 플래시 메모리란?

셀을 병렬로 연결한 플래시 메모리. 랜덤 읽기가 빨라 마이컴의 프로그램 저장 등에 사용된다.

일본어 명칭: NOR型フラッシュメモリ

NOR형 플래시 메모리은(는) SRAM과 플래시 메모리 등 1개 분야의 연습 문제 1개에 나와요.

NOR형 플래시 메모리의 대표적인 용도는 무엇입니까?

  1. A대용량 동영상이나 사진의 저장
  2. BPC의 주기억장치
  3. C기기의 프로그램 코드 저장(부팅용 프로그램 등)
정답과 해설 보기

정답: C. 기기의 프로그램 코드 저장(부팅용 프로그램 등)

NOR형은 각 셀이 비트 라인에 병렬로 연결되어 랜덤 액세스가 빠르므로, CPU가 메모리에서 직접 프로그램을 읽어 실행할 수 있습니다(XIP: Execute In Place). 그래서 기기의 부팅용 프로그램, 마이크로컨트롤러의 펌웨어, 차량용 기기의 제어 코드에 사용됩니다. 용량은 수 Mbit~수 Gbit로 작고 비트 단가는 NAND보다 높으므로, 대용량 데이터 저장에는 NAND형이 사용됩니다.

이 용어가 포함된 비교

  • NAND 플래시와 NOR 플래시의 차이와 용도NAND와 NOR 플래시 메모리를 표로 비교합니다. 셀 연결 방식, 읽기·쓰기 속도, 소거 단위, 집적도, 비용, 신뢰성, 대표 용도를 다룹니다.

관련 용어

마이컴(마이크로컨트롤러) 3D NAND 6T SRAM 셀 가비지 컬렉션(garbage collection) 리드 디스터브(Read Disturb) 비휘발성 메모리 쓰기 증폭(Write Amplification) 웨어 레벨링(Wear Leveling) 전하 트랩형 셀(Charge Trap Cell) 플로팅 게이트(Floating Gate)
