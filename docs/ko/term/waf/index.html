WAF(웹 애플리케이션 방화벽)란?

Web Application Firewall의 약자. 웹 애플리케이션 앞에 두고 HTTP 요청의 URL, 파라미터, 헤더 등의 내용을 조사하여, SQL 인젝션이나 크로스 사이트 스크립팅 등에 전형적인 패턴을 포함한 요청이나 정한 규칙에 맞지 않는 요청을 차단하는 구조. IP 주소나 포트 번호로 제어하는 일반적인 방화벽으로는 막을 수 없는, 애플리케이션에 대한 공격을 대상으로 한다. 취약점 수정까지의 일시적인 방어(가상 패치)에도 사용되지만, 수정을 대신할 수는 없다.

일본어 명칭: WAF(Webアプリケーションファイアウォール)

WAF(웹 애플리케이션 방화벽)은(는) 사이버 공격과 방어의 실무, 네트워크 기초 등 2개 분야의 연습 문제 2개에 나와요.

WAF(웹 애플리케이션 방화벽)에 대한 설명으로 올바른 것은?

  1. AIP 주소와 포트 번호만 보고 통신을 통과시킬지 차단할지를 정하는 장비로, HTTP의 내용은 조사하지 않는다
  2. BWAF를 두면 웹 애플리케이션의 취약점을 수정하지 않아도 SQL 인젝션 등 모든 공격을 완전히 막을 수 있다
  3. C웹 애플리케이션 앞에 두고 HTTP 요청의 내용을 조사하여, 전형적인 공격 문자열을 포함한 요청을 차단한다
정답과 해설 보기

정답: C. 웹 애플리케이션 앞에 두고 HTTP 요청의 내용을 조사하여, 전형적인 공격 문자열을 포함한 요청을 차단한다

일반적인 방화벽은 IP 주소나 포트 번호 등으로 통신을 제어하므로, 허가한 HTTPS 포트를 지나는 웹 애플리케이션에 대한 공격은 막지 못합니다. WAF는 HTTP 요청의 URL, 파라미터, 헤더 등의 내용을 조사하여, SQL 인젝션이나 크로스 사이트 스크립팅에 전형적인 패턴이나, 애플리케이션에 맞춰 정한 규칙에 맞지 않는 요청을 차단합니다. 취약점이 발견된 후 수정이 끝날 때까지의 일시적인 방어(가상 패치)로도 사용됩니다. 다만 규칙을 빠져나가는 공격도 있으므로 취약점 자체의 수정을 대신할 수는 없습니다.

해설 속 WAF(웹 애플리케이션 방화벽)

  • WAF는 HTTP 요청의 URL, 파라미터, 헤더 등의 내용을 조사하여, SQL 인젝션이나 크로스 사이트 스크립팅에 전형적인 패턴이나, 애플리케이션에 맞춰 정한 규칙에 맞지 않는 요청을 차단합니다.

    WAF(웹 애플리케이션 방화벽)에 대한 설명으로 올바른 것은?

  • 또한 허용한 포트를 통과하는 공격(웹 애플리케이션의 취약점을 노리는 것 등)은 막을 수 없으므로 WAF 등 별도의 대책도 사용합니다.
