고정 패턴 노이즈(Fixed-pattern noise)란?

화소나 판독 회로 사이의 편차 때문에 매번 같은 위치에 나타나는 노이즈입니다. 상관 이중 샘플링이나 보정으로 제거합니다.

정답: C. 고정 패턴 노이즈

고정 패턴 노이즈는 화소별 앰프의 오프셋이나 암전류의 편차, 열별 읽기 회로나 ADC의 편차 등으로 촬영할 때마다 같은 위치에 같은 모양으로 나타나는 노이즈입니다. 특히 열별 어긋남은 세로줄 무늬로 두드러집니다. 시간적으로 변하지 않으므로 CDS나 차광한 화소의 값을 이용한 보정, 공장에서의 교정 데이터로 제거할 수 있습니다. 시간에 따라 변하는 샷 노이즈나 열 잡음과는 구별됩니다.
