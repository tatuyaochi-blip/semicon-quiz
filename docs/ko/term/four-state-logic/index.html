4값 논리(four-valued logic)란?

HDL 시뮬레이션에서 쓰는 0, 1, X(불정), Z(하이 임피던스)의 네 가지 값. 초기화되지 않은 신호나 충돌한 신호는 X가 된다.

도전해 보기: 4값 논리(four-valued logic) 관련 문제

Verilog 시뮬레이션에서 사용되는 4값 논리의 값의 조합으로 올바른 것은?

  1. A0, 1, X(불정), Z(하이 임피던스)
  2. B0, 1, 2, 3
  3. C참, 거짓, 위, 아래
정답과 해설 보기

정답: A. 0, 1, X(불정), Z(하이 임피던스)

Verilog의 신호는 0과 1 외에, 값을 알 수 없음을 나타내는 X(불정)와 어디에서도 구동되지 않는 상태를 나타내는 Z(하이 임피던스)를 가질 수 있습니다. 초기화되지 않은 레지스터나 두 출력이 충돌한 신호는 X가 되고, 아무것도 연결되지 않은 선이나 출력을 분리한 트라이스테이트 선은 Z가 됩니다. 시뮬레이션에서 X나 Z를 발견하는 것은 오류를 찾는 큰 단서가 됩니다.
