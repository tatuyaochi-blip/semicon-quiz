JTAG란?

칩의 테스트와 디버그를 위한 표준 인터페이스. 프로그램을 멈추고 내부 값을 보거나 플래시를 다시 쓸 수 있다. Arm에서는 선이 더 적은 SWD도 사용된다.

일본어 명칭: JTAG

JTAG은(는) 테스트와 검사, 임베디드 시스템과 펌웨어, 하드웨어 보안 등 3개 분야의 연습 문제 3개에 나와요.

분야: 임베디드 시스템과 펌웨어

바운더리 스캔: 원래의 목적

JTAG라는 이름은 Joint Test Action Group에서 유래했으며, 규격은 IEEE 1149.1입니다. 원래 목적은 조립된 보드를 테스트하는 것이었습니다. 각 I/O 핀 바로 안쪽에 바운더리 스캔 셀이 있고, 이 셀들은 시프트 레지스터로 연결됩니다. 테스트 장비는 TAP(Test Access Port)를 통해 패턴을 시프트 입력하여 한 칩의 핀에서 출력하고 다른 칩의 핀에서 캡처함으로써, 프로브가 닿을 수 없는 BGA 패키지 아래에서도 납땜 개방(오픈)과 단락(쇼트)을 찾아냅니다.

TAP 신호와 상태 머신

TAP는 TDI(테스트 데이터 입력), TDO(테스트 데이터 출력), TCK(테스트 클록), TMS(테스트 모드 선택)의 네 가지 신호와 선택 사항인 TRST 리셋을 사용합니다. TCK 에지에서 샘플링되는 TMS가 16개 상태의 컨트롤러를 제어하며, 이 컨트롤러는 TDI와 TDO 사이에서 시프트되는 비트가 명령 레지스터로 갈지, 선택된 데이터 레지스터로 갈지를 결정합니다. 각 TDO를 다음 칩의 TDI에 연결하여 여러 칩을 데이지 체인으로 연결할 수 있으므로, 커넥터 하나로 보드의 모든 디바이스에 접근할 수 있습니다.

디버깅과 플래시 프로그래밍, JTAG와 SWD

칩 벤더는 같은 포트를 온칩 디버그 로직에 접근하는 데에도 재사용합니다. PC의 디버거는 코어를 정지시키고, 브레이크포인트를 설정하고, 단일 스텝 실행을 하고, 레지스터와 메모리를 읽고 쓰고, 플래시를 프로그래밍할 수 있어 printf를 쓸 수 없는 상황에서도 내부 상태를 볼 수 있습니다. Arm의 SWD(Serial Wire Debug)는 SWDIO와 SWCLK 두 신호만으로 비슷한 디버그 접근을 제공하여 소형 마이크로컨트롤러의 핀을 절약하지만, 디버그 프로토콜일 뿐 바운더리 스캔은 수행하지 않습니다. 많은 Arm 디바이스가 공유 핀으로 두 방식을 모두 지원합니다.

제품에서 포트 잠그기

개발자에게 도움이 되는 접근 기능은 공격자에게도 도움이 됩니다. 디버그 포트가 열려 있으면 프로브만 있으면 누구나 펌웨어를 읽어 내거나, 키를 추출하거나, 시큐어 부트를 우회할 수 있습니다. 그래서 출하 제품에서는 eFuse를 끊어 포트를 영구적으로 비활성화하거나, 읽기 보호를 적용하거나, 암호학적 챌린지-응답 인증을 거친 후에만 포트를 열어, 권한 있는 엔지니어가 현장에서 반품된 불량품을 분석할 수 있도록 합니다.

정답과 해설 보기

정답: C. 인쇄 회로 기판에 실장한 LSI의 단자끼리의 접속 등을, 프로브를 대지 않고 테스트한다

바운더리 스캔에서는 LSI의 각 단자 안쪽에 스캔용 셀을 두고 이들을 직렬로 연결하여, TDI, TDO, TCK, TMS의 4개(및 리셋) 신호로 외부에서 값을 설정하고 관측합니다. 단자에 프로브를 댈 수 없는 BGA 등에서도 기판 상의 납땜 접속의 단선이나 단락을 검사할 수 있습니다. 이 단자는 디버그나 플래시 메모리 기록에도 널리 사용됩니다.

JTAG나 SWD 같은 디버그용 인터페이스로 할 수 있는 것으로 올바른 것은 무엇입니까?

  1. A실제 기판 위에서 프로그램을 멈추거나 한 줄씩 진행하며 레지스터나 변수 값을 보고 플래시를 다시 쓴다
  2. B마이크로컨트롤러의 제조 공정을 변경한다
  3. C프로그램을 다른 언어로 자동 번역한다
정답과 해설 보기

정답: A. 실제 기판 위에서 프로그램을 멈추거나 한 줄씩 진행하며 레지스터나 변수 값을 보고 플래시를 다시 쓴다

JTAG나 Arm의 SWD는 마이크로컨트롤러 내부의 디버그 회로와 PC의 디버거를 잇는 인터페이스입니다. 브레이크포인트에서 멈춰 변수나 레지스터를 조사하거나, 한 명령씩 실행하거나, 플래시에 프로그램을 쓸 수 있습니다. printf를 쓸 수 없는 상황에서도 내부 상태를 알 수 있습니다. 제품으로 출하할 때는 제3자가 읽어내지 못하도록 디버그 기능을 비활성화하기도 합니다.

자주 묻는 질문

JTAG 핀 구성은 어떻게 되나요?

TDI, TDO, TCK, TMS와 선택 사항인 TRST 리셋이며, 디버그 커넥터에는 이와 함께 그라운드와 보통 기준 전압이 포함됩니다.

JTAG와 SWD의 차이는 무엇인가요?

SWD는 Arm의 2선식 디버그 인터페이스로, 더 적은 핀으로 비슷한 정지, 스텝 실행, 메모리 접근 기능을 제공합니다. JTAG는 4개 또는 5개의 신호를 사용하며, 바운더리 스캔 보드 테스트와 여러 칩의 데이지 체인 연결도 지원합니다.

양산 제품에서 JTAG를 비활성화하는 이유는?

JTAG로 메모리를 읽고 쓰고 프로세서를 정지시킬 수 있으므로, 포트가 열려 있으면 공격자가 펌웨어와 키를 추출하거나 시큐어 부트를 우회할 수 있습니다. 제품에서는 퓨즈로 비활성화하거나 잠금 해제에 인증을 요구합니다.

  • JTAG나 SWD 같은 디버그 포트는 개발 중에 칩 내부를 자유롭게 조사할 수 있는 강력한 도구입니다.
