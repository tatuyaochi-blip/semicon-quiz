원격 증명(Remote Attestation)란?

기기가 자신 안에서 동작하는 소프트웨어의 상태를 칩 안의 키로 서명하여 원격 서버에 제시하고, 신뢰할 수 있는지 확인받는 메커니즘.

일본어 명칭: リモートアテステーション

원격 증명에서는 기기가 TPM이나 TEE에 기록된 소프트웨어 측정 값을, 칩 안에서 꺼낼 수 없는 키로 서명하여 서버에 보냅니다. 서버는 서명과 측정 값을 확인하고, 정해진 소프트웨어로 동작하는 기기에만 비밀 데이터나 서비스를 제공합니다. 클라우드에 기밀 계산을 맡길 때나 기업 네트워크에 연결하는 기기를 확인할 때 등에 사용됩니다.
