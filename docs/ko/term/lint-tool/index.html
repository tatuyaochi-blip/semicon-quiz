정답과 해설 보기

정답: C. 시뮬레이션 없이 기술을 검사하여 비트 폭 불일치, 의도하지 않은 래치, 합성할 수 없는 작성 방식 등의 문제를 찾아낸다

Lint 도구는 HDL 기술을 규칙에 비추어 정적으로 검사하고, 문법상 올바르더라도 문제가 되기 쉬운 작성 방식을 지적합니다. 예를 들어 폭이 다른 신호의 대입, 감지 목록의 누락, 래치 추론, 블로킹과 논블로킹의 혼재, 클록 취급의 오류 등입니다. 테스트를 만들지 않아도 실행할 수 있으므로 설계 초기 단계부터 사용하면 이후 검증의 수고를 줄일 수 있습니다.
