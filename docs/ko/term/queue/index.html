큐(Queue)란?

가장 먼저 넣은 원소를 가장 먼저 꺼내는 선입선출(FIFO) 자료 구조. 뒤에 넣는 조작을 인큐, 앞에서 꺼내는 조작을 디큐라고 한다. 처리 대기열, 태스크 간의 데이터 주고받기, 너비 우선 탐색 등에 쓰인다.

일본어 명칭: キュー

분야: 자료 구조와 알고리즘

이 용어가 포함된 비교

  • 너비 우선 탐색과 깊이 우선 탐색의 차이: 방문 순서·자료 구조·최단 경로·메모리·용도 비교너비 우선 탐색(BFS)과 깊이 우선 탐색(DFS)을 방문 순서, 사용하는 자료 구조, 최단 경로, 계산량, 사용하는 메모리, 해를 찾는지 여부, 트리 순회 순서, 주요 용도의 관점에서 표로 비교…
