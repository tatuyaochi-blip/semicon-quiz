듀얼 시스템(Dual System)란?

2세트의 시스템으로 같은 처리를 동시에 수행하고, 결과를 대조하면서 운전하는 이중화 방식. 결과의 불일치로 오류를 알아차릴 수 있고, 한쪽이 고장 나도 다른 쪽으로 처리를 그대로 계속할 수 있다. 신뢰성은 높지만 2세트의 설비로 같은 처리를 수행하므로 비용은 크다.

  1. A주 시스템(운용계)과 대기 시스템을 준비하고, 평소에는 주 시스템만으로 처리하며, 주 시스템이 고장 나면 대기 시스템으로 전환하여 처리를 계속한다
  2. B여러 시스템이 처리를 나누어 맡아 전체의 처리 능력을 높인다
  3. C2세트의 시스템으로 같은 처리를 동시에 수행하여 결과를 대조하고, 한쪽이 고장 나도 다른 쪽으로 처리를 계속한다

듀얼 시스템은 2세트의 시스템으로 같은 처리를 동시에 수행하고, 결과를 대조하면서 운전하는 방식입니다. 결과가 어긋나면 오류를 알아차릴 수 있고, 한쪽이 고장 나도 다른 쪽으로 처리를 그대로 계속할 수 있으므로 높은 신뢰성이 요구되는 처리에 사용됩니다. 그 대신 2세트의 설비로 같은 처리를 수행하므로 비용이 커집니다. 주 시스템과 대기 시스템으로 나누어 고장 시에 전환하는 방식은 듀플렉스 시스템입니다.
