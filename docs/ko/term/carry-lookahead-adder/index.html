캐리 룩어헤드 가산기(carry-lookahead adder)란?

각 비트의 생성 신호 g = a·b와 전파 신호 p = a ⊕ b로부터 캐리를 병렬로 계산하여, 캐리가 차례로 전달되기를 기다리지 않는 가산기입니다. 피연산자가 넓어도 지연이 작게 유지됩니다.

일본어 명칭: 桁上げ先見加算器

캐리 룩어헤드 가산기(carry-lookahead adder)은(는) 컴퓨터 산술 등 1개 분야의 연습 문제 2개에 나와요.

분야: 컴퓨터 산술

도전해 보기: 캐리 룩어헤드 가산기(carry-lookahead adder) 관련 문제

캐리 룩어헤드 가산기에서 사용하는 각 자리의 생성 신호 g와 전파 신호 p의 정의(a, b는 그 자리의 입력)와, 윗자리로의 올림 c(i+1)의 식의 조합으로 올바른 것은 무엇입니까?

  1. Ag = a + b, p = a・b, c(i+1) = p + g・c(i)
  2. Bg = a・b, p = a ⊕ b, c(i+1) = g + p・c(i)
  3. Cg = a ⊕ b, p = a・b, c(i+1) = g・p・c(i)
정답과 해설 보기

정답: B. g = a・b, p = a ⊕ b, c(i+1) = g + p・c(i)

그 자리에서 a와 b가 모두 1이면 아래에서의 올림과 관계없이 반드시 올림이 발생하므로 생성 신호는 g = a・b입니다. a와 b 중 한쪽만 1이면 아래에서의 올림을 그대로 위로 전달하므로 전파 신호는 p = a ⊕ b(OR로 하기도 함)입니다. 따라서 c(i+1) = g(i) + p(i)・c(i)가 되며, 이를 전개하면 각 자리의 올림을 입력의 g・p와 최하위 올림만으로 2단의 논리로 병렬 계산할 수 있습니다. 생성과 전파를 바꾼 식으로는 올바르게 계산할 수 없습니다.

해설 속 캐리 룩어헤드 가산기(carry-lookahead adder)

  • 이를 겹쳐 부분곱을 2개까지 줄이고, 마지막에 한 번만 캐리 룩어헤드 가산기 등으로 더합니다.

    승산기에서 다수의 부분곱을 더하는 데 캐리 세이브 가산기가 사용되는 주된 이유는 무엇입니까?

캐리 룩어헤드 가산기(carry-lookahead adder)이(가) 나오는 문제 (2)

  1. 캐리 룩어헤드 가산기에서 사용하는 각 자리의 생성 신호 g와 전파 신호 p의 정의(a, b는 그 자리의 입력)와, 윗자리로의 올림 c(i+1)의 식의 조합으로 올바른 것은 무엇입니까?
  2. 승산기에서 다수의 부분곱을 더하는 데 캐리 세이브 가산기가 사용되는 주된 이유는 무엇입니까?
