아이소크로너스 전송(isochronous transfer)란?

일정 대역을 예약해 정해진 간격으로 보내며 오류가 있어도 재전송하지 않는 USB 전송 종류. 음성과 영상에 쓴다.

일본어 명칭: アイソクロナス転送

아이소크로너스 전송(isochronous transfer)은(는) I/O 인터페이스와 버스 등 1개 분야의 연습 문제 1개에 나와요.

USB 전송 유형 중 아이소크로너스 전송의 특징으로 올바른 것은?

  1. A오류가 있으면 몇 번이든 재전송하여 데이터를 반드시 올바르게 전달한다. 파일 전송에 사용한다
  2. B일정한 대역폭을 예약하여 정해진 간격으로 보내지만, 오류가 있어도 재전송하지 않는다. 음성이나 영상에 사용한다
  3. C기기 설정 시에만 사용한다
정답과 해설 보기

정답: B. 일정한 대역폭을 예약하여 정해진 간격으로 보내지만, 오류가 있어도 재전송하지 않는다. 음성이나 영상에 사용한다

USB에는 설정용 컨트롤 전송, 마우스 등의 인터럽트 전송, 대량의 데이터를 확실하게 보내는 벌크 전송, 시간에 맞춰 전달하는 아이소크로너스 전송이 있습니다. 음성이나 영상에서는 늦게 도착한 데이터는 쓸모가 없으므로 대역폭을 예약하여 일정한 간격으로 보내며, 오류가 있어도 재전송하지 않습니다. 약간의 데이터 손실보다 끊김 없이 재생되는 것을 우선하는 것입니다.

해설 속 아이소크로너스 전송(isochronous transfer)

  • USB에는 설정용 컨트롤 전송, 마우스 등의 인터럽트 전송, 대량의 데이터를 확실하게 보내는 벌크 전송, 시간에 맞춰 전달하는 아이소크로너스 전송이 있습니다.
