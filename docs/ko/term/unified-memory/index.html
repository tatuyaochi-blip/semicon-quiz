통합 메모리(Unified Memory)란?

CPU와 GPU에서 같은 포인터로 사용할 수 있고 접근에 따라 데이터가 자동으로 이동하는 메모리. 프로그램은 간단해지지만 이동 비용에 주의가 필요하다.

일본어 명칭: ユニファイドメモリ

통합 메모리(Unified Memory)은(는) GPU 프로그래밍 등 1개 분야의 연습 문제 1개에 나와요.

분야: GPU 프로그래밍

도전해 보기: 통합 메모리(Unified Memory) 관련 문제

CUDA 유니파이드 메모리(통합 메모리)에 대한 설명으로 올바른 것은?

  1. ACPU와 GPU에서 같은 포인터로 사용할 수 있는 메모리로, 필요에 따라 데이터가 자동으로 이동한다
  2. BCPU와 GPU 칩을 물리적으로 하나로 만든 것
  3. CGPU 메모리를 모두 읽기 전용으로 만든 것
정답과 해설 보기

정답: A. CPU와 GPU에서 같은 포인터로 사용할 수 있는 메모리로, 필요에 따라 데이터가 자동으로 이동한다

유니파이드 메모리에서는 할당한 영역에 CPU에서도 GPU에서도 같은 포인터로 접근할 수 있으며, 접근이 있을 때 페이지 단위로 데이터가 필요한 쪽으로 이동합니다. 프로그램이 간단해지고 GPU 메모리보다 큰 데이터도 다루기 쉬워집니다. 다만 이동할 때마다 페이지 폴트와 전송이 발생하므로, 성능이 필요할 때는 미리 이동시키라는 지시를 내리는 등의 궁리를 합니다.
