미스 페널티(miss penalty)란?

캐시 미스가 났을 때 하위 계층에서 데이터를 가져오느라 추가로 걸리는 시간. 하위 계층의 접근 시간과 라인 전송 시간으로 정해진다.

일본어 명칭: ミスペナルティ

미스 페널티(miss penalty)은(는) 메모리 계층 구조 등 1개 분야의 연습 문제 9개에 나와요.

분야: 메모리 계층 구조

도전해 보기: 미스 페널티(miss penalty) 관련 문제

캐시의 히트 시간이 2사이클, 미스율이 4%, 미스 페널티가 150사이클일 때, 평균 메모리 접근 시간은 몇 사이클인가?

  1. A8사이클
  2. B6사이클
  3. C152사이클
정답과 해설 보기

정답: A. 8사이클

평균 메모리 접근 시간 = 히트 시간 + 미스율 × 미스 페널티 = 2 + 0.04 × 150 = 2 + 6 = 8사이클입니다. 히트 시간은 모든 접근에서 소요되고, 미스했을 때만 미스 페널티가 더해진다고 생각합니다. 6사이클은 미스 분량만 계산하고 히트 시간을 더하는 것을 잊은 값입니다. 152사이클은 미스한 접근 1회에 걸리는 시간이며 평균이 아닙니다. 미스율이 겨우 4%여도 평균이 4배가 된다는 것을 알 수 있습니다.

캐시가 이상적이면 평균 CPI가 1.0인 프로세서에서, 명령 1개당 평균 1.3회의 메모리 접근이 있고 그 미스율이 2%, 미스 페널티가 100사이클일 때, 실제 평균 CPI는 얼마인가?

  1. A3.0
  2. B3.6
  3. C1.3
정답과 해설 보기

정답: B. 3.6

명령 1개당 메모리 정지 사이클은 1.3회 × 0.02 × 100사이클 = 2.6사이클입니다. 이를 이상적인 CPI에 더하면 1.0 + 2.6 = 3.6이 되어 성능은 이상의 3.6분의 1로 떨어집니다. 3.0은 명령 1개당 접근을 1회로 잘못 본 값(1.0 + 1 × 0.02 × 100)입니다. 1.3은 명령 1개당 접근 횟수이며 CPI가 아닙니다. 약간의 미스율이어도 미스 페널티가 크면 성능을 크게 떨어뜨린다는 것을 알 수 있습니다.

미스 페널티(miss penalty)이(가) 나오는 문제 (9)

  1. 캐시의 히트 시간이 2사이클, 미스율이 4%, 미스 페널티가 150사이클일 때, 평균 메모리 접근 시간은 몇 사이클인가?
  2. 캐시가 이상적이면 평균 CPI가 1.0인 프로세서에서, 명령 1개당 평균 1.3회의 메모리 접근이 있고 그 미스율이 2%, 미스 페널티가 100사이클일 때, 실제 평균 CPI는 얼마인가?
  3. L1 캐시의 히트 시간이 1 ns, 미스율이 5%, L2 캐시의 히트 시간이 10 ns, L2의 로컬 미스율이 20%, 주기억장치의 접근 시간이 100 ns일 때, 평균 메모리 접근 시간은 얼마인가?
  4. 캐시의 라인 크기를 크게 했을 때의 영향으로 올바른 것은?
  5. 소프트웨어 프리페치 명령을 넣을 때, 얼마나 앞의 데이터를 읽을지(프리페치 거리)에 대한 설명으로 올바른 것은?
  6. L1 캐시 아래에 L2 캐시를 두는 다단 캐시에서 L2 캐시의 주된 역할은?
  7. 캐시 히트율이 95%일 때, 미스율은 얼마인가?
  8. 미스한 라인을 주기억장치에서 읽어 올 때, CPU가 필요로 하는 워드를 먼저 보내고 나머지를 나중에 보내는 기법은?
  9. 캐시 성능을 평가할 때 미스율뿐 아니라 평균 메모리 접근 시간으로 비교해야 하는 이유로 올바른 것은?
