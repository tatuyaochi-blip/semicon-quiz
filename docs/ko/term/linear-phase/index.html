선형 위상(Linear Phase)란?

필터의 위상 특성이 주파수에 비례하는 직선으로 되어 있는 것. 이때 모든 주파수 성분이 같은 시간만큼 지연되므로(군지연이 일정해지므로) 파형의 모양이 무너지지 않는다. FIR 필터에서는 계수를 중심에 대해 대칭(또는 반대칭)으로 하면 정확히 선형 위상이 되며, N탭이면 지연은 (N − 1)/2샘플이다. 안정하고 인과적인 IIR 필터로는 정확한 선형 위상을 실현할 수 없으므로, 파형을 유지하고 싶은 오디오, 통신 수신, 계측 등의 처리에서는 FIR 필터가 자주 사용된다.

일본어 명칭: 直線位相

선형 위상(Linear Phase)은(는) 디지털 신호 처리의 기초 등 1개 분야의 연습 문제 3개에 나와요.

분야: 디지털 신호 처리의 기초

도전해 보기: 선형 위상(Linear Phase) 관련 문제

다음 계수를 갖는 5탭 FIR 필터 중에서 선형 위상(직선 위상) 특성을 갖는 것은?

  1. Ah = {1, 2, 3, 2, 1}
  2. Bh = {1, 2, 3, 4, 5}
  3. Ch = {5, 4, 3, 2, 1}
정답과 해설 보기

정답: A. h = {1, 2, 3, 2, 1}

FIR 필터의 계수가 중심에 대해 좌우 대칭(h[n] = h[N − 1 − n])이면 위상은 주파수에 비례하는 직선이 되어, 모든 주파수 성분이 같은 (N − 1)/2샘플만큼 지연됩니다. {1, 2, 3, 2, 1}은 가운데의 3에 대해 대칭이므로, 지연이 2샘플로 일정한 선형 위상 필터입니다. {1, 2, 3, 4, 5}와 {5, 4, 3, 2, 1}은 대칭도 반대칭도 아니므로, 주파수에 따라 지연이 바뀝니다.

101탭 선형 위상 FIR 필터(계수가 좌우 대칭)의 군지연으로 올바른 것은?

  1. A50샘플
  2. B50.5샘플
  3. C101샘플
정답과 해설 보기

정답: A. 50샘플

계수가 대칭인 N탭 FIR 필터의 군지연은 주파수와 관계없이 (N − 1)/2샘플입니다. N = 101이면 (101 − 1)/2 = 50샘플로, 계수의 중심(51번째 계수 h[50])의 위치에 해당합니다. 샘플링 주파수가 48 kHz라면 50 ÷ 48000 ≈ 1.04 ms의 지연이 되며, 실시간 처리에서는 탭 수를 늘릴수록 지연이 커진다는 점에 주의해야 합니다.

해설 속 선형 위상(Linear Phase)

  • {1, 2, 3, 2, 1}은 가운데의 3에 대해 대칭이므로, 지연이 2샘플로 일정한 선형 위상 필터입니다.

    다음 계수를 갖는 5탭 FIR 필터 중에서 선형 위상(직선 위상) 특성을 갖는 것은?

  • 계수를 좌우 대칭으로 하면 모든 주파수 성분이 같은 시간만큼 지연되는 선형 위상이 되어, 파형의 모양을 무너뜨리지 않습니다.

    FIR 필터(유한 임펄스 응답 필터)의 특징으로 올바른 것은?

선형 위상(Linear Phase)이(가) 나오는 문제 (3)

  1. 다음 계수를 갖는 5탭 FIR 필터 중에서 선형 위상(직선 위상) 특성을 갖는 것은?
  2. 101탭 선형 위상 FIR 필터(계수가 좌우 대칭)의 군지연으로 올바른 것은?
  3. FIR 필터(유한 임펄스 응답 필터)의 특징으로 올바른 것은?

이 용어가 포함된 비교

  • FIR 필터와 IIR 필터의 차이: 구조·안정성·위상·차수·연산량 비교FIR 필터와 IIR 필터를 계산 형태와 임펄스 응답, 안정성, 위상 특성, 같은 특성에 필요한 차수, 연산량, 지연, 계수 양자화, 설계 방법, 용도의 관점에서 표로 비교합니다.
