조건 변수(Condition Variable)란?

어떤 조건이 충족될 때까지 스레드를 재워 두고 다른 스레드의 통지로 깨우는 동기화 메커니즘. 깨어난 뒤에는 조건을 다시 확인한다.

일본어 명칭: 条件変数

조건 변수(Condition Variable)은(는) 멀티코어와 동기화 등 1개 분야의 연습 문제 1개에 나와요.

도전해 보기: 조건 변수(Condition Variable) 관련 문제

조건 변수로 '큐가 비지 않을 때까지 기다린다'고 할 때, 대기에서 깨어난 뒤 조건을 if문이 아닌 while문으로 다시 확인하는 이유로 올바른 것은 무엇입니까?

  1. Awhile문이 if문보다 실행이 빠르기 때문
  2. Bif문에서는 조건 변수를 사용할 수 없는 규칙이기 때문
  3. C깨워졌더라도 다른 스레드가 먼저 가져가 버렸거나 이유 없이 깨어났을 수 있어, 조건이 충족되지 않았을 가능성이 있기 때문

정답: C. 깨워졌더라도 다른 스레드가 먼저 가져가 버렸거나 이유 없이 깨어났을 수 있어, 조건이 충족되지 않았을 가능성이 있기 때문

조건 변수의 대기는 락을 놓고 잠들었다가, 알림을 받아 깨어나면 락을 다시 얻고 복귀합니다. 그러나 깨어나기까지의 사이에 다른 스레드가 먼저 락을 얻어 큐의 요소를 가져가는 경우가 있습니다. 또한 구현상의 이유로 알림이 없어도 깨어나는 것(스퓨리어스 웨이크업)이 허용되어 있습니다. 그래서 깨어난 뒤 조건을 확인하고, 충족되지 않았으면 다시 기다리는 while문으로 작성합니다.
