SoC(시스템 온 칩)란?

CPU, GPU, 메모리 컨트롤러, 통신 기능 등 시스템에 필요한 기능을 1개의 칩에 집적한 LSI. 스마트폰의 핵심 부품이 대표적이다.

일본어 명칭: SoC(システムオンチップ)

SoC(시스템 온 칩)은(는) 전력 관리, IC 설계 흐름과 EDA, 반도체 산업과 시장 등 9개 분야의 연습 문제 19개에 나와요.

분야: 반도체 산업과 시장

SoC에 들어가는 것

일반적인 스마트폰용 SoC(시스템 온 칩)에는 여러 개의 CPU 코어, GPU, 흔히 신경망 처리 장치(NPU)와 이미지 신호 처리기(ISP), 온칩 SRAM 캐시, DRAM 인터페이스를 포함한 메모리 컨트롤러, 디스플레이 및 카메라 인터페이스, 고속 I/O, 보안 블록, 전원 관리 로직이 들어 있으며, 일부 설계에는 셀룰러 모뎀도 포함됩니다. 메인 DRAM은 보통 별도의 칩으로 두며, SoC 패키지 위에 적층하는 경우가 많습니다. 내부 블록들은 온칩 인터커넥트로 통신합니다. 레지스터 접근용 AXI4-Lite와 데이터 흐름용 AXI4-Stream을 포함하는 Arm의 AMBA AXI 계열은 서로 다른 업체의 IP를 연결할 수 있게 해 주는 널리 쓰이는 표준입니다.

한 칩에 집적하는 이유

하나의 다이 안에 머무는 신호는 패키지 핀, 기판 배선, 그리고 이를 구동하는 데 필요한 큰 드라이버를 거치지 않으므로, SoC는 같은 기능을 여러 칩에 나눌 때보다 작고 빠르며 전력을 적게 쓰고, 기판의 부품 수도 줄어듭니다. 그러나 대가도 분명합니다. 다이가 크면 결함 하나가 더 넓은 면적을 불량으로 만들어 수율이 낮아지고, 다이는 약 26 mm × 33 mm인 노광 필드를 넘을 수 없으며, DRAM, 아날로그, RF처럼 다른 공정이 필요한 기능은 같은 로직 공정에서 최적으로 만들기 어렵습니다.

SoC 내부의 전력과 보안

블록마다 요구 속도와 활동량이 다르므로 SoC는 여러 전원 도메인으로 나뉩니다. 각 도메인은 동적 전압·주파수 조정(DVFS)으로 고유의 전압과 주파수에서 동작하거나 완전히 꺼질 수 있으며, 작은 상시 동작(always-on) 도메인이 웨이크업을 담당합니다. 도메인을 넘나드는 신호에는 레벨 시프터와 아이솔레이션 셀이 필요합니다. 외부 전원 관리 IC(PMIC)가 SoC의 제어 아래 배터리로부터 여러 전원 레일을 생성합니다. 보안 측면에서는 Arm TrustZone 같은 메커니즘이 모든 버스 접근을 보안 또는 일반으로 표시해 같은 칩 안에 보호된 환경을 만듭니다.

SoC와 SiP, 칩렛의 비교

SoC는 시스템을 하나의 다이에 올립니다. 반면 SiP(시스템 인 패키지)는 여러 다이와 수동 부품을 하나의 패키지에 넣으므로, 다른 공정으로 만든 칩을 조합하거나 기존 부품을 재사용하기 쉽지만 연결 밀도와 전력에서는 다소 불리합니다. 칩렛 설계는 매우 큰 SoC가 될 것을 여러 다이로 나누어 첨단 패키지 안에서 고밀도로 연결하며, 수율을 높이고 레티클 필드 하나보다 큰 시스템을 가능하게 합니다. SoC를 설계하는 많은 회사는 팹리스이며, 파운드리에 제조를 맡깁니다.

정답과 해설 보기

정답: C. NPU(신경망 처리 장치)

NPU는 신경망 계산의 대부분을 차지하는 곱셈-누산 연산을 8비트 이하의 정수 등 낮은 정밀도로 대량 병렬 처리하는 전용 회로입니다. 범용 CPU보다 전력당 성능이 한 자릿수 이상 높아, 사진 보정, 음성 인식, 번역 등을 스마트폰 안에서 처리할 수 있습니다. 성능은 TOPS(초당 조 회 연산)로 나타내며, PC용 SoC에도 탑재가 확산되고 있습니다.

대규모 SoC 검증에서 설계한 회로를 전용 하드웨어나 FPGA 위에서 동작시키고 소프트웨어와 조합하여 고속으로 검증하는 기법은?

  1. A에뮬레이션이나 FPGA 프로토타이핑
  2. BDRC
  3. CCMP
정답과 해설 보기

정답: A. 에뮬레이션이나 FPGA 프로토타이핑

소프트웨어에 의한 논리 시뮬레이션은 대규모 회로에서는 1초 분량의 동작에 며칠이 걸릴 만큼 느려집니다. 에뮬레이터나 FPGA에 회로를 구현하여 동작시키면 수 자릿수 빠르게 검증할 수 있고, 실제 OS나 애플리케이션을 동작시키면서 칩이 완성되기 전에 소프트웨어 개발과 검증을 진행할 수 있습니다. 에뮬레이터는 내부 신호를 관측하기 쉽고, FPGA 프로토타입은 더 빠르다는 차이가 있습니다.

자주 묻는 질문

SoC와 SiP의 차이는 무엇인가요?

SoC는 시스템의 기능을 하나의 실리콘 다이에 집적하고, SiP는 여러 개의 별도 다이와 부품을 하나의 패키지에 넣습니다. SoC는 전력과 지연이 가장 낮고, SiP는 서로 다른 공정의 칩을 조합하기 쉽습니다.

마이크로컨트롤러도 SoC인가요?

넓은 의미에서는 그렇습니다. 마이크로컨트롤러는 CPU, 플래시, SRAM, 주변 장치를 한 칩에 집적하기 때문입니다. 다만 SoC라는 용어는 보통 외부 DRAM과 함께 완전한 운영 체제를 실행하는 더 큰 애플리케이션 프로세서를 가리킵니다.

DRAM은 왜 보통 SoC와 같은 다이에 넣지 않나요?

범용 DRAM은 고밀도 커패시터 셀에 최적화된 전용 공정을 사용하는데, 이는 고성능 로직 공정과 호환되지 않습니다. 그래서 스마트폰은 별도의 DRAM 칩을 SoC 패키지 위나 옆에 쌓아 둡니다.
