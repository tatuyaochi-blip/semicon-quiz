특권 모드(Privileged Mode)란?

OS 커널만 사용할 수 있는 CPU 동작 모드. 페이지 테이블 설정이나 입출력 조작 등 위험한 명령을 실행할 수 있으며, 애플리케이션이 동작하는 사용자 모드와 구별된다.

일본어 명칭: 特権モード

특권 모드(Privileged Mode)은(는) OS와 하드웨어 등 1개 분야의 연습 문제 5개에 나와요.

분야: OS와 하드웨어

특권 모드가 보호하는 것

어떤 동작은 하나의 프로그램이 기계 전체를 장악하게 만들 수 있습니다. 페이지 테이블이나 그것을 가리키는 레지스터의 변경, 입출력 장치에 대한 직접 접근, 인터럽트 비활성화, OS가 제어권을 되찾게 해 주는 타이머의 재설정, CPU 정지 등입니다. 프로세서는 이러한 동작을 커널 모드 또는 슈퍼바이저 모드라고도 하는 특권 모드에서만 허용합니다. 사용자 모드에서 실행 중인 코드가 이를 시도하면 CPU가 예외를 발생시키고, OS가 대응을 결정하며 보통 해당 프로그램을 종료합니다.

특권 모드로의 진입과 복귀

사용자 코드는 단순히 점프해서 특권 모드로 들어갈 수 없습니다. 진입 경로는 예외, 인터럽트, 그리고 시스템 콜 같은 의도적인 트랩뿐이며, 각각 OS가 미리 설정해 둔 진입점으로 제어를 넘깁니다. CPU는 복귀 주소, 이전 모드, 인터럽트 허용 상태를 전용 레지스터에 저장합니다. RISC-V의 sret이나 mret 같은 특수 복귀 명령어가 이들을 한꺼번에 복원하므로, 특권을 유지한 채 사용자 코드에서 실행이 재개되는 일은 없습니다.

실제 CPU의 권한 레벨

많은 아키텍처에는 두 개보다 많은 레벨이 있습니다. RISC-V는 머신, 슈퍼바이저, 사용자 모드를 정의하고, x86에는 링 0~3이 있어 운영체제는 주로 커널에 링 0, 애플리케이션에 링 3을 사용합니다. Arm은 예외 레벨 EL0~EL3을 사용합니다. 하이퍼바이저는 게스트 커널보다 위에서 동작하며, 게스트가 특권 명령어를 실행하면 하이퍼바이저로 트랩되어 하이퍼바이저가 그 효과를 에뮬레이션합니다. 이 트랩 앤 에뮬레이트 방식은 같은 보호 개념을 한 단계 위에서 재사용하는 것입니다.

특권 모드와 관리자 권한의 차이

특권 모드는 CPU의 하드웨어 상태이지 사용자 계정이 아닙니다. 관리자나 root 사용자가 실행한 프로세스도 여전히 사용자 모드에서 실행되며, 추가 권한은 커널이 그 프로세스의 시스템 콜을 처리할 때 확인하는 허가일 뿐입니다. 특권 모드에서 실행되는 것은 커널 코드뿐이며, 일부 시스템에서는 펌웨어나 하이퍼바이저도 포함됩니다. 메모리 보호는 모드 비트를 보완하며, 페이지 테이블 엔트리가 사용자 모드에서 접근 가능한 페이지를 표시합니다.

  3. C하나의 CPU에서 동시에 두 개의 명령을 실행할 수 있게 하기 위해
정답과 해설 보기

정답: B. 애플리케이션이 페이지 테이블이나 장치를 마음대로 조작하지 못하도록 보호하기 위해

페이지 테이블 재작성, 입출력 장치 조작, 인터럽트 금지 등을 애플리케이션이 마음대로 할 수 있다면 다른 프로그램의 메모리를 망가뜨리거나 시스템 전체를 멈출 수 있습니다. 그래서 CPU는 이러한 명령을 특권 모드에서만 실행할 수 있게 하여 OS 커널만 사용할 수 있도록 합니다. 사용자 모드에서 실행하려 하면 예외가 발생합니다. 속도나 동시 실행을 위한 구조가 아닙니다.

자주 묻는 질문

커널 모드와 사용자 모드 차이

커널(특권) 모드에서는 CPU가 페이지 테이블 변경, 장치 제어, 인터럽트 비활성화 같은 동작을 허용합니다. 사용자 모드에서는 이런 동작이 예외를 일으키므로, 애플리케이션은 시스템 콜을 통해 커널에 요청해야 합니다.

root로 실행하면 커널 모드로 실행되나요

아닙니다. root는 운영체제의 권한 수준이며, root 프로세스도 여전히 사용자 모드에서 실행됩니다. 특권 모드에서 실행되는 것은 커널뿐입니다.

프로그램이 커널 모드로 전환되는 방법

시스템 콜 명령어 실행 같은 트랩, 또는 예외나 인터럽트를 통해서만 전환됩니다. 이들은 모두 OS가 설정해 둔 진입점에서 커널로 들어갑니다.

해설 속 특권 모드(Privileged Mode)

    애플리케이션이 파일 읽기·쓰기 등을 OS에 요청하는 구조를 무엇이라고 합니까?

  • CPU는 현재 명령의 주소를 저장하고 더 높은 특권 모드로 전환하여 OS가 설정한 예외 처리 입구로 진행합니다.

이 용어가 포함된 비교

  • 사용자 모드와 커널 모드의 차이점 정리사용자 모드와 커널 모드를 표로 비교합니다. 실행할 수 있는 명령어, 접근할 수 있는 메모리, 전환 계기, 전환 비용, 오류의 영향, 보호의 목적을 다룹니다.
