CUDA란?

NVIDIA GPU에서 범용 연산을 수행하기 위한 프로그래밍 체계. C++을 확장한 언어로 커널을 작성하고, 그리드·블록·스레드의 계층으로 병렬성을 나타낸다.

일본어 명칭: CUDA

CUDA은(는) GPU 프로그래밍 등 1개 분야의 연습 문제 18개에 나와요.

분야: GPU 프로그래밍

도전해 보기: CUDA 관련 문제

CUDA 등 GPU 프로그래밍에서 말하는 '커널'에 대한 설명으로 올바른 것은?

  1. AGPU OS의 중심이 되는 부분
  2. BGPU에서 다수의 스레드가 동시에 실행하는 함수
  3. CGPU 칩을 식히는 부품
정답과 해설 보기

정답: B. GPU에서 다수의 스레드가 동시에 실행하는 함수

GPU 프로그래밍의 커널은 CPU 측 프로그램에서 호출되어, GPU에서 다수의 스레드가 같은 코드를 실행하는 함수입니다. 각 스레드는 자신의 번호를 이용해 담당할 데이터 요소를 선택합니다. 예를 들어 배열 덧셈이라면 하나의 스레드가 하나의 요소를 더하도록 커널을 작성하고, 요소 수만큼 스레드를 실행합니다. OS의 커널과 용어는 같지만 의미는 다릅니다.

CUDA 스레드 계층의 조합으로 올바른 것은? (큰 순서)

  1. A그리드 → 블록 → 스레드
  2. B스레드 → 블록 → 그리드
  3. C블록 → 스레드 → 그리드
정답과 해설 보기

정답: A. 그리드 → 블록 → 스레드

커널을 한 번 실행하면 전체가 그리드가 되고, 그리드는 다수의 블록으로, 블록은 다수의 스레드로 나뉩니다. 하나의 블록에 속한 스레드는 같은 SM(연산기의 집합)에서 실행되며, 공유 메모리로 협력하거나 동기화할 수 있습니다. 서로 다른 블록은 독립적으로 실행되므로 GPU 규모에 따라 동시에 실행되는 블록 수가 달라지며, 같은 프로그램이 크고 작은 GPU에서 모두 동작합니다.

해설 속 CUDA

  • CUDA에는 점유율을 계산하는 도구도 마련되어 있습니다.

    GPU의 점유율(occupancy)에 대한 설명으로 올바른 것은?

  • 실행 순서열을 한꺼번에 기록해 두었다가 한 번에 보내는 방식(CUDA Graphs 등)도 사용됩니다.

    매우 작은 커널을 수천 번 연속으로 실행하는 프로그램이 느릴 때, 개선 방법으로 가장 적절한 것은?

  • CUDA는 NVIDIA GPU용 체계이지만, OpenCL은 업계 단체가 정한 표준 규격으로 여러 회사의 GPU나 CPU, FPGA 등에서 사용할 수 있습니다.

    NVIDIA 이외의 GPU에서도 사용할 수 있는, GPU 등의 병렬 계산을 위한 프로그래밍 체계의 예로 올…

CUDA이(가) 나오는 문제 (18)

  1. CUDA 등 GPU 프로그래밍에서 말하는 '커널'에 대한 설명으로 올바른 것은?
  2. CUDA 스레드 계층의 조합으로 올바른 것은? (큰 순서)
  3. CUDA 커널에서 위의 식으로 각 스레드의 번호 i를 구한다. blockIdx.x=2, blockDim.x=256, threadIdx.x=5인 스레드의 i는 얼마인가?
  4. 위 CUDA 커널에 "if (i < n)"을 넣은 이유로 올바른 것은?
  5. CUDA 공유 메모리(shared memory)의 특징으로 올바른 것은?
  6. CUDA의 __syncthreads()의 역할로 올바른 것은?
  7. CUDA에서 __syncthreads()를 "if (threadIdx.x < 16)" 안에 써서 일부 스레드만 통과하도록 했다. 일어날 수 있는 일로 올바른 것은?
  8. CUDA 공유 메모리의 뱅크 충돌에 대한 설명으로 올바른 것은?
  9. CUDA에서 블록과 SM(스트리밍 멀티프로세서)의 관계로 올바른 것은?
  10. CUDA에서 커널 도중에 다른 모든 블록의 계산이 끝나기를 기다린 뒤 다음 단계로 진행하고 싶다. 일반적인 방법은?
  11. CUDA 스트림을 여러 개 사용하는 주된 목적은?
  12. CUDA 유니파이드 메모리(통합 메모리)에 대한 설명으로 올바른 것은?
  13. CUDA에서 블록당 스레드 수를 정할 때의 일반적인 기준으로 올바른 것은?
  14. CUDA 상수 메모리(constant memory)가 특히 빠르게 동작하는 것은 어떤 접근일 때인가?
  15. CUDA에서 CPU 측 프로그램이 커널을 실행한 직후의 동작으로 일반적으로 올바른 것은?
