CUDA란?

NVIDIA GPU에서 범용 연산을 수행하기 위한 프로그래밍 체계. C++을 확장한 언어로 커널을 작성하고, 그리드·블록·스레드의 계층으로 병렬성을 나타낸다.

일본어 명칭: CUDA

CUDA은(는) GPU 프로그래밍 등 1개 분야의 연습 문제 18개에 나와요.

분야: GPU 프로그래밍

커널과 스레드 계층

CUDA에서는 CPU(호스트)가 커널, 즉 많은 GPU 스레드가 동시에 실행하는 함수를 실행합니다. 한 번의 실행은 블록으로 이루어진 그리드를 만들며, 각 블록에는 많은 스레드가 들어 있습니다. 각 스레드는 고유한 전역 인덱스, 보통 i = blockIdx.x × blockDim.x + threadIdx.x를 계산해 처리할 데이터 요소를 고릅니다. 블록당 256 스레드일 때 블록 2의 스레드 5는 요소 517을 담당합니다. 스레드는 블록 단위로 실행되므로 마지막 블록에는 보통 남는 스레드가 있으며, 커널은 배열 끝을 넘어 쓰지 않도록 if (i < n)로 메모리 접근을 보호합니다.

블록이 GPU에 배정되는 방식

각 블록은 하나의 스트리밍 멀티프로세서(SM)에 배정되어 그곳에서 끝까지 실행되며, SM 하나는 여러 블록을 동시에 담을 수 있습니다. 내부에서 스레드는 32개 단위의 워프로 실행됩니다. 상주하는 워프 수와 SM 최대치의 비율인 점유율(occupancy)은 스레드당 레지스터, 블록당 공유 메모리, 블록 크기에 의해 제한되며, 점유율이 낮으면 메모리 지연을 숨길 워프가 너무 적어집니다. 블록은 독립적으로 임의의 순서로 실행되므로, 커널 안에서 다른 모든 블록을 기다리면 교착 상태가 될 수 있습니다. 전역 동기화는 보통 작업을 두 번의 커널 실행으로 나누어 얻습니다.

메모리 공간

전역 메모리는 GPU의 DRAM으로, 대역폭이 높고 지연이 크며, 인접한 스레드가 인접한 주소에 접근할 때 가장 빠릅니다. 공유 메모리는 블록마다 있는 작은 온칩 메모리로, 프로그램이 명시적으로 관리합니다. 32개의 뱅크로 나뉘어 있으며, 한 워프의 스레드가 같은 뱅크의 서로 다른 주소에 접근하면 직렬화됩니다. __syncthreads()는 블록의 모든 스레드가 도착할 때까지 각 스레드를 기다리게 하며, 일부 스레드가 건너뛰는 분기 안에 두면 멈추거나 결과가 정의되지 않습니다. 통합 메모리는 호스트와 디바이스가 하나의 포인터를 공유하게 하며, 페이지는 필요할 때 이동됩니다.

GPU를 쉬지 않게 하기

호스트에서 디바이스로의 복사는 PCI Express를 거치며 병목이 되는 경우가 많습니다. 전송과 커널의 순서 있는 큐인 스트림을 쓰면 서로 다른 스트림의 작업이 겹칠 수 있어, 현재 덩어리를 계산하는 동안 다음 데이터 덩어리를 복사할 수 있습니다. 커널 실행마다 수 마이크로초가 들기 때문에, 작은 커널을 수천 번 실행하는 프로그램은 커널을 융합하면 이득을 보며(중간 결과를 메모리에 쓰지 않아도 되는 이점도 있음), CUDA Graphs로 기록된 실행 순서를 한꺼번에 제출해도 됩니다. CUDA 자체는 NVIDIA GPU에서만 동작하며, OpenCL 같은 벤더 중립 대안도 비슷한 커널과 워크 그룹 모델을 따릅니다.

  1. AGPU OS의 중심이 되는 부분
  2. BGPU에서 다수의 스레드가 동시에 실행하는 함수
  3. CGPU 칩을 식히는 부품
정답과 해설 보기

정답: B. GPU에서 다수의 스레드가 동시에 실행하는 함수

GPU 프로그래밍의 커널은 CPU 측 프로그램에서 호출되어, GPU에서 다수의 스레드가 같은 코드를 실행하는 함수입니다. 각 스레드는 자신의 번호를 이용해 담당할 데이터 요소를 선택합니다. 예를 들어 배열 덧셈이라면 하나의 스레드가 하나의 요소를 더하도록 커널을 작성하고, 요소 수만큼 스레드를 실행합니다. OS의 커널과 용어는 같지만 의미는 다릅니다.

CUDA 스레드 계층의 조합으로 올바른 것은? (큰 순서)

  1. A그리드 → 블록 → 스레드
  2. B스레드 → 블록 → 그리드
  3. C블록 → 스레드 → 그리드
정답과 해설 보기

정답: A. 그리드 → 블록 → 스레드

커널을 한 번 실행하면 전체가 그리드가 되고, 그리드는 다수의 블록으로, 블록은 다수의 스레드로 나뉩니다. 하나의 블록에 속한 스레드는 같은 SM(연산기의 집합)에서 실행되며, 공유 메모리로 협력하거나 동기화할 수 있습니다. 서로 다른 블록은 독립적으로 실행되므로 GPU 규모에 따라 동시에 실행되는 블록 수가 달라지며, 같은 프로그램이 크고 작은 GPU에서 모두 동작합니다.

자주 묻는 질문

CUDA 블록과 워프의 차이점

블록은 프로그래머가 정하는 스레드 그룹으로, 하나의 SM에서 실행되며 메모리를 공유하고 동기화할 수 있습니다. 워프는 블록 안에서 하드웨어가 묶는 32개 스레드의 그룹으로, 명령을 록스텝으로 함께 실행합니다.

CUDA에서 전역 스레드 인덱스 계산하는 방법

1차원 실행에서는 i = blockIdx.x * blockDim.x + threadIdx.x를 사용합니다. 마지막 블록에는 남은 요소보다 스레드가 많은 경우가 흔하므로 배열에 접근하기 전에 i < n을 확인합니다.

CUDA 공유 메모리는 어디에 쓰나요?

한 블록의 스레드들이 공유하는 빠른 온칩 메모리로, 전역 메모리의 데이터를 재사용하기 위해 올려 두거나 중간 결과를 교환하는 데 씁니다. 캐시와 달리 무엇을 넣을지 프로그램이 결정하며, __syncthreads()로 접근 순서를 맞춥니다.
