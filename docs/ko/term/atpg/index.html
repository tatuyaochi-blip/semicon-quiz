ATPG(자동 테스트 패턴 생성)란?

회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것. 스캔 설계와 조합하여 사용한다.

일본어 명칭: ATPG(自動テストパターン生成)

ATPG(자동 테스트 패턴 생성)은(는) 테스트와 검사, 계측과 분석, 수율과 품질 관리 등 4개 분야의 연습 문제 7개에 나와요.

분야: 테스트와 검사

ATPG가 테스트를 찾는 방법

자동 테스트 패턴 생성(ATPG)은 게이트 수준 넷리스트와 고장 모델을 바탕으로 동작합니다. 대상 고장마다 고장을 활성화하여, 즉 고장 난 라인을 고착값의 반대로 구동하고, 그 차이를 감응화된 경로를 따라 관측 가능한 출력까지 전파해야 하며, 동시에 둘 다를 성립시키는 주입력 값을 찾아야 합니다. D 알고리즘과 PODEM 같은 고전적 알고리즘이 이 공간을 탐색합니다. 새 패턴마다 고장 시뮬레이션을 하여 우연히 검출되는 다른 모든 고장을 표시하며, 테스트 시간과 테스터 메모리가 패턴 수에 따라 늘어나므로 패턴을 압축합니다.

고장 모델과 커버리지

고착(stuck-at) 모델은 라인이 영구적으로 0 또는 1에 고정되었다고 가정하며, n개의 라인에 대해 2n개의 고장이 생깁니다. 추상적이지만 고착 고장을 검출하는 패턴은 실제 단락과 단선도 많이 잡아내므로, 패턴 집합이 검출하는 모델 고장의 비율인 고장 커버리지를 측정하는 기준으로 여전히 쓰입니다. 신호를 느리게 할 뿐인 결함은 정적 테스트로는 보이지 않으므로, 천이 고장 같은 지연 고장 모델은 천이를 발생시키고 한 클록 뒤에 결과를 포착하는 at-speed 패턴을 추가합니다. 커버리지는 항상 모델에 대한 상대값이며, 가능한 모든 물리적 결함에 대한 것이 아닙니다.

스캔 설계가 필수적인 이유

깊은 순차 회로에 대한 테스트 생성은 매우 어렵습니다. 내부 상태에 도달하려면 많은 클록 사이클을 거쳐야 하기 때문입니다. 테스트 용이화 설계(DFT) 기법인 스캔 설계는 각 플립플롭 입력에 멀티플렉서를 추가하여, 테스트 모드에서 플립플롭들이 시프트 레지스터 체인으로 연결되게 합니다. 테스터는 상태를 시프트 인하고, 기능 캡처 클록을 한 번 인가한 뒤, 결과를 시프트 아웃합니다. 그러면 ATPG는 스캔 셀 사이의 조합 논리만 풀면 되며, 이것이 수억 게이트 규모의 칩에서 높은 커버리지를 현실적으로 가능하게 합니다.

ATPG와 기능 검증

기능 검증은 설계가 올바른지를 묻고, ATPG는 설계가 올바르다고 가정한 뒤 제조된 각 칩이 그 설계와 일치하는지를 묻습니다. ATPG의 출력은 테스트 벡터라고도 하는 테스트 패턴으로, 타임 스텝별 입력값과 기대 응답이며, 자동 테스트 장비(ATE)가 이를 인가하고 비교합니다. 다른 선별 방법이 이를 보완합니다. PAT(part average testing)는 합격하더라도 측정값이 통계적 이상치인 칩을 불합격 처리하며 차량용 부품에서 흔한 관행이고, 자동 결함 분류(ADC)는 전기적 테스트가 아니라 웨이퍼 검사에 속합니다.

테스트 용이화 설계(DFT)의 하나인 스캔 설계에 대한 설명으로 올바른 것은 무엇입니까?

  1. A칩 표면을 광학 현미경으로 주사하여 결함을 찾는다
  2. B테스트 시 전원 전압을 서서히 올려 동작 한계를 조사한다
  3. C회로 내 플립플롭을 시프트 레지스터 형태로 연결하여 내부 상태의 설정과 관측을 쉽게 한다
정답과 해설 보기

정답: C. 회로 내 플립플롭을 시프트 레지스터 형태로 연결하여 내부 상태의 설정과 관측을 쉽게 한다

스캔 설계에서는 각 플립플롭의 입력에 전환용 셀렉터를 달고, 테스트 때는 이들을 줄줄이 연결(스캔 체인)하여 외부에서 임의의 값을 시프트로 설정하고 내부 값을 시프트로 읽어 낼 수 있게 합니다. 순차 회로의 테스트가 조합 회로의 테스트로 대체되므로, ATPG로 높은 고장 검출률의 패턴을 자동 생성할 수 있습니다. 현미경 주사나 전압 스윕과는 별개입니다.

로직 회로 테스트에서 사용되는 고착 고장(스턱앳 고장) 모델에 대한 설명으로 올바른 것은 무엇입니까?

  1. A신호가 전달되는 것이 느려지는 고장
  2. B신호선의 값이 0 또는 1로 고정되어 버리는 고장
  3. C칩의 온도가 올라가는 고장
정답과 해설 보기

정답: B. 신호선의 값이 0 또는 1로 고정되어 버리는 고장

고착 고장 모델에서는 회로 내 어떤 신호선이 항상 0(0 고착) 또는 항상 1(1 고착)로 고정되는 고장을 가정하며, 신호선이 n개라면 2n개의 고장을 생각합니다. 단순하지만 단락이나 단선 등 많은 물리적 결함을 대표할 수 있어, ATPG와 고장 검출률 평가의 기본이 되고 있습니다. 신호가 느려지는 고장은 지연 고장 모델로 다루며, 온도 상승은 고장 모델이 아닙니다.

자주 묻는 질문

VLSI 테스트에서 ATPG란?

회로의 넷리스트로부터 고착 고장 같은 모델화된 제조 고장을 검출하는 입력 패턴과 기대 출력을 자동으로 생성하는 소프트웨어입니다.

ATPG에 스캔 체인이 필요한 이유

스캔 체인으로 테스터가 모든 플립플롭을 직접 설정하고 읽을 수 있으므로, 어려운 순차 테스트 문제가 ATPG가 높은 커버리지로 효율적으로 풀 수 있는 조합 문제로 바뀝니다.

고착 고장 모델과 천이 고장 모델 차이

고착 고장은 라인이 0 또는 1에 고정된 것을 모델화하며 정적 테스트로 찾습니다. 천이 고장은 라인의 스위칭이 너무 느린 것을 모델화하며 at-speed 런치 앤 캡처 패턴이 필요합니다.

해설 속 ATPG(자동 테스트 패턴 생성)

  • 순차 회로의 테스트가 조합 회로의 테스트로 대체되므로, ATPG로 높은 고장 검출률의 패턴을 자동 생성할 수 있습니다.

    로직 회로 테스트에서 사용되는 고착 고장(스턱앳 고장) 모델에 대한 설명으로 올바른 것은 무엇입니까?

  • ATPG는 고착 고장 등의 고장 모델에 기초하여, 각 고장을 출력까지 전달하여 검출할 수 있는 입력 패턴을 넷리스트로부터 자동으로 생성하는 기술입니다.

    회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것을 무엇이라고 합니까?

  • 고장을 효율적으로 검출할 수 있는 패턴은 ATPG로 자동 생성하거나, 설계 시 검증용 시뮬레이션에서 변환하여 만듭니다.

    테스트에서 칩의 입력에 순서대로 가하는 0과 1 신호의 나열과 그에 대한 기대값의 쌍을 무엇이라고 합니까?

  • ATPG는 테스트 패턴 생성, APC는 공정 자동 제어입니다.

ATPG(자동 테스트 패턴 생성)이(가) 나오는 문제 (7)

  1. 테스트 용이화 설계(DFT)의 하나인 스캔 설계에 대한 설명으로 올바른 것은 무엇입니까?
  2. 로직 회로 테스트에서 사용되는 고착 고장(스턱앳 고장) 모델에 대한 설명으로 올바른 것은 무엇입니까?
  3. 회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것을 무엇이라고 합니까?
  4. 테스트에서 칩의 입력에 순서대로 가하는 0과 1 신호의 나열과 그에 대한 기대값의 쌍을 무엇이라고 합니까?
  5. 검사에서 발견된 결함을 SEM으로 촬영하고 그 이미지로부터 결함 종류를 자동으로 분류하는 기능은?
  6. 테스트에서는 규격 내이지만 같은 로트의 분포에서 크게 벗어난 값을 보이는 칩을 불량으로 제외하는 기법은?
  7. 배치 배선 후의 레이아웃에서 배선의 저항과 커패시턴스를 추출하는 공정을 무엇이라고 하는가?

이 용어가 포함된 비교

  • 스캔 테스트와 BIST의 차이점 정리스캔 테스트와 BIST(내장 자체 테스트)를 표로 비교합니다. 패턴 생성 방법, 테스터 의존도, 대상, 고장 검출률, 추가 회로, 테스트 시간을 안내합니다.
