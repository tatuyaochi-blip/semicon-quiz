ATPG(자동 테스트 패턴 생성)란?

회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것. 스캔 설계와 조합하여 사용한다.

일본어 명칭: ATPG(自動テストパターン生成)

ATPG(자동 테스트 패턴 생성)은(는) 테스트와 검사, 계측과 분석, 수율과 품질 관리 등 4개 분야의 연습 문제 7개에 나와요.

분야: 테스트와 검사

도전해 보기: ATPG(자동 테스트 패턴 생성) 관련 문제

테스트 용이화 설계(DFT)의 하나인 스캔 설계에 대한 설명으로 올바른 것은 무엇입니까?

  1. A칩 표면을 광학 현미경으로 주사하여 결함을 찾는다
  2. B테스트 시 전원 전압을 서서히 올려 동작 한계를 조사한다
  3. C회로 내 플립플롭을 시프트 레지스터 형태로 연결하여 내부 상태의 설정과 관측을 쉽게 한다
정답과 해설 보기

정답: C. 회로 내 플립플롭을 시프트 레지스터 형태로 연결하여 내부 상태의 설정과 관측을 쉽게 한다

스캔 설계에서는 각 플립플롭의 입력에 전환용 셀렉터를 달고, 테스트 때는 이들을 줄줄이 연결(스캔 체인)하여 외부에서 임의의 값을 시프트로 설정하고 내부 값을 시프트로 읽어 낼 수 있게 합니다. 순차 회로의 테스트가 조합 회로의 테스트로 대체되므로, ATPG로 높은 고장 검출률의 패턴을 자동 생성할 수 있습니다. 현미경 주사나 전압 스윕과는 별개입니다.

로직 회로 테스트에서 사용되는 고착 고장(스턱앳 고장) 모델에 대한 설명으로 올바른 것은 무엇입니까?

  1. A신호가 전달되는 것이 느려지는 고장
  2. B신호선의 값이 0 또는 1로 고정되어 버리는 고장
  3. C칩의 온도가 올라가는 고장
정답과 해설 보기

정답: B. 신호선의 값이 0 또는 1로 고정되어 버리는 고장

고착 고장 모델에서는 회로 내 어떤 신호선이 항상 0(0 고착) 또는 항상 1(1 고착)로 고정되는 고장을 가정하며, 신호선이 n개라면 2n개의 고장을 생각합니다. 단순하지만 단락이나 단선 등 많은 물리적 결함을 대표할 수 있어, ATPG와 고장 검출률 평가의 기본이 되고 있습니다. 신호가 느려지는 고장은 지연 고장 모델로 다루며, 온도 상승은 고장 모델이 아닙니다.

해설 속 ATPG(자동 테스트 패턴 생성)

  • 순차 회로의 테스트가 조합 회로의 테스트로 대체되므로, ATPG로 높은 고장 검출률의 패턴을 자동 생성할 수 있습니다.

    테스트 용이화 설계(DFT)의 하나인 스캔 설계에 대한 설명으로 올바른 것은 무엇입니까?

  • 단순하지만 단락이나 단선 등 많은 물리적 결함을 대표할 수 있어, ATPG와 고장 검출률 평가의 기본이 되고 있습니다.

    로직 회로 테스트에서 사용되는 고착 고장(스턱앳 고장) 모델에 대한 설명으로 올바른 것은 무엇입니까?

  • ATPG는 고착 고장 등의 고장 모델에 기초하여, 각 고장을 출력까지 전달하여 검출할 수 있는 입력 패턴을 넷리스트로부터 자동으로 생성하는 기술입니다.

    회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것을 무엇이라고 합니까?

  • 고장을 효율적으로 검출할 수 있는 패턴은 ATPG로 자동 생성하거나, 설계 시 검증용 시뮬레이션에서 변환하여 만듭니다.

    테스트에서 칩의 입력에 순서대로 가하는 0과 1 신호의 나열과 그에 대한 기대값의 쌍을 무엇이라고 합니까?

  • ATPG는 테스트 패턴 생성, APC는 공정 자동 제어입니다.

    검사에서 발견된 결함을 SEM으로 촬영하고 그 이미지로부터 결함 종류를 자동으로 분류하는 기능은?

ATPG(자동 테스트 패턴 생성)이(가) 나오는 문제 (7)

  1. 테스트 용이화 설계(DFT)의 하나인 스캔 설계에 대한 설명으로 올바른 것은 무엇입니까?
  2. 로직 회로 테스트에서 사용되는 고착 고장(스턱앳 고장) 모델에 대한 설명으로 올바른 것은 무엇입니까?
  3. 회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것을 무엇이라고 합니까?
  4. 테스트에서 칩의 입력에 순서대로 가하는 0과 1 신호의 나열과 그에 대한 기대값의 쌍을 무엇이라고 합니까?
  5. 검사에서 발견된 결함을 SEM으로 촬영하고 그 이미지로부터 결함 종류를 자동으로 분류하는 기능은?
  6. 테스트에서는 규격 내이지만 같은 로트의 분포에서 크게 벗어난 값을 보이는 칩을 불량으로 제외하는 기법은?
  7. 배치 배선 후의 레이아웃에서 배선의 저항과 커패시턴스를 추출하는 공정을 무엇이라고 하는가?
