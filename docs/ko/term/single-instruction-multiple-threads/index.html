SIMT란?

단일 명령·다중 스레드 방식. 프로그램은 스레드별로 작성하지만 하드웨어는 워프(NVIDIA에서는 32개) 단위로 스레드를 묶어 같은 명령으로 실행한다.

일본어 명칭: SIMT

SIMT은(는) GPU 프로그래밍 등 1개 분야의 연습 문제 2개에 나와요.

분야: GPU 프로그래밍

SIMT가 스레드를 실행하는 방식

단일 명령·다중 스레드(SIMT) 모델에서 프로그래머는 커널을 스레드 하나를 위한 일반 코드로 작성하고, 수천 개의 스레드가 이를 서로 다른 데이터로 실행합니다. 하드웨어는 스레드를 고정된 묶음으로 그룹화하며, NVIDIA GPU에서는 32스레드의 워프, AMD GPU에서는 64개 또는 32개의 웨이브프론트라고 부릅니다. 명령 하나를 묶음 전체에 대해 페치·디코드하고, 모든 스레드가 각자의 레지스터와 데이터로 보조를 맞춰(lockstep) 실행합니다. 이렇게 제어 로직을 많은 연산 레인에 분산시키므로 칩 면적의 대부분을 연산에 쓸 수 있습니다.

분기 다이버전스

각 스레드가 독립적으로 작성되므로 한 워프 안의 스레드들이 서로 다른 분기를 탈 수 있습니다. 하드웨어는 각 경로를 차례로 실행하고, 그 경로에 해당하지 않는 스레드는 마스크로 비활성화한 뒤 다시 합류(재수렴)시켜 이를 처리합니다. 정확성은 유지되지만, if-else의 양쪽으로 스레드가 절반씩 나뉘면 워프는 두 경로 모두에 시간을 쓰므로 처리량이 대략 절반으로 떨어집니다. 성능을 고려한 코드는 같은 워프의 스레드가 같은 경로를 따르도록 데이터를 배치합니다. 예를 들어 분기 조건이 각 스레드의 데이터가 아니라 워프 인덱스에 따라 정해지도록 합니다.

SIMT와 CPU의 SIMD

CPU의 단일 명령·다중 데이터(SIMD) 확장은 4개나 8개처럼 고정된 개수의 요소를 담은 벡터 레지스터에 명령 하나를 적용합니다. 프로그램이나 컴파일러는 그 폭에 맞춰 작성되어야 하며, 명시적인 벡터 명령과 경계 처리를 위한 마스크가 필요합니다. SIMT는 폭을 숨깁니다. 코드는 스칼라 스레드를 기술하고, 하드웨어가 많은 스레드로부터 벡터를 구성하며 다이버전스 시의 마스킹을 관리합니다. 내부의 실행은 비슷하므로, SIMT의 성능 역시 워프 안의 스레드들이 보조를 맞추도록 유지하는 데 달려 있습니다.

실무적인 영향

흔한 GPU 프로그래밍 규칙 몇 가지가 SIMT에서 나옵니다. 스레드 블록 크기는 보통 32의 배수로 정해 일부가 빈 채로 실행되는 워프가 없게 합니다. 메모리 접근은 워프 안의 이웃한 스레드가 이웃한 주소에 접근할 때 가장 빠르며, 이때 하드웨어가 이들을 몇 개의 넓은 트랜잭션으로 합칠 수 있는데 이 패턴을 코얼레싱이라고 합니다. 또한 GPU는 많은 워프를 상주시켜 두고 한 워프가 멈추면 준비된 다른 워프로 전환해 긴 메모리 지연을 숨깁니다. 그래서 코어당 활성 워프 수가 충분한 높은 점유율(occupancy)이 성능에 중요한 경우가 많습니다.

도전해 보기: SIMT 관련 문제

GPU의 SIMT(단일 명령·다중 스레드) 방식과 CPU의 SIMD 명령의 차이로 올바른 것은?

  1. ASIMT는 하나의 데이터에 여러 명령을 동시에 수행하고, SIMD는 하나의 명령을 하나의 데이터에 수행한다
  2. BSIMT와 SIMD는 완전히 같은 것이며 이름만 다르다
  3. CSIMT에서는 각 스레드를 독립된 프로그램으로 작성할 수 있고 분기도 하드웨어가 처리하지만, SIMD에서는 프로그래머나 컴파일러가 폭이 정해진 벡터 명령을 명시적으로 사용한다
정답과 해설 보기

정답: C. SIMT에서는 각 스레드를 독립된 프로그램으로 작성할 수 있고 분기도 하드웨어가 처리하지만, SIMD에서는 프로그래머나 컴파일러가 폭이 정해진 벡터 명령을 명시적으로 사용한다

CPU의 SIMD에서는 4개나 8개의 데이터를 묶은 벡터 레지스터에 하나의 명령을 적용하므로, 프로그램은 벡터 폭을 의식하여 작성합니다. GPU의 SIMT에서는 프로그래머가 하나의 스레드 처리를 평범하게 작성하면 하드웨어가 32개씩 묶어 같은 명령으로 실행합니다. 스레드별로 분기해도 되며 하드웨어가 갈라진 경로를 차례로 실행하지만, 이때는 효율이 떨어집니다.

자주 묻는 질문

GPU 컴퓨팅에서 워프란 무엇인가요?

워프는 NVIDIA GPU에서 같은 명령을 보조를 맞춰 함께 실행하는 32개 스레드의 그룹입니다. SIMT 모델에서 명령 발행의 기본 단위이며, AMD에서는 이에 해당하는 것을 웨이브프론트라고 부릅니다.

SIMT와 SIMD의 차이는 무엇인가요?

SIMD는 프로그래머나 컴파일러가 명시적으로 사용해야 하는 고정 폭 벡터 명령을 제공합니다. SIMT는 각 스레드를 독립된 스칼라 코드로 작성하게 하고, 하드웨어가 스레드를 워프로 묶고 분기 다이버전스를 처리합니다.

워프 다이버전스란 무엇인가요?

같은 워프 안의 스레드들이 서로 다른 분기 경로를 탈 때 발생합니다. 하드웨어는 비활성 스레드를 마스크한 채 각 경로를 순차적으로 실행하므로, 경로가 다시 합류할 때까지 효율이 떨어집니다.
