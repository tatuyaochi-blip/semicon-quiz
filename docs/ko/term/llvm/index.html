LLVM란?

공통 중간 표현(LLVM IR)을 중심으로 언어 프런트엔드, 최적화 패스, CPU 백엔드를 조합하는 컴파일러 인프라입니다. 많은 언어와 CPU에서 사용됩니다.

일본어 명칭: LLVM

LLVM은(는) 컴파일러 등 1개 분야의 연습 문제 1개에 나와요.

분야: 컴파일러

  1. AC 언어 전용 컴파일러로, 다른 언어에는 사용할 수 없다
  2. B특정 CPU만을 대상으로 한 어셈블러와 링커의 조합
  3. C공통 중간 표현을 중심으로 전단부와 후단부를 조합한다
정답과 해설 보기

정답: C. 공통 중간 표현을 중심으로 전단부와 후단부를 조합한다

LLVM은 LLVM IR이라는 공통 중간 표현을 중심으로 한 컴파일러 기반입니다. C/C++의 Clang을 비롯해 다양한 언어의 프런트엔드가 소스를 LLVM IR로 변환하고, 공통 최적화 단계를 거친 뒤 x86, Arm, RISC-V, GPU 등 많은 CPU용 백엔드가 기계어를 생성합니다. 새로운 언어나 CPU를 지원할 때도 한쪽만 만들면 된다는 것이 강점입니다. C 언어 전용도, 특정 CPU 전용도 아닙니다.
