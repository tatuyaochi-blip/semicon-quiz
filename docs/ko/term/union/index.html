공용체(union)란?

C 언어에서 여러 멤버가 같은 주소부터 겹쳐서 놓이는 형. union { uint32_t w; uint8_t b[4]; } u;처럼 선언하며, 크기는 가장 큰 멤버의 크기(정렬 단위의 배수로 올림)가 된다. 한 번에 의미 있는 값을 갖는 것은 하나의 멤버뿐이며, 같은 메모리를 다른 형으로 보는 용도나, 여러 형식 중 하나의 데이터를 갖는 경우의 메모리 절약에 사용된다. u.w에 쓰고 u.b[0]을 읽은 결과는 엔디언에 따라 달라진다.
