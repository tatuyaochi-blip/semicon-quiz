심볼 테이블(symbol table)란?

오브젝트 파일이나 실행 파일에 포함된, 함수와 변수의 이름과 번지 등의 목록. 링크와 디버깅에 쓰이며 strip으로 제거할 수 있다.

일본어 명칭: シンボルテーブル

심볼 테이블(symbol table)은(는) 링커, 로더, 실행 파일 등 1개 분야의 연습 문제 3개에 나와요.

분야: 링커, 로더, 실행 파일

도전해 보기: 심볼 테이블(symbol table) 관련 문제

컴파일러가 하나의 소스 파일에서 출력하는 오브젝트 파일(.o)에 대해 올바른 것은 무엇입니까?

  1. A그대로 OS에서 실행할 수 있는 완성된 프로그램이다
  2. B소스 코드를 압축한 것일 뿐이며 기계어는 포함하지 않는다
  3. C기계어를 포함하지만, 다른 파일에 있는 함수나 변수의 주소는 아직 정해지지 않았다
정답과 해설 보기

정답: C. 기계어를 포함하지만, 다른 파일에 있는 함수나 변수의 주소는 아직 정해지지 않았다

오브젝트 파일에는 그 파일의 함수를 번역한 기계어, 변수의 초기값, 정의하거나 참조하는 이름의 목록(심볼 테이블), 나중에 주소를 채울 위치의 목록(재배치 정보)이 들어 있습니다. printf처럼 다른 파일에 있는 함수를 호출하는 명령은 주소를 알 수 없으므로 임시 값인 채로 있습니다. 링커가 여러 오브젝트 파일을 모아 주소를 정하고 실행 파일을 만듭니다.

링커가 수행하는 심볼 해석의 설명으로 올바른 것은 무엇입니까?

  1. A어떤 파일에서 사용되는 함수나 변수의 이름을 다른 파일에 있는 그 정의와 대응시킨다
  2. B소스 코드의 변수 이름을 짧은 이름으로 바꾸어 읽기 어렵게 한다
  3. C수학 기호를 포함한 식을 수치로 다시 계산한다
정답과 해설 보기

정답: A. 어떤 파일에서 사용되는 함수나 변수의 이름을 다른 파일에 있는 그 정의와 대응시킨다

main.c에서 sum 함수를 호출하고 sum.c에서 그 내용을 정의하면, main.o에는 'sum을 참조한다', sum.o에는 'sum을 정의한다'라는 정보가 들어갑니다. 링커는 모든 오브젝트 파일의 심볼 테이블을 모아 참조마다 대응하는 정의를 하나 찾습니다. 정의를 찾지 못하면 '정의되지 않은 참조', 둘 이상이면 '다중 정의' 오류가 됩니다.

해설 속 심볼 테이블(symbol table)

  • 오브젝트 파일에는 그 파일의 함수를 번역한 기계어, 변수의 초기값, 정의하거나 참조하는 이름의 목록(심볼 테이블), 나중에 주소를 채울 위치의 목록(재배치 정보)이 들어 있습니다.

    컴파일러가 하나의 소스 파일에서 출력하는 오브젝트 파일(.o)에 대해 올바른 것은 무엇입니까?

  • 링커는 모든 오브젝트 파일의 심볼 테이블을 모아 참조마다 대응하는 정의를 하나 찾습니다.

    링커가 수행하는 심볼 해석의 설명으로 올바른 것은 무엇입니까?

  • 실행 파일에는 함수나 변수의 이름을 나열한 심볼 테이블이나 소스 코드 행과의 대응을 나타내는 디버그 정보가 포함되어 있는 경우가 있습니다.

    실행 파일에 strip 명령을 사용했을 때 일어나는 일로 올바른 것은 무엇입니까?

심볼 테이블(symbol table)이(가) 나오는 문제 (3)

  1. 컴파일러가 하나의 소스 파일에서 출력하는 오브젝트 파일(.o)에 대해 올바른 것은 무엇입니까?
  2. 링커가 수행하는 심볼 해석의 설명으로 올바른 것은 무엇입니까?
  3. 실행 파일에 strip 명령을 사용했을 때 일어나는 일로 올바른 것은 무엇입니까?
