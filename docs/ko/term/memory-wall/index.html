메모리 월(memory wall)란?

메모리 대역폭과 지연 시간이 프로세서 성능보다 느리게 개선되어 전체 성능이 제한되는 문제입니다. HBM, 대용량 캐시, 첨단 패키징 등으로 대응합니다.

일본어 명칭: メモリウォール

메모리 월(memory wall)은(는) DRAM, 첨단 패키징(3D와 칩렛) 등 2개 분야의 연습 문제 2개에 나와요.

분야: DRAM

도전해 보기: 메모리 월(memory wall) 관련 문제

프로세서의 성능 향상에 비해 메모리의 대역이나 지연의 개선이 따라가지 못해 생기는 성능 제약을 무엇이라 하는가?

  1. A무어의 법칙
  2. B실리콘 사이클
  3. C메모리 월
정답과 해설 보기

정답: C. 메모리 월

프로세서의 연산 성능이 연 50% 이상 늘던 시기가 있었지만 DRAM의 접근 지연은 수십 ns에서 거의 개선되지 않아, CPU가 수백 사이클이나 데이터를 기다리게 되었습니다. 이것이 메모리 월입니다. 대책으로 다단 캐시, 메모리의 병렬 접근, 프리페치, HBM 같은 광대역 메모리, 연산을 메모리 가까이에서 수행하는 프로세싱 인 메모리 등이 추진되고 있습니다.

프로세서의 연산 성능 향상에 비해 메모리에서 데이터를 공급하는 속도가 따라가지 못해 전체 성능을 제한해 버리는 문제를 무엇이라 하는가?

  1. A열의 벽
  2. B메모리 월(메모리의 벽)
  3. C무어의 법칙
정답과 해설 보기

정답: B. 메모리 월(메모리의 벽)

프로세서의 연산 성능은 빠르게 향상되어 왔지만 메모리와의 데이터 전송 속도(대역폭)의 증가는 그보다 완만하여, 연산기가 데이터를 기다리는 시간이 늘고 있습니다. 이를 메모리 월이라 합니다. 대규모 AI 모델은 계산할 때마다 방대한 가중치를 읽어 들이므로 특히 심각하며, HBM을 프로세서 가까이에 실장하는 첨단 패키지나 대용량 캐시의 적층이 대책이 되고 있습니다.
