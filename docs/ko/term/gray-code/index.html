그레이 코드(Gray Code)란?

인접한 값 사이에서 1비트만 변하는 부호. 로터리 인코더나 서로 다른 클록 간의 카운터 값 전달에서 읽기 오류를 방지하는 데 쓰인다.

일본어 명칭: グレイコード

그레이 코드(Gray Code)은(는) 논리 회로, SRAM과 플래시 메모리 등 2개 분야의 연습 문제 3개에 나와요.

분야: 논리 회로

그레이 코드의 특징으로 올바른 것은?

  1. A10진수의 각 자리를 4비트로 나타내는 부호
  2. B패리티 비트로 오류를 검출하는 부호
  3. C이웃한 값 사이에서 1비트만 변화하는 부호
정답과 해설 보기

정답: C. 이웃한 값 사이에서 1비트만 변화하는 부호

그레이 코드는 이웃한 값 사이에서 반드시 1비트만 변화하는 부호로, 2진수 B에서 B XOR (B >> 1)로 구할 수 있습니다. 여러 비트가 동시에 바뀌지 않으므로 로터리 인코더의 위치 검출이나, 서로 다른 클록으로 동작하는 회로 사이에서 FIFO 포인터를 주고받을 때 중간의 잘못된 값을 읽을 위험이 없습니다. 카르노 맵 칸의 배열도 그레이 코드 순입니다. 10진의 각 자리를 4비트로 나타내는 것은 BCD입니다.

해설 속 그레이 코드(Gray Code)

  • 그레이 코드는 이웃한 값 사이에서 반드시 1비트만 변화하는 부호로, 2진수 B에서 B XOR (B >> 1)로 구할 수 있습니다.

    그레이 코드의 특징으로 올바른 것은?

  • 카르노 맵은 진리표를 이웃한 칸의 입력이 1비트만 다르도록(그레이 코드 순) 배열한 도표입니다.

    카르노 맵의 주된 용도는?

  • 오독은 거의 반드시 이웃한 상태와의 사이에서 일어나므로, 이웃한 상태의 비트열이 1비트만 다른 그레이 코드로 할당해 두면 오독해도 오류가 1비트뿐이어서 ECC의 부담을 최소로 할 수 있습니다.
