OSI 참조 모델(OSI Reference Model)란?

통신 기능을 물리 계층·데이터 링크 계층·네트워크 계층·전송 계층·세션 계층·표현 계층·응용 계층의 7개 계층으로 나누어 정리한 모델. 각 계층의 역할을 나누어 생각하기 위한 공통의 언어로 쓰인다.

일본어 명칭: OSI参照モデル

OSI 참조 모델(OSI Reference Model)은(는) 네트워크 기초 등 1개 분야의 연습 문제 2개에 나와요.

분야: 네트워크 기초

7개 계층의 역할

맨 아래의 1계층(물리 계층)은 케이블이나 전파로 비트를 신호로 보내는 일을 다룹니다. 2계층(데이터 링크 계층)은 MAC 주소를 사용하여 같은 네트워크 안의 이웃한 기기에 프레임을 전달합니다. 3계층(네트워크 계층)은 IP 주소를 사용하여 네트워크에 걸친 경로를 선택하고 패킷을 중계합니다. 4계층(전송 계층)은 단말의 애플리케이션 간 통신을 다루며, TCP라면 재전송과 순서 제어를 수행합니다. 5~7계층(세션 계층·표현 계층·응용 계층)은 통신의 시작과 종료 관리, 데이터 표현의 변환, 애플리케이션의 기능을 다룹니다.

TCP/IP 4계층과의 대응

실제 인터넷에서 사용되는 것은 TCP/IP 프로토콜군이며, 그 모델은 링크 계층·인터넷 계층·전송 계층·응용 계층의 4개 계층으로 나타냅니다. 대략적으로 링크 계층이 OSI의 1~2계층, 인터넷 계층이 3계층, 전송 계층이 4계층, 응용 계층이 5~7계층에 대응합니다. OSI 참조 모델의 프로토콜 자체는 널리 퍼지지 않았지만, 'L2 스위치', 'L3 스위치', 'L7 부하 분산'처럼 기기나 기능이 어느 계층에서 동작하는지를 나타내는 말로 지금도 쓰이고 있습니다.

계층으로 나누는 이점

각 계층은 바로 아래 계층이 제공하는 기능만 사용하고, 바로 위 계층에 기능을 제공합니다. 송신 측에서는 각 계층이 헤더를 붙여 데이터를 감싸고(캡슐화), 수신 측에서는 아래 계층부터 차례로 떼어 냅니다. 계층 사이의 약속만 지키면 어떤 계층의 기술을 바꾸어도 다른 계층은 그대로 사용할 수 있습니다. 예를 들어 유선 LAN을 무선 LAN으로 바꾸어도 IP나 TCP, 웹 브라우저는 변경 없이 동작합니다.

  2. B네트워크 계층(3계층)
  3. C전송 계층(4계층)
정답과 해설 보기

정답: B. 네트워크 계층(3계층)

OSI 참조 모델은 통신 기능을 물리 계층부터 응용 계층까지 7개 계층으로 나누어 정리한 모델입니다. 네트워크 계층(3계층)은 IP 주소 같은 논리 주소를 사용하여 여러 네트워크에 걸쳐 목적지까지의 경로를 선택하고 패킷을 중계합니다. 그 아래의 데이터 링크 계층은 같은 네트워크 안에서 MAC 주소를 사용해 이웃한 기기에 프레임을 전달하는 데까지를 담당합니다. 전송 계층은 단말의 애플리케이션 간 통신을 다루며, TCP라면 재전송과 순서 관리를 수행합니다. 기기로 말하면 라우터는 3계층, L2 스위치는 2계층에서 동작합니다.

자주 묻는 질문

OSI 참조 모델의 7개 계층을 아래부터 차례로 말하면?

물리 계층, 데이터 링크 계층, 네트워크 계층, 전송 계층, 세션 계층, 표현 계층, 응용 계층입니다. 라우터는 주로 3계층, L2 스위치는 2계층, 허브는 1계층에서 동작하는 기기입니다.

OSI 참조 모델과 TCP/IP 모델 중 어느 쪽을 외우면 되나요?

둘의 대응을 함께 파악하는 것이 좋습니다. 실제로 사용되는 것은 TCP/IP 프로토콜이지만, 기기나 기능의 위치는 '3계층', 'L7'처럼 OSI 참조 모델의 번호로 나타내는 경우가 많기 때문입니다.
