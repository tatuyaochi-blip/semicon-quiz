재배치(Relocation)란?

코드와 데이터의 최종 주소가 정해진 뒤 명령이나 데이터 안의 임시 주소를 올바른 값으로 고쳐 쓰는 처리. 링커가 수행하며, 동적 링크에서는 일부를 실행 시 동적 링커가 수행한다.

일본어 명칭: 再配置

재배치(Relocation)은(는) 링커, 로더, 실행 파일, DRAM, 클린룸과 장비 등 3개 분야의 연습 문제 10개에 나와요.

분야: 링커, 로더, 실행 파일

도전해 보기: 재배치(Relocation) 관련 문제

링커가 수행하는 재배치(relocation)의 설명으로 올바른 것은 무엇입니까?

  1. A코드와 데이터의 최종 주소가 정해진 뒤, 명령이나 데이터 안의 주소를 올바른 값으로 고쳐 쓴다
  2. B프로그램을 실행하는 도중에 다른 컴퓨터로 옮겨 이어서 실행한다
  3. C메모리가 부족해지면 페이지를 스토리지로 내보낸다
정답과 해설 보기

정답: A. 코드와 데이터의 최종 주소가 정해진 뒤, 명령이나 데이터 안의 주소를 올바른 값으로 고쳐 쓴다

컴파일러는 각 파일을 주소 0부터 시작하는 것으로 간주하여 만들고, 다른 파일의 함수나 자신의 변수 주소를 사용하는 위치를 재배치 정보로 기록합니다. 링커는 모든 파일을 나열하여 실제 주소를 정한 뒤, 기록된 위치마다 올바른 주소(또는 PC로부터의 거리)를 계산하여 명령에 씁니다. 동적 링크에서는 비슷한 고쳐 쓰기의 일부를 실행 시에 동적 링커가 수행합니다.

해설 속 재배치(Relocation)

  • 컴파일러는 각 파일을 주소 0부터 시작하는 것으로 간주하여 만들고, 다른 파일의 함수나 자신의 변수 주소를 사용하는 위치를 재배치 정보로 기록합니다.

    링커가 수행하는 재배치(relocation)의 설명으로 올바른 것은 무엇입니까?

  • 메모리 컨트롤러는 같은 행에 대한 요청을 모으는 등 접근 순서를 재배치하여 이 페이지 히트를 늘립니다.

    DRAM에서 같은 행(페이지)에 연속으로 접근하면 접근 시간이 짧아지는 이유로 올바른 것은?

  • 웨이퍼는 밀폐 용기와 장비의 미니인바이런먼트로 보호되므로 방 전체의 청정도를 그다지 높이지 않아도 되고, 장비 재배치도 쉬워집니다.

    칸막이가 적은 큰 방 안에 제조 장비를 늘어놓고, FOUP 등의 밀폐 용기와 미니인바이런먼트로 웨이퍼의 청…

  • 오브젝트 파일에는 그 파일의 함수를 번역한 기계어, 변수의 초기값, 정의하거나 참조하는 이름의 목록(심볼 테이블), 나중에 주소를 채울 위치의 목록(재배치 정보)이 들어 있습니다.

    컴파일러가 하나의 소스 파일에서 출력하는 오브젝트 파일(.o)에 대해 올바른 것은 무엇입니까?

  • 링커는 각 오브젝트 파일에서 참조되는 이름(심볼)을 어딘가에서 정의된 실체와 대응시키고(심볼 해석), 각 파일의 코드와 데이터를 배열하여 최종 주소를 정하며, 명령 안의 임시 주소를 올바른 값으로 고쳐 씁니다(재배치).

    링커의 주된 역할로 올바른 것은 무엇입니까?

재배치(Relocation)이(가) 나오는 문제 (10)

  1. 링커가 수행하는 재배치(relocation)의 설명으로 올바른 것은 무엇입니까?
  2. DRAM에서 같은 행(페이지)에 연속으로 접근하면 접근 시간이 짧아지는 이유로 올바른 것은?
  3. 칸막이가 적은 큰 방 안에 제조 장비를 늘어놓고, FOUP 등의 밀폐 용기와 미니인바이런먼트로 웨이퍼의 청정도를 확보하는 클린룸 방식은 무엇인가?
  4. 컴파일러가 하나의 소스 파일에서 출력하는 오브젝트 파일(.o)에 대해 올바른 것은 무엇입니까?
  5. 링커의 주된 역할로 올바른 것은 무엇입니까?
  6. C 언어에서 'extern int count;'라고 썼을 때의 의미로 올바른 것은 무엇입니까?
  7. Linux에서 동적 링크 프로그램을 기동할 때 동작하는 동적 링커(ld.so 등)의 역할로 올바른 것은 무엇입니까?
  8. 오브젝트 파일을 역어셈블했더니 외부 함수 printf를 호출하는 명령의 점프 대상이 0 같은 임시 값이었습니다. 이 값은 언제 올바르게 채워집니까?
  9. ELF 파일에서 '섹션'과 '세그먼트'의 차이로 올바른 것은 무엇입니까?
  10. 주요 OS에서 사용되는 실행 파일 형식의 조합으로 올바른 것은 무엇입니까?
