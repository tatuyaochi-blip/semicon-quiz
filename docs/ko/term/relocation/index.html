재배치(relocation)란?

최종 주소가 정해진 뒤 명령어와 데이터에 들어 있던 임시 주소를 올바른 값으로 고쳐 쓰는 작업입니다. 링커가 수행하며, 동적 링크에서는 일부를 동적 링커가 실행 시에 수행합니다.

일본어 명칭: 再配置

재배치(relocation)은(는) 링커, 로더, 실행 파일, 멀티코어와 동기화, 클린룸과 장비 등 3개 분야의 연습 문제 10개에 나와요.

분야: 링커, 로더, 실행 파일

도전해 보기: 재배치(relocation) 관련 문제

링커가 수행하는 재배치(리로케이션)에 대한 설명으로 올바른 것은?

  1. A코드와 데이터의 최종 주소가 정해진 뒤, 명령이나 데이터 안의 주소를 올바른 값으로 고쳐 쓴다
  2. B프로그램을 실행하는 도중에 다른 컴퓨터로 옮겨서 이어서 실행한다
  3. C메모리가 부족해지면 페이지를 스토리지로 내보낸다
정답과 해설 보기

정답: A. 코드와 데이터의 최종 주소가 정해진 뒤, 명령이나 데이터 안의 주소를 올바른 값으로 고쳐 쓴다

컴파일러는 각 파일을 주소 0부터 시작하는 것으로 간주하여 만들고, 다른 파일의 함수나 자신의 변수 주소를 사용하는 위치를 재배치 정보로 기록해 둡니다. 링커는 모든 파일을 나열해 실제 주소를 정한 뒤, 기록된 위치마다 올바른 주소(또는 PC로부터의 거리)를 계산해 명령에 써 넣습니다. 동적 링크에서는 이와 비슷한 고쳐 쓰기의 일부를 실행할 때 동적 링커가 수행합니다.

해설 속 재배치(relocation)

  • 컴파일러는 각 파일을 주소 0부터 시작하는 것으로 간주하여 만들고, 다른 파일의 함수나 자신의 변수 주소를 사용하는 위치를 재배치 정보로 기록해 둡니다.

    링커가 수행하는 재배치(리로케이션)에 대한 설명으로 올바른 것은?

  • 웨이퍼는 밀폐 용기와 장비의 미니인바이런먼트로 보호되므로 방 전체의 청정도를 그다지 높이지 않아도 되고, 장비 재배치도 쉬워집니다.

    칸막이가 적은 큰 방 안에 제조 장비를 늘어놓고, FOUP 등의 밀폐 용기와 미니인바이런먼트로 웨이퍼의 청…

  • 오브젝트 파일에는 해당 파일의 함수를 번역한 기계어, 변수의 초깃값, 정의하거나 참조하는 이름의 목록(심볼 테이블), 나중에 주소를 채워 넣을 위치의 목록(재배치 정보)이 들어 있습니다.

    컴파일러가 하나의 소스 파일에서 출력하는 오브젝트 파일(.o)에 대한 설명으로 올바른 것은?

  • 링커는 각 오브젝트 파일에서 참조하는 이름(심볼)을 어딘가에서 정의된 실체와 대응시키고(심볼 해석), 각 파일의 코드와 데이터를 나열해 최종 주소를 정한 다음, 명령 안의 임시 주소를 올바른 값으로 고쳐 씁니다(재배치).

    링커의 주된 역할로 올바른 것은?

  • 컴파일러는 count의 주소를 모른 채 참조하는 명령을 만들고 그 위치를 재배치 정보에 기록합니다.
