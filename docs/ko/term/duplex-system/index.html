듀플렉스 시스템(Duplex System)란?

처리를 수행하는 주 시스템(운용계)과 고장에 대비하는 대기 시스템의 2세트로 시스템을 구성하고, 주 시스템이 고장 났을 때 대기 시스템으로 전환하여 처리를 계속하는 이중화 방식. 대기 시스템의 준비 정도에 따라 핫 스탠바이, 웜 스탠바이, 콜드 스탠바이로 나뉜다.

일본어 명칭: デュプレックスシステム

듀플렉스 시스템(Duplex System)은(는) 시스템 구성과 신뢰성 설계 등 1개 분야의 연습 문제 2개에 나와요.

분야: 시스템 구성과 신뢰성 설계

듀얼 시스템과의 차이

듀얼 시스템은 2세트로 같은 처리를 동시에 수행하고 결과를 대조합니다. 듀플렉스 시스템에서는 평소에는 주 시스템만 처리를 수행하고, 대기 시스템은 주 시스템의 고장에 대비하여 기다리고 있습니다. 듀얼 시스템은 오류 검출과 전환 속도가 뛰어난 반면, 2세트를 항상 가동하므로 비용이 커집니다. 듀플렉스 시스템은 비용을 억제하기 쉬운 대신, 전환하는 동안에는 처리가 멈추고 전환 직전의 처리를 잃기도 합니다.

핫·웜·콜드 스탠바이

핫 스탠바이는 대기 시스템을 기동해 두고 주 시스템의 데이터를 항상 대기 시스템에도 반영해 두는 방식으로, 짧은 시간에 전환할 수 있습니다. 콜드 스탠바이는 대기 시스템을 멈춰 두거나 다른 작업에 사용해 두고, 고장이 난 후에 기동이나 데이터 복원을 수행하는 방식으로, 전환에 시간이 걸리는 대신 비용을 억제할 수 있습니다. 웜 스탠바이는 그 중간으로, 대기 시스템은 기동되어 있지만 처리를 인계하기 전에 애플리케이션 기동이나 데이터 반영 등의 준비가 필요합니다. 어느 것을 선택할지는 허용되는 정지 시간과 비용으로 정합니다.

전환 구조와 주의점

주 시스템의 고장은 주 시스템과 대기 시스템 사이에서 정기적으로 신호를 주고받는 하트비트 등으로 검출하며, 자동으로 대기 시스템으로 처리를 옮깁니다(페일오버). 통신 장애로 서로 상대가 멈췄다고 판단하여 양쪽이 모두 주 시스템으로 동작해 버리는 상태(스플릿 브레인)를 막기 위해, 제3의 감시 구조를 마련하기도 합니다. 또한 대기 시스템이 올바르게 인계할 수 있는지는 정기적으로 전환 시험을 하여 확인해 두어야 합니다.

반도체 공장의 제조 실행 시스템(MES) 서버를 주 시스템(운용계)과 대기 시스템으로 이루어진 듀플렉스 시스템으로 구성한다. 대기 시스템을 핫 스탠바이로 했을 때의 특징으로 적절한 것은?

  1. A대기 시스템을 기동한 상태로 대기시키고 주 시스템의 데이터를 항상 대기 시스템에도 반영해 두므로, 주 시스템이 고장 났을 때 짧은 시간에 전환할 수 있다
  2. B대기 시스템의 전원을 꺼 두고 주 시스템이 고장 난 후에 기동하여 데이터를 복원하므로, 전환에 시간이 걸리는 대신 대기 중의 전력이나 비용을 줄일 수 있다
  3. C주 시스템과 대기 시스템에서 같은 처리를 동시에 수행하고, 결과를 대조하면서 운전한다
정답과 해설 보기

정답: A. 대기 시스템을 기동한 상태로 대기시키고 주 시스템의 데이터를 항상 대기 시스템에도 반영해 두므로, 주 시스템이 고장 났을 때 짧은 시간에 전환할 수 있다

핫 스탠바이는 대기 시스템을 기동한 상태로 두고 주 시스템의 데이터를 항상 대기 시스템에도 반영해 두는 방식으로, 주 시스템이 고장 났을 때 짧은 시간에 처리를 인계할 수 있습니다. MES가 멈추면 로트 진행 지시, 장비에 대한 레시피 지정, 제조 이력 기록을 할 수 없게 되므로, 일반적으로 짧은 시간에 전환할 수 있는 구성이 선택됩니다. 대기 시스템을 멈춰 두고 고장 난 후에 기동하는 방식은 콜드 스탠바이이며, 둘의 중간(기동은 되어 있지만 처리 인계에 준비가 필요한 것)을 웜 스탠바이라고 부릅니다. 2세트로 같은 처리를 동시에 수행하여 대조하는 것은 듀얼 시스템입니다.

자주 묻는 질문

듀플렉스 시스템의 대기 시스템은 아무것도 하지 않나요?

콜드 스탠바이의 경우에는 대기 시스템을 멈춰 두거나, 급하지 않은 일괄 처리 등 다른 작업에 사용하기도 합니다. 주 시스템이 고장 나면 그 작업을 멈추고 주 시스템의 처리를 인계합니다. 핫 스탠바이에서는 대기 시스템이 주 시스템의 데이터를 계속 받으면서, 즉시 인계할 수 있는 상태로 기다리고 있습니다.

듀플렉스 시스템의 가동률은 어떻게 계산하나요?

주 시스템과 대기 시스템 중 어느 한쪽이 동작하면 처리를 계속할 수 있다고 보면, 병렬의 식 1 − (1 − a)²로 대략 계산할 수 있습니다. 다만 실제로는 전환 장치, 전환에 걸리는 시간, 양쪽에 공통되는 고장 원인(전원이나 설치 장소 등)이 있으므로, 이 식의 값만큼 높아지지는 않습니다.

해설 속 듀플렉스 시스템(Duplex System)

  • 주 시스템과 대기 시스템으로 나누어 고장 시에 전환하는 방식은 듀플렉스 시스템입니다.
