파이프(|)란?

셸에서 '명령1 | 명령2'처럼 써서, 왼쪽 명령의 표준 출력을 오른쪽 명령의 표준 입력에 직접 연결하는 구조. sort ips.txt | uniq -c | sort -nr처럼 작은 명령을 여러 개 연결하여(파이프라인), 중간 파일을 만들지 않고 복잡한 처리를 조립할 수 있다. 양쪽 명령은 동시에 동작하며, 데이터는 순서대로 흘러간다. 표준 오류 출력은 연결되지 않으므로, 오류도 넘기려면 2>&1을 조합한다.
