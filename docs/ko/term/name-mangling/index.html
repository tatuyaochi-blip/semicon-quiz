네임 맹글링(Name Mangling)란?

C++ 컴파일러가 함수 이름에 인수 타입이나 네임스페이스 정보를 삽입하여 심볼 이름을 만드는 것. 오버로드된 함수를 링커가 구별할 수 있다.

일본어 명칭: 名前修飾

네임 맹글링(Name Mangling)은(는) 링커, 로더, 실행 파일 등 1개 분야의 연습 문제 1개에 나와요.

분야: 링커, 로더, 실행 파일

도전해 보기: 네임 맹글링(Name Mangling) 관련 문제

C++ 컴파일러가 함수 이름에 인수 타입 등의 정보를 덧붙여 심볼 이름을 만드는 '네임 맹글링(name mangling)'의 주된 목적은 무엇입니까?

  1. A함수 이름을 읽을 수 없게 하여 프로그램을 도난당하지 않도록 하기 위해
  2. B함수 이름을 짧게 하여 실행 파일을 작게 하기 위해
  3. C같은 이름이면서 인수 타입이 다른 함수(오버로드)나 네임스페이스를 링커가 구별할 수 있게 하기 위해
정답과 해설 보기

정답: C. 같은 이름이면서 인수 타입이 다른 함수(오버로드)나 네임스페이스를 링커가 구별할 수 있게 하기 위해

링커는 심볼을 이름 문자열만으로 대조합니다. C++에서는 'print(int)'와 'print(double)'처럼 같은 이름의 함수를 만들 수 있으므로 그대로는 구별할 수 없습니다. 그래서 컴파일러는 '_Z5printi'처럼 인수 타입 등을 이름에 넣습니다. C 언어 함수는 맹글링되지 않으므로, C++에서 C 함수를 호출할 때는 'extern "C"'를 붙여 맹글링을 하지 않게 합니다.
