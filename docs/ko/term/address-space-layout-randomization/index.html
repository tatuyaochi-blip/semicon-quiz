주소 공간 배치 무작위화(ASLR)란?

스택, 힙, 공유 라이브러리, 실행 파일의 주소를 실행할 때마다 바꾸어 공격자가 쉽게 예측하지 못하게 하는 대책입니다.

일본어 명칭: ASLR

주소 공간 배치 무작위화(ASLR)은(는) 링커, 로더, 실행 파일 등 1개 분야의 연습 문제 3개에 나와요.

분야: 링커, 로더, 실행 파일

도전해 보기: 주소 공간 배치 무작위화(ASLR) 관련 문제

ASLR(주소 공간 배치 무작위화)의 목적으로 올바른 것은?

  1. A스택, 힙, 라이브러리 등의 주소를 실행할 때마다 바꿔서 공격자가 노리는 주소를 예측하기 어렵게 한다
  2. B메모리 주소를 무작위로 골라 캐시 적중률을 높인다
  3. C사용하지 않는 메모리를 무작위로 해제하여 빈 용량을 늘린다
정답과 해설 보기

정답: A. 스택, 힙, 라이브러리 등의 주소를 실행할 때마다 바꿔서 공격자가 노리는 주소를 예측하기 어렵게 한다

버퍼 오버플로 등을 악용하는 공격에서는 라이브러리 함수나 스택 상 데이터의 주소를 알고 있는 것이 중요합니다. ASLR은 프로세스를 시작할 때마다 스택, 힙, 공유 라이브러리, 실행 파일을 놓는 주소를 옮겨서 공격자가 주소를 단정해서 쓰지 못하게 합니다. 단독으로 완벽하게 막을 수 있는 것은 아니며, 쓰기와 실행의 분리 등 다른 대책과 조합해서 사용합니다.

해설 속 주소 공간 배치 무작위화(ASLR)

  • ASLR은 프로세스를 시작할 때마다 스택, 힙, 공유 라이브러리, 실행 파일을 놓는 주소를 옮겨서 공격자가 주소를 단정해서 쓰지 못하게 합니다.

    ASLR(주소 공간 배치 무작위화)의 목적으로 올바른 것은?

  • 실제 주소는 안전을 위해 ASLR에 의해 실행할 때마다 달라집니다.

    Linux 등의 일반적인 프로세스의 메모리 배치를 주소가 작은 쪽부터 나열한 것으로 올바른 것은?

  • 예전의 실행 파일은 정해진 주소에 읽어 들여진다는 전제로 만들어졌기 때문에, ASLR을 써도 라이브러리나 스택만 옮길 수 있었고 본체 코드의 주소는 공격자에게 알려져 있었습니다.

    실행 파일을 PIE(위치 독립 실행 파일)로 만드는 주된 이유는?

주소 공간 배치 무작위화(ASLR)이(가) 나오는 문제 (3)

  1. ASLR(주소 공간 배치 무작위화)의 목적으로 올바른 것은?
  2. Linux 등의 일반적인 프로세스의 메모리 배치를 주소가 작은 쪽부터 나열한 것으로 올바른 것은?
  3. 실행 파일을 PIE(위치 독립 실행 파일)로 만드는 주된 이유는?
