DDR SDRAM란?

클록의 상승 에지와 하강 에지 모두에서 데이터를 전송하는 동기식 DRAM. DDR4, DDR5로 세대를 거듭하며 전송 속도를 높여 왔다. PC와 서버 주기억장치의 표준.

일본어 명칭: DDR SDRAM

DDR SDRAM은(는) DRAM 등 1개 분야의 연습 문제 2개에 나와요.

분야: DRAM

더블 데이터 레이트와 계산 방법

동기식 DRAM(SDRAM)은 클록 에지에서 커맨드를 받으므로 커맨드 파이프라이닝과 버스트 전송이 가능합니다. DDR SDRAM은 여기에 더해 상승 에지와 하강 에지 모두에서 데이터를 전송하므로, 속도를 초당 메가트랜스퍼(MT/s)로 표기합니다. DDR4-3200은 1600 MHz 클록으로 3200 MT/s를 만듭니다. 피크 대역폭은 데이터 레이트 × 버스 폭이므로, 3200 MT/s의 64비트(8바이트) 채널은 25.6 GB/s를 제공합니다. 실제 지속 대역폭은 로우 전환, 리프레시, 버스 턴어라운드 때문에 이보다 낮습니다.

느린 어레이가 속도를 따라가는 방법

메모리 어레이 자체는 인터페이스보다 훨씬 느리게 동작합니다. DDR은 이 차이를 프리페치로 메웁니다. 각 내부 액세스가 여러 워드를 병렬로 가져온 뒤 핀으로 직렬화하여 내보냅니다. 프리페치는 DDR의 2n에서 DDR2의 4n, DDR3와 DDR4의 8n으로 늘어났으며, DDR5는 버스트 길이 16을 사용합니다. 데이터는 데이터 라인과 나란히 이동하는 데이터 스트로브(DQS)로 캡처되므로, 타이밍 기준과 데이터가 비슷한 지연을 겪는 소스 동기 방식입니다.

세대와 전압

세대마다 데이터 레이트를 높이고 전력을 아끼기 위해 전원 전압을 낮췄습니다. DDR은 약 2.5 V, DDR2는 1.8 V, DDR3는 1.5 V, DDR4는 1.2 V, DDR5는 1.1 V이며, DDR5 부품은 6400 MT/s를 넘습니다. DDR5는 또한 각 모듈을 독립적인 32비트 서브채널 2개로 나누고, 전원 관리 IC로 전압 레귤레이션을 모듈 위로 옮기며, 칩 내부에 온다이 오류 정정을 추가했습니다. 세대 간에는 호환되지 않습니다. 모듈마다 키 위치, 신호 방식, 전압이 다릅니다.

DDR과 LPDDR, GDDR, HBM

표준 DDR은 PC와 서버의 탈착식 모듈에서 용량과 비용에 최적화되어 있습니다. LPDDR은 저전력 상태를 갖추고 휴대폰과 노트북을 대상으로 하며, 보통 프로세서 옆에 납땜됩니다. GDDR은 그래픽 카드용으로, 포인트 투 포인트 링크에서 매우 높은 핀당 데이터 레이트를 제공하며 용량을 대역폭과 맞바꿉니다. 고대역폭 메모리(HBM)는 TSV(실리콘 관통 비아)로 DRAM 다이를 적층하고 인터포저 위의 매우 넓은 인터페이스로 연결합니다. 모두 같은 DRAM 셀과 로우-컬럼 액세스 원리를 공유합니다.

  2. B두 개의 DRAM 칩을 적층한다
  3. C두 배의 전원 전압으로 동작한다
정답과 해설 보기

정답: A. 클록의 상승 에지와 하강 에지 모두에서 데이터를 전송한다

DDR은 클록의 상승 에지와 하강 에지 모두에서 데이터를 전송하여 같은 클록 주파수로 두 배의 전송 속도를 얻는 방식입니다. 그래서 전송 속도는 MHz가 아니라 MT/s(초당 전송 횟수)로 나타내며, DDR4-3200은 클록 1600 MHz에서 3200 MT/s입니다. 세대마다 속도는 올라가고 전원 전압은 내려가 DDR4는 1.2 V, DDR5는 1.1 V이며, DDR5에는 6400 MT/s 이상의 제품도 있습니다.

자주 묻는 질문

클록이 1600 MHz인데 DDR4-3200이라고 부르는 이유는?

데이터가 클록의 양쪽 에지에서 전송되므로 1600 MHz가 초당 32억 번의 전송을 만들기 때문입니다. 이름의 숫자는 클록 주파수가 아니라 MT/s 단위의 데이터 레이트입니다.

DDR 메모리 대역폭은 어떻게 계산하나요?

MT/s 단위의 데이터 레이트에 바이트 단위의 버스 폭과 채널 수를 곱합니다. DDR4-3200의 64비트 채널 하나는 3200 × 8 = 25,600 MB/s, 즉 피크 25.6 GB/s입니다.

DDR5 메모리를 DDR4 슬롯에 쓸 수 있나요?

쓸 수 없습니다. 모듈의 키 노치 위치, 핀 배치, 전원 구성이 다르므로 서로의 슬롯에 맞지도 않고 동작하지도 않습니다.
