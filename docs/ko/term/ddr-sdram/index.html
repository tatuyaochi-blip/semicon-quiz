DDR SDRAM란?

클록의 상승 에지와 하강 에지 양쪽에서 데이터를 전송하는 동기식 DRAM입니다. DDR4, DDR5처럼 세대를 거치며 데이터 전송 속도가 높아졌습니다. PC와 서버의 표준 주 메모리입니다.

일본어 명칭: DDR SDRAM

DDR SDRAM은(는) DRAM 등 1개 분야의 연습 문제 2개에 나와요.

  2. B2개의 DRAM 칩을 적층하고 있다
  3. C2배의 전원 전압으로 동작한다
정답과 해설 보기

정답: A. 클록의 상승 에지와 하강 에지 양쪽에서 데이터를 전송한다

DDR은 클록의 상승 에지와 하강 에지 양쪽에서 데이터를 전송하여, 같은 클록 주파수로 2배의 전송 속도를 얻는 방식입니다. 그래서 전송 속도는 MHz가 아니라 MT/s(초당 전송 횟수)로 나타내며, DDR4-3200은 클록 1600 MHz에서 3200 MT/s입니다. 세대가 바뀔 때마다 속도는 올라가고 전원 전압은 내려왔으며, DDR4는 1.2 V, DDR5는 1.1 V이고 DDR5에는 6400 MT/s 이상의 제품도 있습니다.

해설 속 DDR SDRAM

  • 1990년대 후반에 PC의 주류가 되었고, 양쪽 에지에서 전송하는 DDR SDRAM으로 발전하여 현재에 이릅니다.
