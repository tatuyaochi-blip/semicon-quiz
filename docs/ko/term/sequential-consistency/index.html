순차 일관성(sequential consistency)란?

모든 코어의 동작이 하나의 순서로 나열되고 각 코어의 동작은 프로그램 순서대로 보인다는, 가장 직관적인 메모리 일관성 모델.

일본어 명칭: 逐次一貫性

순차 일관성(sequential consistency)은(는) 멀티코어와 동기화 등 1개 분야의 연습 문제 3개에 나와요.

  3. C모든 연산이 하나의 코어에서만 실행된다
정답과 해설 보기

정답: B. 모든 코어의 연산이 하나의 순서로 나열되고, 각 코어의 연산은 프로그램에 쓴 순서대로 나타나는 것처럼 보인다

순차 일관성에서는 여러 코어의 연산이 카드를 섞듯이 한 줄로 나열되고, 각 코어의 연산은 그 안에서 프로그램 순서를 유지하는 것처럼 보입니다. 프로그래머에게 가장 이해하기 쉬운 모델이지만, 하드웨어가 스토어 버퍼 등으로 순서를 바꾸는 최적화를 크게 제한하므로, 실제 많은 CPU는 더 느슨한 모델을 채택하고 있습니다.
