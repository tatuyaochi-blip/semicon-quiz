논리 합성(logic synthesis)란?

RTL로 기술한 회로를 셀 라이브러리의 게이트로 이루어진 넷리스트로 변환하는 설계 단계입니다.

일본어 명칭: 論理合成

논리 합성(logic synthesis)은(는) IC 설계 흐름과 EDA, HDL과 검증, 논리 회로 등 3개 분야의 연습 문제 23개에 나와요.

분야: IC 설계 흐름과 EDA

도전해 보기: 논리 합성(logic synthesis) 관련 문제

논리 합성에 대한 설명으로 올바른 것은?

  1. A칩 위에 셀을 배치하고 배선을 연결하는 공정
  2. BRTL 기술을 셀 라이브러리의 게이트로 구성한 넷리스트로 변환하는 공정
  3. C웨이퍼 위에 회로 패턴을 전사하는 공정
정답과 해설 보기

정답: B. RTL 기술을 셀 라이브러리의 게이트로 구성한 넷리스트로 변환하는 공정

논리 합성은 RTL로 작성된 회로의 동작 기술을 셀 라이브러리에 있는 논리 게이트와 플립플롭의 연결 정보(넷리스트)로 변환하는 공정입니다. 타이밍·면적·소비 전력 제약을 주면 툴이 논리식을 단순화하고 적절한 구동력의 셀을 골라 제약을 만족하도록 최적화합니다. 셀을 늘어놓고 배선하는 것은 배치 배선, 웨이퍼에 전사하는 것은 리소그래피입니다.

논리 합성 전후로 회로의 논리가 바뀌지 않았음을 시뮬레이션 없이 수학적으로 확인하는 기법은?

  1. A형식적 등가성 검증(포멀 검증)
  2. BDRC
  3. C다이싱
정답과 해설 보기

정답: A. 형식적 등가성 검증(포멀 검증)

형식적 등가성 검증은 두 회로가 같은 논리 함수를 구현하는지를 수학적 기법으로 빠짐없이 확인하는 검증입니다. 테스트 패턴을 준비할 필요가 없고 모든 입력 조합에 대해 등가성을 보증할 수 있으므로, 논리 합성, 배치 배선, ECO 전후의 확인에 사용됩니다. 시뮬레이션으로 모든 조합을 시험하는 것은 입력이 수십 비트만 되어도 현실적으로 불가능합니다. DRC는 도형 규칙의 검사입니다.

해설 속 논리 합성(logic synthesis)

  • 논리 합성은 RTL로 작성된 회로의 동작 기술을 셀 라이브러리에 있는 논리 게이트와 플립플롭의 연결 정보(넷리스트)로 변환하는 공정입니다.

    논리 합성에 대한 설명으로 올바른 것은?

  • 테스트 패턴을 준비할 필요가 없고 모든 입력 조합에 대해 등가성을 보증할 수 있으므로, 논리 합성, 배치 배선, ECO 전후의 확인에 사용됩니다.

    논리 합성 전후로 회로의 논리가 바뀌지 않았음을 시뮬레이션 없이 수학적으로 확인하는 기법은?

  • "always @(posedge clk)"는 클록이 상승하는 순간에만 안의 대입을 수행한다는 의미이며, 논리 합성은 이를 에지에서 동작하는 플립플롭으로 만듭니다.

    위 Verilog 기술이 논리 합성으로 만드는 회로로 올바른 것은?

  • 조합 회로에는 기억 기능이 없으므로 논리 합성은 값을 유지하기 위한 래치를 만듭니다.

    조합 회로를 의도하여 위와 같이 작성하면 논리 합성으로 무엇이 만들어지는가?

  • "#10"은 시뮬레이션 안에서 시간을 10단위 진행시킨다는 뜻이지만, 논리 합성은 지연을 만들 수 없으므로 무시합니다.

    다음 Verilog 기술 중 논리 합성에서 회로가 되지 않고 무시되는 것(시뮬레이션용 기술)은?
