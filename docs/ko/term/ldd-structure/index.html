LDD構造란?

えるでぃーでぃーこうぞう

Lightly Doped Drain の略。ドレインのゲート側の端だけ不純物濃度を低くして電界を緩和し、ホットキャリアによる劣化を抑える構造。

일본어 명칭: LDD構造

분야: MOSFET

관련 용어

貫通電流 基板バイアス効果 短チャネル効果 反転層 相互コンダクタンス 速度飽和 CMOS DIBL GIDL(ゲート誘起ドレインリーク) サブスレッショルドスイング
