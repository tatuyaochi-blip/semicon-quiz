NAND 플래시 메모리란?

메모리 셀을 직렬로 연결한 비휘발성 메모리입니다. 집적도가 높고 대용량화가 쉬워 SSD와 메모리 카드에 사용됩니다.

  1. A약 100회
  2. B약 10만 회
  3. C약 1억 회
정답과 해설 보기

정답: B. 약 10만 회

SLC의 재기록 횟수 기준은 약 5만~10만 회이며, MLC는 수천~1만 회, TLC는 수천 회, QLC는 약 1000회로 비트 수가 늘어날수록 적어집니다. 한계의 주된 원인은 재기록할 때마다 터널 산화막이 조금씩 열화되는 것입니다. SSD의 수명은 TBW(총 쓰기량)나 DWPD(하루에 전체 용량을 몇 번 쓸 수 있는가)로 나타내며, 웨어 레벨링이나 여분 영역으로 늘리고 있습니다.

이 용어가 포함된 비교

  • NAND 플래시와 NOR 플래시의 차이와 용도NAND와 NOR 플래시 메모리를 표로 비교합니다. 셀 연결 방식, 읽기·쓰기 속도, 소거 단위, 집적도, 비용, 신뢰성, 대표 용도를 다룹니다.
  • SLC, MLC, TLC, QLC 낸드의 차이점SLC, MLC, TLC, QLC 낸드 플래시를 표로 비교합니다. 셀당 비트 수, 내구성, 속도, 비용, 오류율, 각 유형을 쓰는 SSD를 다룹니다.
  • SSD vs HDD: 속도, 내구성, 비용의 차이SSD와 HDD를 표로 비교합니다: 데이터 저장 방식, 속도, 지연 시간, 내구성, 소음, 전력, 테라바이트당 비용, 용량, 수명, 적합한 용도.
