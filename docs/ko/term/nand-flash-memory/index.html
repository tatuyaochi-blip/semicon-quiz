NAND 플래시 메모리란?

메모리 셀을 직렬로 연결한 구조의 비휘발성 메모리. 집적도가 높아 대용량화가 쉬우며 SSD와 메모리 카드에 쓰인다.

일본어 명칭: NAND型フラッシュメモリ

NAND 플래시 메모리은(는) SRAM과 플래시 메모리 등 1개 분야의 연습 문제 1개에 나와요.

분야: SRAM과 플래시 메모리

직렬로 연결된 셀

NAND 플래시 셀은 컨트롤 게이트 아래에 플로팅 게이트 또는 전하 트랩막인 전하 저장층을 가진 트랜지스터입니다. 수십 개의 셀이 두 선택 트랜지스터 사이에 스트링으로 직렬 연결되므로 콘택트는 스트링 양 끝에만 필요하며, 그 덕분에 비트당 면적이 매우 작습니다. 셀을 읽을 때는 해당 워드라인에 읽기 전압을 인가하고, 스트링의 나머지 워드라인에는 셀을 완전히 켜는 더 높은 패스 전압을 인가합니다. 스트링이 도통하는지에 따라 선택된 셀의 문턱 전압을 알 수 있습니다.

프로그램과 소거

프로그램 시에는 컨트롤 게이트에 약 20 V를 인가해 전자가 채널에서 얇은 터널 산화막을 통과해 저장층으로 Fowler-Nordheim(FN) 터널링하도록 하며, 이로써 문턱 전압이 올라갑니다. 증분 스텝 펄스 프로그래밍(ISPP)은 펄스 전압을 수백 밀리볼트씩 올리고 펄스마다 검증하여 분포를 좁게 만듭니다. 소거 시에는 셀 웰을 고전압으로 올려 블록 내 모든 셀에서 전자를 빼냅니다. 소거된 저문턱 상태는 1로 읽히므로, 소거된 플래시는 0xFF로 읽힙니다.

페이지, 블록, FTL

NAND는 워드라인 하나에 해당하는 셀들인 약 16 KB의 페이지 단위로 읽고 프로그램하지만, 소거는 수백 페이지로 이루어진 수 MB에서 수십 MB의 블록 단위로만 가능합니다. 프로그램은 비트를 1에서 0으로만 바꿀 수 있으므로 데이터를 제자리에 덮어쓸 수 없습니다. 컨트롤러의 플래시 변환 계층(FTL)은 새 데이터를 빈 페이지에 쓰고 논리 주소를 다시 매핑한 뒤 이전 페이지를 무효로 표시하며, 이후 가비지 컬렉션이 블록에서 유효한 페이지를 복사해 내고 블록을 소거합니다. 웨어 레벨링은 소거를 여러 블록에 분산시키고, 강력한 오류 정정 부호가 비트 오류를 처리합니다.

셀당 비트 수와 내구성

셀당 N비트를 저장하려면 거의 같은 전압 범위 안에 2^N개의 문턱 전압 레벨이 필요합니다. SLC는 2개, MLC는 4개, TLC는 8개, QLC는 16개입니다. 비트가 하나 늘 때마다 기가바이트당 비용은 낮아지지만 레벨 간 간격이 좁아져 프로그램이 느려지고 내구성이 떨어집니다. 프로그램/소거 사이클마다 터널 산화막이 조금씩 열화되기 때문입니다. 대표적인 수치는 SLC가 약 50,000–100,000 사이클, TLC가 수천 사이클, QLC가 약 1,000 사이클입니다. 최신 3D NAND는 100층 이상의 워드라인 층을 수직으로 쌓으며, 대부분 수직 채널 홀 주위에 형성한 전하 트랩 셀을 사용합니다.

SLC의 재기록 횟수 기준은 약 5만~10만 회이며, MLC는 수천~1만 회, TLC는 수천 회, QLC는 약 1000회로 비트 수가 늘어날수록 적어집니다. 한계의 주된 원인은 재기록할 때마다 터널 산화막이 조금씩 열화되는 것입니다. SSD의 수명은 TBW(총 쓰기량)나 DWPD(하루에 전체 용량을 몇 번 쓸 수 있는가)로 표현되며, 웨어 레벨링이나 여분 영역으로 연장합니다.

자주 묻는 질문

NAND 플래시와 NOR 플래시의 차이는 무엇인가요?

NAND는 셀을 직렬로 연결해 셀이 가장 작고 용량이 가장 크지만 페이지 단위로 접근하므로, SSD와 메모리 카드에 쓰입니다. NOR는 각 셀을 비트라인에 병렬로 연결해 랜덤 읽기가 빠르므로 코드 저장과 실행에 적합하지만, 집적도는 낮습니다.

NAND 플래시는 왜 데이터를 덮어쓸 수 없나요?

프로그램은 전하를 더해 문턱 전압을 올리는 것만 가능하고, 전하를 빼려면 블록 전체를 소거해야 합니다. 그래서 컨트롤러는 갱신된 데이터를 새 페이지에 쓰고, 이전 블록은 나중에 가비지 컬렉션으로 회수합니다.

SLC, MLC, TLC, QLC는 무엇을 뜻하나요?

셀당 1, 2, 3, 4비트를 저장한다는 뜻이며, 각각 2, 4, 8, 16개의 구별 가능한 문턱 전압 레벨이 필요합니다. 셀당 비트 수가 많을수록 용량 단가는 낮아지지만 쓰기가 느려지고 내구성이 떨어집니다.
