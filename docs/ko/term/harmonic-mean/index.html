조화 평균(Harmonic Mean)란?

값의 역수의 평균의 역수. 같은 양의 일에 대한 속도(비율)를 평균할 때 사용한다.

일본어 명칭: 調和平均

조화 평균(Harmonic Mean)은(는) 성능 분석 등 1개 분야의 연습 문제 1개에 나와요.

분야: 성능 분석

도전해 보기: 조화 평균(Harmonic Mean) 관련 문제

같은 수의 명령어를 가진 두 프로그램을 하나는 초당 1000 MIPS, 다른 하나는 500 MIPS의 속도로 연속해서 실행했다. 전체 평균 속도는 얼마입니까?

  1. A750 MIPS
  2. B약 707 MIPS
  3. C약 667 MIPS
정답과 해설 보기

정답: C. 약 667 MIPS

각각 명령어가 I개라면 시간은 I÷1000과 I÷500이며 합계는 3I÷1000입니다. 전체 2I개의 명령어를 이 시간에 실행했으므로 평균 속도는 2I÷(3I÷1000)≒667입니다. 느린 쪽 프로그램에 오랜 시간이 걸리므로 평균은 느린 쪽으로 끌려갑니다. 이처럼 같은 양의 일에 대한 속도(비율)를 평균할 때는 산술 평균이 아닌 조화 평균을 사용합니다.

해설 속 조화 평균(Harmonic Mean)
