기본 게이트웨이(Default Gateway)란?

단말이 자신과 다른 네트워크에 있는 목적지로 가는 패킷을 넘기는 라우터. 단말은 서브넷 마스크로 목적지가 같은 네트워크인지 판단하고, 밖이라면 이 라우터로 보낸다.

일본어 명칭: デフォルトゲートウェイ

기본 게이트웨이(Default Gateway)은(는) 네트워크 설계와 운용, 네트워크 기초 등 2개 분야의 연습 문제 9개에 나와요.

분야: 네트워크 기초

도전해 보기: 기본 게이트웨이(Default Gateway) 관련 문제

단말(192.168.1.10/24, 기본 게이트웨이 192.168.1.1)이 다른 네트워크에 있는 서버 203.0.113.80으로 패킷을 보낸다. ARP 캐시가 비어 있을 때, 단말이 ARP로 MAC 주소를 알아내는 상대는?

  1. A기본 게이트웨이 192.168.1.1
  2. B서버 203.0.113.80
  3. C서버까지의 경로상에 있는 모든 라우터
정답과 해설 보기

정답: A. 기본 게이트웨이 192.168.1.1

단말은 먼저 자신의 IP 주소와 서브넷 마스크로 목적지가 같은 네트워크에 있는지를 판단합니다. 203.0.113.80은 192.168.1.0/24 밖이므로 패킷은 기본 게이트웨이(라우터)에 넘깁니다. 이때 IP 헤더의 목적지는 서버의 203.0.113.80 그대로이고, 프레임의 목적지 MAC 주소만 게이트웨이의 것으로 합니다. 그래서 ARP로 알아내는 것은 192.168.1.1의 MAC 주소입니다. ARP 브로드캐스트는 라우터를 넘지 않으므로 다른 네트워크에 있는 서버의 MAC 주소는 알아낼 수 없고, 알 필요도 없습니다. 경로상의 각 라우터가 다음 기기로 보낼 때마다 각자 상대의 MAC 주소를 알아냅니다.

라우터 R1(192.168.1.2)과 R2(192.168.1.3) 2대로 VRRP를 구성하고, 가상 IP 주소를 192.168.1.254로 했다. 평소에는 R1이 마스터로서 전달하고 있다. LAN 단말의 기본 게이트웨이로 설정할 주소로 적절한 것은?

  1. A192.168.1.2(R1의 주소)
  2. B192.168.1.3(R2의 주소)
  3. C192.168.1.254(가상 IP 주소)
정답과 해설 보기

정답: C. 192.168.1.254(가상 IP 주소)

VRRP는 여러 라우터로 하나의 가상 라우터를 만들어 가상 IP 주소와 가상 MAC 주소를 공유하게 하는 프로토콜입니다. 평소에는 마스터 라우터가 가상 주소 앞으로 온 패킷을 전달하고, 마스터가 멈추면 백업 라우터가 마스터가 되어 전달을 이어받습니다. 단말은 가상 IP 주소를 기본 게이트웨이로 해 두면 어느 라우터가 동작하든 설정을 바꿀 필요가 없습니다. 이처럼 기본 게이트웨이를 이중화하는 구조를 FHRP라고 총칭하며, VRRP 외에 HSRP 등이 있습니다.

기본 게이트웨이(Default Gateway)이(가) 나오는 문제 (9)

  1. 단말(192.168.1.10/24, 기본 게이트웨이 192.168.1.1)이 다른 네트워크에 있는 서버 203.0.113.80으로 패킷을 보낸다. ARP 캐시가 비어 있을 때, 단말이 ARP로 MAC 주소를 알아내는 상대는?
  2. 라우터 R1(192.168.1.2)과 R2(192.168.1.3) 2대로 VRRP를 구성하고, 가상 IP 주소를 192.168.1.254로 했다. 평소에는 R1이 마스터로서 전달하고 있다. LAN 단말의 기본 게이트웨이로 설정할 주소로 적절한 것은?
  3. VLAN 20(192.168.20.0/24)의 단말에 다른 네트워크에 있는 DHCP 서버 10.0.0.5로부터 주소를 할당한다. 이를 위해 VLAN 20의 기본 게이트웨이인 L3 스위치의 인터페이스(192.168.20.1)에 DHCP 릴레이 에이전트를 설정했다. 릴레이 에이전트의 동작으로 올바른 것은?
  4. DHCP로 단말이 IP 주소를 얻을 때의 메시지 순서로 올바른 것은?
  5. VLAN 10(192.168.10.0/24)과 VLAN 20(192.168.20.0/24)을 가진 L2 스위치에 라우터를 링크 하나로 연결하여, 두 VLAN 사이에서 통신할 수 있게 하고 싶다. 이 구성의 설정으로 적절한 것은?
  6. NAPT를 하는 라우터(외부 주소는 198.51.100.7)에 '외부 TCP 8080번 포트에 도착한 통신을 내부 웹 서버 192.168.1.20의 80번 포트로 전달한다'는 포트 포워딩(목적지만 변환하는 정적 설정)을 했다. 인터넷상의 단말 203.0.113.9가 출발지 포트 51000으로 198.51.100.7의 8080번 포트에 접속했을 때, 웹 서버가 받는 패킷의 목적지와 출발지 조합은?
  7. IPv6에서 같은 링크 안에서만 쓰이며, IPv6를 쓰는 인터페이스에는 반드시 자동으로 설정되는 링크 로컬 주소의 범위는?
  8. IPv6의 SLAAC(상태 비저장 주소 자동 설정)에서 단말이 글로벌 유니캐스트 주소를 만드는 방법으로 올바른 것은?
  9. 어떤 PC에서 IP 주소를 지정한 ping은 인터넷상의 서버까지 도달하지만, 브라우저에서 도메인 이름을 지정하면 '서버를 찾을 수 없음'이라고 표시되어 웹 페이지를 열 수 없다. 먼저 확인해야 할 설정으로 가장 적절한 것은?
