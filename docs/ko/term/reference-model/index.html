참조 모델(reference model)란?

회로와 같은 기능을 구현한 별도의 모델로, 주로 C로 작성합니다. 같은 입력에 대한 결과를 설계 출력의 기대값으로 사용합니다.

일본어 명칭: 参照モデル

참조 모델(reference model)은(는) HDL과 검증 등 1개 분야의 연습 문제 1개에 나와요.

분야: HDL과 검증

도전해 보기: 참조 모델(reference model) 관련 문제

검증에서 C 언어 등으로 작성한 참조 모델(골든 모델)을 사용하는 목적으로 올바른 것은?

  1. A회로를 제조하기 위한 설계도로서 그대로 공장에 넘긴다
  2. B회로와 같은 기능을 다른 방법으로 계산하고, 그 결과를 기대값으로서 회로의 출력과 비교한다
  3. C회로의 동작을 느리게 하여 보기 쉽게 한다
정답과 해설 보기

정답: B. 회로와 같은 기능을 다른 방법으로 계산하고, 그 결과를 기대값으로서 회로의 출력과 비교한다

참조 모델은 회로가 구현해야 할 기능을 타이밍을 신경 쓰지 않고 소프트웨어로 단순하게 작성한 것입니다. 같은 입력을 회로와 참조 모델 양쪽에 주고 결과를 비교하면, 대량의 랜덤 입력에 대해서도 기대값을 자동으로 만들 수 있습니다. 설계와 같은 사람이 같은 오해를 바탕으로 만들면 오류를 놓치므로, 사양서에서 독립적으로 만드는 것이 중요합니다.
