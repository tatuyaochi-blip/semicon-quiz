라우스-후르비츠 안정 판별법(Routh–Hurwitz Stability Criterion)란?

특성 방정식을 풀지 않고 그 계수만으로 근(폐루프의 극점)이 모두 s 평면의 왼쪽 절반에 있는지를 판정하는 방법. 모든 계수가 같은 부호이고 빠진 항이 없는 것이 필요조건이며, 나아가 라우스 표의 제1열이 모두 같은 부호이면 안정하고, 부호가 바뀌는 횟수가 오른쪽 절반에 있는 근의 수와 같다. 3차 방정식 s³ + a₂s² + a₁s + a₀ = 0에서는 계수가 모두 양이고 a₂a₁ > a₀일 때 안정해진다. 이득을 변수로 하여 안정해지는 범위를 구하는 데 쓰인다. 라우스의 방법과 후르비츠의 방법은 같은 조건을 준다.

라우스-후르비츠 안정 판별법(Routh–Hurwitz Stability Criterion)은(는) 제어 공학의 기초 등 1개 분야의 연습 문제 2개에 나와요.

도전해 보기: 라우스-후르비츠 안정 판별법(Routh–Hurwitz Stability Criterion) 관련 문제

루프 전달 함수가 K/(s(s + 1)(s + 2))인 단위 피드백 시스템이 있다. 폐루프 시스템이 안정해지는 K의 범위로 올바른 것은?

  1. A0 < K < 2
  2. B0 < K < 3
  3. C0 < K < 6
정답과 해설 보기

정답: C. 0 < K < 6

특성 방정식은 s(s + 1)(s + 2) + K = s³ + 3s² + 2s + K = 0입니다. 라우스-후르비츠 안정 판별법에 따르면 3차 방정식 s³ + a₂s² + a₁s + a₀ = 0이 안정할 조건은 계수가 모두 양이고 a₂a₁ > a₀인 것이므로, 3 × 2 > K, 즉 0 < K < 6입니다. K = 6에서는 극점이 s = ±j√2에 와서 각주파수 약 1.41 rad/s(주기 약 4.4 s)의 지속 진동이 됩니다. K가 이보다 크면 진동이 계속 커집니다.

루프 전달 함수 L(s) = 2/(s(s + 1)(s + 2))의 이득 여유에 가장 가까운 것은?

  1. A약 4.8 dB
  2. B약 9.5 dB
  3. C약 15.6 dB
정답과 해설 보기

정답: B. 약 9.5 dB

위상은 −90° − tan⁻¹ω − tan⁻¹(ω/2)이고, 두 각의 합이 90°가 되는 조건 ω × (ω/2) = 1로부터 위상이 −180°가 되는 것은 ω = √2 rad/s일 때입니다. 그곳에서의 이득은 |L(j√2)| = 2/(√2 × √3 × √6) = 1/3이므로 이득 여유는 20 log₁₀3 ≈ 9.5 dB입니다. 이득을 3배(K = 6)로 하면 한계에 도달하게 되어, 라우스-후르비츠 안정 판별법으로 구한 안정 범위 0 < K < 6과 일치합니다.
