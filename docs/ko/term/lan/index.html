LAN(근거리 통신망)란?

Local Area Network의 약자. 가정, 사무실, 공장, 건물 안 등 한정된 범위의 기기를 연결하는 네트워크. 유선에서는 이더넷, 무선에서는 Wi-Fi(무선 LAN)가 주로 쓰인다. 떨어진 거점끼리 잇는 넓은 범위의 네트워크는 WAN(Wide Area Network)이라 부르며, LAN과 WAN의 경계에는 일반적으로 라우터를 둔다.

일본어 명칭: LAN(ローカルエリアネットワーク)

LAN(근거리 통신망)은(는) 시스템 구성과 신뢰성 설계, 네트워크 기초 등 2개 분야의 연습 문제 2개에 나와요.

분야: 네트워크 기초

도전해 보기: LAN(근거리 통신망) 관련 문제

스토리지 접속 방식 중 SAN(스토리지 영역 네트워크)에 대한 설명으로 적절한 것은?

  1. A파일 서버 기능을 가진 기억 장치를 LAN에 연결하여 여러 클라이언트가 파일 단위로 공유한다
  2. B서버와 스토리지를 전용 네트워크로 연결하고, 서버는 스토리지를 자신에게 연결된 디스크처럼 블록 단위로 사용한다
  3. C서버 내부의, 또는 케이블로 서버에 직접 연결한 디스크를 그 서버만 사용한다
정답과 해설 보기

정답: B. 서버와 스토리지를 전용 네트워크로 연결하고, 서버는 스토리지를 자신에게 연결된 디스크처럼 블록 단위로 사용한다

SAN은 서버와 스토리지를 전용 네트워크(파이버 채널이나 IP 네트워크를 사용하는 iSCSI 등)로 연결하고, 서버가 스토리지 영역을 블록 단위로 자신의 디스크처럼 사용하는 방식입니다. 성능이 요구되는 데이터베이스나 가상화 기반에서 많이 사용됩니다. LAN에 연결한 기억 장치를 파일 단위로 공유하는 것은 NAS, 서버에 직접 연결하여 사용하는 것은 DAS(직접 연결 스토리지)입니다.

웹 페이지의 데이터를 보낼 때, 송신 측에서 데이터가 위 계층에서 아래 계층으로 넘겨질 때마다 일어나는 일로 올바른 것은?

  1. A각 계층이 각자의 제어 정보(헤더)를 붙여 감싸고, 수신 측에서는 아래 계층부터 차례로 떼어 낸다
  2. B각 계층이 데이터를 압축하므로 아래 계층일수록 보내는 데이터가 작아진다
  3. C위 계층의 헤더를 제거한 뒤 그 계층의 헤더로 바꿔 붙인다
정답과 해설 보기

정답: A. 각 계층이 각자의 제어 정보(헤더)를 붙여 감싸고, 수신 측에서는 아래 계층부터 차례로 떼어 낸다

이 구조를 캡슐화라고 합니다. 애플리케이션의 데이터에 TCP 헤더가 붙어 세그먼트가 되고, IP 헤더가 붙어 패킷이 되며, 이더넷 헤더와 오류 검출 부호(FCS)가 붙어 프레임이 됩니다. 수신 측은 아래 계층부터 차례로 헤더를 읽고 떼어 내며, 각 계층은 자기 헤더의 정보만 보고 처리합니다. 각 계층이 다른 계층의 내용을 몰라도 되므로, 예를 들어 유선 LAN을 무선 LAN으로 바꾸어도 위 계층은 그대로 사용할 수 있습니다. 그 대신 헤더만큼 회선에 흐르는 비트는 애플리케이션의 데이터보다 많아집니다.
