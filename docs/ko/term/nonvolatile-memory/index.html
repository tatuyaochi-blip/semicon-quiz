비휘발성 메모리란?

전원을 꺼도 기억한 데이터가 사라지지 않는 메모리. 플래시 메모리, MRAM 등. DRAM과 SRAM은 휘발성이다.

일본어 명칭: 不揮発性メモリ

비휘발성 메모리은(는) SRAM과 플래시 메모리, 차세대 메모리, 반도체 산업과 시장 등 3개 분야의 연습 문제 9개에 나와요.

정답과 해설 보기

정답: A. 내장 플래시 메모리

마이크로컨트롤러에는 프로그램과 데이터를 저장하는 내장 플래시가 로직 회로와 같은 칩에 혼재되어 왔습니다. 전원을 꺼도 내용이 남고, 출하 후에 펌웨어를 갱신할 수도 있습니다. 다만 플로팅 게이트 형성 등 공정이 많아, 28 nm 전후보다 앞선 세대나 High-k/메탈 게이트와의 혼재가 어려워, 더 적은 공정으로 만들 수 있는 MRAM이나 ReRAM으로의 교체가 진행되고 있습니다.

MRAM이 마이컴 등의 내장 비휘발성 메모리로 주목받는 이유의 하나로 올바른 것은 무엇입니까?

  1. A첨단 로직 공정에서는 내장 플래시의 제조가 어려워지고, 배선 공정에서 만들 수 있는 MRAM이 대체 후보가 되기 때문
  2. BDRAM보다 대용량이고 저렴하기 때문
  3. C전원을 끄면 데이터가 사라지기 때문
정답과 해설 보기

정답: A. 첨단 로직 공정에서는 내장 플래시의 제조가 어려워지고, 배선 공정에서 만들 수 있는 MRAM이 대체 후보가 되기 때문

내장 플래시는 플로팅 게이트 형성 등으로 마스크를 10장 이상 추가해야 하며, 28 nm 전후보다 앞선 세대나 High-k/메탈 게이트와의 조합에서는 구현이 어려워지고 있습니다. MRAM은 배선 공정 중간에 MTJ를 만들어 넣을 수 있고 추가 마스크도 몇 장이면 되므로, TSMC나 삼성전자 등의 파운드리가 22 nm 이하에서 내장 MRAM을 제공하고 있습니다. 차량용 마이컴 등에서 채택이 늘고 있습니다.

해설 속 비휘발성 메모리

  • 비휘발성 메모리를 캐시나 레지스터에 사용하면 처리가 없는 순간에 전원을 세밀하게 꺼도 데이터가 남으므로 대기 전력을 거의 0으로 할 수 있고 복귀도 빨라집니다(노멀리 오프 컴퓨팅).

    비휘발성 메모리를 캐시나 레지스터 등에 사용함으로써 기대되는 시스템 저전력화의 원리로 올바른 것은 무엇입니…

  • MRAM은 자성체의 자화 방향으로 기억하므로 전원을 꺼도 데이터가 남는 비휘발성 메모리이며, 유지 기간은 일반적으로 10년 이상입니다.

    다음 메모리 중 전원을 꺼도 데이터가 남는 비휘발성 메모리는 무엇입니까?

  • 플래시 메모리는 절연막으로 둘러싸인 플로팅 게이트나 전하 트랩층에 전자를 가두어 기억하므로, 전원을 꺼도 데이터가 남는 비휘발성 메모리입니다.

    플래시 메모리의 성질로 올바른 것은 무엇입니까?

  • USB 메모리나 SD 카드, SSD에는 대용량이고 저렴한 비휘발성 메모리인 NAND 플래시가 사용되며, 내부에는 NAND 칩과 오류 정정이나 웨어 레벨링을 담당하는 컨트롤러가 들어 있습니다.

    USB 메모리나 SD 카드에 주로 사용되는 메모리는 무엇입니까?

  • EEPROM은 1바이트 단위로 소거·재기록이 가능한 비휘발성 메모리로, 각 셀에 선택 트랜지스터를 붙이므로 셀이 크고 용량은 수 Kbit~수 Mbit 정도입니다.

    EEPROM과 플래시 메모리의 차이로 올바른 것은 무엇입니까?

  2. MRAM이 마이컴 등의 내장 비휘발성 메모리로 주목받는 이유의 하나로 올바른 것은 무엇입니까?

  4. 다음 메모리 중 전원을 꺼도 데이터가 남는 비휘발성 메모리는 무엇입니까?
