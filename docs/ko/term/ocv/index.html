OCV(온칩 변동)란?

같은 칩 안에서도 위치에 따라 트랜지스터나 배선의 지연이 달라지는 것. STA에서는 송신 측과 수신 측 경로에 별도의 계수(예: 1.1배와 0.9배)를 곱해 가장 불리한 조합을 상정하여 분석한다.

일본어 명칭: OCV(オンチップばらつき)

OCV(온칩 변동)은(는) 타이밍 분석과 CDC, IC 설계 흐름과 EDA 등 2개 분야의 연습 문제 3개에 나와요.

분야: 타이밍 분석과 CDC

온칩 변동의 원인

하나의 다이 안에서도 트랜지스터와 배선은 정확히 일치하지 않습니다. 랜덤 도펀트 요동, 라인 에지 거칠기, 국부적인 리소그래피 효과가 문턱 전압과 채널 길이를 변화시키고, 배선의 폭과 두께는 국부적인 패턴 밀도에 따라 달라지며, IR 드롭과 핫스팟으로 국부적인 전원 전압과 온도가 달라집니다. 전역 PVT 코너(공정, 전압, 온도)는 칩 간 변동을 다루지만, 같은 칩의 두 경로도 여전히 다를 수 있으며, 셋업 검사와 홀드 검사는 바로 그런 경로 쌍을 비교합니다.

런치 경로와 캡처 경로의 디레이팅

플랫 OCV에서 STA는 각 검사마다 비관적으로 선택된 디레이팅 계수를 지연에 곱합니다. 셋업의 경우 런치 클록 경로와 데이터 경로는 느리게(예: ×1.1), 캡처 클록 경로는 빠르게(×0.9) 만듭니다. 런치 클록 1.0 ns, 데이터 경로 1.5 ns, 캡처 클록 1.0 ns, 주기 3.0 ns, 셋업 타임 0.1 ns인 경우 도착 시간은 2.75 ns, 요구 시간은 3.8 ns가 되어, 디레이팅이 없을 때의 1.40 ns 대신 1.05 ns의 슬랙이 나옵니다. 홀드의 경우에는 계수를 서로 바꿉니다.

CRPR: 불가능한 비관성 제거

런치 클록과 캡처 클록이 클록 루트에서 분기점까지 공통 경로를 공유하면, 플랫 디레이팅은 하나의 검사에서 같은 버퍼 체인을 느린 것과 빠른 것으로 동시에 취급하는데, 이는 하나의 클록 에지에서는 일어날 수 없는 일입니다. CRPR(common path pessimism removal, CPPR이라고도 함)은 그 차이를 슬랙에 다시 더해 줍니다. 계수가 1.1과 0.9이고 공통 구간이 1.0 ns이면 0.2 ns를 회복합니다. 공통 지연을 0으로 만드는 것이 아니라 이중 계산만 제거합니다.

AOCV와 POCV

플랫 디레이팅은 대략적입니다. 랜덤 변동은 깊은 경로를 따라 부분적으로 평균화되는 반면, 멀리 떨어져 배치된 셀일수록 체계적인 차이가 더 커집니다. AOCV(Advanced OCV)는 로직 깊이와 거리로 인덱싱된 테이블을 사용하므로 긴 경로에는 더 작은 디레이팅이 적용됩니다. 파라메트릭 또는 통계적 OCV(POCV, SOCV)는 각 셀에 지연의 평균과 표준 편차를 부여하고 이를 경로를 따라 통계적으로 결합합니다. 두 방법 모두 선택한 신뢰 수준까지 변동을 다루면서도 플랫 OCV가 낭비하는 마진을 회복합니다.

도전해 보기: OCV(온칩 변동) 관련 문제

OCV 디레이팅으로서, 셋업 분석에서 송신 측 클럭 경로와 데이터 경로의 지연을 1.1배, 수신 측 클럭 경로의 지연을 0.9배로 합니다. 송신 측 클럭 경로 1.0 ns, 데이터 경로(클럭→출력 포함) 1.5 ns, 수신 측 클럭 경로 1.0 ns(공통 부분은 없음), 주기 3.0 ns, 셋업 타임 0.1 ns일 때 셋업 슬랙은 얼마입니까?

  1. A1.05 ns
  2. B1.40 ns
  3. C1.25 ns
정답과 해설 보기

정답: A. 1.05 ns

OCV 디레이팅은 같은 칩 안에서도 위치에 따라 지연이 달라지는 것을 예상하여, 셋업에는 가장 불리한 조합(송신 측은 느리고 수신 측 클럭은 빠름)을 가정하는 방법입니다. 도착 시각은 1.1 × (1.0 + 1.5) = 2.75 ns, 요구 시각은 3.0 + 0.9 × 1.0 − 0.1 = 3.8 ns이므로 슬랙은 1.05 ns입니다. 1.40 ns는 디레이팅을 하지 않은 값, 1.25 ns는 데이터 경로에만 계수를 곱한 값입니다. 홀드 분석에서는 계수를 곱하는 방식이 반대가 됩니다.

OCV 디레이팅을 사용한 STA에서 송신 측과 수신 측의 클럭 경로가 도중까지 공통인 경우에 수행하는 CRPR(공통 경로 비관성 제거)에 대한 설명으로 올바른 것은?

  1. A공통 부분의 지연을 0으로 간주하여 클럭의 도착 시각을 다시 계산한다
  2. B공통 부분에 느린 값과 빠른 값을 따로 적용한 데서 생기는, 있을 수 없는 여분의 비관을 제거한다
  3. C공통 부분에는 더 큰 디레이팅 계수를 곱해 안전 측으로 한다
정답과 해설 보기

정답: B. 공통 부분에 느린 값과 빠른 값을 따로 적용한 데서 생기는, 있을 수 없는 여분의 비관을 제거한다

OCV에서는 송신 측 클럭 경로를 느리게, 수신 측을 빠르게 추정하지만, 루트에서 분기점까지의 공통 부분은 물리적으로 같은 버퍼와 배선이므로 한 번의 에지 안에서 느리기도 하고 빠르기도 한 일은 없습니다. 공통 부분의 지연이 1.0 ns이고 계수가 1.1과 0.9라면 1.1 ns와 0.9 ns의 차이인 0.2 ns가 여분의 비관이 됩니다. CRPR은 이 차이를 슬랙에 되돌려 결과를 현실에 가깝게 합니다. 공통 부분의 지연을 0으로 하는 것이 아니며, 계수를 크게 하는 것은 반대의 조작입니다.

자주 묻는 질문

OCV와 PVT 코너의 차이는 무엇인가요?

PVT 코너는 칩 전체가 함께 느린 조건이나 빠른 조건으로 이동하는 것을 모델링합니다. OCV는 주어진 코너에서 같은 칩 위의 경로 간 차이를 모델링하므로, 코너 해석 위에 추가로 적용됩니다.

정적 타이밍 분석(STA)에서 CRPR이란?

CRPR(common path pessimism removal)은 OCV 디레이팅이 런치 클록 경로와 캡처 클록 경로의 공유 부분을 동시에 느린 것과 빠른 것으로 취급하여 잃은 슬랙을 되돌려 주는 것입니다.

OCV 디레이팅을 셋업과 홀드에 다르게 적용하는 이유는?

각 검사가 각자의 최악 조건을 가정하기 때문입니다. 셋업은 늦은 런치와 이른 캡처에서 불리하고, 홀드는 이른 런치와 늦은 캡처에서 불리하므로 느린 계수와 빠른 계수를 서로 바꿉니다.
