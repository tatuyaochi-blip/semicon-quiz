LRU(Least Recently Used)란?

가장 오랫동안 사용되지 않은 데이터를 내보내는 캐시 교체 방식. 시간적 지역성을 잘 활용하지만 웨이가 많으면 정확한 관리가 어려워 근사 방식이 사용된다.

일본어 명칭: LRU(Least Recently Used)

LRU(Least Recently Used)은(는) 메모리 계층 구조, OS와 하드웨어 등 2개 분야의 연습 문제 6개에 나와요.

분야: 메모리 계층 구조

도전해 보기: LRU(Least Recently Used) 관련 문제

용량 2라인의 풀 어소시에이티브 방식에서 LRU 교체를 사용하는 캐시가 처음에는 비어 있을 때, 블록을 A, B, A, C, B, A 순으로 참조하면 미스는 몇 번 일어나는가?

  1. A4번
  2. B5번
  3. C6번
정답과 해설 보기

정답: B. 5번

순서대로 따라가면 A(미스, [A]), B(미스, [A,B]), A(히트, A가 최근), C(미스, 가장 오래된 B를 쫓아내고 [A,C]), B(미스, 가장 오래된 A를 쫓아내고 [C,B]), A(미스, 가장 오래된 C를 쫓아내고 [B,A])가 되어 미스는 5번입니다. 4번이라는 것은 C를 넣을 때 A를 쫓아냈다고 잘못 본 경우 등의 계산이며, LRU에서는 히트한 A가 최신이 되는 점이 중요합니다. 6번은 세 번째 A의 히트를 놓친 횟수입니다.

가장 오랫동안 사용되지 않은 것을 쫓아내는 LRU에 대해, 앞으로 가장 오랫동안 사용되지 않을 것을 쫓아내는 방식(최적 교체, OPT)에 대한 설명으로 올바른 것은?

  1. A실제 캐시에서 널리 사용되는 가장 일반적인 교체 방식이다
  2. B실현할 수는 없지만 다른 방식의 미스 수의 하한을 보여 주는 기준이 된다
  3. C어떤 접근 순서에서도 LRU와 완전히 같은 미스 수가 된다
정답과 해설 보기

정답: B. 실현할 수는 없지만 다른 방식의 미스 수의 하한을 보여 주는 기준이 된다

최적 교체(벨러디의 OPT)는 미래의 접근 순서를 알고 있다고 가정하고 다음에 사용되는 시점이 가장 먼 데이터를 쫓아내는 방식으로, 미스 수가 이론상 최소가 됩니다. 그러나 실제 하드웨어는 미래의 접근을 알 수 없으므로 실현할 수 없고, 기록한 접근 순서에 적용하여 LRU 등의 방식이 얼마나 최적에 가까운지 평가하는 데 사용합니다. LRU와는 쫓아내는 데이터가 다르므로 미스 수는 일반적으로 다릅니다.

LRU(Least Recently Used)이(가) 나오는 문제 (6)

  1. 용량 2라인의 풀 어소시에이티브 방식에서 LRU 교체를 사용하는 캐시가 처음에는 비어 있을 때, 블록을 A, B, A, C, B, A 순으로 참조하면 미스는 몇 번 일어나는가?
  2. 가장 오랫동안 사용되지 않은 것을 쫓아내는 LRU에 대해, 앞으로 가장 오랫동안 사용되지 않을 것을 쫓아내는 방식(최적 교체, OPT)에 대한 설명으로 올바른 것은?
  3. 페이지 교체의 클록 방식(세컨드 찬스 방식)에서 각 페이지의 참조 비트를 사용하는 목적은?
  4. 페이지 교체에서 FIFO 방식을 사용하면 물리 메모리의 페이지 수를 늘렸는데도 페이지 폴트가 늘어나는 경우가 있습니다. 이 현상을 무엇이라고 합니까?
  5. 라이트 백 방식 캐시에서 각 라인에 붙이는 더티 비트의 역할로 올바른 것은?
  6. 캐시의 각 라인에 붙는 유효 비트(valid bit)의 역할로 올바른 것은?
