병렬 리덕션(parallel reduction)란?

이웃한 값을 반복해서 합치는 트리 구조로 많은 값의 합 등을 병렬로 계산하는 방법으로, n개의 값을 log2 n단계에 끝냅니다.

일본어 명칭: 並列リダクション

분야: GPU 프로그래밍

관련 용어

고정 메모리(pinned memory) 그리드 스트라이드 루프(grid-stride loop) 메모리 코얼레싱(memory coalescing) 뱅크 충돌(bank conflict) 상수 메모리(constant memory) 스레드 블록(thread block) 스트리밍 멀티프로세서(streaming multiprocessor, SM) 워프 다이버전스(warp divergence) 지연 시간 은닉(latency hiding) 텐서 코어(tensor core)
