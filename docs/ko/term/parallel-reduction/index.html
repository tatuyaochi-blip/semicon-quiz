병렬 리덕션(parallel reduction)란?

많은 값의 총합 등을 이웃끼리 묶는 과정을 반복하는 트리 형태로 병렬 계산하는 방법. n개의 값을 log2 n단계로 처리할 수 있다.

일본어 명칭: 並列リダクション

분야: GPU 프로그래밍

관련 용어

그리드 스트라이드 루프(Grid-stride Loop) 레이턴시 은닉(Latency Hiding) 메모리 코얼레싱(Memory Coalescing) 뱅크 충돌(bank conflict) 상수 메모리(Constant Memory) 셰어드 메모리(Shared Memory) 스레드 블록(Thread Block) 스트리밍 멀티프로세서(SM) 워프 다이버전스(Warp Divergence) 점유율(Occupancy)
