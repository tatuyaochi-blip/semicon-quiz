힙(Heap)란?

프로그램 실행 중 malloc 등으로 필요한 크기의 메모리를 확보하고 free로 반환하는 영역. 확보와 해제를 반복하면 단편화가 일어날 수 있다.

일본어 명칭: ヒープ

힙(Heap)은(는) C 언어 기초 등 1개 분야의 연습 문제 1개에 나와요.

분야: 링커, 로더, 실행 파일

도전해 보기: 힙(Heap) 관련 문제

C 언어에서 (1) 함수 안에서 static을 붙이지 않고 선언한 지역 변수, (2) malloc으로 확보한 영역, (3) 함수 밖에서 선언한 변수가 각각 존재하는 기간(수명)의 조합으로 올바른 것은?

  1. A(1) 프로그램 종료까지, (2) 확보한 함수에서 돌아올 때까지, (3) 프로그램 종료까지
  2. B(1) 선언한 블록에서 빠져나올 때까지, (2) free로 해제할 때까지, (3) 프로그램 종료까지
  3. C(1) 선언한 블록에서 빠져나올 때까지, (2) 프로그램 종료까지(도중에는 해제할 수 없음), (3) 그 변수를 처음 사용한 함수에서 돌아올 때까지
정답과 해설 보기

정답: B. (1) 선언한 블록에서 빠져나올 때까지, (2) free로 해제할 때까지, (3) 프로그램 종료까지

(1)의 자동 변수는 일반적으로 스택에 놓이며, 선언한 블록에 들어갈 때 만들어지고 빠져나오면 사라집니다. (2)의 malloc으로 확보한 영역은 힙(heap)에 놓이며, 함수에서 돌아와도 남아 있고 free로 해제할 때까지 사용할 수 있습니다. (3)의 함수 밖의 변수(및 static을 붙인 변수)는 프로그램이 실행되는 동안 계속 존재하며, .data나 .bss 같은 정적 영역에 놓입니다. 수명이 끝난 영역을 가리키는 포인터를 사용하는 것이나, free를 잊어 영역이 계속 남는 것이 흔한 실수의 원인이 됩니다.

해설 속 힙(Heap)

  • (2)의 malloc으로 확보한 영역은 힙(heap)에 놓이며, 함수에서 돌아와도 남아 있고 free로 해제할 때까지 사용할 수 있습니다.
