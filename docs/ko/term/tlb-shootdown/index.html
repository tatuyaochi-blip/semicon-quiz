TLB 슛다운(TLB Shootdown)란?

멀티프로세서에서 페이지 테이블을 고쳐 썼을 때 다른 코어의 TLB에 남은 오래된 변환을 지우게 하는 처리. 프로세서 간 인터럽트로 각 코어에 요청하는 방식과 무효화를 전체 코어에 알리는 명령을 쓰는 방식이 있으며 시간이 걸린다.

일본어 명칭: TLBシュートダウン

분야: OS와 하드웨어

관련 용어

디바이스 드라이버(device driver) 메모리 맵 I/O(Memory-mapped I/O) 스래싱(Thrashing) 시스템 콜(system call) 요구 페이징(Demand Paging) 인터럽트 벡터 테이블(Interrupt Vector Table) 인터럽트 핸들러 중첩 페이징(Nested Paging) 카피 온 라이트(Copy-on-Write) 컨텍스트 스위치(context switch)
