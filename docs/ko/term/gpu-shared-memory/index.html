셰어드 메모리(Shared Memory)란?

GPU의 각 SM 안에 있는, 같은 블록의 스레드끼리 공유할 수 있는 작고 빠른 메모리. 무엇을 둘지는 프로그램이 정한다.

일본어 명칭: シェアードメモリ

셰어드 메모리(Shared Memory)은(는) GPU 프로그래밍 등 1개 분야의 연습 문제 1개에 나와요.

CUDA 공유 메모리(shared memory)의 특징으로 올바른 것은?

  1. A모든 GPU와 CPU가 공유하는 대용량 주기억장치
  2. BGPU 메모리를 하드디스크와 공유하는 영역
  3. C같은 블록의 스레드가 공유할 수 있는 칩 상의 작고 빠른 메모리로, 프로그램이 명시적으로 사용한다
정답과 해설 보기

정답: C. 같은 블록의 스레드가 공유할 수 있는 칩 상의 작고 빠른 메모리로, 프로그램이 명시적으로 사용한다

공유 메모리는 각 SM 안에 있는 블록당 수십 KB 정도의 고속 메모리로, 글로벌 메모리(GPU의 DRAM)보다 수십 배 빠르게 읽고 쓸 수 있습니다. 같은 블록의 스레드가 데이터를 두고 공유할 수 있으므로, 글로벌 메모리에서 한 번만 읽어 여러 번 사용하거나 스레드끼리 중간 결과를 주고받는 용도로 사용합니다. 캐시와 달리 무엇을 둘지 프로그램이 결정합니다.
