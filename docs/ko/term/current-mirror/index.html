전류 미러 회로(current mirror)란?

특성이 같은 두 트랜지스터로 한쪽에 흘린 전류와 같은(또는 일정 비의) 전류를 다른 쪽에 흘리는 회로. 아날로그 IC의 바이어스 전류원과 능동 부하에 널리 쓰인다.
