HTTP 메서드(HTTP Method)란?

HTTP 요청에서 리소스에 대해 수행하려는 조작을 나타내는 말. GET(조회), HEAD(헤더만 조회), POST(처리나 생성), PUT(교체), PATCH(일부 갱신), DELETE(삭제), OPTIONS(사용할 수 있는 기능 문의) 등이 있다. 서버의 상태를 바꾸지 않는 것을 '안전', 몇 번 보내도 한 번 보냈을 때와 같은 상태가 되는 것을 '멱등'이라고 한다. GET은 안전하고 멱등이며, PUT과 DELETE는 멱등이지만 안전하지 않고, POST는 일반적으로 어느 쪽도 아니다.

정답과 해설 보기

정답: C. PUT

GET이나 HEAD는 리소스를 읽기만 하는 안전한 메서드이며, 안전한 메서드는 동시에 멱등이기도 합니다. PUT은 지정한 리소스의 상태를 보낸 내용으로 바꿔 놓으므로 몇 번 보내도 결과는 한 번 보냈을 때와 같아, 멱등이지만 안전하지는 않습니다. DELETE도 마찬가지로 멱등입니다. POST는 보낼 때마다 새로운 주문이나 게시글을 만들 수 있으므로 일반적으로 멱등이 아니며, PATCH도 멱등이라고는 할 수 없습니다. 멱등인 요청은 통신 실패로 결과를 알 수 없을 때 그대로 다시 보내도 문제가 생기기 어렵다는 장점이 있습니다.

해설 속 HTTP 메서드(HTTP Method)

  • REST에서는 다루는 대상을 리소스로서 URL로 나타내고, 그 리소스에 대한 조작을 GET(조회), POST(생성), PUT이나 PATCH(갱신), DELETE(삭제) 같은 HTTP 메서드로 나타냅니다.
