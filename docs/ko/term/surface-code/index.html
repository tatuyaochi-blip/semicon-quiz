표면 코드(Surface Code)란?

큐비트를 2차원 격자에 늘어놓고, 이웃한 큐비트끼리의 조작만으로 오류를 검출하는 양자 오류 정정 부호. 임계값이 기준으로 1% 정도로 높고, 초전도 큐비트 칩과 궁합이 좋다. 부호 거리 d인 회전형에서는 하나의 논리 큐비트에 2d² − 1개의 물리 큐비트를 사용한다.

일본어 명칭: 表面符号

표면 코드(Surface Code)은(는) 양자 컴퓨터의 하드웨어 등 1개 분야의 연습 문제 2개에 나와요.

분야: 양자 컴퓨터의 하드웨어

도전해 보기: 표면 코드(Surface Code) 관련 문제

부호 거리 d인 회전형 표면 코드에서는 하나의 논리 큐비트에 데이터용 물리 큐비트 d²개와, 오류를 조사하는 측정용 물리 큐비트 d² − 1개를 사용한다. d = 15일 때 하나의 논리 큐비트에 필요한 물리 큐비트의 수는?

  1. A29개
  2. B225개
  3. C449개
정답과 해설 보기

정답: C. 449개

데이터용이 15² = 225개, 측정용이 225 − 1 = 224개로, 합계 2d² − 1 = 449개입니다. 부호 거리 d인 부호는 (d − 1)/2개까지의 오류를 정정할 수 있으므로, d = 15라면 7개까지의 오류에 대응할 수 있습니다. 물리 큐비트의 오류율이 0.1% 정도일 때, 실용적인 계산에 필요한 논리 오류율을 얻으려면 d를 십수~25 정도로 해야 한다는 추산이 있어, 하나의 논리 큐비트에 수백~천수백 개의 물리 큐비트가 필요해집니다. 표면 코드는 2차원 격자에서 이웃한 큐비트끼리의 조작만으로 동작하므로, 초전도 큐비트 칩과 궁합이 좋은 방식입니다.

표면 코드의 논리 오류율 p_L이 물리 오류율 p, 임계값 p_th, 부호 거리 d를 사용하여 p_L ∝ (p/p_th)^((d+1)/2)로 근사할 수 있다고 하자. p = 0.1%, p_th = 1%일 때, d를 5에서 9로 키웠을 때의 논리 오류율의 비(d = 5일 때의 값 ÷ d = 9일 때의 값)에 가장 가까운 것은?

  1. A약 1.8
  2. B약 10
  3. C약 100
정답과 해설 보기

정답: C. 약 100

지수 (d+1)/2는 d = 5에서 3, d = 9에서 5이므로, 비는 (p_th/p)의 제곱 = 10² = 100, 약 100입니다. 물리 오류율이 임계값보다 충분히 낮으면 부호 거리를 2 늘릴 때마다 논리 오류율이 p_th/p분의 1(여기서는 10분의 1)씩 내려가, 큐비트를 늘릴수록 오류가 지수적으로 줄어듭니다. 반대로 p가 임계값을 넘으면 d를 키울수록 오류의 기회가 늘어나 논리 오류율은 오히려 나빠집니다. 표면 코드의 임계값은 오류 모델에 따라 달라지지만 기준으로 1% 정도로 여겨지며, 물리 오류율을 임계값보다 충분히 낮게 하는 것이 오류 정정의 전제가 됩니다.
