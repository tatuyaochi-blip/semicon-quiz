마이크로 오퍼레이션(Micro-operation)란?

CPU가 명령을 내부에서 분해한 단순한 동작. μop라고도 쓴다. x86 CPU는 복잡한 명령을 μop로 나누어 RISC와 같은 고속 방식으로 실행한다.

일본어 명칭: マイクロオペレーション

마이크로 오퍼레이션(Micro-operation)은(는) ISA와 어셈블리 등 1개 분야의 연습 문제 2개에 나와요.

분야: ISA와 어셈블리

도전해 보기: 마이크로 오퍼레이션(Micro-operation) 관련 문제

x86의 명령어 'add eax, [rbx]'처럼 연산 명령어가 메모리 상의 값을 직접 사용할 수 있는 방식에 대해 올바른 것은?

  1. A명령어 수는 적게 할 수 있지만 하나의 명령어 안에 메모리 읽기와 연산이 포함된다
  2. B로드-스토어 아키텍처라고 하는 방식이다
  3. C메모리 값을 사용하는 연산은 레지스터끼리의 연산과 반드시 같은 시간에 끝난다
정답과 해설 보기

정답: A. 명령어 수는 적게 할 수 있지만 하나의 명령어 안에 메모리 읽기와 연산이 포함된다

x86에서는 하나의 명령어로 '메모리에서 읽어 더하기'를 할 수 있으며, 같은 처리를 RISC-V로 쓰면 lw와 add의 2개 명령어가 됩니다. 명령어 수나 코드는 작아지기 쉬운 반면 명령어마다 일의 양이 제각각이어서 파이프라인으로 다루기 어려워집니다. 그래서 현재의 x86 CPU는 내부에서 이러한 명령어를 로드와 덧셈 같은 단순한 동작(마이크로 오퍼레이션)으로 나누어 실행합니다.

현재의 고성능 x86 CPU가 복잡한 명령어를 내부에서 어떻게 실행하는지에 대한 설명으로 올바른 것은?

  1. A모든 명령어를 소프트웨어 에뮬레이터로 한 명령어씩 실행한다
  2. B명령어를 해독하여 RISC와 유사한 단순한 마이크로 오퍼레이션으로 나누고, 이를 파이프라인으로 실행한다
  3. C복잡한 명령어는 실행할 수 없으므로 OS가 오류로 정지시킨다
정답과 해설 보기

정답: B. 명령어를 해독하여 RISC와 유사한 단순한 마이크로 오퍼레이션으로 나누고, 이를 파이프라인으로 실행한다

x86 CPU는 가변 길이의 복잡한 명령어를 전단의 디코더에서 마이크로 오퍼레이션(μop)이라 불리는 단순한 동작으로 나누고, 후단에서는 이들을 비순차(Out-of-Order) 방식으로 실행합니다. 한 번 나눈 μop를 저장하여 해독을 다시 하지 않아도 되게 하는 μop 캐시를 가진 CPU도 있습니다. 이렇게 옛 소프트웨어와의 호환성을 유지하면서 RISC와 같은 고속 실행 기술을 사용하고 있습니다.
