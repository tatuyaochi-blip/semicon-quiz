IOMMU란?

주변 장치가 DMA로 사용하는 주소를 물리 주소로 변환하여 보호하는 장치. 장치가 허용되지 않은 메모리에 쓰는 것을 막고 가상 머신에 장치를 할당할 때도 사용한다.

일본어 명칭: IOMMU

IOMMU은(는) OS와 하드웨어, 하드웨어 보안, 하드웨어 보안의 최신 동향 등 3개 분야의 연습 문제 3개에 나와요.

분야: OS와 하드웨어

IOMMU가 DMA 주소를 변환하는 방식

IOMMU(input-output memory management unit)가 있으면 장치는 더 이상 물리 주소를 그대로 내보내지 않습니다. 장치의 DMA 요청은 I/O 가상 주소를 담고 있으며, IOMMU는 OS가 해당 장치 또는 장치 그룹용으로 설정한 페이지 테이블에서 이를 조회합니다. PCIe에서 장치는 요청자의 버스, 디바이스, 펑션 번호로 식별됩니다. 최근 변환 결과는 IOTLB(I/O translation lookaside buffer)에 캐시됩니다. 유효한 매핑이 없는 주소나 읽기/쓰기 권한이 맞지 않는 주소에 대한 접근은 메모리에 도달하지 못하고 차단되어 OS에 폴트로 보고됩니다.

IOMMU와 MMU의 차이

둘 다 페이지 테이블로 주소를 변환하지만, 섬기는 대상이 다릅니다. CPU의 MMU는 프로세스별로 가상 주소를 변환하여 프로그램끼리 서로 격리합니다. IOMMU는 장치별로 주소를 변환하여, DMA 엔진이 드라이버가 매핑한 버퍼 안에만 머물도록 합니다. 두 매핑이 독립적이므로, OS는 물리적으로 여러 페이지에 흩어져 있지만 장치의 주소 공간에서는 연속적으로 보이는 버퍼를 장치에 넘겨줄 수 있습니다. 이는 스스로 scatter-gather 전송을 할 수 없는 장치를 단순하게 만들어 줍니다.

DMA 공격 차단

DMA는 CPU와 그 메모리 보호를 우회하므로, IOMMU가 없으면 버스 마스터가 될 수 있는 장치는 무엇이든 키를 읽거나 커널 코드를 수정할 수 있습니다. 이는 PCIe 방식의 DMA를 연결된 하드웨어에 노출하는 외부 포트에서 현실적인 위험입니다. IOMMU를 활성화하면 OS는 각 드라이버가 사용하는 특정 버퍼만, 보통 각 전송이 진행되는 동안만 매핑하며, 그 밖의 모든 영역은 해당 장치에서 접근할 수 없습니다. 많은 플랫폼은 장치가 임의의 인터럽트 메시지를 위조하지 못하도록 IOMMU로 장치 인터럽트도 재매핑합니다.

가상 머신에 대한 디바이스 할당

게스트 OS는 물리 주소라고 믿는 주소로 장치를 설정하지만, 그것은 실제로는 게스트 물리 주소입니다. 하이퍼바이저가 GPU나 네트워크 카드 같은 실제 장치를 가상 머신에 직접 패스스루할 때는, 그 게스트 물리 주소를 해당 VM을 뒷받침하는 호스트 물리 페이지로 변환하도록 IOMMU를 설정합니다. 그러면 장치는 하이퍼바이저가 전송마다 개입하지 않아도 최대 속도로 DMA를 사용할 수 있으면서, 다른 VM의 메모리에는 접근할 수 없습니다. 대가는 약간의 변환 오버헤드로, 주로 IOTLB 미스와 버퍼 매핑 및 해제 비용입니다.

정답: C. 장치의 DMA 주소를 변환하고 부정 접근을 막는다

DMA를 사용하는 장치는 주기억장치를 직접 읽고 쓸 수 있으므로, 오동작하거나 악의적인 장치가 OS의 메모리를 덮어쓸 위험이 있습니다. IOMMU는 CPU의 MMU처럼 장치가 사용하는 주소를 물리 주소로 변환하고 허가된 범위 이외로의 접근을 차단합니다. 연속되지 않은 물리 메모리를 장치에는 연속된 것처럼 보이게 할 수도 있으며, 가상 머신에 장치를 직접 할당할 때도 사용됩니다. 명령 번역이나 전원 제어를 하는 장치가 아닙니다.

자주 묻는 질문

GPU 패스스루를 하려면 IOMMU가 필요한가요?

필요합니다. 물리 장치를 가상 머신에 넘기려면 IOMMU가 게스트의 DMA 주소를 변환하고 장치가 해당 VM 밖의 메모리에 접근하지 못하게 막아야 하므로, 펌웨어와 OS에서 IOMMU가 지원되고 활성화되어 있어야 합니다.

IOMMU를 켜면 I/O가 느려지나요?

변환 미스와 매핑 생성 및 제거에 약간의 비용이 추가되며, 처리율이 매우 높은 장치에서는 이것이 문제가 될 수 있습니다. IOTLB 캐싱과 수명이 긴 매핑 덕분에 대부분의 워크로드에서는 오버헤드가 크지 않습니다.

IOMMU와 MMU의 차이는 무엇인가요?

MMU는 프로세스를 대신해 CPU가 내보내는 주소를 변환하고, IOMMU는 DMA를 수행하는 장치가 내보내는 주소를 변환합니다. 둘 다 페이지 테이블과 권한 비트를 사용하지만, IOMMU의 테이블은 장치 또는 장치 그룹별로 존재합니다.
