IOMMU란?

あいおーえむえむゆー

周辺装置がDMAで使うアドレスを、物理アドレスに変換して保護する装置。装置が許されていないメモリに書き込むのを防ぎ、仮想マシンに装置を割り当てるときにも使う。

일본어 명칭: IOMMU

IOMMU은(는) 하드웨어 보안 등 1개 분야의 연습 문제 1개에 나와요.

도전해 보기: IOMMU 관련 문제

PC에 연결한 외부 기기가 DMA를 이용해 메인 메모리의 내용을 멋대로 읽고 쓰는 공격에 대한 대책으로 올바른 것은?

  1. A외부 기기의 전원 전압을 높인다
  2. BDMA 전송을 빠르게 한다
  3. CIOMMU를 사용하여 각 기기가 DMA로 접근할 수 있는 메모리 범위를 OS가 허가한 영역으로만 제한한다
정답과 해설 보기

정답: C. IOMMU를 사용하여 각 기기가 DMA로 접근할 수 있는 메모리 범위를 OS가 허가한 영역으로만 제한한다

DMA는 기기가 CPU를 거치지 않고 메모리를 직접 읽고 쓰는 구조이므로, 악의적인 기기나 탈취된 기기가 연결되면 OS의 메모리나 키를 읽거나 바꿀 수 있습니다. 고속 외부 단자로 연결되는 기기에서 특히 문제가 되었습니다. IOMMU를 사용하면 기기별로 접근할 수 있는 주소를 OS가 정한 범위로 제한할 수 있어, 허용되지 않은 곳으로의 DMA는 거부됩니다.

해설 속 IOMMU
