적층형 CMOS 이미지 센서(Stacked CIS)란?

화소부와 신호 처리 회로를 별도의 칩으로 만들어 겹쳐 접합한 이미지 센서. 각각에 적합한 공정을 쓸 수 있고, 칩을 작게, 처리를 빠르게 할 수 있다.

일본어 명칭: 積層型CMOSイメージセンサ

적층형 CMOS 이미지 센서(Stacked CIS)은(는) 이미지 센서와 광소자 등 1개 분야의 연습 문제 1개에 나와요.

정답과 해설 보기

정답: C. 화소부와 신호 처리 회로를 별도의 칩으로 만들어 겹쳐 접합한 구조

적층형에서는 화소부 칩과 AD 변환이나 이미지 처리를 하는 로직 회로 칩을 각각 최적의 공정으로 따로 만들고, 구리끼리의 직접 접합(Cu-Cu 접합) 등으로 겹쳐 접합합니다. 2012년에 소니가 제품화했으며, 칩 면적을 줄이면서 고속 읽기, HDR, 동영상의 높은 프레임 레이트화 등을 실현할 수 있습니다. 메모리를 끼운 3층 구조의 제품도 있습니다.
