NUMA란?

ぬま

Non-Uniform Memory Accessの略。コアから近いメモリと遠いメモリがあり、遠いメモリへのアクセスは時間がかかる構成。データとスレッドを同じ側に置くと速い。

일본어 명칭: NUMA

NUMA은(는) 멀티코어와 동기화, 성능 분석, DRAM 등 3개 분야의 연습 문제 4개에 나와요.

도전해 보기: NUMA 관련 문제

NUMA(Non-Uniform Memory Access, 불균일 메모리 접근) 시스템에 대한 설명으로 올바른 것은?

  1. A모든 코어에서 모든 메모리에 같은 시간으로 접근할 수 있다
  2. B코어에서 가까운 메모리와 먼 메모리가 있으며, 먼 메모리에 대한 접근은 시간이 더 걸린다
  3. C각 코어는 자신의 메모리만 읽을 수 있고, 다른 코어의 메모리는 사용할 수 없다
정답과 해설 보기

정답: B. 코어에서 가까운 메모리와 먼 메모리가 있으며, 먼 메모리에 대한 접근은 시간이 더 걸린다

여러 CPU 소켓을 가진 서버 등에서는 각 소켓에 직접 연결된 메모리가 있고, 다른 소켓의 메모리에는 소켓 간 연결을 통해 접근합니다. 그래서 가까운 메모리보다 먼 메모리가 느리고 대역폭도 작습니다. 모든 메모리가 하나의 주소 공간으로 보이므로 프로그램은 그대로 동작하지만, 데이터와 스레드를 같은 쪽에 두면 성능이 올라갑니다.

Linux의 NUMA 시스템에서 자주 사용되는 퍼스트 터치(first-touch) 정책(처음 페이지에 쓴 스레드가 동작 중인 노드의 메모리에 그 페이지를 배치)에서 주의해야 할 점으로 올바른 것은?

  1. A퍼스트 터치에서는 페이지가 무작위 노드에 배치된다
  2. Bmalloc을 호출한 시점에 모든 페이지의 배치 장소가 결정된다
  3. C큰 배열을 하나의 스레드만으로 0으로 초기화하면 전부가 하나의 노드에 배치되어, 다른 노드의 스레드가 먼 메모리를 사용하게 된다
정답과 해설 보기

정답: C. 큰 배열을 하나의 스레드만으로 0으로 초기화하면 전부가 하나의 노드에 배치되어, 다른 노드의 스레드가 먼 메모리를 사용하게 된다

malloc으로 확보만 해서는 물리 페이지가 할당되지 않으며, 처음 쓸 때의 페이지 폴트에서 그 스레드가 있는 노드의 메모리에 배치됩니다. 그래서 초기화를 하나의 스레드로 수행하면 배열 전체가 그 노드에 모이고, 병렬 계산에서 각 스레드가 담당하는 부분의 상당수가 먼 메모리가 됩니다. 초기화도 계산과 같은 분담으로 병렬 수행하면, 각 부분이 담당 스레드 가까이에 배치됩니다.

해설 속 NUMA

  • 옮겨 간 코어의 캐시에는 필요한 데이터가 없고, NUMA 시스템에서는 데이터가 놓인 메모리에서 먼 소켓으로 옮겨 가 버리기도 합니다.

  • 여러 CPU를 가진 서버에서는 각 CPU에 직결된 메모리가 더 빠른 NUMA 구성이 됩니다.
