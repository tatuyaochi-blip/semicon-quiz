하이퍼바이저(hypervisor)란?

한 대의 컴퓨터에서 여러 가상 머신을 실행하며 각 게스트 OS에 CPU, 메모리, 장치를 할당하고 서로 격리하는 소프트웨어입니다. 가상 머신 모니터라고도 합니다.

일본어 명칭: ハイパーバイザ

하이퍼바이저(hypervisor)은(는) OS와 하드웨어, 하드웨어 보안 등 2개 분야의 연습 문제 9개에 나와요.

하이퍼바이저의 유형에 대한 설명으로 올바른 것은 무엇입니까?

  1. A하드웨어 위에서 직접 동작하는 유형과, 일반 OS 위에서 애플리케이션으로 동작하는 유형이 있다
  2. B반드시 일반 OS 위에서 애플리케이션으로 동작하며, 하드웨어 위에서 직접 동작하지는 않는다
  3. C유형에 따른 차이는 없으며, 모두 하드웨어를 사용하지 않고 소프트웨어만으로 동작한다
정답과 해설 보기

정답: A. 하드웨어 위에서 직접 동작하는 유형과, 일반 OS 위에서 애플리케이션으로 동작하는 유형이 있다

하이퍼바이저에는 하드웨어 위에서 직접 동작하며 OS를 관리하는 유형(타입 1, 베어메탈형)과, Windows나 Linux 같은 일반 OS 위에서 애플리케이션으로 동작하는 유형(타입 2, 호스트형)이 있습니다. 타입 1은 불필요한 계층이 없어 성능과 격리가 뛰어나므로 서버나 클라우드에서, 타입 2는 손쉽게 쓸 수 있어 PC에서의 개발이나 테스트에 자주 사용됩니다. 둘 다 CPU의 가상화 지원 기능 등 하드웨어를 이용합니다.

가상 머신의 OS가 특권이 필요한 명령을 실행했을 때 하이퍼바이저로 처리가 넘어가고, 하이퍼바이저가 그 명령의 효과를 대신 재현하는 방식을 무엇이라고 합니까?

  1. A트랩 앤 에뮬레이트(trap-and-emulate)
  2. B카피 온 라이트(copy-on-write)
  3. C디맨드 페이징(demand paging)
정답과 해설 보기

정답: A. 트랩 앤 에뮬레이트(trap-and-emulate)

가상 머신의 OS는 하드웨어를 직접 조작한다고 생각하고 특권 명령을 실행하지만, 실제로는 권한이 낮은 모드에서 실행되고 있으므로 예외(트랩)가 발생합니다. 하이퍼바이저는 이를 받아 그 가상 머신에 올바른 결과가 되도록 명령의 효과를 재현(에뮬레이트)하고 가상 머신으로 돌려보냅니다. CPU의 가상화 지원 기능은 이러한 전환을 빠르고 확실하게 할 수 있게 합니다. 카피 온 라이트와 디맨드 페이징은 메모리 관리 방식입니다.

해설 속 하이퍼바이저(hypervisor)

  • 하이퍼바이저에는 하드웨어 위에서 직접 동작하며 OS를 관리하는 유형(타입 1, 베어메탈형)과, Windows나 Linux 같은 일반 OS 위에서 애플리케이션으로 동작하는 유형(타입 2, 호스트형)이 있습니다.

  • 하이퍼바이저(가상 머신 모니터)는 CPU, 메모리, 장치를 여러 가상 머신에 나누어 주고, 각 OS가 자기 전용 컴퓨터를 쓰고 있는 것처럼 보이게 합니다.

    한 대의 컴퓨터 위에서 여러 OS를 각각 독립된 가상 머신으로 동시에 실행하기 위한 소프트웨어를 무엇이라고…

  • 가상 머신의 OS는 자신이 관리하는 물리 주소(게스트 물리 주소)가 실제 메모리라고 생각하지만, 실제로는 하이퍼바이저가 할당한 다른 위치에 있습니다.

    중첩 페이징(2단 주소 변환)을 사용한 가상화에서 하드웨어가 수행하는 주소 변환에 대한 설명으로 올바른 것…

  • 실제 장치를 세부까지 재현하면 장치 레지스터에 접근할 때마다 하이퍼바이저로의 전환이 일어나 느려집니다.

    준가상화(paravirtualization)에 대한 설명으로 올바른 것은 무엇입니까?

하이퍼바이저(hypervisor)이(가) 나오는 문제 (9)

  1. 하이퍼바이저의 유형에 대한 설명으로 올바른 것은 무엇입니까?
  2. 가상 머신의 OS가 특권이 필요한 명령을 실행했을 때 하이퍼바이저로 처리가 넘어가고, 하이퍼바이저가 그 명령의 효과를 대신 재현하는 방식을 무엇이라고 합니까?
  3. 한 대의 컴퓨터 위에서 여러 OS를 각각 독립된 가상 머신으로 동시에 실행하기 위한 소프트웨어를 무엇이라고 합니까?
  4. 중첩 페이징(2단 주소 변환)을 사용한 가상화에서 하드웨어가 수행하는 주소 변환에 대한 설명으로 올바른 것은 무엇입니까?
  5. 준가상화(paravirtualization)에 대한 설명으로 올바른 것은 무엇입니까?
  6. 컨테이너와 가상 머신의 차이로 올바른 것은 무엇입니까?
  7. RISC-V 특권 아키텍처에서 정해진 주요 동작 모드의 조합으로 올바른 것은 무엇입니까?
  8. Intel SGX와 같은 「엔클레이브(enclave)」형 TEE의 특징으로 올바른 것은?
  9. 클라우드에서 사용되는 「기밀 컴퓨팅(confidential computing)」에서, 가상 머신의 메모리를 CPU가 암호화하는 기능(AMD SEV, Intel TDX 등)의 목적으로 올바른 것은?
