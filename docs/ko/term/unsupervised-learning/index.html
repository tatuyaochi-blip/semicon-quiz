비지도 학습(Unsupervised Learning)란?

정답 레이블이 없는 데이터로부터 데이터 안의 묶음이나 구조를 찾아내는 머신러닝 방법. 비슷한 데이터를 그룹으로 나누는 클러스터링(k-평균 알고리즘 등), 데이터를 적은 변수로 나타내는 차원 축소(주성분 분석 등), 다른 것과 크게 다른 데이터를 찾아내는 이상 탐지 등에 사용된다. 레이블을 준비하지 않아도 되는 반면, 결과의 좋고 나쁨을 평가하기 어렵다.

일본어 명칭: 教師なし学習

  3. C시행착오로 얻는 보상이 커지도록 게임에서 행동을 고르는 방법을 학습한다
정답과 해설 보기

정답: A. 구매 이력만으로 비슷한 구매 패턴을 보이는 고객을 몇 개의 그룹으로 나눈다

비지도 학습은 정답 레이블이 없는 데이터로부터 데이터 안의 묶음이나 구조를 찾아내는 방법입니다. 대표적인 것으로 비슷한 데이터를 그룹으로 나누는 클러스터링과, 데이터를 적은 변수로 나타내는 차원 축소가 있습니다. 고장 유무라는 정답을 사용하여 예측하는 것은 지도 학습, 보상을 단서로 행동을 학습하는 것은 강화 학습입니다.
