크로스포인트 메모리(Cross-point Memory)란?

가로세로 배선의 교점에 기억 소자를 배치한 구조의 메모리. 고밀도화가 가능하지만, 선택하지 않은 셀로의 누설 전류를 막기 위해 기억 소자와 직렬로 셀렉터(선택 소자)를 넣는다.

일본어 명칭: クロスポイント型メモリ

분야: 차세대 메모리

관련 용어

3D XPoint 스토리지 클래스 메모리(SCM) 인메모리 컴퓨팅(in-memory computing) 자기 터널 접합(MTJ) 칼코게나이드(Chalcogenide) 포밍(Forming) FeFET(강유전체 트랜지스터) FeRAM(강유전체 메모리) MRAM PCM(상변화 메모리)
