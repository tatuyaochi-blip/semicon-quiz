DHCP란?

Dynamic Host Configuration Protocol의 약자. 네트워크에 연결한 단말에 IP 주소, 서브넷 마스크, 기본 게이트웨이, DNS 서버 등의 설정을 기한을 두고 자동으로 할당하는 프로토콜.

일본어 명칭: DHCP

DHCP은(는) 네트워크 기초, 네트워크 설계와 운용 등 2개 분야의 연습 문제 4개에 나와요.

분야: 네트워크 기초

도전해 보기: DHCP 관련 문제

DHCP로 단말이 IP 주소를 얻을 때의 메시지 순서로 올바른 것은?

  1. ARequest → Offer → Discover → Ack
  2. BDiscover → Offer → Request → Ack
  3. COffer → Discover → Ack → Request
정답과 해설 보기

정답: B. Discover → Offer → Request → Ack

아직 주소가 없는 단말은 DHCP 서버의 위치도 모르므로 먼저 Discover를 브로드캐스트로 보냅니다. 서버는 빌려줄 수 있는 주소 등을 Offer로 제시하고, 단말은 어느 서버의 제시를 받아들일지를 Request로 알리며, 서버가 Ack로 확정합니다. 머리글자를 따서 DORA라고 부릅니다. 단말은 IP 주소 외에 서브넷 마스크, 기본 게이트웨이, DNS 서버의 주소 등도 받습니다. 주소는 기한(임대 기간)이 있는 대여이며, 단말은 기한이 되기 전에 갱신을 요청합니다. 라우터 너머에 있는 DHCP 서버를 사용하려면 라우터에 DHCP 릴레이를 설정합니다.

VLAN 20(192.168.20.0/24)의 단말에 다른 네트워크에 있는 DHCP 서버 10.0.0.5로부터 주소를 할당한다. 이를 위해 VLAN 20의 기본 게이트웨이인 L3 스위치의 인터페이스(192.168.20.1)에 DHCP 릴레이 에이전트를 설정했다. 릴레이 에이전트의 동작으로 올바른 것은?

  1. A단말이 브로드캐스트로 보낸 DHCP 메시지를 받아, 자신의 VLAN 20 쪽 주소 192.168.20.1을 기록하고 10.0.0.5로 유니캐스트로 전달한다. 서버는 이 주소를 보고 192.168.20.0/24용 범위에서 주소를 고른다
  2. BL3 스위치가 받은 브로드캐스트를 모든 네트워크로 전달하게 되어, DHCP 메시지가 서버에 도달한다
  3. CL3 스위치가 DHCP 서버 대신 주소를 정해 단말에 대여하고, 10.0.0.5에는 결과를 알리기만 하게 된다
정답과 해설 보기

정답: A. 단말이 브로드캐스트로 보낸 DHCP 메시지를 받아, 자신의 VLAN 20 쪽 주소 192.168.20.1을 기록하고 10.0.0.5로 유니캐스트로 전달한다. 서버는 이 주소를 보고 192.168.20.0/24용 범위에서 주소를 고른다

아직 주소가 없는 단말은 DHCP 서버를 찾는 Discover를 브로드캐스트로 보내지만, 라우터나 L3 스위치는 브로드캐스트를 다른 네트워크로 전달하지 않습니다. DHCP 릴레이 에이전트는 이 메시지를 받아 서버로 유니캐스트로 중계하고, 서버의 응답을 단말에 돌려줍니다. 중계할 때는 메시지 안의 필드(giaddr)에 단말 쪽 인터페이스의 주소(여기서는 192.168.20.1)를 기록합니다. 서버는 이 주소를 보고 단말이 있는 서브넷(192.168.20.0/24)을 알아내, 그 서브넷용 범위에서 주소를 고릅니다. 이렇게 하면 VLAN마다 서버를 두지 않아도 DHCP 서버 1대로 많은 서브넷을 담당할 수 있습니다.

  • TCP와 UDP의 차이: 연결·신뢰성·순서·혼잡 제어·헤더·지연·용도 비교TCP와 UDP를 한 장의 표로 비교합니다. 연결 수립, 확인 응답과 재전송, 순서, 데이터 경계, 흐름 제어와 혼잡 제어, 헤더 크기, 지연, 전송 대상의 종류와 대표 용도를 정리합니다.
  • IPv4와 IPv6의 차이: 주소 길이·헤더·프래그먼테이션·주소 설정·NAT 비교IPv4와 IPv6를 한 장의 표로 비교합니다. 주소 길이와 개수, 표기법, 헤더, 단편화(프래그먼테이션), 주소 자동 설정, MAC 주소 확인, NAT, 전송 대상의 종류와 IPsec을 정리합니…
  • DHCPv6와 SLAAC의 차이: IPv6 주소 결정 방식·상태 관리·게이트웨이와 DNS·선택 기준 비교IPv6 주소를 자동으로 설정하는 두 방식인 DHCPv6와 SLAAC(상태 비저장 주소 자동 설정)를 한 장의 표로 비교합니다. 주소를 정하는 주체, 상태, 필요한 것, 쓰는 메시지, 기본 게이트…
