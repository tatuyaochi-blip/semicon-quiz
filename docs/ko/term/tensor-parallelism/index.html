텐서 병렬(Tensor Parallelism)란?

한 층의 가중치 행렬을 행이나 열 방향으로 나누어 여러 GPU에 두고 부분 곱을 구한 뒤 통신으로 합치는 분산 방법.

정답: B. 가중치 행렬을 행 또는 열 방향으로 나누어 각 GPU에 가지게 하고, 부분 곱을 구한 뒤 통신으로 결과를 모은다

텐서 병렬에서는 예를 들어 가중치 행렬을 열 방향으로 4개로 나누어 4개의 GPU에 가지게 하고, 각 GPU가 같은 입력과 자신이 담당하는 열의 곱을 계산합니다. 마지막에 결과를 이어 붙이거나 더하기 위한 통신이 층마다 필요하므로, GPU 사이를 매우 빠른 연결로 이은 같은 서버 안의 GPU에서 사용하는 것이 일반적입니다. 데이터 병렬이나 파이프라인 병렬과 조합하여 거대한 모델을 학습합니다.
