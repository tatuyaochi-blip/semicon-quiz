복귀 주소(return address)란?

함수 처리를 마쳤을 때 돌아갈 번지. RISC-V에서는 jal 명령이 다음 명령의 번지를 ra(x1)에 넣고, x86에서는 call 명령이 스택에 쌓는다.

일본어 명칭: リターンアドレス

복귀 주소(return address)은(는) ISA와 어셈블리, CPU와 아키텍처, 링커, 로더, 실행 파일 등 4개 분야의 연습 문제 10개에 나와요.

정답: A. 스택

서브루틴을 호출하면 복귀 주소, 저장해야 할 레지스터 값, 지역 변수 등이 스택에 쌓입니다. 스택은 나중에 넣은 것을 먼저 꺼내는(LIFO) 구조로, 호출이 중첩되거나 재귀가 되어도 올바른 순서로 돌아올 수 있습니다. 맨 위 위치는 스택 포인터가 가리킵니다. 재귀가 너무 깊어 영역을 다 쓰면 스택 오버플로가 되며, 배열 범위를 넘어 복귀 주소를 덮어쓰는 공격도 있습니다.

해설 속 복귀 주소(return address)

  • 서브루틴을 호출하면 복귀 주소, 저장해야 할 레지스터 값, 지역 변수 등이 스택에 쌓입니다.

    프로그램에서 서브루틴(함수)을 호출할 때 복귀 주소 등을 일시적으로 저장하기 위해 일반적으로 사용되는 영역…

  • 함수 호출에서는 복귀 주소로서 현재 값이 스택이나 링크 레지스터에 저장됩니다.

    CPU의 프로그램 카운터(PC)가 보유하고 있는 것은?

  • 복귀 주소는 x1(ra)에 들어갑니다.

    RISC-V의 레지스터 x0(zero)의 성질로 올바른 것은?

  • 호출 규약에서는 복귀 주소를 ra(x1)에 넣으므로, 함수 호출은 'jal ra, func'이며 의사 명령어로는 'call func'라고 씁니다.

    RISC-V 명령어 'jal ra, func'의 동작으로 올바른 것은?

  • ra는 함수를 호출하는 jal마다 덮어써지므로, 다른 함수를 호출하는 함수는 자신의 복귀 주소를 처음에 스택에 저장해야 합니다.

복귀 주소(return address)이(가) 나오는 문제 (10)

  1. 프로그램에서 서브루틴(함수)을 호출할 때 복귀 주소 등을 일시적으로 저장하기 위해 일반적으로 사용되는 영역은?
  2. CPU의 프로그램 카운터(PC)가 보유하고 있는 것은?
  3. RISC-V의 레지스터 x0(zero)의 성질로 올바른 것은?
  4. RISC-V 명령어 'jal ra, func'의 동작으로 올바른 것은?
  5. 다른 함수를 호출하지 않는 함수(리프 함수)에서는 ra를 스택에 저장하지 않아도 되는 경우가 많다. 그 이유로 올바른 것은?
  6. RISC-V 함수의 시작 부분에서 'addi sp, sp, -16'을 실행하는 목적으로 올바른 것은?
  7. 위의 코드는 어떤 함수의 시작 부분(프롤로그)이다. 이 부분이 하고 있는 일로 올바른 것은?
  8. C 언어의 함수 포인터를 사용한 호출 '(*fp)(x)'는 RISC-V에서 일반적으로 어떤 명령어로 이루어지는가?
  9. 메모리 페이지에 '쓰기 가능'과 '실행 가능'을 동시에 허용하지 않는 것(W^X, 쓰기와 실행의 분리)으로 막기 쉬워지는 공격은 무엇입니까?
  10. 인터럽트나 예외 처리를 마치고 원래 프로그램으로 돌아갈 때, 일반 함수의 리턴 명령이 아니라 전용 복귀 명령(RISC-V의 sret, mret 등)을 사용하는 이유는?
