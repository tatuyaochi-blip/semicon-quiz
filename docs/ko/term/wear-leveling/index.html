웨어 레벨링(Wear Leveling)란?

플래시 메모리의 재기록이 특정 블록에 집중되지 않도록 쓰기 위치를 분산하여 수명을 늘리는 기술.

일본어 명칭: ウェアレベリング

웨어 레벨링(Wear Leveling)은(는) SRAM과 플래시 메모리 등 1개 분야의 연습 문제 3개에 나와요.

분야: SRAM과 플래시 메모리

플래시에 필요한 이유

NAND 플래시는 데이터를 제자리에서 덮어쓸 수 없습니다. 페이지 단위로 프로그램할 수 있지만 소거는 많은 페이지를 담은 블록 전체 단위로만 가능하며, 프로그램/소거(P/E) 사이클마다 터널 산화막이 조금씩 손상됩니다. 따라서 내구성은 셀 종류에 따라 다르며, SLC(single-level cell)는 약 50,000~100,000회, MLC(multi-level cell)는 수천~10,000회, TLC(triple-level cell)는 수천 회, QLC(quad-level cell)는 약 1,000회입니다. 로그나 파일 시스템 메타데이터처럼 자주 갱신되는 하나의 논리 주소가 항상 같은 블록에 쓰인다면, 그 블록은 나머지보다 훨씬 먼저 마모될 것입니다.

FTL을 통한 동작 방식

컨트롤러는 호스트의 논리 블록 주소를 물리 페이지에 매핑하는 플래시 변환 계층(FTL)을 실행합니다. 논리 주소를 갱신할 때마다 다른 곳의 새로 소거된 페이지에 쓰고, 이전 페이지는 무효로 표시만 합니다. 이후 가비지 컬렉션이 블록에 남은 유효 페이지를 다른 곳으로 복사하고 블록을 소거합니다. 동적 웨어 레벨링은 새 쓰기를 소거 횟수가 적은 빈 블록으로 보냅니다. 정적 웨어 레벨링은 거의 바뀌지 않는 콜드 데이터도 재배치해, 그 데이터가 차지하던 거의 마모되지 않은 블록이 다시 순환에 참여하게 하므로 모든 블록이 비슷한 속도로 노화합니다.

쓰기 증폭과 예비 영역

가비지 컬렉션과 정적 웨어 레벨링은 호스트가 요청하지 않은 데이터를 씁니다. 호스트 쓰기에 대한 NAND 쓰기의 비율인 쓰기 증폭 계수(WAF)는 사용 가능한 내구성을 직접 줄입니다. 오버 프로비저닝이라고 부르는 예비 용량 확보와, 어떤 데이터가 삭제되었는지 드라이브에 알려 주는 호스트의 TRIM 명령은 컨트롤러에 작업 여유를 주어 이 계수를 낮춥니다. 드라이브 내구성은 총 기록 바이트 수(TBW)나 일일 드라이브 쓰기 횟수(DWPD)로 표기하며, 대략 용량 × 정격 P/E 사이클 ÷ 쓰기 증폭입니다.

관련 메커니즘과 동작 위치

웨어 레벨링은 마모를 고르게 할 뿐이며, 다른 컨트롤러 기능과 함께 동작합니다. BCH부터 최신 SSD의 LDPC(low-density parity-check) 부호까지의 오류 정정 부호(ECC)는 셀이 노화하며 늘어나는 원시 비트 오류를 정정하고, 배드 블록 관리는 고장 난 블록을 퇴역시킵니다. SSD, USB 드라이브, SD 카드, 임베디드 eMMC 장치는 이 모든 것을 컨트롤러 내부에서 수행하지만, 저가 카드는 단순하게 구현하기도 합니다. 원시 NAND를 프로세서에 직접 연결하는 경우에는 플래시 인식 파일 시스템이나 호스트 소프트웨어가 대신 웨어 레벨링을 제공해야 합니다.

정답: C. 쓰기를 특정 블록에 집중시키지 않고 전체로 분산시켜 수명을 늘린다

블록에는 재기록 횟수의 상한이 있으므로 같은 논리 주소에만 쓰면 그곳만 일찍 수명을 맞습니다. 웨어 레벨링에서는 컨트롤러가 논리 주소와 물리 블록의 대응표(FTL)를 관리하며, 쓰기를 소거 횟수가 적은 블록으로 분배합니다. 재기록이 적은 정적 데이터도 가끔 이동시켜 모든 블록의 소모를 고르게 함으로써 제품 전체의 수명을 늘립니다.

정적 웨어 레벨링과 동적 웨어 레벨링 차이

동적 웨어 레벨링은 새 쓰기에 마모가 적은 빈 블록을 고르고, 정적 웨어 레벨링은 거의 바뀌지 않는 데이터도 마모가 적은 블록에서 옮겨 그 블록들이 쓰기 부하를 분담하게 합니다.

웨어 레벨링으로 쓰기 증폭이 커지나요

정적 웨어 레벨링은 호스트가 바꾸지 않은 데이터를 옮기므로 내부 쓰기가 다소 늘지만, 마모를 고르게 분산하는 이득이 그 비용을 훨씬 웃돕니다.

NAND 플래시 쓰기 가능 횟수

공정과 조건에 따라 다르지만, SLC는 약 50,000~100,000회, MLC는 수천~10,000회, TLC는 수천 회, QLC는 약 1,000회입니다.
