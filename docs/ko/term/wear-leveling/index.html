웨어 레벨링(Wear Leveling)란?

플래시 메모리의 재기록이 특정 블록에 집중되지 않도록 쓰기 위치를 분산하여 수명을 늘리는 기술.

일본어 명칭: ウェアレベリング

웨어 레벨링(Wear Leveling)은(는) SRAM과 플래시 메모리 등 1개 분야의 연습 문제 3개에 나와요.

  2. B데이터를 암호화하여 보호한다
  3. C쓰기를 특정 블록에 집중시키지 않고 전체로 분산시켜 수명을 늘린다
정답과 해설 보기

정답: C. 쓰기를 특정 블록에 집중시키지 않고 전체로 분산시켜 수명을 늘린다

블록에는 재기록 횟수의 상한이 있으므로 같은 논리 주소에만 쓰면 그곳만 일찍 수명을 맞습니다. 웨어 레벨링에서는 컨트롤러가 논리 주소와 물리 블록의 대응표(FTL)를 관리하며, 쓰기를 소거 횟수가 적은 블록으로 분배합니다. 재기록이 적은 정적 데이터도 가끔 이동시켜 모든 블록의 소모를 고르게 함으로써 제품 전체의 수명을 늘립니다.

해설 속 웨어 레벨링(Wear Leveling)

  • 웨어 레벨링에서는 컨트롤러가 논리 주소와 물리 블록의 대응표(FTL)를 관리하며, 쓰기를 소거 횟수가 적은 블록으로 분배합니다.

    SSD 등에서 사용되는 웨어 레벨링의 목적으로 올바른 것은 무엇입니까?

  • USB 메모리나 SD 카드, SSD에는 대용량이고 저렴한 비휘발성 메모리인 NAND 플래시가 사용되며, 내부에는 NAND 칩과 오류 정정이나 웨어 레벨링을 담당하는 컨트롤러가 들어 있습니다.

    USB 메모리나 SD 카드에 주로 사용되는 메모리는 무엇입니까?

  • SSD의 수명은 TBW(총 쓰기량)나 DWPD(하루에 전체 용량을 몇 번 쓸 수 있는가)로 표현되며, 웨어 레벨링이나 여분 영역으로 연장합니다.

    SLC형 NAND 플래시 메모리의 재기록 가능 횟수 기준으로 가장 가까운 것은 무엇입니까?
