아인슈타인 관계식란?

캐리어의 확산 계수 D와 이동도 μ를 잇는 관계식 D = μkT/q. 이동도가 큰 재료일수록 확산도 잘 일어남을 나타낸다.

반도체 캐리어의 확산 계수 D와 이동도 μ의 관계를 나타내는 아인슈타인 관계식은 무엇입니까? (k: 볼츠만 상수, T: 절대 온도, q: 전기 소량)

  1. AD = qμ
  2. BD = μ / (kT)
  3. CD = μkT / q
정답과 해설 보기

정답: C. D = μkT / q

아인슈타인 관계식은 D = μkT/q입니다. 확산도 드리프트도 캐리어가 얼마나 산란되지 않고 움직일 수 있는지로 정해지므로 둘은 비례합니다. 실온에서는 kT/q ≈ 26 mV이므로, 전자(μ ≈ 1400 cm²/V·s)라면 D ≈ 36 cm²/s, 정공(약 450)이라면 약 12 cm²/s입니다. 이동도 표가 있으면 확산 계수를 바로 구할 수 있으며, 확산 길이나 소자 계산에 사용합니다.
