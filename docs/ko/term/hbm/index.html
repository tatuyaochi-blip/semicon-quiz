HBM란?

여러 개의 DRAM 다이를 TSV로 적층하고 매우 넓은 버스 폭으로 높은 대역폭을 구현하는 메모리.

일본어 명칭: HBM

HBM은(는) 첨단 패키징(3D와 칩렛), 반도체 산업과 시장, DRAM 등 10개 분야의 연습 문제 29개에 나와요.

  2. BCPU 칩 안에 내장된 SRAM 캐시
  3. C여러 개의 DRAM 다이를 TSV로 적층하고, 매우 넓은 버스 폭으로 높은 대역폭을 얻는 메모리
정답과 해설 보기

정답: C. 여러 개의 DRAM 다이를 TSV로 적층하고, 매우 넓은 버스 폭으로 높은 대역폭을 얻는 메모리

HBM은 여러 개의 DRAM 다이를 TSV로 쌓아 올리고, 1,024개라는 매우 넓은 데이터 버스로 프로세서와 연결하여 높은 데이터 전송 대역폭을 구현하는 메모리입니다. 예를 들어 HBM3는 핀당 6.4 Gb/s로, 스택 하나에서 약 819 GB/s가 됩니다. 실리콘 인터포저 등의 위에 프로세서와 나란히 배치하는 2.5D 실장에 사용되며, AI용 GPU 등에 탑재됩니다. 플래시나 SRAM 캐시와는 다른 것입니다.

AI용 GPU에서 GPU 칩과 HBM을 하나의 실리콘 인터포저 위에 나란히 실장하는 주된 이유는?

  1. A부품 수를 늘리기 위해
  2. B칩 사이를 매우 많은 배선으로 짧게 연결하여 매우 높은 메모리 대역폭을 얻기 위해
  3. C메모리 용량을 줄이기 위해
정답과 해설 보기

정답: B. 칩 사이를 매우 많은 배선으로 짧게 연결하여 매우 높은 메모리 대역폭을 얻기 위해

HBM은 스택 하나당 1,024개의 데이터선을 가지며 여러 스택을 나란히 놓으면 수천 개가 되므로, 일반 패키지 기판으로는 배선을 다 처리할 수 없습니다. 미세 배선을 만들 수 있는 실리콘 인터포저 위에 GPU와 HBM을 나란히 놓으면, 많은 배선으로 수 mm의 짧은 거리에서 연결할 수 있어 AI 연산에 필요한 수 TB/s의 메모리 대역폭을 구현할 수 있습니다. 부품 수를 늘리거나 용량을 줄이기 위한 것이 아닙니다.

해설 속 HBM

  • HBM은 여러 개의 DRAM 다이를 TSV로 쌓아 올리고, 1,024개라는 매우 넓은 데이터 버스로 프로세서와 연결하여 높은 데이터 전송 대역폭을 구현하는 메모리입니다.

    HBM(High Bandwidth Memory)에 대한 설명으로 올바른 것은?

  • HBM은 스택 하나당 1,024개의 데이터선을 가지며 여러 스택을 나란히 놓으면 수천 개가 되므로, 일반 패키지 기판으로는 배선을 다 처리할 수 없습니다.

    AI용 GPU에서 GPU 칩과 HBM을 하나의 실리콘 인터포저 위에 나란히 실장하는 주된 이유는?

  • HBM에서는 TSV로 연결한 DRAM 다이를 8장, 12장, 나아가 16장까지 쌓고, 최하부의 베이스 다이(로직 다이)와 조합하여 하나의 스택으로 만듭니다.

    HBM에서 하나의 스택에 쌓을 수 있는 DRAM 다이의 수로 일반적인 것은?

  • HBM의 베이스 다이는 적층된 DRAM 다이와 프로세서 사이의 신호 교환을 담당하며, 테스트나 불량 셀 구제를 위한 회로 등도 갖추고 있습니다.

    HBM의 최하층에 있는 베이스 다이(로직 다이)의 역할로 올바른 것은?

  • 인터포저는 노광 범위의 몇 배 크기까지 만들 수 있게 되었고, AI용 GPU와 여러 HBM의 연결에 널리 사용되고 있습니다.

이 용어가 포함된 비교

  • CPU와 GPU의 구조와 용도 차이CPU와 GPU를 표로 비교합니다. 설계 목표, 코어 수, 실행 모델, 캐시, 메모리 대역폭, 분기 처리, 데이터 전송, 대표 워크로드를 다룹니다.
  • DDR, LPDDR, GDDR, HBM: DRAM 종류 비교DDR, LPDDR, GDDR, HBM을 표로 비교합니다. 대상 기기, 버스 폭, 속도, 대역폭, 전력, 패키징, 용량, 비용을 다룹니다.
