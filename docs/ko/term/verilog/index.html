Verilog란?

디지털 회로의 설계와 검증에 널리 사용되는 하드웨어 기술 언어. module을 단위로 회로를 쓰고 assign과 always로 동작을 나타낸다.

일본어 명칭: Verilog

Verilog은(는) HDL과 검증, IC 설계 흐름과 EDA 등 2개 분야의 연습 문제 21개에 나와요.

분야: HDL과 검증

module, assign, always

Verilog 설계는 모듈로 구성되며, 각 모듈은 입력·출력 포트를 선언한 하나의 회로 블록입니다. 모듈은 다른 모듈 안에 필요한 만큼 인스턴스화하고 포트끼리 연결할 수 있으므로, 칩은 부품의 계층 구조로 기술됩니다. 모듈 안에서 assign y = (a & b) | c 같은 연속 할당은 출력이 항상 입력을 따르는 조합 논리를 기술합니다. always 블록은 이벤트로 트리거되는 동작을 기술합니다. always @(posedge clk)는 에지 트리거 플립플롭이 되고, always @(*)는 읽는 신호 중 하나라도 바뀌면 다시 평가되어 조합 논리를 기술합니다.

순서가 아니라 하드웨어로 생각하기

Verilog는 프로그래밍 언어처럼 보이지만, 모든 assign 문과 always 블록은 파일 안의 순서와 관계없이 동시에 동작합니다. 클록 블록에서 논블로킹 할당(<=)은 모든 우변을 에지 이전 값으로 평가한 뒤 한꺼번에 갱신하므로, 동시에 값을 받아들이는 플립플롭과 일치합니다. 블로킹 할당(=)은 위에서 아래로 중간값을 계산하는 조합 블록에 적합합니다. reg로 선언한 신호가 반드시 레지스터인 것은 아닙니다. always @(*)에서 할당되면 조합 논리입니다. 조합 블록에서 else 없는 if는 기억을 의미하므로 의도하지 않은 래치가 추론됩니다. 할당 시 값이 조용히 잘리므로 비트 폭도 중요하며, 신호는 signed로 선언하지 않는 한 부호 없는 값입니다.

시뮬레이션 의미론과 4값 논리

Verilog 시뮬레이터는 이벤트 구동 방식으로, 입력이 바뀐 논리만 다시 평가합니다. 한 사이클에 토글하는 신호는 적으므로 효율적입니다. 신호는 0, 1, 미지값 X, 고임피던스 Z의 네 가지 값을 가집니다. 초기화되지 않은 레지스터와 충돌하는 드라이버는 X를, 구동되지 않는 넷은 Z를 만들므로, 파형에서 이 값들이 보이면 강력한 디버깅 단서가 됩니다. 일부 의미론은 낙관적입니다. if 문은 X 조건을 거짓으로 취급하므로, 실제 하드웨어라면 드러났을 버그를 숨깁니다. == 연산자는 피연산자에 X나 Z가 있으면 X를 반환하고, ===는 이를 문자 그대로 비교하며 테스트벤치에서만 사용합니다.

Verilog, SystemVerilog, VHDL

Verilog의 일부만 합성 가능합니다. #10 같은 지연, $display, 파일 입출력은 시뮬레이션 전용이며 합성에서는 무시되므로, 테스트벤치에서는 자유롭게 써도 되지만 RTL에서는 쓰지 말아야 합니다. 후속 표준인 SystemVerilog는 wire와 reg의 구분을 대부분 없애는 logic 타입과, 설계자의 의도를 명시해 도구가 래치 추론을 지적할 수 있게 하는 always_ff, always_comb를 추가했습니다. 또한 어서션과 클래스 같은 방대한 검증 기능도 추가했습니다. VHDL은 또 하나의 주요 하드웨어 기술 언어로, 타입이 더 엄격하고 기술이 더 장황하며, 둘 다 RTL 설계에 사용됩니다.

  3. CHDL에서는 변수나 조건 분기를 사용할 수 없다
정답과 해설 보기

정답: A. HDL 기술은 동시에 병렬로 동작하는 회로를 나타낸다

HDL은 겉보기에는 프로그램과 비슷하지만, 작성한 내용은 논리 합성을 통해 게이트와 플립플롭으로 이루어진 회로가 됩니다. 회로의 각 부분은 항상 동시에 동작하므로, 여러 assign문이나 always 블록은 작성한 순서와 관계없이 병렬로 동작합니다. 소프트웨어처럼 '이 처리가 끝나면 다음'이라고 생각하면 의도한 회로가 되지 않으므로, 어떤 회로가 만들어질지 상상하면서 작성하는 것이 중요합니다.

Verilog에서 module을 사용하는 목적으로 올바른 것은?

  1. A입력과 출력 단자(포트)를 가진 회로의 부품을 정의하여 다른 module 안에서 사용할 수 있게 한다
  2. B프로그램의 실행을 일시적으로 멈춘다
  3. C시뮬레이션 결과를 화면에 표시한다
정답과 해설 보기

정답: A. 입력과 출력 단자(포트)를 가진 회로의 부품을 정의하여 다른 module 안에서 사용할 수 있게 한다

module은 입력과 출력 포트를 가진 회로의 묶음을 정의하는 단위로, 가산기나 카운터, CPU 전체 등을 나타냅니다. 정의한 module은 다른 module 안에서 부품으로 몇 번이든 사용할 수 있으며(인스턴스화), 포트를 배선으로 연결하여 큰 회로를 조립합니다. 기판 위에 부품을 배치하고 배선하는 것과 마찬가지로, 회로를 계층적으로 만들 수 있습니다.

자주 묻는 질문

Verilog에서 wire와 reg의 차이는 무엇인가요?

wire는 연속 할당이나 모듈 출력으로 구동되고, reg는 always 블록이나 initial 블록 안에서 할당됩니다. reg는 클록 에지에서 갱신될 때만 플립플롭이 되며, always @(*) 안에서는 조합 논리입니다.

블로킹 할당(=)과 논블로킹 할당(<=)은 언제 쓰나요?

플립플롭을 기술하는 클록 always 블록에서는 논블로킹 할당을, 조합 always 블록에서는 블로킹 할당을 사용합니다. 한 블록에서 둘을 섞거나 순차 논리에 블로킹 할당을 쓰면 시뮬레이션 결과가 문장 순서에 의존하게 되어 하드웨어와 달라질 수 있습니다.

Verilog와 SystemVerilog의 차이는 무엇인가요?

SystemVerilog는 Verilog의 상위 집합으로, logic 타입, always_ff, always_comb 같은 설계 편의 기능과, 어서션, 제약 조건 랜덤 자극, 객체 지향 테스트벤치 같은 검증 기능을 추가했습니다.
