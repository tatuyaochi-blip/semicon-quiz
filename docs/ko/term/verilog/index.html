Verilog란?

べりろぐ

デジタル回路の設計と検証に広く使われるハードウェア記述言語。moduleを単位に回路を書き、assignやalwaysで動作を表す。

일본어 명칭: Verilog

Verilog은(는) IC 설계 흐름과 EDA 등 1개 분야의 연습 문제 5개에 나와요.

분야: HDL과 검증

도전해 보기: Verilog 관련 문제

일반적인 디지털 LSI 설계 흐름의 순서로 올바른 것은?

  1. A사양 설계 → RTL 설계 → 논리 합성 → 배치 배선
  2. B논리 합성 → 사양 설계 → 배치 배선 → RTL 설계
  3. C배치 배선 → RTL 설계 → 논리 합성 → 사양 설계
정답과 해설 보기

정답: A. 사양 설계 → RTL 설계 → 논리 합성 → 배치 배선

먼저 사양 설계에서 기능과 성능을 정하고, Verilog나 VHDL 같은 하드웨어 기술 언어로 RTL 설계를 합니다. 다음으로 논리 합성에서 게이트 레벨 넷리스트로 변환하고, 배치 배선에서 칩 상의 레이아웃을 만듭니다. 각 단계에서 검증을 수행하고, 마지막으로 마스크 데이터로 출력합니다. 추상도가 높은 기술에서 구체적인 형태로 차례로 풀어 가는 흐름이므로 다른 순서는 성립하지 않습니다. 선단 제품에서는 사양 결정부터 테이프아웃까지 1~2년이 걸리기도 합니다.

RTL 설계에서 주로 사용되는 하드웨어 기술 언어는?

  1. AVerilog HDL이나 VHDL
  2. BHTML
  3. CSQL
정답과 해설 보기

정답: A. Verilog HDL이나 VHDL

RTL 설계에서는 Verilog HDL(및 그 확장인 SystemVerilog)이나 VHDL 같은 하드웨어 기술 언어로, 클록마다 레지스터 사이에서 데이터가 어떻게 흐르는지를 기술합니다. 소프트웨어 언어와 달리 기술한 처리는 회로로서 동시 병렬로 동작합니다. HTML은 웹 페이지 기술 언어, SQL은 데이터베이스 질의 언어로, 회로를 기술할 수 없습니다.
