DIMM(듀얼 인라인 메모리 모듈)란?

작은 기판에 DRAM 칩 여러 개를 실장하여 PC나 서버의 슬롯에 꽂을 수 있게 한 메모리 모듈입니다.

일본어 명칭: DIMM

DIMM(듀얼 인라인 메모리 모듈)은(는) DRAM 등 1개 분야의 연습 문제 1개에 나와요.

분야: DRAM

정답과 해설 보기

정답: C. DIMM(메모리 모듈)

DIMM(Dual Inline Memory Module)은 여러 DRAM 칩을 1장의 기판에 실장한 모듈로, 앞뒤 단자가 서로 다른 신호를 가지기 때문에 「듀얼」이라 불립니다. 마더보드의 슬롯에 꽂아 교체와 증설을 할 수 있으며, 노트북용 소형 제품은 SO-DIMM입니다. 서버용으로는 신호를 버퍼링하는 RDIMM이 있고, DDR5에서는 모듈 위에 전원 회로(PMIC)도 얹혀 있습니다.
