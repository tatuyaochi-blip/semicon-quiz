하드웨어 기술 언어(HDL)란?

디지털 회로의 구조와 동작을 문장으로 기술하기 위한 언어. HDL. Verilog, SystemVerilog, VHDL이 있으며 논리 합성으로 회로로 변환한다.

일본어 명칭: ハードウェア記述言語

하드웨어 기술 언어(HDL)은(는) HDL과 검증, IC 설계 흐름과 EDA, 논리 회로 등 3개 분야의 연습 문제 11개에 나와요.

분야: HDL과 검증

HDL이 기술하는 것

하드웨어 기술 언어는 명령어의 순서가 아니라 회로를 기술합니다. 모든 assign 문, always 블록, 모듈 인스턴스는 항상 동작하는 하드웨어를 나타내므로, 코드의 순서가 실행 순서를 뜻하지 않습니다. 설계는 보통 레지스터 전송 수준(RTL)으로 작성합니다. 즉 클록 에지에서 갱신되는 레지스터와, 그 다음 값을 계산하는 조합 로직입니다. 주요 언어는 Verilog, 그 확장인 SystemVerilog, 그리고 타입이 더 엄격한 VHDL입니다. 각 언어에서 합성 가능한 부분 집합만 게이트로 매핑되며, 나머지는 시뮬레이션과 검증을 위해 존재합니다.

합성 가능한 RTL 작성

always @(posedge clk) 같은 클록 블록은 플립플롭이 되며, 관례적으로 논블로킹 할당(<=)을 씁니다. 조합 블록은 @(*)나 always_comb와 블로킹 할당(=)을 써야 하며, 예를 들어 default case를 두어 모든 경로에서 모든 출력을 할당해야 합니다. 그렇지 않으면 합성이 래치를 추론합니다. for 루프는 병렬 하드웨어로 펼쳐지므로, 8비트에 대한 루프는 가산기 8개가 됩니다. 상태 머신은 상태 레지스터, 다음 상태 로직, 출력 로직을 조합합니다. 트라이스테이트 출력은 칩 외부의 양방향 핀용으로 남겨 두고, 내부 선택에는 멀티플렉서를 씁니다.

HDL을 이용한 검증

같은 언어로 검증 환경도 만듭니다. 테스트벤치는 검증 대상 설계(DUT)를 인스턴스화하고 클록, 리셋, 자극을 생성하며 출력을 검사합니다. 테스트벤치는 합성되지 않으므로 지연, 파일 입출력, 출력 문을 쓸 수 있습니다. SystemVerilog는 클래스, 제약 기반 랜덤 자극, 기능 커버리지, 어서션을 추가하며, UVM은 재사용 가능한 테스트벤치를 위한 표준 클래스 라이브러리를 제공합니다. 린트 도구는 비트 폭 불일치, 추론된 래치, 합성 불가능한 구문을 정적으로 검사합니다. 검증에는 설계 자체와 같거나 그보다 많은 노력이 드는 경우가 많습니다.

설계 흐름 속의 HDL

HDL은 사양과 게이트 수준 넷리스트 사이에 위치합니다. 엔지니어는 사양으로부터 RTL을 작성해 시뮬레이션하고, 이어서 논리 합성이 공정 설계 키트(PDK)와 타이밍 제약에 따라 이를 파운드리 라이브러리의 셀에 매핑합니다. 이런 식으로 동작을 기술하기 때문에 대규모 설계가 가능합니다. 32비트 가산기만 해도 진리표로는 2⁶⁴행이 필요합니다. 고위 합성은 C나 C++로부터 RTL을 생성해 추상화를 더 높이며, FPGA 도구는 같은 HDL을 받아 표준 셀 대신 룩업 테이블에 매핑합니다.

정답과 해설 보기

정답: A. Verilog HDL이나 VHDL

RTL 설계에서는 Verilog HDL(및 그 확장인 SystemVerilog)이나 VHDL 같은 하드웨어 기술 언어로, 클록마다 레지스터 사이에서 데이터가 어떻게 흐르는지를 기술합니다. 소프트웨어 언어와 달리 기술한 처리는 회로로서 동시 병렬로 동작합니다. HTML은 웹 페이지 기술 언어, SQL은 데이터베이스 질의 언어로, 회로를 기술할 수 없습니다.

Verilog 등의 HDL로 작성한 기술과 C 언어 등의 소프트웨어 프로그램의 큰 차이로 올바른 것은?

  1. AHDL 기술은 동시에 병렬로 동작하는 회로를 나타낸다
  2. BHDL 기술은 위쪽 줄부터 한 줄씩 순서대로 실행되는 명령의 나열이다
  3. CHDL에서는 변수나 조건 분기를 사용할 수 없다
정답과 해설 보기

정답: A. HDL 기술은 동시에 병렬로 동작하는 회로를 나타낸다

HDL은 겉보기에는 프로그램과 비슷하지만, 작성한 내용은 논리 합성을 통해 게이트와 플립플롭으로 이루어진 회로가 됩니다. 회로의 각 부분은 항상 동시에 동작하므로, 여러 assign문이나 always 블록은 작성한 순서와 관계없이 병렬로 동작합니다. 소프트웨어처럼 '이 처리가 끝나면 다음'이라고 생각하면 의도한 회로가 되지 않으므로, 어떤 회로가 만들어질지 상상하면서 작성하는 것이 중요합니다.

자주 묻는 질문

Verilog와 VHDL의 차이점

둘 다 RTL로 하드웨어를 기술하며 합성 도구와 시뮬레이션 도구에서 지원됩니다. Verilog는 간결한 C 비슷한 문법을 가지며, VHDL은 더 장황하고 타입이 엄격합니다. SystemVerilog는 Verilog에 주요 검증 기능을 추가한 확장입니다.

HDL은 프로그래밍 언어인가요?

겉보기에는 그렇지만, 합성 가능한 HDL 코드는 순서대로 실행되는 명령어가 아니라 동시에 동작하는 하드웨어를 기술합니다. 각 줄이 회로 면적을 차지하므로 설계자는 단계가 아니라 레지스터와 로직의 관점에서 생각합니다.

Verilog에서 블로킹 할당과 논블로킹 할당은 언제 쓰나요?

일반적인 지침은 클록 always 블록에는 논블로킹(<=), 조합 블록에는 블로킹(=)을 쓰는 것입니다. 한 블록에서 둘을 섞으면 시뮬레이션과 합성 결과가 어긋나는 흔한 원인이 됩니다.
