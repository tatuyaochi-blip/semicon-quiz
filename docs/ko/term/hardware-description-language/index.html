하드웨어 기술 언어(HDL)란?

디지털 회로의 구조와 동작을 문장으로 기술하기 위한 언어. HDL. Verilog, SystemVerilog, VHDL이 있으며 논리 합성으로 회로로 변환한다.

일본어 명칭: ハードウェア記述言語

하드웨어 기술 언어(HDL)은(는) HDL과 검증, IC 설계 흐름과 EDA, 논리 회로 등 3개 분야의 연습 문제 11개에 나와요.

분야: HDL과 검증

도전해 보기: 하드웨어 기술 언어(HDL) 관련 문제

RTL 설계에서 주로 사용되는 하드웨어 기술 언어는?

  1. AVerilog HDL이나 VHDL
  2. BHTML
  3. CSQL
정답과 해설 보기

정답: A. Verilog HDL이나 VHDL

RTL 설계에서는 Verilog HDL(및 그 확장인 SystemVerilog)이나 VHDL 같은 하드웨어 기술 언어로, 클록마다 레지스터 사이에서 데이터가 어떻게 흐르는지를 기술합니다. 소프트웨어 언어와 달리 기술한 처리는 회로로서 동시 병렬로 동작합니다. HTML은 웹 페이지 기술 언어, SQL은 데이터베이스 질의 언어로, 회로를 기술할 수 없습니다.

Verilog 등의 HDL로 작성한 기술과 C 언어 등의 소프트웨어 프로그램의 큰 차이로 올바른 것은?

  1. AHDL 기술은 동시에 병렬로 동작하는 회로를 나타낸다
  2. BHDL 기술은 위쪽 줄부터 한 줄씩 순서대로 실행되는 명령의 나열이다
  3. CHDL에서는 변수나 조건 분기를 사용할 수 없다
정답과 해설 보기

정답: A. HDL 기술은 동시에 병렬로 동작하는 회로를 나타낸다

HDL은 겉보기에는 프로그램과 비슷하지만, 작성한 내용은 논리 합성을 통해 게이트와 플립플롭으로 이루어진 회로가 됩니다. 회로의 각 부분은 항상 동시에 동작하므로, 여러 assign문이나 always 블록은 작성한 순서와 관계없이 병렬로 동작합니다. 소프트웨어처럼 '이 처리가 끝나면 다음'이라고 생각하면 의도한 회로가 되지 않으므로, 어떤 회로가 만들어질지 상상하면서 작성하는 것이 중요합니다.

  • 테스트벤치는 검증할 회로(DUT)를 인스턴스화하고, 클럭이나 리셋, 입력 신호를 만들어 주어 출력을 관찰하기 위한 HDL 기술입니다.
