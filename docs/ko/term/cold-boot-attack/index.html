콜드 부트 공격(cold boot attack)란?

전원을 끈 뒤에도 잠시 남아 있는 DRAM 내용을 읽어 키 등의 비밀을 빼내는 공격으로, 냉각하면 유지 시간이 늘어납니다. 메모리 암호화로 방어합니다.

일본어 명칭: コールドブート攻撃

콜드 부트 공격(cold boot attack)은(는) 하드웨어 보안, DRAM 등 2개 분야의 연습 문제 2개에 나와요.

콜드 부트 공격(cold boot attack)이 성립하는 이유와 대표적인 대책의 조합으로 올바른 것은?

  1. ADRAM은 전원을 끄면 순식간에 완전히 사라진다. 전원을 켜 둔 채로 둔다
  2. BDRAM은 따뜻하게 하면 내용을 읽기 쉬워진다. 냉각 장치를 단다
  3. CDRAM의 내용은 전원을 꺼도 수 초에서 수 분 남아 있고, 냉각하면 더 오래 남는다. 메모리 내용을 암호화해 둔다
정답과 해설 보기

정답: C. DRAM의 내용은 전원을 꺼도 수 초에서 수 분 남아 있고, 냉각하면 더 오래 남는다. 메모리 내용을 암호화해 둔다

DRAM 셀의 전하는 리프레시가 없어져도 곧바로 사라지지 않아, 수 초에서 수 분 동안 내용이 상당히 남아 있고 저온에서는 더 오래 남습니다. 전원을 끈 직후의 PC에서 메모리를 꺼내 다른 기기로 읽어 내면 디스크 암호의 키 등이 발견되는 경우가 있습니다. 메모리 내용을 회로로 암호화하거나, 전원을 끌 때 키를 지우거나, 키를 CPU 안에만 두는 등의 대책이 있습니다.

해설 속 콜드 부트 공격(cold boot attack)

  • 다만 전원을 끈 직후에 냉각하면 몇 초~몇 분간 데이터가 남는 경우가 있어, 이를 악용해 메모리 속 암호 키를 읽어내는 「콜드 부트 공격」이 알려져 있습니다.
