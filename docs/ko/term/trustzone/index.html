TrustZone란?

Arm 프로세서의 보안 구조. 시큐어 월드와 노멀 월드를 전환하고 버스 신호로 메모리와 주변 회로에 대한 접근을 구분해 제한한다.

일본어 명칭: TrustZone

TrustZone은(는) 하드웨어 보안 등 1개 분야의 연습 문제 2개에 나와요.

분야: 하드웨어 보안

하나의 프로세서 안의 두 월드

TrustZone은 Arm 코어에 시큐어 월드와 노멀 월드라는 두 가지 보안 상태를 부여합니다. 리치 운영체제와 일반 애플리케이션은 노멀 월드에서 실행되고, 작은 신뢰 OS와 그 신뢰 애플리케이션은 시큐어 월드에서 실행됩니다. Cortex-A 프로세서에서 둘 사이의 전환은 SMC(secure monitor call) 명령으로 진입하는 시큐어 모니터를 거치며, 시큐어 모니터는 한쪽 월드의 컨텍스트를 저장하고 다른 쪽 월드의 컨텍스트를 복원합니다. 같은 코어, 캐시, 메모리 시스템을 두 월드가 시분할로 공유하므로, 별도의 보안 프로세서를 추가하지 않고도 하나의 시스템 온 칩(SoC) 안에 보안 영역이 만들어집니다.

버스가 격리를 강제하는 방식

보안 상태는 단순한 소프트웨어 관례가 아닙니다. 코어가 온칩 버스에 내보내는 모든 트랜잭션에는 시큐어인지 논시큐어인지를 표시하는 신호가 붙습니다. DRAM, 온칩 SRAM, 주변 장치 앞에 있는 주소 공간 컨트롤러가 이 신호를 확인해, 시큐어 월드에 할당된 영역에 대한 논시큐어 접근을 거부합니다. 지문 센서 인터페이스나 암호 엔진 같은 주변 장치도 마찬가지로 시큐어 소프트웨어 전용으로 지정할 수 있으며, 캐시는 라인에 월드 태그를 붙입니다. 그 결과 노멀 월드 커널이 완전히 장악되더라도 하드웨어가 접근 자체를 차단하므로 시큐어 메모리를 읽을 수 없습니다.

신뢰 실행 환경으로서의 TrustZone

신뢰 실행 환경(TEE)은 메인 OS가 장악되더라도 살아남아야 하는 작업을 위한, 하드웨어로 격리된 작은 환경입니다. TrustZone은 스마트폰과 그와 비슷한 기기에서 TEE의 기반으로 가장 널리 쓰입니다. 대표적인 시큐어 월드 작업은 생체 정보 대조, 결제 자격 증명 처리, 디지털 저작권 관리(DRM) 키 저장, 시큐어 부트 중의 검증 단계입니다. 핵심은 신뢰 코드 기반을 작게 유지하는 것입니다. 거대한 OS에서 취약점을 모두 없앨 수는 없지만, 인터페이스가 좁은 간결한 신뢰 OS는 검토하고 강화하기가 훨씬 쉽습니다.

TrustZone과 별도의 시큐어 엘리먼트

TrustZone은 소프트웨어를 논리적으로 격리하지만, 코어, 캐시, 전원 레일 같은 물리 자원은 노멀 월드와 공유합니다. 그래서 비용은 낮지만, 전용 칩이라면 더 잘 견딜 수 있는 사이드 채널 공격과 폴트 주입 공격에 노출됩니다. 시큐어 엘리먼트는 자체 프로세서와 메모리를 갖춘 변조 방지형 별도 칩으로, 가장 중요한 키를 위해 TEE와 함께 사용되는 경우가 많습니다. 마이크로컨트롤러급 Armv8-M 코어는 더 가벼운 TrustZone 변형을 구현하며, 여기서는 모니터 없이 시큐어 코드와 논시큐어 코드가 정해진 진입점을 통해 서로를 직접 호출합니다.

정답과 해설 보기

정답: C. CPU가 시큐어 월드와 노멀 월드의 상태를 가지며, 버스 신호 등으로 메모리나 주변 회로에 대한 읽기/쓰기가 어느 월드에서 온 것인지를 구별하여 제한한다

TrustZone에서는 CPU 코어가 시큐어와 노멀의 두 상태를 전환하며 동작하고, 읽기/쓰기마다 지금 어느 상태인지를 나타내는 신호가 버스에 나옵니다. 메모리나 주변 회로 쪽 회로가 이 신호를 보고, 시큐어에 할당한 영역에 대한 노멀 쪽 접근을 거부합니다. 전용 칩을 추가하지 않고 하나의 SoC 안에서 안전한 영역을 만들 수 있으므로 스마트폰 등에서 널리 사용됩니다.

자주 묻는 질문

Arm TrustZone은 어디에 사용되나요?

생체 정보 대조, 결제 처리, 키 저장, 시큐어 부트 검사처럼 보안상 중요한 코드를 하드웨어로 격리된 시큐어 월드에서 실행하는 데 사용됩니다. 일반 운영체제가 장악되더라도 시큐어 월드의 메모리와 키에는 접근할 수 없습니다.

TrustZone과 TEE의 차이는 무엇인가요?

TEE는 하드웨어로 보호되는 격리된 실행 환경이라는 일반적인 개념입니다. TrustZone은 TEE의 신뢰 OS와 애플리케이션이 그 위에 구축되는 격리를 제공하는 Arm의 하드웨어 메커니즘입니다.

TrustZone은 노멀 월드가 시큐어 메모리를 읽지 못하게 어떻게 막나요?

각 버스 트랜잭션에는 그것이 시큐어 상태에서 왔는지 노멀 상태에서 왔는지를 나타내는 신호가 붙습니다. 메모리와 주변 장치 앞의 컨트롤러가 이 신호를 확인해 시큐어 영역에 대한 노멀 월드의 접근을 거부합니다.
