BSS 섹션란?

초기값이 없는(또는 0인) 전역 변수와 정적 변수의 영역. 파일에는 크기만 기록하고 로드 시 0으로 채우므로 실행 파일을 크게 만들지 않는다.

일본어 명칭: BSSセクション

BSS 섹션은(는) 링커, 로더, 실행 파일 등 1개 분야의 연습 문제 2개에 나와요.

분야: 링커, 로더, 실행 파일

.bss에 들어가는 것

C 언어는 정적 저장 기간을 가진 모든 객체, 즉 전역 변수와 static 변수가 초기값이 주어지지 않으면 0에서 시작하도록 요구합니다. 컴파일러는 이런 변수와, 대개 명시적으로 0으로 초기화된 변수도 .bss 섹션에 배치합니다. 0이 아닌 초기값을 가진 전역 변수는 .data에, const로 한정된 상수는 읽기 전용인 .rodata에 들어갑니다. static 키워드는 섹션을 결정하지 않으며, 가시 범위를 한 파일로 제한할 뿐입니다. 지역 자동 변수는 스택에 존재하고 정해진 초기값이 없으므로 .bss에 들어가지 않습니다.

.bss가 파일 공간을 차지하지 않는 이유

실행 파일에 길게 이어진 0을 저장하면 디스크 공간과 로드 시간만 낭비되므로, .bss 섹션에는 크기와 정렬만 기록됩니다. ELF에서는 파일 바이트를 차지하지 않는 섹션으로 표시됩니다. 로더는 .data와 .bss를 포함한 읽기·쓰기 세그먼트를 매핑하고, 세그먼트의 메모리 크기가 파일 크기보다 큰 부분은 0으로 채운 페이지로 제공합니다. 그 결과 static char buf[1000000]; 같은 선언은 메모리 사용량을 약 1 MB 늘리지만 파일 크기는 거의 늘리지 않습니다.

임베디드 시스템의 BSS

운영체제가 없는 마이크로컨트롤러에서는 메모리를 0으로 채워 주는 주체가 없으므로 스타트업 코드가 이를 수행합니다. main을 호출하기 전에 리셋 핸들러는 보통 .data의 초기값을 플래시에서 RAM으로 복사하고, 링커 스크립트가 심볼로 내보낸 시작·끝 주소를 이용해 RAM의 .bss 영역을 0으로 지웁니다. 둘 중 하나라도 빠뜨리면 전역 변수가 쓰레기 값을 갖게 됩니다. size 명령 같은 도구는 text, data, bss를 따로 보고하므로 플래시와 RAM 사용량을 추정하는 데 유용합니다.

이름의 유래

BSS는 흔히 block started by symbol의 약자로 풀이되며, 레이블 아래에 초기화되지 않은 저장 블록을 예약하던 초기 IBM 메인프레임 어셈블러 지시어에서 물려받은 이름입니다. 지시어 자체는 오래전에 사라졌지만 그 의미는 Unix 오브젝트 형식과 이후의 ELF로 이어졌습니다. 오늘날 이 이름은 코드용 .text, 초기화된 데이터용 .data, 상수용 .rodata와 함께 단순히 0으로 초기화되는 데이터 섹션을 가리킵니다.

  3. C상수 문자열을 두는 쓰기 불가 영역이다
정답과 해설 보기

정답: B. 초기값이 없는(또는 0인) 변수의 영역이며, 파일에는 크기만 기록하고 읽어 들일 때 0으로 채운다

초기값을 쓰지 않은 전역 변수나 정적 변수는 C 언어의 규칙상 0에서 시작합니다. 내용이 모두 0이라면 파일에 0을 나열하여 저장하는 것은 낭비이므로, .bss 섹션에는 크기만 기록하고 로더가 메모리를 확보하여 0으로 채웁니다. 예를 들어 'static char buf[1000000];'이 있어도 실행 파일이 1 MB 커지지는 않습니다.

자주 묻는 질문

BSS는 무엇의 약자인가요?

BSS는 옛 어셈블러 지시어에서 유래해 보통 block started by symbol로 풀이됩니다. 현대 툴체인에서는 단순히 0으로 초기화되는 전역 변수와 static 변수를 위한 섹션의 이름입니다.

초기화하지 않은 큰 배열은 실행 파일 크기를 늘리나요?

아닙니다. 초기값이 없는 전역 배열이나 static 배열은 .bss에 들어가며 크기만 기록됩니다. 메모리는 프로그램이 로드될 때 할당되고 0으로 채워집니다.

.data와 .bss의 차이는 무엇인가요?

.data 섹션은 0이 아닌 초기값을 가진 전역 변수와 static 변수를 담으며, 이 값들은 파일에 저장되어야 합니다. .bss 섹션은 0에서 시작하는 변수를 담으므로 실행 시 메모리는 차지하지만 파일에 내용을 위한 공간은 차지하지 않습니다.

해설 속 BSS 섹션
