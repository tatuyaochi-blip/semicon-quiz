BSS 섹션란?

초기값이 없는(또는 0인) 전역 변수와 정적 변수의 영역. 파일에는 크기만 기록하고 로드 시 0으로 채우므로 실행 파일을 크게 만들지 않는다.

일본어 명칭: BSSセクション

BSS 섹션은(는) 링커, 로더, 실행 파일 등 1개 분야의 연습 문제 2개에 나와요.

분야: 링커, 로더, 실행 파일

도전해 보기: BSS 섹션 관련 문제

.bss 섹션의 특징으로 올바른 것은 무엇입니까?

  1. A함수의 지역 변수를 호출될 때마다 두는 영역이다
  2. B초기값이 없는(또는 0인) 변수의 영역이며, 파일에는 크기만 기록하고 읽어 들일 때 0으로 채운다
  3. C상수 문자열을 두는 쓰기 불가 영역이다
정답과 해설 보기

정답: B. 초기값이 없는(또는 0인) 변수의 영역이며, 파일에는 크기만 기록하고 읽어 들일 때 0으로 채운다

초기값을 쓰지 않은 전역 변수나 정적 변수는 C 언어의 규칙상 0에서 시작합니다. 내용이 모두 0이라면 파일에 0을 나열하여 저장하는 것은 낭비이므로, .bss 섹션에는 크기만 기록하고 로더가 메모리를 확보하여 0으로 채웁니다. 예를 들어 'static char buf[1000000];'이 있어도 실행 파일이 1 MB 커지지는 않습니다.

해설 속 BSS 섹션

  • 내용이 모두 0이라면 파일에 0을 나열하여 저장하는 것은 낭비이므로, .bss 섹션에는 크기만 기록하고 로더가 메모리를 확보하여 0으로 채웁니다.
