호출 규약(Calling Convention)란?

함수를 호출할 때 인수와 반환값을 어떤 레지스터나 스택으로 주고받는지, 어떤 레지스터를 누가 저장하는지 등을 정한 약속. ABI의 중요한 일부.

일본어 명칭: 呼び出し規約

호출 규약(Calling Convention)은(는) ISA와 어셈블리 등 1개 분야의 연습 문제 9개에 나와요.

분야: ISA와 어셈블리

도전해 보기: 호출 규약(Calling Convention) 관련 문제

호출 규약(콜링 컨벤션)이 정해져 있는 주된 목적은?

  1. A함수 이름 짓는 방식을 통일하여 프로그램을 읽기 쉽게 한다
  2. B따로 컴파일한 함수나 라이브러리끼리 인자와 반환값을 올바르게 주고받을 수 있게 한다
  3. C함수를 호출할 때마다 OS의 허가를 받도록 한다
정답과 해설 보기

정답: B. 따로 컴파일한 함수나 라이브러리끼리 인자와 반환값을 올바르게 주고받을 수 있게 한다

호출 규약은 인자를 어느 레지스터에 넣는지, 반환값은 어디로 돌려주는지, 호출받은 쪽이 어느 레지스터를 망가뜨려도 되는지, 스택을 어떻게 사용하는지를 정합니다. 이 약속이 있으므로 다른 컴파일러로 만든 라이브러리나, 어셈블리로 작성한 함수와 C 언어 함수를 조합해도 올바르게 동작합니다. 호출 규약은 ABI(애플리케이션 바이너리 인터페이스)의 중요한 일부입니다.

RISC-V의 표준 호출 규약에서 정수 인자와 반환값을 전달하는 데 사용하는 레지스터로 올바른 것은?

  1. A인자는 s0~s7, 반환값은 ra
  2. B인자는 a0~a7, 반환값은 a0(와 a1)
  3. C인자는 모두 스택, 반환값은 sp
정답과 해설 보기

정답: B. 인자는 a0~a7, 반환값은 a0(와 a1)

RISC-V의 표준 호출 규약에서는 정수 인자를 최대 8개까지 a0~a7(x10~x17)에 넣어 전달하고, 반환값은 a0에, 64비트 값 등은 a0와 a1 두 개에 넣어 돌려줍니다. 메모리보다 빠른 레지스터로 주고받으므로 함수 호출의 부담이 작아집니다. 8개를 넘는 인자는 스택에 둡니다. 부동소수점 인자는 fa0~fa7을 사용합니다.

    RISC-V의 표준 호출 규약에서 정수 인자와 반환값을 전달하는 데 사용하는 레지스터로 올바른 것은?

  • ra, sp, a0 같은 별칭도 있으며 호출 규약에서 역할이 정해져 있습니다.

    RISC-V의 RV32I(32비트 기본 정수 명령어 집합)가 가진 범용 정수 레지스터로 올바른 것은?

  • 호출 규약에서는 복귀 주소를 ra(x1)에 넣으므로, 함수 호출은 'jal ra, func'이며 의사 명령어로는 'call func'라고 씁니다.

호출 규약(Calling Convention)이(가) 나오는 문제 (9)

  1. 호출 규약(콜링 컨벤션)이 정해져 있는 주된 목적은?
  2. RISC-V의 표준 호출 규약에서 정수 인자와 반환값을 전달하는 데 사용하는 레지스터로 올바른 것은?
  3. RISC-V의 표준 호출 규약에서 정수 인자가 10개인 함수를 호출할 때 9번째와 10번째 인자는 어디로 전달되는가?
  4. RISC-V 호출 규약에서 s0~s11이 '호출 대상 저장(callee-saved)' 레지스터라는 의미로 올바른 것은?
  5. RISC-V 호출 규약에서 t0~t6은 '호출 원본 저장(caller-saved)' 레지스터이다. 어떤 함수가 t0에 넣은 값을 다른 함수를 호출한 뒤에도 사용하고 싶을 때 올바른 대응은?
  6. RISC-V의 표준 호출 규약에서는 함수에 진입할 때의 스택 포인터 sp를 16바이트의 배수로 맞추게 되어 있다. 그 이유로 가장 적절한 것은?
  7. RISC-V의 RV32I(32비트 기본 정수 명령어 집합)가 가진 범용 정수 레지스터로 올바른 것은?
  8. RISC-V 명령어 'jal ra, func'의 동작으로 올바른 것은?
  9. ABI(애플리케이션 바이너리 인터페이스)에 대한 설명으로 올바른 것은?
