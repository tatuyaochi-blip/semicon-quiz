핫 스탠바이(Hot Standby)란?

듀플렉스 시스템에서 대기 시스템을 기동한 상태로 두고, 주 시스템의 데이터를 항상 대기 시스템에도 반영해 두는 방식. 주 시스템이 고장 났을 때 짧은 시간에 대기 시스템으로 전환하여 처리를 계속할 수 있다. 대기 시스템을 멈춰 두고 고장 난 후에 기동하는 방식은 콜드 스탠바이라고 부른다.

반도체 공장의 제조 실행 시스템(MES) 서버를 주 시스템(운용계)과 대기 시스템으로 이루어진 듀플렉스 시스템으로 구성한다. 대기 시스템을 핫 스탠바이로 했을 때의 특징으로 적절한 것은?

  1. A대기 시스템을 기동한 상태로 대기시키고 주 시스템의 데이터를 항상 대기 시스템에도 반영해 두므로, 주 시스템이 고장 났을 때 짧은 시간에 전환할 수 있다
  2. B대기 시스템의 전원을 꺼 두고 주 시스템이 고장 난 후에 기동하여 데이터를 복원하므로, 전환에 시간이 걸리는 대신 대기 중의 전력이나 비용을 줄일 수 있다
  3. C주 시스템과 대기 시스템에서 같은 처리를 동시에 수행하고, 결과를 대조하면서 운전한다
정답과 해설 보기

정답: A. 대기 시스템을 기동한 상태로 대기시키고 주 시스템의 데이터를 항상 대기 시스템에도 반영해 두므로, 주 시스템이 고장 났을 때 짧은 시간에 전환할 수 있다

핫 스탠바이는 대기 시스템을 기동한 상태로 두고 주 시스템의 데이터를 항상 대기 시스템에도 반영해 두는 방식으로, 주 시스템이 고장 났을 때 짧은 시간에 처리를 인계할 수 있습니다. MES가 멈추면 로트 진행 지시, 장비에 대한 레시피 지정, 제조 이력 기록을 할 수 없게 되므로, 일반적으로 짧은 시간에 전환할 수 있는 구성이 선택됩니다. 대기 시스템을 멈춰 두고 고장 난 후에 기동하는 방식은 콜드 스탠바이이며, 둘의 중간(기동은 되어 있지만 처리 인계에 준비가 필요한 것)을 웜 스탠바이라고 부릅니다. 2세트로 같은 처리를 동시에 수행하여 대조하는 것은 듀얼 시스템입니다.
