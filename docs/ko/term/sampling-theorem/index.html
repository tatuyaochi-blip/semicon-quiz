표본화 정리(sampling theorem)란?

신호의 최고 주파수 성분의 2배보다 높은 주파수로 표본화하면 신호를 복원할 수 있다는 정리입니다. 나이퀴스트-섀넌 정리라고도 합니다.

일본어 명칭: サンプリング定理

표본화 정리(sampling theorem)은(는) A/D·D/A 변환 등 1개 분야의 연습 문제 1개에 나와요.

분야: A/D·D/A 변환

도전해 보기: 표본화 정리(sampling theorem) 관련 문제

AD 변환에서 "샘플링(표본화)"에 대한 설명으로 옳은 것은 무엇인가?

  1. A신호의 크기를 이산적인 값으로 반올림하는 것
  2. B연속된 신호의 값을 일정한 시간 간격마다 추출하는 것
  3. C신호에서 잡음을 제거하는 것
정답과 해설 보기

정답: B. 연속된 신호의 값을 일정한 시간 간격마다 추출하는 것

샘플링은 시간적으로 연속인 신호에서 일정한 시간 간격마다 값을 추출하는 것입니다. 추출한 값을 유한한 단계로 반올림하는 것은 양자화이며, AD 변환은 이 두 가지 처리로 이루어집니다. 샘플링 주파수는 신호의 최고 주파수의 2배보다 높아야 하며(표본화 정리), 부족하면 에일리어싱이 일어납니다. 음성은 8~48 kHz 정도, 영상이나 무선에서는 수십 MHz~GHz로 샘플링합니다.

해설 속 표본화 정리(sampling theorem)

  • 샘플링 주파수는 신호의 최고 주파수의 2배보다 높아야 하며(표본화 정리), 부족하면 에일리어싱이 일어납니다.
