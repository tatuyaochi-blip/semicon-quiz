C 밴드란?

광섬유 통신에서 사용하는 파장 1530~1565 nm 부근의 대역. 석영 광섬유의 손실이 최소(약 0.2 dB/km)가 되고 어븀 첨가 광섬유 증폭기(EDFA)로 증폭할 수 있어, 장거리 통신이나 고밀도 파장 분할 다중화(DWDM)에 사용된다.

일본어 명칭: Cバンド

분야: 실리콘 포토닉스

관련 용어

굴절률 그레이팅 커플러(Grating Coupler) 단일 모드 광섬유 도파로 링 공진기 마흐-젠더 변조기 색분산(Chromatic Dispersion) 소광비 실리콘 포토닉스(Silicon Photonics) 에지 커플러(Edge Coupler)
