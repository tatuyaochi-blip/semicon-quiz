C 밴드란?

광섬유 통신에서 사용하는 파장 1530~1565 nm 부근의 대역. 석영 광섬유의 손실이 최소(약 0.2 dB/km)가 되고 어븀 첨가 광섬유 증폭기(EDFA)로 증폭할 수 있어, 장거리 통신이나 고밀도 파장 분할 다중화(DWDM)에 사용된다.

일본어 명칭: Cバンド

분야: 실리콘 포토닉스

이 파장 대역인 이유

석영 광섬유의 손실은 주로 파장이 길어질수록 급격히 줄어드는(대략 파장의 −4승에 비례) 레일리 산란과, 장파장에서 증가하는 유리의 적외선 흡수에서 생깁니다. 표준 단일 모드 광섬유에서 최소 손실인 약 0.2 dB/km는 1550 nm 부근에 있으므로, 100 km의 광섬유도 손실이 약 20 dB에 불과합니다. 그에 못지않게 중요한 점은, 980 nm 또는 1480 nm 레이저로 펌핑하는 어븀 첨가 광섬유 증폭기(EDFA)가 약 1530~1565 nm에 걸쳐 이득을 제공해, 모든 채널을 전기 신호로 변환하지 않고 광 영역에서 한꺼번에 증폭한다는 것입니다.

C 밴드와 다른 통신 대역의 비교

ITU(국제전기통신연합)는 광섬유의 저손실 영역을 여러 대역으로 나눕니다. O(original, 약 1260~1360 nm), E, S, C(conventional, 1530~1565 nm), L(long, 약 1565~1625 nm), U 밴드입니다. 표준 단일 모드 광섬유에서는 O 밴드인 1310 nm 부근에서 색분산이 거의 0이므로, 데이터센터 내부 같은 단거리 링크에서 흔히 사용합니다. C 밴드는 손실이 더 낮고 EDFA 이득을 쓸 수 있지만 분산이 상당합니다. L 밴드는 장파장에 맞춘 증폭기를 써서 용량을 확장합니다.

고밀도 파장 분할 다중화

고밀도 파장 분할 다중화(DWDM)는 193.1 THz를 기준으로 ITU-T가 정의한 주파수 그리드 위에 100 GHz(약 0.8 nm)나 50 GHz(약 0.4 nm) 같은 간격으로 많은 레이저를 배치합니다. C 밴드는 약 4.4 THz에 걸쳐 있으므로, 100 GHz 간격이면 약 40채널, 50 GHz 간격이면 약 80채널이 들어갑니다. 간격이 매우 좁으므로 레이저 파장은 보통 온도 제어로 안정되게 유지해야 하며, 필터, 멀티플렉서, 링 공진기도 그리드에 맞게 조정해야 합니다.

C 밴드에서의 분산과 실리콘 포토닉스

표준 단일 모드 광섬유는 1550 nm에서 약 17 ps/(nm·km)의 색분산을 가지며, 이는 장거리에서 펄스를 넓힙니다. 예전 시스템은 특수 광섬유로 이를 보상했지만, 현대의 코히어런트 수신기는 디지털 신호 처리로 되돌립니다. 집적 포토닉스에서 C 밴드 광자의 에너지 약 0.8 eV는 실리콘의 밴드갭 1.12 eV보다 작으므로 실리콘 도파로는 투명하며, 실리콘 위에 성장시킨 게르마늄이 광검출기 역할을 합니다. 다만 실리콘의 강한 열광학 효과 때문에 링 공진 파장은 1 °C당 약 0.07~0.08 nm 이동합니다.

자주 묻는 질문

C 밴드 파장 범위

C 밴드(conventional band)는 약 1530~1565 nm이며, 주파수로는 약 191.6~195.9 THz에 해당합니다.

장거리 광통신에 1550 nm를 쓰는 이유

석영 광섬유의 손실이 약 0.2 dB/km로 가장 낮고, 어븀 첨가 광섬유 증폭기가 전기 변환 없이 대역 전체의 신호를 증폭할 수 있기 때문입니다.

O 밴드와 C 밴드 차이

1310 nm 부근의 O 밴드는 표준 광섬유에서 색분산이 거의 0이어서 단거리 링크에 적합하고, 1550 nm 부근의 C 밴드는 손실이 더 낮고 광 증폭이 가능해 장거리와 DWDM 시스템에 적합합니다.

이 용어가 포함된 비교

  • 싱글모드와 멀티모드 광섬유의 차이점싱글모드와 멀티모드 광섬유를 표로 비교합니다. 코어 직경, 사용 파장과 광원, 도달 거리, 모드 분산, 손실, 부품 비용, 용도를 다룹니다.

관련 용어

굴절률 그레이팅 커플러(Grating Coupler) 단일 모드 광섬유 도파로 링 공진기 마흐-젠더 변조기 색분산(Chromatic Dispersion) 소광비 실리콘 포토닉스(Silicon Photonics) 에지 커플러(Edge Coupler)
