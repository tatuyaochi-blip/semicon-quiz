PUE란?

Power Usage Effectiveness의 약어. 데이터센터 전체의 소비 전력을 IT 기기의 소비 전력으로 나눈 값으로, 1에 가까울수록 효율이 좋다.

일본어 명칭: PUE

PUE은(는) 전력 관리 등 1개 분야의 연습 문제 1개에 나와요.

정답과 해설 보기

정답: C. 시설 전체의 소비 전력을 IT 기기의 소비 전력으로 나눈 값으로, 1에 가까울수록 냉각 등의 낭비가 적다

PUE(Power Usage Effectiveness)는 데이터센터 전체에서 사용하는 전력을 서버, 스토리지, 네트워크 기기가 사용하는 전력으로 나눈 값입니다. 냉각이나 전원 변환 손실, 조명 등에 전력을 쓸수록 커집니다. 예를 들어 PUE가 1.5라면 IT 기기 전력의 절반 정도를 냉각 등에 사용하고 있다는 뜻입니다. 외기나 액냉을 이용한 고효율 냉각으로 1.1 정도를 실현한 시설도 있습니다.
