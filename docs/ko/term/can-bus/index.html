CAN 버스란?

Controller Area Network의 약어로, 2개 선의 차동 신호로 ECU끼리 연결하는 차량용 네트워크. ID 값이 작을수록 우선순위가 높으며, 동시에 송신을 시작해도 비파괴 중재로 1개의 프레임만 남는다. 기존 CAN은 최대 1 Mbit/s이며, CAN FD에서는 데이터 부분을 수 Mbit/s로 고속화할 수 있다.

일본어 명칭: CAN

CAN 버스은(는) 차량용 반도체와 기능 안전 등 1개 분야의 연습 문제 2개에 나와요.

도전해 보기: CAN 버스 관련 문제

양 끝에 120 Ω의 종단 저항을 단 CAN 버스에서, 전원을 끈 상태로 CAN_H와 CAN_L 사이의 저항을 측정했다. 정상인 경우의 값으로 가장 가까운 것은?

  1. A120 Ω
  2. B240 Ω
  3. C60 Ω
정답과 해설 보기

정답: C. 60 Ω

CAN 버스는 신호의 반사를 막기 위해 양 끝에 각각 120 Ω의 종단 저항을 답니다. CAN_H와 CAN_L 사이에서 보면 2개의 120 Ω이 병렬로 연결되어 있으므로 120 × 120 / (120 + 120) = 60 Ω이 됩니다. 측정값이 120 Ω이면 한쪽 종단 저항이 달려 있지 않은 경우, 40 Ω 정도면 종단 저항이 3개 달려 있는 경우 등의 배선 오류가 의심됩니다. 240 Ω은 2개를 직렬로 간주한 오류입니다.
