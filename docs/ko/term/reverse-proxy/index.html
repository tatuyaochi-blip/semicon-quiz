리버스 프록시(Reverse Proxy)란?

웹 서버 앞에 놓여, 이용자로부터의 요청을 서버 대신 받아 뒤에 있는 한 대 또는 여러 대의 서버로 중계하는 서버. HTTPS 암호 처리를 한곳에서 모아 수행하는 것(TLS 종료), 자주 사용되는 응답을 저장해 두었다가 돌려주는 것, 여러 서버에 부하를 나누는 것, 뒤쪽 서버의 구성을 숨기는 것과 같은 역할을 담당한다. 이용자 쪽에 놓여 이용자 대신 외부 사이트에 접속하는 포워드 프록시와는 놓이는 장소와 지키는 대상이 다르다.

정답: C. 웹 서버 앞에 놓여 이용자로부터의 요청을 대신 받아 뒤쪽 서버로 중계하고, TLS 처리 등을 담당한다

리버스 프록시는 서버 쪽에 놓여 이용자로부터의 요청을 받고, 뒤에 있는 한 대 또는 여러 대의 서버로 중계합니다. HTTPS 암호 처리를 한곳에서 모아 수행하는 것(TLS 종료), 자주 사용되는 응답을 저장해 두었다가 돌려주는 것, 여러 서버로 분배하는 것과 같은 역할을 담당하며, 뒤쪽 서버의 구성을 이용자로부터 숨길 수도 있습니다. 사내 이용자 대신 외부로 접속하는 것은 포워드 프록시로, 이용자 쪽에 놓인다는 점이 다릅니다.

해설 속 리버스 프록시(Reverse Proxy)

  • 리버스 프록시는 서버 쪽에 놓여 이용자로부터의 요청을 받고, 뒤에 있는 한 대 또는 여러 대의 서버로 중계합니다.
