홈분야용어집비교도해계산 도구성적
홈 › 용어집 › 데이터시트 읽는 법

입력 오프셋 전압란?

연산 증폭기의 출력을 0으로 만들기 위해 입력 사이에 필요한 작은 전압으로, 내부 소자의 부정합으로 생긴다. 회로의 이득만큼 곱해져 출력 오차가 되며, 예를 들어 2 mV에 이득 100배라면 출력은 최대 200 mV 어긋난다.

일본어 명칭: 入力オフセット電圧

입력 오프셋 전압은(는) 아날로그·전자 회로, 데이터시트 읽는 법 등 2개 분야의 연습 문제 2개에 나와요.

분야: 데이터시트 읽는 법

도전해 보기: 입력 오프셋 전압 관련 문제

연산 증폭기의 입력 오프셋 전압에 대한 설명으로 올바른 것은 무엇입니까?

  1. A입력을 0으로 해도 출력이 0이 되지 않는 것을 보정하기 위해 입력 단자 사이에 가해야 하는 작은 전압
  2. B입력에 가할 수 있는 최대 전압
  3. C연산 증폭기의 전원 전압
정답과 해설 보기

정답: A. 입력을 0으로 해도 출력이 0이 되지 않는 것을 보정하기 위해 입력 단자 사이에 가해야 하는 작은 전압

실제 연산 증폭기는 입력단 트랜지스터의 미세한 불일치 때문에 입력을 같은 전압으로 해도 출력이 0이 되지 않습니다. 이를 입력 측으로 환산한 것이 입력 오프셋 전압이며, 범용품은 수 mV, 정밀품은 수십 µV 이하입니다. 출력에는 (1 + Rf/Ri)배가 되어 나타나며 온도에 따라서도 변화(드리프트)합니다. 열전대 같은 직류 미소 신호를 높은 이득으로 다룰 때는 저오프셋품이나 초퍼 안정화형을 사용합니다.

입력 오프셋 전압이 max 2 mV인 연산 증폭기로 이득 100배의 비반전 증폭 회로를 만들었다. 입력을 0 V로 했을 때 출력에 나타날 수 있는 오차 전압의 최대치는 대략 얼마입니까?

  1. A2 mV
  2. B200 mV
  3. C20 mV
정답과 해설 보기

정답: B. 200 mV

입력 오프셋 전압은 입력에 직렬로 들어간 작은 전압원처럼 동작하며, 비반전 증폭 회로의 이득(1 + Rf/Ri)배가 되어 출력에 나타납니다. 2 mV × 100 = 200 mV로, 예를 들어 5 V 풀스케일에 대해 4%의 오차가 됩니다. typ 값이 아닌 max 값으로 추정하고, 온도 드리프트(µV/℃)에 의한 변화도 더합니다. 정밀 측정에는 오프셋이 수 µV 정도인 제로 드리프트(초퍼)형을 선택하거나 소프트웨어로 교정합니다. 2 mV는 이득을 곱하는 것을 잊은 값입니다.

입력 오프셋 전압이(가) 나오는 문제 (2)

  1. 연산 증폭기의 입력 오프셋 전압에 대한 설명으로 올바른 것은 무엇입니까?
  2. 입력 오프셋 전압이 max 2 mV인 연산 증폭기로 이득 100배의 비반전 증폭 회로를 만들었다. 입력을 0 V로 했을 때 출력에 나타날 수 있는 오차 전압의 최대치는 대략 얼마입니까?

관련 용어
