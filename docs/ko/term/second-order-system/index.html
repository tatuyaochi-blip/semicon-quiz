2차 지연계(Second-order System)란?

전달 함수가 G(s) = Kωn²/(s² + 2ζωn s + ωn²)으로 나타나는 시스템. ωn을 고유 각주파수, ζ를 감쇠비(감쇠 계수)라고 부른다. 0 < ζ < 1에서는 계단 응답이 진동하면서 최종값에 다가가고, ζ = 1에서는 최종값을 넘어서지 않고 가장 빨리 수렴하며, ζ > 1에서는 천천히 다가간다. 스프링과 질량과 댐퍼의 기계계, RLC 회로, 위치 제어 루프 등이 이 형태로 나타난다. 고차 시스템도 주요한 2개의 극점으로 근사해 다루는 경우가 많다.

일본어 명칭: 二次遅れ系

2차 지연계(Second-order System)은(는) 제어 공학의 기초 등 1개 분야의 연습 문제 4개에 나와요.

분야: 제어 공학의 기초

감쇠비와 응답의 형태

오버슈트는 exp(−πζ/√(1 − ζ²))로 ζ만으로 정해집니다. ζ = 0.5에서 약 16%, ζ ≈ 0.707(1/√2)에서 약 4.3%입니다. 최종값을 넘어서는 양이 최대가 되는 시각은 π/ωd이며, ωd = ωn√(1 − ζ²)은 감쇠하면서 진동하는 각주파수입니다. ζ가 작을수록 응답은 빠르게 상승하지만, 넘어서는 양과 진동이 커집니다.

극점 위치와의 대응

0 < ζ < 1인 극점은 s = −ζωn ± jωd이며, 원점으로부터의 거리가 ωn, 음의 실수축과 이루는 각 θ가 cos θ = ζ를 만족합니다. 실수부 ζωn이 감쇠의 빠르기를 정하며, ±2%의 정정 시간은 약 4/(ζωn)으로 어림됩니다. 이 식은 진동의 포락선에서 구한 근사이며, 실제 값은 이보다 조금 짧은 경우가 많습니다.

주파수 응답으로 보면

보드 선도에서는 ωn을 절점으로 하여 높은 주파수에서 이득이 −40 dB/dec로 떨어지고, 위상은 0°에서 −180°까지 바뀝니다. ζ가 약 0.707보다 작으면 ωn 근처에서 이득이 솟아오르는 공진 피크가 나타납니다. 피드백을 건 시스템에서는 위상 여유가 작을수록 폐루프의 ζ가 작아지며, 기준으로 ζ는 위상 여유(도)의 약 100분의 1입니다.

도전해 보기: 2차 지연계(Second-order System) 관련 문제

2차 지연계 G(s) = ωn²/(s² + 2ζωn s + ωn²)의 계단 응답이 최종값을 지나쳐 진동하면서 다가가는, 감쇠비 ζ의 범위로 올바른 것은?

  1. Aζ > 1
  2. Bζ = 1
  3. C0 < ζ < 1
정답과 해설 보기

정답: C. 0 < ζ < 1

0 < ζ < 1에서는 극점이 공액 복소수가 되어 응답은 진동하면서 최종값에 다가갑니다(부족 감쇠). ζ = 1에서는 극점이 음의 실수 중근이 되어, 최종값을 넘어서지 않는 응답 중에서 가장 빨리 수렴합니다(임계 감쇠). ζ > 1에서는 극점이 두 개의 음의 실수가 되어, 최종값을 넘어서지는 않지만 천천히 다가갑니다(과감쇠). ζ = 0에서는 진동이 감쇠하지 않고 계속되며, ζ < 0에서는 불안정해집니다.

전달 함수 G(s) = 25/(s² + 4s + 25)인 2차 지연계의 고유 각주파수 ωn과 감쇠비 ζ의 조합으로 올바른 것은?

  1. Aωn = 5 rad/s, ζ = 0.4
  2. Bωn = 5 rad/s, ζ = 0.8
  3. Cωn = 25 rad/s, ζ = 0.08
정답과 해설 보기

정답: A. ωn = 5 rad/s, ζ = 0.4

표준형 ωn²/(s² + 2ζωn s + ωn²)과 비교하면 ωn² = 25에서 ωn = 5 rad/s입니다. s의 계수는 2ζωn = 4이므로 ζ = 4/(2 × 5) = 0.4가 됩니다. 극점은 s = −2 ± j4.58이며, 실수부 −ζωn = −2가 감쇠의 빠르기를, 허수부 ωn√(1 − ζ²) ≈ 4.58 rad/s가 진동의 각주파수를 나타냅니다.

자주 묻는 질문

감쇠비는 어느 정도로 설계하는 것이 좋나요?

최종값을 넘어서는 양을 조금으로 하여 빠르게 응답시키고 싶은 경우에는 ζ = 0.5~0.8 정도가 자주 선택됩니다. ζ ≈ 0.707은 오버슈트가 약 4.3%이며, 주파수 응답에 공진 피크가 나타나지 않는 경계이기도 합니다. 넘어서는 것이 허용되지 않는 용도에서는 ζ ≥ 1로 설계합니다.

3차 이상의 시스템에도 2차 지연계의 식을 쓸 수 있나요?

허수축에 가까운 2개의 극점(대표 극점)이 다른 극점보다 충분히 느린 경우에는 그 2개의 극점으로 근사하여 어림할 수 있습니다. 다른 극점이나 영점이 가까우면 오차가 커지므로 수치 계산으로 확인하는 것이 확실합니다.
