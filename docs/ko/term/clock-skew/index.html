클록 스큐(Clock Skew)란?

같은 클록 신호가 플립플롭마다 도착하는 시각의 차이. 셋업·홀드 여유를 바꾸므로 클록 트리 합성에서 작게 억제한다.

  2. B클록 신호가 플립플롭마다 도착하는 시각의 차이

정답과 해설 보기

정답: B. 클록 신호가 플립플롭마다 도착하는 시각의 차이

클록 스큐는 같은 클록이 배선 길이나 부하의 차이로 플립플롭마다 서로 다른 시각에 도착하는 차이입니다. 수신 측 클록이 늦어지면 셋업에는 유리하지만 홀드에는 불리하며, 반대의 경우도 마찬가지입니다. 칩 전체에 도달하는 클록 트리를 CTS(클록 트리 합성)로 설계하고, 버퍼 배치와 배선 길이를 맞추어 스큐를 수십 ps 이하로 억제합니다. 주기의 시간적 흔들림은 지터입니다.
