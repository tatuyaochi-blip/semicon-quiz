非正規化数란?

ひせいきかすう

指数部がすべて0の浮動小数点数で、先頭の1を仮定せずに、正規化数より小さい0の近くの数を表す。0との間をなだらかにつなぎ(漸進アンダーフロー)、x − y = 0 なら x = y が成り立つようにする。

일본어 명칭: 非正規化数

분야: 컴퓨터 산술

관련 용어

仮数 固定小数点 算術シフト 情報落ち 指数部 最近接偶数丸め 飽和演算 桁落ち 桁上げ保存加算器 桁上げ先見加算器
