밀리 머신(Mealy machine)란?

출력이 현재 상태와 입력 모두에 의존하는 상태 기계입니다. 입력 변화가 같은 사이클 안에 출력에 반영되지만 입력의 글리치도 그대로 전달될 수 있습니다. 무어 머신은 출력이 상태에만 의존합니다.

일본어 명칭: ミーリ型

분야: HDL과 검증

관련 용어

4값 논리(four-state logic) 감응 목록(sensitivity list) 값 변화 덤프(value change dump, VCD) 게이트 레벨 시뮬레이션(gate-level simulation) 논블로킹 할당(nonblocking assignment) 동기 리셋(synchronous reset) 리셋 동기화 회로(reset synchronizer) 린트 도구(lint tool) 블로킹 할당(blocking assignment) 비동기 리셋(asynchronous reset)
