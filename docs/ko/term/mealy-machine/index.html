밀리형(Mealy Machine)란?

출력이 현재 상태와 입력 모두로 결정되는 상태 기계. 입력 변화가 같은 사이클에 출력에 나타나지만 입력의 잡음도 출력에 전달되기 쉽다. 출력이 상태만으로 결정되는 것은 무어형.

일본어 명칭: ミーリ型

밀리형(Mealy Machine)은(는) 논리 회로, HDL과 검증 등 2개 분야의 연습 문제 2개에 나와요.

분야: HDL과 검증

도전해 보기: 밀리형(Mealy Machine) 관련 문제

출력이 현재 상태만으로 결정되는 순차 회로(스테이트 머신)의 유형은?

  1. A밀리형
  2. B무어형
  3. C하버드형
정답과 해설 보기

정답: B. 무어형

무어형에서는 출력이 현재 상태만으로 결정되고, 밀리형에서는 상태와 입력 모두로 결정됩니다. 무어형은 출력이 클록 에지 이후에만 바뀌고 입력의 변화나 글리치가 출력에 직접 전달되지 않으므로 안정적이며 타이밍도 예측하기 쉬운 반면, 입력에 대한 반응이 1클록 늦고 상태 수가 늘어나기 쉽습니다. 밀리형은 상태 수를 줄일 수 있고 입력에 즉시 반응하지만 입력의 변화가 출력에 직접 전달됩니다. 실제 설계에서는 둘을 조합하여 사용합니다.

밀리(Mealy)형 상태 머신의 특징으로 올바른 것은?

  1. A출력이 현재 상태만으로 결정되며, 입력이 바뀌어도 다음 클럭까지 출력은 바뀌지 않는다
  2. B출력이 현재 상태와 입력 모두로 결정되므로, 입력의 변화가 같은 사이클 안에 출력에 나타난다
  3. C상태를 갖지 않는 조합 회로이다
정답과 해설 보기

정답: B. 출력이 현재 상태와 입력 모두로 결정되므로, 입력의 변화가 같은 사이클 안에 출력에 나타난다

밀리형에서는 출력 논리가 현재 상태에 더해 입력도 보므로, 입력이 바뀌면 클럭을 기다리지 않고 출력이 바뀌어 1사이클 빠르게 반응할 수 있습니다. 상태 수가 적어도 되는 경우도 있습니다. 반면 입력에서 출력까지 조합 회로 경로가 이어지므로, 입력의 노이즈가 출력에 나타나거나 타이밍 경로가 길어지기도 합니다. 출력을 플립플롭으로 다시 받아서 사용하기도 합니다.
