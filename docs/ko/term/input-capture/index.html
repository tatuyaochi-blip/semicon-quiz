인풋 캡처(Input Capture)란?

입력 신호가 변화한 순간의 타이머 카운터 값을 하드웨어가 기록하는 기능. 펄스의 폭이나 주파수를 정확하게 측정할 수 있다.

일본어 명칭: インプットキャプチャ

인풋 캡처(Input Capture)은(는) 임베디드 시스템과 펌웨어 등 1개 분야의 연습 문제 1개에 나와요.

분야: 임베디드 시스템과 펌웨어

도전해 보기: 인풋 캡처(Input Capture) 관련 문제

마이크로컨트롤러 타이머의 입력 캡처(input capture) 기능의 용도로 올바른 것은 무엇입니까?

  1. A화면의 이미지를 가져와 저장한다
  2. B입력 신호가 변화한 순간의 카운터 값을 기록하여 펄스의 폭이나 주파수를 정확하게 측정한다
  3. C출력 핀에서 PWM 신호를 내보낸다
정답과 해설 보기

정답: B. 입력 신호가 변화한 순간의 카운터 값을 기록하여 펄스의 폭이나 주파수를 정확하게 측정한다

입력 캡처에서는 입력 핀의 신호가 상승하거나 하강하는 순간에 타이머 카운터 값을 하드웨어가 레지스터에 복사해 둡니다. 두 번의 변화 값의 차이로 펄스의 폭이나 주기를 알 수 있습니다. 소프트웨어로 인터럽트를 받은 뒤 시각을 읽으면 처리 지연으로 오차가 생기지만, 이 방법은 지연과 관계없이 정확하게 측정할 수 있습니다. 회전수 센서나 초음파 거리계 등에서 사용됩니다.

인풋 캡처(Input Capture)이(가) 나오는 문제 (1)

  1. 마이크로컨트롤러 타이머의 입력 캡처(input capture) 기능의 용도로 올바른 것은 무엇입니까?
