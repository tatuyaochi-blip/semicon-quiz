이득 여유(Gain Margin)란?

루프 전달 함수의 위상이 −180°가 되는 주파수(위상 교차 주파수)에서 이득이 0 dB보다 몇 dB 낮은지를 나타내는 양. 루프 이득을 몇 배 더 하면 불안정해지는지를 나타내며, 예를 들어 이득 여유가 약 9.5 dB라면 이득을 3배로 하면 안정 한계에 도달한다. 위상 여유와 함께 안정 여유를 나타내며, 서보계에서는 10~20 dB 정도가 기준으로 여겨진다.

일본어 명칭: ゲイン余裕(利得余裕)

이득 여유(Gain Margin)은(는) 제어 공학의 기초, 아날로그·전자 회로 등 2개 분야의 연습 문제 4개에 나와요.

분야: 제어 공학의 기초

도전해 보기: 이득 여유(Gain Margin) 관련 문제

루프 전달 함수의 보드 선도에서 읽어 내는 이득 여유와 위상 여유의 설명으로 올바른 것은?

  1. A이득 여유는 이득이 0 dB가 되는 주파수에서 위상의 −180°까지의 차이, 위상 여유는 위상이 −180°가 되는 주파수에서 이득의 0 dB까지의 차이이다
  2. B이득 여유는 위상이 −180°가 되는 주파수에서 이득의 0 dB까지의 차이, 위상 여유는 이득이 0 dB가 되는 주파수에서 위상의 −180°까지의 차이이다
  3. C이득 여유와 위상 여유 모두 폐루프 보드 선도에서 이득이 −3 dB가 되는 주파수에서 읽는다
정답과 해설 보기

정답: B. 이득 여유는 위상이 −180°가 되는 주파수에서 이득의 0 dB까지의 차이, 위상 여유는 이득이 0 dB가 되는 주파수에서 위상의 −180°까지의 차이이다

이득 여유는 위상이 −180°가 되는 위상 교차 주파수에서 이득이 0 dB보다 몇 dB 낮은지를 나타냅니다. 위상 여유는 이득이 0 dB가 되는 이득 교차 주파수에서 위상이 −180°까지 몇 도 남아 있는지를 나타냅니다. 둘 다 루프 전달 함수가 점 −1(이득 0 dB, 위상 −180°)에 얼마나 가까운지를 나타내는 지표이며, 폐루프가 아니라 루프 전달 함수에서 읽습니다. 서보계에서는 이득 여유 10~20 dB, 위상 여유 40~60° 정도가 기준으로 자주 쓰입니다.

루프 전달 함수 L(s) = 2/(s(s + 1)(s + 2))의 이득 여유에 가장 가까운 것은?

  1. A약 4.8 dB
  2. B약 9.5 dB
  3. C약 15.6 dB
정답과 해설 보기

정답: B. 약 9.5 dB

위상은 −90° − tan⁻¹ω − tan⁻¹(ω/2)이고, 두 각의 합이 90°가 되는 조건 ω × (ω/2) = 1로부터 위상이 −180°가 되는 것은 ω = √2 rad/s일 때입니다. 그곳에서의 이득은 |L(j√2)| = 2/(√2 × √3 × √6) = 1/3이므로 이득 여유는 20 log₁₀3 ≈ 9.5 dB입니다. 이득을 3배(K = 6)로 하면 한계에 도달하게 되어, 라우스-후르비츠 안정 판별법으로 구한 안정 범위 0 < K < 6과 일치합니다.

해설 속 이득 여유(Gain Margin)

  • 이득 여유는 위상이 −180°가 되는 위상 교차 주파수에서 이득이 0 dB보다 몇 dB 낮은지를 나타냅니다.

    루프 전달 함수의 보드 선도에서 읽어 내는 이득 여유와 위상 여유의 설명으로 올바른 것은?

  • 그곳에서의 이득은 |L(j√2)| = 2/(√2 × √3 × √6) = 1/3이므로 이득 여유는 20 log₁₀3 ≈ 9.5 dB입니다.

    루프 전달 함수 L(s) = 2/(s(s + 1)(s + 2))의 이득 여유에 가장 가까운 것은?

  • 위상 지연이 180°가 되는 주파수에서 루프 이득이 1보다 얼마나 작은지(게인 여유)도 함께 평가합니다.

    부귀환 증폭 회로가 발진하지 않고 안정적으로 동작하는지를 판단하는 지표는 무엇입니까?

  • 이득 여유와 위상 여유는 궤적이 점 −1에서 얼마나 떨어져 있는지를 나타내는 지표입니다.
