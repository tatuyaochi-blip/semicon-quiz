약한 심볼(weak symbol)란?

같은 이름의 일반(강한) 정의가 있으면 그쪽으로 대체되는 예비 정의. 임베디드에서는 인터럽트 핸들러의 기본 처리 등에 쓴다.

일본어 명칭: 弱いシンボル

약한 심볼(weak symbol)은(는) 링커, 로더, 실행 파일 등 1개 분야의 연습 문제 1개에 나와요.

  2. B같은 이름의 일반적인(강한) 정의가 있으면 그쪽이 사용되고, 없으면 약한 정의가 사용된다
  3. C약한 심볼을 포함한 파일은 링크할 수 없다
정답과 해설 보기

정답: B. 같은 이름의 일반적인(강한) 정의가 있으면 그쪽이 사용되고, 없으면 약한 정의가 사용된다

약한 심볼은 '달리 정의가 없으면 이것을 사용한다'는 예비 정의입니다. 임베디드 소프트웨어에서는 인터럽트 핸들러의 기본 처리를 약한 심볼로 준비해 두고, 사용자가 같은 이름의 함수를 작성하면 그것으로 대체되도록 하는 사용법이 자주 보입니다. 강한 정의끼리 겹치면 다중 정의 오류가 되지만, 약한 정의와 겹치는 것은 오류가 되지 않습니다.
