제약 조건 랜덤 검증(constrained random verification)란?

사양이 허용하는 제약 범위 안에서 무작위 입력값을 생성하여, 사람이 떠올리지 못하는 경우까지 폭넓게 검증하는 방법입니다.

일본어 명칭: 制約付きランダム検証

제약 조건 랜덤 검증(constrained random verification)은(는) HDL과 검증 등 1개 분야의 연습 문제 1개에 나와요.

분야: HDL과 검증

도전해 보기: 제약 조건 랜덤 검증(constrained random verification) 관련 문제

SystemVerilog의 제약 조건 기반 랜덤 검증(constrained random verification)에 대한 설명으로 올바른 것은?

  1. A입력 값을 사양에서 허용되는 범위나 조합의 조건(제약) 안에서 랜덤으로 만들어, 사람이 생각하지 못한 경우까지 포함해 폭넓게 시험한다
  2. B입력 값을 완전히 무작위로 만들어, 사양에 없는 값도 많이 준다
  3. C입력 값을 사람이 모두 직접 작성한다
정답과 해설 보기

정답: A. 입력 값을 사양에서 허용되는 범위나 조합의 조건(제약) 안에서 랜덤으로 만들어, 사람이 생각하지 못한 경우까지 포함해 폭넓게 시험한다

사람이 생각한 테스트(지정형 테스트)만으로는 설계자가 상정하지 못한 조합의 불량을 놓치기 쉽습니다. 제약 조건 기반 랜덤 검증에서는 예를 들어 "주소는 4의 배수", "길이는 1~256"과 같은 제약을 작성하고 그 안에서 랜덤으로 입력을 만들므로, 의미 있는 입력만으로 많은 경우를 시험할 수 있습니다. 어떤 경우를 시험했는지는 커버리지로 측정하고, 부족한 부분은 제약을 바꾸거나 지정형 테스트로 보완합니다.
