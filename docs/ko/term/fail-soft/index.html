페일 소프트(Fail-soft)란?

시스템의 일부가 고장 났을 때 고장 난 부분을 분리하고, 기능이나 성능을 낮추더라도 시스템 전체로서는 동작을 계속하는 설계 개념. 여러 서버가 처리를 분담하는 시스템에서 1대가 고장 나도 나머지로 처리를 계속하는 것 등이 예이다.
