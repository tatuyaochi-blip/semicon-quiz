매크로(Macro)란?

C 언어에서 #define으로 이름을 붙인 문자열 치환. #define BUF_SIZE 64 같은 상수의 이름이나, #define SQUARE(x) ((x) * (x)) 같은 인수를 받는 함수 형식 매크로가 있으며, 컴파일 전에 전처리기가 전개한다. 전개는 문자 치환에 불과하므로, 인수나 전체를 괄호로 감싸지 않으면 연산자 우선순위 때문에 의도와 다른 식이 되며, SQUARE(i++)처럼 부작용이 있는 인수는 여러 번 평가된다.

일본어 명칭: マクロ
