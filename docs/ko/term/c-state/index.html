C-state란?

할 일이 없을 때 CPU가 쉬는 깊이를 나타내는 상태. C0이 동작 중이며 숫자가 클수록 전력은 작지만 복귀하는 데 시간이 걸린다.

일본어 명칭: C-state

C-state은(는) 전력 관리 등 1개 분야의 연습 문제 3개에 나와요.

분야: 전력 관리

도전해 보기: C-state 관련 문제

CPU의 C-state(C 스테이트)에 대한 설명으로 올바른 것은?

  1. ACPU가 동작 중일 때의 주파수와 전압의 조합
  2. B할 일이 없을 때의 CPU 휴지 깊이를 나타내는 상태로, 깊은 상태일수록 전력은 작지만 복귀에 시간이 걸린다
  3. CCPU 제조 공정의 이름
정답과 해설 보기

정답: B. 할 일이 없을 때의 CPU 휴지 깊이를 나타내는 상태로, 깊은 상태일수록 전력은 작지만 복귀에 시간이 걸린다

C-state에서는 C0이 명령을 실행 중인 상태이고, C1은 클록만 멈추는 얕은 휴지, 더 깊은 상태에서는 캐시 내용을 기록하고 코어의 전원을 끄는 등, 번호가 커질수록 더 많은 회로를 멈춥니다. 깊을수록 전력은 작아지지만 복귀까지의 시간과 수고가 늘어나므로, OS는 다음 작업까지의 시간을 예측하여 적절한 깊이를 선택합니다.

해설 속 C-state

  • C-state에서는 C0이 명령을 실행 중인 상태이고, C1은 클록만 멈추는 얕은 휴지, 더 깊은 상태에서는 캐시 내용을 기록하고 코어의 전원을 끄는 등, 번호가 커질수록 더 많은 회로를 멈춥니다.

    CPU의 C-state(C 스테이트)에 대한 설명으로 올바른 것은?

  • 휴지 깊이를 나타내는 C-state와 조합하여, 일이 있을 때는 적절한 속도로 동작하고 일이 없을 때는 깊이 쉬는 식으로 관리합니다.

    CPU의 P-state(P 스테이트)에 대한 설명으로 올바른 것은?

  • 펌웨어가 기기 구성과 전원 조작 방법을 표 형태로 OS에 전달하고, OS는 이를 사용하여 슬립(S3)이나 최대 절전 모드(S4)로의 전환, CPU의 C-state와 P-state 제어, 온도에 따른 팬 제어 등을 수행합니다.

    PC 등에서 사용되는 ACPI에 대한 설명으로 올바른 것은?
