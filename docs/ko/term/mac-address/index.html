MAC 주소(MAC Address)란?

이더넷이나 무선 LAN에서 같은 네트워크 안의 기기를 지정하는 데 사용하는 48비트 주소. 상위 24비트가 제조사를 나타내며, 제조 시에 인터페이스마다 할당된다.

일본어 명칭: MACアドレス

MAC 주소(MAC Address)은(는) 네트워크 설계와 운용, 네트워크 기초, 논리 회로 등 3개 분야의 연습 문제 14개에 나와요.

도전해 보기: MAC 주소(MAC Address) 관련 문제

MAC 주소에 대한 설명으로 올바른 것은?

  1. A48비트 값으로, 네트워크 인터페이스마다 할당되며 같은 네트워크 안에서 목적지 기기를 지정하는 데 사용된다
  2. B32비트 값으로, 라우터가 서로 다른 네트워크 사이의 경로를 선택하는 데 사용된다
  3. C접속하는 네트워크가 바뀔 때마다 DHCP 서버에서 할당된다
정답과 해설 보기

정답: A. 48비트 값으로, 네트워크 인터페이스마다 할당되며 같은 네트워크 안에서 목적지 기기를 지정하는 데 사용된다

MAC 주소는 이더넷이나 무선 LAN에서 사용되는 48비트 주소로, 00:1A:2B:3C:4D:5E처럼 16진수로 씁니다. 상위 24비트는 제조사를 나타내는 번호(OUI)이며, 제조 시에 인터페이스마다 할당됩니다. 다만 최근의 OS에서는 프라이버시를 보호하기 위해 무선 LAN에서 무작위 MAC 주소를 사용하기도 합니다. 프레임은 MAC 주소로 같은 네트워크 안의 이웃한 기기에 전달되며, 라우터를 넘을 때마다 출발지와 목적지의 MAC 주소가 바뀌어 붙습니다. 32비트로 라우터가 경로를 선택하는 데 쓰는 것은 IPv4 주소이고, DHCP로 할당되는 것도 IP 주소입니다.

단말(192.168.1.10/24, 기본 게이트웨이 192.168.1.1)이 다른 네트워크에 있는 서버 203.0.113.80으로 패킷을 보낸다. ARP 캐시가 비어 있을 때, 단말이 ARP로 MAC 주소를 알아내는 상대는?

  1. A기본 게이트웨이 192.168.1.1
  2. B서버 203.0.113.80
  3. C서버까지의 경로상에 있는 모든 라우터
정답과 해설 보기

정답: A. 기본 게이트웨이 192.168.1.1

단말은 먼저 자신의 IP 주소와 서브넷 마스크로 목적지가 같은 네트워크에 있는지를 판단합니다. 203.0.113.80은 192.168.1.0/24 밖이므로 패킷은 기본 게이트웨이(라우터)에 넘깁니다. 이때 IP 헤더의 목적지는 서버의 203.0.113.80 그대로이고, 프레임의 목적지 MAC 주소만 게이트웨이의 것으로 합니다. 그래서 ARP로 알아내는 것은 192.168.1.1의 MAC 주소입니다. ARP 브로드캐스트는 라우터를 넘지 않으므로 다른 네트워크에 있는 서버의 MAC 주소는 알아낼 수 없고, 알 필요도 없습니다. 경로상의 각 라우터가 다음 기기로 보낼 때마다 각자 상대의 MAC 주소를 알아냅니다.

MAC 주소(MAC Address)이(가) 나오는 문제 (14)

  1. MAC 주소에 대한 설명으로 올바른 것은?
  2. 단말(192.168.1.10/24, 기본 게이트웨이 192.168.1.1)이 다른 네트워크에 있는 서버 203.0.113.80으로 패킷을 보낸다. ARP 캐시가 비어 있을 때, 단말이 ARP로 MAC 주소를 알아내는 상대는?
  3. L2 스위치가 프레임을 받았을 때 MAC 주소 테이블에 등록하는 정보로 올바른 것은?
  4. MAC 주소 테이블이 비어 있는 L2 스위치의 포트 1~4에 기기가 연결되어 있고, 모두 같은 VLAN에 속한다. 포트 1에 연결된 PC-A가 포트 2에 연결된 PC-B 앞으로 프레임을 보내고, 이어서 PC-B가 PC-A 앞으로 회신 프레임을 보냈다. 두 프레임이 전달되는 방식으로 올바른 것은?
  5. STP에서 스위치 3대의 브리지 ID가 다음과 같이 알려져 있다. SW1은 우선순위 32768, MAC 주소 00-00-5E-00-53-01, SW2는 우선순위 61440, MAC 주소 00-00-5E-00-53-05, SW3은 우선순위 4096, MAC 주소 00-00-5E-00-53-0A이다. 루트 브리지로 선출되는 스위치는?
  6. MAC 주소가 00-1A-2B-3C-4D-5E인 인터페이스가 프리픽스 2001:db8:1:1::/64와 EUI-64 형식의 인터페이스 ID로 SLAAC에 의해 주소를 만든다. 만들어지는 주소는?
  7. 16진수 FF를 10진수로 나타내면 얼마입니까?
  8. OSI 참조 모델에서 IP 주소 같은 논리 주소를 사용하여 서로 다른 네트워크 사이에서 패킷을 중계해 목적지까지 전달하는 역할을 하는 계층은?
  9. 허브(리피터 허브)와 비교했을 때 L2 스위치의 동작으로 올바른 것은?
  10. ARP의 역할로 올바른 것은?
  11. IEEE 802.1Q 태그에 들어가는 VLAN ID는 12비트이며, 그중 0과 4095는 특별한 용도를 위해 예약되어 있다. VLAN 식별에 사용할 수 있는 VLAN ID의 수는?
  12. 라우터 R1(192.168.1.2)과 R2(192.168.1.3) 2대로 VRRP를 구성하고, 가상 IP 주소를 192.168.1.254로 했다. 평소에는 R1이 마스터로서 전달하고 있다. LAN 단말의 기본 게이트웨이로 설정할 주소로 적절한 것은?
  13. 지사의 라우터 R2는 본사의 라우터 R1과 10.255.0.0/30 링크로 연결되어 있으며, R1 쪽 주소는 10.255.0.1, R2 쪽은 10.255.0.2이다. R2에 본사 네트워크 192.168.1.0/24로 가는 정적 경로를 설정할 때, 다음 전달 대상(넥스트 홉)으로 지정할 주소로 적절한 것은?
  14. IPv6의 SLAAC(상태 비저장 주소 자동 설정)에서 단말이 글로벌 유니캐스트 주소를 만드는 방법으로 올바른 것은?
