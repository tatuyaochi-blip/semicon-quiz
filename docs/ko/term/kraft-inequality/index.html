크래프트 부등식(Kraft Inequality)란?

0과 1로 이루어진 부호에서 부호 길이가 l₁, l₂, …, lₙ인 접두 부호를 만들 수 있기 위한 필요충분조건 Σ 2^(−lᵢ) ≤ 1을 나타내는 부등식. 길이 l인 부호어를 하나 사용하면 그것으로 시작하는 비트열을 모두 사용할 수 없게 되어 전체의 2^(−l)을 차지한다고 생각하면 이해하기 쉽다. 예를 들어 길이 1, 2, 3, 3에서는 합이 정확히 1이 되어 0, 10, 110, 111과 같이 만들 수 있다. 한 가지로 복호할 수 있는 어떤 부호도 이 부등식을 만족하므로(맥밀런의 정리), 부호 길이를 정할 때는 접두 부호 중에서 고르면 충분하다.

도전해 보기: 크래프트 부등식(Kraft Inequality) 관련 문제

4개의 기호 A~D에 다음 길이(비트 수)의 부호어를 할당하여, 0과 1로 이루어진 접두 부호를 만들려고 한다. 만들 수 있는 부호 길이의 조합은?

  1. AA: 1, B: 2, C: 3, D: 3
  2. BA: 1, B: 2, C: 2, D: 3
  3. CA: 1, B: 1, C: 2, D: 3
정답과 해설 보기

정답: A. A: 1, B: 2, C: 3, D: 3

부호 길이가 l₁, l₂, …인 접두 부호를 만들 수 있는 것은 크래프트 부등식 Σ 2^(−lᵢ) ≤ 1이 성립할 때입니다. 1, 2, 3, 3에서는 1/2 + 1/4 + 1/8 + 1/8 = 1이므로 만들 수 있으며, 예를 들어 0, 10, 110, 111이 됩니다. 1, 2, 2, 3에서는 1/2 + 1/4 + 1/4 + 1/8 = 9/8, 1, 1, 2, 3에서는 1/2 + 1/2 + 1/4 + 1/8 = 11/8로, 둘 다 1을 넘으므로 만들 수 없습니다.

0과 1로 이루어진 접두 부호를 만들고 있다. 길이 2의 부호어 00과 01을 이미 사용하고 있을 때, 접두 부호의 조건을 유지한 채 추가할 수 있는 길이 3의 부호어의 최대 개수는?

  1. A4개
  2. B6개
  3. C8개
정답과 해설 보기

정답: A. 4개

길이 3의 비트열은 2³ = 8가지가 있지만, 00이나 01로 시작하는 000, 001, 010, 011의 4개는 사용할 수 없습니다. 나머지 100, 101, 110, 111의 4개는 00과도 01과도 앞부분의 관계가 되지 않으므로 모두 추가할 수 있습니다. 크래프트 부등식으로도 2/4 + n/8 ≤ 1에서 n ≤ 4가 됩니다.
