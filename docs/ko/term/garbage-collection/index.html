가비지 컬렉션(garbage collection)란?

SSD에서 무효가 된 데이터를 포함한 블록에서 유효한 데이터만 다른 곳으로 옮기고 블록을 지워 빈 영역을 만드는 처리.

일본어 명칭: ガベージコレクション

가비지 컬렉션(garbage collection)은(는) SRAM과 플래시 메모리 등 1개 분야의 연습 문제 6개에 나와요.

분야: SRAM과 플래시 메모리

도전해 보기: 가비지 컬렉션(garbage collection) 관련 문제

SSD의 가비지 컬렉션의 설명으로 올바른 것은 무엇입니까?

  1. A무효가 된 데이터를 포함한 블록에서 유효한 데이터를 다른 곳으로 옮기고, 블록을 소거하여 빈 영역을 만드는 처리
  2. B컴퓨터 바이러스를 제거하는 처리
  3. C데이터를 압축하는 처리
정답과 해설 보기

정답: A. 무효가 된 데이터를 포함한 블록에서 유효한 데이터를 다른 곳으로 옮기고, 블록을 소거하여 빈 영역을 만드는 처리

NAND는 덮어쓰기가 불가능하고 소거는 블록 단위로만 할 수 있으므로, 재기록할 때마다 오래된 버전이 무효 페이지로 남습니다. 컨트롤러는 무효 페이지가 많은 블록을 골라 유효한 데이터를 다른 블록으로 옮긴 뒤 원래 블록을 소거하여 빈 영역을 만듭니다. 이 추가 복사가 쓰기 증폭의 원인이며, 빈 용량이 적을수록 빈번해져 쓰기 성능이 떨어집니다.

OS가 삭제한 파일의 영역을 SSD에 통지하여 가비지 컬렉션을 효율화하기 위한 명령은 무엇입니까?

  1. AECC
  2. BISPP
  3. CTRIM
정답과 해설 보기

정답: C. TRIM

파일을 삭제해도 OS는 관리 정보를 바꿔 쓸 뿐이므로, SSD는 그 데이터가 불필요해졌음을 알지 못하고 가비지 컬렉션에서 불필요하게 계속 복사합니다. TRIM 명령으로 불필요한 영역을 통지하면 SSD는 그 페이지를 무효로 취급하여 복사하지 않고 소거할 수 있으므로, 쓰기 증폭이 줄어 성능과 수명이 개선됩니다. NVMe에서는 같은 역할을 Deallocate 명령이 담당합니다.

해설 속 가비지 컬렉션(garbage collection)

  • 파일을 삭제해도 OS는 관리 정보를 바꿔 쓸 뿐이므로, SSD는 그 데이터가 불필요해졌음을 알지 못하고 가비지 컬렉션에서 불필요하게 계속 복사합니다.

    OS가 삭제한 파일의 영역을 SSD에 통지하여 가비지 컬렉션을 효율화하기 위한 명령은 무엇입니까?

  • 일부만 바꿔 쓸 때도 덮어쓰기는 할 수 없고, 새 데이터를 빈 페이지에 쓰고 오래된 페이지를 무효로 한 뒤 나중에 가비지 컬렉션으로 한꺼번에 소거합니다.

    NAND형 플래시 메모리에서 데이터를 지우는 단위로 올바른 것은 무엇입니까?

  • 오버프로비저닝은 사용자가 쓸 수 있는 용량보다 많은 플래시를 탑재하고, 여분 영역을 빈 블록 확보, 가비지 컬렉션, 불량 블록 대체에 사용하는 것입니다.

    SSD의 '오버프로비저닝'의 설명으로 올바른 것은 무엇입니까?

  • 플래시는 덮어쓰기가 불가능하고 소거가 블록 단위이므로, 가비지 컬렉션에서 유효한 데이터를 다른 블록으로 복사하는 등 추가 쓰기가 발생하여 실제 쓰기량이 호스트의 쓰기량보다 많아집니다.

    SSD의 '쓰기 증폭(Write Amplification)'의 설명으로 올바른 것은 무엇입니까?

  • 쓰기와 소거의 단위가 다르다는 것이 가비지 컬렉션 등의 관리가 필요한 근본적인 이유입니다.

    NAND형 플래시 메모리에서 데이터 읽기와 쓰기(프로그램)를 수행하는 기본 단위는 무엇입니까?
