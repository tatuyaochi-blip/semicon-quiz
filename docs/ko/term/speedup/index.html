속도 향상률(Speedup)란?

개선 전 실행 시간을 개선 후 실행 시간으로 나눈 값. 스피드업. 2이면 2배 빨라졌음을 나타낸다.

일본어 명칭: 速度向上率

속도 향상률(Speedup)은(는) 성능 분석, CPU와 아키텍처 등 2개 분야의 연습 문제 6개에 나와요.

분야: 성능 분석

도전해 보기: 속도 향상률(Speedup) 관련 문제

전체 처리의 90%를 병렬화할 수 있는 프로그램을 프로세서 수를 한없이 늘려 실행했을 때, 이론상 최대 속도 향상률은?

  1. A10배
  2. B90배
  3. C무한대
정답과 해설 보기

정답: A. 10배

암달의 법칙에서는 병렬화할 수 있는 비율을 p, 프로세서 수를 N이라 하면 속도 향상률은 1/((1 − p) + p/N)입니다. p = 0.9이면 N을 무한대로 해도 1/0.1 = 10배가 상한이고, N = 10이라도 약 5.3배에 그칩니다. 병렬화할 수 없는 부분이 조금이라도 있으면 상한이 정해지므로 순차 부분을 줄이는 것이 중요합니다. 문제의 규모를 키워 병렬 부분을 늘리는 사고방식은 구스타프슨의 법칙입니다.

성능 개선을 나타내는 '속도 향상률(스피드업)'을 구하는 방법으로 올바른 것은?

  1. A개선 전 실행 시간 ÷ 개선 후 실행 시간
  2. B개선 후 실행 시간 ÷ 개선 전 실행 시간
  3. C개선 전 실행 시간 − 개선 후 실행 시간
정답과 해설 보기

정답: A. 개선 전 실행 시간 ÷ 개선 후 실행 시간

속도 향상률은 개선 전 시간을 개선 후 시간으로 나눈 값입니다. 예를 들어 10초 걸리던 처리가 4초가 되면 10÷4=2.5배의 속도 향상입니다. '60% 짧아졌다'와 '2.5배 빨라졌다'는 같은 것을 나타내지만 표현을 혼동하기 쉬우므로 주의가 필요합니다. 병렬화의 효과를 보일 때는 코어 1개일 때의 시간을 기준으로 코어 수를 늘렸을 때의 속도 향상률을 나타냅니다.

  • 속도 향상률은 1÷0.625=1.6배입니다.

    전체 처리의 50%를 차지하는 부분을 4배 빠르게 했다. 전체의 속도 향상률은 얼마입니까?(암달의 법칙)

  • 코어 수를 바꿔 가며 속도 향상률을 측정하면 이상적으로는 코어 수에 비례하여 늘어나지만, 실제로는 병렬화할 수 없는 부분, 동기화나 통신, 메모리 대역폭 부족 등으로 어떤 수부터 증가가 둔해집니다.

    병렬 프로그램의 확장성(스케일러빌리티)을 조사하는 방법으로 가장 적절한 것은?

  • 병렬 효율은 속도 향상률을 코어 수로 나눈 값으로, 코어가 얼마나 유효하게 사용되고 있는지를 나타냅니다.

    8코어로 병렬 실행했더니 1코어일 때보다 6배 빨라졌다. 병렬 효율은 얼마입니까?
