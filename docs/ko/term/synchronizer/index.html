동기화 회로(Synchronizer)란?

비동기 신호를 수신 측 클록에 맞추는 회로로, 싱크로나이저라고도 한다. 2단 플립플롭을 직렬로 연결하는 구성이 기본이며, 1단째가 메타스터빌리티 상태가 되어도 다음 에지까지 안정될 확률을 높인다.

일본어 명칭: 同期化回路

동기화 회로(Synchronizer)은(는) IC 설계 흐름과 EDA, 논리 회로 등 2개 분야의 연습 문제 2개에 나와요.

정답과 해설 보기

정답: B. CDC(클록 도메인 크로싱) 검증

비동기 클록 사이에서 신호를 그대로 주고받으면 플립플롭 출력이 0도 1도 아닌 메타스터빌리티 상태가 되거나 데이터를 놓치는 일이 생깁니다. CDC 검증에서는 이러한 주고받는 지점을 설계에서 자동으로 찾아내고, 2단 플립플롭이나 비동기 FIFO 등의 동기화 회로가 올바르게 들어 있는지 확인합니다. 발생이 드물어 재현하기 어려우므로 일반 시뮬레이션으로는 찾기 힘든 결함을 검출할 수 있습니다.

해설 속 동기화 회로(Synchronizer)

  • CDC 검증에서는 이러한 주고받는 지점을 설계에서 자동으로 찾아내고, 2단 플립플롭이나 비동기 FIFO 등의 동기화 회로가 올바르게 들어 있는지 확인합니다.

    서로 다른 클록으로 동작하는 회로 사이에서 신호를 주고받는 부분에 동기화 회로가 올바르게 들어 있는지 전용…

  • 그래서 비동기 신호는 플립플롭을 2단 이상 연결한 동기화 회로로 받아, 1단째가 불확정이 되어도 2단째까지 확정될 확률을 충분히 높입니다(평균 고장 간격을 수천 년 이상으로).

    비동기 신호를 플립플롭으로 받았을 때 셋업 시간이나 홀드 시간을 만족하지 못해 출력이 일시적으로 0도 1도…

동기화 회로(Synchronizer)이(가) 나오는 문제 (2)

  1. 서로 다른 클록으로 동작하는 회로 사이에서 신호를 주고받는 부분에 동기화 회로가 올바르게 들어 있는지 전용 툴로 확인하는 검증을 무엇이라고 하는가?
  2. 비동기 신호를 플립플롭으로 받았을 때 셋업 시간이나 홀드 시간을 만족하지 못해 출력이 일시적으로 0도 1도 아닌 불확정 상태가 되는 것을 무엇이라고 합니까?

관련 용어

플립플롭(flip-flop) 메타스터빌리티(Metastability) 비동기 FIFO 셋업 시간(Setup Time) 홀드 시간(Hold Time) MTBF(평균 고장 간격) 핸드셰이크(Handshake) 리커버리 체크(Recovery Check) 멀티사이클 패스(Multicycle Path) 슬랙(Slack)
