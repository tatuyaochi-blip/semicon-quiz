진성 난수 생성기(true random number generator, TRNG)란?

열잡음이나 발진기 지터 같은 예측할 수 없는 물리 현상으로 난수를 만드는 회로로, 암호 키의 원천이 됩니다.

일본어 명칭: 真性乱数生成器

진성 난수 생성기(true random number generator, TRNG)은(는) 하드웨어 보안 등 1개 분야의 연습 문제 1개에 나와요.

칩에 내장되는 진성 난수 생성기(TRNG, True Random Number Generator)의 설명으로 올바른 것은?

  1. A정해진 계산식으로 시드(seed)에서 난수열을 만드는 프로그램
  2. B열잡음이나 발진기의 흔들림 등 예측할 수 없는 물리 현상을 바탕으로 난수를 만드는 회로
  3. C시계의 시각을 그대로 난수로 사용하는 회로
정답과 해설 보기

정답: B. 열잡음이나 발진기의 흔들림 등 예측할 수 없는 물리 현상을 바탕으로 난수를 만드는 회로

의사 난수는 시드를 알면 같은 열을 다시 만들 수 있으므로, 시드가 추측되면 키도 추측되어 버립니다. 진성 난수 생성기는 저항의 열잡음이나 링 발진기 주기의 흔들림 같은 예측할 수 없는 물리 현상을 바탕으로 비트를 만듭니다. 실제로는 TRNG의 출력으로 암호용 의사 난수 생성기의 시드를 만들어, 속도와 예측 불가능성을 양립시키는 경우가 많습니다.
