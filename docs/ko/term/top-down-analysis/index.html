탑다운 분석(Top-down Analysis)란?

성능 카운터를 사용하여 CPU의 명령 처리 슬롯 사용 방식을 프런트엔드·백엔드·투기 낭비·리타이어로 나누어 병목을 좁혀 가는 방법.

일본어 명칭: トップダウン分析

분야: 성능 분석

관련 용어

강한 스케일링(strong scaling) 구스타프슨의 법칙(Gustafson's Law) 기하 평균(geometric mean) 리틀의 법칙(Little's Law) 마이크로 벤치마크(Microbenchmark) 벤치마크(Benchmark) 벽시계 시간(Wall-clock Time) 병렬 효율(Parallel Efficiency) 성능 카운터(Performance Counter) 속도 향상률(Speedup)
