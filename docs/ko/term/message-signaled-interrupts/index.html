MSI(메시지 시그널 인터럽트)란?

기기가 지정된 주소에 쓰기를 수행하여 인터럽트를 알리는 방식. 전용 인터럽트 선이 필요 없고 하나의 기기가 많은 인터럽트를 가질 수 있다.

일본어 명칭: MSI(メッセージシグナル割り込み)

MSI(메시지 시그널 인터럽트)은(는) I/O 인터페이스와 버스 등 1개 분야의 연습 문제 1개에 나와요.

도전해 보기: MSI(메시지 시그널 인터럽트) 관련 문제

PCI Express에서 사용되는 MSI(메시지 시그널 인터럽트)의 특징으로 올바른 것은?

  1. A인터럽트가 있을 때마다 기기가 전화를 걸어 CPU에 알린다
  2. B인터럽트를 사용하지 않고 CPU가 항상 기기 상태를 확인한다
  3. C기기가 정해진 주소에 쓰기를 수행하여 인터럽트를 알리므로 전용 인터럽트 선이 필요 없다
정답과 해설 보기

정답: C. 기기가 정해진 주소에 쓰기를 수행하여 인터럽트를 알리므로 전용 인터럽트 선이 필요 없다

예전 기기는 인터럽트를 알리기 위한 전용 선을 가졌고, 여러 기기가 선을 공유하기도 했습니다. MSI에서는 기기가 OS가 지정한 주소에 정해진 데이터를 쓰면 그것이 인터럽트로서 CPU에 전달됩니다. 선의 수에 제약이 없으므로 하나의 기기가 많은 인터럽트를 가질 수 있어, 예를 들어 네트워크 카드가 수신 큐마다 다른 인터럽트를 다른 코어로 보낼 수 있습니다.

해설 속 MSI(메시지 시그널 인터럽트)

  • MSI에서는 기기가 OS가 지정한 주소에 정해진 데이터를 쓰면 그것이 인터럽트로서 CPU에 전달됩니다.
