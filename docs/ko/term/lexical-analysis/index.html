어휘 분석(Lexical Analysis)란?

소스 코드의 문자열을 식별자·숫자·연산자·예약어 등의 토큰(단어)으로 나누는 컴파일러의 첫 단계. 공백과 주석도 여기서 제거한다.

일본어 명칭: 字句解析

어휘 분석(Lexical Analysis)은(는) 컴파일러 등 1개 분야의 연습 문제 4개에 나와요.

분야: 컴파일러

도전해 보기: 어휘 분석(Lexical Analysis) 관련 문제

컴파일러의 어휘 분석의 역할로 올바른 것은?

  1. A프로그램의 문장이 언어의 문법에 맞는지를 트리 형태로 확인한다
  2. B소스 코드의 문자열을 식별자나 연산자 등의 토큰으로 나눈다
  3. C변수의 타입이 맞는지, 정의되지 않은 이름을 사용하지 않았는지를 검사한다
정답과 해설 보기

정답: B. 소스 코드의 문자열을 식별자나 연산자 등의 토큰으로 나눈다

어휘 분석은 컴파일러의 첫 단계로, 예를 들어 「count = count + 1;」을 식별자 count, 기호 =, 식별자 count, 기호 +, 숫자 1, 기호 ; 라는 토큰으로 나눕니다. 공백과 주석도 여기서 제거됩니다. 토큰의 규칙은 정규 표현식으로 쓸 수 있으므로 유한 오토마톤으로 빠르게 처리할 수 있습니다. 문법에 맞는지를 트리 형태로 확인하는 것은 다음 단계인 구문 분석, 타입이나 이름을 검사하는 것은 의미 분석의 역할입니다.

어휘 분석에서 토큰을 구별하는 규칙을 나타내는 데 자주 사용되는 것은?

  1. A부동소수점의 반올림 규칙
  2. B정규 표현식과 이를 처리하는 유한 오토마톤
  3. C캐시 교체 규칙
정답과 해설 보기

정답: B. 정규 표현식과 이를 처리하는 유한 오토마톤

식별자는 「영문자로 시작하고 영숫자가 이어진다」, 숫자는 「숫자가 1개 이상 이어진다」와 같이 토큰의 종류는 정규 표현식으로 간결하게 쓸 수 있습니다. 정규 표현식은 유한 오토마톤(상태의 수가 유한한 기계)으로 변환할 수 있으며, 문자를 하나 읽을 때마다 상태를 옮겨 가기만 하면 입력 길이에 비례하는 시간으로 토큰을 잘라낼 수 있습니다. 그래서 어휘 분석기는 정규 표현식으로부터 자동 생성하는 도구로 만들어지는 경우도 많습니다. 반올림이나 캐시의 규칙은 어휘 분석과 관계가 없습니다.

해설 속 어휘 분석(Lexical Analysis)

  • 어휘 분석은 컴파일러의 첫 단계로, 예를 들어 「count = count + 1;」을 식별자 count, 기호 =, 식별자 count, 기호 +, 숫자 1, 기호 ; 라는 토큰으로 나눕니다.

    컴파일러의 어휘 분석의 역할로 올바른 것은?

  • 그래서 어휘 분석기는 정규 표현식으로부터 자동 생성하는 도구로 만들어지는 경우도 많습니다.

    어휘 분석에서 토큰을 구별하는 규칙을 나타내는 데 자주 사용되는 것은?

  • 구문 분석은 어휘 분석으로 얻은 토큰의 나열이 언어의 문법에 맞는지를 검사하고, if문의 조건과 본체, 식 안의 연산 조합 같은 구조를 트리(구문 트리) 형태로 구성합니다.

    컴파일러의 구문 분석에서 하는 일로 올바른 것은?

  • 정규 문법은 어휘 분석용이며 중첩 구조는 다룰 수 없습니다.

    많은 프로그래밍 언어의 문법을 나타내는 데 사용되며 구문 분석의 기초가 되는 문법의 종류는?
