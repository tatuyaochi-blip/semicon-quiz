어휘 분석(Lexical Analysis)란?

소스 코드의 문자열을 식별자·숫자·연산자·예약어 등의 토큰(단어)으로 나누는 컴파일러의 첫 단계. 공백과 주석도 여기서 제거한다.

일본어 명칭: 字句解析

어휘 분석(Lexical Analysis)은(는) 컴파일러 등 1개 분야의 연습 문제 4개에 나와요.

분야: 컴파일러

문자에서 토큰으로

어휘 분석기(렉서)는 소스 텍스트를 한 문자씩 읽어 토큰으로 묶으며, 각 토큰은 종류와 대개 값을 가집니다. count = count + 1; 이라는 입력에서는 식별자 count, 연산자 =, 식별자 count, 연산자 +, 숫자 1, 세미콜론이 만들어집니다. 공백과 주석은 버려지고, 식별자는 심볼 테이블에 등록될 수 있으며, 이후 단계에서 오류를 정확히 보고할 수 있도록 줄 번호를 기록합니다. 그 다음 구문 분석기(파서)는 토큰 스트림만 가지고 작업합니다.

정규 표현식과 유한 오토마타

토큰 패턴은 정규 표현식으로 기술합니다. 예를 들어 식별자는 문자 뒤에 문자나 숫자가 이어지는 것, 정수는 하나 이상의 숫자입니다. 이는 비결정적 유한 오토마톤으로 변환한 뒤, 문자마다 상태를 바꾸는 결정적 유한 오토마톤(DFA)으로 변환할 수 있으므로, 렉서는 입력 길이에 비례하는 시간에 동작합니다. lex나 flex 같은 생성 도구는 패턴 목록으로부터 이 오토마톤을 자동으로 만들어 주지만, 실제 상용 컴파일러 중에는 손으로 작성한 렉서를 쓰는 경우도 많습니다.

모호성 해소

어떤 토큰을 만들지는 두 가지 규칙으로 정합니다. 최장 일치(maximal munch라고도 함)는 어떤 패턴에든 일치하는 가장 긴 문자열을 택하므로, >=는 > 뒤에 =가 오는 것이 아니라 하나의 토큰이 되고, ifx는 키워드 if 뒤에 x가 오는 것이 아니라 식별자가 됩니다. 두 패턴이 같은 최장 문자열에 일치하면 먼저 나열된 패턴이 우선하며, 이 방식으로 키워드가 일반 식별자 패턴보다 우선합니다.

어휘 분석과 구문 분석의 차이

정규 표현식은 중첩을 셀 수 없으므로, 괄호 짝이나 if 문 안의 if 문을 검사할 수 없습니다. 이는 문맥 자유 문법을 사용해 토큰으로부터 구문 트리를 만드는 구문 분석의 역할입니다. 어휘 오류는 허용되지 않는 문자나 닫히지 않은 문자열 리터럴 같은 것입니다. 세미콜론 누락이나 괄호 불균형은 파서가 찾는 구문 오류이고, 선언되지 않은 변수는 그 뒤의 의미 분석에서 검출됩니다.

컴파일러의 어휘 분석의 역할로 올바른 것은?

  1. A프로그램의 문장이 언어의 문법에 맞는지를 트리 형태로 확인한다
  2. B소스 코드의 문자열을 식별자나 연산자 등의 토큰으로 나눈다
  3. C변수의 타입이 맞는지, 정의되지 않은 이름을 사용하지 않았는지를 검사한다
정답과 해설 보기

정답: B. 소스 코드의 문자열을 식별자나 연산자 등의 토큰으로 나눈다

어휘 분석은 컴파일러의 첫 단계로, 예를 들어 「count = count + 1;」을 식별자 count, 기호 =, 식별자 count, 기호 +, 숫자 1, 기호 ; 라는 토큰으로 나눕니다. 공백과 주석도 여기서 제거됩니다. 토큰의 규칙은 정규 표현식으로 쓸 수 있으므로 유한 오토마톤으로 빠르게 처리할 수 있습니다. 문법에 맞는지를 트리 형태로 확인하는 것은 다음 단계인 구문 분석, 타입이나 이름을 검사하는 것은 의미 분석의 역할입니다.

어휘 분석에서 토큰을 구별하는 규칙을 나타내는 데 자주 사용되는 것은?

  1. A부동소수점의 반올림 규칙
  2. B정규 표현식과 이를 처리하는 유한 오토마톤
  3. C캐시 교체 규칙
정답과 해설 보기

정답: B. 정규 표현식과 이를 처리하는 유한 오토마톤

식별자는 「영문자로 시작하고 영숫자가 이어진다」, 숫자는 「숫자가 1개 이상 이어진다」와 같이 토큰의 종류는 정규 표현식으로 간결하게 쓸 수 있습니다. 정규 표현식은 유한 오토마톤(상태의 수가 유한한 기계)으로 변환할 수 있으며, 문자를 하나 읽을 때마다 상태를 옮겨 가기만 하면 입력 길이에 비례하는 시간으로 토큰을 잘라낼 수 있습니다. 그래서 어휘 분석기는 정규 표현식으로부터 자동 생성하는 도구로 만들어지는 경우도 많습니다. 반올림이나 캐시의 규칙은 어휘 분석과 관계가 없습니다.

자주 묻는 질문

렉서와 파서 차이

렉서는 정규 패턴을 이용해 문자를 토큰으로 바꾸고, 파서는 토큰의 나열을 문맥 자유 문법에 비추어 검사하며 구문 트리를 만듭니다.

컴파일러에서 토큰이란

토큰은 식별자, 키워드, 숫자, 연산자, 구두점처럼 소스 코드에서 의미를 갖는 최소 단위이며, 보통 종류와 그 텍스트 또는 값으로 저장됩니다.

최장 일치(maximal munch) 규칙이란

항상 가능한 가장 긴 일치를 택하는 렉서 규칙으로, ++나 >= 같은 입력이 쪼개지지 않고 하나의 토큰이 되도록 합니다.
