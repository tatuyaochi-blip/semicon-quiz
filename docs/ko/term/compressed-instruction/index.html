압축 명령어(compressed instruction)란?

자주 쓰는 명령을 보통보다 짧은 비트 수로 나타낸 명령. RISC-V의 C 확장은 16비트 명령을 추가해 코드 크기를 대략 25~30% 줄인다.

RISC-V의 C 확장(압축 명령어)의 주된 목적은?

  1. A데이터를 압축하여 메모리 사용량을 줄이는 명령어를 추가한다
  2. BC 언어 프로그램을 직접 실행할 수 있게 한다
  3. C자주 쓰는 명령어를 16비트로 표현하여 프로그램 크기를 줄인다
정답과 해설 보기

정답: C. 자주 쓰는 명령어를 16비트로 표현하여 프로그램 크기를 줄인다

C 확장은 자주 쓰는 명령어를 짧은 형태로 한정한 16비트 명령어로 표현합니다. 예를 들어 'addi sp, sp, -16'이나 작은 오프셋의 lw·sw입니다. 32비트 명령어와 섞어 쓸 수 있으며 코드 크기가 대략 25~30% 줄어듭니다. 프로그램이 작으면 한정된 플래시 메모리에 들어가기 쉽고 명령어 캐시에도 많이 들어가므로, 임베디드 기기에서도 고성능 CPU에서도 도움이 됩니다.

해설 속 압축 명령어(compressed instruction)

  • RISC-V의 기본 명령어는 모두 32비트이며 명령어의 경계를 바로 알 수 있습니다(압축 명령어인 C 확장을 사용하면 16비트 명령어가 섞입니다).

    RISC-V의 기본 명령어와 x86 명령어의 길이에 대해 올바른 것은?

  • M 확장은 mul·div·rem 등의 곱셈과 나눗셈, A 확장은 아토믹 명령어, F와 D는 단정밀도와 배정밀도 부동소수점, C는 16비트 압축 명령어를 추가합니다.
