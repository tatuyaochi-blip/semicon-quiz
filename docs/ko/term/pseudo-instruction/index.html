의사 명령어(pseudo-instruction)란?

어셈블리에서는 명령처럼 쓸 수 있지만 어셈블러가 하나 이상의 실제 명령으로 바꾸는 것. RISC-V의 nop, mv, li, j, ret 등.

일본어 명칭: 疑似命令

의사 명령어(pseudo-instruction)은(는) ISA와 어셈블리 등 1개 분야의 연습 문제 5개에 나와요.

분야: ISA와 어셈블리

어셈블러의 전개 방식

의사 명령어는 고유한 인코딩이 없는 어셈블리 문법으로, 어셈블러가 이를 하나 이상의 실제 명령어로 바꿉니다. RISC-V에서 nop은 addi x0, x0, 0으로, mv rd, rs는 addi rd, rs, 0으로, j label은 jal x0, label로, ret은 jalr x0, 0(ra)로, bnez rs, label은 bne rs, x0, label로 바뀝니다. 상당수는 항상 0으로 읽히고 쓰기는 버려지는 레지스터 x0에 의존합니다. 디스어셈블러는 보통 의사 명령어 형태로 되돌려 출력하므로 리스팅을 읽기가 쉬워집니다.

한 줄이 여러 명령어로

일부 의사 명령어는 가변 개수의 실제 명령어로 전개됩니다. li(load immediate)는 상수가 12비트 부호 있는 즉치값에 들어가면 addi 하나가 되지만, 더 큰 32비트 값이면 lui 뒤에 addi가 오고, 64비트 상수면 더 긴 시퀀스가 됩니다. la(load address)와 먼 함수에 대한 call은 auipc와 두 번째 명령어를 조합해 PC 상대 주소를 만듭니다. 코드 크기나 오프셋을 손으로 계산할 때는 이 점을 고려해야 합니다.

ISA가 의사 명령어에 의존하는 이유

nop, mv, 단순 점프를 별도의 하드웨어 명령어로 정의하면 기능은 늘지 않으면서 옵코드와 디코더 로직만 늘어납니다. x0을 쓰는 기존 명령어로 이미 같은 일을 할 수 있기 때문입니다. 의사 명령어는 RISC-V의 핵심 설계 목표인 작은 하드웨어 명령어 세트를 유지하면서, 함수 복귀나 0과의 비교 같은 흔한 관용구에 읽기 쉬운 이름을 프로그래머에게 제공합니다.

의사 명령어와 디렉티브, 매크로의 차이

.text, .globl, .word 같은 어셈블러 디렉티브는 어셈블러 자체에 대한 지시입니다. 섹션을 선택하거나 심볼을 외부에 공개하거나 데이터를 출력하며, 기계어 명령어에 대응하지 않습니다. 의사 명령어는 항상 툴체인이 정의한 고정된 의미의 실제 명령어로 바뀝니다. 매크로도 비슷한 전개이지만 프로그래머가 정의합니다. 툴체인이 나중에 일부 전개를 줄이기도 하는데, 예를 들어 타깃이 충분히 가까우면 링크 시에 auipc와 jalr로 된 call을 jal 하나로 바꿉니다.

도전해 보기: 의사 명령어(pseudo-instruction) 관련 문제

RISC-V의 의사 명령어 'nop'(아무것도 하지 않음)은 어셈블러에 의해 실제로 어떤 명령어로 치환되는가?

  1. Aaddi x0, x0, 0
  2. Bjal ra, 0
  3. Clw x0, 0(sp)
정답과 해설 보기

정답: A. addi x0, x0, 0

RISC-V에는 '아무것도 하지 않는' 전용 명령어가 없으며, nop은 'addi x0, x0, 0'으로 표현됩니다. x0에 대한 쓰기는 버려지므로 레지스터도 메모리도 아무것도 바뀌지 않습니다. 마찬가지로 'mv rd, rs'는 'addi rd, rs, 0', 'j label'은 'jal x0, label', 'ret'은 'jalr x0, 0(ra)'입니다. x0을 활용해 명령어의 종류를 적게 유지하는 것이 RISC-V의 설계 사상입니다.

RISC-V의 의사 명령어 'ret'은 실제로 어떤 명령어로 실행되는가?

  1. Ajal ra, 0
  2. Bjalr x0, 0(ra)
  3. Clw ra, 0(sp)
정답과 해설 보기

정답: B. jalr x0, 0(ra)

jalr(jump and link register)은 레지스터의 값에 오프셋을 더한 주소로 점프하고, 다음 명령어의 주소를 쓰기 대상에 넣습니다. ret은 'jalr x0, 0(ra)'이며, ra의 주소로 점프하고 링크는 x0에 버립니다. jalr은 함수 포인터나 가상 함수 호출처럼 목적지가 실행 시에 정해지는 점프에도 사용됩니다. ra를 복원하는 'lw ra, …'는 ret 전에 하는 준비입니다.

자주 묻는 질문

의사 명령어와 실제 명령어 차이

실제 명령어는 CPU가 실행하는 고유한 기계어 인코딩을 가집니다. 의사 명령어는 어셈블러 문법일 뿐이며, 실행 전에 하나 이상의 실제 명령어로 번역됩니다.

RISC-V li 명령어 전개

부호 있는 12비트에 들어가는 작은 상수라면 x0에서의 addi 하나, 더 큰 32비트 값이라면 lui 뒤에 addi, 64비트 상수라면 더 긴 시퀀스로 전개됩니다.

RISC-V에서 nop은 실제 명령어인가요

아닙니다. nop은 addi x0, x0, 0으로 인코딩되는 의사 명령어이며, x0에 대한 쓰기는 버려지므로 아무것도 바꾸지 않습니다.

해설 속 의사 명령어(pseudo-instruction)

  • 다만 'li'나 'mv' 같은 의사 명령어는 어셈블러가 하나 이상의 실제 명령어로 치환합니다.

  • bnez는 'bne t1, zero, loop'의 의사 명령어입니다.

    위의 RISC-V 코드를 실행 완료했을 때 t0의 값은 얼마인가?
