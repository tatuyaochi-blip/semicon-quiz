주성분 분석(PCA)란?

많은 변수를 가진 데이터를 정보를 되도록 잃지 않고 적은 변수로 나타내는 차원 축소 방법. 데이터의 분산이 가장 커지는 방향을 제1주성분으로 하고, 그와 직교하는 방향 중 분산이 가장 큰 방향을 제2주성분과 같이 차례로 구하여, 상위 주성분만으로 데이터를 나타낸다. 수학적으로는 데이터의 공분산 행렬의 고유벡터를 구하는 것에 해당한다. 데이터 시각화, 잡음 제거, 학습 전처리 등에 사용된다.

정답: C. 데이터의 흩어짐(분산)이 가장 커지는 방향부터 차례로 서로 직교하는 새 축을 구하여, 적은 수의 축으로 데이터를 나타낸다

주성분 분석은 많은 변수를 가진 데이터를 정보를 되도록 잃지 않고 적은 변수로 나타내는, 차원 축소의 대표적인 방법입니다. 데이터의 분산이 가장 커지는 방향을 제1주성분, 그와 직교하는 방향 중 분산이 가장 커지는 방향을 제2주성분과 같이 차례로 구하고, 상위 몇 개의 주성분만으로 데이터를 나타냅니다. 정답 레이블을 사용하지 않는 비지도 학습의 일종으로, 데이터 시각화나 학습 전처리에 사용됩니다. 변수마다 단위나 크기가 다르면 값이 큰 변수에 결과가 끌려가므로, 사전에 표준화하는 경우가 많습니다.
