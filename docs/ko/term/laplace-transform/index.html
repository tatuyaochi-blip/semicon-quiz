라플라스 변환(Laplace Transform)란?

시간 함수 f(t)(t ≥ 0)를 복소수 s의 함수 F(s) = ∫₀^∞ f(t)e^(−st) dt로 변환하는 방법. 초기값이 0이면 미분은 s를 곱하는 것, 적분은 s로 나누는 것에 대응하므로, 선형 미분 방정식을 s의 대수식으로 다룰 수 있다. 제어 공학에서 전달 함수를 구하는 기본 도구이며, 이산 시간 시스템에서는 z 변환이 같은 역할을 한다. 단위 계단은 1/s, e^(−at)는 1/(s + a)로 변환된다.

자주 쓰는 변환 쌍

단위 임펄스 δ(t)는 1, 단위 계단은 1/s, 램프 t는 1/s², e^(−at)는 1/(s + a), sin ωt는 ω/(s² + ω²)가 됩니다. 시간을 L만큼 늦추면 e^(−Ls)가 곱해지고, e^(−at)를 곱하면 s가 s + a로 바뀝니다. 이 쌍들과 부분 분수 분해를 조합하면 많은 응답을 표를 보면서 역변환할 수 있습니다.

최종값 정리와 초기값 정리

출력의 최종값은 sF(s)의 극점이 모두 s 평면의 왼쪽 절반에 있는 경우에 한해 lim[t→∞] f(t) = lim[s→0] sF(s)로 구할 수 있습니다. 예를 들어 전달 함수 G(s)인 시스템의 계단 응답의 최종값은 G(0)이며, 이를 정상 이득이라고 부릅니다. 초기값은 lim[t→+0] f(t) = lim[s→∞] sF(s)로 구할 수 있습니다.

푸리에 변환, z 변환과의 관계

라플라스 변환을 s = jω인 허수축 위에서 평가한 것이 푸리에 변환(주파수 응답)에 해당합니다. 샘플링한 신호에서는 z = e^(sT)로 둔 z 변환이 같은 역할을 하며, s 평면의 왼쪽 절반이 z 평면 단위원의 안쪽에 대응합니다. 그래서 연속 시간의 '극점의 실수부가 음이면 안정'은 이산 시간에서는 '극점이 단위원 안쪽에 있으면 안정'이 됩니다.

초기값을 모두 0으로 할 때, 시간 함수의 미분과 적분을 라플라스 변환한 s 영역에서 나타내는 계산의 조합으로 올바른 것은?

  1. A미분은 s를 곱하는 것, 적분은 s로 나누는 것
  2. B미분은 s로 나누는 것, 적분은 s를 곱하는 것
  3. C미분은 s를 더하는 것, 적분은 s를 빼는 것
정답과 해설 보기

정답: A. 미분은 s를 곱하는 것, 적분은 s로 나누는 것

라플라스 변환에서 f(t)의 미분은 sF(s) − f(0)에, 적분은 F(s)/s에 대응합니다. 초기값이 0이면 미분은 s를 곱하는 것, 적분은 s로 나누는 것이 되어, 미분 방정식이 s의 다항식 계산으로 바뀝니다. 예를 들어 RC 회로의 식 RC·dv/dt + v = vin은 (RCs + 1)V(s) = Vin(s)가 되어 전달 함수 1/(1 + RCs)를 얻습니다. 단위 계단 함수는 1/s로, e^(−at)는 1/(s + a)로 변환됩니다.

자주 묻는 질문

왜 제어 공학에서 라플라스 변환을 쓰나요?

미분 방정식을 대수식으로 바꿀 수 있으므로, 요소를 연결한 시스템의 전달 함수를 곱셈과 나눗셈으로 조립할 수 있기 때문입니다. 극점의 위치로 안정성이나 응답 속도도 읽어 낼 수 있습니다.

초기값이 0이 아닐 때는 어떻게 되나요?

미분의 변환은 sF(s) − f(0)이 되어 초기값 항이 남습니다. 전달 함수는 초기값을 0으로 하여 정의하므로, 초기값에 의한 응답은 따로 더해서 생각합니다.
