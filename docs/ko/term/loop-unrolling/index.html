루프 언롤링(Loop Unrolling)란?

루프 본체를 여러 번 분량으로 나열하여 반복 횟수를 줄이는 최적화. 분기와 횟수 판정의 부담이 줄고 명령을 재배열하기 쉬워지지만 코드가 커진다.

일본어 명칭: ループ展開

루프 언롤링(Loop Unrolling)은(는) 컴파일러, 메모리 계층 구조 등 2개 분야의 연습 문제 2개에 나와요.

분야: 컴파일러

루프 언롤링이 루프를 바꾸는 방식

두 배열을 요소별로 더하는 루프는 보통 요소마다 유용한 작업 외에도 카운터 증가, 비교, 조건 분기를 수행합니다. 4배로 언롤링하면 본체를 네 번 써서 한 번의 반복에서 i부터 i+3까지의 요소를 처리하고 i를 4씩 증가시키므로, 반복 횟수는 4분의 1이 되고 오버헤드는 요소 4개당 한 번만 듭니다. 반복 횟수가 언롤링 배수의 배수가 아니면 짧은 나머지 루프가 남은 요소를 처리합니다. 반복 횟수가 상수로 알려진 작은 루프는 완전히 펼칠 수도 있습니다.

코드가 빨라지는 이유

분기와 카운터의 오버헤드를 줄이는 것 외에도, 언롤링은 서로 독립적인 작업 복사본 여러 개를 하나의 기본 블록에 배치해 컴파일러의 명령어 스케줄러가 이를 섞어 배치할 자유를 줍니다. 한 복사본의 로드를 발행하는 동안 다른 복사본의 연산을 진행할 수 있어 지연 시간이 숨겨집니다. 합계 같은 리덕션에서는 여러 개의 별도 누산기로 언롤링하면 하나의 긴 의존성 사슬이 끊어집니다. 부동소수점에서는 이것이 반올림 순서를 바꾸므로 컴파일러는 허용된 경우에만 이를 수행합니다. 언롤링은 SIMD 벡터 명령어로 묶을 수 있는 연산 그룹도 드러내 줍니다.

비용과 수확 체감

복사본이 늘어날 때마다 코드가 커져 자주 실행되는 루프가 명령어 캐시에서 밀려날 수 있고, 동시에 다루는 값이 많아지면 레지스터 압박이 커져 메모리로의 스필이 생기고 이득이 상쇄될 수 있습니다. 정확한 분기 예측을 갖춘 최신 비순차 실행 프로세서는 이미 루프 오버헤드의 상당 부분을 숨기므로, 과도한 언롤링은 이점이 적은 경우가 많습니다. 그래서 컴파일러는 휴리스틱으로 언롤링 배수를 정하며, 측정 결과가 뒷받침할 때 프로그래머는 컴파일러 옵션이나 프라그마로 특정 동작을 요청할 수 있습니다.

루프 언롤링과 관련 루프 최적화의 비교

루프 언롤링은 제어 오버헤드와 스케줄링 자유도를 겨냥합니다. 강도 감소(strength reduction)는 다릅니다. 비싼 연산을 싼 연산으로 바꾸는 것으로, 예를 들어 i * 4를 매 반복마다 별도 변수에 4를 더하거나 시프트로 계산합니다. 루프 블로킹 또는 타일링은 행렬 곱셈 같은 루프를 캐시 크기의 블록 단위로 처리하도록 재구성해 데이터 재사용을 늘리며, 분기가 아니라 메모리 미스를 공략합니다. 컴파일러는 흔히 같은 루프에 이들 중 여러 가지를 함께 적용합니다.

루프 전개(루프 언롤링)의 주된 효과로 올바른 것은?

  1. A횟수 판정과 분기의 오버헤드가 줄고 명령도 재배열하기 쉬워진다
  2. B루프의 본체가 1번 분량만 남아 프로그램의 코드가 작아진다
  3. C루프를 함수로 분리하여 다른 곳에서 호출할 수 있게 한다
정답과 해설 보기

정답: A. 횟수 판정과 분기의 오버헤드가 줄고 명령도 재배열하기 쉬워진다

루프 전개는 루프의 본체를 예를 들어 4번 분량 나열해 쓰고 반복 횟수를 4분의 1로 줄이는 최적화입니다. 횟수 판정과 분기 명령이 줄 뿐 아니라, 나열한 본체끼리의 명령을 조합해 순서를 바꿀 수 있으므로 연산의 대기 시간을 메우기 쉬워집니다. 그 대신 코드는 커지고 명령 캐시를 압박하기도 합니다. 본체가 1번 분량이 되어 코드가 작아진다는 것은 반대의 설명이며, 루프를 함수로 분리하는 것은 다른 변환입니다.

자주 묻는 질문

루프 언롤링이란 무엇인가요?

루프 언롤링은 루프 본체를 여러 번 복제하고 그만큼 반복 횟수를 줄이는 컴파일러 또는 수동 최적화로, 카운터 갱신과 분기를 줄이고 스케줄링할 수 있는 명령어를 더 많이 드러냅니다.

루프 언롤링은 항상 성능을 높이나요?

아닙니다. 코드 크기와 레지스터 사용량이 늘어 명령어 캐시 미스나 레지스터 스필이 생길 수 있고, 최신 CPU에서는 남은 루프 오버헤드가 작은 경우가 많으므로 효과를 측정해야 합니다.

루프 언롤링과 루프 타일링의 차이는 무엇인가요?

언롤링은 루프 본체를 복제해 분기 오버헤드를 줄이고 명령어 수준 병렬성을 높입니다. 타일링은 반복 공간을 캐시 크기의 블록으로 나누어 데이터 재사용을 높이고 캐시 미스를 줄입니다.
