서브넷 마스크(Subnet Mask)란?

IP 주소 중 상위 몇 비트가 네트워크를 나타내는 부분(네트워크부)인지를 나타내는 32비트 값. 255.255.255.0처럼 쓰며, CIDR 표기의 /24와 같은 의미가 된다.

일본어 명칭: サブネットマスク

서브넷 마스크(Subnet Mask)은(는) 네트워크 기초 등 1개 분야의 연습 문제 7개에 나와요.

분야: 네트워크 기초

네트워크부와 호스트부

IPv4 주소의 32비트는 어느 네트워크인지를 나타내는 네트워크부와, 그 안의 어느 기기인지를 나타내는 호스트부로 나뉩니다. 서브넷 마스크는 네트워크부를 1, 호스트부를 0으로 한 값입니다. IP 주소와 서브넷 마스크의 비트별 AND를 취하면 네트워크 주소가 구해지며, 단말은 이를 사용하여 목적지가 같은 네트워크에 있는지(직접 보낼 수 있는지), 기본 게이트웨이에 넘겨야 하는지를 판단합니다.

수용할 수 있는 호스트 수의 계산

호스트부가 h비트일 때 주소는 2^h개 있지만, 호스트부가 모두 0인 네트워크 주소와 모두 1인 브로드캐스트 주소는 기기에 할당할 수 없으므로 사용할 수 있는 것은 2^h − 2개입니다. 예를 들어 255.255.255.192(/26)는 호스트부 6비트로 64 − 2 = 62개, 255.255.254.0(/23)은 호스트부 9비트로 512 − 2 = 510개입니다.

CIDR 표기와의 관계

서브넷 마스크의 1의 개수를 '/' 뒤에 쓴 것이 CIDR 표기의 프리픽스 길이로, 255.255.255.0은 /24, 255.255.240.0은 /20입니다. 마스크의 1은 반드시 상위부터 연속해서 나열되므로 프리픽스 길이만으로 같은 정보를 나타낼 수 있습니다. IPv6에서는 서브넷 마스크 표기를 사용하지 않고 2001:db8::/64처럼 프리픽스 길이로 나타냅니다.

도전해 보기: 서브넷 마스크(Subnet Mask) 관련 문제

IP 주소가 192.168.1.10, 서브넷 마스크가 255.255.255.0인 단말이 속한 네트워크의 네트워크 주소는?

  1. A192.168.0.0
  2. B192.168.1.0
  3. C192.168.1.255
정답과 해설 보기

정답: B. 192.168.1.0

서브넷 마스크는 IP 주소의 상위 몇 비트가 네트워크를 나타내는 부분(네트워크부)인지를 나타내는 32비트 값으로, 1이 나열된 부분이 네트워크부, 0인 부분이 호스트부입니다. 255.255.255.0은 상위 24비트가 1이므로 CIDR 표기로는 192.168.1.0/24처럼 '/24'라고 씁니다. IP 주소와 서브넷 마스크의 비트별 AND를 취하면 호스트부가 0이 되어 네트워크 주소 192.168.1.0을 얻습니다. 호스트부를 모두 1로 한 192.168.1.255는 브로드캐스트 주소이며 단말에는 할당하지 않습니다.

CIDR 표기 /20을 서브넷 마스크로 나타낸 것은?

  1. A255.255.240.0
  2. B255.255.255.240
  3. C255.255.248.0
정답과 해설 보기

정답: A. 255.255.240.0

/20은 상위 20비트가 1인 마스크입니다. 처음 16비트로 255.255가 되고, 나머지 4비트는 세 번째 옥텟의 상위 4비트에 들어갑니다. 2진수 11110000은 128 + 64 + 32 + 16 = 240이므로 서브넷 마스크는 255.255.240.0입니다. 호스트부는 12비트이며 2^12 − 2 = 4094대를 수용할 수 있습니다. 255.255.255.240은 상위 28비트가 1인 /28, 255.255.248.0은 상위 21비트가 1인 /21입니다.

자주 묻는 질문

255.255.255.0 서브넷 마스크에서 사용할 수 있는 호스트는 몇 개인가요?

호스트부가 8비트이므로 2^8 − 2 = 254개입니다. 네트워크 주소(끝자리 0)와 브로드캐스트 주소(끝자리 255)의 두 개는 기기에 할당할 수 없습니다.

서브넷 마스크로 네트워크 주소를 구하려면 어떻게 하나요?

IP 주소와 서브넷 마스크를 비트별로 AND합니다. 예를 들어 192.168.10.77과 255.255.255.224에서는 네 번째 옥텟이 77 AND 224 = 64가 되어, 네트워크 주소는 192.168.10.64입니다.
