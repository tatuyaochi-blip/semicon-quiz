고착 고장(Stuck-at Fault)란?

신호선의 값이 0 또는 1로 고정된다고 가정하는, 논리 회로 테스트의 기본적인 고장 모델. 스턱 앳 고장이라고도 한다.

일본어 명칭: 縮退故障

고착 고장(Stuck-at Fault)은(는) 테스트와 검사 등 1개 분야의 연습 문제 5개에 나와요.

분야: 테스트와 검사

도전해 보기: 고착 고장(Stuck-at Fault) 관련 문제

로직 회로 테스트에서 사용되는 고착 고장(스턱앳 고장) 모델에 대한 설명으로 올바른 것은 무엇입니까?

  1. A신호가 전달되는 것이 느려지는 고장
  2. B신호선의 값이 0 또는 1로 고정되어 버리는 고장
  3. C칩의 온도가 올라가는 고장
정답과 해설 보기

정답: B. 신호선의 값이 0 또는 1로 고정되어 버리는 고장

고착 고장 모델에서는 회로 내 어떤 신호선이 항상 0(0 고착) 또는 항상 1(1 고착)로 고정되는 고장을 가정하며, 신호선이 n개라면 2n개의 고장을 생각합니다. 단순하지만 단락이나 단선 등 많은 물리적 결함을 대표할 수 있어, ATPG와 고장 검출률 평가의 기본이 되고 있습니다. 신호가 느려지는 고장은 지연 고장 모델로 다루며, 온도 상승은 고장 모델이 아닙니다.

로직 회로 테스트에서, 스캔 등을 사용하여 회로의 구조상 고장(고착 고장 등)을 망라적으로 검출하는 테스트와, 실제 동작대로 기능을 확인하는 테스트의 명칭 조합으로 올바른 것은 무엇입니까?

  1. ADC 테스트와 AC 테스트
  2. B웨이퍼 테스트와 번인
  3. C스트럭처럴 테스트와 펑셔널 테스트
정답과 해설 보기

정답: C. 스트럭처럴 테스트와 펑셔널 테스트

스트럭처럴 테스트는 회로 구조에 대해 고장 모델을 생각하고 스캔 등을 사용하여 각 부분의 고장을 효율적으로 검출하는 테스트로, 고장 검출률을 수치로 관리할 수 있습니다. 펑셔널 테스트는 실제 사용 방식에 가까운 입력을 주어 사양대로 기능하는지 확인하는 테스트입니다. 전자는 망라성, 후자는 실사용에 가까운 조건에서의 확인에 강하며, 둘을 조합하여 품질을 확보합니다.

해설 속 고착 고장(Stuck-at Fault)

  • 고착 고장 모델에서는 회로 내 어떤 신호선이 항상 0(0 고착) 또는 항상 1(1 고착)로 고정되는 고장을 가정하며, 신호선이 n개라면 2n개의 고장을 생각합니다.

    로직 회로 테스트에서 사용되는 고착 고장(스턱앳 고장) 모델에 대한 설명으로 올바른 것은 무엇입니까?

  • ATPG는 고착 고장 등의 고장 모델에 기초하여, 각 고장을 출력까지 전달하여 검출할 수 있는 입력 패턴을 넷리스트로부터 자동으로 생성하는 기술입니다.

    회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것을 무엇이라고 합니까?

  • 대표적인 March C−는 셀 1개당 10회의 연산으로, 고착 고장에 더해 인접 셀끼리의 간섭(커플링 고장)이나 주소 디코더의 불량도 검출할 수 있습니다.

    메모리 테스트에서 주소를 차례로 따라가며 0과 1의 쓰기와 읽기를 반복하여, 인접 셀 간의 간섭 등의 불량…

  • 종래의 고착 고장 등의 모델은 셀의 입출력 단자에만 주목했습니다.

    표준 셀 내부 트랜지스터의 단락이나 개방 등의 결함을, 셀의 회로를 바탕으로 모델화하여 테스트 패턴을 생성…

고착 고장(Stuck-at Fault)이(가) 나오는 문제 (5)

  1. 로직 회로 테스트에서 사용되는 고착 고장(스턱앳 고장) 모델에 대한 설명으로 올바른 것은 무엇입니까?
  2. 로직 회로 테스트에서, 스캔 등을 사용하여 회로의 구조상 고장(고착 고장 등)을 망라적으로 검출하는 테스트와, 실제 동작대로 기능을 확인하는 테스트의 명칭 조합으로 올바른 것은 무엇입니까?
  3. 회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것을 무엇이라고 합니까?
  4. 메모리 테스트에서 주소를 차례로 따라가며 0과 1의 쓰기와 읽기를 반복하여, 인접 셀 간의 간섭 등의 불량도 검출하는 테스트 패턴은 무엇입니까?
  5. 표준 셀 내부 트랜지스터의 단락이나 개방 등의 결함을, 셀의 회로를 바탕으로 모델화하여 테스트 패턴을 생성하는 기법은 무엇입니까?

관련 용어
