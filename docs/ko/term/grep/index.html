grep란?

파일이나 표준 입력에서 지정한 패턴(정규 표현식)에 일치하는 줄을 찾아 표시하는 명령. -i로 대문자와 소문자를 구별하지 않고, -v로 일치하지 않는 줄을, -c로 일치한 줄의 수를, -n으로 줄 번호를 붙여 표시하며, -r로 하위 디렉터리 안까지 따라가며 찾는다. -E로 확장 정규 표현식을 쓰고, -F로 패턴을 정규 표현식이 아닌 그대로의 문자열로 다룬다. 일치하는 줄이 있으면 종료 상태 0, 없으면 1을 돌려주므로 스크립트의 조건에도 쓸 수 있다. 로그에서 오류 줄을 찾거나 파이프로 출력을 걸러 내는 등, 커맨드 라인에서 가장 자주 쓰는 명령 중 하나이다.

일본어 명칭: grep

Linux의 표준적인 디렉터리와 그곳에 놓이는 것의 조합으로 올바른 것은?

  1. A/etc: 시스템이나 서비스의 설정 파일, /var/log: 로그 파일, /usr/bin: 사용자가 쓰는 명령의 실행 파일
  2. B/etc: 사용자가 쓰는 명령의 실행 파일, /var/log: 로그 파일, /usr/bin: 시스템이나 서비스의 설정 파일
  3. C/etc: 시스템이나 서비스의 설정 파일, /var/log: 로그 파일, /usr/bin: 각 사용자의 개인 파일
정답과 해설 보기

정답: A. /etc: 시스템이나 서비스의 설정 파일, /var/log: 로그 파일, /usr/bin: 사용자가 쓰는 명령의 실행 파일

Linux의 디렉터리 배치는 FHS(파일 시스템 계층 표준)라는 규약을 대체로 따릅니다. /etc에는 시스템이나 서비스의 설정 파일, /var/log에는 로그 파일, /usr/bin에는 ls나 grep 같은 사용자가 쓰는 명령의 실행 파일이 놓입니다. 각 사용자의 개인 파일은 /home 아래에 있는 사용자별 홈 디렉터리에 놓입니다. 재부팅 등으로 사라져도 되는 임시 파일은 /tmp에 둡니다.

해설 속 grep

  • /etc에는 시스템이나 서비스의 설정 파일, /var/log에는 로그 파일, /usr/bin에는 ls나 grep 같은 사용자가 쓰는 명령의 실행 파일이 놓입니다.

    Linux의 표준적인 디렉터리와 그곳에 놓이는 것의 조합으로 올바른 것은?

  • grep의 -i는 대문자와 소문자를 구별하지 않는다는 것, -c는 일치한 '줄의 수'를 출력한다는 것을 나타냅니다.

    위의 조작에서 마지막 명령이 출력하는 값으로 올바른 것은?
