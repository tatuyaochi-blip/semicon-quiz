GPU 커널(GPU Kernel)란?

GPU 위에서 다수의 스레드가 동시에 실행하는 함수. CPU 측 프로그램에서 기동하며 각 스레드는 자신의 번호로 담당할 데이터를 고른다. OS의 커널과는 다른 의미.

일본어 명칭: GPUカーネル

GPU 커널(GPU Kernel)은(는) GPU 프로그래밍 등 1개 분야의 연습 문제 3개에 나와요.

분야: GPU 프로그래밍

도전해 보기: GPU 커널(GPU Kernel) 관련 문제

GPU 커널에서 스레드당 레지스터 사용량이 너무 많을 때 일어날 수 있는 일로 올바른 것은?

  1. A레지스터가 자동으로 늘어나 성능이 반드시 향상된다
  2. B계산 결과가 반드시 틀린다
  3. CSM의 레지스터 총수는 정해져 있으므로 동시에 올릴 수 있는 스레드 수가 줄어 메모리 지연을 숨기기 어려워진다
정답과 해설 보기

정답: C. SM의 레지스터 총수는 정해져 있으므로 동시에 올릴 수 있는 스레드 수가 줄어 메모리 지연을 숨기기 어려워진다

GPU는 실행 중인 모든 스레드의 레지스터를 칩 상에 유지함으로써 워프 전환을 순식간에 수행합니다. 따라서 한 스레드가 사용하는 레지스터가 많으면 SM에 동시에 올릴 수 있는 스레드 수가 줄어듭니다. 부족한 분량은 메모리로 밀려나(스필) 느려지기도 합니다. 컴파일러 설정으로 레지스터 상한을 지정하여 스레드 수와의 균형을 맞추기도 합니다.

GPU 커널을 작성할 때 지켜야 할 전제로 올바른 것은?

  1. A스레드는 반드시 번호가 작은 순서로 하나씩 실행된다
  2. B블록 0이 끝날 때까지 블록 1은 반드시 시작되지 않는다
  3. C스레드나 블록이 어떤 순서로 실행될지는 정해져 있지 않으므로, 결과가 실행 순서에 좌우되지 않도록 작성한다
정답과 해설 보기

정답: C. 스레드나 블록이 어떤 순서로 실행될지는 정해져 있지 않으므로, 결과가 실행 순서에 좌우되지 않도록 작성한다

GPU는 스레드와 블록을 비어 있는 자원에 차례로 할당하므로, 실행 순서는 GPU 기종이나 부하에 따라 달라집니다. 어떤 스레드가 다른 스레드가 쓴 값을 전제로 하면 우연히 올바르게 동작해도 다른 환경에서는 틀립니다. 순서가 필요한 경우에는 블록 안에서는 __syncthreads(), 블록 사이에서는 커널을 나누고, 합산에는 원자 연산이나 리덕션을 사용합니다.
