IIR 필터란?

과거의 출력을 입력 쪽으로 되돌리는 귀환을 가지며, 임펄스 응답이 무한히 계속되는 디지털 필터(무한 임펄스 응답 필터). 예를 들어 y[n] = 0.2x[n] + 0.8y[n − 1](지수 평활화)과 같은 차분 방정식으로 계산하며, 전달 함수는 분모를 갖는다. 적은 계수와 연산량으로 급준한 특성을 얻을 수 있고 지연도 작지만, 위상은 선형이 되지 않는다. 모든 극점이 단위원 안쪽에 있지 않으면 불안정해지며, 고차 필터는 계수 양자화에 약하므로 2차 섹션(바이쿼드)의 종속 접속으로 구현하는 경우가 많다. 아날로그 필터로부터 쌍선형 변환으로 설계하는 방법이 자주 사용된다.

분야: 디지털 신호 처리의 기초

도전해 보기: IIR 필터 관련 문제

지수 평활화 y[n] = 0.2x[n] + 0.8y[n − 1]로 표현되는 1차 IIR 저역 통과 필터의, 직류와 나이퀴스트 주파수에서의 이득 조합으로 올바른 것은?

  1. A직류에서 1, 나이퀴스트 주파수에서 0
  2. B직류에서 5, 나이퀴스트 주파수에서 약 0.56
  3. C직류에서 1, 나이퀴스트 주파수에서 약 0.11
정답과 해설 보기

정답: C. 직류에서 1, 나이퀴스트 주파수에서 약 0.11

전달 함수는 H(z) = 0.2/(1 − 0.8z⁻¹)이며, 직류(z = 1)에서는 0.2/(1 − 0.8) = 1, 나이퀴스트 주파수(z = −1)에서는 0.2/(1 + 0.8) = 1/9 ≈ 0.11(약 −19 dB)입니다. 새 입력에 0.2, 그때까지의 출력에 0.8의 가중치를 곱해 더하므로 가중치의 합이 1이 되어, 일정한 입력은 그대로 통과합니다. 하나 앞의 출력을 기억해 두기만 하면 과거의 입력에 지수적으로 작아지는 가중치를 곱한 평균을 얻을 수 있습니다. 극점은 z = 0.8로 단위원 안쪽에 있으므로 안정하지만, 귀환 계수가 1에 가까울수록 평활화가 강해지고 응답도 느려집니다.

차수가 높은 IIR 필터를 계수의 비트 수가 제한된 고정 소수점으로 구현할 때의 주의점으로 올바른 것은?

  1. AIIR 필터의 극점은 계수 양자화의 영향을 받지 않으므로, 계수의 비트 수는 통과 대역 이득의 정밀도만으로 정하면 된다
  2. B계수를 양자화해도 FIR 필터와 마찬가지로 반드시 안정하므로, 차수가 높아도 하나의 차분 방정식 그대로 구현하는 것이 좋다
  3. C고차의 분모를 하나의 식 그대로 구현하면 계수의 오차로 극점이 움직여 불안정해질 수 있으므로, 2차 섹션의 종속 접속으로 나눈다
정답과 해설 보기

정답: C. 고차의 분모를 하나의 식 그대로 구현하면 계수의 오차로 극점이 움직여 불안정해질 수 있으므로, 2차 섹션의 종속 접속으로 나눈다

고차 다항식의 근(극점)은 계수의 미세한 변화에 민감하며, 특히 극점이 단위원 근처에 모이는 급준한 필터에서는 계수를 반올림하기만 해도 극점이 단위원 밖으로 나가는 경우가 있습니다. 그래서 극점을 2개씩 담당하는 2차 섹션(바이쿼드)으로 나누어 종속으로 접속하면, 각 섹션의 계수 오차가 다른 극점에 영향을 주지 않아 양자화에 강해집니다. FIR 필터는 계수를 양자화해도 안정하지만, 주파수 특성은 변합니다.

  1. 지수 평활화 y[n] = 0.2x[n] + 0.8y[n − 1]로 표현되는 1차 IIR 저역 통과 필터의, 직류와 나이퀴스트 주파수에서의 이득 조합으로 올바른 것은?
  2. 차수가 높은 IIR 필터를 계수의 비트 수가 제한된 고정 소수점으로 구현할 때의 주의점으로 올바른 것은?
  3. 차분 방정식 y[n] = x[n] + 0.5y[n − 1]로 표현되는 시스템에 n = 0부터 단위 계단(n ≥ 0에서 x[n] = 1)을 입력했다. y[−1] = 0일 때, y[2]로 올바른 것은?
