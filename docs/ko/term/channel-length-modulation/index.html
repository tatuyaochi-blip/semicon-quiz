채널 길이 변조(channel-length modulation)란?

포화 상태의 MOSFET에서 드레인 전압을 높이면 핀치오프 점이 소스 쪽으로 이동하여 유효 채널이 짧아지고 드레인 전류가 약간 늘어나는 현상입니다. 이 때문에 출력 저항이 유한해집니다.

일본어 명칭: チャネル長変調

채널 길이 변조(channel-length modulation)은(는) MOSFET 등 1개 분야의 연습 문제 2개에 나와요.

분야: MOSFET

도전해 보기: 채널 길이 변조(channel-length modulation) 관련 문제

포화 영역의 MOSFET의 소신호 출력 저항 ro를 채널 길이 변조 계수 λ와 드레인 전류 ID로 나타낸 식으로 적절한 것은?

  1. Aro ≈ 1 / (λ × ID)
  2. Bro ≈ ID / λ
  3. Cro ≈ λ × ID
정답과 해설 보기

정답: A. ro ≈ 1 / (λ × ID)

채널 길이 변조를 고려하면 포화 영역의 드레인 전류는 ID(1 + λVDS) 형태로 VDS와 함께 약간 늘어나며, 이 기울기의 역수가 출력 저항 ro ≈ 1/(λID)입니다. λ는 채널 길이에 거의 반비례하므로 L을 2배로 하면 ro도 약 2배가 됩니다. 트랜지스터 단독의 최대 전압 이득은 gm·ro이며, 미세한 트랜지스터에서는 10~20배 정도밖에 안 되기 때문에 캐스코드나 다단 구성으로 이득을 확보합니다.

해설 속 채널 길이 변조(channel-length modulation)

  • 채널 길이 변조를 고려하면 포화 영역의 드레인 전류는 ID(1 + λVDS) 형태로 VDS와 함께 약간 늘어나며, 이 기울기의 역수가 출력 저항 ro ≈ 1/(λID)입니다.

  • 이것이 채널 길이 변조이며, ID = (1/2)μCox(W/L)(VGS − Vth)²(1 + λVDS)로 표현되고 출력 저항 ro ≈ 1/(λID)를 결정합니다.
