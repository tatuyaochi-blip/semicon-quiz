채널 길이 변조란?

포화 영역의 MOSFET에서 드레인 전압을 올리면 핀치오프점이 소스 쪽으로 이동하여 유효 채널 길이가 짧아지고 드레인 전류가 약간 증가하는 현상. 출력 저항을 유한하게 만든다.

일본어 명칭: チャネル長変調

채널 길이 변조은(는) MOSFET 등 1개 분야의 연습 문제 2개에 나와요.

분야: MOSFET

도전해 보기: 채널 길이 변조 관련 문제

포화 영역에 있는 MOSFET의 소신호 출력 저항 ro를 채널 길이 변조 계수 λ와 드레인 전류 ID로 나타낸 식으로 적절한 것은 무엇입니까?

  1. Aro ≈ 1 / (λ × ID)
  2. Bro ≈ ID / λ
  3. Cro ≈ λ × ID
정답과 해설 보기

정답: A. ro ≈ 1 / (λ × ID)

채널 길이 변조를 고려하면, 포화 영역의 드레인 전류는 ID(1 + λVDS) 형태로 VDS와 함께 약간 늘어나며, 이 기울기의 역수가 출력 저항 ro ≈ 1/(λID)입니다. λ는 채널 길이에 거의 반비례하므로 L을 2배로 하면 ro도 약 2배가 됩니다. 트랜지스터 단체의 최대 전압 이득은 gm·ro이며, 미세한 트랜지스터에서는 10~20배 정도밖에 안 되므로 캐스코드나 다단 구성으로 이득을 확보합니다.
