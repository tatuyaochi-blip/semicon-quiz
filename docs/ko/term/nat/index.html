NAT(네트워크 주소 변환)란?

Network Address Translation의 약자. 라우터를 지나는 패킷의 IP 주소를 바꿔 쓰는 기술. 포트 번호도 바꿔 써서 하나의 공인 주소를 많은 단말이 공유하는 것을 NAPT(IP 마스커레이드)라고 한다.

일본어 명칭: NAT

NAT(네트워크 주소 변환)은(는) 네트워크 기초 등 1개 분야의 연습 문제 2개에 나와요.

분야: 네트워크 기초

NAT와 NAPT의 구조

기본 NAT는 내부의 사설 주소와 외부의 공인 주소를 1대1로 바꿔 씁니다. 가정이나 회사에서 널리 쓰이는 NAPT는 IP 주소에 더해 출발지 포트 번호도 바꿔 쓰고, '내부의 주소와 포트'와 '외부의 포트'의 대응을 변환 테이블에 기록합니다. 돌아온 패킷은 변환 테이블을 보고 목적지를 원래대로 되돌려 써서 올바른 단말에 전달합니다. 이로써 많은 단말이 하나의 공인 주소를 동시에 사용할 수 있습니다.

IPv4 주소 부족과 NAT

IPv4 주소는 32비트로 약 43억 개밖에 없어, 인터넷이 보급되면서 새로 나눠 줄 수 있는 주소가 부족해졌습니다. NAPT는 조직 안에서는 사설 주소를 사용하고 밖으로 나갈 때만 소수의 공인 주소를 공유함으로써 이 부족을 완화해 왔습니다. 통신 사업자 쪽에서 NAPT를 한 번 더 거는 캐리어 등급 NAT(CGN)도 사용되고 있습니다. IPv6에는 충분한 주소가 있으므로 주소 절약을 위한 NAT는 기본적으로 필요하지 않습니다.

NAT의 부작용

외부에서 시작되는 통신은 변환 테이블에 대응이 없으므로 그대로는 내부 단말에 도달하지 않습니다. 이는 결과적으로 외부로부터의 연결을 막는 효과를 가지지만, 방화벽을 대신하지는 못합니다. 내부에서 서버를 공개하려면 포트 포워딩 설정이 필요하며, 단말끼리 직접 연결하는 온라인 게임이나 통화 애플리케이션에서는 NAT를 넘기 위한 기법(NAT 트래버설)이 필요해집니다.

  1. A가정 내 여러 단말이 포트 번호로 구별됨으로써 하나의 공인 IP 주소를 동시에 공유하여 인터넷과 통신할 수 있다
  2. B가정 내 단말과 인터넷 사이의 통신이 암호화되어 도중에 엿볼 수 없게 된다
  3. C가정 내 단말마다 서로 다른 공인 IP 주소가 자동으로 할당된다
정답과 해설 보기

정답: A. 가정 내 여러 단말이 포트 번호로 구별됨으로써 하나의 공인 IP 주소를 동시에 공유하여 인터넷과 통신할 수 있다

NAT(네트워크 주소 변환)는 라우터를 지나는 패킷의 출발지나 목적지 IP 주소를 바꿔 쓰는 기술입니다. NAPT는 IP 주소에 더해 포트 번호도 바꿔 쓰고, '내부의 주소와 포트'와 '외부의 포트'의 대응을 변환 테이블에 기록합니다. 그래서 사설 주소를 쓰는 여러 단말이 라우터가 가진 하나의 공인 주소를 동시에 사용할 수 있습니다. 돌아온 패킷은 변환 테이블을 보고 올바른 단말로 전달됩니다. 주소를 바꿔 쓸 뿐 암호화는 하지 않습니다. 또한 외부에서 시작되는 통신은 변환 테이블에 없으므로 그대로는 내부 단말에 도달하지 않으며, 내부에서 서버를 공개하려면 포트 포워딩 등의 설정이 필요합니다.

자주 묻는 질문

NAT와 NAPT의 차이는 무엇인가요?

NAT는 IP 주소만 바꿔 쓰며, 기본적으로 내부와 외부의 주소를 1대1로 대응시킵니다. NAPT는 포트 번호도 바꿔 쓰므로 하나의 공인 주소를 많은 단말이 동시에 공유할 수 있습니다. 가정용 라우터가 하는 것은 NAPT입니다.

NAT가 있으면 방화벽은 필요 없나요?

필요 없어지지 않습니다. NAT는 외부에서 시작되는 연결을 결과적으로 통과시키지 않는 경우가 많지만, 통신을 선별하는 규칙을 설정하는 기능이 아니며, 포트 포워딩을 설정한 통신이나 내부에서 시작한 통신은 보호할 수 없습니다.
