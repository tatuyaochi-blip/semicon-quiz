데이터 병렬(data parallelism)란?

각 GPU가 모델 전체의 복제본을 갖고 데이터를 나누어 계산한 뒤 기울기를 모든 GPU에서 평균하여 가중치를 갱신하는 분산 학습 방법.

일본어 명칭: データ並列

데이터 병렬(data parallelism)은(는) AI 하드웨어·소프트웨어 스택, GPU 프로그래밍 등 2개 분야의 연습 문제 4개에 나와요.

도전해 보기: 데이터 병렬(data parallelism) 관련 문제

여러 GPU로 학습하는 데이터 병렬의 설명으로 올바른 것은 무엇인가?

  1. A각 GPU가 모델 전체의 복제본을 가지고 데이터를 나누어 계산하며, 구한 기울기를 전 GPU에서 평균한 뒤 가중치를 갱신한다
  2. B모델의 층을 나누어 각 GPU가 서로 다른 층을 담당한다
  3. CGPU 하나만으로 계산하고 나머지 GPU는 예비로 둔다
정답과 해설 보기

정답: A. 각 GPU가 모델 전체의 복제본을 가지고 데이터를 나누어 계산하며, 구한 기울기를 전 GPU에서 평균한 뒤 가중치를 갱신한다

데이터 병렬에서는 모든 GPU가 같은 모델을 가지고 학습 데이터의 배치를 나누어 각각 순전파와 역전파를 수행합니다. 각 GPU의 기울기는 서로 다르므로 전 GPU의 기울기를 합산하여 평균하는 통신(올리듀스)을 수행하고, 모두가 같은 기울기로 가중치를 갱신하여 모델 복제본을 동일하게 유지합니다. 모델이 GPU 1장에 들어간다면 간단하고 효과적이지만, GPU 수가 늘면 통신이 무거워집니다.

해설 속 데이터 병렬(data parallelism)

  • 데이터 병렬에서는 모든 GPU가 같은 모델을 가지고 학습 데이터의 배치를 나누어 각각 순전파와 역전파를 수행합니다.

    여러 GPU로 학습하는 데이터 병렬의 설명으로 올바른 것은 무엇인가?

  • GPU는 수천 개의 스레드에 같은 처리를 할당하여 병렬로 실행하므로, 이미지의 각 픽셀 처리, 행렬 곱셈, 벡터 연산처럼 다수의 요소를 독립적으로 계산할 수 있는 작업(데이터 병렬)에서 힘을 발휘합니다.

    GPU에서 빠르게 처리할 수 있는 작업의 특징으로 가장 적절한 것은?

  • 데이터 병렬이나 파이프라인 병렬과 조합하여 거대한 모델을 학습합니다.

    GPU 1장의 메모리에 들어가지 않는 큰 층의 행렬 곱을 여러 GPU로 나누어 계산하는 텐서 병렬의 설명으…

  • 데이터 병렬 학습에서는 매번의 기울기 평균에 이 통신을 사용합니다.

    분산 학습에서 사용되는 올리듀스(All-Reduce) 통신의 역할로 올바른 것은 무엇인가?

데이터 병렬(data parallelism)이(가) 나오는 문제 (4)

  1. 여러 GPU로 학습하는 데이터 병렬의 설명으로 올바른 것은 무엇인가?
  2. GPU에서 빠르게 처리할 수 있는 작업의 특징으로 가장 적절한 것은?
  3. GPU 1장의 메모리에 들어가지 않는 큰 층의 행렬 곱을 여러 GPU로 나누어 계산하는 텐서 병렬의 설명으로 올바른 것은 무엇인가?
  4. 분산 학습에서 사용되는 올리듀스(All-Reduce) 통신의 역할로 올바른 것은 무엇인가?
