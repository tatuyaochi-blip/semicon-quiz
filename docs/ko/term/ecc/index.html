ECC(오류 정정 부호)란?

데이터에 중복 비트를 덧붙여 읽을 때 잘못된 비트를 검출·정정하는 방식. 서버용 메모리, 플래시 메모리, DDR5 칩 내부 등에서 쓰인다.

일본어 명칭: ECC(誤り訂正符号)

ECC(오류 정정 부호)은(는) DRAM, 차량용 반도체와 기능 안전, 하드웨어 보안 등 9개 분야의 연습 문제 16개에 나와요.

분야: DRAM

패리티에서 SECDED까지

패리티 비트 하나는 홀수 개의 비트 반전을 검출하지만 오류 위치는 알 수 없으며, 두 개가 반전되면 서로 상쇄됩니다. 해밍 부호는 각각 데이터 비트의 겹치는 부분 집합을 담당하는 여러 패리티 비트를 추가합니다. 읽을 때 다시 계산한 검사 결과가 신드롬을 이루어 잘못된 비트 하나를 가리키므로 그 비트를 되돌릴 수 있습니다. 전체 패리티 비트를 하나 더 두면 정정 가능한 1비트 오류와 검출만 가능한 2비트 오류를 구분할 수 있으며, 이것이 SECDED(single error correction, double error detection)입니다. 64 데이터 비트를 보호하려면 8개의 검사 비트가 필요하므로 익숙한 72비트 메모리 워드가 됩니다.

DRAM 시스템의 ECC

ECC 모듈에는 검사 비트용 추가 칩이 있습니다. x8 칩 9개가 72비트 랭크를 이루며, DDR5에서는 각 32비트 서브채널이 40비트 폭이 됩니다. 메모리 컨트롤러는 쓸 때 부호화하고 읽을 때 검사합니다. DDR5는 각 다이 내부에 128 데이터 비트당 8개의 검사 비트를 두는 온다이 ECC도 추가했지만, 이는 칩 외부에서 보이지 않고 전송 오류를 다루지 않으므로 시스템 ECC를 대체하지 못합니다. 칩킬 계열 부호는 칩 하나가 통째로 고장 나도 견디며, 컨트롤러는 보통 메모리를 스크러빙해 두 번째 오류가 누적되기 전에 1비트 오류를 고칩니다.

ECC가 막아 주는 것

전통적인 대상은 소프트 에러입니다. 패키지 재료에서 나오는 알파 입자나 우주선 중성자가 전하를 만들어 소자 손상 없이 비트를 반전시키며, 중성자 플럭스는 고도에 따라 크게 증가합니다. ECC는 가변 리텐션 시간을 가진 셀, 가끔 발생하는 로우 해머 반전, STT-MRAM의 확률적 쓰기 실패도 흡수합니다. SECDED에서의 2비트 오류처럼 부호의 능력을 넘는 오류는 정정 불가로 보고되며, 시스템은 데이터를 폐기하거나 안전 상태로 전환합니다. 정정된 오류를 기록해 두면 고장 나기 시작한 부품을 조기에 찾는 데 도움이 됩니다.

DRAM 이외의 ECC

NAND 플래시는 원시 비트 오류율이 훨씬 높고 프로그램/소거 마모와 셀당 비트 수 증가에 따라 더 높아지므로, 컨트롤러는 블록당 많은 비트를 정정하는 BCH나 LDPC 같은 더 강력한 부호를 사용합니다. 그레이 코드로 상태를 할당하면 이웃 상태로 잘못 읽어도 오류가 1비트에 그칩니다. 직렬 링크는 PCI Express 6.0의 PAM4처럼 신호 마진이 거의 없을 때 순방향 오류 정정(FEC)을 사용합니다. 차량용 칩에서는 ECC 로직 자체가 안전 메커니즘이며, 그 안의 고장은 BIST가 찾아내야 하는 잠재 고장입니다.

도전해 보기: ECC(오류 정정 부호) 관련 문제

메모리에서 사용되는 오류 정정 부호(ECC)의 역할로 올바른 것은?

  1. A데이터를 압축해 용량을 늘린다
  2. B데이터에 잉여 비트를 추가해 비트 오류를 검출·정정한다
  3. C데이터를 암호화한다
정답과 해설 보기

정답: B. 데이터에 잉여 비트를 추가해 비트 오류를 검출·정정한다

ECC는 데이터에 검사용 비트를 추가하여 읽을 때 오류를 검출·정정하는 방식입니다. 서버용 메모리에서는 64비트에 8비트를 더해 1비트 오류를 정정하고 2비트 오류를 검출하는(SECDED) 방식이 기본입니다. 더 높은 신뢰성이 필요한 서버에는 칩 1개가 통째로 고장 나도 복구할 수 있는 Chipkill 등도 있습니다. DDR5에서는 칩 내부에도 ECC가 내장되었습니다.

데이터 폭 8비트(x8)의 DRAM 칩으로 64비트 폭의 데이터 버스를 구성하려면 1랭크당 몇 개의 칩이 필요한가? (ECC 없음)

  1. A4개
  2. B64개
  3. C8개
정답과 해설 보기

정답: C. 8개

64비트 ÷ 8비트 = 8이므로, x8 칩 8개를 나란히 놓고 동시에 액세스하면 64비트 폭이 됩니다. x4 칩이라면 16개, x16이라면 4개입니다. ECC 포함 모듈은 검사 비트 8개분의 칩을 추가하여 x8이라면 9개(72비트 폭)가 됩니다. DDR5 모듈은 32비트의 서브 채널 2개로 나뉘며, ECC 포함 시 각 서브 채널이 40비트 폭이 됩니다.

자주 묻는 질문

ECC 메모리와 DDR5 온다이 ECC의 차이점

온다이 ECC는 각 DRAM 칩 내부에서 1비트 오류를 정정하고 정정된 데이터만 출력하는 반면, ECC 메모리는 추가 칩을 두어 메모리 컨트롤러가 버스에서 생긴 오류를 포함해 워드 전체를 검사합니다. 서버는 DDR5에서도 후자에 의존합니다.

SECDED ECC로 2비트 오류를 정정할 수 있나요?

아닙니다. 모든 1비트 오류는 정정하지만 2비트 오류는 검출만 할 뿐 정정할 수 없으며, 정정 불가로 보고됩니다. 칩 하나에서 생기는 다중 비트 고장을 견디려면 칩킬 같은 더 강력한 심볼 기반 부호가 필요합니다.

ECC 메모리는 64비트 데이터에 검사 비트를 몇 개 쓰나요?

표준 SECDED는 64 데이터 비트당 8개의 검사 비트를 쓰므로 각 워드는 72비트 폭이 됩니다. 그래서 x8 칩으로 만든 ECC 모듈은 랭크당 칩이 8개가 아니라 9개입니다.

  9. 다치(MLC나 TLC) NAND 플래시에서 이웃한 문턱 전압 상태에 할당하는 비트 배열을 1비트만 다르게 하는 이유로 올바른 것은 무엇입니까?
  10. STT-MRAM의 쓰기가 확률적인 성질을 가짐으로써 생기는 설계상의 과제로 올바른 것은 무엇입니까?

  13. 우주선 유래 중성자에 의한 소프트 에러 발생률이 높아지는 환경으로 올바른 것은?
  14. PAM4를 사용하면 NRZ에 비해 오류 정정(FEC)이 더 중요해지는 이유로 올바른 것은?
