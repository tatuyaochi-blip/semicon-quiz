ECC(오류 정정 부호)란?

데이터에 중복 비트를 덧붙여 읽을 때 잘못된 비트를 검출·정정하는 방식. 서버용 메모리, 플래시 메모리, DDR5 칩 내부 등에서 쓰인다.

일본어 명칭: ECC(誤り訂正符号)

ECC(오류 정정 부호)은(는) DRAM, 차량용 반도체와 기능 안전, 하드웨어 보안 등 9개 분야의 연습 문제 16개에 나와요.

분야: DRAM

도전해 보기: ECC(오류 정정 부호) 관련 문제

메모리에서 사용되는 오류 정정 부호(ECC)의 역할로 올바른 것은?

  1. A데이터를 압축해 용량을 늘린다
  2. B데이터에 잉여 비트를 추가해 비트 오류를 검출·정정한다
  3. C데이터를 암호화한다
정답과 해설 보기

정답: B. 데이터에 잉여 비트를 추가해 비트 오류를 검출·정정한다

ECC는 데이터에 검사용 비트를 추가하여 읽을 때 오류를 검출·정정하는 방식입니다. 서버용 메모리에서는 64비트에 8비트를 더해 1비트 오류를 정정하고 2비트 오류를 검출하는(SECDED) 방식이 기본입니다. 더 높은 신뢰성이 필요한 서버에는 칩 1개가 통째로 고장 나도 복구할 수 있는 Chipkill 등도 있습니다. DDR5에서는 칩 내부에도 ECC가 내장되었습니다.

데이터 폭 8비트(x8)의 DRAM 칩으로 64비트 폭의 데이터 버스를 구성하려면 1랭크당 몇 개의 칩이 필요한가? (ECC 없음)

  1. A4개
  2. B64개
  3. C8개
정답과 해설 보기

정답: C. 8개

64비트 ÷ 8비트 = 8이므로, x8 칩 8개를 나란히 놓고 동시에 액세스하면 64비트 폭이 됩니다. x4 칩이라면 16개, x16이라면 4개입니다. ECC 포함 모듈은 검사 비트 8개분의 칩을 추가하여 x8이라면 9개(72비트 폭)가 됩니다. DDR5 모듈은 32비트의 서브 채널 2개로 나뉘며, ECC 포함 시 각 서브 채널이 40비트 폭이 됩니다.

해설 속 ECC(오류 정정 부호)

  • ECC는 데이터에 검사용 비트를 추가하여 읽을 때 오류를 검출·정정하는 방식입니다.

    메모리에서 사용되는 오류 정정 부호(ECC)의 역할로 올바른 것은?

  • ECC 포함 모듈은 검사 비트 8개분의 칩을 추가하여 x8이라면 9개(72비트 폭)가 됩니다.

    데이터 폭 8비트(x8)의 DRAM 칩으로 64비트 폭의 데이터 버스를 구성하려면 1랭크당 몇 개의 칩이 …

  • 정정까지 필요한 메모리에서는 여러 패리티를 조합한 ECC(해밍 부호 등)가 사용됩니다.

    7비트 데이터 1011001에 짝수 패리티 비트를 붙일 때 패리티 비트의 값은?

  • 대책은 ECC이며, 재료의 방사성 불순물 저감도 이루어집니다.

    메모리의 소프트 에러에 대한 설명으로 올바른 것은?

  • DDR5에서는 미세화로 셀 불량과 오류가 늘어나는 것에 대응하기 위해 DRAM 칩 내부에 오류 정정 회로(온다이 ECC)가 내장되었습니다.

    DDR5에서 채택된, DRAM 칩 내부에서 오류를 정정하는 기능은?

ECC(오류 정정 부호)이(가) 나오는 문제 (16)

  1. 메모리에서 사용되는 오류 정정 부호(ECC)의 역할로 올바른 것은?
  2. 데이터 폭 8비트(x8)의 DRAM 칩으로 64비트 폭의 데이터 버스를 구성하려면 1랭크당 몇 개의 칩이 필요한가? (ECC 없음)
  3. 차량용 마이컴의 메모리에서 1비트 오류를 정정하고 2비트 오류를 검출할 수 있는 ECC(SEC-DED)를 사용하고 있다. 읽어 낸 데이터에 2비트 오류가 일어났을 때 일반적으로 어떻게 되는가?
  4. PAM4로 1파장당 약 106 Gb/s(오류 정정 부호 등을 포함)의 신호를 보낼 때의 심볼 레이트(1초당 심볼 수)에 가장 가까운 것은?
  5. 7비트 데이터 1011001에 짝수 패리티 비트를 붙일 때 패리티 비트의 값은?
  6. 메모리의 소프트 에러에 대한 설명으로 올바른 것은?
  7. DDR5에서 채택된, DRAM 칩 내부에서 오류를 정정하는 기능은?
  8. DRAM 셀 중에는 데이터 유지 시간이 시간에 따라 길어졌다 짧아졌다를 불규칙하게 반복하는 것이 있다. 이 현상을 무엇이라 하는가?
  9. 다치(MLC나 TLC) NAND 플래시에서 이웃한 문턱 전압 상태에 할당하는 비트 배열을 1비트만 다르게 하는 이유로 올바른 것은 무엇입니까?
  10. STT-MRAM의 쓰기가 확률적인 성질을 가짐으로써 생기는 설계상의 과제로 올바른 것은 무엇입니까?
  11. ISO 26262에서 말하는 잠재 고장(레이턴트 폴트)의 예로 가장 적절한 것은?
  12. 차량용 마이컴에서 전원을 켤 때나 주행 전 등에 로직 BIST나 메모리 BIST를 실행하는 기능 안전상의 주된 목적은?
  13. 우주선 유래 중성자에 의한 소프트 에러 발생률이 높아지는 환경으로 올바른 것은?
  14. PAM4를 사용하면 NRZ에 비해 오류 정정(FEC)이 더 중요해지는 이유로 올바른 것은?
  15. DRAM 로우해머(Rowhammer)에 대한 대책에 해당하는 것은 무엇입니까?
