프리차지(Precharge)란?

메모리 읽기 전에 비트 라인을 미리 정해진 전위(DRAM에서는 전원 전압의 절반 등)로 충전해 두는 동작. DRAM에서는 열려 있던 행을 닫고 다음 행의 활성화를 준비하는 조작을 가리키기도 한다.

일본어 명칭: プリチャージ

프리차지(Precharge)은(는) DRAM, SRAM과 플래시 메모리 등 2개 분야의 연습 문제 5개에 나와요.

분야: DRAM

DRAM에서 같은 행(페이지)에 연속으로 접근하면 접근 시간이 짧아지는 이유로 올바른 것은?

  1. A리프레시가 필요 없어지기 때문에
  2. B전원 전압이 올라가기 때문에
  3. C한 번 활성화한 행의 데이터가 센스 앰프에 유지되어 있어 열만 바꾸면 읽을 수 있기 때문에
정답과 해설 보기

정답: C. 한 번 활성화한 행의 데이터가 센스 앰프에 유지되어 있어 열만 바꾸면 읽을 수 있기 때문에

행을 활성화하면 그 행의 모든 셀의 데이터가 센스 앰프로 읽혀 페이지로서 열린 채 유지됩니다. 같은 행이라면 활성화를 다시 하지 않고 열 주소만 바꾸면(CAS 레이턴시만큼의 시간) 읽을 수 있어, 다른 행으로 옮겨 가는 경우(프리차지+활성화+열 접근)보다 빠릅니다. 메모리 컨트롤러는 같은 행에 대한 요청을 모으는 등 접근 순서를 재배치하여 이 페이지 히트를 늘립니다.

DRAM 내부를 여러 뱅크로 나누는 주된 목적은?

  1. A용량을 줄이기 위해
  2. B서로 다른 뱅크의 동작을 겹쳐 수행하여 실효 액세스 성능을 높이기 위해
  3. C발열을 늘리기 위해
정답과 해설 보기

정답: B. 서로 다른 뱅크의 동작을 겹쳐 수행하여 실효 액세스 성능을 높이기 위해

행의 활성화나 프리차지에는 십수 ns가 걸립니다. 내부를 여러 뱅크로 나누면 어떤 뱅크가 이러한 동작을 하는 동안 다른 뱅크에 액세스할 수 있어, 대기 시간을 숨기고 전송 효율을 높일 수 있습니다. DDR4는 16뱅크(4개의 뱅크 그룹), DDR5는 32뱅크입니다. 여러 뱅크에서 서로 다른 행을 열어 둘 수 있으므로 페이지 히트의 기회도 늘어납니다.

  • 같은 행이라면 활성화를 다시 하지 않고 열 주소만 바꾸면(CAS 레이턴시만큼의 시간) 읽을 수 있어, 다른 행으로 옮겨 가는 경우(프리차지+활성화+열 접근)보다 빠릅니다.

  • SRAM 읽기에서는 먼저 한 쌍의 비트 라인을 전원 전압으로 프리차지하고, 워드 라인으로 셀을 선택하면 0을 유지하는 쪽 비트 라인이 액세스 트랜지스터를 통해 조금 방전됩니다.

    SRAM 읽기에서 비트 라인을 미리 전원 전압 등으로 충전해 두는 동작을 무엇이라고 합니까?

  • 읽기 시 0을 유지하는 노드에는 프리차지된 비트 라인에서 액세스 트랜지스터를 통해 전류가 흘러들어 전압이 조금 올라갑니다.

프리차지(Precharge)이(가) 나오는 문제 (5)

  1. DRAM에서 같은 행(페이지)에 연속으로 접근하면 접근 시간이 짧아지는 이유로 올바른 것은?
  2. DRAM 내부를 여러 뱅크로 나누는 주된 목적은?
  3. DRAM 액세스에서 열려 있던 행을 닫고 비트 라인을 중간 전위로 되돌려 다음 행의 활성화를 준비하는 동작을 무엇이라 하는가?
  4. SRAM 읽기에서 비트 라인을 미리 전원 전압 등으로 충전해 두는 동작을 무엇이라고 합니까?
  5. 6T SRAM 셀에서 읽기 시 셀의 내용이 반전되지 않도록(읽기 파괴를 방지하도록) 필요한 설계로 올바른 것은 무엇입니까?
