프리차지(precharge)란?

읽기 전에 비트 라인을 정해진 전위(예: DRAM에서는 전원 전압의 절반)로 충전하는 동작입니다. DRAM에서는 열려 있는 행을 닫아 다음 행의 활성화를 준비하는 것도 뜻합니다.

일본어 명칭: プリチャージ

프리차지(precharge)은(는) DRAM, SRAM과 플래시 메모리 등 2개 분야의 연습 문제 5개에 나와요.

분야: DRAM

정답: C. 한 번 활성화한 행의 데이터가 센스 앰프에 유지되어 있어 열만 바꾸면 읽을 수 있기 때문에

행을 활성화하면 그 행의 모든 셀 데이터가 센스 앰프로 읽혀 나와 페이지로 열린 채 유지됩니다. 같은 행이라면 활성화를 다시 하지 않고 열 주소만 바꾸면(CAS 레이턴시만큼의 시간) 읽을 수 있으므로, 다른 행으로 옮겨 가는 경우(프리차지+활성화+열 접근)보다 빠릅니다. 메모리 컨트롤러는 같은 행에 대한 요청을 모으는 등 접근 순서를 재배열하여 이 페이지 히트를 늘립니다.

  2. B서로 다른 뱅크의 동작을 겹쳐 수행하여 실효 접근 성능을 높이기 위해
  3. C발열을 늘리기 위해
정답과 해설 보기

정답: B. 서로 다른 뱅크의 동작을 겹쳐 수행하여 실효 접근 성능을 높이기 위해

행 활성화나 프리차지에는 십수 ns가 걸립니다. 내부를 여러 뱅크로 나누면 어떤 뱅크가 이러한 동작을 하는 동안 다른 뱅크에 접근할 수 있어, 대기 시간을 숨기고 전송 효율을 높일 수 있습니다. DDR4는 16뱅크(4개의 뱅크 그룹), DDR5는 32뱅크입니다. 여러 뱅크에서 서로 다른 행을 열어 둘 수 있으므로 페이지 히트의 기회도 늘어납니다.

프리차지(precharge)이(가) 나오는 문제 (5)

  1. DRAM에서 같은 행(페이지)에 연속해서 접근하면 접근 시간이 짧아지는 이유로 올바른 것은?
  2. DRAM 내부를 여러 뱅크로 나누는 주된 목적은?
  3. DRAM 접근에서 열려 있던 행을 닫고 비트라인을 중간 전위로 되돌려 다음 행의 활성화에 대비하는 동작을 무엇이라 하는가?
  4. SRAM 읽기에서 비트선을 미리 전원 전압 등으로 충전해 두는 동작을 무엇이라고 부릅니까?
  5. 6T SRAM 셀에서 읽기 시 셀의 내용이 반전되지 않도록(읽기 파괴를 방지하도록) 하기 위해 필요한 설계로 올바른 것은?
