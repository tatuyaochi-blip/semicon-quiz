글리치(glitch)란?

신호 경로별 지연 차이 등으로 출력에 순간적으로 나타나는 불필요한 펄스. 조합 회로에서는 해저드라고도 하며 DA 변환기에서는 코드가 바뀔 때 발생한다.

일본어 명칭: グリッチ

글리치(glitch)은(는) 논리 회로, A/D·D/A 변환 등 2개 분야의 연습 문제 5개에 나와요.

분야: 논리 회로

도전해 보기: 글리치(glitch) 관련 문제

출력이 현재 상태만으로 결정되는 순차 회로(스테이트 머신)의 유형은?

  1. A밀리형
  2. B무어형
  3. C하버드형
정답과 해설 보기

정답: B. 무어형

무어형에서는 출력이 현재 상태만으로 결정되고, 밀리형에서는 상태와 입력 모두로 결정됩니다. 무어형은 출력이 상태 레지스터에서 직접 나오므로 글리치가 적고 안정적이며 타이밍도 예측하기 쉬운 반면, 입력에 대한 반응이 1클록 늦고 상태 수가 늘어나기 쉽습니다. 밀리형은 상태 수를 줄일 수 있고 입력에 즉시 반응하지만 입력의 변화가 출력에 직접 전달됩니다. 실제 설계에서는 둘을 조합하여 사용합니다.

조합 회로에서 입력이 변화할 때 경로별 지연 차이로 인해 출력에 순간적으로 나타나는 불필요한 펄스를 무엇이라고 합니까?

  1. A메타스터블
  2. B글리치(해저드)
  3. C래치업
정답과 해설 보기

정답: B. 글리치(해저드)

같은 입력의 변화가 서로 다른 경로로 출력에 도달할 때, 지연 차이로 출력이 순간적으로 잘못된 값이 될 수 있으며 이를 글리치(해저드)라고 합니다. 동기식 회로에서는 클록 에지까지 안정되면 기능상 문제가 없지만, 불필요한 충방전으로 소비 전력이 늘어납니다. 반면 클록, 비동기 리셋, 다른 칩으로 가는 제어 신호에 글리치가 실리면 오동작하므로 이들은 플립플롭 출력에서 직접 내보내는 것이 철칙입니다.

해설 속 글리치(glitch)

  • 무어형은 출력이 상태 레지스터에서 직접 나오므로 글리치가 적고 안정적이며 타이밍도 예측하기 쉬운 반면, 입력에 대한 반응이 1클록 늦고 상태 수가 늘어나기 쉽습니다.

    출력이 현재 상태만으로 결정되는 순차 회로(스테이트 머신)의 유형은?

  • 같은 입력의 변화가 서로 다른 경로로 출력에 도달할 때, 지연 차이로 출력이 순간적으로 잘못된 값이 될 수 있으며 이를 글리치(해저드)라고 합니다.

    조합 회로에서 입력이 변화할 때 경로별 지연 차이로 인해 출력에 순간적으로 나타나는 불필요한 펄스를 무엇이…

  • 이웃한 상태에서 1비트만 바뀌므로 2입력 게이트만으로 각 상태를 디코드할 수 있고 글리치도 일어나기 어려운 특징이 있습니다.

    n개의 플립플롭으로 구성한 존슨 카운터(트위스트 링 카운터)가 취하는 상태의 수는 몇 개입니까?

  • 상위 비트를 같은 가중치의 전류원 개수로 나타내는 온도계 코드를 사용하면 글리치와 DNL을 억제할 수 있으며, 통신 장비나 파형 발생기의 고속 DAC에 사용되고 있습니다.

    고속 DAC에 많이 사용되는 전류 스티어링형의 특징으로 옳은 것은 무엇인가?

  • 글리치는 여러 비트가 동시에 전환될 때 스위치 타이밍의 미세한 어긋남으로 중간의 잘못된 코드가 순간적으로 나타나는 것 등으로 생기는, 스파이크 모양의 출력 교란입니다.

    DAC에서 입력 코드가 전환되는 순간 출력에 나타나는 일시적인 스파이크 모양의 오차를 무엇이라 하는가?

글리치(glitch)이(가) 나오는 문제 (5)

  1. 출력이 현재 상태만으로 결정되는 순차 회로(스테이트 머신)의 유형은?
  2. 조합 회로에서 입력이 변화할 때 경로별 지연 차이로 인해 출력에 순간적으로 나타나는 불필요한 펄스를 무엇이라고 합니까?
  3. n개의 플립플롭으로 구성한 존슨 카운터(트위스트 링 카운터)가 취하는 상태의 수는 몇 개입니까?
  4. 고속 DAC에 많이 사용되는 전류 스티어링형의 특징으로 옳은 것은 무엇인가?
  5. DAC에서 입력 코드가 전환되는 순간 출력에 나타나는 일시적인 스파이크 모양의 오차를 무엇이라 하는가?
