캐시 메모리란?

CPU 가까이에 두는 고속·소용량 메모리. 자주 쓰는 데이터를 보관하여 주기억장치와의 속도 차이를 완화한다. 주로 SRAM으로 만든다.

일본어 명칭: キャッシュメモリ

정답과 해설 보기

정답: B. 자주 쓰는 데이터를 CPU 가까이에 두어 주기억장치와의 속도 차이를 완화하기 위해

CPU가 1클록(0.2~0.3 ns)에 처리하는 동안 DRAM 접근에는 수십~100 ns, 즉 수백 클록이 걸립니다. 그래서 자주 쓰는 데이터와 명령어를 고속 SRAM 캐시에 두어 대기 시간을 줄입니다. 같은 데이터를 가까운 시간 안에 다시 쓰는 시간적 지역성과 가까운 주소를 연속해서 쓰는 공간적 지역성을 이용하며, L1은 수 클록, L3도 수십 클록에 접근할 수 있습니다.

이 용어가 포함된 비교

  • DRAM과 SRAM의 차이점 한눈에 정리DRAM과 SRAM을 한 장의 표로 비교합니다. 셀 구조, 리프레시, 속도, 집적도, 비용, 전력, 대표 용도와 각각을 언제 쓰는지 안내합니다.
  • CPU와 GPU의 구조와 용도 차이CPU와 GPU를 표로 비교합니다. 설계 목표, 코어 수, 실행 모델, 캐시, 메모리 대역폭, 분기 처리, 데이터 전송, 대표 워크로드를 다룹니다.
  • 라이트스루 vs 라이트백 캐시: 차이점 설명라이트스루와 라이트백 캐시를 표로 비교합니다: 쓰기 정책, 메모리 트래픽, 속도, 일관성, 복잡도, 축출 비용, 대표 용도.
  • 폰 노이만 vs 하버드 아키텍처: 차이점 설명폰 노이만과 하버드 아키텍처를 표로 비교합니다: 메모리, 버스, 처리량, 유연성, 복잡도, 주요 장치, 수정된 하버드 설계.
