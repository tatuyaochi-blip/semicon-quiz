뷰(View)란?

관계형 데이터베이스에서 SELECT 문에 이름을 붙여 정의하는 가상의 표. 보통은 스스로 데이터를 갖지 않고, 참조할 때마다 원래 표에서 결과를 만든다. 복잡한 질의를 간단하게 하거나, 보여 줄 열이나 행을 좁혀 접근할 수 있는 범위를 제한하는 데 사용한다.

일본어 명칭: ビュー

뷰(View)은(는) 데이터베이스 기초 등 1개 분야의 연습 문제 1개에 나와요.

분야: 데이터베이스 기초

도전해 보기: 뷰(View) 관련 문제

관계형 데이터베이스의 뷰에 대한 설명으로 올바른 것은?

  1. ASELECT 문으로 정의한 가상의 표로, 보통은 스스로 데이터를 갖지 않으며 참조할 때마다 원래 표에서 결과를 만든다
  2. B원래 표의 데이터를 복제하여 저장하는 표로, 원래 표를 변경해도 뷰의 내용은 바뀌지 않는다
  3. C표의 특정 열의 값을 빠르게 찾기 위해 만드는 트리 구조의 데이터이다
정답과 해설 보기

정답: A. SELECT 문으로 정의한 가상의 표로, 보통은 스스로 데이터를 갖지 않으며 참조할 때마다 원래 표에서 결과를 만든다

뷰는 CREATE VIEW 영업부원 AS SELECT 사원번호, 이름 FROM 사원 WHERE 부서 = '영업'처럼 SELECT 문에 이름을 붙여 정의하는 가상의 표(가상 테이블)입니다. 일반적인 뷰는 스스로 데이터를 갖지 않고, 뷰를 참조할 때마다 원래 표(기본 테이블)에서 결과가 만들어지므로, 원래 표를 갱신하면 뷰의 내용에도 그대로 반영됩니다. 자주 쓰는 복잡한 질의를 간단히 쓸 수 있게 하거나, 보여 줘도 되는 열이나 행만 뷰로 만들어 이용자에게 권한을 주어 접근할 수 있는 범위를 좁히는 데 사용합니다. 한편 결과를 미리 계산하여 저장해 두는 구체화된 뷰(머티리얼라이즈드 뷰)도 있으며, 읽기는 빨라지지만 원래 표에 맞춰 내용을 갱신해야 합니다. 값을 빠르게 찾기 위한 트리 구조는 인덱스에 대한 설명입니다.

해설 속 뷰(View)

  • 뷰는 CREATE VIEW 영업부원 AS SELECT 사원번호, 이름 FROM 사원 WHERE 부서 = '영업'처럼 SELECT 문에 이름을 붙여 정의하는 가상의 표(가상 테이블)입니다.
