KGD(known good die, 양품 보증 다이)란?

패키징 전에 양품임이 확인된 칩입니다. 한 패키지에 여러 칩을 넣을 때 칩 하나만 불량이어도 모듈 전체가 못 쓰게 되므로 중요합니다.

일본어 명칭: KGD(ノウングッドダイ)

KGD(known good die, 양품 보증 다이)은(는) 테스트와 검사 등 1개 분야의 연습 문제 1개에 나와요.

분야: 테스트와 검사

도전해 보기: KGD(known good die, 양품 보증 다이) 관련 문제

여러 칩을 하나의 패키지에 실장할 때 중요해지는 KGD(Known Good Die)란 무엇입니까?

  1. A대형 칩
  2. B고장 난 칩
  3. C실장 전에 양품임이 확인된 칩(다이)
정답과 해설 보기

정답: C. 실장 전에 양품임이 확인된 칩(다이)

여러 칩을 하나의 패키지에 넣을 경우, 불량 칩이 하나라도 포함되면 다른 양품 칩까지 포함하여 패키지 전체가 불량이 됩니다. 예를 들어 양품률 99%인 칩을 8개 쌓으면 전부 양품일 확률은 0.99⁸≒92%까지 떨어집니다. 그래서 실장 전 다이 단계에서 충분히 테스트한 양품(KGD)을 사용하는 것이 중요하며, HBM이나 칩렛에서 특히 중시됩니다.
