평균 부호 길이(Average Code Length)란?

각 기호의 부호어 길이를 그 기호가 나올 확률로 가중 평균한 값. 기호 i의 확률을 pᵢ, 부호어의 길이를 lᵢ로 하여 L = Σ pᵢ lᵢ(비트/기호)로 나타낸다. 자주 나오는 기호에 짧은 부호어를 할당하면 작아지며, 가역 부호에서는 엔트로피 이상이 된다. 엔트로피를 평균 부호 길이로 나눈 값을 부호화 효율이라 한다. 예를 들어 확률 0.4, 0.3, 0.2, 0.1의 4기호를 허프만 부호로 나타내면 평균 부호 길이는 1.9비트이다.

일본어 명칭: 平均符号長

평균 부호 길이(Average Code Length)은(는) 정보 이론과 부호의 기초 등 1개 분야의 연습 문제 6개에 나와요.

분야: 정보 이론과 부호의 기초

도전해 보기: 평균 부호 길이(Average Code Length) 관련 문제

기호 A, B, C, D를 확률 0.4, 0.3, 0.2, 0.1로 서로 독립적으로 내는 정보원을 허프만 부호로 부호화한다. 1기호당 평균 부호 길이는?

  1. A약 1.85비트
  2. B1.9비트
  3. C2비트
정답과 해설 보기

정답: B. 1.9비트

허프만 부호에서는 확률이 가장 작은 두 개를 묶는 조작을 반복합니다. 0.1과 0.2를 묶어 0.3, 다음으로 0.3과 0.3을 묶어 0.6, 마지막으로 0.6과 0.4를 묶으므로, 부호 길이는 A가 1, B가 2, C와 D가 3비트가 됩니다. 평균 부호 길이는 0.4 × 1 + 0.3 × 2 + 0.2 × 3 + 0.1 × 3 = 1.9비트입니다.

기호 A~E를 확률 0.3, 0.25, 0.2, 0.15, 0.1로 서로 독립적으로 내는 정보원을 허프만 부호로 부호화한다. 같은 확률인 것을 어느 쪽부터 고르느냐에 따라 부호어는 바뀔 수 있지만, 평균 부호 길이는 바뀌지 않는다. 1기호당 평균 부호 길이는?

  1. A2.25비트
  2. B2.4비트
  3. C3비트
정답과 해설 보기

정답: A. 2.25비트

먼저 0.1과 0.15를 묶어 0.25, 다음으로 0.2와 0.25를 묶어 0.45, 남은 0.25와 0.3을 묶어 0.55, 마지막으로 0.45와 0.55를 묶습니다. 부호 길이는 A, B, C가 2비트, D와 E가 3비트가 되며, 평균 부호 길이는 (0.3 + 0.25 + 0.2) × 2 + (0.15 + 0.1) × 3 = 1.5 + 0.75 = 2.25비트입니다. 확률의 치우침이 작은 정보원에서는 1, 2, 3, 4, 4와 같은 계단식 부호 길이보다 길이가 고른 부호가 더 짧아집니다.

평균 부호 길이(Average Code Length)이(가) 나오는 문제 (6)

  1. 기호 A, B, C, D를 확률 0.4, 0.3, 0.2, 0.1로 서로 독립적으로 내는 정보원을 허프만 부호로 부호화한다. 1기호당 평균 부호 길이는?
  2. 기호 A~E를 확률 0.3, 0.25, 0.2, 0.15, 0.1로 서로 독립적으로 내는 정보원을 허프만 부호로 부호화한다. 같은 확률인 것을 어느 쪽부터 고르느냐에 따라 부호어는 바뀔 수 있지만, 평균 부호 길이는 바뀌지 않는다. 1기호당 평균 부호 길이는?
  3. 기호 A, B, C를 확률 0.6, 0.3, 0.1로 서로 독립적으로 내는 정보원이 있으며, 그 엔트로피는 약 1.30비트이다. 이 정보원을 허프만 부호로 부호화했을 때의 효율(엔트로피 ÷ 평균 부호 길이)에 가장 가까운 것은?
  4. 0을 확률 0.8, 1을 확률 0.2로 서로 독립적으로 내는 이진 정보원이 있다. 2기호씩 묶은 00, 01, 10, 11의 4종류를 각각 하나의 기호로 보고 허프만 부호로 부호화한다. 원래의 1기호당 평균 부호 길이는?
  5. 고정 길이 부호와 비교했을 때 가변 길이 부호의 설명으로 올바른 것은?
