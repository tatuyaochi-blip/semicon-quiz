결함 검사 장비란?

웨이퍼 위의 이물질과 패턴 결함을 찾는 장비. 빛을 쏘았을 때의 산란광을 검출하는 방식과 이웃한 다이의 이미지를 비교하는 방식 등이 있다.

일본어 명칭: 欠陥検査装置

결함 검사 장비은(는) 계측과 분석 등 1개 분야의 연습 문제 3개에 나와요.

분야: 계측과 분석

도전해 보기: 결함 검사 장비 관련 문제

웨이퍼 위의 이물이나 패턴 결함을 검출하는 결함 검사 장비에서 사용되는 대표적인 원리는?

  1. A빛을 쪼였을 때의 산란광 검출이나 인접한 다이의 이미지 비교
  2. B웨이퍼 무게의 변화
  3. C웨이퍼를 두드렸을 때의 소리
정답과 해설 보기

정답: A. 빛을 쪼였을 때의 산란광 검출이나 인접한 다이의 이미지 비교

이물이 있으면 쪼인 빛이 산란되므로 산란광을 검출하여 이물을 찾아냅니다. 패턴 결함은 같은 패턴을 가진 이웃 다이의 이미지와 비교하여 차이가 있는 곳을 결함으로 판단합니다. 두 다이의 비교만으로는 어느 쪽이 불량인지 알 수 없으므로 세 개의 다이를 비교하여 다수결로 판정합니다. 검출한 결함은 리뷰 SEM으로 자세히 관찰하여 분류합니다. 무게나 소리로는 결함을 알 수 없습니다.

웨이퍼 결함 검사 장비에서 패턴의 이미지를 직접 보는 명시야 방식과 비교한, 산란광만 포착하는 암시야 방식의 특징으로 올바른 것은?

  1. A이물 등으로부터의 산란광을 높은 감도로 검출할 수 있어 고속으로 넓은 범위를 검사하기 쉽다
  2. B반드시 명시야보다 해상도가 높다
  3. C이물을 검출할 수 없다
정답과 해설 보기

정답: A. 이물 등으로부터의 산란광을 높은 감도로 검출할 수 있어 고속으로 넓은 범위를 검사하기 쉽다

암시야 방식에서는 정반사된 빛을 받지 않고 이물이나 결함에서 산란된 빛만 포착하므로, 배경이 어둡고 작은 이물이 밝게 떠올라 고속으로 넓은 범위를 검사할 수 있습니다. 명시야 방식은 반사광으로 패턴의 이미지를 직접 포착하여 패턴 형상 결함 검출에 뛰어나지만 검사가 느려집니다. 그래서 이물 감시에는 암시야, 새로운 공정의 상세 평가에는 명시야로 구분하여 사용합니다.

해설 속 결함 검사 장비

  • 결함 검사 장비는 웨이퍼 1장에서 수천 개의 결함을 검출하기도 하며, 각각의 원인을 조사하려면 종류 분류가 필요합니다.

    검사에서 발견된 결함을 SEM으로 촬영하고 그 이미지로부터 결함 종류를 자동으로 분류하는 기능은?

결함 검사 장비이(가) 나오는 문제 (3)

  1. 웨이퍼 위의 이물이나 패턴 결함을 검출하는 결함 검사 장비에서 사용되는 대표적인 원리는?
  2. 웨이퍼 결함 검사 장비에서 패턴의 이미지를 직접 보는 명시야 방식과 비교한, 산란광만 포착하는 암시야 방식의 특징으로 올바른 것은?
