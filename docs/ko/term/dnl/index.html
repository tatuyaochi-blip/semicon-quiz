DNL(미분 비직선성)란?

ADC에서 인접한 코드 사이의 스텝 폭이 이상적인 1 LSB에서 얼마나 벗어나는지를 나타내는 오차. −1 LSB에 이르면 미싱 코드가 된다.

일본어 명칭: DNL(微分非直線性)

DNL(미분 비직선성)은(는) A/D·D/A 변환, 테스트와 검사 등 2개 분야의 연습 문제 7개에 나와요.

분야: A/D·D/A 변환

도전해 보기: DNL(미분 비직선성) 관련 문제

ADC의 미분 비선형성(DNL)에 대한 설명으로 옳은 것은 무엇인가?

  1. A입출력 특성 전체의 기울기(이득) 오차
  2. B인접한 코드 사이의 폭(스텝 폭)이 이상적인 1 LSB에서 벗어난 정도
  3. C입력이 0일 때 출력의 어긋남
정답과 해설 보기

정답: B. 인접한 코드 사이의 폭(스텝 폭)이 이상적인 1 LSB에서 벗어난 정도

DNL은 각 코드에 대응하는 입력의 폭(스텝 폭)이 이상적인 1 LSB에서 얼마나 벗어나는가를 나타내며, 예를 들어 폭이 1.5 LSB라면 DNL = +0.5 LSB입니다. DNL이 −1 LSB가 되면 그 코드가 나타나지 않게 되고(미싱 코드), +1 LSB를 넘으면 분해능이 실질적으로 떨어집니다. 입출력 특성 전체가 이상 직선에서 벗어난 정도는 적분 비선형성(INL), 입력 0에서 출력의 어긋남은 오프셋 오차입니다.

해설 속 DNL(미분 비직선성)

  • DNL은 각 코드에 대응하는 입력의 폭(스텝 폭)이 이상적인 1 LSB에서 얼마나 벗어나는가를 나타내며, 예를 들어 폭이 1.5 LSB라면 DNL = +0.5 LSB입니다.

    ADC의 미분 비선형성(DNL)에 대한 설명으로 옳은 것은 무엇인가?

  • DNL이 −1 LSB 이하가 된 코드는 대응하는 입력 폭이 없어져 출력에 나타나지 않습니다.

    입력을 변화시켜도 특정 출력 코드가 한 번도 나타나지 않는 ADC의 결함을 무엇이라 하는가?

  • 상위 비트를 같은 가중치의 전류원 개수로 나타내는 온도계 코드를 사용하면 글리치와 DNL을 억제할 수 있으며, 통신 장비나 파형 발생기의 고속 DAC에 사용되고 있습니다.

    고속 DAC에 많이 사용되는 전류 스티어링형의 특징으로 옳은 것은 무엇인가?

  • 반면 INL이나 DNL 같은 비선형 오차는 단순한 교정으로 제거할 수 없습니다.

    ADC의 입출력 특성에서 입력이 0일 때 출력이 0에서 벗어나 있는 오차를 무엇이라 하는가?

  • DNL을 누적한 것이 INL에 해당합니다.

    ADC의 적분 비선형성(INL)에 대한 설명으로 옳은 것은 무엇인가?

DNL(미분 비직선성)이(가) 나오는 문제 (7)

  1. ADC의 미분 비선형성(DNL)에 대한 설명으로 옳은 것은 무엇인가?
  2. 입력을 변화시켜도 특정 출력 코드가 한 번도 나타나지 않는 ADC의 결함을 무엇이라 하는가?
  3. 고속 DAC에 많이 사용되는 전류 스티어링형의 특징으로 옳은 것은 무엇인가?
  4. ADC의 입출력 특성에서 입력이 0일 때 출력이 0에서 벗어나 있는 오차를 무엇이라 하는가?
  5. ADC의 적분 비선형성(INL)에 대한 설명으로 옳은 것은 무엇인가?
  6. DAC가 "단조성을 갖는다"는 것은 무슨 뜻인가?
  7. AD 컨버터 테스트에서, 천천히 변화하는 정현파 등을 입력하고 각 출력 코드가 나타나는 횟수(히스토그램)를 세는 주된 목적은 무엇입니까?
