워치독 타이머(Watchdog Timer)란?

정해진 시간 안에 소프트웨어가 리셋(킥)하지 않으면 마이크로컨트롤러를 리셋하는 타이머. 프로그램의 폭주나 정지에서 복구시킨다.

일본어 명칭: ウォッチドッグタイマ

워치독 타이머(Watchdog Timer)은(는) CPU와 아키텍처, 임베디드 시스템과 펌웨어 등 2개 분야의 연습 문제 2개에 나와요.

마이컴에 탑재되는 워치독 타이머의 역할로 올바른 것은?

  1. A정확한 시각을 표시한다
  2. B클록 주파수를 높인다
  3. C프로그램이 폭주하여 일정 시간 안에 타이머를 클리어하지 않았을 때 시스템을 리셋한다
정답과 해설 보기

정답: C. 프로그램이 폭주하여 일정 시간 안에 타이머를 클리어하지 않았을 때 시스템을 리셋한다

워치독 타이머는 정상적인 프로그램이 주기적으로 클리어하는 것을 전제로 한 타이머로, 폭주나 정지로 클리어되지 않은 채 시간이 만료되면 마이컴을 리셋합니다. 노이즈나 예상치 못한 상태로 멈추어도 사람 손 없이 자동 복구할 수 있어 차량용 기기, 산업 기기, 원격지 장치에 필수적입니다. CPU와 별도의 클록으로 동작시키거나 너무 이른 클리어도 이상으로 보는 윈도우형으로 하여 신뢰성을 높입니다.

워치독 타이머를 리셋(킥)하는 처리를 1 ms마다의 타이머 인터럽트 핸들러 안에서 무조건 수행하는 것이 좋지 않은 이유로 올바른 것은 무엇입니까?

  1. A워치독은 인터럽트 안에서는 건드릴 수 없는 규칙이기 때문에
  2. B메인 처리가 무한 루프 등으로 멈춰도 인터럽트는 계속 동작하므로, 워치독이 이상을 검출하지 못하게 되기 때문에
  3. C1 ms마다 킥하면 워치독이 고장 나기 때문에
정답과 해설 보기

정답: B. 메인 처리가 무한 루프 등으로 멈춰도 인터럽트는 계속 동작하므로, 워치독이 이상을 검출하지 못하게 되기 때문에

워치독은 정해진 시간 안에 킥되지 않으면 마이크로컨트롤러를 리셋하여 폭주에서 회복시키는 구조입니다. 그런데 타이머 인터럽트는 메인 처리가 멈춰 있어도 계속 동작하므로, 거기에서 무조건 킥하면 멈춰 있다는 것을 알아차리지 못합니다. 메인 루프나 태스크가 각각 정상적으로 한 바퀴 돌았음을 확인하고, 모두 갖춰졌을 때만 킥하는 것이 기본입니다.
