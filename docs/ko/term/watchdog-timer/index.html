워치독 타이머(Watchdog Timer)란?

정해진 시간 안에 소프트웨어가 리셋(킥)하지 않으면 마이크로컨트롤러를 리셋하는 타이머. 프로그램의 폭주나 정지에서 복구시킨다.

일본어 명칭: ウォッチドッグタイマ

워치독 타이머(Watchdog Timer)은(는) 차량용 반도체와 기능 안전, CPU와 아키텍처, 임베디드 시스템과 펌웨어 등 3개 분야의 연습 문제 3개에 나와요.

분야: 임베디드 시스템과 펌웨어

워치독의 동작 원리

워치독은 감시 대상 프로그램과 독립적으로 동작하는 다운 카운터입니다. 소프트웨어는 주기적으로 워치독을 "킥(kick)", "피드(feed)" 또는 "서비스"해야 하며, 보통 특정 키 값을 레지스터에 써서 카운터를 다시 로드합니다. 코드가 루프에서 멈추거나, 폴트 핸들러로 빠지며 크래시하거나, 노이즈로 오동작하여 카운터가 0에 도달하면 워치독은 리셋을 발생시키고(일부 제품에서는 먼저 조기 경고 인터럽트를 발생시킴) 마이크로컨트롤러는 알려진 상태에서 다시 시작합니다. 워치독을 자체 저속 발진기로 클로킹하면 메인 클록이 고장 나더라도 워치독까지 함께 멈추지 않습니다.

어디에서 킥해야 하는가

워치독의 효용은 킥하는 위치에 따라 결정됩니다. 주기적인 타이머 인터럽트 안에서 무조건 킥하는 것은 전형적인 실수입니다. 메인 루프가 멈춰 있어도 인터럽트는 계속 발생하므로 카운터가 만료되지 않고 행(hang)이 발견되지 않습니다. 더 나은 패턴은 각 태스크나 메인 루프의 각 단계가 체크인 플래그를 설정하고, 감시 루틴이 주기 내에 모든 플래그가 설정된 경우에만 워치독을 킥한 뒤 플래그를 지우는 방식입니다. 타임아웃은 최악의 경우의 루프 시간보다 길게, 그러나 복구 시간을 제한할 수 있을 만큼 짧게 정합니다.

윈도 워치독과 표준 워치독

표준 워치독은 너무 늦게 도착한 킥만 잡아냅니다. 폴트로 인해 프로그램이 대부분의 작업을 건너뛰고 킥이 포함된 짧은 루프를 돌게 되면, 타이머가 예상보다 더 자주 서비스되어 아무것도 검출되지 않습니다. 윈도 워치독은 하한을 추가합니다. 킥은 정해진 시간 창 안에서만 받아들여지며, 너무 이른 킥은 누락된 킥과 마찬가지로 폴트로 처리됩니다. 이 방식은 단순 타임아웃이 놓치는 제어 흐름 오류를 잡아내므로, 기능 안전 설계에서 윈도 워치독이 널리 쓰입니다.

안전 시스템의 외부 워치독

자동차 및 산업용 장비에서는 워치독을 자체 클록으로 동작하는 별도의 감시 IC나 전원 관리 IC에 두는 경우가 많습니다. 이렇게 하면 발진기 고장 같은 공통 원인이 프로세서와 감시 장치를 동시에 멈추게 할 수 없습니다. 일부 외부 모니터는 문답(question-and-answer) 방식을 사용하여, 프로세서가 시간 창 안에 챌린지에 대한 올바른 응답을 반환하도록 요구합니다. 워치독 리셋 후 펌웨어는 보통 리셋 원인 레지스터를 읽어, 이벤트가 조용히 반복되지 않고 기록·분석될 수 있게 합니다.

윈도우형 워치독 타이머의 특징으로 올바른 것은?

  1. A한 번 킥되면 그 후에는 감시를 멈추고 소비 전력을 낮춘다
  2. B정해진 시간 창보다 너무 늦은 킥(타이머 클리어)뿐 아니라 너무 이른 킥도 이상으로 검출한다
  3. C킥이 늦어졌을 때는 프로그램이 무거운 처리를 하고 있다고 간주하여, 리셋을 걸지 않고 대기 시간을 자동으로 늘려 처리를 계속하게 한다
정답과 해설 보기

정답: B. 정해진 시간 창보다 너무 늦은 킥(타이머 클리어)뿐 아니라 너무 이른 킥도 이상으로 검출한다

통상의 워치독은 일정 시간 안에 킥되지 않으면 리셋을 겁니다. 그러나 프로그램이 처리의 일부를 건너뛰고 짧은 루프를 도는 것과 같은 이상에서는 킥이 일찍 와 버려 놓치는 경우가 있습니다. 윈도우형에서는 킥해도 되는 시간 창을 정하고, 창보다 너무 이르거나 너무 늦어도 이상으로 판단합니다. 차량용에서는 마이컴과는 별도의 클록으로 동작하는 외장 감시 IC에 워치독을 두어, 공통 원인으로 양쪽이 멈추지 않도록 하기도 합니다.

마이컴에 탑재되는 워치독 타이머의 역할로 올바른 것은?

  1. A정확한 시각을 표시한다
  2. B클록 주파수를 높인다
  3. C프로그램이 폭주하여 일정 시간 안에 타이머를 클리어하지 않았을 때 시스템을 리셋한다
정답과 해설 보기

정답: C. 프로그램이 폭주하여 일정 시간 안에 타이머를 클리어하지 않았을 때 시스템을 리셋한다

워치독 타이머는 정상적인 프로그램이 주기적으로 클리어하는 것을 전제로 한 타이머로, 폭주나 정지로 클리어되지 않은 채 시간이 만료되면 마이컴을 리셋합니다. 노이즈나 예상치 못한 상태로 멈추어도 사람 손 없이 자동 복구할 수 있어 차량용 기기, 산업 기기, 원격지 장치에 필수적입니다. CPU와 별도의 클록으로 동작시키거나 너무 이른 클리어도 이상으로 보는 윈도우형으로 하여 신뢰성을 높입니다.

자주 묻는 질문

워치독 타이머를 킥한다, 피드한다는 게 무슨 뜻인가요?

카운터가 만료되기 전에 다시 시작하도록 워치독의 리로드 레지스터나 서비스 레지스터에 값을 쓰는 것을 말합니다. 정상적인 소프트웨어는 이를 주기적으로 수행하며, 이를 멈추면 워치독이 칩을 리셋합니다.

타이머 인터럽트 안에서 워치독을 킥해도 되나요?

무조건적으로 킥해서는 안 됩니다. 타이머 인터럽트는 메인 코드가 멈춰 있어도 계속 동작하므로 폴트를 숨기게 됩니다. 메인 루프와 각 태스크가 정상적인 사이클을 완료했음을 확인한 후에만 킥해야 합니다.

윈도 워치독과 일반 워치독의 차이는 무엇인가요?

일반 워치독은 킥이 너무 늦게 올 때만 리셋합니다. 윈도 워치독은 너무 일찍 도착한 킥도 폴트로 처리하므로, 비정상적으로 빠르게 루프를 도는 코드를 잡아낼 수 있습니다.
