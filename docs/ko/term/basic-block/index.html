기본 블록(Basic Block)란?

중간에 분기의 입구도 출구도 없이 처음부터 끝까지 반드시 이어서 실행되는 명령의 나열. 제어 흐름 그래프의 노드가 되며 블록 내 최적화의 단위도 된다.

일본어 명칭: 基本ブロック

기본 블록(Basic Block)은(는) 컴파일러 등 1개 분야의 연습 문제 2개에 나와요.

분야: 컴파일러

도전해 보기: 기본 블록(Basic Block) 관련 문제

기본 블록에 대한 설명으로 올바른 것은?

  1. A중간에 분기의 출입이 없고 반드시 이어서 실행되는 명령의 나열
  2. B하나의 함수 안에 포함된 모든 명령을 하나로 묶은 것
  3. C루프의 본체를 여러 번 분량 나열하여 반복 횟수를 줄인 것
정답과 해설 보기

정답: A. 중간에 분기의 출입이 없고 반드시 이어서 실행되는 명령의 나열

기본 블록은 입구가 맨 앞뿐이고 출구가 맨 끝뿐인 명령의 나열로, 일단 실행이 시작되면 도중에 빠져나가거나 도중에 들어오는 일이 없습니다. 분기의 목적지가 되는 명령이나 분기 명령의 바로 뒤에서 구분하여 만듭니다. 블록 안에서는 실행 순서가 정해져 있으므로 국소적인 최적화가 쉽고, 블록을 노드로 한 제어 흐름 그래프로 전체의 흐름을 나타냅니다. 함수 전체는 보통 여러 개의 기본 블록으로 이루어지며, 루프 본체를 나열하는 것은 루프 전개입니다.

해설 속 기본 블록(Basic Block)

  • 기본 블록은 입구가 맨 앞뿐이고 출구가 맨 끝뿐인 명령의 나열로, 일단 실행이 시작되면 도중에 빠져나가거나 도중에 들어오는 일이 없습니다.

    기본 블록에 대한 설명으로 올바른 것은?

  • 제어 흐름 그래프는 기본 블록을 노드로, 어떤 블록의 실행 뒤에 이어질 가능성이 있는 블록으로의 전이(조건 분기의 양쪽 목적지나 그대로 다음 블록으로 진행하는 흐름)를 화살표로 나타낸 그래프입니다.

    제어 흐름 그래프에서 노드와 화살표가 나타내는 것의 조합으로 올바른 것은?
