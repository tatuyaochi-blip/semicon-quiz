GPU란?

Graphics Processing Unit의 약어. 단순한 연산기를 다수 갖추고 대량의 데이터를 병렬로 처리하는 프로세서. 영상 처리 외에 AI의 학습과 추론에 널리 사용된다.

일본어 명칭: GPU

GPU은(는) GPU 프로그래밍, AI 하드웨어·소프트웨어 스택, 첨단 패키징(3D와 칩렛) 등 11개 분야의 연습 문제 81개에 나와요.

도전해 보기: GPU 관련 문제

GPU의 그래픽 메모리로 사용되는 GDDR의 특징으로 올바른 것은?

  1. A데이터 전송 대역폭(속도)을 중시한 규격이다
  2. B전원을 꺼도 데이터가 남는다
  3. C느리지만 매우 저렴하다
정답과 해설 보기

정답: A. 데이터 전송 대역폭(속도)을 중시한 규격이다

GDDR은 GPU가 대량의 이미지 데이터를 고속으로 처리할 수 있도록 핀당 전송 속도를 중시한 DRAM으로, GDDR6X에서는 20 Gb/s 이상, GDDR7에서는 30 Gb/s 안팎에 달합니다(DDR5의 수 배). 기판 위에서 GPU 주위에 배치하여 짧은 배선으로 연결합니다. 용량당 비용과 소비 전력은 DDR보다 높은 편입니다. 더 넓은 대역폭이 필요한 AI용 가속기에는 적층된 HBM이 사용됩니다.

GPU가 행렬 연산이나 AI의 학습·추론에 적합한 주된 이유는?

  1. A클록 주파수가 CPU의 100배 이상이기 때문
  2. B단순한 연산기를 다수 갖추고 있어 대량의 데이터를 병렬로 처리할 수 있기 때문
  3. C메모리를 갖지 않기 때문
정답과 해설 보기

정답: B. 단순한 연산기를 다수 갖추고 있어 대량의 데이터를 병렬로 처리할 수 있기 때문

GPU는 원래 화면의 수많은 화소를 동시에 처리하기 위해 단순한 연산기를 수천~1만 개 이상 늘어놓은 구조를 가지고 있습니다. 행렬 연산처럼 같은 계산을 대량의 데이터에 반복하는 처리에서는 이 병렬성으로 높은 성능을 발휘합니다. 최근에는 행렬 연산 전용 유닛(Tensor Core 등)과 광대역 HBM을 갖추어 AI 학습의 주역이 되었습니다. 분기가 많은 순차적 처리는 CPU가 더 잘합니다.
