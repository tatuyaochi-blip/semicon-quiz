GPU란?

Graphics Processing Unit의 약어. 단순한 연산기를 다수 갖추고 대량의 데이터를 병렬로 처리하는 프로세서. 영상 처리 외에 AI의 학습과 추론에 널리 사용된다.

일본어 명칭: GPU

GPU은(는) GPU 프로그래밍, AI 하드웨어·소프트웨어 스택, 첨단 패키징(3D와 칩렛) 등 13개 분야의 연습 문제 83개에 나와요.

분야: CPU와 아키텍처

GPU의 구성

GPU에는 많은 스트리밍 멀티프로세서(SM)가 있으며, 각 SM은 자체 레지스터와 온칩 공유 메모리를 갖춘 단순한 실행 유닛의 집합입니다. CPU 코어처럼 큰 캐시와 정교한 분기 예측으로 하나의 스레드를 빠르게 만드는 대신, GPU는 수천 개의 스레드를 동시에 진행시키고 어떤 그룹이 메모리를 기다리면 다른 그룹으로 전환합니다. 이렇게 순전한 병렬성으로 지연을 숨기고 처리량을 극대화합니다. 스레드는 같은 명령을 함께 록스텝으로 발행하는 고정 크기 그룹 단위로 스케줄링되며, NVIDIA GPU에서는 32개 스레드를 워프라고 부릅니다. 이 모델을 SIMT(single instruction, multiple threads)라고 합니다.

SIMT와 CPU SIMD의 차이

CPU의 SIMD 명령은 정해진 개수의 요소를 담은 벡터 레지스터에 하나의 연산을 적용하며, 프로그래머나 컴파일러가 그 폭에 맞춰 코드를 작성해야 합니다. SIMT에서는 프로그래머가 스레드 하나에 대한 평범한 코드를 작성하고, 하드웨어가 스레드를 워프로 묶습니다. 스레드는 서로 다른 분기를 탈 수 있지만, 그러면 하드웨어가 각 경로를 차례로 실행하므로 레인이 낭비됩니다. 따라서 GPU는 각 요소를 같은 연산으로 독립적으로 처리할 때 뛰어나며, 연결 리스트 순회처럼 데이터에 의존하는 순차적 작업에는 약합니다.

병목은 메모리 대역폭

수천 개의 실행 유닛에 데이터를 공급하려면 막대한 대역폭이 필요합니다. 그래픽 보드는 최근 세대에서 핀당 20 Gb/s를 넘는 GDDR 메모리를 짧은 배선으로 GPU 주위에 배치합니다. AI 가속기는 대신 적층 HBM을 실리콘 인터포저 위 GPU 바로 옆에 배치하며(2.5D 패키징), HBM 하나에 1,024개의 데이터 라인이 있어 여러 개로 수 TB/s를 제공합니다. 소프트웨어도 협력해야 합니다. 인접한 스레드가 인접한 주소를 읽으면 접근이 소수의 넓은 트랜잭션으로 병합(코얼레싱)되므로, 보통 구조체의 배열보다 배열의 구조체가 유리합니다.

GPU 프로그램 작성 방식

CUDA 같은 프레임워크에서는 CPU가 커널, 즉 많은 GPU 스레드가 동시에 실행하는 함수를 실행(launch)합니다. 한 번의 실행은 블록으로 이루어진 그리드를 형성하며, 각 블록은 같은 SM에서 실행되고 공유 메모리로 협력할 수 있는 많은 스레드를 포함합니다. 각 스레드는 자신의 인덱스를 계산해 처리할 데이터 요소를 고르며, if (i < n) 가드는 마지막 블록의 남는 스레드가 배열 범위 밖 메모리에 접근하지 않도록 막습니다. 블록은 서로 독립적으로 실행되므로 같은 프로그램이 작은 GPU에서 큰 GPU까지 확장됩니다.

GPU의 그래픽 메모리로 사용되는 GDDR의 특징으로 올바른 것은?

  1. A데이터 전송 대역폭(속도)을 중시한 규격이다
  2. B전원을 꺼도 데이터가 남는다
  3. C느리지만 매우 저렴하다
정답과 해설 보기

정답: A. 데이터 전송 대역폭(속도)을 중시한 규격이다

GDDR은 GPU가 대량의 이미지 데이터를 고속으로 처리할 수 있도록 핀당 전송 속도를 중시한 DRAM으로, 2025년 시점의 제품 기준으로 GDDR6X에서는 20 Gb/s 이상, GDDR7에서는 30 Gb/s 안팎에 달합니다(DDR5의 수 배). 기판 위에서 GPU 주위에 배치하여 짧은 배선으로 연결합니다. 용량당 비용과 소비 전력은 DDR보다 높은 편입니다. 더 넓은 대역폭이 필요한 AI용 가속기에는 적층된 HBM이 사용됩니다.

GPU가 행렬 연산이나 AI의 학습·추론에 적합한 주된 이유는?

  1. A클록 주파수가 CPU의 100배 이상이기 때문
  2. B단순한 연산기를 다수 갖추고 있어 대량의 데이터를 병렬로 처리할 수 있기 때문
  3. C메모리를 갖지 않기 때문
정답과 해설 보기

정답: B. 단순한 연산기를 다수 갖추고 있어 대량의 데이터를 병렬로 처리할 수 있기 때문

GPU는 원래 화면의 수많은 화소를 동시에 처리하기 위해 단순한 연산기를 수천~1만 개 이상 늘어놓은 구조를 가지고 있습니다. 행렬 연산처럼 같은 계산을 대량의 데이터에 반복하는 처리에서는 이 병렬성으로 높은 성능을 발휘합니다. 최근에는 행렬 연산 전용 유닛(Tensor Core 등)과 광대역 HBM을 갖추어 AI 학습의 주역이 되었습니다. 분기가 많은 순차적 처리는 CPU가 더 잘합니다.

자주 묻는 질문

CPU와 GPU의 차이점은?

CPU는 개별 작업을 낮은 지연으로 끝내도록 최적화된 소수의 복잡한 코어를 가지며, GPU는 병렬성이 높은 작업의 총 처리량에 최적화된 다수의 단순한 코어를 가집니다. GPU는 큰 캐시에 의존하는 대신 수천 개의 스레드를 전환하며 메모리 지연을 숨깁니다.

AI에 GPU를 쓰는 이유는?

신경망의 학습과 추론은 대부분 거대한 배열에 같은 연산을 적용하는 대규모 행렬 곱셈으로 이루어지며, 이는 수천 개의 병렬 스레드에 자연스럽게 대응됩니다. HBM 같은 고대역폭 메모리가 그 유닛들에 데이터를 계속 공급합니다.

워프 다이버전스란?

같은 워프 안의 스레드가 서로 다른 분기를 탈 때 발생하며, 하드웨어가 각 경로를 차례로 실행하는 동안 다른 스레드는 쉬게 되어 효율이 떨어집니다. 워프 안에서 분기 조건을 균일하게 유지하면 이를 피할 수 있습니다.
