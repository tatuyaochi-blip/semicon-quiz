함수 포인터(Function Pointer)란?

함수의 주소를 값으로 갖는 포인터. int (*fp)(int, int) = add;처럼 인수와 반환값의 형을 포함하여 선언하고, fp(1, 2) 또는 (*fp)(1, 2)로 가리키는 함수를 호출한다. 함수 포인터의 배열을 사용하면 번호에 따라 처리를 전환하는 테이블을 만들 수 있다. 정렬의 비교 함수를 전달하는 qsort 같은 콜백, 인터럽트 벡터 테이블, 상태 기계의 각 상태 처리 등에 사용된다. 기계어로는 주소를 레지스터에 넣고 점프하는 간접 호출이 된다.

C 언어의 함수 포인터를 사용한 호출 '(*fp)(x)'는 RISC-V에서 일반적으로 어떤 명령어로 이루어지는가?

  3. Cbeq로 함수의 주소와 비교하여 같으면 점프한다
정답과 해설 보기

정답: A. 함수의 주소를 레지스터에 넣고 jalr로 그 레지스터의 주소로 점프한다

함수 포인터가 가리키는 곳은 실행 시까지 알 수 없으므로, 명령어 안에 목적지를 쓰는 jal은 사용할 수 없습니다. 그래서 포인터 값을 레지스터에 읽어 들이고 'jalr ra, 0(t0)'처럼 레지스터의 주소로 점프하며 복귀 주소는 ra에 남깁니다. C++의 가상 함수나 공유 라이브러리 함수 호출도 같은 간접 호출입니다. 목적지가 바뀌므로 CPU는 간접 분기 예측기로 목적지를 예상합니다.
