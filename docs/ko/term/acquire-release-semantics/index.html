어콰이어-릴리스(acquire-release)란?

획득(acquire) 뒤의 동작은 획득보다 앞으로 이동하지 않고, 해제(release) 앞의 동작은 해제보다 뒤로 이동하지 않는다는 순서 보장. 락의 획득과 해제에 쓰이며 완전한 배리어보다 가볍다.

일본어 명칭: アクワイア・リリース

분야: 멀티코어와 동기화

관련 용어

거짓 공유(False Sharing) 데드락(Deadlock) 데이터 레이스(Data Race) 디렉터리 방식(Directory-based Coherence) 락 프리(Lock-free) 메모리 배리어(Memory Barrier) 메모리 일관성 모델(Memory Consistency Model) 뮤텍스(Mutex) 배리어 동기화(Barrier Synchronization) 세마포어(Semaphore)
