CD-SEM란?

패턴의 선폭(CD)을 측정하기 위한 주사 전자 현미경. 리소그래피와 식각 후의 치수 관리에 쓰인다.

일본어 명칭: CD-SEM

CD-SEM은(는) 계측과 분석, 포토리소그래피 등 2개 분야의 연습 문제 4개에 나와요.

분야: 계측과 분석

도전해 보기: CD-SEM 관련 문제

CD-SEM으로 ArF 레지스트 패턴을 측정할 때, 전자선 조사로 인해 패턴이 줄어드는 현상을 무엇이라고 합니까?

  1. A슈링크(전자선에 의한 레지스트 수축)
  2. B차지업
  3. C드리프트
정답과 해설 보기

정답: A. 슈링크(전자선에 의한 레지스트 수축)

ArF 레지스트는 전자선에 약하여, 측정을 위한 전자선 조사로 분자가 분해되어 부피가 줄어들고 패턴이 수축합니다. 측정할 때마다 값이 달라지므로 조사량을 줄이거나 수축량을 미리 구하여 보정합니다. 차지업은 절연물에 전하가 쌓여 상이 일그러지는 현상, 드리프트는 상이나 장비의 값이 시간에 따라 어긋나는 현상으로, 둘 다 수축하는 현상이 아닙니다.

여러 서로 다른 계측 수법(광학식·CD-SEM·AFM 등)의 데이터를 조합하여 하나의 수법만 사용하는 것보다 정확하게 치수나 형상을 구하는 개념을 무엇이라고 합니까?

  1. A블라인드 계측
  2. B하이브리드 메트롤로지
  3. C싱글 샷
정답과 해설 보기

정답: B. 하이브리드 메트롤로지

첨단 미세 구조에서는 하나의 계측 수법만으로는 측정할 수 있는 양이나 정밀도에 한계가 있습니다. 하이브리드 메트롤로지에서는 예를 들어 XRR로 정밀하게 구한 막 두께를 광학식 치수 계측(OCD)의 해석 모델에 고정값으로 넣고 나머지 형상 값을 안정적으로 구하는 등, 서로의 약점을 보완하여 더 정확한 결과를 얻습니다. 수법별로 잘하는 양을 파악하여 조합하는 것이 중요합니다.

해설 속 CD-SEM

  • 측정에는 CD-SEM이나 스캐터로메트리가 사용됩니다.

    리소그래피에서 관리하는 'CDU'의 의미로 올바른 것은 무엇입니까?

  • 공장에서는 낮은 가속 전압으로 패턴의 선폭을 측정하는 CD-SEM이 공정 관리에 사용됩니다.

    주사 전자 현미경(SEM)의 원리로 올바른 것은?

CD-SEM이(가) 나오는 문제 (4)

  1. CD-SEM으로 ArF 레지스트 패턴을 측정할 때, 전자선 조사로 인해 패턴이 줄어드는 현상을 무엇이라고 합니까?
  2. 여러 서로 다른 계측 수법(광학식·CD-SEM·AFM 등)의 데이터를 조합하여 하나의 수법만 사용하는 것보다 정확하게 치수나 형상을 구하는 개념을 무엇이라고 합니까?
  3. 리소그래피에서 관리하는 'CDU'의 의미로 올바른 것은 무엇입니까?
  4. 주사 전자 현미경(SEM)의 원리로 올바른 것은?
