UART란?

ゆーあーと

クロックの線を使わず、送る側と受ける側が同じボーレートに合わせて通信する非同期式のシリアル通信の回路。スタートビットとストップビットで文字を区切る。

일본어 명칭: UART

UART은(는) CPU와 아키텍처 등 1개 분야의 연습 문제 2개에 나와요.

도전해 보기: UART 관련 문제

CPU, 메모리, 타이머나 ADC 등의 주변 기능을 1칩에 담아 가전이나 기기 제어에 사용되는 LSI는?

  1. AGPU
  2. B마이크로컨트롤러(마이컴)
  3. CHBM
정답과 해설 보기

정답: B. 마이크로컨트롤러(마이컴)

마이컴은 CPU에 더해 프로그램을 저장하는 플래시 메모리, 작업용 RAM, 타이머, ADC, 통신 인터페이스(UART, SPI, I²C, CAN 등)를 1칩에 집적한 LSI입니다. 가전, 자동차(1대에 수십~100개 이상), 산업 기기 등의 제어에 쓰이며 연간 수백억 개가 출하됩니다. 소형이고 저렴하며 소비 전력이 작고, 전원을 켜면 바로 동작할 수 있는 것이 특징입니다.

마이컴 등에서 주변기기의 레지스터를 메모리와 같은 주소 공간에 할당하고 일반적인 메모리 읽기/쓰기 명령어로 조작하는 방식은?

  1. A가상 메모리
  2. B메모리 맵 I/O
  3. C캐시 코히런시
정답과 해설 보기

정답: B. 메모리 맵 I/O

메모리 맵 I/O에서는 타이머나 UART 등 주변기기의 제어 레지스터에 특정 주소를 할당하고 일반적인 로드/스토어 명령어로 조작합니다. 입출력 전용 명령어를 마련하는 방식(x86의 IN/OUT 등 포트 맵 I/O)에 비해 명령어 세트를 단순하게 할 수 있어 ARM과 RISC-V 마이컴에서 표준적입니다. 주변 레지스터는 캐시하지 않고, 컴파일러가 최적화하지 못하게 하는(volatile) 등의 주의가 필요합니다.
