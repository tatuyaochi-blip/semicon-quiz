P-state란?

ぴーすてーと

動いているCPUの周波数と電圧の組み合わせで表した性能の段階。DVFSで負荷に合わせて切り替える。

일본어 명칭: P-state

분야: 전력 관리

도전해 보기: P-state 관련 문제

CPU의 P-state(P 스테이트)에 대한 설명으로 올바른 것은?

  1. ACPU가 동작 중일 때의 주파수와 전압의 조합으로 나타낸 성능 단계
  2. BCPU가 쉬고 있을 때의 휴지 깊이
  3. CCPU 패키지의 종류
정답과 해설 보기

정답: A. CPU가 동작 중일 때의 주파수와 전압의 조합으로 나타낸 성능 단계

P-state는 동작 중인 CPU의 주파수와 전압의 조합을 단계로 나눈 것으로, 높은 단계일수록 빠르고 전력도 큽니다. OS나 CPU 내부의 전원 관리 회로는 부하에 맞추어 P-state를 전환합니다(DVFS). 휴지 깊이를 나타내는 C-state와 조합하여, 할 일이 있을 때는 적절한 속도로 동작하고 할 일이 없을 때는 깊이 쉬는 식으로 관리합니다.

해설 속 P-state

  • P-state는 동작 중인 CPU의 주파수와 전압의 조합을 단계로 나눈 것으로, 높은 단계일수록 빠르고 전력도 큽니다.

    CPU의 P-state(P 스테이트)에 대한 설명으로 올바른 것은?

  • 펌웨어가 기기 구성과 전원 조작 방법을 테이블 형태로 OS에 알려 주고, OS는 이를 이용하여 슬립(S3)이나 최대 절전 모드(S4)로의 전환, CPU의 C-state와 P-state 제어, 온도에 따른 팬 제어 등을 수행합니다.
