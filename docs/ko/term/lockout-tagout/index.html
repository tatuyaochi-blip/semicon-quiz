LOTO(잠금·표지 부착)란?

장비 보수 작업 전에 전원과 가스 등의 에너지원을 차단하고 자물쇠와 표지를 달아, 작업 중 누군가 실수로 다시 투입하지 못하도록 하는 절차.

일본어 명칭: ロックアウト・タグアウト(LOTO)

분야: 환경·보건·안전

관련 용어

과불화탄소(PFC) 국소 배기 장치 리스크 평가(risk assessment) 산소 결핍(산결) 제해 장치(스크러버) 폭발 하한계(LEL) GHS RoHS 지침 SDS(안전보건자료)
