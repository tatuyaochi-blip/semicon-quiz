클록 데이터 복원(CDR)란?

수신한 데이터 신호의 변화로부터 클록 타이밍을 추출하여 비트를 판정하는 수신 회로. CDR. 클록 전용선이 필요 없어진다.

일본어 명칭: クロック・データ・リカバリ

클록 데이터 복원(CDR)은(는) I/O 인터페이스와 버스 등 1개 분야의 연습 문제 3개에 나와요.

분야: I/O 인터페이스와 버스

도전해 보기: 클록 데이터 복원(CDR) 관련 문제

고속 직렬 전송의 수신 측에 있는 클록 데이터 복원(CDR) 회로의 역할로 올바른 것은?

  1. A송신 측에서 별도의 선으로 보내오는 클록을 증폭한다
  2. B수신한 데이터 신호의 변화에서 클록 타이밍을 추출하고, 그 타이밍에 비트를 판정한다
  3. C데이터 오류를 찾아 송신 측에 재전송을 요청한다
정답과 해설 보기

정답: B. 수신한 데이터 신호의 변화에서 클록 타이밍을 추출하고, 그 타이밍에 비트를 판정한다

클록을 별도의 선으로 보내면 데이터 선과의 사이에 어긋남이 생깁니다. 그래서 고속 직렬 전송에서는 CDR 회로가 데이터의 0과 1이 전환되는 타이밍을 보고, PLL 등으로 같은 주파수·위상의 클록을 만들어 비트의 한가운데에서 데이터를 판정합니다. 따라서 데이터에는 어느 정도 빈도로 전환이 포함되어야 하며, 부호화로 이를 보장합니다.

해설 속 클록 데이터 복원(CDR)

    고속 직렬 전송의 수신 측에 있는 클록 데이터 복원(CDR) 회로의 역할로 올바른 것은?

  • 0이나 1이 길게 이어지면 수신 측 CDR이 타이밍을 놓치고, 신호의 평균 전압이 어긋나 올바르게 판정할 수 없게 됩니다.

    직렬 전송에서 8b/10b 부호화(8비트 데이터를 10비트 부호로 만들어 보내는 방식)가 사용되어 온 목적…

  • 수신 측 CDR은 이 느린 변화를 따라가며 데이터를 수신할 수 있도록 만들어져 있습니다.

  2. 직렬 전송에서 8b/10b 부호화(8비트 데이터를 10비트 부호로 만들어 보내는 방식)가 사용되어 온 목적으로 올바른 것은?
