パッシベーション膜란?

ぱっしべーしょんまく

チップの最上層に形成し、内部の回路を水分や汚染、機械的な傷から守る膜。シリコン窒化膜やポリイミドなどが使われる。

일본어 명칭: パッシベーション膜

분야: 배선 공정
