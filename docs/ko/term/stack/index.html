스택(Stack)란?

마지막에 넣은 원소를 가장 먼저 꺼내는 후입선출(LIFO) 자료 구조. 원소를 쌓는 조작을 push, 꺼내는 조작을 pop이라고 한다. 함수 호출의 복귀 주소나 지역 변수의 관리(콜 스택), 역폴란드 표기법의 수식 계산, 깊이 우선 탐색 등에 쓰인다.

도전해 보기: 스택(Stack) 관련 문제

빈 스택에 대해 push 1, push 2, pop, push 3, push 4, pop, pop의 순서로 조작했다. pop으로 꺼낸 값을 차례로 나열한 것은?

  1. A1, 2, 3
  2. B2, 3, 4
  3. C2, 4, 3
정답과 해설 보기

정답: C. 2, 4, 3

스택은 마지막에 넣은 것을 가장 먼저 꺼내는 후입선출(LIFO) 구조입니다. push 1, push 2 다음의 pop에서는 맨 위의 2가 나오고 1이 남습니다. 이어서 3, 4를 쌓으면 위에서부터 4, 3, 1의 순서로 놓이므로, 두 번의 pop으로 4, 3의 순서로 나옵니다. 따라서 꺼낸 순서는 2, 4, 3이며, 마지막에 스택에는 1이 남습니다. 1, 2, 3은 먼저 넣은 것부터 꺼내는 큐(선입선출, FIFO)로 다룬 경우의 순서입니다.

역폴란드 표기법(후위 표기법)으로 쓴 식 '3 4 + 2 * 5 −'를, 수가 오면 스택에 쌓고 연산자가 오면 두 값을 꺼내 계산하여 결과를 쌓는 방법으로 평가했다. 결과는 얼마인가? 여기서 연산자의 왼쪽 값은 먼저 쌓인 쪽의 값으로 한다.

  1. A−9
  2. B6
  3. C9
정답과 해설 보기

정답: C. 9

3, 4를 쌓고 +에서 꺼내어 3 + 4 = 7을 쌓습니다. 다음으로 2를 쌓고 *에서 7 × 2 = 14를 쌓습니다. 5를 쌓고 −에서 먼저 쌓인 14에서 나중의 5를 빼어 14 − 5 = 9가 결과입니다. 후위 표기법은 연산 순서가 나열 순서로 정해지므로 괄호가 필요 없으며, 보통의 식으로는 (3 + 4) × 2 − 5에 해당합니다. −9는 뺄셈의 좌우를 바꿔 계산한 값, 6은 괄호 없이 3 + 4 × 2 − 5로 읽은 값입니다.

  3. 요소 수 5인 정수형 배열 st와 정수형 변수 top으로 스택을 나타낸다. st의 요소는 모두 0, top은 0에서 시작한다. push(v)는 top에 1을 더한 후 st[top] ← v를 수행하고, pop()은 st[top]의 값을 반환한 후 top에서 1을 뺀다(st의 요소는 바꾸지 않는다). 다음 프로그램을 실행한 후의 top과 st의 조합은?
  4. 다른 함수를 호출하지 않는 함수(리프 함수)에서는 ra를 스택에 저장하지 않아도 되는 경우가 많다. 그 이유로 올바른 것은?

  7. 프로세스의 힙과 스택을 사이에 넓은 빈 공간을 두고 반대 방향으로 늘어나는 배치로 하는 이점으로 올바른 것은 무엇입니까?

  9. 빈 큐에 A, B, C의 순서로 원소를 넣고 하나를 꺼낸 뒤, D를 넣고 하나를 꺼내고, E를 넣고 하나를 꺼냈다. 꺼낸 원소를 차례로 나열한 것은?
