SerDes란?

시리얼라이저/디시리얼라이저. 송신 측에서 칩 내부의 병렬 데이터를 하나의 빠른 비트열로 바꾸고 수신 측에서 원래의 병렬 데이터로 되돌리는 회로. 고속 직렬 전송 물리 계층의 핵심.

일본어 명칭: SerDes

SerDes은(는) I/O 인터페이스와 버스, 실리콘 포토닉스, 논리 회로 등 4개 분야의 연습 문제 9개에 나와요.

분야: I/O 인터페이스와 버스

송신 측

칩 내부에서 데이터는 폭이 넓고 비교적 느린 버스로 이동합니다. 시리얼라이저는 그 병렬 워드를 하나의 빠른 비트열로 다중화하며, 기준 클록을 라인 레이트까지 체배하는 위상 고정 루프(PLL)로 클록을 공급받습니다. 직렬화하기 전에 데이터는 보통 8b/10b, 64b/66b, 128b/130b 같은 부호로 라인 코딩되거나 스크램블되어, 비트열에 천이가 자주 생기고 긴 DC 구간이 없도록 합니다. 이어서 출력 드라이버가 피드포워드 등화(프리엠퍼시스)로 파형을 다듬어, 기판 배선, 케이블, 커넥터의 고주파 손실을 상쇄하도록 천이를 강조합니다.

수신 측과 클록 복원

데이터와 함께 전송되는 별도의 클록이 없으므로 수신기가 클록을 복원해야 합니다. CTLE(연속 시간 선형 등화기)와 DFE(판정 궤환 등화기) 같은 등화기가 채널 손실과 반사를 되돌리고, CDR(클록 데이터 복원) 회로가 샘플링 클록을 입력 천이에 동기시켜 각 비트를 아이의 중앙 부근에서 샘플링합니다. 그 후 디시리얼라이저가 원래의 넓은 워드를 재구성합니다. 멀티레인 링크에서는 각 레인이 자체 클록을 복원하고 서로 다른 지연으로 도착하므로, 수신기가 레인 간 스큐를 제거하고 재정렬도 수행합니다.

레인, 신호 방식, 속도

레인당 속도는 회로와 채널 손실로 제한되므로, 높은 대역폭은 레인을 빠르게 하는 것과 레인 수를 늘리는 것 양쪽에서 얻습니다. 100기가비트 이더넷은 25 Gb/s 레인 4개로 구성할 수도 있고, 4레벨 펄스 진폭 변조(PAM4)를 사용하는 100 Gb/s 레인 하나로 전송할 수도 있습니다. PAM4는 심볼당 2비트를 보내므로 2레벨 NRZ 신호 방식에 비해 심볼 레이트가 절반이 되지만, 아이 개구가 작아 순방향 오류 정정(FEC)이 필요합니다. PCI Express, USB, 이더넷, 스토리지 링크, GPU 간 링크는 모두 SerDes 레인으로 물리 계층을 구성합니다.

테스트와 전력

테스터로 초당 수십 기가비트 신호를 직접 프로빙하기는 쉽지 않으므로, SerDes에는 내장 테스트 기능이 들어 있습니다. 루프백 모드에서는 송신기가 의사 난수 비트열을 보내고, 이것이 내부 경로나 로드 보드 배선을 통해 수신기로 되돌아오며, 온칩 체커가 비트 오류를 셉니다. 전력도 늘 고민거리입니다. PLL, CDR, 등화기는 데이터가 흐르지 않을 때도 동작하므로, PCI Express의 L0s와 L1 같은 링크 전력 상태는 유휴 시 일부 회로를 끄는 대신 복귀 지연을 감수합니다. 리니어 드라이브 광모듈은 모듈의 DSP를 없애고 호스트 SerDes의 등화에 의존합니다.

정답과 해설 보기

정답: B. 송신 측에서 칩 내부의 병렬 데이터를 1개의 빠른 비트열로 바꾸고, 수신 측에서 원래의 병렬 데이터로 되돌린다

칩 내부에서 데이터는 수십 비트 폭으로 느리게 움직입니다. SerDes의 송신 측은 이를 1개의 매우 빠른 비트열로 재배열하여 내보내고, 수신 측은 비트열에서 클록을 추출해 비트를 판정하여 원래 폭의 데이터로 되돌립니다. PCI Express, USB, 이더넷, 스토리지 접속 등 많은 고속 인터페이스의 물리 계층은 SerDes로 구성됩니다.

자주 묻는 질문

SerDes는 무슨 역할을 하나요?

넓은 병렬 데이터를 전송용 단일 고속 직렬 비트열로 변환하고, 수신 측에서는 클록을 복원하여 비트열을 다시 병렬 워드로 변환합니다.

칩 간 연결에서 직렬이 병렬보다 빠른 이유

넓은 병렬 버스는 배선 간 스큐 문제가 있고 핀이 많이 필요합니다. 직렬 레인은 클록을 데이터에 내장하고 레인별로 등화할 수 있으므로, 소수의 빠른 레인이 다수의 느린 배선보다 성능이 좋습니다.

SerDes NRZ와 PAM4 차이

NRZ는 2개의 전압 레벨로 심볼당 1비트를 보내고, PAM4는 4개의 레벨로 심볼당 2비트를 보내므로 같은 심볼 레이트에서 데이터 레이트가 2배가 되지만 노이즈 마진이 줄어듭니다.
