SerDes란?

시리얼라이저/디시리얼라이저. 송신 측에서 칩 내부의 병렬 데이터를 하나의 빠른 비트열로 바꾸고 수신 측에서 원래의 병렬 데이터로 되돌리는 회로. 고속 직렬 전송 물리 계층의 핵심.

일본어 명칭: SerDes

SerDes은(는) I/O 인터페이스와 버스, 논리 회로, 테스트와 검사 등 3개 분야의 연습 문제 7개에 나와요.

정답과 해설 보기

정답: B. 송신 측에서 칩 내부의 병렬 데이터를 1개의 빠른 비트열로 바꾸고, 수신 측에서 원래의 병렬 데이터로 되돌린다

칩 내부에서 데이터는 수십 비트 폭으로 느리게 움직입니다. SerDes의 송신 측은 이를 1개의 매우 빠른 비트열로 재배열하여 내보내고, 수신 측은 비트열에서 클록을 추출해 비트를 판정하여 원래 폭의 데이터로 되돌립니다. PCI Express, USB, 이더넷, 스토리지 접속 등 많은 고속 인터페이스의 물리 계층은 SerDes로 구성됩니다.

SerDes이(가) 나오는 문제 (7)

  1. 고속 직렬 전송에서 사용되는 SerDes(시리얼라이저/디시리얼라이저)의 역할로 올바른 것은?
  2. 플립플롭을 직렬로 연결하여 클록마다 데이터를 1비트씩 옆으로 옮기는 시프트 레지스터의 대표적인 용도는?
  3. 고속 직렬 통신 인터페이스 테스트에서, 칩의 송신 회로 출력을 수신 회로로 되돌려 연결하여 칩 스스로 통신을 확인하는 방법은 무엇입니까?
  4. PCI Express의 통신 구조로 올바른 것은?
  5. 100기가비트 이더넷 같은 고속 접속이 예를 들어 25 Gb/s 레인 4개를 묶어 구성되는 경우가 있다. 이 발상으로 올바른 것은?
