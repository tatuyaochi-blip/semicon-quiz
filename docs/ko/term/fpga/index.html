분야: IC 설계 흐름과 EDA

FPGA의 내부 구조

FPGA(field-programmable gate array)는 구성 가능한 논리 블록을 프로그래머블 배선으로 연결한 격자입니다. 각 논리 블록에는 룩업 테이블(LUT)이 있는데, 저장된 비트가 진리표를 정하고 입력이 출력을 고르는 멀티플렉서를 구동하는 작은 메모리이므로, k입력 LUT는 k개 입력의 어떤 함수든 구현할 수 있습니다. 플립플롭은 상태를 저장합니다. 최신 소자에는 블록 RAM, DSP 곱셈 누산기, 클록 관리기, 고속 직렬 트랜시버, 때로는 프로세서 코어 같은 하드 블록도 들어 있습니다. 대부분의 FPGA에서 구성 정보는 SRAM 셀에 저장되며, 전원 투입 시 외부 플래시에서 로드됩니다.

HDL에서 비트스트림까지

설계는 Verilog나 VHDL 같은 하드웨어 기술 언어로 작성합니다. 합성은 표준적인 코딩 패턴을 인식해 논리를 LUT, 플립플롭, 하드 블록에 매핑합니다. 클록에 동기해 쓰고 읽는 레지스터 배열은 블록 RAM으로 추론되고, 비동기 읽기는 플립플롭이나 분산 메모리가 될 수 있습니다. 이어서 배치 배선이 자원과 배선을 할당하고, 정적 타이밍 분석이 클록 주파수를 확인하며, 그 결과물이 소자에 로드되는 비트스트림입니다. 처리 블록들은 흔히 AXI4-Stream 같은 표준 온칩 인터페이스로 연결합니다.

FPGA와 ASIC의 비교

FPGA는 마스크나 제조 리드 타임이 필요 없고 현장에서 다시 프로그래밍할 수 있어, 출하 후에도 버그 수정과 새 기능 추가가 가능합니다. 대가는 오버헤드입니다. 구성 가능한 배선과 LUT 때문에 같은 기능이라도 주문형 반도체(ASIC)보다 느리고 전력을 많이 소모하며 면적이 훨씬 크고, 단가도 높습니다. ASIC은 막대한 초기 개발비와 마스크 비용을 많은 수량에 분산할 수 있는 대량 생산에서 유리하고, FPGA는 시제품, 소량 생산, 요구 사항이 빠르게 바뀌는 경우에 유리합니다.

FPGA가 쓰이는 곳

FPGA는 통신 장비, 시험·계측기, 영상 및 신호 처리 파이프라인, 산업 제어, 데이터 센터 가속기에 쓰입니다. 대규모 SoC 검증에서도 핵심적인 역할을 합니다. 설계를 FPGA에 매핑하는 FPGA 프로토타이핑은 소프트웨어 시뮬레이션보다 몇 자릿수 빠르게 동작하므로, 실리콘이 나오기 전에 실제 운영 체제와 애플리케이션을 실행할 수 있습니다. 하드웨어 에뮬레이터도 같은 목적으로 쓰이며 내부 신호의 가시성이 더 좋지만, 일반적으로 FPGA 프로토타입이 더 빠르게 동작합니다.

정답: C. 제조 후에 사용자가 논리 회로 구성을 다시 쓸 수 있다

FPGA는 작은 진리표(LUT)를 가진 논리 블록과 배선의 연결 방식을 제조 후에 설정 데이터로 다시 쓸 수 있는 디바이스입니다. ASIC처럼 제조에 시간과 마스크 비용이 들지 않으므로, 시제작, 소량 생산, 기능 업데이트가 필요한 기기에 사용됩니다. 반면 재기록을 위한 회로가 추가로 필요하므로, 같은 회로라면 ASIC이 더 빠르고 저전력이며 면적도 작습니다. 아날로그 전용 디바이스가 아닙니다.

대규모 SoC 검증에서 설계한 회로를 전용 하드웨어나 FPGA 위에서 동작시키고 소프트웨어와 조합하여 고속으로 검증하는 기법은?

  1. A에뮬레이션이나 FPGA 프로토타이핑
  2. BDRC
  3. CCMP
정답과 해설 보기

정답: A. 에뮬레이션이나 FPGA 프로토타이핑

소프트웨어에 의한 논리 시뮬레이션은 대규모 회로에서는 1초 분량의 동작에 며칠이 걸릴 만큼 느려집니다. 에뮬레이터나 FPGA에 회로를 구현하여 동작시키면 수 자릿수 빠르게 검증할 수 있고, 실제 OS나 애플리케이션을 동작시키면서 칩이 완성되기 전에 소프트웨어 개발과 검증을 진행할 수 있습니다. 에뮬레이터는 내부 신호를 관측하기 쉽고, FPGA 프로토타입은 더 빠르다는 차이가 있습니다.

자주 묻는 질문

FPGA는 무엇의 약자인가요?

FPGA는 field-programmable gate array의 약자로, 논리와 배선이 제조 과정에서 고정되지 않고 제조 후 현장(field)에서 사용자가 구성할 수 있는 칩입니다.

FPGA와 마이크로컨트롤러의 차이는 무엇인가요?

마이크로컨트롤러는 소프트웨어 명령을 하나씩 순서대로 실행하는 고정된 프로세서를 가집니다. FPGA는 고정된 기능이 없고 하드웨어 자체를 구성하므로 매 클록 사이클마다 많은 연산을 병렬로 실행할 수 있지만, 설계 흐름이 더 어렵습니다.

FPGA는 전원을 꺼도 구성 정보가 유지되나요?

대부분의 FPGA는 구성 정보를 SRAM에 저장하므로 전원을 끄면 사라지고, 전원을 켤 때마다 외부 플래시 메모리에서 비트스트림을 다시 로드합니다. 일부 제품군은 온칩 플래시나 일회성 안티퓨즈를 사용해 비휘발성입니다.
