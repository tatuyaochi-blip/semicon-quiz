동적 소비 전력(dynamic power)란?

CMOS 회로에서 신호가 전환될 때 용량을 충전·방전하느라 쓰이는 전력. 활동률 α, 용량 C, 전압 V, 주파수 f를 사용해 αCV²f로 나타낸다.

일본어 명칭: 動的消費電力

동적 소비 전력(dynamic power)은(는) 전력 관리, CPU와 아키텍처, MOSFET 등 4개 분야의 연습 문제 6개에 나와요.

분야: 전력 관리

도전해 보기: 동적 소비 전력(dynamic power) 관련 문제

CMOS 회로에서 다른 조건은 바꾸지 않고 전원 전압만 절반으로 하면 동적 소비 전력은 어떻게 되는가?

  1. A변하지 않는다
  2. B1/2이 된다
  3. C1/4이 된다
정답과 해설 보기

정답: C. 1/4이 된다

CMOS의 동적 소비 전력은 P = αCV²f로 전원 전압의 제곱에 비례하므로, 전압을 절반으로 하면 1/4이 됩니다. 다만 전압을 낮추면 트랜지스터의 전류가 줄어 느려지므로 같은 주파수로는 동작할 수 없게 됩니다. 그래도 주파수를 낮추고 전압도 낮추면 전력은 3제곱에 가깝게 줄어들기 때문에, DVFS로 처리가 가벼울 때 전압과 주파수를 낮추는 것이 가장 효과적인 절전 수단입니다.

CMOS 회로의 동적 소비 전력식 P = αCV²f에서 α가 나타내는 것으로 올바른 것은?

  1. A트랜지스터의 수
  2. B1클록당 신호가 전환되는 비율(활동률)
  3. C칩의 온도
정답과 해설 보기

정답: B. 1클록당 신호가 전환되는 비율(활동률)

동적 소비 전력은 배선이나 게이트의 용량을 충전하고 방전할 때 사용되는 전력입니다. C는 전환되는 부분의 용량, V는 전원 전압, f는 클록 주파수이며, α는 1클록 동안 신호가 어느 정도의 비율로 전환되는지를 나타내는 활동률입니다. 데이터가 변하지 않는 부분이나 클록을 멈춘 부분은 전환되지 않으므로, α를 작게 하는 것도 중요한 저전력 수단입니다.

해설 속 동적 소비 전력(dynamic power)

  • CMOS의 동적 소비 전력은 P = αCV²f로 전원 전압의 제곱에 비례하므로, 전압을 절반으로 하면 1/4이 됩니다.

    CMOS 회로에서 다른 조건은 바꾸지 않고 전원 전압만 절반으로 하면 동적 소비 전력은 어떻게 되는가?

  • 동적 소비 전력은 배선이나 게이트의 용량을 충전하고 방전할 때 사용되는 전력입니다.

    CMOS 회로의 동적 소비 전력식 P = αCV²f에서 α가 나타내는 것으로 올바른 것은?

  • 실제 칩에서는 전환되는 용량이 회로 규모에 비례하여 커지며, 전체 동적 소비 전력은 수십~수백 W에 이르기도 합니다.

    활동률 α=0.1, 전환되는 용량 C=1 nF, 전원 전압 V=1 V, 주파수 f=1 GHz인 회로의 동적…

  • 동적 소비 전력은 전압의 제곱에 비례하므로, 전압을 0.9배로 하면 전력은 0.9²=0.81배, 즉 약 19% 줄어듭니다.

    전원 전압만 10% 낮췄을 때(다른 조건은 같다고 합니다) 동적 소비 전력은 대략 몇 % 줄어듭니까?

  • 천이를 빠르게 유지하면 동적 소비 전력 전체의 1할 정도 이하로 수렴합니다.

    CMOS 인버터에서 입력이 전환되는 도중에 전원에서 그라운드로 흐르는 전류를 무엇이라고 합니까?

동적 소비 전력(dynamic power)이(가) 나오는 문제 (6)

  1. CMOS 회로에서 다른 조건은 바꾸지 않고 전원 전압만 절반으로 하면 동적 소비 전력은 어떻게 되는가?
  2. CMOS 회로의 동적 소비 전력식 P = αCV²f에서 α가 나타내는 것으로 올바른 것은?
  3. 활동률 α=0.1, 전환되는 용량 C=1 nF, 전원 전압 V=1 V, 주파수 f=1 GHz인 회로의 동적 소비 전력은 얼마입니까?
  4. 전원 전압만 10% 낮췄을 때(다른 조건은 같다고 합니다) 동적 소비 전력은 대략 몇 % 줄어듭니까?
  5. CMOS 인버터에서 입력이 전환되는 도중에 전원에서 그라운드로 흐르는 전류를 무엇이라고 합니까?
  6. 사용하지 않는 회로 블록에 대한 클록 공급을 멈춰 불필요한 소비 전력을 줄이는 저전력 설계 기법은?
