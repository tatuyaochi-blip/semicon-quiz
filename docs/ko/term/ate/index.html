ATE(자동 시험 장비)란?

칩에 테스트 패턴을 인가하고 출력을 측정하여 양부를 자동으로 판정하는 장비. 테스터라고도 한다.

일본어 명칭: ATE(自動試験装置)

ATE(자동 시험 장비)은(는) 테스트와 검사 등 1개 분야의 연습 문제 1개에 나와요.

분야: 테스트와 검사

테스터가 하는 일

자동 시험 장비(ATE)는 피시험 소자(DUT)에 전원과 신호를 인가하고, 응답을 측정해 기댓값과 비교한 뒤, 부품을 합격, 불합격 또는 성능 등급(빈)으로 분류합니다. 테스트 프로그램이 단계의 순서를 정합니다. 테스터에는 수백에서 수천 개의 채널이 있으며, 각 핀의 회로는 프로그래밍된 타이밍으로 로직 레벨을 구동하고, 스트로브 시점에 출력을 기댓값과 비교하며, 핀별 파라메트릭 측정 유닛을 통해 전압이나 전류를 인가하면서 나머지 하나를 측정할 수 있습니다. 디바이스 전원 장치는 전원 레일을 공급하고 감시합니다.

웨이퍼 테스트와 최종 테스트

ATE는 크게 두 시점에서 사용됩니다. 웨이퍼 소트라고도 하는 웨이퍼 테스트에서는 프로버가 웨이퍼를 프로브 카드 아래로 이동시키고, 프로브 카드의 바늘이 폭 수십 마이크로미터인 각 칩의 패드에 접촉합니다. 프로브 자국은 이후의 와이어 본딩이나 범핑에 지장이 없도록 검사합니다. 불량 다이는 패키징되지 않도록 표시합니다. 최종 테스트에서는 핸들러가 패키징된 부품을 로드 보드의 소켓으로 옮기고, 흔히 고온이나 저온에서 시험한 뒤 결과에 따라 분류합니다.

무엇을 테스트하는가

일반적인 흐름은 오픈과 쇼트를 확인하는 도통 검사로 시작해, 누설 전류와 전원 전류 같은 DC 파라메트릭 테스트, 그다음 기능 테스트와 구조 테스트로 이어집니다. 디지털 로직에서는 자동 테스트 패턴 생성(ATPG)으로 만든 스캔 패턴이 제조 결함을 검출하며, 흔히 실속도로 수행합니다. 메모리는 알고리즘 패턴이나 내장 자체 테스트(BIST)로 검사합니다. 아날로그, 혼성 신호, RF 부품은 선형성, 잡음, 주파수 응답을 측정하는 계측기가 필요하므로, 테스터 플랫폼은 로직 및 SoC용, 메모리용, 혼성 신호용, RF용으로 특화되어 있습니다.

테스트 비용

테스터는 고가이므로 테스트 비용은 대략 테스트 시간에 테스터의 초당 비용을 곱한 값입니다. 제조사는 여러 소자를 병렬로 테스트하고(멀티사이트 테스트), 중복 테스트를 줄이며, 테스트 용이화 설계(DFT) 기능을 추가하여 비용을 낮춥니다. 스캔 체인, 압축, BIST 덕분에 적은 수의 테스터 핀과 얕은 패턴 메모리로도 대형 칩을 커버할 수 있으며, 핀 수를 줄인 테스트는 더 저렴한 테스터로 더 많은 사이트를 동시에 처리할 수 있게 합니다.

정답과 해설 보기

정답: A. 테스트 패턴을 입력하고 출력을 기대값과 비교하여 양부를 판정하는 장치

ATE(Automatic Test Equipment)는 테스트 대상 칩에 전원과 신호를 주고, 출력을 측정하여 기대값과 비교해 양부를 판정하는 장치입니다. 핀마다 신호 발생, 전압과 전류 측정, 타이밍 판정이 가능한 회로를 수백~수천 채널 갖추고 있습니다. 웨이퍼 테스트에서는 프로버, 최종 테스트에서는 핸들러와 조합하여 사용합니다. 노광이나 세정은 전공정 장치의 역할입니다.

자주 묻는 질문

반도체에서 ATE는 무엇의 약자인가요?

ATE는 automatic test equipment(자동 시험 장비)의 약자로, 칩에 테스트 패턴을 인가하고 출력을 측정해 합격 여부를 자동으로 판정하는 테스터입니다.

프로버와 핸들러의 차이는 무엇인가요?

둘 다 ATE에 소자를 공급합니다. 프로버는 웨이퍼 레벨 테스트를 위해 웨이퍼를 프로브 카드 아래에 위치시키고, 핸들러는 패키징된 칩을 집어 테스트 소켓에 넣고 최종 테스트 후 분류합니다.

테스트 용이화 설계(DFT)가 ATE 비용을 줄이는 이유는?

스캔 체인, 테스트 압축, 내장 자체 테스트 같은 구조 덕분에 칩이 스스로를 테스트하거나 적은 핀으로 테스트될 수 있어, 테스트 시간이 줄고 더 저렴한 장비로 더 많은 소자를 병렬 테스트할 수 있기 때문입니다.
