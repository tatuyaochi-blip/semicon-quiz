NVMe란?

えぬぶいえむいー

PCI Expressで接続したSSDを高速に扱うためのインターフェースの規格。多数のコマンドを並列に処理でき、HDD向けに作られたSATAより遅延が小さい。

일본어 명칭: NVMe

분야: SRAM과 플래시 메모리

이 용어가 포함된 비교

  • NVMe와 SATA SSD: 속도, 인터페이스, 선택 기준NVMe와 SATA SSD를 표로 비교합니다. 인터페이스, 속도, 지연 시간, 명령 큐, 폼팩터, 전력, 호환성, 가격, 각각에 알맞은 사용자를 다룹니다.
