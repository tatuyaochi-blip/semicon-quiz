NVMe란?

PCI Express로 연결된 SSD에 고속으로 접근하기 위한 인터페이스 규격입니다. 많은 명령을 병렬로 처리하며, HDD용으로 설계된 SATA보다 지연 시간이 짧습니다.

일본어 명칭: NVMe

NVMe은(는) SRAM과 플래시 메모리, I/O 인터페이스와 버스 등 2개 분야의 연습 문제 3개에 나와요.

분야: SRAM과 플래시 메모리

도전해 보기: NVMe 관련 문제

네트워크 카드나 NVMe SSD 등에서 널리 사용되는, 메모리 상의 기술자(디스크립터) 링을 사용한 DMA 구조에 대해 올바른 것은 무엇입니까?

  1. ACPU가 데이터를 1바이트씩 기기의 레지스터에 써서 전송한다
  2. BCPU는 전송의 주소와 길이를 기술자에 써서 기기에 알리기만 하고, 기기가 기술자를 읽어 스스로 전송을 진행한다
  3. C기술자는 기기 안에만 있고 CPU에서는 보이지 않는다
정답과 해설 보기

정답: B. CPU는 전송의 주소와 길이를 기술자에 써서 기기에 알리기만 하고, 기기가 기술자를 읽어 스스로 전송을 진행한다

기술자 링은 메인 메모리 상에 나열한 「어느 주소부터 몇 바이트를 보낼지」를 적은 표를 고리처럼 사용하는 구조입니다. CPU는 비어 있는 기술자에 전송 내용을 쓰고, 기기 레지스터에 「여기까지 썼다」고 한 번 알립니다. 기기는 DMA로 기술자를 읽고 데이터를 전송하며, 끝난 기술자에 완료 표시를 붙입니다. CPU와 기기가 서로를 기다리지 않고 많은 전송을 진행할 수 있습니다.

이 용어가 포함된 비교

  • NVMe와 SATA SSD: 속도, 인터페이스, 선택 기준NVMe와 SATA SSD를 표로 비교합니다. 인터페이스, 속도, 지연 시간, 명령 큐, 폼팩터, 전력, 호환성, 가격, 각각에 알맞은 사용자를 다룹니다.
