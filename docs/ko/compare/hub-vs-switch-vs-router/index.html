허브·스위치·라우터의 차이: 동작 계층·사용 주소·전달 방식·도메인 분할 비교

세 가지 모두 기기를 연결하고 데이터를 중계하지만, 어느 계층의 정보를 써서 전달하는지가 다릅니다. 허브(리피터 허브)는 1계층(물리 계층) 장비로, 들어온 신호를 그대로 모든 포트로 내보냅니다. 스위치(L2 스위치)는 2계층(데이터 링크 계층) 장비로, 프레임의 목적지 MAC 주소를 읽어 그 목적지가 연결된 포트로만 전달합니다. 라우터는 3계층(네트워크 계층) 장비로, 목적지 IP 주소와 라우팅 테이블을 바탕으로 서로 다른 네트워크 사이에서 패킷을 중계합니다. 허브와 스위치는 한 네트워크 안의 기기를 연결하고, 라우터는 네트워크끼리 연결합니다.

상황별 선택 기준

허브
지금은 스위치로 대체되어 새로 설치할 때 고르는 일은 거의 없습니다. 스위치의 동작을 이해하기 위한 비교 대상으로는 여전히 유용합니다.
스위치(L2 스위치)
한 네트워크 안에서 많은 기기를 연결할 때. VLAN을 지원하는 모델은 한 대로 네트워크를 논리적으로 나눌 수도 있습니다.
라우터
다른 네트워크끼리 연결할 때. LAN과 인터넷의 경계나 서브넷 사이에 두고, 경로 선택, NAT, 패킷 필터링 같은 일을 맡습니다.

자주 묻는 질문

L3 스위치는 라우터와 무엇이 다른가요?

L3 스위치는 스위치에 라우터 기능(3계층 전달)을 더한 것으로, VLAN 사이의 통신을 하드웨어로 빠르게 중계할 수 있습니다. 주로 LAN 안에서 서브넷과 VLAN을 연결하는 데 씁니다. 라우터는 보통 인터넷이나 다른 거점으로 이어지는 회선의 연결, NAT, VPN처럼 네트워크 경계에서 필요한 기능을 더 폭넓게 갖춥니다. 다만 제품에 따라 기능 범위가 겹칩니다.

가정용 브로드밴드 라우터는 이 중 어느 것인가요?

라우터, 스위치, 무선 LAN 액세스 포인트 등을 한 대에 합친 것입니다. LAN 쪽 포트끼리는 스위치로 연결되고, LAN과 인터넷 사이의 통신은 라우터로서 중계하며 NAPT로 글로벌 주소 하나를 함께 씁니다. 많은 제품이 DHCP 서버 역할도 합니다.

스위치를 쓰면 브로드캐스트가 줄어드나요?

줄지 않습니다. 스위치는 브로드캐스트 프레임을 들어온 포트를 제외한 모든 포트로 보내므로, 연결된 모든 기기에 닿습니다. 스위치가 나누는 것은 충돌 도메인입니다. 브로드캐스트가 닿는 범위를 제한하려면 VLAN이나 라우터로 네트워크를 나눕니다.

허브는 왜 더 이상 쓰이지 않나요?

허브는 모든 포트가 하나의 통신로를 공유하므로, 연결된 기기가 많을수록 충돌이 늘고 대역도 나누어 씁니다. 게다가 모든 통신이 모든 포트로 흐르므로 기기가 다른 기기 앞으로 가는 통신을 받을 수 있습니다. 스위치는 목적지 포트로만 전달하고 포트마다 전이중으로 통신할 수 있으므로, 서로 다른 포트 쌍의 통신을 동시에 할 수 있습니다.

OSI 참조 모델에서 IP 주소 같은 논리 주소를 사용하여 서로 다른 네트워크 사이에서 패킷을 중계해 목적지까지 전달하는 역할을 하는 계층은?

  1. A데이터 링크 계층(2계층)
  2. B네트워크 계층(3계층)
  3. C전송 계층(4계층)
정답과 해설 보기

정답: B. 네트워크 계층(3계층)

OSI 참조 모델은 통신 기능을 물리 계층부터 응용 계층까지 7개 계층으로 나누어 정리한 모델입니다. 네트워크 계층(3계층)은 IP 주소 같은 논리 주소를 사용하여 여러 네트워크에 걸쳐 목적지까지의 경로를 선택하고 패킷을 중계합니다. 그 아래의 데이터 링크 계층은 같은 네트워크 안에서 MAC 주소를 사용해 이웃한 기기에 프레임을 전달하는 데까지를 담당합니다. 전송 계층은 단말의 애플리케이션 간 통신을 다루며, TCP라면 재전송과 순서 관리를 수행합니다. 기기로 말하면 라우터는 3계층, L2 스위치는 2계층에서 동작합니다.

허브(리피터 허브)와 비교했을 때 L2 스위치의 동작으로 올바른 것은?

  1. AIP 주소를 보고 서로 다른 네트워크 사이에서 패킷을 중계한다
  2. B프레임의 목적지 MAC 주소를 보고 목적지 기기가 연결된 포트로만 전달한다
  3. C도착한 프레임을 항상 모든 포트로 보내고, 목적지 기기만 그것을 받는다
정답과 해설 보기

정답: B. 프레임의 목적지 MAC 주소를 보고 목적지 기기가 연결된 포트로만 전달한다

허브는 1계층 기기로, 어느 포트에 도착한 신호를 그대로 모든 포트로 흘려보냅니다. 그래서 연결된 모든 기기가 하나의 통신로를 공유하며, 동시에 보내면 충돌이 일어납니다. L2 스위치는 2계층 기기로, 도착한 프레임의 출발지 MAC 주소와 포트의 대응을 표(MAC 주소 테이블)에 기억하고, 목적지 MAC 주소가 연결된 포트로만 전달합니다. 표에 아직 없는 목적지나 브로드캐스트 프레임은 받은 포트를 제외한 모든 포트로 보냅니다(플러딩). 포트마다 통신이 나뉘므로 서로 다른 포트끼리의 통신은 동시에 할 수 있습니다. IP 주소를 보고 서로 다른 네트워크 사이를 중계하는 것은 3계층인 라우터의 역할입니다.

L2 스위치 1대에 VLAN을 설정하여 포트 1~4를 VLAN 10, 포트 5~8을 VLAN 20으로 했다. 이때의 동작으로 올바른 것은?

  1. AVLAN 10과 VLAN 20은 같은 스위치에 연결되어 있으므로 라우터를 사용하지 않고 직접 통신할 수 있다
  2. BVLAN을 2개로 나누면 각 포트의 통신 속도가 각각 절반이 된다
  3. CVLAN 10의 기기가 보낸 브로드캐스트는 VLAN 20의 포트에는 도달하지 않으며, VLAN 10과 VLAN 20 사이의 통신에는 라우터(또는 L3 스위치)가 필요하다
정답과 해설 보기

정답: C. VLAN 10의 기기가 보낸 브로드캐스트는 VLAN 20의 포트에는 도달하지 않으며, VLAN 10과 VLAN 20 사이의 통신에는 라우터(또는 L3 스위치)가 필요하다

VLAN(가상 LAN)은 스위치의 포트 등을 단위로 하여, 물리적으로는 같은 기기 위에 논리적으로 별개의 네트워크를 만드는 기능입니다. VLAN마다 브로드캐스트가 도달하는 범위(브로드캐스트 도메인)가 나뉘며, 스위치는 같은 VLAN의 포트 사이에서만 프레임을 전달합니다. 그래서 이 예의 VLAN 10과 VLAN 20처럼 서로 다른 VLAN 사이의 통신은 3계층에서 중계하는 라우터나 L3 스위치를 거쳐야 합니다. 여러 스위치에 걸쳐 VLAN을 사용할 때는 IEEE 802.1Q로 정해진 태그(VLAN ID)를 프레임에 넣어 어느 VLAN의 프레임인지를 구별합니다. 부서별로 네트워크를 나누거나, 방문객용 무선 LAN을 사내 네트워크에서 분리하는 데 사용됩니다.

  1. 단말(192.168.1.10/24, 기본 게이트웨이 192.168.1.1)이 다른 네트워크에 있는 서버 203.0.113.80으로 패킷을 보낸다. ARP 캐시가 비어 있을 때, 단말이 ARP로 MAC 주소를 알아내는 상대는?
  2. 라우터의 라우팅 테이블에 0.0.0.0/0(다음 전달 대상은 라우터 A), 10.0.0.0/8(라우터 B), 10.1.0.0/16(라우터 C), 10.1.2.0/24(라우터 D)의 4개 경로가 있다. 목적지가 10.1.5.9인 패킷은 어느 라우터로 보내지는가?
  3. 동적 라우팅에 대한 설명으로 올바른 것은?

네트워크 기초 문제 풀기

주요 용어 설명

OSI 참조 모델(OSI Reference Model)
통신 기능을 물리 계층·데이터 링크 계층·네트워크 계층·전송 계층·세션 계층·표현 계층·응용 계층의 7개 계층으로 나누어 정리한 모델. 각 계층의 역할을 나누어 생각하기 위한 공통의 언어로 쓰인다.
MAC 주소(MAC Address)
이더넷이나 무선 LAN에서 같은 네트워크 안의 기기를 지정하는 데 사용하는 48비트 주소. 상위 24비트가 제조사를 나타내며, 제조 시에 인터페이스마다 할당된다.
VLAN(가상 LAN)
가상 LAN. 스위치의 포트 등을 단위로, 물리적으로 같은 기기 위에 논리적으로 별개의 네트워크(브로드캐스트 도메인)를 만드는 기능. 스위치 사이에서는 IEEE 802.1Q 태그로 구별한다.
ARP(주소 결정 프로토콜)
Address Resolution Protocol의 약자. IP 주소로부터 같은 네트워크에 있는 기기의 MAC 주소를 알아내는 프로토콜. 요청을 브로드캐스트로 보내고, 해당하는 기기가 응답한다.
기본 게이트웨이(Default Gateway)
단말이 자신과 다른 네트워크에 있는 목적지로 가는 패킷을 넘기는 라우터. 단말은 서브넷 마스크로 목적지가 같은 네트워크인지 판단하고, 밖이라면 이 라우터로 보낸다.
NAT(네트워크 주소 변환)
Network Address Translation의 약자. 라우터를 지나는 패킷의 IP 주소를 바꿔 쓰는 기술. 포트 번호도 바꿔 써서 하나의 공인 주소를 많은 단말이 공유하는 것을 NAPT(IP 마스커레이드)라고 한다.
서브넷 마스크(Subnet Mask)
IP 주소 중 상위 몇 비트가 네트워크를 나타내는 부분(네트워크부)인지를 나타내는 32비트 값. 255.255.255.0처럼 쓰며, CIDR 표기의 /24와 같은 의미가 된다.
