NAND 플래시와 NOR 플래시의 차이와 용도

둘 다 비휘발성 플래시 메모리지만 배선 방식이 다릅니다. NOR 플래시는 셀을 병렬로 연결해 빠른 랜덤 읽기와 코드 직접 실행이 가능하지만 비트당 가격이 비쌉니다. NAND 플래시는 셀을 직렬로 연결해 같은 면적에 훨씬 많은 비트를 담을 수 있고 저렴하지만, 페이지 단위로 읽고 쓰며 오류 정정이 필요합니다. 그래서 NAND는 데이터를, NOR는 펌웨어를 저장합니다.

쓰기(프로그램)한 번에 한 페이지씩 프로그램하며 순차 쓰기 처리량이 높습니다작은 단위로 프로그램하며 대용량 데이터에는 더 느립니다

수치는 대략적인 자릿수 기준이며, 공정 세대와 제품에 따라 달라져요.

상황별 선택 기준

NAND 플래시
저렴한 대용량 비휘발성 저장 공간이 필요하고 페이지 단위로 읽고 쓸 수 있을 때: SSD, 휴대전화, 카메라, 메모리 카드.
NOR 플래시
프로세서가 직접 읽는 프로그램 코드를 안정적으로 저장해야 하고 용량은 크지 않아도 될 때: 부트 ROM, 펌웨어, 소규모 임베디드 시스템.
함께 사용
많은 기기가 둘 다 사용합니다. 작은 NOR 칩에 부트 코드를 두고, 이 코드가 대용량 NAND 장치에서 운영체제를 불러옵니다.

자주 묻는 질문

NAND 플래시는 왜 NOR 플래시보다 저렴한가요?

NAND 셀은 직렬 스트링으로 연결되어 콘택트를 공유하므로 비트당 면적이 훨씬 작습니다. 3D 적층과 멀티비트 셀까지 더해져 집적도가 높고 비트당 비용이 낮습니다. NOR 셀은 병렬로 배선되어 면적을 더 차지합니다.

프로세서가 NAND 플래시에서 코드를 직접 실행할 수 있나요?

직접은 어렵습니다. NAND는 페이지 단위로 읽고 비트 오류가 있으므로 보통 코드를 먼저 RAM으로 복사합니다. NOR 플래시는 제자리 실행(XIP)을 지원하기 때문에 부트 코드와 펌웨어를 저장하는 데 쓰입니다.

SSD와 휴대전화에는 어떤 플래시가 쓰이나요?

NAND 플래시입니다. SSD, USB 드라이브, 메모리 카드, eMMC와 UFS 같은 휴대전화 스토리지는 낮은 비용과 큰 용량 때문에 모두 NAND를 사용합니다.

NAND 플래시는 NOR보다 더 빨리 마모되나요?

일반적으로 그렇습니다. NAND의 내구성은 약 100,000회(SLC)에서 약 1,000회(QLC)까지이고, NOR는 보통 약 100,000회입니다. NAND 컨트롤러는 웨어 레벨링과 오류 정정으로 수명을 늘립니다.

이해도 확인

NOR형과 비교했을 때 NAND형 플래시 메모리의 특징으로 올바른 것은 무엇입니까?

  1. A랜덤 액세스가 빠르고 프로그램 코드의 직접 실행에 적합하다
  2. B메모리 셀을 직렬로 접속하므로 고집적화하기 쉽고 대용량 스토리지에 적합하다
  3. C전원을 끄면 데이터가 사라지는 휘발성 메모리이다
정답과 해설 보기

정답: B. 메모리 셀을 직렬로 접속하므로 고집적화하기 쉽고 대용량 스토리지에 적합하다

NAND형은 메모리 셀을 수십 개 직렬로 연결하고 셀마다의 컨택트를 생략했기 때문에 비트당 면적이 작아 대용량화에 적합하며, SSD나 메모리 카드에 사용됩니다. 대신 읽기는 직렬의 셀을 거치므로 느리고 페이지 단위 액세스가 됩니다. NOR형은 각 셀이 비트 라인에 병렬로 연결되어 랜덤 읽기가 빠르고 코드의 직접 실행에 적합합니다. 둘 다 비휘발성입니다.

NOR형 플래시 메모리의 대표적인 용도는 무엇입니까?

  1. A대용량 동영상이나 사진의 저장
  2. BPC의 주기억장치
  3. C기기의 프로그램 코드 저장(부팅용 프로그램 등)
정답과 해설 보기

정답: C. 기기의 프로그램 코드 저장(부팅용 프로그램 등)

NOR형은 각 셀이 비트 라인에 병렬로 연결되어 랜덤 액세스가 빠르므로, CPU가 메모리에서 직접 프로그램을 읽어 실행할 수 있습니다(XIP: Execute In Place). 그래서 기기의 부팅용 프로그램, 마이크로컨트롤러의 펌웨어, 차량용 기기의 제어 코드에 사용됩니다. 용량은 수 Mbit~수 Gbit로 작고 비트 단가는 NAND보다 높으므로, 대용량 데이터 저장에는 NAND형이 사용됩니다.

NAND형 플래시 메모리에서 데이터를 지우는 단위로 올바른 것은 무엇입니까?

  1. A비트 단위
  2. B블록 단위
  3. C바이트 단위
정답과 해설 보기

정답: B. 블록 단위

NAND에서 읽기·쓰기는 페이지(16 KB 안팎) 단위이지만, 소거는 수백~수천 페이지를 묶은 블록(수 MB~수십 MB) 단위로만 할 수 있습니다. 소거는 웰 전체에 고전압을 걸어 한꺼번에 전자를 빼내므로 이 단위가 됩니다. 일부만 바꿔 쓸 때도 덮어쓰기는 할 수 없고, 새 데이터를 빈 페이지에 쓰고 오래된 페이지를 무효로 한 뒤 나중에 가비지 컬렉션으로 한꺼번에 소거합니다.

  1. NAND형 플래시 메모리의 쓰기(프로그램)에서 주로 사용되는 전자 주입 방식은 무엇입니까?
  2. 3D NAND형 플래시 메모리의 설명으로 올바른 것은 무엇입니까?
  3. NAND 플래시 컨트롤러에서 다치화에 따른 읽기 오류 증가에 대응하기 위해 사용되는 기술은 무엇입니까?

SRAM과 플래시 메모리 문제 풀기

주요 용어 설명

NAND 플래시 메모리
메모리 셀을 직렬로 연결한 구조의 비휘발성 메모리. 집적도가 높아 대용량화가 쉬우며 SSD와 메모리 카드에 쓰인다.
NOR형 플래시 메모리
셀을 병렬로 연결한 플래시 메모리. 랜덤 읽기가 빨라 마이컴의 프로그램 저장 등에 사용된다.
3D NAND
NAND 플래시의 메모리 셀을 수직 방향으로 여러 겹 쌓아 대용량화한 것. 평면 미세화의 한계를 넘기 위해 도입되었으며 적층 수는 200단 이상에 이른다.
비휘발성 메모리
전원을 꺼도 기억한 데이터가 사라지지 않는 메모리. 플래시 메모리, MRAM 등. DRAM과 SRAM은 휘발성이다.
