웨이퍼 테스트와 파이널 테스트의 차이점 정리

웨이퍼 테스트는 전공정을 마치고 다이싱하기 전의 웨이퍼에서 각 칩의 전극 패드에 프로브 카드의 바늘을 대어 양부를 검사하는 테스트입니다. 불량 칩을 조립 전에 제거해 패키지와 조립 비용을 낭비하지 않습니다. 파이널 테스트(최종 테스트)는 패키지로 조립한 뒤의 IC를 핸들러로 소켓에 넣어 측정하는 테스트로, 조립에서 생긴 불량까지 포함해 사양대로 동작하는지 확인한 뒤 출하합니다.

비교 항목웨이퍼 테스트(프로브 테스트)파이널 테스트(최종 테스트)
시기전공정을 마치고 다이싱하기 전조립(패키지 봉지)을 마친 뒤, 출하 전
대상웨이퍼 위의 모든 칩패키지에 봉지한 IC(웨이퍼 테스트에서 양품이었던 칩을 조립한 것)
접촉 방식프로버가 웨이퍼를 움직이고, 프로브 카드의 바늘을 칩의 전극 패드에 댐핸들러가 IC를 소켓에 넣고, 포고 핀 등으로 패키지 단자(리드나 볼)에 접촉시킴
사용 장비테스터, 프로버, 프로브 카드테스터, 핸들러, 소켓을 탑재한 로드 보드
온도웨이퍼를 올리는 척의 온도를 바꿔 측정. 상온 외에 고온이나 저온에서 측정하기도 함핸들러로 IC를 가열·냉각해, 제품이 보증하는 온도 범위의 고온·저온에서 측정하는 경우가 많음
주요 테스트 항목직류 특성(누설 전류 등), 기능 테스트, 스캔 테스트. 메모리에서는 불량 비트를 예비로 교체하는 리페어를 위한 측정기능, 직류 특성, 타이밍 등의 교류 특성, 실제 속도에서의 동작. 속도 등에 따른 등급 분류
고속 신호 측정바늘의 전기적 특성 제약이 있어 고속 신호나 대전류 측정이 어려운 경우가 있음소켓이 전기적으로 유리해 고속 신호를 측정하기 쉬움
불량 검출 목적조립 전에 불량 칩을 제거해 패키지와 조립 비용을 절약. 웨이퍼 맵으로 공정 문제를 빨리 발견조립에서 생긴 불량(접속 불량 등)까지 포함해 제거하고, 품질을 보증해 출하
불량 처리불량 칩을 웨이퍼 맵 전자 데이터에 기록하고 조립에 쓰지 않음(예전에는 잉크로 표시함)불량품을 제거하고, 양품은 성능 등으로 분류해 출하
KGD와의 관계여러 칩을 하나의 패키지에 탑재하는 경우, 이 단계에서 양품으로 확인된 칩(KGD)이 요구됨조립한 뒤에 불량으로 판명되어도 불량 칩만 교체하기는 어려움

수치는 대략적인 자릿수 기준이며, 공정 세대와 제품에 따라 달라져요.

상황별 선택 기준

웨이퍼 테스트
조립 전에 불량 칩을 제거해 패키지와 조립 비용을 절약하고 싶을 때. 여러 칩을 하나의 패키지에 탑재하는 제품에서 양품으로 확인된 칩(KGD)만 쓰고 싶을 때.
파이널 테스트
조립 후 패키지 상태에서 사양대로 동작함을 보증한 뒤 출하할 때. 보증 온도 범위나 실제 속도에서의 동작을 확인하고 싶을 때.
조합
일반적인 제품은 웨이퍼 테스트 → 조립 → 파이널 테스트 → 출하 순으로 두 테스트를 모두 수행합니다. 두 테스트가 항목을 분담해 중복을 줄이고 테스트 비용을 낮춥니다.

자주 묻는 질문

파이널 테스트가 있는데도 웨이퍼 테스트를 하는 이유는 무엇인가요?

불량 칩을 조립해 버리면 패키지 재료와 조립 비용이 낭비되기 때문입니다. 웨이퍼 단계에서 불량을 제거하면 양품만 조립할 수 있습니다. 또한 웨이퍼 맵으로 불량 분포를 보면 원인이 된 공정을 빨리 찾을 수 있습니다.

웨이퍼 테스트와 WAT(파라메트릭 테스트)는 무엇이 다른가요?

WAT는 웨이퍼 위의 TEG(평가용 패턴)에서 문턱 전압이나 면저항 등을 측정해 공정이 규격대로 이루어졌는지 확인하는 검사입니다. 웨이퍼 테스트는 제품의 각 칩이 올바르게 동작하는지 조사해 양부를 판정하는 테스트입니다.

KGD란 무엇인가요?

실장하기 전에 양품임이 확인된 칩(Known Good Die)을 말합니다. 여러 칩을 하나의 패키지에 탑재하는 경우, 불량 칩이 하나라도 섞이면 패키지 전체가 불량이 되므로 웨이퍼 테스트 단계에서 충분히 확인해 둘 필요가 있습니다.

번인은 어느 단계에서 하나요?

높은 온도와 전압을 가해 초기 고장을 일으키기 쉬운 칩을 제거하는 시험으로, 패키지로 조립한 뒤에 하는 경우가 많습니다. KGD가 필요한 경우 등에는 웨이퍼 상태에서 수행하는 웨이퍼 레벨 번인도 있습니다.

이해도 확인

웨이퍼 테스트(프로브 테스트)에 대한 설명으로 올바른 것은 무엇입니까?

  1. A다이싱 전에 웨이퍼 상의 각 칩에 프로브를 접촉시켜 전기적 특성을 검사한다
  2. B패키지 봉지 후에 외관만 검사한다
  3. C제품을 장기간 사용하여 고장률을 조사한다
정답과 해설 보기

정답: A. 다이싱 전에 웨이퍼 상의 각 칩에 프로브를 접촉시켜 전기적 특성을 검사한다

웨이퍼 테스트에서는 프로버가 웨이퍼를 움직여 프로브 카드의 침을 칩의 전극 패드에 접촉시키고, 테스터로 전기적 특성과 기능을 검사합니다. 불량 칩을 이 단계에서 찾아내면 패키지 재료비와 조립 공수를 낭비하지 않아도 됩니다. 불량은 뒤 공정에서 발견될수록 손실이 커지기 때문입니다. 봉지 후의 검사는 최종 테스트, 장기간 사용하여 고장률을 조사하는 것은 신뢰성 시험입니다.

일반적인 반도체 제품의 테스트 흐름으로 올바른 것은 무엇입니까?

  1. A최종 테스트 → 웨이퍼 테스트 → 조립 → 출하
  2. B조립 → 웨이퍼 테스트 → 출하 → 최종 테스트
  3. C웨이퍼 테스트 → 조립 → 최종 테스트 → 출하
정답과 해설 보기

정답: C. 웨이퍼 테스트 → 조립 → 최종 테스트 → 출하

먼저 전공정을 마친 웨이퍼 상태에서 웨이퍼 테스트를 하여 불량 칩을 판별합니다. 양품 칩만 조립 공정에서 패키지에 넣고, 최종 테스트로 특성을 확인한 뒤 출하합니다. 제품에 따라서는 최종 테스트 전후에 번인이나 시스템 레벨 테스트를 수행합니다. 최종 테스트는 조립 후이며, 출하 후에 하는 테스트는 없으므로 다른 순서는 성립하지 않습니다.

프로브 카드에 대한 설명으로 올바른 것은 무엇입니까?

  1. A칩을 봉지하기 위한 금형
  2. B웨이퍼를 반송하기 위한 용기
  3. C웨이퍼 상 칩의 전극에 침을 접촉시켜 테스터와 전기적으로 연결하는 지그
정답과 해설 보기

정답: C. 웨이퍼 상 칩의 전극에 침을 접촉시켜 테스터와 전기적으로 연결하는 지그

프로브 카드는 칩의 전극 패드 배치에 맞추어 다수의 침을 배열한, 품종별 전용 지그입니다. 프로버가 카메라로 웨이퍼 위치를 맞추고 척을 올려 침과 패드를 접촉시켜 테스터와 칩을 전기적으로 연결합니다. 침의 방식에는 비스듬한 침의 캔틸레버형, 수직형, MEMS 기술로 만드는 형이 있습니다. 봉지용 금형이나 반송 용기와는 별개입니다.

  1. 패키지 후의 최종 테스트에서 테스터와 조합하여 IC를 자동으로 공급하고 테스트 결과에 따라 분류하는 장치는 무엇입니까?
  2. 여러 칩을 하나의 패키지에 실장할 때 중요해지는 KGD(Known Good Die)란 무엇입니까?
  3. 웨이퍼 테스트에서 불량으로 판정한 칩의 정보를 이후 조립 공정에서 사용하는 방법으로 현재 일반적인 것은 무엇입니까?

테스트와 검사 문제 풀기

주요 용어 설명

웨이퍼 테스트(프로브 테스트)
다이싱 전에 웨이퍼 위 각 칩의 전극에 프로브를 접촉시켜 전기적 특성을 검사하는 공정. 불량 칩을 조립 전에 찾아내 불필요한 조립을 피한다.
프로브 카드(Probe Card)
웨이퍼 상태에서 칩의 전극에 다수의 바늘(프로브)을 접촉시켜 테스터와 전기적으로 연결하기 위한 지그.
KGD(Known Good Die)
실장 전에 양품임이 확인된 칩. 여러 칩을 하나의 패키지에 쌓을 때 하나라도 불량이 섞이면 전체가 불량이 되므로 중요하다.
번인(Burn-in)
고온·고전압 등의 스트레스를 가하며 동작시켜, 초기 불량이 생기기 쉬운 제품을 출하 전에 제거하는 시험.
다이싱(dicing)
웨이퍼를 개별 칩(다이)으로 자르는 공정. 회전하는 블레이드로 자르는 방법 외에 레이저로 내부에 개질층을 만드는 스텔스 다이싱 등이 있다.
