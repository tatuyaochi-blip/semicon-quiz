인핸스먼트형과 디플리션형 MOSFET의 차이: 문턱 전압·기호·용도 비교

인핸스먼트형은 게이트 전압이 0 V일 때는 채널이 없고, 게이트에 전압을 걸어 반전층을 만들어야 비로소 전류가 흐르는 MOSFET입니다(노멀리 오프). 디플리션형은 미리 채널이 만들어져 있어 게이트가 0 V여도 전류가 흐르며, 게이트에 반대 방향의 전압을 걸어 채널을 없애면 전류가 멈춥니다(노멀리 온). n채널에서는 문턱 전압이 인핸스먼트형은 양, 디플리션형은 음이 됩니다. CMOS 논리 회로를 비롯해 대부분의 용도에서는 인핸스먼트형이 사용됩니다.

상황별 선택 기준

인핸스먼트형
대부분의 경우. 게이트를 0 V로 하면 확실히 오프가 되므로, 논리 회로의 스위치나 안전하게 오프하고 싶은 파워용 스위치에 사용합니다.
디플리션형
게이트 전압 없이 전류를 흘리고 싶을 때. 저항 대신 쓰는 부하 소자, 게이트와 소스를 연결한 간단한 정전류원, 전원이 상승하기 전부터 동작하는 기동 회로 등.
노멀리 온 소자를 사용할 때
GaN HEMT처럼 본래 노멀리 온인 소자는 게이트 구조를 연구하거나, 저내압 실리콘 MOSFET과 직렬로 연결하는 캐스코드 구성으로 노멀리 오프로 사용합니다.

자주 묻는 질문

파워 용도에서 노멀리 오프가 요구되는 이유는 무엇인가요?

노멀리 온 소자는 게이트 구동 회로의 전원이 꺼지거나 고장 나면 온이 되어, 전원이 단락되어 큰 전류가 흐를 우려가 있기 때문입니다. 인핸스먼트형이라면 게이트가 0 V에서 오프가 되므로 안전합니다.

디플리션형은 어떤 회로에서 사용되어 왔나요?

CMOS가 주류가 되기 전의 NMOS 논리에서는 게이트와 소스를 연결한 디플리션형을 저항 대신 부하 소자로 사용했습니다. 현재도 간단한 정전류원이나 전원 기동 회로 등에서 사용되고 있습니다.

회로 기호에서는 어떻게 구별하나요?

채널을 나타내는 선으로 구별합니다. 인핸스먼트형은 게이트 전압을 걸지 않으면 채널이 없다는 것을 나타내기 위해 선을 3개로 끊어진 파선으로 그립니다. 디플리션형은 채널이 처음부터 있으므로 1개의 실선으로 그립니다.

문턱 전압 값으로 구별할 수 있나요?

구별할 수 있습니다. n채널에서는 문턱 전압이 양이면 인핸스먼트형, 음이면 디플리션형입니다. p채널에서는 부호가 반대가 되어, 음이면 인핸스먼트형, 양이면 디플리션형입니다.

이해도 확인

디플리션형 MOSFET의 특징으로 올바른 것은 무엇입니까?

  1. A게이트를 갖지 않는다
  2. B게이트 전압이 0 V여도 채널이 존재하여 전류가 흐른다
  3. C문턱 전압보다 높은 게이트 전압에서도 전류가 흐르지 않는다
정답과 해설 보기

정답: B. 게이트 전압이 0 V여도 채널이 존재하여 전류가 흐른다

디플리션형은 채널이 미리 만들어져 있어 게이트 전압이 0 V여도 전류가 흐르는(노멀리 온) MOSFET입니다. n채널이라면 음의 게이트 전압으로 채널을 없애 전류를 멈춥니다. 초기 NMOS 논리에서는 부하 소자로 사용되었습니다. 전원이 꺼져도 도통하므로 안전 면에서 주의가 필요하며, GaN HEMT도 본래 노멀리 온이기 때문에 노멀리 오프화하는 구조적 연구가 이루어지고 있습니다.

인핸스먼트형 n채널 MOSFET이 켜지는(도통하는) 조건으로 올바른 것은 무엇입니까? (VGS: 게이트-소스 간 전압, Vth: 문턱 전압)

  1. AVGS가 0 V일 것
  2. BVGS가 Vth보다 클 것
  3. CVGS가 음의 전압일 것
정답과 해설 보기

정답: B. VGS가 Vth보다 클 것

인핸스먼트형 nMOSFET에서는 게이트에 Vth를 넘는 양의 전압을 가하면 p형 기판 표면에 전자가 끌려와 반전층(채널)이 생기고, 소스와 드레인 사이에 전류가 흐릅니다. VGS = 0 V에서는 채널이 없어 꺼져 있으므로 게이트가 플로팅되어도 전류가 흐르기 어렵고(노멀리 오프), 논리 회로나 파워 용도의 안전성에 적합합니다. Vth는 첨단 로직에서 0.2~0.4 V, 파워용에서 1~4 V 정도가 일반적입니다.

인핸스먼트형 p채널 MOSFET의 문턱 전압(소스 기준)의 부호는 무엇입니까?

  1. A양의 값
  2. B음의 값
  3. C반드시 0 V
정답과 해설 보기

정답: B. 음의 값

pMOS에서는 게이트에 소스보다 낮은 전압을 가하면 n형 기판(n웰) 표면에 정공의 반전층이 생겨 켜집니다. 그래서 인핸스먼트형 pMOS의 문턱 전압은 음의 값(예: −0.4 V)입니다. 회로에서는 소스를 전원 VDD에 연결하고, 게이트를 VDD보다 |Vth| 이상 낮추면 켜진다고 생각합니다. 설계 자료에서는 부호의 혼란을 피하기 위해 절댓값 |Vth|로 비교하는 일이 많습니다.

  1. 파워 디바이스에서 게이트 전압이 0 V일 때 전류가 흐르지 않는 '노멀리 오프' 특성이 요구되는 주된 이유는?
  2. 노멀리 온형 GaN HEMT를 노멀리 오프 동작으로 안전하게 사용하기 위해 저내압 실리콘 MOSFET와 직렬로 조합하는 구성은?

MOSFET 문제 풀기

주요 용어 설명

문턱 전압
MOSFET에서 채널(반전층)이 형성되어 전류가 흐르기 시작하는 게이트 전압. Vth로 표기한다.
노멀리 오프(Normally-off)
게이트 전압이 0 V일 때 전류가 흐르지 않는 특성. 구동 회로가 고장 나도 전류가 계속 흐르지 않으므로 전력 소자에서 안전상 요구된다.
반전층
게이트 전압에 의해 반도체 표면에 원래와 반대 유형의 캐리어가 모여 생기는 층. MOSFET의 채널이 된다.

  • 조합 논리 vs 순차 논리: 차이점 설명조합 논리와 순차 논리를 표로 비교합니다: 출력이 의존하는 것, 기억 소자, 클럭, 피드백, 예시, 타이밍, HDL 작성 방식.
