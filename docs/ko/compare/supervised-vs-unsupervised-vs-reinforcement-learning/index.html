지도 학습·비지도 학습·강화 학습의 차이: 데이터·정답 제공 방식·목적·기법·예 비교

머신러닝은 데이터로부터 배울 때 무엇을 단서로 삼느냐에 따라 크게 3가지로 나뉩니다. 지도 학습은 입력과 정답(레이블)의 쌍을 주고, 입력에서 정답을 예측하는 모델을 학습합니다. 비지도 학습은 정답이 없는 데이터만으로 비슷한 것끼리의 묶음이나, 데이터를 적은 변수로 나타내는 구조를 찾습니다. 강화 학습은 에이전트(학습하는 주체)가 환경 속에서 행동을 고르고, 그 결과로 얻는 보상의 합계가 커지는 행동 선택 방법(정책)을 시행착오를 통해 학습합니다. 정답을 준비할 수 있고 예측하고 싶다면 지도 학습, 정답이 없고 데이터의 구조를 알고 싶다면 비지도 학습, 일련의 행동의 좋고 나쁨을 결과로부터 배우게 하고 싶다면 강화 학습이라는 것이 기본적인 선택 기준입니다.

비교 항목지도 학습비지도 학습강화 학습
학습에 쓰는 데이터입력과 정답(레이블)의 쌍정답이 없는 입력 데이터만환경과 주고받으며 얻는 상태·행동·보상의 기록. 미리 준비하는 것이 아니라 행동하면서 모은다
정답 제공 방식입력마다 올바른 출력이 주어진다주어지지 않는다행동마다의 정답은 주어지지 않는다. 보상이라는 좋고 나쁨의 평가만이 늦게 얻어지는 경우도 많다
학습 목적새로운 입력에 대한 출력을 올바르게 예측한다데이터 속의 묶음이나 구조를 찾는다앞으로 받을 보상의 합계를 크게 하는 정책을 찾는다
주요 과제회귀(수치를 예측)와 분류(클래스를 예측)클러스터링, 차원 축소, 이상 탐지일련의 행동 선택(기계의 제어, 게임의 수, 순서 결정 등)
대표적인 기법선형 회귀, 로지스틱 회귀, 결정 트리, 서포트 벡터 머신, 신경망k-평균 알고리즘, 계층적 클러스터링, 주성분 분석(PCA)Q 러닝, 정책 경사법
평가 방법따로 떼어 둔 테스트용 데이터로 정확도, 정밀도와 재현율, 평균 제곱 오차 등을 써서 정답과 비교해 평가할 수 있다정답이 없어 평가하기 어렵다. 묶음의 좋고 나쁨을 나타내는 지표나, 사람이 보고 의미가 있는지로 판단한다얻은 보상의 합계(누적 보상)로 평가한다
어려운 점정답 레이블을 준비하는 데 수고와 비용이 든다. 과적합에 주의가 필요하다결과의 좋고 나쁨을 판단하기 어렵고, 찾아낸 묶음의 의미는 사람이 해석해야 한다많은 시행착오가 필요하기 쉽다. 실물로 시험하면 위험과 비용이 크므로 시뮬레이션을 쓰는 경우가 많다. 보상을 정하는 방법도 어렵다
활용 예스팸 메일 판정, 이미지 인식, 수요와 가격 예측, 장치의 고장 예측고객 그룹 분류, 데이터 시각화와 학습의 전처리, 부정 거래나 장치 이상의 탐지바둑 같은 게임, 로봇 제어, 언어 모델의 출력을 사람의 평가에 맞추는 조정

수치는 대략적인 자릿수 기준이며, 공정 세대와 제품에 따라 달라져요.

상황별 선택 기준

지도 학습
과거 데이터에 정답(결과)이 기록되어 있고, 새로운 데이터에 대해 같은 것을 예측하고 싶을 때 적합합니다. 실무에서 쓰이는 머신러닝의 대부분이 여기에 해당합니다.
비지도 학습
정답 레이블이 없거나 준비하기 어려운 데이터에서 묶음이나 경향을 찾고 싶을 때 적합합니다. 지도 학습의 전처리로 차원 축소를 쓰기도 합니다.
강화 학습
올바른 답을 하나씩 보여 주기는 어렵지만 행동 결과의 좋고 나쁨은 평가할 수 있을 때 적합합니다. 몇 수 앞의 결과까지 생각해 일련의 행동을 정하는 문제에 쓰입니다.

자주 묻는 질문

이상 탐지는 지도 학습과 비지도 학습 중 어느 쪽인가요?

데이터에 따라 어느 쪽도 될 수 있습니다. 정상 데이터의 경향을 학습해 거기서 크게 벗어난 것을 이상으로 보는 경우에는 이상의 정답 레이블을 쓰지 않으므로 비지도 학습의 방법입니다. 이상 사례에도 레이블이 붙어 있고 수가 충분하다면 지도 학습의 분류로 다룰 수 있습니다. 실제로는 이상 사례가 매우 적은 경우가 많아 비지도 학습의 방법이 자주 쓰입니다.

준지도 학습과 자기 지도 학습이란 무엇인가요?

준지도 학습은 소량의 레이블이 붙은 데이터와 대량의 레이블이 없는 데이터를 조합해 학습하는 방법입니다. 자기 지도 학습은 문장의 일부를 가리고 그것을 맞히게 하는 것처럼 데이터 자체에서 정답을 만들어 학습하는 방법으로, 대규모 언어 모델의 사전 학습 등에 쓰입니다. 둘 다 레이블을 준비하는 수고를 줄이기 위한, 지도 학습과 비지도 학습의 중간적인 방법입니다.

강화 학습과 지도 학습의 가장 큰 차이는 무엇인가요?

지도 학습에서는 입력마다 올바른 출력이 주어지고, 그것과의 차이를 줄이도록 학습합니다. 강화 학습에서는 행동마다의 정답이 주어지지 않고, 보상이라는 평가만을 단서로 삼습니다. 게다가 보상은 일련의 행동 뒤에 한꺼번에 얻어지는 경우가 많아, 어느 행동이 좋았는지를 스스로 가려내야 합니다. 학습에 쓰는 데이터를 자신의 행동으로 모은다는 점도 다릅니다.

머신러닝의 기초 문제 풀기

주요 용어 설명

지도 학습(Supervised Learning)
입력과 정답(레이블)의 쌍으로 이루어진 데이터를 사용하여, 입력으로부터 정답을 예측하는 모델을 학습하는 머신러닝 방법. 예측하는 출력이 연속적인 수치이면 회귀, 정해진 몇 개의 클래스 중 하나이면 분류라고 부른다. 선형 회귀, 로지스틱 회귀, 결정 트리, 서포트 벡터 머신, 신경망 등의 모델이 사용된다. 정답 레이블을 준비하는 데 수고가 드는 경우가 많다.
비지도 학습(Unsupervised Learning)
정답 레이블이 없는 데이터로부터 데이터 안의 묶음이나 구조를 찾아내는 머신러닝 방법. 비슷한 데이터를 그룹으로 나누는 클러스터링(k-평균 알고리즘 등), 데이터를 적은 변수로 나타내는 차원 축소(주성분 분석 등), 다른 것과 크게 다른 데이터를 찾아내는 이상 탐지 등에 사용된다. 레이블을 준비하지 않아도 되는 반면, 결과의 좋고 나쁨을 평가하기 어렵다.
강화 학습(Reinforcement Learning)
에이전트(학습하는 주체)가 환경의 상태를 보고 행동을 선택하며, 그 결과로 받는 보상의 합계(앞으로 받을 몫을 포함)가 커지는 행동 선택 방법(정책)을 시행착오를 통해 학습하는 머신러닝 방법. 행동마다의 정답은 주어지지 않으며, 보상이 늦게 얻어지는 경우도 많다. 게임, 로봇 제어, 언어 모델의 출력을 사람의 평가에 맞추는 조정 등에 사용된다.
k-평균 알고리즘(k-means)
데이터를 미리 정한 k개의 클러스터로 나누는 대표적인 클러스터링 방법. k개의 중심을 임시로 정하고, 각 데이터를 가장 가까운 중심의 클러스터에 할당하는 것과 각 클러스터에 속한 데이터의 평균을 새 중심으로 삼는 것을 할당이 바뀌지 않을 때까지 반복한다. 계산이 간단하고 큰 데이터에도 사용할 수 있지만, 결과가 초깃값에 좌우되고, k를 스스로 정해야 하며, 구형이 아닌 묶음은 나누기 어렵다.
주성분 분석(PCA)
많은 변수를 가진 데이터를 정보를 되도록 잃지 않고 적은 변수로 나타내는 차원 축소 방법. 데이터의 분산이 가장 커지는 방향을 제1주성분으로 하고, 그와 직교하는 방향 중 분산이 가장 큰 방향을 제2주성분과 같이 차례로 구하여, 상위 주성분만으로 데이터를 나타낸다. 수학적으로는 데이터의 공분산 행렬의 고유벡터를 구하는 것에 해당한다. 데이터 시각화, 잡음 제거, 학습 전처리 등에 사용된다.
과적합(Overfitting)
모델이 학습용 데이터의 세세한 특징이나 우연한 잡음까지 외워 버려서, 학습용 데이터에서는 오차가 작은데 새로운 데이터에 대한 오차(일반화 오차)가 커지는 상태. 과대적합이라고도 한다. 파라미터가 많은 복잡한 모델을 적은 데이터로 학습하면 일어나기 쉽다. 데이터를 늘리기, 모델을 단순하게 하기, 정칙화, 드롭아웃, 조기 종료 등으로 억제한다.
정밀도와 재현율(Precision and Recall)
2클래스 분류 모델의 평가 지표. 정밀도(precision)는 양성으로 예측한 것 중 실제로 양성이었던 비율 TP ÷ (TP + FP), 재현율(recall)은 실제로 양성인 것 중 양성으로 예측할 수 있었던 비율 TP ÷ (TP + FN)이다. 일반적으로 판정 임계값을 바꾸면 한쪽이 오르면 다른 쪽이 내려가는 관계에 있다. 둘의 조화 평균 2PR ÷ (P + R)을 F값(F1 점수)이라고 부른다.
