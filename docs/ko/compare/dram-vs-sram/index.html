DRAM과 SRAM의 차이점 한눈에 정리

DRAM은 각 비트를 작은 커패시터의 전하로 저장하므로 집적도가 높고 저렴하지만 리프레시가 필요합니다. SRAM은 트랜지스터로 만든 래치에 각 비트를 저장하므로 더 빠르고 리프레시가 필요 없지만, 비트당 면적이 훨씬 큽니다. 그래서 컴퓨터는 대용량 메인 메모리에는 DRAM을, 작고 빠른 캐시에는 SRAM을 사용합니다.

상황별 선택 기준

DRAM
비트당 비용이 낮은 대용량 메모리가 필요하고 어느 정도의 지연을 감수할 수 있을 때: PC, 서버, 스마트폰의 메인 메모리와 GPU용 그래픽 메모리.
SRAM
속도가 가장 중요하고 용량은 작아도 될 때: CPU 캐시, 레지스터 파일, 리프레시 회로를 두고 싶지 않은 작은 버퍼.
함께 사용
실제 컴퓨터는 둘 다 사용합니다. 빠른 SRAM 캐시가 자주 쓰는 데이터를 보관해 느린 DRAM의 지연을 가려 줍니다.

자주 묻는 질문

SRAM이 DRAM보다 빠른가요?

네. SRAM은 각 비트를 트랜지스터 래치에 저장하므로 온칩 SRAM은 약 1나노초 만에 접근할 수 있습니다. DRAM은 먼저 행을 활성화해야 해서 수십 나노초가 걸리며, 이것이 CPU 캐시에 SRAM을 쓰는 이유입니다.

DRAM은 왜 SRAM보다 저렴한가요?

DRAM 셀은 트랜지스터 1개와 커패시터 1개만 필요하지만, SRAM 셀은 보통 트랜지스터 6개가 필요합니다. 셀이 작으면 같은 실리콘 면적에 훨씬 많은 비트를 넣을 수 있어 비트당 비용이 낮아집니다.

DRAM은 왜 리프레시가 필요한가요?

DRAM 셀의 커패시터는 전하가 서서히 새어 나가므로 데이터를 주기적으로(보통 64 ms 이내) 읽고 다시 써야 합니다. SRAM은 전원이 공급되는 동안 값을 유지하므로 리프레시가 필요 없습니다.

DRAM과 SRAM 중 비휘발성인 것은 무엇인가요?

둘 다 아닙니다. 두 메모리 모두 전원이 끊기면 데이터를 잃습니다. 플래시, MRAM, ReRAM 같은 비휘발성 메모리는 전원 없이도 데이터를 유지합니다.

이해도 확인

SRAM과 비교했을 때 DRAM의 특징으로 올바른 것은?

  1. ASRAM보다 빠르고 리프레시도 필요 없다
  2. B셀이 작아 비트당 비용이 낮지만 리프레시가 필요하다
  3. C전원을 꺼도 데이터가 남는다
정답과 해설 보기

정답: B. 셀이 작아 비트당 비용이 낮지만 리프레시가 필요하다

DRAM은 1T1C의 작은 셀(약 6F²)로, 6T SRAM(약 120~150F²)보다 20배 안팎 고밀도로 만들 수 있어 비트당 비용이 낮아집니다. 반면 리프레시가 필요하고, 접근에 행 활성화 등으로 수십 ns가 걸려 SRAM(1 ns 안팎)보다 느립니다. 그래서 주기억장치에는 DRAM, CPU 캐시에는 SRAM을 사용하여 두 가지의 장점을 조합한 메모리 계층이 만들어집니다.

일반적인 DRAM의 1비트 메모리 셀 구성으로 올바른 것은?

  1. A트랜지스터 1개와 커패시터 1개
  2. B트랜지스터 6개
  3. C플로팅 게이트를 가진 트랜지스터 1개
정답과 해설 보기

정답: A. 트랜지스터 1개와 커패시터 1개

DRAM 셀은 트랜지스터 1개와 커패시터 1개(1T1C)로 이루어지며, 커패시터의 전하 유무로 1비트를 저장합니다. 커패시터는 약 10 fF 정도로 매우 작아, 불과 수만 개 전자의 차이로 0과 1을 구분합니다. 소자 수가 적어 셀 면적이 약 6F²로 작고 대용량화에 적합합니다. 트랜지스터 6개는 SRAM, 플로팅 게이트 트랜지스터는 플래시 메모리의 셀 구성입니다.

DRAM에서 주기적인 리프레시 동작이 필요한 이유로 올바른 것은?

  1. A읽기 속도를 높이기 위해
  2. B쓰기 횟수에 상한이 있기 때문에
  3. C커패시터에 저장된 전하가 누설 전류로 인해 서서히 사라지기 때문에
정답과 해설 보기

정답: C. 커패시터에 저장된 전하가 누설 전류로 인해 서서히 사라지기 때문에

커패시터의 전하는 셀 트랜지스터의 서브스레숄드 누설과 접합 누설로 조금씩 사라집니다. 데이터를 판별할 수 없게 되기 전에 읽어서 다시 쓰는 것이 리프레시이며, DDR4까지의 규격에서는 64 ms 이내, DDR5에서는 32 ms 이내에 모든 행을 한 바퀴 돕니다. 리프레시 중에는 해당 뱅크에 접근할 수 없고 전력도 소비하므로 용량이 커질수록 부담이 커집니다. 쓰기 횟수 상한은 플래시 메모리의 특징입니다.

DRAM 문제 풀기

주요 용어 설명

1T1C 셀
트랜지스터 1개와 커패시터 1개로 1비트를 기억하는 DRAM 메모리 셀. 커패시터의 전하 유무로 0과 1을 나타낸다.
6T SRAM 셀
교차 연결된 두 인버터(4개)와 접근용 트랜지스터 2개로 이루어진 SRAM의 메모리 셀.
리프레시(Refresh)
DRAM 커패시터의 전하가 누설로 사라지기 전에 주기적으로 데이터를 읽어 다시 쓰는 동작.
캐시 메모리
CPU 가까이에 두는 고속·소용량 메모리. 자주 쓰는 데이터를 보관하여 주기억장치와의 속도 차이를 완화한다. 주로 SRAM으로 만든다.

  • 폰 노이만 vs 하버드 아키텍처: 차이점 설명폰 노이만과 하버드 아키텍처를 표로 비교합니다: 메모리, 버스, 처리량, 유연성, 복잡도, 주요 장치, 수정된 하버드 설계.

  • 라이트스루 vs 라이트백 캐시: 차이점 설명라이트스루와 라이트백 캐시를 표로 비교합니다: 쓰기 정책, 메모리 트래픽, 속도, 일관성, 복잡도, 축출 비용, 대표 용도.
  • L1, L2, L3 캐시의 차이점 정리L1, L2, L3 캐시를 일반적인 PC·서버 CPU를 예로 표로 비교합니다. 용량과 레이턴시, 코어별 또는 공유, 명령어와 데이터의 분리, 포함 관계, 설계에서 중시하는 점을 다룹니다.
