Verilog와 VHDL: 두 HDL의 차이점

Verilog와 VHDL은 시뮬레이션과 합성을 위해 디지털 회로를 기술하는 두 가지 주요 하드웨어 기술 언어(HDL)입니다. Verilog는 C와 비슷한 간결한 문법이라 시작하기 쉽습니다. VHDL은 장황하고 강한 타입 체계를 가져 더 많은 실수를 초기에 잡아 냅니다. 두 언어 모두 같은 회로를 기술할 수 있으며, 선택은 보통 업계, 회사, 기존 코드에 따라 달라집니다.

상황별 선택 기준

Verilog / SystemVerilog
업계 도구와 라이브러리가 SystemVerilog를 중심으로 만들어져 있으므로 칩 설계와 검증의 좋은 기본 선택입니다.
VHDL
안전 필수 및 방위 프로젝트처럼 엄격한 타입 체계와 장기적인 유지보수성이 중요한 곳에 좋은 선택입니다.
실제로는
두 언어를 모두 읽어야 하는 경우가 많습니다. 모듈(또는 엔티티), 동시 신호, 클록 프로세스 같은 개념은 동일합니다.

자주 묻는 질문

Verilog와 VHDL 중 어느 쪽이 배우기 쉬운가요?

Verilog입니다. 문법이 짧고 C와 비슷하기 때문입니다. VHDL은 더 장황하고 강한 타입 체계라 처음엔 어렵지만 컴파일 시점에 더 많은 실수를 잡아 줍니다.

업계에서는 어느 쪽을 더 많이 쓰나요?

ASIC과 SoC 설계 및 검증에서는 특히 미국과 아시아에서 SystemVerilog가 지배적입니다. VHDL은 유럽, 항공우주·방위 산업, 다수의 FPGA 프로젝트에서 흔합니다.

하나의 프로젝트에서 Verilog와 VHDL을 섞어 쓸 수 있나요?

네. 주요 시뮬레이터와 합성 도구가 혼합 언어 설계를 지원하므로, 한 언어로 작성한 모듈을 다른 언어에서 사용할 수 있습니다.

SystemVerilog란 무엇인가요?

SystemVerilog는 Verilog를 확장해 클래스, 제약 랜덤 테스트, 어서션, UVM 방법론을 추가한 언어로, 칩 검증의 표준입니다.

이해도 확인

Verilog 등의 HDL로 작성한 기술과 C 언어 등의 소프트웨어 프로그램의 큰 차이로 올바른 것은?

  1. AHDL 기술은 동시에 병렬로 동작하는 회로를 나타낸다
  2. BHDL 기술은 위쪽 줄부터 한 줄씩 순서대로 실행되는 명령의 나열이다
  3. CHDL에서는 변수나 조건 분기를 사용할 수 없다
정답과 해설 보기

정답: A. HDL 기술은 동시에 병렬로 동작하는 회로를 나타낸다

HDL은 겉보기에는 프로그램과 비슷하지만, 작성한 내용은 논리 합성을 통해 게이트와 플립플롭으로 이루어진 회로가 됩니다. 회로의 각 부분은 항상 동시에 동작하므로, 여러 assign문이나 always 블록은 작성한 순서와 관계없이 병렬로 동작합니다. 소프트웨어처럼 '이 처리가 끝나면 다음'이라고 생각하면 의도한 회로가 되지 않으므로, 어떤 회로가 만들어질지 상상하면서 작성하는 것이 중요합니다.

Verilog에서 module을 사용하는 목적으로 올바른 것은?

  1. A입력과 출력 단자(포트)를 가진 회로의 부품을 정의하여 다른 module 안에서 사용할 수 있게 한다
  2. B프로그램의 실행을 일시적으로 멈춘다
  3. C시뮬레이션 결과를 화면에 표시한다
정답과 해설 보기

정답: A. 입력과 출력 단자(포트)를 가진 회로의 부품을 정의하여 다른 module 안에서 사용할 수 있게 한다

module은 입력과 출력 포트를 가진 회로의 묶음을 정의하는 단위로, 가산기나 카운터, CPU 전체 등을 나타냅니다. 정의한 module은 다른 module 안에서 부품으로 몇 번이든 사용할 수 있으며(인스턴스화), 포트를 배선으로 연결하여 큰 회로를 조립합니다. 기판 위에 부품을 배치하고 배선하는 것과 마찬가지로, 회로를 계층적으로 만들 수 있습니다.

Verilog의 wire형과 reg형의 차이로 올바른 것은?

  1. Areg는 반드시 플립플롭이 되고, wire는 반드시 조합 회로가 된다
  2. Bwire는 assign문 등으로 연결되는 배선을 나타내고, reg는 always 블록 안에서 값을 대입하는 신호를 나타내지만, reg가 반드시 플립플롭이 되는 것은 아니다
  3. Cwire는 숫자를, reg는 문자를 담기 위한 형이다
정답과 해설 보기

정답: B. wire는 assign문 등으로 연결되는 배선을 나타내고, reg는 always 블록 안에서 값을 대입하는 신호를 나타내지만, reg가 반드시 플립플롭이 되는 것은 아니다

Verilog에서는 assign문이나 module의 출력으로 구동되는 신호는 wire, always 블록 안에서 대입되는 신호는 reg로 선언하는 규칙입니다. reg는 '레지스터'의 약자처럼 보이지만, always @(*) 안에서 대입하면 조합 회로가 되며 플립플롭이 되지는 않습니다. 플립플롭이 되는지 여부는 클럭 에지에서 값을 갱신하는 방식으로 작성했는지에 따라 결정됩니다. SystemVerilog에서는 둘 다 logic형으로 쓸 수 있습니다.

  1. Verilog의 논블로킹 대입(<=)의 동작으로 올바른 것은?
  2. RTL 설계에서 주로 사용되는 하드웨어 기술 언어는?
  3. SystemVerilog를 사용한 검증에서 재사용하기 쉬운 테스트 환경(테스트벤치)을 구성하기 위한 표준 방법론은 무엇인가?

HDL과 검증 문제 풀기

주요 용어 설명

Verilog
디지털 회로의 설계와 검증에 널리 사용되는 하드웨어 기술 언어. module을 단위로 회로를 쓰고 assign과 always로 동작을 나타낸다.
SystemVerilog
Verilog를 확장한 언어. logic형과 always_ff·always_comb 등의 설계 기능, 클래스, 제약 조건 랜덤, 어서션 등의 검증 기능을 갖는다.
하드웨어 기술 언어(HDL)
디지털 회로의 구조와 동작을 문장으로 기술하기 위한 언어. HDL. Verilog, SystemVerilog, VHDL이 있으며 논리 합성으로 회로로 변환한다.
RTL(레지스터 전송 레벨)
레지스터 간에 데이터가 어떻게 전송·처리되는지로 회로를 기술하는 설계 추상화 수준. Verilog나 VHDL로 작성하며 논리 합성의 입력이 된다.
