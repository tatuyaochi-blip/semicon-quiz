스캔 테스트와 BIST의 차이점 정리

스캔 테스트는 칩 안의 플립플롭을 연결해 시프트 레지스터(스캔 체인)로 만들고, 외부 테스터에서 테스트 패턴을 넣은 뒤 회로의 응답을 꺼내 기댓값과 비교하는 방법입니다. 패턴은 ATPG 도구가 넷리스트로부터 만듭니다. BIST는 패턴을 만드는 회로와 결과를 판정하는 회로를 칩 안에 내장해 칩 스스로 테스트하는 방법입니다. 양산 테스트에서는 로직에는 스캔 테스트, 내장 메모리에는 메모리 BIST를 쓰는 조합이 일반적이며, BIST는 출하 후 자기 진단에도 쓸 수 있습니다.

비교 항목스캔 테스트BIST(내장 자체 테스트)
기본 개념플립플롭을 스캔 체인으로 연결하고, 패턴을 시프트로 넣어 한 번 동작시킨 뒤 결과를 시프트로 꺼내 비교패턴을 만드는 회로와 응답을 판정하는 회로를 칩에 내장해, 칩 스스로 테스트하고 합격 여부를 출력
테스트 패턴 생성 방법ATPG가 넷리스트로부터 고착 고장이나 천이 지연 고장을 겨냥한 결정적 패턴을 만듦로직 BIST는 LFSR로 의사 난수 패턴을 만듦. 메모리 BIST는 마치 테스트 등 정해진 절차로 주소와 데이터를 만듦
응답 판정테스터가 기댓값과 비교(테스트 압축에서는 칩 안에서 압축한 응답을 비교)로직 BIST는 MISR로 응답을 압축한 시그니처를 기댓값과 비교. 메모리 BIST는 읽은 값을 비교기로 직접 확인
테스터 의존도패턴과 기댓값을 테스터 메모리에 보관. 스캔용 단자와 테스터의 성능·메모리 용량이 필요시작 지시와 결과 읽기(JTAG 등)만으로 충분하며, 간단한 테스터로 가능
주요 대상로직 회로(조합 회로와 플립플롭)메모리 BIST는 내장 SRAM 등의 메모리. 로직 BIST는 로직 회로
고장 검출률겨냥한 고장을 향해 패턴을 만들므로 높이기 쉬움로직 BIST는 의사 난수로는 찾기 어려운 고장이 남기 쉬워 테스트 포인트 삽입으로 보완. 메모리 BIST는 메모리 고장 모델에 맞춘 절차로 높은 검출률을 얻음
추가 회로플립플롭을 스캔 플립플롭(전환용 멀티플렉서 포함)으로 교체하고 체인 배선을 추가패턴 발생기, 응답 압축기, 제어 회로가 필요. 로직 BIST에서는 부정값(X)이 나오지 않도록 회로를 정비할 필요도 있음
테스트 시간체인이 길면 시프트에 시간이 걸리고 테스터 속도에도 제한됨. 테스트 압축으로 단축칩 내부 클록으로 많은 패턴을 빠르게 흘릴 수 있음. 로직 BIST는 패턴 수가 많아짐
사용 시기양산 웨이퍼 테스트와 최종 테스트가 중심. 불량품의 고장 진단에도 사용양산 테스트에 더해, 기판 실장 후 검사나 출하 후 전원 투입 시 등의 자기 진단에도 사용 가능

수치는 대략적인 자릿수 기준이며, 공정 세대와 제품에 따라 달라져요.

상황별 선택 기준

스캔 테스트
양산 테스트에서 로직의 구조적 고장을 높은 검출률로 찾고 싶을 때. 불량 칩의 고장 위치를 좁히고 싶을 때.
BIST
외부에서 직접 접근하기 어려운 내장 메모리의 테스트. 테스터 단자나 메모리를 줄이고 싶을 때. 차량용 등에서 출하 후 전원 투입 시나 주행 전 자기 진단이 필요할 때.
조합
실제 칩에서는 로직에 스캔 테스트(테스트 압축 포함), 메모리에 메모리 BIST를 쓰는 것이 일반적입니다. 로직 BIST도 스캔 체인을 토대로 동작합니다.

자주 묻는 질문

BIST가 있으면 스캔 테스트는 필요 없나요?

많은 칩에서는 둘 다 사용합니다. 로직 BIST는 의사 난수 패턴을 쓰므로 찾기 어려운 고장이 남기 쉬워, 양산 테스트에서는 ATPG로 만든 패턴에 의한 스캔 테스트로 높은 고장 검출률을 확보하는 것이 일반적입니다. 메모리는 규칙적인 구조이므로 메모리 BIST로 테스트합니다.

로직 BIST와 스캔 테스트는 어떤 관계인가요?

로직 BIST도 스캔 체인을 사용합니다. LFSR이 만든 패턴을 체인에 넣고, 회로를 동작시킨 뒤 나온 응답을 MISR로 압축해, 마지막에 만들어진 시그니처를 기댓값과 비교합니다. 스캔 설계가 토대가 됩니다.

내장 메모리 테스트에 BIST가 자주 쓰이는 이유는 무엇인가요?

칩에 내장된 메모리는 외부 단자에서 직접 읽고 쓰기 어렵고, 구조가 규칙적이어서 마치 테스트 같은 정해진 절차의 주소와 데이터를 작은 회로로 만들 수 있기 때문입니다. 찾아낸 불량 비트를 예비 행이나 열로 교체하는 리페어와 조합하는 경우도 많습니다.

차량용 칩에서 전원 투입 시 BIST를 수행하는 이유는 무엇인가요?

출하 후 생긴 고장이나 평소 동작에서는 드러나지 않는 잠재 고장을 찾기 위해서입니다. BIST는 테스터 없이도 칩 스스로 실행할 수 있으므로 차량 안에서의 자기 진단에 쓸 수 있습니다.

이해도 확인

테스트 용이화 설계(DFT)의 하나인 스캔 설계에 대한 설명으로 올바른 것은 무엇입니까?

  1. A칩 표면을 광학 현미경으로 주사하여 결함을 찾는다
  2. B테스트 시 전원 전압을 서서히 올려 동작 한계를 조사한다
  3. C회로 내 플립플롭을 시프트 레지스터 형태로 연결하여 내부 상태의 설정과 관측을 쉽게 한다
정답과 해설 보기

정답: C. 회로 내 플립플롭을 시프트 레지스터 형태로 연결하여 내부 상태의 설정과 관측을 쉽게 한다

스캔 설계에서는 각 플립플롭의 입력에 전환용 셀렉터를 달고, 테스트 때는 이들을 줄줄이 연결(스캔 체인)하여 외부에서 임의의 값을 시프트로 설정하고 내부 값을 시프트로 읽어 낼 수 있게 합니다. 순차 회로의 테스트가 조합 회로의 테스트로 대체되므로, ATPG로 높은 고장 검출률의 패턴을 자동 생성할 수 있습니다. 현미경 주사나 전압 스윕과는 별개입니다.

BIST(내장 자체 테스트)에 대한 설명으로 올바른 것은 무엇입니까?

  1. A외부 테스터만으로 모든 테스트를 수행한다
  2. B테스트용 회로를 칩 안에 내장하여 칩 스스로 테스트를 수행한다
  3. C사람의 눈으로 외관을 검사한다
정답과 해설 보기

정답: B. 테스트용 회로를 칩 안에 내장하여 칩 스스로 테스트를 수행한다

BIST는 테스트 패턴의 생성 회로와 결과의 판정 회로를 칩에 내장하여 칩 스스로 테스트를 실행하는 구조입니다. 메모리용 MBIST는 마치 테스트 등의 패턴을 고속으로 발생시키고, 로직 회로용 LBIST는 의사 난수 패턴을 사용합니다. 고가의 테스터에 대한 의존과 테스트 시간을 줄일 수 있을 뿐 아니라, 차량용에서는 전원을 켤 때마다 출하 후에도 자기 진단을 할 수 있다는 장점이 있습니다.

회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것을 무엇이라고 합니까?

  1. ADRC
  2. BATPG(자동 테스트 패턴 생성)
  3. CCTS
정답과 해설 보기

정답: B. ATPG(자동 테스트 패턴 생성)

ATPG는 고착 고장 등의 고장 모델에 기초하여, 각 고장을 출력까지 전달하여 검출할 수 있는 입력 패턴을 넷리스트로부터 자동으로 생성하는 기술입니다. 스캔 설계와 조합하면 수억 게이트의 회로에서도 높은 고장 검출률의 패턴을 효율적으로 만들 수 있습니다. DRC는 레이아웃의 설계 규칙 검사, CTS는 클록 트리 합성으로, 둘 다 설계 공정입니다.

  1. 테스트 패턴의 고장 검출률(폴트 커버리지)의 정의로 올바른 것은 무엇입니까?
  2. 스캔 테스트의 데이터 양과 테스트 시간을 줄이기 위해 칩 안에서 테스트 패턴을 전개하고 응답을 압축하는 기술을 무엇이라고 합니까?
  3. 차량용 마이컴에서 전원을 켤 때나 주행 전 등에 로직 BIST나 메모리 BIST를 실행하는 기능 안전상의 주된 목적은?

테스트와 검사 문제 풀기

주요 용어 설명

스캔 테스트(scan test)
회로 안의 플립플롭을 사슬 모양으로 이은 스캔 체인을 사용해 내부 상태를 설정·관측하며 테스트하는 방법.
BIST(내장 자체 테스트)
테스트용 회로를 칩 안에 내장해 칩 스스로 테스트 패턴을 생성하고 결과를 판정하는 방식. 메모리 테스트 등에 널리 쓰인다.
ATPG(자동 테스트 패턴 생성)
회로의 넷리스트로부터 고장을 검출하기 위한 테스트 패턴을 자동으로 생성하는 것. 스캔 설계와 조합하여 사용한다.
고장 검출률(Fault Coverage)
가정한 고장 중 해당 테스트 패턴으로 검출할 수 있는 고장의 비율. 높을수록 불량품을 놓치기 어렵다.
DFT(테스트 용이화 설계)
스캔 체인이나 BIST처럼 테스트하기 쉽게 하는 구조를 회로에 미리 넣어 두는 설계 기법.

관련 비교

  • 정적 번인 vs 동적 번인 vs 웨이퍼 레벨 번인: 스트레스·커버리지·비용 비교정적 번인, 동적 번인, 웨이퍼 레벨 번인을 표로 비교합니다: 스트레스를 가하는 방식, 수행 단계, 대표 조건, 스트레스가 걸리는 범위, 장비와 지그, 모니터링, 비용, 과제, 용도. 구분해서 쓰…
  • 웨이퍼 테스트와 파이널 테스트의 차이점 정리웨이퍼 테스트(프로브 테스트)와 파이널 테스트를 표로 비교합니다. 시기와 대상, 접촉 방식, 온도, 테스트 항목, 불량 검출 목적, KGD를 안내합니다.
  • 와이어 본딩 vs 플립 칩: 칩 인터커넥트 비교와이어 본딩과 플립 칩을 표로 비교합니다: 칩 연결 방식, I/O 수, 전기적 성능, 비용, 크기, 공정, 대표 용도.
  • SEM vs TEM: 반도체 분석용 전자현미경SEM과 TEM을 표로 비교합니다: 원리, 관찰 대상, 해상도, 시료 준비, 전압, 속도, 비용, 칩 분석에서의 대표 용도.
  • BGA vs QFP vs QFN: IC 패키지 유형 비교BGA, QFP, QFN 패키지를 표로 비교합니다: 단자, 핀 수, 피치, 크기, 전기적 및 열 성능, 검사, 주요 용도.
  • 볼 본딩 vs 웨지 본딩: 재료·공정·방향성·용도 비교볼 본딩과 웨지 본딩을 표로 비교합니다: 접합 형태, 공구, 접합 에너지, 와이어 재료(Au·Cu와 Al·리본), 굵기, 방향성, 속도, 루프, 신뢰성, 용도. 각각을 언제 쓰는지도 설명합니다.
