CMOS 인버터

CMOS 인버터는 전원 쪽 pMOS와 GND 쪽 nMOS를 직렬로 연결하고, 두 게이트에 같은 입력을 넣은 회로입니다. 입력이 0이면 pMOS가 켜지고 nMOS가 꺼져 출력은 전원 전압(1)이 되고, 입력이 1이면 pMOS가 꺼지고 nMOS가 켜져 출력은 0이 됩니다.

어느 상태에서든 한쪽 트랜지스터가 꺼져 있으므로 전원에서 GND로 전류가 거의 흐르지 않습니다. 이것이 CMOS의 소비 전력이 작은 이유입니다. 다만 입력이 바뀌는 도중에는 두 트랜지스터가 동시에 도통하는 순간이 있어 관통 전류가 흐릅니다.

직접 확인하기: 입력 전압과 출력

입력 전압을 0에서 전원 전압까지 움직이면 pMOS와 nMOS의 켜짐/꺼짐과 출력 전압이 바뀝니다. 오른쪽 그래프는 입력과 출력의 관계(전달 특성)입니다. 조건은 VDD = 1.2 V, 문턱 전압의 크기 0.35 V, nMOS와 pMOS의 구동력이 같다고 보고, 장채널 제곱 법칙으로 계산합니다.
