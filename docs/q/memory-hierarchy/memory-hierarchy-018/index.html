メモリ階層と性能

行列の積などで使われるループブロッキング(タイリング)の主な目的はどれか。

  1. Aキャッシュに収まる小さなブロックごとに計算し、データの再利用を増やすため
  2. Bループの回数を減らして、ループの終わりで実行する分岐命令の数を少なくするため
  3. C計算の順番を変えずに、使うメモリの総量を半分にするため
答えと解説を見る

正解：A. キャッシュに収まる小さなブロックごとに計算し、データの再利用を増やすため

大きな行列の積をそのまま計算すると、一度読み込んだ要素が再び使われる前にキャッシュから追い出され、何度も主記憶から読み直すことになります。ループブロッキングでは行列をキャッシュに収まる小さなブロックに分け、ブロックの中で計算をすませることで、読み込んだデータを何度も再利用し、容量ミスを大きく減らします。分岐命令を減らすのはループ展開の目的で、使うメモリの総量は変わりません。

  • A. 正しい。キャッシュに収まる単位で計算し、データの再利用を増やします。
  • B. 分岐を減らすのはループ展開の目的です。
  • C. 計算の順番は変わり、使うメモリの総量は変わりません。

この分野の比較

  • ライトスルーとライトバックの違い：キャッシュの書き込み方式を比較ライトスルーとライトバックのキャッシュを、書き込みの方式・メモリのトラフィック・速度・整合性・複雑さ・追い出しのコスト・用途の観点で表にして比較します。
  • ダイレクトマップ・セットアソシアティブ・フルアソシアティブの違い：キャッシュの方式を比較ダイレクトマップ、セットアソシアティブ、フルアソシアティブのキャッシュを、ブロックを置ける場所・タグの比較・速度・コスト・競合ミス・用途の観点で表にして比較します。
  • L1・L2・L3キャッシュの違い：容量・レイテンシ・共有範囲・包含関係を比較L1・L2・L3キャッシュを、容量とレイテンシの目安・コアごとか共有か・命令とデータの分離・包含関係・設計で重視することの観点で、一般的なPCやサーバーのCPUを例に表で比較します。
