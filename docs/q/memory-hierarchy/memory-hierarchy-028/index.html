メモリ階層と性能

大きなページ(ヒュージページ)を使う主な利点と欠点の組み合わせとして正しいものはどれか。

  1. A利点はキャッシュのミス率が下がること、欠点はTLBミスが増えること
  2. B利点はページフォルトがなくなること、欠点はディスクの容量を多く使うこと
  3. C利点はTLBミスが減ること、欠点は内部断片化が増えやすいこと
答えと解説を見る

正解：C. 利点はTLBミスが減ること、欠点は内部断片化が増えやすいこと

ページを大きくすると、1つのTLBエントリで広い範囲を変換できるため、大きなデータを扱うプログラムでTLBミスが大きく減ります。一方、少しのデータでも大きなページ単位で割り当てるので、使わない領域(内部断片化)が増え、メモリの割り当ても柔軟でなくなります。TLBミスはむしろ減り、キャッシュのミス率はページの大きさに直接は左右されません。ページフォルトがなくなるわけでもありません。

  • A. TLBミスはむしろ減り、キャッシュのミス率は直接変わりません。
  • B. ページフォルトはなくなりません。
  • C. 正しい。TLBミスが減る反面、内部断片化が増えます。

メモリ階層と性能のほかの問題

  1. 2次元配列の1行の大きさが4096バイト(2の累乗)のとき、列方向に要素をたどると、キャッシュの容量に余裕があってもミスが多くなることがある。その対策として効果があるものはどれか。
