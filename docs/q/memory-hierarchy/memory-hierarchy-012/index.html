メモリ階層と性能

ライトバック方式のキャッシュで、各ラインに付けるダーティビットの役割として正しいものはどれか。

  1. Aそのラインのデータが有効で読み出せるかどうかを示す
  2. B書き換えられ、主記憶と内容が違うことを示す
  3. Cそのラインに最後にアクセスした時刻を示す
答えと解説を見る

正解：B. 書き換えられ、主記憶と内容が違うことを示す

ライトバック方式では書き込みをキャッシュだけで済ませるため、主記憶の内容が古くなったラインができます。ダーティビットはそのラインが書き換えられたことを示し、追い出すときにダーティなラインだけを主記憶へ書き戻せば済むようにします。書き換えていないラインはそのまま捨てられるので、無駄な書き込みを減らせます。ラインが有効かどうかを示すのは有効ビットで、アクセスの順番はLRUなどの置き換え用の情報で管理します。

  • A. データが有効かどうかを示すのは有効ビットです。
  • B. 正しい。書き換えられて主記憶と違うことを示し、追い出し時の書き戻しを決めます。
  • C. アクセスの順番は置き換え方式のための別の情報です。
