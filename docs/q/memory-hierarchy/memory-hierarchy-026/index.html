メモリ階層と性能

L1キャッシュのミス率(全アクセスに対する割合)が4%、L2キャッシュのグローバルミス率(全アクセスのうちL2でもミスする割合)が1%のとき、L2のローカルミス率はいくらか。

  1. A25%
  2. B4%
  3. C1%
答えと解説を見る

正解：A. 25%

ローカルミス率は、そのキャッシュに届いたアクセスのうちミスした割合です。L2に届くのはL1でミスした全体の4%で、そのうち全体の1%がL2でもミスするので、ローカルミス率は 1 ÷ 4 = 25%です。L2のローカルミス率は高く見えますが、L2にはL1で取りきれなかった局所性の低いアクセスだけが届くためで、L2の効果が小さいとは限りません。1%は全体に対するグローバルミス率、4%はL1のミス率です。

  • A. 正しい。L2に届いた4%のうち1%がミスするので25%です。
  • B. 4%はL1のミス率です。
  • C. 1%は全アクセスに対するグローバルミス率です。

メモリ階層と性能のほかの問題

  1. TLBのエントリが64個で、ページサイズが4 KBのとき、TLBのミスなしでアクセスできるメモリの範囲(TLBリーチ)はいくらか。
  2. 大きなページ(ヒュージページ)を使う主な利点と欠点の組み合わせとして正しいものはどれか。
  3. 2次元配列の1行の大きさが4096バイト(2の累乗)のとき、列方向に要素をたどると、キャッシュの容量に余裕があってもミスが多くなることがある。その対策として効果があるものはどれか。
  4. 主記憶のDRAMへのアクセスにかかる時間は、L1キャッシュのヒット時間のおよそ何倍か。(一般的なPCやサーバーのCPUの場合)
  5. キャッシュの各ラインに付けられる有効ビット(valid bit)の役割として正しいものはどれか。

この分野の比較

  • ライトスルーとライトバックの違い：キャッシュの書き込み方式を比較ライトスルーとライトバックのキャッシュを、書き込みの方式・メモリのトラフィック・速度・整合性・複雑さ・追い出しのコスト・用途の観点で表にして比較します。
  • ダイレクトマップ・セットアソシアティブ・フルアソシアティブの違い：キャッシュの方式を比較ダイレクトマップ、セットアソシアティブ、フルアソシアティブのキャッシュを、ブロックを置ける場所・タグの比較・速度・コスト・競合ミス・用途の観点で表にして比較します。
