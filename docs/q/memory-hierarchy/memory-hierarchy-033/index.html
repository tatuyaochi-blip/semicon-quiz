メモリ階層と性能

L1キャッシュの下にL2キャッシュを置く多段のキャッシュで、L2キャッシュの主な役割はどれか。

  1. AL1キャッシュより速いヒット時間で、L1のミスそのものをなくす
  2. BL1より大きく遅いが、L1のミスペナルティを小さくする
  3. C主記憶の代わりにプログラムの全データを常に保持する
答えと解説を見る

正解：B. L1より大きく遅いが、L1のミスペナルティを小さくする

L1は速さを優先して小さく作るため、ミスがある程度起こります。L2はL1より大きく、ヒット時間は長いものの主記憶よりはずっと速いので、L1でミスしたアクセスの多くをL2で受け止め、L1のミスペナルティを主記憶まで行くより大きく減らします。L1より速いわけではなく、L1のミスをなくすこともできません。容量は主記憶よりはるかに小さく、全データを保持することもできません。

  • A. L2はL1より遅く、L1のミスをなくすことはできません。
  • B. 正しい。L1のミスの多くを受け止めて、ミスペナルティを小さくします。
  • C. 容量は主記憶よりはるかに小さく、全データは入りません。
