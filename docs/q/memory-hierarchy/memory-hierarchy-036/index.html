メモリ階層と性能

8ウェイ・セットアソシアティブ方式のキャッシュで、1回のアクセスのたびに並列に比べるタグの数はいくつか。

  1. Aキャッシュ全体のライン数と同じ数
  2. B8個
  3. C1個
答えと解説を見る

正解：B. 8個

セットアソシアティブ方式では、まずアドレスのインデックスで1つのセットを選び、そのセットにある全ウェイのタグを並列に比べます。8ウェイなら1セットに8ラインがあるので、比べるタグは8個で、そのための比較器も8個必要です。キャッシュ全体のライン数だけ比べるのはフルアソシアティブ方式、1個だけ比べるのはダイレクトマップ方式です。ウェイを増やすと比較器と消費電力が増えるため、L1の連想度は控えめにされることが多くあります。

  • A. 全ラインと比べるのはフルアソシアティブ方式です。
  • B. 正しい。選んだセットの8ウェイ分のタグを比べます。
  • C. 1個だけ比べるのはダイレクトマップ方式です。
