エッチング

GaNのドライエッチングに一般的に使われるガスはどれか。

  1. A塩素系ガス(Cl2、BCl3など)
  2. B酸素だけ
  3. C水蒸気
答えと解説を見る

正解：A. 塩素系ガス(Cl2、BCl3など)

GaNは化学的に安定でエッチングしにくい材料ですが、塩素系のガスのプラズマを使うと、揮発性の塩化物にして除去できます。ICPなどの高密度プラズマ装置で、LEDやパワーデバイスのメサ構造などを加工します。

エッチングのほかの問題

  1. Cu配線をドライエッチングで直接加工するのが難しい理由として正しいものはどれか。
  2. ゲートのエッチングで、下地の絶縁膜との境界付近のパターン側面が横にえぐれる現象を何と呼ぶか。
  3. ドライエッチングのあとに、パターンの側壁などに残った反応生成物(ポリマー)を除去する理由として正しいものはどれか。
  4. 酸化膜をエッチングして、下にある窒化膜のところで止めたい場合に必要なものはどれか。
  5. 半導体製造におけるエッチングの役割として正しいものはどれか。
