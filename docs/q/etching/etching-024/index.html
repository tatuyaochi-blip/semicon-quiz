エッチング

エッチング装置の内壁の状態が変わると加工結果が変動するため、製品の前にダミーウエハを処理して状態を安定させることを何と呼ぶか。

  1. Aシーズニング
  2. Bアッシング
  3. Cデポジション
答えと解説を見る

正解：A. シーズニング

エッチング装置の内壁には反応生成物が付着し、その状態によってプラズマ中のラジカルの量などが変わります。クリーニングの直後などに、ダミーウエハを処理して内壁の状態を整え、加工結果を安定させる作業をシーズニングといいます。

  3. Cu配線をドライエッチングで直接加工するのが難しい理由として正しいものはどれか。
  4. ゲートのエッチングで、下地の絶縁膜との境界付近のパターン側面が横にえぐれる現象を何と呼ぶか。
  5. ドライエッチングのあとに、パターンの側壁などに残った反応生成物(ポリマー)を除去する理由として正しいものはどれか。
