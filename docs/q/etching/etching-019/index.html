エッチング

プラズマで生成したラジカルだけをウエハに供給するダウンフロー型エッチングの特徴として正しいものはどれか。

  1. Aイオン衝撃が強いため、異方性が非常に高い
  2. Bイオン衝撃がほとんどないため、ダメージが少なく等方的にエッチングできる
  3. C薬液を使ってエッチングする
答えと解説を見る

正解：B. イオン衝撃がほとんどないため、ダメージが少なく等方的にエッチングできる

ダウンフロー型では、プラズマを発生させる場所とウエハを離し、寿命の長い中性のラジカルだけをウエハに届けます。イオンが当たらないためダメージが少なく、等方的にエッチングできます。レジストの除去や、ダメージを嫌う工程での膜の除去などに使われます。

エッチングのほかの問題

  1. 高アスペクト比のエッチングで見られる形状異常の例として正しいものはどれか。
  2. 酸化膜のエッチング速度が100 nm/min、マスクの削れる速度が20 nm/minのとき、マスクに対する選択比はいくらか。
  3. SiO2のウェットエッチングに使われる、フッ酸をフッ化アンモニウムで緩衝した液はどれか。
  4. ウエハを極低温に冷やしてエッチングする方法が、高アスペクト比の加工で注目されている理由として正しいものはどれか。
  5. エッチング装置の内壁の状態が変わると加工結果が変動するため、製品の前にダミーウエハを処理して状態を安定させることを何と呼ぶか。
