エッチング

ドライエッチングで異方性が得られる仕組みの一つとして正しいものはどれか。

  1. A側壁に堆積した保護膜が横方向のエッチングを防ぎ、底面ではイオンの衝撃で保護膜が除去されてエッチングが進む
  2. B側壁だけが速く溶ける
  3. C薬液がすべての方向に均等に反応する
答えと解説を見る

正解：A. 側壁に堆積した保護膜が横方向のエッチングを防ぎ、底面ではイオンの衝撃で保護膜が除去されてエッチングが進む

ドライエッチングでは、反応生成物やガスに由来する膜が側壁に付着して横方向のエッチングを防ぎます。一方、底面には垂直にイオンが当たるため保護膜が取り除かれ、エッチングが進みます。この仕組みにより、垂直な形状が得られます。

エッチングのほかの問題

  1. シリコン窒化膜のウェットエッチングに一般的に使われる薬液はどれか。
  2. プラズマエッチング中に、長い配線などのアンテナとなる導体が電荷を集め、つながっているゲート酸化膜を損傷させる現象を何と呼ぶか。
  3. 水酸化カリウム(KOH)水溶液によるシリコンのウェットエッチングの特徴として正しいものはどれか。
  4. 誘導結合プラズマ(ICP)型エッチング装置の特徴として正しいものはどれか。
  5. ウエハ面内でのエッチング速度のばらつきの小ささを表す指標はどれか。
