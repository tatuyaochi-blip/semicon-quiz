エッチング

ドライエッチングの終点検出によく使われる方法はどれか。

  1. Aウエハの重さを量る
  2. Bプラズマの発光スペクトルの変化を監視する
  3. Cエッチング後に目視で確認する
答えと解説を見る

正解：B. プラズマの発光スペクトルの変化を監視する

エッチングしている膜がなくなって下地が出てくると、プラズマ中の反応生成物が変わり、特定の波長の発光強度が変化します。この発光スペクトルの変化を監視することで、エッチングの終点をリアルタイムで検出できます(発光分光法:OES)。
