エッチング

原子層エッチング(ALE)の特徴として正しいものはどれか。

  1. A1回の処理で数µmを高速にエッチングする
  2. B表面の改質と除去を交互に繰り返し、原子層レベルでエッチング量を制御する
  3. C薬液を使った等方的なウェットエッチングである
答えと解説を見る

正解：B. 表面の改質と除去を交互に繰り返し、原子層レベルでエッチング量を制御する

ALEは、まず表面の1層だけを反応させて改質し、次にその層だけを取り除く、という自己制限的な工程を繰り返します。1サイクルで削れる量が一定なため、原子層レベルで精密に制御でき、表面へのダメージも小さくなります。ALDのエッチング版といえる技術です。

エッチングのほかの問題

  1. ドライエッチングで異方性が得られる仕組みの一つとして正しいものはどれか。
  2. シリコン窒化膜のウェットエッチングに一般的に使われる薬液はどれか。
  3. プラズマエッチング中に、長い配線などのアンテナとなる導体が電荷を集め、つながっているゲート酸化膜を損傷させる現象を何と呼ぶか。
  4. 水酸化カリウム(KOH)水溶液によるシリコンのウェットエッチングの特徴として正しいものはどれか。
  5. 誘導結合プラズマ(ICP)型エッチング装置の特徴として正しいものはどれか。
