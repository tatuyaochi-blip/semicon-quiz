エッチング

高アスペクト比のパターンのプラズマエッチングで、電子が側壁で遮られてパターンの上部に負の電荷がたまり、正イオンが底で曲げられて形状異常やダメージを起こす現象はどれか。

  1. A電子シェーディング効果
  2. Bトンネル効果
  3. Cピエゾ効果
答えと解説を見る

正解：A. 電子シェーディング効果

電子は方向がばらばらに飛ぶため狭いパターンの奥に入りにくく、パターンの上部の側壁に負の電荷がたまります。一方、イオンは垂直に入って底を正に帯電させます。この電荷の偏りで後から来るイオンが曲げられ、ノッチングやゲート絶縁膜のダメージの原因になります。

  • A. 正しい。電子が遮られて帯電の偏りが生じる現象です。
  • B. トンネル効果は粒子が障壁を通り抜ける量子力学的な現象です。
  • C. ピエゾ効果は圧電体の力と電荷の関係です。

エッチングのほかの問題

  2. プラズマエッチング装置の内壁や部品の表面に、酸化イットリウム(Y2O3)などのコーティングが使われる主な理由はどれか。
  3. プラズマエッチング装置で、ウエハの外周を囲むフォーカスリングの主な役割はどれか。
  4. 異方性エッチングの説明として正しいものはどれか。
  5. エッチングにおける「選択比」の説明として正しいものはどれか。
