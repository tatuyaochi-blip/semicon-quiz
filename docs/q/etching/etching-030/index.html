エッチング

酸化膜をエッチングして、下にある窒化膜のところで止めたい場合に必要なものはどれか。

  1. A低い選択比
  2. B等方性のエッチング
  3. C窒化膜に対する酸化膜の高いエッチング選択比
答えと解説を見る

正解：C. 窒化膜に対する酸化膜の高いエッチング選択比

窒化膜で止めたい場合は、酸化膜は速くエッチングし、窒化膜はほとんどエッチングしない条件が必要です。フルオロカーボン系ガスで炭素の多い条件を使うなどして、窒化膜に対する酸化膜の選択比を高めます。自己整合コンタクトの形成などで重要になります。

エッチングのほかの問題

  1. 半導体製造におけるエッチングの役割として正しいものはどれか。
  2. ドライエッチングで使われる「プラズマ」の説明として正しいものはどれか。
  3. エッチング速度が100 nm/minの条件で3分間エッチングしたとき、削れる膜の厚さはいくらか。
  4. ウェットエッチングで、薬液の温度を上げたときのエッチング速度の変化として一般的なものはどれか。
  5. 容量結合型などのプラズマ装置で、ウエハ側の電極が自然に負の直流電位をもち、イオンをウエハに向けて加速する現象を何と呼ぶか。
