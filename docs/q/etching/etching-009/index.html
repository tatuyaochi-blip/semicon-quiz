エッチング

酸素プラズマなどを使ってフォトレジストを灰化して除去する工程を何と呼ぶか。

  1. Aアッシング
  2. Bアニール
  3. Cダイシング
答えと解説を見る

正解：A. アッシング

アッシングは、酸素プラズマなどでレジストの有機物を酸化させ、CO2やH2Oとして除去する工程です。エッチングやイオン注入のマスクとして使い終わったレジストを取り除くために行い、その後に薬液洗浄で残渣を除去します。

エッチングのほかの問題

  1. 原子層エッチング(ALE)の特徴として正しいものはどれか。
  2. ドライエッチングで異方性が得られる仕組みの一つとして正しいものはどれか。
  3. シリコン窒化膜のウェットエッチングに一般的に使われる薬液はどれか。
  4. プラズマエッチング中に、長い配線などのアンテナとなる導体が電荷を集め、つながっているゲート酸化膜を損傷させる現象を何と呼ぶか。
  5. 水酸化カリウム(KOH)水溶液によるシリコンのウェットエッチングの特徴として正しいものはどれか。
