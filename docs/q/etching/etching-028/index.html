エッチング

ゲートのエッチングで、下地の絶縁膜との境界付近のパターン側面が横にえぐれる現象を何と呼ぶか。

  1. Aボーイング
  2. Bノッチング
  3. Cディッシング
答えと解説を見る

正解：B. ノッチング

ノッチングは、エッチングが下地の絶縁膜に達したあと、絶縁膜の表面にイオンの正電荷がたまり、後から来るイオンの軌道が横に曲げられて、パターンの根元が横にえぐれる現象です。特にパターンの端の部分で起こりやすく、ゲート長が局所的に変わってトランジスタの特性がばらつきます。パルスプラズマや低い周波数のバイアスで帯電を抑えたり、オーバーエッチの条件を工夫したりして対策します。

エッチングのほかの問題

  1. ドライエッチングのあとに、パターンの側壁などに残った反応生成物(ポリマー)を除去する理由として正しいものはどれか。
  2. 酸化膜をエッチングして、下にある窒化膜のところで止めたい場合に必要なものはどれか。
  3. 半導体製造におけるエッチングの役割として正しいものはどれか。
  4. ドライエッチングで使われる「プラズマ」の説明として正しいものはどれか。
  5. エッチング速度が100 nm/minの条件で3分間エッチングしたとき、削れる膜の厚さはいくらか。
