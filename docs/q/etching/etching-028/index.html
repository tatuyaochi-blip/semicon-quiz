エッチング

ゲートのエッチングで、下地の絶縁膜との境界付近のパターン側面が横にえぐれる現象を何と呼ぶか。

  1. Aボーイング
  2. Bノッチング
  3. Cディッシング
答えと解説を見る

正解：B. ノッチング

ノッチングは、エッチングが下地の絶縁膜に達したあと、絶縁膜の表面に電荷がたまり、イオンの軌道が曲げられてパターンの根元が横にえぐれる現象です。ゲート長が局所的に変わってしまうため、パルスプラズマなどで帯電を抑えて対策します。

エッチングのほかの問題

  1. ドライエッチングのあとに、パターンの側壁などに残った反応生成物(ポリマー)を除去する理由として正しいものはどれか。
  2. 酸化膜をエッチングして、下にある窒化膜のところで止めたい場合に必要なものはどれか。
  3. 異方性エッチングの説明として正しいものはどれか。
  4. エッチングにおける「選択比」の説明として正しいものはどれか。
  5. ウェットエッチングの一般的な特徴として正しいものはどれか。
