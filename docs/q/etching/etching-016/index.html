エッチング

ウエハ面内でのエッチング速度のばらつきの小ささを表す指標はどれか。

  1. A選択比
  2. B均一性(ユニフォーミティ)
  3. Cアスペクト比
答えと解説を見る

正解：B. 均一性(ユニフォーミティ)

均一性は、ウエハの中心と外周などでエッチング速度や加工形状がどれだけそろっているかを表します。均一性が悪いと、場所によって削り残しや削りすぎが起こるため、プラズマの分布やガスの流れ、ウエハ温度などを調整して改善します。

この分野を解く 分野ページへ

エッチングのほかの問題

  1. エッチングの終点を検出したあと、ウエハ全面で膜を確実に除去するために、さらに一定時間エッチングを続けることを何と呼ぶか。
  2. 深い穴の加工などで、フォトレジストだけではマスクとして持たない場合に使われる、窒化膜や炭素膜などのマスクを何と呼ぶか。
  3. プラズマで生成したラジカルだけをウエハに供給するダウンフロー型エッチングの特徴として正しいものはどれか。
  4. 高アスペクト比のエッチングで見られる形状異常の例として正しいものはどれか。
  5. 酸化膜のエッチング速度が100 nm/min、マスクの削れる速度が20 nm/minのとき、マスクに対する選択比はいくらか。
