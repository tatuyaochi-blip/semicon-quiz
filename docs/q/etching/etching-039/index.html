エッチング

ゲート電極のエッチングで、下地の薄いゲート絶縁膜を残すために一般的に行われる工夫はどれか。

  1. A最初から最後まで同じ強い条件でエッチングする
  2. B途中まではエッチング速度の速い条件で削り、下地に近づいたら下地との選択比が高い条件に切り替える
  3. C下地が見えた後もしばらく強い条件で削り続ける
答えと解説を見る

正解：B. 途中まではエッチング速度の速い条件で削り、下地に近づいたら下地との選択比が高い条件に切り替える

ゲートのエッチングでは、まず形状を決める速い条件(メインエッチ)で大部分を削り、終点を検出したら、下の数nmの絶縁膜をほとんど削らない高選択比の条件(オーバーエッチ)に切り替えて段差の残りを取り除きます。条件を数段階に分けることで、垂直な形状と下地の保護を両立できます。ゲート絶縁膜を突き破ると、その下のシリコンが削られてトランジスタが不良になります。

  • A. 強い条件のままでは、薄い下地まで削れてしまいます。
  • B. 正しい。条件を段階的に切り替えて下地を残します。
  • C. 強い条件で削り続けると下地が突き破られます。

エッチングのほかの問題

  1. 厚さ1 µmの膜を、完全に等方的なウェットエッチングでちょうど下地まで削ったとき、マスクの端から横方向に削れる量(アンダーカット)のおよその大きさはどれか。
  2. エッチングでできた穴や溝の側壁が垂直からどれだけ傾いているかを表す指標はどれか。
  3. フッ素系ガスによるエッチングに酸素を少し加えたときの効果として一般的に正しいものはどれか。
  4. エッチングに使う一般的なプラズマの中で、イオンとラジカルの数の関係として正しいものはどれか。
  5. プラズマに細い電極を差し込み、電圧を変えたときの電流からプラズマの電子温度や密度を測る方法はどれか。
