エッチング

Cu配線をドライエッチングで直接加工するのが難しい理由として正しいものはどれか。

  1. ACuは電気を通さないため
  2. BCuが柔らかすぎるため
  3. CCuのハロゲン化物は揮発しにくく、反応生成物を取り除けないため
答えと解説を見る

正解：C. Cuのハロゲン化物は揮発しにくく、反応生成物を取り除けないため

アルミニウムは塩素と反応して揮発性の塩化アルミニウムになるためドライエッチングできますが、銅の塩化物などは揮発しにくく、表面に残ってしまいます。そのため、Cu配線はエッチングを使わずに、溝に埋め込んでCMPで削るダマシン法でつくられます。

この分野を解く 分野ページへ

エッチングのほかの問題

  1. ゲートのエッチングで、下地の絶縁膜との境界付近のパターン側面が横にえぐれる現象を何と呼ぶか。
  2. ドライエッチングのあとに、パターンの側壁などに残った反応生成物(ポリマー)を除去する理由として正しいものはどれか。
  3. 酸化膜をエッチングして、下にある窒化膜のところで止めたい場合に必要なものはどれか。
  4. 異方性エッチングの説明として正しいものはどれか。
  5. エッチングにおける「選択比」の説明として正しいものはどれか。
