エッチング

深い穴の加工などで、フォトレジストだけではマスクとして持たない場合に使われる、窒化膜や炭素膜などのマスクを何と呼ぶか。

  1. Aペリクル
  2. B位相シフトマスク
  3. Cハードマスク
答えと解説を見る

正解：C. ハードマスク

深い加工ではレジストが途中でなくなってしまうため、まずレジストのパターンを窒化膜、酸化膜、アモルファスカーボン膜などに転写し、それをマスクとして本来の膜をエッチングします。こうした無機膜などのマスクをハードマスクといいます。

エッチングのほかの問題

  1. プラズマで生成したラジカルだけをウエハに供給するダウンフロー型エッチングの特徴として正しいものはどれか。
  2. 高アスペクト比のエッチングで見られる形状異常の例として正しいものはどれか。
  3. 酸化膜のエッチング速度が100 nm/min、マスクの削れる速度が20 nm/minのとき、マスクに対する選択比はいくらか。
  4. SiO2のウェットエッチングに使われる、フッ酸をフッ化アンモニウムで緩衝した液はどれか。
  5. ウエハを極低温に冷やしてエッチングする方法が、高アスペクト比の加工で注目されている理由として正しいものはどれか。
