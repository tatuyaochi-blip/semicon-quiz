エッチング

ウエハを極低温に冷やしてエッチングする方法が、高アスペクト比の加工で注目されている理由として正しいものはどれか。

  1. Aエッチング速度が0になるため
  2. B側壁での反応が抑えられ、速く垂直な深い加工がしやすいため
  3. Cプラズマが不要になるため
答えと解説を見る

正解：B. 側壁での反応が抑えられ、速く垂直な深い加工がしやすいため

ウエハを極低温に冷やすと、側壁ではラジカルによる自発的な化学反応が抑えられたり、保護膜が形成されやすくなったりする一方、イオンが当たる底面ではエッチングが進みます。そのため、深く垂直な穴を速く加工でき、3D NANDのメモリホールの加工などで注目されています。

エッチングのほかの問題

  1. エッチング装置の内壁の状態が変わると加工結果が変動するため、製品の前にダミーウエハを処理して状態を安定させることを何と呼ぶか。
  2. プラズマの高周波電力をオン・オフしながらエッチングするパルスプラズマの利点として正しいものはどれか。
  3. GaNのドライエッチングに一般的に使われるガスはどれか。
  4. Cu配線をドライエッチングで直接加工するのが難しい理由として正しいものはどれか。
  5. ゲートのエッチングで、下地の絶縁膜との境界付近のパターン側面が横にえぐれる現象を何と呼ぶか。
