エッチング

パターンが細く深くなるほどエッチング速度が低下する現象を何と呼ぶか。

  1. Aオートドーピング
  2. Bアスペクト比依存エッチング(ARDE、マイクロローディング効果)
  3. Cディッシング
答えと解説を見る

正解：B. アスペクト比依存エッチング(ARDE、マイクロローディング効果)

細く深い穴の底にはイオンやラジカルが届きにくく、反応生成物も排出されにくいため、アスペクト比が大きいほどエッチング速度が遅くなります。この現象はARDEやマイクロローディング効果と呼ばれ、パターンの寸法によって深さがそろわない原因になります。
