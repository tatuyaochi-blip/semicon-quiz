エッチング

ドライエッチングのあとに、パターンの側壁などに残った反応生成物(ポリマー)を除去する理由として正しいものはどれか。

  1. A次の工程での不良や、電気的な特性の劣化を防ぐため
  2. Bウエハの色を変えるため
  3. Cウエハを重くするため
答えと解説を見る

正解：A. 次の工程での不良や、電気的な特性の劣化を防ぐため

エッチングの際に側壁に付いた保護膜などのポリマーが残っていると、次の成膜の密着性が悪くなったり、コンタクトの抵抗が上がったり、塩素を含む残渣がアルミ配線を腐食させたりします。そのため、アッシングや有機系・フッ素系の薬液による洗浄で丁寧に除去します。ただし先端の配線では、薬液がLow-k膜や細い金属を傷めないよう、除去の強さと材料へのダメージのバランスが重要です。

エッチングのほかの問題

  1. 酸化膜をエッチングして、下にある窒化膜のところで止めたい場合に必要なものはどれか。
  2. 半導体製造におけるエッチングの役割として正しいものはどれか。
  3. ドライエッチングで使われる「プラズマ」の説明として正しいものはどれか。
  4. エッチング速度が100 nm/minの条件で3分間エッチングしたとき、削れる膜の厚さはいくらか。
  5. ウェットエッチングで、薬液の温度を上げたときのエッチング速度の変化として一般的なものはどれか。

この分野の比較

  • ウェットエッチングとドライエッチングの違い：方向性・選択比・用途を比較ウェットエッチングとドライエッチングを、媒体・方向性・選択比・微細化・スループット・ダメージ・コスト・使われる工程の観点で表にして比較します。
  • RIE・ICP-RIE・ALEの違い：圧力・プラズマ密度・イオンエネルギー・精度を比較容量結合型のRIE、ICP-RIE、原子層エッチング(ALE)を、プラズマの作り方・圧力・プラズマ密度・イオンエネルギーの制御・エッチング速度・ダメージ・深さの精度・用途の観点で表にして比較し、使い分けも解説します。
  • CCPとICPの違い：プラズマの作り方・密度・イオンエネルギー・用途を比較容量結合プラズマ(CCP)と誘導結合プラズマ(ICP)を、電極とコイル・プラズマ密度・イオンエネルギーの独立制御・圧力・エッチングの用途(酸化膜とSi・金属)・プラズマCVDなど成膜への応用の観点で表にして比較します。
