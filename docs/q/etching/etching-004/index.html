エッチング

反応性イオンエッチング(RIE)の説明として正しいものはどれか。

  1. A反応性ガスのプラズマ中で、化学反応とイオンの衝撃を組み合わせてエッチングする
  2. B薬液にウエハを浸してエッチングする
  3. C研磨パッドでウエハ表面を削る
答えと解説を見る

正解：A. 反応性ガスのプラズマ中で、化学反応とイオンの衝撃を組み合わせてエッチングする

RIEは、反応性ガスのプラズマでつくったラジカルによる化学反応と、電界で加速したイオンの衝撃を組み合わせたドライエッチングです。イオンが垂直に入射するため、縦方向のエッチングが進みやすく、異方性の高い加工ができます。
