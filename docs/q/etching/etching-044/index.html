エッチング

プラズマに細い電極を差し込み、電圧を変えたときの電流からプラズマの電子温度や密度を測る方法はどれか。

  1. A四探針法
  2. BX線回折
  3. Cラングミュアプローブ法
答えと解説を見る

正解：C. ラングミュアプローブ法

ラングミュアプローブは、プラズマ中に小さな電極(プローブ)を入れ、加える電圧を変えながら流れる電流を測ります。その電流-電圧特性から、電子温度、電子密度、プラズマ電位などを求められ、プラズマの状態の評価に使われます。

  • A. 四探針法は膜やウエハの抵抗率を測る方法です。
  • B. X線回折は結晶構造を調べる方法です。
  • C. 正しい。プローブの電流-電圧特性からプラズマを評価します。

エッチングのほかの問題

  1. ドライエッチングで、溝の底の側壁際が中央より深く掘れて細い溝ができる形状異常を何と呼ぶか。
  2. シリコンにXeF2のガスとアルゴンイオンのビームを同時に当てると、それぞれ単独の場合の和よりはるかに速くエッチングが進む。このことが示すドライエッチングの性質はどれか。
  3. 高アスペクト比のパターンのプラズマエッチングで、電子が側壁で遮られてパターンの上部に負の電荷がたまり、正イオンが底で曲げられて形状異常やダメージを起こす現象はどれか。
  4. プラズマで生成したイオンを中性化してからウエハに当て、帯電や紫外線によるダメージを抑えて加工する研究段階のエッチング方法はどれか。
  5. プラズマエッチング装置の内壁や部品の表面に、酸化イットリウム(Y2O3)などのコーティングが使われる主な理由はどれか。
