エッチング

微細なパターンを深く加工するため、下から有機膜(炭素膜)、シリコンを含む中間膜、レジストの3層を重ねて使うマスクの方式を何と呼ぶか。

  1. A三層レジスト(トライレイヤー)プロセス
  2. Bダマシンプロセス
  3. CLOCOSプロセス
答えと解説を見る

正解：A. 三層レジスト(トライレイヤー)プロセス

三層レジストでは、薄いレジストのパターンをまずシリコンを含む中間膜に写し、それをマスクにして厚い有機膜を酸素系のプラズマでエッチングします。異なる材料の高い選択比を順につなぐことで、薄いレジストでも厚く丈夫なマスクをつくれます。

  • A. 正しい。3層を重ねてパターンを順に写し取る方式です。
  • B. ダマシンは溝に金属を埋め込んで配線をつくる方式です。
  • C. LOCOSは選択酸化による素子分離の方式です。
この分野を解く 分野ページへ

エッチングのほかの問題

  1. MEMSの犠牲層除去などで、プラズマを使わずにシリコンを等方的にエッチングできる気体はどれか。
  2. 露光でつくったレジストのパターンを、プラズマで少しずつ細らせて、露光の限界より細い線をつくる手法はどれか。
  3. ゲート電極のエッチングで、下地の薄いゲート絶縁膜を残すために一般的に行われる工夫はどれか。
  4. 厚さ1 µmの膜を、完全に等方的なウェットエッチングでちょうど下地まで削ったとき、マスクの端から横方向に削れる量(アンダーカット)のおよその大きさはどれか。
  5. エッチングでできた穴や溝の側壁が垂直からどれだけ傾いているかを表す指標はどれか。
