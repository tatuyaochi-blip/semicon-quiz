エッチング

ポリシリコンゲートのドライエッチングによく使われるガスはどれか。

  1. A窒素(N2)
  2. Bヘリウム(He)
  3. C塩素(Cl2)や臭化水素(HBr)などのハロゲン系ガス
答えと解説を見る

正解：C. 塩素(Cl2)や臭化水素(HBr)などのハロゲン系ガス

ポリシリコンのエッチングには、塩素や臭化水素などのハロゲン系ガスがよく使われます。シリコンと反応して揮発性のSiCl4やSiBr4になる一方、酸化膜とはほとんど反応しないため、下地の薄いゲート酸化膜に対して100以上の高い選択比をとれます。HBrは側壁に保護膜をつくりやすく、垂直な形状を得やすい利点もあります。酸素を少し加えて保護膜の量を調整します。

エッチングのほかの問題

  1. 酸素プラズマなどを使ってフォトレジストを灰化して除去する工程を何と呼ぶか。
  2. 原子層エッチング(ALE)の特徴として正しいものはどれか。
  3. ドライエッチングで異方性が得られる仕組みの一つとして正しいものはどれか。
  4. シリコン窒化膜のウェットエッチングに一般的に使われる薬液はどれか。
  5. プラズマエッチング中に、長い配線などのアンテナとなる導体が電荷を集め、つながっているゲート酸化膜を損傷させる現象を何と呼ぶか。
