エッチング

シリコン窒化膜のウェットエッチングに一般的に使われる薬液はどれか。

  1. A純水
  2. B熱リン酸
  3. Cアンモニア水
答えと解説を見る

正解：B. 熱リン酸

シリコン窒化膜は、約160 ℃に加熱した濃いリン酸で、酸化膜に対して数十〜100以上の高い選択比でエッチングできます。LOCOSやSTIの形成後にマスクとして使った窒化膜を除去する工程や、3D NANDで酸化膜と窒化膜を交互に積んだ層から窒化膜だけを除いてワード線の金属に置き換える工程で使われます。液中のシリコン濃度で選択比が変わるため厳密な管理が必要です。

エッチングのほかの問題

  1. プラズマエッチング中に、長い配線などのアンテナとなる導体が電荷を集め、つながっているゲート酸化膜を損傷させる現象を何と呼ぶか。
  2. 水酸化カリウム(KOH)水溶液によるシリコンのウェットエッチングの特徴として正しいものはどれか。
  3. 誘導結合プラズマ(ICP)型エッチング装置の特徴として正しいものはどれか。
  4. ウエハ面内でのエッチング速度のばらつきの小ささを表す指標はどれか。
  5. エッチングの終点を検出したあと、ウエハ全面で膜を確実に除去するために、さらに一定時間エッチングを続けることを何と呼ぶか。
