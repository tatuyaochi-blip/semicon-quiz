エッチング

SiO2のウェットエッチングに使われる、フッ酸をフッ化アンモニウムで緩衝した液はどれか。

  1. ASPM
  2. B熱リン酸
  3. Cバッファードフッ酸(BHF)
答えと解説を見る

正解：C. バッファードフッ酸(BHF)

バッファードフッ酸は、フッ酸にフッ化アンモニウムを加えてpHを安定させた液で、酸化膜を溶かす主な成分(HF2⁻)の濃度が液の消耗によって変わりにくく、エッチング速度が安定し、レジストもはがれにくいという特徴があります。熱酸化膜で毎分数十〜100 nm程度の速さです。酸化膜のパターニングや、自然酸化膜の除去、膜質の評価などに使われてきました。

エッチングのほかの問題

  1. ウエハを極低温に冷やしてエッチングする方法が、高アスペクト比の加工で注目されている理由として正しいものはどれか。
  2. エッチング装置の内壁の状態が変わると加工結果が変動するため、製品の前にダミーウエハを処理して状態を安定させることを何と呼ぶか。
  3. プラズマの高周波電力をオン・オフしながらエッチングするパルスプラズマの利点として正しいものはどれか。
  4. GaNのドライエッチングに一般的に使われるガスはどれか。
  5. Cu配線をドライエッチングで直接加工するのが難しい理由として正しいものはどれか。
