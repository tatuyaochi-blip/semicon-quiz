リソグラフィ

露光量とフォーカスを変えても、パターンの寸法が許容範囲内に収まる条件の範囲を何と呼ぶか。

  1. Aプロセスウィンドウ
  2. Bオーバーレイ
  3. Cラインエッジラフネス
答えと解説を見る

正解：A. プロセスウィンドウ

プロセスウィンドウは、露光量とフォーカスのずれを許容できる範囲を示します。量産では、装置のばらつきやウエハの凹凸によって露光量やフォーカスが変動するため、プロセスウィンドウが広いほど安定して製造できます。OPCや照明条件の最適化は、これを広げるために行われます。
