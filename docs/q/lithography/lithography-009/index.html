リソグラフィ

リソグラフィにおける重ね合わせ(オーバーレイ)精度とは何か。

  1. A塗布したレジストの膜厚の均一性
  2. B前の工程でつくったパターンに対して、新しいパターンをどれだけ正確な位置に重ねられるか
  3. C露光量のばらつき
答えと解説を見る

正解：B. 前の工程でつくったパターンに対して、新しいパターンをどれだけ正確な位置に重ねられるか

LSIは何十層ものパターンを重ねてつくるため、各層を前の層に正確に位置合わせする必要があります。そのずれの小ささが重ね合わせ精度です。微細化が進むほど許されるずれは小さくなり、ナノメートル単位の精度が求められています。

リソグラフィのほかの問題

  1. 化学増幅型レジストの特徴として正しいものはどれか。
  2. 現在の露光装置(スキャナー)で一般的な、マスクのパターンをウエハ上に投影するときの縮小倍率はどれか。
  3. スキャナー型露光装置の特徴として正しいものはどれか。
  4. EUV露光で使われるマスクの特徴として正しいものはどれか。
  5. リソグラフィの一般的な工程順として正しいものはどれか。
