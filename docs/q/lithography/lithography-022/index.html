リソグラフィ

EUV露光で問題になる確率的なゆらぎ(ストカスティクス)の主な原因として正しいものはどれか。

  1. AEUV光の波長がArFより長いため
  2. BEUV露光ではレンズを使うため
  3. CEUV光は光子1個のエネルギーが大きく、同じ露光量でも光子の数が少ないため
答えと解説を見る

正解：C. EUV光は光子1個のエネルギーが大きく、同じ露光量でも光子の数が少ないため

EUV光(13.5 nm)の光子1個のエネルギーはArF光(193 nm)の約14倍あるため、同じ露光量でも当たる光子の数は大幅に少なくなります。微小な領域では光子の数の統計的なばらつきが大きくなり、パターンの欠け、つながり、LERなどの確率的な欠陥の原因になります。
