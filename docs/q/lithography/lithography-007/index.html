リソグラフィ

OPC(光近接効果補正)の説明として正しいものはどれか。

  1. Aレジストを厚く塗って解像度を上げる
  2. Bマスクを洗浄して異物を除去する
  3. Cマスクパターンをあらかじめ補正しておき、転写後の形状のずれを小さくする
答えと解説を見る

正解：C. マスクパターンをあらかじめ補正しておき、転写後の形状のずれを小さくする

解像限界に近いパターンでは、光の回折や干渉によって、線の端が縮んだり角が丸くなったりと、マスクどおりの形が転写されません。OPCでは、この変形を見込んで、マスクのパターンに補助的な図形を加えたり寸法を調整したりします。
