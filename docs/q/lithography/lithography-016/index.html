リソグラフィ

フォトマスク(レチクル)のパターンを描くために主に使われる装置はどれか。

  1. A電子線描画装置
  2. Bステッパー
  3. CCMP装置
答えと解説を見る

正解：A. 電子線描画装置

フォトマスクのパターンは、細く絞ったり長方形に成形したり(可変成形ビーム)した電子線をマスク上のレジストに直接当てて描く電子線描画装置でつくります。マスクなしで非常に細かいパターンを描けますが、一筆書きのため1枚に十数時間かかることもあり、量産ではマスクを使って一括転写します。先端マスクでは、数十万本の電子ビームを同時に使うマルチビーム描画装置で、OPCや曲線のパターンを高速に描いています。

リソグラフィのほかの問題

  1. フォトマスクの上に一定の間隔をあけて張る薄い膜(ペリクル)の役割はどれか。
  2. レジストの下に塗る反射防止膜(BARC)の主な目的はどれか。
  3. 次世代のEUV露光装置として開発された「High-NA EUV」の特徴として正しいものはどれか。
  4. 微細なレジストパターンの側面に生じる、ナノメートル単位の凹凸を表す指標はどれか。
  5. 解像度の式 R = k1 × λ / NA の係数k1についての説明として正しいものはどれか。
