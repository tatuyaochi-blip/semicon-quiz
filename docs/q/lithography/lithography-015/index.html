リソグラフィ

微細なパターンをもつ型(モールド)をレジストに押し付けて、パターンを転写する技術を何と呼ぶか。

  1. A電子線描画
  2. BEUV露光
  3. Cナノインプリントリソグラフィ
答えと解説を見る

正解：C. ナノインプリントリソグラフィ

ナノインプリントリソグラフィは、凹凸のパターンをもつ型をレジストに押し当て、紫外線や熱で固めて形を写し取る技術です。高価な光学系が不要でコストを抑えられる可能性があり、一部のメモリ製造などで実用化が進められています。

リソグラフィのほかの問題

  1. フォトマスク(レチクル)のパターンを描くために主に使われる装置はどれか。
  2. フォトマスクの上に一定の間隔をあけて張る薄い膜(ペリクル)の役割はどれか。
  3. レジストの下に塗る反射防止膜(BARC)の主な目的はどれか。
  4. 次世代のEUV露光装置として開発された「High-NA EUV」の特徴として正しいものはどれか。
  5. 微細なレジストパターンの側面に生じる、ナノメートル単位の凹凸を表す指標はどれか。
