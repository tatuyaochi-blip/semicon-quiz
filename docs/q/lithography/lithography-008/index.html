リソグラフィ

位相シフトマスクの目的として正しいものはどれか。

  1. A隣り合う開口部を通る光の位相を変え、干渉を利用して解像度やコントラストを高める
  2. Bマスクを軽くする
  3. C露光の光量を2倍にする
答えと解説を見る

正解：A. 隣り合う開口部を通る光の位相を変え、干渉を利用して解像度やコントラストを高める

位相シフトマスクは、マスクの一部を通る光の位相を180°ずらし、隣り合うパターンからの光を打ち消し合わせて、パターンの境界のコントラストを高めます。同じ波長でより細かいパターンを解像するための超解像技術の一つです。
