リソグラフィ

マスクを斜めの方向から照明して、細かいパターンの解像度を高める技術はどれか。

  1. AOPC(光近接効果補正)
  2. B変形照明(斜入射照明)
  3. C位相シフトマスク
答えと解説を見る

正解：B. 変形照明(斜入射照明)

細かい周期パターンでは、回折光が大きく広がってレンズに入らなくなります。光を斜めから当てると、0次光と1次回折光の両方をレンズに取り込めるため、より細かいパターンを解像できます。輪帯照明や2極・4極照明などがあり、パターンに合わせて最適化されます。
