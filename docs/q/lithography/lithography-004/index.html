リソグラフィ

ArF液浸露光の説明として正しいものはどれか。

  1. Aウエハ全体を水に沈めて現像する
  2. Bレジストを水で薄めて塗布する
  3. C投影レンズとウエハの間を水で満たし、開口数(NA)を大きくする
答えと解説を見る

正解：C. 投影レンズとウエハの間を水で満たし、開口数(NA)を大きくする

液浸露光では、投影レンズとウエハの間を空気(屈折率約1)より屈折率の高い水(約1.44)で満たします。これにより開口数を1より大きくでき、同じ193 nmの波長でもより細かいパターンを解像できます。

この分野を解く 分野ページへ

リソグラフィのほかの問題

  1. ダブルパターニング(マルチパターニング)の説明として正しいものはどれか。
  2. 露光装置の開口数(NA)を大きくすると、焦点深度(DOF)は一般にどうなるか。
  3. OPC(光近接効果補正)の説明として正しいものはどれか。
  4. 位相シフトマスクの目的として正しいものはどれか。
  5. リソグラフィにおける重ね合わせ(オーバーレイ)精度とは何か。
