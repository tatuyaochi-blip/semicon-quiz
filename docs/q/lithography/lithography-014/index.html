リソグラフィ

リソグラフィの一般的な工程順として正しいものはどれか。

  1. A露光 → レジスト塗布 → 現像 → プリベーク
  2. Bレジスト塗布 → プリベーク → 露光 → 露光後ベーク → 現像
  3. C現像 → 露光 → レジスト塗布 → エッチング
答えと解説を見る

正解：B. レジスト塗布 → プリベーク → 露光 → 露光後ベーク → 現像

まずレジストを塗布し、プリベークで溶剤を飛ばします。次に露光し、化学増幅型レジストでは露光後ベーク(PEB)で反応を進めます。最後に現像してパターンを形成し、必要に応じてポストベークで硬化させます。塗布から現像までは、露光装置とつながったコーター/デベロッパーで行われます。
