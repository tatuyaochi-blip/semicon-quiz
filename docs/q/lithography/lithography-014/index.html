リソグラフィ

リソグラフィの一般的な工程順として正しいものはどれか。

  1. A露光 → レジスト塗布 → 現像 → プリベーク
  2. Bレジスト塗布 → プリベーク → 露光 → 露光後ベーク → 現像
  3. C現像 → 露光 → レジスト塗布 → エッチング
答えと解説を見る

正解：B. レジスト塗布 → プリベーク → 露光 → 露光後ベーク → 現像

まずHMDS処理で密着性を高め、反射防止膜とレジストを塗布し、プリベーク(約100 ℃)で溶剤を飛ばします。次に露光し、化学増幅型レジストでは露光後ベーク(PEB)で反応を進めます。最後にアルカリ現像液で現像してパターンを形成し、必要に応じてポストベークで硬化させます。塗布から現像までは露光装置とつながったコーター/デベロッパーで、温度を±0.1 ℃程度で管理しながら行われます。

リソグラフィのほかの問題

  1. 微細なパターンをもつ型(モールド)をレジストに押し付けて、パターンを転写する技術を何と呼ぶか。
  2. フォトマスク(レチクル)のパターンを描くために主に使われる装置はどれか。
  3. フォトマスクの上に一定の間隔をあけて張る薄い膜(ペリクル)の役割はどれか。
  4. レジストの下に塗る反射防止膜(BARC)の主な目的はどれか。
  5. 次世代のEUV露光装置として開発された「High-NA EUV」の特徴として正しいものはどれか。
