リソグラフィ

フォトマスクをつくるときに使う、石英ガラスの基板に遮光膜などをあらかじめ成膜した材料を何と呼ぶか。

  1. Aマスクブランクス
  2. Bウエハ
  3. Cペレット
答えと解説を見る

正解：A. マスクブランクス

マスクブランクスは、高純度の石英ガラス基板にクロムなどの遮光膜(EUV用では多層膜と吸収膜)を成膜し、レジストを塗った状態の材料です。これに電子ビームでパターンを描き、エッチングしてフォトマスクをつくります。日本企業が大きなシェアをもつ分野です。

  • A. 正しい。マスクの元になる材料です。
  • B. ウエハはデバイスをつくるシリコンの円板です。
  • C. ペレットは粒状に成形した材料です。
この分野を解く 分野ページへ

リソグラフィのほかの問題

  1. マスクを使わず、電子ビームでウエハ上のレジストに直接パターンを描く方式の特徴として正しいものはどれか。
  2. EUV露光装置の光源で、13.5 nmの光をつくる方法として正しいものはどれか。
  3. スピンコートでレジストを塗った後、ウエハの外周部に盛り上がったレジストを溶剤で取り除く処理を何と呼ぶか。
  4. 現在のスキャナー型露光装置で、1回の露光(1ショット)でウエハ上に露光できる最大の領域の大きさとして一般的なものはどれか。
  5. 露光装置の照明の形とマスクのパターンを、計算機で同時に最適化して解像性を高める技術はどれか。
