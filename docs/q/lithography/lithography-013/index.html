リソグラフィ

EUV露光で使われるマスクの特徴として正しいものはどれか。

  1. A光を反射させる多層膜ミラーの上に、吸収体のパターンをつくった反射型マスク
  2. Bガラスを光が透過する透過型マスク
  3. Cマスクは使わない
答えと解説を見る

正解：A. 光を反射させる多層膜ミラーの上に、吸収体のパターンをつくった反射型マスク

EUV光はほとんどの物質に吸収されるため、透過型のマスクは使えません。EUVマスクは、モリブデンとシリコンを交互に積み重ねた多層膜ミラーの上に、光を吸収する材料でパターンをつくった反射型です。

リソグラフィのほかの問題

  1. リソグラフィの一般的な工程順として正しいものはどれか。
  2. 微細なパターンをもつ型(モールド)をレジストに押し付けて、パターンを転写する技術を何と呼ぶか。
  3. フォトマスク(レチクル)のパターンを描くために主に使われる装置はどれか。
  4. フォトマスクの上に一定の間隔をあけて張る薄い膜(ペリクル)の役割はどれか。
  5. レジストの下に塗る反射防止膜(BARC)の主な目的はどれか。
