リソグラフィ

ポジ型フォトレジストの説明として正しいものはどれか。

  1. A露光した部分が現像後に残る
  2. B露光した部分が現像で溶けて除去される
  3. C露光の有無に関係なく現像ですべて溶ける
答えと解説を見る

正解：B. 露光した部分が現像で溶けて除去される

ポジ型レジストは、露光された部分が現像液に溶けやすくなり、現像で除去されます。そのためマスクで光を遮った部分のパターンが残ります。露光した部分が残るのはネガ型レジストです。
