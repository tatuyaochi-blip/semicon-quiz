リソグラフィ

微細なレジストパターンの側面に生じる、ナノメートル単位の凹凸を表す指標はどれか。

  1. A焦点深度(DOF)
  2. B開口数(NA)
  3. Cラインエッジラフネス(LER)
答えと解説を見る

正解：C. ラインエッジラフネス(LER)

LERは、パターンの側面のでこぼこの大きさ(通常は3σで表す)を表す指標で、線幅のばらつきとして表したものはLWRと呼びます。線幅が20 nm前後になると、2〜3 nmの凹凸でも線幅の1割を超え、トランジスタのしきい値や配線抵抗のばらつきの原因になります。レジストの分子の大きさ、酸の拡散、光子数の確率的なゆらぎが原因で、エッチングでの平滑化などで改善します。

リソグラフィのほかの問題

  1. 解像度の式 R = k1 × λ / NA の係数k1についての説明として正しいものはどれか。
  2. EUV露光で問題になる確率的なゆらぎ(ストカスティクス)の主な原因として正しいものはどれか。
  3. EUVマスクで、多層膜の内部に埋もれた欠陥が問題になる理由として正しいものはどれか。
  4. 露光量とフォーカスを変えても、パターンの寸法が許容範囲内に収まる条件の範囲を何と呼ぶか。
  5. LELE(リソ・エッチ・リソ・エッチ)方式のダブルパターニングで、特に厳しく求められるものはどれか。
