リソグラフィ

マスクを使わず、電子ビームでウエハ上のレジストに直接パターンを描く方式の特徴として正しいものはどれか。

  1. A量産で最も高速な方式である
  2. Bマスクが不要で非常に細かいパターンを描けるが、描画に時間がかかるため大量生産には向かない
  3. Cパターンを描くことはできない
答えと解説を見る

正解：B. マスクが不要で非常に細かいパターンを描けるが、描画に時間がかかるため大量生産には向かない

電子ビーム直接描画は、電子ビームを走査してパターンを1つずつ描くため、マスクなしで非常に微細なパターンを形成できます。しかし描画に長い時間がかかるため、大量生産には向かず、研究開発や少量の試作、フォトマスクの製作などに使われます。

  • A. 一筆書きのように描くため、量産の速度は遅くなります。
  • B. 正しい。マスクは不要ですが、描画に時間がかかります。
  • C. 電子ビームでパターンを描くことができます。
