機械学習の基礎

入力層と出力層だけからなる単純パーセプトロン(しきい値で0か1を出力する1つのニューロン)で表せない論理関数はどれか。

  1. AXOR
  2. BAND
  3. COR
答えと解説を見る

正解：A. XOR

単純パーセプトロンは、入力の重み付きの和がしきい値を超えるかどうかで出力を決めるので、入力の空間を1本の直線(超平面)で2つに分けることしかできません。ANDとORは出力が1の点と0の点を直線で分けられますが、XORは (0, 1) と (1, 0) が1、(0, 0) と (1, 1) が0で、1本の直線では分けられません。間に隠れ層を加え、非線形な活性化関数を使う多層パーセプトロンにすると、XORも表せます。

  • A. 正しい。XORは1本の直線で分けられない(線形分離可能でない)ので、単純パーセプトロンでは表せません。
  • B. 例えば、重みを1と1、しきい値を1.5にするとANDを表せます。
  • C. 例えば、重みを1と1、しきい値を0.5にするとORを表せます。

機械学習の基礎のほかの問題

  1. 3クラスの分類で、ソフトマックス関数に入力する値(ロジット)が3、1、0だった。1番目のクラスの出力(確率)は、2番目のクラスの出力の約何倍か。最も近いものはどれか。
  2. 入力が x₁ = 1、x₂ = 2 の小さなニューラルネットワークで、隠れ層の2つのニューロンが h₁ = ReLU(x₁ + x₂ − 1)、h₂ = ReLU(x₁ − 2x₂ + 1)、出力が y = 2h₁ + 3h₂ + 1 である。yの値はどれか。
  3. 正解のクラスに対してモデルが出力した確率をpとするとき、分類の学習で使う交差エントロピー損失 −log p の性質として、適切なものはどれか。
  4. 勾配降下法で、重み w = 2.0 における損失の勾配 ∂L/∂w が0.5、学習率が0.1のとき、1回の更新後の重みはどれか。
  5. y = (2x + 1)² の x = 1 における微分係数 dy/dx を、u = 2x + 1、y = u² として連鎖律で求めるとき、正しい値はどれか。
