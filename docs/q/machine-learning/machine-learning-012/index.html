機械学習の基礎

2クラス分類のモデルを200件のテストデータで評価した混同行列で、真陽性(TP)が45件、偽陽性(FP)が5件、偽陰性(FN)が45件、真陰性(TN)が105件だった。適合率と再現率の組合せとして、正しいものはどれか。

  1. A適合率0.50、再現率0.90
  2. B適合率0.75、再現率0.50
  3. C適合率0.90、再現率0.50
答えと解説を見る

正解：C. 適合率0.90、再現率0.50

適合率(precision)は、陽性と予測したもののうち実際に陽性だった割合で、TP ÷ (TP + FP) = 45 ÷ 50 = 0.90です。再現率(recall)は、実際に陽性のもののうち陽性と予測できた割合で、TP ÷ (TP + FN) = 45 ÷ 90 = 0.50です。このモデルは、陽性と判定したものはほぼ正しいものの、陽性の半分を見逃しています。正解率は (45 + 105) ÷ 200 = 0.75です。

  • A. 適合率と再現率を取り違えています。
  • B. 0.75は正解率(全体のうち正しく予測した割合)で、適合率ではありません。
  • C. 正しい。適合率は45 ÷ 50 = 0.90、再現率は45 ÷ 90 = 0.50です。
