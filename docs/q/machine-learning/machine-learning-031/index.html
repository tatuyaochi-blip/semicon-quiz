機械学習の基礎

1万件の学習用データを、ミニバッチの大きさ(バッチサイズ)50で学習する。1エポックでの重みの更新の回数はどれか。

  1. A50回
  2. B200回
  3. C2000回
答えと解説を見る

正解：B. 200回

1エポックは、学習用データ全体をひと通り使い終わるまでの学習の単位です。ミニバッチ学習では、ミニバッチごとに勾配を求めて重みを1回更新するので、1エポックでの更新の回数(イテレーション数)は 10000 ÷ 50 = 200回です。10エポック学習すれば、更新は合計で2000回になります。ミニバッチ学習は、全データで1回だけ更新するバッチ学習と、1件ごとに更新するオンライン学習の中間の方法です。

  • A. バッチサイズの値で、1回の更新に使うデータの件数です。
  • B. 正しい。10000 ÷ 50 = 200回です。
  • C. 10エポック学習したときの、更新の回数の合計です。
