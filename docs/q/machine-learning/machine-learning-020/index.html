機械学習の基礎

アンサンブル学習のバギング(ランダムフォレストなど)とブースティングの違いとして、適切なものはどれか。

  1. Aバギングは、復元抽出で作ったいくつもの学習用データで独立にモデルを学習して結果を平均や多数決でまとめ、ブースティングは、前のモデルの誤りを補うようにモデルを順に追加していく
  2. Bバギングは、前のモデルが誤ったデータを重視しながらモデルを1つずつ順に追加し、ブースティングは、復元抽出したデータで互いに独立なモデルを並列に学習して多数決をとる
  3. Cバギングもブースティングも、1つの大きな決定木を作ってから不要な枝を切り落とし、過学習を防ぐ方法である
答えと解説を見る

正解：A. バギングは、復元抽出で作ったいくつもの学習用データで独立にモデルを学習して結果を平均や多数決でまとめ、ブースティングは、前のモデルの誤りを補うようにモデルを順に追加していく

バギングは、元のデータから重複を許してランダムに抜き出す(ブートストラップ)ことで少しずつ違う学習用データを作り、それぞれで学習した多数のモデルの予測を平均や多数決でまとめます。モデルどうしは独立なので並列に学習でき、主にバリアンスを下げる効果があります。ランダムフォレストは、分割に使う特徴量もランダムに選んで決定木の多様性を高めたバギングの方法です。ブースティングは、それまでのモデルの誤りを補うように弱いモデルを順に追加していく方法で、主にバイアスを下げます。

  • A. 正しい。バギングは独立なモデルの平均や多数決、ブースティングは誤りを補うモデルの順次の追加です。
  • B. バギングとブースティングの説明が逆です。
  • C. 決定木の剪定(枝刈り)の説明で、複数のモデルを組み合わせるアンサンブル学習ではありません。

機械学習の基礎のほかの問題

  1. 2次元の点 (0, 0) のクラスをk近傍法で予測する。学習用データは、赤の点 (1, 0)、(3, 0)、(0, −3) と、青の点 (0, 2)、(−2, 1) である。距離をユークリッド距離とするとき、k = 3 と k = 5 の予測の組合せとして、正しいものはどれか。
  2. サポートベクターマシン(SVM)の説明として、適切なものはどれか。
  3. メール全体の20%がスパムである。ある単語は、スパムの50%と、スパムでないメールの5%に含まれる。この単語を含むメールがスパムである確率に最も近いものはどれか。
  4. 入力層と出力層だけからなる単純パーセプトロン(しきい値で0か1を出力する1つのニューロン)で表せない論理関数はどれか。
  5. 3クラスの分類で、ソフトマックス関数に入力する値(ロジット)が3、1、0だった。1番目のクラスの出力(確率)は、2番目のクラスの出力の約何倍か。最も近いものはどれか。
