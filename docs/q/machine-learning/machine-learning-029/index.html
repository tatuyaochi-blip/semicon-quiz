機械学習の基礎

y = (2x + 1)² の x = 1 における微分係数 dy/dx を、u = 2x + 1、y = u² として連鎖律で求めるとき、正しい値はどれか。

  1. A6
  2. B9
  3. C12
答えと解説を見る

正解：C. 12

連鎖律では dy/dx = (dy/du) × (du/dx) です。dy/du = 2u、du/dx = 2 で、x = 1 では u = 3 なので、dy/dx = 2 × 3 × 2 = 12です。誤差逆伝播法は、この連鎖律を出力側から入力側へ順に適用して、損失に対する各層の重みの勾配を効率よく求める方法です。各層は、後ろの層から受け取った勾配に自分の局所的な微分を掛けて、前の層へ渡します。

  • A. dy/du = 2u = 6 だけを求め、du/dx = 2 を掛け忘れた値です。
  • B. x = 1 のときの y の値 3² = 9で、微分係数ではありません。
  • C. 正しい。2u × 2 = 2 × 3 × 2 = 12です。
