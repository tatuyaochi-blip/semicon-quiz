機械学習の基礎

過学習(過剰適合)が起きているときに見られる様子として、適切なものはどれか。

  1. A学習用データでの誤差は小さいが、検証用データでの誤差が大きい
  2. B学習用データでも検証用データでも、誤差が大きいまま下がらない
  3. C学習を進めるほど、学習用データでの誤差も検証用データでの誤差も同じように下がり続ける
答えと解説を見る

正解：A. 学習用データでの誤差は小さいが、検証用データでの誤差が大きい

過学習は、モデルが学習用データの細かな特徴や雑音まで覚え込んでしまい、新しいデータに対する性能(汎化性能)が落ちる状態です。学習用データでの誤差は小さいのに、検証用データでの誤差が大きいことが目安になります。学習用データでも誤差が大きい状態は、モデルが単純すぎるなどで傾向をとらえきれていない未学習(学習不足)です。対策には、データを増やす、モデルを単純にする、正則化やドロップアウト、検証用データでの誤差が上がり始めたところで学習を止める早期終了などがあります。

  • A. 正しい。学習用データに合わせすぎて、新しいデータでの誤差が大きくなっています。
  • B. 未学習(学習不足)の様子です。
  • C. 学習が順調に進んでいる様子です。過学習では、検証用データでの誤差が途中から上がり始めます。

機械学習の基礎のほかの問題

  1. モデルの誤差を、バイアス(偏り)とバリアンス(ばらつき)に分けて考えるとき、適切なものはどれか。
  2. 過学習を抑える正則化などの手法の説明として、適切なものはどれか。
  3. 機械学習のモデルを作る手順のうち、データリーク(評価に使うデータの情報が学習に紛れ込むこと)を起こしているものはどれか。
  4. 2クラス分類のモデルを200件のテストデータで評価した混同行列で、真陽性(TP)が45件、偽陽性(FP)が5件、偽陰性(FN)が45件、真陰性(TN)が105件だった。適合率と再現率の組合せとして、正しいものはどれか。
  5. 2クラス分類のモデルを200件のテストデータで評価したところ、TPが20件、FPが5件、FNが30件、TNが145件だった。F値(F1スコア)に最も近いものはどれか。
