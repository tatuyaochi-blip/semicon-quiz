CMP・洗浄

CMPが使われる工程の組み合わせとして正しいものはどれか。

  1. ASTIの酸化膜、タングステンプラグ、Cuダマシン配線などの平坦化
  2. B露光とレジスト塗布
  3. Cイオン注入とアニール
答えと解説を見る

正解：A. STIの酸化膜、タングステンプラグ、Cuダマシン配線などの平坦化

CMPは、STIの埋め込み酸化膜の平坦化、層間絶縁膜の平坦化、タングステンプラグやCu配線の余分な金属の除去、さらにゲートラストのダミーゲートの露出や、ウエハの貼り合わせ前の表面の仕上げなど、多くの工程で使われ、先端ロジックでは数十回にもなります。研磨する材料ごとに、スラリー、パッド、研磨条件、終点の検出方法が使い分けられます。

CMP・洗浄のほかの問題

  1. CMPの研磨パッドの表面をダイヤモンドの工具で削って整え、研磨速度を安定させる作業を何と呼ぶか。
  2. CMPが、熱によるリフローやエッチバックによる平坦化と比べて優れている点として正しいものはどれか。
  3. 標準的なRCA洗浄におけるSC-1とSC-2の順序と目的の組み合わせとして正しいものはどれか。
  4. 高アスペクト比のパターンを洗浄・乾燥するときに、パターンの倒れが起こる主な原因はどれか。
  5. タングステンのCMPで、スラリーに過酸化水素などの酸化剤を加える理由として正しいものはどれか。
