CMP・洗浄

CMPの研磨速度を表すプレストンの式で、研磨速度に比例するとされる量はどれか。

  1. Aスラリーの色
  2. Bウエハの直径
  3. C研磨圧力と、パッドとウエハの相対速度の積
答えと解説を見る

正解：C. 研磨圧力と、パッドとウエハの相対速度の積

プレストンの式は「研磨速度 = k × 圧力 × 相対速度」という経験式で、研磨速度が圧力と速度の積に比例することを表します。比例係数kはスラリーやパッド、研磨する膜の種類によって変わります。

CMP・洗浄のほかの問題

  1. STI形成のCMPで、シリコン窒化膜に対する酸化膜の研磨選択比を高くするためによく使われる研磨粒子はどれか。
  2. MHz帯の超音波を洗浄液に加えて、ウエハ表面の微小なパーティクルを除去する洗浄方法はどれか。
  3. オゾンを溶かした超純水(オゾン水)を洗浄に用いる主な目的はどれか。
  4. Cu配線のCMPスラリーに添加されるベンゾトリアゾール(BTA)などの役割として正しいものはどれか。
  5. CMPの研磨ヘッドでウエハの周りを囲むリテーナリングの役割はどれか。
