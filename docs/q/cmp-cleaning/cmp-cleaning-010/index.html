CMP・洗浄

CMPの研磨終点を検出する方法として使われるものはどれか。

  1. A研磨後にウエハの重さを量る
  2. B研磨中の摩擦の変化(モーターのトルクなど)や、光の反射率の変化を監視する
  3. Cスラリーの色を目視で確認する
答えと解説を見る

正解：B. 研磨中の摩擦の変化(モーターのトルクなど)や、光の反射率の変化を監視する

研磨している膜がなくなって下地が出てくると、摩擦の大きさや表面の光の反射率が変わります。CMP装置では、研磨台を回すモーターのトルクや、研磨中にウエハへ当てた光の反射を監視して、研磨の終点をリアルタイムで検出します。

CMP・洗浄のほかの問題

  1. CMPの研磨速度を表すプレストンの式で、研磨速度に比例するとされる量はどれか。
  2. STI形成のCMPで、シリコン窒化膜に対する酸化膜の研磨選択比を高くするためによく使われる研磨粒子はどれか。
  3. MHz帯の超音波を洗浄液に加えて、ウエハ表面の微小なパーティクルを除去する洗浄方法はどれか。
  4. オゾンを溶かした超純水(オゾン水)を洗浄に用いる主な目的はどれか。
  5. Cu配線のCMPスラリーに添加されるベンゾトリアゾール(BTA)などの役割として正しいものはどれか。
