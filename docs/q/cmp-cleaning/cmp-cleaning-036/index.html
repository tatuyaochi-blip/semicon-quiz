CMP・洗浄

Cu配線のCMPで、一般的に研磨を段階に分けて行う理由として正しいものはどれか。

  1. ACuと、その下のバリアメタル(TaNなど)では適した研磨条件が異なるため、まずCuの大部分を除き、次にバリアメタルを除く
  2. B研磨装置を休ませるため
  3. CCuを厚くするため
答えと解説を見る

正解：A. Cuと、その下のバリアメタル(TaNなど)では適した研磨条件が異なるため、まずCuの大部分を除き、次にバリアメタルを除く

Cu配線では、溝の外の厚いCuと、その下の薄いバリアメタル、さらに下の絶縁膜を順に研磨します。材料ごとに研磨速度や選択比を最適にするため、Cuを速く削る段階と、バリアメタルを除去して平坦に仕上げる段階に分け、スラリーを使い分けます。

  • A. 正しい。材料ごとに条件を変えて段階的に研磨します。
  • B. 装置を休ませるためではありません。
  • C. CMPはCuを削る工程です。

CMP・洗浄のほかの問題

  1. CMPの研磨パッドで、硬いパッドと柔らかいパッドの一般的な特徴の違いとして正しいものはどれか。
  2. 希フッ酸で最後に洗浄したシリコン表面の状態として正しいものはどれか。
  3. CMPのスラリーを研磨装置に供給する配管の途中に、フィルタを設ける主な目的はどれか。
  4. 洗浄でウエハ表面のパーティクルを取り除くとき、粒子の大きさと除去のしやすさの関係として一般的に正しいものはどれか。
  5. CMPで研磨を続けると研磨パッドの温度が上がる。このときの研磨速度の変化として一般的に正しいものはどれか。
