CMP・洗浄

CMPの研磨パッドの表面をダイヤモンドの工具で削って整え、研磨速度を安定させる作業を何と呼ぶか。

  1. Aアッシング
  2. Bパッドコンディショニング(ドレッシング)
  3. Cダイシング
答えと解説を見る

正解：B. パッドコンディショニング(ドレッシング)

研磨を続けると、パッドの表面がつぶれたり研磨くずが詰まったりして、研磨速度が下がります。ダイヤモンドの粒を付けたコンディショナでパッドの表面を削り、細かい凹凸を再生することで、研磨速度を安定させます。

CMP・洗浄のほかの問題

  1. CMPが、熱によるリフローやエッチバックによる平坦化と比べて優れている点として正しいものはどれか。
  2. 標準的なRCA洗浄におけるSC-1とSC-2の順序と目的の組み合わせとして正しいものはどれか。
  3. 高アスペクト比のパターンを洗浄・乾燥するときに、パターンの倒れが起こる主な原因はどれか。
  4. タングステンのCMPで、スラリーに過酸化水素などの酸化剤を加える理由として正しいものはどれか。
  5. CMPの研磨量がチップ内のパターンの密度によって変わることへの、設計上の対策として正しいものはどれか。
