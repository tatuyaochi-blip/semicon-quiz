CMP・洗浄

SC-1のようなアルカリ性の洗浄液で、いったん離れたパーティクルが再付着しにくい理由として正しいものはどれか。

  1. A洗浄液の粘度が非常に高いため
  2. Bウエハ表面と粒子が同じ符号に帯電し、互いに反発するため
  3. C粒子が洗浄液に溶けて消えるため
答えと解説を見る

正解：B. ウエハ表面と粒子が同じ符号に帯電し、互いに反発するため

アルカリ性の液中では、シリコン表面や多くの粒子の表面がともに負に帯電します(ゼータ電位が負になる)。同じ符号の電荷どうしは反発するため、表面から離れた粒子が再び付着しにくくなります。SC-1がパーティクル除去に効果的な理由の一つです。

CMP・洗浄のほかの問題

  1. ウエハ表面の鉄や銅などの金属汚染が引き起こす問題として正しいものはどれか。
  2. CMPでウエハ表面に微細な傷(スクラッチ)が生じる主な原因として正しいものはどれか。
  3. 微細な構造の倒壊を防ぐため、液体を使わずに表面の自然酸化膜などを除去する方法はどれか。
  4. CMPが使われる工程の組み合わせとして正しいものはどれか。
  5. CMPの研磨パッドの表面をダイヤモンドの工具で削って整え、研磨速度を安定させる作業を何と呼ぶか。
