CMP・洗浄

ウエハ表面の鉄や銅などの金属汚染が引き起こす問題として正しいものはどれか。

  1. Aキャリアのライフタイムの低下や、ゲート酸化膜の耐圧の低下などによる特性・信頼性の劣化
  2. Bウエハが軽くなる
  3. Cウエハが発光する
答えと解説を見る

正解：A. キャリアのライフタイムの低下や、ゲート酸化膜の耐圧の低下などによる特性・信頼性の劣化

鉄や銅などの金属不純物は、シリコン中でバンドギャップの中ほどに深い準位をつくる再結合中心になり、キャリアのライフタイムを下げたり、接合のリーク電流やイメージセンサの白傷を増やしたりします。ゲート酸化膜に取り込まれると耐圧や信頼性を低下させます。そのため洗浄で金属汚染を10⁹〜10¹⁰ atoms/cm²程度以下に抑え、薬液や純水の金属不純物もppt(1兆分の1)レベルで管理します。

CMP・洗浄のほかの問題

  1. CMPでウエハ表面に微細な傷(スクラッチ)が生じる主な原因として正しいものはどれか。
  2. 微細な構造の倒壊を防ぐため、液体を使わずに表面の自然酸化膜などを除去する方法はどれか。
  3. CMPが使われる工程の組み合わせとして正しいものはどれか。
  4. CMPの研磨パッドの表面をダイヤモンドの工具で削って整え、研磨速度を安定させる作業を何と呼ぶか。
  5. CMPが、熱によるリフローやエッチバックによる平坦化と比べて優れている点として正しいものはどれか。
