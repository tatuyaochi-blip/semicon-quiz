CMP・洗浄

洗浄で取り除く対象となるウエハ表面の汚染の種類の組み合わせとして正しいものはどれか。

  1. A光・音・熱
  2. B電子・正孔・イオン注入した不純物
  3. Cパーティクル・金属汚染・有機物汚染・自然酸化膜など
答えと解説を見る

正解：C. パーティクル・金属汚染・有機物汚染・自然酸化膜など

洗浄で除去する汚染には、微小な粒子(パーティクル)、鉄・銅・ナトリウムなどの金属汚染、レジストの残りや空気中のガスから付着する有機物、不要な自然酸化膜、表面のマイクロラフネスなどがあります。それぞれに適した薬液(SC-1、SC-2、SPM、希フッ酸など)と物理的な力(ブラシ、メガソニック)を組み合わせて取り除き、材料を傷めないことも同時に求められます。

  • A. 光・音・熱は汚染ではありません。
  • B. キャリアや意図して入れた不純物は洗浄の対象ではありません。
  • C. 正しい。パーティクル・金属・有機物・自然酸化膜などです。
