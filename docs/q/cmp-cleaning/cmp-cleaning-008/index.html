CMP・洗浄

ウエハを1枚ずつ処理する枚葉式洗浄装置の利点として正しいものはどれか。

  1. A一度に大量のウエハを同時に処理できる
  2. B薬液をまったく使わない
  3. Cウエハ間の相互汚染が起こりにくく、処理条件を1枚ごとに制御しやすい
答えと解説を見る

正解：C. ウエハ間の相互汚染が起こりにくく、処理条件を1枚ごとに制御しやすい

枚葉式洗浄では、回転するウエハに薬液を吹きかけて1枚ずつ処理するため、ほかのウエハから汚染が移りにくく、条件を細かく制御できます。多数のウエハを薬液槽に浸すバッチ式は処理能力が高い一方、相互汚染のリスクがあります。先端工程では枚葉式が増えています。
