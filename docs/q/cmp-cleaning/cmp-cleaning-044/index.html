CMP・洗浄

CMPの直後のウエハを、乾かさずに濡れたまま洗浄工程へ運ぶことが重要とされる理由はどれか。

  1. Aウエハの重さを保つため
  2. Bウエハを冷やすため
  3. C表面に残ったスラリーの粒子や薬液が乾いて固着すると、後の洗浄で除去しにくくなるため
答えと解説を見る

正解：C. 表面に残ったスラリーの粒子や薬液が乾いて固着すると、後の洗浄で除去しにくくなるため

研磨後の表面にはスラリーの粒子や反応生成物が残っています。これが乾くと粒子が表面に強く固着し、洗浄で取り除くのが難しくなって欠陥になります。そのため、CMP装置と洗浄部を一体化し、ウエハを濡れたまま洗浄・乾燥まで連続して処理します。

  • A. 重さを保つためではありません。
  • B. 冷却が目的ではありません。
  • C. 正しい。乾くと粒子が固着して除去しにくくなります。

CMP・洗浄のほかの問題

  1. 多数のウエハを同じ洗浄液の槽に浸して洗うバッチ式の洗浄の注意点として正しいものはどれか。
  2. 微細なパターンを倒さずにパーティクルを除去する方法として研究・実用化されている、極低温の二酸化炭素やアルゴンなどの微粒子を吹き付ける洗浄はどれか。
  3. CMPの研磨ヘッドで、ウエハを押し付ける圧力を同心円状の複数の区画ごとに変えられるようにする主な目的はどれか。
  4. 研磨粒子をスラリーに入れる代わりに、研磨パッドの中に固定しておく方式のCMPはどれか。
  5. SPM(硫酸と過酸化水素水)洗浄の後のすすぎが不十分なときに起こりやすい問題として知られているものはどれか。
