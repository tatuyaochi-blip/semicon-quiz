CMP・洗浄

CMPスラリーの研磨粒子の大きさの目安として正しいものはどれか。

  1. A数mm程度
  2. B数cm程度
  3. C数十〜百数十nm程度
答えと解説を見る

正解：C. 数十〜百数十nm程度

CMPスラリーの研磨粒子は、数十〜百数十nm程度の非常に細かい粒子です。粒子が大きすぎるとスクラッチの原因になるため、粒子の大きさの分布や、凝集した大きな粒子の混入が厳しく管理されています。
