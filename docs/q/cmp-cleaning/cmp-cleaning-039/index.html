CMP・洗浄

CMPのスラリーを研磨装置に供給する配管の途中に、フィルタを設ける主な目的はどれか。

  1. A研磨粒子をすべて取り除くため
  2. B凝集した大きな粒子などを取り除き、ウエハの傷(スクラッチ)を防ぐため
  3. Cスラリーを温めるため
答えと解説を見る

正解：B. 凝集した大きな粒子などを取り除き、ウエハの傷(スクラッチ)を防ぐため

スラリーの研磨粒子は保管や輸送の間に凝集して大きな塊になることがあり、それがウエハに傷をつけます。供給ラインのフィルタで、こうした大きな粒子を取り除き、必要な大きさの研磨粒子だけを通します。

  • A. 研磨粒子がなくなると研磨できません。
  • B. 正しい。凝集した粗大粒子を除いて傷を防ぎます。
  • C. フィルタはスラリーを温めるためのものではありません。

CMP・洗浄のほかの問題

  1. 洗浄でウエハ表面のパーティクルを取り除くとき、粒子の大きさと除去のしやすさの関係として一般的に正しいものはどれか。
  2. CMPで研磨を続けると研磨パッドの温度が上がる。このときの研磨速度の変化として一般的に正しいものはどれか。
  3. SC-1(アンモニア・過酸化水素水の混合液)の中で、過酸化水素が果たす役割として正しいものはどれか。
  4. 洗浄後のウエハ表面のパーティクルの数を数えるのに一般的に使われる方法はどれか。
  5. CMPの直後のウエハを、乾かさずに濡れたまま洗浄工程へ運ぶことが重要とされる理由はどれか。
