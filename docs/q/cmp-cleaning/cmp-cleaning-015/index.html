CMP・洗浄

Cu配線のCMPスラリーに添加されるベンゾトリアゾール(BTA)などの役割として正しいものはどれか。

  1. A銅表面に保護膜をつくり、過剰なエッチングや腐食を抑える
  2. B研磨粒子を大きくする
  3. Cスラリーに色を付ける
答えと解説を見る

正解：A. 銅表面に保護膜をつくり、過剰なエッチングや腐食を抑える

Cu CMPのスラリーには銅を酸化・溶解させる成分が含まれますが、そのままでは凹部の銅まで溶けてしまいます。BTAなどの防食剤は銅の表面に保護膜をつくり、パッドが当たる凸部だけが研磨されるようにして、平坦化と腐食防止を両立させます。

CMP・洗浄のほかの問題

  1. CMPの研磨ヘッドでウエハの周りを囲むリテーナリングの役割はどれか。
  2. SC-1のようなアルカリ性の洗浄液で、いったん離れたパーティクルが再付着しにくい理由として正しいものはどれか。
  3. ウエハ表面の鉄や銅などの金属汚染が引き起こす問題として正しいものはどれか。
  4. CMPでウエハ表面に微細な傷(スクラッチ)が生じる主な原因として正しいものはどれか。
  5. 微細な構造の倒壊を防ぐため、液体を使わずに表面の自然酸化膜などを除去する方法はどれか。
