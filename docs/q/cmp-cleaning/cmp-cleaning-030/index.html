CMP・洗浄

ウエハの裏面や外周(ベベル部)を洗浄する主な目的はどれか。

  1. Aウエハを軽くするため
  2. B裏面や外周の汚染やパーティクルが、装置や他のウエハ、表面に移るのを防ぐため
  3. Cウエハを光らせるため
答えと解説を見る

正解：B. 裏面や外周の汚染やパーティクルが、装置や他のウエハ、表面に移るのを防ぐため

ウエハの裏面や外周の汚染は、装置のステージや搬送部品、FOUPを通じて他のウエハに広がったり、剥がれて表面に付着したりします。特に外周部に付いた膜は剥がれやすいため、ベベル部の膜を除去したり洗浄したりして、汚染の広がりを防ぎます。
