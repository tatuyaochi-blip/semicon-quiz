CMP・洗浄

タングステンのCMPで、スラリーに過酸化水素などの酸化剤を加える理由として正しいものはどれか。

  1. Aタングステンの表面を研磨しやすい酸化物に変えるため
  2. Bタングステンを光らせるため
  3. Cスラリーを冷却するため
答えと解説を見る

正解：A. タングステンの表面を研磨しやすい酸化物に変えるため

タングステンは硬い金属で、そのまま機械的に研磨するのは困難です。酸化剤で表面を柔らかい酸化物に変え、それを研磨粒子で取り除くことを繰り返して研磨を進めます。CMPの「化学」の部分の役割がよくわかる例です。

この分野を解く 分野ページへ

CMP・洗浄のほかの問題

  1. CMPの研磨量がチップ内のパターンの密度によって変わることへの、設計上の対策として正しいものはどれか。
  2. CMPスラリーの研磨粒子の大きさの目安として正しいものはどれか。
  3. 近年の洗浄工程で、薬液を希釈して使ったり、機能水を使ったりする主な目的はどれか。
  4. ウエハの裏面や外周(ベベル部)を洗浄する主な目的はどれか。
  5. 半導体の製造工程でウエハの洗浄が重要とされる主な理由はどれか。
