CMP・洗浄

RCA洗浄で使われるSC-1(アンモニア・過酸化水素水の混合液)の主な目的はどれか。

  1. A金属汚染の除去
  2. Bパーティクルや有機物の除去
  3. C自然酸化膜の除去
答えと解説を見る

正解：B. パーティクルや有機物の除去

SC-1(NH4OH:H2O2:H2O、例えば1:1:5、約70 ℃)は、過酸化水素で表面を酸化しながら、アンモニアでその酸化膜を毎分0.1〜1 nm程度ゆっくり溶かすことで、パーティクルを下から浮かせて除去します。アルカリ性で粒子と表面がともに負に帯電して反発するため、再付着もしにくくなります。有機物の除去にも効果があります。金属汚染の除去にはSC-2、自然酸化膜の除去には希フッ酸を使います。
