CMP・洗浄

RCA洗浄で使われるSC-1(アンモニア・過酸化水素水の混合液)の主な目的はどれか。

  1. A金属汚染の除去
  2. Bパーティクルや有機物の除去
  3. C自然酸化膜の除去
答えと解説を見る

正解：B. パーティクルや有機物の除去

SC-1は、過酸化水素で表面を酸化しながらアンモニアで薄くエッチングすることで、パーティクルを浮かせて除去します。有機物の除去にも効果があります。金属汚染の除去にはSC-2(塩酸・過酸化水素水)、自然酸化膜の除去には希フッ酸(DHF)を使います。
