CMP・洗浄

近年の洗浄工程で、薬液を希釈して使ったり、機能水を使ったりする主な目的はどれか。

  1. A薬液の使用量と環境への負荷を減らすため
  2. B洗浄力を必ず強くするため
  3. Cウエハの色を変えるため
答えと解説を見る

正解：A. 薬液の使用量と環境への負荷を減らすため

従来の洗浄では濃い薬液を大量に使っていましたが、薬液を希釈したり、オゾン水や水素水などの機能水を使ったりすることで、薬液と純水の使用量や廃液を減らしながら、必要な洗浄効果を得る工夫が進められています。

  1. ウエハの裏面や外周(ベベル部)を洗浄する主な目的はどれか。
  2. 半導体の製造工程でウエハの洗浄が重要とされる主な理由はどれか。
  3. LSIの製造工程全体の中で、洗浄工程の回数についての説明として正しいものはどれか。
  4. 洗浄で取り除く対象となるウエハ表面の汚染の種類の組み合わせとして正しいものはどれか。
  5. 多層配線などの工程で、CMPによってウエハの表面を平坦にすることが必要になる主な理由はどれか。
