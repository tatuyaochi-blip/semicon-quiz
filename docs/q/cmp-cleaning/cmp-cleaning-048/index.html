CMP・洗浄

研磨粒子をスラリーに入れる代わりに、研磨パッドの中に固定しておく方式のCMPはどれか。

  1. Aスピンコート
  2. B固定砥粒CMP
  3. C電解めっき
答えと解説を見る

正解：B. 固定砥粒CMP

固定砥粒CMPでは、セリアなどの研磨粒子を樹脂の中に固定したパッドを使い、粒子を含まない薬液だけを供給して研磨します。凸部だけが砥粒に触れて削られ、凹部はほとんど削られないため平坦化の能力が高く、平坦になると研磨が自然に遅くなる自己停止性も得られます。スラリーの使用量や廃液も減らせるため、STIの平坦化などに使われてきましたが、パッドの欠陥管理が課題です。

  • A. スピンコートは回転で液を広げて膜をつくる方法です。
  • B. 正しい。研磨粒子をパッドに固定した方式です。
  • C. 電解めっきは電気で金属を析出させる成膜方法です。
