CMP・洗浄

CMPのあとの洗浄で特に取り除く必要があるものはどれか。

  1. Aフォトレジストの膜
  2. Bウエハ表面に残ったスラリーの研磨粒子や金属汚染
  3. C下地の酸化膜すべて
答えと解説を見る

正解：B. ウエハ表面に残ったスラリーの研磨粒子や金属汚染

CMPのあとのウエハ表面には、スラリーの研磨粒子や研磨くず、金属イオンが残っています。これらは不良の原因になるため、ブラシによるスクラブ洗浄や薬液洗浄で取り除きます。CMPと洗浄は一体の装置で行われることが一般的です。

CMP・洗浄のほかの問題

  1. ウエハを1枚ずつ処理する枚葉式洗浄装置の利点として正しいものはどれか。
  2. 洗浄後のウエハを乾燥させる工程でIPA(イソプロピルアルコール)を用いる主な目的はどれか。
  3. CMPの研磨終点を検出する方法として使われるものはどれか。
  4. CMPの研磨速度を表すプレストンの式で、研磨速度に比例するとされる量はどれか。
  5. STI形成のCMPで、シリコン窒化膜に対する酸化膜の研磨選択比を高くするためによく使われる研磨粒子はどれか。
