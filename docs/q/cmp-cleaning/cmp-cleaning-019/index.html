CMP・洗浄

CMPでウエハ表面に微細な傷(スクラッチ)が生じる主な原因として正しいものはどれか。

  1. A研磨圧力を0にしたため
  2. B洗浄液の温度が低いため
  3. Cスラリー中の凝集した大きな粒子や、パッドに残った異物
答えと解説を見る

正解：C. スラリー中の凝集した大きな粒子や、パッドに残った異物

スラリー中の研磨粒子が凝集して大きな塊になったり、パッドに硬い異物が残ったりすると、ウエハ表面を引っかいてスクラッチができます。配線の断線や短絡の原因になるため、スラリーのろ過や管理、パッドのコンディショニングなどで防ぎます。

CMP・洗浄のほかの問題

  1. 微細な構造の倒壊を防ぐため、液体を使わずに表面の自然酸化膜などを除去する方法はどれか。
  2. CMPが使われる工程の組み合わせとして正しいものはどれか。
  3. CMPの研磨パッドの表面をダイヤモンドの工具で削って整え、研磨速度を安定させる作業を何と呼ぶか。
  4. CMPが、熱によるリフローやエッチバックによる平坦化と比べて優れている点として正しいものはどれか。
  5. 標準的なRCA洗浄におけるSC-1とSC-2の順序と目的の組み合わせとして正しいものはどれか。
