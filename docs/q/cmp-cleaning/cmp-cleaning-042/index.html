CMP・洗浄

SC-1(アンモニア・過酸化水素水の混合液)の中で、過酸化水素が果たす役割として正しいものはどれか。

  1. Aパーティクルを接着させる
  2. B表面を水素で終端する
  3. Cシリコンの表面を酸化して薄い酸化膜で覆い、アンモニアによるシリコンの直接の荒れを抑えつつ、表面をわずかにエッチングし続ける
答えと解説を見る

正解：C. シリコンの表面を酸化して薄い酸化膜で覆い、アンモニアによるシリコンの直接の荒れを抑えつつ、表面をわずかにエッチングし続ける

SC-1では、過酸化水素がシリコン表面を酸化して薄い酸化膜をつくり、アンモニアがその酸化膜をゆっくり溶かします。酸化とエッチングが同時に進むことで、表面がわずかずつ削られてパーティクルが持ち上げられて除去されます。過酸化水素が少ないと、アンモニアがシリコンを直接エッチングして表面が荒れます。

  • A. パーティクルを除去するための液です。
  • B. 水素終端になるのは希フッ酸で処理したときです。
  • C. 正しい。表面を酸化して保護しながら、わずかなエッチングを続けます。

CMP・洗浄のほかの問題

  1. 洗浄後のウエハ表面のパーティクルの数を数えるのに一般的に使われる方法はどれか。
  2. CMPの直後のウエハを、乾かさずに濡れたまま洗浄工程へ運ぶことが重要とされる理由はどれか。
  3. 多数のウエハを同じ洗浄液の槽に浸して洗うバッチ式の洗浄の注意点として正しいものはどれか。
  4. 微細なパターンを倒さずにパーティクルを除去する方法として研究・実用化されている、極低温の二酸化炭素やアルゴンなどの微粒子を吹き付ける洗浄はどれか。
  5. CMPの研磨ヘッドで、ウエハを押し付ける圧力を同心円状の複数の区画ごとに変えられるようにする主な目的はどれか。
