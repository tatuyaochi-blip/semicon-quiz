CMP・洗浄

SC-1(アンモニア・過酸化水素水の混合液)の中で、過酸化水素が果たす役割として正しいものはどれか。

  1. Aパーティクルを接着させる
  2. B表面を水素で終端する
  3. Cシリコンの表面を酸化して薄い酸化膜で覆い、アンモニアによるシリコンの直接の荒れを抑えつつ、表面をわずかにエッチングし続ける
答えと解説を見る

正解：C. シリコンの表面を酸化して薄い酸化膜で覆い、アンモニアによるシリコンの直接の荒れを抑えつつ、表面をわずかにエッチングし続ける

SC-1では、過酸化水素がシリコン表面を酸化して厚さ約1 nmの薄い酸化膜をつくり、アンモニアがその酸化膜をゆっくり溶かします。酸化とエッチングが同時に進むことで、表面がわずかずつ削られてパーティクルが下から持ち上げられて除去されます。過酸化水素が少ないと、アンモニアがシリコンを直接エッチングして表面が荒れるため、両者の比と温度が最適化され、近年は希釈して荒れを抑えています。

  • A. パーティクルを除去するための液です。
  • B. 水素終端になるのは希フッ酸で処理したときです。
  • C. 正しい。表面を酸化して保護しながら、わずかなエッチングを続けます。
