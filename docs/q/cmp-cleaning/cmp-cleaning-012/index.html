CMP・洗浄

STI形成のCMPで、シリコン窒化膜に対する酸化膜の研磨選択比を高くするためによく使われる研磨粒子はどれか。

  1. Aセリア(酸化セリウム)
  2. B鉄の粉
  3. Cダイヤモンドの粗粒
答えと解説を見る

正解：A. セリア(酸化セリウム)

セリア系スラリーは、添加剤と組み合わせることで、酸化膜を速く研磨しながら窒化膜の研磨を非常に遅くできます。そのため、窒化膜をストッパーとして使うSTIのCMPで、平坦性と研磨の止まりやすさを両立させるために使われます。
