CMP・洗浄

多数のウエハを同じ洗浄液の槽に浸して洗うバッチ式の洗浄の注意点として正しいものはどれか。

  1. Aウエハから溶け出したり落ちたりした汚染が液を通じて他のウエハに移る(相互汚染)おそれがある
  2. B1枚ずつしか処理できない
  3. C薬液を一切使わない
答えと解説を見る

正解：A. ウエハから溶け出したり落ちたりした汚染が液を通じて他のウエハに移る(相互汚染)おそれがある

バッチ式では、50枚程度のウエハを同じ槽で処理するため処理能力が高い一方、あるウエハから出た汚染(金属、パーティクル、レジストの残り)が液中に広がり、他のウエハに付着するおそれがあります。そのため液の交換頻度や、循環・ろ過、濃度の管理が重要で、汚染に敏感な工程や、ウエハごとに条件を変えたい工程では枚葉式が使われます。

  • A. 正しい。液を通じた相互汚染に注意が必要です。
  • B. バッチ式は多数のウエハを同時に処理します。
  • C. バッチ式も薬液を使って洗浄します。

CMP・洗浄のほかの問題

  1. 微細なパターンを倒さずにパーティクルを除去する方法として研究・実用化されている、極低温の二酸化炭素やアルゴンなどの微粒子を吹き付ける洗浄はどれか。
  2. CMPの研磨ヘッドで、ウエハを押し付ける圧力を同心円状の複数の区画ごとに変えられるようにする主な目的はどれか。
  3. 研磨粒子をスラリーに入れる代わりに、研磨パッドの中に固定しておく方式のCMPはどれか。
  4. SPM(硫酸と過酸化水素水)洗浄の後のすすぎが不十分なときに起こりやすい問題として知られているものはどれか。
  5. 機械的な力を小さくしたい用途で研究されてきた、電気化学的な溶解を組み合わせて金属を平坦化する研磨方法はどれか。
