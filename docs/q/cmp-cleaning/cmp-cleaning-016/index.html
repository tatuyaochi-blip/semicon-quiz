CMP・洗浄

CMPの研磨ヘッドでウエハの周りを囲むリテーナリングの役割はどれか。

  1. Aウエハを冷却する
  2. Bスラリーに色を付ける
  3. C研磨中にウエハが飛び出さないよう保持し、ウエハ周辺部の研磨のばらつきを抑える
答えと解説を見る

正解：C. 研磨中にウエハが飛び出さないよう保持し、ウエハ周辺部の研磨のばらつきを抑える

リテーナリングは、研磨ヘッドに保持したウエハの外周を囲む樹脂のリングです。研磨中にウエハが横に飛び出すのを防ぐとともに、ウエハより少し外側でパッドを押さえて、パッドがウエハの縁で盛り上がったり沈んだりする変形を抑え、外周数mmの研磨量のばらつきを小さくします。リング自体もパッドで削られて消耗するため、定期的に交換します。

CMP・洗浄のほかの問題

  1. SC-1のようなアルカリ性の洗浄液で、いったん離れたパーティクルが再付着しにくい理由として正しいものはどれか。
  2. ウエハ表面の鉄や銅などの金属汚染が引き起こす問題として正しいものはどれか。
  3. CMPでウエハ表面に微細な傷(スクラッチ)が生じる主な原因として正しいものはどれか。
  4. 微細な構造の倒壊を防ぐため、液体を使わずに表面の自然酸化膜などを除去する方法はどれか。
  5. CMPが使われる工程の組み合わせとして正しいものはどれか。
