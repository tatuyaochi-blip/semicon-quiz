CMP・洗浄

MHz帯の超音波を洗浄液に加えて、ウエハ表面の微小なパーティクルを除去する洗浄方法はどれか。

  1. Aアッシング
  2. Bメガソニック洗浄
  3. Cスクライブ
答えと解説を見る

正解：B. メガソニック洗浄

メガソニック洗浄は、約1 MHz前後の超音波を洗浄液に加え、液の速い流れ(音響流)や薄い境界層で微小なパーティクルを表面から引き離して除去します。数十kHzの超音波洗浄では液中にできた気泡がつぶれる強い衝撃(キャビテーション)で微細パターンが壊れやすいのに対し、周波数が高いと衝撃が小さく、ダメージを抑えながら0.1 µm以下の粒子も取り除けます。SC-1と組み合わせてよく使われます。

CMP・洗浄のほかの問題

  1. オゾンを溶かした超純水(オゾン水)を洗浄に用いる主な目的はどれか。
  2. Cu配線のCMPスラリーに添加されるベンゾトリアゾール(BTA)などの役割として正しいものはどれか。
  3. CMPの研磨ヘッドでウエハの周りを囲むリテーナリングの役割はどれか。
  4. SC-1のようなアルカリ性の洗浄液で、いったん離れたパーティクルが再付着しにくい理由として正しいものはどれか。
  5. ウエハ表面の鉄や銅などの金属汚染が引き起こす問題として正しいものはどれか。
