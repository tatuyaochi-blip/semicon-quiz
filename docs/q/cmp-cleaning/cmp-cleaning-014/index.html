CMP・洗浄

オゾンを溶かした超純水(オゾン水)を洗浄に用いる主な目的はどれか。

  1. A金属膜を成膜する
  2. Bウエハを研磨する
  3. C有機物を酸化分解して除去する
答えと解説を見る

正解：C. 有機物を酸化分解して除去する

オゾン水は強い酸化力をもち、有機物の除去やシリコン表面の酸化に使われます。硫酸などの薬液を使う洗浄に比べ、薬液の使用量や廃液を減らせる環境負荷の小さい洗浄として利用されています。

CMP・洗浄のほかの問題

  1. Cu配線のCMPスラリーに添加されるベンゾトリアゾール(BTA)などの役割として正しいものはどれか。
  2. CMPの研磨ヘッドでウエハの周りを囲むリテーナリングの役割はどれか。
  3. SC-1のようなアルカリ性の洗浄液で、いったん離れたパーティクルが再付着しにくい理由として正しいものはどれか。
  4. ウエハ表面の鉄や銅などの金属汚染が引き起こす問題として正しいものはどれか。
  5. CMPでウエハ表面に微細な傷(スクラッチ)が生じる主な原因として正しいものはどれか。
