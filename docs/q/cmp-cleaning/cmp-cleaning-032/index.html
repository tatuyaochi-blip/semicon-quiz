CMP・洗浄

LSIの製造工程全体の中で、洗浄工程の回数についての説明として正しいものはどれか。

  1. A最後に1回だけ行う
  2. B多くの工程の前後で繰り返し行われ、全工程の中でも特に回数の多い工程の一つである
  3. C最初に1回だけ行う
答えと解説を見る

正解：B. 多くの工程の前後で繰り返し行われ、全工程の中でも特に回数の多い工程の一つである

洗浄は、成膜・エッチング・イオン注入・CMPなどの前後で繰り返し行われ、先端のLSIでは数百回に及びます。工程の数としては全体の中でも特に多く、歩留まりを支える基本的な工程です。

  • A. 最後だけでは途中の工程の汚染を取り除けません。
  • B. 正しい。工程の前後で何度も繰り返し行います。
  • C. 1回だけでは各工程で生じる汚染を取り除けません。

CMP・洗浄のほかの問題

  1. 洗浄で取り除く対象となるウエハ表面の汚染の種類の組み合わせとして正しいものはどれか。
  2. 多層配線などの工程で、CMPによってウエハの表面を平坦にすることが必要になる主な理由はどれか。
  3. CMP装置の基本的な構成として正しいものはどれか。
  4. Cu配線のCMPで、一般的に研磨を段階に分けて行う理由として正しいものはどれか。
  5. CMPの研磨パッドで、硬いパッドと柔らかいパッドの一般的な特徴の違いとして正しいものはどれか。
