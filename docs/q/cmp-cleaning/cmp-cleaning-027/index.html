CMP・洗浄

CMPの研磨量がチップ内のパターンの密度によって変わることへの、設計上の対策として正しいものはどれか。

  1. Aチップの色を変える
  2. Bダミーパターンを配置して、パターンの密度を均一にする
  3. Cパターンの数を減らす
答えと解説を見る

正解：B. ダミーパターンを配置して、パターンの密度を均一にする

パターンが密な場所と疎な場所では研磨の進み方が異なり、膜厚がばらつきます。設計の段階で空いた場所にダミーパターンを配置して密度をそろえると、CMP後の膜厚が均一になります。設計と製造が協力して歩留まりを高める例の一つです。
