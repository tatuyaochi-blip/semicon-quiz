CMP・洗浄

CMPが、熱によるリフローやエッチバックによる平坦化と比べて優れている点として正しいものはどれか。

  1. A必ず低コストである
  2. B研磨くずが一切出ない
  3. Cウエハ全体にわたる広い範囲の平坦化(グローバル平坦化)ができる
答えと解説を見る

正解：C. ウエハ全体にわたる広い範囲の平坦化(グローバル平坦化)ができる

リフローやエッチバックでは、局所的な段差はなだらかにできても、ウエハ全体にわたる広い範囲の平坦化は困難です。CMPは硬いパッドで凸部を優先的に研磨するため、チップ全体、ウエハ全体にわたって高い平坦性が得られ、多層配線の実現を可能にしました。
