CMP・洗浄

半導体の製造工程でウエハの洗浄が重要とされる主な理由はどれか。

  1. Aわずかなパーティクルや金属などの汚染でも、配線の短絡や断線、特性の変動を起こして歩留まりを下げるため
  2. Bウエハの色をそろえるため
  3. Cウエハを軽くするため
答えと解説を見る

正解：A. わずかなパーティクルや金属などの汚染でも、配線の短絡や断線、特性の変動を起こして歩留まりを下げるため

微細なLSIでは、数十nmのパーティクルや、ごく微量の金属・有機物の汚染でも、パターンの欠陥やリーク電流の増加、しきい値電圧の変動などを引き起こします。そのため、各工程の前後で汚染を取り除く洗浄が欠かせません。

  • A. 正しい。わずかな汚染でも不良の原因になります。
  • B. 色をそろえるためではありません。
  • C. 重さを変えるためではありません。

CMP・洗浄のほかの問題

  1. LSIの製造工程全体の中で、洗浄工程の回数についての説明として正しいものはどれか。
  2. 洗浄で取り除く対象となるウエハ表面の汚染の種類の組み合わせとして正しいものはどれか。
  3. 多層配線などの工程で、CMPによってウエハの表面を平坦にすることが必要になる主な理由はどれか。
  4. CMP装置の基本的な構成として正しいものはどれか。
  5. Cu配線のCMPで、一般的に研磨を段階に分けて行う理由として正しいものはどれか。
