CMP・洗浄

洗浄後のウエハを乾燥させる工程でIPA(イソプロピルアルコール)を用いる主な目的はどれか。

  1. Aウォーターマーク(乾燥しみ)の発生を防ぐ
  2. Bウエハ表面をエッチングする
  3. Cウエハ表面を酸化させる
答えと解説を見る

正解：A. ウォーターマーク(乾燥しみ)の発生を防ぐ

水が表面に残ったまま自然に乾くと、溶けていた成分などが残ってウォーターマークができます。IPAは水と混ざりやすく表面張力が小さいため、水と置き換えてすばやく乾かしたり、表面張力の差(マランゴニ効果)で水を引き離したりして、しみの発生を防ぎます。
