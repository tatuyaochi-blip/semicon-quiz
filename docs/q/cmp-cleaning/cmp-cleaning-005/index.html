CMP・洗浄

CMPで使うスラリーの説明として正しいものはどれか。

  1. Aシリカやセリアなどの研磨粒子を薬液に分散させた研磨液
  2. Bウエハに塗る感光性の樹脂
  3. Cプラズマを発生させるためのガス
答えと解説を見る

正解：A. シリカやセリアなどの研磨粒子を薬液に分散させた研磨液

スラリーは、シリカ(SiO2)やセリア(CeO2)、アルミナなどの微細な研磨粒子を、酸化剤やpH調整剤などを含む薬液に分散させたものです。研磨する膜の種類に合わせて、粒子の種類や薬液の成分を選びます。
