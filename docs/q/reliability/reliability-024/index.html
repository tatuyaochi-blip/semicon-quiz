信頼性

信頼度0.9の部品を2つ並列に接続し、どちらか一方が動作すれば機能するシステムの信頼度はいくらか。

  1. A0.81
  2. B0.9
  3. C0.99
答えと解説を見る

正解：C. 0.99

並列システムが機能しなくなるのは、2つの部品が両方とも故障したときだけです。その確率は (1 − 0.9) × (1 − 0.9) = 0.01 なので、信頼度は 1 − 0.01 = 0.99 になります。冗長化によって信頼性を高められることがわかります。

信頼性のほかの問題

  1. 信頼度0.9の部品を2つ直列に接続し、両方が動作しないと機能しないシステムの信頼度はいくらか。
  2. TDDBの寿命評価で、実際の使用電圧より高い電圧をかけて試験する理由として正しいものはどれか。
  3. スマートフォンなどの携帯機器で、はんだ接合部の信頼性の評価として特に重視される試験はどれか。
  4. エレクトロマイグレーションで配線にヒロック(突起)が生じたときに起こりうる故障はどれか。
  5. 非常に低い故障率を統計的に保証するための信頼性試験の条件として適切なものはどれか。
