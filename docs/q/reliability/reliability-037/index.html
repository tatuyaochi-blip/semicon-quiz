信頼性

温度に加えて、湿度や電圧などの複数のストレスの影響を含めて寿命の加速を表す、熱力学にもとづくモデルはどれか。

  1. Aポアソンモデル
  2. Bオームの法則
  3. Cアイリングモデル
答えと解説を見る

正解：C. アイリングモデル

アイリングモデルは、化学反応の速度を熱力学から導いたもので、アレニウスの温度の項に、湿度や電圧、電流などのストレスの項を掛け合わせた形で、複数のストレスによる寿命の加速を表します。高温高湿バイアス試験などの結果から、実際の使用条件での寿命を推定するのに使われます。湿度の項をべき乗で表す湿度向けのペックのモデルも、この考え方の一種です。

  • A. ポアソンモデルは歩留まりの計算などに使われます。
  • B. オームの法則は電圧・電流・抵抗の関係です。
  • C. 正しい。複数のストレスを含めた加速モデルです。

信頼性のほかの問題

  1. 温度サイクルによるはんだ接合の疲労寿命を、温度変化の幅(ひずみの大きさ)と繰り返しの回数の関係で表すモデルはどれか。
  2. エレクトロマイグレーションの寿命試験で、多数の配線の故障までの時間の分布を表すのによく使われる統計分布はどれか。
  3. 車載用などで、製品が寿命の間にどのような温度・電圧・動作時間の条件にさらされるかをまとめた想定のことを何と呼ぶか。
  4. 故障率が100 FITの部品を10,000個使ったとき、1年間(約8,760時間)に故障する数の期待値に最も近いものはどれか。(1 FIT = 10⁹時間あたり1件の故障)
  5. プリント基板などで、湿気のある環境で電圧がかかった電極の間に、金属(銀や銅など)がイオンとして溶け出して移動し、樹枝状に析出して短絡を起こす現象を何と呼ぶか。
