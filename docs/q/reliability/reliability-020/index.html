信頼性

宇宙線に由来する中性子によるソフトエラーの発生率が高くなる環境として正しいものはどれか。

  1. A地下深くの施設
  2. B標高の高い場所や航空機の中
  3. C水中
答えと解説を見る

正解：B. 標高の高い場所や航空機の中

宇宙線が大気と衝突して生じる中性子は、高度が高いほど多くなります。そのため、標高の高い場所や航空機の中ではソフトエラーの発生率が地上より高くなります。航空機や宇宙機器、データセンターなどでは、誤り訂正や冗長化などの対策がとられます。

信頼性のほかの問題

  1. 車載用の集積回路の信頼性試験の基準として広く使われている規格はどれか。
  2. 故障率λが一定のとき、時間tまで故障しない確率(信頼度)R(t)を表す式はどれか。
  3. 故障率が一定で1×10⁻⁵ /時間の部品の平均故障時間(MTTF)はいくらか。
  4. 信頼度0.9の部品を2つ並列に接続し、どちらか一方が動作すれば機能するシステムの信頼度はいくらか。
  5. 信頼度0.9の部品を2つ直列に接続し、両方が動作しないと機能しないシステムの信頼度はいくらか。
