信頼性

BTIの劣化について、ストレスを取り去るとしきい値電圧の変化が一部もとに戻ることによる評価上の注意点として正しいものはどれか。

  1. A測定時間は結果に影響しない
  2. Bストレスをやめてから測定するまでの時間で結果が変わるため、測定を素早く行ったり条件をそろえたりする必要がある
  3. Cもとに戻るので劣化は気にしなくてよい
答えと解説を見る

正解：B. ストレスをやめてから測定するまでの時間で結果が変わるため、測定を素早く行ったり条件をそろえたりする必要がある

BTIでは、ストレスを止めると捕獲された電荷の一部が放出され、しきい値電圧の変化がマイクロ秒〜秒の単位で少しずつ回復します。そのため、ストレスを止めてから測るまでの時間が長いと劣化を小さく見積もってしまいます。ストレスを止めずに測る方法やマイクロ秒単位の高速な測定法を使い、実際の回路のオン・オフの繰り返しによる回復も考慮して評価します。回復は一部で、劣化は残ります。

  • A. 回復があるため、測定時間は結果に影響します。
  • B. 正しい。回復のため測定のタイミングに注意が必要です。
  • C. 回復は一部で、劣化は残ります。

信頼性のほかの問題

  1. 宇宙線の中性子によるソフトエラーの起こりやすさを評価するため、実際の環境よりはるかに強い中性子を当てて短時間で測る方法として正しいものはどれか。
  2. TDDBの試験結果を使用電圧に外挿するときのモデルとして、寿命を電界に対して指数関数で表すEモデルと、電界の逆数に対して指数関数で表す1/Eモデルがある。両者の違いについて正しいものはどれか。
  3. 故障率の時間変化を表すバスタブ曲線を構成する3つの期間の組み合わせとして正しいものはどれか。
  4. エレクトロマイグレーションの説明として正しいものはどれか。
  5. MTBF(平均故障間隔)の説明として正しいものはどれか。
