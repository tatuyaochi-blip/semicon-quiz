信頼性

故障解析を行うときの一般的な進め方として正しいものはどれか。

  1. A最初にパッケージを壊して内部を観察する
  2. B故障品はすぐに廃棄して新しいものを調べる
  3. C外観観察やX線透視、電気測定などの非破壊解析を先に行い、その後に開封や断面観察などの破壊解析を行う
答えと解説を見る

正解：C. 外観観察やX線透視、電気測定などの非破壊解析を先に行い、その後に開封や断面観察などの破壊解析を行う

破壊解析を先に行うと、故障の痕跡が失われて原因がわからなくなるおそれがあります。そのため、まず外観観察、X線透視、超音波探傷、電気特性の測定などの非破壊解析で故障箇所を絞り込み、その後に開封や断面観察などの破壊解析を行います。

この分野を解く 分野ページへ

信頼性のほかの問題

  1. 金ワイヤとアルミパッドの接合部で、高温で長時間保存すると金属間化合物やボイドが成長して接合強度が低下する現象の通称はどれか。
  2. 宇宙線に由来する中性子によるソフトエラーの発生率が高くなる環境として正しいものはどれか。
  3. 車載用の集積回路の信頼性試験の基準として広く使われている規格はどれか。
  4. 故障率λが一定のとき、時間tまで故障しない確率(信頼度)R(t)を表す式はどれか。
  5. 故障率が一定で1×10⁻⁵ /時間の部品の平均故障時間(MTTF)はいくらか。
