信頼性

故障率の時間変化を表すバスタブ曲線を構成する3つの期間の組み合わせとして正しいものはどれか。

  1. A初期故障期・偶発故障期・摩耗故障期
  2. B設計期・製造期・出荷期
  3. C試作期・量産期・保守期
答えと解説を見る

正解：A. 初期故障期・偶発故障期・摩耗故障期

バスタブ曲線は、使い始めに製造上の欠陥で故障率が高い初期故障期、故障率が低く一定に近い偶発故障期、劣化によって故障率が上がる摩耗故障期の3つからなり、形が浴槽の断面に似ています。初期故障はバーンインなどで出荷前に取り除き、摩耗故障は製品の想定寿命より後に起こるように設計します。設計・製造・出荷などは製品のライフサイクルの段階で、故障率の期間ではありません。
