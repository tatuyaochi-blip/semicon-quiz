信頼性

MTBF(平均故障間隔)の説明として正しいものはどれか。

  1. A故障してから修理が完了するまでの平均時間
  2. B最初の故障が起きるまでの最短時間
  3. C修理可能なシステムで、故障から次の故障までの平均動作時間
答えと解説を見る

正解：C. 修理可能なシステムで、故障から次の故障までの平均動作時間

MTBF(Mean Time Between Failures)は、修理しながら使うシステムで、故障と故障の間の平均動作時間を表します。大きいほど信頼性が高いことを示します。故障から修理完了までの平均時間はMTTR、修理しない部品などの故障までの平均時間はMTTFと呼びます。

信頼性のほかの問題

  2. TDDB(経時絶縁破壊)の説明として正しいものはどれか。
  3. 故障率の単位FITの意味として正しいものはどれか。
  4. 温度サイクル試験で主に評価する故障はどれか。
  5. ESD(静電気放電)対策としてLSIの入出力端子に設けるものはどれか。
