信頼性

高温高湿バイアス試験(THBやHAST)で主に評価する故障はどれか。

  1. A宇宙線によるソフトエラー
  2. Bクロックの遅れ
  3. C水分の侵入による電極の腐食やリーク電流の増加
答えと解説を見る

正解：C. 水分の侵入による電極の腐食やリーク電流の増加

高温高湿の環境で電圧をかけると、パッケージ内に侵入した水分によって、アルミパッドの腐食やイオンの移動(マイグレーション)が起こり、リーク電流の増加や断線を招きます。HASTは、高い圧力をかけて水分の侵入を加速し、短時間で耐湿性を評価する試験です。

信頼性のほかの問題

  1. 信頼性データの解析によく使われ、形状パラメータの値によって初期故障型・偶発故障型・摩耗故障型を表せる分布はどれか。
  2. 電流が流れていなくても、配線内部の応力によって金属原子が移動し、ボイドが発生する現象はどれか。
  3. スズめっきの表面から針状の金属結晶が成長し、隣の端子と短絡する現象を何と呼ぶか。
  4. 製品を高温で長時間動作させ、寿命や故障率を評価する代表的な信頼性試験はどれか。
  5. 活性化エネルギー0.7 eVの故障メカニズムについて、アレニウスモデルで55 ℃に対する125 ℃の加速係数を求めるとおよそいくらか。(ボルツマン定数 8.6×10⁻⁵ eV/K)
