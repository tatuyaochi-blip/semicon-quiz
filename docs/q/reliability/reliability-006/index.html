信頼性

故障率の単位FITの意味として正しいものはどれか。

  1. A10億(10⁹)デバイス時間あたり1件の故障
  2. B1年に1件の故障
  3. C1万時間あたり1件の故障
答えと解説を見る

正解：A. 10億(10⁹)デバイス時間あたり1件の故障

1 FITは、10⁹デバイス時間あたり1件の故障が起こる故障率です。例えば100 FITの部品を100万個、1万時間使うと、10⁶ × 10⁴ × 100 / 10⁹ = 1000件の故障が見込まれます。半導体のような故障率の低い部品の評価に使われる単位です。

信頼性のほかの問題

  1. 温度サイクル試験で主に評価する故障はどれか。
  2. ESD(静電気放電)対策としてLSIの入出力端子に設けるものはどれか。
  3. pMOSトランジスタに負のゲート電圧と高温が加わり続けると、しきい値電圧の絶対値が徐々に増加していく劣化現象はどれか。
  4. CMOS回路のラッチアップの説明として正しいものはどれか。
  5. ドレイン近くの高電界で加速されたキャリアがゲート絶縁膜に注入され、トランジスタの特性が劣化する現象はどれか。
