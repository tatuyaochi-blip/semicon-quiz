信頼性

市場で使われている製品の故障(フィールド故障)の情報を集めて解析する主な目的はどれか。

  1. A製品の価格を上げるため
  2. B試験を一切しなくてよくするため
  3. C実際の使用条件での故障の傾向をつかみ、設計・製造・試験の条件の改善につなげるため
答えと解説を見る

正解：C. 実際の使用条件での故障の傾向をつかみ、設計・製造・試験の条件の改善につなげるため

信頼性試験は実際の使用条件を模擬したものにすぎず、市場では想定外の使われ方や環境で故障が起こることがあります。返品された故障品を解析し、故障率や故障モードの傾向をつかむことで、設計や製造工程、試験条件の改善に役立てます。同じロットや装置で作られた他の製品への影響を調べ、必要なら出荷を止める判断にもつながります。

  • A. 価格を上げることが目的ではありません。
  • B. フィールドの情報があっても、出荷前の試験は必要です。
  • C. 正しい。実際の故障の傾向をつかんで改善に役立てます。

信頼性のほかの問題

  1. ESD(静電気放電)の耐性を評価する試験モデルで、「帯電した人がICの端子に触れたときの放電」と「IC自体が帯電していて端子が金属に触れたときの放電」の呼び方の組み合わせとして正しいものはどれか。
  2. 温度に加えて、湿度や電圧などの複数のストレスの影響を含めて寿命の加速を表す、熱力学にもとづくモデルはどれか。
  3. 温度サイクルによるはんだ接合の疲労寿命を、温度変化の幅(ひずみの大きさ)と繰り返しの回数の関係で表すモデルはどれか。
  4. エレクトロマイグレーションの寿命試験で、多数の配線の故障までの時間の分布を表すのによく使われる統計分布はどれか。
  5. 車載用などで、製品が寿命の間にどのような温度・電圧・動作時間の条件にさらされるかをまとめた想定のことを何と呼ぶか。
