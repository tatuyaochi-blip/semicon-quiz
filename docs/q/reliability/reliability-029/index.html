信頼性

非常に低い故障率を統計的に保証するための信頼性試験の条件として適切なものはどれか。

  1. A多くのサンプルを長い時間試験し、加速条件も利用する
  2. Bサンプルを1個だけ短時間試験する
  3. C試験を行わずに保証する
答えと解説を見る

正解：A. 多くのサンプルを長い時間試験し、加速条件も利用する

故障率が非常に低い場合、少数のサンプルを短時間試験しただけでは故障が起こらず、統計的に意味のある結論を出せません。多くのサンプルを長時間試験し、温度や電圧による加速を利用して、信頼水準を考慮しながら故障率の上限を推定します。

信頼性のほかの問題

  1. 薄いゲート酸化膜で、完全に絶縁が失われる前に、リーク電流が段階的に増える軽い破壊を何と呼ぶか。
  2. 故障率の時間変化を表すバスタブ曲線を構成する3つの期間の組み合わせとして正しいものはどれか。
  3. エレクトロマイグレーションの説明として正しいものはどれか。
  4. MTBF(平均故障間隔)の説明として正しいものはどれか。
  5. 温度を上げて寿命試験の時間を短縮する加速試験で、温度と寿命の関係を表すためによく使われるモデルはどれか。
