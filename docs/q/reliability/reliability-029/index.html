信頼性

非常に低い故障率を統計的に保証するための信頼性試験の条件として適切なものはどれか。

  1. A多くのサンプルを長い時間試験し、加速条件も利用する
  2. Bサンプルを1個だけ短時間試験する
  3. C試験を行わずに保証する
答えと解説を見る

正解：A. 多くのサンプルを長い時間試験し、加速条件も利用する

故障率が非常に低い場合、少数のサンプルを短時間試験しただけでは故障が起こらず、統計的に意味のある結論を出せません。多くのサンプルを長時間試験し、温度や電圧による加速を利用して、信頼水準を考慮しながら故障率の上限を推定します。例えば1000個を1000時間、加速係数80で試験して故障0なら、信頼水準60%で故障率は約12 FIT以下といえます。

信頼性のほかの問題

  1. 薄いゲート酸化膜で、完全に絶縁が失われる前に、リーク電流が段階的に増える軽い破壊を何と呼ぶか。
  2. 故障の分類で、「機能が突然まったく失われる故障」と「特性が少しずつ変化して規格を外れる故障」の呼び方の組み合わせとして正しいものはどれか。
  3. 一般的な民生用の半導体製品で、信頼性の設計で想定されることの多い使用期間の目安として最も近いものはどれか。
  4. 同じ半導体でも、民生機器用と自動車用で求められる信頼性の水準についての説明として正しいものはどれか。
  5. 多くの化学反応や劣化の目安としてよく使われる「温度が10℃上がると反応の速さがおよそ2倍になる」という経験則から考えると、使用温度を10℃下げたときの寿命はおよそどうなるか。
