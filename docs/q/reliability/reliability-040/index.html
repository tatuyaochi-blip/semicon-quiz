信頼性

車載用などで、製品が寿命の間にどのような温度・電圧・動作時間の条件にさらされるかをまとめた想定のことを何と呼ぶか。

  1. Aミッションプロファイル
  2. Bデータシート
  3. Cネットリスト
答えと解説を見る

正解：A. ミッションプロファイル

ミッションプロファイルは、製品が使われる期間中に、どの温度で何時間、どの電圧で動作し、何回の温度サイクルを受けるかといった使用条件の想定です。これをもとに必要な信頼性試験の条件や設計の余裕を決めます。

  • A. 正しい。寿命中の使用条件の想定です。
  • B. データシートは製品の仕様をまとめた資料です。
  • C. ネットリストは回路の接続関係を表したデータです。
この分野を解く 分野ページへ

信頼性のほかの問題

  1. 故障率が100 FITの部品を10,000個使ったとき、1年間(約8,760時間)に故障する数の期待値に最も近いものはどれか。(1 FIT = 10⁹時間あたり1件の故障)
  2. プリント基板などで、湿気のある環境で電圧がかかった電極の間に、金属(銀や銅など)がイオンとして溶け出して移動し、樹枝状に析出して短絡を起こす現象を何と呼ぶか。
  3. High-k/メタルゲートのnMOSトランジスタで、ゲートに正の電圧と高温が加わり続けるとしきい値電圧が変化していく劣化を何と呼ぶか。
  4. 先端のLSIの設計で、トランジスタが使用期間中にBTIやHCIで劣化することを見込んで、劣化後の特性でもタイミングを満たすか確認する取り組みを何と呼ぶか。
  5. 高温高湿試験の結果から実使用の寿命を推定するとき、湿度の影響を相対湿度のべき乗で表すモデルとしてよく使われるものはどれか。
