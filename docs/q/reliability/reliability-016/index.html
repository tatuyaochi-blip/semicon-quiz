信頼性

製品を高温で長時間動作させ、寿命や故障率を評価する代表的な信頼性試験はどれか。

  1. A温度サイクル試験
  2. B高温動作寿命試験(HTOL)
  3. C落下試験
答えと解説を見る

正解：B. 高温動作寿命試験(HTOL)

HTOL(High Temperature Operating Life)試験は、製品を125 ℃前後の高温で、定格以上の電圧をかけて長時間動作させ、故障の発生を調べる試験です。車載用のAEC-Q100では、3ロットから77個ずつを1000時間試験し、故障0を求めます。温度と電圧による加速を利用して、短い試験時間で実使用での寿命や故障率を推定します。温度サイクル試験は接合の疲労、落下試験は衝撃への強さを評価します。

信頼性のほかの問題

  1. 活性化エネルギー0.7 eVの故障メカニズムについて、アレニウスモデルで55 ℃に対する125 ℃の加速係数を求めるとおよそいくらか。(ボルツマン定数 8.6×10⁻⁵ eV/K)
  2. 故障解析を行うときの一般的な進め方として正しいものはどれか。
  3. 金ワイヤとアルミパッドの接合部で、高温で長時間保存すると金属間化合物やボイドが成長して接合強度が低下する現象の通称はどれか。
  4. 宇宙線に由来する中性子によるソフトエラーの発生率が高くなる環境として正しいものはどれか。
  5. 車載用の集積回路の信頼性試験の基準として広く使われている規格はどれか。
