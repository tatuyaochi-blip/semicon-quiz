信頼性

高温高湿試験の結果から実使用の寿命を推定するとき、湿度の影響を相対湿度のべき乗で表すモデルとしてよく使われるものはどれか。

  1. Aペックのモデル
  2. Bデナードのスケーリング則
  3. Cショックレーの式
答えと解説を見る

正解：A. ペックのモデル

ペックのモデルは、寿命が相対湿度RHのべき乗(RH^(−n)、nはおよそ3程度)とアレニウス型の温度の項の積で決まるとするモデルです。85 ℃/85%RHやHASTなどの加速試験の結果を、実際の温度・湿度の環境での寿命に換算するのに使われます。例えばn=3なら、湿度が85%から40%に下がるだけで寿命は約10倍になります。デナードの則とショックレーの式は別の分野の式です。

  • A. 正しい。湿度をべき乗で表す加速モデルです。
  • B. デナードのスケーリング則は微細化の指針です。
  • C. ショックレーの式はダイオードの電流の式です。

信頼性のほかの問題

  1. ゲート絶縁膜の絶縁破壊の寿命について、試験に使う素子の面積と、実際のチップ全体のゲートの面積の違いを考える必要がある理由として正しいものはどれか。
  2. フリップチップのはんだバンプで、大きな電流によってエレクトロマイグレーションが問題になるとき、特に故障が起こりやすい場所として知られているのはどこか。
  3. BTIの劣化について、ストレスを取り去るとしきい値電圧の変化が一部もとに戻ることによる評価上の注意点として正しいものはどれか。
  4. 宇宙線の中性子によるソフトエラーの起こりやすさを評価するため、実際の環境よりはるかに強い中性子を当てて短時間で測る方法として正しいものはどれか。
  5. TDDBの試験結果を使用電圧に外挿するときのモデルとして、寿命を電界に対して指数関数で表すEモデルと、電界の逆数に対して指数関数で表す1/Eモデルがある。両者の違いについて正しいものはどれか。
