信頼性

ゲート絶縁膜の絶縁破壊の寿命について、試験に使う素子の面積と、実際のチップ全体のゲートの面積の違いを考える必要がある理由として正しいものはどれか。

  1. A面積は寿命に関係しないため
  2. B面積が大きいほど寿命が必ず長くなるため
  3. C破壊は弱い場所から起こるため、面積が大きいほど早く破壊する確率が高くなり、ワイブル分布にもとづく面積の換算が必要になるため
答えと解説を見る

正解：C. 破壊は弱い場所から起こるため、面積が大きいほど早く破壊する確率が高くなり、ワイブル分布にもとづく面積の換算が必要になるため

絶縁破壊は、膜の中で最も弱い場所で最初に起こる(最弱リンク)と考えられます。面積が大きいほど弱い場所を含む確率が高くなり、寿命は短くなります。ワイブル分布では寿命が面積の−1/m乗に比例するため、例えば傾きm=1.5で面積が1000倍になると寿命は1/100になります。この関係で小さな試験素子の結果をチップ全体のゲートの面積に換算して、製品の寿命を見積もります。

  • A. 面積は寿命に大きく関係します。
  • B. 面積が大きいほど寿命は短くなる方向です。
  • C. 正しい。面積が大きいほど早く破壊しやすく、換算が必要です。
