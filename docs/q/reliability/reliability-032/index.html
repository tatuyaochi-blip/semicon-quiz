信頼性

一般的な民生用の半導体製品で、信頼性の設計で想定されることの多い使用期間の目安として最も近いものはどれか。

  1. A約1週間
  2. B約10年
  3. C約1,000年
答えと解説を見る

正解：B. 約10年

多くの半導体製品は、決められた使用条件で10年程度は故障率を十分低く保つことを目標に設計・評価されます。車載用などではさらに長い期間や厳しい条件が求められます。この期間の劣化を、加速試験とモデルを使って短い試験時間から推定します。

  • A. 約1週間では製品として短すぎます。
  • B. 正しい。10年程度を想定することが多くあります。
  • C. 約1,000年を保証する設計は現実的ではありません。

信頼性のほかの問題

  1. 同じ半導体でも、民生機器用と自動車用で求められる信頼性の水準についての説明として正しいものはどれか。
  2. 多くの化学反応や劣化の目安としてよく使われる「温度が10℃上がると反応の速さがおよそ2倍になる」という経験則から考えると、使用温度を10℃下げたときの寿命はおよそどうなるか。
  3. 市場で使われている製品の故障(フィールド故障)の情報を集めて解析する主な目的はどれか。
  4. ESD(静電気放電)の耐性を評価する試験モデルで、「帯電した人がICの端子に触れたときの放電」と「IC自体が帯電していて端子が金属に触れたときの放電」の呼び方の組み合わせとして正しいものはどれか。
  5. 温度に加えて、湿度や電圧などの複数のストレスの影響を含めて寿命の加速を表す、熱力学にもとづくモデルはどれか。
