信頼性

スズめっきの表面から針状の金属結晶が成長し、隣の端子と短絡する現象を何と呼ぶか。

  1. Aヒロック
  2. Bボイド
  3. Cウィスカ
答えと解説を見る

正解：C. ウィスカ

ウィスカは、スズめっきなどの表面から、内部の圧縮応力などによって直径数µmの細い針状の結晶が成長する現象で、数mmまで伸びることもあります。隣の端子に接触して短絡を起こします。鉛を加えたスズ-鉛めっきでは抑えられていたため、鉛フリー化で改めて問題になりました。めっき後の熱処理、ニッケルの下地、めっきの組成の工夫などで抑えます。ヒロックは配線の突起、ボイドは空洞です。

信頼性のほかの問題

  1. 製品を高温で長時間動作させ、寿命や故障率を評価する代表的な信頼性試験はどれか。
  2. 活性化エネルギー0.7 eVの故障メカニズムについて、アレニウスモデルで55 ℃に対する125 ℃の加速係数を求めるとおよそいくらか。(ボルツマン定数 8.6×10⁻⁵ eV/K)
  3. 故障解析を行うときの一般的な進め方として正しいものはどれか。
  4. 金ワイヤとアルミパッドの接合部で、高温で長時間保存すると金属間化合物やボイドが成長して接合強度が低下する現象の通称はどれか。
  5. 宇宙線に由来する中性子によるソフトエラーの発生率が高くなる環境として正しいものはどれか。
