信頼性

故障率が一定で1×10⁻⁵ /時間の部品の平均故障時間(MTTF)はいくらか。

  1. A1×10³時間
  2. B1×10⁵時間
  3. C1×10⁷時間
答えと解説を見る

正解：B. 1×10⁵時間

故障率が一定のとき、平均故障時間は故障率の逆数になります。1 ÷ (1×10⁻⁵) = 1×10⁵時間、つまり約11年です。ただし、これは偶発故障期についての値で、摩耗故障が始まる時期を表すものではありません。

この分野を解く 分野ページへ

信頼性のほかの問題

  1. 信頼度0.9の部品を2つ並列に接続し、どちらか一方が動作すれば機能するシステムの信頼度はいくらか。
  2. 信頼度0.9の部品を2つ直列に接続し、両方が動作しないと機能しないシステムの信頼度はいくらか。
  3. TDDBの寿命評価で、実際の使用電圧より高い電圧をかけて試験する理由として正しいものはどれか。
  4. スマートフォンなどの携帯機器で、はんだ接合部の信頼性の評価として特に重視される試験はどれか。
  5. エレクトロマイグレーションで配線にヒロック(突起)が生じたときに起こりうる故障はどれか。
