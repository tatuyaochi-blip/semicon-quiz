信頼性

スマートフォンなどの携帯機器で、はんだ接合部の信頼性の評価として特に重視される試験はどれか。

  1. AHTOL(高温動作寿命試験)
  2. BIDDQテスト
  3. C落下衝撃試験
答えと解説を見る

正解：C. 落下衝撃試験

携帯機器は落としたときの衝撃で、基板がたわみ、BGAなどのはんだ接合部が割れることがあります。そのため、基板に実装した状態で落下の衝撃を繰り返し加え、接合部の破断を評価する落下衝撃試験が重視されます。

信頼性のほかの問題

  1. エレクトロマイグレーションで配線にヒロック(突起)が生じたときに起こりうる故障はどれか。
  2. 非常に低い故障率を統計的に保証するための信頼性試験の条件として適切なものはどれか。
  3. 薄いゲート酸化膜で、完全に絶縁が失われる前に、リーク電流が段階的に増える軽い破壊を何と呼ぶか。
  4. 故障率の時間変化を表すバスタブ曲線を構成する3つの期間の組み合わせとして正しいものはどれか。
  5. エレクトロマイグレーションの説明として正しいものはどれか。
