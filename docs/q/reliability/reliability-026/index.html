信頼性

TDDBの寿命評価で、実際の使用電圧より高い電圧をかけて試験する理由として正しいものはどれか。

  1. A故障を加速させ、短い時間で寿命を推定するため
  2. B使用電圧では故障が起こらないことを確認するため
  3. C試験装置を壊さないため
答えと解説を見る

正解：A. 故障を加速させ、短い時間で寿命を推定するため

実際の使用電圧では、TDDBによる故障が起こるまでに何年もかかります。高い電圧(と高い温度)をかけると故障が早く起こるため、その結果と電圧依存性のモデルを使って、実際の使用条件での寿命を推定します。適切な加速モデルの選択が重要です。

信頼性のほかの問題

  1. スマートフォンなどの携帯機器で、はんだ接合部の信頼性の評価として特に重視される試験はどれか。
  2. エレクトロマイグレーションで配線にヒロック(突起)が生じたときに起こりうる故障はどれか。
  3. 非常に低い故障率を統計的に保証するための信頼性試験の条件として適切なものはどれか。
  4. 薄いゲート酸化膜で、完全に絶縁が失われる前に、リーク電流が段階的に増える軽い破壊を何と呼ぶか。
  5. 故障率の時間変化を表すバスタブ曲線を構成する3つの期間の組み合わせとして正しいものはどれか。
