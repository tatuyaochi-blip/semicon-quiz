信頼性

温度サイクルによるはんだ接合の疲労寿命を、温度変化の幅(ひずみの大きさ)と繰り返しの回数の関係で表すモデルはどれか。

  1. Aコフィン・マンソン則
  2. Bブラックの式
  3. Cムーアの法則
答えと解説を見る

正解：A. コフィン・マンソン則

コフィン・マンソン則は、繰り返し加わるひずみの大きさと、疲労で破壊するまでの繰り返し回数の関係を表すもので、温度変化の幅が大きいほど寿命の回数が少なくなります。温度サイクル試験の結果から、実際の使用環境での寿命を推定するのに使われます。

  • A. 正しい。温度変化の幅と疲労寿命の関係を表します。
  • B. ブラックの式はエレクトロマイグレーションの寿命の式です。
  • C. ムーアの法則は集積度の向上に関する経験則です。

信頼性のほかの問題

  1. エレクトロマイグレーションの寿命試験で、多数の配線の故障までの時間の分布を表すのによく使われる統計分布はどれか。
  2. 車載用などで、製品が寿命の間にどのような温度・電圧・動作時間の条件にさらされるかをまとめた想定のことを何と呼ぶか。
  3. 故障率が100 FITの部品を10,000個使ったとき、1年間(約8,760時間)に故障する数の期待値に最も近いものはどれか。(1 FIT = 10⁹時間あたり1件の故障)
  4. プリント基板などで、湿気のある環境で電圧がかかった電極の間に、金属(銀や銅など)がイオンとして溶け出して移動し、樹枝状に析出して短絡を起こす現象を何と呼ぶか。
  5. High-k/メタルゲートのnMOSトランジスタで、ゲートに正の電圧と高温が加わり続けるとしきい値電圧が変化していく劣化を何と呼ぶか。
