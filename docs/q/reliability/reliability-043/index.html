信頼性

High-k/メタルゲートのnMOSトランジスタで、ゲートに正の電圧と高温が加わり続けるとしきい値電圧が変化していく劣化を何と呼ぶか。

  1. Aラッチアップ
  2. BPBTI(正バイアス温度不安定性)
  3. Cエレクトロマイグレーション
答えと解説を見る

正解：B. PBTI(正バイアス温度不安定性)

PBTIは、nMOSに正のゲート電圧と高温が加わることで、High-k膜の中の欠陥に電子が捕獲され、しきい値電圧が上がっていく劣化です。SiO2のゲート絶縁膜では小さかったものの、High-k材料の導入で問題になりました。pMOSで起こるNBTIと対になる現象です。

  • A. ラッチアップは寄生サイリスタによる大電流の現象です。
  • B. 正しい。nMOSで起こる正バイアスの温度不安定性です。
  • C. エレクトロマイグレーションは配線の金属原子の移動です。
この分野を解く 分野ページへ

信頼性のほかの問題

  1. 先端のLSIの設計で、トランジスタが使用期間中にBTIやHCIで劣化することを見込んで、劣化後の特性でもタイミングを満たすか確認する取り組みを何と呼ぶか。
  2. 高温高湿試験の結果から実使用の寿命を推定するとき、湿度の影響を相対湿度のべき乗で表すモデルとしてよく使われるものはどれか。
  3. ゲート絶縁膜の絶縁破壊の寿命について、試験に使う素子の面積と、実際のチップ全体のゲートの面積の違いを考える必要がある理由として正しいものはどれか。
  4. フリップチップのはんだバンプで、大きな電流によってエレクトロマイグレーションが問題になるとき、特に故障が起こりやすい場所として知られているのはどこか。
  5. BTIの劣化について、ストレスを取り去るとしきい値電圧の変化が一部もとに戻ることによる評価上の注意点として正しいものはどれか。
