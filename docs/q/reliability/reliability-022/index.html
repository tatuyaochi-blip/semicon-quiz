信頼性

故障率λが一定のとき、時間tまで故障しない確率(信頼度)R(t)を表す式はどれか。

  1. Aλt
  2. B1 / (λt)
  3. Cexp(−λt)
答えと解説を見る

正解：C. exp(−λt)

故障率が一定の偶発故障期では、故障までの時間は指数分布に従い、信頼度はR(t)=exp(−λt)と表されます。このとき平均故障時間(MTTF)は1/λで、t=MTTFでの信頼度はexp(−1)≈37%にすぎません。つまり、平均故障時間まで使うと6割以上が故障しています。λtはλtが小さいときの故障する確率の近似で、1/(λt)は意味のある式ではありません。
