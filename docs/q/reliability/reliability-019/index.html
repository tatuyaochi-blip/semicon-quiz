信頼性

金ワイヤとアルミパッドの接合部で、高温で長時間保存すると金属間化合物やボイドが成長して接合強度が低下する現象の通称はどれか。

  1. Aパープルプレーグ
  2. Bウィスカ
  3. Cポップコーン現象
答えと解説を見る

正解：A. パープルプレーグ

金とアルミニウムの接合部では、高温で金属間化合物が成長し、その過程で原子の拡散速度の違いからボイドができて、接合が弱くなったり抵抗が上がったりします。化合物の一つが紫色に見えることからパープルプレーグと呼ばれます。

信頼性のほかの問題

  1. 宇宙線に由来する中性子によるソフトエラーの発生率が高くなる環境として正しいものはどれか。
  2. 車載用の集積回路の信頼性試験の基準として広く使われている規格はどれか。
  3. 故障率λが一定のとき、時間tまで故障しない確率(信頼度)R(t)を表す式はどれか。
  4. 故障率が一定で1×10⁻⁵ /時間の部品の平均故障時間(MTTF)はいくらか。
  5. 信頼度0.9の部品を2つ並列に接続し、どちらか一方が動作すれば機能するシステムの信頼度はいくらか。
