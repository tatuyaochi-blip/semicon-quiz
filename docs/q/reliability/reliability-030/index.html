信頼性

薄いゲート酸化膜で、完全に絶縁が失われる前に、リーク電流が段階的に増える軽い破壊を何と呼ぶか。

  1. Aハードブレークダウン
  2. Bエレクトロマイグレーション
  3. Cソフトブレークダウン
答えと解説を見る

正解：C. ソフトブレークダウン

非常に薄いゲート酸化膜では、ストレスを加え続けると、まず局所的な導電経路ができてリーク電流が段階的に増えるソフトブレークダウンが起こることがあります。その後、完全に絶縁が失われるハードブレークダウンに進む場合があります。回路によってはソフトブレークダウン後も動作を続けられます。

  2. エレクトロマイグレーションの説明として正しいものはどれか。
  3. MTBF(平均故障間隔)の説明として正しいものはどれか。
  4. 温度を上げて寿命試験の時間を短縮する加速試験で、温度と寿命の関係を表すためによく使われるモデルはどれか。
  5. TDDB(経時絶縁破壊)の説明として正しいものはどれか。
