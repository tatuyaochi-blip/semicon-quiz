信頼性

エレクトロマイグレーションの説明として正しいものはどれか。

  1. A湿気によって配線が腐食する現象
  2. B電流によって配線の金属原子が移動し、ボイドやヒロックが生じる現象
  3. C静電気放電によって素子が破壊される現象
答えと解説を見る

正解：B. 電流によって配線の金属原子が移動し、ボイドやヒロックが生じる現象

エレクトロマイグレーションは、配線を流れる電子が金属原子に衝突して運動量を与え、原子を少しずつ電子の流れの向きに移動させる現象です。原子が抜けたところにボイドができて断線し、たまったところにヒロックができて隣の配線と短絡します。寿命はブラックの式で、電流密度のおよそ2乗に反比例し、温度が高いほど短くなります。湿気による腐食や静電気による破壊は別の故障です。
