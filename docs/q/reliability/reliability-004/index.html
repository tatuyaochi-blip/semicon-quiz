信頼性

温度を上げて寿命試験の時間を短縮する加速試験で、温度と寿命の関係を表すためによく使われるモデルはどれか。

  1. Aムーアの法則
  2. Bアレニウスモデル
  3. Cオームの法則
答えと解説を見る

正解：B. アレニウスモデル

アレニウスモデルは、劣化の反応速度が exp(−Ea / kT)(Ea:活性化エネルギー)に比例するという考え方で、温度を上げると寿命が指数関数的に短くなることを表します。高温で試験した結果から、実際の使用温度での寿命を推定するのに使われます。
