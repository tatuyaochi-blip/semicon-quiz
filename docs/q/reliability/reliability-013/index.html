信頼性

信頼性データの解析によく使われ、形状パラメータの値によって初期故障型・偶発故障型・摩耗故障型を表せる分布はどれか。

  1. Aワイブル分布
  2. B一様分布
  3. C二項分布
答えと解説を見る

正解：A. ワイブル分布

ワイブル分布は、形状パラメータmが1より小さいと故障率が時間とともに減る初期故障型、1で一定の偶発故障型、1より大きいと増える摩耗故障型を表します。故障データをワイブル確率紙などにプロットして、故障の傾向や寿命を推定します。

信頼性のほかの問題

  1. 電流が流れていなくても、配線内部の応力によって金属原子が移動し、ボイドが発生する現象はどれか。
  2. スズめっきの表面から針状の金属結晶が成長し、隣の端子と短絡する現象を何と呼ぶか。
  3. 製品を高温で長時間動作させ、寿命や故障率を評価する代表的な信頼性試験はどれか。
  4. 活性化エネルギー0.7 eVの故障メカニズムについて、アレニウスモデルで55 ℃に対する125 ℃の加速係数を求めるとおよそいくらか。(ボルツマン定数 8.6×10⁻⁵ eV/K)
  5. 故障解析を行うときの一般的な進め方として正しいものはどれか。
