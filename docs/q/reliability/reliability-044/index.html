信頼性

先端のLSIの設計で、トランジスタが使用期間中にBTIやHCIで劣化することを見込んで、劣化後の特性でもタイミングを満たすか確認する取り組みを何と呼ぶか。

  1. Aフォトリソグラフィ
  2. Bウエハの再生
  3. Cエージング(劣化)を考慮した信頼性設計
答えと解説を見る

正解：C. エージング(劣化)を考慮した信頼性設計

トランジスタの特性は使用中に少しずつ劣化し、回路が遅くなります。劣化を考慮した信頼性設計では、動作条件から劣化量をモデルで予測し、劣化後の特性で回路シミュレーションやタイミング解析を行って、寿命の終わりまで規格を満たすよう余裕を確保します。

  • A. フォトリソグラフィはパターンを転写する工程です。
  • B. ウエハの再生は使用済みのモニターウエハを再利用することです。
  • C. 正しい。劣化後の特性でも動作するよう設計します。

信頼性のほかの問題

  1. 高温高湿試験の結果から実使用の寿命を推定するとき、湿度の影響を相対湿度のべき乗で表すモデルとしてよく使われるものはどれか。
  2. ゲート絶縁膜の絶縁破壊の寿命について、試験に使う素子の面積と、実際のチップ全体のゲートの面積の違いを考える必要がある理由として正しいものはどれか。
  3. フリップチップのはんだバンプで、大きな電流によってエレクトロマイグレーションが問題になるとき、特に故障が起こりやすい場所として知られているのはどこか。
  4. BTIの劣化について、ストレスを取り去るとしきい値電圧の変化が一部もとに戻ることによる評価上の注意点として正しいものはどれか。
  5. 宇宙線の中性子によるソフトエラーの起こりやすさを評価するため、実際の環境よりはるかに強い中性子を当てて短時間で測る方法として正しいものはどれか。
