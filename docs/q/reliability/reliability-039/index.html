信頼性

エレクトロマイグレーションの寿命試験で、多数の配線の故障までの時間の分布を表すのによく使われる統計分布はどれか。

  1. A二項分布
  2. B対数正規分布
  3. C一様分布
答えと解説を見る

正解：B. 対数正規分布

エレクトロマイグレーションによる故障時間は、時間の対数をとると正規分布に近いばらつき方をすることが多く、対数正規分布で解析されます。試験で得た分布の中央値とばらつきから、ごく一部の配線が早く故障する確率を推定して、設計の電流密度の規則を決めます。

  • A. 二項分布は成功・失敗の回数の分布で、故障時間の分布ではありません。
  • B. 正しい。対数正規分布がよく使われます。
  • C. 一様分布では故障時間のばらつきを表せません。

信頼性のほかの問題

  1. 車載用などで、製品が寿命の間にどのような温度・電圧・動作時間の条件にさらされるかをまとめた想定のことを何と呼ぶか。
  2. 故障率が100 FITの部品を10,000個使ったとき、1年間(約8,760時間)に故障する数の期待値に最も近いものはどれか。(1 FIT = 10⁹時間あたり1件の故障)
  3. プリント基板などで、湿気のある環境で電圧がかかった電極の間に、金属(銀や銅など)がイオンとして溶け出して移動し、樹枝状に析出して短絡を起こす現象を何と呼ぶか。
  4. High-k/メタルゲートのnMOSトランジスタで、ゲートに正の電圧と高温が加わり続けるとしきい値電圧が変化していく劣化を何と呼ぶか。
  5. 先端のLSIの設計で、トランジスタが使用期間中にBTIやHCIで劣化することを見込んで、劣化後の特性でもタイミングを満たすか確認する取り組みを何と呼ぶか。
