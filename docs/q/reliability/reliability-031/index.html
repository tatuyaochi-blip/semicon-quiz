信頼性

故障の分類で、「機能が突然まったく失われる故障」と「特性が少しずつ変化して規格を外れる故障」の呼び方の組み合わせとして正しいものはどれか。

  1. A致命故障(突発故障)と劣化故障
  2. B初期故障と偶発故障
  3. C設計故障と製造故障
答えと解説を見る

正解：A. 致命故障(突発故障)と劣化故障

致命故障(突発故障)は、配線の断線や絶縁膜の破壊などで機能が突然失われる故障です。劣化故障は、しきい値電圧の変化やリーク電流の増加などで特性が少しずつ変わり、やがて規格を外れる故障です。対策や評価の方法が異なるため、区別して扱います。

  • A. 正しい。突然失われる故障と少しずつ劣化する故障です。
  • B. 初期故障と偶発故障は、故障が起こる時期による分類です。
  • C. 設計と製造は故障の原因による分類です。

信頼性のほかの問題

  1. 一般的な民生用の半導体製品で、信頼性の設計で想定されることの多い使用期間の目安として最も近いものはどれか。
  2. 同じ半導体でも、民生機器用と自動車用で求められる信頼性の水準についての説明として正しいものはどれか。
  3. 多くの化学反応や劣化の目安としてよく使われる「温度が10℃上がると反応の速さがおよそ2倍になる」という経験則から考えると、使用温度を10℃下げたときの寿命はおよそどうなるか。
  4. 市場で使われている製品の故障(フィールド故障)の情報を集めて解析する主な目的はどれか。
  5. ESD(静電気放電)の耐性を評価する試験モデルで、「帯電した人がICの端子に触れたときの放電」と「IC自体が帯電していて端子が金属に触れたときの放電」の呼び方の組み合わせとして正しいものはどれか。
