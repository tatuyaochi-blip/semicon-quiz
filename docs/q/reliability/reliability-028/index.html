信頼性

エレクトロマイグレーションで配線にヒロック(突起)が生じたときに起こりうる故障はどれか。

  1. A断線だけ
  2. B隣の配線との短絡(ショート)
  3. Cしきい値電圧の上昇
答えと解説を見る

正解：B. 隣の配線との短絡(ショート)

エレクトロマイグレーションでは、原子が抜けた場所にボイドができて断線の原因になり、原子がたまった場所にはヒロックができて、隣の配線や上下の配線と接触して短絡を起こすことがあります。

この分野を解く 分野ページへ

信頼性のほかの問題

  1. 非常に低い故障率を統計的に保証するための信頼性試験の条件として適切なものはどれか。
  2. 薄いゲート酸化膜で、完全に絶縁が失われる前に、リーク電流が段階的に増える軽い破壊を何と呼ぶか。
  3. 故障の分類で、「機能が突然まったく失われる故障」と「特性が少しずつ変化して規格を外れる故障」の呼び方の組み合わせとして正しいものはどれか。
  4. 一般的な民生用の半導体製品で、信頼性の設計で想定されることの多い使用期間の目安として最も近いものはどれか。
  5. 同じ半導体でも、民生機器用と自動車用で求められる信頼性の水準についての説明として正しいものはどれか。
