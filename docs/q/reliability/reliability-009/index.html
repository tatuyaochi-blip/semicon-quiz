信頼性

pMOSトランジスタに負のゲート電圧と高温が加わり続けると、しきい値電圧の絶対値が徐々に増加していく劣化現象はどれか。

  1. ANBTI
  2. Bエレクトロマイグレーション
  3. CESD
答えと解説を見る

正解：A. NBTI

NBTI(Negative Bias Temperature Instability)は、pMOSに負のゲートバイアスと高温が加わることで、Si/SiO2界面のSi-H結合が切れて界面準位が増え、絶縁膜中にも正の電荷がたまって、しきい値電圧の絶対値が大きくなる劣化です。回路の動作速度が年単位で徐々に遅くなるため、設計時に劣化分の余裕を見込みます。ストレスを除くと一部が回復するのも特徴です。

信頼性のほかの問題

  1. CMOS回路のラッチアップの説明として正しいものはどれか。
  2. ドレイン近くの高電界で加速されたキャリアがゲート絶縁膜に注入され、トランジスタの特性が劣化する現象はどれか。
  3. 高温高湿バイアス試験(THBやHAST)で主に評価する故障はどれか。
  4. 信頼性データの解析によく使われ、形状パラメータの値によって初期故障型・偶発故障型・摩耗故障型を表せる分布はどれか。
  5. 電流が流れていなくても、配線内部の応力によって金属原子が移動し、ボイドが発生する現象はどれか。
