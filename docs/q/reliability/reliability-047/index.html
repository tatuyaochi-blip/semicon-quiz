信頼性

フリップチップのはんだバンプで、大きな電流によってエレクトロマイグレーションが問題になるとき、特に故障が起こりやすい場所として知られているのはどこか。

  1. A電流が一点に集中して流れ込む、バンプと配線の接続部の付近
  2. Bバンプの中心で電流がまったく流れない部分
  3. Cパッケージの外側の樹脂
答えと解説を見る

正解：A. 電流が一点に集中して流れ込む、バンプと配線の接続部の付近

はんだバンプでは、細い配線から太いバンプに電流が入る接続部の角で電流密度が局所的に非常に高くなる(電流集中)ため、そこからボイドが発生しやすくなります。また、ジュール熱による温度上昇や、はんだと金属の間の化合物の成長も劣化を加速します。

  • A. 正しい。電流が集中する接続部の付近で故障しやすくなります。
  • B. 電流が流れない部分ではエレクトロマイグレーションは起こりません。
  • C. 樹脂は電流を流しません。
この分野を解く 分野ページへ

信頼性のほかの問題

  1. BTIの劣化について、ストレスを取り去るとしきい値電圧の変化が一部もとに戻ることによる評価上の注意点として正しいものはどれか。
  2. 宇宙線の中性子によるソフトエラーの起こりやすさを評価するため、実際の環境よりはるかに強い中性子を当てて短時間で測る方法として正しいものはどれか。
  3. TDDBの試験結果を使用電圧に外挿するときのモデルとして、寿命を電界に対して指数関数で表すEモデルと、電界の逆数に対して指数関数で表す1/Eモデルがある。両者の違いについて正しいものはどれか。
  4. 故障率の時間変化を表すバスタブ曲線を構成する3つの期間の組み合わせとして正しいものはどれか。
  5. エレクトロマイグレーションの説明として正しいものはどれか。
