信頼性

同じ半導体でも、民生機器用と自動車用で求められる信頼性の水準についての説明として正しいものはどれか。

  1. Aどの用途でもまったく同じである
  2. B自動車用の方がゆるい
  3. C自動車用は広い温度範囲や長い期間で非常に低い故障率が求められ、より厳しい
答えと解説を見る

正解：C. 自動車用は広い温度範囲や長い期間で非常に低い故障率が求められ、より厳しい

自動車用の半導体は、エンジンルームのような高温や寒冷地の低温、振動の中で、十数年以上にわたって使われ、故障が安全に直結します。そのため、民生用より広い温度範囲での動作と、ppbレベルを目指す非常に低い不良率が求められ、AEC-Q100による認定や、機能安全の規格ISO 26262への対応も必要です。民生用と同じでもゆるくもありません。

  • A. 用途によって求められる水準は異なります。
  • B. 安全に関わるため、自動車用の方が厳しくなります。
  • C. 正しい。自動車用はより厳しい信頼性が求められます。
この分野を解く 分野ページへ

信頼性のほかの問題

  1. 多くの化学反応や劣化の目安としてよく使われる「温度が10℃上がると反応の速さがおよそ2倍になる」という経験則から考えると、使用温度を10℃下げたときの寿命はおよそどうなるか。
  2. 市場で使われている製品の故障(フィールド故障)の情報を集めて解析する主な目的はどれか。
  3. ESD(静電気放電)の耐性を評価する試験モデルで、「帯電した人がICの端子に触れたときの放電」と「IC自体が帯電していて端子が金属に触れたときの放電」の呼び方の組み合わせとして正しいものはどれか。
  4. 温度に加えて、湿度や電圧などの複数のストレスの影響を含めて寿命の加速を表す、熱力学にもとづくモデルはどれか。
  5. 温度サイクルによるはんだ接合の疲労寿命を、温度変化の幅(ひずみの大きさ)と繰り返しの回数の関係で表すモデルはどれか。
