信頼性

プリント基板などで、湿気のある環境で電圧がかかった電極の間に、金属(銀や銅など)がイオンとして溶け出して移動し、樹枝状に析出して短絡を起こす現象を何と呼ぶか。

  1. Aエレクトロマイグレーション
  2. Bストレスマイグレーション
  3. Cイオンマイグレーション
答えと解説を見る

正解：C. イオンマイグレーション

イオンマイグレーションは、水分があると電極の金属がイオンになって溶け出し、電界によって反対側の電極へ移動して樹枝状(デンドライト)に析出する現象です。最終的に電極間が短絡します。銀が最も起こりやすく、銅でも起こります。電極の間隔が狭いほど、湿度とハロゲンなどの汚れが多いほど起こりやすく、洗浄や防湿コーティングで防ぎます。金属内の原子の移動であるエレクトロマイグレーションとは異なります。

  • A. エレクトロマイグレーションは金属の中を原子が電流で移動する現象です。
  • B. ストレスマイグレーションは応力による原子の移動です。
  • C. 正しい。水分と電界で金属イオンが移動して短絡を起こす現象です。

信頼性のほかの問題

  1. High-k/メタルゲートのnMOSトランジスタで、ゲートに正の電圧と高温が加わり続けるとしきい値電圧が変化していく劣化を何と呼ぶか。
  2. 先端のLSIの設計で、トランジスタが使用期間中にBTIやHCIで劣化することを見込んで、劣化後の特性でもタイミングを満たすか確認する取り組みを何と呼ぶか。
  3. 高温高湿試験の結果から実使用の寿命を推定するとき、湿度の影響を相対湿度のべき乗で表すモデルとしてよく使われるものはどれか。
  4. ゲート絶縁膜の絶縁破壊の寿命について、試験に使う素子の面積と、実際のチップ全体のゲートの面積の違いを考える必要がある理由として正しいものはどれか。
  5. フリップチップのはんだバンプで、大きな電流によってエレクトロマイグレーションが問題になるとき、特に故障が起こりやすい場所として知られているのはどこか。
