次世代メモリ

銀や銅などの金属イオンが固体電解質の中を移動して導電パスをつくったり切ったりすることで抵抗を変えるメモリはどれか。

  1. ACBRAM(導電性ブリッジメモリ)
  2. BFeRAM
  3. CSTT-MRAM
答えと解説を見る

正解：A. CBRAM(導電性ブリッジメモリ)

CBRAMは、銀や銅などの活性な金属電極から金属イオンが固体電解質層に溶け出し、電圧で反対側の電極へ移動して金属の導電ブリッジを作ったり、逆の電圧で溶かして切ったりして低抵抗と高抵抗を切り替えます。動作電圧が低く、書き込みエネルギーも小さいのが特徴です。酸素欠損を使う酸化物型と並ぶReRAMの一種とされ、低消費電力の組み込みメモリとして製品化されています。

  • A. 正しい。金属イオンによる導電ブリッジを使うメモリです。
  • B. FeRAMは強誘電体の分極で記憶します。
  • C. STT-MRAMは磁化の向きで記憶します。

次世代メモリのほかの問題

  1. ReRAMの動作方式で「バイポーラ型」と「ユニポーラ型」の違いとして正しいものはどれか。
  2. クロスポイント型のPCMなどで、記憶素子と直列に置くセレクタとして使われる、ある電圧を超えると急に導通するカルコゲナイド材料の素子はどれか。
  3. STT-MRAMで、読み出し電流の大きさに制限が必要になる理由として正しいものはどれか。
  4. 強誘電体の分極の向きによって、薄い強誘電体層を通るトンネル電流の大きさが変わることを利用する素子はどれか。
  5. MRAMの書き込みエネルギーを下げる方法として研究されている、電圧で磁性層の磁気異方性を変える効果はどれか。

この分野の比較

  • MRAM・ReRAM・PCM・FeRAMの違い：新規メモリを比較MRAM、ReRAM、PCM、FeRAMを、記憶の原理・書き込み方法・速度・書き換え寿命・集積度・課題・用途の観点で表にして比較します。
