次世代メモリ

MTJで、2つの磁性層の磁化の向きが平行のときと反平行のときの抵抗の関係として正しいものはどれか。

  1. Aどちらも同じ抵抗である
  2. B平行のときの方が抵抗が高い
  3. C平行のときの方が抵抗が低い
答えと解説を見る

正解：C. 平行のときの方が抵抗が低い

磁性体の中では、多数派と少数派のスピンの電子で状態の数が異なります。磁化が平行のときは、両側で多数派どうしが対応するため電子がトンネルしやすく抵抗が低くなり、反平行のときは片側の多数派がもう一方の少数派の状態にしか入れないためトンネルしにくく抵抗が高くなります。この抵抗の違いで0と1を区別します。

  • A. 抵抗が同じでは情報を読み出せません。
  • B. 抵抗が高くなるのは反平行のときです。
  • C. 正しい。平行のときに抵抗が低くなります。
