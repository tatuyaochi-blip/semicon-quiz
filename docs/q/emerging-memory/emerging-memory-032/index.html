次世代メモリ

MRAMの「M」が表すものとして正しいものはどれか。

  1. AMicro(微小)
  2. BMagnetoresistive(磁気抵抗)
  3. CMulti-level(多値)
答えと解説を見る

正解：B. Magnetoresistive(磁気抵抗)

MRAMは Magnetoresistive Random Access Memory の略で、磁化の向きによって抵抗が変わる磁気抵抗効果で情報を読み出します。1990年代はAMR(異方性磁気抵抗)やGMR(巨大磁気抵抗)が使われましたが、抵抗差の大きいTMR(トンネル磁気抵抗)の発展で実用的になりました。GMRの発見は2007年のノーベル物理学賞の対象で、HDDの大容量化にも大きく貢献しました。

  • A. 大きさを表す略語ではありません。
  • B. 正しい。磁気抵抗効果を利用するメモリです。
  • C. 多値記憶を表す略語ではありません。
