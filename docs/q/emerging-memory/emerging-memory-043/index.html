次世代メモリ

かつてIntelとMicronが共同開発し、「Optane」の製品名で販売されたストレージクラスメモリの技術はどれか。

  1. A3D NAND
  2. B3D XPoint
  3. CHBM
答えと解説を見る

正解：B. 3D XPoint

3D XPointは、抵抗変化型の記憶素子とセレクタを縦横の配線の交点に配置して積み重ねたメモリ技術で、DRAMとNANDフラッシュの間を埋めるストレージクラスメモリとして「Optane」の名前で製品化されました。市場の拡大が進まず、製品は2022年に終息が発表されました。

  • A. 3D NANDはセルを縦に積み重ねたフラッシュメモリです。
  • B. 正しい。Optaneは3D XPoint技術による製品です。
  • C. HBMはDRAMを積層した広帯域メモリです。

次世代メモリのほかの問題

  1. 相変化メモリ(PCM)で、1つのセルに複数ビットを記憶する(多値化する)方法として正しいものはどれか。
  2. 銀や銅などの金属イオンが固体電解質の中を移動して導電パスをつくったり切ったりすることで抵抗を変えるメモリはどれか。
  3. ReRAMの動作方式で「バイポーラ型」と「ユニポーラ型」の違いとして正しいものはどれか。
  4. クロスポイント型のPCMなどで、記憶素子と直列に置くセレクタとして使われる、ある電圧を超えると急に導通するカルコゲナイド材料の素子はどれか。
  5. STT-MRAMで、読み出し電流の大きさに制限が必要になる理由として正しいものはどれか。
