次世代メモリ

MRAMやFeRAMが宇宙機器など放射線の多い環境で使われることがある理由として正しいものはどれか。

  1. A放射線を吸収して遮へいする材料でできているため
  2. Bフラッシュメモリより必ず大容量なため
  3. C記憶に電荷を使わないため、放射線によるデータの反転が起こりにくいため
答えと解説を見る

正解：C. 記憶に電荷を使わないため、放射線によるデータの反転が起こりにくいため

DRAMやフラッシュは電荷の量で記憶するため、宇宙線や放射線が生む電荷でデータが反転したり、蓄積された電荷が乱されたりします。MRAMは磁化、FeRAMは分極で記憶するため、記憶そのものは放射線の影響を受けにくく、人工衛星や探査機、原子力関連の機器で使われることがあります。ただし周辺のCMOS回路は放射線の影響を受けるため、別途対策が必要です。

  • A. 放射線を遮へいする材料という理由ではありません。
  • B. 容量は一般にフラッシュメモリの方が大きいです。
  • C. 正しい。電荷以外の物理量で記憶するため放射線に強い傾向があります。

次世代メモリのほかの問題

  1. かつてIntelとMicronが共同開発し、「Optane」の製品名で販売されたストレージクラスメモリの技術はどれか。
  2. 相変化メモリ(PCM)で、1つのセルに複数ビットを記憶する(多値化する)方法として正しいものはどれか。
  3. 銀や銅などの金属イオンが固体電解質の中を移動して導電パスをつくったり切ったりすることで抵抗を変えるメモリはどれか。
  4. ReRAMの動作方式で「バイポーラ型」と「ユニポーラ型」の違いとして正しいものはどれか。
  5. クロスポイント型のPCMなどで、記憶素子と直列に置くセレクタとして使われる、ある電圧を超えると急に導通するカルコゲナイド材料の素子はどれか。
