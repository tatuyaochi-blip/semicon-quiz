次世代メモリ

MRAMを使うときに注意が必要な外部環境として正しいものはどれか。

  1. A強い光
  2. B強い外部磁界
  3. C低い湿度
答えと解説を見る

正解：B. 強い外部磁界

MRAMは磁化の向きで情報を記憶するため、強い外部磁界にさらされると、記録層の磁化が乱れてデータが失われるおそれがあります。用途によっては磁気シールドを施したパッケージが使われます。

  • A. MRAMは光で情報を記憶するものではありません。
  • B. 正しい。強い磁界でデータが乱れるおそれがあります。
  • C. 湿度はMRAMの記憶原理には直接関係しません。

次世代メモリのほかの問題

  1. MRAMやFeRAMが宇宙機器など放射線の多い環境で使われることがある理由として正しいものはどれか。
  2. かつてIntelとMicronが共同開発し、「Optane」の製品名で販売されたストレージクラスメモリの技術はどれか。
  3. 相変化メモリ(PCM)で、1つのセルに複数ビットを記憶する(多値化する)方法として正しいものはどれか。
  4. 銀や銅などの金属イオンが固体電解質の中を移動して導電パスをつくったり切ったりすることで抵抗を変えるメモリはどれか。
  5. ReRAMの動作方式で「バイポーラ型」と「ユニポーラ型」の違いとして正しいものはどれか。
