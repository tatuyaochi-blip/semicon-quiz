次世代メモリ

次のメモリのうち、電源を切ってもデータが残る不揮発性メモリはどれか。

  1. AMRAM
  2. BDRAM
  3. CSRAM
答えと解説を見る

正解：A. MRAM

MRAMは、磁性体の磁化の向きで情報を記憶するため、電源を切ってもデータが残る不揮発性メモリです。DRAMとSRAMはどちらも電源を切るとデータが消える揮発性メモリです。

  • A. 正しい。MRAMは磁化の向きで記憶する不揮発性メモリです。
  • B. DRAMは揮発性で、電源を切るとデータが消えます。
  • C. SRAMも揮発性で、電源を切るとデータが消えます。
