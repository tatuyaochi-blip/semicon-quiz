次世代メモリ

相変化メモリ(PCM)で、セルを高抵抗のアモルファス状態にする(リセットする)方法として正しいものはどれか。

  1. A磁界をかけて磁化を反転させる
  2. B大きな電流パルスで融点以上に加熱したあと、急冷する
  3. C結晶化温度付近で長時間保持する
答えと解説を見る

正解：B. 大きな電流パルスで融点以上に加熱したあと、急冷する

リセットでは、大きな電流パルスで材料を融点以上に加熱して溶かし、すぐに冷やすことで、結晶にならないままのアモルファス状態にします。逆にセット(低抵抗化)では、結晶化温度以上・融点未満で一定時間加熱して結晶化させます。
