次世代メモリ

相変化メモリ(PCM)で、アモルファス状態の抵抗値が時間とともに少しずつ増加していく現象を何と呼ぶか。

  1. Aスティクション
  2. B抵抗ドリフト
  3. C過渡増速拡散
答えと解説を見る

正解：B. 抵抗ドリフト

PCMのアモルファス相は、時間とともに構造がわずかに緩和して、抵抗値が徐々に上がっていきます。これを抵抗ドリフトといいます。1セルに多値を記憶する場合、抵抗値の区別が難しくなるため、読み出し方法の工夫などで対策します。
