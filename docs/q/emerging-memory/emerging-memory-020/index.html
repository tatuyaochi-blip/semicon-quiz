次世代メモリ

相変化メモリ(PCM)で、アモルファス状態の抵抗値が時間とともに少しずつ増加していく現象を何と呼ぶか。

  1. Aスティクション
  2. B抵抗ドリフト
  3. C過渡増速拡散
答えと解説を見る

正解：B. 抵抗ドリフト

PCMのアモルファス相は、時間とともに原子配置がわずかに緩和して、抵抗値が時間の対数に比例するように徐々に上がっていきます(R ∝ t^ν、νは0.1程度)。これが抵抗ドリフトです。高抵抗と低抵抗の2値なら問題になりにくいものの、中間の抵抗で多値化すると隣のレベルとの区別が難しくなります。基準となる参照セルを一緒に読む、ドリフトの小さい材料を選ぶなどの対策がとられます。
