次世代メモリ

相変化メモリ(PCM)で、1つのセルに複数ビットを記憶する(多値化する)方法として正しいものはどれか。

  1. Aセルの色を変える
  2. Bセルの磁化の向きを複数にする
  3. Cセルの中のアモルファス領域の大きさなどを制御して、中間の抵抗値をつくり分ける
答えと解説を見る

正解：C. セルの中のアモルファス領域の大きさなどを制御して、中間の抵抗値をつくり分ける

PCMでは、セル内のアモルファス領域の大きさ(結晶部分との割合)を、書き込みパルスの高さや長さで制御すると、高抵抗と低抵抗の間の中間的な抵抗値を作れます。抵抗差が2〜3桁と大きいため、複数のレベルを区別すれば1セルに2ビット以上を記憶できます。ただし抵抗ドリフトや温度による変化があるため、書き込み後に確認して調整する方式や、ドリフトを補正する読み出し方法が必要です。

  • A. PCMは電気的な抵抗で記憶し、色を使うものではありません。
  • B. 磁化の向きで記憶するのはMRAMです。
  • C. 正しい。中間の抵抗値をつくり分けます。

次世代メモリのほかの問題

  1. 銀や銅などの金属イオンが固体電解質の中を移動して導電パスをつくったり切ったりすることで抵抗を変えるメモリはどれか。
  2. ReRAMの動作方式で「バイポーラ型」と「ユニポーラ型」の違いとして正しいものはどれか。
  3. クロスポイント型のPCMなどで、記憶素子と直列に置くセレクタとして使われる、ある電圧を超えると急に導通するカルコゲナイド材料の素子はどれか。
  4. STT-MRAMで、読み出し電流の大きさに制限が必要になる理由として正しいものはどれか。
  5. 強誘電体の分極の向きによって、薄い強誘電体層を通るトンネル電流の大きさが変わることを利用する素子はどれか。
