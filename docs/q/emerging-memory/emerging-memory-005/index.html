次世代メモリ

STT-MRAMで情報を書き込む方法として正しいものはどれか。

  1. A外部のコイルが発生する磁界だけで書き込む
  2. B紫外線を照射して書き込む
  3. Cスピン偏極した電流によるスピントランスファートルクで磁化を反転させる
答えと解説を見る

正解：C. スピン偏極した電流によるスピントランスファートルクで磁化を反転させる

STT-MRAMでは、MTJに電流を流し、電子のスピンがもつ角運動量を磁性層に移す(スピントランスファートルク)ことで磁化の向きを反転させます。磁界で書き込む方式より書き込み電流を小さくでき、微細化に向いています。
