次世代メモリ

STT-MRAMで、読み出し電流の大きさに制限が必要になる理由として正しいものはどれか。

  1. A読み出し電流が大きいと、MTJの抵抗が永久に変わってしまうため
  2. B読み出し電流でもスピントルクが働くため、大きすぎると記録層の磁化を誤って反転させてしまうため
  3. C読み出し電流が大きいと、磁性層が溶けるため
答えと解説を見る

正解：B. 読み出し電流でもスピントルクが働くため、大きすぎると記録層の磁化を誤って反転させてしまうため

STT-MRAMは読み出しも書き込みもMTJに電流を流すため、読み出し電流が書き込みの反転電流に近いと、読み出しのたびに確率的に磁化が反転するおそれがあります(読み出しディスターブ)。そのため読み出し電流は書き込み電流より十分小さく設計しますが、小さすぎると信号が弱まって読み出しが遅く誤りやすくなります。素子の微細化で書き込み電流が下がるほど、この両立は難しくなります。

  • A. 抵抗が永久に変わる劣化を主な理由とするものではありません。
  • B. 正しい。読み出し電流でも誤って書き込まれるおそれがあります。
  • C. 通常の読み出し電流で磁性層が溶けることはありません。
