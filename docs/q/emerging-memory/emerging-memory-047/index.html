次世代メモリ

クロスポイント型のPCMなどで、記憶素子と直列に置くセレクタとして使われる、ある電圧を超えると急に導通するカルコゲナイド材料の素子はどれか。

  1. AOTS(オボニック閾値スイッチ)
  2. Bツェナーダイオード
  3. Cフローティングゲート
答えと解説を見る

正解：A. OTS(オボニック閾値スイッチ)

OTS(Ovonic Threshold Switch)は、カルコゲナイド材料でできた素子で、しきい値電圧を超えると急に低抵抗になり、電圧を下げると元の高抵抗に戻ります。この非線形な特性により、選択していないセルへの回り込み電流を抑えるセレクタとして使われます。PCMと異なり、状態を記憶はしません。

  • A. 正しい。カルコゲナイドを使ったしきい値スイッチです。
  • B. ツェナーダイオードは逆方向の降伏を利用する素子で、クロスポイントのセレクタとしては一般的ではありません。
  • C. フローティングゲートはフラッシュメモリの電荷を蓄える電極です。

  4. MRAMの記憶原理として正しいものはどれか。
  5. 相変化メモリ(PCM)の記憶原理として正しいものはどれか。
