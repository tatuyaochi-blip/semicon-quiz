次世代メモリ

SOT-MRAMの特徴として正しいものはどれか。

  1. A光を照射して書き込む
  2. Bキャパシタの電荷で記憶する
  3. C重金属層に流す電流によるスピン軌道トルクで磁化を反転させ、書き込みと読み出しの電流経路を分けられる
答えと解説を見る

正解：C. 重金属層に流す電流によるスピン軌道トルクで磁化を反転させ、書き込みと読み出しの電流経路を分けられる

SOT-MRAMは、MTJの下の重金属層などに電流を流したときに生じるスピン軌道トルクで記録層の磁化を反転させます。書き込み電流がトンネル障壁を通らないため障壁が劣化しにくく、高速な書き込みが可能で、キャッシュ用途などが期待されています。

  2. MRAMで、記憶素子(MTJ)を小さくしすぎると問題になりやすいことはどれか。
  3. 近年のSTT-MRAMで、磁化の向きが膜面に垂直なMTJ(垂直磁化MTJ)が主流になった理由として正しいものはどれか。
  4. 抵抗変化素子を縦横の配線の交点に配置するクロスポイント型メモリで、選択していないセルに電流が回り込むのを防ぐために、記憶素子と直列に入れる素子はどれか。
  5. ゲート絶縁膜に強誘電体を使ったFeFETの特徴として正しいものはどれか。
