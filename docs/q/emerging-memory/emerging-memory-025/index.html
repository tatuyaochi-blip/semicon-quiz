次世代メモリ

FeRAMが使われてきた代表的な用途として正しいものはどれか。

  1. A大容量のSSD
  2. Bパソコンの主記憶
  3. C高速・低消費電力の書き込みを生かしたICカードなど
答えと解説を見る

正解：C. 高速・低消費電力の書き込みを生かしたICカードなど

FeRAMは書き込みが速く、必要な電力が小さく、書き換え回数も多いため、非接触の電波から得るわずかな電力で動く交通系ICカードや電子マネーのカードで使われてきました。ほかにも、電源が急に切れてもデータを失いたくないメーターや医療機器、頻繁に記録する計測機器などに使われます。一方、キャパシタの微細化が難しく容量は数Mbit程度にとどまるため、大容量用途には向きません。

次世代メモリのほかの問題

  1. MRAMの記憶素子(MTJ)は、ロジックLSIのどの工程でつくり込むのが一般的か。

  3. STT-MRAMの書き込みが確率的な性質をもつことによる設計上の課題として正しいものはどれか。
  4. ReRAMのセルの抵抗値のばらつきが大きいことによる課題として正しいものはどれか。
  5. 一般に、書き換え可能回数が最も少ないメモリはどれか。
