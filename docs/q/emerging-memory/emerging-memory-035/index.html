次世代メモリ

MRAMで1ビットの情報を記憶する素子として使われる、2つの磁性層で薄い絶縁層を挟んだ構造を何と呼ぶか。

  1. APN接合
  2. Bショットキー接合
  3. C磁気トンネル接合(MTJ)
答えと解説を見る

正解：C. 磁気トンネル接合(MTJ)

MRAMの記憶素子は、2つの磁性層の間に厚さ1 nm程度の絶縁層(トンネル障壁)を挟んだ磁気トンネル接合(MTJ)です。2つの磁性層の磁化の向きがそろっているかどうかで、トンネル電流の流れやすさ(抵抗)が変わります。

  • A. PN接合はp型とn型の半導体の接合です。
  • B. ショットキー接合は金属と半導体の接合です。
  • C. 正しい。磁性層で絶縁層を挟んだMTJです。

次世代メモリのほかの問題

  1. MTJのトンネル磁気抵抗比(TMR比)の説明として正しいものはどれか。
  2. MTJで、2つの磁性層の磁化の向きが平行のときと反平行のときの抵抗の関係として正しいものはどれか。
  3. MTJを構成する2つの磁性層の役割として正しいものはどれか。
  4. 相変化メモリ(PCM)で、セルを低抵抗の結晶状態にする(セットする)ときの加熱のしかたとして正しいものはどれか。
  5. 強誘電体のヒステリシス曲線(分極-電界特性)で、電界をゼロに戻しても残る分極を何と呼ぶか。
