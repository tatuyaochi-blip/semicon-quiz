次世代メモリ

MRAMのデータの読み出し方法として正しいものはどれか。

  1. AMTJに小さな電流を流し、抵抗の高低を検出する
  2. B強い磁界をかけて反応を見る
  3. C光を当てて反射光を測る
答えと解説を見る

正解：A. MTJに小さな電流を流し、抵抗の高低を検出する

MRAMでは、MTJに書き込みより小さな電流を流し、2つの磁性層の磁化が平行(低抵抗)か反平行(高抵抗)かを、電流や電圧の違いとして検出します。磁化を反転させない非破壊読み出しのため、読み出し後の再書き込みは不要です。
