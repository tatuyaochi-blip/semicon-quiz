次世代メモリ

MRAMのデータの読み出し方法として正しいものはどれか。

  1. AMTJに小さな電流を流し、抵抗の高低を検出する
  2. B強い磁界をかけて反応を見る
  3. C光を当てて反射光を測る
答えと解説を見る

正解：A. MTJに小さな電流を流し、抵抗の高低を検出する

MRAMの読み出しでは、MTJに書き込みより小さな電流を流し、平行(低抵抗)か反平行(高抵抗)かを、基準の抵抗との比較で電流や電圧の違いとして検出します。TMR比が100〜200%程度あっても、抵抗の差は2〜3倍しかなく、DRAMやフラッシュより読み出しの余裕は小さめです。磁化を反転させない非破壊読み出しのため、読み出し後の書き戻しは不要です。
