次世代メモリ

MRAMが、マイコンなどの組み込み不揮発メモリとして注目されている理由の一つとして正しいものはどれか。

  1. A先端のロジックプロセスでは埋め込みフラッシュの製造が難しくなり、配線工程でつくれるMRAMが代替の候補になるため
  2. BDRAMより大容量で安価なため
  3. C電源を切るとデータが消えるため
答えと解説を見る

正解：A. 先端のロジックプロセスでは埋め込みフラッシュの製造が難しくなり、配線工程でつくれるMRAMが代替の候補になるため

組み込みフラッシュはフローティングゲートの形成などで10枚以上のマスクを追加する必要があり、28 nm前後より先の世代やHigh-k/メタルゲートとの組み合わせでは実現が難しくなっています。MRAMは配線工程の途中にMTJを作り込め、追加マスクも数枚で済むため、TSMCやSamsungなどのファウンドリが22 nm以下で組み込みMRAMを提供しています。車載マイコンなどで採用が進んでいます。

次世代メモリのほかの問題

  1. MRAMで、記憶素子(MTJ)を小さくしすぎると問題になりやすいことはどれか。
  2. 近年のSTT-MRAMで、磁化の向きが膜面に垂直なMTJ(垂直磁化MTJ)が主流になった理由として正しいものはどれか。
  3. 抵抗変化素子を縦横の配線の交点に配置するクロスポイント型メモリで、選択していないセルに電流が回り込むのを防ぐために、記憶素子と直列に入れる素子はどれか。
  4. ゲート絶縁膜に強誘電体を使ったFeFETの特徴として正しいものはどれか。
  5. 相変化メモリ(PCM)で、アモルファス状態の抵抗値が時間とともに少しずつ増加していく現象を何と呼ぶか。
