次世代メモリ

強誘電体の分極の向きによって、薄い強誘電体層を通るトンネル電流の大きさが変わることを利用する素子はどれか。

  1. AFTJ(強誘電体トンネル接合)
  2. BMTJ(磁気トンネル接合)
  3. CMIMキャパシタ
答えと解説を見る

正解：A. FTJ(強誘電体トンネル接合)

FTJ(Ferroelectric Tunnel Junction)は、数nmの非常に薄い強誘電体層を電極で挟んだ素子で、分極の向きによってトンネル障壁の形が変わり、抵抗が変化します。キャパシタ型FeRAMと違って非破壊で抵抗として読み出せるため、低消費電力のメモリや演算素子として研究されています。

  • A. 正しい。強誘電体の分極でトンネル抵抗が変わる素子です。
  • B. MTJは磁化の向きでトンネル抵抗が変わる素子です。
  • C. MIMキャパシタは金属-絶縁体-金属のコンデンサで、抵抗変化を利用するものではありません。
