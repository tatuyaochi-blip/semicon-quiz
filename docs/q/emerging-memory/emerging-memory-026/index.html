次世代メモリ

MRAMの記憶素子(MTJ)は、ロジックLSIのどの工程でつくり込むのが一般的か。

  1. A配線工程(BEOL)の配線層の間
  2. Bシリコンウエハを製造するとき
  3. Cパッケージに組み立てたあと
答えと解説を見る

正解：A. 配線工程(BEOL)の配線層の間

MTJは、トランジスタを作り終えた後の配線工程(BEOL)で、配線層の間に形成されます。トランジスタの工程を変えずに混載でき、同じMTJ技術を世代をまたいで使い回しやすい利点があります。ただし配線工程の熱処理(約400 ℃)に耐えるMTJ材料が必要で、磁性膜の加工では金属の再付着を防ぐためイオンビームエッチングなど特殊な技術が使われます。

次世代メモリのほかの問題

  1. 相変化メモリを微細化するときに問題になる、書き込み時の熱が隣のセルに伝わって状態を変えてしまう現象はどれか。
  2. STT-MRAMの書き込みが確率的な性質をもつことによる設計上の課題として正しいものはどれか。
  3. ReRAMのセルの抵抗値のばらつきが大きいことによる課題として正しいものはどれか。
  4. 一般に、書き換え可能回数が最も少ないメモリはどれか。
  5. 次のメモリのうち、電源を切ってもデータが残る不揮発性メモリはどれか。
