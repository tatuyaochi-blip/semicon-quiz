次世代メモリ

ReRAM(抵抗変化メモリ)の記憶原理として正しいものはどれか。

  1. A磁性層の磁化の向きの違い
  2. B金属酸化物などに電圧を加えて、高抵抗状態と低抵抗状態を切り替える
  3. Cキャパシタに蓄えた電荷の有無
答えと解説を見る

正解：B. 金属酸化物などに電圧を加えて、高抵抗状態と低抵抗状態を切り替える

ReRAMは、金属酸化物などの薄膜を電極ではさんだ単純な構造で、電圧を加えると膜中の酸素欠損が集まった導電性フィラメントができたり切れたりして、抵抗が10倍以上変わります。素子が小さく配線工程で作れるため、ロジックへの混載やクロスポイント構造による高密度化に向きます。マイコンの組み込みメモリとして実用化されており、抵抗のばらつきの大きさが課題です。

次世代メモリのほかの問題

  1. STT-MRAMで情報を書き込む方法として正しいものはどれか。
  2. 「ストレージクラスメモリ」の位置づけとして正しいものはどれか。
  3. フラッシュメモリと比べたときのMRAMの一般的な利点として正しいものはどれか。
  4. 近年、FeRAMや強誘電体トランジスタ(FeFET)の材料として注目されている、CMOSプロセスと相性のよい強誘電体材料はどれか。
  5. 相変化メモリ(PCM)で、セルを高抵抗のアモルファス状態にする(リセットする)方法として正しいものはどれか。
