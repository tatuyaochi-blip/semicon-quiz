次世代メモリ

ReRAM(抵抗変化メモリ)の記憶原理として正しいものはどれか。

  1. A磁性層の磁化の向きの違い
  2. B金属酸化物などに電圧を加えて、高抵抗状態と低抵抗状態を切り替える
  3. Cキャパシタに蓄えた電荷の有無
答えと解説を見る

正解：B. 金属酸化物などに電圧を加えて、高抵抗状態と低抵抗状態を切り替える

ReRAMは、金属酸化物などの薄膜を電極ではさんだ構造で、電圧を加えると膜中に導電性のフィラメントができたり消えたりして、抵抗が大きく変わる現象を利用します。構造が単純で、高速・低消費電力の不揮発性メモリとして開発が進められています。
