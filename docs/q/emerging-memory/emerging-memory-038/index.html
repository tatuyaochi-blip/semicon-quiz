次世代メモリ

MTJを構成する2つの磁性層の役割として正しいものはどれか。

  1. A両方の層の磁化を書き込みのたびに反転させる
  2. B両方の層の磁化を常に固定しておく
  3. C一方は磁化の向きが固定された参照層、もう一方は書き込みで向きを変える自由層である
答えと解説を見る

正解：C. 一方は磁化の向きが固定された参照層、もう一方は書き込みで向きを変える自由層である

MTJの一方の磁性層は、磁化の向きが固定された参照層(固定層)です。もう一方は、書き込みによって磁化の向きを反転できる自由層(記録層)です。自由層の向きが参照層と平行か反平行かで、0と1を記憶します。

  • A. 基準となる参照層の向きは変えません。
  • B. 両方を固定すると情報を書き込めません。
  • C. 正しい。参照層と自由層の組み合わせです。
