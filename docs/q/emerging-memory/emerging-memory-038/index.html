次世代メモリ

MTJを構成する2つの磁性層の役割として正しいものはどれか。

  1. A一方は磁化の向きが固定された参照層、もう一方は書き込みで向きを変える自由層である
  2. B両方の層の磁化を書き込みのたびに反転させる
  3. C両方の層の磁化を常に固定しておく
答えと解説を見る

正解：A. 一方は磁化の向きが固定された参照層、もう一方は書き込みで向きを変える自由層である

MTJの一方は磁化の向きが固定された参照層(固定層)、もう一方は書き込みで向きを反転できる自由層(記録層)で、自由層が参照層と平行か反平行かで0と1を記憶します。参照層は、反強磁性体や、磁化を打ち消し合う2層構造(合成反強磁性体)で強く固定し、書き込み電流や外部磁界で動かないようにします。自由層は保持と書き込みやすさのバランスで設計します。

  • A. 正しい。参照層と自由層の組み合わせです。
  • B. 基準となる参照層の向きは変えません。
  • C. 両方を固定すると情報を書き込めません。
