次世代メモリ

一般に、書き換え可能回数が最も少ないメモリはどれか。

  1. ADRAM
  2. BSRAM
  3. CNANDフラッシュメモリ
答えと解説を見る

正解：C. NANDフラッシュメモリ

DRAMやSRAMは書き換えによる劣化がほとんどなく、実質的に無制限に書き換えられます。NANDフラッシュは、トンネル酸化膜の劣化のため、書き換え可能回数が数千〜数万回程度(多値ほど少ない)に限られます。MRAMは非常に多くの書き換えに耐えるとされています。
