次世代メモリ

一般に、書き換え可能回数が最も少ないメモリはどれか。

  1. ADRAM
  2. BSRAM
  3. CNANDフラッシュメモリ
答えと解説を見る

正解：C. NANDフラッシュメモリ

DRAMやSRAMは書き換えによる劣化がほとんどなく、実質的に無制限に書き換えられます。NANDフラッシュは、トンネル酸化膜の劣化のため、書き換え可能回数が数千〜数万回程度(多値ほど少ない)に限られます。MRAMは非常に多くの書き換えに耐えるとされています。

次世代メモリのほかの問題

  1. 次のメモリのうち、電源を切ってもデータが残る不揮発性メモリはどれか。
  2. MRAMの「M」が表すものとして正しいものはどれか。
  3. 多くの次世代メモリの研究開発で目標とされてきた「ユニバーサルメモリ」の考え方として正しいものはどれか。
  4. FeRAMの「Fe」が表すものとして正しいものはどれか。
  5. MRAMで1ビットの情報を記憶する素子として使われる、2つの磁性層で薄い絶縁層を挟んだ構造を何と呼ぶか。
