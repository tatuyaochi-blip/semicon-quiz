次世代メモリ

多くの次世代メモリの研究開発で目標とされてきた「ユニバーサルメモリ」の考え方として正しいものはどれか。

  1. Aどの機器にも差し込めるメモリカード
  2. B必ず磁気を使うメモリ
  3. CDRAM並みの速さと書き換え回数、フラッシュ並みの不揮発性と大容量を1つで兼ね備えるメモリ
答えと解説を見る

正解：C. DRAM並みの速さと書き換え回数、フラッシュ並みの不揮発性と大容量を1つで兼ね備えるメモリ

ユニバーサルメモリは、高速で書き換え回数に制限が少ないDRAMやSRAMの長所と、電源を切ってもデータが残るフラッシュメモリの長所を1つのメモリで実現しようという考え方です。実際にはそれぞれの次世代メモリに得意・不得意があり、用途に応じて使い分けられています。

  • A. メモリカードの規格の話ではありません。
  • B. 記憶の原理は磁気に限りません。
  • C. 正しい。速さと不揮発性などの長所を1つで兼ね備えることを目指します。

  3. MTJのトンネル磁気抵抗比(TMR比)の説明として正しいものはどれか。
  4. MTJで、2つの磁性層の磁化の向きが平行のときと反平行のときの抵抗の関係として正しいものはどれか。
  5. MTJを構成する2つの磁性層の役割として正しいものはどれか。
