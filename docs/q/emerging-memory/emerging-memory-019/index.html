次世代メモリ

ゲート絶縁膜に強誘電体を使ったFeFETの特徴として正しいものはどれか。

  1. A分極の向きでしきい値電圧が変わり、トランジスタ1個で不揮発に記憶でき、非破壊で読み出せる
  2. B電源を切るとデータが消える
  3. Cキャパシタの電荷で記憶する
答えと解説を見る

正解：A. 分極の向きでしきい値電圧が変わり、トランジスタ1個で不揮発に記憶でき、非破壊で読み出せる

FeFETでは、強誘電体の分極の向きによってトランジスタのしきい値電圧が変わります。電流が流れるかどうかでデータを読み出すため、分極を反転させない非破壊読み出しが可能です。酸化ハフニウム系の強誘電体の発見により、実用化への研究が進んでいます。
