次世代メモリ

ゲート絶縁膜に強誘電体を使ったFeFETの特徴として正しいものはどれか。

  1. A分極の向きでしきい値電圧が変わり、トランジスタ1個で不揮発に記憶でき、非破壊で読み出せる
  2. B電源を切るとデータが消える
  3. Cキャパシタの電荷で記憶する
答えと解説を見る

正解：A. 分極の向きでしきい値電圧が変わり、トランジスタ1個で不揮発に記憶でき、非破壊で読み出せる

FeFETでは、ゲート絶縁膜の強誘電体の分極の向きによって、チャネルに誘起される電荷が変わり、しきい値電圧がずれます。トランジスタ1個で記憶でき(1T)、電流が流れるかどうかで読むため、分極を反転させない非破壊読み出しが可能です。書き込みはゲート電圧だけで行え、消費電力も小さくなります。HfO2系の強誘電体の発見で再び注目されており、書き換え耐性の向上が課題です。
