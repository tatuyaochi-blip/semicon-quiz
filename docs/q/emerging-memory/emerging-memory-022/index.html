次世代メモリ

相変化メモリの記録材料として代表的なGSTとはどのような材料か。

  1. Aガリウム・シリコン・チタンの合金
  2. B金・銀・スズの合金
  3. Cゲルマニウム・アンチモン・テルルの化合物(Ge2Sb2Te5など)
答えと解説を見る

正解：C. ゲルマニウム・アンチモン・テルルの化合物(Ge2Sb2Te5など)

GSTは、ゲルマニウム(Ge)、アンチモン(Sb)、テルル(Te)からなるカルコゲナイド材料で、Ge2Sb2Te5が代表的な組成です。結晶とアモルファスの間を高速に切り替えられ、両者の抵抗や光の反射率が大きく異なるため、書き換え型光ディスクやPCMに使われてきました。

  3. FeRAMが使われてきた代表的な用途として正しいものはどれか。
  4. MRAMの記憶素子(MTJ)は、ロジックLSIのどの工程でつくり込むのが一般的か。
  5. 相変化メモリを微細化するときに問題になる、書き込み時の熱が隣のセルに伝わって状態を変えてしまう現象はどれか。
