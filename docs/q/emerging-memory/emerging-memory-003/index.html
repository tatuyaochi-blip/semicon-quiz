次世代メモリ

FeRAM(強誘電体メモリ)が情報の記憶に利用している性質はどれか。

  1. A酸化物中の導電性フィラメントの形成と消滅
  2. B磁気抵抗効果
  3. C強誘電体の自発分極(残留分極)の向き
答えと解説を見る

正解：C. 強誘電体の自発分極(残留分極)の向き

FeRAMは、電圧を取り去っても分極が残る強誘電体の性質(残留分極)を使い、分極の向きで0と1を記憶します。書き込みは分極を反転させるだけなので、フラッシュのような高電圧が不要で、速く(数十ns)消費電力も小さく、書き換え回数も10¹²回以上と多いのが特徴です。従来はPZT(チタン酸ジルコン酸鉛)が使われてきました。フィラメントを使うのはReRAM、磁気抵抗はMRAMです。
