次世代メモリ

ReRAMの動作方式で「バイポーラ型」と「ユニポーラ型」の違いとして正しいものはどれか。

  1. Aバイポーラ型はバイポーラトランジスタを使い、ユニポーラ型はMOSFETを使う
  2. Bバイポーラ型は2ビット、ユニポーラ型は1ビットを記憶する
  3. Cバイポーラ型は電圧の極性を変えてセット・リセットし、ユニポーラ型は同じ極性で電圧や電流の大きさを変えて切り替える
答えと解説を見る

正解：C. バイポーラ型は電圧の極性を変えてセット・リセットし、ユニポーラ型は同じ極性で電圧や電流の大きさを変えて切り替える

バイポーラ型のReRAMは、セット(低抵抗化)とリセット(高抵抗化)で逆の極性の電圧を加えます。ユニポーラ型は同じ極性のまま、電圧や電流の大きさ・時間を変えて切り替えます。素子の材料や電極の組み合わせによってどちらの動作になるかが決まります。

  • A. トランジスタの種類を表す用語ではありません。
  • B. 記憶するビット数の違いではありません。
  • C. 正しい。電圧の極性を使い分けるかどうかの違いです。

次世代メモリのほかの問題

  1. クロスポイント型のPCMなどで、記憶素子と直列に置くセレクタとして使われる、ある電圧を超えると急に導通するカルコゲナイド材料の素子はどれか。
  2. STT-MRAMで、読み出し電流の大きさに制限が必要になる理由として正しいものはどれか。
  3. 強誘電体の分極の向きによって、薄い強誘電体層を通るトンネル電流の大きさが変わることを利用する素子はどれか。
  4. MRAMの書き込みエネルギーを下げる方法として研究されている、電圧で磁性層の磁気異方性を変える効果はどれか。
  5. MRAMの記憶原理として正しいものはどれか。
