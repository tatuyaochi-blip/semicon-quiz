次世代メモリ

ReRAMの動作方式で「バイポーラ型」と「ユニポーラ型」の違いとして正しいものはどれか。

  1. Aバイポーラ型はバイポーラトランジスタを使い、ユニポーラ型はMOSFETを使う
  2. Bバイポーラ型は2ビット、ユニポーラ型は1ビットを記憶する
  3. Cバイポーラ型は電圧の極性を変えてセット・リセットし、ユニポーラ型は同じ極性で電圧や電流の大きさを変えて切り替える
答えと解説を見る

正解：C. バイポーラ型は電圧の極性を変えてセット・リセットし、ユニポーラ型は同じ極性で電圧や電流の大きさを変えて切り替える

バイポーラ型のReRAMは、セット(低抵抗化)とリセット(高抵抗化)で逆の極性の電圧を加え、電界で酸素イオンなどを行き来させてフィラメントをつないだり切ったりします。ユニポーラ型は同じ極性のまま、電圧や電流の大きさ・時間を変え、主にジュール熱でフィラメントを切ります。制御しやすく安定しているバイポーラ型が主流で、どちらになるかは材料や電極の組み合わせで決まります。

  • A. トランジスタの種類を表す用語ではありません。
  • B. 記憶するビット数の違いではありません。
  • C. 正しい。電圧の極性を使い分けるかどうかの違いです。
