次世代メモリ

近年のSTT-MRAMで、磁化の向きが膜面に垂直なMTJ(垂直磁化MTJ)が主流になった理由として正しいものはどれか。

  1. A製造に磁性材料が不要になるため
  2. B微細化しても熱安定性を保ちやすく、書き込み電流も下げやすいため
  3. C読み出しに光が使えるため
答えと解説を見る

正解：B. 微細化しても熱安定性を保ちやすく、書き込み電流も下げやすいため

膜面内に磁化をもつMTJは、素子の形状で磁化の向きを安定させるため微細化に限界があります。垂直磁化MTJは材料の性質(垂直磁気異方性)で磁化を安定させるため、小さな素子でも熱安定性を確保しやすく、書き込みに必要な電流も小さくできます。
