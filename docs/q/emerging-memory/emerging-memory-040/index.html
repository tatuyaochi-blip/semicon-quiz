次世代メモリ

強誘電体のヒステリシス曲線(分極-電界特性)で、電界をゼロに戻しても残る分極を何と呼ぶか。

  1. A残留分極
  2. B飽和磁化
  3. C絶縁破壊電界
答えと解説を見る

正解：A. 残留分極

強誘電体に電界を加えて分極させた後、電界をゼロに戻しても残る分極を残留分極(Pr)といい、その向き(正か負か)で0と1を記憶するのがFeRAMの原理です。分極を反転させるのに必要な電界を抗電界(Ec)といいます。読み出しの信号は残留分極の大きさに比例するため、Prが大きく、Ecが適度に小さい(低電圧で書ける)材料が望まれます。

  • A. 正しい。電界をゼロにしても残る分極です。
  • B. 飽和磁化は磁性体の磁化に関する量です。
  • C. 絶縁破壊電界は絶縁体が破壊される電界です。

次世代メモリのほかの問題

  1. MRAMを使うときに注意が必要な外部環境として正しいものはどれか。
  2. MRAMやFeRAMが宇宙機器など放射線の多い環境で使われることがある理由として正しいものはどれか。
  3. かつてIntelとMicronが共同開発し、「Optane」の製品名で販売されたストレージクラスメモリの技術はどれか。
  4. 相変化メモリ(PCM)で、1つのセルに複数ビットを記憶する(多値化する)方法として正しいものはどれか。
  5. 銀や銅などの金属イオンが固体電解質の中を移動して導電パスをつくったり切ったりすることで抵抗を変えるメモリはどれか。
