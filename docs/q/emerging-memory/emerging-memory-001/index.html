次世代メモリ

MRAMの記憶原理として正しいものはどれか。

  1. A磁気トンネル接合(MTJ)の磁化の向きによる抵抗の違い
  2. Bカルコゲナイド材料の結晶状態とアモルファス状態の抵抗の違い
  3. Cキャパシタに蓄えた電荷の有無
答えと解説を見る

正解：A. 磁気トンネル接合(MTJ)の磁化の向きによる抵抗の違い

MRAMは、2つの磁性層で薄い絶縁層をはさんだ磁気トンネル接合(MTJ)を使います。2つの磁性層の磁化の向きが平行なときは抵抗が低く、反平行なときは高くなるトンネル磁気抵抗効果を利用して情報を記憶します。
