ソフトウェア開発とプロジェクト管理

結合点を①〜⑥とし、作業を「名前: 始点→終点、所要日数」で示すと、A: ①→②、6日、B: ①→③、4日、C: ②→④、4日、D: ③→⑤、4日、E: ④→⑥、2日、F: ⑤→⑥、3日、ダミー作業: ②→③(所要日数0)となるアローダイアグラムがある。プロジェクト全体の最短の所要日数はどれか。

  1. A11日
  2. B12日
  3. C13日
答えと解説を見る

正解：C. 13日

ダミー作業②→③は、作業Dを始めるには、Bだけでなく A も終わっている必要があることを表します。各結合点の最早結合点時刻は、②が6日、③が max(4, 6 + 0) = 6日、④が 6 + 4 = 10日、⑤が 6 + 4 = 10日、⑥が max(10 + 2, 10 + 3) = 13日なので、全体の所要日数は13日で、クリティカルパスは A→ダミー→D→F です。ダミー作業を見落とすと D が4日目から始められることになり、A→C→E の12日が最長になってしまいます。11日は B→D→F の経路だけの日数です。

  • A. B→D→F(4 + 4 + 3)だけの日数で、D の前に A も終わる必要があることを無視しています。
  • B. ダミー作業を見落とした場合で、A→C→E(6 + 4 + 2)が最長になります。
  • C. 正しい。A→ダミー→D→F の 6 + 0 + 4 + 3 = 13日が最長です。

ソフトウェア開発とプロジェクト管理のほかの問題

  1. 作業と所要日数、先行作業が、A: 4日(先行作業なし)、B: 2日(なし)、C: 3日(A)、D: 2日(B)、E: 5日(C)、F: 4日(C と D)、G: 2日(F)のプロジェクトがある。ほかの作業はできるだけ早く始めるとき、作業Bの開始を遅らせても全体の所要日数が延びない最大の日数はどれか。
  2. 作業と所要日数、先行作業が、A: 6日(なし)、B: 4日(なし)、C: 4日(A)、D: 4日(A と B)、E: 2日(C)、F: 3日(D)で、全体の所要日数が13日のプロジェクトがある。各作業を1日短縮するのにかかる追加の費用は、A が30万円、B が5万円、C が10万円、D が20万円、E が8万円、F が25万円である。全体の所要日数を1日短縮するのに、追加の費用が最も少ない方法はどれか。
  3. ある作業の所要日数を三点見積もりで見積もったところ、楽観値が4日、最可能値が7日、悲観値が16日だった。PERTの式で求めた所要日数の期待値はどれか。
  4. 完成時総予算(BAC)が2,000万円のプロジェクトで、ある時点の計画価値(PV)が800万円、出来高(EV)が600万円、実コスト(AC)が750万円だった。この時点のプロジェクトの状況として、正しいものはどれか。
  5. 完成時総予算(BAC)が1,200万円のプロジェクトで、現時点の計画価値(PV)が600万円、出来高(EV)が480万円、実コスト(AC)が600万円である。今後も現在のコスト効率が続くとしたとき、完成時総コストの見積もり(EAC)はどれか。
