ソフトウェア開発とプロジェクト管理

ボトムアップテストで、まだできていない上位モジュールの代わりに、テストの対象の下位モジュールを呼び出してテストデータを渡し、結果を受け取るために作るものはどれか。

  1. Aドライバ
  2. Bスタブ
  3. Cインサーキットエミュレータ
答えと解説を見る

正解：A. ドライバ

ボトムアップテストは、下位のモジュールから順に結合していく方法で、呼び出す側の上位モジュールがまだないので、代わりに呼び出すテスト用のプログラムであるドライバを作ります。逆に、上位から順に結合するトップダウンテストでは、まだできていない下位モジュールの代わりに、決まった値を返すだけのスタブを作ります。インサーキットエミュレータは、マイコンの代わりに基板に接続して、実機の上でプログラムの実行を止めたり内部を観察したりするデバッグ用の装置です。

  • A. 正しい。上位モジュールの代わりに、テストの対象を呼び出すテスト用のプログラムです。
  • B. トップダウンテストで、まだない下位モジュールの代わりに呼び出される側のプログラムです。
  • C. 実機の上でプログラムを止めたり観察したりするデバッグ用の装置で、テスト用の模擬モジュールではありません。

ソフトウェア開発とプロジェクト管理のほかの問題

  1. テストの工程で、テストの時間(またはテストケースの消化数)を横軸に、見つかった不具合の累積件数を縦軸にとった信頼度成長曲線を描いた。曲線がまだ右上がりのままで、飽和する(横ばいになる)様子が見えないときの判断として、最も適切なものはどれか。
  2. 規模が25 kステップ(2万5,000行)のファームウェアの結合テストで、不具合が30件見つかった。組織の過去の実績から、この工程で見つかる不具合の目安は1 kステップ当たり2〜4件とされている。この結果の評価として、最も適切なものはどれか。
  3. Gitで、2人の開発者が同じファイルの同じ行をそれぞれ別のブランチで書き換え、一方のブランチをもう一方にマージした。このとき起こることとして、適切なものはどれか。
  4. 設計書やソースコードのレビューの方法のうち、モデレータ(進行役)が主導し、参加者の役割を決め、チェックリストなどを使って公式に行い、見つけた欠陥を記録して修正まで確認するものはどれか。
  5. 正しく動くことが分かっているファームウェアの版の後に1,000個のコミットがあり、最新のコミットでは不具合が起こる。不具合はある1つのコミットで入り、それ以降のコミットではすべて起こるとする。git bisect のように二分探索で原因のコミットを特定するとき、ビルドしてテストする回数の最大値はどれか。
