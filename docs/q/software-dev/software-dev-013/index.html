ソフトウェア開発とプロジェクト管理

モジュール間の結合度のうち、最も結合度が弱く、モジュールの独立性が高いものはどれか。

  1. A共通結合
  2. B制御結合
  3. Cデータ結合
答えと解説を見る

正解：C. データ結合

結合度は、モジュールどうしがどれだけ依存し合っているかを表し、弱いほど独立性が高く望ましいとされます。弱い順に、データ結合、スタンプ結合、制御結合、外部結合、共通結合、内容結合と分類されます。データ結合は、必要なデータだけを単純な引数で受け渡す結合です。制御結合は処理の流れを切り替えるフラグなどを渡す結合、共通結合は複数のモジュールが同じ大域データ(グローバル変数)を参照する結合で、どちらも相手のモジュールの中の作りに依存しやすくなります。

  • A. 複数のモジュールが同じ大域データを参照する結合で、内容結合の次に強い結合です。
  • B. 処理を切り替えるフラグなどを渡す結合で、呼び出される側の中の作りに依存します。
  • C. 正しい。必要なデータだけを引数で受け渡す、最も弱い結合です。

ソフトウェア開発とプロジェクト管理のほかの問題

  1. GoFのデザインパターンのうち、あるオブジェクトの状態が変わったときに、それに依存する複数のオブジェクトへ自動で通知されるようにするパターンはどれか。
  2. ファームウェアのソースコードに静的解析ツールを使うとき、プログラムを実行せずに見つけやすい問題として、最も適切なものはどれか。
  3. ブラックボックステストの説明として、適切なものはどれか。
  4. 整数だけが入力される欄で、1以上100以下の値を受け付け、それ以外はエラーにする。同値分割で入力を分けたときの、同値クラスの数(有効同値クラスと無効同値クラスの合計)はどれか。
  5. 入場料金を年齢(0以上の整数)で決めるプログラムがあり、0〜17歳は子供料金、18〜64歳は一般料金、65歳以上はシニア料金とする。料金区分が変わる境目を確かめるために、境界値分析で選ぶテストの値の組合せとして、最も適切なものはどれか。
