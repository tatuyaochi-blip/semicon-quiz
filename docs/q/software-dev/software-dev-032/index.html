ソフトウェア開発とプロジェクト管理

作業と所要日数、先行作業が、A: 6日(なし)、B: 4日(なし)、C: 4日(A)、D: 4日(A と B)、E: 2日(C)、F: 3日(D)で、全体の所要日数が13日のプロジェクトがある。各作業を1日短縮するのにかかる追加の費用は、A が30万円、B が5万円、C が10万円、D が20万円、E が8万円、F が25万円である。全体の所要日数を1日短縮するのに、追加の費用が最も少ない方法はどれか。

  1. A作業Bを1日短縮する(5万円)
  2. B作業Dを1日短縮する(20万円)
  3. C作業Aを1日短縮する(30万円)
答えと解説を見る

正解：B. 作業Dを1日短縮する(20万円)

クリティカルパスは A→D→F(6 + 4 + 3 = 13日)で、ほかの経路は A→C→E が12日、B→D→F が11日です。全体を短くするにはクリティカルパス上の作業を短縮する必要があり、その中で費用が最も少ないのは D の20万円で、短縮後は A→D→F と A→C→E がともに12日になります。B はいちばん安いのですが、クリティカルパス上にないので、短縮しても全体は13日のままです。A を短縮しても全体は12日になりますが、費用は30万円かかります。このように費用をかけて作業の期間を縮めることを、クラッシングといいます。

  • A. B はクリティカルパス上にないので、短縮しても全体は13日のままです。
  • B. 正しい。クリティカルパス上で最も安く、全体が12日になります。
  • C. 全体は12日になりますが、D より10万円多くかかります。

ソフトウェア開発とプロジェクト管理のほかの問題

  1. ある作業の所要日数を三点見積もりで見積もったところ、楽観値が4日、最可能値が7日、悲観値が16日だった。PERTの式で求めた所要日数の期待値はどれか。
  2. 完成時総予算(BAC)が2,000万円のプロジェクトで、ある時点の計画価値(PV)が800万円、出来高(EV)が600万円、実コスト(AC)が750万円だった。この時点のプロジェクトの状況として、正しいものはどれか。
  3. 完成時総予算(BAC)が1,200万円のプロジェクトで、現時点の計画価値(PV)が600万円、出来高(EV)が480万円、実コスト(AC)が600万円である。今後も現在のコスト効率が続くとしたとき、完成時総コストの見積もり(EAC)はどれか。
  4. 遅れているソフトウェア開発のプロジェクトで、開発者を5人から10人に増やした。2人の間の意思疎通の経路の数(2人の組の数)は、増やす前の何倍になるか。
  5. プロジェクトのリスクへの対応のうち、起こったときの損失に備えて保険をかけたり、契約によってその作業を専門の会社に引き受けてもらったりして、影響を第三者に移すものはどれか。
