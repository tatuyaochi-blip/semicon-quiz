ソフトウェア開発とプロジェクト管理

ソフトウェア開発のウォーターフォールモデルの特徴として、適切なものはどれか。

  1. A要件定義・設計・実装・テストなどの工程を上流から順に進め、原則として前の工程の成果物が確定してから次の工程に進む
  2. B短い期間の反復を繰り返し、そのたびに動くソフトウェアを作って利用者の意見を取り入れる
  3. C最初に試作品(プロトタイプ)を作って利用者に見せ、要求を確かめてから本格的に開発する
答えと解説を見る

正解：A. 要件定義・設計・実装・テストなどの工程を上流から順に進め、原則として前の工程の成果物が確定してから次の工程に進む

ウォーターフォールモデルは、水が上から下へ流れるように、要件定義、設計、プログラミング、テストの順に工程を進める開発モデルです。工程ごとに成果物をレビューで確定させるので、計画を立てやすく進み具合も管理しやすい一方、後の工程で要件の誤りが見つかると手戻りが大きくなります。要件が明確で変わりにくい開発や、ハードウェアと一緒に仕様を早く固める必要がある開発で使われます。反復して利用者の意見を取り入れるのはアジャイル開発などの反復型、試作品で要求を確かめるのはプロトタイピングモデルの特徴です。

  • A. 正しい。工程を順に進め、前の工程の成果物を確定させてから次に進みます。
  • B. 反復型の開発やアジャイル開発の特徴です。ウォーターフォールモデルでは全体を1回の流れで作ります。
  • C. プロトタイピングモデルの特徴です。要求があいまいなときに、早い段階で利用者に確かめるために使います。
