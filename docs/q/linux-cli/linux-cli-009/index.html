Linuxとコマンドラインの基礎

ディレクトリ d の権限が rwx--x--x(711)で、その中のファイル f.txt の権限が rw-r--r--(644)である。所有者でもスーパーユーザでもない利用者が「ls d」と「cat d/f.txt」を実行したときの結果として、正しいものはどれか。

  1. Als d は一覧を表示できるが、cat d/f.txt はディレクトリの権限が足りないので許可されない
  2. Bls d も cat d/f.txt も許可されない
  3. Cls d は許可されないが、cat d/f.txt は中身を表示できる
答えと解説を見る

正解：C. ls d は許可されないが、cat d/f.txt は中身を表示できる

ディレクトリでは、r はその中の名前の一覧を読む権限、x はその中に入って名前を指定したファイルにたどり着く権限を表します。その他の利用者には x だけがあるので、ls d は「Permission denied」になりますが、名前を知っている d/f.txt にはたどり着けます。f.txt 自身はその他にも r があるので、cat で中身を表示できます。逆に r だけで x のないディレクトリでは、名前の一覧は見えても中のファイルは開けません。

  • A. これは r があって x がないディレクトリのときの結果です。711 のその他は x だけなので、一覧は読めません。
  • B. ディレクトリの x があれば、名前を指定したファイルにはたどり着けます。開けるかどうかは f.txt 自身の権限で決まります。
  • C. 正しい。x だけのディレクトリでは、一覧は見えなくても、名前を知っているファイルは開けます。
