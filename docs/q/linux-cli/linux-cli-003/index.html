Linuxとコマンドラインの基礎

ディレクトリ /home/alice/data があり、カレントディレクトリは /home/alice/work である。「cd ../data」を実行してから「pwd」を実行したときに表示されるディレクトリとして、正しいものはどれか。

  1. A/data
  2. B/home/alice/data
  3. C/home/alice/work/data
答えと解説を見る

正解：B. /home/alice/data

「/」で始まらないパスは相対パスで、カレントディレクトリを起点に解釈されます。「..」は親のディレクトリを表すので、/home/alice/work から .. で /home/alice に移り、そこから data に入って /home/alice/data になります。pwd はカレントディレクトリを、「/」から始まる絶対パスで表示します。「/」で始まる絶対パスは、カレントディレクトリに関係なく同じ場所を指します。

  • A. /data は、ルートディレクトリの直下の data です。相対パスは「/」からではなく、カレントディレクトリから解釈されます。
  • B. 正しい。.. で /home/alice に移り、そこから data に入ります。
  • C. /home/alice/work/data は「cd data」で移る先です。「..」は親のディレクトリに戻ることを表します。

Linuxとコマンドラインの基礎のほかの問題

  1. ホームディレクトリで「ls」を実行すると notes.txt だけが表示され、「ls -a」を実行すると「.」「..」「.bashrc」「notes.txt」が表示された。この結果の説明として、正しいものはどれか。
  2. 上のコマンドを順に実行したとき、最後の2つの cat の結果として、正しいものはどれか。
  3. あるディレクトリに a1.txt、a2.txt、a10.txt、b1.txt、c1.txt、a1.csv の6つのファイルがある。このディレクトリで「ls [ab]?.txt」を実行したときに表示されるファイルの数として、正しいものはどれか。
  4. ファイル run.sh に「chmod 754 run.sh」を実行した後、「ls -l run.sh」の行の先頭に表示される権限の表記として、正しいものはどれか。
  5. touch は新しいファイルを 666 から、mkdir は新しいディレクトリを 777 から、umask のビットを取り除いた権限で作る。umask が 027 のシェルで新しいファイルと新しいディレクトリを作ったときの、それぞれの権限の組み合わせとして、正しいものはどれか。
