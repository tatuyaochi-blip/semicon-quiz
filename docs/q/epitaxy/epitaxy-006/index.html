エピタキシャル成長

シリコンのエピタキシャル成長で原料として使われるガスはどれか。

  1. Aアルゴンだけ
  2. Bトリクロロシラン(SiHCl3)やジクロロシラン(SiH2Cl2)
  3. C酸素
答えと解説を見る

正解：B. トリクロロシラン(SiHCl3)やジクロロシラン(SiH2Cl2)

シリコンのエピタキシャル成長には、トリクロロシラン、ジクロロシラン、シランなどのシリコンを含むガスを水素と一緒に使います。高温で分解・還元されてシリコンが基板上に析出し、例えば SiHCl3 + H2 → Si + 3HCl の反応が起こります。塩素を含む原料ほど高温が必要ですが、HClが酸化膜上への析出を抑えるため選択成長に向きます。ドーピングにはホスフィンやジボランを加えます。

エピタキシャル成長のほかの問題

  1. 選択エピタキシャル成長の説明として正しいものはどれか。
  2. エピタキシャル成長中に、基板などの不純物が気相を通じて成長層に取り込まれてしまう現象を何と呼ぶか。
  3. p+基板の上に低濃度のp型エピタキシャル層を成長させたウエハ(p/p+エピウエハ)の利点として正しいものはどれか。
  4. ヘテロエピタキシャル成長における臨界膜厚の説明として正しいものはどれか。
  5. シリコンのエピタキシャル成長の直前に、高温の水素雰囲気でウエハを加熱する主な目的はどれか。
