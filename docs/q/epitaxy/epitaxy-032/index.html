エピタキシャル成長

LSIやパワーデバイス用のシリコンエピウエハで、エピタキシャル層の厚さとして一般的な範囲はどれか。

  1. A数nm程度
  2. B数µm〜数十µm程度
  3. C数mm程度
答えと解説を見る

正解：B. 数µm〜数十µm程度

ロジックやイメージセンサ用のエピ層は数µm程度、高耐圧のパワーデバイス用では数十µm以上になることもあります。厚さ約775 µmのウエハ本体に比べるとごく薄い層です。

  • A. 数nmは量子井戸などの極薄の層の厚さです。
  • B. 正しい。数µm〜数十µmが一般的です。
  • C. 数mmはウエハ本体よりも厚く、エピ層の厚さではありません。

エピタキシャル成長のほかの問題

  1. シリコンのエピタキシャル成長で、原料ガスと一緒に大量に流される水素(H2)の主な役割はどれか。
  2. GaNの自立基板をつくるために、厚いGaN層を高速に成長させる方法として使われるものはどれか。
  3. サファイア基板上に成長させたGaNに含まれる、膜の表面まで突き抜ける貫通転位の密度の目安として最も近いものはどれか。
  4. バイポーラトランジスタなどで、エピタキシャル層の下に高濃度の層(埋め込み層)を設ける主な目的はどれか。
  5. SiCのエピタキシャル成長(CVD)の一般的な成長温度に最も近いものはどれか。
