エピタキシャル成長

MBE(分子線エピタキシー)の特徴として正しいものはどれか。

  1. A大気圧で厚い膜を高速に成長させる
  2. B超高真空中で原料を分子線として基板に供給し、膜厚や組成を原子層レベルで精密に制御できる
  3. C液体の原料にウエハを浸して成長させる
答えと解説を見る

正解：B. 超高真空中で原料を分子線として基板に供給し、膜厚や組成を原子層レベルで精密に制御できる

MBEは、超高真空の装置内で原料を加熱して分子(原子)の線として基板に当て、結晶を成長させる方法です。成長の様子をその場で観察しながら、原子層単位で膜厚や組成を制御できるため、研究開発や高性能な化合物半導体デバイスに使われます。成長速度は遅く、量産性はMOCVDに劣ります。

  2. 選択エピタキシャル成長の説明として正しいものはどれか。
  3. エピタキシャル成長中に、基板などの不純物が気相を通じて成長層に取り込まれてしまう現象を何と呼ぶか。
  4. p+基板の上に低濃度のp型エピタキシャル層を成長させたウエハ(p/p+エピウエハ)の利点として正しいものはどれか。
  5. ヘテロエピタキシャル成長における臨界膜厚の説明として正しいものはどれか。
