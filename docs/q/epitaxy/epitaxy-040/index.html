エピタキシャル成長

エピタキシャル層の結晶の品質を評価するX線回折のロッキングカーブで、ピークの半値幅が狭いことは何を意味するか。

  1. A膜が厚いこと
  2. B結晶の傾きやモザイク性、欠陥が少なく、結晶の品質がよいこと
  3. C不純物濃度が高いこと
答えと解説を見る

正解：B. 結晶の傾きやモザイク性、欠陥が少なく、結晶の品質がよいこと

ロッキングカーブは、試料の角度を少しずつ変えながら特定の回折ピークの強さを測ったものです。結晶の向きのばらつき(モザイク性)や転位が多いとピークが広がるため、半値幅が狭いほど結晶の品質がよいことを示します。GaNなどのエピ層の評価に広く使われます。

  • A. 半値幅は膜厚の直接の指標ではありません。
  • B. 正しい。結晶の向きのそろいがよく、欠陥が少ないことを示します。
  • C. 不純物濃度の直接の指標ではありません。

エピタキシャル成長のほかの問題

  1. MOCVDによるGaNの成長で、条件として管理される「V/III比」の意味はどれか。
  2. 高濃度の基板の上に低濃度のエピ層を高温で成長させるとき、固体の中の拡散によって基板の不純物がエピ層側にしみ出し、界面の濃度変化がなだらかになる現象を何と呼ぶか。
  3. サファイア基板の上に高品質なGaNを成長させるために、赤﨑勇・天野浩らが開発した、まず低温で薄い層を堆積してから高温でGaNを成長させる技術はどれか。
  4. 格子不整合のある系で、最初の数原子層は層状に成長し、ひずみがたまると島状に成長に変わる成長様式はどれか。量子ドットの作製にも利用される。
  5. 埋め込み層などのパターンがある基板の上にシリコンをエピタキシャル成長させたとき、表面に現れる段差の位置が下のパターンからずれたり、形がゆがんだりする現象を何と呼ぶか。
