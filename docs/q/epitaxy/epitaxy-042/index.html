エピタキシャル成長

高濃度の基板の上に低濃度のエピ層を高温で成長させるとき、固体の中の拡散によって基板の不純物がエピ層側にしみ出し、界面の濃度変化がなだらかになる現象を何と呼ぶか。

  1. Aエレクトロマイグレーション
  2. Bスパッタリング
  3. C外方拡散(アウトディフュージョン)
答えと解説を見る

正解：C. 外方拡散(アウトディフュージョン)

エピ成長や後の熱処理の高温によって、高濃度基板の不純物が固体中を拡散してエピ層に入り込み、基板とエピ層の境界の濃度変化がなだらかになります。これが外方拡散で、実効的な低濃度層の厚さが減り、パワーデバイスでは耐圧の低下につながります。拡散の遅いヒ素やアンチモンを基板に使い、熱予算を抑えて防ぎます。気相を通じて取り込まれるオートドーピングとは区別されます。

  • A. エレクトロマイグレーションは、電流によって配線の金属原子が移動する現象です。
  • B. スパッタリングは、イオンの衝突で原子をはじき出す成膜法です。
  • C. 正しい。基板の不純物が固体中を拡散してエピ層に入る現象です。

  2. 格子不整合のある系で、最初の数原子層は層状に成長し、ひずみがたまると島状に成長に変わる成長様式はどれか。量子ドットの作製にも利用される。
