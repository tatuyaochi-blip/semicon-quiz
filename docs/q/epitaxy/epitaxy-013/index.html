エピタキシャル成長

CVDによるエピタキシャル成長で、比較的低い温度の領域では成長速度が温度に強く依存する。その理由として正しいものはどれか。

  1. A原料ガスの供給量だけで成長速度が決まるため
  2. B表面での化学反応の速さが成長速度を決めている(表面反応律速)ため
  3. C成長速度が温度に依存しないため
答えと解説を見る

正解：B. 表面での化学反応の速さが成長速度を決めている(表面反応律速)ため

低温では表面での反応が遅く、反応の速さが成長速度を決めます(表面反応律速)。反応速度は温度に指数関数的に依存するため、成長速度も温度に強く依存します。高温では反応が十分速くなり、原料ガスの供給の速さが成長速度を決める供給律速になります。

エピタキシャル成長のほかの問題

  2. GaNなどで、マスクの開口部から結晶を成長させ、マスクの上を横方向に成長させることで転位を減らす技術を何と呼ぶか。
  3. 溶かした金属の溶液などから、基板の上に結晶を析出させて成長させる方法はどれか。
  4. トリクロロシランを使ったシリコンのエピタキシャル成長の一般的な成長温度に最も近いものはどれか。
  5. 格子定数の大きい緩和したSiGe層の上に、薄いシリコン層をエピタキシャル成長させたとき、シリコン層に生じるひずみはどれか。
