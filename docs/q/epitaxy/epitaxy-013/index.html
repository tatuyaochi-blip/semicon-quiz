エピタキシャル成長

CVDによるエピタキシャル成長で、比較的低い温度の領域では成長速度が温度に強く依存する。その理由として正しいものはどれか。

  1. A原料ガスの供給量だけで成長速度が決まるため
  2. B表面での化学反応の速さが成長速度を決めている(表面反応律速)ため
  3. C成長速度が温度に依存しないため
答えと解説を見る

正解：B. 表面での化学反応の速さが成長速度を決めている(表面反応律速)ため

低温では表面での化学反応が遅く、反応の速さが成長速度を決めます(表面反応律速)。反応速度はアレニウスの式に従って温度に指数関数的に依存するため、成長速度も温度に強く依存し、ウエハ内の温度の均一性がそのまま膜厚の均一性になります。高温では反応が十分速くなり、原料ガスが表面に届く速さが成長速度を決める供給律速(拡散律速)になり、ガスの流れの均一性が重要になります。
