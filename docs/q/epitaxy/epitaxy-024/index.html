エピタキシャル成長

エピタキシャル成長中にドーピングガスを流し、成長と同時に不純物を添加することを何と呼ぶか。

  1. Aインサイチュドーピング
  2. Bイオン注入
  3. Cゲッタリング
答えと解説を見る

正解：A. インサイチュドーピング

インサイチュドーピングでは、成長と同時にドーピングガス(ホスフィン、ジボランなど)を流して不純物を取り込むため、イオン注入のような結晶の損傷や活性化のための高温アニールが不要です。ガスの流量を切り替えて深さ方向に精密な濃度分布をつくれ、活性化率も高くできます。先端トランジスタのソース・ドレインのSiGe:BやSi:Pのエピ層では、10²¹ cm⁻³級の高濃度を実現しています。

エピタキシャル成長のほかの問題

  1. 異なる材料の層を交互に積み重ね、各層を数nm程度に薄くした周期的な構造を何と呼ぶか。
  2. SiGe HBTのベース層を形成するのに使われる技術として正しいものはどれか。
  3. エピタキシャル成長中に不純物を添加する方法が、熱拡散と比べて有利な点として正しいものはどれか。
  4. 先端CMOSの工程で、シリコンやSiGeのエピタキシャル成長の温度を下げることが求められる理由として正しいものはどれか。
  5. SiCパワーデバイスに主に使われている結晶多形(ポリタイプ)はどれか。
