エピタキシャル成長

格子定数の大きい緩和したSiGe層の上に、薄いシリコン層をエピタキシャル成長させたとき、シリコン層に生じるひずみはどれか。

  1. A圧縮ひずみ
  2. Bひずみは生じない
  3. C引っ張りひずみ
答えと解説を見る

正解：C. 引っ張りひずみ

シリコンの格子定数はSiGeより小さいため、SiGeの上に成長させると、シリコンの原子の間隔がSiGeに合わせて引き伸ばされ、引っ張りひずみが生じます。引っ張りひずみをもつシリコンでは電子の移動度が高くなるため、nMOSの性能向上に使われてきました。
