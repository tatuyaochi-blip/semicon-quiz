エピタキシャル成長

エピタキシャル成長中に不純物を添加する方法が、熱拡散と比べて有利な点として正しいものはどれか。

  1. A必ず安価である
  2. B深さ方向に急峻な濃度の変化をつくりやすい
  3. C濃度を均一にできない
答えと解説を見る

正解：B. 深さ方向に急峻な濃度の変化をつくりやすい

熱拡散では、不純物が表面から内部へ広がるため、濃度はなだらかに変化します。エピタキシャル成長では、成長中に添加するガスの量を切り替えることで、層ごとに濃度を変えられ、急峻な濃度の変化や、内部に高濃度の層を埋め込んだ構造をつくれます。

  2. SiCパワーデバイスに主に使われている結晶多形(ポリタイプ)はどれか。
  3. MBEで、成長中の表面に電子線を浅い角度で当て、その回折像から成長の様子をその場で観察する手法はどれか。
  4. 「エピタキシー(epitaxy)」という言葉の由来として正しいものはどれか。
  5. LSIやパワーデバイス用のシリコンエピウエハで、エピタキシャル層の厚さとして一般的な範囲はどれか。
