エピタキシャル成長

SiGe HBTのベース層を形成するのに使われる技術として正しいものはどれか。

  1. Aエピタキシャル成長(Ge濃度を深さ方向に変化させることもある)
  2. BCMP
  3. Cスパッタリング
答えと解説を見る

正解：A. エピタキシャル成長(Ge濃度を深さ方向に変化させることもある)

SiGe HBTのベースは、シリコンの上にSiGe層をエピタキシャル成長させてつくります。Geの濃度をエミッタ側からコレクタ側に向けて増やすと、バンドギャップの傾きによってベース内に電界ができ、電子が加速されて高速動作に有利になります。

エピタキシャル成長のほかの問題

  1. エピタキシャル成長中に不純物を添加する方法が、熱拡散と比べて有利な点として正しいものはどれか。
  2. 先端CMOSの工程で、シリコンやSiGeのエピタキシャル成長の温度を下げることが求められる理由として正しいものはどれか。
  3. SiCパワーデバイスに主に使われている結晶多形(ポリタイプ)はどれか。
  4. MBEで、成長中の表面に電子線を浅い角度で当て、その回折像から成長の様子をその場で観察する手法はどれか。
  5. 「エピタキシー(epitaxy)」という言葉の由来として正しいものはどれか。
