エピタキシャル成長

MBEで、成長中の表面に電子線を浅い角度で当て、その回折像から成長の様子をその場で観察する手法はどれか。

  1. ASIMS
  2. BRHEED(反射高速電子回折)
  3. CXPS
答えと解説を見る

正解：B. RHEED(反射高速電子回折)

RHEEDは、成長中の表面に高速の電子線をすれすれに当て、回折パターンを蛍光スクリーンで観察する手法です。表面の平坦さや結晶構造がわかり、1原子層ずつ成長するたびに強度が振動するため、成長した層の数をその場で数えることもできます。超高真空のMBEならではの観察方法です。

  3. シリコンのエピタキシャル成長で、原料ガスと一緒に大量に流される水素(H2)の主な役割はどれか。
  4. GaNの自立基板をつくるために、厚いGaN層を高速に成長させる方法として使われるものはどれか。
  5. サファイア基板上に成長させたGaNに含まれる、膜の表面まで突き抜ける貫通転位の密度の目安として最も近いものはどれか。
