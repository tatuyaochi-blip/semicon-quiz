エピタキシャル成長

MOCVDによるGaNの成長で、条件として管理される「V/III比」の意味はどれか。

  1. A膜厚と成長時間の比
  2. B供給するV族原料(アンモニアなど)とIII族原料(有機ガリウムなど)のモル比
  3. C成長温度と圧力の比
答えと解説を見る

正解：B. 供給するV族原料(アンモニアなど)とIII族原料(有機ガリウムなど)のモル比

V/III比は、反応炉に供給するV族元素の原料とIII族元素の原料の量の比です。GaNの成長では、アンモニアの分解効率が低く、高温で窒素が抜けやすいため、V/III比を数百〜数千と非常に大きくします。V/III比は、表面の平坦性、横方向と縦方向の成長の速さのバランス、炭素などの不純物の取り込み、点欠陥の量などに影響する重要な条件です。

  • A. 膜厚と時間の比は成長速度です。
  • B. 正しい。V族とIII族の原料の供給比です。
  • C. 温度と圧力の比ではありません。

エピタキシャル成長のほかの問題

  1. 高濃度の基板の上に低濃度のエピ層を高温で成長させるとき、固体の中の拡散によって基板の不純物がエピ層側にしみ出し、界面の濃度変化がなだらかになる現象を何と呼ぶか。
  2. サファイア基板の上に高品質なGaNを成長させるために、赤﨑勇・天野浩らが開発した、まず低温で薄い層を堆積してから高温でGaNを成長させる技術はどれか。
  3. 格子不整合のある系で、最初の数原子層は層状に成長し、ひずみがたまると島状に成長に変わる成長様式はどれか。量子ドットの作製にも利用される。
  4. 埋め込み層などのパターンがある基板の上にシリコンをエピタキシャル成長させたとき、表面に現れる段差の位置が下のパターンからずれたり、形がゆがんだりする現象を何と呼ぶか。
  5. nMOSのソース・ドレインに、シリコンに少量の炭素を加えたSi:Cをエピタキシャル成長させて埋め込む主な目的はどれか。
