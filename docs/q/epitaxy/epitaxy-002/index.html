エピタキシャル成長

ヘテロエピタキシャル成長の例として正しいものはどれか。

  1. Aシリコン基板上へのシリコンの成長
  2. Bシリコン基板上へのSiGeの成長
  3. Cシリコン基板の熱酸化
答えと解説を見る

正解：B. シリコン基板上へのSiGeの成長

基板と同じ材料を成長させることをホモエピタキシー、異なる材料を成長させることをヘテロエピタキシーといいます。シリコン上のSiGeや、サファイアやSiC上のGaNなどがヘテロエピタキシーの例です。熱酸化でできるSiO2はアモルファスで、エピタキシャル成長ではありません。
