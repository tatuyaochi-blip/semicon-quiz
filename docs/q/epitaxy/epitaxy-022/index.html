エピタキシャル成長

高濃度基板の上の低濃度エピ層の厚さを、赤外光の干渉を利用して測る方法はどれか。

  1. ASIMS
  2. BSEMによる断面観察
  3. Cフーリエ変換赤外分光(FTIR)法
答えと解説を見る

正解：C. フーリエ変換赤外分光(FTIR)法

高濃度基板とエピ層では、赤外光に対する屈折率がわずかに異なるため、界面で反射が起こります。表面と界面からの反射光の干渉をFTIRで測ると、非破壊でエピ層の厚さを求められます。エピウエハの膜厚管理に広く使われています。
