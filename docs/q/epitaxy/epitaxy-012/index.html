エピタキシャル成長

SiCパワーデバイスの製造でエピタキシャル層が重要な理由として正しいものはどれか。

  1. A耐圧を受け持つドリフト層を、低い不純物濃度と必要な厚さで精密に形成するため
  2. Bウエハを透明にするため
  3. C配線の抵抗を下げるため
答えと解説を見る

正解：A. 耐圧を受け持つドリフト層を、低い不純物濃度と必要な厚さで精密に形成するため

SiCでは不純物の熱拡散がほとんど起こらないため、デバイスの主要な層はエピタキシャル成長とイオン注入で形成します。1200 V級ではドリフト層を約10 µm・10¹⁶ cm⁻³程度に精密に制御する必要があり、耐圧とオン抵抗を直接決めます。エピ層中の基底面転位や表面欠陥はキラー欠陥やバイポーラ劣化の原因になるため、欠陥を減らすことが歩留まりと信頼性の鍵です。
