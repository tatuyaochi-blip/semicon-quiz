エピタキシャル成長

SiCパワーデバイスの製造でエピタキシャル層が重要な理由として正しいものはどれか。

  1. A耐圧を受け持つドリフト層を、低い不純物濃度と必要な厚さで精密に形成するため
  2. Bウエハを透明にするため
  3. C配線の抵抗を下げるため
答えと解説を見る

正解：A. 耐圧を受け持つドリフト層を、低い不純物濃度と必要な厚さで精密に形成するため

SiCでは不純物の熱拡散がほとんど起こらないため、デバイスの主要な層はエピタキシャル成長で形成します。耐圧を決めるドリフト層の不純物濃度と厚さを精密に制御する必要があり、エピ層の結晶欠陥を減らすことも歩留まりや信頼性の面で重要です。

エピタキシャル成長のほかの問題

  1. CVDによるエピタキシャル成長で、比較的低い温度の領域では成長速度が温度に強く依存する。その理由として正しいものはどれか。
  2. エピタキシャル層に生じる代表的な結晶欠陥の一つで、原子面の積み重なりの順序が乱れたものはどれか。
  3. GaNなどで、マスクの開口部から結晶を成長させ、マスクの上を横方向に成長させることで転位を減らす技術を何と呼ぶか。
  4. 溶かした金属の溶液などから、基板の上に結晶を析出させて成長させる方法はどれか。
  5. トリクロロシランを使ったシリコンのエピタキシャル成長の一般的な成長温度に最も近いものはどれか。
