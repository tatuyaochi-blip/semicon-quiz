エピタキシャル成長

ヘテロエピタキシャル成長における臨界膜厚の説明として正しいものはどれか。

  1. A成長が始まるために必要な最小の膜厚
  2. Bエッチングで除去できる最大の膜厚
  3. C転位を発生させずに、ひずみを保ったまま成長できる最大の膜厚
答えと解説を見る

正解：C. 転位を発生させずに、ひずみを保ったまま成長できる最大の膜厚

格子定数の異なる膜は、薄いうちは基板に合わせてひずんだまま成長します(コヒーレント成長)。しかし膜厚が臨界膜厚を超えると、ひずみエネルギーを解放するためにミスフィット転位が発生します。ひずみSiGe層などを設計するときに重要な値です。

エピタキシャル成長のほかの問題

  1. シリコンのエピタキシャル成長の直前に、高温の水素雰囲気でウエハを加熱する主な目的はどれか。
  2. SiCパワーデバイスの製造でエピタキシャル層が重要な理由として正しいものはどれか。
  3. CVDによるエピタキシャル成長で、比較的低い温度の領域では成長速度が温度に強く依存する。その理由として正しいものはどれか。
  4. エピタキシャル層に生じる代表的な結晶欠陥の一つで、原子面の積み重なりの順序が乱れたものはどれか。
  5. GaNなどで、マスクの開口部から結晶を成長させ、マスクの上を横方向に成長させることで転位を減らす技術を何と呼ぶか。
