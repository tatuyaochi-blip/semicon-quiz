エピタキシャル成長

溶かした金属の溶液などから、基板の上に結晶を析出させて成長させる方法はどれか。

  1. A液相エピタキシー(LPE)
  2. B分子線エピタキシー(MBE)
  3. C有機金属気相成長(MOCVD)
答えと解説を見る

正解：A. 液相エピタキシー(LPE)

液相エピタキシーは、成長させたい材料を溶かし込んだ金属(GaAsならガリウム)の溶液を基板に接触させ、温度を下げて過飽和にした分を結晶として析出させる方法です。熱平衡に近い条件で成長するため結晶性がよく、装置が簡単で成長も速いため、かつては赤色・赤外LEDや初期の半導体レーザーの製造に広く使われました。薄い層や急峻な界面の制御は、MOCVDやMBEの方が得意です。
