エピタキシャル成長

エピタキシャルウエハの品質として管理される主な項目はどれか。

  1. Aウエハの色と重さ
  2. Bエピ層の膜厚と抵抗率(不純物濃度)、結晶欠陥
  3. Cウエハの価格だけ
答えと解説を見る

正解：B. エピ層の膜厚と抵抗率(不純物濃度)、結晶欠陥

エピタキシャルウエハでは、エピ層の膜厚と抵抗率(不純物濃度)が仕様どおりで、ウエハ面内で均一であることが重要で、例えば膜厚・抵抗率とも±数%以内に管理されます。さらに、積層欠陥などの結晶欠陥やパーティクルが少ないこと、平坦度、金属汚染なども管理されます。膜厚はFTIRで、抵抗率はC-V測定などで非破壊に測り、欠陥はレーザー散乱式の表面検査装置で数えます。
