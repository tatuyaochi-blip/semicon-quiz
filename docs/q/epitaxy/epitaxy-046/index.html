エピタキシャル成長

nMOSのソース・ドレインに、シリコンに少量の炭素を加えたSi:Cをエピタキシャル成長させて埋め込む主な目的はどれか。

  1. Aゲート容量を減らす
  2. Bチャネルに圧縮ひずみを加えて正孔の移動度を上げる
  3. C格子定数の小さいSi:Cでチャネルに引っ張りひずみを加え、電子の移動度を上げる
答えと解説を見る

正解：C. 格子定数の小さいSi:Cでチャネルに引っ張りひずみを加え、電子の移動度を上げる

炭素はシリコンより原子が小さいため、Si:Cの格子定数はシリコンより小さくなります。これをnMOSのソース・ドレインに埋め込むと、チャネルが引っ張られて引っ張りひずみが生じ、電子の移動度が上がります。pMOSでは逆に格子定数の大きいSiGeを埋め込んで圧縮ひずみを加えます。

  • A. ゲート容量を減らす目的ではありません。
  • B. 圧縮ひずみで正孔の移動度を上げるのは、pMOSのSiGeの役割です。
  • C. 正しい。引っ張りひずみで電子の移動度を上げます。

エピタキシャル成長のほかの問題

  1. グラフェンなどの2次元材料で覆った基板の上に結晶を成長させ、成長した膜を基板からはがして再利用できるようにする研究段階の技術はどれか。
  2. GaN HEMT用のエピ構造で、チャネルの下のGaNバッファ層に炭素や鉄を添加する主な目的はどれか。
  3. GaAsのような極性をもつ化合物半導体を、無極性のシリコン基板の上に成長させるときに生じやすい、結晶の中でGaとAsの並びが反転した領域の境界を何と呼ぶか。
  4. SiCのエピタキシャル成長で、表面の原子ステップがいくつも集まって大きな段差になり、表面が荒れる現象を何と呼ぶか。
  5. エピタキシャル成長の説明として正しいものはどれか。
