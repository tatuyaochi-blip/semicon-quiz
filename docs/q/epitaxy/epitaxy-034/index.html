エピタキシャル成長

GaNの自立基板をつくるために、厚いGaN層を高速に成長させる方法として使われるものはどれか。

  1. AALD(原子層堆積)
  2. BHVPE(ハイドライド気相成長)
  3. C熱酸化
答えと解説を見る

正解：B. HVPE(ハイドライド気相成長)

HVPEは、高温のガリウムに塩化水素を流して塩化ガリウム(GaCl)をつくり、アンモニアと反応させてGaNを成長させる方法で、毎時数十〜数百µmとMOCVDの数十倍の速さが得られます。サファイアなどの上に数百µm〜mmの厚いGaNを成長させ、基板を外すと自立基板になり、厚く成長させるほど転位が減っていく利点もあります。GaN基板はレーザーや縦型パワーデバイスに使われます。

  • A. ALDは原子層ずつ成長させる方法で、厚い層の成長には向きません。
  • B. 正しい。高い成長速度で厚いGaNを成長させます。
  • C. 熱酸化はシリコンの酸化膜をつくる工程です。

エピタキシャル成長のほかの問題

  1. サファイア基板上に成長させたGaNに含まれる、膜の表面まで突き抜ける貫通転位の密度の目安として最も近いものはどれか。
  2. バイポーラトランジスタなどで、エピタキシャル層の下に高濃度の層(埋め込み層)を設ける主な目的はどれか。
  3. SiCのエピタキシャル成長(CVD)の一般的な成長温度に最も近いものはどれか。
  4. 300 mmウエハのシリコンエピタキシャル成長で主流となっている反応炉の形式はどれか。
  5. 格子定数の大きく異なる材料をヘテロエピタキシャル成長させるとき、組成を少しずつ変えた層を間に挟む「グレーデッドバッファ層」の目的はどれか。
