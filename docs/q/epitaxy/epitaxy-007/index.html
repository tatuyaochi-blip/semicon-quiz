エピタキシャル成長

選択エピタキシャル成長の説明として正しいものはどれか。

  1. Aウエハ全面に均一に成長させる
  2. Bアモルファスの膜を選んで成長させる
  3. Cシリコンが露出した部分にだけ結晶を成長させ、絶縁膜の上には成長させない
答えと解説を見る

正解：C. シリコンが露出した部分にだけ結晶を成長させ、絶縁膜の上には成長させない

選択エピタキシャル成長では、成長条件を調整して、シリコンが露出した部分だけに結晶を成長させ、酸化膜や窒化膜の上には成長させません。先端CMOSのソース・ドレインにSiGeやSiCを埋め込んでチャネルにひずみを加える工程などで使われています。

エピタキシャル成長のほかの問題

  1. エピタキシャル成長中に、基板などの不純物が気相を通じて成長層に取り込まれてしまう現象を何と呼ぶか。
  2. p+基板の上に低濃度のp型エピタキシャル層を成長させたウエハ(p/p+エピウエハ)の利点として正しいものはどれか。
  3. ヘテロエピタキシャル成長における臨界膜厚の説明として正しいものはどれか。
  4. シリコンのエピタキシャル成長の直前に、高温の水素雰囲気でウエハを加熱する主な目的はどれか。
  5. SiCパワーデバイスの製造でエピタキシャル層が重要な理由として正しいものはどれか。
