エピタキシャル成長

p+基板の上に低濃度のp型エピタキシャル層を成長させたウエハ(p/p+エピウエハ)の利点として正しいものはどれか。

  1. Aウエハが透明になる
  2. B表面の結晶品質がよく、CMOSのラッチアップを抑えやすい
  3. Cエッチングが不要になる
答えと解説を見る

正解：B. 表面の結晶品質がよく、CMOSのラッチアップを抑えやすい

エピ層は欠陥が少なく、デバイスをつくる表面の品質がよくなります。また、下に低抵抗のp+基板があることで寄生トランジスタが動作しにくくなり、CMOSのラッチアップを抑えやすくなります。高濃度基板は金属不純物のゲッタリングにも役立ちます。

エピタキシャル成長のほかの問題

  1. ヘテロエピタキシャル成長における臨界膜厚の説明として正しいものはどれか。
  2. シリコンのエピタキシャル成長の直前に、高温の水素雰囲気でウエハを加熱する主な目的はどれか。
  3. SiCパワーデバイスの製造でエピタキシャル層が重要な理由として正しいものはどれか。
  4. CVDによるエピタキシャル成長で、比較的低い温度の領域では成長速度が温度に強く依存する。その理由として正しいものはどれか。
  5. エピタキシャル層に生じる代表的な結晶欠陥の一つで、原子面の積み重なりの順序が乱れたものはどれか。
