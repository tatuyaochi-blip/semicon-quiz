エピタキシャル成長

エピタキシャル成長中に、基板などの不純物が気相を通じて成長層に取り込まれてしまう現象を何と呼ぶか。

  1. Aオートドーピング
  2. Bゲッタリング
  3. Cエレクトロマイグレーション
答えと解説を見る

正解：A. オートドーピング

オートドーピングは、高濃度に不純物を含む基板やその裏面・側面から不純物が蒸発し、ガスを通じて成長中の層に取り込まれる現象です。特に成長の初期に多く、エピ層の不純物濃度が設計値からずれたり、界面の濃度変化がなだらかになったりします。基板の裏面を酸化膜やポリシリコンで覆う、減圧で成長させる、成長前に一度ガスで不純物を追い出すなどの対策がとられます。

エピタキシャル成長のほかの問題

  1. p+基板の上に低濃度のp型エピタキシャル層を成長させたウエハ(p/p+エピウエハ)の利点として正しいものはどれか。
  2. ヘテロエピタキシャル成長における臨界膜厚の説明として正しいものはどれか。
  3. シリコンのエピタキシャル成長の直前に、高温の水素雰囲気でウエハを加熱する主な目的はどれか。
  4. SiCパワーデバイスの製造でエピタキシャル層が重要な理由として正しいものはどれか。
  5. CVDによるエピタキシャル成長で、比較的低い温度の領域では成長速度が温度に強く依存する。その理由として正しいものはどれか。
