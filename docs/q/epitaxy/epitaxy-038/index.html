エピタキシャル成長

300 mmウエハのシリコンエピタキシャル成長で主流となっている反応炉の形式はどれか。

  1. Aウエハを1枚ずつ処理する枚葉式の反応炉
  2. B液体に浸すディップ式
  3. C数百枚をまとめて処理するバッチ式の拡散炉
答えと解説を見る

正解：A. ウエハを1枚ずつ処理する枚葉式の反応炉

300 mmウエハのエピタキシャル成長では、ウエハを1枚ずつ石英窓越しのハロゲンランプで急速に加熱し、ガスの流れや温度を精密に制御する枚葉式の反応炉が主流です。ウエハを回転させて均一性を高め、膜厚や抵抗率のばらつきを±1〜2%程度に抑えます。条件の調整もしやすく、加熱・冷却が速いため熱予算も小さくできます。代表的なメーカーは米国のApplied MaterialsやASMなどです。

  • A. 正しい。枚葉式の反応炉が主流です。
  • B. 液体に浸す方式は液相成長で、シリコンのLSI用エピでは使いません。
  • C. バッチ式の炉は酸化や拡散などで使われますが、300 mmのエピでは枚葉式が主流です。

エピタキシャル成長のほかの問題

  1. 格子定数の大きく異なる材料をヘテロエピタキシャル成長させるとき、組成を少しずつ変えた層を間に挟む「グレーデッドバッファ層」の目的はどれか。
  2. エピタキシャル層の結晶の品質を評価するX線回折のロッキングカーブで、ピークの半値幅が狭いことは何を意味するか。
  3. MOCVDによるGaNの成長で、条件として管理される「V/III比」の意味はどれか。
  4. 高濃度の基板の上に低濃度のエピ層を高温で成長させるとき、固体の中の拡散によって基板の不純物がエピ層側にしみ出し、界面の濃度変化がなだらかになる現象を何と呼ぶか。
  5. サファイア基板の上に高品質なGaNを成長させるために、赤﨑勇・天野浩らが開発した、まず低温で薄い層を堆積してから高温でGaNを成長させる技術はどれか。
