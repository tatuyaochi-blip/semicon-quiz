エピタキシャル成長

格子定数の大きく異なる材料をヘテロエピタキシャル成長させるとき、組成を少しずつ変えた層を間に挟む「グレーデッドバッファ層」の目的はどれか。

  1. Aウエハを薄くするため
  2. B格子定数を徐々に変化させて、ひずみを少しずつ緩和し、上の層に貫通する転位を減らすため
  3. C成長速度を上げるため
答えと解説を見る

正解：B. 格子定数を徐々に変化させて、ひずみを少しずつ緩和し、上の層に貫通する転位を減らすため

格子定数の差が大きい材料を直接成長させると、多くの転位が上の層まで突き抜けます。組成を少しずつ変えたバッファ層(例えばGeを1 µmあたり10%ずつ増やすSiGe)を挟むと、ひずみが段階的に緩和され、ミスフィット転位が界面に沿って長く伸びてバッファ層の中にとどまり、上の層の貫通転位を10⁵〜10⁶ cm⁻²程度まで減らせます。その分バッファ層は数µmと厚くなります。

  • A. ウエハを薄くする目的ではありません。
  • B. 正しい。ひずみを段階的に緩和して上の層の転位を減らします。
  • C. 成長速度を上げる目的ではありません。

エピタキシャル成長のほかの問題

  1. エピタキシャル層の結晶の品質を評価するX線回折のロッキングカーブで、ピークの半値幅が狭いことは何を意味するか。
  2. MOCVDによるGaNの成長で、条件として管理される「V/III比」の意味はどれか。
  3. 高濃度の基板の上に低濃度のエピ層を高温で成長させるとき、固体の中の拡散によって基板の不純物がエピ層側にしみ出し、界面の濃度変化がなだらかになる現象を何と呼ぶか。
  4. サファイア基板の上に高品質なGaNを成長させるために、赤﨑勇・天野浩らが開発した、まず低温で薄い層を堆積してから高温でGaNを成長させる技術はどれか。
  5. 格子不整合のある系で、最初の数原子層は層状に成長し、ひずみがたまると島状に成長に変わる成長様式はどれか。量子ドットの作製にも利用される。
