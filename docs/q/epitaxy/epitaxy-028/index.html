エピタキシャル成長

先端CMOSの工程で、シリコンやSiGeのエピタキシャル成長の温度を下げることが求められる理由として正しいものはどれか。

  1. Aエピタキシャル成長を速くするため
  2. B装置を大型化するため
  3. Cすでに形成した構造の不純物の拡散や変形を抑えるため(熱予算の制約)
答えと解説を見る

正解：C. すでに形成した構造の不純物の拡散や変形を抑えるため(熱予算の制約)

トランジスタの微細な構造や急峻な不純物の分布は、高温にさらされると崩れてしまいます。そのため、工程の後半で行うエピタキシャル成長などは、できるだけ低い温度で行う必要があります。工程全体で許される熱の量を熱予算(サーマルバジェット)といいます。

エピタキシャル成長のほかの問題

  1. SiCパワーデバイスに主に使われている結晶多形(ポリタイプ)はどれか。
  2. MBEで、成長中の表面に電子線を浅い角度で当て、その回折像から成長の様子をその場で観察する手法はどれか。
  3. 「エピタキシー(epitaxy)」という言葉の由来として正しいものはどれか。
  4. LSIやパワーデバイス用のシリコンエピウエハで、エピタキシャル層の厚さとして一般的な範囲はどれか。
  5. シリコンのエピタキシャル成長で、原料ガスと一緒に大量に流される水素(H2)の主な役割はどれか。
