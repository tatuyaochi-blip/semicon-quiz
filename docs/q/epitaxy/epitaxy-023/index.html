エピタキシャル成長

Si基板の上にGaNを成長させるときの主な課題はどれか。

  1. A基板が非常に高価である
  2. B格子定数や熱膨張係数の差が大きく、転位やクラック、ウエハの反りが生じやすい
  3. CGaNがまったく成長しない
答えと解説を見る

正解：B. 格子定数や熱膨張係数の差が大きく、転位やクラック、ウエハの反りが生じやすい

GaNとシリコンは格子定数の差が約17%と大きいため転位が多く発生し、熱膨張係数もGaNの方が大きいため、1000 ℃以上で成長させて冷やすと膜に引っ張り応力がかかり、クラックや数十µmのウエハの反りが生じやすくなります。さらにGaとSiが高温で反応する問題もあります。AlNの核形成層とAlGaNなどの多層のバッファ層で応力を打ち消すことで、200 mmのSi基板上へのGaNの成長が実用化されています。

  2. 異なる材料の層を交互に積み重ね、各層を数nm程度に薄くした周期的な構造を何と呼ぶか。
  3. SiGe HBTのベース層を形成するのに使われる技術として正しいものはどれか。
  4. エピタキシャル成長中に不純物を添加する方法が、熱拡散と比べて有利な点として正しいものはどれか。
  5. 先端CMOSの工程で、シリコンやSiGeのエピタキシャル成長の温度を下げることが求められる理由として正しいものはどれか。
