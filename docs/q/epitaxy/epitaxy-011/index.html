エピタキシャル成長

シリコンのエピタキシャル成長の直前に、高温の水素雰囲気でウエハを加熱する主な目的はどれか。

  1. A表面を厚く酸化させる
  2. B不純物を高濃度に添加する
  3. C表面の自然酸化膜を除去し、清浄な結晶面を露出させる
答えと解説を見る

正解：C. 表面の自然酸化膜を除去し、清浄な結晶面を露出させる

表面に自然酸化膜や汚染が残っていると、その上には単結晶がうまく成長せず、欠陥の原因になります。成長の前に水素中で高温に加熱(水素ベーク)して自然酸化膜を取り除き、清浄なシリコンの結晶面を露出させてから成長を始めます。

エピタキシャル成長のほかの問題

  1. SiCパワーデバイスの製造でエピタキシャル層が重要な理由として正しいものはどれか。
  2. CVDによるエピタキシャル成長で、比較的低い温度の領域では成長速度が温度に強く依存する。その理由として正しいものはどれか。
  3. エピタキシャル層に生じる代表的な結晶欠陥の一つで、原子面の積み重なりの順序が乱れたものはどれか。
  4. GaNなどで、マスクの開口部から結晶を成長させ、マスクの上を横方向に成長させることで転位を減らす技術を何と呼ぶか。
  5. 溶かした金属の溶液などから、基板の上に結晶を析出させて成長させる方法はどれか。
