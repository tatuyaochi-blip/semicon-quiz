エピタキシャル成長

GaNなどで、マスクの開口部から結晶を成長させ、マスクの上を横方向に成長させることで転位を減らす技術を何と呼ぶか。

  1. A横方向エピタキシャル成長(ELO)
  2. BALD
  3. CCMP
答えと解説を見る

正解：A. 横方向エピタキシャル成長(ELO)

ELOでは、マスクの開口部から成長した結晶がマスクの上を横方向に広がって成長します。基板から伸びる転位はマスクでさえぎられるため、マスクの上の領域では転位の少ない結晶が得られます。GaN系レーザーの高性能化などに使われてきました。

  3. 格子定数の大きい緩和したSiGe層の上に、薄いシリコン層をエピタキシャル成長させたとき、シリコン層に生じるひずみはどれか。
  4. エピタキシャルウエハの品質として管理される主な項目はどれか。
  5. SiCのエピタキシャル成長で、結晶軸から数度傾けた(オフ角をつけた)基板を使う主な理由はどれか。
