エピタキシャル成長

トリクロロシランを使ったシリコンのエピタキシャル成長の一般的な成長温度に最も近いものはどれか。

  1. A約100 ℃
  2. B約1100 ℃
  3. C約2000 ℃
答えと解説を見る

正解：B. 約1100 ℃

トリクロロシランを使ったシリコンのエピタキシャル成長は、一般に1100 ℃前後の高温で行われます。ジクロロシランやシランを使うと、より低い温度でも成長できます。2000 ℃はシリコンの融点(約1414 ℃)を超えています。
