エピタキシャル成長

SiCパワーデバイスに主に使われている結晶多形(ポリタイプ)はどれか。

  1. A4H-SiC
  2. B3C-SiC
  3. C15R-SiC
答えと解説を見る

正解：A. 4H-SiC

SiCには200種類以上の結晶多形がありますが、パワーデバイスには、バンドギャップが約3.3 eVと大きく、電子移動度の異方性が小さい4H-SiCが主に使われています。高品質な基板とエピタキシャル成長の技術が確立していることも理由です。

  3. ヘテロエピタキシャル成長の例として正しいものはどれか。
  4. MOCVD(有機金属気相成長法)が主に使われる用途はどれか。
