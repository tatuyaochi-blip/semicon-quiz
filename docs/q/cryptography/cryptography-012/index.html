暗号技術の基礎と応用

ハッシュ関数のSHA-2とSHA-3の説明として、正しいものはどれか。

  1. ASHA-3は、SHA-2と同じ内部構造のまま、出力を長くした改良版である
  2. BSHA-3は、SHA-2とは異なるスポンジ構造に基づく方式で、SHA-2も現在広く使われている
  3. CSHA-256はSHA-3の一種で、SHA-3の系統のうち出力が256ビットのものをSHA-256と呼ぶ
答えと解説を見る

正解：B. SHA-3は、SHA-2とは異なるスポンジ構造に基づく方式で、SHA-2も現在広く使われている

SHA-2は、SHA-224、SHA-256、SHA-384、SHA-512などからなるハッシュ関数の一群で、ブロックを順に圧縮関数に通すMerkle–Damgård構造でできています。SHA-3は、NISTの公募で選ばれたKeccakをもとに、2015年にFIPS 202として標準化されたもので、大きな内部状態に入力を吸収し、出力を絞り出すスポンジ構造を使います。SHA-3はSHA-2が破られたから作られたのではなく、構造の異なる代わりを用意しておく意味をもち、SHA-2は現在も広く使われています。一方、SHA-1は2017年に実際の衝突の例が公表され、デジタル署名などには使われなくなっています。

  • A. SHA-3は、内部の構造がSHA-2とまったく違います。
  • B. 正しい。構造の異なる2つの系統が、どちらも標準として使われています。
  • C. SHA-256はSHA-2の一種です。SHA-3で出力が256ビットのものは、SHA3-256と書きます。

暗号技術の基礎と応用のほかの問題

  1. 秘密の鍵Kとメッセージmをつなげた値のハッシュ値 SHA-256(K ‖ m) を、改ざんの検出用のタグとして使うのは危険とされる。その理由として正しいものはどれか。
  2. 1 GiB = 2³⁰ バイト、1 EiB = 2⁶⁰ バイトとする。ブロック長が64ビットのブロック暗号(3DESなど)をCBCモードで使い、1つの鍵で大量のデータを暗号化する。暗号文ブロックをランダムな64ビットの値とみなすとき、誕生日のパラドックスにより、同じ暗号文ブロックの組が現れる確率が無視できなくなるデータ量の目安はどれか。
  3. TLS 1.3などのプロトコルで、ECDHEの鍵交換で得た共有の秘密をそのまま暗号の鍵には使わず、HKDFのような鍵導出関数(KDF)を通して鍵を作る理由として、適切なものはどれか。
  4. RSA暗号の仕組みを小さな数で確かめる。素数 p = 5、q = 11 から n = pq を作り、公開指数を e = 3 とする。φ(n) = (p − 1)(q − 1) として、e × d ≡ 1 (mod φ(n)) を満たす秘密指数 d(0 < d < φ(n))はどれか。
  5. RSA暗号で、公開鍵を n = 55、e = 3 とする。平文 m = 7 を c = m^e mod n で暗号化したときの暗号文 c はどれか。
