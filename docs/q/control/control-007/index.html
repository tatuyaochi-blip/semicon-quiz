制御工学の基礎

線形で時不変な系の伝達関数の説明として正しいものはどれか。

  1. A入力と出力の時間波形の比 y(t)/x(t) を、時刻ごとに計算したもの
  2. B正弦波を入れたときの出力と入力の振幅の比で、系の性質だけで決まるので、入れる正弦波の周波数によらず一定の値になるもの
  3. C初期値をすべて0として、出力のラプラス変換と入力のラプラス変換の比 Y(s)/X(s) をとったもの
答えと解説を見る

正解：C. 初期値をすべて0として、出力のラプラス変換と入力のラプラス変換の比 Y(s)/X(s) をとったもの

伝達関数は、初期値をすべて0としたときの、出力と入力のラプラス変換の比です。系のインパルス応答をラプラス変換したものに等しく、系の性質を s の分数式で表します。分母を0にする s を極、分子を0にする s を零点と呼び、極の位置から安定性や応答の速さがわかります。s = jω とおくと周波数応答になり、離散時間の系では、z変換で表す H(z) が同じ役割をします。

  • A. 時間波形の比は時刻によって変わり、系の性質を表しません。
  • B. 振幅の比は周波数応答のゲインで、一般に周波数によって変わります。
  • C. 正しい。初期値を0とすることで、入力と出力の関係だけを表せます。

制御工学の基礎のほかの問題

  1. 伝達関数 G(s) = 2/(1 + 0.5s) の一次遅れ系に、時刻0で大きさ1のステップを入力した。t = 1 s での出力に最も近いものはどれか。
  2. ある一次遅れ系に大きさ2のステップを入力したところ、出力は最終的に6に落ち着き、入力から0.4 sで最終値の約63%に達した。この系の伝達関数として正しいものはどれか。
  3. 二次遅れ系 G(s) = ωn²/(s² + 2ζωn s + ωn²) のステップ応答が、最終値を行き過ぎて振動しながら近づく、減衰係数 ζ の範囲として正しいものはどれか。
  4. 伝達関数 G(s) = 25/(s² + 4s + 25) の二次遅れ系の、固有角周波数 ωn と減衰係数 ζ の組み合わせとして正しいものはどれか。
  5. 減衰係数 ζ = 0.5 の二次遅れ系(零点のない標準形)にステップを入力した。オーバーシュート(最大の行き過ぎ量の、最終値に対する割合)に最も近いものはどれか。
