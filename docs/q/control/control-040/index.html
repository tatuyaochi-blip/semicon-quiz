制御工学の基礎

シーケンス制御の説明として正しいものはどれか。

  1. A制御量を連続的に測り、目標値との偏差をPID演算で0に近づける制御で、温度や速度を一定に保つのに使われる
  2. Bあらかじめ定めた順序や条件に従って、制御の各段階を順に進めていく制御で、洗濯機や信号機、工場の搬送装置などで使われる
  3. C外乱を測り、その影響を打ち消す操作量を前もって加える制御で、制御を段階に分けたり順序を決めたりするという考え方をもたない
答えと解説を見る

正解：B. あらかじめ定めた順序や条件に従って、制御の各段階を順に進めていく制御で、洗濯機や信号機、工場の搬送装置などで使われる

シーケンス制御は、「スタートボタンが押されたら給水し、水位に達したら洗いを始め、一定時間後に排水する」のように、順序や条件、時間に従って動作を進める制御です。センサやスイッチのオンとオフの信号を使う論理の制御で、制御量を目標値に近づけ続けるフィードバック制御とは目的が違います。工場の機械では、PLC(プログラマブルロジックコントローラ)で実装し、ラダー図で記述することが多くあります。実際の装置では、各段階の中でフィードバック制御を使うなど、両方を組み合わせます。

  • A. これはフィードバック制御(PID制御)の説明です。
  • B. 正しい。決められた手順を順に進めるのがシーケンス制御です。
  • C. これはフィードフォワード制御の説明です。

制御工学の基礎のほかの問題

  1. フィードバック制御(閉ループ制御)の説明として正しいものはどれか。
  2. フィードフォワード制御を、フィードバック制御と組み合わせて使う理由として正しいものはどれか。
  3. 前向きの経路の伝達関数が G(s)、フィードバックの経路の伝達関数が H(s) の負帰還のブロック線図がある。目標値 R(s) から出力 Y(s) までの閉ループ伝達関数 Y(s)/R(s) として正しいものはどれか。
  4. 前向きの利得 G = 100、フィードバックの利得 H = 0.1 の負帰還の系がある。部品の劣化で G が50に半減したとき、閉ループの利得の減少の割合に最も近いものはどれか。
  5. 初期値をすべて0とするとき、時間関数の微分と積分を、ラプラス変換した s の領域で表す計算の組み合わせとして正しいものはどれか。
