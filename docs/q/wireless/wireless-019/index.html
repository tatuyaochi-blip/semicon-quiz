無線通信の基礎

OFDMA(直交周波数分割多元接続)の説明として、適切なものはどれか。

  1. A1回の送信では1台の端末だけが、すべてのサブキャリアを使って通信する方式
  2. B端末ごとに異なる拡散符号を割り当て、同じ周波数で同時に通信する方式
  3. COFDMのサブキャリアをいくつかのまとまりに分け、時間と周波数の区切りごとに異なる端末へ割り当てて、複数の端末と同時に通信する方式
答えと解説を見る

正解：C. OFDMのサブキャリアをいくつかのまとまりに分け、時間と周波数の区切りごとに異なる端末へ割り当てて、複数の端末と同時に通信する方式

OFDMAは、OFDMのサブキャリアを、時間と周波数で区切った単位(4G LTEや5G NRのリソースブロックなど)ごとに異なる端末へ割り当てる多元接続の方式です。データの少ない端末には少ない単位を割り当てたり、電波の状態がよい周波数をその端末に割り当てたりできるので、多数の端末を効率よく収容できます。携帯電話の4G LTE(下りリンク)や5G NRのほか、無線LANでもIEEE 802.11axから使われています。

  • A. OFDMを1台の端末だけで使う場合の説明です。802.11a/g/nなどの従来の無線LANは、この使い方でした。
  • B. CDMAの説明です。
  • C. 正しい。サブキャリアのまとまりを端末ごとに割り当てます。

無線通信の基礎のほかの問題

  1. 送信アンテナ4本、受信アンテナ2本のMIMOで、空間多重によって同じ周波数・同じ時間に送れる独立したデータの流れ(ストリーム)の数の上限はどれか。
  2. 複数のアンテナ素子から送る信号の位相(と振幅)を素子ごとに調整して、特定の方向に電波を強め合わせて送る技術はどれか。
  3. 5Gのミリ波帯の基地局や端末で、多数のアンテナ素子を並べたアレイアンテナによるビームフォーミングが使われる主な理由として、最も適切なものはどれか。
  4. 携帯電話のセルラー方式で、サービスする地域を多数の小さな区域(セル)に分け、それぞれに基地局を置く主な理由はどれか。
  5. 4G LTEの上りリンク(端末から基地局への送信)で、下りリンクのOFDMAではなく、SC-FDMA(DFT拡散OFDM)が採用された主な理由として、最も適切なものはどれか。
