無線通信の基礎

交通系ICカードやスマートフォンの非接触決済で使われるNFCの特徴として、適切なものはどれか。

  1. A2.4 GHz帯の電波を使い、数十m離れた機器とも通信できる
  2. Bカードの中に電池を内蔵し、その電力で強い電波を出して通信する
  3. C13.56 MHzの電磁誘導を使い、通信距離は数cm〜10 cm程度で、カードは読み取り機からの磁界で電力を受け取って動く
答えと解説を見る

正解：C. 13.56 MHzの電磁誘導を使い、通信距離は数cm〜10 cm程度で、カードは読み取り機からの磁界で電力を受け取って動く

NFCは、13.56 MHzの磁界による電磁誘導を使う近距離無線通信です。読み取り機(リーダー)が出す磁界からカード側のコイルが電力を受け取るので、カードには電池が要りません。通信距離が数cm〜10 cm程度と短いので、離れた場所から意図せず読み取られにくく、「かざす」操作で使えます。日本の交通系ICカードなどで使われているFeliCaも、同じ13.56 MHzを使う方式です。

  • A. 無線LANやBluetoothの特徴です。
  • B. NFCのカードは電池をもたず、読み取り機の磁界から電力を受け取ります。
  • C. 正しい。13.56 MHzの電磁誘導で、近づけて通信します。

無線通信の基礎のほかの問題

  1. GPSなどのGNSS(全地球航法衛星システム)の受信機が、自分の時計の誤差もあわせて求めながら3次元の位置を決めるために、最低限必要な衛星の数はどれか。
  2. 無線の受信機で、アンテナのすぐ後ろに置かれ、自分の雑音をできるだけ加えずに微弱な受信信号を増幅する回路はどれか。
  3. 受信機で、受信した信号と局部発振器(LO)の信号を掛け合わせて、両者の周波数の差(や和)の周波数の信号をつくり、周波数を変換する回路はどれか。
  4. スーパーヘテロダイン受信機で、900 MHzの信号を受信するために、局部発振器(LO)を800 MHzにして100 MHzの中間周波数(IF)に変換している。このとき、同じ100 MHzのIFに変換されてしまうイメージ周波数はどれか。
  5. 局部発振器(LO)の周波数を受信する信号と同じにして、中間周波数を経ずに直接ベースバンドに変換するダイレクトコンバージョン受信機の、スーパーヘテロダイン受信機と比べた説明として、適切なものはどれか。
