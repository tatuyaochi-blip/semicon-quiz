歩留まり・品質管理

工場の中で、どのロットがどの工程・装置にあり、どの条件で処理されたかなどを管理し、生産の流れを指示・記録するシステムはどれか。

  1. ABIST
  2. BMES(製造実行システム)
  3. CEDA
答えと解説を見る

正解：B. MES(製造実行システム)

MES(Manufacturing Execution System)は、ロットの進み具合、装置の状態、処理の条件(レシピ)、作業の記録などを管理し、次にどの装置で何を処理するかを指示するシステムです。誤ったレシピでの処理や工程の飛ばしを防ぐ役割もあり、自動搬送システムと連携して工場全体を動かします。製造履歴の追跡(トレーサビリティ)の基盤にもなります。BISTはテスト回路、EDAは設計ツールです。

  • A. BISTはチップに組み込んだ自己テストの回路です。
  • B. 正しい。工場の生産の流れを管理するシステムです。
  • C. EDAは回路設計の支援ツールです。

歩留まり・品質管理のほかの問題

  1. 多数の製品から一部を抜き取って検査し、ロット全体を合格とするか不合格とするかを判定する方式で、合格とみなす品質の水準を表す指標はどれか。
  2. 歩留まりのデータを分析するときの注意点として、「2つの量に相関があっても、一方が他方の原因とは限らない」ことを示す例として正しいものはどれか。
  3. 工場に蓄積された大量の装置データ・計測データ・テスト結果を、機械学習などで解析して歩留まりを高める取り組みの説明として正しいものはどれか。
  4. 欠陥がウエハ上で偏って集まって発生する(クラスタリングする)ことを考慮した歩留まりモデルとして使われるものはどれか。
  5. 欠陥検査で見つかった欠陥の種類ごとに、その欠陥があったチップのうち実際に電気的な不良になった割合を表す量を何と呼ぶか。
