歩留まり・品質管理

製品や工程で起こりうる故障モードを洗い出し、その影響と重要度を評価して、事前に対策を講じる手法はどれか。

  1. Aパレート図
  2. Bヒストグラム
  3. CFMEA(故障モード影響解析)
答えと解説を見る

正解：C. FMEA(故障モード影響解析)

FMEAは、部品や工程ごとに起こりうる故障モードを挙げ、その影響の大きさ、発生頻度、検出のしやすさなどを評価して、優先的に対策すべき項目を決める手法です。問題が起きる前に予防するための手法として、設計や工程の立ち上げで使われます。

歩留まり・品質管理のほかの問題

  1. 2つの特性値の組をプロットし、それらの相関関係を調べるための図はどれか。
  2. 新しいプロセスの立ち上げ以降、不良原因の解析と対策を重ねることで、歩留まりが時間とともに向上していく様子を表したものを何と呼ぶか。
  3. 製造のばらつきを、ロット間・ウエハ間・ウエハ内などの要因ごとに分けて評価する目的として正しいものはどれか。
  4. 品質管理で「シックスシグマ」と呼ばれる活動の考え方として正しいものはどれか。
  5. 同じウエハで、チップの面積を小さくすると、1枚から取れる良品チップの数が大きく増える理由として正しいものはどれか。
