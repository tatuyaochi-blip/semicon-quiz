歩留まり・品質管理

欠陥がウエハ上で偏って集まって発生する(クラスタリングする)ことを考慮した歩留まりモデルとして使われるものはどれか。

  1. A負の二項分布モデル
  2. Bオームの法則
  3. Cデナードのスケーリング則
答えと解説を見る

正解：A. 負の二項分布モデル

ポアソンモデルは欠陥がランダムに一様に分布すると仮定しますが、実際の欠陥は局所的に集まる傾向があります。負の二項分布モデルはクラスタリングの度合いを表すパラメータαを含み、Y=(1+DA/α)^(−α)で表されます。DA=1のとき、ポアソンでは約37%、α=1では50%となり、欠陥が固まるほど無傷のチップが多く残ります。αが大きいほどポアソンモデルに近づきます。

  • A. 正しい。クラスタリングを考慮した歩留まりモデルです。
  • B. オームの法則は電圧・電流・抵抗の関係です。
  • C. デナードのスケーリング則は微細化の指針です。
この分野を解く 分野ページへ

歩留まり・品質管理のほかの問題

  1. 欠陥検査で見つかった欠陥の種類ごとに、その欠陥があったチップのうち実際に電気的な不良になった割合を表す量を何と呼ぶか。
  2. 工場の中の仕掛り(WIP)の量、処理の速さ(スループット)、サイクルタイムの関係を表す「リトルの法則」の内容として正しいものはどれか。
  3. 歩留まりの低いロットに共通して使われた装置やチャンバー、材料などを、多数のロットの製造履歴から統計的に洗い出す解析を何と呼ぶか。
  4. 互いに相関のある複数の特性値を、1つずつではなくまとめて監視し、組み合わせとしての異常を検出する統計的な工程管理の手法はどれか。
  5. 同じ種類の装置が複数台あるとき、装置やチャンバーの間で加工結果の差が小さくなるように調整・管理することを何と呼ぶか。
