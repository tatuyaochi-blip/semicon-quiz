歩留まり・品質管理

品質管理で使われるパレート図の目的として正しいものはどれか。

  1. A2つの変数の相関関係を調べる
  2. B時系列で工程の異常を監視する
  3. C不良の項目を件数の多い順に並べ、重点的に対策すべき項目を見つける
答えと解説を見る

正解：C. 不良の項目を件数の多い順に並べ、重点的に対策すべき項目を見つける

パレート図は、不良の項目や原因を件数(または損失金額)の多い順に棒グラフで並べ、累積比率の折れ線を重ねた図です。少数の項目が全体の大部分を占めることが多いため、優先して対策すべき項目がひと目でわかります。相関を見るのは散布図、時系列の異常を見るのは管理図です。

この分野を解く 分野ページへ

歩留まり・品質管理のほかの問題

  1. 工程能力指数Cp(規格の中心と工程の平均が一致している場合)を求める式はどれか。(σ:工程の標準偏差)
  2. 歩留まり低下の要因のうち、設計と製造工程の相性などによって、特定のパターンで繰り返し発生する不良を何と呼ぶか。
  3. 問題(結果)と、それに影響を与える要因の関係を、魚の骨のような形に整理した図はどれか。
  4. ウエハテストの結果を、ウエハ上のチップの位置ごとに良否で表示したウエハマップを分析する主な目的はどれか。
  5. ほかの条件が同じとき、ウエハの直径を200 mmから300 mmにすると、ウエハの面積はおよそ何倍になるか。
