歩留まり・品質管理

ほかの条件が同じとき、ウエハの直径を200 mmから300 mmにすると、ウエハの面積はおよそ何倍になるか。

  1. A約2.25倍
  2. B1.5倍
  3. C3倍
答えと解説を見る

正解：A. 約2.25倍

面積は直径の2乗に比例するため、(300 / 200)² = 1.5² = 2.25倍になります。実際には外周部の欠けたチップの割合が減るため、取れるチップの数は2.25倍より多くなります。大口径化がコスト低減に効く理由です。

歩留まり・品質管理のほかの問題

  1. 管理図で、すべての点が管理限界内にあっても、異常と判断すべき例はどれか。
  2. ポアソンモデル Y = exp(−D × A) で、欠陥密度D = 0.1個/cm²、チップ面積A = 1 cm²のとき、歩留まりはおよそいくらか。
  3. ウエハ上の欠陥のうち、実際にチップの電気的な不良を引き起こすものを何と呼ぶか。
  4. データをいくつかの区間に分けて度数を棒グラフで表し、ばらつきの分布の形を見るための図はどれか。
  5. 工程の平均値が規格の中心からずれている場合に用いる工程能力指数はどれか。
