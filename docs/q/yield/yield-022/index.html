歩留まり・品質管理

不良率(不良品の割合)を管理するために使われる管理図はどれか。

  1. AX̄-R管理図
  2. Bp管理図
  3. C散布図
答えと解説を見る

正解：B. p管理図

p管理図は、ロットなどのサンプルごとの不良率をプロットして管理する計数値の管理図です。サンプルの大きさが変わると管理限界の幅も変わるのが特徴です。不良の個数をそのまま管理するnp管理図や、欠点の数を管理するc管理図もあります。膜厚や寸法などの計量値の平均とばらつきを管理するにはX̄-R管理図、散布図は相関を見る図です。

歩留まり・品質管理のほかの問題

  1. 工程ごとに欠陥検査を行い、前の工程から新たに増えた欠陥だけを抽出する目的として正しいものはどれか。
  2. 粒子の大きさと配線の配置から、その粒子が落ちると不良を引き起こしうる領域の面積を表す考え方はどれか。
  3. 問題の真の原因を探るために「なぜ」を繰り返して掘り下げていく手法はどれか。
  4. 1枚のウエハに600個のチップがあり、歩留まりが80%のとき、良品チップの数はいくつか。
  5. ウエハ工程の歩留まりが95%、ウエハテストの歩留まりが90%のとき、両者を掛け合わせた総合歩留まりはおよそいくらか。
