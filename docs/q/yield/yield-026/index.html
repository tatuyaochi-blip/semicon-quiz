歩留まり・品質管理

1枚のウエハに600個のチップがあり、歩留まりが80%のとき、良品チップの数はいくつか。

  1. A120個
  2. B480個
  3. C520個
答えと解説を見る

正解：B. 480個

良品チップの数は「チップの数 × 歩留まり」で求めます。600 × 0.8 = 480個です。120個は不良品の数にあたります。

この分野を解く 分野ページへ

歩留まり・品質管理のほかの問題

  1. ウエハ工程の歩留まりが95%、ウエハテストの歩留まりが90%のとき、両者を掛け合わせた総合歩留まりはおよそいくらか。
  2. 異常が見つかったときに影響を受けた可能性のある製品を特定するために必要な、製品ごとの製造履歴を追跡できる仕組みを何と呼ぶか。
  3. テストでは規格内でも、同じロットの分布から大きく外れた値を示すチップを不良として除く手法はどれか。
  4. 管理図の管理限界と、製品の規格限界の違いとして正しいものはどれか。
  5. 1枚のウエハから500個のチップが取れ、そのうち450個が良品だった。このウエハの歩留まりはいくらか。
