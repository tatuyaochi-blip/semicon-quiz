歩留まり・品質管理

管理図の管理限界と、製品の規格限界の違いとして正しいものはどれか。

  1. A管理限界は工程の実際のばらつきから決め、規格限界は製品に求められる要求から決める
  2. B管理限界と規格限界は常に同じ値である
  3. C管理限界は顧客が決め、規格限界は工程のデータから計算する
答えと解説を見る

正解：A. 管理限界は工程の実際のばらつきから決め、規格限界は製品に求められる要求から決める

管理限界は、工程が安定しているときのデータの平均とばらつきから計算する線で、工程に異常が起きていないかを判断するためのものです。規格限界は、製品として許される範囲を顧客の要求や設計から決めたものです。両者は別の考え方にもとづくため、混同しないことが大切です。

歩留まり・品質管理のほかの問題

  1. 1枚のウエハから500個のチップが取れ、そのうち450個が良品だった。このウエハの歩留まりはいくらか。
  2. 欠陥密度が同じ条件で、チップ面積を大きくすると歩留まりは一般にどうなるか。
  3. 工程管理に使われる管理図(シューハート管理図)で、管理限界線を一般にどのように設定するか。
  4. 品質管理で使われるパレート図の目的として正しいものはどれか。
  5. 工程能力指数Cp(規格の中心と工程の平均が一致している場合)を求める式はどれか。(σ:工程の標準偏差)
