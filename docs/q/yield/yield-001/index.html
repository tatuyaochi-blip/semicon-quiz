歩留まり・品質管理

1枚のウエハから500個のチップが取れ、そのうち450個が良品だった。このウエハの歩留まりはいくらか。

  1. A80%
  2. B90%
  3. C95%
答えと解説を見る

正解：B. 90%

歩留まりは「良品数 ÷ 全体の数」で求めます。450 ÷ 500 = 0.9 なので、歩留まりは90%です。80%なら良品は400個、95%なら475個になるはずです。実際の工場では、前工程のライン歩留まり、ウエハテストの歩留まり、組立・最終テストの歩留まりを段階ごとに管理し、それらを掛け合わせて総合歩留まりを求めます。歩留まりが1ポイント上がるだけでも、利益への影響は大きくなります。

歩留まり・品質管理のほかの問題

  1. 欠陥密度が同じ条件で、チップ面積を大きくすると歩留まりは一般にどうなるか。
  2. 工程管理に使われる管理図(シューハート管理図)で、管理限界線を一般にどのように設定するか。
  3. 品質管理で使われるパレート図の目的として正しいものはどれか。
  4. 工程能力指数Cp(規格の中心と工程の平均が一致している場合)を求める式はどれか。(σ:工程の標準偏差)
  5. 歩留まり低下の要因のうち、設計と製造工程の相性などによって、特定のパターンで繰り返し発生する不良を何と呼ぶか。
