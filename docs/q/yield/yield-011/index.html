歩留まり・品質管理

ポアソンモデル Y = exp(−D × A) で、欠陥密度D = 0.1個/cm²、チップ面積A = 1 cm²のとき、歩留まりはおよそいくらか。

  1. A約50%
  2. B約90%
  3. C約99%
答えと解説を見る

正解：B. 約90%

D × A = 0.1 なので、Y = exp(−0.1) ≈ 0.905、つまり約90%です。同じ欠陥密度でチップ面積が5 cm²になると、exp(−0.5) ≈ 61%まで下がります。

  1. ウエハ上の欠陥のうち、実際にチップの電気的な不良を引き起こすものを何と呼ぶか。
  2. データをいくつかの区間に分けて度数を棒グラフで表し、ばらつきの分布の形を見るための図はどれか。
  3. 工程の平均値が規格の中心からずれている場合に用いる工程能力指数はどれか。
  4. 前の工程の計測結果などをもとに、次のロットやウエハの装置の加工条件を自動で補正する制御はどれか。
  5. 製品や工程で起こりうる故障モードを洗い出し、その影響と重要度を評価して、事前に対策を講じる手法はどれか。
