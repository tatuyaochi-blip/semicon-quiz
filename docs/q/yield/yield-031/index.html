歩留まり・品質管理

品質管理や業務改善で使われる「PDCAサイクル」の順序として正しいものはどれか。

  1. A計画(Plan)→ 実行(Do)→ 評価(Check)→ 改善(Act)
  2. B実行 → 計画 → 改善 → 評価
  3. C評価 → 改善 → 計画 → 実行
答えと解説を見る

正解：A. 計画(Plan)→ 実行(Do)→ 評価(Check)→ 改善(Act)

PDCAサイクルは、計画を立て(Plan)、実行し(Do)、結果を評価し(Check)、改善の処置をとる(Act)という4つの段階を繰り返して、品質や業務を継続的に改善する考え方です。

  • A. 正しい。計画・実行・評価・改善の順です。
  • B. 計画の前に実行するのは順序が逆です。
  • C. 評価から始めるのはPDCAの順序ではありません。

歩留まり・品質管理のほかの問題

  1. QC七つ道具の一つで、データを装置別・作業者別・材料別などのグループに分けて比べ、違いの原因を探る考え方はどれか。
  2. QC七つ道具の一つで、確認すべき項目をあらかじめ表にしておき、点検の結果や不良の発生を記録・集計しやすくするものはどれか。
  3. 製品の「品質」と「信頼性」の違いとして一般的な説明はどれか。
  4. 問題が起きたときに、実際の現場で、実際の物を見て、実際の状況を確かめることを重視する考え方を何と呼ぶか。
  5. 工程の条件(温度、時間、ガス流量など)を複数同時に計画的に変えて、少ない実験の回数で各要因の影響を効率よく調べる手法はどれか。
