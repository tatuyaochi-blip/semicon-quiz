歩留まり・品質管理

テストでは規格内でも、同じロットの分布から大きく外れた値を示すチップを不良として除く手法はどれか。

  1. AATPG
  2. BPAT(パーツ平均テスト)
  3. CAPC
答えと解説を見る

正解：B. PAT(パーツ平均テスト)

PAT(Part Average Testing)は、ロットやウエハごとの測定値の分布を求め、規格内であっても平均から例えば±6σを超えるような外れ値のチップを除く手法です。外れ値のチップは潜在的な欠陥をもち、将来故障しやすい可能性が高いためです。車載用の半導体の品質向上に使われ、AEC(車載電子部品評議会)のガイドラインにも定められています。ATPGはパターン生成、APCは工程制御です。

歩留まり・品質管理のほかの問題

  1. 管理図の管理限界と、製品の規格限界の違いとして正しいものはどれか。
  2. 品質管理や業務改善で使われる「PDCAサイクル」の順序として正しいものはどれか。
  3. QC七つ道具の一つで、データを装置別・作業者別・材料別などのグループに分けて比べ、違いの原因を探る考え方はどれか。
  4. QC七つ道具の一つで、確認すべき項目をあらかじめ表にしておき、点検の結果や不良の発生を記録・集計しやすくするものはどれか。
  5. 製品の「品質」と「信頼性」の違いとして一般的な説明はどれか。
