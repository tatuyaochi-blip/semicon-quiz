歩留まり・品質管理

新しいプロセスの立ち上げ以降、不良原因の解析と対策を重ねることで、歩留まりが時間とともに向上していく様子を表したものを何と呼ぶか。

  1. Aバスタブ曲線
  2. B歩留まり学習曲線(ラーニングカーブ)
  3. CS字曲線
答えと解説を見る

正解：B. 歩留まり学習曲線(ラーニングカーブ)

新しいプロセスの立ち上げ直後は歩留まりが低く、不良解析と対策を繰り返すことで徐々に向上していきます。この推移を表したものが歩留まり学習曲線です。歩留まりを早く高い水準に引き上げることは、半導体メーカーの競争力に直結します。

この分野を解く 分野ページへ

歩留まり・品質管理のほかの問題

  1. 製造のばらつきを、ロット間・ウエハ間・ウエハ内などの要因ごとに分けて評価する目的として正しいものはどれか。
  2. 品質管理で「シックスシグマ」と呼ばれる活動の考え方として正しいものはどれか。
  3. 同じウエハで、チップの面積を小さくすると、1枚から取れる良品チップの数が大きく増える理由として正しいものはどれか。
  4. 不良率(不良品の割合)を管理するために使われる管理図はどれか。
  5. 工程ごとに欠陥検査を行い、前の工程から新たに増えた欠陥だけを抽出する目的として正しいものはどれか。
