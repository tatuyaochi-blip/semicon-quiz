歩留まり・品質管理

工程の平均値が規格の中心からずれている場合に用いる工程能力指数はどれか。

  1. ACp
  2. BCpk
  3. CMTTR
答えと解説を見る

正解：B. Cpk

Cpは平均が規格の中心にあると仮定した指数ですが、Cpkは平均と近い方の規格限界までの距離を3σで割って求めるため、平均のずれも考慮できます。平均が規格の中心にあれば、CpとCpkは等しくなります。

歩留まり・品質管理のほかの問題

  1. 前の工程の計測結果などをもとに、次のロットやウエハの装置の加工条件を自動で補正する制御はどれか。
  2. 製品や工程で起こりうる故障モードを洗い出し、その影響と重要度を評価して、事前に対策を講じる手法はどれか。
  3. 2つの特性値の組をプロットし、それらの相関関係を調べるための図はどれか。
  4. 新しいプロセスの立ち上げ以降、不良原因の解析と対策を重ねることで、歩留まりが時間とともに向上していく様子を表したものを何と呼ぶか。
  5. 製造のばらつきを、ロット間・ウエハ間・ウエハ内などの要因ごとに分けて評価する目的として正しいものはどれか。
