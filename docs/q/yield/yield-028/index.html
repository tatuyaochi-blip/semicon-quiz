歩留まり・品質管理

異常が見つかったときに影響を受けた可能性のある製品を特定するために必要な、製品ごとの製造履歴を追跡できる仕組みを何と呼ぶか。

  1. Aビニング
  2. Bガードバンド
  3. Cトレーサビリティ
答えと解説を見る

正解：C. トレーサビリティ

トレーサビリティは、各製品がどのウエハ、どのロットから作られ、どの装置でどの条件で処理されたかを記録し、さかのぼって追跡できる仕組みです。装置の異常などが見つかったときに、影響を受けた製品の範囲を素早く特定し、出荷の停止や回収を最小限にできます。

歩留まり・品質管理のほかの問題

  1. テストでは規格内でも、同じロットの分布から大きく外れた値を示すチップを不良として除く手法はどれか。
  2. 管理図の管理限界と、製品の規格限界の違いとして正しいものはどれか。
  3. 品質管理や業務改善で使われる「PDCAサイクル」の順序として正しいものはどれか。
  4. QC七つ道具の一つで、データを装置別・作業者別・材料別などのグループに分けて比べ、違いの原因を探る考え方はどれか。
  5. QC七つ道具の一つで、確認すべき項目をあらかじめ表にしておき、点検の結果や不良の発生を記録・集計しやすくするものはどれか。
