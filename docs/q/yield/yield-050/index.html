歩留まり・品質管理

同じ種類の装置が複数台あるとき、装置やチャンバーの間で加工結果の差が小さくなるように調整・管理することを何と呼ぶか。

  1. Aリソグラフィ
  2. Bチャンバーマッチング(装置間の合わせ込み)
  3. Cゲッタリング
答えと解説を見る

正解：B. チャンバーマッチング(装置間の合わせ込み)

量産工場では同じ工程を多数の装置・チャンバーで並行して処理するため、それぞれの加工結果に差があると、製品の特性がばらつきます。部品の状態やセンサの値、加工結果をそろえるように調整・監視することをチャンバーマッチングといい、ばらつきの低減に欠かせません。

  • A. リソグラフィはパターンを転写する工程です。
  • B. 正しい。装置間の差を小さくする調整・管理です。
  • C. ゲッタリングは有害な不純物を捕らえる技術です。

歩留まり・品質管理のほかの問題

  1. 1枚のウエハから500個のチップが取れ、そのうち450個が良品だった。このウエハの歩留まりはいくらか。
  2. 欠陥密度が同じ条件で、チップ面積を大きくすると歩留まりは一般にどうなるか。
  3. 工程管理に使われる管理図(シューハート管理図)で、管理限界線を一般にどのように設定するか。
  4. 品質管理で使われるパレート図の目的として正しいものはどれか。
  5. 工程能力指数Cp(規格の中心と工程の平均が一致している場合)を求める式はどれか。(σ:工程の標準偏差)
