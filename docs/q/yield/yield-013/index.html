歩留まり・品質管理

データをいくつかの区間に分けて度数を棒グラフで表し、ばらつきの分布の形を見るための図はどれか。

  1. A散布図
  2. B特性要因図
  3. Cヒストグラム
答えと解説を見る

正解：C. ヒストグラム

ヒストグラムは、測定値をいくつかの区間に区切り、各区間に入るデータの数を棒の高さで表した図です。分布の中心やばらつき、偏り、2つの山があるかなどがわかり、規格の範囲と比べて工程の状態を判断するのに使います。

この分野を解く 分野ページへ

歩留まり・品質管理のほかの問題

  1. 工程の平均値が規格の中心からずれている場合に用いる工程能力指数はどれか。
  2. 前の工程の計測結果などをもとに、次のロットやウエハの装置の加工条件を自動で補正する制御はどれか。
  3. 製品や工程で起こりうる故障モードを洗い出し、その影響と重要度を評価して、事前に対策を講じる手法はどれか。
  4. 2つの特性値の組をプロットし、それらの相関関係を調べるための図はどれか。
  5. 新しいプロセスの立ち上げ以降、不良原因の解析と対策を重ねることで、歩留まりが時間とともに向上していく様子を表したものを何と呼ぶか。
