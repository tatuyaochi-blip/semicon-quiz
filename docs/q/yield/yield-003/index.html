歩留まり・品質管理

工程管理に使われる管理図(シューハート管理図)で、管理限界線を一般にどのように設定するか。

  1. A中心線 ± 1σ
  2. B中心線 ± 2σ
  3. C中心線 ± 3σ
答えと解説を見る

正解：C. 中心線 ± 3σ

シューハート管理図では、一般に中心線から ± 3σ(σ:標準偏差)の位置に上方・下方管理限界線を引きます。正規分布では、偶然のばらつきだけで点がこの範囲の外に出る確率は約0.3%と小さいため、外に出た場合は工程に何らかの異常が起きたと判断します。

歩留まり・品質管理のほかの問題

  1. 品質管理で使われるパレート図の目的として正しいものはどれか。
  2. 工程能力指数Cp(規格の中心と工程の平均が一致している場合)を求める式はどれか。(σ:工程の標準偏差)
  3. 歩留まり低下の要因のうち、設計と製造工程の相性などによって、特定のパターンで繰り返し発生する不良を何と呼ぶか。
  4. 問題(結果)と、それに影響を与える要因の関係を、魚の骨のような形に整理した図はどれか。
  5. ウエハテストの結果を、ウエハ上のチップの位置ごとに良否で表示したウエハマップを分析する主な目的はどれか。
