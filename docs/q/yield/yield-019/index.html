歩留まり・品質管理

製造のばらつきを、ロット間・ウエハ間・ウエハ内などの要因ごとに分けて評価する目的として正しいものはどれか。

  1. Aどの階層のばらつきが大きいかを知り、原因となる工程や装置を絞り込むため
  2. B製品の販売価格を決めるため
  3. Cウエハの色をそろえるため
答えと解説を見る

正解：A. どの階層のばらつきが大きいかを知り、原因となる工程や装置を絞り込むため

ばらつきがロット間で大きければ材料や装置の状態の変化、ウエハ内で大きければ装置の面内均一性など、ばらつきの階層によって疑うべき原因が異なります。分散分析などで要因ごとに分けて評価すると、効果的な対策につなげられます。

歩留まり・品質管理のほかの問題

  1. 品質管理で「シックスシグマ」と呼ばれる活動の考え方として正しいものはどれか。
  2. 同じウエハで、チップの面積を小さくすると、1枚から取れる良品チップの数が大きく増える理由として正しいものはどれか。
  3. 不良率(不良品の割合)を管理するために使われる管理図はどれか。
  4. 工程ごとに欠陥検査を行い、前の工程から新たに増えた欠陥だけを抽出する目的として正しいものはどれか。
  5. 粒子の大きさと配線の配置から、その粒子が落ちると不良を引き起こしうる領域の面積を表す考え方はどれか。
