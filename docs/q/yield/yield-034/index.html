歩留まり・品質管理

製品の「品質」と「信頼性」の違いとして一般的な説明はどれか。

  1. A品質は見た目だけ、信頼性は価格を表す
  2. B品質は出荷時点で規格を満たしているか、信頼性は使い続けたときに期間中その機能を保てるかを主に表す
  3. C2つはまったく同じ意味である
答えと解説を見る

正解：B. 品質は出荷時点で規格を満たしているか、信頼性は使い続けたときに期間中その機能を保てるかを主に表す

品質(初期品質)は、出荷した時点で製品が規格どおりの性能をもっているかを表します。信頼性は、決められた条件と期間のあいだ、故障せずに機能を保ち続けられるかという時間的な性質を表します。どちらも半導体製品には欠かせません。

  • A. 見た目や価格を表すものではありません。
  • B. 正しい。出荷時点の適合性と、使用期間中の持続性の違いです。
  • C. 時間の要素を含むかどうかで意味が異なります。

歩留まり・品質管理のほかの問題

  1. 問題が起きたときに、実際の現場で、実際の物を見て、実際の状況を確かめることを重視する考え方を何と呼ぶか。
  2. 工程の条件(温度、時間、ガス流量など)を複数同時に計画的に変えて、少ない実験の回数で各要因の影響を効率よく調べる手法はどれか。
  3. 製造装置のセンサのデータ(温度・圧力・電力など)を処理中に監視し、普段と違う状態を検知して異常を早く知らせる仕組みを何と呼ぶか。
  4. 製造装置の生産性を、稼働時間の割合・性能(速さ)・良品率を掛け合わせて評価する指標はどれか。
  5. 半導体の工場で、ウエハの投入から完成までにかかる時間を何と呼ぶか。
