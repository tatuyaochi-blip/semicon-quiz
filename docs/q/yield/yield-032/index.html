歩留まり・品質管理

QC七つ道具の一つで、データを装置別・作業者別・材料別などのグループに分けて比べ、違いの原因を探る考え方はどれか。

  1. Aシックスシグマ
  2. B層別
  3. CPDCA
答えと解説を見る

正解：B. 層別

層別は、データをその発生条件(装置、作業者、材料のロット、時間帯など)ごとのグループに分けて比べる方法です。全体ではわからなかった差が、特定のグループに偏っていることを見つけるのに役立ちます。

  • A. シックスシグマはばらつきを減らす品質改善の活動です。
  • B. 正しい。データをグループに分けて比べる方法です。
  • C. PDCAは改善の進め方のサイクルです。

歩留まり・品質管理のほかの問題

  1. QC七つ道具の一つで、確認すべき項目をあらかじめ表にしておき、点検の結果や不良の発生を記録・集計しやすくするものはどれか。
  2. 製品の「品質」と「信頼性」の違いとして一般的な説明はどれか。
  3. 問題が起きたときに、実際の現場で、実際の物を見て、実際の状況を確かめることを重視する考え方を何と呼ぶか。
  4. 工程の条件(温度、時間、ガス流量など)を複数同時に計画的に変えて、少ない実験の回数で各要因の影響を効率よく調べる手法はどれか。
  5. 製造装置のセンサのデータ(温度・圧力・電力など)を処理中に監視し、普段と違う状態を検知して異常を早く知らせる仕組みを何と呼ぶか。
