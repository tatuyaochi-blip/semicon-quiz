歩留まり・品質管理

前の工程の計測結果などをもとに、次のロットやウエハの装置の加工条件を自動で補正する制御はどれか。

  1. AFMEA
  2. Bパレート分析
  3. CAPC(Run-to-Run制御など)
答えと解説を見る

正解：C. APC(Run-to-Run制御など)

APC(Advanced Process Control)は、計測データを使って装置の条件を自動で調整し、工程のばらつきを小さくする制御です。例えば、前の工程の膜厚の測定値からエッチングやCMPの時間を補正します。管理図で監視するSPCに加え、積極的に補正する手法として使われています。

歩留まり・品質管理のほかの問題

  1. 製品や工程で起こりうる故障モードを洗い出し、その影響と重要度を評価して、事前に対策を講じる手法はどれか。
  2. 2つの特性値の組をプロットし、それらの相関関係を調べるための図はどれか。
  3. 新しいプロセスの立ち上げ以降、不良原因の解析と対策を重ねることで、歩留まりが時間とともに向上していく様子を表したものを何と呼ぶか。
  4. 製造のばらつきを、ロット間・ウエハ間・ウエハ内などの要因ごとに分けて評価する目的として正しいものはどれか。
  5. 品質管理で「シックスシグマ」と呼ばれる活動の考え方として正しいものはどれか。
