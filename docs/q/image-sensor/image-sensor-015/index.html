イメージセンサ・光デバイス

非冷却型の赤外線イメージセンサに使われるマイクロボロメータの原理として正しいものはどれか。

  1. A光電効果で電子を放出させる
  2. B赤外線を吸収して温度が上がり、それによる抵抗値の変化を検出する
  3. Cホール効果で磁界を検出する
答えと解説を見る

正解：B. 赤外線を吸収して温度が上がり、それによる抵抗値の変化を検出する

マイクロボロメータは、MEMS技術で基板から浮かせた酸化バナジウムやアモルファスシリコンの薄膜が赤外線を吸収してわずかに温まり、その温度変化による抵抗値の変化を検出します。熱が逃げないよう真空パッケージに封じます。冷却装置が不要で小型・安価なため、体温計測のサーモグラフィー、建物の断熱診断、夜間の監視や車の歩行者検知などに使われています。

イメージセンサ・光デバイスのほかの問題

  1. 明るい部分と暗い部分が混在する場面を撮影するための、イメージセンサのHDR(ハイダイナミックレンジ)化の手法として正しいものはどれか。
  2. イメージセンサの量子効率の定義として正しいものはどれか。
  3. シリコンのイメージセンサで、近赤外光の感度を高めるのが難しい理由として正しいものはどれか。
  4. CMOSイメージセンサの読み出しで使われる相関二重サンプリング(CDS)の目的として正しいものはどれか。
  5. 有機EL(OLED)ディスプレイの特徴として正しいものはどれか。
