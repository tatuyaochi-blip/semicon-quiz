イメージセンサ・光デバイス

非冷却型の赤外線イメージセンサに使われるマイクロボロメータの原理として正しいものはどれか。

  1. A光電効果で電子を放出させる
  2. B赤外線を吸収して温度が上がり、それによる抵抗値の変化を検出する
  3. Cホール効果で磁界を検出する
答えと解説を見る

正解：B. 赤外線を吸収して温度が上がり、それによる抵抗値の変化を検出する

マイクロボロメータは、断熱構造で浮かせた薄膜が赤外線を吸収して温まり、その温度変化による抵抗値の変化を検出します。MEMS技術でつくられ、冷却装置が不要なため、サーモグラフィーなどに使われています。

  2. イメージセンサの量子効率の定義として正しいものはどれか。
  3. シリコンのイメージセンサで、近赤外光の感度を高めるのが難しい理由として正しいものはどれか。
  4. CMOSイメージセンサの読み出しで使われる相関二重サンプリング(CDS)の目的として正しいものはどれか。
  5. 有機EL(OLED)ディスプレイの特徴として正しいものはどれか。
