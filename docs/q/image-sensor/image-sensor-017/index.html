イメージセンサ・光デバイス

イメージセンサの量子効率の定義として正しいものはどれか。

  1. A画素の数に対する出力の数
  2. B入射した光子の数に対する、発生して信号になった電子の数の割合
  3. C電源電圧に対する出力電圧の比
答えと解説を見る

正解：B. 入射した光子の数に対する、発生して信号になった電子の数の割合

量子効率は、センサーに入った光子のうち、どれだけが電子に変換されて信号として取り出されたかの割合です。波長によって異なり、量子効率が高いほど感度の高いセンサーになります。裏面照射型やマイクロレンズは量子効率を高める技術です。

イメージセンサ・光デバイスのほかの問題

  1. シリコンのイメージセンサで、近赤外光の感度を高めるのが難しい理由として正しいものはどれか。
  2. CMOSイメージセンサの読み出しで使われる相関二重サンプリング(CDS)の目的として正しいものはどれか。
  3. 有機EL(OLED)ディスプレイの特徴として正しいものはどれか。
  4. CMOSイメージセンサの代表的な4トランジスタ画素で、フォトダイオードの電荷を浮遊拡散層(フローティングディフュージョン)に移す役割をもつトランジスタはどれか。
  5. 画素ごとの特性のばらつきによって、毎回同じ位置に同じように現れるノイズを何と呼ぶか。
