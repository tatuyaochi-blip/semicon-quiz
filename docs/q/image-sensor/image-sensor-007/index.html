イメージセンサ・光デバイス

イメージセンサの各画素の上に設けるマイクロレンズの役割はどれか。

  1. A光を色ごとに分ける
  2. B赤外線を遮る
  3. C各画素の上で光を集め、フォトダイオードへ効率よく導く
答えと解説を見る

正解：C. 各画素の上で光を集め、フォトダイオードへ効率よく導く

画素の面積のうち、光を受けられるフォトダイオードの部分は一部にすぎません。マイクロレンズは画素に入った光を集めてフォトダイオードに導き、感度を高めます。色を分けるのはカラーフィルタ、赤外線を遮るのはIRカットフィルタの役割です。
