イメージセンサ・光デバイス

CMOSイメージセンサの「変換ゲイン」の説明として正しいものはどれか。

  1. A画素に蓄えた電子1個あたりの出力電圧(例えば µV/e⁻)
  2. Bレンズの拡大率
  3. C画素数を2倍にする倍率
答えと解説を見る

正解：A. 画素に蓄えた電子1個あたりの出力電圧(例えば µV/e⁻)

変換ゲインは、浮遊拡散層(FD)に転送された電子1個が何µVの電圧になるかで、q/C_FD で決まります。FDの容量が1 fFなら約160 µV/e⁻です。大きいと後段回路のノイズの影響が相対的に小さく暗い場面に強い一方、扱える電子数は減ります。そこで、FDに容量を追加するかどうかを切り替えて、暗い場面と明るい場面で変換ゲインを使い分けるデュアルゲイン方式が使われます。

  • A. 正しい。電子1個あたりの電圧変化です。
  • B. レンズの拡大率ではありません。
  • C. 画素数とは関係ありません。

イメージセンサ・光デバイスのほかの問題

  1. 多くのCMOSイメージセンサで採用されている、画素の列ごとにAD変換器を設けて並列に変換する方式の主な利点はどれか。
  2. イメージセンサの「画素ビニング」の説明として正しいものはどれか。
  3. 非常に明るい光を受けた画素から電荷があふれ、周囲の画素まで白く広がって写る現象を何と呼ぶか。
  4. 細かい縞模様の被写体を撮影したときに、画素の配列との干渉で本来ない模様(モアレ)が現れるのを抑えるために、センサの前に置かれることがある部品はどれか。
  5. 人や物の温度を画像にするサーモグラフィで、主に検出に使われる赤外線の波長帯はどれか。
