イメージセンサ・光デバイス

CMOSイメージセンサの「変換ゲイン」の説明として正しいものはどれか。

  1. A画素数を2倍にする倍率
  2. B画素に蓄えた電子1個あたりの出力電圧(例えば µV/e⁻)
  3. Cレンズの拡大率
答えと解説を見る

正解：B. 画素に蓄えた電子1個あたりの出力電圧(例えば µV/e⁻)

変換ゲインは、浮遊拡散層(FD)に転送された信号電子1個がどれだけの電圧変化になるかを表し、FDの容量が小さいほど大きくなります。変換ゲインが大きいと読み出し回路のノイズの影響が相対的に小さくなり、暗い場面に強くなりますが、扱える電子の数(ダイナミックレンジ)は小さくなりがちです。

  • A. 画素数とは関係ありません。
  • B. 正しい。電子1個あたりの電圧変化です。
  • C. レンズの拡大率ではありません。

イメージセンサ・光デバイスのほかの問題

  1. 多くのCMOSイメージセンサで採用されている、画素の列ごとにAD変換器を設けて並列に変換する方式の主な利点はどれか。
  2. イメージセンサの「画素ビニング」の説明として正しいものはどれか。
  3. 非常に明るい光を受けた画素から電荷があふれ、周囲の画素まで白く広がって写る現象を何と呼ぶか。
  4. 細かい縞模様の被写体を撮影したときに、画素の配列との干渉で本来ない模様(モアレ)が現れるのを抑えるために、センサの前に置かれることがある部品はどれか。
  5. 人や物の温度を画像にするサーモグラフィで、主に検出に使われる赤外線の波長帯はどれか。
