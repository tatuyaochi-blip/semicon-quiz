イメージセンサ・光デバイス

イメージセンサの画素の「開口率(フィルファクタ)」の意味として正しいものはどれか。

  1. Aレンズの絞りの大きさ
  2. B画素数に対する有効画素数の割合
  3. C画素の面積のうち、光を受けて電荷に変える部分が占める割合
答えと解説を見る

正解：C. 画素の面積のうち、光を受けて電荷に変える部分が占める割合

開口率は、1つの画素の面積のうちフォトダイオードとして光を受けられる部分の割合です。トランジスタや配線が光を遮る部分が多いと開口率が下がり、感度が落ちます。マイクロレンズや裏面照射型の構造は、実効的な開口率を高めるための工夫です。

  • A. レンズの絞りはF値で表され、画素の開口率とは別のものです。
  • B. 有効画素数の割合とは別の指標です。
  • C. 正しい。画素の中で受光できる面積の割合です。

イメージセンサ・光デバイスのほかの問題

  1. ベイヤー配列などのカラーフィルタを使ったセンサの出力から、各画素の赤・緑・青すべての値を周囲の画素から補って求める処理を何と呼ぶか。
  2. 放送用カメラなどで使われる「3板式」の撮像方式の説明として正しいものはどれか。
  3. 降伏電圧を超える逆バイアスで動作させ、光子1個でもなだれ増倍によるパルスを発生させる受光素子はどれか。
  4. 画素ごとに明るさの変化だけを検出し、変化があった画素の情報だけを非同期に出力するイメージセンサはどれか。
  5. CMOSイメージセンサで、フォトダイオードから浮遊拡散層への電荷の転送が不完全なときに起こる問題はどれか。
