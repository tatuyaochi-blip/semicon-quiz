イメージセンサ・光デバイス

暗い場所で撮影した画像がざらついて(ノイズが目立って)見える主な理由はどれか。

  1. A暗いとイメージセンサの画素数が減るため
  2. B暗いと光の波長が長くなるため
  3. C画素に入る光子の数が少なく、信号に対してノイズが相対的に大きくなるため
答えと解説を見る

正解：C. 画素に入る光子の数が少なく、信号に対してノイズが相対的に大きくなるため

暗い場所では画素に届く光子が少なく信号が小さくなる一方、光子数のゆらぎ(ショットノイズ、√N)や読み出し回路のノイズは残るため、SN比が下がって画像がざらつきます。ISO感度を上げても信号とノイズが一緒に増幅されるだけです。そのため大きなセンサや明るいレンズで光を多く集める、複数枚を重ねて平均する(夜景モード)などの方法でSN比を改善します。

  • A. 画素数は明るさによって変わりません。
  • B. 暗さによって光の波長が変わるわけではありません。
  • C. 正しい。信号が小さくなり、SN比が下がるためです。

イメージセンサ・光デバイスのほかの問題

  1. CMOSイメージセンサの「変換ゲイン」の説明として正しいものはどれか。
  2. 多くのCMOSイメージセンサで採用されている、画素の列ごとにAD変換器を設けて並列に変換する方式の主な利点はどれか。
  3. イメージセンサの「画素ビニング」の説明として正しいものはどれか。
  4. 非常に明るい光を受けた画素から電荷があふれ、周囲の画素まで白く広がって写る現象を何と呼ぶか。
  5. 細かい縞模様の被写体を撮影したときに、画素の配列との干渉で本来ない模様(モアレ)が現れるのを抑えるために、センサの前に置かれることがある部品はどれか。
