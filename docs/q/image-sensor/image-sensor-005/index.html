イメージセンサ・光デバイス

ベイヤー配列のカラーフィルタで、2×2の画素の中に最も多く配置される色はどれか。

  1. A赤
  2. B青
  3. C緑
答えと解説を見る

正解：C. 緑

ベイヤー配列では、2×2画素に赤1つ、青1つ、緑2つを配置します。人の目は緑の光に最も敏感で、明るさの情報の多くを緑から得ているため、緑を多くして解像感を高めています。各画素にない色の情報は、周囲の画素から補間して求めます。
