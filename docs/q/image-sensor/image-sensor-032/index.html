イメージセンサ・光デバイス

カラー画像を撮るイメージセンサで、画素の上にカラーフィルタを置く必要がある理由として正しいものはどれか。

  1. A画素数を増やすため
  2. Bフォトダイオード自体は光の色(波長)を区別できず、光の強さしかわからないため
  3. Cフォトダイオードを熱から守るため
答えと解説を見る

正解：B. フォトダイオード自体は光の色(波長)を区別できず、光の強さしかわからないため

シリコンのフォトダイオードは、バンドギャップより大きなエネルギーの光であれば色に関係なく電荷を発生するため、明るさしかわかりません。そこで画素ごとに赤・緑・青のフィルタを置き、通った色の光の強さを測ることで色の情報を得ます。

  • A. フィルタを置いても画素数は増えません。
  • B. 正しい。フォトダイオードは色を区別できません。
  • C. カラーフィルタは熱から守るためのものではありません。

イメージセンサ・光デバイスのほかの問題

  1. 現在のスマートフォンのカメラに主に使われているイメージセンサはどれか。
  2. 逆バイアスをかけたフォトダイオードに当たる光を強くすると、流れる電流(光電流)はどうなるか。
  3. 暗い場所で撮影した画像がざらついて(ノイズが目立って)見える主な理由はどれか。
  4. CMOSイメージセンサの「変換ゲイン」の説明として正しいものはどれか。
  5. 多くのCMOSイメージセンサで採用されている、画素の列ごとにAD変換器を設けて並列に変換する方式の主な利点はどれか。
