イメージセンサ・光デバイス

画素ごとに明るさの変化だけを検出し、変化があった画素の情報だけを非同期に出力するイメージセンサはどれか。

  1. Aラインセンサ
  2. BCCDイメージセンサ
  3. Cイベントベースビジョンセンサ
答えと解説を見る

正解：C. イベントベースビジョンセンサ

イベントベースビジョンセンサは、決まったフレームごとに全画素を読むのではなく、明るさが一定以上変化した画素だけが、その位置・時刻・増減の向きをイベントとして非同期に出力します。動きのない背景はデータにならないためデータ量が少なく、マイクロ秒級の時間分解能と120 dB以上のダイナミックレンジが得られます。高速な物体の追跡、工場の振動監視、ロボットの視覚などに使われます。

  • A. ラインセンサは画素を1列に並べたセンサで、スキャナなどに使われます。
  • B. CCDはフレームごとに全画素の電荷を順に転送して読み出します。
  • C. 正しい。変化した画素だけを非同期に出力します。
