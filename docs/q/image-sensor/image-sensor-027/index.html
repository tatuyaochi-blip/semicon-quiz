イメージセンサ・光デバイス

スマートフォン向けの高画素イメージセンサの画素サイズとして最も近いものはどれか。

  1. A約1 mm
  2. B約1 µm前後
  3. C約100 µm
答えと解説を見る

正解：B. 約1 µm前後

スマートフォン向けの高画素センサーでは、画素サイズが1 µm前後、さらにそれ以下まで小さくなっています。小さな画素で感度を保つため、裏面照射型、DTI、複数の画素をまとめて1画素として使う技術などが組み合わされています。
