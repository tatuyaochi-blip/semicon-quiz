イメージセンサ・光デバイス

スマートフォン向けの高画素イメージセンサの画素サイズとして最も近いものはどれか。

  1. A約1 mm
  2. B約1 µm前後
  3. C約100 µm
答えと解説を見る

正解：B. 約1 µm前後

スマートフォン向けの高画素センサの画素サイズは1 µm前後、さらに0.6 µm程度まで小さくなっています。可視光の波長(0.4〜0.7 µm)に近いため、光の回折で集光が難しくなります。小さな画素で感度を保つため、裏面照射型、DTI、積層型に加え、4つ(または9つ、16個)の同色画素を並べてまとめて使うクアッドベイヤー配列などが組み合わされています。デジタル一眼の画素は4〜6 µm程度です。
