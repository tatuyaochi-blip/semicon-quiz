イメージセンサ・光デバイス

イメージセンサの1画素に蓄えられる電子の最大数を何と呼ぶか。

  1. A飽和電子数(フルウェル容量)
  2. B量子効率
  3. C暗電流
答えと解説を見る

正解：A. 飽和電子数(フルウェル容量)

飽和電子数は、フォトダイオードに蓄えられる電子の最大数で、これを超えると白飛びになります。飽和電子数をノイズの大きさで割った値がダイナミックレンジになり、大きいほど明暗差の大きい場面を表現できます。画素を小さくすると飽和電子数は減る傾向があります。

  2. 「1,200万画素」のイメージセンサの説明として正しいものはどれか。
  3. カラー画像を撮るイメージセンサで、画素の上にカラーフィルタを置く必要がある理由として正しいものはどれか。
  4. 現在のスマートフォンのカメラに主に使われているイメージセンサはどれか。
  5. 逆バイアスをかけたフォトダイオードに当たる光を強くすると、流れる電流(光電流)はどうなるか。
