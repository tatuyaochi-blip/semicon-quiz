イメージセンサ・光デバイス

CMOSイメージセンサの代表的な4トランジスタ画素で、フォトダイオードの電荷を浮遊拡散層(フローティングディフュージョン)に移す役割をもつトランジスタはどれか。

  1. A転送トランジスタ
  2. Bリセットトランジスタ
  3. C選択トランジスタ
答えと解説を見る

正解：A. 転送トランジスタ

4トランジスタ画素は、転送、リセット、増幅(ソースフォロワ)、選択の4つのトランジスタで構成されます。転送トランジスタが埋め込みフォトダイオードの電荷を浮遊拡散層(FD)に移し、その電圧を増幅トランジスタで出力します。リセットはFDの初期化、選択は読み出す行の選択です。転送前後の値の差をとるCDSが可能になるのがこの構造の利点で、隣の画素とFDなどを共有して面積を減らす工夫もあります。

イメージセンサ・光デバイスのほかの問題

  1. 画素ごとの特性のばらつきによって、毎回同じ位置に同じように現れるノイズを何と呼ぶか。
  2. 光子の数の統計的なゆらぎによるショットノイズの大きさと、信号電子の数Nの関係として正しいものはどれか。
  3. 微細な画素の間に深い溝を掘り、絶縁物などを埋め込む構造(DTI)の主な目的はどれか。
  4. 光ファイバ通信の1.55 µm帯の光を受けるフォトダイオードに使われる材料として適切なものはどれか。
  5. CCDイメージセンサの信号の読み出し方式として正しいものはどれか。
