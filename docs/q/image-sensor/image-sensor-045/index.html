イメージセンサ・光デバイス

降伏電圧を超える逆バイアスで動作させ、光子1個でもなだれ増倍によるパルスを発生させる受光素子はどれか。

  1. APINフォトダイオード
  2. BSPAD(単一光子アバランシェダイオード)
  3. C太陽電池
答えと解説を見る

正解：B. SPAD(単一光子アバランシェダイオード)

SPADは、降伏電圧を超えた逆バイアス(ガイガーモード)で動作させ、光子1個が生む電子でもなだれ増倍を起こして大きな電流パルスを出します。クエンチ回路でなだれを止めて次の光子に備えます。光子の到着時刻を精密に測れるため、LiDARなどの距離計測に使われます。

  • A. PINフォトダイオードは増倍作用をもたない受光素子です。
  • B. 正しい。単一光子を検出できるアバランシェダイオードです。
  • C. 太陽電池は発電用の素子で、単一光子の検出には使いません。

イメージセンサ・光デバイスのほかの問題

  1. 画素ごとに明るさの変化だけを検出し、変化があった画素の情報だけを非同期に出力するイメージセンサはどれか。
  2. CMOSイメージセンサで、フォトダイオードから浮遊拡散層への電荷の転送が不完全なときに起こる問題はどれか。
  3. イメージセンサの変換ゲインなどを、明るさを変えて撮った画像の信号の平均値とばらつき(分散)の関係から求める評価方法はどれか。
  4. シリコンでは検出できない短波長赤外(SWIR、約1〜2 µm)を、安価なイメージセンサで検出するために研究・実用化が進んでいる受光材料の例はどれか。
  5. 医療用のX線撮影に使われる間接変換型のフラットパネル検出器で、X線を検出する方法として正しいものはどれか。
