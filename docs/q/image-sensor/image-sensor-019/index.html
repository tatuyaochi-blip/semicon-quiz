イメージセンサ・光デバイス

CMOSイメージセンサの読み出しで使われる相関二重サンプリング(CDS)の目的として正しいものはどれか。

  1. A信号を2倍に増幅するため
  2. B色の情報を補間するため
  3. Cリセット時と信号読み出し時の差をとり、リセットノイズや画素ごとのオフセットを除去するため
答えと解説を見る

正解：C. リセット時と信号読み出し時の差をとり、リセットノイズや画素ごとのオフセットを除去するため

CDSでは、画素をリセットした直後の出力と、光の信号を読み出したときの出力をそれぞれサンプリングし、その差を信号とします。リセットのたびにばらつくノイズや、画素ごとのアンプのオフセットが打ち消されるため、ノイズの少ない画像が得られます。

イメージセンサ・光デバイスのほかの問題

  1. 有機EL(OLED)ディスプレイの特徴として正しいものはどれか。
  2. CMOSイメージセンサの代表的な4トランジスタ画素で、フォトダイオードの電荷を浮遊拡散層(フローティングディフュージョン)に移す役割をもつトランジスタはどれか。
  3. 画素ごとの特性のばらつきによって、毎回同じ位置に同じように現れるノイズを何と呼ぶか。
  4. 光子の数の統計的なゆらぎによるショットノイズの大きさと、信号電子の数Nの関係として正しいものはどれか。
  5. 微細な画素の間に深い溝を掘り、絶縁物などを埋め込む構造(DTI)の主な目的はどれか。
