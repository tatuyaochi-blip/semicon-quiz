イメージセンサ・光デバイス

細かい縞模様の被写体を撮影したときに、画素の配列との干渉で本来ない模様(モアレ)が現れるのを抑えるために、センサの前に置かれることがある部品はどれか。

  1. A光学ローパスフィルタ
  2. Bマイクロレンズ
  3. C偏光板
答えと解説を見る

正解：A. 光学ローパスフィルタ

画素の間隔より細かい模様は正しく表せず、折り返し(エイリアシング)によってモアレや偽色が現れます。光学ローパスフィルタは光をわずかにぼかして細かすぎる成分を落とし、これを抑えます。解像感が下がるため、高画素のカメラでは省かれることもあります。

  • A. 正しい。光をわずかにぼかして細かすぎる成分を落とします。
  • B. マイクロレンズは光を画素の受光部に集めるためのものです。
  • C. 偏光板は特定の向きの偏光を通すもので、モアレ対策ではありません。

イメージセンサ・光デバイスのほかの問題

  1. 人や物の温度を画像にするサーモグラフィで、主に検出に使われる赤外線の波長帯はどれか。
  2. イメージセンサの画素の「開口率(フィルファクタ)」の意味として正しいものはどれか。
  3. ベイヤー配列などのカラーフィルタを使ったセンサの出力から、各画素の赤・緑・青すべての値を周囲の画素から補って求める処理を何と呼ぶか。
  4. 放送用カメラなどで使われる「3板式」の撮像方式の説明として正しいものはどれか。
  5. 降伏電圧を超える逆バイアスで動作させ、光子1個でもなだれ増倍によるパルスを発生させる受光素子はどれか。
