イメージセンサ・光デバイス

CCDイメージセンサの信号の読み出し方式として正しいものはどれか。

  1. A画素の電荷をバケツリレーのように順に転送し、出力部で電圧に変換する
  2. B画素ごとの増幅器で電圧に変換し、行ごとに読み出す
  3. C光を直接デジタル信号に変換する
答えと解説を見る

正解：A. 画素の電荷をバケツリレーのように順に転送し、出力部で電圧に変換する

CCDは、画素に蓄えた電荷を、電極の電圧を順に切り替えることでバケツリレーのように転送し、出力部の1つのアンプで電圧に変換します。ノイズが少なく画質がよい一方、高い電圧での駆動が必要で消費電力が大きく、周辺回路の集積も難しいため、現在はCMOSイメージセンサが主流です。
