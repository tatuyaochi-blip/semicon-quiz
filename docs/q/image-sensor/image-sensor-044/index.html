イメージセンサ・光デバイス

放送用カメラなどで使われる「3板式」の撮像方式の説明として正しいものはどれか。

  1. A3つのレンズで立体映像を撮る
  2. B3回露光して明るさを合成する
  3. Cプリズムで光を赤・緑・青に分け、それぞれ別のイメージセンサで受ける
答えと解説を見る

正解：C. プリズムで光を赤・緑・青に分け、それぞれ別のイメージセンサで受ける

3板式では、ダイクロイックプリズムで光を赤・緑・青に分け、3枚のイメージセンサでそれぞれの色を受けます。各画素がすべての色の情報をもつため色補間が不要で、光をフィルタで捨てないので感度も高く、色再現や解像感に優れます。代わりにプリズムを含む光学系が大きく高価になり、3枚の位置合わせも必要です。放送用カメラや一部の業務用ビデオカメラで使われています。

  • A. 立体映像の撮影方式ではありません。
  • B. 明るさを合成するHDRの方式ではありません。
  • C. 正しい。光を3色に分けて別々のセンサで受けます。

イメージセンサ・光デバイスのほかの問題

  1. 降伏電圧を超える逆バイアスで動作させ、光子1個でもなだれ増倍によるパルスを発生させる受光素子はどれか。
  2. 画素ごとに明るさの変化だけを検出し、変化があった画素の情報だけを非同期に出力するイメージセンサはどれか。
  3. CMOSイメージセンサで、フォトダイオードから浮遊拡散層への電荷の転送が不完全なときに起こる問題はどれか。
  4. イメージセンサの変換ゲインなどを、明るさを変えて撮った画像の信号の平均値とばらつき(分散)の関係から求める評価方法はどれか。
  5. シリコンでは検出できない短波長赤外(SWIR、約1〜2 µm)を、安価なイメージセンサで検出するために研究・実用化が進んでいる受光材料の例はどれか。
