イメージセンサ・光デバイス

シリコンのイメージセンサで、近赤外光の感度を高めるのが難しい理由として正しいものはどれか。

  1. Aシリコンでの近赤外光の吸収が弱く、深いところまで透過してしまうため
  2. B近赤外光はレンズを通らないため
  3. C近赤外光は電子を発生させないため
答えと解説を見る

正解：A. シリコンでの近赤外光の吸収が弱く、深いところまで透過してしまうため

シリコンは波長が長い光ほど吸収が弱く、近赤外光はフォトダイオードの深い位置まで透過してしまいます。そのため薄いフォトダイオードでは十分に吸収できず、感度が低くなります。表面に光を閉じ込める構造をつくったり、受光層を厚くしたりする工夫が行われています。

イメージセンサ・光デバイスのほかの問題

  1. CMOSイメージセンサの読み出しで使われる相関二重サンプリング(CDS)の目的として正しいものはどれか。
  2. 有機EL(OLED)ディスプレイの特徴として正しいものはどれか。
  3. CMOSイメージセンサの代表的な4トランジスタ画素で、フォトダイオードの電荷を浮遊拡散層(フローティングディフュージョン)に移す役割をもつトランジスタはどれか。
  4. 画素ごとの特性のばらつきによって、毎回同じ位置に同じように現れるノイズを何と呼ぶか。
  5. 光子の数の統計的なゆらぎによるショットノイズの大きさと、信号電子の数Nの関係として正しいものはどれか。
