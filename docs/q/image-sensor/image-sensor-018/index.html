イメージセンサ・光デバイス

シリコンのイメージセンサで、近赤外光の感度を高めるのが難しい理由として正しいものはどれか。

  1. Aシリコンでの近赤外光の吸収が弱く、深いところまで透過してしまうため
  2. B近赤外光はレンズを通らないため
  3. C近赤外光は電子を発生させないため
答えと解説を見る

正解：A. シリコンでの近赤外光の吸収が弱く、深いところまで透過してしまうため

シリコンは波長が長いほど吸収が弱く、吸収の深さは550 nmで約1.5 µm、850 nmで約20 µm、940 nmでは50 µm以上になります。数µmの薄いフォトダイオードでは十分に吸収できず、感度が低くなります。顔認証やToFで使う近赤外の感度を上げるため、表面に細かい凹凸をつけて光を斜めに散らし、画素内で光路を長くする構造などが使われています。
