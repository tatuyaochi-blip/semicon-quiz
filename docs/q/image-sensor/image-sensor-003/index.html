イメージセンサ・光デバイス

LEDの発光色(発光波長)を決める主な要因はどれか。

  1. Aパッケージの形状
  2. B駆動電流の向き
  3. C発光層に使う半導体のバンドギャップ
答えと解説を見る

正解：C. 発光層に使う半導体のバンドギャップ

LEDでは、電子と正孔が再結合するときにバンドギャップに相当するエネルギーの光が出ます。光の波長は λ(nm) ≈ 1240 / Eg(eV) で表され、バンドギャップが大きいほど短い波長(青色側)の光になります。
