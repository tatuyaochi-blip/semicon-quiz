イメージセンサ・光デバイス

イメージセンサの暗電流の説明として正しいものはどれか。

  1. A光の強さに比例して増える信号電流
  2. B光が当たっていなくても流れる電流で、温度が上がると増える
  3. C画素を読み出すためのクロック電流
答えと解説を見る

正解：B. 光が当たっていなくても流れる電流で、温度が上がると増える

暗電流は、光が当たっていなくてもフォトダイオードで熱的に発生する電荷による電流です。暗い場所での撮影や長時間露光でノイズの原因になり、温度が上がると増えます。結晶欠陥や界面の準位を減らすことで抑えられます。
