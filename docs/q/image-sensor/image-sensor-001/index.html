イメージセンサ・光デバイス

CMOSイメージセンサの各画素で、光を電荷に変換する素子はどれか。

  1. Aフォトダイオード
  2. B発光ダイオード(LED)
  3. Cツェナーダイオード
答えと解説を見る

正解：A. フォトダイオード

イメージセンサの画素では、フォトダイオードが入射した光を吸収して電子と正孔の対をつくり、光の量に応じた電荷を蓄えます。CMOSイメージセンサでは、その電荷を画素内のトランジスタで電圧に変えて読み出します。

  3. CCDイメージセンサと比べたときの、CMOSイメージセンサの一般的な特長として正しいものはどれか。
