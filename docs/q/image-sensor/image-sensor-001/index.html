イメージセンサ・光デバイス

CMOSイメージセンサの各画素で、光を電荷に変換する素子はどれか。

  1. Aフォトダイオード
  2. B発光ダイオード(LED)
  3. Cツェナーダイオード
答えと解説を見る

正解：A. フォトダイオード

イメージセンサの画素では、フォトダイオードが光を吸収して電子と正孔の対をつくり、光の量に応じた電子を露光の間ためておきます。CMOSイメージセンサでは、その電荷を画素内のトランジスタで電圧に変えて読み出します。光子1個から電子1個ができる割合(量子効率)は可視光で50〜80%程度です。LEDは電気を光に変える素子、ツェナーダイオードは定電圧用です。

イメージセンサ・光デバイスのほかの問題

  1. 裏面照射型(BSI)CMOSイメージセンサの主な利点として正しいものはどれか。
  2. LEDの発光色(発光波長)を決める主な要因はどれか。
  3. CCDイメージセンサと比べたときの、CMOSイメージセンサの一般的な特長として正しいものはどれか。
  4. ベイヤー配列のカラーフィルタで、2×2の画素の中に最も多く配置される色はどれか。
  5. CMOSイメージセンサのローリングシャッター方式で、速く動く被写体がゆがんで写る理由として正しいものはどれか。
