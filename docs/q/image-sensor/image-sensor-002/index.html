イメージセンサ・光デバイス

裏面照射型(BSI)CMOSイメージセンサの主な利点として正しいものはどれか。

  1. A画素数を減らせる
  2. B配線層を通らずに光がフォトダイオードへ届くため、感度を高めやすい
  3. Cカラーフィルタが不要になる
答えと解説を見る

正解：B. 配線層を通らずに光がフォトダイオードへ届くため、感度を高めやすい

従来の表面照射型では、光が配線層のすき間を通ってフォトダイオードに届くため、配線で光が遮られたり反射したりしていました。裏面照射型はウエハを薄くして配線層の反対側から光を入れるため、光を効率よく取り込め、画素が小さくても感度を確保しやすくなります。
