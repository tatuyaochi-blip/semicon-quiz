GPUプログラミング

最近のGPUに搭載されているテンソルコア(行列演算ユニット)の特徴として正しいものはどれか。

  1. A小さな行列どうしの積和を1つの命令でまとめて計算し、主に低い精度の数値でAIの計算を大幅に速くする
  2. Bテンソルという物理量を測るセンサである
  3. Cグラフィックスの影を描く専用の回路である
答えと解説を見る

正解：A. 小さな行列どうしの積和を1つの命令でまとめて計算し、主に低い精度の数値でAIの計算を大幅に速くする

テンソルコアは、例えば4×4や16×16のような小さな行列の掛け算と足し算を、1つの命令で一度に行う演算器です。普通の演算器で1回ずつ掛け算と足し算を行うより、同じ面積と電力で何倍もの計算ができます。FP16やBF16、FP8、INT8などの低い精度で使うことが多く、ニューラルネットワークの学習と推論の大部分を占める行列の積を大きく速くします。

  • A. 正しい。行列の積に特化した演算器です。
  • B. センサではありません。
  • C. 影の描画のための回路ではありません。

GPUプログラミングのほかの問題

  1. GPUの混合精度の計算で、掛け算をFP16などの低い精度で行い、足し合わせ(累積)をFP32で行うことが多い理由として正しいものはどれか。
  2. GPUで同じデータの浮動小数点数の総和を求めたところ、実行するたびに結果の最後の桁がわずかに違った。最も考えられる原因はどれか。
  3. CUDAで1ブロックあたりのスレッドの数を決めるときの一般的な目安として正しいものはどれか。
  4. 上のようなループ(グリッドストライドループ)でカーネルを書く利点として正しいものはどれか。
  5. CUDAの定数メモリ(コンスタントメモリ)が特に速く働くのはどのようなアクセスのときか。
