成膜(CVD・PVD)

真空蒸着の説明として正しいものはどれか。

  1. A原料ガスの化学反応で膜を堆積させる
  2. B電解液中で金属を析出させる
  3. C真空中で材料を加熱して蒸発させ、基板に付着させる
答えと解説を見る

正解：C. 真空中で材料を加熱して蒸発させ、基板に付着させる

真空蒸着は、抵抗加熱や電子ビームで材料を加熱して蒸発させ、10⁻⁴ Pa程度以下の真空中を飛んだ原子を基板に付着させるPVDです。装置が比較的簡単で純度の高い膜が得られますが、原子がまっすぐ飛ぶため段差被覆性は低く、合金の組成もずれやすいため、LSIの配線にはスパッタが主に使われます。化合物半導体の電極形成のリフトオフや、有機ELの発光層の成膜などに使われます。

成膜(CVD・PVD)のほかの問題

  1. 成膜した薄膜の内部応力が大きいときに起こりやすい問題はどれか。
  2. 液状の材料をウエハの中心に滴下し、高速で回転させて均一な膜をつくる方法を何と呼ぶか。
  3. シリコン酸化膜のCVDで原料として広く使われる、液体の有機シリコン化合物はどれか。
  4. タングステンのCVDで原料として使われるガスはどれか。
  5. 高密度プラズマCVD(HDP-CVD)が、狭い溝の絶縁膜埋め込みに使われてきた理由として正しいものはどれか。

この分野の比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
