成膜(CVD・PVD)

LPCVDでポリシリコン膜を成膜するときに一般的に使われる原料ガスはどれか。

  1. Aアルゴン
  2. Bシラン(SiH4)
  3. C二酸化炭素
答えと解説を見る

正解：B. シラン(SiH4)

ポリシリコンは、シランを600 ℃前後で熱分解させて堆積させます。成膜温度によって結晶粒の大きさが変わり、温度が低いとアモルファスシリコンになります。ゲート電極や抵抗、キャパシタの電極などに使われます。

  4. シリコン酸化膜のCVDで原料として広く使われる、液体の有機シリコン化合物はどれか。
  5. タングステンのCVDで原料として使われるガスはどれか。
