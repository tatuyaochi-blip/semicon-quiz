成膜(CVD・PVD)

LPCVDでポリシリコン膜を成膜するときに一般的に使われる原料ガスはどれか。

  1. Aアルゴン
  2. Bシラン(SiH4)
  3. C二酸化炭素
答えと解説を見る

正解：B. シラン(SiH4)

ポリシリコンは、シランを600〜650 ℃程度で熱分解(SiH4 → Si + 2H2)させて堆積させます。成膜温度によって結晶粒の大きさが変わり、約580 ℃より低いとアモルファスシリコンになります。ゲート電極(High-k以前)、抵抗、DRAMやフラッシュの電極、MEMSの構造体などに使われ、成膜中や後から不純物を入れて抵抗を下げます。

成膜(CVD・PVD)のほかの問題

  1. 真空蒸着の説明として正しいものはどれか。
  2. 成膜した薄膜の内部応力が大きいときに起こりやすい問題はどれか。
  3. 液状の材料をウエハの中心に滴下し、高速で回転させて均一な膜をつくる方法を何と呼ぶか。
  4. シリコン酸化膜のCVDで原料として広く使われる、液体の有機シリコン化合物はどれか。
  5. タングステンのCVDで原料として使われるガスはどれか。

この分野の比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
