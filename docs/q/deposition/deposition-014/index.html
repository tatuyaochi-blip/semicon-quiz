成膜(CVD・PVD)

シリコン窒化膜(Si3N4)の用途として正しいものはどれか。

  1. Aゲート電極や配線の主材料
  2. BLOCOSの酸化マスク、CMPのストッパー、表面の保護膜(パッシベーション)
  3. Cフォトレジストの代わり
答えと解説を見る

正解：B. LOCOSの酸化マスク、CMPのストッパー、表面の保護膜(パッシベーション)

シリコン窒化膜は酸素や水分を通しにくく、硬いため、選択酸化(LOCOS)のマスク、STI形成でのCMPストッパー、チップ表面を水分や可動イオンから守るパッシベーション膜などに使われます。エッチングのストッパーやハードマスクとしても使われます。

  2. CVDで段差被覆性(コンフォーマル性)がよくなる条件として正しいものはどれか。
  3. シランを熱分解してシリコン膜を堆積するとき、成膜温度を低くした場合にできる膜はどれか。
  4. ALDで成膜される代表的な材料の例として正しいものはどれか。
  5. スパッタした原子をイオン化し、ウエハにかけたバイアスで垂直に引き込むスパッタ方式の主な目的はどれか。
