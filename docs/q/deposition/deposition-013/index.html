成膜(CVD・PVD)

高密度プラズマCVD(HDP-CVD)が、狭い溝の絶縁膜埋め込みに使われてきた理由として正しいものはどれか。

  1. A成膜と同時にイオンによるスパッタで開口部の膜を削り、ボイドを抑えて埋め込めるため
  2. B成膜温度が1000 ℃以上と高いため
  3. C金属膜しか成膜できないため
答えと解説を見る

正解：A. 成膜と同時にイオンによるスパッタで開口部の膜を削り、ボイドを抑えて埋め込めるため

通常のCVDで狭い溝を埋めると、開口部の角に膜が厚く付いて先にふさがり、中に空洞(ボイド)が残ることがあります。HDP-CVDでは、成膜しながらイオンで開口部の膜を削るため、底から順に埋め込めます。STIや配線間の埋め込みに使われてきました。

成膜(CVD・PVD)のほかの問題

  1. シリコン窒化膜(Si3N4)の用途として正しいものはどれか。
  2. マグネトロンスパッタリングで、ターゲットの裏側に磁石を置く主な目的はどれか。
  3. CVDで段差被覆性(コンフォーマル性)がよくなる条件として正しいものはどれか。
  4. シランを熱分解してシリコン膜を堆積するとき、成膜温度を低くした場合にできる膜はどれか。
  5. ALDで成膜される代表的な材料の例として正しいものはどれか。
