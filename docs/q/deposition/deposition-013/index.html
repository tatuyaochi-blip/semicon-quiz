成膜(CVD・PVD)

高密度プラズマCVD(HDP-CVD)が、狭い溝の絶縁膜埋め込みに使われてきた理由として正しいものはどれか。

  1. A成膜と同時にイオンによるスパッタで開口部の膜を削り、ボイドを抑えて埋め込めるため
  2. B成膜温度が1000 ℃以上と高いため
  3. C金属膜しか成膜できないため
答えと解説を見る

正解：A. 成膜と同時にイオンによるスパッタで開口部の膜を削り、ボイドを抑えて埋め込めるため

通常のCVDで狭い溝を埋めると、開口部の角に膜が厚く付いて先にふさがり、中に空洞(ボイド)が残ることがあります。HDP-CVDでは、10¹¹ cm⁻³以上の高密度プラズマで成膜しながら、基板バイアスで引き込んだアルゴンなどのイオンで開口部の角の膜を斜めから削るため、底から順に埋め込めます。0.25〜65 nm世代のSTIや配線間の埋め込みに使われ、より狭い溝には流動性CVDなどが使われます。

成膜(CVD・PVD)のほかの問題

  1. シリコン窒化膜(Si3N4)の用途として正しいものはどれか。
  2. マグネトロンスパッタリングで、ターゲットの裏側に磁石を置く主な目的はどれか。
  3. CVDで段差被覆性(コンフォーマル性)がよくなる条件として正しいものはどれか。
  4. シランを熱分解してシリコン膜を堆積するとき、成膜温度を低くした場合にできる膜はどれか。
  5. ALDで成膜される代表的な材料の例として正しいものはどれか。

この分野の比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
