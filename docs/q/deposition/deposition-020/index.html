成膜(CVD・PVD)

成膜やエッチングの装置で、ウエハを静電気力で台に固定する機構はどれか。

  1. A真空ピンセット
  2. B静電チャック(ESC)
  3. CFOUP
答えと解説を見る

正解：B. 静電チャック(ESC)

静電チャックは、台の内部の電極に電圧をかけ、ウエハとの間にはたらく静電気力でウエハを吸着・固定します。真空中でも使え、ウエハ全面を均一に保持できるため、ウエハの温度制御もしやすくなります。
