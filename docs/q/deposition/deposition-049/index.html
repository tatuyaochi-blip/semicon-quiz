成膜(CVD・PVD)

反応性スパッタで、反応ガスの流量を増やしすぎたときに、ターゲットの表面が化合物で覆われて成膜速度が急に下がる現象を何と呼ぶか。

  1. Aターゲットの被毒(ポイズニング)
  2. Bブルーミング
  3. Cスティクション
答えと解説を見る

正解：A. ターゲットの被毒(ポイズニング)

反応性スパッタでは、反応ガスが増えるとターゲットの表面自体が窒化物や酸化物で覆われます。化合物は金属よりスパッタ収率が低いため、成膜速度が急に数分の1に下がります。これが被毒(ポイズニング)で、ガスを減らしても表面の化合物がすぐには除かれないため、ガス流量に対して成膜速度がヒステリシスを示します。プラズマの発光をモニターしてガスを制御し、遷移領域で安定させる方法などで対策します。

  • A. 正しい。ターゲットの表面が化合物で覆われる現象です。
  • B. ブルーミングはイメージセンサで電荷があふれる現象です。
  • C. スティクションはMEMSの可動部が張り付く現象です。

成膜(CVD・PVD)のほかの問題

  1. プラズマCVDのシリコン窒化膜の応力を、圧縮から引っ張りまで調整する方法として使われるものはどれか。
  2. スパッタリングによる成膜は、次のどれに分類されるか。
  3. ALD(原子層堆積)の特徴として正しいものはどれか。
  4. プラズマCVD(PECVD)の主な利点として正しいものはどれか。
  5. 成膜におけるステップカバレッジ(段差被覆性)の説明として正しいものはどれか。

この分野の比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
