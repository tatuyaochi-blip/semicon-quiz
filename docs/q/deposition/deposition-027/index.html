成膜(CVD・PVD)

同じ材料の膜で比べたとき、高温の熱CVD膜がプラズマCVD膜より一般に優れている点はどれか。

  1. A成膜温度が低い
  2. B成膜速度が必ず速い
  3. C膜が緻密で、水素などの不純物が少ない
答えと解説を見る

正解：C. 膜が緻密で、水素などの不純物が少ない

高温の熱CVDでは、原料が十分に反応して緻密な膜ができ、原料に由来する水素などの不純物も少なくなります。プラズマCVDは低温で成膜できる一方、水素を多く含み、膜が粗くなりやすい傾向があります。用途や工程の温度の制約に応じて使い分けます。
