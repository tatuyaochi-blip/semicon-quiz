成膜(CVD・PVD)

非常に狭く深い溝を、流動性のある膜で下から埋めてから固化させる成膜方法として正しいものはどれか。

  1. A真空蒸着
  2. B流動性CVD(FCVD)や塗布型絶縁膜(SOD)
  3. Cマグネトロンスパッタリング
答えと解説を見る

正解：B. 流動性CVD(FCVD)や塗布型絶縁膜(SOD)

流動性CVDは、液体のように流れる膜を低温で堆積させて溝の底から埋め、その後の処理で固化・改質して酸化膜にする方法です。塗布型絶縁膜(SOD)も同様に流動性を利用します。微細なSTIなど、通常のCVDではボイドが残りやすい溝の埋め込みに使われます。

成膜(CVD・PVD)のほかの問題

  1. スパッタリングで成膜速度を上げるために一般に行われることはどれか。
  2. 同じ材料の膜で比べたとき、高温の熱CVD膜がプラズマCVD膜より一般に優れている点はどれか。
  3. ALDの1サイクルで成膜される膜厚の目安として正しいものはどれか。
  4. 電子ビームで材料を加熱する真空蒸着の利点として正しいものはどれか。
  5. 表面の材料の違いを利用して、特定の場所だけに膜を成長させる技術はどれか。
