成膜(CVD・PVD)

減圧CVD(LPCVD)の特徴として正しいものはどれか。

  1. A減圧下で行うため膜厚の均一性がよく、多数のウエハを一度に処理できる
  2. B大気圧で行うため装置が最も簡単である
  3. Cプラズマを使うため室温で成膜できる
答えと解説を見る

正解：A. 減圧下で行うため膜厚の均一性がよく、多数のウエハを一度に処理できる

LPCVDは、数十〜数百Pa程度に減圧して行う熱CVDです。ガス分子が拡散しやすく表面反応が律速になるため、ウエハを立てて多数並べても均一な膜が得られます。ポリシリコン、シリコン窒化膜、酸化膜などの成膜に使われます。

成膜(CVD・PVD)のほかの問題

  1. LPCVDでポリシリコン膜を成膜するときに一般的に使われる原料ガスはどれか。
  2. 真空蒸着の説明として正しいものはどれか。
  3. 成膜した薄膜の内部応力が大きいときに起こりやすい問題はどれか。
  4. 液状の材料をウエハの中心に滴下し、高速で回転させて均一な膜をつくる方法を何と呼ぶか。
  5. シリコン酸化膜のCVDで原料として広く使われる、液体の有機シリコン化合物はどれか。
