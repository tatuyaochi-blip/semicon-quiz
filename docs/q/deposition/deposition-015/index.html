成膜(CVD・PVD)

マグネトロンスパッタリングで、ターゲットの裏側に磁石を置く主な目的はどれか。

  1. Aターゲットを冷却するため
  2. Bウエハを固定するため
  3. C磁場で電子をターゲット近くに閉じ込めてプラズマ密度を高め、成膜速度を上げるため
答えと解説を見る

正解：C. 磁場で電子をターゲット近くに閉じ込めてプラズマ密度を高め、成膜速度を上げるため

ターゲットの裏に磁石を置くと、ターゲット表面近くに磁場ができ、電子がらせん運動をしながらとどまるため、ガスの電離が促進されて高密度のプラズマができます。これにより、低い圧力でも高い成膜速度が得られます。現在のスパッタ装置の多くがこの方式です。

成膜(CVD・PVD)のほかの問題

  1. CVDで段差被覆性(コンフォーマル性)がよくなる条件として正しいものはどれか。
  2. シランを熱分解してシリコン膜を堆積するとき、成膜温度を低くした場合にできる膜はどれか。
  3. ALDで成膜される代表的な材料の例として正しいものはどれか。
  4. スパッタした原子をイオン化し、ウエハにかけたバイアスで垂直に引き込むスパッタ方式の主な目的はどれか。
  5. 成膜やエッチングの装置で、ウエハを静電気力で台に固定する機構はどれか。
