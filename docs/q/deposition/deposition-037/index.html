成膜(CVD・PVD)

狭い溝を成膜で埋めるとき、溝の入り口付近に膜が厚くつく(オーバーハング)と起こりやすい問題はどれか。

  1. A溝の中が膜で過剰に埋まる
  2. B膜が導体になる
  3. C入り口が先にふさがり、溝の中に空洞(ボイド)が残る
答えと解説を見る

正解：C. 入り口が先にふさがり、溝の中に空洞(ボイド)が残る

溝の入り口の角に膜が厚くつく(オーバーハング)と、底や側壁に膜が十分つく前に入り口が閉じ、中に空洞(ボイド)が残ります。ボイドは配線の抵抗の上昇や断線、後の工程での薬液のしみ込み、信頼性の低下の原因になります。段差被覆性のよい成膜方法を選ぶほか、成膜とエッチングを交互に繰り返して入り口を広げる(dep-etch-dep)、溝の形を上広がりにするなどの工夫をします。

  • A. 入り口がふさがるため、中はむしろ埋まりません。
  • B. 膜の電気的性質は変わりません。
  • C. 正しい。入り口が閉じて空洞が残ります。

成膜(CVD・PVD)のほかの問題

  1. スパッタ装置で、ターゲットとウエハの間に多数の穴をもつ板(コリメータ)を置く目的はどれか。
  2. スパッタリングや蒸着などのPVDで、深い溝の側壁や底に膜がつきにくい主な理由はどれか。
  3. LPCVDでポリシリコン膜を成膜しながら、リンなどの不純物を含むガスを同時に流して導電性の膜をつくることを何と呼ぶか。
  4. コンタクトホールをタングステンのCVDで埋め込む前に、TiN(窒化チタン)などの薄い膜を下地につける主な理由はどれか。
  5. 低温のCVDなどで成膜した酸化膜を、成膜後に高温で熱処理する「デンシファイ(緻密化)」の主な目的はどれか。
