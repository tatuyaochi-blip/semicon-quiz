成膜(CVD・PVD)

Cu配線の溝を埋め込むために主に用いられる成膜方法はどれか。

  1. A熱酸化
  2. B電解めっき
  3. Cイオン注入
答えと解説を見る

正解：B. 電解めっき

ダマシン法では、溝にバリア層とCuのシード層をスパッタリングで薄くつけたあと、電解めっきでCuを埋め込みます。めっき液に添加剤を加え、溝の底から優先的にCuを成長させることで、空洞(ボイド)なく埋め込めるようにしています。
