成膜(CVD・PVD)

真空蒸着と比べたときのスパッタリングの利点として正しいものはどれか。

  1. A成膜する原子のエネルギーが低い
  2. B必ず成膜速度が速い
  3. C合金や化合物のターゲットの組成を比較的保ったまま成膜でき、膜の密着性もよい
答えと解説を見る

正解：C. 合金や化合物のターゲットの組成を比較的保ったまま成膜でき、膜の密着性もよい

蒸着では合金の成分ごとに蒸気圧が違うため、蒸発しやすい成分から先に飛んで膜の組成がずれます。スパッタではターゲットの表面から原子を物理的にはじき出すため、表面の組成が落ち着けばターゲットとほぼ同じ組成で成膜できます。また、飛んでくる原子のエネルギーが数eV〜数十eVと蒸着(約0.1 eV)より高いため、膜が緻密で密着性もよく、大面積を均一に成膜しやすい利点があります。

  • A. スパッタの原子は蒸着よりエネルギーが高く、それが密着性のよさにつながります。
  • B. 成膜速度は材料や条件によっては蒸着の方が速いこともあります。
  • C. 正しい。組成を保ちやすく、密着性もよいのが利点です。

成膜(CVD・PVD)のほかの問題

  1. CVD装置の方式で、ウエハを置く台だけを加熱し、反応炉の壁は低温に保つ方式はどれか。
  2. HfO2のゲート絶縁膜をALDで成膜するときに使われる原料の組み合わせの例として正しいものはどれか。
  3. スパッタで成膜した金属膜が、成膜温度が低いと柱状の結晶粒とすき間の多い組織になりやすいことを、温度とガス圧で整理したモデルはどれか。
  4. CVDで、成膜する面積が大きいウエハやパターンほど原料が多く消費され、成膜速度が下がる現象を何と呼ぶか。
  5. 反応性スパッタで、反応ガスの流量を増やしすぎたときに、ターゲットの表面が化合物で覆われて成膜速度が急に下がる現象を何と呼ぶか。
