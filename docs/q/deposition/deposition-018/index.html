成膜(CVD・PVD)

ALDで成膜される代表的な材料の例として正しいものはどれか。

  1. A厚い銅配線
  2. Bフォトレジスト
  3. CHigh-k膜の酸化ハフニウムや窒化チタンなど
答えと解説を見る

正解：C. High-k膜の酸化ハフニウムや窒化チタンなど

ALDは原子層単位で膜厚を制御でき、段差被覆性に優れるため、High-kゲート絶縁膜の酸化ハフニウム、メタルゲートやバリア層の窒化チタン、DRAMキャパシタの酸化ジルコニウム、3D NANDの電荷トラップ層まわりの膜、マルチパターニングのスペーサーなど、薄く均一な膜が必要な用途で使われています。先端のロジックやメモリでは、成膜工程の中でALDの割合が増え続けています。

成膜(CVD・PVD)のほかの問題

  1. スパッタした原子をイオン化し、ウエハにかけたバイアスで垂直に引き込むスパッタ方式の主な目的はどれか。
  2. 成膜やエッチングの装置で、ウエハを静電気力で台に固定する機構はどれか。
  3. 熱CVDでシリコン窒化膜(Si3N4)を成膜するときに使われる原料ガスの組み合わせとして正しいものはどれか。
  4. チタンのターゲットを窒素を含むガス中でスパッタし、窒化チタン(TiN)膜を形成する方法を何と呼ぶか。
  5. プラズマを使うALD(PEALD)の利点として正しいものはどれか。

この分野の比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
