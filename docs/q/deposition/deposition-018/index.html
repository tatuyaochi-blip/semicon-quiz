成膜(CVD・PVD)

ALDで成膜される代表的な材料の例として正しいものはどれか。

  1. A厚い銅配線
  2. Bフォトレジスト
  3. CHigh-k膜の酸化ハフニウムや窒化チタンなど
答えと解説を見る

正解：C. High-k膜の酸化ハフニウムや窒化チタンなど

ALDは、原子層単位で膜厚を制御でき、段差被覆性に優れるため、High-kゲート絶縁膜の酸化ハフニウム、メタルゲートやバリア層の窒化チタン、DRAMキャパシタの誘電体膜など、薄く均一な膜が必要な用途で使われています。

成膜(CVD・PVD)のほかの問題

  1. スパッタした原子をイオン化し、ウエハにかけたバイアスで垂直に引き込むスパッタ方式の主な目的はどれか。
  2. 成膜やエッチングの装置で、ウエハを静電気力で台に固定する機構はどれか。
  3. 熱CVDでシリコン窒化膜(Si3N4)を成膜するときに使われる原料ガスの組み合わせとして正しいものはどれか。
  4. チタンのターゲットを窒素を含むガス中でスパッタし、窒化チタン(TiN)膜を形成する方法を何と呼ぶか。
  5. プラズマを使うALD(PEALD)の利点として正しいものはどれか。
