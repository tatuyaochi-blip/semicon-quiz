成膜(CVD・PVD)

熱CVDでシリコン窒化膜(Si3N4)を成膜するときに使われる原料ガスの組み合わせとして正しいものはどれか。

  1. Aジクロロシランとアンモニア
  2. Bシランと酸素
  3. C六フッ化タングステンと水素
答えと解説を見る

正解：A. ジクロロシランとアンモニア

LPCVDによるシリコン窒化膜は、ジクロロシラン(SiH2Cl2)とアンモニア(NH3)を700〜800 ℃程度で反応させてつくるのが一般的で(3SiH2Cl2 + 4NH3 → Si3N4 + 6HCl + 6H2)、化学量論に近い緻密な膜が得られます。アンモニアを過剰に流して組成を保ちます。低温が必要な場合はプラズマCVDやALDが使われます。シランと酸素は酸化膜、WF6と水素はタングステンの成膜に使われます。

成膜(CVD・PVD)のほかの問題

  1. チタンのターゲットを窒素を含むガス中でスパッタし、窒化チタン(TiN)膜を形成する方法を何と呼ぶか。
  2. プラズマを使うALD(PEALD)の利点として正しいものはどれか。
  3. CVD装置で、原料ガスをウエハの上から多数の小さな穴を通して均一に供給する部品はどれか。
  4. 非常に狭く深い溝を、流動性のある膜で下から埋めてから固化させる成膜方法として正しいものはどれか。
  5. スパッタリングで成膜速度を上げるために一般に行われることはどれか。

この分野の比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
  • LPCVDとPECVDの違い：温度・膜質・段差被覆性・応力・用途を比較減圧CVD(LPCVD)とプラズマCVD(PECVD)を、温度・膜質・水素の含有量・段差被覆性・膜の応力・処理の方式とスループット・用途の観点で表にして比較します。
