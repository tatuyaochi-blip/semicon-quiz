成膜(CVD・PVD)

熱CVDでシリコン窒化膜(Si3N4)を成膜するときに使われる原料ガスの組み合わせとして正しいものはどれか。

  1. Aジクロロシランとアンモニア
  2. Bシランと酸素
  3. C六フッ化タングステンと水素
答えと解説を見る

正解：A. ジクロロシランとアンモニア

LPCVDによるシリコン窒化膜は、ジクロロシラン(SiH2Cl2)とアンモニア(NH3)を700〜800 ℃程度で反応させてつくるのが一般的です。シランと酸素の組み合わせは酸化膜、WF6と水素はタングステンの成膜に使われます。

成膜(CVD・PVD)のほかの問題

  1. チタンのターゲットを窒素を含むガス中でスパッタし、窒化チタン(TiN)膜を形成する方法を何と呼ぶか。
  2. プラズマを使うALD(PEALD)の利点として正しいものはどれか。
  3. CVD装置で、原料ガスをウエハの上から多数の小さな穴を通して均一に供給する部品はどれか。
  4. 非常に狭く深い溝を、流動性のある膜で下から埋めてから固化させる成膜方法として正しいものはどれか。
  5. スパッタリングで成膜速度を上げるために一般に行われることはどれか。
