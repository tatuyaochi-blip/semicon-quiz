成膜(CVD・PVD)

LPCVDでポリシリコン膜を成膜しながら、リンなどの不純物を含むガスを同時に流して導電性の膜をつくることを何と呼ぶか。

  1. Aその場(in-situ)ドーピング
  2. Bイオン注入
  3. C熱酸化
答えと解説を見る

正解：A. その場(in-situ)ドーピング

成膜中にドーパントのガス(ホスフィン、ジボランなど)を一緒に流し、膜をつくると同時に不純物を取り込ませる方法をその場(in-situ)ドーピングといいます。後からイオン注入や拡散で不純物を入れる必要がなく、DRAMのキャパシタ電極のような深い溝や穴の中の膜にも均一に不純物を入れやすい利点があります。ただしドーパントのガスで成膜速度や均一性が変わるため、条件の調整が必要です。

  • A. 正しい。成膜と同時に不純物を取り込ませます。
  • B. イオン注入は成膜後に不純物を打ち込む方法です。
  • C. 熱酸化は酸化膜をつくる工程です。

成膜(CVD・PVD)のほかの問題

  1. コンタクトホールをタングステンのCVDで埋め込む前に、TiN(窒化チタン)などの薄い膜を下地につける主な理由はどれか。
  2. 低温のCVDなどで成膜した酸化膜を、成膜後に高温で熱処理する「デンシファイ(緻密化)」の主な目的はどれか。
  3. ALDで、表面の自己停止的な反応によって1サイクルあたりの膜厚が一定になる温度の範囲を何と呼ぶか。
  4. 真空蒸着と比べたときのスパッタリングの利点として正しいものはどれか。
  5. CVD装置の方式で、ウエハを置く台だけを加熱し、反応炉の壁は低温に保つ方式はどれか。

この分野の比較
