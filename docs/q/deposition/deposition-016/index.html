成膜(CVD・PVD)

CVDで段差被覆性(コンフォーマル性)がよくなる条件として正しいものはどれか。

  1. A表面反応律速となる条件(比較的低温・低圧など)
  2. B原料ガスの供給が律速となる条件
  3. C原料ガスを一方向から高速で吹き付ける条件
答えと解説を見る

正解：A. 表面反応律速となる条件(比較的低温・低圧など)

表面反応律速の条件では、原料ガスが溝の奥まで十分に行き渡ってから表面で反応するため、場所による成膜速度の差が小さくなり、段差の側壁や底にも均一に成膜できます。供給律速の条件では、ガスが届きやすい開口部ほど厚く付きやすくなります。

成膜(CVD・PVD)のほかの問題

  2. ALDで成膜される代表的な材料の例として正しいものはどれか。
  3. スパッタした原子をイオン化し、ウエハにかけたバイアスで垂直に引き込むスパッタ方式の主な目的はどれか。
  4. 成膜やエッチングの装置で、ウエハを静電気力で台に固定する機構はどれか。
  5. 熱CVDでシリコン窒化膜(Si3N4)を成膜するときに使われる原料ガスの組み合わせとして正しいものはどれか。
