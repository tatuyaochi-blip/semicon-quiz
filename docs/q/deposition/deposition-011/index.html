成膜(CVD・PVD)

シリコン酸化膜のCVDで原料として広く使われる、液体の有機シリコン化合物はどれか。

  1. A六フッ化タングステン(WF6)
  2. BTEOS(テトラエトキシシラン)
  3. Cトリメチルガリウム
答えと解説を見る

正解：B. TEOS(テトラエトキシシラン)

TEOSは常温で液体の有機シリコン化合物で、気化させてCVDの原料に使います。シランに比べて安全に扱いやすく、段差被覆性のよい酸化膜が得られるため、層間絶縁膜などの形成に広く使われています。

成膜(CVD・PVD)のほかの問題

  1. タングステンのCVDで原料として使われるガスはどれか。
  2. 高密度プラズマCVD(HDP-CVD)が、狭い溝の絶縁膜埋め込みに使われてきた理由として正しいものはどれか。
  3. シリコン窒化膜(Si3N4)の用途として正しいものはどれか。
  4. マグネトロンスパッタリングで、ターゲットの裏側に磁石を置く主な目的はどれか。
  5. CVDで段差被覆性(コンフォーマル性)がよくなる条件として正しいものはどれか。
