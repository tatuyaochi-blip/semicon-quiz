成膜(CVD・PVD)

タングステンのCVDで原料として使われるガスはどれか。

  1. ATEOS
  2. Bシラン(SiH4)
  3. C六フッ化タングステン(WF6)
答えと解説を見る

正解：C. 六フッ化タングステン(WF6)

タングステンのCVDでは、WF6を水素で還元して(WF6 + 3H2 → W + 6HF)タングステン膜を堆積させ、初期の核づけにはシランなどを使います。段差被覆性がよく、直径数十nmの細いコンタクトホールも埋め込めるうえ、融点が高く電流による劣化にも強いため、トランジスタと配線をつなぐコンタクトプラグや、3D NANDのワード線の形成に使われています。

成膜(CVD・PVD)のほかの問題

  1. 高密度プラズマCVD(HDP-CVD)が、狭い溝の絶縁膜埋め込みに使われてきた理由として正しいものはどれか。
  2. シリコン窒化膜(Si3N4)の用途として正しいものはどれか。
  3. マグネトロンスパッタリングで、ターゲットの裏側に磁石を置く主な目的はどれか。
  4. CVDで段差被覆性(コンフォーマル性)がよくなる条件として正しいものはどれか。
  5. シランを熱分解してシリコン膜を堆積するとき、成膜温度を低くした場合にできる膜はどれか。
