成膜(CVD・PVD)

LSIの製造工程の基本的な組み立て方として正しいものはどれか。

  1. A部品を接着剤で貼り合わせてつくる
  2. B成膜・リソグラフィ・エッチングなどの工程を何十回も繰り返して層を重ねていく
  3. Cウエハを一度だけ加工して完成させる
答えと解説を見る

正解：B. 成膜・リソグラフィ・エッチングなどの工程を何十回も繰り返して層を重ねていく

LSIは、膜をつける(成膜)、パターンを写す(リソグラフィ)、不要な部分を削る(エッチング)、不純物を入れる、洗浄する、といった工程を何十回、何百回と繰り返して、トランジスタと何層もの配線を積み重ねてつくります。

  • A. LSIの内部は貼り合わせではなく、工程の繰り返しでつくります。
  • B. 正しい。工程を繰り返して層を重ねます。
  • C. 一度の加工ではつくれません。

  4. プラズマCVDで成膜したシリコン窒化膜の特徴として正しいものはどれか。
