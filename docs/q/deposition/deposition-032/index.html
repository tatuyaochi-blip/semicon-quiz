成膜(CVD・PVD)

LSIの製造工程の基本的な組み立て方として正しいものはどれか。

  1. A部品を接着剤で貼り合わせてつくる
  2. B成膜・リソグラフィ・エッチングなどの工程を何十回も繰り返して層を重ねていく
  3. Cウエハを一度だけ加工して完成させる
答えと解説を見る

正解：B. 成膜・リソグラフィ・エッチングなどの工程を何十回も繰り返して層を重ねていく

LSIは、膜をつける(成膜)、パターンを写す(リソグラフィ)、不要な部分を削る(エッチング)、不純物を入れる、平坦化する、洗浄する、といった工程を繰り返し、トランジスタと十数層の配線を積み重ねてつくります。先端ロジックでは工程数が1000を超え、ウエハ投入から完成まで3か月前後かかります。この繰り返しの各段階で検査・計測も行われます。

  • A. LSIの内部は貼り合わせではなく、工程の繰り返しでつくります。
  • B. 正しい。工程を繰り返して層を重ねます。
  • C. 一度の加工ではつくれません。

成膜(CVD・PVD)のほかの問題

  1. 多くの成膜を真空の装置の中で行う主な理由はどれか。
  2. アルミニウム配線の膜をつくるのに主に使われてきた成膜方法はどれか。
  3. スパッタリングの「スパッタ収率」の意味として正しいものはどれか。
  4. プラズマCVDで成膜したシリコン窒化膜の特徴として正しいものはどれか。
  5. 狭い溝を成膜で埋めるとき、溝の入り口付近に膜が厚くつく(オーバーハング)と起こりやすい問題はどれか。

この分野の比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
