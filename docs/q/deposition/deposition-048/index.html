成膜(CVD・PVD)

CVDで、成膜する面積が大きいウエハやパターンほど原料が多く消費され、成膜速度が下がる現象を何と呼ぶか。

  1. Aエレクトロマイグレーション
  2. Bローディング効果
  3. Cチャネリング
答えと解説を見る

正解：B. ローディング効果

CVDでは、反応する表面の面積が大きいと原料ガスの消費が増え、ガスの供給が追いつかない場所では成膜速度が下がります。ウエハの枚数や露出しているパターンの面積によって成膜速度が変わるこの現象をローディング効果といい、膜厚の均一性に影響します。

  • A. エレクトロマイグレーションは電流による配線の金属原子の移動です。
  • B. 正しい。原料の消費による成膜速度の低下です。
  • C. チャネリングはイオン注入で結晶のすき間を深く進む現象です。
