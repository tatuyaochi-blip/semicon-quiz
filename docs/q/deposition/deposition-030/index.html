成膜(CVD・PVD)

表面の材料の違いを利用して、特定の場所だけに膜を成長させる技術はどれか。

  1. Aスパッタリング
  2. B全面成膜
  3. C領域選択成膜(エリアセレクティブデポジション)
答えと解説を見る

正解：C. 領域選択成膜(エリアセレクティブデポジション)

領域選択成膜は、金属の上には成膜し絶縁膜の上には成膜しない、といったように、下地の材料による反応のしやすさの違いを利用して必要な場所だけに膜をつくる技術です。成膜させたくない面を自己組織化単分子膜(SAM)などで覆って反応を防ぐ方法もあります。リソグラフィやエッチングの工程を減らせ、位置合わせのずれもないため、微細な配線などへの応用が研究されています。

この分野の比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
  • LPCVDとPECVDの違い：温度・膜質・段差被覆性・応力・用途を比較減圧CVD(LPCVD)とプラズマCVD(PECVD)を、温度・膜質・水素の含有量・段差被覆性・膜の応力・処理の方式とスループット・用途の観点で表にして比較します。
