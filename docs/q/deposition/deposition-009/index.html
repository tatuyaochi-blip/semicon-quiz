成膜(CVD・PVD)

成膜した薄膜の内部応力が大きいときに起こりやすい問題はどれか。

  1. Aウエハの反りや、膜の剥がれ・クラック
  2. B膜の色が変わるだけで特に問題はない
  3. C膜の電気抵抗が0になる
答えと解説を見る

正解：A. ウエハの反りや、膜の剥がれ・クラック

薄膜には、成膜条件や基板との熱膨張係数の差によって引っ張り応力や圧縮応力が残ります。応力が大きいとウエハが反って露光の焦点が合わなくなったり、膜が剥がれたり割れたりします。一方で、応力をあえて利用してチャネルにひずみを加える技術もあります。

成膜(CVD・PVD)のほかの問題

  1. 液状の材料をウエハの中心に滴下し、高速で回転させて均一な膜をつくる方法を何と呼ぶか。
  2. シリコン酸化膜のCVDで原料として広く使われる、液体の有機シリコン化合物はどれか。
  3. タングステンのCVDで原料として使われるガスはどれか。
  4. 高密度プラズマCVD(HDP-CVD)が、狭い溝の絶縁膜埋め込みに使われてきた理由として正しいものはどれか。
  5. シリコン窒化膜(Si3N4)の用途として正しいものはどれか。
