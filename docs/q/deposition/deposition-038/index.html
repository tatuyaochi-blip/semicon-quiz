成膜(CVD・PVD)

スパッタ装置で、ターゲットとウエハの間に多数の穴をもつ板(コリメータ)を置く目的はどれか。

  1. A斜めに飛ぶ原子をさえぎって垂直に近い原子だけを通し、穴の底まで膜をつけやすくするため
  2. B成膜速度を上げるため
  3. Cウエハを冷やすため
答えと解説を見る

正解：A. 斜めに飛ぶ原子をさえぎって垂直に近い原子だけを通し、穴の底まで膜をつけやすくするため

コリメータは、蜂の巣のように穴の開いた板(穴の長さと径の比が1〜2程度)で、斜めに飛んでくるスパッタ原子をさえぎり、ウエハにほぼ垂直に向かう原子だけを通します。これで深い穴の底への膜の付き方(ボトムカバレッジ)が改善されます。ただしコリメータにも膜が付くため成膜速度が下がり、付いた膜がはがれてパーティクルになる問題もあり、現在はイオン化スパッタが主流です。

  • A. 正しい。垂直に近い原子だけを通します。
  • B. 原子の一部をさえぎるので、成膜速度はむしろ下がります。
  • C. ウエハの冷却が目的ではありません。

成膜(CVD・PVD)のほかの問題

  1. スパッタリングや蒸着などのPVDで、深い溝の側壁や底に膜がつきにくい主な理由はどれか。
  2. LPCVDでポリシリコン膜を成膜しながら、リンなどの不純物を含むガスを同時に流して導電性の膜をつくることを何と呼ぶか。
  3. コンタクトホールをタングステンのCVDで埋め込む前に、TiN(窒化チタン)などの薄い膜を下地につける主な理由はどれか。
  4. 低温のCVDなどで成膜した酸化膜を、成膜後に高温で熱処理する「デンシファイ(緻密化)」の主な目的はどれか。
  5. ALDで、表面の自己停止的な反応によって1サイクルあたりの膜厚が一定になる温度の範囲を何と呼ぶか。
