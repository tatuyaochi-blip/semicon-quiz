成膜(CVD・PVD)

スパッタした原子をイオン化し、ウエハにかけたバイアスで垂直に引き込むスパッタ方式の主な目的はどれか。

  1. A深い穴や溝の底部への膜の付き回り(ボトムカバレッジ)を改善する
  2. B成膜速度を遅くする
  3. C膜の色を変える
答えと解説を見る

正解：A. 深い穴や溝の底部への膜の付き回り(ボトムカバレッジ)を改善する

通常のスパッタでは原子がさまざまな方向から飛んでくるため、深い穴の底には膜が付きにくくなります。スパッタされた原子をプラズマ中でイオン化し、ウエハのバイアスで垂直に引き込むと、穴の底まで膜を付けやすくなります。バリア層やシード層の形成に使われます。

成膜(CVD・PVD)のほかの問題

  1. 成膜やエッチングの装置で、ウエハを静電気力で台に固定する機構はどれか。
  2. 熱CVDでシリコン窒化膜(Si3N4)を成膜するときに使われる原料ガスの組み合わせとして正しいものはどれか。
  3. チタンのターゲットを窒素を含むガス中でスパッタし、窒化チタン(TiN)膜を形成する方法を何と呼ぶか。
  4. プラズマを使うALD(PEALD)の利点として正しいものはどれか。
  5. CVD装置で、原料ガスをウエハの上から多数の小さな穴を通して均一に供給する部品はどれか。
