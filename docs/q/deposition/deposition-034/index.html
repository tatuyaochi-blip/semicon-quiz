成膜(CVD・PVD)

アルミニウム配線の膜をつくるのに主に使われてきた成膜方法はどれか。

  1. Aイオン注入
  2. Bスパッタリング
  3. C熱酸化
答えと解説を見る

正解：B. スパッタリング

アルミニウム配線は、銅を0.5%程度、かつてはシリコンも含む合金のターゲットをアルゴンイオンでたたき、はじき出された原子をウエハに堆積させるスパッタで成膜されてきました。銅はエレクトロマイグレーションへの耐性を上げ、シリコンは下地のシリコンとの反応(スパイク)を防ぐためです。その後パターンを描いてドライエッチングし配線にします。0.13 µm世代以降、主な配線は銅に置き換わりました。

  • A. イオン注入は不純物を打ち込む工程です。
  • B. 正しい。アルミ配線はスパッタリングで成膜されてきました。
  • C. 熱酸化はシリコンの酸化膜をつくる工程です。

成膜(CVD・PVD)のほかの問題

  1. スパッタリングの「スパッタ収率」の意味として正しいものはどれか。
  2. プラズマCVDで成膜したシリコン窒化膜の特徴として正しいものはどれか。
  3. 狭い溝を成膜で埋めるとき、溝の入り口付近に膜が厚くつく(オーバーハング)と起こりやすい問題はどれか。
  4. スパッタ装置で、ターゲットとウエハの間に多数の穴をもつ板(コリメータ)を置く目的はどれか。
  5. スパッタリングや蒸着などのPVDで、深い溝の側壁や底に膜がつきにくい主な理由はどれか。

この分野の比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
