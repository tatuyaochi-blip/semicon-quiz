成膜(CVD・PVD)

スパッタリングで成膜速度を上げるために一般に行われることはどれか。

  1. Aターゲットに投入する電力を大きくする
  2. Bガスの圧力を極端に高くする
  3. Cターゲットへの電力を0にする
答えと解説を見る

正解：A. ターゲットに投入する電力を大きくする

ターゲットに投入する電力を大きくすると、ターゲットに衝突するイオンの数とエネルギーが増え、はじき出される原子が増えるため、成膜速度はほぼ電力に比例して上がります。300 mm用のターゲットでは数十kWの電力をかけることもあります。ただし投入した電力の大部分は熱になるため、ターゲットを水冷して温度上昇や割れ、ボンディング層の溶融を防ぎ、膜の品質への影響にも注意します。

成膜(CVD・PVD)のほかの問題

  1. 同じ材料の膜で比べたとき、高温の熱CVD膜がプラズマCVD膜より一般に優れている点はどれか。
  2. ALDの1サイクルで成膜される膜厚の目安として正しいものはどれか。
  3. 電子ビームで材料を加熱する真空蒸着の利点として正しいものはどれか。
  4. 表面の材料の違いを利用して、特定の場所だけに膜を成長させる技術はどれか。
  5. 半導体の製造で扱う薄膜の厚さの目安として最も適切なものはどれか。

この分野の比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
