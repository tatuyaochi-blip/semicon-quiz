成膜(CVD・PVD)

スパッタリングで成膜速度を上げるために一般に行われることはどれか。

  1. Aターゲットに投入する電力を大きくする
  2. Bガスの圧力を極端に高くする
  3. Cターゲットへの電力を0にする
答えと解説を見る

正解：A. ターゲットに投入する電力を大きくする

ターゲットに投入する電力を大きくすると、ターゲットに衝突するイオンの数とエネルギーが増え、はじき出される原子が増えるため、成膜速度が上がります。ただし、ターゲットの温度上昇や割れ、膜の品質への影響に注意が必要です。
