成膜(CVD・PVD)

液状の材料をウエハの中心に滴下し、高速で回転させて均一な膜をつくる方法を何と呼ぶか。

  1. Aスパッタリング
  2. Bスピンコート
  3. Cイオン注入
答えと解説を見る

正解：B. スピンコート

スピンコートでは、遠心力で液を広げ、余分な液を振り切って均一な膜をつくります。膜厚は回転数と液の粘度で調整します。フォトレジストの塗布や、塗布型の絶縁膜(SOG)の形成などに使われます。

  1. シリコン酸化膜のCVDで原料として広く使われる、液体の有機シリコン化合物はどれか。
  2. タングステンのCVDで原料として使われるガスはどれか。
  3. 高密度プラズマCVD(HDP-CVD)が、狭い溝の絶縁膜埋め込みに使われてきた理由として正しいものはどれか。
  4. シリコン窒化膜(Si3N4)の用途として正しいものはどれか。
  5. マグネトロンスパッタリングで、ターゲットの裏側に磁石を置く主な目的はどれか。
