成膜(CVD・PVD)

スパッタリングの「スパッタ収率」の意味として正しいものはどれか。

  1. Aウエハ1枚あたりの良品の割合
  2. Bターゲットに入射したイオン1個あたりに、はじき出される原子の数
  3. C成膜にかかる時間
答えと解説を見る

正解：B. ターゲットに入射したイオン1個あたりに、はじき出される原子の数

スパッタ収率は、ターゲットに衝突したイオン1個あたりに、何個の原子がはじき出されるかを表します。イオンのエネルギーや質量、入射角、ターゲットの材料によって変わり、成膜速度を決める要素の一つです。

  • A. 良品の割合は歩留まりです。
  • B. 正しい。イオン1個あたりのはじき出される原子数です。
  • C. 時間ではありません。

成膜(CVD・PVD)のほかの問題

  1. プラズマCVDで成膜したシリコン窒化膜の特徴として正しいものはどれか。
  2. 狭い溝を成膜で埋めるとき、溝の入り口付近に膜が厚くつく(オーバーハング)と起こりやすい問題はどれか。
  3. スパッタ装置で、ターゲットとウエハの間に多数の穴をもつ板(コリメータ)を置く目的はどれか。
  4. スパッタリングや蒸着などのPVDで、深い溝の側壁や底に膜がつきにくい主な理由はどれか。
  5. LPCVDでポリシリコン膜を成膜しながら、リンなどの不純物を含むガスを同時に流して導電性の膜をつくることを何と呼ぶか。
