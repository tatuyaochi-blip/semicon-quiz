成膜(CVD・PVD)

ALDの1サイクルで成膜される膜厚の目安として正しいものはどれか。

  1. A約1 µm
  2. B約0.1 nm(1原子層程度以下)
  3. C約100 nm
答えと解説を見る

正解：B. 約0.1 nm(1原子層程度以下)

ALDでは、1サイクルで成膜されるのは1原子層程度以下、およそ0.1 nm前後で、原料分子が大きいと表面を覆い尽くせず1層に満たないこともあります。1サイクルに数秒〜数十秒かかるため、数nmの膜でも数十サイクル・数分〜数十分が必要です。速度を補うため、複数のウエハを同時に処理するバッチ式や、ウエハを回転させてガスの領域を通過させる空間分割型のALDも使われます。

成膜(CVD・PVD)のほかの問題

  1. 電子ビームで材料を加熱する真空蒸着の利点として正しいものはどれか。
  2. 表面の材料の違いを利用して、特定の場所だけに膜を成長させる技術はどれか。
  3. 半導体の製造で扱う薄膜の厚さの目安として最も適切なものはどれか。
  4. LSIの製造工程の基本的な組み立て方として正しいものはどれか。
  5. 多くの成膜を真空の装置の中で行う主な理由はどれか。
