成膜(CVD・PVD)

ALDの1サイクルで成膜される膜厚の目安として正しいものはどれか。

  1. A約1 µm
  2. B約0.1 nm(1原子層程度以下)
  3. C約100 nm
答えと解説を見る

正解：B. 約0.1 nm(1原子層程度以下)

ALDでは、1サイクルで成膜されるのは1原子層程度以下、およそ0.1 nm前後です。そのため、数nmの膜でも数十サイクルが必要になり、成膜速度は遅くなります。その代わり、サイクル数で膜厚を精密に制御できます。

  3. 半導体の製造で扱う薄膜の厚さの目安として最も適切なものはどれか。
  4. LSIの製造工程の基本的な組み立て方として正しいものはどれか。
  5. 多くの成膜を真空の装置の中で行う主な理由はどれか。
