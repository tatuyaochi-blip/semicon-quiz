成膜(CVD・PVD)

ALD(原子層堆積)の特徴として正しいものはどれか。

  1. A1回の処理で数µmの膜を高速に堆積できる
  2. B前駆体の自己制限的な表面反応を繰り返し、原子層レベルで膜厚を制御できる
  3. C真空を必要としない印刷技術である
答えと解説を見る

正解：B. 前駆体の自己制限的な表面反応を繰り返し、原子層レベルで膜厚を制御できる

ALDでは、原料ガスを供給して表面に1層分だけ吸着させ、パージしたあと反応ガスを供給して反応させる、というサイクルを繰り返します。表面反応が1層で止まる(自己制限的)ため、膜厚を精密に制御でき、深い溝の中にも均一に成膜できます。そのかわり成膜速度は遅くなります。
