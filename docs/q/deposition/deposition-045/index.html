成膜(CVD・PVD)

CVD装置の方式で、ウエハを置く台だけを加熱し、反応炉の壁は低温に保つ方式はどれか。

  1. Aコールドウォール型
  2. B大気開放型
  3. Cホットウォール型
答えと解説を見る

正解：A. コールドウォール型

コールドウォール型は、ウエハ(またはサセプタ)だけをランプやヒーターで加熱し、壁は冷やしておくため、壁への膜の堆積やそこからのパーティクルが少なく、ガスの切り替えも速くできます。枚葉式のエピ装置や金属CVDで使われます。一方、炉全体を加熱するホットウォール型は、温度が均一で多数のウエハを一度に処理しやすく、LPCVDのバッチ炉で使われますが、壁にも膜が付くため定期的な清掃が必要です。

  • A. 正しい。ウエハ側だけを加熱する方式です。
  • B. CVDは通常、雰囲気を管理した反応炉の中で行います。
  • C. ホットウォール型は炉全体を加熱する方式です。

成膜(CVD・PVD)のほかの問題

  1. HfO2のゲート絶縁膜をALDで成膜するときに使われる原料の組み合わせの例として正しいものはどれか。
  2. スパッタで成膜した金属膜が、成膜温度が低いと柱状の結晶粒とすき間の多い組織になりやすいことを、温度とガス圧で整理したモデルはどれか。
  3. CVDで、成膜する面積が大きいウエハやパターンほど原料が多く消費され、成膜速度が下がる現象を何と呼ぶか。
  4. 反応性スパッタで、反応ガスの流量を増やしすぎたときに、ターゲットの表面が化合物で覆われて成膜速度が急に下がる現象を何と呼ぶか。
  5. プラズマCVDのシリコン窒化膜の応力を、圧縮から引っ張りまで調整する方法として使われるものはどれか。
