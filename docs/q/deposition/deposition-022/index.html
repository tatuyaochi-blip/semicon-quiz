成膜(CVD・PVD)

チタンのターゲットを窒素を含むガス中でスパッタし、窒化チタン(TiN)膜を形成する方法を何と呼ぶか。

  1. A真空蒸着
  2. B反応性スパッタリング
  3. Cイオン注入
答えと解説を見る

正解：B. 反応性スパッタリング

反応性スパッタリングは、アルゴンに窒素や酸素などの反応性ガスを加えてスパッタし、金属とガスを反応させて窒化物や酸化物の膜をつくる方法です。化合物のターゲットは割れやすく電気を通しにくいものもあるため、扱いやすい金属ターゲットから化合物の膜を得られる利点があり、ガスの流量で組成を調整できます。TiNはバリア層、ハードマスク、メタルゲートの仕事関数調整などに使われます。

成膜(CVD・PVD)のほかの問題

  1. プラズマを使うALD(PEALD)の利点として正しいものはどれか。
  2. CVD装置で、原料ガスをウエハの上から多数の小さな穴を通して均一に供給する部品はどれか。
  3. 非常に狭く深い溝を、流動性のある膜で下から埋めてから固化させる成膜方法として正しいものはどれか。
  4. スパッタリングで成膜速度を上げるために一般に行われることはどれか。
  5. 同じ材料の膜で比べたとき、高温の熱CVD膜がプラズマCVD膜より一般に優れている点はどれか。

この分野の比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
  • LPCVDとPECVDの違い：温度・膜質・段差被覆性・応力・用途を比較減圧CVD(LPCVD)とプラズマCVD(PECVD)を、温度・膜質・水素の含有量・段差被覆性・膜の応力・処理の方式とスループット・用途の観点で表にして比較します。
