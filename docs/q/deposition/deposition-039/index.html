成膜(CVD・PVD)

スパッタリングや蒸着などのPVDで、深い溝の側壁や底に膜がつきにくい主な理由はどれか。

  1. APVDでは原子が溝を避けるように動くため
  2. B原子がほぼまっすぐ飛んでくるため、溝の入り口から見通せない部分には届きにくいため
  3. CPVDでは膜が液体になるため
答えと解説を見る

正解：B. 原子がほぼまっすぐ飛んでくるため、溝の入り口から見通せない部分には届きにくいため

PVDでは、ターゲットや蒸発源から飛び出した原子がほぼ直進して基板に付着します。そのため、溝の上面や入り口には膜がつきやすい一方、溝の側壁や底のように見通しの悪い部分には届きにくくなります。表面での化学反応で成膜するCVDやALDの方が、段差被覆性はよくなります。

  • A. 原子が溝を避けて動くわけではありません。
  • B. 正しい。直進するため見通せない部分に届きにくいのです。
  • C. PVDの膜は液体にはなりません。
この分野を解く 分野ページへ

成膜(CVD・PVD)のほかの問題

  1. LPCVDでポリシリコン膜を成膜しながら、リンなどの不純物を含むガスを同時に流して導電性の膜をつくることを何と呼ぶか。
  2. コンタクトホールをタングステンのCVDで埋め込む前に、TiN(窒化チタン)などの薄い膜を下地につける主な理由はどれか。
  3. 低温のCVDなどで成膜した酸化膜を、成膜後に高温で熱処理する「デンシファイ(緻密化)」の主な目的はどれか。
  4. ALDで、表面の自己停止的な反応によって1サイクルあたりの膜厚が一定になる温度の範囲を何と呼ぶか。
  5. 真空蒸着と比べたときのスパッタリングの利点として正しいものはどれか。
