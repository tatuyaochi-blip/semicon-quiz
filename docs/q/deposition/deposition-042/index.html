成膜(CVD・PVD)

低温のCVDなどで成膜した酸化膜を、成膜後に高温で熱処理する「デンシファイ(緻密化)」の主な目的はどれか。

  1. A膜を厚くするため
  2. B膜を導体にするため
  3. C膜を緻密にして水分などを追い出し、エッチング速度や電気的特性を熱酸化膜に近づけるため
答えと解説を見る

正解：C. 膜を緻密にして水分などを追い出し、エッチング速度や電気的特性を熱酸化膜に近づけるため

低温で成膜した酸化膜は、すき間が多く水分や水素などを含むため、エッチングが速く、絶縁性も劣りがちです。高温で熱処理すると膜が締まって緻密になり、含まれた不純物が抜けて、膜質が熱酸化膜に近づきます。

  • A. 熱処理で膜は締まり、むしろ少し薄くなります。
  • B. 絶縁膜が導体になるわけではありません。
  • C. 正しい。緻密にして膜質を改善します。
