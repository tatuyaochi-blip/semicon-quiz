成膜(CVD・PVD)

スパッタで成膜した金属膜が、成膜温度が低いと柱状の結晶粒とすき間の多い組織になりやすいことを、温度とガス圧で整理したモデルはどれか。

  1. ADeal-Groveモデル
  2. Bソーントンの構造ゾーンモデル
  3. Cポアソンモデル
答えと解説を見る

正解：B. ソーントンの構造ゾーンモデル

ソーントンの構造ゾーンモデルは、基板温度(材料の融点との比)とスパッタのガス圧によって、膜の組織が、すき間の多い柱状組織から、緻密な繊維状組織、大きな柱状結晶、再結晶した等軸結晶へと変わることを整理したものです。膜の密度や応力、抵抗率を考えるときの目安になります。

  • A. Deal-Groveモデルは熱酸化の成長モデルです。
  • B. 正しい。温度とガス圧で膜の組織を整理したモデルです。
  • C. ポアソンモデルは歩留まりの計算などに使われるモデルです。
