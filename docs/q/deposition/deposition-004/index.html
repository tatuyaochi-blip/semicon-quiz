成膜(CVD・PVD)

成膜におけるステップカバレッジ(段差被覆性)の説明として正しいものはどれか。

  1. A段差の側壁や底部に、平坦部と比べてどの程度の厚さで膜が付くかを表す
  2. B膜の電気抵抗を表す
  3. C1分あたりの成膜速度を表す
答えと解説を見る

正解：A. 段差の側壁や底部に、平坦部と比べてどの程度の厚さで膜が付くかを表す

ステップカバレッジは、溝や穴などの段差の側壁や底に、平坦部と比べてどれだけ膜が付くかを、例えば「底の膜厚 ÷ 上面の膜厚」の百分率で表します。一般にスパッタなどのPVDは直進する原子のため低く(深い穴の底では10%以下も)、CVDは表面反応で回り込むため高く、ALDはほぼ100%です。微細な穴に薄く均一な膜が必要なバリア層やゲート膜では、この指標が成膜方法の選択を左右します。

  3. LPCVDでポリシリコン膜を成膜するときに一般的に使われる原料ガスはどれか。
  4. 真空蒸着の説明として正しいものはどれか。
  5. 成膜した薄膜の内部応力が大きいときに起こりやすい問題はどれか。
