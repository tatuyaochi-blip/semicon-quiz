成膜(CVD・PVD)

成膜におけるステップカバレッジ(段差被覆性)の説明として正しいものはどれか。

  1. A段差の側壁や底部に、平坦部と比べてどの程度の厚さで膜が付くかを表す
  2. B膜の電気抵抗を表す
  3. C1分あたりの成膜速度を表す
答えと解説を見る

正解：A. 段差の側壁や底部に、平坦部と比べてどの程度の厚さで膜が付くかを表す

ステップカバレッジは、溝や穴などの段差の側壁や底に、平坦部と比べてどれだけ膜が付くかを表す指標です。一般にスパッタリングなどのPVDは段差被覆性が低く、CVD、さらにALDほど段差の内部まで均一に成膜できます。
