成膜(CVD・PVD)

ALDで、表面の自己停止的な反応によって1サイクルあたりの膜厚が一定になる温度の範囲を何と呼ぶか。

  1. Aガラス転移点
  2. BALDウィンドウ
  3. Cプロセスマージン
答えと解説を見る

正解：B. ALDウィンドウ

ALDでは、温度が低すぎると原料が凝縮したり反応が不十分になり、高すぎると原料が熱分解してCVDのような成長になったり、吸着した分子が脱離したりします。その間の、1サイクルあたりの膜厚がほぼ一定になる温度範囲をALDウィンドウと呼び、この範囲で成膜します。

  • A. ガラス転移点は、ガラスやポリマーが軟らかくなり始める温度です。
  • B. 正しい。成長が自己停止的になる温度範囲です。
  • C. プロセスマージンは工程条件の余裕全般を指す言葉です。

成膜(CVD・PVD)のほかの問題

  1. 真空蒸着と比べたときのスパッタリングの利点として正しいものはどれか。
  2. CVD装置の方式で、ウエハを置く台だけを加熱し、反応炉の壁は低温に保つ方式はどれか。
  3. HfO2のゲート絶縁膜をALDで成膜するときに使われる原料の組み合わせの例として正しいものはどれか。
  4. スパッタで成膜した金属膜が、成膜温度が低いと柱状の結晶粒とすき間の多い組織になりやすいことを、温度とガス圧で整理したモデルはどれか。
  5. CVDで、成膜する面積が大きいウエハやパターンほど原料が多く消費され、成膜速度が下がる現象を何と呼ぶか。
