成膜(CVD・PVD)

スパッタリングによる成膜は、次のどれに分類されるか。

  1. APVD(物理気相成長)
  2. BCVD(化学気相成長)
  3. C熱酸化
答えと解説を見る

正解：A. PVD(物理気相成長)

スパッタリングは、アルゴンなどのプラズマ中のイオンを数百Vで加速してターゲットに衝突させ、運動量を受け取ってはじき出された原子をウエハに堆積させる方法で、化学反応を使わない物理的な現象なのでPVD(物理気相成長)に分類されます。金属配線、バリアメタル(Ta、TiNなど)、Cuのシード層、電極などの成膜に使われます。CVDは原料ガスの化学反応、熱酸化はシリコン自体の酸化です。

成膜(CVD・PVD)のほかの問題

  1. ALD(原子層堆積)の特徴として正しいものはどれか。
  2. プラズマCVD(PECVD)の主な利点として正しいものはどれか。
  3. 成膜におけるステップカバレッジ(段差被覆性)の説明として正しいものはどれか。
  4. Cu配線の溝を埋め込むために主に用いられる成膜方法はどれか。
  5. 減圧CVD(LPCVD)の特徴として正しいものはどれか。

この分野の比較

  • CVDとPVDの違い：薄膜の成膜方法を比較CVDとPVDを、原理・主な材料・ステップカバレッジ・温度・純度・環境・危険性・チップ製造での用途の観点で表にして比較します。
  • ALDとCVDの違い：原子層堆積を比較ALDとCVDを、仕組み・膜厚の制御・被覆性・速度・温度・均一性・先端チップでの用途の観点で表にして比較します。
  • LPCVDとPECVDの違い：温度・膜質・段差被覆性・応力・用途を比較減圧CVD(LPCVD)とプラズマCVD(PECVD)を、温度・膜質・水素の含有量・段差被覆性・膜の応力・処理の方式とスループット・用途の観点で表にして比較します。
