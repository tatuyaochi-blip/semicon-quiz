イオン注入

アモルファス化した層を再結晶させたとき、元のアモルファス層と結晶の境界より少し深い位置に残る欠陥を何と呼ぶか。

  1. AEOR(End of Range)欠陥
  2. BCOP
  3. COSF
答えと解説を見る

正解：A. EOR(End of Range)欠陥

アモルファス化した層の下の結晶側には、過剰な格子間シリコンが集まっています。アニールで再結晶させても、この位置に転位ループなどの欠陥が残ることがあり、EOR欠陥と呼ばれます。接合の近くに残るとリーク電流の原因になるため、注入とアニールの条件で制御します。

  4. LSIの製造で使われるイオン注入のドーズ量の範囲として最も近いものはどれか。
  5. イオン注入装置のビームの通り道を高い真空にする主な理由はどれか。
