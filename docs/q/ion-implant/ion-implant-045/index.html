イオン注入

減速モード(高いエネルギーで運んでからウエハの手前で減速する方式)の低エネルギー注入で注意が必要な「エネルギーコンタミネーション」の原因はどれか。

  1. A減速する前に中性化したイオンが減速されずに、高いエネルギーのままウエハに届くこと
  2. Bウエハの温度が低すぎること
  3. C質量分析磁石が強すぎること
答えと解説を見る

正解：A. 減速する前に中性化したイオンが減速されずに、高いエネルギーのままウエハに届くこと

減速モードでは、ビームを数十keVの高いエネルギーで運んでから、ウエハの直前で減速して数百eV〜数keVで注入します。低エネルギーのビームは空間電荷で広がりやすいため、高い電流を得るための方法です。しかし途中で残留ガスとの衝突で中性化した粒子は電界で減速されず、高いエネルギーのまま届いて狙いより深く入ります。数%の混入でも浅い接合を損なうため、真空度の向上や偏向フィルタで除きます。

  • A. 正しい。中性化した粒子が減速されずに届くことが原因です。
  • B. ウエハの温度はエネルギーコンタミネーションの原因ではありません。
  • C. 質量分析の強さが原因ではありません。

イオン注入のほかの問題

  1. マスクの端の付近にイオン注入したとき、不純物がマスクの下まで横方向に広がって入り込む原因として正しいものはどれか。
  2. 注入されたイオンが物質中でエネルギーを失う2つの仕組みの組み合わせとして正しいものはどれか。
  3. SiCにアルミニウムなどをイオン注入するとき、ウエハを数百℃に加熱しながら注入する(高温注入)ことが多い理由はどれか。
  4. nMOSのチャネルに急峻なレトログレード分布をつくるために、ボロンより重いp型不純物として検討・使用されてきた元素はどれか。
  5. 高ドーズのイオン注入を受けたフォトレジストを除去するときに問題になりやすいことはどれか。

この分野の比較

  • 熱拡散とイオン注入の違い：ドーピング方法を比較熱拡散とイオン注入を、原理・ドーズ量の制御・深さ方向の分布・温度・結晶のダメージ・コスト・用途の観点で表にして比較します。
