イオン注入

イオン注入でチャネリング(イオンが結晶のすき間を通って深く入りすぎる現象)を抑える方法として一般的なものはどれか。

  1. A加速エネルギーを最大にする
  2. B注入後にウエハを洗浄する
  3. Cウエハを結晶軸から数度傾けて注入する
答えと解説を見る

正解：C. ウエハを結晶軸から数度傾けて注入する

結晶の原子の並びに沿ってイオンが入ると、原子に衝突しにくいすき間を通って予定より深く入ってしまいます。ウエハを結晶軸から数度(例:7°)傾けて注入したり、表面に薄い膜を通して注入したりすることで、チャネリングを抑えます。

イオン注入のほかの問題

  1. イオン注入のドーズ量を表す単位として正しいものはどれか。
  2. 微細なトランジスタのソース・ドレインに浅い接合をつくるための工夫として正しいものはどれか。
  3. イオン注入後の不純物の深さ方向の分布を近似的に表す分布と、そのピークの深さを表す量の組み合わせとして正しいものはどれか。
  4. イオン注入装置で、磁場を使って目的のイオン種だけを選び出す部分はどれか。
  5. 熱拡散と比べたときのイオン注入の主な利点はどれか。
