イオン注入

イオン注入でできる結晶の損傷の分布として一般的に正しいものはどれか。

  1. A表面だけに集中する
  2. Bウエハの裏面に集中する
  3. Cイオンが止まる深さ(飛程)の付近から、それより少し浅い位置に多くできる
答えと解説を見る

正解：C. イオンが止まる深さ(飛程)の付近から、それより少し浅い位置に多くできる

イオンは、高速のうちは主に電子との相互作用でエネルギーを失い、速度が落ちると原子核との衝突で原子をはじき飛ばすようになります。そのため結晶の損傷は、イオンが止まる飛程の付近とその少し手前に多くできます。

  • A. 表面だけでなく、飛程付近までの深さに損傷ができます。
  • B. 注入は表面側から行うので、裏面には届きません。
  • C. 正しい。飛程の付近とその手前に多くできます。

イオン注入のほかの問題

  1. MOSFETのポリシリコンゲート電極を低抵抗にするために、ゲートに不純物を導入する方法として一般的に使われてきたものはどれか。
  2. すでにp型の領域にn型の不純物を注入して、正味の不純物濃度を下げたり導電型を反転させたりする手法を何と呼ぶか。
  3. 減速モード(高いエネルギーで運んでからウエハの手前で減速する方式)の低エネルギー注入で注意が必要な「エネルギーコンタミネーション」の原因はどれか。
  4. マスクの端の付近にイオン注入したとき、不純物がマスクの下まで横方向に広がって入り込む原因として正しいものはどれか。
  5. 注入されたイオンが物質中でエネルギーを失う2つの仕組みの組み合わせとして正しいものはどれか。
