イオン注入

ソース・ドレインの形成のように、大きなドーズ量を短い時間で注入するために使われるイオン注入装置はどれか。

  1. A高エネルギー注入装置
  2. B高電流(ハイカレント)注入装置
  3. C中電流注入装置
答えと解説を見る

正解：B. 高電流(ハイカレント)注入装置

イオン注入装置は、扱うビーム電流とエネルギーで高電流型、中電流型、高エネルギー型に分けられます。ソース・ドレインやポリシリコンゲートのような10¹⁵ ions/cm²前後の高ドーズの注入には、数mA〜数十mAのビームを出せる高電流型が使われ、低エネルギー・大電流のビームを広がらせずに運ぶ技術が鍵です。中電流型はしきい値調整やハロー、高エネルギー型は深いウェルなどに使われます。

イオン注入のほかの問題

  1. 同じアニール条件で、イオン注入のドーズ量を増やすと注入層のシート抵抗は一般にどうなるか。
  2. イオン注入のマスクとしてフォトレジストを使うときに注意すべき点はどれか。
  3. ウエハをドーパントを含むプラズマに直接さらし、低エネルギーのイオンを注入するプラズマドーピングの利点として正しいものはどれか。
  4. ウエハを傾けてイオン注入を行う際に、レジストなどの高いパターンの陰になって注入されない部分ができる現象を何と呼ぶか。
  5. アニールでドーパントを活性化させるとき、電気的に活性化できる濃度の上限を決める性質はどれか。
