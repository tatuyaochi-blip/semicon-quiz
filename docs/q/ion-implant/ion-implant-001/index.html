イオン注入

イオン注入で、不純物が打ち込まれる深さ(飛程)を主に決めるパラメータはどれか。

  1. A加速エネルギー
  2. Bドーズ量
  3. C注入後の洗浄時間
答えと解説を見る

正解：A. 加速エネルギー

注入の深さは主にイオンの加速エネルギーで決まり、エネルギーが高いほど深く入ります。ドーズ量は単位面積あたりに注入するイオンの数で、不純物濃度を決めます。イオンの種類(質量)も深さに影響し、同じエネルギーなら軽いイオンほど深く入ります。

イオン注入のほかの問題

  1. イオン注入後にアニール(熱処理)を行う主な目的として正しいものはどれか。
  2. イオン注入でチャネリング(イオンが結晶のすき間を通って深く入りすぎる現象)を抑える方法として一般的なものはどれか。
  3. イオン注入のドーズ量を表す単位として正しいものはどれか。
  4. 微細なトランジスタのソース・ドレインに浅い接合をつくるための工夫として正しいものはどれか。
  5. イオン注入後の不純物の深さ方向の分布を近似的に表す分布と、そのピークの深さを表す量の組み合わせとして正しいものはどれか。
