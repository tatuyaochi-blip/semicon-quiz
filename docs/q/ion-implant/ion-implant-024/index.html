イオン注入

イオン注入装置で、注入したイオンの量(ドーズ)を求めるために、ビーム電流を測定する部品はどれか。

  1. Aファラデーカップ
  2. Bマイクロレンズ
  3. Cペリクル
答えと解説を見る

正解：A. ファラデーカップ

ファラデーカップは、イオンビームを受け止めて、その電荷を電流として測定するカップ状の電極です。イオン1個あたりの電荷はわかっているので、電流を時間で積分すれば注入したイオンの数(ドーズ量)を求められ、目標に達したら注入を止めます。ビームが当たって出る二次電子が逃げると電流を誤って測るため、磁場や電極で電子を閉じ込める構造になっています。

イオン注入のほかの問題

  1. 浅いp型接合をつくる際に、ボロンと一緒に炭素などを注入する(共注入する)主な目的はどれか。
  2. イオン注入装置のイオン源で、ボロンのイオンをつくるために使われる代表的なガスはどれか。
  3. 数MeVに及ぶ高エネルギーのイオン注入が使われる用途の例として正しいものはどれか。
  4. ドーズ量1×10¹⁵ cm⁻²の不純物が、深さ100 nmの範囲に均一に分布しているとすると、平均の濃度はおよそいくらか。
  5. ウエハの剥離(スマートカット)や、パワーデバイスのライフタイム制御などに使われるイオン注入として正しいものはどれか。
