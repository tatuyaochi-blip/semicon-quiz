イオン注入

MOSFETのポリシリコンゲート電極を低抵抗にするために、ゲートに不純物を導入する方法として一般的に使われてきたものはどれか。

  1. Aゲートに光を当てる
  2. Bイオン注入(ソース・ドレインと同時に行うことも多い)
  3. Cゲートを長時間水に浸す
答えと解説を見る

正解：B. イオン注入(ソース・ドレインと同時に行うことも多い)

ポリシリコンゲートは不純物を高濃度に導入して導電性を高めます。nMOSにはn型、pMOSにはp型の不純物をイオン注入し、多くの場合ソース・ドレインの注入と同時に行います。導入した不純物はアニールで活性化します。

  • A. 光を当てても不純物は導入されません。
  • B. 正しい。イオン注入で不純物を導入します。
  • C. 水に浸しても不純物は導入されません。
この分野を解く 分野ページへ

イオン注入のほかの問題

  1. すでにp型の領域にn型の不純物を注入して、正味の不純物濃度を下げたり導電型を反転させたりする手法を何と呼ぶか。
  2. 減速モード(高いエネルギーで運んでからウエハの手前で減速する方式)の低エネルギー注入で注意が必要な「エネルギーコンタミネーション」の原因はどれか。
  3. マスクの端の付近にイオン注入したとき、不純物がマスクの下まで横方向に広がって入り込む原因として正しいものはどれか。
  4. 注入されたイオンが物質中でエネルギーを失う2つの仕組みの組み合わせとして正しいものはどれか。
  5. SiCにアルミニウムなどをイオン注入するとき、ウエハを数百℃に加熱しながら注入する(高温注入)ことが多い理由はどれか。
