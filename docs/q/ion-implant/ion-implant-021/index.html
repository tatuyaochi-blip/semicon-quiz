イオン注入

アニールでドーパントを活性化させるとき、電気的に活性化できる濃度の上限を決める性質はどれか。

  1. A固溶度
  2. B移動度
  3. C誘電率
答えと解説を見る

正解：A. 固溶度

結晶中に熱平衡で溶け込める不純物の最大濃度を固溶度といい、シリコン中ではボロンが約2×10²⁰ cm⁻³(1000 ℃付近)、ヒ素やリンは10²¹ cm⁻³前後です。固溶度を超える濃度で注入しても、余った不純物は析出したりクラスターをつくったりして電気的に活性になりません。ミリ秒アニールや固相エピタキシャル再成長では、熱平衡に達する前に冷やすため、一時的に固溶度を超える活性化が得られます。

イオン注入のほかの問題

  1. レーザーアニールの特徴として正しいものはどれか。
  2. イオン注入で、ウエハ面内のドーズを均一にするための方法として正しいものはどれか。
  3. イオン注入装置で、注入したイオンの量(ドーズ)を求めるために、ビーム電流を測定する部品はどれか。
  4. 浅いp型接合をつくる際に、ボロンと一緒に炭素などを注入する(共注入する)主な目的はどれか。
  5. イオン注入装置のイオン源で、ボロンのイオンをつくるために使われる代表的なガスはどれか。

この分野の比較

  • 熱拡散とイオン注入の違い：ドーピング方法を比較熱拡散とイオン注入を、原理・ドーズ量の制御・深さ方向の分布・温度・結晶のダメージ・コスト・用途の観点で表にして比較します。
