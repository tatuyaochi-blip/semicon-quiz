イオン注入

アニールでドーパントを活性化させるとき、電気的に活性化できる濃度の上限を決める性質はどれか。

  1. A固溶度
  2. B移動度
  3. C誘電率
答えと解説を見る

正解：A. 固溶度

結晶中に溶け込める不純物の最大濃度を固溶度といいます。固溶度を超える濃度で注入しても、余った不純物は析出したりクラスターをつくったりして、電気的に活性になりません。短時間で高温にするアニールでは、一時的に固溶度を超える活性化が得られることもあります。

イオン注入のほかの問題

  1. レーザーアニールの特徴として正しいものはどれか。
  2. イオン注入で、ウエハ面内のドーズを均一にするための方法として正しいものはどれか。
  3. イオン注入装置で、注入したイオンの量(ドーズ)を求めるために、ビーム電流を測定する部品はどれか。
  4. 浅いp型接合をつくる際に、ボロンと一緒に炭素などを注入する(共注入する)主な目的はどれか。
  5. イオン注入装置のイオン源で、ボロンのイオンをつくるために使われる代表的なガスはどれか。
