イオン注入

SiCにアルミニウムなどをイオン注入するとき、ウエハを数百℃に加熱しながら注入する(高温注入)ことが多い理由はどれか。

  1. Aウエハを溶かすため
  2. B注入中に損傷を回復させ、アモルファス化などの回復しにくい損傷を防ぐため
  3. Cイオンを重くするため
答えと解説を見る

正解：B. 注入中に損傷を回復させ、アモルファス化などの回復しにくい損傷を防ぐため

SiCは室温で高ドーズの注入を行うと、アモルファス化などの回復しにくい損傷が残りやすくなります。ウエハを数百℃に加熱しながら注入すると、注入中に損傷の一部が回復し、その後の1,600℃以上の活性化アニールで良好な結晶と高い活性化率が得られやすくなります。

  • A. 数百℃でSiCは溶けません。
  • B. 正しい。注入中に損傷を回復させるためです。
  • C. 加熱してもイオンの質量は変わりません。

イオン注入のほかの問題

  2. 高ドーズのイオン注入を受けたフォトレジストを除去するときに問題になりやすいことはどれか。
  3. イオン注入で、不純物が打ち込まれる深さ(飛程)を主に決めるパラメータはどれか。
  4. イオン注入後にアニール(熱処理)を行う主な目的として正しいものはどれか。
  5. イオン注入でチャネリング(イオンが結晶のすき間を通って深く入りすぎる現象)を抑える方法として一般的なものはどれか。
