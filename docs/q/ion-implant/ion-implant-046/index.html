イオン注入

マスクの端の付近にイオン注入したとき、不純物がマスクの下まで横方向に広がって入り込む原因として正しいものはどれか。

  1. Aウエハが回転しているため
  2. Bマスクが溶けるため
  3. C注入されたイオンが原子との衝突で横方向にも散乱する(横方向の広がりをもつ)ため
答えと解説を見る

正解：C. 注入されたイオンが原子との衝突で横方向にも散乱する(横方向の広がりをもつ)ため

注入されたイオンは原子との衝突を繰り返しながら止まるため、深さ方向だけでなく横方向にも広がり、その標準偏差は深さ方向のΔRpと同程度(数nm〜数十nm)になります。そのため、マスクの端の下にも不純物が入り込み、ゲートとソース・ドレインの重なり(オーバーラップ)や実効チャネル長に影響します。微細なトランジスタでは、この横方向の広がりもシミュレーションで見込んで設計します。

  • A. ウエハの回転が原因ではありません。
  • B. マスクが溶けることが原因ではありません。
  • C. 正しい。衝突による横方向の散乱で広がります。

イオン注入のほかの問題

  1. 注入されたイオンが物質中でエネルギーを失う2つの仕組みの組み合わせとして正しいものはどれか。
  2. SiCにアルミニウムなどをイオン注入するとき、ウエハを数百℃に加熱しながら注入する(高温注入)ことが多い理由はどれか。
  3. nMOSのチャネルに急峻なレトログレード分布をつくるために、ボロンより重いp型不純物として検討・使用されてきた元素はどれか。
  4. 高ドーズのイオン注入を受けたフォトレジストを除去するときに問題になりやすいことはどれか。
  5. イオン注入で、不純物が打ち込まれる深さ(飛程)を主に決めるパラメータはどれか。
