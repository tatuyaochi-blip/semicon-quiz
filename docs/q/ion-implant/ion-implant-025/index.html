イオン注入

浅いp型接合をつくる際に、ボロンと一緒に炭素などを注入する(共注入する)主な目的はどれか。

  1. Ap型をn型に変えるため
  2. Bウエハを発光させるため
  3. Cボロンの拡散を抑え、接合を浅く保つため
答えと解説を見る

正解：C. ボロンの拡散を抑え、接合を浅く保つため

ボロンは格子間シリコンの助けを借りて拡散が増速されます(過渡増速拡散)。炭素を一緒に注入すると、炭素が格子間シリコンを捕らえるため、ボロンの拡散が抑えられ、アニール後も浅い接合を保てます。

イオン注入のほかの問題

  1. イオン注入装置のイオン源で、ボロンのイオンをつくるために使われる代表的なガスはどれか。
  2. 数MeVに及ぶ高エネルギーのイオン注入が使われる用途の例として正しいものはどれか。
  3. ドーズ量1×10¹⁵ cm⁻²の不純物が、深さ100 nmの範囲に均一に分布しているとすると、平均の濃度はおよそいくらか。
  4. ウエハの剥離(スマートカット)や、パワーデバイスのライフタイム制御などに使われるイオン注入として正しいものはどれか。
  5. アモルファス化した層を再結晶させたとき、元のアモルファス層と結晶の境界より少し深い位置に残る欠陥を何と呼ぶか。
