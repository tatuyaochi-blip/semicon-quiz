イオン注入

nMOSのチャネルに急峻なレトログレード分布をつくるために、ボロンより重いp型不純物として検討・使用されてきた元素はどれか。

  1. Aリン
  2. Bインジウム
  3. Cヒ素
答えと解説を見る

正解：B. インジウム

インジウムはIII族のアクセプタで、ボロンよりはるかに重く拡散も遅いため、浅い位置で止まり、熱処理後も急峻な分布を保てます。そのため、表面は低濃度で少し深い位置で高濃度になるレトログレードのチャネル分布をつくるのに使われました。ただし活性化しにくいという欠点があります。

  • A. リンはn型の不純物です。
  • B. 正しい。重くて拡散の遅いp型不純物です。
  • C. ヒ素はn型の不純物です。

イオン注入のほかの問題

  1. 高ドーズのイオン注入を受けたフォトレジストを除去するときに問題になりやすいことはどれか。
  2. イオン注入で、不純物が打ち込まれる深さ(飛程)を主に決めるパラメータはどれか。
  3. イオン注入後にアニール(熱処理)を行う主な目的として正しいものはどれか。
  4. イオン注入でチャネリング(イオンが結晶のすき間を通って深く入りすぎる現象)を抑える方法として一般的なものはどれか。
  5. イオン注入のドーズ量を表す単位として正しいものはどれか。
