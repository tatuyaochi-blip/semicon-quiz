イオン注入

イオン注入後の不純物の深さ方向の分布を近似的に表す分布と、そのピークの深さを表す量の組み合わせとして正しいものはどれか。

  1. A一様分布で、ピークは常に表面
  2. Bガウス分布で、ピークの深さを投影飛程(Rp)という
  3. C指数分布で、ピークの深さを拡散長という
答えと解説を見る

正解：B. ガウス分布で、ピークの深さを投影飛程(Rp)という

イオン注入した不純物の分布は、近似的にガウス分布で表され、ピークの深さを投影飛程Rp、広がりを標準偏差ΔRpで表します。Rpは加速エネルギーとイオンの種類で決まります。実際にはチャネリングなどによって裾が深い側に伸びることがあります。

イオン注入のほかの問題

  1. イオン注入装置で、磁場を使って目的のイオン種だけを選び出す部分はどれか。
  2. 熱拡散と比べたときのイオン注入の主な利点はどれか。
  3. プリアモルファス化注入(PAI)の目的として正しいものはどれか。
  4. イオン注入中のウエハの帯電(チャージアップ)を抑えるために用いられるものはどれか。
  5. 1価のイオンを、面積100 cm²のウエハにドーズ量1×10¹⁵ ions/cm²で注入する。ビーム電流が1 mAのとき、必要な注入時間はおよそいくらか。(電気素量 1.6×10⁻¹⁹ C)
