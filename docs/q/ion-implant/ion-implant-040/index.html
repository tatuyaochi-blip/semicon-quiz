イオン注入

注入されたイオンがシリコンの原子をはじき飛ばしたときに結晶中にできる、空孔と格子間原子の組を何と呼ぶか。

  1. Aフレンケル対
  2. Bクーパー対
  3. C電子正孔対
答えと解説を見る

正解：A. フレンケル対

注入されたイオンがシリコン原子に衝突すると、原子が本来の位置からはじき出されて格子間原子になり、元の位置には空孔が残ります。この組がフレンケル対で、1個のイオンが数百〜数千個のフレンケル対をつくることもあります。ドーズが多いと損傷が重なってアモルファス層になります。アニールで大部分は再結合して回復しますが、残った格子間シリコンが過渡増速拡散やEOR欠陥の原因になります。

  • A. 正しい。空孔と格子間原子の組です。
  • B. クーパー対は超伝導で電子が対になったものです。
  • C. 電子正孔対は光などでつくられるキャリアの対です。

イオン注入のほかの問題

  1. 大電流のイオン注入中にウエハを冷却する主な理由はどれか。
  2. イオン注入でできる結晶の損傷の分布として一般的に正しいものはどれか。
  3. MOSFETのポリシリコンゲート電極を低抵抗にするために、ゲートに不純物を導入する方法として一般的に使われてきたものはどれか。
  4. すでにp型の領域にn型の不純物を注入して、正味の不純物濃度を下げたり導電型を反転させたりする手法を何と呼ぶか。
  5. 減速モード(高いエネルギーで運んでからウエハの手前で減速する方式)の低エネルギー注入で注意が必要な「エネルギーコンタミネーション」の原因はどれか。
