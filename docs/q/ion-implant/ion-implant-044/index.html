イオン注入

すでにp型の領域にn型の不純物を注入して、正味の不純物濃度を下げたり導電型を反転させたりする手法を何と呼ぶか。

  1. Aゲッタリング
  2. Bパッシベーション
  3. Cカウンタードーピング(補償)
答えと解説を見る

正解：C. カウンタードーピング(補償)

反対の導電型の不純物を重ねて注入すると、ドナーとアクセプタが互いに打ち消し合い(補償)、正味のキャリア濃度が下がり、量が多ければ導電型が反転します。チャネルの表面だけ濃度を下げてしきい値電圧を調整したり、埋め込みチャネルをつくったりするのに使われます。ただし総不純物量が増えてイオン化不純物散乱が強まるため、移動度は下がりやすく、ばらつきの原因にもなります。

  • A. ゲッタリングは有害な不純物を捕らえる手法です。
  • B. パッシベーションは表面を保護・不活性化する処理です。
  • C. 正しい。反対の導電型の不純物で打ち消す手法です。

イオン注入のほかの問題

  1. 減速モード(高いエネルギーで運んでからウエハの手前で減速する方式)の低エネルギー注入で注意が必要な「エネルギーコンタミネーション」の原因はどれか。
  2. マスクの端の付近にイオン注入したとき、不純物がマスクの下まで横方向に広がって入り込む原因として正しいものはどれか。
  3. 注入されたイオンが物質中でエネルギーを失う2つの仕組みの組み合わせとして正しいものはどれか。
  4. SiCにアルミニウムなどをイオン注入するとき、ウエハを数百℃に加熱しながら注入する(高温注入)ことが多い理由はどれか。
  5. nMOSのチャネルに急峻なレトログレード分布をつくるために、ボロンより重いp型不純物として検討・使用されてきた元素はどれか。
