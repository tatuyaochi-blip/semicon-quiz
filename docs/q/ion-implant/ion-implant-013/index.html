イオン注入

ソース・ドレインの端に、チャネルと同じ導電型の不純物を斜めに注入するハロー(ポケット)注入の主な目的はどれか。

  1. Aゲート電極の抵抗を下げる
  2. B短チャネル効果を抑える
  3. Cトランジスタを発光させる
答えと解説を見る

正解：B. 短チャネル効果を抑える

ハロー注入では、ウエハを20〜45°程度傾けて、ゲートの下に潜り込むようにソース・ドレイン端の近くにチャネルと同じ導電型の不純物を局所的に入れます。ドレインから広がる空乏層を抑えられるため、ゲート長が短くなってもしきい値電圧の低下やパンチスルーを抑えられます。チャネル全体を濃くするより移動度の低下が小さく、平面型の微細なトランジスタで標準的に使われました。

イオン注入のほかの問題

  1. 浅いp型層をつくるために、ボロン単体ではなくBF2⁺イオンを注入することがある理由はどれか。
  2. イオン注入後のアニールの初期に、注入で生じた格子間シリコンの影響で、ボロンなどの拡散が一時的に速くなる現象を何と呼ぶか。
  3. ソース・ドレインの形成のように、大きなドーズ量を短い時間で注入するために使われるイオン注入装置はどれか。
  4. 同じアニール条件で、イオン注入のドーズ量を増やすと注入層のシート抵抗は一般にどうなるか。
  5. イオン注入のマスクとしてフォトレジストを使うときに注意すべき点はどれか。
