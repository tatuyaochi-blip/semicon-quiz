イオン注入

一般的なイオン注入装置で、イオンが通る順序として正しいものはどれか。

  1. Aイオン源 → 質量分析 → 加速部 → 走査 → ウエハ
  2. B加速部 → イオン源 → 質量分析 → ウエハ
  3. C質量分析 → イオン源 → ウエハ → 加速部
答えと解説を見る

正解：A. イオン源 → 質量分析 → 加速部 → 走査 → ウエハ

イオン源でガスをプラズマにしてイオンを取り出し、質量分析磁石で目的のイオンだけを選び、加速部で必要なエネルギーまで加速します。その後、ビームを走査してウエハ全面に均一に注入します(装置によって加速と分析の順序が異なる場合もあります)。

  • A. 正しい。イオン源から始まり、選別・加速・走査を経てウエハに届きます。
  • B. イオンをつくる前に加速することはできません。
  • C. イオン源より前に質量分析はできません。

イオン注入のほかの問題

  1. 同じ加速エネルギーでシリコンに注入したとき、ヒ素(質量数75)とリン(質量数31)の飛程の関係として正しいものはどれか。
  2. イオン注入装置で、加速電圧50 kVで2価のイオン(電荷が2倍)を加速したときのエネルギーはいくらか。
  3. MOSFETのしきい値電圧の調整やウェルのような、中程度のドーズ量の注入に主に使われるイオン注入装置はどれか。
  4. 注入されたイオンがシリコンの原子をはじき飛ばしたときに結晶中にできる、空孔と格子間原子の組を何と呼ぶか。
  5. 大電流のイオン注入中にウエハを冷却する主な理由はどれか。
