イオン注入

イオン注入の原理として正しいものはどれか。

  1. A不純物をイオンにして電界で加速し、ウエハに打ち込む
  2. B不純物を含む液体にウエハを浸す
  3. C不純物を含むガスの中でウエハを加熱し、表面から染み込ませる
答えと解説を見る

正解：A. 不純物をイオンにして電界で加速し、ウエハに打ち込む

イオン注入では、ボロンやリンなどの不純物をイオン化し、電界で加速して高速でウエハに打ち込みます。加速のエネルギーで深さを、打ち込むイオンの数(ドーズ量)で濃度を精密に制御できます。

  • A. 正しい。イオンを加速して打ち込みます。
  • B. 液体に浸す方法はイオン注入ではありません。
  • C. ガス中で加熱して染み込ませるのは熱拡散です。

  3. LSIの製造で使われるイオン注入のドーズ量の範囲として最も近いものはどれか。
  4. イオン注入装置のビームの通り道を高い真空にする主な理由はどれか。
  5. 一般的なイオン注入装置で、イオンが通る順序として正しいものはどれか。
