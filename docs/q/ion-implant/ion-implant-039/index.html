イオン注入

MOSFETのしきい値電圧の調整やウェルのような、中程度のドーズ量の注入に主に使われるイオン注入装置はどれか。

  1. ACMP装置
  2. B中電流イオン注入装置
  3. C電子ビーム描画装置
答えと解説を見る

正解：B. 中電流イオン注入装置

イオン注入装置は、ドーズ量とエネルギーの範囲によって、中電流(しきい値調整やハロー注入など)、大電流(ソース・ドレインなどの高ドーズ)、高エネルギー(深いウェルなど)に大きく分けられます。中電流装置はドーズの精度や注入角度の制御に優れています。

  • A. CMP装置は研磨で平坦化する装置です。
  • B. 正しい。中程度のドーズの注入に使われます。
  • C. 電子ビーム描画装置はパターンを描く装置です。

イオン注入のほかの問題

  1. 注入されたイオンがシリコンの原子をはじき飛ばしたときに結晶中にできる、空孔と格子間原子の組を何と呼ぶか。
  2. 大電流のイオン注入中にウエハを冷却する主な理由はどれか。
  3. イオン注入でできる結晶の損傷の分布として一般的に正しいものはどれか。
  4. MOSFETのポリシリコンゲート電極を低抵抗にするために、ゲートに不純物を導入する方法として一般的に使われてきたものはどれか。
  5. すでにp型の領域にn型の不純物を注入して、正味の不純物濃度を下げたり導電型を反転させたりする手法を何と呼ぶか。
