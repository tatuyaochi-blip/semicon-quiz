イオン注入

シリコンに注入する不純物と導電型の組み合わせとして正しいものはどれか。

  1. Aリン:p型、ヒ素:p型
  2. Bボロン:n型、リン:p型
  3. Cボロン:p型、リン・ヒ素:n型
答えと解説を見る

正解：C. ボロン:p型、リン・ヒ素:n型

III族のボロンはアクセプタとして働きp型を、V族のリンやヒ素はドナーとして働きn型をつくります。イオン注入では、これらの元素を目的の場所に必要な量だけ打ち込みます。

  • A. リンもヒ素もn型をつくります。
  • B. ボロンとリンの導電型が逆です。
  • C. 正しい。ボロンはp型、リン・ヒ素はn型です。

イオン注入のほかの問題

  1. LSIの製造で使われるイオン注入のドーズ量の範囲として最も近いものはどれか。
  2. イオン注入装置のビームの通り道を高い真空にする主な理由はどれか。
  3. 一般的なイオン注入装置で、イオンが通る順序として正しいものはどれか。
  4. 同じ加速エネルギーでシリコンに注入したとき、ヒ素(質量数75)とリン(質量数31)の飛程の関係として正しいものはどれか。
  5. イオン注入装置で、加速電圧50 kVで2価のイオン(電荷が2倍)を加速したときのエネルギーはいくらか。
