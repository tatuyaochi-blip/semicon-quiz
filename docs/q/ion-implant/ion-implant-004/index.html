イオン注入

イオン注入のドーズ量を表す単位として正しいものはどれか。

  1. AeV
  2. Bions/cm²(単位面積あたりのイオン数)
  3. CΩ/□
答えと解説を見る

正解：B. ions/cm²(単位面積あたりのイオン数)

ドーズ量は、ウエハの単位面積あたりに注入したイオンの数で、ions/cm²(またはatoms/cm²)で表します。eVはイオンの加速エネルギーの単位、Ω/□はシート抵抗の単位です。

イオン注入のほかの問題

  1. 微細なトランジスタのソース・ドレインに浅い接合をつくるための工夫として正しいものはどれか。
  2. イオン注入後の不純物の深さ方向の分布を近似的に表す分布と、そのピークの深さを表す量の組み合わせとして正しいものはどれか。
  3. イオン注入装置で、磁場を使って目的のイオン種だけを選び出す部分はどれか。
  4. 熱拡散と比べたときのイオン注入の主な利点はどれか。
  5. プリアモルファス化注入(PAI)の目的として正しいものはどれか。
