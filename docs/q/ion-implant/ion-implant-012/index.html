イオン注入

CMOSのウェル形成で、高エネルギーのイオン注入を使って、表面より深い位置の不純物濃度を高くしたウェルを何と呼ぶか。

  1. Aレトログレードウェル
  2. BLDD
  3. Cシリサイド
答えと解説を見る

正解：A. レトログレードウェル

レトログレードウェルは、数百keV〜MeV級の高エネルギー注入で深い位置に濃度のピークをもたせたウェルです。表面の濃度はトランジスタの特性に合わせて低めにしつつ、深い位置を高濃度にして、パンチスルーやラッチアップ(寄生サイリスタの動作)を抑えられます。従来の拡散ウェルのように1000 ℃以上で数時間の熱拡散が不要になり、熱予算と工程時間を大きく減らせる利点もあります。

イオン注入のほかの問題

  1. ソース・ドレインの端に、チャネルと同じ導電型の不純物を斜めに注入するハロー(ポケット)注入の主な目的はどれか。
  2. 浅いp型層をつくるために、ボロン単体ではなくBF2⁺イオンを注入することがある理由はどれか。
  3. イオン注入後のアニールの初期に、注入で生じた格子間シリコンの影響で、ボロンなどの拡散が一時的に速くなる現象を何と呼ぶか。
  4. ソース・ドレインの形成のように、大きなドーズ量を短い時間で注入するために使われるイオン注入装置はどれか。
  5. 同じアニール条件で、イオン注入のドーズ量を増やすと注入層のシート抵抗は一般にどうなるか。
