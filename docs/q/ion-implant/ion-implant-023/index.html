イオン注入

イオン注入で、ウエハ面内のドーズを均一にするための方法として正しいものはどれか。

  1. Aビームを1点に固定して当て続ける
  2. Bビームやウエハを走査して、ウエハ全面に均一に当てる
  3. Cウエハを加熱し続ける
答えと解説を見る

正解：B. ビームやウエハを走査して、ウエハ全面に均一に当てる

イオンビームはウエハより小さいため、ビームを電場や磁場で振ったり、ウエハを機械的に動かしたりして、全面を走査しながら注入します。走査の速度や回数を制御することで、ウエハ面内のドーズのばらつきを小さくします。

イオン注入のほかの問題

  1. イオン注入装置で、注入したイオンの量(ドーズ)を求めるために、ビーム電流を測定する部品はどれか。
  2. 浅いp型接合をつくる際に、ボロンと一緒に炭素などを注入する(共注入する)主な目的はどれか。
  3. イオン注入装置のイオン源で、ボロンのイオンをつくるために使われる代表的なガスはどれか。
  4. 数MeVに及ぶ高エネルギーのイオン注入が使われる用途の例として正しいものはどれか。
  5. ドーズ量1×10¹⁵ cm⁻²の不純物が、深さ100 nmの範囲に均一に分布しているとすると、平均の濃度はおよそいくらか。
