イオン注入

イオン注入のマスクとしてフォトレジストを使うときに注意すべき点はどれか。

  1. Aレジストは薄いほどよい
  2. Bレジストは注入のあとも除去しなくてよい
  3. Cイオンがレジストを突き抜けないよう、注入エネルギーに対して十分な厚さが必要である
答えと解説を見る

正解：C. イオンがレジストを突き抜けないよう、注入エネルギーに対して十分な厚さが必要である

レジストが薄すぎると、高エネルギーのイオンが突き抜けてマスクした部分にも注入されてしまいます。そのため注入エネルギーとイオン種に応じた厚さが必要です。高ドーズの注入ではレジストの表面が硬化して除去しにくくなるため、アッシングの条件にも注意が必要です。

この分野を解く 分野ページへ

  2. ウエハを傾けてイオン注入を行う際に、レジストなどの高いパターンの陰になって注入されない部分ができる現象を何と呼ぶか。
  3. アニールでドーパントを活性化させるとき、電気的に活性化できる濃度の上限を決める性質はどれか。
  4. レーザーアニールの特徴として正しいものはどれか。
  5. イオン注入で、ウエハ面内のドーズを均一にするための方法として正しいものはどれか。
