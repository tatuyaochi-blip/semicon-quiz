イオン注入

イオン注入中のウエハの帯電(チャージアップ)を抑えるために用いられるものはどれか。

  1. Aウエハを高温に加熱する
  2. Bビーム電流を最大にする
  3. C電子を供給して電荷を中和する装置(プラズマフラッドガンなど)
答えと解説を見る

正解：C. 電子を供給して電荷を中和する装置(プラズマフラッドガンなど)

正のイオンを注入し続けると、ウエハ上の絶縁された部分が帯電し、ゲート酸化膜が破壊されるおそれがあります。そこで、低エネルギーの電子をウエハ付近に供給して正電荷を中和するプラズマフラッドガンやエレクトロンシャワーが使われます。

イオン注入のほかの問題

  1. 1価のイオンを、面積100 cm²のウエハにドーズ量1×10¹⁵ ions/cm²で注入する。ビーム電流が1 mAのとき、必要な注入時間はおよそいくらか。(電気素量 1.6×10⁻¹⁹ C)
  2. CMOSのウェル形成で、高エネルギーのイオン注入を使って、表面より深い位置の不純物濃度を高くしたウェルを何と呼ぶか。
  3. ソース・ドレインの端に、チャネルと同じ導電型の不純物を斜めに注入するハロー(ポケット)注入の主な目的はどれか。
  4. 浅いp型層をつくるために、ボロン単体ではなくBF2⁺イオンを注入することがある理由はどれか。
  5. イオン注入後のアニールの初期に、注入で生じた格子間シリコンの影響で、ボロンなどの拡散が一時的に速くなる現象を何と呼ぶか。
