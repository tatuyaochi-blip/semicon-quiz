イオン注入

熱拡散と比べたときのイオン注入の主な利点はどれか。

  1. A低温で処理でき、ドーズ量と深さを精度よく制御できる
  2. B高温で長時間の処理ができる
  3. C結晶に損傷をまったく与えない
答えと解説を見る

正解：A. 低温で処理でき、ドーズ量と深さを精度よく制御できる

イオン注入は室温付近で行えるため、フォトレジストをマスクとして使え、注入量は電流の測定で精密に管理できます。深さもエネルギーで制御できます。一方、結晶に損傷を与えるため、注入後のアニールが必要です。

イオン注入のほかの問題

  1. プリアモルファス化注入(PAI)の目的として正しいものはどれか。
  2. イオン注入中のウエハの帯電(チャージアップ)を抑えるために用いられるものはどれか。
  3. 1価のイオンを、面積100 cm²のウエハにドーズ量1×10¹⁵ ions/cm²で注入する。ビーム電流が1 mAのとき、必要な注入時間はおよそいくらか。(電気素量 1.6×10⁻¹⁹ C)
  4. CMOSのウェル形成で、高エネルギーのイオン注入を使って、表面より深い位置の不純物濃度を高くしたウェルを何と呼ぶか。
  5. ソース・ドレインの端に、チャネルと同じ導電型の不純物を斜めに注入するハロー(ポケット)注入の主な目的はどれか。
