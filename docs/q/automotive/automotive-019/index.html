車載半導体と機能安全

単一点故障指標(SPFM)について、ASIL Dで求められる目標値の目安として正しいものはどれか。

  1. A90%以上
  2. B60%以上
  3. C99%以上
答えと解説を見る

正解：C. 99%以上

SPFMは、安全に関係する故障のうち、単独で安全目標の侵害につながる単一点故障と、安全機構で検出しきれずに残る残余故障が少ないことを表す指標で、1から両者の故障率の割合を引いて求めます。目標値の目安は、ASIL Bで90%以上、ASIL Cで97%以上、ASIL Dで99%以上です。潜在故障指標(LFM)の目安は、ASIL Bで60%以上、ASIL Cで80%以上、ASIL Dで90%以上なので、90%や60%はLFMやASIL Bの値と混同しやすい数字です。

  2. 安全に関係するハードウェアの故障率の合計が1000 FITで、そのうち単一点故障と残余故障(安全機構で検出されずに残る故障)の故障率の合計が5 FITのとき、単一点故障指標(SPFM)はいくらか。
  3. 故障率200 FITの回路に、診断カバレッジ99%の安全機構を設けた。安全機構で検出されずに残る故障の故障率はいくらか。

  5. 車載マイコンの安全機構として使われるロックステップCPUの仕組みとして正しいものはどれか。
