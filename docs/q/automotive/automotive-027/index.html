車載半導体と機能安全

ウィンドウ型のウォッチドッグタイマの特徴として正しいものはどれか。

  1. A一度キックされると、その後は監視を止めて、消費電力を下げる
  2. B決められた時間の窓より遅すぎるキック(タイマのクリア)だけでなく、早すぎるキックも異常として検出する
  3. Cキックが遅れたときは、プログラムが重い処理をしているとみなし、リセットをかけずに待ち時間を自動で延ばして処理を続けさせる
答えと解説を見る

正解：B. 決められた時間の窓より遅すぎるキック(タイマのクリア)だけでなく、早すぎるキックも異常として検出する

通常のウォッチドッグは、一定時間内にキックされないとリセットをかけます。しかし、プログラムが処理の一部を飛ばして短いループを回るような異常では、キックが早く来てしまい、見逃されることがあります。ウィンドウ型では、キックしてよい時間の窓を決め、窓より早すぎても遅すぎても異常とします。車載では、マイコンとは別のクロックで動く外付けの監視ICにウォッチドッグを持たせ、共通の原因で両方が止まらないようにすることもあります。
