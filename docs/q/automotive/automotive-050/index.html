車載半導体と機能安全

次のうち、ISO 26262(機能安全)ではなく、主にSOTIF(ISO 21448、意図した機能の安全性)で扱う問題はどれか。

  1. Aレーダーの送信回路の部品が、長年の使用中に温度変化などのストレスで劣化して壊れ、前方の物体を検出できなくなる
  2. Bブレーキ制御のソフトウェアの誤りのために、特定の条件で制動力の計算を誤る
  3. C故障していないカメラが、強い逆光のために前方の歩行者を認識できず、自動ブレーキが作動しない
答えと解説を見る

正解：C. 故障していないカメラが、強い逆光のために前方の歩行者を認識できず、自動ブレーキが作動しない

SOTIFは、部品が故障していなくても、センサの性能の限界や認識アルゴリズムの不足、仕様の不十分さ、予見できる誤用などによって生じる危険を扱います。逆光で歩行者を認識できないのは、故障ではなく機能の限界による問題なのでSOTIFの対象です。部品の劣化による故障はランダムハードウェア故障、ソフトウェアの誤りはシステマティック故障で、どちらもISO 26262で扱います。SOTIFでは、試験やシミュレーションで未知の危険なシナリオを減らしていきます。
