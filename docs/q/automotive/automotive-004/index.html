車載半導体と機能安全

車載用の半導体で求められる「ゼロディフェクト(ゼロ不良)」の考え方として最も適切なものはどれか。

  1. A一定の割合の不良はどうしても避けられないので、市場で故障した部品を無償で新品と交換し、保証の費用で対応することを前提にする
  2. B出荷前の全数検査を厳しくすれば十分なので、設計や工程の管理には特に力を入れなくてよい
  3. C不良ゼロを目標に、設計・製造・テストの各段階で不良の作り込みと流出を防ぎ、1件の不良でも原因を突き止めて再発を防ぐ
答えと解説を見る

正解：C. 不良ゼロを目標に、設計・製造・テストの各段階で不良の作り込みと流出を防ぎ、1件の不良でも原因を突き止めて再発を防ぐ

車の故障は人命に関わり、1台に数千個の半導体が使われるため、部品1個あたりの不良率は極めて低くなければなりません。ゼロディフェクトは、不良ゼロを目標に、設計の余裕、工程の管理、外れ値のチップを除くテストなどを組み合わせて不良の作り込みと流出を防ぐ考え方です。市場で1件でも不良が出れば、根本原因を解析して再発防止につなげます。検査だけでは見逃しが残るため、設計と工程の管理も欠かせません。
