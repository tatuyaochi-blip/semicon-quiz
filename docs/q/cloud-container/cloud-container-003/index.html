クラウドとコンテナの基礎

コンテナイメージとコンテナの関係の説明として、正しいものはどれか。

  1. Aコンテナを停止すると、コンテナの中で変更した内容が自動でイメージに書き戻され、もとのイメージが上書きされる
  2. Bイメージは読み取り専用のひな形で、1つのイメージから、それぞれ書き込み可能な層をもつ複数のコンテナを起動できる
  3. C1つのイメージから同時に起動できるコンテナは1つだけで、2つ目を起動するには、イメージを別の名前で複製しておく必要がある
答えと解説を見る

正解：B. イメージは読み取り専用のひな形で、1つのイメージから、それぞれ書き込み可能な層をもつ複数のコンテナを起動できる

イメージは、アプリケーションの実行に必要なファイルと設定をまとめた読み取り専用のひな形で、コンテナはイメージから作られた実行の単位です。コンテナを作ると、イメージの層の上に、そのコンテナ専用の書き込み可能な層が重ねられます。そのため、1つのイメージから多数のコンテナを起動でき、各コンテナでの変更は、ほかのコンテナやイメージに影響しません。変更をイメージとして残したい場合は、Dockerfileを直してイメージを作り直すのが一般的です。

  • A. コンテナでの変更は、そのコンテナの書き込み可能な層に残るだけで、イメージは自動では変わりません。
  • B. 正しい。イメージは共有され、コンテナごとに書き込み可能な層が付きます。
  • C. 同じイメージから、いくつでもコンテナを起動できます。イメージを複製する必要はありません。
