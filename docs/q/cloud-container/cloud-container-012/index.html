クラウドとコンテナの基礎

イメージを registry.example.com/team/web:1.4 と指定して取得(pull)する。この指定の各部分の意味の組み合わせとして、正しいものはどれか。

  1. Aregistry.example.com:リポジトリ、team/web:タグ、1.4:イメージの中身から計算したダイジェスト
  2. Bregistry.example.com:レジストリ(イメージを保管するサーバ)、team/web:リポジトリ、1.4:タグ
  3. Cregistry.example.com:レジストリ、team:リポジトリ、web:タグ、1.4:起動するコンテナの名前
答えと解説を見る

正解：B. registry.example.com:レジストリ(イメージを保管するサーバ)、team/web:リポジトリ、1.4:タグ

イメージの指定は「レジストリ/リポジトリ:タグ」の形で、レジストリはイメージを保管して配るサーバ、リポジトリは同じ種類のイメージをまとめたもの、タグは版などを表す名前で、この例では registry.example.com がレジストリ、team/web がリポジトリ、1.4 がタグです。レジストリを省くと既定のレジストリ(Docker Hub)が、タグを省くと latest が使われます。タグは利用者が付ける名前で、同じタグを後から別のイメージに付け替えることもできます。中身が変われば必ず変わる識別子は sha256 で始まるダイジェストで、@ の後ろに書いて指定します。

  • A. 1.4 は利用者が付けたタグです。ダイジェストは「@sha256:…」の形で指定します。
  • B. 正しい。レジストリ、リポジトリ、タグの順に並んでいます。
  • C. team/web 全体がリポジトリの名前で、1.4 はタグです。コンテナの名前は docker run のときに付けます。

クラウドとコンテナの基礎のほかの問題

  1. scratch は、ファイルを何も含まない空のイメージである。上のマルチステージビルドのDockerfileで作った最終のイメージに含まれるものとして、正しいものはどれか。
  2. Kubernetesで、デプロイして管理する最小の単位であり、1つ以上のコンテナをまとめて、同じIPアドレスやボリュームを共有させるものはどれか。
  3. Kubernetesで、replicas: 3 を指定したDeploymentのPodが3つ動いている。このうち1つのPodを kubectl delete pod で削除したときに起きることとして、正しいものはどれか。
  4. KubernetesのDeploymentで、Podのテンプレートのコンテナイメージを新しい版に変更した。既定の更新方式(RollingUpdate)で起きることとして、正しいものはどれか。
  5. replicas: 10 のDeploymentで、ローリングアップデートの設定を maxSurge: 25%、maxUnavailable: 25% とした。更新の途中の、Podの総数の上限と、利用可能なPodの数の下限の組み合わせとして、正しいものはどれか。
