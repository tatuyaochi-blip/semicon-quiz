クラウドとコンテナの基礎

KubernetesのSecretに、データベースのパスワードを保存する。Secretの説明として、正しいものはどれか。

  1. ASecretに入れた値は自動的に強い暗号で暗号化されるので、クラスタの中のだれが読み出しても、元のパスワードは分からない
  2. BSecretの値はコンテナから参照できないので、パスワードはイメージの中の設定ファイルに書いておく必要がある
  3. C値は既定ではBase64で表されているだけで暗号化ではないので、読める利用者の制限や、保存するときの暗号化を合わせて使う
答えと解説を見る

正解：C. 値は既定ではBase64で表されているだけで暗号化ではないので、読める利用者の制限や、保存するときの暗号化を合わせて使う

Secretは、パスワードやAPIのキーのような機密の値を、イメージやPodの定義から切り離して管理し、環境変数やファイルとしてコンテナに渡すためのリソースです。ただし、マニフェストに書く値はBase64で表しているだけで、だれでも元に戻せます。また、既定では、クラスタの情報を保存する etcd に暗号化されずに保存されます。そのため、RBACでSecretを読める利用者を絞り、etcd に保存するときの暗号化を有効にするなどの対策を合わせて行います。

  • A. Base64は符号化で、暗号化ではありません。読む権限があれば、だれでも元の値に戻せます。
  • B. Secretは、環境変数やファイルとしてコンテナに渡せます。パスワードをイメージに書くと、イメージを取得できる人に知られてしまいます。
  • C. 正しい。Base64は暗号化ではないので、権限の制限や保存時の暗号化と組み合わせます。

クラウドとコンテナの基礎のほかの問題

  1. あるWebアプリケーションは、起動してからキャッシュを読み込むまでの約60秒間は要求を処理できず、その間は /ready に503を返す。Podのコンテナに上の設定を加えたときの効果として、正しいものはどれか。
  2. KubernetesのWebアプリケーションで、livenessプローブの確認の処理の中で、依存先のデータベースに接続できるかまで調べるようにした。この設定で起こりうる問題として、最も適切なものはどれか。
  3. KubernetesのHorizontalPodAutoscalerで、PodのCPU使用率の目標を70%、Podの数の範囲を1〜10とした。いま5つのPodの平均のCPU使用率が30%である。必要なPodの数を ⌈現在の数 × 現在の使用率 ÷ 目標の使用率⌉(⌈ ⌉ は切り上げ)で求めるとき、必要なPodの数として、正しいものはどれか。
  4. Podのコンテナに上の設定をしたDeploymentで、Podが4つ動いており、どのPodもCPUを400m(0.4コア)ずつ使っている。HorizontalPodAutoscalerのCPU使用率の目標を60%とし、必要なPodの数は ⌈現在の数 × 現在の使用率 ÷ 目標の使用率⌉ で求めるものとする。必要なPodの数として、正しいものはどれか。
  5. Kubernetesで、コンテナに設定する資源の requests と limits の説明として、正しいものはどれか。
