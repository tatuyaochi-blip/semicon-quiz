クラウドとコンテナの基礎

ある仮想マシンは、使った時間だけ払うオンデマンドでは1時間あたり50円、1年分の利用を前もって約束する予約では、使った時間にかかわらず1年で262,800円かかる(どちらも架空の価格)。1年を8,760時間とすると、1年間の利用時間がある時間を超えたときに、予約の方が安くなる。その時間として、正しいものはどれか。

  1. A3,504時間(1年の40%)
  2. B5,256時間(1年の60%)
  3. C8,760時間(1年の100%)
答えと解説を見る

正解：B. 5,256時間(1年の60%)

予約の料金は利用時間によらず262,800円で、オンデマンドの料金は 50円 × 利用時間 なので、両者が等しくなるのは 262,800 ÷ 50 = 5,256時間です。これは 5,256 ÷ 8,760 = 60% に当たり、1年の60%より長く使うなら予約の方が安くなります。予約を1時間あたりに直すと 262,800 ÷ 8,760 = 30円で、オンデマンドより40%安い計算です。常に動かすサーバは予約、負荷に合わせて増やす分はオンデマンドのように使い分けることがよくあります。

  • A. 予約の割引率(30円は50円より40%安い)を、利用時間の割合と取り違えた値です。
  • B. 正しい。262,800 ÷ 50 = 5,256時間で、1年の60%です。
  • C. 1年中使わなければ予約が得にならないわけではありません。5,256時間を超えれば、予約の方が安くなります。

クラウドとコンテナの基礎のほかの問題

  1. 多くのパブリッククラウドのデータ転送の料金の考え方として、一般に当てはまるものはどれか。
  2. 宣言的なIaC(Infrastructure as Code)のツールで、ネットワークと仮想マシン2台の構成を定義したファイルを適用して、環境を作った。その直後に、何も変えずに同じファイルをもう一度適用したときに起きることとして、適切なものはどれか。
  3. イミュータブルインフラストラクチャの考え方に沿った、本番のサーバのソフトウェアの更新の方法として、適切なものはどれか。
  4. 本番と同じ構成の環境を2つ用意し、一方で現在の版を動かしたまま、もう一方に新しい版を入れて確かめてから、ロードバランサの向き先を一度に切り替える。問題があれば、向き先を戻してすぐに元の版に戻す。このリリースの方法はどれか。
  5. 1時間に12,000件の要求を受けるサービスで、新しい版をカナリアリリースし、要求の5%だけを新しい版に送った。新しい版には、受けた要求の3%が失敗する不具合があり、1時間後に気づいて、すべての要求を元の版に戻した。この1時間に不具合で失敗した要求の件数として、正しいものはどれか。
