クラウドとコンテナの基礎

サーバーレスの関数(FaaS)で、しばらく呼び出されていなかった関数の最初の呼び出しだけ、応答が数百ミリ秒から数秒遅くなることがある。この現象の説明として、正しいものはどれか。

  1. A最初の呼び出しの結果がキャッシュされ、2回目以降は関数のコードが実行されずに、保存した結果だけが返されるため
  2. B関数を実行する環境を新しく用意し、言語の実行環境の起動や初期化の処理を行う時間がかかるため(コールドスタート)
  3. C最初の呼び出しでは、関数のコードが利用者の端末に送られ、端末の上でコンパイルされてから実行されるため
答えと解説を見る

正解：B. 関数を実行する環境を新しく用意し、言語の実行環境の起動や初期化の処理を行う時間がかかるため(コールドスタート)

サーバーレスの関数では、事業者が実行環境(コンテナや軽量の仮想マシンなど)を必要に応じて用意し、しばらく使われないと片付けます。片付けられた後の最初の呼び出しでは、環境の用意、言語の実行環境の起動、関数の初期化の処理が必要になり、その分だけ応答が遅くなります。続けて呼び出されると、用意された環境が再利用されるので速くなります(ウォームスタート)。対策として、初期化の処理や読み込むライブラリを軽くする、あらかじめ一定数の環境を用意しておく設定を使う、などがあります。

  • A. 関数の結果が自動でキャッシュされることはなく、呼び出しのたびにコードが実行されます。
  • B. 正しい。実行環境の用意と初期化の時間が、最初の呼び出しに加わります。
  • C. 関数はクラウドの側の実行環境で動きます。利用者の端末に送られて実行されるわけではありません。

クラウドとコンテナの基礎のほかの問題

  1. クラウドのストレージを、①仮想マシンにディスクとして接続してファイルシステムを作り、データベースのデータファイルを置く、②複数のサーバから同時にマウントして共有のディレクトリとして使う、③HTTPのAPIでキー(名前)を指定して大量の画像を読み書きし、容量を前もって決めずに増やす、という3つの用途で使う。①〜③に適したストレージの種類の組み合わせとして、適切なものはどれか。
  2. 1時間あたり40円(架空の単価)で、使った時間だけ料金がかかる仮想マシンを使う。平常時は2台を1か月(30日)の間ずっと動かし、平日の20日は、毎日6時間だけ負荷に合わせて4台を追加する。1か月の料金として、正しいものはどれか。
  3. ある仮想マシンは、使った時間だけ払うオンデマンドでは1時間あたり50円、1年分の利用を前もって約束する予約では、使った時間にかかわらず1年で262,800円かかる(どちらも架空の価格)。1年を8,760時間とすると、1年間の利用時間がある時間を超えたときに、予約の方が安くなる。その時間として、正しいものはどれか。
  4. 多くのパブリッククラウドのデータ転送の料金の考え方として、一般に当てはまるものはどれか。
  5. 宣言的なIaC(Infrastructure as Code)のツールで、ネットワークと仮想マシン2台の構成を定義したファイルを適用して、環境を作った。その直後に、何も変えずに同じファイルをもう一度適用したときに起きることとして、適切なものはどれか。

この分野の比較

  • 仮想マシンとコンテナの違い：仮想化する層・カーネル・起動の速さ・隔離の強さ・使い分けを比較仮想マシンとコンテナを、仮想化する層・OSのカーネル・動かせるOS・イメージの大きさ・起動の速さ・隔離の強さ・資源の効率・主な用途の観点で表にして比較します。
  • IaaS・PaaS・SaaSの違い：提供される範囲・利用者が管理するもの・自由度・運用の手間を比較IaaS・PaaS・SaaSを、事業者が提供するもの・利用者が管理するもの・自由度・運用の手間・主な利用者・料金の考え方・責任共有モデルでの分担・代表的な例の観点で表にして比較します。
