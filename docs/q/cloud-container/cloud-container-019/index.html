クラウドとコンテナの基礎

Kubernetesのクラスタで、1つのホスト名に届いたHTTPSの要求のうち、パスが /api で始まるものは api のServiceへ、それ以外は web のServiceへ振り分けたい。この振り分けの規則を定めるのに適したリソースはどれか。

  1. AIngress
  2. BReplicaSet
  3. Ctype: ClusterIP のService
答えと解説を見る

正解：A. Ingress

Ingressは、ホスト名やURLのパスに応じて、クラスタの外から来たHTTPやHTTPSの要求を各Serviceに振り分ける規則を定めるリソースで、TLSの終端もここで設定できます。実際に要求を受けて振り分けるのは、クラスタに導入したIngressコントローラ(リバースプロキシとして動くもの)です。type: ClusterIP のServiceはクラスタの中からだけ使える接続先で、パスで振り分ける機能はもちません。ReplicaSetはPodの数を保つためのもので、通信の振り分けとは関係しません。

  • A. 正しい。ホスト名やパスで、要求をServiceに振り分けます。
  • B. ReplicaSetは、指定した数のPodが動いている状態を保つものです。
  • C. ClusterIP のServiceはクラスタの中の接続先で、URLのパスを見て振り分けることはしません。

クラウドとコンテナの基礎のほかの問題

  1. KubernetesのSecretに、データベースのパスワードを保存する。Secretの説明として、正しいものはどれか。
  2. あるWebアプリケーションは、起動してからキャッシュを読み込むまでの約60秒間は要求を処理できず、その間は /ready に503を返す。Podのコンテナに上の設定を加えたときの効果として、正しいものはどれか。
  3. KubernetesのWebアプリケーションで、livenessプローブの確認の処理の中で、依存先のデータベースに接続できるかまで調べるようにした。この設定で起こりうる問題として、最も適切なものはどれか。
  4. KubernetesのHorizontalPodAutoscalerで、PodのCPU使用率の目標を70%、Podの数の範囲を1〜10とした。いま5つのPodの平均のCPU使用率が30%である。必要なPodの数を ⌈現在の数 × 現在の使用率 ÷ 目標の使用率⌉(⌈ ⌉ は切り上げ)で求めるとき、必要なPodの数として、正しいものはどれか。
  5. Podのコンテナに上の設定をしたDeploymentで、Podが4つ動いており、どのPodもCPUを400m(0.4コア)ずつ使っている。HorizontalPodAutoscalerのCPU使用率の目標を60%とし、必要なPodの数は ⌈現在の数 × 現在の使用率 ÷ 目標の使用率⌉ で求めるものとする。必要なPodの数として、正しいものはどれか。
