クラウドとコンテナの基礎

クラウドのマネージドなデータベースサービス(事業者がデータベースのソフトウェアを運用するサービス)を使う。責任共有モデルの考え方で、一般に利用者の責任として残るものはどれか。

  1. Aデータベースを動かすサーバのOSと、データベースのソフトウェアに、セキュリティの修正を適用すること
  2. Bデータセンターの建物や、サーバなどの物理的な機器を、故障や侵入から守ること
  3. Cデータベースの利用者のアカウントと権限、接続を許可するネットワークの範囲、保存するデータを管理すること
答えと解説を見る

正解：C. データベースの利用者のアカウントと権限、接続を許可するネットワークの範囲、保存するデータを管理すること

責任共有モデルでは、クラウドの事業者と利用者がセキュリティと運用の責任を分け合い、その境目はサービスの形態によって変わります。マネージドなデータベースサービスでは、物理的な設備に加えて、OSやデータベースのソフトウェアの更新も事業者が受け持ちます。一方、だれにどのデータへのアクセスを許すか、どのネットワークからの接続を許すか、どんなデータを保存するかは、どの形態でも利用者の責任として残ります。設定を誤ってデータベースをインターネットに公開してしまう事故は、利用者の側の問題です。

  • A. マネージドなサービスでは、OSやデータベースのソフトウェアの更新は、一般に事業者が行います。
  • B. 物理的な設備の管理は、どのサービスの形態でも事業者の責任です。
  • C. 正しい。アクセスの権限、接続の許可、データの管理は利用者に残ります。

クラウドとコンテナの基礎のほかの問題

  1. クラウドで、同じリージョンの中の複数のアベイラビリティゾーンに、Webサーバとデータベースの複製を分けて置く主な目的として、適切なものはどれか。
  2. サーバーレスの関数(FaaS)で、しばらく呼び出されていなかった関数の最初の呼び出しだけ、応答が数百ミリ秒から数秒遅くなることがある。この現象の説明として、正しいものはどれか。
  3. クラウドのストレージを、①仮想マシンにディスクとして接続してファイルシステムを作り、データベースのデータファイルを置く、②複数のサーバから同時にマウントして共有のディレクトリとして使う、③HTTPのAPIでキー(名前)を指定して大量の画像を読み書きし、容量を前もって決めずに増やす、という3つの用途で使う。①〜③に適したストレージの種類の組み合わせとして、適切なものはどれか。
  4. 1時間あたり40円(架空の単価)で、使った時間だけ料金がかかる仮想マシンを使う。平常時は2台を1か月(30日)の間ずっと動かし、平日の20日は、毎日6時間だけ負荷に合わせて4台を追加する。1か月の料金として、正しいものはどれか。
  5. ある仮想マシンは、使った時間だけ払うオンデマンドでは1時間あたり50円、1年分の利用を前もって約束する予約では、使った時間にかかわらず1年で262,800円かかる(どちらも架空の価格)。1年を8,760時間とすると、1年間の利用時間がある時間を超えたときに、予約の方が安くなる。その時間として、正しいものはどれか。
