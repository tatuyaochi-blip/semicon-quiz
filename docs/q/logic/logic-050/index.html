論理回路

オープンドレイン出力の回路を複数、プルアップ抵抗のある1本の信号線につないだときの動作として正しいものはどれか。

  1. Aどれか1つでも0を出すと線が0になり、ワイヤードANDとして働く
  2. Bどれか1つでも1を出すと線が1になる
  3. C出力どうしが衝突して必ず壊れる
答えと解説を見る

正解：A. どれか1つでも0を出すと線が0になり、ワイヤードANDとして働く

オープンドレイン出力は、トランジスタで線をグラウンドに引き下げるか、切り離すかの2状態をとります。1の状態はプルアップ抵抗が作ります。そのため、どれか1つでも0を出すと線は0になり、すべてが切り離したときだけ1になるワイヤードANDとして働きます。I²Cや割り込み線などに使われます。

  • A. 正しい。1つでも0なら0になるワイヤードANDです。
  • B. オープンドレインは1を能動的に出さないので、1が優先されることはありません。
  • C. 引き下げるだけなので、出力どうしが衝突しても壊れません。
