論理回路

オープンドレイン出力の回路を複数、プルアップ抵抗のある1本の信号線につないだときの動作として正しいものはどれか。

  1. A出力どうしが衝突して必ず壊れる
  2. Bどれか1つでも0を出すと線が0になり、ワイヤードANDとして働く
  3. Cどれか1つでも1を出すと線が1になる
答えと解説を見る

正解：B. どれか1つでも0を出すと線が0になり、ワイヤードANDとして働く

オープンドレイン出力は、トランジスタで線をグラウンドに引き下げるか切り離すかの2状態で、1はプルアップ抵抗が作ります。どれか1つでも0を出すと線は0になり、全員が切り離したときだけ1になるワイヤードANDとして働き、出力どうしが衝突しても壊れません。I²Cのバスや割り込み線、異なる電源電圧の回路間のレベル変換に使われます。立ち上がりはプルアップ抵抗と配線容量で決まるため遅くなります。

  • A. 引き下げるだけなので、出力どうしが衝突しても壊れません。
  • B. 正しい。1つでも0なら0になるワイヤードANDです。
  • C. オープンドレインは1を能動的に出さないので、1が優先されることはありません。
