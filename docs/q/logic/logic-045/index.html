論理回路

8ビットの2の補数表現で表せる整数の範囲はどれか。

  1. A−128 〜 +127
  2. B−127 〜 +127
  3. C0 〜 255
答えと解説を見る

正解：A. −128 〜 +127

nビットの2の補数では −2ⁿ⁻¹ から 2ⁿ⁻¹ − 1 までを表せます。8ビットでは −128 から +127 です。負の数が1つ多いのは、0が1通りの表現しかもたないためです。0〜255は符号なしの8ビットの範囲です。

  • A. 正しい。−2⁷ 〜 2⁷ − 1 です。
  • B. −127 〜 +127 は、0が2通りある符号と絶対値の表現などの範囲です。
  • C. 0 〜 255 は符号なし8ビットの範囲です。

  5. オープンドレイン出力の回路を複数、プルアップ抵抗のある1本の信号線につないだときの動作として正しいものはどれか。
