論理回路

すべてのフリップフロップが共通のクロックで動作する同期式回路の利点として正しいものはどれか。

  1. A消費電力が必ず0になる
  2. Bタイミングの設計と検証がしやすい
  3. Cクロックが不要になる
答えと解説を見る

正解：B. タイミングの設計と検証がしやすい

同期式回路では、データがクロックのエッジでそろって更新されるため、フリップフロップ間の遅延がクロック周期に収まっているか(セットアップ)と、速すぎないか(ホールド)を確認すれば正しく動作します。この検証は静的タイミング解析(STA)で全経路を網羅的に行えるため、数十億トランジスタの回路でも設計できます。非同期式は省電力の利点がありますが、設計と検証が難しく用途は限られます。

論理回路のほかの問題

  1. 同期式回路で、動作できる最大のクロック周波数を決めるものはどれか。
  2. 組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。
  3. 2入力ANDゲートの出力が1になるのはどのときか。
  4. 2入力ORゲートの出力が0になるのはどのときか。
  5. NOTゲート(インバータ)の働きとして正しいものはどれか。
