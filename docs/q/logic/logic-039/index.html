論理回路

クロックが入るたびに出力が反転するTフリップフロップ1個の出力の周波数は、クロック周波数の何倍になるか。

  1. A2倍
  2. B1/2倍
  3. C1/4倍
答えと解説を見る

正解：B. 1/2倍

Tフリップフロップは(T = 1のとき)クロックの立ち上がりごとに出力が反転するので、出力は2クロックで1周期になり、周波数はクロックの1/2になります。これを直列につなぐと、1/4、1/8…の分周回路やバイナリカウンタになります。

  • A. フリップフロップで周波数を2倍にすることはできません。
  • B. 正しい。2クロックで1周期なので1/2になります。
  • C. 1/4にするにはTフリップフロップを2段つなぎます。
