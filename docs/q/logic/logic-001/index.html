論理回路

2入力NANDゲートの出力が0になるのはどのときか。

  1. A2つの入力がともに1のとき
  2. B少なくとも一方の入力が0のとき
  3. C2つの入力がともに0のとき
答えと解説を見る

正解：A. 2つの入力がともに1のとき

NANDはANDの否定です。ANDの出力が1になるのは入力がすべて1のときだけなので、NANDの出力が0になるのも入力がすべて1のときだけです。それ以外の組み合わせでは出力は1になります。
