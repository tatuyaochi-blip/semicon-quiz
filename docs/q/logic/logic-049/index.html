論理回路

シフトレジスタの一部の出力のXORを入力に戻す線形帰還シフトレジスタ(LFSR)の代表的な用途はどれか。

  1. A正確な時刻を計る
  2. Bアナログ信号を増幅する
  3. C疑似乱数パターンの生成や、テストでのパターン生成・CRC計算
答えと解説を見る

正解：C. 疑似乱数パターンの生成や、テストでのパターン生成・CRC計算

LFSRは、適切な帰還(タップ)を選ぶと、nビットで 2ⁿ − 1 通りの状態を巡回する、一見ランダムな系列を生成します。少ない回路で実現できるため、内蔵テスト(BIST)のパターン生成、CRCの計算、スクランブラなどに使われます。

  • A. 時刻を正確に計る用途ではありません。
  • B. LFSRはデジタル回路で、アナログ信号の増幅はしません。
  • C. 正しい。疑似乱数やテストパターン、CRCに使われます。

  2. 2入力NANDゲートの出力が0になるのはどのときか。
  3. ド・モルガンの定理によれば、NOT(A AND B) と等しい論理式はどれか。
  4. D型フリップフロップの動作として正しいものはどれか。
  5. 2入力XOR(排他的論理和)ゲートの出力が1になるのはどのときか。
