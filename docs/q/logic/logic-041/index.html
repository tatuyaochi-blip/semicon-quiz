論理回路

全加算器を直列につないだリプルキャリー加算器の欠点として正しいものはどれか。

  1. A負の数を扱えない
  2. B桁上げが下位から順に伝わるため、ビット数に比例して遅延が大きくなる
  3. Cビット数が増えても回路の規模が変わらない
答えと解説を見る

正解：B. 桁上げが下位から順に伝わるため、ビット数に比例して遅延が大きくなる

リプルキャリー加算器では、各ビットの全加算器が下位からの桁上げを待ってから計算するため、桁上げが最下位から最上位まで順に伝わります。そのためビット数に比例して遅延が増えます。高速化には桁上げ先見加算器などが使われます。

  • A. 2の補数を使えば負の数も同じ回路で扱えます。
  • B. 正しい。桁上げの伝搬で遅延がビット数に比例します。
  • C. ビット数が増えれば全加算器の数も増え、回路は大きくなります。
