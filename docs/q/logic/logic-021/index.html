論理回路

全加算器の入力として正しい組み合わせはどれか。

  1. A加える2つのビットと、下位の桁からの桁上げ
  2. B加える2つのビットだけ
  3. Cクロック信号だけ
答えと解説を見る

正解：A. 加える2つのビットと、下位の桁からの桁上げ

全加算器は、加える2つのビットA、Bと下位からの桁上げCinの3入力から、和と上位への桁上げを出力します。nビットの加算には全加算器をn個つなぎます(リップルキャリー加算器)。最下位のCinを1にしてBを反転すれば A − B = A + (¬B + 1) となり、同じ回路で減算もできます。この性質によりCPUのALUは1つの加算器で加減算を兼ねています。

論理回路のほかの問題

  1. 3ビットの入力に応じて、8本の出力のうち1本だけを有効にする回路はどれか。
  2. フリップフロップを直列につなぎ、クロックごとにデータを1ビットずつ隣へ移すシフトレジスタの代表的な用途はどれか。
  3. 2進数を1ビット左にシフトすると、値はどうなるか。(桁あふれがない場合)
  4. 7ビットのデータ 1011001 に偶数パリティのビットを付けるとき、パリティビットの値はどれか。
  5. 2入力NORゲートの出力が1になるのはどのときか。
