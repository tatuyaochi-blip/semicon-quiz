論理回路

2進数を1ビット左にシフトすると、値はどうなるか。(桁あふれがない場合)

  1. A2倍になる
  2. B半分になる
  3. C1だけ増える
答えと解説を見る

正解：A. 2倍になる

2進数では各桁が2倍ずつの重みをもつため、全体を1ビット左にずらして最下位に0を入れると、値は2倍になります。右に1ビットずらすと半分(切り捨て)になります。このため、2のべき乗の掛け算や割り算はシフト演算で高速に行えます。
