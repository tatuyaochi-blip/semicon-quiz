論理回路

グレイコードの特徴として正しいものはどれか。

  1. A10進数の各桁を4ビットで表す符号
  2. Bパリティビットで誤りを検出する符号
  3. C隣り合う値の間で1ビットだけが変化する符号
答えと解説を見る

正解：C. 隣り合う値の間で1ビットだけが変化する符号

グレイコードは、隣り合う値の間で必ず1ビットだけが変化する符号です。複数のビットが同時に変わらないため、ロータリーエンコーダの位置検出や、異なるクロックの回路間でカウンタの値を受け渡すときに誤りが起きにくくなります。10進数の各桁を4ビットで表すのはBCDです。

この分野を解く 分野ページへ

論理回路のほかの問題

  1. Dラッチの動作の説明として正しいものはどれか。
  2. 非同期の信号をフリップフロップで受けたときに、セットアップ時間やホールド時間を満たせず、出力が一時的に0とも1とも定まらなくなる状態を何と呼ぶか。
  3. 出力が現在の状態だけで決まる順序回路(ステートマシン)の型はどれか。
  4. 10進数の59をBCD(2進化10進数)で表したものはどれか。
  5. 3入力の多数決回路の出力が1になる条件として正しいものはどれか。
