論理回路

複数の入力が同時に1になったとき、最も優先度の高い入力の番号を2進数で出力する回路はどれか。

  1. Aプライオリティエンコーダ
  2. Bデマルチプレクサ
  3. Cコンパレータ
答えと解説を見る

正解：A. プライオリティエンコーダ

エンコーダはどの入力が1かを2進数のコードに変換する回路で、普通のエンコーダは1つの入力だけが1であることを前提にしています。プライオリティエンコーダは複数の入力が同時に1でも、最も優先度の高い入力の番号を出力し、有効な入力があるかどうかを示す信号も出します。割り込みコントローラでの要求の選択や、浮動小数点の正規化での先頭の1の位置検出(リーディングゼロ検出)に使われます。

  • A. 正しい。優先度の高い入力の番号を出力します。
  • B. デマルチプレクサは、1つの入力を選んだ出力先に振り分ける回路です。
  • C. コンパレータは2つの値の大小や一致を比べる回路です。

論理回路のほかの問題

  1. 全加算器を直列につないだリプルキャリー加算器の欠点として正しいものはどれか。
  2. フリップフロップのホールド時間の説明として正しいものはどれか。
  3. 同期式回路の「クロックスキュー」の説明として正しいものはどれか。
  4. トライステートバッファの出力がとりうる3つ目の状態はどれか。
  5. 8ビットの2の補数表現で表せる整数の範囲はどれか。

この分野の比較

  • ラッチとフリップフロップの違い：動作と使い分けを比較ラッチとフリップフロップを、トリガー・出力の動き・構成・大きさ・タイミング解析・グリッチ・デジタル設計での使い分けの観点で表にして比較します。
  • 組み合わせ回路と順序回路の違い：出力の決まり方を比較組み合わせ回路と順序回路を、出力が何で決まるか・記憶素子・クロック・フィードバック・例・タイミング・HDLでの書き方の観点で表にして比較します。
  • CMOSとTTLの違い：論理ICのファミリーを比較CMOSとTTLの論理ICを、トランジスタ・静的消費電力・電源電圧・論理レベル・ノイズマージン・速度・入力・使われる場所の観点で表にして比較します。
