論理回路

複数の入力が同時に1になったとき、最も優先度の高い入力の番号を2進数で出力する回路はどれか。

  1. Aプライオリティエンコーダ
  2. Bデマルチプレクサ
  3. Cコンパレータ
答えと解説を見る

正解：A. プライオリティエンコーダ

エンコーダは、どの入力が1かを2進数のコードに変換する回路です。プライオリティエンコーダは、複数の入力が同時に1になっても、優先度の最も高い入力の番号を出力します。割り込み要求の処理などに使われます。

  • A. 正しい。優先度の高い入力の番号を出力します。
  • B. デマルチプレクサは、1つの入力を選んだ出力先に振り分ける回路です。
  • C. コンパレータは2つの値の大小や一致を比べる回路です。
