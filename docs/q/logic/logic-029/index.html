論理回路

同期式回路で、動作できる最大のクロック周波数を決めるものはどれか。

  1. A最も遅延の小さい経路の遅延
  2. B電源電圧だけ
  3. Cフリップフロップ間で最も遅延の大きい経路(クリティカルパス)の遅延
答えと解説を見る

正解：C. フリップフロップ間で最も遅延の大きい経路(クリティカルパス)の遅延

クロック周期は、フリップフロップから出たデータが、論理回路を通って次のフリップフロップに届き、セットアップ時間を満たすまでの時間より長くなければなりません。そのため、最も遅延の大きい経路(クリティカルパス)が最大のクロック周波数を決めます。

  2. 2入力NANDゲートの出力が0になるのはどのときか。
  3. ド・モルガンの定理によれば、NOT(A AND B) と等しい論理式はどれか。
  4. D型フリップフロップの動作として正しいものはどれか。
  5. 2入力XOR(排他的論理和)ゲートの出力が1になるのはどのときか。
