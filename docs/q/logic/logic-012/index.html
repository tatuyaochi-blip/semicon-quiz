論理回路

カルノー図の主な用途はどれか。

  1. A回路の遅延時間を測る
  2. Bアナログフィルタを設計する
  3. C論理式を簡単化する
答えと解説を見る

正解：C. 論理式を簡単化する

カルノー図は、真理値表を、隣り合うマスの入力が1ビットだけ異なるように並べた図です。1が隣り合うマスをまとめることで、論理式を視覚的に簡単化できます。入力変数が4つ程度までの手作業での簡単化に便利です。

論理回路のほかの問題

  1. フリップフロップのセットアップ時間の説明として正しいものはどれか。
  2. 4ビットのバイナリカウンタが表すことのできる状態の数はいくつか。
  3. グレイコードの特徴として正しいものはどれか。
  4. Dラッチの動作の説明として正しいものはどれか。
  5. 非同期の信号をフリップフロップで受けたときに、セットアップ時間やホールド時間を満たせず、出力が一時的に0とも1とも定まらなくなる状態を何と呼ぶか。
