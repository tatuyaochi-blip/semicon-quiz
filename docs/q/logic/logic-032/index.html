論理回路

2入力ORゲートの出力が0になるのはどのときか。

  1. A2つの入力が異なるとき
  2. B2つの入力がどちらも0のとき
  3. C2つの入力がどちらも1のとき
答えと解説を見る

正解：B. 2つの入力がどちらも0のとき

ORゲート(論理和)は少なくとも1つの入力が1なら出力が1になり、0になるのはすべての入力が0のときだけです。並列につないだスイッチと同じで、「どれか1つでも条件を満たせば動く」制御に使われます。例えば複数の割り込み要求をまとめる回路や、ビット演算で特定のビットを1にする操作(x OR 0x80で最上位ビットを1に)に使われます。

  • A. 入力が異なるとき、ORの出力は1です。
  • B. 正しい。ORはすべての入力が0のときだけ0を出します。
  • C. 両方1のときORの出力は1です。
