論理回路

非同期の信号をフリップフロップで受けたときに、セットアップ時間やホールド時間を満たせず、出力が一時的に0とも1とも定まらなくなる状態を何と呼ぶか。

  1. Aメタステーブル
  2. Bグリッチ
  3. Cラッチアップ
答えと解説を見る

正解：A. メタステーブル

メタステーブル状態では、出力が中間電圧にとどまったり、定まるまでに長い時間がかかったりします。原理的に完全には防げず、解消までの時間に対して確率が指数関数的に減るだけです。そのため非同期信号はフリップフロップを2段以上つないだ同期化回路で受け、1段目で不定になっても2段目までに確定する確率を十分高めます(平均故障間隔を数千年以上に)。多ビットのデータはFIFOやハンドシェイクで受け渡します。

論理回路のほかの問題

  1. 出力が現在の状態だけで決まる順序回路(ステートマシン)の型はどれか。
  2. 10進数の59をBCD(2進化10進数)で表したものはどれか。
  3. 3入力の多数決回路の出力が1になる条件として正しいものはどれか。
  4. 全加算器の入力として正しい組み合わせはどれか。
  5. 3ビットの入力に応じて、8本の出力のうち1本だけを有効にする回路はどれか。

この分野の比較

  • ラッチとフリップフロップの違い：動作と使い分けを比較ラッチとフリップフロップを、トリガー・出力の動き・構成・大きさ・タイミング解析・グリッチ・デジタル設計での使い分けの観点で表にして比較します。
  • 組み合わせ回路と順序回路の違い：出力の決まり方を比較組み合わせ回路と順序回路を、出力が何で決まるか・記憶素子・クロック・フィードバック・例・タイミング・HDLでの書き方の観点で表にして比較します。
  • CMOSとTTLの違い：論理ICのファミリーを比較CMOSとTTLの論理ICを、トランジスタ・静的消費電力・電源電圧・論理レベル・ノイズマージン・速度・入力・使われる場所の観点で表にして比較します。
