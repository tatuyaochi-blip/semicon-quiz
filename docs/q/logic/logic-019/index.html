論理回路

10進数の59をBCD(2進化10進数)で表したものはどれか。

  1. A0011 1011
  2. B0101 1010
  3. C0101 1001
答えと解説を見る

正解：C. 0101 1001

BCDでは10進数の各桁をそれぞれ4ビットで表し、5は0101、9は1001なので、59は 0101 1001 です。4ビットのうち1010〜1111の6通りは使わないため効率は落ちますが、10進の表示(7セグメントLED)や金額の計算で、2進⇔10進の変換誤差なく扱えるのが利点です。0011 1011 は59を通常の2進数(00111011)で表したもので、桁ごとの区切りとは対応しません。
