論理回路

n個のフリップフロップで構成したジョンソンカウンタ(ツイストリングカウンタ)がとる状態の数はいくつか。

  1. An
  2. B2n
  3. C2ⁿ
答えと解説を見る

正解：B. 2n

ジョンソンカウンタは、シフトレジスタの最後の出力を反転して先頭に戻す構成で、n個のフリップフロップで2n個の状態を順にとります。隣り合う状態で1ビットしか変わらないため、デコードが簡単でグリッチが起きにくい特徴があります。

  • A. n個の状態をとるのは、1を循環させるリングカウンタです。
  • B. 正しい。ジョンソンカウンタは2n個の状態をとります。
  • C. 2ⁿ 個の状態をとるのはバイナリカウンタです。

  4. ド・モルガンの定理によれば、NOT(A AND B) と等しい論理式はどれか。
