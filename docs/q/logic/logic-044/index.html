論理回路

トライステートバッファの出力がとりうる3つ目の状態はどれか。

  1. A電源電圧の半分の電圧を出す状態
  2. B0と1を高速に繰り返す状態
  3. C出力を切り離して高インピーダンスにする状態
答えと解説を見る

正解：C. 出力を切り離して高インピーダンスにする状態

トライステートバッファは、0と1に加えて、出力を回路から切り離した高インピーダンス(Hi-Z)状態をとれます。複数の回路が1本のバスを共有するとき、使わない回路の出力を高インピーダンスにしておくことで、信号の衝突を防ぎます。

  • A. 中間の電圧を出し続ける状態ではありません。
  • B. 発振させる状態ではありません。
  • C. 正しい。3つ目の状態は高インピーダンスです。
