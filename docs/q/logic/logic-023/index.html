論理回路

フリップフロップを直列につなぎ、クロックごとにデータを1ビットずつ隣へ移すシフトレジスタの代表的な用途はどれか。

  1. A交流の整流
  2. B発振
  3. Cシリアルデータとパラレルデータの変換
答えと解説を見る

正解：C. シリアルデータとパラレルデータの変換

シフトレジスタは、1本の線から順に入ってくるシリアルデータを蓄えてまとめてパラレルに取り出したり、その逆を行ったりできます。高速の通信インターフェース(SerDes)はこの変換を数十Gb/sで行い、配線の本数を減らしています。そのほか、LEDの多数個制御(74HC595)、遅延線、半導体のテストでフリップフロップを数珠つなぎにするスキャンチェーンにも使われます。

論理回路のほかの問題

  1. 2進数を1ビット左にシフトすると、値はどうなるか。(桁あふれがない場合)
  2. 7ビットのデータ 1011001 に偶数パリティのビットを付けるとき、パリティビットの値はどれか。
  3. 2入力NORゲートの出力が1になるのはどのときか。
  4. 論理式 A + A・B を簡単化した結果はどれか。
  5. すべてのフリップフロップが共通のクロックで動作する同期式回路の利点として正しいものはどれか。

この分野の比較

  • ラッチとフリップフロップの違い：動作と使い分けを比較ラッチとフリップフロップを、トリガー・出力の動き・構成・大きさ・タイミング解析・グリッチ・デジタル設計での使い分けの観点で表にして比較します。
  • 組み合わせ回路と順序回路の違い：出力の決まり方を比較組み合わせ回路と順序回路を、出力が何で決まるか・記憶素子・クロック・フィードバック・例・タイミング・HDLでの書き方の観点で表にして比較します。
  • CMOSとTTLの違い：論理ICのファミリーを比較CMOSとTTLの論理ICを、トランジスタ・静的消費電力・電源電圧・論理レベル・ノイズマージン・速度・入力・使われる場所の観点で表にして比較します。
