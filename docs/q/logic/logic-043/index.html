論理回路

同期式回路の「クロックスキュー」の説明として正しいものはどれか。

  1. Aクロックの周波数が時間とともに変動すること
  2. Bクロック信号がフリップフロップごとに到着する時刻のずれ
  3. Cクロック信号の電圧が電源電圧より高くなること
答えと解説を見る

正解：B. クロック信号がフリップフロップごとに到着する時刻のずれ

クロックスキューは、同じクロックが配線の長さや負荷の違いでフリップフロップごとに異なる時刻に到着するずれです。受け側のクロックが遅れるとセットアップには有利でもホールドには不利になり、逆も同様です。チップ全体に届くクロックツリーをCTS(クロックツリー合成)で設計し、バッファの配置や配線長をそろえてスキューを数十ps以下に抑えます。周期の時間的な揺らぎはジッタです。

  • A. 周波数や周期の時間的な揺らぎはジッタと呼ばれます。
  • B. 正しい。場所によるクロック到着時刻のずれです。
  • C. クロックスキューは電圧の問題ではありません。

論理回路のほかの問題

  1. トライステートバッファの出力がとりうる3つ目の状態はどれか。
  2. 8ビットの2の補数表現で表せる整数の範囲はどれか。
  3. 桁上げ先見(キャリールックアヘッド)加算器が高速な理由として正しいものはどれか。
  4. 2の補数表現の数どうしの加算で、オーバーフロー(桁あふれ)が起きたことを判定する条件として正しいものはどれか。
  5. n個のフリップフロップで構成したジョンソンカウンタ(ツイストリングカウンタ)がとる状態の数はいくつか。

この分野の比較

  • ラッチとフリップフロップの違い：動作と使い分けを比較ラッチとフリップフロップを、トリガー・出力の動き・構成・大きさ・タイミング解析・グリッチ・デジタル設計での使い分けの観点で表にして比較します。
  • 組み合わせ回路と順序回路の違い：出力の決まり方を比較組み合わせ回路と順序回路を、出力が何で決まるか・記憶素子・クロック・フィードバック・例・タイミング・HDLでの書き方の観点で表にして比較します。
  • CMOSとTTLの違い：論理ICのファミリーを比較CMOSとTTLの論理ICを、トランジスタ・静的消費電力・電源電圧・論理レベル・ノイズマージン・速度・入力・使われる場所の観点で表にして比較します。
