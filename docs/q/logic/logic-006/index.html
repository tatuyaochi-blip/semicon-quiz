論理回路

順序回路の説明として正しいものはどれか。

  1. A出力が、現在の入力と、記憶している内部状態によって決まる
  2. B出力が現在の入力だけで決まる
  3. Cアナログ信号だけを扱う
答えと解説を見る

正解：A. 出力が、現在の入力と、記憶している内部状態によって決まる

順序回路は、フリップフロップなどの記憶素子をもち、出力が現在の入力だけでなく過去の入力の履歴(内部状態)にも依存する回路です。カウンタやレジスタ、ステートマシンが代表例です。出力が現在の入力だけで決まる回路は組み合わせ回路といいます。

  4. マルチプレクサの機能として正しいものはどれか。
