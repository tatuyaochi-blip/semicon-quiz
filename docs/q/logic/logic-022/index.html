論理回路

3ビットの入力に応じて、8本の出力のうち1本だけを有効にする回路はどれか。

  1. Aエンコーダ
  2. Bデコーダ
  3. Cカウンタ
答えと解説を見る

正解：B. デコーダ

デコーダは、nビットの入力をもとに、2ⁿ本の出力のうち対応する1本だけを有効にする回路です。メモリのアドレスから行や列を選ぶ回路などに使われます。逆に、有効になった入力の番号を2進数に変換する回路はエンコーダといいます。

  2. 2進数を1ビット左にシフトすると、値はどうなるか。(桁あふれがない場合)
  3. 7ビットのデータ 1011001 に偶数パリティのビットを付けるとき、パリティビットの値はどれか。
  4. 2入力NORゲートの出力が1になるのはどのときか。
  5. 論理式 A + A・B を簡単化した結果はどれか。
