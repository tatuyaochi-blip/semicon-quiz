論理回路

2入力NORゲートの出力が1になるのはどのときか。

  1. A2つの入力がともに1のとき
  2. B2つの入力が異なるとき
  3. C2つの入力がともに0のとき
答えと解説を見る

正解：C. 2つの入力がともに0のとき

NORはORの否定で、出力が1になるのは入力がすべて0のときだけです。NANDと同様にNORだけで任意の論理回路を構成でき、アポロ誘導コンピュータはNORゲートだけで作られました。CMOSではpMOSが直列になるため、移動度の低いpMOSを大きくする必要があり、多入力のNORは遅くなりがちです。NORフラッシュの名前は、セルがビット線に並列につながる構造がNORに似ていることに由来します。

論理回路のほかの問題

  1. 論理式 A + A・B を簡単化した結果はどれか。
  2. すべてのフリップフロップが共通のクロックで動作する同期式回路の利点として正しいものはどれか。
  3. 同期式回路で、動作できる最大のクロック周波数を決めるものはどれか。
  4. 組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。
