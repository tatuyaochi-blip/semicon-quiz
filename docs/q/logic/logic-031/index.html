論理回路

2入力ANDゲートの出力が1になるのはどのときか。

  1. A2つの入力がどちらも1のとき
  2. B2つの入力がどちらも0のとき
  3. Cどちらか一方の入力が1のとき
答えと解説を見る

正解：A. 2つの入力がどちらも1のとき

ANDゲート(論理積)は、すべての入力が1のときだけ出力が1になり、それ以外は0になります。少なくとも1つの入力が1で出力が1になるのはORゲートです。

  • A. 正しい。ANDはすべての入力が1のときだけ1を出します。
  • B. 両方0のときに1になるのはNORゲートです。
  • C. 一方だけが1のときにも1になるのはORゲートです。
