論理回路

7ビットのデータ 1011001 に偶数パリティのビットを付けるとき、パリティビットの値はどれか。

  1. A1
  2. B0
  3. Cデータによらず常に1
答えと解説を見る

正解：B. 0

偶数パリティでは、パリティビットを含めた1の数が偶数になるようにします。1011001には1が4個あり、すでに偶数なのでパリティビットは0です。受信側で1の数が奇数なら1ビットの誤りを検出できますが、2ビット同時の誤りは検出できず、どのビットが誤ったかもわかりません。訂正まで必要なメモリでは、複数のパリティを組み合わせたECC(ハミング符号など)が使われます。

論理回路のほかの問題

  1. 2入力NORゲートの出力が1になるのはどのときか。
  2. 論理式 A + A・B を簡単化した結果はどれか。
  3. すべてのフリップフロップが共通のクロックで動作する同期式回路の利点として正しいものはどれか。
  4. 同期式回路で、動作できる最大のクロック周波数を決めるものはどれか。
  5. 組み合わせ回路で、入力が変化したときに、経路ごとの遅延の差によって出力に一瞬だけ現れる不要なパルスを何と呼ぶか。

この分野の比較

  • ラッチとフリップフロップの違い：動作と使い分けを比較ラッチとフリップフロップを、トリガー・出力の動き・構成・大きさ・タイミング解析・グリッチ・デジタル設計での使い分けの観点で表にして比較します。
  • 組み合わせ回路と順序回路の違い：出力の決まり方を比較組み合わせ回路と順序回路を、出力が何で決まるか・記憶素子・クロック・フィードバック・例・タイミング・HDLでの書き方の観点で表にして比較します。
  • CMOSとTTLの違い：論理ICのファミリーを比較CMOSとTTLの論理ICを、トランジスタ・静的消費電力・電源電圧・論理レベル・ノイズマージン・速度・入力・使われる場所の観点で表にして比較します。
