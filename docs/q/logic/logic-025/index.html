論理回路

7ビットのデータ 1011001 に偶数パリティのビットを付けるとき、パリティビットの値はどれか。

  1. A1
  2. B0
  3. Cデータによらず常に1
答えと解説を見る

正解：B. 0

偶数パリティでは、パリティビットを含めた1の数が偶数になるようにします。1011001には1が4個含まれ、すでに偶数なので、パリティビットは0です。受信側で1の数が奇数になっていれば、1ビットの誤りがあったことを検出できます。
