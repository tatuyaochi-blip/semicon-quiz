論理回路

Dラッチの動作の説明として正しいものはどれか。

  1. Aクロックの立ち上がりエッジの瞬間だけ入力を取り込む
  2. B入力を常に反転して出力する
  3. Cイネーブル信号が有効な間は入力がそのまま出力に伝わり、無効になるとその値を保持する
答えと解説を見る

正解：C. イネーブル信号が有効な間は入力がそのまま出力に伝わり、無効になるとその値を保持する

Dラッチはレベルで動作する記憶素子で、イネーブル(クロック)が有効な間は入力の変化がそのまま出力に現れ(透過)、無効になった瞬間の値を保持します。エッジの瞬間だけ取り込むのはD型フリップフロップで、2つのラッチを組み合わせてつくれます。

この分野を解く 分野ページへ

論理回路のほかの問題

  1. 非同期の信号をフリップフロップで受けたときに、セットアップ時間やホールド時間を満たせず、出力が一時的に0とも1とも定まらなくなる状態を何と呼ぶか。
  2. 出力が現在の状態だけで決まる順序回路(ステートマシン)の型はどれか。
  3. 10進数の59をBCD(2進化10進数)で表したものはどれか。
  4. 3入力の多数決回路の出力が1になる条件として正しいものはどれか。
  5. 全加算器の入力として正しい組み合わせはどれか。
