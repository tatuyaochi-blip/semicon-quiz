論理回路

4ビットの2の補数表現で −1 を表すビット列はどれか。

  1. A1111
  2. B1001
  3. C0001
答えと解説を見る

正解：A. 1111

2の補数では、正の数のビットを反転して1を足すと負の数になります。+1(0001)を反転すると1110、1を足して1111です。4ビットの2の補数では −8〜+7 を表せます。1001は符号と絶対値で表す方式での −1 にあたります。
