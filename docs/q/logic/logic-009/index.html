論理回路

4ビットの2の補数表現で −1 を表すビット列はどれか。

  1. A1111
  2. B1001
  3. C0001
答えと解説を見る

正解：A. 1111

2の補数では、正の数のビットを反転して1を足すと負の数になり、+1(0001)→1110→1111 が −1 です。最上位ビットの重みを −8 とみなすと、1111 = −8 + 4 + 2 + 1 = −1 と直接読めます。4ビットでは −8〜+7 を表せ、減算を「補数を足す」加算で行えるため、ほぼすべてのコンピュータが採用しています。1001は符号と絶対値方式での −1 です。

  • 組み合わせ回路と順序回路の違い：出力の決まり方を比較組み合わせ回路と順序回路を、出力が何で決まるか・記憶素子・クロック・フィードバック・例・タイミング・HDLでの書き方の観点で表にして比較します。
