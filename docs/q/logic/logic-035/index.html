論理回路

3入力の論理回路の真理値表は何行になるか。

  1. A6行
  2. B9行
  3. C8行
答えと解説を見る

正解：C. 8行

各入力は0か1の2通りなので、3入力の組み合わせは 2³ = 8 通りです。真理値表はすべての入力の組み合わせを1行ずつ並べるので8行になります。n入力では 2ⁿ 行です。

  • A. 6行は 3 × 2 で、組み合わせの数の数え方として誤りです。
  • B. 9行は 3² で、2値の入力の組み合わせの数ではありません。
  • C. 正しい。2³ = 8 行です。
