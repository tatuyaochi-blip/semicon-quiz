論理回路

マルチプレクサの機能として正しいものはどれか。

  1. A入力の値を1クロック分記憶する
  2. B入力信号の論理を反転する
  3. C選択信号に応じて、複数の入力から1つを選んで出力する
答えと解説を見る

正解：C. 選択信号に応じて、複数の入力から1つを選んで出力する

マルチプレクサ(セレクタ)は、選択信号の値に応じて複数の入力から1つを選んで出力に伝える回路で、選択信号がnビットなら2ⁿ個の入力から選べます。CPUではレジスタの値の選択やバスの切り替えに使われ、FPGAの論理ブロック(LUT)もメモリとマルチプレクサで任意の論理を実現しています。1つの入力を複数の出力の1つに振り分ける回路はデマルチプレクサです。
