パワー半導体

インバータで、上下のスイッチが同時にオンするなどの短絡が起きたとき、パワーデバイスが破壊されずに耐えられる時間を表す指標はどれか。

  1. AFIT
  2. BMTBF
  3. C短絡耐量
答えと解説を見る

正解：C. 短絡耐量

短絡耐量は、短絡によって大電流が流れたときに、デバイスが破壊されずに耐えられる時間(数µs程度)を表します。保護回路は、その時間内に短絡を検出してデバイスをオフにする必要があります。チップが小さいSiC MOSFETは、IGBTより短絡耐量が短くなりやすい点に注意が必要です。

この分野を解く 分野ページへ

パワー半導体のほかの問題

  1. インバータの上下のスイッチを切り替えるときに、両方をオフにしておく短い時間(デッドタイム)を設ける目的はどれか。
  2. SiC MOSFETのボディダイオードに電流を流し続けると、特性が劣化することがある原因として知られているものはどれか。
  3. GaNパワーデバイスの採用が進んでいる身近な製品の例として正しいものはどれか。
  4. パワー半導体の主な役割として正しいものはどれか。
  5. オン抵抗10 mΩのパワーMOSFETに10 Aの電流が流れているときの導通損失はいくらか。
