パワー半導体

パワーデバイスのゲート駆動回路で、ゲート抵抗の値を大きくしたときの影響として正しいものはどれか。

  1. Aスイッチングが遅くなり、サージやノイズは減るが、スイッチング損失は増える
  2. Bスイッチングが速くなり、損失もノイズも減る
  3. Cスイッチングには何も影響しない
答えと解説を見る

正解：A. スイッチングが遅くなり、サージやノイズは減るが、スイッチング損失は増える

ゲート抵抗を大きくするとゲート容量の充放電が遅くなり、電圧・電流の変化がゆるやかになります。その結果、サージ電圧やノイズは減りますが、切り替わりの時間が長くなるためスイッチング損失は増えます。オンとオフで別の抵抗値を使い分けたり(ダイオードで経路を分ける)、状況に応じてゲート駆動の強さを変えるアクティブゲート駆動で、損失とノイズを両立させる工夫もあります。

パワー半導体のほかの問題

  1. インバータで、上下のスイッチが同時にオンするなどの短絡が起きたとき、パワーデバイスが破壊されずに耐えられる時間を表す指標はどれか。
  2. インバータの上下のスイッチを切り替えるときに、両方をオフにしておく短い時間(デッドタイム)を設ける目的はどれか。
  3. SiC MOSFETのボディダイオードに電流を流し続けると、特性が劣化することがある原因として知られているものはどれか。
  4. GaNパワーデバイスの採用が進んでいる身近な製品の例として正しいものはどれか。
  5. パワー半導体の主な役割として正しいものはどれか。
