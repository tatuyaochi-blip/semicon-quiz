パワー半導体

電力変換器のスイッチング周波数を高くすることの主な利点はどれか。

  1. Aスイッチング損失が必ず減る
  2. Bコイルやコンデンサなどの受動部品を小型化できる
  3. C電磁ノイズが必ず減る
答えと解説を見る

正解：B. コイルやコンデンサなどの受動部品を小型化できる

スイッチング周波数を高くすると、1周期あたりにコイルやコンデンサが蓄える必要のあるエネルギーが小さくなるため、これらの部品を小さくでき、電源を小型・軽量にできます。一方、スイッチング損失やノイズは増えやすいため、高速スイッチングに適したSiCやGaNのデバイスが活躍しています。
