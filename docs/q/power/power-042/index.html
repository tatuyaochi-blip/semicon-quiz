パワー半導体

パワーMOSFETのゲートを一定電流で充電したとき、ゲート電圧がしばらく平らになる「ミラープラトー」が生じる理由として正しいものはどれか。

  1. Aゲート電流が止まるため
  2. Bゲート絶縁膜が一時的に壊れるため
  3. Cドレイン電圧が変化する間、ゲート電流がゲート-ドレイン間容量の充放電に使われるため
答えと解説を見る

正解：C. ドレイン電圧が変化する間、ゲート電流がゲート-ドレイン間容量の充放電に使われるため

スイッチング中にドレイン電圧が大きく変化するあいだ、ゲートに流し込んだ電流はゲート-ドレイン間容量(ミラー容量)の充放電に使われ、ゲート電圧はほぼ一定に保たれます。この平らな部分がミラープラトーで、その長さがスイッチング速度や損失に大きく影響します。

  • A. ゲート電流は流れ続けています。
  • B. 絶縁膜が壊れる現象ではありません。
  • C. 正しい。ミラー容量の充放電に電流が使われるためです。

  2. 一般的なシリコンのパワーデバイスの最大接合温度(Tj max)の定格として多いものはどれか。
  3. パワーデバイスを選ぶとき、定格電圧に余裕をもたせて実際の使用電圧より高い耐圧の素子を使う(ディレーティングする)主な理由はどれか。
  4. パワーMOSFETの「アバランシェ耐量」が重要になるのはどのような場合か。
  5. パワーモジュールに温度の上昇と下降を繰り返し与える「パワーサイクル試験」で見られる代表的な故障はどれか。
