パワー半導体

パワーデバイスを選ぶとき、定格電圧に余裕をもたせて実際の使用電圧より高い耐圧の素子を使う(ディレーティングする)主な理由はどれか。

  1. Aスイッチング時のサージ電圧や、宇宙線による故障などに備えて信頼性を確保するため
  2. B部品の価格を下げるため
  3. Cオン抵抗を下げるため
答えと解説を見る

正解：A. スイッチング時のサージ電圧や、宇宙線による故障などに備えて信頼性を確保するため

実際の回路では、スイッチング時に寄生インダクタンスによるサージ電圧が加わるうえ、高電圧で使い続けると宇宙線由来の中性子がデバイス内で電荷を生み、突然の破壊(シングルイベントバーンアウト)が起こる確率が電圧とともに急に上がります。そのため、例えば400 V系の回路に650 V品を使うように、使用電圧の1.5倍程度の定格の素子を選ぶのが一般的です。高度の高い場所では余裕をさらに大きくします。

  • A. 正しい。サージや宇宙線故障に備えて余裕をもたせます。
  • B. 耐圧の高い素子は一般に価格も高くなります。
  • C. 一般に耐圧の高い素子ほどオン抵抗は大きくなります。

パワー半導体のほかの問題

  1. パワーMOSFETの「アバランシェ耐量」が重要になるのはどのような場合か。

  3. 高速スイッチング用のパワーデバイスのパッケージで、ゲート駆動の戻り線専用のソース端子(ケルビンソース)を設ける目的はどれか。
  4. ハーフブリッジの上側(ハイサイド)のnチャネルMOSFETを駆動するために、ダイオードとコンデンサで電源電圧より高いゲート電圧をつくる回路はどれか。
  5. ユニポーラ型のパワーデバイス材料の性能を比べる「バリガ性能指数」で、特に大きく効く材料の物性値はどれか。
