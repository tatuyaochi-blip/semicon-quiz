パワー半導体

電気自動車のインバータにSiCパワーデバイスを使う主な利点はどれか。

  1. Aシリコンより必ず安価になる
  2. B損失が小さく、航続距離の延長や冷却装置の小型化につながる
  3. Cモーターが不要になる
答えと解説を見る

正解：B. 損失が小さく、航続距離の延長や冷却装置の小型化につながる

SiCデバイスはオン抵抗とスイッチング損失が小さく高温に強いため、EVのインバータ損失を減らせます。損失が減れば同じ電池で走れる距離が数%〜1割程度延び、冷却装置やインバータも小型・軽量にできます。2018年のTesla Model 3で本格採用されて以降、普及が進み、800 V系の高電圧バッテリーで特に効果が大きくなります。課題はSi IGBTより高いコストです。
