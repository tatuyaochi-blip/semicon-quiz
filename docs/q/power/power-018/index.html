パワー半導体

電源回路に使われる力率改善(PFC)回路の目的として正しいものはどれか。

  1. A出力電圧を2倍にする
  2. B電源のノイズを増やす
  3. C入力電流の波形を電圧に近い正弦波に整え、力率を1に近づける
答えと解説を見る

正解：C. 入力電流の波形を電圧に近い正弦波に整え、力率を1に近づける

コンデンサで平滑する単純な整流回路では、入力電流がピーク付近にだけ流れる、ひずんだ波形になり、力率が低下して高調波が電力系統に悪影響を与えます。PFC回路は、入力電流を電圧と同じ形の正弦波に近づけ、力率を改善して高調波を抑えます。
