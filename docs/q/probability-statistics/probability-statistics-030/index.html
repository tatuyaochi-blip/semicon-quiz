確率・統計と待ち行列

仮説検定で得られるp値の意味として、適切なものはどれか。

  1. A観測されたデータから計算した、帰無仮説そのものが正しい確率
  2. Bp値が0.03なら、対立仮説が正しい確率は97%であるということ
  3. C帰無仮説が正しいと仮定したとき、観測された結果か、それより極端な結果が得られる確率
答えと解説を見る

正解：C. 帰無仮説が正しいと仮定したとき、観測された結果か、それより極端な結果が得られる確率

仮説検定では、「差がない」などの帰無仮説を立て、それが正しいと仮定したときに、実際のデータのような結果がどのくらい起こりにくいかをp値で表します。p値があらかじめ決めた有意水準(例えば0.05)より小さければ、帰無仮説を棄却して、差があると判断します。p値は、帰無仮説や対立仮説そのものが正しい確率ではありません。

  • A. p値は帰無仮説が正しいと仮定して計算する値で、帰無仮説が正しい確率そのものではありません。
  • B. 1からp値を引いても、対立仮説が正しい確率にはなりません。
  • C. 正しい。帰無仮説のもとで、観測された結果と同じか、それより極端な結果が出る確率です。

確率・統計と待ち行列のほかの問題

  1. 製品のロットが規格を満たしているかを、抜き取ったサンプルで検定する。帰無仮説を「このロットは規格を満たしている」とするとき、第1種の誤りに当たるものはどれか。
  2. 1時間あたり平均12件の依頼が届き、1件の処理に平均4分かかる窓口がある。M/M/1の待ち行列とみなすとき、窓口の利用率はどれか。
  3. 1分あたり平均3件の要求が届き、1件の処理に平均15秒かかるサーバを、M/M/1の待ち行列とみなす。要求が届いてから処理が終わるまでの平均の時間(平均応答時間)はどれか。
  4. あるWebサーバの中には、処理中と待ちを合わせて平均12件の要求がある。要求は毎秒40件の割合で届き、同じ割合で処理されている(定常状態)。リトルの法則から求めた、1件の要求がサーバの中にいる平均の時間はどれか。
  5. M/M/1の待ち行列とみなせるサーバで、平均サービス時間は変わらないまま到着率が増え、利用率が0.8から0.9に上がった。平均待ち時間Wq(行列で待つ時間)は何倍になるか。最も近いものはどれか。
