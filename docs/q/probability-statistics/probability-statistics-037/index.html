確率・統計と待ち行列

平均サービス時間が0.2秒のサーバを、M/M/1の待ち行列とみなす。平均応答時間(待ち時間と処理の時間の合計)を1.0秒以下に抑えるとき、受け付けられる到着率の上限に最も近いものはどれか。

  1. A4.0件/秒
  2. B4.2件/秒
  3. C5.0件/秒
答えと解説を見る

正解：A. 4.0件/秒

平均応答時間は W = Ts/(1 − ρ) なので、0.2/(1 − ρ) ≤ 1.0 から 1 − ρ ≥ 0.2、つまり ρ ≤ 0.8 です。ρ = λ × Ts なので、λ ≤ 0.8 ÷ 0.2 = 4.0件/秒です。到着率が5.0件/秒では利用率が1になり、行列は限りなく伸びます。

  • A. 正しい。ρ ≤ 0.8 なので、λ ≤ 0.8 ÷ 0.2 = 4.0件/秒です。
  • B. 待ち時間Wqだけを1.0秒以下にした場合の値(ρ ≤ 5/6、λ ≤ 約4.17件/秒)で、処理の時間0.2秒を含めていません。
  • C. 1 ÷ 0.2 = 5.0 は利用率が1になる到着率で、このとき待ち時間は限りなく長くなります。

確率・統計と待ち行列のほかの問題

  1. 不良率が5%の大きなロットから10個を無作為に抜き取り、不良品が1個もなければロットを合格とする抜取検査を行う。このロットが合格になる確率に最も近いものはどれか。
  2. ビット誤り率が1 × 10⁻⁴の伝送路で、10,000ビットのデータを送る。各ビットの誤りは互いに独立に起こるとき、少なくとも1ビットが誤る確率に最も近いものはどれか。
  3. 8ビットのデータに偶数パリティのビットを1つ付けた、合わせて9ビットを送る。各ビットは互いに独立に1%の確率で誤るとき、パリティの検査で検出できない誤りが起こる確率に最も近いものはどれか。
  4. 8人のメンバーの中から3人の委員を選ぶ。委員の間に役割の区別はないとき、選び方の数はどれか。
  5. 5人の中から、議長、副議長、書記を1人ずつ選ぶ。1人が2つ以上の役を兼ねることはできないとき、選び方の数はどれか。
