シリコンフォトニクス

シリコンのリング共振器が、特定の波長の光にだけ強く反応する理由として正しいものはどれか。

  1. Aリングの材料が、その波長の光だけを吸収するバンドギャップをもつように選ばれているから
  2. Bリングの半径が光の波長とちょうど等しくなる波長でだけ、光がリングに入れるから
  3. Cリングを一周する光学的な経路長が波長の整数倍になる波長で、周回する光が強め合うから
答えと解説を見る

正解：C. リングを一周する光学的な経路長が波長の整数倍になる波長で、周回する光が強め合うから

リング共振器では、そばを通るバス導波路から光の一部がリングへ移り、リングを何度も周回します。一周の光学的な長さ(実効屈折率×周長)が波長の整数倍になる波長では、周回のたびに位相がそろって光が強め合い(共振)、バス導波路を通過する光がその波長だけ大きく落ち込みます。この性質を、特定の波長を取り出すフィルタや、共振波長を電気でずらす小型の変調器に使います。共振波長はとびとびに複数あり、半径数 µm〜数十 µmのリングが使われます。
