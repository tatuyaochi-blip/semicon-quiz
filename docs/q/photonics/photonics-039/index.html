シリコンフォトニクス

データセンター内の光接続で広く使われる強度変調・直接検波(IM-DD)方式でPAM4を使う場合、4つの値として変えているものはどれか。

  1. A光の位相
  2. B光の偏光の向き
  3. C光の強さ(パワー)
答えと解説を見る

正解：C. 光の強さ(パワー)

IM-DD(Intensity Modulation / Direct Detection)では、送信側で光の強さを変調し、受信側ではフォトダイオードで光の強さを直接電流に変えて判定します。PAM4では光の強さを4段階に変え、1つの記号で2ビットを送ります。受光器は光の強さしか検出できませんが、そのぶん構成が簡単で、低コスト・低消費電力です。光の位相や偏光にも情報を乗せるには、受信側で別のレーザーの光と干渉させて検出するコヒーレント方式が必要で、回路が複雑になります。

シリコンフォトニクスのほかの問題

  1. PAM4で、1波長あたり約106 Gb/s(誤り訂正の符号などを含む)の信号を送るときのシンボルレート(1秒あたりの記号の数)に最も近いものはどれか。
  2. データセンター間を結ぶ数十 km以上の接続などで使われるコヒーレント方式の、IM-DD方式と比べた特徴として正しいものはどれか。
  3. 800 Gb/sの光トランシーバの消費電力が16 Wのとき、1ビットあたりのエネルギーはいくらか。
  4. 合計51.2 Tb/sの帯域をもつスイッチで、すべての光接続を1ビットあたり5 pJで行うとき、光接続の消費電力に最も近いものはどれか。
