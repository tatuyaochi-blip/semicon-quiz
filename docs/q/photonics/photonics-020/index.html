シリコンフォトニクス

リング共振器の周長を短くしたときの変化として正しいものはどれか。

  1. A隣り合う共振波長の間隔(FSR)が広くなる
  2. B隣り合う共振波長の間隔(FSR)が狭くなる
  3. C共振が起こらなくなり、すべての波長を通す
答えと解説を見る

正解：A. 隣り合う共振波長の間隔(FSR)が広くなる

FSR(自由スペクトル領域)は隣り合う共振波長の間隔で、おおよそ FSR ≈ λ² /(ng × L)(ngは群屈折率、Lは周長)と表され、周長に反比例します。例えば、λ = 1.55 µm、ng ≈ 4.2、L ≈ 63 µm(半径約10 µm)ではFSRは約9 nmです。周長を半分にするとFSRは約2倍になり、多数の波長を扱うWDMで、1つのリングが別の波長にも反応してしまうことを避けやすくなります。ただし、急に曲げるほど曲げの損失が増えるため、小さくするには限界があります。

シリコンフォトニクスのほかの問題

  1. シリコンフォトニクスで、シリコン導波路とともに窒化シリコン(SiN)の導波路を組み合わせることがある。SiN導波路の特徴として正しいものはどれか。
  2. シリコンの光回路で、通信波長の受光器にゲルマニウム(Ge)が広く使われる理由として正しいものはどれか。
  3. シリコンの上に成長させたゲルマニウムの受光器で、暗電流が大きくなりやすい主な原因はどれか。
  4. 波長1.55 µmで量子効率80%のフォトダイオードの受光感度(1 Wの光あたりに流れる電流)に最も近いものはどれか(R [A/W] ≈ 量子効率 × λ [µm] / 1.24)。
  5. 光受信器で、フォトダイオードのすぐ後ろに置かれるトランスインピーダンスアンプ(TIA)の役割はどれか。
