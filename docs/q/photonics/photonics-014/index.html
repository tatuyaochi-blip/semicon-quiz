シリコンフォトニクス

マッハツェンダー変調器が、光の位相の変化を光の強さの変化に変える仕組みとして正しいものはどれか。

  1. A光を2つの腕に分け、腕の間に位相差をつけてから再び合流させ、干渉させる
  2. B光をリング状の共振器の中で何度も周回させ、特定の波長だけを吸収させる
  3. C位相を変えた光をそのまま受光器に当てると、位相の違いが電流の大きさの違いになる
答えと解説を見る

正解：A. 光を2つの腕に分け、腕の間に位相差をつけてから再び合流させ、干渉させる

マッハツェンダー変調器では、入ってきた光を2本の腕に等しく分け、腕の屈折率を電気信号で変えて位相に差をつけたあと、再び1本に合流させます。2つの光の位相差が0なら強め合って明るく、π(半波長分)なら打ち消し合って暗くなり、その間では位相差に応じた強さになります。これにより、受光器で検出できる強さの変化として信号を乗せられます。受光器は光の強さに応じた電流を出すだけで、位相の違いを直接は検出できません。共振器を使うのはリング変調器です。
