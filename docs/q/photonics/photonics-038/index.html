シリコンフォトニクス

DSPを省いたリニアドライブの光トランシーバの課題として正しいものはどれか。

  1. ADSPがない分、モジュールの消費電力がDSPを使う方式より大きくなってしまう
  2. B信号の補償をホストのSerDesに頼るため、ホストや基板の配線を含めた系全体で性能を保証する必要がある
  3. CDSPがないと光の信号をつくれないため、電気の配線の代わりには使えない
答えと解説を見る

正解：B. 信号の補償をホストのSerDesに頼るため、ホストや基板の配線を含めた系全体で性能を保証する必要がある

リニアドライブでは、モジュール内で信号を受け直して整える部分がないため、ホストのSerDesの送信波形、基板の配線の損失、ドライバや変調器、ファイバ、受信側の特性がすべてつながった1本の伝送路として性能が決まります。どこか一部の性能が足りないと全体の誤りが増え、異なる会社の製品を組み合わせたときの相互運用性の確認も難しくなります。また、モジュール内で信号を整え直せない分、届く距離はデータセンター内の比較的短い範囲が中心です。消費電力と遅延はDSPを使う方式より小さくなります。

シリコンフォトニクスのほかの問題

  1. データセンター内の光接続で広く使われる強度変調・直接検波(IM-DD)方式でPAM4を使う場合、4つの値として変えているものはどれか。
  2. PAM4で、1波長あたり約106 Gb/s(誤り訂正の符号などを含む)の信号を送るときのシンボルレート(1秒あたりの記号の数)に最も近いものはどれか。
  3. データセンター間を結ぶ数十 km以上の接続などで使われるコヒーレント方式の、IM-DD方式と比べた特徴として正しいものはどれか。
  4. 800 Gb/sの光トランシーバの消費電力が16 Wのとき、1ビットあたりのエネルギーはいくらか。
  5. 合計51.2 Tb/sの帯域をもつスイッチで、すべての光接続を1ビットあたり5 pJで行うとき、光接続の消費電力に最も近いものはどれか。
