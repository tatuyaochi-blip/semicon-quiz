テスト・検査

プローブカードの説明として正しいものはどれか。

  1. Aチップを封止するための金型
  2. Bウエハを搬送するための容器
  3. Cウエハ上のチップの電極に針を接触させ、テスタと電気的に接続する治具
答えと解説を見る

正解：C. ウエハ上のチップの電極に針を接触させ、テスタと電気的に接続する治具

プローブカードは、ウエハテストで使う治具で、チップの電極パッドの配置に合わせて多数の針(プローブ)が並んでいます。プローバという装置がウエハを動かして針と電極の位置を合わせ、テスタとチップを電気的につなぎます。

テスト・検査のほかの問題

  1. 論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。
  2. テストパターンの故障検出率(フォールトカバレッジ)の定義として正しいものはどれか。
  3. 複数のチップを1つのパッケージに実装する際に重要となるKGD(Known Good Die)とは何か。
  4. テストのコストを下げるために、テスタで複数のチップを同時に測定する手法を何と呼ぶか。
  5. 回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。
