テスト・検査

高速なシリアル通信のインターフェースのテストで、チップの送信回路の出力を受信回路に折り返してつなぎ、チップ自身で通信を確認する方法はどれか。

  1. AIDDQテスト
  2. Bバーンイン
  3. Cループバックテスト
答えと解説を見る

正解：C. ループバックテスト

数十Gb/sに達する高速なSerDesなどを、テスタだけで直接測るのは難しく高価です。ループバックテストでは、送信回路から擬似乱数のデータを出して受信回路に戻し、チップ内の回路でビット誤りを数えます。チップ内で折り返す方法と、ロードボード上の配線で外を通して折り返す方法があり、汎用のテスタで高速インターフェースを効率よくテストできます。

  • A. IDDQテストは静止時の電源電流で欠陥を検出するテストです。
  • B. バーンインは初期不良を取り除くストレス試験です。
  • C. 正しい。送信を受信に折り返して確認する方法です。

テスト・検査のほかの問題

  1. ウエハテストなどの途中の結果や統計にもとづいて、チップごと・ロットごとにテスト項目や判定値を動的に変える手法を何と呼ぶか。
  2. ADコンバータのテストで、ゆっくり変化する正弦波などを入力して、各出力コードが現れる回数(ヒストグラム)を数える主な目的はどれか。
  3. スキャンテストで不良になったチップについて、どの出力のどのパターンで不一致が出たかの情報から、故障していそうな場所の候補を論理的に絞り込む処理を何と呼ぶか。
  4. スタンダードセルの内部のトランジスタの短絡や開放などの欠陥を、セルの回路をもとにモデル化してテストパターンを生成する手法はどれか。
  5. ウエハテスト(プローブテスト)の説明として正しいものはどれか。
