テスト・検査

CMOS回路が静止状態のときの電源電流を測定して、ブリッジ故障などの欠陥を検出するテストを何と呼ぶか。

  1. AIDDQテスト
  2. Bファンクションテスト
  3. Cバーンイン
答えと解説を見る

正解：A. IDDQテスト

CMOS回路は、静止状態ではpMOSとnMOSのどちらかが必ずオフなので、電源電流がほとんど流れません。配線間の短絡(ブリッジ)やゲート酸化膜の欠陥があると、静止時に電源からグラウンドへ電流が流れるため、静止時の電源電流(IDDQ)を測ることで欠陥を検出できます。ただし微細化でリーク電流が大きくなり、正常品との区別が難しくなっています。
