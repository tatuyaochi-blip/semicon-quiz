テスト・検査

CMOS回路が静止状態のときの電源電流を測定して、ブリッジ故障などの欠陥を検出するテストを何と呼ぶか。

  1. AIDDQテスト
  2. Bファンクションテスト
  3. Cバーンイン
答えと解説を見る

正解：A. IDDQテスト

CMOS回路は、静止状態では電源電流がほとんど流れません。配線間の短絡などの欠陥があると異常な電流が流れるため、静止時の電源電流(IDDQ)を測ることで欠陥を検出できます。ただし微細化でリーク電流が大きくなると、正常品との区別が難しくなります。

テスト・検査のほかの問題

  1. IEEE 1149.1(JTAG)で規定されたバウンダリスキャンの主な用途はどれか。
  2. パッケージ後の最終テストで、テスタと組み合わせてICを自動で供給し、テスト結果に応じて分類する装置はどれか。
  3. 電源電圧や動作周波数などの条件を変えながら合否を調べ、その結果を2次元の図にまとめたものを何と呼ぶか。
  4. 一般的な半導体製品のテストの流れとして正しいものはどれか。
  5. ACテストで主に確認する項目はどれか。
