テスト・検査

ウエハテストで不良と判定したチップの情報を、後の組立工程で使う方法として、現在一般的なものはどれか。

  1. A不良チップに印を付けずに、組立工程ですべて再検査する
  2. B電子データのウエハマップとして組立工程に渡す
  3. C作業者が目視で覚えておく
答えと解説を見る

正解：B. 電子データのウエハマップとして組立工程に渡す

かつては不良チップにインクで印を付けていましたが、現在はウエハテストの結果をウエハマップの電子データとして保存し、組立工程のダイボンダーがそのデータを読み取って良品チップだけを取り出すのが一般的です。

テスト・検査のほかの問題

  1. 車載用の半導体で、室温だけでなく高温や低温でもテストを行う主な理由はどれか。
  2. メモリのテストで、アドレスを順にたどりながら0と1の書き込みと読み出しを繰り返し、隣接するセル間の干渉などの不良も検出するテストパターンはどれか。
  3. ATE(自動試験装置)の説明として正しいものはどれか。
  4. ウエハテストで、プローブの針が電極パッドに触れたあと、さらに少し押し込んで確実に接触させることを何と呼ぶか。
  5. テスト容易化設計で高めることを目指す2つの性質の組み合わせとして正しいものはどれか。
