テスト・検査

テスタとICをつなぐテスト用の治具で、ばねで伸縮する細いピンを使って端子に確実に接触させる部品はどれか。

  1. Aボンディングワイヤ
  2. Bはんだボール
  3. Cポゴピン(スプリングプローブ)
答えと解説を見る

正解：C. ポゴピン(スプリングプローブ)

ポゴピンは、筒の中にばねを入れた細い接触ピンで、ICの端子や基板の電極に押し当てると適度な力で確実に接触し、端子の高さのばらつきも吸収できます。テストソケットや、テストヘッドとロードボードの接続などに多数使われます。何十万回も接触を繰り返すと先端が摩耗し、汚れも付くため、定期的に清掃・交換します。ワイヤやはんだボールは製品の一部です。

  • A. ボンディングワイヤはチップとパッケージをつなぐ永続的な配線です。
  • B. はんだボールはパッケージを基板に接合するための端子です。
  • C. 正しい。ばねで伸縮する接触ピンです。
