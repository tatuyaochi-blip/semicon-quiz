テスト・検査

テスタとICをつなぐテスト用の治具で、ばねで伸縮する細いピンを使って端子に確実に接触させる部品はどれか。

  1. Aボンディングワイヤ
  2. Bはんだボール
  3. Cポゴピン(スプリングプローブ)
答えと解説を見る

正解：C. ポゴピン(スプリングプローブ)

ポゴピンは、内部にばねを入れた細い接触ピンで、ICの端子や基板の電極に押し当てると適度な力で確実に接触します。テストソケットやテストヘッドとロードボードの接続などに多数使われます。

  • A. ボンディングワイヤはチップとパッケージをつなぐ永続的な配線です。
  • B. はんだボールはパッケージを基板に接合するための端子です。
  • C. 正しい。ばねで伸縮する接触ピンです。

テスト・検査のほかの問題

  1. テスタのテストヘッドに取り付け、ICのソケットや周辺の部品を載せて、品種ごとに信号をICへ引き回すプリント基板を何と呼ぶか。
  2. プローブカードの方式で、針をパッドに対して垂直に立てて並べる垂直型の主な利点はどれか。
  3. ウエハテストを続けると、プローブの針先にパッドのアルミニウムの削りくずなどが付着する。このとき定期的に行う処理はどれか。
  4. プローバで、ウエハを載せる台(チャック)の温度を高温や低温に制御できるようにする目的はどれか。
  5. 論理回路のテストで、スキャンなどを使って回路の構造上の故障(縮退故障など)を網羅的に検出するテストと、実際の動作どおりに機能を確認するテストの呼び方の組み合わせとして正しいものはどれか。
