テスト・検査

実際の動作周波数でテストを行い、信号の伝わる速さが遅すぎる不良を検出するテストを何と呼ぶか。

  1. ADCテスト
  2. B外観検査
  3. C実速度(アットスピード)テスト
答えと解説を見る

正解：C. 実速度(アットスピード)テスト

微細なLSIでは、論理的には正しく動いても、わずかな欠陥で信号の伝わる時間が延びる遅延不良が問題になります。アットスピードテストでは、スキャンで値を設定したあと、チップ内のPLLから実際の動作周波数のクロックを2回続けて与え、信号の変化が1周期内に届くかを調べます。遷移故障などの遅延故障モデルにもとづくパターンを使います。

テスト・検査のほかの問題

  1. テスト結果にもとづいて、動作速度や消費電力などの性能ごとに製品を分類することを何と呼ぶか。
  2. テストで、測定誤差や経時変化を考慮して、製品の規格より少し厳しい判定値を設けることを何と呼ぶか。
  3. テストプログラムの開発で、テストのコストを下げるために重視されることとして正しいものはどれか。
  4. ウエハテストで不良と判定したチップの情報を、後の組立工程で使う方法として、現在一般的なものはどれか。
  5. 車載用の半導体で、室温だけでなく高温や低温でもテストを行う主な理由はどれか。
