テスト・検査

テストパターンの故障検出率(フォールトカバレッジ)の定義として正しいものはどれか。

  1. A想定した故障のうち、そのテストで検出できる故障の割合
  2. B出荷した製品のうち不良品の割合
  3. Cウエハ上の良品チップの割合
答えと解説を見る

正解：A. 想定した故障のうち、そのテストで検出できる故障の割合

故障検出率は、モデル化した全故障のうち、テストパターンで検出できる故障の割合です。この値が低いと、不良品をテストで見逃して出荷してしまう可能性が高くなります。高品質が求められる車載用LSIなどでは、非常に高い故障検出率が求められます。

この分野を解く 分野ページへ

テスト・検査のほかの問題

  1. 複数のチップを1つのパッケージに実装する際に重要となるKGD(Known Good Die)とは何か。
  2. テストのコストを下げるために、テスタで複数のチップを同時に測定する手法を何と呼ぶか。
  3. 回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。
  4. CMOS回路が静止状態のときの電源電流を測定して、ブリッジ故障などの欠陥を検出するテストを何と呼ぶか。
  5. IEEE 1149.1(JTAG)で規定されたバウンダリスキャンの主な用途はどれか。
