テスト・検査

スキャンテストのデータ量とテスト時間を減らすため、チップ内でテストパターンを展開し、応答を圧縮する技術を何と呼ぶか。

  1. Aテスト圧縮(スキャン圧縮)
  2. Bバーンイン
  3. CIDDQテスト
答えと解説を見る

正解：A. テスト圧縮(スキャン圧縮)

大規模なLSIでは、スキャンテストのパターン量が膨大になり、テスタのメモリとテスト時間が問題になります。テスト圧縮では、少ない入力データをチップ内の回路で多数のスキャンチェーンに展開し、出力も圧縮して比較することで、データ量とテスト時間を大幅に減らします。

この分野を解く 分野ページへ

テスト・検査のほかの問題

  1. 実際の動作周波数でテストを行い、信号の伝わる速さが遅すぎる不良を検出するテストを何と呼ぶか。
  2. テスト結果にもとづいて、動作速度や消費電力などの性能ごとに製品を分類することを何と呼ぶか。
  3. テストで、測定誤差や経時変化を考慮して、製品の規格より少し厳しい判定値を設けることを何と呼ぶか。
  4. テストプログラムの開発で、テストのコストを下げるために重視されることとして正しいものはどれか。
  5. ウエハテストで不良と判定したチップの情報を、後の組立工程で使う方法として、現在一般的なものはどれか。
