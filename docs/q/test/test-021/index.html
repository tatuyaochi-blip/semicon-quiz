テスト・検査

テストで、測定誤差や経時変化を考慮して、製品の規格より少し厳しい判定値を設けることを何と呼ぶか。

  1. Aビニング
  2. Bテスト圧縮
  3. Cガードバンド
答えと解説を見る

正解：C. ガードバンド

テスタには測定誤差があり、製品の特性も温度や経年で少しずつ変化します。規格ぎりぎりの製品を良品と判定してしまわないよう、判定値を規格より余裕をもって厳しく設定します。この余裕をガードバンドといいます。広くとりすぎると良品まで不良と判定して歩留まりが下がるため、測定の再現性を高めてガードバンドを小さくする努力が続けられます。

テスト・検査のほかの問題

  1. テストプログラムの開発で、テストのコストを下げるために重視されることとして正しいものはどれか。
  2. ウエハテストで不良と判定したチップの情報を、後の組立工程で使う方法として、現在一般的なものはどれか。
  3. 車載用の半導体で、室温だけでなく高温や低温でもテストを行う主な理由はどれか。
  4. メモリのテストで、アドレスを順にたどりながら0と1の書き込みと読み出しを繰り返し、隣接するセル間の干渉などの不良も検出するテストパターンはどれか。
  5. ATE(自動試験装置)の説明として正しいものはどれか。
