テスト・検査

ウエハテストで、プローブの針が電極パッドに触れたあと、さらに少し押し込んで確実に接触させることを何と呼ぶか。

  1. Aアンダーフィル
  2. Bガードバンド
  3. Cオーバードライブ
答えと解説を見る

正解：C. オーバードライブ

プローブの針が電極パッドに触れた位置から、さらに数十µm程度押し込むことをオーバードライブといいます。針の先がパッドの表面の酸化膜を突き破り、安定した電気的な接触が得られます。押し込みすぎると、パッドやその下の構造を傷めるおそれがあります。
