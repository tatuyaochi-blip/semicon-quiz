テスト・検査

ACテストで主に確認する項目はどれか。

  1. A入出力端子のリーク電流
  2. B伝搬遅延やセットアップ時間など、信号のタイミングに関する特性
  3. Cパッケージの外観
答えと解説を見る

正解：B. 伝搬遅延やセットアップ時間など、信号のタイミングに関する特性

ACテストでは、入力から出力までの伝搬遅延時間、セットアップ時間やホールド時間、出力の立ち上がり・立ち下がり時間など、時間に関する特性を測ります。直流的な特性はDCテスト、論理機能はファンクションテストで確認します。

この分野を解く 分野ページへ

テスト・検査のほかの問題

  1. スキャンテストのデータ量とテスト時間を減らすため、チップ内でテストパターンを展開し、応答を圧縮する技術を何と呼ぶか。
  2. 実際の動作周波数でテストを行い、信号の伝わる速さが遅すぎる不良を検出するテストを何と呼ぶか。
  3. テスト結果にもとづいて、動作速度や消費電力などの性能ごとに製品を分類することを何と呼ぶか。
  4. テストで、測定誤差や経時変化を考慮して、製品の規格より少し厳しい判定値を設けることを何と呼ぶか。
  5. テストプログラムの開発で、テストのコストを下げるために重視されることとして正しいものはどれか。
