テスト・検査

ADコンバータのテストで、ゆっくり変化する正弦波などを入力して、各出力コードが現れる回数(ヒストグラム)を数える主な目的はどれか。

  1. Aチップの重さを測るため
  2. BDNLやINLなどの直線性を求めるため
  3. C消費電力を測るため
答えと解説を見る

正解：B. DNLやINLなどの直線性を求めるため

理想的なADCに既知の分布の信号を入れると、各コードの出現回数は計算できる分布になります。実際の出現回数とのずれから各コードの幅、つまりDNLを求め、それを積み上げてINLを求めます。これをヒストグラム法といいます。正弦波は頂点付近に多く分布するため理論分布で補正し、三角波やランプ波ならほぼ均一な分布になります。消費電力は電源電流から求めます。

  • A. 重さとは関係ありません。
  • B. 正しい。出現回数から直線性を求めます。
  • C. 消費電力は電源電流を測って求めます。

テスト・検査のほかの問題

  1. スキャンテストで不良になったチップについて、どの出力のどのパターンで不一致が出たかの情報から、故障していそうな場所の候補を論理的に絞り込む処理を何と呼ぶか。
  2. スタンダードセルの内部のトランジスタの短絡や開放などの欠陥を、セルの回路をもとにモデル化してテストパターンを生成する手法はどれか。
  3. ウエハテスト(プローブテスト)の説明として正しいものはどれか。
  4. バーンインの目的として正しいものはどれか。
  5. テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。
