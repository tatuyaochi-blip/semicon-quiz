テスト・検査

前工程を終えたウエハで、TEGのしきい値電圧やシート抵抗などを測り、工程が規格どおりにできたかを確認する検査を何と呼ぶか。

  1. AWAT(ウエハアクセプタンステスト)/ パラメトリックテスト
  2. B最終テスト
  3. Cバーンイン
答えと解説を見る

正解：A. WAT(ウエハアクセプタンステスト)/ パラメトリックテスト

WATは、前工程の完了後にTEGの電気的なパラメータ(しきい値電圧、オン電流、シート抵抗、コンタクト抵抗など)を測る検査です。規格を外れたウエハは後の工程に進めず、データは工程の監視や改善にも使われます。チップの機能を調べるテストとは目的が異なります。

  • A. 正しい。工程の出来ばえをパラメータで確認する検査です。
  • B. 最終テストはパッケージ後の製品の良否を調べる検査です。
  • C. バーンインは初期不良を取り除くためのストレス試験です。

テスト・検査のほかの問題

  1. テスタとICをつなぐテスト用の治具で、ばねで伸縮する細いピンを使って端子に確実に接触させる部品はどれか。
  2. テスタのテストヘッドに取り付け、ICのソケットや周辺の部品を載せて、品種ごとに信号をICへ引き回すプリント基板を何と呼ぶか。
  3. プローブカードの方式で、針をパッドに対して垂直に立てて並べる垂直型の主な利点はどれか。
  4. ウエハテストを続けると、プローブの針先にパッドのアルミニウムの削りくずなどが付着する。このとき定期的に行う処理はどれか。
  5. プローバで、ウエハを載せる台(チャック)の温度を高温や低温に制御できるようにする目的はどれか。
