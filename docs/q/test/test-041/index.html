テスト・検査

プローバで、ウエハを載せる台(チャック)の温度を高温や低温に制御できるようにする目的はどれか。

  1. Aウエハを乾燥させるため
  2. B実際の使用温度の範囲でチップが規格を満たすかを、ウエハの段階で確認するため
  3. Cチップを接着するため
答えと解説を見る

正解：B. 実際の使用温度の範囲でチップが規格を満たすかを、ウエハの段階で確認するため

チップの特性は温度によって変わり、高温でリークが増えたり、低温でタイミングが変わったりします。チャックの温度を制御して高温・低温でウエハテストを行うことで、パッケージする前に温度依存の不良を見つけ、組立のコストのむだを減らせます。

  • A. 乾燥させるためではありません。
  • B. 正しい。使用温度の範囲での良否をウエハの段階で確認します。
  • C. 接着するためではありません。

テスト・検査のほかの問題

  1. 論理回路のテストで、スキャンなどを使って回路の構造上の故障(縮退故障など)を網羅的に検出するテストと、実際の動作どおりに機能を確認するテストの呼び方の組み合わせとして正しいものはどれか。
  2. テストの判定が厳しすぎたり測定が不安定だったりして、本来は良品のチップを不良と判定して捨ててしまうことを何と呼ぶか。
  3. メモリのテストで、どのアドレスのどのビットが不良だったかを記録した図をつくる主な目的はどれか。
  4. スキャンテストで出力を圧縮するとき、シミュレーションで値が0か1か決まらない信号(不定値X)を取り除く処理が必要になる理由はどれか。
  5. 高速なシリアル通信のインターフェースのテストで、チップの送信回路の出力を受信回路に折り返してつなぎ、チップ自身で通信を確認する方法はどれか。
