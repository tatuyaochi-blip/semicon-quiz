テスト・検査

ウエハテストなどの途中の結果や統計にもとづいて、チップごと・ロットごとにテスト項目や判定値を動的に変える手法を何と呼ぶか。

  1. Aアダプティブテスト
  2. Bダミーテスト
  3. Cブラックボックステスト
答えと解説を見る

正解：A. アダプティブテスト

アダプティブテストでは、前の工程や同じウエハのほかのチップの結果、統計的な外れ値の検出などにもとづいて、テストを追加・省略したり判定値を変えたりします。例えば規格内でも周りのチップから大きく外れた値のチップを除くPAT(パーツアベレージテスト)は、車載用で潜在不良を減らすために使われます。品質を保ちながらテスト時間も減らせます。

  • A. 正しい。結果にもとづいてテストを動的に変える手法です。
  • B. そのような名前の一般的な手法ではありません。
  • C. ブラックボックステストは内部構造を見ずに入出力で確認するソフトウェアのテストの考え方です。
