テスト・検査

ウエハテストなどの途中の結果や統計にもとづいて、チップごと・ロットごとにテスト項目や判定値を動的に変える手法を何と呼ぶか。

  1. Aアダプティブテスト
  2. Bダミーテスト
  3. Cブラックボックステスト
答えと解説を見る

正解：A. アダプティブテスト

アダプティブテストでは、前の工程や同じウエハのほかのチップの結果、統計的な外れ値の検出などにもとづいて、テストを追加・省略したり判定値を変えたりします。品質を保ちながらテスト時間を減らしたり、潜在的な不良を見つけやすくしたりできます。

  • A. 正しい。結果にもとづいてテストを動的に変える手法です。
  • B. そのような名前の一般的な手法ではありません。
  • C. ブラックボックステストは内部構造を見ずに入出力で確認するソフトウェアのテストの考え方です。

テスト・検査のほかの問題

  1. ADコンバータのテストで、ゆっくり変化する正弦波などを入力して、各出力コードが現れる回数(ヒストグラム)を数える主な目的はどれか。
  2. スキャンテストで不良になったチップについて、どの出力のどのパターンで不一致が出たかの情報から、故障していそうな場所の候補を論理的に絞り込む処理を何と呼ぶか。
  3. スタンダードセルの内部のトランジスタの短絡や開放などの欠陥を、セルの回路をもとにモデル化してテストパターンを生成する手法はどれか。
  4. ウエハテスト(プローブテスト)の説明として正しいものはどれか。
  5. バーンインの目的として正しいものはどれか。
