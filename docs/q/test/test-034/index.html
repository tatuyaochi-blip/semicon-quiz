テスト・検査

テストで、チップの入力に順番に加える0と1の信号の並びと、それに対する期待値の組を何と呼ぶか。

  1. Aレシピ
  2. Bテストパターン(テストベクタ)
  3. Cフォトマスク
答えと解説を見る

正解：B. テストパターン(テストベクタ)

テストパターン(テストベクタ)は、各時刻にチップの入力に加える信号の値と、そのときに出力されるべき期待値をまとめたものです。故障を効率よく検出できるパターンを、自動生成(ATPG)などでつくります。

  • A. レシピは製造装置の処理条件の設定のことです。
  • B. 正しい。入力の並びと期待値の組です。
  • C. フォトマスクは露光でパターンを転写するための原版です。
この分野を解く 分野ページへ

テスト・検査のほかの問題

  1. ウエハ上のチップの間(スクライブライン)などに置かれ、トランジスタや抵抗などの特性を測ってプロセスを評価するための専用のパターンを何と呼ぶか。
  2. 前工程を終えたウエハで、TEGのしきい値電圧やシート抵抗などを測り、工程が規格どおりにできたかを確認する検査を何と呼ぶか。
  3. テスタとICをつなぐテスト用の治具で、ばねで伸縮する細いピンを使って端子に確実に接触させる部品はどれか。
  4. テスタのテストヘッドに取り付け、ICのソケットや周辺の部品を載せて、品種ごとに信号をICへ引き回すプリント基板を何と呼ぶか。
  5. プローブカードの方式で、針をパッドに対して垂直に立てて並べる垂直型の主な利点はどれか。
