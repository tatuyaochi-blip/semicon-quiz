テスト・検査

ウエハテストで、プローブカードの針を接触させるチップ上の場所はどれか。

  1. Aトランジスタのゲートの上
  2. Bチップの電極パッド
  3. Cウエハの裏面の中央だけ
答えと解説を見る

正解：B. チップの電極パッド

ウエハテストでは、プローブカードの多数の針を、各チップの周辺などに並んだ電極パッドに接触させ、テスタから電源や信号を加えて応答を測ります。パッドは後のワイヤボンディングやバンプの接続にも使う電極で、数十µm角の大きさです。針跡が接合の妨げにならないよう、針跡の大きさや位置も検査されます。トランジスタは配線層の下にあり、直接は触れられません。

  • A. トランジスタのゲートは配線層の下にあり、直接針は当てられません。
  • B. 正しい。電極パッドに針を接触させます。
  • C. ウエハの裏面だけでは回路の各端子に接続できません。

テスト・検査のほかの問題

  1. 論理回路のテストで、チップが正常かどうかを判定する基本的な方法はどれか。
  2. テストで、チップの入力に順番に加える0と1の信号の並びと、それに対する期待値の組を何と呼ぶか。
  3. ウエハ上のチップの間(スクライブライン)などに置かれ、トランジスタや抵抗などの特性を測ってプロセスを評価するための専用のパターンを何と呼ぶか。
  4. 前工程を終えたウエハで、TEGのしきい値電圧やシート抵抗などを測り、工程が規格どおりにできたかを確認する検査を何と呼ぶか。
  5. テスタとICをつなぐテスト用の治具で、ばねで伸縮する細いピンを使って端子に確実に接触させる部品はどれか。
