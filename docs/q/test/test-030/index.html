テスト・検査

出荷した製品100万個あたりの不良数を表す品質の指標はどれか。

  1. AFIT
  2. BCp
  3. CDPPM
答えと解説を見る

正解：C. DPPM

DPPM(Defective Parts Per Million)は、出荷した製品100万個あたりの不良品の数を表します。車載用の半導体などでは、非常に低いDPPMが求められ、テストでの見逃しを減らすことが重要になります。FITは時間あたりの故障率、Cpは工程能力指数です。

テスト・検査のほかの問題

  1. ウエハテスト(プローブテスト)の説明として正しいものはどれか。
  2. バーンインの目的として正しいものはどれか。
  3. テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。
  4. 半導体のDCテスト(直流特性試験)で主に確認する項目はどれか。
  5. BIST(組み込み自己テスト)の説明として正しいものはどれか。
