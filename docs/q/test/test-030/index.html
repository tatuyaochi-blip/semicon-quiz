テスト・検査

出荷した製品100万個あたりの不良数を表す品質の指標はどれか。

  1. AFIT
  2. BCp
  3. CDPPM
答えと解説を見る

正解：C. DPPM

DPPM(Defective Parts Per Million)は、出荷した製品100万個あたりの不良品の数を表します。車載用の半導体などでは、非常に低いDPPMが求められ、テストでの見逃しを減らすことが重要になります。FITは時間あたりの故障率、Cpは工程能力指数です。

テスト・検査のほかの問題

  1. 半導体製品の製造でテストを行う主な目的はどれか。
  2. ウエハテストで、プローブカードの針を接触させるチップ上の場所はどれか。
  3. 論理回路のテストで、チップが正常かどうかを判定する基本的な方法はどれか。
  4. テストで、チップの入力に順番に加える0と1の信号の並びと、それに対する期待値の組を何と呼ぶか。
  5. ウエハ上のチップの間(スクライブライン)などに置かれ、トランジスタや抵抗などの特性を測ってプロセスを評価するための専用のパターンを何と呼ぶか。
