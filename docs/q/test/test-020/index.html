テスト・検査

テスト結果にもとづいて、動作速度や消費電力などの性能ごとに製品を分類することを何と呼ぶか。

  1. Aダイシング
  2. Bビニング(性能別の選別)
  3. Cモールド
答えと解説を見る

正解：B. ビニング(性能別の選別)

同じ設計のチップでも、製造ばらつきによって動作できる最高周波数や消費電力が異なります。ビニングでは、テストの結果に応じて製品を性能ごとのグレードに分け、異なる製品として出荷します。CPUの周波数グレードがその例で、一部のコアに不良があるチップをコア数の少ない製品として出荷することもあり、ウエハから得られる売上を増やせます。

テスト・検査のほかの問題

  1. テストで、測定誤差や経時変化を考慮して、製品の規格より少し厳しい判定値を設けることを何と呼ぶか。
  2. テストプログラムの開発で、テストのコストを下げるために重視されることとして正しいものはどれか。
  3. ウエハテストで不良と判定したチップの情報を、後の組立工程で使う方法として、現在一般的なものはどれか。
  4. 車載用の半導体で、室温だけでなく高温や低温でもテストを行う主な理由はどれか。
  5. メモリのテストで、アドレスを順にたどりながら0と1の書き込みと読み出しを繰り返し、隣接するセル間の干渉などの不良も検出するテストパターンはどれか。
