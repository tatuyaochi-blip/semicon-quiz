テスト・検査

ウエハ上のチップの間(スクライブライン)などに置かれ、トランジスタや抵抗などの特性を測ってプロセスを評価するための専用のパターンを何と呼ぶか。

  1. Aダミーゲート
  2. Bアライメントマーク
  3. CTEG(テストエレメントグループ)
答えと解説を見る

正解：C. TEG(テストエレメントグループ)

TEGは、トランジスタ、抵抗、容量、配線のチェーンなど、プロセスの出来ばえを評価するための単純な構造の集まりです。スクライブラインなどに配置し、その電気的な特性を測ることで、工程が正しく行われたかを確認します。

  • A. ダミーゲートは加工の均一性などのために置く機能のないゲートです。
  • B. アライメントマークは露光の位置合わせ用の目印です。
  • C. 正しい。プロセス評価用のテストパターンです。

テスト・検査のほかの問題

  1. 前工程を終えたウエハで、TEGのしきい値電圧やシート抵抗などを測り、工程が規格どおりにできたかを確認する検査を何と呼ぶか。
  2. テスタとICをつなぐテスト用の治具で、ばねで伸縮する細いピンを使って端子に確実に接触させる部品はどれか。
  3. テスタのテストヘッドに取り付け、ICのソケットや周辺の部品を載せて、品種ごとに信号をICへ引き回すプリント基板を何と呼ぶか。
  4. プローブカードの方式で、針をパッドに対して垂直に立てて並べる垂直型の主な利点はどれか。
  5. ウエハテストを続けると、プローブの針先にパッドのアルミニウムの削りくずなどが付着する。このとき定期的に行う処理はどれか。
