テスト・検査

テストプログラムの開発で、テストのコストを下げるために重視されることとして正しいものはどれか。

  1. A不良を十分に検出できる範囲で、測定項目や順序を最適化してテスト時間を短くする
  2. Bすべての項目を最大の回数ずつ測定する
  3. C不良が多い項目のテストを省略する
答えと解説を見る

正解：A. 不良を十分に検出できる範囲で、測定項目や順序を最適化してテスト時間を短くする

テストのコストはテスト時間にほぼ比例するため、品質を確保できる範囲で測定項目を絞り、測定の順序や条件を工夫してテスト時間を短くします。過去のデータから不良がほとんど出ない項目を見直したり、マルチサイトテストと組み合わせたりします。

この分野を解く 分野ページへ

テスト・検査のほかの問題

  1. ウエハテストで不良と判定したチップの情報を、後の組立工程で使う方法として、現在一般的なものはどれか。
  2. 車載用の半導体で、室温だけでなく高温や低温でもテストを行う主な理由はどれか。
  3. メモリのテストで、アドレスを順にたどりながら0と1の書き込みと読み出しを繰り返し、隣接するセル間の干渉などの不良も検出するテストパターンはどれか。
  4. ATE(自動試験装置)の説明として正しいものはどれか。
  5. ウエハテストで、プローブの針が電極パッドに触れたあと、さらに少し押し込んで確実に接触させることを何と呼ぶか。
