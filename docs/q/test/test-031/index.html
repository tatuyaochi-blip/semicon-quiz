テスト・検査

半導体製品の製造でテストを行う主な目的はどれか。

  1. A製造中にできた不良品を見つけて取り除き、規格を満たす製品だけを出荷するため
  2. Bチップの色を確認するため
  3. Cチップの重さを測るため
答えと解説を見る

正解：A. 製造中にできた不良品を見つけて取り除き、規格を満たす製品だけを出荷するため

どれほど管理しても、製造工程では一定の割合で欠陥をもつチップができます。テストで電気的な特性や機能を調べて不良品を取り除くことで、規格を満たす製品だけを出荷します。不良は後で見つかるほど損失が大きく、市場で見つかれば回収などの大きな問題になります。テストの結果は不良の原因を探して製造工程を改善するためのデータにもなります。

  • A. 正しい。不良品を取り除いて良品だけを出荷します。
  • B. 色を確認することが目的ではありません。
  • C. 重さを測ることが目的ではありません。

テスト・検査のほかの問題

  1. ウエハテストで、プローブカードの針を接触させるチップ上の場所はどれか。
  2. 論理回路のテストで、チップが正常かどうかを判定する基本的な方法はどれか。
  3. テストで、チップの入力に順番に加える0と1の信号の並びと、それに対する期待値の組を何と呼ぶか。
  4. ウエハ上のチップの間(スクライブライン)などに置かれ、トランジスタや抵抗などの特性を測ってプロセスを評価するための専用のパターンを何と呼ぶか。
  5. 前工程を終えたウエハで、TEGのしきい値電圧やシート抵抗などを測り、工程が規格どおりにできたかを確認する検査を何と呼ぶか。
