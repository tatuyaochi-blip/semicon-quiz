テスト・検査

ウエハテスト(プローブテスト)の説明として正しいものはどれか。

  1. Aダイシング前に、ウエハ上の各チップにプローブを当てて電気的特性を検査する
  2. Bパッケージ封止後に、外観だけを検査する
  3. C製品を長期間使用して故障率を調べる
答えと解説を見る

正解：A. ダイシング前に、ウエハ上の各チップにプローブを当てて電気的特性を検査する

ウエハテストでは、プローバがウエハを動かしてプローブカードの針をチップの電極パッドに当て、テスタで電気的な特性や機能を検査します。不良チップをこの段階で見つければ、パッケージの材料費や組立の手間をむだにせずに済みます。不良は後の工程で見つかるほど損失が大きくなるためです。封止後の検査は最終テスト、長期間使って故障率を調べるのは信頼性試験です。
