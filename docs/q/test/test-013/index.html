テスト・検査

IEEE 1149.1(JTAG)で規定されたバウンダリスキャンの主な用途はどれか。

  1. Aウエハ上の膜厚の測定
  2. B配線のエレクトロマイグレーション評価
  3. Cプリント基板に実装したLSIの端子どうしの接続などを、プローブを当てずにテストする
答えと解説を見る

正解：C. プリント基板に実装したLSIの端子どうしの接続などを、プローブを当てずにテストする

バウンダリスキャンでは、LSIの各端子の内側にスキャン用のセルを設け、それらをシリアルにつないで外部から値を設定・観測します。基板上で端子にプローブを当てられないBGAなどでも、はんだ接続の不良などを検査できます。デバッグや書き込みにも使われます。

この分野を解く 分野ページへ

テスト・検査のほかの問題

  1. パッケージ後の最終テストで、テスタと組み合わせてICを自動で供給し、テスト結果に応じて分類する装置はどれか。
  2. 電源電圧や動作周波数などの条件を変えながら合否を調べ、その結果を2次元の図にまとめたものを何と呼ぶか。
  3. 一般的な半導体製品のテストの流れとして正しいものはどれか。
  4. ACテストで主に確認する項目はどれか。
  5. スキャンテストのデータ量とテスト時間を減らすため、チップ内でテストパターンを展開し、応答を圧縮する技術を何と呼ぶか。
