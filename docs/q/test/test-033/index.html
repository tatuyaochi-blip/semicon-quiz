テスト・検査

論理回路のテストで、チップが正常かどうかを判定する基本的な方法はどれか。

  1. Aチップを顕微鏡で眺めるだけ
  2. Bチップの温度だけを測る
  3. C入力にテストパターンを加え、出力を正常な回路で得られるはずの期待値と比べる
答えと解説を見る

正解：C. 入力にテストパターンを加え、出力を正常な回路で得られるはずの期待値と比べる

論理回路のテストでは、テスタがテストパターン(入力信号の並び)をチップに加え、出てきた出力を、正常な回路で得られるはずの期待値と比べます。1か所でも一致しなければ不良と判定します。

  • A. 外観を見るだけでは内部の電気的な不良はわかりません。
  • B. 温度だけでは機能の良否は判定できません。
  • C. 正しい。出力を期待値と比べて判定します。

テスト・検査のほかの問題

  1. テストで、チップの入力に順番に加える0と1の信号の並びと、それに対する期待値の組を何と呼ぶか。
  2. ウエハ上のチップの間(スクライブライン)などに置かれ、トランジスタや抵抗などの特性を測ってプロセスを評価するための専用のパターンを何と呼ぶか。
  3. 前工程を終えたウエハで、TEGのしきい値電圧やシート抵抗などを測り、工程が規格どおりにできたかを確認する検査を何と呼ぶか。
  4. テスタとICをつなぐテスト用の治具で、ばねで伸縮する細いピンを使って端子に確実に接触させる部品はどれか。
  5. テスタのテストヘッドに取り付け、ICのソケットや周辺の部品を載せて、品種ごとに信号をICへ引き回すプリント基板を何と呼ぶか。
