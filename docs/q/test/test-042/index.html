テスト・検査

論理回路のテストで、スキャンなどを使って回路の構造上の故障(縮退故障など)を網羅的に検出するテストと、実際の動作どおりに機能を確認するテストの呼び方の組み合わせとして正しいものはどれか。

  1. ADCテストとACテスト
  2. Bウエハテストとバーンイン
  3. Cストラクチャルテストとファンクショナルテスト
答えと解説を見る

正解：C. ストラクチャルテストとファンクショナルテスト

ストラクチャルテストは、回路の構造に対して故障モデルを考え、スキャンなどを使って各部分の故障を効率よく検出するテストです。ファンクショナルテストは、実際の使い方に近い入力を与えて、仕様どおりに機能するかを確認するテストです。両者を組み合わせて品質を確保します。

  • A. DCテストとACテストは、直流特性とタイミングなどの交流特性のテストです。
  • B. ウエハテストとバーンインは、テストの時期や種類による区別です。
  • C. 正しい。構造に基づくテストと機能に基づくテストです。

テスト・検査のほかの問題

  1. テストの判定が厳しすぎたり測定が不安定だったりして、本来は良品のチップを不良と判定して捨ててしまうことを何と呼ぶか。
  2. メモリのテストで、どのアドレスのどのビットが不良だったかを記録した図をつくる主な目的はどれか。
  3. スキャンテストで出力を圧縮するとき、シミュレーションで値が0か1か決まらない信号(不定値X)を取り除く処理が必要になる理由はどれか。
  4. 高速なシリアル通信のインターフェースのテストで、チップの送信回路の出力を受信回路に折り返してつなぎ、チップ自身で通信を確認する方法はどれか。
  5. ウエハテストなどの途中の結果や統計にもとづいて、チップごと・ロットごとにテスト項目や判定値を動的に変える手法を何と呼ぶか。
