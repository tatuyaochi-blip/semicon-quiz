テスト・検査

車載用の半導体で、室温だけでなく高温や低温でもテストを行う主な理由はどれか。

  1. A使用される広い温度範囲で正しく動作することを保証するため
  2. Bテスト時間を短くするため
  3. Cテストのコストを下げるため
答えと解説を見る

正解：A. 使用される広い温度範囲で正しく動作することを保証するため

自動車は寒冷地から炎天下のエンジンルームまで、非常に広い温度範囲で使われます。半導体の特性は温度によって変わるため、高温と低温でもテストして、保証する温度範囲のすべてで規格を満たすことを確認します。

この分野を解く 分野ページへ

テスト・検査のほかの問題

  1. メモリのテストで、アドレスを順にたどりながら0と1の書き込みと読み出しを繰り返し、隣接するセル間の干渉などの不良も検出するテストパターンはどれか。
  2. ATE(自動試験装置)の説明として正しいものはどれか。
  3. ウエハテストで、プローブの針が電極パッドに触れたあと、さらに少し押し込んで確実に接触させることを何と呼ぶか。
  4. テスト容易化設計で高めることを目指す2つの性質の組み合わせとして正しいものはどれか。
  5. 実際の使用状態に近い環境でOSやアプリケーションを動かして、チップの良否を判定するテストを何と呼ぶか。
