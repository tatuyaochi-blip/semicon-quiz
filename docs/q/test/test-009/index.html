テスト・検査

複数のチップを1つのパッケージに実装する際に重要となるKGD(Known Good Die)とは何か。

  1. A大型のチップ
  2. B故障したチップ
  3. C実装前に良品であることが確認されたチップ(ダイ)
答えと解説を見る

正解：C. 実装前に良品であることが確認されたチップ(ダイ)

複数のチップを1つのパッケージに組み込む場合、1つでも不良チップが含まれると、ほかの良品チップも含めてパッケージ全体が不良になります。そのため、実装前のダイの段階で十分にテストし、良品であることが確認されたKGDを使うことが重要です。

テスト・検査のほかの問題

  1. テストのコストを下げるために、テスタで複数のチップを同時に測定する手法を何と呼ぶか。
  2. 回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。
  3. CMOS回路が静止状態のときの電源電流を測定して、ブリッジ故障などの欠陥を検出するテストを何と呼ぶか。
  4. IEEE 1149.1(JTAG)で規定されたバウンダリスキャンの主な用途はどれか。
  5. パッケージ後の最終テストで、テスタと組み合わせてICを自動で供給し、テスト結果に応じて分類する装置はどれか。
