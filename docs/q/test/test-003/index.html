テスト・検査

テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。

  1. Aチップの表面を光学顕微鏡で走査して欠陥を探す
  2. Bテスト時に電源電圧を徐々に上げて動作限界を調べる
  3. C回路内のフリップフロップをシフトレジスタ状につなぎ、内部状態の設定と観測を容易にする
答えと解説を見る

正解：C. 回路内のフリップフロップをシフトレジスタ状につなぎ、内部状態の設定と観測を容易にする

スキャン設計では、テストのときに回路内のフリップフロップを数珠つなぎ(スキャンチェーン)にし、外部から任意の値を設定したり、内部の値を読み出したりできるようにします。これにより、組み合わせ回路部分を効率よくテストでき、テストパターンの自動生成(ATPG)も可能になります。

テスト・検査のほかの問題

  1. 半導体のDCテスト(直流特性試験)で主に確認する項目はどれか。
  2. BIST(組み込み自己テスト)の説明として正しいものはどれか。
  3. プローブカードの説明として正しいものはどれか。
  4. 論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。
  5. テストパターンの故障検出率(フォールトカバレッジ)の定義として正しいものはどれか。
