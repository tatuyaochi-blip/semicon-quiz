テスト・検査

メモリのテストで、アドレスを順にたどりながら0と1の書き込みと読み出しを繰り返し、隣接するセル間の干渉などの不良も検出するテストパターンはどれか。

  1. AIDDQテスト
  2. Bシュムープロット
  3. Cマーチテスト
答えと解説を見る

正解：C. マーチテスト

マーチテストは、アドレスを昇順や降順にたどりながら、各セルに決められた順序で書き込みと読み出しを行うメモリのテストアルゴリズムです。代表的なMarch C−は1セルあたり10回の操作で、縮退故障に加え、隣接セルどうしの干渉(カップリング故障)やアドレスデコーダの不良も検出できます。テスト時間がセル数に比例するため、大容量メモリにも使えます。

テスト・検査のほかの問題

  1. ATE(自動試験装置)の説明として正しいものはどれか。
  2. ウエハテストで、プローブの針が電極パッドに触れたあと、さらに少し押し込んで確実に接触させることを何と呼ぶか。
  3. テスト容易化設計で高めることを目指す2つの性質の組み合わせとして正しいものはどれか。
  4. 実際の使用状態に近い環境でOSやアプリケーションを動かして、チップの良否を判定するテストを何と呼ぶか。
  5. 出荷した製品100万個あたりの不良数を表す品質の指標はどれか。
