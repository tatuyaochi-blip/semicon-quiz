テスト・検査

実際の使用状態に近い環境でOSやアプリケーションを動かして、チップの良否を判定するテストを何と呼ぶか。

  1. Aシステムレベルテスト(SLT)
  2. BDCテスト
  3. CIDDQテスト
答えと解説を見る

正解：A. システムレベルテスト(SLT)

システムレベルテストでは、チップを実際の製品に近いボードに載せ、OSを起動したりアプリケーションを動かしたりして動作を確認します。複数のブロックが同時に動くときの電源ノイズや、構造的なテストのパターンでは再現しにくい組み合わせで起こる不良を検出できます。テスト時間が長いため、多数のボードで並行して行い、主に高性能なプロセッサで使われます。
