テスト・検査

実際の使用状態に近い環境でOSやアプリケーションを動かして、チップの良否を判定するテストを何と呼ぶか。

  1. Aシステムレベルテスト(SLT)
  2. BDCテスト
  3. CIDDQテスト
答えと解説を見る

正解：A. システムレベルテスト(SLT)

システムレベルテストでは、チップを実際の製品に近いボードに載せ、OSを起動したりアプリケーションを動かしたりして動作を確認します。構造的なテストだけでは見つけにくい不良を検出できるため、高性能なプロセッサなどで使われています。

この分野を解く 分野ページへ

テスト・検査のほかの問題

  1. 出荷した製品100万個あたりの不良数を表す品質の指標はどれか。
  2. ウエハテスト(プローブテスト)の説明として正しいものはどれか。
  3. バーンインの目的として正しいものはどれか。
  4. テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。
  5. 半導体のDCテスト(直流特性試験)で主に確認する項目はどれか。
