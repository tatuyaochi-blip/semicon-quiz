テスト・検査

実際の使用状態に近い環境でOSやアプリケーションを動かして、チップの良否を判定するテストを何と呼ぶか。

  1. Aシステムレベルテスト(SLT)
  2. BDCテスト
  3. CIDDQテスト
答えと解説を見る

正解：A. システムレベルテスト(SLT)

システムレベルテストでは、チップを実際の製品に近いボードに載せ、OSを起動したりアプリケーションを動かしたりして動作を確認します。構造的なテストだけでは見つけにくい不良を検出できるため、高性能なプロセッサなどで使われています。

この分野を解く 分野ページへ

テスト・検査のほかの問題

  1. 出荷した製品100万個あたりの不良数を表す品質の指標はどれか。
  2. 半導体製品の製造でテストを行う主な目的はどれか。
  3. ウエハテストで、プローブカードの針を接触させるチップ上の場所はどれか。
  4. 論理回路のテストで、チップが正常かどうかを判定する基本的な方法はどれか。
  5. テストで、チップの入力に順番に加える0と1の信号の並びと、それに対する期待値の組を何と呼ぶか。
