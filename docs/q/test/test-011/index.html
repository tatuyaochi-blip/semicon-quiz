テスト・検査

回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。

  1. ADRC
  2. BATPG(自動テストパターン生成)
  3. CCTS
答えと解説を見る

正解：B. ATPG(自動テストパターン生成)

ATPGは、縮退故障などの故障モデルにもとづいて、各故障を出力まで伝えて検出できる入力パターンを、ネットリストから自動で生成する技術です。スキャン設計と組み合わせることで、数億ゲートの回路でも高い故障検出率のパターンを効率よく作成できます。DRCはレイアウトの設計ルールの検査、CTSはクロックツリーの合成で、どちらも設計の工程です。

テスト・検査のほかの問題

  1. CMOS回路が静止状態のときの電源電流を測定して、ブリッジ故障などの欠陥を検出するテストを何と呼ぶか。
  2. IEEE 1149.1(JTAG)で規定されたバウンダリスキャンの主な用途はどれか。
  3. パッケージ後の最終テストで、テスタと組み合わせてICを自動で供給し、テスト結果に応じて分類する装置はどれか。
  4. 電源電圧や動作周波数などの条件を変えながら合否を調べ、その結果を2次元の図にまとめたものを何と呼ぶか。
  5. 一般的な半導体製品のテストの流れとして正しいものはどれか。

この分野の比較

  • スタティック・ダイナミック・ウエハレベルのバーンインの違い：ストレス・網羅性・コストを比較スタティックバーンイン、ダイナミックバーンイン、ウエハレベルバーンインを、ストレスの加え方・行う段階・代表的な条件・ストレスがかかる範囲・装置と治具・監視・コスト・課題・用途の観点で表にして比較し、使い分けも解説します。
  • スキャンテストとBISTの違い：パターンの作り方・テスター・対象・追加回路・用途を比較スキャンテストとBIST(組み込み自己テスト)を、テストパターンの作り方(ATPGと内蔵の生成器)・テスターへの依存・対象のロジックとメモリ・故障検出率・追加回路・テスト時間の観点で比較します。
  • ウエハテストとファイナルテストの違い：時期・接触のしかた・温度・項目・目的を比較ウエハテスト(プローブテスト)とファイナルテストを、テストの時期と対象・接触のしかた(プローブカードとソケット)・温度・テスト項目・不良を見つける目的・KGDの観点で表にして比較します。
