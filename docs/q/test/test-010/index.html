テスト・検査

テストのコストを下げるために、テスタで複数のチップを同時に測定する手法を何と呼ぶか。

  1. Aバーンイン
  2. Bマルチサイトテスト(同時測定)
  3. Cワイヤボンディング
答えと解説を見る

正解：B. マルチサイトテスト(同時測定)

テストのコストは、高価なテスタを使う時間にほぼ比例します。マルチサイトテストでは、1台のテスタで複数のチップを並行して測定し、1チップあたりのテスト時間とコストを下げます。メモリのテストでは数百個を同時に測ることもあります。同時に測るチップの数だけテスタのチャンネルが必要になるため、BISTやスキャン圧縮で必要なピンを減らす工夫と組み合わせます。

テスト・検査のほかの問題

  1. 回路のネットリストから、故障を検出するためのテストパターンを自動で生成することを何と呼ぶか。
  2. CMOS回路が静止状態のときの電源電流を測定して、ブリッジ故障などの欠陥を検出するテストを何と呼ぶか。
  3. IEEE 1149.1(JTAG)で規定されたバウンダリスキャンの主な用途はどれか。
  4. パッケージ後の最終テストで、テスタと組み合わせてICを自動で供給し、テスト結果に応じて分類する装置はどれか。
  5. 電源電圧や動作周波数などの条件を変えながら合否を調べ、その結果を2次元の図にまとめたものを何と呼ぶか。
