テスト・検査

スキャンテストで不良になったチップについて、どの出力のどのパターンで不一致が出たかの情報から、故障していそうな場所の候補を論理的に絞り込む処理を何と呼ぶか。

  1. A故障診断(ダイアグノシス)
  2. Bゲッタリング
  3. Cリソグラフィ
答えと解説を見る

正解：A. 故障診断(ダイアグノシス)

故障診断は、不良チップのテスト結果と、故障を仮定したシミュレーションの結果を照合して、故障が起きていそうなネットやセルの候補を絞り込む処理です。物理的な故障解析で断面を切る場所を絞り込めるため、解析の時間を大きく短縮できます。多数の不良チップの診断結果を統計的に集める量産診断では、特定の配線パターンやセルに偏る系統的な不良を見つけて歩留まりの向上に役立てます。

  • A. 正しい。テスト結果から故障箇所の候補を絞り込む処理です。
  • B. ゲッタリングは有害な不純物を捕らえる技術です。
  • C. リソグラフィはパターンを転写する工程です。

テスト・検査のほかの問題

  1. スタンダードセルの内部のトランジスタの短絡や開放などの欠陥を、セルの回路をもとにモデル化してテストパターンを生成する手法はどれか。
  2. ウエハテスト(プローブテスト)の説明として正しいものはどれか。
  3. バーンインの目的として正しいものはどれか。
  4. テスト容易化設計(DFT)の一つであるスキャン設計の説明として正しいものはどれか。
  5. 半導体のDCテスト(直流特性試験)で主に確認する項目はどれか。
