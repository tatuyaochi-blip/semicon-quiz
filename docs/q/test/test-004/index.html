テスト・検査

半導体のDCテスト(直流特性試験)で主に確認する項目はどれか。

  1. A入出力端子のリーク電流や電圧レベル、消費電流
  2. B回路の論理機能だけ
  3. Cパッケージの外観
答えと解説を見る

正解：A. 入出力端子のリーク電流や電圧レベル、消費電流

DCテストでは、入出力端子のリーク電流、出力電圧のHとLのレベル、入力のしきい値、待機時や動作時の消費電流など、直流的な電気特性が規格を満たすかを測ります。最初に、各端子の保護ダイオードに電流を流して針の接触や断線・短絡を確かめるコンタクトテストを行うのが一般的です。論理機能はファンクションテスト、外観は外観検査で確認します。

テスト・検査のほかの問題

  1. BIST(組み込み自己テスト)の説明として正しいものはどれか。
  2. プローブカードの説明として正しいものはどれか。
  3. 論理回路のテストで使われる縮退故障(スタックアット故障)モデルの説明として正しいものはどれか。
  4. テストパターンの故障検出率(フォールトカバレッジ)の定義として正しいものはどれか。
  5. 複数のチップを1つのパッケージに実装する際に重要となるKGD(Known Good Die)とは何か。
