テスト・検査

メモリのテストで、どのアドレスのどのビットが不良だったかを記録した図をつくる主な目的はどれか。

  1. Aメモリの容量を増やすため
  2. Bチップの色を決めるため
  3. C不良の位置にもとづいて冗長な行・列で置き換える救済を行い、不良の原因の解析にも使うため
答えと解説を見る

正解：C. 不良の位置にもとづいて冗長な行・列で置き換える救済を行い、不良の原因の解析にも使うため

フェイルビットマップは、不良ビットの位置をアドレスに対応させて表したものです。不良の行や列を予備の行・列に置き換える冗長救済の計算に使い、救済はレーザーや電気でヒューズを切って行います。不良の並び方(1ビット、行全体、列全体、塊など)から、パーティクルや配線の短絡など製造工程の欠陥の種類を推定する解析にも役立ちます。

  • A. 不良の記録で容量が増えるわけではありません。
  • B. 色とは関係ありません。
  • C. 正しい。救済と不良解析に使います。

テスト・検査のほかの問題

  1. スキャンテストで出力を圧縮するとき、シミュレーションで値が0か1か決まらない信号(不定値X)を取り除く処理が必要になる理由はどれか。
  2. 高速なシリアル通信のインターフェースのテストで、チップの送信回路の出力を受信回路に折り返してつなぎ、チップ自身で通信を確認する方法はどれか。
  3. ウエハテストなどの途中の結果や統計にもとづいて、チップごと・ロットごとにテスト項目や判定値を動的に変える手法を何と呼ぶか。
  4. ADコンバータのテストで、ゆっくり変化する正弦波などを入力して、各出力コードが現れる回数(ヒストグラム)を数える主な目的はどれか。
  5. スキャンテストで不良になったチップについて、どの出力のどのパターンで不一致が出たかの情報から、故障していそうな場所の候補を論理的に絞り込む処理を何と呼ぶか。
