テスト・検査

ATE(自動試験装置)の説明として正しいものはどれか。

  1. Aテストパターンを入力し、出力を期待値と比較して良否を判定する装置
  2. Bウエハに回路パターンを露光する装置
  3. Cウエハを洗浄する装置
答えと解説を見る

正解：A. テストパターンを入力し、出力を期待値と比較して良否を判定する装置

ATE(Automatic Test Equipment)は、テスト対象のチップに電源や信号を与え、出力を測定して期待値と比べ、良否を判定する装置です。ピンごとに信号の発生、電圧・電流の測定、タイミングの判定ができる回路を数百〜数千チャンネル備えています。ウエハテストではプローバ、最終テストではハンドラと組み合わせて使います。露光や洗浄は前工程の装置の仕事です。

テスト・検査のほかの問題

  1. ウエハテストで、プローブの針が電極パッドに触れたあと、さらに少し押し込んで確実に接触させることを何と呼ぶか。
  2. テスト容易化設計で高めることを目指す2つの性質の組み合わせとして正しいものはどれか。
  3. 実際の使用状態に近い環境でOSやアプリケーションを動かして、チップの良否を判定するテストを何と呼ぶか。
  4. 出荷した製品100万個あたりの不良数を表す品質の指標はどれか。
  5. 半導体製品の製造でテストを行う主な目的はどれか。
