タイミング解析とCDC

同じクロックの立ち上がりエッジで送り出しと取り込みを行う通常の経路で、ホールド違反(スラック −0.03 ns)が見つかった。クロック周波数を半分に下げたときの、この違反の扱いとして正しいものはどれか。

  1. Aホールドのチェックはクロック周期に関係しないので、違反は残る
  2. B周期が2倍になるので、違反は解消される
  3. C周期が長くなるぶん、違反はさらに大きくなる
答えと解説を見る

正解：A. ホールドのチェックはクロック周期に関係しないので、違反は残る

ホールドのチェックは、同じクロックエッジで送り出された新しいデータが、受け側で前のデータを壊さないかを見るもので、このような経路では式にクロック周期が入りません。そのため周波数を下げても −0.03 ns のスラックは変わらず、悪化もしません。一方セットアップは周期に依存するので、周波数を下げれば救えます。製造後に見つかったホールド違反は、周波数の調整では直せない致命的な不良になりやすいため、設計段階で確実に修正しておくことが重要です。

タイミング解析とCDCのほかの問題

  1. ホールド違反を直すために、データ経路に遅延用のバッファを挿入する。このときに確認すべきこととして最も重要なものはどれか。
  2. クロック周期 1.25 ns(800 MHz)の経路で、クロック→出力遅延と組み合わせ回路の遅延の合計が 1.05 ns、セットアップ時間が 0.05 ns、セットアップ用のクロックの不確かさが 0.05 ns に設定されている。セットアップのスラックはいくらか。
  3. クロックの不確かさの設定で、セットアップ用には周期ジッタを含めるが、ホールド用には含めないことが多い。その理由として正しいものはどれか。
  4. STAで、セットアップとホールドをそれぞれ主にどのコーナー条件で確認するかの組み合わせとして正しいものはどれか。
  5. OCVディレーティングとして、セットアップ解析で送り側のクロック経路とデータ経路の遅延を1.1倍、受け側のクロック経路の遅延を0.9倍にする。送り側クロック経路 1.0 ns、データ経路(クロック→出力を含む)1.5 ns、受け側クロック経路 1.0 ns(共通部分はない)、周期 3.0 ns、セットアップ時間 0.1 ns のとき、セットアップのスラックはいくらか。
