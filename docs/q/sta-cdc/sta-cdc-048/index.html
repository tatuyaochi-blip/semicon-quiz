タイミング解析とCDC

同じ送り側のドメインから来た2本の制御信号を、それぞれ別の2段同期化回路で受け、受け側でANDをとって使う設計の問題点として正しいものはどれか。

  1. AANDゲートを通るとメタステーブルが増幅され、受け側の回路全体が不安定になり続ける
  2. B送り側で同時に変わった2本が受け側では1サイクルずれて見えることがあり、本来ありえない組み合わせが現れる
  3. C2本の信号は受け側で必ず同じサイクルにそろうので、問題は起きない
答えと解説を見る

正解：B. 送り側で同時に変わった2本が受け側では1サイクルずれて見えることがあり、本来ありえない組み合わせが現れる

別々に同期化した信号が受け側で再び合流することをリコンバージェンス(収束)と呼びます。2本が送り側で同時に変わっても、それぞれの同期化回路で新旧どちらに決まるかは独立なので、受け側では一方だけが変わったサイクルが生じえます。例えば2本が0→1と1→0に同時に変わると、前後ともANDは0のはずなのに、1が1サイクル出ることがあります。対策は、1本にまとめて同期化してから分けるか、グレイコードのように1ビットだけ変わる符号にすることです。

タイミング解析とCDCのほかの問題

  1. STAとRTLシミュレーションを行っていても、CDC検証ツールによる確認が必要とされる理由として正しいものはどれか。
  2. 非同期FIFOのグレイコードのポインタを相手のドメインに渡す経路を、非同期だからといって制約なし(フォールスパス)にすると問題になりうる理由として正しいものはどれか。
  3. クロック周期 2.0 ns の同期回路で、送り側フリップフロップのクロック→出力遅延が 0.2 ns、組み合わせ回路の遅延が 1.4 ns、受け側フリップフロップのセットアップ時間が 0.1 ns である。クロックスキューを0とすると、セットアップのスラックはいくらか。
  4. フリップフロップ間の経路で、クロック→出力遅延が 0.15 ns、組み合わせ回路の最大遅延が 2.2 ns、セットアップ時間が 0.15 ns である。スキューとクロックの不確かさを無視すると、この経路で動作できる最大のクロック周波数はいくらか。
  5. STAのレポートに出てくるWNSとTNSの説明として正しいものはどれか。
