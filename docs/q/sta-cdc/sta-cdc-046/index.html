タイミング解析とCDC

書き込み側 250 MHz、読み出し側 200 MHz で、どちらも毎サイクル1語ずつ転送する。64語のバーストを受けるFIFOに計算上必要な最小の深さはいくらか(同期化による遅れは無視し、端数は切り上げる)。

  1. A51語
  2. B64語
  3. C13語
答えと解説を見る

正解：C. 13語

64語の書き込みにかかる時間は 64 × 4 ns = 256 ns で、その間に読み出せるのは 256 ÷ 5 ns = 51.2語分です。残る量は 64 − 51.2 = 12.8語なので、切り上げて13語が必要です。51語は読み出せる量のほうを答えた値、64語はバーストをまるごと蓄える場合の値で、足りはしますが最小ではありません。実際の設計では、ポインタの同期化の遅れの分を加え、グレイコードのポインタを使いやすい2のべき乗の16語などに切り上げます。

タイミング解析とCDCのほかの問題

  1. アクティブLowの外部リセットから、「非同期にアサートし、同期してデアサートする」内部リセットを作るリセット同期化回路の構成として正しいものはどれか。
  2. 同じ送り側のドメインから来た2本の制御信号を、それぞれ別の2段同期化回路で受け、受け側でANDをとって使う設計の問題点として正しいものはどれか。
  3. STAとRTLシミュレーションを行っていても、CDC検証ツールによる確認が必要とされる理由として正しいものはどれか。
  4. 非同期FIFOのグレイコードのポインタを相手のドメインに渡す経路を、非同期だからといって制約なし(フォールスパス)にすると問題になりうる理由として正しいものはどれか。
  5. クロック周期 2.0 ns の同期回路で、送り側フリップフロップのクロック→出力遅延が 0.2 ns、組み合わせ回路の遅延が 1.4 ns、受け側フリップフロップのセットアップ時間が 0.1 ns である。クロックスキューを0とすると、セットアップのスラックはいくらか。
