タイミング解析とCDC

周期 2.5 ns(400 MHz)のクロックで、出力端子に set_output_delay 0.8 ns が設定されている。出力端子を駆動するフリップフロップのクロック→出力遅延が 0.2 ns のとき、フリップフロップから出力端子までの組み合わせ回路と配線に許される最大遅延はいくらか(クロックの遅延は無視する)。

  1. A1.5 ns
  2. B2.3 ns
  3. C1.7 ns
答えと解説を見る

正解：A. 1.5 ns

出力遅延 0.8 ns はチップの外で使われる時間なので、チップ内部で使えるのは 2.5 − 0.8 = 1.7 ns です。そこからフリップフロップのクロック→出力遅延 0.2 ns を引いた 1.5 ns が、組み合わせ回路と配線に許される遅延になります。2.3 ns は出力遅延を考えずに計算した値、1.7 ns はクロック→出力遅延を引き忘れた値です。出力端子の直前にフリップフロップを置いて出力をレジスタから直接出すと、内部の遅延が小さく安定し、制約を満たしやすくなります。

タイミング解析とCDCのほかの問題

  1. 周期 1.0 ns のクロックで、フリップフロップA→B→Cとつながる経路がある。A→Bはクロック→出力遅延とセットアップ時間を含めて 1.2 ns が必要で、B→Cは 0.8 ns で足りる。スキューを意図的に使って両方のセットアップを満たすには、Bのクロックをどうすればよいか(AとCのクロックは同時に届くものとする)。
  2. クロックを分周回路で2分周して別の回路に使う場合、SDCでの扱いとして正しいものはどれか。
  3. 非同期リセット付きフリップフロップで、リセットの解除がクロックのエッジに近すぎないかをSTAで調べるチェックはどれか。
  4. 2つのクロックドメインの間の経路で、同期化回路が必要になるのはどれか。
  5. 2段フリップフロップの同期化回路を3段に増やしたときの、メタステーブルによる故障の平均間隔(MTBF)の変化として正しいものはどれか。
