シリコンウエハ

ウエハ表面の金属汚染を高感度に分析するため、フッ酸の蒸気で表面の酸化膜を溶かし、液滴で回収して分析装置にかける前処理の方法はどれか。

  1. A四探針法
  2. BSEM観察
  3. CVPD(気相分解)法
答えと解説を見る

正解：C. VPD(気相分解)法

VPD(Vapor Phase Decomposition)法では、フッ酸の蒸気でウエハ表面の自然酸化膜などを分解し、表面の金属不純物を液滴に集めて回収します。回収した液をICP-MSなどで分析することで、ウエハ全面の微量な金属汚染を高感度に測定できます。

  • A. 四探針法は抵抗率を測る方法です。
  • B. SEM観察は表面の形を見る方法で、微量金属の定量には向きません。
  • C. 正しい。表面の汚染を液滴に集めて分析します。

シリコンウエハのほかの問題

  1. ウエハの表面にある、波長が数mm程度の非常にゆるやかで高さ数十nm程度の凹凸を何と呼ぶか。
  2. CZシリコンに含まれる格子間酸素が、FZシリコンに比べてウエハの機械的強度に与える影響として正しいものはどれか。
  3. CZ結晶の育成中に窒素を微量に添加する(窒素ドープ)ことの効果として知られているものはどれか。
  4. シリコン結晶中の転位や積層欠陥などを光学顕微鏡で観察できるようにするため、欠陥の部分を選択的に浅くエッチングする方法はどれか。
  5. CZ結晶で、結晶の成長界面の温度のゆらぎなどによって生じる、ドーパントや酸素の濃度の周期的な縞状の変化を何と呼ぶか。
