シリコンウエハ

CZ法で単結晶を引き上げ終えるとき、インゴットの直径を少しずつ細くして(テールを絞って)融液から切り離す主な理由はどれか。

  1. A酸素濃度を上げるため
  2. B融液から急に切り離すと熱衝撃でスリップ転位が入り、結晶の中まで伝わるのを防ぐため
  3. Cインゴットを軽くするため
答えと解説を見る

正解：B. 融液から急に切り離すと熱衝撃でスリップ転位が入り、結晶の中まで伝わるのを防ぐため

太い直径のまま融液から切り離すと、急な温度変化による熱応力で転位が発生し、それが結晶の上の方まで伝わって製品になる部分を損ないます。直径を徐々に細くしてから切り離すことで、この転位の発生と伝わりを防ぎます。

  • A. 酸素濃度を上げる目的ではありません。
  • B. 正しい。熱衝撃による転位の発生と伝搬を防ぎます。
  • C. 軽くすることが目的ではありません。

シリコンウエハのほかの問題

  1. CZ法で育成したシリコン結晶に含まれる格子間酸素の濃度の目安として最も近いものはどれか。
  2. シリコンウエハの鏡面研磨(CMPによる仕上げ研磨)で、研磨液の砥粒として一般的に使われるものはどれか。
  3. ヒ素やアンチモンを高濃度に添加した低抵抗のn⁺シリコンウエハの主な用途として正しいものはどれか。
  4. CZシリコンを450℃付近で熱処理すると、酸素原子が集まってドナーとして働き、ウエハの抵抗率が変わることがある。これを何と呼ぶか。
  5. ウエハ表面の金属汚染を高感度に分析するため、フッ酸の蒸気で表面の酸化膜を溶かし、液滴で回収して分析装置にかける前処理の方法はどれか。
