シリコンウエハ

ウエハを熱処理して表面付近の酸素を外に拡散させ、デバイスをつくる表面に欠陥の少ない層をつくる。この層を何と呼ぶか。

  1. A埋め込み酸化膜(BOX層)
  2. BDZ(無欠陥層)
  3. CLDD
答えと解説を見る

正解：B. DZ(無欠陥層)

1100 ℃以上の高温で熱処理して表面付近の酸素を外に拡散させると、表面には酸素析出物のない無欠陥層(DZ:Denuded Zone)が数十µmできます。その後の低温・中温の熱処理で内部に析出物をつくれば、ゲッタリング層になります。デバイスは欠陥のない表面につくり、金属汚染は内部で捕らえる構造です。最近は、水素やアルゴン中のアニールや急速熱処理でこの構造をつくるウエハも使われます。
