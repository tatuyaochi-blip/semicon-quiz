シリコンウエハ

ウエハを熱処理して表面付近の酸素を外に拡散させ、デバイスをつくる表面に欠陥の少ない層をつくる。この層を何と呼ぶか。

  1. A埋め込み酸化膜(BOX層)
  2. BDZ(無欠陥層)
  3. CLDD
答えと解説を見る

正解：B. DZ(無欠陥層)

高温の熱処理で表面付近の酸素を外に逃がすと、表面には酸素析出物のない無欠陥層(DZ:Denuded Zone)ができ、内部には析出物によるゲッタリング層ができます。デバイスは欠陥のない表面につくり、金属汚染は内部で捕らえるという構造です。
