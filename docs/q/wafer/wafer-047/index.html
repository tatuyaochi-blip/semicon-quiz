シリコンウエハ

CZ結晶の育成中に窒素を微量に添加する(窒素ドープ)ことの効果として知られているものはどれか。

  1. A酸素の析出を促進し、結晶に取り込まれる空孔の集合体(ボイド)を小さくする
  2. B結晶の直径が自動的に大きくなる
  3. C結晶がn型の高濃度になる
答えと解説を見る

正解：A. 酸素の析出を促進し、結晶に取り込まれる空孔の集合体(ボイド)を小さくする

微量の窒素を添加すると、酸素析出の核ができやすくなってゲッタリング能力が高まり、また空孔が集まってできるボイド欠陥が小さくなって、その後の熱処理で消しやすくなります。添加量はごく微量で、ドナーとしての影響はほとんど問題になりません。

  • A. 正しい。酸素析出を促進し、ボイドを小さくします。
  • B. 直径は引き上げ条件で決まります。
  • C. 添加量が微量なため、導電型や抵抗率への影響はほとんどありません。
この分野を解く 分野ページへ

シリコンウエハのほかの問題

  1. シリコン結晶中の転位や積層欠陥などを光学顕微鏡で観察できるようにするため、欠陥の部分を選択的に浅くエッチングする方法はどれか。
  2. CZ結晶で、結晶の成長界面の温度のゆらぎなどによって生じる、ドーパントや酸素の濃度の周期的な縞状の変化を何と呼ぶか。
  3. シリコン単結晶が最も割れやすい(へき開しやすい)結晶面はどれか。
  4. LSI用の単結晶シリコンの製造で最も広く使われている方法はどれか。
  5. 現在、最先端のロジックやメモリの量産ラインで主流となっているウエハの直径はどれか。
