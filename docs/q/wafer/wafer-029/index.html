シリコンウエハ

シリコン単結晶インゴットの直径を一定に保つため、引き上げ中に主に調整する条件はどれか。

  1. A引き上げ速度や融液の温度
  2. Bインゴットの色
  3. C工場の照明の明るさ
答えと解説を見る

正解：A. 引き上げ速度や融液の温度

CZ法では、結晶と融液の境界付近の様子をカメラなどで監視し、引き上げ速度やヒーターの出力(融液の温度)を調整して、結晶の直径を一定に保ちます。引き上げ速度は直径だけでなく、結晶に取り込まれる欠陥にも影響します。

シリコンウエハのほかの問題

  1. SiCウエハの製造が難しく、高価である理由の一つとして正しいものはどれか。
  2. LSI用の単結晶シリコンの製造で最も広く使われている方法はどれか。
  3. 現在、最先端のロジックやメモリの量産ラインで主流となっているウエハの直径はどれか。
  4. FZ法(フローティングゾーン法)で作製したシリコン単結晶の特徴として正しいものはどれか。
  5. シリコンウエハの外周に設けるノッチ(小さな切り欠き)の主な役割はどれか。
