シリコンウエハ

シリコンのインゴットを、一度に多数のウエハにスライスするために一般的に使われる装置はどれか。

  1. Aダイシングブレード
  2. Bマルチワイヤーソー
  3. CCMP装置
答えと解説を見る

正解：B. マルチワイヤーソー

マルチワイヤーソーは、細いワイヤーを多数平行に張って走らせ、砥粒やダイヤモンドを付けたワイヤーでインゴットを一度に多数のウエハに切断する装置です。切りしろが小さく、材料の無駄を減らせます。ダイシングブレードは完成したウエハをチップに切り分けるのに使います。

シリコンウエハのほかの問題

  1. ウエハの外周を面取り(ベベル加工)する主な目的はどれか。
  2. CZ法でp型のシリコン結晶をつくるとき、融液に添加する代表的な不純物はどれか。
  3. CZ法で不純物を添加した結晶を引き上げると、結晶の下部(引き上げの後半)ほど不純物濃度が高くなる傾向がある。その理由として正しいものはどれか。
  4. 300 mmの次の口径として開発が進められた450 mmウエハについての説明として適切なものはどれか。
  5. CZウエハの内部で、酸素が析出してできる微小な欠陥(BMD)を利用する目的として正しいものはどれか。
