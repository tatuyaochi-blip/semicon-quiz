シリコンウエハ

シリコンウエハの外周に設けるノッチ(小さな切り欠き)の主な役割はどれか。

  1. A結晶方位の基準を示す
  2. Bウエハを軽くする
  3. C洗浄液を排出する
答えと解説を見る

正解：A. 結晶方位の基準を示す

ノッチは、ウエハの外周にある深さ約1 mmのV字の切り欠きで、結晶方位(例えば<110>方向)を示す目印です。装置はノッチを検出してウエハの向きをそろえ、結晶方位に対して正しい向きでパターンをつくります。結晶方位によってエッチングの速さや移動度が変わるため重要です。150 mm以下では外周の一部を直線に削ったオリエンテーションフラット(オリフラ)が使われ、面積の無駄を減らすためノッチに変わりました。

シリコンウエハのほかの問題

  1. ゲッタリングの説明として正しいものはどれか。
  2. CZ法で育成したシリコン結晶に、るつぼから比較的多く取り込まれる不純物はどれか。
  3. 単結晶インゴットからウエハをつくる工程の順序として最も適切なものはどれか。
  4. SOIウエハの代表的な製造方法として正しいものはどれか。
  5. CMOS LSI用のシリコンウエハで一般的に使われる面方位はどれか。
