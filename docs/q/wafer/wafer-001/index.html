シリコンウエハ

LSI用の単結晶シリコンの製造で最も広く使われている方法はどれか。

  1. Aチョクラルスキー法(CZ法)
  2. Bゾルゲル法
  3. C電解精錬法
答えと解説を見る

正解：A. チョクラルスキー法(CZ法)

CZ法では、石英るつぼで約1420 ℃以上に溶かしたシリコンに種結晶を浸し、回転させながら1時間に数cm程度の速さでゆっくり引き上げて、直径300 mm・長さ2 m前後、重さ数百kgの単結晶インゴットをつくります。大口径化と量産に向いており、LSI用ウエハの大部分がこの方法でつくられています。1916年にポーランドのチョクラルスキーが金属結晶の成長法として考案しました。
