シリコンウエハ

SiCウエハの製造が難しく、高価である理由の一つとして正しいものはどれか。

  1. ACZ法で非常に速く結晶を成長できるため
  2. B原料がシリコンより豊富にあるため
  3. C常圧では融解しないため昇華法などで高温で結晶を成長させる必要があり、成長が遅く欠陥も生じやすいため
答えと解説を見る

正解：C. 常圧では融解しないため昇華法などで高温で結晶を成長させる必要があり、成長が遅く欠陥も生じやすいため

SiCは常圧では融けずに昇華するため、シリコンのように融液から結晶を引き上げることができません。2000 ℃を超える高温で原料を昇華させ、種結晶の上に再結晶させる昇華法などで成長させるため、成長速度が遅く、転位などの欠陥も生じやすくなります。
