シリコンウエハ

CZ法で、結晶の引き上げ速度と結晶中の温度勾配の比(V/G)を制御する主な目的はどれか。

  1. A結晶に取り込まれる点欠陥(空孔や格子間シリコン)の種類と量を制御し、結晶欠陥を減らす
  2. B結晶の色を変える
  3. Cるつぼの寿命を延ばす
答えと解説を見る

正解：A. 結晶に取り込まれる点欠陥(空孔や格子間シリコン)の種類と量を制御し、結晶欠陥を減らす

引き上げ速度Vと温度勾配Gの比によって、結晶に過剰に取り込まれる点欠陥が空孔になるか格子間シリコンになるかが決まります。V/Gを適切に制御すると、それらが集まってできる微小な欠陥(COPなど)の少ない、高品質な結晶が得られます。

シリコンウエハのほかの問題

  1. 高純度の多結晶シリコンの代表的な製造方法はどれか。
  2. 装置の状態確認や膜厚の測定などのために、製品とは別に工程に流すウエハを何と呼ぶか。
  3. シリコンウエハに高い平坦度が求められる主な理由として正しいものはどれか。
  4. シリコンのインゴットを、一度に多数のウエハにスライスするために一般的に使われる装置はどれか。
  5. ウエハの外周を面取り(ベベル加工)する主な目的はどれか。
