シリコンウエハ

直径300 mmのシリコンウエハは、インチで表すとおよそ何インチと呼ばれるか。

  1. A12インチ
  2. B6インチ
  3. C8インチ
答えと解説を見る

正解：A. 12インチ

1インチは約25.4 mmなので、300 mmは約11.8インチになり、一般に「12インチウエハ」と呼ばれます。200 mmは8インチ、150 mmは6インチと呼ばれます。

  • A. 正しい。300 mmは12インチと呼ばれます。
  • B. 6インチは150 mmウエハの呼び方です。
  • C. 8インチは200 mmウエハの呼び方です。
この分野を解く 分野ページへ

シリコンウエハのほかの問題

  1. CZ法などで育成した、ウエハに切り出す前の円柱状の単結晶シリコンの塊を何と呼ぶか。
  2. シリコンウエハが円形をしている主な理由として正しいものはどれか。
  3. シリコンウエハの世界市場で大きなシェアをもつ日本の企業の組み合わせとして正しいものはどれか。
  4. CZ法の引き上げの初めに、種結晶の直後を細く絞って成長させる(ネッキング)目的はどれか。
  5. 大口径のウエハを高温で熱処理するときに問題となる「スリップ」の原因として正しいものはどれか。
