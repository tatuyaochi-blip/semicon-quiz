シリコンウエハ

CMOS LSI用のシリコンウエハで一般的に使われる面方位はどれか。

  1. A(111)
  2. B(100)
  3. C(211)
答えと解説を見る

正解：B. (100)

CMOS LSIには(100)面のウエハが一般的に使われます。(100)面は表面の原子あたりの結合の手が少なく、SiO2との界面の界面準位密度が(111)面の約1/10と低いため、しきい値電圧が安定し、MOSトランジスタの特性が良好になるためです。電子の移動度も(100)面が高くなります。(111)面は酸化速度が速く、かつてバイポーラ素子などで使われていました。

シリコンウエハのほかの問題

  1. シリコンウエハの抵抗率と、添加した不純物濃度の関係として正しいものはどれか。
  2. 300 mmシリコンウエハの標準的な厚さに最も近いものはどれか。
  3. CZ法で、結晶の引き上げ速度と結晶中の温度勾配の比(V/G)を制御する主な目的はどれか。
  4. 高純度の多結晶シリコンの代表的な製造方法はどれか。
  5. 装置の状態確認や膜厚の測定などのために、製品とは別に工程に流すウエハを何と呼ぶか。
