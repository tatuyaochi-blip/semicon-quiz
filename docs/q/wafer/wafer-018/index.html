シリコンウエハ

CZ法でp型のシリコン結晶をつくるとき、融液に添加する代表的な不純物はどれか。

  1. Aリン(P)
  2. Bヒ素(As)
  3. Cホウ素(B)
答えと解説を見る

正解：C. ホウ素(B)

p型にするにはIII族元素のホウ素を融液に添加します。ホウ素は偏析係数が約0.8と1に近く、インゴットの上下で濃度が比較的そろうため扱いやすい不純物です。n型にする場合は、リン、ヒ素、アンチモンなどのV族元素を使います。結晶の抵抗率は添加する量で決まり、LSI用には1〜20 Ω·cm程度のp型が多く使われます。

シリコンウエハのほかの問題

  1. CZ法で不純物を添加した結晶を引き上げると、結晶の下部(引き上げの後半)ほど不純物濃度が高くなる傾向がある。その理由として正しいものはどれか。
  2. 300 mmの次の口径として開発が進められた450 mmウエハについての説明として適切なものはどれか。
  3. CZウエハの内部で、酸素が析出してできる微小な欠陥(BMD)を利用する目的として正しいものはどれか。
  4. ウエハを熱処理して表面付近の酸素を外に拡散させ、デバイスをつくる表面に欠陥の少ない層をつくる。この層を何と呼ぶか。
  5. ウエハの表面や裏面に刻むレーザーマーク(IDマーク)の目的はどれか。
