シリコンウエハ

装置の状態確認や膜厚の測定などのために、製品とは別に工程に流すウエハを何と呼ぶか。

  1. ASOIウエハ
  2. Bエピタキシャルウエハ
  3. Cモニターウエハ(テストウエハ)
答えと解説を見る

正解：C. モニターウエハ(テストウエハ)

モニターウエハは、成膜の膜厚、パーティクルの数、エッチング速度などを確認するために、製品とは別に流すウエハです。装置が正常かどうかを定期的にチェックするのに使われます。使用後は表面を研磨して再生し、繰り返し使うこともあります。

シリコンウエハのほかの問題

  1. シリコンウエハに高い平坦度が求められる主な理由として正しいものはどれか。
  2. シリコンのインゴットを、一度に多数のウエハにスライスするために一般的に使われる装置はどれか。
  3. ウエハの外周を面取り(ベベル加工)する主な目的はどれか。
  4. CZ法でp型のシリコン結晶をつくるとき、融液に添加する代表的な不純物はどれか。
  5. CZ法で不純物を添加した結晶を引き上げると、結晶の下部(引き上げの後半)ほど不純物濃度が高くなる傾向がある。その理由として正しいものはどれか。
