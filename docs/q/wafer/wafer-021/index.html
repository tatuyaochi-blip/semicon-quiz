シリコンウエハ

CZウエハの内部で、酸素が析出してできる微小な欠陥(BMD)を利用する目的として正しいものはどれか。

  1. A金属不純物を捕獲するゲッタリングサイトとして使う
  2. Bウエハを発光させる
  3. Cウエハの強度を下げる
答えと解説を見る

正解：A. 金属不純物を捕獲するゲッタリングサイトとして使う

CZウエハに含まれる酸素は、熱処理によってウエハ内部で析出物(BMD:Bulk Micro Defect)をつくります。この析出物とその周りのひずみが金属不純物を捕らえるため、表面のデバイス領域から金属汚染を遠ざけるイントリンシックゲッタリングに利用されます。

シリコンウエハのほかの問題

  1. ウエハを熱処理して表面付近の酸素を外に拡散させ、デバイスをつくる表面に欠陥の少ない層をつくる。この層を何と呼ぶか。
  2. ウエハの表面や裏面に刻むレーザーマーク(IDマーク)の目的はどれか。
  3. 300 mmウエハで一般的な研磨の方法として正しいものはどれか。
  4. 使用済みのモニターウエハの表面の膜などを除去し、研磨し直して再び使えるようにしたものを何と呼ぶか。
  5. ウエハの抵抗率を非接触で測定する方法として使われるものはどれか。
