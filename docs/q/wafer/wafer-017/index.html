シリコンウエハ

ウエハの外周を面取り(ベベル加工)する主な目的はどれか。

  1. A搬送や工程中の欠け(チッピング)や割れを防ぎ、外周での膜の盛り上がりなども抑えるため
  2. Bウエハを軽くするため
  3. Cウエハの色を変えるため
答えと解説を見る

正解：A. 搬送や工程中の欠け(チッピング)や割れを防ぎ、外周での膜の盛り上がりなども抑えるため

ウエハの角が鋭いままだと、搬送時の接触で欠けやすく、欠けた破片がパーティクルになり、割れの起点にもなります。外周を丸く面取り(ベベル加工)することで欠けや割れを防ぎ、レジストやエピ層が外周で盛り上がる(クラウン)のも抑えられます。外周部はチップには使われませんが、膜のはがれやパーティクルの発生源になりやすいため、ベベル部の洗浄や膜の除去も重要です。

シリコンウエハのほかの問題

  1. CZ法でp型のシリコン結晶をつくるとき、融液に添加する代表的な不純物はどれか。
  2. CZ法で不純物を添加した結晶を引き上げると、結晶の下部(引き上げの後半)ほど不純物濃度が高くなる傾向がある。その理由として正しいものはどれか。
  3. 300 mmの次の口径として開発が進められた450 mmウエハについての説明として適切なものはどれか。
  4. CZウエハの内部で、酸素が析出してできる微小な欠陥(BMD)を利用する目的として正しいものはどれか。
  5. ウエハを熱処理して表面付近の酸素を外に拡散させ、デバイスをつくる表面に欠陥の少ない層をつくる。この層を何と呼ぶか。
