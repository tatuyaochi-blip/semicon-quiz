シリコンウエハ

300 mmウエハで一般的な研磨の方法として正しいものはどれか。

  1. A表と裏の両面を研磨して、高い平坦度を得る
  2. B片面だけを研磨し、裏面は粗いまま残す
  3. C研磨は行わない
答えと解説を見る

正解：A. 表と裏の両面を研磨して、高い平坦度を得る

300 mmウエハでは、厳しい平坦度の要求に応えるため、表面と裏面を同時に研磨する両面研磨が一般的です。その後、表面を仕上げ研磨して鏡面にします。裏面も平滑になるため、ステージへの吸着時の変形やパーティクルの発生も抑えられます。

  3. FZシリコンに中性子を照射し、シリコンの一部をリンに変換して均一なn型にする方法はどれか。
  4. CZ法で、るつぼに磁場をかけて融液の対流を抑え、酸素濃度などを制御する方法はどれか。
  5. シリコン単結晶インゴットの直径を一定に保つため、引き上げ中に主に調整する条件はどれか。
