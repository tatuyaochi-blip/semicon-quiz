シリコンウエハ

CZ法で不純物を添加した結晶を引き上げると、結晶の下部(引き上げの後半)ほど不純物濃度が高くなる傾向がある。その理由として正しいものはどれか。

  1. A重力で不純物が下に沈むため
  2. B多くの不純物の偏析係数が1より小さく、結晶に取り込まれにくい不純物が融液中に濃縮されていくため
  3. C引き上げの後半ほど温度が低いため
答えと解説を見る

正解：B. 多くの不純物の偏析係数が1より小さく、結晶に取り込まれにくい不純物が融液中に濃縮されていくため

結晶が固まるとき、多くの不純物は結晶に取り込まれにくく(偏析係数が1より小さく)、融液側に残ります。引き上げが進むほど融液中の不純物濃度が上がるため、結晶の後半ほど不純物濃度が高く、抵抗率が低くなります。そのためインゴットの位置によって抵抗率が異なります。

シリコンウエハのほかの問題

  1. 300 mmの次の口径として開発が進められた450 mmウエハについての説明として適切なものはどれか。
  2. CZウエハの内部で、酸素が析出してできる微小な欠陥(BMD)を利用する目的として正しいものはどれか。
  3. ウエハを熱処理して表面付近の酸素を外に拡散させ、デバイスをつくる表面に欠陥の少ない層をつくる。この層を何と呼ぶか。
  4. ウエハの表面や裏面に刻むレーザーマーク(IDマーク)の目的はどれか。
  5. 300 mmウエハで一般的な研磨の方法として正しいものはどれか。
