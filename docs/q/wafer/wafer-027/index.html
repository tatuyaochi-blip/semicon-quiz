シリコンウエハ

FZシリコンに中性子を照射し、シリコンの一部をリンに変換して均一なn型にする方法はどれか。

  1. A中性子照射ドーピング(NTD)
  2. Bイオン注入
  3. C熱拡散
答えと解説を見る

正解：A. 中性子照射ドーピング(NTD)

シリコンに中性子を当てると、約3%含まれる同位体Si-30が中性子を吸収してSi-31になり、半減期約2.6時間でβ崩壊してリン(P-31)になります。中性子は結晶全体に均一に届くため、偏析のある通常のドーピングでは得られない、抵抗率のばらつきが数%以下の非常に均一なn型ウエハが得られます。原子炉を使うため供給量は限られ、高耐圧のパワーデバイス(サイリスタやIGBT)に使われます。
