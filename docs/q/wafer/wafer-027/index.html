シリコンウエハ

FZシリコンに中性子を照射し、シリコンの一部をリンに変換して均一なn型にする方法はどれか。

  1. A中性子照射ドーピング(NTD)
  2. Bイオン注入
  3. C熱拡散
答えと解説を見る

正解：A. 中性子照射ドーピング(NTD)

シリコンに中性子を当てると、一部のシリコン(Si-30)が中性子を吸収してSi-31になり、それが崩壊してリンになります。結晶全体に均一にリンができるため、抵抗率のばらつきが非常に小さいn型ウエハが得られ、高耐圧のパワーデバイスなどに使われます。

シリコンウエハのほかの問題

  1. CZ法で、るつぼに磁場をかけて融液の対流を抑え、酸素濃度などを制御する方法はどれか。
  2. シリコン単結晶インゴットの直径を一定に保つため、引き上げ中に主に調整する条件はどれか。
  3. SiCウエハの製造が難しく、高価である理由の一つとして正しいものはどれか。
  4. LSI用の単結晶シリコンの製造で最も広く使われている方法はどれか。
  5. 現在、最先端のロジックやメモリの量産ラインで主流となっているウエハの直径はどれか。
