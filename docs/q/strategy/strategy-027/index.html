経営戦略と会計の基礎(ストラテジ系)

プロダクトライフサイクルで、売上の伸びが鈍って市場が飽和に近づき、競合が多くなって価格競争が激しくなる段階はどれか。

  1. A成長期
  2. B成熟期
  3. C衰退期
答えと解説を見る

正解：B. 成熟期

プロダクトライフサイクルは、製品が市場に出てから姿を消すまでを、導入期・成長期・成熟期・衰退期の4つの段階に分けて考えるものです。成熟期には売上の伸びが鈍り、多くの競合が似た製品を出すので価格競争が激しくなり、製品の改良や差別化、コストの削減で利益を確保することが重要になります。成長期は売上が急速に伸びて新しい競合が参入してくる段階、衰退期は売上が減っていき、撤退や生産の終了を検討する段階です。

  • A. 売上が急速に伸び、新しい競合が次々に参入してくる段階です。
  • B. 正しい。売上の伸びが鈍り、価格競争が激しくなる段階です。
  • C. 売上と利益が減っていき、撤退や生産の終了を検討する段階です。

経営戦略と会計の基礎(ストラテジ系)のほかの問題

  1. マイコンメーカーが、市場を用途によって車載・産業機器・家電などに分け、その中から車載市場を狙うことに決めた。そのうえで、「長期にわたる安定供給と高い信頼性」を打ち出して、競合製品とは違う位置付けを顧客に認識してもらう取組みを進めている。この最後の取組みに当たるSTPの段階はどれか。
  2. ある企業が新しい計測装置を発売するときに、新しい技術を高く評価して早く導入したい一部の顧客向けに高い価格を付けて開発費を早く回収し、その後、需要に合わせて段階的に価格を下げていく方針をとった。この価格戦略はどれか。
  3. 8種類の製品の年間売上高(万円)は、製品1が380、製品2が55、製品3が260、製品4が30、製品5が130、製品6が85、製品7が40、製品8が20である。売上高の大きい順に並べ、累積構成比が70%以下の製品をA、70%を超え90%以下の製品をB、それ以外をCとするABC分析を行ったとき、Bに分類される製品はどれか。
  4. ある工場の月ごとのウエハの投入枚数x(千枚)と電力費y(百万円)は、(x, y) = (2, 5)、(4, 9)、(6, 11)、(8, 15)だった。最小二乗法で回帰直線 y = ax + b を求め、傾きaを1千枚あたりの変動費、切片bを固定費とみなすとき、その組合せとして正しいものはどれか。
  5. 新しい製造ラインへの投資を検討している。大規模投資(投資額10億円)では、需要が大きい場合(確率0.6)に25億円、小さい場合(確率0.4)に8億円の収入が見込まれる。小規模投資(投資額4億円)では、需要が小さい場合の収入は7億円で、需要が大きい場合は、そのままなら12億円の収入だが、その時点で5億円を追加投資すると収入が22億円になる。収入から投資額を引いた利益の期待値が最大になる方針をとるとき、その期待値はどれか。
