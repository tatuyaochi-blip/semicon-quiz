クリーンルーム・製造装置

クリーンルームの作業者から出る粒子の量について正しいものはどれか。

  1. Aクリーンスーツを着れば、動き方に関係なくゼロになる
  2. B座っているときのほうが、歩いているときより多い
  3. C体の動きが大きいほど多くなるため、走ったり急な動作をしたりしないようにする
答えと解説を見る

正解：C. 体の動きが大きいほど多くなるため、走ったり急な動作をしたりしないようにする

人は皮膚のかけらや衣服の繊維などの粒子を常に出しており、その量は静止時より歩行時、さらに激しい動作のときに大きく増えます。クリーンスーツで外に出る量を減らしても完全には防げないため、クリーンルームでは走らない、急な動きをしないといった行動のルールも定められています。

  • A. クリーンスーツでもゼロにはなりません。
  • B. 動いているときのほうが多く出ます。
  • C. 正しい。動作が大きいほど発塵が増えます。

クリーンルーム・製造装置のほかの問題

  1. 回路の微細化が進むにつれて、クリーンルームで管理すべき粒子の大きさはどう変わるか。
  2. ウエハを素手で触ってはいけない主な理由はどれか。
  3. ISO 14644-1の清浄度クラスについて正しい説明はどれか。
  4. 天井の一部から清浄な空気を吹き出し、室内の空気と混ぜて薄めながら清浄度を保つ方式のクリーンルームはどれか。清浄度は一方向流より低いが、設備費は安い。
  5. クリーンルームの空気から、アンモニアや有機物などの分子状汚染(AMC)を取り除くために使われるフィルタはどれか。
