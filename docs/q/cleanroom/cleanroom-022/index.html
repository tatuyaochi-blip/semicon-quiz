クリーンルーム・製造装置

200 mmウエハの時代に普及した、カセットを密閉したポッドに入れて装置に受け渡すミニエンバイロメントの方式はどれか。

  1. AFOUP
  2. BSMIF
  3. CEFEM
答えと解説を見る

正解：B. SMIF

SMIF(Standard Mechanical Interface)は、ウエハのカセットを密閉したポッドに入れて運び、装置の上でポッドの底を開けてカセットを装置内に取り込む方式です。ミニエンバイロメントの考え方を広め、300 mmのFOUPへと発展しました。

クリーンルーム・製造装置のほかの問題

  1. ダウンフロー方式のクリーンルームで、床に穴のあいたパネル(グレーチング)を使う理由として正しいものはどれか。
  2. 真空を使うプロセス装置で、反応で生成した有害な物質を含む排ガスを、装置ごとに処理する装置はどれか。
  3. 瞬時電圧低下(瞬低)や停電による、製造中のウエハの損失を防ぐために半導体工場で導入される設備はどれか。
  4. 旧米国連邦規格のクラス100(1立方フィートあたり0.5 µm以上の粒子が100個以下)に相当するISO 14644-1の清浄度クラスはどれか。
  5. ダウンフロー方式のクリーンルームで一般的な、天井からの吹き出し風速の目安はどれか。
