クリーンルーム・製造装置

ガラス繊維のフィルタなどから放出され、ウエハの意図しないドーピング(汚染)の原因になることがある元素はどれか。

  1. Aホウ素(ボロン)
  2. B金
  3. C鉄
答えと解説を見る

正解：A. ホウ素(ボロン)

ガラス繊維のHEPAフィルタには、ホウケイ酸ガラスを使ったものがあり、フッ酸の蒸気などと反応してホウ素を含むガスが放出されることがあります。これがウエハ表面に付着すると、p型の不純物として意図しないドーピングを起こし、特性がずれます。そのため、低ボロンのろ材を使ったフィルタやケミカルフィルタが使われます。金や鉄は深い準位をつくる金属汚染で、フィルタ由来の代表ではありません。

クリーンルーム・製造装置のほかの問題

  1. クリーンルームの一般的な温度の設定値に最も近いものはどれか。
  2. クリーンルームの空気中に含まれる微粒子の数と大きさを測るために使われる装置はどれか。
  3. クリーンルームの入口などの床に置かれ、靴底に付いたほこりを取り除くためのものはどれか。
  4. クリーンルームの作業者から出る粒子の量について正しいものはどれか。
  5. 回路の微細化が進むにつれて、クリーンルームで管理すべき粒子の大きさはどう変わるか。
