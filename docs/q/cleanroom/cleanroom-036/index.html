クリーンルーム・製造装置

ISO 14644-1の清浄度クラスについて正しい説明はどれか。

  1. A数字が大きいほど清浄度が高い
  2. B粒子の数ではなく、粒子の重さで決まる
  3. Cクラスの数字Nが1つ小さくなるごとに、許される粒子の数がおよそ10分の1になる
答えと解説を見る

正解：C. クラスの数字Nが1つ小さくなるごとに、許される粒子の数がおよそ10分の1になる

ISO 14644-1では、ISOクラスNのとき、1 m³あたりの0.1 µm以上の粒子の上限が10のN乗個と定められています(ほかの粒径の上限も式で決まります)。例えばクラス5は10万個、クラス4は1万個で、数字が小さいほど清浄度が高くなります。重さではなく個数濃度で決まります。先端の工場では、ウエハが触れる空間でクラス1〜3程度が求められます。

  • A. 数字が小さいほど清浄度が高くなります。
  • B. 粒子の個数濃度で決まります。
  • C. 正しい。1クラスごとに粒子数の上限が10倍変わります。

クリーンルーム・製造装置のほかの問題

  1. 天井の一部から清浄な空気を吹き出し、室内の空気と混ぜて薄めながら清浄度を保つ方式のクリーンルームはどれか。清浄度は一方向流より低いが、設備費は安い。
  2. クリーンルームの空気から、アンモニアや有機物などの分子状汚染(AMC)を取り除くために使われるフィルタはどれか。
  3. クリーンルームの空調で、取り入れた外気を除じんし、温度と湿度を調整してから室内の循環空気に供給する装置はどれか。
  4. 半導体工場の自動搬送システムで、次の工程に進むまでのFOUPを一時的に保管する自動倉庫はどれか。
  5. ベイ方式の工場の自動搬送で、ベイとベイの間の搬送と、ベイの中で装置間を結ぶ搬送の呼び方の組み合わせとして正しいものはどれか。
