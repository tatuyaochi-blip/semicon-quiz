クリーンルーム・製造装置

クリーンルームの床材や作業台に、導電性(静電気を逃がす性質)をもつ材料が使われる主な理由はどれか。

  1. A床を光らせて明るくするため
  2. B帯電による静電気放電で素子が壊れたり、粒子が静電気で引き寄せられて付着したりするのを防ぐため
  3. C電気を流して床を温めるため
答えと解説を見る

正解：B. 帯電による静電気放電で素子が壊れたり、粒子が静電気で引き寄せられて付着したりするのを防ぐため

クリーンルームには樹脂製の容器や衣服が多く、乾燥していて静電気がたまりやすい環境です。帯電した物や人から放電(ESD)が起こると素子が壊れることがあり、帯電したウエハには粒子が引き寄せられます。導電性の床や作業台、接地したリストストラップ、導電性の靴を組み合わせて、電荷を大地へ逃がします。見た目や床暖房のためではありません。

  • A. 見た目のためではありません。
  • B. 正しい。静電気をためないようにするためです。
  • C. 床暖房のためではありません。
