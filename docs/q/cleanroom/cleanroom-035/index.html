クリーンルーム・製造装置

ウエハを素手で触ってはいけない主な理由はどれか。

  1. A皮脂や汗に含まれるナトリウムなどがウエハを汚染し、素子の特性や信頼性を損なうため
  2. B体温でウエハが溶けるため
  3. C指紋がウエハの結晶方位を変えるため
答えと解説を見る

正解：A. 皮脂や汗に含まれるナトリウムなどがウエハを汚染し、素子の特性や信頼性を損なうため

手の皮脂や汗には有機物や、ナトリウムなどのアルカリ金属が含まれます。ナトリウムは酸化膜の中を動く可動イオンとなってトランジスタのしきい値電圧を変動させ、有機物は成膜や接合の不良の原因になります。そのためウエハは専用の手袋やピンセット、搬送ロボットなどで扱います。

  • A. 正しい。皮脂や汗の成分が汚染源になります。
  • B. 体温でシリコンが溶けることはありません。
  • C. 指紋で結晶方位が変わることはありません。

クリーンルーム・製造装置のほかの問題

  1. ISO 14644-1の清浄度クラスについて正しい説明はどれか。
  2. 天井の一部から清浄な空気を吹き出し、室内の空気と混ぜて薄めながら清浄度を保つ方式のクリーンルームはどれか。清浄度は一方向流より低いが、設備費は安い。
  3. クリーンルームの空気から、アンモニアや有機物などの分子状汚染(AMC)を取り除くために使われるフィルタはどれか。
  4. クリーンルームの空調で、取り入れた外気を除じんし、温度と湿度を調整してから室内の循環空気に供給する装置はどれか。
  5. 半導体工場の自動搬送システムで、次の工程に進むまでのFOUPを一時的に保管する自動倉庫はどれか。
