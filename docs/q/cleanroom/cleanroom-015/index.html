クリーンルーム・製造装置

製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。

  1. AOHT
  2. BULPAフィルタ
  3. CEFEM(ロードポートや搬送ロボットを含む装置前面のモジュール)
答えと解説を見る

正解：C. EFEM(ロードポートや搬送ロボットを含む装置前面のモジュール)

EFEM(Equipment Front End Module)は、FOUPを置くロードポート、ふたを開ける機構、ウエハを取り出して装置内へ運ぶロボットなどを、清浄な空間に収めたモジュールです。ウエハを外気にさらさずに装置とFOUPの間でやり取りできます。

この分野を解く 分野ページへ

クリーンルーム・製造装置のほかの問題

  1. クリーンスーツに求められる性質として正しいものはどれか。
  2. 天井にフィルタとファンを一体化して並べ、清浄な空気を送り出す装置はどれか。
  3. クリーンルームの湿度を極端に低くしすぎないように管理する理由の一つとして正しいものはどれか。
  4. クリーンルーム内への持ち込みが厳しく制限されるものはどれか。
  5. 半導体工場で一般的な、装置のレイアウトの考え方として正しいものはどれか。
