クリーンルーム・製造装置

半導体工場で一般的な、装置のレイアウトの考え方として正しいものはどれか。

  1. A自動車工場のように、工程順に装置を一直線に並べる方式だけが使われる
  2. B同じ種類の装置をまとめたベイ(エリア)ごとに配置し、搬送システムでつなぐジョブショップ型の方式
  3. Cすべての装置を1台ずつ別の建物に置く方式
答えと解説を見る

正解：B. 同じ種類の装置をまとめたベイ(エリア)ごとに配置し、搬送システムでつなぐジョブショップ型の方式

半導体の製造では、成膜・リソグラフィ・エッチングなどを何十回も繰り返すため、ウエハは同じ種類の装置を何度も訪れます。工程順に一直線に並べると同じ装置を何十台も用意する必要があるため、同じ種類の装置をベイにまとめて配置し、自動搬送システムでつなぐジョブショップ型の配置が一般的です。装置を1台ずつ別の建物に置くことはありません。
