クリーンルーム・製造装置

クリーンスーツに求められる性質として正しいものはどれか。

  1. A保温性が非常に高いこと
  2. B目立つ色であること
  3. C繊維くずなどの発塵が少なく、人から出る粒子を外に出しにくいこと
答えと解説を見る

正解：C. 繊維くずなどの発塵が少なく、人から出る粒子を外に出しにくいこと

クリーンスーツは、ポリエステルなどの長い繊維でできた発塵の少ない生地でつくられ、人の体から出る皮膚片や髪の毛、衣服の繊維などを外に出さないように全身を覆います。首や手首、足首は締まる構造にし、帯電を防ぐために導電性の糸を織り込んだものもあります。洗濯も専用の工場で行います。保温性や目立つ色は求められる性質ではありません。
