クリーンルーム・製造装置

ベイ・チェイス方式のクリーンルームで、装置の裏側の保守用の空間(チェイス)の清浄度の扱いとして一般的なものはどれか。

  1. A工場内で最も高い清浄度で管理される
  2. B屋外と同じ環境にされる
  3. Cウエハを扱う作業エリア(ベイ)より低い清浄度で管理されることが多い
答えと解説を見る

正解：C. ウエハを扱う作業エリア(ベイ)より低い清浄度で管理されることが多い

ベイ・チェイス方式では、ウエハを扱う作業エリア(ベイ)を高い清浄度に保ち、装置の裏側の保守用の空間(チェイス)はそれより低い清浄度で管理することが多くあります。清浄度を区分けすることで、建設費や運転費を抑えています。

クリーンルーム・製造装置のほかの問題

  1. ガラス繊維のフィルタなどから放出され、ウエハの意図しないドーピング(汚染)の原因になることがある元素はどれか。
  2. クリーンルームの一般的な温度の設定値に最も近いものはどれか。
  3. クリーンルームの空気中に含まれる微粒子の数と大きさを測るために使われる装置はどれか。
  4. クリーンルームの入口などの床に置かれ、靴底に付いたほこりを取り除くためのものはどれか。
  5. クリーンルームの作業者から出る粒子の量について正しいものはどれか。
