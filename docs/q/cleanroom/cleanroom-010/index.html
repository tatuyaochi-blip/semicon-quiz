クリーンルーム・製造装置

300 mmウエハの工場で、FOUPを天井のレールに沿って装置間で自動搬送するシステムはどれか。

  1. A人手による台車搬送
  2. Bベルトコンベアのみによる搬送
  3. COHT(天井走行式無人搬送車)
答えと解説を見る

正解：C. OHT(天井走行式無人搬送車)

300 mmウエハを25枚入れたFOUPは重いため、人手での搬送は負担が大きく、発塵や落下の危険もあります。OHTは天井のレールを走る搬送車で、FOUPを吊り下げて装置のロードポートまで自動で運びます。工場全体の自動搬送システム(AMHS)の中心となる設備です。

クリーンルーム・製造装置のほかの問題

  1. クリーンルームの入口で、作業者に強い清浄空気を吹き付けて衣服の表面のほこりを落とす設備はどれか。
  2. クリーンルーム、特に露光エリアで温度を非常に厳しく一定に保つ主な理由はどれか。
  3. 露光装置などの精密装置で、床から伝わる振動の影響を抑えるために用いられるものはどれか。
  4. クリーンルームで、空気中にイオンを供給してウエハや装置の帯電を中和する装置はどれか。
  5. 製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。
