クリーンルーム・製造装置

高い清浄度のダウンフロー方式のクリーンルームで、1時間に部屋の空気が入れ替わる回数(換気回数)の目安として最も近いものはどれか。

  1. A数百回
  2. B1回
  3. C5〜10回
答えと解説を見る

正解：A. 数百回

ダウンフロー方式では天井全面から約0.3〜0.5 m/sで空気を吹き出すため、天井の高さが数メートルの部屋では、1時間に数百回も空気が入れ替わる計算になります。一般の事務所の換気回数は数回程度で、クリーンルームは空気を動かすために大きなエネルギーを使っています。

  • A. 正しい。一般の建物よりはるかに多くなります。
  • B. 1回では粒子を十分に排出できません。
  • C. 一般の建物に近い値で、高い清浄度には足りません。

クリーンルーム・製造装置のほかの問題

  2. HEPAフィルタの性能の一般的な定義として正しいものはどれか。
  3. 化学増幅型レジストを使う露光エリアで、アンモニアやアミンなどの塩基性の分子状汚染を特に厳しく管理する理由はどれか。
  4. 半導体工場で、高純度のガスを供給するステンレス配管の内面に電解研磨(EP)が施される主な理由はどれか。
  5. 半導体工場のクリーンルームの床に使われる、格子状に穴のあいた厚いコンクリートの床(ワッフルスラブ)の役割として正しいものはどれか。
