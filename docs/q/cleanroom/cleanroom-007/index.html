クリーンルーム・製造装置

クリーンルーム内の気圧を周囲より高く(陽圧に)保つ主な理由はどれか。

  1. A室内の酸素濃度を高めるため
  2. B騒音を小さくするため
  3. C外部から汚れた空気が入り込むのを防ぐため
答えと解説を見る

正解：C. 外部から汚れた空気が入り込むのを防ぐため

クリーンルームを陽圧にしておくと、扉の開閉時や隙間からは空気が内から外へ流れ、外の汚れた空気が入り込みにくくなります。清浄度の高い部屋ほど気圧を高くし、清浄度の低い区域へ空気が流れるように設計します。

  5. クリーンルーム、特に露光エリアで温度を非常に厳しく一定に保つ主な理由はどれか。
