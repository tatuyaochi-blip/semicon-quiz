クリーンルーム・製造装置

クリーンルームの空気中に含まれる微粒子の数と大きさを測るために使われる装置はどれか。

  1. A光散乱式パーティクルカウンタ
  2. B四探針測定器
  3. Cエリプソメータ
答えと解説を見る

正解：A. 光散乱式パーティクルカウンタ

光散乱式パーティクルカウンタは、吸い込んだ空気にレーザー光を当て、粒子が散乱する光の強さから粒子の大きさを、パルスの数から個数を求めます。クリーンルームの清浄度の評価や、日常の監視に使われます。

  • A. 正しい。散乱光で粒子を数えます。
  • B. 四探針測定器は薄膜やウエハの抵抗率を測る装置です。
  • C. エリプソメータは薄膜の厚さや屈折率を測る装置です。

クリーンルーム・製造装置のほかの問題

  1. クリーンルームの入口などの床に置かれ、靴底に付いたほこりを取り除くためのものはどれか。
  2. クリーンルームの作業者から出る粒子の量について正しいものはどれか。
  3. 回路の微細化が進むにつれて、クリーンルームで管理すべき粒子の大きさはどう変わるか。
  4. ウエハを素手で触ってはいけない主な理由はどれか。
  5. ISO 14644-1の清浄度クラスについて正しい説明はどれか。
