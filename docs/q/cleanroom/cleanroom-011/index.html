クリーンルーム・製造装置

クリーンルームの入口で、作業者に強い清浄空気を吹き付けて衣服の表面のほこりを落とす設備はどれか。

  1. Aパスボックス
  2. Bドラフトチャンバー
  3. Cエアシャワー
答えと解説を見る

正解：C. エアシャワー

エアシャワーは、クリーンルームへの入室時に作業者が通る小部屋で、四方のノズルから毎秒20 m以上の高速の清浄空気を吹き付けて、クリーンスーツの表面に付いたほこりを落とします。両側の扉が同時に開かない仕組みで、外気の流入も防ぎます。物品の受け渡しに使う小さな箱状の設備はパスボックス、ドラフトチャンバーは薬品の蒸気を排気する作業台です。

クリーンルーム・製造装置のほかの問題

  1. クリーンルーム、特に露光エリアで温度を非常に厳しく一定に保つ主な理由はどれか。
  2. 露光装置などの精密装置で、床から伝わる振動の影響を抑えるために用いられるものはどれか。
  3. クリーンルームで、空気中にイオンを供給してウエハや装置の帯電を中和する装置はどれか。
  4. 製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。
  5. クリーンスーツに求められる性質として正しいものはどれか。
