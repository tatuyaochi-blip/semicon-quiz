クリーンルーム・製造装置

クリーンルームの空調で、取り入れた外気を除じんし、温度と湿度を調整してから室内の循環空気に供給する装置はどれか。

  1. Aロードポート
  2. Bスクラバー
  3. C外気処理空調機(外調機、MAU)
答えと解説を見る

正解：C. 外気処理空調機(外調機、MAU)

クリーンルームは陽圧の維持や排気の補給のために外気を取り入れますが、外気は季節によって温度や湿度が大きく変わり、汚れも含みます。外気処理空調機でこれを前処理しておき、室内では循環空気をFFUなどで清浄化しながら細かく温度を調整する、という分担が一般的です。

  • A. ロードポートはFOUPを置いて装置に受け渡す部分です。
  • B. スクラバーは排ガスを洗浄する装置です。
  • C. 正しい。外気をまとめて前処理します。

クリーンルーム・製造装置のほかの問題

  2. ベイ方式の工場の自動搬送で、ベイとベイの間の搬送と、ベイの中で装置間を結ぶ搬送の呼び方の組み合わせとして正しいものはどれか。
  3. 仕切りの少ない大きな部屋の中に製造装置を並べ、FOUPなどの密閉容器とミニエンバイロメントでウエハの清浄度を確保するクリーンルームの方式はどれか。
  4. 高い清浄度のダウンフロー方式のクリーンルームで、1時間に部屋の空気が入れ替わる回数(換気回数)の目安として最も近いものはどれか。
  5. クリーンルームの床材や作業台に、導電性(静電気を逃がす性質)をもつ材料が使われる主な理由はどれか。
