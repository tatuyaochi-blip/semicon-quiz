クリーンルーム・製造装置

半導体工場の自動搬送システムで、次の工程に進むまでのFOUPを一時的に保管する自動倉庫はどれか。

  1. Aストッカ
  2. BEFEM
  3. Cエアシャワー
答えと解説を見る

正解：A. ストッカ

ストッカは、ロボットがFOUPを出し入れする棚を備えた自動倉庫で、装置が空くのを待つFOUPなどを一時的に保管します。中は清浄な空気や窒素で満たされ、OHTなどの搬送システムとつながっていて、生産管理システムの指示で必要なFOUPを払い出します。近年は、天井の空間を使ってレールの横にFOUPを置く小型の保管棚も使われます。

  • A. 正しい。FOUPを一時保管する自動倉庫です。
  • B. EFEMは装置前面でウエハを受け渡すモジュールです。
  • C. エアシャワーは入室時に衣服のほこりを落とす設備です。
この分野を解く 分野ページへ

クリーンルーム・製造装置のほかの問題

  1. ベイ方式の工場の自動搬送で、ベイとベイの間の搬送と、ベイの中で装置間を結ぶ搬送の呼び方の組み合わせとして正しいものはどれか。
  2. 仕切りの少ない大きな部屋の中に製造装置を並べ、FOUPなどの密閉容器とミニエンバイロメントでウエハの清浄度を確保するクリーンルームの方式はどれか。
  3. 高い清浄度のダウンフロー方式のクリーンルームで、1時間に部屋の空気が入れ替わる回数(換気回数)の目安として最も近いものはどれか。
  4. クリーンルームの床材や作業台に、導電性(静電気を逃がす性質)をもつ材料が使われる主な理由はどれか。
  5. HEPAフィルタの性能の一般的な定義として正しいものはどれか。
