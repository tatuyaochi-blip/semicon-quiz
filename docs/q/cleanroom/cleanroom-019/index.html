クリーンルーム・製造装置

クリーンルーム内への持ち込みが厳しく制限されるものはどれか。

  1. Aクリーンルーム専用の紙(無塵紙)
  2. BFOUP
  3. C一般の紙や鉛筆など、発塵しやすい物品
答えと解説を見る

正解：C. 一般の紙や鉛筆など、発塵しやすい物品

一般の紙は繊維が落ちやすく、鉛筆は削りかすや芯の粉が出るため、クリーンルームでは使えません。代わりに、発塵の少ない無塵紙や専用のボールペンを使います。化粧品や整髪料も粒子や分子状汚染の原因になるため、制限されることがあります。持ち込む物品はふき取りや専用の袋への入れ替えを経て、パスボックスなどから入れます。無塵紙やFOUPは使ってよいものです。

クリーンルーム・製造装置のほかの問題

  1. 半導体工場で一般的な、装置のレイアウトの考え方として正しいものはどれか。
  2. FOUPの内部を窒素で置換(パージ)する主な目的はどれか。
  3. 200 mmウエハの時代に普及した、カセットを密閉したポッドに入れて装置に受け渡すミニエンバイロメントの方式はどれか。
  4. ダウンフロー方式のクリーンルームで、床に穴のあいたパネル(グレーチング)を使う理由として正しいものはどれか。
  5. 真空を使うプロセス装置で、反応で生成した有害な物質を含む排ガスを、装置ごとに処理する装置はどれか。
