クリーンルーム・製造装置

クリーンルームで、空気中にイオンを供給してウエハや装置の帯電を中和する装置はどれか。

  1. AULPAフィルタ
  2. Bイオナイザ(除電装置)
  3. Cスクラバー
答えと解説を見る

正解：B. イオナイザ(除電装置)

乾燥したクリーンルームでは静電気が発生しやすく、帯電したウエハやマスクはパーティクルを引き寄せたり、静電気放電でデバイスやマスクのパターンを損傷したりします。イオナイザは、コロナ放電などで正と負のイオンをつくって空気中に供給し、物体の帯電を中和します。接地できない絶縁物の除電に特に有効です。ULPAフィルタは粒子の除去、スクラバーは排ガスの洗浄に使います。

クリーンルーム・製造装置のほかの問題

  1. 製造装置の前面で、FOUPのふたを開け、ウエハを清浄な環境のまま装置内に搬送するユニットはどれか。
  2. クリーンスーツに求められる性質として正しいものはどれか。
  3. 天井にフィルタとファンを一体化して並べ、清浄な空気を送り出す装置はどれか。
  4. クリーンルームの湿度を極端に低くしすぎないように管理する理由の一つとして正しいものはどれか。
  5. クリーンルーム内への持ち込みが厳しく制限されるものはどれか。
