クリーンルーム・製造装置

瞬時電圧低下(瞬低)や停電による、製造中のウエハの損失を防ぐために半導体工場で導入される設備はどれか。

  1. AULPAフィルタ
  2. B無停電電源装置(UPS)や瞬低対策装置
  3. CFOUP
答えと解説を見る

正解：B. 無停電電源装置(UPS)や瞬低対策装置

半導体の製造装置は、0.1秒程度の電圧低下でも停止することがあり、処理中のウエハが不良になったり、真空や温度を戻して再び立ち上げるまでに長い時間がかかったりします。雷などによる瞬低は珍しくないため、重要な装置や設備には無停電電源装置や瞬低対策装置を設けて、電力の供給を途切れさせないようにしています。フィルタやFOUPは電源の対策ではありません。

クリーンルーム・製造装置のほかの問題

  1. 旧米国連邦規格のクラス100(1立方フィートあたり0.5 µm以上の粒子が100個以下)に相当するISO 14644-1の清浄度クラスはどれか。
  2. ダウンフロー方式のクリーンルームで一般的な、天井からの吹き出し風速の目安はどれか。
  3. ベイ・チェイス方式のクリーンルームで、装置の裏側の保守用の空間(チェイス)の清浄度の扱いとして一般的なものはどれか。
  4. ガラス繊維のフィルタなどから放出され、ウエハの意図しないドーピング(汚染)の原因になることがある元素はどれか。
  5. クリーンルームの一般的な温度の設定値に最も近いものはどれか。
