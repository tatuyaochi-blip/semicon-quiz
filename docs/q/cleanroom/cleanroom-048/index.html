クリーンルーム・製造装置

半導体工場のクリーンルームの床に使われる、格子状に穴のあいた厚いコンクリートの床(ワッフルスラブ)の役割として正しいものはどれか。

  1. A高い剛性で振動を抑えながら、穴を通して空気を床下へ流す
  2. B雨水をためる
  3. C床を軽くして建設費を下げる
答えと解説を見る

正解：A. 高い剛性で振動を抑えながら、穴を通して空気を床下へ流す

ワッフルスラブは、格子状の梁で補強された厚いコンクリートの床に多数の穴をあけたもので、ダウンフローの空気を床下へ通す通路になります。同時に高い剛性で、露光装置などの精密な装置に有害な振動を抑えます。穴の上にはグレーチングのパネルを置いて歩けるようにします。

  • A. 正しい。剛性と空気の通り道を両立します。
  • B. 雨水をためる設備ではありません。
  • C. 振動を抑えるため、重く剛性の高い構造です。

クリーンルーム・製造装置のほかの問題

  2. 電子ビーム描画装置や電子顕微鏡などを設置するとき、振動のほかに特に配慮が必要な環境の要因はどれか。
  3. クリーンルームの清浄度は、一般に何によって表されるか。
  4. リソグラフィ工程のエリアで黄色い照明が使われている主な理由はどれか。
  5. FOUPの説明として正しいものはどれか。
