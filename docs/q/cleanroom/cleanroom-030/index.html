クリーンルーム・製造装置

クリーンルームの一般的な温度の設定値に最も近いものはどれか。

  1. A約5 ℃
  2. B約23 ℃
  3. C約40 ℃
答えと解説を見る

正解：B. 約23 ℃

クリーンルームの温度は、作業者の快適さと装置やプロセスの安定性を考えて、一般に23 ℃前後に設定されます。露光装置の周辺などでは、温度の変動をさらに小さな範囲に抑えて管理します。
