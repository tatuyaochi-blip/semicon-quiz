クリーンルーム・製造装置

旧米国連邦規格のクラス100(1立方フィートあたり0.5 µm以上の粒子が100個以下)に相当するISO 14644-1の清浄度クラスはどれか。

  1. AISOクラス5
  2. BISOクラス1
  3. CISOクラス9
答えと解説を見る

正解：A. ISOクラス5

旧米国連邦規格のクラス100は、ISO 14644-1のクラス5にほぼ相当します。ISOクラスは1 m³あたりの粒子数で定義され、数字が1つ小さくなるごとに許される粒子数は1/10になります。かつての呼び方として、現在も「クラス100」などの表現が使われることがあります。

クリーンルーム・製造装置のほかの問題

  1. ダウンフロー方式のクリーンルームで一般的な、天井からの吹き出し風速の目安はどれか。
  2. ベイ・チェイス方式のクリーンルームで、装置の裏側の保守用の空間(チェイス)の清浄度の扱いとして一般的なものはどれか。
  3. ガラス繊維のフィルタなどから放出され、ウエハの意図しないドーピング(汚染)の原因になることがある元素はどれか。
  4. クリーンルームの一般的な温度の設定値に最も近いものはどれか。
  5. クリーンルームの清浄度は、一般に何によって表されるか。
