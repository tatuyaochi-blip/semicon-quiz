クリーンルーム・製造装置

ベイ方式の工場の自動搬送で、ベイとベイの間の搬送と、ベイの中で装置間を結ぶ搬送の呼び方の組み合わせとして正しいものはどれか。

  1. Aフロントエンド搬送とバックエンド搬送
  2. Bインターベイ搬送とイントラベイ搬送
  3. Cウェット搬送とドライ搬送
答えと解説を見る

正解：B. インターベイ搬送とイントラベイ搬送

ベイ方式では、ストッカなどを経由して離れたベイどうしを結ぶインターベイ搬送と、ベイの中で装置どうしや装置とストッカを結ぶイントラベイ搬送を組み合わせてきました。近年の300 mm工場では、OHTが両方を一体的に担い、装置から装置へ直接運ぶ方式も広く使われています。

  • A. 前工程・後工程の区分とは別の話です。
  • B. 正しい。ベイ間がインターベイ、ベイ内がイントラベイです。
  • C. 搬送の区分として、この呼び方は一般的ではありません。

クリーンルーム・製造装置のほかの問題

  1. 仕切りの少ない大きな部屋の中に製造装置を並べ、FOUPなどの密閉容器とミニエンバイロメントでウエハの清浄度を確保するクリーンルームの方式はどれか。
  2. 高い清浄度のダウンフロー方式のクリーンルームで、1時間に部屋の空気が入れ替わる回数(換気回数)の目安として最も近いものはどれか。
  3. クリーンルームの床材や作業台に、導電性(静電気を逃がす性質)をもつ材料が使われる主な理由はどれか。
  4. HEPAフィルタの性能の一般的な定義として正しいものはどれか。
  5. 化学増幅型レジストを使う露光エリアで、アンモニアやアミンなどの塩基性の分子状汚染を特に厳しく管理する理由はどれか。
