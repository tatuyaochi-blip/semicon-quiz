クリーンルーム・製造装置

リソグラフィ工程のエリアで黄色い照明が使われている主な理由はどれか。

  1. A作業者の目の疲れを防ぐため
  2. Bフォトレジストが感光する短波長の光を含まないようにするため
  3. C静電気の発生を防ぐため
答えと解説を見る

正解：B. フォトレジストが感光する短波長の光を含まないようにするため

フォトレジストは紫外線などの短い波長の光に反応します。通常の白色照明には短波長の光が含まれるため、それを取り除いた黄色の照明を使い、意図しない感光を防いでいます。このようなエリアはイエロールームと呼ばれます。
