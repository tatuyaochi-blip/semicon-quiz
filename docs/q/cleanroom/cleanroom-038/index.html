クリーンルーム・製造装置

クリーンルームの空気から、アンモニアや有機物などの分子状汚染(AMC)を取り除くために使われるフィルタはどれか。

  1. AULPAフィルタ
  2. Bケミカルフィルタ(活性炭やイオン交換体を使ったフィルタ)
  3. C金属メッシュのプレフィルタ
答えと解説を見る

正解：B. ケミカルフィルタ(活性炭やイオン交換体を使ったフィルタ)

ULPAやHEPAのフィルタは粒子をとらえますが、ガス状の分子はすり抜けてしまいます。ケミカルフィルタは活性炭やイオン交換樹脂などを使い、酸やアルカリ、有機物などの分子を吸着・反応させて取り除きます。外気の取り入れ口や、露光装置などの重要な装置に使われます。

  • A. ULPAフィルタは粒子をとらえるもので、ガス状の分子は通してしまいます。
  • B. 正しい。吸着や化学反応で分子状汚染を取り除きます。
  • C. プレフィルタは大きなほこりを取るためのものです。

クリーンルーム・製造装置のほかの問題

  1. クリーンルームの空調で、取り入れた外気を除じんし、温度と湿度を調整してから室内の循環空気に供給する装置はどれか。
  2. 半導体工場の自動搬送システムで、次の工程に進むまでのFOUPを一時的に保管する自動倉庫はどれか。
  3. ベイ方式の工場の自動搬送で、ベイとベイの間の搬送と、ベイの中で装置間を結ぶ搬送の呼び方の組み合わせとして正しいものはどれか。
  4. 仕切りの少ない大きな部屋の中に製造装置を並べ、FOUPなどの密閉容器とミニエンバイロメントでウエハの清浄度を確保するクリーンルームの方式はどれか。
  5. 高い清浄度のダウンフロー方式のクリーンルームで、1時間に部屋の空気が入れ替わる回数(換気回数)の目安として最も近いものはどれか。
