クリーンルーム・製造装置

真空を使うプロセス装置で、反応で生成した有害な物質を含む排ガスを、装置ごとに処理する装置はどれか。

  1. A除害装置(ローカルスクラバー)
  2. BFFU
  3. CEFEM
答えと解説を見る

正解：A. 除害装置(ローカルスクラバー)

成膜やエッチングの装置から出る排ガスには、未反応の特殊材料ガスや有害な副生成物が含まれます。除害装置は、装置の近くでこれらを燃焼、熱分解、吸着、水洗などで無害化してから、工場の排気系に送ります。

クリーンルーム・製造装置のほかの問題

  1. 瞬時電圧低下(瞬低)や停電による、製造中のウエハの損失を防ぐために半導体工場で導入される設備はどれか。
  2. 旧米国連邦規格のクラス100(1立方フィートあたり0.5 µm以上の粒子が100個以下)に相当するISO 14644-1の清浄度クラスはどれか。
  3. ダウンフロー方式のクリーンルームで一般的な、天井からの吹き出し風速の目安はどれか。
  4. ベイ・チェイス方式のクリーンルームで、装置の裏側の保守用の空間(チェイス)の清浄度の扱いとして一般的なものはどれか。
  5. ガラス繊維のフィルタなどから放出され、ウエハの意図しないドーピング(汚染)の原因になることがある元素はどれか。
