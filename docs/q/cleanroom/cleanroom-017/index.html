クリーンルーム・製造装置

天井にフィルタとファンを一体化して並べ、清浄な空気を送り出す装置はどれか。

  1. AFFU(ファンフィルタユニット)
  2. BEFEM
  3. COHT
答えと解説を見る

正解：A. FFU(ファンフィルタユニット)

FFUは、送風ファンとHEPA/ULPAフィルタを一体化したユニットで、クリーンルームの天井に多数並べて、清浄な空気を下向きに吹き出します。ユニットごとに風量を調整でき、レイアウトの変更にも対応しやすいため、広く使われています。

クリーンルーム・製造装置のほかの問題

  2. クリーンルーム内への持ち込みが厳しく制限されるものはどれか。
  3. 半導体工場で一般的な、装置のレイアウトの考え方として正しいものはどれか。
  4. FOUPの内部を窒素で置換(パージ)する主な目的はどれか。
  5. 200 mmウエハの時代に普及した、カセットを密閉したポッドに入れて装置に受け渡すミニエンバイロメントの方式はどれか。
