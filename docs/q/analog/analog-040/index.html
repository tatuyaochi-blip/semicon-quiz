アナログ・電子回路

テブナンの定理の内容として正しいものはどれか。

  1. A電源と抵抗からなる線形回路は、ある2端子から見ると、1つの電圧源と直列の1つの抵抗に置き換えられる
  2. B回路の電流は、どの部分でも等しい
  3. Cすべての抵抗を並列に置き換えても電流は変わらない
答えと解説を見る

正解：A. 電源と抵抗からなる線形回路は、ある2端子から見ると、1つの電圧源と直列の1つの抵抗に置き換えられる

テブナンの定理によれば、線形回路は注目する2端子から見ると、開放電圧Vthの電圧源と内部抵抗Rth(電源を取り除いて見た抵抗)の直列に置き換えられます。負荷RLに流れる電流は Vth/(Rth + RL) と簡単に求まり、RL = Rth のとき負荷への電力が最大になる(最大電力供給の定理)こともここから導けます。電流源と並列抵抗に置き換えるのはノートンの定理です。

  • A. 正しい。電圧源と直列抵抗の等価回路に置き換えられます。
  • B. 回路の電流がどこでも等しいのは、直列回路の場合だけです。
  • C. 抵抗のつなぎ方を変えれば、電流は一般に変わります。

アナログ・電子回路のほかの問題

  1. 共振回路のQ値(クオリティファクタ)が大きいことの意味として正しいものはどれか。
  2. 理想的な電流源の出力インピーダンスはどれか。
  3. 水晶発振器が、時計やマイコンのクロック源として広く使われる主な理由はどれか。
  4. LDO(低ドロップアウトのリニアレギュレータ)の「ドロップアウト電圧」の意味として正しいものはどれか。
  5. 1次のローパス特性をもつ回路の帯域幅BWと、ステップ入力に対する立ち上がり時間trの関係として近似的に正しいものはどれか。(10%〜90%の立ち上がり時間)
