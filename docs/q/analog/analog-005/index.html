アナログ・電子回路

オペアンプを使ったボルテージフォロワの説明として正しいものはどれか。

  1. A電圧利得が1で、入力インピーダンスが高く出力インピーダンスが低いため、バッファとして使う
  2. B電圧利得が無限大の比較器として使う
  3. C入力電流を電圧に変換する回路として使う
答えと解説を見る

正解：A. 電圧利得が1で、入力インピーダンスが高く出力インピーダンスが低いため、バッファとして使う

ボルテージフォロワは、出力を反転入力に直接つないだ回路で、出力電圧が入力電圧と等しくなります(利得1)。電圧は増幅しませんが、信号源に負担をかけずに負荷を駆動できるため、インピーダンス変換用のバッファとして使われます。

  3. 電圧利得が100倍の増幅回路の利得をデシベルで表すといくらか。
  4. オペアンプの反転増幅回路で、帰還抵抗をコンデンサに置き換えた回路は何と呼ばれるか。
  5. LC直列共振回路の共振周波数を表す式はどれか。
