アナログ・電子回路

コンデンサのインピーダンス(容量性リアクタンス)の大きさは、周波数が高くなるとどうなるか。

  1. A大きくなる
  2. B小さくなる
  3. C変化しない
答えと解説を見る

正解：B. 小さくなる

コンデンサのインピーダンスの大きさは 1/(2πfC) で、周波数fが高いほど小さくなります。直流(f = 0)は通さず、高い周波数ほど通しやすくなります。この性質をフィルタやバイパスコンデンサに利用します。

  • A. 周波数とともにインピーダンスが大きくなるのはコイル(インダクタ)です。
  • B. 正しい。1/(2πfC) なので周波数が高いほど小さくなります。
  • C. コンデンサのインピーダンスは周波数に強く依存します。

アナログ・電子回路のほかの問題

  1. コイル(インダクタ)のインピーダンスの大きさは、周波数が高くなるとどうなるか。
  2. キルヒホッフの電流則(第1法則)の内容として正しいものはどれか。
  3. コンデンサに一定の電流を流し続けたとき、コンデンサの電圧はどのように変化するか。
  4. フィルタの周波数特性で「−3 dB」の点が表すものとして正しいものはどれか。
  5. 4つの抵抗R1・R2・R3・R4でつくったホイートストンブリッジ(R1とR2、R3とR4がそれぞれ直列で、その2組が並列)で、2組の中点の間に電流が流れない(平衡する)条件はどれか。
