アナログ・電子回路

共振回路のQ値(クオリティファクタ)が大きいことの意味として正しいものはどれか。

  1. A共振周波数が高い
  2. B損失が小さく、共振のピークが鋭い(帯域幅が狭い)
  3. C損失が大きく、帯域幅が広い
答えと解説を見る

正解：B. 損失が小さく、共振のピークが鋭い(帯域幅が狭い)

Q値は共振の鋭さを表し、Q = f0/Δf(共振周波数÷帯域幅)です。Qが大きいほど損失が小さく、ピークが鋭く帯域幅は狭くなります。例えば f0 = 1 MHz、Q = 100 なら帯域幅は10 kHzです。直列RLC回路では Q = (1/R)√(L/C) で、抵抗(損失)が小さいほど大きくなります。周波数選択性の高いフィルタや位相雑音の小さい発振器には高いQが求められます。

  • A. Q値は共振周波数の高さではなく、共振の鋭さを表します。
  • B. 正しい。Qが大きいほど損失が小さく帯域が狭くなります。
  • C. 損失が大きいとQは小さくなり、帯域幅は広がります。

アナログ・電子回路のほかの問題

  1. 理想的な電流源の出力インピーダンスはどれか。
  2. 水晶発振器が、時計やマイコンのクロック源として広く使われる主な理由はどれか。
  3. LDO(低ドロップアウトのリニアレギュレータ)の「ドロップアウト電圧」の意味として正しいものはどれか。
  4. 1次のローパス特性をもつ回路の帯域幅BWと、ステップ入力に対する立ち上がり時間trの関係として近似的に正しいものはどれか。(10%〜90%の立ち上がり時間)
  5. オペアンプの位相補償で使われる「ドミナントポール補償」の考え方として正しいものはどれか。
