アナログ・電子回路

入力が上がるときと下がるときでしきい値が異なり、ノイズによる出力のばたつきを防ぐ回路はどれか。

  1. APLL
  2. Bサンプルホールド回路
  3. Cシュミットトリガ
答えと解説を見る

正解：C. シュミットトリガ

シュミットトリガは、出力を切り替える入力のしきい値にヒステリシス(上昇時と下降時の差)をもたせた回路です。ゆっくり変化する信号やノイズを含む信号を受けても、しきい値付近で出力が何度も切り替わることを防げます。

アナログ・電子回路のほかの問題

  1. 回路の電源電圧の変動が出力にどれだけ伝わりにくいかを表す指標はどれか。
  2. 負帰還増幅回路が発振せずに安定に動作するかを判断する指標はどれか。
  3. A級増幅回路と比べたときのB級プッシュプル増幅回路の特徴として正しいものはどれか。
  4. 理想オペアンプの特性として正しい組み合わせはどれか。
  5. 理想オペアンプを使った反転増幅回路で、入力抵抗Ri = 10 kΩ、帰還抵抗Rf = 100 kΩのとき、電圧利得はいくらか。
