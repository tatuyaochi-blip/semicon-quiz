アナログ・電子回路

オペアンプのスルーレートの意味として正しいものはどれか。

  1. A出力電圧が変化できる最大の速さ
  2. B入力端子に流れる電流の大きさ
  3. C出力に含まれる雑音の大きさ
答えと解説を見る

正解：A. 出力電圧が変化できる最大の速さ

スルーレートは、出力電圧が単位時間あたりに変化できる最大の速さで、V/µsの単位で表します。大振幅で高い周波数の信号を出そうとすると、スルーレートの限界で出力波形がひずみます。

  2. 帰還型の発振回路が発振を持続するための条件として正しいものはどれか。
  3. 負帰還をかけた理想オペアンプ回路で、2つの入力端子の電圧がほぼ等しくなる性質を何と呼ぶか。
  4. オペアンプの入力オフセット電圧の説明として正しいものはどれか。
  5. コンデンサを信号の経路に直列に入れ、抵抗を出力と接地の間に入れたRC回路の特性として正しいものはどれか。
