アナログ・電子回路

温度係数が逆向きの2つの電圧を足し合わせて、温度に依存しにくい約1.2 Vの基準電圧をつくる回路はどれか。

  1. APLL
  2. Bミキサー
  3. Cバンドギャップ基準電圧回路
答えと解説を見る

正解：C. バンドギャップ基準電圧回路

ベース-エミッタ間電圧は温度が上がると下がり、2つのトランジスタのVBEの差は温度に比例して上がります。これらを適切な比で足し合わせると、温度係数が打ち消されて、シリコンのバンドギャップに近い約1.2 Vの安定した電圧が得られます。ADCや電源回路の基準電圧に使われます。

アナログ・電子回路のほかの問題

  1. 基準クロックに位相を合わせながら、その整数倍などの周波数のクロックをつくる回路はどれか。
  2. オペアンプの反転増幅回路で、入力抵抗をコンデンサに置き換えた回路は何と呼ばれるか。
  3. 入力が上がるときと下がるときでしきい値が異なり、ノイズによる出力のばたつきを防ぐ回路はどれか。
  4. 回路の電源電圧の変動が出力にどれだけ伝わりにくいかを表す指標はどれか。
  5. 負帰還増幅回路が発振せずに安定に動作するかを判断する指標はどれか。
