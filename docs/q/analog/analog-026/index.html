アナログ・電子回路

オペアンプの反転増幅回路で、入力抵抗をコンデンサに置き換えた回路は何と呼ばれるか。

  1. A微分回路
  2. B積分回路
  3. C比較器
答えと解説を見る

正解：A. 微分回路

入力にコンデンサ、帰還に抵抗を使うと、出力電圧は入力電圧の時間変化(微分)に比例します。これが微分回路です。高い周波数ほど利得が大きくなるため雑音を増幅しやすく、実際には入力コンデンサに直列に抵抗を入れて高域の利得を制限します。

この分野を解く 分野ページへ

アナログ・電子回路のほかの問題

  1. 入力が上がるときと下がるときでしきい値が異なり、ノイズによる出力のばたつきを防ぐ回路はどれか。
  2. 回路の電源電圧の変動が出力にどれだけ伝わりにくいかを表す指標はどれか。
  3. 負帰還増幅回路が発振せずに安定に動作するかを判断する指標はどれか。
  4. A級増幅回路と比べたときのB級プッシュプル増幅回路の特徴として正しいものはどれか。
  5. 10 kΩの抵抗に1 mAの電流が流れているとき、抵抗の両端の電圧はいくらか。
