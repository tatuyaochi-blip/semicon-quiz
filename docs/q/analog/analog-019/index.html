アナログ・電子回路

リニアレギュレータ(LDOなど)と比べたときのスイッチングレギュレータの特徴として正しいものはどれか。

  1. A効率は低いが、ノイズが非常に少ない
  2. B交流を出力する
  3. C電力変換効率が高いが、スイッチングによるノイズが出やすい
答えと解説を見る

正解：C. 電力変換効率が高いが、スイッチングによるノイズが出やすい

スイッチングレギュレータは、トランジスタを高速にオン・オフしてコイルやコンデンサでエネルギーを受け渡すため、入出力の電圧差が大きくても高い効率が得られます。一方、スイッチングに伴うリプルやノイズが出やすいため、ノイズに敏感な回路ではリニアレギュレータと組み合わせることもあります。

アナログ・電子回路のほかの問題

  1. RC回路のステップ応答で、コンデンサの電圧が最終値の約63%に達するまでの時間はどれか。
  2. フォトダイオードの電流を電圧に変換するために、オペアンプの反転入力に電流を入れ、帰還抵抗で電圧に変える回路はどれか。
  3. センサーの微小な差動信号を高精度に増幅するために使われる、オペアンプ3個などで構成される増幅器はどれか。
  4. 抵抗で発生する熱雑音(ジョンソン雑音)の電圧を大きくする要因として正しいものはどれか。
  5. 温度係数が逆向きの2つの電圧を足し合わせて、温度に依存しにくい約1.2 Vの基準電圧をつくる回路はどれか。
