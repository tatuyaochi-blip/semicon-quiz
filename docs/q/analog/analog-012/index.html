アナログ・電子回路

利得帯域幅積(GBW)が1 MHzのオペアンプで、利得10倍の非反転増幅回路をつくったときの帯域幅はおよそいくらか。

  1. A約10 MHz
  2. B約10 kHz
  3. C約100 kHz
答えと解説を見る

正解：C. 約100 kHz

内部で位相補償されたオペアンプは、開ループ利得が −20 dB/dec で下がるため、利得と帯域幅の積がほぼ一定です。GBWが1 MHzなら、利得10倍の帯域は 1 MHz ÷ 10 = 約100 kHz です。正確には非反転利得(ノイズゲイン)で割るため、反転増幅回路の−10倍は ÷11 で約91 kHz になります。高利得と広帯域を両立したいときは、GBWの大きいオペアンプを選ぶか、増幅を複数段に分けます。

アナログ・電子回路のほかの問題

  1. オペアンプのスルーレートの意味として正しいものはどれか。
  2. 反転増幅回路の反転入力端子に、抵抗を通して複数の入力を接続した回路の働きとして正しいものはどれか。
  3. 帰還型の発振回路が発振を持続するための条件として正しいものはどれか。
  4. 負帰還をかけた理想オペアンプ回路で、2つの入力端子の電圧がほぼ等しくなる性質を何と呼ぶか。
  5. オペアンプの入力オフセット電圧の説明として正しいものはどれか。
