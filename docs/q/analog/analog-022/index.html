アナログ・電子回路

センサーの微小な差動信号を高精度に増幅するために使われる、オペアンプ3個などで構成される増幅器はどれか。

  1. Aパワーアンプ
  2. B計装アンプ(インスツルメンテーションアンプ)
  3. C積分回路
答えと解説を見る

正解：B. 計装アンプ(インスツルメンテーションアンプ)

計装アンプは、入力インピーダンスが高く、同相信号除去比(CMRR)が非常に大きいため、ブリッジ回路などのセンサーから出る小さな差動信号を、同相のノイズに埋もれずに精度よく増幅できます。利得は1本の抵抗で設定できる構成が一般的です。

アナログ・電子回路のほかの問題

  1. 抵抗で発生する熱雑音(ジョンソン雑音)の電圧を大きくする要因として正しいものはどれか。
  2. 温度係数が逆向きの2つの電圧を足し合わせて、温度に依存しにくい約1.2 Vの基準電圧をつくる回路はどれか。
  3. 基準クロックに位相を合わせながら、その整数倍などの周波数のクロックをつくる回路はどれか。
  4. オペアンプの反転増幅回路で、入力抵抗をコンデンサに置き換えた回路は何と呼ばれるか。
  5. 入力が上がるときと下がるときでしきい値が異なり、ノイズによる出力のばたつきを防ぐ回路はどれか。
