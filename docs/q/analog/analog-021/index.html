アナログ・電子回路

フォトダイオードの電流を電圧に変換するために、オペアンプの反転入力に電流を入れ、帰還抵抗で電圧に変える回路はどれか。

  1. A積分回路
  2. B比較器
  3. Cトランスインピーダンスアンプ(電流-電圧変換回路)
答えと解説を見る

正解：C. トランスインピーダンスアンプ(電流-電圧変換回路)

トランスインピーダンスアンプでは反転入力が仮想接地になるため、入力電流はすべて帰還抵抗に流れ、出力は −(入力電流 × 帰還抵抗)です。例えば1 µAを1 MΩで受けると1 Vになります。フォトダイオードの両端の電圧がほぼ0に保たれるため、応答が速く直線性もよくなります。帰還抵抗に並列の小さなコンデンサで発振を防ぎ、光通信の受信器や光センサー、CTスキャナの検出回路に使われます。

アナログ・電子回路のほかの問題

  1. センサーの微小な差動信号を高精度に増幅するために使われる、オペアンプ3個などで構成される増幅器はどれか。
  2. 抵抗で発生する熱雑音(ジョンソン雑音)の電圧を大きくする要因として正しいものはどれか。
  3. 温度係数が逆向きの2つの電圧を足し合わせて、温度に依存しにくい約1.2 Vの基準電圧をつくる回路はどれか。
  4. 基準クロックに位相を合わせながら、その整数倍などの周波数のクロックをつくる回路はどれか。
  5. オペアンプの反転増幅回路で、入力抵抗をコンデンサに置き換えた回路は何と呼ばれるか。

この分野の比較

  • LDOとスイッチングレギュレータの違い：効率・ノイズ・部品・用途を比較リニアレギュレータ(LDO)とスイッチングレギュレータ(DC-DCコンバータ)を、動作の仕組み・効率・発熱・ノイズ・部品点数・昇圧の可否・負荷への応答・用途の観点で表にして比較し、2つを組み合わせる電源の構成も説明しま…
  • ジッタと位相雑音の違い：測る量・単位・測定器・換算・使い分けを比較クロックのゆらぎを時間領域で見るジッタと、周波数領域で見る位相雑音を、測る量・単位・測定器・代表的な指標・積分によるRMSジッタへの換算・使う分野の観点で比較します。
  • A級・AB級・D級アンプの違い：動作原理・効率・ひずみ・発熱・用途を比較A級・AB級・D級の電力増幅回路(アンプ)を、動作原理・導通角・理論上の最大効率・ひずみ・発熱・ノイズ・用途の観点で表にして比較し、B級との関係も説明します。
