アナログ・電子回路

反転増幅回路の反転入力端子に、抵抗を通して複数の入力を接続した回路の働きとして正しいものはどれか。

  1. A各入力電圧の積を出力する
  2. B入力電圧の大小を比較する
  3. C各入力電圧の重み付きの和(符号は反転)を出力する
答えと解説を見る

正解：C. 各入力電圧の重み付きの和(符号は反転)を出力する

反転入力端子は仮想接地なので、各入力から抵抗を通って流れ込む電流が互いに影響せずに足し合わされ、帰還抵抗に流れます。その結果 Vout = −Rf(V1/R1 + V2/R2 + …) となり、重み付きの加算ができます(反転加算回路)。オーディオのミキサーや、抵抗を2進の重み(R、2R、4R…)にした簡単なDAコンバータ、センサー信号へのオフセットの加算に使われます。
