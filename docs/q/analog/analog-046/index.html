アナログ・電子回路

オペアンプの位相補償で使われる「ドミナントポール補償」の考え方として正しいものはどれか。

  1. Aすべての極(ポール)を同じ周波数に集める
  2. B利得をすべての周波数で0 dBにする
  3. C1つの極を十分低い周波数に置き、他の極に達する前に利得を1以下に下げて安定させる
答えと解説を見る

正解：C. 1つの極を十分低い周波数に置き、他の極に達する前に利得を1以下に下げて安定させる

ドミナントポール補償では、コンデンサを加えて1つの極を十分低い周波数に移します。すると利得は低い周波数から −20 dB/dec で下がり、他の極で位相が大きく回る前に利得が1(0 dB)を下回るので、十分な位相余裕が得られ、負帰還をかけても発振しにくくなります。

  • A. 極を同じ周波数に集めると位相が急に回り、かえって不安定になります。
  • B. 利得を全周波数で0 dBにすると増幅器として使えません。
  • C. 正しい。支配的な極で利得を早く下げて安定させます。

アナログ・電子回路のほかの問題

  1. MOSFETで特に目立つ、周波数が低いほど大きくなる雑音はどれか。
  2. スイッチとコンデンサCで電圧をサンプリングしたときに、コンデンサに残る熱雑音の電圧(実効値)として正しいものはどれか。(k:ボルツマン定数、T:絶対温度)
  3. バターワース特性のローパスフィルタの特徴として正しいものはどれか。
  4. バイポーラ入力のオペアンプを使った反転増幅回路で、非反転入力とグラウンドの間に、入力抵抗と帰還抵抗の並列値に等しい抵抗を入れる目的はどれか。
  5. 理想オペアンプの特性として正しい組み合わせはどれか。
