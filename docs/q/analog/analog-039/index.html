アナログ・電子回路

4つの抵抗R1・R2・R3・R4でつくったホイートストンブリッジ(R1とR2、R3とR4がそれぞれ直列で、その2組が並列)で、2組の中点の間に電流が流れない(平衡する)条件はどれか。

  1. AR1 + R2 = R3 + R4
  2. BR1 / R2 = R3 / R4
  3. CR1 × R2 = R3 × R4
答えと解説を見る

正解：B. R1 / R2 = R3 / R4

2組の直列抵抗の中点の電圧が等しければ、中点間に電流は流れません。中点の電圧はそれぞれの分圧比で決まるので、R1/R2 = R3/R4(R1 × R4 = R2 × R3)が平衡条件です。ひずみゲージなどの微小な抵抗変化を高感度に測る回路に使われます。

  • A. 抵抗の和が等しくても、分圧比が等しくなければ平衡しません。
  • B. 正しい。両側の分圧比が等しいことが平衡条件です。
  • C. 積の組み合わせは R1 × R4 = R2 × R3 が正しく、R1 × R2 = R3 × R4 ではありません。

アナログ・電子回路のほかの問題

  1. テブナンの定理の内容として正しいものはどれか。
  2. 共振回路のQ値(クオリティファクタ)が大きいことの意味として正しいものはどれか。
  3. 理想的な電流源の出力インピーダンスはどれか。
  4. 水晶発振器が、時計やマイコンのクロック源として広く使われる主な理由はどれか。
  5. LDO(低ドロップアウトのリニアレギュレータ)の「ドロップアウト電圧」の意味として正しいものはどれか。
