アナログ・電子回路

理想オペアンプを使った非反転増幅回路で、入力側の抵抗R1 = 10 kΩ、帰還抵抗R2 = 90 kΩのとき、電圧利得はいくらか。

  1. A−9倍
  2. B+9倍
  3. C+10倍
答えと解説を見る

正解：C. +10倍

非反転増幅回路の利得は 1 + R2/R1 で、1 + 90/10 = 10倍、出力は入力と同相です。入力が非反転入力に直接入るため入力インピーダンスが非常に高く、信号源に負担をかけないのが利点です。利得は1倍未満にはできません(R2 = 0でボルテージフォロワ)。反転増幅回路の −R2/R1(ここでは−9倍)と混同しないようにしましょう。

アナログ・電子回路のほかの問題

  1. オペアンプを使ったボルテージフォロワの説明として正しいものはどれか。
  2. 増幅回路に負帰還をかけたときの効果として正しいものはどれか。
  3. 差動増幅回路のCMRR(同相信号除去比)が大きいことの意味として正しいものはどれか。
  4. 電圧利得が100倍の増幅回路の利得をデシベルで表すといくらか。
  5. オペアンプの反転増幅回路で、帰還抵抗をコンデンサに置き換えた回路は何と呼ばれるか。
