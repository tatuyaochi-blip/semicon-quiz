アナログ・電子回路

LC直列共振回路の共振周波数を表す式はどれか。

  1. A2π√(LC)
  2. B1 / (2π√(LC))
  3. C√(L / C)
答えと解説を見る

正解：B. 1 / (2π√(LC))

LC回路では、コイルのリアクタンス2πfLとコンデンサのリアクタンス1/(2πfC)が等しくなる周波数で共振します。これを解くと f = 1 / (2π√(LC)) となります。発振回路や同調回路、フィルタの設計に使われます。
