アナログ・電子回路

オペアンプの反転増幅回路で、帰還抵抗をコンデンサに置き換えた回路は何と呼ばれるか。

  1. A積分回路
  2. B微分回路
  3. C比較器
答えと解説を見る

正解：A. 積分回路

入力に抵抗R、帰還にコンデンサCを使うと、出力電圧は入力電圧を時間で積分した値に比例します(反転積分回路)。逆に、入力にコンデンサ、帰還に抵抗を使うと微分回路になります。積分回路は波形整形やフィルタ、二重積分型ADCなどに使われます。

  5. 反転増幅回路の反転入力端子に、抵抗を通して複数の入力を接続した回路の働きとして正しいものはどれか。
