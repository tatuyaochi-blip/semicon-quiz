アナログ・電子回路

負帰還をかけた理想オペアンプ回路で、2つの入力端子の電圧がほぼ等しくなる性質を何と呼ぶか。

  1. Aスルーレート
  2. Bオフセット
  3. C仮想短絡(イマジナリーショート)
答えと解説を見る

正解：C. 仮想短絡(イマジナリーショート)

開ループ利得Aが非常に大きいオペアンプに負帰還をかけると、出力が有限の値でつり合うために入力端子間の電圧差は Vout/A とほぼ0になります。実際につながっていないのに短絡したように見えるため仮想短絡と呼び、非反転入力が接地されていれば反転入力も0 V(仮想接地)とみなせます。オペアンプ回路の解析の基本ですが、出力が飽和したときや正帰還の回路(コンパレータ)では成り立ちません。

アナログ・電子回路のほかの問題

  1. オペアンプの入力オフセット電圧の説明として正しいものはどれか。
  2. コンデンサを信号の経路に直列に入れ、抵抗を出力と接地の間に入れたRC回路の特性として正しいものはどれか。
  3. リニアレギュレータ(LDOなど)と比べたときのスイッチングレギュレータの特徴として正しいものはどれか。
  4. RC回路のステップ応答で、コンデンサの電圧が最終値の約63%に達するまでの時間はどれか。
  5. フォトダイオードの電流を電圧に変換するために、オペアンプの反転入力に電流を入れ、帰還抵抗で電圧に変える回路はどれか。
