アナログ・電子回路

抵抗R = 1 kΩとコンデンサC = 1 µFで構成したRCローパスフィルタのカットオフ周波数に最も近いものはどれか。

  1. A約16 Hz
  2. B約160 Hz
  3. C約1.6 kHz
答えと解説を見る

正解：B. 約160 Hz

RCフィルタのカットオフ周波数は fc = 1 / (2πRC) です。RC = 1×10³ × 1×10⁻⁶ = 1×10⁻³ s なので、fc = 1 / (2π × 10⁻³) ≈ 159 Hz となり、約160 Hzです。

アナログ・電子回路のほかの問題

  1. 理想オペアンプを使った非反転増幅回路で、入力側の抵抗R1 = 10 kΩ、帰還抵抗R2 = 90 kΩのとき、電圧利得はいくらか。
  2. オペアンプを使ったボルテージフォロワの説明として正しいものはどれか。
  3. 増幅回路に負帰還をかけたときの効果として正しいものはどれか。
  4. 差動増幅回路のCMRR(同相信号除去比)が大きいことの意味として正しいものはどれか。
  5. 電圧利得が100倍の増幅回路の利得をデシベルで表すといくらか。
