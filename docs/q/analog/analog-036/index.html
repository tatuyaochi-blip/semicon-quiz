アナログ・電子回路

キルヒホッフの電流則(第1法則)の内容として正しいものはどれか。

  1. A回路の1つの節点に流れ込む電流の和は、流れ出る電流の和に等しい
  2. B閉じた回路を一周したときの電圧の和はゼロになる
  3. C抵抗に流れる電流は電圧に比例する
答えと解説を見る

正解：A. 回路の1つの節点に流れ込む電流の和は、流れ出る電流の和に等しい

キルヒホッフの電流則は、回路の節点(分岐点)に流れ込む電流の和と流れ出る電流の和が等しいという法則で、電荷の保存を表します。閉回路を一周した電圧の和がゼロになるのは電圧則(第2法則)、電流が電圧に比例するのはオームの法則です。

  • A. 正しい。節点で電流の出入りは等しくなります。
  • B. これはキルヒホッフの電圧則(第2法則)です。
  • C. これはオームの法則です。

  3. 4つの抵抗R1・R2・R3・R4でつくったホイートストンブリッジ(R1とR2、R3とR4がそれぞれ直列で、その2組が並列)で、2組の中点の間に電流が流れない(平衡する)条件はどれか。
  4. テブナンの定理の内容として正しいものはどれか。
  5. 共振回路のQ値(クオリティファクタ)が大きいことの意味として正しいものはどれか。
