アナログ・電子回路

フィルタの周波数特性で「−3 dB」の点が表すものとして正しいものはどれか。

  1. A電力が約1/2(電圧が約0.707倍)になる点
  2. B電圧がちょうど1/3になる点
  3. C電力がゼロになる点
答えと解説を見る

正解：A. 電力が約1/2(電圧が約0.707倍)になる点

−3 dBは、電力では約1/2、電圧では 1/√2 ≈ 0.707倍に当たります。フィルタではこの点をカットオフ周波数とし、通過帯域の境目の目安とします。

  • A. 正しい。電力が半分、電圧が約0.707倍になる点です。
  • B. 電圧1/3は約−9.5 dBです。
  • C. 電力がゼロになるのは −∞ dB です。
