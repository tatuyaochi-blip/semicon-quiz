アナログ・電子回路

フィルタの周波数特性で「−3 dB」の点が表すものとして正しいものはどれか。

  1. A電力が約1/2(電圧が約0.707倍)になる点
  2. B電圧がちょうど1/3になる点
  3. C電力がゼロになる点
答えと解説を見る

正解：A. 電力が約1/2(電圧が約0.707倍)になる点

−3 dBは電力で約1/2、電圧で 1/√2 ≈ 0.707倍に当たり、フィルタや増幅器ではこの点をカットオフ周波数(帯域の境目)とします。1次のRCフィルタではこの点で位相が45°ずれます。電力半値なので「半値点」とも呼ばれます。−6 dBは電圧1/2、−20 dBは電圧1/10です。dBは比を表すので、何を基準にしたか(dBm、dBVなど)にも注意します。

  • A. 正しい。電力が半分、電圧が約0.707倍になる点です。
  • B. 電圧1/3は約−9.5 dBです。
  • C. 電力がゼロになるのは −∞ dB です。

  2. テブナンの定理の内容として正しいものはどれか。
  3. 共振回路のQ値(クオリティファクタ)が大きいことの意味として正しいものはどれか。
  4. 理想的な電流源の出力インピーダンスはどれか。
  5. 水晶発振器が、時計やマイコンのクロック源として広く使われる主な理由はどれか。
