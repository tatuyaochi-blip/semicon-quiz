アナログ・電子回路

1次のローパス特性をもつ回路の帯域幅BWと、ステップ入力に対する立ち上がり時間trの関係として近似的に正しいものはどれか。(10%〜90%の立ち上がり時間)

  1. Atr ≈ 0.35 / BW
  2. Btr ≈ BW / 0.35
  3. Ctr ≈ 0.35 × BW
答えと解説を見る

正解：A. tr ≈ 0.35 / BW

1次のローパス回路では、10%から90%への立ち上がり時間は約 2.2RC、帯域幅は 1/(2πRC) なので、tr ≈ 2.2/(2π BW) ≈ 0.35/BW となります。帯域幅が広いほど立ち上がりは速くなります。オシロスコープの帯域を選ぶときの目安にも使われます。

  • A. 正しい。tr ≈ 0.35/BW です。
  • B. 時間と周波数は逆数の関係なので、BWを分子に置くのは誤りです。
  • C. 帯域幅が広いほど立ち上がりは速いので、BWに比例するのは誤りです。

アナログ・電子回路のほかの問題

  1. オペアンプの位相補償で使われる「ドミナントポール補償」の考え方として正しいものはどれか。
  2. MOSFETで特に目立つ、周波数が低いほど大きくなる雑音はどれか。
  3. スイッチとコンデンサCで電圧をサンプリングしたときに、コンデンサに残る熱雑音の電圧(実効値)として正しいものはどれか。(k:ボルツマン定数、T:絶対温度)
  4. バターワース特性のローパスフィルタの特徴として正しいものはどれか。
  5. バイポーラ入力のオペアンプを使った反転増幅回路で、非反転入力とグラウンドの間に、入力抵抗と帰還抵抗の並列値に等しい抵抗を入れる目的はどれか。
