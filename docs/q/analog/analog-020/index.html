アナログ・電子回路

RC回路のステップ応答で、コンデンサの電圧が最終値の約63%に達するまでの時間はどれか。

  1. ARC / 2
  2. BRC(時定数)
  3. C5RC
答えと解説を見る

正解：B. RC(時定数)

RC回路のコンデンサの電圧は V(1 − e^(−t/RC)) で変化し、t = RC のとき 1 − 1/e ≈ 63% に達します。このRCが時定数τで、2τで約86%、3τで約95%、5τで99%以上になり、実用上は5τで充電完了とみなします。例えば10 kΩと1 µFなら τ = 10 msです。マイコンのリセット回路の遅延、スイッチのチャタリング除去、カメラのフラッシュの充電時間の見積もりに使われます。

アナログ・電子回路のほかの問題

  1. フォトダイオードの電流を電圧に変換するために、オペアンプの反転入力に電流を入れ、帰還抵抗で電圧に変える回路はどれか。
  2. センサーの微小な差動信号を高精度に増幅するために使われる、オペアンプ3個などで構成される増幅器はどれか。
  3. 抵抗で発生する熱雑音(ジョンソン雑音)の電圧を大きくする要因として正しいものはどれか。
  4. 温度係数が逆向きの2つの電圧を足し合わせて、温度に依存しにくい約1.2 Vの基準電圧をつくる回路はどれか。
  5. 基準クロックに位相を合わせながら、その整数倍などの周波数のクロックをつくる回路はどれか。
