アナログ・電子回路

抵抗で発生する熱雑音(ジョンソン雑音)の電圧を大きくする要因として正しいものはどれか。

  1. A抵抗値が大きいこと、温度が高いこと、帯域が広いこと
  2. B抵抗値が小さいこと
  3. C温度が低いこと
答えと解説を見る

正解：A. 抵抗値が大きいこと、温度が高いこと、帯域が広いこと

熱雑音の電圧は √(4kTRB)(k:ボルツマン定数、T:絶対温度、R:抵抗値、B:帯域幅)で表されます。抵抗が大きく、温度が高く、帯域が広いほど大きくなります。微小な信号を扱う回路では、抵抗値や帯域を必要最小限にすることで雑音を抑えます。

アナログ・電子回路のほかの問題

  1. 温度係数が逆向きの2つの電圧を足し合わせて、温度に依存しにくい約1.2 Vの基準電圧をつくる回路はどれか。
  2. 基準クロックに位相を合わせながら、その整数倍などの周波数のクロックをつくる回路はどれか。
  3. オペアンプの反転増幅回路で、入力抵抗をコンデンサに置き換えた回路は何と呼ばれるか。
  4. 入力が上がるときと下がるときでしきい値が異なり、ノイズによる出力のばたつきを防ぐ回路はどれか。
  5. 回路の電源電圧の変動が出力にどれだけ伝わりにくいかを表す指標はどれか。
