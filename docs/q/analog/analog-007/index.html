アナログ・電子回路

差動増幅回路のCMRR(同相信号除去比)が大きいことの意味として正しいものはどれか。

  1. A消費電力が大きい
  2. B両入力に同じように加わる雑音(同相信号)を除去する能力が高い
  3. C利得が1より小さい
答えと解説を見る

正解：B. 両入力に同じように加わる雑音(同相信号)を除去する能力が高い

差動増幅回路は、2つの入力の差を増幅し、両方に同じように加わる成分(同相信号)は増幅しないのが理想です。CMRRは差動利得と同相利得の比で、大きいほど電源ノイズや誘導ノイズのような同相の雑音に強くなります。
