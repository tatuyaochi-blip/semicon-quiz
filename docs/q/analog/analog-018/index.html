アナログ・電子回路

コンデンサを信号の経路に直列に入れ、抵抗を出力と接地の間に入れたRC回路の特性として正しいものはどれか。

  1. A高い周波数を減衰させ、低い周波数を通す
  2. B低い周波数を減衰させ、高い周波数を通す
  3. Cすべての周波数を同じように通す
答えと解説を見る

正解：B. 低い周波数を減衰させ、高い周波数を通す

コンデンサは低い周波数ほどインピーダンスが大きくなるため、直列に入れると低い周波数の信号を通しにくくなります。この回路は低い周波数を減衰させるハイパスフィルタで、カットオフ周波数はローパスフィルタと同じく 1/(2πRC) です。直流をカットする結合コンデンサとしても使われます。

アナログ・電子回路のほかの問題

  1. リニアレギュレータ(LDOなど)と比べたときのスイッチングレギュレータの特徴として正しいものはどれか。
  2. RC回路のステップ応答で、コンデンサの電圧が最終値の約63%に達するまでの時間はどれか。
  3. フォトダイオードの電流を電圧に変換するために、オペアンプの反転入力に電流を入れ、帰還抵抗で電圧に変える回路はどれか。
  4. センサーの微小な差動信号を高精度に増幅するために使われる、オペアンプ3個などで構成される増幅器はどれか。
  5. 抵抗で発生する熱雑音(ジョンソン雑音)の電圧を大きくする要因として正しいものはどれか。
