半導体物性

ホール効果の測定から分かることとして正しいものはどれか。

  1. Aキャリアの種類(電子か正孔か)とキャリア密度
  2. Bバンドギャップの大きさ
  3. C結晶の融点
答えと解説を見る

正解：A. キャリアの種類(電子か正孔か)とキャリア密度

電流を流した試料に垂直に磁界をかけると、キャリアが曲げられてホール電圧が生じます。その電圧の符号からキャリアが電子か正孔かがわかり、大きさからキャリア密度を求められます。抵抗率の測定と組み合わせると移動度も求められます。

この分野を解く 分野ページへ

半導体物性のほかの問題

  1. 不純物濃度が非常に高く、フェルミ準位が伝導帯や価電子帯の中に入り込んだ半導体を何と呼ぶか。
  2. 半導体のキャリアの拡散係数Dと移動度μの関係を表すアインシュタインの関係式はどれか。(k:ボルツマン定数、T:絶対温度、q:電気素量)
  3. 室温(300 K)における熱電圧 kT/q の値に最も近いものはどれか。
  4. シリコン中のリンがつくるドナー準位の、バンドギャップ内での位置として正しいものはどれか。
  5. ドナー濃度5×10¹⁶ cm⁻³とアクセプタ濃度2×10¹⁶ cm⁻³の両方を含むシリコン(室温、すべてイオン化)の性質として正しいものはどれか。
