半導体物性

シリコンのバンド構造の種類として正しいものはどれか。

  1. A直接遷移型
  2. B間接遷移型
  3. Cバンドギャップをもたない金属型
答えと解説を見る

正解：B. 間接遷移型

シリコンは、伝導帯の底と価電子帯の頂上が運動量(波数)空間で異なる位置にある間接遷移型です。電子と正孔が再結合して光を出すには、運動量を補うフォノン(格子振動)が同時に関わる必要があり、発光効率が非常に低くなります。そのためLEDやレーザーにはGaAs、InP、GaNなどの直接遷移型が使われます。一方、光の吸収はフォノンの助けで起こるので、シリコンも受光素子には使えます。

半導体物性のほかの問題

  1. ホール効果の測定から分かることとして正しいものはどれか。
  2. 不純物濃度が非常に高く、フェルミ準位が伝導帯や価電子帯の中に入り込んだ半導体を何と呼ぶか。
  3. 半導体のキャリアの拡散係数Dと移動度μの関係を表すアインシュタインの関係式はどれか。(k:ボルツマン定数、T:絶対温度、q:電気素量)
  4. 室温(300 K)における熱電圧 kT/q の値に最も近いものはどれか。
  5. シリコン中のリンがつくるドナー準位の、バンドギャップ内での位置として正しいものはどれか。
