半導体物性

シリコン中のリンがつくるドナー準位の、バンドギャップ内での位置として正しいものはどれか。

  1. A伝導帯の下端のすぐ近く(約0.045 eV下)
  2. B価電子帯の上端のすぐ近く
  3. Cバンドギャップのほぼ中央
答えと解説を見る

正解：A. 伝導帯の下端のすぐ近く(約0.045 eV下)

リンのドナー準位は伝導帯の下端から約0.045 eVと非常に浅い位置にあります。室温の熱エネルギー(約0.026 eV)でもほぼすべてのドナーがイオン化し、電子を伝導帯に供給します。バンドギャップの中央付近にできる深い準位は、金などの不純物によるものです。

半導体物性のほかの問題

  1. ドナー濃度5×10¹⁶ cm⁻³とアクセプタ濃度2×10¹⁶ cm⁻³の両方を含むシリコン(室温、すべてイオン化)の性質として正しいものはどれか。
  2. n型シリコンを極低温まで冷やしたとき、キャリア密度が大きく減少する理由として正しいものはどれか。
  3. キャリア濃度が高いときに顕著になる再結合で、再結合で放出されたエネルギーが光ではなく別のキャリアに与えられる過程はどれか。
  4. 電子密度1×10¹⁶ cm⁻³、電子の移動度1000 cm²/V·sのn型シリコンの抵抗率はおよそいくらか。(正孔の寄与は無視、電気素量1.6×10⁻¹⁹ C)
  5. 半導体の真空準位から伝導帯の下端までのエネルギー差を何と呼ぶか。
