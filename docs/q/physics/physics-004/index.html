半導体物性

シリコンにおける電子と正孔の移動度の比較として正しいものはどれか。

  1. A電子の移動度のほうが大きい
  2. B正孔の移動度のほうが大きい
  3. C両者は常に等しい
答えと解説を見る

正解：A. 電子の移動度のほうが大きい

シリコンでは、室温・低不純物濃度で電子の移動度が約1400 cm²/V·s、正孔の移動度が約450 cm²/V·sと、電子の方が約3倍大きくなります。このため、同じ寸法ならnMOSの方がpMOSより大きな電流を流せます。

半導体物性のほかの問題

  1. n型半導体のフェルミ準位の位置として正しいものはどれか。
  2. 真性半導体の抵抗率の温度依存性として正しいものはどれか。
  3. 熱平衡状態の半導体における電子密度nと正孔密度pの積(n×p)として正しいものはどれか。(ni:真性キャリア密度)
  4. 半導体中で拡散電流が流れる原因として正しいものはどれか。
  5. シリコン中の少数キャリアのライフタイム(寿命)を短くする要因として代表的なものはどれか。
