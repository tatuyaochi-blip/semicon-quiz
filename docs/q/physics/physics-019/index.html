半導体物性

半導体のキャリアの拡散係数Dと移動度μの関係を表すアインシュタインの関係式はどれか。(k:ボルツマン定数、T:絶対温度、q:電気素量)

  1. AD = qμ
  2. BD = μ / (kT)
  3. CD = μkT / q
答えと解説を見る

正解：C. D = μkT / q

アインシュタインの関係式は D = μkT/q です。拡散のしやすさとドリフトのしやすさは、どちらもキャリアの散乱で決まるため、互いに比例します。室温ではkT/qは約26 mVなので、例えば μ = 1000 cm²/V·s なら D ≈ 26 cm²/s です。

半導体物性のほかの問題

  1. 室温(300 K)における熱電圧 kT/q の値に最も近いものはどれか。
  2. シリコン中のリンがつくるドナー準位の、バンドギャップ内での位置として正しいものはどれか。
  3. ドナー濃度5×10¹⁶ cm⁻³とアクセプタ濃度2×10¹⁶ cm⁻³の両方を含むシリコン(室温、すべてイオン化)の性質として正しいものはどれか。
  4. n型シリコンを極低温まで冷やしたとき、キャリア密度が大きく減少する理由として正しいものはどれか。
  5. キャリア濃度が高いときに顕著になる再結合で、再結合で放出されたエネルギーが光ではなく別のキャリアに与えられる過程はどれか。
