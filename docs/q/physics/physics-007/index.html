半導体物性

熱平衡状態の半導体における電子密度nと正孔密度pの積(n×p)として正しいものはどれか。(ni:真性キャリア密度)

  1. A常に0になる
  2. Bni の2乗に等しい
  3. C不純物濃度の2乗に等しい
答えと解説を見る

正解：B. ni の2乗に等しい

熱平衡状態では、不純物を添加しても n × p = ni² が成り立ちます(質量作用の法則)。電子を増やすと再結合の相手が増えるため、正孔はその分だけ減るという関係です。例えばシリコン(ni ≈ 1×10¹⁰ cm⁻³)に1×10¹⁶ cm⁻³のドナーを入れると、正孔は1×10⁴ cm⁻³になります。光の照射や電流の注入がある非平衡状態では成り立たず、np > ni² になります。

半導体物性のほかの問題

  1. 半導体中で拡散電流が流れる原因として正しいものはどれか。
  2. シリコン中の少数キャリアのライフタイム(寿命)を短くする要因として代表的なものはどれか。
  3. シリコン単結晶の結晶構造はどれか。
  4. 移動度1000 cm²/V·sの電子に、100 V/cmの電界をかけたときのドリフト速度はいくらか。
  5. 結晶中の電子の運動を、外力に対する応答から自由電子と同じように扱うために導入される質量を何と呼ぶか。
