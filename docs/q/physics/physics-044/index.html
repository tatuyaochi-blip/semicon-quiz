半導体物性

物質の仕事関数の定義として正しいものはどれか。

  1. A伝導帯の下端から価電子帯の上端までのエネルギー差
  2. B真空準位からフェルミ準位までのエネルギー差
  3. C真空準位から伝導帯の下端までのエネルギー差
答えと解説を見る

正解：B. 真空準位からフェルミ準位までのエネルギー差

仕事関数は、フェルミ準位にある電子を真空中に取り出すのに必要なエネルギーで、真空準位とフェルミ準位の差です。半導体ではフェルミ準位が不純物濃度で変わるため、仕事関数も変わります。真空準位から伝導帯の下端までの差は電子親和力です。

  • A. 伝導帯の下端と価電子帯の上端の差はバンドギャップです。
  • B. 正しい。仕事関数は真空準位とフェルミ準位の差です。
  • C. 真空準位から伝導帯の下端までの差は電子親和力です。

半導体物性のほかの問題

  1. シリコンの比誘電率に最も近い値はどれか。
  2. 不純物の少ないシリコンの室温における電子の移動度に最も近い値はどれか。
  3. シリコンのような間接遷移型の半導体で、電子と正孔が再結合して光を出す確率が低い理由として正しいものはどれか。
  4. 光の照射や電流の注入によって熱平衡から外れた半導体で、電子密度と正孔密度をそれぞれ表すために導入される準位を何と呼ぶか。
  5. シリコン結晶の格子定数に最も近い値はどれか。
