半導体物性

シリコンが吸収できる光として正しいものはどれか。

  1. Aすべての波長の光を同じように吸収する
  2. Bバンドギャップより大きいエネルギーをもつ光(波長約1.1 µmより短い光)
  3. Cバンドギャップより小さいエネルギーをもつ光だけ
答えと解説を見る

正解：B. バンドギャップより大きいエネルギーをもつ光(波長約1.1 µmより短い光)

光が電子を価電子帯から伝導帯へ励起するには、バンドギャップ以上のエネルギーが必要です。シリコンの約1.12 eVに対応する波長は約1.1 µmで、これより短い光は吸収され、長い赤外光はほぼ透過します。吸収の深さは波長で大きく異なり、青色光は表面から約0.1〜0.5 µm、赤色光は数µmまで届きます。イメージセンサや太陽電池の設計では、この深さの違いを考慮します。

半導体物性のほかの問題

  1. シリコンのバンド構造の種類として正しいものはどれか。
  2. ホール効果の測定から分かることとして正しいものはどれか。
  3. 不純物濃度が非常に高く、フェルミ準位が伝導帯や価電子帯の中に入り込んだ半導体を何と呼ぶか。
  4. 半導体のキャリアの拡散係数Dと移動度μの関係を表すアインシュタインの関係式はどれか。(k:ボルツマン定数、T:絶対温度、q:電気素量)
  5. 室温(300 K)における熱電圧 kT/q の値に最も近いものはどれか。
