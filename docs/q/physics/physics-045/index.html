半導体物性

シリコンの比誘電率に最も近い値はどれか。

  1. A約11.7
  2. B約80
  3. C約3.9
答えと解説を見る

正解：A. 約11.7

シリコンの比誘電率は約11.7で、空乏層の幅(W = √(2εV/qN))や接合容量の計算に使います。SiO2は約3.9で、ゲート絶縁膜の性能はこの値を基準にした等価酸化膜厚(EOT)で比べます。HfO2(約20〜25)などのHigh-k材料を使えば、物理的に厚くしてトンネル電流を抑えつつ、薄いSiO2と同じ容量が得られます。配線間には逆に誘電率の低いLow-k材料を使います。

  • A. 正しい。シリコンの比誘電率は約11.7です。
  • B. 約80は水の比誘電率です。
  • C. 約3.9は二酸化シリコン(SiO2)の比誘電率です。

半導体物性のほかの問題

  1. 不純物の少ないシリコンの室温における電子の移動度に最も近い値はどれか。
  2. シリコンのような間接遷移型の半導体で、電子と正孔が再結合して光を出す確率が低い理由として正しいものはどれか。
  3. 光の照射や電流の注入によって熱平衡から外れた半導体で、電子密度と正孔密度をそれぞれ表すために導入される準位を何と呼ぶか。
  4. シリコン結晶の格子定数に最も近い値はどれか。
  5. シリコンの真性フェルミ準位が、バンドギャップのちょうど中央からわずかにずれる理由として正しいものはどれか。
