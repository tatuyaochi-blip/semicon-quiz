半導体物性

結晶中の電子の運動を、外力に対する応答から自由電子と同じように扱うために導入される質量を何と呼ぶか。

  1. A静止質量
  2. B原子量
  3. C有効質量
答えと解説を見る

正解：C. 有効質量

結晶中の電子は、周期的な原子の電位の影響を受けるため、真空中の電子とは異なる動き方をします。その影響をまとめて、電子が別の質量をもつかのように扱うのが有効質量です。有効質量が小さいほど移動度は大きくなる傾向があります。
