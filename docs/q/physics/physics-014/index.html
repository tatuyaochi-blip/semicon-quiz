半導体物性

ドナー濃度1×10¹⁶ cm⁻³のn型シリコン(ドナーはすべてイオン化、真性キャリア密度ni = 1×10¹⁰ cm⁻³)の正孔密度はおよそいくらか。

  1. A1×10⁴ cm⁻³
  2. B1×10⁶ cm⁻³
  3. C1×10¹⁰ cm⁻³
答えと解説を見る

正解：A. 1×10⁴ cm⁻³

電子密度はドナー濃度とほぼ等しく n ≈ 1×10¹⁶ cm⁻³ です。質量作用の法則 n × p = ni² より、p = (1×10¹⁰)² / 1×10¹⁶ = 1×10⁴ cm⁻³ となります。多数キャリアに比べて、少数キャリアは非常に少なくなります。

半導体物性のほかの問題

  1. シリコンが吸収できる光として正しいものはどれか。
  2. シリコンのバンド構造の種類として正しいものはどれか。
  3. ホール効果の測定から分かることとして正しいものはどれか。
  4. 不純物濃度が非常に高く、フェルミ準位が伝導帯や価電子帯の中に入り込んだ半導体を何と呼ぶか。
  5. 半導体のキャリアの拡散係数Dと移動度μの関係を表すアインシュタインの関係式はどれか。(k:ボルツマン定数、T:絶対温度、q:電気素量)
