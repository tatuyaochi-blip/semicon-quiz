半導体物性

シリコンのバンドギャップは、温度が上がるとどうなるか。

  1. Aわずかに小さくなる
  2. Bわずかに大きくなる
  3. C温度によらず一定である
答えと解説を見る

正解：A. わずかに小さくなる

温度が上がると、格子の熱膨張や格子振動の影響でバンドギャップはわずかに小さくなります。シリコンでは室温付近で1 Kあたり約0.3 meV小さくなります。この性質は、ダイオードの順方向電圧が温度とともに下がる一因にもなります。

  • A. 正しい。温度が上がるとバンドギャップは少し小さくなります。
  • B. 多くの半導体では、温度上昇でバンドギャップは小さくなります。
  • C. バンドギャップは温度によってわずかに変化します。

半導体物性のほかの問題

  1. シリコン中の電子に強い電界を加えたとき、ドリフト速度はどうなるか。
  2. 波長620 nmの光の光子1個がもつエネルギーに最も近い値はどれか。(E [eV] ≈ 1240 / λ [nm])
  3. シリコンの不純物濃度を高くすると、キャリアの移動度は一般にどうなるか。
  4. 物質の仕事関数の定義として正しいものはどれか。
  5. シリコンの比誘電率に最も近い値はどれか。
