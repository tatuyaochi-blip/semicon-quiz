半導体物性

不純物濃度の低いシリコンで、温度が上がると移動度が下がる主な理由はどれか。

  1. A不純物の数が増えるため
  2. Bキャリアの数が減るため
  3. C格子振動(フォノン)による散乱が増えるため
答えと解説を見る

正解：C. 格子振動(フォノン)による散乱が増えるため

温度が上がると結晶の原子の振動(格子振動)が激しくなり、キャリアが散乱されやすくなるため、移動度は下がります。不純物濃度が高い場合は不純物による散乱も重要になり、低温ではこちらが支配的になります。

半導体物性のほかの問題

  1. 室温におけるシリコンの真性キャリア密度に最も近い値はどれか。
  2. シリコン結晶の原子密度に最も近い値はどれか。
  3. 正孔(ホール)の説明として正しいものはどれか。
  4. 室温におけるゲルマニウム(Ge)のバンドギャップに最も近い値はどれか。
  5. シリコン原子1個がもつ価電子(最外殻電子)の数はいくつか。
