半導体物性

シリコン単結晶の結晶構造はどれか。

  1. A体心立方構造
  2. Bダイヤモンド構造
  3. C塩化ナトリウム型構造
答えと解説を見る

正解：B. ダイヤモンド構造

シリコンは、各原子が4つの隣接原子と共有結合したダイヤモンド構造をとります。ゲルマニウムも同じ構造です。GaAsなどの多くのIII-V族化合物半導体は、ダイヤモンド構造の2種類の位置に異なる原子が入った閃亜鉛鉱型構造をとります。

半導体物性のほかの問題

  1. 移動度1000 cm²/V·sの電子に、100 V/cmの電界をかけたときのドリフト速度はいくらか。
  2. 結晶中の電子の運動を、外力に対する応答から自由電子と同じように扱うために導入される質量を何と呼ぶか。
  3. フェルミ準位の意味として正しいものはどれか。
  4. ドナー濃度1×10¹⁶ cm⁻³のn型シリコン(ドナーはすべてイオン化、真性キャリア密度ni = 1×10¹⁰ cm⁻³)の正孔密度はおよそいくらか。
  5. シリコンが吸収できる光として正しいものはどれか。
