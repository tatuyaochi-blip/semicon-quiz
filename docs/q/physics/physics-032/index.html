半導体物性

シリコン原子1個がもつ価電子(最外殻電子)の数はいくつか。

  1. A5個
  2. B4個
  3. C3個
答えと解説を見る

正解：B. 4個

シリコンは周期表のIV族(14族)の元素で、価電子を4個もちます。結晶中では隣り合う4個の原子と価電子を共有して共有結合をつくります。III族のホウ素は価電子3個、V族のリンは価電子5個で、それぞれアクセプタ、ドナーとして働きます。

  • A. 価電子5個はリンやヒ素などのV族元素です。
  • B. 正しい。IV族元素なので価電子は4個です。
  • C. 価電子3個はホウ素などのIII族元素です。

  2. p型半導体の多数キャリアはどれか。
  3. 次の材料のうち、バンドギャップが最も大きいものはどれか。
  4. キャリアの移動度の単位として正しいものはどれか。
  5. 電子密度n、正孔密度p、電子の移動度μn、正孔の移動度μp、電荷素量qのとき、半導体の導電率σを表す式はどれか。
