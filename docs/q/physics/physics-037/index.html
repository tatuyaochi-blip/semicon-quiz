半導体物性

電子密度n、正孔密度p、電子の移動度μn、正孔の移動度μp、電荷素量qのとき、半導体の導電率σを表す式はどれか。

  1. Aσ = q(nμn + pμp)
  2. Bσ = q(nμn − pμp)
  3. Cσ = (nμn + pμp) / q
答えと解説を見る

正解：A. σ = q(nμn + pμp)

電子と正孔はどちらも電流に寄与し、それぞれの導電率は q n μn と q p μp です。両者は足し合わされるので σ = q(nμn + pμp) となります。抵抗率はその逆数 ρ = 1/σ です。

  • A. 正しい。電子と正孔の寄与を足し合わせます。
  • B. 正孔は電子と逆向きに動きますが電荷も逆なので、電流は同じ向きになり差ではなく和になります。
  • C. 導電率は電荷素量qに比例するので、qで割るのは誤りです。
