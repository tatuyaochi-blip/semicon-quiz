半導体物性

真性半導体の温度を上げたとき、真性キャリア密度はどうなるか。

  1. A増加する
  2. B減少する
  3. C変化しない
答えと解説を見る

正解：A. 増加する

温度が上がると、熱エネルギーによって価電子帯の電子がバンドギャップを越えて伝導帯へ励起されやすくなります。そのため電子と正孔の対が増え、真性キャリア密度はおおむね指数関数的に増加します。

半導体物性のほかの問題

  1. シリコンにおける電子と正孔の移動度の比較として正しいものはどれか。
  2. n型半導体のフェルミ準位の位置として正しいものはどれか。
  3. 真性半導体の抵抗率の温度依存性として正しいものはどれか。
  4. 熱平衡状態の半導体における電子密度nと正孔密度pの積(n×p)として正しいものはどれか。(ni:真性キャリア密度)
  5. 半導体中で拡散電流が流れる原因として正しいものはどれか。
