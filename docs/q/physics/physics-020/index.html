半導体物性

室温(300 K)における熱電圧 kT/q の値に最も近いものはどれか。

  1. A約26 mV
  2. B約0.26 mV
  3. C約2.6 V
答えと解説を見る

正解：A. 約26 mV

ボルツマン定数k ≈ 1.38×10⁻²³ J/K、T = 300 K、電気素量q ≈ 1.6×10⁻¹⁹ Cから、kT/q ≈ 0.0259 V、つまり約26 mVです。ダイオードの電流式やMOSFETのサブスレッショルド特性など、多くの式に現れる重要な値です。

半導体物性のほかの問題

  1. シリコン中のリンがつくるドナー準位の、バンドギャップ内での位置として正しいものはどれか。
  2. ドナー濃度5×10¹⁶ cm⁻³とアクセプタ濃度2×10¹⁶ cm⁻³の両方を含むシリコン(室温、すべてイオン化)の性質として正しいものはどれか。
  3. n型シリコンを極低温まで冷やしたとき、キャリア密度が大きく減少する理由として正しいものはどれか。
  4. キャリア濃度が高いときに顕著になる再結合で、再結合で放出されたエネルギーが光ではなく別のキャリアに与えられる過程はどれか。
  5. 電子密度1×10¹⁶ cm⁻³、電子の移動度1000 cm²/V·sのn型シリコンの抵抗率はおよそいくらか。(正孔の寄与は無視、電気素量1.6×10⁻¹⁹ C)
