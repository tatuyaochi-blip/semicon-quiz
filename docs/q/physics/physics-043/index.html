半導体物性

シリコンの不純物濃度を高くすると、キャリアの移動度は一般にどうなるか。

  1. A変化しない
  2. B小さくなる
  3. C大きくなる
答えと解説を見る

正解：B. 小さくなる

不純物濃度が高くなると、イオン化した不純物によるクーロン散乱(イオン化不純物散乱)が増え、移動度は下がります。シリコンの電子では、10¹⁵ cm⁻³で約1350 cm²/V·sが、10¹⁹ cm⁻³では約100 cm²/V·s程度まで下がります。抵抗率は濃度の増加ほどには下がらない計算になります。MOSFETのチャネルを低ドープに保ちたい理由の1つで、FinFETやGAAは低ドープのチャネルを使えます。

  • A. 不純物濃度は移動度に大きく影響します。
  • B. 正しい。イオン化不純物散乱が増えて移動度は下がります。
  • C. 不純物が増えると散乱が増えるので、移動度は大きくなりません。

半導体物性のほかの問題

  1. 物質の仕事関数の定義として正しいものはどれか。
  2. シリコンの比誘電率に最も近い値はどれか。
  3. 不純物の少ないシリコンの室温における電子の移動度に最も近い値はどれか。
  4. シリコンのような間接遷移型の半導体で、電子と正孔が再結合して光を出す確率が低い理由として正しいものはどれか。
  5. 光の照射や電流の注入によって熱平衡から外れた半導体で、電子密度と正孔密度をそれぞれ表すために導入される準位を何と呼ぶか。
