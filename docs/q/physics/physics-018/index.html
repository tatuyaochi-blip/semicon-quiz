半導体物性

不純物濃度が非常に高く、フェルミ準位が伝導帯や価電子帯の中に入り込んだ半導体を何と呼ぶか。

  1. A真性半導体
  2. B絶縁体
  3. C縮退半導体
答えと解説を見る

正解：C. 縮退半導体

不純物濃度が非常に高く(シリコンではおよそ10¹⁸〜10¹⁹ cm⁻³以上)なると、フェルミ準位が伝導帯や価電子帯の中に入り、金属に近い性質を示します。これが縮退半導体で、n × p = ni² の簡単な式が成り立たなくなり、バンドギャップも見かけ上小さくなります(バンドギャップ狭窄)。MOSFETのソース・ドレインや、電極との低抵抗接触、トンネルダイオードの高濃度領域がその例です。

半導体物性のほかの問題

  1. 半導体のキャリアの拡散係数Dと移動度μの関係を表すアインシュタインの関係式はどれか。(k:ボルツマン定数、T:絶対温度、q:電気素量)
  2. 室温(300 K)における熱電圧 kT/q の値に最も近いものはどれか。
  3. シリコン中のリンがつくるドナー準位の、バンドギャップ内での位置として正しいものはどれか。
  4. ドナー濃度5×10¹⁶ cm⁻³とアクセプタ濃度2×10¹⁶ cm⁻³の両方を含むシリコン(室温、すべてイオン化)の性質として正しいものはどれか。
  5. n型シリコンを極低温まで冷やしたとき、キャリア密度が大きく減少する理由として正しいものはどれか。
