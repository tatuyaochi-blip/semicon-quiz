半導体物性

半導体中で拡散電流が流れる原因として正しいものはどれか。

  1. A電界によるキャリアの移動
  2. B磁界によるキャリアの曲がり
  3. Cキャリア濃度の勾配(濃度差)
答えと解説を見る

正解：C. キャリア濃度の勾配(濃度差)

キャリアは濃度の高い所から低い所へ広がろうとし、この濃度勾配によって流れる電流が拡散電流です(J = qD·dn/dx)。電界で加速されて流れるドリフト電流とは原因が異なります。PN接合では、平衡状態でこの2つがちょうど打ち消し合って電流が0になり、順バイアスでは拡散電流が勝って電流が流れます。バイポーラトランジスタのベースを流れる電流も主に拡散電流です。

  2. シリコン単結晶の結晶構造はどれか。
  3. 移動度1000 cm²/V·sの電子に、100 V/cmの電界をかけたときのドリフト速度はいくらか。

  5. フェルミ準位の意味として正しいものはどれか。

この分野の比較

  • 直接遷移型と間接遷移型の半導体の違い：バンド構造・発光効率・光吸収・材料を比較直接遷移型と間接遷移型の半導体を、バンド構造・フォノンの関与・発光効率・キャリアの寿命・光の吸収の深さ・代表的な材料・用途の観点で表にして比較します。
  • n型半導体とp型半導体の違い：ドーパント・多数キャリア・フェルミ準位・移動度を比較n型とp型の半導体を、添加する不純物(ドナーとアクセプタ)・多数キャリア・不純物準位・フェルミ準位の位置・移動度と抵抗率・デバイスで使われる場所の観点で表にして比較します。
  • 導体・半導体・絶縁体の違い：バンドギャップ・抵抗率・温度特性を比較導体(金属)・半導体・絶縁体を、バンド構造・バンドギャップ・抵抗率・キャリアの数・温度や光による変化・代表的な材料・デバイスでの役割の観点で表にして比較します。
