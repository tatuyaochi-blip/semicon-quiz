半導体物性

n型シリコンを極低温まで冷やしたとき、キャリア密度が大きく減少する理由として正しいものはどれか。

  1. A温度が下がると不純物の数が減るため
  2. B低温では移動度が0になるため
  3. C熱エネルギーが不足し、ドナーから電子が伝導帯に励起されなくなるため(キャリアのフリーズアウト)
答えと解説を見る

正解：C. 熱エネルギーが不足し、ドナーから電子が伝導帯に励起されなくなるため(キャリアのフリーズアウト)

ドナー準位は浅いとはいえ、電子を伝導帯に出すには少しの熱エネルギーが必要です。極低温ではそのエネルギーが不足し、電子がドナーに束縛されたままになるため、キャリア密度が大きく減ります。これをキャリアのフリーズアウトといいます。

この分野を解く 分野ページへ

半導体物性のほかの問題

  1. キャリア濃度が高いときに顕著になる再結合で、再結合で放出されたエネルギーが光ではなく別のキャリアに与えられる過程はどれか。
  2. 電子密度1×10¹⁶ cm⁻³、電子の移動度1000 cm²/V·sのn型シリコンの抵抗率はおよそいくらか。(正孔の寄与は無視、電気素量1.6×10⁻¹⁹ C)
  3. 半導体の真空準位から伝導帯の下端までのエネルギー差を何と呼ぶか。
  4. 不純物濃度の低いシリコンで、温度が上がると移動度が下がる主な理由はどれか。
  5. 室温におけるシリコンの真性キャリア密度に最も近い値はどれか。
