半導体物性

禁制帯の中にできた深い準位(トラップ)を介して電子と正孔が再結合する過程を何と呼ぶか。

  1. ASRH(ショックレー・リード・ホール)再結合
  2. B放射再結合
  3. Cオージェ再結合
答えと解説を見る

正解：A. SRH(ショックレー・リード・ホール)再結合

金属不純物や結晶欠陥がつくる深い準位を介して、電子と正孔が段階的に再結合する過程をSRH再結合といいます。シリコンのような間接遷移型の半導体では主要な再結合過程で、少数キャリアのライフタイムを決める大きな要因になります。

  • A. 正しい。トラップを介する再結合はSRH再結合です。
  • B. 放射再結合は、電子と正孔が直接再結合して光を出す過程で、直接遷移型の半導体で起こりやすくなります。
  • C. オージェ再結合は、放出エネルギーが別のキャリアに渡される過程で、キャリア濃度が高いときに目立ちます。

半導体物性のほかの問題

  1. 少数キャリアの拡散係数をD、ライフタイムをτとしたとき、拡散長Lを表す式はどれか。
  2. シリコンのバンドギャップは、温度が上がるとどうなるか。
  3. シリコン中の電子に強い電界を加えたとき、ドリフト速度はどうなるか。
  4. 波長620 nmの光の光子1個がもつエネルギーに最も近い値はどれか。(E [eV] ≈ 1240 / λ [nm])
  5. シリコンの不純物濃度を高くすると、キャリアの移動度は一般にどうなるか。
