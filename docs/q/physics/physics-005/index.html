半導体物性

n型半導体のフェルミ準位の位置として正しいものはどれか。

  1. A真性フェルミ準位より価電子帯側にある
  2. B真性フェルミ準位より伝導帯側にある
  3. C常に価電子帯の中にある
答えと解説を見る

正解：B. 真性フェルミ準位より伝導帯側にある

ドナーを添加したn型半導体では伝導帯の電子が多くなるため、フェルミ準位はバンドギャップの中央付近にある真性フェルミ準位より伝導帯側に移ります。ドナー濃度が高いほど伝導帯に近づきます。p型では逆に価電子帯側に移ります。

半導体物性のほかの問題

  1. 真性半導体の抵抗率の温度依存性として正しいものはどれか。
  2. 熱平衡状態の半導体における電子密度nと正孔密度pの積(n×p)として正しいものはどれか。(ni:真性キャリア密度)
  3. 半導体中で拡散電流が流れる原因として正しいものはどれか。
  4. シリコン中の少数キャリアのライフタイム(寿命)を短くする要因として代表的なものはどれか。
  5. シリコン単結晶の結晶構造はどれか。
