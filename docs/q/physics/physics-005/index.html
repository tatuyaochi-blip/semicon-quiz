半導体物性

n型半導体のフェルミ準位の位置として正しいものはどれか。

  1. A真性フェルミ準位より価電子帯側にある
  2. B真性フェルミ準位より伝導帯側にある
  3. C常に価電子帯の中にある
答えと解説を見る

正解：B. 真性フェルミ準位より伝導帯側にある

n型では伝導帯の電子が多いため、フェルミ準位はギャップ中央付近の真性フェルミ準位より伝導帯側に移ります。位置は Ec − EF ≈ kT·ln(Nc/ND) で決まり、ドナー濃度が10倍になるごとに約60 mV(室温)ずつ伝導帯に近づきます。p型では逆に価電子帯側に移ります。フェルミ準位は常に禁制帯の中にあるとは限らず、非常に高濃度では帯の中に入ります(縮退半導体)。

関連する計算ツール

シリコンの抵抗率と不純物濃度の換算シリコンの抵抗率と不純物濃度(n型・p型)を相互に換算し、移動度も表示真性キャリア密度の温度依存Si・Ge・GaAsの真性キャリア密度niを温度から計算。不純物濃度を入れると真性化する温度もわかる

半導体物性のほかの問題

  1. 真性半導体の抵抗率の温度依存性として正しいものはどれか。
  2. 熱平衡状態の半導体における電子密度nと正孔密度pの積(n×p)として正しいものはどれか。(ni:真性キャリア密度)
  3. 半導体中で拡散電流が流れる原因として正しいものはどれか。
  4. シリコン中の少数キャリアのライフタイム(寿命)を短くする要因として代表的なものはどれか。
  5. シリコン単結晶の結晶構造はどれか。

この分野の比較

  • 直接遷移型と間接遷移型の半導体の違い：バンド構造・発光効率・光吸収・材料を比較直接遷移型と間接遷移型の半導体を、バンド構造・フォノンの関与・発光効率・キャリアの寿命・光の吸収の深さ・代表的な材料・用途の観点で表にして比較します。
  • n型半導体とp型半導体の違い：ドーパント・多数キャリア・フェルミ準位・移動度を比較n型とp型の半導体を、添加する不純物(ドナーとアクセプタ)・多数キャリア・不純物準位・フェルミ準位の位置・移動度と抵抗率・デバイスで使われる場所の観点で表にして比較します。
  • 導体・半導体・絶縁体の違い：バンドギャップ・抵抗率・温度特性を比較導体(金属)・半導体・絶縁体を、バンド構造・バンドギャップ・抵抗率・キャリアの数・温度や光による変化・代表的な材料・デバイスでの役割の観点で表にして比較します。
