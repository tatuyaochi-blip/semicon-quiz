半導体物性

少数キャリアの拡散係数をD、ライフタイムをτとしたとき、拡散長Lを表す式はどれか。

  1. AL = D / τ
  2. BL = √(D × τ)
  3. CL = D × τ
答えと解説を見る

正解：B. L = √(D × τ)

拡散長は、少数キャリアが再結合するまでに拡散で進むおよその距離で、L = √(Dτ) で表されます。ライフタイムが長いほど、また拡散係数が大きいほど拡散長は長くなります。太陽電池やバイポーラトランジスタの特性を決める重要な量です。

  • A. D/τ の単位は cm²/s² になり、長さになりません。
  • B. 正しい。拡散長は √(Dτ) です。
  • C. D×τ の単位は cm² になり、長さになりません。

半導体物性のほかの問題

  1. シリコンのバンドギャップは、温度が上がるとどうなるか。
  2. シリコン中の電子に強い電界を加えたとき、ドリフト速度はどうなるか。
  3. 波長620 nmの光の光子1個がもつエネルギーに最も近い値はどれか。(E [eV] ≈ 1240 / λ [nm])
  4. シリコンの不純物濃度を高くすると、キャリアの移動度は一般にどうなるか。
  5. 物質の仕事関数の定義として正しいものはどれか。
