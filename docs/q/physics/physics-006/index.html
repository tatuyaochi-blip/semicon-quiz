半導体物性

真性半導体の抵抗率の温度依存性として正しいものはどれか。

  1. A温度が上がると抵抗率が下がる
  2. B温度が上がると抵抗率が上がる
  3. C温度によらず抵抗率は一定である
答えと解説を見る

正解：A. 温度が上がると抵抗率が下がる

真性半導体では、温度が上がると価電子帯から伝導帯へ励起されるキャリアが急に増えるため、抵抗率は下がります。金属はキャリアの数がほぼ一定で、温度が上がると格子振動による散乱が増えるため、逆に抵抗率が上がります。この違いは半導体の大きな特徴です。

半導体物性のほかの問題

  1. 熱平衡状態の半導体における電子密度nと正孔密度pの積(n×p)として正しいものはどれか。(ni:真性キャリア密度)
  2. 半導体中で拡散電流が流れる原因として正しいものはどれか。
  3. シリコン中の少数キャリアのライフタイム(寿命)を短くする要因として代表的なものはどれか。
  4. シリコン単結晶の結晶構造はどれか。
  5. 移動度1000 cm²/V·sの電子に、100 V/cmの電界をかけたときのドリフト速度はいくらか。
