組込み・ファームウェア

SPIの部品をつないでも正しいデータが読めないとき、確かめるべき設定として最も適切なものはどれか。

  1. AI2Cのアドレスが部品と合っているか
  2. BUARTのボーレートが部品と合っているか
  3. Cクロックの極性と位相(CPOLとCPHA、SPIのモード)が部品の仕様と合っているか
答えと解説を見る

正解：C. クロックの極性と位相(CPOLとCPHA、SPIのモード)が部品の仕様と合っているか

SPIには、クロックの待機時の値(CPOL)と、クロックのどちらの変化でデータを読むか(CPHA)の組み合わせで4つのモードがあります。マスタと部品でモードが違うと、データを読むタイミングが半周期ずれ、ビットがずれたり値が不定になったりします。部品のデータシートでモードを確かめ、マイコンのSPIの設定を合わせる必要があります。

  • A. SPIにアドレスはありません。
  • B. SPIはボーレートで合わせる方式ではありません。
  • C. 正しい。4つのモードのどれを使うかは部品によって違います。

組込み・ファームウェアのほかの問題

  1. I2C通信の特徴として正しいものはどれか。
  2. I2Cで、データを1バイト受け取った側が、受け取ったことを知らせる方法として正しいものはどれか。
  3. 同じ型番のI2Cの温度センサを2つ、同じI2Cの線につなぎたいが、どちらも同じアドレスを持っている。対策として正しいものはどれか。
  4. UART・SPI・I2Cを比べた説明として正しいものはどれか。
  5. 周辺回路の状態を知る方法のうち、ポーリングと割り込みの違いとして正しいものはどれか。
