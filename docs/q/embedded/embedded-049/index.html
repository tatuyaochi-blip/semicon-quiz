組込み・ファームウェア

マイコンのブラウンアウト検出(BOD、ブラウンアウトリセット)の役割として正しいものはどれか。

  1. A電源の電圧が動作に必要な値より下がったときにマイコンをリセットし、不確かな動作を防ぐ
  2. B部屋が暗くなったときに、LEDを点灯させる
  3. C電源の電圧を、自動で高くする
答えと解説を見る

正解：A. 電源の電圧が動作に必要な値より下がったときにマイコンをリセットし、不確かな動作を防ぐ

電池が減ったり電源が不安定になったりして電圧が下がると、マイコンの回路は正しく動く保証がなくなり、命令を誤って実行したり、フラッシュにでたらめな値を書いたりする恐れがあります。ブラウンアウト検出は、電圧が決められた値を下回るとマイコンをリセット状態に保ち、電圧が十分に戻ってから動き出させます。データを守るために重要な機能です。

  • A. 正しい。フラッシュへの誤った書き込みなども防ぎます。
  • B. 明るさのセンサの機能ではありません。
  • C. 電圧を上げる機能ではありません。

組込み・ファームウェアのほかの問題

  1. 割り込みに優先度を付けられるマイコンで、優先度の低い割り込みのハンドラを実行中に、優先度の高い割り込みが起きた。一般にどうなるか(割り込みのネストを許す設定とする)。
  2. C言語で、レジスタregのビット3だけを1にし、ほかのビットは変えない書き方として正しいものはどれか。
  3. C言語で、レジスタregのビット3だけを0にし、ほかのビットは変えない書き方として正しいものはどれか。
  4. LEDをつないだ出力端子のビットを、実行するたびに点灯と消灯で切り替えたい。C言語の書き方として正しいものはどれか。
  5. 入力用のレジスタinのビット5が1かどうかを調べるC言語の条件として正しいものはどれか。
