組込み・ファームウェア

115200 bpsのUARTで、データ8ビット・パリティなし・ストップビット1(8N1)の形式で送るとき、1秒間に送れるバイト数に最も近いものはどれか。

  1. A約14400バイト
  2. B約11500バイト
  3. C約115200バイト
答えと解説を見る

正解：B. 約11500バイト

8N1の形式では、1バイトのデータを送るのにスタートビット1、データ8、ストップビット1の合計10ビットが必要です。115200÷10=11520なので、1秒間に約11500バイト、1バイトあたり約87 µsかかります。ログを大量に出すと思ったより時間がかかり、処理の遅れの原因になることがあるので、出力の量やバッファの使い方に注意が必要です。

  • A. スタートビットとストップビットを含めずに8で割った値です。
  • B. 正しい。1バイトに10ビットかかります。
  • C. ビットの数をバイトの数とみなしています。

組込み・ファームウェアのほかの問題

  1. UARTの送信側と受信側のボーレートが少しずれていると、文字化けが起こることがある。ずれの許容範囲がおよそ数%程度に限られる理由として正しいものはどれか。
  2. SPI通信の特徴として正しいものはどれか。
  3. SPIで一般に使われる4本の信号の組み合わせとして正しいものはどれか。
  4. SPIの部品をつないでも正しいデータが読めないとき、確かめるべき設定として最も適切なものはどれか。
  5. I2C通信の特徴として正しいものはどれか。
