組込み・ファームウェア

マイコンの入力端子にスイッチだけをつなぎ、プルアップやプルダウンの抵抗を付けなかった。スイッチが開いているときに起こりうることはどれか。

  1. A端子は必ず1として読める
  2. B端子の電位が定まらず(浮いた状態)、雑音で0と1が不規則に変わって読める
  3. Cマイコンの電源が切れる
答えと解説を見る

正解：B. 端子の電位が定まらず(浮いた状態)、雑音で0と1が不規則に変わって読める

CMOSの入力端子はほとんど電流が流れないので、何もつながっていないと電位が決まらず、近くの信号や手を近づけたことによる雑音で値が変わります。入力回路が中間の電位で貫通電流を流し、消費電力が増えることもあります。プルアップ抵抗で電源につないでおけば、スイッチが開いているときは1、閉じて接地すると0と、確実に読めます。多くのマイコンは内蔵のプルアップを設定できます。

  • A. 何もつながっていないと、値は定まりません。
  • B. 正しい。抵抗でどちらかの電位に固定する必要があります。
  • C. 電源が切れることはありません。

組込み・ファームウェアのほかの問題

  1. マイコンのGPIO(汎用入出力)の端子を使うときに、最初に設定する必要があることとして正しいものはどれか。
  2. 機械式のスイッチを押したときに、接点が細かく跳ねて短い時間に何度もオンとオフを繰り返す現象を何と呼ぶか。
  3. ソフトウェアでスイッチのチャタリングを取り除く方法として最も適切なものはどれか。
  4. 16 MHzのクロックをプリスケーラで16分周したものでタイマを数え、1000カウントごとに割り込みを起こす設定にした。割り込みの間隔はいくらか。
  5. 周期が1000カウントのPWM信号で、1周期のうち250カウントの間だけ出力を1(High)にしている。デューティ比はいくらか。

この分野の比較

  • I2C・SPI・UARTの違い：配線・速度・使い分けを比較I2C、SPI、UARTを、配線の数・クロック・速度・接続形態・アドレス・誤り検出・マイコンでの主な用途の観点で表にして比較します。
  • MCUとMPUの違い：マイコンとマイクロプロセッサを比較MCUとMPUを、集積度・クロック・メモリ・OS・リアルタイム性・消費電力・起動時間・コスト・用途の観点で表にして比較します。
  • 割り込みとポーリングの違い：仕組みと使い分けを比較割り込みとポーリングを、仕組み・CPUの使用・応答時間・オーバーヘッド・複雑さ・消費電力・組み込みやOSでの用途の観点で表にして比較します。
