組込み・ファームウェア

周期が1000カウントのPWM信号で、1周期のうち250カウントの間だけ出力を1(High)にしている。デューティ比はいくらか。

  1. A75%
  2. B25%
  3. C250%
答えと解説を見る

正解：B. 25%

デューティ比は、1周期のうち出力がHighになっている時間の割合で、250÷1000=25%です。PWM(パルス幅変調)は、周期を一定にしたままHighの時間の長さを変えることで、平均の電圧や電力を調整します。マイコンのタイマは、カウンタの値と比較の値を比べて出力を切り替えることで、CPUの手を借りずにPWM信号を出し続けられます。

  • A. 75%は出力が0の時間の割合です。
  • B. 正しい。250÷1000=0.25です。
  • C. 割合は100%を超えません。

組込み・ファームウェアのほかの問題

  1. マイコンでLEDの明るさやモーターの回転の速さを調整するのによく使われる方法はどれか。
  2. マイコンのタイマのインプットキャプチャ機能の用途として正しいものはどれか。
  3. 割り込みハンドラの中で避けるべきこととして最も適切なものはどれか。
  4. 上のプログラムを最適化を有効にしてコンパイルすると、タイマ割り込みが起きてもled_on()が呼ばれないことがある。原因と対策の組み合わせとして正しいものはどれか。
  5. 8ビットのマイコンで、タイマ割り込みが32ビットの変数ticksを1ずつ増やし、メイン処理がticksを読んで経過時間を求めている。まれに大きくずれた値が読めてしまう原因として正しいものはどれか。
