組込み・ファームウェア

SPI通信の特徴として正しいものはどれか。

  1. Aクロックを使わない非同期式で、2本の線だけでつなぐ
  2. Bマスタがクロックを出す同期式で、送信と受信を同時に行え、チップセレクトの線で相手を選ぶ
  3. Cアドレスで相手を選ぶので、何台つないでも線は2本で済む
答えと解説を見る

正解：B. マスタがクロックを出す同期式で、送信と受信を同時に行え、チップセレクトの線で相手を選ぶ

SPIは、マスタが出すクロックに合わせて、マスタからスレーブへの線とスレーブからマスタへの線で同時にデータを送り合う同期式の通信です。相手ごとにチップセレクト(CS)の線を用意し、0にした相手とだけ通信します。仕組みが単純でクロックを数十MHzまで上げられるので、フラッシュメモリや表示装置、ADCなどの高速な部品とよく接続されます。

  • A. それはUARTの特徴に近い説明です。
  • B. 正しい。シンプルで高速な通信です。
  • C. それはI2Cの特徴です。

組込み・ファームウェアのほかの問題

  1. SPIで一般に使われる4本の信号の組み合わせとして正しいものはどれか。
  2. SPIの部品をつないでも正しいデータが読めないとき、確かめるべき設定として最も適切なものはどれか。
  3. I2C通信の特徴として正しいものはどれか。
  4. I2Cで、データを1バイト受け取った側が、受け取ったことを知らせる方法として正しいものはどれか。
  5. 同じ型番のI2Cの温度センサを2つ、同じI2Cの線につなぎたいが、どちらも同じアドレスを持っている。対策として正しいものはどれか。
