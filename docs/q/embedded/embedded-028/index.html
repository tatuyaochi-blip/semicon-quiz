組込み・ファームウェア

周辺回路の状態を知る方法のうち、ポーリングと割り込みの違いとして正しいものはどれか。

  1. AポーリングはCPUが状態を繰り返し調べに行き、割り込みは状態が変わったときに周辺回路からCPUに知らせる
  2. Bポーリングと割り込みは同じものである
  3. C割り込みはCPUが状態を繰り返し調べに行く方式である
答えと解説を見る

正解：A. ポーリングはCPUが状態を繰り返し調べに行き、割り込みは状態が変わったときに周辺回路からCPUに知らせる

ポーリングは仕組みが単純で、調べる間隔が決まっているので動きを予測しやすい一方、何も起きていなくてもCPUが調べ続けるので時間と電力をむだにします。割り込みは変化があったときだけCPUが応えるので、待っている間に別の処理をしたり眠ったりできます。ただし割り込みが非常に頻繁だと、かえって処理の手間が大きくなるので、使い分けが大切です。

  • A. 正しい。待つ間にほかの処理ができるのが割り込みの利点です。
  • B. 仕組みが違います。
  • C. それはポーリングの説明です。

組込み・ファームウェアのほかの問題

  1. OSを使わないマイコンのプログラムでよく見られる「スーパーループ」の構成の説明として正しいものはどれか。
  2. 組込み機器でRTOS(リアルタイムOS)を使う主な目的はどれか。
  3. プリエンプティブなRTOSで、優先度の低いタスクの実行中に、優先度の高いタスクが待っていたデータを受け取って実行できる状態になった。一般にどうなるか。
  4. RTOSで起こる優先度逆転の説明として正しいものはどれか。
  5. 優先度逆転を防ぐために使われる「優先度継承」の考え方として正しいものはどれか。

この分野の比較

  • I2C・SPI・UARTの違い：配線・速度・使い分けを比較I2C、SPI、UARTを、配線の数・クロック・速度・接続形態・アドレス・誤り検出・マイコンでの主な用途の観点で表にして比較します。
  • MCUとMPUの違い：マイコンとマイクロプロセッサを比較MCUとMPUを、集積度・クロック・メモリ・OS・リアルタイム性・消費電力・起動時間・コスト・用途の観点で表にして比較します。
  • 割り込みとポーリングの違い：仕組みと使い分けを比較割り込みとポーリングを、仕組み・CPUの使用・応答時間・オーバーヘッド・複雑さ・消費電力・組み込みやOSでの用途の観点で表にして比較します。
