組込み・ファームウェア

UARTの送信側と受信側のボーレートが少しずれていると、文字化けが起こることがある。ずれの許容範囲がおよそ数%程度に限られる理由として正しいものはどれか。

  1. A受信側はスタートビットで合わせた後、自分のクロックで各ビットの真ん中を読むので、ずれが1文字の間に積み重なって最後のビットで半ビットを超えると誤るから
  2. Bボーレートがずれると、送信側の電圧が下がるから
  3. CUARTはずれを自動で直すので、実際には許容範囲はない
答えと解説を見る

正解：A. 受信側はスタートビットで合わせた後、自分のクロックで各ビットの真ん中を読むので、ずれが1文字の間に積み重なって最後のビットで半ビットを超えると誤るから

受信側は、スタートビットの始まりでタイミングを合わせ、その後は自分のボーレートで数えて各ビットの真ん中で値を読みます。速度にずれがあると、読むタイミングのずれがビットごとに積み重なり、約10ビット後のストップビットで半ビット以上ずれると隣のビットを読んでしまいます。そのため両側を合わせた誤差は数%以内に抑える必要があり、クロックの精度の低い内蔵の発振器では注意が必要です。

  • A. 正しい。約10ビットの間に半ビット以上ずれると誤ります。
  • B. 電圧とは関係ありません。
  • C. 普通のUARTは文字の途中でずれを直しません。

組込み・ファームウェアのほかの問題

  1. SPI通信の特徴として正しいものはどれか。
  2. SPIで一般に使われる4本の信号の組み合わせとして正しいものはどれか。
  3. SPIの部品をつないでも正しいデータが読めないとき、確かめるべき設定として最も適切なものはどれか。
  4. I2C通信の特徴として正しいものはどれか。
  5. I2Cで、データを1バイト受け取った側が、受け取ったことを知らせる方法として正しいものはどれか。

この分野の比較

  • I2C・SPI・UARTの違い：配線・速度・使い分けを比較I2C、SPI、UARTを、配線の数・クロック・速度・接続形態・アドレス・誤り検出・マイコンでの主な用途の観点で表にして比較します。
  • MCUとMPUの違い：マイコンとマイクロプロセッサを比較MCUとMPUを、集積度・クロック・メモリ・OS・リアルタイム性・消費電力・起動時間・コスト・用途の観点で表にして比較します。
  • 割り込みとポーリングの違い：仕組みと使い分けを比較割り込みとポーリングを、仕組み・CPUの使用・応答時間・オーバーヘッド・複雑さ・消費電力・組み込みやOSでの用途の観点で表にして比較します。
