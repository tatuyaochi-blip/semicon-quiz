組込み・ファームウェア

ハードリアルタイムとソフトリアルタイムの違いとして正しいものはどれか。

  1. Aハードはハードウェアだけで、ソフトはソフトウェアだけで作る
  2. Bハードは処理が遅く、ソフトは処理が速い
  3. Cハードは期限を1度でも守れないとシステムの失敗になり、ソフトは時々遅れても性能が下がるだけで済む
答えと解説を見る

正解：C. ハードは期限を1度でも守れないとシステムの失敗になり、ソフトは時々遅れても性能が下がるだけで済む

ハードリアルタイムの例は、自動車のエアバッグやエンジン、ブレーキの制御で、期限に遅れると重大な事故につながります。最悪の場合でも期限を守れることを、設計の段階で確かめる必要があります。ソフトリアルタイムの例は動画や音声の再生で、時々遅れても画像が少し乱れる程度で済みます。どちらに当たるかで、必要な検証の厳しさが大きく変わります。

  • A. 作り方の違いではありません。
  • B. 速さではなく、期限を守る厳しさの違いです。
  • C. 正しい。エアバッグやブレーキの制御はハードの例です。

組込み・ファームウェアのほかの問題

  1. ウォッチドッグタイマをリセットする(キックする)処理を、1 msごとのタイマ割り込みハンドラの中で無条件に行うのが良くない理由として正しいものはどれか。
  2. 組込み機器のブートローダの役割として正しいものはどれか。
  3. 無線でファームウェアを書き換える(OTA更新)機器で、フラッシュメモリにファームウェアを置く場所を2つ(A面とB面)用意する理由として正しいものはどれか。
  4. 電池で動く組込み機器で、マイコンのスリープモードを使う主な目的はどれか。
  5. あるセンサ機器は、全体の1%の時間だけ10 mAで動き、残りの99%の時間は10 µAで眠っている。平均の消費電流に最も近いものはどれか。

この分野の比較

  • I2C・SPI・UARTの違い：配線・速度・使い分けを比較I2C、SPI、UARTを、配線の数・クロック・速度・接続形態・アドレス・誤り検出・マイコンでの主な用途の観点で表にして比較します。
  • MCUとMPUの違い：マイコンとマイクロプロセッサを比較MCUとMPUを、集積度・クロック・メモリ・OS・リアルタイム性・消費電力・起動時間・コスト・用途の観点で表にして比較します。
  • 割り込みとポーリングの違い：仕組みと使い分けを比較割り込みとポーリングを、仕組み・CPUの使用・応答時間・オーバーヘッド・複雑さ・消費電力・組み込みやOSでの用途の観点で表にして比較します。
