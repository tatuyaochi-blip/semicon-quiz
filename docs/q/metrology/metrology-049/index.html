計測・分析

光を使う欠陥検査で、異物が小さくなるほど検出が急に難しくなる理由として正しいものはどれか。

  1. A波長より十分小さい粒子の散乱光の強さは、粒径のおよそ6乗に比例して急激に弱くなるため
  2. B小さい粒子は光を反射しないため
  3. C小さい粒子はすべて透明だから
答えと解説を見る

正解：A. 波長より十分小さい粒子の散乱光の強さは、粒径のおよそ6乗に比例して急激に弱くなるため

波長より十分小さな粒子による光の散乱(レイリー散乱)の強さは、粒径のおよそ6乗に比例します。粒径が半分になると散乱光は約1/64になり、表面の粗さやパターンからの背景の雑音に埋もれてしまいます。そのため、短い波長の光や強い光源を使い、雑音を減らす光学系を工夫し、さらに小さい欠陥には電子線の検査を組み合わせます。

  • A. 正しい。散乱光は粒径の約6乗に比例して弱くなります。
  • B. 小さい粒子も光を散乱しますが、その強さが急に弱くなります。
  • C. 粒子が透明になるわけではありません。

  2. 走査電子顕微鏡(SEM)の原理として正しいものはどれか。
  3. エリプソメトリ(分光エリプソメトリ)で主に測定するものはどれか。
  4. SIMS(二次イオン質量分析法)の説明として正しいものはどれか。
  5. 4探針法で主に測定するものはどれか。
