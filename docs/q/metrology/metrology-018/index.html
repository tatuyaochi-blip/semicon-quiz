計測・分析

X線を非常に浅い角度で入射させ、反射率の振動から薄膜の厚さや密度を求める手法はどれか。

  1. ASIMS
  2. BX線反射率法(XRR)
  3. C4探針法
答えと解説を見る

正解：B. X線反射率法(XRR)

XRRでは、X線を浅い角度で入射させたときの反射率を、角度を変えながら測ります。膜の表面と界面で反射したX線が干渉して反射率が振動するため、その周期から膜厚を、全反射が起こる臨界角から膜の密度を、振動の減衰から界面の粗さを求められます。光学定数を仮定せずに測れるため、数nmの極薄膜の評価に向いています。SIMSと4探針法は別の量を測ります。
