計測・分析

製造ラインの計測で、すべてのウエハやすべての点を測るのではなく、一部を選んで測ることが多い主な理由はどれか。

  1. Aすべてを測ると製品が壊れるため
  2. B計測装置は1日に1回しか使えないため
  3. C計測にも時間とコストがかかるため、工程のばらつきを把握できる範囲で抜き取って測る
答えと解説を見る

正解：C. 計測にも時間とコストがかかるため、工程のばらつきを把握できる範囲で抜き取って測る

計測には装置の時間とコストがかかり、すべてのウエハのすべての点を測ると生産の流れが遅くなり、計測装置も大量に必要になります。そこで、工程のばらつきの性質に合わせて、ロットから何枚、ウエハ内の何点を測るかを決めた抜き取り計画にもとづいて計測します。安定した工程では測る量を減らし、重要な工程や異常の兆候があるときは増やします。

  • A. 多くの計測は非破壊で、製品は壊れません。
  • B. 計測装置は連続して使えます。
  • C. 正しい。時間とコストを考えて抜き取って測ります。

計測・分析のほかの問題

  1. 断面の形をくわしく調べるために、ウエハを割ったり削ったりしてから観察する方法の特徴として正しいものはどれか。
  2. 計測器の性能で、「同じものを何度測っても値のばらつきが小さいこと」と「測った値が真の値に近いこと」の呼び方の組み合わせとして正しいものはどれか。
  3. シリコンに加わっている応力(ひずみ)を、局所的に非破壊で評価するのによく使われる分光法はどれか。
  4. パッケージの内部のはんだ接合のボイドや、ワイヤの形などを、パッケージを壊さずに立体的に観察するのに使われる方法はどれか。
  5. パッケージの内部の封止樹脂とチップなどの境界のはく離(デラミネーション)を、非破壊で見つけるのに広く使われる装置はどれか。
