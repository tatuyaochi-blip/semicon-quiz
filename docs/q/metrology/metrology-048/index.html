計測・分析

パッケージや基板の配線に高速のパルスを送り、反射してくる波形から断線やショートの位置を求める方法はどれか。

  1. AXPS
  2. BTDR(時間領域反射法)
  3. CAFM
答えと解説を見る

正解：B. TDR(時間領域反射法)

TDRでは、配線に立ち上がりの速いパルスを入れ、インピーダンスが変わる場所で反射してくる信号の時間と形を測ります。反射が戻るまでの時間から距離が、波形から断線(開放)かショートかがわかるため、パッケージの不良の位置の特定に使われます。

  • A. XPSは表面の元素と化学状態を調べる方法です。
  • B. 正しい。反射波から不良の位置を求めます。
  • C. AFMは表面の凹凸を測る方法です。

計測・分析のほかの問題

  1. 光を使う欠陥検査で、異物が小さくなるほど検出が急に難しくなる理由として正しいものはどれか。
  2. 複数の異なる計測手法(光学式・CD-SEM・AFMなど)のデータを組み合わせて、一つの手法だけより正確に寸法や形状を求める考え方を何と呼ぶか。
  3. 走査電子顕微鏡(SEM)の原理として正しいものはどれか。
  4. エリプソメトリ(分光エリプソメトリ)で主に測定するものはどれか。
  5. SIMS(二次イオン質量分析法)の説明として正しいものはどれか。
