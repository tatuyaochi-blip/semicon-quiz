計測・分析

SEMで絶縁物の試料を観察するときに、帯電(チャージアップ)を防ぐための方法として正しいものはどれか。

  1. A加速電圧を下げる、または試料表面に薄い導電膜をコーティングする
  2. B加速電圧をできるだけ上げる
  3. C試料を水に浸す
答えと解説を見る

正解：A. 加速電圧を下げる、または試料表面に薄い導電膜をコーティングする

絶縁物に電子線を当てると、電荷が逃げずにたまって像がゆがんだり明るさが乱れたりします。加速電圧を下げて入射と放出の電子のつり合いをとる、試料の表面に金や炭素などの薄い導電膜をつける、低真空の条件で観察するなどの方法で、帯電を防ぎます。

この分野を解く 分野ページへ

計測・分析のほかの問題

  1. 深い穴の形状などを、断面を壊さずに3次元的に測る技術として研究・導入が進められているものはどれか。
  2. シリコン中の格子間酸素の濃度の測定に使われる方法はどれか。
  3. ウエハのキャリアのライフタイムを非接触で測定し、金属汚染などを評価する方法はどれか。
  4. 検査で見つかった欠陥をSEMで撮影し、その画像から欠陥の種類を自動で分類する機能はどれか。
  5. 半導体の製造ラインでの「計測」と「検査」の一般的な違いとして正しいものはどれか。
