計測・分析

透過電子顕微鏡(TEM)で試料を観察するために必要な前処理として正しいものはどれか。

  1. A試料を数cmの厚さに積層する
  2. B電子線が透過できるよう、試料を100 nm程度以下まで薄く加工する
  3. C試料を液体に溶かす
答えと解説を見る

正解：B. 電子線が透過できるよう、試料を100 nm程度以下まで薄く加工する

TEMは試料を透過した電子で像をつくるため、試料を非常に薄くする必要があります。半導体デバイスでは、集束イオンビーム(FIB)で観察したい場所を薄片に加工する方法がよく使われます。原子の並びが見えるほどの高い分解能で、断面の構造を観察できます。
