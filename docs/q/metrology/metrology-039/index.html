計測・分析

化合物半導体のウエハやエピ層の品質を非接触で評価するため、レーザー光を当てて出てくる発光のスペクトルや強度の分布を測る方法はどれか。

  1. AAFM
  2. Bフォトルミネッセンス(PL)測定
  3. C四探針法
答えと解説を見る

正解：B. フォトルミネッセンス(PL)測定

フォトルミネッセンスでは、バンドギャップより大きなエネルギーのレーザー光を当ててキャリアをつくり、それが再結合するときに出る光を測ります。発光の波長から組成やバンドギャップ、強度の分布から欠陥や不均一さがわかるため、LEDやレーザー用のエピ層の評価に広く使われます。電極が不要でウエハ全面の分布図を描けます。試料を冷やすと欠陥に由来する発光を詳しく分けて調べられます。

  • A. AFMは表面の凹凸を測る方法です。
  • B. 正しい。光を当てて出る発光を測る方法です。
  • C. 四探針法は抵抗率を測る接触式の方法です。

計測・分析のほかの問題

  1. ウエハの欠陥検査装置で、パターンの像を直接見る明視野方式と比べた、散乱光だけを捉える暗視野方式の特徴として正しいものはどれか。
  2. 細い針で試料の表面をなぞり、針の上下の動きから段差の高さや表面の形を測る装置はどれか。
  3. 装置のセンサのデータなどから、実際に測っていないウエハの膜厚や寸法を統計モデルで予測する手法を何と呼ぶか。
  4. AFMで、非常に細い溝や急な側壁の形を測るときに誤差の原因になりやすいことはどれか。
  5. TEMで、細く絞った電子線を走査しながら、透過した電子のエネルギーの損失を測って元素や化学状態の分布を調べる手法はどれか。
