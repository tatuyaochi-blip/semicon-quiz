計測・分析

ウエハ上の異物やパターン欠陥を検出する欠陥検査装置で使われる代表的な原理はどれか。

  1. A光を当てたときの散乱光の検出や、隣り合うダイの画像の比較
  2. Bウエハの重さの変化
  3. Cウエハを叩いたときの音
答えと解説を見る

正解：A. 光を当てたときの散乱光の検出や、隣り合うダイの画像の比較

異物があると当てた光が散乱するため、散乱光を検出して異物を見つけます。パターン欠陥は、同じパターンをもつ隣のダイの画像と比較して、違いがある場所を欠陥として検出します。検出した欠陥はSEMで詳しく観察して分類(レビュー)します。

計測・分析のほかの問題

  1. 原子間力顕微鏡(AFM)で主に測定するものはどれか。
  2. SEMやTEMと組み合わせて使われるEDX(エネルギー分散型X線分光)で分かることはどれか。
  3. ウエハ表面の微量な金属汚染の分析によく使われる方法はどれか。
  4. MOSキャパシタのC-V(容量-電圧)測定から評価できるものとして正しいものはどれか。
  5. 周期的なパターンに光を当て、反射・回折光のスペクトルをモデルと比較して、線幅や断面形状を求める計測を何と呼ぶか。
