計測・分析

シリコン中の格子間酸素の濃度の測定に使われる方法はどれか。

  1. A4探針法
  2. BEDX
  3. C赤外吸収(FTIR)法
答えと解説を見る

正解：C. 赤外吸収(FTIR)法

シリコン中の格子間酸素は、Si-O-Siの結合の振動により波数約1107 cm⁻¹の赤外光を吸収します。FTIRでその吸収の強さを測ることで、酸素濃度を非破壊で求められます。CZウエハの酸素は、ゲッタリングに役立つ一方で多すぎると析出による欠陥の原因にもなるため、濃度を管理します。置換型の炭素(約605 cm⁻¹)の測定にも使われます。4探針法とEDXでは酸素濃度は測れません。
