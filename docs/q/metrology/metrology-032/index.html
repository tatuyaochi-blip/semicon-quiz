計測・分析

製造ラインで工程の途中に計測や検査を行う主な目的はどれか。

  1. A工程を必ず遅らせるため
  2. B工程の異常を早く見つけて止め、不良品を大量につくり続けるのを防ぐため
  3. C製品の重さを増やすため
答えと解説を見る

正解：B. 工程の異常を早く見つけて止め、不良品を大量につくり続けるのを防ぐため

先端のLSIは1000を超える工程を経て、完成までに数か月かかります。完成してから問題に気づくと、その間に流れた大量のウエハが不良になってしまいます。工程の途中で計測・検査を行い、異常を早く見つけて原因の装置や工程を止め、条件を修正することで損失を小さく抑えます。測定結果を次のウエハの条件の補正に使う制御にも役立ちます。

  • A. 工程を遅らせることが目的ではありません。
  • B. 正しい。異常を早く見つけて損失を抑えるためです。
  • C. 重さを増やすためではありません。

計測・分析のほかの問題

  1. 製造ラインの計測で、すべてのウエハやすべての点を測るのではなく、一部を選んで測ることが多い主な理由はどれか。
  2. 断面の形をくわしく調べるために、ウエハを割ったり削ったりしてから観察する方法の特徴として正しいものはどれか。
  3. 計測器の性能で、「同じものを何度測っても値のばらつきが小さいこと」と「測った値が真の値に近いこと」の呼び方の組み合わせとして正しいものはどれか。
  4. シリコンに加わっている応力(ひずみ)を、局所的に非破壊で評価するのによく使われる分光法はどれか。
  5. パッケージの内部のはんだ接合のボイドや、ワイヤの形などを、パッケージを壊さずに立体的に観察するのに使われる方法はどれか。
