計測・分析

走査電子顕微鏡(SEM)の原理として正しいものはどれか。

  1. A細く絞った電子線を試料表面で走査し、発生する二次電子などを検出して表面の形状を観察する
  2. BX線の回折から結晶構造を調べる
  3. C光の干渉から膜厚を測る
答えと解説を見る

正解：A. 細く絞った電子線を試料表面で走査し、発生する二次電子などを検出して表面の形状を観察する

SEMは、電子線を試料の表面で走査し、そこから出る二次電子や反射電子を検出して像をつくります。光学顕微鏡より高い倍率で表面の形状を観察できます。半導体工場では、パターンの線幅を測るCD-SEM(測長SEM)が工程管理に使われています。

計測・分析のほかの問題

  1. エリプソメトリ(分光エリプソメトリ)で主に測定するものはどれか。
  2. SIMS(二次イオン質量分析法)の説明として正しいものはどれか。
  3. 4探針法で主に測定するものはどれか。
  4. 透過電子顕微鏡(TEM)で試料を観察するために必要な前処理として正しいものはどれか。
  5. ウエハ上の異物やパターン欠陥を検出する欠陥検査装置で使われる代表的な原理はどれか。
