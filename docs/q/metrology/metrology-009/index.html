計測・分析

ウエハ表面の微量な金属汚染の分析によく使われる方法はどれか。

  1. A全反射蛍光X線分析(TXRF)
  2. B4探針法
  3. Cエリプソメトリ
答えと解説を見る

正解：A. 全反射蛍光X線分析(TXRF)

TXRFは、X線をウエハ表面にごく浅い角度で入射させて全反射させ、表面付近の原子から出る蛍光X線を測定する方法です。表面だけを高感度に分析できるため、洗浄工程の評価など、ウエハ表面の微量な金属汚染の管理に使われます。

  3. X線回折(XRD)で主に評価できるものはどれか。
  4. 集束イオンビーム(FIB)装置の主な用途はどれか。
  5. X線を照射して放出される光電子のエネルギーから、表面の元素と化学結合状態を調べる分析法はどれか。
