計測・分析

複数の異なる計測手法(光学式・CD-SEM・AFMなど)のデータを組み合わせて、一つの手法だけより正確に寸法や形状を求める考え方を何と呼ぶか。

  1. Aブラインド計測
  2. Bハイブリッドメトロロジー
  3. Cシングルショット
答えと解説を見る

正解：B. ハイブリッドメトロロジー

先端の微細な構造では、1つの計測手法だけでは測れる量や精度に限界があります。ハイブリッドメトロロジーでは、例えばXRRで精度よく求めた膜厚を光学式の寸法計測(OCD)の解析モデルに固定値として入れ、残りの形状の値を安定して求めるなど、互いの弱点を補ってより正確な結果を得ます。手法ごとの得意な量を見極めて組み合わせることが大切です。

  • A. そのような名前の一般的な計測の考え方ではありません。
  • B. 正しい。複数の手法を組み合わせて精度を高める考え方です。
  • C. そのような名前の一般的な計測の考え方ではありません。

計測・分析のほかの問題

  1. 走査電子顕微鏡(SEM)の原理として正しいものはどれか。
  2. エリプソメトリ(分光エリプソメトリ)で主に測定するものはどれか。
  3. SIMS(二次イオン質量分析法)の説明として正しいものはどれか。
  4. 4探針法で主に測定するものはどれか。
  5. 透過電子顕微鏡(TEM)で試料を観察するために必要な前処理として正しいものはどれか。

この分野の比較

  • SEMとTEMの違い：電子顕微鏡の使い分けを比較SEMとTEMを、原理・見えるもの・分解能・試料の準備・加速電圧・速度・コスト・チップ解析での用途の観点で表にして比較します。
