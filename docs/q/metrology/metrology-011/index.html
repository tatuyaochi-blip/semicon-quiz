計測・分析

周期的なパターンに光を当て、反射・回折光のスペクトルをモデルと比較して、線幅や断面形状を求める計測を何と呼ぶか。

  1. ASIMS
  2. Bスキャッタロメトリ(光学式CD計測、OCD)
  3. CTEM観察
答えと解説を見る

正解：B. スキャッタロメトリ(光学式CD計測、OCD)

スキャッタロメトリは、テスト用の周期パターンからの反射・回折光のスペクトルを測り、形状をモデル化して電磁界の計算で求めたスペクトルと照合することで、線幅、高さ、側壁角などを求めます。非破壊で高速なうえ、断面の形の情報まで得られるため、量産ラインでの寸法管理に広く使われます。ただし、正しいモデルを用意しないと誤った答えになります。SIMSやTEMは破壊的な分析です。

計測・分析のほかの問題

  1. X線回折(XRD)で主に評価できるものはどれか。
  2. 集束イオンビーム(FIB)装置の主な用途はどれか。
  3. X線を照射して放出される光電子のエネルギーから、表面の元素と化学結合状態を調べる分析法はどれか。
  4. LSIの故障箇所を特定するために、動作中の不良箇所から出るわずかな光を検出する解析手法はどれか。
  5. CD-SEMでArFレジストのパターンを測定するとき、電子線の照射によってパターンが縮んでしまう現象を何と呼ぶか。
