計測・分析

成膜前後のウエハの反りの変化から、膜の応力を求めるときに使われる関係式はどれか。

  1. Aブラックの式
  2. Bストーニーの式
  3. Cプレストンの式
答えと解説を見る

正解：B. ストーニーの式

ストーニーの式は、基板の厚さや弾性定数、膜の厚さと、成膜前後のウエハの曲率の変化から、膜の応力を求める式です。ウエハの反りをレーザーなどで測定して応力を評価します。ブラックの式はエレクトロマイグレーション、プレストンの式はCMPの研磨速度に関する式です。

  2. 製造ラインの中で、製品のウエハを工程の途中で計測して工程を監視する計測を何と呼ぶか。

  5. 深い穴の形状などを、断面を壊さずに3次元的に測る技術として研究・導入が進められているものはどれか。
