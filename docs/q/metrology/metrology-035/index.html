計測・分析

計測器の性能で、「同じものを何度測っても値のばらつきが小さいこと」と「測った値が真の値に近いこと」の呼び方の組み合わせとして正しいものはどれか。

  1. A感度と分解能
  2. B速度と容量
  3. C精密さ(精度・繰り返し性)と正確さ(確度)
答えと解説を見る

正解：C. 精密さ(精度・繰り返し性)と正確さ(確度)

繰り返し測ったときのばらつきが小さいことを精密さ(プレシジョン)、測定値が真の値に近いことを正確さ(アキュラシー)と呼びます。的当てにたとえると、矢がまとまっているのが精密さ、中心に近いのが正確さです。ばらつきが小さくても全体がずれていれば正確とはいえません。正確さは、値が分かった基準試料で校正することで確保します。

  • A. 感度と分解能は別の性能です。
  • B. 速度と容量は計測の精度の用語ではありません。
  • C. 正しい。精密さ(ばらつき)と正確さ(真の値への近さ)です。

計測・分析のほかの問題

  1. シリコンに加わっている応力(ひずみ)を、局所的に非破壊で評価するのによく使われる分光法はどれか。
  2. パッケージの内部のはんだ接合のボイドや、ワイヤの形などを、パッケージを壊さずに立体的に観察するのに使われる方法はどれか。
  3. パッケージの内部の封止樹脂とチップなどの境界のはく離(デラミネーション)を、非破壊で見つけるのに広く使われる装置はどれか。
  4. 化合物半導体のウエハやエピ層の品質を非接触で評価するため、レーザー光を当てて出てくる発光のスペクトルや強度の分布を測る方法はどれか。
  5. ウエハの欠陥検査装置で、パターンの像を直接見る明視野方式と比べた、散乱光だけを捉える暗視野方式の特徴として正しいものはどれか。
