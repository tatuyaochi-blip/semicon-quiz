計測・分析

検査で見つかった欠陥をSEMで撮影し、その画像から欠陥の種類を自動で分類する機能はどれか。

  1. AATPG
  2. B自動欠陥分類(ADC)
  3. CAPC
答えと解説を見る

正解：B. 自動欠陥分類(ADC)

欠陥検査装置は多数の欠陥を検出しますが、それぞれの原因を調べるには種類の分類が必要です。自動欠陥分類(ADC:Automatic Defect Classification)は、レビューSEMの画像から、異物、パターン欠陥、スクラッチなどに自動で分類し、原因の特定を早めます。近年は機械学習も活用されています。

計測・分析のほかの問題

  1. 半導体の製造ラインでの「計測」と「検査」の一般的な違いとして正しいものはどれか。
  2. 製造ラインで工程の途中に計測や検査を行う主な目的はどれか。
  3. 製造ラインの計測で、すべてのウエハやすべての点を測るのではなく、一部を選んで測ることが多い主な理由はどれか。
  4. 断面の形をくわしく調べるために、ウエハを割ったり削ったりしてから観察する方法の特徴として正しいものはどれか。
  5. 計測器の性能で、「同じものを何度測っても値のばらつきが小さいこと」と「測った値が真の値に近いこと」の呼び方の組み合わせとして正しいものはどれか。
