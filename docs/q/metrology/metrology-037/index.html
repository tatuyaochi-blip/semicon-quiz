計測・分析

パッケージの内部のはんだ接合のボイドや、ワイヤの形などを、パッケージを壊さずに立体的に観察するのに使われる方法はどれか。

  1. Aエリプソメトリ
  2. BSIMS
  3. CX線CT
答えと解説を見る

正解：C. X線CT

X線CTは、さまざまな方向からX線の透過像を撮影し、計算で内部の3次元の像を再構成する方法です。パッケージを壊さずに、BGAのはんだボールのボイドやブリッジ、ワイヤの変形、内部の割れなどを観察できます。

  • A. エリプソメトリは薄膜の厚さや光学定数を測る方法です。
  • B. SIMSは試料を削りながら元素を分析する破壊的な方法です。
  • C. 正しい。X線の透過像から内部を立体的に再構成します。

計測・分析のほかの問題

  1. パッケージの内部の封止樹脂とチップなどの境界のはく離(デラミネーション)を、非破壊で見つけるのに広く使われる装置はどれか。
  2. 化合物半導体のウエハやエピ層の品質を非接触で評価するため、レーザー光を当てて出てくる発光のスペクトルや強度の分布を測る方法はどれか。
  3. ウエハの欠陥検査装置で、パターンの像を直接見る明視野方式と比べた、散乱光だけを捉える暗視野方式の特徴として正しいものはどれか。
  4. 細い針で試料の表面をなぞり、針の上下の動きから段差の高さや表面の形を測る装置はどれか。
  5. 装置のセンサのデータなどから、実際に測っていないウエハの膜厚や寸法を統計モデルで予測する手法を何と呼ぶか。
