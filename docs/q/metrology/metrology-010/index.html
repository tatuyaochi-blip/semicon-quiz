計測・分析

MOSキャパシタのC-V(容量-電圧)測定から評価できるものとして正しいものはどれか。

  1. Aパターンの線幅
  2. B酸化膜厚、界面準位、基板の不純物濃度など
  3. Cウエハ表面の異物の数
答えと解説を見る

正解：B. 酸化膜厚、界面準位、基板の不純物濃度など

MOSキャパシタに加える電圧を変えながら容量を測ると、蓄積・空乏・反転の状態に応じて容量が変化します。蓄積側の最大容量Coxから酸化膜厚がtox=εox·A/Coxで求まり、曲線の位置からフラットバンド電圧や膜中の電荷、曲線のなまりから界面準位密度、空乏側の傾きから基板の不純物濃度が分かります。線幅や異物の数は分かりません。

計測・分析のほかの問題

  1. 周期的なパターンに光を当て、反射・回折光のスペクトルをモデルと比較して、線幅や断面形状を求める計測を何と呼ぶか。
  2. X線回折(XRD)で主に評価できるものはどれか。
  3. 集束イオンビーム(FIB)装置の主な用途はどれか。
  4. X線を照射して放出される光電子のエネルギーから、表面の元素と化学結合状態を調べる分析法はどれか。
  5. LSIの故障箇所を特定するために、動作中の不良箇所から出るわずかな光を検出する解析手法はどれか。
