計測・分析

装置のセンサのデータなどから、実際に測っていないウエハの膜厚や寸法を統計モデルで予測する手法を何と呼ぶか。

  1. A破壊検査
  2. B外観検査
  3. C仮想計測(バーチャルメトロロジー)
答えと解説を見る

正解：C. 仮想計測(バーチャルメトロロジー)

仮想計測は、処理中の装置の温度・圧力・電力などのセンサデータと、過去の計測結果との関係を機械学習などでモデル化し、計測していないウエハの結果を予測する手法です。全数を計測しなくても工程の状態を推定でき、異常の早期検出や、ウエハごとに条件を補正する制御に役立ちます。ただし、装置の状態が変わるとモデルがずれるため、実際の計測で定期的に確かめます。

  • A. 破壊検査は試料を壊して調べる方法です。
  • B. 外観検査は見た目の異常を調べる検査です。
  • C. 正しい。センサデータから計測値を予測する手法です。

計測・分析のほかの問題

  1. AFMで、非常に細い溝や急な側壁の形を測るときに誤差の原因になりやすいことはどれか。
  2. TEMで、細く絞った電子線を走査しながら、透過した電子のエネルギーの損失を測って元素や化学状態の分布を調べる手法はどれか。
  3. 針状に加工した試料の先端から原子を1個ずつ電界で蒸発させ、その位置と種類を検出して、ドーパントなどの3次元の原子の分布を調べる分析法はどれか。
  4. 電極をつくらずに、ウエハの表面にコロナ放電で電荷を載せ、表面電位の変化を測って酸化膜や界面の電気的な特性を評価する方法はどれか。
  5. 動作させたチップの微小な発熱を、加える電力を周期的に変えて同期した熱画像を積算することで高感度に検出し、故障箇所を特定する手法はどれか。
