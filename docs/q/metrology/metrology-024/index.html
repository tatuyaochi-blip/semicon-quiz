計測・分析

製造ラインの中で、製品のウエハを工程の途中で計測して工程を監視する計測を何と呼ぶか。

  1. Aインライン計測
  2. Bオフライン計測
  3. C破壊解析
答えと解説を見る

正解：A. インライン計測

インライン計測は、製造ラインに組み込まれた計測装置で、製品のウエハの膜厚、寸法、重ね合わせ、欠陥などを工程の途中で測るものです。異常を早く見つけて不良品が後工程に流れるのを防ぎ、結果を装置の条件の補正に使うこともあります。製品を壊さない非破壊の方法が使われます。ラインの外に持ち出して詳しく調べるオフライン計測や、試料を壊す破壊解析とは区別されます。

計測・分析のほかの問題

  1. 電子線を当てたときの帯電の違いによる明るさの差を利用して、コンタクトの導通不良などを検出する検査はどれか。
  2. SEMで絶縁物の試料を観察するときに、帯電(チャージアップ)を防ぐための方法として正しいものはどれか。
  3. 深い穴の形状などを、断面を壊さずに3次元的に測る技術として研究・導入が進められているものはどれか。
  4. シリコン中の格子間酸素の濃度の測定に使われる方法はどれか。
  5. ウエハのキャリアのライフタイムを非接触で測定し、金属汚染などを評価する方法はどれか。
