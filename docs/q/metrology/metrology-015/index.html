計測・分析

LSIの故障箇所を特定するために、動作中の不良箇所から出るわずかな光を検出する解析手法はどれか。

  1. AXRD
  2. BTXRF
  3. Cエミッション顕微鏡(発光解析)
答えと解説を見る

正解：C. エミッション顕微鏡(発光解析)

リーク電流が流れている箇所や、ホットキャリアが生じているトランジスタからは、ごく弱い近赤外の光が出ます。エミッション顕微鏡は、この光を高感度のカメラで検出して、動作中のチップ上の故障箇所を特定する手法です。多層配線に表側がふさがれている場合は、シリコンが赤外光を通すことを利用して、薄くした裏面から観察します。XRDは結晶、TXRFは表面の汚染を調べます。

計測・分析のほかの問題

  1. CD-SEMでArFレジストのパターンを測定するとき、電子線の照射によってパターンが縮んでしまう現象を何と呼ぶか。
  2. 重ね合わせ(オーバーレイ)のずれを計測するために、ウエハ上に設けるものはどれか。
  3. X線を非常に浅い角度で入射させ、反射率の振動から薄膜の厚さや密度を求める手法はどれか。
  4. ウエハの反り(ボウ・ワープ)や平坦度の測定に使われる方法として正しいものはどれか。
  5. 計測器の繰り返し性や再現性が、管理したい工程のばらつきに対して十分小さいかを評価する手法はどれか。
