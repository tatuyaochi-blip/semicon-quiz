計測・分析

X線を照射して放出される光電子のエネルギーから、表面の元素と化学結合状態を調べる分析法はどれか。

  1. A原子間力顕微鏡(AFM)
  2. BXPS(X線光電子分光法)
  3. C4探針法
答えと解説を見る

正解：B. XPS(X線光電子分光法)

XPSは、X線を当てて表面から飛び出す光電子の運動エネルギーを測り、そこから求めた結合エネルギーで元素の種類と化学結合の状態を調べる方法です。同じSiでも、単体では約99 eV、SiO2では約103 eVと値がずれるため、酸化の程度が分かります。光電子は数nmの深さからしか出られないため、薄膜や界面、表面処理の評価に向きます。AFMは形状、4探針法は抵抗を測ります。

  2. CD-SEMでArFレジストのパターンを測定するとき、電子線の照射によってパターンが縮んでしまう現象を何と呼ぶか。
  3. 重ね合わせ(オーバーレイ)のずれを計測するために、ウエハ上に設けるものはどれか。
  4. X線を非常に浅い角度で入射させ、反射率の振動から薄膜の厚さや密度を求める手法はどれか。
  5. ウエハの反り(ボウ・ワープ)や平坦度の測定に使われる方法として正しいものはどれか。
