計測・分析

ウエハのキャリアのライフタイムを非接触で測定し、金属汚染などを評価する方法はどれか。

  1. Aマイクロ波光導電減衰法(μ-PCD)
  2. BSIMS
  3. CXRD
答えと解説を見る

正解：A. マイクロ波光導電減衰法(μ-PCD)

μ-PCDでは、ウエハに光パルスを当ててキャリアを発生させ、それが再結合して減っていく様子を、マイクロ波の反射の変化から測定します。金属汚染があるとライフタイムが短くなるため、熱処理炉などの汚染の監視に使われます。

  2. 半導体の製造ラインでの「計測」と「検査」の一般的な違いとして正しいものはどれか。
  3. 製造ラインで工程の途中に計測や検査を行う主な目的はどれか。
  4. 製造ラインの計測で、すべてのウエハやすべての点を測るのではなく、一部を選んで測ることが多い主な理由はどれか。
  5. 断面の形をくわしく調べるために、ウエハを割ったり削ったりしてから観察する方法の特徴として正しいものはどれか。
