計測・分析

X線回折(XRD)で主に評価できるものはどれか。

  1. A表面の有機物汚れ
  2. Bシート抵抗
  3. C結晶構造や格子定数、膜のひずみ
答えと解説を見る

正解：C. 結晶構造や格子定数、膜のひずみ

XRDは、X線が結晶の原子面で回折されるブラッグの条件2d·sinθ=nλから、結晶構造や格子面の間隔を調べる方法です。高分解能のXRDでは、SiGeなどのエピタキシャル膜の回折ピークの位置から組成やひずみ、ピークの幅から結晶の完全性を評価できます。多結晶膜では結晶の向きのそろい方も分かります。有機物汚れやシート抵抗は測れません。

計測・分析のほかの問題

  1. 集束イオンビーム(FIB)装置の主な用途はどれか。
  2. X線を照射して放出される光電子のエネルギーから、表面の元素と化学結合状態を調べる分析法はどれか。
  3. LSIの故障箇所を特定するために、動作中の不良箇所から出るわずかな光を検出する解析手法はどれか。
  4. CD-SEMでArFレジストのパターンを測定するとき、電子線の照射によってパターンが縮んでしまう現象を何と呼ぶか。
  5. 重ね合わせ(オーバーレイ)のずれを計測するために、ウエハ上に設けるものはどれか。
