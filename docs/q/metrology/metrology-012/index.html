計測・分析

X線回折(XRD)で主に評価できるものはどれか。

  1. A表面の有機物汚れ
  2. Bシート抵抗
  3. C結晶構造や格子定数、膜のひずみ
答えと解説を見る

正解：C. 結晶構造や格子定数、膜のひずみ

XRDは、X線が結晶の原子面で回折される角度から、結晶構造や格子定数を調べる方法です。エピタキシャル膜の組成やひずみ、結晶性の評価などに使われます。
