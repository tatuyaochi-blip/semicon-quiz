計測・分析

4探針法で主に測定するものはどれか。

  1. Aシート抵抗
  2. B膜の応力
  3. C表面の粗さ
答えと解説を見る

正解：A. シート抵抗

4探針法は、一直線に並べた4本の針を試料に当て、外側の2本に電流を流し、内側の2本で電圧を測る方法です。電流を流す針と電圧を測る針を分けることで、接触抵抗の影響を受けずにシート抵抗を測定できます。拡散層や金属膜の評価に使われます。
