計測・分析

電子線を当てたときの帯電の違いによる明るさの差を利用して、コンタクトの導通不良などを検出する検査はどれか。

  1. AX線回折(XRD)
  2. B電位コントラスト(ボルテージコントラスト)検査
  3. CX線反射率法(XRR)
答えと解説を見る

正解：B. 電位コントラスト(ボルテージコントラスト)検査

電子線を当てると、基板などに電気的につながっているコンタクトは電荷が逃げて帯電せず、断線して浮いているものは帯電します。帯電の違いで出てくる二次電子の量が変わるため、明るさの差となって現れます。この電位コントラストを使うと、表面からは見えないコンタクトの開口不良や配線の断線を検出でき、電子線検査装置で量産ラインでも使われています。
