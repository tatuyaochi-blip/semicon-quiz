計測・分析

光学顕微鏡で、数十nmの微細なパターンを直接観察できない主な理由はどれか。

  1. A光の回折による分解能の限界(おおよそ光の波長程度)があるため
  2. B光学顕微鏡は色がつかないため
  3. C光学顕微鏡は暗すぎるため
答えと解説を見る

正解：A. 光の回折による分解能の限界(おおよそ光の波長程度)があるため

光学顕微鏡の分解能は、光の回折によって、使う光の波長の半分程度が限界です。可視光の波長は400〜700 nm程度なので、数十nmのパターンは見分けられません。そのため、より波長の短い電子線を使うSEMやTEMが使われます。
