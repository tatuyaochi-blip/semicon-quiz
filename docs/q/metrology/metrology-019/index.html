計測・分析

ウエハの反り(ボウ・ワープ)や平坦度の測定に使われる方法として正しいものはどれか。

  1. A光の干渉計や静電容量センサによる非接触の形状測定
  2. BSIMSによる質量分析
  3. CEDXによる元素分析
答えと解説を見る

正解：A. 光の干渉計や静電容量センサによる非接触の形状測定

ウエハの形状は、光の干渉を利用した測定器や、ウエハの両面の距離を静電容量で測るセンサなどで、ウエハに触れずに測定します。反り(ボウ・ワープ)は搬送や吸着に、局所的な平坦度は露光の焦点深度の中に収まるかに影響するため、ウエハの受け入れ検査や成膜後の評価で管理されます。SIMSは質量分析、EDXは元素分析の方法です。
