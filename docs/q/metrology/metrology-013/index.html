計測・分析

集束イオンビーム(FIB)装置の主な用途はどれか。

  1. A微小な領域の加工、断面試料の作製、回路の修正
  2. Bウエハ全面の膜厚測定
  3. Cウエハの洗浄
答えと解説を見る

正解：A. 微小な領域の加工、断面試料の作製、回路の修正

FIBは、ガリウムなどのイオンを細く絞って試料に当て、狙った位置をナノメートル単位で削ったり、原料ガスと組み合わせて白金やタングステンの膜を堆積させたりできる装置です。TEM用の薄片の作製、不良箇所の断面観察、試作チップの配線を切ってつなぎ直す回路修正などに使われます。SEMと一体になった装置なら、削りながら観察できます。全面の膜厚測定や洗浄はしません。

計測・分析のほかの問題

  1. X線を照射して放出される光電子のエネルギーから、表面の元素と化学結合状態を調べる分析法はどれか。
  2. LSIの故障箇所を特定するために、動作中の不良箇所から出るわずかな光を検出する解析手法はどれか。
  3. CD-SEMでArFレジストのパターンを測定するとき、電子線の照射によってパターンが縮んでしまう現象を何と呼ぶか。
  4. 重ね合わせ(オーバーレイ)のずれを計測するために、ウエハ上に設けるものはどれか。
  5. X線を非常に浅い角度で入射させ、反射率の振動から薄膜の厚さや密度を求める手法はどれか。
