計測・分析

深い穴の形状などを、断面を壊さずに3次元的に測る技術として研究・導入が進められているものはどれか。

  1. A光学顕微鏡による目視
  2. BX線の散乱を使った寸法計測(CD-SAXS)など
  3. Cウエハの重さの測定
答えと解説を見る

正解：B. X線の散乱を使った寸法計測(CD-SAXS)など

3D NANDのメモリホールのような深く細い構造は、光学的な計測やSEMでは内部の形状がわかりにくく、断面観察は破壊を伴います。X線は物質を透過しやすいため、X線の散乱パターンから周期構造の形状を求めるCD-SAXSなどの方法が研究・導入されています。

計測・分析のほかの問題

  1. シリコン中の格子間酸素の濃度の測定に使われる方法はどれか。
  2. ウエハのキャリアのライフタイムを非接触で測定し、金属汚染などを評価する方法はどれか。
  3. 検査で見つかった欠陥をSEMで撮影し、その画像から欠陥の種類を自動で分類する機能はどれか。
  4. 半導体の製造ラインでの「計測」と「検査」の一般的な違いとして正しいものはどれか。
  5. 製造ラインで工程の途中に計測や検査を行う主な目的はどれか。
