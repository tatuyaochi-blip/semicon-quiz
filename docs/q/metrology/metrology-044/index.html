計測・分析

TEMで、細く絞った電子線を走査しながら、透過した電子のエネルギーの損失を測って元素や化学状態の分布を調べる手法はどれか。

  1. A4探針法
  2. Bホール測定
  3. CSTEM-EELS(電子エネルギー損失分光)
答えと解説を見る

正解：C. STEM-EELS(電子エネルギー損失分光)

STEM(走査型透過電子顕微鏡)では、細い電子線を試料上で走査します。透過した電子がどれだけエネルギーを失ったかを測るEELSを組み合わせると、原子レベルに近い空間分解能で元素の種類や化学結合の状態の分布を調べられます。軽い元素の検出に強く、極薄のゲート絶縁膜や界面の評価などに使われます。ホール測定はキャリアの種類や移動度を調べる方法です。

  • A. 4探針法は抵抗率を測る方法です。
  • B. ホール測定はキャリアの種類や濃度、移動度を調べる方法です。
  • C. 正しい。透過電子のエネルギー損失で元素や状態を調べます。

計測・分析のほかの問題

  1. 針状に加工した試料の先端から原子を1個ずつ電界で蒸発させ、その位置と種類を検出して、ドーパントなどの3次元の原子の分布を調べる分析法はどれか。
  2. 電極をつくらずに、ウエハの表面にコロナ放電で電荷を載せ、表面電位の変化を測って酸化膜や界面の電気的な特性を評価する方法はどれか。
  3. 動作させたチップの微小な発熱を、加える電力を周期的に変えて同期した熱画像を積算することで高感度に検出し、故障箇所を特定する手法はどれか。
  4. パッケージや基板の配線に高速のパルスを送り、反射してくる波形から断線やショートの位置を求める方法はどれか。
  5. 光を使う欠陥検査で、異物が小さくなるほど検出が急に難しくなる理由として正しいものはどれか。
