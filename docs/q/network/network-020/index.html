ネットワークの基礎

動的ルーティングの説明として正しいものはどれか。

  1. A管理者が各ルータに経路を手で設定し、障害が起きても設定を変えるまで同じ経路を使い続ける
  2. Bルータどうしがルーティングプロトコルで経路の情報を交換し、障害で経路が使えなくなると自動的に別の経路に切り替える
  3. Cパケットごとに経路をランダムに選び、複数の経路に負荷を均等に分散する
答えと解説を見る

正解：B. ルータどうしがルーティングプロトコルで経路の情報を交換し、障害で経路が使えなくなると自動的に別の経路に切り替える

静的ルーティングは、管理者が経路を手で設定する方法です。設定が単純で動きを予測しやすく、小さなネットワークや、出口が1つしかない拠点のデフォルトルートに向きますが、障害が起きても自動では切り替わりません。動的ルーティングでは、ルータがOSPFやBGPなどのルーティングプロトコルで情報を交換して経路表を自動で作り、リンクが切れると別の経路を計算し直します。インターネットでは、組織のネットワーク(自律システム)の間の経路をBGPで交換しています。実際のネットワークでは、両方を組み合わせて使うのが一般的です。

  • A. これは静的ルーティングの説明です。
  • B. 正しい。障害に合わせて経路表を自動で作り直します。
  • C. 動的ルーティングでも、経路はプロトコルで計算した経路表に従って決まり、ランダムではありません。

ネットワークの基礎のほかの問題

  1. UDPの特徴として正しいものはどれか。
  2. TCPでコネクションを確立する3ウェイハンドシェイクで、やり取りされるパケットの順序として正しいものはどれか。
  3. RTT(往復の時間)が100 msのWebサーバに、HTTPS(TCPの上のTLS 1.3)で新しく接続し、最初のリクエストを送って応答を受け取り始めるまでにかかる時間に最も近いものはどれか。DNSの名前解決は済んでおり、サーバの処理時間とデータの転送時間は無視する。
  4. プロトコルと、そのサーバが標準で使うポート番号の組み合わせとして正しいものはどれか。
  5. TCPのフロー制御で、受信側がウィンドウサイズ(受信ウィンドウ)を送信側に通知する目的として正しいものはどれか。
