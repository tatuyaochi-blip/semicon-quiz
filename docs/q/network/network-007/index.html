ネットワークの基礎

IPv6アドレス 2001:0db8:0000:0000:0000:0000:0000:0001 を、省略の規則に従って正しく短く書いたものはどれか。

  1. A2001:db8:1
  2. B2001:db8::1
  3. C2001:db8::0::1
答えと解説を見る

正解：B. 2001:db8::1

IPv6アドレスは128ビットで、16ビットずつ8つのグループに分け、各グループを4桁の16進数で書きます(IPv4は32ビットです)。省略の規則は2つで、各グループの先頭の0は省ける(0db8→db8、0001→1)ことと、0だけのグループが続く部分を1か所だけ「::」に置き換えられることです。この例では、3番目から7番目までの0のグループ5つをまとめて 2001:db8::1 になります。「::」を2か所に使うと、それぞれが何グループ分の0かが決まらなくなるため使えません。「2001:db8:1」は3グループしかなく、0のグループを省いたことを示す「::」がないので、別のアドレスとして読めてしまい、正しくありません。

  • A. 0のグループを省くときは「::」で示す必要があり、これでは3グループのアドレスになって不正です。
  • B. 正しい。先頭の0を省き、連続する0のグループを1か所の「::」にまとめます。
  • C. 「::」は1か所にしか使えません。

ネットワークの基礎のほかの問題

  1. IPアドレスが 192.168.1.10、サブネットマスクが 255.255.255.0 の端末が属するネットワークのネットワークアドレスはどれか。
  2. 192.168.5.0/26 のネットワークで、ホスト(端末やルータのインターフェース)に割り当てられるIPアドレスはいくつか。
  3. IPアドレス 192.168.10.77/27 の端末が属するサブネットのブロードキャストアドレスはどれか。
  4. 1つのサブネットに500台のホストを収容したい。これを満たすサブネットのうち、最も小さいもの(プレフィックス長が最も長いもの)はどれか。
  5. CIDR表記の /20 をサブネットマスクで表したものはどれか。
