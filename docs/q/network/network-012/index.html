ネットワークの基礎

CIDR表記の /20 をサブネットマスクで表したものはどれか。

  1. A255.255.240.0
  2. B255.255.255.240
  3. C255.255.248.0
答えと解説を見る

正解：A. 255.255.240.0

/20 は上位20ビットが1のマスクです。最初の16ビットで 255.255 となり、残りの4ビットは第3オクテットの上位4ビットに入ります。2進数の 11110000 は 128 + 64 + 32 + 16 = 240 なので、サブネットマスクは 255.255.240.0 です。ホスト部は12ビットで、2^12 − 2 = 4094 台を収容できます。255.255.255.240 は上位28ビットが1の /28、255.255.248.0 は上位21ビットが1の /21 です。

  • A. 正しい。上位20ビットが1で、第3オクテットは 11110000 = 240 です。
  • B. これは /28 のサブネットマスクです。
  • C. 第3オクテットが 11111000 = 248 なので、/21 のサブネットマスクです。

ネットワークの基礎のほかの問題

  1. 次のIPv4アドレスのうち、プライベートアドレスの範囲に含まれるものはどれか。
  2. 家庭のブロードバンドルータは、NAT(ネットワークアドレス変換)の一種であるNAPT(IPマスカレード)を行っている。NAPTによって可能になることとして正しいものはどれか。
  3. NAPTを行うルータ(外側のグローバルアドレスは 198.51.100.7)の内側にある端末A(192.168.1.10)が、送信元ポート50000でWebサーバ 203.0.113.5 の443番ポートへ接続した。ルータは送信元を 198.51.100.7 のポート61000に変換した。Webサーバが返す応答パケットの宛先はどれか。
  4. ARPの役割として正しいものはどれか。
  5. 端末(192.168.1.10/24、デフォルトゲートウェイ 192.168.1.1)が、別のネットワークにあるサーバ 203.0.113.80 にパケットを送る。ARPのキャッシュが空のとき、端末がARPでMACアドレスを調べる相手はどれか。

この分野の比較

  • TCPとUDPの違い：接続・信頼性・順序・輻輳制御・ヘッダ・遅延・用途を比較TCPとUDPを、接続の確立・届いたかの確認と再送・順序・データの区切り・フロー制御と輻輳制御・ヘッダの大きさ・遅延・宛先の種類・主な用途の観点で表にして比較します。
  • IPv4とIPv6の違い：アドレス長・ヘッダ・フラグメンテーション・アドレスの設定・NATを比較IPv4とIPv6を、アドレスの長さと数・表記・ヘッダ・フラグメンテーション・アドレスの自動設定・MACアドレスの解決・NAT・宛先の種類・IPsecの観点で表にして比較します。
  • ハブ・スイッチ・ルータの違い：動作する層・使うアドレス・転送のしかた・ドメインの分け方を比較ハブ(リピータハブ)・スイッチ(L2スイッチ)・ルータを、動作する層・使うアドレス・扱うデータの単位・転送のしかた・コリジョンドメイン・ブロードキャストドメイン・異なるネットワークの接続・置く場所の観点で表にして比較し…
