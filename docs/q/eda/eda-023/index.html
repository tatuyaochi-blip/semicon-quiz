LSI設計フロー・EDA

アナログ回路のレイアウトで、ペアにするトランジスタを、互いの重心が一致するように分割して配置する手法はどれか。

  1. Aコモンセントロイド配置
  2. Bスタンダードセル配置
  3. Cクロックツリー合成
答えと解説を見る

正解：A. コモンセントロイド配置

差動対やカレントミラーのように、特性がそろっていることが重要なトランジスタの組では、ウエハ上の膜厚や不純物濃度、温度の傾きの影響を受けないように、トランジスタを分割して交互に、重心が一致するように配置します(例えばABBA)。傾きの影響が両方に同じだけ加わって打ち消されます。これをコモンセントロイド配置といいます。スタンダードセル配置やCTSはデジタル回路の手法です。

LSI設計フロー・EDAのほかの問題

  1. レイアウトの空いた場所に、回路として機能しないダミーパターンを配置する主な目的はどれか。
  2. ダブルパターニングを前提としたレイアウトで、設計ツールが行うパターンの割り振りとして正しいものはどれか。
  3. ネットリストの説明として正しいものはどれか。
  4. 論理合成や静的タイミング解析で、クロック周期や入出力の遅延などのタイミングの条件を記述したものを何と呼ぶか。
  5. マスク製作のために製造側に渡すレイアウトデータの代表的な形式はどれか。
