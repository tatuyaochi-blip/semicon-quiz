LSI設計フロー・EDA

マスク製作のために製造側に渡すレイアウトデータの代表的な形式はどれか。

  1. AVerilog
  2. BSPICEネットリスト
  3. CGDSIIやOASIS
答えと解説を見る

正解：C. GDSIIやOASIS

GDSIIやOASISは、レイアウトの図形(多角形)を層ごとに記述するデータ形式で、テープアウトで製造側に引き渡され、マスクの製作に使われます。Verilogは回路の記述言語、SPICEネットリストは回路シミュレーション用のデータです。

この分野を解く 分野ページへ

LSI設計フロー・EDAのほかの問題

  1. 配置配線の最初に、大きな回路ブロックや入出力端子、電源配線などのおおまかな配置を決める工程はどれか。
  2. RTLの検証で、検証がどれだけ十分に行われたかを評価するために使われる指標はどれか。
  3. 一般的なデジタルLSIの設計フローの順序として正しいものはどれか。
  4. 論理合成の説明として正しいものはどれか。
  5. 静的タイミング解析(STA)の説明として正しいものはどれか。
