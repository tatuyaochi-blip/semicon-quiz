LSI設計フロー・EDA

製造上のばらつきや欠陥の影響を受けにくいように、レイアウトなどを工夫する設計の考え方はどれか。

  1. ADFT(テスト容易化設計)
  2. BCTS(クロックツリー合成)
  3. CDFM(製造容易化設計)
答えと解説を見る

正解：C. DFM(製造容易化設計)

DFM(Design for Manufacturability)は、リソグラフィやCMPで問題になりやすいパターンを避ける、ビアを二重にする、配線の間隔を可能な範囲で広げるなど、製造しやすく歩留まりの高いレイアウトにするための設計手法です。

LSI設計フロー・EDAのほかの問題

  1. アナログ回路のレイアウトで、ペアにするトランジスタを、互いの重心が一致するように分割して配置する手法はどれか。
  2. レイアウトの空いた場所に、回路として機能しないダミーパターンを配置する主な目的はどれか。
  3. ダブルパターニングを前提としたレイアウトで、設計ツールが行うパターンの割り振りとして正しいものはどれか。
  4. ネットリストの説明として正しいものはどれか。
  5. 論理合成や静的タイミング解析で、クロック周期や入出力の遅延などのタイミングの条件を記述したものを何と呼ぶか。
