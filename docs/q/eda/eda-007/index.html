LSI設計フロー・EDA

スタンダードセル方式の設計の説明として正しいものはどれか。

  1. Aすべてのトランジスタを人手で1個ずつ配置して設計する
  2. Bあらかじめ設計・検証されたゲートなどのセルを並べて配線し、回路をつくる
  3. C製造後に回路を書き換えて使う
答えと解説を見る

正解：B. あらかじめ設計・検証されたゲートなどのセルを並べて配線し、回路をつくる

スタンダードセル方式では、NANDやフリップフロップなどの基本回路を、高さをそろえたセルとしてあらかじめ設計・検証しておき、論理合成と配置配線のツールでそれらを並べて接続します。大規模なデジタルLSIの多くがこの方式で設計されています。

LSI設計フロー・EDAのほかの問題

  1. FPGAの特徴として正しいものはどれか。
  2. 配置配線工程でのクロックツリー合成(CTS)の主な目的はどれか。
  3. LSI設計で使われる「IP(IPコア)」の意味として正しいものはどれか。
  4. 静的タイミング解析で、信号がクロックのエッジ直後に早く変化しすぎて、フリップフロップが前のデータを正しく保持できなくなるタイミング違反はどれか。
  5. ファウンドリが設計者に提供する、デザインルール、デバイスモデル、セルライブラリなどの設計用データ一式を何と呼ぶか。
