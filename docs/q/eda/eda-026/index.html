LSI設計フロー・EDA

ネットリストの説明として正しいものはどれか。

  1. A回路を構成する素子(セル)とそれらの接続関係を記述したデータ
  2. Bマスクのパターンの図形データ
  3. Cテストの合否を記録したデータ
答えと解説を見る

正解：A. 回路を構成する素子(セル)とそれらの接続関係を記述したデータ

ネットリストは、回路にどの素子(トランジスタやセル)があり、それらの端子がどの配線(ネット)でつながっているかを記述したデータです。図形の情報はもたず、接続関係だけを表します。論理合成の出力や配置配線の入力として使われ、LVSではレイアウトから取り出したネットリストと回路図のネットリストを比べます。マスクの図形はGDSIIなどのレイアウトデータに含まれます。

LSI設計フロー・EDAのほかの問題

  1. 論理合成や静的タイミング解析で、クロック周期や入出力の遅延などのタイミングの条件を記述したものを何と呼ぶか。
  2. マスク製作のために製造側に渡すレイアウトデータの代表的な形式はどれか。
  3. 配置配線の最初に、大きな回路ブロックや入出力端子、電源配線などのおおまかな配置を決める工程はどれか。
  4. RTLの検証で、検証がどれだけ十分に行われたかを評価するために使われる指標はどれか。
  5. 「EDA」が表すものとして正しいものはどれか。
