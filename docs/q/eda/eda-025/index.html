LSI設計フロー・EDA

ダブルパターニングを前提としたレイアウトで、設計ツールが行うパターンの割り振りとして正しいものはどれか。

  1. Aすべてのパターンを1枚のマスクにまとめる
  2. Bパターンをランダムに削除する
  3. Cパターンを2枚のマスクに振り分け(色分けし)、同じマスク内でパターンが近づきすぎないようにする
答えと解説を見る

正解：C. パターンを2枚のマスクに振り分け(色分けし)、同じマスク内でパターンが近づきすぎないようにする

ダブルパターニングでは、1回の露光では解像できない間隔のパターンを、2枚のマスクに分けて露光します。設計ツールは、近すぎるパターンどうしが別のマスクになるように色分け(カラリング)を行い、色分けできない配置があればエラーとして修正を求めます。

LSI設計フロー・EDAのほかの問題

  1. ネットリストの説明として正しいものはどれか。
  2. 論理合成や静的タイミング解析で、クロック周期や入出力の遅延などのタイミングの条件を記述したものを何と呼ぶか。
  3. マスク製作のために製造側に渡すレイアウトデータの代表的な形式はどれか。
  4. 配置配線の最初に、大きな回路ブロックや入出力端子、電源配線などのおおまかな配置を決める工程はどれか。
  5. RTLの検証で、検証がどれだけ十分に行われたかを評価するために使われる指標はどれか。
