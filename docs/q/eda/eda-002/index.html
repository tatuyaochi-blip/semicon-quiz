LSI設計フロー・EDA

論理合成の説明として正しいものはどれか。

  1. Aチップ上にセルを配置し、配線を引く工程
  2. BRTLの記述を、セルライブラリのゲートで構成したネットリストに変換する工程
  3. Cウエハ上に回路パターンを転写する工程
答えと解説を見る

正解：B. RTLの記述を、セルライブラリのゲートで構成したネットリストに変換する工程

論理合成は、RTLで書かれた回路の動作記述を、セルライブラリにある論理ゲートやフリップフロップの接続情報(ネットリスト)に変換する工程です。面積・速度・消費電力の制約を与えると、ツールがそれを満たすように回路を最適化します。

LSI設計フロー・EDAのほかの問題

  1. 静的タイミング解析(STA)の説明として正しいものはどれか。
  2. RTL設計で主に使われるハードウェア記述言語はどれか。
  3. レイアウト検証におけるDRC(デザインルールチェック)の説明として正しいものはどれか。
  4. 論理合成の前後で回路の論理が変わっていないことを、シミュレーションを使わずに数学的に確認する手法はどれか。
  5. スタンダードセル方式の設計の説明として正しいものはどれか。
