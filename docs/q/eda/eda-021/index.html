LSI設計フロー・EDA

テープアウト前の最終確認(サインオフ)で、タイミングの検証と並んで行う電源配線の解析はどれか。

  1. Aパッケージの色の確認
  2. BIRドロップやエレクトロマイグレーションの解析
  3. Cチップの価格の見積もり
答えと解説を見る

正解：B. IRドロップやエレクトロマイグレーションの解析

サインオフでは、タイミング、DRC・LVSに加えて、電源配線の電圧降下(IRドロップ)や、配線の電流密度によるエレクトロマイグレーションの解析を行います。電源電圧が下がるとタイミングが悪化するため、両者を組み合わせて解析することもあります。

LSI設計フロー・EDAのほかの問題

  1. 製造上のばらつきや欠陥の影響を受けにくいように、レイアウトなどを工夫する設計の考え方はどれか。
  2. アナログ回路のレイアウトで、ペアにするトランジスタを、互いの重心が一致するように分割して配置する手法はどれか。
  3. レイアウトの空いた場所に、回路として機能しないダミーパターンを配置する主な目的はどれか。
  4. ダブルパターニングを前提としたレイアウトで、設計ツールが行うパターンの割り振りとして正しいものはどれか。
  5. ネットリストの説明として正しいものはどれか。
