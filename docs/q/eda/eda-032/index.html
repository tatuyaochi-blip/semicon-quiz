LSI設計フロー・EDA

EDAツールの世界市場で大きなシェアをもつ企業の組み合わせとして正しいものはどれか。

  1. AASML・東京エレクトロン・Applied Materials
  2. BSynopsys・Cadence・Siemens EDA
  3. CTSMC・Samsung・Intel
答えと解説を見る

正解：B. Synopsys・Cadence・Siemens EDA

EDAツールの市場は、米国のSynopsysとCadence Design Systems、ドイツのSiemensのEDA部門(旧Mentor Graphics)の3社が大部分を占めています。設計の流れ全体をそろえて提供でき、ファウンドリの新しいプロセスへの対応も早いことが強みです。TSMCやSamsungは半導体の製造企業、ASMLや東京エレクトロンは製造装置の企業です。

  • A. これらは半導体の製造装置の企業です。
  • B. 正しい。この3社がEDA市場の大部分を占めます。
  • C. これらは半導体を製造する企業です。

  2. LSIの設計の評価でよく使われる「PPA」が表す3つの指標の組み合わせとして正しいものはどれか。
  3. トランジスタの寸法や配置を一つひとつ人が設計して、性能や面積を極限まで追求する設計手法はどれか。
  4. トランジスタを敷き詰めた共通の下地(マスター)をあらかじめつくっておき、配線層だけを品種ごとに設計して製造する方式はどれか。
  5. SystemVerilogを使った検証で、再利用しやすいテスト環境(テストベンチ)を組み立てるための標準的な方法論はどれか。
