LSI設計フロー・EDA

配置配線工程でのクロックツリー合成(CTS)の主な目的はどれか。

  1. Aクロック信号が各フリップフロップへ届く時間のばらつき(スキュー)を小さくする
  2. B電源電圧を上げる
  3. Cレイアウトのデザインルール違反を修正する
答えと解説を見る

正解：A. クロック信号が各フリップフロップへ届く時間のばらつき(スキュー)を小さくする

チップ内の多数のフリップフロップにクロックが届く時刻がばらつくと、タイミング違反の原因になります。CTSでは、バッファを木のように配置してクロックを分配し、各フリップフロップへの到着時刻のばらつき(スキュー)を小さくします。
