LSI設計フロー・EDA

配置配線工程でのクロックツリー合成(CTS)の主な目的はどれか。

  1. Aクロック信号が各フリップフロップへ届く時間のばらつき(スキュー)を小さくする
  2. B電源電圧を上げる
  3. Cレイアウトのデザインルール違反を修正する
答えと解説を見る

正解：A. クロック信号が各フリップフロップへ届く時間のばらつき(スキュー)を小さくする

チップ内の数百万個のフリップフロップにクロックが届く時刻がばらつくと、タイミング違反の原因になります。CTSでは、バッファを木のように配置してクロックを分配し、各フリップフロップへの到着時刻のばらつき(スキュー)を小さくします。クロックは常に切り替わるため、クロックツリーはチップの消費電力の大きな部分を占めることもあります。電源電圧やDRC違反の修正とは別の目的です。

LSI設計フロー・EDAのほかの問題

  1. LSI設計で使われる「IP(IPコア)」の意味として正しいものはどれか。
  2. 静的タイミング解析で、信号がクロックのエッジ直後に早く変化しすぎて、フリップフロップが前のデータを正しく保持できなくなるタイミング違反はどれか。
  3. ファウンドリが設計者に提供する、デザインルール、デバイスモデル、セルライブラリなどの設計用データ一式を何と呼ぶか。
  4. トランジスタレベルの回路の電圧や電流を、デバイスモデルを使って詳しく計算する回路シミュレータの代表はどれか。
  5. C言語やC++などで書いたアルゴリズムの記述から、RTLを自動で生成する技術を何と呼ぶか。
