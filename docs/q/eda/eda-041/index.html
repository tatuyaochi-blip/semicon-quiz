LSI設計フロー・EDA

異なるクロックで動く回路どうしの間で信号を受け渡す部分に、同期化の回路が正しく入っているかを専用のツールで確認する検証を何と呼ぶか。

  1. AIRドロップ解析
  2. BCDC(クロックドメインクロッシング)検証
  3. CDRC
答えと解説を見る

正解：B. CDC(クロックドメインクロッシング)検証

非同期のクロックの間で信号をそのまま受け渡すと、メタステーブルやデータの取りこぼしが起こります。CDC検証では、こうした受け渡しの箇所を設計から自動で見つけ、2段のフリップフロップなどの同期化回路が正しく入っているかを確認します。通常のシミュレーションでは見つけにくい不具合を検出できます。

  • A. IRドロップ解析は電源の電圧降下の解析です。
  • B. 正しい。クロックをまたぐ信号の受け渡しを確認する検証です。
  • C. DRCはレイアウトの図形の規則の検査です。

LSI設計フロー・EDAのほかの問題

  1. 設計の終盤や製造の途中で見つかった小さな修正を、設計全体をやり直さずに、既存のレイアウトを部分的に変更して反映することを何と呼ぶか。
  2. スタンダードセルの配置で、セルの間のすき間を埋めたり、ウェルの電位を固定したり、電源のノイズを抑えたりするために置く機能をもたない(または補助的な)セルの組み合わせとして正しいものはどれか。
  3. スタンダードセルの遅延や消費電力を、さまざまな入力の遷移時間・負荷容量・電圧・温度の条件で回路シミュレーションして表にまとめる作業を何と呼ぶか。
  4. 静的タイミング解析で、同じチップの中でも場所によってトランジスタや配線の遅延がばらつくことを考慮するため、遅延に係数を掛けて余裕をとる手法を何と呼ぶか。
  5. コーナー条件で最悪の値を組み合わせるのではなく、遅延のばらつきを確率分布として扱い、タイミングを満たす確率を求める解析手法はどれか。
