LSI設計フロー・EDA

静的タイミング解析を、プロセスのばらつき・電源電圧・温度の組み合わせを変えた複数の条件で行う理由として正しいものはどれか。

  1. A解析時間を短くするため
  2. B製造ばらつきや使用環境が変わっても、すべての条件でタイミングを満たすことを確認するため
  3. Cレイアウトの面積を小さくするため
答えと解説を見る

正解：B. 製造ばらつきや使用環境が変わっても、すべての条件でタイミングを満たすことを確認するため

トランジスタの速さは、製造のばらつき(Process)、電源電圧(Voltage)、温度(Temperature)によって変わります。遅くなる条件ではセットアップ違反が、速くなる条件ではホールド違反が起こりやすいため、複数のPVTコーナーで解析して、どの条件でも正しく動作することを確認します。

LSI設計フロー・EDAのほかの問題

  1. 配置配線後のレイアウトから、配線の抵抗や容量を取り出す工程を何と呼ぶか。
  2. 大規模なSoCの検証で、設計した回路を専用のハードウェアやFPGAの上で動かし、ソフトウェアと組み合わせて高速に検証する手法はどれか。
  3. 設計と検証を終え、マスク製作のためのデータを製造側に引き渡すことを何と呼ぶか。
  4. テープアウト前の最終確認(サインオフ)で、タイミングの検証と並んで行う電源配線の解析はどれか。
  5. 製造上のばらつきや欠陥の影響を受けにくいように、レイアウトなどを工夫する設計の考え方はどれか。
