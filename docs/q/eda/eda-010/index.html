LSI設計フロー・EDA

LSI設計で使われる「IP(IPコア)」の意味として正しいものはどれか。

  1. Aインターネットのアドレス
  2. BCPUやインターフェースなど、再利用できる設計済みの回路ブロック
  3. C製造装置の名称
答えと解説を見る

正解：B. CPUやインターフェースなど、再利用できる設計済みの回路ブロック

IPコアは、CPUコア、メモリ、USBやPCIeなどのインターフェース回路など、他の設計で再利用できるように用意された設計済みの回路ブロックです。自社で開発するほか、専門の企業からライセンスを受け、使用料を払って使うこともあります。検証済みの部品を組み合わせることで、大規模なSoCの開発期間とリスクを減らせます。IPはIntellectual Property(知的財産)の略で、ネットワークのIPアドレスとは別物です。
