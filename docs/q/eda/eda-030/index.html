LSI設計フロー・EDA

RTLの検証で、検証がどれだけ十分に行われたかを評価するために使われる指標はどれか。

  1. AFIT
  2. Bカバレッジ(コードカバレッジや機能カバレッジ)
  3. CCp
答えと解説を見る

正解：B. カバレッジ(コードカバレッジや機能カバレッジ)

カバレッジは、検証でRTLのコードのどの行や分岐が実行されたか(コードカバレッジ)、仕様で定めた機能や状況がどれだけ確認されたか(機能カバレッジ)を表す指標です。カバレッジが低い部分は検証が不足しているため、テストを追加します。

LSI設計フロー・EDAのほかの問題

  1. 「EDA」が表すものとして正しいものはどれか。
  2. EDAツールの世界市場で大きなシェアをもつ企業の組み合わせとして正しいものはどれか。
  3. 大規模なLSIの開発で、全体の工数の中で大きな割合を占めるとされる作業はどれか。
  4. LSIの設計の評価でよく使われる「PPA」が表す3つの指標の組み合わせとして正しいものはどれか。
  5. トランジスタの寸法や配置を一つひとつ人が設計して、性能や面積を極限まで追求する設計手法はどれか。
