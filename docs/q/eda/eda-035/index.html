LSI設計フロー・EDA

トランジスタの寸法や配置を一つひとつ人が設計して、性能や面積を極限まで追求する設計手法はどれか。

  1. Aスタンダードセル方式の自動配置配線
  2. BFPGAへの書き込み
  3. Cフルカスタム設計
答えと解説を見る

正解：C. フルカスタム設計

フルカスタム設計では、トランジスタのサイズやレイアウトを設計者が直接つくり込み、高速化や面積の縮小を極限まで図ります。手間がかかるため、プロセッサの重要なデータパス、SRAMなどのメモリのセル、アナログ回路、スタンダードセル自体などに使われ、それ以外は自動配置配線が主流です。スタンダードセル方式は既製のセルを自動で並べ、FPGAは製造後に回路を書き込みます。

  • A. スタンダードセル方式は、用意されたセルを自動で配置配線する手法です。
  • B. FPGAは製造後に回路を書き込むデバイスです。
  • C. 正しい。人が細部まで設計する手法です。

LSI設計フロー・EDAのほかの問題

  1. トランジスタを敷き詰めた共通の下地(マスター)をあらかじめつくっておき、配線層だけを品種ごとに設計して製造する方式はどれか。
  2. SystemVerilogを使った検証で、再利用しやすいテスト環境(テストベンチ)を組み立てるための標準的な方法論はどれか。
  3. レイアウト検証で、入力端子が浮いたまま(どこにもつながっていない)になっていないか、電源どうしが短絡していないかなど、電気的な接続の誤りを調べる検査はどれか。
  4. 設計が満たすべき性質(例えば「要求が来たら3サイクル以内に応答する」)を記述しておき、シミュレーション中や形式検証で自動的にチェックさせる手法はどれか。
  5. 低消費電力設計で、電源ドメインや電源の遮断、レベルシフタなどの「電源の意図」を、回路の記述とは別にまとめて記述する標準形式はどれか。
