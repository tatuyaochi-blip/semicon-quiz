LSI設計フロー・EDA

SystemVerilogを使った検証で、再利用しやすいテスト環境(テストベンチ)を組み立てるための標準的な方法論はどれか。

  1. AOPC
  2. BCMP
  3. CUVM(Universal Verification Methodology)
答えと解説を見る

正解：C. UVM(Universal Verification Methodology)

UVMは、SystemVerilogでテストベンチを部品(入力を与えるドライバ、出力を監視するモニタ、期待値と比べるスコアボードなど)の組み合わせとして構成するための標準的な方法論とクラスライブラリです。部品を他の設計の検証にも再利用でき、制約付きランダムな入力の生成やカバレッジの収集を組み込みやすくなります。IEEE 1800.2として標準化されています。OPCとCMPは製造の技術です。

  • A. OPCは露光の光近接効果の補正です。
  • B. CMPは化学機械研磨です。
  • C. 正しい。テストベンチを構成するための標準的な方法論です。

LSI設計フロー・EDAのほかの問題

  1. レイアウト検証で、入力端子が浮いたまま(どこにもつながっていない)になっていないか、電源どうしが短絡していないかなど、電気的な接続の誤りを調べる検査はどれか。
  2. 設計が満たすべき性質(例えば「要求が来たら3サイクル以内に応答する」)を記述しておき、シミュレーション中や形式検証で自動的にチェックさせる手法はどれか。
  3. 低消費電力設計で、電源ドメインや電源の遮断、レベルシフタなどの「電源の意図」を、回路の記述とは別にまとめて記述する標準形式はどれか。
  4. 異なるクロックで動く回路どうしの間で信号を受け渡す部分に、同期化の回路が正しく入っているかを専用のツールで確認する検証を何と呼ぶか。
  5. 設計の終盤や製造の途中で見つかった小さな修正を、設計全体をやり直さずに、既存のレイアウトを部分的に変更して反映することを何と呼ぶか。
