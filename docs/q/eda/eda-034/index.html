LSI設計フロー・EDA

LSIの設計の評価でよく使われる「PPA」が表す3つの指標の組み合わせとして正しいものはどれか。

  1. A圧力・パワー・角度
  2. B性能(Performance)・消費電力(Power)・面積(Area)
  3. C価格・利益・広告
答えと解説を見る

正解：B. 性能(Performance)・消費電力(Power)・面積(Area)

PPAは、性能(動作速度など)、消費電力、チップの面積の3つを表し、設計やプロセスの良し悪しを比べる基本的な指標です。これらは互いにトレードオフの関係にあることが多く、用途に応じてバランスをとって設計します。

  • A. 圧力や角度ではありません。
  • B. 正しい。性能・電力・面積です。
  • C. 価格や利益は設計の指標PPAではありません。

LSI設計フロー・EDAのほかの問題

  1. トランジスタの寸法や配置を一つひとつ人が設計して、性能や面積を極限まで追求する設計手法はどれか。
  2. トランジスタを敷き詰めた共通の下地(マスター)をあらかじめつくっておき、配線層だけを品種ごとに設計して製造する方式はどれか。
  3. SystemVerilogを使った検証で、再利用しやすいテスト環境(テストベンチ)を組み立てるための標準的な方法論はどれか。
  4. レイアウト検証で、入力端子が浮いたまま(どこにもつながっていない)になっていないか、電源どうしが短絡していないかなど、電気的な接続の誤りを調べる検査はどれか。
  5. 設計が満たすべき性質(例えば「要求が来たら3サイクル以内に応答する」)を記述しておき、シミュレーション中や形式検証で自動的にチェックさせる手法はどれか。
