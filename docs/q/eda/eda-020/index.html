LSI設計フロー・EDA

設計と検証を終え、マスク製作のためのデータを製造側に引き渡すことを何と呼ぶか。

  1. Aダイシング
  2. Bテープアウト
  3. Cボンディング
答えと解説を見る

正解：B. テープアウト

テープアウトは、設計の最終データ(マスクデータ)を製造側に引き渡すことで、設計工程の大きな節目です。かつて磁気テープでデータを渡していたことに由来します。テープアウト後に不具合が見つかるとマスクの作り直しが必要になり、大きな費用と時間がかかります。

LSI設計フロー・EDAのほかの問題

  1. テープアウト前の最終確認(サインオフ)で、タイミングの検証と並んで行う電源配線の解析はどれか。
  2. 製造上のばらつきや欠陥の影響を受けにくいように、レイアウトなどを工夫する設計の考え方はどれか。
  3. アナログ回路のレイアウトで、ペアにするトランジスタを、互いの重心が一致するように分割して配置する手法はどれか。
  4. レイアウトの空いた場所に、回路として機能しないダミーパターンを配置する主な目的はどれか。
  5. ダブルパターニングを前提としたレイアウトで、設計ツールが行うパターンの割り振りとして正しいものはどれか。
