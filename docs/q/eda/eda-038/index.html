LSI設計フロー・EDA

レイアウト検証で、入力端子が浮いたまま(どこにもつながっていない)になっていないか、電源どうしが短絡していないかなど、電気的な接続の誤りを調べる検査はどれか。

  1. AERC(電気的ルールチェック)
  2. BDRC
  3. COPC
答えと解説を見る

正解：A. ERC(電気的ルールチェック)

ERC(Electrical Rule Check)は、回路の電気的な接続に関する規則違反、例えば入力の浮き、出力どうしの衝突、異なる電源の短絡、ウェルの電位の未接続などを検出します。図形の寸法の規則を調べるDRCや、回路図との一致を調べるLVSとともにサインオフで行います。

  • A. 正しい。電気的な接続の誤りを調べる検査です。
  • B. DRCは図形の寸法や間隔の規則を調べる検査です。
  • C. OPCは露光の補正で、検証ではありません。

LSI設計フロー・EDAのほかの問題

  1. 設計が満たすべき性質(例えば「要求が来たら3サイクル以内に応答する」)を記述しておき、シミュレーション中や形式検証で自動的にチェックさせる手法はどれか。
  2. 低消費電力設計で、電源ドメインや電源の遮断、レベルシフタなどの「電源の意図」を、回路の記述とは別にまとめて記述する標準形式はどれか。
  3. 異なるクロックで動く回路どうしの間で信号を受け渡す部分に、同期化の回路が正しく入っているかを専用のツールで確認する検証を何と呼ぶか。
  4. 設計の終盤や製造の途中で見つかった小さな修正を、設計全体をやり直さずに、既存のレイアウトを部分的に変更して反映することを何と呼ぶか。
  5. スタンダードセルの配置で、セルの間のすき間を埋めたり、ウェルの電位を固定したり、電源のノイズを抑えたりするために置く機能をもたない(または補助的な)セルの組み合わせとして正しいものはどれか。
