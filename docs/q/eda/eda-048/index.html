LSI設計フロー・EDA

静的タイミング解析で、悲観的になりやすい通常の解析の結果を、違反した経路について実際の信号の伝わり方にもとづいて詳しく再計算し、余分な余裕を取り除く手法を何と呼ぶか。

  1. ADRC
  2. Bパスベース解析(PBA)
  3. Cグラフベース解析(GBA)だけ
答えと解説を見る

正解：B. パスベース解析(PBA)

通常のグラフベース解析(GBA)は、各ノードで合流する信号のうち最悪の遷移時間を使うため、実際にはありえない組み合わせで悲観的な結果になることがあります。パスベース解析では、特定の経路に沿った実際の遷移時間を使って再計算するため、より正確な遅延が得られ、不要な修正を減らせます。計算量が多いため、GBAで違反した経路に絞って使うのが一般的です。

  • A. DRCはレイアウトの図形の規則の検査です。
  • B. 正しい。経路ごとに詳しく再計算する手法です。
  • C. GBAは高速ですが悲観的になりやすい通常の解析です。

LSI設計フロー・EDAのほかの問題

  1. アナログ回路の設計で、製造のばらつきによるトランジスタの特性の変化をランダムに何度も与えてシミュレーションし、性能の分布や歩留まりを見積もる手法はどれか。
  2. 回路の論理シミュレーションの方式で、信号の値が変化したとき(イベント)にだけ、その影響を受ける部分を計算する方式はどれか。
  3. 一般的なデジタルLSIの設計フローの順序として正しいものはどれか。
  4. 論理合成の説明として正しいものはどれか。
  5. 静的タイミング解析(STA)の説明として正しいものはどれか。
