LSI設計フロー・EDA

コーナー条件で最悪の値を組み合わせるのではなく、遅延のばらつきを確率分布として扱い、タイミングを満たす確率を求める解析手法はどれか。

  1. ADRC
  2. B論理シミュレーション
  3. C統計的静的タイミング解析(SSTA)
答えと解説を見る

正解：C. 統計的静的タイミング解析(SSTA)

コーナーによる解析は、すべてのばらつきが同時に最悪になる場合を想定するため、余裕を取りすぎることがあります。SSTAでは、各要素の遅延を確率分布として扱い、場所による相関も考慮して経路の遅延の分布を求めることで、タイミングを満たす確率をより現実的に評価します。段数の多い経路ではランダムなばらつきが平均化されるため、過剰な余裕を減らせます。

  • A. DRCはレイアウトの図形の規則の検査です。
  • B. 論理シミュレーションは回路の動作を入力に対して確かめる方法です。
  • C. 正しい。ばらつきを確率分布として扱うタイミング解析です。

LSI設計フロー・EDAのほかの問題

  1. タイミングの制約(SDC)で、クロックのジッタやスキューの見込みなどとしてクロックの周期から差し引いておく余裕を指定するものはどれか。
  2. 静的タイミング解析で、悲観的になりやすい通常の解析の結果を、違反した経路について実際の信号の伝わり方にもとづいて詳しく再計算し、余分な余裕を取り除く手法を何と呼ぶか。
  3. アナログ回路の設計で、製造のばらつきによるトランジスタの特性の変化をランダムに何度も与えてシミュレーションし、性能の分布や歩留まりを見積もる手法はどれか。
  4. 回路の論理シミュレーションの方式で、信号の値が変化したとき(イベント)にだけ、その影響を受ける部分を計算する方式はどれか。
  5. 一般的なデジタルLSIの設計フローの順序として正しいものはどれか。
