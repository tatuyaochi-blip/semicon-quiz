パワーエレクトロニクス回路

直流電圧Eから単相の交流をつくるインバータで、ハーフブリッジ(スイッチ2個)とフルブリッジ(スイッチ4個)の出力電圧を比べた説明として、正しいものはどれか。

  1. Aハーフブリッジの出力は +E/2 と −E/2 の間で振れ、フルブリッジは +E と −E の間で振れるので、出力電圧の大きさを2倍にできる
  2. Bフルブリッジはスイッチの数が2倍になるぶん損失が増えるだけで、取り出せる出力電圧の大きさはハーフブリッジとまったく同じになる
  3. Cハーフブリッジは片方向の直流の電圧しか出力できないので、負荷に交流の電圧を加えるにはフルブリッジが必要である
答えと解説を見る

正解：A. ハーフブリッジの出力は +E/2 と −E/2 の間で振れ、フルブリッジは +E と −E の間で振れるので、出力電圧の大きさを2倍にできる

ハーフブリッジでは、直流電源を2つのコンデンサで分けた中点と2個のスイッチの接続点の間に負荷をつなぐので、負荷には +E/2 か −E/2 がかかります。フルブリッジでは2つのレグの接続点の間に負荷をつなぐので、+E と −E に加えて、両方を同じ側につないだ0も出力できます。同じ直流電圧で2倍の出力電圧が得られ、3つのレベルを使ってPWMの高調波を減らすこともできます。三相のインバータは、3つのレグ(6個のスイッチ)でつくります。

  • A. 正しい。フルブリッジは2つのレグの差を出力するので、出力電圧の大きさが2倍になります。
  • B. 同じ直流電圧でも、フルブリッジの出力電圧の大きさはハーフブリッジの2倍です。
  • C. ハーフブリッジでも、2つのスイッチを交互にオンにすれば交流を出力できます。
