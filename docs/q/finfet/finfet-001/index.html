先端トランジスタ(FinFET・GAA)

FinFETの構造上の特徴として正しいものはどれか。

  1. Aひれ(フィン)状に立てたチャネルを、ゲートが3方向から囲む
  2. Bチャネルの上面だけを平面のゲートで覆う
  3. Cゲート絶縁膜を使わず、金属を直接チャネルに接触させる
答えと解説を見る

正解：A. ひれ(フィン)状に立てたチャネルを、ゲートが3方向から囲む

FinFETは、シリコンをひれ(フィン)のように薄く立てた形にし、その両側面と上面をゲートで囲む立体構造のトランジスタです。ゲートがチャネルを3方向から制御できるため、平面型より短チャネル効果を抑えやすく、オフ時のリーク電流を減らせます。
