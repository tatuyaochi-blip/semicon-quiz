先端トランジスタ(FinFET・GAA)

ロジックの微細化の度合いを表す指標として、プロセスの世代名(ノード名)より実態を示すとされるものはどれか。

  1. Aウエハの直径
  2. Bゲートピッチ(CPP)や最小配線ピッチなどの実際の寸法
  3. Cチップの販売価格
答えと解説を見る

正解：B. ゲートピッチ(CPP)や最小配線ピッチなどの実際の寸法

近年の世代名は物理的な寸法と直接対応していないため、実際の集積度を比べるには、ゲートの配置間隔(Contacted Poly Pitch)や最小の配線間隔、SRAMセルの面積などの実寸法が使われます。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. サブスレッショルド係数の60 mV/decの壁を超えることをめざして研究されている素子はどれか。
  2. ナノシート型GAAで、各シートの間のゲートとソース・ドレインの間に設ける絶縁物(インナースペーサー)の主な役割はどれか。
  3. スタンダードセルの高さを、配線トラックの本数で表したとき、トラック数を減らすことの効果として正しいものはどれか。
  4. 同じチップの中で、しきい値電圧の異なる複数種類のトランジスタを使い分ける目的として正しいものはどれか。
  5. ゲートを絶縁膜で覆っておき、コンタクトの位置が多少ずれてもゲートとショートしないようにする技術はどれか。
