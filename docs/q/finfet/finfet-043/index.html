先端トランジスタ(FinFET・GAA)

量産されているナノシート型GAAトランジスタで、1つのトランジスタに積み重ねるナノシートの枚数として一般的なものはどれか。

  1. A1枚
  2. B3枚程度
  3. C100枚程度
答えと解説を見る

正解：B. 3枚程度

現在のナノシート型GAAでは、3枚程度のシートを積み重ねるのが一般的です。枚数を増やせば同じ面積で電流を増やせますが、下のシートほどソース・ドレインからの距離や寄生容量の影響が大きくなり、加工も難しくなるため、効果と難しさのバランスで枚数が決まります。

  • A. 1枚では、積層による電流の増加という利点が得られません。
  • B. 正しい。3枚程度が一般的です。
  • C. 100枚も積み重ねるのは、ロジックのトランジスタでは現実的ではありません。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. nMOSとpMOSのナノシートの間に薄い絶縁の壁を挟んで近づけ、セルの面積を小さくする構造はどれか。
  2. チャネルが非常に短くなり、キャリアがソースからドレインまで散乱をほとんど受けずに走り抜ける状態を何と呼ぶか。
  3. ソース・チャネル・ドレインを同じ導電型・同じ濃度でつくり、PN接合をもたないトランジスタはどれか。
  4. バルク基板上につくるFinFETで、フィンの根元(ゲートで制御しにくい部分)に高濃度の不純物層を設ける目的はどれか。
  5. 短チャネル効果の強さを見積もるのに使われる「スケール長(ナチュラル長)λ」の説明として正しいものはどれか。
