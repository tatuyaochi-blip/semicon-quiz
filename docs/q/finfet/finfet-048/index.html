先端トランジスタ(FinFET・GAA)

短チャネル効果の強さを見積もるのに使われる「スケール長(ナチュラル長)λ」の説明として正しいものはどれか。

  1. Aゲート配線の長さ
  2. Bドレインの電位の影響がチャネル内に及ぶ距離の目安で、ゲート長がλより十分長ければ短チャネル効果は小さい
  3. Cフィンの高さとまったく同じ値
答えと解説を見る

正解：B. ドレインの電位の影響がチャネル内に及ぶ距離の目安で、ゲート長がλより十分長ければ短チャネル効果は小さい

スケール長λは、チャネル内でドレイン電位の影響が減衰する距離の目安で、絶縁膜の厚さ、チャネルの厚さ、誘電率、ゲートの構造などで決まります。ゲート長がλの数倍以上あれば短チャネル効果は小さく抑えられます。ゲートで囲む面が多い構造ほどλが小さくなり、より短いゲート長まで微細化できます。

  • A. 配線の長さを表すものではありません。
  • B. 正しい。ドレインの影響が及ぶ距離の目安です。
  • C. フィンの高さとは別の量です。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. フィンやナノシートの厚さを数nmまで薄くしたときに生じる量子閉じ込め効果の影響として正しいものはどれか。
  2. (100)面のウエハ上に一般的な向きでつくったFinFETでは、チャネルとなるフィンの側面は主に(110)面になる。このことによる移動度への影響として正しいものはどれか。
  3. FinFETの構造上の特徴として正しいものはどれか。
  4. GAA(ゲートオールアラウンド)型トランジスタの説明として正しいものはどれか。
  5. MOSFETの短チャネル効果として当てはまるものはどれか。
