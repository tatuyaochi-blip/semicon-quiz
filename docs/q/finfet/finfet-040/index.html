先端トランジスタ(FinFET・GAA)

トランジスタの性能指標「Ion/Ioff比」の説明として正しいものはどれか。

  1. Aゲート長とゲート幅の比
  2. B電源電圧としきい値電圧の比
  3. Cオン状態の電流とオフ状態のリーク電流の比で、大きいほどスイッチとして優れる
答えと解説を見る

正解：C. オン状態の電流とオフ状態のリーク電流の比で、大きいほどスイッチとして優れる

Ion/Ioff比は、トランジスタがオンのときに流れる電流とオフのときに流れるリーク電流の比です。大きいほど、高速に動作しつつ待機時のリークが少ない、よいスイッチといえます。微細化で短チャネル効果が強まるとIoffが増えてこの比が下がるため、FinFETやGAAでゲートの制御力を高めています。

  • A. 寸法の比ではありません。
  • B. 電圧の比ではありません。
  • C. 正しい。オン電流とオフ電流の比です。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. 平面型トランジスタからFinFETに移行したことで、サブスレッショルド係数(SS)は一般にどう変わったか。
  2. 微細化が物理的に難しくなるなかで、設計とプロセス技術を同時に検討して、面積や性能を最適化する取り組みを何と呼ぶか。
  3. 量産されているナノシート型GAAトランジスタで、1つのトランジスタに積み重ねるナノシートの枚数として一般的なものはどれか。
  4. nMOSとpMOSのナノシートの間に薄い絶縁の壁を挟んで近づけ、セルの面積を小さくする構造はどれか。
  5. チャネルが非常に短くなり、キャリアがソースからドレインまで散乱をほとんど受けずに走り抜ける状態を何と呼ぶか。
