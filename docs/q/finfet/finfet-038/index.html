先端トランジスタ(FinFET・GAA)

High-k/メタルゲートのトランジスタで、シリコンとHigh-k膜(ハフニウム系酸化膜など)の間に、ごく薄いSiO2などの層を設けることが多い理由はどれか。

  1. Aシリコンとの界面の品質を保ち、移動度の低下などを抑えるため
  2. Bゲート容量を大きくするため
  3. C金属ゲートの抵抗を下げるため
答えと解説を見る

正解：A. シリコンとの界面の品質を保ち、移動度の低下などを抑えるため

High-k膜をシリコンに直接つけると、界面の欠陥やHigh-k膜中の電荷・振動の影響で、チャネルの移動度が下がりやすくなります。そこで1 nm程度以下のSiO2などの界面層(IL)を挟み、良好な界面を保ちます。ただし界面層は比誘電率が低いため、EOTを下げるには極力薄くする必要があります。

  • A. 正しい。界面の品質を保つための層です。
  • B. 界面層は比誘電率が低く、ゲート容量はむしろ下がる方向です。
  • C. ゲート電極の抵抗とは関係ありません。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. 将来のnMOSのチャネル材料として、InGaAsなどのIII-V族化合物半導体が研究されてきた主な理由はどれか。
  2. トランジスタの性能指標「Ion/Ioff比」の説明として正しいものはどれか。
  3. 平面型トランジスタからFinFETに移行したことで、サブスレッショルド係数(SS)は一般にどう変わったか。
  4. 微細化が物理的に難しくなるなかで、設計とプロセス技術を同時に検討して、面積や性能を最適化する取り組みを何と呼ぶか。
  5. 量産されているナノシート型GAAトランジスタで、1つのトランジスタに積み重ねるナノシートの枚数として一般的なものはどれか。
