先端トランジスタ(FinFET・GAA)

FinFETやSOIトランジスタで問題になりやすい自己発熱の原因として正しいものはどれか。

  1. Aトランジスタが冷えすぎるため
  2. B電流がまったく流れないため
  3. Cチャネルが細い構造や絶縁膜に囲まれており、発生した熱が基板へ逃げにくいため
答えと解説を見る

正解：C. チャネルが細い構造や絶縁膜に囲まれており、発生した熱が基板へ逃げにくいため

フィンのような細い構造や、熱伝導率の低い酸化膜で囲まれた構造では、トランジスタで発生した熱が基板に逃げにくく、チャネルの温度が上がります。温度が上がると移動度が下がり、配線の信頼性にも影響するため、設計時に考慮が必要です。

  2. 将来の極微細トランジスタのチャネル材料として研究されている、二硫化モリブデン(MoS2)などの材料の特徴として正しいものはどれか。
  3. FinFETのソース・ドレインで、フィンの上にエピタキシャル成長で結晶を盛り上げる主な目的はどれか。
  4. 金属と半導体のコンタクト抵抗を下げるための基本的な方法として正しいものはどれか。
  5. ロジックの微細化の度合いを表す指標として、プロセスの世代名(ノード名)より実態を示すとされるものはどれか。
