先端トランジスタ(FinFET・GAA)

ナノシート型GAAで、各シートの間のゲートとソース・ドレインの間に設ける絶縁物(インナースペーサー)の主な役割はどれか。

  1. Aゲートとソース・ドレインの間の寄生容量を減らし、短絡を防ぐ
  2. Bチャネルを発光させる
  3. C電流を増幅する
答えと解説を見る

正解：A. ゲートとソース・ドレインの間の寄生容量を減らし、短絡を防ぐ

ナノシート型GAAでは、シートの間のすき間にゲートが入り込み、ソース・ドレインと近接します。インナースペーサーは、その間に挟む絶縁物で、ゲートとソース・ドレインの間の寄生容量を小さくし、電気的な短絡を防ぎます。

この分野を解く 分野ページへ

先端トランジスタ(FinFET・GAA)のほかの問題

  1. スタンダードセルの高さを、配線トラックの本数で表したとき、トラック数を減らすことの効果として正しいものはどれか。
  2. 同じチップの中で、しきい値電圧の異なる複数種類のトランジスタを使い分ける目的として正しいものはどれか。
  3. ゲートを絶縁膜で覆っておき、コンタクトの位置が多少ずれてもゲートとショートしないようにする技術はどれか。
  4. pMOSのチャネル材料として、シリコンの代わりにSiGeやゲルマニウムが検討・採用されている理由はどれか。
  5. トランジスタの層をウエハの上に順に積み重ねてつくる、チップの貼り合わせによらない3次元集積の方式はどれか。
