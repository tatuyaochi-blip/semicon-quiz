先端トランジスタ(FinFET・GAA)

nMOSとpMOSのナノシートの間に薄い絶縁の壁を挟んで近づけ、セルの面積を小さくする構造はどれか。

  1. AFD-SOI
  2. Bプレーナ型MOSFET
  3. Cフォークシート型FET
答えと解説を見る

正解：C. フォークシート型FET

フォークシート型FETは、nMOSとpMOSのナノシートを誘電体の壁の両側に配置し、フォークの歯のような形にした構造です。nとpの間隔を大幅に詰められるため、スタンダードセルやSRAMの面積を小さくできます。GAAとCFETの間の世代の候補として研究されています。

  • A. FD-SOIは薄いシリコン層を絶縁膜の上に置いた平面型の構造です。
  • B. プレーナ型は平面のチャネルをもつ従来の構造です。
  • C. 正しい。誘電体の壁の両側にnとpのシートを配置します。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. チャネルが非常に短くなり、キャリアがソースからドレインまで散乱をほとんど受けずに走り抜ける状態を何と呼ぶか。
  2. ソース・チャネル・ドレインを同じ導電型・同じ濃度でつくり、PN接合をもたないトランジスタはどれか。
  3. バルク基板上につくるFinFETで、フィンの根元(ゲートで制御しにくい部分)に高濃度の不純物層を設ける目的はどれか。
  4. 短チャネル効果の強さを見積もるのに使われる「スケール長(ナチュラル長)λ」の説明として正しいものはどれか。
  5. フィンやナノシートの厚さを数nmまで薄くしたときに生じる量子閉じ込め効果の影響として正しいものはどれか。
