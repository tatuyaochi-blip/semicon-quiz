先端トランジスタ(FinFET・GAA)

平面型トランジスタからFinFETに移行したことで、サブスレッショルド係数(SS)は一般にどう変わったか。

  1. A理論限界の約60 mV/decを下回るようになった
  2. B理論限界の約60 mV/decに近づいた(小さくなった)
  3. C大きくなり、オフにしにくくなった
答えと解説を見る

正解：B. 理論限界の約60 mV/decに近づいた(小さくなった)

サブスレッショルド係数は、しきい値以下でドレイン電流を1桁変えるのに必要なゲート電圧で、室温では約60 mV/decが理論限界です。FinFETではゲートがチャネルを3方向から制御するため、ゲートの支配力が強まり、SSが限界の60 mV/decに近づきます。ただし通常のMOSFETの原理では60 mV/decを下回ることはできません。

  • A. 通常のMOSFETでは、熱的な限界のため60 mV/decを下回れません。
  • B. 正しい。ゲートの支配力が強まり、限界に近づきます。
  • C. FinFETではSSは改善(小さく)されます。
