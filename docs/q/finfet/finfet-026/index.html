先端トランジスタ(FinFET・GAA)

スタンダードセルの高さを、配線トラックの本数で表したとき、トラック数を減らすことの効果として正しいものはどれか。

  1. Aセルの面積が小さくなり、集積度が上がる
  2. Bセルの面積が大きくなる
  3. C配線の本数が増える
答えと解説を見る

正解：A. セルの面積が小さくなり、集積度が上がる

スタンダードセルの高さは、その上を通せる最小ピッチの配線の本数(トラック数)で表し、例えば最小配線ピッチ28 nmで6トラックなら約170 nmです。トラック数を減らすとセルが低くなり、同じ回路をより小さな面積でつくれます。先端世代では7.5T→6T→5T程度まで減ってきましたが、セル内の配線の余裕やフィン(シート)の数が減るため、配線混雑や駆動力の低下に注意が必要です。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. 同じチップの中で、しきい値電圧の異なる複数種類のトランジスタを使い分ける目的として正しいものはどれか。
  2. ゲートを絶縁膜で覆っておき、コンタクトの位置が多少ずれてもゲートとショートしないようにする技術はどれか。
  3. pMOSのチャネル材料として、シリコンの代わりにSiGeやゲルマニウムが検討・採用されている理由はどれか。
  4. トランジスタの層をウエハの上に順に積み重ねてつくる、チップの貼り合わせによらない3次元集積の方式はどれか。
  5. FinFET(IntelはTri-Gateと呼んだ)を初めて量産のロジック製品に採用した企業と世代の組み合わせとして正しいものはどれか。
