先端トランジスタ(FinFET・GAA)

トランジスタのチャネルにひずみ(応力)を加える技術の主な目的はどれか。

  1. Aしきい値電圧を0 Vにする
  2. Bキャリアの移動度を高め、駆動電流を増やす
  3. Cゲート容量を小さくする
答えと解説を見る

正解：B. キャリアの移動度を高め、駆動電流を増やす

シリコン結晶にひずみを加えるとバンド構造が変わり、キャリアの有効質量や散乱が減って移動度が向上します。nMOSには電流方向の引っ張りひずみ、pMOSには圧縮ひずみが有効で、pMOSではソース・ドレインにSiGeを埋め込み、nMOSでは引っ張り応力をもつ窒化膜で覆う方法などが使われます。90 nm世代(2003年頃)から導入され、微細化と並ぶ性能向上の柱になりました。
