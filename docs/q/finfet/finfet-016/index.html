先端トランジスタ(FinFET・GAA)

FinFETの細いフィンをつくるのに使われる、側壁スペーサーを利用してリソグラフィの限界より細かいパターンをつくる技術はどれか。

  1. ASADP/SAQP(自己整合ダブル/クアドルプルパターニング)
  2. BOPC
  3. CCMP
答えと解説を見る

正解：A. SADP/SAQP(自己整合ダブル/クアドルプルパターニング)

SADPでは、芯となるパターンの側壁に膜をつけてスペーサーを形成し、芯を取り除くことで、元のパターンの2倍の密度の細い線をつくります。これを2回繰り返すSAQPでは4倍になります。フィンや配線など、規則的な細かいパターンの形成に使われています。
