先端トランジスタ(FinFET・GAA)

サブスレッショルド係数の60 mV/decの壁を超えることをめざして研究されている素子はどれか。

  1. Aダイオード
  2. Bサイリスタ
  3. CトンネルFETや負性容量FET
答えと解説を見る

正解：C. トンネルFETや負性容量FET

通常のMOSFETは、キャリアが熱的に障壁を越える仕組みで動くため、室温では60 mV/decより急峻なスイッチングができません。トンネルFETはバンド間トンネルで、負性容量FETは強誘電体による電圧の増幅で、この限界を超え、低い電圧で動作する素子をめざしています。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. ナノシート型GAAで、各シートの間のゲートとソース・ドレインの間に設ける絶縁物(インナースペーサー)の主な役割はどれか。
  2. スタンダードセルの高さを、配線トラックの本数で表したとき、トラック数を減らすことの効果として正しいものはどれか。
  3. 同じチップの中で、しきい値電圧の異なる複数種類のトランジスタを使い分ける目的として正しいものはどれか。
  4. ゲートを絶縁膜で覆っておき、コンタクトの位置が多少ずれてもゲートとショートしないようにする技術はどれか。
  5. pMOSのチャネル材料として、シリコンの代わりにSiGeやゲルマニウムが検討・採用されている理由はどれか。
