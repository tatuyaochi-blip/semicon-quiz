先端トランジスタ(FinFET・GAA)

ゲートを絶縁膜で覆っておき、コンタクトの位置が多少ずれてもゲートとショートしないようにする技術はどれか。

  1. ALDD
  2. BTSV
  3. C自己整合コンタクト(SAC)
答えと解説を見る

正解：C. 自己整合コンタクト(SAC)

ゲートの上面と側面を窒化膜などで覆っておくと、コンタクトのエッチングがゲートの位置にずれても、窒化膜は酸化膜よりエッチングされにくいため絶縁膜で止まり、ゲートに届きません。この自己整合コンタクトにより、位置合わせの誤差を見込んだ余白が不要になり、ゲートとコンタクトの間隔を詰められます。さらにゲートの真上にコンタクトを置くCOAGなど、セル面積を縮める技術につながっています。

先端トランジスタ(FinFET・GAA)のほかの問題

  2. トランジスタの層をウエハの上に順に積み重ねてつくる、チップの貼り合わせによらない3次元集積の方式はどれか。
  3. FinFET(IntelはTri-Gateと呼んだ)を初めて量産のロジック製品に採用した企業と世代の組み合わせとして正しいものはどれか。
  4. GAA(ナノシート)型トランジスタを、世界で最初に量産に採用したと発表した企業と世代の組み合わせとして正しいものはどれか。
  5. トランジスタを微細化する主な目的として正しいものはどれか。
