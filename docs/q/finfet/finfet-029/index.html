先端トランジスタ(FinFET・GAA)

pMOSのチャネル材料として、シリコンの代わりにSiGeやゲルマニウムが検討・採用されている理由はどれか。

  1. A正孔の移動度が高いため
  2. B電子の移動度が非常に低いため
  3. C材料が安価なため
答えと解説を見る

正解：A. 正孔の移動度が高いため

ゲルマニウムやSiGeは、シリコンより正孔の移動度が高く、pMOSの駆動電流を大きくできます。SiGeチャネルのpMOSは、しきい値電圧の調整にも役立つため、先端のプロセスで採用されています。
