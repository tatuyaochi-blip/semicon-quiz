先端トランジスタ(FinFET・GAA)

「High-kゲート絶縁膜」のkが表すものはどれか。

  1. A結晶の硬さ
  2. B熱伝導率
  3. C比誘電率(誘電率の大きさ)
答えと解説を見る

正解：C. 比誘電率(誘電率の大きさ)

High-kのkは比誘電率を表し、High-k材料はSiO2(約3.9)より比誘電率の大きい絶縁材料です。代表的なものはハフニウム系の酸化物(比誘電率20程度)で、物理的に厚い膜でも大きなゲート容量が得られます。

  • A. 硬さを表す記号ではありません。
  • B. 熱伝導率を表す記号ではありません。
  • C. 正しい。kは比誘電率を表します。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. フィンの高さ50 nm、幅6 nmのFinFETで、フィン1本あたりの実効的なチャネル幅(ゲートが囲む周の長さ)に最も近いものはどれか。
  2. FinFETで短チャネル効果を十分に抑えるために、フィンの幅について一般に求められることはどれか。
  3. High-k/メタルゲートのトランジスタで、シリコンとHigh-k膜(ハフニウム系酸化膜など)の間に、ごく薄いSiO2などの層を設けることが多い理由はどれか。
  4. 将来のnMOSのチャネル材料として、InGaAsなどのIII-V族化合物半導体が研究されてきた主な理由はどれか。
  5. トランジスタの性能指標「Ion/Ioff比」の説明として正しいものはどれか。
