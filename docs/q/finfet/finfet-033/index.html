先端トランジスタ(FinFET・GAA)

トランジスタを微細化する主な目的として正しいものはどれか。

  1. Aチップの消費電力を必ず増やすため
  2. B1つのトランジスタを大きく重くするため
  3. C同じ面積により多くのトランジスタを集積し、性能・消費電力・コストを改善するため
答えと解説を見る

正解：C. 同じ面積により多くのトランジスタを集積し、性能・消費電力・コストを改善するため

トランジスタを小さくすると、同じ面積により多くの回路を集積でき、1トランジスタあたりのコストが下がります。容量が小さくなって高速化や消費電力の低減も期待でき、この3つ(PPA:性能・電力・面積)の同時改善が微細化の目的です。ムーアの法則に沿って約2年で集積度を2倍にしてきましたが、近年は製造コストの上昇で、1トランジスタあたりのコスト低下は鈍っています。

  • A. 微細化は一般に1回路あたりの消費電力を減らす方向です。
  • B. 微細化はトランジスタを小さくすることです。
  • C. 正しい。集積度を上げて性能・電力・コストを改善します。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. ナノシート型GAAトランジスタの「ナノシート」が指すものとして正しいものはどれか。
  2. 「High-kゲート絶縁膜」のkが表すものはどれか。
  3. フィンの高さ50 nm、幅6 nmのFinFETで、フィン1本あたりの実効的なチャネル幅(ゲートが囲む周の長さ)に最も近いものはどれか。
  4. FinFETで短チャネル効果を十分に抑えるために、フィンの幅について一般に求められることはどれか。
  5. High-k/メタルゲートのトランジスタで、シリコンとHigh-k膜(ハフニウム系酸化膜など)の間に、ごく薄いSiO2などの層を設けることが多い理由はどれか。

この分野の比較

  • FinFETとGAAトランジスタの違い：構造・制御性・製造を比較FinFETとゲートオールアラウンド(GAA)ナノシートのトランジスタを、ゲート構造・チャネル・静電制御・幅の調整・製造・採用状況の観点で表にして比較します。
  • SOIとバルクシリコンの違い：チップメーカーから見た比較SOIウェハとバルクシリコンを、構造・分離・寄生容量・ラッチアップ・バックバイアス・自己発熱・コスト・用途の観点で表にして比較します。
  • プレーナ型MOSFETとFinFETの違い：業界が切り替えた理由プレーナ型MOSFETとFinFETを、構造・ゲートの制御・短チャネル効果・リーク電流・サブスレッショルドスイング・駆動電流・ドーピング・使われる場所の観点で表にして比較します。
