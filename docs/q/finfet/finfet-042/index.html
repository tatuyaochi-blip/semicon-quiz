先端トランジスタ(FinFET・GAA)

微細化が物理的に難しくなるなかで、設計とプロセス技術を同時に検討して、面積や性能を最適化する取り組みを何と呼ぶか。

  1. Aウエハレベルテスト
  2. Bムーアの法則
  3. CDTCO(設計・技術協調最適化)
答えと解説を見る

正解：C. DTCO(設計・技術協調最適化)

DTCO(Design-Technology Co-Optimization)は、トランジスタや配線のプロセス技術と、スタンダードセルやSRAMなどの設計ルールを同時に検討し、セルの高さの縮小や配線の工夫などでチップの面積・性能・電力を改善する取り組みです。寸法の縮小だけに頼れなくなった先端世代で重要性が増しています。

  • A. ウエハレベルテストは、ウエハの状態でチップを検査することです。
  • B. ムーアの法則は集積度の向上に関する経験則で、取り組みの名前ではありません。
  • C. 正しい。設計とプロセスを一緒に最適化します。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. 量産されているナノシート型GAAトランジスタで、1つのトランジスタに積み重ねるナノシートの枚数として一般的なものはどれか。
  2. nMOSとpMOSのナノシートの間に薄い絶縁の壁を挟んで近づけ、セルの面積を小さくする構造はどれか。
  3. チャネルが非常に短くなり、キャリアがソースからドレインまで散乱をほとんど受けずに走り抜ける状態を何と呼ぶか。
  4. ソース・チャネル・ドレインを同じ導電型・同じ濃度でつくり、PN接合をもたないトランジスタはどれか。
  5. バルク基板上につくるFinFETで、フィンの根元(ゲートで制御しにくい部分)に高濃度の不純物層を設ける目的はどれか。
