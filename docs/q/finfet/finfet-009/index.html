先端トランジスタ(FinFET・GAA)

FinFETでトランジスタの実効的なチャネル幅を調整する方法として正しいものはどれか。

  1. Aフィンの本数を変えて調整するため、チャネル幅はとびとびの値になる
  2. Bゲート電圧の大きさで調整する
  3. C平面型と同じように任意の連続した値に設定できる
答えと解説を見る

正解：A. フィンの本数を変えて調整するため、チャネル幅はとびとびの値になる

FinFETでは、フィンの高さや幅はプロセスで決まって一定なので、チャネル幅はフィンの本数で調整します。そのため、幅は「フィン何本分」というとびとびの値になり、平面型のように自由に設定できないことが回路設計上の制約になります。

  2. High-k/メタルゲートのトランジスタで、しきい値電圧を調整する主な手段の一つはどれか。
  3. ゲートラスト(リプレースメントメタルゲート)プロセスの説明として正しいものはどれか。
  4. 完全空乏型SOI(FD-SOI)トランジスタの利点として正しいものはどれか。
  5. 微細なトランジスタで、チャネル中の不純物原子の数や位置の統計的なばらつきによってしきい値電圧がばらつく現象を何と呼ぶか。
