先端トランジスタ(FinFET・GAA)

High-k/メタルゲートのトランジスタで、しきい値電圧を調整する主な手段の一つはどれか。

  1. Aゲート電極に使う金属材料の仕事関数を選ぶ
  2. Bウエハの直径を変える
  3. Cパッケージの材料を変える
答えと解説を見る

正解：A. ゲート電極に使う金属材料の仕事関数を選ぶ

メタルゲートでは、ゲート電極の金属の仕事関数によってしきい値電圧が変わります。nMOSとpMOSでそれぞれ適した仕事関数の金属を使い分けたり、薄い金属層を重ねて仕事関数を調整したりして、目的のしきい値電圧を得ています。

  2. 完全空乏型SOI(FD-SOI)トランジスタの利点として正しいものはどれか。

  4. FinFETと比べたときの、ナノシート型GAAトランジスタの設計上の利点として正しいものはどれか。
