先端トランジスタ(FinFET・GAA)

微細なトランジスタで、チャネル中の不純物原子の数や位置の統計的なばらつきによってしきい値電圧がばらつく現象を何と呼ぶか。

  1. Aランダムドーパントゆらぎ(RDF)
  2. Bエレクトロマイグレーション
  3. C経時絶縁破壊(TDDB)
答えと解説を見る

正解：A. ランダムドーパントゆらぎ(RDF)

トランジスタが小さくなると、チャネル中に含まれる不純物原子は数十〜数百個程度になり、その数や配置の偶然のばらつきがしきい値電圧に大きく影響します。チャネルの不純物を減らせるFinFETやFD-SOIは、この点でも有利です。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. FinFETと比べたときの、ナノシート型GAAトランジスタの設計上の利点として正しいものはどれか。
  2. FinFETの細いフィンをつくるのに使われる、側壁スペーサーを利用してリソグラフィの限界より細かいパターンをつくる技術はどれか。
  3. ナノシート型GAAトランジスタの製造で、SiとSiGeを交互に積み重ねた層からSiGe層だけを選択的に除去する理由として正しいものはどれか。
  4. FinFETやSOIトランジスタで問題になりやすい自己発熱の原因として正しいものはどれか。
  5. 微細化が進んだトランジスタで、性能を制限する要因として重要性が増しているものはどれか。
