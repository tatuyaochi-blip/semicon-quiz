先端トランジスタ(FinFET・GAA)

FinFETのソース・ドレインで、フィンの上にエピタキシャル成長で結晶を盛り上げる主な目的はどれか。

  1. Aトランジスタを発光させるため
  2. Bゲート長を長くするため
  3. C寄生抵抗を下げ、チャネルにひずみを加えるため
答えと解説を見る

正解：C. 寄生抵抗を下げ、チャネルにひずみを加えるため

フィンは細いため、そのままではソース・ドレインの抵抗やコンタクトの面積が問題になります。エピタキシャル成長で結晶を盛り上げると、抵抗を下げ、コンタクトをとりやすくできます。pMOSではSiGe、nMOSではSiPなどを使い、チャネルにひずみを加える役割も果たします。

  2. ロジックの微細化の度合いを表す指標として、プロセスの世代名(ノード名)より実態を示すとされるものはどれか。
  3. サブスレッショルド係数の60 mV/decの壁を超えることをめざして研究されている素子はどれか。
  4. ナノシート型GAAで、各シートの間のゲートとソース・ドレインの間に設ける絶縁物(インナースペーサー)の主な役割はどれか。
  5. スタンダードセルの高さを、配線トラックの本数で表したとき、トラック数を減らすことの効果として正しいものはどれか。
