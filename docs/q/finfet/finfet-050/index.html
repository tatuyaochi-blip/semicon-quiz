先端トランジスタ(FinFET・GAA)

(100)面のウエハ上に一般的な向きでつくったFinFETでは、チャネルとなるフィンの側面は主に(110)面になる。このことによる移動度への影響として正しいものはどれか。

  1. A電子・正孔ともに移動度は変わらない
  2. B(100)面に比べて正孔の移動度は上がり、電子の移動度は下がる傾向がある
  3. C電子・正孔ともに移動度が大きく上がる
答えと解説を見る

正解：B. (100)面に比べて正孔の移動度は上がり、電子の移動度は下がる傾向がある

シリコンの移動度は結晶面と電流の向きに依存し、(110)面では(100)面に比べて正孔の移動度が大きく(約2倍)、電子の移動度は小さくなる傾向があります。FinFETでは電流の大部分が側面を流れるため、pMOSに有利でnMOSに不利な面方位になります。nMOSの不利はひずみ技術などで補います。この性質により、FinFETではnMOSとpMOSの性能差が平面型より小さくなりました。

  • A. 移動度は結晶面によって変わります。
  • B. 正しい。正孔は有利、電子は不利になる傾向があります。
  • C. 電子の移動度は(110)面ではむしろ下がる傾向です。

  2. GAA(ゲートオールアラウンド)型トランジスタの説明として正しいものはどれか。
  3. MOSFETの短チャネル効果として当てはまるものはどれか。
  4. ゲート絶縁膜にHigh-k(高誘電率)材料を使う主な理由はどれか。
  5. トランジスタのチャネルにひずみ(応力)を加える技術の主な目的はどれか。
