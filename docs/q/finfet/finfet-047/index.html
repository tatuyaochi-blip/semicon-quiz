先端トランジスタ(FinFET・GAA)

バルク基板上につくるFinFETで、フィンの根元(ゲートで制御しにくい部分)に高濃度の不純物層を設ける目的はどれか。

  1. Aフィンの下の部分を通るパンチスルーのリーク電流を抑えるため
  2. Bゲートの抵抗を下げるため
  3. Cフィンを高くするため
答えと解説を見る

正解：A. フィンの下の部分を通るパンチスルーのリーク電流を抑えるため

バルクFinFETでは、フィンの下部はゲートに囲まれていないため、ソースとドレインの間で電流が漏れやすくなります。フィンの根元付近にチャネルと逆の導電型の高濃度層(パンチスルーストッパ)を設け、この経路のリークを抑えます。チャネル部分には不純物を入れたくないため、浅い位置にだけ急峻に入れる制御が難しい点です。SOI基板を使えば絶縁膜で分離できますが、ウエハが高価です。

  • A. 正しい。フィンの下部のリークを抑えます。
  • B. ゲート電極の抵抗とは関係ありません。
  • C. フィンの高さを変えるための層ではありません。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. 短チャネル効果の強さを見積もるのに使われる「スケール長(ナチュラル長)λ」の説明として正しいものはどれか。
  2. フィンやナノシートの厚さを数nmまで薄くしたときに生じる量子閉じ込め効果の影響として正しいものはどれか。
  3. (100)面のウエハ上に一般的な向きでつくったFinFETでは、チャネルとなるフィンの側面は主に(110)面になる。このことによる移動度への影響として正しいものはどれか。
  4. FinFETの構造上の特徴として正しいものはどれか。
  5. GAA(ゲートオールアラウンド)型トランジスタの説明として正しいものはどれか。
