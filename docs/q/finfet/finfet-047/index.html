先端トランジスタ(FinFET・GAA)

バルク基板上につくるFinFETで、フィンの根元(ゲートで制御しにくい部分)に高濃度の不純物層を設ける目的はどれか。

  1. Aフィンの下の部分を通るパンチスルーのリーク電流を抑えるため
  2. Bゲートの抵抗を下げるため
  3. Cフィンを高くするため
答えと解説を見る

正解：A. フィンの下の部分を通るパンチスルーのリーク電流を抑えるため

バルクFinFETでは、フィンの下部はゲートに囲まれていないため、ソースとドレインの間で電流が漏れやすくなります。フィンの根元付近にチャネルと逆の導電型の高濃度層(パンチスルーストッパ)を設けて、この経路のリークを抑えます。SOI基板を使えば絶縁膜で分離できます。

  • A. 正しい。フィンの下部のリークを抑えます。
  • B. ゲート電極の抵抗とは関係ありません。
  • C. フィンの高さを変えるための層ではありません。

  4. FinFETの構造上の特徴として正しいものはどれか。
