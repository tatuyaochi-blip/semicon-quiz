先端トランジスタ(FinFET・GAA)

将来のnMOSのチャネル材料として、InGaAsなどのIII-V族化合物半導体が研究されてきた主な理由はどれか。

  1. Aシリコンより安価に製造できるため
  2. B電子の移動度がシリコンよりはるかに大きいため
  3. Cバンドギャップがシリコンより大きく、リークが少ないため
答えと解説を見る

正解：B. 電子の移動度がシリコンよりはるかに大きいため

InGaAsなどのIII-V族化合物半導体は、電子の移動度がシリコンの数倍以上と大きく、低い電圧でも大きな電流を流せると期待されてきました。一方で、シリコン基板上への結晶成長、ゲート絶縁膜との界面、正孔の移動度の低さ、コストなど、実用化には多くの課題があります。

  • A. 化合物半導体はシリコンより製造コストが高くなりがちです。
  • B. 正しい。電子の移動度が非常に大きいことが理由です。
  • C. InGaAsのバンドギャップはシリコンより小さく、リークは増えやすい方向です。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. トランジスタの性能指標「Ion/Ioff比」の説明として正しいものはどれか。
  2. 平面型トランジスタからFinFETに移行したことで、サブスレッショルド係数(SS)は一般にどう変わったか。
  3. 微細化が物理的に難しくなるなかで、設計とプロセス技術を同時に検討して、面積や性能を最適化する取り組みを何と呼ぶか。
  4. 量産されているナノシート型GAAトランジスタで、1つのトランジスタに積み重ねるナノシートの枚数として一般的なものはどれか。
  5. nMOSとpMOSのナノシートの間に薄い絶縁の壁を挟んで近づけ、セルの面積を小さくする構造はどれか。
