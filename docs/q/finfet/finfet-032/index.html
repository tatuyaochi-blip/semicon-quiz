先端トランジスタ(FinFET・GAA)

GAA(ナノシート)型トランジスタを、世界で最初に量産に採用したと発表した企業と世代の組み合わせとして正しいものはどれか。

  1. AIntelの45 nm世代
  2. BSamsungの3 nm世代(2022年)
  3. CTSMCの28 nm世代
答えと解説を見る

正解：B. Samsungの3 nm世代(2022年)

Samsungは2022年に、3 nm世代でGAA型トランジスタ(同社の呼び名はMBCFET)の量産を開始したと発表しました。TSMCは2 nm世代(N2)、Intelは18A世代(RibbonFET)でGAAを採用し、2025年頃から量産が本格化しています。GAAでは、ナノシートの幅を変えられる柔軟性と、裏面電源供給などの新技術との組み合わせが性能向上の鍵になっています。

  • A. 45 nm世代は平面型にHigh-k/メタルゲートが導入された世代です。
  • B. 正しい。Samsungが3 nm世代で最初に量産を発表しました。
  • C. 28 nm世代は平面型トランジスタの世代です。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. トランジスタを微細化する主な目的として正しいものはどれか。
  2. ナノシート型GAAトランジスタの「ナノシート」が指すものとして正しいものはどれか。
  3. 「High-kゲート絶縁膜」のkが表すものはどれか。
  4. フィンの高さ50 nm、幅6 nmのFinFETで、フィン1本あたりの実効的なチャネル幅(ゲートが囲む周の長さ)に最も近いものはどれか。
  5. FinFETで短チャネル効果を十分に抑えるために、フィンの幅について一般に求められることはどれか。

  • FinFETとGAAトランジスタの違い：構造・制御性・製造を比較FinFETとゲートオールアラウンド(GAA)ナノシートのトランジスタを、ゲート構造・チャネル・静電制御・幅の調整・製造・採用状況の観点で表にして比較します。
  • SOIとバルクシリコンの違い：チップメーカーから見た比較SOIウェハとバルクシリコンを、構造・分離・寄生容量・ラッチアップ・バックバイアス・自己発熱・コスト・用途の観点で表にして比較します。
