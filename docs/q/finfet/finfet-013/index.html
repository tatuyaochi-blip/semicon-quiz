先端トランジスタ(FinFET・GAA)

完全空乏型SOI(FD-SOI)トランジスタの利点として正しいものはどれか。

  1. Aシリコン層を厚くでき、不純物を多く入れられる
  2. Bゲート電極が不要になる
  3. Cチャネルの不純物を少なくでき、しきい値電圧のばらつきを抑えられ、基板バイアスでしきい値を調整しやすい
答えと解説を見る

正解：C. チャネルの不純物を少なくでき、しきい値電圧のばらつきを抑えられ、基板バイアスでしきい値を調整しやすい

FD-SOIでは、極めて薄いシリコン層全体が空乏化するため、チャネルに不純物を多く入れなくても短チャネル効果を抑えられます。不純物のばらつきによるしきい値電圧のばらつきが小さく、薄い埋め込み酸化膜を通して基板側から電圧をかけ、しきい値を調整できます。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. 微細なトランジスタで、チャネル中の不純物原子の数や位置の統計的なばらつきによってしきい値電圧がばらつく現象を何と呼ぶか。
  2. FinFETと比べたときの、ナノシート型GAAトランジスタの設計上の利点として正しいものはどれか。
  3. FinFETの細いフィンをつくるのに使われる、側壁スペーサーを利用してリソグラフィの限界より細かいパターンをつくる技術はどれか。
  4. ナノシート型GAAトランジスタの製造で、SiとSiGeを交互に積み重ねた層からSiGe層だけを選択的に除去する理由として正しいものはどれか。
  5. FinFETやSOIトランジスタで問題になりやすい自己発熱の原因として正しいものはどれか。
