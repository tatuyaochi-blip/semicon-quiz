先端トランジスタ(FinFET・GAA)

将来の極微細トランジスタのチャネル材料として研究されている、二硫化モリブデン(MoS2)などの材料の特徴として正しいものはどれか。

  1. A厚さ数mmの金属である
  2. B原子数層の厚さでも半導体として働く2次元材料である
  3. C電気を通さない絶縁体である
答えと解説を見る

正解：B. 原子数層の厚さでも半導体として働く2次元材料である

MoS2などの遷移金属ダイカルコゲナイドは、原子3個分(約0.65 nm)の1層でも半導体の性質を保つ2次元材料です。表面に結合の手が余っていないため、薄くしても移動度が落ちにくいのが特徴です。シリコンは数nm以下に薄くすると表面の凹凸による散乱で移動度が大きく低下するため、GAAの先の極薄チャネルの候補として研究されていますが、大面積で均一な成膜と低抵抗のコンタクトが課題です。

  2. 金属と半導体のコンタクト抵抗を下げるための基本的な方法として正しいものはどれか。
  3. ロジックの微細化の度合いを表す指標として、プロセスの世代名(ノード名)より実態を示すとされるものはどれか。
  4. サブスレッショルド係数の60 mV/decの壁を超えることをめざして研究されている素子はどれか。
  5. ナノシート型GAAで、各シートの間のゲートとソース・ドレインの間に設ける絶縁物(インナースペーサー)の主な役割はどれか。
