先端トランジスタ(FinFET・GAA)

同じチップの中で、しきい値電圧の異なる複数種類のトランジスタを使い分ける目的として正しいものはどれか。

  1. Aチップを装飾するため
  2. B速さが必要な部分には低いしきい値、リークを抑えたい部分には高いしきい値のトランジスタを使い、性能と消費電力を両立するため
  3. Cしきい値電圧を測定できないようにするため
答えと解説を見る

正解：B. 速さが必要な部分には低いしきい値、リークを抑えたい部分には高いしきい値のトランジスタを使い、性能と消費電力を両立するため

しきい値電圧が低いトランジスタは速い一方でリークが大きく、0.1 V下げるとリークは1桁以上増えます。そこで同じチップにLVT・SVT・HVTなど複数のしきい値のトランジスタを用意し、タイミングに余裕のない経路にだけ低いしきい値を使い、それ以外は高いしきい値にします。設計ツールがタイミング解析の結果を見て自動で入れ替え、性能を保ちながら待機電力を大幅に抑えます。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. ゲートを絶縁膜で覆っておき、コンタクトの位置が多少ずれてもゲートとショートしないようにする技術はどれか。
  2. pMOSのチャネル材料として、シリコンの代わりにSiGeやゲルマニウムが検討・採用されている理由はどれか。
  3. トランジスタの層をウエハの上に順に積み重ねてつくる、チップの貼り合わせによらない3次元集積の方式はどれか。
  4. FinFET(IntelはTri-Gateと呼んだ)を初めて量産のロジック製品に採用した企業と世代の組み合わせとして正しいものはどれか。
  5. GAA(ナノシート)型トランジスタを、世界で最初に量産に採用したと発表した企業と世代の組み合わせとして正しいものはどれか。
