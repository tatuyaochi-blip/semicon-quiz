先端トランジスタ(FinFET・GAA)

チャネルが非常に短くなり、キャリアがソースからドレインまで散乱をほとんど受けずに走り抜ける状態を何と呼ぶか。

  1. Aバリスティック伝導
  2. B拡散伝導
  3. Cホッピング伝導
答えと解説を見る

正解：A. バリスティック伝導

チャネル長がキャリアの平均自由行程と同程度以下になると、キャリアは格子振動や不純物でほとんど散乱されずにソースからドレインへ移動します。これをバリスティック伝導といい、電流は移動度ではなく、ソースからの注入速度などで決まるようになります。

  • A. 正しい。散乱なしで走り抜ける伝導です。
  • B. 拡散伝導は、散乱を何度も受けながら進む通常の伝導です。
  • C. ホッピング伝導は、局在した準位の間をキャリアが飛び移る伝導で、アモルファス材料などで見られます。

先端トランジスタ(FinFET・GAA)のほかの問題

  1. ソース・チャネル・ドレインを同じ導電型・同じ濃度でつくり、PN接合をもたないトランジスタはどれか。
  2. バルク基板上につくるFinFETで、フィンの根元(ゲートで制御しにくい部分)に高濃度の不純物層を設ける目的はどれか。
  3. 短チャネル効果の強さを見積もるのに使われる「スケール長(ナチュラル長)λ」の説明として正しいものはどれか。
  4. フィンやナノシートの厚さを数nmまで薄くしたときに生じる量子閉じ込め効果の影響として正しいものはどれか。
  5. (100)面のウエハ上に一般的な向きでつくったFinFETでは、チャネルとなるフィンの側面は主に(110)面になる。このことによる移動度への影響として正しいものはどれか。
