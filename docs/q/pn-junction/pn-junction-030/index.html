PN接合・ダイオード

PN接合の逆バイアス時の容量を、電圧を変えながら測る(C-V測定)ことで評価できるものとして正しいものはどれか。

  1. A発光の色
  2. Bキャリアの移動度だけ
  3. C低濃度側の不純物濃度とその深さ方向の分布
答えと解説を見る

正解：C. 低濃度側の不純物濃度とその深さ方向の分布

逆バイアスを大きくすると空乏層が広がり、容量が小さくなります。その変化の仕方は空乏層の端の不純物濃度で決まるため、C-V測定から低濃度側の不純物濃度と深さ方向の分布を求めることができます。

PN接合・ダイオードのほかの問題

  1. PN接合ダイオードの2つの端子のうち、p型側の端子を何と呼ぶか。
  2. ダイオードが一方向にだけ電流をよく流し、逆方向にはほとんど流さない性質を何と呼ぶか。
  3. 熱平衡状態のPN接合の空乏層の説明として正しいものはどれか。
  4. 定電圧ダイオード(ツェナーダイオード)を定電圧回路で使うときの一般的な向きはどれか。
  5. ダイオード1個と抵抗で構成した半波整流回路に正弦波の交流を入力したときの出力として正しいものはどれか。
