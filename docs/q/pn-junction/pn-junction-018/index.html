PN接合・ダイオード

アバランシェフォトダイオード(APD)の特徴として正しいものはどれか。

  1. A電流を流すと強く発光する
  2. Bなだれ増倍を利用して光電流を内部で増幅し、微弱な光を高感度に検出できる
  3. C交流を直流に変換する
答えと解説を見る

正解：B. なだれ増倍を利用して光電流を内部で増幅し、微弱な光を高感度に検出できる

APDは、降伏電圧に近い大きな逆バイアスをかけ、光で生じたキャリアをなだれ増倍で増やして大きな電流として取り出すフォトダイオードです。微弱な光を高感度に検出できるため、光通信の受光器やLiDARなどに使われます。

PN接合・ダイオードのほかの問題

  1. ダイオードの電流の式 I = Is {exp(qV / nkT) − 1} で、降伏しない範囲で逆方向に大きな電圧を加えたときに流れる電流はどうなるか。
  2. リレーのコイルなどの誘導性負荷に並列に接続するダイオード(フライホイールダイオード)の目的として正しいものはどれか。
  3. 順方向バイアスのPN接合で、注入された少数キャリアの蓄積によって生じる容量はどれか。
  4. 片側階段接合の空乏層の幅と逆バイアス電圧Vの関係として正しいものはどれか。(Vが内蔵電位より十分大きい場合)
  5. 高耐圧のPN接合で、接合の端(周辺部)にガードリングなどの終端構造を設ける目的として正しいものはどれか。
