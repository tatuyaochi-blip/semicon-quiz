PN接合・ダイオード

単接合の太陽電池の理論的な変換効率の上限(ショックレー・クワイサー限界)に最も近い値はどれか。

  1. A約100%
  2. B約80%
  3. C約33%
答えと解説を見る

正解：C. 約33%

単一のPN接合の太陽電池では、ギャップより小さいエネルギーの光は吸収できず、大きいエネルギーの光の余分は熱として失われます。そのため最適なバンドギャップ(約1.34 eV)でも理論効率の上限は約33%です(ショックレー・クワイサー限界)。シリコン(1.12 eV)では約29〜30%が実用上の限界とされ、量産セルは25%前後に達しています。上限を超えるには、ギャップの異なるセルを重ねる多接合が使われます。

PN接合・ダイオードのほかの問題

  1. なだれ降伏の降伏電圧は、温度が上がると一般にどうなるか。
  2. PINダイオードに順方向電流を流したとき、i層に大量のキャリアが注入されて抵抗が大きく下がる現象を何と呼ぶか。
  3. PN接合の逆バイアス時の容量を、電圧を変えながら測る(C-V測定)ことで評価できるものとして正しいものはどれか。
  4. PN接合ダイオードの2つの端子のうち、p型側の端子を何と呼ぶか。
  5. ダイオードが一方向にだけ電流をよく流し、逆方向にはほとんど流さない性質を何と呼ぶか。

この分野の比較

  • PN接合ダイオードとショットキーダイオードの違い：構造・順方向電圧・逆回復・リーク電流を比較PN接合ダイオードとショットキーバリアダイオードを、構造・電流を運ぶキャリア・順方向電圧・逆回復・逆方向リーク電流・耐圧・温度特性・用途の観点で表にして比較します。
  • ツェナー降伏とアバランシェ降伏の違い：しくみ・不純物濃度・降伏電圧・温度係数を比較PN接合のツェナー降伏とアバランシェ(なだれ)降伏を、しくみ・不純物濃度・空乏層の幅・降伏電圧の目安・温度係数の符号・降伏の立ち上がり・用途の観点で表にして比較します。
