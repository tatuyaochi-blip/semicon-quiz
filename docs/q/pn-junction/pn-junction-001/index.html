PN接合・ダイオード

PN接合ダイオードに順方向バイアスを加えるときの電圧のかけ方として正しいものはどれか。

  1. Ap側を正、n側を負にする
  2. Bp側を負、n側を正にする
  3. Cp側とn側を同じ電位にする
答えと解説を見る

正解：A. p側を正、n側を負にする

p側(アノード)を正、n側(カソード)を負にすると、外部電圧が内蔵電位を打ち消す向きに働いて電位障壁が下がり、多数キャリアが接合を越えて相手側に注入されます。これが順方向バイアスで、電流は電圧に対して指数関数的に増えます。逆につなぐと障壁が高くなり、熱で生じた少数キャリアによるごく小さな電流しか流れません。同電位では拡散とドリフトがつり合い、電流は0です。

PN接合・ダイオードのほかの問題

  2. 定電圧ダイオード(ツェナーダイオード)が主に利用している現象はどれか。
  3. PN接合ダイオードの順方向電流と順方向電圧の関係として正しいものはどれか。
  4. 一般的なシリコンPN接合ダイオードの順方向電圧(電流が流れ始めるおよその電圧)はどれか。
  5. PN接合ダイオードの逆方向飽和電流と温度の関係として正しいものはどれか。

  • PN接合ダイオードとショットキーダイオードの違い：構造・順方向電圧・逆回復・リーク電流を比較PN接合ダイオードとショットキーバリアダイオードを、構造・電流を運ぶキャリア・順方向電圧・逆回復・逆方向リーク電流・耐圧・温度特性・用途の観点で表にして比較します。
