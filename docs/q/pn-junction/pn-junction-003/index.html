PN接合・ダイオード

定電圧ダイオード(ツェナーダイオード)が主に利用している現象はどれか。

  1. A順方向の拡散電流
  2. B逆方向バイアスでの降伏現象
  3. C光の吸収による起電力
答えと解説を見る

正解：B. 逆方向バイアスでの降伏現象

定電圧ダイオードは、逆方向電圧がある値(降伏電圧)に達すると急に電流が流れ、電流が変わっても電圧がほぼ一定に保たれる性質を利用します。降伏にはツェナー降伏となだれ降伏があります。光による起電力は太陽電池やフォトダイオードで利用される現象です。

PN接合・ダイオードのほかの問題

  1. PN接合ダイオードの順方向電流と順方向電圧の関係として正しいものはどれか。
  2. 一般的なシリコンPN接合ダイオードの順方向電圧(電流が流れ始めるおよその電圧)はどれか。
  3. PN接合ダイオードの逆方向飽和電流と温度の関係として正しいものはどれか。
  4. ショットキーバリアダイオードの特徴として正しいものはどれか。
  5. 可変容量ダイオード(バラクタダイオード)が利用している性質はどれか。
