PN接合・ダイオード

高耐圧のPN接合で、接合の端(周辺部)にガードリングなどの終端構造を設ける目的として正しいものはどれか。

  1. A接合を発光させるため
  2. B接合の端に電界が集中して、設計より低い電圧で降伏するのを防ぐため
  3. C接合容量を大きくするため
答えと解説を見る

正解：B. 接合の端に電界が集中して、設計より低い電圧で降伏するのを防ぐため

実際の接合は有限の大きさで、端の部分は曲率をもつため電界が集中し、平面部分より低い電圧で降伏してしまいます。ガードリング、フィールドプレート、接合の濃度を外側ほど薄くするJTE(接合終端拡張)などの終端構造で端部の電界を広げ、平面接合に近い耐圧を確保します。高耐圧のパワーデバイスでは、チップ周辺の終端領域がかなりの面積を占めます。

PN接合・ダイオードのほかの問題

  1. 定電圧ダイオードを使った簡単な定電圧回路で、ダイオードと直列に入れる抵抗の役割として正しいものはどれか。
  2. 両側を非常に高濃度にしたPN接合で、順方向電圧を上げると電流が減る負性抵抗の領域が現れるダイオードはどれか。
  3. 結晶シリコン太陽電池のセル1枚の開放電圧の目安として正しいものはどれか。
  4. 単接合の太陽電池の理論的な変換効率の上限(ショックレー・クワイサー限界)に最も近い値はどれか。
  5. なだれ降伏の降伏電圧は、温度が上がると一般にどうなるか。
