PN接合・ダイオード

ダイオードの電流の式 I ∝ exp(qV / nkT) の理想係数nが2に近くなるのは、主にどのような電流が支配的なときか。

  1. A中性領域での少数キャリアの拡散電流
  2. B空乏層内での再結合電流
  3. Cトンネル電流
答えと解説を見る

正解：B. 空乏層内での再結合電流

少数キャリアの拡散電流が支配的なときは n ≈ 1 ですが、空乏層内で欠陥準位を介して起こる再結合電流が支配的になると n ≈ 2 に近づきます。シリコンダイオードでは、電流の小さい領域で再結合電流が目立ち、nが大きくなる傾向があります。

  • A. 拡散電流が支配的なときは n ≈ 1 です。
  • B. 正しい。空乏層内の再結合電流では n ≈ 2 になります。
  • C. トンネル電流は exp(qV/nkT) の形の温度依存性に従いません。

PN接合・ダイオードのほかの問題

  1. 階段接合のPN接合に逆バイアスを加えたとき、電界が最も強くなる場所はどこか。
  2. PN接合の解析で使われる「空乏近似」の内容として正しいものはどれか。
  3. PN接合ダイオードに順方向バイアスを加えるときの電圧のかけ方として正しいものはどれか。
  4. PN接合に加える逆方向バイアス電圧を大きくすると、空乏層の幅はどうなるか。
  5. 定電圧ダイオード(ツェナーダイオード)が主に利用している現象はどれか。
