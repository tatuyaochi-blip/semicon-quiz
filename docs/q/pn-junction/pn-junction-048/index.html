PN接合・ダイオード

ダイオードの電流の式 I ∝ exp(qV / nkT) の理想係数nが2に近くなるのは、主にどのような電流が支配的なときか。

  1. A中性領域での少数キャリアの拡散電流
  2. B空乏層内での再結合電流
  3. Cトンネル電流
答えと解説を見る

正解：B. 空乏層内での再結合電流

中性領域での少数キャリアの拡散電流が支配的なら n ≈ 1ですが、空乏層内で欠陥準位を介する再結合電流が支配的になると n ≈ 2 に近づきます。再結合電流は exp(qV/2kT) に比例するためです。シリコンダイオードでは低電流域で再結合電流が目立ちます。片対数のI-V特性からnを求めると、欠陥の多さや製造品質の目安になり、太陽電池の評価にも使われます。

  • A. 拡散電流が支配的なときは n ≈ 1 です。
  • B. 正しい。空乏層内の再結合電流では n ≈ 2 になります。
  • C. トンネル電流は exp(qV/nkT) の形の温度依存性に従いません。
