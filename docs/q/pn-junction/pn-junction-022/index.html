PN接合・ダイオード

片側階段接合の空乏層の幅と逆バイアス電圧Vの関係として正しいものはどれか。(Vが内蔵電位より十分大きい場合)

  1. AVに比例する
  2. BVの2乗に比例する
  3. CVの平方根にほぼ比例する
答えと解説を見る

正解：C. Vの平方根にほぼ比例する

片側階段接合の空乏層幅は W ∝ √(Vbi + V) で表され、Vが十分大きければほぼ√Vに比例します。そのため接合容量は1/√Vにほぼ比例して小さくなります。また、低濃度側の不純物濃度が低いほど空乏層は広がります。

この分野を解く 分野ページへ

PN接合・ダイオードのほかの問題

  1. 高耐圧のPN接合で、接合の端(周辺部)にガードリングなどの終端構造を設ける目的として正しいものはどれか。
  2. 定電圧ダイオードを使った簡単な定電圧回路で、ダイオードと直列に入れる抵抗の役割として正しいものはどれか。
  3. 両側を非常に高濃度にしたPN接合で、順方向電圧を上げると電流が減る負性抵抗の領域が現れるダイオードはどれか。
  4. 結晶シリコン太陽電池のセル1枚の開放電圧の目安として正しいものはどれか。
  5. 単接合の太陽電池の理論的な変換効率の上限(ショックレー・クワイサー限界)に最も近い値はどれか。
