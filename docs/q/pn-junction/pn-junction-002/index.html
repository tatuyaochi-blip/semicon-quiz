PN接合・ダイオード

PN接合に加える逆方向バイアス電圧を大きくすると、空乏層の幅はどうなるか。

  1. A狭くなる
  2. B変化しない
  3. C広くなる
答えと解説を見る

正解：C. 広くなる

逆方向バイアスでは外部電圧が内蔵電位と同じ向きに加わり、キャリアがさらに接合から引き離されるため、空乏層は広がります。幅はおよそ √(Vbi + V) に比例し、例えば電圧を4倍にすると約2倍になります。空乏層が広がると接合容量(C = εA/W)は小さくなり、この性質が可変容量ダイオードに使われます。電界を受け持つ幅が広がることは、耐圧の確保にもつながります。
