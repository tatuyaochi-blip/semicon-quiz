PN接合・ダイオード

PN接合に加える逆方向バイアス電圧を大きくすると、空乏層の幅はどうなるか。

  1. A狭くなる
  2. B変化しない
  3. C広くなる
答えと解説を見る

正解：C. 広くなる

逆方向バイアスでは、外部電圧が内蔵電位と同じ向きに加わり、接合部のキャリアがさらに引き離されます。そのため空乏層は広がります。空乏層が広がると接合容量は小さくなり、この性質は可変容量ダイオードに利用されます。

PN接合・ダイオードのほかの問題

  1. 定電圧ダイオード(ツェナーダイオード)が主に利用している現象はどれか。
  2. PN接合ダイオードの順方向電流と順方向電圧の関係として正しいものはどれか。
  3. 一般的なシリコンPN接合ダイオードの順方向電圧(電流が流れ始めるおよその電圧)はどれか。
  4. PN接合ダイオードの逆方向飽和電流と温度の関係として正しいものはどれか。
  5. ショットキーバリアダイオードの特徴として正しいものはどれか。
