PN接合・ダイオード

p層とn層の間に不純物の少ないi層を挟んだPINダイオードの特徴として正しいものはどれか。

  1. A電流を増幅できる
  2. B順方向電圧が0 Vになる
  3. Ci層が広い空乏層となるため、高耐圧化や、光検出器の高速・高感度化に向く
答えと解説を見る

正解：C. i層が広い空乏層となるため、高耐圧化や、光検出器の高速・高感度化に向く

PINダイオードでは、不純物の少ないi層全体が空乏層として働きます。広い空乏層で高い電圧を受け持てるため高耐圧のダイオードに、また光を吸収する領域が広く接合容量も小さいため、高速・高感度の光検出器に使われます。高周波のスイッチにも利用されます。

PN接合・ダイオードのほかの問題

  1. アバランシェフォトダイオード(APD)の特徴として正しいものはどれか。
  2. ダイオードの電流の式 I = Is {exp(qV / nkT) − 1} で、降伏しない範囲で逆方向に大きな電圧を加えたときに流れる電流はどうなるか。
  3. リレーのコイルなどの誘導性負荷に並列に接続するダイオード(フライホイールダイオード)の目的として正しいものはどれか。
  4. 順方向バイアスのPN接合で、注入された少数キャリアの蓄積によって生じる容量はどれか。
  5. 片側階段接合の空乏層の幅と逆バイアス電圧Vの関係として正しいものはどれか。(Vが内蔵電位より十分大きい場合)
