PN接合・ダイオード

LEDが光る仕組みとして正しいものはどれか。

  1. A順方向バイアスで注入された電子と正孔が再結合するときに光を出す
  2. B逆方向の降伏電流で高温になり、熱放射で光る
  3. C光が当たると電流が流れる
答えと解説を見る

正解：A. 順方向バイアスで注入された電子と正孔が再結合するときに光を出す

LEDに順方向電圧をかけると、n側から電子が、p側から正孔が接合部に注入され、それらが再結合するときにバンドギャップに相当するエネルギーを光として放出します。光が当たると電流が流れるのはフォトダイオードの働きです。

PN接合・ダイオードのほかの問題

  1. p層とn層の間に不純物の少ないi層を挟んだPINダイオードの特徴として正しいものはどれか。
  2. アバランシェフォトダイオード(APD)の特徴として正しいものはどれか。
  3. ダイオードの電流の式 I = Is {exp(qV / nkT) − 1} で、降伏しない範囲で逆方向に大きな電圧を加えたときに流れる電流はどうなるか。
  4. リレーのコイルなどの誘導性負荷に並列に接続するダイオード(フライホイールダイオード)の目的として正しいものはどれか。
  5. 順方向バイアスのPN接合で、注入された少数キャリアの蓄積によって生じる容量はどれか。
