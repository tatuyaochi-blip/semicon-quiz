PN接合・ダイオード

PN接合ダイオードの順方向電流と順方向電圧の関係として正しいものはどれか。

  1. A電圧に比例して直線的に増加する
  2. B電圧に対して指数関数的に増加する
  3. C電圧に関係なく一定である
答えと解説を見る

正解：B. 電圧に対して指数関数的に増加する

ダイオードの電流は I = Is{exp(qV/nkT) − 1} で表され、順方向電圧に対して指数関数的に増えます。室温では電圧を約60 mV上げるごとに電流が約10倍になるため、ある電圧を超えると急に流れ始めるように見えます。そのため抵抗のようにオームの法則には従わず、電流が大きい領域では直列抵抗の影響で直線に近づきます。この急な立ち上がりが整流やスイッチの基礎です。
