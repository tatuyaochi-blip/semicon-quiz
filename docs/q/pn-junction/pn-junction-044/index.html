PN接合・ダイオード

片側の不純物濃度を低くしたPN接合の降伏電圧は、一般にどうなるか。

  1. A不純物濃度には関係しない
  2. B低くなる
  3. C高くなる
答えと解説を見る

正解：C. 高くなる

不純物濃度が低いと、同じ電圧でも空乏層が広く伸び、接合内の電界が弱くなります。そのため、なだれ降伏が起こる臨界電界に達するにはより高い電圧が必要になり、降伏電圧は高くなります。高耐圧のパワーデバイスで低濃度のドリフト層を使うのはこのためです。

  • A. 降伏電圧は不純物濃度に強く依存します。
  • B. 高濃度にすると降伏電圧は低くなり、低濃度にすると高くなります。
  • C. 正しい。空乏層が広がり電界が弱まるため、降伏電圧は高くなります。

PN接合・ダイオードのほかの問題

  1. ICの入出力端子に接続されるESD保護ダイオードの主な役割はどれか。
  2. 定電圧ダイオードで、ツェナー電圧が約5〜6 Vのものは温度による電圧の変化が小さい。その理由として正しいものはどれか。
  3. 金属と半導体の接触をオーミック接触(抵抗性の接触)にするためによく使われる方法はどれか。
  4. ダイオードの電流の式 I ∝ exp(qV / nkT) の理想係数nが2に近くなるのは、主にどのような電流が支配的なときか。
  5. 階段接合のPN接合に逆バイアスを加えたとき、電界が最も強くなる場所はどこか。
