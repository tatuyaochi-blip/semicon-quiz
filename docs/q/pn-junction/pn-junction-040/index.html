PN接合・ダイオード

逆バイアスのPN接合の空乏層容量(接合容量)Cを、接合の面積A、空乏層の幅W、半導体の誘電率εで表した式はどれか。

  1. AC = εA / W
  2. BC = εW / A
  3. CC = ε / (A × W)
答えと解説を見る

正解：A. C = εA / W

空乏層は、両側に電荷がたまった絶縁層のように振る舞うため、平行平板コンデンサと同じく C = εA/W で表せます。逆バイアスを大きくするとWが広がり、容量は小さくなります。

  • A. 正しい。平行平板コンデンサと同じ形の式です。
  • B. 幅Wが広いほど容量は小さくなるので、Wは分母にきます。
  • C. 面積Aが大きいほど容量は大きくなるので、Aは分子にきます。
この分野を解く 分野ページへ

PN接合・ダイオードのほかの問題

  1. 熱平衡状態のPN接合で、外部に電流が流れない理由として正しいものはどれか。
  2. 太陽電池の曲線因子(フィルファクタ、FF)の定義として正しいものはどれか。
  3. 順方向に1 mAの電流を流している理想的なシリコンダイオードの小信号抵抗(動抵抗)は、室温でおよそいくらか。(kT/q ≈ 26 mV)
  4. 片側の不純物濃度を低くしたPN接合の降伏電圧は、一般にどうなるか。
  5. ICの入出力端子に接続されるESD保護ダイオードの主な役割はどれか。
