計算機算術

乗算器で多数の部分積を足し合わせるのに、桁上げ保存加算器が使われる主な理由はどれか。

  1. A桁上げ保存加算器は、部分積の数を最初から1つに減らせるから
  2. B桁上げ保存加算器は、掛け算を足し算なしで行えるから
  3. C桁上げを伝えずに3つを2つにまとめ、遅延が一定だから
答えと解説を見る

正解：C. 桁上げを伝えずに3つを2つにまとめ、遅延が一定だから

通常の加算器で部分積を1つずつ足していくと、そのたびに桁上げが下位から上位へ伝わるのを待つ必要があります。桁上げ保存加算器は、全加算器を桁ごとに独立に並べたもので、3つの数を「各桁の和」と「各桁の桁上げ」の2つの数にまとめるだけなので、桁上げの伝わりを待たず、遅延は全加算器1段分で一定です。これを重ねて部分積を2つまで減らし、最後に1回だけ桁上げ先見加算器などで足します。部分積をいきなり1つにはできません。

  • A. 一度に減らせるのは3つから2つで、1つにはなりません。
  • B. 部分積を足し合わせる足し算そのものに使います。
  • C. 正しい。桁上げを伝えずに3つを2つにまとめ、遅延が一定です。
