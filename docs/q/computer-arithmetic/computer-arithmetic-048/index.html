計算機算術

IEEE 754の単精度の浮動小数点数で、0から始めてすべての整数を正確に表せる上限はどれか。

  1. A2²³ = 8388608
  2. B2²⁴ = 16777216
  3. C2³¹ = 2147483648
答えと解説を見る

正解：B. 2²⁴ = 16777216

単精度の仮数は、隠れビットを含めて24ビットの精度があるので、2²⁴ = 16777216 までのすべての整数を正確に表せます。それを超えると、表せる値の間隔が2になり、16777217 は表せずに 16777216 に丸められます。そのため、単精度の変数でカウンタを数えると、この値で増えなくなります。2²³は隠れビットを数え忘れた値、2³¹は32ビットの整数の範囲と混同した値です。倍精度なら 2⁵³ まで正確に表せます。

  • A. 2²³は隠れビットを数え忘れた値です。
  • B. 正しい。24ビットの精度で、2²⁴までの整数を正確に表せます。
  • C. 2³¹は32ビットの整数の範囲と混同した値です。

この分野の比較

  • 固定小数点と浮動小数点の違い：表現・範囲と精度・演算器の規模・オーバーフロー・用途を比較固定小数点と浮動小数点を、表現のしかた・表せる範囲と精度・演算器の規模と電力・オーバーフローの扱い・プログラミングの手間・使われる場所の観点で表にして比較します。
  • FP32・FP16・BF16・INT8の違い：ビット構成・範囲・精度・用途を比較FP32・FP16・BF16・INT8を、ビット構成(符号・指数・仮数)・表せる範囲・精度・FP32からの変換・メモリ・演算器の効率・学習と推論での用途の観点で表にして比較します。
