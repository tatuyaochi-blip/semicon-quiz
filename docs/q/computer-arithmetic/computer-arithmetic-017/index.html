計算機算術

IEEE 754の単精度で、指数部がすべて1(255)のビット列が表すものの説明として正しいものはどれか。

  1. A仮数にかかわらず、すべて最大の正規化数を表す
  2. B仮数が0なら無限大、仮数が0でなければNaNを表す
  3. C仮数にかかわらず、すべて0を表す
答えと解説を見る

正解：B. 仮数が0なら無限大、仮数が0でなければNaNを表す

指数部の最大値(すべて1)は特殊値のために予約されています。仮数がすべて0なら、符号ビットに応じて正または負の無限大を表し、仮数が0でなければNaNを表します。NaNは仮数の値によってさらに種類が分かれ、計算で例外を起こすかどうかなどを区別できます。最大の正規化数は指数部が254のときの値で、0は指数部も仮数もすべて0のビット列です。指数部が0のときは、0と非正規化数を表します。

  • A. 最大の正規化数は指数部が254のときの値です。
  • B. 正しい。仮数0なら無限大、0以外ならNaNです。
  • C. 0は指数部も仮数もすべて0のビット列です。
