計算機算術

最近接偶数丸めで整数に丸めるとき、2.5 と 3.5 はそれぞれいくつになるか。

  1. A3 と 4
  2. B2 と 4
  3. C2 と 3
答えと解説を見る

正解：B. 2 と 4

どちらもちょうど中間の値なので、偶数の方に丸めます。2.5は2と3の中間で、偶数の2に丸めます。3.5は3と4の中間で、偶数の4に丸めます。中間を常に切り上げる四捨五入では3と4になり、合計は元の合計6より1大きい7になってしまいますが、偶数への丸めでは 2 + 4 = 6 で合計が保たれます。2と3は、中間を常に切り捨てた場合の結果です。丸め誤差のかたよりを防ぐのがこの方式の利点です。

  • A. 3と4は中間を常に切り上げる四捨五入の結果です。
  • B. 正しい。中間の値はどちらも偶数側の2と4に丸めます。
  • C. 2と3は中間を常に切り捨てた結果です。

計算機算術のほかの問題

  1. ほぼ等しい2つの浮動小数点数を引き算したとき、有効な桁が大きく減ってしまう現象を何と呼ぶか。
  2. x が非常に大きいとき、√(x + 1) − √x を浮動小数点で計算すると桁落ちが起こる。結果を精度よく求めるための書き換えとして正しいものはどれか。
  3. 単精度の浮動小数点数で、1億(10⁸)に1を足しても結果が1億のまま変わらない。この現象の説明として正しいものはどれか。
  4. 大量の浮動小数点数を足し合わせるときに使われるカハンの加算(補正つき加算)の目的として正しいものはどれか。
  5. FMA(融合積和演算)命令で a × b + c を計算する利点として正しいものはどれか。
