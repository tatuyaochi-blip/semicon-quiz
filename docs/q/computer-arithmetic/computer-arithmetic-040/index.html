計算機算術

符号なしの8ビットの数どうしを掛けたとき、結果を桁あふれなく表すのに必要なビット数はどれか。

  1. A8ビット
  2. B9ビット
  3. C16ビット
答えと解説を見る

正解：C. 16ビット

8ビットの符号なしの数の最大値は255なので、最大の積は 255 × 255 = 65025 です。これは 2¹⁶ = 65536 より小さく 2¹⁵ = 32768 より大きいので、16ビットあれば必ず表せ、15ビットでは足りません。一般に、nビットとmビットの数の積は n + m ビットで表せます。そのため乗算器の出力は入力の2倍の幅をもつのが普通です。9ビットは足し算の結果(和は n + 1 ビット)に必要な幅です。

  • A. 8ビットでは255までしか表せず、積はあふれます。
  • B. 9ビットは足し算の結果に必要な幅です。
  • C. 正しい。最大の積65025は16ビットで表せます。
