計算機算術

IEEE 754の浮動小数点数の演算で、正の数を0で割ったときの結果として規格で定められているものはどれか。

  1. A0
  2. B最も大きな正規化数
  3. C正の無限大
答えと解説を見る

正解：C. 正の無限大

IEEE 754では、0でない数を0で割ると、符号に応じて正または負の無限大を返すと定めています。無限大は指数部がすべて1、仮数が0のビット列で表され、オーバーフローしたときの結果にも使われます。プログラムを止めずに計算を続けられ、あとで結果を調べて異常を見つけられます。なお0 ÷ 0 は値が定まらないのでNaNになります。整数の割り算とは違い、浮動小数点では例外で停止しないのが既定です。

  • A. 0にはなりません。
  • B. 最大の正規化数ではなく、無限大になります。
  • C. 正しい。正の数 ÷ 0 は正の無限大です。
