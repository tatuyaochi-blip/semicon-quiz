計算機算術

IEEE 754で既定の丸めの方法として定められているものはどれか。

  1. A最も近い値に丸め、ちょうど中間なら偶数側に丸める
  2. B常に0に近い方へ切り捨てる
  3. C常に大きい方へ切り上げる
答えと解説を見る

正解：A. 最も近い値に丸め、ちょうど中間なら偶数側に丸める

IEEE 754の既定の丸めは、表せる値のうち最も近いものに丸め、ちょうど中間のときは最下位のビットが0(偶数)になる方を選ぶ最近接偶数丸めです。中間を常に切り上げると誤差が一方向にかたより、計算を重ねるとずれが大きくなりますが、偶数側に丸めると上下に半々に分かれて打ち消し合います。0の方向や正の方向への丸めも規格に定められていますが、区間演算などの特別な目的で選んで使うもので、既定ではありません。

  • A. 正しい。最近接偶数丸めが既定です。
  • B. 0の方向への丸めは規格にありますが既定ではありません。
  • C. 正の方向への丸めも既定ではありません。

計算機算術のほかの問題

  1. 最近接偶数丸めで整数に丸めるとき、2.5 と 3.5 はそれぞれいくつになるか。
  2. ほぼ等しい2つの浮動小数点数を引き算したとき、有効な桁が大きく減ってしまう現象を何と呼ぶか。
  3. x が非常に大きいとき、√(x + 1) − √x を浮動小数点で計算すると桁落ちが起こる。結果を精度よく求めるための書き換えとして正しいものはどれか。
  4. 単精度の浮動小数点数で、1億(10⁸)に1を足しても結果が1億のまま変わらない。この現象の説明として正しいものはどれか。
  5. 大量の浮動小数点数を足し合わせるときに使われるカハンの加算(補正つき加算)の目的として正しいものはどれか。
