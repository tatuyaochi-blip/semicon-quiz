計算機算術

IEEE 754の浮動小数点数を構成する3つの部分の組み合わせとして正しいものはどれか。

  1. A符号、指数部、仮数
  2. B整数部、小数部、桁上げ
  3. C上位バイト、下位バイト、パリティ
答えと解説を見る

正解：A. 符号、指数部、仮数

浮動小数点数は、値を「(−1)^符号 × 1.仮数 × 2^指数」の形で表し、正か負かを表す符号ビット、2の何乗かを表す指数部、有効数字を表す仮数の3つの部分で記録します。指数で小数点の位置を動かせるので、非常に小さな数から大きな数までを同じビット数で表せます。整数部と小数部に分けるのは固定小数点の考え方で、パリティは誤りの検出のためのビットです。

  • A. 正しい。符号・指数部・仮数の3つからなります。
  • B. 整数部と小数部に分けるのは固定小数点の考え方です。
  • C. パリティは誤りの検出のためのもので、構成要素ではありません。

計算機算術のほかの問題

  1. IEEE 754の単精度(32ビット)の浮動小数点数で、符号・指数部・仮数に割り当てられるビット数の組み合わせはどれか。
  2. IEEE 754の倍精度(64ビット)の浮動小数点数で、指数部と仮数のビット数の組み合わせとして正しいものはどれか。
  3. IEEE 754の単精度で、指数部に記録される値が130のとき、実際の指数(2の何乗か)はいくつか。
  4. IEEE 754の正規化数で、仮数の先頭の1を記録しない(隠れビット)ことの効果として正しいものはどれか。
  5. 10進数の1.0を、IEEE 754の単精度で表したビット列を16進数で書くとどれか。
