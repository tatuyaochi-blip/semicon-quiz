計算機算術

浮動小数点数で、隣り合う表せる値どうしの間隔についての説明として正しいものはどれか。

  1. A絶対値が大きい数ほど、隣の値との間隔が広くなる
  2. Bどの大きさの数でも、隣の値との間隔は同じである
  3. C絶対値が大きい数ほど、隣の値との間隔が狭くなる
答えと解説を見る

正解：A. 絶対値が大きい数ほど、隣の値との間隔が広くなる

浮動小数点数は、仮数の桁数が決まっていて指数で大きさを変えるので、同じ指数の範囲の中では等間隔ですが、指数が1つ大きくなると間隔は2倍になります。例えば単精度では、1付近の間隔は約1.2 × 10⁻⁷ですが、1億付近では8になります。このため相対的な精度はどの大きさでもほぼ同じで、絶対的な誤差は大きい数ほど大きくなります。どこでも同じ間隔になるのは固定小数点の性質です。

  • A. 正しい。指数が大きいほど間隔は広くなります。
  • B. どこでも同じ間隔になるのは固定小数点です。
  • C. 大きい数ほど間隔は広がり、狭くはなりません。

計算機算術のほかの問題

  1. IEEE 754の単精度の浮動小数点数で、0から始めてすべての整数を正確に表せる上限はどれか。
  2. 金額の計算で、2進数の浮動小数点数ではなく、最小の単位(1円や1セント)を1とする整数で扱うことが多い主な理由はどれか。
  3. AIの混合精度の学習で、計算の多くをFP16やbfloat16で行いながら、重みの元の値(マスターウェイト)をFP32で保持しておく主な理由はどれか。
  4. 8ビットのうち下位4ビットを小数部とする固定小数点(符号なし)で、ビット列 0011 1000 が表す値はいくらか。
  5. IEEE 754の浮動小数点数を構成する3つの部分の組み合わせとして正しいものはどれか。
