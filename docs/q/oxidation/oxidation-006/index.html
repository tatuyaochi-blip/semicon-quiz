酸化・拡散

シリコン上の酸化膜が、膜厚に応じてさまざまな色に見える理由として正しいものはどれか。

  1. A酸化膜に含まれる不純物の色
  2. B酸化膜の表面と裏面(シリコンとの界面)で反射した光の干渉
  3. C酸化膜自体が発光している
答えと解説を見る

正解：B. 酸化膜の表面と裏面(シリコンとの界面)で反射した光の干渉

SiO2自体は透明ですが、膜の表面で反射した光とシリコンとの界面で反射した光が干渉し、膜厚に応じて特定の色が強め合って見えます。そのため、色を見ればおおよその膜厚がわかります。精密な測定にはエリプソメトリなどを使います。

酸化・拡散のほかの問題

  1. 多数のウエハを一度に熱酸化するときに一般的に使われる装置はどれか。
  2. 熱拡散で、表面に一定量の不純物を導入する工程のあとに、不純物をより深く押し込む工程を何と呼ぶか。
  3. シリコンの熱酸化における酸化速度の面方位依存性として正しいものはどれか。
  4. ゲート酸化膜に窒素を導入して酸窒化膜(SiON)にする主な目的はどれか。
  5. 熱酸化膜が、拡散の際の不純物のマスクとして使える理由として正しいものはどれか。
