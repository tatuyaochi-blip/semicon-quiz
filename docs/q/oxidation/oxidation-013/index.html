酸化・拡散

熱酸化の際に、塩化水素(HCl)などの塩素を含むガスを少量加える主な目的はどれか。

  1. A酸化膜を導電性にするため
  2. B酸化速度を0にするため
  3. Cナトリウムなどの可動イオンや金属汚染の影響を抑えるため
答えと解説を見る

正解：C. ナトリウムなどの可動イオンや金属汚染の影響を抑えるため

塩素を含む雰囲気で酸化すると、ナトリウムなどの可動イオンや金属汚染が塩化物として取り除かれたり、酸化膜中で不活性化されたりします。その結果、酸化膜の電気的な特性や信頼性が向上します。

  2. ランプなどでウエハを1枚ずつ、数秒程度の短時間で高温に加熱する熱処理を何と呼ぶか。
  3. 熱酸化で形成したSiO2膜の比誘電率に最も近い値はどれか。
  4. シリコンがMOSデバイスの材料として広く使われてきた大きな理由の一つとして正しいものはどれか。
  5. ゲート酸化膜中にナトリウムイオンなどの可動イオンが含まれると起こる問題として正しいものはどれか。
