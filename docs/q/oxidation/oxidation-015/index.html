酸化・拡散

ランプなどでウエハを1枚ずつ、数秒程度の短時間で高温に加熱する熱処理を何と呼ぶか。

  1. Aバッチ炉アニール
  2. BRTP(急速熱処理)
  3. CCMP
答えと解説を見る

正解：B. RTP(急速熱処理)

RTP(Rapid Thermal Processing)は、ハロゲンランプなどでウエハを急速に加熱・冷却する熱処理です。高温にさらす時間が短いため、不純物の拡散を抑えながら活性化アニールや薄い酸化膜の形成などができます。

酸化・拡散のほかの問題

  1. 熱酸化で形成したSiO2膜の比誘電率に最も近い値はどれか。
  2. シリコンがMOSデバイスの材料として広く使われてきた大きな理由の一つとして正しいものはどれか。
  3. ゲート酸化膜中にナトリウムイオンなどの可動イオンが含まれると起こる問題として正しいものはどれか。
  4. シリコン中の熱処理での拡散が比較的遅く、浅い接合をつくりやすいn型不純物はどれか。
  5. パイロジェニック酸化(水素燃焼酸化)の説明として正しいものはどれか。
