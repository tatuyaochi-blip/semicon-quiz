酸化・拡散

パイロジェニック酸化(水素燃焼酸化)の説明として正しいものはどれか。

  1. A水素と酸素を燃焼させて生成した高純度の水蒸気で酸化する、ウェット酸化の方法
  2. B乾燥した酸素だけで酸化するドライ酸化の方法
  3. CCVDで酸化膜を堆積する方法
答えと解説を見る

正解：A. 水素と酸素を燃焼させて生成した高純度の水蒸気で酸化する、ウェット酸化の方法

パイロジェニック酸化では、炉の入口(トーチ)で水素と酸素を燃焼させて水蒸気をつくり、その水蒸気でシリコンを酸化します。純水を沸騰させて水蒸気を送る方法に比べて汚染が少なく、ガスの流量で水蒸気の量を正確に制御できます。水素が残ると爆発の危険があるため、酸素を少し多めに流す安全設計になっています。厚いフィールド酸化膜やマスク酸化膜の形成に広く使われてきました。
