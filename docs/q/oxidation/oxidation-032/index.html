酸化・拡散

シリコンの熱酸化が一般的に行われる温度の範囲として最も近いものはどれか。

  1. A約100〜200℃
  2. B約800〜1,200℃
  3. C約2,000〜3,000℃
答えと解説を見る

正解：B. 約800〜1,200℃

シリコンの熱酸化は、一般に800〜1,200℃程度の高温で行われます。温度が高いほど酸化は速く進みます。シリコンの融点は約1,414℃なので、それより十分低い温度で処理します。

  • A. 約100〜200℃では、シリコンの酸化はほとんど進みません。
  • B. 正しい。800〜1,200℃程度で行います。
  • C. 約2,000℃以上はシリコンの融点を超えてしまいます。

酸化・拡散のほかの問題

  1. 半導体製造でいう不純物の「拡散」の説明として正しいものはどれか。
  2. シリコンの熱酸化膜の代表的な使われ方として正しいものはどれか。
  3. 拡散係数Dの単位として正しいものはどれか。
  4. フィックの第1法則の内容として正しいものはどれか。(J:拡散の流束、D:拡散係数、C:濃度、x:位置)
  5. 同じ温度で不純物を拡散させるとき、拡散時間を4倍にすると、不純物が広がるおよその距離は何倍になるか。
