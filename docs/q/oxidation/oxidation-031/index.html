酸化・拡散

シリコンのドライ熱酸化で起こる化学反応として正しいものはどれか。

  1. ASi + O2 → SiO2
  2. BSi + N2 → SiN
  3. CSiO2 + H2 → Si + H2O
答えと解説を見る

正解：A. Si + O2 → SiO2

ドライ酸化では、高温でシリコンと酸素が反応して二酸化シリコンができます(Si + O2 → SiO2)。ウェット酸化では水蒸気を使い、Si + 2H2O → SiO2 + 2H2 の反応が起こり、生じた水素が膜中に一部残るため、ウェットの膜はやや密度が低くなります。いずれも酸化剤は膜中を拡散して界面で反応し、シリコンを消費しながら膜が成長します。

  • A. 正しい。シリコンと酸素からSiO2ができます。
  • B. 窒素との反応では酸化膜はできません。
  • C. これは酸化膜を還元する逆向きの反応で、酸化ではありません。
