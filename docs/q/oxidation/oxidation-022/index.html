酸化・拡散

ウエハ表面の近くで水素と酸素を反応させ、短時間で良質な薄い酸化膜をつくる方法はどれか。

  1. Aスパッタリング
  2. BISSG(インサイチュ・スチーム・ジェネレーション)酸化
  3. C原子層エッチング
答えと解説を見る

正解：B. ISSG(インサイチュ・スチーム・ジェネレーション)酸化

ISSG酸化では、減圧したチャンバー内で水素と酸素を加熱したウエハの表面近くで反応させます。発生した水蒸気や酸素ラジカルによって、短時間で良質な薄い酸化膜を形成でき、角の部分も丸く酸化しやすいため、STIのライナー酸化膜などに使われます。

酸化・拡散のほかの問題

  1. 薄いゲート酸化膜の表面に、プラズマで生成した窒素を導入する処理を何と呼ぶか。
  2. 同じ希フッ酸でエッチングしたとき、熱酸化膜とCVDで成膜した酸化膜のエッチング速度の一般的な関係として正しいものはどれか。
  3. 熱酸化の際に、酸化によって生じた過剰な格子間シリコンがシリコン中に注入されて成長する欠陥はどれか。
  4. 熱酸化の温度を上げると、同じ時間で得られる酸化膜の厚さはどうなるか。
  5. LOCOS(選択酸化)で、窒化膜マスクの端の下に酸化膜が鳥のくちばし状に食い込む現象を何と呼ぶか。
