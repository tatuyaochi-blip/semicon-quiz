酸化・拡散

シリコン中の熱処理での拡散が比較的遅く、浅い接合をつくりやすいn型不純物はどれか。

  1. Aホウ素(B)
  2. Bリン(P)
  3. Cヒ素(As)
答えと解説を見る

正解：C. ヒ素(As)

n型不純物のうちヒ素は、リンより原子が大きく拡散係数が小さく、質量も75とリン(31)の2倍以上あるためイオン注入でも浅く入ります。また固溶度が高く高濃度にできるため、浅く急峻で低抵抗な接合が求められるnMOSのソース・ドレインやエクステンションに使われてきました。リンは拡散が速いため、深いウェルや、最近はエピタキシャルのSiPとして使われます。ホウ素はp型です。

酸化・拡散のほかの問題

  1. パイロジェニック酸化(水素燃焼酸化)の説明として正しいものはどれか。
  2. 良質な熱酸化膜(SiO2)の絶縁破壊電界の目安として正しいものはどれか。
  3. ウエハ表面の近くで水素と酸素を反応させ、短時間で良質な薄い酸化膜をつくる方法はどれか。
  4. 薄いゲート酸化膜の表面に、プラズマで生成した窒素を導入する処理を何と呼ぶか。
  5. 同じ希フッ酸でエッチングしたとき、熱酸化膜とCVDで成膜した酸化膜のエッチング速度の一般的な関係として正しいものはどれか。
