酸化・拡散

SiO2膜が、ボロンやリンの拡散のマスクには使えるが、ガリウムやアルミニウムに対してはマスクとして働きにくい理由として正しいものはどれか。

  1. ASiO2がガリウムやアルミニウムと反応して導体になるため
  2. BガリウムやアルミニウムはSiO2中の拡散が非常に速いため
  3. Cガリウムやアルミニウムはシリコン中で電気的に不活性なため
答えと解説を見る

正解：B. ガリウムやアルミニウムはSiO2中の拡散が非常に速いため

ボロンやリンはSiO2の中での拡散がシリコン中よりずっと遅いため、酸化膜でさえぎることができます。一方、ガリウムやアルミニウムはSiO2の中を速く拡散してしまうため、酸化膜をマスクにした選択的な拡散には向きません。シリコンのp型不純物としてボロンが主に使われる理由の一つです。

  • A. 反応して導体になるわけではありません。
  • B. 正しい。SiO2中の拡散が速いため、さえぎれません。
  • C. ガリウムやアルミニウムもシリコン中ではアクセプタとして働きます。

酸化・拡散のほかの問題

  1. 不純物濃度が真性キャリア密度より十分高い領域で、ヒ素などの拡散係数が濃度によって変わる現象についての説明として正しいものはどれか。
  2. 不純物を多く含む多結晶シリコン(ポリシリコン)を熱酸化したときの特徴として正しいものはどれか。
  3. シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。
  4. シリコンを熱酸化して厚さxのSiO2膜をつくったとき、消費されるシリコンの厚さはおよそいくらか。
  5. シリコン中の不純物の拡散係数と温度の関係として正しいものはどれか。
