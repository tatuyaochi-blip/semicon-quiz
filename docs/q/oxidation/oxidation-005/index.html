酸化・拡散

熱酸化で酸化膜が十分厚くなったときの、酸化膜厚と酸化時間の関係として正しいものはどれか。

  1. A膜厚は時間の平方根にほぼ比例する(放物線則)
  2. B膜厚は時間の2乗に比例する
  3. C膜厚は時間に関係なく一定である
答えと解説を見る

正解：A. 膜厚は時間の平方根にほぼ比例する(放物線則)

Deal-Groveモデルによると、酸化膜が薄いうちは界面での反応が律速となり膜厚は時間にほぼ比例します(直線則)。膜が厚くなると酸化剤が膜中を拡散する過程が律速となり、膜厚は時間の平方根にほぼ比例します(放物線則)。厚くなるほど成長が遅くなります。

この分野を解く 分野ページへ

酸化・拡散のほかの問題

  1. シリコン上の酸化膜が、膜厚に応じてさまざまな色に見える理由として正しいものはどれか。
  2. 多数のウエハを一度に熱酸化するときに一般的に使われる装置はどれか。
  3. 熱拡散で、表面に一定量の不純物を導入する工程のあとに、不純物をより深く押し込む工程を何と呼ぶか。
  4. シリコンの熱酸化における酸化速度の面方位依存性として正しいものはどれか。
  5. ゲート酸化膜に窒素を導入して酸窒化膜(SiON)にする主な目的はどれか。
