酸化・拡散

良質な熱酸化膜(SiO2)の絶縁破壊電界の目安として正しいものはどれか。

  1. A約10 MV/cm
  2. B約10 V/cm
  3. C約10 kV/cm
答えと解説を見る

正解：A. 約10 MV/cm

良質な熱酸化膜の絶縁破壊電界は約10 MV/cmです。例えば厚さ10 nmの酸化膜なら、約10 Vで破壊する計算になります。実際のデバイスでは、長期の信頼性を確保するため、これよりかなり低い電界で使います。

酸化・拡散のほかの問題

  1. ウエハ表面の近くで水素と酸素を反応させ、短時間で良質な薄い酸化膜をつくる方法はどれか。
  2. 薄いゲート酸化膜の表面に、プラズマで生成した窒素を導入する処理を何と呼ぶか。
  3. 同じ希フッ酸でエッチングしたとき、熱酸化膜とCVDで成膜した酸化膜のエッチング速度の一般的な関係として正しいものはどれか。
  4. 熱酸化の際に、酸化によって生じた過剰な格子間シリコンがシリコン中に注入されて成長する欠陥はどれか。
  5. 熱酸化の温度を上げると、同じ時間で得られる酸化膜の厚さはどうなるか。
