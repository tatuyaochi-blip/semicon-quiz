酸化・拡散

ゲート酸化膜中にナトリウムイオンなどの可動イオンが含まれると起こる問題として正しいものはどれか。

  1. A酸化膜が発光する
  2. B電界や温度によってイオンが移動し、しきい値電圧が変動する
  3. C酸化膜の機械的強度が上がる
答えと解説を見る

正解：B. 電界や温度によってイオンが移動し、しきい値電圧が変動する

ナトリウムなどのアルカリ金属イオンは酸化膜中を動きやすく、電界や温度によって界面付近に移動すると、しきい値電圧を変動させます。MOSデバイスの初期の大きな問題で、クリーンルームでの汚染管理や塩素酸化、リンガラスによる捕獲などで対策されてきました。

酸化・拡散のほかの問題

  1. シリコン中の熱処理での拡散が比較的遅く、浅い接合をつくりやすいn型不純物はどれか。
  2. パイロジェニック酸化(水素燃焼酸化)の説明として正しいものはどれか。
  3. 良質な熱酸化膜(SiO2)の絶縁破壊電界の目安として正しいものはどれか。
  4. ウエハ表面の近くで水素と酸素を反応させ、短時間で良質な薄い酸化膜をつくる方法はどれか。
  5. 薄いゲート酸化膜の表面に、プラズマで生成した窒素を導入する処理を何と呼ぶか。
