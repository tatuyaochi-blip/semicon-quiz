酸化・拡散

ドライ酸化で厚さ数十nm以下の薄い酸化膜をつくるとき、Deal-Groveモデルからずれることとして知られているものはどれか。

  1. A初期の酸化がモデルの予測より速く進む
  2. B酸化がまったく進まない
  3. C酸化膜が導体になる
答えと解説を見る

正解：A. 初期の酸化がモデルの予測より速く進む

Deal-Groveモデルは厚い酸化膜の成長をよく表しますが、ドライ酸化で膜厚が数十nm以下の初期の領域では、実際の酸化がモデルの予測より速く進みます。そのため、薄いゲート酸化膜の厚さを予測するには、この初期の増速を考慮したモデルや実測が必要になります。

  • A. 正しい。初期の薄い領域ではモデルより速く酸化が進みます。
  • B. 酸化は進みます。
  • C. SiO2は絶縁体で、導体にはなりません。

酸化・拡散のほかの問題

  1. LOCOSで、窒化膜マスクの下のシリコン表面に薄い窒化物ができ、後のゲート酸化膜が局所的に薄くなったり不良になったりする現象を何と呼ぶか。
  2. 熱酸化で生じた酸化膜の圧縮応力が、およそ950℃以上の高温の酸化では小さくなる主な理由はどれか。
  3. SiO2膜が、ボロンやリンの拡散のマスクには使えるが、ガリウムやアルミニウムに対してはマスクとして働きにくい理由として正しいものはどれか。
  4. 不純物濃度が真性キャリア密度より十分高い領域で、ヒ素などの拡散係数が濃度によって変わる現象についての説明として正しいものはどれか。
  5. 不純物を多く含む多結晶シリコン(ポリシリコン)を熱酸化したときの特徴として正しいものはどれか。
