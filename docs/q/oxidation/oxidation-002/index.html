酸化・拡散

シリコンを熱酸化して厚さxのSiO2膜をつくったとき、消費されるシリコンの厚さはおよそいくらか。

  1. A約0.44x
  2. B約1.0x
  3. C約2.2x
答えと解説を見る

正解：A. 約0.44x

熱酸化ではシリコン自身が酸素と反応してSiO2になります。シリコンの原子密度(約5.0×10²² cm⁻³)とSiO2の分子密度(約2.3×10²² cm⁻³)の比から、厚さxの酸化膜をつくるのに消費されるシリコンは約0.44xです。酸化膜の約44%は元の表面より下に、56%は上に成長し、体積は約2.2倍に膨らみます。このため酸化した部分は段差になり、界面は常に新しい清浄な面になります。
