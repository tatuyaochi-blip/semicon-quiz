酸化・拡散

微細なLSIの素子分離に主に使われている方法はどれか。

  1. Aワイヤボンディング
  2. BLOCOS(選択酸化)
  3. CSTI(シャロートレンチ分離)
答えと解説を見る

正解：C. STI(シャロートレンチ分離)

現在の微細なLSIでは、シリコンに浅い溝を掘って絶縁膜を埋め込み、CMPで平坦化するSTIが主に使われます。かつて主流だったLOCOSは、酸化膜が横方向にも食い込む「バーズビーク」が生じて素子分離の幅を小さくしにくいため、微細化とともにSTIに置き換えられました。

酸化・拡散のほかの問題

  1. 熱酸化で酸化膜が十分厚くなったときの、酸化膜厚と酸化時間の関係として正しいものはどれか。
  2. シリコン上の酸化膜が、膜厚に応じてさまざまな色に見える理由として正しいものはどれか。
  3. 多数のウエハを一度に熱酸化するときに一般的に使われる装置はどれか。
  4. 熱拡散で、表面に一定量の不純物を導入する工程のあとに、不純物をより深く押し込む工程を何と呼ぶか。
  5. シリコンの熱酸化における酸化速度の面方位依存性として正しいものはどれか。
