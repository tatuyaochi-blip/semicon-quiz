酸化・拡散

LOCOSなどの素子分離に使われたフィールド酸化膜と、MOSFETのゲート酸化膜の厚さの関係として一般的に正しいものはどれか。

  1. Aゲート酸化膜の方がずっと厚い
  2. B両者は同じ厚さである
  3. Cフィールド酸化膜の方がずっと厚い
答えと解説を見る

正解：C. フィールド酸化膜の方がずっと厚い

フィールド酸化膜は、配線の下などで寄生トランジスタがオンしないように、数百nm程度と厚くつくります。一方、ゲート酸化膜はゲートの電界をチャネルに強く伝えるため、数nm程度と非常に薄くします。

  • A. ゲート酸化膜は電界を強く伝えるため薄くします。
  • B. 役割が違うため、厚さは大きく異なります。
  • C. 正しい。素子分離用の酸化膜はずっと厚くつくります。

酸化・拡散のほかの問題

  1. PN接合の「接合深さ」の定義として一般的に正しいものはどれか。
  2. シリコンを酸化している間に、ボロンやリンの拡散が酸化していないときより速くなる現象を何と呼ぶか。
  3. ドライ酸化で厚さ数十nm以下の薄い酸化膜をつくるとき、Deal-Groveモデルからずれることとして知られているものはどれか。
  4. LOCOSで、窒化膜マスクの下のシリコン表面に薄い窒化物ができ、後のゲート酸化膜が局所的に薄くなったり不良になったりする現象を何と呼ぶか。
  5. 熱酸化で生じた酸化膜の圧縮応力が、およそ950℃以上の高温の酸化では小さくなる主な理由はどれか。
