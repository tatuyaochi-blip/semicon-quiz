酸化・拡散

熱酸化で形成したSiO2膜の比誘電率に最も近い値はどれか。

  1. A約1
  2. B約3.9
  3. C約25
答えと解説を見る

正解：B. 約3.9

SiO2の比誘電率は約3.9です。High-k材料の酸化ハフニウムは約20〜25、Low-k材料はおおむね3以下です。誘電率を比べるときの基準として、SiO2の値はよく使われます。

酸化・拡散のほかの問題

  1. シリコンがMOSデバイスの材料として広く使われてきた大きな理由の一つとして正しいものはどれか。
  2. ゲート酸化膜中にナトリウムイオンなどの可動イオンが含まれると起こる問題として正しいものはどれか。
  3. シリコン中の熱処理での拡散が比較的遅く、浅い接合をつくりやすいn型不純物はどれか。
  4. パイロジェニック酸化(水素燃焼酸化)の説明として正しいものはどれか。
  5. 良質な熱酸化膜(SiO2)の絶縁破壊電界の目安として正しいものはどれか。
