酸化・拡散

シリコン中の不純物の拡散係数と温度の関係として正しいものはどれか。

  1. A温度に依存しない
  2. B温度が上がると小さくなる
  3. C温度が上がると指数関数的に大きくなる
答えと解説を見る

正解：C. 温度が上がると指数関数的に大きくなる

拡散係数は D = D0·exp(−Ea/kT) のアレニウス型で表され、活性化エネルギーEaはシリコン中のホウ素やリンで約3.5 eVです。このため温度を100 ℃上げると拡散係数は1桁前後大きくなり、わずかな温度差で拡散の深さが大きく変わります。拡散工程や熱処理では温度を±1 ℃以下の精度で管理し、先端工程では高温にさらす時間を極力短くして浅い接合を保ちます。

  2. 熱酸化で酸化膜が十分厚くなったときの、酸化膜厚と酸化時間の関係として正しいものはどれか。
  3. シリコン上の酸化膜が、膜厚に応じてさまざまな色に見える理由として正しいものはどれか。
  4. 多数のウエハを一度に熱酸化するときに一般的に使われる装置はどれか。
  5. 熱拡散で、表面に一定量の不純物を導入する工程のあとに、不純物をより深く押し込む工程を何と呼ぶか。
