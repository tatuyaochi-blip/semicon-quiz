酸化・拡散

シリコン中の不純物の拡散係数と温度の関係として正しいものはどれか。

  1. A温度に依存しない
  2. B温度が上がると小さくなる
  3. C温度が上がると指数関数的に大きくなる
答えと解説を見る

正解：C. 温度が上がると指数関数的に大きくなる

拡散係数は D = D0 exp(-Ea / kT) というアレニウス型の式で表され、温度が上がると指数関数的に大きくなります。わずかな温度差で拡散の深さが大きく変わるため、拡散工程や熱処理では温度を精密に管理する必要があります。
