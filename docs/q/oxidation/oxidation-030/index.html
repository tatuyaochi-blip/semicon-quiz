酸化・拡散

Deal-Groveモデルによると、熱酸化はどこで進むか。

  1. A酸化膜の最表面で、シリコン原子と酸化剤が反応する
  2. Bシリコン原子が酸化膜の表面まで拡散して反応する
  3. C酸化剤が酸化膜中を拡散し、Si/SiO2界面でシリコンと反応する
答えと解説を見る

正解：C. 酸化剤が酸化膜中を拡散し、Si/SiO2界面でシリコンと反応する

Deal-Groveモデルでは、酸化剤(O2やH2O)が酸化膜の表面に吸着し、酸化膜中を拡散して、シリコンとの界面で反応して新しい酸化膜ができると考えます。酸化膜が厚くなるほど拡散に時間がかかるため、成長は遅くなります。

酸化・拡散のほかの問題

  1. シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。
  2. シリコンを熱酸化して厚さxのSiO2膜をつくったとき、消費されるシリコンの厚さはおよそいくらか。
  3. シリコン中の不純物の拡散係数と温度の関係として正しいものはどれか。
  4. 微細なLSIの素子分離に主に使われている方法はどれか。
  5. 熱酸化で酸化膜が十分厚くなったときの、酸化膜厚と酸化時間の関係として正しいものはどれか。
