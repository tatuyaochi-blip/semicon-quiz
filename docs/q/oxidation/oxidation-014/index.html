酸化・拡散

ボロンを含むシリコンを熱酸化するとき、界面付近のシリコン側のボロン濃度はどうなる傾向があるか。

  1. Aボロンが酸化膜側に取り込まれやすいため、低下する
  2. Bボロンが界面に押し出されるため、上昇する
  3. C変化しない
答えと解説を見る

正解：A. ボロンが酸化膜側に取り込まれやすいため、低下する

不純物はシリコンとSiO2の境界で、両側にどのような濃度比で分かれるかが決まっています(偏析)。ボロンは酸化膜に取り込まれやすいため、シリコン側の表面付近の濃度が下がります。一方、リンやヒ素はシリコン側に押し出され、界面付近の濃度が上がる傾向があります。

酸化・拡散のほかの問題

  1. ランプなどでウエハを1枚ずつ、数秒程度の短時間で高温に加熱する熱処理を何と呼ぶか。
  2. 熱酸化で形成したSiO2膜の比誘電率に最も近い値はどれか。
  3. シリコンがMOSデバイスの材料として広く使われてきた大きな理由の一つとして正しいものはどれか。
  4. ゲート酸化膜中にナトリウムイオンなどの可動イオンが含まれると起こる問題として正しいものはどれか。
  5. シリコン中の熱処理での拡散が比較的遅く、浅い接合をつくりやすいn型不純物はどれか。
