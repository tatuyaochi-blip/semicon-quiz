酸化・拡散

LOCOSで、窒化膜マスクの下のシリコン表面に薄い窒化物ができ、後のゲート酸化膜が局所的に薄くなったり不良になったりする現象を何と呼ぶか。

  1. Aディッシング
  2. Bバーズビーク
  3. Cクーイ効果(ホワイトリボン)
答えと解説を見る

正解：C. クーイ効果(ホワイトリボン)

フィールド酸化中に窒化膜と水蒸気の反応でアンモニアなどができ、窒化膜の端の下のシリコン表面が窒化されることがあります。この窒化物があると、後のゲート酸化でその部分の酸化膜が薄くなり、耐圧不良の原因になります。クーイ効果と呼ばれ、犠牲酸化とその除去で対策します。

  • A. ディッシングはCMPで配線の中央がへこむ現象です。
  • B. バーズビークは、窒化膜の端の下に酸化膜が食い込む現象です。
  • C. 正しい。窒化物によってゲート酸化膜が局所的に不良になる現象です。

酸化・拡散のほかの問題

  1. 熱酸化で生じた酸化膜の圧縮応力が、およそ950℃以上の高温の酸化では小さくなる主な理由はどれか。
  2. SiO2膜が、ボロンやリンの拡散のマスクには使えるが、ガリウムやアルミニウムに対してはマスクとして働きにくい理由として正しいものはどれか。
  3. 不純物濃度が真性キャリア密度より十分高い領域で、ヒ素などの拡散係数が濃度によって変わる現象についての説明として正しいものはどれか。
  4. 不純物を多く含む多結晶シリコン(ポリシリコン)を熱酸化したときの特徴として正しいものはどれか。
  5. シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。
