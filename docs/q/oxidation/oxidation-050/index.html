酸化・拡散

不純物を多く含む多結晶シリコン(ポリシリコン)を熱酸化したときの特徴として正しいものはどれか。

  1. A酸化されない
  2. B粒界や高濃度の不純物の影響で、単結晶より速く酸化されることが多く、酸化膜の質も劣りやすい
  3. C単結晶シリコンと必ず同じ速度で酸化される
答えと解説を見る

正解：B. 粒界や高濃度の不純物の影響で、単結晶より速く酸化されることが多く、酸化膜の質も劣りやすい

ポリシリコンは結晶粒の向きがばらばらで粒界も多く、さらにリンなどを高濃度に含むと単結晶より酸化が速くなります。粒界に沿って酸化が進むため界面が凹凸になりやすく、凸部に電界が集中するため、その上の酸化膜は単結晶の熱酸化膜より耐圧などの質が劣る傾向があります。フラッシュメモリのフローティングゲートの上の絶縁膜では、この問題を避けるためONO膜が使われてきました。

  • A. ポリシリコンも酸化されます。
  • B. 正しい。速く酸化されやすく、膜の質も劣りやすくなります。
  • C. 粒界や不純物の影響で、酸化速度は単結晶と異なります。

酸化・拡散のほかの問題

  1. シリコンの熱酸化について、ドライ酸化(O2)とウェット酸化(H2O)の比較として正しいものはどれか。
  2. シリコンを熱酸化して厚さxのSiO2膜をつくったとき、消費されるシリコンの厚さはおよそいくらか。
  3. シリコン中の不純物の拡散係数と温度の関係として正しいものはどれか。
  4. 微細なLSIの素子分離に主に使われている方法はどれか。
  5. 熱酸化で酸化膜が十分厚くなったときの、酸化膜厚と酸化時間の関係として正しいものはどれか。
