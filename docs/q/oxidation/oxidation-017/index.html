酸化・拡散

シリコンがMOSデバイスの材料として広く使われてきた大きな理由の一つとして正しいものはどれか。

  1. A直接遷移型で効率よく発光するため
  2. B電子移動度がすべての半導体の中で最も高いため
  3. C熱酸化によって、界面準位の少ない良質な絶縁膜(SiO2)を簡単に形成できるため
答えと解説を見る

正解：C. 熱酸化によって、界面準位の少ない良質な絶縁膜(SiO2)を簡単に形成できるため

シリコンは熱酸化するだけで、絶縁性が高く、界面準位が10¹⁰ cm⁻²eV⁻¹程度と非常に少ないSiO2膜を形成できます。GeO2は水に溶け、化合物半導体では良い自然酸化膜ができないことと比べると、この良好なMOS界面はシリコンの大きな強みで、1960年頃にMOSFETが実用化されて以来、LSIの材料として選ばれ続けてきた理由の一つです。地殻に豊富に存在することも利点です。

酸化・拡散のほかの問題

  1. ゲート酸化膜中にナトリウムイオンなどの可動イオンが含まれると起こる問題として正しいものはどれか。
  2. シリコン中の熱処理での拡散が比較的遅く、浅い接合をつくりやすいn型不純物はどれか。
  3. パイロジェニック酸化(水素燃焼酸化)の説明として正しいものはどれか。
  4. 良質な熱酸化膜(SiO2)の絶縁破壊電界の目安として正しいものはどれか。
  5. ウエハ表面の近くで水素と酸素を反応させ、短時間で良質な薄い酸化膜をつくる方法はどれか。
