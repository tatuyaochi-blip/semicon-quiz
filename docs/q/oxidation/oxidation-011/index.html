酸化・拡散

熱酸化膜が、拡散の際の不純物のマスクとして使える理由として正しいものはどれか。

  1. Aホウ素やリンなど多くの不純物が、SiO2中ではシリコン中より拡散しにくいため
  2. BSiO2が電気をよく通すため
  3. CSiO2が光を通さないため
答えと解説を見る

正解：A. ホウ素やリンなど多くの不純物が、SiO2中ではシリコン中より拡散しにくいため

ホウ素、リン、ヒ素などの主要な不純物は、SiO2中での拡散がシリコン中よりずっと遅いため、十分な厚さの酸化膜があれば下のシリコンへの侵入を防げます。この性質を利用して、酸化膜に窓を開けた部分だけに不純物を導入する選択拡散が行われてきました。

酸化・拡散のほかの問題

  1. Si/SiO2界面の界面準位を減らすために行われる、水素を含む雰囲気での熱処理を何と呼ぶか。
  2. 熱酸化の際に、塩化水素(HCl)などの塩素を含むガスを少量加える主な目的はどれか。
  3. ボロンを含むシリコンを熱酸化するとき、界面付近のシリコン側のボロン濃度はどうなる傾向があるか。
  4. ランプなどでウエハを1枚ずつ、数秒程度の短時間で高温に加熱する熱処理を何と呼ぶか。
  5. 熱酸化で形成したSiO2膜の比誘電率に最も近い値はどれか。
