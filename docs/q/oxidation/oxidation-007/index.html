酸化・拡散

多数のウエハを一度に熱酸化するときに一般的に使われる装置はどれか。

  1. A縦型の熱処理炉(拡散炉)
  2. Bイオン注入装置
  3. CCMP装置
答えと解説を見る

正解：A. 縦型の熱処理炉(拡散炉)

熱酸化や拡散、アニールには、石英の反応管にウエハを100枚程度まとめて入れて加熱する縦型の熱処理炉がよく使われます。均一性が高く、一度に多くのウエハを処理できます。短時間で加熱したい場合は、ランプで1枚ずつ加熱するRTP装置が使われます。

酸化・拡散のほかの問題

  1. 熱拡散で、表面に一定量の不純物を導入する工程のあとに、不純物をより深く押し込む工程を何と呼ぶか。
  2. シリコンの熱酸化における酸化速度の面方位依存性として正しいものはどれか。
  3. ゲート酸化膜に窒素を導入して酸窒化膜(SiON)にする主な目的はどれか。
  4. 熱酸化膜が、拡散の際の不純物のマスクとして使える理由として正しいものはどれか。
  5. Si/SiO2界面の界面準位を減らすために行われる、水素を含む雰囲気での熱処理を何と呼ぶか。
