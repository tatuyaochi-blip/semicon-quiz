酸化・拡散

シリコンの熱酸化における酸化速度の面方位依存性として正しいものはどれか。

  1. A(100)面の方が(111)面より酸化速度が速い
  2. B面方位によらず酸化速度は同じである
  3. C(111)面の方が(100)面より酸化速度が速い
答えと解説を見る

正解：C. (111)面の方が(100)面より酸化速度が速い

同じ条件では、(111)面の方が(100)面より酸化速度が速くなります。表面の原子密度が高く、酸化反応に使える結合が多いためです。FinFETのように側面と上面で面方位が異なる構造では、この違いを考慮する必要があります。

  2. 熱酸化膜が、拡散の際の不純物のマスクとして使える理由として正しいものはどれか。

  4. 熱酸化の際に、塩化水素(HCl)などの塩素を含むガスを少量加える主な目的はどれか。
  5. ボロンを含むシリコンを熱酸化するとき、界面付近のシリコン側のボロン濃度はどうなる傾向があるか。
