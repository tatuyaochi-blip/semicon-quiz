酸化・拡散

薄いゲート酸化膜の表面に、プラズマで生成した窒素を導入する処理を何と呼ぶか。

  1. Aドライブイン
  2. BCMP
  3. Cプラズマ窒化
答えと解説を見る

正解：C. プラズマ窒化

プラズマ窒化では、窒素のプラズマでつくった活性な窒素を酸化膜の表面付近に導入し、酸窒化膜(SiON)にします。熱による窒化より低温で、窒素を表面付近に集中させられるため、界面の特性を損なわずにホウ素の突き抜けを抑え、誘電率も高められます。

酸化・拡散のほかの問題

  1. 同じ希フッ酸でエッチングしたとき、熱酸化膜とCVDで成膜した酸化膜のエッチング速度の一般的な関係として正しいものはどれか。
  2. 熱酸化の際に、酸化によって生じた過剰な格子間シリコンがシリコン中に注入されて成長する欠陥はどれか。
  3. 熱酸化の温度を上げると、同じ時間で得られる酸化膜の厚さはどうなるか。
  4. LOCOS(選択酸化)で、窒化膜マスクの端の下に酸化膜が鳥のくちばし状に食い込む現象を何と呼ぶか。
  5. 高い圧力の酸化雰囲気で熱酸化を行う利点として正しいものはどれか。
