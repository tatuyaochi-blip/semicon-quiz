情報セキュリティの基礎

ソーシャルエンジニアリングの例として当てはまるものはどれか。

  1. Aシステムの管理者を名乗って電話をかけ、「障害の対応のため」と言って社員からパスワードを聞き出す
  2. BWebアプリケーションの入力欄に特殊な文字列を入力して、データベースを不正に操作する
  3. Cパスワードの候補をプログラムで次々に試して、ログインできるものを探す
答えと解説を見る

正解：A. システムの管理者を名乗って電話をかけ、「障害の対応のため」と言って社員からパスワードを聞き出す

ソーシャルエンジニアリングは、技術的な手段ではなく、人の心理や習慣、不注意につけ込んで、パスワードなどの重要な情報を聞き出したり、操作をさせたりする手口の総称です。管理者や取引先、上司を名乗る電話やメール、肩越しに画面やキーの入力をのぞき見る(ショルダーハッキング)、捨てられた書類をあさる(トラッシング)などがあります。「急いで」「緊急」「内密に」のように、考える時間を与えない言い方が使われることが多いのが特徴です。対策として、電話やメールでパスワードを教えないという決まりを作って周知し、相手の身元を、知らされた連絡先ではなく、もともと知っている連絡先に問い合わせて確かめます。フィッシングも、人をだますという点でソーシャルエンジニアリングの一種です。入力欄に特殊な文字列を入れるのはSQLインジェクションのような技術的な攻撃、候補を次々に試すのは総当たり攻撃です。

  • A. 正しい。人をだまして情報を聞き出すのが、ソーシャルエンジニアリングです。
  • B. 入力欄から特殊な文字列でデータベースを操作するのは、SQLインジェクションのような技術的な攻撃です。
  • C. パスワードの候補をプログラムで試すのは、総当たり攻撃(ブルートフォース攻撃)で、技術的な手段による攻撃です。

情報セキュリティの基礎のほかの問題

  1. 取引先の担当者を名乗るメールで「振込先の口座が変わったので、今回の請求からはこちらに支払ってほしい」と依頼された。ビジネスメール詐欺(BEC)を疑うときの対応として最も適切なものはどれか。
  2. ログインの画面で、パスワードの欄に ' OR '1'='1 のような文字列を入力されると、パスワードを知らなくてもログインできてしまうWebアプリケーションがある。この攻撃の名前はどれか。
  3. SQLインジェクションへの対策として、プレースホルダを使うプリペアドステートメント(パラメータ化クエリ)が、入力の中の危険な文字を取り除く方法より根本的な対策とされる理由として正しいものはどれか。
  4. 掲示板のWebアプリケーションで、利用者が投稿した文章の中のスクリプトが、ほかの閲覧者のブラウザで実行されてしまう脆弱性があった。この脆弱性の名前と、根本的な対策の組み合わせとして正しいものはどれか。
  5. Webアプリケーションで、ログインしたままの利用者が攻撃者の用意した罠のページを開くと、利用者のブラウザから正規のサイトへ、利用者の意図しない送金や設定の変更のリクエストが送られてしまう脆弱性がある。この脆弱性への対策として適切なものはどれか。

この分野の比較

  • ファイアウォール・IDS・IPS・WAFの違い：調べる範囲・止めるか知らせるか・守る対象を比較ファイアウォール・IDS(侵入検知システム)・IPS(侵入防止システム)・WAFを、調べる範囲(層)・通信の経路への置き方・見つけたときの動き・判定の方法・守る対象・誤検知の影響・置く場所・限界の観点で表にして比較しま…
  • 境界型防御とゼロトラストの違い：信頼の前提・認証の頻度・リモートアクセスを比較境界型防御とゼロトラストを、信頼の前提・防御を置く場所・認証と認可の頻度・リモートアクセス(VPNとZTNA)・侵入後の横への広がり・可視化と記録・クラウドとの相性・移行の難しさの観点で表にして比較します。
