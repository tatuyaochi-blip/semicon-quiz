情報セキュリティの基礎

ある顔認証の装置では、しきい値をA・B・Cの3通りに設定でき、それぞれの他人受入率(FAR)と本人拒否率(FRR)は、Aが1%と0.5%、Bが0.1%と2%、Cが0.01%と8%である。研究室の入室の管理で「FARを0.1%以下にする」ことを条件とし、そのうえで正規の利用者ができるだけ拒否されないようにしたい。選ぶべきしきい値はどれか。

  1. Aしきい値A
  2. Bしきい値B
  3. Cしきい値C
答えと解説を見る

正解：B. しきい値B

まず条件を満たすものを選びます。FARが0.1%以下なのはB(0.1%)とC(0.01%)で、A(1%)は他人が100回に1回受け入れられてしまうので条件を満たしません。次に、条件を満たすBとCのうち、正規の利用者が拒否されにくいのはFRRが低いほうで、Bの2%はCの8%より低いので、Bを選びます。Cは他人をより確実に拒否できますが、本人が100回のうち約8回拒否され、使い勝手が悪くなります。しきい値をAからCへと厳しくするにつれて、FARが下がりFRRが上がっていることも確かめられます。セキュリティの要求を条件として先に満たし、そのうえで利便性を最大にする、というのが、しきい値の決め方の基本です。

  • A. AはFARが1%で、条件の0.1%以下を満たしません。
  • B. 正しい。FARの条件を満たすBとCのうち、FRRが低い(2%)のはBです。
  • C. CもFARの条件は満たしますが、FRRが8%と高く、正規の利用者が拒否されやすくなります。
