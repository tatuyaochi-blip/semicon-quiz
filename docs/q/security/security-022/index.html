情報セキュリティの基礎

シングルサインオン(SSO)の説明として正しいものはどれか。

  1. A1回の認証で、連携している複数のサービスを改めてログインせずに使えるようにする仕組みで、利便性が上がる一方、その認証が破られると多くのサービスに影響するので、多要素認証と組み合わせることが望ましい
  2. Bすべてのサービスで同じパスワードを使い回すことをいい、安全性を高めるために推奨されている
  3. C1つのサービスには同時に1人しかログインできないようにする仕組みである
答えと解説を見る

正解：A. 1回の認証で、連携している複数のサービスを改めてログインせずに使えるようにする仕組みで、利便性が上がる一方、その認証が破られると多くのサービスに影響するので、多要素認証と組み合わせることが望ましい

シングルサインオン(SSO)では、利用者が認証を行う仕組み(IdP、IDプロバイダ)に一度ログインすると、その結果が連携する各サービスに安全な形で伝えられ、サービスごとにログインし直さずに使えます。代表的な方式に、SAMLやOpenID Connectがあります。各サービスにパスワードを渡さないので、管理するパスワードが減り、退職者のアカウントを1か所で止められるなど管理の面でも利点があります。ただし、IdPのアカウントが乗っ取られると連携するすべてのサービスに入られてしまうため、IdPでの多要素認証が特に重要です。パスワードの使い回しは、1つのサービスから漏れたパスワードでほかのサービスにも入られる(パスワードリスト攻撃)原因になるもので、SSOとは別のものです。

  • A. 正しい。1回の認証で複数のサービスを使えますが、認証が破られたときの影響が大きいので多要素認証と組み合わせます。
  • B. パスワードの使い回しは、1か所で漏れるとほかのサービスにも入られる危険な使い方で、SSOとは別のものです。
  • C. 同時にログインできる人数を制限する仕組みは、SSOとは関係がありません。
