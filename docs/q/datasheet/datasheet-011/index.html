データシートの読み方

データシートで入力端子が「5 Vトレラント」とされている意味として正しいものはどれか。

  1. A電源電圧を5 Vにしても3.3 Vにしても、同じ性能で動作することが保証されている
  2. Bその端子から、5 VのHレベルの信号を出力することができる
  3. C電源電圧が3.3 Vなどで動作していても、その入力に5 Vの信号を加えてよい
答えと解説を見る

正解：C. 電源電圧が3.3 Vなどで動作していても、その入力に5 Vの信号を加えてよい

通常のCMOS入力には、電源(VDD)側へ向かう静電気保護用のダイオードがあり、入力がVDD + 0.3 V程度を超えるとダイオードが導通して電流が流れ込みます。5 Vトレラントの入力は、この経路をもたない構造にして、電源3.3 Vのときに5 Vを加えても壊れず、電流も流れ込まないようにしたものです。入力を許容するだけで、出力が5 Vになるわけではありません。電源が切れているときにも5 Vを加えてよいかは、別の記載を確認します。
