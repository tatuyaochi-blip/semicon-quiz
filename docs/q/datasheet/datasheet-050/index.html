データシートの読み方

横軸が対数目盛のグラフで、10と100の目盛のちょうど中間の位置が表す値に最も近いものはどれか。

  1. A50
  2. B55
  3. C約32
答えと解説を見る

正解：C. 約32

対数目盛では、位置が値の対数に比例します。log₁₀10 = 1 と log₁₀100 = 2 の中間は1.5なので、値は10の1.5乗、つまり √1000 ≈ 31.6 です。同じように、1桁(1ディケード)の幅のうち2は約30%、5は約70%の位置にあります。データシートの周波数特性やSOAのグラフは対数軸のものが多く、目盛の間隔が均等でないので、線形の感覚で読むと大きく読み違えます。55は10と100の算術平均で、線形目盛での中間の値です。

データシートの読み方のほかの問題

  1. データシートの「絶対最大定格」と「推奨動作条件」の違いとして正しいものはどれか。
  2. 試作中の基板で、電源電圧が絶対最大定格を一瞬だけ超えるサージが見つかった。ICはその後も正常に動いている。考え方として適切なものはどれか。
  3. 部品の「ディレーティング」の考え方として適切なものはどれか。
  4. 電気的特性表の「typ(標準値)」の説明として正しいものはどれか。
  5. 電流制限値が min 1.0 A、typ 1.5 A、max 2.2 A と規定されたロードスイッチ(電源の入り切りをするIC)で、負荷に最大1.2 Aを流したい。正しい判断はどれか。
