データシートの読み方

データシートの「絶対最大定格」と「推奨動作条件」の違いとして正しいものはどれか。

  1. A絶対最大定格の範囲内であれば壊れないうえ、電気的特性表に書かれた値もすべてそのまま保証される
  2. B絶対最大定格は超えると壊れるおそれのある限界値で、特性が保証されるのは推奨動作条件の範囲内である
  3. C推奨動作条件は連続して動作させるときの上限で、絶対最大定格は短時間であれば常用してよい上限である
答えと解説を見る

正解：B. 絶対最大定格は超えると壊れるおそれのある限界値で、特性が保証されるのは推奨動作条件の範囲内である

絶対最大定格は、一瞬でも超えると破壊や劣化のおそれがある限界の値で、この範囲内なら壊れないというだけで、正しく動くことは保証していません。電気的特性表の値が保証されるのは推奨動作条件の範囲内です。例えば3.3 V品で、電源電圧の絶対最大定格が −0.3〜4.6 V、推奨動作条件が 3.0〜3.6 V のように規定されます。設計では推奨動作条件の中で使い、絶対最大定格はノイズやサージを含めても超えないことを確認します。

データシートの読み方のほかの問題

  1. 試作中の基板で、電源電圧が絶対最大定格を一瞬だけ超えるサージが見つかった。ICはその後も正常に動いている。考え方として適切なものはどれか。
  2. 部品の「ディレーティング」の考え方として適切なものはどれか。
  3. 電気的特性表の「typ(標準値)」の説明として正しいものはどれか。
  4. 電流制限値が min 1.0 A、typ 1.5 A、max 2.2 A と規定されたロードスイッチ(電源の入り切りをするIC)で、負荷に最大1.2 Aを流したい。正しい判断はどれか。
  5. 電気的特性表の冒頭に「特記なき限り Ta = 25 ℃、VDD = 3.3 V」と書かれている。この表を読むときの注意として正しいものはどれか。
