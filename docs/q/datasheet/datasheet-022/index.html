データシートの読み方

ロジックICのデータシートにある伝搬遅延 tPLH の一般的な定義として正しいものはどれか。

  1. A出力がLからHに変わるとき、振幅の10%から90%まで変化するのにかかる時間
  2. B入力がLからHに変わってから、出力が完全に安定する100%の点に達するまでの時間
  3. C入力の変化から出力がLからHに変わるまでの時間で、振幅の50%の点どうしで測る
答えと解説を見る

正解：C. 入力の変化から出力がLからHに変わるまでの時間で、振幅の50%の点どうしで測る

tPLHは出力がLからHへ変わる場合の伝搬遅延、tPHLはHからLへ変わる場合の伝搬遅延で、両者は一般に同じ値ではありません。測定の基準点は、多くの場合入力と出力それぞれの振幅の50%(VDD/2)で、TTL系では1.5 Vを使うこともあります。振幅の10%から90%まで変化する時間は立ち上がり時間で、伝搬遅延とは別の項目です。遅延は負荷容量や電源電圧、温度で変わるので、表の測定条件とあわせて読みます。

データシートの読み方のほかの問題

  1. ロジックICの推奨動作条件に、入力の立ち上がり・立ち下がりの遅さの上限(例えば 10 ns/V)が規定されている主な理由はどれか。
  2. タイミング図で、アドレスやデータのバスを上下2本の平行線で描き、ところどころで×の形に交差させる表記の意味として正しいものはどれか。
  3. データシートに記載された θJA(接合〜周囲の熱抵抗)を、実際の機器の熱設計に使うときの注意として正しいものはどれか。
  4. 最大接合温度 Tj(max) = 125 ℃、θJA = 50 ℃/W のICを、周囲温度 Ta = 85 ℃ で使うとき、許される消費電力の上限はいくらか。
  5. ヒートシンクを取り付けて使うパワーデバイスの接合温度を見積もるとき、接合から周囲までの熱抵抗として使う組み合わせはどれか。
