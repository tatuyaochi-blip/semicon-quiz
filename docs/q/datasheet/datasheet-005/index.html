データシートの読み方

電流制限値が min 1.0 A、typ 1.5 A、max 2.2 A と規定されたロードスイッチ(電源の入り切りをするIC)で、負荷に最大1.2 Aを流したい。正しい判断はどれか。

  1. Atyp値が1.5 Aなので0.3 Aの余裕があり、問題なく流せる
  2. Bmax値の2.2 Aに対して約半分の電流なので、十分な余裕をもって問題なく流せる
  3. C製品によっては1.0 A付近で電流制限がかかるので、1.2 Aを流せる保証はない
答えと解説を見る

正解：C. 製品によっては1.0 A付近で電流制限がかかるので、1.2 Aを流せる保証はない

電流制限値は製品ごとに1.0〜2.2 Aの範囲でばらつき、1.0 Aに近い製品に当たると、1.2 Aを流そうとした時点で制限がかかって出力電圧が下がります。必要な電流を必ず流すには、制限値のmin(1.0 A)が負荷電流より大きい製品を選ぶ必要があります。反対に、故障時に流れうる電流を見積もるときにはmax値の2.2 Aを使います。typ値で判断すると、試作では動いても量産で一部が動かないという問題が起こります。

データシートの読み方のほかの問題

  1. 電気的特性表の冒頭に「特記なき限り Ta = 25 ℃、VDD = 3.3 V」と書かれている。この表を読むときの注意として正しいものはどれか。
  2. 電気的特性表の脚注に「設計および特性評価により保証。出荷試験は行っていない」と書かれた項目の意味として正しいものはどれか。
  3. 入力のしきい値が VIH(min) = 2.0 V、VIL(max) = 0.8 V と規定されたICの入力端子に、1.4 Vの電圧を加えた。どう判定されるか。
  4. 出力側のICが VOH(min) = 2.9 V、VOL(max) = 0.4 V、入力側のICが VIH(min) = 2.0 V、VIL(max) = 0.8 V のとき、Lレベルのノイズマージンはいくらか。
  5. 3.3 V電源のICの出力を、5 V電源で動くCMOS入力(VIH(min) = 0.7 × VDD)に直接つなぐときの問題として正しいものはどれか。
