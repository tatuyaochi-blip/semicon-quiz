データシートの読み方

データシートの「代表特性(Typical Characteristics)」のグラフの扱いとして正しいものはどれか。

  1. A代表的なサンプルの傾向を示すもので保証値ではなく、設計では表のmin/maxを基準にする
  2. B表に書かれていない条件の値も、グラフから読み取った値であればそのまま保証値として使える
  3. Cシミュレーションによる計算結果を示したものなので、実際の製品の測定値とは関係がない
答えと解説を見る

正解：A. 代表的なサンプルの傾向を示すもので保証値ではなく、設計では表のmin/maxを基準にする

代表特性のグラフは、温度、電源電圧、負荷、周波数などを変えたときに特性がどう変わるかを、代表的なサンプルで測って示したものです。多くのグラフには「typ」や「代表値」と注記があり、ばらつきの範囲は示されていません。設計の基準は表のmin/maxとし、グラフは条件による変化の傾向を知ったり、表にない条件での値の見当をつけたりするのに使います。例えば25 ℃のmax値を、グラフから読んだ温度による変化の割合で高温側に補正して見積もる、といった使い方です。
