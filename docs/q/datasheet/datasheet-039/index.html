データシートの読み方

PSRR(電源電圧変動除去比)が1 kHzで60 dBのLDOの入力に、1 kHz・振幅100 mVのリップルが乗っている。出力に現れるリップルの目安はどれか。

  1. A0.1 µV
  2. B約1.7 mV
  3. C0.1 mV
答えと解説を見る

正解：C. 0.1 mV

電圧の比をデシベルで表すときは 20 log₁₀ を使うので、60 dBは1/1000です。100 mV ÷ 1000 = 0.1 mV が出力に現れます。0.1 µVは10 log₁₀(電力比)として計算した誤り、約1.7 mVは100を60で割った誤りです。PSRRは周波数が高くなると低下するのが一般的で、1 kHzで60 dBあっても数百kHzでは20〜30 dB程度まで下がる製品もあります。スイッチングレギュレータの後段にLDOを置くときは、そのスイッチング周波数でのPSRRをグラフで確認します。

データシートの読み方のほかの問題

  1. ADコンバータのデータシートにある「ミッシングコードなし(no missing codes)」の保証と、最も関係が深い条件はどれか。
  2. 16ビットのADコンバータで、SINAD(信号対雑音・ひずみ比)が74 dBと規定されている。有効ビット数(ENOB)はおよそいくらか。
  3. QFPやSOPなどのパッケージで、ピン番号の一般的な付け方として正しいものはどれか。
  4. QFNパッケージの裏面にある大きな露出パッド(エクスポーズドパッド)の一般的な扱いとして正しいものはどれか。
  5. データシートに「ESD耐性:HBM ±2 kV、CDM ±500 V」とある。この値の解釈として正しいものはどれか。
