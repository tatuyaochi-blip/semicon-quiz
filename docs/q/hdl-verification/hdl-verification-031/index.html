ハードウェア記述言語と検証

HDLでZ(ハイインピーダンス)を出力するトライステートの記述について、一般的に正しいものはどれか。

  1. Aチップの内部の信号は、すべてトライステートで作るのが普通である
  2. Bチップの外とつながる双方向の端子などに使い、チップの内部の信号ではマルチプレクサを使うのが普通である
  3. CZは0と同じ意味なので、どこで使っても同じである
答えと解説を見る

正解：B. チップの外とつながる双方向の端子などに使い、チップの内部の信号ではマルチプレクサを使うのが普通である

トライステートは、出力を切り離して複数の回路で1本の線を共有するための仕組みで、外部のバスやメモリのデータ線のような双方向の端子で使われます。チップの内部で使うと、同時に2つが駆動して衝突する危険や、誰も駆動せずに浮いてしまう危険があり、タイミングの解析も難しくなります。そのため内部では、マルチプレクサで信号を選ぶ記述にするのが一般的です。

  • A. 内部ではマルチプレクサで選ぶのが一般的です。
  • B. 正しい。内部のトライステートはタイミングや検証を難しくします。
  • C. Zはどこからも駆動されていない状態で、0とは違います。

ハードウェア記述言語と検証のほかの問題

  1. HDLの検証で使うテストベンチの説明として正しいものはどれか。
  2. テストベンチの上の記述で作られるクロックの周期はいくらか(時間の単位は1 nsとする)。
  3. テストベンチで、回路への入力をクロックの立ち上がりと同じ時刻にブロッキング代入で変えると、問題が起きることがある。主な理由と対策の組み合わせとして正しいものはどれか。
  4. 自己チェック型のテストベンチの特徴として正しいものはどれか。
  5. 検証で、C言語などで書いた参照モデル(ゴールデンモデル)を使う目的として正しいものはどれか。

この分野の比較

  • VerilogとVHDLの違い：2つのハードウェア記述言語を比較VerilogとVHDLを、成り立ち・文法・型・大文字小文字・検証機能・使われる分野・選び方の観点で表にして比較します。
  • ブロッキング代入とノンブロッキング代入の違い：評価のタイミング・順序・使う場所を比較Verilogのブロッキング代入(=)とノンブロッキング代入(<=)を、左辺を更新するタイミング・記述の順序への依存・使う場所(組み合わせ回路と順序回路)・シミュレーションと合成の不一致の観点で表にして比較します。
  • 同期リセットと非同期リセットの違い：タイミング・クロック・解除の注意を比較同期リセットと非同期リセットを、効くタイミング・クロックが必要か・グリッチへの強さ・タイミング解析・リセット解除時の同期化・面積・Verilogの書き方の観点で表にして比較し、それぞれが向く回路も説明します。
