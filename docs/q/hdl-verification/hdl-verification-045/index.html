ハードウェア記述言語と検証

HDLの検証で使われるLintツールの役割として正しいものはどれか。

  1. A回路のゴミ(糸くず)をチップから取り除く装置
  2. Bシミュレーションの波形を美しく表示する道具
  3. Cシミュレーションをせずに記述を調べ、ビット幅の不一致や意図しないラッチ、合成できない書き方などの問題を見つける
答えと解説を見る

正解：C. シミュレーションをせずに記述を調べ、ビット幅の不一致や意図しないラッチ、合成できない書き方などの問題を見つける

Lintツールは、HDLの記述を規則に照らして静的に調べ、文法上は正しくても問題になりやすい書き方を指摘します。例えば、幅の違う信号の代入、センシティビティリストの書き漏れ、ラッチの推論、ブロッキングとノンブロッキングの混在、クロックの扱いの誤りなどです。テストを作らなくても実行できるので、設計の早い段階から使うと、後の検証の手間を減らせます。

  • A. 物理的な清掃の装置ではありません。
  • B. 波形の表示の道具ではありません。
  • C. 正しい。早い段階で手軽に誤りを見つけられます。

ハードウェア記述言語と検証のほかの問題

  2. 上の記述のように、フリップフロップを通らずに組み合わせ回路の出力が自分の入力に戻ってくる形を何と呼び、なぜ避けるべきか。
  3. 上の記述をFPGA向けに論理合成すると、一般にどう扱われるか。
