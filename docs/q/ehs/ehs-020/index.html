環境安全

企業の温室効果ガス排出量の算定で、自社の工場での燃料の燃焼や、プロセスガスの排出などの直接排出が分類される区分はどれか。

  1. Aスコープ2
  2. Bスコープ3
  3. Cスコープ1
答えと解説を見る

正解：C. スコープ1

温室効果ガスの排出量は、自社による直接排出(スコープ1)、購入した電力などのエネルギー使用に伴う間接排出(スコープ2)、原材料の調達や製品の使用などサプライチェーン全体での排出(スコープ3)に分けて算定されます。半導体工場では、燃料の燃焼に加え、PFCやNF3などのプロセスガスの排出がスコープ1に含まれ、除害装置の分解効率がその量を左右します。

環境安全のほかの問題

  1. 毒性ガスの漏えい警報が鳴ったときの基本的な行動として正しいものはどれか。
  2. 化学物質を使う作業について、危険性や有害性を特定し、そのリスクの大きさを見積もって対策を決める取り組みを何と呼ぶか。
  3. 有機溶剤を扱う作業で、容器や配管を接地(アース)する主な目的はどれか。
  4. 廃棄物を減らすための考え方「3R」の組み合わせとして正しいものはどれか。
  5. CVD装置のチャンバークリーニングで、PFCの排出削減の観点から採用されてきた方法として正しいものはどれか。
