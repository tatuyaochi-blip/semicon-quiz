環境安全

エッチングや装置のクリーニングに使われるPFC(パーフルオロカーボン)類の排出が環境上問題とされる主な理由はどれか。

  1. A水質汚濁の主な原因物質であるため
  2. B酸性雨の主な原因物質であるため
  3. C地球温暖化係数が大きく、大気中での寿命が長い温室効果ガスであるため
答えと解説を見る

正解：C. 地球温暖化係数が大きく、大気中での寿命が長い温室効果ガスであるため

CF4やC2F6などのPFC類は、CO2の数千倍以上の地球温暖化係数をもち、大気中に非常に長く残る温室効果ガスです。半導体業界では、除害装置による分解、代替ガスへの切り替え、使用量の最適化などで排出削減に取り組んでいます。

この分野を解く 分野ページへ

環境安全のほかの問題

  1. 毒性や可燃性をもつ特殊材料ガスのボンベの一般的な取り扱いとして正しいものはどれか。
  2. フッ酸を含む排水の代表的な処理方法はどれか。
  3. 薬液を扱う装置などで、発生したガスやミストを発生源の近くで吸い込んで排出する設備はどれか。
  4. 酸やアルカリの薬液を扱う作業で着用すべき保護具の組み合わせとして適切なものはどれか。
  5. 化学品の危険有害性を、ドクロや炎などの絵表示と注意書きによって国際的に統一して示す仕組みはどれか。
