環境安全

酸やアルカリの薬液を扱う作業で着用すべき保護具の組み合わせとして適切なものはどれか。

  1. A軍手と普通の眼鏡
  2. B耐薬品性の手袋、保護めがね(フェイスシールド)、耐薬品性のエプロン
  3. C防じんマスクだけ
答えと解説を見る

正解：B. 耐薬品性の手袋、保護めがね(フェイスシールド)、耐薬品性のエプロン

薬液が皮膚や目に付くと重い化学熱傷を負うおそれがあるため、薬液に適した耐薬品性の手袋、目と顔を守る保護めがねやフェイスシールド、体を覆うエプロンなどを着用します。軍手は薬液を吸い込むため危険です。万一に備えて、緊急シャワーや洗眼器の場所も確認しておきます。

  2. 電気電子機器に含まれる鉛や水銀などの特定有害物質の使用を制限するEUの規制はどれか。
  3. 半導体工場で、大量に使う水について行われている環境面の取り組みとして適切なものはどれか。
  4. 目に薬液が入ったときの応急措置として適切なものはどれか。
  5. 可燃性ガスの爆発下限界(LEL)の意味として正しいものはどれか。
