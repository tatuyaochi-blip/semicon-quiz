環境安全

製品の原材料の調達から製造、使用、廃棄までの全体で、環境への負荷を評価する手法はどれか。

  1. AFMEA
  2. BSPC
  3. Cライフサイクルアセスメント(LCA)
答えと解説を見る

正解：C. ライフサイクルアセスメント(LCA)

ライフサイクルアセスメント(LCA)は、製品の一生を通じたエネルギーや資源の使用量、温室効果ガスの排出量などを定量的に評価する手法です。半導体では、製造時の電力やプロセスガスに加えて、製品の使用時の消費電力も考慮されます。

  3. けがには至らなかったものの、ひやりとしたり、はっとしたりした出来事を報告し合う活動の目的として正しいものはどれか。
  4. 職場の安全や品質の基本として広く行われている「5S」の組み合わせとして正しいものはどれか。
  5. 地震が多い地域の半導体工場で、大きな揺れを感知したときに自動的に行われる安全対策として一般的なものはどれか。
