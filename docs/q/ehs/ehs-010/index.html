環境安全

半導体工場で、大量に使う水について行われている環境面の取り組みとして適切なものはどれか。

  1. A使用した水は処理せずにすべて海へ放流する
  2. B排水を処理・回収して、超純水の原水などに再利用する
  3. C水の使用量を記録しない
答えと解説を見る

正解：B. 排水を処理・回収して、超純水の原水などに再利用する

半導体工場はウエハの洗浄に大量の超純水を使うため、水資源の節約が重要な課題です。比較的きれいな排水を回収・処理して超純水の原水や冷却水などに再利用し、回収率を高める取り組みが進められています。放流する排水は、法令の基準を満たすよう処理します。

環境安全のほかの問題

  1. 目に薬液が入ったときの応急措置として適切なものはどれか。
  2. 可燃性ガスの爆発下限界(LEL)の意味として正しいものはどれか。
  3. 排ガス中の酸性ガスなどを、水や薬液と接触させて吸収・除去する装置はどれか。
  4. 環境マネジメントシステムに関する国際規格はどれか。
  5. 半導体工場のエネルギー消費で大きな割合を占める設備として正しいものはどれか。
