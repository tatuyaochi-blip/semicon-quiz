環境安全

CF4などの非常に安定で分解しにくいPFCを、装置の排ガスから取り除くために用いられる除害方式として適切なものはどれか。

  1. A水で洗うだけの湿式スクラバー
  2. B活性炭への吸着だけ
  3. C燃焼式やプラズマ式など、高温で分解する方式
答えと解説を見る

正解：C. 燃焼式やプラズマ式など、高温で分解する方式

CF4などのPFCは化学的に非常に安定で、水にもほとんど溶けないため、湿式スクラバーや一般的な吸着ではほとんど除去できません。燃焼式や電気ヒーター式、プラズマ式などで1000 ℃前後以上の高温にして分解し、生成したフッ化水素などを後段の湿式スクラバーで取り除きます。

  • A. PFCは水にほとんど溶けないため、水洗いだけでは除去できません。
  • B. 安定なPFCは吸着だけでは十分に除去できません。
  • C. 正しい。高温で分解し、生成物を後段で処理します。

  2. フッ化水素酸(フッ酸)の取り扱いに関する説明として正しいものはどれか。
  3. SDS(安全データシート)の説明として正しいものはどれか。
  4. エッチングや装置のクリーニングに使われるPFC(パーフルオロカーボン)類の排出が環境上問題とされる主な理由はどれか。
  5. 毒性や可燃性をもつ特殊材料ガスのボンベの一般的な取り扱いとして正しいものはどれか。
