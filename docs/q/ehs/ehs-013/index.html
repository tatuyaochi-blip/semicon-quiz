環境安全

排ガス中の酸性ガスなどを、水や薬液と接触させて吸収・除去する装置はどれか。

  1. AULPAフィルタ
  2. BOHT
  3. C湿式スクラバー
答えと解説を見る

正解：C. 湿式スクラバー

湿式スクラバーは、排ガスを水や中和用の薬液のシャワーなどと接触させ、水に溶けやすい酸性ガスやアルカリ性ガスを吸収して取り除く装置です。工場全体の排気処理や、装置ごとの除害装置の後段などで使われます。

環境安全のほかの問題

  1. 環境マネジメントシステムに関する国際規格はどれか。
  2. 半導体工場のエネルギー消費で大きな割合を占める設備として正しいものはどれか。
  3. 薬液の保管で、互いに混ざると激しく反応するおそれのある物質を離して保管する理由として正しいものはどれか。
  4. 有害な化学物質を扱う作業場で、空気中の有害物質の濃度などを定期的に測って作業環境を評価することを何と呼ぶか。
  5. 半導体工場で発生する廃液を、酸・アルカリ・フッ素系・有機溶剤などに分けて回収する主な理由はどれか。
