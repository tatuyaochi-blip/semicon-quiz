環境安全

有機溶剤を扱う作業で、容器や配管を接地(アース)する主な目的はどれか。

  1. A溶剤を冷却するため
  2. B静電気の放電による引火を防ぐため
  3. C溶剤の色を保つため
答えと解説を見る

正解：B. 静電気の放電による引火を防ぐため

有機溶剤を移し替えたり配管で流したりすると、摩擦で静電気が発生します。溶剤の多くは電気を通しにくいため電荷が逃げにくく、たまって放電すると、その火花で溶剤の蒸気に引火するおそれがあります。容器や配管、人を接地(アース)して電荷を大地へ逃がすことで、これを防ぎます。流す速さを抑えることも静電気の発生を減らします。冷却や色の保持が目的ではありません。
