環境安全

フッ化水素酸(フッ酸)の取り扱いに関する説明として正しいものはどれか。

  1. A皮膚に付着すると深部まで浸透し、重い障害を起こすおそれがある
  2. B揮発しないため、換気は不要である
  3. C水で薄めれば素手で扱ってよい
答えと解説を見る

正解：A. 皮膚に付着すると深部まで浸透し、重い障害を起こすおそれがある

フッ化水素酸は皮膚から体内に浸透し、組織の深部やカルシウムの代謝に重い障害を起こすおそれがあります。濃度が低いと痛みがすぐに出ないことがあり、気づくのが遅れる危険もあります。保護具を着用し、付着した場合はすぐに大量の水で洗い流して医療機関を受診するなど、定められた手順に従います。

環境安全のほかの問題

  1. SDS(安全データシート)の説明として正しいものはどれか。
  2. エッチングや装置のクリーニングに使われるPFC(パーフルオロカーボン)類の排出が環境上問題とされる主な理由はどれか。
  3. 毒性や可燃性をもつ特殊材料ガスのボンベの一般的な取り扱いとして正しいものはどれか。
  4. フッ酸を含む排水の代表的な処理方法はどれか。
  5. 薬液を扱う装置などで、発生したガスやミストを発生源の近くで吸い込んで排出する設備はどれか。
