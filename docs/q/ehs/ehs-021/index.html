環境安全

毒性ガスの漏えい警報が鳴ったときの基本的な行動として正しいものはどれか。

  1. A自分で漏えい箇所を探しに近づく
  2. B警報を止めて作業を続ける
  3. C定められた手順に従って速やかに避難し、決められた担当者が遮断などの対応を行う
答えと解説を見る

正解：C. 定められた手順に従って速やかに避難し、決められた担当者が遮断などの対応を行う

毒性ガスの漏えい時に不用意に近づくと、ガスを吸い込んで重大な被害を受けるおそれがあります。警報が鳴ったら、定められた避難経路で速やかに避難し、保護具を着けた担当者や緊急対応チームが、ガスの遮断などを手順に従って行います。日ごろの訓練が重要です。

環境安全のほかの問題

  1. 化学物質を使う作業について、危険性や有害性を特定し、そのリスクの大きさを見積もって対策を決める取り組みを何と呼ぶか。
  2. 有機溶剤を扱う作業で、容器や配管を接地(アース)する主な目的はどれか。
  3. 廃棄物を減らすための考え方「3R」の組み合わせとして正しいものはどれか。
  4. CVD装置のチャンバークリーニングで、PFCの排出削減の観点から採用されてきた方法として正しいものはどれか。
  5. フッ化水素酸が皮膚に付いたときの応急措置で、大量の水で洗い流したあとに使われることがある薬剤はどれか。
