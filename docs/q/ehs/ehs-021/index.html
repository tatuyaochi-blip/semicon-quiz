環境安全

毒性ガスの漏えい警報が鳴ったときの基本的な行動として正しいものはどれか。

  1. A自分で漏えい箇所を探しに近づく
  2. B警報を止めて作業を続ける
  3. C定められた手順に従って速やかに避難し、決められた担当者が遮断などの対応を行う
答えと解説を見る

正解：C. 定められた手順に従って速やかに避難し、決められた担当者が遮断などの対応を行う

毒性ガスの漏えい時に不用意に近づくと、ガスを吸い込んで重大な被害を受けるおそれがあります。警報が鳴ったら、定められた避難経路で風上の安全な場所へ速やかに避難し、保護具や空気呼吸器を着けた担当者や緊急対応チームが、ガスの遮断などを手順に従って行います。警報を止めて作業を続けるのは論外です。日ごろの避難訓練と、避難したことの確認(点呼)が重要です。
