環境安全

窒素ガスを大量に使う場所で、特に注意が必要な労働災害はどれか。

  1. A酸素欠乏(酸欠)
  2. B感電
  3. C騒音による難聴
答えと解説を見る

正解：A. 酸素欠乏(酸欠)

窒素は無色・無臭で毒性はありませんが、漏れて空気中の酸素濃度が下がると、気づかないうちに酸素欠乏症になります。酸素濃度18%未満は危険とされ、ごく低い酸素濃度の空気は一呼吸で意識を失うこともあります。窒素を使う閉鎖空間や装置内に入るときは、酸素濃度を測定し、換気を十分に行い、監視者を置きます。感電や騒音は窒素に特有の災害ではありません。

  2. 毒性ガスの漏えい警報が鳴ったときの基本的な行動として正しいものはどれか。

  4. 有機溶剤を扱う作業で、容器や配管を接地(アース)する主な目的はどれか。
  5. 廃棄物を減らすための考え方「3R」の組み合わせとして正しいものはどれか。
