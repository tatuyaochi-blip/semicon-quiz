環境安全

半導体工場で発生する廃液を、酸・アルカリ・フッ素系・有機溶剤などに分けて回収する主な理由はどれか。

  1. A廃液の重さを減らすため
  2. B廃液の色をそろえるため
  3. C種類ごとに適した処理や再利用を行い、混合による危険な反応も防ぐため
答えと解説を見る

正解：C. 種類ごとに適した処理や再利用を行い、混合による危険な反応も防ぐため

廃液は種類によって適した処理方法が異なり、例えばフッ素を含む廃液はカルシウムを加えて沈殿させ、酸やアルカリは中和し、有機溶剤は焼却や蒸留による回収を行います。分別しておくことで処理や再資源化がしやすくなり、硫酸や現像液を回収して再利用する例もあります。混合による発熱や有毒ガスの発生といった危険も防げます。重さや色をそろえるためではありません。
