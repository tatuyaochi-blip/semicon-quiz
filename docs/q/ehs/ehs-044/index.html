環境安全

ウエハの乾燥や洗浄に使われるイソプロピルアルコール(IPA)の取り扱いで、特に注意すべき性質はどれか。

  1. A水に触れると爆発する
  2. B引火点が低く、常温でも火花などで引火するおそれがある
  3. C強い放射線を出す
答えと解説を見る

正解：B. 引火点が低く、常温でも火花などで引火するおそれがある

IPAの引火点は約12 ℃で、常温でも可燃性の蒸気が発生し、火花や静電気の放電などで引火するおそれがあります。蒸気は空気より重く、低い所にたまりやすい性質もあります。そのため換気を十分に行い、火気を遠ざけ、容器や装置を接地するなどして扱い、保管量は消防法で管理されます。IPAは水とよく混ざり、水で爆発したり放射線を出したりはしません。

  • A. IPAは水とよく混ざり、水に触れて爆発することはありません。
  • B. 正しい。引火しやすい液体として扱います。
  • C. IPAは放射性物質ではありません。

環境安全のほかの問題

  2. 半導体製造装置の環境・健康・安全に関する設計の指針として、業界で広く用いられているSEMIの規格はどれか。

  4. アルシンやホスフィンなどの毒性ガスを、吸着材に吸着させて大気圧より低い圧力で容器に貯蔵・供給する方式の安全上の利点はどれか。
