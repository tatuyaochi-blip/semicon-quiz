環境安全

温室効果ガスの算定で、原材料や部品の製造、製品の輸送や使用など、自社の外のサプライチェーンで生じる排出が含まれる区分はどれか。

  1. Aスコープ3
  2. Bスコープ1
  3. Cスコープ2
答えと解説を見る

正解：A. スコープ3

スコープ3は、購入した原材料・部品・装置の製造、輸送、従業員の通勤、販売した製品の使用や廃棄など、自社の外で生じる間接排出です。半導体では、ウエハや薬品、ガスの製造に伴う排出や、チップを使う機器の電力消費などが含まれ、取引先と協力して削減に取り組みます。

  • A. 正しい。サプライチェーン全体の間接排出です。
  • B. スコープ1は自社の直接排出です。
  • C. スコープ2は購入した電力や熱による排出です。

環境安全のほかの問題

  1. EUで化学物質を製造・輸入する事業者に、物質の登録や安全性の情報の提出を義務づけ、高懸念物質の使用を管理する規則はどれか。
  2. 電子部品のサプライチェーンで、紛争地域の武装勢力の資金源にならないよう調達の確認が求められている鉱物(3TG)の組み合わせとして正しいものはどれか。
  3. 自然環境の中でほとんど分解されず「永遠の化学物質」とも呼ばれ、レジスト材料などに使われることから、半導体業界でも規制への対応や代替が課題になっている物質群はどれか。
  4. 事業で使う電力を100%再生可能エネルギーでまかなうことを目標に掲げる企業が参加する国際的な取り組みはどれか。
  5. 日本で、事業者が特定の化学物質について、環境への排出量や廃棄物としての移動量を把握して国に届け出る制度はどれか。
