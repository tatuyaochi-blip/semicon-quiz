環境安全

フッ酸を含む排水の代表的な処理方法はどれか。

  1. Aそのまま河川に放流する
  2. B加熱して水分だけを蒸発させる
  3. Cカルシウム化合物を加え、フッ化カルシウムとして沈殿させて取り除く
答えと解説を見る

正解：C. カルシウム化合物を加え、フッ化カルシウムとして沈殿させて取り除く

フッ素を含む排水には、消石灰などのカルシウム化合物を加えて、水に溶けにくいフッ化カルシウム(CaF2)として沈殿させ、取り除きます。処理後の排水は、法令や地域の排水基準を満たしていることを確認してから放流します。

環境安全のほかの問題

  1. 薬液を扱う装置などで、発生したガスやミストを発生源の近くで吸い込んで排出する設備はどれか。
  2. 酸やアルカリの薬液を扱う作業で着用すべき保護具の組み合わせとして適切なものはどれか。
  3. 化学品の危険有害性を、ドクロや炎などの絵表示と注意書きによって国際的に統一して示す仕組みはどれか。
  4. 電気電子機器に含まれる鉛や水銀などの特定有害物質の使用を制限するEUの規制はどれか。
  5. 半導体工場で、大量に使う水について行われている環境面の取り組みとして適切なものはどれか。
