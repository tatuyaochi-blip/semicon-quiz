環境安全

クリーンルーム内での火災に備えた設備として適切なものはどれか。

  1. A煙や熱の感知器と、薬品や装置に適した消火設備
  2. B消火設備は一切置かない
  3. C消火には必ず大量の水だけを使う
答えと解説を見る

正解：A. 煙や熱の感知器と、薬品や装置に適した消火設備

クリーンルームには可燃性の薬品やガス、高価な装置があるため、早期に火災を検知する感知器と、対象に応じた消火設備が設けられます。装置によっては、内部に専用の消火装置を備えるものもあります。水が適さない薬品や電気設備もあるため、消火方法を事前に確認しておきます。

環境安全のほかの問題

  1. 製品の原材料の調達から製造、使用、廃棄までの全体で、環境への負荷を評価する手法はどれか。
  2. 半導体製造装置に付いている赤い大きな非常停止ボタン(EMO)の役割として正しいものはどれか。
  3. 装置の保守作業の前に、電源やガスなどのエネルギー源を遮断し、錠と札を付けて、作業中に誰かが誤って再投入できないようにする手順はどれか。
  4. けがには至らなかったものの、ひやりとしたり、はっとしたりした出来事を報告し合う活動の目的として正しいものはどれか。
  5. 職場の安全や品質の基本として広く行われている「5S」の組み合わせとして正しいものはどれか。
