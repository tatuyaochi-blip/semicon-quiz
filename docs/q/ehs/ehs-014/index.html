環境安全

環境マネジメントシステムに関する国際規格はどれか。

  1. AISO 14001
  2. BISO 9001
  3. CISO 14644
答えと解説を見る

正解：A. ISO 14001

ISO 14001は、組織が環境への影響を管理し、継続的に改善するための仕組み(環境マネジメントシステム)の国際規格です。環境方針を定め、PDCAサイクルで目標の設定・実行・確認・見直しを繰り返します。第三者の審査で認証を受けることができ、取引の条件とされることもあります。ISO 9001は品質マネジメントシステム、ISO 14644はクリーンルームの清浄度などに関する規格です。
