環境安全

日本で、事業者が特定の化学物質について、環境への排出量や廃棄物としての移動量を把握して国に届け出る制度はどれか。

  1. AGHS
  2. BRoHS
  3. CPRTR制度
答えと解説を見る

正解：C. PRTR制度

PRTR(化学物質排出移動量届出制度)は、化管法にもとづき、対象の化学物質を一定量以上扱う事業者が、大気・水・土壌への排出量と、廃棄物や下水道への移動量を毎年届け出る制度です。集計結果は公表され、化学物質の管理の改善や、排出の削減を促します。

  • A. GHSは化学品の危険有害性を表示する仕組みです。
  • B. RoHSはEUの特定有害物質の使用制限です。
  • C. 正しい。排出量と移動量を届け出る制度です。

環境安全のほかの問題

  1. 有害な化学物質の「許容濃度」の説明として正しいものはどれか。
  2. ウエハの乾燥や洗浄に使われるイソプロピルアルコール(IPA)の取り扱いで、特に注意すべき性質はどれか。
  3. エピタキシャル成長やアニールに使われる水素ガスの危険性として正しいものはどれか。
  4. 半導体製造装置の環境・健康・安全に関する設計の指針として、業界で広く用いられているSEMIの規格はどれか。
  5. 現像液に使われるTMAH(水酸化テトラメチルアンモニウム)の高濃度液が皮膚に付いた場合に特に危険とされる理由はどれか。
