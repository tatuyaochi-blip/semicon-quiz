環境安全

ヒ素などの有害物質を含む廃棄物の扱いとして適切なものはどれか。

  1. A一般のごみとして捨てる
  2. B燃やして煙として放出する
  3. C法令に従い、特別な管理と処理が必要な廃棄物として扱う
答えと解説を見る

正解：C. 法令に従い、特別な管理と処理が必要な廃棄物として扱う

ヒ素などの有害物質を含む廃棄物は、法令で特別な管理が必要な産業廃棄物として扱われ、決められた方法で保管・運搬・処理しなければなりません。処理を委託する場合も、適正に処理されたことを確認する責任があります。

環境安全のほかの問題

  1. 作業を始める前に、その作業に潜む危険を話し合い、対策を確認する活動を何と呼ぶか。
  2. クリーンルーム内での火災に備えた設備として適切なものはどれか。
  3. 製品の原材料の調達から製造、使用、廃棄までの全体で、環境への負荷を評価する手法はどれか。
  4. 半導体製造装置に付いている赤い大きな非常停止ボタン(EMO)の役割として正しいものはどれか。
  5. 装置の保守作業の前に、電源やガスなどのエネルギー源を遮断し、錠と札を付けて、作業中に誰かが誤って再投入できないようにする手順はどれか。
