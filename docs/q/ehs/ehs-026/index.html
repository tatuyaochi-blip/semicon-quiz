環境安全

フッ化水素酸が皮膚に付いたときの応急措置で、大量の水で洗い流したあとに使われることがある薬剤はどれか。

  1. Aグルコン酸カルシウムのゲル
  2. B砂糖の水溶液
  3. C食塩
答えと解説を見る

正解：A. グルコン酸カルシウムのゲル

フッ化水素酸のフッ化物イオンは、体内のカルシウムと結びついて組織を傷つけます。大量の水で十分に洗い流したあと、グルコン酸カルシウムのゲルを塗ってフッ化物イオンをカルシウムと反応させることで、障害の進行を抑えます。必ず医療機関を受診します。
