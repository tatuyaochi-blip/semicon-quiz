環境安全

フッ化水素酸が皮膚に付いたときの応急措置で、大量の水で洗い流したあとに使われることがある薬剤はどれか。

  1. Aグルコン酸カルシウムのゲル
  2. B砂糖の水溶液
  3. C食塩
答えと解説を見る

正解：A. グルコン酸カルシウムのゲル

フッ化水素酸のフッ化物イオンは、体内のカルシウムと結びついて組織を傷つけます。大量の水で十分に洗い流したあと、2.5%程度のグルコン酸カルシウムのゲルを塗ってすり込むと、フッ化物イオンを皮膚の表面でカルシウムと反応させ、障害の進行と痛みを抑えられます。フッ酸を扱う職場では、このゲルを手の届く場所に備えておきます。それでも必ず医療機関を受診します。
