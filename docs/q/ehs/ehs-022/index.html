環境安全

化学物質を使う作業について、危険性や有害性を特定し、そのリスクの大きさを見積もって対策を決める取り組みを何と呼ぶか。

  1. Aリスクアセスメント
  2. B統計的工程管理
  3. Cビニング
答えと解説を見る

正解：A. リスクアセスメント

リスクアセスメントでは、使う化学物質の危険性・有害性をSDSなどで確認し、使用量や作業方法からばく露や事故の可能性を見積もって、代替物質の使用、設備の改善、保護具の着用などの対策を優先順位をつけて決めます。

環境安全のほかの問題

  1. 有機溶剤を扱う作業で、容器や配管を接地(アース)する主な目的はどれか。
  2. 廃棄物を減らすための考え方「3R」の組み合わせとして正しいものはどれか。
  3. CVD装置のチャンバークリーニングで、PFCの排出削減の観点から採用されてきた方法として正しいものはどれか。
  4. フッ化水素酸が皮膚に付いたときの応急措置で、大量の水で洗い流したあとに使われることがある薬剤はどれか。
  5. ヒ素などの有害物質を含む廃棄物の扱いとして適切なものはどれか。
