環境安全

SDS(安全データシート)の説明として正しいものはどれか。

  1. A製造装置の保守手順書
  2. B化学物質の危険有害性や取り扱い方法、応急措置などを記載した文書
  3. C製品の出荷検査の成績書
答えと解説を見る

正解：B. 化学物質の危険有害性や取り扱い方法、応急措置などを記載した文書

SDSは、化学物質やそれを含む製品を譲渡・提供するときに、提供者が相手に渡す文書です。成分、危険有害性、取り扱いと保管の方法、暴露防止策、応急措置、廃棄方法などが記載されています。化学物質を扱う前に内容を確認することが基本です。

環境安全のほかの問題

  1. エッチングや装置のクリーニングに使われるPFC(パーフルオロカーボン)類の排出が環境上問題とされる主な理由はどれか。
  2. 毒性や可燃性をもつ特殊材料ガスのボンベの一般的な取り扱いとして正しいものはどれか。
  3. フッ酸を含む排水の代表的な処理方法はどれか。
  4. 薬液を扱う装置などで、発生したガスやミストを発生源の近くで吸い込んで排出する設備はどれか。
  5. 酸やアルカリの薬液を扱う作業で着用すべき保護具の組み合わせとして適切なものはどれか。
