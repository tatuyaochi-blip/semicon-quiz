環境安全

化学品の危険有害性を、ドクロや炎などの絵表示と注意書きによって国際的に統一して示す仕組みはどれか。

  1. AISO 9001
  2. BRoHS指令
  3. CGHS(化学品の分類および表示に関する世界調和システム)
答えと解説を見る

正解：C. GHS(化学品の分類および表示に関する世界調和システム)

GHSは、化学品の危険有害性を世界共通のルールで分類し、絵表示(ピクトグラム)、注意喚起語、危険有害性情報などでラベルやSDSに表示する仕組みです。ISO 9001は品質マネジメントシステムの規格、RoHS指令は電気電子機器の有害物質規制です。

この分野を解く 分野ページへ

環境安全のほかの問題

  1. 電気電子機器に含まれる鉛や水銀などの特定有害物質の使用を制限するEUの規制はどれか。
  2. 半導体工場で、大量に使う水について行われている環境面の取り組みとして適切なものはどれか。
  3. 目に薬液が入ったときの応急措置として適切なものはどれか。
  4. 可燃性ガスの爆発下限界(LEL)の意味として正しいものはどれか。
  5. 排ガス中の酸性ガスなどを、水や薬液と接触させて吸収・除去する装置はどれか。
