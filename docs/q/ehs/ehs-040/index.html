環境安全

自然環境の中でほとんど分解されず「永遠の化学物質」とも呼ばれ、レジスト材料などに使われることから、半導体業界でも規制への対応や代替が課題になっている物質群はどれか。

  1. APFAS(有機フッ素化合物)
  2. Bグルコース
  3. C塩化ナトリウム
答えと解説を見る

正解：A. PFAS(有機フッ素化合物)

PFASは炭素とフッ素の強い結合をもつ数千種類の有機フッ素化合物の総称で、環境中や体内に長く残ることが問題視され、欧米で規制が強化されています。半導体ではレジストの光酸発生剤や反射防止膜、界面活性剤、フッ素樹脂の配管や部品などに使われ、性能を代わりに果たせる材料が少ないため、代替材料の開発と排出の管理が並行して進められています。

  • A. 正しい。分解されにくい有機フッ素化合物の総称です。
  • B. グルコースはブドウ糖で、分解されやすい物質です。
  • C. 塩化ナトリウムは食塩で、PFASではありません。

環境安全のほかの問題

  1. 事業で使う電力を100%再生可能エネルギーでまかなうことを目標に掲げる企業が参加する国際的な取り組みはどれか。
  2. 日本で、事業者が特定の化学物質について、環境への排出量や廃棄物としての移動量を把握して国に届け出る制度はどれか。
  3. 有害な化学物質の「許容濃度」の説明として正しいものはどれか。
  4. ウエハの乾燥や洗浄に使われるイソプロピルアルコール(IPA)の取り扱いで、特に注意すべき性質はどれか。
  5. エピタキシャル成長やアニールに使われる水素ガスの危険性として正しいものはどれか。
