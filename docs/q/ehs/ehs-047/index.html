環境安全

現像液に使われるTMAH(水酸化テトラメチルアンモニウム)の高濃度液が皮膚に付いた場合に特に危険とされる理由はどれか。

  1. A強い放射線を出すため
  2. B皮膚から吸収されて神経や筋肉の働きを妨げ、呼吸が止まるなどの全身の中毒を起こすおそれがあるため
  3. Cすぐに凍りついて凍傷を起こすため
答えと解説を見る

正解：B. 皮膚から吸収されて神経や筋肉の働きを妨げ、呼吸が止まるなどの全身の中毒を起こすおそれがあるため

TMAHは強いアルカリで皮膚を傷めるだけでなく、皮膚から吸収されたテトラメチルアンモニウムイオンが神経から筋肉への信号の伝達を妨げ、呼吸の停止などを起こすことがあります。高濃度液の接触による死亡事故も報告されており、保護具の着用と、付着したときのただちの洗浄と受診が重要です。

  • A. TMAHは放射性物質ではありません。
  • B. 正しい。皮膚からの吸収による全身の中毒が危険です。
  • C. 凍傷を起こす物質ではありません。
この分野を解く 分野ページへ

環境安全のほかの問題

  1. アルシンやホスフィンなどの毒性ガスを、吸着材に吸着させて大気圧より低い圧力で容器に貯蔵・供給する方式の安全上の利点はどれか。
  2. CF4などの非常に安定で分解しにくいPFCを、装置の排ガスから取り除くために用いられる除害方式として適切なものはどれか。
  3. 化学物質のばく露の管理で、1日8時間の平均の値とは別に、15分間などの短い時間のばく露について定められる上限はどれか。
  4. フッ化水素酸(フッ酸)の取り扱いに関する説明として正しいものはどれか。
  5. SDS(安全データシート)の説明として正しいものはどれか。
