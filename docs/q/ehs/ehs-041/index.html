環境安全

事業で使う電力を100%再生可能エネルギーでまかなうことを目標に掲げる企業が参加する国際的な取り組みはどれか。

  1. AISO 14644
  2. BRE100
  3. CJEDEC
答えと解説を見る

正解：B. RE100

RE100は、事業活動で使う電力を100%再生可能エネルギーにすることを目標に掲げた企業が参加する国際的なイニシアチブです。電力を大量に使う半導体企業も参加しており、太陽光発電の設置や再生可能エネルギーの電力購入契約(PPA)などによって、スコープ2の排出削減を進めています。

  • A. ISO 14644はクリーンルームの規格です。
  • B. 正しい。再生可能エネルギー100%を目指す取り組みです。
  • C. JEDECは半導体の標準化団体です。

環境安全のほかの問題

  1. 日本で、事業者が特定の化学物質について、環境への排出量や廃棄物としての移動量を把握して国に届け出る制度はどれか。
  2. 有害な化学物質の「許容濃度」の説明として正しいものはどれか。
  3. ウエハの乾燥や洗浄に使われるイソプロピルアルコール(IPA)の取り扱いで、特に注意すべき性質はどれか。
  4. エピタキシャル成長やアニールに使われる水素ガスの危険性として正しいものはどれか。
  5. 半導体製造装置の環境・健康・安全に関する設計の指針として、業界で広く用いられているSEMIの規格はどれか。
