環境安全

けがには至らなかったものの、ひやりとしたり、はっとしたりした出来事を報告し合う活動の目的として正しいものはどれか。

  1. A報告した人を罰するため
  2. B作業の時間を計るため
  3. C重大な事故の背後にある小さな危険を早めに見つけ、対策して事故を防ぐため
答えと解説を見る

正解：C. 重大な事故の背後にある小さな危険を早めに見つけ、対策して事故を防ぐため

ハインリッヒの法則では、1件の重大な事故の背後には29件の軽い事故と、300件のヒヤリハットがあるとされます。ヒヤリハットを集めて原因を分析し、設備や手順を改善すれば、重大な事故を未然に防げます。報告しやすい雰囲気をつくるため、報告者を責めないことが大切です。作業時間の測定や処罰のための活動ではありません。

  • A. 報告者を責めると報告が集まらなくなります。
  • B. 作業時間の測定が目的ではありません。
  • C. 正しい。小さな危険の段階で対策するための活動です。

環境安全のほかの問題

  1. 職場の安全や品質の基本として広く行われている「5S」の組み合わせとして正しいものはどれか。
  2. 地震が多い地域の半導体工場で、大きな揺れを感知したときに自動的に行われる安全対策として一般的なものはどれか。
  3. 企業の温室効果ガス排出量の算定で、購入した電力や熱の使用に伴う間接的な排出が分類される区分はどれか。
  4. 温室効果ガスの算定で、原材料や部品の製造、製品の輸送や使用など、自社の外のサプライチェーンで生じる排出が含まれる区分はどれか。
  5. EUで化学物質を製造・輸入する事業者に、物質の登録や安全性の情報の提出を義務づけ、高懸念物質の使用を管理する規則はどれか。
