環境安全

半導体工場のエネルギー消費で大きな割合を占める設備として正しいものはどれか。

  1. A照明だけ
  2. B製造装置に加え、クリーンルームの空調や超純水製造、排気処理などのユーティリティ設備
  3. C事務所のパソコン
答えと解説を見る

正解：B. 製造装置に加え、クリーンルームの空調や超純水製造、排気処理などのユーティリティ設備

半導体工場では、製造装置そのものに加えて、大量の空気を循環させるクリーンルームの空調、超純水の製造、排気・排水の処理、冷却水などのユーティリティ設備が多くの電力を使います。これらの効率化は、工場の省エネルギーと温室効果ガス削減の重要なテーマです。

環境安全のほかの問題

  1. 薬液の保管で、互いに混ざると激しく反応するおそれのある物質を離して保管する理由として正しいものはどれか。
  2. 有害な化学物質を扱う作業場で、空気中の有害物質の濃度などを定期的に測って作業環境を評価することを何と呼ぶか。
  3. 半導体工場で発生する廃液を、酸・アルカリ・フッ素系・有機溶剤などに分けて回収する主な理由はどれか。
  4. 窒素ガスを大量に使う場所で、特に注意が必要な労働災害はどれか。
  5. 企業の温室効果ガス排出量の算定で、自社の工場での燃料の燃焼や、プロセスガスの排出などの直接排出が分類される区分はどれか。
