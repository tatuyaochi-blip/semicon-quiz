環境安全

目に薬液が入ったときの応急措置として適切なものはどれか。

  1. Aただちに洗眼器などの大量の流水で十分に洗い流し、医療機関を受診する
  2. B目を強くこすって薬液を出す
  3. Cしばらく様子を見て、痛みが続いたら洗う
答えと解説を見る

正解：A. ただちに洗眼器などの大量の流水で十分に洗い流し、医療機関を受診する

薬液が目に入った場合は、ただちに洗眼器などで大量の流水を使って十分な時間洗い流し、速やかに医療機関を受診します。こすると傷が広がるおそれがあります。薬液の種類によって応急措置が異なる場合もあるため、事前にSDSで確認しておくことが大切です。

環境安全のほかの問題

  1. 可燃性ガスの爆発下限界(LEL)の意味として正しいものはどれか。
  2. 排ガス中の酸性ガスなどを、水や薬液と接触させて吸収・除去する装置はどれか。
  3. 環境マネジメントシステムに関する国際規格はどれか。
  4. 半導体工場のエネルギー消費で大きな割合を占める設備として正しいものはどれか。
  5. 薬液の保管で、互いに混ざると激しく反応するおそれのある物質を離して保管する理由として正しいものはどれか。
