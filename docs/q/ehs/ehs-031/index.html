環境安全

半導体製造装置に付いている赤い大きな非常停止ボタン(EMO)の役割として正しいものはどれか。

  1. A異常や危険が起きたときに、装置の動作や危険なエネルギーの供給をすぐに止める
  2. B装置の生産速度を上げる
  3. C装置の画面の表示を切り替える
答えと解説を見る

正解：A. 異常や危険が起きたときに、装置の動作や危険なエネルギーの供給をすぐに止める

EMO(Emergency Off)ボタンは、人が危険にさらされたときや装置に異常が起きたときに、押すだけで装置の動作を止め、電源やガスなどの危険なエネルギーを遮断するためのものです。誰でもすぐに押せるよう、目立つ色と形で、手の届きやすい場所に付けられています。

  • A. 正しい。緊急時に装置をすぐ止めるためのボタンです。
  • B. 生産速度を変えるものではありません。
  • C. 表示の切り替えのためのボタンではありません。

環境安全のほかの問題

  1. 装置の保守作業の前に、電源やガスなどのエネルギー源を遮断し、錠と札を付けて、作業中に誰かが誤って再投入できないようにする手順はどれか。
  2. けがには至らなかったものの、ひやりとしたり、はっとしたりした出来事を報告し合う活動の目的として正しいものはどれか。
  3. 職場の安全や品質の基本として広く行われている「5S」の組み合わせとして正しいものはどれか。
  4. 地震が多い地域の半導体工場で、大きな揺れを感知したときに自動的に行われる安全対策として一般的なものはどれか。
  5. 企業の温室効果ガス排出量の算定で、購入した電力や熱の使用に伴う間接的な排出が分類される区分はどれか。
