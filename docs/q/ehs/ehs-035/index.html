環境安全

地震が多い地域の半導体工場で、大きな揺れを感知したときに自動的に行われる安全対策として一般的なものはどれか。

  1. A感震器と連動して、特殊材料ガスなどの供給弁を自動で閉じる
  2. Bすべての照明を消す
  3. Cクリーンルームの扉をすべて施錠する
答えと解説を見る

正解：A. 感震器と連動して、特殊材料ガスなどの供給弁を自動で閉じる

大きな地震では配管の破損などで、毒性や可燃性のガスが漏れるおそれがあります。そのため感震器が一定以上の揺れを感知すると、ガスの供給弁を自動で遮断する仕組みが設けられています。あわせて、装置や棚の転倒防止、薬液タンクの固定などの対策も行われます。

  • A. 正しい。揺れを感知してガスの供給を止めます。
  • B. 照明を消すと避難の妨げになります。
  • C. 扉を施錠すると避難できなくなります。

環境安全のほかの問題

  1. 企業の温室効果ガス排出量の算定で、購入した電力や熱の使用に伴う間接的な排出が分類される区分はどれか。
  2. 温室効果ガスの算定で、原材料や部品の製造、製品の輸送や使用など、自社の外のサプライチェーンで生じる排出が含まれる区分はどれか。
  3. EUで化学物質を製造・輸入する事業者に、物質の登録や安全性の情報の提出を義務づけ、高懸念物質の使用を管理する規則はどれか。
  4. 電子部品のサプライチェーンで、紛争地域の武装勢力の資金源にならないよう調達の確認が求められている鉱物(3TG)の組み合わせとして正しいものはどれか。
  5. 自然環境の中でほとんど分解されず「永遠の化学物質」とも呼ばれ、レジスト材料などに使われることから、半導体業界でも規制への対応や代替が課題になっている物質群はどれか。
