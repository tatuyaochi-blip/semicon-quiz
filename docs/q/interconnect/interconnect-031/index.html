配線プロセス

LSIの中の配線の主な役割はどれか。

  1. Aトランジスタどうしや電源・入出力端子を電気的につなぎ、信号や電力を伝える
  2. B光を発する
  3. Cデータを長期間記憶する
答えと解説を見る

正解：A. トランジスタどうしや電源・入出力端子を電気的につなぎ、信号や電力を伝える

LSIの配線は、数十億個のトランジスタを互いにつなぎ、また電源やチップの外につながる端子とも接続して、信号や電力を伝える役割をもちます。トランジスタの上に何層も積み重ねてつくられます。

  • A. 正しい。素子どうしや電源・端子をつなぎます。
  • B. 光を発するのは発光素子の役割です。
  • C. データの記憶はメモリセルの役割です。

配線プロセスのほかの問題

  1. LSIの「多層配線」の説明として正しいものはどれか。
  2. 室温での銅(Cu)の抵抗率に最も近い値はどれか。(バルクの値)
  3. LSIの配線材料に求められる主な性質の組み合わせとして正しいものはどれか。
  4. 配線と配線の間を埋める層間絶縁膜の基本的な役割はどれか。
  5. アルミニウム配線に、銅を0.5%程度添加したAl-Cu合金が使われてきた主な理由はどれか。
