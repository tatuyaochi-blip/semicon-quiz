配線プロセス

配線間の絶縁膜の一部を空洞(エアギャップ)にする技術の主な目的はどれか。

  1. A配線の機械的強度を高める
  2. B配線間の容量を下げる(空気の比誘電率はほぼ1)
  3. C配線の抵抗を下げる
答えと解説を見る

正解：B. 配線間の容量を下げる(空気の比誘電率はほぼ1)

空気(真空)の比誘電率はほぼ1で、どの絶縁材料よりも低いため、配線の間を空洞にすると配線間の容量を20〜30%程度下げられます。配線を形成したあと間の絶縁膜を除いて上からふさぐ方法や、成膜でわざと空洞を残す方法があります。機械的強度、熱の逃げにくさ、上の層のビアが空洞に落ちる問題などがあるため、特に容量を下げたい密な層に限って使われています。

配線プロセスのほかの問題

  1. 先端ロジックで導入が進む裏面電源供給(バックサイドパワーデリバリー)の説明として正しいものはどれか。
  2. 電源配線の抵抗に電流が流れることで、回路に届く電源電圧が下がる現象を何と呼ぶか。
  3. 隣り合う配線の間の容量結合によって、一方の信号の変化がもう一方の信号に雑音として現れる現象を何と呼ぶか。
  4. Cu配線の上面にコバルトなどのキャップ層を設ける主な目的はどれか。
  5. エレクトロマイグレーションによる配線の寿命を表すブラックの式で、寿命を短くする要因として正しいものはどれか。
