配線プロセス

LSIの「多層配線」の説明として正しいものはどれか。

  1. A配線を1層だけ平面に並べたもの
  2. B絶縁膜を挟んで配線の層を何層も重ね、層の間をビアでつないだもの
  3. C配線を使わずに無線で信号を送るもの
答えと解説を見る

正解：B. 絶縁膜を挟んで配線の層を何層も重ね、層の間をビアでつないだもの

多層配線では、配線の層と絶縁膜を交互に重ね、上下の層の配線をビアと呼ぶ縦の接続でつなぎます。平面だけでは配線しきれない多数の接続を、立体的に効率よく配置できます。

  • A. 1層だけでは多数の素子をつなぎきれません。
  • B. 正しい。絶縁膜を挟んで何層も重ね、ビアでつなぎます。
  • C. LSIの中の配線は金属による有線の接続です。

配線プロセスのほかの問題

  1. 室温での銅(Cu)の抵抗率に最も近い値はどれか。(バルクの値)
  2. LSIの配線材料に求められる主な性質の組み合わせとして正しいものはどれか。
  3. 配線と配線の間を埋める層間絶縁膜の基本的な役割はどれか。
  4. アルミニウム配線に、銅を0.5%程度添加したAl-Cu合金が使われてきた主な理由はどれか。
  5. 電解めっきで形成したCu膜が、室温で放置するだけでも時間とともに結晶粒が大きくなり、抵抗率が下がる現象を何と呼ぶか。
