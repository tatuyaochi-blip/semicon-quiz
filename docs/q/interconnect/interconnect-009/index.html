配線プロセス

Cu配線の幅が非常に細くなると、配線の実効的な抵抗率が上昇する主な理由はどれか。

  1. A配線の温度が下がるため
  2. B電子の表面散乱や粒界散乱が増え、抵抗の高いバリア層の占める割合も大きくなるため
  3. CCuが半導体に変わるため
答えと解説を見る

正解：B. 電子の表面散乱や粒界散乱が増え、抵抗の高いバリア層の占める割合も大きくなるため

配線幅が電子の平均自由行程(Cuで約40 nm)と同程度以下まで細くなると、配線の表面や結晶粒界での電子の散乱が増え、抵抗率がバルクの数倍にもなります。細い配線では結晶粒も小さくなるため、粒界散乱がさらに増えます。加えて、一定の厚さが必要なバリア層が断面に占める割合も大きくなります。そのため、平均自由行程の短いコバルトやルテニウム、モリブデンなどの新しい配線材料が検討・導入されています。

配線プロセスのほかの問題

  1. 多層配線で、上層の配線ほど太く厚くする主な理由はどれか。
  2. 配線間の絶縁膜の一部を空洞(エアギャップ)にする技術の主な目的はどれか。
  3. 先端ロジックで導入が進む裏面電源供給(バックサイドパワーデリバリー)の説明として正しいものはどれか。
  4. 電源配線の抵抗に電流が流れることで、回路に届く電源電圧が下がる現象を何と呼ぶか。
  5. 隣り合う配線の間の容量結合によって、一方の信号の変化がもう一方の信号に雑音として現れる現象を何と呼ぶか。
