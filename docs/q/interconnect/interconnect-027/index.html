配線プロセス

エレクトロマイグレーションによるボイドが発生しやすい場所として正しいものはどれか。

  1. Aビアと配線の境界など、金属原子の流れが不連続になる場所
  2. B電流が流れていない配線の中央
  3. Cチップの外のパッケージ基板
答えと解説を見る

正解：A. ビアと配線の境界など、金属原子の流れが不連続になる場所

エレクトロマイグレーションでは、原子が電子の流れに押されて移動します(電子風力)。ビアと配線の境界、ビアの下のバリアのように原子の流れが途切れる場所では、上流側から原子が出ていく一方で補充されないためボイドができ、下流側では原子がたまってヒロック(盛り上がり)ができます。設計では冗長ビアを置く、ビアの周りの配線を広げる、電流の向きを考えるなどの対策をとります。
