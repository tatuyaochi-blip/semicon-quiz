配線プロセス

エレクトロマイグレーションによるボイドが発生しやすい場所として正しいものはどれか。

  1. Aビアと配線の境界など、金属原子の流れが不連続になる場所
  2. B電流が流れていない配線の中央
  3. Cチップの外のパッケージ基板
答えと解説を見る

正解：A. ビアと配線の境界など、金属原子の流れが不連続になる場所

エレクトロマイグレーションでは、原子が電子の流れに押されて移動します。ビアと配線の境界のように、原子の流れが途切れる場所では、原子が出ていく一方で補充されないため、ボイドができやすくなります。設計では、ビアを複数にするなどの対策をとります。

配線プロセスのほかの問題

  2. Low-k膜をエッチングやアッシングで加工するときに注意すべき問題として正しいものはどれか。
  3. 配線どうしの間隔が狭くなることで重要性が増している、配線間の絶縁膜の経時的な絶縁破壊を何と呼ぶか。
  4. LSIの中の配線の主な役割はどれか。
  5. LSIの「多層配線」の説明として正しいものはどれか。
