配線プロセス

Cuを電解めっきで埋め込む前に、スパッタリングで薄く形成するCu膜の役割として正しいものはどれか。

  1. ACuの拡散を防ぐバリア
  2. Bめっきの電流を流すための導電層(シード層)
  3. C層間の絶縁
答えと解説を見る

正解：B. めっきの電流を流すための導電層(シード層)

電解めっきでは、表面に電流を流して金属を析出させるため、溝の内面まで導電性の層が必要です。そこで、バリア層の上にスパッタリングで薄いCuのシード層をつくってから、めっきでCuを埋め込みます。

この分野を解く 分野ページへ

配線プロセスのほかの問題

  1. Cuの埋め込みが不十分で、ビアの中に空洞(ボイド)が残ると起こる問題として正しいものはどれか。
  2. 同じ層で隣り合う配線の間隔を半分にすると、その配線間の容量はおよそどうなるか。(平行平板として近似する)
  3. 上下の配線層の位置合わせのずれに強くするため、ビアを配線の溝に合わせて自己整合的に形成する技術はどれか。
  4. 抵抗率2 µΩ·cmの配線で、長さ1 mm、幅と厚さがそれぞれ100 nmのときの抵抗はおよそいくらか。
  5. エレクトロマイグレーションによるボイドが発生しやすい場所として正しいものはどれか。
