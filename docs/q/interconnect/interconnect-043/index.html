配線プロセス

機械的に弱いLow-k膜を使ったチップで、パッケージに実装するときの応力によって膜が割れたりはがれたりする問題を何と呼ぶか。

  1. A量子化誤差
  2. Bチップとパッケージの相互作用(CPI)の問題
  3. Cショートチャネル効果
答えと解説を見る

正解：B. チップとパッケージの相互作用(CPI)の問題

Low-k膜は多孔質などで機械的強度が低いため、はんだバンプの接合や樹脂の封止、温度変化による応力がチップに加わると、配線層の膜が割れたりはがれたりすることがあります。これをチップ・パッケージ相互作用(CPI)の問題といい、構造設計や材料選定で対策します。

  • A. 量子化誤差はAD変換の誤差です。
  • B. 正しい。実装時の応力による配線層の破壊の問題です。
  • C. ショートチャネル効果は微細なトランジスタの特性の問題です。

配線プロセスのほかの問題

  1. Cu配線の上面に、絶縁膜側の拡散防止とエッチングストップを兼ねてつける膜として一般的なものはどれか。
  2. エレクトロマイグレーションの試験で、ある長さより短い配線では寿命が大きく延びる(劣化がほとんど進まない)現象が知られている。この現象の名前はどれか。
  3. 配線の幅が結晶粒より細くなり、結晶粒界が配線を横切るように並んだ構造を何と呼び、エレクトロマイグレーションにどう影響するか。
  4. 高い周波数の信号が配線を流れるとき、電流が導体の表面付近に集中し、実効的な抵抗が上がる現象を何と呼ぶか。
  5. ワイヤボンディングなどを行う電極パッドの真下に、能動素子や配線を配置する設計を何と呼ぶか。
