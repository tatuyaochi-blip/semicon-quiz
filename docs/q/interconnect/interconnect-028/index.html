配線プロセス

微細化が進んだLSIで、ゲートの遅延と比べた配線の遅延の傾向として正しいものはどれか。

  1. A配線の遅延は小さくなり、無視できるようになった
  2. B配線の遅延とゲートの遅延は無関係である
  3. C配線の遅延の割合が大きくなり、性能を制限する要因になっている
答えと解説を見る

正解：C. 配線の遅延の割合が大きくなり、性能を制限する要因になっている

トランジスタは微細化で速くなる一方、配線は断面積が縮んで抵抗が増え、間隔が狭まって容量も減らないため、配線の遅延は小さくなりにくくなっています。1990年代後半(0.25 µm世代前後)を境に、長い配線の遅延はゲートの遅延を上回るようになり、回路全体に占める配線の遅延と電力の割合が大きくなりました。そのため配線の材料・構造の改良、リピータの挿入、配置の工夫が重要です。
