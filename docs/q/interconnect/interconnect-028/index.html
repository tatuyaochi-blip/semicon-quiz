配線プロセス

微細化が進んだLSIで、ゲートの遅延と比べた配線の遅延の傾向として正しいものはどれか。

  1. A配線の遅延は小さくなり、無視できるようになった
  2. B配線の遅延とゲートの遅延は無関係である
  3. C配線の遅延の割合が大きくなり、性能を制限する要因になっている
答えと解説を見る

正解：C. 配線の遅延の割合が大きくなり、性能を制限する要因になっている

トランジスタは微細化で速くなる一方、配線は細く間隔が狭くなるため抵抗と容量が増え、配線の遅延は小さくなりにくくなっています。そのため、回路全体の遅延に占める配線の遅延の割合が大きくなり、配線の材料や構造の改良、リピータの挿入などが重要になっています。

配線プロセスのほかの問題

  1. Low-k膜をエッチングやアッシングで加工するときに注意すべき問題として正しいものはどれか。
  2. 配線どうしの間隔が狭くなることで重要性が増している、配線間の絶縁膜の経時的な絶縁破壊を何と呼ぶか。
  3. LSIの中の配線の主な役割はどれか。
  4. LSIの「多層配線」の説明として正しいものはどれか。
  5. 室温での銅(Cu)の抵抗率に最も近い値はどれか。(バルクの値)
