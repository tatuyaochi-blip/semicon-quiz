配線プロセス

Cu配線の上面にコバルトなどのキャップ層を設ける主な目的はどれか。

  1. A配線の抵抗を意図的に高める
  2. B配線を透明にする
  3. CCu表面に沿った原子の移動を抑え、エレクトロマイグレーション耐性を高める
答えと解説を見る

正解：C. Cu表面に沿った原子の移動を抑え、エレクトロマイグレーション耐性を高める

Cu配線のエレクトロマイグレーションは、主に配線の上面(絶縁膜との界面)に沿った原子の移動で進みます。上面をコバルトなどの金属キャップで覆うと界面の結合が強くなり、原子が動きにくくなるため、エレクトロマイグレーション耐性が向上します。

配線プロセスのほかの問題

  1. エレクトロマイグレーションによる配線の寿命を表すブラックの式で、寿命を短くする要因として正しいものはどれか。
  2. 先端ロジックLSIの配線層の数として最も近いものはどれか。
  3. Cuに代わる微細配線の材料として検討されているルテニウム(Ru)などの金属の利点として正しいものはどれか。
  4. チップの最上層に形成し、内部の回路を水分や汚染、機械的な傷から守る膜を何と呼ぶか。
  5. 多くのLSIで、ワイヤボンディングを行う最上層の電極パッドに使われてきた金属はどれか。
