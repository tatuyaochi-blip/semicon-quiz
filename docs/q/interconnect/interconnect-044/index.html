配線プロセス

Cu配線の上面に、絶縁膜側の拡散防止とエッチングストップを兼ねてつける膜として一般的なものはどれか。

  1. Aフォトレジスト
  2. Bポリシリコン
  3. CSiCNなどの誘電体キャップ膜
答えと解説を見る

正解：C. SiCNなどの誘電体キャップ膜

CMPで露出したCu配線の上面には、Cuが上の絶縁膜へ拡散するのを防ぎ、次の層のビアのエッチングを止める役割をもつSiCNやSiNなどの誘電体キャップ膜(厚さ数nm〜数十nm)をつけます。キャップと配線の界面はエレクトロマイグレーションの主な経路でもあるため、界面の密着性が信頼性を決めます。比誘電率が5前後と比較的高いため、配線間容量を増やさないよう薄くすることが求められます。

  • A. フォトレジストは加工用の一時的な膜です。
  • B. ポリシリコンは導電性があり、配線の上の絶縁キャップには使いません。
  • C. 正しい。SiCNなどの誘電体キャップ膜を使います。

配線プロセスのほかの問題

  1. エレクトロマイグレーションの試験で、ある長さより短い配線では寿命が大きく延びる(劣化がほとんど進まない)現象が知られている。この現象の名前はどれか。
  2. 配線の幅が結晶粒より細くなり、結晶粒界が配線を横切るように並んだ構造を何と呼び、エレクトロマイグレーションにどう影響するか。
  3. 高い周波数の信号が配線を流れるとき、電流が導体の表面付近に集中し、実効的な抵抗が上がる現象を何と呼ぶか。
  4. ワイヤボンディングなどを行う電極パッドの真下に、能動素子や配線を配置する設計を何と呼ぶか。
  5. Cuにマンガンなどを少量加えた合金を成膜し、熱処理で絶縁膜との界面に薄いバリア層を自然に形成させる技術はどれか。
