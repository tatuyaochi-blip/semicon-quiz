配線プロセス

上下の配線層の位置合わせのずれに強くするため、ビアを配線の溝に合わせて自己整合的に形成する技術はどれか。

  1. ATSV
  2. B自己整合ビア(セルフアラインビア)
  3. CLDD
答えと解説を見る

正解：B. 自己整合ビア(セルフアラインビア)

配線のピッチが狭くなると、ビアの位置が少しずれるだけで隣の配線とショートするおそれがあります。自己整合ビアでは、ビアのエッチングが配線の溝やハードマスクの範囲に制限されるようにして、位置合わせのずれがあっても隣の配線とつながらないようにします。

この分野を解く 分野ページへ

配線プロセスのほかの問題

  1. 抵抗率2 µΩ·cmの配線で、長さ1 mm、幅と厚さがそれぞれ100 nmのときの抵抗はおよそいくらか。
  2. エレクトロマイグレーションによるボイドが発生しやすい場所として正しいものはどれか。
  3. 微細化が進んだLSIで、ゲートの遅延と比べた配線の遅延の傾向として正しいものはどれか。
  4. Low-k膜をエッチングやアッシングで加工するときに注意すべき問題として正しいものはどれか。
  5. 配線どうしの間隔が狭くなることで重要性が増している、配線間の絶縁膜の経時的な絶縁破壊を何と呼ぶか。
