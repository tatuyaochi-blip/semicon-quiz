配線プロセス

配線の溝とビアを同時にCuで埋め込み、1回のCMPで形成する方法を何と呼ぶか。

  1. Aシングルダマシン法
  2. Bエッチバック法
  3. Cデュアルダマシン法
答えと解説を見る

正解：C. デュアルダマシン法

デュアルダマシン法では、絶縁膜にビアの穴と配線の溝の両方をリソグラフィとエッチングで形成してから、バリア層、シード層、Cuめっきでまとめて埋め込み、1回のCMPで仕上げます。ビアと配線を別々につくるシングルダマシン法より、成膜・めっき・CMPがそれぞれ1回ずつ減り、ビアと配線の間にバリアの界面もできないため抵抗と信頼性の面でも有利です。穴と溝のどちらを先に開けるかで方式が分かれます。

配線プロセスのほかの問題

  1. Cuを電解めっきで埋め込む前に、スパッタリングで薄く形成するCu膜の役割として正しいものはどれか。
  2. Cuの埋め込みが不十分で、ビアの中に空洞(ボイド)が残ると起こる問題として正しいものはどれか。
  3. 同じ層で隣り合う配線の間隔を半分にすると、その配線間の容量はおよそどうなるか。(平行平板として近似する)
  4. 上下の配線層の位置合わせのずれに強くするため、ビアを配線の溝に合わせて自己整合的に形成する技術はどれか。
  5. 抵抗率2 µΩ·cmの配線で、長さ1 mm、幅と厚さがそれぞれ100 nmのときの抵抗はおよそいくらか。
