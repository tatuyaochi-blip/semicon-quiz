配線プロセス

配線どうしの間隔が狭くなることで重要性が増している、配線間の絶縁膜の経時的な絶縁破壊を何と呼ぶか。

  1. A配線間TDDB(BEOL TDDB)
  2. BNBTI
  3. CHCI
答えと解説を見る

正解：A. 配線間TDDB(BEOL TDDB)

配線どうしの間隔が狭くなると、配線間の絶縁膜にかかる電界が強くなり、長時間の使用で絶縁破壊が起こるおそれがあります。特にLow-k膜は従来の酸化膜より絶縁耐性が低い傾向があるため、配線間TDDBは配線の信頼性の重要な評価項目になっています。

配線プロセスのほかの問題

  1. LSIの中の配線の主な役割はどれか。
  2. LSIの「多層配線」の説明として正しいものはどれか。
  3. 室温での銅(Cu)の抵抗率に最も近い値はどれか。(バルクの値)
  4. LSIの配線材料に求められる主な性質の組み合わせとして正しいものはどれか。
  5. 配線と配線の間を埋める層間絶縁膜の基本的な役割はどれか。
