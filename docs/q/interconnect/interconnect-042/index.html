配線プロセス

配線の幅を変えずに厚さ(高さ)を大きくしたときの影響として正しいものはどれか。

  1. A抵抗も容量も変わらない
  2. B抵抗も容量も下がる
  3. C抵抗は下がるが、隣の配線と向かい合う面積が増えて配線間の容量は上がる
答えと解説を見る

正解：C. 抵抗は下がるが、隣の配線と向かい合う面積が増えて配線間の容量は上がる

配線を厚くすると断面積が増えて抵抗は下がります。一方、隣の配線と向かい合う側面の面積が増えるため、配線間の容量は大きくなります。そのため、遅延や消費電力、クロストークのバランスを考えて配線の厚さ(アスペクト比)を決めます。

  • A. 断面積と向かい合う面積が変わるので、どちらも変わります。
  • B. 容量は向かい合う面積が増えて上がります。
  • C. 正しい。抵抗は下がり、容量は上がります。

配線プロセスのほかの問題

  1. 機械的に弱いLow-k膜を使ったチップで、パッケージに実装するときの応力によって膜が割れたりはがれたりする問題を何と呼ぶか。
  2. Cu配線の上面に、絶縁膜側の拡散防止とエッチングストップを兼ねてつける膜として一般的なものはどれか。
  3. エレクトロマイグレーションの試験で、ある長さより短い配線では寿命が大きく延びる(劣化がほとんど進まない)現象が知られている。この現象の名前はどれか。
  4. 配線の幅が結晶粒より細くなり、結晶粒界が配線を横切るように並んだ構造を何と呼び、エレクトロマイグレーションにどう影響するか。
  5. 高い周波数の信号が配線を流れるとき、電流が導体の表面付近に集中し、実効的な抵抗が上がる現象を何と呼ぶか。
