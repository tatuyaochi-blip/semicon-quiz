配線プロセス

ある配線の容量について、正しい説明はどれか。

  1. A同じ層の隣の配線との容量だけを考えればよい
  2. B同じ層の隣の配線との容量に加えて、上下の層の配線や基板との容量もある
  3. C配線には容量はない
答えと解説を見る

正解：B. 同じ層の隣の配線との容量に加えて、上下の層の配線や基板との容量もある

配線の容量は、同じ層で隣り合う配線との間(横方向)の容量に加えて、上下の層の配線や基板との間(縦方向)の容量も合わせたものです。配線のピッチが詰まると横方向の容量の割合が大きくなります。

  • A. 上下の層や基板との容量も無視できません。
  • B. 正しい。横方向と縦方向の容量があります。
  • C. 配線は周囲の導体との間に必ず容量をもちます。

配線プロセスのほかの問題

  1. 配線の幅を変えずに厚さ(高さ)を大きくしたときの影響として正しいものはどれか。
  2. 機械的に弱いLow-k膜を使ったチップで、パッケージに実装するときの応力によって膜が割れたりはがれたりする問題を何と呼ぶか。
  3. Cu配線の上面に、絶縁膜側の拡散防止とエッチングストップを兼ねてつける膜として一般的なものはどれか。
  4. エレクトロマイグレーションの試験で、ある長さより短い配線では寿命が大きく延びる(劣化がほとんど進まない)現象が知られている。この現象の名前はどれか。
  5. 配線の幅が結晶粒より細くなり、結晶粒界が配線を横切るように並んだ構造を何と呼び、エレクトロマイグレーションにどう影響するか。
