配線プロセス

エレクトロマイグレーションによる配線の寿命を表すブラックの式で、寿命を短くする要因として正しいものはどれか。

  1. A配線を太くすること
  2. B電流密度が高いことと、温度が高いこと
  3. C温度を下げること
答えと解説を見る

正解：B. 電流密度が高いことと、温度が高いこと

ブラックの式では、平均故障時間が「電流密度のn乗に反比例し、exp(Ea/kT)に比例する」と表されます。電流密度が高いほど、また温度が高いほど寿命は短くなります。設計では、配線ごとに流してよい電流密度の上限が決められています。

配線プロセスのほかの問題

  1. 先端ロジックLSIの配線層の数として最も近いものはどれか。
  2. Cuに代わる微細配線の材料として検討されているルテニウム(Ru)などの金属の利点として正しいものはどれか。
  3. チップの最上層に形成し、内部の回路を水分や汚染、機械的な傷から守る膜を何と呼ぶか。
  4. 多くのLSIで、ワイヤボンディングを行う最上層の電極パッドに使われてきた金属はどれか。
  5. 配線の溝とビアを同時にCuで埋め込み、1回のCMPで形成する方法を何と呼ぶか。
