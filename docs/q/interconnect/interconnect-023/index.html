配線プロセス

Cuの埋め込みが不十分で、ビアの中に空洞(ボイド)が残ると起こる問題として正しいものはどれか。

  1. A抵抗の増加や断線、エレクトロマイグレーション耐性の低下
  2. B配線が発光する
  3. C配線間の容量が0になる
答えと解説を見る

正解：A. 抵抗の増加や断線、エレクトロマイグレーション耐性の低下

ビアの中にボイドがあると、電流の通り道が狭くなって抵抗が上がり、ひどい場合は断線します。また、局所的に電流密度が高くなるため、エレクトロマイグレーションによる故障も起こりやすくなります。めっき液の添加剤や条件の最適化で、ボイドのない埋め込みを実現しています。

配線プロセスのほかの問題

  1. 同じ層で隣り合う配線の間隔を半分にすると、その配線間の容量はおよそどうなるか。(平行平板として近似する)
  2. 上下の配線層の位置合わせのずれに強くするため、ビアを配線の溝に合わせて自己整合的に形成する技術はどれか。
  3. 抵抗率2 µΩ·cmの配線で、長さ1 mm、幅と厚さがそれぞれ100 nmのときの抵抗はおよそいくらか。
  4. エレクトロマイグレーションによるボイドが発生しやすい場所として正しいものはどれか。
  5. 微細化が進んだLSIで、ゲートの遅延と比べた配線の遅延の傾向として正しいものはどれか。
