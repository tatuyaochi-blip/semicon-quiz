配線プロセス

先端LSIの配線材料が、アルミニウム(Al)から銅(Cu)に置き換えられた主な理由はどれか。

  1. A抵抗率が低く、エレクトロマイグレーション耐性も高いため
  2. Bドライエッチングで加工しやすいため
  3. C酸化膜との密着性が非常に高く、バリア層が不要なため
答えと解説を見る

正解：A. 抵抗率が低く、エレクトロマイグレーション耐性も高いため

Cuは抵抗率がAlの約6割と低く、配線遅延を減らせます。またエレクトロマイグレーションに対する耐性も高いという利点があります。一方、Cuはドライエッチングが難しく、絶縁膜中に拡散しやすいため、ダマシン法で形成し、TaやTaNなどのバリア層で囲んで使います。

配線プロセスのほかの問題

  1. Cu配線の形成に一般的に用いられるダマシン法の説明として正しいものはどれか。
  2. 層間絶縁膜にLow-k(低誘電率)材料を用いる主な目的はどれか。
  3. Cu配線で、TaやTaNなどのバリアメタルを設ける主な目的はどれか。
  4. 多層配線におけるビアの説明として正しいものはどれか。
  5. 配線の断面形状や配線間隔を変えずに、配線の長さを2倍にすると、配線のRC遅延はおよそ何倍になるか。
