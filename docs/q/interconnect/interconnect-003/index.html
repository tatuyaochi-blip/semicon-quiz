配線プロセス

層間絶縁膜にLow-k(低誘電率)材料を用いる主な目的はどれか。

  1. A配線の抵抗を下げる
  2. B層間絶縁膜の機械的強度を高める
  3. C配線間の寄生容量を下げ、RC遅延を低減する
答えと解説を見る

正解：C. 配線間の寄生容量を下げ、RC遅延を低減する

配線の間隔が狭くなると配線間の容量が大きくなり、信号の遅延(RC遅延)や消費電力が増えます。誘電率の低い絶縁膜を使うと容量を減らせます。ただしLow-k材料は多孔質などで機械的強度が低い傾向があり、CMPやパッケージ工程での扱いが課題になります。

配線プロセスのほかの問題

  1. Cu配線で、TaやTaNなどのバリアメタルを設ける主な目的はどれか。
  2. 多層配線におけるビアの説明として正しいものはどれか。
  3. 配線の断面形状や配線間隔を変えずに、配線の長さを2倍にすると、配線のRC遅延はおよそ何倍になるか。
  4. トランジスタのソース・ドレインやゲートの表面に、NiSiなどのシリサイドを形成する目的はどれか。
  5. トランジスタと最下層の配線をつなぐコンタクトホールの埋め込みに広く使われてきた金属はどれか。
