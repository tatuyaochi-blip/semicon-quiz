配線プロセス

先端ロジックLSIの配線層の数として最も近いものはどれか。

  1. A1層
  2. B3層
  3. C10層以上
答えと解説を見る

正解：C. 10層以上

先端のロジックLSIでは、トランジスタの上に10層を超える多層配線が形成されます。下層には微細な配線、上層には太く厚い電源やグローバル配線を配置します。配線工程(BEOL)の工程数は、トランジスタをつくる工程に匹敵するほど多くなっています。

この分野を解く 分野ページへ

配線プロセスのほかの問題

  1. Cuに代わる微細配線の材料として検討されているルテニウム(Ru)などの金属の利点として正しいものはどれか。
  2. チップの最上層に形成し、内部の回路を水分や汚染、機械的な傷から守る膜を何と呼ぶか。
  3. 多くのLSIで、ワイヤボンディングを行う最上層の電極パッドに使われてきた金属はどれか。
  4. 配線の溝とビアを同時にCuで埋め込み、1回のCMPで形成する方法を何と呼ぶか。
  5. Cuを電解めっきで埋め込む前に、スパッタリングで薄く形成するCu膜の役割として正しいものはどれか。
