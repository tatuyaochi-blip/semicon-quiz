配線プロセス

アルミニウム配線に、銅を0.5%程度添加したAl-Cu合金が使われてきた主な理由はどれか。

  1. Aエレクトロマイグレーションに対する耐性を高めるため
  2. B抵抗率を大幅に下げるため
  3. C配線の色を変えるため
答えと解説を見る

正解：A. エレクトロマイグレーションに対する耐性を高めるため

純アルミニウムの配線は、電流による原子の移動(エレクトロマイグレーション)でボイドやヒロックができやすいという問題がありました。少量の銅を添加すると、銅が結晶粒界に偏析してアルミニウム原子の粒界での移動を抑え、寿命が大きく延びます。

  • A. 正しい。エレクトロマイグレーションへの耐性を高めます。
  • B. 少量の銅の添加で抵抗率はむしろわずかに上がります。
  • C. 色を変えるためではありません。

配線プロセスのほかの問題

  1. 電解めっきで形成したCu膜が、室温で放置するだけでも時間とともに結晶粒が大きくなり、抵抗率が下がる現象を何と呼ぶか。
  2. 配線の上下をつなぐビアを、可能な場所では1個でなく2個以上並べて配置する設計上の工夫の主な目的はどれか。
  3. トランジスタ(FEOL側)と多層配線をつなぐ、コンタクトや局所的な配線の部分を指して使われる言葉はどれか。
  4. 微細化が進んだ多層配線で、ビアの抵抗が問題になってきた主な理由として正しいものはどれか。
  5. ある配線の容量について、正しい説明はどれか。
