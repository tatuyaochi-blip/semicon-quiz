配線プロセス

数GHzで動作するチップのクロック配線のように長く太い配線で、抵抗と容量に加えて考慮が必要になる配線の性質はどれか。

  1. A密度
  2. Bインダクタンス
  3. C色
答えと解説を見る

正解：B. インダクタンス

抵抗の小さい太く長い配線で信号の立ち上がりが数十psと速くなると、配線のインダクタンス(L·di/dt)の影響が無視できなくなり、信号の反射やオーバーシュート、遅延の変化が生じます。インダクタンスは電流の帰り道との距離で決まるため、クロック配線や電源網の設計では、近くにグラウンド配線を並べて帰り道を明確にし、伝送線路として扱って解析します。

  • A. 密度は配線の電気的なふるまいを表す主な量ではありません。
  • B. 正しい。高速では配線のインダクタンスも考慮が必要です。
  • C. 色は電気的な特性ではありません。

  3. 層間絶縁膜にLow-k(低誘電率)材料を用いる主な目的はどれか。
  4. Cu配線で、TaやTaNなどのバリアメタルを設ける主な目的はどれか。
  5. 多層配線におけるビアの説明として正しいものはどれか。
