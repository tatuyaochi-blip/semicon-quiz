配線プロセス

Cu配線で、TaやTaNなどのバリアメタルを設ける主な目的はどれか。

  1. A配線の抵抗を下げる
  2. BCuが絶縁膜やシリコンへ拡散するのを防ぐ
  3. CCuの表面を酸化させる
答えと解説を見る

正解：B. Cuが絶縁膜やシリコンへ拡散するのを防ぐ

Cuは絶縁膜やシリコン中に拡散しやすく、トランジスタの特性を劣化させたり、配線間の絶縁を悪くしたりします。そのため、Cu配線の周りをTa/TaNなどのバリアメタルで囲み、拡散を防いでいます。バリアメタルは絶縁膜との密着性を高める役割もあります。

配線プロセスのほかの問題

  1. 多層配線におけるビアの説明として正しいものはどれか。
  2. 配線の断面形状や配線間隔を変えずに、配線の長さを2倍にすると、配線のRC遅延はおよそ何倍になるか。
  3. トランジスタのソース・ドレインやゲートの表面に、NiSiなどのシリサイドを形成する目的はどれか。
  4. トランジスタと最下層の配線をつなぐコンタクトホールの埋め込みに広く使われてきた金属はどれか。
  5. Cu配線の幅が非常に細くなると、配線の実効的な抵抗率が上昇する主な理由はどれか。
