配線プロセス

微細化が進んだ多層配線で、ビアの抵抗が問題になってきた主な理由として正しいものはどれか。

  1. Aビアの断面積が小さくなり、さらに抵抗の高いバリアメタルが占める割合が大きくなるため
  2. Bビアが長くなったため
  3. Cビアに電流が流れなくなったため
答えと解説を見る

正解：A. ビアの断面積が小さくなり、さらに抵抗の高いバリアメタルが占める割合が大きくなるため

ビアが細くなると、断面積が小さくなって抵抗が上がるうえ、Cuの拡散を防ぐための抵抗の高いバリアメタルの厚さはあまり薄くできないため、ビアに占めるその割合が大きくなります。そのため、バリアを薄くする技術や別の材料が検討されています。

  • A. 正しい。断面積の縮小とバリアの割合の増加が原因です。
  • B. 微細化でビアが長くなるわけではありません。
  • C. ビアにも電流は流れます。

配線プロセスのほかの問題

  1. ある配線の容量について、正しい説明はどれか。
  2. 配線の幅を変えずに厚さ(高さ)を大きくしたときの影響として正しいものはどれか。
  3. 機械的に弱いLow-k膜を使ったチップで、パッケージに実装するときの応力によって膜が割れたりはがれたりする問題を何と呼ぶか。
  4. Cu配線の上面に、絶縁膜側の拡散防止とエッチングストップを兼ねてつける膜として一般的なものはどれか。
  5. エレクトロマイグレーションの試験で、ある長さより短い配線では寿命が大きく延びる(劣化がほとんど進まない)現象が知られている。この現象の名前はどれか。
