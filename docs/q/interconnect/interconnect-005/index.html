配線プロセス

多層配線におけるビアの説明として正しいものはどれか。

  1. A上下の配線層の間を電気的に接続する導体
  2. B同じ層の隣り合う配線を絶縁する膜
  3. Cチップとパッケージを接続する金属線
答えと解説を見る

正解：A. 上下の配線層の間を電気的に接続する導体

ビアは、層間絶縁膜にあけた穴に金属を埋め込んで、上の層と下の層の配線をつなぐ導体です。トランジスタと最下層の配線をつなぐものはコンタクトと呼ばれます。デュアルダマシン法では、配線の溝とビアを一度にCuで埋め込みます。

配線プロセスのほかの問題

  1. 配線の断面形状や配線間隔を変えずに、配線の長さを2倍にすると、配線のRC遅延はおよそ何倍になるか。
  2. トランジスタのソース・ドレインやゲートの表面に、NiSiなどのシリサイドを形成する目的はどれか。
  3. トランジスタと最下層の配線をつなぐコンタクトホールの埋め込みに広く使われてきた金属はどれか。
  4. Cu配線の幅が非常に細くなると、配線の実効的な抵抗率が上昇する主な理由はどれか。
  5. 多層配線で、上層の配線ほど太く厚くする主な理由はどれか。
