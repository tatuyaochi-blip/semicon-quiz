配線プロセス

Cuにマンガンなどを少量加えた合金を成膜し、熱処理で絶縁膜との界面に薄いバリア層を自然に形成させる技術はどれか。

  1. A自己形成バリア
  2. BLOCOS
  3. Cイオン注入
答えと解説を見る

正解：A. 自己形成バリア

Cu-Mn合金のシード層を使うと、熱処理でMnが界面に移動して絶縁膜のSiO2と反応し、厚さ数nm以下のMnSiOxなどのバリア層が自然にできます。Mnは界面に集まるため、残ったCu内部の不純物も減ります。別にバリアメタルを厚く成膜する必要が減るため、細い配線やビアで低抵抗のCuの割合を増やせ、日本の研究グループが開発を主導した技術の一つです。

  • A. 正しい。界面にバリアを自然に形成する技術です。
  • B. LOCOSは選択酸化による素子分離です。
  • C. イオン注入は不純物を打ち込む工程です。

配線プロセスのほかの問題

  1. 数GHzで動作するチップのクロック配線のように長く太い配線で、抵抗と容量に加えて考慮が必要になる配線の性質はどれか。
  2. 裏面電源供給の製造では、表面にトランジスタと配線をつくったウエハを支持用のウエハに貼り合わせ、元の基板を裏面から薄くしてから裏面の電源配線をつくる。この工程で特に難しくなることとして正しいものはどれか。
  3. 先端LSIの配線材料が、アルミニウム(Al)から銅(Cu)に置き換えられた主な理由はどれか。
  4. Cu配線の形成に一般的に用いられるダマシン法の説明として正しいものはどれか。
  5. 層間絶縁膜にLow-k(低誘電率)材料を用いる主な目的はどれか。
