配線プロセス

先端ロジックで導入が進む裏面電源供給(バックサイドパワーデリバリー)の説明として正しいものはどれか。

  1. A電源をチップの外から供給しない方式
  2. Bすべての配線を光ファイバーに置き換える方式
  3. C電源配線をウエハの裏面側に配置し、表面の配線を信号用に使えるようにして、電圧降下や配線の混雑を減らす方式
答えと解説を見る

正解：C. 電源配線をウエハの裏面側に配置し、表面の配線を信号用に使えるようにして、電圧降下や配線の混雑を減らす方式

従来は信号配線と電源配線をすべてトランジスタの上側(表面側)の配線層でつくっていました。裏面電源供給では、ウエハを薄くして裏側に電源配線を設け、トランジスタに下から電源を供給します。電源配線を太く短くでき、表面側の配線を信号に使えるようになります。

この分野を解く 分野ページへ

配線プロセスのほかの問題

  1. 電源配線の抵抗に電流が流れることで、回路に届く電源電圧が下がる現象を何と呼ぶか。
  2. 隣り合う配線の間の容量結合によって、一方の信号の変化がもう一方の信号に雑音として現れる現象を何と呼ぶか。
  3. Cu配線の上面にコバルトなどのキャップ層を設ける主な目的はどれか。
  4. エレクトロマイグレーションによる配線の寿命を表すブラックの式で、寿命を短くする要因として正しいものはどれか。
  5. 先端ロジックLSIの配線層の数として最も近いものはどれか。
