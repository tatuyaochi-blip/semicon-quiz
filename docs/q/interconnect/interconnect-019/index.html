配線プロセス

チップの最上層に形成し、内部の回路を水分や汚染、機械的な傷から守る膜を何と呼ぶか。

  1. Aゲート酸化膜
  2. Bパッシベーション膜
  3. C埋め込み酸化膜
答えと解説を見る

正解：B. パッシベーション膜

パッシベーション膜は、チップの表面を覆う保護膜で、シリコン窒化膜や酸化膜、さらにポリイミドなどの樹脂膜が使われます。水分やイオンの侵入、組み立て時の傷から回路を守り、製品の信頼性を高めます。電極パッドの部分だけは開口してあります。

この分野を解く 分野ページへ

配線プロセスのほかの問題

  1. 多くのLSIで、ワイヤボンディングを行う最上層の電極パッドに使われてきた金属はどれか。
  2. 配線の溝とビアを同時にCuで埋め込み、1回のCMPで形成する方法を何と呼ぶか。
  3. Cuを電解めっきで埋め込む前に、スパッタリングで薄く形成するCu膜の役割として正しいものはどれか。
  4. Cuの埋め込みが不十分で、ビアの中に空洞(ボイド)が残ると起こる問題として正しいものはどれか。
  5. 同じ層で隣り合う配線の間隔を半分にすると、その配線間の容量はおよそどうなるか。(平行平板として近似する)
