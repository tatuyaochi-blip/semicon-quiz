配線プロセス

LSIの配線材料に求められる主な性質の組み合わせとして正しいものはどれか。

  1. A電気を通さず、熱を通さないこと
  2. B抵抗が低く、電流による劣化(エレクトロマイグレーション)に強く、加工しやすいこと
  3. C光をよく通し、柔らかいこと
答えと解説を見る

正解：B. 抵抗が低く、電流による劣化(エレクトロマイグレーション)に強く、加工しやすいこと

配線材料には、信号の遅延や電力の損失を減らすための低い抵抗、大きな電流密度でも劣化しにくい信頼性、そして微細なパターンに加工・埋め込みしやすいことが求められます。これらのバランスから、AlからCuへ、さらに極微細な部分では他の金属へと材料が変わってきました。

  • A. 電気を通さない材料は配線になりません。
  • B. 正しい。低抵抗・信頼性・加工性が求められます。
  • C. 光を通すことは配線には求められません。

配線プロセスのほかの問題

  1. 配線と配線の間を埋める層間絶縁膜の基本的な役割はどれか。
  2. アルミニウム配線に、銅を0.5%程度添加したAl-Cu合金が使われてきた主な理由はどれか。
  3. 電解めっきで形成したCu膜が、室温で放置するだけでも時間とともに結晶粒が大きくなり、抵抗率が下がる現象を何と呼ぶか。
  4. 配線の上下をつなぐビアを、可能な場所では1個でなく2個以上並べて配置する設計上の工夫の主な目的はどれか。
  5. トランジスタ(FEOL側)と多層配線をつなぐ、コンタクトや局所的な配線の部分を指して使われる言葉はどれか。
