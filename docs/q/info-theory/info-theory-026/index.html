情報理論と符号の基礎

4ビットのデータ4行について、各行の右端に行の偶数パリティのビットを、最後に各列の偶数パリティを並べた行を付けて送った(垂直水平パリティ)。受信したビットは、1行目 1011 1、2行目 0100 0、3行目 1100 0、4行目 0101 0、パリティの行 0100 であった(各行の右端の1ビットが行のパリティ)。1ビットだけが誤っているとき、誤ったビットの位置はどれか。

  1. A1行目の3列目
  2. B2行目の3列目
  3. C3行目の2列目
答えと解説を見る

正解：B. 2行目の3列目

各行で、パリティを含めた1の個数を数えると、1行目は4、2行目は1、3行目は2、4行目は2で、奇数になるのは2行目だけです。各列で、パリティの行を含めた1の個数を数えると、1列目は2、2列目は4、3列目は1、4列目は2で、奇数になるのは3列目だけです。したがって、2行目と3列目が交わるビットが誤っており、これを反転すれば訂正できます。

  • A. 1行目は1の個数が4で偶数なので、1行目には誤りがありません。
  • B. 正しい。奇数になる行と列が1つずつあり、その交点が誤ったビットです。
  • C. 行と列を取り違えています。3行目は1の個数が2で偶数なので、誤りがありません。

情報理論と符号の基礎のほかの問題

  1. データを1バイトずつ足し合わせ、和の下位8ビットを検査値(チェックサム)として付けて送る。この検査で検出できない誤りはどれか。
  2. データ 1101 に、生成多項式 x³ + x + 1(ビット列 1011)のCRCの検査ビット3ビットを付ける。検査ビットは、データの後ろに0を3つ付けた 1101000 を 1011 で割った余りで、割り算では引き算の代わりに排他的論理和を使う。検査ビットはどれか。
  3. 生成多項式の次数がr(検査ビットがrビット)で、定数項が1のCRCの性質として、正しいものはどれか。
  4. 2つの7ビットの符号語 1011010 と 0110011 のハミング距離はどれか。
  5. ある符号の最小ハミング距離(どの2つの符号語の間のハミング距離のうちの最小値)が5である。誤りの検出だけに使う場合と、訂正だけに使う場合を考える。確実に検出できる誤りのビット数と、確実に訂正できる誤りのビット数の組み合わせとして、正しいものはどれか。
