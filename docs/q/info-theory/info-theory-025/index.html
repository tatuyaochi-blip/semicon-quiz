情報理論と符号の基礎

データのビット列に、1の個数が偶数になるように偶数パリティのビットを1つ付けて送る。受信側で1の個数を調べる検査の性質として、正しいものはどれか。

  1. A1ビットの誤りを検出でき、どのビットが誤ったかも分かるので、受信側で訂正できる
  2. B2ビットが同時に誤ったときも、1ビットのときと同じように誤りを検出できる
  3. C誤ったビットの数が奇数なら検出できるが、偶数なら検出できない
答えと解説を見る

正解：C. 誤ったビットの数が奇数なら検出できるが、偶数なら検出できない

1ビットが反転すると1の個数の偶奇が変わるので、検査で誤りが分かります。2ビットが反転すると偶奇が元に戻るため、誤りに気づけません。一般に、奇数個の誤りは検出でき、偶数個の誤りは検出できません。また、どのビットが誤ったかは分からないので訂正はできず、送り直してもらうなどの対応が必要です。

  • A. 誤りがあることは分かりますが、どのビットかは分かりません。訂正にはハミング符号などが必要です。
  • B. 2ビットが反転すると1の個数の偶奇が元に戻るので、検出できません。
  • C. 正しい。1の個数の偶奇が変わるのは、奇数個のビットが誤ったときだけです。

情報理論と符号の基礎のほかの問題

  1. 4ビットのデータ4行について、各行の右端に行の偶数パリティのビットを、最後に各列の偶数パリティを並べた行を付けて送った(垂直水平パリティ)。受信したビットは、1行目 1011 1、2行目 0100 0、3行目 1100 0、4行目 0101 0、パリティの行 0100 であった(各行の右端の1ビットが行のパリティ)。1ビットだけが誤っているとき、誤ったビットの位置はどれか。
  2. データを1バイトずつ足し合わせ、和の下位8ビットを検査値(チェックサム)として付けて送る。この検査で検出できない誤りはどれか。
  3. データ 1101 に、生成多項式 x³ + x + 1(ビット列 1011)のCRCの検査ビット3ビットを付ける。検査ビットは、データの後ろに0を3つ付けた 1101000 を 1011 で割った余りで、割り算では引き算の代わりに排他的論理和を使う。検査ビットはどれか。
  4. 生成多項式の次数がr(検査ビットがrビット)で、定数項が1のCRCの性質として、正しいものはどれか。
  5. 2つの7ビットの符号語 1011010 と 0110011 のハミング距離はどれか。
