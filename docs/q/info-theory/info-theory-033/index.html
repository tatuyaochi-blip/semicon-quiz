情報理論と符号の基礎

4ビットのデータに3ビットの検査ビットを付けて7ビットの符号語にする、ハミング符号(7, 4)の符号化率に最も近いものはどれか。

  1. A約0.43
  2. B約0.57
  3. C1.75
答えと解説を見る

正解：B. 約0.57

符号化率は、符号語の長さnのうち、データのビット数kが占める割合 k/n です。ハミング符号(7, 4)では 4/7 ≈ 0.57 で、送るビットの約57%がデータです。符号化率が低いほど、検査ビットが多く誤りに強くしやすい一方、データを送る効率は下がります。

  • A. 約0.43は 3/7 で、符号語のうち検査ビットが占める割合です。
  • B. 正しい。4/7 ≈ 0.57 です。
  • C. 1.75は 7/4 で、分子と分母が逆です。符号化率は1以下の値になります。

情報理論と符号の基礎のほかの問題

  1. ハミング符号(7, 4)で、7ビットを左から1〜7ビット目とし、1、2、4ビット目を検査ビットとする。検査1は1、3、5、7ビット目、検査2は2、3、6、7ビット目、検査4は4、5、6、7ビット目の1の個数が、それぞれ偶数になるように作る。受信した 0110001 に1ビットの誤りがあるとき、誤ったビットはどれか。
  2. 32ビットのデータに、1ビットの誤りを訂正し、2ビットの誤りを検出できるSECDED符号を付ける。ハミング符号の検査ビットの数rは、2^r ≥ データのビット数 + r + 1 を満たす最小の値で、SECDEDではこれに全体のパリティを1ビット加える。必要な検査ビットの数はどれか。
  3. ハミング符号(7, 4)の符号語を5つ並べ、各符号語の1ビット目を5つ、次に2ビット目を5つ、という順に送る(深さ5のインターリーブ)。受信側で元の順に並べ戻してから、符号語ごとに1ビットの誤りを訂正する。連続したビットに集中して起こるバースト誤りのうち、必ず訂正できる最大の長さはどれか。
  4. 通信で誤りに対処する方式のARQ(自動再送要求)とFEC(前方誤り訂正)の説明として、正しいものはどれか。
  5. 0と1を送り、各ビットが互いに独立に確率0.1で反転する二元対称通信路がある。2値のエントロピー関数を H(p) = −p log₂ p − (1 − p) log₂(1 − p) とすると、H(0.1) ≈ 0.469 である。この通信路の、1回の伝送あたりの通信路容量に最も近いものはどれか。
