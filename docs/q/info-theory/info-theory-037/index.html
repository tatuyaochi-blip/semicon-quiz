情報理論と符号の基礎

通信で誤りに対処する方式のARQ(自動再送要求)とFEC(前方誤り訂正)の説明として、正しいものはどれか。

  1. AARQは、受信側だけで誤りを訂正するので、送信側へ知らせを返す通信路が要らない
  2. BFECは、誤りを検出したら送り直しを求めるので、誤りが多いと遅延が大きくなりやすい
  3. CFECは、冗長なビットを使って受信側で誤りを訂正するので、片方向の放送にも使える
答えと解説を見る

正解：C. FECは、冗長なビットを使って受信側で誤りを訂正するので、片方向の放送にも使える

ARQは、CRCなどで誤りを検出し、受け取れなかったことを送信側に知らせて送り直してもらう方式で、戻りの通信路が必要で、送り直しの分だけ遅れます。FECは、冗長なビットを付けて送り、受信側だけで誤りを訂正するので、片方向の放送や、往復に時間のかかる宇宙との通信、遅れの許されない通信に向きます。実際の通信では、FECで大部分の誤りを直し、残った誤りをARQで送り直す組み合わせもよく使われます。

  • A. これはFECの性質です。ARQは送り直しを求めるので、受信側から送信側への通信路が必要です。
  • B. これはARQの性質です。FECは送り直しを求めずに、受信側で訂正します。
  • C. 正しい。受信側だけで訂正できるので、戻りの通信路がなくても使えます。

情報理論と符号の基礎のほかの問題

  1. 0と1を送り、各ビットが互いに独立に確率0.1で反転する二元対称通信路がある。2値のエントロピー関数を H(p) = −p log₂ p − (1 − p) log₂(1 − p) とすると、H(0.1) ≈ 0.469 である。この通信路の、1回の伝送あたりの通信路容量に最も近いものはどれか。
  2. シャノンの通信路符号化定理の内容として、正しいものはどれか。
  3. グレイコードを通常の2進数に直すには、最上位のビットはそのまま使い、それより下位のビットは、1つ上位の位置で求めた2進数のビットと、同じ位置のグレイコードのビットとの排他的論理和で求める。4ビットのグレイコード 1101 を2進数に直したものはどれか。
  4. 事象の確率をpとするとき、その事象が起こったと知らされて得られる情報量を −log₂ p ビットとする。確率1/8で起こる事象が起こったと知らされたときの情報量はどれか。
  5. 情報量(確率pの事象が起こったと知らされたときの −log₂ p)の性質として、正しいものはどれか。
