情報理論と符号の基礎

記号A、B、C、Dに、符号語 A = 0、B = 10、C = 110、D = 111 を割り当てた接頭符号がある。ビット列 110100111 を先頭から復号した結果はどれか。

  1. ACABD
  2. BCBDA
  3. CCBAD
答えと解説を見る

正解：C. CBAD

先頭から読み、符号語に一致した時点で区切ります。110 で C、続く 10 で B、0 で A、残りの 111 で D となり、CBAD です。接頭符号なので、このように区切り方が1通りに決まり、区切りの記号を入れなくても復号できます。

  • A. CABD を符号化すると 110、0、10、111 で 110010111 となり、与えられたビット列と異なります。
  • B. CBDA を符号化すると 110、10、111、0 で 110101110 となり、与えられたビット列と異なります。
  • C. 正しい。110、10、0、111 と区切れます。

情報理論と符号の基礎のほかの問題

  1. 4つの記号A〜Dに、次の長さ(ビット数)の符号語を割り当てて、0と1からなる接頭符号を作りたい。作ることができる符号長の組み合わせはどれか。
  2. 0と1からなる接頭符号を作っている。長さ2の符号語 00 と 01 をすでに使っているとき、接頭符号の条件を保ったまま追加できる、長さ3の符号語の最大の個数はどれか。
  3. 記号A、B、C、Dを確率0.4、0.3、0.2、0.1で、互いに独立に出す情報源を、ハフマン符号で符号化する。1記号あたりの平均符号長はどれか。
  4. 記号A〜Eを確率0.3、0.25、0.2、0.15、0.1で、互いに独立に出す情報源を、ハフマン符号で符号化する。等しい確率のものをどちらから選ぶかで符号語は変わることがあるが、平均符号長は変わらない。1記号あたりの平均符号長はどれか。
  5. 記号A、B、Cを確率0.6、0.3、0.1で、互いに独立に出す情報源があり、そのエントロピーは約1.30ビットである。この情報源をハフマン符号で符号化したときの効率(エントロピー ÷ 平均符号長)に最も近いものはどれか。
