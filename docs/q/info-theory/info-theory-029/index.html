情報理論と符号の基礎

生成多項式の次数がr(検査ビットがrビット)で、定数項が1のCRCの性質として、正しいものはどれか。

  1. A1ビットの誤りなら、どのビットが誤ったかを特定して訂正することが、主な使い方である
  2. B長さがrビット以下のバースト誤り(連続した範囲に収まる誤り)は、すべて検出できる
  3. C生成多項式をうまく選べば、どのような誤りのパターンでも、すべて検出できる
答えと解説を見る

正解：B. 長さがrビット以下のバースト誤り(連続した範囲に収まる誤り)は、すべて検出できる

誤りのパターンを多項式 E(x) で表すと、CRCで検出できないのは、E(x) が生成多項式 G(x) で割り切れるときだけです。長さr以下のバースト誤りは x^i × B(x)(B(x) は次数がr − 1以下で、定数項が1)と書け、定数項が1のr次の G(x) では割り切れないので、必ず検出できます。一方、G(x) そのものの形の誤りのように、割り切れるパターンは検出できません。CRCは主に誤りの検出に使われ、誤りがあればデータを送り直してもらいます。

  • A. CRCは主に誤りの検出に使い、誤りがあれば送り直してもらいます。訂正には、ハミング符号などの誤り訂正符号を使います。
  • B. 正しい。長さr以下のバースト誤りは、生成多項式で割り切れないので、必ず検出できます。
  • C. 誤りのパターンが生成多項式で割り切れると、余りが変わらないので検出できません。どの生成多項式にも、このようなパターンがあります。

情報理論と符号の基礎のほかの問題

  1. 2つの7ビットの符号語 1011010 と 0110011 のハミング距離はどれか。
  2. ある符号の最小ハミング距離(どの2つの符号語の間のハミング距離のうちの最小値)が5である。誤りの検出だけに使う場合と、訂正だけに使う場合を考える。確実に検出できる誤りのビット数と、確実に訂正できる誤りのビット数の組み合わせとして、正しいものはどれか。
  3. 4つの符号語 00000、01011、10101、11110 からなる符号の、最小ハミング距離と、確実に訂正できる誤りのビット数の組み合わせとして、正しいものはどれか。
  4. 4ビットのデータに3ビットの検査ビットを付けて7ビットの符号語にする、ハミング符号(7, 4)の符号化率に最も近いものはどれか。
  5. ハミング符号(7, 4)で、7ビットを左から1〜7ビット目とし、1、2、4ビット目を検査ビットとする。検査1は1、3、5、7ビット目、検査2は2、3、6、7ビット目、検査4は4、5、6、7ビット目の1の個数が、それぞれ偶数になるように作る。受信した 0110001 に1ビットの誤りがあるとき、誤ったビットはどれか。
