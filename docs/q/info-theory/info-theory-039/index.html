情報理論と符号の基礎

シャノンの通信路符号化定理の内容として、正しいものはどれか。

  1. A伝送速度が通信路容量より小さければ、適切な符号化で誤り率をいくらでも小さくできる
  2. B誤り訂正符号を強くすれば、通信路容量を超える速度でも誤り率をいくらでも小さくできる
  3. C雑音のある通信路で誤り率を0に近づけるには、伝送速度も0に近づけるしかない
答えと解説を見る

正解：A. 伝送速度が通信路容量より小さければ、適切な符号化で誤り率をいくらでも小さくできる

通信路符号化定理は、通信路容量Cより小さい速度なら、十分に長い符号を使うことで誤り率をいくらでも小さくでき、Cを超える速度ではそれができないことを示します。定理は、そのような符号があることを示しますが、具体的な作り方までは示していません。現在は、LDPC符号やポーラー符号など、この限界(シャノン限界)に近い性能の符号が実用化されています。

  • A. 正しい。通信路容量より遅ければ、誤りをいくらでも少なくできる符号が存在します。
  • B. 通信路容量を超える速度では、どのような符号を使っても、誤り率を小さくすることはできません。
  • C. 同じビットを繰り返して送る方法では、速度を下げないと誤りが減りませんが、定理は、容量より小さい一定の速度のままでも誤りを減らせることを示しています。
