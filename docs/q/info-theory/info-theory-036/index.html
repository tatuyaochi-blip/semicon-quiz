情報理論と符号の基礎

ハミング符号(7, 4)の符号語を5つ並べ、各符号語の1ビット目を5つ、次に2ビット目を5つ、という順に送る(深さ5のインターリーブ)。受信側で元の順に並べ戻してから、符号語ごとに1ビットの誤りを訂正する。連続したビットに集中して起こるバースト誤りのうち、必ず訂正できる最大の長さはどれか。

  1. A5ビット
  2. B7ビット
  3. C35ビット
答えと解説を見る

正解：A. 5ビット

送るビット列では、同じ符号語のビットが5ビットおきに現れます。そのため、連続した5ビット以下のバースト誤りは、並べ戻すと5つの符号語に1ビットずつ以下に分かれ、どれもハミング符号で訂正できます。6ビットになると、どれかの符号語に2ビットの誤りが入り、訂正できなくなります。インターリーブを使わなければ、2ビットのバースト誤りでも1つの符号語に入ってしまいます。

  • A. 正しい。深さが5なので、5ビットまでのバースト誤りは、各符号語の1ビットずつに分かれます。
  • B. 7ビットは符号語の長さです。6ビットのバースト誤りで、すでにどれかの符号語に2ビットの誤りが入ります。
  • C. 35ビットは送るビット全体の数です。各符号語で訂正できるのは1ビットだけなので、そこまでは訂正できません。

情報理論と符号の基礎のほかの問題

  1. 通信で誤りに対処する方式のARQ(自動再送要求)とFEC(前方誤り訂正)の説明として、正しいものはどれか。
  2. 0と1を送り、各ビットが互いに独立に確率0.1で反転する二元対称通信路がある。2値のエントロピー関数を H(p) = −p log₂ p − (1 − p) log₂(1 − p) とすると、H(0.1) ≈ 0.469 である。この通信路の、1回の伝送あたりの通信路容量に最も近いものはどれか。
  3. シャノンの通信路符号化定理の内容として、正しいものはどれか。
  4. グレイコードを通常の2進数に直すには、最上位のビットはそのまま使い、それより下位のビットは、1つ上位の位置で求めた2進数のビットと、同じ位置のグレイコードのビットとの排他的論理和で求める。4ビットのグレイコード 1101 を2進数に直したものはどれか。
  5. 事象の確率をpとするとき、その事象が起こったと知らされて得られる情報量を −log₂ p ビットとする。確率1/8で起こる事象が起こったと知らされたときの情報量はどれか。
