情報理論と符号の基礎

可逆圧縮と、情報源のエントロピーの関係の説明として、正しいものはどれか。

  1. A優れた可逆圧縮のアルゴリズムを使えば、どのような内容のファイルでも、必ず元より小さくできる
  2. B記号を独立に出す情報源でも、工夫した可逆な符号なら、平均符号長をエントロピーより小さくできる
  3. C可逆な符号の平均符号長はエントロピーより小さくできないが、記号をまとめて符号化すると近づけられる
答えと解説を見る

正解：C. 可逆な符号の平均符号長はエントロピーより小さくできないが、記号をまとめて符号化すると近づけられる

記号を独立に出す情報源では、可逆な符号の1記号あたりの平均符号長はエントロピー以上になり、記号をまとめて符号化すると、エントロピーにいくらでも近づけられます(情報源符号化定理)。また、nビットのファイルは2ⁿ通りあるのに、それより短いビット列は全部で 2ⁿ − 1 通りしかないので、すべてのファイルを短くできる可逆圧縮はありません。可逆圧縮は、偏りや繰り返しのあるデータを短くする代わりに、そうでないデータを少し長くしています。

  • A. 鳩の巣原理から、すべてのファイルを短くすることはできません。ランダムなデータや、すでに圧縮したデータは、ほとんど小さくなりません。
  • B. 平均符号長の下限がエントロピーです。それより短くしようとすると、1通りに復号できない符号になります。
  • C. 正しい。エントロピーが、可逆な符号化の限界を与えます。

情報理論と符号の基礎のほかの問題

  1. 40文字の文字列 AAAAAAAAAAAABBBBCCCCCCCCCCCCCCCCCCCCDDDD(Aが12個、Bが4個、Cが20個、Dが4個)を、同じ文字の連続を「文字(1バイト)と個数(1バイト)」の組で表すランレングス符号化で圧縮する。元の文字列は1文字1バイトとし、圧縮率を「圧縮後の大きさ ÷ 圧縮前の大きさ」とするとき、圧縮率はどれか。
  2. ランレングス符号化で圧縮したときに、大きさを最も小さくしやすいデータはどれか。
  3. ZIPやgzipなどで使われるLZ77方式の考え方として、正しいものはどれか。
  4. LZ77方式で圧縮したデータを復元する。データは「文字A」「文字B」「(距離2、長さ5)」の順に並んでいる。(距離d、長さL)は、「復元済みの文字列の末尾からd文字前の文字を末尾に写す」ことを1文字ずつL回繰り返すことを表す。復元した文字列はどれか。
  5. データを圧縮するとき、非可逆圧縮ではなく可逆圧縮を使わなければならないものはどれか。
