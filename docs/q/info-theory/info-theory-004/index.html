情報理論と符号の基礎

8種類の記号を出す情報源のエントロピーの最大値と、最大になる条件の組み合わせとして、正しいものはどれか。

  1. A3ビット。どれか1つの記号の確率が1のとき
  2. B3ビット。8種類の記号の確率がすべて1/8のとき
  3. C8ビット。8種類の記号の確率がすべて1/8のとき
答えと解説を見る

正解：B. 3ビット。8種類の記号の確率がすべて1/8のとき

n種類の記号を出す情報源のエントロピーは、すべての記号が等しい確率1/nで出るときに最大になり、その値は log₂ n です。n = 8 なら log₂ 8 = 3 ビットです。どの記号が出るかを最も予想しにくいときに、1記号あたりの平均情報量が最大になります。逆に、1つの記号が確率1で出るときは、何が出るか分かっているので、エントロピーは0です。

  • A. 1つの記号が確率1で出るときは、エントロピーは最小の0ビットです。
  • B. 正しい。等しい確率のとき、最大の log₂ 8 = 3 ビットになります。
  • C. 8は記号の種類の数です。エントロピーの最大値は、その対数の log₂ 8 = 3 ビットです。

情報理論と符号の基礎のほかの問題

  1. 0を確率0.9、1を確率0.1で、互いに独立に出す2値の情報源がある。log₂ 0.9 ≈ −0.152、log₂ 0.1 ≈ −3.32 とする。この情報源のエントロピーに最も近いものはどれか。
  2. 8種類の記号を出す情報源のエントロピーが2.4ビットであった。冗長度を 1 − (エントロピー ÷ 最大エントロピー) と定義するとき、この情報源の冗長度はどれか。
  3. 2つの確率変数X、Yについて、条件付きエントロピー H(X|Y) と相互情報量 I(X;Y) の説明として、正しいものはどれか。
  4. 2つの確率変数X(値は0か1)とY(値はa、b、cのどれか)の同時確率が、P(0, a) = P(0, b) = P(1, b) = P(1, c) = 1/4 で、ほかの組み合わせの確率は0である。相互情報量 I(X;Y) はどれか。
  5. 英大文字26種類と数字10種類の、合わせて36種類の文字を、どれも同じ長さのビット列(固定長符号)で区別したい。1文字あたりに必要な最小のビット数はどれか。
