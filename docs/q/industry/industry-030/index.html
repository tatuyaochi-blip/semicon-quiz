半導体産業・市場

CPUなどの設計資産(IP)を他社にライセンスし、使用料を得るビジネスモデルの企業を何と呼ぶか。

  1. Aファウンドリ
  2. BIPベンダー
  3. COSAT
答えと解説を見る

正解：B. IPベンダー

IPベンダーは、CPUコアやインターフェース回路などの設計資産を開発し、半導体企業にライセンスして、契約時のライセンス料と製品ごとの使用料(ロイヤリティ)を得ます。スマートフォンのプロセッサの多くは、IPベンダーからライセンスを受けたCPUコアを使っています。IPを活用することで、半導体企業は開発期間とコストを抑えられます。ファウンドリは製造、OSATは後工程を受託します。

半導体産業・市場のほかの問題

  1. 半導体が、さまざまな製品に欠かせない基礎的な部品であることから、日本でたとえて呼ばれてきた言葉はどれか。
  2. メモリ半導体の市場で、売上の大部分を占める2つの製品の組み合わせとして正しいものはどれか。
  3. 台湾に本社を置き、ファウンドリ(半導体の受託製造)として世界最大のシェアをもつ企業はどれか。
  4. 2020年から2021年ごろに起きた半導体不足で、自動車の生産が大きな影響を受けた理由として適切なものはどれか。
  5. 家電製品や自動車などの機器に組み込まれ、その制御を行う、CPUやメモリ、入出力回路を1チップにまとめた小さなコンピュータはどれか。
