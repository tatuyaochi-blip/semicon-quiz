性能評価・プロファイリング

サーバの使用率(忙しい時間の割合)が100%に近づくと、要求の待ち時間はどうなるか。

  1. A急激に長くなる(使用率が上がるほど、増え方が大きくなる)
  2. B使用率に比例して、少しずつ長くなる
  3. C使用率が高いほど、待ち時間は短くなる
答えと解説を見る

正解：A. 急激に長くなる(使用率が上がるほど、増え方が大きくなる)

要求が不規則に届く場合、サーバが空いている時間があっても、たまたま要求が重なると待ち行列ができます。使用率が高いほど空いている時間が少なく、できた行列が解消されにくくなるので、待ち時間は使用率をρとして1÷(1−ρ)のような形で急に増えます。例えば使用率50%と90%では待ち時間に何倍もの差が出ます。そのため、応答の速さが大切なシステムでは使用率に余裕を残します。

  • A. 正しい。使用率に余裕を残して運用する理由です。
  • B. 比例ではなく、急に増えます。
  • C. 逆に長くなります。

性能評価・プロファイリングのほかの問題

  1. プログラムの性能を改善するときにプロファイラを使う目的として正しいものはどれか。
  2. サンプリング方式のプロファイラの特徴として正しいものはどれか。
  3. 関数の入口と出口に時間を測るコードを入れて記録する計測(インストルメンテーション)方式のプロファイラについて正しいものはどれか。
  4. プログラムの性能の分析でいうホットスポットの説明として正しいものはどれか。
  5. プロファイルの結果を表すフレームグラフの読み方として正しいものはどれか。
