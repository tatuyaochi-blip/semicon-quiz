性能評価・プロファイリング

STREAMベンチマークで主に測るものはどれか。

  1. ACPUの浮動小数点の演算の最大の速さ
  2. B大きな配列のコピーや足し算などを行ったときに実際に得られるメモリの帯域
  3. Cストレージの容量
答えと解説を見る

正解：B. 大きな配列のコピーや足し算などを行ったときに実際に得られるメモリの帯域

STREAMは、キャッシュに入らない大きな配列に対して、コピー、定数倍、足し算、それらの組み合わせの4つの単純な処理を行い、1秒あたりに読み書きできたバイト数を測るベンチマークです。計算はほとんどないので、結果はメモリの帯域で決まります。カタログの理論値と比べて、実際にどれだけの帯域が使えるかを知る目安になり、Rooflineモデルの斜めの線の傾きにも使われます。

  • A. 演算の速さを測るものではありません。
  • B. 正しい。実際に使える帯域の目安になります。
  • C. 容量ではなく帯域を測ります。

性能評価・プロファイリングのほかの問題

  1. 並列プログラムのスケーラビリティを調べるときの方法として最も適切なものはどれか。
  2. 8コアで並列に実行したところ、1コアのときより6倍速くなった。並列効率はいくらか。
  3. 性能を測るための仕組みを入れたことで、測りたいプログラムの動きそのものが変わってしまう現象を何と呼ぶか。
  4. プログラムの性能を改善するときの進め方として最も適切なものはどれか。
  5. 大量のデータを処理するプログラムで、最も大きな速度向上が得られる可能性が高い改善はどれか。
