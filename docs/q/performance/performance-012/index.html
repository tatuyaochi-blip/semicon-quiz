性能評価・プロファイリング

並列計算の評価でいう「強いスケーリング」と「弱いスケーリング」の違いとして正しいものはどれか。

  1. A強いスケーリングは問題の大きさを固定してプロセッサを増やし、弱いスケーリングはプロセッサあたりの問題の大きさを固定して全体を大きくする
  2. B強いスケーリングは速いプロセッサ、弱いスケーリングは遅いプロセッサを使う
  3. Cどちらも同じ測り方で、呼び方が違うだけである
答えと解説を見る

正解：A. 強いスケーリングは問題の大きさを固定してプロセッサを増やし、弱いスケーリングはプロセッサあたりの問題の大きさを固定して全体を大きくする

強いスケーリングでは、同じ問題をより多くのプロセッサで解いて、どれだけ時間が短くなるかを見ます。並列にできない部分や通信のために、プロセッサが増えると効果が頭打ちになりやすいです。弱いスケーリングでは、プロセッサ1つあたりの仕事の量を同じにして全体を大きくし、時間が一定に保たれるかを見ます。どちらで評価したかを示さないと、結果を正しく比べられません。

  • A. 正しい。前者はアムダール、後者はグスタフソンの考え方に対応します。
  • B. プロセッサの速さの違いではありません。
  • C. 何を固定するかが違います。

性能評価・プロファイリングのほかの問題

  1. コンピュータの性能をベンチマークで評価するときの考え方として最も適切なものはどれか。
  2. SPEC CPUのような標準のベンチマークの説明として正しいものはどれか。
  3. 複数のベンチマークの、基準の計算機に対する速さの比をまとめるときに、幾何平均がよく使われる理由として正しいものはどれか。
  4. 同じ数の命令を持つ2つのプログラムを、1つは1秒あたり1000百万命令、もう1つは500百万命令の速さで続けて実行した。全体の平均の速さはいくらか。
  5. 上のような小さなループで計算の速さを測ったところ、Nを大きくしても時間がほとんど0だった。最も考えられる原因はどれか。
