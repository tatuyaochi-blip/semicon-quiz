性能評価・プロファイリング

グスタフソンの法則が示す考え方として正しいものはどれか。

  1. Aプロセッサの数を増やすとき、扱う問題の大きさも増やせば、並列にできる部分の割合が増え、大きな速度向上が得られる
  2. Bプロセッサの数をいくら増やしても、速度向上は必ず2倍が上限になる
  3. C並列にできる部分は、問題の大きさに関係なく常に一定である
答えと解説を見る

正解：A. プロセッサの数を増やすとき、扱う問題の大きさも増やせば、並列にできる部分の割合が増え、大きな速度向上が得られる

アムダールの法則は、問題の大きさを変えずにプロセッサを増やす場合を考えるので、並列にできない部分が速度向上の上限を決めます。グスタフソンの法則は、プロセッサを増やしたら、同じ時間でより大きな問題を解くと考えます。シミュレーションの格子を細かくするなど、問題を大きくすると並列の部分が増え、逐次の部分の割合が小さくなるので、プロセッサの数にほぼ比例した効果が得られます。

  • A. 正しい。大規模な計算で並列化が有効な理由です。
  • B. そのような上限はありません。
  • C. 問題が大きくなると、並列にできる部分が増えることが多いです。

性能評価・プロファイリングのほかの問題

  1. 並列計算の評価でいう「強いスケーリング」と「弱いスケーリング」の違いとして正しいものはどれか。
  2. コンピュータの性能をベンチマークで評価するときの考え方として最も適切なものはどれか。
  3. SPEC CPUのような標準のベンチマークの説明として正しいものはどれか。
  4. 複数のベンチマークの、基準の計算機に対する速さの比をまとめるときに、幾何平均がよく使われる理由として正しいものはどれか。
  5. 同じ数の命令を持つ2つのプログラムを、1つは1秒あたり1000百万命令、もう1つは500百万命令の速さで続けて実行した。全体の平均の速さはいくらか。
