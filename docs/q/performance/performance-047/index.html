性能評価・プロファイリング

データセンターでサーバを選ぶとき、ピークの性能だけでなく考えるべき観点として当てはまらないものはどれか。

  1. A1ワットあたりの性能と、冷却を含めた電気代
  2. Bサーバの筐体の色の好み
  3. C購入から廃棄までにかかる費用の合計(総所有コスト)
答えと解説を見る

正解：B. サーバの筐体の色の好み

データセンターでは、サーバを何年も動かし続けるので、購入の価格だけでなく、電気代や冷却の費用、設置の場所、保守の手間なども合わせた総所有コストが重要です。そのため、ピークの性能よりも、実際の仕事での1ワットあたりの性能や、1ドルあたりの性能で比べることが多くなります。性能の評価は、何を最も大切にするかを決めてから行う必要があります。

  • A. これは重要な観点です。
  • B. 正しい。性能やコストの評価には関係ありません。
  • C. これは重要な観点です。

性能評価・プロファイリングのほかの問題

  1. 「新しい方法で100倍速くなった」という主張を評価するときに確かめるべき点として最も適切なものはどれか。
  2. SSDの性能を、連続の読み出しの帯域(MB/s)だけでなく、4 KBのランダムな読み出しのIOPS(1秒あたりの入出力の回数)でも示すことが多い理由として正しいものはどれか。
  3. 配列の大きさを少しずつ大きくしながら、配列を繰り返し読む処理の1要素あたりの時間を測ると、ある大きさごとに時間が段階的に増える。その理由として正しいものはどれか。
  4. プログラムのCPUでの実行時間を表す基本の式として正しいものはどれか。
  5. 10億個の命令を実行するプログラムを、平均CPIが2、クロック周波数が2 GHzのCPUで実行した。実行時間はいくらか。
