性能評価・プロファイリング

SPEC CPUのような標準のベンチマークの説明として正しいものはどれか。

  1. A実際のアプリケーションをもとにした多数のプログラムを、決まった規則で実行し、基準の計算機との比をまとめた値で性能を示す
  2. B1つの足し算を何回できるかだけを測る
  3. Cベンチマークの結果は、メーカーが自由に決めてよい
答えと解説を見る

正解：A. 実際のアプリケーションをもとにした多数のプログラムを、決まった規則で実行し、基準の計算機との比をまとめた値で性能を示す

SPEC CPUは、コンパイラ、圧縮、物理のシミュレーションなど、実際のアプリケーションをもとにした多数のプログラムからなるベンチマークです。各プログラムの実行時間を基準の計算機の時間と比べた比を求め、それらを幾何平均でまとめて1つの値にします。コンパイラの設定や実行の方法にも規則があり、結果は詳しい条件とともに公開されます。

  • A. 正しい。規則を決めて公平に比べられるようにしています。
  • B. 実際のプログラムに近いものを多数使います。
  • C. 決まった規則で測り、結果を報告します。

性能評価・プロファイリングのほかの問題

  1. 複数のベンチマークの、基準の計算機に対する速さの比をまとめるときに、幾何平均がよく使われる理由として正しいものはどれか。
  2. 同じ数の命令を持つ2つのプログラムを、1つは1秒あたり1000百万命令、もう1つは500百万命令の速さで続けて実行した。全体の平均の速さはいくらか。
  3. 上のような小さなループで計算の速さを測ったところ、Nを大きくしても時間がほとんど0だった。最も考えられる原因はどれか。
  4. プログラムの実行時間を測るとき、同じ測定を何回も繰り返し、最初の数回の結果を除くことが多い理由として正しいものはどれか。
  5. 非常に短い処理の時間を、1回だけ測ろうとしたときの問題と、その対策の組み合わせとして正しいものはどれか。
