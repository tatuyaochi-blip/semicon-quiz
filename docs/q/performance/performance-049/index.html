性能評価・プロファイリング

SSDの性能を、連続の読み出しの帯域(MB/s)だけでなく、4 KBのランダムな読み出しのIOPS(1秒あたりの入出力の回数)でも示すことが多い理由として正しいものはどれか。

  1. AIOPSはSSDの容量を表す値だから
  2. B連続の読み出しは、SSDではできないから
  3. CデータベースやOSのように、小さな読み書きをばらばらの場所に大量に行う用途では、回数の多さが性能を決めるから
答えと解説を見る

正解：C. データベースやOSのように、小さな読み書きをばらばらの場所に大量に行う用途では、回数の多さが性能を決めるから

動画のような大きなファイルを読むときは、連続の読み出しの帯域が性能を決めます。一方、データベースやOSの処理では、4 KBほどの小さなデータを、ディスクのあちこちから大量に読み書きします。この場合は1回ごとの遅延と、同時に何回の要求をこなせるかが大切で、帯域の数字だけでは性能を判断できません。同じSSDでも、用途によって速さの感じ方は大きく変わります。

  • A. 容量ではなく、1秒あたりの処理の回数です。
  • B. SSDも連続の読み出しができます。
  • C. 正しい。用途に合った指標で比べる必要があります。

性能評価・プロファイリングのほかの問題

  1. 配列の大きさを少しずつ大きくしながら、配列を繰り返し読む処理の1要素あたりの時間を測ると、ある大きさごとに時間が段階的に増える。その理由として正しいものはどれか。
  2. プログラムのCPUでの実行時間を表す基本の式として正しいものはどれか。
  3. 10億個の命令を実行するプログラムを、平均CPIが2、クロック周波数が2 GHzのCPUで実行した。実行時間はいくらか。
  4. CPUの設計の変更で、クロックの周波数は1.5倍になったが、CPIも1.2倍に増えた(命令数は同じ)。実行の速さは元の何倍になるか。
  5. コンパイラの新しい最適化で、実行する命令の数は20%減ったが、平均CPIが10%増えた(周波数は同じ)。この最適化の効果として正しいものはどれか。
