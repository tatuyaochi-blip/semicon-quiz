性能評価・プロファイリング

コンピュータの性能をベンチマークで評価するときの考え方として最も適切なものはどれか。

  1. A実際に使う用途に近いプログラムで測り、その結果で比べる
  2. Bどの用途でも、1つの小さなループの速さだけで決める
  3. Cメーカーが公表したクロックの周波数だけで決める
答えと解説を見る

正解：A. 実際に使う用途に近いプログラムで測り、その結果で比べる

あるコンピュータが速いかどうかは、何に使うかによって変わります。整数の処理、浮動小数点の計算、メモリを大量に使う処理、入出力の多い処理など、得意な仕事はそれぞれ違います。そのため、実際の用途にできるだけ近いプログラムや、多くの代表的なプログラムを集めた標準のベンチマークで測り、条件をそろえて比べることが大切です。

  • A. 正しい。用途によって速いコンピュータは変わります。
  • B. 小さなループの結果は、実際の用途と大きく違うことがあります。
  • C. 周波数だけでは性能は決まりません。

性能評価・プロファイリングのほかの問題

  1. SPEC CPUのような標準のベンチマークの説明として正しいものはどれか。
  2. 複数のベンチマークの、基準の計算機に対する速さの比をまとめるときに、幾何平均がよく使われる理由として正しいものはどれか。
  3. 同じ数の命令を持つ2つのプログラムを、1つは1000 MIPS(1秒あたり10億命令)、もう1つは500 MIPSの速さで続けて実行した。全体の平均の速さはいくらか。
  4. 上のような小さなループで計算の速さを測ったところ、Nを大きくしても時間がほとんど0だった。最も考えられる原因はどれか。
  5. プログラムの実行時間を測るとき、同じ測定を何回も繰り返し、最初の数回の結果を除くことが多い理由として正しいものはどれか。
