性能評価・プロファイリング

「新しい方法で100倍速くなった」という主張を評価するときに確かめるべき点として最も適切なものはどれか。

  1. A100という数字が偶数かどうか
  2. B主張した人の名前の長さ
  3. C比べた相手(基準)が十分に最適化されたものか、同じ条件や同じ精度で比べているか
答えと解説を見る

正解：C. 比べた相手(基準)が十分に最適化されたものか、同じ条件や同じ精度で比べているか

速度向上率は、何と比べたかで大きく変わります。最適化していない古いプログラムや、1つのコアしか使わないプログラムと比べれば、大きな倍率が出やすくなります。また、データの大きさや精度、測った範囲(転送の時間を含むか)などが違えば、公平な比べ方とはいえません。主張を正しく評価するには、基準の内容と測定の条件がはっきり示されているかを確かめることが大切です。

  • A. 数字の性質は関係ありません。
  • B. 名前は関係ありません。
  • C. 正しい。基準しだいで倍率はいくらでも大きく見せられます。

性能評価・プロファイリングのほかの問題

  1. SSDの性能を、連続の読み出しの帯域(MB/s)だけでなく、4 KBのランダムな読み出しのIOPS(1秒あたりの入出力の回数)でも示すことが多い理由として正しいものはどれか。
  2. 配列の大きさを少しずつ大きくしながら、配列を繰り返し読む処理の1要素あたりの時間を測ると、ある大きさごとに時間が段階的に増える。その理由として正しいものはどれか。
  3. プログラムのCPUでの実行時間を表す基本の式として正しいものはどれか。
  4. 10億個の命令を実行するプログラムを、平均CPIが2、クロック周波数が2 GHzのCPUで実行した。実行時間はいくらか。
  5. CPUの設計の変更で、クロックの周波数は1.5倍になったが、CPIも1.2倍に増えた(命令数は同じ)。実行の速さは元の何倍になるか。
