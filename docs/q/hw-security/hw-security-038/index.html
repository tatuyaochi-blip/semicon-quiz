ハードウェアセキュリティ

ハードウェアトロイへの対策として当てはまらないものはどれか。

  1. Aチップを出荷した後に、ソフトウェアの更新でトロイの回路を削除する
  2. B設計のデータや使うIPを、信頼できる相手からだけ受け取り、変更を厳しく管理する
  3. C正常なチップと比べて、消費電力や遅延などの特性の違いを調べる
答えと解説を見る

正解：A. チップを出荷した後に、ソフトウェアの更新でトロイの回路を削除する

ハードウェアトロイは回路として作り込まれているので、出荷後に取り除くことはできません。対策は、信頼できる設計の道具やIP、製造の委託先を選ぶ、設計のデータの変更を記録して確かめる、製造したチップの一部を分解して設計と比べる、正常なチップとの消費電力や遅延の違いを調べる、重要な部分を別々の工場で製造する、などを組み合わせて行います。

  • A. 正しい。回路はソフトウェアでは削除できません。
  • B. これは有効な対策です。
  • C. これは有効な対策です。
