ハードウェアセキュリティ

暗号の鍵を作るときに、予測されやすい質の悪い乱数を使うと起こりうることとして正しいものはどれか。

  1. A暗号の処理が速くなる
  2. B暗号文の長さが2倍になる
  3. C暗号のアルゴリズムが強くても、鍵を推測されて暗号が破られてしまう
答えと解説を見る

正解：C. 暗号のアルゴリズムが強くても、鍵を推測されて暗号が破られてしまう

暗号の安全は、攻撃者が鍵を知らないことに頼っています。鍵を作る乱数に偏りがあったり、電源を入れた直後で十分な予測できなさが集まっていなかったりすると、鍵の候補が少なくなり、総当たりで見つけられてしまいます。実際に、乱数の不備のせいで多くの機器が同じような鍵を持ってしまった例が報告されています。乱数の生成は、セキュリティの最も基本的な部品の1つです。

  • A. 速さとは関係ありません。
  • B. 長さとは関係ありません。
  • C. 正しい。鍵の予測できなさが安全の土台です。
