ハードウェアセキュリティ

投機的実行の脆弱性への対策について、一般的に正しいものはどれか。

  1. A対策を入れても、性能はまったく変わらない
  2. B投機的実行やキャッシュの共有を制限するほど安全になるが、性能が下がるので、安全と性能の釣り合いを考えて選ぶ
  3. C投機的実行をなくせば、CPUは速くなる
答えと解説を見る

正解：B. 投機的実行やキャッシュの共有を制限するほど安全になるが、性能が下がるので、安全と性能の釣り合いを考えて選ぶ

投機的実行、分岐予測、共有のキャッシュは、現在のCPUの高い性能を支える仕組みです。これらを制限すれば漏れる情報は減りますが、そのぶん性能が落ちます。そのため、OSやコンパイラ、CPUの設計では、守るべき情報や脅威の大きさに応じて、どこまで対策を入れるかを選んでいます。新しいCPUでは、性能への影響の小さい対策を回路に組み込む工夫が進んでいます。

  • A. 処理によっては目に見えて遅くなります。
  • B. 正しい。性能のための仕組みそのものが原因だからです。
  • C. 投機的実行は性能を上げるための仕組みです。
