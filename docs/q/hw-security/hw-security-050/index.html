ハードウェアセキュリティ

CPUのハードウェアの脆弱性が見つかったとき、出荷済みのCPUで行われる対策の1つとして正しいものはどれか。

  1. AすべてのCPUを回収して、トランジスタを1つずつ交換する
  2. BCPUのマイクロコードを更新して、問題のある内部の動作を変えたり、OSが使える新しい制御の機能を加えたりする
  3. CCPUの表面の印字を変える
答えと解説を見る

正解：B. CPUのマイクロコードを更新して、問題のある内部の動作を変えたり、OSが使える新しい制御の機能を加えたりする

多くのCPUは、複雑な命令の実行や一部の内部の制御を、書き換えのできるマイクロコードで行っています。脆弱性が見つかると、CPUの会社はマイクロコードの更新を配布し、BIOSやOSを通じて起動のたびに読み込ませます。これで問題のある動作を抑えたり、分岐予測器を消去する命令などの新しい制御を加えたりできます。回路そのものの問題は、次の世代のCPUで根本的に直します。

  • A. トランジスタを交換することはできません。
  • B. 正しい。OSやコンパイラの対策と組み合わせて使います。
  • C. 印字を変えても動作は変わりません。
