ハードウェアセキュリティ

暗号の処理を行うチップの消費電力の波形を使う電力解析のうち、差分電力解析(DPA)の特徴として正しいものはどれか。

  1. A多数の処理の電力の波形を集めて統計的に処理し、1回の波形では見えない鍵に関係する小さな差を取り出す
  2. B1回の電力の波形を目で見るだけで、鍵がすべて分かる
  3. Cチップの電源を切って、鍵を取り出す
答えと解説を見る

正解：A. 多数の処理の電力の波形を集めて統計的に処理し、1回の波形では見えない鍵に関係する小さな差を取り出す

CMOSの回路は、信号が切り替わるときに電力を使うので、扱うデータによって消費電力がわずかに変わります。単純電力解析は1回の波形の形から処理の流れを読み取りますが、差分電力解析は、何千回もの暗号の処理の波形を集め、鍵の候補ごとに予想した中間の値と波形の相関を計算して、正しい鍵を見つけます。雑音に埋もれた小さな差でも、統計で取り出せるのが特徴です。

  • A. 正しい。雑音の中の小さな差を統計で浮かび上がらせます。
  • B. それは単純電力解析(SPA)が理想的にうまくいった場合です。
  • C. 電源を切ると処理は行われません。
