ハードウェアセキュリティ

DRAMのロウハンマーへの対策として当てはまるものはどれか。

  1. ADRAMの容量を半分にする
  2. B何度も活性化された行の隣の行を早めにリフレッシュする(TRRなど)、リフレッシュの頻度を上げる
  3. CCPUのクロックを止める
答えと解説を見る

正解：B. 何度も活性化された行の隣の行を早めにリフレッシュする(TRRなど)、リフレッシュの頻度を上げる

ロウハンマーは、ある行を短時間に何度も活性化すると、電気的な干渉で隣の行のセルの電荷が漏れてビットが反転する現象です。権限のないプログラムがほかのプロセスやカーネルのデータを書き換える攻撃に使える恐れがあります。対策として、多く活性化された行の隣を追加でリフレッシュする仕組みや、リフレッシュの頻度を上げる方法、ECCで反転を見つけて直す方法などが組み合わされます。

  • A. 容量を減らしても対策にはなりません。
  • B. 正しい。電荷が漏れきる前に書き直します。
  • C. クロックを止めると動作できません。

ハードウェアセキュリティのほかの問題

  1. コールドブート攻撃が成り立つ理由と、代表的な対策の組み合わせとして正しいものはどれか。
  2. セキュアブートの説明として正しいものはどれか。
  3. セキュアブートの「ルートオブトラスト(信頼の起点)」として、チップの中に置かれるものとして最も適切なものはどれか。
  4. セキュアブートで、ソフトウェアの署名の確認に公開鍵暗号を使う利点として正しいものはどれか。
  5. セキュアブートを備えた機器で、ロールバック防止(アンチロールバック)の仕組みが必要になる理由として正しいものはどれか。
