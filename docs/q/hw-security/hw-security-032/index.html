ハードウェアセキュリティ

SRAM PUFが利用している性質として正しいものはどれか。

  1. A電源を入れた直後のSRAMの各セルが、トランジスタのばらつきによって0か1のどちらかに偏って決まりやすいこと
  2. BSRAMは電源を切ってもデータが永久に残ること
  3. CSRAMのすべてのセルが、電源を入れると必ず0になること
答えと解説を見る

正解：A. 電源を入れた直後のSRAMの各セルが、トランジスタのばらつきによって0か1のどちらかに偏って決まりやすいこと

SRAMのセルは、2つのインバータを向かい合わせにつないだ回路で、電源を入れた直後にどちらに倒れるかは、2つのインバータのトランジスタのわずかな強さの違いで決まります。そのため、セルごとの初期値の並びはチップに固有で、電源を入れるたびにほぼ同じ並びが現れます。特別な回路を追加せずに、多くのチップがすでに持っているSRAMを使えるのが利点です。

  • A. 正しい。初期値の並びがチップごとの指紋になります。
  • B. SRAMは揮発性です。
  • C. すべて0になるなら、指紋になりません。

  3. 暗号の鍵を作るときに、予測されやすい質の悪い乱数を使うと起こりうることとして正しいものはどれか。
  4. ハードウェアトロイ(ハードウェアトロイの木馬)の説明として正しいものはどれか。
