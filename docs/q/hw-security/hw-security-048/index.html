ハードウェアセキュリティ

ハードウェアとソフトウェアのセキュリティで重視される「多層防御」の考え方として正しいものはどれか。

  1. A最も強い対策を1つだけ選び、ほかはすべて省く
  2. B1つの対策が破られても全体が破られないように、性質の違う複数の対策を重ねる
  3. C対策を何もしないで、攻撃されてから考える
答えと解説を見る

正解：B. 1つの対策が破られても全体が破られないように、性質の違う複数の対策を重ねる

どんな対策にも、まだ知られていない弱点があるかもしれません。多層防御では、セキュアブート、メモリの保護、TEE、暗号化、サイドチャネル対策、物理的な耐タンパ性など、性質の違う対策を重ねて、1つが破られても次の層で守れるようにします。攻撃者にとって、すべての層を同時に破る手間と費用が大きくなることが、全体の安全につながります。

  • A. 1つが破られると、全体が破られてしまいます。
  • B. 正しい。完全な対策は1つでは作れないという前提です。
  • C. 事前の対策が必要です。

ハードウェアセキュリティのほかの問題

  1. 多数の機器を製造するとき、すべての機器に同じ鍵を入れずに、機器ごとに違う鍵を持たせる理由として正しいものはどれか。
  2. CPUのハードウェアの脆弱性が見つかったとき、出荷済みのCPUで行われる対策の1つとして正しいものはどれか。
  3. ハードウェアセキュリティで扱う問題の説明として最も適切なものはどれか。
  4. サイドチャネル攻撃の説明として正しいものはどれか。
  5. タイミング攻撃が成り立つ原理と、代表的な対策の組み合わせとして正しいものはどれか。
