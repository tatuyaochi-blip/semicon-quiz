ハードウェアセキュリティ

PUFから鍵を作るときに、誤り訂正の仕組み(ヘルパーデータなど)を組み合わせる理由として正しいものはどれか。

  1. A温度や電圧、雑音によって、PUFの出力の一部のビットが読み出すたびに変わることがあり、鍵は毎回まったく同じでなければならないから
  2. BPUFの出力は、毎回すべてのビットが逆になるから
  3. C誤り訂正をすると、鍵の長さが自動で2倍になるから
答えと解説を見る

正解：A. 温度や電圧、雑音によって、PUFの出力の一部のビットが読み出すたびに変わることがあり、鍵は毎回まったく同じでなければならないから

PUFの値は製造のばらつきで決まりますが、2つの候補の差が小さいセルでは、温度や電圧、雑音によって読み出すたびに値が変わることがあります。暗号の鍵は1ビットでも違えば使えないので、登録のときにヘルパーデータと呼ぶ補助の情報を作っておき、読み出しのたびに誤り訂正の符号でゆらいだビットを直してから鍵を作ります。ヘルパーデータは鍵そのものを明かさないように作られます。

  • A. 正しい。わずかなゆらぎを直してから鍵にします。
  • B. ほとんどのビットは毎回同じです。
  • C. 鍵の長さを増やすためではありません。
