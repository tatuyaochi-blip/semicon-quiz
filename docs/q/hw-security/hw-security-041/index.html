ハードウェアセキュリティ

ICカードなどのセキュリティ用のチップに求められる耐タンパ性の説明として正しいものはどれか。

  1. Aチップが水に濡れても壊れない性質
  2. Bチップを開けたり探針を当てたりする物理的な攻撃を難しくし、検知したら鍵を消すなどして、中の秘密を守る性質
  3. Cチップが高い温度でも速く動く性質
答えと解説を見る

正解：B. チップを開けたり探針を当てたりする物理的な攻撃を難しくし、検知したら鍵を消すなどして、中の秘密を守る性質

耐タンパ性とは、チップを分解したり内部の配線に探針を当てたりして秘密を取り出そうとする攻撃に耐える性質です。表面を覆う金属の配線の網(シールド)が切られたら検知する、光や温度、電圧の異常を検知する、内部の配線を暗号化したり複雑に配置したりする、異常を検知したら鍵を消去する、などの対策を組み合わせます。サイドチャネルや故障注入への対策も含めて評価されます。

  • A. 防水の性質のことではありません。
  • B. 正しい。物理的な攻撃に対する強さです。
  • C. 速さの性質ではありません。
