MOSFET

MOSFETのチャネルの移動度が、シリコン結晶内部の移動度より小さくなる主な理由として正しいものはどれか。

  1. Aチャネルでは温度が極端に低いため
  2. BチャネルのキャリアがSi/SiO2界面の近くを流れるため、界面の凹凸や電荷による散乱を受けやすいから
  3. Cチャネルには不純物がまったくないため
答えと解説を見る

正解：B. チャネルのキャリアがSi/SiO2界面の近くを流れるため、界面の凹凸や電荷による散乱を受けやすいから

MOSFETのチャネルは、ゲート絶縁膜との界面のごく近くにできます。キャリアは界面の凹凸や界面付近の電荷によって散乱されやすく、ゲート電圧を上げて界面に強く引き寄せるほど散乱が増えるため、移動度は結晶内部より小さくなります。

  2. CMOS論理ゲートの遅延時間をおおまかに表す式として適切なものはどれか。(C:負荷容量、V:電源電圧、I:駆動電流)
  3. エンハンスメント型pチャネルMOSFETのしきい値電圧(ソース基準)の符号はどれか。
  4. ゲート-ドレイン間の容量が、増幅回路の入力側から見ると(1 + 利得)倍に大きく見える効果を何と呼ぶか。
  5. ポリシリコンゲートで、ゲート電極側のポリシリコンが空乏化することによる問題として正しいものはどれか。
