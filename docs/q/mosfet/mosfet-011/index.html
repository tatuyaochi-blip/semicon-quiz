MOSFET

飽和領域にあるMOSFETで、ドレイン電圧を上げると実効的なチャネル長が短くなり、ドレイン電流がわずかに増える現象を何と呼ぶか。

  1. Aラッチアップ
  2. B基板バイアス効果
  3. Cチャネル長変調
答えと解説を見る

正解：C. チャネル長変調

飽和領域では、ドレイン端でチャネルが消えるピンチオフ点ができます。ドレイン電圧を上げるとピンチオフ点がソース側に移って実効チャネル長が短くなり、ドレイン電流が少し増えます。これがチャネル長変調で、ID = (1/2)μCox(W/L)(VGS − Vth)²(1 + λVDS) と表され、出力抵抗 ro ≈ 1/(λID) を決めます。チャネルが短いほど影響が大きいため、アナログ回路では長めのLを使います。

MOSFETのほかの問題

  1. MOSFETの相互コンダクタンスgmの定義として正しいものはどれか。
  2. p型基板のMOS構造で、ゲートに負の電圧を加えたときの半導体表面の状態として正しいものはどれか。
  3. CMOSインバータの論理しきい値電圧を電源電圧のほぼ半分にするための設計として正しいものはどれか。
  4. nMOSとpMOSを並列に接続したトランスミッションゲートの利点として正しいものはどれか。
  5. MOSFETのゲート-ソース間に、定格を大きく超える電圧を加えたときに起こりうる破壊はどれか。
