MOSFET

ドレイン-ソース間電圧VDSが十分小さい線形領域でのMOSFETの振る舞いとして正しいものはどれか。

  1. Aゲート電圧によって抵抗値が変わる可変抵抗のように振る舞う
  2. BVDSによらず一定の電流を流す定電流源のように振る舞う
  3. C一方向にしか電流を流さないダイオードのように振る舞う
答えと解説を見る

正解：A. ゲート電圧によって抵抗値が変わる可変抵抗のように振る舞う

線形領域では、ドレイン電流がVDSにほぼ比例し、その比例係数(コンダクタンス)がゲート電圧で変わります。つまり、ゲート電圧で制御できる可変抵抗のように振る舞います。スイッチとして使うときのオン状態はこの領域にあたります。VDSが大きくなると電流がほぼ一定の飽和領域になります。

MOSFETのほかの問題

  1. MOSFETのLDD(Lightly Doped Drain)構造の目的として正しいものはどれか。
  2. 飽和領域にあるMOSFETで、ドレイン電圧を上げると実効的なチャネル長が短くなり、ドレイン電流がわずかに増える現象を何と呼ぶか。
  3. MOSFETの相互コンダクタンスgmの定義として正しいものはどれか。
  4. p型基板のMOS構造で、ゲートに負の電圧を加えたときの半導体表面の状態として正しいものはどれか。
  5. CMOSインバータの論理しきい値電圧を電源電圧のほぼ半分にするための設計として正しいものはどれか。
