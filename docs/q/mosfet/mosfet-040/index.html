MOSFET

短チャネルのMOSFETで、ドレイン電圧を上げるとソース側のエネルギー障壁が下がり、しきい値電圧が低下する現象はどれか。

  1. AGIDL
  2. BDIBL(ドレイン誘起障壁低下)
  3. Cホットキャリア注入
答えと解説を見る

正解：B. DIBL(ドレイン誘起障壁低下)

チャネルが短くなると、ドレインの電界がソース付近まで届き、ソースとチャネルの間のエネルギー障壁を下げます。その結果、ドレイン電圧が高いほどしきい値電圧が下がり、オフ時のリーク電流も増えます。これをDIBLといい、短チャネル効果の代表例です。

  • A. GIDLは、ゲートとドレインの重なり部分でのバンド間トンネルによるリーク電流です。
  • B. 正しい。ドレイン電圧でソース側の障壁が下がる現象です。
  • C. ホットキャリア注入は、高エネルギーのキャリアが絶縁膜に入り込む劣化現象です。

MOSFETのほかの問題

  1. MOSFETのパンチスルーの説明として正しいものはどれか。
  2. MOSFETのチャネルにひずみを加える技術(ひずみシリコン)の主な目的はどれか。
  3. CMOSインバータで、入力が切り替わる途中に電源からグラウンドへ流れる電流を何と呼ぶか。
  4. CMOS回路で起こるラッチアップの説明として正しいものはどれか。
  5. デナードのスケーリング則(定電界スケーリング)で、寸法と電圧をそれぞれ1/kにしたときの説明として正しいものはどれか。
