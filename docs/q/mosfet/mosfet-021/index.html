MOSFET

ゲート-ドレイン間の容量が、増幅回路の入力側から見ると(1 + 利得)倍に大きく見える効果を何と呼ぶか。

  1. Aアーリー効果
  2. Bミラー効果
  3. Cホール効果
答えと解説を見る

正解：B. ミラー効果

反転増幅回路では、入力と出力の間の容量の両端に入力電圧の(1 + 利得)倍の電圧変化がかかるため、入力側から見ると容量が(1 + |Av|)倍に見えます。これがミラー効果で、MOSFETではゲート-ドレイン間容量Cgdが対象です。信号源の抵抗と大きな入力容量で帯域が狭まります。一方、オペアンプの位相補償では、この効果を利用して小さな容量で大きな容量の働きをさせています。

  2. MOSFETのしきい値電圧を下げたときの一般的な影響として正しいものはどれか。
  3. CMOSの2入力NANDゲートのトランジスタの接続として正しいものはどれか。
  4. ゲートとドレインが重なる部分の強い電界によってバンド間トンネル電流が流れ、オフ時のリーク電流が増える現象はどれか。
  5. MOSFETのゲートにほとんど電流が流れないことによる回路上の利点として正しいものはどれか。
