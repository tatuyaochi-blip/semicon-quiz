MOSFET

ゲート-ドレイン間の容量が、増幅回路の入力側から見ると(1 + 利得)倍に大きく見える効果を何と呼ぶか。

  1. Aアーリー効果
  2. Bミラー効果
  3. Cホール効果
答えと解説を見る

正解：B. ミラー効果

反転増幅回路では、入力と出力の間にある容量の両端に、入力電圧の(1 + 利得)倍の電圧変化がかかるため、入力側から見ると容量が大きく見えます。これをミラー効果といい、増幅回路の高い周波数での利得を下げる原因になります。
