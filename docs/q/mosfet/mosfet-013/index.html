MOSFET

p型基板のMOS構造で、ゲートに負の電圧を加えたときの半導体表面の状態として正しいものはどれか。

  1. A電子が集まる反転状態
  2. B正孔が集まる蓄積状態
  3. Cキャリアが消えた完全な真空状態
答えと解説を見る

正解：B. 正孔が集まる蓄積状態

p型基板のMOS構造でゲートに負の電圧を加えると、多数キャリアである正孔が表面に引き寄せられ、蓄積状態になります。正の電圧を加えていくと、正孔が追い払われた空乏状態を経て、さらに大きな電圧で電子が集まる反転状態になります。

MOSFETのほかの問題

  1. CMOSインバータの論理しきい値電圧を電源電圧のほぼ半分にするための設計として正しいものはどれか。
  2. nMOSとpMOSを並列に接続したトランスミッションゲートの利点として正しいものはどれか。
  3. MOSFETのゲート-ソース間に、定格を大きく超える電圧を加えたときに起こりうる破壊はどれか。
  4. MOSFETのチャネルの移動度が、シリコン結晶内部の移動度より小さくなる主な理由として正しいものはどれか。
  5. 短チャネルのMOSFETで、ドレイン電流が(VGS − Vth)の2乗則より小さくなり、1乗に近い依存性を示すようになる主な原因はどれか。
