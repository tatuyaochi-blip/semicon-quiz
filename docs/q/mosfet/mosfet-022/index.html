MOSFET

ポリシリコンゲートで、ゲート電極側のポリシリコンが空乏化することによる問題として正しいものはどれか。

  1. Aゲートの抵抗が0になる
  2. Bトランジスタが発光する
  3. C実効的なゲート絶縁膜が厚くなったのと同じことになり、駆動電流が低下する
答えと解説を見る

正解：C. 実効的なゲート絶縁膜が厚くなったのと同じことになり、駆動電流が低下する

ポリシリコンは半導体なので、ゲートに電圧をかけるとゲート電極側にも厚さ0.3〜0.5 nm程度の空乏層ができます。これが直列の容量として働き、実効的な絶縁膜厚が増えたのと同じになって駆動電流が下がります。絶縁膜が1 nm台まで薄くなると無視できない割合になりました。45 nm世代以降のHigh-k/メタルゲート(HKMG)では、金属の電極を使うためこの問題が解消されています。

MOSFETのほかの問題

  1. MOSFETのしきい値電圧を下げたときの一般的な影響として正しいものはどれか。
  2. CMOSの2入力NANDゲートのトランジスタの接続として正しいものはどれか。
  3. ゲートとドレインが重なる部分の強い電界によってバンド間トンネル電流が流れ、オフ時のリーク電流が増える現象はどれか。
  4. MOSFETのゲートにほとんど電流が流れないことによる回路上の利点として正しいものはどれか。
  5. MOSFETのソースフォロワ(ドレイン接地)回路の特徴として正しいものはどれか。
