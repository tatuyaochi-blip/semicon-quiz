MOSFET

ゲート絶縁膜の材料と面積を変えずに膜厚だけを薄くすると、単位面積あたりのゲート容量はどうなるか。

  1. A大きくなる
  2. B小さくなる
  3. C変化しない
答えと解説を見る

正解：A. 大きくなる

ゲート容量は平行平板コンデンサとみなせ、単位面積あたり Cox = ε/t です。膜厚を薄くすると容量が大きくなり、同じゲート電圧でチャネルに誘起される電荷が増え、駆動電流が増えて短チャネル効果も抑えられます。ただしSiO2を約1.2 nmまで薄くした時点でトンネル電流によるゲートリークが限界に達し、45 nm世代からは物理的に厚くできるHfO2系のHigh-k材料が使われています。

MOSFETのほかの問題

  1. CMOSインバータの静的(定常状態の)消費電力が小さい理由として正しいものはどれか。
  2. 長チャネルのMOSFETが飽和領域で動作しているとき、ドレイン電流IDはおよそ何に比例するか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  3. 同じ寸法のnMOSとpMOSでは、一般にnMOSの方が駆動電流が大きい。その主な理由はどれか。
  4. nチャネルMOSFETで、ソースに対して基板(ボディ)に負の電圧をかける(基板バイアスをかける)と、しきい値電圧はどうなるか。
  5. デプレッション型MOSFETの特徴として正しいものはどれか。
