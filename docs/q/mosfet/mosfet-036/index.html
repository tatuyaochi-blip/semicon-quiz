MOSFET

一般的な集積回路のMOSFETで、ソースとドレインの関係として正しいものはどれか。

  1. A構造はほぼ対称で、電位の関係によってどちらがソースになるかが決まる
  2. Bソースは必ずドレインより不純物濃度が高い
  3. Cソースとドレインは異なる半導体材料でつくられる
答えと解説を見る

正解：A. 構造はほぼ対称で、電位の関係によってどちらがソースになるかが決まる

集積回路の一般的なMOSFETでは、ソースとドレインは同じ工程で作られる同じ構造の拡散層で、ほぼ対称です。nMOSでは電位の低い側がソース、高い側がドレインとして働くため、トランスミッションゲートやDRAMのセルトランジスタのように電流の向きが入れ替わる使い方ができます。一方、パワーMOSFETやLDMOSは耐圧のためにドレイン側だけ構造を変えた非対称の素子で、入れ替えられません。

  • A. 正しい。対称な構造で、電位で役割が決まります。
  • B. 通常のMOSFETでは、ソースとドレインは同じ濃度でつくられます。
  • C. ソースとドレインは同じ材料・同じ工程でつくられます。

MOSFETのほかの問題

  1. 長チャネルのnMOSFETが飽和領域で動作する条件として正しいものはどれか。(VGS > Vth とする)
  2. nMOSFETのチャネル領域(p型基板)の不純物濃度を高くすると、しきい値電圧はどうなるか。
  3. 他の条件を変えずにゲート絶縁膜を厚くすると、nMOSFETのしきい値電圧の大きさは一般にどうなるか。
  4. MOSFETのゲート長(マスク上や加工後のゲート電極の長さ)と、実効チャネル長の関係として一般的に正しいものはどれか。
  5. MOSFETのパンチスルーの説明として正しいものはどれか。
