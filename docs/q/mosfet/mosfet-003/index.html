MOSFET

CMOSインバータの静的(定常状態の)消費電力が小さい理由として正しいものはどれか。

  1. A電源電圧が高いため
  2. Bゲートに常に電流が流れているため
  3. C入力が0でも1でも、pMOSとnMOSのどちらか一方がオフになり、電源から接地への電流がほとんど流れないため
答えと解説を見る

正解：C. 入力が0でも1でも、pMOSとnMOSのどちらか一方がオフになり、電源から接地への電流がほとんど流れないため

CMOSインバータでは、入力が0のときpMOSがオン・nMOSがオフ、1のときはその逆になり、定常状態では電源と接地の間に必ずオフのトランジスタが入るため貫通電流がほとんど流れません。電力を主に消費するのはスイッチング時の負荷容量の充放電で、P = α·C·V²·f と表されます。ただし微細化でオフ時のリーク電流が増え、先端チップでは静的電力も無視できない割合になっています。

MOSFETのほかの問題

  1. 長チャネルのMOSFETが飽和領域で動作しているとき、ドレイン電流IDはおよそ何に比例するか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  2. 同じ寸法のnMOSとpMOSでは、一般にnMOSの方が駆動電流が大きい。その主な理由はどれか。
  3. nチャネルMOSFETで、ソースに対して基板(ボディ)に負の電圧をかける(基板バイアスをかける)と、しきい値電圧はどうなるか。
  4. デプレッション型MOSFETの特徴として正しいものはどれか。
  5. 室温におけるMOSFETのサブスレッショルド係数(しきい値以下でドレイン電流を1桁変えるのに必要なゲート電圧)の理論的な下限値に最も近いものはどれか。

この分野の比較

  • JFETとMOSFETの違い：ゲート構造と使い分けを比較JFETとMOSFETを、ゲートの構造・ノーマリオンかオフか・ゲート電流・雑音・静電気への強さ・集積度・用途の観点で表にして比較します。
  • nMOSとpMOSの違い：キャリア・移動度・しきい値電圧・CMOSでの役割を比較nMOSとpMOSを、構造・キャリア・移動度・しきい値電圧の符号・オンになる条件・CMOSでの役割・伝えやすい論理レベル・同じ駆動力に必要なゲート幅の観点で表にして比較します。
  • エンハンスメント型とデプレッション型MOSFETの違い：しきい値電圧・記号・用途を比較エンハンスメント型とデプレッション型のMOSFETを、ゲート0 Vでの状態・しきい値電圧の符号・チャネルのでき方・電流の止め方・回路記号・安全性・用途の観点で表にして比較します。
