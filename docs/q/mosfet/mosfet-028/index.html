MOSFET

MOSFETのしきい値電圧の絶対値は、温度が上がると一般にどうなるか。

  1. A大きくなる
  2. B小さくなる
  3. C変化しない
答えと解説を見る

正解：B. 小さくなる

温度が上がるとフェルミ準位がギャップ中央に近づき反転しやすくなるため、しきい値電圧の絶対値は約1〜2 mV/℃で小さくなります。一方で移動度は下がるため、ドレイン電流の温度依存性はゲート電圧によって逆転し、ある電圧では温度によらず電流がほぼ一定になります(温度補償点)。高ゲート電圧では移動度低下が勝って電流が減り、低ゲート電圧ではVth低下が勝ってリークが増えます。

  2. MOSFETがオフの状態で流れるリーク電流の主な成分の組み合わせとして正しいものはどれか。
  3. MOSFETの「MOS」が表す構造として正しいものはどれか。
  4. MOSFETの端子として、ゲート・ソース・ドレインのほかにもう1つあるものはどれか。
  5. nチャネルMOSFETのチャネルで電流を運ぶキャリアはどれか。
