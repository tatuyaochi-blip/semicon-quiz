MOSFET

長チャネルのnMOSFETが飽和領域で動作する条件として正しいものはどれか。(VGS > Vth とする)

  1. AVDS = 0
  2. BVDS < VGS − Vth
  3. CVDS ≥ VGS − Vth
答えと解説を見る

正解：C. VDS ≥ VGS − Vth

VGS > Vth でチャネルがあるとき、VDS ≥ VGS − Vth になるとドレイン端でチャネルがピンチオフし、ドレイン電流はVDSにほとんど依存しなくなります。これが飽和領域です。VDS < VGS − Vth のときは線形(三極管)領域です。

  • A. VDS = 0 では電流は流れません。
  • B. VDS < VGS − Vth は線形領域の条件です。
  • C. 正しい。ドレイン端でピンチオフが起こる条件です。

MOSFETのほかの問題

  1. nMOSFETのチャネル領域(p型基板)の不純物濃度を高くすると、しきい値電圧はどうなるか。
  2. 他の条件を変えずにゲート絶縁膜を厚くすると、nMOSFETのしきい値電圧の大きさは一般にどうなるか。
  3. MOSFETのゲート長(マスク上や加工後のゲート電極の長さ)と、実効チャネル長の関係として一般的に正しいものはどれか。
  4. MOSFETのパンチスルーの説明として正しいものはどれか。
  5. nMOSFETを1個だけ使ったパストランジスタ(スイッチ)で、ゲートを電源電圧VDDにして入力のVDDを出力側へ伝えるとき、出力電圧はおよそどこまで上がるか。
