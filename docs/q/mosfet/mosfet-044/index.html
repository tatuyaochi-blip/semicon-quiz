MOSFET

パワーMOSFETを複数並列に接続して使いやすい理由として、オン抵抗の温度依存性に関する説明で正しいものはどれか。

  1. Aオン抵抗は温度によらず一定である
  2. B温度が上がるとオン抵抗が下がるので、熱い素子にさらに電流が集中する
  3. C温度が上がるとオン抵抗が上がるので、熱くなった素子の電流が自然に減り、電流が分散する
答えと解説を見る

正解：C. 温度が上がるとオン抵抗が上がるので、熱くなった素子の電流が自然に減り、電流が分散する

MOSFETのオン抵抗は、温度が上がると移動度が下がるため大きくなります(正の温度係数)。並列の素子の1つが熱くなると、その抵抗が増えて電流が減り、ほかの素子へ電流が分散するため、熱暴走が起きにくく並列接続しやすい特徴があります。ただししきい値付近の低いゲート電圧では温度係数が負になり、リニア動作やゆっくりしたスイッチングでは電流集中が起こりうるので注意が必要です。

  • A. オン抵抗は温度によって大きく変化します。
  • B. 温度上昇で抵抗が下がり電流が集中する性質は、バイポーラトランジスタの熱暴走の原因になる性質です。
  • C. 正しい。正の温度係数により電流が自然に分散します。

この分野の比較

  • JFETとMOSFETの違い：ゲート構造と使い分けを比較JFETとMOSFETを、ゲートの構造・ノーマリオンかオフか・ゲート電流・雑音・静電気への強さ・集積度・用途の観点で表にして比較します。
  • nMOSとpMOSの違い：キャリア・移動度・しきい値電圧・CMOSでの役割を比較nMOSとpMOSを、構造・キャリア・移動度・しきい値電圧の符号・オンになる条件・CMOSでの役割・伝えやすい論理レベル・同じ駆動力に必要なゲート幅の観点で表にして比較します。
  • エンハンスメント型とデプレッション型MOSFETの違い：しきい値電圧・記号・用途を比較エンハンスメント型とデプレッション型のMOSFETを、ゲート0 Vでの状態・しきい値電圧の符号・チャネルのでき方・電流の止め方・回路記号・安全性・用途の観点で表にして比較します。
