MOSFET

パワーMOSFETを複数並列に接続して使いやすい理由として、オン抵抗の温度依存性に関する説明で正しいものはどれか。

  1. Aオン抵抗は温度によらず一定である
  2. B温度が上がるとオン抵抗が下がるので、熱い素子にさらに電流が集中する
  3. C温度が上がるとオン抵抗が上がるので、熱くなった素子の電流が自然に減り、電流が分散する
答えと解説を見る

正解：C. 温度が上がるとオン抵抗が上がるので、熱くなった素子の電流が自然に減り、電流が分散する

MOSFETのオン抵抗は、温度が上がると移動度が下がるために大きくなります(正の温度係数)。並列に接続した素子のうち1つが熱くなると、その素子の抵抗が増えて電流が減り、ほかの素子へ電流が分散します。そのため熱暴走が起きにくく、並列接続しやすい特徴があります。

  • A. オン抵抗は温度によって大きく変化します。
  • B. 温度上昇で抵抗が下がり電流が集中する性質は、バイポーラトランジスタの熱暴走の原因になる性質です。
  • C. 正しい。正の温度係数により電流が自然に分散します。

MOSFETのほかの問題

  1. デナードのスケーリング則(定電界スケーリング)で、寸法と電圧をそれぞれ1/kにしたときの説明として正しいものはどれか。
  2. MOS構造のフラットバンド電圧の説明として正しいものはどれか。
  3. p型基板のMOSキャパシタを高周波で測定したC-V特性で、ゲートに大きな正の電圧を加えて強反転させたときの容量はどうなるか。
  4. ゲート絶縁膜が非常に薄いMOSFETで、反転層の電子の分布のピークが界面から少し離れた位置にくることによる影響として正しいものはどれか。
  5. 飽和領域にあるMOSFETの小信号の出力抵抗roを、チャネル長変調係数λとドレイン電流IDで表した式として適切なものはどれか。
