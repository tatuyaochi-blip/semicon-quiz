MOSFET

エンハンスメント型pチャネルMOSFETのしきい値電圧(ソース基準)の符号はどれか。

  1. A正の値
  2. B負の値
  3. C必ず0 V
答えと解説を見る

正解：B. 負の値

pチャネルMOSFETでは、ゲートにソースより低い(負の)電圧を加えたときにn型基板の表面に正孔の反転層ができ、オンになります。そのため、エンハンスメント型pMOSのしきい値電圧は負の値になります。

MOSFETのほかの問題

  1. ゲート-ドレイン間の容量が、増幅回路の入力側から見ると(1 + 利得)倍に大きく見える効果を何と呼ぶか。
  2. ポリシリコンゲートで、ゲート電極側のポリシリコンが空乏化することによる問題として正しいものはどれか。
  3. MOSFETのしきい値電圧を下げたときの一般的な影響として正しいものはどれか。
  4. CMOSの2入力NANDゲートのトランジスタの接続として正しいものはどれか。
  5. ゲートとドレインが重なる部分の強い電界によってバンド間トンネル電流が流れ、オフ時のリーク電流が増える現象はどれか。
