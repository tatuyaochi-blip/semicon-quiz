MOSFET

CMOSインバータで、入力が切り替わる途中に電源からグラウンドへ流れる電流を何と呼ぶか。

  1. Aゲートリーク電流
  2. B貫通電流(短絡電流)
  3. Cサブスレッショルド電流
答えと解説を見る

正解：B. 貫通電流(短絡電流)

入力が中間の電圧を通過する間は、nMOSとpMOSが同時にわずかにオンになり、電源からグラウンドへ直接電流が流れます。これが貫通電流(短絡電流)です。入力の遷移が遅いほど長く流れるため、信号の立ち上がり・立ち下がりを速く保つことが大切で、設計ツールは遷移時間の上限(max transition)を守るようにバッファを挿入します。遷移を速く保てば、動的消費電力全体の1割程度以下に収まります。

  • A. ゲートリーク電流は、ゲート絶縁膜を通り抜ける電流です。
  • B. 正しい。両方のトランジスタが同時にオンになる間に流れます。
  • C. サブスレッショルド電流は、オフ状態のトランジスタに流れるリーク電流です。

MOSFETのほかの問題

  1. パワーMOSFETを複数並列に接続して使いやすい理由として、オン抵抗の温度依存性に関する説明で正しいものはどれか。
  2. デナードのスケーリング則(定電界スケーリング)で、寸法と電圧をそれぞれ1/kにしたときの説明として正しいものはどれか。
  3. MOS構造のフラットバンド電圧の説明として正しいものはどれか。
  4. p型基板のMOSキャパシタを高周波で測定したC-V特性で、ゲートに大きな正の電圧を加えて強反転させたときの容量はどうなるか。
  5. ゲート絶縁膜が非常に薄いMOSFETで、反転層の電子の分布のピークが界面から少し離れた位置にくることによる影響として正しいものはどれか。

この分野の比較

  • JFETとMOSFETの違い：ゲート構造と使い分けを比較JFETとMOSFETを、ゲートの構造・ノーマリオンかオフか・ゲート電流・雑音・静電気への強さ・集積度・用途の観点で表にして比較します。
  • nMOSとpMOSの違い：キャリア・移動度・しきい値電圧・CMOSでの役割を比較nMOSとpMOSを、構造・キャリア・移動度・しきい値電圧の符号・オンになる条件・CMOSでの役割・伝えやすい論理レベル・同じ駆動力に必要なゲート幅の観点で表にして比較します。
  • エンハンスメント型とデプレッション型MOSFETの違い：しきい値電圧・記号・用途を比較エンハンスメント型とデプレッション型のMOSFETを、ゲート0 Vでの状態・しきい値電圧の符号・チャネルのでき方・電流の止め方・回路記号・安全性・用途の観点で表にして比較します。
