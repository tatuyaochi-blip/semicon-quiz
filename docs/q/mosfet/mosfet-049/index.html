MOSFET

飽和領域にあるMOSFETの小信号の出力抵抗roを、チャネル長変調係数λとドレイン電流IDで表した式として適切なものはどれか。

  1. Aro ≈ 1 / (λ × ID)
  2. Bro ≈ ID / λ
  3. Cro ≈ λ × ID
答えと解説を見る

正解：A. ro ≈ 1 / (λ × ID)

チャネル長変調を考えると、飽和領域のドレイン電流は ID(1 + λVDS) の形でVDSとともにわずかに増え、この傾きの逆数が出力抵抗 ro ≈ 1/(λID) です。λはチャネル長にほぼ反比例するため、Lを2倍にするとroも約2倍になります。トランジスタ単体の最大電圧利得は gm·ro で、微細なトランジスタでは10〜20倍程度しかないため、カスコードや多段構成で利得を確保します。

  • A. 正しい。ro ≈ 1/(λID) です。
  • B. ID/λ の単位は電流×電圧で、抵抗になりません。
  • C. λ × ID の単位は電流/電圧で、抵抗ではありません。

MOSFETのほかの問題

  1. MOSFETのしきい値電圧を定義するときに用いられる「強反転」の条件として一般的なものはどれか。(φF:フェルミ電位)
  2. エンハンスメント型のnチャネルMOSFETがオン(導通)するための条件として正しいものはどれか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  3. ゲート絶縁膜の材料と面積を変えずに膜厚だけを薄くすると、単位面積あたりのゲート容量はどうなるか。
  4. CMOSインバータの静的(定常状態の)消費電力が小さい理由として正しいものはどれか。
  5. 長チャネルのMOSFETが飽和領域で動作しているとき、ドレイン電流IDはおよそ何に比例するか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
