MOSFET

MOSFETのしきい値電圧を定義するときに用いられる「強反転」の条件として一般的なものはどれか。(φF:フェルミ電位)

  1. A表面電位が −φF になる
  2. B表面電位が 2φF になる(表面の少数キャリア密度が基板の多数キャリア密度に等しくなる)
  3. C表面電位がゼロになる
答えと解説を見る

正解：B. 表面電位が 2φF になる(表面の少数キャリア密度が基板の多数キャリア密度に等しくなる)

強反転の開始は、表面電位が 2φF になるとき、つまり表面の電子密度が基板内部の正孔密度と等しくなるときと定義されるのが一般的です。このときのゲート電圧がしきい値電圧で、Vth = VFB + 2φF + √(2εqNA·2φF)/Cox と表されます。実際の測定では、一定電流になるゲート電圧(定電流法)や、ID-VG曲線の直線部を外挿する方法でVthを決めるため、定義によって値が少し異なります。

  • A. 表面電位が負の向きでは、p型基板の表面は蓄積状態になります。
  • B. 正しい。表面電位 2φF が強反転の目安です。
  • C. 表面電位ゼロはフラットバンドの状態です。

MOSFETのほかの問題

  1. エンハンスメント型のnチャネルMOSFETがオン(導通)するための条件として正しいものはどれか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  2. ゲート絶縁膜の材料と面積を変えずに膜厚だけを薄くすると、単位面積あたりのゲート容量はどうなるか。
  3. CMOSインバータの静的(定常状態の)消費電力が小さい理由として正しいものはどれか。
  4. 長チャネルのMOSFETが飽和領域で動作しているとき、ドレイン電流IDはおよそ何に比例するか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  5. 同じ寸法のnMOSとpMOSでは、一般にnMOSの方が駆動電流が大きい。その主な理由はどれか。
