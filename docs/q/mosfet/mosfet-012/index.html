MOSFET

MOSFETの相互コンダクタンスgmの定義として正しいものはどれか。

  1. Aゲート電圧の変化に対するドレイン電流の変化の割合
  2. Bドレイン電圧をドレイン電流で割った値
  3. Cゲート絶縁膜の容量
答えと解説を見る

正解：A. ゲート電圧の変化に対するドレイン電流の変化の割合

相互コンダクタンスは gm = ΔID / ΔVGS で表され、ゲート電圧の変化がドレイン電流をどれだけ変化させるかを示します。gmが大きいほど増幅回路の利得を大きくでき、トランジスタの性能を表す重要な指標です。

MOSFETのほかの問題

  1. p型基板のMOS構造で、ゲートに負の電圧を加えたときの半導体表面の状態として正しいものはどれか。
  2. CMOSインバータの論理しきい値電圧を電源電圧のほぼ半分にするための設計として正しいものはどれか。
  3. nMOSとpMOSを並列に接続したトランスミッションゲートの利点として正しいものはどれか。
  4. MOSFETのゲート-ソース間に、定格を大きく超える電圧を加えたときに起こりうる破壊はどれか。
  5. MOSFETのチャネルの移動度が、シリコン結晶内部の移動度より小さくなる主な理由として正しいものはどれか。
