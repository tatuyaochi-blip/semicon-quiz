MOSFET

MOSFETのパンチスルーの説明として正しいものはどれか。

  1. Aチャネルの移動度が温度で下がること
  2. Bソースとドレインの空乏層がつながり、ゲートで制御できない電流が流れること
  3. Cゲート絶縁膜が絶縁破壊すること
答えと解説を見る

正解：B. ソースとドレインの空乏層がつながり、ゲートで制御できない電流が流れること

チャネルが短く基板の濃度が低いと、ドレイン電圧を上げたときにドレイン側の空乏層がソース側の空乏層とつながります。するとゲートとは関係なく基板の深い部分を電流が流れ、トランジスタをオフにできなくなります。これをパンチスルーといいます。

  • A. 移動度の温度変化はパンチスルーではありません。
  • B. 正しい。空乏層がつながって制御できない電流が流れます。
  • C. 絶縁膜の破壊はゲート絶縁破壊で、パンチスルーとは別の現象です。

MOSFETのほかの問題

  1. nMOSFETを1個だけ使ったパストランジスタ(スイッチ)で、ゲートを電源電圧VDDにして入力のVDDを出力側へ伝えるとき、出力電圧はおよそどこまで上がるか。
  2. CMOSインバータで、入力が切り替わる途中に電源からグラウンドへ流れる電流を何と呼ぶか。
  3. パワーMOSFETを複数並列に接続して使いやすい理由として、オン抵抗の温度依存性に関する説明で正しいものはどれか。
  4. デナードのスケーリング則(定電界スケーリング)で、寸法と電圧をそれぞれ1/kにしたときの説明として正しいものはどれか。
  5. MOS構造のフラットバンド電圧の説明として正しいものはどれか。
