MOSFET

nMOSFETを1個だけ使ったパストランジスタ(スイッチ)で、ゲートを電源電圧VDDにして入力のVDDを出力側へ伝えるとき、出力電圧はおよそどこまで上がるか。

  1. AVDD まで
  2. BVDD + Vth まで
  3. CVDD − Vth まで
答えと解説を見る

正解：C. VDD − Vth まで

nMOSはゲート-ソース間電圧がVthを下回るとオフになるため、出力(ソース側)が VDD − Vth に近づくと電流がほとんど流れなくなり、それ以上上がりません。さらにソース電位が上がるとボディ効果でVthも上がり、実際の到達電圧はもう少し低くなります。弱い1は次段のpMOSを完全にオフにできず、リーク電流の原因になります。0は完全に伝わるため、pMOSと組み合わせたトランスミッションゲートが使われます。

  • A. VDDまで上げるには、pMOSを並列にするなどの工夫が必要です。
  • B. ゲート電圧より高い電圧を出すことはできません。
  • C. 正しい。しきい値電圧の分だけ低い電圧で止まります。

MOSFETのほかの問題

  1. CMOSインバータで、入力が切り替わる途中に電源からグラウンドへ流れる電流を何と呼ぶか。
  2. パワーMOSFETを複数並列に接続して使いやすい理由として、オン抵抗の温度依存性に関する説明で正しいものはどれか。
  3. デナードのスケーリング則(定電界スケーリング)で、寸法と電圧をそれぞれ1/kにしたときの説明として正しいものはどれか。
  4. MOS構造のフラットバンド電圧の説明として正しいものはどれか。
  5. p型基板のMOSキャパシタを高周波で測定したC-V特性で、ゲートに大きな正の電圧を加えて強反転させたときの容量はどうなるか。

この分野の比較

  • JFETとMOSFETの違い：ゲート構造と使い分けを比較JFETとMOSFETを、ゲートの構造・ノーマリオンかオフか・ゲート電流・雑音・静電気への強さ・集積度・用途の観点で表にして比較します。
  • nMOSとpMOSの違い：キャリア・移動度・しきい値電圧・CMOSでの役割を比較nMOSとpMOSを、構造・キャリア・移動度・しきい値電圧の符号・オンになる条件・CMOSでの役割・伝えやすい論理レベル・同じ駆動力に必要なゲート幅の観点で表にして比較します。
  • エンハンスメント型とデプレッション型MOSFETの違い：しきい値電圧・記号・用途を比較エンハンスメント型とデプレッション型のMOSFETを、ゲート0 Vでの状態・しきい値電圧の符号・チャネルのでき方・電流の止め方・回路記号・安全性・用途の観点で表にして比較します。
