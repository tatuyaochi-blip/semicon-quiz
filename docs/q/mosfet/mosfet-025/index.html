MOSFET

ゲートとドレインが重なる部分の強い電界によってバンド間トンネル電流が流れ、オフ時のリーク電流が増える現象はどれか。

  1. ADIBL
  2. BNBTI
  3. CGIDL(ゲート誘起ドレインリーク)
答えと解説を見る

正解：C. GIDL(ゲート誘起ドレインリーク)

トランジスタがオフでも、ゲートとドレインの間に大きな電圧がかかっていると、ドレインのゲート端付近で電界が強くなり、バンド間トンネル効果によって電流が流れます。これをGIDLといい、DRAMのセルトランジスタなど、リーク電流を極めて小さくしたい素子で問題になります。

MOSFETのほかの問題

  1. MOSFETのゲートにほとんど電流が流れないことによる回路上の利点として正しいものはどれか。
  2. MOSFETのソースフォロワ(ドレイン接地)回路の特徴として正しいものはどれか。
  3. MOSFETのしきい値電圧の絶対値は、温度が上がると一般にどうなるか。
  4. MOSFETのドレイン電流を大きくするための寸法の変え方として正しいものはどれか。
  5. MOSFETがオフの状態で流れるリーク電流の主な成分の組み合わせとして正しいものはどれか。
