MOSFET

MOS構造のフラットバンド電圧の説明として正しいものはどれか。

  1. Aチャネルが強反転するときのゲート電圧
  2. Bゲート絶縁膜が破壊するときのゲート電圧
  3. C半導体表面でバンドが曲がらない(平らになる)ときのゲート電圧
答えと解説を見る

正解：C. 半導体表面でバンドが曲がらない(平らになる)ときのゲート電圧

フラットバンド電圧VFBは、半導体表面のバンドが曲がらず平らになるゲート電圧で、VFB = φms − Qox/Cox(仕事関数差と、絶縁膜中・界面の電荷)で決まります。しきい値電圧はVFBに、反転に必要な2φFと空乏層電荷による電圧を加えたものです。C-V測定でVFBのずれを見れば、絶縁膜中の電荷や汚染(Naイオンなど)を評価でき、プロセス管理の重要な指標になっています。

  • A. 強反転するときの電圧はしきい値電圧です。
  • B. 絶縁膜が破壊する電圧は絶縁破壊電圧です。
  • C. 正しい。表面のバンドが平らになるときのゲート電圧です。

MOSFETのほかの問題

  1. p型基板のMOSキャパシタを高周波で測定したC-V特性で、ゲートに大きな正の電圧を加えて強反転させたときの容量はどうなるか。
  2. ゲート絶縁膜が非常に薄いMOSFETで、反転層の電子の分布のピークが界面から少し離れた位置にくることによる影響として正しいものはどれか。
  3. 飽和領域にあるMOSFETの小信号の出力抵抗roを、チャネル長変調係数λとドレイン電流IDで表した式として適切なものはどれか。
  4. MOSFETのしきい値電圧を定義するときに用いられる「強反転」の条件として一般的なものはどれか。(φF:フェルミ電位)
  5. エンハンスメント型のnチャネルMOSFETがオン(導通)するための条件として正しいものはどれか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)

この分野の比較

  • JFETとMOSFETの違い：ゲート構造と使い分けを比較JFETとMOSFETを、ゲートの構造・ノーマリオンかオフか・ゲート電流・雑音・静電気への強さ・集積度・用途の観点で表にして比較します。
  • nMOSとpMOSの違い：キャリア・移動度・しきい値電圧・CMOSでの役割を比較nMOSとpMOSを、構造・キャリア・移動度・しきい値電圧の符号・オンになる条件・CMOSでの役割・伝えやすい論理レベル・同じ駆動力に必要なゲート幅の観点で表にして比較します。
  • エンハンスメント型とデプレッション型MOSFETの違い：しきい値電圧・記号・用途を比較エンハンスメント型とデプレッション型のMOSFETを、ゲート0 Vでの状態・しきい値電圧の符号・チャネルのでき方・電流の止め方・回路記号・安全性・用途の観点で表にして比較します。
