MOSFET

他の条件を変えずにゲート絶縁膜を厚くすると、nMOSFETのしきい値電圧の大きさは一般にどうなるか。

  1. Aゼロになる
  2. B大きくなる
  3. C小さくなる
答えと解説を見る

正解：B. 大きくなる

ゲート絶縁膜を厚くするとCoxが小さくなり、同じ空乏層電荷を支えるのに必要なゲート電圧が増えるため、しきい値電圧の大きさは大きくなります(Vth = VFB + 2φF + Qd/Cox の第3項が増える)。同じチップ内でも、コア回路には薄い膜、1.8 Vや3.3 Vの入出力回路には厚い膜のトランジスタを使い分けます(デュアルゲート酸化膜)。厚膜のトランジスタは耐圧が高い代わりに遅く、Vthも高めです。

  • A. 絶縁膜の厚さだけでしきい値電圧がゼロになることはありません。
  • B. 正しい。Coxが小さくなるので、必要なゲート電圧が増えます。
  • C. 絶縁膜を薄くするとしきい値電圧は小さくなる方向です。

MOSFETのほかの問題

  1. MOSFETのゲート長(マスク上や加工後のゲート電極の長さ)と、実効チャネル長の関係として一般的に正しいものはどれか。
  2. MOSFETのパンチスルーの説明として正しいものはどれか。
  3. nMOSFETを1個だけ使ったパストランジスタ(スイッチ)で、ゲートを電源電圧VDDにして入力のVDDを出力側へ伝えるとき、出力電圧はおよそどこまで上がるか。
  4. CMOSインバータで、入力が切り替わる途中に電源からグラウンドへ流れる電流を何と呼ぶか。
  5. パワーMOSFETを複数並列に接続して使いやすい理由として、オン抵抗の温度依存性に関する説明で正しいものはどれか。
