MOSFET

MOSFETのしきい値電圧を下げたときの一般的な影響として正しいものはどれか。

  1. A駆動電流は増えるが、オフ時のリーク電流も増える
  2. B駆動電流もリーク電流も減る
  3. C何も変化しない
答えと解説を見る

正解：A. 駆動電流は増えるが、オフ時のリーク電流も増える

しきい値電圧を下げると、同じ電源電圧でもゲートの実効的な駆動力が増え、オン電流が増えます。一方で、サブスレッショルド特性によりオフ時のリーク電流は指数関数的に増えます。そのため、高速用と低リーク用でしきい値電圧の異なるトランジスタを使い分けます。

MOSFETのほかの問題

  1. CMOSの2入力NANDゲートのトランジスタの接続として正しいものはどれか。
  2. ゲートとドレインが重なる部分の強い電界によってバンド間トンネル電流が流れ、オフ時のリーク電流が増える現象はどれか。
  3. MOSFETのゲートにほとんど電流が流れないことによる回路上の利点として正しいものはどれか。
  4. MOSFETのソースフォロワ(ドレイン接地)回路の特徴として正しいものはどれか。
  5. MOSFETのしきい値電圧の絶対値は、温度が上がると一般にどうなるか。
