MOSFET

デナードのスケーリング則(定電界スケーリング)で、寸法と電圧をそれぞれ1/kにしたときの説明として正しいものはどれか。

  1. A回路の遅延は1/kになり、消費電力密度は一定に保たれる
  2. B回路の遅延はk倍になる
  3. C消費電力密度はk²倍になる
答えと解説を見る

正解：A. 回路の遅延は1/kになり、消費電力密度は一定に保たれる

デナードのスケーリング則では、寸法・電圧を1/k、不純物濃度をk倍にすると、電界を一定に保ったまま遅延は1/k、1素子の電力は1/k²、面積も1/k²になり、電力密度は一定です。1974年に示され、30年近く微細化の指針になりました。しかしサブスレッショルドリークのためVthと電源電圧を下げられなくなった2000年代半ば以降は崩れ、クロック周波数の伸びが止まってマルチコア化が進みました。

  • A. 正しい。速くなり、電力密度は一定に保たれます。
  • B. 寸法が小さくなると遅延は小さく(速く)なります。
  • C. 電圧も下げるため、電力密度は理想的には一定です。

MOSFETのほかの問題

  1. MOS構造のフラットバンド電圧の説明として正しいものはどれか。
  2. p型基板のMOSキャパシタを高周波で測定したC-V特性で、ゲートに大きな正の電圧を加えて強反転させたときの容量はどうなるか。
  3. ゲート絶縁膜が非常に薄いMOSFETで、反転層の電子の分布のピークが界面から少し離れた位置にくることによる影響として正しいものはどれか。
  4. 飽和領域にあるMOSFETの小信号の出力抵抗roを、チャネル長変調係数λとドレイン電流IDで表した式として適切なものはどれか。
  5. MOSFETのしきい値電圧を定義するときに用いられる「強反転」の条件として一般的なものはどれか。(φF:フェルミ電位)

この分野の比較

  • JFETとMOSFETの違い：ゲート構造と使い分けを比較JFETとMOSFETを、ゲートの構造・ノーマリオンかオフか・ゲート電流・雑音・静電気への強さ・集積度・用途の観点で表にして比較します。
  • nMOSとpMOSの違い：キャリア・移動度・しきい値電圧・CMOSでの役割を比較nMOSとpMOSを、構造・キャリア・移動度・しきい値電圧の符号・オンになる条件・CMOSでの役割・伝えやすい論理レベル・同じ駆動力に必要なゲート幅の観点で表にして比較します。
  • エンハンスメント型とデプレッション型MOSFETの違い：しきい値電圧・記号・用途を比較エンハンスメント型とデプレッション型のMOSFETを、ゲート0 Vでの状態・しきい値電圧の符号・チャネルのでき方・電流の止め方・回路記号・安全性・用途の観点で表にして比較します。
