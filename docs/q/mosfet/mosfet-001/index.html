MOSFET

エンハンスメント型のnチャネルMOSFETがオン(導通)するための条件として正しいものはどれか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)

  1. AVGSが0 Vであること
  2. BVGSがVthより大きいこと
  3. CVGSが負の電圧であること
答えと解説を見る

正解：B. VGSがVthより大きいこと

エンハンスメント型のnMOSFETでは、ゲートにVthを超える正の電圧を加えると、p型基板の表面に電子が引き寄せられて反転層(チャネル)ができ、ソースとドレインの間に電流が流れます。VGS = 0 Vではチャネルがなくオフなので、ゲートが浮いても電流が流れにくく(ノーマリーオフ)、論理回路やパワー用途の安全性に向きます。Vthは先端ロジックで0.2〜0.4 V、パワー用で1〜4 V程度が一般的です。

MOSFETのほかの問題

  1. ゲート絶縁膜の材料と面積を変えずに膜厚だけを薄くすると、単位面積あたりのゲート容量はどうなるか。
  2. CMOSインバータの静的(定常状態の)消費電力が小さい理由として正しいものはどれか。
  3. 長チャネルのMOSFETが飽和領域で動作しているとき、ドレイン電流IDはおよそ何に比例するか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)
  4. 同じ寸法のnMOSとpMOSでは、一般にnMOSの方が駆動電流が大きい。その主な理由はどれか。
  5. nチャネルMOSFETで、ソースに対して基板(ボディ)に負の電圧をかける(基板バイアスをかける)と、しきい値電圧はどうなるか。
