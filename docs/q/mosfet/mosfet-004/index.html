MOSFET

長チャネルのMOSFETが飽和領域で動作しているとき、ドレイン電流IDはおよそ何に比例するか。(VGS:ゲート-ソース間電圧、Vth:しきい値電圧)

  1. A(VGS − Vth)の2乗
  2. BVGS − Vth
  3. CVGSの逆数
答えと解説を見る

正解：A. (VGS − Vth)の2乗

長チャネルMOSFETの飽和領域では ID = (1/2)μCox(W/L)(VGS − Vth)² で、ドレイン電流は(VGS − Vth)の2乗に比例します(2乗則)。VGS − Vth はオーバードライブ電圧と呼ばれ、アナログ設計の基本パラメータです。短チャネルでは速度飽和によって1乗に近づき、さらに移動度の劣化や寄生抵抗の影響でずれるため、実際の設計ではBSIMなどの精密なモデルを使います。

MOSFETのほかの問題

  1. 同じ寸法のnMOSとpMOSでは、一般にnMOSの方が駆動電流が大きい。その主な理由はどれか。
  2. nチャネルMOSFETで、ソースに対して基板(ボディ)に負の電圧をかける(基板バイアスをかける)と、しきい値電圧はどうなるか。
  3. デプレッション型MOSFETの特徴として正しいものはどれか。
  4. 室温におけるMOSFETのサブスレッショルド係数(しきい値以下でドレイン電流を1桁変えるのに必要なゲート電圧)の理論的な下限値に最も近いものはどれか。
  5. ドレイン-ソース間電圧VDSが十分小さい線形領域でのMOSFETの振る舞いとして正しいものはどれか。
