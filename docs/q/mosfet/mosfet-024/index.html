MOSFET

CMOSの2入力NANDゲートのトランジスタの接続として正しいものはどれか。

  1. ApMOS2個を直列、nMOS2個を並列に接続する
  2. BpMOS2個を並列、nMOS2個を直列に接続する
  3. C4個すべてを並列に接続する
答えと解説を見る

正解：B. pMOS2個を並列、nMOS2個を直列に接続する

NANDは両方の入力が1のときだけ出力が0になるため、出力と接地の間にnMOSを直列に入れ、両方オンのときだけ0につながるようにします。出力と電源の間にはpMOSを並列に入れ、どちらかの入力が0なら1につながるようにします。NORはこの逆の接続になります。

MOSFETのほかの問題

  1. ゲートとドレインが重なる部分の強い電界によってバンド間トンネル電流が流れ、オフ時のリーク電流が増える現象はどれか。
  2. MOSFETのゲートにほとんど電流が流れないことによる回路上の利点として正しいものはどれか。
  3. MOSFETのソースフォロワ(ドレイン接地)回路の特徴として正しいものはどれか。
  4. MOSFETのしきい値電圧の絶対値は、温度が上がると一般にどうなるか。
  5. MOSFETのドレイン電流を大きくするための寸法の変え方として正しいものはどれか。
