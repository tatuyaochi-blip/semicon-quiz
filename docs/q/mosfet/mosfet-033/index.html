MOSFET

nチャネルMOSFETのチャネルで電流を運ぶキャリアはどれか。

  1. A正孔
  2. Bイオン
  3. C電子
答えと解説を見る

正解：C. 電子

nチャネルMOSFETでは、p型基板の表面にゲート電圧で電子を引き寄せて反転層をつくり、その電子がソースからドレインへ流れて電流を運びます。pチャネルMOSFETでは正孔が電流を運びます。

  • A. 正孔が電流を運ぶのはpチャネルMOSFETです。
  • B. MOSFETのチャネルではイオンは電流を運びません。
  • C. 正しい。nチャネルでは電子が電流を運びます。

MOSFETのほかの問題

  1. CMOSの「C(Complementary:相補型)」が表す意味として正しいものはどれか。
  2. MOSFETをスイッチとして使うときの「オン抵抗」の説明として正しいものはどれか。
  3. 一般的な集積回路のMOSFETで、ソースとドレインの関係として正しいものはどれか。
  4. 長チャネルのnMOSFETが飽和領域で動作する条件として正しいものはどれか。(VGS > Vth とする)
  5. nMOSFETのチャネル領域(p型基板)の不純物濃度を高くすると、しきい値電圧はどうなるか。
