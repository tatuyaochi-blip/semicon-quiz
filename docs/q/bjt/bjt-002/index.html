バイポーラトランジスタ

バイポーラトランジスタの直流電流増幅率hFEを表す式はどれか。(IC:コレクタ電流、IB:ベース電流、IE:エミッタ電流)

  1. AIB / IC
  2. BIC / IB
  3. CIE / IC
答えと解説を見る

正解：B. IC / IB

hFEはエミッタ接地での直流電流増幅率で、hFE = IC / IB です。小さなベース電流で大きなコレクタ電流を制御できることを表し、一般的な小信号トランジスタでは数十〜数百程度の値になります。

バイポーラトランジスタのほかの問題

  1. バイポーラトランジスタのベース幅を薄くする主な理由として最も適切なものはどれか。
  2. バイポーラトランジスタをスイッチとして使うとき、オンの状態に対応する動作領域はどれか。
  3. エミッタ接地増幅回路の出力電圧の位相は、入力電圧に対してどうなるか。
  4. NPNトランジスタで、エミッタの不純物濃度をベースより高くする主な理由はどれか。
  5. ベース接地電流増幅率α = 0.99のバイポーラトランジスタのエミッタ接地電流増幅率βはおよそいくらか。
