バイポーラトランジスタ

NPNトランジスタを増幅に使う(能動領域で動作させる)ときのバイアス条件として正しいものはどれか。

  1. Aベース-エミッタ間は順方向、ベース-コレクタ間は逆方向
  2. Bベース-エミッタ間は逆方向、ベース-コレクタ間は順方向
  3. Cベース-エミッタ間、ベース-コレクタ間ともに順方向
答えと解説を見る

正解：A. ベース-エミッタ間は順方向、ベース-コレクタ間は逆方向

能動領域では、ベース-エミッタ接合を順方向にしてエミッタからベースへ電子を注入し、ベース-コレクタ接合を逆方向にして、ベースを通り抜けた電子を強い電界でコレクタへ引き込みます。コレクタ電流はコレクタ電圧にほとんど左右されず、ベース電流(またはVBE)で決まるため増幅ができます。両方が順方向なら飽和領域(スイッチのオン)、両方が逆方向なら遮断領域(オフ)です。

バイポーラトランジスタのほかの問題

  1. バイポーラトランジスタの直流電流増幅率hFEを表す式はどれか。(IC:コレクタ電流、IB:ベース電流、IE:エミッタ電流)
  2. バイポーラトランジスタのベース幅を薄くする主な理由として最も適切なものはどれか。
  3. バイポーラトランジスタをスイッチとして使うとき、オンの状態に対応する動作領域はどれか。
  4. エミッタ接地増幅回路の出力電圧の位相は、入力電圧に対してどうなるか。
  5. NPNトランジスタで、エミッタの不純物濃度をベースより高くする主な理由はどれか。

この分野の比較

  • BJTとMOSFETの違い：制御方式・速度・用途を比較バイポーラトランジスタ(BJT)とMOSFETを、制御方式・入力電流・キャリア・速度・オン状態・温度特性・集積度・用途の観点で表にして比較します。
  • NPNトランジスタとPNPトランジスタの違い：構造・電流の向き・回路記号・使い方を比較バイポーラトランジスタのNPN型とPNP型を、半導体の並び・主なキャリア・バイアスのかけ方・電流の向き・回路記号の矢印・スイッチとしてのつなぎ方・性能の観点で表にして比較します。
