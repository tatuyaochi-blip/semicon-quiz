バイポーラトランジスタ

NPNトランジスタを増幅に使う(能動領域で動作させる)ときのバイアス条件として正しいものはどれか。

  1. Aベース-エミッタ間は順方向、ベース-コレクタ間は逆方向
  2. Bベース-エミッタ間は逆方向、ベース-コレクタ間は順方向
  3. Cベース-エミッタ間、ベース-コレクタ間ともに順方向
答えと解説を見る

正解：A. ベース-エミッタ間は順方向、ベース-コレクタ間は逆方向

能動領域では、ベース-エミッタ接合を順方向にしてエミッタからベースへキャリアを注入し、ベース-コレクタ接合を逆方向にしてそのキャリアをコレクタへ引き込みます。両方の接合が順方向になる状態は飽和領域で、スイッチのオン状態に相当します。

バイポーラトランジスタのほかの問題

  1. バイポーラトランジスタの直流電流増幅率hFEを表す式はどれか。(IC:コレクタ電流、IB:ベース電流、IE:エミッタ電流)
  2. バイポーラトランジスタのベース幅を薄くする主な理由として最も適切なものはどれか。
  3. バイポーラトランジスタをスイッチとして使うとき、オンの状態に対応する動作領域はどれか。
  4. エミッタ接地増幅回路の出力電圧の位相は、入力電圧に対してどうなるか。
  5. NPNトランジスタで、エミッタの不純物濃度をベースより高くする主な理由はどれか。
