バイポーラトランジスタ

バイポーラトランジスタのエミッタ電流IE、ベース電流IB、コレクタ電流ICの関係として正しいものはどれか。

  1. AIE = IC − IB
  2. BIE = IB × IC
  3. CIE = IB + IC
答えと解説を見る

正解：C. IE = IB + IC

トランジスタに流れ込む電流と流れ出る電流は等しいので、エミッタ電流はベース電流とコレクタ電流の和、IE = IB + IC になります。IBはICよりずっと小さいので、IE ≈ IC とみなせることも多くあります。

  • A. ベース電流とコレクタ電流はどちらもエミッタに流れ込む(NPNの場合)ので、差ではなく和になります。
  • B. 電流の関係は和であり、積ではありません。
  • C. 正しい。キルヒホッフの電流則より IE = IB + IC です。

バイポーラトランジスタのほかの問題

  1. 直流電流増幅率hFE = 100のトランジスタにベース電流10 μAを流したとき、能動領域でのコレクタ電流はおよそいくらか。
  2. バイポーラトランジスタが遮断領域(オフ)にあるときの接合の状態として正しいものはどれか。
  3. 能動領域で動作しているシリコンのバイポーラトランジスタのベース-エミッタ間電圧VBEの目安として正しいものはどれか。
  4. コレクタ-エミッタ間電圧5 V、コレクタ電流100 mAで動作しているトランジスタのコレクタ損失はいくらか。
  5. バイポーラトランジスタとMOSFETの制御の違いとして正しいものはどれか。
