バイポーラトランジスタ

エミッタ接地増幅回路の高周波特性を悪くするミラー効果の説明として正しいものはどれか。

  1. Aベース-コレクタ間の容量が、電圧利得に応じて入力側から見て大きな容量に見える
  2. Bエミッタの抵抗が温度によって変化する
  3. Cコレクタ電流が熱雑音で揺らぐ
答えと解説を見る

正解：A. ベース-コレクタ間の容量が、電圧利得に応じて入力側から見て大きな容量に見える

エミッタ接地回路ではコレクタの電圧がベースと逆位相で大きく振れるため、ベース-コレクタ間の容量Cμは入力側から見ると約(1 + |Av|)倍に大きく見えます。この大きな入力容量が信号源の抵抗とともに帯域を狭めます。カスコード接続などで対策します。

  • A. 正しい。帰還容量が利得倍されて見えるのがミラー効果です。
  • B. 温度による抵抗変化はミラー効果ではありません。
  • C. 熱雑音はミラー効果とは別の現象です。

バイポーラトランジスタのほかの問題

  1. ベース-コレクタ間にショットキーバリアダイオードを並列に入れたトランジスタ(ショットキークランプ)の狙いとして正しいものはどれか。
  2. NPNトランジスタを増幅に使う(能動領域で動作させる)ときのバイアス条件として正しいものはどれか。
  3. バイポーラトランジスタの直流電流増幅率hFEを表す式はどれか。(IC:コレクタ電流、IB:ベース電流、IE:エミッタ電流)
  4. バイポーラトランジスタのベース幅を薄くする主な理由として最も適切なものはどれか。
  5. バイポーラトランジスタをスイッチとして使うとき、オンの状態に対応する動作領域はどれか。
