バイポーラトランジスタ

増幅回路の段と段の間に入れる結合コンデンサの役割として正しいものはどれか。

  1. A信号を増幅する
  2. B直流のバイアスを互いに分離し、交流の信号だけを伝える
  3. C交流を直流に変換する
答えと解説を見る

正解：B. 直流のバイアスを互いに分離し、交流の信号だけを伝える

コンデンサは直流を通さず、交流を通します。段間に結合コンデンサを入れると、前段と後段の直流のバイアス電圧が互いに影響しないように分離しつつ、交流の信号だけを伝えられます。低い周波数ではインピーダンスが大きくなるため、低域の利得が下がる原因にもなります。

バイポーラトランジスタのほかの問題

  1. シリコンのバイポーラトランジスタの電流増幅率hFEは、一般に温度が上がるとどうなるか。
  2. エミッタ接地増幅回路の小信号の入力抵抗(hie)を大きくする条件として正しいものはどれか。
  3. 増幅回路の負荷抵抗の代わりに、電流源として働くトランジスタを使う能動負荷の利点として正しいものはどれか。
  4. スイッチ用のトランジスタを深い飽和状態からオフにするとき、オフになるまでに時間がかかる主な理由はどれか。
  5. バイポーラトランジスタで構成された代表的な論理ICの系列はどれか。
