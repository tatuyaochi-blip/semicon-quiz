バイポーラトランジスタ

増幅回路の段と段の間に入れる結合コンデンサの役割として正しいものはどれか。

  1. A信号を増幅する
  2. B直流のバイアスを互いに分離し、交流の信号だけを伝える
  3. C交流を直流に変換する
答えと解説を見る

正解：B. 直流のバイアスを互いに分離し、交流の信号だけを伝える

コンデンサは直流を通さず交流を通すため、段間に結合コンデンサを入れると、前段と後段のバイアス電圧を分離したまま信号だけを伝えられます。ただし次段の入力抵抗Rとともにハイパスフィルタになり、遮断周波数 f = 1/(2πRC) より低い周波数は減衰します。オーディオなら20 Hz以下になるよう容量を選びます。ICの内部では大きな容量を作れないため、直結(直流結合)で設計するのが一般的です。
