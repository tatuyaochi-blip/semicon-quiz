バイポーラトランジスタ

バイポーラトランジスタの大信号動作を、2つのダイオードと電流源で表したモデルはどれか。

  1. Aショックレーの空乏近似
  2. Bポアソンモデル
  3. Cエバース・モルモデル
答えと解説を見る

正解：C. エバース・モルモデル

エバース・モルモデルは、ベース-エミッタ接合とベース-コレクタ接合をそれぞれダイオードとし、一方の接合の電流に比例して他方に電流を流す従属電流源を組み合わせたモデルです。能動・飽和・遮断・逆能動のすべての領域を1つの式で扱えます。これにアーリー効果や高注入効果、電荷の蓄積を加えたのがガンメル・プーンモデルで、SPICEのバイポーラモデルの基礎になっています。

  • A. 空乏近似はPN接合の空乏層を解析するための近似で、トランジスタ全体のモデルではありません。
  • B. ポアソンモデルは歩留まりの計算などに使われるモデルです。
  • C. 正しい。2つのダイオードと従属電流源で表すモデルです。

バイポーラトランジスタのほかの問題

  1. バイポーラトランジスタの電流増幅率hFEのコレクタ電流依存性として正しいものはどれか。
  2. ベースを開放したときのコレクタ-エミッタ間の降伏電圧BVCEOと、エミッタを開放したときのコレクタ-ベース間の降伏電圧BVCBOの関係として正しいものはどれか。
  3. エミッタ接地増幅回路の高周波特性を悪くするミラー効果の説明として正しいものはどれか。
  4. ベース-コレクタ間にショットキーバリアダイオードを並列に入れたトランジスタ(ショットキークランプ)の狙いとして正しいものはどれか。
  5. NPNトランジスタを増幅に使う(能動領域で動作させる)ときのバイアス条件として正しいものはどれか。
