バイポーラトランジスタ

バイポーラトランジスタの3つの端子の組み合わせとして正しいものはどれか。

  1. Aエミッタ・ベース・コレクタ
  2. Bアノード・カソード・ゲート
  3. Cソース・ゲート・ドレイン
答えと解説を見る

正解：A. エミッタ・ベース・コレクタ

バイポーラトランジスタの端子は、キャリアを注入するエミッタ(emit=放出)、電流を制御するベース、キャリアを集めるコレクタ(collect=集める)の3つです。名前のとおり役割が決まっており、構造上エミッタは高濃度、コレクタは低濃度で大きく作られているため、エミッタとコレクタを入れ替えて使うと電流増幅率が大きく下がります。ベースの名前は、最初の点接触トランジスタで土台だったことに由来します。

  • A. 正しい。エミッタ・ベース・コレクタです。
  • B. アノード・カソード・ゲートはサイリスタの端子です。
  • C. ソース・ゲート・ドレインはMOSFETの端子です。

バイポーラトランジスタのほかの問題

  1. NPNトランジスタの回路記号で、エミッタに付いている矢印の向きとして正しいものはどれか。
  2. バイポーラトランジスタのエミッタ電流IE、ベース電流IB、コレクタ電流ICの関係として正しいものはどれか。
  3. 直流電流増幅率hFE = 100のトランジスタにベース電流10 μAを流したとき、能動領域でのコレクタ電流はおよそいくらか。
  4. バイポーラトランジスタが遮断領域(オフ)にあるときの接合の状態として正しいものはどれか。
  5. 能動領域で動作しているシリコンのバイポーラトランジスタのベース-エミッタ間電圧VBEの目安として正しいものはどれか。
