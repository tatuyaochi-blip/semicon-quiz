バイポーラトランジスタ

NPNとPNPのトランジスタで正と負の半周期を分担するB級プッシュプル増幅回路で生じやすいひずみはどれか。

  1. A量子化誤差
  2. Bエイリアシング
  3. Cクロスオーバーひずみ
答えと解説を見る

正解：C. クロスオーバーひずみ

B級プッシュプル回路では、入力が0付近のとき、どちらのトランジスタもベース-エミッタ間電圧が足りずに導通しない区間ができ、波形が切り替わる部分がひずみます。これをクロスオーバーひずみといい、わずかにバイアス電流を流すAB級にすることで低減します。

バイポーラトランジスタのほかの問題

  1. 増幅回路の段と段の間に入れる結合コンデンサの役割として正しいものはどれか。
  2. シリコンのバイポーラトランジスタの電流増幅率hFEは、一般に温度が上がるとどうなるか。
  3. エミッタ接地増幅回路の小信号の入力抵抗(hie)を大きくする条件として正しいものはどれか。
  4. 増幅回路の負荷抵抗の代わりに、電流源として働くトランジスタを使う能動負荷の利点として正しいものはどれか。
  5. スイッチ用のトランジスタを深い飽和状態からオフにするとき、オフになるまでに時間がかかる主な理由はどれか。
