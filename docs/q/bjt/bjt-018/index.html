バイポーラトランジスタ

2つのトランジスタのエミッタを共通の電流源につないだ差動対の働きとして正しいものはどれか。

  1. A2つの入力電圧の和を増幅する
  2. B2つの入力電圧の差を増幅する
  3. C入力電圧を整流する
答えと解説を見る

正解：B. 2つの入力電圧の差を増幅する

差動対では、2つの入力電圧の差に応じて、共通の電流源の電流が2つのトランジスタに分配されます。両方の入力が同じように変化(同相)しても分配は変わらないため、差だけが増幅され、電源ノイズや温度変化など両方に同じように乗る成分は打ち消されます。差動利得と同相利得の比をCMRR(同相除去比)といいます。オペアンプの入力段や、高速の差動伝送(LVDSなど)の受信回路に使われます。

バイポーラトランジスタのほかの問題

  1. コレクタ電流1 mAで動作しているバイポーラトランジスタの相互コンダクタンスgmはおよそいくらか。(室温、熱電圧VT ≈ 26 mVとする)
  2. LEDとフォトトランジスタを1つのパッケージに組み合わせたフォトカプラの主な用途はどれか。
  3. トランジスタ増幅回路で、エミッタ抵抗を入れた電流帰還バイアス回路を使う主な理由はどれか。
  4. 増幅回路で、入力信号がないときのトランジスタの直流の電圧・電流の状態を何と呼ぶか。
  5. NPNとPNPのトランジスタで正と負の半周期を分担するB級プッシュプル増幅回路で生じやすいひずみはどれか。
