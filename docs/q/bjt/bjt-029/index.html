バイポーラトランジスタ

バイポーラトランジスタで構成された代表的な論理ICの系列はどれか。

  1. ATTL
  2. BCMOS 4000シリーズ
  3. CNMOSロジック
答えと解説を見る

正解：A. TTL

TTL(Transistor-Transistor Logic)は、バイポーラトランジスタで構成された論理ICで、かつてデジタル回路の標準として広く使われました。現在は消費電力の小さいCMOSが主流ですが、TTLとの互換性をもつCMOSロジックなどにその名残があります。

この分野を解く 分野ページへ

バイポーラトランジスタのほかの問題

  1. バイポーラトランジスタとCMOSを同じチップに集積する技術とその狙いの組み合わせとして正しいものはどれか。
  2. バイポーラトランジスタの3つの端子の組み合わせとして正しいものはどれか。
  3. NPNトランジスタの回路記号で、エミッタに付いている矢印の向きとして正しいものはどれか。
  4. バイポーラトランジスタのエミッタ電流IE、ベース電流IB、コレクタ電流ICの関係として正しいものはどれか。
  5. 直流電流増幅率hFE = 100のトランジスタにベース電流10 μAを流したとき、能動領域でのコレクタ電流はおよそいくらか。
