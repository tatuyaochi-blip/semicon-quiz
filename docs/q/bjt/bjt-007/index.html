バイポーラトランジスタ

ベース接地電流増幅率α = 0.99のバイポーラトランジスタのエミッタ接地電流増幅率βはおよそいくらか。

  1. A0.99
  2. B9.9
  3. C99
答えと解説を見る

正解：C. 99

αとβの間には β = α / (1 − α) の関係があります。α = 0.99 なら、β = 0.99 / 0.01 = 99 です。αがわずかに1に近づくだけで、βは大きく変化します。
