バイポーラトランジスタ

SiGe HBT(ヘテロ接合バイポーラトランジスタ)の特徴として正しいものはどれか。

  1. Aベースを金属にしたトランジスタである
  2. BベースにSiGeを用いたヘテロ接合により、高い周波数まで動作しやすい
  3. C電流増幅率が1以下に固定されている
答えと解説を見る

正解：B. ベースにSiGeを用いたヘテロ接合により、高い周波数まで動作しやすい

SiGe HBTは、ベースにバンドギャップの小さいSiGeを使ったヘテロ接合バイポーラトランジスタです。エミッタからの注入効率を保ったままベースを高濃度・薄くでき、ベース内に電界をつくってキャリアを加速することもできるため、高周波特性に優れ、通信用ICなどに使われます。

バイポーラトランジスタのほかの問題

  1. シリコンのバイポーラトランジスタが飽和領域にあるときの、コレクタ-エミッタ間電圧の目安として正しいものはどれか。
  2. 特性のそろった2つのトランジスタを使い、一方に流した電流と同じ大きさの電流をもう一方に流す回路はどれか。
  3. 2つのトランジスタのエミッタを共通の電流源につないだ差動対の働きとして正しいものはどれか。
  4. コレクタ電流1 mAで動作しているバイポーラトランジスタの相互コンダクタンスgmはおよそいくらか。(室温、熱電圧VT ≈ 26 mVとする)
  5. LEDとフォトトランジスタを1つのパッケージに組み合わせたフォトカプラの主な用途はどれか。
