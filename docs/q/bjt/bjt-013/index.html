バイポーラトランジスタ

バイポーラトランジスタのトランジション周波数fTの意味として正しいものはどれか。

  1. A電源の周波数
  2. Bエミッタ接地の電流増幅率が1まで低下する周波数
  3. C回路が発振する周波数
答えと解説を見る

正解：B. エミッタ接地の電流増幅率が1まで低下する周波数

トランジスタの電流増幅率は、周波数が高くなると低下していきます。エミッタ接地の電流増幅率が1になる周波数をトランジション周波数fTといい、トランジスタの高周波性能を表す指標になります。

バイポーラトランジスタのほかの問題

  1. バイポーラトランジスタの熱暴走の説明として正しいものはどれか。
  2. SiGe HBT(ヘテロ接合バイポーラトランジスタ)の特徴として正しいものはどれか。
  3. シリコンのバイポーラトランジスタが飽和領域にあるときの、コレクタ-エミッタ間電圧の目安として正しいものはどれか。
  4. 特性のそろった2つのトランジスタを使い、一方に流した電流と同じ大きさの電流をもう一方に流す回路はどれか。
  5. 2つのトランジスタのエミッタを共通の電流源につないだ差動対の働きとして正しいものはどれか。
