バイポーラトランジスタ

ベース接地増幅回路の特徴として正しいものはどれか。

  1. A電流利得はほぼ1だが、高い周波数まで増幅しやすい
  2. B電流利得が3つの接地方式の中で最も大きい
  3. C入力インピーダンスが3つの接地方式の中で最も高い
答えと解説を見る

正解：A. 電流利得はほぼ1だが、高い周波数まで増幅しやすい

ベース接地では、入力のエミッタ電流と出力のコレクタ電流がほぼ等しいため、電流利得はα(ほぼ1)になります。入力インピーダンスは低い一方、出力と入力の間の帰還容量の影響を受けにくいため、高い周波数まで増幅しやすく、高周波回路で使われます。
