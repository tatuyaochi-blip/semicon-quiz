バイポーラトランジスタ

トランジスタ増幅回路の出力特性の図に引く「負荷線」が表すものとして正しいものはどれか。

  1. Aトランジスタの最大定格
  2. B温度とコレクタ電流の関係
  3. C負荷抵抗と電源電圧で決まる、とりうるVCEとICの組み合わせ
答えと解説を見る

正解：C. 負荷抵抗と電源電圧で決まる、とりうるVCEとICの組み合わせ

コレクタ側に抵抗RCと電源VCCがあると、VCE = VCC − IC × RC が成り立ちます。この直線を出力特性の図に引いたものが負荷線で、トランジスタはこの線上のどこかで動作します。負荷線とIBの曲線の交点が動作点になります。

  • A. 最大定格は損失の曲線などで表され、負荷線とは別のものです。
  • B. 負荷線は温度との関係を表すものではありません。
  • C. 正しい。外部回路が許すVCEとICの組み合わせを表します。

バイポーラトランジスタのほかの問題

  1. 理想的なB級プッシュプル増幅回路の最大の電力効率に最も近い値はどれか。
  2. トランジスタをスイッチとして使う回路で、ベースに直列に抵抗を入れる主な目的はどれか。
  3. 直流電流増幅率hFEと、小信号の電流増幅率hfeの違いとして正しいものはどれか。
  4. バイポーラトランジスタの大信号動作を、2つのダイオードと電流源で表したモデルはどれか。
  5. バイポーラトランジスタの電流増幅率hFEのコレクタ電流依存性として正しいものはどれか。
