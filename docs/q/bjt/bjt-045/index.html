バイポーラトランジスタ

直流電流増幅率hFEと、小信号の電流増幅率hfeの違いとして正しいものはどれか。

  1. AhFEは直流のIC/IB、hfeは動作点まわりの小さな変化分の比ΔIC/ΔIBである
  2. BhFEは小信号の変化分の比、hfeは直流の比である
  3. Cどちらも同じ量を別の名前で呼んでいるだけである
答えと解説を見る

正解：A. hFEは直流のIC/IB、hfeは動作点まわりの小さな変化分の比ΔIC/ΔIBである

hFEは直流でのコレクタ電流とベース電流の比 IC/IB です。一方hfeは、ある動作点のまわりで信号が小さく変化したときの比 ΔIC/ΔIB です。両者は近い値になることが多いものの、電流によってhFEが変わるため一般には一致しません。

  • A. 正しい。直流の比と小信号の比の違いです。
  • B. 大文字のFが直流、小文字のfが小信号を表すので、説明が逆です。
  • C. 定義が異なり、値も一般には一致しません。

バイポーラトランジスタのほかの問題

  1. バイポーラトランジスタの大信号動作を、2つのダイオードと電流源で表したモデルはどれか。
  2. バイポーラトランジスタの電流増幅率hFEのコレクタ電流依存性として正しいものはどれか。
  3. ベースを開放したときのコレクタ-エミッタ間の降伏電圧BVCEOと、エミッタを開放したときのコレクタ-ベース間の降伏電圧BVCBOの関係として正しいものはどれか。
  4. エミッタ接地増幅回路の高周波特性を悪くするミラー効果の説明として正しいものはどれか。
  5. ベース-コレクタ間にショットキーバリアダイオードを並列に入れたトランジスタ(ショットキークランプ)の狙いとして正しいものはどれか。
