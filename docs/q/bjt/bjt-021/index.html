バイポーラトランジスタ

トランジスタ増幅回路で、エミッタ抵抗を入れた電流帰還バイアス回路を使う主な理由はどれか。

  1. A電圧利得を最大にするため
  2. B温度変化やhFEのばらつきによる動作点の変動を抑えて安定させるため
  3. C回路を発振させるため
答えと解説を見る

正解：B. 温度変化やhFEのばらつきによる動作点の変動を抑えて安定させるため

エミッタ抵抗を入れると、コレクタ電流が増えたときにエミッタ電圧が上がってベース-エミッタ間電圧が下がり、電流の増加を抑える負帰還がかかります。そのため、温度やトランジスタごとのhFEのばらつきがあっても、動作点が安定します。

バイポーラトランジスタのほかの問題

  1. 増幅回路で、入力信号がないときのトランジスタの直流の電圧・電流の状態を何と呼ぶか。
  2. NPNとPNPのトランジスタで正と負の半周期を分担するB級プッシュプル増幅回路で生じやすいひずみはどれか。
  3. 増幅回路の段と段の間に入れる結合コンデンサの役割として正しいものはどれか。
  4. シリコンのバイポーラトランジスタの電流増幅率hFEは、一般に温度が上がるとどうなるか。
  5. エミッタ接地増幅回路の小信号の入力抵抗(hie)を大きくする条件として正しいものはどれか。
