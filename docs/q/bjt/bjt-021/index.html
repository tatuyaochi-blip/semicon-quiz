バイポーラトランジスタ

トランジスタ増幅回路で、エミッタ抵抗を入れた電流帰還バイアス回路を使う主な理由はどれか。

  1. A電圧利得を最大にするため
  2. B温度変化やhFEのばらつきによる動作点の変動を抑えて安定させるため
  3. C回路を発振させるため
答えと解説を見る

正解：B. 温度変化やhFEのばらつきによる動作点の変動を抑えて安定させるため

エミッタ抵抗を入れると、コレクタ電流が増えたときにエミッタ電圧が上がってVBEが下がり、電流の増加を抑える負帰還がかかります。ベースを抵抗分割で固定し、エミッタ抵抗にVBEの変動より十分大きい電圧(1 V以上など)をかけておくと、温度やhFEのばらつきに左右されにくくなります。交流の利得が下がるのを防ぐため、エミッタ抵抗に並列にバイパスコンデンサを入れることもよくあります。
