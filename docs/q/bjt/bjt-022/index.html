バイポーラトランジスタ

増幅回路で、入力信号がないときのトランジスタの直流の電圧・電流の状態を何と呼ぶか。

  1. A動作点(バイアス点)
  2. B遮断点
  3. Cピンチオフ点
答えと解説を見る

正解：A. 動作点(バイアス点)

動作点は、信号がないときにバイアス回路によって決まる直流の電圧と電流の状態です。信号はこの点を中心に変化するため、ひずみなく大きな信号を扱うには、動作点を特性の直線的な部分の中央付近に設定することが重要です。

バイポーラトランジスタのほかの問題

  1. NPNとPNPのトランジスタで正と負の半周期を分担するB級プッシュプル増幅回路で生じやすいひずみはどれか。
  2. 増幅回路の段と段の間に入れる結合コンデンサの役割として正しいものはどれか。
  3. シリコンのバイポーラトランジスタの電流増幅率hFEは、一般に温度が上がるとどうなるか。
  4. エミッタ接地増幅回路の小信号の入力抵抗(hie)を大きくする条件として正しいものはどれか。
  5. 増幅回路の負荷抵抗の代わりに、電流源として働くトランジスタを使う能動負荷の利点として正しいものはどれか。
