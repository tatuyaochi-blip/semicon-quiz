バイポーラトランジスタ

バイポーラトランジスタの熱暴走の説明として正しいものはどれか。

  1. A温度が下がりすぎて動作が止まる現象
  2. B電流が突然0になる現象
  3. C温度上昇でコレクタ電流が増え、さらに発熱して温度が上がる正帰還によって破壊に至る現象
答えと解説を見る

正解：C. 温度上昇でコレクタ電流が増え、さらに発熱して温度が上がる正帰還によって破壊に至る現象

バイポーラトランジスタは、同じVBEでも温度が上がるとコレクタ電流が増えます(VBEは約−2 mV/℃)。電流が増えると発熱が増え、さらに温度が上がる正帰還がかかると、電流が際限なく増えて破壊に至ります。これが熱暴走です。エミッタ抵抗による負帰還、十分な放熱、安全動作領域(SOA)内での使用で防ぎます。複数並列にする場合も各エミッタに抵抗を入れて電流を均等化します。

バイポーラトランジスタのほかの問題

  1. SiGe HBT(ヘテロ接合バイポーラトランジスタ)の特徴として正しいものはどれか。
  2. シリコンのバイポーラトランジスタが飽和領域にあるときの、コレクタ-エミッタ間電圧の目安として正しいものはどれか。
  3. 特性のそろった2つのトランジスタを使い、一方に流した電流と同じ大きさの電流をもう一方に流す回路はどれか。
  4. 2つのトランジスタのエミッタを共通の電流源につないだ差動対の働きとして正しいものはどれか。
  5. コレクタ電流1 mAで動作しているバイポーラトランジスタの相互コンダクタンスgmはおよそいくらか。(室温、熱電圧VT ≈ 26 mVとする)
