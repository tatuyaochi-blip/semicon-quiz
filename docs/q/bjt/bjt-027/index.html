バイポーラトランジスタ

増幅回路の負荷抵抗の代わりに、電流源として働くトランジスタを使う能動負荷の利点として正しいものはどれか。

  1. A利得が必ず小さくなる
  2. B小さな面積で、非常に大きな抵抗と同じ効果が得られ、利得を大きくできる
  3. C回路が発光するようになる
答えと解説を見る

正解：B. 小さな面積で、非常に大きな抵抗と同じ効果が得られ、利得を大きくできる

電流源は小信号に対して非常に大きな抵抗として働くため、能動負荷を使うと、大きな抵抗を実際に配置しなくても大きな電圧利得が得られます。大きな抵抗はIC上で大きな面積を必要とするため、能動負荷はアナログICで広く使われています。

バイポーラトランジスタのほかの問題

  1. スイッチ用のトランジスタを深い飽和状態からオフにするとき、オフになるまでに時間がかかる主な理由はどれか。
  2. バイポーラトランジスタで構成された代表的な論理ICの系列はどれか。
  3. バイポーラトランジスタとCMOSを同じチップに集積する技術とその狙いの組み合わせとして正しいものはどれか。
  4. NPNトランジスタを増幅に使う(能動領域で動作させる)ときのバイアス条件として正しいものはどれか。
  5. バイポーラトランジスタの直流電流増幅率hFEを表す式はどれか。(IC:コレクタ電流、IB:ベース電流、IE:エミッタ電流)
