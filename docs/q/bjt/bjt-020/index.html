バイポーラトランジスタ

LEDとフォトトランジスタを1つのパッケージに組み合わせたフォトカプラの主な用途はどれか。

  1. A電流を大きく増幅する
  2. B太陽光で発電する
  3. C入力側と出力側を電気的に絶縁したまま信号を伝える
答えと解説を見る

正解：C. 入力側と出力側を電気的に絶縁したまま信号を伝える

フォトカプラは、入力の電気信号でLEDを光らせ、その光をフォトトランジスタで受けて出力側に伝えます。入出力が光だけでつながるため、数kVの絶縁耐圧で、電位の異なる回路の間でも安全に信号をやり取りでき、グラウンドを通じたノイズの回り込みも防げます。スイッチング電源の出力電圧の帰還やPLCの入力回路で使われます。最近は、容量や磁気で結合するデジタルアイソレータも増えています。

バイポーラトランジスタのほかの問題

  1. トランジスタ増幅回路で、エミッタ抵抗を入れた電流帰還バイアス回路を使う主な理由はどれか。
  2. 増幅回路で、入力信号がないときのトランジスタの直流の電圧・電流の状態を何と呼ぶか。
  3. NPNとPNPのトランジスタで正と負の半周期を分担するB級プッシュプル増幅回路で生じやすいひずみはどれか。
  4. 増幅回路の段と段の間に入れる結合コンデンサの役割として正しいものはどれか。
  5. シリコンのバイポーラトランジスタの電流増幅率hFEは、一般に温度が上がるとどうなるか。
