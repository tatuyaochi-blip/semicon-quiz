バイポーラトランジスタ

スイッチ用のトランジスタを深い飽和状態からオフにするとき、オフになるまでに時間がかかる主な理由はどれか。

  1. Aトランジスタの温度が下がるため
  2. B接合容量が0になるため
  3. Cベース領域に蓄積された過剰な少数キャリアを取り除くのに時間がかかるため
答えと解説を見る

正解：C. ベース領域に蓄積された過剰な少数キャリアを取り除くのに時間がかかるため

飽和状態では、ベース領域に必要以上の少数キャリアが蓄積されています。オフにしようとしても、これらのキャリアが取り除かれるまでコレクタ電流は流れ続けます(蓄積時間)。ショットキーダイオードでクランプして深い飽和を防ぐなどの方法で高速化します。

この分野を解く 分野ページへ

バイポーラトランジスタのほかの問題

  1. バイポーラトランジスタで構成された代表的な論理ICの系列はどれか。
  2. バイポーラトランジスタとCMOSを同じチップに集積する技術とその狙いの組み合わせとして正しいものはどれか。
  3. NPNトランジスタを増幅に使う(能動領域で動作させる)ときのバイアス条件として正しいものはどれか。
  4. バイポーラトランジスタの直流電流増幅率hFEを表す式はどれか。(IC:コレクタ電流、IB:ベース電流、IE:エミッタ電流)
  5. バイポーラトランジスタのベース幅を薄くする主な理由として最も適切なものはどれか。
