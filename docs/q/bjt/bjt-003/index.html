バイポーラトランジスタ

バイポーラトランジスタのベース幅を薄くする主な理由として最も適切なものはどれか。

  1. Aコレクタの耐圧を上げるため
  2. Bベース抵抗を下げるため
  3. Cベースでの再結合を減らし、電流増幅率を高めるため
答えと解説を見る

正解：C. ベースでの再結合を減らし、電流増幅率を高めるため

エミッタからベースに注入されたキャリアは、ベースを通過する間に一部が再結合して失われ、それがベース電流になります。ベースを拡散長より十分薄くすると通過時間が短くなり、ほとんどのキャリアがコレクタに届くため電流増幅率が高くなり、高周波特性も良くなります。代わりにベース抵抗が大きくなり、コレクタの空乏層がエミッタまで届くパンチスルーが起こりやすくなるため、耐圧の面では不利です。
