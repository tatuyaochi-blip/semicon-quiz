バイポーラトランジスタ

バイポーラトランジスタをスイッチとして使うとき、オンの状態に対応する動作領域はどれか。

  1. A遮断領域
  2. B能動領域
  3. C飽和領域
答えと解説を見る

正解：C. 飽和領域

スイッチとして使う場合、オフは両方の接合が逆バイアスの遮断領域、オンは両方の接合が順バイアスの飽和領域に対応します。飽和領域ではコレクタ-エミッタ間電圧が小さくなり、スイッチが閉じた状態に近くなります。能動領域は増幅に使う領域です。

バイポーラトランジスタのほかの問題

  1. エミッタ接地増幅回路の出力電圧の位相は、入力電圧に対してどうなるか。
  2. NPNトランジスタで、エミッタの不純物濃度をベースより高くする主な理由はどれか。
  3. ベース接地電流増幅率α = 0.99のバイポーラトランジスタのエミッタ接地電流増幅率βはおよそいくらか。
  4. バイポーラトランジスタのアーリー効果の説明として正しいものはどれか。
  5. 2つのトランジスタを組み合わせたダーリントン接続の特徴として正しいものはどれか。
