バイポーラトランジスタ

ベースを開放したときのコレクタ-エミッタ間の降伏電圧BVCEOと、エミッタを開放したときのコレクタ-ベース間の降伏電圧BVCBOの関係として正しいものはどれか。

  1. ABVCEOとBVCBOは常に等しい
  2. BBVCEOはBVCBOより低い
  3. CBVCEOはBVCBOより高い
答えと解説を見る

正解：B. BVCEOはBVCBOより低い

ベースを開放した状態では、コレクタ接合で発生したなだれ電流がベースに流れ込み、トランジスタの増幅作用で増幅されます。そのため、BVCBOより低い電圧で電流が急増して降伏に至ります。回路設計では、より低いBVCEOを目安にする必要があります。

  • A. 2つの降伏電圧は一般に異なります。
  • B. 正しい。増幅作用により、BVCEOはBVCBOより低くなります。
  • C. トランジスタ動作のためにBVCEOの方が低くなります。

バイポーラトランジスタのほかの問題

  1. エミッタ接地増幅回路の高周波特性を悪くするミラー効果の説明として正しいものはどれか。
  2. ベース-コレクタ間にショットキーバリアダイオードを並列に入れたトランジスタ(ショットキークランプ)の狙いとして正しいものはどれか。
  3. NPNトランジスタを増幅に使う(能動領域で動作させる)ときのバイアス条件として正しいものはどれか。
  4. バイポーラトランジスタの直流電流増幅率hFEを表す式はどれか。(IC:コレクタ電流、IB:ベース電流、IE:エミッタ電流)
  5. バイポーラトランジスタのベース幅を薄くする主な理由として最も適切なものはどれか。
