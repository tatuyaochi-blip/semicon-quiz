バイポーラトランジスタ

エミッタ接地増幅回路の小信号の入力抵抗(hie)を大きくする条件として正しいものはどれか。

  1. Aコレクタ電流を小さくする、または電流増幅率の大きいトランジスタを使う
  2. Bコレクタ電流を大きくする
  3. C温度を下げる
答えと解説を見る

正解：A. コレクタ電流を小さくする、または電流増幅率の大きいトランジスタを使う

エミッタ接地の入力抵抗は、おおよそ hie ≈ hFE × VT / IC で表されます。コレクタ電流を小さくするか、hFEの大きいトランジスタを使うと、入力抵抗は大きくなります。その分、相互コンダクタンスは小さくなるため、利得とのバランスで動作点を決めます。

この分野を解く 分野ページへ

バイポーラトランジスタのほかの問題

  1. 増幅回路の負荷抵抗の代わりに、電流源として働くトランジスタを使う能動負荷の利点として正しいものはどれか。
  2. スイッチ用のトランジスタを深い飽和状態からオフにするとき、オフになるまでに時間がかかる主な理由はどれか。
  3. バイポーラトランジスタで構成された代表的な論理ICの系列はどれか。
  4. バイポーラトランジスタとCMOSを同じチップに集積する技術とその狙いの組み合わせとして正しいものはどれか。
  5. バイポーラトランジスタの3つの端子の組み合わせとして正しいものはどれか。
