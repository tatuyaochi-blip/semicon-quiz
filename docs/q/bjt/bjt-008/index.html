バイポーラトランジスタ

バイポーラトランジスタのアーリー効果の説明として正しいものはどれか。

  1. A温度が上がると電流増幅率が下がる効果
  2. Bコレクタ-ベース間の逆バイアスが大きくなると実効的なベース幅が狭くなり、コレクタ電流が増える効果
  3. C光を当てるとベース電流が流れる効果
答えと解説を見る

正解：B. コレクタ-ベース間の逆バイアスが大きくなると実効的なベース幅が狭くなり、コレクタ電流が増える効果

コレクタ電圧を大きくすると、コレクタ-ベース接合の空乏層がベース側にも広がり、実効的なベース幅が狭くなります。その結果、ベースでの再結合が減り、同じベース電流でもコレクタ電流が少し増えます。これがアーリー効果で、出力特性が水平にならず傾く原因です。
