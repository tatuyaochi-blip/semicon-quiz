CPU・アーキテクチャ

キャッシュの書き込み方式で、ライトバック方式の説明として正しいものはどれか。

  1. Aキャッシュには書き込まず、主記憶だけを更新する
  2. B書き込みのたびに、キャッシュと主記憶の両方を必ず更新する
  3. Cまずキャッシュだけを更新し、そのデータがキャッシュから追い出されるときに主記憶へ書き戻す
答えと解説を見る

正解：C. まずキャッシュだけを更新し、そのデータがキャッシュから追い出されるときに主記憶へ書き戻す

ライトバック方式では書き込みはキャッシュだけに行い、更新済み(ダーティ)のラインが追い出されるときにまとめて主記憶へ書き戻します。同じ場所への何度もの書き込みが1回の書き戻しで済むため、主記憶への通信量が大幅に減り、多くのCPUのL1〜L3で使われます。代わりに主記憶とキャッシュの内容が一時的に食い違うため、コヒーレンシやDMAとの一貫性の管理が必要です。

  • A. キャッシュを使わない書き込み方式の説明です。
  • B. 毎回キャッシュと主記憶の両方を更新するのはライトスルー方式です。
  • C. 正しい。追い出すときに主記憶へ書き戻します。

CPU・アーキテクチャのほかの問題

  1. セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。
  2. 現在の多くのCPUで使われているキャッシュライン(キャッシュブロック)の大きさとして一般的なものはどれか。
  3. パイプラインで、前の命令の結果を次の命令がすぐ使う(データハザード)とき、レジスタへの書き込みを待たずに演算結果を直接次の命令に渡す手法はどれか。
  4. リトルエンディアンの説明として正しいものはどれか。
  5. 1つのCPUコアで複数のスレッドの命令を同時に処理し、コア内の演算器などを有効に使う技術はどれか。
