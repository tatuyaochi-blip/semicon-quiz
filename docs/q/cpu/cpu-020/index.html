CPU・アーキテクチャ

高性能なコアと省電力なコアを組み合わせ、処理の重さに応じて使い分けるCPUの構成はどれか。

  1. Aシングルコア構成
  2. B同じコアだけを並べた構成
  3. C性能の異なるコアを組み合わせたヘテロジニアス構成(big.LITTLEなど)
答えと解説を見る

正解：C. 性能の異なるコアを組み合わせたヘテロジニアス構成(big.LITTLEなど)

重い処理は高性能コアで速く実行し、軽い処理やバックグラウンドの処理は面積が小さく電力効率の高い省電力コアで行うことで、性能と電池の持ちを両立させます。ARMのbig.LITTLEとしてスマートフォンで広まり、IntelのPコア/Eコアのようにパソコン向けにも採用されています。どの処理をどちらのコアに割り当てるかは、OSのスケジューラとハードウェアの協調が重要です。

CPU・アーキテクチャのほかの問題

  1. 命令の依存関係を調べ、実行できる命令からプログラムの順序と異なる順で実行して性能を高める方式はどれか。
  2. 実行中の処理を一時的に中断し、外部機器からの要求などに応じた処理を優先して行うCPUの仕組みはどれか。
  3. CPUを介さずに、周辺装置とメモリの間で直接データを転送する仕組みはどれか。
  4. CPU、メモリ、タイマーやADCなどの周辺機能を1チップにまとめ、家電や機器の制御に使われるLSIはどれか。
  5. マルチコアCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組みはどれか。
