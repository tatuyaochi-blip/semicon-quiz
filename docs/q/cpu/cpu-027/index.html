CPU・アーキテクチャ

投機的実行の痕跡がキャッシュに残ることを悪用し、本来アクセスできないデータを推測する攻撃が明らかになった脆弱性の例はどれか。

  1. Aロウハンマー
  2. BSpectreやMeltdown
  3. Cラッチアップ
答えと解説を見る

正解：B. SpectreやMeltdown

2018年に公表されたSpectreやMeltdownは、プロセッサが投機的に実行した処理の結果は取り消されても、キャッシュの状態に痕跡が残ることを悪用し、アクセス時間の違いから秘密のデータを推測する攻撃です。性能向上のための仕組みがセキュリティ上の弱点になりうることを示しました。
