CPU・アーキテクチャ

CPUの中のALU(算術論理演算装置)の役割として正しいものはどれか。

  1. A命令やデータを長期間保存する
  2. B画面に画像を表示する
  3. C加算や論理演算などの計算を行う
答えと解説を見る

正解：C. 加算や論理演算などの計算を行う

ALU(Arithmetic Logic Unit)は、加算・減算などの算術演算や、AND・OR・比較などの論理演算を行う回路です。命令の解読結果に従って、レジスタから受け取ったデータを演算し、結果を返します。

  • A. データの長期保存は記憶装置の役割です。
  • B. 画像の表示はGPUや表示回路の役割です。
  • C. 正しい。算術演算と論理演算を行います。

CPU・アーキテクチャのほかの問題

  1. CPUのプログラムカウンタ(PC)が保持しているものはどれか。
  2. キャッシュの書き込み方式で、ライトバック方式の説明として正しいものはどれか。
  3. セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。
  4. 現在の多くのCPUで使われているキャッシュライン(キャッシュブロック)の大きさとして一般的なものはどれか。
  5. パイプラインで、前の命令の結果を次の命令がすぐ使う(データハザード)とき、レジスタへの書き込みを待たずに演算結果を直接次の命令に渡す手法はどれか。
