CPU・アーキテクチャ

マイコンに搭載されるウォッチドッグタイマの役割として正しいものはどれか。

  1. A正確な時刻を表示する
  2. Bクロック周波数を上げる
  3. Cプログラムが暴走して一定時間内にタイマーをクリアしなかったとき、システムをリセットする
答えと解説を見る

正解：C. プログラムが暴走して一定時間内にタイマーをクリアしなかったとき、システムをリセットする

ウォッチドッグタイマは、正常に動いているプログラムが定期的にクリアすることを前提にしたタイマーです。プログラムが暴走したり停止したりしてクリアされないまま時間切れになると、マイコンをリセットして復旧させます。機器の信頼性を高めるための仕組みです。

  • A. 時刻の表示はリアルタイムクロック(RTC)などの役割です。
  • B. クロック周波数を上げる機能ではありません。
  • C. 正しい。暴走を検出してリセットします。

CPU・アーキテクチャのほかの問題

  1. プログラムでサブルーチン(関数)を呼び出すとき、戻り先のアドレスなどを一時的に保存するために一般的に使われる領域はどれか。
  2. キャッシュミスの分類「3つのC」に含まれるものの組み合わせとして正しいものはどれか。
  3. アウトオブオーダー実行のCPUで、順序を入れ替えて実行した命令の結果を、プログラムの本来の順序で確定(リタイア)させるための仕組みはどれか。
  4. アウトオブオーダー実行のCPUで使われるレジスタリネーミングの主な目的はどれか。
  5. AI向けのアクセラレータなどで、多数の積和演算器を格子状に並べ、データを隣の演算器へ順に流しながら行列の積を計算する構成はどれか。
