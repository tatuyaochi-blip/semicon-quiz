CPU・アーキテクチャ

一般的なコンピュータで、アクセスが速い順に並べた記憶階層として正しいものはどれか。

  1. ASSD → 主記憶 → L2キャッシュ → L1キャッシュ → レジスタ
  2. B主記憶 → レジスタ → SSD → L1キャッシュ
  3. Cレジスタ → L1キャッシュ → L2キャッシュ → 主記憶(DRAM) → SSD
答えと解説を見る

正解：C. レジスタ → L1キャッシュ → L2キャッシュ → 主記憶(DRAM) → SSD

CPUに近い記憶ほど高速で小容量、遠いほど低速で大容量・安価になります。レジスタ、L1・L2・L3キャッシュ(SRAM)、主記憶(DRAM)、ストレージ(SSDなど)という階層をつくり、よく使うデータを速い階層に置くことで、全体として速く大容量の記憶を実現しています。

CPU・アーキテクチャのほかの問題

  1. クロック周波数2 GHz、平均CPI(1命令あたりの平均クロック数)0.5のプロセッサが、1秒間に実行できる命令数はおよそいくらか。
  2. 処理全体の90%を並列化できるプログラムを、プロセッサの数を限りなく増やして実行したとき、理論上の最大の高速化率はどれか。
  3. 1つの命令で複数のデータに同じ演算を同時に行う方式はどれか。
  4. 高性能なコアと省電力なコアを組み合わせ、処理の重さに応じて使い分けるCPUの構成はどれか。
  5. 命令の依存関係を調べ、実行できる命令からプログラムの順序と異なる順で実行して性能を高める方式はどれか。
