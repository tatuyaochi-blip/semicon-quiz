CPU・アーキテクチャ

クロック周波数2 GHz、平均CPI(1命令あたりの平均クロック数)0.5のプロセッサが、1秒間に実行できる命令数はおよそいくらか。

  1. A10億命令
  2. B40億命令
  3. C1億命令
答えと解説を見る

正解：B. 40億命令

1秒間のクロック数は 2×10⁹ で、1命令あたり平均0.5クロックなので、2×10⁹ ÷ 0.5 = 4×10⁹、つまり40億命令です。CPIが1未満なのは、スーパースカラで1クロックに複数の命令を実行しているためです。性能は「命令数 × CPI ÷ 周波数」の実行時間で決まるため、命令数・CPI・周波数のどれか1つだけでは比較できません。

CPU・アーキテクチャのほかの問題

  1. 処理全体の90%を並列化できるプログラムを、プロセッサの数を限りなく増やして実行したとき、理論上の最大の高速化率はどれか。
  2. 1つの命令で複数のデータに同じ演算を同時に行う方式はどれか。
  3. 高性能なコアと省電力なコアを組み合わせ、処理の重さに応じて使い分けるCPUの構成はどれか。
  4. 命令の依存関係を調べ、実行できる命令からプログラムの順序と異なる順で実行して性能を高める方式はどれか。
  5. 実行中の処理を一時的に中断し、外部機器からの要求などに応じた処理を優先して行うCPUの仕組みはどれか。

この分野の比較

  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
  • ARM・RISC-V・x86の違い：命令セットアーキテクチャを比較ARM、RISC-V、x86を、設計の考え方・命令長・ライセンス・レジスタ・ソフトウェアの環境・強み・用途の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
