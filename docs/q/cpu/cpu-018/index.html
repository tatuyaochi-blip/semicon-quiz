CPU・アーキテクチャ

処理全体の90%を並列化できるプログラムを、プロセッサの数を限りなく増やして実行したとき、理論上の最大の高速化率はどれか。

  1. A10倍
  2. B90倍
  3. C無限大
答えと解説を見る

正解：A. 10倍

アムダールの法則によると、並列化できない部分(10%)はプロセッサを増やしても短くならないため、全体の実行時間は元の10%より短くなりません。したがって最大の高速化率は 1 ÷ 0.1 = 10倍です。並列化できない部分を減らすことが重要だとわかります。

CPU・アーキテクチャのほかの問題

  1. 1つの命令で複数のデータに同じ演算を同時に行う方式はどれか。
  2. 高性能なコアと省電力なコアを組み合わせ、処理の重さに応じて使い分けるCPUの構成はどれか。
  3. 命令の依存関係を調べ、実行できる命令からプログラムの順序と異なる順で実行して性能を高める方式はどれか。
  4. 実行中の処理を一時的に中断し、外部機器からの要求などに応じた処理を優先して行うCPUの仕組みはどれか。
  5. CPUを介さずに、周辺装置とメモリの間で直接データを転送する仕組みはどれか。
