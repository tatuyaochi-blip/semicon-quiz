CPU・アーキテクチャ

CPUの分岐予測の目的として正しいものはどれか。

  1. A分岐命令の結果を予測して先の命令を実行し、パイプラインの停止を減らす
  2. B消費電力を予測して電源を制御する
  3. C主記憶の容量を予測する
答えと解説を見る

正解：A. 分岐命令の結果を予測して先の命令を実行し、パイプラインの停止を減らす

パイプラインでは、分岐命令の結果がわかるまで次に実行する命令が決まらず、処理が止まってしまいます。分岐予測では過去の履歴などから分岐先を予測して先に実行を進め、予測が外れたときだけやり直します。予測精度が性能に大きく影響します。
