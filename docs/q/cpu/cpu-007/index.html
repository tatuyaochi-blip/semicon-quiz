CPU・アーキテクチャ

CPUの分岐予測の目的として正しいものはどれか。

  1. A分岐命令の結果を予測して先の命令を実行し、パイプラインの停止を減らす
  2. B消費電力を予測して電源を制御する
  3. C主記憶の容量を予測する
答えと解説を見る

正解：A. 分岐命令の結果を予測して先の命令を実行し、パイプラインの停止を減らす

パイプラインでは分岐命令の結果がわかるまで次の命令が決まらず、処理が止まってしまいます。分岐予測では過去の履歴などから分岐先を予測して先へ実行を進め、外れたときだけやり直します。プログラムの約5命令に1つが分岐なので影響は大きく、現在の高性能CPUは95%を超える精度で予測します。予測ミス1回で十数〜二十クロック程度を失うため、わずかな精度向上でも性能に効きます。

CPU・アーキテクチャのほかの問題

  1. GPUが行列演算やAIの学習・推論に向いている主な理由はどれか。
  2. キャッシュのアクセス時間が10 ns、主記憶のアクセス時間が100 ns、キャッシュのヒット率が90%のとき、平均アクセス時間はいくらか。
  3. CMOS回路で、ほかの条件を変えずに電源電圧だけを半分にすると、動的消費電力はどうなるか。
  4. ARM、x86、RISC-Vといった名前が主に表しているものはどれか。
  5. RISC-Vの特徴として正しいものはどれか。

この分野の比較

  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
  • ARM・RISC-V・x86の違い：命令セットアーキテクチャを比較ARM、RISC-V、x86を、設計の考え方・命令長・ライセンス・レジスタ・ソフトウェアの環境・強み・用途の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
