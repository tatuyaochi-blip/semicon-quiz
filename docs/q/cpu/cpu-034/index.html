CPU・アーキテクチャ

CPUが1つの命令を処理する基本的な流れとして正しい順序はどれか。

  1. A実行 → 解読 → 取り出し
  2. B取り出し(フェッチ)→ 解読(デコード)→ 実行
  3. C解読 → 取り出し → 実行
答えと解説を見る

正解：B. 取り出し(フェッチ)→ 解読(デコード)→ 実行

CPUは、メモリから命令を取り出し(フェッチ)、その内容を解読(デコード)して何をするかを決め、演算などを実行します。必要に応じて結果をレジスタやメモリに書き戻します。パイプライン処理は、この段階を重ねて並行に進めるものです。

  • A. 命令を取り出さないうちに実行はできません。
  • B. 正しい。取り出し・解読・実行の順です。
  • C. 命令を取り出す前に解読はできません。

CPU・アーキテクチャのほかの問題

  1. CPUの中のALU(算術論理演算装置)の役割として正しいものはどれか。
  2. CPUのプログラムカウンタ(PC)が保持しているものはどれか。
  3. キャッシュの書き込み方式で、ライトバック方式の説明として正しいものはどれか。
  4. セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。
  5. 現在の多くのCPUで使われているキャッシュライン(キャッシュブロック)の大きさとして一般的なものはどれか。
