CPU・アーキテクチャ

プログラムでサブルーチン(関数)を呼び出すとき、戻り先のアドレスなどを一時的に保存するために一般的に使われる領域はどれか。

  1. Aスタック
  2. Bキャッシュのタグ
  3. CROMの固定領域
答えと解説を見る

正解：A. スタック

サブルーチンを呼び出すと、戻り先のアドレス、保存すべきレジスタの値、局所変数などがスタックに積まれます。スタックは後から入れたものを先に取り出す(LIFO)構造で、呼び出しが入れ子や再帰になっても正しい順で戻れます。先頭位置はスタックポインタが示します。再帰が深すぎて領域を使い果たすとスタックオーバーフローになり、配列のはみ出しで戻り先を書き換える攻撃もあります。

  • A. 正しい。戻り先のアドレスなどはスタックに保存されます。
  • B. キャッシュのタグは、キャッシュのデータがどのアドレスのものかを示す情報です。
  • C. ROMは書き換えられないので、実行時の一時的な保存には使えません。

CPU・アーキテクチャのほかの問題

  1. キャッシュミスの分類「3つのC」に含まれるものの組み合わせとして正しいものはどれか。
  2. アウトオブオーダー実行のCPUで、順序を入れ替えて実行した命令の結果を、プログラムの本来の順序で確定(リタイア)させるための仕組みはどれか。
  3. アウトオブオーダー実行のCPUで使われるレジスタリネーミングの主な目的はどれか。
  4. AI向けのアクセラレータなどで、多数の積和演算器を格子状に並べ、データを隣の演算器へ順に流しながら行列の積を計算する構成はどれか。
  5. プログラムの性能が、演算性能とメモリ帯域のどちらで制限されるかを、演算強度(1バイトあたりの演算数)を横軸にして図示するモデルはどれか。

この分野の比較

  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
  • ARM・RISC-V・x86の違い：命令セットアーキテクチャを比較ARM、RISC-V、x86を、設計の考え方・命令長・ライセンス・レジスタ・ソフトウェアの環境・強み・用途の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
