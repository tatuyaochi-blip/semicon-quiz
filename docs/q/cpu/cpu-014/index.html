CPU・アーキテクチャ

仮想アドレスから物理アドレスへの変換結果を保持し、アドレス変換を高速化するキャッシュはどれか。

  1. AL3キャッシュ
  2. BTLB(変換索引バッファ)
  3. Cレジスタファイル
答えと解説を見る

正解：B. TLB(変換索引バッファ)

仮想記憶では、プログラムが使う仮想アドレスを物理アドレスに変換する必要があり、変換表(ページテーブル)はメモリ上にあるため、毎回参照すると何度もメモリにアクセスすることになります。そこで最近使った変換結果をTLBに保持します。TLBは数十〜数千項目と小さく、扱うメモリが広いとミスが増えるため、2 MBなどの大きなページ(ヒュージページ)でTLBの守備範囲を広げることもあります。

CPU・アーキテクチャのほかの問題

  1. AIの推論処理を高速かつ低い消費電力で行うために、スマートフォン用のSoCなどに搭載される専用回路はどれか。
  2. 一般的なコンピュータで、アクセスが速い順に並べた記憶階層として正しいものはどれか。
  3. クロック周波数2 GHz、平均CPI(1命令あたりの平均クロック数)0.5のプロセッサが、1秒間に実行できる命令数はおよそいくらか。
  4. 処理全体の90%を並列化できるプログラムを、プロセッサの数を限りなく増やして実行したとき、理論上の最大の高速化率はどれか。
  5. 1つの命令で複数のデータに同じ演算を同時に行う方式はどれか。

この分野の比較

  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
  • ARM・RISC-V・x86の違い：命令セットアーキテクチャを比較ARM、RISC-V、x86を、設計の考え方・命令長・ライセンス・レジスタ・ソフトウェアの環境・強み・用途の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
