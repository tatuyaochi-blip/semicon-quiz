CPU・アーキテクチャ

AI向けのアクセラレータなどで、多数の積和演算器を格子状に並べ、データを隣の演算器へ順に流しながら行列の積を計算する構成はどれか。

  1. Aシストリックアレイ
  2. Bクロスバースイッチ
  3. Cリングバッファ
答えと解説を見る

正解：A. シストリックアレイ

シストリックアレイは、積和演算器(MAC)を2次元に並べ、データを隣の演算器へ規則的に送りながら計算する構成です。一度読み込んだデータを多くの演算器で再利用できるため、メモリへのアクセスを減らして行列演算を効率よく行えます。GoogleのTPUなどで使われています。

  • A. 正しい。演算器を格子状に並べてデータを流しながら計算します。
  • B. クロスバースイッチは、多数の入力と出力を自由につなぎ替える接続回路です。
  • C. リングバッファは、循環的に使うデータの格納領域です。

CPU・アーキテクチャのほかの問題

  1. プログラムの性能が、演算性能とメモリ帯域のどちらで制限されるかを、演算強度(1バイトあたりの演算数)を横軸にして図示するモデルはどれか。
  2. CPUのパイプライン処理の主な目的として正しいものはどれか。
  3. キャッシュメモリを設ける主な目的として正しいものはどれか。
  4. ノイマン型コンピュータの特徴として正しいものはどれか。
  5. 1つのチップに複数のプロセッサコアを搭載する(マルチコア化する)主な目的はどれか。
