CPU・アーキテクチャ

アウトオブオーダー実行のCPUで、順序を入れ替えて実行した命令の結果を、プログラムの本来の順序で確定(リタイア)させるための仕組みはどれか。

  1. ATLB
  2. Bリオーダバッファ
  3. Cスヌープフィルタ
答えと解説を見る

正解：B. リオーダバッファ

リオーダバッファは、順序を入れ替えて実行された命令の結果を一時的に保持し、プログラムの順序どおりに確定させる仕組みです。例外や分岐予測ミスが起きたときにも、それ以降の命令の結果を破棄して正しい状態に戻せます(正確な例外)。

  • A. TLBはアドレス変換の結果を保持するキャッシュです。
  • B. 正しい。実行結果を本来の順序で確定させます。
  • C. スヌープフィルタはキャッシュコヒーレンシの通信を減らす仕組みです。

CPU・アーキテクチャのほかの問題

  1. アウトオブオーダー実行のCPUで使われるレジスタリネーミングの主な目的はどれか。
  2. AI向けのアクセラレータなどで、多数の積和演算器を格子状に並べ、データを隣の演算器へ順に流しながら行列の積を計算する構成はどれか。
  3. プログラムの性能が、演算性能とメモリ帯域のどちらで制限されるかを、演算強度(1バイトあたりの演算数)を横軸にして図示するモデルはどれか。
  4. CPUのパイプライン処理の主な目的として正しいものはどれか。
  5. キャッシュメモリを設ける主な目的として正しいものはどれか。
