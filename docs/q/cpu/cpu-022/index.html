CPU・アーキテクチャ

実行中の処理を一時的に中断し、外部機器からの要求などに応じた処理を優先して行うCPUの仕組みはどれか。

  1. A割り込み
  2. Bパイプライン
  3. Cキャッシュ
答えと解説を見る

正解：A. 割り込み

割り込みは、キーボード入力、タイマー、通信の受信などのイベントが起きたときに、CPUが実行中の処理を中断し、レジスタなどの状態を保存して対応する処理(割り込みハンドラ)を行い、終わったら元に戻る仕組みです。CPUが周辺機器の状態を常に確認し続ける方式(ポーリング)より無駄が少なく、応答も速くなります。優先度を付けて重要な要求を先に処理します。

CPU・アーキテクチャのほかの問題

  1. CPUを介さずに、周辺装置とメモリの間で直接データを転送する仕組みはどれか。
  2. CPU、メモリ、タイマーやADCなどの周辺機能を1チップにまとめ、家電や機器の制御に使われるLSIはどれか。
  3. マルチコアCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組みはどれか。
  4. CPUの消費電力を減らすため、負荷に応じて動作周波数と電源電圧を動的に変える技術はどれか。
  5. 投機的実行の痕跡がキャッシュに残ることを悪用し、本来アクセスできないデータを推測する攻撃が明らかになった脆弱性の例はどれか。
