CPU・アーキテクチャ

1つの命令で複数のデータに同じ演算を同時に行う方式はどれか。

  1. ASISD
  2. BSIMD
  3. CMISD
答えと解説を見る

正解：B. SIMD

SIMD(Single Instruction, Multiple Data)は、1つの命令で複数のデータに同じ演算を並列に行う方式です。画像処理や行列演算などに有効で、多くのCPUがSIMD命令を備えています。GPUもSIMDに近い考え方で多数のデータを並列処理します。

CPU・アーキテクチャのほかの問題

  1. 高性能なコアと省電力なコアを組み合わせ、処理の重さに応じて使い分けるCPUの構成はどれか。
  2. 命令の依存関係を調べ、実行できる命令からプログラムの順序と異なる順で実行して性能を高める方式はどれか。
  3. 実行中の処理を一時的に中断し、外部機器からの要求などに応じた処理を優先して行うCPUの仕組みはどれか。
  4. CPUを介さずに、周辺装置とメモリの間で直接データを転送する仕組みはどれか。
  5. CPU、メモリ、タイマーやADCなどの周辺機能を1チップにまとめ、家電や機器の制御に使われるLSIはどれか。
