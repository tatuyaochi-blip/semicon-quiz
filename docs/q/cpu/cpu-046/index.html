CPU・アーキテクチャ

キャッシュミスの分類「3つのC」に含まれるものの組み合わせとして正しいものはどれか。

  1. A書き込みミス・読み出しミス・分岐ミス
  2. Bクロックミス・電圧ミス・温度ミス
  3. C初期参照ミス・容量ミス・競合ミス
答えと解説を見る

正解：C. 初期参照ミス・容量ミス・競合ミス

キャッシュミスは、初めてのアクセスで起こる初期参照ミス(Compulsory)、容量不足で追い出されたために起こる容量ミス(Capacity)、同じセットの取り合いで起こる競合ミス(Conflict)に分類されます。対策は、初期参照ミスにはラインを大きくしたりプリフェッチで先読みしたり、容量ミスにはキャッシュを大きくしたり、競合ミスには連想度を上げたりと、原因ごとに異なります。

  • A. 読み書きの種類による分類ではありません。
  • B. 動作条件による分類ではありません。
  • C. 正しい。Compulsory・Capacity・Conflictの3つです。

CPU・アーキテクチャのほかの問題

  2. アウトオブオーダー実行のCPUで使われるレジスタリネーミングの主な目的はどれか。
  3. AI向けのアクセラレータなどで、多数の積和演算器を格子状に並べ、データを隣の演算器へ順に流しながら行列の積を計算する構成はどれか。
  4. プログラムの性能が、演算性能とメモリ帯域のどちらで制限されるかを、演算強度(1バイトあたりの演算数)を横軸にして図示するモデルはどれか。
  5. CPUのパイプライン処理の主な目的として正しいものはどれか。
