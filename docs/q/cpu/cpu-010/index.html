CPU・アーキテクチャ

CMOS回路で、ほかの条件を変えずに電源電圧だけを半分にすると、動的消費電力はどうなるか。

  1. A変わらない
  2. B1/2になる
  3. C1/4になる
答えと解説を見る

正解：C. 1/4になる

CMOS回路の動的消費電力は P = α C V² f(α:動作率、C:負荷容量、V:電源電圧、f:周波数)で表され、電源電圧の2乗に比例します。電圧を半分にすると電力は1/4になります。そのため低電圧化は省電力化の最も効果的な手段ですが、動作速度は低下します。
