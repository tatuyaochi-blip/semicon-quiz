CPU・アーキテクチャ

「64ビットCPU」の64ビットが主に表しているものはどれか。

  1. ACPUのコアの数
  2. Bキャッシュメモリの容量
  3. C汎用レジスタやアドレスなど、一度に扱う整数データの幅
答えと解説を見る

正解：C. 汎用レジスタやアドレスなど、一度に扱う整数データの幅

64ビットCPUは、汎用レジスタやアドレスの幅が64ビットで、一度に64ビットの整数を扱えます。32ビットCPUのアドレス空間は2³² = 4 GBに限られますが、64ビットでは理論上16 EB(エクサバイト)と桁違いに広く、大容量のメモリを使えます(実装上は48〜57ビット程度)。パソコンでは2000年代にx86-64が、スマートフォンでは2013年頃から64ビットのARMが普及しました。

  • A. コアの数はビット数とは別の指標です。
  • B. キャッシュの容量はビット数では表しません。
  • C. 正しい。一度に扱うデータやアドレスの幅です。

CPU・アーキテクチャのほかの問題

  1. CPUが1つの命令を処理する基本的な流れとして正しい順序はどれか。
  2. CPUの中のALU(算術論理演算装置)の役割として正しいものはどれか。
  3. CPUのプログラムカウンタ(PC)が保持しているものはどれか。
  4. キャッシュの書き込み方式で、ライトバック方式の説明として正しいものはどれか。
  5. セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。

この分野の比較

  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
  • ARM・RISC-V・x86の違い：命令セットアーキテクチャを比較ARM、RISC-V、x86を、設計の考え方・命令長・ライセンス・レジスタ・ソフトウェアの環境・強み・用途の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
