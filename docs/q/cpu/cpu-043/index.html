CPU・アーキテクチャ

マイコンなどで、周辺機器のレジスタをメモリと同じアドレス空間に割り当て、通常のメモリ読み書き命令で操作する方式はどれか。

  1. A仮想記憶
  2. BメモリマップドI/O
  3. Cキャッシュコヒーレンシ
答えと解説を見る

正解：B. メモリマップドI/O

メモリマップドI/Oでは、タイマーやUARTなどの周辺機器の制御レジスタに特定のアドレスを割り当て、メモリと同じ読み書き命令で操作します。入出力専用の命令を用意する方式(ポートマップドI/O)と比べて、命令セットを単純にできます。

  • A. 仮想記憶は、仮想アドレスと物理アドレスを対応づける仕組みです。
  • B. 正しい。周辺機器をメモリ空間に割り当てて操作します。
  • C. キャッシュコヒーレンシは、複数のキャッシュの内容の一貫性を保つ仕組みです。

CPU・アーキテクチャのほかの問題

  1. マイコンに搭載されるウォッチドッグタイマの役割として正しいものはどれか。
  2. プログラムでサブルーチン(関数)を呼び出すとき、戻り先のアドレスなどを一時的に保存するために一般的に使われる領域はどれか。
  3. キャッシュミスの分類「3つのC」に含まれるものの組み合わせとして正しいものはどれか。
  4. アウトオブオーダー実行のCPUで、順序を入れ替えて実行した命令の結果を、プログラムの本来の順序で確定(リタイア)させるための仕組みはどれか。
  5. アウトオブオーダー実行のCPUで使われるレジスタリネーミングの主な目的はどれか。
