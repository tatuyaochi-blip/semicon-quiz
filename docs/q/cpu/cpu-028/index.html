CPU・アーキテクチャ

CPUの冷却設計の目安となる、標準的な高負荷時に発生する熱量を表す指標はどれか。

  1. ACPI
  2. BIPC
  3. CTDP(熱設計電力)
答えと解説を見る

正解：C. TDP(熱設計電力)

TDPは、冷却装置の設計の目安となる発熱量で、ワットで表されます。冷却装置はTDPの熱を逃がせるように設計します。最近のCPUは、温度や電力に余裕がある短い時間だけTDPを超えて動作するブースト機能をもち、実際の最大消費電力はTDPより大きいことがあります。そのためメーカーによっては、持続電力と短時間の最大電力を分けて表示しています。

  1. 1クロックあたりに実行できる命令数を表す指標はどれか。

  3. CPUの日本語での一般的な呼び方として正しいものはどれか。
  4. クロック周波数3 GHzのCPUの説明として正しいものはどれか。
  5. 「64ビットCPU」の64ビットが主に表しているものはどれか。

この分野の比較

  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
  • ARM・RISC-V・x86の違い：命令セットアーキテクチャを比較ARM、RISC-V、x86を、設計の考え方・命令長・ライセンス・レジスタ・ソフトウェアの環境・強み・用途の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
