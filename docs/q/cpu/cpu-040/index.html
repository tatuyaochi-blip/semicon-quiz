CPU・アーキテクチャ

パイプラインで、前の命令の結果を次の命令がすぐ使う(データハザード)とき、レジスタへの書き込みを待たずに演算結果を直接次の命令に渡す手法はどれか。

  1. Aフォワーディング(バイパス)
  2. B仮想記憶
  3. C分岐予測
答えと解説を見る

正解：A. フォワーディング(バイパス)

フォワーディング(バイパス)は、演算器の出力を、レジスタに書き込まれるのを待たずに後続の命令の入力へ直接回す手法です。例えば「r1 = r2 + r3」の直後に「r4 = r1 × 2」があっても、数クロックの停止(ストール)なしに実行できます。ただしメモリからのロード結果を直後に使う場合は、データがまだ届いていないため1クロック程度の停止が残ります(ロード使用ハザード)。

  • A. 正しい。結果を直接次の命令に回します。
  • B. 仮想記憶はアドレス空間を管理する仕組みで、ハザード対策ではありません。
  • C. 分岐予測は、分岐による制御ハザードへの対策です。

CPU・アーキテクチャのほかの問題

  1. リトルエンディアンの説明として正しいものはどれか。
  2. 1つのCPUコアで複数のスレッドの命令を同時に処理し、コア内の演算器などを有効に使う技術はどれか。
  3. マイコンなどで、周辺機器のレジスタをメモリと同じアドレス空間に割り当て、通常のメモリ読み書き命令で操作する方式はどれか。
  4. マイコンに搭載されるウォッチドッグタイマの役割として正しいものはどれか。
  5. プログラムでサブルーチン(関数)を呼び出すとき、戻り先のアドレスなどを一時的に保存するために一般的に使われる領域はどれか。

この分野の比較

  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
  • ARM・RISC-V・x86の違い：命令セットアーキテクチャを比較ARM、RISC-V、x86を、設計の考え方・命令長・ライセンス・レジスタ・ソフトウェアの環境・強み・用途の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
