CPU・アーキテクチャ

パイプラインで、前の命令の結果を次の命令がすぐ使う(データハザード)とき、レジスタへの書き込みを待たずに演算結果を直接次の命令に渡す手法はどれか。

  1. Aフォワーディング(バイパス)
  2. B仮想記憶
  3. C分岐予測
答えと解説を見る

正解：A. フォワーディング(バイパス)

フォワーディング(バイパス)は、演算器の出力を、レジスタに書き込まれるのを待たずに後続の命令の入力へ直接回す手法です。データハザードによるパイプラインの停止(ストール)を減らせます。分岐予測は分岐による制御ハザードへの対策です。

  • A. 正しい。結果を直接次の命令に回します。
  • B. 仮想記憶はアドレス空間を管理する仕組みで、ハザード対策ではありません。
  • C. 分岐予測は、分岐による制御ハザードへの対策です。

CPU・アーキテクチャのほかの問題

  1. リトルエンディアンの説明として正しいものはどれか。
  2. 1つのCPUコアで複数のスレッドの命令を同時に処理し、コア内の演算器などを有効に使う技術はどれか。
  3. マイコンなどで、周辺機器のレジスタをメモリと同じアドレス空間に割り当て、通常のメモリ読み書き命令で操作する方式はどれか。
  4. マイコンに搭載されるウォッチドッグタイマの役割として正しいものはどれか。
  5. プログラムでサブルーチン(関数)を呼び出すとき、戻り先のアドレスなどを一時的に保存するために一般的に使われる領域はどれか。
