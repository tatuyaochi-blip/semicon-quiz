CPU・アーキテクチャ

CPU、メモリ、タイマーやADCなどの周辺機能を1チップにまとめ、家電や機器の制御に使われるLSIはどれか。

  1. AGPU
  2. Bマイクロコントローラ(マイコン)
  3. CHBM
答えと解説を見る

正解：B. マイクロコントローラ(マイコン)

マイコンは、CPUに加えて、プログラムを格納するフラッシュメモリ、作業用のRAM、タイマー、ADC、通信インターフェースなどを1チップに集積したLSIです。家電、自動車、産業機器など、あらゆる機器の制御に使われており、出荷数が非常に多い半導体製品です。

CPU・アーキテクチャのほかの問題

  1. マルチコアCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組みはどれか。
  2. CPUの消費電力を減らすため、負荷に応じて動作周波数と電源電圧を動的に変える技術はどれか。
  3. 投機的実行の痕跡がキャッシュに残ることを悪用し、本来アクセスできないデータを推測する攻撃が明らかになった脆弱性の例はどれか。
  4. CPUの冷却設計の目安となる、標準的な高負荷時に発生する熱量を表す指標はどれか。
  5. 1クロックあたりに実行できる命令数を表す指標はどれか。
