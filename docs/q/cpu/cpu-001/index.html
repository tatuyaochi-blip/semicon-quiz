CPU・アーキテクチャ

CPUのパイプライン処理の主な目的として正しいものはどれか。

  1. A命令処理を複数の段階に分け、異なる命令の段階を重ねて実行することでスループットを高める
  2. B1つの命令の実行時間(レイテンシ)を必ず短くする
  3. C命令の数を減らしてプログラムを小さくする
答えと解説を見る

正解：A. 命令処理を複数の段階に分け、異なる命令の段階を重ねて実行することでスループットを高める

パイプラインは、命令の取り出し・解読・実行・書き戻しなどの段階を流れ作業のように重ねて処理し、単位時間あたりに完了する命令数(スループット)を高めます。1命令あたりの処理時間そのものが短くなるわけではなく、分岐やデータの依存関係によって流れが乱れる(ハザード)ことがあります。
