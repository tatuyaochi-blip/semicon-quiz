CPU・アーキテクチャ

1クロックあたりに実行できる命令数を表す指標はどれか。

  1. AIPC
  2. BCPI
  3. CTDP
答えと解説を見る

正解：A. IPC

IPC(Instructions Per Clock)は、1クロックあたりに実行できる平均の命令数で、CPI(Clocks Per Instruction)の逆数です。同じクロック周波数なら、IPCが大きいほど性能が高くなります。スーパースカラやアウトオブオーダー実行は、IPCを高めるための技術です。
