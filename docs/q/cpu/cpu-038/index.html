CPU・アーキテクチャ

セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。

  1. Aあるアドレスのデータを、決まったセットの中の複数の場所(ウェイ)のどれかに置ける
  2. Bあるアドレスのデータを置ける場所が、キャッシュ内の1か所に決まっている
  3. Cデータをキャッシュのどこにでも置ける
答えと解説を見る

正解：A. あるアドレスのデータを、決まったセットの中の複数の場所(ウェイ)のどれかに置ける

セットアソシアティブ方式では、アドレスの一部でセットが決まり、その中の複数のウェイのどれかにデータを置けます。例えば8ウェイなら8か所の候補があり、ダイレクトマップ方式より同じ場所の取り合い(競合ミス)を減らせます。ウェイを増やすと比較回路と電力が増えるため、L1で8〜12ウェイ程度、L3で16ウェイ前後が一般的です。どこにでも置けるのはフルアソシアティブ方式です。

  • A. 正しい。決まったセット内の複数のウェイに置けます。
  • B. 置き場所が1か所に決まっているのはダイレクトマップ方式です。
  • C. どこにでも置けるのはフルアソシアティブ方式です。

CPU・アーキテクチャのほかの問題

  1. 現在の多くのCPUで使われているキャッシュライン(キャッシュブロック)の大きさとして一般的なものはどれか。
  2. パイプラインで、前の命令の結果を次の命令がすぐ使う(データハザード)とき、レジスタへの書き込みを待たずに演算結果を直接次の命令に渡す手法はどれか。
  3. リトルエンディアンの説明として正しいものはどれか。
  4. 1つのCPUコアで複数のスレッドの命令を同時に処理し、コア内の演算器などを有効に使う技術はどれか。
  5. マイコンなどで、周辺機器のレジスタをメモリと同じアドレス空間に割り当て、通常のメモリ読み書き命令で操作する方式はどれか。

この分野の比較

  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
  • ARM・RISC-V・x86の違い：命令セットアーキテクチャを比較ARM、RISC-V、x86を、設計の考え方・命令長・ライセンス・レジスタ・ソフトウェアの環境・強み・用途の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
