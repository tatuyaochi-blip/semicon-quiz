CPU・アーキテクチャ

RISC-Vの特徴として正しいものはどれか。

  1. A特定の1社だけが使える専用の命令セットである
  2. BGPU専用の命令セットである
  3. C仕様が公開されており、ライセンス料なしで利用できる命令セットアーキテクチャである
答えと解説を見る

正解：C. 仕様が公開されており、ライセンス料なしで利用できる命令セットアーキテクチャである

RISC-Vは2010年にカリフォルニア大学バークレー校で開発が始まったオープンなISAで、仕様が公開され、ライセンス料なしで誰でも実装できます。基本の整数命令は約40個と小さく、用途に応じて浮動小数点やベクトルなどの拡張を選んで組み合わせられます。独自命令も追加できるため、組み込みマイコン、ストレージのコントローラ、AIアクセラレータなどで採用が広がっています。

CPU・アーキテクチャのほかの問題

  1. 1クロックサイクルに複数の命令を同時に発行・実行するプロセッサの方式を何と呼ぶか。
  2. 仮想アドレスから物理アドレスへの変換結果を保持し、アドレス変換を高速化するキャッシュはどれか。
  3. AIの推論処理を高速かつ低い消費電力で行うために、スマートフォン用のSoCなどに搭載される専用回路はどれか。
  4. 一般的なコンピュータで、アクセスが速い順に並べた記憶階層として正しいものはどれか。
  5. クロック周波数2 GHz、平均CPI(1命令あたりの平均クロック数)0.5のプロセッサが、1秒間に実行できる命令数はおよそいくらか。
