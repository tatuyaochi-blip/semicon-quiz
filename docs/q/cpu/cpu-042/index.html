CPU・アーキテクチャ

1つのCPUコアで複数のスレッドの命令を同時に処理し、コア内の演算器などを有効に使う技術はどれか。

  1. ADVFS
  2. BDMA
  3. CSMT(同時マルチスレッディング)
答えと解説を見る

正解：C. SMT(同時マルチスレッディング)

SMT(Simultaneous Multi-Threading)は、1つのコアが複数のスレッドの命令を並行して発行することで、1つのスレッドだけでは使い切れない演算器などの資源を活用する技術です。Intelのハイパースレッディングが代表例で、OSからは1つのコアが2つの論理プロセッサに見えます。

  • A. DVFSは電圧と周波数を動的に変える省電力技術です。
  • B. DMAはCPUを介さずにデータを転送する仕組みです。
  • C. 正しい。1コアで複数スレッドを同時に処理します。

CPU・アーキテクチャのほかの問題

  1. マイコンなどで、周辺機器のレジスタをメモリと同じアドレス空間に割り当て、通常のメモリ読み書き命令で操作する方式はどれか。
  2. マイコンに搭載されるウォッチドッグタイマの役割として正しいものはどれか。
  3. プログラムでサブルーチン(関数)を呼び出すとき、戻り先のアドレスなどを一時的に保存するために一般的に使われる領域はどれか。
  4. キャッシュミスの分類「3つのC」に含まれるものの組み合わせとして正しいものはどれか。
  5. アウトオブオーダー実行のCPUで、順序を入れ替えて実行した命令の結果を、プログラムの本来の順序で確定(リタイア)させるための仕組みはどれか。
