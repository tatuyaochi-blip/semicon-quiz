CPU・アーキテクチャ

CPUの消費電力を減らすため、負荷に応じて動作周波数と電源電圧を動的に変える技術はどれか。

  1. ADVFS(動的電圧・周波数制御)
  2. Bオーバークロック
  3. CSIMD
答えと解説を見る

正解：A. DVFS(動的電圧・周波数制御)

DVFSは、処理が軽いときには周波数と電源電圧を下げ、重いときには上げる技術です。動的消費電力は電圧の2乗と周波数に比例するため、電圧と周波数を一緒に下げると、消費電力を大きく減らせます。スマートフォンやノートパソコンなどで広く使われています。
