CPU・アーキテクチャ

現在の多くのCPUで使われているキャッシュライン(キャッシュブロック)の大きさとして一般的なものはどれか。

  1. A1バイト
  2. B64バイト
  3. C64 MB
答えと解説を見る

正解：B. 64バイト

多くのCPUでは、キャッシュと主記憶の間のデータのやりとりを64バイト程度のライン単位で行います。近くのアドレスのデータは続けて使われることが多い(空間的局所性)ため、まとめて取り込むと効率がよくなります。

  • A. 1バイトずつでは、主記憶とのやりとりの効率が悪くなります。
  • B. 正しい。64バイトが一般的です。
  • C. 64 MBはキャッシュ全体の容量の桁で、ラインの大きさではありません。

CPU・アーキテクチャのほかの問題

  1. パイプラインで、前の命令の結果を次の命令がすぐ使う(データハザード)とき、レジスタへの書き込みを待たずに演算結果を直接次の命令に渡す手法はどれか。
  2. リトルエンディアンの説明として正しいものはどれか。
  3. 1つのCPUコアで複数のスレッドの命令を同時に処理し、コア内の演算器などを有効に使う技術はどれか。
  4. マイコンなどで、周辺機器のレジスタをメモリと同じアドレス空間に割り当て、通常のメモリ読み書き命令で操作する方式はどれか。
  5. マイコンに搭載されるウォッチドッグタイマの役割として正しいものはどれか。
