CPU・アーキテクチャ

CPUを介さずに、周辺装置とメモリの間で直接データを転送する仕組みはどれか。

  1. ATLB
  2. BSIMD
  3. CDMA(ダイレクトメモリアクセス)
答えと解説を見る

正解：C. DMA(ダイレクトメモリアクセス)

DMAでは、専用のコントローラがメモリと周辺装置の間のデータ転送を行うため、CPUは転送の間ほかの処理を進められます。ストレージやネットワークなど、大量のデータを転送する場面で使われます。

CPU・アーキテクチャのほかの問題

  1. CPU、メモリ、タイマーやADCなどの周辺機能を1チップにまとめ、家電や機器の制御に使われるLSIはどれか。
  2. マルチコアCPUで、各コアのキャッシュに同じアドレスのデータがあるとき、その内容の一貫性を保つ仕組みはどれか。
  3. CPUの消費電力を減らすため、負荷に応じて動作周波数と電源電圧を動的に変える技術はどれか。
  4. 投機的実行の痕跡がキャッシュに残ることを悪用し、本来アクセスできないデータを推測する攻撃が明らかになった脆弱性の例はどれか。
  5. CPUの冷却設計の目安となる、標準的な高負荷時に発生する熱量を表す指標はどれか。
