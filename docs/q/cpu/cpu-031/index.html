CPU・アーキテクチャ

CPUの日本語での一般的な呼び方として正しいものはどれか。

  1. A中央処理装置
  2. B主記憶装置
  3. C補助記憶装置
答えと解説を見る

正解：A. 中央処理装置

CPUは Central Processing Unit の略で、日本語では中央処理装置と呼ばれます。命令を読み出して解釈し、演算や制御を行うコンピュータの中心となる部分です。主記憶装置はメインメモリ、補助記憶装置はSSDやHDDなどを指します。

  • A. 正しい。CPUは中央処理装置です。
  • B. 主記憶装置はDRAMなどのメインメモリのことです。
  • C. 補助記憶装置はSSDやHDDなどのことです。

CPU・アーキテクチャのほかの問題

  1. クロック周波数3 GHzのCPUの説明として正しいものはどれか。
  2. 「64ビットCPU」の64ビットが主に表しているものはどれか。
  3. CPUが1つの命令を処理する基本的な流れとして正しい順序はどれか。
  4. CPUの中のALU(算術論理演算装置)の役割として正しいものはどれか。
  5. CPUのプログラムカウンタ(PC)が保持しているものはどれか。
