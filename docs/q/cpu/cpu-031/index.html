CPU・アーキテクチャ

CPUの日本語での一般的な呼び方として正しいものはどれか。

  1. A中央処理装置
  2. B主記憶装置
  3. C補助記憶装置
答えと解説を見る

正解：A. 中央処理装置

CPUは Central Processing Unit の略で、日本語では中央処理装置と呼ばれます。命令を読み出して解釈し、演算や制御を行うコンピュータの中心部分です。1971年のIntel 4004が1チップに収めた最初の商用マイクロプロセッサで、約2300個のトランジスタでした。現在のCPUは数百億個のトランジスタを集積しています。主記憶装置はメインメモリ、補助記憶装置はSSDやHDDです。

  • A. 正しい。CPUは中央処理装置です。
  • B. 主記憶装置はDRAMなどのメインメモリのことです。
  • C. 補助記憶装置はSSDやHDDなどのことです。
