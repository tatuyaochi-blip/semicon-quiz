CPU・アーキテクチャ

1クロックサイクルに複数の命令を同時に発行・実行するプロセッサの方式を何と呼ぶか。

  1. Aスーパースカラ
  2. Bシングルサイクル
  3. Cハーバードアーキテクチャ
答えと解説を見る

正解：A. スーパースカラ

スーパースカラは、複数の演算器を備え、互いに依存しない命令を1クロックに複数発行して、IPCを1より大きくする方式です。最近の高性能コアは1クロックに6〜10命令程度を処理できる幅をもちます。命令の順序を入れ替えるアウトオブオーダー実行と組み合わせて性能を高めますが、依存関係の検査回路は幅の2乗程度で複雑になるため、むやみに広げられません。

  5. 処理全体の90%を並列化できるプログラムを、プロセッサの数を限りなく増やして実行したとき、理論上の最大の高速化率はどれか。
