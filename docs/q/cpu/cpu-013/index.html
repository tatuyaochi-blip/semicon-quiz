CPU・アーキテクチャ

1クロックサイクルに複数の命令を同時に発行・実行するプロセッサの方式を何と呼ぶか。

  1. Aスーパースカラ
  2. Bシングルサイクル
  3. Cハーバードアーキテクチャ
答えと解説を見る

正解：A. スーパースカラ

スーパースカラは、複数の演算器を備え、互いに依存しない命令を1クロックに複数発行して、IPCを1より大きくする方式です。最近の高性能コアは1クロックに6〜10命令程度を処理できる幅をもちます。命令の順序を入れ替えるアウトオブオーダー実行と組み合わせて性能を高めますが、依存関係の検査回路は幅の2乗程度で複雑になるため、むやみに広げられません。

CPU・アーキテクチャのほかの問題

  1. 仮想アドレスから物理アドレスへの変換結果を保持し、アドレス変換を高速化するキャッシュはどれか。
  2. AIの推論処理を高速かつ低い消費電力で行うために、スマートフォン用のSoCなどに搭載される専用回路はどれか。
  3. 一般的なコンピュータで、アクセスが速い順に並べた記憶階層として正しいものはどれか。
  4. クロック周波数2 GHz、平均CPI(1命令あたりの平均クロック数)0.5のプロセッサが、1秒間に実行できる命令数はおよそいくらか。
  5. 処理全体の90%を並列化できるプログラムを、プロセッサの数を限りなく増やして実行したとき、理論上の最大の高速化率はどれか。

この分野の比較

  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
  • ARM・RISC-V・x86の違い：命令セットアーキテクチャを比較ARM、RISC-V、x86を、設計の考え方・命令長・ライセンス・レジスタ・ソフトウェアの環境・強み・用途の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
