CPU・アーキテクチャ

1クロックサイクルに複数の命令を同時に発行・実行するプロセッサの方式を何と呼ぶか。

  1. Aスーパースカラ
  2. Bシングルサイクル
  3. Cハーバードアーキテクチャ
答えと解説を見る

正解：A. スーパースカラ

スーパースカラは、複数の演算器を備え、互いに依存しない命令を同時に実行することで、1クロックあたりの実行命令数を増やす方式です。命令の順序を入れ替えて実行するアウトオブオーダー実行などと組み合わせて、高性能なCPUで使われています。

  5. 処理全体の90%を並列化できるプログラムを、プロセッサの数を限りなく増やして実行したとき、理論上の最大の高速化率はどれか。
