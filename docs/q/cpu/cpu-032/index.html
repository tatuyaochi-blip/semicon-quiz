CPU・アーキテクチャ

クロック周波数3 GHzのCPUの説明として正しいものはどれか。

  1. A1秒間に3,000回のクロックが入る
  2. B1秒間に30億回のクロックが入る
  3. C1秒間に3命令を実行する
答えと解説を見る

正解：B. 1秒間に30億回のクロックが入る

1 GHzは10⁹ Hzなので、3 GHzは1秒間に30億回のクロックが入り、1周期は約0.33 nsです。ただし1クロックで実行できる命令数(IPC)は設計で大きく異なるため、周波数だけでは性能は比べられません。また多くのCPUは負荷や温度に応じて周波数を常に変えており、表記される値は基本周波数や最大ブースト周波数のことが多い点にも注意します。

  • A. 3,000回は3 kHzに相当します。
  • B. 正しい。3 GHz = 1秒間に30億回です。
  • C. クロック周波数は命令数そのものではありません。

CPU・アーキテクチャのほかの問題

  1. 「64ビットCPU」の64ビットが主に表しているものはどれか。
  2. CPUが1つの命令を処理する基本的な流れとして正しい順序はどれか。
  3. CPUの中のALU(算術論理演算装置)の役割として正しいものはどれか。
  4. CPUのプログラムカウンタ(PC)が保持しているものはどれか。
  5. キャッシュの書き込み方式で、ライトバック方式の説明として正しいものはどれか。
