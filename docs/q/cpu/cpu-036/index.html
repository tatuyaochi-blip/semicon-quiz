CPU・アーキテクチャ

CPUのプログラムカウンタ(PC)が保持しているものはどれか。

  1. A次に実行する命令のアドレス
  2. B実行した命令の総数
  3. CCPUの温度
答えと解説を見る

正解：A. 次に実行する命令のアドレス

プログラムカウンタは、次に取り出して実行する命令のメモリ上のアドレスを保持するレジスタです。通常は命令を1つ実行するごとに命令の長さ分だけ進み(例えば4バイト)、分岐やジャンプ命令ではジャンプ先のアドレスに、割り込みでは割り込み処理の先頭アドレスに書き換えられます。関数の呼び出しでは、戻り先として現在の値がスタックやリンクレジスタに保存されます。

  • A. 正しい。次に実行する命令のアドレスを保持します。
  • B. 実行した命令の数を数えるのは性能カウンタなどです。
  • C. 温度はセンサーで測るもので、プログラムカウンタとは関係ありません。

CPU・アーキテクチャのほかの問題

  1. キャッシュの書き込み方式で、ライトバック方式の説明として正しいものはどれか。
  2. セットアソシアティブ方式のキャッシュの説明として正しいものはどれか。
  3. 現在の多くのCPUで使われているキャッシュライン(キャッシュブロック)の大きさとして一般的なものはどれか。
  4. パイプラインで、前の命令の結果を次の命令がすぐ使う(データハザード)とき、レジスタへの書き込みを待たずに演算結果を直接次の命令に渡す手法はどれか。
  5. リトルエンディアンの説明として正しいものはどれか。

この分野の比較

  • RISCとCISCの違い：命令セットの考え方と代表例を比較RISCとCISCの命令セットアーキテクチャを、命令長・メモリアクセス・レジスタ・デコード・コードサイズ・ARM、RISC-V、x86などの例の観点で表にして比較します。
  • ARM・RISC-V・x86の違い：命令セットアーキテクチャを比較ARM、RISC-V、x86を、設計の考え方・命令長・ライセンス・レジスタ・ソフトウェアの環境・強み・用途の観点で表にして比較します。
  • ノイマン型とハーバード型の違い：命令とデータの扱いを比較ノイマン型とハーバード型のアーキテクチャを、メモリ・バス・スループット・柔軟性・複雑さ・代表的な機器・修正ハーバード型の観点で表にして比較します。
