デジタル信号処理の基礎

次数の高いIIRフィルタを、係数のビット数が限られた固定小数点で実装するときの注意として正しいものはどれか。

  1. AIIRフィルタの極は係数の量子化の影響を受けないので、係数のビット数は通過帯域の利得の精度だけで決めればよい
  2. B係数を量子化してもFIRフィルタと同じく必ず安定なので、次数が高くても1つの差分方程式のまま実装するのがよい
  3. C高次の分母を1つの式のまま実装すると係数の誤差で極が動いて不安定になりうるので、2次の部分の縦続接続に分ける
答えと解説を見る

正解：C. 高次の分母を1つの式のまま実装すると係数の誤差で極が動いて不安定になりうるので、2次の部分の縦続接続に分ける

高次の多項式の根(極)は係数のわずかな変化に敏感で、特に極が単位円の近くに集まる急峻なフィルタでは、係数を丸めただけで極が単位円の外に出ることがあります。そこで、極を2個ずつ受け持つ2次のセクション(バイクワッド)に分けて縦続に接続すると、各セクションの係数の誤差が他の極に影響せず、量子化に強くなります。FIRフィルタは係数を量子化しても安定ですが、周波数特性は変わります。

  • A. IIRの極は分母の係数で決まり、量子化によって位置が動きます。
  • B. 量子化しても必ず安定なのは帰還のないFIRフィルタで、IIRフィルタは量子化で不安定になることがあります。
  • C. 正しい。2次のセクションの縦続接続にすると、極の位置が係数の誤差に強くなります。

デジタル信号処理の基礎のほかの問題

  1. サンプリング周波数48 kHzの信号を、4サンプルごとに1つ取り出して12 kHzに下げる(1/4のデシメーション)。間引く前に置くローパスフィルタで取り除いておくべき周波数の成分として正しいものはどれか。
  2. サンプリング周波数を L 倍にするため、各サンプルの間に L − 1 個の0を挿入した(ゼロ挿入)。このあとに必要な処理の説明として正しいものはどれか。
  3. サンプリング周波数を44.1 kHzから48 kHzに変換するため、L 倍のアップサンプリングと 1/M のダウンサンプリングを組み合わせる。最小の整数の組 (L, M) として正しいものはどれか。
  4. 256タップのFIRフィルタを、サンプリング周波数44.1 kHzで実時間に動かす。1秒あたりに必要な積和演算(MAC)の回数として正しいものはどれか。
  5. サンプリング周波数48 kHzで、1サンプルごとにFIRフィルタの出力を計算する。クロック200 MHzで1サイクルに1回の積和ができるプロセッサを使い、ほかの処理の時間を無視するとき、実時間で処理できるタップ数の上限に最も近いものはどれか。
