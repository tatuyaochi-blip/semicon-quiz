デジタル信号処理の基礎

DFTの前に掛ける窓関数について、方形窓(何も掛けない場合)とハン窓(ハニング窓)を比べた説明として正しいものはどれか。

  1. Aハン窓はメインローブの幅が方形窓の約半分になり、サイドローブも低くなるので、どの点でも方形窓より優れている
  2. Bハン窓はサイドローブが低く遠くのビンへの漏れが小さいが、メインローブの幅は方形窓の約2倍に広がる
  3. Cハン窓はメインローブが狭くなる代わりに、サイドローブが方形窓より高くなる
答えと解説を見る

正解：B. ハン窓はサイドローブが低く遠くのビンへの漏れが小さいが、メインローブの幅は方形窓の約2倍に広がる

方形窓は、メインローブの幅(最初の零点まで)が ±1 ビンと狭い一方、最大のサイドローブが約 −13 dB と高く、漏れが遠くのビンまで広がります。ハン窓は区間の両端をなめらかに0にするので、最大のサイドローブが約 −31 dB まで下がりますが、メインローブの幅は ±2 ビンと約2倍になります。強い信号の近くにある弱い信号を見たいときはハン窓のような窓、周波数の近い同じくらいの強さの信号を見分けたいときは方形窓が向く、というように目的で使い分けます。

  • A. メインローブは逆に広がります。サイドローブを下げるとメインローブが広がる、というトレードオフがあります。
  • B. 正しい。サイドローブは約 −13 dB から約 −31 dB に下がり、メインローブは ±1 ビンから ±2 ビンに広がります。
  • C. 逆です。ハン窓はサイドローブが低く、メインローブが広くなります。

デジタル信号処理の基礎のほかの問題

  1. 点数 N は十分大きいものとする。方形窓のDFTで、正弦波の周波数が隣り合う2つのビンのちょうど中間にあるとき、最も近いビンで読み取れる振幅の、周波数がビンの中心に一致する場合からの低下として最も近いものはどれか。
  2. 4点の信号 x[n] = {1, −1, 2, 0} の DFT を X[k] = Σx[n]e^(−j2πkn/4) とする。Σ|X[k]|²(k = 0〜3)として正しいものはどれか。
  3. 離散時間のLTIシステムの伝達関数 H(z) から周波数応答を求めるとき、z を動かす場所として正しいものはどれか。
  4. 差分方程式 y[n] = x[n] + 0.5x[n − 1] + 0.25y[n − 1] で表されるシステムの伝達関数 H(z) = Y(z)/X(z) として正しいものはどれか。
  5. 伝達関数 H(z) = 1/(1 − 1.3z⁻¹ + 0.4z⁻²) で表される因果的なシステムの、極と安定性の組み合わせとして正しいものはどれか。
