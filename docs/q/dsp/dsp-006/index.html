デジタル信号処理の基礎

x[n] = 2cos(πn/4) の平均電力(1周期にわたる |x[n]|² の平均)として正しいものはどれか。

  1. A2
  2. B4
  3. C16
答えと解説を見る

正解：A. 2

振幅 A の正弦波の平均電力は A²/2 で、A = 2 なら 4/2 = 2 です。1周期の8サンプル(2, √2, 0, −√2, −2, −√2, 0, √2)の2乗を平均しても、(4 + 2 + 0 + 2 + 4 + 2 + 0 + 2)/8 = 2 になります。周期信号はエネルギーが無限大になるので、エネルギーではなく平均電力で大きさを表します(電力信号)。

  • A. 正しい。A²/2 = 4/2 = 2 です。
  • B. ピーク値の2乗(A² = 4)です。正弦波の2乗の平均は、ピーク値の2乗の半分です。
  • C. 1周期の8サンプルの2乗の和です。平均電力は、これをサンプル数8で割った値です。

デジタル信号処理の基礎のほかの問題

  1. 入力 x[n]、出力 y[n] のシステムのうち、線形かつ時不変(LTI)であるものはどれか。
  2. y[n] = n·x[n] で表されるシステムの性質として正しいものはどれか。
  3. 入力 x[n]、出力 y[n] のシステムのうち、因果的(出力がその時刻までの入力だけで決まる)であるものはどれか。
  4. u[n] を単位ステップとする。インパルス応答が次のように表されるLTIシステムのうち、BIBO安定(有界な入力に対して出力が必ず有界)であるものはどれか。
  5. x[n] = {1, 2, 3}(n = 0, 1, 2)を、インパルス応答 h[n] = {1, −1}(n = 0, 1)のLTIシステムに入力した。出力 y[0]〜y[3] として正しいものはどれか。
