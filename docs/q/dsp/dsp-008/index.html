デジタル信号処理の基礎

y[n] = n·x[n] で表されるシステムの性質として正しいものはどれか。

  1. A線形で、時不変でもある
  2. B線形だが、時不変ではない
  3. C線形ではないが、時不変である
答えと解説を見る

正解：B. 線形だが、時不変ではない

入力 a·x₁[n] + b·x₂[n] に対する出力は n(a·x₁[n] + b·x₂[n]) = a·y₁[n] + b·y₂[n] なので、線形です。一方、入力を k サンプル遅らせた x[n − k] に対する出力は n·x[n − k] ですが、出力を k サンプル遅らせたものは (n − k)·x[n − k] で、両者は一致しません。例えば入力 δ[n − 1] に対する出力は δ[n − 1] ですが、δ[n − 2] に対する出力は 2δ[n − 2] になり、同じ形が遅れるだけにはなりません。掛ける値が時刻 n によって変わるシステムは、線形でも時不変ではありません。

  • A. 線形ですが、掛ける値 n が時刻によって変わるので、時不変ではありません。
  • B. 正しい。重ね合わせは成り立ちますが、入力を遅らせても出力は同じ形で遅れるだけにはなりません。
  • C. 入力の和に対して出力も和になる(重ね合わせが成り立つ)ので線形です。また、時不変ではありません。

デジタル信号処理の基礎のほかの問題

  1. 入力 x[n]、出力 y[n] のシステムのうち、因果的(出力がその時刻までの入力だけで決まる)であるものはどれか。
  2. u[n] を単位ステップとする。インパルス応答が次のように表されるLTIシステムのうち、BIBO安定(有界な入力に対して出力が必ず有界)であるものはどれか。
  3. x[n] = {1, 2, 3}(n = 0, 1, 2)を、インパルス応答 h[n] = {1, −1}(n = 0, 1)のLTIシステムに入力した。出力 y[0]〜y[3] として正しいものはどれか。
  4. 差分方程式 y[n] = x[n] + 0.5y[n − 1] で表されるシステムに、n = 0 から単位ステップ(n ≥ 0 で x[n] = 1)を入力した。y[−1] = 0 のとき、y[2] として正しいものはどれか。
  5. サンプリング周波数48 kHzの信号を、1024点の離散フーリエ変換(DFT)で解析する。周波数ビンの間隔として正しいものはどれか。
