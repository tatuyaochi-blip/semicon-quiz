デジタル信号処理の基礎

u[n] を単位ステップとする。インパルス応答が次のように表されるLTIシステムのうち、BIBO安定(有界な入力に対して出力が必ず有界)であるものはどれか。

  1. Ah[n] = (−0.9)ⁿu[n]
  2. Bh[n] = u[n]
  3. Ch[n] = (1.1)ⁿu[n]
答えと解説を見る

正解：A. h[n] = (−0.9)ⁿu[n]

LTIシステムがBIBO安定である必要十分条件は、インパルス応答の絶対値の総和 Σ|h[n]| が有限であることです。h[n] = (−0.9)ⁿu[n] では Σ|h[n]| = Σ0.9ⁿ = 1/(1 − 0.9) = 10 で有限なので安定です。h[n] = u[n] は入力をたし続ける累算器で、総和が無限大になり、一定の入力に対して出力が際限なく増えます。(1.1)ⁿ は時間とともに大きくなるので、不安定です。

  • A. 正しい。符号は交互に変わりますが、Σ|h[n]| = 10 で有限です。
  • B. 累算器のインパルス応答で、Σ|h[n]| が無限大なので安定ではありません。ステップを入力すると、出力が n + 1 と増え続けます。
  • C. |1.1| > 1 なので h[n] が増え続け、不安定です。

デジタル信号処理の基礎のほかの問題

  1. x[n] = {1, 2, 3}(n = 0, 1, 2)を、インパルス応答 h[n] = {1, −1}(n = 0, 1)のLTIシステムに入力した。出力 y[0]〜y[3] として正しいものはどれか。
  2. 差分方程式 y[n] = x[n] + 0.5y[n − 1] で表されるシステムに、n = 0 から単位ステップ(n ≥ 0 で x[n] = 1)を入力した。y[−1] = 0 のとき、y[2] として正しいものはどれか。
  3. サンプリング周波数48 kHzの信号を、1024点の離散フーリエ変換(DFT)で解析する。周波数ビンの間隔として正しいものはどれか。
  4. k = 0 を直流のビンとする。サンプリング周波数8 kHzでサンプリングした1 kHzの正弦波を256点のDFTで解析したとき、正の周波数の側でピークが現れるビンの番号 k として正しいものはどれか。
  5. 実数の信号 x[n] の64点のDFTを計算したところ、X[10] = 3 + 4j であった。X[54] として正しいものはどれか。
