デジタル信号処理の基礎

指数平滑化 y[n] = 0.2x[n] + 0.8y[n − 1] で表される1次のIIRローパスフィルタの、直流とナイキスト周波数での利得の組み合わせとして正しいものはどれか。

  1. A直流で1、ナイキスト周波数で0
  2. B直流で5、ナイキスト周波数で約0.56
  3. C直流で1、ナイキスト周波数で約0.11
答えと解説を見る

正解：C. 直流で1、ナイキスト周波数で約0.11

伝達関数は H(z) = 0.2/(1 − 0.8z⁻¹) で、直流(z = 1)では 0.2/(1 − 0.8) = 1、ナイキスト周波数(z = −1)では 0.2/(1 + 0.8) = 1/9 ≈ 0.11(約 −19 dB)です。新しい入力に0.2、それまでの出力に0.8の重みを掛けて足すので、重みの和が1となり、一定の入力はそのまま通ります。1つ前の出力を覚えておくだけで、過去の入力に指数的に小さくなる重みを掛けた平均が得られます。極は z = 0.8 で単位円の内側にあるので安定ですが、帰還の係数が1に近いほど平滑化が強くなり、応答も遅くなります。

  • A. この式の分子は定数で、単位円の上に零点がないので、利得が0になる周波数はありません。
  • B. 入力の係数0.2を1とした y[n] = x[n] + 0.8y[n − 1] の利得(1/0.2 = 5、1/1.8 ≈ 0.56)です。
  • C. 正しい。z = 1 で 0.2/0.2 = 1、z = −1 で 0.2/1.8 ≈ 0.11 です。

デジタル信号処理の基礎のほかの問題

  1. アナログフィルタの伝達関数 H(s) からデジタルフィルタを設計するときに使う、双一次変換の説明として正しいものはどれか。
  2. 次数の高いIIRフィルタを、係数のビット数が限られた固定小数点で実装するときの注意として正しいものはどれか。
  3. サンプリング周波数48 kHzの信号を、4サンプルごとに1つ取り出して12 kHzに下げる(1/4のデシメーション)。間引く前に置くローパスフィルタで取り除いておくべき周波数の成分として正しいものはどれか。
  4. サンプリング周波数を L 倍にするため、各サンプルの間に L − 1 個の0を挿入した(ゼロ挿入)。このあとに必要な処理の説明として正しいものはどれか。
  5. サンプリング周波数を44.1 kHzから48 kHzに変換するため、L 倍のアップサンプリングと 1/M のダウンサンプリングを組み合わせる。最小の整数の組 (L, M) として正しいものはどれか。
