デジタル信号処理の基礎

8点の実数の信号 x[n] = {3, 1, 3, 1, 3, 1, 3, 1} の DFT を X[k] = Σx[n]e^(−j2πkn/8) とする。ナイキスト周波数に当たるビン X[4] の値として正しいものはどれか。

  1. A1
  2. B2
  3. C8
答えと解説を見る

正解：C. 8

k = N/2 = 4 では e^(−jπn) = (−1)ⁿ なので、X[4] = Σ(−1)ⁿx[n] = 3 − 1 + 3 − 1 + 3 − 1 + 3 − 1 = 8 です。この信号は、平均2の直流に、±1で交互に変わる成分 (−1)ⁿ が重なったもので、交互の成分がナイキストのビンに、直流が X[0] = 16 に現れます。X[0] と X[N/2] は、実数の信号では常に実数になります。

  • A. 交互に変わる成分の振幅(X[4]/N = 8/8)です。この定義のDFTの値は、その N 倍になります。
  • B. 信号の平均値(直流の成分、X[0]/N = 16/8)です。
  • C. 正しい。(−1)ⁿ を掛けて足すと8になります。

デジタル信号処理の基礎のほかの問題

  1. N点のDFTを定義どおりに計算すると約 N² 回、FFT(高速フーリエ変換)では約 N log₂N 回の演算で済むとする。N = 1024 のとき、FFTによる演算回数の削減の度合いとして最も近いものはどれか。
  2. 256点の信号のあとに0を768個付け足して(ゼロパディング)、1024点のDFTを計算した。256点のままDFTを計算した場合と比べた説明として正しいものはどれか。
  3. DFTでスペクトル漏れが生じる主な原因として正しいものはどれか。
  4. DFTの前に掛ける窓関数について、方形窓(何も掛けない場合)とハン窓(ハニング窓)を比べた説明として正しいものはどれか。
  5. 点数 N は十分大きいものとする。方形窓のDFTで、正弦波の周波数が隣り合う2つのビンのちょうど中間にあるとき、最も近いビンで読み取れる振幅の、周波数がビンの中心に一致する場合からの低下として最も近いものはどれか。
