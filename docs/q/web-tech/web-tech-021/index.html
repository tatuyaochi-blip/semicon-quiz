Web技術の基礎

ブラウザで使われるDOM(Document Object Model)の説明として、正しいものはどれか。

  1. Aサーバのデータベースの表の構造を、ブラウザに送るためにHTMLの表(table要素)の形に変換したものである
  2. BHTMLの文書を、要素などを節(ノード)とする木の構造で表したもので、JavaScriptから読み書きできる
  3. CCSSの規則を、ファイルを小さくして読み込みを速くするために、空白を除いて圧縮した形式である
答えと解説を見る

正解：B. HTMLの文書を、要素などを節(ノード)とする木の構造で表したもので、JavaScriptから読み書きできる

ブラウザはHTMLを解析して、html要素を根とし、head、body、その中の段落などを節とする木の構造(DOMツリー)を作ります。JavaScriptは、document.querySelector で要素を探したり、文字や属性を書き換えたり、要素を追加したりして、DOMを通じてページを変えます。DOMが変わると、ブラウザは必要に応じて配置の計算と描画をやり直します。DOMは、特定のプログラミング言語によらない、文書を操作するためのインターフェースとして標準化されています。

  • A. DOMはブラウザの中の文書の構造で、データベースとは関係がありません。
  • B. 正しい。文書を木の構造で表し、スクリプトから操作できるようにしたものです。
  • C. CSSの圧縮とは関係がありません。CSSから作られる構造はCSSOMと呼ばれます。
