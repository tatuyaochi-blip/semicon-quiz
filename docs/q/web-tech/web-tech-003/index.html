Web技術の基礎

HTTPのステータスコードと、その意味の組み合わせとして正しいものはどれか。

  1. A301: 要求された資源が、一時的に別のURLにある
  2. B404: 要求された資源が、サーバに見つからなかった
  3. C503: リクエストの書き方に誤りがあり、サーバが理解できなかった
答えと解説を見る

正解：B. 404: 要求された資源が、サーバに見つからなかった

ステータスコードは3桁の数で、百の位が分類を表します。2xxは成功(200 OK、201 Created、204 No Content)、3xxはリダイレクト(301 Moved Permanently、302 Found、304 Not Modified)、4xxはクライアント側の誤り(400 Bad Request、401 Unauthorized、403 Forbidden、404 Not Found)、5xxはサーバ側の誤り(500 Internal Server Error、503 Service Unavailable)です。404は、URLで示した資源がサーバに見つからなかったことを示します。

  • A. 301は資源が恒久的に移ったことを示します。一時的な移動には302や307を使います。
  • B. 正しい。404 Not Found は、要求された資源が見つからなかったことを示します。
  • C. リクエストの誤りを示すのは400 Bad Requestです。503は、過負荷や保守のために一時的に処理できないことを示します。

Web技術の基礎のほかの問題

  1. 会員制のWebサイトで、ログインしている一般の会員が、管理者だけに許されたページを要求した。サーバは利用者がだれかを確認できているが、このページへのアクセスは許可しない。このとき返すステータスコードとして最も適切なものはどれか。
  2. Web APIが、応答の本文としてJSON形式のデータを返す。本文の形式を示すために応答に付けるヘッダとして、一般に使われるものはどれか。
  3. ブラウザが、前に受け取った画像を、そのときの応答に付いていたETagの値をIf-None-Matchヘッダに入れて、もう一度要求した。サーバ上の画像が変わっていないときの、サーバの応答として正しいものはどれか。
  4. HTTP/2とHTTP/3の説明として正しいものはどれか。
  5. RTTが40 msのWebサーバから、HTMLを1つと、そこから参照される画像を4つ、1つずつ順番に取得する。TCPの接続の確立に1往復、各リクエストと応答に1往復かかるとし、データの転送時間、サーバの処理時間、TLS、接続の切断は考えない。オブジェクトごとに新しいTCP接続を張る場合と、1つのTCP接続を使い回す持続的接続の場合とで、かかる時間の差はどれか。
