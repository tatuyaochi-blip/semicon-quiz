Web技術の基礎

1.5 MBのテキストのデータを、gzipで3分の1の大きさに圧縮して送る。帯域が10 Mbps、RTTが100 msで、データを送り始める前に、TCPの接続、TLSのハンドシェイク、HTTPのリクエストで合わせて3往復かかるとする。1 MB = 10^6 バイトとし、圧縮と展開の時間、ヘッダ、TCPの輻輳制御による待ちは無視する。データを受け取り終えるまでの時間に最も近いものはどれか。

  1. A約0.4 s
  2. B約0.7 s
  3. C約1.5 s
答えと解説を見る

正解：B. 約0.7 s

圧縮した後の大きさは 1.5 ÷ 3 = 0.5 MB で、ビットに直すと 0.5 × 8 = 4 Mビットです。これを10 Mbpsで送る時間は 4 ÷ 10 = 0.4 s で、送り始める前の3往復の 3 × 0.1 = 0.3 s を足すと、合わせて約0.7 sです。圧縮しなければ、1.5 MB = 12 Mビットの転送に 12 ÷ 10 = 1.2 s かかり、合計は約1.5 sになります。

  • A. データの転送時間の0.4 sだけで、送り始める前の3往復の0.3 sを足していません。
  • B. 正しい。0.4 + 0.3 = 0.7 s です。
  • C. 圧縮しないで1.5 MBを送った場合の 1.2 + 0.3 = 1.5 s です。

Web技術の基礎のほかの問題

  1. 1秒あたり2,000件のリクエストを受けるCDNで、キャッシュヒット率が90%から98%に上がった。ヒットしたときの応答時間は20 ms、ヒットしなかったときはオリジンサーバから取得して返すので200 msかかり、ヒットしなかったリクエストだけがオリジンサーバに届くとする。98%になった後の、オリジンサーバに届くリクエストの数と平均の応答時間の組み合わせはどれか。
  2. Webページの体験を表す指標であるCore Web Vitalsのうち、CLS(Cumulative Layout Shift)が表すものはどれか。
  3. Webページで使う画像の形式と、その一般的な使い方の組み合わせとして、適切なものはどれか。
  4. 3,000バイトの画像のデータをBase64で符号化して、HTMLの中に埋め込む。改行を入れないとき、符号化した後の文字数はどれか。
  5. Webシステムを、Webサーバ、アプリケーションサーバ、データベースサーバの3層で構成する。アプリケーションサーバが主に受け持つ処理として、適切なものはどれか。
