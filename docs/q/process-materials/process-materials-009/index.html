プロセス材料(ガス・薬液)

半導体用の高純度ガスや薬液の不純物濃度を表すのによく使われる単位はどれか。

  1. Appb(10億分の1)やppt(1兆分の1)
  2. B%(100分の1)だけ
  3. Ckg
答えと解説を見る

正解：A. ppb(10億分の1)やppt(1兆分の1)

半導体用の材料では、金属不純物などをppb(10⁻⁹)やppt(10⁻¹²)の単位で管理します。ウエハ表面の金属汚染は10¹⁰ atoms/cm²程度でも問題になるため、薬液やガスに含まれる不純物もそれに見合う低さが必要です。%は100分の1の単位で、半導体材料の不純物を表すには粗すぎます。kgは質量の単位で、濃度を表すものではありません。

  3. 装置に供給する直前のガスから、微量の不純物やパーティクルを取り除くために配管に設けられる機器はどれか。
  4. ArFエキシマレーザーの発振に使われるガスの組み合わせとして適切なものはどれか。
  5. エピタキシャル成長や熱処理で、キャリアガスや還元性の雰囲気として使われるガスはどれか。
