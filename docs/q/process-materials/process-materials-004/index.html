プロセス材料(ガス・薬液)

シリコン酸化膜(SiO2)のドライエッチングに主に使われるガスはどれか。

  1. A窒素ガスのみ
  2. Bヘリウムガスのみ
  3. CCF4やC4F8などのフルオロカーボン系ガス
答えと解説を見る

正解：C. CF4やC4F8などのフルオロカーボン系ガス

SiO2のドライエッチングでは、フッ素を含むフルオロカーボン系ガスのプラズマを使い、Siを揮発性のSiF4にして除去します。これらのガスの多くは地球温暖化係数が大きいため、使用後は除害装置で分解してから排出します。
