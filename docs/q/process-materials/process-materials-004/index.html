プロセス材料(ガス・薬液)

シリコン酸化膜(SiO2)のドライエッチングに主に使われるガスはどれか。

  1. A窒素ガスのみ
  2. Bヘリウムガスのみ
  3. CCF4やC4F8などのフルオロカーボン系ガス
答えと解説を見る

正解：C. CF4やC4F8などのフルオロカーボン系ガス

SiO2のドライエッチングでは、CF4やC4F8などのフルオロカーボンガスのプラズマを使います。フッ素がSiと結びついて揮発性のSiF4になり、炭素は膜中の酸素とCOやCO2になって排気されます。窒素やヘリウムだけでは化学反応が起こらず、膜を削れません。これらのガスは地球温暖化係数がCO2の数千倍以上と大きいため、使用後は除害装置で分解してから排出します。
