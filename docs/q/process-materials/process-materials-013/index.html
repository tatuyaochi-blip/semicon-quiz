プロセス材料(ガス・薬液)

ArFエキシマレーザーの発振に使われるガスの組み合わせとして適切なものはどれか。

  1. A酸素と窒素
  2. B水素とヘリウムだけ
  3. Cアルゴンとフッ素(ネオンなどのバッファガスを含む)
答えと解説を見る

正解：C. アルゴンとフッ素(ネオンなどのバッファガスを含む)

ArFエキシマレーザーは、アルゴンとフッ素を含む混合ガスを放電で励起し、波長193 nmの光を出します。ガスの大部分はネオンなどのバッファガスです。KrFエキシマレーザー(248 nm)では、クリプトンとフッ素を使います。

プロセス材料(ガス・薬液)のほかの問題

  1. エピタキシャル成長や熱処理で、キャリアガスや還元性の雰囲気として使われるガスはどれか。
  2. MOCVDの原料であるトリメチルガリウム(TMGa)などの有機金属化合物の取り扱い上の注意点として正しいものはどれか。
  3. ガスの純度を「6N」と表したときの純度として正しいものはどれか。
  4. 半導体工場で最も大量に使われるガスの一つで、パージや雰囲気ガスとして配管で供給されるものはどれか。
  5. ArF液浸露光で、フォトレジストの上に塗り、液浸の水とレジストが直接触れないようにする膜はどれか。
