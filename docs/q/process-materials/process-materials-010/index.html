プロセス材料(ガス・薬液)

CMPの研磨パッドに一般的に使われる材料はどれか。

  1. Aタングステン
  2. B発泡ポリウレタン
  3. C石英ガラス
答えと解説を見る

正解：B. 発泡ポリウレタン

CMPのパッドには、細かい気孔をもつ発泡ポリウレタンがよく使われます。気孔と表面の溝にスラリーを保持してウエハ全体に行き渡らせ、研磨くずを排出します。使ううちに気孔が目詰まりして研磨速度が落ちるため、ダイヤモンドを埋め込んだディスクで表面を削って整えるコンディショニングを行います。硬いパッドは平坦性に優れ、柔らかいパッドは傷が少ないため、重ねて使うこともあります。
