プロセス材料(ガス・薬液)

CMPの研磨パッドに一般的に使われる材料はどれか。

  1. Aタングステン
  2. B発泡ポリウレタン
  3. C石英ガラス
答えと解説を見る

正解：B. 発泡ポリウレタン

CMPのパッドには、細かい気孔をもつ発泡ポリウレタンがよく使われます。気孔や表面の溝にスラリーを保持し、ウエハ全体に行き渡らせる役割があります。パッドの表面は使ううちに目詰まりするため、ダイヤモンドの工具で表面を整える(コンディショニング)必要があります。

プロセス材料(ガス・薬液)のほかの問題

  1. p型不純物(ホウ素)の導入に使われる原料ガスとして正しいものはどれか。
  2. 装置に供給する直前のガスから、微量の不純物やパーティクルを取り除くために配管に設けられる機器はどれか。
  3. ArFエキシマレーザーの発振に使われるガスの組み合わせとして適切なものはどれか。
  4. エピタキシャル成長や熱処理で、キャリアガスや還元性の雰囲気として使われるガスはどれか。
  5. MOCVDの原料であるトリメチルガリウム(TMGa)などの有機金属化合物の取り扱い上の注意点として正しいものはどれか。
