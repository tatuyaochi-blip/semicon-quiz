プロセス材料(ガス・薬液)

ArF露光用のフォトマスクの基板に使われる材料はどれか。

  1. A合成石英ガラス
  2. Bソーダ石灰ガラス
  3. Cアルミニウム
答えと解説を見る

正解：A. 合成石英ガラス

ArF露光(193 nm)では、短い波長の光をよく通し、熱膨張が小さい合成石英ガラスがマスク基板に使われます。その上にクロムなどの遮光膜や位相シフト膜でパターンをつくります。EUVマスクでは、熱膨張がさらに小さい特殊なガラスの上に多層膜をつくります。

プロセス材料(ガス・薬液)のほかの問題

  1. EUVマスクの反射多層膜に使われる材料の組み合わせとして正しいものはどれか。
  2. 酸化膜のエッチングで、C4F8のように炭素の割合が多いフルオロカーボンガスを使う理由として正しいものはどれか。
  3. Cuのシード層用スパッタリングターゲットに求められる純度の目安として正しいものはどれか。
  4. 洗浄後の乾燥などに使われるIPAの化学名として正しいものはどれか。
  5. CVDなどの原料として使われるシラン(SiH4)の取り扱い上の主な危険性はどれか。
