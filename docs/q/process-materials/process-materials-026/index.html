プロセス材料(ガス・薬液)

ArF露光用のフォトマスクの基板に使われる材料はどれか。

  1. A合成石英ガラス
  2. Bソーダ石灰ガラス
  3. Cアルミニウム
答えと解説を見る

正解：A. 合成石英ガラス

ArF露光(193 nm)では、短い波長の光をよく通し、熱膨張が小さい合成石英ガラスをマスク基板に使い、その上にクロムの遮光膜や位相シフト膜でパターンをつくります。ソーダ石灰ガラスは深紫外光を吸収し、熱膨張も大きいため使えません。EUVでは光を通す材料がないため反射型マスクとなり、熱膨張がほぼゼロの低熱膨張ガラスの上に多層膜をつくります。
