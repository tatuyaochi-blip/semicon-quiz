プロセス材料(ガス・薬液)

熱処理炉の反応管や、ウエハを載せる治具に広く使われる、高純度で耐熱性に優れた材料はどれか。

  1. Aポリエチレン
  2. B石英ガラス
  3. C銅
答えと解説を見る

正解：B. 石英ガラス

石英ガラスは高純度で、軟化点が約1600 ℃と高く、熱膨張係数が約0.5×10⁻⁶ /Kと非常に小さいため急な温度変化でも割れにくく、多くの薬品にも強い材料です。そのため熱処理炉の反応管、ウエハボート、CZ法のるつぼなどに使われます。より高温での強度や長寿命が必要な部材にはSiCも使われます。ポリエチレンは耐熱性がなく、銅は金属汚染の原因になります。
