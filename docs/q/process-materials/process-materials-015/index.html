プロセス材料(ガス・薬液)

MOCVDの原料であるトリメチルガリウム(TMGa)などの有機金属化合物の取り扱い上の注意点として正しいものはどれか。

  1. A毒性も反応性もなく、安全に扱える
  2. B強い放射線を出す
  3. C空気や水と激しく反応し、自然発火するおそれがある
答えと解説を見る

正解：C. 空気や水と激しく反応し、自然発火するおそれがある

トリメチルガリウムやトリメチルアルミニウムなどの有機金属化合物は、空気中で自然発火し、水とも激しく反応します。温度を一定に保ったバブラーという容器に入れ、水素や窒素を通して蒸気を運びます。温度で蒸気圧が決まるため、容器の温度とガスの流量で供給量を制御します。放射線は出さず、安全に扱える物質でもありません。GaNやGaAsのMOCVDで使われます。

プロセス材料(ガス・薬液)のほかの問題

  1. ガスの純度を「6N」と表したときの純度として正しいものはどれか。
  2. 半導体工場で最も大量に使われるガスの一つで、パージや雰囲気ガスとして配管で供給されるものはどれか。
  3. ArF液浸露光で、フォトレジストの上に塗り、液浸の水とレジストが直接触れないようにする膜はどれか。
  4. Low-k層間絶縁膜として使われる代表的な材料はどれか。
  5. 熱処理炉の反応管や、ウエハを載せる治具に広く使われる、高純度で耐熱性に優れた材料はどれか。
