プロセス材料(ガス・薬液)

ガスの配管で、ガスが流れずにたまる行き止まりの部分(デッドスペース)を少なくする設計が求められる理由はどれか。

  1. A配管を長くするため
  2. Bたまったガスや水分、不純物が入れ替わりにくく、汚染源になったり、ガスの切り替えに時間がかかったりするため
  3. C配管の色をそろえるため
答えと解説を見る

正解：B. たまったガスや水分、不純物が入れ替わりにくく、汚染源になったり、ガスの切り替えに時間がかかったりするため

デッドスペースにはガスや水分、不純物がたまり、パージしても入れ替わりにくくなります。これがプロセスガスを汚染したり、異なるガスに切り替えるときに前のガスが残ったりする原因になるため、配管やバルブはデッドスペースが少なくなるように設計されます。

  • A. 配管を長くするためではありません。
  • B. 正しい。汚染源になり、切り替えにも時間がかかるためです。
  • C. 色の問題ではありません。

プロセス材料(ガス・薬液)のほかの問題

  1. ガスのラインを開放したり、別のガスに切り替えたりする前に、不活性ガスでの加圧と排気を何度も繰り返す操作を何と呼ぶか。
  2. 塩化水素などのハロゲン系のガスの配管で、ガス中の水分をとくに厳しく管理する理由として正しいものはどれか。
  3. CVDなどの原料として使われるシラン(SiH4)の取り扱い上の主な危険性はどれか。
  4. 半導体用の多結晶シリコン(ポリシリコン)原料に求められる純度の目安として最も適切なものはどれか。
  5. 半導体製造で使う超純水の純度管理に使われる代表的な指標はどれか。
