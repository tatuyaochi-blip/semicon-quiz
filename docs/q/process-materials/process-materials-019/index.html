プロセス材料(ガス・薬液)

Low-k層間絶縁膜として使われる代表的な材料はどれか。

  1. A炭素を含む酸化シリコン(SiOC)系の膜
  2. B銅
  3. C窒化チタン
答えと解説を見る

正解：A. 炭素を含む酸化シリコン(SiOC)系の膜

Low-k膜には、酸化シリコンに炭素やメチル基を取り込んで誘電率を下げたSiOC系の膜(炭素ドープ酸化膜)が広く使われています。さらに誘電率を下げるため、膜中に微細な空孔をつくったポーラス膜も使われますが、機械的強度が下がることが課題です。
