プロセス材料(ガス・薬液)

装置のチャンバーのクリーニングなどに使われる三フッ化塩素(ClF3)の特徴として正しいものはどれか。

  1. A不活性で、ほとんどの物質と反応しない
  2. B反応性が非常に高く、多くの物質と激しく反応するため、厳重な取り扱いが必要である
  3. C無害で、換気も不要である
答えと解説を見る

正解：B. 反応性が非常に高く、多くの物質と激しく反応するため、厳重な取り扱いが必要である

ClF3は非常に反応性の高いガスで、プラズマを使わなくても多くの物質と反応してエッチングできるため、チャンバーのクリーニングなどに使われます。その反面、多くの材料と激しく反応して発火することもあり、毒性も高いため、厳重な管理のもとで使用されます。
