プロセス材料(ガス・薬液)

装置のチャンバーのクリーニングなどに使われる三フッ化塩素(ClF3)の特徴として正しいものはどれか。

  1. A不活性で、ほとんどの物質と反応しない
  2. B反応性が非常に高く、多くの物質と激しく反応するため、厳重な取り扱いが必要である
  3. C無害で、換気も不要である
答えと解説を見る

正解：B. 反応性が非常に高く、多くの物質と激しく反応するため、厳重な取り扱いが必要である

ClF3は反応性が非常に高く、プラズマを使わなくても多くの物質をエッチングできるため、エピタキシャル装置などのチャンバー内の付着物をその場で除去するクリーニングに使われます。その反面、有機物や多くの金属と激しく反応して発火することもあり、毒性も高いため、材料の選定や漏えい対策を厳重に行います。不活性でも無害でもなく、反応性の高さこそが用途と危険の両方の理由です。
