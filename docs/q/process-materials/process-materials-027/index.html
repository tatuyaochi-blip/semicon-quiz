プロセス材料(ガス・薬液)

EUVマスクの反射多層膜に使われる材料の組み合わせとして正しいものはどれか。

  1. A金と銀
  2. B銅とアルミニウム
  3. Cモリブデンとシリコン
答えと解説を見る

正解：C. モリブデンとシリコン

EUVマスクやEUV露光装置のミラーには、モリブデン(Mo)とシリコン(Si)の薄い層を40対程度交互に積み重ねた多層膜が使われます。各層の厚さを波長に合わせることで、反射光が強め合い、13.5 nmの光を約70%程度反射できます。

プロセス材料(ガス・薬液)のほかの問題

  1. 酸化膜のエッチングで、C4F8のように炭素の割合が多いフルオロカーボンガスを使う理由として正しいものはどれか。
  2. Cuのシード層用スパッタリングターゲットに求められる純度の目安として正しいものはどれか。
  3. 洗浄後の乾燥などに使われるIPAの化学名として正しいものはどれか。
  4. 半導体の製造に使われるプロセス材料の主な種類の組み合わせとして正しいものはどれか。
  5. フォトレジストの一般的な保管方法として適切なものはどれか。
