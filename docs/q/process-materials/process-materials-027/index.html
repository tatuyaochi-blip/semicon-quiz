プロセス材料(ガス・薬液)

EUVマスクの反射多層膜に使われる材料の組み合わせとして正しいものはどれか。

  1. A金と銀
  2. B銅とアルミニウム
  3. Cモリブデンとシリコン
答えと解説を見る

正解：C. モリブデンとシリコン

EUVマスクや露光装置のミラーには、モリブデンとシリコンの薄い層を周期約7 nmで40対ほど交互に重ねた多層膜が使われます。各界面で少しずつ反射した光の位相がそろうよう厚さを設計しているため、13.5 nmの光を約70%反射できます。EUVはあらゆる物質に強く吸収されるので、レンズではなく反射光学系が必要です。表面はルテニウムなどの保護層で覆います。
