プロセス材料(ガス・薬液)

半導体工場で最も大量に使われるガスの一つで、パージや雰囲気ガスとして配管で供給されるものはどれか。

  1. Aホスフィン
  2. B窒素(N2)
  3. C三フッ化窒素(NF3)
答えと解説を見る

正解：B. 窒素(N2)

窒素は不活性で安価なため、装置や配管のパージ、FOUPや装置内の雰囲気の置換、真空ポンプの保護などに大量に使われます。大きな工場では空気分離装置を敷地内や隣に置き、配管で供給します。大量に使うため、狭い場所に漏れると酸素濃度が18%を下回って酸素欠乏症の危険があります。ホスフィンやNF3は特定の工程だけで使う特殊材料ガスです。

  4. フォトレジストの現像に一般的に使われる水溶液はどれか。
  5. 半導体の現像液に、水酸化ナトリウムなどではなくTMAHのような有機アルカリが使われる主な理由はどれか。
