プロセス材料(ガス・薬液)

半導体工場で最も大量に使われるガスの一つで、パージや雰囲気ガスとして配管で供給されるものはどれか。

  1. Aホスフィン
  2. B窒素(N2)
  3. C三フッ化窒素(NF3)
答えと解説を見る

正解：B. 窒素(N2)

窒素は不活性で安価なため、装置や配管のパージ、FOUPや装置内の雰囲気の置換、真空ポンプのパージなどに大量に使われます。工場の敷地内に窒素製造設備を設けて、配管で供給することも一般的です。大量に使うため、酸素欠乏への注意も必要です。

プロセス材料(ガス・薬液)のほかの問題

  1. ArF液浸露光で、フォトレジストの上に塗り、液浸の水とレジストが直接触れないようにする膜はどれか。
  2. Low-k層間絶縁膜として使われる代表的な材料はどれか。
  3. 熱処理炉の反応管や、ウエハを載せる治具に広く使われる、高純度で耐熱性に優れた材料はどれか。
  4. フォトレジストの現像に一般的に使われる水溶液はどれか。
  5. 半導体の現像液に、水酸化ナトリウムなどではなくTMAHのような有機アルカリが使われる主な理由はどれか。
