プロセス材料(ガス・薬液)

化学増幅型フォトレジストの主な構成要素の組み合わせとして正しいものはどれか。

  1. Aベース樹脂、光酸発生剤(PAG)、溶剤
  2. B銅の粒子と水
  3. Cシリコン単結晶と酸素
答えと解説を見る

正解：A. ベース樹脂、光酸発生剤(PAG)、溶剤

化学増幅型レジストは、現像液への溶けやすさが変わるベース樹脂、露光で酸を発生する光酸発生剤、塗布のための溶剤などからなります。酸の拡散を調整するクエンチャーなどの添加剤も含まれます。

  3. 半導体用の高純度ガスや薬液の不純物濃度を表すのによく使われる単位はどれか。
  4. CMPの研磨パッドに一般的に使われる材料はどれか。
  5. p型不純物(ホウ素)の導入に使われる原料ガスとして正しいものはどれか。
