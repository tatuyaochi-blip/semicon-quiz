プロセス材料(ガス・薬液)

p型不純物(ホウ素)の導入に使われる原料ガスとして正しいものはどれか。

  1. Aジボラン(B2H6)や三フッ化ホウ素(BF3)
  2. Bホスフィン(PH3)
  3. Cアルシン(AsH3)
答えと解説を見る

正解：A. ジボラン(B2H6)や三フッ化ホウ素(BF3)

ホウ素の導入には、ジボランや三フッ化ホウ素などのホウ素を含むガスが使われます。ホスフィンやアルシンは、n型不純物であるリンやヒ素の原料です。いずれも毒性や反応性が高く、厳重に管理されます。

この分野を解く 分野ページへ

プロセス材料(ガス・薬液)のほかの問題

  1. 装置に供給する直前のガスから、微量の不純物やパーティクルを取り除くために配管に設けられる機器はどれか。
  2. ArFエキシマレーザーの発振に使われるガスの組み合わせとして適切なものはどれか。
  3. エピタキシャル成長や熱処理で、キャリアガスや還元性の雰囲気として使われるガスはどれか。
  4. MOCVDの原料であるトリメチルガリウム(TMGa)などの有機金属化合物の取り扱い上の注意点として正しいものはどれか。
  5. ガスの純度を「6N」と表したときの純度として正しいものはどれか。
