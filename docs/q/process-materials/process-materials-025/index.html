プロセス材料(ガス・薬液)

半導体の材料の供給に関するリスクとして適切なものはどれか。

  1. A半導体材料はどこでも簡単に入手できるため、リスクはない
  2. B半導体は材料を使わずに製造できる
  3. C一部の高純度材料やガスは供給元が限られており、災害や地政学的な事情で供給が滞るリスクがある
答えと解説を見る

正解：C. 一部の高純度材料やガスは供給元が限られており、災害や地政学的な事情で供給が滞るリスクがある

高純度のガス、薬液、ウエハ、レジストなどの中には、供給できる企業や地域が限られているものがあります。災害や輸出規制、紛争などで供給が途絶えると、半導体の生産に大きな影響が出るため、調達先の分散や在庫の確保などの対策が重要になっています。
