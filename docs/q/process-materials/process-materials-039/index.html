プロセス材料(ガス・薬液)

半導体工場で大量に使われる窒素ガスを工場の近くで製造する、代表的な方法はどれか。

  1. A石油を燃やす
  2. B空気を冷却・液化して沸点の違いで窒素を分離する(深冷分離)
  3. C水を電気分解する
答えと解説を見る

正解：B. 空気を冷却・液化して沸点の違いで窒素を分離する(深冷分離)

大量の窒素は、空気を圧縮・冷却して液化し、窒素と酸素などの沸点の違いを利用して分離する深冷分離で製造されます。大きな半導体工場では、敷地内や隣接する場所に空気分離装置を置き、配管で高純度の窒素を供給することが多くあります。

  • A. 石油を燃やしても高純度の窒素は得られません。
  • B. 正しい。空気を液化して沸点の違いで分離します。
  • C. 水の電気分解では水素と酸素ができます。

  2. SiGeのエピタキシャル成長で、ゲルマニウムの原料として使われるガスはどれか。
  3. シランとともにCVDでシリコン酸化膜や酸窒化膜をつくるとき、酸化剤として使われることのあるガスはどれか。
  4. ジボランやホスフィンなどのドーパント用のガスが、多くの場合、水素や窒素などで低い濃度に薄めた状態で供給される主な理由はどれか。
  5. 高純度ガス中の微量の水分の量を表すのによく使われる指標はどれか。
