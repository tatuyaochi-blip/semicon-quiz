プロセス材料(ガス・薬液)

半導体製造で使う超純水の純度管理に使われる代表的な指標はどれか。

  1. A色の濃さ
  2. B比抵抗(抵抗率)
  3. C粘度
答えと解説を見る

正解：B. 比抵抗(抵抗率)

水に含まれるイオンが少ないほど電気が流れにくくなるため、超純水の純度は比抵抗で管理されます。理論上の上限は25 ℃で約18.2 MΩ·cmで、半導体用の超純水はこれに近い値に保たれます。このほか、TOC(全有機体炭素)、微粒子、溶存酸素なども管理します。
