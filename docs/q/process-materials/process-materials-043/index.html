プロセス材料(ガス・薬液)

ジボランやホスフィンなどのドーパント用のガスが、多くの場合、水素や窒素などで低い濃度に薄めた状態で供給される主な理由はどれか。

  1. Aガスの色を変えるため
  2. B必要な添加量はごく少なく、流量を精密に制御しやすくするとともに、毒性や反応性のリスクを下げるため
  3. Cにおいを強くするため
答えと解説を見る

正解：B. 必要な添加量はごく少なく、流量を精密に制御しやすくするとともに、毒性や反応性のリスクを下げるため

ドーパントの添加量はごく微量なので、純ガスのままでは流量が小さすぎて精密に制御できません。数%〜ppmレベルに希釈したガスを使うと、流量計で扱いやすくなり、漏えい時の危険性も下げられます。

  • A. 色を変えるためではありません。
  • B. 正しい。精密な制御と安全性のために希釈します。
  • C. においを強くするためではありません。

プロセス材料(ガス・薬液)のほかの問題

  1. 高純度ガス中の微量の水分の量を表すのによく使われる指標はどれか。
  2. 常温で液体の原料(TEOSなど)を、CVD装置にガスとして供給する方法として正しいものはどれか。
  3. 高純度ガスの配管の継手として広く使われる、金属のガスケットを面で押しつぶしてシールする方式はどれか。
  4. 熱処理炉で使う石英の部品を高温で長く使い続けたときに起こりやすい劣化はどれか。
  5. ガスの配管で、ガスが流れずにたまる行き止まりの部分(デッドスペース)を少なくする設計が求められる理由はどれか。
