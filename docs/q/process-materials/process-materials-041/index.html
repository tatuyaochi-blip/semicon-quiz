プロセス材料(ガス・薬液)

SiGeのエピタキシャル成長で、ゲルマニウムの原料として使われるガスはどれか。

  1. Aアンモニア(NH3)
  2. Bゲルマン(GeH4)
  3. Cアルシン(AsH3)
答えと解説を見る

正解：B. ゲルマン(GeH4)

SiGeの成長では、シリコンの原料(シランやジクロロシランなど)とともに、ゲルマニウムの原料としてゲルマン(GeH4)を流します。両者の流量の比でGeの組成を制御します。ゲルマンも水素化物で、毒性と可燃性があるため注意して扱います。

  • A. アンモニアは窒素の原料で、窒化膜などに使います。
  • B. 正しい。ゲルマンがゲルマニウムの原料です。
  • C. アルシンはヒ素の原料で、n型のドーパントなどに使います。

プロセス材料(ガス・薬液)のほかの問題

  1. シランとともにCVDでシリコン酸化膜や酸窒化膜をつくるとき、酸化剤として使われることのあるガスはどれか。
  2. ジボランやホスフィンなどのドーパント用のガスが、多くの場合、水素や窒素などで低い濃度に薄めた状態で供給される主な理由はどれか。
  3. 高純度ガス中の微量の水分の量を表すのによく使われる指標はどれか。
  4. 常温で液体の原料(TEOSなど)を、CVD装置にガスとして供給する方法として正しいものはどれか。
  5. 高純度ガスの配管の継手として広く使われる、金属のガスケットを面で押しつぶしてシールする方式はどれか。
