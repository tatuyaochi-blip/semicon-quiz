プロセス材料(ガス・薬液)

ガスの純度を「6N」と表したときの純度として正しいものはどれか。

  1. A99.9999%
  2. B96%
  3. C99.6%
答えと解説を見る

正解：A. 99.9999%

純度の表記で「N」は9(nine)の数を表し、6Nは9が6個並ぶ99.9999%です。不純物は合計で0.0001%、つまり1 ppm以下になります。96%や99.6%は、6という数字を末尾や途中に置いただけの誤った読み方です。99.9995%のように最後が5で終わる場合は5N5と書きます。半導体用の特殊ガスでは、6N以上の純度が求められることも多くあります。

プロセス材料(ガス・薬液)のほかの問題

  1. 半導体工場で最も大量に使われるガスの一つで、パージや雰囲気ガスとして配管で供給されるものはどれか。
  2. ArF液浸露光で、フォトレジストの上に塗り、液浸の水とレジストが直接触れないようにする膜はどれか。
  3. Low-k層間絶縁膜として使われる代表的な材料はどれか。
  4. 熱処理炉の反応管や、ウエハを載せる治具に広く使われる、高純度で耐熱性に優れた材料はどれか。
  5. フォトレジストの現像に一般的に使われる水溶液はどれか。
