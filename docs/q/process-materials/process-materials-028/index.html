プロセス材料(ガス・薬液)

酸化膜のエッチングで、C4F8のように炭素の割合が多いフルオロカーボンガスを使う理由として正しいものはどれか。

  1. Aエッチング速度を0にするため
  2. Bポリマー(保護膜)をつくりやすく、下地やマスクに対する選択比を高めやすいため
  3. Cプラズマを不要にするため
答えと解説を見る

正解：B. ポリマー(保護膜)をつくりやすく、下地やマスクに対する選択比を高めやすいため

炭素の多いフルオロカーボンガスは、プラズマ中で炭素とフッ素からなるポリマーをつくりやすくなります。酸化膜の上では、膜中の酸素がポリマーを取り除くためエッチングが進みますが、シリコンや窒化膜の上ではポリマーが堆積してエッチングが抑えられ、高い選択比が得られます。

プロセス材料(ガス・薬液)のほかの問題

  1. Cuのシード層用スパッタリングターゲットに求められる純度の目安として正しいものはどれか。
  2. 洗浄後の乾燥などに使われるIPAの化学名として正しいものはどれか。
  3. CVDなどの原料として使われるシラン(SiH4)の取り扱い上の主な危険性はどれか。
  4. 半導体用の多結晶シリコン(ポリシリコン)原料に求められる純度の目安として最も適切なものはどれか。
  5. 半導体製造で使う超純水の純度管理に使われる代表的な指標はどれか。
