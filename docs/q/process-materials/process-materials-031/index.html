プロセス材料(ガス・薬液)

半導体の製造に使われるプロセス材料の主な種類の組み合わせとして正しいものはどれか。

  1. Aウエハ、ガス、薬液、フォトレジスト、スパッタターゲット、CMPスラリーなど
  2. B木材、紙、布
  3. Cガソリン、軽油、灯油
答えと解説を見る

正解：A. ウエハ、ガス、薬液、フォトレジスト、スパッタターゲット、CMPスラリーなど

半導体の製造では、基板となるウエハのほか、成膜やエッチングに使う各種のガス、洗浄やエッチングの薬液、露光に使うフォトレジスト、スパッタのターゲット、CMPのスラリーやパッドなど、多くの高純度な材料が使われます。

  • A. 正しい。ウエハ・ガス・薬液・レジスト・ターゲット・スラリーなどです。
  • B. 木材・紙・布は半導体のプロセス材料ではありません。
  • C. 燃料はプロセス材料ではありません。

  3. 半導体の製造に使うガスや薬液に、非常に高い純度が求められる主な理由はどれか。
  4. 高純度ガスの配管に一般的に使われる材料と表面処理の組み合わせとして正しいものはどれか。
