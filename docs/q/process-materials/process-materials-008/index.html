プロセス材料(ガス・薬液)

三フッ化窒素(NF3)の主な用途はどれか。

  1. A露光装置の光源
  2. Bめっき液の主成分
  3. CCVD装置のチャンバー内に付着した膜を除去するクリーニング
答えと解説を見る

正解：C. CVD装置のチャンバー内に付着した膜を除去するクリーニング

CVDを繰り返すとチャンバーの内壁にも膜が付着し、はがれてパーティクルの原因になります。NF3をプラズマで分解してつくったフッ素ラジカルで、この付着物を揮発性のフッ化物にして取り除きます。チャンバーの外でプラズマをつくってラジカルだけを送り込むリモートプラズマ方式が主流で、部品の損傷を抑えられます。NF3の地球温暖化係数はCO2の約1万6000倍と大きいため、除害装置で分解して排出します。
