プロセス材料(ガス・薬液)

高純度ガス中の微量の水分の量を表すのによく使われる指標はどれか。

  1. ApH
  2. B比重
  3. C露点(水分が凝結し始める温度)
答えと解説を見る

正解：C. 露点(水分が凝結し始める温度)

ガス中の水分は、冷やしていったときに水分が凝結し始める温度(露点)で表されることがよくあります。露点が低いほど水分は少なく、例えば −100℃前後の露点はppbレベルの水分に相当します。水分は配管の腐食や膜の品質の低下の原因になります。

  • A. pHは液体の酸性・アルカリ性の指標です。
  • B. 比重は密度の比で、水分量の指標ではありません。
  • C. 正しい。露点で水分の量を表します。

プロセス材料(ガス・薬液)のほかの問題

  1. 常温で液体の原料(TEOSなど)を、CVD装置にガスとして供給する方法として正しいものはどれか。
  2. 高純度ガスの配管の継手として広く使われる、金属のガスケットを面で押しつぶしてシールする方式はどれか。
  3. 熱処理炉で使う石英の部品を高温で長く使い続けたときに起こりやすい劣化はどれか。
  4. ガスの配管で、ガスが流れずにたまる行き止まりの部分(デッドスペース)を少なくする設計が求められる理由はどれか。
  5. ガスのラインを開放したり、別のガスに切り替えたりする前に、不活性ガスでの加圧と排気を何度も繰り返す操作を何と呼ぶか。
