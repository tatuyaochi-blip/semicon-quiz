プロセス材料(ガス・薬液)

エピタキシャル成長や熱処理で、キャリアガスや還元性の雰囲気として使われるガスはどれか。

  1. Aオゾン
  2. B水素(H2)
  3. C塩素
答えと解説を見る

正解：B. 水素(H2)

水素は、エピタキシャル成長の原料を運ぶキャリアガスや、表面の自然酸化膜を除去する還元性の雰囲気、フォーミングガスアニールなどに使われます。可燃性で爆発の危険があるため、漏えい検知などの安全対策のもとで使用します。

この分野を解く 分野ページへ

プロセス材料(ガス・薬液)のほかの問題

  1. MOCVDの原料であるトリメチルガリウム(TMGa)などの有機金属化合物の取り扱い上の注意点として正しいものはどれか。
  2. ガスの純度を「6N」と表したときの純度として正しいものはどれか。
  3. 半導体工場で最も大量に使われるガスの一つで、パージや雰囲気ガスとして配管で供給されるものはどれか。
  4. ArF液浸露光で、フォトレジストの上に塗り、液浸の水とレジストが直接触れないようにする膜はどれか。
  5. Low-k層間絶縁膜として使われる代表的な材料はどれか。
