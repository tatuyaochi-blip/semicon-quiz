プロセス材料(ガス・薬液)

ArF液浸露光で、フォトレジストの上に塗り、液浸の水とレジストが直接触れないようにする膜はどれか。

  1. ABARC(反射防止膜)
  2. Bペリクル
  3. Cトップコート
答えと解説を見る

正解：C. トップコート

液浸露光では、レンズとウエハの間の水がレジストに触れるため、光酸発生剤などが水に溶け出してレンズを汚したり、水がしみ込んでパターンの欠陥を生んだりするおそれがあります。トップコートはレジストの上に塗る保護膜で、これを防ぎ、ステージの高速移動で水が残らないよう表面をはっ水性にします。BARCはレジストの下に敷く反射防止膜、ペリクルはマスクを守る薄い膜です。
