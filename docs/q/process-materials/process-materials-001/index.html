プロセス材料(ガス・薬液)

CVDなどの原料として使われるシラン(SiH4)の取り扱い上の主な危険性はどれか。

  1. A自然発火性があり、空気中に漏れると発火するおそれがある
  2. B不燃性で毒性もないため、特別な管理は不要である
  3. C強い放射線を出す
答えと解説を見る

正解：A. 自然発火性があり、空気中に漏れると発火するおそれがある

シランは空気に触れると自然に発火する自然発火性ガスで、高い濃度で漏れると、すぐには燃えずにたまってから爆発的に燃えることもあります。そのため、排気されたシリンダーキャビネットに収め、漏えい検知器と緊急遮断弁を備えた配管で供給します。放射線は出さず、特別な管理が不要な安全なガスでもありません。ポリシリコンやSiO2、SiNのCVDの原料として広く使われています。
