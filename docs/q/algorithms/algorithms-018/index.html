データ構造とアルゴリズム

(名前, 点数) のデータ (A, 80)、(B, 70)、(C, 80)、(D, 70) がこの順に並んでいる。点数の昇順に安定ソートで並べ替えたときの名前の順はどれか。

  1. AB, D, A, C
  2. BD, B, A, C
  3. CB, D, C, A
答えと解説を見る

正解：A. B, D, A, C

安定ソートでは、キー(ここでは点数)が同じ要素どうしは、並べ替える前の順番がそのまま保たれます。70点の B と D は元の順に B、D、80点の A と C も元の順に A、C となるので、B, D, A, C です。安定なソートにはバブルソート、挿入ソート、マージソートがあり、選択ソート、クイックソート、ヒープソートは一般に安定ではありません。安定ソートを使うと、先に名前順に並べてから点数で並べ直すといった、複数のキーでの並べ替えができます。

  • A. 正しい。同じ点数どうしでは元の順(B→D、A→C)が保たれます。
  • B. 70点どうしの B と D の順が元と逆になっています。
  • C. 80点どうしの A と C の順が元と逆になっています。

データ構造とアルゴリズムのほかの問題

  1. クイックソートの計算量が O(n²) になる典型的な場合はどれか。
  2. マージソートで、昇順に整列済みの2つの列 1, 4, 7, 9 と 2, 3, 8, 10 を、先頭どうしを比べて小さい方を出力することを繰り返して1つの列にまとめる(マージする)。片方の列が空になったら、残りは比べずにそのまま出力する。比較の回数は何回か。
  3. 二分ヒープを、根を a[0] とする配列 a[0], a[1], a[2], … に、上の段から順に左から詰めて格納する。a[4] の子と親はどれか。
  4. 親の値が子の値以上になる最大ヒープを、根を a[0] とする配列で表している。ヒープ 50, 30, 40, 10, 20, 35 に45を追加する。末尾に置いてから、親より大きい間は親と交換する操作を行った後の配列はどれか。
  5. 二分探索木を中間順(通りがけ順。左の部分木、その節、右の部分木の順に訪れる)でたどったとき、訪れた節の値はどのように並ぶか。値はすべて異なるものとする。

この分野の比較

  • 幅優先探索と深さ優先探索の違い：訪れる順・データ構造・最短経路・メモリ・用途を比較幅優先探索(BFS)と深さ優先探索(DFS)を、訪れる順・使うデータ構造・最短経路・計算量・使うメモリ・解が見つかるか・木をたどる順・主な用途の観点で表にして比較します。
  • 配列と連結リストの違い：読み出し・挿入と削除・メモリの並び・キャッシュ・計算量を比較配列と連結リストを、メモリ上の並び方・i番目の要素の読み出し・値の探索・途中への挿入と削除・末尾への追加・大きさの変更・使うメモリ・キャッシュの効きやすさ・主な用途の観点で表にして比較します。
