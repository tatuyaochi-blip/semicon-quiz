データ構造とアルゴリズム

辺に向きのないグラフで、各頂点の隣の頂点が次のとおりである。A: B, C / B: A, D, E / C: A, F / D: B / E: B, F / F: C, E。頂点 A から再帰的な深さ優先探索を行う。隣の頂点はここに書いた順に調べ、まだ訪れていない頂点が見つかったらすぐにその頂点へ進む。頂点を訪れる順はどれか。

  1. AA, B, C, D, E, F
  2. BA, B, D, E, C, F
  3. CA, B, D, E, F, C
答えと解説を見る

正解：C. A, B, D, E, F, C

A から B へ進み、B の隣で最初の未訪問の D へ進みます。D の隣は訪問済みの B だけなので B に戻って次の E へ進み、E から未訪問の F へ、F からその隣の C へと進みます。したがって A, B, D, E, F, C の順です。A, B, C, D, E, F は、出発点から近い順に訪れる幅優先探索の順です。A, B, D, E, C, F は、E から未訪問の F へ進まずに戻ってしまっており、深さ優先探索の順にはなりません。

  • A. 出発点から近い順に訪れる、幅優先探索の順です。
  • B. E の隣に未訪問の F があるので、C に戻る前に F へ進みます。
  • C. 正しい。行けるところまで進み、行き止まりになったら戻る順になっています。

データ構造とアルゴリズムのほかの問題

  1. 辺に向きのないグラフで、辺の重み(距離)が S−A: 4、S−B: 1、A−B: 2、A−C: 1、B−C: 5、C−T: 3、A−T: 6 である。ダイクストラ法で S から T までの最短経路を求めたとき、その経路と長さはどれか。
  2. ダイクストラ法で正しい最短経路が求められるための、グラフについての条件として正しいものはどれか。
  3. 作業 A〜E に「A は C より前」「B は C より前」「C は D より前」「B は E より前」「E は D より前」という順序の制約がある。すべての制約を満たす作業の順(トポロジカルソートの結果)はどれか。
  4. 関数 f(x, y) を「y が0なら x を返し、そうでなければ f(y, x mod y) を返す」と定義する。f(84, 36) を呼んだときの戻り値と、f が呼ばれる回数(最初の呼び出しを含む)の組はどれか。
  5. フィボナッチ数を求める関数 fib(n) を「n が1以下なら n を返し、そうでなければ fib(n−1) + fib(n−2) を返す」と再帰で定義した。fib(5) を呼んだとき、fib が呼ばれる回数は最初の呼び出しを含めて何回か。
