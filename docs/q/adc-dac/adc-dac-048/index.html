AD/DA変換

ΔΣ型ADコンバータの変調器の次数を上げる(例えば1次から2次にする)ことの効果として正しいものはどれか。

  1. Aサンプリング周波数を下げられる
  2. B量子化雑音をより強く高い周波数側に追いやり、同じオーバーサンプリング比で信号帯域の雑音を減らせる
  3. Cデシメーションフィルタが不要になる
答えと解説を見る

正解：B. 量子化雑音をより強く高い周波数側に追いやり、同じオーバーサンプリング比で信号帯域の雑音を減らせる

ΔΣ変調器は量子化雑音を高い周波数へ追いやる(ノイズシェーピング)働きをもち、次数を上げるほど低周波側の雑音がより強く抑えられます。そのため同じオーバーサンプリング比でも信号帯域内のSNRが上がります。ただし高次の変調器は不安定になりやすく、設計に工夫が必要です。

  • A. 次数を上げてもサンプリング周波数を下げることが直接の効果ではありません。
  • B. 正しい。ノイズシェーピングが強くなり、帯域内の雑音が減ります。
  • C. 高い周波数の雑音を取り除くためのデシメーションフィルタは引き続き必要です。

AD/DA変換のほかの問題

  1. 複数のADCを交互に動かすタイムインターリーブ型ADCで、各ADCのオフセットや利得、タイミングのずれ(ミスマッチ)によって生じる問題はどれか。
  2. 正負の両方の電圧を扱うADCで使われる「オフセットバイナリ」符号の説明として正しいものはどれか。
  3. 8ビットのADコンバータが表現できる出力の段階数はいくつか。
  4. 最高20 kHzの成分を含むアナログ信号を、折り返し雑音(エイリアシング)なくサンプリングするために必要なサンプリング周波数はどれか。
  5. フラッシュ型ADコンバータの特徴として正しいものはどれか。
