AD/DA変換

デジタルマルチメータなどによく使われる二重積分型ADコンバータの特徴として正しいものはどれか。

  1. A比較器を多数並べるため最も高速である
  2. B1回の比較で変換が終わる
  3. C変換は遅いが高精度で、積分によってノイズの影響を受けにくい
答えと解説を見る

正解：C. 変換は遅いが高精度で、積分によってノイズの影響を受けにくい

二重積分型は、入力電圧を一定時間積分し、次に基準電圧で逆向きに積分して0に戻るまでの時間を数えて変換します。部品の値の誤差が打ち消され、積分によって雑音も平均化されるため高精度です。変換に時間がかかるため、測定器など低速な用途に使われます。

AD/DA変換のほかの問題

  1. ADコンバータの微分非直線性(DNL)の説明として正しいものはどれか。
  2. 入力を変化させても、ある出力コードが一度も現れないADコンバータの不具合を何と呼ぶか。
  3. 高速なDAコンバータで多く使われる電流ステアリング型の特徴として正しいものはどれか。
  4. 実際のADコンバータの雑音やひずみを含めた性能を、理想的なADCのビット数に換算した指標はどれか。
  5. 変換を複数の段に分けて流れ作業のように処理し、高速と中〜高分解能を両立するADコンバータはどれか。
