AD/DA変換

3ビットのフラッシュ型ADコンバータに必要なコンパレータの数はいくつか。

  1. A8個
  2. B7個
  3. C3個
答えと解説を見る

正解：B. 7個

フラッシュ型ADCは入力をすべてのしきい値と同時に比べるため、Nビットでは 2ᴺ − 1 個の比較器が必要で、3ビットなら7個です。比較器の出力は「ある所までは全部1、それより上は全部0」という温度計符号になり、エンコーダで2進数に変換します。8ビットでは255個になり、入力容量や消費電力が大きくなるため、高分解能には向きません。

  • A. 8個は出力の段階の数で、境目の数は1つ少なくなります。
  • B. 正しい。2³ − 1 = 7 個です。
  • C. 3個はビット数と同じで、逐次比較のように1ビットずつ決める方式の発想です。

AD/DA変換のほかの問題

  2. ADコンバータの性能を表すSFDR(スプリアスフリーダイナミックレンジ)の説明として正しいものはどれか。
  3. Nビットの逐次比較型ADコンバータが、1回の変換で行う比較の回数として基本的に正しいものはどれか。
  4. サンプルホールド回路の「アクイジション時間」の説明として正しいものはどれか。
