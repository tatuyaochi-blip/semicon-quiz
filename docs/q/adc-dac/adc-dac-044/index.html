AD/DA変換

Nビットの逐次比較型ADコンバータが、1回の変換で行う比較の回数として基本的に正しいものはどれか。

  1. A1 回
  2. B2ᴺ 回
  3. CN 回
答えと解説を見る

正解：C. N 回

逐次比較型ADCは、最上位ビットから順に「入力は内部DACの電圧より大きいか」を比べ、1回の比較で1ビットずつ決めていきます(二分探索)。そのためNビットの変換には基本的にN回の比較が必要です。

  • A. 1回の比較ですべてのビットを決めるのは、コンパレータを多数並べたフラッシュ型の発想です。
  • B. 2ᴺ 回は、すべての段階を順に比べる方法の回数です。
  • C. 正しい。1ビットにつき1回、合計N回です。

AD/DA変換のほかの問題

  1. サンプルホールド回路の「アクイジション時間」の説明として正しいものはどれか。
  2. 中心周波数70 MHz、帯域幅10 MHzの信号を、それより低いサンプリング周波数で意図的にサンプリングして周波数変換も兼ねる手法はどれか。
  3. AD変換の前に、小さな雑音(ディザ)をわざと加える主な目的はどれか。
  4. ΔΣ型ADコンバータの変調器の次数を上げる(例えば1次から2次にする)ことの効果として正しいものはどれか。
  5. 複数のADCを交互に動かすタイムインターリーブ型ADCで、各ADCのオフセットや利得、タイミングのずれ(ミスマッチ)によって生じる問題はどれか。
