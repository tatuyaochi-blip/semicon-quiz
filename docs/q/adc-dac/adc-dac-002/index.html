AD/DA変換

最高20 kHzの成分を含むアナログ信号を、折り返し雑音(エイリアシング)なくサンプリングするために必要なサンプリング周波数はどれか。

  1. A10 kHz以上
  2. B20 kHzちょうど
  3. C40 kHzより高い周波数
答えと解説を見る

正解：C. 40 kHzより高い周波数

サンプリング定理(標本化定理)により、信号に含まれる最高周波数の2倍より高い周波数でサンプリングすれば、元の信号を復元できます。20 kHzの2倍は40 kHzです。音楽CDのサンプリング周波数44.1 kHzは、可聴域の上限約20 kHzをもとに決められています。

AD/DA変換のほかの問題

  1. フラッシュ型ADコンバータの特徴として正しいものはどれか。
  2. 逐次比較型(SAR型)ADコンバータの動作として正しいものはどれか。
  3. 理想的なADコンバータにおける量子化誤差の最大値はどれか。(LSB:最下位ビット1つ分に相当する電圧)
  4. ΔΣ(デルタシグマ)型ADコンバータの特徴として正しいものはどれか。
  5. 分解能10ビット、フルスケール入力1.024 VのADコンバータの1 LSBに相当する電圧はいくらか。
