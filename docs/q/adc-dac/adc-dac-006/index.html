AD/DA変換

ΔΣ(デルタシグマ)型ADコンバータの特徴として正しいものはどれか。

  1. Aオーバーサンプリングとノイズシェーピングにより、高い分解能を得やすい
  2. Bすべての方式の中で最も変換が高速である
  3. CNビットの変換に 2ᴺ−1 個の比較器が必要である
答えと解説を見る

正解：A. オーバーサンプリングとノイズシェーピングにより、高い分解能を得やすい

ΔΣ型は、信号帯域よりはるかに高い周波数でサンプリングし(オーバーサンプリング)、量子化ノイズを高い周波数側に追いやって(ノイズシェーピング)、デジタルフィルタで取り除きます。低い周波数で高い分解能が得られるため、オーディオや計測用途に使われます。

AD/DA変換のほかの問題

  1. 分解能10ビット、フルスケール入力1.024 VのADコンバータの1 LSBに相当する電圧はいくらか。
  2. ADコンバータの前段に置くアンチエイリアシングフィルタとして使われるフィルタの種類はどれか。
  3. R-2Rラダー型DAコンバータの特徴として正しいものはどれか。
  4. ADコンバータの前段に置くサンプルホールド回路の役割はどれか。
  5. 理想的なNビットADコンバータの、量子化雑音によって決まる信号対雑音比(SNR)の近似式はどれか。(フルスケールの正弦波入力の場合)
