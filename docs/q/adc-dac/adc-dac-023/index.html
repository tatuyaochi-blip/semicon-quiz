AD/DA変換

ADコンバータに差動入力を使う利点として正しいものはどれか。

  1. A回路が必ず単純になる
  2. B消費電力が必ず0になる
  3. C同相のノイズを打ち消しやすく、扱える信号の振幅も大きくとれる
答えと解説を見る

正解：C. 同相のノイズを打ち消しやすく、扱える信号の振幅も大きくとれる

差動入力では、2本の信号線の電圧の差を変換するため、両方に同じように乗るノイズ(同相ノイズ)が打ち消されます。また、同じ電源電圧でも単一端の入力の2倍の振幅を扱えるため、SNRを高めやすくなります。高性能なADCの多くが差動入力を採用しています。

AD/DA変換のほかの問題

  1. ΔΣ型ADコンバータで、高速で粗い量子化出力を、低いサンプリング周波数の高分解能なデータに変換するデジタル回路はどれか。
  2. DAコンバータで、入力コードが切り替わる瞬間に出力に現れる一時的なとげ状の誤差を何と呼ぶか。
  3. 複数のADコンバータを少しずつずらしたタイミングで交互に動作させ、全体として高いサンプリング速度を得る方式はどれか。
  4. 逐次比較型ADコンバータの入力の前に、オペアンプなどのドライバ回路を置く主な理由はどれか。
  5. 多くの逐次比較型ADコンバータで、内部のDACとして使われている方式はどれか。
