AD/DA変換

分解能10ビット、フルスケール入力1.024 VのADコンバータの1 LSBに相当する電圧はいくらか。

  1. A0.1 mV
  2. B1 mV
  3. C10 mV
答えと解説を見る

正解：B. 1 mV

10ビットは2¹⁰ = 1024段階なので、1 LSB = 1.024 V ÷ 1024 = 1 mV です。基準電圧を2のべき乗の値(1.024 V、2.048 V、4.096 Vなど)にすると、1 LSBがきりのよい値になり計算しやすいため、こうした基準電圧ICが市販されています。同じフルスケールで12ビットなら0.25 mVです。ただし実際の精度は、基準電圧の誤差や雑音でも決まります。

AD/DA変換のほかの問題

  1. ADコンバータの前段に置くアンチエイリアシングフィルタとして使われるフィルタの種類はどれか。
  2. R-2Rラダー型DAコンバータの特徴として正しいものはどれか。
  3. ADコンバータの前段に置くサンプルホールド回路の役割はどれか。
  4. 理想的なNビットADコンバータの、量子化雑音によって決まる信号対雑音比(SNR)の近似式はどれか。(フルスケールの正弦波入力の場合)
  5. デジタルマルチメータなどによく使われる二重積分型ADコンバータの特徴として正しいものはどれか。
