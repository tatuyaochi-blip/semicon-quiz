AD/DA変換

フラッシュ型ADコンバータの特徴として正しいものはどれか。

  1. A多数の比較器を並列に並べて一度に変換するため高速だが、分解能を上げると回路規模が急増する
  2. B1ビットずつ順に比較して変換するため、速度は遅いが回路が小さい
  3. C入力電圧を長い時間積分するため、高精度だが変換が遅い
答えと解説を見る

正解：A. 多数の比較器を並列に並べて一度に変換するため高速だが、分解能を上げると回路規模が急増する

フラッシュ型は、入力電圧を2ᴺ−1個の比較器で同時に基準電圧と比べるため、1回の比較で変換が終わり、最も高速な方式です。そのかわり、Nビットで比較器が2ᴺ−1個必要になり、分解能を上げると面積と消費電力が急に増えます。

AD/DA変換のほかの問題

  1. 逐次比較型(SAR型)ADコンバータの動作として正しいものはどれか。
  2. 理想的なADコンバータにおける量子化誤差の最大値はどれか。(LSB:最下位ビット1つ分に相当する電圧)
  3. ΔΣ(デルタシグマ)型ADコンバータの特徴として正しいものはどれか。
  4. 分解能10ビット、フルスケール入力1.024 VのADコンバータの1 LSBに相当する電圧はいくらか。
  5. ADコンバータの前段に置くアンチエイリアシングフィルタとして使われるフィルタの種類はどれか。
