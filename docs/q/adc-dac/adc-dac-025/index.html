AD/DA変換

DAコンバータで、入力コードが切り替わる瞬間に出力に現れる一時的なとげ状の誤差を何と呼ぶか。

  1. Aジッタ
  2. Bオフセット
  3. Cグリッチ
答えと解説を見る

正解：C. グリッチ

グリッチは、複数のビットが同時に切り替わるとき、各スイッチの切り替わるタイミングがわずかにずれることなどで生じる一時的な出力の乱れです。特に、多くのビットが同時に変わる中央付近のコード(例:0111…から1000…)で大きくなりやすく、高速DACの性能を左右します。

この分野を解く 分野ページへ

AD/DA変換のほかの問題

  1. 複数のADコンバータを少しずつずらしたタイミングで交互に動作させ、全体として高いサンプリング速度を得る方式はどれか。
  2. 逐次比較型ADコンバータの入力の前に、オペアンプなどのドライバ回路を置く主な理由はどれか。
  3. 多くの逐次比較型ADコンバータで、内部のDACとして使われている方式はどれか。
  4. 抵抗を直列に多数つないだ抵抗ストリング型DACの特徴として正しいものはどれか。
  5. ADコンバータの方式のうち、オーバーサンプリング型に分類されるものはどれか。
