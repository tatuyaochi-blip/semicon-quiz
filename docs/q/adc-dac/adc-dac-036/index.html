AD/DA変換

音楽CDのサンプリング周波数として正しいものはどれか。

  1. A44.1 kHz
  2. B8 kHz
  3. C1 MHz
答えと解説を見る

正解：A. 44.1 kHz

音楽CDは44.1 kHz・16ビット・2チャンネルで記録され、データ量は約1.4 Mb/sです。可聴域の上限約20 kHzの2倍を少し上回る値で、当時の業務用ビデオ機器に記録しやすい数値から決まったといわれています。16ビットのダイナミックレンジは約96 dBです。放送や映像では48 kHz、ハイレゾ音源では96 kHzや192 kHz・24ビット、電話音声では8 kHzが使われます。

  • A. 正しい。CDは44.1 kHzでサンプリングします。
  • B. 8 kHzは電話音声などで使われる値で、音楽には低すぎます。
  • C. 1 MHzはCDの規格よりはるかに高い値です。

AD/DA変換のほかの問題

  1. ADコンバータの積分非直線性(INL)の説明として正しいものはどれか。
  2. ADコンバータの利得誤差(ゲイン誤差)の説明として正しいものはどれか。
  3. DAコンバータが「単調性をもつ」とはどういう意味か。
  4. 各ビットに重みの異なる抵抗(R、2R、4R…)を割り当てる重み付け抵抗型DACの欠点として正しいものはどれか。
  5. 3ビットのフラッシュ型ADコンバータに必要なコンパレータの数はいくつか。
