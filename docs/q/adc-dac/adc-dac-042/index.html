AD/DA変換

10 kHzの正弦波を、アンチエイリアシングフィルタなしでサンプリング周波数12 kHzでサンプリングすると、何Hzの信号として現れるか。

  1. A2 kHz
  2. B10 kHz
  3. C22 kHz
答えと解説を見る

正解：A. 2 kHz

ナイキスト周波数(サンプリング周波数の半分)は6 kHzで、10 kHzはこれを超えています。このような信号は |fs − f| = |12 − 10| = 2 kHz の信号として折り返して現れます(エイリアシング)。一度折り返すと元の信号と区別できないため、サンプリングの前にフィルタで取り除く必要があります。

  • A. 正しい。12 kHz − 10 kHz = 2 kHz に折り返します。
  • B. 10 kHzはナイキスト周波数(6 kHz)を超えているため、そのままでは表せません。
  • C. 22 kHzはナイキスト周波数を超えており、サンプリング後の信号として現れません。

AD/DA変換のほかの問題

  1. ADコンバータの性能を表すSFDR(スプリアスフリーダイナミックレンジ)の説明として正しいものはどれか。
  2. Nビットの逐次比較型ADコンバータが、1回の変換で行う比較の回数として基本的に正しいものはどれか。
  3. サンプルホールド回路の「アクイジション時間」の説明として正しいものはどれか。
  4. 中心周波数70 MHz、帯域幅10 MHzの信号を、それより低いサンプリング周波数で意図的にサンプリングして周波数変換も兼ねる手法はどれか。
  5. AD変換の前に、小さな雑音(ディザ)をわざと加える主な目的はどれか。
