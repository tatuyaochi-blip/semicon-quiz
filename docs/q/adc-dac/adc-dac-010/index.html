AD/DA変換

ADコンバータの前段に置くサンプルホールド回路の役割はどれか。

  1. A入力信号を増幅する
  2. BAD変換を行っている間、入力電圧の値を一定に保持する
  3. Cクロック信号を生成する
答えと解説を見る

正解：B. AD変換を行っている間、入力電圧の値を一定に保持する

AD変換には一定の時間がかかるため、その間に入力電圧が変わると正しく変換できません。サンプルホールド回路は、ある瞬間の入力電圧をコンデンサに取り込み、変換が終わるまでその値を保持します。逐次比較型ADCなどでは欠かせない回路です。

AD/DA変換のほかの問題

  1. 理想的なNビットADコンバータの、量子化雑音によって決まる信号対雑音比(SNR)の近似式はどれか。(フルスケールの正弦波入力の場合)
  2. デジタルマルチメータなどによく使われる二重積分型ADコンバータの特徴として正しいものはどれか。
  3. ADコンバータの微分非直線性(DNL)の説明として正しいものはどれか。
  4. 入力を変化させても、ある出力コードが一度も現れないADコンバータの不具合を何と呼ぶか。
  5. 高速なDAコンバータで多く使われる電流ステアリング型の特徴として正しいものはどれか。
