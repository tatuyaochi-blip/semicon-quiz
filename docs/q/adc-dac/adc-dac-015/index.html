AD/DA変換

高速なDAコンバータで多く使われる電流ステアリング型の特徴として正しいものはどれか。

  1. A入力を長時間積分して出力をつくるため低速である
  2. Bコンデンサの電荷を少しずつ放電して出力をつくる
  3. C多数の電流源の電流の行き先をスイッチで切り替えて出力をつくるため、高速動作に向く
答えと解説を見る

正解：C. 多数の電流源の電流の行き先をスイッチで切り替えて出力をつくるため、高速動作に向く

電流ステアリング型DACは、多数の電流源を用意し、デジタル入力に応じて各電流を出力側かダミー側かに切り替えて、合計の電流で出力をつくります。電流源を止めずに行き先だけを切り替えるため高速で、通信機器などの高速DACに使われています。

AD/DA変換のほかの問題

  1. 実際のADコンバータの雑音やひずみを含めた性能を、理想的なADCのビット数に換算した指標はどれか。
  2. 変換を複数の段に分けて流れ作業のように処理し、高速と中〜高分解能を両立するADコンバータはどれか。
  3. ノイズシェーピングを行わない単純なオーバーサンプリングで、サンプリング周波数を4倍にしたときに得られる量子化雑音の改善量はどれか。
  4. 高い周波数の信号をAD変換するとき、サンプリングクロックの時間的なゆらぎ(ジッタ)が問題になる理由として正しいものはどれか。
  5. マイコンでPWM信号をローパスフィルタに通してアナログ電圧をつくる方法で、出力電圧を決めるものはどれか。
