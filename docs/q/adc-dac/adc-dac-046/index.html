AD/DA変換

中心周波数70 MHz、帯域幅10 MHzの信号を、それより低いサンプリング周波数で意図的にサンプリングして周波数変換も兼ねる手法はどれか。

  1. Aノイズシェーピング
  2. Bオーバーサンプリング
  3. Cアンダーサンプリング(バンドパスサンプリング)
答えと解説を見る

正解：C. アンダーサンプリング(バンドパスサンプリング)

帯域が限られた信号であれば、帯域幅の2倍以上のサンプリング周波数で、エイリアシングを利用して低い周波数に折り返して取り込めます。これをアンダーサンプリング(バンドパスサンプリング)といい、無線受信機でミキサーを省くなどの目的で使われます。ADCの入力帯域が信号周波数まで十分あることやジッタの小ささが必要です。

  • A. ノイズシェーピングは、量子化雑音を高い周波数側へ追いやる手法です。
  • B. オーバーサンプリングは、必要より高い周波数でサンプリングする手法です。
  • C. 正しい。折り返しを積極的に使って帯域信号を取り込みます。

AD/DA変換のほかの問題

  1. AD変換の前に、小さな雑音(ディザ)をわざと加える主な目的はどれか。
  2. ΔΣ型ADコンバータの変調器の次数を上げる(例えば1次から2次にする)ことの効果として正しいものはどれか。
  3. 複数のADCを交互に動かすタイムインターリーブ型ADCで、各ADCのオフセットや利得、タイミングのずれ(ミスマッチ)によって生じる問題はどれか。
  4. 正負の両方の電圧を扱うADCで使われる「オフセットバイナリ」符号の説明として正しいものはどれか。
  5. 8ビットのADコンバータが表現できる出力の段階数はいくつか。
