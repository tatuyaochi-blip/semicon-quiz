AD/DA変換

ADコンバータの性能を表すSFDR(スプリアスフリーダイナミックレンジ)の説明として正しいものはどれか。

  1. A入力できる最大電圧と最小電圧の比
  2. B信号の大きさと、最も大きい不要な周波数成分(スプリアス)の大きさの比
  3. Cサンプリング周波数とナイキスト周波数の比
答えと解説を見る

正解：B. 信号の大きさと、最も大きい不要な周波数成分(スプリアス)の大きさの比

SFDRは、正弦波を入力したときの出力スペクトルで、基本波と最も大きいスプリアス(高調波や不要な成分)の差をdBで表したものです。無線の受信機では、強い妨害波があるときに、そのひずみに埋もれずに弱い信号を検出できるかの目安になります。通信用の高速ADCでは70〜90 dB程度が一般的です。SNRが雑音全体を見るのに対し、SFDRは最悪の1本だけを見る指標です。

  • A. 入力範囲の比はSFDRの定義ではありません。
  • B. 正しい。信号と最大のスプリアスの比です。
  • C. 周波数の比はSFDRではありません。

AD/DA変換のほかの問題

  1. Nビットの逐次比較型ADコンバータが、1回の変換で行う比較の回数として基本的に正しいものはどれか。
  2. サンプルホールド回路の「アクイジション時間」の説明として正しいものはどれか。
  3. 中心周波数70 MHz、帯域幅10 MHzの信号を、それより低いサンプリング周波数で意図的にサンプリングして周波数変換も兼ねる手法はどれか。
  4. AD変換の前に、小さな雑音(ディザ)をわざと加える主な目的はどれか。
  5. ΔΣ型ADコンバータの変調器の次数を上げる(例えば1次から2次にする)ことの効果として正しいものはどれか。

この分野の比較

  • SAR・ΔΣ・パイプライン・フラッシュADCの違い：方式を比較フラッシュ型、SAR型、パイプライン型、ΔΣ型のADCを、仕組み・分解能・速度・遅延・消費電力・面積・用途の観点で表にして比較します。
