AD/DA変換

入力を変化させても、ある出力コードが一度も現れないADコンバータの不具合を何と呼ぶか。

  1. Aミッシングコード
  2. Bエイリアシング
  3. Cグリッチ
答えと解説を見る

正解：A. ミッシングコード

DNLが −1 LSB以下になるコードは、対応する入力の幅がなくなり、出力に現れません。これをミッシングコードといいます。制御系などでは、出力が単調に変化しないと問題になるため、ミッシングコードがないことが仕様で保証されることがあります。

AD/DA変換のほかの問題

  1. 高速なDAコンバータで多く使われる電流ステアリング型の特徴として正しいものはどれか。
  2. 実際のADコンバータの雑音やひずみを含めた性能を、理想的なADCのビット数に換算した指標はどれか。
  3. 変換を複数の段に分けて流れ作業のように処理し、高速と中〜高分解能を両立するADコンバータはどれか。
  4. ノイズシェーピングを行わない単純なオーバーサンプリングで、サンプリング周波数を4倍にしたときに得られる量子化雑音の改善量はどれか。
  5. 高い周波数の信号をAD変換するとき、サンプリングクロックの時間的なゆらぎ(ジッタ)が問題になる理由として正しいものはどれか。
