AD/DA変換

抵抗を直列に多数つないだ抵抗ストリング型DACの特徴として正しいものはどれか。

  1. A構造上、出力が入力コードに対して必ず単調に変化する
  2. B必ず最も高速である
  3. C抵抗を2種類しか使わない
答えと解説を見る

正解：A. 構造上、出力が入力コードに対して必ず単調に変化する

抵抗ストリング型は、直列につないだ抵抗の各接続点の電圧から、入力コードに対応する点をスイッチで選んで出力します。コードが1増えれば必ず隣の高い点が選ばれるため、抵抗の値がばらついても出力は必ず単調に増えます。ビット数が増えると抵抗とスイッチが2ᴺ個に増えるため、8〜10ビット程度の用途が中心で、ほかの方式と組み合わせて上位ビットを担うこともあります。

AD/DA変換のほかの問題

  1. ADコンバータの方式のうち、オーバーサンプリング型に分類されるものはどれか。
  2. ADコンバータ(ADC)の働きとして正しいものはどれか。
  3. DAコンバータ(DAC)が使われる例として最も適切なものはどれか。
  4. 入力範囲が同じADコンバータで、分解能(ビット数)を大きくするとどうなるか。
  5. AD変換における「サンプリング(標本化)」の説明として正しいものはどれか。
