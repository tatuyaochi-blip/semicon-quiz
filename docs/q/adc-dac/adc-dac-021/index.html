AD/DA変換

ADコンバータの変換速度を表す「MS/s(MSPS)」の意味として正しいものはどれか。

  1. Aメガシーメンス毎秒
  2. B1秒間に何百万回サンプリング(変換)できるか
  3. C1回の変換にかかるミリ秒数
答えと解説を見る

正解：B. 1秒間に何百万回サンプリング(変換)できるか

MS/sはMega Samples per secondの略で、1秒間に何百万回サンプリングして変換できるかを表します。例えば100 MS/sのADCは、1秒間に1億回変換できます。サンプリング定理から、扱える信号の周波数の上限はその半分になります。

AD/DA変換のほかの問題

  1. ADコンバータの入出力特性で、入力が0のときに出力が0からずれている誤差を何と呼ぶか。
  2. ADコンバータに差動入力を使う利点として正しいものはどれか。
  3. ΔΣ型ADコンバータで、高速で粗い量子化出力を、低いサンプリング周波数の高分解能なデータに変換するデジタル回路はどれか。
  4. DAコンバータで、入力コードが切り替わる瞬間に出力に現れる一時的なとげ状の誤差を何と呼ぶか。
  5. 複数のADコンバータを少しずつずらしたタイミングで交互に動作させ、全体として高いサンプリング速度を得る方式はどれか。
