AD/DA変換

理想的なNビットADコンバータの、量子化雑音によって決まる信号対雑音比(SNR)の近似式はどれか。(フルスケールの正弦波入力の場合)

  1. A6.02N + 1.76 dB
  2. B3N dB
  3. C20N dB
答えと解説を見る

正解：A. 6.02N + 1.76 dB

理想的なADCでは、SNR ≈ 6.02N + 1.76 dB となり、1ビット増えるごとに約6 dB改善します。例えば12ビットなら約74 dBです。実際のADCでは、熱雑音やひずみなどにより、この値より低くなります。

AD/DA変換のほかの問題

  1. デジタルマルチメータなどによく使われる二重積分型ADコンバータの特徴として正しいものはどれか。
  2. ADコンバータの微分非直線性(DNL)の説明として正しいものはどれか。
  3. 入力を変化させても、ある出力コードが一度も現れないADコンバータの不具合を何と呼ぶか。
  4. 高速なDAコンバータで多く使われる電流ステアリング型の特徴として正しいものはどれか。
  5. 実際のADコンバータの雑音やひずみを含めた性能を、理想的なADCのビット数に換算した指標はどれか。
