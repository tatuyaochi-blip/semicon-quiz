AD/DA変換

DAコンバータ(DAC)が使われる例として最も適切なものはどれか。

  1. A温度センサーの電圧を読み取ってマイコンに取り込む
  2. Bデジタル音声データをスピーカーで鳴らすためのアナログ信号にする
  3. Cカメラのイメージセンサーの画素の電圧を数値にする
答えと解説を見る

正解：B. デジタル音声データをスピーカーで鳴らすためのアナログ信号にする

DACはデジタル値をアナログ電圧や電流に変換します。デジタル音声データを、アンプとスピーカーで鳴らせるアナログ信号に戻すのが代表的な用途です。センサーの電圧を数値にするのはADCの役割です。

  • A. センサーの電圧を数値に変えるのはADCの役割です。
  • B. 正しい。デジタル音声をアナログ信号に変換するのはDACです。
  • C. 画素の電圧を数値に変えるのはADCの役割です。

AD/DA変換のほかの問題

  1. 入力範囲が同じADコンバータで、分解能(ビット数)を大きくするとどうなるか。
  2. AD変換における「サンプリング(標本化)」の説明として正しいものはどれか。
  3. AD変換における「量子化」によって生じる誤差を何と呼ぶか。
  4. 音楽CDのサンプリング周波数として正しいものはどれか。
  5. ADコンバータの積分非直線性(INL)の説明として正しいものはどれか。
