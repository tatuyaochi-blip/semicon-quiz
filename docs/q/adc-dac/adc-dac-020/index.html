AD/DA変換

マイコンでPWM信号をローパスフィルタに通してアナログ電圧をつくる方法で、出力電圧を決めるものはどれか。

  1. Aパルスのデューティ比(1周期のうちオンの時間の割合)
  2. Bパルスの色
  3. Cマイコンのメモリ容量
答えと解説を見る

正解：A. パルスのデューティ比(1周期のうちオンの時間の割合)

PWM信号をローパスフィルタで平均化すると、出力電圧は「振幅 × デューティ比」になります。例えば5 Vのパルスでデューティ比が40%なら約2 Vです。専用のDACがなくても簡単にアナログ電圧をつくれますが、リプルが残るため精度や速度は限られます。

AD/DA変換のほかの問題

  1. ADコンバータの変換速度を表す「MS/s(MSPS)」の意味として正しいものはどれか。
  2. ADコンバータの入出力特性で、入力が0のときに出力が0からずれている誤差を何と呼ぶか。
  3. ADコンバータに差動入力を使う利点として正しいものはどれか。
  4. ΔΣ型ADコンバータで、高速で粗い量子化出力を、低いサンプリング周波数の高分解能なデータに変換するデジタル回路はどれか。
  5. DAコンバータで、入力コードが切り替わる瞬間に出力に現れる一時的なとげ状の誤差を何と呼ぶか。
