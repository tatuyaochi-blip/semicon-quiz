AD/DA変換

8ビットのADコンバータが表現できる出力の段階数はいくつか。

  1. A8段階
  2. B256段階
  3. C1024段階
答えと解説を見る

正解：B. 256段階

Nビットのコンバータは2のN乗の段階を表現できます。8ビットなら2⁸ = 256段階です。1024段階は10ビットに相当します。ビット数が1つ増えるごとに段階数は2倍になり、細かい電圧の違いを区別できるようになります。

AD/DA変換のほかの問題

  1. 最高20 kHzの成分を含むアナログ信号を、折り返し雑音(エイリアシング)なくサンプリングするために必要なサンプリング周波数はどれか。
  2. フラッシュ型ADコンバータの特徴として正しいものはどれか。
  3. 逐次比較型(SAR型)ADコンバータの動作として正しいものはどれか。
  4. 理想的なADコンバータにおける量子化誤差の最大値はどれか。(LSB:最下位ビット1つ分に相当する電圧)
  5. ΔΣ(デルタシグマ)型ADコンバータの特徴として正しいものはどれか。
