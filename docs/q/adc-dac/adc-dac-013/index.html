AD/DA変換

ADコンバータの微分非直線性(DNL)の説明として正しいものはどれか。

  1. A入出力特性全体の傾き(利得)の誤差
  2. B隣り合うコード間の幅(ステップ幅)の、理想的な1 LSBからのずれ
  3. C入力が0のときの出力のずれ
答えと解説を見る

正解：B. 隣り合うコード間の幅(ステップ幅)の、理想的な1 LSBからのずれ

DNLは、各出力コードに対応する入力電圧の幅が、理想の1 LSBからどれだけずれているかを表します。入出力特性全体の理想直線からのずれは積分非直線性(INL)、入力0での出力のずれはオフセット誤差と呼びます。

この分野を解く 分野ページへ

AD/DA変換のほかの問題

  1. 入力を変化させても、ある出力コードが一度も現れないADコンバータの不具合を何と呼ぶか。
  2. 高速なDAコンバータで多く使われる電流ステアリング型の特徴として正しいものはどれか。
  3. 実際のADコンバータの雑音やひずみを含めた性能を、理想的なADCのビット数に換算した指標はどれか。
  4. 変換を複数の段に分けて流れ作業のように処理し、高速と中〜高分解能を両立するADコンバータはどれか。
  5. ノイズシェーピングを行わない単純なオーバーサンプリングで、サンプリング周波数を4倍にしたときに得られる量子化雑音の改善量はどれか。
