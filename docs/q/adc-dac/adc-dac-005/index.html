AD/DA変換

理想的なADコンバータにおける量子化誤差の最大値はどれか。(LSB:最下位ビット1つ分に相当する電圧)

  1. A±2 LSB
  2. B±1 LSB
  3. C±1/2 LSB
答えと解説を見る

正解：C. ±1/2 LSB

連続したアナログ値を一定の幅(1 LSB)の段階に丸めるため、変換には必ず誤差が生じます。これが量子化誤差で、理想的なADCでは最大±1/2 LSBです。ビット数を増やすと1 LSBが小さくなり、量子化誤差も小さくなります。

  3. ADコンバータの前段に置くアンチエイリアシングフィルタとして使われるフィルタの種類はどれか。
  4. R-2Rラダー型DAコンバータの特徴として正しいものはどれか。
  5. ADコンバータの前段に置くサンプルホールド回路の役割はどれか。
