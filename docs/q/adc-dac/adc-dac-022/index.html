AD/DA変換

ADコンバータの入出力特性で、入力が0のときに出力が0からずれている誤差を何と呼ぶか。

  1. Aオフセット誤差
  2. Bゲイン誤差
  3. C微分非直線性
答えと解説を見る

正解：A. オフセット誤差

オフセット誤差は、入出力特性全体が平行にずれている誤差で、入力0での出力のずれとして現れます。傾きの誤差はゲイン誤差といいます。どちらも、多くの場合は校正によって補正できます。

AD/DA変換のほかの問題

  1. ADコンバータに差動入力を使う利点として正しいものはどれか。
  2. ΔΣ型ADコンバータで、高速で粗い量子化出力を、低いサンプリング周波数の高分解能なデータに変換するデジタル回路はどれか。
  3. DAコンバータで、入力コードが切り替わる瞬間に出力に現れる一時的なとげ状の誤差を何と呼ぶか。
  4. 複数のADコンバータを少しずつずらしたタイミングで交互に動作させ、全体として高いサンプリング速度を得る方式はどれか。
  5. 逐次比較型ADコンバータの入力の前に、オペアンプなどのドライバ回路を置く主な理由はどれか。
