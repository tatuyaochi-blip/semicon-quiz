インターフェース・バス規格

CXL(Compute Express Link)の説明として正しいものはどれか。

  1. Aチップレットどうしをパッケージの中でつなぐための規格
  2. BPCI Expressの物理層を使い、CPUとアクセラレータやメモリ装置の間で、キャッシュの一貫性を保ったメモリの共有を可能にする規格
  3. C無線LANの新しい規格
答えと解説を見る

正解：B. PCI Expressの物理層を使い、CPUとアクセラレータやメモリ装置の間で、キャッシュの一貫性を保ったメモリの共有を可能にする規格

PCI Expressでは、機器のメモリとCPUのキャッシュの一貫性はハードウェアでは保たれず、ソフトウェアが気を配る必要がありました。CXLは、PCI Expressと同じ物理層の上で、キャッシュの一貫性を保つ通信と、CPUから機器のメモリを普通のメモリのように読み書きする通信を加えた規格です。アクセラレータとのデータの共有や、メモリの増設に使われます。

  • A. それはUCIeなどです。
  • B. 正しい。PCI Expressと同じ端子で使えます。
  • C. 無線LANとは関係ありません。

インターフェース・バス規格のほかの問題

  1. CXLを使ったメモリの拡張(CXLメモリ)の利点として正しいものはどれか。
  2. CXLを構成する3つのプロトコルの組み合わせとして正しいものはどれか。
  3. 高速なシリアル伝送の受信回路で使われるイコライザ(CTLEやDFEなど)の役割として正しいものはどれか。
  4. 高速なシリアル信号の品質を見るアイパターン(アイダイアグラム)について正しいものはどれか。
  5. シリアル伝送の速度を上げるほど、同じ長さの基板の配線で信号を送るのが難しくなり、途中にリタイマなどを入れることがある。その主な理由はどれか。
