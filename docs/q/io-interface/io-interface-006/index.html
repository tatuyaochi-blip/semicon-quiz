インターフェース・バス規格

8b/10b符号化を使う伝送路の信号の速度が5 Gb/sのとき、データとして送れる実効的な速度はいくらか。

  1. A4 Gb/s
  2. B5 Gb/s
  3. C6.25 Gb/s
答えと解説を見る

正解：A. 4 Gb/s

8b/10b符号化では、10ビットを送るうちデータは8ビットなので、実効的な速度は信号の速度の8/10です。5 Gb/s×0.8=4 Gb/sになります。これはPCI Express 2.0の1レーンの片方向の速さで、バイトに直すと500 MB/sです。インターフェースの速度を比べるときは、信号の速度(GT/sなど)と符号化の効率を分けて考える必要があります。

  • A. 正しい。5×8/10=4です。
  • B. 符号化で増えたビットの分を引く必要があります。
  • C. これは5に10/8を掛けた値で、逆です。

インターフェース・バス規格のほかの問題

  1. PCI Express 3.0以降で採用された128b/130b符号化の効率に最も近いものはどれか。
  2. PCI Expressの「レーン」の説明として正しいものはどれか。
  3. PCI Express 3.0(1レーンあたり8 GT/s、128b/130b符号化)のx16接続の、片方向の実効的な帯域に最も近いものはどれか。
  4. PCI Expressの世代が1つ進むごとの、1レーンあたりの信号の速度の変化として、第3世代から第6世代について正しいものはどれか。
  5. PCI Express 6.0で採用されたPAM4(4値パルス振幅変調)の特徴として正しいものはどれか。
