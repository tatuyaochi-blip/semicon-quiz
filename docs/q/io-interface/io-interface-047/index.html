インターフェース・バス規格

AI向けのGPUを多数つなぐシステムで、PCI Expressとは別の、GPUどうしを結ぶ専用の高速な接続(NVIDIAのNVLinkなど)が使われる主な理由はどれか。

  1. APCI Expressでは、GPUを1つもつなげないから
  2. B専用の接続を使うと、GPUのメモリが不要になるから
  3. C大きなモデルの学習ではGPUどうしで大量のデータを交換するので、PCI Expressより大きな帯域が必要だから
答えと解説を見る

正解：C. 大きなモデルの学習ではGPUどうしで大量のデータを交換するので、PCI Expressより大きな帯域が必要だから

大きなAIモデルを複数のGPUで学習すると、計算の途中で勾配やパラメータ、途中の結果をGPUどうしで頻繁にやり取りします。この通信が遅いと、GPUは計算を止めて待つことになります。GPUどうしを結ぶ専用の接続は、多数の高速なSerDesのレーンを束ね、PCI Expressより何倍も大きな帯域で直接データを交換できるようにしています。

  • A. GPUは普通PCI Expressでつながっています。
  • B. GPUのメモリは引き続き必要です。
  • C. 正しい。GPUの間の通信が性能の制約になりやすいからです。

インターフェース・バス規格のほかの問題

  1. PCI Expressで、64バイトの小さなデータを書き込むパケットを多数送ると、実効的な帯域が理論値よりかなり小さくなる。その主な理由はどれか。
  2. ネットワークカードやNVMeのSSDなどで広く使われる、メモリ上の記述子(ディスクリプタ)の輪(リング)を使ったDMAのしくみについて正しいものはどれか。
  3. PCI Expressのリンクの省電力の機能(ASPMによるL0sやL1の状態)について正しいものはどれか。
  4. チップやボードの間の高速な接続が、多数の線を並べる並列伝送から、少ない線に速い信号を流すシリアル伝送に移ってきた主な理由はどれか。
  5. 高速なシリアル伝送で使われるSerDes(シリアライザ/デシリアライザ)の役割として正しいものはどれか。

この分野の比較

  • NVMeとSATAのSSDの違い：速度・インターフェース・選び方NVMeとSATAのSSDを、インターフェース・速度・遅延・コマンドキュー・形状・消費電力・互換性・価格・向いている人の観点で表にして比較します。
  • DMAとプログラムI/Oの違い：データ転送の方法を比較DMAとプログラムI/O(PIO)を、データを動かす主体・CPUの負荷・スループット・準備のコスト・複雑さ・バスの使用・用途の観点で表にして比較します。
  • PCIe 3.0・4.0・5.0・6.0の違い：速度と世代ごとの特徴を比較PCIe 3.0、4.0、5.0、6.0を、転送レート・レーンあたりと×4、×16のリンクの帯域・エンコード・信号方式・使われる機器の観点で表にして比較します。
