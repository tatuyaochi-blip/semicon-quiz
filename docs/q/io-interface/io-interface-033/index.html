インターフェース・バス規格

AXI4-Streamの特徴として正しいものはどれか。

  1. Aメモリの番地を指定して、ランダムに読み書きするための規格である
  2. Bアドレスを持たず、データを一方向に流し続けるための規格で、映像や信号処理のパイプラインに向く
  3. Cチップの外のディスプレイにつなぐためのコネクタの規格である
答えと解説を見る

正解：B. アドレスを持たず、データを一方向に流し続けるための規格で、映像や信号処理のパイプラインに向く

映像のフィルタや通信の信号処理のように、データが処理の段から段へ順に流れていく回路では、番地は必要ありません。AXI4-Streamは、データとVALID・READYの手順だけを持ち、パケットの終わりを示す信号などを付けて、一方向に流し続けられるようにした規格です。FPGAの設計でも、処理のブロックをつなぐのによく使われます。

  • A. 番地を使うのはAXIやAXI4-Liteです。
  • B. 正しい。VALIDとREADYでデータだけを受け渡します。
  • C. チップの中の規格です。

  5. 高速なシリアル伝送の受信回路で使われるイコライザ(CTLEやDFEなど)の役割として正しいものはどれか。
