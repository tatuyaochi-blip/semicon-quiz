インターフェース・バス規格

PCI Expressのリンクの省電力の機能(ASPMによるL0sやL1の状態)について正しいものはどれか。

  1. Aデータを送らない間はリンクを低い電力の状態にするが、元の状態に戻るまでに時間がかかり、遅延が増えることがある
  2. Bリンクの速度を上げて、消費電力を増やす機能である
  3. C省電力の状態でも、データの送受信の速さはまったく変わらない
答えと解説を見る

正解：A. データを送らない間はリンクを低い電力の状態にするが、元の状態に戻るまでに時間がかかり、遅延が増えることがある

SerDesは、データを送っていない間も信号を保つために電力を使います。ASPMでは、しばらくやり取りがないとリンクをL0sやL1という低い電力の状態にし、送受信の回路の一部を止めます。L1の方が電力は小さくなりますが、元に戻るまでの時間が長くなります。ノートパソコンでは電池の持ちのために使い、遅延を重視するサーバでは切っておくこともあります。

  • A. 正しい。電力と応答の速さの釣り合いを考えて設定します。
  • B. 省電力のための機能です。
  • C. 戻るまでの時間の分、最初の転送が遅れます。
