インターフェース・バス規格

PCI Expressの1レーンが「全二重」であることの意味として正しいものはどれか。

  1. A送信と受信を同時に行える
  2. B送信と受信を交互に切り替えて行う
  3. C送信しかできず、受信はできない
答えと解説を見る

正解：A. 送信と受信を同時に行える

全二重は、両方向に同時にデータを流せる方式です。PCI Expressの1レーンは送信用と受信用の差動ペアを別々に持つので、例えばGPUへデータを送りながら、同時にGPUから結果を受け取れます。そのため帯域を示すときは、片方向の値か両方向の合計かをはっきりさせる必要があります。1組の線を交互に使う方式は半二重と呼ばれます。

  • A. 正しい。送受信で別々の差動ペアを使います。
  • B. それは半二重です。
  • C. 受信もできます。

インターフェース・バス規格のほかの問題

  1. PCI Expressで使われるクレジット方式のフロー制御の説明として正しいものはどれか。
  2. AI向けのGPUを多数つなぐシステムで、PCI Expressとは別の、GPUどうしを結ぶ専用の高速な接続(NVIDIAのNVLinkなど)が使われる主な理由はどれか。
  3. PCI Expressで、64バイトの小さなデータを書き込むパケットを多数送ると、実効的な帯域が理論値よりかなり小さくなる。その主な理由はどれか。
  4. ネットワークカードやNVMeのSSDなどで広く使われる、メモリ上の記述子(ディスクリプタ)の輪(リング)を使ったDMAのしくみについて正しいものはどれか。
  5. PCI Expressのリンクの省電力の機能(ASPMによるL0sやL1の状態)について正しいものはどれか。
