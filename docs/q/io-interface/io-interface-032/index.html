インターフェース・バス規格

AXIの種類のうち、AXI4-Liteが主に使われる用途はどれか。

  1. A周辺回路の設定用レジスタの読み書きのように、少ない量のデータを単純にやり取りする用途
  2. BGPUとHBMの間の大量のデータの転送
  3. Cチップの外の機器とケーブルでつなぐ用途
答えと解説を見る

正解：A. 周辺回路の設定用レジスタの読み書きのように、少ない量のデータを単純にやり取りする用途

AXI4-Liteは、バースト転送や複数の未完了の要求などの機能を省き、1回に1つのデータを読み書きするだけにした簡単な版です。回路が小さく作りやすいので、タイマーや通信回路などの設定用レジスタをCPUからつなぐのに使われます。速さが必要な大量のデータの転送には、フルのAXIや、アドレスを持たないAXI4-Streamを使い分けます。

  • A. 正しい。バースト転送を持たない簡単な版です。
  • B. 大量の転送には、バーストを持つフルのAXIなどを使います。
  • C. チップの中のバスです。
