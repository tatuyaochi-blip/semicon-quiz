インターフェース・バス規格

シリアル伝送で8b/10b符号化(8ビットのデータを10ビットの符号にして送る方式)が使われてきた目的として正しいものはどれか。

  1. Aデータを圧縮して、送る量を減らす
  2. B0と1の数の偏りをなくし、十分な頻度で信号が切り替わるようにして、受信側がクロックを取り出せるようにする
  3. Cデータを暗号化して、第三者が読めないようにする
答えと解説を見る

正解：B. 0と1の数の偏りをなくし、十分な頻度で信号が切り替わるようにして、受信側がクロックを取り出せるようにする

0や1が長く続くと、受信側のCDRがタイミングを見失い、また信号の平均電圧がずれて正しく判定できなくなります。8b/10b符号化は、8ビットのデータを、0と1の数がほぼ等しく連続が短い10ビットの符号に置き換えます。代わりに送るビットが25%増えるので、データとしての効率は80%になります。PCI Expressの第1・第2世代やUSB 3.0などで使われました。

  • A. むしろ送る量は25%増えます。
  • B. 正しい。DCバランスと切り替わりの確保が目的です。
  • C. 暗号化はしません。

インターフェース・バス規格のほかの問題

  1. 8b/10b符号化を使う伝送路の信号の速度が5 Gb/sのとき、データとして送れる実効的な速度はいくらか。
  2. PCI Express 3.0以降で採用された128b/130b符号化の効率に最も近いものはどれか。
  3. PCI Expressの「レーン」の説明として正しいものはどれか。
  4. PCI Express 3.0(1レーンあたり8 GT/s、128b/130b符号化)のx16接続の、片方向の実効的な帯域に最も近いものはどれか。
  5. PCI Expressの世代が1つ進むごとの、1レーンあたりの信号の速度の変化として、第3世代から第6世代について正しいものはどれか。

  • DMAとプログラムI/Oの違い：データ転送の方法を比較DMAとプログラムI/O(PIO)を、データを動かす主体・CPUの負荷・スループット・準備のコスト・複雑さ・バスの使用・用途の観点で表にして比較します。
