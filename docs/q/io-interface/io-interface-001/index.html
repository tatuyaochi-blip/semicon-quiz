インターフェース・バス規格

チップやボードの間の高速な接続が、多数の線を並べる並列伝送から、少ない線に速い信号を流すシリアル伝送に移ってきた主な理由はどれか。

  1. A並列伝送では線ごとの到着時間のずれ(スキュー)が問題になり、速度を上げにくいから
  2. Bシリアル伝送では電気を使わないので、消費電力が0になるから
  3. C並列伝送は法律で禁止されたから
答えと解説を見る

正解：A. 並列伝送では線ごとの到着時間のずれ(スキュー)が問題になり、速度を上げにくいから

並列伝送では、多数の線のビットを同じクロックでそろえて受け取る必要があります。速度が上がると、配線の長さのわずかな差による到着時間のずれ(スキュー)がクロックの周期に対して無視できなくなり、それ以上速くできません。シリアル伝送では1組の線ごとにクロックをデータから取り出すのでスキューの問題がなく、線あたりの速度を大きく上げられます。端子や配線の数も減らせます。

  • A. 正しい。線を減らすと配線や端子も減らせます。
  • B. シリアル伝送も電気信号で、電力を使います。
  • C. 禁止されたわけではありません。

インターフェース・バス規格のほかの問題

  1. 高速なシリアル伝送で使われるSerDes(シリアライザ/デシリアライザ)の役割として正しいものはどれか。
  2. 高速なシリアル伝送で、2本の線に逆向きの信号を流す差動信号が使われる主な理由はどれか。
  3. 高速なシリアル伝送の受信側にあるクロック・データ・リカバリ(CDR)回路の役割として正しいものはどれか。
  4. シリアル伝送で8b/10b符号化(8ビットのデータを10ビットの符号にして送る方式)が使われてきた目的として正しいものはどれか。
  5. 8b/10b符号化を使う伝送路の信号の速度が5 Gb/sのとき、データとして送れる実効的な速度はいくらか。
