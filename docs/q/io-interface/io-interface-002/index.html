インターフェース・バス規格

高速なシリアル伝送で使われるSerDes(シリアライザ/デシリアライザ)の役割として正しいものはどれか。

  1. Aデータを暗号化して、盗み見を防ぐ
  2. B送る側でチップ内の並列のデータを1本の速いビット列に変え、受ける側で元の並列のデータに戻す
  3. C電源の電圧を、ほかの回路に合わせて変換する
答えと解説を見る

正解：B. 送る側でチップ内の並列のデータを1本の速いビット列に変え、受ける側で元の並列のデータに戻す

チップの内部では、データは数十ビットの幅でゆっくり動いています。SerDesの送信側はこれを1本の非常に速いビット列に並べ替えて送り出し、受信側はビット列からクロックを取り出してビットを判定し、元の幅のデータに戻します。PCI Express、USB、イーサネット、ストレージの接続など、多くの高速なインターフェースの物理層はSerDesで作られています。

  • A. 暗号化の回路ではありません。
  • B. 正しい。シリアル伝送の送受信の中心となる回路です。
  • C. 電源の変換とは関係ありません。

インターフェース・バス規格のほかの問題

  1. 高速なシリアル伝送で、2本の線に逆向きの信号を流す差動信号が使われる主な理由はどれか。
  2. 高速なシリアル伝送の受信側にあるクロック・データ・リカバリ(CDR)回路の役割として正しいものはどれか。
  3. シリアル伝送で8b/10b符号化(8ビットのデータを10ビットの符号にして送る方式)が使われてきた目的として正しいものはどれか。
  4. 8b/10b符号化を使う伝送路の信号の速度が5 Gb/sのとき、データとして送れる実効的な速度はいくらか。
  5. PCI Express 3.0以降で採用された128b/130b符号化の効率に最も近いものはどれか。
