インターフェース・バス規格

USB Power Delivery(USB PD)の説明として正しいものはどれか。

  1. A給電する側と受ける側が通信して電圧と電流を取り決め、5 Vより高い電圧で大きな電力を送れるようにする
  2. BUSBのデータ通信を、電力線を通して行う
  3. Cどの機器にも常に20 Vを加えて充電を速くする
答えと解説を見る

正解：A. 給電する側と受ける側が通信して電圧と電流を取り決め、5 Vより高い電圧で大きな電力を送れるようにする

USBの基本の給電は5 Vで、送れる電力は小さいものでした。USB PDでは、つないだ後に両側がCC線で通信し、受ける側が対応できる電圧と電流を取り決めてから電圧を上げます。ノートパソコンの充電などに使われ、規格の拡張で最大48 V・5 A(240 W)まで送れるようになりました。取り決めが済むまでは安全な5 Vのままです。

  • A. 正しい。最新の規格では48 V・240 Wまで扱えます。
  • B. 電力線通信の規格ではありません。
  • C. 取り決めなしに高い電圧を加えると機器が壊れます。

インターフェース・バス規格のほかの問題

  1. USBの転送の種類のうち、アイソクロナス転送の特徴として正しいものはどれか。
  2. USBやPCI Expressの一部で使える「ホットプラグ」の説明として正しいものはどれか。
  3. SoCの内部で、CPUやメモリコントローラ、周辺回路などのブロックをつなぐのに広く使われている、ArmのAMBA規格のバスはどれか。
  4. AXIバスの特徴として正しいものはどれか。
  5. AXIの各チャネルで使われるVALIDとREADYによる受け渡し(ハンドシェイク)で、データが受け渡されるのはどのときか。
