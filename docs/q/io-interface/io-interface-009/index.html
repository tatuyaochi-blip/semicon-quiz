インターフェース・バス規格

PCI Express 3.0(1レーンあたり8 GT/s、128b/130b符号化)のx16接続の、片方向の実効的な帯域に最も近いものはどれか。

  1. A約128 GB/s
  2. B約1 GB/s
  3. C約16 GB/s
答えと解説を見る

正解：C. 約16 GB/s

1レーンの実効的な速度は8 Gb/s×128/130≒7.88 Gb/sで、8で割ると約0.985 GB/sです。16レーンなら約15.8 GB/s、つまり約16 GB/sが片方向の帯域になり、送受信を合わせると約32 GB/sです。PCI Expressの帯域は、世代(1レーンの速度)、符号化の効率、レーン数の掛け算で求められます。実際にはパケットの見出しなどのむだがあり、もう少し小さくなります。

  • A. ビットをバイトに直していません。
  • B. これは1レーン分の帯域です。
  • C. 正しい。1レーン約0.985 GB/sの16倍です。

インターフェース・バス規格のほかの問題

  1. PCI Expressの世代が1つ進むごとの、1レーンあたりの信号の速度の変化として、第3世代から第6世代について正しいものはどれか。
  2. PCI Express 6.0で採用されたPAM4(4値パルス振幅変調)の特徴として正しいものはどれか。
  3. PAM4を使うと、NRZに比べて誤り訂正(FEC)がより重要になる理由として正しいものはどれか。
  4. x4のPCI ExpressのSSDを、マザーボードのx16の長さのスロットに差し込むとどうなるか(スロットがx4以上の配線を持つとする)。
  5. PCI Expressの構成について正しいものはどれか。
