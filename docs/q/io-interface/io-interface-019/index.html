インターフェース・バス規格

インターフェースの性能を表す「帯域」と「遅延(レイテンシ)」の違いとして正しいものはどれか。

  1. A帯域と遅延は同じものを別の単位で表しただけである
  2. B帯域が大きければ、遅延は必ず小さくなる
  3. C帯域は単位時間に送れるデータの量で、遅延は1つのデータが届くまでにかかる時間である
答えと解説を見る

正解：C. 帯域は単位時間に送れるデータの量で、遅延は1つのデータが届くまでにかかる時間である

帯域は道路の車線の数、遅延は目的地までの所要時間にたとえられます。車線を増やせば一度に多くの車を通せますが、1台が着くまでの時間は短くなりません。大きなデータを送るときは帯域が、小さなデータを何度もやり取りするときは遅延が性能を決めます。どちらが効いているかを見極めることが、性能の改善の第一歩です。

  • A. 別の量です。
  • B. 帯域が大きくても遅延が大きい接続はあります。
  • C. 正しい。別の量なので分けて考えます。

インターフェース・バス規格のほかの問題

  1. 帯域10 GB/s、遅延1 µsの接続で、64バイトのデータを1回送るのにかかる時間に最も近いものはどれか(時間=遅延+データ量÷帯域とする)。
  2. 機器との間で小さなデータを1つずつ何千回もやり取りするプログラムを速くする方法として、最も効果的なものはどれか。
  3. USBの通信のしくみについて正しいものはどれか(USB4を除く従来のUSBについて)。
  4. USB Type-Cについて正しいものはどれか。
  5. USB Power Delivery(USB PD)の説明として正しいものはどれか。

この分野の比較

  • NVMeとSATAのSSDの違い：速度・インターフェース・選び方NVMeとSATAのSSDを、インターフェース・速度・遅延・コマンドキュー・形状・消費電力・互換性・価格・向いている人の観点で表にして比較します。
  • DMAとプログラムI/Oの違い：データ転送の方法を比較DMAとプログラムI/O(PIO)を、データを動かす主体・CPUの負荷・スループット・準備のコスト・複雑さ・バスの使用・用途の観点で表にして比較します。
  • PCIe 3.0・4.0・5.0・6.0の違い：速度と世代ごとの特徴を比較PCIe 3.0、4.0、5.0、6.0を、転送レート・レーンあたりと×4、×16のリンクの帯域・エンコード・信号方式・使われる機器の観点で表にして比較します。
