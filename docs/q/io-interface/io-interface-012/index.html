インターフェース・バス規格

PAM4を使うと、NRZに比べて誤り訂正(FEC)がより重要になる理由として正しいものはどれか。

  1. APAM4ではクロックを取り出せないので、誤りが毎回起きるから
  2. B同じ振幅の中に4段階を入れるので段階の間隔が約1/3になり、雑音でビットを誤りやすくなるから
  3. CPAM4の信号は暗号化されているので、復号の誤りを直す必要があるから
答えと解説を見る

正解：B. 同じ振幅の中に4段階を入れるので段階の間隔が約1/3になり、雑音でビットを誤りやすくなるから

電圧の振れ幅が同じなら、2段階のNRZでは0と1の間に振れ幅いっぱいの間隔がありますが、4段階のPAM4では隣の段階との間隔が約1/3になります。雑音の余裕がおよそ9.5 dB小さくなるので、ビットの誤りが起こりやすくなります。そこでPCI Express 6.0では、軽い誤り訂正の符号を加え、受信側で小さな誤りを直してから使います。

  • A. PAM4でもクロックは取り出せます。
  • B. 正しい。雑音の余裕が小さくなります。
  • C. 暗号化とは関係ありません。

インターフェース・バス規格のほかの問題

  1. x4のPCI ExpressのSSDを、マザーボードのx16の長さのスロットに差し込むとどうなるか(スロットがx4以上の配線を持つとする)。
  2. PCI Expressの構成について正しいものはどれか。
  3. PCI Expressの通信のしくみとして正しいものはどれか。
  4. PCI Expressのデータリンク層が、伝送中のビットの誤りに対して行うこととして正しいものはどれか。
  5. PCI Expressの機器のレジスタやメモリを、CPUから読み書きできるようにするしくみとして正しいものはどれか。

この分野の比較

  • NVMeとSATAのSSDの違い：速度・インターフェース・選び方NVMeとSATAのSSDを、インターフェース・速度・遅延・コマンドキュー・形状・消費電力・互換性・価格・向いている人の観点で表にして比較します。
  • DMAとプログラムI/Oの違い：データ転送の方法を比較DMAとプログラムI/O(PIO)を、データを動かす主体・CPUの負荷・スループット・準備のコスト・複雑さ・バスの使用・用途の観点で表にして比較します。
  • PCIe 3.0・4.0・5.0・6.0の違い：速度と世代ごとの特徴を比較PCIe 3.0、4.0、5.0、6.0を、転送レート・レーンあたりと×4、×16のリンクの帯域・エンコード・信号方式・使われる機器の観点で表にして比較します。
