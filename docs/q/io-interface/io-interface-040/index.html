インターフェース・バス規格

シリアル伝送の速度を上げるほど、同じ長さの基板の配線で信号を送るのが難しくなり、途中にリタイマなどを入れることがある。その主な理由はどれか。

  1. A配線の損失は周波数が高いほど大きくなるので、速い信号ほど届くまでに大きく弱まるから
  2. B速い信号は配線の中を光より速く進んでしまうから
  3. C速い信号ほど配線の抵抗が0に近づき、電流が流れすぎるから
答えと解説を見る

正解：A. 配線の損失は周波数が高いほど大きくなるので、速い信号ほど届くまでに大きく弱まるから

配線では、表皮効果による導体の損失と、基板の材料による誘電体の損失が、どちらも周波数とともに増えます。速度を2倍にすると、同じ長さでも信号は大きく弱まり、受信側のイコライザだけでは補いきれなくなります。そこで、損失の小さい基板の材料を使ったり、途中にリタイマを入れて信号をいったん受け取り、きれいな信号として送り直したりします。

  • A. 正しい。リタイマは信号を受け直して送り直します。
  • B. 光より速く進むことはありません。
  • C. 周波数が高いほど、損失はむしろ増えます。

インターフェース・バス規格のほかの問題

  1. 高速なシリアル伝送の要求として「ビット誤り率(BER)が10のマイナス12乗以下」とされているときの意味として正しいものはどれか。
  2. 高速な信号の配線で、配線の特性インピーダンスを送受信の回路と合わせる(整合をとる)目的として正しいものはどれか。
  3. 100ギガビットのイーサネットのような高速な接続が、例えば25 Gb/sのレーンを4本束ねて作られることがある。この考え方として正しいものはどれか。
  4. PCI Expressなどで使われるスペクトラム拡散クロック(SSC)の目的として正しいものはどれか。
  5. PCI Expressの1レーンが「全二重」であることの意味として正しいものはどれか。
