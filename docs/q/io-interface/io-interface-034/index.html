インターフェース・バス規格

大きなSoCで、1本の共有のバスの代わりにネットワークオンチップ(NoC)が使われるようになった理由として正しいものはどれか。

  1. ANoCを使うと、チップの中で無線通信ができるから
  2. B共有のバスでは1度に1つの転送しか通せず、ブロックが増えると混み合い、配線も長くなるから
  3. C共有のバスでは、CPUがメモリを読めないから
答えと解説を見る

正解：B. 共有のバスでは1度に1つの転送しか通せず、ブロックが増えると混み合い、配線も長くなるから

ブロックが少ないうちは共有のバスで十分ですが、CPUのコアやGPU、各種のアクセラレータが何十個もつながると、1度に1つしか通れないバスは混み合います。NoCは、ルータとリンクを網の目のように並べ、データをパケットにして経路を選んで送るので、離れたブロックどうしの多くの転送を同時に運べます。配線を短い区間に分けられるので、高い周波数でも動かしやすくなります。

  • A. NoCも配線による接続です。
  • B. 正しい。NoCは多くの転送を並列に運べます。
  • C. 共有のバスでもメモリは読めます。

インターフェース・バス規格のほかの問題

  1. CXL(Compute Express Link)の説明として正しいものはどれか。
  2. CXLを使ったメモリの拡張(CXLメモリ)の利点として正しいものはどれか。
  3. CXLを構成する3つのプロトコルの組み合わせとして正しいものはどれか。
  4. 高速なシリアル伝送の受信回路で使われるイコライザ(CTLEやDFEなど)の役割として正しいものはどれか。
  5. 高速なシリアル信号の品質を見るアイパターン(アイダイアグラム)について正しいものはどれか。
