インターフェース・バス規格

PCI Expressで使われるクレジット方式のフロー制御の説明として正しいものはどれか。

  1. A受ける側がバッファの空きの量をクレジットとして送る側に知らせ、送る側はクレジットの範囲でだけパケットを送る
  2. B送る側は受ける側の状態に関係なく送り、あふれたパケットは捨てる
  3. C送るデータの量に応じて、利用者に料金を請求する
答えと解説を見る

正解：A. 受ける側がバッファの空きの量をクレジットとして送る側に知らせ、送る側はクレジットの範囲でだけパケットを送る

受ける側のバッファがいっぱいのときにパケットを送ると、捨てて送り直すむだが生じます。クレジット方式では、受ける側が「あとこれだけ受け取れる」という量を送る側に知らせ、送る側はその範囲でだけ送り、受ける側は処理してバッファが空くたびにクレジットを返します。あふれが起きないので、捨てて再送する手間がありません。

  • A. 正しい。バッファがあふれることがありません。
  • B. あふれさせないための仕組みです。
  • C. お金のクレジットとは関係ありません。

インターフェース・バス規格のほかの問題

  1. AI向けのGPUを多数つなぐシステムで、PCI Expressとは別の、GPUどうしを結ぶ専用の高速な接続(NVIDIAのNVLinkなど)が使われる主な理由はどれか。
  2. PCI Expressで、64バイトの小さなデータを書き込むパケットを多数送ると、実効的な帯域が理論値よりかなり小さくなる。その主な理由はどれか。
  3. ネットワークカードやNVMeのSSDなどで広く使われる、メモリ上の記述子(ディスクリプタ)の輪(リング)を使ったDMAのしくみについて正しいものはどれか。
  4. PCI Expressのリンクの省電力の機能(ASPMによるL0sやL1の状態)について正しいものはどれか。
  5. チップやボードの間の高速な接続が、多数の線を並べる並列伝送から、少ない線に速い信号を流すシリアル伝送に移ってきた主な理由はどれか。

この分野の比較

  • NVMeとSATAのSSDの違い：速度・インターフェース・選び方NVMeとSATAのSSDを、インターフェース・速度・遅延・コマンドキュー・形状・消費電力・互換性・価格・向いている人の観点で表にして比較します。
  • DMAとプログラムI/Oの違い：データ転送の方法を比較DMAとプログラムI/O(PIO)を、データを動かす主体・CPUの負荷・スループット・準備のコスト・複雑さ・バスの使用・用途の観点で表にして比較します。
  • PCIe 3.0・4.0・5.0・6.0の違い：速度と世代ごとの特徴を比較PCIe 3.0、4.0、5.0、6.0を、転送レート・レーンあたりと×4、×16のリンクの帯域・エンコード・信号方式・使われる機器の観点で表にして比較します。
