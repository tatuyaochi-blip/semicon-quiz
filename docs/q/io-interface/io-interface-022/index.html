インターフェース・バス規格

USBの通信のしくみについて正しいものはどれか(USB4を除く従来のUSBについて)。

  1. Aホストが通信の予定を決めて機器に問い合わせ、機器はホストの指示に応じてデータを送る
  2. Bすべての機器が対等で、好きなときに勝手にデータを送れる
  3. C機器どうしがホストを通さずに直接通信するのが基本である
答えと解説を見る

正解：A. ホストが通信の予定を決めて機器に問い合わせ、機器はホストの指示に応じてデータを送る

USBでは、パソコンなどのホストが接続された機器を管理し、どの機器といつ通信するかを決めます。マウスのような機器も、ホストが定期的に問い合わせたときに入力のデータを返します。機器の側を単純にでき、多くの機器を安く作れるのが利点です。機器はつないだときにホストに自分の種類を知らせ、ホストが合うドライバを読み込みます。

  • A. 正しい。ホストが主導する方式です。
  • B. 機器が勝手に送ることはできません。
  • C. 基本はホストと機器の間の通信です。

インターフェース・バス規格のほかの問題

  1. USB Type-Cについて正しいものはどれか。
  2. USB Power Delivery(USB PD)の説明として正しいものはどれか。
  3. USBの転送の種類のうち、アイソクロナス転送の特徴として正しいものはどれか。
  4. USBやPCI Expressの一部で使える「ホットプラグ」の説明として正しいものはどれか。
  5. SoCの内部で、CPUやメモリコントローラ、周辺回路などのブロックをつなぐのに広く使われている、ArmのAMBA規格のバスはどれか。

この分野の比較

  • NVMeとSATAのSSDの違い：速度・インターフェース・選び方NVMeとSATAのSSDを、インターフェース・速度・遅延・コマンドキュー・形状・消費電力・互換性・価格・向いている人の観点で表にして比較します。
  • DMAとプログラムI/Oの違い：データ転送の方法を比較DMAとプログラムI/O(PIO)を、データを動かす主体・CPUの負荷・スループット・準備のコスト・複雑さ・バスの使用・用途の観点で表にして比較します。
  • PCIe 3.0・4.0・5.0・6.0の違い：速度と世代ごとの特徴を比較PCIe 3.0、4.0、5.0、6.0を、転送レート・レーンあたりと×4、×16のリンクの帯域・エンコード・信号方式・使われる機器の観点で表にして比較します。
