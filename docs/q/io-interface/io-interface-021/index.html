インターフェース・バス規格

機器との間で小さなデータを1つずつ何千回もやり取りするプログラムを速くする方法として、最も効果的なものはどれか。

  1. A帯域が2倍の世代の接続に変えるだけにする
  2. Bデータをまとめて大きな塊にし、やり取りの回数を減らす
  3. C1回ごとのデータをさらに小さく分ける
答えと解説を見る

正解：B. データをまとめて大きな塊にし、やり取りの回数を減らす

小さなやり取りでは、1回ごとに遅延とソフトウェアの処理の手間がかかり、帯域はほとんど使われていません。データをまとめて1回で送れば、遅延を払う回数が減り、帯域も有効に使えます。ストレージやネットワークでは、複数の要求を待ち行列にためて一度に渡す、割り込みをまとめる、といった同じ考え方の工夫が広く使われています。

  • A. 小さなデータでは遅延が支配的なので、効果は小さいです。
  • B. 正しい。遅延を払う回数が減ります。
  • C. 回数が増えて、さらに遅くなります。

インターフェース・バス規格のほかの問題

  1. USBの通信のしくみについて正しいものはどれか(USB4を除く従来のUSBについて)。
  2. USB Type-Cについて正しいものはどれか。
  3. USB Power Delivery(USB PD)の説明として正しいものはどれか。
  4. USBの転送の種類のうち、アイソクロナス転送の特徴として正しいものはどれか。
  5. USBやPCI Expressの一部で使える「ホットプラグ」の説明として正しいものはどれか。
