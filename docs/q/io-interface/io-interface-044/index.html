インターフェース・バス規格

PCI Expressなどで使われるスペクトラム拡散クロック(SSC)の目的として正しいものはどれか。

  1. Aクロックの周波数を大きく上げて、データの速度を2倍にする
  2. Bクロックの周波数をわずかに揺らして、電磁的な雑音のエネルギーを広い周波数に分散させ、ピークを下げる
  3. Cクロックを止めて、消費電力を0にする
答えと解説を見る

正解：B. クロックの周波数をわずかに揺らして、電磁的な雑音のエネルギーを広い周波数に分散させ、ピークを下げる

一定の周波数のクロックで動く回路は、その周波数と倍数に鋭い雑音のピークを出し、電磁妨害の規制を超えることがあります。SSCでは、クロックの周波数を0.5%ほどの幅でゆっくり上下させ、雑音のエネルギーを周りの周波数に広げてピークを下げます。受信側のCDRはこのゆっくりした変化に追いついてデータを受け取れるように作られています。

  • A. 揺らす幅は0.5%ほどで、速度を上げるものではありません。
  • B. 正しい。電磁妨害(EMI)の規制を満たしやすくなります。
  • C. クロックは止めません。

インターフェース・バス規格のほかの問題

  1. PCI Expressの1レーンが「全二重」であることの意味として正しいものはどれか。
  2. PCI Expressで使われるクレジット方式のフロー制御の説明として正しいものはどれか。
  3. AI向けのGPUを多数つなぐシステムで、PCI Expressとは別の、GPUどうしを結ぶ専用の高速な接続(NVIDIAのNVLinkなど)が使われる主な理由はどれか。
  4. PCI Expressで、64バイトの小さなデータを書き込むパケットを多数送ると、実効的な帯域が理論値よりかなり小さくなる。その主な理由はどれか。
  5. ネットワークカードやNVMeのSSDなどで広く使われる、メモリ上の記述子(ディスクリプタ)の輪(リング)を使ったDMAのしくみについて正しいものはどれか。

この分野の比較

  • NVMeとSATAのSSDの違い：速度・インターフェース・選び方NVMeとSATAのSSDを、インターフェース・速度・遅延・コマンドキュー・形状・消費電力・互換性・価格・向いている人の観点で表にして比較します。
  • DMAとプログラムI/Oの違い：データ転送の方法を比較DMAとプログラムI/O(PIO)を、データを動かす主体・CPUの負荷・スループット・準備のコスト・複雑さ・バスの使用・用途の観点で表にして比較します。
  • PCIe 3.0・4.0・5.0・6.0の違い：速度と世代ごとの特徴を比較PCIe 3.0、4.0、5.0、6.0を、転送レート・レーンあたりと×4、×16のリンクの帯域・エンコード・信号方式・使われる機器の観点で表にして比較します。
