インターフェース・バス規格

高速なシリアル伝送の受信側にあるクロック・データ・リカバリ(CDR)回路の役割として正しいものはどれか。

  1. A送信側から別の線で送られてくるクロックを増幅する
  2. B受け取ったデータの信号の変化からクロックのタイミングを取り出し、そのタイミングでビットを判定する
  3. Cデータの誤りを見つけて、送信側に再送を頼む
答えと解説を見る

正解：B. 受け取ったデータの信号の変化からクロックのタイミングを取り出し、そのタイミングでビットを判定する

クロックを別の線で送ると、データの線との間にずれが生じてしまいます。そこで高速なシリアル伝送では、データの0と1が切り替わるタイミングをCDR回路が見て、PLLなどで同じ周波数・位相のクロックを作り、ビットの真ん中でデータを判定します。そのため、データにはある程度の頻度で切り替わりが含まれている必要があり、符号化でそれを保証します。

  • A. 多くの高速シリアル伝送はクロックを別の線で送りません。
  • B. 正しい。クロック専用の線が要りません。
  • C. 再送はより上の層の仕事です。
