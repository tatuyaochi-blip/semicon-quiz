インターフェース・バス規格

高速な信号の配線で、配線の特性インピーダンスを送受信の回路と合わせる(整合をとる)目的として正しいものはどれか。

  1. A配線の抵抗を0にして、損失をなくすため
  2. B配線を光らせて、目で見て確かめられるようにするため
  3. Cインピーダンスの不連続な所で信号が反射し、波形が乱れるのを防ぐため
答えと解説を見る

正解：C. インピーダンスの不連続な所で信号が反射し、波形が乱れるのを防ぐため

速い信号では、配線は電気の波が進む伝送路として振る舞います。途中で特性インピーダンスが変わる所(コネクタ、ビア、終端の抵抗の違いなど)があると、信号の一部が反射して戻り、後のビットに重なって波形を乱します。そこで配線の幅や層の間隔を調整して、例えば差動の配線を100 Ωなどに作り、終端も同じ値に合わせます。

  • A. インピーダンスを合わせても抵抗による損失は残ります。
  • B. 配線が光ることはありません。
  • C. 正しい。差動の配線では100 Ωなどに合わせます。

インターフェース・バス規格のほかの問題

  1. 100ギガビットのイーサネットのような高速な接続が、例えば25 Gb/sのレーンを4本束ねて作られることがある。この考え方として正しいものはどれか。
  2. PCI Expressなどで使われるスペクトラム拡散クロック(SSC)の目的として正しいものはどれか。
  3. PCI Expressの1レーンが「全二重」であることの意味として正しいものはどれか。
  4. PCI Expressで使われるクレジット方式のフロー制御の説明として正しいものはどれか。
  5. AI向けのGPUを多数つなぐシステムで、PCI Expressとは別の、GPUどうしを結ぶ専用の高速な接続(NVIDIAのNVLinkなど)が使われる主な理由はどれか。
