インターフェース・バス規格

高速なシリアル伝送の要求として「ビット誤り率(BER)が10のマイナス12乗以下」とされているときの意味として正しいものはどれか。

  1. A1秒間に12ビットまでなら誤ってもよいこと
  2. B12ビットに1ビットの割合で誤ること
  3. C平均して1兆ビットに1ビット以下しか誤らないこと
答えと解説を見る

正解：C. 平均して1兆ビットに1ビット以下しか誤らないこと

ビット誤り率は、送ったビットのうち誤って受け取られたビットの割合です。10のマイナス12乗は1兆ビットに1ビットで、10 Gb/sの伝送なら平均して100秒に1回ほどの誤りになります。小さな数字に見えても、速い伝送では誤りはそれなりの頻度で起きるので、PCI Expressなどではデータリンク層の再送や誤り訂正で、上の層に誤りが届かないようにしています。

  • A. 単位時間あたりの誤りの数ではありません。
  • B. それでは誤りが多すぎて通信になりません。
  • C. 正しい。10の12乗は1兆です。

インターフェース・バス規格のほかの問題

  1. 高速な信号の配線で、配線の特性インピーダンスを送受信の回路と合わせる(整合をとる)目的として正しいものはどれか。
  2. 100ギガビットのイーサネットのような高速な接続が、例えば25 Gb/sのレーンを4本束ねて作られることがある。この考え方として正しいものはどれか。
  3. PCI Expressなどで使われるスペクトラム拡散クロック(SSC)の目的として正しいものはどれか。
  4. PCI Expressの1レーンが「全二重」であることの意味として正しいものはどれか。
  5. PCI Expressで使われるクレジット方式のフロー制御の説明として正しいものはどれか。
