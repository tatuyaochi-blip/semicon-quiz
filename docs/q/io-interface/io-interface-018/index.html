インターフェース・バス規格

PCI Expressで使われるMSI(メッセージシグナル割り込み)の特徴として正しいものはどれか。

  1. A割り込みのたびに、機器が電話をかけてCPUに知らせる
  2. B割り込みを使わず、CPUが常に機器の状態を調べ続ける
  3. C機器が決められた番地へ書き込みを行うことで割り込みを知らせ、専用の割り込み線が不要になる
答えと解説を見る

正解：C. 機器が決められた番地へ書き込みを行うことで割り込みを知らせ、専用の割り込み線が不要になる

昔の機器は、割り込みを知らせるための専用の線を持ち、複数の機器で線を共有することもありました。MSIでは、機器がOSに指定された番地へ決められたデータを書き込むと、それが割り込みとしてCPUに届きます。線の数の制約がないので、1つの機器が多くの割り込みを持て、例えばネットワークカードが受信の待ち行列ごとに別の割り込みを別のコアへ送れます。

  • A. もちろん電話は使いません。
  • B. それはポーリングです。
  • C. 正しい。割り込みもパケットとして送ります。

インターフェース・バス規格のほかの問題

  1. インターフェースの性能を表す「帯域」と「遅延(レイテンシ)」の違いとして正しいものはどれか。
  2. 帯域10 GB/s、遅延1 µsの接続で、64バイトのデータを1回送るのにかかる時間に最も近いものはどれか(時間=遅延+データ量÷帯域とする)。
  3. 機器との間で小さなデータを1つずつ何千回もやり取りするプログラムを速くする方法として、最も効果的なものはどれか。
  4. USBの通信のしくみについて正しいものはどれか(USB4を除く従来のUSBについて)。
  5. USB Type-Cについて正しいものはどれか。

この分野の比較

  • NVMeとSATAのSSDの違い：速度・インターフェース・選び方NVMeとSATAのSSDを、インターフェース・速度・遅延・コマンドキュー・形状・消費電力・互換性・価格・向いている人の観点で表にして比較します。
  • DMAとプログラムI/Oの違い：データ転送の方法を比較DMAとプログラムI/O(PIO)を、データを動かす主体・CPUの負荷・スループット・準備のコスト・複雑さ・バスの使用・用途の観点で表にして比較します。
  • PCIe 3.0・4.0・5.0・6.0の違い：速度と世代ごとの特徴を比較PCIe 3.0、4.0、5.0、6.0を、転送レート・レーンあたりと×4、×16のリンクの帯域・エンコード・信号方式・使われる機器の観点で表にして比較します。
