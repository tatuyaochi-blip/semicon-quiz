インターフェース・バス規格

PCI Expressの構成について正しいものはどれか。

  1. Aすべての機器が1本の共有のバスにつながり、1度に1つの機器だけが使える
  2. B機器どうしは無線でつながる
  3. CCPU側のルートコンプレックスから、スイッチを通って各機器(エンドポイント)へ、点と点の接続で木の形につながる
答えと解説を見る

正解：C. CPU側のルートコンプレックスから、スイッチを通って各機器(エンドポイント)へ、点と点の接続で木の形につながる

昔のPCIは、複数の機器が1本のバスを共有し、使う権利を取り合う方式でした。PCI Expressでは、CPUやメモリとつながるルートコンプレックスを根として、スイッチで分岐し、各リンクは2つの機器だけを結ぶ点と点の接続です。リンクごとに帯域を専有できるので、機器が増えても互いに帯域を奪い合いにくく、信号の品質も保ちやすくなります。

  • A. それは古いPCIのような共有バスの方式です。
  • B. 有線の接続です。
  • C. 正しい。各リンクを2つの機器が専有します。

インターフェース・バス規格のほかの問題

  1. PCI Expressの通信のしくみとして正しいものはどれか。
  2. PCI Expressのデータリンク層が、伝送中のビットの誤りに対して行うこととして正しいものはどれか。
  3. PCI Expressの機器のレジスタやメモリを、CPUから読み書きできるようにするしくみとして正しいものはどれか。
  4. PCI Expressで使われるMSI(メッセージシグナル割り込み)の特徴として正しいものはどれか。
  5. インターフェースの性能を表す「帯域」と「遅延(レイテンシ)」の違いとして正しいものはどれか。
