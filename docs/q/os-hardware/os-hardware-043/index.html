OSとハードウェア

RISC-Vの特権アーキテクチャで定められている主な動作モードの組み合わせとして正しいものはどれか。

  1. Aマシンモード、スーパーバイザモード、ユーザモード
  2. Bリアルモード、プロテクトモード、ロングモード
  3. Cアドレスモード、データモード、命令モード
答えと解説を見る

正解：A. マシンモード、スーパーバイザモード、ユーザモード

RISC-Vの特権アーキテクチャでは、最も特権の高いマシンモード(M)、OSのカーネルが動くスーパーバイザモード(S)、アプリケーションが動くユーザモード(U)が定められています。マシンモードは必ず実装され、電源投入直後やファームウェアがここで動きます。小さなマイコンではMとUだけ、OSを動かす場合はM・S・Uをもつのが一般的で、仮想化の拡張ではさらにハイパーバイザ用のモードが加わります。リアル・プロテクト・ロングモードはx86の用語です。

  • A. 正しい。M・S・Uの3つのモードです。
  • B. これはx86の動作モードの用語です。
  • C. このようなモードの区分はありません。

OSとハードウェアのほかの問題

  1. 割り込みや例外の処理を終えて元のプログラムに戻るとき、通常の関数の戻り命令ではなく、専用の復帰命令(RISC-Vのsret・mretなど)を使う理由はどれか。
  2. リアルタイム性が求められるシステムで、割り込みが発生してからハンドラが動き出すまでの時間(割り込み遅延)を大きくしてしまう要因として最も適切なものはどれか。
  3. NMI(マスク不可能割り込み)の説明として正しいものはどれか。
  4. 複数のコアをもつシステムで、OSがあるページのページテーブルの項目を書き換えて対応を取り消したとき、必要になる処理として正しいものはどれか。
  5. プログラムが、OSが割り当てていないアドレスにアクセスしたときに一般的に起こることはどれか。
