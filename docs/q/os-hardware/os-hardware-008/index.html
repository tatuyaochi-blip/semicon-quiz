OSとハードウェア

重要な処理の途中で一時的に割り込みを禁止(マスク)するときの注意点として正しいものはどれか。

  1. A禁止している時間が長いと、ほかの割り込みへの応答が遅れるため、できるだけ短くする
  2. B割り込みを禁止すると、届いた割り込みはすべて失われるので、二度と処理されない
  3. C割り込みを禁止すると、CPUの消費電力が大きく増えるので使ってはならない
答えと解説を見る

正解：A. 禁止している時間が長いと、ほかの割り込みへの応答が遅れるため、できるだけ短くする

割り込みを禁止すると、共有するデータの更新を途中で割り込まれずに済みますが、その間に届いた割り込みは待たされます。禁止の時間が長いと、通信の受信やタイマーの処理が遅れ、データの取りこぼしや応答の遅れにつながるため、禁止する区間はできるだけ短くします。届いた割り込みは多くの場合、保留されて禁止が解けたあとに処理されるので、すべて失われるわけではありません。消費電力が大きく増えるわけでもありません。

  • A. 正しい。応答の遅れを防ぐため、禁止する区間を短くします。
  • B. 多くの場合、割り込みは保留され、解除後に処理されます。
  • C. 割り込みの禁止で消費電力が大きく増えることはありません。
