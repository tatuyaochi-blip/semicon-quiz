OSとハードウェア

仮想マシンのOSが特権の必要な命令を実行したとき、ハイパーバイザに処理が移り、ハイパーバイザがその命令の効果を代わりに再現する方式を何と呼ぶか。

  1. Aトラップ・アンド・エミュレート
  2. Bコピーオンライト
  3. Cデマンドページング
答えと解説を見る

正解：A. トラップ・アンド・エミュレート

仮想マシンのOSは、ハードウェアを直接操作するつもりで特権命令を実行しますが、実際には特権の低いモードで動かされているため例外(トラップ)が起きます。ハイパーバイザはそれを受け取って、その仮想マシンにとって正しい結果になるように命令の効果を再現(エミュレート)し、仮想マシンに戻します。CPUの仮想化支援機能は、こうした切り替えを速く確実に行えるようにします。コピーオンライトとデマンドページングはメモリ管理の方式です。

  • A. 正しい。特権命令を例外で捕まえ、ハイパーバイザが再現する方式です。
  • B. コピーオンライトは書き込み時に複製するメモリ管理の方式です。
  • C. デマンドページングはページを必要なときに読み込む方式です。

OSとハードウェアのほかの問題

  1. 準仮想化(パラバーチャライゼーション)の説明として正しいものはどれか。
  2. コンテナと仮想マシンの違いとして正しいものはどれか。
  3. 多くのOSで、カーネルの領域を各プロセスのアドレス空間の一部(例えば上位の範囲)に割り当てておき、ページテーブルの保護ビットでユーザモードからのアクセスを禁止している。この配置の主な利点はどれか。
  4. ページサイズが4 KBのとき、仮想アドレスのうちページ内の位置(オフセット)を表すのは何ビットか。
  5. ページサイズが4 KBのとき、32ビットの仮想アドレス0x00403ABCのページ番号とページ内のオフセットの組み合わせとして正しいものはどれか。
