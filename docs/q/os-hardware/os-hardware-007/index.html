OSとハードウェア

割り込みベクタテーブルの役割として正しいものはどれか。

  1. A割り込みが起きた回数を種類ごとに記録しておく
  2. B割り込みや例外の種類ごとに、処理を始めるアドレスを決めておく
  3. C次にどのプロセスを実行するかの順番を記録しておく
答えと解説を見る

正解：B. 割り込みや例外の種類ごとに、処理を始めるアドレスを決めておく

割り込みや例外が起きると、CPUはその原因に対応する番号(ベクタ番号)を得て、割り込みベクタテーブルからハンドラの先頭アドレスを読み、そこへ処理を移します。表の中身はOSが起動時に設定し、タイマー、各装置、ページフォルト、システムコールなどで別々のハンドラを呼べるようにします。回数を数えるのは統計のための別のしくみで、実行するプロセスの順番はOSのスケジューラが管理します。

  • A. 回数の記録は統計のための別のしくみです。
  • B. 正しい。原因ごとのハンドラの開始アドレスを決める表です。
  • C. 実行するプロセスの順番はスケジューラが管理します。

OSとハードウェアのほかの問題

  1. 重要な処理の途中で一時的に割り込みを禁止(マスク)するときの注意点として正しいものはどれか。
  2. 割り込みハンドラの処理を、すぐに行う短い部分と、あとで通常の文脈で行う残りの部分に分ける理由として正しいものはどれか。
  3. ページテーブルの役割として正しいものはどれか。
  4. ページフォルトが起こる場合として正しいものはどれか。
  5. 追い出されてディスクにあるページにアクセスしてページフォルトが起きたとき、OSが行う処理の流れとして正しいものはどれか。
