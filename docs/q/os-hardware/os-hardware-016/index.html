OSとハードウェア

ページテーブルの各項目にふつう含まれる情報の組み合わせとして正しいものはどれか。

  1. A物理ページの番号と、有効・保護・参照・書き換えのビット
  2. Bそのページのデータの内容そのものと、最後に書き込んだ時刻
  3. Cそのページを使うプロセスの名前と、使用した時間の合計
答えと解説を見る

正解：A. 物理ページの番号と、有効・保護・参照・書き換えのビット

ページテーブルの項目には、対応する物理ページの番号のほか、そのページが物理メモリにあるかを示す有効ビット、読み書きや実行、ユーザモードからのアクセスの許可、ハードウェアが設定するアクセス済み(参照)ビットと書き換え済み(ダーティ)ビットが入ります。OSは参照ビットでページ置き換えの判断を、ダーティビットで追い出すときの書き戻しの要否を判断します。データの内容やプロセスの名前は入りません。

  • A. 正しい。物理ページ番号と、保護・状態のビットが入ります。
  • B. データの内容はページそのものにあり、表には入りません。
  • C. プロセスの名前や使用時間は別の場所で管理します。

OSとハードウェアのほかの問題

  1. プロセスを複製するときにコピーオンライトを使う利点として正しいものはどれか。
  2. デマンドページングの説明として正しいものはどれか。
  3. ページ置き換えのクロック方式(セカンドチャンス方式)で、各ページの参照ビットを使う目的はどれか。
  4. ページ置き換えでFIFO方式を使うと、物理メモリのページ数を増やしたのにページフォルトが増える場合がある。この現象を何と呼ぶか。
  5. 物理メモリが足りず、ページの追い出しと読み込みばかりが続いて処理がほとんど進まなくなる状態を何と呼ぶか。
