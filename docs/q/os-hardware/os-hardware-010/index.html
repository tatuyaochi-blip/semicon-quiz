OSとハードウェア

ページテーブルの役割として正しいものはどれか。

  1. A仮想アドレスのページ番号を、物理アドレスのページ番号に対応づける
  2. B物理メモリにあるデータの内容を、ページごとに複製して保存する
  3. C実行中のプロセスの優先度を、ページの順番に並べて管理する
答えと解説を見る

正解：A. 仮想アドレスのページ番号を、物理アドレスのページ番号に対応づける

仮想記憶では、プログラムが使う仮想アドレスを、実際の物理メモリのアドレスに変換して使います。ページテーブルは、仮想ページの番号ごとに、対応する物理ページの番号と、読み書きの許可などの保護の情報を記録した表で、OSがプロセスごとに作り、CPUのMMUが参照します。よく使う変換結果はTLBに保持されます。データの内容そのものを複製したり、プロセスの優先度を管理したりする表ではありません。

  • A. 正しい。仮想ページを物理ページに対応づける表です。
  • B. データの内容の複製は保存しません。
  • C. プロセスの優先度はスケジューラが管理します。

OSとハードウェアのほかの問題

  1. ページフォルトが起こる場合として正しいものはどれか。
  2. 追い出されてディスクにあるページにアクセスしてページフォルトが起きたとき、OSが行う処理の流れとして正しいものはどれか。
  3. ページテーブルを1段ではなく多段(階層型)にする主な理由はどれか。
  4. 仮想アドレスが32ビット、ページサイズが4 KB、ページテーブルの1項目が4バイトのとき、1段のページテーブルの大きさはいくらか。
  5. 仮想アドレスのうち48ビットを使い、ページサイズ4 KB、各段の表が512項目(9ビット)の多段ページテーブルでは、何段の表をたどる必要があるか。
