OSとハードウェア

物理メモリが足りず、ページの追い出しと読み込みばかりが続いて処理がほとんど進まなくなる状態を何と呼ぶか。

  1. Aデッドロック
  2. Bキャッシュコヒーレンシ
  3. Cスラッシング
答えと解説を見る

正解：C. スラッシング

同時に動くプロセスが使うページの合計(ワーキングセット)が物理メモリより大きくなると、必要なページを読み込むたびに別のプロセスが使うページを追い出し、すぐにまたそれが必要になる、という繰り返しが起こります。ディスクの読み書きを待つ時間ばかりになり、CPUの利用率も下がります。これがスラッシングで、実行するプロセスを減らすかメモリを増やすと解消します。デッドロックは互いの資源を待ち合って止まる状態です。

  • A. デッドロックは互いに資源を待ち合って止まる状態です。
  • B. キャッシュコヒーレンシはキャッシュの内容の一貫性の話です。
  • C. 正しい。メモリ不足でページの入れ替えが続く状態です。

OSとハードウェアのほかの問題

  1. メモリのアクセス時間が100 ns、ページフォルトの処理に8 msかかるとき、100万回に1回ページフォルトが起こると、平均のアクセス時間はおよそいくらになるか。
  2. コンテキストスイッチで、切り替える前のプロセスについて保存しておく必要があるものはどれか。
  3. プロセスのコンテキストスイッチが、レジスタの保存と復元にかかる時間よりも、実際には大きな性能の低下を招くことがある主な理由はどれか。
  4. TLBの各項目にASID(アドレス空間識別子)を付ける利点として正しいものはどれか。
  5. OSが、自分からCPUを手放さないプログラムからでも一定時間ごとにCPUを取り戻して、ほかのプロセスに切り替えられるのは、主にどのしくみによるか。
