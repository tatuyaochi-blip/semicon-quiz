OSとハードウェア

次のうち、命令の実行とは無関係に、いつ起こるか決まっていない非同期のものはどれか。

  1. Aタイマーからの割り込み
  2. B存在しないページへのアクセスによるページフォルト
  3. C0での割り算による例外
答えと解説を見る

正解：A. タイマーからの割り込み

タイマーからの割り込みは、どの命令を実行しているかに関係なく、決められた時間がたつと外部の回路から届くので非同期です。ページフォルトやゼロ除算は、特定の命令を実行したことが原因で起こり、同じ状況で同じ命令を実行すれば同じ場所で必ず起こるので、同期的な例外です。同期的な例外では、原因となった命令をやり直したり飛ばしたりする判断が必要になる点も、割り込みとの違いです。

  • A. 正しい。命令とは無関係に外部から届く非同期の割り込みです。
  • B. ページフォルトは特定の命令が原因の同期的な例外です。
  • C. ゼロ除算は割り算の命令が原因の同期的な例外です。

OSとハードウェアのほかの問題

  1. CPUが割り込みを受け付けたときの一般的な処理の流れとして正しいものはどれか。
  2. 割り込みベクタテーブルの役割として正しいものはどれか。
  3. 重要な処理の途中で一時的に割り込みを禁止(マスク)するときの注意点として正しいものはどれか。
  4. 割り込みハンドラの処理を、すぐに行う短い部分と、あとで通常の文脈で行う残りの部分に分ける理由として正しいものはどれか。
  5. ページテーブルの役割として正しいものはどれか。
