AIハードウェアとソフトウェアスタック

AIのアクセラレータの性能として示される「○○ TOPS」という値について注意すべき点として正しいものはどれか。

  1. A多くはINT8などの低い精度で数えた理論上の最大値で、実際のモデルでの速さはメモリ帯域や演算器の利用率で大きく変わる
  2. BTOPSが2倍なら、どのモデルでも必ず2倍速く動く
  3. CTOPSはメモリの容量を表す値である
答えと解説を見る

正解：A. 多くはINT8などの低い精度で数えた理論上の最大値で、実際のモデルでの速さはメモリ帯域や演算器の利用率で大きく変わる

TOPS(1秒あたりの兆回の演算)は、全部の演算器が休みなく動いたときの理論上の値で、多くはINT8やそれより低い精度で数えられ、スパースを使った場合の値のこともあります。実際のモデルでは、メモリ帯域で律速されたり、演算器が遊んだり、対応していない演算をほかの回路で行ったりするので、実効の性能はずっと低くなることがあります。製品を比べるときは、同じ条件の実測の値を見ることが大切です。

  • A. 正しい。精度の条件や実測の値を確かめる必要があります。
  • B. メモリ律速のモデルでは、TOPSを上げても速くなりません。
  • C. 1秒あたりの演算回数(兆回)を表します。

AIハードウェアとソフトウェアスタックのほかの問題

  1. 大規模な学習の効率を表す指標のMFU(Model FLOPs Utilization)の説明として正しいものはどれか。
  2. Transformerのモデルの学習に必要な演算の数の目安として、パラメータ数をN、学習に使うトークンの数をDとしたとき、よく使われる近似はどれか。
  3. パラメータ数Nの大規模言語モデルで、1トークンを生成する推論に必要な演算の数の目安はどれか(アテンションの部分を除く)。
  4. ソフトマックス関数exp(xi)/Σexp(xj)を計算するとき、各xiから最大値を引いてから計算することが多い理由として正しいものはどれか。
  5. 大規模言語モデルの推論を速くする「投機的デコーディング」の考え方として正しいものはどれか。
