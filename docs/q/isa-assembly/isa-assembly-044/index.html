命令セット・アセンブリ

RISC-VのM拡張が基本の整数命令セットに追加する命令はどれか。

  1. A浮動小数点演算
  2. Bアトミック命令
  3. C整数の乗算と除算
答えと解説を見る

正解：C. 整数の乗算と除算

RISC-Vは、小さな基本の整数命令セット(RV32IやRV64I)に、必要な拡張を組み合わせるモジュール式のISAです。M拡張はmul・div・remなどの乗算と除算、A拡張はアトミック命令、FとDは単精度と倍精度の浮動小数点、Cは16ビットの圧縮命令を加えます。小さなマイコンは基本命令だけにし、汎用のCPUは多くの拡張を載せる、という使い分けができます。

  • A. 浮動小数点はF拡張やD拡張です。
  • B. アトミック命令はA拡張です。
  • C. 正しい。MはMultiplyの意味です。

命令セット・アセンブリのほかの問題

  1. RISC-VのC拡張(圧縮命令)の主な目的はどれか。
  2. M拡張のないRV32IのCPU向けに、C言語の「a * b」(int同士の掛け算)をコンパイルすると、一般にどうなるか。
  3. 昔のMIPSなどにあった分岐遅延スロット(分岐命令の直後の1命令は、分岐するかどうかに関係なく実行される決まり)について正しいものはどれか。
  4. 64ビットのRV64Iでlw命令を実行すると、読み込んだ32ビットの値は64ビットのレジスタにどのように入るか。
  5. ABI(アプリケーションバイナリインターフェース)の説明として正しいものはどれか。
