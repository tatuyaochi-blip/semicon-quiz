ネットワークの設計と運用

ルータの一方のインターフェースにL2スイッチをつなぎ、そのスイッチに4台のPCをつないだ。ルータのもう一方のインターフェースにはリピータハブをつなぎ、そのハブに3台のPCをつないだ。VLANは使っていない。コリジョンドメインを、半二重のイーサネットでフレームの衝突が起こりうる範囲として数えるとき、ブロードキャストドメインとコリジョンドメインの数の組み合わせとして正しいものはどれか。

  1. Aブロードキャストドメイン2、コリジョンドメイン2
  2. Bブロードキャストドメイン2、コリジョンドメイン6
  3. Cブロードキャストドメイン6、コリジョンドメイン2
答えと解説を見る

正解：B. ブロードキャストドメイン2、コリジョンドメイン6

ルータはブロードキャストを転送しないので、ルータのインターフェースごとにブロードキャストドメインが分かれ、ここでは2つです。L2スイッチはポートごとにコリジョンドメインを分けるので、スイッチ側では、4台のPCのポートとルータにつながるポートの5つが、それぞれ別のコリジョンドメインになります。リピータハブは届いた信号をすべてのポートに流すだけなので、ハブと3台のPC、ルータのインターフェースが1つのコリジョンドメインになります。合わせて 5 + 1 = 6 個です。いまのスイッチは全二重でつなぐのがふつうで、全二重のリンクでは衝突そのものが起こりません。

  • A. スイッチ全体を1つのコリジョンドメインと数えた値です。スイッチはポートごとにコリジョンドメインを分けます。
  • B. 正しい。ブロードキャストドメインはルータで2つに分かれ、コリジョンドメインはスイッチ側の5つとハブ側の1つです。
  • C. ブロードキャストドメインとコリジョンドメインの数を取り違えた組み合わせです。ブロードキャストを止めるのはルータで、スイッチやハブは止めません。

ネットワークの設計と運用のほかの問題

  1. IEEE 802.1Qのタグに入るVLAN IDは12ビットで、そのうち0と4095は特別な用途のために予約されている。VLANの識別に使えるVLAN IDの数はどれか。
  2. 2台のスイッチSW1とSW2の両方に、VLAN 10とVLAN 20のポートがある。2台を1本のケーブルでつなぎ、同じVLANどうしならスイッチをまたいで通信できるようにしたい。つなぐポートの設定として適切なものはどれか。
  3. スイッチを冗長な経路でつないだネットワークで、スパニングツリープロトコル(STP)が果たす役割として正しいものはどれか。
  4. STPで、3台のスイッチのブリッジIDが次のように分かっている。SW1は優先度32768、MACアドレス 00-00-5E-00-53-01、SW2は優先度61440、MACアドレス 00-00-5E-00-53-05、SW3は優先度4096、MACアドレス 00-00-5E-00-53-0A である。ルートブリッジに選ばれるスイッチはどれか。
  5. 3台のスイッチSW1、SW2、SW3を、互いに1本ずつのリンクで三角形につないだ。STPのルートブリッジはSW1で、ブリッジIDはSW2の方がSW3より小さい。どのリンクもパスコストは同じとする。ブロックされる(フレームを転送しない)ポートはどれか。
