ネットワークの設計と運用

リンクステート型のルーティングプロトコルの説明として正しいものはどれか。

  1. A各ルータが、隣のルータから受け取った宛先と距離(ホップ数など)の情報だけをもとに、自分の経路表を作る
  2. B各ルータが、自分につながるリンクの状態を広めてネットワーク全体の構成(トポロジ)を共有し、それぞれがダイクストラ法で最短経路を計算する
  3. C管理者が各ルータに経路を手で設定し、ルータどうしは経路の情報を交換しない
答えと解説を見る

正解：B. 各ルータが、自分につながるリンクの状態を広めてネットワーク全体の構成(トポロジ)を共有し、それぞれがダイクストラ法で最短経路を計算する

リンクステート型(OSPFやIS-ISなど)では、各ルータが自分のリンクの状態(つながっている相手とコスト)を広告し、同じ範囲のすべてのルータが同じ地図をもちます。各ルータはこの地図から、自分を起点にダイクストラ法で最短経路の木を計算します。距離ベクトル型(RIPなど)は、隣から聞いた「どの宛先まで距離いくつか」に自分からの距離を足して経路を選ぶので、しくみは単純ですが、ネットワーク全体の構成は分からず、障害の後に経路が落ち着くまで時間がかかることがあります。リンクステート型は、計算とメモリの負担は大きいものの、変化に素早く追従できます。

  • A. これは距離ベクトル型の説明です。
  • B. 正しい。全体の構成を共有し、各ルータが最短経路を計算します。
  • C. これは静的ルーティングの説明です。

ネットワークの設計と運用のほかの問題

  1. OSPFで、ルータR1からR4の先にあるネットワークへの経路が3つある。経路Aは R1–R5 が10 Gbps、R5–R4 が1 Gbpsのリンク、経路Bは R1–R4 を直接つなぐ100 Mbpsのリンク、経路Cは R1–R2、R2–R3、R3–R4 がすべて1 Gbpsのリンクである。各リンクのコストを「参照帯域幅10 Gbps ÷ リンクの帯域幅」とし、R4から先のコストはどの経路でも同じとする。R1が選ぶ経路はどれか。
  2. インターネットで、プロバイダなどの組織が管理するネットワークの単位(AS、自律システム)の間で経路の情報をやり取りし、通ってきたASの並び(AS_PATH)などの属性と、組織ごとの方針(ポリシー)に基づいて経路を選ぶプロトコルはどれか。
  3. VLAN 20(192.168.20.0/24)の端末に、別のネットワークにあるDHCPサーバ 10.0.0.5 からアドレスを割り当てる。そのため、VLAN 20のデフォルトゲートウェイであるL3スイッチのインターフェース(192.168.20.1)に、DHCPリレーエージェントを設定した。リレーエージェントの動作として正しいものはどれか。
  4. あるドメイン宛ての電子メールを受け取るメールサーバを指定する、DNSのリソースレコードはどれか。
  5. DNSの名前解決での、再帰的な問い合わせと非再帰的な(反復的な)問い合わせの使われ方として正しいものはどれか。
