ネットワークの設計と運用

NAPTを行うルータ(外側のアドレスは 198.51.100.7)に、「外側のTCP 8080番ポートに届いた通信を、内側のWebサーバ 192.168.1.20 の80番ポートへ転送する」というポート転送(宛先だけを変換する静的な設定)を行った。インターネット上の端末 203.0.113.9 が、送信元ポート51000で 198.51.100.7 の8080番ポートに接続したとき、Webサーバが受け取るパケットの宛先と送信元の組み合わせはどれか。

  1. A宛先 198.51.100.7:8080、送信元 203.0.113.9:51000
  2. B宛先 192.168.1.20:80、送信元 203.0.113.9:51000
  3. C宛先 192.168.1.20:80、送信元 198.51.100.7:51000
答えと解説を見る

正解：B. 宛先 192.168.1.20:80、送信元 203.0.113.9:51000

ポート転送では、ルータは外側のアドレスとポート(198.51.100.7:8080)宛てに届いたパケットの宛先を、設定した内側のアドレスとポート(192.168.1.20:80)に書き換えます。送信元は書き換えないので、Webサーバには 203.0.113.9:51000 から届いたように見え、アクセスの記録にも相手の本当のアドレスが残ります。サーバの応答はデフォルトゲートウェイであるこのルータを通り、ルータは変換表を見て、送信元を 198.51.100.7:8080 に書き戻してから端末に返します。外から始まる通信は、ふだんのNAPTでは変換表に対応がなく内側に届かないので、内側でサーバを公開するにはこの設定が必要です。

  • A. ルータで書き換えられる前の、端末が送ったときの宛先です。
  • B. 正しい。宛先だけが内側のサーバのアドレスとポートに書き換えられます。
  • C. 宛先だけを変換する設定なので、送信元は書き換えられません。

ネットワークの設計と運用のほかの問題

  1. ルータのインターフェースに、入ってくるパケットを上から順に調べるACLを設定した。規則1は「宛先 10.0.0.10 のTCP 443番ポートへの通信を許可」、規則2は「送信元が 192.168.1.0/24 の通信をすべて拒否」、規則3は「送信元が 192.168.0.0/16 で、宛先がTCP 80番ポートの通信を許可」で、ほかに規則はない。ア「192.168.1.5 から 10.0.0.10 のTCP 443番ポートへ」、イ「192.168.1.5 から 10.0.0.20 のTCP 80番ポートへ」、ウ「192.168.2.5 から 10.0.0.20 のTCP 80番ポートへ」、エ「192.168.2.5 から 10.0.0.20 のTCP 22番ポートへ」の4つのパケットのうち、通過できるものをすべて挙げたものはどれか。
  2. IPv6で、同じリンクの中だけで使われ、IPv6を使うインターフェースには必ず自動的に設定されるリンクローカルアドレスの範囲はどれか。
  3. IPv6のSLAAC(ステートレスアドレス自動設定)で、端末がグローバルユニキャストアドレスを作る方法として正しいものはどれか。
  4. MACアドレスが 00-1A-2B-3C-4D-5E のインターフェースが、プレフィックス 2001:db8:1:1::/64 と、EUI-64形式のインターフェースIDから、SLAACでアドレスを作る。できるアドレスはどれか。
  5. IPv6だけで動く2つの拠点を、IPv4だけで動くネットワークを通してつなぎ、拠点の間をIPv6のパケットのまま通信させたい。用いる方法として適切なものはどれか。
