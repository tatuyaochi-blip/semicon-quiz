ネットワークの設計と運用

IEEE 802.1Qのタグに入るVLAN IDは12ビットで、そのうち0と4095は特別な用途のために予約されている。VLANの識別に使えるVLAN IDの数はどれか。

  1. A4094個
  2. B4095個
  3. C4096個
答えと解説を見る

正解：A. 4094個

12ビットで表せる値は 2^12 = 4096 通り(0〜4095)です。このうち、優先度だけを示すタグに使う0と、予約されている4095を除いた 4096 − 2 = 4094 個を、VLANの識別に使えます。802.1Qのタグは4バイトで、イーサネットのフレームの送信元MACアドレスの後ろに挿入されます。タグは、タグであることを示す2バイトの値(0x8100)と、3ビットの優先度(PCP)、1ビットのDEI、12ビットのVLAN IDからなります。

  • A. 正しい。2^12 − 2 = 4094 個です。
  • B. 0だけを除いた値です。4095も予約されています。
  • C. 12ビットで表せる値の総数で、予約された2つを除いていません。

ネットワークの設計と運用のほかの問題

  1. 2台のスイッチSW1とSW2の両方に、VLAN 10とVLAN 20のポートがある。2台を1本のケーブルでつなぎ、同じVLANどうしならスイッチをまたいで通信できるようにしたい。つなぐポートの設定として適切なものはどれか。
  2. スイッチを冗長な経路でつないだネットワークで、スパニングツリープロトコル(STP)が果たす役割として正しいものはどれか。
  3. STPで、3台のスイッチのブリッジIDが次のように分かっている。SW1は優先度32768、MACアドレス 00-00-5E-00-53-01、SW2は優先度61440、MACアドレス 00-00-5E-00-53-05、SW3は優先度4096、MACアドレス 00-00-5E-00-53-0A である。ルートブリッジに選ばれるスイッチはどれか。
  4. 3台のスイッチSW1、SW2、SW3を、互いに1本ずつのリンクで三角形につないだ。STPのルートブリッジはSW1で、ブリッジIDはSW2の方がSW3より小さい。どのリンクもパスコストは同じとする。ブロックされる(フレームを転送しない)ポートはどれか。
  5. 従来のSTP(IEEE 802.1D)は、既定のタイマーのままでは、障害の後にブロックされていたポートが転送を始めるまでに30〜50秒ほどかかる。RSTPが切り替えを速くしたしくみとして正しいものはどれか。
