システム構成と信頼性設計

シンクライアントの説明として、適切なものはどれか。

  1. A利用者の端末に高性能のCPUと大容量の記憶装置をもたせ、ネットワークにつながっていなくても単独で処理できるようにする方式
  2. B端末の機能を最小限にする代わりに、ネットワークが途切れても端末だけで業務を続けられるようにする方式
  3. C利用者の端末には入出力などの最小限の機能だけをもたせ、アプリケーションの実行やデータの保存はサーバの側で行う方式
答えと解説を見る

正解：C. 利用者の端末には入出力などの最小限の機能だけをもたせ、アプリケーションの実行やデータの保存はサーバの側で行う方式

シンクライアントは、端末に入力と画面の表示などの最小限の機能だけをもたせ、アプリケーションの実行やデータの保存をサーバの側で行う方式です。端末にデータが残らないので、端末の紛失や盗難による情報の漏えいを防ぎやすく、ソフトウェアの更新もサーバの側でまとめて行えます。その代わり、ネットワークやサーバが止まると端末では業務を続けられません。端末だけで多くの処理を行う方式は、ファットクライアント(リッチクライアント)と呼ばれます。

  • A. ファットクライアント(リッチクライアント)の説明です。
  • B. シンクライアントは処理をサーバで行うので、ネットワークが途切れると業務を続けられません。
  • C. 正しい。処理とデータをサーバに集め、端末は入出力だけを担います。

システム構成と信頼性設計のほかの問題

  1. ピアツーピア(P2P)型のシステムの特徴として、適切なものはどれか。
  2. 集中処理と比べた分散処理の特徴として、適切なものはどれか。
  3. バッチ処理で行うのが適している処理はどれか。
  4. オンライン処理のシステムの性能を評価する指標のうち、レスポンスタイム(応答時間)の説明として、適切なものはどれか。
  5. 利用者の要求を、Webサーバ層、アプリケーションサーバ層、データベースサーバ層の順に処理するシステムがある。各要求は3つの層をそれぞれ1回ずつ通り、各層が処理できる最大の件数は、Webサーバ層が毎秒1,200件、アプリケーションサーバ層が毎秒1,000件、データベースサーバ層が毎秒900件である。データベースサーバ層を増強して毎秒1,500件を処理できるようにしたとき、システム全体で処理できる最大の件数として、正しいものはどれか。
