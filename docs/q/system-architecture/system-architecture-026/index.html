システム構成と信頼性設計

事業継続の計画でいうRPO(目標復旧時点)の説明として、適切なものはどれか。

  1. A障害が起きたとき、どの時点までのデータを復旧できればよいか(どれだけ前までのデータの損失を許すか)を表す目標
  2. B障害が起きてから、業務やシステムを再開するまでに許される時間の目標
  3. Cシステムが故障してから、次に故障するまでの平均の時間
答えと解説を見る

正解：A. 障害が起きたとき、どの時点までのデータを復旧できればよいか(どれだけ前までのデータの損失を許すか)を表す目標

RPO(Recovery Point Objective、目標復旧時点)は、障害が起きたときに、どの時点の状態までデータを戻せればよいかを表す目標です。例えばRPOが1時間なら、障害の直前1時間以内の時点まで戻せる必要があり、少なくとも1時間ごとにバックアップやデータの複製を取る必要があります。業務を再開するまでに許される時間はRTO(Recovery Time Objective、目標復旧時間)で、RPOとRTOを短くするほど、必要な設備の費用は大きくなります。

  • A. 正しい。許されるデータの損失の範囲を、時点で表す目標です。
  • B. RTO(目標復旧時間)の説明です。
  • C. MTBF(平均故障間隔)の説明です。

システム構成と信頼性設計のほかの問題

  1. あるシステムで、RPO(目標復旧時点)を4時間、RTO(目標復旧時間)を2時間と定めた。障害はいつでも起こりうるものとし、バックアップの取得にかかる時間は無視できるものとする。この目標を満たすデータの保護の方式として、適切なものはどれか。
  2. 1,000 km離れた2か所のデータセンターの間で、データベースの更新を同期レプリケーションする。更新のたびに、もう一方への転送と書き込み完了の通知の1往復の通信を待つとする。光ファイバの中の光の速さを約20万 km/sとし、ファイバの経路の長さは直線の距離と同じとみなすとき、通信の伝搬だけで1回の更新の応答時間が増える量として、最も近いものはどれか。
  3. クラウドサービスのIaaSで、一般に利用者が自分で管理するものはどれか。
  4. システムの処理能力を高める方法のうち、スケールアウトに当たるものはどれか。
  5. 負荷に応じてサーバの台数を自動で増減するオートスケールを使うシステムの設計として、一般に望ましいものはどれか。
