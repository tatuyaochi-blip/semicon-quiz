システム構成と信頼性設計

毎週日曜日の夜にフルバックアップを取り、月曜日から土曜日までは毎晩、増分バックアップを取っている。木曜日の昼に障害が起き、水曜日の夜のバックアップの時点までデータを戻すことにした。復元に使うバックアップの数として、正しいものはどれか。

  1. A2
  2. B3
  3. C4
答えと解説を見る

正解：C. 4

増分バックアップには直前のバックアップ以降の変更だけが入っているので、日曜日のフルバックアップを戻したあと、月曜日、火曜日、水曜日の増分バックアップを順に適用する必要があります。そのため、使うバックアップは 1 + 3 = 4 つです。2つで済むのは、毎晩差分バックアップを取っている場合(フルバックアップと水曜日の差分バックアップ)です。

  • A. 差分バックアップの場合の数です。増分バックアップでは、途中の増分もすべて必要です。
  • B. 増分バックアップの3つだけを数え、もとになる日曜日のフルバックアップを数えていません。
  • C. 正しい。フルバックアップ1つと、月曜日から水曜日の増分バックアップ3つです。

システム構成と信頼性設計のほかの問題

  1. データ全体が500 GBのシステムで、毎週日曜日にフルバックアップを取り、月曜日から土曜日までは毎晩、差分バックアップを取る。毎日、それまで変更されていなかった別のデータが20 GBずつ変更されるものとする。月曜日から土曜日までの6回の差分バックアップの容量の合計として、正しいものはどれか。
  2. 事業継続の計画でいうRPO(目標復旧時点)の説明として、適切なものはどれか。
  3. あるシステムで、RPO(目標復旧時点)を4時間、RTO(目標復旧時間)を2時間と定めた。障害はいつでも起こりうるものとし、バックアップの取得にかかる時間は無視できるものとする。この目標を満たすデータの保護の方式として、適切なものはどれか。
  4. 1,000 km離れた2か所のデータセンターの間で、データベースの更新を同期レプリケーションする。更新のたびに、もう一方への転送と書き込み完了の通知の1往復の通信を待つとする。光ファイバの中の光の速さを約20万 km/sとし、ファイバの経路の長さは直線の距離と同じとみなすとき、通信の伝搬だけで1回の更新の応答時間が増える量として、最も近いものはどれか。
  5. クラウドサービスのIaaSで、一般に利用者が自分で管理するものはどれか。
