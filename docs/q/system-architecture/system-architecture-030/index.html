システム構成と信頼性設計

システムの処理能力を高める方法のうち、スケールアウトに当たるものはどれか。

  1. A同じ構成のサーバの台数を増やし、ロードバランサで処理を振り分ける
  2. BサーバのCPUをより高性能なものに交換し、メモリを増やす
  3. Cサーバの台数を減らして、1台あたりの使用率を上げる
答えと解説を見る

正解：A. 同じ構成のサーバの台数を増やし、ロードバランサで処理を振り分ける

スケールアウトは、サーバの台数を増やして処理を分け合い、システム全体の処理能力を高める方法です。台数を増やすだけで能力を足しやすく、1台が故障しても残りで処理を続けられますが、処理を分けられるようにシステムを設計しておく必要があります。1台のサーバの部品をより高性能にするのはスケールアップで、構成は簡単ですが、1台で実現できる性能には限りがあります。台数を減らすことはスケールインと呼びます。

  • A. 正しい。台数を増やして処理を分け合います。
  • B. 1台の性能を高めるスケールアップです。
  • C. 台数を減らすスケールインで、処理能力は下がります。
