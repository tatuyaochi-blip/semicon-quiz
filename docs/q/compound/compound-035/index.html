化合物半導体

GaAsの高周波トランジスタとして使われてきたMESFETのゲートの構造として正しいものはどれか。

  1. A厚い酸化膜の上にゲートを置くMOS構造
  2. BPN接合をゲートにする構造
  3. C金属を半導体に直接接触させたショットキー接合をゲートにする構造
答えと解説を見る

正解：C. 金属を半導体に直接接触させたショットキー接合をゲートにする構造

MESFET(Metal-Semiconductor FET)は、ゲート金属を半導体に直接接触させたショットキー接合をゲートとし、その空乏層の幅でチャネルの厚さを変えて電流を制御します。GaAsには良質な絶縁膜をつくりにくいため、MOS構造の代わりにこの構造が使われ、1970〜90年代の衛星放送の受信機や携帯電話の高周波回路で広く用いられました。現在は、より高性能なHEMTやHBTに置き換わっています。

  • A. MOS構造ではなく、金属を直接接触させた構造です。
  • B. PN接合をゲートにするのは接合型FET(JFET)です。
  • C. 正しい。ショットキー接合をゲートに使います。

  2. InGaNを発光層に使うLEDで、インジウム(In)の組成比を大きくすると発光の色はどう変わるか。
  3. ブルーレイディスクの読み書きに使われる波長約405 nmの青紫色の半導体レーザーの材料はどれか。
  4. 組成を変えることでバンドギャップを調整でき、中赤外から長波長赤外の高性能な赤外線検出器に使われてきた材料はどれか。
