化合物半導体

高輝度の赤色〜黄色LEDに使われる代表的な材料はどれか。

  1. Aシリコン
  2. BAlGaInP系
  3. Cダイヤモンド
答えと解説を見る

正解：B. AlGaInP系

AlGaInP系の化合物半導体は、組成を変えることで赤色から黄色の光を効率よく発光します。信号機や自動車のテールランプ、ディスプレイなどに使われています。青色・緑色はInGaN系が使われます。

  4. GaNが高周波・高出力のトランジスタに適している理由として正しいものはどれか。
