化合物半導体

AlGaAsのような混晶半導体の利点として正しいものはどれか。

  1. A不純物を添加しなくても必ずn型になる
  2. B必ず間接遷移型になる
  3. C組成比を変えることで、バンドギャップや格子定数を調整できる
答えと解説を見る

正解：C. 組成比を変えることで、バンドギャップや格子定数を調整できる

混晶半導体では、元素の組成比を変えることでバンドギャップや格子定数を連続的に調整できます。例えばAlGaAsはAlの割合を増やすとバンドギャップが大きくなります。発光波長の調整や、ヘテロ接合の設計に欠かせない性質です。

  1. HEMT(高電子移動度トランジスタ)が用いられる代表的な用途はどれか。
  2. GaNデバイスで、GaN層を成長させる基板として一般的に使われるものはどれか。
  3. 次世代パワー半導体材料として研究が進む酸化ガリウム(Ga2O3)の特徴として正しいものはどれか。
  4. バンドギャップ約1.42 eVのGaAsから出る光のおよその波長はどれか。
  5. GaAsなどの化合物半導体ウエハの一般的な口径について正しいものはどれか。
