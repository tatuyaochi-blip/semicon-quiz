化合物半導体

LEDの外部量子効率が、青色(InGaN系)と赤色(AlGaInP系)では高いのに、その間の緑〜黄色の波長域で低くなる問題を何と呼ぶか。

  1. Aレッドアウト
  2. Bブルーシフト
  3. Cグリーンギャップ
答えと解説を見る

正解：C. グリーンギャップ

InGaN系で緑を出すにはIn組成を高くする必要があり、組成のむら、ひずみ、強い分極電界(量子閉じ込めシュタルク効果)で効率が落ちます。一方、AlGaInP系は短い波長にするほど伝導帯の谷の並びが変わって間接遷移に近づき、効率が落ちます。このため緑〜黄色(約530〜590 nm)で高効率のLEDが得にくく、グリーンギャップと呼ばれます。人の目はこの色域に最も敏感なため、照明の効率にも影響します。

  • A. そのような名前の問題はありません。
  • B. ブルーシフトは発光波長が短い方へずれる現象です。
  • C. 正しい。緑〜黄色の領域で効率が低くなる問題です。

化合物半導体のほかの問題

  1. ヘテロ接合のバンドの並び方で、「タイプI」の説明として正しいものはどれか。
  2. MOCVD法でマグネシウムを添加したGaNが、成長直後には高抵抗でp型にならない主な理由と、その対策の組み合わせとして正しいものはどれか。
  3. InGaN系のLEDで、電流を大きくすると発光効率がかえって下がる現象を何と呼ぶか。
  4. LEDの正式な名称として正しいものはどれか。
  5. ガリウムヒ素(GaAs)のバンド構造として正しいものはどれか。
