化合物半導体

InP基板の上に、組成を調整したInGaAsを格子整合させて成長させる利点として正しいものはどれか。

  1. A基板が必ず安くなる
  2. B格子定数をそろえることで、転位の少ない高品質な結晶が得られる
  3. C必ず間接遷移型になる
答えと解説を見る

正解：B. 格子定数をそろえることで、転位の少ない高品質な結晶が得られる

In0.53Ga0.47Asのように組成を調整すると、InGaAsの格子定数をInPとほぼ一致させられます。格子定数がそろっていればひずみや転位が生じにくく、厚い層でも高品質な結晶が得られます。光通信用の受光素子やHEMTなどに使われています。

化合物半導体のほかの問題

  2. 高輝度の青色LEDの発明によって、2014年のノーベル物理学賞を受賞した研究者の組み合わせとして正しいものはどれか。
  3. ガリウムヒ素(GaAs)を構成する元素の組み合わせとして正しいものはどれか。
  4. LED照明が白熱電球に比べて省エネルギーである主な理由はどれか。
  5. 電子の移動度が非常に大きく、磁気センサ(ホール素子)などに使われる化合物半導体はどれか。
