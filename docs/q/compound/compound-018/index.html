化合物半導体

殺菌用などの深紫外LEDの発光層に主に使われる材料はどれか。

  1. AGaAs
  2. BAlGaN(窒化アルミニウムガリウム)
  3. CInP
答えと解説を見る

正解：B. AlGaN(窒化アルミニウムガリウム)

AlGaNはアルミニウムの割合を増やすほどバンドギャップが大きくなり、深紫外の短い波長の光を出せます。深紫外LEDは水や空気の殺菌などに使われますが、発光効率の向上が課題になっています。GaAsやInPは赤外の発光に使われる材料です。

  2. GaNでp型層をつくるために使われる代表的な不純物はどれか。
  3. GaNの代表的な結晶構造はどれか。
  4. InPやGaAsを使ったHBT(ヘテロ接合バイポーラトランジスタ)が用いられる用途の例として正しいものはどれか。
  5. GaAsにシリコンを添加してn型にするとき、シリコンが主に置き換わる位置はどれか。
