データベースの基礎

関係データベースの用語で、表(リレーション)の1行に当たるものはどれか。

  1. Aタプル
  2. B属性
  3. Cドメイン
答えと解説を見る

正解：A. タプル

関係データベースは、データを行と列からなる表(関係、リレーション)の形で表し、表どうしを値で関連付けて扱うデータベースです。関係モデルの用語では、表の1行をタプル(組)、1列を属性(アトリビュート)、ある属性が取りうる値の集合をドメイン(定義域)と呼びます。例えば社員表で、1人の社員のデータの行がタプル、「氏名」や「部署」の列が属性、「年齢」の列が取りうる0以上の整数の範囲がドメインです。関係モデルでは、表を行の集合として扱うので、行の順番には意味がなく、まったく同じ行が2つあることも認めません(実際のSQLの表では、主キーを決めないと同じ行が入ることがあります)。

  • A. 正しい。表の1行がタプル(組)です。
  • B. 属性は表の1列のことで、「氏名」のような項目に当たります。
  • C. ドメインは、ある属性が取りうる値の集合のことです。

データベースの基礎のほかの問題

  1. 関係データベースの表で、主キーに指定する列(または列の組)が満たさなければならない条件はどれか。
  2. 社員表(社員番号, メールアドレス, 氏名, 部署)で、社員番号とメールアドレスはどちらも社員ごとに異なり、NULLにならない。氏名と部署は、ほかの社員と同じになることがある。この表の候補キーをすべて挙げたものはどれか。
  3. 履修表(学生番号, 科目番号, 成績)は、どの学生がどの科目を履修し、どんな成績だったかを記録する。1人の学生は複数の科目を履修し、1つの科目は複数の学生が履修する。同じ学生が同じ科目を2回登録することはないとき、この表の主キーとして適切なものはどれか。
  4. 顧客表(顧客ID, 氏名)の主キーは顧客IDで、注文表(注文ID, 顧客ID)の顧客IDは、顧客表の顧客IDを参照する外部キーとして定義されている。顧客表には顧客IDが'C1'と'C2'の行だけがある。この状態で INSERT INTO 注文 VALUES ('O9', 'C5') を実行したときの結果として正しいものはどれか。
  5. SQLの文は、データ定義言語(DDL)、データ操作言語(DML)、データ制御言語(DCL)に分けられる。DDLに分類されるものはどれか。
