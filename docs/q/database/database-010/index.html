データベースの基礎

試験表の点数の列に、80、NULL、70、90 の4つの値がある(NULLは未受験を表す)。SELECT AVG(点数) FROM 試験 の結果はどれか。

  1. A60
  2. B80
  3. CNULL
答えと解説を見る

正解：B. 80

SQLの集約関数(SUM、AVG、MAX、MIN、列を指定したCOUNT)は、NULLを無視して計算します。AVG(点数)は、NULLでない3つの値の平均なので、(80 + 70 + 90) ÷ 3 = 240 ÷ 3 = 80 です。NULLを0とみなして4で割ると 240 ÷ 4 = 60 になりますが、AVGはそのようには計算しません。未受験者を0点として平均したいときは、AVG(COALESCE(点数, 0)) のように、NULLを0に置き換えてから集計します。なお、値がすべてNULLの場合は、AVGの結果はNULLになります。

  • A. NULLを0とみなして4で割った値です。AVGはNULLを無視します。
  • B. 正しい。NULLを除いた3つの値の平均で、240 ÷ 3 = 80 です。
  • C. 1つでもNULLがあると結果がNULLになるのは、+ のような演算の場合です。集約関数はNULLを無視します。

データベースの基礎のほかの問題

  1. 成績表の点数の列に、50、NULL、70、NULL、90、30 の6つの値がある。SELECT COUNT(*), COUNT(点数), AVG(点数) FROM 成績 の結果を順に並べたものはどれか。
  2. 社員表(社員番号, 部署, 給与)から、部署ごとの平均給与が300以上の部署と、その平均給与を求めたい。正しいSQL文はどれか。
  3. 売上表(店舗, 金額)に、(A, 500)、(A, 700)、(B, 300)、(B, 400)、(C, 1200)、(D, 200)、(D, 900) の7行がある。SELECT 店舗, SUM(金額) FROM 売上 GROUP BY 店舗 HAVING SUM(金額) >= 1000 の結果は何行になるか。
  4. 社員表(氏名, 部署, 給与)に8行あり、部署ごとの給与は、営業が320、280、350、開発が400、310、総務が260、300、企画が330である。SELECT 部署, COUNT(*) FROM 社員 WHERE 給与 >= 300 GROUP BY 部署 HAVING COUNT(*) >= 2 の結果は何行になるか。
  5. 社員表(社員番号, 氏名, 部署ID)に4行あり、部署IDは順に10、20、10、NULLである。部署表(部署ID, 部署名)には部署IDが10、20、30の3行がある。SELECT 社員.氏名, 部署.部署名 FROM 社員 INNER JOIN 部署 ON 社員.部署ID = 部署.部署ID の結果は何行になるか。
