データベースの基礎

NoSQLと呼ばれるデータベースのうち、キー・バリュー型の特徴として、一般に正しいものはどれか。

  1. A表どうしの結合や副問い合わせを含む複雑なSQLを、関係データベースより高速に処理できる
  2. Bデータを書き込む前に、すべての列の名前と型をスキーマとして厳密に定義しなければならない
  3. Cキーを指定して値を読み書きする単純な操作に特化しており、複数のサーバに分散して規模を広げやすいが、表の結合のような複雑な問い合わせには向かない
答えと解説を見る

正解：C. キーを指定して値を読み書きする単純な操作に特化しており、複数のサーバに分散して規模を広げやすいが、表の結合のような複雑な問い合わせには向かない

NoSQLは、関係データベース以外のデータベースをまとめて指す言葉で、キー・バリュー型、ドキュメント型、列指向型(ワイドカラム型)、グラフ型などがあります。キー・バリュー型は、キー(識別子)と値の組を保存し、キーを指定して値を取り出すという単純な操作に特化しています。データをキーで分けて複数のサーバに分散しやすいので、アクセスの量が非常に多いWebサービスで、ログイン中の利用者の情報(セッション)などを保存するのに使われます。その一方で、値の中身による検索や、表の結合のような複雑な問い合わせは苦手で、アプリケーションの側で工夫する必要があります。値の形式を前もって厳密に決めておく必要がない(スキーマレス)製品が多いのも特徴です。また、分散した複製の間で、更新がすぐにはそろわない結果整合性を許す製品もあります。

  • A. 結合や副問い合わせを含む複雑な問い合わせは、関係データベースが得意とするものです。
  • B. 値の形式を前もって厳密に決めなくてよい(スキーマレス)製品が多いのが特徴です。
  • C. 正しい。キーによる単純な読み書きと分散のしやすさが特徴で、複雑な問い合わせは苦手です。

データベースの基礎のほかの問題

  1. 複数のサーバにデータの複製を置く分散データベースについての、CAP定理の説明として適切なものはどれか。
  2. 関係データベースの用語で、表(リレーション)の1行に当たるものはどれか。
  3. 関係データベースの表で、主キーに指定する列(または列の組)が満たさなければならない条件はどれか。
  4. 社員表(社員番号, メールアドレス, 氏名, 部署)で、社員番号とメールアドレスはどちらも社員ごとに異なり、NULLにならない。氏名と部署は、ほかの社員と同じになることがある。この表の候補キーをすべて挙げたものはどれか。
  5. 履修表(学生番号, 科目番号, 成績)は、どの学生がどの科目を履修し、どんな成績だったかを記録する。1人の学生は複数の科目を履修し、1つの科目は複数の学生が履修する。同じ学生が同じ科目を2回登録することはないとき、この表の主キーとして適切なものはどれか。
