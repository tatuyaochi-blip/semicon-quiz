データベースの基礎

社員表(氏名, 部署, 給与)に8行あり、部署ごとの給与は、営業が320、280、350、開発が400、310、総務が260、300、企画が330である。SELECT 部署, COUNT(*) FROM 社員 WHERE 給与 >= 300 GROUP BY 部署 HAVING COUNT(*) >= 2 の結果は何行になるか。

  1. A2行
  2. B3行
  3. C4行
答えと解説を見る

正解：A. 2行

まずWHEREで、給与が300以上の行だけを残します。営業は320と350の2行、開発は400と310の2行、総務は300の1行、企画は330の1行が残り、営業の280と総務の260は除かれます。次にGROUP BYで部署ごとにまとめると4グループになり、それぞれの行数は営業2、開発2、総務1、企画1です。最後に HAVING COUNT(*) >= 2 で行数が2以上のグループだけを残すので、営業と開発の2行が結果になります。WHEREを付けずに数えると、営業3、開発2、総務2、企画1となり、HAVINGを満たすのは3行です。WHEREはグループ化の前、HAVINGはグループ化の後に働くという順番が、結果を左右します。

  • A. 正しい。WHEREで絞ったあとに2行以上残る営業と開発の2行です。
  • B. WHEREで給与300未満の行を除く前に数えた場合の結果で、総務が誤って残っています。
  • C. HAVINGで絞る前のグループの数です。

  2. 社員表(社員番号, 氏名, 部署ID)に5行あり、部署IDは順に10、20、10、NULL、NULLである。部署表(部署ID, 部署名)には部署IDが10、20、30の3行がある。SELECT 部署.部署名, 社員.氏名 FROM 部署 LEFT OUTER JOIN 社員 ON 部署.部署ID = 社員.部署ID の結果は何行になるか。
  3. 表Rの列xの値は 1、1、2、3 の4行、表Sの列xの値は 1、1、2、4 の4行である。SELECT * FROM R INNER JOIN S ON R.x = S.x の結果は何行になるか。
  4. 顧客表(顧客ID, 氏名)には (C1, 青木)、(C2, 井上)、(C3, 上田)、(C4, 江藤) の4行がある。注文表(注文ID, 顧客ID, 金額)には (O1, C1, 3000)、(O2, C2, 8000)、(O3, C1, 6000)、(O4, C3, 2000)、(O5, C2, 9000) の5行がある。SELECT 氏名 FROM 顧客 WHERE 顧客ID IN (SELECT 顧客ID FROM 注文 WHERE 金額 > 5000) の結果は何行になるか。
