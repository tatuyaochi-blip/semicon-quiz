サイバー攻撃と防御の実務

クラウドの上で動くバッチの処理に、すべての操作を許可した管理者の権限のアクセスキー(長期間有効な認証情報)を、設定ファイルに書いて渡していた。このキーが漏えいしたときの被害を小さくするための見直しとして、最も適切なものはどれか。

  1. Aアクセスキーの文字列をより長いものに替えて攻撃者に推測されにくくし、権限は今のまま変えずに使い続ける
  2. B処理に必要な操作と対象だけを許可したロールを割り当て、実行環境から自動で発行される、短時間だけ有効な認証情報を使う
  3. Cアクセスキーを設定ファイルからプログラムのソースコードの中に移し、ソースコードと一緒にリポジトリで管理して共有する
答えと解説を見る

正解：B. 処理に必要な操作と対象だけを許可したロールを割り当て、実行環境から自動で発行される、短時間だけ有効な認証情報を使う

すべての操作を許可した長期間有効なキーが漏えいすると、攻撃者はアカウントの中のあらゆる資源を読み出したり、削除したり、新しい資源を作って悪用したりできるので、被害が最も大きくなります。最小権限の原則に沿って、処理に必要な操作と対象だけを許可したロールを割り当て、仮想マシンやコンテナに結び付けたロールから、数時間などで失効する一時的な認証情報を自動で受け取る方式にすると、キーを保存しておく必要もなくなります。あわせて、使われていない権限を定期的に見直し、ふだんと違う操作の呼び出しを監視します。

  • A. キーの長さは推測されにくさの問題で、漏えいしたときの被害の大きさは変わりません。
  • B. 正しい。権限を絞り、短時間で失効する認証情報にすることで、漏えいしたときの被害を小さくします。
  • C. ソースコードに書くと、リポジトリを通じて漏えいしやすくなり、かえって危険です。

サイバー攻撃と防御の実務のほかの問題

  1. 攻撃者が社員のパスワードを入手し、ログインを何十回も繰り返して、社員のスマートフォンに承認を求める通知を大量に送りつけた。社員はわずらわしくなり、つい「承認」を押してしまった。この攻撃への対策として、最も適切なものはどれか。
  2. FIDO2(WebAuthn)のパスキーによる認証が、ワンタイムパスワード(OTP)と比べて、フィッシングに強いとされる理由として、正しいものはどれか。
  3. あるWebサービスで、多数の異なるIPアドレスから、それぞれ別の利用者のIDとパスワードの組で、ログインが大量に試みられ、一部が成功した。試された組の多くは、ほかのサービスから漏えいしたものと一致していた。この攻撃の名前はどれか。
  4. 多要素認証を使っているクラウドのメールサービスで、社員が本物そっくりのログインの画面に誘導され、パスワードとワンタイムパスワードを入力した。攻撃者はその画面を本物のサービスとの中継に使い、ログインの後に発行されたセッションのCookieを盗んで、社員になりすました。この攻撃と対策の説明として、最も適切なものはどれか。
  5. サーバの管理者のアカウントを守るための、特権アクセス管理(PAM)の考え方として、最も適切なものはどれか。
