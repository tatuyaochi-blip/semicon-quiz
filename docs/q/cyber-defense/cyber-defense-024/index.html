サイバー攻撃と防御の実務

組織の防御を確かめる方法のうち、脆弱性スキャン、ペネトレーションテスト、レッドチーム演習の違いの説明として、正しいものはどれか。

  1. A3つとも同じ方法の別の呼び名で、ツールを使って既知の脆弱性を自動で洗い出し、一覧の報告書を作ることを指す
  2. Bスキャンは既知の脆弱性を自動で広く探し、ペネトレーションテストは実際に侵入を試み、レッドチーム演習は検知と対応の力まで評価する
  3. Cレッドチーム演習は、ツールで既知の脆弱性を自動で洗い出すだけの作業で、ペネトレーションテストより対象とする範囲も目的も狭いものである
答えと解説を見る

正解：B. スキャンは既知の脆弱性を自動で広く探し、ペネトレーションテストは実際に侵入を試み、レッドチーム演習は検知と対応の力まで評価する

脆弱性スキャンは、ツールで多くの機器やソフトウェアを調べ、既知の脆弱性や設定の不備を広く洗い出すもので、定期的に繰り返し行います。ペネトレーションテストは、決めた範囲の対象に対して、専門家が脆弱性を組み合わせて実際に侵入できるか、どこまで到達できるかを確かめます。レッドチーム演習は、「顧客の情報を持ち出す」といった目標を決めて、実際の攻撃者の手口(ATT&CKのテクニックなど)をまね、防御の側(ブルーチーム)が気づいて対応できるかまで評価します。いずれも、事前に範囲と方法について組織の許可を得て行います。

  • A. 目的も方法も違います。ツールで既知の脆弱性を洗い出すのは、脆弱性スキャンです。
  • B. 正しい。広く洗い出すスキャン、侵入できるかを確かめるテスト、検知と対応まで試す演習の順に、目的が広がります。
  • C. レッドチーム演習は、攻撃者をまねて組織の検知と対応まで評価するもので、自動のスキャンとは違います。

サイバー攻撃と防御の実務のほかの問題

  1. 外部のセキュリティの研究者が、ある企業の製品に未公表の脆弱性を見つけた。協調された脆弱性の開示(Coordinated Vulnerability Disclosure)の考え方に沿った進め方として、最も適切なものはどれか。
  2. SBOM(ソフトウェア部品表)を作って管理する主な目的として、正しいものはどれか。
  3. ある企業は、社内のパッケージの置き場(プライベートレジストリ)に、社内専用のライブラリ acme-utils を置いて使っている。攻撃者が、公開のパッケージの置き場に、同じ名前 acme-utils でより大きな版番号のパッケージを登録したところ、ビルドの設定によっては、社内のビルドの環境が攻撃者のパッケージを取り込んでしまうことが分かった。この「依存関係の混乱(dependency confusion)」への対策として、最も適切なものはどれか。
  4. 2020年12月に発覚したSolarWinds社の事件では、IT管理用のソフトウェアのビルドの環境に攻撃者が入り込み、正規の更新プログラムに不正なコードが混ぜられた。この更新は、開発元の正規のコード署名が付いた状態で配布された。この事件から得られる教訓として、最も適切なものはどれか。
  5. クラウドのオブジェクトストレージに置いた顧客の情報のファイルが、インターネットの誰からでも読み出せる状態になっていたことが分かった。このような情報の漏えいの典型的な原因と、再発を防ぐ対策の組み合わせとして、適切なものはどれか。
