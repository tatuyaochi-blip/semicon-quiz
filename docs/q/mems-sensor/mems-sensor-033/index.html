MEMS・センサ

スマートウォッチなどで手首から心拍数を測る光学式のセンサの原理として正しいものはどれか。

  1. A皮膚の温度変化を測る
  2. B腕の動きの加速度だけから計算する
  3. CLEDの光を当て、血流の変化による反射光の強さの変化をフォトダイオードで検出する
答えと解説を見る

正解：C. LEDの光を当て、血流の変化による反射光の強さの変化をフォトダイオードで検出する

光学式の心拍センサは、緑色などのLEDの光を皮膚に当て、拍動に合わせて変わる血液の量による反射光の強さの変化をフォトダイオードで検出します(光電容積脈波、PPG)。緑色は血液のヘモグロビンによく吸収されるため変化が大きく出ます。体の動きによる雑音は加速度センサの情報で補正します。赤色と赤外の光の吸収の違いを比べると、血中酸素飽和度(SpO2)も測れます。

  • A. 皮膚の温度変化では拍動をとらえにくいです。
  • B. 加速度センサは動きの補正に使いますが、心拍の検出そのものは光で行います。
  • C. 正しい。反射光の変化をフォトダイオードで検出します。

MEMS・センサのほかの問題

  1. スマートフォンが周囲の明るさに合わせて画面の明るさを自動で調整するために使っているセンサはどれか。
  2. 通話中に顔を近づけると画面を消して誤操作を防ぐために、スマートフォンで使われているセンサの一般的な原理はどれか。
  3. MEMSのアクチュエータとして使われる「くし歯型(コムドライブ)」の駆動原理として正しいものはどれか。
  4. 圧電基板の表面を伝わる弾性波を利用し、スマートフォンなどの高周波フィルタに使われるデバイスはどれか。
  5. 人が近づくと照明を点灯させる人感センサに広く使われている、温度の変化によって電荷が生じる材料を利用したセンサはどれか。
