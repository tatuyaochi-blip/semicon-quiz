MEMS・センサ

ばねとおもりからなるMEMS構造の共振周波数を高くする方法として正しいものはどれか。

  1. Aばねを柔らかくし、おもりを重くする
  2. Bばねを硬くするか、おもりを軽くする
  3. C構造の色を変える
答えと解説を見る

正解：B. ばねを硬くするか、おもりを軽くする

ばね定数k、質量mの構造の共振周波数は f = (1/2π)√(k/m) で表されます。ばねを硬くするか、おもりを軽くすると共振周波数は高くなります。センサーの設計では、感度(柔らかいほど大きく動く)と応答速度や耐衝撃性のバランスを考えて決めます。
