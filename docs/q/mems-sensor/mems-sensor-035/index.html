MEMS・センサ

通話中に顔を近づけると画面を消して誤操作を防ぐために、スマートフォンで使われているセンサの一般的な原理はどれか。

  1. A音の大きさを測る
  2. B地磁気の強さを測る
  3. C赤外線を出し、物体で反射して戻ってくる光の強さを受光素子で検出する
答えと解説を見る

正解：C. 赤外線を出し、物体で反射して戻ってくる光の強さを受光素子で検出する

近接センサは、赤外線LEDなどから940 nm前後の目に見えない光を出し、近くの物体(顔など)で反射して戻ってくる光を受光素子で検出します。反射光が一定以上強ければ物体が近いと判断し、通話中に画面を消してタッチの誤操作を防ぎます。周囲の光の影響を除くため、LEDを点滅させて点灯時と消灯時の差をとります。最近はToF方式で距離を直接測るものもあります。

  • A. 音の大きさで顔の接近を判定するわけではありません。
  • B. 地磁気の測定は電子コンパスの原理です。
  • C. 正しい。赤外線の反射光で物体の近さを検出します。
