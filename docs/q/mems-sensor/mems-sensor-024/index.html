MEMS・センサ

基板の上に積層した薄膜を加工して可動構造をつくるMEMSの加工法はどれか。

  1. Aバルクマイクロマシニング
  2. B表面マイクロマシニング
  3. Cダマシン法
答えと解説を見る

正解：B. 表面マイクロマシニング

表面マイクロマシニングは、犠牲層と構造層の薄膜を基板の上に積み重ねて加工し、最後に犠牲層を除去して構造を浮かせる方法です。基板そのものを深く削って構造をつくる方法はバルクマイクロマシニングといいます。

MEMS・センサのほかの問題

  1. MEMSセンサとその信号処理回路を組み合わせる方法について正しいものはどれか。
  2. MEMS加速度センサが、静止した状態でも約1 Gの加速度を検出する理由として正しいものはどれか。
  3. 加速度センサ、ジャイロ、地磁気センサなどの情報を組み合わせて、より正確な姿勢や動きを求める処理を何と呼ぶか。
  4. クロック源として、水晶振動子の代わりに使われることがあるMEMS発振器の利点として正しいものはどれか。
  5. ガスの流れによってヒーターの熱が運ばれることを利用して、流量を測るMEMSセンサはどれか。
