MEMS・センサ

プロジェクターに使われるDMD(デジタルミラーデバイス)の動作原理として正しいものはどれか。

  1. A液晶分子の向きを変えて光を遮る
  2. B多数の微小なミラーの傾きを個別に切り替え、光の向きを制御する
  3. C画素ごとに有機物を発光させる
答えと解説を見る

正解：B. 多数の微小なミラーの傾きを個別に切り替え、光の向きを制御する

DMDは、数µm角の微小なミラーを画素の数だけ並べたMEMSデバイスで、各ミラーの傾きを静電気力で高速に切り替えて、光をスクリーンに向けるか外すかを制御します。オンの時間の割合で明るさを表現します。

  2. スマートフォンなどの高周波フィルタに使われるBAWフィルタが利用している現象はどれか。
  3. MEMSジャイロなどで可動部を真空中に封止する主な理由として正しいものはどれか。
  4. MEMSの製造中や使用中に、微小な可動部が表面張力などによって基板に張り付き、動かなくなる現象を何と呼ぶか。
  5. 酸化スズなどを使った半導体式ガスセンサの検出原理として正しいものはどれか。
