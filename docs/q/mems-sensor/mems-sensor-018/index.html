MEMS・センサ

MEMSの製造でSOIウエハがよく使われる理由として正しいものはどれか。

  1. ASOIウエハは最も安価なウエハだから
  2. B上部のシリコン層を構造体に、埋め込み酸化膜をエッチングが止まる層や犠牲層として使えるから
  3. CSOIウエハは光を通さないから
答えと解説を見る

正解：B. 上部のシリコン層を構造体に、埋め込み酸化膜をエッチングが止まる層や犠牲層として使えるから

SOIウエハでは、上部の単結晶シリコン層の厚さが正確にそろっているため、そのまま可動構造の材料に使えます。深掘りエッチングは埋め込み酸化膜で止まり、その酸化膜を除去すれば構造体を浮かせることもできるため、MEMSの製造に便利です。

MEMS・センサのほかの問題

  1. MEMSの封止などで、シリコンとガラスを加熱しながら電圧をかけて接合する方法を何と呼ぶか。
  2. 自動車のLiDARなどで、レーザー光を走査するために使われるMEMSデバイスはどれか。
  3. ばねとおもりからなるMEMS構造の共振周波数を高くする方法として正しいものはどれか。
  4. 自動車のエアバッグの作動判定に使われてきたMEMSセンサはどれか。
  5. SiO2の犠牲層を除去してMEMS構造を浮かせるとき、スティクションを防ぐために使われる方法として適切なものはどれか。
