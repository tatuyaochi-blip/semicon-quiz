MEMS・センサ

MEMSセンサとその信号処理回路を組み合わせる方法について正しいものはどれか。

  1. A組み合わせることはできない
  2. B必ず同じチップに集積しなければならない
  3. C同じチップに集積する方法と、別々のチップを1つのパッケージに収める方法がある
答えと解説を見る

正解：C. 同じチップに集積する方法と、別々のチップを1つのパッケージに収める方法がある

MEMSと信号処理回路を同じチップにつくり込むと寄生容量が小さく小型化できますが、両方の工程を両立させる必要があり複雑です。それぞれ最適なプロセスでチップをつくり、1つのパッケージに並べたり重ねたりする方法も広く使われ、多くのスマートフォン用センサはこの方式です。最近は、MEMSウエハとCMOSウエハを貼り合わせて一体化する方法も使われています。

MEMS・センサのほかの問題

  1. MEMS加速度センサが、静止した状態でも約1 Gの加速度を検出する理由として正しいものはどれか。
  2. 加速度センサ、ジャイロ、地磁気センサなどの情報を組み合わせて、より正確な姿勢や動きを求める処理を何と呼ぶか。
  3. クロック源として、水晶振動子の代わりに使われることがあるMEMS発振器の利点として正しいものはどれか。
  4. ガスの流れによってヒーターの熱が運ばれることを利用して、流量を測るMEMSセンサはどれか。
  5. 機械的な接点の開閉で高周波信号を切り替えるRF MEMSスイッチの利点として正しいものはどれか。
