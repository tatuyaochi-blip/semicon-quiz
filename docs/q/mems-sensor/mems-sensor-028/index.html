MEMS・センサ

クロック源として、水晶振動子の代わりに使われることがあるMEMS発振器の利点として正しいものはどれか。

  1. A周波数の安定性が水晶より必ず高い
  2. B半導体プロセスでつくれるため小型で衝撃に強く、ICと一体化しやすい
  3. Cサイズが大きく、扱いやすい
答えと解説を見る

正解：B. 半導体プロセスでつくれるため小型で衝撃に強く、ICと一体化しやすい

MEMS発振器は、シリコンの微小な振動子と駆動・温度補償の回路を組み合わせたもので、半導体プロセスで量産できます。小型で衝撃や振動に強く、パッケージにまとめやすいため、一部の用途で水晶振動子の代わりに使われています。

MEMS・センサのほかの問題

  2. 機械的な接点の開閉で高周波信号を切り替えるRF MEMSスイッチの利点として正しいものはどれか。
  3. 温度によって電気抵抗が大きく変わる性質を利用した温度センサはどれか。
  4. MEMSでつくられる可動構造の大きさの目安として最も適切なものはどれか。
  5. スマートウォッチなどで手首から心拍数を測る光学式のセンサの原理として正しいものはどれか。
