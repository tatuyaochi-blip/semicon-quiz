MEMS・センサ

表面マイクロマシニングで構造層に使うポリシリコンなどの薄膜で、内部に大きな残留応力があるとどのような問題が起こるか。

  1. A膜の抵抗がゼロになる
  2. B犠牲層を除去して浮かせたときに、構造が反ったり座屈したりする
  3. C膜が透明になる
答えと解説を見る

正解：B. 犠牲層を除去して浮かせたときに、構造が反ったり座屈したりする

成膜時にできる残留応力が大きいと、犠牲層を除去して構造を浮かせたときに、圧縮応力の両持ち梁は座屈して波打ち、厚さ方向に応力の分布があると片持ち梁が反ります。設計どおりの形や共振周波数にならず、電極に触れて動かなくなることもあります。ポリシリコンでは成膜温度やアニールで応力を数十MPa以下に制御し、窒化膜では組成で引っ張り応力に調整します。

  • A. 抵抗がゼロになるわけではありません。
  • B. 正しい。反りや座屈が起こります。
  • C. 応力によって膜が透明になるわけではありません。

MEMS・センサのほかの問題

  1. MEMSの静電アクチュエータで、2枚の平行な電極の間に加える電圧を2倍にすると、電極間に働く静電引力はおよそ何倍になるか。(電極の間隔は変わらないとする)
  2. MEMS加速度センサの仕様で、測定範囲(例えば ±2 G と ±16 G)の選び方として正しい考え方はどれか。
  3. 平行平板型の静電アクチュエータで、電圧を上げていくと、可動電極がある位置を超えたところで急に固定電極に引き寄せられて張り付く現象を何と呼ぶか。
  4. MEMSジャイロスコープのバイアス安定性(出力のゆっくりとした変動)を評価するのに広く使われる手法はどれか。
  5. MEMSの可動板が、すぐ近くの固定面に向かって動くときに、間にある気体が押し出されることで生じる減衰を何と呼ぶか。
