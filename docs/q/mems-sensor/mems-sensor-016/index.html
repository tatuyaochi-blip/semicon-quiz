MEMS・センサ

スマートフォンの電子コンパスに使われるセンサが検出するものはどれか。

  1. A地磁気の向き
  2. B気圧
  3. C周囲の明るさ
答えと解説を見る

正解：A. 地磁気の向き

電子コンパスは、ホール素子や磁気抵抗素子などの磁気センサで地磁気を3軸で測定し、方位を求めます。加速度センサで求めた傾きと組み合わせることで、端末をどのように持っていても正しい方位を計算できます。

MEMS・センサのほかの問題

  1. スマートフォンのMEMS気圧センサで、気圧の変化から推定できる情報として正しいものはどれか。
  2. MEMSの製造でSOIウエハがよく使われる理由として正しいものはどれか。
  3. MEMSの封止などで、シリコンとガラスを加熱しながら電圧をかけて接合する方法を何と呼ぶか。
  4. 自動車のLiDARなどで、レーザー光を走査するために使われるMEMSデバイスはどれか。
  5. ばねとおもりからなるMEMS構造の共振周波数を高くする方法として正しいものはどれか。
