MEMS・センサ

MEMSの可動板が、すぐ近くの固定面に向かって動くときに、間にある気体が押し出されることで生じる減衰を何と呼ぶか。

  1. A誘電緩和
  2. Bスクイーズフィルムダンピング
  3. Cクーロン摩擦
答えと解説を見る

正解：B. スクイーズフィルムダンピング

可動板と固定面のすき間が狭いと、板が動くたびにすき間の気体が押し出されたり吸い込まれたりして、大きな粘性の抵抗が生じます。これをスクイーズフィルムダンピングといい、加速度センサの応答の調整に利用される一方、共振器のQ値を下げる原因になります。穴を開けたり真空に封止したりして調整します。

  • A. 誘電緩和は誘電体の分極の応答の遅れです。
  • B. 正しい。すき間の気体の出入りによる減衰です。
  • C. クーロン摩擦は接触面の固体摩擦です。

MEMS・センサのほかの問題

  1. 非常に小さなMEMSの加速度センサやジャイロで、分解能の限界の一つになる、おもりが周囲の気体分子などとの熱的なやりとりでランダムに揺れることによる雑音はどれか。
  2. 微小な片持ち梁や水晶振動子の表面に物質が付着すると共振周波数が変わることを利用して、ごくわずかな質量を検出する方法として正しい説明はどれか。
  3. MEMSの説明として正しいものはどれか。
  4. 静電容量式のMEMS加速度センサが加速度を検出する原理として正しいものはどれか。
  5. MEMSの製造で使われる犠牲層エッチングの目的として正しいものはどれか。
