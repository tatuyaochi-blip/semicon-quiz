MEMS・センサ

半導体圧力センサなどに利用されるピエゾ抵抗効果の説明として正しいものはどれか。

  1. A機械的な応力が加わると、材料の電気抵抗率が変化する効果
  2. B光を当てると電圧が生じる効果
  3. C磁界によって電流の向きが曲げられる効果
答えと解説を見る

正解：A. 機械的な応力が加わると、材料の電気抵抗率が変化する効果

シリコンは応力が加わると結晶のバンド構造が変わり、抵抗率が金属のひずみゲージより数十倍大きく変化します(ピエゾ抵抗効果)。圧力を受けて変形する薄いダイヤフラムの縁に4つの抵抗をつくり込み、ホイートストンブリッジで抵抗変化を検出すると、圧力を電気信号に変換できます。自動車のエンジンやタイヤの圧力、血圧計、気圧計などに使われ、温度補償が設計の鍵です。
