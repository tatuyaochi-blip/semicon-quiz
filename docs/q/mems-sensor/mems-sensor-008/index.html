MEMS・センサ

MEMSマイクロフォンで音を電気信号に変える代表的な方式はどれか。

  1. A音で発熱する抵抗の温度変化を検出する
  2. B音で発光する素子の光量を検出する
  3. C音圧で振動する膜と固定電極の間の静電容量の変化を検出する
答えと解説を見る

正解：C. 音圧で振動する膜と固定電極の間の静電容量の変化を検出する

一般的なMEMSマイクロフォンは、音圧で振動する薄い膜(ダイヤフラム)と、穴のあいた固定電極(バックプレート)でコンデンサを構成し、膜の振動による静電容量の変化を電気信号に変えます。小型で量産性が高く、スマートフォンなどに広く使われています。

MEMS・センサのほかの問題

  1. 一定電流を流したシリコンPN接合の順方向電圧の温度依存性として正しいものはどれか。
  2. プロジェクターに使われるDMD(デジタルミラーデバイス)の動作原理として正しいものはどれか。
  3. MEMS技術でつくられるインクジェットプリンタのヘッドの一般的なインク吐出方式はどれか。
  4. スマートフォンなどの高周波フィルタに使われるBAWフィルタが利用している現象はどれか。
  5. MEMSジャイロなどで可動部を真空中に封止する主な理由として正しいものはどれか。
