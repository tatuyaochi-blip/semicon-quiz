MEMS・センサ

スマートフォンの画面内指紋センサや医療用の超音波診断に使われることがある、MEMSでつくる超音波素子はどれか。

  1. AVCSEL
  2. BCCD
  3. CPMUT・CMUT(微細加工超音波トランスデューサ)
答えと解説を見る

正解：C. PMUT・CMUT(微細加工超音波トランスデューサ)

PMUT(圧電型)とCMUT(静電容量型)は、MEMS技術でつくる超音波の送受信素子で、薄い膜を振動させて超音波を出し、反射してきた超音波を検出します。従来の厚い圧電セラミックの素子と比べて、半導体の工程で多数の素子を細かいピッチのアレイに並べ、回路と一体化できます。スマートフォンの画面内超音波指紋センサや、手のひらサイズの超音波診断装置、距離センサなどに使われます。

  • A. VCSELは面発光型の半導体レーザーです。
  • B. CCDは光を検出するイメージセンサです。
  • C. 正しい。MEMSでつくる超音波トランスデューサです。

MEMS・センサのほかの問題

  1. 表面マイクロマシニングで構造層に使うポリシリコンなどの薄膜で、内部に大きな残留応力があるとどのような問題が起こるか。
  2. MEMSの静電アクチュエータで、2枚の平行な電極の間に加える電圧を2倍にすると、電極間に働く静電引力はおよそ何倍になるか。(電極の間隔は変わらないとする)
  3. MEMS加速度センサの仕様で、測定範囲(例えば ±2 G と ±16 G)の選び方として正しい考え方はどれか。
  4. 平行平板型の静電アクチュエータで、電圧を上げていくと、可動電極がある位置を超えたところで急に固定電極に引き寄せられて張り付く現象を何と呼ぶか。
  5. MEMSジャイロスコープのバイアス安定性(出力のゆっくりとした変動)を評価するのに広く使われる手法はどれか。
