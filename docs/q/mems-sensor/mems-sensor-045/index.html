MEMS・センサ

MEMS加速度センサの仕様で、測定範囲(例えば ±2 G と ±16 G)の選び方として正しい考え方はどれか。

  1. A測定範囲を広くすると大きな衝撃まで測れるが、同じビット数では分解能は粗くなる
  2. B測定範囲を広くするほど、必ず分解能も細かくなる
  3. C測定範囲はセンサの消費電力だけを決める
答えと解説を見る

正解：A. 測定範囲を広くすると大きな衝撃まで測れるが、同じビット数では分解能は粗くなる

同じビット数で出力する場合、測定範囲を広くすると1 LSBあたりの加速度が大きくなり、細かい変化は区別しにくくなります。歩数計や傾き検出には狭い範囲で高分解能、衝突や落下の検出には広い範囲というように、用途に合わせて選びます。多くのセンサは範囲を切り替えられます。

  • A. 正しい。範囲と分解能はトレードオフです。
  • B. 範囲を広げると、同じビット数では分解能は粗くなります。
  • C. 測定範囲は分解能や測れる大きさに関係します。

MEMS・センサのほかの問題

  1. 平行平板型の静電アクチュエータで、電圧を上げていくと、可動電極がある位置を超えたところで急に固定電極に引き寄せられて張り付く現象を何と呼ぶか。
  2. MEMSジャイロスコープのバイアス安定性(出力のゆっくりとした変動)を評価するのに広く使われる手法はどれか。
  3. MEMSの可動板が、すぐ近くの固定面に向かって動くときに、間にある気体が押し出されることで生じる減衰を何と呼ぶか。
  4. 非常に小さなMEMSの加速度センサやジャイロで、分解能の限界の一つになる、おもりが周囲の気体分子などとの熱的なやりとりでランダムに揺れることによる雑音はどれか。
  5. 微小な片持ち梁や水晶振動子の表面に物質が付着すると共振周波数が変わることを利用して、ごくわずかな質量を検出する方法として正しい説明はどれか。
