MEMS・センサ

スマートフォンが周囲の明るさに合わせて画面の明るさを自動で調整するために使っているセンサはどれか。

  1. A気圧センサ
  2. B照度センサ(環境光センサ)
  3. Cジャイロスコープ
答えと解説を見る

正解：B. 照度センサ(環境光センサ)

照度センサは、フォトダイオードで周囲の明るさ(照度、ルクス)を測るセンサです。シリコンは赤外線にも反応するため、フィルタや複数の受光素子の組み合わせで人の目の感度(視感度、緑の555 nm付近が最大)に近い特性にしています。測った明るさに応じて画面の輝度を調整し、見やすさと省電力を両立します。最近は色温度も測り、画面の色味を合わせる機能もあります。

  • A. 気圧センサは気圧から高度の変化などを推定するセンサです。
  • B. 正しい。周囲の明るさを測るセンサです。
  • C. ジャイロスコープは回転の速さ(角速度)を測るセンサです。

MEMS・センサのほかの問題

  1. 通話中に顔を近づけると画面を消して誤操作を防ぐために、スマートフォンで使われているセンサの一般的な原理はどれか。
  2. MEMSのアクチュエータとして使われる「くし歯型(コムドライブ)」の駆動原理として正しいものはどれか。
  3. 圧電基板の表面を伝わる弾性波を利用し、スマートフォンなどの高周波フィルタに使われるデバイスはどれか。
  4. 人が近づくと照明を点灯させる人感センサに広く使われている、温度の変化によって電荷が生じる材料を利用したセンサはどれか。
  5. MEMSの「エネルギーハーベスティング(環境発電)」の例として正しいものはどれか。
