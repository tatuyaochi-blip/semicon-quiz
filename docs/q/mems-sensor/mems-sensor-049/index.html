MEMS・センサ

非常に小さなMEMSの加速度センサやジャイロで、分解能の限界の一つになる、おもりが周囲の気体分子などとの熱的なやりとりでランダムに揺れることによる雑音はどれか。

  1. A熱機械雑音(ブラウン雑音)
  2. Bクロック雑音
  3. C量子化雑音
答えと解説を見る

正解：A. 熱機械雑音(ブラウン雑音)

有限の温度では、おもりは周囲の気体分子の衝突などで常にランダムに揺れています。この熱機械雑音(ブラウン雑音)は加速度に換算すると √(4kTω₀/(mQ)) で表され、おもりが軽いほど、またダンピングが大きい(Qが低い)ほど大きくなります。そのため小型化するほど不利になり、高精度のセンサではおもりを重く(大きく)し、真空封止でQを高めて雑音を下げます。

  • A. 正しい。熱による機械的な揺れの雑音です。
  • B. クロック雑音はセンサの機械部分の基本的な限界ではありません。
  • C. 量子化雑音はAD変換で生じる雑音です。
