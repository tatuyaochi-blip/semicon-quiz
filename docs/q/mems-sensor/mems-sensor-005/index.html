MEMS・センサ

ホール効果を利用したセンサ(ホール素子)で主に検出するものはどれか。

  1. A温度
  2. B磁界
  3. C湿度
答えと解説を見る

正解：B. 磁界

電流が流れている半導体に垂直に磁界をかけると、キャリアがローレンツ力で曲げられ、電流と磁界の両方に垂直な方向に電圧(ホール電圧)が生じます。ホール素子はこの電圧から磁界を検出し、ブラシレスモーターの回転位置の検出、非接触の電流センサ、スマートフォンのカバーの開閉検知などに使われます。移動度の大きいInSbやGaAsが高感度で、CMOSに集積したシリコンのものもあります。
