MEMS・センサ

MEMSの製造で使われる犠牲層エッチングの目的として正しいものはどれか。

  1. Aウエハを薄くして軽くする
  2. B配線の抵抗を下げる
  3. C構造体の下にある層を取り除き、可動部を基板から浮かせる
答えと解説を見る

正解：C. 構造体の下にある層を取り除き、可動部を基板から浮かせる

犠牲層エッチングでは、あとで取り除く前提の層(犠牲層、例えばSiO2)の上に構造体の膜をつくり、最後に犠牲層だけを選択的にエッチングで除去します。こうすることで、基板から浮いた梁や膜などの可動構造をつくれます。
