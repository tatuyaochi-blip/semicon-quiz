MEMS・センサ

室内の二酸化炭素(CO2)濃度の測定によく使われるNDIR方式のガスセンサの原理として正しいものはどれか。

  1. ACO2の重さを直接はかる
  2. BCO2が特定の波長の赤外線を吸収することを利用し、透過した赤外線の量から濃度を求める
  3. CCO2が電気を流すことを利用する
答えと解説を見る

正解：B. CO2が特定の波長の赤外線を吸収することを利用し、透過した赤外線の量から濃度を求める

NDIR(非分散型赤外線吸収)方式は、CO2が波長約4.3 µmの赤外線を強く吸収する性質を利用します。光源からの赤外線がガスを通る間にどれだけ弱まったかを、その波長だけを通すフィルタをつけた検出器で測り、ランベルト・ベールの法則から濃度を求めます。ほかのガスに反応しにくく長期間安定しているため、換気の管理(1000 ppm以下が目安)、農業用ハウス、空調の制御に使われます。

  • A. 重さを直接はかる方式ではありません。
  • B. 正しい。赤外線の吸収量からCO2の濃度を求めます。
  • C. CO2の電気伝導を利用する方式ではありません。

MEMS・センサのほかの問題

  1. スマートフォンの画面内指紋センサや医療用の超音波診断に使われることがある、MEMSでつくる超音波素子はどれか。
  2. 表面マイクロマシニングで構造層に使うポリシリコンなどの薄膜で、内部に大きな残留応力があるとどのような問題が起こるか。
  3. MEMSの静電アクチュエータで、2枚の平行な電極の間に加える電圧を2倍にすると、電極間に働く静電引力はおよそ何倍になるか。(電極の間隔は変わらないとする)
  4. MEMS加速度センサの仕様で、測定範囲(例えば ±2 G と ±16 G)の選び方として正しい考え方はどれか。
  5. 平行平板型の静電アクチュエータで、電圧を上げていくと、可動電極がある位置を超えたところで急に固定電極に引き寄せられて張り付く現象を何と呼ぶか。
