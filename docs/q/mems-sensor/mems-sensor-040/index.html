MEMS・センサ

微小な流路をチップ上につくり、少量の液体で化学分析や検査を行う技術はどれか。

  1. Aマイクロ流体デバイス(ラボオンチップ)
  2. Bフォトマスク
  3. Cボンディングワイヤ
答えと解説を見る

正解：A. マイクロ流体デバイス(ラボオンチップ)

マイクロ流体デバイスは、MEMSの加工技術でチップ上に幅数十〜数百µmの流路や混合部、反応部をつくり、ごく少量の試料で分析や検査を行うものです。ラボオンチップとも呼ばれ、医療の迅速診断や遺伝子解析などに使われています。

  • A. 正しい。チップ上の微小な流路で分析を行います。
  • B. フォトマスクは露光で回路パターンを転写するための原版です。
  • C. ボンディングワイヤはチップと端子を結ぶ細い金属線です。

MEMS・センサのほかの問題

  1. 室内の二酸化炭素(CO2)濃度の測定によく使われるNDIR方式のガスセンサの原理として正しいものはどれか。
  2. スマートフォンの画面内指紋センサや医療用の超音波診断に使われることがある、MEMSでつくる超音波素子はどれか。
  3. 表面マイクロマシニングで構造層に使うポリシリコンなどの薄膜で、内部に大きな残留応力があるとどのような問題が起こるか。
  4. MEMSの静電アクチュエータで、2枚の平行な電極の間に加える電圧を2倍にすると、電極間に働く静電引力はおよそ何倍になるか。(電極の間隔は変わらないとする)
  5. MEMS加速度センサの仕様で、測定範囲(例えば ±2 G と ±16 G)の選び方として正しい考え方はどれか。
