MEMS・センサ

自動車のエアバッグの作動判定に使われてきたMEMSセンサはどれか。

  1. A加速度センサ
  2. BMEMSマイクロフォン
  3. CDMD
答えと解説を見る

正解：A. 加速度センサ

衝突時の急激な減速を加速度センサで検出し、その大きさや時間変化からエアバッグを展開するかを判定します。MEMS加速度センサは小型で信頼性が高く、安価に大量生産できるため、自動車への搭載をきっかけに普及が進みました。

この分野を解く 分野ページへ

MEMS・センサのほかの問題

  1. SiO2の犠牲層を除去してMEMS構造を浮かせるとき、スティクションを防ぐために使われる方法として適切なものはどれか。
  2. 基板の上に積層した薄膜を加工して可動構造をつくるMEMSの加工法はどれか。
  3. MEMSセンサとその信号処理回路を組み合わせる方法について正しいものはどれか。
  4. MEMS加速度センサが、静止した状態でも約1 Gの加速度を検出する理由として正しいものはどれか。
  5. 加速度センサ、ジャイロ、地磁気センサなどの情報を組み合わせて、より正確な姿勢や動きを求める処理を何と呼ぶか。
