MEMS・センサ

MEMSの製造で使われるDeep RIE(ボッシュプロセス)の説明として正しいものはどれか。

  1. A薬液で等方的にエッチングする
  2. Bエッチングと側壁保護膜の堆積を交互に繰り返し、深く垂直な穴や溝を加工する
  3. Cウエハを研磨して薄くする
答えと解説を見る

正解：B. エッチングと側壁保護膜の堆積を交互に繰り返し、深く垂直な穴や溝を加工する

ボッシュプロセスでは、SF6などによるシリコンのエッチングと、C4F8などによる保護膜の堆積を短い周期で交互に繰り返します。側壁は保護膜で守られ、底面だけが進むため、アスペクト比の高い深く垂直な構造をつくれます。MEMSやTSVの加工に使われます。
