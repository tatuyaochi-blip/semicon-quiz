MEMS・センサ

酸化スズなどを使った半導体式ガスセンサの検出原理として正しいものはどれか。

  1. Aガスの温度で発光する
  2. Bガスによって音が変化する
  3. C検出対象のガスが表面に吸着・反応して、センサー材料の電気抵抗が変化する
答えと解説を見る

正解：C. 検出対象のガスが表面に吸着・反応して、センサー材料の電気抵抗が変化する

半導体式ガスセンサでは、加熱した酸化スズなどの表面に酸素が吸着して電子を捕らえ、抵抗が高い状態になっています。可燃性ガスなどがあると吸着酸素と反応して電子が戻り、抵抗が下がります。この抵抗変化でガスを検出します。

MEMS・センサのほかの問題

  1. スマートフォンの電子コンパスに使われるセンサが検出するものはどれか。
  2. スマートフォンのMEMS気圧センサで、気圧の変化から推定できる情報として正しいものはどれか。
  3. MEMSの製造でSOIウエハがよく使われる理由として正しいものはどれか。
  4. MEMSの封止などで、シリコンとガラスを加熱しながら電圧をかけて接合する方法を何と呼ぶか。
  5. 自動車のLiDARなどで、レーザー光を走査するために使われるMEMSデバイスはどれか。
