MEMS・センサ

酸化スズなどを使った半導体式ガスセンサの検出原理として正しいものはどれか。

  1. Aガスの温度で発光する
  2. Bガスによって音が変化する
  3. C検出対象のガスが表面に吸着・反応して、センサー材料の電気抵抗が変化する
答えと解説を見る

正解：C. 検出対象のガスが表面に吸着・反応して、センサー材料の電気抵抗が変化する

半導体式ガスセンサでは、300〜400 ℃程度に加熱した酸化スズ(n型半導体)の表面に酸素が吸着して電子を捕らえ、粒子の境界に障壁ができて抵抗が高くなっています。可燃性ガスや還元性ガスがあると吸着酸素と反応して電子が戻り、抵抗が下がります。1960年代に日本で実用化され、ガス漏れ警報器に広く使われています。安価で高感度な反面、ガスの種類の区別は苦手です。
