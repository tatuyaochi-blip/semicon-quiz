MEMS・センサ

平行平板型の静電アクチュエータで、電圧を上げていくと、可動電極がある位置を超えたところで急に固定電極に引き寄せられて張り付く現象を何と呼ぶか。

  1. Aピエゾ効果
  2. B共振
  3. Cプルイン
答えと解説を見る

正解：C. プルイン

電極間の静電引力は間隔が狭くなるほど急に強くなるため、ばねの復元力とのつり合いが保てなくなる点があります。平行平板ではこの点が初期の間隔の約1/3だけ動いたところで、それを超えると可動電極は一気に引き寄せられます。これをプルインといい、可動範囲の制限やスイッチの設計で考慮されます。

  • A. ピエゾ効果は、圧電体に力を加えると電荷が生じる(またはその逆の)現象です。
  • B. 共振は、特定の周波数で振動が大きくなる現象です。
  • C. 正しい。つり合いが崩れて急に引き寄せられる現象です。

  3. 非常に小さなMEMSの加速度センサやジャイロで、分解能の限界の一つになる、おもりが周囲の気体分子などとの熱的なやりとりでランダムに揺れることによる雑音はどれか。
  4. 微小な片持ち梁や水晶振動子の表面に物質が付着すると共振周波数が変わることを利用して、ごくわずかな質量を検出する方法として正しい説明はどれか。
  5. MEMSの説明として正しいものはどれか。
