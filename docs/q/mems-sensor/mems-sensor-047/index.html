MEMS・センサ

MEMSジャイロスコープのバイアス安定性(出力のゆっくりとした変動)を評価するのに広く使われる手法はどれか。

  1. Aアラン分散(アラン偏差)の解析
  2. BC-V測定
  3. C四探針法
答えと解説を見る

正解：A. アラン分散(アラン偏差)の解析

アラン分散は、静止状態で数時間記録した出力を、さまざまな平均時間τで区切り、隣り合う区間の平均値の差のばらつきを調べる手法です。両対数グラフの傾きから、短い時間で支配的なランダム雑音(角度ランダムウォーク、傾き−1/2)や、底の部分に現れるバイアス不安定性(°/h)などの成分を分けて評価できます。ジャイロや加速度センサ、発振器の性能比較の標準的な方法です。

  • A. 正しい。アラン分散で雑音とバイアス変動を評価します。
  • B. C-V測定はMOS構造などの容量を評価する方法です。
  • C. 四探針法は薄膜やウエハの抵抗率を測る方法です。

MEMS・センサのほかの問題

  2. 非常に小さなMEMSの加速度センサやジャイロで、分解能の限界の一つになる、おもりが周囲の気体分子などとの熱的なやりとりでランダムに揺れることによる雑音はどれか。
  3. 微小な片持ち梁や水晶振動子の表面に物質が付着すると共振周波数が変わることを利用して、ごくわずかな質量を検出する方法として正しい説明はどれか。
  4. MEMSの説明として正しいものはどれか。
  5. 静電容量式のMEMS加速度センサが加速度を検出する原理として正しいものはどれか。
