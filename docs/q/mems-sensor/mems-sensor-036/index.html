MEMS・センサ

MEMSのアクチュエータとして使われる「くし歯型(コムドライブ)」の駆動原理として正しいものはどれか。

  1. Aかみ合ったくし歯状の電極の間に電圧を加えたときの静電引力
  2. B磁石とコイルの電磁力
  3. C熱による膨張
答えと解説を見る

正解：A. かみ合ったくし歯状の電極の間に電圧を加えたときの静電引力

くし歯型アクチュエータは、互いにかみ合ったくし歯状の固定電極と可動電極の間に電圧を加え、静電引力で可動部を動かします。くし歯の数を増やすと力を大きくでき、移動量に対して力がほぼ一定になるのが特徴です。共振型のジャイロや光スイッチなどに使われます。

  • A. 正しい。くし歯状の電極間の静電引力で動かします。
  • B. 電磁力を使う電磁駆動とは別の方式です。
  • C. 熱膨張を使う熱駆動とは別の方式です。

  2. 人が近づくと照明を点灯させる人感センサに広く使われている、温度の変化によって電荷が生じる材料を利用したセンサはどれか。
  3. MEMSの「エネルギーハーベスティング(環境発電)」の例として正しいものはどれか。
  4. 微小な流路をチップ上につくり、少量の液体で化学分析や検査を行う技術はどれか。
  5. 室内の二酸化炭素(CO2)濃度の測定によく使われるNDIR方式のガスセンサの原理として正しいものはどれか。
