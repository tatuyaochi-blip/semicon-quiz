MEMS・センサ

人が近づくと照明を点灯させる人感センサに広く使われている、温度の変化によって電荷が生じる材料を利用したセンサはどれか。

  1. A焦電型赤外線センサ
  2. Bホール素子
  3. Cひずみゲージ
答えと解説を見る

正解：A. 焦電型赤外線センサ

焦電型赤外線センサは、温度が変化すると表面に電荷が現れる焦電体(PZTやタンタル酸リチウムなど)を使い、人体が出す波長約10 µmの赤外線の量の変化を検出します。温度の変化にだけ反応するため、人が動いたときに信号が出て、静止した人は検出しにくい特徴があります。フレネルレンズで視野を区切って動きを捉え、照明、トイレ、エアコン、防犯装置の人感センサに使われます。

  • A. 正しい。焦電効果で赤外線の変化を検出します。
  • B. ホール素子は磁界を検出するセンサです。
  • C. ひずみゲージは変形による抵抗変化を測るセンサです。

MEMS・センサのほかの問題

  1. MEMSの「エネルギーハーベスティング(環境発電)」の例として正しいものはどれか。
  2. 微小な流路をチップ上につくり、少量の液体で化学分析や検査を行う技術はどれか。
  3. 室内の二酸化炭素(CO2)濃度の測定によく使われるNDIR方式のガスセンサの原理として正しいものはどれか。
  4. スマートフォンの画面内指紋センサや医療用の超音波診断に使われることがある、MEMSでつくる超音波素子はどれか。
  5. 表面マイクロマシニングで構造層に使うポリシリコンなどの薄膜で、内部に大きな残留応力があるとどのような問題が起こるか。
