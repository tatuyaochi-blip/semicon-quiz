MEMS・センサ

スマートフォンなどの高周波フィルタに使われるBAWフィルタが利用している現象はどれか。

  1. Aホール効果
  2. B圧電薄膜の機械的な共振
  3. Cゼーベック効果
答えと解説を見る

正解：B. 圧電薄膜の機械的な共振

BAW(バルク弾性波)フィルタは、窒化アルミニウムなどの圧電薄膜を電極で挟んだ共振器を使います。電気信号で膜が厚さ方向に振動し、特定の周波数で共振する性質を利用して、必要な周波数帯の信号だけを通します。

MEMS・センサのほかの問題

  1. MEMSジャイロなどで可動部を真空中に封止する主な理由として正しいものはどれか。
  2. MEMSの製造中や使用中に、微小な可動部が表面張力などによって基板に張り付き、動かなくなる現象を何と呼ぶか。
  3. 酸化スズなどを使った半導体式ガスセンサの検出原理として正しいものはどれか。
  4. スマートフォンの電子コンパスに使われるセンサが検出するものはどれか。
  5. スマートフォンのMEMS気圧センサで、気圧の変化から推定できる情報として正しいものはどれか。
