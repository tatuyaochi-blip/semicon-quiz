MEMS・センサ

MEMS技術でつくられるインクジェットプリンタのヘッドの一般的なインク吐出方式はどれか。

  1. A重力でインクを自然に落とす
  2. Bインクを帯電させて磁石で引き寄せる
  3. C圧電素子の変形や、ヒーターの加熱で生じる気泡の圧力でインクを押し出す
答えと解説を見る

正解：C. 圧電素子の変形や、ヒーターの加熱で生じる気泡の圧力でインクを押し出す

インクジェットヘッドには、圧電素子に電圧をかけて変形させ、その圧力でインクを押し出すピエゾ方式(エプソンなど)と、ヒーターでインクを数µsで300 ℃以上に加熱して気泡をつくり、その圧力で押し出すサーマル方式(キヤノン、HPなど)があります。直径数十µmのノズル数千個と流路がMEMS技術でつくられ、数pLの液滴を吐出します。印刷のほか、ディスプレイの製造などにも応用されています。

MEMS・センサのほかの問題

  1. スマートフォンなどの高周波フィルタに使われるBAWフィルタが利用している現象はどれか。
  2. MEMSジャイロなどで可動部を真空中に封止する主な理由として正しいものはどれか。
  3. MEMSの製造中や使用中に、微小な可動部が表面張力などによって基板に張り付き、動かなくなる現象を何と呼ぶか。
  4. 酸化スズなどを使った半導体式ガスセンサの検出原理として正しいものはどれか。
  5. スマートフォンの電子コンパスに使われるセンサが検出するものはどれか。
