MEMS・センサ

機械的な接点の開閉で高周波信号を切り替えるRF MEMSスイッチの利点として正しいものはどれか。

  1. A半導体スイッチより必ず高速である
  2. B接点がないため摩耗がまったくない
  3. C挿入損失が小さく、信号のひずみが少ない切り替えができる
答えと解説を見る

正解：C. 挿入損失が小さく、信号のひずみが少ない切り替えができる

RF MEMSスイッチは、微小な可動電極を機械的に動かして接点を開閉するため、オン時の抵抗やオフ時の容量が小さく、挿入損失や信号のひずみを小さくできます。一方、切り替え速度は半導体スイッチより遅く、接点の寿命や信頼性が課題になります。

MEMS・センサのほかの問題

  1. 温度によって電気抵抗が大きく変わる性質を利用した温度センサはどれか。
  2. MEMSでつくられる可動構造の大きさの目安として最も適切なものはどれか。
  3. スマートウォッチなどで手首から心拍数を測る光学式のセンサの原理として正しいものはどれか。
  4. スマートフォンが周囲の明るさに合わせて画面の明るさを自動で調整するために使っているセンサはどれか。
  5. 通話中に顔を近づけると画面を消して誤操作を防ぐために、スマートフォンで使われているセンサの一般的な原理はどれか。
