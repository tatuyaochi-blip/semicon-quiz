MEMS・センサ

MEMSでつくられる可動構造の大きさの目安として最も適切なものはどれか。

  1. A数メートル
  2. B数マイクロメートル〜数ミリメートル
  3. C数ピコメートル
答えと解説を見る

正解：B. 数マイクロメートル〜数ミリメートル

MEMSは、半導体の微細加工技術を使って、マイクロメートルからミリメートル程度の大きさの機械構造(ばね、おもり、膜、ミラーなど)を電子回路とともにつくる技術です。原子の大きさ(数十〜数百ピコメートル)よりはるかに大きく、肉眼で見える部品よりは小さい大きさです。

  • A. 数メートルは一般の機械の大きさです。
  • B. 正しい。マイクロメートル〜ミリメートルの大きさです。
  • C. 数ピコメートルは原子の大きさより小さく、構造はつくれません。

MEMS・センサのほかの問題

  1. スマートウォッチなどで手首から心拍数を測る光学式のセンサの原理として正しいものはどれか。
  2. スマートフォンが周囲の明るさに合わせて画面の明るさを自動で調整するために使っているセンサはどれか。
  3. 通話中に顔を近づけると画面を消して誤操作を防ぐために、スマートフォンで使われているセンサの一般的な原理はどれか。
  4. MEMSのアクチュエータとして使われる「くし歯型(コムドライブ)」の駆動原理として正しいものはどれか。
  5. 圧電基板の表面を伝わる弾性波を利用し、スマートフォンなどの高周波フィルタに使われるデバイスはどれか。
