MEMS・センサ

スマートフォンのMEMS気圧センサで、気圧の変化から推定できる情報として正しいものはどれか。

  1. A周囲の明るさ
  2. B地磁気の向き
  3. C高さの変化(建物の階数など)
答えと解説を見る

正解：C. 高さの変化(建物の階数など)

気圧は高さが上がるほど下がり、地表付近では約10 m上がるごとに約1.2 hPa下がります。高精度のMEMS気圧センサは約±0.05 hPa(高さ約50 cm相当)の変化まで分解できるため、ナビゲーションで建物の階数を判定したり、登った階段の数を数えたり、緊急通報で高さを伝えたりできます。天気による気圧変化と区別するため、短時間の変化を見るなどの処理を行います。
