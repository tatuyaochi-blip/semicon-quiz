MEMS・センサ

MEMSの静電アクチュエータで、2枚の平行な電極の間に加える電圧を2倍にすると、電極間に働く静電引力はおよそ何倍になるか。(電極の間隔は変わらないとする)

  1. A1/2倍
  2. B2倍
  3. C4倍
答えと解説を見る

正解：C. 4倍

平行平板の電極間に働く静電引力は、F = εAV² / (2d²) と表され、電圧Vの2乗に比例します。そのため電圧を2倍にすると力は4倍になります。静電アクチュエータで大きな力を得るには高い電圧が必要になるのはこのためです。

  • A. 電圧を上げると力は大きくなります。
  • B. 力は電圧に比例するのではなく、電圧の2乗に比例します。
  • C. 正しい。2² = 4倍になります。

MEMS・センサのほかの問題

  1. MEMS加速度センサの仕様で、測定範囲(例えば ±2 G と ±16 G)の選び方として正しい考え方はどれか。
  2. 平行平板型の静電アクチュエータで、電圧を上げていくと、可動電極がある位置を超えたところで急に固定電極に引き寄せられて張り付く現象を何と呼ぶか。
  3. MEMSジャイロスコープのバイアス安定性(出力のゆっくりとした変動)を評価するのに広く使われる手法はどれか。
  4. MEMSの可動板が、すぐ近くの固定面に向かって動くときに、間にある気体が押し出されることで生じる減衰を何と呼ぶか。
  5. 非常に小さなMEMSの加速度センサやジャイロで、分解能の限界の一つになる、おもりが周囲の気体分子などとの熱的なやりとりでランダムに揺れることによる雑音はどれか。
