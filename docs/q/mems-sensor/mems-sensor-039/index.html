MEMS・センサ

MEMSの「エネルギーハーベスティング(環境発電)」の例として正しいものはどれか。

  1. Aコンセントから電力を得る
  2. B周囲の振動を圧電体などで電気に変え、センサの電源にする
  3. C電池を並列につないで容量を増やす
答えと解説を見る

正解：B. 周囲の振動を圧電体などで電気に変え、センサの電源にする

エネルギーハーベスティングは、周囲の振動・熱・光・電波などの微小なエネルギーを電気に変えて利用する技術です。MEMSの圧電素子で機械の振動を電気に変えると、得られるのはµW〜mW程度ですが、間欠的に動作する低消費電力の無線センサなら十分に動かせます。工場の設備の振動監視、橋などの構造物の監視、電池交換の難しい場所のIoTセンサなどで使われ始めています。

  • A. コンセントからの給電は環境発電ではありません。
  • B. 正しい。周囲の振動などを電気に変えて使います。
  • C. 電池を並べるのは環境発電ではありません。

MEMS・センサのほかの問題

  1. 微小な流路をチップ上につくり、少量の液体で化学分析や検査を行う技術はどれか。
  2. 室内の二酸化炭素(CO2)濃度の測定によく使われるNDIR方式のガスセンサの原理として正しいものはどれか。
  3. スマートフォンの画面内指紋センサや医療用の超音波診断に使われることがある、MEMSでつくる超音波素子はどれか。
  4. 表面マイクロマシニングで構造層に使うポリシリコンなどの薄膜で、内部に大きな残留応力があるとどのような問題が起こるか。
  5. MEMSの静電アクチュエータで、2枚の平行な電極の間に加える電圧を2倍にすると、電極間に働く静電引力はおよそ何倍になるか。(電極の間隔は変わらないとする)
