MEMS・センサ

MEMSジャイロなどで可動部を真空中に封止する主な理由として正しいものはどれか。

  1. A空気の抵抗(ダンピング)を減らし、振動を大きく保って感度を高めるため
  2. B可動部を重くするため
  3. Cセンサーの色を変えるため
答えと解説を見る

正解：A. 空気の抵抗(ダンピング)を減らし、振動を大きく保って感度を高めるため

振動型のMEMSジャイロでは、可動部を大きく安定して振動させるほど感度が高くなります。空気があると抵抗で振動が弱まるため、ウエハレベルでの接合などにより内部を真空に封止して、共振の鋭さ(Q値)を高めています。

  3. スマートフォンの電子コンパスに使われるセンサが検出するものはどれか。
  4. スマートフォンのMEMS気圧センサで、気圧の変化から推定できる情報として正しいものはどれか。
  5. MEMSの製造でSOIウエハがよく使われる理由として正しいものはどれか。
