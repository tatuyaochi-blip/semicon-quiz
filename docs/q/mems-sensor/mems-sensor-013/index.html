MEMS・センサ

MEMSジャイロなどで可動部を真空中に封止する主な理由として正しいものはどれか。

  1. A空気の抵抗(ダンピング)を減らし、振動を大きく保って感度を高めるため
  2. B可動部を重くするため
  3. Cセンサーの色を変えるため
答えと解説を見る

正解：A. 空気の抵抗(ダンピング)を減らし、振動を大きく保って感度を高めるため

振動型のMEMSジャイロでは、可動部を大きく安定して振動させるほど、コリオリ力による信号が大きくなり感度が上がります。空気があると抵抗(ダンピング)で振動が弱まるため、ウエハどうしを接合してMEMSの部分を真空に封止し、共振のQ値を数千〜数万に高めています。一方、加速度センサは適度なダンピングが必要なため、ガスを封入します。用途で封止の圧力を使い分けます。
