MEMS・センサ

一定電流を流したシリコンPN接合の順方向電圧の温度依存性として正しいものはどれか。

  1. A温度が上がると約2 mV/℃ずつ小さくなる
  2. B温度が上がると大きくなる
  3. C温度によらず一定である
答えと解説を見る

正解：A. 温度が上がると約2 mV/℃ずつ小さくなる

シリコンのPN接合の順方向電圧は、一定電流のもとで温度が1 ℃上がるごとに約2 mV小さくなります。この性質はLSI内蔵の温度センサに利用されています。また、電圧の温度変化を打ち消すように組み合わせたものがバンドギャップ基準電圧回路です。

MEMS・センサのほかの問題

  1. プロジェクターに使われるDMD(デジタルミラーデバイス)の動作原理として正しいものはどれか。
  2. MEMS技術でつくられるインクジェットプリンタのヘッドの一般的なインク吐出方式はどれか。
  3. スマートフォンなどの高周波フィルタに使われるBAWフィルタが利用している現象はどれか。
  4. MEMSジャイロなどで可動部を真空中に封止する主な理由として正しいものはどれか。
  5. MEMSの製造中や使用中に、微小な可動部が表面張力などによって基板に張り付き、動かなくなる現象を何と呼ぶか。
