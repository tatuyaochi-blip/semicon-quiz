MEMS・センサ

微小な片持ち梁や水晶振動子の表面に物質が付着すると共振周波数が変わることを利用して、ごくわずかな質量を検出する方法として正しい説明はどれか。

  1. A付着した質量が増えると共振周波数が上がる
  2. B付着した質量が増えると共振周波数が下がり、その変化量から質量を求める
  3. C共振周波数は質量に関係しない
答えと解説を見る

正解：B. 付着した質量が増えると共振周波数が下がり、その変化量から質量を求める

共振周波数は √(k/m) に比例するため、表面に物質が付着して質量mが増えると周波数は下がり、小さな変化なら Δf/f ≈ −Δm/(2m) です。振動子が小さく軽いほど、わずかな質量変化で周波数が大きく変わり、ナノメートル級の梁では1個の分子に近い質量も検出できます。水晶振動子マイクロバランス(QCM)は蒸着装置の膜厚モニターとして広く使われ、ガスや生体分子のセンサにも応用されています。

  • A. 質量が増えると共振周波数は下がります。
  • B. 正しい。周波数の低下から付着した質量を求めます。
  • C. 共振周波数は質量に依存します。

MEMS・センサのほかの問題

  1. MEMSの説明として正しいものはどれか。
  2. 静電容量式のMEMS加速度センサが加速度を検出する原理として正しいものはどれか。
  3. MEMSの製造で使われる犠牲層エッチングの目的として正しいものはどれか。
  4. 半導体圧力センサなどに利用されるピエゾ抵抗効果の説明として正しいものはどれか。
  5. ホール効果を利用したセンサ(ホール素子)で主に検出するものはどれか。
