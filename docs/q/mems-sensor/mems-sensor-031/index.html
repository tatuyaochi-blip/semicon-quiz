MEMS・センサ

温度によって電気抵抗が大きく変わる性質を利用した温度センサはどれか。

  1. Aサーミスタ
  2. Bホール素子
  3. Cフォトダイオード
答えと解説を見る

正解：A. サーミスタ

サーミスタは、金属酸化物の焼結体などでつくられ、温度によって抵抗値が大きく変化する素子です。温度が上がると抵抗が下がるNTCサーミスタが代表的で、電池の温度監視や家電の温度制御などに広く使われています。

  • A. 正しい。抵抗の温度変化を利用した温度センサです。
  • B. ホール素子は磁界を検出するセンサです。
  • C. フォトダイオードは光を検出するセンサです。

MEMS・センサのほかの問題

  1. MEMSでつくられる可動構造の大きさの目安として最も適切なものはどれか。
  2. スマートウォッチなどで手首から心拍数を測る光学式のセンサの原理として正しいものはどれか。
  3. スマートフォンが周囲の明るさに合わせて画面の明るさを自動で調整するために使っているセンサはどれか。
  4. 通話中に顔を近づけると画面を消して誤操作を防ぐために、スマートフォンで使われているセンサの一般的な原理はどれか。
  5. MEMSのアクチュエータとして使われる「くし歯型(コムドライブ)」の駆動原理として正しいものはどれか。
