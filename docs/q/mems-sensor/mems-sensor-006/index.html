MEMS・センサ

振動型のMEMSジャイロスコープが角速度を検出するために利用している力はどれか。

  1. Aコリオリ力
  2. Bクーロン力のみ
  3. C浮力
答えと解説を見る

正解：A. コリオリ力

振動している物体が回転すると、振動方向と回転軸の両方に垂直な方向に、速度と角速度に比例するコリオリ力がはたらきます。MEMSジャイロは、おもりを数kHz〜数十kHzで共振させておき、回転によって直交方向に生じる微小な変位を静電容量などで検出して角速度を求めます。カメラの手ぶれ補正、スマートフォンの姿勢検出、車の横滑り防止、ドローンの制御などに使われます。

  1. MEMSの製造で使われるDeep RIE(ボッシュプロセス)の説明として正しいものはどれか。
  2. MEMSマイクロフォンで音を電気信号に変える代表的な方式はどれか。
  3. 一定電流を流したシリコンPN接合の順方向電圧の温度依存性として正しいものはどれか。
  4. プロジェクターに使われるDMD(デジタルミラーデバイス)の動作原理として正しいものはどれか。
  5. MEMS技術でつくられるインクジェットプリンタのヘッドの一般的なインク吐出方式はどれか。
