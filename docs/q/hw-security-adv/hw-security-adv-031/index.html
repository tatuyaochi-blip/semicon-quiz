ハードウェアセキュリティの最新動向

暗号モジュールの認証の基準であるFIPS 140-3のセキュリティレベル1〜4について、物理的な安全性の要求の説明として、正しいものはどれか。

  1. Aレベル1が最も厳しい要求で、数字が大きくなるほど要求は緩くなり、レベル4はソフトウェアだけでできた暗号モジュールのためのレベルである
  2. Bレベルは使える暗号の鍵の長さで決まり、レベル3はAES-192、レベル4はAES-256を使うことを意味し、物理的な安全性の要求は含まない
  3. Cレベル2は開けた跡が残ること、レベル3は開けにくくして検知したら鍵を消すこと、レベル4は外装全体での侵入の検知や電圧・温度の異常への対策まで求める
答えと解説を見る

正解：C. レベル2は開けた跡が残ること、レベル3は開けにくくして検知したら鍵を消すこと、レベル4は外装全体での侵入の検知や電圧・温度の異常への対策まで求める

FIPS 140-3は米国のNISTが定める暗号モジュールの基準で、国際規格ISO/IEC 19790をもとにしており、FIPS 140-2の後継として2020年に認証の受け付けが始まりました。レベル1では製品として普通の品質の部品であればよく、レベル2では開けた跡が残る封印やコーティング、レベル3では開けたり探ったりしにくくし、検知したら鍵などの重要な値を消すこと、レベル4では外装の全体で侵入を検知することや、電圧や温度が範囲を外れたときの保護が求められます。認証の対象は物理的な安全性だけでなく、暗号のアルゴリズムの正しい実装、鍵の管理、自己テストなどにも及びます。HSMやセキュリティチップを調達する条件として、レベルの指定がよく使われます。

  • A. 逆です。数字が大きいほど要求が厳しくなります。
  • B. レベルは鍵の長さではなく、物理的な安全性や利用者の認証の方法などの要求の厳しさを表します。
  • C. 正しい。数字が大きいほど、物理的な攻撃への対策の要求が強くなります。

ハードウェアセキュリティの最新動向のほかの問題

  1. セキュリティ製品を評価する国際規格であるコモンクライテリア(ISO/IEC 15408)のEAL(評価保証レベル)が表すものとして、正しいものはどれか。
  2. IoT機器向けのセキュリティの認証の枠組みであるPSA CertifiedやSESIPで重視されている、合成(コンポジション)の考え方として、正しいものはどれか。
  3. 出荷した製品のデバッグのポートを、メーカーの技術者だけが開けるようにする、認証付きのデバッグの設計として、最も適切なものはどれか。
  4. セキュリティチップのライフサイクルの状態を、テスト、本番(プロダクション)、故障品の解析(RMA)などに分けて管理する。本番の状態から故障の解析のためにRMAの状態に移すときの扱いとして、適切なものはどれか。
  5. スキャンテストのためのスキャンチェーンが、暗号の処理を行うチップで攻撃の経路になりうる理由と、その対策の組み合わせとして、正しいものはどれか。
