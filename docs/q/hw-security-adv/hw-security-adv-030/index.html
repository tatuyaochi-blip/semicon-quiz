ハードウェアセキュリティの最新動向

チップの層を1枚ずつ削って電子顕微鏡で撮影したり、X線で内部を撮影したりして回路を読み取る逆解析を前提にしたとき、設計の考え方として適切なものはどれか。

  1. AマスクROMの値や配線の形は画像から読み取られうるので、秘密の鍵は回路の形に作り込まず、機器ごとに違う値にして物理的な対策と合わせて守る
  2. B回路の配置を十分に複雑にしておけば、画像から回路を読み取られることはないので、すべての機器に共通の秘密の鍵をマスクROMに書いてよい
  3. CX線ではチップの内部の回路は写らないので、層を削られないようにチップの表面を硬い膜で覆っておけば、逆解析への対策として十分である
答えと解説を見る

正解：A. マスクROMの値や配線の形は画像から読み取られうるので、秘密の鍵は回路の形に作り込まず、機器ごとに違う値にして物理的な対策と合わせて守る

マスクROMの値は、トランジスタや接点の有無として回路の形に作り込まれるので、層を削って撮影すれば読み取れます。また、同じマスクで作ったすべてのチップに同じ値が入るので、1つを解析されれば全部の機器の秘密が漏れます。2020年代には、X線の撮影でチップを壊さずに内部の配線を細かく撮る研究も報告されています。そのため、秘密は回路の形に頼らず機器ごとに違う値にし、eFuseのように書き込んだ跡が見えうる記憶では、PUFから作った鍵で暗号化して置くなどの工夫をして、読み出しの経路を限り、耐タンパ性の対策と組み合わせます。

  • A. 正しい。回路の形に秘密を頼らず、機器ごとの鍵と物理的な対策で守ります。
  • B. 配置を複雑にしても、時間と費用をかければ読み取られます。形を隠すことに秘密を頼るのは危険です。
  • C. X線でも内部の構造を撮影できることが示されており、表面を硬くするだけでは不十分です。

ハードウェアセキュリティの最新動向のほかの問題

  1. 暗号モジュールの認証の基準であるFIPS 140-3のセキュリティレベル1〜4について、物理的な安全性の要求の説明として、正しいものはどれか。
  2. セキュリティ製品を評価する国際規格であるコモンクライテリア(ISO/IEC 15408)のEAL(評価保証レベル)が表すものとして、正しいものはどれか。
  3. IoT機器向けのセキュリティの認証の枠組みであるPSA CertifiedやSESIPで重視されている、合成(コンポジション)の考え方として、正しいものはどれか。
  4. 出荷した製品のデバッグのポートを、メーカーの技術者だけが開けるようにする、認証付きのデバッグの設計として、最も適切なものはどれか。
  5. セキュリティチップのライフサイクルの状態を、テスト、本番(プロダクション)、故障品の解析(RMA)などに分けて管理する。本番の状態から故障の解析のためにRMAの状態に移すときの扱いとして、適切なものはどれか。
