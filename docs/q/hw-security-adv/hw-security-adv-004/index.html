ハードウェアセキュリティの最新動向

機密コンピューティングで、利用者の検証サーバ(検証者)が、VM型のTEEから受け取ったアテステーションの報告を確かめてから、データを復号する鍵を渡す。検証者が確かめる内容の組み合わせとして、最も適切なものはどれか。

  1. A署名がCPUのメーカーの鍵につながること、起動時の測定値が期待どおりであること、TCBの版が修正済み以上であること、検証者が送ったノンスを含むこと
  2. B報告の署名が本物のCPUのメーカーの鍵につながっていれば、中で動くソフトウェアも安全といえるので、測定値や版の番号までは確かめなくてよい
  3. C報告に書かれた仮想マシンの名前やIPアドレス、メモリの容量が、クラウドの事業者と契約したときの内容と一致していること
答えと解説を見る

正解：A. 署名がCPUのメーカーの鍵につながること、起動時の測定値が期待どおりであること、TCBの版が修正済み以上であること、検証者が送ったノンスを含むこと

署名の確認で分かるのは、報告が本物のTEEから出たことだけです。中で何が起動したかは測定値を正しいと分かっている値と比べて確かめ、検証者が送ったノンスが含まれていることで、今作られた報告でありリプレイではないことを確かめます。さらに、脆弱性が修正される前のファームウェアやマイクロコードで動くTEEも正しく署名された報告を出せるので、報告に含まれるTCBの版(セキュリティの版の番号)が修正済みの版以上であることも確かめます。報告に通信用の公開鍵のハッシュ値を含めておけば、渡す鍵がその仮想マシンの中だけに届くようにできます。

  • A. 正しい。出どころ、中身、版、新しさのすべてを確かめます。
  • B. 署名が正しくても、期待と違うソフトウェアや、修正前の古いファームウェアで動いていることがあります。
  • C. 名前やアドレス、容量は、TEEが本物かどうかや、中で何が動いているかを示しません。

ハードウェアセキュリティの最新動向のほかの問題

  1. 2020年代半ば時点で、データセンター向けの一部のGPUは、CPUのTEEと組み合わせて機密コンピューティングに使える機能を備えている。この仕組みの考え方として、正しいものはどれか。
  2. Arm CCA(Confidential Compute Architecture)で導入されたレルム(Realm)の説明として、正しいものはどれか。
  3. CHERIと呼ばれる命令セットの拡張で使われるケイパビリティの説明として、正しいものはどれか。
  4. ArmのMTE(メモリタギング拡張)では、メモリの16バイトごとに4ビットのタグを付け、ポインタの上位のビットにも4ビットのタグを入れて、アクセスのたびに両者が一致するかをCPUが確かめる。解放した領域を指す古いポインタで、その領域にアクセスする誤りを考える。領域を割り当て直したときの新しいタグが16通りから一様にランダムに選ばれるとすると、タグが偶然一致して誤りを見逃す確率はどれか。
  5. Armのポインタ認証(PAC)の仕組みとして、正しいものはどれか。
