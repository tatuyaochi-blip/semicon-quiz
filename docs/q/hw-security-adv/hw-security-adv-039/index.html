ハードウェアセキュリティの最新動向

ある故障注入の試みが1回で成功する確率が0.1%で、各回の結果は互いに独立とする。1,000回試みたとき、少なくとも1回成功する確率として、最も近いものはどれか。

  1. A約0.1%
  2. B約63%
  3. C100%
答えと解説を見る

正解：B. 約63%

1回も成功しない確率は (1 − 0.001)¹⁰⁰⁰ ≈ e⁻¹ ≈ 0.368 なので、少なくとも1回成功する確率は 1 − 0.368 ≈ 0.632、約63%です。1回あたりの成功率が低くても、自動で何千回も試せる攻撃では、成功はかなり確かなものになります。そのため対策では、1回の成功率を下げるだけでなく、異常を何回か検知したら鍵を消す、試みの回数を数えて制限する、といった仕組みを組み合わせます。単純に 0.1% × 1,000 = 100% とするのは、成功が重なる場合を二重に数えた誤りです。

  • A. 1回だけ試みたときの確率です。
  • B. 正しい。1 − 0.999¹⁰⁰⁰ ≈ 63% です。
  • C. 0.1% × 1,000 と単純に掛けた値で、確率の計算としては誤りです。

ハードウェアセキュリティの最新動向のほかの問題

  1. ファームウェアの署名の確認を、故障注入の1回の試みで飛ばされる確率が1/1,000であるとする。同じ確認を2か所で行い、両方を飛ばさないと攻撃が成功しないようにした。1回の試みで2か所を同時に狙えて、それぞれが飛ばされるのは互いに独立に確率1/1,000で起きるとき、攻撃が成功するまでの試みの回数の期待値はどれか。
  2. 機密コンピューティングで使われるTEEのうち、仮想マシン全体を守るVM型のもの(AMD SEV-SNP、Intel TDXなど)と、アプリケーションの一部を守るエンクレーブ型のもの(Intel SGXなど)の違いの説明として、正しいものはどれか。
  3. VM型のTEEで、仮想マシンのメモリを暗号化するだけでは不十分とされ、AMDのSEV-SNPのようにメモリの完全性を守る仕組みが加えられた理由として、正しいものはどれか。
  4. メモリの暗号化に、改ざんの検出とリプレイの防止を加える回路を考える。64バイトのキャッシュラインごとに、8バイトのMAC(改ざんを検出するための符号)と、書き込みのたびに増える8バイトのカウンタを主記憶に保存するとする。カウンタを守るための木の分は考えないとき、保護するデータの量に対して、余分に必要な記憶容量の割合はどれか。
  5. 機密コンピューティングで、利用者の検証サーバ(検証者)が、VM型のTEEから受け取ったアテステーションの報告を確かめてから、データを復号する鍵を渡す。検証者が確かめる内容の組み合わせとして、最も適切なものはどれか。
