ハードウェアセキュリティの最新動向

故障注入攻撃のうち、レーザを使う方法と電磁パルスを使う方法の特徴の組み合わせとして、正しいものはどれか。

  1. Aレーザは開封したチップに裏側から近赤外光を当てることが多く、狙う場所を細かく選べる。電磁パルスはコイルで加え、開封せずに使えることもあるが、狙える範囲は比較的広い
  2. Bレーザはパッケージの樹脂を透過するので、チップを開封しなくても狙った1個のトランジスタに当てられる。電磁パルスは、チップを削って配線を露出させないと使えない
  3. Cレーザも電磁パルスも、チップの一部の温度を急に上げて配線やトランジスタを溶かすことで、元に戻らない故障を起こさせて回路の働きを変える方法である
答えと解説を見る

正解：A. レーザは開封したチップに裏側から近赤外光を当てることが多く、狙う場所を細かく選べる。電磁パルスはコイルで加え、開封せずに使えることもあるが、狙える範囲は比較的広い

シリコンのバンドギャップは約1.12 eVで、波長が約1.1 µmより長い光はほとんど吸収されません。1 µm付近の近赤外光は吸収が弱いので、薄くした基板の裏側から奥まで届き、トランジスタの近くで一部が吸収されて電子と正孔の対を作ります。表側は多くの金属の配線の層で覆われているので、レーザ故障注入では裏側から当てるのが一般的で、光が作る電流で特定のトランジスタやSRAMのセルを狙って誤動作させます。電磁パルスでは、コイルに大きな電流を短く流して強い磁場の変化を起こし、チップの中の配線や電源網に電圧を生じさせて誤動作させます。対策として、光や電磁場を検知するセンサ、重要な計算の二重化、誤りを検知したら鍵を消す仕組みなどを組み合わせます。

  • A. 正しい。レーザは狙いの細かさ、電磁パルスは開封しなくてよい手軽さに特徴があります。
  • B. レーザは一般に開封が必要で、電磁パルスは開封せずに使えることがあり、説明が逆に近くなっています。
  • C. どちらも熱で溶かすのではなく、電荷や誘起した電圧で、一時的な誤動作を起こさせます。

ハードウェアセキュリティの最新動向のほかの問題

  1. ある故障注入の試みが1回で成功する確率が0.1%で、各回の結果は互いに独立とする。1,000回試みたとき、少なくとも1回成功する確率として、最も近いものはどれか。
  2. ファームウェアの署名の確認を、故障注入の1回の試みで飛ばされる確率が1/1,000であるとする。同じ確認を2か所で行い、両方を飛ばさないと攻撃が成功しないようにした。1回の試みで2か所を同時に狙えて、それぞれが飛ばされるのは互いに独立に確率1/1,000で起きるとき、攻撃が成功するまでの試みの回数の期待値はどれか。
  3. 機密コンピューティングで使われるTEEのうち、仮想マシン全体を守るVM型のもの(AMD SEV-SNP、Intel TDXなど)と、アプリケーションの一部を守るエンクレーブ型のもの(Intel SGXなど)の違いの説明として、正しいものはどれか。
  4. VM型のTEEで、仮想マシンのメモリを暗号化するだけでは不十分とされ、AMDのSEV-SNPのようにメモリの完全性を守る仕組みが加えられた理由として、正しいものはどれか。
  5. メモリの暗号化に、改ざんの検出とリプレイの防止を加える回路を考える。64バイトのキャッシュラインごとに、8バイトのMAC(改ざんを検出するための符号)と、書き込みのたびに増える8バイトのカウンタを主記憶に保存するとする。カウンタを守るための木の分は考えないとき、保護するデータの量に対して、余分に必要な記憶容量の割合はどれか。
