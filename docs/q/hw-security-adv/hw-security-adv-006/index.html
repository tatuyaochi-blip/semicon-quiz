ハードウェアセキュリティの最新動向

Arm CCA(Confidential Compute Architecture)で導入されたレルム(Realm)の説明として、正しいものはどれか。

  1. Aノーマルワールドとセキュアワールドに加えて、仮想マシンを動かすためのレルムという世界を設け、ハイパーバイザは資源を割り当てても中身には触れられないようにする
  2. BTrustZoneのセキュアワールドの名前を変えただけのもので、スマートフォンの指紋の照合や決済などの小さな処理を、機器のメーカーが用意したOSでそこで行う
  3. Cレルムの中のプログラムはハードウェアによる保護を受けず、ゲストOSが自分でメモリの内容をソフトウェアで暗号化することだけで守られる
答えと解説を見る

正解：A. ノーマルワールドとセキュアワールドに加えて、仮想マシンを動かすためのレルムという世界を設け、ハイパーバイザは資源を割り当てても中身には触れられないようにする

TrustZoneのセキュアワールドは、機器のメーカーが用意する小さな信頼できるOSのためのもので、利用者が自分の仮想マシンを動かす用途には向いていませんでした。CCAでは、ノーマルとセキュアに加えて、レルムと、世界の切り替えを管理するルートの世界を設けます。メモリの各領域がどの世界のものかをCPUが表(グラニュール保護テーブル)で確かめるので、ノーマルワールドで動くハイパーバイザは、レルムの仮想マシンにメモリやCPUの時間を割り当てても、中身を読み書きできません。AMD SEV-SNPやIntel TDXと同じく、VM型のTEEをArmのアーキテクチャで実現するための仕組みです。

  • A. 正しい。資源を管理する権利と、中身に触れる権利を分けます。
  • B. レルムはセキュアワールドとは別の世界で、利用者の仮想マシンを動かすためのものです。
  • C. レルムのメモリは、CPUが世界ごとのアクセスを確かめることで、ハードウェアで守られます。

ハードウェアセキュリティの最新動向のほかの問題

  1. CHERIと呼ばれる命令セットの拡張で使われるケイパビリティの説明として、正しいものはどれか。
  2. ArmのMTE(メモリタギング拡張)では、メモリの16バイトごとに4ビットのタグを付け、ポインタの上位のビットにも4ビットのタグを入れて、アクセスのたびに両者が一致するかをCPUが確かめる。解放した領域を指す古いポインタで、その領域にアクセスする誤りを考える。領域を割り当て直したときの新しいタグが16通りから一様にランダムに選ばれるとすると、タグが偶然一致して誤りを見逃す確率はどれか。
  3. Armのポインタ認証(PAC)の仕組みとして、正しいものはどれか。
  4. IntelのCET(制御フロー強制技術)などで採用されているハードウェアのシャドウスタックの説明として、正しいものはどれか。
  5. 制御フロー完全性をハードウェアで支える機能について、関数からの戻りを守るものと、関数ポインタなどによる間接的な呼び出しやジャンプを守るものの組み合わせとして、正しいものはどれか。
