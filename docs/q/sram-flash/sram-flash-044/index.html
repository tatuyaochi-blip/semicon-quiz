SRAM・フラッシュメモリ

高速なSSDとホストの接続に広く使われている、PCI Expressを利用したインターフェース規格はどれか。

  1. AIDE
  2. BUSB 1.1
  3. CNVMe
答えと解説を見る

正解：C. NVMe

NVMe(NVM Express)は、PCI Express上でフラッシュメモリを効率よく扱うために設計されたインターフェース規格です。多数のコマンドキューを並列に扱えるため、HDD向けに設計されたSATA(AHCI)より低遅延・高帯域を実現できます。

  • A. IDEは古いHDD向けの並列インターフェースです。
  • B. USB 1.1は低速な汎用インターフェースです。
  • C. 正しい。PCIeを使う高速SSD向けの規格です。

SRAM・フラッシュメモリのほかの問題

  1. SRAMで、待機中に電源電圧を下げてリーク電流を減らすときの下限を決める「データ保持電圧」の説明として正しいものはどれか。
  2. 6T SRAMセルで、読み出し時にセルの内容が反転しない(読み出し破壊を防ぐ)ために必要な設計として正しいものはどれか。
  3. 低電圧でのSRAMの書き込み失敗を防ぐ「書き込みアシスト」の例として正しいものはどれか。
  4. 多値(MLCやTLC)のNANDフラッシュで、隣り合うしきい値電圧の状態に割り当てるビットの並びを、1ビットだけ異なるようにする理由として正しいものはどれか。
  5. 3D NANDで、積み重ねた各層のワード線に配線をつなぐために、端部を階段状に加工した構造を何と呼ぶか。
