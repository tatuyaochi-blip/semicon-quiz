SRAM・フラッシュメモリ

マイコンのプログラムを格納するために、ロジック回路と同じチップに混載されてきた不揮発メモリはどれか。

  1. A組み込みフラッシュメモリ
  2. BHBM
  3. CGDDR
答えと解説を見る

正解：A. 組み込みフラッシュメモリ

マイコンには、プログラムやデータを格納する組み込みフラッシュメモリがロジック回路と同じチップに混載されてきました。電源を切っても内容が残り、書き換えもできます。先端プロセスでは混載が難しくなり、MRAMなどへの置き換えも進んでいます。

  2. フラッシュメモリの性質として正しいものはどれか。
  3. USBメモリやSDカードに主に使われているメモリはどれか。
  4. SLC(Single-Level Cell)型のフラッシュメモリは、1つのセルに何ビットを記憶するか。
  5. HDD(ハードディスク)と比べたときのSSDの特徴として正しいものはどれか。
