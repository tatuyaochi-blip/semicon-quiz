SRAM・フラッシュメモリ

QLC(1セル4ビット)のNANDフラッシュで、1つのセルが区別しなければならないしきい値電圧の状態の数はいくつか。

  1. A4
  2. B8
  3. C16
答えと解説を見る

正解：C. 16

1セルにNビットを記憶するには、2ᴺ個のしきい値電圧の状態を区別する必要があります。QLCでは 2⁴ = 16 状態です。SLCは2状態、MLCは4状態、TLCは8状態です。状態が増えるほど各状態の間隔が狭くなり、読み書きの精度が求められます。

SRAM・フラッシュメモリのほかの問題

  1. TLCやQLCのSSDで、一部の領域をSLCとして使い、書き込みを一時的に受け止める仕組みの主な目的はどれか。
  2. SRAMの電源電圧を下げていくと起こりやすい問題として正しいものはどれか。
  3. 6T SRAMに読み出し専用のトランジスタを追加した8T SRAMセルの利点として正しいものはどれか。
  4. フラッシュメモリの消去で、フローティングゲートなどから電子を引き抜くと、セルのしきい値電圧はどうなるか。
  5. 近年の3D NANDの積層数として最も近いものはどれか。
