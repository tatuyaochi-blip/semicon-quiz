SRAM・フラッシュメモリ

SRAMの電源電圧を下げていくと起こりやすい問題として正しいものはどれか。

  1. A読み書きの安定性の余裕(ノイズマージン)が小さくなり、誤動作しやすくなる
  2. Bアクセスが速くなりすぎる
  3. C記憶容量が増える
答えと解説を見る

正解：A. 読み書きの安定性の余裕(ノイズマージン)が小さくなり、誤動作しやすくなる

SRAMセルはラッチの安定性と、アクセストランジスタとの駆動力のバランスで動作しています。電源電圧を下げるとノイズマージンが小さくなり、トランジスタのばらつきが相対的に効いて、読み出し時のデータ反転や書き込み失敗が起きやすくなります。そのためSRAMの最低動作電圧(Vmin)がチップ全体の電源電圧の下限を決めることが多く、低電圧化の壁になっています。

SRAM・フラッシュメモリのほかの問題

  1. 6T SRAMに読み出し専用のトランジスタを追加した8T SRAMセルの利点として正しいものはどれか。
  2. フラッシュメモリの消去で、フローティングゲートなどから電子を引き抜くと、セルのしきい値電圧はどうなるか。
  3. 近年の3D NANDの積層数として最も近いものはどれか。
  4. NANDフラッシュで、直列につながったメモリセルの両端に設けられる選択トランジスタの役割として正しいものはどれか。
  5. SRAMセルへの書き込みでは、ビット線の一方を0 Vに引き下げてセルの状態を反転させる。このとき、アクセストランジスタに求められる条件として正しいものはどれか。

この分野の比較

  • NAND型とNOR型フラッシュメモリの違い：速度・容量・用途を比較NAND型とNOR型のフラッシュメモリを、セルの接続・読み出し速度・消去単位・容量・コスト・信頼性・用途の観点で表にして比較します。
  • SLC・MLC・TLC・QLCの違い：寿命・速度・コストを比較SLC、MLC、TLC、QLCのNAND型フラッシュを、1セルのビット数・書き換え寿命・速度・コスト・誤り率・使われるSSDの観点で表にして比較します。
