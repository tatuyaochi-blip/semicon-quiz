SRAM・フラッシュメモリ

SRAMの読み出しで、ビット線をあらかじめ電源電圧などに充電しておく動作を何と呼ぶか。

  1. Aリフレッシュ
  2. B消去
  3. Cプリチャージ
答えと解説を見る

正解：C. プリチャージ

SRAMの読み出しでは、まずビット線をプリチャージしておき、ワード線でセルを選ぶと、記憶内容に応じて一方のビット線がわずかに放電されます。その小さな電位差をセンスアンプで増幅して高速にデータを読み出します。

SRAM・フラッシュメモリのほかの問題

  1. NAND型フラッシュメモリの書き込み(プログラム)で主に使われる電子の注入方式はどれか。
  2. NANDフラッシュで、同じブロックを何度も読み出すうちに、読み出していないセルのしきい値電圧が少しずつ変化してしまう現象を何と呼ぶか。
  3. QLC(1セル4ビット)のNANDフラッシュで、1つのセルが区別しなければならないしきい値電圧の状態の数はいくつか。
  4. TLCやQLCのSSDで、一部の領域をSLCとして使い、書き込みを一時的に受け止める仕組みの主な目的はどれか。
  5. SRAMの電源電圧を下げていくと起こりやすい問題として正しいものはどれか。
