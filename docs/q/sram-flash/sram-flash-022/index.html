SRAM・フラッシュメモリ

6T SRAMに読み出し専用のトランジスタを追加した8T SRAMセルの利点として正しいものはどれか。

  1. Aセルの面積が6Tより小さくなる
  2. B電源を切ってもデータが残る
  3. C読み出し時にセルのデータが乱れにくく、低電圧でも安定して動作しやすい
答えと解説を見る

正解：C. 読み出し時にセルのデータが乱れにくく、低電圧でも安定して動作しやすい

6Tセルでは、読み出し時にビット線の電荷がセルの記憶ノードに影響し、データが反転するおそれがあります。8Tセルでは読み出し専用の経路を分けるため、読み出しで記憶ノードが乱されず、低電圧でも安定に動作しやすくなります。その代わり面積は大きくなります。

SRAM・フラッシュメモリのほかの問題

  1. フラッシュメモリの消去で、フローティングゲートなどから電子を引き抜くと、セルのしきい値電圧はどうなるか。
  2. 近年の3D NANDの積層数として最も近いものはどれか。
  3. NANDフラッシュで、直列につながったメモリセルの両端に設けられる選択トランジスタの役割として正しいものはどれか。
  4. SRAMセルへの書き込みでは、ビット線の一方を0 Vに引き下げてセルの状態を反転させる。このとき、アクセストランジスタに求められる条件として正しいものはどれか。
  5. NANDフラッシュで、少しずつ電圧を上げた書き込みパルスを繰り返し、そのたびにしきい値電圧を確認しながら書き込む方式はどれか。
