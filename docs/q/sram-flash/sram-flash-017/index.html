SRAM・フラッシュメモリ

NAND型フラッシュメモリの書き込み(プログラム)で主に使われる電子の注入方式はどれか。

  1. AFN(ファウラー・ノルドハイム)トンネル電流
  2. B光による電子の励起
  3. C磁界による電子の移動
答えと解説を見る

正解：A. FN(ファウラー・ノルドハイム)トンネル電流

NAND型では、制御ゲートに高い電圧をかけて、薄いトンネル酸化膜を通してチャネルから電荷蓄積層に電子を注入します。この量子力学的なトンネル電流をFNトンネル電流といいます。電流が小さいため、多数のセルを同時に書き込めます。NOR型ではチャネルホットエレクトロン注入もよく使われます。

SRAM・フラッシュメモリのほかの問題

  1. NANDフラッシュで、同じブロックを何度も読み出すうちに、読み出していないセルのしきい値電圧が少しずつ変化してしまう現象を何と呼ぶか。
  2. QLC(1セル4ビット)のNANDフラッシュで、1つのセルが区別しなければならないしきい値電圧の状態の数はいくつか。
  3. TLCやQLCのSSDで、一部の領域をSLCとして使い、書き込みを一時的に受け止める仕組みの主な目的はどれか。
  4. SRAMの電源電圧を下げていくと起こりやすい問題として正しいものはどれか。
  5. 6T SRAMに読み出し専用のトランジスタを追加した8T SRAMセルの利点として正しいものはどれか。
