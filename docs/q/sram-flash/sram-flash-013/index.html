SRAM・フラッシュメモリ

NANDフラッシュのコントローラで、多値化に伴う読み出し誤りの増加に対応するために使われる技術はどれか。

  1. Aデータの暗号化
  2. B強力な誤り訂正符号(LDPC符号など)
  3. Cクロックの高速化
答えと解説を見る

正解：B. 強力な誤り訂正符号(LDPC符号など)

1セルに多くのビットを記憶するほど、しきい値電圧の分布の間隔が狭くなり、読み出し誤りが増えます。そのためNANDのコントローラは、数KBのデータに数百バイトの検査ビットを付けたLDPC符号などの強力な誤り訂正を使います。LDPCは「どのくらい確からしいか」の軟判定情報を使えるため、読み出し電圧を少しずつ変えて読み直し、訂正能力をさらに高めます。

SRAM・フラッシュメモリのほかの問題

  1. NOR型フラッシュメモリの代表的な用途はどれか。
  2. SSDのガベージコレクションの説明として正しいものはどれか。
  3. SRAMの読み出しで、ビット線をあらかじめ電源電圧などに充電しておく動作を何と呼ぶか。
  4. NAND型フラッシュメモリの書き込み(プログラム)で主に使われる電子の注入方式はどれか。
  5. NANDフラッシュで、同じブロックを何度も読み出すうちに、読み出していないセルのしきい値電圧が少しずつ変化してしまう現象を何と呼ぶか。
