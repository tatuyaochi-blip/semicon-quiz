SRAM・フラッシュメモリ

NAND型フラッシュメモリで、データの読み出しと書き込み(プログラム)を行う基本的な単位はどれか。

  1. Aブロック
  2. Bページ
  3. Cチップ全体
答えと解説を見る

正解：B. ページ

NANDフラッシュでは、読み出しと書き込みはページ(数KB〜十数KB)単位、消去は多数のページを含むブロック単位で行います。書き込みと消去の単位が異なることが、ガベージコレクションなどの管理が必要になる理由です。

  • A. ブロックは消去の単位です。
  • B. 正しい。読み出し・書き込みはページ単位です。
  • C. チップ全体を単位に読み書きするわけではありません。
この分野を解く 分野ページへ

SRAM・フラッシュメモリのほかの問題

  1. 高速なSSDとホストの接続に広く使われている、PCI Expressを利用したインターフェース規格はどれか。
  2. SRAMで、待機中に電源電圧を下げてリーク電流を減らすときの下限を決める「データ保持電圧」の説明として正しいものはどれか。
  3. 6T SRAMセルで、読み出し時にセルの内容が反転しない(読み出し破壊を防ぐ)ために必要な設計として正しいものはどれか。
  4. 低電圧でのSRAMの書き込み失敗を防ぐ「書き込みアシスト」の例として正しいものはどれか。
  5. 多値(MLCやTLC)のNANDフラッシュで、隣り合うしきい値電圧の状態に割り当てるビットの並びを、1ビットだけ異なるようにする理由として正しいものはどれか。
