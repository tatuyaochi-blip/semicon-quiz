SRAM・フラッシュメモリ

SSDのガベージコレクションの説明として正しいものはどれか。

  1. A無効になったデータを含むブロックから有効なデータを別の場所に移し、ブロックを消去して空き領域をつくる処理
  2. Bコンピュータウイルスを除去する処理
  3. Cデータを圧縮する処理
答えと解説を見る

正解：A. 無効になったデータを含むブロックから有効なデータを別の場所に移し、ブロックを消去して空き領域をつくる処理

NANDフラッシュは上書きができず、消去はブロック単位でしか行えません。書き換えられたデータの古い版は無効なページとして残るため、コントローラは有効なデータを別のブロックに集めてから元のブロックを消去し、新しく書き込める空き領域をつくります。

SRAM・フラッシュメモリのほかの問題

  1. SRAMの読み出しで、ビット線をあらかじめ電源電圧などに充電しておく動作を何と呼ぶか。
  2. NAND型フラッシュメモリの書き込み(プログラム)で主に使われる電子の注入方式はどれか。
  3. NANDフラッシュで、同じブロックを何度も読み出すうちに、読み出していないセルのしきい値電圧が少しずつ変化してしまう現象を何と呼ぶか。
  4. QLC(1セル4ビット)のNANDフラッシュで、1つのセルが区別しなければならないしきい値電圧の状態の数はいくつか。
  5. TLCやQLCのSSDで、一部の領域をSLCとして使い、書き込みを一時的に受け止める仕組みの主な目的はどれか。
