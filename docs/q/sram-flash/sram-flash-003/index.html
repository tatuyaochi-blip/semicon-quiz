SRAM・フラッシュメモリ

フラッシュメモリで、1つのメモリセルに3ビットの情報を記憶する方式を何と呼ぶか。

  1. ASLC
  2. BMLC
  3. CTLC
答えと解説を見る

正解：C. TLC

1セルあたりのビット数によって、SLC(1ビット)、MLC(2ビット)、TLC(3ビット)、QLC(4ビット)と呼ばれます。ビット数が多いほど大容量・低コストになりますが、しきい値電圧の区別が細かくなるため、書き換え可能回数や速度の面では不利になります。

SRAM・フラッシュメモリのほかの問題

  1. フラッシュメモリのデータの書き込み・消去の原理として正しいものはどれか。
  2. 3D NAND型フラッシュメモリの説明として正しいものはどれか。
  3. フラッシュメモリの書き換え可能回数に上限がある主な理由はどれか。
  4. SSDなどで使われるウェアレベリングの目的として正しいものはどれか。
  5. NAND型フラッシュメモリでデータを消去する単位として正しいものはどれか。
