SRAM・フラッシュメモリ

フラッシュメモリの消去で、フローティングゲートなどから電子を引き抜くと、セルのしきい値電圧はどうなるか。

  1. A高くなる
  2. B低くなる
  3. C変化しない
答えと解説を見る

正解：B. 低くなる

フローティングゲートに電子(負の電荷)があると、ゲート電圧の一部が打ち消されてチャネルを作るのにより大きな電圧が必要になるため、しきい値電圧は高くなります。消去で電子を引き抜くとしきい値電圧は低くなり、書き込みで電子を注入すると高くなります。NANDでは一般に消去状態(低いしきい値)を「1」、書き込み状態を「0」としており、消去したフラッシュの中身が0xFFになるのはこのためです。

SRAM・フラッシュメモリのほかの問題

  1. 近年の3D NANDの積層数として最も近いものはどれか。
  2. NANDフラッシュで、直列につながったメモリセルの両端に設けられる選択トランジスタの役割として正しいものはどれか。
  3. SRAMセルへの書き込みでは、ビット線の一方を0 Vに引き下げてセルの状態を反転させる。このとき、アクセストランジスタに求められる条件として正しいものはどれか。
  4. NANDフラッシュで、少しずつ電圧を上げた書き込みパルスを繰り返し、そのたびにしきい値電圧を確認しながら書き込む方式はどれか。
  5. OSが削除したファイルの領域をSSDに通知し、ガベージコレクションを効率化するためのコマンドはどれか。
