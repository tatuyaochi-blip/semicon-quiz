SRAM・フラッシュメモリ

3D NANDで、積み重ねた各層のワード線に配線をつなぐために、端部を階段状に加工した構造を何と呼ぶか。

  1. A階段(ステアケース)構造
  2. Bダマシン構造
  3. Cトレンチ構造
答えと解説を見る

正解：A. 階段(ステアケース)構造

3D NANDでは、ワード線となる導電層が何十〜何百層も積み重なっているため、各層に個別に電極をつなぐ必要があります。そこでアレイの端を階段状に加工し、各層の上面を露出させてコンタクトを立てます。層数が増えるほど階段の加工が難しくなり、面積も必要になります。

  • A. 正しい。各層に接続するための階段状の構造です。
  • B. ダマシンは溝に金属を埋め込んで配線をつくる工程です。
  • C. トレンチは基板に掘った溝のことで、各層への接続構造ではありません。

  3. NOR型と比べたときのNAND型フラッシュメモリの特徴として正しいものはどれか。
  4. フラッシュメモリで、1つのメモリセルに3ビットの情報を記憶する方式を何と呼ぶか。
  5. フラッシュメモリのデータの書き込み・消去の原理として正しいものはどれか。
