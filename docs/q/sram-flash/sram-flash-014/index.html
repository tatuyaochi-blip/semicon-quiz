SRAM・フラッシュメモリ

NOR型フラッシュメモリの代表的な用途はどれか。

  1. A大容量の動画や写真の保存
  2. Bパソコンの主記憶
  3. C機器のプログラムコードの格納(起動用プログラムなど)
答えと解説を見る

正解：C. 機器のプログラムコードの格納(起動用プログラムなど)

NOR型はランダムアクセスが速く、CPUがメモリから直接プログラムを読み出して実行できるため、機器の起動用プログラムやマイコンのファームウェアの格納に使われます。大容量のデータ保存にはNAND型が使われます。

SRAM・フラッシュメモリのほかの問題

  1. SSDのガベージコレクションの説明として正しいものはどれか。
  2. SRAMの読み出しで、ビット線をあらかじめ電源電圧などに充電しておく動作を何と呼ぶか。
  3. NAND型フラッシュメモリの書き込み(プログラム)で主に使われる電子の注入方式はどれか。
  4. NANDフラッシュで、同じブロックを何度も読み出すうちに、読み出していないセルのしきい値電圧が少しずつ変化してしまう現象を何と呼ぶか。
  5. QLC(1セル4ビット)のNANDフラッシュで、1つのセルが区別しなければならないしきい値電圧の状態の数はいくつか。
