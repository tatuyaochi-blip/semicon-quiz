SRAM・フラッシュメモリ

TLCやQLCのSSDで、一部の領域をSLCとして使い、書き込みを一時的に受け止める仕組みの主な目的はどれか。

  1. A容量を増やすため
  2. Bデータを暗号化するため
  3. C書き込みを高速にするため
答えと解説を見る

正解：C. 書き込みを高速にするため

TLCやQLCは状態を細かく作り込むため書き込みに時間がかかります。そこで空き領域の一部をSLCモードで使い、まず高速にそこへ書き込んでから、アイドル時にTLC/QLC領域へ移します(SLCキャッシュ)。大量のデータを書き続けてキャッシュがあふれると、本来の書き込み速度まで大きく低下するため、大きなファイルのコピーでは速度が途中で落ちることがあります。

SRAM・フラッシュメモリのほかの問題

  1. SRAMの電源電圧を下げていくと起こりやすい問題として正しいものはどれか。
  2. 6T SRAMに読み出し専用のトランジスタを追加した8T SRAMセルの利点として正しいものはどれか。
  3. フラッシュメモリの消去で、フローティングゲートなどから電子を引き抜くと、セルのしきい値電圧はどうなるか。
  4. 近年の3D NANDの積層数として最も近いものはどれか。
  5. NANDフラッシュで、直列につながったメモリセルの両端に設けられる選択トランジスタの役割として正しいものはどれか。

この分野の比較

  • NAND型とNOR型フラッシュメモリの違い：速度・容量・用途を比較NAND型とNOR型のフラッシュメモリを、セルの接続・読み出し速度・消去単位・容量・コスト・信頼性・用途の観点で表にして比較します。
  • SLC・MLC・TLC・QLCの違い：寿命・速度・コストを比較SLC、MLC、TLC、QLCのNAND型フラッシュを、1セルのビット数・書き換え寿命・速度・コスト・誤り率・使われるSSDの観点で表にして比較します。
  • SSDとHDDの違い：速度・耐久性・コストを比較SSDとHDDを、データの記録方法・速度・遅延・耐衝撃性・騒音・消費電力・1TBあたりのコスト・容量・寿命・向いている用途の観点で表にして比較します。
