回路解析(交流回路・線形回路・過渡現象)

図のように、テブナンの等価電圧 Vth = 10 V(実効値)、内部インピーダンス Zth = 3 + j4 Ω の交流回路の端子a-bに、負荷インピーダンス ZL をつなぐ。ZL の抵抗分とリアクタンス分を自由に選べるとき、負荷で消費される電力の最大値に最も近いものはどれか。

  1. A3.0 W
  2. B約6.3 W
  3. C約8.3 W
答えと解説を見る

正解：C. 約8.3 W

解き方1(共役整合): ZL を Zth の共役複素数 3 − j4 Ω にするとリアクタンスが打ち消し合い、回路のインピーダンスは6 Ωの抵抗だけになります。電流は 10/6 ≈ 1.67 A で、負荷の電力は (10/6)² × 3 ≈ 8.3 W です。一般に Pmax = Vth²/(4Rth) = 100/12 ≈ 8.3 W です。解き方2(式を最大化): ZL = RL + jXL とすると P = Vth² RL/((3 + RL)² + (4 + XL)²) で、まず XL = −4 Ω で分母のリアクタンス分を0にし、次に RL/(3 + RL)² を最大にする RL = 3 Ω を選ぶと、同じ結果になります。

  • A. ZL を Zth と同じ 3 + j4 Ω にした場合です。リアクタンスが打ち消されず電流は1 Aにとどまり、3 Wになります。
  • B. 負荷を |Zth| = 5 Ω の抵抗にした場合の値です。リアクタンスを選べないときはこれが最大ですが、リアクタンスも選べるなら共役整合のほうが大きくなります。
  • C. 正しい。共役整合で Pmax = Vth²/(4Rth) ≈ 8.3 W です。
