回路解析(交流回路・線形回路・過渡現象)

図(b)のRCハイパスフィルタに、角周波数 ω = 1/(RC) の正弦波を入力した。入力に対する出力の振幅と位相の関係として正しいものはどれか。

  1. A振幅は約0.71倍で、出力は入力より45°遅れる
  2. B振幅は約0.71倍で、出力は入力より45°進む
  3. C振幅は0.5倍で、出力と入力は同相
答えと解説を見る

正解：B. 振幅は約0.71倍で、出力は入力より45°進む

解き方1(複素数): 伝達関数は H(jω) = jωRC/(1 + jωRC) で、ωRC = 1 のとき H = j/(1 + j) = (1 + j)/2 です。大きさは 1/√2 ≈ 0.71(−3 dB)、偏角は +45° なので、出力は入力より45°進みます。解き方2(フェーザ図): RC直列回路の電流は容量性なので入力電圧より進み、ω = 1/(RC) では R と 1/(ωC) が等しいので、進み角はちょうど45°です。出力はRの電圧で電流と同相なので、出力も入力より45°進みます。同じ周波数で、図(a)のローパスフィルタの出力は45°遅れます。

  • A. 大きさは正しいですが、45°遅れるのは図(a)のローパスフィルタの場合です。
  • B. 正しい。H = (1 + j)/2 で、約0.71倍、45°進みです。
  • C. R と 1/(ωC) の電圧を、位相を考えずに半分ずつ分けると考えた誤りです。2つの電圧は直角なので、それぞれ入力の 1/√2 倍になります。
