回路解析(交流回路・線形回路・過渡現象)

図の直列RLC回路で、L = 1 mH、C = 0.1 µF である。ステップ応答が振動せずに最も速く最終値に近づく臨界減衰になる抵抗Rの値はどれか。

  1. A100 Ω
  2. B200 Ω
  3. C10 kΩ
答えと解説を見る

正解：B. 200 Ω

解き方1(特性方程式): 回路の式 L di/dt + Ri + (1/C)∫i dt = E から、特性方程式は Ls² + Rs + 1/C = 0 です。重根になる(判別式が0になる)条件は R² = 4L/C で、R = 2√(L/C) = 2 × √(1×10⁻³/0.1×10⁻⁶) = 2 × 100 = 200 Ω です。解き方2(減衰係数): 標準形 s² + 2ζωn s + ωn² と比べると ζ = (R/2)√(C/L) で、臨界減衰の ζ = 1 から同じ R = 2√(L/C) = 200 Ω が得られます。Rがこれより小さいと減衰振動、大きいと過減衰になります。

  • A. √(L/C) = 100 Ω で、2倍するのを忘れています。この値では ζ = 0.5 の減衰振動になります。
  • B. 正しい。R = 2√(L/C) = 200 Ω です。
  • C. L/C = 10⁴ の平方根をとり忘れた値です(単位も Ω² になってしまいます)。
