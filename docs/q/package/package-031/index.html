パッケージ・実装

半導体パッケージの主な役割の組み合わせとして正しいものはどれか。

  1. Aチップを外部の環境から保護し、プリント基板と電気的に接続し、発生した熱を逃がす
  2. Bチップの回路を設計する
  3. Cチップの中のトランジスタを増やす
答えと解説を見る

正解：A. チップを外部の環境から保護し、プリント基板と電気的に接続し、発生した熱を逃がす

パッケージは、壊れやすいチップを水分や衝撃、光や汚れから守り、チップ上の数十µm間隔の電極を、プリント基板ではんだ付けできる0.4〜1 mm程度の間隔の端子に変換し、チップで発生した熱を外部へ逃がす役割をもちます。近年は、複数のチップを高密度につなぐ先端パッケージが性能を左右するようになり、パッケージは単なる入れ物ではなくなっています。

  • A. 正しい。保護・電気的接続・放熱が主な役割です。
  • B. 回路の設計は設計工程で行います。
  • C. トランジスタの数はチップの製造工程で決まります。

パッケージ・実装のほかの問題

  1. 完成したICのパッケージの表面に、品名やロット番号などを表示する工程として一般的なものはどれか。
  2. ワイヤボンディングで使われるワイヤの太さとして一般的なものはどれか。
  3. 表面実装用のICを、くぼみのあるテープに1個ずつ入れて巻き取り、実装機に供給する梱包形態を何と呼ぶか。
  4. 端子をプリント基板の穴に差し込む実装と比べた、表面実装の主な利点はどれか。
  5. リードフレームを使うパッケージで、外に出たリードの表面にスズ(Sn)系のめっきをする主な目的はどれか。

この分野の比較

  • ワイヤボンディングとフリップチップの違い：チップの接続方法を比較ワイヤボンディングとフリップチップを、接続のしかた・入出力の数・電気的な性能・コスト・大きさ・工程・用途の観点で表にして比較します。
  • BGA・QFP・QFNの違い：ICパッケージの種類を比較BGA、QFP、QFNのパッケージを、端子・ピン数・ピッチ・大きさ・電気的な性能と放熱・検査・用途の観点で表にして比較します。
