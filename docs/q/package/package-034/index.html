パッケージ・実装

表面実装用のICを、くぼみのあるテープに1個ずつ入れて巻き取り、実装機に供給する梱包形態を何と呼ぶか。

  1. Aウエハカセット
  2. Bテープ・アンド・リール
  3. CFOUP
答えと解説を見る

正解：B. テープ・アンド・リール

テープ・アンド・リールは、部品を入れるくぼみ(ポケット)のあるキャリアテープに部品を並べ、カバーテープでふたをしてリールに巻いた梱包形態です。実装機に取り付けると、テープを送りながらノズルで部品を次々に吸い上げて基板に載せられます。大型のBGAなどはトレイ、挿入部品はスティック状のチューブで供給されることもあります。

  • A. ウエハカセットはウエハを並べて入れる容器です。
  • B. 正しい。テープに入れてリールに巻いた梱包形態です。
  • C. FOUPは工場内でウエハを運ぶ密閉容器です。

パッケージ・実装のほかの問題

  1. 端子をプリント基板の穴に差し込む実装と比べた、表面実装の主な利点はどれか。
  2. リードフレームを使うパッケージで、外に出たリードの表面にスズ(Sn)系のめっきをする主な目的はどれか。
  3. 鉛フリーはんだ(Sn-Ag-Cu系)を使うリフローで、部品が受けるピーク温度の目安として最も近いものはどれか。
  4. レーザーをウエハの内部に集光して改質層をつくり、テープを引き伸ばしてチップに分割する、切りしろの少ないダイシングの方法はどれか。
  5. パッケージの底面に、はんだボールではなく平らな電極(ランド)を格子状に並べたパッケージはどれか。
