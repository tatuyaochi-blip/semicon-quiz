パッケージ・実装

チップをリードフレームや基板の所定の位置に接着・固定する工程を何と呼ぶか。

  1. Aワイヤボンディング
  2. Bダイシング
  3. Cダイボンディング
答えと解説を見る

正解：C. ダイボンディング

ダイボンディングは、切り出したチップ(ダイ)を、銀ペーストやはんだ、ダイアタッチフィルムなどの接着材でリードフレームや基板に固定する工程です。このあとワイヤボンディングでチップと外部端子を電気的に接続します。

パッケージ・実装のほかの問題

  1. パッケージを薄くするため、ダイシングの前にウエハの裏面を研削して薄くする工程を何と呼ぶか。
  2. 吸湿した樹脂パッケージをはんだリフローで加熱したとき、内部の水分が急に気化して膨張し、パッケージが割れる現象を何と呼ぶか。
  3. ワイヤボンディングで、金(Au)ワイヤから銅(Cu)ワイヤへの置き換えが進んだ主な理由はどれか。
  4. パッケージの放熱性能を表す、チップの接合部から周囲の空気までの熱抵抗を表す記号はどれか。
  5. プリント基板にはんだペーストを印刷し、部品を載せてから炉で加熱してはんだ付けする方法はどれか。
