パッケージ・実装

樹脂を流し込んでモールドするとき、樹脂の流れによってボンディングワイヤが押し流されて変形する不良を何と呼ぶか。

  1. Aワイヤスイープ(ワイヤ流れ)
  2. Bエレクトロマイグレーション
  3. Cブルーミング
答えと解説を見る

正解：A. ワイヤスイープ(ワイヤ流れ)

モールドの際に流れ込む樹脂の力でワイヤが横に押し流されると、隣のワイヤと接触してショートしたり、断線したりするおそれがあります。これをワイヤスイープといい、ワイヤの長さや配置、樹脂の粘度や流し込む速さを調整して防ぎます。

  • A. 正しい。樹脂の流れでワイヤが変形する不良です。
  • B. エレクトロマイグレーションは電流による原子の移動です。
  • C. ブルーミングはイメージセンサで電荷があふれる現象です。

パッケージ・実装のほかの問題

  1. 封止樹脂の温度がガラス転移温度(Tg)を超えると起こる変化として正しいものはどれか。
  2. 非常に薄いチップをつくるため、ウエハの表面から途中の深さまで溝を切っておき、その後に裏面を研削してチップに分割する方法はどれか。
  3. スマートフォンなどの高密度な実装で、パッケージの表面に金属膜をスパッタなどで形成する目的として正しいものはどれか。
  4. リフローで、チップ抵抗などの小さな部品の片側だけが浮き上がって立ってしまう不良を何と呼ぶか。
  5. ワイヤボンディングの際の力や超音波によって、電極パッドの下の絶縁膜やシリコンが割れる不良を何と呼ぶか。
