パッケージ・実装

発熱の大きいプロセッサのパッケージで、チップの上に載せて熱を広げる金属の板を何と呼ぶか。

  1. Aリードフレーム
  2. Bヒートスプレッダ(リッド)
  3. Cプローブカード
答えと解説を見る

正解：B. ヒートスプレッダ(リッド)

ヒートスプレッダは、チップで発生した熱を広い面積に広げて、その上のヒートシンクなどに伝えやすくする金属(主に銅)の板です。チップを保護するふたの役割も兼ねます。チップとの間にはTIMを挟んで熱を伝えます。

パッケージ・実装のほかの問題

  1. フリップチップBGAなどで使われる、絶縁層と微細な配線層を積み重ねてつくる有機パッケージ基板はどれか。
  2. 金ワイヤの先端を放電で溶かしてボールをつくり、熱と超音波を加えて電極に接合するワイヤボンディングの方式はどれか。
  3. 宇宙用など高い信頼性が求められる用途で使われる、セラミックや金属で内部を密閉したパッケージはどれか。
  4. パッケージの2辺から、ガルウィング状のリードを出した表面実装パッケージはどれか。
  5. 多ピンのQFPで、リードの間隔を狭くしすぎると起こりやすい問題はどれか。
