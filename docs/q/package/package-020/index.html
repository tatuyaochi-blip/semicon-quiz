パッケージ・実装

大型のパッケージで、リフロー時の加熱による反り(ワーページ)が問題になる理由として正しいものはどれか。

  1. Aパッケージの色が変わるため
  2. Bはんだボールの一部が基板に接合されず、接続不良の原因になるため
  3. Cパッケージが軽くなるため
答えと解説を見る

正解：B. はんだボールの一部が基板に接合されず、接続不良の原因になるため

パッケージはチップ、基板、封止樹脂など熱膨張係数の異なる材料でできているため、加熱すると反りが生じます。反りが大きいと、はんだボールの一部が基板に届かなかったり、隣どうしがつながったりして、接続不良の原因になります。大型化が進むパッケージでは重要な課題です。

パッケージ・実装のほかの問題

  1. 表面実装パッケージで、防湿梱包を開封してからリフローまでに放置してよい時間などを定めた、吸湿に関する等級はどれか。
  2. 発熱の大きいプロセッサのパッケージで、チップの上に載せて熱を広げる金属の板を何と呼ぶか。
  3. フリップチップBGAなどで使われる、絶縁層と微細な配線層を積み重ねてつくる有機パッケージ基板はどれか。
  4. 金ワイヤの先端を放電で溶かしてボールをつくり、熱と超音波を加えて電極に接合するワイヤボンディングの方式はどれか。
  5. 宇宙用など高い信頼性が求められる用途で使われる、セラミックや金属で内部を密閉したパッケージはどれか。
