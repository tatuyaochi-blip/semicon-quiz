パッケージ・実装

宇宙用など高い信頼性が求められる用途で使われる、セラミックや金属で内部を密閉したパッケージはどれか。

  1. A樹脂モールドパッケージ
  2. B気密封止(ハーメチックシール)パッケージ
  3. Cテープキャリアパッケージ
答えと解説を見る

正解：B. 気密封止(ハーメチックシール)パッケージ

気密封止パッケージは、セラミックや金属のパッケージにチップを収め、ふたを溶接やろう付けで密閉して、内部に水分などが入らないようにしたものです。樹脂パッケージより高価ですが、耐湿性や信頼性に優れ、宇宙・防衛・医療などの用途で使われます。

  4. 封止樹脂に大量のシリカのフィラーを加える主な目的はどれか。
  5. パッケージやプリント基板に、デカップリングコンデンサ(バイパスコンデンサ)を配置する主な目的はどれか。
