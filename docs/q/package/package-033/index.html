パッケージ・実装

ワイヤボンディングで使われるワイヤの太さとして一般的なものはどれか。

  1. A約1〜2 mm
  2. B約1 nm
  3. C約15〜50 µm
答えと解説を見る

正解：C. 約15〜50 µm

ボンディングワイヤは、直径が約15〜50 µm程度の非常に細い金属線で、髪の毛(約70 µm)より細いものが多く使われます。電流の大きいパワーデバイスでは、数百µmの太いアルミニウムワイヤも使われます。

  • A. 1 mm以上では太すぎて、チップの電極に接合できません。
  • B. 1 nmは原子数個分の太さで、ワイヤにはなりません。
  • C. 正しい。髪の毛より細い数十µm程度の線です。
