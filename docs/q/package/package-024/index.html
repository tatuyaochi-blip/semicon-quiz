パッケージ・実装

金ワイヤの先端を放電で溶かしてボールをつくり、熱と超音波を加えて電極に接合するワイヤボンディングの方式はどれか。

  1. Aボールボンディング(熱圧着超音波接合)
  2. Bウェッジボンディング
  3. Cリフローはんだ付け
答えと解説を見る

正解：A. ボールボンディング(熱圧着超音波接合)

ボールボンディングでは、キャピラリーという細い管から出したワイヤの先端を放電で溶かしてボールをつくり、チップの電極に熱・圧力・超音波で接合します。その後ワイヤを引き回して、リードの側は押しつぶして接合します。金ワイヤや銅ワイヤで広く使われる方式です。

パッケージ・実装のほかの問題

  1. 宇宙用など高い信頼性が求められる用途で使われる、セラミックや金属で内部を密閉したパッケージはどれか。
  2. パッケージの2辺から、ガルウィング状のリードを出した表面実装パッケージはどれか。
  3. 多ピンのQFPで、リードの間隔を狭くしすぎると起こりやすい問題はどれか。
  4. チップと基板を加熱・加圧しながら1個ずつ接合し、反りの大きい薄いチップや狭いピッチのバンプの接続に使われる方法はどれか。
  5. 封止樹脂に大量のシリカのフィラーを加える主な目的はどれか。
