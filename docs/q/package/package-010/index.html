パッケージ・実装

環境規制に対応した鉛フリーはんだとして広く使われている組成はどれか。

  1. ASn-Pb共晶
  2. BSn-Ag-Cu系
  3. CHg-Au系
答えと解説を見る

正解：B. Sn-Ag-Cu系

RoHS指令などで鉛の使用が制限されたことから、スズ・銀・銅を主成分とするSn-Ag-Cu(SAC)系はんだが広く使われるようになりました。従来のSn-Pb共晶はんだより融点が高いため、リフローの温度も高くなります。
