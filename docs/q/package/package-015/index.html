パッケージ・実装

ワイヤボンディングで、金(Au)ワイヤから銅(Cu)ワイヤへの置き換えが進んだ主な理由はどれか。

  1. A銅は金より酸化しにくいため
  2. B銅は金より柔らかく接合しやすいため
  3. C材料コストを大幅に下げられ、電気伝導性も良いため
答えと解説を見る

正解：C. 材料コストを大幅に下げられ、電気伝導性も良いため

金の価格高騰を背景に、材料費の安い銅ワイヤへの置き換えが進みました。銅は電気伝導性や熱伝導性にも優れています。一方で、金より硬く酸化しやすいため、接合時のチップへのダメージ防止や、不活性ガス雰囲気での接合などの対策が必要です。
