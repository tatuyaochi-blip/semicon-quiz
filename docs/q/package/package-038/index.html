パッケージ・実装

レーザーをウエハの内部に集光して改質層をつくり、テープを引き伸ばしてチップに分割する、切りしろの少ないダイシングの方法はどれか。

  1. Aステルスダイシング
  2. Bブレードダイシングのみ
  3. Cワイヤソー
答えと解説を見る

正解：A. ステルスダイシング

ステルスダイシングは、シリコンを透過する赤外のレーザーをウエハの内部に集光して改質層をつくり、そこを起点にテープを引き伸ばして割る方法です。表面を削らないため削りくずも水も使わず、切りしろもほとんどありません。そのため、汚れや振動に弱いMEMS、薄いウエハ、チップを多く取りたい小さなチップに向いています。ブレードは数十µmの切りしろが必要です。

  • A. 正しい。内部に改質層をつくって割る方法です。
  • B. ブレードダイシングは回転する刃で切るため、切りしろと削りくずが出ます。
  • C. ワイヤソーはインゴットをウエハに切る装置です。

  3. 多くの樹脂封止パッケージの封止樹脂が黒い色をしている主な理由はどれか。
  4. 多ピンのBGAパッケージで、ボールの多くを電源とグラウンドに割り当てる主な理由はどれか。
  5. ボール形成を使うワイヤボンディングで、一般的に最初の接合(ボールボンド)をする場所はどれか。
