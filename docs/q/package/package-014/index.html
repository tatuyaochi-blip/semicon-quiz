パッケージ・実装

吸湿した樹脂パッケージをはんだリフローで加熱したとき、内部の水分が急に気化して膨張し、パッケージが割れる現象を何と呼ぶか。

  1. Aウィスカ
  2. Bポップコーン現象
  3. Cスティクション
答えと解説を見る

正解：B. ポップコーン現象

樹脂パッケージは保管中に空気中の水分を吸収します。その状態でリフローの高温にさらすと、内部の水分が急に水蒸気になって膨張し、樹脂の剥離やクラックを起こします。音を立てて割れることからポップコーン現象と呼ばれ、防湿梱包や実装前のベーキングで防ぎます。
