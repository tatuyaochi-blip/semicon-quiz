パッケージ・実装

リードフレームの材料として一般的に使われるものはどれか。

  1. A銅合金や鉄-ニッケル合金(42アロイ)
  2. Bガラス
  3. Cエポキシ樹脂
答えと解説を見る

正解：A. 銅合金や鉄-ニッケル合金(42アロイ)

リードフレームは、チップを載せ、外部端子にもなる金属の枠です。電気伝導・熱伝導に優れた銅合金や、熱膨張係数がシリコンに近い鉄-ニッケル合金(42アロイ)が使われます。表面には、はんだ付け性を良くするためのめっきが施されます。

  3. フリップチップ実装で、チップと基板の隙間にアンダーフィル樹脂を充填する主な目的はどれか。
  4. 環境規制に対応した鉛フリーはんだとして広く使われている組成はどれか。
  5. QFN(Quad Flat No-lead)パッケージの特徴として正しいものはどれか。
