パッケージ・実装

ワイヤボンディングの説明として正しいものはどれか。

  1. Aチップの電極パッドとリードフレームや基板を、金属の細線で接続する方法
  2. Bチップを裏返し、バンプで基板と直接接続する方法
  3. Cチップを樹脂で封止する方法
答えと解説を見る

正解：A. チップの電極パッドとリードフレームや基板を、金属の細線で接続する方法

ワイヤボンディングは、金・銅・アルミニウムなどの細いワイヤで、チップの電極パッドとリードフレームやパッケージ基板の端子をつなぐ方法です。熱・圧力・超音波を利用して接合します。歴史が長く、現在も多くのパッケージで使われています。
