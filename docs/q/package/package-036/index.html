パッケージ・実装

リードフレームを使うパッケージで、外に出たリードの表面にスズ(Sn)系のめっきをする主な目的はどれか。

  1. Aはんだのぬれ性をよくして、基板へのはんだ付けを確実にし、リードの酸化も防ぐため
  2. Bリードを光らせて見た目をよくするため
  3. Cリードを絶縁体にするため
答えと解説を見る

正解：A. はんだのぬれ性をよくして、基板へのはんだ付けを確実にし、リードの酸化も防ぐため

銅合金などのリードの表面は酸化しやすく、そのままでははんだがよくぬれません。スズ系のめっきをしておくと、はんだがなじみやすくなり、実装時の接合が確実になります。鉛フリー化でスズ-鉛から純スズのめっきに替わりましたが、純スズからはウィスカという針状の結晶が伸びてショートの原因になるため、熱処理やニッケル下地などで対策します。

  • A. 正しい。はんだ付け性を高め、酸化を防ぎます。
  • B. 見た目のためではありません。
  • C. めっきは金属で、リードを絶縁体にはしません。
