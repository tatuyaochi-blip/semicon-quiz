パッケージ・実装

封止樹脂の温度がガラス転移温度(Tg)を超えると起こる変化として正しいものはどれか。

  1. A樹脂が金属になる
  2. B樹脂の色が透明になる
  3. C熱膨張係数が大きくなり、弾性率が下がる
答えと解説を見る

正解：C. 熱膨張係数が大きくなり、弾性率が下がる

樹脂はガラス転移温度を超えると、硬いガラス状態からやわらかいゴム状態に変わり、熱膨張係数が大きく増え、弾性率が下がります。チップやリードフレームとの熱膨張の差による応力が変わるため、パッケージの信頼性の設計で重要な特性です。

  • A. 樹脂が金属になることはありません。
  • B. 色が透明になる変化ではありません。
  • C. 正しい。膨張係数が増え、弾性率が下がります。

パッケージ・実装のほかの問題

  1. 非常に薄いチップをつくるため、ウエハの表面から途中の深さまで溝を切っておき、その後に裏面を研削してチップに分割する方法はどれか。
  2. スマートフォンなどの高密度な実装で、パッケージの表面に金属膜をスパッタなどで形成する目的として正しいものはどれか。
  3. リフローで、チップ抵抗などの小さな部品の片側だけが浮き上がって立ってしまう不良を何と呼ぶか。
  4. ワイヤボンディングの際の力や超音波によって、電極パッドの下の絶縁膜やシリコンが割れる不良を何と呼ぶか。
  5. ワイヤボンディングの説明として正しいものはどれか。
