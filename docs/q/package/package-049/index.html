パッケージ・実装

リフローで、チップ抵抗などの小さな部品の片側だけが浮き上がって立ってしまう不良を何と呼ぶか。

  1. Aツームストーン(マンハッタン現象)
  2. Bスティクション
  3. Cラッチアップ
答えと解説を見る

正解：A. ツームストーン(マンハッタン現象)

部品の両端のはんだが溶けるタイミングがずれたり、はんだの量や温度に差があったりすると、先に溶けた側の表面張力で部品が引っ張られ、もう一方が浮き上がって墓石のように立ちます。これをツームストーンといい、部品が小さく軽いほど起こりやすくなります。左右のパッドの大きさや配線をそろえ、リフローの温度を均一にして防ぎます。

  • A. 正しい。部品の片側が浮き上がって立つ不良です。
  • B. スティクションはMEMSの可動部が張り付く現象です。
  • C. ラッチアップはCMOSの寄生サイリスタによる大電流の現象です。
