パッケージ・実装

電子機器のプリント基板の基材として最も広く使われている材料はどれか。

  1. Aガラス繊維の布にエポキシ樹脂をしみ込ませたもの(FR-4など)
  2. B単結晶シリコン
  3. C純粋な銅の板
答えと解説を見る

正解：A. ガラス繊維の布にエポキシ樹脂をしみ込ませたもの(FR-4など)

一般的なプリント基板は、ガラス繊維の布にエポキシ樹脂をしみ込ませて硬化させた材料(FR-4など)を絶縁の基材とし、その表面や内層に銅箔の配線をつくっています。高周波用には、誘電損失の小さい特殊な樹脂の基材も使われます。

  • A. 正しい。ガラスエポキシ(FR-4など)が広く使われます。
  • B. 単結晶シリコンはチップの材料で、プリント基板には使いません。
  • C. 銅は配線の材料で、基材は絶縁体である必要があります。
