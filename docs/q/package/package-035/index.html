パッケージ・実装

端子をプリント基板の穴に差し込む実装と比べた、表面実装の主な利点はどれか。

  1. A部品が必ず大きくなる
  2. Bはんだ付けが不要になる
  3. C部品を小さくでき、基板の両面に高密度に実装でき、自動化もしやすい
答えと解説を見る

正解：C. 部品を小さくでき、基板の両面に高密度に実装でき、自動化もしやすい

表面実装では、基板の表面のパッドに部品の端子をはんだ付けするため穴を開ける必要がなく、部品を小さくして基板の両面に高い密度で実装できます。実装機とリフロー炉で一括して自動化でき、端子が短いため高周波特性もよくなります。ただし、大きな力がかかるコネクタや大型部品には、機械的に強い挿入実装が今も使われます。

  • A. 表面実装はむしろ部品を小さくできます。
  • B. 表面実装でもはんだ付けを行います。
  • C. 正しい。小型・高密度・自動化しやすいことが利点です。
