パッケージ・実装

プリント基板にはんだペーストを印刷し、部品を載せてから炉で加熱してはんだ付けする方法はどれか。

  1. Aワイヤボンディング
  2. Bリフローはんだ付け
  3. Cフロー(噴流)はんだ付け
答えと解説を見る

正解：B. リフローはんだ付け

リフローはんだ付けでは、メタルマスクで基板の電極にはんだペーストを印刷し、部品を搭載したあと、リフロー炉で予熱・溶融・冷却の温度プロファイルに沿って加熱して接合します。溶けたはんだの表面張力で部品が正しい位置に引き寄せられる効果もあり、表面実装の主流です。溶けたはんだの波に基板を通すフローはんだ付けは、主に挿入部品に使われます。

パッケージ・実装のほかの問題

  1. プロセッサのパッケージの上に、メモリのパッケージを重ねて実装する方式を何と呼ぶか。
  2. パッケージの両側2列にピンを並べ、基板の穴に差し込んで実装する、古くからあるパッケージはどれか。
  3. 大型のパッケージで、リフロー時の加熱による反り(ワーページ)が問題になる理由として正しいものはどれか。
  4. 表面実装パッケージで、防湿梱包を開封してからリフローまでに放置してよい時間などを定めた、吸湿に関する等級はどれか。
  5. 発熱の大きいプロセッサのパッケージで、チップの上に載せて熱を広げる金属の板を何と呼ぶか。

この分野の比較

  • ワイヤボンディングとフリップチップの違い：チップの接続方法を比較ワイヤボンディングとフリップチップを、接続のしかた・入出力の数・電気的な性能・コスト・大きさ・工程・用途の観点で表にして比較します。
  • BGA・QFP・QFNの違い：ICパッケージの種類を比較BGA、QFP、QFNのパッケージを、端子・ピン数・ピッチ・大きさ・電気的な性能と放熱・検査・用途の観点で表にして比較します。
