パッケージ・実装

パッケージやプリント基板に、デカップリングコンデンサ(バイパスコンデンサ)を配置する主な目的はどれか。

  1. A信号を増幅するため
  2. B電源電圧の変動(ノイズ)を抑え、急な電流の変化に対して電荷を供給するため
  3. Cチップを光らせるため
答えと解説を見る

正解：B. 電源電圧の変動(ノイズ)を抑え、急な電流の変化に対して電荷を供給するため

LSIは動作によって電源電流が急に変化し、電源配線のインダクタンスのために電源電圧が揺れます。チップの近くにデカップリングコンデンサを置くと、急な電流の変化に対してコンデンサから電荷が供給され、電源電圧の変動を抑えられます。
