パッケージ・実装

パッケージの放熱性能を表す、チップの接合部から周囲の空気までの熱抵抗を表す記号はどれか。

  1. AθJA(Rth(j-a))
  2. BCpk
  3. CFIT
答えと解説を見る

正解：A. θJA(Rth(j-a))

θJAは、チップの接合部(ジャンクション)から周囲の空気(アンビエント)までの熱抵抗で、単位は℃/Wです。値が小さいほど熱を逃がしやすいパッケージです。消費電力にθJAを掛けると、周囲温度からの接合温度の上昇がわかります。

  5. 表面実装パッケージで、防湿梱包を開封してからリフローまでに放置してよい時間などを定めた、吸湿に関する等級はどれか。
