パッケージ・実装

スマートフォンなどの高密度な実装で、パッケージの表面に金属膜をスパッタなどで形成する目的として正しいものはどれか。

  1. Aはんだ付けを不要にするため
  2. B電磁波を遮へいして、周囲の部品との間の電磁干渉(EMI)を防ぐため
  3. Cパッケージを透明にするため
答えと解説を見る

正解：B. 電磁波を遮へいして、周囲の部品との間の電磁干渉(EMI)を防ぐため

高周波の部品を密に並べると、互いの電磁波が干渉して誤動作の原因になります。パッケージの表面に金属膜をつけて接地し、電磁シールドとすることで、従来の金属ケースを使わずに薄く小さく電磁干渉を防げます。

  • A. はんだ付けは引き続き必要です。
  • B. 正しい。電磁シールドとして干渉を防ぎます。
  • C. 金属膜でパッケージは透明になりません。
