パッケージ・実装

鉛フリーはんだ(Sn-Ag-Cu系)を使うリフローで、部品が受けるピーク温度の目安として最も近いものはどれか。

  1. A約500℃
  2. B約100℃
  3. C約245〜260℃
答えと解説を見る

正解：C. 約245〜260℃

Sn-Ag-Cu系の鉛フリーはんだは融点が約217〜220 ℃で、確実に溶かしてぬらすために、リフローのピーク温度を約245〜260 ℃にします。Sn-Pbはんだ(融点183 ℃)のピークは220〜235 ℃程度だったため、部品の耐熱性の基準は260 ℃に引き上げられました。高温になるほど吸湿したパッケージの破損が起こりやすく、MSLの管理もより重要になりました。

  • A. 約500℃ではパッケージの樹脂などが損傷します。
  • B. 約100℃では鉛フリーはんだは溶けません。
  • C. 正しい。ピークは約245〜260℃です。
