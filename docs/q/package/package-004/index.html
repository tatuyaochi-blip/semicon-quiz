パッケージ・実装

ダイシングの説明として正しいものはどれか。

  1. Aチップを樹脂で封止する工程
  2. Bチップの電気的特性を検査する工程
  3. Cウエハを個々のチップに切り分ける工程
答えと解説を見る

正解：C. ウエハを個々のチップに切り分ける工程

ダイシングは、回路をつくり終えたウエハを、ダイヤモンドブレードやレーザーで切断して、個々のチップ(ダイ)に分ける工程です。切り出したチップは、ダイボンディング、ワイヤボンディング、封止などの工程に進みます。
