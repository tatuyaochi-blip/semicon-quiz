パッケージ・実装

多くの樹脂封止パッケージの封止樹脂が黒い色をしている主な理由はどれか。

  1. A樹脂の強度を下げるため
  2. B光をさえぎり、光によってチップの中にキャリアが発生して誤動作するのを防ぐため
  3. C熱を吸収してチップを温めるため
答えと解説を見る

正解：B. 光をさえぎり、光によってチップの中にキャリアが発生して誤動作するのを防ぐため

シリコンは光を吸収すると電子と正孔ができる(光電効果)ため、光が当たると漏れ電流が増えたり誤動作したりします。封止樹脂にカーボンブラックなどを加えて黒くし、光をさえぎっています。マーキングの見やすさにもつながります。

  • A. 強度を下げる目的ではありません。
  • B. 正しい。光による誤動作を防ぐためです。
  • C. チップを温める目的ではありません。
