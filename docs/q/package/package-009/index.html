パッケージ・実装

フリップチップ実装で、チップと基板の隙間にアンダーフィル樹脂を充填する主な目的はどれか。

  1. Aチップと基板の熱膨張差による応力がバンプに集中するのを防ぎ、接続の信頼性を高める
  2. Bチップを発光させる
  3. Cチップからの放熱を妨げる
答えと解説を見る

正解：A. チップと基板の熱膨張差による応力がバンプに集中するのを防ぎ、接続の信頼性を高める

シリコンチップと有機基板では熱膨張係数が大きく異なるため、温度が変化するとバンプに大きなひずみがかかり、疲労で割れるおそれがあります。隙間をアンダーフィル樹脂で埋めると、応力が分散されて接続の寿命が大きく延びます。

パッケージ・実装のほかの問題

  1. 環境規制に対応した鉛フリーはんだとして広く使われている組成はどれか。
  2. QFN(Quad Flat No-lead)パッケージの特徴として正しいものはどれか。
  3. チップをリードフレームや基板の所定の位置に接着・固定する工程を何と呼ぶか。
  4. パッケージを薄くするため、ダイシングの前にウエハの裏面を研削して薄くする工程を何と呼ぶか。
  5. 吸湿した樹脂パッケージをはんだリフローで加熱したとき、内部の水分が急に気化して膨張し、パッケージが割れる現象を何と呼ぶか。
