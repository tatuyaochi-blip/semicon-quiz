パッケージ・実装

完成したICのパッケージの表面に、品名やロット番号などを表示する工程として一般的なものはどれか。

  1. Aエピタキシャル成長
  2. Bレーザーなどによるマーキング(捺印)
  3. Cイオン注入
答えと解説を見る

正解：B. レーザーなどによるマーキング(捺印)

パッケージの表面には、製品名、ロット番号、製造週などを、レーザーで樹脂の表面を焼いたり、インクで印刷したりして表示します。これをマーキングといい、製品の識別や追跡(トレーサビリティ)に使われます。

  • A. エピタキシャル成長はウエハに結晶を成長させる工程です。
  • B. 正しい。レーザーなどでマーキングします。
  • C. イオン注入はウエハに不純物を打ち込む工程です。

  3. 端子をプリント基板の穴に差し込む実装と比べた、表面実装の主な利点はどれか。
  4. リードフレームを使うパッケージで、外に出たリードの表面にスズ(Sn)系のめっきをする主な目的はどれか。
  5. 鉛フリーはんだ(Sn-Ag-Cu系)を使うリフローで、部品が受けるピーク温度の目安として最も近いものはどれか。
