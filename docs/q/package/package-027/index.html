パッケージ・実装

多ピンのQFPで、リードの間隔を狭くしすぎると起こりやすい問題はどれか。

  1. Aパッケージが発光する
  2. B実装時のはんだブリッジ(隣のリードとの短絡)
  3. Cパッケージが重くなる
答えと解説を見る

正解：B. 実装時のはんだブリッジ(隣のリードとの短絡)

リードの間隔が狭いと、はんだ付けのときに隣のリードとの間にはんだがつながるブリッジが起こりやすくなります。また、細いリードは曲がりやすくなります。そのため、さらに多くの端子が必要な場合は、底面に端子を並べられるBGAなどが使われます。

この分野を解く 分野ページへ
