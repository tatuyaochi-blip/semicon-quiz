DRAM

DRAMの内部を複数のバンクに分ける主な目的はどれか。

  1. A容量を減らすため
  2. B異なるバンクの動作を重ねて行い、実効的なアクセス性能を高めるため
  3. C発熱を増やすため
答えと解説を見る

正解：B. 異なるバンクの動作を重ねて行い、実効的なアクセス性能を高めるため

行の活性化やプリチャージには十数nsかかります。内部を複数のバンクに分けると、あるバンクがこれらの動作をしている間に別のバンクへアクセスでき、待ち時間を隠して転送効率を高められます。DDR4は16バンク(4つのバンクグループ)、DDR5は32バンクです。複数のバンクで別々の行を開いておけるため、ページヒットの機会も増えます。

DRAMのほかの問題

  1. DRAMの読み出しで、ビット線に現れる電圧の変化が非常に小さい理由として正しいものはどれか。
  2. 将来のDRAMの大容量化の手段として研究開発が進められている3D DRAMの考え方として正しいものはどれか。
  3. DRAMで、ある行を短時間に何度も活性化すると、隣接する行のデータが反転してしまうことがある現象を何と呼ぶか。
  4. DRAMのセルのデータ保持時間を決める主なリークの経路として正しいものはどれか。
  5. DRAMのセル面積を表すときに使われる「6F²」のFの意味として正しいものはどれか。
