DRAM

SRAMと比べたときのDRAMの特徴として正しいものはどれか。

  1. ASRAMより高速で、リフレッシュも不要である
  2. Bセルが小さくビットあたりのコストが低いが、リフレッシュが必要である
  3. C電源を切ってもデータが残る
答えと解説を見る

正解：B. セルが小さくビットあたりのコストが低いが、リフレッシュが必要である

DRAMは1T1Cの小さなセルで構成されるため、6TのSRAMより大容量化しやすく、ビットあたりのコストが低くなります。一方でリフレッシュが必要で、アクセス速度はSRAMより遅いため、主記憶にはDRAM、キャッシュにはSRAMと使い分けられています。

DRAMのほかの問題

  1. DRAMの歩留まりを上げるために使われる冗長救済の説明として正しいものはどれか。
  2. メモリで使われる誤り訂正符号(ECC)の働きとして正しいものはどれか。
  3. DRAMで、同じ行(ページ)に連続してアクセスするとアクセス時間が短くなる理由として正しいものはどれか。
  4. DRAMのキャパシタの誘電体膜に、酸化ジルコニウムなどのHigh-k材料が使われる理由として正しいものはどれか。
  5. DRAMのセルフリフレッシュモードの説明として正しいものはどれか。
