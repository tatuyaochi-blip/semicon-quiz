DRAM

パソコンやサーバーで、DRAMが主に使われる用途はどれか。

  1. ACPU内部のレジスタ
  2. B実行中のプログラムやデータを置くメインメモリ
  3. C電源を切ってもデータを残すための長期保存
答えと解説を見る

正解：B. 実行中のプログラムやデータを置くメインメモリ

DRAMは大容量で比較的高速なため、CPUが実行中のプログラムやデータを置くメインメモリとして使われます。容量はパソコンで8〜64 GB、サーバーでは1台で数TBに達します。揮発性なので長期保存にはSSDやHDDを使い、CPU内部のレジスタやキャッシュにはSRAMやフリップフロップを使います。速度・容量・価格の違うメモリを組み合わせた記憶階層の中間に位置します。

  • A. CPU内部のレジスタはフリップフロップなどでつくられます。
  • B. 正しい。DRAMはメインメモリとして使われます。
  • C. DRAMは揮発性で、電源を切るとデータが消えるため長期保存には向きません。

DRAMのほかの問題

  1. パソコンのメモリとして、複数のDRAMチップを小さな基板に載せて差し込めるようにした部品を何と呼ぶか。
  2. SDRAMの「S(Synchronous)」が表す特徴として正しいものはどれか。
  3. DRAMの世界市場で大きなシェアをもつ主要メーカー3社の組み合わせとして正しいものはどれか。
  4. 一般的なDRAMの規格で、すべてのセルを一通りリフレッシュする周期として定められている時間に最も近いものはどれか。(通常の温度範囲)
  5. DRAMのタイミング規格「tRCD」が表すものはどれか。

この分野の比較

  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • DDR・LPDDR・GDDR・HBMの違い：DRAMの種類を比較DDR、LPDDR、GDDR、HBMを、使われる機器・バス幅・速度・帯域・消費電力・実装・容量・コストの観点で表にして比較します。
  • DDR4とDDR5の違い：速度・構造・買い替えの目安DDR4とDDR5を、速度・電圧・チャネル構造・バースト長・バンク・オンダイECC・電源管理・遅延・帯域・互換性の観点で表にして比較します。
