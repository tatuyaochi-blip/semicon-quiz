DRAM

DDR4 SDRAMなどで使われている「8nプリフェッチ」の考え方として正しいものはどれか。

  1. A内部のセルアレイから一度に8倍の幅のデータを取り出し、外部端子で高速に順番に出力する
  2. B8回分のリフレッシュをまとめて行う
  3. C8個のチップに同じデータを書き込む
答えと解説を見る

正解：A. 内部のセルアレイから一度に8倍の幅のデータを取り出し、外部端子で高速に順番に出力する

DRAMのセルアレイ自体の動作速度はあまり上がらないため、内部では1回のアクセスで端子幅の8倍(8n)のデータをまとめて読み出し、それを外部の高速なインターフェースで順に送り出します。こうして内部の速度を上げずに外部の転送速度を高めています。

  • A. 正しい。内部で広い幅のデータを読み出し、外部で高速に出力します。
  • B. リフレッシュをまとめる仕組みではありません。
  • C. 同じデータを複数のチップに書く仕組みではありません。

DRAMのほかの問題

  2. DRAMのセルの中には、データ保持時間が時間とともに長くなったり短くなったりを不規則に繰り返すものがある。この現象を何と呼ぶか。
  3. DRAMのワード線を駆動する電圧に、電源電圧より高い昇圧電圧(VPP)が使われる主な理由はどれか。
  4. 一般的なDRAMの1ビットのメモリセルの構成として正しいものはどれか。
  5. DRAMで定期的なリフレッシュ動作が必要になる理由として正しいものはどれか。
