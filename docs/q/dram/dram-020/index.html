DRAM

最近のDRAMのセルトランジスタで、ゲート電極をシリコン基板の溝の中に埋め込む構造(埋め込みワード線)を使う主な目的はどれか。

  1. Aセルを発光させるため
  2. B実効的なチャネル長を長くしてリーク電流を抑えながら、セルを小さくするため
  3. Cキャパシタを不要にするため
答えと解説を見る

正解：B. 実効的なチャネル長を長くしてリーク電流を抑えながら、セルを小さくするため

DRAMのセルトランジスタには、キャパシタの電荷を逃がさないよう極めて小さいリーク電流が求められます。ゲートを溝に埋め込むと、平面上の寸法が小さくても、溝に沿って実効的なチャネル長を長くでき、短チャネル効果によるリークを抑えられます。

DRAMのほかの問題

  1. DRAMで、アドレスを行アドレスと列アドレスに分けて、同じ端子から順番に与える主な理由はどれか。
  2. DRAMの内部を複数のバンクに分ける主な目的はどれか。
  3. DRAMの読み出しで、ビット線に現れる電圧の変化が非常に小さい理由として正しいものはどれか。
  4. 将来のDRAMの大容量化の手段として研究開発が進められている3D DRAMの考え方として正しいものはどれか。
  5. DRAMで、ある行を短時間に何度も活性化すると、隣接する行のデータが反転してしまうことがある現象を何と呼ぶか。
