DRAM

一般的なDRAMの規格で、すべてのセルを一通りリフレッシュする周期として定められている時間に最も近いものはどれか。(通常の温度範囲)

  1. A約64 ms
  2. B約64 µs
  3. C約64 s
答えと解説を見る

正解：A. 約64 ms

一般的なDDR系のDRAMでは、通常の温度範囲で約64 ms以内にすべての行をリフレッシュするよう定められています。実際には、この時間の中でリフレッシュコマンドを数千回に分けて発行し、少しずつ行をリフレッシュします。

  • A. 正しい。通常は64 ms以内に全セルをリフレッシュします。
  • B. 64 µsでは短すぎ、リフレッシュに時間を取られすぎます。
  • C. 64 sではセルのデータ保持が持ちません。
