DRAM

DRAMのセル面積を表すときに使われる「6F²」のFの意味として正しいものはどれか。

  1. Aファラッド(容量の単位)
  2. Bフィンの本数
  3. C最小加工寸法(フィーチャーサイズ)
答えと解説を見る

正解：C. 最小加工寸法(フィーチャーサイズ)

Fは最小加工寸法を表し、セル面積を「Fの2乗の何倍か」で表します。6F²は、最小加工寸法の2乗の6倍の面積という意味です。DRAMは8F²から6F²へとセル構造が改良されてきており、4F²の実現をめざした研究も進められています。

DRAMのほかの問題

  1. DRAMのアクセスで、開いていた行を閉じ、ビット線を中間電位に戻して次の行の活性化に備える動作を何と呼ぶか。
  2. DDR5で採用された、DRAMチップの内部で誤りを訂正する機能はどれか。
  3. プロセッサの性能向上に比べて、メモリの帯域や遅延の改善が追いつかないことによって生じる性能の制約を何と呼ぶか。
  4. 一般的なDRAMの1ビットのメモリセルの構成として正しいものはどれか。
  5. DRAMで定期的なリフレッシュ動作が必要になる理由として正しいものはどれか。
