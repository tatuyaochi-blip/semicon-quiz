DRAM

GPUのグラフィックスメモリとして使われるGDDRの特徴として正しいものはどれか。

  1. Aデータ転送の帯域(速度)を重視した規格である
  2. B電源を切ってもデータが残る
  3. C低速だが非常に安価である
答えと解説を見る

正解：A. データ転送の帯域(速度)を重視した規格である

GDDRは、GPUが大量の画像データを高速に扱えるよう、1端子あたりの転送速度を重視したDRAMで、GDDR6Xでは20 Gb/s以上、GDDR7では30 Gb/s前後に達します(DDR5の数倍)。基板上でGPUの周囲に並べて短い配線でつなぎます。容量あたりのコストや消費電力はDDRより高めです。さらに広い帯域が必要なAI向けアクセラレータでは、積層したHBMが使われます。

DRAMのほかの問題

  1. 最近のDRAMのセルトランジスタで、ゲート電極をシリコン基板の溝の中に埋め込む構造(埋め込みワード線)を使う主な目的はどれか。
  2. DRAMで、アドレスを行アドレスと列アドレスに分けて、同じ端子から順番に与える主な理由はどれか。
  3. DRAMの内部を複数のバンクに分ける主な目的はどれか。
  4. DRAMの読み出しで、ビット線に現れる電圧の変化が非常に小さい理由として正しいものはどれか。
  5. 将来のDRAMの大容量化の手段として研究開発が進められている3D DRAMの考え方として正しいものはどれか。
