DRAM

プロセッサの性能向上に比べて、メモリの帯域や遅延の改善が追いつかないことによって生じる性能の制約を何と呼ぶか。

  1. Aムーアの法則
  2. Bシリコンサイクル
  3. Cメモリウォール
答えと解説を見る

正解：C. メモリウォール

プロセッサの演算性能は年率50%以上で伸びた時期がありましたが、DRAMのアクセス遅延は数十nsからほとんど改善しておらず、CPUが数百サイクルもデータを待つことになりました。これがメモリウォールです。対策として、多段のキャッシュ、メモリの並列アクセス、プリフェッチ、HBMのような広帯域メモリ、演算をメモリの近くで行うプロセッシング・イン・メモリなどが進められています。

DRAMのほかの問題

  1. DRAMの「RAM(Random Access Memory)」の意味として正しいものはどれか。
  2. パソコンやサーバーで、DRAMが主に使われる用途はどれか。
  3. パソコンのメモリとして、複数のDRAMチップを小さな基板に載せて差し込めるようにした部品を何と呼ぶか。
  4. SDRAMの「S(Synchronous)」が表す特徴として正しいものはどれか。
  5. DRAMの世界市場で大きなシェアをもつ主要メーカー3社の組み合わせとして正しいものはどれか。

この分野の比較

  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • DDR・LPDDR・GDDR・HBMの違い：DRAMの種類を比較DDR、LPDDR、GDDR、HBMを、使われる機器・バス幅・速度・帯域・消費電力・実装・容量・コストの観点で表にして比較します。
  • DDR4とDDR5の違い：速度・構造・買い替えの目安DDR4とDDR5を、速度・電圧・チャネル構造・バースト長・バンク・オンダイECC・電源管理・遅延・帯域・互換性の観点で表にして比較します。
