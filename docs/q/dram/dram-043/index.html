DRAM

現在の多くのパソコン用プロセッサで、DRAMを制御するメモリコントローラが置かれている場所はどれか。

  1. ADRAMチップの中
  2. Bプロセッサのチップ(パッケージ)の中
  3. CSSDの中
答えと解説を見る

正解：B. プロセッサのチップ(パッケージ)の中

かつてメモリコントローラはマザーボード上のチップセット(ノースブリッジ)にありましたが、2003年のAMD Opteron、2008年のIntel Core i7(Nehalem)以降、プロセッサに内蔵されるのが一般的です。CPUとメモリの間の経路が短くなり、レイテンシが数十%改善しました。複数のCPUを持つサーバーでは、各CPUに直結されたメモリのほうが速いNUMA構成になります。

  • A. DRAMチップは、外部のメモリコントローラから送られたコマンドに従って動きます。
  • B. 正しい。現在はプロセッサに内蔵されるのが一般的です。
  • C. SSDのコントローラはフラッシュメモリを管理するもので、DRAMのメインメモリは制御しません。
この分野を解く 分野ページへ

DRAMのほかの問題

  1. DRAMの規格で、チップの温度が高い範囲(例えば85℃を超える範囲)で求められる対応として一般的なものはどれか。
  2. DRAMの容量が大きくなるにつれて、リフレッシュに関して問題になりやすいことはどれか。
  3. DRAMのセルアレイのビット線の構成で、対になるビット線を同じセルアレイ内に並べて配置する方式はどれか。
  4. DDR4 SDRAMなどで使われている「8nプリフェッチ」の考え方として正しいものはどれか。
  5. DDR系のDRAMで、信号の反射を抑えるための終端抵抗をDRAMチップの内部に持たせ、オン・オフを制御できるようにした機能はどれか。
