DRAM

将来のDRAMの大容量化の手段として研究開発が進められている3D DRAMの考え方として正しいものはどれか。

  1. Aメモリセルを縦方向に積み重ね、平面の微細化だけに頼らずに容量を増やす
  2. Bチップを大きくするだけで容量を増やす
  3. CDRAMをSRAMに置き換える
答えと解説を見る

正解：A. メモリセルを縦方向に積み重ね、平面の微細化だけに頼らずに容量を増やす

DRAMは、キャパシタの高アスペクト比化やセルトランジスタの微細化が限界に近づいています。そこで3D NANDのようにセルを縦方向に積み重ねる3D DRAMの研究開発が進められ、トランジスタとキャパシタを横向きにして何層も積む構造や、キャパシタを使わないセルなどが検討されています。実現すれば平面の微細化に頼らず容量を増やせますが、量産技術はまだ開発段階です。

DRAMのほかの問題

  1. DRAMで、ある行を短時間に何度も活性化すると、隣接する行のデータが反転してしまうことがある現象を何と呼ぶか。
  2. DRAMのセルのデータ保持時間を決める主なリークの経路として正しいものはどれか。
  3. DRAMのセル面積を表すときに使われる「6F²」のFの意味として正しいものはどれか。
  4. DRAMのアクセスで、開いていた行を閉じ、ビット線を中間電位に戻して次の行の活性化に備える動作を何と呼ぶか。
  5. DDR5で採用された、DRAMチップの内部で誤りを訂正する機能はどれか。

この分野の比較

  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • DDR・LPDDR・GDDR・HBMの違い：DRAMの種類を比較DDR、LPDDR、GDDR、HBMを、使われる機器・バス幅・速度・帯域・消費電力・実装・容量・コストの観点で表にして比較します。
  • DDR4とDDR5の違い：速度・構造・買い替えの目安DDR4とDDR5を、速度・電圧・チャネル構造・バースト長・バンク・オンダイECC・電源管理・遅延・帯域・互換性の観点で表にして比較します。
