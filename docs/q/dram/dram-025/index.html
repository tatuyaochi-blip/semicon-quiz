DRAM

DRAMで、ある行を短時間に何度も活性化すると、隣接する行のデータが反転してしまうことがある現象を何と呼ぶか。

  1. Aソフトエラー
  2. Bロウハンマー
  3. Cラッチアップ
答えと解説を見る

正解：B. ロウハンマー

ロウハンマーは、同じ行を短時間に何万回も活性化すると、ワード線の電圧変動や電荷の移動によって隣接行のセルの電荷が失われ、データが反転する現象です。2014年に広く報告され、権限昇格などの攻撃に悪用できることが示されました。対策として、頻繁に活性化された行の隣を追加でリフレッシュする仕組み(TRR、DDR5のRFMなど)がDRAMやコントローラに組み込まれています。

DRAMのほかの問題

  1. DRAMのセルのデータ保持時間を決める主なリークの経路として正しいものはどれか。
  2. DRAMのセル面積を表すときに使われる「6F²」のFの意味として正しいものはどれか。
  3. DRAMのアクセスで、開いていた行を閉じ、ビット線を中間電位に戻して次の行の活性化に備える動作を何と呼ぶか。
  4. DDR5で採用された、DRAMチップの内部で誤りを訂正する機能はどれか。
  5. プロセッサの性能向上に比べて、メモリの帯域や遅延の改善が追いつかないことによって生じる性能の制約を何と呼ぶか。
