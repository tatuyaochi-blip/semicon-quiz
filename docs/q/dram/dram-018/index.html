DRAM

LPDDRと呼ばれるDRAM規格の主な用途はどれか。

  1. A大型サーバー専用
  2. B光ディスクへの記録
  3. Cスマートフォンなど低消費電力が求められる機器
答えと解説を見る

正解：C. スマートフォンなど低消費電力が求められる機器

LPDDR(Low Power DDR)は、低い電源電圧、深い省電力モード、温度に応じたリフレッシュ制御などで消費電力を抑えたモバイル向けDRAMです。スマートフォンやタブレット、薄型ノートPCに使われ、プロセッサのパッケージに重ねたり(PoP)、すぐ隣に置いたりして配線を短くします。モジュールではなく基板に直接実装するため後から増設できないことが多く、最新のLPDDR5Xは8533 MT/s以上に達します。

DRAMのほかの問題

  1. GPUのグラフィックスメモリとして使われるGDDRの特徴として正しいものはどれか。
  2. 最近のDRAMのセルトランジスタで、ゲート電極をシリコン基板の溝の中に埋め込む構造(埋め込みワード線)を使う主な目的はどれか。
  3. DRAMで、アドレスを行アドレスと列アドレスに分けて、同じ端子から順番に与える主な理由はどれか。
  4. DRAMの内部を複数のバンクに分ける主な目的はどれか。
  5. DRAMの読み出しで、ビット線に現れる電圧の変化が非常に小さい理由として正しいものはどれか。

この分野の比較

  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • DDR・LPDDR・GDDR・HBMの違い：DRAMの種類を比較DDR、LPDDR、GDDR、HBMを、使われる機器・バス幅・速度・帯域・消費電力・実装・容量・コストの観点で表にして比較します。
  • DDR4とDDR5の違い：速度・構造・買い替えの目安DDR4とDDR5を、速度・電圧・チャネル構造・バースト長・バンク・オンダイECC・電源管理・遅延・帯域・互換性の観点で表にして比較します。
