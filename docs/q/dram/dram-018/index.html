DRAM

LPDDRと呼ばれるDRAM規格の主な用途はどれか。

  1. A大型サーバー専用
  2. B光ディスクへの記録
  3. Cスマートフォンなど低消費電力が求められる機器
答えと解説を見る

正解：C. スマートフォンなど低消費電力が求められる機器

LPDDR(Low Power DDR)は、低い電源電圧や省電力モードなどにより消費電力を抑えたモバイル向けのDRAM規格です。スマートフォンやタブレット、薄型ノートパソコンなどに使われ、プロセッサと同じパッケージに重ねて実装されることもあります。
