DRAM

DRAMのセルで、キャパシタの容量を確保するために使われてきた立体構造の組み合わせとして正しいものはどれか。

  1. Aフィン型とプレーナ型
  2. Bトレンチ型とスタック型
  3. Cフローティングゲート型と電荷トラップ型
答えと解説を見る

正解：B. トレンチ型とスタック型

セルを小さくしてもキャパシタの容量を確保するため、DRAMではキャパシタを立体化してきました。基板に深い溝を掘ってつくるトレンチ型と、トランジスタの上に背の高い構造を積み上げるスタック型があり、現在はスタック型が主流です。フローティングゲートや電荷トラップはフラッシュメモリの構造です。

DRAMのほかの問題

  1. DRAMの性質として正しいものはどれか。
  2. DDR SDRAMの「DDR(ダブルデータレート)」の意味として正しいものはどれか。
  3. DRAMのセルアレイで、セルトランジスタのゲートにつながり、読み書きする行を選択する配線はどれか。
  4. 温度が上がると、DRAMのセルがデータを保持できる時間は一般にどうなるか。
  5. メモリのソフトエラーの説明として正しいものはどれか。
