DRAM

DRAMの歩留まりを上げるために使われる冗長救済の説明として正しいものはどれか。

  1. A不良セルを含む行や列を、あらかじめ用意した予備の行や列に置き換える
  2. B不良セルを含むチップはすべて廃棄する
  3. C電源電圧を上げて不良セルを動作させる
答えと解説を見る

正解：A. 不良セルを含む行や列を、あらかじめ用意した予備の行や列に置き換える

数十億個のセルが1つも不良なく作れることはまれなため、DRAMには予備の行や列が用意されています。ウエハテストで見つかった不良箇所のアドレスを、レーザーで切るヒューズや電気的に書き込むアンチヒューズに記録し、アクセスを予備に振り替えます。パッケージ後に救済できる仕組み(PPR)もあります。この冗長救済がなければ、大容量DRAMの歩留まりは成り立ちません。

DRAMのほかの問題

  1. メモリで使われる誤り訂正符号(ECC)の働きとして正しいものはどれか。
  2. DRAMで、同じ行(ページ)に連続してアクセスするとアクセス時間が短くなる理由として正しいものはどれか。
  3. DRAMのキャパシタの誘電体膜に、酸化ジルコニウムなどのHigh-k材料が使われる理由として正しいものはどれか。
  4. DRAMのセルフリフレッシュモードの説明として正しいものはどれか。
  5. 容量8 GbitのDRAMチップは、バイトに換算するといくらか。
