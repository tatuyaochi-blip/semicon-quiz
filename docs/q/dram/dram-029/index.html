DRAM

DDR5で採用された、DRAMチップの内部で誤りを訂正する機能はどれか。

  1. AオンダイECC
  2. Bウェアレベリング
  3. CTRIM
答えと解説を見る

正解：A. オンダイECC

DDR5では、微細化によってセルの不良やエラーが増えることに対応するため、DRAMチップの内部に誤り訂正回路(オンダイECC)が組み込まれました。システム側のECCとは別に、チップ内部で単一ビットの誤りなどを訂正します。

  2. DRAMの「RAM(Random Access Memory)」の意味として正しいものはどれか。
  3. パソコンやサーバーで、DRAMが主に使われる用途はどれか。
  4. パソコンのメモリとして、複数のDRAMチップを小さな基板に載せて差し込めるようにした部品を何と呼ぶか。
  5. SDRAMの「S(Synchronous)」が表す特徴として正しいものはどれか。
