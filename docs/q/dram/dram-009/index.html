DRAM

メモリのソフトエラーの説明として正しいものはどれか。

  1. A放射線などによって記憶データが一時的に反転する、素子の破壊を伴わない誤り
  2. B製造時の配線不良による永久的な故障
  3. C経年劣化によって素子が壊れる故障
答えと解説を見る

正解：A. 放射線などによって記憶データが一時的に反転する、素子の破壊を伴わない誤り

ソフトエラーは、パッケージ材料からのα線や宇宙線由来の中性子がシリコン中で電荷を発生させ、記憶データが反転する現象です。素子は壊れていないため、書き直せば正常に戻ります。高度が高いほど中性子が多く、航空機内では地上の数百倍になります。対策はECCで、材料の放射性不純物の低減も行われます。製造不良や劣化による永久故障はハードエラーです。

DRAMのほかの問題

  1. SRAMと比べたときのDRAMの特徴として正しいものはどれか。
  2. DRAMの歩留まりを上げるために使われる冗長救済の説明として正しいものはどれか。
  3. メモリで使われる誤り訂正符号(ECC)の働きとして正しいものはどれか。
  4. DRAMで、同じ行(ページ)に連続してアクセスするとアクセス時間が短くなる理由として正しいものはどれか。
  5. DRAMのキャパシタの誘電体膜に、酸化ジルコニウムなどのHigh-k材料が使われる理由として正しいものはどれか。

この分野の比較

  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • DDR・LPDDR・GDDR・HBMの違い：DRAMの種類を比較DDR、LPDDR、GDDR、HBMを、使われる機器・バス幅・速度・帯域・消費電力・実装・容量・コストの観点で表にして比較します。
  • DDR4とDDR5の違い：速度・構造・買い替えの目安DDR4とDDR5を、速度・電圧・チャネル構造・バースト長・バンク・オンダイECC・電源管理・遅延・帯域・互換性の観点で表にして比較します。
