DRAM

DRAMの規格で、チップの温度が高い範囲(例えば85℃を超える範囲)で求められる対応として一般的なものはどれか。

  1. Aリフレッシュを停止する
  2. Bクロック周波数を2倍にする
  3. Cリフレッシュの頻度を上げる(周期を短くする)
答えと解説を見る

正解：C. リフレッシュの頻度を上げる(周期を短くする)

温度が高いとセルの接合リークが増え、データ保持時間が短くなります。DDR4などでは、85 ℃を超える拡張温度範囲(〜95 ℃)でリフレッシュ間隔を半分(tREFI = 3.9 µs)にすることが求められます。リフレッシュが増えるとアクセスできない時間と消費電力が増えるため、性能も少し下がります。車載向けDRAMでは105 ℃以上で動作する製品もあります。

  • A. リフレッシュを止めるとデータが失われます。
  • B. クロック周波数を上げてもデータ保持の問題は解決しません。
  • C. 正しい。高温では保持時間が短くなるため、リフレッシュを頻繁に行います。

DRAMのほかの問題

  1. DRAMの容量が大きくなるにつれて、リフレッシュに関して問題になりやすいことはどれか。
  2. DRAMのセルアレイのビット線の構成で、対になるビット線を同じセルアレイ内に並べて配置する方式はどれか。
  3. DDR4 SDRAMなどで使われている「8nプリフェッチ」の考え方として正しいものはどれか。
  4. DDR系のDRAMで、信号の反射を抑えるための終端抵抗をDRAMチップの内部に持たせ、オン・オフを制御できるようにした機能はどれか。
  5. DRAMのセルの中には、データ保持時間が時間とともに長くなったり短くなったりを不規則に繰り返すものがある。この現象を何と呼ぶか。

この分野の比較

  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • DDR・LPDDR・GDDR・HBMの違い：DRAMの種類を比較DDR、LPDDR、GDDR、HBMを、使われる機器・バス幅・速度・帯域・消費電力・実装・容量・コストの観点で表にして比較します。
  • DDR4とDDR5の違い：速度・構造・買い替えの目安DDR4とDDR5を、速度・電圧・チャネル構造・バースト長・バンク・オンダイECC・電源管理・遅延・帯域・互換性の観点で表にして比較します。
