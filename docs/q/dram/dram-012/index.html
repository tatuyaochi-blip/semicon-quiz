DRAM

メモリで使われる誤り訂正符号(ECC)の働きとして正しいものはどれか。

  1. Aデータを圧縮して容量を増やす
  2. Bデータに冗長なビットを付け加え、ビットの誤りを検出・訂正する
  3. Cデータを暗号化する
答えと解説を見る

正解：B. データに冗長なビットを付け加え、ビットの誤りを検出・訂正する

ECCは、データにチェック用のビットを付け加え、読み出し時に誤りを検出・訂正する仕組みです。サーバー用のメモリでは64ビットに8ビットを加え、1ビットの誤りを訂正し2ビットの誤りを検出する(SECDED)方式が基本です。さらに高信頼のサーバーでは、チップ1個がまるごと故障しても救えるChipkillなどもあります。DDR5ではチップ内部にもECCが組み込まれました。

DRAMのほかの問題

  1. DRAMで、同じ行(ページ)に連続してアクセスするとアクセス時間が短くなる理由として正しいものはどれか。
  2. DRAMのキャパシタの誘電体膜に、酸化ジルコニウムなどのHigh-k材料が使われる理由として正しいものはどれか。
  3. DRAMのセルフリフレッシュモードの説明として正しいものはどれか。
  4. 容量8 GbitのDRAMチップは、バイトに換算するといくらか。
  5. DRAMのCASレイテンシ(CL)の意味として正しいものはどれか。
