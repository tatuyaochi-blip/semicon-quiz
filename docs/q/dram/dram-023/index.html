DRAM

DRAMの読み出しで、ビット線に現れる電圧の変化が非常に小さい理由として正しいものはどれか。

  1. A電源電圧が非常に高いため
  2. Bビット線の抵抗が0であるため
  3. Cセルのキャパシタの容量が、ビット線の寄生容量に比べてはるかに小さいため
答えと解説を見る

正解：C. セルのキャパシタの容量が、ビット線の寄生容量に比べてはるかに小さいため

読み出しでは、セルのキャパシタの電荷がビット線と分け合われます。セルの容量はビット線の容量よりずっと小さいため、ビット線の電圧はわずか(数十〜百数十mV程度)しか変化しません。この小さな変化をセンスアンプで増幅して、0か1かを判定します。

DRAMのほかの問題

  1. 将来のDRAMの大容量化の手段として研究開発が進められている3D DRAMの考え方として正しいものはどれか。
  2. DRAMで、ある行を短時間に何度も活性化すると、隣接する行のデータが反転してしまうことがある現象を何と呼ぶか。
  3. DRAMのセルのデータ保持時間を決める主なリークの経路として正しいものはどれか。
  4. DRAMのセル面積を表すときに使われる「6F²」のFの意味として正しいものはどれか。
  5. DRAMのアクセスで、開いていた行を閉じ、ビット線を中間電位に戻して次の行の活性化に備える動作を何と呼ぶか。
