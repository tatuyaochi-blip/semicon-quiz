DRAM

温度が上がると、DRAMのセルがデータを保持できる時間は一般にどうなるか。

  1. A長くなる
  2. B変化しない
  3. C短くなる
答えと解説を見る

正解：C. 短くなる

温度が上がると接合のリーク電流が増え、キャパシタの電荷が早く失われるため、データ保持時間は短くなります。そのため、高温ではリフレッシュの間隔を短くする仕組みが規格に設けられています。

DRAMのほかの問題

  1. メモリのソフトエラーの説明として正しいものはどれか。
  2. SRAMと比べたときのDRAMの特徴として正しいものはどれか。
  3. DRAMの歩留まりを上げるために使われる冗長救済の説明として正しいものはどれか。
  4. メモリで使われる誤り訂正符号(ECC)の働きとして正しいものはどれか。
  5. DRAMで、同じ行(ページ)に連続してアクセスするとアクセス時間が短くなる理由として正しいものはどれか。
