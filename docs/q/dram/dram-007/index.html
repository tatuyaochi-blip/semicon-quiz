DRAM

DRAMのセルアレイで、セルトランジスタのゲートにつながり、読み書きする行を選択する配線はどれか。

  1. Aビット線
  2. Bワード線
  3. C電源線
答えと解説を見る

正解：B. ワード線

DRAMのセルアレイでは、ワード線で行を選んでセルトランジスタをオンにし、ビット線を通してキャパシタの電荷を読み書きします。ビット線の先にはセンスアンプがつながっています。

  3. SRAMと比べたときのDRAMの特徴として正しいものはどれか。
  4. DRAMの歩留まりを上げるために使われる冗長救済の説明として正しいものはどれか。
  5. メモリで使われる誤り訂正符号(ECC)の働きとして正しいものはどれか。
