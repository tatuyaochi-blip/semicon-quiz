DRAM

DRAMで、同じ行(ページ)に連続してアクセスするとアクセス時間が短くなる理由として正しいものはどれか。

  1. Aリフレッシュが不要になるため
  2. B電源電圧が上がるため
  3. C一度活性化した行のデータがセンスアンプに保持されており、列を切り替えるだけで読み出せるため
答えと解説を見る

正解：C. 一度活性化した行のデータがセンスアンプに保持されており、列を切り替えるだけで読み出せるため

DRAMでは、行を活性化するとその行の全セルのデータがセンスアンプに読み出されます。同じ行のデータであれば、行の活性化をやり直さずに列アドレスを変えるだけで読み出せるため、アクセスが速くなります。メモリコントローラはこの性質を利用してアクセス順を最適化します。
