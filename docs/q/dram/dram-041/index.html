DRAM

DRAMモジュールの「ランク」の説明として正しいものはどれか。

  1. A1つのチップの中のバンクの数
  2. B同時にアクセスされて、データバスの全幅(例えば64ビット)を構成するDRAMチップの組
  3. CDRAMチップの性能の等級
答えと解説を見る

正解：B. 同時にアクセスされて、データバスの全幅(例えば64ビット)を構成するDRAMチップの組

ランクは、チップセレクト信号で一緒に選ばれ、まとめてデータバスの全幅を構成するDRAMチップのグループで、x8のチップ8個で64ビットの1ランクになります。1枚のモジュールに複数のランクを載せれば容量を増やせ、ランクを交互に使うと待ち時間を隠せる利点もありますが、バスの負荷が増えて最高速度が下がることがあります。チップ内部の分割はバンクです。

  • A. チップ内部の分割はバンクと呼ばれます。
  • B. 正しい。データバス全幅を構成するチップの組です。
  • C. ランクは性能の等級を表す言葉ではありません。

DRAMのほかの問題

  1. データ幅8ビット(x8)のDRAMチップを使って、64ビット幅のデータバスを構成するには、1ランクあたり何個のチップが必要か(ECCなし)。
  2. 現在の多くのパソコン用プロセッサで、DRAMを制御するメモリコントローラが置かれている場所はどれか。
  3. DRAMの規格で、チップの温度が高い範囲(例えば85℃を超える範囲)で求められる対応として一般的なものはどれか。
  4. DRAMの容量が大きくなるにつれて、リフレッシュに関して問題になりやすいことはどれか。
  5. DRAMのセルアレイのビット線の構成で、対になるビット線を同じセルアレイ内に並べて配置する方式はどれか。

この分野の比較

  • DRAMとSRAMの違い：構造・速度・コスト・用途を比較DRAMとSRAMを、セル構造・リフレッシュ・速度・集積度・コスト・消費電力・用途の観点で表にまとめて比較。どちらをどんなときに使うかも解説します。
  • DDR・LPDDR・GDDR・HBMの違い：DRAMの種類を比較DDR、LPDDR、GDDR、HBMを、使われる機器・バス幅・速度・帯域・消費電力・実装・容量・コストの観点で表にして比較します。
  • DDR4とDDR5の違い：速度・構造・買い替えの目安DDR4とDDR5を、速度・電圧・チャネル構造・バースト長・バンク・オンダイECC・電源管理・遅延・帯域・互換性の観点で表にして比較します。
