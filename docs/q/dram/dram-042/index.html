DRAM

データ幅8ビット(x8)のDRAMチップを使って、64ビット幅のデータバスを構成するには、1ランクあたり何個のチップが必要か(ECCなし)。

  1. A8個
  2. B4個
  3. C64個
答えと解説を見る

正解：A. 8個

64ビット ÷ 8ビット = 8 なので、x8のチップ8個を並べて同時にアクセスすると64ビット幅になります。ECCつきのモジュールでは、検査ビットのためにさらに1個(合計9個)を追加することが一般的です。

  • A. 正しい。64 ÷ 8 = 8個です。
  • B. 4個では32ビット幅にしかなりません。
  • C. 64個は、1ビット幅(x1)のチップを使う場合の数です。

DRAMのほかの問題

  1. 現在の多くのパソコン用プロセッサで、DRAMを制御するメモリコントローラが置かれている場所はどれか。
  2. DRAMの規格で、チップの温度が高い範囲(例えば85℃を超える範囲)で求められる対応として一般的なものはどれか。
  3. DRAMの容量が大きくなるにつれて、リフレッシュに関して問題になりやすいことはどれか。
  4. DRAMのセルアレイのビット線の構成で、対になるビット線を同じセルアレイ内に並べて配置する方式はどれか。
  5. DDR4 SDRAMなどで使われている「8nプリフェッチ」の考え方として正しいものはどれか。
