DRAM

一般的なDRAMの1ビットのメモリセルの構成として正しいものはどれか。

  1. Aトランジスタ1個とキャパシタ1個
  2. Bトランジスタ6個
  3. Cフローティングゲートをもつトランジスタ1個
答えと解説を見る

正解：A. トランジスタ1個とキャパシタ1個

DRAMのセルは、トランジスタ1個とキャパシタ1個(1T1C)で構成され、キャパシタに電荷があるかないかで1ビットを記憶します。トランジスタ6個はSRAM、フローティングゲートのトランジスタはフラッシュメモリのセル構成です。

DRAMのほかの問題

  1. DRAMで定期的なリフレッシュ動作が必要になる理由として正しいものはどれか。
  2. DRAMの読み出し動作の特徴として正しいものはどれか。
  3. DRAMのセルで、キャパシタの容量を確保するために使われてきた立体構造の組み合わせとして正しいものはどれか。
  4. DRAMの性質として正しいものはどれか。
  5. DDR SDRAMの「DDR(ダブルデータレート)」の意味として正しいものはどれか。
