インテグレーションエンジニア

多くの工程をつなぎ合わせ、全体としてデバイスが狙いどおりに動く製造の流れを組み立てる技術者です。新しい世代や製品の立ち上げで中心となります。

仕事の内容

半導体の製造は、成膜、リソグラフィ、エッチング、イオン注入などを何度も繰り返す、長い工程の流れでできています。インテグレーションエンジニアは、この流れ全体を設計し、個々の工程を組み合わせたときに、デバイスが狙いどおりの特性と歩留まりになるようにまとめる仕事です。ある工程の条件を変えると、前後の工程や電気特性に影響が出るため、全体を見て最適な組み合わせを決めます。新しい世代のプロセスや新製品の立ち上げでは、工程の順序や目標値を決め、試作の結果を評価して、量産に移せる状態まで仕上げていきます。

一緒に働く人・扱うもの

各工程のプロセスエンジニア、特性を作り込むデバイスエンジニア、歩留まり・品質エンジニア、そして設計部門の間に立ち、調整役を果たすことが多い職種です。扱うものは、工程の順序と条件を記したプロセスフロー、ウエハ上に作り込む評価用のテスト構造とその電気測定の結果、断面の観察像、歩留まりのデータなどです。設計者に渡すデザインルールや、PDK(プロセスデザインキット)の内容に関わることもあります。量産が始まったあとも、歩留まりや特性の課題が工程をまたぐ場合は、その解決の取りまとめを担います。

求められる知識とスキル

個々の工程を深く掘り下げるよりも、すべての工程の原理と、それらがどうつながっているかを広く理解していることが求められます。STI(シャロートレンチ分離)からトランジスタ、シリサイド、配線までの断面構造を頭の中で描けることが基本です。さらに、電気特性の測定結果から、どの工程に原因がありそうかを推定する力が必要です。多くの部署の意見をまとめて判断するため、根拠を示して論理的に説明し、優先順位をつける調整力も重要になります。

学び始めるなら

まずは『製造プロセスを一通り』コースで、前工程の各分野を順に学びましょう。とくに『リソグラフィ』『エッチング』『成膜(CVD・PVD)』『イオン注入』『配線プロセス』は、工程の流れを組み立てるうえで欠かせません。工程がデバイスの特性にどう効くかは、『MOSFET』と『先端トランジスタ(FinFET・GAA)』の分野、または『デバイスを深く知る』コースで学べます。最後に『歩留まり・品質管理』の分野で、量産に向けた評価の考え方を押さえておくとよいでしょう。

おすすめの学習コース

製造プロセスを一通りウエハからクリーンルーム、酸化、リソグラフィ、エッチング、成膜、配線、計測、歩留まりまで、前工程を流れの順に学びます。デバイスを深く知る物性の基礎からトランジスタ、先端トランジスタ、パワーや化合物、センサーまで、デバイスの原理を順に学びます。

よくある質問

文系や未経験からインテグレーションエンジニアになれますか？

工程全体とデバイスの両方の知識を使うため、一般に、理工系の知識が前提とされることが多い職種です。プロセスエンジニアやデバイスエンジニアとしての経験を生かして担当することもあれば、新卒から配属されることもあり、考え方は会社によって異なります。どの場合も、各工程の原理とトランジスタの構造を一通り理解しておくことが出発点になります。

プロセスエンジニアとの違いは何ですか？

プロセスエンジニアは、特定の工程の条件と結果に責任を持ち、その工程を深く掘り下げます。インテグレーションエンジニアは、工程の組み合わせ全体と、最終的なデバイスの特性や歩留まりに責任を持ちます。たとえば、ある寸法の目標値を決めるのはインテグレーション、その寸法を実現する条件を作るのはプロセス、という分担になることがありますが、境界は会社によって異なります。

必要な資格はありますか？

一般に、必須の免許や資格はありません。工程とデバイスの幅広い知識、データから原因を推定する力、多くの部署と調整する力が重視されます。学生のうちに、半導体の製造工程やデバイスを扱う実験・研究に触れておくと、仕事のイメージをつかみやすくなります。
