テストエンジニア

ウエハやパッケージ後のチップが仕様どおりに動くかを自動試験装置(ATE)で確かめるテストを開発し、品質とテストのコストを両立させる技術者です。

仕事の内容

テストエンジニアは、製造したチップが仕様どおりに動くかを確かめるテストを作り、量産で使える状態にする仕事です。テストは一般に、ダイシング前のウエハの状態で行うウエハテストと、パッケージに組み立てたあとで行う最終テストに分かれます。ATE(自動試験装置)で動くテストプログラムを開発し、電圧や電流、タイミング、機能を測る項目と、合否の判定基準を決めます。不良を確実に見つけることと、1個あたりのテスト時間を短くしてコストを下げることを両立させるのが、腕の見せどころです。量産が始まったあとも、テスト結果を分析して改善を続けます。

一緒に働く人・扱うもの

テストの内容はチップの設計で決まるため、回路設計者、とくにDFT(テスト容易化設計)の担当者と早い段階から協力します。テストの結果は歩留まりの解析にも使われるので、歩留まり・品質エンジニアとも連携します。扱うものは、ATE、ウエハの電極に針を当てるプローブカード、チップとATEをつなぐ治具や基板、テストプログラム、そして大量のテスト結果のデータです。自社のテスト工程のほか、テストを請け負うOSATと協力して量産を進めることもあります。

求められる知識とスキル

デジタル回路とアナログ回路の両方の基礎が必要です。デジタルではスキャンテストやATPG(自動テストパターン生成)、故障検出率(フォールトカバレッジ)の考え方、アナログではオペアンプやADCの特性の測り方を理解していると役立ちます。テストプログラムを書くためのプログラミングの力、データシートの仕様を正確に読む力、測定の誤差やノイズを見抜く力も求められます。テストの抜けは市場での不良に、過剰なテストはコストの増加につながるため、その釣り合いを考える視点が大切です。

学び始めるなら

まずは『テスト・検査』の分野で、ウエハテスト、バーンイン、スキャンテストなどの基本を押さえましょう。テストする対象を理解するために、『論理回路』『アナログ・電子回路』『AD/DA変換』の分野を学ぶと、どの項目をなぜ測るのかが分かるようになります。仕様の読み方は『データシートの読み方』、テスト結果の使われ方は『歩留まり・品質管理』の分野で学べます。コースでは、『後工程・品質・安全』と『回路・設計とメモリ』がおすすめです。

よくある質問

文系や未経験からテストエンジニアになれますか？

電気回路の知識とプログラミングの両方を使う職種なので、一般に、電気電子や情報系の知識がある人が採用の対象になりやすい傾向があります。ソフトウェア開発の経験は、テストプログラムの開発に生かせる場面があります。採用の条件は会社や時期によって異なりますが、回路の基礎とテストの考え方を学んでおくと、仕事の理解が早くなります。

設計の検証エンジニアとの違いは何ですか？

検証エンジニアは、製造する前に、設計そのものが仕様どおりかをシミュレーションなどで確かめます。テストエンジニアは、製造したあとの一つひとつのチップに、製造時の欠陥がないかを装置で確かめます。前者は設計の誤りを、後者は製造の不良を見つける仕事と考えると分かりやすいでしょう。

必要な資格はありますか？

一般に、テストエンジニアになるために必須の免許や資格はありません。実務では、回路の理解、テストプログラムを書くプログラミングの力、データを分析して改善につなげる力が重視されます。使うATEやプログラムの書き方は職場によって異なり、多くの場合は入社後に身につけます。
