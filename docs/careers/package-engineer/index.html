パッケージ・実装エンジニア

チップを外部とつなぎ、熱や力、湿気から守るパッケージの設計と組み立て工程を担う技術者です。複数のチップを一体化する先端パッケージも扱います。

仕事の内容

パッケージ・実装エンジニアは、ウエハから切り出したチップを外部の基板と電気的につなぎ、熱や力、湿気から守る形に仕上げる仕事です。担当は大きく、パッケージの構造や材料を決める設計・開発と、ダイシング、ダイボンディング、ワイヤボンディングやフリップチップによる接続、封止などの組み立て工程の条件出しと量産維持に分かれます。製品の熱をどう逃がすか、温度の変化で生じる反りやひずみにどう耐えるかを、シミュレーションと評価で確かめます。複数のチップを一つのパッケージにまとめる先端パッケージも、この職種が扱う領域です。

一緒に働く人・扱うもの

チップの設計者とは端子の配置や電源のつなぎ方を、信頼性エンジニアとは温度サイクル試験などの結果を、テストエンジニアとは最終テストの方法を話し合います。パッケージ基板や封止樹脂などの材料メーカー、組み立てを請け負うOSATと協力することも多くあります。扱うものは、リードフレームやパッケージ基板、はんだボール、封止樹脂、アンダーフィルなどの材料と、組み立て装置、熱や応力のシミュレーション、断面観察やX線による検査の結果です。

求められる知識とスキル

材料、機械、熱、電気の知識を横断的に使う職種です。材料ごとの熱膨張の違いが生む応力、はんだなどの接合部の疲労、熱抵抗による温度上昇の見積もりなどが基本になります。高速な信号を扱う製品では、配線の寄生成分や信号の品質を考える電気設計の知識も求められます。有限要素法などのシミュレーションを使う職場もあります。先端パッケージでは、TSV(シリコン貫通電極)、再配線層(RDL)、ハイブリッドボンディングのように、前工程に近い微細な加工の知識も必要になります。

学び始めるなら

まずは『パッケージ・実装』の分野で、ワイヤボンディング、フリップチップ、BGAなどの基本的な構造と、組み立ての流れを学びましょう。続いて『先端技術(3D実装・チップレット)』の分野で、複数のチップをつなぐ技術を押さえます。パッケージの寿命を左右する故障は『信頼性』、熱抵抗やMSLなどの仕様は『データシートの読み方』、組み立て後の検査は『テスト・検査』の分野で学べます。後工程全体は『後工程・品質・安全』コースでまとめて確認できます。

よくある質問

文系や未経験からパッケージ・実装エンジニアになれますか？

材料・機械・電気などの理工系の知識が役立つ職種です。電子部品の実装、プリント基板、機械設計など、近い分野の経験を生かせる場面があります。未経験者の採用や育成の方針は会社や時期によって異なるため、個別の募集要項を確認してください。

前工程のプロセスエンジニアとの違いは何ですか？

前工程のプロセスエンジニアは、ウエハの上にトランジスタや配線をつくる工程を担当します。パッケージ・実装エンジニアは、完成したチップを切り出してから製品の形にするまでを担当し、熱や機械的な強さ、材料どうしの接合が主なテーマになります。ただし先端パッケージでは、ウエハの状態で配線や接合を行うことが多く、両者の境界は近づいています。

必要な資格はありますか？

一般に、必須の免許や資格はありません。実務では、材料と熱・機械の基礎、評価とシミュレーションの経験が重視されます。電子部品の実装やはんだ付けに関する技能の検定などを学習に活用する人もいますが、採用での扱いは会社によって異なります。
