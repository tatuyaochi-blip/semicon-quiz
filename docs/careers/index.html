半導体業界の職種ガイド

半導体の会社には、製造・開発・設計・品質など、さまざまな仕事があります。職種ごとに、どんな仕事か、どの分野を学んでおくとよいかをまとめました。就職・転職の準備や、配属先の勉強に使えます。

  • プロセスエンジニアウエハ上にトランジスタや配線をつくる前工程で、成膜・エッチング・リソグラフィなどの工程条件を決め、改善し、量産を安定させる技術者です。
  • 装置エンジニア(設備エンジニア)製造装置を決められた性能で動かし続けるために、保守・故障対応・立ち上げを担う技術者です。工場側のほか、装置メーカーで顧客の工場を支える働き方もあります。
  • 歩留まり・品質エンジニアウエハから取れる良品の割合(歩留まり)を上げるために、不良の原因をデータと解析で突き止め、工程の改善と品質の安定につなげる技術者です。
  • デバイスエンジニアトランジスタなどのデバイスの構造を考え、試作したデバイスの電気特性を測って評価し、回路設計で使うモデルにまとめる技術者です。
  • インテグレーションエンジニア多くの工程をつなぎ合わせ、全体としてデバイスが狙いどおりに動く製造の流れを組み立てる技術者です。新しい世代や製品の立ち上げで中心となります。
  • 信頼性エンジニア製品が使われる期間を通じて故障せずに動くことを、加速試験と故障のしくみの解析によって確かめ、保証する技術者です。
  • テストエンジニアウエハやパッケージ後のチップが仕様どおりに動くかを自動試験装置(ATE)で確かめるテストを開発し、品質とテストのコストを両立させる技術者です。
  • パッケージ・実装エンジニアチップを外部とつなぎ、熱や力、湿気から守るパッケージの設計と組み立て工程を担う技術者です。複数のチップを一体化する先端パッケージも扱います。
  • デジタル回路設計・検証エンジニアハードウェア記述言語で論理回路を設計し、シミュレーションで正しさを確かめ、論理合成とタイミング解析を経てチップの形にしていく技術者です。
  • アナログ回路設計エンジニア増幅回路、AD/DA変換回路、電源回路など、連続的な電圧や電流を扱う回路を、トランジスタの特性やレイアウトまで考えて設計する技術者です。
