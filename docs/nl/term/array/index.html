Wat is Array?

Een datastructuur die waarden van hetzelfde type achter elkaar opslaat en elk element aanwijst met een index. Omdat de elementen aaneengesloten in het geheugen staan, kan de positie van elk element uit de index worden berekend, zodat elk element in constante tijd kan worden gelezen of geschreven. Sommige talen laten indexen bij 0 beginnen, sommige notaties bij 1.

Japanse benaming: 配列

Nu oefenen: vragen over Array

Wat is de tijdcomplexiteit van een bewerking die in een array van n elementen elk paar van twee verschillende elementen precies één keer vergelijkt (een dubbele lus die element i vergelijkt met alle elementen erna en i telkens één stap verder zet)?

  1. AO(n)
  2. BO(n log n)
  3. CO(n²)
Antwoord en toelichting tonen

Antwoord: C. O(n²)

Het aantal vergeleken paren is (n−1) + (n−2) + … + 1 = n(n−1)/2: 45 voor n = 10 en 499.500 voor n = 1000. De O-notatie kijkt alleen naar hoe het aantal groeit als n groot wordt, dus de factor 1/2 en de termen van lagere orde vallen weg en het resultaat is O(n²). Als n verdubbelt, wordt het aantal ongeveer vier keer zo groot. O(n) is de complexiteit van een bewerking die elk element één keer bekijkt, en O(n log n) die van algoritmen zoals mergesort, die de gegevens herhaaldelijk in tweeën delen.

Lineair zoeken vergelijkt de elementen van een array met 100 verschillende waarden één voor één vanaf het begin om een gezochte waarde te vinden. De gezochte waarde staat altijd in de array en heeft op elke positie dezelfde kans. Wat is het gemiddelde aantal vergelijkingen?

  1. AOngeveer 7
  2. B50,5
  3. C100
Antwoord en toelichting tonen

Antwoord: B. 50,5

Staat de gezochte waarde op positie k, dan zijn er k vergelijkingen nodig. Het gemiddelde is dus (1 + 2 + … + 100) / 100 = 50,5, in het algemeen (n + 1)/2. In het beste geval (waarde vooraan) is er 1 vergelijking nodig, in het slechtste geval (waarde achteraan) 100. Zowel het gemiddelde als het slechtste geval is evenredig met n, dus de tijdcomplexiteit is O(n). Ongeveer 7 komt overeen met log₂ 100 ≈ 6,6, het aantal stappen van binair zoeken, dat alleen werkt als de gegevens gesorteerd zijn.
