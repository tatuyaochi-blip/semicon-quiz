Wat is Shared memory?

Klein, snel geheugen binnen elke SM van de GPU dat door threads van hetzelfde blok kan worden gedeeld. Het programma bepaalt wat erin wordt geplaatst.

Japanse benaming: シェアードメモリ

Antwoord en toelichting tonen

Antwoord: C. Een klein, snel geheugen op de chip dat door de threads van hetzelfde block kan worden gedeeld en expliciet door het programma wordt gebruikt

Shared memory is een snel geheugen in elke SM van enkele tientallen KB per block, dat tientallen keren sneller kan worden gelezen en geschreven dan global memory (het DRAM van de GPU). Omdat de threads van hetzelfde block er data in kunnen plaatsen en delen, wordt het gebruikt om data één keer uit global memory te lezen en meerdere keren te gebruiken of om tussenresultaten tussen threads door te geven. Anders dan bij een cache bepaalt het programma wat erin wordt geplaatst.

Welke uitspraak over bank conflicts van CUDA shared memory is juist?

  2. BEen probleem waarbij de capaciteit van shared memory tekortschiet en het programma stopt
  3. CShared memory is verdeeld in 32 banks, en als meerdere threads van een warp tegelijk verschillende adressen in dezelfde bank lezen, worden de toegangen na elkaar uitgevoerd en daalt de snelheid
Antwoord en toelichting tonen

Antwoord: C. Shared memory is verdeeld in 32 banks, en als meerdere threads van een warp tegelijk verschillende adressen in dezelfde bank lezen, worden de toegangen na elkaar uitgevoerd en daalt de snelheid

Shared memory bestaat uit 32 banks waaraan om de 4 bytes opeenvolgend adressen zijn toegewezen, en elke bank kan per keer slechts één adres lezen of schrijven. Als de 32 threads van een warp verschillende banks gebruiken, volstaat één keer, maar als twee threads verschillende adressen in dezelfde bank gebruiken, wordt het in twee keer gesplitst. Bij het lezen van bijvoorbeeld elke 32 elementen komt iedereen op dezelfde bank terecht en splitst het zich in 32 keer. Als iedereen hetzelfde adres leest, wordt het in één keer aan allen uitgedeeld en is er geen conflict.
