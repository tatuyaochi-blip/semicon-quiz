Wat is Remote attestation?

Mechanisme waarbij een apparaat de toestand van de software die erin draait met een sleutel in de chip ondertekent en aan een server op afstand toont, zodat die kan nagaan of het apparaat te vertrouwen is.

Japanse benaming: リモートアテステーション

“Remote attestation” komt voor in 2 oefenvragen uit 1 onderwerpen, bijv. Hardwarebeveiliging.

Vakgebied: Hardwarebeveiliging

Welke uitspraak over remote attestation (attestatie op afstand) is juist?

  1. AIemand op afstand kijkt naar het scherm van een apparaat en bedient het
  2. BEen apparaat laat de locatie via GPS aan een server weten
  3. CEen apparaat toont de toestand van de software die in het apparaat draait, ondertekend met een sleutel in de chip, aan een server op afstand, die controleert of het betrouwbaar is
Antwoord en toelichting tonen

Antwoord: C. Een apparaat toont de toestand van de software die in het apparaat draait, ondertekend met een sleutel in de chip, aan een server op afstand, die controleert of het betrouwbaar is

Bij remote attestation ondertekent een apparaat de meetwaarden van software die in een TPM of TEE zijn vastgelegd met een sleutel die niet uit de chip kan worden gehaald en stuurt ze naar een server. De server controleert handtekening en meetwaarden en geeft alleen aan apparaten die met vastgestelde software draaien geheime data of diensten. Het wordt gebruikt wanneer vertrouwelijke berekeningen aan de cloud worden toevertrouwd of wanneer wordt gecontroleerd welke apparaten met een bedrijfsnetwerk mogen verbinden.
