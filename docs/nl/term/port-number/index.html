Wat is Poortnummer?

Getal van 0 tot 65535 waarmee TCP en UDP aangeven voor welke applicatie op een apparaat het verkeer bestemd is. De poorten 0–1023, zoals 80 voor HTTP, 443 voor HTTPS en 53 voor DNS, heten well-known ports.

Antwoord en toelichting tonen

Antwoord: A. HTTP 80, HTTPS 443, DNS 53

Een poortnummer is een getal van 16 bits van 0 tot 65535 dat aangeeft voor welke applicatie op een via het IP-adres bereikt apparaat het verkeer bestemd is. De poorten 0–1023 heten well-known ports en zijn toegewezen aan de belangrijkste diensten. Typische voorbeelden zijn HTTP 80, HTTPS 443, DNS 53, SSH 22 en SMTP (doorsturen van e-mail) 25. De client gebruikt als bronpoort een nummer dat het besturingssysteem telkens kiest (een ephemeral port). Diensten kunnen ook op een afwijkend nummer draaien; 8080 wordt vaak gebruikt voor webontwikkeling of proxyservers, maar dan moet de verbindende kant het nummer opgeven.
