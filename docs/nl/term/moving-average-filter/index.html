Wat is Moving-averagefilter?

Het eenvoudigste laagdoorlaatfilter, dat het gemiddelde van de laatste N samples als uitgang geeft. Het is y[n] = (x[n] + x[n − 1] + … + x[n − N + 1])/N, een FIR-filter waarvan alle coëfficiënten 1/N zijn. De DC-versterking is 1 en de versterking is 0 bij gehele veelvouden van fs/N, dus middelen over een interval dat precies samenvalt met de netperiode verwijdert bijvoorbeeld ruis op de netfrequentie en de harmonischen daarvan. De coëfficiënten zijn symmetrisch, dus het filter heeft een lineaire fase met een vertraging van (N − 1)/2 samples. Door de som bij te werken met de nieuwste sample erbij en de oudste eraf, kan het filter ongeacht N met weinig bewerkingen worden berekend.

Nu oefenen: vragen over Moving-averagefilter

Bij een bemonsteringsfrequentie van 8 kHz middelt een moving-averagefilter y[n] = (x[n] + x[n − 1] + … + x[n − 7])/8 de laatste 8 samples. Wat is de laagste frequentie waarbij de uitgang 0 is?

  1. A500 Hz
  2. B1 kHz
  3. C4 kHz
Antwoord en toelichting tonen

Antwoord: B. 1 kHz

De versterking van een moving average over N samples is (1 + 1 + … + 1)/N = 1 bij DC, en 0 bij gehele veelvouden van fs/N (DC uitgezonderd). Een sinusgolf op fs/N = 8000 ÷ 8 = 1 kHz doorloopt in 8 samples precies één periode, dus het gemiddelde ervan is 0. De moving average is een eenvoudig laagdoorlaatfilter, maar heeft zijlobben waar de versterking tussen de nulpunten weer stijgt, zodat de afsnijding niet erg steil is.
