Wat is API (application programming interface)?

Het geheel van afspraken (namen van functies of bewerkingen, argumenten, returnwaarden, gegevensformaten enzovoort) waarmee andere programma's de functies van een stuk software aanroepen en gebruiken. Voorbeelden zijn API's van besturingssystemen, API's van bibliotheken en web-API's die gegevens uitwisselen via HTTP, zoals REST-API's. Aanroepers hoeven de implementatie niet te kennen, en de implementatie kan worden vervangen zolang de API gelijk blijft. De overeenkomstige afspraak op het niveau van de machinecode heet de ABI.

Nu oefenen: vragen over API (application programming interface)

Cloudopslag wordt voor drie doeleinden gebruikt: (1) als schijf aan een virtuele machine koppelen, er een bestandssysteem op maken en de gegevensbestanden van een database erop plaatsen; (2) tegelijk vanaf meerdere servers mounten en als gedeelde map gebruiken; (3) een groot aantal afbeeldingen via een API over HTTP met een sleutel (naam) lezen en schrijven, en de capaciteit laten groeien zonder die vooraf vast te leggen. Welke combinatie van opslagsoorten is geschikt voor (1) tot (3)?

  1. A(1) objectopslag, (2) blokopslag, (3) bestandsopslag
  2. B(1) bestandsopslag, (2) objectopslag, (3) blokopslag
  3. C(1) blokopslag, (2) bestandsopslag, (3) objectopslag
Antwoord en toelichting tonen

Antwoord: C. (1) blokopslag, (2) bestandsopslag, (3) objectopslag

Blokopslag koppelt een gebied met een vaste grootte als virtuele schijf aan een virtuele machine; er wordt een bestandssysteem op gemaakt, en het is geschikt voor toepassingen zoals databases die veel kleine lees- en schrijfbewerkingen snel uitvoeren. Bestandsopslag levert een gedeeld bestandssysteem dat meerdere servers tegelijk kunnen mounten via NFS, SMB of iets vergelijkbaars. Objectopslag leest en schrijft gegevens als volledige objecten die met sleutels worden aangeduid, via een API over HTTP; de capaciteit kan vrijwel onbeperkt groeien, en het is geschikt voor afbeeldingen, back-ups en logs. Het is niet geschikt om een deel van een object te herschrijven; de gegevensbestanden van een database worden er dus niet in geplaatst.

Een web-API geeft gegevens in JSON-formaat terug als body van het antwoord. Welke header wordt in het algemeen aan het antwoord toegevoegd om het formaat van de body aan te geven?

  1. AAccept: application/json
  2. BContent-Type: text/html
  3. CContent-Type: application/json
Antwoord en toelichting tonen

Antwoord: C. Content-Type: application/json

Het soort gegevens in de body wordt aangegeven met de header Content-Type, met als waarde een mediatype (MIME-type) in de vorm „type/subtype”, zoals text/html of image/png. Het mediatype van JSON is application/json. JSON is een tekstformaat dat gegevens weergeeft met naam-waardeparen en arrays, zoals in {"id": 42, "tags": ["a", "b"]}; het is beknopter dan XML en gemakkelijk te verwerken vanuit JavaScript, en wordt daarom veel gebruikt in web-API's. De header Accept wordt in een verzoek gebruikt om de server te laten weten welke formaten de client wil ontvangen.
