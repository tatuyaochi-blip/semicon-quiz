Wat is Objectgeoriënteerd programmeren?

Een benadering die programma's opbouwt uit objecten, die elk gegevens bundelen met de procedures (methoden) die erop werken. De blauwdruk voor objecten heet een klasse, elk object dat uit een klasse wordt gemaakt heet een instantie, en elke instantie heeft haar eigen waarden van de lidvariabelen.

Japanse benaming: オブジェクト指向

“Objectgeoriënteerd programmeren” komt voor in 1 oefenvragen uit 1 onderwerpen, bijv. Basis van programmeren (pseudocode traceren).

Vakgebied: Basis van programmeren (pseudocode traceren)
