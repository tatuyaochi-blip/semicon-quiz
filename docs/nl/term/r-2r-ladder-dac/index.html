Wat is R-2R-laddernetwerk-DAC?

DA-omzetter die slechts twee weerstandswaarden, R en 2R, in een laddernetwerk gebruikt. Er zijn weinig soorten weerstanden nodig en de weerstandsverhouding blijft klein, ook als het aantal bits toeneemt.

Japanse benaming: R-2Rラダー型DAC

Vakgebied: A/D- en D/A-conversie

Verwante termen

Aliasing Bemonsteringstheorema (sampling theorem) DNL (differentiële niet-lineariteit) ENOB (effectief aantal bits) Flash-ADC INL (integrale niet-lineariteit) Jitter Kwantisatiefout Missing code Noise shaping
