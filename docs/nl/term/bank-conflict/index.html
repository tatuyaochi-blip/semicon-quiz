Wat is Bankconflict?

Bij gedeeld geheugen het verschijnsel dat meerdere threads van een warp tegelijk verschillende adressen in dezelfde bank benaderen, waardoor de toegangen na elkaar worden uitgevoerd en het traag wordt. Is te vermijden met padding.

Japanse benaming: バンク競合

Vakgebied: GPU-programmeren

Verwante termen

Constant memory CUDA Gemengde precisie (mixed precision) GPU-kernel Grid-stride loop Latentieverberging (latency hiding) Memory coalescing Occupancy OpenCL Parallelle reductie
