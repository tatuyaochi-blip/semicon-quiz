Wat is DHCP (Dynamic Host Configuration Protocol)?

Protocol dat apparaten die met een netwerk verbinding maken automatisch en voor beperkte tijd een IP-adres, subnetmasker, standaardgateway, DNS-servers en andere instellingen toekent.

Japanse benaming: DHCP

Nu oefenen: vragen over DHCP (Dynamic Host Configuration Protocol)

Wat is de juiste volgorde van de berichten wanneer een apparaat via DHCP een IP-adres verkrijgt?

  1. ARequest → Offer → Discover → Ack
  2. BDiscover → Offer → Request → Ack
  3. COffer → Discover → Ack → Request
Antwoord en toelichting tonen

Antwoord: B. Discover → Offer → Request → Ack

Een apparaat dat nog geen adres heeft, weet ook niet waar de DHCP-server is en stuurt daarom eerst een Discover als broadcast. Een server stelt in een Offer een adres en andere instellingen voor, het apparaat laat in een Request weten welk aanbod van welke server het aanneemt, en de server bevestigt met een Ack. Naar de beginletters heet dit DORA. Naast het IP-adres ontvangt het apparaat onder meer het subnetmasker, de standaardgateway en de adressen van de DNS-servers. Adressen worden voor beperkte tijd uitgeleend (de lease), en het apparaat vraagt om verlenging voordat die afloopt. Om een DHCP-server voorbij een router te gebruiken, wordt op de router een DHCP-relay ingesteld.

Apparaten in VLAN 20 (192.168.20.0/24) moeten hun adressen krijgen van een DHCP-server, 10.0.0.5, in een ander netwerk. Daarom is op de interface 192.168.20.1 van de L3-switch, de standaardgateway van VLAN 20, een DHCP-relayagent ingesteld. Welke beschrijving van wat de relayagent doet, is juist?

  1. AHij ontvangt de DHCP-berichten die apparaten als broadcast versturen, schrijft er zijn eigen adres aan de kant van VLAN 20, 192.168.20.1, in en stuurt ze via unicast door naar 10.0.0.5. Aan de hand van dit adres kiest de server een adres uit het bereik voor 192.168.20.0/24
  2. BDe L3-switch gaat de broadcasts die hij ontvangt naar alle netwerken doorsturen, zodat de DHCP-berichten de server bereiken
  3. CDe L3-switch kiest in plaats van de DHCP-server de adressen en leent ze uit aan de apparaten, en meldt de resultaten alleen aan 10.0.0.5
Antwoord en toelichting tonen

Antwoord: A. Hij ontvangt de DHCP-berichten die apparaten als broadcast versturen, schrijft er zijn eigen adres aan de kant van VLAN 20, 192.168.20.1, in en stuurt ze via unicast door naar 10.0.0.5. Aan de hand van dit adres kiest de server een adres uit het bereik voor 192.168.20.0/24

Een apparaat dat nog geen adres heeft, verstuurt een Discover als broadcast om een DHCP-server te vinden, maar routers en L3-switches sturen broadcasts niet door naar andere netwerken. Een DHCP-relayagent ontvangt deze berichten, geeft ze via unicast door aan de server en stuurt de antwoorden van de server terug naar het apparaat. Bij het doorgeven schrijft hij het adres van zijn interface aan de kant van het apparaat (hier 192.168.20.1) in een veld van het bericht (giaddr). Aan dat adres ziet de server in welk subnet het apparaat zit (192.168.20.0/24), en hij kiest een adres uit het bereik voor dat subnet. Zo kan één DHCP-server veel subnetten bedienen zonder een server in elk VLAN.
