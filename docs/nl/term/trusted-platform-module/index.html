Wat is TPM?

Trusted Platform Module. Beveiligingschip of -functie die sleutels genereert en bewaart, meetwaarden van opgestarte software vastlegt en de toestand bevestigt.

Japanse benaming: TPM

“TPM” komt voor in 5 oefenvragen uit 3 onderwerpen, bijv. Hardwarebeveiliging, Basis en toepassingen van cryptografie, Hardwarebeveiliging: nieuwste ontwikkelingen.

Vakgebied: Hardwarebeveiliging

Wat er in een TPM zit

Een Trusted Platform Module is een manipulatiebestendige beveiligingschip, of een equivalente functie die in firmware op de hoofdprocessor is geïmplementeerd, vaak fTPM genoemd. Hij bevat een random-number-generator, engines voor hashen, ondertekenen en versleutelen, beschermde niet-vluchtige opslag en een set platform configuration registers (PCR's). Sleutels kunnen in de TPM worden gegenereerd en daar worden gebruikt zonder dat het private deel ooit onversleuteld naar buiten komt. De interface is gedefinieerd door de Trusted Computing Group, en huidige pc's gebruiken versie 2.0.

Measured boot en PCR's

Bij measured boot hasht elke stage het volgende stuk software voordat het wordt uitgevoerd en extendt de hash in een PCR. Extenden betekent dat de nieuwe PCR-waarde de hash is van de oude waarde, aaneengeschakeld met de nieuwe meting; software kan een PCR niet direct schrijven, en de PCR's voor bootmetingen worden alleen door een platformreset gewist. De eindwaarden vatten daardoor de hele bootvolgorde in volgorde samen, en elke wijziging levert andere waarden op. Anders dan secure boot houdt measured boot niets tegen; het levert bewijs voor latere controles.

Sealing en remote attestation

Uit PCR's volgen twee toepassingen. Sealing bindt data, zoals een sleutel voor schijfversleuteling, aan specifieke PCR-waarden, zodat de TPM die alleen vrijgeeft als het platform de verwachte software heeft geboot; een verwijderde schijf of een gewijzigde bootloader krijgt niets. Bij remote attestation ondertekent de TPM een rapport van zijn PCR-waarden met een sleutel die niet kan worden geëxtraheerd, en een server controleert de handtekening en de metingen voordat hij geheimen, diensten of netwerktoegang verleent. Een verse willekeurige challenge van de server voorkomt dat een oud rapport opnieuw wordt afgespeeld.

TPM vs. secure element en TEE

Een TPM is een gestandaardiseerde component voor platformvertrouwen, gericht op meting, sleutelbescherming en attestation, en is relatief traag; bulkversleuteling draait op de CPU met sleutels die de TPM heeft vrijgegeven. Een secure element is een chip van smartcardklasse voor betaal- of identiteitsgegevens, en een trusted execution environment (TEE) is een geïsoleerde modus van de hoofdprocessor die vertrouwde code uitvoert. Systemen combineren ze vaak, en attestation kan geworteld zijn in een TPM of in een TEE.

Een TPM is een tegen manipulatie van buitenaf bestendige beveiligingschip (of in de CPU opgenomen functie) die onder meer sleutels genereert en bewaart, cryptografie uitvoert, toevalsgetallen genereert en hashes van gestarte software vastlegt. Als de sleutel voor schijfversleuteling bijvoorbeeld alleen wordt vrijgegeven wanneer de opstarttoestand juist is, zijn de data moeilijk te lezen, ook als de schijf wordt verwijderd of de opstartsoftware wordt herschreven.

Veelgestelde vragen

Verschil tussen TPM en secure boot

Secure boot voorkomt dat niet-ondertekende of gewijzigde bootsoftware draait. Een TPM legt metingen vast van wat er is geboot, beschermt sleutels en kan de platformtoestand aan anderen bewijzen; de twee worden vaak samen gebruikt.

Wat is een PCR in een TPM?

Een platform configuration register bevat een doorlopende hash van gemeten software. Het kan alleen worden geëxtend door nieuwe metingen in te hashen, zodat de waarde de exacte volgorde weerspiegelt van wat sinds de reset is geladen.

Wat is een firmware-TPM (fTPM)?

Het is TPM-functionaliteit die is geïmplementeerd in firmware die in een geïsoleerde omgeving van de hoofdprocessor draait in plaats van in een aparte chip. Het biedt dezelfde interface, maar een andere weerstand tegen fysieke aanvallen dan een discrete TPM.
