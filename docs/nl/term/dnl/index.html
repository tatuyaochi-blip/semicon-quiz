Wat is DNL (differentiële niet-lineariteit)?

Fout die aangeeft hoeveel de stapbreedte tussen aangrenzende codes van een AD-omzetter afwijkt van de ideale 1 LSB. Bij −1 LSB ontstaat een ontbrekende code (missing code).

Japanse benaming: DNL(微分非直線性)

“DNL (differentiële niet-lineariteit)” komt voor in 8 oefenvragen uit 3 onderwerpen, bijv. A/D- en D/A-conversie, Testen en inspectie, Datasheets lezen.

Vakgebied: A/D- en D/A-conversie

Hoe DNL is gedefinieerd

Een ideale N-bit-omzetter verdeelt zijn volle bereik in 2ᴺ gelijke stappen van 1 LSB (least significant bit). Bij een analoog-digitaalomzetter (ADC) moet elke uitgangscode daarom overeenkomen met een ingangsinterval van precies 1 LSB breed. Differentiële niet-lineariteit (DNL) is de fout in de werkelijke breedte van elke code, uitgedrukt in LSB: DNL = (werkelijke breedte − 1 LSB) / 1 LSB. Een code van 1,5 LSB breed heeft DNL = +0,5 LSB, en een van 0,7 LSB breed −0,3 LSB. Bij een digitaal-analoogomzetter (DAC) geldt hetzelfde idee voor de grootte van elke uitgangsstap.

Ontbrekende codes en monotonie

Wanneer de DNL van een code −1 LSB bereikt, krimpt haar breedte tot nul, zodat die code nooit verschijnt, hoe de ingang ook wordt doorlopen: een ontbrekende code (missing code). Een garantie van ‘geen ontbrekende codes’ bij een bepaalde resolutie staat dus gelijk aan een DNL die boven −1 LSB blijft. Een grote positieve DNL, boven ongeveer +1 LSB, verspilt resolutie, omdat één brede code bestrijkt wat meerdere codes hadden moeten zijn. Bij een DAC garandeert een DNL boven −1 LSB monotonie: de uitgang daalt nooit wanneer de code stijgt. Fouten concentreren zich bij de grote carry-overgangen, zoals van 0111…1 naar 1000…0, waar niet-overeenkomende binair gewogen elementen worden omgewisseld.

DNL versus INL, offset- en versterkingsfout

Een offsetfout verschuift de hele overdrachtskromme en een versterkingsfout verandert haar helling; beide zijn lineair en kunnen met een tweepuntskalibratie worden verwijderd. Integrale niet-lineariteit (INL) is de maximale afwijking van de werkelijke kromme ten opzichte van een rechte lijn, getrokken door de eindpunten of als best passende lijn, en is bij elke code gelijk aan de cumulatieve som van de DNL tot die code. Een omzetter kan dus overal een kleine DNL hebben en toch een grote INL, als kleine fouten zich in één richting opstapelen. INL uit zich als harmonische vervorming bij grote signalen, terwijl DNL de nauwkeurigheid van kleine stappen en ontbrekende codes bepaalt; geen van beide wordt met eenvoudige kalibratie opgelost.

DNL meten en omlaag ontwerpen

De histogram- of code-density-methode voert de ADC een signaal toe met een bekende amplitudeverdeling en telt hoe vaak elke code voorkomt. Bij een langzame ramp of driehoek zou elke code hetzelfde aantal treffers moeten krijgen, dus het aantal per code gedeeld door het gemiddelde, min één, geeft de DNL van die code; een sinus is makkelijker zuiver te maken, maar vereist correctie voor zijn verdeling die naar de pieken toe zwaarder weegt. Het sommeren van de DNL geeft de INL. Aan de ontwerpkant zijn thermometergecodeerde current-steering-DAC's en weerstandsladder-DAC's (resistor string) per constructie monotoon, en het segmenteren van de hogere bits in elementen met gelijk gewicht vermindert de DNL bij grote overgangen.

Nu oefenen: vragen over DNL (differentiële niet-lineariteit)

Welke uitspraak over de differentiële niet-lineariteit (DNL) van een AD-converter is juist?

  1. ADe fout in de helling (versterking) van de gehele overdrachtskarakteristiek
  2. BDe afwijking van de breedte (stapgrootte) tussen aangrenzende codes ten opzichte van de ideale 1 LSB
  3. CDe afwijking van de uitgang wanneer de ingang nul is
Antwoord en toelichting tonen

Antwoord: B. De afwijking van de breedte (stapgrootte) tussen aangrenzende codes ten opzichte van de ideale 1 LSB

DNL geeft aan hoeveel de ingangsbreedte (stapgrootte) per code afwijkt van de ideale 1 LSB; bij een breedte van 1,5 LSB is DNL bijvoorbeeld +0,5 LSB. Bij een DNL van −1 LSB verschijnt de betreffende code niet meer (missing code), en boven +1 LSB neemt de effectieve resolutie af. De afwijking van de gehele karakteristiek ten opzichte van de ideale rechte is de integrale niet-lineariteit (INL), en de afwijking van de uitgang bij nul ingang is de offsetfout.

Veelgestelde vragen

Wat betekent een DNL van ±0,5 LSB?

Elke codebreedte ligt tussen 0,5 en 1,5 LSB, dus er ontbreekt geen enkele code en geen code is breder dan anderhalve ideale stap. Het is een gangbare specificatie voor omzetters van goede kwaliteit.

Wat is het verschil tussen DNL en INL?

DNL is de fout in de breedte van elke afzonderlijke stap, terwijl INL aangeeft hoe ver de hele overdrachtskromme van een rechte lijn afdwaalt. De INL bij een code is in wezen de opgetelde DNL tot dat punt.

Garandeert een DNL groter dan −1 LSB dat er geen codes ontbreken?

Ja. Een ontbrekende code is precies een code waarvan de breedte tot nul is gekrompen, wat overeenkomt met DNL = −1 LSB, dus door elke DNL boven −1 LSB te houden is dat uitgesloten.
