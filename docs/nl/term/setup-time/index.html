Wat is Insteltijd (setup time)?

Minimale tijd dat de data-ingang van een flipflop vóór de actieve klokflank stabiel moeten zijn. Paden die hieraan niet voldoen, beperken de maximale werkfrequentie van de schakeling.

Japanse benaming: セットアップ時間
