Wat is Surface code (oppervlaktecode)?

Code voor kwantumfoutcorrectie waarbij qubits op een tweedimensionaal rooster zijn geplaatst en fouten worden gedetecteerd met alleen bewerkingen tussen naburige qubits. De drempel is hoog, ruwweg 1%, en de code past goed bij chips met supergeleidende qubits. De geroteerde versie met codeafstand d gebruikt 2d² − 1 fysieke qubits per logische qubit.

Nu oefenen: vragen over Surface code (oppervlaktecode)

Een geroteerde surface code met codeafstand d gebruikt voor één logische qubit d² fysieke dataqubits en d² − 1 fysieke meetqubits die op fouten controleren. Hoeveel fysieke qubits heeft één logische qubit nodig bij d = 15?

  1. A29
  2. B225
  3. C449
Antwoord en toelichting tonen

Antwoord: C. 449

Er zijn 15² = 225 dataqubits en 225 − 1 = 224 meetqubits, in totaal 2d² − 1 = 449. Een code met afstand d kan tot (d − 1)/2 fouten corrigeren, dus d = 15 kan tot 7 fouten aan. Volgens schattingen vraagt het halen van de logische foutkansen die voor praktische berekeningen nodig zijn, bij fysieke foutkansen van ongeveer 0,1%, een d van ruim tien tot ongeveer 25; dat betekent enkele honderden tot ruim duizend fysieke qubits per logische qubit. Omdat de surface code werkt met alleen bewerkingen tussen naburige qubits op een tweedimensionaal rooster, past hij goed bij chips met supergeleidende qubits.

Stel dat de logische foutkans p_L van een surface code kan worden benaderd als p_L ∝ (p/p_th)^((d+1)/2), met de fysieke foutkans p, de drempel p_th en de codeafstand d. Welke waarde ligt bij p = 0,1% en p_th = 1% het dichtst bij de verhouding van de logische foutkansen als d van 5 naar 9 wordt verhoogd (de waarde bij d = 5 gedeeld door de waarde bij d = 9)?

  1. AOngeveer 1,8
  2. BOngeveer 10
  3. COngeveer 100
Antwoord en toelichting tonen

Antwoord: C. Ongeveer 100

De exponent (d+1)/2 is 3 voor d = 5 en 5 voor d = 9, dus de verhouding is (p_th/p) in het kwadraat = 10² = 100, ongeveer 100. Ligt de fysieke foutkans ruim onder de drempel, dan verlaagt elke verhoging van de codeafstand met 2 de logische foutkans met een factor p_th/p (hier 10), zodat fouten exponentieel afnemen naarmate er meer qubits worden ingezet. Ligt p omgekeerd boven de drempel, dan voegt een grotere d alleen meer kansen op fouten toe en wordt de logische foutkans slechter. De drempel van de surface code hangt af van het foutmodel, maar ligt ruwweg rond 1%, en de fysieke foutkans ruim onder de drempel houden is een voorwaarde voor foutcorrectie.
