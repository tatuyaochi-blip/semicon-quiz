Wat is Stuck-at-fout?

Basaal foutmodel voor het testen van logische schakelingen waarbij wordt aangenomen dat de waarde van een signaallijn vastzit op 0 of 1. Ook stuck-at fault genoemd.

Japanse benaming: 縮退故障

Vakgebied: Testen en inspectie

Verwante termen

ATE (automatic test equipment) ATPG (automatic test pattern generation) BIST (built-in self-test) Burn-in DFT (design for testability) Foutdekking (fault coverage) IDDQ-test KGD (known good die) Probe card Scantest
