Wat is Struct (C-structuur)?

Een mechanisme in C dat meerdere waarden (members), mogelijk van verschillende typen, samenvoegt tot één type. Een struct wordt gedefinieerd zoals in struct sensor { int id; float value; }; de members van een variabele s worden gebruikt als s.id, en via een pointer p naar een struct als p->id. De members liggen in de volgorde van declaratie in het geheugen, maar voor de uitlijning kan er opvulling (padding) tussen worden ingevoegd, zodat het geheel groter kan zijn dan de som van de groottes van de members.

Vakgebied: Basis van programmeren in C

Definitie en gebruik

Met de definitie struct point { int x; int y; }; wordt een variabele gemaakt zoals in struct point p = {1, 2}; en wordt elke member gebruikt als p.x of p.y. Met typedef een alias geven, zoals in typedef struct { … } Point;, maakt de declaratie Point p; mogelijk zonder struct te schrijven. Structs kunnen met = in hun geheel worden toegekend, als argument aan functies worden doorgegeven en als retourwaarde worden teruggegeven, maar grote structs worden in het algemeen via een pointer doorgegeven.

Indeling in het geheugen

Members worden in de volgorde van declaratie geplaatst, van lagere adressen naar hogere. Vóór een type dat uitgelijnd moet worden, zoals een int van 4 bytes op een grens van 4 bytes, wordt opvulling (padding) ingevoegd, en de grootte van de hele struct wordt naar boven afgerond op een veelvoud van de strengste uitlijning. Een struct met char, int en char in die volgorde neemt daardoor in een gebruikelijke omgeving met een int van 4 bytes 12 bytes in, en door de int vooraan te zetten, daalt dat tot 8 bytes.

Aandachtspunten in embedded systemen en communicatie

De indeling van registers van randapparaten met een struct weergeven is gebruikelijk, maar de padding en de bitvolgorde van bitvelden mogen per implementatie verschillen, dus wie ze zonder controle gebruikt, kan verschoven adressen krijgen. Wie communicatiegegevens of een bestandsformaat behandelt als de ruwe geheugeninhoud van een struct, verliest door verschillen in padding en endianness de compatibiliteit met andere omgevingen, dus worden de gegevens vaak byte voor byte samengesteld.

Antwoord en toelichting tonen

Antwoord: B. De volgorde van de bits in bitvelden mag per compiler verschillen, dus met een andere compiler kunnen onbedoeld andere bits worden bewerkt

Bitvelden zijn leesbaar te schrijven, maar de C-norm laat het aan de implementatie of bits in een struct van hoog naar laag of van laag naar hoog worden geplaatst, hoe velden die een grens overschrijden worden behandeld en welke toegangsbreedte wordt gebruikt. Wat bij de ene compiler goed werkt, kan daarom bij een andere compiler of CPU andere bits lezen of schrijven. De headers van microcontrollerfabrikanten zijn vaak geschreven met maskers en verschuivingen.

Veelgestelde vragen

Wat is het verschil tussen een struct en een array?

Een array zet elementen van hetzelfde type achter elkaar, die met een index worden gekozen. Een struct voegt members van mogelijk verschillende typen samen, die met hun naam worden gekozen. De twee worden vaak gecombineerd, zoals in een array van structs of een struct met een array als member.

Waarom moet de grootte van een struct met sizeof worden gecontroleerd?

Hoeveel padding er tussen en na de members komt, hangt af van de groottes van de typen en de regels voor uitlijning (de ABI), dus het optellen van de groottes van de members geeft niet de juiste grootte. Bij het reserveren van een struct met malloc of het wegschrijven naar een bestand wordt de werkelijke grootte bepaald met sizeof(struct naam).
