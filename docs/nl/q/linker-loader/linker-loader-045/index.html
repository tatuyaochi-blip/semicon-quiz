Antwoord en toelichting tonen

Antwoord: B. Linux gebruikt ELF, Windows gebruikt PE en macOS gebruikt Mach-O

Het formaat van uitvoerbare bestanden is per OS vastgelegd. Linux, BSD en veel embedded apparaten gebruiken ELF, Windows gebruikt PE (Portable Executable) voor .exe en .dll, en macOS en iOS gebruiken Mach-O. De ideeën erachter (code- en datagebieden, symbolen, relocatie en informatie voor dynamisch linken) lijken op elkaar, maar omdat de formaten verschillen, werkt een uitvoerbaar bestand ook voor dezelfde CPU niet zomaar op een ander OS.
