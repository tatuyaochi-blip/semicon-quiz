Systeemarchitectuur en betrouwbaarheid

Wat is een kenmerk van een peer-to-peersysteem (P2P)?

  1. AElke computer vervult zowel de rol van client als die van server, dus verwerking en verkeer concentreren zich niet snel op een bepaalde server
  2. BAlle communicatie loopt over een centrale server, dus de belasting van de server verandert niet als het aantal gebruikers toeneemt
  3. CGegevensconsistentie en gebruikersbeheer zijn eenvoudig samen op één server te regelen
Antwoord en toelichting tonen

Antwoord: A. Elke computer vervult zowel de rol van client als die van server, dus verwerking en verkeer concentreren zich niet snel op een bepaalde server

In een peer-to-peersysteem zijn de computers (peers) die op het netwerk zijn aangesloten gelijkwaardig, en elk ervan vraagt diensten aan en levert ze ook. Omdat er geen speciale server is, concentreren verwerking en verkeer zich niet snel op één plek, en hoe meer peers meedoen, hoe meer middelen het systeem als geheel kan bieden. Anderzijds kunnen gegevensconsistentie, gebruikersbeheer en beveiliging niet op één plek worden geregeld, wat het beheer lastiger maakt.
