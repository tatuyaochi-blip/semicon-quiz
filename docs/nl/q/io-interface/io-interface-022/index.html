Interfaces en busstandaarden

Welke uitspraak over de werking van USB-communicatie is juist (voor conventionele USB, met uitzondering van USB4)?

  1. ADe host bepaalt het communicatieschema en bevraagt apparaten, en apparaten verzenden data op aanwijzing van de host
  2. BAlle apparaten zijn gelijkwaardig en kunnen zelf naar believen data verzenden
  3. CIn principe communiceren apparaten rechtstreeks met elkaar zonder de host
Antwoord en toelichting tonen

Antwoord: A. De host bepaalt het communicatieschema en bevraagt apparaten, en apparaten verzenden data op aanwijzing van de host

Bij USB beheert de host, zoals een pc, de aangesloten apparaten en bepaalt met welk apparaat wanneer wordt gecommuniceerd. Ook een apparaat zoals een muis stuurt de invoerdata terug wanneer de host periodiek bevraagt. Het voordeel is dat de apparaatzijde eenvoudig kan zijn en veel apparaten goedkoop kunnen worden gemaakt. Bij het aansluiten meldt een apparaat zijn type aan de host en laadt de host het passende stuurprogramma.
