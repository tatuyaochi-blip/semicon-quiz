Basis van digitale signaalverwerking

Welk verband tussen de eenheidsimpuls δ[n] (1 bij n = 0, elders 0) en de eenheidsstap u[n] (1 voor n ≥ 0, 0 voor n < 0) is juist?

  1. Aδ[n] = u[n] + u[n − 1]
  2. Bδ[n] = u[n] × u[n − 1]
  3. Cδ[n] = u[n] − u[n − 1]
Antwoord en toelichting tonen

Antwoord: C. δ[n] = u[n] − u[n − 1]

Trekt men u[n − 1], de met één sample vertraagde stap, af van u[n], dan krijgt men 1 − 1 = 0 voor n ≥ 1, 1 − 0 = 1 bij n = 0 en 0 voor n < 0, en dat is δ[n]. Omgekeerd is u[n] de cumulatieve som van δ[n] tot en met n. Zo wordt het verband uit de continue tijd, „de afgeleide van een stap is een impuls, en de integraal van een impuls is een stap”, uitgedrukt met een verschil en een cumulatieve som.
