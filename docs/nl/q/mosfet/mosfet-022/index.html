MOSFET

Welk probleem is juist bij een polysilicium-gate wanneer het polysilicium aan de gatezijde uitgeput raakt?

  1. ADe weerstand van de gate wordt 0
  2. BDe transistor straalt licht uit
  3. CHet komt neer op een effectief dikkere gate-isolator, waardoor de aandrijfstroom afneemt
Antwoord en toelichting tonen

Antwoord: C. Het komt neer op een effectief dikkere gate-isolator, waardoor de aandrijfstroom afneemt

Omdat polysilicium een halfgeleider is, ontstaat bij het aanleggen van een spanning op de gate ook aan de gate-elektrodezijde een uitputtingslaag van ongeveer 0,3 tot 0,5 nm dik. Deze werkt als een seriecapaciteit, wat gelijkstaat aan een toegenomen effectieve isolatordikte, zodat de aandrijfstroom daalt. Naarmate de isolator tot enkele nm dun werd, werd dit een niet meer te verwaarlozen aandeel. Bij High-k/metal gate (HKMG) vanaf de 45 nm-generatie is dit probleem opgelost omdat een metalen elektrode wordt gebruikt.
