Logische schakelingen

Welk bereik van gehele getallen kan met 8-bits two's-complementrepresentatie worden voorgesteld?

  1. A−128 tot +127
  2. B−127 tot +127
  3. C0 tot 255
Antwoord en toelichting tonen

Antwoord: A. −128 tot +127

Een two's complement van n bits stelt −2ⁿ⁻¹ tot 2ⁿ⁻¹ − 1 voor, bij 8 bits dus −128 tot +127. Omdat 0 slechts op één manier wordt voorgesteld (00000000), heeft de negatieve kant er één meer. Bij grenswaarden is voorzichtigheid geboden: −128 vermenigvuldigd met −1 kan niet worden voorgesteld en geeft overloop. Bij 16 bits is het −32.768 tot +32.767 en bij 32 bits ongeveer ±2,1 miljard. 0 tot 255 is het bereik als dezelfde 8 bits zonder teken worden geïnterpreteerd.
