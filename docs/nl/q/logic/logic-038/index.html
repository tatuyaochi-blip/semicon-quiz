Logische schakelingen

Wat gebeurt er in een JK-flip-flop als J = 1 en K = 1 en er een klok binnenkomt?

  1. ADe uitgang keert om (toggle)
  2. BDe uitgang wordt op 0 gereset
  3. CDe uitgang wordt vastgehouden
Antwoord en toelichting tonen

Antwoord: A. De uitgang keert om (toggle)

Een JK-flip-flop zet bij J = 1, K = 0, reset bij J = 0, K = 1, houdt vast bij J = K = 0 en togglet (keert om) bij J = K = 1. Het geeft de bij de SR-flip-flop verboden combinatie S = R = 1 de betekenis „omkeren”, en de volgende toestand kan worden geschreven als Q⁺ = J·¬Q + ¬K·Q. Door J en K te verbinden tot één ingang T ontstaat een T-flip-flop, die bij T = 1 omkeert en in tellers wordt gebruikt. In huidige ontwerpen is het D-type de hoofdstroom.
