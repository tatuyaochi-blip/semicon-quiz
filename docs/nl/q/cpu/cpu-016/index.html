CPU en architectuur

Welke volgorde van het geheugenhiërarchie, van snel naar langzaam toegankelijk, is voor een gewone computer juist?

  1. ASSD → hoofdgeheugen → L2-cache → L1-cache → register
  2. BHoofdgeheugen → register → SSD → L1-cache
  3. CRegister → L1-cache → L2-cache → hoofdgeheugen (DRAM) → SSD
Antwoord en toelichting tonen

Antwoord: C. Register → L1-cache → L2-cache → hoofdgeheugen (DRAM) → SSD

Geheugen dichter bij de CPU is sneller en kleiner; geheugen verder weg is langzamer, groter en goedkoper. Richtwaarden zijn: registers minder dan één klokcyclus, L1 circa 1 ns (tientallen KB), L2 enkele ns (enkele MB), L3 enkele tientallen ns (tientallen MB), DRAM circa 100 ns (tientallen GB) en SSD tientallen tot 100 µs (enkele TB). Door veelgebruikte gegevens in snellere niveaus te plaatsen, wordt een in totaal snel geheugen met grote capaciteit goedkoop gerealiseerd.
