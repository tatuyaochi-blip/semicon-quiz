Antwoord en toelichting tonen

Antwoord: B. Magnetoresistive (magnetoweerstand)

MRAM is de afkorting van Magnetoresistive Random Access Memory en leest informatie uit via het magnetoweerstandseffect, waarbij de weerstand met de magnetisatierichting verandert. In de jaren 1990 werden AMR (anisotrope magnetoweerstand) en GMR (reuzenmagnetoweerstand) gebruikt, maar door de ontwikkeling van TMR (tunnelmagnetoweerstand) met een groot weerstandsverschil werd het praktisch bruikbaar. De ontdekking van GMR was het onderwerp van de Nobelprijs voor de Natuurkunde in 2007 en droeg sterk bij aan de grotere capaciteit van HDD's.
