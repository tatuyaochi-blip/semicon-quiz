Computerarithmetiek

Welke uitspraak is juist over het bitpatroon bij enkele precisie in IEEE 754 waarvan het exponentveld uit alleen enen (255) bestaat?

  1. AOngeacht de mantisse stelt het altijd het grootste genormaliseerde getal voor
  2. BBij een mantisse van 0 stelt het oneindig voor, bij een mantisse ongelijk aan 0 NaN
  3. COngeacht de mantisse stelt het altijd 0 voor
Antwoord en toelichting tonen

Antwoord: B. Bij een mantisse van 0 stelt het oneindig voor, bij een mantisse ongelijk aan 0 NaN

De maximale exponentwaarde (alleen enen) is gereserveerd voor speciale waarden. Is de mantisse geheel nul, dan stelt het afhankelijk van het tekenbit positief of negatief oneindig voor; is de mantisse ongelijk aan nul, dan stelt het NaN voor. NaN wordt naargelang de mantisse verder onderverdeeld, zodat kan worden onderscheiden of een berekening een uitzondering veroorzaakt. Het grootste genormaliseerde getal heeft exponentveld 254, en 0 is het bitpatroon waarin zowel de exponent als de mantisse nul zijn. Bij een exponentveld van 0 worden 0 en gedenormaliseerde getallen voorgesteld.
