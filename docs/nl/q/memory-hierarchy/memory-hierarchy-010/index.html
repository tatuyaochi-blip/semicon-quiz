Geheugenhiërarchie en prestaties

Wat is een juist gevolg van het vergroten van de regelgrootte van de cache?

  1. AHet aantal compulsory misses neemt toe en de misstraf wordt kleiner
  2. BDe missratio blijft bij elk programma monotoon dalen
  3. CRuimtelijke lokaliteit wordt beter benut, maar de misstraf wordt groter
Antwoord en toelichting tonen

Antwoord: C. Ruimtelijke lokaliteit wordt beter benut, maar de misstraf wordt groter

Bij een grotere regel wordt nabijgelegen data bij één miss in één keer binnengehaald, zodat bij verwerking met ruimtelijke lokaliteit het aantal compulsory misses afneemt. Daar staat tegenover dat per miss meer data wordt overgedragen, waardoor de misstraf groter wordt; bij gelijke capaciteit neemt bovendien het aantal regels af, waardoor conflictmisses en het inlezen van ongebruikte data toenemen. Een te grote regel kan de missratio dus juist verhogen; de missratio daalt niet onbeperkt. Dat het aantal compulsory misses toeneemt is eveneens omgekeerd.
