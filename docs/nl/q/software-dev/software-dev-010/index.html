Softwareontwikkeling en projectmanagement

Welk UML-diagram is geschikt om te laten zien hoe de toestand van een object verandert als reactie op gebeurtenissen (een druk op een knop, een timer die afloopt, een temperatuur die wordt bereikt enzovoort), zoals in de besturingssoftware van een rijstkoker?

  1. AKlassendiagram
  2. BUse-casediagram
  3. CState-machinediagram
Antwoord en toelichting tonen

Antwoord: C. State-machinediagram

Een state-machinediagram (toestandsdiagram) toont de mogelijke toestanden, welke gebeurtenis tot welke toestand leidt (een transitie) en de acties die daarbij worden uitgevoerd. Het wordt vaak gebruikt om software te ontwerpen waarvan het gedrag ook bij dezelfde invoer afhangt van de huidige toestand, zoals bij de besturing van embedded apparaten. Een klassendiagram toont de statische structuur van klassen, hun attributen en operaties en de relaties tussen klassen. Een use-casediagram toont de functies van het systeem zoals de gebruikers (actoren) die zien.
