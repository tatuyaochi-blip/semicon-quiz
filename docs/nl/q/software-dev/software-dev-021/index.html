Softwareontwikkeling en projectmanagement

De waarheidswaarden van a, b en c kunnen onafhankelijk van elkaar worden gekozen. Hoeveel testgevallen zijn er voor de code „if (a) { S1; } if (b) { S2; } if (c) { S3; }” minimaal nodig om takdekking te bereiken (de uitkomsten waar en onwaar van elke beslissing elk minstens één keer uitvoeren)?

  1. A1
  2. B2
  3. C8
Antwoord en toelichting tonen

Antwoord: B. 2

Elk van de drie beslissingen moet in beide richtingen worden genomen, waar en onwaar. Met de twee testgevallen (a, b en c allemaal waar) en (allemaal onwaar) worden de uitkomsten waar en onwaar van elke beslissing elk één keer uitgevoerd, dus het minimum is 2. Eén testgeval (allemaal waar) voert alle statements S1 tot S3 uit en bereikt zo statementdekking, maar de onware takken (de paden die niets doen en doorgaan) worden niet uitgevoerd. 8 is het aantal van alle 2³ = 8 combinaties van waar en onwaar.

Meer vragen over Softwareontwikkeling en projectmanagement

  1. Voor de beslissing „A en B” (A en B zijn voorwaarden waarvan de waarheidswaarden onafhankelijk kunnen worden gekozen) zijn twee testgevallen uitgevoerd: (A = waar, B = onwaar) en (A = onwaar, B = waar). Welke uitspraak over de dekkingscriteria is juist?
  2. Wat wordt bij bottom-uptesten gebouwd als vervanging van een module op hoger niveau die nog niet bestaat, zodat die de te testen module op lager niveau aanroept, er testgegevens aan doorgeeft en de resultaten ontvangt?
  3. Tijdens het testen is een betrouwbaarheidsgroeicurve getekend, met de testtijd (of het aantal uitgevoerde testgevallen) op de horizontale as en het cumulatieve aantal gevonden defecten op de verticale as. De curve stijgt nog steeds en vertoont geen teken van verzadiging (afvlakking). Welke beoordeling is het meest passend?
  4. Bij de integratietest van firmware met 25 KLOC (25.000 regels) zijn 30 defecten gevonden. Volgens eerdere resultaten van de organisatie ligt de richtwaarde voor in deze fase gevonden defecten op 2 tot 4 per KLOC. Welke beoordeling van dit resultaat is het meest passend?
  5. In Git hebben twee ontwikkelaars dezelfde regel van hetzelfde bestand in verschillende branches gewijzigd, waarna de ene branch in de andere is gemerged. Wat gebeurt er?
