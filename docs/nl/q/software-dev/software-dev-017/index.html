Softwareontwikkeling en projectmanagement

Een invoerveld accepteert alleen gehele getallen; waarden van 1 tot en met 100 worden geaccepteerd en alle andere geven een foutmelding. Hoeveel equivalentieklassen zijn er in totaal (geldige en ongeldige klassen samen) als de invoer met equivalentiepartitionering wordt ingedeeld?

  1. A1
  2. B2
  3. C3
Antwoord en toelichting tonen

Antwoord: C. 3

Equivalentiepartitionering verdeelt de invoer in groepen (equivalentieklassen) die het programma op dezelfde manier hoort te behandelen, en test uit elke klasse één representatieve waarde. Voor dit veld zijn er één geldige klasse (1 tot 100) en twee ongeldige klassen (0 of minder, en 101 of meer), samen 3. Met bijvoorbeeld 50, −5 en 150 als representanten wordt elke klasse met drie tests gecontroleerd. De ongeldige invoer wordt opgesplitst in een lage en een hoge kant, omdat het programma ze met afzonderlijke controles afhandelt (de controle op de ondergrens en die op de bovengrens).

Meer vragen over Softwareontwikkeling en projectmanagement

  1. Een programma bepaalt de toegangsprijs op basis van leeftijd (een geheel getal van 0 of meer): 0 tot 17 jaar betaalt het kindertarief, 18 tot 64 jaar het standaardtarief en 65 jaar of ouder het seniorentarief. Welke reeks testwaarden is het meest geschikt voor grenswaardenanalyse om de grenzen te controleren waar de tariefcategorie verandert?
  2. Volgens de specificatie moet er „een waarschuwing worden gegeven als de temperatuur 85 °C of hoger is”, maar in de firmware staat per vergissing „if (t > 85)”. De temperatuur t is een geheel getal. Met welke van de volgende testwaarden kan deze fout worden gevonden?
  3. De waarden van temp en err kunnen onafhankelijk van elkaar worden gekozen. Hoeveel testgevallen zijn er voor de code „if (temp > 80) { fan = HIGH; } else { fan = LOW; } if (err) { log(); }” minimaal nodig om statementdekking te bereiken (elk statement minstens één keer uitvoeren)?
  4. De waarheidswaarden van a, b en c kunnen onafhankelijk van elkaar worden gekozen. Hoeveel testgevallen zijn er voor de code „if (a) { S1; } if (b) { S2; } if (c) { S3; }” minimaal nodig om takdekking te bereiken (de uitkomsten waar en onwaar van elke beslissing elk minstens één keer uitvoeren)?
  5. Voor de beslissing „A en B” (A en B zijn voorwaarden waarvan de waarheidswaarden onafhankelijk kunnen worden gekozen) zijn twee testgevallen uitgevoerd: (A = waar, B = onwaar) en (A = onwaar, B = waar). Welke uitspraak over de dekkingscriteria is juist?
