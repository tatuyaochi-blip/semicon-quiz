Kansrekening, statistiek en wachtrijen

Een server met een gemiddelde bedieningstijd van 0,2 seconden wordt als M/M/1-wachtrij beschouwd. Welke waarde ligt het dichtst bij de maximale aankomstintensiteit die kan worden toegelaten als de gemiddelde responstijd (wachttijd plus verwerkingstijd) hoogstens 1,0 seconde mag zijn?

  1. A4,0 per seconde
  2. B4,2 per seconde
  3. C5,0 per seconde
Antwoord en toelichting tonen

Antwoord: A. 4,0 per seconde

De gemiddelde responstijd is W = Ts/(1 − ρ), dus uit 0,2/(1 − ρ) ≤ 1,0 volgt 1 − ρ ≥ 0,2, ofwel ρ ≤ 0,8. Omdat ρ = λ × Ts, is λ ≤ 0,8 ÷ 0,2 = 4,0 per seconde. Bij een aankomstintensiteit van 5,0 per seconde zou de bezettingsgraad 1 zijn en zou de wachtrij onbeperkt groeien.
