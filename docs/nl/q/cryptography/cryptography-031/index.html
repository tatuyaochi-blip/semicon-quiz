Basis en toepassingen van cryptografie

Welke uitspraak over mutual TLS (mTLS) is juist?

  1. AEen schema dat de TLS-versleuteling twee keer over elkaar toepast om de sterkte van de versleuteling te verdubbelen
  2. BEen schema dat binnen één verbinding tegelijk zowel het protocol TLS 1.2 als TLS 1.3 gebruikt
  3. CEen schema waarbij niet alleen de server maar ook de client een certificaat toont, zodat beide kanten elkaar authenticeren
Antwoord en toelichting tonen

Antwoord: C. Een schema waarbij niet alleen de server maar ook de client een certificaat toont, zodat beide kanten elkaar authenticeren

Bij gewone TLS controleert alleen de client het certificaat van de server, en de client wordt geauthenticeerd met mechanismen bovenop TLS, zoals wachtwoorden of tokens. Bij mutual TLS vraagt de server ook de client om een certificaat, en de client stuurt zijn certificaat en een handtekening die met de bijbehorende privésleutel is gemaakt. Het wordt vaak gebruikt voor authenticatie tussen machines die niet door mensen worden bediend, zoals communicatie tussen microservices, verbindingen tussen IoT-apparaten en servers, en netwerken die op het zero-trustprincipe zijn gebaseerd.
