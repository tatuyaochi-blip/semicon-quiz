Compilers

Welke fout wordt het best gevonden door de semantische analyse van een compiler?

  1. AAan een variabele voor een geheel getal wordt een waarde van een niet-passend type toegewezen
  2. BDe puntkomma aan het einde van een statement is vergeten
  3. CBij het uitvoeren van het programma treedt halverwege een deling door 0 op
Antwoord en toelichting tonen

Antwoord: A. Aan een variabele voor een geheel getal wordt een waarde van een niet-passend type toegewezen

Semantische analyse onderzoekt bij een programma dat grammaticaal correct is geschreven of de types kloppen, of geen niet-gedeclareerde namen worden gebruikt en of het aantal argumenten dat aan een functie wordt doorgegeven juist is. Een toewijzing met een niet-passend type is een typische fout die in deze fase wordt gevonden. Een vergeten puntkomma is een grammaticafout en wordt door parsing gevonden. Een deling door 0 is een runtime-fout die pas bij uitvoering optreedt en in het algemeen niet door de compiler wordt gevonden.
