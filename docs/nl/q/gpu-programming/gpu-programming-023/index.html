GPU-programmeren

Welke uitspraak over de bezettingsgraad (occupancy) van een GPU is juist?

  1. AHet aandeel van het chipoppervlak van de GPU dat door rekeneenheden wordt ingenomen
  2. BDe verhouding van het werkelijke aantal warps dat op een SM staat tot het maximale aantal warps dat tegelijk op een SM kan staan
  3. CHet aandeel van het geheugen van de GPU dat met data is gevuld
Antwoord en toelichting tonen

Antwoord: B. De verhouding van het werkelijke aantal warps dat op een SM staat tot het maximale aantal warps dat tegelijk op een SM kan staan

Het aantal warps dat een SM tegelijk kan laden heeft een bovengrens, en het werkelijke aantal wordt bepaald door onder meer de registers per thread, het shared memory per block en de blockgrootte. Die verhouding is de occupancy. Bij een lage occupancy zijn er weinig warps die kunnen worden uitgevoerd in plaats van de warps die op geheugen wachten, en staan de rekeneenheden gemakkelijk stil. CUDA biedt ook een tool om de occupancy te berekenen.
