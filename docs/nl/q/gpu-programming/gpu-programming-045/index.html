GPU-programmeren

Welke uitspraak is juist over een kenmerk van GPU-caches in vergelijking met CPU's?

  1. AEen GPU heeft helemaal geen cache
  2. BOok een GPU heeft L1- en L2-caches, maar omdat het aantal threads dat tegelijk draait zeer groot is, is de cachecapaciteit per thread veel kleiner
  3. CDe cache van een GPU is per thread vele malen groter dan die van een CPU
Antwoord en toelichting tonen

Antwoord: B. Ook een GPU heeft L1- en L2-caches, maar omdat het aantal threads dat tegelijk draait zeer groot is, is de cachecapaciteit per thread veel kleiner

Ook een GPU heeft per SM een L1-cache en een L2-cache die door de hele chip wordt gedeeld, maar omdat tienduizenden threads tegelijk draaien, is de capaciteit per thread ordes van grootte kleiner dan voor één CPU-thread. Het uitgangspunt van de GPU is niet latentie te verminderen door op de cache te vertrouwen, maar latentie te verbergen door tussen veel warps om te schakelen en het geheugengebruik te verbeteren met coalesced toegang en shared memory.
