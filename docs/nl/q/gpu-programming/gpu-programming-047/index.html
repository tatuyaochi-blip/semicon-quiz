GPU-programmeren

Op een GPU wil men alleen de elementen die aan een voorwaarde voldoen uit een array halen en in een andere array compact wegschrijven (elke thread levert 0 of 1 uitvoer). Welke parallelle berekening wordt veel gebruikt om het schrijfadres van elke thread te bepalen?

  1. AMatrixtranspositie
  2. BPrefix sum (scan, cumulatieve som van voren af)
  3. CSnelle Fouriertransformatie
Antwoord en toelichting tonen

Antwoord: B. Prefix sum (scan, cumulatieve som van voren af)

Als voor elke thread met 0 of 1 wordt aangegeven of hij een uitvoer levert en de cumulatieve som van voren af (exclusieve prefix sum) wordt bepaald, wordt de waarde van elke thread 'het aantal threads vóór hem dat een uitvoer levert', en dat is direct het schrijfadres. Een scan kan net als een reductie in boomvorm parallel worden berekend. Het is een basisinstrument om bewerkingen waarvan het aantal uitvoeren per element verschilt, parallel compact weg te schrijven.
