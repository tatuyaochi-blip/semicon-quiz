GPU-programmeren

Welke uitspraak over het verschil in ontwerpfilosofie tussen CPU en GPU is juist?

  1. ADe CPU legt de nadruk op doorvoer met veel eenvoudige cores en de GPU maakt één taak sneller met enkele krachtige cores
  2. BHet verschil tussen CPU en GPU zit alleen in de naam; de opbouw is hetzelfde
  3. CDe CPU legt de nadruk op het zo snel mogelijk voltooien van één taak met enkele krachtige cores en de GPU legt de nadruk op de totale doorvoer met veel eenvoudige rekeneenheden
Antwoord en toelichting tonen

Antwoord: C. De CPU legt de nadruk op het zo snel mogelijk voltooien van één taak met enkele krachtige cores en de GPU legt de nadruk op de totale doorvoer met veel eenvoudige rekeneenheden

De CPU besteedt zijn schakelingen aan grote caches, sprongvoorspelling, out-of-order-uitvoering e.d. om één thread zo snel mogelijk te laten vorderen. De GPU vereenvoudigt die schakelingen en plaatst daarvoor in de plaats veel meer rekeneenheden, die duizenden threads tegelijk uitvoeren om de totale doorvoer te vergroten. Ook als elke thread afzonderlijk traag is, is de GPU bij werk waarbij dezelfde bewerking op grote hoeveelheden data wordt uitgevoerd vele malen sneller.
