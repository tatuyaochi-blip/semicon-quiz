A/D- en D/A-conversie

Welke uitspraak over de code "offset binary", die wordt gebruikt bij ADC's voor zowel positieve als negatieve spanningen, is juist?

  1. AHet teken wordt uitsluitend door de hoogste bit weergegeven en de overige bits geven de absolute waarde
  2. BHet negatieve full-scale is helemaal 0, het positieve full-scale helemaal 1 en 0 V wordt weergegeven door de middencode
  3. CAlle negatieve waarden worden samengevoegd tot de code met louter nullen
Antwoord en toelichting tonen

Antwoord: B. Het negatieve full-scale is helemaal 0, het positieve full-scale helemaal 1 en 0 V wordt weergegeven door de middencode

Bij offset binary is het negatieve full-scale 000…0, het positieve full-scale 111…1 en wordt 0 V weergegeven door een code rond het midden (100…0). Ten opzichte van twee-complement is alleen de hoogste bit geïnverteerd, zodat omzetting eenvoudig is. Omdat binnen een ADC het eenvoudig van onderaf tellende offset binary natuurlijk is, wordt deze code vaak voor de uitgang gebruikt; de digitale verwerking zet haar voor de berekening om in twee-complement.
