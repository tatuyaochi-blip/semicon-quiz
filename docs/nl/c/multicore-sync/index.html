Multicore en synchronisatie: kernpunten

In een multicore-CPU, waarin meerdere cores op één chip zitten, heeft elke core zijn eigen cache en delen alle cores hetzelfde geheugen. Coherentieprotocollen zoals MESI beheren de toestand van de caches, zodat een core niet met verouderde gegevens werkt nadat een andere core ze heeft gewijzigd.

Verder moet u geheugenconsistentiemodellen begrijpen, die bepalen in welke volgorde schrijfacties voor andere cores zichtbaar worden, atomaire instructies waarmee meerdere cores veilig een waarde bijwerken, locks en geheugenbarrières. U leert ook valkuilen zoals false sharing en data races, waardoor een ogenschijnlijk correct programma traag wordt of fout werkt.
