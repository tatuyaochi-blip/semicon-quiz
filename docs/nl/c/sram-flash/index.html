SRAM en flashgeheugen: kernpunten

SRAM is een geheugen dat gegevens vasthoudt in een latch van twee kruislings gekoppelde inverters. Het is snel en heeft geen refresh nodig. Het wordt gebruikt in onder meer CPU-cachegeheugen, maar neemt per bit meer oppervlak in beslag.

Flashgeheugen is niet-vluchtig geheugen dat zijn gegevens ook zonder spanning behoudt. Er bestaan NAND-flash, geschikt voor opslag met grote capaciteit, en NOR-flash, met snel willekeurig uitlezen. Het opslaan van meerdere bits per cel (multi-level) is volop in ontwikkeling.
