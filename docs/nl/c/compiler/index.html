Compilers: kernpunten

Een compiler is software die een door een mens geschreven programma vertaalt naar machinecode die de CPU kan uitvoeren. De broncode wordt via lexicale analyse (opdelen in tokens), syntactische analyse (opbouwen van een boomstructuur volgens de grammatica) en semantische analyse (controle van typen en namen) omgezet in een tussenrepresentatie (IR).

Op de tussenrepresentatie worden optimalisaties uitgevoerd, zoals constant folding, eliminatie van gemeenschappelijke subexpressies, inlining, loop unrolling en vectorisatie. Ten slotte genereren registertoewijzing en instructieplanning code die bij de CPU past. Wie begrijpt hoe optimalisatie werkt, weet hoe snelle programma's worden geschreven en hoe de prestaties van de hardware worden benut.
