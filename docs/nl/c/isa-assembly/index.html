Instructieset en assembly: kernpunten

Een instructiesetarchitectuur (ISA) is de overeenkomst tussen software en hardware. Daarin is vastgelegd welke instructies er zijn, met welke bitpatronen ze worden voorgesteld en hoe registers en geheugen worden aangeduid. Zolang dezelfde ISA wordt gevolgd, draait hetzelfde programma ook op CPU's met een andere interne opbouw.

Assemblytaal is een voor mensen leesbare notatie van machinecode-instructies. Wie de basisinstructies van RISC-V, het gebruik van registers, het doorgeven van argumenten en retourwaarden bij functieaanroepen (aanroepconventie) en het opbouwen van stackframes kent, begrijpt de code die een compiler genereert en hoe een programma op de CPU draait.
