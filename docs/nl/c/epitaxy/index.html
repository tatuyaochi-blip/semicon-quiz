Epitaxiale groei: kernpunten

Epitaxiale groei is een techniek waarbij een monokristallijne dunne laag op een monokristallijn substraat wordt gegroeid met dezelfde kristaloriëntatie als het substraat. Omdat lagen met een nauwkeurig geregelde onzuiverheidsconcentratie kunnen worden gemaakt, wordt de techniek gebruikt voor onder meer vermogenscomponenten, bipolaire componenten en verbindingshalfgeleidercomponenten.

Er is homo-epitaxie, waarbij hetzelfde materiaal als het substraat wordt gegroeid, en hetero-epitaxie, waarbij een ander materiaal wordt gegroeid. Bij de laatste moet worden gelet op defecten door het verschil in roosterconstante (roostermismatch).
