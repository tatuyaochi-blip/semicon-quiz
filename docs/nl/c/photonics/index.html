シリコンフォトニクス: kernpunten

シリコンフォトニクスは、CMOSと同じシリコンの製造技術を使って、光を通す導波路や変調器、受光器などを1つのチップに集積する技術です。シリコンは通信に使う1.31〜1.55 µm帯の光をほとんど吸収せず、周囲の酸化膜との屈折率差が大きいため、光を小さな回路に強く閉じ込められます。

AIの学習などでデータセンターの通信量が急増し、電気配線では高速化に伴って損失や消費電力が増え続けています。光トランシーバや、スイッチICのすぐ近くに光部品を実装するCPOなどの光インターコネクトは、こうした課題を解決する中心技術として注目されています。
